## Konvensi

- **Satu topik = satu file** di dalam folder level/modul terkait.
- Nama file materi memakai nomor urut (`01.`, `02.`, …) agar urutannya konsisten.
- Nama folder level: `Level N - <Nama>`; bagian: `A.`, `B.`, `C.`, ….
- Link antar catatan memakai wiki-link `[[Nama Catatan]]` (Obsidian mencocokkan berdasarkan nama file, jadi aman dipindah antar folder).
- Untuk menghindari link ambigu, hindari dua file dengan **nama yang sama** di folder berbeda.
