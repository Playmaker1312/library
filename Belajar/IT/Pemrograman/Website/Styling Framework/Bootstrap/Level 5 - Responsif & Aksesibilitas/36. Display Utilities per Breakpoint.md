# Display Utilities per Breakpoint

## Penjelasan

Bootstrap memiliki utility `d-{value}` yang bisa dikombinasikan dengan breakpoint untuk menampilkan atau menyembunyikan elemen di ukuran layar tertentu. Ini memungkinkan kita menyajikan konten berbeda untuk mobile vs desktop tanpa JavaScript.

## Fungsi

- Menyembunyikan navigasi kompleks di mobile, menampilkan tombol hamburger
- Menampilkan tabel penuh di desktop, versi card/list di mobile
- Mengatur urutan elemen berbeda per breakpoint
- Menghemat bandwidth dengan tidak mengirim konten yang tidak perlu secara visual

## Cara Pengimplementasian

```html
<!-- Navigasi: hamburger di mobile, horizontal di desktop -->
<nav>
  <!-- Tombol menu mobile, hanya terlihat di < md -->
  <button class="d-md-none navbar-toggler">☰</button>

  <!-- Menu navigasi, tersembunyi di mobile, flex di desktop -->
  <ul class="d-none d-md-flex list-unstyled gap-3">
    <li>Beranda</li>
    <li>Tentang</li>
    <li>Kontak</li>
  </ul>
</nav>

<!-- Teks berbeda: singkat di mobile, panjang di desktop -->
<p class="d-md-none">Baca selengkapnya...</p>
<p class="d-none d-md-block">
  Ini adalah paragraf lengkap yang hanya muncul di layar tablet ke atas.
</p>

<!-- Tabel vs Card -->
<table class="d-none d-lg-table">
  Tabel penuh di desktop
</table>
<div class="d-lg-none">
  <div class="card">Card item 1</div>
  <div class="card">Card item 2</div>
</div>

<!-- Responsive Order -->
<div class="d-flex flex-column flex-md-row">
  <div class="order-2 order-md-1">Konten utama (pertama di desktop)</div>
  <div class="order-1 order-md-2">Sidebar (kedua di desktop)</div>
</div>
```

```css
/* Fallback jika tidak pakai utility Bootstrap */
.mobile-only {
  display: block;
}
.desktop-only {
  display: none;
}

@media (min-width: 768px) {
  .mobile-only {
    display: none;
  }
  .desktop-only {
    display: block;
  }
}
```

## Analogi

Display utilities = **perabot yang muncul/sembunyi di ruangan tertentu**. Di ruangan sempit (mobile), lemari besar disembunyikan, hanya kursi lipat yang kelihatan. Di ruangan luas (desktop), lemari dan meja besar ditampilkan. Nomor urut perabot juga bisa diubah — di ruang sempit kursi tamu didepan, di ruang luas lemari yang pertama.

## Dipakai untuk apa

- Navigasi mobile dengan collapse/hamburger
- Ads banner yang berbeda ukuran per device
- Sidebar yang hanya muncul di desktop (`d-none d-lg-block`)
- Kolom tambahan tabel yang hanya relevan di layar lebar
- Elemen "back to top" hanya di mobile (`d-md-none`)

## Kesalahan umum yang sering terjadi

- **`d-none` tanpa breakpoint** — Elemen hilang permanen di semua layar
- **Lupa `d-*-block` atau `d-*-flex`** — Setelah `d-none`, harus dinyalakan dengan class display lain
- **Menggunakan `d-none` untuk konten penting** — Screen reader tetap membaca elemen `d-none`? Ya, kecuali pakai `visually-hidden` atau `aria-hidden`
- **Terlalu banyak variasi** — Membingungkan maintainer; usahakan maksimal 2 versi per elemen

## Koneksi dengan materi sebelumnya

Setelah audit mobile-first (materi 34) kita tahu elemen mana yang perlu disembunyikan/ditampilkan di mobile. Display utilities per breakpoint adalah alat eksekusinya. Bersama responsive spacing (materi 35) dan grid (level 4), kita bisa mengatur tata letak lengkap.

## Soal latihan & jawaban

**Soal 1:** Tulislah class agar elemen tersembunyi di mobile dan muncul sebagai block di desktop!

**Jawaban:** `d-none d-lg-block`

**Soal 2:** Bagaimana cara membuat gambar hero muncul di desktop tapi diganti teks di mobile?

**Jawaban:**
```html
<img src="hero.jpg" class="d-none d-md-block" alt="Hero">
<p class="d-md-none">Teks hero versi mobile</p>
```

**Soal 3:** Kapan sebaiknya menggunakan `d-none` vs `visually-hidden`?

**Jawaban:** `d-none` untuk menyembunyikan elemen secara visual DAN dari layout (tidak terlihat dan tidak memakan ruang). `visually-hidden` untuk menyembunyikan secara visual tapi tetap dibaca screen reader. Gunakan `visually-hidden` jika konten tetap penting untuk aksesibilitas.
