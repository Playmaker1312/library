# Lighthouse Audit

## Penjelasan

Lighthouse adalah alat audit otomatis dari Chrome DevTools yang mengukur kualitas website dalam 4 kategori: Performance, Accessibility, Best Practices, SEO. Target ideal: Performance ≥85, Accessibility ≥95, Best Practices ≥90, SEO ≥90.

## Fungsi

- Mengukur performa loading website secara objektif
- Mendeteksi masalah aksesibilitas yang terlewat
- Memberi rekomendasi perbaikan konkret
- Memvalidasi praktik terbaik dan SEO teknis

## Cara Pengimplementasian

Buka Chrome → F12 → tab Lighthouse → pilih categories → Generate report.

```html
<!-- 1. Lazy loading untuk gambar di bawah fold -->
<img src="hero.jpg" alt="Hero" loading="lazy">

<!-- 2. Width & height untuk gambar — cegah CLS -->
<img src="logo.png" alt="Logo" width="200" height="50" loading="eager">
<img src="foto-artikel.jpg" alt="Artikel" width="800" height="450" loading="lazy">

<!-- 3. Preload font untuk mempercepat FCP -->
<link rel="preload" href="fonts/inter-var.woff2" as="font" type="font/woff2" crossorigin>

<!-- 4. Meta description untuk SEO -->
<head>
  <meta name="description" content="Toko online sepatu terpercaya dengan pengiriman seluruh Indonesia. Beli sepatu original harga murah!">
  <title>Toko Sepatu Online | Sepatu Original Murah</title>
</head>

<!-- 5. Minify CSS/JS — pastikan sudah di-build -->
<!-- Sebelum: banyak spasi dan komentar -->
<!-- Sesudah: satu baris, tanpa komentar -->
```

```html
<!-- Implementasi lengkap di HTML -->
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Deskripsi unik untuk setiap halaman — jangan copy paste">

  <!-- Preload font kritis -->
  <link rel="preload" href="/fonts/primary.woff2" as="font" type="font/woff2" crossorigin>

  <!-- CSS sudah diminify -->
  <link rel="stylesheet" href="style.min.css">

  <!-- Defer non-critical CSS -->
  <link rel="stylesheet" href="non-critical.css" media="print" onload="this.media='all'">
</head>
<body>
  <header>
    <a href="#main" class="visually-hidden-focusable">Skip to content</a>
  </header>

  <main id="main">
    <!-- Hero image dengan width/height dan lazy loading -->

      <img src="artikel1.webp" alt="Ilustrasi artikel" width="800" height="450" loading="lazy">
      <p>Konten artikel...</p>
    </section>
  </main>
</body>
</html>
```

## Analogi

Lighthouse audit = **sertifikat kelayakan rumah**. Petugas (Lighthouse) datang memeriksa: struktur kokoh? (Performance — ≥85), akses untuk disabilitas? (Accessibility — ≥95), menggunakan material standar? (Best Practices — ≥90), mudah ditemukan orang? (SEO — ≥90). Laporan berisi nilai dan rekomendasi: "perbaiki fondasi", "tambah ramp kursi roda", "ganti kabel yang tidak standar", "pasang papan nama lebih jelas".

## Dipakai untuk apa

- Quality gate sebelum deploy ke production
- Benchmark performa website
- Mendeteksi regression setelah perubahan besar
- Memenuhi SLA client atau standar perusahaan

## Perbaikan umum berdasarkan kategori

| Kategori | Masalah | Solusi |
|----------|---------|--------|
| **Performance** | Gambar terlalu besar | WebP + lazy loading + width/height |
| **Performance** | Font blocking render | Preload font, swap |
| **Performance** | CSS/JS besar | Minify + tree shaking (materi 39) |
| **Accessibility** | Tidak ada skip link | Tambah `visually-hidden-focusable` |
| **Accessibility** | Kontras warna kurang | Perbaiki rasio ≥4.5:1 |
| **Accessibility** | Tombol tanpa label | Tambah `aria-label` |
| **Best Practices** | HTTPS tidak aktif | Aktifkan SSL |
| **Best Practices** | Console error | Perbaiki error JS |
| **SEO** | Tidak ada meta description | Tambah `<meta name="description">` |
| **SEO** | Title tidak deskriptif | Perbaiki `<title>` per halaman |

## Koneksi dengan materi sebelumnya

Lighthouse adalah **ujian akhir** level ini. Semua materi sebelumnya — mobile audit (34), spacing responsif (35), display utility (36), ARIA/keyboard (37), visually-hidden/kontras (38), optimasi CSS (39) — semuanya berdampak pada skor Lighthouse. Target accessibility ≥95 menuntut penerapan seluruh materi 34-38. Target performance ≥85 menuntut optimasi materi 39.

## Soal latihan & jawaban

**Soal 1:** Sebutkan target skor minimum untuk masing-masing kategori Lighthouse!

**Jawaban:**
- Performance: ≥85
- Accessibility: ≥95
- Best Practices: ≥90
- SEO: ≥90

**Soal 2:** Mengapa gambar perlu atribut `width` dan `height` + `loading="lazy"`?

**Jawaban:**
- `width` & `height` mencegah Cumulative Layout Shift (CLS) — gambar tidak "melompat" saat loading
- `loading="lazy"` menunda loading gambar di bawah fold, mempercepat First Contentful Paint (FCP)

**Soal 3:** Sebutkan 3 perbaikan untuk meningkatkan skor Accessibility Lighthouse!

**Jawaban:**
1. Tambah skip link (`visually-hidden-focusable`)
2. Pastikan kontras warna teks ≥4.5:1
3. Tambah `aria-label` atau `visually-hidden` untuk semua tombol ikon
