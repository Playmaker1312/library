# Form Dasar — Buku Tamu

## Penjelasan
**Form** adalah komponen untuk mengumpulkan input dari pengguna. Dalam analogi **Membangun Rumah**, form adalah **buku tamu** yang diletakkan di meja depan — ada kolom isian untuk nama (input text), alamat (textarea), pilihan jenis kelamin (select/radio), setuju peraturan (checkbox), dan keterangan tambahan (helper text).

---

## Fungsi
- Menerima input dari pengguna (teks, angka, pilihan, file)
- Mengirim data ke server untuk diproses
- Memvalidasi input sebelum dikirim

---

## Cara Pengimplementasian

```html
<!-- Input Text & Label -->
<div class="mb-3">
  <label for="nama" class="form-label">Nama Lengkap</label>
  <input type="text" class="form-control" id="nama" placeholder="Masukkan nama">
</div>

<!-- Select (Dropdown) -->
<div class="mb-3">
  <label for="kota" class="form-label">Kota</label>
  <select class="form-select" id="kota">
    <option selected>Pilih kota...</option>
    <option value="jakarta">Jakarta</option>
    <option value="bandung">Bandung</option>
    <option value="surabaya">Surabaya</option>
  </select>
</div>

<!-- Textarea -->
<div class="mb-3">
  <label for="alamat" class="form-label">Alamat Lengkap</label>
  <textarea class="form-control" id="alamat" rows="3" placeholder="Masukkan alamat"></textarea>
</div>

<!-- Checkbox -->
<div class="mb-3 form-check">
  <input type="checkbox" class="form-check-input" id="setuju">
  <label class="form-check-label" for="setuju">Saya setuju dengan syarat & ketentuan</label>
</div>

<!-- Radio Button -->
<div class="mb-3">
  <label class="form-label">Jenis Kelamin</label>
  <div class="form-check">
    <input class="form-check-input" type="radio" name="jk" id="laki" value="laki">
    <label class="form-check-label" for="laki">Laki-laki</label>
  </div>
  <div class="form-check">
    <input class="form-check-input" type="radio" name="jk" id="perempuan" value="perempuan">
    <label class="form-check-label" for="perempuan">Perempuan</label>
  </div>
</div>

<!-- Helper Text -->
<div class="mb-3">
  <label for="password" class="form-label">Password</label>
  <input type="password" class="form-control" id="password" aria-describedby="passwordHelp">
  <div id="passwordHelp" class="form-text">Minimal 8 karakter, kombinasi huruf dan angka.</div>
</div>

<!-- Input dengan Validasi -->
<div class="mb-3">
  <label for="email" class="form-label">Email</label>
  <input type="email" class="form-control is-invalid" id="email" value="salah@email">
  <div class="invalid-feedback">Format email tidak valid.</div>
</div>

<!-- Struktur Form Lengkap -->
<form>
  <div class="mb-3">
    <label for="namaLengkap" class="form-label">Nama Lengkap</label>
    <input type="text" class="form-control" id="namaLengkap" placeholder="Nama lengkap">
  </div>

  <div class="mb-3">
    <label for="emailForm" class="form-label">Email</label>
    <input type="email" class="form-control" id="emailForm" placeholder="email@contoh.com">
  </div>

  <div class="mb-3">
    <label for="kotaForm" class="form-label">Kota</label>
    <select class="form-select" id="kotaForm">
      <option selected>Pilih...</option>
      <option value="jakarta">Jakarta</option>
      <option value="bandung">Bandung</option>
    </select>
  </div>

  <div class="mb-3">
    <label for="pesan" class="form-label">Pesan</label>
    <textarea class="form-control" id="pesan" rows="3"></textarea>
  </div>

  <div class="mb-3 form-check">
    <input type="checkbox" class="form-check-input" id="setujuForm">
    <label class="form-check-label" for="setujuForm">Saya setuju</label>
  </div>

  <button type="submit" class="btn btn-primary">Kirim</button>
</form>
```

---

## Analogi — Membangun Rumah
| Elemen | Analogi |
|--------|---------|
| `<form>` | **Buku tamu** — wadah semua isian |
| `<input>` | **Kolom isian di buku tamu** — "Nama: _____" |
| `<label>` | **Label pertanyaan** — "Nama:", "Alamat:" |
| `<textarea>` | **Kotak pesan panjang** — "Kesan & Pesan:" |
| `<select>` | **Daftar pilihan** — seperti kolom "Pilih kota" yang tinggal dicentang |
| `form-check` | **Kotak centang / radio** — seperti "☑ Setuju" di buku tamu |
| `form-text` | **Catatan kecil** — "Isi dengan huruf kapital" |
| `is-invalid` / `invalid-feedback` | **Stempel "SALAH"** — memberi tahu ada yang keliru |

---

## Dipakai untuk apa
- Form registrasi / login
- Form kontak
- Form survey / kuesioner
- Form checkout e-commerce
- Pengaturan profil pengguna

---

## Kesalahan umum yang sering terjadi
| Kesalahan | Solusi |
|-----------|--------|
| Lupa `for` pada label | `for` harus sama dengan `id` input agar label bisa diklik |
| Checkbox tidak tercentang saat diklik labelnya | Pastikan `id` checkbox cocok dengan `for` label |
| `form-select` tertukar dengan `form-control` | Select pakai `form-select`, input/text pakai `form-control` |
| Helper text tidak menggunakan class `form-text` | Gunakan `form-text` agar styling sesuai Bootstrap |
| Validasi tidak muncul | Tambahkan class `is-invalid` / `is-valid` pada input, dan `invalid-feedback` / `valid-feedback` |

---

## Koneksi dengan materi sebelumnya
- **Level 2 — Button (15)**: Form selalu punya tombol submit (`btn btn-primary`).
- **Level 2 — Alert (21)**: Setelah form disubmit, tampilkan alert sukses atau error.
- **Level 1 — Grid**: Form bisa diatur dalam grid untuk tata letak multi-kolom.
- **Level 1 — Spacing**: `mb-3` memberi jarak antar elemen form.
