# 32. Custom Utility & Component

## Penjelasan

Setelah menyiapkan cetakan cat (variabel) di materi sebelumnya, sekarang kita **membuat komponen dan utilitas khusus** yang tidak tersedia di Bootstrap. Seperti tukang kayu yang membuat **meja bundar custom** atau **rak dinding miring** — bentuk yang tidak ada di katalog standar, tapi dibuat dengan alat-alat Bootstrap (mixin) yang sudah ada.

## Fungsi

- Membangun komponen **khusus proyek** yang tidak ada di Bootstrap
- Menggunakan **mixin Bootstrap** (`media-breakpoint-up`, `media-breakpoint-down`, `map-get`) agar komponen tetap responsif
- Membuat **utilitas kustom** seperti `.section`, `.hero`, `.feature-icon`, `.card-hover`
- Menjaga **konsistensi** dengan sistem desain Bootstrap (spacing, warna, breakpoint)

## Cara Pengimplementasian

### Struktur file

```scss
// src/scss/main.scss
// (setelah semua import Bootstrap dan override variabel)

@import "bootstrap/scss/functions";
@import "bootstrap/scss/variables";
@import "bootstrap/scss/variables-dark";

// Override variabel...
$primary: #6C5CE7;
// ...dst

@import "bootstrap/scss/maps";
@import "bootstrap/scss/mixins";  // ← mixins dibutuhkan untuk kustom komponen
@import "bootstrap/scss/root";
@import "bootstrap/scss/reboot";
@import "bootstrap/scss/type";
@import "bootstrap/scss/grid";
@import "bootstrap/scss/buttons";
@import "bootstrap/scss/card";
@import "bootstrap/scss/navbar";
@import "bootstrap/scss/forms";
@import "bootstrap/scss/utilities";

// ============================================
// LAPISAN KUSTOM: Komponen & Utility buatan sendiri
// ============================================

// --- 1. .section — Ruang antar seksi rumah ---
.section {
  padding-top: map-get($spacers, 6) * 1.5;    // 6rem
  padding-bottom: map-get($spacers, 6) * 1.5; // 6rem

  // Di layar lebar, padding lebih besar
  @include media-breakpoint-up(lg) {
    padding-top: map-get($spacers, 8);    // 7rem
    padding-bottom: map-get($spacers, 8);
  }
}

// Variasi section
.section-sm {
  padding-top: map-get($spacers, 4);
  padding-bottom: map-get($spacers, 4);
}

.section-lg {
  padding-top: map-get($spacers, 9);
  padding-bottom: map-get($spacers, 9);
}

// --- 2. .hero — Tampilan depan rumah (landing area) ---
.hero {
  min-height: 80vh;
  display: flex;
  align-items: center;
  background-color: $dark;
  color: $light;

  // Background image via inline style di HTML
  background-size: cover;
  background-position: center;

  @include media-breakpoint-down(md) {
    min-height: 60vh;
    text-align: center;
  }
}

.hero-overlay {
  position: relative;

  &::before {
    content: '';
    position: absolute;
    inset: 0;
    background: linear-gradient(
      135deg,
      rgba($dark, 0.85),
      rgba($primary, 0.6)
    );
  }
}

// --- 3. .feature-icon — Ikon fitur seperti hiasan dinding ---
.feature-icon {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  width: 56px;
  height: 56px;
  border-radius: $border-radius;
  background-color: rgba($primary, 0.1);
  color: $primary;
  font-size: 1.5rem;

  // Ukuran berbeda untuk konteks berbeda
  &-lg {
    width: 72px;
    height: 72px;
    font-size: 2rem;
  }

  &-sm {
    width: 40px;
    height: 40px;
    font-size: 1.125rem;
  }

  // Warna bisa disesuaikan
  &-secondary {
    background-color: rgba($secondary, 0.1);
    color: $secondary;
  }

  &-warning {
    background-color: rgba($warning, 0.15);
    color: darken($warning, 20%);
  }
}

// --- 4. .card-hover — Kartu yang berefek saat disentuh ---
.card-hover {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
  cursor: pointer;

  &:hover {
    transform: translateY(-4px);
    box-shadow: $box-shadow-lg;
  }
}

// Variasi card-hover dengan warna berbeda
.card-hover-primary {
  @extend .card-hover;

  &:hover {
    border-color: $primary;
    box-shadow: 0 8px 32px rgba($primary, 0.2);
  }
}
```

## Analogi

| Komponen | Analogi Membangun Rumah |
|---|---|
| `.section` | Ruang tamu, ruang tidur — area dengan fungsi spesifik |
| `.hero` | Tampak depan/fasad rumah — yang pertama dilihat |
| `.feature-icon` | Hiasan dinding, lampu hias — aksen dekoratif |
| `.card-hover` | Pintu yang "menyambut" saat disentuh (efek interaksi) |
| `media-breakpoint-up` | Mengukur ruangan — "kalau rumah lebih lebar dari 4m, pasang jendela besar" |
| `map-get($spacers, 6)` | Mengambil jarak dari cetakan — ambil ukuran "6 palu" dari rak |

## Dipakai untuk apa

- **Landing page** — hero, section, feature icons adalah komponen wajib
- **Halaman profil perusahaan** — section untuk tim, layanan, testimoni
- **Dashboard admin** — card-hover untuk menu atau statistik yang interaktif
- **Portfolio** — menampilkan proyek dengan efek hover yang profesional

## Kesalahan umum yang sering terjadi

1. **Menggunakan mixin tanpa import `mixins`** — error `Undefined mixin 'media-breakpoint-up'`
2. **Salah urutan parameter `map-get`** — formatnya `map-get($map, $key)`, bukan `map-get($key, $map)`
3. **Lupa import `maps`** — `$spacers`, `$theme-colors`, dan map lainnya tidak tersedia
4. **`@extend` di luar konteks** — `@extend .card-hover` tidak akan berfungsi jika `.card-hover` didefinisikan di file yang berbeda tanpa diimport
5. **Hardcode value** — menulis `padding-top: 112px` padahal sudah ada `map-get($spacers, 8)` — tidak konsisten dengan sistem desain

## Koneksi dengan materi sebelumnya

- **Materi 30 (Struktur File)**: Mixins dan maps adalah "lapisan kerangka" yang harus diimpor sebelum komponen kustom
- **Materi 31 (Override Variables)**: Komponen kustom menggunakan variabel yang sudah di-override (`$primary`, `$spacers`, dll)
- **Level 2 (Responsif)**: `media-breakpoint-up` dan `media-breakpoint-down` adalah versi Sass dari class `.d-md-none`, `.d-lg-block` — bedanya sekarang dipakai di dalam blok SCSS

## Soal Latihan & Jawaban

### Soal 1

Apa fungsi `@include media-breakpoint-up(lg)` di dalam aturan `.section`?

<details>
<summary>Jawaban</summary>

Membuat aturan CSS yang hanya berlaku di layar dengan ukuran `lg` (≥992px) ke atas. Ibarat memberi instruksi: "Kalau rumah punya ruang tamu yang lebih lebar dari 4 meter, pasang lampu gantung."
</details>

### Soal 2

Buat komponen `.badge-custom` yang memiliki:
- Background warna `$primary` dengan opacity 0.15
- Warna teks `$primary`
- Border radius 50px
- Padding horizontal 0.75rem dan vertikal 0.35rem
- Font size 0.75rem

<details>
<summary>Jawaban</summary>

```scss
  display: inline-block;
  background-color: rgba($primary, 0.15);
  color: $primary;
  border-radius: 50px;
  padding: 0.35rem 0.75rem;

  font-weight: 600;
}
```
</details>

### Soal 3

Apa perbedaan antara `media-breakpoint-up(md)` dan `media-breakpoint-down(md)`?

<details>
<summary>Jawaban</summary>

- `media-breakpoint-up(md)`: berlaku untuk layar **≥768px** (tablet ke atas) — `min-width: 768px`
- `media-breakpoint-down(md)`: berlaku untuk layar **<768px** (ponsel) — `max-width: 767.98px`

Keduanya seperti alat ukur yang berbeda: yang satu "kalau ruangan lebih besar dari X", yang lain "kalau ruangan lebih kecil dari X".
</details>
