# Konsep Grid 12 Kolom

## Penjelasan
Bootstrap menggunakan sistem grid 12 kolom yang fleksibel. Halaman dibagi menjadi 12 kolom imajiner yang bisa digabung (col-span) untuk membentuk layout. Sistem ini terdiri dari tiga komponen utama: Container, Row, dan Column.

## Fungsi
Membantu mendesain layout halaman secara terstruktur, rapi, dan responsif tanpa menggunakan CSS manual.

## Cara Pengimplementasian

```html
<div class="container">
  <div class="row">
    <div class="col-4">Kolom 1 (4/12)</div>
    <div class="col-4">Kolom 2 (4/12)</div>
    <div class="col-4">Kolom 3 (4/12)</div>
  </div>
  <div class="row">
    <div class="col-8">Kolom besar (8/12)</div>
    <div class="col-4">Kolom kecil (4/12)</div>
  </div>
</div>
```

```css
/* Tanpa Bootstrap — kita harus menulis ini manual */
.col-4 {
  width: 33.333%;
  float: left;
}
.col-8 {
  width: 66.667%;
  float: left;
}
```

## Analogi
Grid 12 kolom = **denah rumah** yang membagi lahan menjadi 12 bagian sama lebar.
- **Container** = **pondasi** rumah — batas luar di mana bangunan berdiri
- **Row** = **lantai** — setiap lantai bisa memiliki tata ruang berbeda
- **Col** = **ruangan** — ukuran ruangan diukur dari berapa bagian dari 12 yang ditempati

Misal: col-4 = ruangan selebar 4/12 loteng, col-8 = ruangan selebar 8/12 loteng.

## Dipakai untuk apa
Membuat layout halaman: sidebar + konten utama, grid card, galeri foto, dashboard, dan hampir semua tata letak website.

## Kesalahan umum yang sering terjadi
- Menempatkan `.col` langsung di dalam `.container` tanpa `.row` (grid tidak berfungsi)
- Jumlah kolom dalam satu row melebihi 12 (kolom kelebihan akan turun ke baris baru)
- Menganggap bahwa grid 12 kolom berarti halaman harus selalu 12 kolom penuh
- Menggunakan class kolom di luar elemen `.row`

## Koneksi dengan materi sebelumnya
Grid adalah inti Bootstrap. Materi sebelumnya (CDN, npm, file Bootstrap) adalah cara menyiapkan "kotak alat". Sekarang kita mulai benar-benar membangun "rumah" menggunakan denah (grid), pondasi (container), lantai (row), dan ruangan (col).

## Soal latihan & jawaban

**1. Buatlah layout dengan 3 kolom sama lebar menggunakan Bootstrap!**
```html
<div class="container">
  <div class="row">
    <div class="col-4">Kiri</div>
    <div class="col-4">Tengah</div>
    <div class="col-4">Kanan</div>
  </div>
</div>
```

**2. Jika kita punya col-9 dan col-5 dalam satu row, apa yang terjadi?**
col-9 (9/12) + col-5 (5/12) = 14/12 > 12. Kolom ke-5 akan turun ke baris baru karena kelebihan dari total 12 kolom.

**3. Dalam analogi membangun rumah, apa yang diwakili oleh Row?**
Row adalah lantai — setiap lantai memiliki tata letak ruangan (kolom) yang bisa berbeda.
