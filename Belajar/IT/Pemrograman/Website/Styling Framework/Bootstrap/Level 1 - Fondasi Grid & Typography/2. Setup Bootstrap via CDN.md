# Setup Bootstrap via CDN

## Penjelasan
CDN (Content Delivery Network) adalah cara termudah untuk mulai menggunakan Bootstrap tanpa mengunduh atau menginstal apa pun. Cukup tambahkan tag `<link>` dan `<script>` dari server Bootstrap ke halaman HTML.

## Fungsi
Memungkinkan eksperimen cepat dengan Bootstrap — cocok untuk belajar, prototyping, dan project kecil tanpa build tool.

## Cara Pengimplementasian
Salin template lengkap di bawah ini ke file `.html` dan buka di browser.

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Belajar Bootstrap</title>
  <!-- Bootstrap CSS -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="container py-5">
    <h1 class="text-center">Halo, Bootstrap!</h1>
  </div>

  <!-- Bootstrap JS -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Analogi
Setup via CDN seperti **memanggil kontrakan alat berat** — kamu tidak perlu membeli atau menyimpan sendiri, cukup telepon dan alat datang saat dibutuhkan. Cocok untuk proyek kecil atau saat kamu baru belajar membangun "rumah" (website).

## Dipakai untuk apa
Untuk mencoba Bootstrap secara instan: belajar, membuat halaman sederhana, atau prototyping tanpa ribet.

## Kesalahan umum yang sering terjadi
- Lupa menyertakan `<meta name="viewport">` — tanpa ini, tampilan tidak akan responsif
- Salah versi Bootstrap — misal mencampur CSS v5 dengan JS v4
- Meletakkan script di `<head>` bukan sebelum `</body>` (bisa memperlambat render)
- Menggunakan tautan CDN yang sudah usang

## Koneksi dengan materi sebelumnya
Setelah mengenal Bootstrap (materi 1), langkah pertama adalah memasang "kotak alat" ke project. CDN adalah cara termudah. Nanti akan ada cara yang lebih profesional menggunakan npm + Vite (materi 3).

## Soal latihan & jawaban

**1. Dua tag apa yang wajib ada dalam setup CDN Bootstrap?**
`<link>` untuk CSS (di `<head>`) dan `<script>` untuk JavaScript (sebelum `</body>`).

**2. Kenapa `<meta name="viewport">` penting dalam template Bootstrap?**
Karena Bootstrap adalah framework mobile-first. Tag ini memberi tahu browser untuk menyesuaikan lebar halaman dengan lebar perangkat, sehingga grid dan komponen responsif berfungsi dengan benar.

**3. Apa kelebihan utama setup via CDN dibandingkan instalasi manual?**
Tidak perlu mengunduh file, selalu mendapatkan versi terbaru, dan lebih hemat ruang karena file di-cache oleh browser.
