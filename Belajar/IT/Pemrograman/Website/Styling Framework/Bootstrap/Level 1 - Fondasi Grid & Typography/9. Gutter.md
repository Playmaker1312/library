# Gutter

## Penjelasan
Gutter adalah jarak (spasi) antar kolom dalam grid Bootstrap. Di Bootstrap 5, gutter dikontrol dengan class `g-*` (global), `gx-*` (horizontal), dan `gy-*` (vertikal), menggantikan sistem `spacer` dari versi sebelumnya.

## Fungsi
Memberi jarak antar "ruangan" (kolom) agar tidak saling menempel sehingga layout lebih rapi dan mudah dibaca.

## Cara Pengimplementasian

```html
<!-- Gutter global (horizontal + vertikal) -->
<div class="container">
  <div class="row g-3">
    <div class="col-4">Konten</div>
    <div class="col-4">Konten</div>
    <div class="col-4">Konten</div>
  </div>
</div>

<!-- Gutter horizontal saja -->
<div class="row gx-4">
  <div class="col-4">Konten</div>
  <div class="col-4">Konten</div>
  <div class="col-4">Konten</div>
</div>

<!-- Gutter vertikal saja -->
<div class="row gy-2">
  <div class="col-6">Konten</div>
  <div class="col-6">Konten</div>
</div>

<!-- Tanpa gutter (no-gutters di BS4, sekarang g-0) -->
<div class="row g-0">
  <div class="col-6">Konten rapat</div>
  <div class="col-6">Konten rapat</div>
</div>
```

| Class | Ukuran |
|-------|--------|
| `g-0` | 0 |
| `g-1` | 0.25rem |
| `g-2` | 0.5rem |
| `g-3` | 1rem |
| `g-4` | 1.5rem |
| `g-5` | 3rem |

## Analogi
Gutter = **jarak antar ruangan** dalam rumah.
- **g-0** = ruangan berdempetan tanpa sekat
- **g-2** = **koridor sempit** antar kamar
- **g-4** = **koridor lebar** — ruangan terasa lega
- **gx** = jarak kiri-kanan (lebar koridor)
- **gy** = jarak atas-bawah (tinggi antar lantai/mezzanine)

## Dipakai untuk apa
Mengatur kerapatan layout seperti kartu produk, galeri gambar, section konten — penting untuk estetika dan readability.

## Kesalahan umum yang sering terjadi
- Menempatkan class `g-*` pada `.col` — harus pada `.row`
- Mengira `g-*` sama dengan `gap` CSS modern — Bootstrap gutter menggunakan padding negatif di row
- Menggunakan `no-gutters` (class BS4) di Bootstrap 5 — sekarang pakai `g-0`
- Gutter tidak bekerja jika kolom tidak dibungkus `.row`

## Koneksi dengan materi sebelumnya
Setelah memahami container (materi 6), row, dan col (materi 5, 7, 8), gutter adalah "lem" spasi yang membuat tata ruang (layout) tidak terlihat sesak. Dari analogi jarak antar ruangan ini, nantinya akan terhubung ke materi spacing utilities (materi 14) yang lebih general.

## Soal latihan & jawaban

**1. Apa class Bootstrap 5 untuk menghapus semua jarak antar kolom?**
`g-0` pada elemen `.row`.

**2. Bedakan `gx-3` dan `gy-3`!**
`gx-3` mengatur jarak horizontal (kiri-kanan) antar kolom. `gy-3` mengatur jarak vertikal (atas-bawah) antar baris/lantai.

**3. Dalam analogi rumah, apa yang diwakili oleh `g-4`?**
Koridor lebar antar ruangan — sehingga setiap ruangan (kolom) memiliki jarak yang lega satu sama lain.
