# Toast

## Penjelasan
Toast adalah komponen notifikasi kecil yang muncul sementara di sudut layar. Toast bersifat **interaktif** karena muncul sebagai respons terhadap aksi pengguna dan bisa ditutup secara manual atau otomatis setelah beberapa detik.

**Analogi: Bel pintu / notifikasi singkat** — Saat seseorang menekan bel pintu, bunyi "ding-dong" terdengar sebentar lalu diam lagi. Anda bisa melihat siapa yang datang melalui lubang pintu, lalu menutupnya. Toast bekerja seperti itu: muncul singkat, memberitahu sesuatu, lalu menghilang.

---

## Fungsi
- Menampilkan notifikasi singkat (sukses, error, info)
- Memberi umpan balik tanpa mengganggu aktivitas pengguna
- Tidak membutuhkan konfirmasi pengguna (bisa hilang sendiri)

---

## Cara Pengimplementasian

### Struktur Toast
```html
<!-- Container Toast (biasanya di pojok kanan atas) -->
<div class="toast-container position-fixed top-0 end-0 p-3">
  <div id="toastContoh" class="toast" role="alert" aria-live="assertive" aria-atomic="true">
    <div class="toast-header">
      <strong class="me-auto">Notifikasi</strong>
      <small>baru saja</small>
      <button type="button" class="btn-close" data-bs-dismiss="toast"></button>
    </div>
    <div class="toast-body">
      Data berhasil disimpan!
    </div>
  </div>
</div>

<!-- Tombol Trigger -->
<button type="button" class="btn btn-success" onclick="showToast()">Tampilkan Toast</button>
```

### JavaScript untuk Show
```html
<script>
  function showToast() {
    const toastEl = document.getElementById('toastContoh');
    const toast = new bootstrap.Toast(toastEl);
    toast.show();
  }
</script>
```

### Auto Dismiss
```html
<script>
  const toastEl = document.getElementById('toastContoh');
  const toast = new bootstrap.Toast(toastEl, {
    autohide: true,
    delay: 3000   // hilang setelah 3 detik
  });
  toast.show();
</script>
```

### Posisi dengan `position-fixed`
```html
<!-- Pojok kanan atas -->
<div class="toast-container position-fixed top-0 end-0 p-3">...</div>

<!-- Pojok kiri bawah -->
<div class="toast-container position-fixed bottom-0 start-0 p-3">...</div>

<!-- Tengah atas -->
<div class="toast-container position-fixed top-50 start-50 translate-middle">...</div>
```

## Analogi — Bel Pintu / Notifikasi Singkat
| Komponen Bootstrap | Analogi Rumah |
|---|---|
| toast | Bel pintu yang berbunyi |
| toast-container | Rumah tempat bel dipasang |
| toast-header | Bagian atas bel (tombol bel) |
| toast-body | Pesan notifikasi (suara bel) |
| btn-close | Tangan yang membuka pintu lalu menutupnya |
| position-fixed | Lokasi tetap bel di dinding |
| autohide | Bel yang diam sendiri setelah bunyi |

---

## Dipakai untuk apa
- Notifikasi "Data berhasil disimpan" setelah form disubmit
- Peringatan "Koneksi terputus" saat jaringan bermasalah
- Umpan balik aksi (berhasil/gagal) tanpa mengganggu layar
- Pesan singkat "Pesan baru" di aplikasi chat

---

## Kesalahan umum yang sering terjadi
1. **Toast tidak muncul** — lupa memanggil `new bootstrap.Toast()` dan `.show()`.
2. **Toast tidak hilang otomatis** — lupa mengatur `autohide: true` atau properti `delay`.
3. **Toast bertumpuk tidak rapi** — tidak menggunakan `toast-container` sehingga posisi toast kacau.
4. **Lupa `role="alert"`** — aksesibilitas screen reader berkurang.
5. **ID toast duplikat** — jika ada beberapa toast di halaman yang sama, pastikan ID unik.

---

## Koneksi dengan materi sebelumnya
- **Alert** (Level 2) → toast mirip alert tapi lebih ringan dan otomatis menghilang
- **Position** (Level 1) → `position-fixed` digunakan untuk menempatkan toast di tempat tetap
- **Button & Close** (Level 2) → `btn-close` digunakan untuk menutup toast
- **JavaScript Bootstrap** (Level 3) → toast membutuhkan inisialisasi JavaScript

## Soal Latihan & Jawaban

### Soal 1
Buat toast yang muncul di pojok kanan bawah dengan pesan "Data berhasil dihapus!". Toast harus otomatis hilang setelah 2 detik.

**Jawaban:**
```html
<div class="toast-container position-fixed bottom-0 end-0 p-3">
  <div id="toastHapus" class="toast" role="alert">
    <div class="toast-body">
      Data berhasil dihapus!
    </div>
  </div>
</div>

<button class="btn btn-danger" onclick="hapusToast()">Hapus Data</button>

<script>
  function hapusToast() {
    const el = document.getElementById('toastHapus');
    const toast = new bootstrap.Toast(el, { autohide: true, delay: 2000 });
    toast.show();
  }
</script>
```

### Soal 2
Apa yang dimaksud dengan `position-fixed` pada komponen toast dan mengapa digunakan?

**Jawaban:** `position-fixed` membuat elemen berada di posisi tetap pada layar browser, tidak terpengaruh oleh scroll halaman. Pada toast, ini digunakan agar notifikasi selalu terlihat di sudut layar meskipun pengguna menggulir halaman ke bawah.

### Soal 3
Sebutkan dua opsi konfigurasi yang bisa diberikan saat membuat instance Toast dengan JavaScript (`new bootstrap.Toast()`).

**Jawaban:**
1. `autohide` (boolean) — menentukan apakah toast akan hilang secara otomatis (default: `true`).
2. `delay` (number) — waktu dalam milidetik sebelum toast otomatis hilang (default: `5000`).
