# Tabel Bootstrap

## Penjelasan
Bootstrap menyediakan kelas-kelas utility untuk mempercantik tabel HTML standar. Tabel tidak bersifat "interaktif" seperti modal atau accordion, tetapi merupakan komponen penyaji data yang sangat penting dalam halaman web.

**Analogi: Lemari arsip/data** — Lemari arsip kantor memiliki laci-laci yang tersusun rapi, setiap laci berisi folder yang diberi label. Baris pada tabel seperti laci, kolom seperti sekat dalam laci. Lemari yang rapi memudahkan Anda mencari dokumen — sama seperti tabel Bootstrap yang rapi memudahkan pembacaan data.

---

## Fungsi
- Menampilkan data dalam struktur baris dan kolom
- Meningkatkan keterbacaan dengan warna selang-seling (striped)
- Menyesuaikan tampilan tabel di berbagai ukuran layar (responsive)
- Memberi efek hover untuk memudahkan pelacakan baris

---

## Cara Pengimplementasian

### Tabel Dasar
```html
<table class="table">
  <thead>
    <tr>
      <th>#</th>
      <th>Nama</th>
      <th>Usia</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>1</td>
      <td>Andi</td>
      <td>25</td>
    </tr>
    <tr>
      <td>2</td>
      <td>Budi</td>
      <td>30</td>
    </tr>
  </tbody>
</table>
```

### Varian Tabel
```html
<!-- Bordered (garis di semua sel) -->
<table class="table table-bordered">...</table>

<!-- Hover (baris berubah warna saat mouse di atasnya) -->
<table class="table table-hover">...</table>

<!-- Dark theme -->
<table class="table table-dark">...</table>

<!-- Striped (warna baris selang-seling) -->
<table class="table table-striped">...</table>

<!-- Responsive (scroll horizontal di layar kecil) -->
<div class="table-responsive">
  <table class="table">...</table>
</div>
```

### Color Variants
```html
<table class="table table-primary">...</table>   <!-- biru -->
<table class="table table-secondary">...</table> <!-- abu-abu -->
<table class="table table-success">...</table>   <!-- hijau -->
<table class="table table-danger">...</table>    <!-- merah -->
<table class="table table-warning">...</table>   <!-- kuning -->
<table class="table table-info">...</table>      <!-- biru muda -->
<table class="table table-light">...</table>     <!-- terang -->
<table class="table table-dark">...</table>      <!-- gelap -->
```

### Kombinasi
```html
<table class="table table-bordered table-hover table-striped">
  ...
</table>
```

## Analogi — Lemari Arsip/Data
| Komponen Bootstrap | Analogi Rumah |
|---|---|
| table | Lemari arsip |
| thead | Label laci (kategori) |
| tbody | Isi laci |
| tr | Satu laci |
| th / td | Folder dalam laci / data dalam folder |
| table-bordered | Garis sekat antar laci |
| table-hover | Laci yang menyala saat disentuh |
| table-striped | Laci dengan warna selang-seling |
| table-responsive | Lemari yang bisa diperluas/dipersempit |

---

## Dipakai untuk apa
- Menampilkan daftar pengguna, produk, atau transaksi
- Laporan data keuangan atau statistik
- Perbandingan harga atau fitur produk
- Jadwal atau daftar inventaris

---

## Kesalahan umum yang sering terjadi
1. **Lupa tag `<thead>` dan `<tbody>`** — struktur tabel tidak semantik dan styling bisa kacau.
2. **`table-responsive` tidak membungkus tabel** — di layar kecil, tabel akan keluar dari kontainer dan terpotong.
3. **`table-dark` dan `table-striped` tidak bekerja optimal bersama** — striped mungkin tidak terlihat jelas di tema gelap.
4. **Menggunakan `table-bordered` tanpa `table`** — class `table-bordered` hanya bekerja jika `table` juga disertakan.
5. **Warna baris (varian) diaplikasikan ke `<table>` bukan ke `<tr>` atau `<td>`** — untuk mewarnai baris tertentu, gunakan di elemen `<tr>`.

---

## Koneksi dengan materi sebelumnya
- **Grid & Layout** (Level 1) → `table-responsive` menggunakan prinsip grid/breakpoint
- **Warna & Background** (Level 1) → varian warna tabel menggunakan utility yang sama
- **Typography** (Level 1) → styling teks di dalam tabel mengikuti aturan tipografi Bootstrap

## Soal Latihan & Jawaban

### Soal 1
Buat tabel dengan class `table table-bordered table-hover table-striped` yang memiliki kolom No, Nama, dan Kota dengan 3 baris data.

**Jawaban:**
```html
<table class="table table-bordered table-hover table-striped">
  <thead>
    <tr>
      <th>No</th>
      <th>Nama</th>
      <th>Kota</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>1</td>
      <td>Citra</td>
      <td>Jakarta</td>
    </tr>
    <tr>
      <td>2</td>
      <td>Doni</td>
      <td>Bandung</td>
    </tr>
    <tr>
      <td>3</td>
      <td>Eka</td>
      <td>Surabaya</td>
    </tr>
  </tbody>
</table>
```

### Soal 2
Buat tabel dengan tema gelap (`table-dark`) yang memiliki efek hover dan garis border.

**Jawaban:**
```html
<table class="table table-dark table-hover table-bordered">
  <thead>
    <tr>
      <th>Produk</th>
      <th>Harga</th>
    </tr>
  </thead>
  <tbody>
    <tr><td>Buku</td><td>50000</td></tr>
    <tr><td>Pensil</td><td>5000</td></tr>
    <tr><td>Penghapus</td><td>3000</td></tr>
  </tbody>
</table>
```

### Soal 3
Apa fungsi dari `div class="table-responsive"` dan kapan sebaiknya digunakan?

**Jawaban:** `table-responsive` membuat tabel dapat di-scroll secara horizontal di layar yang sempit (mobile/tablet). Sebaiknya digunakan ketika tabel memiliki banyak kolom sehingga tidak muat ditampilkan dalam satu layar penuh pada ukuran viewport kecil.
