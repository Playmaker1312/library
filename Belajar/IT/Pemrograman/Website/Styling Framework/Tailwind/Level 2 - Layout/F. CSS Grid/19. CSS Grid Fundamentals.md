# CSS Grid Fundamentals

## Penjelasan
- `grid`: mengubah elemen menjadi grid container
- `grid-cols-*`: menentukan jumlah kolom (grid-cols-1 sampai grid-cols-12, juga grid-cols-none)
- `grid-rows-*`: menentukan jumlah baris
- `gap-*`: jarak antar cell (baris dan kolom), bisa dipisah dengan `gap-x-*` dan `gap-y-*`
- Grid bersifat **2 dimensi**: mengatur baris DAN kolom secara bersamaan
- Perbedaan flex vs grid:
  - **Flexbox**: 1 dimensi (baris ATAU kolom), cocok untuk distribusi konten dinamis
  - **Grid**: 2 dimensi (baris DAN kolom), cocok untuk layout page yang terstruktur
- Grid implisit vs eksplisit: grid bisa otomatis membuat baris/kolom baru jika item melebihi definisi awal

## Fungsi
Membuat layout dua dimensi dengan baris dan kolom yang terstruktur, cocok untuk halaman dengan area-area yang sudah ditentukan.

## Cara Pengimplementasian / Kode

```html

  <div class="bg-blue-500 text-white p-6 rounded-lg text-center">2</div>

  <div class="bg-blue-500 text-white p-6 rounded-lg text-center">4</div>

  <div class="bg-blue-500 text-white p-6 rounded-lg text-center">6</div>
</div>

<!-- grid-cols-4 dengan gap berbeda -->
<div class="grid grid-cols-4 gap-4 bg-gray-100 p-6 rounded-lg mt-8">
  <div class="bg-green-500 text-white p-4 rounded">1</div>
  <div class="bg-green-500 text-white p-4 rounded">2</div>
  <div class="bg-green-500 text-white p-4 rounded">3</div>
  <div class="bg-green-500 text-white p-4 rounded">4</div>
  <div class="bg-green-500 text-white p-4 rounded">5</div>

<!-- grid dengan 2 kolom + gap + row span implisit -->
<div class="grid grid-cols-2 gap-8 bg-gray-100 p-6 rounded-lg mt-8">
  <div class="bg-purple-500 text-white p-6 rounded-lg">Sidebar (kiri)</div>
  <div class="bg-purple-500 text-white p-6 rounded-lg">Konten utama (kanan)</div>

<div class="grid grid-cols-1 md:grid-cols-3 gap-6 bg-gray-100 p-6 rounded-lg mt-8">
  <div class="bg-orange-500 text-white p-6 rounded-lg">Card 1</div>
  <div class="bg-orange-500 text-white p-6 rounded-lg">Card 2</div>
  <div class="bg-orange-500 text-white p-6 rounded-lg">Card 3</div>
</div>

<!-- Grid dengan auto rows -->
<div class="grid grid-cols-3 gap-4 auto-rows-min bg-gray-100 p-6 rounded-lg mt-8">
  <div class="bg-pink-500 text-white p-8 rounded-lg h-20">Pendek</div>
  <div class="bg-pink-500 text-white p-8 rounded-lg h-40">Sedang</div>
  <div class="bg-pink-500 text-white p-8 rounded-lg h-32">Antara</div>
</div>
```

## Analogi
Grid seperti **rak minuman kaleng** -- ada baris dan kolom yang teratur, setiap kaleng punya slot masing-masing. Anda bisa mengatur berapa kolom (lebar rak) dan berapa jarak antar kaleng. Sedangkan flexbox seperti **antrian orang di kasir** -- hanya satu baris, dan orang-orang mengikuti urutan ke samping atau ke depan. Grid untuk layout struktur halaman, flexbox untuk distribusi konten dalam satu baris/kolom.

## Dipakai untuk Apa
- Layout halaman utama (header, sidebar, main, footer)
- Gallery foto dengan jumlah kolom tetap
- Dashboard dengan widget-widget
- Kartu produk dalam grid
- Form dengan label dan input dalam kolom
- Pricing table

## Kesalahan Umum yang Sering Terjadi
- Menggunakan grid untuk layout sederhana yang cukup dengan flexbox (over-engineering)
- Lupa menambahkan `gap` sehingga cell menempel satu sama lain
- Mengatur `grid-cols-*` tapi tidak memikirkan responsivitas (perlu prefix `md:`, `lg:`)
- Menaruh `gap` di child bukan di parent grid
- Bingung kapan pakai flex vs grid: jika satu dimensi pilih flex, jika dua dimensi pilih grid
- Tidak menggunakan `col-span` untuk item yang ingin melebihi satu kolom

## Koneksi dengan Materi Sebelumnya
Flexbox mengatur layout satu dimensi (baris ATAU kolom). Grid melengkapi dengan kemampuan mengatur **dua dimensi** (baris DAN kolom). Setelah menguasai spacing, flexbox, dan sekarang grid, Anda sudah punya toolkit lengkap untuk membuat layout website profesional. Grid biasanya digunakan untuk layout level halaman, sedangkan flexbox untuk komponen di dalam grid.

## Soal Latihan
Buat layout halaman sederhana dengan:
1. Grid 3 kolom di desktop, 1 kolom di mobile
2. Header (full width, col-span-3 atau col-span-1)
3. Sidebar kiri (1 kolom)
4. Konten utama (2 kolom di desktop)
5. Footer (full width)
6. Gunakan gap untuk jarak yang rapi
