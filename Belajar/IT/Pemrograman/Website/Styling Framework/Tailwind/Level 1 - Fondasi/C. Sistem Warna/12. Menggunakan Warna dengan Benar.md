# Menggunakan Warna dengan Benar

## Penjelasan
- Setiap warna dalam desain harus punya **makna (semantic meaning)** — tidak asal pilih karena "bagus".
- **Semantic color mapping** standar:
  - **Success / Hijau** (`green`): operasi berhasil, konfirmasi, data tersimpan, status aktif.
  - **Error / Merah** (`red`): kesalahan, validasi gagal, hapus data, status kritis.
  - **Info / Biru** (`blue`): informasi umum, notifikasi, update, fitur baru.
  - **Warning / Kuning** (`yellow` atau `amber`): peringatan, hampir habis, perlu perhatian.
  - **Neutral / Abu-abu** (`slate`, `gray`): default, non-aktif, background, teks biasa.
- Selain semantic, konsistensi juga penting: pilih **primary color** (warna utama brand) dan **accent color** (warna aksen untuk CTA/tombol penting).
- Aksesibilitas: pastikan kontras antara teks dan background memenuhi standar WCAG AA minimal (rasio 4.5:1 untuk teks normal, 3:1 untuk teks besar).
- Tips kontras: gunakan setidaknya selisih 3-4 level shade antara background dan teks. Background `blue-50` aman dengan teks `blue-700` atau `blue-800`.

## Fungsi
Warna yang konsisten dan semantik membuat antarmuka lebih intuitif — pengguna langsung paham arti warna tanpa perlu baca teks.

## Cara Pengimplementasian / Kode

```html
<div class="p-8 space-y-4 max-w-md">
  <!-- Success -->
  <div class="bg-green-50 border border-green-200 text-green-700 p-4 rounded-lg">
    <p class="font-medium">Data berhasil disimpan</p>
    <p class="text-sm text-green-600 mt-1">Perubahan sudah tersimpan secara otomatis.</p>
  </div>

  <!-- Error -->
  <div class="bg-red-50 border border-red-200 text-red-700 p-4 rounded-lg">
    <p class="font-medium">Gagal menyimpan data</p>
    <p class="text-sm text-red-600 mt-1">Periksa koneksi internet Anda lalu coba lagi.</p>
  </div>

  <!-- Warning -->
  <div class="bg-amber-50 border border-amber-200 text-amber-700 p-4 rounded-lg">
    <p class="font-medium">Kuota hampir habis</p>
    <p class="text-sm text-amber-600 mt-1">Sisa 2 dari 10 slot. Segera daftar.</p>
  </div>

  <!-- Info -->
  <div class="bg-blue-50 border border-blue-200 text-blue-700 p-4 rounded-lg">
    <p class="font-medium">Update tersedia</p>
    <p class="text-sm text-blue-600 mt-1">Versi 2.4.0 sudah rilis. Klik untuk update.</p>
  </div>

  <!-- Neutral -->
  <div class="bg-gray-50 border border-gray-200 text-gray-700 p-4 rounded-lg">
    <p class="font-medium">Tidak ada notifikasi baru</p>
    <p class="text-sm text-gray-500 mt-1">Semua sudah dibaca.</p>
  </div>
</div>
```

## Analogi
Warna semantik seperti **rambu-rambu lalu lintas di proyek konstruksi**:
- **Hijau** = sukses → seperti "jalan aman, silakan lewat".
- **Merah** = error → seperti "dilarang masuk, area berbahaya".
- **Kuning** = warning → seperti "hati-hati, ada lubang".
- **Biru** = info → seperti "papan petunjuk arah".
- **Abu-abu** = neutral → seperti "trotoar biasa, tidak ada tanda khusus".

Konsisten dengan makna ini membuat pengguna langsung paham tanpa perlu mikir.

## Dipakai untuk Apa
- Alert/notifikasi: success, error, warning, info.
- Tombol: tombol simpan (hijau), tombol hapus (merah), tombol aksi utama (brand color).
- Status badge: aktif (hijau), nonaktif (abu-abu), pending (kuning).
- Form validasi: border merah untuk input error, border hijau untuk input valid.
- Data visualization: chart, progress bar.

## Kesalahan Umum yang Sering Terjadi
- **Tombol hijau untuk hapus**: Hijau secara psikologis berarti "aman/lanjutkan". Jangan pakai hijau untuk aksi destruktif.
- **Merah untuk sukses**: Merah berarti "berhenti/error". Jangan pakai merah untuk notifikasi sukses — membingungkan.
- **Terlalu banyak warna dalam satu halaman**: Pilih 1-2 warna semantik + 1 warna netral. Maksimal 3-4 warna berbeda.
- **Kontras tidak memadai**: Notifikasi kuning dengan teks kuning muda tidak terbaca. Pastikan setidaknya 3-4 level shade selisih.

## Koneksi dengan Materi Sebelumnya
Setelah mempelajari palet warna (materi 11), sekarang kamu belajar *kapan* dan *bagaimana* menggunakan warna yang tepat. Ini bukan soal selera — ini soal psikologi pengguna dan aksesibilitas.

## Soal Latihan

Buat halaman status sistem (system status page) yang menampilkan 4 status: Database (active - green), API Server (warning - amber), Cache (error - red), Email Service (maintenance - info blue). Gunakan semantic color yang benar.
