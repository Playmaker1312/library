# VS Code Setup

## Penjelasan
- **Extension utama**: **Tailwind CSS IntelliSense** — memberikan autocomplete, hover preview, linting, dan class ordering otomatis.
- Cara kerja IntelliSense: membaca `tailwind.config.js` (jika ada) dan file CSS yang meng-import Tailwind, lalu memberikan saran class yang valid beserta nilai CSS-nya.
- **Prettier + Plugin Tailwind**: untuk format otomatis dan sorting class Tailwind.
  - Plugin: `prettier-plugin-tailwindcss` — otomatis mengurutkan class Tailwind sesuai rekomendasi official (layout, spacing, sizing, typography, visual, dll).
- Setup hanya perlu: install extension, install npm package prettier dan plugin, lalu konfigurasi prettier.

## Fungsi
Membuat workflow develop Tailwind jauh lebih cepat — tidak perlu menghafal semua class, format kode otomatis, dan class selalu terurut rapi.

## Cara Pengimplementasian / Kode

```bash
# 1. Install prettier dan plugin tailwind sebagai dev dependency
npm install -D prettier prettier-plugin-tailwindcss
```

```json
// .prettierrc — config Prettier minimal
{
  "plugins": ["prettier-plugin-tailwindcss"],
  "tabWidth": 2,
  "semi": false,
  "singleQuote": true
}
```

```bash
# 2. Install extension "Tailwind CSS IntelliSense" dari VS Code
# Buka VS Code, tekan Ctrl+Shift+X, cari "Tailwind CSS IntelliSense", klik Install
```

```html
<!-- Sebelum Prettier — class berantakan -->
<div class="text-xl p-4 bg-blue-500 font-bold text-white rounded-lg shadow-lg"></div>

<!-- Setelah Prettier — class terurut otomatis -->
<div class="rounded-lg bg-blue-500 p-4 text-xl font-bold text-white shadow-lg"></div>
```

```json
// settings.json VS Code (buka dengan Ctrl+Shift+P → "Preferences: Open Settings (JSON)")
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "[html]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  }
}
```

## Analogi
IntelliSense seperti **asisten arsitek yang hafal semua katalog bata lego** — kamu bilang "saya perlu bata warna biru ukuran sedang", asisten langsung ngasih yang tepat tanpa kamu perlu hafal kode katalognya. Prettier seperti **mandor yang merapikan tumpukan bata** setelah kamu pasang — semua rapi dan teratur tanpa kamu mikir.

## Dipakai untuk Apa
- Semua proyek Tailwind di VS Code — ini adalah setup wajib untuk produktivitas maksimal.

## Kesalahan Umum yang Sering Terjadi
- **Tidak install plugin prettier-tailwindcss, cuma prettier biasa**: Class tidak akan terurut otomatis. Pastikan package `prettier-plugin-tailwindcss` terinstall dan terdaftar di plugins.
- **Lupa set `editor.formatOnSave`**: File tidak otomatis terformat saat disimpan.
- **IntelliSense tidak muncul**: Pastikan ada file CSS yang berisi `@import "tailwindcss"` atau folder `node_modules/tailwindcss` ada. Kadang perlu reload VS Code.
- **Multiple formatter bentrok**: Set `editor.defaultFormatter` ke prettier, terutama untuk HTML.

## Koneksi dengan Materi Sebelumnya
Setelah project lokal (materi 4) aktif, setup VS Code ini adalah tahap akhir setup lingkungan develop. Sekarang kamu punya playground online (Tailwind Play) plus environment lokal profesional dengan autocomplete dan auto-format. Materi selanjutnya akan fokus ke utility class itu sendiri.

## Soal Latihan

Buat proyek Tailwind Vite baru. Setup Prettier + Tailwind plugin. Buat file HTML dengan beberapa class Tailwind yang sengaja diacak urutannya. Format file dengan Prettier dan pastikan class terurut sesuai standar Tailwind.

```bash
npm create vite@latest prettier-test -- --template vanilla
cd prettier-test
npm install
npm install -D tailwindcss @tailwindcss/vite prettier prettier-plugin-tailwindcss
```

```json
// .prettierrc
```

```html
<div class="shadow-lg text-center bg-white mt-10 p-8 rounded-2xl mx-auto max-w-sm border border-gray-200">
```

```bash
# Format manual
```
