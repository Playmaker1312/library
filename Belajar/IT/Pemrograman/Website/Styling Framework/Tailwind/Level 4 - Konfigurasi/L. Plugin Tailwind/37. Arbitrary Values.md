# Arbitrary Values

## Penjelasan

- **Arbitrary Values** adalah fitur Tailwind yang memungkinkan menggunakan nilai kustom langsung di HTML tanpa perlu mendefinisikannya di `tailwind.config.js`.
- Format: `[nilai]` ditempelkan langsung setelah nama properti, contoh `w-[347px]`, `bg-[#1a1a2e]`.
- Tidak terbatas pada properti standar -- bisa menggunakan properti CSS apapun dengan format arbitrari properti.
- **Arbitrary Property** untuk properti CSS yang tidak memiliki utility Tailwind: `[properti:nilai]`, contoh `[&>li]:mt-2`.
- Berguna untuk nilai satu-off yang tidak perlu dimasukkan ke dalam design system.
- Mendukung semua utility: spacing, colors, sizing, typography, layout, grid, transform, filter, dan lainnya.
- Kalkulasi CSS juga bisa: `w-[calc(100%-4rem)]`, `top-[calc(50%-20px)]`.
- Arbitrary value bisa dikombinasikan dengan variant: `hover:bg-[#ff0000]`, `dark:text-[#e0e0e0]`.

## Fungsi

Memberikan fleksibilitas penuh untuk menggunakan nilai CSS kapan saja tanpa perlu memperluas tema di config, cocok untuk desain pixel-perfect atau nilai yang hanya dipakai sekali.

## Cara Pengimplementasian / Kode

```html
<!-- Arbitrary Sizing -->
<div class="w-[347px] h-[200px] bg-blue-500">
  Elemen dengan lebar 347px persis
</div>

<!-- Arbitrary Colors -->
<div class="bg-[#1a1a2e] text-[#e94560] p-4">
  Warna kustom tanpa config
</div>

<div class="text-[rgb(100,200,50)]">
  RGB value langsung
</div>

<div class="border-[hsl(200,50%,50%)]">
  HSL value langsung
</div>

<!-- Arbitrary Spacing -->
<div class="mt-[42px] p-[13px]">
  Spacing kustom
</div>

<!-- Arbitrary Grid & Flex -->
<div class="grid grid-cols-[2fr_1fr] gap-4">
  <div class="bg-gray-200 p-4">2fr</div>
  <div class="bg-gray-300 p-4">1fr</div>
</div>

<div class="flex gap-[7px]">
  <span>Item 1</span>
  <span>Item 2</span>
</div>

<!-- Arbitrary Typography -->
<p class="text-[15px] leading-[1.8] tracking-[2px]">
  Tipografi kustom
</p>

<!-- Arbitrary with Fraction/Calc -->
<div class="w-[33.333%]">
  Persentase kustom
</div>

<div class="w-[calc(100%-40px)]">
  Kalkulasi CSS
</div>

<!-- Arbitrary Properties (CSS Properties) -->
<div class="[scrollbar-width:none]">
  Properti CSS yang tidak ada utility Tailwind
</div>

<!-- Arbitrary with Variants -->
<button class="bg-blue-600 hover:bg-[#ff0000] dark:bg-[#333] dark:hover:bg-[#555]">
  Tombol dengan arbitrary value dan variant
</button>

<!-- Arbitrary Selector / Pseudo-class -->
<ul class="[&>li]:mt-2 [&>li:first-child]:mt-0">
  <li>Item pertama (tanpa margin-top)</li>
  <li>Item kedua (mt-2)</li>
  <li>Item ketiga (mt-2)</li>
</ul>

<!-- Media Query Arbitrary -->
<div class="max-[600px]:text-sm min-[900px]:text-xl">
  Responsif dengan arbitrary breakpoint
</div>
```

## Analogi

Bayangkan kamu seorang kontraktor yang sedang membangun rumah. **Tailwind config** seperti toko material bangunan yang menyediakan ukuran standar: papan 2x4, pipa 1/2 inci, batu bata ukuran standar. **Arbitrary Values** seperti tukang yang memotong kayu, memotong pipa, atau memecah batu bata sesuai ukuran persis yang dibutuhkan di lapangan -- tanpa harus memesan ukuran khusus dari pabrik (config). Fleksibel untuk situasi yang tidak terduga, tapi jangan digunakan untuk semua hal agar rumah tetap konsisten.

## Dipakai untuk Apa

- Desain pixel-perfect dari Figma yang tidak cocok dengan skala spacing default Tailwind.
- Nilai satu-off yang hanya dipakai di satu tempat dan tidak perlu menjadi bagian dari design system.
- Warna eksak dari brand guideline yang hanya muncul sekali.
- Properti CSS eksperimental atau baru yang belum punya utility Tailwind.
- Grid layout dengan track sizing kustom (`grid-cols-[200px_1fr_auto]`).
- Kalkulasi dinamis yang tidak mungkin diwakili nilai tetap.

## Kesalahan Umum yang Sering Terjadi

1. **Overuse arbitrary values**: Menggunakan arbitrary value untuk hal yang sebenarnya sudah ada di tema default (misal `w-[16px]` padahal ada `w-4`).
2. **Typo format**: Lupa kurung siku atau salah format seperti `bg-[#1a1a2e]` tanpa tanda pagar dalam kurung menjadi `bg-[1a1a2e]`.
3. **Spasi dalam nilai**: `grid-cols-[2fr 1fr]` benar, tapi `grid-cols-[2fr 1fr]` dengan spasi juga perlu diperhatikan -- jika nilai mengandung spasi, tidak perlu dikutip.
4. **Arbitrary property tanpa selector**: `[scrollbar-width:none]` benar, bukan `[scrollbar-width: none]` (spasi setelah titik dua boleh).
5. **Mencampur dengan nilai negatif**: `-top-[10px]` tidak bekerja. Gunakan `top-[-10px]` atau `-top-[10px]` dengan benar sesuai sintaks Tailwind.
6. **Tidak ada fallback**: Beberapa properti arbitrary mungkin tidak didukung di browser lama. Pastikan ada fallback.

## Koneksi dengan Materi Sebelumnya

Di materi 31 (Extend vs Override), kamu belajar menambahkan nilai kustom ke tema. Arbitrary Values adalah alternatif cepat untuk nilai satu-off tanpa harus mengedit config. Keduanya saling melengkapi: config untuk nilai yang dipakai berulang (design system), arbitrary untuk nilai sekali pakai. Plugin typography (materi 35) dan forms (materi 36) juga bisa dikombinasikan dengan arbitrary values jika perlu override spesifik.

## Soal Latihan

Buat sebuah komponen card yang menggunakan:
1. Lebar `380px` (arbitrary width)
2. Warna background `#16213e` (arbitrary color)
3. Border radius `16px` (arbitrary rounded)
4. Box shadow kustom `0 4px 20px rgba(0,0,0,0.3)` (arbitrary shadow)
5. Grid dengan 2 kolom `1fr auto` di dalam card
6. Padding `18px` (arbitrary spacing)
