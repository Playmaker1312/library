# Plugin Typography

## Penjelasan

- `@tailwindcss/typography` adalah plugin resmi Tailwind untuk menata konten kaya HTML seperti artikel blog, dokumentasi, atau konten Markdown.
- Plugin ini menyediakan kelas `prose` yang menerapkan tipografi indah secara otomatis ke semua elemen HTML di dalamnya (heading, paragraf, link, list, blockquote, code, tabel, gambar).
- Variasi ukuran: `prose-sm`, `prose-base` (default), `prose-lg`, `prose-xl`, `prose-2xl`.
- Variasi warna: `prose-slate`, `prose-gray`, `prose-zinc`, `prose-neutral`, `prose-stone`.
- Modifikasi elemen spesifik: `prose-headings` (semua heading), `prose-h1`, `prose-h2`, `prose-p`, `prose-a`, `prose-strong`, `prose-em`, `prose-code`, `prose-pre`, `prose-blockquote`, `prose-li`, `prose-img`, `prose-figure`, `prose-figcaption`.
- Untuk dark mode, kombinasikan dengan `prose-invert` yang otomatis membalik warna teks dan background.
- Plugin ini diinstal terpisah dan harus ditambahkan ke daftar plugins di `tailwind.config.js`.

## Fungsi

Menata konten HTML kaya (rich text) secara konsisten dan estetis tanpa harus menulis utility Tailwind satu per satu untuk setiap elemen di dalam artikel.

## Cara Pengimplementasian / Kode

**Instalasi:**

```bash
npm install -D @tailwindcss/typography
```

**Config:**

```js
// tailwind.config.js
module.exports = {
  plugins: [
    require('@tailwindcss/typography'),
  ],
}
```

**HTML:**

```html
<!-- Artikel blog dengan typography plugin -->
<article class="max-w-3xl mx-auto px-4 py-8">
  
  <h1 class="text-4xl font-bold text-gray-900 mb-4">Judul Artikel Blog</h1>
  <p class="text-sm text-gray-500 mb-8">Ditulis oleh Admin | 30 Juni 2026</p>

  <!-- Konten artikel menggunakan prose -->
  <div class="prose prose-lg prose-slate dark:prose-invert max-w-none">
    
    <p>Ini adalah paragraf pembuka artikel. <strong>Teks tebal</strong> dan <em>teks miring</em> sudah ditata otomatis.</p>

    <h2>Sub-Judul Pertama</h2>
    <p>Paragraf setelah heading. Link secara otomatis mendapat warna biru dan underline: <a href="#">klik di sini</a>.</p>

    <blockquote>
      <p>Ini adalah blockquote. Plugin typography memberikan margin, border kiri, dan warna abu-abu secara otomatis.</p>
    </blockquote>

    <h3>Daftar Tidak Berurut</h3>
    <ul>
      <li>Item pertama dengan bullet point yang ditata rapi</li>
      <li>Item kedua dengan spacing yang konsisten</li>
      <li>Item ketiga</li>
    </ul>

    <h3>Kode</h3>
    <p>Kode inline: <code>const x = 10;</code> dan blok kode:</p>
    <pre><code>function hello() {
  console.log('Hello World');
}</code></pre>

    <h3>Tabel</h3>
    <table>
      <thead>
        <tr>
          <th>Nama</th>
          <th>Usia</th>
          <th>Kota</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td>Andi</td>
          <td>25</td>
          <td>Jakarta</td>
        </tr>
        <tr>
          <td>Budi</td>
          <td>30</td>
          <td>Bandung</td>
        </tr>
      </tbody>
    </table>

    <h3>Gambar</h3>
    <figure>
      <img src="https://via.placeholder.com/800x400" alt="Contoh gambar">
      <figcaption>Keterangan gambar otomatis ditata lebih kecil dan abu-abu.</figcaption>
    </figure>

  </div>
</article>
```

## Analogi

Bayangkan kamu seorang arsitek interior yang ditugaskan mendekorasi 20 ruangan di sebuah gedung perkantoran. Tanpa plugin, kamu harus memilihkan furnitur, cat, dan pencahayaan untuk setiap ruangan satu per satu. Dengan `@tailwindcss/typography`, kamu mendapat satu paket furnitur siap pakai yang seragam dan indah untuk semua ruangan -- tinggal taruh, dan semua ruangan langsung tertata rapi.

## Dipakai untuk Apa

- Blog posts dan artikel
- Dokumentasi teknis (seperti docsify, VitePress, docusaurus)
- Halaman konten dari CMS (seperti konten yang di-render dari Markdown)
- Halaman statis dengan konten panjang (privacy policy, terms of service, about us)
- Newsletter atau email template

## Kesalahan Umum yang Sering Terjadi

1. **Lupa install plugin**: Mengimpor `prose` tanpa menginstal `@tailwindcss/typography` dan mendaftarkannya di `plugins`.
2. **Tidak pakai `max-w-none`**: `prose` memiliki max-width default (65ch). Jika ingin full-width, tambahkan `max-w-none`.
3. **Overwrite manual yang tidak perlu**: Menambahkan utility heading seperti `text-2xl font-bold` di dalam elemen yang sudah ditata `prose` -- hasilnya dobel style.
4. **Prose di elemen yang salah**: `prose` harus ditempatkan di elemen pembungkus konten, bukan di setiap elemen individual.
5. **Dark mode tapi tanpa `prose-invert`**: Konten tetap terang di background gelap karena `prose` tidak otomatis mendeteksi dark mode.

## Koneksi dengan Materi Sebelumnya

Dark mode setup (materi 33, 34) telah membahas bagaimana menata UI seperti navbar, card, dan tombol untuk dark mode. Plugin typography melengkapi dengan menata konten kaya (artikel/blog) yang juga perlu mendukung dark mode melalui `prose-invert`. Brand dari materi 31 bisa diterapkan dengan kustomisasi warna `prose` melalui config.

## Soal Latihan

1. Instal dan aktifkan `@tailwindcss/typography` di proyek.
2. Buat halaman artikel dengan:
   - Judul, tanggal, penulis
   - Minimal 2 heading, 3 paragraf, 1 blockquote, 1 unordered list, 1 blok kode, dan 1 gambar
   - Menggunakan `prose-lg` untuk ukuran lebih besar
   - Mendukung dark mode dengan `prose-invert`
