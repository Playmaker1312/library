# Dark Mode Setup

## Penjelasan

- Tailwind mendukung dark mode melalui strategi `class` atau `media`.
- **`darkMode: 'media'`** (default): Menggunakan prefers-color-scheme CSS media query. Mode terang/gelap mengikuti pengaturan sistem operasi pengguna. Tidak bisa di-toggle manual.
- **`darkMode: 'class'`**: Menggunakan kelas `.dark` pada elemen induk (biasanya `<html>`). Memberi kontrol penuh untuk toggle manual, cocok untuk fitur toggle dark mode.
- Untuk `class` strategy, kamu perlu mengatur toggle logic dengan JavaScript.
- `localStorage` digunakan untuk menyimpan preferensi dark mode pengguna agar persisten antar kunjungan.
- **Prevent flash**: Karena localStorage dibaca setelah page render, ada teknik untuk mencegah flash (kedipan putih) dengan inline script di `<head>` yang membaca localStorage sebelum konten dirender.
- Dengan `class` strategy, utility `dark:` akan aktif ketika elemen induk memiliki kelas `dark`.

## Fungsi

Mengaktifkan dark mode di proyek Tailwind dengan strategi yang sesuai -- baik otomatis mengikuti sistem atau manual dengan toggle.

## Cara Pengimplementasian / Kode

**Config:**

```js
// tailwind.config.js
module.exports = {
  darkMode: 'class', // atau 'media' untuk otomatis
  // ...
}
```

**Toggle logic + prevent flash:**

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <!-- Prevent flash: inline script sebelum render -->
  <script>
    if (localStorage.getItem('color-theme') === 'dark' ||
        (!('color-theme' in localStorage) && 
         window.matchMedia('(prefers-color-scheme: dark)').matches)) {
      document.documentElement.classList.add('dark');
    } else {
      document.documentElement.classList.remove('dark');
    }
  </script>
</head>
<body>
  <!-- Toggle button -->
  <button id="theme-toggle" class="p-2 rounded-lg bg-gray-200 dark:bg-gray-700">
    <span id="theme-icon" class="text-xl">Mode</span>
  </button>

  <script>
    const toggleBtn = document.getElementById('theme-toggle');
    const html = document.documentElement;

    toggleBtn.addEventListener('click', () => {
      html.classList.toggle('dark');
      // Simpan preferensi
      if (html.classList.contains('dark')) {
        localStorage.setItem('color-theme', 'dark');
      } else {
        localStorage.setItem('color-theme', 'light');
      }
    });
  </script>
</body>
</html>
```

## Analogi

Seperti rumah yang memiliki sistem pencahayaan otomatis. **`darkMode: 'media'`** seperti sensor cahaya yang otomatis menyesuaikan lampu berdasarkan kondisi luar (sistem operasi). **`darkMode: 'class'`** seperti saklar dinding yang bisa kamu nyalakan atau matikan kapan saja, dan keputusan terakhir tersimpan di memori (localStorage) -- saat kamu datang lagi, lampu menyala sesuai pengaturan terakhir.

## Dipakai untuk Apa

- Situs atau aplikasi yang perlu mendukung tema gelap untuk kenyamanan pengguna di malam hari.
- Aplikasi dengan fitur toggle tema manual yang memberi pengguna kontrol penuh.
- Dashboard atau alat produktivitas yang digunakan di berbagai kondisi pencahayaan.

## Kesalahan Umum yang Sering Terjadi

1. **Lupa mengatur `darkMode` di config**: Jika tidak disetel, strategi default adalah `media` dan `dark:` hanya aktif saat sistem dalam mode gelap.
2. **Kedipan putih saat reload (flash)**: Terjadi jika script toggle tidak dijalankan sebelum konten dirender. Solusi: inline script di `<head>`.
3. **Menyimpan di localStorage tapi tidak membaca saat load**: Toggle berfungsi tetapi preferensi hilang setelah halaman ditutup.
4. **Menambahkan kelas `dark` ke elemen yang salah**: Kelas `dark` harus di elemen induk tertinggi (`<html>`), bukan di `<body>` atau div tertentu.
5. **Mengabaikan fallback `prefers-color-scheme`**: Jika belum pernah toggle, sebaiknya ikuti sistem operasi sebagai default.

## Koneksi dengan Materi Sebelumnya

Brand kustom yang sudah dibuat di materi 31 (Extend vs Override) dan komponen di materi 32 (@layer) sekarang perlu diadaptasi agar tetap terlihat baik di lingkungan gelap. Dark mode adalah langkah pertama untuk memastikan brand yang sudah kamu config juga tampil optimal dalam kondisi minim cahaya.

## Soal Latihan

1. Atur `tailwind.config.js` untuk menggunakan dark mode dengan strategi `class`.
2. Buat halaman sederhana dengan header, card, dan footer yang memiliki variasi dark mode (dark:bg-gray-900, dark:text-white, dll).
3. Sertakan script toggle dan prevent flash.
