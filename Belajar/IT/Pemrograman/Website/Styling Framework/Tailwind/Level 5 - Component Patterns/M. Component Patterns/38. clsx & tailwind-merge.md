# clsx & tailwind-merge

## Penjelasan
- Saat membuat komponen di Tailwind, sering terjadi konflik class seperti `px-4 px-6`. Browser akan pakai `px-6` karena ditulis lebih akhir, tapi ini tidak selalu yang kita mau.
- **clsx** adalah library kecil untuk menggabungkan class secara conditional. clsx bisa menerima string, object, array, dan akan menghasilkan string class yang rapi.
- **tailwind-merge (twMerge)** adalah library yang secara cerdas menggabungkan class Tailwind dan menyelesaikan konflik. Contoh: `twMerge('px-4', 'px-6')` menghasilkan `px-6` saja karena tahu ini class yang sama.
- **cn()** adalah utility function yang menggabungkan clsx + twMerge jadi satu fungsi. Pola ini dipakai di shadcn/ui dan banyak project Tailwind modern.
- cn() biasanya ditulis di file `lib/utils.ts` atau `src/utils/cn.ts` dan di-export untuk dipakai di semua komponen.
- twMerge bisa handle konflik class Tailwind yang kompleks, termasuk variant seperti `dark:`, `hover:`, `lg:`, dll.

## Fungsi
- clsx: mengelola class conditional secara deklaratif dan ringkas
- twMerge: menyelesaikan konflik antar class Tailwind secara otomatis
- cn(): satu fungsi untuk keduanya — menulis class conditional tanpa khawatir konflik

## Cara Pengimplementasian / Kode

```js
// lib/utils.ts
import { clsx } from "clsx";
import { twMerge } from "tailwind-merge";

export function cn(...inputs) {
  return twMerge(clsx(inputs));
}
```

```js
// components/Button.tsx
import { cn } from "@/lib/utils";

const variants = {
  primary: "bg-blue-600 text-white hover:bg-blue-700",
  secondary: "bg-gray-200 text-gray-900 hover:bg-gray-300",
  danger: "bg-red-600 text-white hover:bg-red-700",
};

const sizes = {
  sm: "px-3 py-1.5 text-sm",
  md: "px-4 py-2 text-base",
  lg: "px-6 py-3 text-lg",
};

export function Button({
  variant = "primary",
  size = "md",
  disabled = false,
  className,
  children,
}) {
  return (
    <button
      disabled={disabled}
      className={cn(
        "inline-flex items-center justify-center rounded-md font-medium transition-colors",
        "focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-offset-2",
        variants[variant],
        sizes[size],
        disabled && "opacity-50 cursor-not-allowed",
        className
      )}
    >
      {children}
    </button>
  );
}
```

```js
// Contoh penggunaan yang menunjukkan konflik terselesaikan
<Button className="px-8">Tombol Lebar</Button>
// Hasil akhir: px-8 dipakai, bukan px-4 dari sizes.md
```

## Analogi
clsx seperti koki yang memilih bumbu sesuai resep dengan tepat — hanya menambahkan bumbu yang diperlukan untuk hidangan tertentu. twMerge seperti koki senior yang memastikan tidak ada bumbu dobel di masakan — jika sudah ada garam, dia tidak akan menambahkan garam lagi. cn() adalah koki kepala yang menggabungkan kedua keahlian itu: memilih bumbu yang tepat lalu memastikan tidak ada duplikasi.

## Dipakai untuk Apa
- Membuat komponen dengan variant (primary, secondary, danger) dan size (sm, md, lg)
- Komponen yang menerima prop `className` dari luar agar bisa di-override tanpa konflik
- Class conditional berdasarkan state (disabled, active, loading, error)
- Membangun design system dengan komponen yang konsisten tapi fleksibel
- Project yang menggunakan shadcn/ui atau framework serupa

## Kesalahan Umum yang Sering Terjadi
- Menggunakan clsx saja tanpa twMerge — konflik class tidak terselesaikan, class terakhir selalu menang
- Menggunakan twMerge saja tanpa clsx — tidak bisa handle conditional dengan rapi, harus pakai ternary
- Urutan argumen cn() salah: class yang paling ingin di-override harus diletakkan paling akhir
- Lupa install kedua library: `npm install clsx tailwind-merge`
- Menulis class kustom (bukan Tailwind) di parameter className — twMerge tidak bisa handle class kustom
- Menganggap cn() hanya untuk Tailwind — padahal bisa dipakai untuk class CSS apapun

## Koneksi dengan Materi Sebelumnya
Di Level 4 kamu sudah setup tailwind.config dengan brand colors, fonts, dan spacing. Sekarang komponen-komponenmu perlu mengelola class Tailwind secara rapi. cn() menjadi jembatan antara config global (brand) dengan implementasi komponen. Ini juga melanjutkan pola utility-first: class tetap ditulis inline, tapi dikelola dengan alat bantu agar tidak kacau.

## Soal Latihan
Buat komponen `Badge` yang menerima prop `variant` (success, warning, error), `size` (sm, md), dan `className`. Gunakan cn() untuk menggabungkan class. Tampilkan badge dengan variant success dan size md, lalu override dengan className `uppercase`.

<summary>Jawaban</summary>

```js
import { cn } from "@/lib/utils";

const badgeVariants = {
  success: "bg-green-100 text-green-800 border-green-200",
  warning: "bg-yellow-100 text-yellow-800 border-yellow-200",
  error: "bg-red-100 text-red-800 border-red-200",
};

const badgeSizes = {
  sm: "px-2 py-0.5 text-xs",
  md: "px-3 py-1 text-sm",
};

export function Badge({ variant = "success", size = "md", className, children }) {
  return (
    <span
      className={cn(
        "inline-flex items-center rounded-full border font-medium",
        badgeVariants[variant],
        badgeSizes[size],
        className
      )}
    >
      {children}
    </span>
  );
}

// Penggunaan:
// <Badge variant="success" size="md" className="uppercase">Aktif</Badge>
```
