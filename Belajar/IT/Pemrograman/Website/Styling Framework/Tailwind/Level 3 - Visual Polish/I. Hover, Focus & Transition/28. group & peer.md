# group & peer

## Penjelasan
- `group` adalah class yang ditambahkan ke elemen parent, lalu child bisa menggunakan `group-hover:`, `group-focus:`, `group-active:` untuk berubah saat parent di-hover/focus
- `group` bisa dinamed: `group/name` dan `group-hover/name:` untuk multiple grup berbeda di satu hierarki
- `peer` adalah class pada elemen sibling (saudara), dan elemen sibling lain bisa menggunakan `peer-hover:`, `peer-focus:`, `peer-checked:`, `peer-disabled:`, `peer-required:` untuk berubah saat sibling berinteraksi
- `peer` bisa dinamed seperti group: `peer/name` dan `peer-checked/name:`
- Pola umum: accordion (group-hover pada parent card), floating label (peer-checked atau peer-focus pada input), custom checkbox/radio

## Fungsi
Memungkinkan styling elemen berdasarkan state elemen lain yang merupakan parent (group) atau sibling (peer) tanpa perlu JavaScript.

## Cara Pengimplementasian / Kode

```html
<!-- Group Hover: seluruh card berubah saat di-hover -->
<div class="group p-6 bg-white rounded-xl shadow-md hover:shadow-xl transition-all duration-300 cursor-pointer">
  <h3 class="text-lg font-semibold group-hover:text-blue-600 transition-colors">Judul Card</h3>
  <p class="text-gray-500 group-hover:text-gray-700 transition-colors">Deskripsi yang muncul saat card di-hover.</p>
  <div class="mt-4 opacity-0 group-hover:opacity-100 transition-opacity">
    Tombol tersembunyi muncul saat hover
  </div>
</div>

<!-- Peer Checked: custom checkbox -->
<div class="flex items-center gap-3 p-4">
  <input type="checkbox" id="agree" class="peer hidden">
  <label for="agree" class="w-6 h-6 border-2 border-gray-300 rounded peer-checked:bg-blue-600 peer-checked:border-blue-600"></label>
  <label for="agree" class="peer-checked:text-blue-600">Saya setuju dengan syarat dan ketentuan</label>
</div>

<!-- Floating Label Pattern -->
<div class="relative mt-6">
  <input
    type="text"
    id="name"
    placeholder=" "
    class="peer border border-gray-300 rounded-lg px-4 pt-6 pb-2 w-full focus:outline-none focus:border-blue-500"
  >
  <label
    for="name"
    class="absolute left-4 top-5 text-gray-400 transition-all peer-focus:top-2 peer-focus:text-xs peer-focus:text-blue-500 peer-[:not(:placeholder-shown)]:top-2 peer-[:not(:placeholder-shown)]:text-xs"
  >
    Nama Lengkap
  </label>
</div>

<!-- Named group -->
<div class="group/card p-6 bg-white rounded-xl shadow">
  <div class="group/header">
    <h4 class="group-hover/header:text-red-500">Header</h4>
    <p class="group-hover/card:text-green-500">Konten</p>
  </div>
</div>
```

## Analogi
Group seperti kru tim di proyek konstruksi. Jika mandor (parent) memberikan sinyal "angkat tangan", maka semua anggota tim (children) merespon secara bersamaan. Peer seperti dua pekerja yang bersebelahan -- jika satu pekerja (peer) mulai mengebor, pekerja di sebelahnya langsung memasang earplug. Group memungkinkan koordinasi dari atas ke bawah, peer memungkinkan reaksi antar tetangga.

## Dipakai untuk Apa
- Group: card yang menampilkan tombol aksi saat di-hover, navbar item dengan icon yang berubah, gallery item dengan overlay
- Peer: custom checkbox/radio yang lebih menarik, floating label input, form dengan validasi, accordion murni CSS
- Group named: komponen kompleks dengan beberapa grup berbeda dalam satu container

## Kesalahan Umum yang Sering Terjadi
- Lupa menambahkan class `group` di parent sehingga `group-hover:` tidak berfungsi
- Menggunakan `peer-checked` tanpa menyembunyikan checkbox asli (`hidden` atau `sr-only`) sehingga muncul dua elemen
- Struktur HTML tidak sesuai (child tidak ada di dalam parent group, atau sibling tidak se-level)
- Mencoba menggunakan `group-hover` untuk element yang bukan descendant langsung dari `group`
- Tidak menggunakan named group ketika ada nested group, sehingga terjadi konflik state

## Koneksi dengan Materi Sebelumnya
Di materi sebelumnya kamu belajar hover/focus pada elemen itu sendiri. Group dan peer memperluas kemampuan itu ke relasi antar elemen. Jika sebelumnya `hover:bg-blue-700` hanya mengubah tombol itu sendiri saat di-hover, sekarang dengan `group-hover:bg-blue-700` kamu bisa mengubah child elemen saat parent di-hover. Ini seperti memiliki remote control -- sentuh satu elemen, banyak yang bereaksi.

## Soal Latihan
Buat sebuah card dengan gambar placeholder dan teks. Saat seluruh card di-hover, background card berubah menjadi biru muda (blue-50), teks judul berubah menjadi biru, dan tombol "Lihat Detail" yang sebelumnya transparan muncul (opacity 100).
