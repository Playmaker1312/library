# 49. E-commerce Product Pages

## Penjelasan

Project ini adalah membangun halaman toko online (e-commerce) lengkap menggunakan Tailwind CSS. Terdiri dari halaman home, catalog dengan filter, detail produk, keranjang belanja, dan checkout multi-step. Semua interaksi seperti image gallery zoom, filter sidebar accordion, cart management, dan form wizard dikelola dengan vanilla JavaScript.

E-commerce adalah jenis aplikasi web yang paling kompleks dari sisi UI karena menggabungkan banyak pola interaksi: navigasi produk, filtering, image viewing, manajemen state keranjang, dan form multi-step. Project ini akan menguji kemampuanmu dalam mengelola state UI yang kompleks dengan class toggle vanilla JS.

## Fungsi

- Membangun layout e-commerce yang lengkap dari halaman depan hingga checkout
- Menerapkan image gallery dengan fitur zoom (lens magnifier)
- Membangun filter sidebar dengan accordion (kategori, harga, rating, warna)
- Mengelola state keranjang belanja dengan JavaScript murni
- Membangun multi-step form wizard untuk checkout
- Mengimplementasikan review stars interaktif
- Menerapkan responsive grid catalog dengan product cards

## Struktur Project

### 7. JavaScript Cart Management

Sistem keranjang menggunakan localStorage untuk persistensi. Mendukung add, remove, update quantity, dan kalkulasi total.

```javascript
// cart.js
const CartManager = {
  getCart() {
    return JSON.parse(localStorage.getItem('cart') || '[]');
  },

  saveCart(cart) {
    localStorage.setItem('cart', JSON.stringify(cart));
    this.updateCartBadge();
  },

  addItem(product) {
    const cart = this.getCart();
    const existing = cart.find(item => item.id === product.id);
    if (existing) {
      existing.quantity += 1;
    } else {
      cart.push({ ...product, quantity: 1 });
    }
    this.saveCart(cart);
    this.showAddedToast(product.name);
  },

  removeItem(productId) {
    let cart = this.getCart();
    cart = cart.filter(item => item.id !== productId);
    this.saveCart(cart);
  },

  updateQuantity(productId, qty) {
    const cart = this.getCart();
    const item = cart.find(i => i.id === productId);
    if (item) {
      item.quantity = Math.max(1, Math.min(99, parseInt(qty)));
      this.saveCart(cart);
    }
  },

  getTotal() {
    return this.getCart().reduce((sum, item) => sum + (item.price * item.quantity), 0);
  },

  getCount() {
    return this.getCart().reduce((sum, item) => sum + item.quantity, 0);
  },

  updateCartBadge() {
    const badge = document.getElementById('cartBadge');
    if (badge) {
      const count = this.getCount();
      badge.textContent = count;
      badge.classList.toggle('hidden', count === 0);
    }
  },

  showAddedToast(productName) {
    const toast = document.createElement('div');
    toast.className = 'fixed top-4 right-4 z-50 flex items-center gap-3 px-4 py-3 bg-white rounded-lg shadow-lg border border-gray-200 dark:bg-gray-800 dark:border-gray-700 animate-slide-in';
    toast.innerHTML = `
      <svg class="w-5 h-5 text-green-500" fill="currentColor" viewBox="0 0 20 20"><path d="M16.707 5.293a1 1 0 0 1 0 1.414l-8 8a1 1 0 0 1-1.414 0l-4-4a1 1 0 0 1 1.414-1.414L8 12.586l7.293-7.293a1 1 0 0 1 1.414 0Z"/></svg>
      <span class="text-sm text-gray-700 dark:text-gray-300">${productName} added to cart</span>
    `;
    document.body.appendChild(toast);
    setTimeout(() => toast.remove(), 3000);
  }
};

function initImageZoom() {
  const container = document.getElementById('mainImageContainer');
  const mainImage = document.getElementById('mainImage');
  const lens = document.getElementById('zoomLens');
  const result = document.getElementById('zoomResult');

  container.addEventListener('mousemove', (e) => {
    const rect = container.getBoundingClientRect();
    const x = e.clientX - rect.left;
    const y = e.clientY - rect.top;

    lens.classList.remove('hidden');
    result.classList.remove('hidden');

    const lensW = lens.offsetWidth / 2;
    const lensH = lens.offsetHeight / 2;
    let lensX = x - lensW;
    let lensY = y - lensH;

    lensX = Math.max(0, Math.min(lensX, rect.width - lens.offsetWidth));
    lensY = Math.max(0, Math.min(lensY, rect.height - lens.offsetHeight));

    lens.style.left = lensX + 'px';
    lens.style.top = lensY + 'px';

    const px = result.offsetWidth / lens.offsetWidth;
    const py = result.offsetHeight / lens.offsetHeight;
    result.style.backgroundImage = `url(${mainImage.src})`;
    result.style.backgroundSize = `${rect.width * px}px ${rect.height * py}px`;
    result.style.backgroundPosition = `-${lensX * px}px -${lensY * py}px`;
  });

  container.addEventListener('mouseleave', () => {
    lens.classList.add('hidden');
    result.classList.add('hidden');
  });
}

Catalog adalah **deretan toko** yang bisa difilter berdasarkan jenis barang. ProductCard adalah **etalase toko** yang menampilkan barang dengan info harga. ReviewStars adalah **buku tamu** di setiap toko. Cart adalah **keranjang belanja fisik** yang kamu bawa. Checkout wizard adalah **proses di kasir** yang terdiri dari beberapa langkah: data diri, pembayaran, konfirmasi. Setiap langkah seperti antrean di kasir yang harus diisi dengan benar sebelum lanjut ke langkah berikutnya.

## Tantangan Teknis

1. **Image gallery zoom**: Fitur zoom lens memerlukan perhitungan posisi kursor yang presisi, skala gambar, dan background-position. Harus bekerja dengan baik di berbagai ukuran layar. Perlu fallback untuk mobile (cukup tap untuk buka gambar fullscreen).

2. **Filter sidebar dengan accordion**: Accordion harus bisa multiple expand atau single expand (sesuai preferensi). Filter state harus dipertahankan saat user navigasi. Perlu sinkronisasi antara checkbox, range slider, dan tombol Apply/Reset.

3. **Multi-step form wizard**: Setiap step harus memiliki validasi sendiri. Progress bar harus akurat. State form harus dipertahankan saat maju/mundur antar step. Animasi transisi antar step membuat UX lebih baik.

4. **Cart state management**: Keranjang harus persist di localStorage. Quantity update harus real-time. Badge counter harus sinkron di semua halaman. Perlu handle edge case: quantity 0 (remove item), item duplikat, stock limit.

5. **Grid/List toggle**: Catalog harus bisa toggle antara grid view dan list view tanpa reload. State view harus persist selama sesi. Animasi transisi antar mode tampilan.

6. **Product variant selection**: Halaman product detail harus mendukung pemilihan varian (size, color, dll) yang mengubah harga, gambar, dan stok. Setiap kombinasi varian harus memiliki data sendiri.
