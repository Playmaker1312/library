# 48. SaaS Dashboard Admin

## Penjelasan

Project ini adalah membangun dashboard admin untuk aplikasi SaaS (Software as a Service) menggunakan Tailwind CSS murni tanpa framework JavaScript. Dashboard ini mencakup halaman utama dengan statistik, halaman analytics, manajemen pengguna, pengaturan, dan halaman login. Semua interaksi seperti sidebar toggle, modal, toast, dan navigasi tab ditangani dengan vanilla JavaScript menggunakan class toggling.

Dashboard admin adalah tulang punggung aplikasi SaaS modern. Di sini kamu akan menggabungkan semua keterampilan Tailwind CSS dari Level 1 hingga Level 6 untuk membangun antarmuka yang kompleks dengan layouting, komponen interaktif, responsivitas, dark mode, dan performa optimal.

## Fungsi

- Melatih kemampuan membangun layout kompleks dengan sidebar + topbar + content area
- Menerapkan state management UI menggunakan class toggle vanilla JS
- Membangun komponen reusable seperti StatsCard, DataTable, Modal, Toast, Skeleton, EmptyState
- Mengintegrasikan chart library (Chart.js) dengan Tailwind CSS
- Menerapkan dark mode penuh pada seluruh halaman
- Mengelola responsivitas sidebar dari mobile ke desktop

### 10. JavaScript State Management

Semua state management dilakukan dengan class toggle vanilla JavaScript. Setiap komponen memiliki controller sendiri.

```javascript
// sidebar.js
const sidebar = document.getElementById('sidebar');
const toggleBtn = document.getElementById('toggleSidebar');
const overlay = document.createElement('div');

overlay.className = 'fixed inset-0 z-30 bg-gray-900/50 hidden md:hidden';
document.body.appendChild(overlay);

toggleBtn.addEventListener('click', () => {
  sidebar.classList.toggle('-translate-x-full');
  overlay.classList.toggle('hidden');
});

overlay.addEventListener('click', () => {
  sidebar.classList.add('-translate-x-full');
  overlay.classList.add('hidden');
});

// dropdown.js - reusable dropdown
function initDropdown(btnId, menuId) {
  const btn = document.getElementById(btnId);
  const menu = document.getElementById(menuId);
  btn.addEventListener('click', (e) => {
    e.stopPropagation();
    menu.classList.toggle('hidden');
  });
  document.addEventListener('click', () => menu.classList.add('hidden'));
}

// Toast system
function showToast(type, message) {
  const container = document.getElementById('toastContainer');
  const template = document.getElementById(`toast${type}`);
  const clone = template.content
    ? template.content.cloneNode(true)
    : template.cloneNode(true);

  clone.querySelector('.text-sm.font-normal').textContent = message;
  clone.classList.remove('hidden');
  container.appendChild(clone);

  setTimeout(() => {
    clone.classList.add('opacity-0', 'transition-opacity', 'duration-300');
    setTimeout(() => clone.remove(), 300);
  }, 4000);
}
```

## Analogi

Dashboard admin ini seperti **ruang kontrol pusat sebuah gedung pencakar langit**. Sidebar adalah **panel kontrol utama** tempat semua tombol dan sakelar berada -- mengatur akses ke setiap lantai (halaman). Topbar adalah **panel notifikasi dan komunikasi** yang terhubung ke seluruh gedung. StatsCard adalah **alat ukur di setiap lantai** yang menunjukkan suhu, jumlah orang, konsumsi listrik, dan metrik lainnya secara real-time. DataTable adalah **daftar inventaris dan penghuni gedung** yang bisa diurutkan, dicari, dan diedit. Modal adalah **pintu khusus** yang muncul saat dibutuhkan untuk tugas spesifik (isi formulir, konfirmasi). Toast adalah **sistem pengumuman interkom** yang memberitahu penghuni tentang status operasi. Skeleton loading adalah **perancah bangunan** yang terlihat sebelum semua material terpasang. Empty state adalah **ruang kosong** yang menunggu untuk diisi.

## Tantangan Teknis

1. **Responsive sidebar**: Sidebar harus bertransisi dari overlay di mobile (dengan backdrop) ke sidebar statis di desktop. Menggunakan `translate-x` untuk sembunyikan/tampilkan dan `md:translate-x-0` untuk desktop. Transisi harus mulus dengan `transition-transform duration-300`.

2. **State management dengan class toggle**: Tanpa framework JS, semua UI state dikelola dengan menambah/menghapus class `hidden`, `active`, `dark`, dll. Harus konsisten dan tidak ada kebocoran state. Gunakan event delegation untuk dropdown dan modal yang banyak.

3. **Integrasi Chart.js**: Chart harus merespons perubahan dark mode. Warna teks, grid, dan background chart harus diperbarui saat theme toggle ditekan. Gunakan `chart.update()` dengan konfigurasi warna baru.

4. **Form validation**: Halaman settings dan modal form memerlukan validasi sisi klien. Implementasi dengan constraint validation API atau custom validation. Tampilkan error message dengan styling yang konsisten.

5. **Performance dengan banyak data**: DataTable dengan ribuan baris harus tetap responsif. Virtual scrolling terlalu kompleks tanpa framework, jadi gunakan pagination dan debounce pada search input.
