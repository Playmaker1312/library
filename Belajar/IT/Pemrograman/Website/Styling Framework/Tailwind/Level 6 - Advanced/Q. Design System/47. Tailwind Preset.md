# Tailwind Preset

## Penjelasan

- Preset adalah konfigurasi Tailwind yang bisa dibagikan ke banyak project. Di v3, preset didefinisikan di `tailwind.config.js` sebagai array `presets`. Di v4, preset dibuat sebagai package NPM yang mengekspor file CSS dengan `@theme`, lalu di-import di project.
- Preset berguna untuk tim yang mengelola banyak project dengan identitas brand yang sama. Cukup satu tempat untuk mengupdate warna, font, spacing, dan semua project otomatis mendapatkan pembaruan.
- Di v3, preset bisa berisi `theme`, `plugins`, `variants`, dll. Di v4, preset cukup berupa file CSS yang di-`@import`.
- Implementasi v4: buat package terpisah (misal `@company/saas-preset`), tulis konfigurasi `@theme` di CSS-nya, lalu project tinggal `@import "@company/saas-preset"` sebelum `@import "tailwindcss"`.

## Fungsi

Menyediakan konfigurasi Tailwind yang konsisten dan reusable antar project. Menghindari duplikasi konfigurasi, mempermudah maintenance, dan memastikan semua project dalam satu organisasi memiliki identitas visual yang seragam.

## Cara Pengimplementasian / Kode

**v3 -- Preset di tailwind.config.js:**

```js
// packages/saas-preset/index.js
module.exports = {
  theme: {
    extend: {
      colors: {
        brand: {
          50: "#eff6ff",
          500: "#3b82f6",
          700: "#1d4ed8",
        },
      },
      fontFamily: {
        sans: ["Inter", "sans-serif"],
      },
    },
  },
  plugins: [
    require("@tailwindcss/forms"),
    require("@tailwindcss/typography"),
  ],
};
```

```js
// Project A -- tailwind.config.js
module.exports = {
  presets: [require("@company/saas-preset")],
  content: ["./src/**/*.{html,js}"],
  theme: {
    extend: {
      // tambahan khusus project A
      colors: {
        accent: "#f59e0b",
      },
    },
  },
};
```

**v4 -- Preset sebagai package CSS:**

```css
/* packages/saas-preset/style.css */
@import "tailwindcss";

@theme {
  --color-brand-50: #eff6ff;
  --color-brand-500: #3b82f6;
  --color-brand-700: #1d4ed8;
  --font-family-sans: "Inter", sans-serif;
}

/* Plugin di v4 cukup diwakili dengan @layer utilities */
@layer utilities {
  .content-auto {
    content-visibility: auto;
  }
}
```

```css
/* Project A -- src/style.css */
@import "@company/saas-preset";
@import "tailwindcss";

@theme {
  /* Tambahan khusus project A */
  --color-accent: #f59e0b;
}
```

**Package.json untuk preset (v4):**

```json
{
  "name": "@company/saas-preset",
  "version": "1.0.0",
  "main": "style.css",
  "files": ["style.css"],
  "peerDependencies": {
    "tailwindcss": "^4.0.0"
  }
}
```

## Analogi

Preset adalah seperti cetak biru standar perusahaan konstruksi. Jika perusahaan memiliki 10 proyek rumah, mereka tidak perlu menggambar ulang spesifikasi kabel listrik, pipa air, dan ukuran pintu untuk setiap proyek. Cukup buat satu cetak biru standar (`preset`) lalu setiap proyek tinggal menambahkan cetak biru khusus untuk bagian yang unik. Semua proyek tetap konsisten dan menghemat waktu gambar ulang.

## Dipakai untuk Apa

- Organisasi dengan banyak project front-end yang perlu tampil seragam.
- Agensi yang mengerjakan banyak client dengan design system masing-masing.
- Saat ingin memisahkan design system ke dalam package NPM tersendiri.
- Memperbarui warna brand di semua project cukup dengan bump version preset.

## Kesalahan Umum yang Sering Terjadi

- Membuat preset terlalu besar dengan konfigurasi yang jarang terpakai di banyak project.
- Di v4, mengimpor preset setelah `@import "tailwindcss"` sehingga nilai `@theme` dari preset tidak terbaca.
- Lupa menambahkan `"files": ["style.css"]` di package.json preset sehingga file CSS tidak ikut ter-publish ke NPM.
- Terlalu kaku: preset tidak menyediakan opsi override, sehingga project kesulitan menambahkan kustomisasi.
- Menggabungkan preset dengan plugin yang bersifat spesifik ke project tertentu (misal plugin untuk framework Vue yang tidak dipakai di project React).

## Koneksi dengan Materi Sebelumnya

Di materi sebelumnya kamu belajar membuat design system dalam satu file HTML. Preset adalah langkah selanjutnya: alih-alih hanya dokumentasi, konfigurasi design system sekarang benar-benar bisa di-*package* dan diinstal sebagai dependensi NPM. Project di Level 4 dan 5 seperti komponen dashboard yang sudah kamu buat bisa langsung menggunakan preset ini. v4 membuat integrasi preset lebih sederhana dengan `@import` langsung, tanpa file config JS.

## Soal Latihan

Buat preset sederhana bernama `@company/minimal-preset` yang berisi:
- Warna `primary` (biru #2563eb) dan `secondary` (abu #64748b)
- Font sans: "Inter", sans-serif
- Spacing kustom `page` sebesar 2rem

Tulis file CSS preset-nya dan file CSS project yang mengimport dan menggunakan preset tersebut (tambah warna `danger` merah #dc2626 khusus project).

**File preset `style.css`:**

```css
@import "tailwindcss";

@theme {
  --color-primary: #2563eb;
  --color-secondary: #64748b;
  --font-family-sans: "Inter", sans-serif;
  --spacing-page: 2rem;
}
```

**File `package.json` untuk preset:**

```json
{
  "name": "@company/minimal-preset",
  "version": "1.0.0",
  "main": "style.css",
  "files": ["style.css"],
  "peerDependencies": {
    "tailwindcss": "^4.0.0"
  }
}
```

**File project `src/style.css`:**

```css
@import "@company/minimal-preset";
@import "tailwindcss";

@theme {
  --color-danger: #dc2626;
}
```

**File project `index.html` (contoh penggunaan):**

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Project dengan Preset</title>
  <link href="/src/style.css" rel="stylesheet" />
</head>
<body class="font-sans p-page">

  <button class="px-6 py-2 bg-primary text-white rounded-lg hover:bg-primary/90">
    Simpan
  </button>

  <button class="px-6 py-2 bg-danger text-white rounded-lg hover:bg-danger/90 ml-2">
    Hapus
  </button>

</body>
</html>
```

Penjelasan:
- Preset @company/minimal-preset menyediakan warna primary, secondary, font Inter, dan spacing page.
- Project mengimport preset dulu, baru `@import "tailwindcss"`.
- Project menambahkan warna `danger` khusus sendiri tanpa mengubah preset.
- Utility `p-page` menggunakan nilai `--spacing-page` dari preset.
