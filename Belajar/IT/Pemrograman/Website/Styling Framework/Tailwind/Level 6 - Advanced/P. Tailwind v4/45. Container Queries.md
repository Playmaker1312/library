# Container Queries

## Penjelasan

- Container Queries memungkinkan elemen merespons ukuran *parent container*-nya, bukan ukuran viewport (browser). Ini berbeda dengan Media Queries yang selalu berdasarkan lebar layar.
- Di Tailwind v4, Container Queries diaktifkan dengan menambahkan `@container` pada elemen parent, lalu menggunakan utility `@md:`, `@lg:`, `@sm:` pada elemen child.
- Ukuran container: `@sm:` (>= 24rem), `@md:` (>= 32rem), `@lg:` (>= 40rem), `@xl:` (>= 48rem), `@2xl:` (>= 56rem).
- Container bisa diberi nama dengan `@container/nama` untuk membedakan beberapa container dalam satu halaman.
- Tidak perlu plugin tambahan di v4 -- Container Queries sudah built-in.

## Fungsi

Membuat komponen yang layout-nya berubah secara dinamis berdasarkan ruang yang tersedia di dalam parent, bukan berdasarkan ukuran layar. Komponen jadi lebih portabel karena tidak terikat ukuran viewport.

## Cara Pengimplementasian / Kode

```html
<div class="@container space-y-4">
  <!-- Kartu yang berubah layout jika container >= 32rem -->
  <div class="flex flex-col @md:flex-row @md:items-center border rounded-lg p-4 gap-4">
    <img
      src="thumbnail.jpg"
      alt="Thumbnail"
      class="w-full @md:w-32 h-48 @md:h-24 object-cover rounded"
    />
    <div class="flex-1">
      <h3 class="text-lg font-semibold">Judul Artikel</h3>
      <p class="text-gray-600 line-clamp-2 @md:line-clamp-3">
        Deskripsi artikel yang panjangnya bisa menyesuaikan dengan ruang yang tersedia...
      </p>
    </div>
  </div>
</div>
```

**Container dengan nama:**

```html
<div class="@container/sidebar space-y-2">
  <div class="@lg/sidebar:grid-cols-3 grid grid-cols-1 gap-4">
    <div class="bg-white p-4 rounded shadow">
      <h4 class="font-bold">Kartu 1</h4>
      <p class="text-sm @md/sidebar:text-base">Konten kartu...</p>
    </div>
    <div class="bg-white p-4 rounded shadow">Kartu 2</div>
    <div class="bg-white p-4 rounded shadow">Kartu 3</div>
  </div>
</div>
```

## Analogi

Container Query seperti meja yang ukuran dan bentuknya menyesuaikan dengan ukuran ruangan tempat meja itu diletakkan, bukan ukuran seluruh gedung. Jika meja dipindah ke ruangan kecil, mejanya otomatis mengecil tanpa menunggu arsitek mengubah cetak biru gedung. Media Query adalah seperti mendesain meja berdasarkan ukuran gedung -- kalau dipindah ruangan, meja bisa salah ukuran.

## Dipakai untuk Apa

- Komponen kartu produk atau artikel yang diletakkan di berbagai layout (sidebar, grid, hero).
- Dashboard widget yang perlu menyesuaikan diri di berbagai panel.
- Komponen reusable yang dipakai di halaman berbeda dengan ukuran kontainer berbeda.
- Layout yang sangat dinamis di mana ukuran container tidak bisa diprediksi.

## Kesalahan Umum yang Sering Terjadi

- Menerapkan class container query di parent tapi lupa bahwa parent juga harus memiliki lebar yang bisa berubah (misal parent-nya `width: 100%` tapi child absolute).
- Menggunakan `@md:` tanpa memastikan parent sudah diberi `@container`, sehingga utility tidak aktif.
- Terlalu detail: menerapkan container query untuk perubahan kecil yang cukup dengan flex/grid biasa.
- Lupa memberi nama container saat ada container bertumpuk, sehingga query dari container dalam membingungkan.
- Menganggap container query menggantikan semua media query -- keduanya punya use case berbeda.

## Koneksi dengan Materi Sebelumnya

Di Level 3 kamu belajar responsive design dengan `sm:`, `md:`, `lg:` yang berdasarkan viewport (media query). Container queries memperluas konsep itu: sekarang komponen bisa responsif terhadap parent-nya sendiri. Di materi v4 sebelumnya, kamu lihat bahwa v4 mendukung `@container` secara native tanpa plugin. Ini adalah evolusi alami dari responsive utility yang sudah kamu kuasai.

## Soal Latihan

Buat dua kartu dalam satu baris menggunakan grid. Setiap kartu harus menampilkan gambar di atas dan teks di samping jika lebar container kartu >= 32rem (`@md`). Container utama adalah grid dengan 2 kolom. Setiap item grid harus memiliki `@container`.

<details>
<summary>Jawaban</summary>

```html
<div class="grid grid-cols-2 gap-4">
  <!-- Kartu 1 -->
  <div class="@container border rounded-lg p-2">
    <div class="flex flex-col @md:flex-row @md:items-center gap-3">
      <img
        src="https://placehold.co/150x150"
        alt="Gambar 1"
        class="w-full @md:w-24 h-40 @md:h-20 object-cover rounded"
      />
      <div>
        <h3 class="font-bold">Produk A</h3>
        <p class="text-sm text-gray-500">Deskripsi singkat produk.</p>
      </div>
    </div>
  </div>

  <!-- Kartu 2 -->
  <div class="@container border rounded-lg p-2">
    <div class="flex flex-col @md:flex-row @md:items-center gap-3">
      <img
        src="https://placehold.co/150x150"
        alt="Gambar 2"
        class="w-full @md:w-24 h-40 @md:h-20 object-cover rounded"
      />
      <div>
        <h3 class="font-bold">Produk B</h3>
        <p class="text-sm text-gray-500">Deskripsi singkat produk.</p>
      </div>
    </div>
  </div>
</div>
```

Penjelasan:
- Grid `grid-cols-2` membuat dua kolom. Setiap kolom otomatis lebarnya ~50% viewport.
- Masing-masing kartu diberi `@container` sebagai parent container query.
- Di dalam kartu, layout default `flex-col` (gambar di atas teks).
- Saat container mencapai `@md` (>= 32rem), layout berubah jadi `flex-row` dengan gambar di samping.
</details>
