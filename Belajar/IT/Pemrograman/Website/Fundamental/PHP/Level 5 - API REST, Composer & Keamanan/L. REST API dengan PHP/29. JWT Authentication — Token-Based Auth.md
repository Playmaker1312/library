# JWT Authentication — Token-Based Auth

## Penjelasan

**JWT (JSON Web Token)** adalah standar terbuka (RFC 7519) untuk mengamankan API secara **stateless**. JWT berbentuk string yang terdiri dari **3 bagian** dipisahkan titik (`.`): `header.payload.signature`

Struktur JWT:

- **Header** → berisi tipe token (`typ: "JWT"`) dan algoritma tanda tangan (`alg: "HS256"`).
- **Payload (Claims)** → berisi data klaim (informasi user, role, exp, iat, sub). Biasanya tidak menyimpan data sensitif (password).
- **Signature** → hasil enkripsi `base64url(header).base64url(payload) + secret` dengan algoritma HS256. Digunakan untuk **memverifikasi** bahwa token tidak diubah.

Cara kerja JWT di REST API:

1. **Login** → user kirim kredensial (email/password). Jika valid, server **generate JWT**.
2. **Kirim token** → client terima token, simpan (localStorage/sessionStorage).
3. **Akses endpoint protected** → client kirim header `Authorization: Bearer <token>`.
4. **Verifikasi** → server cek signature & validitas (exp/iat). Jika valid, izinkan akses.
5. **Logout** → client hapus token (stateless: server tidak perlu "mencatat" token blacklist kecuali kebutuhan khusus).

Kelebihan vs Session Cookie:

- **Stateless** → cocok untuk REST API & microservice.
- **Cross-domain** → mudah dipakai SPA + mobile.
- **Scalable** → tidak perlu session storage terpusat.

Kekurangan: token bisa dicuri jika disimpan sembarangan → wajib pakai HTTPS.

Konteks perpustakaan: proteksi endpoint `GET /pinjaman-saya`, `POST /pinjam-buku` hanya untuk anggota yang login.

## Fungsi

- **Autentikasi stateless** untuk REST API.
- **Proteksi endpoint** tertentu (hanya user terautentikasi).
- **Identifikasi user** dari token (claims `user_id`, `role`).
- **Mencegah akses tanpa izin**.
- **Cocok integrasi SPA/mobile**.
- **Standar industri** untuk token-based auth.

**File: `29-jwt-auth-sederhana.php`**

```php
<?php
// File: 29-jwt-auth-sederhana.php
declare(strict_types=1);

error_reporting(E_ALL);
ini_set('display_errors', 1);

header('Content-Type: application/json; charset=utf-8');
header('Access-Control-Allow-Origin: *');
header('Access-Control-Allow-Methods: GET, POST, OPTIONS');
header('Access-Control-Allow-Headers: Content-Type, Authorization');

if ($_SERVER['REQUEST_METHOD'] === 'OPTIONS') {
    http_response_code(200);
    exit;
}

// SECRET KEY (JANGAN pernah expose di production)
define('JWT_SECRET', 'rahasia-perpustakaan-lokal-123456');

// Fungsi base64url encode/decode
function base64urlEncode(string $data): string
{
    return rtrim(strtr(base64_encode($data), '+/', '-_'), '=');
}

function base64urlDecode(string $data): string
{
    $remainder = strlen($data) % 4;
    if ($remainder) {
        $data .= str_repeat('=', 4 - $remainder);
    }
    return base64_decode(strtr($data, '-_', '+/'));
}

// Generate JWT
function generateJWT(array $payload, int $expireMinutes = 60): string
{
    $header = [
        'alg' => 'HS256',
        'typ' => 'JWT'
    ];
    
    $now = time();
    $payload['iat'] = $now;           // issued at
    $payload['nbf'] = $now;           // not before
    $payload['exp'] = $now + ($expireMinutes * 60); // expired
    
    $headerEncoded  = base64urlEncode(json_encode($header, JSON_UNESCAPED_UNICODE));
    $payloadEncoded = base64urlEncode(json_encode($payload, JSON_UNESCAPED_UNICODE));
    
    // Buat signature: HMAC-SHA256
    $signature = hash_hmac('sha256', $headerEncoded . '.' . $payloadEncoded, JWT_SECRET, true);
    $signatureEncoded = base64urlEncode($signature);
    
    return $headerEncoded . '.' . $payloadEncoded . '.' . $signatureEncoded;
}

// Verify JWT
function verifyJWT(string $token): ?array
{
    // Pisahkan 3 bagian
    $parts = explode('.', $token);
    if (count($parts) !== 3) {
        return null;
    }
    
    [$headerEncoded, $payloadEncoded, $signatureEncoded] = $parts;
    
    // Hitung ulang signature
    $signatureCheck = hash_hmac('sha256', $headerEncoded . '.' . $payloadEncoded, JWT_SECRET, true);
    $signatureCheckEncoded = base64urlEncode($signatureCheck);
    
    // Bandingkan signature (timing safe)
    if (!hash_equals($signatureEncoded, $signatureCheckEncoded)) {
        return null; // signature tidak valid
    }
    
    // Decode payload
    $payloadJson = base64urlDecode($payloadEncoded);
    $payload = json_decode($payloadJson, true);
    
    if (json_last_error() !== JSON_ERROR_NONE || !is_array($payload)) {
        return null;
    }
    
    // Cek expired
    $now = time();
    if (isset($payload['exp']) && $now >= $payload['exp']) {
        return null; // token expired
    }
    
    // Cek not before
    if (isset($payload['nbf']) && $now < $payload['nbf']) {
        return null;
    }
    
    return $payload;
}

// Ambil token dari header Authorization
function getTokenFromHeader(): ?string
{
    $headers = getallheaders();
    if (!$headers) {
        return null;
    }
    
    // Cari Authorization header (case-insensitive)
    foreach ($headers as $key => $value) {
        if (strtolower($key) === 'authorization') {
            // Format: Bearer <token>
            if (str_starts_with($value, 'Bearer ')) {
                return trim(substr($value, 7));
            }
            return trim($value);
        }
    }
    return null;
}

// Fungsi respon
function sendResponse(int $code, array $data = [], string $message = ''): void
{
    http_response_code($code);
    echo json_encode([
        'status' => $code >= 200 && $code < 300 ? 'success' : 'error',
        'code'   => $code,
        'message'=> $message,
        'data'   => $data,
        'timestamp' => date('Y-m-d H:i:s')
    ], JSON_UNESCAPED_UNICODE | JSON_PRETTY_PRINT);
    exit;
}

// Routing
$method = $_SERVER['REQUEST_METHOD'];
$uri    = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);
$uri    = rtrim($uri, '/');
$segments = explode('/', $uri);
$endpoint = end($segments);

// 1. POST /login -> generate token
if ($method === 'POST' && $endpoint === 'login') {
    $raw = file_get_contents('php://input');
    $input = json_decode($raw, true);
    
    if (json_last_error() !== JSON_ERROR_NONE) {
        sendResponse(400, [], 'Format JSON tidak valid');
    }
    
    $email = trim($input['email'] ?? '');
    $password = trim($input['password'] ?? '');
    
    if ($email === '' || $password === '') {
        sendResponse(400, [], 'Email dan password wajib diisi');
    }
    
    // Simulasi validasi user (hardcode untuk latihan)
    // Data dummy anggota perpustakaan
    if ($email === 'andi@perpustakaan.test' && $password === 'rahasia123') {
        $payload = [
            'user_id' => 1,
            'nama'    => 'Andi Pratama',
            'email'   => $email,
            'role'    => 'anggota',
        ];
        $token = generateJWT($payload, 60); // berlaku 60 menit
        sendResponse(200, [
            'token' => $token,
            'type'  => 'Bearer',
            'expires_in' => 3600
        ], 'Login berhasil. Token berhasil dibuat');
    }
    
    sendResponse(401, [], 'Email atau password salah');
}

// 2. GET /profile -> endpoint protected (butuh token)
if ($method === 'GET' && $endpoint === 'profile') {
    $token = getTokenFromHeader();
    if ($token === null) {
        sendResponse(401, [], 'Token tidak ditemukan. Kirim header: Authorization: Bearer <token>');
    }
    
    $payload = verifyJWT($token);
    if ($payload === null) {
        sendResponse(401, [], 'Token tidak valid atau sudah expired');
    }
    
    // Token valid -> kembalikan data profile dari payload
    sendResponse(200, [
        'user_id' => $payload['user_id'],
        'nama'    => $payload['nama'],
        'email'   => $payload['email'],
        'role'    => $payload['role'],
        'iat'     => $payload['iat'],
        'exp'     => $payload['exp'],
    ], 'Profil berhasil diambil');
}

// 3. GET /public -> endpoint publik (tanpa token)
if ($method === 'GET' && $endpoint === 'public') {
    sendResponse(200, [
        'info' => 'Endpoint ini bisa diakses tanpa token',
        'katalog_tersedia' => true
    ], 'Data publik berhasil diambil');
}

// 404 fallback
sendResponse(404, [], 'Endpoint tidak ditemukan. Coba: POST login, GET profile, GET public');
```

## Tracing Code (Step-by-Step)

Kita telusuri alur **Login → Generate JWT** lalu **Akses Profile → Verify JWT**.

### Tracing A: POST /login → generateJWT()

**Langkah 1 — Terima input JSON**

`$input = json_decode(file_get_contents('php://input'), true)`. Validasi format JSON.

**Langkah 2 — Ambil & validasi kredensial**

Cek `email === 'andi@perpustakaan.test' && password === 'rahasia123'`. Jika benar → lanjut generate token.

**Langkah 3 — Buat payload dasar**

```php
$payload = [
  'user_id' => 1,
  'nama'    => 'Andi Pratama',
  'email'   => $email,
  'role'    => 'anggota',
];
```

**Langkah 4 — generateJWT($payload, 60)**

- Buat `$header = ['alg'=>'HS256','typ'=>'JWT']`
- `$now = time()` (epoch)
- Tambah `iat = now`, `nbf = now`, `exp = now + 3600`

Jadi payload jadi:

```php
['user_id'=>1,'nama'=>'Andi Pratama','email'=>'andi@...','role'=>'anggota','iat'=>1760688000,'nbf'=>1760688000,'exp'=>1760691600]
```

**Langkah 5 — Base64url encode header & payload**

- `json_encode($header)` → `{"alg":"HS256","typ":"JWT"}`
- `base64urlEncode` → hasil mirip `eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9`

Sama untuk payload.

**Langkah 6 — Buat signature**

`$dataToSign = $headerEncoded . '.' . $payloadEncoded`

`$signature = hash_hmac('sha256', $dataToSign, JWT_SECRET, true)` → binary HMAC-SHA256

`$signatureEncoded = base64urlEncode($signature)` → bentuk base64url

**Langkah 7 — Gabung jadi JWT**

`$token = $headerEncoded . '.' . $payloadEncoded . '.' . $signatureEncoded`

Inilah string 3 bagian terpisah titik.

**Langkah 8 — Kirim respon 200**

Kembalikan token + type Bearer + expires_in 3600.

### Tracing B: GET /profile → verifyJWT()

**Langkah 1 — Ambil token dari header**

`getTokenFromHeader()` mencari `Authorization: Bearer eyJ...`

Ekstrak substring setelah `Bearer ` → dapat token murni.

Jika header tidak ada → **401**.

**Langkah 2 — verifyJWT($token)**

- `explode('.', $token)` → dapat 3 bagian. Jika !=3 → **null**.
- Ambil `$headerEncoded, $payloadEncoded, $signatureEncoded`

**Langkah 3 — Hitung ulang signature**

`$signatureCheck = hash_hmac('sha256', $headerEncoded . '.' . $payloadEncoded, JWT_SECRET, true)`

`$signatureCheckEncoded = base64urlEncode($signatureCheck)`

**Langkah 4 — Bandingkan signature**

Pakai `hash_equals($signatureEncoded, $signatureCheckEncoded)` (timing-attack safe).

**Jika berbeda** → artinya payload/header diubah (mis. ubah role jadi `admin`) → signature tidak match → **return null** → **401 "Token tidak valid"**.

**Jika sama** → signature valid (token asli, belum diubah).

**Langkah 5 — Decode payload**

`$payloadJson = base64urlDecode($payloadEncoded); $payload = json_decode($payloadJson, true)`

Validasi decode berhasil.

**Langkah 6 — Cek waktu kadaluarsa**

- Cek `exp` → jika `now >= exp` → **expired** → return null → **401**.
- Cek `nbf` (not before) → jika `now < nbf` → belum boleh dipakai → return null.

**Langkah 7 — Token valid → return payload**

Kembalikan array payload. Di route `/profile`, kita ambil `user_id,nama,email,role,iat,exp` dan kirim sebagai respon **200**.

## Analogi

Bayangkan **sistem akses perpustakaan digital** dengan kartu akses digital.

- **Login** = Pengunjung menunjukkan KTP ke petugas loket. Petugas verifikasi data.
- **JWT** = **Kartu Akses Bertanda Tangan Digital**. Di kartu tertera identitas (nama, nomor anggota, role) + masa berlaku.
- **Header** = Jenis kartu "JWT" dan metode cetak "HS256".
- **Payload (Claims)** = **Data identitas** di kartu: "Anggota #1, Andi Pratama, role: anggota, berlaku sampai 17/10/25 11:00".
- **Signature** = **Tanda tangan digital rahasia** petugas. Dibuat dari isi kartu + stempel rahasia perpustakaan.
- **SECRET_KEY (JWT_SECRET)** = **Cap/stempel rahasia** yang **HANYA** dimiliki sistem perpustakaan. Tidak boleh dibagikan.
- **generateJWT** = Petugas **mencetak kartu** dengan menambahkan tanda tangan digital.
- **Authorization: Bearer <token>** = Pengunjung **menunjukkan kartu** ke gerbang/layanan digital.
- **verifyJWT** = Sistem **memeriksa tanda tangan**: "Apakah tanda tangan ini cocok dengan cap rahasia kita?". Juga cek "masih berlaku atau sudah expired?".
- **hash_equals** = Pemeriksaan sangat teliti (anti-timing attack) — seperti membandingkan cap dengan mikroskop.
- **base64url** = Cara **mengkodekan** data kartu jadi bentuk ringkas & aman untuk dikirim via HTTP (tanpa spasi/+ berbahaya).
- **Stateless** = Gerbang **tidak perlu menghubungi buku besar** untuk mengingat semua kartu yang dikeluarkan. Cukup **periksa tanda tangan + masa berlaku** di kartu itu sendiri.
- **Expired (exp)** = Kartu **kedaluwarsa** setelah waktu tertentu → wajib login ulang.
- **401 Unauthorized** = "Akses ditolak. Tunjukkan kartu yang sah".

Kuncinya: **Siapa pun bisa BACA isi payload** (karena base64url bisa didecode), tapi **TIDAK BISA MENGUBAH isi payload TANPA merusak signature**. Karena untuk buat signature baru perlu `JWT_SECRET`.

## Dipakai untuk Apa

- **Proteksi REST API endpoint** (profile, pinjam-buku, riwayat-peminjaman).
- **Autentikasi SPA** (React/Vue) tanpa session cookie.
- **Mobile App API** (Android/iOS).
- **Role-based access** (cek `role` di payload).
- **Single Sign-On ringan** antar service (dengan secret bersama).
- **API Key alternatif** berbasis klaim.
- **Mendukung arsitektur stateless microservice**.

## Kesalahan Umum yang Sering Terjadi

- **Menyimpan secret di codebase publik** → gunakan `.env` (env var). Jangan commit `JWT_SECRET`.
- **Menyimpan token di `localStorage` tanpa proteksi** → rentan XSS. Alternatif: `HttpOnly Secure SameSite` cookie (lebih aman) tapi beda pendekatan.
- **Tidak pakai `HTTPS` di production** → token bisa disadap (MITM).
- **Membawa data sensitif di payload** (password, NIK) → **JANGAN**. Payload bisa dibaca client.
- **Lupa cek `exp`/`nbf`** → token kadaluarsa masih bisa dipakai.
- **Pakai algoritma `none`** → sangat berbahaya (bisa bypass signature).
- **Bandingkan signature dengan `==` biasa** → kurang aman. Pakai `hash_equals`.
- **Lupa `Bearer` prefix** → parsing gagal.
- **Header case-sensitive?** `Authorization` vs `authorization` → cek lowercase seperti contoh.
- **getallheaders()** bisa beda di CLI vs web server (FPM/Apache) — umumnya aman di Apache. Di lingkungan lain bisa perlu fallback `$_SERVER['HTTP_AUTHORIZATION']`.
- **Secret lemah** → gampang ditebak/brute force HS256.
- **Tidak rotate secret** saat kebocoran.

**Penjelasan `nbf` (Not Before):** Kita sudah punya `if (isset($payload['nbf']) && $now < $payload['nbf']) return null;`. Artinya **token TIDAK boleh dipakai sebelum waktu `nbf`** (berguna misal mau "jadwalkan" aktivasi token nanti, atau mencegah reuse token terlalu dini). Kalau `nbf = now`, token bisa langsung dipakai.
