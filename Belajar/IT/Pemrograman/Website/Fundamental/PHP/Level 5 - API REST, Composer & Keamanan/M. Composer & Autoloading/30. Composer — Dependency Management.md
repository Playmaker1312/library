# Composer — Dependency Management & Autoloading

## Penjelasan

**Composer** adalah **dependency manager** (manajer paket/library) untuk PHP. Composer membantu kita mengelola library pihak ketiga, mengatur versi, serta menyediakan **autoloading** otomatis untuk class PHP.

Konsep penting Composer:

- **`composer.json`** → file konfigurasi utama berisi daftar dependency, autoload, metadata project.
- **`composer.lock`** → file kunci yang mencatat **versi persis** library yang terinstall (menjamin konsistensi tim/production).
- **`vendor/`** → folder berisi semua library hasil instalasi + `autoload.php`.
- **`composer require <package>`** → menambah dependency baru.
- **`composer install`** → install semua dependency berdasarkan `composer.lock` (umum dipakai di production/clone repo).
- **`composer update`** → update dependency ke versi terbaru sesuai constraint.
- **PSR-4 Autoloading** → standar autoload class PHP (menghubungkan `namespace\Class` dengan path folder).
- **Autoload files/classes** → bisa autoload class sendiri tanpa `require` manual per file.
- **Packagist** → repository resmi paket PHP (https://packagist.org).

Kapan pakai Composer?

- Butuh library: `firebase/php-jwt`, `vlucas/phpdotenv`, `phpmailer/phpmailer`, dll.
- Mau bikin struktur OOP rapi dengan **namespace + autoload**.
- Siap migrasi ke framework (Laravel/Symfony pakai Composer).

Konteks perpustakaan: kita bisa pakai `firebase/php-jwt` untuk JWT versi production, atau bikin **autoload PSR-4** untuk class `Buku`, `Anggota`, `Peminjaman` sendiri.

## Fungsi

- **Mengelola dependency** dengan rapi (tanpa download manual ZIP).
- **Menyelesaikan dependency tree** (library butuh library lain otomatis).
- **Autoloading otomatis** → hilangkan `require_once` berantakan.
- **Konsistensi versi** antar environment via `composer.lock`.
- **Mudah upgrade/downgrade** library.
- **Standar PSR** untuk struktur project.
- **Fondasi wajib** project PHP modern.

## Cara Pengimplementasian / Code

Kita akan praktikkan **dua hal**: (1) Inisialisasi project Composer + PSR-4 autoload, (2) Contoh penggunaan class dengan autoload.

### Langkah 1: Inisialisasi Composer (via CLI)

Buka terminal di folder project, misal `D:\xampp\htdocs\perpustakaan\`

```bash
composer init
```

Isi interaktif (bisa skip):
- Package name: `latihan/perpustakaan` (opsional)
- Description: Belajar Composer
- Author: Nama kamu
- Minimum stability: stable
- Package type: project
- License: MIT

Lalu tambahkan autoload PSR-4:

Bisa edit manual `composer.json` atau lewat CLI. Kita edit manual biar jelas.

**File: `composer.json` (contoh hasil)**

```json
{
    "name": "belajar/perpustakaan",
    "description": "Latihan Composer untuk materi fundamental PHP",
    "type": "project",
    "license": "MIT",
    "authors": [
        {
            "name": "Peserta Belajar",
            "email": "peserta@perpustakaan.test"
        }
    ],
    "require": {},
    "autoload": {
        "psr-4": {
            "App\\": "src/"
        }
    }
}
```

Penjelasan:
- `"App\\"` = **namespace prefix**
- `"src/"` = folder tempat class kita berada

### Langkah 2: Buat struktur folder & class

Buat folder `src/` di root project.

**File: `src/Buku.php`**

```php
<?php
// src/Buku.php

namespace App;

class Buku
{
    public function __construct(
        public int $id,
        public string $judul,
        public string $pengarang,
        public int $tahun,
        public int $stok = 1
    ) {
    }

    public function info(): string
    {
        return "#{$this->id} - {$this->judul} ({$this->pengarang}, {$this->tahun}) | Stok: {$this->stok}";
    }

    public function tersedia(): bool
    {
        return $this->stok > 0;
    }
}
```

**File: `src/Anggota.php`**

```php
<?php
// src/Anggota.php

namespace App;

class Anggota
{
    public function __construct(
        public int $id,
        public string $nama,
        public string $email
    ) {
    }

    public function salam(): string
    {
        return "Halo, {$this->nama}! Selamat datang di Perpustakaan Digital.";
    }
}
```

### Langkah 3: Generate Autoload

Jalankan perintah di terminal:

```bash
composer dump-autoload
```

Hasilnya akan terbuat folder `vendor/` yang berisi `autoload.php` dan file pendukung.

### Langkah 4: Gunakan Autoload di file utama

**File: `30-composer-autoload-demo.php`**

```php
<?php
// File: 30-composer-autoload-demo.php
declare(strict_types=1);

error_reporting(E_ALL);
ini_set('display_errors', 1);

// Load autoload Composer
require_once __DIR__ . '/vendor/autoload.php';

// Gunakan class dengan namespace App\
use App\Buku;
use App\Anggota;

// Instansiasi
$buku = new Buku(101, 'Clean Code', 'Robert C. Martin', 2008, 5);
$anggota = new Anggota(1, 'Andi Pratama', 'andi@perpustakaan.test');

echo $buku->info() . PHP_EOL;
echo ($buku->tersedia() ? 'Tersedia' : 'Habis') . PHP_EOL;
echo PHP_EOL;
echo $anggota->salam() . PHP_EOL;
```

**Cara menjalankan/menguji:**

1. Buka terminal di `htdocs/perpustakaan/`
2. `composer init` (jika belum) → isi sesuai langkah 1
3. Buat folder `src/` + file `Buku.php`, `Anggota.php`
4. `composer dump-autoload`
5. Buat `30-composer-autoload-demo.php`
6. Akses `http://localhost/perpustakaan/30-composer-autoload-demo.php`

## Tracing Code (Step-by-Step)

Kita telusuri alur Composer + Autoload.

### Tracing A: `composer.json` & PSR-4

**Langkah 1 — Definisi PSR-4 mapping**

`"App\\": "src/"` berarti:
- Setiap class dengan **namespace `App\`** (contoh `App\Buku`)
- Akan dicari di folder **`src/`** relatif terhadap `composer.json`
- Nama file harus **sama persis** dengan nama class + `.php` (case-sensitive)

Contoh: `App\Buku` → `src/Buku.php`, `App\Service\Pinjam` (jika ada) → `src/Service/Pinjam.php`

**Langkah 2 — `composer dump-autoload`**

Composer membaca `composer.json`, membangun **class map**/**PSR-4 rules**, lalu generate file `vendor/composer/autoload_psr4.php`, `autoload_classmap.php`, `autoload_files.php`, dan `autoload.php` utama.

Isi kunci `vendor/composer/autoload_psr4.php` (ringkas):

```php
return [
  'App\\' => array($baseDir . '/src'),
];
```

Artinya: prefix `App\` diarahkan ke path `src/`.

### Tracing B: `require_once vendor/autoload.php`

**Langkah 1 — Load bootstrap autoload**

`require_once __DIR__ . '/vendor/autoload.php';` memuat loader Composer.

`vendor/autoload.php` akan:
- Mendaftarkan semua autoload function (PSR-4, classmap, files)
- Siap mencari class saat pertama kali diinstansiasi (`new`) atau dipanggil (`class_exists`, dll.)

**Langkah 2 — `use App\Buku; use App\Anggota;`**

`use` adalah **alias/import** di level PHP (tidak memuat file). Hanya mempermudah penulisan `new Buku()` alih-alih `new App\Buku()`.

**Langkah 3 — `new Buku(...)`**

PHP melihat class `Buku` tanpa namespace full? Tapi kita pakai `use App\Buku` jadi ekivalen `new App\Buku()`.

Saat pertama kali `new App\Buku()` dipanggil:
- Composer autoload (PSR-4) mencari: prefix `App\` cocok → arahkan ke `src/`
- Gabung path: `src/Buku.php`
- Cek file exists → ya, `src/Buku.php`
- `require` file tersebut secara **otomatis** (tanpa kita tulis manual)
- Lalu jalankan constructor `Buku`

Proses sama untuk `new Anggota()` → load `src/Anggota.php`.

**Langkah 4 — Eksekusi method**

`$buku->info()` mengembalikan string gabungan. `echo` ditampilkan.

**Output akhir:**

```text
#101 - Clean Code (Robert C. Martin, 2008) | Stok: 5
Tersedia

Halo, Andi Pratama! Selamat datang di Perpustakaan Digital.
```

### Tracing C: `composer require` (contoh)

Misal kita tambah library `firebase/php-jwt`:

```bash
composer require firebase/php-jwt
```

Yang terjadi:
- Composer cek Packagist untuk package `firebase/php-jwt`
- Ambil info versi stabil terbaru
- Update `composer.json` → tambahkan `"firebase/php-jwt": "^6.10"` (contoh)
- Download package ke `vendor/firebase/php-jwt/`
- Update `composer.lock` (rekam versi persis)
- Jalankan `dump-autoload` otomatis

Setelah itu kita bisa pakai:

```php
use Firebase\JWT\JWT;
use Firebase\JWT\Key;
```

Dan `vendor/autoload.php` sudah mencakup PSR-4 dari package tsb.

## Analogi

Bayangkan **perpustakaan dengan sistem inventaris modern**.

- **Composer** = **Petugas Pengadaan Perpustakaan**. Bertugas mencari, membeli, mencatat & mengatur koleksi "alat bantu" (library) yang dibutuhkan pustakawan lain.
- **Packagist** = **Toko alat perpustakaan online** (pusat distributor). Dari sana Composer bisa "memesan" library yang dibutuhkan.
- **`composer.json`** = **Daftar Kebutuhan Bulanan**. "Bulan ini kita butuh firebase/php-jwt, vlucas/phpdotenv". Hanya **daftar keinginan** (bisa pakai ^ ~).
- **`composer.lock`** = **Bon pembelian FIX**. Mencatat **merk & nomor seri persis** barang yang benar-benar dibeli: "Yang datang versi 6.10.0 persis". Ini jaminan semua petugas dapet barang SAMA.
- **`vendor/`** = **Gudang alat**. Semua library yang dibeli disimpan rapi di satu tempat.
- **`composer require`** = **Pesan & ambil alat baru** ke gudang.
- **`composer install`** = **Bongkar & tata alat** sesuai bon (`composer.lock`) saat pindah lokasi (misal deploy ke server).
- **`composer update`** = **Ganti alat ke versi lebih baru** dengan catatan sesuai constraint.
- **`vendor/autoload.php`** = **Kartu indeks otomatis gudang**. "Kalau kamu butuh class `Firebase\JWT\JWT`, aku tunjukin letaknya di `vendor/firebase/php-jwt/...`".
- **PSR-4 Autoloading** = **Sistem penataan arsip pustaka**. Aturan: "Koleksi dengan label `App\` taruh di rak `src/`. Nama map sama dengan nama buku/class".
- **`dump-autoload`** = **Perbarui kartu indeks** setiap kali kita tambah class baru di `src/`.
- **`use App\Buku`** = **Minta petugas tunjukin rak** tanpa harus sebut alamat penuh tiap kali.
- **Tanpa Composer (manual require)** = **Mencari-cari map kertas satu-satu**: `require 'src/Buku.php'; require 'src/Anggota.php'; ...` makin banyak makin repot.

Intinya: Composer membuat kita **"minta alat" bukan "copy-paste file manual"**, dan **autoload membuat kita "panggil class" bukan "require file"**.

## Dipakai untuk Apa

- **Project OOP terstruktur** (pisah class ke `src/`, `app/`, `Models/`).
- **Integrasi library pihak ketiga** (JWT, dotenv, validation, mailer).
- **Membangun REST API modular** (Controller/Service/Repository).
- **Siap pakai framework** (konsep autoload & composer wajib).
- **Kolaborasi tim** → `composer.lock` pastikan semua pakai versi sama.
- **Deployment production** → cukup `composer install --no-dev`.
- **Testing** → gampang tambah PHPUnit via composer.
- **Autoload custom namespace** untuk project sendiri.

## Kesalahan Umum yang Sering Terjadi

- **Commit `vendor/` ke Git** → folder besar & bisa bentrok. Biasanya **DIABAIKAN** (`.gitignore`).
- **Lupa commit `composer.lock`** → beda versi saat deploy. **WAJIB commit** `composer.lock`.
- **Jalankan `composer update` di production** → bisa ubah versi tanpa sengaja (break). Pakai `composer install`.
- **Salah mapping PSR-4**: `"App\\": "src/"` tapi class pakai namespace beda → Class not found.
- **Nama file != nama class** (case-sensitive) → autoload gagal.
- **Lupa `composer dump-autoload`** setelah tambah class baru → "Class 'App\X' not found".
- **Panggil `vendor/autoload.php` dari path salah** → `require_once 'vendor/autoload.php'` bisa fail kalau file beda folder.
- **Minimum PHP version mismatch** → composer error saat install.
- **Global vs local composer** → pastikan pakai composer yang tersedia.
- **Mengedit `composer.lock` manual** → jangan. Biarkan composer yang urus.

## Soal Latihan & Jawaban

### Soal

1. Buat project Composer baru di folder `latihan-composer/` (bisa di dalam `htdocs/perpustakaan/latihan-composer/`).
2. Buat `composer.json` dengan PSR-4: `"App\\": "src/"`
3. Buat class `App\Repository\BukuRepository` di `src/Repository/BukuRepository.php`. Class ini punya method `getAll(): array` yang return minimal 2 data buku dummy.
4. Buat class `App\Service\BukuService` di `src/Service/BukuService.php`. Class ini menerima `BukuRepository` via **constructor** (Dependency Injection) dan punya method `tampilkanKatalog(): void` yang echo daftar buku.
5. Buat file `index.php` di root, load `vendor/autoload.php`, instansiasi service & panggil `tampilkanKatalog()`.
6. Jalankan `composer dump-autoload` dan uji hasilnya.

### Jawaban

**Struktur folder:**

```
latihan-composer/
├── composer.json
├── index.php
├── src/
│   ├── Repository/
│   │   └── BukuRepository.php
│   └── Service/
│       └── BukuService.php
└── vendor/ (setelah dump-autoload)
```

**composer.json**

```json
{
    "autoload": {
        "psr-4": {
            "App\\": "src/"
        }
    }
}
```

**src/Repository/BukuRepository.php**

```php
<?php

namespace App\Repository;

class BukuRepository
{
    public function getAll(): array
    {
        return [
            ['id'=>1,'judul'=>'Clean Code','pengarang'=>'Robert C. Martin'],
            ['id'=>2,'judul'=>'Atomic Habits','pengarang'=>'James Clear'],
        ];
    }
}
```

**src/Service/BukuService.php**

```php
<?php

namespace App\Service;

use App\Repository\BukuRepository;

class BukuService
{
    public function __construct(private BukuRepository $repo)
    {
    }

    public function tampilkanKatalog(): void
    {
        $list = $this->repo->getAll();
        echo "=== KATALOG BUKU ===" . PHP_EOL;
        foreach ($list as $b) {
            echo "#{$b['id']} - {$b['judul']} ({$b['pengarang']})" . PHP_EOL;
        }
    }
}
```

**index.php**

```php
<?php

require_once __DIR__ . '/vendor/autoload.php';

use App\Repository\BukuRepository;
use App\Service\BukuService;

$repo = new BukuRepository();
$service = new BukuService($repo);
$service->tampilkanKatalog();
```

**Terminal:**

```bash
composer dump-autoload
php index.php
```

**Output:**

```text
=== KATALOG BUKU ===
#1 - Clean Code (Robert C. Martin)
#2 - Atomic Habits (James Clear)
```
