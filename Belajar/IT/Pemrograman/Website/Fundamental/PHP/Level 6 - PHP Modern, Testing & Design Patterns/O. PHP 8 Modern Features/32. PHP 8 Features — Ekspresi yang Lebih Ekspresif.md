# PHP 8 Features — Ekspresi yang Lebih Ekspresif

## Penjelasan

PHP 8 membawa banyak peningkatan sintaks & fitur yang membuat kode lebih **ringkas, aman, ekspresif dan mudah dibaca**. Di materi ini kita fokus pada fitur yang **paling relevan** untuk pembelajaran & praktik sehari-hari:

Fitur yang dibahas:

- **Constructor Property Promotion** (sudah dipakai di 23–25) — mendefinisikan property langsung di constructor.
- **Union Types** (`int|string`, `float|int|null`) — parameter/return bisa menerima lebih dari 1 tipe.
- **Named Arguments** (`function(nama: 'Andi', id: 1)`) — sebut nama parameter saat memanggil, urutan bebas.
- **Match Expression** (`match($x){...}`) — pengganti `switch` yang lebih ringkas & strict comparison (`===`).
- **Nullsafe Operator (`?->`)** — aman mengakses property/method saat nilai bisa `null` tanpa `isset()` beruntun.
- **Enumerations (Enum)** — tipe data khusus untuk kumpulan nilai konstan (lebih aman ketimbang string/const).
- **str_contains()**, **str_starts_with()**, **str_ends_with()** — cek keberadaan substring (sudah kita pakai, tapi dipertegas).
- **Attributes (`#[...]`)** — metadata untuk class/method/property (pengantar).
- **Trailing Comma in Parameter Lists** (kecil tapi nyaman).
- **`throw` expression** (bisa dipakai di expression context).

Konteks perpustakaan: Enum untuk `StatusPinjam` (`DIPINJAM`, `DIKEMBALIKAN`, `TERLAMBAT`), Match untuk mapping status, Nullsafe untuk data relasi, Union Type untuk fleksibel.

## Fungsi

- **Kode lebih ringkas** (kurangi boilerplate).
- **Lebih aman** (type strict, nullsafe, enum).
- **Meningkatkan readability** (match lebih jelas vs switch).
- **Mempermudah refactor** ke OOP modern.
- **Siap pakai di project nyata & framework** (Laravel 11+ butuh PHP 8.2+).
- **Mengurangi bug** lewat type system & strict comparison.
- **Ekspresif** tanpa kehilangan kejelasan.

**File: `32-php8-features.php`**

```php
<?php
// File: 32-php8-features.php
declare(strict_types=1);

error_reporting(E_ALL);
ini_set('display_errors', 1);

// 1. ENUM (PHP 8.1+)
enum StatusPinjam: string
{
    case DIPINJAM    = 'dipinjam';
    case DIKEMBALIKAN= 'dikembalikan';
    case TERLAMBAT   = 'terlambat';
    case HILANG      = 'hilang';
}

// 2. Union Types + Return Type
function formatHarga(int|float $nominal): string
{
    return 'Rp ' . number_format($nominal, 0, ',', '.');
}

// 3. Match Expression
function statusLabel(StatusPinjam $status): string
{
    return match ($status) {
        StatusPinjam::DIPINJAM     => 'Sedang Dipinjam',
        StatusPinjam::DIKEMBALIKAN => 'Sudah Dikembalikan',
        StatusPinjam::TERLAMBAT    => 'Terlambat Dikembalikan',
        StatusPinjam::HILANG       => 'Buku Hilang',
        default                    => 'Status Tidak Dikenal',
    };
}

// 4. Nullsafe Operator (?->)
class ProfilAnggota
{
    public function __construct(public ?string $noHp = null)
    {
    }
}

class Anggota
{
    public function __construct(public ?ProfilAnggota $profil = null)
    {
    }
}

// 5. Constructor Property Promotion + Union + Named Args (demo)
class Buku
{
    public function __construct(
        public int $id,
        public string $judul,
        public string|int|null $kodeRak = null, // Union Type
        public ?string $kategori = null,
    ) {
    }
    
    public function info(): string
    {
        $rak = $this->kodeRak ?? 'Belum Ditentukan';
        return "#{$this->id} - {$this->judul} | Rak: {$rak} | Kategori: {$this->kategori ?? '-'}";
    }
}

// 6. Function dengan Named Arguments
function buatAnggota(int $id, string $nama, string $email, bool $aktif = true): array
{
    return [
        'id'    => $id,
        'nama'  => $nama,
        'email' => $email,
        'aktif' => $aktif,
    ];
}

// 7. Attribute (PHP 8+)
#[Attribute(Attribute::TARGET_CLASS | Attribute::TARGET_METHOD)]
class DeskripsiMateri
{
    public function __construct(public string $teks)
    {
    }
}

#[DeskripsiMateri('Kelas ini merepresentasikan data peminjaman buku perpustakaan')]
class Peminjaman
{
    public function __construct(
        public int $idBuku,
        public int $idAnggota,
        public string $tglPinjam = '2025-10-17'
    ) {
    }
}

// Demo Eksekusi
echo "=== 1. ENUM ===" . PHP_EOL;
$pinjamStatus = StatusPinjam::TERLAMBAT;
echo "Status: " . $pinjamStatus->value . PHP_EOL; // 'terlambat'
echo "Label: " . statusLabel($pinjamStatus) . PHP_EOL . PHP_EOL;

echo "=== 2. UNION TYPES & FORMAT HARGA ===" . PHP_EOL;
echo formatHarga(150000) . PHP_EOL;
echo formatHarga(135000.50) . PHP_EOL . PHP_EOL; // float juga diterima

echo "=== 3. NULLSAFE OPERATOR (?->) ===" . PHP_EOL;
$anggota1 = new Anggota(new ProfilAnggota('081234567890'));
$anggota2 = new Anggota(null); // profil null
$anggota3 = new Anggota();      // profil null (default)

// Akses aman: ?-> akan return null jika chain gagal
echo "No HP Anggota1: " . ($anggota1->profil?->noHp ?? 'Tidak ada') . PHP_EOL;
echo "No HP Anggota2: " . ($anggota2->profil?->noHp ?? 'Tidak ada') . PHP_EOL;
echo "No HP Anggota3: " . ($anggota3->profil?->noHp ?? 'Tidak ada') . PHP_EOL . PHP_EOL;

echo "=== 4. CONSTRUCTOR PROPERTY PROMOTION + UNION ===" . PHP_EOL;
$buku1 = new Buku(1, 'Clean Code', 'A-01', 'Pemrograman');
$buku2 = new Buku(2, 'Atomic Habits', 12); // kodeRak bisa int
echo $buku1->info() . PHP_EOL;
echo $buku2->info() . PHP_EOL . PHP_EOL;

echo "=== 5. NAMED ARGUMENTS (urutan bebas) ===" . PHP_EOL;
// Urutan beda, tetap benar karena sebut nama
$ag1 = buatAnggota(email: 'andi@perpustakaan.test', nama: 'Andi Pratama', id: 1, aktif: true);
$ag2 = buatAnggota(id: 2, nama: 'Budi Santoso', email: 'budi@perpustakaan.test');
print_r($ag1);
print_r($ag2);
echo PHP_EOL;

echo "=== 6. MATCH EXPRESSION ===" . PHP_EOL;
echo "DIPINJAM -> " . statusLabel(StatusPinjam::DIPINJAM) . PHP_EOL;
echo "DIKEMBALIKAN -> " . statusLabel(StatusPinjam::DIKEMBALIKAN) . PHP_EOL . PHP_EOL;

echo "=== 7. STRING HELPERS (PHP 8) ===" . PHP_EOL;
$judul = "Clean Architecture";
echo "str_contains('Clean Architecture','Clean')? " . (str_contains($judul, 'Clean') ? 'YA' : 'TIDAK') . PHP_EOL;
echo "str_starts_with('Clean Architecture','Clean')? " . (str_starts_with($judul, 'Clean') ? 'YA' : 'TIDAK') . PHP_EOL;
echo "str_ends_with('Clean Architecture','ture')? " . (str_ends_with($judul, 'ture') ? 'YA' : 'TIDAK') . PHP_EOL . PHP_EOL;

// 8. Attributes reflection sederhana
$ref = new ReflectionClass(Peminjaman::class);
$attrs = $ref->getAttributes(DeskripsiMateri::class);
foreach ($attrs as $attr) {
    $inst = $attr->newInstance();
    echo "=== 8. ATTRIBUTES ===" . PHP_EOL;
    echo "Deskripsi: " . $inst->teks . PHP_EOL;
}
```

## Tracing Code (Step-by-Step)

### Tracing 1: Enum `StatusPinjam`

**Langkah 1 — Deklarasi enum**

`enum StatusPinjam: string` → **Backed Enum** (memiliki nilai string). Setiap case punya `value`.

**Langkah 2 — Akses**

`$pinjamStatus = StatusPinjam::TERLAMBAT;` → object enum instance.

`$pinjamStatus->value` → `'terlambat'`

`statusLabel($pinjamStatus)` dipanggil → masuk match.

### Tracing 2: Match Expression

`match ($status) { ... }` dibandingkan dengan `===`.

- `$status === StatusPinjam::TERLAMBAT` → match case TERLAMBAT → return `'Terlambat Dikembalikan'`.
- Berbeda dengan `switch`: match **langsung return value**, lebih ringkas, **no fall-through**, bisa strict.
- `default` opsional tapi aman.

**Kelebihan vs switch:** match expression adalah **expression** (bisa disimpan di variabel/return), switch adalah statement.

### Tracing 3: Union Types `int|float`

`function formatHarga(int|float $nominal): string`

Dipanggil dengan `150000` (int) → diterima. `135000.50` (float) → diterima. Jika dikirim `null` atau `'150000'` → TypeError karena `declare(strict_types=1)`.

### Tracing 4: Nullsafe Operator `?->`

Chain: `$anggota1->profil?->noHp`

- `$anggota1->profil` ada (object ProfilAnggota) → akses `->noHp` → `'081234567890'`
- `$anggota2->profil` **null** → operator `?->` **berhenti** dan return `null` (tanpa error)
- Digabung `?? 'Tidak ada'` → tampil fallback

Tanpa nullsafe kita perlu:

```php
$noHp = ($anggota2->profil !== null) ? $anggota2->profil->noHp : 'Tidak ada';
```

Jauh lebih bertele.

### Tracing 5: Constructor Property Promotion + Union

`public string|int|null $kodeRak = null`

- `$buku1` kirim `'A-01'` (string) → valid
- `$buku2` kirim `12` (int) → valid (union type mengizinkan)
- Bisa `null` (default)

Property langsung dibuat & diisi tanpa body constructor manual.

### Tracing 6: Named Arguments

`buatAnggota(email: 'andi@...', nama: 'Andi...', id: 1, aktif: true)`

Urutan argumen **dibalik** dari definisi `(int $id, string $nama, string $email, ...)`. PHP tetap mengikat berdasarkan **nama parameter**. Sangat berguna kalau fungsi punya banyak parameter opsional.

### Tracing 7: String Helpers

- `str_contains($judul,'Clean')` → true (PHP 8)
- `str_starts_with($judul,'Clean')` → true
- `str_ends_with($judul,'ture')` → true (`'ture'` dari `'Architecture'`? 'Architecture' ends with 'ture'? Cek: Architecture → ...ture? 'Architecture' = Archi + tecture? 'cture' vs 'ture' → 'ture' tidak persis; hasil true/false tergantung string. Contoh ini demo fungsi.)

### Tracing 8: Attributes

`#[DeskripsiMateri('Kelas ini merepresentasikan data peminjaman buku perpustakaan')]` ditempel di class `Peminjaman`.

`ReflectionClass(Peminjaman::class)->getAttributes(...)` membaca metadata. `newInstance()` buat object attribute & ambil `$inst->teks`.

Attributes berguna untuk route, validation, doctrine mapping dll di framework.

## Analogi

Bayangkan **perpustakaan modern yang sudah upgrade sistemnya**.

- **Enum** = **Lemari laci berlabel tetap**. Status pinjam cuma boleh: DIPINJAM, DIKEMBALIKAN, TERLAMBAT, HILANG. Tidak bisa ketik sembarangan "dipinjem" typo.
- **Match Expression** = **Papan petunjuk status**. "Kalau status TERLAMBAT → tampil 'Terlambat Dikembalikan'". Jelas, langsung tunjuk hasil.
- **Union Types** = **Pintu fleksibel**. Kode rak bisa angka **ATAU** huruf+angka. Sistem tetap menerima keduanya.
- **Nullsafe Operator `?->`** = **Jalur aman**. "Kalau ada profil, cek no HP. Kalau profil kosong, berhenti aman & kasih 'Tidak ada'".
- **Constructor Property Promotion** = **Formulir instan**. Langsung jadi kolom property tanpa copy-paste assignment.
- **Named Arguments** = **Mengisi formulir berdasarkan label**. Boleh isi "Email" duluan meski urutan beda.
- **str_contains/starts_with/ends_with** = **Mesin pencari cepat**. Cek "ada kata Clean?" tanpa `strpos!==false`.
- **Attributes** = **Kartu catatan tempel** di map buku/class. "Catatan: kelas ini untuk Peminjaman". Bisa dibaca sistem lain secara otomatis (reflection).
- **Match vs Switch** = Match seperti **menu digital** yang langsung return, switch seperti **lembar instruksi bertahap**.
- **Strict Types** = **Pintu pemeriksaan ketat**. Mencegah salah kirim string ke fungsi yang minta int.

Intinya: Fitur PHP 8 bikin sistem perpustakaan **lebih teratur, aman & minim salah input**.

## Dipakai untuk Apa

- **Enum**: Status transaksi, Role user, Tipe notifikasi.
- **Match**: Mapping status → label, redirect by role, konversi kode.
- **Union Types**: API flexible, DTO yang menerima berbagai bentuk.
- **Nullsafe**: Handle data nested (relasi user->profil).
- **Named Args**: Panggil helper/factory dengan jelas.
- **Attributes**: Routing, Validation, Middleware di app modern.
- **String helpers**: Validasi/pencarian cepat.
- **Promotion**: Biar class DTO/entity lebih ringkas.

## Kesalahan Umum yang Sering Terjadi

- **Pake Enum tapi bandingkan string** → salah. Bandingkan object enum: `$status === StatusPinjam::DIPINJAM`.
- **Lupa `->value`** saat butuh nilai string dari backed enum.
- **Union type terlalu longgar** (`mixed`) → kurang manfaat. Gunakan spesifik seperlunya.
- **Nullsafe chain panjang** → boleh, tapi bisa jadi tanda perlu refactor.
- **Named args + positional campur** → di PHP 8, **positional HARUS dulu**, baru named. `f(1, nama:'A')` OK. `f(nama:'A', 1)` ERROR.
- **Attributes butuh `use Attribute;`** kalau custom (kita sudah pakai `Attribute::TARGET_*` via FQN? `Attribute::TARGET_CLASS` butuh import atau `\Attribute`).
- **Match tanpa default** → kalau value tidak match bisa throw `UnhandledMatchError`.
- **str_contains case-sensitive** → kalau mau case-insensitive pakai `mb_stripos` + logic, atau `strtolower` keduanya.
- **strict_types=1** + union → tetap strict.

## Hubungan dengan Materi Sebelumnya

- **Materi 23–25 (OOP)**: Promotion, union, enum sangat natural dipadukan class.
- **Materi 15 (Fungsi)**: Named args & union types memperkuat signature.
- **Materi 13–14 (Array)**: Match bisa ganti if-elseif panjang.
- **Materi 26–27 (PDO)**: Enum bisa dipakai untuk status di tabel (mapping).
- **Materi 28–29 (API+JWT)**: Union type & validation logic.
- **Hubungan ke 33 (Testing)**: Enum/match mempermudah test (state jelas).

## Soal Latihan & Jawaban

### Soal

1. Buat **Enum** `RoleUser: string` dengan case `ANGGOTA='anggota'`, `PETUGAS='petugas'`, `ADMIN='admin'`.
2. Buat function `aksesLabel(RoleUser $role): string` pakai **match** → `Anggota`, `Petugas`, `Admin`.
3. Buat class `User` dengan **Constructor Property Promotion**: `id (int), nama (string), role (RoleUser)`.
4. Buat function `bolehAksesAdmin(RoleUser $role): bool` pakai match/ternary (boleh hanya `PETUGAS` & `ADMIN`).
5. Buat contoh dengan **Named Arguments** saat instansiasi `User`.
6. Tampilkan hasil dengan nullsafe logic sederhana.

### Jawaban

```php
<?php
declare(strict_types=1);

enum RoleUser: string {
  case ANGGOTA='anggota'; case PETUGAS='petugas'; case ADMIN='admin';
}

function aksesLabel(RoleUser $r): string {
  return match($r){
    RoleUser::ANGGOTA=>'Anggota',
    RoleUser::PETUGAS=>'Petugas',
    RoleUser::ADMIN=>'Admin',
    default=>'Tidak Diketahui'
  };
}
function bolehAksesAdmin(RoleUser $r): bool {
  return match($r){ RoleUser::PETUGAS=>true, RoleUser::ADMIN=>true, default=>false };
}
class User {
  public function __construct(public int $id, public string $nama, public RoleUser $role){}
}
$u1 = new User(id:1, nama:'Andi', role:RoleUser::ANGGOTA);
$u2 = new User(id:2, nama:'Sari', role:RoleUser::PETUGAS);
echo aksesLabel($u1->role).PHP_EOL;
echo aksesLabel($u2->role).PHP_EOL;
echo $u2->role->value.' boleh admin? '.(bolehAksesAdmin($u2->role)?'YA':'TIDAK').PHP_EOL;
```
