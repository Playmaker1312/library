# PDO — Koneksi Database yang Aman

## Penjelasan

**PDO (PHP Data Objects)** adalah ekstensi PHP yang menyediakan **API konsisten** untuk mengakses berbagai database (MySQL, PostgreSQL, SQLite, dll.) dengan cara yang terstruktur dan aman.

Beberapa keunggulan PDO:

- **Database Agnostic**: Bisa ganti driver DB (MySQL→Postgres) dengan minimal perubahan.
- **Prepared Statements**: Dukungan kuat untuk mencegah **SQL Injection** (dibahas materi 27).
- **Exception Mode**: Bisa menangani error dengan `try/catch` (`PDOException`).
- **Fetch Modes Fleksibel**: Bisa ambil data dalam bentuk array, object, class, dll.
- **Secure by Design**: Lebih aman jika dipakai dengan prepared statements.

Komponen penting koneksi PDO:

- **DSN (Data Source Name)**: String koneksi berisi `host`, `dbname`, `charset`.
- **Username & Password**: Kredensial akses database.
- **Options**: Konfigurasi perilaku PDO (`ATTR_ERRMODE`, `ATTR_DEFAULT_FETCH_MODE`, `ATTR_EMULATE_PREPARES`).

Untuk sistem **perpustakaan**, PDO kita pakai untuk membaca/menyimpan data buku, anggota, peminjaman ke MySQL secara aman.

## Fungsi

- **Membuat koneksi terpusat & aman** ke database.
- **Menstandarkan akses database** (konsisten antar proyek).
- **Mempermudah penanganan error** dengan exception.
- **Mendukung prepared statements** untuk keamanan wajib.
- **Memisahkan konfigurasi koneksi** dari logika bisnis.
- **Siap dipakai pola OOP/Repository (materi 34)**.

## Cara Pengimplementasian / Code

```php
<?php
// File: 26-pdo-koneksi.php
declare(strict_types=1);

error_reporting(E_ALL);
ini_set('display_errors', 1);

$host     = 'localhost';
$dbname   = 'perpustakaan_db';
$username = 'root';
$password = '';
$charset  = 'utf8mb4';

$dsn = "mysql:host={$host};dbname={$dbname};charset={$charset}";

$options = [
    // Mode error: throw exception saat ada error SQL
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
    // Fetch default sebagai associative array
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    // Matikan emulate prepares (lebih aman, pakai prepared asli server)
    PDO::ATTR_EMULATE_PREPARES   => false,
    // Atribut opsional: timezone/null handling
    PDO::ATTR_TIMEOUT            => 5,
];

try {
    // Membuat koneksi PDO
    $pdo = new PDO($dsn, $username, $password, $options);
    
    echo "Koneksi database berhasil!" . PHP_EOL;
    echo "Database: {$dbname}" . PHP_EOL;
    echo "Host: {$host}" . PHP_EOL;
    
    // Test query sederhana (cek versi MySQL)
    $stmt = $pdo->query("SELECT VERSION() AS mysql_version");
    $result = $stmt->fetch();
    
    if ($result && isset($result['mysql_version'])) {
        echo "MySQL Version: " . $result['mysql_version'] . PHP_EOL;
    }
    
} catch (PDOException $e) {
    // Tangani error koneksi
    echo "Koneksi database GAGAL!" . PHP_EOL;
    echo "Error: " . $e->getMessage() . PHP_EOL;
    
    // Di lingkungan production, JANGAN tampilkan detail error ke user
    // Log error ke file/log server saja
    exit;
}
```

**Persiapan database (opsional untuk testing):**


5. Jika berhasil muncul "Koneksi database berhasil!"

## Tracing Code (Step-by-Step)

Kita telusuri eksekusi koneksi PDO baris demi baris.

**Langkah 1 — Inisialisasi konfigurasi**

- `$host = 'localhost'` → server database lokal
- `$dbname = 'perpustakaan_db'` → nama database target
- `$username = 'root'` → user default XAMPP/Laragon
- `$password = ''` → kosong default lokal
- `$charset = 'utf8mb4'` → encoding UTF-8 full (mendukung emoji & karakter Unicode)

**Langkah 2 — Membentuk DSN**

`$dsn = "mysql:host={$host};dbname={$dbname};charset={$charset}"`

DSN ini memberitahu PDO: driver `mysql`, host `localhost`, database `perpustakaan_db`, charset `utf8mb4`.

**Langkah 3 — Menyiapkan `$options`**

Array opsi konfigurasi PDO:
- `PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION` → Jika terjadi error SQL/koneksi, PDO akan **melempar exception** (`PDOException`). Ini memudahkan penanganan dengan `try/catch`.
- `PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC` → Secara default, hasil query di-fetch dalam bentuk **associative array** (`['column'=>'value']`). Konsisten dengan materi array associative.
- `PDO::ATTR_EMULATE_PREPARES => false` → Mematikan emulasi prepared statements. PDO akan menggunakan **prepared statements asli dari MySQL server**. Ini lebih aman dan sesuai best practice (mencegah edge case SQL Injection).
- `PDO::ATTR_TIMEOUT => 5` → Timeout koneksi 5 detik (opsional, berguna menghindari hang).

**Langkah 4 — `try { ... }` block**

Memulai blok percobaan koneksi.

**Langkah 5 — `$pdo = new PDO($dsn, $username, $password, $options);`**

PHP membuat **object PDO baru**. Proses ini:
1. Mencoba terhubung ke MySQL server di `localhost` dengan kredensial `root/''`
2. Memilih database `perpustakaan_db`
3. Menerapkan options (`ERRMODE_EXCEPTION`, fetch mode, emulate_prepares)
4. Jika **berhasil** → object `$pdo` terbuat, eksekusi lanjut ke baris setelah `new PDO`.
5. Jika **gagal** (DB tidak ada, salah password, MySQL tidak jalan) → PDO melempar `PDOException`, langsung masuk `catch (PDOException $e)`.

**Langkah 6 — Tampilkan pesan sukses**

Jika koneksi berhasil, echo `"Koneksi database berhasil!"`, tampil nama DB & host.

**Langkah 7 — Test query `$pdo->query("SELECT VERSION() AS mysql_version")`**

- `query()` = mengeksekusi SQL **langsung** (tanpa parameter binding). Cocok untuk query read-only statis (seperti cek versi).
- Return object `PDOStatement`.
- `$stmt->fetch()` mengambil 1 baris hasil, sesuai default fetch mode `PDO::FETCH_ASSOC` → array `['mysql_version' => '8.x.x']`
- Tampilkan versi MySQL.

**Langkah 8 — `catch (PDOException $e)`**

Jika exception dilempar di langkah 5, blok catch dijalankan:
- Echo pesan `"Koneksi database GAGAL!"`
- `echo "Error: " . $e->getMessage()` → menampilkan pesan error detail dari PDO (berguna saat development)
- `exit` → menghentikan eksekusi script

**Catatan Penting (Production):** Di lingkungan **production (online)**, **JANGAN pernah** menampilkan `$e->getMessage()` langsung ke pengguna. Pesan error bisa membocorkan info sensitif (nama DB, path, dll). Sebaiknya **log ke file** dan tampilkan pesan umum `"Terjadi kesalahan sistem"`.

**Output akhir (berhasil):**

```text
Koneksi database berhasil!
Database: perpustakaan_db
Host: localhost
MySQL Version: 8.0.30
```

**Output akhir (gagal):**

```text
Koneksi database GAGAL!
Error: SQLSTATE[HY000] [1049] Unknown database 'perpustakaan_db'
```

## Analogi

Bayangkan **sistem perpustakaan modern** dengan **gudang data terpusat (database MySQL)**.

- **PDO** = **Jembatan penghubung resmi & aman** antara aplikasi perpustakaan (PHP) dengan gudang data.
- **DSN** = **Alamat lengkap gudang**: "Gudang Perpustakaan terletak di localhost, nama gudang: perpustakaan_db, pakai protokol utf8mb4".
- **Username/Password** = **Kartu akses petugas** untuk bisa masuk ke gudang data.
- **`new PDO(...)`** = Petugas **menyeberang jembatan** dan membuka kunci gudang dengan kartu akses yang benar. Jika kartu salah/gudang terkunci → akses ditolak (exception).
- **`try/catch`** = Petugas **siap dengan prosedur darurat** jika jembatan/gudang tidak bisa diakses ("Catat laporan, beritahu teknisi, jangan bocorkan detail ke pengunjung").
- **`PDO::ERRMODE_EXCEPTION`** = Sistem **langsung mengangkat alarm** (exception) jika ada masalah, bukan diam saja.
- **`ATTR_EMULATE_PREPARES => false`** = Memastikan **pemeriksaan data dilakukan di dalam gudang (server DB)**, bukan cuma di jembatan. Ini lapisan keamanan ekstra.
- **`query("SELECT VERSION()")`** = Tes singkat: "Cek apakah gudang bisa merespons permintaan dengan benar".
- **Gudang MySQL** = **Arsip buku/anggota terpusat** yang persisten (bertahan lama), beda dari file JSON (materi 22).

Jadi: PDO adalah **jalur resmi, terstandar dan aman** untuk bertukar data dengan database.

## Dipakai untuk Apa

- **Koneksi database MySQL** secara aman dan terstruktur.
- **CRUD** (Create, Read, Update, Delete) data perpustakaan (buku, anggota, peminjaman).
- **Mendukung pola Repository/Data Access Layer** (materi 34).
- **Aplikasi MVC/Framework** (Laravel/Symfony tetap pakai konsep serupa).
- **Multi-driver database** jika suatu saat pindah DB.
- **Centralized DB connection** (bisa dipisah ke file `config/db.php` terpisah).
- **Project profesional** (best practice vs mysql_* legacy yang sudah deprecated).

## Kesalahan Umum yang Sering Terjadi

- **Menyimpan credential DB langsung di code produksi** → sebaiknya pakai `.env` (nanti saat framework). Untuk belajar boleh, jangan commit password asli.
- **Lupa `charset=utf8mb4`** → bisa muncul masalah karakter (emoticon/Unicode) atau mojibake.
- **`ATTR_EMULATE_PREPARES` dibiarkan `true` default lama** → mengurangi efektivitas prepared statements asli. Set ke `false`.
- **Tampilkan error detail di production** (`$e->getMessage()` ke user) → **risiko informasi sensitif**. Gunakan logging.
- **Tidak pakai `try/catch`** → error bisa muncul tidak terkontrol.
- **Buat koneksi PDO berulang-ulang di tiap file** → boros. Buat **satu koneksi terpusat** (include file koneksi).
- **Pakai `query()` untuk data dari user (input)** → **BERBAHAYA** (bisa SQL Injection). Gunakan **prepared statements** (`prepare()` + `execute()`) — materi 27.
- **MySQL belum running** → `PDOException` (SQLSTATE[HY000] [2002] Connection refused).
- **Database tidak ditemukan** → `SQLSTATE[HY000] [1049] Unknown database`.
- **Salah username/password** → `SQLSTATE[HY000] [1045] Access denied`.

### Jawaban

```php
<?php
declare(strict_types=1);

error_reporting(E_ALL);
ini_set('display_errors', 1);

$dsn = "mysql:host=localhost;dbname=perpustakaan_db;charset=utf8mb4";
$options = [
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES   => false,
    PDO::ATTR_TIMEOUT            => 5,
];

try {
    $pdo = new PDO($dsn, 'root', '', $options);
    echo "Koneksi berhasil." . PHP_EOL;

    // Cek apakah tabel buku ada
    $stmt = $pdo->query("SHOW TABLES LIKE 'buku'");
    if ($stmt->rowCount() > 0) {
        $q = $pdo->query("SELECT COUNT(*) AS total_buku FROM buku");
        $r = $q->fetch();
        echo "Total buku di database: " . $r['total_buku'] . PHP_EOL;
    } else {
        echo "Tabel 'buku' belum ditemukan. Buat tabel terlebih dahulu untuk latihan." . PHP_EOL;
    }
} catch (PDOException $e) {
    echo "Koneksi/Gagal Query: " . $e->getMessage() . PHP_EOL;
    exit;
}
```
