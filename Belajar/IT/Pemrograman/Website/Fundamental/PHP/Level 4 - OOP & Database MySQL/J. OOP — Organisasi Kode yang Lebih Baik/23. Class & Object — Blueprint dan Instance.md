# Class & Object — Blueprint dan Instance

## Penjelasan

**OOP (Object-Oriented Programming)** adalah cara berpikir dan menulis kode dengan mengelompokkan **data (property)** dan **perilaku (method)** ke dalam satu unit bernama **Class**.

Konsep dasarnya:

- **Class** = blueprint/cetakan. Berisi rancangan tentang apa yang dimiliki dan bisa dilakukan oleh objek.
- **Object (Instance)** = hasil cetakan dari class. Setiap object memiliki datanya sendiri-sendiri.
- **Property** = variabel yang berada di dalam class (data/atribut).
- **Method** = fungsi yang berada di dalam class (perilaku/tindakan).
- **`__construct()`** = method khusus yang dijalankan **otomatis** saat object dibuat dengan `new`.
- **`$this`** = kata kunci untuk merujuk ke **object saat ini** (mengakses property/method milik object tersebut).
- **Constructor Property Promotion** (PHP 8) = cara ringkas untuk mendefinisikan property langsung lewat parameter constructor.
- **Type Declaration** = menentukan tipe data property/method agar lebih aman dan terprediksi.

Dalam sistem perpustakaan, kita bisa memodelkan entitas nyata seperti `Buku`, `Anggota`, atau `Peminjaman` menjadi sebuah **class** agar datanya terorganisir dengan rapi.

## Fungsi

- **Mengorganisir kode** agar lebih terstruktur dan mudah dibaca.
- **Mengurangi duplikasi kode** karena logika bisa dipakai ulang lewat object.
- **Mempermudah pemeliharaan** (maintenance) ketika kode bertambah besar.
- **Merepresentasikan dunia nyata** ke dalam kode secara logis.
- **Menjadi fondasi** untuk konsep OOP lanjutan (Inheritance, Interface, Trait).
- **Mempersiapkan kode** agar bisa dipakai di framework modern.

## Cara Pengimplementasian / Code

```php
<?php
// File: 23-class-object.php
declare(strict_types=1);

error_reporting(E_ALL);
ini_set('display_errors', 1);

class Buku
{
    // Constructor Property Promotion (PHP 8)
    public function __construct(
        public int $id,
        public string $judul,
        public string $pengarang,
        public int $tahun,
        public float $harga,
        public int $stok = 0
    ) {
        // Constructor dijalankan otomatis saat object dibuat
    }

    // Method: mengecek ketersediaan buku
    public function tersedia(): bool
    {
        return $this->stok > 0;
    }

    // Method: memformat harga ke format Rupiah
    public function formatHarga(): string
    {
        return 'Rp ' . number_format($this->harga, 0, ',', '.');
    }

    // Method: meminjam buku
    public function pinjam(): bool
    {
        // Jika tidak tersedia, tidak bisa dipinjam
        if (!$this->tersedia()) {
            return false;
        }

        // Kurangi stok sebanyak 1
        $this->stok--;
        return true;
    }

    // Method: mengembalikan buku
    public function kembalikan(): void
    {
        // Tambah stok sebanyak 1
        $this->stok++;
    }

    // Method: menampilkan info buku
    public function info(): string
    {
        return "#{$this->id} - {$this->judul} ({$this->pengarang}, {$this->tahun}) | {$this->formatHarga()} | Stok: {$this->stok}";
    }
}

// Membuat object (instance) dari class Buku
$buku1 = new Buku(1, 'Clean Code', 'Robert C. Martin', 2008, 150000, 5);
$buku2 = new Buku(2, 'Atomic Habits', 'James Clear', 2018, 135000, 0);

// Menampilkan info buku
echo $buku1->info() . PHP_EOL;
echo $buku2->info() . PHP_EOL;

// Mengecek ketersediaan
echo 'Buku 1 tersedia? ' . ($buku1->tersedia() ? 'Ya' : 'Tidak') . PHP_EOL;
echo 'Buku 2 tersedia? ' . ($buku2->tersedia() ? 'Ya' : 'Tidak') . PHP_EOL;

// Simulasi peminjaman
if ($buku1->pinjam()) {
    echo 'Buku 1 berhasil dipinjam.' . PHP_EOL;
} else {
    echo 'Buku 1 gagal dipinjam.' . PHP_EOL;
}

if ($buku2->pinjam()) {
    echo 'Buku 2 berhasil dipinjam.' . PHP_EOL;
} else {
    echo 'Buku 2 gagal dipinjam (stok habis).' . PHP_EOL;
}

// Menampilkan info setelah peminjaman
echo 'Info setelah peminjaman:' . PHP_EOL;
echo $buku1->info() . PHP_EOL;
echo $buku2->info() . PHP_EOL;
```

**Cara menjalankan/menguji:**

1. Simpan file sebagai `23-class-object.php` di `C:\xampp\htdocs\perpustakaan\`
2. Buka browser: `http://localhost/perpustakaan/23-class-object.php`
3. Perhatikan data tiap object yang terpisah meski dibuat dari class yang sama.

## Tracing Code (Step-by-Step)

Kita telusuri kode di atas baris demi baris, seolah-olah PHP mengikuti eksekusi.

**Langkah 1 — Membuat object `$buku1 = new Buku(1, 'Clean Code', 'Robert C. Martin', 2008, 150000, 5);`**

PHP melakukan:
- Membuat **instance baru** dari class `Buku`.
- Memanggil method `__construct()` secara **otomatis**.
- Constructor Property Promotion mengisi property langsung:
  - `$this->id = 1`
  - `$this->judul = 'Clean Code'`
  - `$this->pengarang = 'Robert C. Martin'`
  - `$this->tahun = 2008`
  - `$this->harga = 150000.0`
  - `$this->stok = 5` (dikirim via argument)

**Kondisi saat ini:** Object `$buku1` memiliki property terisi sesuai nilai di atas.

**Langkah 2 — Membuat object `$buku2 = new Buku(2, 'Atomic Habits', 'James Clear', 2018, 135000, 0);`**

Constructor berjalan untuk object `$buku2` terpisah:
- `$this->id = 2`
- `$this->judul = 'Atomic Habits'`
- `$this->pengarang = 'James Clear'`
- `$this->tahun = 2018`
- `$this->harga = 135000.0`
- `$this->stok = 0`

**Kondisi saat ini:** Terdapat 2 object berbeda, **data tidak saling bercampur**.

**Langkah 3 — `echo $buku1->info() . PHP_EOL;`**

Memanggil method `info()` milik `$buku1`.
- Method `info()` mengakses `$this->id`, `$this->judul`, `$this->pengarang`, `$this->tahun`, `$this->stok`.
- Di dalam `info()` juga memanggil `$this->formatHarga()` → method tersebut mengembalikan `"Rp 150.000"`.
- Hasil string: `"#1 - Clean Code (Robert C. Martin, 2008) | Rp 150.000 | Stok: 5"`

**Langkah 4 — `echo $buku2->info() . PHP_EOL;`**

Method `info()` dijalankan untuk `$buku2` (berbeda object). Mengembalikan: `"#2 - Atomic Habits (James Clear, 2018) | Rp 135.000 | Stok: 0"`

**Langkah 5 — Panggil `$buku1->tersedia()`**

Method `tersedia()` mengembalikan `(5 > 0)` → `true`.

**Langkah 6 — Panggil `$buku2->tersedia()`**

Mengembalikan `(0 > 0)` → `false`.

**Langkah 7 — `$buku1->pinjam()`**

- Cek `if (!$this->tersedia())` → `!true = false`, jadi tidak masuk if.
- Jalankan `$this->stok--` → `$this->stok` dari `5` menjadi `4`.
- Return `true`.

**Kondisi saat ini:** `$buku1->stok = 4`, `$buku2->stok = 0`.

**Langkah 8 — `$buku2->pinjam()`**

- Cek `tersedia()` → `false`. Kondisi `if (!$this->tersedia())` → `true`, maka masuk if dan **langsung return `false`**.
- Baris `$this->stok--` **tidak dijalankan**.

**Kondisi saat ini:** Stok `$buku2` tetap `0` (tidak berkurang).

**Langkah 9 — Tampilkan info setelah peminjaman**

`$buku1->info()` menampilkan `Stok: 4`. `$buku2->info()` tetap `Stok: 0`.

**Output akhir:**

```text

#2 - Atomic Habits (James Clear, 2018) | Rp 135.000 | Stok: 0
Buku 1 tersedia? Ya
Buku 2 tersedia? Tidak
Buku 1 berhasil dipinjam.

Info setelah peminjaman:
#1 - Clean Code (Robert C. Martin, 2008) | Rp 150.000 | Stok: 4
#2 - Atomic Habits (James Clear, 2018) | Rp 135.000 | Stok: 0
```

## Analogi

Bayangkan sebuah **perpustakaan**.

- **Class `Buku`** = **resep/cetakan kartu katalog buku** di bagian pengolahan koleksi. Ia menjelaskan: setiap buku harus punya "Judul, Pengarang, Tahun, Harga, Stok" dan bisa "dicek ketersediaan, dipinjam, dikembalikan".
- **Object `$buku1`** = **kartu katalog nyata** untuk buku *Clean Code*. Kartu ini punya data fisik tersendiri (stok 5).
- **Object `$buku2`** = **kartu katalog nyata** lain untuk buku *Atomic Habits* (stok 0). Terpisah dari kartu pertama.
- **Property** = **kolom-kolom data** yang terisi di kartu katalog (Judul, Pengarang, Stok).
- **Method** = **prosedur kerja petugas perpustakaan** yang tertera: "cek ketersediaan", "catat peminjaman (stok--)", "catat pengembalian (stok++)".
- **`$this`** = petugas **sedang mengerjakan kartu katalog itu sendiri** (bukan kartu yang lain).
- **`__construct()`** = saat petugas **membuat kartu katalog baru**, kolom-kolomnya langsung diisi berdasarkan data buku yang masuk.

Intinya: **satu cetakan (Class), bisa menghasilkan banyak benda terpisah (Object)** dengan data masing-masing.

## Dipakai untuk Apa

- **Model data domain** (Buku, Anggota, Peminjaman, Denda).
- **Business Logic** (atur aturan peminjaman, pengembalian, ketersediaan).
- **CRUD terstruktur** sebelum memakai ORM/Framework.
- **Organisasi kode besar** (MVC).
- **Reusable component** antar modul aplikasi.
- **Fondasi kuat** sebelum Inheritance (24).
- **Merepresentasikan entitas database** di level aplikasi.

## Kesalahan Umum yang Sering Terjadi

- **Lupa `$this->`** saat mengakses property/method di dalam class → PHP menganggap variabel lokal (Undefined variable/notice).
- **Mencampur object dan array** → bingung kapan pakai `['key']` vs `->property`.
- **Membuat property tapi tidak dipakai** atau lupa inisialisasi.
- **Menulis logika terlalu banyak di global scope** alih-alih dimasukkan ke method class.
- **Salah visibility** (public/protected/private) — bisa mengakses property sembarangan jika semua public tanpa alasan.
- **Mengakses property sebelum di-set** (terutama tanpa default value).
- **Memanggil method static seperti object** atau sebaliknya tanpa paham perbedaan.
- **Constructor terlalu banyak parameter** → bisa dibersihkan nanti (DTO/Builder).
- **Lupa `return` di method yang seharusnya mengembalikan nilai**.

## Hubungan dengan Materi Sebelumnya

- **Materi 13–14 (Array Associative)**: Sebelumnya kita menyimpan detail buku dalam **associative array** (`['judul'=>...]`). **Class/Object** adalah **evolusi terstruktur** dari pola array tersebut (bisa punya perilaku, bukan hanya data).
- **Materi 15–16 (Fungsi)**: Fungsi yang berkaitan dengan buku bisa dipindah jadi **Method** di dalam Class. Bedanya: method otomatis punya konteks object (`$this`).
- **Materi 17 (Scope Variabel)**: Scope bertambah dengan visibility (`public/protected/private`).
- **Hubungan ke Materi Selanjutnya (24):** Kita akan belajar **Inheritance** untuk mewarisi property/method antar class (misal `User` → `Anggota`, `Staff`, `Admin`).
- **Hubungan ke Materi 26–27 (PDO):** Nanti kita akan menggabungkan OOP dengan akses database (Repository Pattern).

## Soal Latihan & Jawaban

### Soal

Buat class `Anggota` dengan spesifikasi berikut:

1. Buat class `Anggota` dengan property: `id` (int), `nama` (string), `email` (string), `aktif` (bool) — gunakan **Constructor Property Promotion** (PHP 8).
2. Buat method `salam(): string` yang mengembalikan teks: `"Halo, [Nama Anggota]!"`
3. Buat method `statusAktif(): string` yang mengembalikan `"Aktif"` jika `$this->aktif === true`, atau `"Non-Aktif"` jika false.
4. Buat method `info(): string` yang mengembalikan info lengkap: `"#[id] - [nama] ([email]) - [statusAktif]"`
5. Buat 2 object `Anggota` (satu aktif, satu non-aktif), lalu tampilkan `salam()` dan `info()` masing-masing.

### Jawaban

```php
<?php
declare(strict_types=1);

error_reporting(E_ALL);
ini_set('display_errors', 1);

class Anggota
{
    public function __construct(
        public int $id,
        public string $nama,
        public string $email,
        public bool $aktif = true
    ) {
    }

    public function salam(): string
    {
        return "Halo, {$this->nama}!";
    }

    public function statusAktif(): string
    {
        return $this->aktif ? 'Aktif' : 'Non-Aktif';
    }

    public function info(): string
    {
        return "#{$this->id} - {$this->nama} ({$this->email}) - {$this->statusAktif()}";
    }
}

// Membuat object
$anggota1 = new Anggota(1, 'Andi Pratama', 'andi@perpustakaan.test', true);
$anggota2 = new Anggota(2, 'Budi Santoso', 'budi@perpustakaan.test', false);

// Menampilkan
echo $anggota1->salam() . PHP_EOL;
echo $anggota1->info() . PHP_EOL;
echo PHP_EOL;
echo $anggota2->salam() . PHP_EOL;
echo $anggota2->info() . PHP_EOL;
```
