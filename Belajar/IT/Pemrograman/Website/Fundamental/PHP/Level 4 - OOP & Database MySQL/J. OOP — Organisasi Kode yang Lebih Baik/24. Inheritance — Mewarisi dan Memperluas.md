# Inheritance — Mewarisi dan Memperluas

## Penjelasan

**Inheritance (Pewarisan)** adalah konsep OOP yang memungkinkan sebuah **class anak (child/derived class)** mewarisi **property** dan **method** dari **class induk (parent/base class)**. Tujuannya adalah **mendaur ulang kode (code reuse)** tanpa perlu menulis ulang logika yang sama.

Beberapa hal penting:

- **`extends`** = kata kunci untuk menerapkan pewarisan. `class Anak extends Induk { ... }`
- **Property & Method diwarisi** = child bisa langsung memakai apa yang ada di parent (sesuai visibility).
- **`override` (menimpa)** = child bisa mendefinisikan ulang method milik parent dengan logika sendiri.
- **`parent::`** = mengakses method/property milik parent, biasanya dipakai saat override untuk tetap menjalankan logika parent.
- **`protected`** = visibility yang bisa diakses oleh parent maupun child, tapi tidak bisa diakses langsung dari luar.
- **`abstract class`** = class induk yang **tidak bisa di-instansiasi langsung** (`new`). Hanya bisa diwarisi. Biasanya berisi kerangka umum.
- **`final class/method`** = mencegah pewarisan/override (opsional, jarang dipakai di pemula).
- **`::class`** = helper untuk nama class (bisa dipakai nanti).

Dalam konteks **perpustakaan**, kita bisa punya class `User` (umum: id, nama, email) lalu diwarisi oleh `Anggota`, `Petugas`, `Admin` karena mereka punya kesamaan, namun juga punya peran berbeda.

## Fungsi

- **Mengurangi duplikasi kode** (hindari menulis property `nama`, `email` berulang).
- **Membangun hierarki logis** antar entitas.
- **Mempermudah perluasan** (bisa tambah role baru tanpa mengubah parent).
- **Menerapkan prinsip "general ke spesifik"**.
- **Menjaga konsistensi** antar class turunan.
- **Fondasi untuk Polymorphism** (konsep OOP lanjut).

## Cara Pengimplementasian / Code

```php
<?php
// File: 24-inheritance.php
declare(strict_types=1);

error_reporting(E_ALL);
ini_set('display_errors', 1);

// Class Induk (Abstract) - tidak bisa diinstansiasi langsung
abstract class User
{
    public function __construct(
        protected int $id,
        protected string $nama,
        protected string $email,
        protected bool $aktif = true
    ) {
    }

    // Method umum untuk semua user
    public function getId(): int
    {
        return $this->id;
    }

    public function getNama(): string
    {
        return $this->nama;
    }

    public function getEmail(): string
    {
        return $this->email;
    }

    public function isAktif(): bool
    {
        return $this->aktif;
    }

    public function infoUmum(): string
    {
        return "#{$this->id} - {$this->nama} ({$this->email})";
    }

    // Abstract method: wajib di-implement oleh child class
    abstract public function getRole(): string;
}

// Class Anak 1: Anggota
class Anggota extends User
{
    public function __construct(
        int $id,
        string $nama,
        string $email,
        bool $aktif = true,
        private string $nomorAnggota = 'AGT-0000'
    ) {
        // Memanggil constructor parent
        parent::__construct($id, $nama, $email, $aktif);
        $this->nomorAnggota = $nomorAnggota;
    }

    public function getNomorAnggota(): string
    {
        return $this->nomorAnggota;
    }

    // Override abstract method
    public function getRole(): string
    {
        return 'Anggota';
    }

    // Method spesifik anggota
    public function infoLengkap(): string
    {
        $status = $this->isAktif() ? 'Aktif' : 'Non-Aktif';
        return $this->infoUmum() . " | Role: {$this->getRole()} | No: {$this->nomorAnggota} | Status: $status";
    }
}

// Class Anak 2: Petugas
class Petugas extends User
{
    public function __construct(
        int $id,
        string $nama,
        string $email,
        bool $aktif = true,
        private string $shift = 'Pagi'
    ) {
        parent::__construct($id, $nama, $email, $aktif);
        $this->shift = $shift;
    }

    public function getShift(): string
    {
        return $this->shift;
    }

    public function getRole(): string
    {
        return 'Petugas';
    }

    public function infoLengkap(): string
    {
        $status = $this->isAktif() ? 'Aktif' : 'Non-Aktif';
        return $this->infoUmum() . " | Role: {$this->getRole()} | Shift: {$this->shift} | Status: $status";
    }
}

// Class Anak 3: Admin
class Admin extends User
{
    public function __construct(
        int $id,
        string $nama,
        string $email,
        bool $aktif = true,
        private string $departemen = 'Umum'
    ) {
        parent::__construct($id, $nama, $email, $aktif);
        $this->departemen = $departemen;
    }

    public function getRole(): string
    {
        return 'Admin';
    }

    public function infoLengkap(): string
    {
        $status = $this->isAktif() ? 'Aktif' : 'Non-Aktif';
        return $this->infoUmum() . " | Role: {$this->getRole()} | Dept: {$this->departemen} | Status: $status";
    }

    // Method spesifik admin
    public function resetPassword(string $targetNama): string
    {
        return "Admin {$this->getNama()} telah mereset password untuk $targetNama.";
    }
}

// Membuat object dari child class
$anggota = new Anggota(1, 'Andi Pratama', 'andi@perpustakaan.test', true, 'AGT-0001');
$petugas = new Petugas(2, 'Sari Dewi', 'sari@perpustakaan.test', true, 'Siang');
$admin   = new Admin(3, 'Rizky Maulana', 'rizky@perpustakaan.test', true, 'IT');

// Menampilkan info
echo $anggota->infoLengkap() . PHP_EOL;
echo $petugas->infoLengkap() . PHP_EOL;
echo $admin->infoLengkap() . PHP_EOL;
echo PHP_EOL;
echo $admin->resetPassword($anggota->getNama()) . PHP_EOL;
```

**Cara menjalankan/menguji:**

1. Simpan file sebagai `24-inheritance.php` di `C:\xampp\htdocs\perpustakaan\`
2. Buka browser: `http://localhost/perpustakaan/24-inheritance.php`
3. Perhatikan: `Anggota`, `Petugas`, `Admin` sama-sama punya `id,nama,email`, tapi beda role, data spesifik & method.

## Tracing Code (Step-by-Step)

Kita telusuri alur saat membuat object `$anggota` dan pemanggilan method.

**Langkah 1 — Definisi `abstract class User`**

`User` bersifat abstrak → **tidak boleh** `new User(...)`. Di dalamnya ada `protected` property (`id,nama,email,aktif`), method umum (`getId/getNama/getEmail/isAktif/infoUmum`) dan `abstract public function getRole(): string;` yang **wajib** diimplementasikan oleh semua child.

**Langkah 2 — `class Anggota extends User`**

`Anggota` mewarisi semua property/method yang **bukan private** dari `User`. `Anggota` menambahkan property `private string $nomorAnggota`. Juga meng-override `getRole()` dan menambahkan `infoLengkap()` serta `getNomorAnggota()`.

**Langkah 3 — `$anggota = new Anggota(1, 'Andi Pratama', 'andi@perpustakaan.test', true, 'AGT-0001');`**

Eksekusi constructor `Anggota`:
- Menerima argumen `(1, 'Andi Pratama', 'andi@perpustakaan.test', true, 'AGT-0001')`
- Baris pertama: `parent::__construct($id, $nama, $email, $aktif);` → memanggil constructor `User`
  - Di constructor `User`, nilai di-assign ke `protected $id=1`, `protected $nama='Andi Pratama'`, `protected $email='andi@perpustakaan.test'`, `protected $aktif=true`
- Kembali ke `Anggota`, assign `$this->nomorAnggota = 'AGT-0001'`

**Kondisi saat ini:** Object `$anggota` memiliki gabungan property dari `User` (via inheritance) + property miliknya sendiri.

**Langkah 4 — `$petugas = new Petugas(2, 'Sari Dewi', 'sari@perpustakaan.test', true, 'Siang');`**

Sama seperti langkah 3. Pertama panggil `parent::__construct` → isi property parent. Lalu isi `$shift='Siang'`. Method `getRole()` return `'Petugas'`.

**Langkah 5 — `$admin = new Admin(3, 'Rizky Maulana', 'rizky@perpustakaan.test', true, 'IT');`**

Constructor `Admin` panggil parent, lalu set `$departemen='IT'`. Punya method tambahan `resetPassword()`.

**Langkah 6 — `echo $anggota->infoLengkap() . PHP_EOL;`**

Method `infoLengkap()` milik `Anggota` dijalankan:
- `$this->infoUmum()` → diwarisi dari `User`. Method ini mengembalikan `"#1 - Andi Pratama (andi@perpustakaan.test)"`
- `$this->isAktif()` → diwarisi dari `User`, return `true` → `'Aktif'`
- `$this->getRole()` → **di-override** oleh `Anggota`, return `'Anggota'`
- Gabung dengan `$this->nomorAnggota` → `'AGT-0001'`

Hasil akhir: `"#1 - Andi Pratama (andi@perpustakaan.test) | Role: Anggota | No: AGT-0001 | Status: Aktif"`

**Langkah 7 — `echo $petugas->infoLengkap() . PHP_EOL;`**

Mirip, tapi `getRole()` return `'Petugas'`, tampil `Shift: Siang`.

**Langkah 8 — `echo $admin->infoLengkap() . PHP_EOL;`**

`getRole()` return `'Admin'`, tampil `Dept: IT`.

**Langkah 9 — `echo $admin->resetPassword($anggota->getNama()) . PHP_EOL;`**

Admin memanggil method spesifiknya. `$anggota->getNama()` dipanggil (method diwarisi dari `User`) mengembalikan `'Andi Pratama'`. Hasil: `"Admin Rizky Maulana telah mereset password untuk Andi Pratama."`

**Output akhir:**

```text
#1 - Andi Pratama (andi@perpustakaan.test) | Role: Anggota | No: AGT-0001 | Status: Aktif
#2 - Sari Dewi (sari@perpustakaan.test) | Role: Petugas | Shift: Siang | Status: Aktif
#3 - Rizky Maulana (rizky@perpustakaan.test) | Role: Admin | Dept: IT | Status: Aktif

Admin Rizky Maulana telah mereset password untuk Andi Pratama.
```

## Analogi

Bayangkan sistem kepegawaian di **perpustakaan**.

- **`abstract class User`** = **Kartu Identitas Umum Perpustakaan**. Semua orang yang terdaftar (anggota/petugas/admin) **minimal** punya ID, Nama, Email. Kartu ini bersifat **kerangka** — kita tidak mencetak "Kartu User" kosong begitu saja, kita mencetak kartu per **peran**.
- **`extends`** = "berdasarkan Kartu Identitas Umum ini, kita buat varian khusus".
- **`Anggota`** = **Kartu Anggota**. Selain data umum, ada **Nomor Anggota** dan hak akses sebagai anggota.
- **`Petugas`** = **Kartu Petugas**. Ada info **Shift jaga** (Pagi/Siang/Malam).
- **`Admin`** = **Kartu Admin**. Ada **Departemen** dan wewenang tambahan (mis. reset password).
- **`protected`** = data umum (nama/email) **bisa dilihat & dipakai** oleh petugas pencetak kartu turunan, tapi **tidak dipamerkan sembarangan** di luar sistem.
- **`abstract method getRole()`** = aturan: **setiap jenis kartu wajib mencantumkan "Peran"**-nya dengan jelas.
- **`parent::__construct()`** = saat mencetak kartu spesifik, kita **pertama-tama mengisi data identitas umum** dari template induk, baru menambahkan data khusus peran.
- **`override getRole()`** = tiap peran **menuliskan label rolenya sendiri** (Anggota/Petugas/Admin).

Jadi: **bukan meng-copy-paste**, tapi **mewarisi kerangka + menambahkan ciri khas**.

## Dipakai untuk Apa

- **Sistem Role & Permission** (Anggota/Petugas/Admin).
- **Manajemen User** di aplikasi perpustakaan.
- **Model Hierarki** (Produk → Buku/Fiksi/Non-Fiksi) jika dikembangkan.
- **Codebase yang rapi & scalable**.
- **Mengurangi redudansi** saat banyak class punya field sama.
- **Persiapan ke Interface/Polymorphism**.
- **Struktur yang mirip pola di framework** (User Model).

## Kesalahan Umum yang Sering Terjadi

- **Mewarisi terlalu dalam (deep inheritance)** → hierarki jadi rumit. Lebih baik favor **composition** kalau hubungan bukan "is-a".
- **Memaksa inheritance padahal hubungan "has-a"** (Contoh: `Buku extends Perpustakaan` salah. Yang benar `Perpustakaan` punya koleksi `Buku`).
- **Lupa `parent::__construct()`** di child constructor → property parent tidak terisi.
- **Menggunakan `public` untuk data sensitif** padahal cukup `protected/private` + getter.
- **Membuat abstract class tanpa alasan** → bikin berlapis tanpa manfaat.
- **Override method tapi menghilangkan logika penting parent** (kalau perlu, tetap panggil `parent::...`).
- **Akses `private` parent langsung dari child** → tidak bisa. Gunakan `protected`.
- **Bertumpuk override** tanpa dokumentasi.
- **Instansiasi abstract class** → Fatal Error.

## Hubungan dengan Materi Sebelumnya

- **Materi 23 (Class & Object)**: Inheritance **memperluas** konsep class. Kita tidak mulai dari nol, tapi mewarisi yang sudah ada.
- **Materi 15–17 (Fungsi & Scope)**: Konsep scope + visibility melengkapi inheritance.
- **Hubungan ke Materi Selanjutnya (25):** Kadang inheritance kurang fleksibel. Kita akan belajar **Interface & Trait** untuk solusi reuse lintas hierarki.
- **Hubungan ke Materi 26–27 (PDO):** Bisa dipakai saat bikin `UserRepository extends BaseRepository` atau pola serupa.

## Soal Latihan & Jawaban

### Soal

Buat hierarki sederhana untuk sistem perpustakaan:

1. Buat `abstract class Person` dengan property `protected int $id, protected string $nama, protected string $hp`. Tambah `abstract public function getTipe(): string;` dan `public function info(): string` yang mengembalikan `"ID:$id | Nama:$nama | HP:$hp"`.
2. Buat class `Peminjam` extends `Person` dengan tambahan `private string $kelas`. Implement `getTipe()` return `"Peminjam"`. Tambah `infoLengkap()` gabungan `info()` + tipe + kelas.
3. Buat class `Pengunjung` extends `Person` dengan tambahan `private string $tujuan`. Implement `getTipe()` return `"Pengunjung"`. Tambah `infoLengkap()`.
4. Buat object keduanya dan tampilkan `infoLengkap()`.

### Jawaban

```php
<?php
declare(strict_types=1);

abstract class Person
{
    public function __construct(
        protected int $id,
        protected string $nama,
        protected string $hp
    ) {
    }

    abstract public function getTipe(): string;

    public function info(): string
    {
        return "ID:{$this->id} | Nama:{$this->nama} | HP:{$this->hp}";
    }
}

class Peminjam extends Person
{
    public function __construct(
        int $id,
        string $nama,
        string $hp,
        private string $kelas
    ) {
        parent::__construct($id, $nama, $hp);
        $this->kelas = $kelas;
    }

    public function getTipe(): string
    {
        return 'Peminjam';
    }

    public function infoLengkap(): string
    {
        return $this->info() . " | Tipe:{$this->getTipe()} | Kelas:{$this->kelas}";
    }
}

class Pengunjung extends Person
{
    public function __construct(
        int $id,
        string $nama,
        string $hp,
        private string $tujuan
    ) {
        parent::__construct($id, $nama, $hp);
        $this->tujuan = $tujuan;
    }

    public function getTipe(): string
    {
        return 'Pengunjung';
    }

    public function infoLengkap(): string
    {
        return $this->info() . " | Tipe:{$this->getTipe()} | Tujuan:{$this->tujuan}";
    }
}

$peminjam  = new Peminjam(1, 'Dina', '081234567890', 'XI-RPL');
$pengunjung= new Pengunjung(2, 'Aldi', '081298765432', 'Membaca');

echo $peminjam->infoLengkap() . PHP_EOL;
echo $pengunjung->infoLengkap() . PHP_EOL;
```
