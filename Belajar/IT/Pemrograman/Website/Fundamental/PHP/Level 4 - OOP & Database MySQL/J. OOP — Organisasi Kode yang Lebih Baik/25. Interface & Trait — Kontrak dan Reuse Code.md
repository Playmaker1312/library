# Interface & Trait — Kontrak dan Reuse Code

## Penjelasan

Inheritance sangat berguna, tapi punya batasan: **satu class hanya bisa `extends` satu class induk** (PHP tidak mendukung multiple inheritance untuk class). Untuk mengatasi hal itu, PHP menyediakan **Interface** dan **Trait**.

### 1. Interface

- **Interface** = **kontrak (contract)**. Berisi deklarasi method saja (tanpa isi/body), kecuali constant (interface constant).
- Class yang `implements` interface **wajib** mengimplementasikan **semua method** yang dideklarasikan.
- Satu class bisa `implements` **banyak interface** sekaligus.
- Interface **tidak punya property** dan **tidak punya implementasi method**.
- Cocok untuk mendefinisikan **kemampuan/perilaku** ("bisa apa?").

### 2. Trait

- **Trait** = blok kode yang bisa **dipakai ulang (reusable)** di banyak class tanpa pewarisan.
- Dipakai dengan kata kunci `use` di dalam class.
- Bisa punya **property** dan **method dengan implementasi**.
- Satu class bisa `use` **banyak trait**.
- Cocok untuk memecah logika umum yang bisa dipakai lintas hierarki class.

**Perbedaan utama ringkas:**

| Aspek | Interface | Trait |
|---|---|---|
| Tujuan | Mendefinisikan kontrak | Membagikan implementasi kode |
| Method Body | Tidak ada (hanya deklarasi) | Bisa ada (punya isi) |
| Property | Tidak boleh | Boleh |
| Penggunaan | `implements` | `use` |
| Jumlah | Bisa banyak interface | Bisa banyak trait |

Dalam konteks **perpustakaan**: `Searchable` (bisa dicari), `Exportable` (bisa diekspor), `Logger`/`Timestampable` (punya log/waktu).

## Fungsi

- **Interface**: Memaksa class untuk patuh pada kontrak tertentu (membantu konsistensi API).
- **Trait**: Mengurangi duplikasi lintas class berbeda (solusi multiple inheritance terstruktur).
- **Pemisahan tanggung jawab** (separating concerns).
- **Lebih fleksibel** dibanding inheritance saja.
- **Mudah diuji & dipelihara**.
- **Mendorong prinsip "program to interface"** (loosely coupled).

## Cara Pengimplementasian / Code

```php
<?php
// File: 25-interface-trait.php
declare(strict_types=1);

error_reporting(E_ALL);
ini_set('display_errors', 1);

// 1. Interface - Kontrak perilaku
interface Searchable
{
    public function cari(string $keyword): array;
}

interface Exportable
{
    public function exportFormat(): string;
}

// 2. Trait - Reusable logic
trait HasTimestamps
{
    protected ?string $createdAt = null;
    protected ?string $updatedAt = null;

    public function setCreatedAt(string $datetime): void
    {
        $this->createdAt = $datetime;
    }

    public function getCreatedAt(): ?string
    {
        return $this->createdAt;
    }

    public function setUpdatedAt(string $datetime): void
    {
        $this->updatedAt = $datetime;
    }

    public function getUpdatedAt(): ?string
    {
        return $this->updatedAt;
    }

    public function touch(): void
    {
        $this->updatedAt = date('Y-m-d H:i:s');
        if ($this->createdAt === null) {
            $this->createdAt = $this->updatedAt;
        }
    }
}

trait Loggable
{
    public function log(string $message): string
    {
        $timestamp = date('Y-m-d H:i:s');
        return "[LOG] [$timestamp] $message";
    }
}

// 3. Class Buku - implements beberapa interface + use trait
class Buku implements Searchable, Exportable
{
    use HasTimestamps;
    use Loggable;

    public function __construct(
        public int $id,
        public string $judul,
        public string $pengarang,
        public string $kategori = 'Umum'
    ) {
        // Set timestamps saat dibuat
        $this->touch();
    }

    // Implementasi method dari interface Searchable
    public function cari(string $keyword): array
    {
        $keywordLower = strtolower($keyword);
        $judulLower   = strtolower($this->judul);
        $pengarangLower = strtolower($this->pengarang);

        if (
            str_contains($judulLower, $keywordLower) ||
            str_contains($pengarangLower, $keywordLower)
        ) {
            return [
                'id'        => $this->id,
                'judul'     => $this->judul,
                'pengarang' => $this->pengarang,
                'kategori'  => $this->kategori,
                'created_at'=> $this->getCreatedAt(),
                'updated_at'=> $this->getUpdatedAt(),
            ];
        }

        return [];
    }

    // Implementasi method dari interface Exportable
    public function exportFormat(): string
    {
        return json_encode([
            'id'        => $this->id,
            'judul'     => $this->judul,
            'pengarang' => $this->pengarang,
            'kategori'  => $this->kategori,
        ], JSON_UNESCAPED_UNICODE | JSON_PRETTY_PRINT);
    }

    public function info(): string
    {
        return "#{$this->id} - {$this->judul} ({$this->pengarang}) | Kategori: {$this->kategori}";
    }
}

// 4. Class Katalog - implements Searchable
class Katalog implements Searchable
{
    use Loggable;

    /** @var Buku[] */
    private array $koleksiBuku = [];

    public function tambahBuku(Buku $buku): void
    {
        $this->koleksiBuku[] = $buku;
        echo $this->log("Buku '{$buku->judul}' ditambahkan ke katalog.") . PHP_EOL;
    }

    // Implementasi Searchable
    public function cari(string $keyword): array
    {
        $hasil = [];

        foreach ($this->koleksiBuku as $buku) {
            $temu = $buku->cari($keyword);
            if (!empty($temu)) {
                $hasil[] = $temu;
            }
        }

        return $hasil;
    }

    public function jumlahBuku(): int
    {
        return count($this->koleksiBuku);
    }
}

// Instansiasi
$katalog = new Katalog();

$buku1 = new Buku(101, 'Clean Code', 'Robert C. Martin', 'Pemrograman');
$buku2 = new Buku(102, 'Atomic Habits', 'James Clear', 'Pengembangan Diri');
$buku3 = new Buku(103, 'Refactoring', 'Martin Fowler', 'Pemrograman');

$katalog->tambahBuku($buku1);
$katalog->tambahBuku($buku2);
$katalog->tambahBuku($buku3);

echo PHP_EOL;

// Pencarian dengan interface Searchable
$keyword = 'code';
$hasilCari = $katalog->cari($keyword);

echo "Hasil pencarian untuk '{$keyword}':" . PHP_EOL;
if (empty($hasilCari)) {
    echo "- Tidak ditemukan." . PHP_EOL;
} else {
    foreach ($hasilCari as $h) {
        echo "- #{$h['id']} - {$h['judul']} ({$h['pengarang']})" . PHP_EOL;
    }
}

echo PHP_EOL;

// Exportable
echo "=== EXPORT BUKU 1 (JSON) ===" . PHP_EOL;
echo $buku1->exportFormat() . PHP_EOL;

echo PHP_EOL;
echo $buku1->log("Buku Clean Code diakses oleh anggota.") . PHP_EOL;
```

**Cara menjalankan/menguji:**

1. Simpan file sebagai `25-interface-trait.php` di `C:\xampp\htdocs\perpustakaan\`
2. Buka browser: `http://localhost/perpustakaan/25-interface-trait.php`

## Tracing Code (Step-by-Step)

Kita telusuri eksekusi secara baris demi baris.

**Langkah 1 — Deklarasi `interface Searchable`**

Interface mendeklarasikan method `cari(string $keyword): array;`. Tidak ada body.

**Langkah 2 — Deklarasi `interface Exportable`**

Mendeklarasikan `exportFormat(): string;`.

**Langkah 3 — Trait `HasTimestamps`**

Memiliki property `protected ?string $createdAt = null`, `protected ?string $updatedAt = null` dan method `setCreatedAt`, `getCreatedAt`, `setUpdatedAt`, `getUpdatedAt`, `touch()`. Method `touch()`:
- Set `$this->updatedAt = date('Y-m-d H:i:s')`
- Jika `createdAt === null`, set juga `createdAt = updatedAt` (auto-set saat pertama kali).

**Langkah 4 — Trait `Loggable`**

Method `log(string $message): string` mengembalikan string `[LOG] [Y-m-d H:i:s] $message`.

**Langkah 5 — `class Buku implements Searchable, Exportable`**

Class ini **wajib** mengimplementasikan kedua method dari interface (`cari()` dan `exportFormat()`).
Class ini juga `use HasTimestamps, Loggable` → semua property/method dari kedua trait tersedia di dalam `Buku` (seolah disalin).

**Langkah 6 — Constructor `Buku`**

Menerima parameter, lalu memanggil `$this->touch();` (dari trait `HasTimestamps`). Saat pertama kali dibuat, `createdAt` dan `updatedAt` akan terisi timestamp sekarang.

Contoh `$buku1` dibuat:
- `id=101, judul='Clean Code', pengarang='Robert C. Martin', kategori='Pemrograman'`
- `$this->touch()` dijalankan → `updatedAt = '2025-10-17 HH:MM:SS'`, `createdAt` masih null → diset sama.

**Langkah 7 — Method `cari()` di Buku (implements Searchable)**

Menerima `$keyword`. Mengubah jadi lowercase, cek apakah `judul` **atau** `pengarang` mengandung keyword (`str_contains`). Jika ditemukan → return array detail buku termasuk timestamps (via getter trait). Jika tidak → return `[]`.

**Langkah 8 — Method `exportFormat()` di Buku (implements Exportable)**

Return JSON terformat berisi `id,judul,pengarang,kategori` (tanpa timestamp).

**Langkah 9 — `class Katalog implements Searchable`**

Hanya `implements Searchable` (wajib implement `cari()`). `use Loggable` saja. Punya private array `$koleksiBuku`.

**Langkah 10 — `$katalog->tambahBuku($buku1)`**

Push `$buku1` ke array koleksi. Lalu `echo $this->log("Buku 'Clean Code' ditambahkan ke katalog.")` (dari trait Loggable) → mencetak `[LOG] [...] Buku 'Clean Code' ditambahkan ke katalog.`

Dilakukan juga untuk buku2, buku3.

**Langkah 11 — `$katalog->cari('code')`**

Loop tiap buku di koleksi:
- `$buku1->cari('code')` → `'clean code'` mengandung `'code'` (lowercase) → return array detail.
- `$buku2` → `'atomic habits'` tidak mengandung `'code'` → `[]`.
- `$buku3` → `'refactoring'` tidak → `[]`.

Gabung hasil → array berisi 1 elemen.

**Langkah 12 — Tampilkan hasil cari**

Loop hasil → tampil `#101 - Clean Code (Robert C. Martin)`.

**Langkah 13 — `echo $buku1->exportFormat()`**

Menampilkan JSON terformat dari `Buku`.

**Langkah 14 — `echo $buku1->log(...)`**

Memanggil method dari trait Loggable milik Buku.

**Output akhir:**

```text
[LOG] [2025-10-17 10:00:00] Buku 'Clean Code' ditambahkan ke katalog.
[LOG] [2025-10-17 10:00:00] Buku 'Atomic Habits' ditambahkan ke katalog.
[LOG] [2025-10-17 10:00:00] Buku 'Refactoring' ditambahkan ke katalog.

Hasil pencarian untuk 'code':
- #101 - Clean Code (Robert C. Martin)

=== EXPORT BUKU 1 (JSON) ===
{
    "id": 101,
    "judul": "Clean Code",
    "pengarang": "Robert C. Martin",
    "kategori": "Pemrograman"
}

[LOG] [2025-10-17 10:00:00] Buku Clean Code diakses oleh anggota.
```

## Analogi

Bayangkan **manajemen koleksi perpustakaan**:

- **Interface `Searchable`** = **SOP (Standar Operasional Prosedur) Pencarian** yang harus dipatuhi semua bagian. "Barang apa pun yang bisa dicari, WAJIB punya metode `cari(keyword)`". Baik itu `Katalog` maupun `Buku`, keduanya bisa "di-searchable" dengan cara masing-masing.
- **Interface `Exportable`** = **Kontrak Ekspor Data**. Buku bisa diekspor ke format tertentu (JSON), katalog mungkin beda.
- **Trait `HasTimestamps`** = **Stamp waktu pelayanan**. Ini adalah "peralatan terpisah" (stempel tanggal/jam) yang bisa dipinjam oleh `Buku` (atau entitas lain) tanpa harus menjadi bagian dari hierarki pewarisan. Seperti alat stempel yang bisa dipakai banyak jenis dokumen.
- **Trait `Loggable`** = **Buku Catatan Aktivitas (Log)**. Bisa dipakai `Buku` maupun `Katalog` untuk mencatat kejadian — dipinjam terpisah, bukan diwarisi.
- **`implements Searchable`** = Petugas menandatangani kontrak: "Saya siap melayani pencarian sesuai SOP".
- **`use HasTimestamps`** = Petugas meminjam alat stempel waktu untuk mencatat kapan buku dicatat/diperbarui.
- **`use Loggable`** = Meminjam buku log untuk mencatat aktivitas.

Perbedaannya jelas: **Interface = "Harus bisa melakukan..." (kontrak perilaku). Trait = "Punya kemampuan siap pakai..." (reusable implementasi)**.

## Dipakai untuk Apa

- **Interface**: Mendefinisikan kontrak untuk service/repository (`BukuRepositoryInterface`, `Searchable`, `Exportable`).
- **Trait**: Shared logic (`Timestampable`, `SoftDeletes`, `Sluggable`, `Loggable`) lintas class.
- **Menerapkan "Program to Interfaces"** → mudah ganti implementasi (mock untuk testing).
- **Repository Pattern + DI** (bersiap ke materi 34).
- **Code DRY** tanpa memaksakan inheritance yang salah arah.
- **API Contract** yang konsisten antar class.

## Kesalahan Umum yang Sering Terjadi

- **Mengisi body di interface** → Error. Interface hanya deklarasi (kecuali constant PHP >=8.1 interface can have constant/final, tapi method tanpa body).
- **Lupa implement semua method interface** → Fatal Error: Class ... must implement all abstract methods.
- **Trait conflict**: jika 2 trait punya method nama sama, harus diselesaikan `use A, B { A::method insteadof B; B::method as methodB; }`
- **Overuse trait** → bisa menyulitkan trace asal method (sebaiknya digunakan untuk logic umum terukur).
- **Mencampur inheritance & trait tidak tepat** — trait untuk "has-a behavior", bukan ganti inheritance "is-a".
- **Property trait bentrok nama** dengan property class.
- **Menganggap interface bisa simpan state** (tidak bisa, hanya constant).
- **Paksa interface untuk hal sepele** → tambahkan hanya jika benar-benar dibutuhkan kontrak.

## Soal Latihan & Jawaban

### Soal

1. Buat `interface Printable` dengan method `print(): string`.
2. Buat `trait HasAuthor` dengan property `protected string $author` dan method `getAuthor(): string`, `setAuthor(string $author): void`.
3. Buat class `Majalah` yang `implements Printable` dan `use HasAuthor`. Property `judul (string), halaman (int)`. Constructor terima judul, halaman, author. Implement `print()` return `"Majalah: [judul] - Hal: [hal] - Oleh: [author]"`.
4. Buat object dan tampilkan hasil `print()`.

### Jawaban

```php
<?php
declare(strict_types=1);

interface Printable
{
    public function print(): string;
}

trait HasAuthor
{
    protected string $author;

    public function getAuthor(): string
    {
        return $this->author;
    }

    public function setAuthor(string $author): void
    {
        $this->author = $author;
    }
}

class Majalah implements Printable
{
    use HasAuthor;

    public function __construct(
        public string $judul,
        public int $halaman,
        string $author
    ) {
        $this->setAuthor($author);
    }

    public function print(): string
    {
        return "Majalah: {$this->judul} - Hal: {$this->halaman} - Oleh: {$this->getAuthor()}";
    }
}

$majalah = new Majalah('Baca Perpustakaan', 24, 'Tim Redaksi');
echo $majalah->print() . PHP_EOL;
```
