# Variabel — Wadah Data dengan Tanda Dollar

## Penjelasan

**Variabel** adalah wadah untuk menyimpan data sementara di memori komputer. Ketika kita ingin memakai suatu nilai berulang kali, kita cukup simpan ke variabel, lalu panggil namanya.

Di PHP, semua variabel **wajib diawali dengan tanda dollar (`$`)**. Contoh: `$judulBuku`, `$hargaBuku`.

Beberapa hal penting tentang variabel di PHP:

- **Dimulai dengan `$`** — ciri khas PHP yang membedakannya dari bahasa lain.
- **Case-sensitive** — `$buku` berbeda dengan `$Buku`.
- **Bisa langsung diisi** — tidak perlu deklarasi tipe data seperti di Java/C#. PHP akan menentukan tipe datanya otomatis saat kita memberi nilai.
- **Bersifat dinamis (dynamically typed)** — tipe data bisa "berubah" tergantung nilai yang kita masukkan.
- **Nama variabel boleh berisi huruf, angka, underscore (`_`)** — tapi **tidak boleh** diawali dengan angka.
- **Tidak boleh pakai spasi dan tanda hubung (`-`)**.

Tipe data dasar yang sering dipakai: `string` (teks), `integer` (bilangan bulat), `float` (desimal), `boolean` (benar/salah), `NULL` (kosong).

## Fungsi

Fungsi variabel adalah **menyimpan, memberi nama, dan memanggil kembali data** agar kode kita lebih mudah dipahami dan dipakai berulang.

Tanpa variabel, kita terpaksa menulis nilai berulang kali. Dengan variabel:

- Kode jadi **lebih rapi** — cukup panggil `$judulBuku` daripada menulis `"Clean Code"` berkali-kali.
- Mudah diubah — ubah nilainya sekali, efeknya ke seluruh tempat pemanggilan.
- Relevan dengan konteks **perpustakaan** — kita bisa menyimpan data buku: judul, pengarang, harga, stok, dll.
- Menjadi pondasi untuk belajar array, function, form, database, dan OOP.

## Cara Pengimplementasian / Code

Kita akan membuat contoh dengan data buku perpustakaan.

```php
<?php
// File: 6-variabel.php

// Aktifkan error reporting untuk development
error_reporting(E_ALL);
ini_set('display_errors', 1);

// Deklarasi variabel untuk data buku perpustakaan
$judulBuku  = "Clean Code";        // Tipe: string
$pengarang  = "Robert C. Martin";  // Tipe: string
$tahunTerbit= 2008;                // Tipe: integer
$hargaBuku  = 150000;              // Tipe: integer
$rating     = 4.8;                 // Tipe: float
$stokTersedia = true;             // Tipe: boolean
$isbn       = "9780132350884";     // Tipe: string
$sinopsis   = null;                // Tipe: NULL (belum diisi)

// Menampilkan data dengan echo
echo "<h1>Data Buku Perpustakaan</h1>";
echo "<p><strong>Judul:</strong> " . $judulBuku . "</p>";
echo "<p><strong>Pengarang:</strong> " . $pengarang . "</p>";
echo "<p><strong>Tahun Terbit:</strong> " . $tahunTerbit . "</p>";
echo "<p><strong>Harga:</strong> Rp " . number_format($hargaBuku, 0, ',', '.') . "</p>";
echo "<p><strong>Rating:</strong> " . $rating . "</p>";
echo "<p><strong>Stok Tersedia:</strong> " . ($stokTersedia ? "Ya" : "Tidak") . "</p>";
echo "<p><strong>ISBN:</strong> " . $isbn . "</p>";
echo "<p><strong>Sinopsis:</strong> " . ($sinopsis ?? "Belum ada sinopsis") . "</p>";

// Melihat tipe data sebenarnya dengan var_dump
echo "<hr>";
echo "<h2>Debug: Melihat Tipe Data dengan var_dump</h2>";
var_dump($judulBuku);
echo "<br>";
var_dump($hargaBuku);
echo "<br>";
var_dump($rating);
echo "<br>";
var_dump($stokTersedia);
echo "<br>";
var_dump($sinopsis);
?>
```

**Cara menjalankan/menguji:**

1. Simpan file sebagai `6-variabel.php` di folder `perpustakaan/`
2. Akses lewat browser:
   - Laragon: `http://perpustakaan.test/6-variabel.php`
   - XAMPP: `http://localhost/perpustakaan/6-variabel.php`

Perhatikan perbedaan: `echo` menampilkan **nilai**, sedangkan `var_dump` menampilkan **tipe + nilai**.

## Tracing Code (Step-by-Step)

Kita telusuri kode di atas baris demi baris untuk melihat apa yang terjadi.

**Langkah 1 — Baris `$judulBuku = "Clean Code";`**

PHP membuat wadah bernama `$judulBuku` di memori, lalu mengisinya dengan teks `"Clean Code"`. Karena nilainya berupa teks, PHP menetapkan **tipe data string** untuk variabel ini.

> Sekarang `$judulBuku` berisi: `"Clean Code"` (tipe: string)

**Langkah 2 — Baris `$pengarang = "Robert C. Martin";`**

PHP membuat `$pengarang` dan mengisi `"Robert C. Martin"`. Tipe: **string**.

> `$pengarang` berisi: `"Robert C. Martin"`

**Langkah 3 — Baris `$tahunTerbit = 2008;`**

PHP mengisi `$tahunTerbit` dengan angka `2008` tanpa tanda kutip. PHP mengenalinya sebagai **integer** (bilangan bulat).

> `$tahunTerbit` berisi: `2008` (tipe: integer)

**Langkah 4 — Baris `$hargaBuku = 150000;`**

Diberi nilai angka bulat `150000`. Tipe: **integer**.

> `$hargaBuku` berisi: `150000`

**Langkah 5 — Baris `$rating = 4.8;`**

Diberi nilai `4.8` yang mengandung titik desimal. PHP menetapkan tipe **float** (bilangan pecahan).

> `$rating` berisi: `4.8` (tipe: float)

**Langkah 6 — Baris `$stokTersedia = true;`**

Diberi nilai `true` (benar). PHP menetapkan tipe **boolean**.

> `$stokTersedia` berisi: `true` (tipe: boolean)

**Langkah 7 — Baris `$isbn = "9780132350884";`**

Diberi nilai berupa deretan angka **di dalam tanda kutip**. Karena ada tanda kutip, PHP memperlakukannya sebagai **string**, bukan integer.

> `$isbn` berisi: `"9780132350884"` (tipe: string)

**Langkah 8 — Baris `$sinopsis = null;`**

Diberi nilai `null` yang berarti "belum ada nilai/kosong". Tipe: **NULL**.

> `$sinopsis` berisi: `NULL`

**Langkah 9 — PHP mulai menampilkan HTML dengan echo**

Saat mencapai baris `echo "<h1>Data Buku Perpustakaan</h1>";`, PHP mencetak tag HTML ke output response.

**Langkah 10 — Menggabungkan string dan variabel**

Baris `echo "<p><strong>Judul:</strong> " . $judulBuku . "</p>";`

PHP mengambil nilai `$judulBuku` (`"Clean Code"`), menggabungkannya dengan teks di sekitarnya menggunakan tanda titik (`.`), lalu mencetak hasilnya.

Hasil akhir: `<p><strong>Judul:</strong> Clean Code</p>`

Hal yang sama terjadi untuk pengarang, tahun, harga, rating, stok, ISBN, sinopsis.

**Langkah 11 — `var_dump` menampilkan tipe & nilai**

Saat `var_dump($judulBuku);` dijalankan, PHP menampilkan informasi detail:

- `string(9) "Clean Code"` → artinya **tipe string**, panjang **9 karakter**, nilainya `"Clean Code"`

Begitu juga untuk yang lain:
- `int(150000)` → integer dengan nilai 150000
- `float(4.8)` → float dengan nilai 4.8
- `bool(true)` → boolean bernilai true
- `NULL` → kosong

**Output akhir (ringkas):**

Halaman menampilkan tabel data buku, lalu di bawahnya deretan hasil `var_dump` yang memperlihatkan tipe data asli tiap variabel.

## Analogi

Bayangkan **rak buku di perpustakaan**.

Setiap rak punya **label nama** yang jelas, misalnya: `Rak Fiksi A`, `Rak Sejarah B`. Di dalam rak itu, kita menyimpan **buku tertentu** (isinya).

Di PHP, **variabel** itu ibarat **label pada rak**. Nama variabel seperti `$judulBuku` adalah **label rak-nya**. Nilai yang kita simpan (`"Clean Code"`) adalah **buku yang ada di dalam rak tersebut**.

Kapan kita butuh bukunya? Cukup kita lihat label rak: "ambil isi rak `$judulBuku`", maka kita dapat `"Clean Code"`.

Bedanya dengan rak fisik: di PHP, **satu rak (`variabel`) bisa kita ganti isinya kapan saja**. Kita bisa dulu isi dengan `"Clean Code"`, lalu nanti ganti jadi `"The Pragmatic Programmer"`. Label rak-nya tetap sama (`$judulBuku`), yang berubah cuma isinya.

Konteks perpustakaan kita jadi makin nyata: `$stokBuku`, `$hargaBuku`, `$namaAnggota` — semua adalah "label rak" untuk menyimpan data penting sistem perpustakaan.

## Dipakai untuk Apa

- **Menyimpan data buku** — judul, pengarang, ISBN, tahun terbit, harga, stok.
- **Menyimpan data anggota** — nama, NIM/ID anggota, email, status keanggotaan.
- **Menyimpan hasil perhitungan** — menghitung denda keterlambatan, total harga, sisa stok.
- **Menyimpan input form** — nilai yang dikirim user dari form tambah buku/peminjaman.
- **Menyimpan kondisi** — status login, hak akses (admin/anggota), mode tampilan.
- **Menyimpan tanggal/waktu** — tanggal pinjam, tanggal kembali, batas pengembalian.
- **Debugging** — pakai `var_dump`/`print_r` untuk melihat isi variabel saat ada masalah.

## Kesalahan Umum yang Sering Terjadi

- **Lupa tanda `$`** — Menulis `judulBuku = ...` tanpa `$` akan menyebabkan `Parse error`.
- **Diawali angka** — `$1buku` tidak valid. Gunakan `$buku1` atau `$buku_pertama`.
- **Pakai tanda hubung** — `$judul-buku` salah. Gunakan **underscore** `$judul_buku` atau **camelCase** `$judulBuku`.
- **Case-sensitive keliru** — `$stok` dan `$Stok` dianggap **dua variabel berbeda**.
- **Pakai nama tidak deskriptif** — `$a`, `$x`, `$data` kurang jelas. Lebih baik `$judulBuku`, `$stokBuku`.
- **Kebingungan string vs angka** — Menulis `$isbn = 9780132350884` tanpa kutip bisa aman di integer, tapi ISBN sebaiknya tetap **string** karena bisa diawali 0 & tidak dipakai untuk kalkulasi.
- **Langsung echo boolean** — `echo true` akan menampilkan `1`, `echo false` akan menampilkan **kosong**. Makanya kita pakai ternary seperti `($stokTersedia ? "Ya" : "Tidak")`.
- **Menganggap NULL sama dengan string kosong** — `null` beda dengan `""`. Perlu diperhatikan saat validasi form.

## Hubungan dengan Materi Sebelumnya

**Materi sebelumnya (Poin 5):** `Error Reporting — Baca Error, Jangan Takut`. Kita belajar membaca error, dan sekarang kita mulai menulis variabel. Kalau lupa `$`, error reporting akan langsung memberitahu `Parse error`.

**Hubungan ke materi ini:** Error reporting membantu kita cepat sadar saat ada kesalahan penulisan variabel.

**Materi selanjutnya (Poin 7):** `Type Juggling — PHP yang Suka Mengubah Tipe`. Setelah paham variabel & tipe data, kita akan melihat keunikan PHP: bisa mengubah tipe data secara otomatis saat operasi hitung/perbandingan. Ini penting biar kita tidak kaget hasilnya.

Buat halaman data **anggota perpustakaan** dengan menggunakan variabel. Ikuti ketentuan berikut:
