# Konstanta — Nilai yang Tidak Berubah

## Penjelasan

**Konstanta** adalah wadah penyimpan nilai yang **tidak bisa diubah** setelah dideklarasikan. Berbeda dengan variabel (`$nama`) yang bisa kita ubah nilainya kapan saja, konstanta akan **tetap bernilai sama** sepanjang program berjalan.

Konstanta biasanya dipakai untuk nilai-nilai yang bersifat **tetap (konfigurasi)**, seperti nama aplikasi, versi sistem, batas maksimal pinjam buku, tarif denda per hari, atau nilai tetap matematika.

Di PHP, ada **dua cara** untuk mendeklarasikan konstanta:

1. **`define('NAMA', nilai)`** — cara lama, bisa dipakai di mana saja (termasuk dalam fungsi).
2. **`const NAMA = nilai`** — cara modern (PHP 5.3+), lebih umum dipakai di class atau scope global.

Perbedaan penulisan: konstanta **tidak diawali dengan tanda `$`**, dan penamaannya biasanya ditulis dengan **HURUF BESAR** (ALL CAPS) sebagai konvensi.

PHP juga menyediakan banyak **built-in constants** seperti `PHP_VERSION`, `PHP_INT_MAX`, `DIRECTORY_SEPARATOR`, dll.

## Fungsi

- **Menyimpan nilai tetap** — cocok untuk konfigurasi sistem perpustakaan (batas pinjam, denda, nama perpustakaan).
- **Mencegah perubahan tidak sengaja** — kalau ada yang mencoba mengubahnya, PHP akan error.
- **Meningkatkan keterbacaan kode** — `MAKS_PINJAM_BUKU` lebih jelas maknanya daripada angka `5` langsung.
- **Mudahan dipelihara** — ubah nilai di satu tempat, berlaku ke seluruh aplikasi.
- **Berlaku global** — konstanta bisa diakses dari mana saja tanpa `global` (berbeda dengan variabel).
- **Praktik profesional** — banyak dipakai di konfigurasi aplikasi modern.

## Cara Pengimplementasian / Code

```php
<?php
// File: 9-konstanta.php

error_reporting(E_ALL);
ini_set('display_errors', 1);

// 1. Membuat konstanta dengan define() (cara lama)
define('NAMA_PERPUSTAKAAN', 'Perpustakaan Digital Kota');
define('ALAMAT_PERPUSTAKAAN', 'Jl. Pendidikan No. 10, Jakarta');
define('MAKS_PINJAM_BUKU', 5);        // Maksimal buku bisa dipinjam
define('DENDA_PER_HARI', 1000);        // Denda per hari (Rupiah)
define('VERSI_SISTEM', '1.0.0');

// 2. Membuat konstanta dengan const (cara modern PHP)
const TAHUN_BERDIRI = 2018;
const KATEGORI_BUKU = ['Fiksi', 'Non-Fiksi', 'Sains', 'Teknologi', 'Sejarah', 'Psikologi'];

// 3. Built-in Constants PHP
?>
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Konstanta di PHP</title>
    <style>
        body { font-family: Arial; padding: 2rem; }

        .info { background: #f0fdf4; padding: 1rem; border-left: 4px solid #22c55e; }
        code { background: #e5e7eb; padding: 2px 4px; border-radius: 3px; }
    </style>
</head>
<body>
    <h1>Konstanta — Nilai yang Tidak Berubah</h1>

    <div class="card">
        <h2>Informasi Sistem Perpustakaan</h2>
        <p><strong>Nama Perpustakaan:</strong> <?= NAMA_PERPUSTAKAAN ?></p>
        <p><strong>Alamat:</strong> <?= ALAMAT_PERPUSTAKAAN ?></p>
        <p><strong>Maksimal Pinjam Buku:</strong> <?= MAKS_PINJAM_BUKU ?> buku</p>
        <p><strong>Denda Keterlambatan:</strong> Rp <?= number_format(DENDA_PER_HARI, 0, ',', '.') ?> / hari</p>
        <p><strong>Versi Sistem:</strong> <?= VERSI_SISTEM ?></p>
        <p><strong>Tahun Berdiri:</strong> <?= TAHUN_BERDIRI ?></p>

    </div>

        <h2>Kategori Buku</h2>
        <ul>
            <?php foreach (KATEGORI_BUKU as $kategori): ?>
                <li><?= $kategori ?></li>
            <?php endforeach; ?>
        </ul>
    </div>

    <div class="info">
        <h2>PHP Built-in Constants (Bawaan PHP)</h2>
        <p><strong>Versi PHP:</strong> <?= PHP_VERSION ?></p>
        <p><strong>PHP_INT_MAX:</strong> <?= PHP_INT_MAX ?></p>
        <p><strong>PHP_INT_MIN:</strong> <?= PHP_INT_MIN ?></p>
        <p><strong>PHP_EOL:</strong> <code><?= PHP_EOL ?></code> (End of Line)</p>
        <p><strong>DIRECTORY_SEPARATOR:</strong> <code><?= DIRECTORY_SEPARATOR ?></code> (Pembatas folder)</p>
        <p><strong>__FILE__:</strong> <code><?= __FILE__ ?></code> (File saat ini)</p>
        <p><strong>__DIR__:</strong> <code><?= __DIR__ ?></code> (Direktori saat ini)</p>
        <p><strong>__LINE__:</strong> <code><?= __LINE__ ?></code> (Baris kode saat ini)</p>
    </div>

    <div class="card" style="background:#fef3c7;border-left-color:#f59e0b;">
        <h3>Catatan: Konstanta Tidak Bisa Diubah</h3>
        <p>Jika kita mencoba mengubah konstanta, PHP akan menghasilkan error. Contoh:</p>
        <code>// NAMA_PERPUSTAKAAN = "Perpustakaan Baru";</code> → <strong>Fatal error: Cannot re-assign constant</strong>
    </div>
</body>
</html>
```

## Tracing Code (Step-by-Step)

Kita telusuri deklarasi konstanta dan penggunaannya.

### Tracing 1: `define('NAMA_PERPUSTAKAAN', 'Perpustakaan Digital Kota');`

**Langkah 1 — PHP memproses define()**

Fungsi `define()` dipanggil saat script PHP dijalankan. Ia menerima 2 parameter: nama konstanta (`'NAMA_PERPUSTAKAAN'`) dan nilainya (`'Perpustakaan Digital Kota'`).

**Langkah 2 — Mendaftarkan konstanta**

PHP menyimpan konstanta ini di memori global. Konstanta ini **terikat dengan nama string** `'NAMA_PERPUSTAKAAN'` dan nilainya `"Perpustakaan Digital Kota"`. Setelah terdaftar, nilainya **tidak bisa diubah**.

**Langkah 3 — Penggunaan `<?= NAMA_PERPUSTAKAAN ?>`**

Saat PHP menghasilkan HTML, ia menemukan `NAMA_PERPUSTAKAAN` tanpa `$`. PHP mengenali ini sebagai **konstanta** (bukan variabel), lalu menggantinya dengan nilainya `"Perpustakaan Digital Kota"`.

### Tracing 2: `const MAKS_PINJAM_BUKU = 5;`

**Langkah 1 — Kompilasi parse time (perbedaan kecil)**

Berbeda dengan `define()`, `const` diproses saat **parse time** (waktu parsing), bukan runtime. Tapi hasilnya sama: konstanta terdaftar dengan nilai tetap.

**Langkah 2 — Digunakan dalam perhitungan**

`<?= date('Y') - TAHUN_BERDIRI ?>` → PHP mengambil nilai `TAHUN_BERDIRI` (2018), mengurangi dari tahun sekarang (misal 2025), hasil 7. Nilai konstanta **tidak berubah**.

### Tracing 3: Mencoba mengubah konstanta

Jika kita tambahkan `NAMA_PERPUSTAKAAN = "Buku Baru";` (tanpa define), PHP akan menganggap kita mencoba **re-assign** konstanta. Ini tidak diperbolehkan → **Fatal error: Cannot redefine constant 'NAMA_PERPUSTAKAAN'** atau **Cannot re-assign constant** tergantung kasusnya.

PHP langsung **menghentikan eksekusi** saat mendeteksi upaya mengubah konstanta.

## Analogi

Bayangkan **peraturan tetap perpustakaan** yang dipajang di dinding depan.

Contoh peraturan:
- **Maksimal pinjam: 5 buku** (tidak bisa diubah sembarangan oleh petugas harian)
- **Denda keterlambatan: Rp 1.000/hari** (aturan tetap dari manajemen)
- **Nama perpustakaan: "Perpustakaan Digital Kota"** (nama resmi, tidak berubah)

Peraturan-peraturan ini **tertulis permanen di papan pengumuman**. Setiap petugas dan pengunjung melihat nilai yang **SAMA** setiap hari. Tidak boleh ada yang datang lalu menghapus dan mengganti angka denda seenaknya.

Itulah **konstanta**. Ia seperti **nilai tetap yang terukir** di sistem. Berbeda dengan variabel (bisa diubah sesuai keadaan), konstanta adalah **aturan baku yang tidak berubah**.

Konteks perpustakaan: `MAKS_PINJAM_BUKU = 5`, `DENDA_PER_HARI = 1000` — ideal dijadikan konstanta karena merupakan **kebijakan bisnis yang tetap**.

## Dipakai untuk Apa

- **Konfigurasi aplikasi** — nama aplikasi, versi, alamat, tahun berdiri.
- **Aturan bisnis** — batas pinjam buku, denda keterlambatan, masa pinjam (14 hari).
- **Nilai tetap matematika** — jika ada konstanta tetap (jarang di PHP dasar).
- **Path/file penting** — bisa pakai `__DIR__` + konstanta nama folder.
- **Status/flag tetap** — nilai enum yang tidak berubah.
- **Environment config** — base URL, nama sistem (bisa dipakai nanti).
- **Mencegah magic number** — hindari angka "misterius" `5`, `1000` langsung di kode. Pakai nama konstanta yang jelas.

## Kesalahan Umum yang Sering Terjadi

- **Mencoba mengubah konstanta** — Akan muncul Fatal Error. Itu memang tujuannya (melindungi nilai tetap).
- **Lupa tidak pakai `$`** — Benar, konstanta **tidak pakai `$`**. Kalau tulis `$NAMA`, itu variabel beda.
- **Nama konstanta pakai huruf kecil** — Boleh secara teknis, tapi konvensi umum pakai **ALL CAPS** biar mudah dibedakan dari variabel.
- **Pakai `const` dalam kondisi/loop** — `const` tidak bisa dideklarasikan dalam `if`, `while`, atau function (beda dengan `define()` yang bisa). Untuk global/config, aman pakai `const`.
- **Mendefinisikan ulang konstanta** — `define()` dengan nama sama akan error kalau pakai mode default. Bisa pakai `define(..., ..., true)` untuk case-insensitive (jarang disarankan).
- **Pakai magic number** — Contoh buruk: `if ($jumlah > 5)` lebih baik `if ($jumlah > MAKS_PINJAM_BUKU)`.
- **Salah pakai define vs const** — Untuk pemula, cukup pakai `const` untuk konstanta global sederhana, atau `define()` kalau butuh fleksibilitas.

### Soal

Buat konfigurasi sistem perpustakaan menggunakan **konstanta**. Ikuti ketentuan:

1. Buat minimal **5 konstanta** menggunakan `define()` atau `const` (campur boleh):

   - `DENDA_PER_HARI` = `1000` (rupiah)
   - `EMAIL_ADMIN` = `"admin@perpustakaan.id"`

3. Tampilkan semua konfigurasi + hasil perhitungan dalam HTML rapi.
4. Tampilkan juga **3 built-in constants** PHP yang menurutmu berguna (pilih bebas).
5. Simpan dengan nama `10-konfigurasi-perpustakaan.php`
