# Operator — Semua yang Perlu Diketahui

## Penjelasan

**Operator** adalah simbol khusus yang digunakan untuk melakukan operasi pada satu atau lebih nilai (operand). Dengan operator, kita bisa menghitung, membandingkan, menggabungkan, atau memanipulasi data.

Di PHP, operator dibagi menjadi beberapa kelompok. Untuk pemula di Level 1, kita cukup fokus pada yang **paling sering dipakai** saat membangun sistem perpustakaan:

- **Aritmatika** (`+`, `-`, `*`, `/`, `%`, `**`) — perhitungan matematika
- **Penugasan** (`=`, `+=`, `-=`, `*=`, `/=`, `.=`) — memberi/mengubah nilai variabel
- **Perbandingan** (`==`, `===`, `!=`, `!==`, `>`, `<`, `>=`, `<=`) — membandingkan nilai
- **Logika** (`&&`, `||`, `!`, `and`, `or`) — gabungan kondisi
- **String** (`.`) — menggabungkan teks
- **Increment/Decrement** (`++`, `--`) — menaikkan/menurunkan nilai
- **Ternary, Null Coalescing** (`?:`, `??`) — shortcut if-else
- **Spaceship Operator** (`<=>`) — perbandingan 3 arah (sangat berguna untuk sorting)

Khusus **perbandingan**, ingat kembali pelajaran Poin 7: lebih aman pakai **`===`** daripada `==` untuk menghindari type juggling.

## Fungsi

- **Melakukan perhitungan** — hitung denda, total harga, sisa stok buku.
- **Membangun logika kondisional** — validasi form, cek batas pinjam, cek stok tersedia.
- **Memanipulasi string** — gabung nama depan+belakang, buat pesan dinamis.
- **Menyederhanakan kode** — operator shortcut (`+=`, `??`, ternary) bikin kode lebih ringkas.
- **Membandingkan data** — bandingkan input user dengan aturan sistem.
- **Sorting & comparison** — spaceship operator berguna saat mengurutkan daftar buku nanti di Level 2.
- **Menangani nilai opsional** — `??` sangat praktis untuk input form (`$_POST['nama'] ?? ''`).

## Tracing Code (Step-by-Step)

Kita fokus ke 3 operator paling relevan untuk sistem perpustakaan: **Null Coalescing**, **Ternary**, dan **Spaceship**.

### Tracing A: Null Coalescing `??`

Kode:
```php
$_POST = ['nama' => 'Budi', 'email' => 'budi@email.com'];
$telepon = $_POST['telepon'] ?? 'Belum diisi';
```

**Langkah 1 — Cek keberadaan key `'telepon'`**

PHP mengecek: apakah `$_POST` memiliki key `'telepon'` **dan nilainya tidak NULL**?

Di array kita, key `'telepon'` **tidak ada**.

**Langkah 2 — Ambil fallback value**

Karena key tidak ada, PHP langsung mengambil nilai fallback `'Belum diisi'`.

> `$telepon` = `"Belum diisi"`

**Bandingkan dengan ternary + isset:** `isset($_POST['telepon']) ? $_POST['telepon'] : 'Belum diisi'` → hasil sama, tapi `??` jauh lebih ringkas.

### Tracing B: Ternary `($stok > 0) ? "Tersedia" : "Habis"`

**Langkah 1 — Evaluasi kondisi**

`$stok = 3`, jadi `3 > 0` = **true**.

**Langkah 2 — Pilih nilai berdasarkan hasil**

Kondisi true → ambil bagian **sebelum** `:` yaitu `"Tersedia"`.

> `$status` = `"Tersedia"`

Kalau `$stok = 0`, kondisi false → ambil `"Habis"`.

### Tracing C: Spaceship `$hargaA <=> $hargaB`

Kasus: `$hargaA = 150000`, `$hargaB = 175000`

**Langkah 1 — Bandingkan nilai kiri vs kanan**

Apakah kiri < kanan? `150000 < 175000` → **true**.

**Langkah 2 — Kembalikan nilai sesuai aturan**

Aturan spaceship:
- Jika **kiri < kanan** → kembalikan **-1**
- Jika **kiri == kanan** → kembalikan **0**
- Jika **kiri > kanan** → kembalikan **1**

Karena 150000 < 175000 → hasil **-1**.

> `$banding` = `-1`

Lalu kita pakai `match()` untuk menerjemahkan jadi teks yang manusiawi: *"Harga A LEBIH MURAH dari Harga B"*

### Tracing D: Logika gabungan peminjaman buku

```php
$bisaPinjam = ($sudahLogin && $stokTersedia > 0 && $jumlahPinjam <= BATAS_PINJAM);
```

Dengan nilai: `$sudahLogin = true`, `$stokTersedia = 3 (>0 true)`, `$jumlahPinjam = 2 <= 5 true`

Evaluasi bertahap (left-to-right dengan &&):
1. `true && true` → `true`
2. `true && true` → `true`

Hasil akhir **true** → pesan "BISA dipinjam".

Kalau misal `$sudahLogin = false`, evaluasi langsung berhenti jadi `false` → "TIDAK BISA dipinjam".

## Analogi

Bayangkan **sistem antrian & aturan peminjaman** di perpustakaan.

- **Aritmatika (+ - * / %)** → Seperti kasir menghitung total denda: keterlambatan 5 hari × Rp 1000 = Rp 5000.
- **Perbandingan (== === > <)** → Petugas mengecek: "Apakah jumlah buku yang mau dipinjam <= kuota anggota?"
- **Logika (&& || !)** → Aturan ketat: **HARUS** sudah login **DAN** stok ada **DAN** kuota cukup → baru boleh pinjam.
- **Ternary (?:)** → Petugas cepat mengambil keputusan: "Kalau stok > 0 → Tersedia, kalau tidak → Habis".
- **Null Coalescing (??)** → Petugas mengisi formulir dengan aman: "Kalau kolom telepon kosong, isi 'Belum diisi'".
- **Spaceship (<=>)** → Saat merapikan rak buku berdasarkan harga atau tahun terbit, sistem butuh cara membandingkan cepat: lebih kecil/sama/lebih besar.
- **Penugasan (`+=`, `.=`)** → Seperti menambah stok: "Stok lama + buku baru masuk".
- **Increment (`++`)** → Menghitung jumlah pengunjung yang masuk: hitung +1 setiap kali.

Semua operator ini adalah **"aturan berpikir"** petugas perpustakaan yang kita terjemahkan jadi kode PHP.

## Dipakai untuk Apa

- **Kalkulasi keuangan** — denda, diskon, total bayar (aritmatika).
- **Validasi form** — cek field wajib, batas angka, kombinasi syarat (perbandingan + logika).
- **Menangani input kosong** — `??` untuk $_POST/$_GET yang opsional.
- **Menampilkan status dinamis** — ternary untuk label "Tersedia/Habis", "Aktif/Tidak Aktif".
- **Logika peminjaman** — gabungan banyak syarat: login + stok + kuota.
- **Pengurutan data** — spaceship operator dasar untuk `usort()` nanti di Level 2.
- **Membangun pesan** — `.=` untuk merangkai pesan notifikasi flash.
- **Counter** — `++` untuk menghitung jumlah item, iterasi sederhana.
- **Pengaman** — `isset()`-like dengan `??`, strict comparison `===` untuk aman.

## Kesalahan Umum yang Sering Terjadi

- **Pakai `==` padahal seharusnya `===`** — Terutama saat bandingkan dengan nilai boolean/konstanta. Ingat type juggling.
- **Keliru prioritas operator** — `&&` punya prioritas lebih tinggi dari `||`. Kalau ragu, pakai **tanda kurung `()`** biar jelas.
- **Salah pakai `=` vs `==`** — `if ($a = 5)` **selalu true** (assignment), bukan perbandingan. Harus `if ($a == 5)`.
- **Menggunakan `and/or` tanpa paham prioritas** — `and/or` punya prioritas **lebih rendah** dari `&&/||`. Bisa bikin hasil tak terduga.
- **Lupa `??` bisa mencegah Notice** — Saat akses key array yang belum ada ($_POST), lebih aman pakai `??`.
- **Ternary bersarang berlebihan** — Boleh, tapi jadi susah dibaca. Lebih baik pakai `if-elseif` atau `match()` (PHP 8).
- **Pakai modulo `%` pada float** — Modulo di PHP bekerja untuk integer, tapi bisa menerima float. Hasil kadang nggak intuitif.
- **Increment dalam ekspresi kompleks** — `echo $i++ . ++$i;` bisa membingungkan. Untuk pemula, pakai terpisah lebih aman.

## Hubungan dengan Materi Sebelumnya

**Materi sebelumnya (Poin 9):** `Konstanta — Nilai yang Tidak Berubah`. Kita sudah punya konstanta untuk konfigurasi (DENDA_PER_HARI, BATAS_PINJAM).

**Hubungan:** Operator menghubungkan variabel + konstanta jadi **logika yang berguna**. Contohnya hitung denda = hari * DENDA_PER_HARI (pakai operator `*`).

**Materi selanjutnya (Level 2):** Setelah menguasai operator ini, kita masuk ke **String, Array & Fungsi** (Poin 11–17). Di sana kita akan sering pakai operator perbandingan untuk filter array, operator logika untuk validasi, spaceship untuk sorting, dll.
