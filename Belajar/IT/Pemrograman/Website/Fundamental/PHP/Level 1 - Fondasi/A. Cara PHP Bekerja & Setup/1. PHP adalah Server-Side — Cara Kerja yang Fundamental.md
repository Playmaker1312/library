# PHP adalah Server-Side — Cara Kerja yang Fundamental

## Penjelasan

PHP (Hypertext Preprocessor) adalah bahasa pemrograman **server-side**. Artinya, kode PHP **dieksekusi di server**, bukan di browser pengguna. 

Jadi saat kamu mengakses file `.php` lewat browser, yang terjadi bukan browser membaca PHP, tapi browser mengirim permintaan (request) ke server. Server yang akan memproses semua kode PHP, lalu mengirimkan kembali hasilnya berupa **HTML murni** ke browser.

Dengan cara ini, kode PHP **tidak pernah terlihat** oleh pengguna. Yang mereka lihat hanyalah hasil tampilan halaman web (HTML).

**Cara kerja PHP secara sederhana:**

- PHP dijalankan di **server** (komputer yang menyimpan website).
- Hasil eksekusinya adalah **HTML**.
- Browser hanya menerima HTML, bukan kode PHP.
- Karena itu, PHP cocok untuk membuat halaman web yang **dinamis** (bisa berubah-ubah sesuai data atau input pengguna).

**Alur request-response PHP (step by step):**

1. **User** mengetik URL di browser, misalnya `http://localhost/index.php` → browser mengirim **HTTP Request** ke server.
2. **Web Server** (Apache/Nginx) menerima request tersebut. Ia melihat bahwa file yang diminta berakhiran `.php`.
3. Server meneruskan file `.php` ke **PHP Engine** (mesin pemroses PHP).
4. **PHP Engine** membaca dan menjalankan semua kode PHP di dalam file tersebut. Selama proses ini, PHP bisa mengambil data dari database, membaca file, memproses form, atau melakukan perhitungan.
5. Hasil pemrosesan PHP biasanya berupa kode HTML. PHP Engine mengirim hasil itu kembali ke Web Server.
6. **Web Server** mengirim **HTTP Response** berisi HTML murni ke browser.
7. **Browser** menerima HTML tersebut, lalu merender (menampilkan) halaman web ke layar pengguna.

**Perbedaan penting dengan JavaScript:**

- **PHP = Server-side** → dijalankan di server, hasilnya HTML.
- **JavaScript = Client-side** → dijalankan langsung di browser pengguna.

Bukti sederhana: buka halaman web manapun yang dibuat dengan PHP (misalnya `view-source:https://wordpress.com`), kamu **tidak akan menemukan** kode PHP di sana. Yang ada hanya HTML, CSS, dan JavaScript.

## Fungsi

Fungsi PHP dalam pengembangan web adalah **menghubungkan data yang ada di server dengan tampilan yang dilihat pengguna**.

Secara sederhana: PHP menyelesaikan masalah "bagaimana membuat halaman web yang bisa menampilkan data yang berbeda-beda, tanpa harus membuat banyak file HTML terpisah?"

Contohnya:
- Situs berita bisa menampilkan artikel berbeda tergantung URL-nya.
- Sistem perpustakaan bisa menampilkan daftar buku yang berbeda tergantung stok/data di database.
- Halaman bisa menampilkan salam "Selamat pagi" atau "Selamat siang" tergantung waktu saat ini.

Jadi PHP berfungsi agar website bisa menjadi **dinamis**, bukan cuma statis.

## Cara Pengimplementasian / Code

Berikut contoh sederhana yang menunjukkan PHP memproses logika, lalu menghasilkan HTML yang dikirim ke browser.

```php
<?php
// File: 1-php-server-side.php

// Menentukan salam berdasarkan jam saat ini
$waktu = date("H"); // Ambil jam dalam format 24 jam (contoh: 09, 14, 22)

if ($waktu < 12) {
    // Jika jam masih di bawah 12 siang
    $salam = "Selamat pagi";
} else {
    // Jika jam sudah 12 siang ke atas
    $salam = "Selamat siang";
}
?>
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Cara Kerja PHP</title>
</head>
<body>
    <h1><?php echo $salam; ?></h1>
    <p>Sekarang jam <?php echo date("H:i"); ?></p>
    <p>Lihat sumber halaman ini (View Page Source) — kamu tidak akan melihat kode PHP-nya, hanya HTML.</p>
</body>
</html>
```

**Cara menjalankan/menguji:**

1. Pastikan XAMPP/Laragon sudah berjalan (Apache aktif).
2. Simpan file di folder `C:\xampp\htdocs\perpustakaan\` (XAMPP) atau `C:\laragon\www\perpustakaan\` (Laragon). Beri nama `1-php-server-side.php`.
3. Buka browser, ketik alamat: `http://localhost/perpustakaan/1-php-server-side.php`
4. Coba buka View Source (Klik kanan → View Page Source / `Ctrl+U`), maka kamu hanya akan melihat kode HTML, tidak ada `<?php ... ?>`.

## Tracing Code (Step-by-Step)

Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer saat PHP memprosesnya di server.

Kode yang akan kita telusuri:

```php
<?php
$waktu = date("H");
if ($waktu < 12) {
    $salam = "Selamat pagi";
} else {
    $salam = "Selamat siang";
}
?>
<!DOCTYPE html>
...
<h1><?php echo $salam; ?></h1>
<p>Sekarang jam <?php echo date("H:i"); ?></p>
```

**Langkah 1 — Baris `$waktu = date("H");`**

PHP memanggil fungsi `date("H")`. Fungsi ini meminta sistem server untuk mengembalikan **jam saat ini dalam format 24 jam** (hanya angka jam, tanpa menit).

Misalkan saat ini jam **09:30** pagi, maka `date("H")` akan mengembalikan nilai `"09"` (string). Karena PHP bertipe dinamis, nilai ini bisa diperlakukan sebagai angka saat dibandingkan.

Sekarang variabel `$waktu` **berisi** `"09"`.

**Langkah 2 — Baris `if ($waktu < 12) { ... }`**

PHP melakukan perbandingan: apakah nilai `$waktu` **lebih kecil dari 12**?

Contoh kasus: `$waktu` = `"09"`. Dibandingkan dengan angka `12` → `09 < 12` adalah **benar (true)**.

Karena kondisi benar, PHP **masuk ke cabang pertama** (blok `if`), dan **melewati blok `else`**.

**Langkah 3 — Baris `$salam = "Selamat pagi";`**

PHP membuat variabel `$salam`, lalu mengisinya dengan teks `"Selamat pagi"`.

Sekarang `$salam` **berisi** `"Selamat pagi"`.

**Langkah 4 — PHP keluar dari blok `if-else`**

Semua logika PHP di bagian atas sudah selesai diproses. Sekarang PHP mulai menghasilkan **output HTML** yang ada di bawah tag `?>`.

**Langkah 5 — Baris `<h1><?php echo $salam; ?></h1>`**

Saat sampai di sini, PHP bertemu tag `<?php echo $salam; ?>`. PHP menjalankan perintah `echo` untuk mencetak isi variabel `$salam`.

Isi `$salam` saat ini adalah `"Selamat pagi"`. Jadi PHP menggantikan bagian itu menjadi: `<h1>Selamat pagi</h1>`

**Langkah 6 — Baris `<p>Sekarang jam <?php echo date("H:i"); ?></p>`**

PHP kembali menjalankan fungsi `date("H:i")`. Fungsi ini mengembalikan jam dan menit saat ini, misalnya `"09:30"`.

Maka bagian ini digantikan menjadi: `<p>Sekarang jam 09:30</p>`

**Langkah 7 — Sisa HTML dikirim apa adanya**

Tag HTML lainnya (`<!DOCTYPE html>`, `<head>`, `<body>`, `<p>` penjelasan) tidak mengandung PHP, jadi PHP **melewatkannya langsung** sebagai teks HTML.

**Output akhir yang dikirim ke browser:**

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Cara Kerja PHP</title>
</head>
<body>
    <h1>Selamat pagi</h1>
    <p>Sekarang jam 09:30</p>
    <p>Lihat sumber halaman ini (View Page Source) — kamu tidak akan melihat kode PHP-nya, hanya HTML.</p>
</body>
</html>
```

**Kesimpulan Tracing:** Browser **tidak pernah menerima** kode PHP. Ia hanya menerima HTML hasil olahan PHP di server.

## Analogi

Bayangkan sebuah **perpustakaan**. 

Kamu (pengunjung/browser) datang ke loket dan meminta: *"Tolong berikan saya daftar rekomendasi buku untuk pagi ini, sesuai suasana hati pembaca pemula."*

Pustakawan (PHP Engine) tidak langsung memberimu rak buku. Ia masuk ke gudang perpustakaan (server/database), memeriksa kondisi saat ini (jam berapa sekarang), memilih buku-buku yang sesuai dengan logika "pagi hari" (logika `if`), lalu menuliskan **daftar rekomendasi** di secarik kertas (output HTML).

Kamu sebagai pengunjung **hanya menerima kertas itu**. Kamu tidak pernah melihat proses pustakawan mondar-mandir di dalam gudang, mencari-cari buku, atau berpikir memilih rekomendasi. Kamu hanya melihat hasil akhirnya di kertas.

Begitulah cara kerja PHP: **proses terjadi di dalam "gudang" server, hasilnya dikirim dalam bentuk HTML ke pengguna.**

## Dipakai untuk Apa

- **Website dinamis** — bisa menampilkan konten yang berubah-ubah (portal berita, blog, forum).
- **Sistem berbasis data** — menampilkan data dari database (sistem perpustakaan, inventory, katalog produk).
- **Form dan interaksi pengguna** — memproses login, registrasi, pencarian buku, peminjaman buku.
- **Backend aplikasi web** — mengelola data sebelum ditampilkan ke halaman web.
- **REST API** — bisa digunakan untuk mengirim data ke aplikasi mobile (Android/iOS).
- **CMS (Content Management System)** — seperti WordPress, Joomla, Drupal dibangun dengan PHP.

## Kesalahan Umum yang Sering Terjadi

- **Mengklik file `.php` langsung di File Explorer/Windows Explorer.** File akan terbuka sebagai teks mentah (bukan dijalankan). Solusinya: harus diakses lewat `http://localhost/...` agar diproses server.
- **Menyangka kode PHP bisa dilihat oleh pengguna.** Salah. Karena diproses di server, yang sampai ke browser hanya HTML murni. Cek dengan View Page Source untuk membuktikannya.
- **Tidak menjalankan web server lokal.** Tanpa Apache (XAMPP/Laragon) yang aktif, file `.php` tidak bisa diproses. Solusinya: pastikan `Apache` dalam keadaan Running.
- **Lupa tag pembuka `<?php`.** Jika lupa, kode PHP bisa terbaca sebagai teks biasa di browser. Selalu mulai dengan `<?php`.
- **Mencampur logika dan tampilan secara berlebihan tanpa pemahaman alur.** Bisa membuat bingung saat debugging. Pahami dulu alur request-response ini terlebih dahulu.

## Soal Latihan & Jawaban

### Soal

Seorang petugas perpustakaan ingin membuat halaman sambutan dinamis untuk pengunjung. Jika saat ini jam menunjukkan pukul 10:00 pagi, halaman tersebut harus menampilkan tulisan:  
**"Selamat datang di Perpustakaan Digital — Jam: 10:00"**

Tugasmu: Tulis kode PHP & HTML yang bisa menghasilkan tampilan tersebut. Gunakan **variabel** untuk menyimpan pesan dan jam, sesuai prinsip pemisahan logika dan tampilan.

### Jawaban

```php
<?php
// Simpan jam saat ini ke dalam variabel
$jam = date("H:i");

// Simpan pesan sambutan ke dalam variabel
$pesan = "Selamat datang di Perpustakaan Digital — Jam: $jam";
?>
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Perpustakaan Digital</title>
</head>
<body>
    <h1><?php echo $pesan; ?></h1>
</body>
</html>
```
