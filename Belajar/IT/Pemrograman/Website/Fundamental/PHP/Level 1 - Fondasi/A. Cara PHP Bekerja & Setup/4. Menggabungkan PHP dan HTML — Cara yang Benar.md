# Menggabungkan PHP dan HTML — Cara yang Benar

## Penjelasan

Di materi sebelumnya (Poin 3), kita masih banyak menggunakan `echo` untuk mencetak tag HTML. Cara itu **bisa dipakai**, tapi akan terasa kurang rapi kalau halaman HTML-nya panjang.

Cara yang **lebih baik dan umum dipakai** adalah **menyisipkan kode PHP langsung di dalam file HTML**. Artinya: kita menulis HTML seperti biasa, lalu hanya bagian-bagian yang butuh logika PHP saja yang kita bungkus dengan `<?php ... ?>`.

PHP dirancang untuk bisa "campur" dengan HTML dengan mulus. Ini memudahkan kita memisahkan **logika (PHP)** dan **tampilan (HTML)**, terutama saat membangun halaman web.

Selain itu, PHP punya **short echo tag** (`<?= ... ?>`) yang sangat praktis untuk menampilkan nilai variabel di dalam HTML.

## Fungsi

- **Membuat kode lebih rapi dan mudah dibaca** dibanding harus `echo` semua tag HTML.
- **Memisahkan logika dan tampilan** — PHP untuk menghitung/data, HTML untuk struktur tampilan.
- **Menghemat waktu** saat membuat halaman web yang kompleks (form, tabel, layout).
- **Praktis untuk menampilkan data dinamis** langsung di dalam elemen HTML (judul, tabel, footer, dll).
- **Mengikuti praktik umum** yang dipakai di framework PHP (Laravel, Symfony) nantinya.

## Cara Pengimplementasian / Code

Kita akan melihat perbandingan cara lama (echo semua) vs cara benar (campur PHP-HTML).

### Perbandingan 1: Mencetak HTML dengan echo vs campur langsung

**Cara A — Pakai echo (kurang rapi):**

```php
<?php
$namaPerpustakaan = "Perpustakaan Digital Kota";
echo "<h1>" . $namaPerpustakaan . "</h1>";
echo "<p>Selamat datang!</p>";
?>
```

**Cara B — Campur PHP dan HTML (lebih rapi):**

```php
<?php
$namaPerpustakaan = "Perpustakaan Digital Kota";
?>
<h1><?php echo $namaPerpustakaan; ?></h1>
<p>Selamat datang!</p>
```

Kedua hasilnya **sama persis** di browser. Tapi Cara B jauh lebih mudah dibaca karena strukturnya seperti HTML biasa.

### Perbandingan 2: Short Echo Tag (`<?= ... ?>`)

PHP menyediakan shortcut untuk `<?php echo ... ?>`, yaitu **`<?= ... ?>`**.

```php
<?php
$namaPerpustakaan = "Perpustakaan Digital Kota";
$jumlahBuku = 1250;
$tahunSekarang = date("Y");
?>
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title><?= $namaPerpustakaan ?></title>
</head>
<body>
    <h1>Selamat Datang di <?= $namaPerpustakaan ?></h1>
    <p>Koleksi kami saat ini: <?= $jumlahBuku ?> buku</p>
    <footer>
        <p>&copy; <?= $tahunSekarang ?> <?= $namaPerpustakaan ?></p>
    </footer>
</body>
</html>
```

**Catatan penting:** `<?= ... ?>` **selalu aktif** di PHP (berbeda dengan short tag `<? ... ?>` yang bisa dimatikan di php.ini). Jadi aman digunakan.

## Tracing Code (Step-by-Step)

Kita telusuri file di atas dari atas ke bawah, melihat bagaimana PHP dan HTML digabung.

Kode yang ditelusuri (bagian penting):

```php
<?php
$namaPerpustakaan = "Perpustakaan Digital Kota";
$alamat           = "Jl. Pendidikan No. 10, Jakarta";
...
$tahun            = date("Y");
?>
<!DOCTYPE html>
...
<title><?= $namaPerpustakaan ?></title>
...
<h1><?= $namaPerpustakaan ?></h1>
<p><strong>Alamat:</strong> <?= $alamat ?></p>
...
<footer><p>&copy; <?= $tahun ?> <?= $namaPerpustakaan ?></p></footer>
```

**Langkah 1 — Blok PHP di atas (`<?php ... ?>`)**

PHP menjalankan semua perintah di dalam blok ini **pertama kali**.

- `$namaPerpustakaan = "Perpustakaan Digital Kota"`
- `$alamat = "Jl. Pendidikan No. 10, Jakarta"`
- `$jamBuka = "Senin - Sabtu: 08:00 - 17:00 WIB"`
- `$jumlahBuku = 1250`
- `$jumlahAnggota = 842`
- `$tahun = date("Y")` → misalnya mengembalikan `"2025"`

Sekarang **semua variabel sudah terisi** nilainya di memori PHP.

**Langkah 2 — Tag `<!DOCTYPE html>` sampai `<head>`**

Setelah blok PHP pertama selesai (`?>`), PHP berhenti memproses logika. Semua teks di luar blok PHP (HTML murni) akan **dilewatkan langsung ke output response**, tanpa diubah.

Jadi baris `<!DOCTYPE html>`, `<html>`, `<head>`, `<meta>`, `<style>`, sampai `</head>` **dikirim apa adanya** ke browser.

**Langkah 3 — `<title><?= $namaPerpustakaan ?></title>`**

PHP bertemu `<?= $namaPerpustakaan ?>`. Ini adalah short echo tag. PHP akan **mencetak isi variabel** `$namaPerpustakaan` ("Perpustakaan Digital Kota") ke output.

Jadi title menjadi: `<title>Perpustakaan Digital Kota</title>`

**Langkah 4 — `<body>` dan `<h1><?= $namaPerpustakaan ?></h1>`**

HTML `<body>` dan pembuka `<div>` dikirim apa adanya. Lalu `<?= $namaPerpustakaan ?>` diganti menjadi teks nama perpustakaan.

Hasil: `<h1>Perpustakaan Digital Kota</h1>`

**Langkah 5 — Menampilkan data di dalam `.info`**

Baris `<p><strong>Alamat:</strong> <?= $alamat ?></p>` → PHP mengganti `<?= $alamat ?>` dengan `"Jl. Pendidikan No. 10, Jakarta"`. 

Begitu seterusnya untuk jam buka, jumlah buku, jumlah anggota. Setiap `<?= ... ?>` **dievaluasi dan dicetak** nilainya.

**Langkah 6 — Footer**

`<p>&copy; <?= $tahun ?> <?= $namaPerpustakaan ?></p>` → digabung menjadi `&copy; 2025 Perpustakaan Digital Kota`

**Langkah 7 — Penutup HTML**

Tag `</div>`, `</body>`, `</html>` dikirim apa adanya.

**Output akhir yang dikirim ke browser:**

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <style>
        body { font-family: Arial, sans-serif; padding: 2rem; background: #f5f5f5; }

        .info { margin: 1rem 0; padding: 1rem; background: #f0fdf4; border-left: 4px solid #2c7a7b; }
    </style>
</head>
<body>
    <div class="container">
        <h1>Perpustakaan Digital Kota</h1>
        
        <div class="info">
            <p><strong>Alamat:</strong> Jl. Pendidikan No. 10, Jakarta</p>
            <p><strong>Jam Buka:</strong> Senin - Sabtu: 08:00 - 17:00 WIB</p>
            <p><strong>Koleksi Buku:</strong> 1250 buku</p>
```

**Kesimpulan Tracing:** PHP memproses **hanya bagian dalam `<?php ... ?>` dan `<?= ... ?>`**. Sisanya (HTML) **dilewatkan apa adanya** ke output. Hasil akhir tetap **100% HTML murni** di browser.

## Analogi

Bayangkan kamu membuat **brosur promosi perpustakaan**.

Ada dua cara:

- **Cara pertama (echo semua):** Kamu menulis semua kalimat brosur lewat mesin ketik yang otomatis (PHP echo). Kamu harus "ketik ulang" semua format layout di dalam teks. Agak repot dan susah dibaca.
- **Cara kedua (campur PHP+HTML):** Kamu **desain brosur dulu pakai kertas layout (HTML)** — tata letak, warna, spasi, font. Baru bagian yang bisa berubah-ubah (nama perpustakaan, jumlah buku, tahun) kamu **isi dengan stempel data (PHP `<?= ... ?>`)**.

Jadi desain tetap terpisah dengan data yang dinamis. Sangat rapi dan mudah diperbaiki.

Dalam konteks perpustakaan kita: **template halaman web (HTML)** adalah "formulir tampilan" tetap, sedangkan **data perpustakaan (PHP variabel)** adalah "isi yang bisa berubah" tergantung keadaan real-nya.

## Dipakai untuk Apa

- **Membuat halaman web dinamis** yang rapi (profil, dashboard, daftar buku).
- **Template web** — memisahkan struktur HTML dengan data PHP.
- **Menampilkan data dari variabel** langsung di dalam elemen HTML (judul, tabel, badge, footer).
- **Membangun layout yang kompleks** tanpa harus `echo` ratusan baris HTML.
- **Persiapan ke framework** — pola ini mirip dengan templating di Laravel/Blade nantinya.
- **Halaman yang mudah dirawat** (maintainable) — designer bisa edit HTML, programmer fokus ke PHP.

## Kesalahan Umum yang Sering Terjadi

- **Terlalu banyak campur PHP-HTML di satu file** — Boleh, tapi untuk file besar lebih baik dipisah (nanti belajar include/require). Untuk pemula masih wajar.
- **Lupa `<?php` pembuka** saat menyisipkan PHP di tengah HTML — Bisa membuat kode PHP muncul sebagai teks di browser.
- **Menyisipkan logika kompleks di dalam HTML** — HTML sebaiknya hanya untuk menampilkan data (`<?= $variabel ?>`, `if` sederhana). Logika berat tetap di atas (blok PHP terpisah).
- **Kurang konsisten pakai `<?=` vs `<?php echo`** — Keduanya benar. `<?=` lebih ringkas untuk output sederhana.
- **Tag PHP tidak tertutup dengan benar** — Jika ada blok `<?php if (...) { ?> ... <?php } ?>`, pastikan kurung kurawal dan tag penutupnya pas.
- **Menyimpan file dengan ekstensi `.html` padahal ada PHP** — Server tidak akan memproses PHP di file `.html`. Harus ekstensi `.php`.

## Hubungan dengan Materi Sebelumnya

**Materi sebelumnya (Poin 3):** `File .php Pertama — Hello World yang Sesungguhnya`. Kita belajar mencetak output dengan `echo`.

**Hubungan:** Di poin 3 kita fokus ke "bisa menampilkan", di poin 4 kita fokus ke **"cara menampilkan yang rapi dan benar"**. Ini adalah penyempurnaan gaya penulisan PHP-HTML.

**Materi selanjutnya (Poin 5):** `Error Reporting — Baca Error, Jangan Takut`. Setelah mulai mencampur PHP-HTML dan menulis kode lebih kompleks, kita perlu belajar cara membaca dan menangani error agar bisa memperbaiki kesalahan dengan cepat.
