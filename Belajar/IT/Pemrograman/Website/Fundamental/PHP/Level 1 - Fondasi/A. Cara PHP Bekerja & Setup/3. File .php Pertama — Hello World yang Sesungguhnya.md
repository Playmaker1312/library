# File .php Pertama — Hello World yang Sesungguhnya

## Penjelasan

Setelah environment siap, saatnya kita membuat **file `.php` pertama** untuk membuktikan bahwa PHP benar-benar diproses di server dan menghasilkan HTML.

Kebiasaan klasik pemrograman adalah menampilkan "Hello World". Namun di PHP, versi "Hello World yang sesungguhnya" bukan cuma menampilkan teks, tapi juga **membuktikan alur server-side**: logika diproses di server, hasilnya dikirim ke browser.

Di PHP, kode ditulis di antara tag `<?php ... ?>`. Tag penutup `?>` **boleh dihilangkan** jika file tersebut murni berisi kode PHP (praktik yang baik untuk menghindari spasi tak sengaja di akhir file).

Kita juga akan belajar perbedaan antara membuka file langsung (`file://`) vs lewat server (`http://localhost/...`).

## Fungsi

Membuktikan bahwa:

- Server lokal kita sudah benar-benar bisa memproses PHP.
- PHP bisa mencetak teks ke halaman web menggunakan `echo`.
- Hasil yang sampai ke browser adalah HTML murni, bukan kode PHP.
- Kita bisa menggabungkan logika PHP (tanggal, waktu) dengan tampilan.

Dengan ini, kita punya **landasan praktis** sebelum masuk ke variabel, tipe data, dan konsep selanjutnya.

## Cara Pengimplementasian / Code

Kita buat dua versi untuk melihat perbedaan: versi paling sederhana, dan versi yang lebih realistis dengan konteks **perpustakaan**.

### Versi 1: Hello World Sederhana

Buat file `hello.php` di dalam folder `perpustakaan/`.

```php
<?php
// File: hello.php

// echo digunakan untuk menampilkan teks ke browser
echo "Hello World! Ini file PHP pertamaku.";
```

**Cara menjalankan:**

- Laragon: `http://perpustakaan.test/hello.php`
- XAMPP: `http://localhost/perpustakaan/hello.php`

### Versi 2: Hello World Kontekstual (Konteks Perpustakaan)

Biar lebih relevan dengan roadmap kita, kita buat halaman sambutan perpustakaan digital.

Buat file `index.php` di dalam folder `perpustakaan/`.

```php
<?php
// File: index.php

// Ambil informasi waktu saat ini
$tanggal = date("d F Y"); // Contoh: 17 October 2025
$jam     = date("H:i");   // Contoh: 09:30

// Tampilkan pesan sambutan
echo "<h1>Selamat Datang di Perpustakaan Digital</h1>";
echo "<p>Hari ini: " . $tanggal . "</p>";
echo "<p>Jam saat ini: " . $jam . "</p>";
echo "<hr>";
echo "<p>Sistem ini masih dalam tahap belajar PHP Fundamental.</p>";
```

**Cara menjalankan:**

- Laragon: `http://perpustakaan.test/`
- XAMPP: `http://localhost/perpustakaan/`

**Perhatikan:** Karena namanya `index.php`, kita bisa langsung mengakses foldernya tanpa menyebut nama file.

## Tracing Code (Step-by-Step)

Kita telusuri file `index.php` baris demi baris.

Kode yang ditelusuri:

```php
<?php
$tanggal = date("d F Y");
$jam     = date("H:i");

echo "<h1>Selamat Datang di Perpustakaan Digital</h1>";
echo "<p>Hari ini: " . $tanggal . "</p>";
echo "<p>Jam saat ini: " . $jam . "</p>";
echo "<hr>";
echo "<p>Sistem ini masih dalam tahap belajar PHP Fundamental.</p>";
```

**Langkah 1 — Baris `$tanggal = date("d F Y");`**

PHP memanggil fungsi `date("d F Y")`. Fungsi ini meminta server untuk mengembalikan **tanggal hari ini** dengan format: **tanggal bulan tahun** (dalam bahasa Inggris default, tergantung pengaturan locale. Namun secara default PHP akan menampilkan `October`, `January`, dll).

Misalkan hari ini 17 Oktober 2025 → fungsi mengembalikan `"17 October 2025"`.

Variabel `$tanggal` **berisi** `"17 October 2025"`.

**Langkah 2 — Baris `$jam = date("H:i");`**

PHP memanggil `date("H:i")`. Mengembalikan jam dan menit dalam format 24 jam.

Misalkan sekarang jam 09:30 → mengembalikan `"09:30"`.

Variabel `$jam` **berisi** `"09:30"`.

**Langkah 3 — Baris `echo "<h1>Selamat Datang di Perpustakaan Digital</h1>";`**

PHP menjalankan `echo` dan mencetak string HTML `<h1>Selamat Datang di Perpustakaan Digital</h1>` langsung ke output response.

Hasil ini akan dikirim ke browser dan dirender sebagai **judul utama**.

**Langkah 4 — Baris `echo "<p>Hari ini: " . $tanggal . "</p>";`**

Di sini kita melihat **penggabungan string** dengan tanda titik (`.`). PHP menggabungkan 3 bagian:

- `"<p>Hari ini: "`
- isi `$tanggal` → `"17 October 2025"`
- `"</p>"`

Menjadi: `"<p>Hari ini: 17 October 2025</p>"`

Lalu dicetak ke output.

**Langkah 5 — Baris `echo "<p>Jam saat ini: " . $jam . "</p>";`**

Sama seperti langkah 4. Digabung menjadi: `"<p>Jam saat ini: 09:30</p>"`

**Langkah 6 — Baris `echo "<hr>";`**

Mencetak tag horizontal rule `<hr>` (garis pemisah).

**Langkah 7 — Baris terakhir `echo "<p>Sistem ini masih dalam tahap belajar PHP Fundamental.</p>";`**

Mencetak paragraf penutup.

**Output akhir yang dikirim ke browser:**

```html
<h1>Selamat Datang di Perpustakaan Digital</h1>
<p>Hari ini: 17 October 2025</p>
<p>Jam saat ini: 09:30</p>
<hr>
<p>Sistem ini masih dalam tahap belajar PHP Fundamental.</p>
```

**Penting:** Perhatikan bahwa **tidak ada satupun kode PHP** di output ini. Semua `<?php ... ?>` sudah diproses dan digantikan oleh hasil cetaknya.

## Analogi

Bayangkan kamu sedang berada di **resepsionis perpustakaan digital**.

Pengunjung (browser) datang dan bertanya: *"Kapan perpustakaan ini dibuka hari ini? Jam berapa sekarang?"*

Resepsionis (PHP Engine) melihat jam dinding dan kalender yang ada di **ruang belakang perpustakaan** (server). Ia tidak membawa kalender mentah ke pengunjung. Ia menuliskan jawaban yang rapi di **kartu informasi**:

*"Selamat datang. Hari ini 17 Oktober 2025, jam 09:30. Sistem perpustakaan digital siap digunakan."*

Pengunjung **hanya menerima kartu informasi** berisi teks & format yang enak dibaca. Ia tidak tahu resepsionis tadi melihat jam dinding, merangkai kalimat, atau memilih kata-kata. Yang dilihat pengunjung hanya **hasil akhirnya**.

Persis seperti itu: PHP merangkai teks+HTML di server, lalu mengirim hasil jadi ke browser.

## Dipakai untuk Apa

- **Menguji environment** — memastikan Apache + PHP berjalan dengan benar.
- **Belajar dasar `echo`** — cara paling fundamental untuk menampilkan output.
- **Mengenal fungsi bawaan** — seperti `date()` untuk mengambil informasi waktu.
- **Membuktikan server-side** — perbedaan buka langsung vs lewat localhost jadi sangat jelas.
- **Fondasi halaman dinamis** — walau sederhana, ini awal dari halaman web yang bisa "berpikir".
- **Template awal project** — file `index.php` sering jadi halaman awal aplikasi.

## Kesalahan Umum yang Sering Terjadi

- **Tidak pakai tag `<?php`** — Browser akan menampilkan tulisan `<?php echo ... ?>` sebagai teks biasa.
- **Lupa titik koma (`;`) di akhir perintah** — Akan muncul `Parse error: syntax error, unexpected ...` di browser.
- **Membuka file langsung (`file://`)** — Browser menampilkan kode PHP mentah, bukan hasil proses. Solusinya: akses via `http://localhost/...`
- **Salah nama file atau salah folder** — Akan muncul `404 Not Found`. Pastikan file ada di `htdocs/perpustakaan/` atau `www/perpustakaan/`.
- **Menggabungkan string tanpa titik (`.`)** — Contoh salah: `echo "<p>Hari ini: $tanggal</p>";` sebenarnya **boleh** pakai double quote (interpolasi), tapi kalau pakai single quote tidak bisa. Pemula sering bingung. Yang aman: pahami kedua cara.
- **Lupa ekstensi `.php`** — Kalau disimpan sebagai `.html`, server TIDAK akan memproses kode PHP.

## Soal Latihan & Jawaban

### Soal

Buat halaman sambutan untuk **Sistem Perpustakaan Digital** dengan ketentuan berikut:

1. Tampilkan judul: **"Sistem Perpustakaan Digital"**
2. Tampilkan informasi: **"Akses hari ini: [tanggal lengkap]"**. Gunakan format `l, d F Y` (contoh: Friday, 17 October 2025). 
3. Tampilkan **nama petugas** yang bertugas hari ini, simpan dalam variabel `$petugas`.
4. Tampilkan juga **jumlah koleksi buku** yang tersedia, simpan dalam variabel `$jumlahBuku`.
5. Gunakan minimal **2 variabel** dan gabungkan dengan teks HTML.

Simpan dengan nama `perpustakaan-sambutan.php` dan akses lewat browser dengan URL yang benar.

### Jawaban

**Isi file `perpustakaan-sambutan.php`:**

```php
<?php
// File: perpustakaan-sambutan.php

// Data dinamis
$tanggalAkses = date("l, d F Y"); // Tanggal lengkap dengan nama hari
$petugas      = "Budi Santoso";
$jumlahBuku   = 1250;
?>
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Sistem Perpustakaan Digital</title>
</head>
<body>
    <h1>Sistem Perpustakaan Digital</h1>
    <p>Akses hari ini: <?php echo $tanggalAkses; ?></p>
    <p>Petugas bertugas: <?php echo $petugas; ?></p>
    <p>Jumlah koleksi buku: <?php echo $jumlahBuku; ?> buku</p>
    <hr>
    <p>Selamat bertugas dan semangat melayani pengunjung!</p>
</body>
</html>
```

**URL akses:**

- **Laragon:** `http://perpustakaan.test/perpustakaan-sambutan.php`
- **XAMPP:** `http://localhost/perpustakaan/perpustakaan-sambutan.php`

**Penjelasan singkat:** Dengan cara ini, meski kita buka besok/lusa, nilai `$tanggalAkses` akan **otomatis berubah** sesuai tanggal hari itu. Inilah contoh sederhana halaman web yang **dinamis** berkat PHP.
