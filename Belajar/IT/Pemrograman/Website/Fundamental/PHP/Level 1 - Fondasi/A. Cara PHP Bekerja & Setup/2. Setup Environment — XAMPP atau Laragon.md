# Setup Environment — XAMPP atau Laragon

## Penjelasan

Agar bisa menjalankan file `.php` sesuai dengan cara kerjanya (diproses di server), kita **tidak bisa** langsung membuka file `.php` lewat File Explorer. Kita butuh **lingkungan server lokal** di komputer kita sendiri.

Lingkungan server lokal ini terdiri dari 3 komponen utama:

1. **Web Server** — bertugas menerima request dari browser dan mengirimkan response (Apache atau Nginx).
2. **PHP Engine** — bertugas memproses kode PHP menjadi HTML.
3. **Database Server** — bertugas menyimpan data (MySQL/MariaDB). Ini nanti akan kita pakai saat belajar database di Level 4.

Kedua tools yang paling umum digunakan untuk pemula adalah **XAMPP** dan **Laragon**. Keduanya sudah menggabungkan ketiganya dalam satu paket instalasi.

## Fungsi

Fungsi setup environment adalah **membuat "mini server" di laptop/komputer pribadi** agar kita bisa:

- Menjalankan file `.php` lewat browser dengan alamat `http://localhost/...`
- Menguji kode PHP tanpa perlu upload ke internet/server hosting
- Membangun dan menguji sistem perpustakaan digital secara lokal
- Belajar alur request-response secara nyata (persis seperti di server sungguhan)

Singkatnya: **menciptakan ruang latihan yang aman dan praktis untuk belajar PHP.**

## Cara Pengimplementasian / Code

Kita akan fokus pada dua pilihan: **Laragon (rekomendasi modern)** dan **XAMPP (klasik, banyak tutorial)**. Kamu cukup pilih **salah satu** saja.

### A. Menggunakan Laragon (Rekomendasi)

Laragon ringan, cepat, dan sangat ramah untuk pemula Windows.

**Langkah instalasi:**

1. Kunjungi [https://laragon.org/download/](https://laragon.org/download/)
2. Download Laragon (versi Full atau Lite). Untuk belajar PHP, cukup **Full**.
3. Jalankan file installer → Next → Install. Biarkan lokasi default (`C:\laragon\`).
4. Setelah selesai, buka Laragon → klik **Start All**. Jika berhasil, ikon Laragon akan berwarna hijau.

**Struktur folder Laragon:**

Folder kerja kita ada di `C:\laragon\www\`. Semua project PHP kita akan disimpan di sini.

**Membuat project pertama:**

1. Buka folder `C:\laragon\www\`
2. Buat folder baru dengan nama: `perpustakaan`
3. Di dalam folder `perpustakaan`, buat file `info.php` dengan isi:

```php
<?php
phpinfo();
```

**Menguji di browser:**

Buka browser, ketik: `http://perpustakaan.test`

> **Catatan:** Laragon otomatis membuat domain `.test` untuk tiap folder di `www\`. Jadi nama folder = nama domain.

Jika halaman `phpinfo()` muncul berisi informasi PHP (versi PHP, konfigurasi, dll), berarti Laragon berhasil terinstall dengan benar.

### B. Menggunakan XAMPP (Alternatif)

XAMPP juga sangat populer dan tersedia lintas platform.

**Langkah instalasi:**

1. Kunjungi [https://www.apachefriends.org/download.html](https://www.apachefriends.org/download.html)
2. Pilih versi PHP 8.x sesuai Windows kamu (32-bit/64-bit)
3. Jalankan installer → Next → Pilih komponen minimal: **Apache**, **MySQL**, **PHP** (sudah terpilih default)
4. Lokasi instalasi: biarkan default `C:\xampp\`
5. Selesai install, buka **XAMPP Control Panel**

**Menjalankan server:**

Klik **Start** pada kolom **Apache** dan **Start** pada kolom **MySQL**. Status akan berubah jadi hijau.

**Struktur folder XAMPP:**

Folder kerja ada di `C:\xampp\htdocs\`.

**Membuat project pertama:**

1. Buka folder `C:\xampp\htdocs\`
2. Buat folder baru: `perpustakaan`
3. Buat file `info.php` di dalamnya:

```php
<?php
phpinfo();
```

**Menguji di browser:**

Buka browser, ketik: `http://localhost/perpustakaan/info.php`

Jika halaman `phpinfo()` muncul, berarti XAMPP berhasil.

## Tracing Code (Step-by-Step)

Kita telusuri apa yang terjadi saat kita mengakses `info.php` melalui browser.

Kode yang ditelusuri:

```php
<?php
phpinfo();
```

**Langkah 1 — Browser mengirim request**

Kamu mengetik `http://localhost/perpustakaan/info.php` di browser. Browser mengirim **HTTP Request** ke alamat `localhost` (komputer sendiri) dengan port default web server (biasanya 80).

**Langkah 2 — Web Server menerima request**

Apache (di XAMPP/Laragon) mendengar request tersebut. Ia mencari file `info.php` di dalam folder kerja:

- Laragon: `C:\laragon\www\perpustakaan\info.php`
- XAMPP: `C:\xampp\htdocs\perpustakaan\info.php`

File ditemukan.

**Langkah 3 — Web Server meneruskan ke PHP Engine**

Karena ekstensi file adalah `.php`, Apache tidak mengirim file mentah. Ia meneruskan isi file ke **PHP Engine** untuk diproses.

**Langkah 4 — PHP Engine menjalankan kode**

PHP Engine membaca baris pertama: `<?php` (tag pembuka). Lalu membaca `phpinfo();`

Fungsi bawaan PHP `phpinfo()` dijalankan. Fungsi ini **menghasilkan output berupa tabel HTML** yang berisi seluruh informasi konfigurasi PHP yang sedang berjalan (versi PHP, ekstensi aktif, path, nilai konfigurasi php.ini, dll).

**Langkah 5 — PHP Engine mengembalikan output ke Web Server**

Hasil dari `phpinfo()` adalah **kode HTML panjang**. PHP Engine mengirim HTML tersebut kembali ke Apache.

**Langkah 6 — Web Server mengirim response ke browser**

Apache mengirimkan **HTTP Response** berisi `Content-Type: text/html` beserta seluruh kode HTML hasil `phpinfo()`.

**Langkah 7 — Browser merender halaman**

Browser menerima HTML, CSS, dan tabel dari response tersebut, lalu menampilkannya menjadi halaman `phpinfo()` yang kita lihat.

**Output akhir:** Halaman berisi informasi detail tentang PHP environment kita.

## Analogi

Bayangkan kamu ingin **menonton film** di ruang teater mini di rumahmu.

Untuk bisa menonton, kamu butuh beberapa hal:
- **Layar & proyektor (Web Server)** → menampilkan hasil ke penonton (browser)
- **Pemutar film (PHP Engine)** → memutar file film menjadi gambar & suara yang bisa ditampilkan
- **Rak DVD (Database Server)** → tempat menyimpan koleksi film (data)

Kalau kamu cuma punya file film `.mp4` di laptop dan langsung membukanya pakai aplikasi pemutar, itu seperti membuka `.php` langsung. Tapi kalau kamu pengen pengalaman "teater" seperti layaknya bioskop (bisa diakses lewat remote, terstruktur), kamu butuh sistem teater lengkap.

**XAMPP/Laragon** itu ibarat **paket teater mini 1 set**. Semua alatnya sudah digabung jadi satu: proyektor, pemutar, dan rak koleksi. Jadi kamu tinggal "nyalakan" teaternya (`Start All`), lalu "putar film" (`akses file .php lewat localhost`).

Konteks perpustakaan kita: server lokal ini adalah **ruang baca digital mini** milik kita sendiri, tempat kita menguji sistem perpustakaan sebelum benar-benar dipakai.

## Dipakai untuk Apa

- **Belajar PHP** — tempat latihan aman tanpa risiko merusak website online.
- **Menguji fitur baru** — coba form, session, database, API tanpa mempengaruhi project lain.
- **Membangun project portofolio** — sistem perpustakaan digital, blog, toko online lokal.
- **Simulasi production** — belajar alur request-response persis seperti hosting sungguhan.
- **Integrasi database** — bisa pakai phpMyAdmin untuk mengelola MySQL/MariaDB dengan mudah.
- **Rapid prototyping** — cepat buat ide jadi aplikasi web yang bisa langsung dicoba.

## Kesalahan Umum yang Sering Terjadi

- **Apache gagal start (port bentrok)** — Biasanya karena aplikasi lain pakai port 80/443 (Skype, IIS, VMware). Solusinya: ganti port di `httpd.conf` atau hentikan aplikasi yang bentrok.
- **Membuka file .php langsung di browser** — Hasilnya teks mentah. Solusinya: wajib akses via `http://localhost/...` atau `http://nama.test`.
- **Salah tempat menyimpan file** — File harus ada di `htdocs/` (XAMPP) atau `www/` (Laragon). Kalau di luar folder itu, server tidak bisa mengenali.
- **Firewall/Antivirus memblokir** — Kadang antivirus memblokir Apache/MySQL. Solusinya: izinkan akses atau tambahkan exception.
- **Lupa start Apache/MySQL** — Halaman akan muncul "This site can't be reached". Selalu pastikan `Start All` / `Apache+MySQL` dalam keadaan Running.
- **Menggunakan spasi di nama folder** — Hindari `Perpustakaan Baru`. Lebih aman pakai `perpustakaan` (huruf kecil, tanpa spasi).

## Soal Latihan & Jawaban

### Soal

Kamu baru saja memahami bahwa file `.php` harus dijalankan melalui web server. Sekarang, buktikan environment-mu sudah siap!

Tugasmu:
1. Buat folder `perpustakaan` di folder kerja (htdocs/www).
2. Buat file `tes-setup.php` dengan kode berikut:
   ```php
   <?php
   echo "Environment PHP berhasil berjalan!";
   echo "<br>";
   echo "Versi PHP: " . PHP_VERSION;
   ```
3. Akses file tersebut lewat browser dengan URL yang benar sesuai tools pilihanmu (XAMPP atau Laragon).
4. Jelaskan **mengapa** kita TIDAK boleh membuka file ini langsung dengan double-click di File Explorer.

### Jawaban

**Langkah praktis:**

- **Jika pakai Laragon:** simpan di `C:\laragon\www\perpustakaan\tes-setup.php` → akses `http://perpustakaan.test/tes-setup.php`
- **Jika pakai XAMPP:** simpan di `C:\xampp\htdocs\perpustakaan\tes-setup.php` → akses `http://localhost/perpustakaan/tes-setup.php`

**Isi file `tes-setup.php`:**

```php
<?php
echo "Environment PHP berhasil berjalan!";
echo "<br>";
echo "Versi PHP: " . PHP_VERSION;
```

**Jawaban penjelasan:**

Kita **tidak boleh** membuka file `.php` langsung dengan double-click karena:

- Saat dibuka langsung (file://), sistem operasi akan membuka file tersebut dengan text editor/browser sebagai **file mentah**.
- Browser akan menampilkan **kode PHP apa adanya** (`<?php ... ?>`), bukan hasil prosesnya.
- PHP Engine **hanya berjalan di dalam web server** (Apache). Tanpa web server, tidak ada yang memproses kode PHP menjadi HTML.
- Dengan mengakses lewat `http://localhost/...`, request dikirim ke Apache → diteruskan ke PHP Engine → diproses → dikembalikan sebagai HTML murni ke browser. Inilah alur yang benar sesuai cara kerja server-side.
