# File PHP — Simpan Data sebagai JSON

## Penjelasan

Sebelum menggunakan database seperti MySQL di Level 4, kita bisa menyimpan data secara **persisten** (tetap tersimpan meski browser ditutup) ke dalam **file**. Salah satu cara yang praktis adalah menyimpan data dalam format **JSON**.

Format JSON (`.json`) bersifat ringan, mudah dibaca manusia, dan sangat cocok dipadukan dengan PHP. PHP memiliki fungsi bawaan untuk mengolah JSON: `json_encode()` untuk mengubah array/objek jadi string JSON, dan `json_decode()` untuk mengubah string JSON jadi array/objek PHP.

Kita akan membuat sistem penyimpanan sederhana untuk **katalog buku perpustakaan**: membaca file JSON, menambah data, menghapus data, lalu menyimpannya kembali ke file.

## Fungsi

- **Menyimpan data secara persisten** tanpa perlu database server.
- **Mudah dipahami** untuk latihan CRUD (Create, Read, Update, Delete) dasar.
- **Belajar File I/O** di PHP (`file_exists`, `file_get_contents`, `file_put_contents`, `mkdir`).
- **Siap dipindah ke database** — pola logikanya mirip saat nanti pakai PDO.
- **Praktis untuk prototyping** sistem perpustakaan skala kecil.
- **Format portabel** — file JSON bisa dibaca aplikasi lain.

<?php

session_start();

ini_set('display_errors', 1);

// Lokasi file penyimpanan data
define('DATA_DIR', __DIR__ . '/data');
define('DATA_FILE', DATA_DIR . '/buku.json');

// Fungsi untuk membaca semua data buku
function bacaSemuaBuku(): array {
    if (!file_exists(DATA_FILE)) {
        return [];
    }
    $json = file_get_contents(DATA_FILE);
    if ($json === false || trim($json) === '') {
        return [];
    }
    $data = json_decode($json, true);
    return is_array($data) ? $data : [];
}

// Fungsi untuk menyimpan semua data buku
function simpanSemuaBuku(array $buku): bool {
    // Buat folder jika belum ada
    if (!is_dir(DATA_DIR)) {
        mkdir(DATA_DIR, 0755, true);
    }
    // Konversi array ke JSON (rapi + support unicode)
    $json = json_encode($buku, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);
    if ($json === false) {
        return false;
    }
    // Tulis ke file
    return file_put_contents(DATA_FILE, $json) !== false;
}

// Fungsi untuk menambah buku
function tambahBuku(array $dataBaru): array {
    $buku = bacaSemuaBuku();
    // Cari ID terbesar
    $maxId = 0;
    foreach ($buku as $b) {
        if (isset($b['id']) && $b['id'] > $maxId) {
            $maxId = $b['id'];
        }
    }
    // Generate ID baru
    $dataBaru['id'] = $maxId + 1;
    $dataBaru['created_at'] = date('Y-m-d H:i:s');
    // Tambahkan ke array
    $buku[] = $dataBaru;
    // Simpan
    simpanSemuaBuku($buku);
    return $dataBaru;
}

// Fungsi untuk menghapus buku berdasarkan ID
function hapusBuku(int $id): bool {
    $buku = bacaSemuaBuku();
    $baru = [];
    $berhasil = false;
    foreach ($buku as $b) {
        if (isset($b['id']) && $b['id'] === $id) {
            // Lewati (dihapus)
            $berhasil = true;
            continue;
        }
        $baru[] = $b;
    }
    if ($berhasil) {
        simpanSemuaBuku(array_values($baru));
    }
    return $berhasil;
}

## Tracing Code (Step-by-Step)

Kita telusuri alur saat klik **"Tambah Data Demo"** (`?tambah=demo`).

**Langkah 1 — Browser mengirim GET `?tambah=demo`**

Klik link `href="?tambah=demo"`. Browser mengirim HTTP GET ke `22-file-json.php?tambah=demo`.

**Langkah 2 — Kondisi terpenuhi**

```php
if (isset($_GET['tambah']) && $_GET['tambah'] === 'demo') { ... }
```
Kondisi true → masuk blok.

**Langkah 3 — Panggil `tambahBuku([...])`**

Fungsi `tambahBuku()` dipanggil dengan array data demo:
```php

  'judul' => 'Clean Code',
  'pengarang' => 'Robert C. Martin',
  'tahun' => 2008,
  'harga' => 150000,
  'stok' => 5,

```

**Langkah 4 — `bacaSemuaBuku()` dijalankan**

Fungsi membaca file `data/buku.json`. Karena file **belum ada** (pertama kali), `file_exists(DATA_FILE)` return false → fungsi mengembalikan `[]` (array kosong).

**Langkah 5 — Generate ID baru**

Looping array kosong, `$maxId` tetap `0`. Maka `$dataBaru['id'] = 0 + 1 = 1`.

**Langkah 6 — Tambah timestamp**

`$dataBaru['created_at'] = date('Y-m-d H:i:s')` → misal `"2025-10-17 10:00:00"`.

**Langkah 7 — Gabung array**

`$buku[] = $dataBaru` → array `$buku` sekarang berisi 1 elemen (data buku dengan id=1).

**Langkah 8 — Panggil `simpanSemuaBuku($buku)`**

Fungsi `simpanSemuaBuku()`:
- Cek `is_dir(DATA_DIR)` → folder `data/` belum ada → `mkdir(DATA_DIR, 0755, true)` membuat folder.
- `json_encode($buku, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE)` mengkonversi array menjadi string JSON terformat:
```json
[
    {
        "judul": "Clean Code",
        "pengarang": "Robert C. Martin",
        "tahun": 2008,
        "harga": 150000,
        "stok": 5,
        "id": 1,
        "created_at": "2025-10-17 10:00:00"
    }
]
```
- `file_put_contents(DATA_FILE, $json)` menulis string JSON ke file `data/buku.json`. Return true/false.

**Langkah 9 — Redirect**

Setelah simpan berhasil, `header('Location: 22-file-json.php'); exit;` redirect kembali ke halaman tanpa query string.

**Langkah 10 — Halaman dimuat ulang & menampilkan data**

Saat halaman dimuat ulang, `bacaSemuaBuku()` dipanggil. Kali ini `file_exists` true → `file_get_contents` membaca isi file JSON → `json_decode($json, true)` mengubah kembali jadi array PHP. Array berisi 1 buku, lalu ditampilkan dalam tabel HTML.

**Kesimpulan Tracing:** Data **tetap tersimpan** di file `data/buku.json` meski kita close browser/restart server. Saat halaman dibuka kembali, data otomatis terbaca.

## Analogi

Bayangkan **buku inventaris perpustakaan** (buku catatan fisik) yang digunakan petugas untuk mencatat koleksi buku.

- **File `buku.json`** → Ibarat **buku inventaris** itu sendiri. Semua data koleksi buku tertulis di dalamnya.
- **`bacaSemuaBuku()`** → Ibarat petugas **membuka buku inventaris** dan membaca seluruh daftar buku yang ada.
- **`tambahBuku()`** → Ibarat petugas **menulis entri baru** di buku inventaris: mencatat judul, pengarang, tahun, harga, stok, lalu memberi nomor urut (ID).
- **`simpanSemuaBuku()`** → Ibarat petugas **menyimpan kembali** buku inventaris dengan rapi setelah menulis.
- **`json_encode`** → Ibarat **menterjemahkan** catatan berstruktur (array) menjadi tulisan yang seragam & mudah disimpan.
- **`json_decode`** → Ibarat **menterjemahkan kembali** tulisan JSON menjadi bentuk yang bisa dipahami & diolah PHP.
- **`mkdir`** → Ibarat membuat **map/sampul folder arsip** baru kalau belum ada.

Kekuatan analogi: **buku inventaris tetap ada** meski petugas pulang. Besok petugas bisa buka lagi dan semua data masih utuh. Persis seperti file JSON yang persisten.

## Kesalahan Umum yang Sering Terjadi

- **Lupa `mkdir()`** → Jika folder `data/` belum ada, `file_put_contents` akan gagal (Permission denied / gagal tulis).
- **JSON rusak** → Kalau file `buku.json` di-edit manual & salah format, `json_decode` return null → perlu handle (`is_array` check).
- **File kosong** → Saat file baru dibuat tapi kosong, `trim($json)===''` bisa terjadi → return array kosong (sudah di-handle).
- **Lupa `JSON_UNESCAPED_UNICODE`** → Karakter Indonesia (é, á, dll) bisa jadi `\u00e9` kurang enak dibaca.
- **Lupa `JSON_PRETTY_PRINT`** → JSON jadi 1 baris, susah dibaca saat debug.
- **ID duplikat** → Kalau tidak hitung `maxId` dengan benar, bisa bentrok. Solusi: ambil max dari ID yang ada.
- **File permission** → Di server tertentu, perlu permission 0755/0644. Saat belajar lokal jarang masalah.
- **Direct access berbahaya** — file `.json` bisa diakses langsung via browser kalau diletak di web root. Solusi: letak di folder diluar `public/` atau tambahkan `.htaccess`. Untuk latihan ini masih aman.
- **Overwrite data** — `file_put_contents` dengan mode default menimpa. Kita mau menimpa seluruh file (benar untuk pendekatan ini).
- **Lupa `array_values()`** setelah filter — index bisa tidak berurutan (opsional).
