# String Syntax — Single Quote vs Double Quote

## Penjelasan

**String** adalah tipe data yang berisi kumpulan karakter (huruf, angka, simbol). Di PHP, kita bisa menulis string dengan **dua cara**: menggunakan **single quote (`'...'`)** atau **double quote (`"..."`)**.

Perbedaan utamanya terletak pada **interpolasi variabel** dan **escape sequence**.

- **Double quote (`"..."`)** → PHP akan **memproses** variabel yang ada di dalam string dan beberapa karakter escape seperti `\n`, `\t`, `\"`.
- **Single quote (`'...'`)** → PHP **TIDAK memproses** variabel maupun escape sequence (kecuali `\\` dan `\'`).

Selain itu, PHP juga menyediakan **Heredoc** (`<<<EOT ... EOT`) dan **Nowdoc** (`<<<'EOT' ... EOT`) untuk menulis string multi-baris dengan lebih nyaman.

Pemahaman ini penting agar kita bisa memilih cara penulisan string yang tepat dan efisien.

## Fungsi

- **Menentukan kapan variabel bisa langsung dimasukkan ke string** tanpa perlu tanda titik (`.`).
- **Menghemat penulisan kode** saat menggabungkan teks dan variabel.
- **Memilih cara paling efisien** — single quote sedikit lebih cepat karena tidak ada parsing variabel.
- **Menulis string kompleks** (multi-baris, HTML) dengan lebih rapi menggunakan Heredoc/Nowdoc.
- **Menghindari salah tafsir** saat string mengandung tanda kutip atau variabel.
- **Cocok untuk konteks perpustakaan** — merangkai pesan, judul buku, notifikasi dinamis.

## Tracing Code (Step-by-Step)

Kita fokus ke perbedaan single quote vs double quote.

### Tracing A: Double Quote dengan variabel

```php
echo "Buku \"$judulBuku\" oleh $pengarang";
```

**Langkah 1 — PHP membaca string dalam double quote**

Saat bertemu `"..."`, PHP tahu: "Aku harus **memeriksa** isi string ini. Ada variabel atau escape sequence kah?"

**Langkah 2 — Menemukan escape `\"`**

`\` sebelum `"` artinya **escape** → cetak tanda kutip, bukan tutup string.

**Langkah 3 — Menemukan variabel `$judulBuku`**

PHP melihat `$judulBuku` dan menggantinya dengan nilai `"Clean Code"`. Begitu juga `$pengarang` → `"Robert C. Martin"`.

**Hasil:** `Buku "Clean Code" oleh Robert C. Martin`

### Tracing B: Single Quote dengan variabel

```php
echo 'Buku "$judulBuku" oleh $pengarang';
```

**Langkah 1 — PHP membaca single quote `'...'`**

PHP tahu: **JANGAN proses variabel**. Hanya escape `\\` dan `\'` yang diproses.

**Langkah 2 — `$judulBuku` dan `$pengarang` tetap apa adanya**

Karena dalam single quote, PHP tidak menggantinya. Tanda `$` dicetak sebagai karakter literal.

**Hasil:** `Buku "$judulBuku" oleh $pengarang`

### Tracing C: Escape sequence `\n` dan `\t`

- **Double quote**: `\n` → baris baru (newline), `\t` → tab
- **Single quote**: `\n` dan `\t` **dicetak persis** sebagai huruf `\`, `n`, `\`, `t`

Itu sebabnya di browser, single quote menampilkan `\nBaris 2\t(Tab)` karena browser merender sebagai spasi biasa, bukan baris baru. Kalau mau lihat efek nyata, bisa pakai `nl2br()` atau lihat source HTML.

### Tracing D: Heredoc `<<<EOT ... EOT`

```php
$deskripsiBuku = <<<EOT
<strong>Judul:</strong> $judulBuku
...
EOT;
```

- **Identifier** `EOT` bisa bebas (EOD, TXT, dll)
- Baris setelah `<<<EOT` langsung isi string (tidak boleh ada spasi)
- **Semua variabel diproses** seperti double quote
- Sangat nyaman untuk HTML multi-baris
- Penutup `EOT` harus **di awal baris**, tanpa indentasi (kecuali konfigurasi khusus)

### Tracing E: Nowdoc `<<<'EOT' ... EOT`

Sama seperti Heredoc, tapi identifier **dalam single quote** `<<<'EOT'`. Akibatnya **variabel TIDAK diproses**. Cocok untuk template mentah yang tidak butuh interpolasi.

## Analogi

Bayangkan petugas perpustakaan sedang **menulis label buku**.

Ada dua cara menulis:

- **Double quote = "Label Dinamis"**  
  Petugas punya template: *"Judul: [NAMA_BUKU] oleh [PENGARANG]"*. Saat menulis, ia **mengisi langsung** nama buku & pengarang yang sebenarnya ke dalam template. Hasilnya jadi label jadi yang sudah lengkap.

- **Single quote = 'Label Statis'**  
  Petugas menulis persis apa yang ada di kertas: *"[NAMA_BUKU]"* ditulis dengan huruf `$`, `N`, `A`, `M`, `A` bukan diganti nama bukunya. Cocok kalau yang mau ditulis **justru teks literal** `$judulBuku`.

**Heredoc** ibarat **formulir panjang** (deskripsi buku lengkap) yang bisa diisi banyak baris dan ada tempat kosong untuk data dinamis.

**Nowdoc** ibarat **contoh/template cetakan** yang mau dipertahankan **persis** seperti aslinya, tanpa diganti isinya.

Konteks perpustakaan: untuk **pesan notifikasi dinamis** (Halo [nama anggota], buku [judul] siap dipinjam) pakai double quote/Heredoc. Untuk **HTML template statis** tanpa variabel, single quote lebih aman & efisien.

## Dipakai untuk Apa

- **Merangkai pesan dinamis** — notifikasi ke anggota: "Buku $judul berhasil dipinjam"
- **Membuat link HTML** — single quote cocok karena isinya statis
- **Menulis deskripsi multi-baris** — Heredoc praktis untuk konten panjang
- **Template email/SMS** — bisa pakai Nowdoc kalau mau template mentah
- **Menyisipkan data ke string** — double quote menghemat `.` berulang
- **Menampilkan teks dengan kutip** — hindari konflik tanda kutip
- **Membuat output HTML terstruktur** — Heredoc bikin kode lebih bersih

## Kesalahan Umum yang Sering Terjadi

- **Menyangka single quote bisa proses variabel** — Hasilnya variabel muncul sebagai `$nama` literal.
- **Lupa escape kutip** — `"Dia berkata "Halo""` salah. Harus `"Dia berkata \"Halo\""` atau pakai single quote `'Dia berkata "Halo"'`.
- **Salah indentasi penutup Heredoc** — Penutup `EOT;` **harus** di kolom paling kiri (no spaces/tabs) di barisnya sendiri.
- **Spasi setelah `<<<EOT`** — Tidak boleh ada spasi: `<<< EOT` salah.
- **Pilih double quote padahal tidak butuh interpolasi** — Boleh, tapi single quote lebih ringan & eksplisit.
- **Keliru pakai `\n` di single quote** — Tidak jadi baris baru. Gunakan `\n` hanya di double quote, atau pakai `<br>` + `nl2br()`.
- **Heredoc/Nowdoc tanpa identifier konsisten** — Identifier penutup harus **persis** sama dengan pembuka.
- **Mencampur PHP tag `<?=` di dalam Heredoc** — `<?=` bisa dipakai, tapi kadang kurang jelas. Lebih aman pakai `{$hargaBuku}` atau hitung dulu di luar.
