# String Functions — Yang Paling Sering Digunakan

## Penjelasan

Setelah paham cara menulis string (Poin 11), kita perlu belajar **memanipulasi string**. PHP menyediakan ratusan fungsi string, tapi untuk pemula kita cukup fokus pada yang **paling sering dipakai** di sistem perpustakaan.

Fungsi-fungsi ini berguna untuk: membersihkan input user (`trim`), mengubah huruf besar/kecil (`strtoupper`, `strtolower`), mencari teks (`strpos`, `str_contains`), mengganti teks (`str_replace`), memotong string (`substr`), memecah & menggabung string (`explode`, `implode`), memformat angka (`number_format`), dan lainnya.

Kita juga akan pakai fungsi PHP 8: `str_contains`, `str_starts_with`, `str_ends_with` yang jauh lebih mudah dipahami ketimbang cara lama.

## Fungsi

- **Membersihkan input** — hapus spasi berlebih dengan `trim`, `ltrim`, `rtrim`
- **Standarisasi huruf** — seragamkan kapitalisasi judul buku/nama anggota
- **Pencarian & validasi** — cek keberadaan kata/format (ISBN, email)
- **Penggantian teks** — bersihkan karakter tidak diinginkan (tanda hubung ISBN)
- **Memotong/pemecahan** — olah data terpisah (mis. "AGT-001" dipisah)
- **Formatting** — tampilkan harga dalam format rupiah `number_format`
- **Sanitasi dasar** — persiapan sebelum validasi/simpan ke database
- **Meningkatkan UX** — tampilkan teks lebih rapi di halaman web

## Tracing Code (Step-by-Step)

Kita telusuri beberapa fungsi kunci.

### Tracing A: `trim($judulKotor)`

`$judulKotor = "   clean code   "` (ada 3 spasi kiri, 3 spasi kanan)

`trim()` menghapus **whitespace** dari kedua sisi → `"clean code"`

### Tracing B: `strtolower(trim($email))`

Rantai pemanggilan dievaluasi dari dalam ke luar:
1. `trim($email)` → hapus spasi
2. `strtolower(...)` → ubah semua jadi huruf kecil

Hasil: `"andi.wijaya@gmail.com"` siap dibandingkan/validasi.

### Tracing C: `str_contains($teks, "Perpustakaan")`

PHP 8 function. Mencari apakah substring `"Perpustakaan"` **ada** di dalam `$teks`.

Karena ada → mengembalikan **true**. Sangat lebih readable ketimbang `strpos(...) !== false`.

### Tracing D: `str_replace("-", "", $isbn)`

Mencari semua `"-"` di `"978-0-13-235088-4"`, ganti dengan `""` (kosong). Hasil: `"9780132350884"`. Cocok disimpan ke database tanpa pemisah.

### Tracing E: `explode("-", $isbn)`

Memecah string berdasarkan delimiter `"-"`. Menghasilkan **array**:
`["978", "0", "13", "235088", "4"]`

Kebalikan dari `implode()` yang menggabung array jadi string.

### Tracing F: Rantai `implode(" ", array_map('ucfirst', explode(" ", $nama)))`

Urutan eksekusi dari dalam keluar:

1. `explode(" ", $nama)` → `["andi", "wijaya", "saputra"]`
2. `array_map('ucfirst', ...)` → ubah tiap elemen jadi `ucfirst`: `["Andi", "Wijaya", "Saputra"]`
3. `implode(" ", ...)` → gabung dengan spasi: `"Andi Wijaya Saputra"`

Ini contoh praktis mengubah nama jadi **Title Case**.

## Analogi

Bayangkan petugas perpustakaan sedang **merapikan data anggota baru** dari formulir kertas.

Formulir terisi:
- Nama: `"  andi wijaya  "` (ada spasi)
- Email: `"ANDI@GMAIL.COM"`
- ISBN: `"978-0-13-235088-4"`

Petugas melakukan serangkaian "pembersihan":

- **trim()** → seperti menghapus noda/spasi berlebih di pinggir kertas
- **strtolower/ucwords** → merapikan penulisan nama biar seragam di kartu anggota
- **str_replace** → menghapus tanda strip dari ISBN biar rapi di sistem komputer
- **explode/implode** → memecah nama jadi bagian-bagian, merapikan tiap bagian, lalu menyatukan kembali
- **number_format** → mencetak label harga dengan pemisah ribuan biar mudah dibaca pengunjung

Semua fungsi ini adalah **"alat rapi-rapi data"** petugas perpustakaan sebelum data masuk ke buku induk (database).

## Dipakai untuk Apa

- **Form validation & sanitasi** — bersihkan input sebelum disimpan
- **Normalisasi email** — ubah jadi lowercase agar pencocokan konsisten
- **Formatting harga** — tampilkan Rp 150.000 di halaman web
- **Generate ID** — gabung prefix + angka dengan `str_pad`
- **Cek ekstensi file** — `str_ends_with($file, '.pdf')`
- **Filter pencarian** — `str_contains` untuk search buku
- **Validasi format** — cek awalan ID anggota `str_starts_with($id, 'AGT')`
- **Bersihkan ISBN** — hapus tanda hubung/spasi
- **Rapikan nama** — Title Case untuk tampilan
- **Parsing data sederhana** — pecah string berdelimiter

## Kesalahan Umum yang Sering Terjadi

- **Lupa trim() saat validasi** — `" test@mail.com "` bisa lolos tapi sebaiknya dibersihkan
- **Pakai strpos() tanpa !== false** — `strpos('abc','a')` return `0` (index pertama) yang dianggap **falsy**. Jadi cek `!== false`.
- **str_contains butuh PHP 8** — Kalau project masih PHP 7.x, harus pakai `strpos`.
- **substr salah index** — index mulai dari 0. Sangat umum keliru.
- **explode dengan delimiter tidak ditemukan** — mengembalikan array berisi 1 elemen (string utuh). Bukan error.
- **number_format menambah koma** — hasilnya string, bukan angka. Jangan dipakai untuk kalkulasi lagi.
- **strtolower untuk nama** — bisa salah untuk nama unik, tapi umumnya aman.
- **str_pad terlalu panjang** — perhatikan panjang yang diinginkan.
- **Mengabaikan case saat bandingkan** — pakai `strcasecmp()` atau `strtolower` kedua sisi.
