# Closure & Arrow Function — Fungsi Anonim

## Penjelasan

**Fungsi anonim** adalah fungsi yang **tidak memiliki nama**. Di PHP, fungsi anonim dibagi menjadi dua jenis utama:

1. **Closure** (`Closure`) — fungsi anonim yang bisa **"menangkap" (capture)** variabel dari scope luar menggunakan keyword `use()`.
2. **Arrow Function** (`fn()`) — diperkenalkan di PHP 7.4+, lebih ringkas. Arrow function **secara otomatis menangkap variabel** dari scope luar (tanpa perlu `use()`).

Fungsi anonim ini biasa dipakai sebagai **callback** (argumen fungsi lain), terutama saat bekerja dengan **array functions** seperti `array_filter`, `array_map`, `usort`, dan `array_reduce` yang sudah kita pelajari di Poin 14.

Konsep ini disebut **Higher-Order Function**: fungsi yang bisa menerima fungsi lain sebagai parameter, atau mengembalikan fungsi lain.

## Fungsi

- **Membuat callback ringkas** — ideal untuk filter, map, sort tanpa harus buat fungsi terpisah.
- **Mengurangi clutter** — cukup tulis logika inline di tempat dipakai.
- **Closure bisa capture variabel luar** — berguna untuk filter dinamis (misal harga maksimal).
- **Arrow function lebih ringkas** — sintaks lebih pendek, auto-capture variabel dari parent scope.
- **Mengembalikan fungsi** — bisa dipakai untuk membuat "factory function" (fungsi pembuat fungsi).
- **Praktis untuk sistem perpustakaan** — filter buku tersedia, sort berdasarkan harga, pencarian dinamis, dll.
- **Menjembatani ke OOP & Closure modern** — sering dipakai di framework (Laravel, Symfony).

**Catatan:** Arrow function (`fn`) di PHP **tidak bisa** memiliki blok `{ ... }` multiple statements dan **tidak bisa** pakai `use()`. Ia otomatis capture **semua variabel dari scope induk** secara nilai (by value) secara default, dan bersifat readonly untuk variabel yang di-capture.

## Tracing Code (Step-by-Step)

### Tracing A: Closure dengan `use($hargaMaks)`

```php
$hargaMaks = 140000;
$terjangkau = array_filter($katalog, function($buku) use ($hargaMaks) {
    return $buku['harga'] <= $hargaMaks;
});
```

**Langkah 1 — Variabel `$hargaMaks` ada di scope luar**

Nilai `$hargaMaks = 140000` terdefinisi di scope global/file.

**Langkah 2 — Closure dibuat**

Fungsi anonim `function($buku) { ... }` dibuat. Tanpa `use()`, closure **tidak bisa mengakses** `$hargaMaks` dari luar.

**Langkah 3 — `use($hargaMaks)` menangkap variabel**

Keyword `use($hargaMaks)` memberitahu PHP: *"Ambil nilai `$hargaMaks` dari scope luar saat closure ini dibuat, lalu simpan di dalam closure"*. Capture terjadi **by value** (nilai saat ini disalin).

**Langkah 4 — array_filter memanggil closure per elemen**

Untuk tiap elemen `$buku` di `$katalog`, closure dipanggil. Ia mengevaluasi `return $buku['harga'] <= 140000`. Elemen yang hasilnya `true` dipertahankan.

**Hasil:** Buku dengan harga <= 140000 (Sapiens 120000, Atomic Habits 135000, Laskar Pelangi 85000) lolos filter.

### Tracing B: Arrow Function `fn()` Auto-Capture

```php
$hargaMaks2 = 140000;
$terjangkau2 = array_filter($katalog, fn($buku) => $buku['harga'] <= $hargaMaks2);
```

**Langkah 1 — Arrow function `fn($buku) => ...`**

Tidak ada `use()`, tapi PHP **otomatis menangkap semua variabel yang digunakan** dari scope parent (dalam hal ini `$hargaMaks2`).

**Langkah 2 — Evaluasi per elemen**

Sama seperti closure, dipanggil berulang oleh `array_filter`. Hasilnya identik dengan closure di atas.

**Perbedaan kunci:** Arrow function **lebih ringkas**, tidak perlu `use()`. Cocok untuk ekspresi sederhana (single expression return implisit).

### Tracing C: Factory Function `buatFilter`

```php
function buatFilter(string $field, mixed $nilai): Closure {
    return fn($buku) => $buku[$field] === $nilai;
}
$filterTeknologi = buatFilter('kategori', 'Teknologi');
```

**Langkah 1 — Panggil `buatFilter('kategori', 'Teknologi')`**

Fungsi ini mengembalikan **sebuah closure/arrow function**. Parameter `$field='kategori'`, `$nilai='Teknologi'` masuk ke scope factory.

**Langkah 2 — Arrow function dibuat & dikembalikan**

Arrow function `fn($buku) => $buku[$field] === $nilai` dibuat. Ia **menangkap `$field` dan `$nilai`** dari scope `buatFilter` (parent scope). Closure ini "membawa" kedua nilai tersebut bersamanya.

**Langkah 3 — Simpan sebagai `$filterTeknologi`**

Sekarang `$filterTeknologi` adalah **fungsi yang bisa dipanggil**: saat dipanggil dengan `$buku`, ia mengembalikan `true` jika kategori == 'Teknologi'.

**Langkah 4 — Kombinasi filter**

`array_filter($katalog, fn($b) => $filterTeknologi($b) && $filterTersedia($b))` menerapkan **dua kondisi** sekaligus (buku Teknologi AND stok > 0).

## Analogi

Bayangkan petugas perpustakaan sedang **menyaring buku sesuai permintaan pengunjung**.

- **Closure `function($b) use($hargaMaks)`** → Seperti petugas yang **membawa catatan kecil** bertulis "Maksimal Rp 140.000" di tangannya (`use`). Saat memeriksa tiap buku, ia melihat harga buku, lalu membandingkan dengan catatan di tangannya. Catatan itu "dibawa" bersamanya saat melakukan penyaringan.
- **Arrow Function `fn($b) => ...`** → Versi lebih praktis: petugas **langsung ingat** batas harga itu tanpa perlu membawa catatan fisik. Otomatis "terbawa ingatan"-nya.
- **Factory Function `buatFilter()`** → Seperti **mesin cetak filter khusus**. Kita bilang "Buatkan aku filter untuk kategori 'Teknologi'". Mesin itu mencetak **alat penyaring khusus** yang siap dipakai berulang kali untuk menyaring buku Teknologi.
- **Callback di `array_filter`** → Seperti petugas yang **menerima instruksi penyaringan** (aturan filter) dan menerapkannya ke tiap buku di rak satu per satu.

Dengan analogi perpustakaan: kita bisa membuat "aturan filter dinamis" sesuai permintaan pengunjung (berdasarkan harga, kategori, ketersediaan stok) dan menerapkannya ke seluruh katalog.

## Dipakai untuk Apa

- **Array functions** — filter, map, sort, reduce dengan logika dinamis
- **Validasi fleksibel** — buat rule filter berdasarkan input user
- **Fitur pencarian/filter dinamis** — filter buku berdasarkan harga maks, kategori, status
- **Sorting kustom** — `usort` dengan aturan kompleks
- **Factory/Builder pattern sederhana** — menghasilkan fungsi sesuai parameter
- **Event/callback** — umum di library modern
- **Memoization sederhana** — bisa dibungkus closure
- **Kode lebih bersih** — hindari bikin banyak named function kecil yang dipakai sekali

## Kesalahan Umum yang Sering Terjadi

- **Lupa `use()` di Closure** — Error `Undefined variable`. Solusinya tambahkan `use($var)`.
- **Keliru pakai Arrow vs Closure** — Arrow **tidak bisa** pakai blok kode multi-statement atau statement seperti `if` kompleks dengan `{}` berganda. Cocok ekspresi tunggal.
- **Berpikir Arrow capture by reference** — Di PHP, arrow function **capture by value** untuk variabel luar (readonly). Tidak bisa mengubah variabel luar langsung.
- **Closure capture by value default** — `use($x)` itu **by value**. Kalau mau ubah variabel luar, pakai `use(&$x)` (by reference).
- **Return salah di factory** — Pastikan return type `Closure` atau `callable`.
- **Arrow function terlalu kompleks** — Kalau butuh banyak baris logika, lebih baik pakai Closure.
- **Terlalu banyak nesting** — Callback bersarang bisa susah dibaca, pertimbangkan ekstrak jadi variabel.
- **Lupa titik koma setelah assignment closure** — `$sapa = function() {...};` wajib titik koma.
