# Fungsi — Definisi, Parameter & Return

## Penjelasan

**Fungsi** adalah blok kode yang bisa dipanggil berulang untuk menyelesaikan tugas tertentu. Tujuannya: **menghindari duplikasi kode (DRY - Don't Repeat Yourself)** dan membuat kode lebih terorganisir.

Di PHP, kita bisa membuat **named function** (fungsi bernama) dengan kata kunci `function`. Fungsi bisa menerima **parameter**, punya **nilai default**, dan bisa **mengembalikan nilai** lewat `return`.

Sejak PHP 7+, kita bisa pakai **type hinting** (menentukan tipe parameter & return type). Sejak PHP 8, ada **named arguments** yang mempermudah pemanggilan fungsi dengan parameter banyak.

Untuk sistem perpustakaan, fungsi sangat berguna: `hitungDenda()`, `formatHarga()`, `cariBuku()`, `cekBisaPinjam()`, dll.

## Fungsi

- **Reusable** — panggil berkali-kali tanpa copy-paste
- **Modular** — pisahkan logika jadi unit kecil
- **Mudah diuji** — fungsi terpisah lebih gampang dicek
- **Baca lebih jelas** — nama fungsi menjelaskan tujuannya
- **Type safety** — type hint mencegah salah input
- **Fleksibel** — parameter default + named arguments
- **Cocok untuk utility** — formatter, kalkulator, validator
- **Fondasi OOP** — method di class mirip fungsi

## Tracing Code (Step-by-Step)

### Tracing A: `function hitungDenda(int $hariTerlambat, int $tarif = DENDA_PER_HARI): int`

- Parameter `$tarif` punya **default value** → boleh dipanggil tanpa argumen kedua
- `return $hariTerlambat * $tarif` mengembalikan nilai int
- Pemanggilan `hitungDenda(3)` → return 3000
- Pemanggilan `hitungDenda(3,2000)` → override default jadi 6000

### Tracing B: Named arguments `buatID(prefix: 'AGT', nomor: 5)`

Kita sebut nama parameter saat memanggil. Jadi **urutan tidak wajib** sama dengan definisi. Sangat berguna kalau fungsi punya banyak parameter opsional.

### Tracing C: `?array` return type

Fungsi boleh return `array` **atau** `null`. Saat data tidak ditemukan, return `null`. Di pemanggilan, kita **wajib cek** `!== null` sebelum akses key.

### Tracing D: Variadic `...$harga`

Tanda `...` berarti "kumpulkan semua argumen ekstra jadi array". `totalHarga(150000,85000,120000)` → `$harga` jadi `[150000,85000,120000]`. Lalu kita loop & jumlahkan.

## Analogi

Bayangkan petugas perpustakaan punya **beragam tugas rutin**.

- **Fungsi `hitungDenda()`** → seperti "kalkulator denda" standar. Petugas tinggal masukkan jumlah hari, langsung dapat hasil.
- **Fungsi `formatHarga()`** → seperti "mesin cetak label harga" yang selalu format Rp X.XXX.XXX seragam.
- **Fungsi `cariBukuById()`** → seperti "petugas pencari" yang tahu cara mencari di katalog. Kita tanya ID, dia balas datanya atau bilang "tidak ada".
- **Parameter default** → seperti "aturan default": kalau tidak disebut tarif khusus, pakai tarif umum.
- **Named arguments** → seperti mengisi formulir dengan **mencantumkan label** "Nama: ..., Nomor: ..." biar tidak salah urutan.
- **Variadic** → seperti menghitung **total belanja** meski jumlah bukunya beda-beda tiap transaksi.

Semua ini adalah "prosedur baku" yang bisa dipakai berulang tanpa mengulang penjelasan.

- **Pencarian** — cari di array/katalog
- **CRUD logic** — pisah logic dari tampilan

- **Reusable di banyak halaman** — bisa dipanggil ulang

## Kesalahan Umum yang Sering Terjadi

- **Fungsi dipanggil sebelum didefinisikan** — di file sama aman, tapi kalau dipanggil dari file lain urutan load penting
- **Lupa `return` padahal butuh nilai** — fungsi return `int` tapi tanpa return → `null` (bisa warning)
- **Type hint strict_types** — default PHP loose, tapi aman biasakan konsisten
- **Nullable return tapi lupa cek null** → bisa `Trying to access array offset on null`
- **Parameter default harus di kanan** — `function f($a=1,$b)` boleh? `$b` tanpa default harus di kiri? Salah: default wajib **di kanan**: `function f($a, $b=1)`
- **Variadic harus paling akhir** — `function f(...$args, $x)` tidak boleh
- **Named arguments dengan variadic** — bisa, tapi perlu hati-hati
- **Terlalu banyak parameter** (>4–5) → pertimbangkan pakai array/object

```php
<?php
// File: 16-latihan-fungsi.php

error_reporting(E_ALL);
ini_set('display_errors', 1);

define('BATAS_PINJAM',5);

function formatRupiah(int|float $nominal): string {
    return 'Rp '.number_format($nominal,0,',','.');
}

function hitungDenda(int $hari, int $tarif=1000): int {
    return $hari < 0 ? 0 : $hari*$tarif;
}

function bisaPinjam(int $stok, int $jumlah, bool $sudahLogin, int $kuotaTersisa): bool {
    if(!$sudahLogin) return false;
    if($stok<=0) return false;
    if($jumlah<=0) return false;
    if($jumlah>BATAS_PINJAM) return false;
    if($jumlah>$kuotaTersisa) return false;
    return true;
}

function cariBuku(array $katalog, string $keyword): array {
    $k = strtolower(trim($keyword));
    $res = array_filter($katalog, fn($b)=>str_contains(strtolower($b['judul']),$k)||str_contains(strtolower($b['pengarang']),$k));
    return array_values($res);
}

function getStatusStok(int $stok): string {
    if($stok<=0) return 'Habis';
    if($stok<=2) return 'Menipis';
    return 'Tersedia';
}

    ['id'=>1,'judul'=>'Clean Code','pengarang'=>'Robert C. Martin','harga'=>150000,'stok'=>5],
    ['id'=>2,'judul'=>'Atomic Habits','pengarang'=>'James Clear','harga'=>135000,'stok'=>1],
];
?>
```
