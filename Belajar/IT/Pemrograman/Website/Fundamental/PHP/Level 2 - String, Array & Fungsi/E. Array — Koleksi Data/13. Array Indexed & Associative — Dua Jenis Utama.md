# Array Indexed & Associative — Dua Jenis Utama

## Penjelasan

**Array** adalah tipe data yang bisa menyimpan **banyak nilai** dalam satu variabel. Berbeda dengan variabel biasa yang cuma bisa simpan **satu nilai**, array bisa simpan koleksi data (daftar buku, daftar anggota, daftar kategori, dll).

Di PHP, ada **dua jenis array utama**:

1. **Indexed Array** — key-nya berupa **angka berurutan** (0,1,2,...). Cocok untuk daftar sederhana.
2. **Associative Array** — key-nya berupa **string** (nama kunci). Cocok untuk data berstruktur seperti "judul", "pengarang", "harga".

PHP juga mendukung **Multidimensional Array** (array di dalam array), yang sangat berguna untuk merepresentasikan katalog buku dalam sistem perpustakaan.

Kunci array: akses pakai `[]` → `$array[0]` atau `$array['judul']`.

## Fungsi

- **Mengelompokkan data** — satu variabel untuk banyak data terkait
- **Merepresentasikan objek sederhana** — buku, anggota, peminjaman
- **Membangun katalog** — daftar banyak buku dalam satu struktur
- **Mempermudah looping** — bisa tampilkan semua dengan `foreach`
- **Menjadi pondasi CRUD** — tambah/ubah/hapus data kolektif
- **Mendukung relasi sederhana** — array multidimensi
- **Lebih efisien** ketimbang bikin banyak variabel terpisah

## Tracing Code (Step-by-Step)

### Tracing A: Indexed Array `$kategori = ['Fiksi', ...];`

PHP membuat array dengan key otomatis:
- `'Fiksi'` → key `0`
- `'Non-Fiksi'` → key `1`
- `'Sains'` → key `2`
- dst.

Akses `$kategori[0]` mengembalikan `'Fiksi'`.

### Tracing B: Associative Array `$buku = ['judul' => 'Clean Code', ...];`

Kita **menentukan sendiri key-nya** (string). Key `'judul'` dipetakan ke nilai `'Clean Code'`. Ini seperti "kamus" (key-value pair).

Akses `$buku['harga']` langsung dapat `150000`.

### Tracing C: Modifikasi array

- `$buku['rating'] = 4.8` → tambah key baru jika belum ada
- `$buku['stok'] = 3` → timpa nilai lama (5 jadi 3)
- `unset($buku['isbn'])` → hapus key `'isbn'` beserta nilainya

### Tracing D: Multidimensional Array `$katalog`

`$katalog` adalah **array berisi 4 elemen**. Tiap elemen adalah **array associative** (data buku).

Akses bertingkat: `$katalog[2]['judul']` artinya "ambil elemen index 2, lalu ambil key 'judul'". Hasil: `'Laskar Pelangi'`.

### Tracing E: `foreach ($katalog as $index => $bukuItem)`

Looping tiap elemen:
- `$index` = 0,1,2,3
- `$bukuItem` = array associative tiap buku
- `$index + 1` untuk nomor urut di tabel
- Ternary `$bukuItem['stok'] > 0 ? 'Tersedia' : 'Habis'` menentukan status

## Analogi

Bayangkan **rak katalog buku** di perpustakaan.

- **Indexed Array = Daftar nomor rak**  
  Lihat daftar: `[Rak 1, Rak 2, Rak 3]`. Kita tahu cukup dengan **nomor urut** untuk menemukannya. Sederhana.

- **Associative Array = Kartu katalog buku**  
  Setiap kartu punya **kolom berlabel**: Judul, Pengarang, ISBN, Tahun, Harga. Kita mencari berdasarkan **nama kolom** (`'judul'`), bukan angka. Sangat natural.

- **Multidimensional Array = Seluruh lemari katalog**  
  Lemari berisi **banyak kartu katalog**. Tiap kartu adalah data lengkap satu buku. Jadi kita punya "koleksi kartu" dalam satu wadah.

Saat petugas mau menampilkan **daftar semua buku** ke pengunjung, ia akan membuka lemari katalog dan membacakan tiap kartu satu per satu. Itulah persis yang dilakukan `foreach`.

## Dipakai untuk Apa

- **Katalog buku** — simpan semua data buku dalam satu array
- **Daftar anggota** — koleksi data anggota perpustakaan
- **Form data** — representasi data sebelum simpan ke DB
- **Filter & pencarian** — olah koleksi data
- **Menu navigasi** — daftar link (indexed) atau menu dengan label (associative)
- **Konfigurasi** — setting aplikasi berbentuk key-value
- **Session/Flash data** — menyimpan pesan sementara
- **API response dummy** — latihan sebelum pakai database

## Kesalahan Umum yang Sering Terjadi

- **Lupa koma di akhir array (PHP >= 7.3 boleh, tapi aman selalu ada)** — terutama saat multi-line
- **Mencampur key numeric & string tanpa sengaja** — bikin bingung
- **Akses key yang tidak ada** → Notice `Undefined index`
- **Keliru index saat multidimensi** → `$katalog['0']['judul']` kadang salah, pakai `$katalog[0]['judul']`
- **Pakai `count()` di foreach tidak perlu** — foreach lebih aman
- **Mengubah key saat looping** — hindari modifikasi struktur saat iterasi
- **Lupa `htmlspecialchars()` saat tampilkan data user** — potensi XSS (walau data dummy, biasakan)
- **Membedakan `[]` vs `list()`** — `[]` modern, `list()` lama

1. Buat array `$anggota` berisi **3 data anggota** (associative). Minimal field: `id`, `nama`, `email`, `no_hp`, `status_aktif`, `tahun_daftar`
