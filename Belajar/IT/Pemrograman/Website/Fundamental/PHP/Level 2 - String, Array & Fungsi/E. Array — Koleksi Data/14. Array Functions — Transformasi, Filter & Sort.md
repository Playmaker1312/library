# Array Functions — Transformasi, Filter & Sort

## Penjelasan

Setelah paham struktur array (Poin 13), kita masuk ke **array functions** yang paling sering dipakai untuk mengolah koleksi data. Fungsi-fungsi ini ibarat "mesin olah" katalog buku di perpustakaan.

Yang akan kita pelajari: `array_map` (ubah bentuk), `array_filter` (saring data), `array_values` (reset index), `usort` (urutkan kustom), `array_reduce` (akumulasi), `array_column` (ambil kolom), `array_search`/`in_array`, dan kombinasi praktis.

Fokus kita adalah **closure/arrow function** (`fn()`) yang diperkenalkan PHP 7.4+. Sintaksnya ringkas dan sangat nyaman dipadukan dengan array functions.

## Fungsi

- **Transformasi data** — ubah array mentah jadi bentuk baru (`array_map`)
- **Filter data** — tampilkan hanya buku tersedia, anggota aktif (`array_filter`)
- **Sorting** — urutkan berdasarkan harga/tahun (`usort`, `uasort`)
- **Ekstraksi kolom** — ambil semua judul buku jadi array terpisah (`array_column`)
- **Akumulasi** — hitung total harga/stok (`array_reduce`)
- **Reset index** — rapikan index setelah filter (`array_values`)
- **Pencarian** — cek keberadaan atau cari data spesifik
- **Membuat fitur dinamis** — "Cari", "Filter Kategori", "Urutkan" di web app

## Tracing Code (Step-by-Step)

### Tracing A: `array_map(fn($b) => $b['judul'], $katalog)`

Untuk tiap elemen `$b` di `$katalog`, ambil hanya `$b['judul']`. Hasil dikumpulkan jadi array baru: `['Clean Code', 'The Pragmatic Programmer', ..., 'Atomic Habits']`

### Tracing B: `array_filter(fn($b) => $b['stok'] > 0, $katalog)`

Filter: hanya elemen yang **kondisinya true** yang dipertahankan. Buku "Laskar Pelangi" stok 0 → **dibuang**. Yang tersisa 4 buku. Key-nya masih 0,1,2,4 (index 3 hilang) → kita pakai `array_values` biar jadi 0,1,2,3.

### Tracing C: `usort($katalogHargaAsc, fn($a,$b) => $a['harga'] <=> $b['harga'])`

`usort` **mengubah array asli secara in-place** (kecuali kita copy). `spaceship <=>` mengembalikan -1/0/1 untuk menentukan urutan.

- `$a['harga']=85000, $b['harga']=120000` → -1 → `$a` ditaruh sebelum `$b`
- Hasil akhir urut naik: 85000, 120000, 135000, 150000, 175000

### Tracing D: `array_reduce($katalog, fn($carry, $b) => $carry + $b['harga'], 0)`

Iterasi:
1. carry=0, b=buku1 → 0+150000=150000
2. carry=150000, b=buku2 → 150000+175000=325000
3. carry=325000, b=buku3 → 325000+85000=410000
dst. Akhirnya total 665000.

Initial value `0` wajib biar aman.

### Tracing E: `array_column($katalog, null, 'id')`

Jika parameter kedua `null`, `array_column` akan **mengambil seluruh baris**, tapi **menggunakan 'id' sebagai key array hasil**. Jadi kita bisa akses langsung `$byId[1]['judul']` tanpa loop.

## Analogi

Bayangkan petugas perpustakaan mengelola **katalog buku fisik**.

- **array_map** → Seperti membuat **daftar singkat** "hanya judul buku" untuk ditempel di papan pengumuman. Bentuk diubah, isi inti dipertahankan.
- **array_filter** → Seperti memilih buku yang **masih tersedia** (stok > 0) untuk ditampilkan ke rak "Bisa Dipinjam". Yang habis disembunyikan.
- **usort** → Seperti mengurutkan buku di rak berdasarkan **harga termurah-termahal** biar pengunjung mudah bandingkan.
- **array_reduce** → Seperti menghitung **total nilai inventaris** semua buku dengan menjumlahkan harga satu per satu.
- **array_column** → Seperti mengambil **hanya kolom "Judul"** dari seluruh kartu katalog untuk bikin indeks cepat.
- **array_values** → Seperti **menomori ulang** daftar buku setelah ada yang dihapus, biar urut rapi 1,2,3...

Semua ini menghemat waktu dibanding memilah manual satu per satu.

## Dipakai untuk Apa

- **Fitur pencarian buku** — filter berdasarkan keyword judul/pengarang
- **Filter kategori** — tampilkan hanya "Teknologi"
- **Sorting tabel** — urutkan harga naik/turun
- **Dashboard statistik** — hitung total buku, total stok, rata-rata harga
- **Dropdown/select** — ambil list judul/kategori
- **Reindex data** — rapikan hasil API/filter
- **Membuat map by ID** — akses cepat tanpa foreach
- **Transformasi untuk view** — siapkan data rapi sebelum ditampilkan

## Kesalahan Umum yang Sering Terjadi

- **Lupa `array_values` setelah `array_filter`** — index bisa lompat (0,2,4). Kadang bikin masalah di JS atau loop tertentu.
- **Menggunakan `usort` tanpa copy** — `$katalogHargaAsc = $katalog` itu **copy by value**? Di PHP assignment array = copy. OK. Tapi hati-hati.
- **Arrow function vs closure** — `fn()` otomatis capture variabel luar. Closure butuh `use()`. Keduanya benar.
- **Parameter order `array_filter`** — signature: `array_filter(array $array, callable $callback, int $mode = 0)`. Benar urutannya array dulu, callback kedua.
- **array_reduce initial value penting** — kalau array kosong dan tanpa initial, return null. Biasakan kasih 0 untuk angka.
- **usort mengubah key jadi numeric 0-based** — wajar, karena sorting mengacak urutan.
- **Membandingkan float dengan <=> aman** — spaceship works for int/float/string.
- **in_array strict mode** — default `false`. Kalau mau bandingkan tipe persis, pakai `true` ketiga.

## Soal Latihan & Jawaban

### Soal

Olah katalog buku dengan array functions.

1. Buat array `$buku` minimal **5 item** dengan field: `id, judul, pengarang, harga, stok, kategori`
2. Gunakan `array_filter` → ambil buku **Fiksi** yang **stok > 0**
3. Gunakan `array_map` → buat array baru berisi `['judul' => ..., 'harga_format' => 'Rp ...']`
4. Gunakan `usort` → urutkan berdasarkan **harga** termurah→termahal
5. Gunakan `array_reduce` → hitung **total stok** seluruh katalog
6. Gunakan `array_column` + `array_unique` (opsional) → ambil daftar **kategori unik**
7. Buat fungsi `cariByHarga($buku, $maks)` pakai `array_filter` → buku dengan harga <= $maks
8. Tampilkan hasilnya rapi

// File: 15-latihan-array-functions.php

error_reporting(E_ALL);
ini_set('display_errors', 1);

$buku = [
    ['id'=>1,'judul'=>'Clean Code','pengarang'=>'Robert C. Martin','harga'=>150000,'stok'=>5,'kategori'=>'Teknologi'],
    ['id'=>2,'judul'=>'Negeri 5 Menara','pengarang'=>'Ahmad Fuadi','harga'=>95000,'stok'=>3,'kategori'=>'Fiksi'],
    ['id'=>3,'judul'=>'Laskar Pelangi','pengarang'=>'Andrea Hirata','harga'=>85000,'stok'=>4,'kategori'=>'Fiksi'],
    ['id'=>4,'judul'=>'Sapiens','pengarang'=>'Yuval Noah Harari','harga'=>120000,'stok'=>0,'kategori'=>'Sejarah'],
    ['id'=>5,'judul'=>'Rich Dad Poor Dad','pengarang'=>'Robert Kiyosaki','harga'=>110000,'stok'=>6,'kategori'=>'Non-Fiksi'],
];

// 2. Fiksi tersedia
$fiksiTersedia = array_values(array_filter($buku, fn($b)=>$b['kategori']==='Fiksi' && $b['stok']>0));

// 3. Format ringkas
$format = array_map(fn($b)=>[
    'judul' => $b['judul'],
    'harga_format' => 'Rp '.number_format($b['harga'],0,',','.')
], $buku);

// 4. Urut harga asc
$bukuSort = $buku;
usort($bukuSort, fn($a,$b)=>$a['harga'] <=> $b['harga']);

// 5. Total stok
$totalStok = array_reduce($buku, fn($c,$b)=>$c+$b['stok'], 0);

// 6. Kategori unik
$kategoriList = array_unique(array_column($buku,'kategori'));

// 7. Fungsi cari by harga
function cariByHarga($arr,$maks){
    return array_values(array_filter($arr, fn($b)=>$b['harga'] <= $maks));
}
$murah = cariByHarga($buku, 120000);
