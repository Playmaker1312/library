# Symfony — Framework Enterprise-Grade

## Penjelasan

**Symfony** adalah framework PHP yang terkenal **fokus pada komponen yang bisa dipakai ulang**. Alih-alih satu paket besar, Symfony menyediakan banyak **komponen mandiri** (HTTP, Routing, Console, Validator, dan lain-lain) yang bisa dipakai terpisah, bahkan tanpa framework penuhnya. Karena itu Symfony sering dipilih untuk aplikasi **enterprise** yang butuh fleksibilitas jangka panjang.

Konsep penting:

- **Komponen inti**:
  - **HttpFoundation** — membungkus request & response (`Request`, `Response`).
  - **HttpKernel** — mesin yang mengubah request menjadi response melalui event.
  - **Routing** — memetakan URL ke controller (lewat atribut PHP 8 `#[Route(...)]`).
  - **DependencyInjection** — service container yang mengelola objek & dependensinya.
  - **Twig** — template engine untuk view.
  - **Doctrine ORM** — mengakses database lewat object.
  - **Console** — membuat perintah CLI sendiri.
- **Bundle** — paket fitur yang dipasang ke aplikasi.
- **Environment** (`dev`, `prod`) — pengaturan berbeda untuk pengembangan & produksi.
- **Flex** — alat memasang dependency dalam satu perintah (`composer require`).

Konteks perpustakaan: kita buat halaman daftar buku memakai controller, Twig, dan Doctrine.

## Fungsi

- **Komponen modular** — pakai hanya yang dibutuhkan.
- **Cocok untuk jangka panjang** — proyek besar tetap rapi karena struktur tegas.
- **Standar de facto** — banyak framework lain (termasuk Laravel) memakai komponennya.
- **Tangguh & teruji** — lama dipakai di sistem berskala besar.
- **Dependency Injection kuat** — inti arsitektur Symfony.
- **Ekonomi karier** — keterampilan Symfony dicari di perusahaan enterprise.

## Cara Pengimplementasian / Code

```bash
# 1) Membuat proyek Symfony (butuh Composer, tetapi tanpa "symfony/skeleton" simpel)
composer create-project symfony/skeleton perpustakaan

# 2) Masuk folder & pasang yang dibutuhkan
cd perpustakaan
composer require webapp          # paket web lengkap (Twig, Doctrine, dll)

# 3) Jalankan server pengembangan
symfony serve                     # atau: php -S localhost:8000 -t public
```

**Entity — `src/Entity/Buku.php`:**

```php
<?php
// Entity Doctrine: satu class mewakili tabel
namespace App\Entity;

use Doctrine\ORM\Mapping as ORM;

#[ORM\Entity]
#[ORM\Table(name: 'buku')]
class Buku
{
    #[ORM\Id]
    #[ORM\GeneratedValue]
    #[ORM\Column]
    private ?int $id = null;

    #[ORM\Column(length: 255)]
    private string $judul;

    #[ORM\Column(length: 255)]
    private string $pengarang;

    #[ORM\Column]
    private int $stok = 0;

    // Getter & setter
    public function getId(): ?int { return $this->id; }
    public function getJudul(): string { return $this->judul; }
    public function setJudul(string $judul): static { $this->judul = $judul; return $this; }
    public function getPengarang(): string { return $this->pengarang; }
    public function setPengarang(string $p): static { $this->pengarang = $p; return $this; }
    public function getStok(): int { return $this->stok; }
}
```

**Controller — `src/Controller/BukuController.php`:**

```php
<?php
// Controller dengan routing memakai atribut PHP 8
namespace App\Controller;

use App\Entity\Buku;
use App\Repository\BukuRepository;
use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Routing\Attribute\Route;

class BukuController extends AbstractController
{
    // Route web, arahkan ke method daftar()
    #[Route('/buku', name: 'buku_daftar', methods: ['GET'])]
    public function daftar(BukuRepository $repo): Response
    {
        // Repository otomatis disuntikkan berkat service container
        $buku = $repo->findBy([], ['judul' => 'ASC']);

        // Render template Twig dengan data
        return $this->render('buku/daftar.html.twig', ['buku' => $buku]);
    }

    // Detail satu buku; {id} otomatis dikonversi ke objek Buku
    #[Route('/buku/{id}', name: 'buku_detail', methods: ['GET'])]
    public function detail(Buku $buku): Response
    {
        return $this->render('buku/detail.html.twig', ['buku' => $buku]);
    }
}
```

**View — `templates/buku/daftar.html.twig`:**

```twig
{# Menampilkan daftar buku #}
<h1>Katalog Buku</h1>
<table border="1" cellpadding="6">
    <tr><th>Judul</th><th>Pengarang</th><th>Stok</th></tr>
    {% for b in buku %}
        <tr>
            <td><a href="{{ path('buku_detail', {id: b.id}) }}">{{ b.judul }}</a></td>
            <td>{{ b.pengarang }}</td>
            <td>{{ b.stok }}</td>
        </tr>
    {% endfor %}
</table>
```

**Cara menjalankan/menguji:** `symfony serve`, lalu buka `https://127.0.0.1:8000/buku`. Buat tabel dengan `php bin/console doctrine:schema:update --force` (untuk latihan) atau `doctrine:migrations`.

## Tracing Code (Step-by-Step)

Kita telusuri request **GET /buku** di Symfony.

**Langkah 1 — front controller `public/index.php`**

Semua request masuk lewat `public/index.php`. File ini memuat autoload Composer dan membuat **Kernel**.

**Langkah 2 — HttpKernel menangani request**

Kernel mengubah data PHP mentah (`$_SERVER`, body) menjadi objek `Request` (komponen **HttpFoundation**).

**Langkah 3 — Router mencocokkan URL**

Router membaca semua atribut `#[Route]`. URL `/buku` dengan method `GET` cocok dengan `BukuController::daftar`.

**Langkah 4 — Service Container menyiapkan controller**

Symfony membuat instance `BukuController`. Karena method `daftar()` minta `BukuRepository`, container **menyuntikkan** repository itu secara otomatis. Inilah Dependency Injection.

**Langkah 5 — `$repo->findBy([], ['judul' => 'ASC'])`**

Doctrine menyusun query `SELECT ... FROM buku ORDER BY judul ASC`, menjalankannya lewat PDO, lalu **hydrate** baris jadi objek `Buku`. Hasilnya array berisi objek.

**Langkah 6 — render Twig**

`$this->render('buku/daftar.html.twig', [...])` menjalankan Twig. `{% for b in buku %}` mengulang, `{{ b.judul }}` otomatis di-escape agar aman, `path('buku_detail', {id: b.id})` membentuk URL detail.

**Langkah 7 — Response dikembalikan**

Twig menghasilkan HTML yang dibungkus objek `Response` dengan status `200`. Kernel mengirimkannya ke browser.

**Output akhir (potongan):**

```html
<h1>Katalog Buku</h1>
<table border="1" cellpadding="6">
  <tr><th>Judul</th><th>Pengarang</th><th>Stok</th></tr>
  <tr><td><a href="/buku/2">Atomic Habits</a></td><td>James Clear</td><td>0</td></tr>
  <tr><td><a href="/buku/1">Clean Code</a></td><td>Robert C. Martin</td><td>5</td></tr>
</table>
```

## Analogi

Bayangkan **membangun perpustakaan dari modul prefab yang bisa dipilih**.

- **Symfony** = **katalog modul bangunan perpustakaan**: rak, loket, panel petunjuk, sistem keamanan — semuanya modul siap pasang.
- **Komponen (HttpFoundation, Routing, dll)** = **modul** yang bisa dipakai di gedung lain juga, bukan hanya bangunan ini.
- **Kernel** = **mesin inti gedung** yang mengubah permintaan pengunjung menjadi layanan.
- **Router** = **papan petunjuk loket**.
- **Controller** = **petugas meja**.
- **Doctrine** = **petugas gudang** (akses rak/database).
- **Twig** = **perancang brosur** tampilan.
- **Service Container** = **kepala personalia** yang menyiapkan petugas + alat.
- **Bundle** = **paket modul tambahan** yang dipasang sesuai kebutuhan.
- **Environment dev/prod** = **mode latihan vs mode operasional** gedung.

Intinya: **bangun hanya modul yang dibutuhkan**, tapi semua modul dirancang agar rapi & tahan lama.

## Dipakai untuk Apa

- **Aplikasi enterprise skala besar** dengan umur panjang.
- **REST API** lewat controller dan serializer.
- **Modular / microservice** karena komponen bisa dipakai terpisah.
- **Sistem dengan aturan DI rumit**.
- **Perintah CLI khusus** memakai komponen Console.
- **Library internal perusahaan** yang butuh stabilitas.

## Kesalahan Umum yang Sering Terjadi

- **Tidak membaca dokumentasi "Flex"** → salah memasang paket sehingga konfigurasi berantakan.
- **Menaruh logika berat di controller** → sebaiknya dipindah ke service.
- **Mengedit file di `vendor/`** → hilang saat `composer update`.
- **Lupa mengubah konfigurasi `.env`** → koneksi database gagal.
- **Mengabaikan cache** → setelah ubah config, jalankan `php bin/console cache:clear`.
- **Memakai `POST` tanpa perlindungan CSRF** → form rawan. Manfaatkan form Symfony.
- **Salah namespace `Attribute\Route` vs `Annotation\Route`** → route tidak dikenali di versi lama/baru.
- **Menaruh produk `prod` dengan debug `dev`** → membocorkan informasi. Set environment dengan benar.

## Soal Latihan & Jawaban

### Soal

Pada proyek Symfony, buat fitur **anggota**:

1. Entity `Anggota` (`id`, `nama`, `email`).
2. Route `GET /anggota` menampilkan semua anggota.
3. Controller `AnggotaController::daftar()` yang menerima `AnggotaRepository` (via DI) dan merender template Twig.

### Jawaban

```php
<?php
// src/Entity/Anggota.php
namespace App\Entity;

use Doctrine\ORM\Mapping as ORM;

#[ORM\Entity]
#[ORM\Table(name: 'anggota')]
class Anggota
{
    #[ORM\Id]
    #[ORM\GeneratedValue]
    #[ORM\Column]
    private ?int $id = null;

    #[ORM\Column(length: 255)]
    private string $nama;

    #[ORM\Column(length: 180, unique: true)]
    private string $email;

    public function getId(): ?int { return $this->id; }
    public function getNama(): string { return $this->nama; }
    public function setNama(string $nama): static { $this->nama = $nama; return $this; }
    public function getEmail(): string { return $this->email; }
    public function setEmail(string $email): static { $this->email = $email; return $this; }
}
```

```php
<?php
// src/Controller/AnggotaController.php
namespace App\Controller;

use App\Repository\AnggotaRepository;
use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Routing\Attribute\Route;

class AnggotaController extends AbstractController
{
    #[Route('/anggota', name: 'anggota_daftar', methods: ['GET'])]
    public function daftar(AnggotaRepository $repo): Response
    {
        // Repository disuntikkan otomatis, data diambil lalu dikirim ke Twig
        return $this->render('anggota/daftar.html.twig', [
            'anggota' => $repo->findBy([], ['nama' => 'ASC']),
        ]);
    }
}
```

```twig
{# templates/anggota/daftar.html.twig #}
<h1>Daftar Anggota</h1>
<ul>
    {% for a in anggota %}
        <li>{{ a.nama }} — {{ a.email }}</li>
    {% endfor %}
</ul>
```
