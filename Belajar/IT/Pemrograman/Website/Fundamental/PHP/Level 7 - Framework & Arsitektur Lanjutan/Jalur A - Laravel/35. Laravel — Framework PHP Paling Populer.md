# Laravel — Framework PHP Paling Populer

## Penjelasan

**Laravel** adalah *full-stack web framework* PHP yang paling banyak dipakai. Prinsipnya "convention over configuration": banyak keputusan sudah punya nilai bawaan yang wajar, sehingga kita bisa cepat membangun aplikasi tanpa mengatur semuanya dari nol.

Laravel memakai pola **MVC (Model–View–Controller)**:

- **Model** — mengurus data & aturan, biasanya lewat **Eloquent ORM** (mengubah tabel jadi object).
- **View** — tampilan, memakai **Blade** (template HTML + sintaks singkat).
- **Controller** — penghubung: menerima request, memanggil model, mengembalikan view/JSON.

Komponen utama yang perlu dikenal:

- **Routing** — mendefinisikan URL di `routes/web.php` atau `routes/api.php`.
- **Middleware** — lapisan pemeriksa sebelum request masuk (auth, throttle).
- **Artisan** — perintah CLI (`php artisan`), mis. membuat migration, controller, model.
- **Migration & Seeder** — versi kontrol struktur database dan pengisian data awal.
- **Validation** — validator bawaan yang rapi (`$request->validate([...])`).
- **Blade** — template engine dengan `@if`, `@foreach`, `{{ }}`.
- **Service Container & Dependency Injection** — Laravel otomatis menyuntikkan dependency.
- **Composer & PSR-4** — fondasi pemasangan paket dan autoload.

Konteks perpustakaan: kita bangun halaman daftar & detail buku dengan Eloquent dan Blade.

## Fungsi

- **Mempercepat pengembangan** karena struktur & alat sudah disiapkan.
- **Menyeragamkan cara kerja tim** — semua proyek Laravel mirip.
- **Menyediakan alat lengkap**: ORM, migrasi, validasi, auth, queue, testing.
- **Menerapkan best practice** keamanan (CSRF, hashing, query builder aman).
- **Menghubungkan konsep sebelumnya** (OOP, PDO, Composer, DI) dalam satu kesatuan.
- **Ekosistem luas** (Laravel Sanctum, Livewire, Inertia).

## Cara Pengimplementasian / Code

Buat proyek, lalu tambahkan route, controller, model, dan view bertema perpustakaan.

```bash
# 1) Membuat proyek Laravel baru (butuh Composer)
composer create-project laravel/laravel perpustakaan

# 2) Masuk ke folder & jalankan server pengembangan
cd perpustakaan
php artisan serve
# buka http://127.0.0.1:8000
```

**Migration — `database/migrations/xxxx_create_buku_table.php`:**

```php
<?php
// Membuat tabel buku
use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration {
    public function up(): void
    {
        Schema::create('buku', function (Blueprint $table) {
            $table->id();
            $table->string('judul');
            $table->string('pengarang');
            $table->year('tahun')->nullable();
            $table->unsignedInteger('stok')->default(0);
            $table->timestamps();
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('buku');
    }
};
```

```bash
php artisan migrate   # menjalankan migration
```

**Model — `app/Models/Buku.php`:**

```php
<?php
// Model Eloquent: satu class mewakili tabel "buku"
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Buku extends Model
{
    protected $table = 'buku';
    protected $fillable = ['judul', 'pengarang', 'tahun', 'stok'];

    // Contoh accessor: status ketersediaan
    public function getStatusAttribute(): string
    {
        return $this->stok > 0 ? 'Tersedia' : 'Habis';
    }
}
```

**Controller — `app/Http/Controllers/BukuController.php`:**

```php
<?php
// Controller: menerima request & menyiapkan data untuk view
namespace App\Http\Controllers;

use App\Models\Buku;
use Illuminate\Http\Request;

class BukuController extends Controller
{
    // Menampilkan semua buku
    public function index()
    {
        $buku = Buku::orderBy('judul')->get();
        return view('buku.index', compact('buku'));
    }

    // Menampilkan detail satu buku
    public function show(Buku $buku) // route model binding otomatis
    {
        return view('buku.show', compact('buku'));
    }

    // Menyimpan buku baru dengan validasi
    public function store(Request $request)
    {
        $validated = $request->validate([
            'judul'     => 'required|min:3',
            'pengarang' => 'required',
            'tahun'     => 'nullable|integer|between:1900,2100',
            'stok'      => 'required|integer|min:0',
        ]);

        Buku::create($validated); // Eloquent memakai prepared statement di baliknya
        return redirect()->route('buku.index')->with('sukses', 'Buku ditambahkan');
    }
}
```

**Route — `routes/web.php`:**

```php
<?php
use Illuminate\Support\Facades\Route;
use App\Http\Controllers\BukuController;

Route::get('/buku', [BukuController::class, 'index'])->name('buku.index');
Route::get('/buku/{buku}', [BukuController::class, 'show'])->name('buku.show');
Route::post('/buku', [BukuController::class, 'store'])->name('buku.store');
```

**View — `resources/views/buku/index.blade.php`:**

```blade
{{-- Menampilkan daftar buku --}}
<h1>Katalog Buku</h1>
<table border="1" cellpadding="6">
    <tr><th>Judul</th><th>Pengarang</th><th>Status</th></tr>
    @foreach ($buku as $b)
        <tr>
            <td>{{ $b->judul }}</td>
            <td>{{ $b->pengarang }}</td>
            <td>{{ $b->status }}</td>
        </tr>
    @endforeach
</table>
```

**Cara menjalankan/menguji:** `php artisan serve`, buka `http://127.0.0.1:8000/buku`.

## Tracing Code (Step-by-Step)

Kita telusuri request **GET /buku** masuk ke Laravel.

**Langkah 1 — titik masuk `public/index.php`**

Semua request masuk lewat satu pintu: `public/index.php`. File ini memuat autoload Composer dan membuat instance aplikasi dari `bootstrap/app.php`.

**Langkah 2 — HTTP Kernel**

Request diserahkan ke HTTP Kernel. Kernel menentukan akan memproses lewat grup **middleware** (mis. pemeriksaan route, session, CSRF untuk POST).

**Langkah 3 — Router mencocokkan URL**

Router membaca daftar route. `/buku` dengan method `GET` cocok dengan:

```php
Route::get('/buku', [BukuController::class, 'index']);
```

**Langkah 4 — Service Container menyiapkan controller**

Laravel membuat `BukuController` lewat container. Jika controller butuh dependency, Laravel menyuntikkannya otomatis (inilah DI bawaan).

**Langkah 5 — method `index()` dijalankan**

Baris `Buku::orderBy('judul')->get()` memanggil **Eloquent**. Eloquent menyusun query SQL `SELECT * FROM buku ORDER BY judul ASC`, menjalankannya (memakai koneksi PDO aman), lalu mengubah tiap baris menjadi objek `Buku`.

**Langkah 6 — data diserahkan ke view**

`view('buku.index', compact('buku'))` memuat file `resources/views/buku/index.blade.php`. Blade mengeksekusi `@foreach`, mengisi `{{ $b->judul }}` (otomatis di-escape agar aman), dan menghasilkan HTML akhir.

**Langkah 7 — Response dikembalikan**

HTML dikirim sebagai `Response` dengan status `200`, melewati middleware dalam perjalanan keluar, lalu ditampilkan browser.

**Output akhir (potongan):**

```html
<h1>Katalog Buku</h1>
<table border="1" cellpadding="6">
  <tr><th>Judul</th><th>Pengarang</th><th>Status</th></tr>
  <tr><td>Atomic Habits</td><td>James Clear</td><td>Habis</td></tr>
  <tr><td>Clean Code</td><td>Robert C. Martin</td><td>Tersedia</td></tr>
</table>
```

## Analogi

Bayangkan **perpustakaan besar dengan SOP lengkap dan petugas ahli di tiap bagian**.

- **Laravel** = **manajemen perpustakaan modern** yang sudah menyiapkan semua prosedur standar.
- **Route** = **papan petunjuk loket**: "Untuk daftar buku, ke meja /buku."
- **Controller** = **petugas layanan** di meja yang menerima permintaan.
- **Model / Eloquent** = **petugas gudang** yang mengambil & menyimpan buku di rak (database).
- **Blade / View** = **perancang tampilan** yang menyusun brosur/laporan rapi.
- **Middleware** = **satpam & pemeriksa tiket** sebelum pengunjung masuk.
- **Artisan** = **asisten CLI** yang membuat formulir, jadwal, dan struktur rak.
- **Migration** = **cetak biru rak** yang bisa dipasang & dilepas berurutan.
- **Service Container** = **kepala personalia** yang menyiapkan petugas beserta alatnya otomatis.
- **Convention over configuration** = perpustakaan sudah punya **standar baku**, jadi petugas tidak perlu diajari ulang tiap proyek.

## Dipakai untuk Apa

- **Aplikasi web skala kecil sampai besar** dengan pengembangan cepat.
- **REST API** memakai `routes/api.php`, Sanctum, atau Passport.
- **Dashboard admin** dengan autentikasi & otorisasi bawaan.
- **Aplikasi dengan CRUD kompleks** berkat Eloquent & migrasi.
- **Proyek tim** yang butuh struktur & standar seragam.
- **Prototipe cepat** ide aplikasi perpustakaan.

## Kesalahan Umum yang Sering Terjadi

- **Menulis query mentah di view** → melanggar MVC. Query di model/controller, view hanya menampilkan.
- **Lupa `$fillable`/`$guarded`** di model → mass-assignment gagal atau tidak aman.
- **Menyambung input ke query mentah** (`DB::select("... $input")`) → SQL Injection. Eloquent/Query Builder aman, tetap jangan disambung manual.
- **Lupa `php artisan migrate`** setelah mengubah migration → tabel tidak sesuai.
- **Routing salah method** (`GET` vs `POST`) → error 405 Method Not Allowed.
- **Tidak membaca `.env`** → koneksi database & kunci aplikasi tidak terbaca.
- **Menaruh logika bisnis berat di controller** → sebaiknya dipindah ke service/action class.
- **Mengedit `vendor/`** → hilang saat `composer install` ulang.

## Soal Latihan & Jawaban

### Soal

Pada proyek Laravel, buat fitur **anggota**:

1. Migration tabel `anggota` (`id`, `nama`, `email` unik, `timestamps`).
2. Model `Anggota` dengan `$fillable`.
3. Route `GET /anggota` and `POST /anggota`.
4. Controller `AnggotaController` dengan `index()` (tampilkan semua) dan `store()` (validasi `nama` & `email` lalu simpan).

### Jawaban

```php
<?php
// database/migrations/xxxx_create_anggota_table.php
use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration {
    public function up(): void
    {
        Schema::create('anggota', function (Blueprint $table) {
            $table->id();
            $table->string('nama');
            $table->string('email')->unique();
            $table->timestamps();
        });
    }
    public function down(): void { Schema::dropIfExists('anggota'); }
};
```

```php
<?php
// app/Models/Anggota.php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Anggota extends Model
{
    protected $table = 'anggota';
    protected $fillable = ['nama', 'email'];
}
```

```php
<?php
// app/Http/Controllers/AnggotaController.php
namespace App\Http\Controllers;

use App\Models\Anggota;
use Illuminate\Http\Request;

class AnggotaController extends Controller
{
    public function index()
    {
        return view('anggota.index', ['anggota' => Anggota::orderBy('nama')->get()]);
    }

    public function store(Request $request)
    {
        $data = $request->validate([
            'nama'  => 'required|min:3',
            'email' => 'required|email|unique:anggota,email',
        ]);
        Anggota::create($data);
        return redirect()->route('anggota.index')->with('sukses', 'Anggota ditambahkan');
    }
}
```

```php
<?php
// routes/web.php
use Illuminate\Support\Facades\Route;
use App\Http\Controllers\AnggotaController;

Route::get('/anggota', [AnggotaController::class, 'index'])->name('anggota.index');
Route::post('/anggota', [AnggotaController::class, 'store'])->name('anggota.store');
```
