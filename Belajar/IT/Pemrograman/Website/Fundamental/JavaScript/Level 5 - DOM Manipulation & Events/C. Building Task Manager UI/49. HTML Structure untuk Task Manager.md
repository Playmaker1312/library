# HTML Structure untuk Task Manager

## Penjelasan
Sebelum JavaScript bisa menampilkan apa pun, halaman harus punya "tempat" untuk setiap elemen. Struktur HTML adalah kerangka halaman yang menyediakan semua titik tempel (elemen) yang akan dicari dan diisi oleh JS.

Untuk Task Manager kita butuh empat elemen utama:
- `<input id="taskInput">` — kolom tempat user menulis judul task.
- `<button id="addBtn">` — tombol yang nanti dipasangi event listener (materi 46).
- `<ul id="taskList">` — daftar task; di HTML masih kosong, isinya diisi JS (materi 50).
- `<div id="error">` — tempat pesan error validasi (dipakai materi 53-54).

Setiap task nanti dirender (ditampilkan ulang oleh JS) menjadi satu `<li>` berbentuk begini:

```html
<li class="task-item completed" data-id="1">
  <span>Pinjam buku</span>
  <button class="btn-complete">Complete</button>
  <button class="btn-delete">Delete</button>
</li>
```

Aturan penting struktur ini:
- `id` harus unik di seluruh halaman. JS menemukan elemen lewat id ini (`getElementById`).
- Class dipakai untuk styling CSS dan penanda jenis tombol (`btn-complete`, `btn-delete`).
- `data-id` adalah *data attribute* (atribut khusus yang diawali `data-`) untuk menyimpan id task dari manager, supaya JS tahu task mana yang sedang diklik.

## Fungsi
Struktur HTML adalah pondasi aplikasi. Tanpa elemen-elemen ini, kode seperti `document.getElementById("taskInput")` akan gagal mencari elemennya. Dengan struktur yang rapi, tugas JS tinggal "mengisi" dan "merespons" — bukan membuat halaman dari nol.

Pemisahan ini juga membuat kode mudah dirawat: mengganti tema CSS tidak menyentuh logika JavaScript sama sekali.

## Cara Pengimplementasian / Code
```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Task Manager</title>
</head>
<body>
  <div class="container">
    <h1>Task Manager</h1>

    <!-- Kelompok input: kolom judul + tombol tambah -->
    <div class="input-group">
      <input id="taskInput" placeholder="Enter task...">
      <button id="addBtn">Add Task</button>
    </div>

    <!-- Daftar task; kosong di awal, diisi oleh renderTasks() -->
    <ul id="taskList"></ul>

    <!-- Pesan error validasi; disembunyikan di awal -->
    <div id="error" class="error-message" style="display: none;"></div>
  </div>

  <script src="level5.js"></script>
</body>
</html>
```

Cara menjalankan: simpan sebagai `index.html` di folder yang sama dengan `level5.js` (berisi class `TaskManager` dari materi 42). Buka `index.html` di browser (boleh lewat Live Server), tekan F12 → tab Elements untuk melihat strukturnya.

## Tracing Code (Step-by-Step)
Kita telusuri bagaimana browser "membaca" file di atas saat halaman dibuka.

**Langkah 1 — `<head>` dibaca**
Browser mulai membangun pohon DOM (struktur berbentuk pohon yang mewakili semua elemen halaman). Judul tab menjadi "Task Manager".

**Langkah 2 — `<h1>Task Manager</h1>`**
Elemen h1 pertama masuk sebagai anak `div.container`.

**Langkah 3 — `<div class="input-group">`**
Browser membuat dua anak di dalamnya: elemen input (kosong, placeholder "Enter task...") dan tombol "Add Task".

**Langkah 4 — `<ul id="taskList"></ul>`**
Elemen ul dibuat tanpa anak sama sekali. Ini wajar — isinya memang menyusul dari JS.

**Langkah 5 — `<div id="error" ...>`**
Elemen error dibuat, tapi karena inline style `display: none`, dia tidak terlihat di layar.

**Langkah 6 — `<script src="level5.js">`**
Browser mengunduh `level5.js` lalu menjalankannya. Saat inilah `window.manager = new TaskManager()` berjalan (materi 42). Karena script berada di akhir `<body>`, semua elemen di atasnya sudah tersedia saat JS berjalan.

**Output akhir:**
```
Pohon DOM (sederhana):
body
└── div.container
    ├── h1 "Task Manager"
    ├── div.input-group
    │   ├── input#taskInput
    │   └── button#addBtn "Add Task"
    ├── ul#taskList (kosong)
    └── div#error (display: none)
```

## Analogi
Struktur HTML ini seperti **denah ruang perpustakaan**. `div.container` adalah ruang utama, `input-group` adalah meja layanan tempat pengunjung mengisi formulir, `ul#taskList` adalah papan pengumuman daftar buku, dan `div#error` adalah kotak catatan yang baru ditempeli saat ada masalah. Tanpa denah ini, pustakawan (JS) tidak tahu harus menulis di mana.

## Dipakai untuk Apa
- Menyediakan kerangka UI untuk aplikasi to-do list dan task manager.
- Dasar form di hampir semua aplikasi web: login, registrasi, pencarian.
- Menyediakan pegangan (id/class) untuk CSS styling dan JavaScript.

## Kesalahan Umum yang Sering Terjadi
- **Id salah ketik atau tidak ada**: Menulis `getElementById("taskInput")` sementara di HTML id-nya `task-input` → JS mendapat `null` dan muncul error `Cannot read properties of null`. Selalu cocokkan huruf besar-kecil persis.
- **Id duplikat**: Memakai id yang sama di dua elemen → `getElementById` hanya mengembalikan elemen pertama sehingga elemen kedua "tersembunyi" dari JS. Pakai class untuk elemen yang berulang.
- **Script ditaruh di `<head>` tanpa `defer`**: JS berjalan sebelum body selesai dibaca → elemen seperti `#taskInput` belum ada dan JS gagal. Letakkan `<script>` di akhir `<body>` atau tambahkan `defer`.
- **Menyimpan id task di teks tampilan**: Menulis id di dalam `<span>` agar bisa dibaca JS itu sulit dan rapuh. Simpan di atribut `data-id` — teks hanya untuk user.

## Soal Latihan & Jawaban
### Soal
Di bawah `<ul id="taskList">`, tambahkan elemen baru: `<p id="taskCount">Jumlah task: 0</p>` yang nanti akan diisi JS dengan jumlah task. Buat ulang file `index.html` lengkap dengan elemen tersebut, plus sedikit CSS agar task yang `.completed` terlihat dicoret dan `#error` berwarna merah.

### Jawaban
```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Task Manager</title>
  <style>
    /* task selesai dicoret */
    .task-item.completed span { text-decoration: line-through; color: #888; }
    /* pesan error merah */
    #error { color: red; margin-top: 8px; }
  </style>
</head>
<body>
  <div class="container">
    <h1>Task Manager</h1>

    <div class="input-group">
      <input id="taskInput" placeholder="Enter task...">
      <button id="addBtn">Add Task</button>
    </div>

    <ul id="taskList"></ul>
    <!-- paragraf penghitung jumlah task -->
    <p id="taskCount">Jumlah task: 0</p>
    <div id="error" class="error-message" style="display: none;"></div>
  </div>
  <script src="level5.js"></script>
</body>
</html>
```
