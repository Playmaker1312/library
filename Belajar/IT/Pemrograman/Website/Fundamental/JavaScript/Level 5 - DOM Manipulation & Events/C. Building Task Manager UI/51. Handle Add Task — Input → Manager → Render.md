# Handle Add Task — Input → Manager → Render

## Penjelasan
UI sudah ada (materi 49) dan render sudah bisa jalan (materi 50). Sekarang tugasnya: menghubungkan keduanya lewat aksi user. Inilah alur inti aplikasi kita — sering disebut pola **input → manager → render**:

1. **Input** — user menulis judul di `#taskInput`, lalu menekan tombol `#addBtn`.
2. **Manager** — JS membaca nilai input, memanggil `manager.addTask(title)`; data masuk array dan localStorage.
3. **Render** — JS memanggil `renderTasks()` sehingga tampilan di-update dari data terbaru.

Yang menangkap aksi klik adalah `addEventListener("click", ...)` dari materi 46. Callback-nya dijalankan browser setiap kali tombol diklik.

Detail kecil tapi penting:
- `taskInput.value` selalu berupa string, bisa saja kosong `""` atau berisi spasi `"   "`.
- `title.trim()` membuang spasi di ujung; kalau hasilnya kosong, user tidak menulis apa-apa → hentikan alur dengan `return`.
- Setelah task masuk, input dikosongkan (`taskInput.value = ""`) supaya user langsung bisa menulis task berikutnya.

## Fungsi
Tanpa handler ini, tombol Add Task hanyalah hiasan. Handler inilah yang membuat aplikasi *interaktif*: data baru masuk dari user, tersimpan di manager, lalu tampil di layar. Pola yang sama dipakai di hampir semua form aplikasi — login, komentar, tambah produk.

## Cara Pengimplementasian / Code
```js
let addBtn = document.getElementById("addBtn");
let taskInput = document.getElementById("taskInput");

addBtn.addEventListener("click", () => {
  let title = taskInput.value;      // baca nilai input
  if (!title.trim()) return;        // tolak judul kosong/spasi

  window.manager.addTask(title);    // simpan lewat manager (materi 42)
  taskInput.value = "";             // kosongkan kolom input
  renderTasks();                    // gambar ulang list (materi 50)
});
```

Cara menjalankan: simpan di `level5.js` bersama `renderTasks()` dan instance `window.manager`. Buka `index.html` di browser (Live Server), tekan F12 → tab Console/Elements, tulis sebuah task, klik **Add Task**, dan amati `<ul>` berubah di tab Elements.

## Tracing Code (Step-by-Step)
Misal di `#taskList` sudah ada dua task (id 1 dan 2). User menulis "Belajar DOM" di kolom input, lalu mengklik tombol **Add Task**.

**Langkah 1 — user mengklik `#addBtn`**
Browser membuat event `click` dan meneruskannya ke fungsi callback yang kita pasang.

**Langkah 2 — `let title = taskInput.value;`**
Nilai kolom input, yaitu `"Belajar DOM"`, disimpan ke variabel `title`.

**Langkah 3 — `if (!title.trim()) return;`**
`trim()` menghasilkan `"Belajar DOM"` (tidak kosong), jadi kondisinya `false`. Aluran tidak berhenti.

**Langkah 4 — `window.manager.addTask("Belajar DOM")`**
Manager membuat task `{ id: 3, title: "Belajar DOM", completed: false }`, mendorongnya ke array, dan menyimpan ke localStorage. Di memori kini ada 3 task.

**Langkah 5 — `taskInput.value = ""`**
Kolom input menjadi kosong. Di tab Elements, atribut `value` input berubah dari "Belajar DOM" jadi "".

**Langkah 6 — `renderTasks()`**
Fungsi render (materi 50) mengosongkan `<ul>` lalu menulis ulang tiga `<li>` — dua task lama plus task baru "Belajar DOM" sebagai item ketiga.

**Output akhir:**
```
<ul id="taskList">
  <li class="task-item" data-id="1">...</li>
  <li class="task-item" data-id="2">...</li>
  <li class="task-item" data-id="3"><span>Belajar DOM</span> ...</li>
</ul>
#taskInput value: "" (kosong)
```

## Analogi
Ini seperti meja layanan perpustakaan. Pengunjung mengisi **formulir permintaan buku** (`#taskInput`), lalu menyerahkannya dengan menekan bel (**#addBtn**). Pustakawan mencatat judul ke buku katalog (`manager.addTask`), mengembalikan formulir kosong (`value = ""`), dan terakhir memperbarui papan pengumuman (`renderTasks`).

## Kesalahan Umum yang Sering Terjadi
- **Lupa `renderTasks()`**: `addTask` jalan dan data tersimpan, tapi layar diam saja sampai user refresh. Selalu render ulang setelah mengubah data.
- **Lupa mengosongkan input**: User harus menghapus teks lama manual sebelum menulis task baru. Setelah `addTask`, set `taskInput.value = ""`.
- **`if (!title)` saja tanpa `trim()`**: String berisi spasi `"   "` dianggap judul valid sehingga muncul task tanpa nama. Selalu pakai `!title.trim()`.
- **Listener dipasang sebelum elemen tersedia**: Kalau script jalan sebelum `<body>` selesai dibaca, `getElementById` menghasilkan `null` dan listener gagal terpasang. Letakkan `<script>` di akhir body atau pakai `defer`.

## Soal Latihan & Jawaban
### Soal
Agar lebih nyaman, user juga boleh menekan tombol **Enter** di kolom input untuk menambah task — tanpa harus mengklik tombol. Pasang listener event `keypress` pada `#taskInput` yang menambah task hanya jika tombol yang ditekan adalah Enter (`event.key === "Enter"`). Buat proses tambah-task jadi satu fungsi `addTaskFromInput()` agar tidak ada kode duplikat.

### Jawaban
```js
let addBtn = document.getElementById("addBtn");
let taskInput = document.getElementById("taskInput");

// satu fungsi untuk seluruh proses tambah task
function addTaskFromInput() {
  let title = taskInput.value;
  if (!title.trim()) return;

  window.manager.addTask(title);
  taskInput.value = "";
  renderTasks();
}

// klik tombol Add Task
addBtn.addEventListener("click", addTaskFromInput);

// tekan Enter di kolom input
taskInput.addEventListener("keypress", (event) => {
  if (event.key === "Enter") addTaskFromInput();
});
```
