# Render Tasks — Populate DOM dengan Data dari TaskManager

## Penjelasan
Data task sudah hidup di class `TaskManager` (materi 42), tapi user tidak bisa melihatnya. Fungsi `renderTasks()` adalah jembatannya: ia membaca data dari manager lalu menuliskannya ke `<ul id="taskList">` sebagai elemen `<li>`.

Alur kerjanya:
- Ambil daftar task lewat `manager.getTasks()`.
- Kosongkan isi `<ul>` dengan `taskList.innerHTML = ""` supaya tampilan lama tidak menumpuk.
- Loop tiap task dengan `forEach`, buat satu `<li>` baru, lalu `appendChild` ke `<ul>`.
- Isi `<li>` dengan template literal (string dengan penyisipan `${...}`) berisi judul dan dua tombol.
- Class `completed` dan atribut `data-id` disalin dari data task ke `<li>`.

Aturan emasnya: **satu sumber kebenaran**. Tampilan selalu dibangun ulang dari data manager, tidak pernah disimpan terpisah. Jadi saat data berubah, tinggal panggil `renderTasks()` lagi.

## Fungsi
Tanpa render, aplikasi hanya "otak tanpa wajah": data tersimpan di memori tapi user tidak bisa melihat, menandai, atau menghapus apa pun. Render membuat data terlihat, sekaligus memasang `data-id` yang dibutuhkan materi 52 untuk delete & complete.

Pola "render ulang dari data" ini juga yang membuat tampilan dijamin tidak pernah menyimpang dari data manager.

## Cara Pengimplementasian / Code
```js
function renderTasks() {
  let manager = window.manager;          // instance TaskManager global
  let tasks = manager.getTasks();        // ambil salinan data task
  let taskList = document.getElementById("taskList");

  taskList.innerHTML = "";               // kosongkan list (hindari dobel)

  tasks.forEach(task => {                // loop tiap task
    let li = document.createElement("li");
    // gabungkan class: selalu "task-item", plus "completed" bila selesai
    li.className = `task-item ${task.completed ? "completed" : ""}`;
    li.setAttribute("data-id", task.id); // simpan id task di atribut

    li.innerHTML = `
      <span>${task.title}</span>
      <button class="btn-complete">Complete</button>
      <button class="btn-delete">Delete</button>
    `;

    taskList.appendChild(li);            // tempelkan ke <ul>
  });
}
```

Cara menjalankan: simpan di `level5.js` setelah class `TaskManager` dan `window.manager = new TaskManager();`. Buka `index.html` di browser (Live Server), tekan F12 → tab Console, ketik `manager.addTask("Pinjam buku"); renderTasks();`, lalu lihat hasilnya di tab Elements.

## Tracing Code (Step-by-Step)
Misal manager sudah berisi dua task: id 1 "Pinjam buku" (belum selesai) dan id 2 "Kembalikan buku" (sudah selesai). Kita jalankan `renderTasks()` dari Console.

**Langkah 1 — `let manager = window.manager;`**
JS mengambil instance TaskManager yang tersimpan di variabel global `window.manager`.

**Langkah 2 — `let tasks = manager.getTasks();`**
`getTasks()` mengembalikan salinan array: `[{id:1, title:"Pinjam buku", completed:false}, {id:2, title:"Kembalikan buku", completed:true}]`.

**Langkah 3 — `document.getElementById("taskList")`**
Referensi ke `<ul id="taskList">` di halaman.

**Langkah 4 — `taskList.innerHTML = ""`**
Semua anak `<ul>` (kalau ada sisa render sebelumnya) dihapus. Sekarang `<ul>` kosong.

**Langkah 5 — `forEach` mulai**
Setiap putaran membuat satu `<li>` lalu menempelkannya:

| Putaran | task.id | task.title | task.completed | class `<li>` |
|---|---|---|---|---|
| 1 | 1 | Pinjam buku | false | `task-item ` |
| 2 | 2 | Kembalikan buku | true | `task-item completed` |

Di putaran 1, `<li>` dibuat, `data-id` diisi "1", judul dan dua tombol ditulis lewat `innerHTML`, lalu ditempelkan ke `<ul>`.

**Langkah 6 — putaran 2**
Sama seperti putaran 1, tapi untuk task id 2. Karena `completed` bernilai `true`, class `<li>` menjadi `task-item completed`.

**Langkah 7 — loop selesai**
`renderTasks()` berakhir. Di tab Elements terlihat `<ul>` kini berisi dua `<li>`.

**Output akhir:**
```
<ul id="taskList">
  <li class="task-item" data-id="1"><span>Pinjam buku</span> ...</li>
  <li class="task-item completed" data-id="2"><span>Kembalikan buku</span> ...</li>
</ul>
```

## Analogi
Pustakawan punya buku katalog (data manager) dan sebuah papan pengumuman (`<ul>`). Setiap kali katalog berubah, pustakawan **menghapus semua kartu lama di papan, lalu menulis ulang kartu demi kartu** sesuai isi katalog. Cara ini sederhana, tapi dijamin papan selalu sama persis dengan katalog — tidak ada kartu nyasar atau dobel.

## Dipakai untuk Apa
- Menampilkan daftar data dari array ke halaman: to-do list, tabel, gallery.
- Menyegarkan tampilan setelah data berubah (add, update, delete).
- Pola "render ulang seluruh list" yang dipakai banyak library UI modern.

## Kesalahan Umum yang Sering Terjadi
- **Lupa mengosongkan `<ul>`**: Tanpa `taskList.innerHTML = ""`, tiap render menambahkan salinan baru → daftar dobel dan terus memanjang.
- **Lupa `data-id`**: `<li>` tampil normal, tapi di materi 52 JS tidak tahu task mana yang diklik karena `getAttribute("data-id")` bernilai `null`. Selalu `setAttribute("data-id", task.id)`.
- **Class `completed` tanpa kondisi**: Menulis `li.className = "task-item completed"` membuat semua task dianggap selesai. Gunakan ternary: `task.completed ? "completed" : ""`.
- **Menyimpan salinan data hasil render di variabel**: Tampilan dan data mudah tidak sinkron. Selalu baca langsung dari `manager.getTasks()`.

## Soal Latihan & Jawaban
### Soal
Ubah `renderTasks()` agar: (1) tiap task yang selesai menampilkan teks "(selesai)" di sebelah judulnya, contoh "Kembalikan buku (selesai)"; (2) jika daftar kosong, tampil teks "Belum ada task" di dalam `<ul>`.

### Jawaban
```js
function renderTasks() {
  let manager = window.manager;
  let tasks = manager.getTasks();
  let taskList = document.getElementById("taskList");

  taskList.innerHTML = "";

  // tampilkan pesan bila tidak ada task
  if (tasks.length === 0) {
    taskList.innerHTML = "<li>Belum ada task</li>";
    return;
  }

  tasks.forEach(task => {
    let li = document.createElement("li");
    li.className = `task-item ${task.completed ? "completed" : ""}`;
    li.setAttribute("data-id", task.id);

    // tambahkan tanda (selesai) bila task sudah completed
    let label = task.completed ? `${task.title} (selesai)` : task.title;

    li.innerHTML = `
      <span>${label}</span>
      <button class="btn-complete">Complete</button>
      <button class="btn-delete">Delete</button>
    `;

    taskList.appendChild(li);
  });
}
```
