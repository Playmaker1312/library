# Event Object — target, type, preventDefault, stopPropagation

## Penjelasan
Setiap kali sebuah event terjadi, browser **membuat objek `event`** dan meneruskannya sebagai argumen pertama ke handler. Objek ini berisi semua informasi tentang kejadian itu. Handler menuliskannya sebagai parameter: `function (event) { ... }` atau `(e) => { ... }`.

Bagian-bagian objek `event` yang paling sering dipakai:

- `event.target` — **elemen asal** kejadian. Kalau user mengklik teks di dalam `<li>`, `target` bisa elemen teksnya, bukan `<li>`-nya.
- `event.currentTarget` — elemen tempat listener ini dipasang (berbeda dari `target` saat event merambat).
- `event.type` — nama event dalam bentuk string, misal `"click"` atau `"submit"`.
- `event.preventDefault()` — **membatalkan perilaku bawaan** browser: reload saat submit form, pindah halaman saat klik link.
- `event.stopPropagation()` — **menghentikan event merambat** (bubbling) ke elemen induk, jadi handler di parent tidak ikut jalan.

Perlu diingat: objek `event` hanya ada **di dalam** handler. Di luar handler, tidak ada `event` yang bisa diakses.

## Fungsi
Tanpa objek `event`, satu handler tidak bisa tahu detail kejadian: elemen mana yang diklik, teks apa yang diketik, atau tombol keyboard apa yang ditekan. Objek inilah yang membuat satu fungsi handler bisa melayani banyak kejadian berbeda — dan `preventDefault`/`stopPropagation` membuat kita bisa **mengatur** perilaku browser agar sesuai keinginan aplikasi, bukan sebaliknya.

## Cara Pengimplementasian / Code
```js
// level5.js
let taskForm = document.getElementById("taskForm");
let input = document.getElementById("taskInput");

// 1. preventDefault — cegah form reload halaman
taskForm.addEventListener("submit", (event) => {
  event.preventDefault(); // tanpa ini, halaman ikut refresh
  console.log("Form submitted!");
  console.log("Target submit:", event.target.id); // target = elemen form
});

// 2. target — tahu elemen mana yang memicu event
input.addEventListener("input", (event) => {
  console.log("Input value:", event.target.value); // event.target = #taskInput
});

// 3. type — satu handler untuk banyak jenis event
function laporkan(event) {
  console.log("Event type:", event.type);
}
input.addEventListener("focus", laporkan); // "focus"
input.addEventListener("blur", laporkan);  // "blur"

// 4. stopPropagation — hentikan bubbling ke induk
let taskItem = document.querySelector(".task-item");
let taskList = document.getElementById("taskList");

taskItem.addEventListener("click", (event) => {
  event.stopPropagation(); // klik TIDAK diteruskan ke #taskList
  console.log("Task item diklik (parent tidak tahu)");
});

taskList.addEventListener("click", () => {
  console.log("TaskList ikut bereaksi"); // tidak akan muncul
});
```

Cara menjalankan: buka `index.html` di browser (Live Server), tekan F12 untuk lihat Console/elemen.

## Tracing Code (Step-by-Step)
Kita ikuti kejadian saat user berinteraksi dengan halaman.

**Langkah 1 — script dimuat**
Semua listener terpasang. Belum ada handler yang jalan. Di halaman ada elemen `.task-item` di dalam `#taskList`.

**Langkah 2 — USER mengklik `#taskInput` lalu mengetik "Ra"**
Saat kursor masuk ke input, event `"focus"` memancar dan handler `laporkan` jalan, mencetak `event.type` yaitu `"focus"`. Setiap kali satu karakter diketik, event `"input"` memancar. Browser membuat objek `event` yang `target`-nya menunjuk `#taskInput`.

**Langkah 3 — handler `input` berjalan (per karakter)**
Handler `input` menerima `event`. Nilai `event.target.value` berisi teks terbaru di input, lalu dicetak: `"Input value: R"` saat karakter pertama, `"Input value: Ra"` saat karakter kedua, dan seterusnya.

**Langkah 4 — USER menekan Enter di `#taskInput`**
Karena input ada di dalam form, browser memancarkan event `"submit"` ke `#taskForm` dan memanggil handler `submit` dengan objek `event` baru.

**Langkah 5 — handler `submit` berjalan**
`event.preventDefault()` membatalkan perilaku bawaan submit (reload/mengirim ke server) — halaman tetap diam. Lalu `console.log("Form submitted!")` mencetak pesannya. `event.target` menunjuk elemen asal kejadian, yaitu form itu sendiri, sehingga `event.target.id` bernilai `"taskForm"`.

**Langkah 6 — USER meninggalkan input, lalu mengklik `.task-item`**
Saat kursor keluar dari input, event `"blur"` memancar dan `laporkan` mencetak `event.type` yaitu `"blur"`. Selanjutnya klik terjadi di elemen `.task-item`. Browser biasanya meneruskan (bubbling) ke induk, yaitu `#taskList`. Tapi handler `.task-item` memanggil `event.stopPropagation()`, jadi rambatan **dihentikan** tepat di situ. Handler `#taskList` tidak pernah dipanggil.

**Langkah 7 — urutan klik task muncul di Console**
Handler `.task-item` mencetak pesannya sebagai satu-satunya.

**Output akhir:**
```
Event type: focus
Input value: R
Input value: Ra
Form submitted!
Target submit: taskForm
Event type: blur
Task item diklik (parent tidak tahu)
```

## Analogi
Objek `event` itu seperti **surat laporan di meja pustakawan**. Saat ada kejadian (buku dikembalikan), suratnya memuat rincian: kejadian apa (`type`), buku/anggota mana yang terlibat (`target`), dan instruksi khusus seperti "jangan buka pintu otomatis" (`preventDefault`). Kalau pustakawan dilarang meneruskan laporan ke ruang atas (`stopPropagation`), hanya dia yang tahu kejadian itu.

## Dipakai untuk Apa
- Membaca judul task dari `#taskInput` saat form di-submit.
- Mencegah halaman reload dengan `preventDefault()` pada event `submit`.
- Mengetahui elemen mana yang diklik lewat `event.target`.
- Memakai satu handler untuk beberapa event lewat `event.type`.
- Mencegah handler parent ikut jalan saat menangani klik elemen anak.

## Kesalahan Umum yang Sering Terjadi
- **Lupa `preventDefault()` pada `submit`**: Halaman langsung reload, semua state di memori hilang, dan handler terlihat "jalan sebentar lalu hilang". Selalu panggil `event.preventDefault()` di baris pertama handler submit.
- **`target` vs `currentTarget` tertukar**: `event.target` adalah elemen yang **diklik** (bisa elemen kecil di dalam), sedangkan `event.currentTarget` adalah elemen tempat **listener dipasang**. Kalau kode mencari atribut di `target` tapi nilainya `null`, coba gunakan `currentTarget`.
- **Mengakses `event` di luar handler**: `event` hanya hidup di dalam callback. Menyimpannya ke variabel global lalu dipakai nanti sering menghasilkan `undefined` (atau `null` di browser lama).
- **`stopPropagation` dipakai berlebihan**: Menghentikan bubbling membuat listener di parent tidak bisa dipakai (termasuk teknik event delegation di materi 48). Hentikan rambatan hanya jika memang perlu.

## Soal Latihan & Jawaban
### Soal
Buat satu handler pada `#taskInput` untuk event `"input"` yang menampilkan di Console:
1. `event.type` (jenis event).
2. `event.target.id` (id elemen asal).
3. Panjang teks yang sedang diketik user.

Lalu pasang handler pada `#taskForm` untuk event `"submit"` yang **mencegah reload halaman** dan menampilkan isi `#taskInput`.

### Jawaban
```js
let input = document.getElementById("taskInput");
let taskForm = document.getElementById("taskForm");

// Handler untuk event input
input.addEventListener("input", (event) => {
  console.log("Tipe:", event.type);              // "Tipe: input"
  console.log("Elemen:", event.target.id);       // "Elemen: taskInput"
  console.log("Panjang:", event.target.value.length);
});

// Handler untuk event submit
taskForm.addEventListener("submit", (event) => {
  event.preventDefault(); // cegah halaman reload
  console.log("Judul task:", input.value.trim());
});
```
Buka `index.html` di browser (Live Server), tekan F12 untuk lihat Console/elemen. Ketik beberapa huruf di input, lalu tekan Enter.
