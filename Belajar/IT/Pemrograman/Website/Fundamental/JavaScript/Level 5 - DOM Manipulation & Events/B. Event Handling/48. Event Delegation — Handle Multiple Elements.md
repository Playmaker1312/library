# Event Delegation — Handle Multiple Elements

## Penjelasan
**Event delegation** (delegasi event) adalah teknik memasang **satu event listener di elemen induk**, lalu menangani event dari semua elemen anaknya dari sana. Namanya "delegasi" karena induk "mewakili" anak-anaknya untuk urusan event.

Cara kerjanya bertumpu pada **bubbling**: saat user mengklik sebuah elemen, event awalnya terjadi di elemen itu, lalu otomatis "merambat" naik ke induk, kakek, seterusnya sampai `document`. Karena begitu, listener di induk tetap bisa mendetar klik yang terjadi di anak-anaknya.

Langkah umum sebuah handler delegation:

1. Pasang **satu** listener di induk (misal `#taskList`).
2. Di dalam handler, kenali elemen asal lewat `event.target`.
3. Gunakan **`event.target.closest("selector")`** untuk naik ke elemen terdekat yang cocok dengan selector — misalnya `.task-item` — karena elemen yang diklik bisa saja teks `<span>` di dalamnya.
4. Kalau `closest()` menemukan elemen, proses; kalau `null` (klik di area kosong induk), abaikan.
5. Baca `data-id` dari elemen itu untuk tahu task mana yang dimaksud.

Kenapa teknik ini penting: daftar task **berubah-ubah** — task baru bisa ditambah kapan saja. Kalau kamu memasang listener per task, task yang ditambah **setelahnya** tidak punya listener. Delegation menyelesaikan masalah ini karena induknya tidak pernah berubah.

## Fungsi
- Satu listener melayani puluhan bahkan ribuan elemen — lebih hemat memori daripada listener per elemen.
- Elemen yang **baru ditambahkan** ke DOM otomatis ikut terlayani, tanpa perlu memasang listener lagi.
- Logika hapus, edit, dan toggle status task bisa ditulis **satu kali** untuk seluruh daftar.

## Cara Pengimplementasian / Code
```html
<!-- index.html — bagian dalam #taskList, dibuat oleh level5.js -->
<div id="taskList"></div>
```

```js
// level5.js
let manager = new TaskManager(); // class dari Level 4
let taskList = document.getElementById("taskList");

// Render semua task dari TaskManager ke DOM
function renderTasks() {
  let tasks = manager.getTasks();
  if (tasks.length === 0) {
    taskList.textContent = "Belum ada task. Ayo tambah!";
    return;
  }
  let html = "";
  for (let t of tasks) {
    // Simpan id task di atribut data-id (materi 45)
    html += "<div class='task-item' data-id='" + t.id + "'>" + t.title + "</div>";
  }
  taskList.innerHTML = html;
}

// SATU listener untuk seluruh daftar (event delegation)
taskList.addEventListener("click", (event) => {
  // Naik ke elemen .task-item terdekat dari yang diklik
  let taskElement = event.target.closest(".task-item");
  if (taskElement) {
    let taskId = Number(taskElement.getAttribute("data-id"));
    console.log("Clicked task:", taskId);
    taskElement.classList.toggle("completed"); // tandai selesai/tidak
  }
});

renderTasks();
```

Cara menjalankan: buka `index.html` di browser (Live Server), tekan F12 untuk lihat Console/elemen. Klik task mana pun — termasuk task yang baru ditambahkan — handler tetap menangkapnya.

## Tracing Code (Step-by-Step)
Kita ikuti alur dari render awal sampai user mengklik sebuah task.

**Langkah 1 — `new TaskManager()`**
Objek `manager` dibuat dan memuat daftar task dari `localStorage` (atau kosong).

**Langkah 2 — listener delegation terpasang**
Satu listener `"click"` menempel di `#taskList`. Belum ada task di DOM, tapi tidak masalah — listener induk sudah siap.

**Langkah 3 — `renderTasks()` dijalankan**
Misal `manager.getTasks()` mengembalikan dua task: `{ id: 1, title: "Rapikan rak buku" }` dan `{ id: 2, title: "Kembalikan buku" }`. Perulangan `for...of` menyusun string `html` berisi dua `div.task-item`, masing-masing dengan `data-id` sesuai id task. `taskList.innerHTML = html` membuat kedua div itu muncul di halaman.

**Langkah 4 — USER mengklik teks "Kembalikan buku"**
Yang diklik sebenarnya adalah teks di dalam `div` kedua. Event `"click"` terjadi di teks itu, lalu **merambat naik** ke `div.task-item` (data-id 2), lalu ke `#taskList`. Listener di `#taskList` tertangkap dan handler berjalan.

**Langkah 5 — `event.target.closest(".task-item")`**
`event.target` menunjuk elemen teks yang diklik. `closest()` berjalan naik dari situ mencari elemen terdekat yang punya class `.task-item`. Ketemu: `div` dengan `data-id="2"`. Hasilnya disimpan ke `taskElement`. (Kalau user mengklik area kosong `#taskList`, `closest()` menghasilkan `null` dan blok `if` dilewati.)

**Langkah 6 — `getAttribute("data-id")` dan `Number(...)`**
Atribut `data-id` dibaca: `"2"`. Karena ID dibandingkan sebagai angka, `Number("2")` mengubahnya menjadi `2` → `taskId = 2`.

**Langkah 7 — `console.log` dan `classList.toggle`**
Console mencetak `Clicked task: 2`. Lalu `taskElement.classList.toggle("completed")` men-toggle class `completed` di `div` kedua — kalau tadi belum ada, sekarang ditambahkan (tampilan task berubah sesuai CSS).

**Output akhir:**
```
Clicked task: 2
```
Dan di halaman, div task dengan `data-id="2"` kini punya class `completed`.

## Analogi
Di perpustakaan, memasang listener per task itu seperti **menempelkan bel di setiap buku** — ribuan buku berarti ribuan bel dan ribuan catatan pengawas. Event delegation lebih seperti **satu bel di meja pustakawan**: pengunjung cukup menekan bel apa pun yang ada di dekat buku yang ia tuju, dan pustakawan bertanya langsung ke pengunjung, "Buku yang mana tadi?" (`event.target.closest`). Satu bel tetap melayani seluruh rak, termasuk buku-buku yang baru datang.

## Dipakai untuk Apa
- Mengklik task untuk menandai `completed` — tanpa listener per task.
- Tombol hapus di tiap task: baca `data-id`, panggil `manager.deleteTask(id)`.
- Menangani daftar yang sering berubah (ditambah/dihapus) tanpa update listener.
- Daftar panjang (ratusan item) — performa jauh lebih ringan.
- Satu handler melayani beberapa jenis target berbeda (task dan tombol di dalamnya).

## Kesalahan Umum yang Sering Terjadi
- **Lupa `closest()` dan pakai `event.target` langsung**: Kalau di dalam `div.task-item` ada `<span>` atau `<strong>`, `event.target` bisa menunjuk elemen kecil itu, bukan pembungkus task-nya. Akibatnya `getAttribute("data-id")` menghasilkan `null`. Selalu naik dengan `closest(".task-item")`.
- **Listener dipasang setiap render**: Memanggil `addEventListener` lagi setiap `renderTasks()` membuat listener menumpuk — satu klik bisa memicu handler berkali-kali. Pasang listener **satu kali** di luar fungsi render; itu justru keunggulan delegation.
- **Tidak memeriksa hasil `closest()`**: Mengklik area kosong di `#taskList` menghasilkan `closest()` bernilai `null`. Langsung mengakses `taskElement.getAttribute` akan melempar `TypeError`. Bungkus selalu dengan `if (taskElement)`.
- **Membuang `data-id` saat render ulang**: `innerHTML` mengganti seluruh isi, jadi atribut `data-id` harus ikut ditulis ulang di setiap render. Kalau lupa, semua task tampak ada tapi handler tidak bisa mengenali id-nya.

## Soal Latihan & Jawaban
### Soal
`#taskList` berisi beberapa `<div class="task-item" data-id="...">`. Buat satu listener delegation yang:
1. Menangkap klik di seluruh `#taskList`.
2. Mencari elemen `.task-item` terdekat dari yang diklik.
3. Kalau task yang diklik `completed`-nya `false`, ubah jadi `true` lewat `manager.updateTask(id, { completed: true })`, render ulang, dan tampilkan `"Task <id> selesai"` di Console. Kalau sudah `true`, lewati.

### Jawaban
```js
let manager = new TaskManager();
let taskList = document.getElementById("taskList");

// Asumsi sudah ada fungsi renderTasks() seperti pada contoh utama
taskList.addEventListener("click", (event) => {
  let taskElement = event.target.closest(".task-item"); // 2. cari elemen task
  if (!taskElement) return; // klik area kosong — abaikan

  let taskId = Number(taskElement.getAttribute("data-id"));
  let task = manager.getTasks().find((t) => t.id === taskId);

  if (task && !task.completed) { // 3. belum selesai
    manager.updateTask(taskId, { completed: true }); // ubah datanya
    renderTasks(); // gambar ulang daftar ke DOM
    console.log("Task", taskId, "selesai");
  }
});

renderTasks();
```
Buka `index.html` di browser (Live Server), tekan F12 untuk lihat Console/elemen. Klik sebuah task, lalu klik lagi — Console hanya mencetak "selesai" untuk klik pertama.
