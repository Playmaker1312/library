# addEventListener — Attach Event Listener

## Penjelasan
**Event** adalah sinyal dari browser saat terjadi sesuatu — user mengklik tombol, mengetik di input, mengirim form, atau memindahkan mouse. **Event listener** adalah "pendengar" yang kita pasang di sebuah elemen: begitu event tertentu terjadi di elemen itu, sebuah fungsi (disebut **handler**) langsung dijalankan.

Cara memasang listener modern:

```js
element.addEventListener("namaEvent", handlerFunction);
```

Event yang paling sering dipakai di aplikasi Task Manager:

- `"click"` — user mengklik elemen (misalnya tombol `#addBtn`).
- `"submit"` — user mengirim form (Enter di input atau klik tombol submit).
- `"input"` — user mengetik apa pun di input, setiap karakter.
- `"change"` — nilai elemen berubah dan user sudah selesai (blur/Enter).
- `"keypress"` / `"keydown"` — tombol keyboard ditekan.
- `"mouseover"` — mouse masuk ke area elemen.

Handler bisa ditulis sebagai function biasa atau arrow function. Saat event terjadi, browser **melewatkan objek `event`** sebagai argumen pertama handler — objek itu akan dibahas detail di materi 47.

Penting: pasang listener **setelah** elemen ada di HTML. Kalau `level5.js` dimuat sebelum elemen, `querySelector` menghasilkan `null` dan pemasangan listener gagal.

## Fungsi
Tanpa event listener, aplikasi hanya menampilkan halaman statis — tombol bisa diklik tapi tidak melakukan apa pun. Listener adalah **jembatan antara UI dan logika**: aksi user di layar diterjemahkan menjadi kode JavaScript yang menjalankan method `TaskManager` (materi 42), lalu memperbarui DOM. Inilah yang membuat aplikasi "merespons" user.

## Cara Pengimplementasian / Code
```js
// level5.js — pilih elemen dulu, baru pasang listener
let input = document.getElementById("taskInput");
let addBtn = document.getElementById("addBtn");
let taskForm = document.getElementById("taskForm");

// 1. Klik tombol Tambah — handler berupa function biasa
addBtn.addEventListener("click", function (event) {
  console.log("Tombol Tambah diklik!");
  event.preventDefault(); // cegah tombol ikut meng-submit form
});

// 2. Arrow function — perilakunya sama saja
addBtn.addEventListener("click", () => {
  console.log("Handler kedua juga jalan!");
});

// 3. Submit form — user menekan Enter di input
taskForm.addEventListener("submit", (event) => {
  event.preventDefault(); // jangan reload halaman
  let judul = input.value.trim();
  if (judul) {
    console.log("Task baru:", judul);
    input.value = ""; // kosongkan input
  }
});

// 4. Event input — berjalan setiap user mengetik 1 karakter
input.addEventListener("input", (event) => {
  console.log("Isi input sekarang:", event.target.value);
});
```

Cara menjalankan: buka `index.html` di browser (Live Server), tekan F12 untuk lihat Console/elemen.

## Tracing Code (Step-by-Step)
Kita ikuti alur eksekusi, termasuk momen saat user berinteraksi.

**Langkah 1 — script dimuat**
Browser mengeksekusi `level5.js` dari atas ke bawah. `input`, `addBtn`, dan `taskForm` dipilih dari HTML. Saat ini **belum ada handler yang jalan** — kita hanya mendaftarkan listener.

**Langkah 2 — `addBtn.addEventListener("click", ...)` pertama**
Listener pertama terpasang di tombol. `#addBtn` kini punya satu pendengar event `"click"`.

**Langkah 3 — `addBtn.addEventListener("click", ...)` kedua**
Listener kedua terpasang di elemen **yang sama**. Tombol kini punya dua pendengar. Keduanya akan jalan saat diklik — tidak saling menimpa.

**Langkah 4 — listener `submit` dan `input` terpasang**
Sekarang `#taskForm` mendengarkan `"submit"` dan `#taskInput` mendengarkan `"input"`. Pemasangan selesai.

**Langkah 5 — USER mengetik huruf "R" di `#taskInput`**
Event `"input"` terjadi. Browser membuat objek `event` dan memanggil handler ke-4. Di dalamnya, `event.target` menunjuk `#taskInput`, jadi `event.target.value` bernilai `"R"`. Console mencetak: `Isi input sekarang: R`.

**Langkah 6 — USER menekan Enter di input**
Karena input berada di dalam `<form>`, browser memancarkan event `"submit"` ke `#taskForm`. Handler ke-3 jalan: `event.preventDefault()` menghentikan kebiasaan form (reload halaman). `judul` kini `"Rapikan rak buku"` (misal), tidak kosong, jadi dicetak `Task baru: Rapikan rak buku`. Lalu `input.value` dihapus jadi `""`.

**Langkah 7 — USER mengklik tombol `#addBtn`**
Event `"click"` terjadi di tombol. **Kedua** handler click jalan berurutan: muncul `Tombol Tambah diklik!` lalu `Handler kedua juga jalan!`.

**Output akhir** (urutan muncul di Console setelah user mengetik "Rapikan rak buku", menekan Enter, lalu mengklik tombol):
```
Isi input sekarang: R
Isi input sekarang: Ra
... (setiap karakter sampai selesai)
Task baru: Rapikan rak buku
Tombol Tambah diklik!
Handler kedua juga jalan!
```

## Analogi
Di perpustakaan, memasang event listener itu seperti **mendaftarkan notifikasi ke pustakawan**. Kamu berkata, "Kalau ada yang menekan bel meja (event `click`), tolong cetak pemberitahuan." Pustakawan menempel catatan di bel. Begitu bel berbunyi, dia langsung menjalankan tugas yang dijanjikan. Satu bel bisa punyi beberapa catatan sekaligus — semua tugas jalan, tidak ada yang saling menghapus.

## Dipakai untuk Apa
- Tombol `#addBtn` diklik → tambah task via `manager.addTask()`.
- Form di-submit (Enter) → tangkap judul dari `#taskInput`.
- User mengetik → validasi real-time (misal nonaktifkan tombol saat input kosong).
- Tombol hapus per task → jalankan `manager.deleteTask(id)`.
- Checkbox task dicentang → tandai `completed`.

## Kesalahan Umum yang Sering Terjadi
- **Handler dieksekusi langsung dengan `()`**: Menulis `addEventListener("click", prosesTask())` — fungsi `prosesTask()` jalan **saat pemasangan**, bukan saat diklik, dan yang dipasang adalah hasil return-nya (biasanya `undefined`, error). Tulis namanya saja: `prosesTask`.
- **Script jalan sebelum elemen ada**: Kalau tag `<script>` ada sebelum elemen HTML, `document.getElementById(...)` menghasilkan `null` dan `null.addEventListener` melempar `TypeError`. Solusi: taruh `<script>` di akhir `<body>` atau bungkus dengan `DOMContentLoaded`.
- **Berpikir listener kedua menimpa yang pertama**: `addEventListener` **menambah** pendengar, tidak menimpa. Kalau satu tombol bisa diklik dua kali harusnya cuma jalan sekali, berarti ada listener ganda — biasanya karena script dimuat dua kali.
- **Lupa `preventDefault` di event `submit`**: Default form adalah **reload/mengirim halaman ke server**. Tanpa `event.preventDefault()`, semua state di halaman hilang setiap user menekan Enter.

## Soal Latihan & Jawaban
### Soal
Pasang event listener pada `#addBtn` yang melakukan hal berikut saat diklik:
1. Cegah perilaku default-nya.
2. Baca nilai `#taskInput`, buang spasi di awal/akhir.
3. Kalau tidak kosong, cetak ke Console `"Menambah: <judul>"` dan kosongkan input; kalau kosong, cetak `"Judul kosong!"`.

### Jawaban
```js
let input = document.getElementById("taskInput");
let addBtn = document.getElementById("addBtn");

addBtn.addEventListener("click", (event) => {
  event.preventDefault();              // 1. cegah default
  let judul = input.value.trim();      // 2. baca & rapikan judul

  if (judul) {                         // 3. tidak kosong
    console.log("Menambah:", judul);
    input.value = "";                  //    kosongkan input
  } else {
    console.log("Judul kosong!");
  }
});
```
Buka `index.html` di browser (Live Server), tekan F12 untuk lihat Console/elemen. Coba klik tombol tanpa mengetik apa pun, lalu dengan mengisi judul.
