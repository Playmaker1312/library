# Mengubah Attributes — setAttribute, getAttribute, classList

## Penjelasan
Selain mengubah isi elemen (materi 44), kita juga bisa mengubah **atribut** dan **class** sebuah elemen HTML. Atribut adalah properti yang menempel di tag, misalnya `id`, `src`, `href`, `disabled`, atau `data-id`.

Dua cara utama mengubah atribut:

- `element.setAttribute("nama", "nilai")` — menulis atribut ke elemen. Bisa membuat atribut baru kalau belum ada.
- `element.getAttribute("nama")` — membaca nilai atribut. Kalau tidak ada, hasilnya `null`.

Untuk class, lebih nyaman memakai **`classList`** yang punya method khusus:

- `classList.add("cls")` — tambah class (tanpa menghapus yang lain)
- `classList.remove("cls")` — hapus class
- `classList.toggle("cls")` — kalau ada hapus, kalau tidak ada tambah
- `classList.contains("cls")` — cek ada atau tidak, hasilnya `true`/`false`

Atribut khusus `data-*` (misal `data-id`) sangat berguna untuk **menyimpan informasi tambahan** pada sebuah elemen, misalnya ID task dari array `TaskManager`, sehingga bisa dibaca lagi kapan pun lewat `getAttribute("data-id")`.

## Fungsi
Tampilan sebuah elemen hampir seluruhnya ditentukan oleh class CSS-nya. Dengan `classList`, JavaScript bisa mengubah **tampilan** elemen — misalnya menandai task selesai dengan coretan lewat class `completed` — tanpa menyentuh isi teksnya. Sedangkan `data-*` + `getAttribute` membuat kita bisa **menyimpan jejak data** di balik setiap elemen, jadi saat user mengklik sebuah task di layar, kita tahu task ID berapa yang dimaksud.

## Cara Pengimplementasian / Code
```js
// level5.js

// Asumsi di #taskList sudah ada: <div class="task-item">Rapikan rak buku</div>
let task = document.querySelector(".task-item");

// 1. Simpan ID task ke atribut data-id
task.setAttribute("data-id", "123");

// 2. Baca lagi atributnya — tampil di Console
console.log(task.getAttribute("data-id")); // "123"

// 3. Tandai task selesai dengan menambah class "completed"
task.classList.add("completed");

// 4. Cek class-nya
console.log(task.classList.contains("completed")); // true

// 5. Toggle class "highlight" — sekali jalan jadi aktif
task.classList.toggle("highlight"); // "highlight" ditambahkan

// 6. Matikan input sementara (atribut boolean)
let input = document.getElementById("taskInput");
input.setAttribute("disabled", ""); // input jadi tidak bisa diketik
input.removeAttribute("disabled");  // aktifkan lagi

// 7. Baca class apa saja yang menempel
console.log(task.className); // "task-item completed highlight"
```

Cara menjalankan: buka `index.html` di browser (Live Server), tekan F12 untuk lihat Console/elemen.

## Tracing Code (Step-by-Step)
Kita ikuti browser mengeksekusi `level5.js` baris demi baris.

**Langkah 1 — `document.querySelector(".task-item")`**
Browser mencari elemen pertama dengan class `task-item` di `#taskList`. Misal elemennya `<div class="task-item">Rapikan rak buku</div>`. Objeknya disimpan ke `task`.

**Langkah 2 — `task.setAttribute("data-id", "123")`**
Atribut baru `data-id="123"` ditulis ke elemen `div` itu. Di tab Elements (F12), kamu akan melihat atributnya muncul di balik tag.

**Langkah 3 — `task.getAttribute("data-id")`**
Browser membaca atribut `data-id` dari `task`. Nilainya `"123"` dan dicetak ke Console.

**Langkah 4 — `task.classList.add("completed")`**
`classList` memeriksa class apa yang menempel saat ini: hanya `task-item`. Lalu `completed` ditambahkan. Sekarang `class` elemen menjadi `task-item completed`.

**Langkah 5 — `task.classList.contains("completed")`**
`classList` mengecek: apakah `completed` ada di daftar class? Ada. Hasilnya `true`, dicetak ke Console.

**Langkah 6 — `task.classList.toggle("highlight")`**
`toggle` bertanya: apakah `highlight` ada? Tidak ada. Maka `highlight` **ditambahkan**. Class elemen kini `task-item completed highlight`. (Kalau toggle dijalankan lagi, `highlight` justru dihapus.)

**Langkah 7 — `input.setAttribute("disabled", "")` dan `removeAttribute`**
`<input id="taskInput">` diberi atribut `disabled`, sehingga user tidak bisa mengetik. Baris berikutnya menghapus atribut itu, dan input kembali aktif.

**Langkah 8 — `console.log(task.className)`**
`className` membaca seluruh daftar class sebagai satu string, yaitu `"task-item completed highlight"`.

**Output akhir:**
```
123
true
task-item completed highlight
```

## Analogi
Di perpustakaan, setiap buku punya **label rak** dan **stempel status**. `classList` itu seperti stempel pustakawan: `add("dipinjam")` menempelkan stempel "dipinjam", `remove("dipinjam")` menghapusnya, dan `toggle("terlarang")` menempel atau mencabut stempel terlarang sesuai keadaan. Sedangkan `data-id` itu seperti **nomor inventaris** yang ditulis kecil di balik buku — tidak terlihat pembaca, tapi pustakawan bisa membacanya kapan pun untuk mencocokkan buku dengan kartu katalog.

## Dipakai untuk Apa
- Menandai task selesai: `classList.add("completed")` → teks jadi tercoret lewat CSS.
- Menyimpan ID task di `data-id` untuk keperluan edit/hapus.
- Mengubah state tombol: `disabled` saat form kosong, aktif saat ada isinya.
- Menampilkan/menyembunyikan elemen dengan men-toggle class `hidden`.
- Menandai menu aktif di navigasi (`classList.add("active")`).

## Kesalahan Umum yang Sering Terjadi
- **`className` vs `classList`**: `className` adalah string lama yang **menimpa semua class** saat ditulis (`task.className = "completed"` membuat class `task-item` hilang). Selalu pakai `classList` yang punya `add`/`remove`.
- **Menulis atribut `data-id` tapi lupa membacanya**: `data-id` disimpan di HTML, tapi sering lupa `getAttribute` saat dibutuhkan — akibatnya handler tidak tahu task mana yang diklik.
- **`getAttribute` mengembalikan `null`**: Atribut yang tidak pernah diset akan menghasilkan `null`, bukan string kosong. Kalau `null` langsung dipakai perhitungan, hasilnya bisa salah atau error.
- **`setAttribute("disabled", false)` tidak mematikan efek**: Untuk atribut boolean seperti `disabled` dan `checked`, keberadaannya sendiri yang aktif, bukan nilainya. Cara mematikan: `removeAttribute("disabled")` atau pakai properti `input.disabled = false`.

## Soal Latihan & Jawaban
### Soal
Di `#taskList` ada elemen `<div class="task-item" data-id="2">Kembalikan buku</div>`. Tulis kode JavaScript yang:
1. Membaca `data-id` elemen itu dan menampilkannya di Console.
2. Men-toggle class `completed` (sekali jalan — harus menambahkan karena belum ada).
3. Mengecek apakah class `completed` sudah menempel, lalu tampilkan hasilnya.

### Jawaban
```js
// Select elemen task pertama
let task = document.querySelector(".task-item");

// 1. Baca atribut data-id
let id = task.getAttribute("data-id");
console.log("ID task:", id); // "ID task: 2"

// 2. Toggle class completed — karena belum ada, hasilnya ditambahkan
task.classList.toggle("completed");

// 3. Cek apakah class sudah menempel
console.log("Completed?", task.classList.contains("completed")); // "Completed? true"
```
Buka `index.html` di browser (Live Server), tekan F12 untuk lihat Console/elemen.
