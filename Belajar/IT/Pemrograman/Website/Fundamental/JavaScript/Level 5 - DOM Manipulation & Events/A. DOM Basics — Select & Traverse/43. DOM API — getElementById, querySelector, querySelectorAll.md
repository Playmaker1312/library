# DOM API — getElementById, querySelector, querySelectorAll

## Penjelasan
DOM (Document Object Model) adalah representasi halaman HTML dalam bentuk objek yang bisa diakses JavaScript. Saat browser membaca `index.html`, ia membangun "pohon" elemen — `<form>`, `<input>`, `<button>`, `<div>` — dan semua itu bisa kamu ambil lewat objek global `document`.

Untuk mengambil (memilih) elemen dari HTML, ada tiga cara utama:

- `document.getElementById("id")` — mengambil **satu** elemen berdasarkan atribut `id`. Cepat dan sederhana.
- `document.querySelector("selector")` — memakai **sintaks CSS selector** (misal `.btn`, `#taskList`, `li.task-item`) dan mengembalikan **elemen pertama** yang cocok.
- `document.querySelectorAll("selector")` — sama seperti di atas, tapi mengembalikan **semua** elemen yang cocok dalam bentuk **NodeList** (mirip array, bukan array asli).

Catatan penting:
- `id` bersifat unik — satu id hanya boleh dipakai satu elemen.
- `querySelector` dan `querySelectorAll` jauh lebih fleksibel karena bisa memakai selector apa pun yang valid di CSS.
- Kalau tidak ada elemen yang cocok, `getElementById` dan `querySelector` mengembalikan `null`, sedangkan `querySelectorAll` mengembalikan NodeList kosong.

## Fungsi
Sebelum kamu bisa mengubah tampilan halaman (menulis teks, menambah class, memasang event listener), kamu harus **membawa elemen HTML ke dalam JavaScript** dulu. Ketiga API ini adalah jembatannya: tanpa select elemen, kode JS tidak punya "pegangan" ke HTML sama sekali.

## Cara Pengimplementasian / Code
```html
<!-- index.html -->
<!DOCTYPE html>
<html lang="id">
<head><title>Task Manager</title></head>
<body>
  <h1 id="judul">Task Manager</h1>
  <form id="taskForm">
    <input id="taskInput" placeholder="Tambah task..." />
    <button id="addBtn" class="btn">Tambah</button>
  </form>
  <div id="taskList"></div>
  <script src="level5.js"></script>
</body>
</html>
```

```js
// level5.js

// 1. Ambil satu elemen lewat id
let input = document.getElementById("taskInput");
let judul = document.getElementById("judul");

// 2. Ambil lewat selector CSS — querySelector mengembalikan yang PERTAMA cocok
let button = document.querySelector("#addBtn");
let buttonLain = document.querySelector(".btn"); // sama saja, id dan class

// 3. Ambil BANYAK elemen sekaligus — hasilnya NodeList
let semuaItem = document.querySelectorAll(".task-item");

console.log(input);        // <input id="taskInput">
console.log(buttonLain);   // <button class="btn">Tambah</button>
console.log(semuaItem.length); // 0 (list masih kosong)
```

Cara menjalankan: buka `index.html` di browser (Live Server), tekan F12 untuk lihat Console/elemen.

## Tracing Code (Step-by-Step)
Kita telusuri kode `level5.js` baris demi baris, seolah-olah kita mengikuti browser.

**Langkah 1 — `document.getElementById("taskInput")`**
Browser mencari di seluruh halaman elemen dengan `id="taskInput"`. Ketemu: elemen `<input>`. Objek elemen itu disimpan ke variabel `input`.

**Langkah 2 — `document.getElementById("judul")`**
Sama seperti tadi, tapi targetnya `<h1 id="judul">`. Objek `<h1>` disimpan ke variabel `judul`.

**Langkah 3 — `document.querySelector("#addBtn")`**
`querySelector` membaca selector CSS `#addBtn`, artinya "cari elemen dengan id `addBtn`". Elemen `<button id="addBtn">` ditemukan dan disimpan ke `button`.

**Langkah 4 — `document.querySelector(".btn")`**
Kali ini selector-nya `.btn` (class). Karena `querySelector` hanya mengembalikan yang pertama, hanya `<button class="btn">` yang diambil — dan ternyata itu memang elemen yang sama dengan langkah 3.

**Langkah 5 — `document.querySelectorAll(".task-item")`**
Browser mencari **semua** elemen dengan class `task-item` di dalam halaman. Saat ini `<div id="taskList">` masih kosong, jadi tidak ada satu pun yang cocok. Hasilnya NodeList berisi 0 elemen, disimpan ke `semuaItem`.

**Langkah 6 — tiga `console.log`**
Nilai `input`, `buttonLain`, dan `semuaItem.length` dicetak ke Console.

**Output akhir:**
```
<input id="taskInput" placeholder="Tambah task...">
<button id="addBtn" class="btn">Tambah</button>
0
```

## Analogi
Di perpustakaan, memilih elemen itu seperti **meminta kartu katalog ke pustakawan**. Kamu memberi kode tertentu — nomor rak (`getElementById`) atau kategori pencarian (`querySelector`) — lalu pustakawan mengambilkan bukunya. Kalau kamu minta "semua buku fiksi" (`querySelectorAll`), pustakawan memberikan tumpukan kartu, bukan cuma satu.

## Dipakai untuk Apa
- Menyimpan elemen form (`#taskInput`, `#addBtn`) agar bisa dibaca nilainya.
- Memilih seluruh daftar task (`.task-item`) untuk dihitung atau diubah massal.
- Menempelkan event listener ke tombol dan form.
- Menyiapkan elemen wadah (`#taskList`) tempat render daftar task.

## Kesalahan Umum yang Sering Terjadi
- **Salah penulisan selector**: Menulis `querySelector("taskList")` tanpa `#` — browser menganggapnya tag `<taskList>` yang tidak ada, hasilnya `null`. Selalu awali dengan `#` untuk id dan `.` untuk class.
- **Menggunakan hasil `querySelector` yang `null`**: Kalau elemen tidak ketemu, hasilnya `null`; akses `.value` atau `.addEventListener` padanya langsung melempar error `TypeError`. Selalu cek dulu atau pastikan script dimuat setelah elemen HTML.
- **Menyangka `querySelectorAll` mengembalikan array**: Ia mengembalikan NodeList, yang **tidak punya** method array seperti `push`, `map`, dan `forEach`-nya memang ada tapi cara paling aman adalah ubah dulu: `[...nodeList]`.
- **`getElementById` dipanggil dari `document.getElementByIdt` atau dari elemen**: Method ini khusus ada di `document`, bukan di elemen lain. Yang ada di elemen adalah `querySelector`.

## Soal Latihan & Jawaban
### Soal
Di halaman Task Manager terdapat tiga elemen: `<input id="taskInput">`, `<button class="btn">`, dan `<div id="taskList">` yang di dalamnya sudah ada dua elemen `<p class="task-item">`. Tulis kode JavaScript untuk:
1. Menyimpan elemen input ke variabel `input`.
2. Menyimpan elemen button ke variabel `btn` memakai `querySelector`.
3. Menyimpan semua `.task-item` ke variabel `items`, lalu tampilkan jumlahnya di Console.

### Jawaban
```js
// 1. Select input lewat id
let input = document.getElementById("taskInput");

// 2. Select button lewat selector CSS
let btn = document.querySelector(".btn");

// 3. Select semua task item — hasilnya NodeList
let items = document.querySelectorAll(".task-item");
console.log("Jumlah task:", items.length); // "Jumlah task: 2"
```
Buka `index.html` di browser (Live Server), tekan F12 untuk lihat Console/elemen.
