# Mengubah Content — textContent, innerHTML, innerText

## Penjelasan
Setelah elemen HTML kamu pilih (materi 43), langkah berikutnya adalah **mengubah isinya**. Ada tiga properti utama untuk itu:

- `element.textContent` — mengambil atau mengubah **teks murni** di dalam elemen. Isi apa pun yang kamu tulis di situ **bukan** dianggap HTML, jadi aman dari serangan XSS (inject script lewat input user).
- `element.innerHTML` — mengambil atau mengubah isi dalam bentuk **markup HTML**. Berguna saat ingin menambahkan banyak elemen sekaligus, tapi **berisiko** jika isinya berasal dari input user yang belum dibersihkan.
- `element.innerText` — mirip `textContent`, tapi **menghormati tampilan CSS**: teks yang disembunyikan lewat `display: none` tidak ikut terbaca, dan hasilnya memakai spasi ala tampilan layar.

Perbedaan kunci: `textContent` cepat dan membaca semuanya apa adanya; `innerText` lebih lambat karena harus memeriksa tampilan CSS; `innerHTML` satu-satunya yang bisa membuat elemen HTML baru dari string.

Aturan praktis:
- Tampilkan/ubah teks biasa → pakai `textContent`.
- Butuh sisipkan elemen HTML → pakai `innerHTML`, tapi jangan pernah dengan data user mentah.
- Membaca teks sesuai tampilan layar → `innerText`.

## Fungsi
Halaman statis isinya sudah ditentukan di HTML. Agar aplikasi terasa hidup, JavaScript harus bisa **menulis ulang isi halaman berdasarkan data** — misalnya menampilkan judul aplikasi baru, menaruh pesan "No tasks yet", atau merender seluruh daftar task dari array `TaskManager` ke dalam `#taskList`. Ketiga properti inilah alat untuk itu.

## Cara Pengimplementasian / Code
```js
// level5.js

// 1. Ubah judul halaman — textContent menulis teks murni
let heading = document.querySelector("h1");
heading.textContent = "Task Manager v1.0";

// 2. Isi wadah daftar task saat belum ada data
let taskDiv = document.getElementById("taskList");
taskDiv.textContent = "Belum ada task. Ayo tambah!";

// 3. innerHTML: sisipkan elemen HTML sekaligus
taskDiv.innerHTML = "<p class='empty-msg'>Belum ada task. Ayo tambah!</p>";

// 4. Baca isi elemen kembali
console.log(heading.textContent); // "Task Manager v1.0"
console.log(taskDiv.innerHTML);   // "<p class='empty-msg'>Belum ada task. Ayo tambah!</p>"

// 5. innerText menghormati CSS — <p> kedua disembunyikan lewat CSS
taskDiv.innerHTML += "<p class='hidden' style='display:none'>Teks tersembunyi</p>";
console.log(taskDiv.innerText); // hanya teks <p> pertama yang muncul
```

Cara menjalankan: buka `index.html` di browser (Live Server), tekan F12 untuk lihat Console/elemen.

## Tracing Code (Step-by-Step)
Kita ikuti browser mengeksekusi `level5.js` baris demi baris.

**Langkah 1 — `document.querySelector("h1")`**
Browser mencari `<h1>` pertama di halaman dan menyimpannya ke `heading`. Judul awal di HTML misalnya "Task Manager".

**Langkah 2 — `heading.textContent = "Task Manager v1.0"`**
Teks lama di dalam `<h1>` dibuang dan diganti total menjadi "Task Manager v1.0". Tampilan halaman langsung berubah.

**Langkah 3 — `document.getElementById("taskList")`**
`<div id="taskList">` dipilih dan disimpan ke `taskDiv`. Isinya masih kosong.

**Langkah 4 — `taskDiv.textContent = "Belum ada task. Ayo tambah!";`**
`div` yang tadinya kosong kini berisi teks itu, murni sebagai teks — tidak ada elemen di dalamnya.

**Langkah 5 — `taskDiv.innerHTML = "<p class='empty-msg'>...</p>"`**
Kali ini string-nya dibaca sebagai **HTML**. Hasilnya `div` berisi satu elemen `<p>` dengan class `empty-msg`. Teks lama dari langkah 4 hilang (karena `innerHTML = ...` menimpa seluruh isi).

**Langkah 6 — dua `console.log` pertama**
`heading.textContent` membaca teks di dalam `<h1>` → `"Task Manager v1.0"`. `taskDiv.innerHTML` membaca isi dalam bentuk markup → `"<p class='empty-msg'>Belum ada task. Ayo tambah!</p>"`.

**Langkah 7 — `taskDiv.innerHTML += ...`**
Tanda `+=` **menambah** di akhir isi, bukan menimpa. Sekarang `div` berisi dua `<p>`: yang pertama tampil, yang kedua punya `style='display:none'` sehingga tersembunyi di layar.

**Langkah 8 — `console.log(taskDiv.innerText)`**
`innerText` hanya membaca teks yang **terlihat** di layar. `<p>` kedua tersembunyi, jadi tidak ikut.

**Output akhir:**
```
Task Manager v1.0
<p class="empty-msg">Belum ada task. Ayo tambah!</p>
Belum ada task. Ayo tambah!
```

## Analogi
Bayangkan `<div id="taskList">` itu **papan pengumuman perpustakaan**. Mengubah `textContent` seperti menulis satu kalimat langsung ke papan dengan spidol. Mengubah `innerHTML` seperti menempelkan seluruh poster berisi gambar dan teks ke papan. Dan `innerText` seperti membaca papan dari jauh — tulisan yang ditutupi kertas lain (tersembunyi CSS) memang tidak kamu baca.

## Dipakai untuk Apa
- Merender daftar task dari array `TaskManager.getTasks()` ke `#taskList`.
- Menampilkan counter "Total: 3 task" di halaman.
- Menampilkan pesan kosong saat belum ada task.
- Mengupdate label tombol atau judul halaman secara dinamis.
- Notifikasi singkat ke user, misalnya "Task berhasil ditambahkan!".

## Kesalahan Umum yang Sering Terjadi
- **`innerHTML` dengan data user**: Menyisipkan judul task apa adanya (`taskDiv.innerHTML = userTitle`) — kalau user menulis `<img onerror=alert(1) src=x>`, script-nya ikut jalan (XSS). Hindari dengan pakai `textContent`, atau bersihkan input dulu.
- **Salah sangka `innerHTML = ""` menghapus elemen**: `innerHTML` mengganti isi elemen itu sendiri, bukan menghapus elemennya. Untuk menghapus elemennya, harus pakai `remove()` atau `parent.removeChild()`.
- **`innerText` vs `textContent` membingungkan**: Kalau kamu tidak butuh informasi visibilitas CSS, selalu pakai `textContent` — lebih cepat dan perilakunya paling mudah ditebak.
- **Menimpa isi tanpa sengaja**: `innerHTML = ...` membuang semua isi beserta event listener yang menempel di dalamnya. Kalau daftar sering di-update, pakai cara yang lebih hati-hati (lihat materi 48 tentang event delegation).

## Soal Latihan & Jawaban
### Soal
Saat aplikasi dibuka dan `TaskManager.getTasks()` mengembalikan `[{ id: 1, title: "Rapikan rak buku" }]`, kamu diminta menampilkan isi `#taskList` sebagai berikut (elemen `<p>` dengan teks tebal):

> **1. Rapikan rak buku**

Tulis kode yang menampilkan daftar itu dengan `innerHTML`, lalu tampilkan juga isi asli `#taskList` (sebagai HTML) di Console.

### Jawaban
```js
// Data dari TaskManager Level 4
let manager = new TaskManager(); // sudah ada task "Rapikan rak buku" dengan id 1
let tasks = manager.getTasks();

// Susun string HTML dari seluruh task
let html = "";
for (let t of tasks) {
  html += "<p><strong>" + t.id + ". " + t.title + "</strong></p>";
}

// Tulis ke dalam wadah daftar
let taskDiv = document.getElementById("taskList");
taskDiv.innerHTML = html;

// Baca kembali isi dalam bentuk HTML
console.log(taskDiv.innerHTML);
// Output: "<p><strong>1. Rapikan rak buku</strong></p>"
```
Buka `index.html` di browser (Live Server), tekan F12 untuk lihat Console/elemen.
