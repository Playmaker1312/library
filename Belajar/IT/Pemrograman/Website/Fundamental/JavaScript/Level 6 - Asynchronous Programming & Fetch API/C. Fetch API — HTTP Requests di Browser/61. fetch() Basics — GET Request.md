# fetch() Basics — GET Request

## Penjelasan
`fetch()` adalah fungsi bawaan browser untuk **mengirim request HTTP** (permintaan data) ke sebuah URL. Cukup tulis `fetch(url)`, dan browser mengurus pengirimannya. Dua hal wajib diketahui:
- `fetch(url)` **mengembalikan Promise**, bukan data. Jadi hasilnya harus dikonsumsi dengan `.then()` atau `await`.
- Yang pertama kamu terima adalah objek **Response** (jawaban server): berisi status, header, dan **body yang belum dibaca**. Body-nya dibaca lewat `response.json()` (atau `.text()`), dan `response.json()` ini **juga mengembalikan Promise** karena mengubah teks JSON menjadi objek JavaScript.
- `fetch` memakai **GET** secara default — metode untuk **mengambil** data, metode paling dasar dalam HTTP.
- `response.ok` bernilai `true` kalau status 200–299 (sukses), `false` untuk 404, 500, dll.

Penting: `fetch` hanya **reject** (masuk `.catch`) kalau koneksi gagal total (misal internet putus). Server yang menjawab 404 atau 500 tetap dianggap "ada jawaban", jadi **kamu wajib mengecek `response.ok` sendiri**.

## Fungsi
Selama ini data Task Manager berasal dari localStorage — hanya isian browser sendiri. Dengan `fetch`, aplikasi bisa **mengambil data dari server orang lain** (API): daftar task, data user, berita, cuaca, harga, dan sebagainya. Ini langkah pertama integrasi Task Manager dengan API, sekaligus latihan membaca hasil Promise dari materi sebelumnya.

## Cara Pengimplementasian / Code
```js
// level6.js — ambil 5 task pertama dari API publik JSONPlaceholder
fetch("https://jsonplaceholder.typicode.com/todos?_limit=5")
  .then((response) => {
    // Cek status HTTP dulu; false untuk status 404, 500, dll.
    if (!response.ok) {
      throw new Error("Request gagal, status " + response.status);
    }
    // Ubah body JSON menjadi objek JS — method ini juga mengembalikan Promise
    return response.json();
  })
  .then((tasks) => {
    console.log("Jumlah task masuk:", tasks.length);
    console.log("Task pertama:", tasks[0].title);
  })
  .catch((error) => console.error("Error:", error.message));
```

Cara menjalankan: simpan kode di atas sebagai `level6.js`, lalu muat dari `level6.html` dengan `<script src="level6.js"></script>`. Buka file HTML itu di browser, tekan **F12** → tab **Console** (juga bisa intip **tab Network** untuk melihat request-nya). Kalau nanti pakai endpoint sendiri, cukup ganti URL-nya dengan `/api/tasks` dari materi 69.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

```js
fetch("https://jsonplaceholder.typicode.com/todos?_limit=5")
  .then((response) => {
    if (!response.ok) throw new Error("Request gagal, status " + response.status);
    return response.json();
  })
  .then((tasks) => {
    console.log("Jumlah task masuk:", tasks.length);
    console.log("Task pertama:", tasks[0].title);
  })
  .catch((error) => console.error("Error:", error.message));
```

**Langkah 1 — baris `fetch(...)`**
Browser mengirim request GET ke jsonplaceholder.typicode.com. Fungsi ini **langsung selesai** dan mengembalikan Promise berstatus **pending** — belum ada data sama sekali. Kedua `.then` dan `.catch` hanya mendaftarkan fungsi masing-masing, lalu program selesai menulis kode dan tinggal menunggu.

**Langkah 2 — server menjawab (beberapa ratus ms kemudian)**
Server mengirim balasan berisi status `200` dan body berupa **teks JSON** (bukan objek). Promise pertama berpindah ke **resolved** dengan isi objek `response`.

**Langkah 3 — `.then` pertama dijalankan**
`response.ok` bernilai `true` (status 200), jadi `if (!response.ok)` **tidak dimasuki** dan `throw` tidak terjadi. Lalu `return response.json()` dijalankan: teks JSON mulai diubah jadi objek JavaScript. Karena proses ini butuh waktu, `return` itu **meneruskan Promise kedua** ke `.then` berikutnya — rantai menunggu promise ini.

**Langkah 4 — teks selesai diubah jadi objek**
`.then` kedua dijalankan dengan `tasks` berupa array 5 objek task (urutan sesuai server). `tasks.length` bernilai `5`, dan `tasks[0].title` berisi judul task id 1.

**Langkah 5 — `.catch` dilewati**
Tidak ada error sama sekali, jadi tidak ada yang tercetak dari blok `.catch`.

**Output akhir:**
```
Jumlah task masuk: 5
Task pertama: delectus aut autem
```

## Analogi
Memesan daftar buku dari gudang pusat lewat kurir. Kamu menyerahkan formulir (request) dan beberapa saat kemudian kurir kembali membawa **amplop** (Response). Amplop itu belum boleh langsung dipakai: kamu cek dulu stempelnya apakah bertuliskan "diterima" (`response.ok`), baru amplop dibuka dan isinya dibaca (`response.json()`). Kalau kurirnya tidak datang sama sekali (koneksi putus), barulah kamu panik — itulah satu-satunya kondisi `fetch` menyerah tanpa amplop.

## Kesalahan Umum yang Sering Terjadi
- **Lupa cek `response.ok`**: status 404/500 tetap dianggap sukses oleh `fetch`, jadi kamu lanjut memparse halaman error sebagai data — hasilnya `undefined` atau error membingungkan. Selalu cek `response.ok` lalu `throw`.
- **Menganggap `fetch` langsung reject untuk status error**: `fetch` hanya reject saat koneksi gagal. Error HTTP harus kamu deteksi sendiri.
- **Lupa `response.json()`**: `console.log(response)` hanya menampilkan objek `Response` (kosong), bukan data. Ingat, `.json()` juga mengembalikan Promise, jadi butuh `.then` lagi atau `await`.
- **Menyimpan `fetch(url)` langsung ke variabel**: `let data = fetch(url)` berisi **Promise**, bukan data — mengakses `data.title` hasilnya `undefined`.
- **Mengabaikan waktu tunggu**: tepat setelah baris `fetch`, data belum ada. Kode yang membaca hasilnya harus berada di dalam `.then` atau setelah `await` (materi 64).

## Soal Latihan & Jawaban
### Soal
Muat 3 todo pertama dari `https://jsonplaceholder.typicode.com/todos?_limit=3`, lalu tampilkan id dan judul tiap task memakai `.then()`. Jika request gagal atau statusnya bukan 2xx, tampilkan pesan "Gagal memuat task: <pesan error>".

### Jawaban
```js
fetch("https://jsonplaceholder.typicode.com/todos?_limit=3")
  .then((response) => {
    // 2xx = sukses; selain itu anggap gagal
    if (!response.ok) throw new Error("status " + response.status);
    return response.json(); // teks JSON → objek JS (masih sebuah Promise)
  })
  .then((tasks) => {
    tasks.forEach((task) => console.log(task.id + ". " + task.title));
  })
  .catch((error) => console.error("Gagal memuat task:", error.message));

// Output:
// 1. delectus aut autem
// 2. quis ut nam facilis et officia qui
// 3. fugiat veniam minus
```
