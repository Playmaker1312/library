# Parallel & Sequential Async — Promise.all dalam async-await

## Penjelasan
Saat ada beberapa operasi async, ada dua cara menjalankannya:

- **Sequential (berurutan)**: satu `await` setelah lainnya. Operasi kedua baru dimulai setelah yang pertama selesai. Total waktu = jumlah semua waktu.
- **Parallel (bersamaan)**: semua promise dimulai **dulu sekaligus**, baru hasilnya di-`await` bersamaan dengan `Promise.all([...])`. Total waktu = waktu operasi paling lama.

Kata kuncinya: `await` tidak membuat promise mulai bekerja — promise mulai bekerja saat **dipanggil**. `await` hanya menunggu hasilnya. Jadi kalau kamu menulis `await a(); await b();`, promise `b` bahkan belum sempat dimulai saat `a` dikerjakan.

`Promise.all([...])` menerima array promise dan mengembalikan satu promise berisi array hasil, sesuai urutan aslinya. Kalau **salah satu** gagal, `Promise.all` langsung gagal — dan errornya bisa ditangkap `try...catch` seperti biasa.

Aturan praktis:
- Pakai **sequential** kalau hasil operasi pertama dibutuhkan untuk operasi kedua (misalnya butuh `user.id` sebelum ambil posts).
- Pakai **parallel** kalau operasinya tidak saling bergantung (misalnya ambil tasks dan ambil user sekaligus).

## Fungsi
Menjalankan operasi bergantungan secara berurutan membuat aplikasi lambat tanpa alasan — pengguna menunggu jumlah semua delay. Dengan `Promise.all`, beberapa request berjalan bersamaan dan waktu tunggu jauh berkurang. Ini penting di aplikasi Task Manager modern yang memuat banyak data sekaligus saat halaman dibuka.

## Cara Pengimplementasian / Code
```js
// Mock API: meniru jeda server berbeda-beda
function mockFetch(url, delay) {
  return new Promise((resolve) => {
    setTimeout(() => resolve({ url, selesai: true }), delay);
  });
}

class TaskManager {
  // SEQUENTIAL: hasil tasks baru dipakai setelah selesai, lalu lanjut
  async muatSemuaSequential() {
    let tasks = await mockFetch("/api/tasks", 2000);
    let user = await mockFetch("/api/users/1", 1000);
    return { tasks, user };
  }

  // PARALLEL: dua promise dimulai bareng, hasilnya diambil bersamaan
  async muatSemuaParallel() {
    let [tasks, user] = await Promise.all([
      mockFetch("/api/tasks", 2000),
      mockFetch("/api/users/1", 1000),
    ]);
    return { tasks, user };
  }
}

let manager = new TaskManager();

(async () => {
  console.time("sequential");
  await manager.muatSemuaSequential();
  console.timeEnd("sequential"); // total = 2000 + 1000

  console.time("parallel");
  await manager.muatSemuaParallel();
  console.timeEnd("parallel");   // total = 2000 (yang paling lama)
})();
```
Cara menjalankan: simpan kode di atas sebagai file `level6.js`, muat dari `level6.html` (`<script src="level6.js"></script>`), lalu buka di browser dan tekan F12 → tab Console (tab Network juga bisa dipakai untuk membandingkan durasi request sungguhan).

## Tracing Code (Step-by-Step)
Kita telusuri kedua method untuk melihat kapan tiap promise dimulai dan kapan ditunggu.

**Bagian 1 — `muatSemuaSequential()`:**

**Langkah 1 — baris `let tasks = await mockFetch(..., 2000)`**
Promise pertama **mulai dikerjakan** (timer 2 detik jalan). Kode method berhenti di `await`, menunggu promise itu.

**Langkah 2 — 2 detik kemudian**
Promise pertama resolved, `tasks` berisi hasilnya. Barulah baris berikutnya dijalankan.

**Langkah 3 — 2 detik kemudian, promise pertama selesai**
`tasks` berisi hasilnya, lalu baris berikutnya baru dijalankan: promise kedua `mockFetch("/api/users/1", 1000)` **baru mulai dikerjakan** dan method berhenti menunggu lagi. 1 detik kemudian `user` berisi hasilnya, method mengembalikan `{ tasks, user }`. Total waktu tunggu: **2000 + 1000 = 3000 ms**. Lini masa eksekusinya:

| Waktu | Yang berjalan |
|---|---|
| 0 - 2000 ms | menunggu `/api/tasks` (yang kedua belum dimulai) |
| 2000 - 3000 ms | menunggu `/api/users/1` |
| 3000 ms | selesai |

**Bagian 2 — `muatSemuaParallel()`:**

**Langkah 5 — `Promise.all([...])` memanggil kedua promise sekaligus**
Kedua `mockFetch` **langsung dipanggil bersamaan** — timer 2 detik dan 1 detik berjalan bersamaan. Saat `await` menghentikan method, keduanya sudah bekerja; tinggal menunggu yang paling lama, yaitu 2 detik.

**Langkah 6 — 2 detik kemudian, `await` melepas nilai**
`Promise.all` menghasilkan array hasil berurutan sesuai urutan di array, lalu dipecah dengan destructuring: `tasks` dapat hasil pertama, `user` hasil kedua. Total waktu: **2000 ms** (bukan 3000 ms). Catatan: karena `user` sebenarnya sudah selesai di detik ke-1, hasilnya menunggu "temannya" sampai detik ke-2.

**Output akhir:**
```
sequential: 3000.5ms
parallel: 2000.2ms
```
(Angka desimal bisa sedikit berbeda tergantung komputer; yang penting: sequential ±3 detik, parallel ±2 detik.)

## Analogi
Di perpustakaan, kamu memesan dua buku ke gudang pusat. **Sequential**: pustakawan memesan buku A, duduk menunggu datang (2 menit), baru setelah itu memesan buku B dan menunggu lagi (1 menit) — total 3 menit. **Parallel**: pustakawan memesan A dan B **di saat yang sama** lewat dua formulir, lalu menunggu berdua — total tinggal 2 menit, yaitu lama buku yang paling lambat datang. Pustakawan yang pintar memilih cara kedua selama tidak ada buku yang saling butuh.

## Dipakai untuk Apa
- Memuat daftar task dan data user sekaligus saat aplikasi Task Manager dibuka.
- Menampilkan dashboard yang butuh beberapa endpoint (tasks, kategori, statistik) sekaligus.
- Menggabungkan hasil banyak request jadi satu objek untuk dirender.
- Mempercepat halaman yang sebelumnya memuat data berurutan tanpa perlu saling bergantung.

## Kesalahan Umum yang Sering Terjadi
- **Salah urutan `await` yang menyebabkan tak perlu paralel**: `let a = await x(); let b = await y();` lalu mengira keduanya bersamaan. Yang benar: panggil dulu kedua promise-nya, baru `await` dengan `Promise.all`.
- **`Promise.all` langsung gagal saat satu promise gagal**: Jika satu di antaranya rejected, hasil yang sukses ikut terbuang dan error menyebar ke `try...catch`. Kalau kamu mau hasil apa adanya meski sebagian gagal, gunakan `Promise.allSettled`.
- **Mengubah hasil setelah destructure tanpa sadar**: `let [tasks, user] = await Promise.all([...])` menghasilkan salinan referensi hasil — memodifikasi isinya berdampak pada data asli yang dipakai komponen lain.
- **Parallel untuk operasi yang bergantung**: Menjalankan `fetchPosts(user.id)` bersamaan dengan `fetchUser()` padahal `user.id` belum diketahui → nilai `user.id` masih `undefined` dan request-nya gagal. Pastikan hasilnya benar-benar tidak saling butuh.

## Soal Latihan & Jawaban
### Soal
Saat aplikasi Task Manager dibuka, kamu perlu memuat 3 data: `/api/tasks` (delay 1500 ms), `/api/categories` (delay 1000 ms), dan `/api/user` (delay 500 ms). Tulis method `async muatDashboard()` yang menjalankan ketiganya secara parallel menggunakan `Promise.all` dan `async/await`, lalu tampilkan total waktu yang dibutuhkan.

### Jawaban
```js
// Mock API dengan delay berbeda-beda
function mockFetch(url, delay) {
  return new Promise((resolve) => {
    setTimeout(() => resolve({ url, data: "isi " + url }), delay);
  });
}

class TaskManager {
  // Parallel: ketiga promise dimulai bersamaan
  async muatDashboard() {
    let [tasks, categories, user] = await Promise.all([
      mockFetch("/api/tasks", 1500),
      mockFetch("/api/categories", 1000),
      mockFetch("/api/user", 500),
    ]);
    return { tasks, categories, user };
  }
}

let manager = new TaskManager();

(async () => {
  console.time("dashboard");
  let hasil = await manager.muatDashboard();
  console.timeEnd("dashboard"); // ±1500ms, bukan 3000ms
  console.log("Data masuk:", hasil);
})();
```
