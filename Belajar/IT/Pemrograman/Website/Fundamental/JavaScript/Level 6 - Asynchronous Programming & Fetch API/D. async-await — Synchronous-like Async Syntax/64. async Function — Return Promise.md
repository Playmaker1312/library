# async Function — Return Promise

## Penjelasan
`async` adalah kata kunci untuk membuat function yang **selalu mengembalikan promise** (janji yang berisi hasil di kemudian hari). Di dalam function `async`, kamu bisa memakai `await` untuk **menunggu sebuah promise selesai** sebelum lanjut ke baris berikutnya.

Aturan penting:
- Function `async` selalu return promise, **meskipun kamu menulis angka biasa** — JavaScript otomatis membungkusnya dalam resolved promise (promise yang langsung sukses).
- `await expression` artinya: "jalan dulu promise-nya, saya tunggu di sini sampai selesai, lalu ambil hasilnya".
- `await` **hanya boleh di dalam** function `async` (atau di top-level module).
- Setelah `await`, kode berhenti dulu di situ — tapi browser tetap bekerja, tidak macet.
- Hasil setelah `await` adalah **nilai hasil promise**, bukan promise-nya.

`async/await` sebenarnya hanya tampilan rapi dari promise — di balik layar tetap `.then()` dan `.catch()`.

## Fungsi
Dengan promise biasa (`.then().catch()`), kode yang berurutan jadi bersarang dan susah dibaca. `async/await` membuat operasi asynchronous terlihat seperti kode biasa yang berjalan dari atas ke bawah. Ini standar modern JavaScript untuk menangani operasi yang butuh waktu, seperti mengambil data dari server.

## Cara Pengimplementasian / Code
```js
// Mock fetch sederhana: meniru jeda server 1 detik, tanpa server sungguhan
function ambilDariServer(url) {
  return new Promise((resolve) => {
    setTimeout(() => resolve({ tasks: ["Belajar JS", "Bikin UI"] }), 1000);
  });
}

class TaskManager {
  #tasks = [];

  // async: method ini SELALU mengembalikan promise
  async loadTasks() {
    let data = await ambilDariServer("/api/tasks"); // ditunggu 1 detik, hasilnya data
    this.#tasks = data.tasks;
    return this.#tasks; // angka/array biasa tetap dibungkus promise otomatis
  }

  async hitungJumlahTask() {
    let data = await this.loadTasks(); // await method async lain juga boleh
    return data.length; // return angka biasa → otomatis jadi promise<number>
  }
}

let manager = new TaskManager();

// Cara memanggil: hasilnya tetap promise, jadi bisa .then() atau await
let promiseTasks = manager.loadTasks();
console.log("setelah dipanggil:", promiseTasks); // masih pending

promiseTasks.then((hasil) => console.log("hasil loadTasks:", hasil));
manager.hitungJumlahTask().then((n) => console.log("jumlah task:", n));
```
Cara menjalankan: simpan kode di atas sebagai file `level6.js`, muat dari `level6.html` (`<script src="level6.js"></script>`), lalu buka di browser dan tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris.

```js
let promiseTasks = manager.loadTasks();
console.log("setelah dipanggil:", promiseTasks);
```

**Langkah 1 — `manager.loadTasks()` dipanggil**
Karena `loadTasks` bertanda `async`, JavaScript langsung membuat promise lalu menjalankan isi method-nya. Yang dikembalikan ke variabel `promiseTasks` adalah **promise**, bukan daftar task.

**Langkah 2 — baris `let data = await ...` di dalam method**
`await` membuat kode method berhenti di baris ini dulu. `ambilDariServer("/api/tasks")` jalan — di dalamnya ada `setTimeout` 1 detik. Selama menunggu, eksekusi program bebas mengerjakan hal lain.

**Langkah 3 — baris `console.log("setelah dipanggil:", ...)`**
Karena metode `loadTasks` sedang berhenti menunggu (pending), yang dicetak adalah promise dengan status pending. Ini terjadi **sebelum** data datang.

**Langkah 4 — 1 detik kemudian, `setTimeout` berbunyi**
Promise dari `ambilDariServer` sukses (resolved) berisi `{ tasks: [...] }`. Karena `await` sekarang sudah punya hasil, kode method lanjut: `data` berisi objek itu, lalu `this.#tasks = ["Belajar JS", "Bikin UI"]`.

**Langkah 5 — `return this.#tasks;`**
Nilai array dikembalikan, tapi karena method-nya `async`, promise dari `loadTasks` kini resolved berisi array tersebut. Promise inilah yang mengaktifkan `.then()` di Langkah 6.

**Langkah 6 — `.then((hasil) => ...)` jalan**
`hasil` berisi `["Belajar JS", "Bikin UI"]` dan dicetak ke console. Bersamaan itu, `hitungJumlahTask` juga sudah menunggu `loadTasks` (sudah resolved, jadi cepat) lalu mengembalikan angka `2` (otomatis dibungkus promise), sehingga `jumlah task: 2` ikut tercetak.

**Output akhir:**
```
setelah dipanggil: Promise { <pending> }
hasil loadTasks: [ 'Belajar JS', 'Bikin UI' ]
jumlah task: 2
```
(Tiga baris terakhir muncul setelah jeda ±1 detik.)

## Analogi
Pustakawan memesan buku ke gudang pusat. Saat memesan, dia **langsung memberi kamu nomor resi** (promise) — bukunya belum ada, tapi resi sudah ada di tanganmu. Kata `async` membuat metode pesan-buku ini resmi berjanji: "nanti kuberikan hasilnya lewat resi ini". `await` artinya pustakawan menempel di meja sambil menunggu buku datang, dan begitu datang, yang dia serahkan ke rak buku adalah **buku aslinya**, bukan resinya lagi.

## Dipakai untuk Apa
- Mengambil daftar task dari server saat aplikasi dibuka (`loadTasks`).
- Menyimpan task baru ke server sebelum menampilkan ulang daftarnya.
- Mengganti rantai `.then().then()` yang bersarang jadi kode lurus yang mudah dibaca.
- Menjalankan beberapa operasi berurutan yang masing-masing butuh waktu.

## Kesalahan Umum yang Sering Terjadi
- **`await` di luar function `async`**: Menulis `await` di top-level script biasa atau function biasa → error `SyntaxError: await is only valid in async functions`. Cara menghindari: bungkus dengan `async` function, atau pakai module (`type="module"`).
- **Lupa `await`, variabel berisi promise**: `let data = loadTasks();` tanpa `await` membuat `data` berisi promise, bukan array task. Mengakses `data.length` jadi `undefined`. Selalu tulis `await` kalau mau isi promise-nya.
- **Menganggap `await` menghentikan seluruh program**: Yang berhenti hanya baris di dalam function `async` itu. Event listener dan kode lain tetap jalan — jangan pakai `await` untuk "membekukan" aplikasi.
- **Lupa bahwa return value dibungkus promise**: `return 5;` di dalam `async` function menghasilkan `Promise { 5 }`, bukan `5`. Harus `await` atau `.then()` dulu untuk dapat angkanya.

## Soal Latihan & Jawaban
### Soal
Di aplikasi Task Manager, buat method async `ambilTaskPertama()` pada class `TaskManager` yang menunggu 1 detik (meniru server) lalu mengembalikan task pertama dari daftar `["Belajar JS", "Bikin UI", "Refactor Level 5"]`. Panggil method itu dua cara: dengan `.then()`, dan dengan `await` di dalam function async. Tampilkan hasilnya di console.

### Jawaban
```js
class TaskManager {
  #tasks = ["Belajar JS", "Bikin UI", "Refactor Level 5"];

  // Meniru server: selesai setelah 1 detik
  async ambilTaskPertama() {
    await new Promise((resolve) => setTimeout(resolve, 1000));
    return this.#tasks[0]; // otomatis dibungkus promise
  }
}

let manager = new TaskManager();

// Cara 1: dengan .then()
manager.ambilTaskPertama().then((t) => console.log(".then():", t));

// Cara 2: dengan await di dalam function async
(async () => {
  let hasil = await manager.ambilTaskPertama();
  console.log("await:", hasil);
})();
// Output setelah ±1 detik:
// .then(): Belajar JS
// await: Belajar JS
```
