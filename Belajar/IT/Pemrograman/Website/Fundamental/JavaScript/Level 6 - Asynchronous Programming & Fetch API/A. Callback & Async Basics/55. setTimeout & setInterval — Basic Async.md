# setTimeout & setInterval — Basic Async

## Penjelasan
`setTimeout` dan `setInterval` adalah fungsi bawaan browser untuk **menjalankan kode nanti, bukan sekarang**. `setTimeout(callback, delay)` menjalankan `callback` (fungsi yang disiapkan lebih dulu, lalu dipanggil setelah jeda) sekali saja setelah `delay` milidetik. `setInterval(callback, interval)` menjalankan `callback` berulang-ulang setiap `interval` milidetik.

Fakta penting:
- JavaScript bersifat **single-threaded**: satu urutan kode dikerjakan pada satu waktu.
- Kode **synchronous** (sinkron) bersifat **blocking** — berjalan langsung dan menahan semua kode di belakangnya sampai selesai.
- Kode **asynchronous** (asinkron) bersifat **non-blocking** — JavaScript mencatat jadwalnya, lalu lanjut ke baris berikutnya. Callback-nya baru dijalankan setelah jeda lewat.
- Kedua fungsi mengembalikan **id** (nomor jadwal) untuk membatalkan lewat `clearTimeout(id)` atau `clearInterval(id)`.
- Delay adalah **janji minimum, bukan waktu pasti**. Saat tab tidak aktif, browser boleh menunda callback-nya.

## Fungsi
Banyak fitur tidak boleh menahan layar sambil menunggu: menampilkan pesan "Task tersimpan!" selama beberapa detik, hitung mundur, memuat data setelah halaman tampil, atau mengecek server berkala. Tanpa `setTimeout`/`setInterval`, satu-satunya cara adalah membiarkan kode menunggu dan layar terasa macet. Dua fungsi ini adalah pintu pertama kamu ke pola asinkron (pola di mana kode dijalankan tidak berurutan).

## Cara Pengimplementasian / Code
```js
// level6.js
console.log("Aplikasi dimulai");

// Dijalankan SEKALI, 1,5 detik kemudian
setTimeout(() => {
  console.log("Task selesai dimuat");
}, 1500);

console.log("UI siap dipakai"); // tidak menunggu setTimeout di atas

// Dijalankan BERULANG setiap 1 detik sampai dibatalkan
let sisa = 3;
let pengingat = setInterval(() => {
  console.log("Sinkronisasi: " + sisa + " detik lagi");
  sisa--;
  if (sisa < 0) { // berhenti setelah hitungan habis
    clearInterval(pengingat);
    console.log("Sinkronisasi selesai");
  }
}, 1000);

// Contoh pembatalan: notifikasi ini dicabut sebelum waktunya
let notifikasi = setTimeout(() => console.log("Tidak akan muncul"), 5000);
clearTimeout(notifikasi);
```

Cara menjalankan: simpan kode di atas sebagai `level6.js`, lalu muat dari `level6.html` dengan `<script src="level6.js"></script>`. Buka file HTML itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

```js
console.log("Aplikasi dimulai");
setTimeout(() => { console.log("Task selesai dimuat"); }, 1500);
console.log("UI siap dipakai");
let sisa = 3;
let pengingat = setInterval(() => { ...isi... }, 1000);
let notifikasi = setTimeout(() => console.log("Tidak akan muncul"), 5000);
clearTimeout(notifikasi);
```

**Langkah 1 — baris `console.log("Aplikasi dimulai")`**
JavaScript menjalankannya langsung. Belum ada yang ditunda.

**Langkah 2 — blok `setTimeout(...)`**
JavaScript **tidak menunggu** 1,5 detik. Ia hanya mencatat jadwal: "jalankan fungsi ini nanti, 1.500 ms dari sekarang". Fungsinya belum pernah dijalankan, lalu eksekusi lanjut ke baris berikutnya.

**Langkah 3 — baris `console.log("UI siap dipakai")`**
Langsung tercetak. Ini bukti jadwal `setTimeout` tadi tidak menahan kode.

**Langkah 4 — blok `setInterval(...)`**
Jadwal kedua dicatat: jalankan pertama kali 1.000 ms dari sekarang, lalu ulangi tiap 1.000 ms. Variabel `sisa` dibuat berisi 3, dan `pengingat` diisi nomor jadwalnya.

**Langkah 5 — baris `setTimeout(...)` + `clearTimeout(notifikasi)`**
Jadwal notifikasi dicatat untuk 5.000 ms, tapi langsung dicabut lewat nomor `notifikasi`. Fungsinya tidak akan pernah jalan.

**Langkah 6 — setelah 1.000 ms**
Callback interval dijalankan pertama kali: mencetak "Sinkronisasi: 3 detik lagi", lalu `sisa` berubah dari 3 jadi 2.

**Langkah 7 — setelah 1.500 ms**
Callback `setTimeout` dijalankan: mencetak "Task selesai dimuat".

**Langkah 8 — interval berikutnya tiap 1.000 ms**

| Ke- | Waktu | Yang dicetak | Isi `sisa` setelah `sisa--` |
|---|---|---|---|
| 1 | 1000 ms | Sinkronisasi: 3 detik lagi | 2 |
| 2 | 2000 ms | Sinkronisasi: 2 detik lagi | 1 |
| 3 | 3000 ms | Sinkronisasi: 1 detik lagi | 0 |
| 4 | 4000 ms | Sinkronisasi: 0 detik lagi | -1, lalu `clearInterval` + "Sinkronisasi selesai" |

**Output akhir:**
```
Aplikasi dimulai
UI siap dipakai
Sinkronisasi: 3 detik lagi
Task selesai dimuat
Sinkronisasi: 2 detik lagi
Sinkronisasi: 1 detik lagi
Sinkronisasi: 0 detik lagi
Sinkronisasi selesai
```

## Analogi
Di perpustakaan, ini seperti **catatan tunda di meja pustakawan**. Pustakawan menempel catatan "umumkan buku baru 1,5 menit lagi" di papan, lalu tetap melayani antrean — catatan itu baru dibacakan setelah jadwalnya tiba. `setInterval` kira-kira seperti **lonceng pengingat** yang berbunyi tiap satu menit, sampai pustakawan mencabutnya dengan `clearInterval`.

## Dipakai untuk Apa
- Toast pesan "Task tersimpan!" yang hilang sendiri setelah beberapa detik
- Hitung mundur sebelum halaman memuat ulang data
- Menampilkan indikator loading sambil menunggu data (materi 68)
- Mengecek server berkala tiap beberapa detik (polling)
- Menunda render sedikit supaya halaman sempat tampil dulu

## Kesalahan Umum yang Sering Terjadi
- **Menganggap isi `setTimeout` langsung berjalan**: yang langsung berjalan adalah baris *setelah* `setTimeout`, bukan isinya. Akibatnya urutan log di console tidak seperti yang kamu bayangkan. Hindari: ingat, callback baru jalan setelah jeda lewat.
- **Lupa membatalkan `setInterval`**: callback terus berjalan tiap interval, memboroskan memori dan menumpuk log/DOM yang sudah tidak relevan. Hindari: simpan id-nya, lalu `clearInterval` saat sudah selesai (misal saat modal ditutup).
- **Salah satuan waktu**: delay ditulis dalam milidetik. `setTimeout(..., 2)` berarti 2 milidetik (nyaris instan), bukan 2 detik.
- **Menganggap jadwal waktunya selalu tepat**: saat tab berada di background, browser menunda timer (throttling), jadi interval bisa meleset. Hindari: jangan menaruh logika kritis di keakuratan waktu.

## Soal Latihan & Jawaban
### Soal
Saat halaman Task Manager dibuka, aplikasi diminta: (1) mencetak "Memuat task..." seketika, (2) mencetak "Task siap!" setelah 1,5 detik, (3) mencetak hitung mundur "Autosave dalam 3 detik", "Autosave dalam 2 detik", "Autosave dalam 1 detik" tiap detik, lalu mencetak "Autosave dijalankan" dan interval-nya berhenti total. Buat kodenya.

### Jawaban
```js
console.log("Memuat task...");

setTimeout(() => {
  console.log("Task siap!");
}, 1500);

let hitung = 3;
let otomatis = setInterval(() => {
  if (hitung > 0) {
    console.log("Autosave dalam " + hitung + " detik");
    hitung--;
  } else {
    console.log("Autosave dijalankan");
    clearInterval(otomatis); // hentikan interval setelah sekali jalan
  }
}, 1000);
```
