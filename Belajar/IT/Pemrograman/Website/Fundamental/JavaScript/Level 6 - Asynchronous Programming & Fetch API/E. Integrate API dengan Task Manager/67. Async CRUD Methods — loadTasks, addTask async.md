# Async CRUD Methods — loadTasks, addTask async

## Penjelasan
CRUD (Create, Read, Update, Delete) sebelumnya dijalankan synchronous: data langsung ada di memori atau localStorage. Sekarang data tinggal di **server**, jadi tiap operasi butuh waktu menunggu jaringan — sehingga semua method CRUD dibuat `async` dan memakai `await` terhadap `fetch()`. Pola umum tiap method:
- **`loadTasks()`** — GET `/api/tasks`, simpan ke `#tasks`; kalau gagal, fallback (jalan ke alternatif) ke localStorage.
- **`addTask(title)`** — POST `/api/tasks` dengan body JSON; kalau server sukses (`response.ok`), task ditambahkan ke `#tasks` lokal.
- **`updateTask(id, updates)`** — PUT `/api/tasks/:id`, lalu sinkronkan array lokal. **`deleteTask(id)`** — DELETE `/api/tasks/:id`, lalu hapus dari array lokal. Prinsip penting: **server adalah sumber kebenaran** — array `#tasks` hanya "tampilan lokal" yang disinkronkan setelah operasi server selesai, dan tiap method dibungkus `try...catch` supaya kegagalan jaringan tidak membekukan aplikasi.

## Fungsi
Sebelumnya Task Manager menyimpan data di localStorage — hanya hidup di satu browser. Dengan method async CRUD, data tersimpan di server sehingga bisa diakses dari device mana pun, dan jadi fondasi aplikasi multi-pengguna. Ini adalah refactor besar Level 5 → Level 6: bentuk class tidak berubah banyak, tapi semua method yang menyentuh data kini ber-`async`.

## Cara Pengimplementasian / Code
```js
class TaskManager {
  #tasks = [];
  #nextId = 1;

  async loadTasks() {
    try {
      let response = await fetch("/api/tasks"); // GET: ambil semua task
      let data = await response.json();
      this.#tasks = data;
      // nextId = id terbesar + 1, supaya id baru tidak bentrok
      this.#nextId = Math.max(...data.map((t) => t.id), 0) + 1;
    } catch (error) {
      console.error("Load failed:", error);
      // Fallback: kalau API down, muat dari localStorage
      let stored = localStorage.getItem("tasks");
      this.#tasks = stored ? JSON.parse(stored) : [];
    }
  }

  async addTask(title) {
    if (!title.trim()) return null;
    let newTask = { id: this.#nextId++, title, completed: false, createdAt: new Date() };

    try {
      // POST: kirim task baru ke API
      let response = await fetch("/api/tasks", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(newTask), // object → string JSON
      });
      if (!response.ok) throw new Error("Create failed");
      this.#tasks.push(newTask); // sinkronkan data lokal
      return newTask;
    } catch (error) {
      console.error("Add task error:", error);
      throw error; // lempar lagi supaya pemanggil bisa tahu gagal
    }
  }

  async deleteTask(id) {
    try {
      // DELETE: hapus di server
      let response = await fetch(`/api/tasks/${id}`, { method: "DELETE" });
      if (!response.ok) throw new Error("Delete failed");
      this.#tasks = this.#tasks.filter((t) => t.id !== id);
    } catch (error) {
      console.error("Delete task error:", error);
      throw error;
    }
  }
}
```
Cara menjalankan: simpan kode di atas sebagai file `level6.js`, muat dari `level6.html` (`<script src="level6.js"></script>`), lalu buka di browser dan tekan F12 → tab Console dan tab Network. Agar `fetch("/api/tasks")` benar-benar jalan, jalankan mock API dari materi 69 (`global.fetch = mockFetch;`) atau json-server lokal.

## Tracing Code (Step-by-Step)
Kita telusuri alur aplikasi: buka halaman → tambah task → hapus task. Asumsikan mock API dari materi 69 sudah aktif dan berisi task awal `[{ id: 1, title: "Belajar JS" }]`.

```js
let manager = new TaskManager();
await manager.loadTasks();
await manager.addTask("Bikin UI");
await manager.deleteTask(1);
```

**Langkah 1 — `new TaskManager()` lalu `await manager.loadTasks()`**
Constructor jalan: `#tasks` kosong `[]`, `#nextId = 1`. Lalu masuk `try` `loadTasks`. `await fetch("/api/tasks")` mengirim request GET dan method **berhenti menunggu**. `response` berisi hasil server. `data` berisi `[{ id: 1, title: "Belajar JS" }]`, lalu `this.#tasks = data` — array lokal berisi 1 task. `this.#nextId = Math.max(1, 0) + 1 = 2`. Blok `catch` **dilewati** karena tidak ada error.

**Langkah 2 — `await manager.addTask("Bikin UI")`**
`"Bikin UI".trim()` tidak kosong, jadi `if return` dilewati. `newTask` dibuat: `{ id: 2, title: "Bikin UI", completed: false, createdAt: ... }` dan `#nextId` naik jadi 3. Request POST dikirim dengan `body` berupa string JSON; method berhenti menunggu. Server merespons `ok: true`, jadi `throw` tidak jalan dan `this.#tasks.push(newTask)` menambah task ke-2 di array lokal. Method mengembalikan `newTask`.

**Langkah 3 — `await manager.deleteTask(1)`**
Request DELETE ke `/api/tasks/1` dikirim, method berhenti menunggu. Server merespons sukses. `this.#tasks = this.#tasks.filter((t) => t.id !== 1)` menyisakan hanya `[{ id: 2, title: "Bikin UI" }]`. Blok `catch` dilewati, method selesai tanpa nilai return.

**Output akhir (setelah ketiga await):**
```
#tasks = [ { id: 2, title: 'Bikin UI', completed: false } ] — #nextId = 3
```

## Analogi
Pustakawan tidak lagi menyimpan buku di lemari meja. Setiap kali kamu minta daftar buku (`loadTasks`), dia memesan **kartu katalog ke gudang pusat** dan menunggu jawabannya. Saat kamu menambah buku (`addTask`), formulir pesanan dikirim ke gudang dulu — lemari meja hanya diisi **setelah** gudang mengirim balasan "diterima". Kalau telepon ke gudang putus (`catch`), dia menyalakan lemari cadangan (localStorage) supaya layanan tidak berhenti total.

## Dipakai untuk Apa
- Memuat daftar task dari server saat aplikasi dibuka, dan menyimpan task baru saat tombol **Add** ditekan.
- Menandai task selesai (`updateTask` dengan PUT), menghapusnya permanen (`deleteTask`), atau menyediakan fallback localStorage saat API down.

## Kesalahan Umum yang Sering Terjadi
- **Memanggil method tanpa `await`**: `manager.loadTasks(); renderTasks();` membuat render jalan sebelum data dari server datang, sehingga daftar kosong. Selalu `await` atau gunakan `.then()`.
- **Lupa `JSON.stringify` saat POST/PUT**: `body` fetch harus string. Tanpa `JSON.stringify`, object jadi `"[object Object]"` dan data di server rusak. Sertakan juga header `"Content-Type": "application/json"`.
- **Menyentuh `#tasks` sebelum `await loadTasks()`**: Karena `loadTasks` butuh waktu, kode yang membaca `#tasks` tepat setelahnya masih melihat array kosong. Tunggu dulu dengan `await`.
- **`catch` menelan error tanpa kabar ke pemanggil**: Method `addTask` mencetak error lalu `throw error` lagi supaya UI (bukan hanya console) bisa menampilkan pesan "Gagal menambah task".

## Soal Latihan & Jawaban
### Soal
Lengkapi method `async updateTask(id, updates)` pada class `TaskManager` di atas: kirim PUT ke `/api/tasks/:id` dengan body JSON berisi perubahan (misalnya `{ completed: true }`), cek `response.ok`, lalu sinkronkan array `#tasks` lokal dengan cara mengganti task yang id-nya cocok menggunakan `Object.assign`. Setelah itu, panggil `updateTask(2, { completed: true })` dan tampilkan isi `#tasks` terakhir.

### Jawaban
```js
class TaskManager {
  #tasks = [
    { id: 1, title: "Belajar JS", completed: false },
    { id: 2, title: "Bikin UI", completed: false },
  ];

  async updateTask(id, updates) {
    try {
      // PUT: kirim perubahan ke server
      let response = await fetch(`/api/tasks/${id}`, {
        method: "PUT",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(updates),
      });
      if (!response.ok) throw new Error("Update failed");
      // Sinkronkan data lokal: ganti property task yang cocok
      let task = this.#tasks.find((t) => t.id === id);
      if (task) Object.assign(task, updates);
    } catch (error) {
      console.error("Update task error:", error);
      throw error;
    }
  }

  get tasks() { return this.#tasks; }
}

// Pakai mock API dari materi 69 dulu: global.fetch = mockFetch;
let manager = new TaskManager();

(async () => {
  await manager.updateTask(2, { completed: true });
  console.log("Task sekarang:", manager.tasks);
  // Task sekarang: [ { id: 1, title: 'Belajar JS', completed: false }, { id: 2, title: 'Bikin UI', completed: true } ]
})();
```
