# Mock API Server — JSONServer atau Mock Function

## Penjelasan
Semua method async CRUD (materi 67) butuh "server" untuk diuji, padahal kamu mungkin belum punya server sungguhan. **Mock API** adalah tiruan server yang balas permintaan secara palsu — tapi dengan bentuk respons yang sama persis seperti aslinya.

Tiga pilihan mock API:
1. **API publik siap pakai** — misalnya JSONPlaceholder (`https://jsonplaceholder.typicode.com/todos`). Kode fetch kamu diuji langsung dengan server asli, tapi tidak bisa menyimpan data sungguhan (setiap POST palsu).
2. **json-server lokal** — dipasang lewat `npm`, mengubah satu file JSON jadi API lengkap (GET, POST, PUT, DELETE) di `http://localhost:3000`. Paling mirip server sungguhan untuk latihan.
3. **Mock function** — kamu buat function di JavaScript yang **mengembalikan promise** berisi jawaban, lengkap dengan `setTimeout` untuk meniru jeda server. Paling ringan karena tidak perlu instal apa pun.

Syarat sebuah mock function bisa menggantikan `fetch`: ia harus resolve dengan objek yang punya properti `ok` dan method `json()` yang mengembalikan promise — persis seperti objek Response asli. Karena bentuknya sama, `global.fetch = mockFetch;` bisa dipakai supaya seluruh kode TaskManager tanpa perlu diubah.

## Fungsi
Mock function membuat kamu bisa mengembangkan dan mendemokan Task Manager **tanpa internet dan tanpa server**. Delay buatannya juga berguna untuk melatih hal lain: menguji loading indicator (materi 68) dan menangani kegagalan (materi 65) dengan sengaja membuat mock gagal.

## Cara Pengimplementasian / Code
```js
// Data "server" palsu
const MOCK_TASKS = [
  { id: 1, title: "Belajar JS", completed: false },
  { id: 2, title: "Bikin UI", completed: true },
];

// Mock API: meniru fetch sungguhan, selesai setelah 500ms
function mockFetch(url, options = {}) {
  return new Promise((resolve) => {
    setTimeout(() => {
      let method = options.method || "GET"; // default GET
      if (url === "/api/tasks" && method === "GET") {
        // Balas seperti Response asli: ok + json()
        resolve({
          ok: true,
          json: () => Promise.resolve([...MOCK_TASKS]), // salinan data
        });
      } else if (url === "/api/tasks" && method === "POST") {
        let newTask = JSON.parse(options.body); // body string → object
        MOCK_TASKS.push(newTask);
        resolve({ ok: true, json: () => Promise.resolve(newTask) });
      } else {
        // Endpoint/metode tidak dikenal → tiru error 404
        resolve({ ok: false, status: 404, json: () => Promise.resolve({}) });
      }
    }, 500);
  });
}

// Ganti fetch global supaya seluruh class TaskManager langsung terbantu
// Tanpa perlu mengubah method fetch apa pun di dalamnya
global.fetch = mockFetch;

// Tes cepat:
(async () => {
  let response = await fetch("/api/tasks");
  let data = await response.json();
  console.log("Tasks dari mock:", data);
})();
```
Cara menjalankan: simpan kode di atas sebagai file `level6.js`, muat dari `level6.html` (`<script src="level6.js"></script>`), lalu buka di browser dan tekan F12 → tab Console dan tab Network. Catatan: kalau dipakai di browser, ganti `global.fetch` menjadi `window.fetch`.

## Tracing Code (Step-by-Step)
Kita telusuri bagian "Tes cepat" di atas.

```js
global.fetch = mockFetch;
let response = await fetch("/api/tasks");
let data = await response.json();
console.log("Tasks dari mock:", data);
```

**Langkah 1 — `global.fetch = mockFetch;`**
Sekarang setiap pemanggilan `fetch(...)` di mana pun di script ini akan memanggil `mockFetch`, bukan fetch bawaan browser. Class TaskManager tidak tahu dan tidak perlu tahu ada penggantian.

**Langkah 2 — `await fetch("/api/tasks")`**
`mockFetch` dipanggil dengan `url = "/api/tasks"` dan `options = {}` (default). Ia membuat promise dan menjalankan `setTimeout` 500 ms, lalu method berhenti menunggu di `await`.

**Langkah 3 — 500 ms kemudian, `setTimeout` berbunyi**
`method` dibaca: karena `options.method` kosong, `method = "GET"`. Kondisi pertama terpenuhi (`url` dan `GET` cocok). `resolve` dipanggil dengan objek `{ ok: true, json: ... }` — promise sekarang resolved, dan `await` melepas nilai: `response` kini berisi objek tiruan itu.

**Langkah 4 — `await response.json()`**
`json()` mengembalikan promise yang berisi salinan `MOCK_TASKS` (`[...MOCK_TASKS]`, jadi mengubah hasilnya tidak merusak data asli). Karena promise ini langsung resolved, `data` berisi array 2 task, lalu `console.log` menampilkannya. Perhatikan seluruh proses **tidak menyentuh jaringan** — semuanya terjadi di memori, tapi urutan eksekusinya identik dengan fetch sungguhan.

**Output akhir:**
```
Tasks dari mock: [
  { id: 1, title: 'Belajar JS', completed: false },
  { id: 2, title: 'Bikin UI', completed: true }
]
```

## Kesalahan Umum yang Sering Terjadi
- **Mock tidak punya `json()` method**: Objek resolve tanpa `json()` membuat `await response.json()` error `response.json is not a function`. Selalu sediakan `json: () => Promise.resolve(data)`.
- **Lupa `setTimeout`, semuanya instan**: Promise yang langsung resolve membuat delay 0 — kamu jadi tidak bisa menguji loading indicator dan bug timing tidak pernah muncul. Beri jeda kecil (300-500 ms).
- **Mengembalikan data asli, bukan salinan**: `json: () => Promise.resolve(MOCK_TASKS)` tanpa `[...]` membuat konsumen bisa mengubah data mock dari luar. Kembalikan salinan agar data "server" aman.
- **Mock POST tidak memvalidasi `body`**: Langsung `options.body` tanpa `JSON.parse` membuat data masuk sebagai string dan daftar task rusak. Selalu parse dulu, seperti server sungguhan menerima JSON.

## Soal Latihan & Jawaban
### Soal
Lengkapi `mockFetch` agar juga melayani **DELETE** `/api/tasks/:id`: hapus task dari `MOCK_TASKS` berdasarkan id dari URL, balas `{ ok: true, json: () => Promise.resolve({}) }`. Kalau id tidak ditemukan, balas `{ ok: false, status: 404 }`. Lalu uji dengan memanggil `fetch("/api/tasks/1", { method: "DELETE" })` dan `fetch("/api/tasks")` lagi untuk memastikan task id 1 hilang.

### Jawaban
```js
const MOCK_TASKS = [
  { id: 1, title: "Belajar JS", completed: false },
  { id: 2, title: "Bikin UI", completed: true },
];

function mockFetch(url, options = {}) {
  return new Promise((resolve) => {
    setTimeout(() => {
      let method = options.method || "GET";
      if (url === "/api/tasks" && method === "GET") {
        resolve({ ok: true, json: () => Promise.resolve([...MOCK_TASKS]) });
      } else if (method === "DELETE") {
        // Ambil id dari URL: "/api/tasks/1" → 1
        let id = Number(url.split("/").pop());
        let index = MOCK_TASKS.findIndex((t) => t.id === id);
        if (index === -1) {
          resolve({ ok: false, status: 404, json: () => Promise.resolve({}) }); // id tidak ada → tiru 404
          return;
        }
        MOCK_TASKS.splice(index, 1); // hapus dari data "server"
        resolve({ ok: true, json: () => Promise.resolve({}) });
      }
    }, 500);
  });
}

global.fetch = mockFetch; // di browser: window.fetch = mockFetch;

(async () => {
  await fetch("/api/tasks/1", { method: "DELETE" }); // hapus task id 1
  let response = await fetch("/api/tasks");
  console.log("Sisa tasks:", await response.json());
  // Sisa tasks: [ { id: 2, title: 'Bikin UI', completed: true } ]
})();
```
