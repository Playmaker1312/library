# .then() & .catch() — Consume Promise

## Penjelasan
"Consume" artinya **memakai hasil** Promise. Setelah punya Promise (materi 58), kamu membaca hasilnya dengan tiga method:
- **`.then(onResolve, onReject)`** — `onResolve` dijalankan kalau Promise berhasil, dan menerima `value` dari `resolve`. Argumen kedua (`onReject`) boleh diisi, tapi lebih jarang dipakai.
- **`.catch(onReject)`** — hanya menangani jalur gagal, menerima `error` dari `reject`. Ini cara yang lebih terbaca daripada argumen kedua `.then`.
- **`.finally(onFinally)`** — dijalankan **apapun hasilnya**, sukses maupun gagal. Cocok untuk bersih-bersih seperti mematikan indikator loading.

Aturan rantai (chaining):
- Setiap `.then()` menghasilkan **Promise baru**, jadi bisa ditumpuk terus: `.then().then().catch().finally()`.
- Nilai yang di-`return` di dalam `.then` menjadi **input** `.then` berikutnya. Kalau lupa `return`, input berikutnya jadi `undefined`.
- `throw` di dalam `.then` memindahkan Promise ke status **rejected** — lompatan langsung ke `.catch` berikutnya.

## Fungsi
Tanpa `.then`, hasil Promise tidak bisa diambil (statusnya sudah berubah tapi nilainya tidak ke mana-mana). `.then()` mengubah hasil async menjadi alur berantai yang terbaca dari atas ke bawah, sementara `.catch()` mengumpulkan **semua** penanganan error di satu titik — tidak perlu menulis `if (error)` di setiap langkah seperti pola callback. `.finally` memberi tempat tunggal untuk kode yang harus jalan di kedua jalur.

## Cara Pengimplementasian / Code
```js
// level6.js
function ambilTaskDariServer(id) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (id > 0) resolve({ id: id, title: "Rapikan laci arsip", selesai: false });
      else reject("ID task tidak valid");
    }, 1000);
  });
}

// Rantai 1: jalur sukses
ambilTaskDariServer(1)
  .then((task) => {
    console.log("Task diterima:", task.title);
    return task.id; // nilai ini diteruskan ke .then berikutnya
  })
  .then((id) => console.log("ID diteruskan:", id))
  .catch((error) => console.error("Terjadi kesalahan:", error))
  .finally(() => console.log("Proses selesai (apapun hasilnya)"));

// Rantai 2: jalur gagal
ambilTaskDariServer(0)
  .then((task) => console.log("Tidak akan dicetak:", task.title))
  .catch((error) => console.error("Terjadi kesalahan:", error))
  .finally(() => console.log("Proses selesai (apapun hasilnya)"));
```

Cara menjalankan: simpan kode di atas sebagai `level6.js`, lalu muat dari `level6.html` dengan `<script src="level6.js"></script>`. Buka file HTML itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

```js
ambilTaskDariServer(1)
  .then((task) => { console.log(...); return task.id; })
  .then((id) => console.log(...))
  .catch((error) => console.error(...))
  .finally(() => console.log(...));

ambilTaskDariServer(0).then(...).catch(...).finally(...);
```

**Langkah 1 — `ambilTaskDariServer(1)`**
Executor langsung jalan dan `setTimeout` mencatat jadwal "1.000 ms lagi jalankan `resolve`". Promise berstatus **pending** dikembalikan.

**Langkah 2 — `.then`, `.then`, `.catch`, `.finally` dipasang**
Keempatnya hanya **mendaftarkan** fungsi masing-masing. Belum ada yang berjalan. Lalu pemanggilan kedua `ambilTaskDariServer(0)` dilakukan: `id = 0` tidak lebih besar dari 0, jadi jadwalnya nanti akan memanggil `reject`. Empat handler kedua dipasang, statusnya juga masih **pending**.

**Langkah 3 — setelah ±1.000 ms, jadwal pertama dijalankan**
`resolve({ id: 1, title: "Rapikan laci arsip", ... })` → status rantai pertama jadi **resolved**. `.then` pertama jalan: tercetak `Task diterima: Rapikan laci arsip`, lalu `return task.id` menghasilkan angka `1`.

**Langkah 4 — nilai `1` mengalir ke `.then` kedua**
Karena ada nilai return, `.then` kedua menerima `id = 1` → tercetak `ID diteruskan: 1`. `.catch` **dilewati** (tidak ada error), lalu `.finally` tetap jalan → tercetak `Proses selesai (apapun hasilnya)`.

**Langkah 5 — jadwal kedua menyusul, kali ini `reject`**
`reject("ID task tidak valid")` → status rantai kedua jadi **rejected**. `.then` pertama **dilewati** langsung, `.catch` jalan → tercetak `Terjadi kesalahan: ID task tidak valid`, lalu `.finally` jalan lagi → tercetak `Proses selesai (apapun hasilnya)`.

**Output akhir:**
```
Task diterima: Rapikan laci arsip
ID diteruskan: 1
Proses selesai (apapun hasilnya)
Terjadi kesalahan: ID task tidak valid
Proses selesai (apapun hasilnya)
```

## Analogi
Di perpustakaan ada sistem **tanda terima berantai**. Setiap petugas yang menerima berkas menuliskan hasilnya di lembar, lalu meneruskan lembar itu ke petugas berikutnya (`.then` yang saling terhubung). Kalau ada masalah, berkasnya diserahkan ke petugas khusus penanganan masalah (`.catch`) dan petugas biasa dilewati. Petugas terakhir menandatangai semua berkas tanpa peduli hasilnya (`.finally`) — tanda tangan itu memang selalu diperlukan.

## Dipakai untuk Apa
- Menampilkan data hasil `fetch()` di layar (materi 61)
- Mengubah data bertahap: ambil task → hitung → tampilkan ringkasan
- Menangkap semua error jaringan di satu `.catch()` di ujung rantai
- Menjalankan kode penutup di `.finally`, misal mematikan indikator loading (materi 68)
- Menggabungkan beberapa request dengan `Promise.all()` (materi 60)

## Kesalahan Umum yang Sering Terjadi
- **Lupa `return` di dalam `.then`**: nilai berikutnya jadi `undefined` dan data hilang di tengah rantai, sering baru ketahuan saat muncul `TypeError: Cannot read properties of undefined`.
- **`.catch()` diletakkan di tengah rantai**: ia hanya menangkap error dari langkah **sebelumnya**; error di `.then` sesudahnya lolos tanpa tertangani. Taruh `.catch()` di ujung rantai.
- **Menganggap `.then()` langsung berjalan saat dipasang**: handler-nya dijadwalkan setelah kode sinkron selesai, jadi urutan di console sedikit berbeda dari urutan tulisan.
- **Mengandalkan `.finally()` untuk mengubah hasil**: nilai `return` di dalam `.finally` diabaikan (kecuali kalau melempar error). Pakai `.finally` untuk bersih-bersih saja, bukan untuk memanipulasi hasil.
- **Rantai tanpa `.catch()` sama sekali**: saat Promise rejected, error jadi "unhandled" dan console merah tanpa keterangan jelas.

## Soal Latihan & Jawaban
### Soal
Buat fungsi `loadTasks()` yang mengembalikan Promise berisi 3 task setelah 1 detik. Rantai kodenya: `.then` pertama menghitung berapa task yang sudah selesai lalu mengembalikan angkanya, `.then` kedua mencetak jumlah itu, `.catch` menampilkan pesan error, dan `.finally` mencetak "Loading dimatikan" untuk mematikan indikator loading — baik sukses maupun gagal.

### Jawaban
```js
function loadTasks() {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve([
        { id: 1, title: "Belajar Promise", selesai: true },
        { id: 2, title: "Rapikan laci arsip", selesai: false },
        { id: 3, title: "Cek buku terlambat", selesai: true },
      ]);
    }, 1000);
  });
}

loadTasks()
  .then((tasks) => {
    // return di sini jadi input .then berikutnya
    return tasks.filter((t) => t.selesai).length;
  })
  .then((jumlah) => console.log("Task selesai:", jumlah))
  .catch((error) => console.error("Terjadi kesalahan:", error))
  .finally(() => console.log("Loading dimatikan"));

// Output:
// Task selesai: 2
// Loading dimatikan
```
