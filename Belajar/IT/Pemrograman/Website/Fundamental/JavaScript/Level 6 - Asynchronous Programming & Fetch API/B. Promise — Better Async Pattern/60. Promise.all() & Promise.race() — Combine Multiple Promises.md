# Promise.all() & Promise.race() — Combine Multiple Promises

## Penjelasan
Kadang satu aplikasi butuh beberapa data sekaligus. Daripada menunggu satu per satu (lambat), Promise bisa digabung:
- **`Promise.all([p1, p2, ...])`** — menunggu **semua** Promise selesai, lalu resolve membawa **array hasil** sesuai urutan input (bukan urutan selesai). Kalau **ada satu saja yang gagal**, hasil akhirnya langsung **rejected** membawa error pertama itu.
- **`Promise.race([p1, p2, ...])`** — "lomba": hasil akhir mengikuti **Promise yang paling dulu selesai**, entah itu berhasil maupun gagal.
- **`Promise.allSettled([p1, p2, ...])`** — menunggu semua selesai **tanpa peduli ada yang gagal**. Hasilnya berupa array berisi `{ status: "fulfilled", value }` atau `{ status: "rejected", reason }`, jadi kegagalan satu data tidak membuang data lain.

Catatan: ketiganya menerima array, dan yang di dalamnya harus sudah berupa Promise.

## Fungsi
Tanpa penggabung, kamu harus menunggu `loadTasks()` selesai baru mulai `loadTasksProfil()` — total waktunya jumlah semua request. Dengan `Promise.all`, request berjalan **bersamaan** (paralel) dan hanya menunggu yang paling lambat, jadi halaman jauh lebih cepat terisi. `Promise.race` berguna untuk "siapa cepat dia dapat" seperti timeout, sedangkan `Promise.allSettled` dipakai saat kegagalan satu data tidak boleh menjatuhkan seluruh halaman.

## Cara Pengimplementasian / Code
```js
// level6.js — tiga mock request dengan kecepatan berbeda
function ambilTasks() {
  return new Promise((resolve) =>
    setTimeout(() => resolve([
      { id: 1, title: "Belajar Promise.all" },
      { id: 2, title: "Rapikan laci arsip" },
    ]), 1500));
}

function ambilProfilUser() {
  return new Promise((resolve) =>
    setTimeout(() => resolve({ nama: "Andi", role: "admin" }), 1000));
}

function ambilKategori() {
  return new Promise((resolve, reject) =>
    setTimeout(() => reject("/api/categories tidak terjangkau"), 500));
}

// 1) Promise.all — dua request paralel, hasil berupa array (destructuring, materi 70)
Promise.all([ambilTasks(), ambilProfilUser()])
  .then(([tasks, profil]) => console.log("Tasks:", tasks.length, "dari user", profil.nama))
  .catch((error) => console.error("Gagal:", error));

// 2) Promise.all — satu yang gagal membuat seluruhnya ikut gagal
Promise.all([ambilTasks(), ambilKategori()])
  .then(([tasks, kategori]) => console.log("Tidak akan jalan"))
  .catch((error) => console.error("Satu gagal, semua gagal:", error));

// 3) Promise.race — hasil dari yang pertama selesai (bisa sukses, bisa gagal)
Promise.race([ambilProfilUser(), ambilKategori()])
  .then((pemenang) => console.log("Menang:", pemenang.nama))
  .catch((error) => console.error("Race yang menang gagal:", error));

// 4) Promise.allSettled — semua ditunggu, kegagalan tidak membatalkan
Promise.allSettled([ambilTasks(), ambilKategori()])
  .then((hasil) => console.log("Status:", hasil.map((h) => h.status).join(", ")));
```

Cara menjalankan: simpan kode di atas sebagai `level6.js`, lalu muat dari `level6.html` dengan `<script src="level6.js"></script>`. Buka file HTML itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

```js
Promise.all([ambilTasks(), ambilProfilUser()]).then(...).catch(...);
Promise.all([ambilTasks(), ambilKategori()]).then(...).catch(...);
Promise.race([ambilProfilUser(), ambilKategori()]).then(...).catch(...);
Promise.allSettled([ambilTasks(), ambilKategori()]).then(...);
```

**Langkah 1 — keempat blok dijalankan berurutan, sangat cepat**
Saat dipanggil, tiap `Promise.all`/`race`/`allSettled` membuat Promise gabungan berstatus **pending** dan langsung menyalakan semua mock request di dalamnya. Total ada 7 timer berjalan bersamaan: `ambilTasks` (1500 ms), `ambilProfilUser` (1000 ms), dan `ambilKategori` (500 ms) — masing-masing dipanggil terpisah, jadi punya timer sendiri-sendiri.

**Langkah 2 — setelah 500 ms, `ambilKategori` pertama gagal**
`reject(...)` dipanggil → Promise `Promise.all` blok 2 langsung berpindah ke **rejected**. Blok `then` dilewati, `catch` jalan. Promise `tasks` miliknya yang masih jalan dibiarkan, hasilnya dibuang.

**Langkah 3 — 500 ms juga, `ambilKategori` kedua gagal**
Ini milik `Promise.race` blok 3. Yang pertama selesai di "lomba" ini justru yang **gagal**, jadi hasil akhir race-nya ikut **rejected** → `catch` blok 3 jalan.

**Langkah 4 — setelah 1.000 ms, `ambilProfilUser` sukses**
Di blok 1, `Promise.all` masih menunggu `ambilTasks`, jadi belum ada output. Di blok 3, race sudah selesai sejak langkah 3, jadi hasil ini diabaikan.

**Langkah 5 — setelah 1.500 ms, kedua `ambilTasks` selesai**
Promise pertama (blok 1) kini lengkap: tasks + profil sama-sama sukses → **resolved** dengan array `[tasks, profil]` → `catch` dilewati, `then` jalan. Berbarengan, `Promise.allSettled` blok 4 juga menerima hasil terakhirnya dan **resolved** tanpa peduli `kategori` tadi gagal.

**Output akhir:**
```
Satu gagal, semua gagal: /api/categories tidak terjangkau
Race yang menang gagal: /api/categories tidak terjangkau
Tasks: 2 dari user Andi
Status: fulfilled, rejected
```

## Analogi
Di perpustakaan, pustakawan mengirim tiga formulir permintaan ke tiga bagian gudang sekaligus, lalu menunggu. **`Promise.all`** berarti "semua formulir wajib berhasil" — satu formulir hilang, seluruh pemesanan batal dan dia melapor ke atasan. **`Promise.race`** seperti lomba antar kurir: siapa yang menyerahkan hasil duluan, dialah yang dipakai — walau kurir itu datang membawa kabar buruk. **`Promise.allSettled`** berarti semua jawaban dicatat lengkap beserta statusnya, termasuk yang gagal, tanpa membatalkan sisanya.

## Dipakai untuk Apa
- Memuat data profil, task, dan kategori **bersamaan** saat halaman dibuka (lebih cepat)
- Membuat permintaan timeout: siapa yang selesai duluan, itulah hasilnya
- Menampilkan sebagian data tetap walau satu endpoint sedang down (`allSettled`)
- Menggabungkan beberapa API publik jadi satu tampilan dashboard

## Kesalahan Umum yang Sering Terjadi
- **Menganggap `Promise.all` menunggu semua meski ada error**: ia berhenti (rejected) begitu ada yang gagal pertama kali — request lain tetap berjalan tapi hasilnya dibuang. Kalau semua hasil dibutuhkan, pakai `Promise.allSettled`.
- **Lupa hasil `Promise.all` berupa array**: hasilnya selalu array panjang yang **urutannya sesuai urutan input**, bukan urutan yang selesai — jangan mengambil elemen berdasarkan waktu.
- **Menganggap `Promise.race` mengabaikan error**: kalau yang menang itu adalah Promise yang gagal, hasil akhirnya ikut gagal. Wajib pasang `.catch()`.
- **Menjalankan request berurutan tanpa perlu**: `await a(); await b();` menghabiskan waktu a + b. Kalau tidak saling bergantung, gabungkan dengan `Promise.all` (dibahas lagi di materi 66).

## Soal Latihan & Jawaban
### Soal
Halaman Task Manager butuh dua data: `tasks` (siap setelah 1,2 detik) dan `profil` (siap setelah 0,8 detik). Tampilkan keduanya dengan `Promise.all`. Lalu jalankan ulang dengan `Promise.allSettled` untuk kasus di mana endpoint profil gagal — buktikan halaman tetap bisa menampilkan data tasks beserta status masing-masing data.

### Jawaban
```js
function ambilTasks() {
  return new Promise((resolve) =>
    setTimeout(() => resolve([
      { id: 1, title: "Belajar Promise.all" },
      { id: 2, title: "Rapikan laci arsip" },
    ]), 1200)
  );
}

function ambilProfil(gagal) {
  return new Promise((resolve, reject) =>
    setTimeout(() => {
      if (gagal) reject("/profil gagal");
      else resolve({ nama: "Andi" });
    }, 800)
  );
}

// Semua harus sukses → hasil berupa array
Promise.all([ambilTasks(), ambilProfil(false)])
  .then(([tasks, profil]) =>
    console.log("Tasks:", tasks.length, "| user:", profil.nama))
  .catch((error) => console.error("Gagal:", error));

// Satu gagal tidak menjatuhkan yang lain
Promise.allSettled([ambilTasks(), ambilProfil(true)])
  .then((hasil) =>
    hasil.forEach((h, i) => console.log("Data", i, h.status, h.value ?? h.reason)));

// Output:
// Tasks: 2 | user: Andi
// Data 0 fulfilled [ { id: 1, title: 'Belajar Promise.all' }, { id: 2, ... } ]
// Data 1 rejected /profil gagal
```
