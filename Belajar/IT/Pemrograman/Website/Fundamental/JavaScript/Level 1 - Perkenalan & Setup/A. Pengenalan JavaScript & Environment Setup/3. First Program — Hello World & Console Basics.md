# First Program — Hello World & Console Basics

## Penjelasan
Program pertamamu adalah "Hello World": satu baris kode yang menampilkan teks, untuk memastikan semuanya berjalan. Di JavaScript, alat untuk menampilkan teks kecuali ke layar adalah **console** — panel bawaan browser yang berfungsi sebagai tempat cetak output dan melihat error (pesan kesalahan).
Tiga perintah dasar yang wajib kamu hafal:
- `console.log()` — menampilkan pesan biasa (yang paling sering dipakai).
- `console.warn()` — menampilkan peringatan, biasanya berlatar kuning.
- `console.error()` — menampilkan error, biasanya berlatar merah dengan ikon silang.

Kode JavaScript ditulis di dalam tag `<script>` di file HTML. Satu file HTML boleh punya lebih dari satu blok `<script>`.

## Fungsi
`console.log()` adalah alat debugging (alat melacak masalah) paling dasar dan paling sering dipakai programmer. Saat programmu aneh, langkah pertamanya hampir selalu: cetak isi variabel ke console untuk tahu apa yang sebenarnya terjadi. Kebiasaan membaca console ini bahkan masuk di checklist kebiasaan Level 1: buka console setiap kode baru dan baca pesan errornya, jangan di-skip.

## Cara Pengimplementasian / Code
```html
<!DOCTYPE html>
<html>
<body>
  <h1>Task Manager</h1>

  <script>
    // Program pertama: sapaan
    console.log("Halo Dunia");

    // Menampilkan beberapa nilai sekaligus
    const appName = "Task Manager";
    let taskCount = 3;
    console.log("App:", appName, "| Tugas:", taskCount);

    // Pesan peringatan dan error
    console.warn("Ada 1 tugas tanpa judul");
    console.error("Gagal menyimpan: storage penuh");
  </script>
</body>
</html>
```
Cara menjalankan: simpan sebagai `level1.html`, buka di browser, tekan F12 → tab Console. Tiga pesan (log, warn, error) akan tampil dengan gaya berbeda.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris.

**Langkah 1 — browser memuat `level1.html`**
Browser membaca heading `Task Manager` dan menampilkannya di halaman. Belum ada output di console.

**Langkah 2 — baris `console.log("Halo Dunia");`**
Browser menemukan tag `<script>` lalu menjalankan isinya dari atas. Baris pertama memanggil `console.log` dengan teks `"Halo Dunia"`. Console menampilkan teks itu.

**Langkah 3 — baris `const appName = "Task Manager";`**
Dibuat variabel `appName` berisi teks `Task Manager`.

**Langkah 4 — baris `let taskCount = 3;`**
Dibuat variabel `taskCount` berisi angka `3`.

**Langkah 5 — baris `console.log("App:", appName, "| Tugas:", taskCount);`**
`console.log` boleh menerima banyak argumen (nilai) dan memisahkannya dengan spasi. Nilai `appName` dan `taskCount` diambil dari variabelnya. Console menampilkan: `App: Task Manager | Tugas: 3`.

**Langkah 6 — baris `console.warn("Ada 1 tugas tanpa judul");`**
Console menampilkan pesan peringatan dengan ikon segitiga kuning.

**Langkah 7 — baris `console.error("Gagal menyimpan: storage penuh");`**
Console menampilkan pesan dengan ikon silang merah.

**Output akhir:**
```
Halo Dunia
App: Task Manager | Tugas: 3
```
(ditambah 1 pesan warning dan 1 pesan error di bawahnya)

## Analogi
Console adalah **kartu keluaran pustakawan**. Setiap kali pustakawan (JavaScript) mengerjakan sesuatu, dia menulis catatan kecil: `log` adalah catatan harian biasa, `warn` adalah catatan kuning "hati-hati ada masalah", dan `error` adalah catatan merah "ini rusak, segera perbaiki". Kamu tinggal membaca tumpukan catatan itu setelah program berjalan.

## Dipakai untuk Apa
- Mencetak isi variabel saat mencari bug (kesalahan program)
- Memastikan sebuah blok kode benar-benar dijalankan
- Menandai masalah dengan `warn` dan `error` supaya gampang dicari di antara banyak log
- Menampilkan hasil program sementara sebelum kamu belajar menampilkan output ke halaman

## Kesalahan Umum yang Sering Terjadi
- **Salah eja perintah**: Menulis `consol.log` atau `console.logs` menghasilkan error `... is not a function` dan kode sesudahnya tidak jalan. Salin perlahan atau manfaatkan autocomplete VS Code.
- **Lupa tanda kutip atau kurung**: `console.log(Halo Dunia)` membuat JavaScript bingung membedakan teks dan nama variabel. Teks selalu dibungkus kutip, dan setiap `log(...)` harus ditutup kurung.
- **Membaca console yang penuh log lama**: Output tertumpuk dengan pesan dari percobaan sebelumnya sehingga kamu salah kira kode baru tidak jalan. Klik ikon clear (membuluh kosong) sebelum menjalankan kode baru.
- **Hanya melihat pesan kuning/merah tanpa klik**: Pesan error biasanya punya nama file dan baris error — klik untuk tahu persis baris mana yang salah, jangan cuma melihat sekilas.

## Soal Latihan & Jawaban
### Soal
Buat program Task Manager versi mini: tampilkan 3 pesan ke console berturut-turut — teks `Task Manager v1`, lalu peringatan `Belum ada tugas yang diselesaikan`, lalu error `Fitur hapus belum dibuat` — masing-masing dengan perintah console yang sesuai (`log`, `warn`, `error`).

### Jawaban
```html
<!DOCTYPE html>
<html>
<body>
  <script>
    // Pesan biasa
    console.log("Task Manager v1");

    // Peringatan
    console.warn("Belum ada tugas yang diselesaikan");

    // Error
    console.error("Fitur hapus belum dibuat");
  </script>
</body>
</html>
```
