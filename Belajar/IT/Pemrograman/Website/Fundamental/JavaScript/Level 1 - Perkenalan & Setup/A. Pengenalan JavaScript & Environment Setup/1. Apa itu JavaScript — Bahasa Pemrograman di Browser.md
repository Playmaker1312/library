# Apa itu JavaScript — Bahasa Pemrograman di Browser

## Penjelasan
JavaScript adalah bahasa pemrograman yang berjalan di dalam browser (program untuk membuka website, seperti Chrome atau Firefox). Kalau HTML adalah kerangka gedung dan CSS adalah cat serta dekorasinya, JavaScript adalah tukang yang membuat pintu bisa dibuka dan lampu bisa dinyalakan.
Fakta-fakta penting:
- JavaScript dieksekusi (dijalankan) langsung di browser, bukan di server. Karena itu hasilnya langsung terlihat.
- JavaScript bersifat **interpreter**, artinya browser membaca kode satu baris lalu langsung menjalankannya.
- JavaScript bersifat **event-driven**, artinya kode jalan sebagai reaksi terhadap kejadian (event), misalnya user menekan tombol atau mengetik di form.
- JavaScript bisa mengubah isi halaman saat itu juga, tanpa perlu memuat ulang halaman.

## Fungsi
Tanpa JavaScript, website cuma halaman statis yang hanya bisa ditampilkan dan diklik linknya. JavaScript membuat halaman jadi interaktif: form bisa divalidasi sebelum dikirim, tombol bisa merespons klik, animasi bisa berjalan, dan data bisa dimuat tanpa refresh halaman. Ini alasan kenapa materi ini jadi pondasi sebelum kamu bikin aplikasi Task Manager yang benar-benar bisa dipakai.

## Cara Pengimplementasian / Code
```html
<!DOCTYPE html>
<html>
<head>
  <title>Kenalan dengan JavaScript</title>
</head>
<body>
  <h1 id="judul">Task Manager</h1>
  <button id="tombolTambah">Tambah Tugas</button>

  <script>
    // Ambil elemen tombol dari halaman
    const tombol = document.getElementById("tombolTambah");

    // Pasang "pendengar event": kode ini jalan saat tombol diklik
    tombol.addEventListener("click", function () {
      console.log("Tombol Tambah Tugas diklik!");
      document.getElementById("judul").textContent = "Task Manager (ada klik!)";
    });
  </script>
</body>
</html>
```
Cara menjalankan: simpan sebagai `level1.html`, buka di browser, tekan F12 → tab Console, lalu klik tombolnya.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris.

**Langkah 1 — browser memuat file HTML**
Browser membaca tag `<h1 id="judul">` dan `<button id="tombolTambah">`, lalu menampilkannya di layar. Tombol belum melakukan apa-apa.

**Langkah 2 — baris `const tombol = document.getElementById("tombolTambah");`**
`document.getElementById` berarti "cari elemen di halaman berdasarkan id-nya". Browser menemukan tombol tadi dan menyimpannya ke variabel `tombol`. Isi `tombol` sekarang = elemen tombol di halaman.

**Langkah 3 — baris `tombol.addEventListener(...)`**
Kode ini memasang pendengar: "kalau `tombol` diklik, jalankan fungsi di dalamnya". Belum ada yang terjadi, kita baru mendaftarkan aturan.

**Langkah 4 — user mengklik tombol**
Browser melihat kejadian klik pada `tombol`, lalu menjalankan fungsi di dalam `addEventListener`.

**Langkah 5 — baris `console.log("Tombol Tambah Tugas diklik!");`**
Console (panel debug di DevTools) menampilkan teks `Tombol Tambah Tugas diklik!`.

**Langkah 6 — baris `document.getElementById("judul").textContent = ...`**
Elemen `<h1>` yang tadinya berisi `Task Manager` diganti teksnya menjadi `Task Manager (ada klik!)`. Halaman berubah tanpa di-refresh.

**Output akhir:**
```
Tombol Tambah Tugas diklik!
```
(dan judul di halaman berubah menjadi "Task Manager (ada klik!)")

## Analogi
Di perpustakaan, HTML adalah denah gedung dan CSS adalah cat serta pajangan raknya. JavaScript adalah **pustakawan** yang duduk di meja dan menunggu. Saat kamu menekan bel (event), pustakawan bangun, memeriksa kartu permintaanmu, lalu mengambilkan buku dari rak — semuanya terjadi di tempat, tanpa harus pulang dan datang lagi.

## Dipakai untuk Apa
- Validasi form login sebelum data dikirim ke server
- Menambah/menghapus/mengedit daftar tugas di Task Manager (CRUD)
- Menampilkan notifikasi, popup, atau pesan error di halaman
- Animasi dan efek hover/scroll
- Memuat data dari server tanpa refresh halaman ( AJAX)

## Kesalahan Umum yang Sering Terjadi
- **Menempel kode di posisi yang salah**: JavaScript ditulis sebelum elemen HTML yang dicarinya ada, sehingga `getElementById` tidak menemukan apa-apa (`null`) dan muncul error. Hindari dengan menaruh `<script>` di akhir `<body>`.
- **Mengira JavaScript jalan di server**: Padahal kode di `<script>` dijalankan browser kamu. Kalau butuh data dari server, itu materi tingkat lanjut.
- **Console ditutup sehingga tidak tahu ada error**: Banyak pemula bingung "tidak terjadi apa-apa" padahal error jelas terlihat di Console. Buka F12 setiap kali menjalankan kode.
- **Campur aduk HTML, CSS, dan JavaScript dalam satu tag**: Menaruh JavaScript di atribut `onclick` di mana-mana bikin kode susah dirawat. Pisahkan di `<script>`.

## Soal Latihan & Jawaban
### Soal
Di aplikasi Task Manager, user harus mengisi judul tugas sebelum bisa menambahkannya. Buat halaman HTML berisi input `id="taskInput"` dan tombol `id="btnAdd"`. Saat tombol diklik: kalau input kosong, tampilkan pesan `"Judul tugas kosong!"` di console; kalau terisi, tampilkan `"Menambah: <isi input>"` di console.

### Jawaban
```html
<!DOCTYPE html>
<html>
<body>
  <input id="taskInput" placeholder="Judul tugas">
  <button id="btnAdd">Tambah</button>

  <script>
    const input = document.getElementById("taskInput");
    const tombol = document.getElementById("btnAdd");

    tombol.addEventListener("click", function () {
      if (input.value === "") {
        console.log("Judul tugas kosong!");
      } else {
        console.log("Menambah: " + input.value);
      }
    });
  </script>
</body>
</html>
```
