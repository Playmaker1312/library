# Setup Environment — Text Editor & Browser

## Penjelasan
Environment (lingkungan kerja) adalah kumpulan alat yang kamu butuhkan untuk menulis, menjalankan, dan memperbaiki kode JavaScript. Untuk level pemula, environment-nya sederhana banget: cuma butuh dua hal.
- **Text editor**, tempat kamu menulis kode. Rekomendasi: **VS Code** (gratis).
- **Browser** apa pun (Chrome, Edge, Firefox) — di sinilah JavaScript dijalankan.

Yang perlu disiapkan:
- VS Code terpasang di komputer.
- Ekstensi (tambahan fitur) VS Code: **Live Server** (menyajikan file ke browser secara otomatis) dan **JavaScript (ES6) Code Snippets** (pintasan menulis kode JS).
- Struktur folder belajar, misalnya `js-learning/` yang di dalamnya punya subfolder per level.

Catatan: untuk Level 1 ini kita belum butuh server. Cukup buka file HTML langsung di browser.

## Fungsi
Tanpa editor yang bagus, kamu akan menulis kode di Notepad tanpa bantuan apa pun — rawan salah ketik dan susah mencari kesalahan. Tanpa browser, kode JavaScript tidak bisa dijalankan sama sekali. Setup sekali di awal ini bikin proses belajar selanjutnya tinggal fokus ke kode, bukan ke urusan alat.

## Cara Pengimplementasian / Code
```html
<!DOCTYPE html>
<html>
<head>
  <title>Task Manager - Level 1</title>
</head>
<body>
  <h1>Task Manager</h1>
  <ul id="taskList">
    <li>Belajar setup environment</li>
  </ul>

  <script>
    // Hitung jumlah tugas yang sudah ada di daftar
    const jumlahTugas = document.querySelectorAll("#taskList li").length;
    console.log("Jumlah tugas saat ini: " + jumlahTugas);
  </script>
</body>
</html>
```
Cara menjalankan: buat folder `js-learning/`, simpan file di atas sebagai `level1.html` di dalamnya, buka file itu dengan VS Code lalu klik kanan → *Open with Live Server* (atau langsung buka filenya di browser), tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris.

**Langkah 1 — file `level1.html` dibuka di browser**
Browser membaca seluruh isi file: judul halaman, heading `Task Manager`, dan satu daftar `<ul id="taskList">` yang berisi satu `<li>`.

**Langkah 2 — baris `const jumlahTugas = ...`**
`document.querySelectorAll("#taskList li")` berarti "cari semua elemen `<li>` di dalam elemen yang id-nya `taskList`". Ada satu elemen `<li>`, jadi hasilnya 1. Variabel `jumlahTugas` sekarang berisi `1`.

**Langkah 3 — baris `console.log("Jumlah tugas saat ini: " + jumlahTugas);`**
Tanda `+` menggabungkan teks dan angka. `"Jumlah tugas saat ini: " + 1` menjadi teks `Jumlah tugas saat ini: 1`, lalu ditampilkan di Console.

**Output akhir:**
```
Jumlah tugas saat ini: 1
```

## Analogi
Menyiapkan environment seperti menyiapkan **meja kerja pustakawan** sebelum toko buku buka. Kamu perlu meja (text editor) untuk menulis kartu katalog, lampu (browser) supaya bisa membaca, dan lacinya diberi label per rak (struktur folder `js-learning/`). Sekali meja rapi, pekerjaan harian tinggal duduk dan mulai.

## Dipakai untuk Apa
- Menulis dan menyimpan semua file latihan JavaScript sepanjang course
- Menjalankan project Task Manager langsung di browser
- Live Server memperbarui halaman otomatis setiap file disimpan (tanpa klik refresh)
- Menjaga folder rapi: satu folder per level, memudahkan kamu menengok kemajuan belajar

## Kesalahan Umum yang Sering Terjadi
- **Bekerja di folder yang tidak jelas**: File berserakan di `Downloads` sehingga susah menemukannya lagi dan file lama tertukar. Hindari dengan membuat folder khusus `js-learning/` dari awal.
- **Lupa menginstall ekstensi Live Server**: Akibatnya kamu klik refresh manual terus tiap mengubah kode. Pasang ekstensinya sekali dari panel Extensions VS Code.
- **Menyimpan file dengan ekstensi ganda**: Misal menyimpan `level1.html.txt` karena format file di Save As tidak dipilih *All Files*. Browser tidak akan membukanya sebagai HTML. Periksa nama file setelah menyimpan.
- **Menjalankan kode tapi halamannya tidak berubah**: Biasanya karena file yang dibuka browser adalah file lama, atau perubahan belum disimpan. Selalu simpan file (Ctrl+S) lalu refresh browser.

## Soal Latihan & Jawaban
### Soal
Buat file `level1.html` di folder `js-learning/` yang menampilkan jumlah anggota perpustakaan. Tulis angka `25` di dalam elemen `<span id="memberCount">`, lalu baca angka itu lewat JavaScript dan tampilkan di console dalam format: `Jumlah anggota: 25`.

### Jawaban
```html
<!DOCTYPE html>
<html>
<body>
  <p>Jumlah anggota: <span id="memberCount">25</span></p>

  <script>
    // Ambil teks dari elemen, lalu ubah jadi angka
    const jumlah = Number(document.getElementById("memberCount").textContent);
    console.log("Jumlah anggota: " + jumlah);
  </script>
</body>
</html>
```
