# for Loop — Looping dengan Counter

## Penjelasan
`for` adalah perintah **perulangan** (loop) yang menjalankan blok kode berkali-kali memakai **penghitung** (*counter*) — sebuah variabel yang nilainya berubah tiap putaran.

Strukturnya: `for (inisialisasi; kondisi; update) { ... }`
- **inisialisasi** → membuat penghitung, dijalankan **sekali saja** di awal, misal `let i = 0`.
- **kondisi** → dicek tiap awal putaran. Kalau `true`, masuk blok; kalau `false`, loop berhenti.
- **update** → dijalankan tiap **setelah** blok selesai, misal `i++` yang artinya nilai `i` bertambah 1.

Urutan tiap putaran: inisialisasi → cek kondisi → jalankan blok → update → cek kondisi → jalankan blok → update → dan seterusnya sampai kondisi `false`.

Istilah di sekitarnya:
- Penghitung sering diberi nama `i`, `j`, `k`. `i` singkatan dari *index* (nomor urut).
- `break` → menghentikan **seluruh** loop di putaran itu juga.
- `continue` → melewati sisa blok putaran ini, lalu **lanjut** ke putaran berikutnya.

## Fungsi
Bayangkan Task Manager punya 100 tugas. Tanpa loop, kamu harus menulis 100 blok `console.log` yang isinya sama persis — ribet dan tidak masuk akal.

`for` menyelesaikan masalah itu: satu blok kode dijalankan otomatis sebanyak yang kamu butuhkan. Jumlah tugas berubah dari 5 jadi 1000, kodenya tetap sama — cuma angka kondisinya yang menyesuaikan.

## Cara Pengimplementasian / Code
```js
// Data aplikasi Task Manager
const manager = "Andi";
let tasks = ["Rapat Tim", "Buat Laporan", "Review PR"];

// 1. Loop standar: tampilkan semua tugas satu per satu
for (let i = 0; i < tasks.length; i++) {
  console.log("Task ke-" + (i + 1) + ": " + tasks[i]);
}

// 2. Loop dengan continue dan break
for (let i = 1; i <= 5; i++) {
  if (i === 2) continue;   // lewati putaran ini, langsung ke putaran berikutnya
  if (i === 4) break;      // hentikan seluruh loop
  console.log("Task ke-" + i);
}
```

Cara menjalankan: simpan kode di atas di dalam tag `<script>` pada file `level1.html`, buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

**Langkah 1 — baris `let tasks = [...]`**
Variabel `tasks` berisi 3 elemen, jadi `tasks.length` bernilai `3`.

**Langkah 2 — loop pertama dimulai**
`for` membuat penghitung `i` berisi `0` (inisialisasi). Lalu bertanya: "apakah `0 < 3`?" Hasilnya `true`, jadi masuk blok. `i + 1` bernilai `1` dan `tasks[0]` berisi `"Rapat Tim"`, sehingga mencetak `Task ke-1: Rapat Tim`.

**Langkah 3 — `i++` lalu cek kondisi lagi**
`i` bertambah jadi `1`. `1 < 3` → `true` → masuk blok lagi → mencetak `Task ke-2: Buat Laporan`.

| Putaran | Nilai `i` | `i < 3`? | Output |
|---|---|---|---|
| 1 | 0 | ya | Task ke-1: Rapat Tim |
| 2 | 1 | ya | Task ke-2: Buat Laporan |
| 3 | 2 | ya | Task ke-3: Review PR |
| — | 3 | tidak | (loop berhenti) |

**Langkah 4 — loop kedua dimulai**
Penghitung baru `i` dibuat berisi `1`. `1 <= 5` → `true`. Cek `i === 2` → `false`, cek `i === 4` → `false`, jadi mencetak `Task ke-1`.

**Langkah 5 — putaran `i = 2`**
`i === 2` bernilai `true`, maka `continue` dijalankan: sisa blok dilewati, `console.log` tidak jalan, dan putaran langsung lanjut ke `i = 3`.

**Langkah 6 — putaran `i = 3` dan `i = 4`**
`i = 3`: tidak ada yang cocok, jadi mencetak `Task ke-3`. Lalu `i = 4`: `i === 4` bernilai `true`, `break` dijalankan dan seluruh loop berhenti — putaran `i = 5` tidak pernah terjadi.

| Putaran | Nilai `i` | `i === 2`? | `i === 4`? | Output |
|---|---|---|---|---|
| 1 | 1 | tidak | tidak | Task ke-1 |
| 2 | 2 | ya → continue | — | (dilewati) |
| 3 | 3 | tidak | tidak | Task ke-3 |
| 4 | 4 | tidak | ya → break | (loop berhenti) |

**Output akhir:**
```
Task ke-1: Rapat Tim
Task ke-2: Buat Laporan
Task ke-3: Review PR
Task ke-1
Task ke-3
```

## Analogi
Pustakawan sedang mengecek isi rak buku satu per satu. Dia memegang penghitung di tangan: mulai dari rak nomor 0, selama nomor rak masih kurang dari total rak, dia periksa isinya, lalu penghitung digeser naik. Kalau ada rak berlabel "jangan diutak-atik", dia langsung **melewati** rak itu (`continue`); kalau ada tanda bahaya, dia **berhenti total** dari pemeriksaan (`break`).

## Dipakai untuk Apa
- Menampilkan seluruh isi `tasks` di console (dan nanti di layar).
- Menjumlahkan nilai, misal total poin dari daftar tugas.
- Membuat banyak elemen sekaligus, misal 30 baris kalender.
- Mencari tugas berdasarkan judul: diperiksa satu per satu sampai ketemu.
- Menghitung berapa tugas yang berstatus `"done"` lewat penghitung.

## Kesalahan Umum yang Sering Terjadi
- **Lupa update (penghitung tidak pernah naik)**: `for (let i = 0; i < tasks.length;)` membuat kondisi selalu `true`. Akibatnya loop tak berujung dan browser sampai macet. Hindari: pastikan selalu ada `i++` di bagian update.
- **Salah memakai `<` atau `<=`**: Index array di JavaScript mulai dari `0`, jadi akses terakhir yang benar adalah `i < tasks.length`. Kalau pakai `<=`, `i` akan menyentuh `tasks.length` yang isinya tidak ada. Akibatnya muncul `undefined` di output.
- **Memakai `i` di luar loop**: `let i` hanya hidup di dalam blok `for`. Akibatnya muncul error `i is not defined` di console. Hindari: buat variabel lain di luar kalau memang perlu dipakai sesudah loop.
- **Mengubah isi `tasks` saat loop berjalan**: Menghapus elemen membuat indeks di belakangnya bergeser, sehingga ada tugas yang terlewat. Akibatnya data tidak semua ikut diproses.

## Hubungan dengan Materi Sebelumnya

## Soal Latihan & Jawaban
### Soal
Task Manager punya daftar tugas berikut:
```js
let tasks = ["Rapat Tim", "Buat Laporan", "Review PR", "Deploy", "Tulis Dokumentasi"];
```
Buat program yang:
1. Menampilkan semua tugas lengkap dengan nomor urut mulai dari 1.
2. Menghitung jumlah total tugas memakai variabel penghitung `total` (hasilnya jangan diambil dari `tasks.length`).
3. Menampilkan tugas sampai ketemu `"Deploy"`, lalu berhenti memakai `break`.

### Jawaban
```js
let tasks = ["Rapat Tim", "Buat Laporan", "Review PR", "Deploy", "Tulis Dokumentasi"];

// 1. Tampilkan semua tugas dengan nomor urut
for (let i = 0; i < tasks.length; i++) {
  console.log("Task ke-" + (i + 1) + ": " + tasks[i]);
}

// 2. Hitung total tugas dengan penghitung sendiri
let total = 0;
for (let i = 0; i < tasks.length; i++) {
  total = total + 1;
}
console.log("Total tugas: " + total);

// 3. Berhenti begitu menemukan "Deploy"
for (let i = 0; i < tasks.length; i++) {
  if (tasks[i] === "Deploy") {
    console.log("Ketemu: " + tasks[i]);
    break;
  }
}
```
