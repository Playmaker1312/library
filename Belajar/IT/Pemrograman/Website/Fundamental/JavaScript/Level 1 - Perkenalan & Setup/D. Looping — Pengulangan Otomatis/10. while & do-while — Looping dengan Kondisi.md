# while & do-while — Looping dengan Kondisi

## Penjelasan
`while` adalah perulangan yang **mengulang selama kondisi masih `true`**, tanpa penghitung bawaan.

- `while (kondisi) { ... }` → kondisi dicek **sebelum** putaran. Kalau `false` sejak awal, blok tidak pernah jalan.
- `do { ... } while (kondisi)` → blok dijalankan **dulu**, baru kondisinya dicek. Jadi blok ini **minimal sekali jalan**, walau kondisi awalnya `false`.

Cara kerja `while`:
1. Cek kondisi.
2. Kalau `true`, jalankan bloknya — termasuk baris yang mengubah kondisi.
3. Ulangi dari langkah 1 sampai kondisi `false`, lalu lanjut ke baris sesudah loop.

Kapan pakai mana:
- `for` → jumlah putaran **sudah pasti** dari awal, misal semua isi `tasks`.
- `while` → jumlah putaran **belum diketahui**, tergantung kondisi data, misal proses tugas selama antrean masih ada.
- `do-while` → butuh hasil minimal sekali, misal menampilkan menu dulu sebelum menanyakan pilihan.

## Fungsi
Tidak semua pengulangan bisa dihitung di awal. Kalau kamu harus terus mengulang sampai pengguna mengisi `taskInput` dengan benar, kamu tidak tahu berapa kali harus mengulang — di sinilah `while` bekerja.

`do-while` menutup satu celah `while`: ada momen di mana blok **wajib** jalan dulu, seperti menampilkan menu atau pesan konfirmasi, baru syarat pengulangannya dinilai.

## Cara Pengimplementasian / Code
```js
// Data aplikasi Task Manager
let queue = 3;   // jumlah tugas dalam antrean

// while: proses tugas selama antrean masih ada
while (queue > 0) {
  console.log("Memproses tugas ke-" + queue);
  queue = queue - 1;   // kondisi diubah supaya loop tidak abadi
}
console.log("Antrean kosong");

// do-while: menu ini pasti tampil minimal sekali
let pilihan = "3";
do {
  console.log("=== Menu Task Manager ===");
  console.log("1. Tambah  2. Hapus  3. Keluar");
  // di aplikasi nyata, pilihan dibaca ulang dari input pengguna di sini
} while (pilihan !== "3");
```

Cara menjalankan: simpan kode di atas di dalam tag `<script>` pada file `level1.html`, buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

**Langkah 1 — baris `let queue = 3;`**
Variabel `queue` dibuat berisi angka `3`.

**Langkah 2 — cek `while (queue > 0)` untuk pertama kali**
`3 > 0` bernilai `true`, jadi JavaScript masuk blok dan mencetak `Memproses tugas ke-3`. Lalu baris `queue = queue - 1` mengubah `queue` jadi `2`.

| Putaran | Nilai `queue` saat dicek | `queue > 0`? | Output | Nilai `queue` setelah putaran |
|---|---|---|---|---|
| 1 | 3 | ya | Memproses tugas ke-3 | 2 |
| 2 | 2 | ya | Memproses tugas ke-2 | 1 |
| 3 | 1 | ya | Memproses tugas ke-1 | 0 |
| — | 0 | tidak | (loop berhenti) | 0 |

**Langkah 3 — kondisi terakhir bernilai `false`**
`0 > 0` → `false`. Loop berhenti, lalu JavaScript mencetak `Antrean kosong`.

**Langkah 4 — baris `do { ... }`**
JavaScript belum mengecek kondisi apa pun. Ia langsung masuk blok dan mencetak dua baris menu.

**Langkah 5 — cek `while (pilihan !== "3")`**
`pilihan` berisi `"3"`, jadi `"3" !== "3"` bernilai `false` dan loop selesai. Blok di atas tetap tercetak walau kondisinya false — inilah bukti aturan "minimal sekali jalan".

**Output akhir:**
```
Memproses tugas ke-3
Memproses tugas ke-2
Memproses tugas ke-1
Antrean kosong
=== Menu Task Manager ===
1. Tambah  2. Hapus  3. Keluar
```

## Analogi
Pustakawan melayani antrean pengunjung dengan aturan sederhana: **selama masih ada orang berdiri di depan meja, terus layani** — begitu antrean habis, dia berhenti dan duduk. Itulah `while`. Sedangkan `do-while` mirip pemeriksaan kartu: pustakawan wajib memeriksa **setidaknya satu kartu** dulu sebelum menyatakan pemeriksaan selesai, walau kartu di tangannya sudah terbaca benar sejak awal.

## Dipakai untuk Apa
- Memproses tugas selama array `tasks` belum kosong.
- Menampilkan menu berulang sampai pengguna memilih "Keluar".
- Mengulang pertanyaan sampai `taskInput` tidak kosong.
- Menampilkan pesan konfirmasi sebelum menghapus tugas.
- Loading state: menampilkan "Memuat..." selama data belum siap (dipakai lagi di Level 6).

## Kesalahan Umum yang Sering Terjadi
- **Lupa mengubah kondisi di dalam blok**: `while (queue > 0)` tanpa `queue--` membuat kondisi selalu `true`. Akibatnya loop tak berujung dan browser sampai macet. Hindari: ubah variabel yang dicek setiap putaran.
- **Pakai `while` padahal butuh minimal sekali**: kalau kondisi awal sudah `false`, blok tidak pernah jalan. Akibatnya menu atau pesan konfirmasi tidak pernah tampil. Hindari: pakai `do-while`.
- **Kondisi terbalik**: `while (queue < 0)` dengan isi `queue = 3` menghasilkan `false` di awal, jadi loop tidak jalan sama sekali. Akibatnya output kosong tanpa adanya error, sehingga sulit dicari penyebabnya.
- **Pakai `=` (assignment) di kondisi**: `while (queue = 0)` menimpa isi `queue` jadi `0`, sebuah nilai salah. Akibatnya loop tidak pernah jalan. Hindari: gunakan `===` untuk membandingkan.

## Soal Latihan & Jawaban
### Soal
Task Manager punya antrean tugas berikut:
```js
let antrean = ["Rapat Tim", "Buat Laporan", "Review PR", "Deploy"];
```
Buat program yang:
1. Memakai `while` untuk mencetak `Memproses: <nama tugas>` untuk tiap isi antrean, lalu mencetak `Semua tugas selesai` setelah antrean habis.
2. Memakai `do-while` untuk menampilkan `Yakin hapus semua tugas? (y/n): <jawaban>` minimal sekali, dengan `jawaban` diisi `"y"`. Loop berhenti kalau `jawaban` sudah `"y"` atau `"n"`.

### Jawaban
```js
let antrean = ["Rapat Tim", "Buat Laporan", "Review PR", "Deploy"];
let nomor = 0;

// while: jalan selama masih ada tugas yang belum diproses
while (nomor < antrean.length) {
  console.log("Memproses: " + antrean[nomor]);
  nomor = nomor + 1;   // supaya kondisi akhirnya false
}
console.log("Semua tugas selesai");

// do-while: pertanyaan tetap tampil walau jawaban sudah benar
let jawaban = "y";
do {
  console.log("Yakin hapus semua tugas? (y/n): " + jawaban);
} while (jawaban !== "y" && jawaban !== "n");
```
