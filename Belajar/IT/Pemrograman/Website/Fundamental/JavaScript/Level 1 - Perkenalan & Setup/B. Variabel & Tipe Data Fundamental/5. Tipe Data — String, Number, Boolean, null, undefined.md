# Tipe Data — String, Number, Boolean, null, undefined

## Penjelasan
Tipe data adalah **jenis isi** yang disimpan di dalam variabel. JavaScript termasuk bahasa *dynamically typed* (tipe ditentukan dari isinya, bukan dari deklarasinya), jadi satu variabel bisa berisi teks hari ini dan angka besok. Tipe primitif (tipe dasar) yang wajib kamu kuasai dulu:
- **`string`** — teks, selalu dibungkus kutip (`"halo"`, `'halo'`, atau `` `halo` ``). Backtick (kutip mundur) mendukung *template literal*: `` `Tugas ${count}` ``.
- **`number`** — angka, baik bilangan bulat (`5`) maupun desimal (`5.5`). Ada nilai khusus: `Infinity` (hasil bagi nol) dan `NaN` (*Not a Number*, hasil operasi yang tidak masuk akal).
- **`boolean`** — hanya `true` atau `false`.
- **`null`** — "sengaja kosong", kamu mengisinya sendiri dengan nilai kosong.
- **`undefined`** — "belum diisi", variabel dibuat tapi tidak pernah dikasih nilai.

Operator `typeof` dipakai untuk mengecek tipe suatu nilai: `typeof "halo"` → `"string"`.

## Fungsi
JavaScript memperlakukan `5` (angka) dan `"5"` (teks) secara berbeda — `"5" + 1` menghasilkan teks `"51"`, bukan `6`. Memahami tipe data mencegah bug aneh seperti jumlah tugas yang "tertempel" alih-alih bertambah. Kamu juga butuh `typeof` untuk memeriksa isi input user sebelum diproses.

## Cara Pengimplementasian / Code
```js
// string: teks — judul tugas
const taskTitle = "Belajar tipe data";

// number: angka — jumlah tugas selesai
const tasksDone = 5;

// boolean: true/false — status tugas
let isCompleted = false;

// null: sengaja dikosongkan (misal belum ada catatan)
let note = null;

// undefined: dibuat tapi belum pernah diisi
let dueDate;

console.log(typeof taskTitle);  // "string"
console.log(typeof tasksDone);  // "number"
console.log(typeof isCompleted); // "boolean"
console.log(typeof note);       // "object" (fakta unik JavaScript, null dianggap object)
console.log(typeof dueDate);    // "undefined"

// template literal: menyisipkan variabel ke dalam teks
const count = 3;
console.log(`Kamu punya ${count} tugas`);
```
Cara menjalankan: simpan sebagai `level1.html`, buka di browser, tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris.

**Langkah 1 — baris `const taskTitle = "Belajar tipe data";`**
Dibuat variabel `taskTitle` berisi teks `Belajar tipe data`. Isinya teks, jadi tipenya `string`.

**Langkah 2 — baris `const tasksDone = 5;`**
Dibuat variabel `tasksDone` berisi angka `5`. Tipe `number`.

**Langkah 3 — baris `let isCompleted = false;`**
Dibuat variabel `isCompleted` berisi `false`. Tipe `boolean`.

**Langkah 4 — baris `let note = null;`**
`note` diisi nilai `null` (kosong sengaja). Nilainya `null`.

**Langkah 5 — baris `let dueDate;`**
`dueDate` dibuat tapi tidak dikasih nilai, jadi otomatis berisi `undefined`.

**Langkah 6 — lima baris `console.log(typeof ...)`**
Satu per satu, `typeof` membaca tipenya lalu console mencetak:

| Nilai | Hasil `typeof` |
|---|---|
| `"Belajar tipe data"` | `string` |
| `5` | `number` |
| `false` | `boolean` |
| `null` | `object` (keanehan bawaan JS) |
| `undefined` | `undefined` |

**Langkah 7 — baris `const count = 3;`**
`count` berisi angka `3`.

**Langkah 8 — baris `` console.log(`Kamu punya ${count} tugas`) ``**
`${count}` diganti dengan isi `count`, yaitu `3`. Teks jadi `Kamu punya 3 tugas`.

**Output akhir:**
```
string
number
boolean
object
undefined
Kamu punya 3 tugas
```

## Analogi
Di perpustakaan, setiap isian **kartu katalog** punya kolom baku: kolom *Judul* harus berisi teks, kolom *Jumlah Halaman* harus berisi angka, kolom *Status Pinjam* hanya boleh "Ya"/"Tidak". `null` berarti kolom *Catatan* sengaja dikosongkan pustakawan; `undefined` berarti kartu baru dicetak dan kolomnya belum sempat diisi sama sekali.

## Dipakai untuk Apa
- `string`: judul tugas, nama user, isi input form
- `number`: jumlah tugas, poin, harga, indeks posisi
- `boolean`: status selesai/belum, toggle fitur on/off
- `null`: mengosongkan data dengan sadar (misal catatan dihapus)
- `undefined`: menandai data yang belum tersedia (misal tanggal tenggat belum diisi)
- `typeof`: validasi input sebelum data dihitung

## Kesalahan Umum yang Sering Terjadi
- **Angka ditulis dalam kutip**: `"5" + 1` menghasilkan `"51"` (teks ditempel), bukan `6`. Hilangkan kutip untuk angka, atau ubah dengan `Number("5")`.
- **Mengira `null` sama dengan `undefined`**: `null` artinya "sengaja kosong", `undefined` artinya "belum pernah diisi". Beda makna, meski keduanya berarti tidak ada isi.
- **Terkecoh `typeof null` yang bilang `object`**: Ini bug kuno JavaScript yang masih dipertahankan. Kalau perlu cek benar-benar kosong, pakai `value === null`.
- **Membaca `NaN` sebagai angka biasa**: `NaN` adalah tanda operasi gagal (misal `Number("abc")`). Selalu cek dengan `isNaN()`, jangan langsung dipakai hitungan.

## Soal Latihan & Jawaban
### Soal
Buat variabel untuk satu tugas di Task Manager: `title` berisi `"Raporku"`, `priority` berisi angka `2`, `isDone` berisi `false`, `category` berisi `null`, dan `reminder` (dideklarasikan tanpa nilai). Tampilkan tipe tiap variabel dengan `typeof`, lalu tampilkan kalimat: `Tugas "Raporku" selesai? false`.

### Jawaban
```html
<!DOCTYPE html>
<html>
<body>
  <script>
    const title = "Raporku";   // string
    const priority = 2;        // number
    let isDone = false;        // boolean
    let category = null;       // null (sengaja kosong)
    let reminder;              // undefined (belum diisi)

    console.log(typeof title);
    console.log(typeof priority);
    console.log(typeof isDone);
    console.log(typeof category);
    console.log(typeof reminder);

    console.log(`Tugas "${title}" selesai? ${isDone}`);
  </script>
</body>
</html>
```
