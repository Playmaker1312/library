# Operator Aritmatika & Logika — Manipulasi Data

## Penjelasan
Operator adalah simbol yang meminta JavaScript menghitung, membandingkan, atau menggabungkan nilai. Ada lima kelompok yang perlu kamu kuasai:
- **Aritmatika**: `+` (jumlah), `-` (kurang), `*` (kali), `/` (bagi), `%` (sisa bagi / modulo), `**` (pangkat). Operator `%` sering dipakai untuk cek ganjil-genap (sisa bagi 2).
- **Perbandingan**: `==` dan `===` (sama dengan), `!=` dan `!==` (tidak sama), `<`, `>`, `<=`, `>=`. Hasilnya selalu `boolean`. Pakai **`===`** (tiga sama dengan) — dia membandingkan nilai **dan** tipe, jadi `"5" === 5` bernilai `false`. `==` sering menipu karena dulu mengabaikan tipe.
- **Logika**: `&&` (dan — kedua sisi harus benar), `||` (atau — cukup satu sisi benar), `!` (kebalikan).
- **Assignment**: `=` (isi), `+=` (tambah lalu isi), `-=`, `*=` — singkatan dari menulis ulang.
- **Ternary**: `kondisi ? nilaiJikaBenar : nilaiJikaSalah` — if singkat dalam satu baris.

## Fungsi
Operator adalah alat manipulasi data. Aritmatika menghitung (misal jumlah tugas selesai), perbandingan dan logika menghasilkan `boolean` yang jadi bahan keputusan program. Operator assignment mempersingkat kode hitung yang berulang. Tanpa operator, kamu cuma bisa menyimpan data — tidak bisa memprosesnya.

## Cara Pengimplementasian / Code
```js
const totalTasks = 10;
const doneTasks = 7;

// Aritmatika
const remaining = totalTasks - doneTasks;      // 3
const isEven = totalTasks % 2 === 0;           // 10 sisa bagi 2 = 0 → genap

// Assignment
let score = 100;
score += 50;   // sama dengan score = score + 50 → 150

// Perbandingan (pakai ===, bukan ==)
console.log(totalTasks === 10);   // true
console.log("10" === 10);         // false: tipe beda (string vs number)

// Logika: semua tugas selesai = doneTasks === totalTasks DAN score > 100
const allDone = doneTasks === totalTasks && score > 100;
console.log(allDone);             // false

// Ternary: label status tugas
const status = remaining === 0 ? "Selesai" : "Masih ada " + remaining + " tugas";
console.log(status);
```
Cara menjalankan: simpan sebagai `level1.html`, buka di browser, tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris.

**Langkah 1 — baris `const totalTasks = 10;` dan `const doneTasks = 7;`**
Dibuat dua variabel: `totalTasks` = `10`, `doneTasks` = `7`.

**Langkah 2 — baris `const remaining = totalTasks - doneTasks;`**
`10 - 7 = 3`. Variabel `remaining` sekarang berisi `3`.

**Langkah 3 — baris `const isEven = totalTasks % 2 === 0;`**
`10 % 2` = sisa pembagian 10 dengan 2 = `0`. Lalu `0 === 0` → `true`. Variabel `isEven` berisi `true`.

**Langkah 4 — baris `let score = 100;` lalu `score += 50;`**
`score` awal `100`. `score += 50` berarti `score = 100 + 50`. Sekarang `score` berisi `150`.

**Langkah 5 — baris `console.log(totalTasks === 10);`**
`10 === 10` benar → console mencetak `true`.

**Langkah 6 — baris `console.log("10" === 10);`**
`"10"` bertipe teks, `10` bertipe angka. `===` menuntut tipe sama juga → console mencetak `false`.

**Langkah 7 — baris `const allDone = doneTasks === totalTasks && score > 100;`**
Uji kiri: `7 === 10` → `false`. Karena `&&` menuntut kedua sisi benar, hasil akhir `false` tanpa perlu menunggu. `allDone` berisi `false`.

**Langkah 8 — baris `const status = ...`**
Kondisi `remaining === 0` → `3 === 0` → `false`, jadi ternary mengambil nilai setelah `:`, yaitu `"Masih ada 3 tugas"`.

**Langkah 9 — baris `console.log(status);`**
Console mencetak isi `status`.

**Output akhir:**
```
true
false
false
Masih ada 3 tugas
```

## Analogi
Di perpustakaan, operator adalah **aturan di meja pustakawan**. Operator aritmatika menghitung sisa buku yang belum dikembalikan. Perbandingan memeriksa kartu: "apakah anggota ini telat?". Operator logika menggabungkan syarat: "anggota telat **dan** punya denda" baru boleh ditahan kartunya. Ternary adalah papan label singkat: `lunas ? "Boleh pinjam" : "Bayar denda dulu"`.

## Dipakai untuk Apa
- Menghitung progres tugas: `doneTasks / totalTasks * 100`
- Menentukan ganjil-genap, kelipatan, dan sisa (modulo)
- Memvalidasi input sebelum disimpan (nilai kosong? angka negatif?)
- Membuat keputusan program: prioritas tinggi atau bukan, tugas telat atau tidak
- Menyusun pesan status singkat dengan ternary

## Kesalahan Umum yang Sering Terjadi
- **Pakai `==` sehingga nilai aneh dianggap sama**: `"1" == 1` bernilai `true`, dan `"" == 0` juga `true` — kadang cocok, kadang tidak. Selalu pakai `===` dan `!==`.
- **Salah tipe saat operasi hitung**: `"10" - 5` bisa jadi `5` (JS mengubah otomatis), tapi `"10" + 5` jadi `"105"` (ditempel). Pastikan angka benar-benar `number`.
- **Lupa urutan operasi**: `10 - 2 * 3` dihitung `10 - 6 = 4`, bukan `24`. Gunakan kurung untuk mempertegas: `(10 - 2) * 3`.
- **Pakai `=` saat bermaksud membandingkan**: `if (score = 100)` mengisi `score` dengan 100, bukan memeriksanya. Bandingkan selalu dengan `===`.
- **Tanda koma jadi pemisah nilai di console**: `console.log(1, 2)` mencetak `1 2`. Untuk operasi, tulis `1 + 2`.

## Hubungan dengan Materi Sebelumnya
Setelah paham variabel (**materi 4 — Variabel — let, const, var**) dan tipe datanya (**materi 5 — Tipe Data — String, Number, Boolean, null, undefined**), sekarang kamu belajar cara memanipulasi isi variabel itu. Hasil operator berupa `boolean` inilah yang langsung kamu pakai di **materi 7 — if, else, else if — Kontrol Alur Dasar** dan **materi 8 — switch & Ternary**, kemudian dipakai lagi sebagai syarat loop di materi 9-10.

## Soal Latihan & Jawaban
### Soal
Sebuah proyek Task Manager punya `totalTasks = 8`, `doneTasks = 5`, dan `bonus = 10`. Hitung: (1) sisa tugas dengan `-=`, (2) apakah semua tugas selesai (pakai `===` dan `&&`), (3) apakah sisa tugas genap (pakai `%`), (4) tampilkan status akhir dengan ternary: `"Selesai"` jika tidak ada sisa, selain itu `"Sisa N tugas"`.

### Jawaban
```html
<!DOCTYPE html>
<html>
<body>
  <script>
    let totalTasks = 8;
    let doneTasks = 5;
    let bonus = 10;

    // (1) sisa = total - done, ditulis dengan assignment singkat
    let remaining = totalTasks;
    remaining -= doneTasks; // remaining = 8 - 5 = 3
    console.log("Sisa: " + remaining);

    // (2) semua selesai?
    const allDone = doneTasks === totalTasks;
    console.log("Semua selesai? " + allDone);

    // (3) sisa genap?
    const isEven = remaining % 2 === 0;
    console.log("Sisa genap? " + isEven);

    // (4) status dengan ternary
    const status = remaining === 0 ? "Selesai" : "Sisa " + remaining + " tugas";
    console.log(status);
  </script>
</body>
</html>
```
