# Variabel — let, const, var (Perbedaan & Best Practice)

## Penjelasan
Variabel adalah wadah bernama untuk menyimpan data dalam program. JavaScript punya tiga cara membuat variabel, dan ketiganya punya perilaku berbeda:
- **`var`** — cara lama. Cakupannya (area tempat variabel bisa diakses) adalah **fungsi**, artinya variabel `var` "bocor" keluar dari blok `if`/`for`. Nilainya juga bisa berubah diam-diam karena *hoisting* (variabel diangkat ke atas sebelum kode jalan, sehingga bisa terbaca sebelum dibuat). Sebaiknya dihindari.
- **`let`** — cara modern. Cakupannya **blok** (`{ ... }`), jadi tidak bocor keluar blok. Nilainya boleh diubah (di-*reassign*).
- **`const`** — sama seperti `let` dalam hal cakupan, tapi **nilainya tidak boleh diubah** setelah diisi. Ini pilihan utama untuk JavaScript modern.

Aturan penamaan:
- Pakai **camelCase**: `taskCount`, `taskTitle` (huruf pertama kecil, tiap kata berikutnya huruf besar).
- Nama harus deskriptif, bukan `x` atau `a`.
- Nama variabel case-sensitive: `task` berbeda dengan `Task`.
- Tidak boleh diawali angka dan tidak boleh memakai spasi.

## Fungsi
Variabel membuat data tidak perlu ditulis berulang di mana-mana. Nama aplikasi cukup disimpan sekali di `APP_NAME`, lalu dipakai di banyak tempat — kalau mau ganti nama, ubah di satu tempat saja. Pemilihan `let` vs `const` mencegah bug: data yang seharusnya tetap (seperti nama aplikasi) dijaga `const` supaya tidak tersalah-ubah oleh kode lain.

## Cara Pengimplementasian / Code
```js
// const: untuk nilai yang tidak berubah — ini pilihan utama
const APP_NAME = "Task Manager";

// let: untuk nilai yang akan berubah
let taskCount = 0;

// Menambah jumlah tugas
taskCount = taskCount + 1; // boleh, karena pakai let
console.log(APP_NAME, taskCount);

// var: cara lama, cakupannya bocor keluar blok — hindari
for (var nomorLama = 1; nomorLama <= 2; nomorLama++) {}
console.log(nomorLama); // masih terbaca di luar for! (bocor)

// let tidak bocor: coba di luar blok ini akan muncul error
{
  let nomorBaru = 1;
}
// console.log(nomorBaru); // ReferenceError jika diaktifkan
```
Cara menjalankan: simpan sebagai `level1.html`, buka di browser, tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris.

**Langkah 1 — baris `const APP_NAME = "Task Manager";`**
Dibuat variabel bernama `APP_NAME` berisi teks `Task Manager` dan dikunci: nilainya tidak boleh diganti.

**Langkah 2 — baris `let taskCount = 0;`**
Dibuat variabel `taskCount` berisi angka `0`. Karena pakai `let`, nilainya nanti boleh diganti.

**Langkah 3 — baris `taskCount = taskCount + 1;`**
Nilai lama `0` ditambah `1`, hasilnya `1` ditulis kembali ke `taskCount`. Sekarang `taskCount` berisi `1`.

**Langkah 4 — baris `console.log(APP_NAME, taskCount);`**
Console menampilkan kedua nilai, dipisah spasi: `Task Manager 1`.

**Langkah 5 — loop `for (var nomorLama = ...)`**
Loop berjalan dua putaran. Kita lihat nilai `nomorLama` tiap putaran:

| Putaran | `nomorLama <= 2`? | Isi `nomorLama` setelah loop |
|---|---|---|
| 1 | ya (1) | — |
| 2 | ya (2) | — |
| — | tidak (3) | 3, dan karena `var`, variabel tetap terbaca di luar for |

**Langkah 6 — baris `console.log(nomorLama);`**
Karena `var` punya cakupan fungsi (bukan blok), `nomorLama` masih terbaca. Console menampilkan `3` — ini yang dimaksud "bocor".

**Langkah 7 — blok `{ let nomorBaru = 1; }`**
`nomorBaru` hanya ada di dalam blok kurung kurawal. Setelah blok selesai, variabelnya hilang.

**Output akhir:**
```
Task Manager 1
3
```

## Analogi
Di perpustakaan, `var` seperti label nama yang ditempel di **seluruh rak**, jadi bisa dilihat (dan dipakai) dari mana pun — rawan tertukar. `let` seperti label di **satu rak saja**, hanya terbaca saat berdiri di depan rak itu. `const` seperti label yang **di-laminasi ke rak**: isinya terbaca, tapi tidak bisa diganti orang.

## Dipakai untuk Apa
- `const` untuk konfigurasi: `const APP_NAME = "Task Manager"`
- `let` untuk data yang berubah: `taskCount`, `currentIndex`, hasil input user
- `let` untuk menyimpan nilai sementara saat perhitungan
- Nama deskriptif membuat kode bisa dibaca orang lain (termasuk kamu sendiri nanti)

## Kesalahan Umum yang Sering Terjadi
- **Mengubah nilai `const`**: `const taskCount = 0; taskCount = 5;` langsung error `Assignment to constant variable`. Pakai `let` kalau nilainya harus berubah.
- **Pakai `var` dan heran variabel bocor**: `var` terbaca keluar blok `for`/`if` sehingga nilai lama bisa menimpa variabel lain tanpa kamu sadari. Ganti ke `let`.
- **Nama variabel tidak deskriptif**: `let a = 3;` tidak menjelaskan apa-apa. Belakangan kamu sendiri akan lupa `a` itu apa. Pakai `taskCount`.
- **Salah kapitalisasi**: `taskCount` dan `taskcount` adalah dua variabel berbeda. Konsisten pakai camelCase.
- **Menulis nama dengan spasi atau diawali angka**: `let 2task` atau `let my task` error. Nama hanya boleh huruf, angka, `$`, `_`, tanpa spasi.

## Soal Latihan & Jawaban
### Soal
Buat variabel untuk aplikasi Task Manager: `APP_NAME` berisi `"Task Manager"` (tidak boleh berubah), `taskCount` berisi `0` (boleh berubah), dan `owner` berisi `"Rina"` (boleh berubah). Tambah `taskCount` sebanyak 2, ganti `owner` menjadi `"Budi"`, lalu tampilkan: `Task Manager | Tugas: 2 | Pemilik: Budi`.

### Jawaban
```html
<!DOCTYPE html>
<html>
<body>
  <script>
    const APP_NAME = "Task Manager"; // konstan, tidak boleh diubah
    let taskCount = 0;               // boleh berubah
    let owner = "Rina";              // boleh berubah

    taskCount = taskCount + 1;
    taskCount = taskCount + 1;
    owner = "Budi";

    console.log(APP_NAME + " | Tugas: " + taskCount + " | Pemilik: " + owner);
  </script>
</body>
</html>
```
