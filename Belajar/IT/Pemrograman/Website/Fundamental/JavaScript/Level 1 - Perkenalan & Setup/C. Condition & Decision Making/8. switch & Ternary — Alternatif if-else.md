# switch & Ternary — Alternatif if-else

## Penjelasan
`switch` adalah perintah percabangan untuk membandingkan **satu variabel** dengan banyak nilai sekaligus. Bentuknya lebih ringkas daripada menulis `else if` beruntun.

Strukturnya:
- `switch (ekspresi)` → nilai yang akan dicocokkan (hasil perhitungan atau isi variabel).
- `case nilai:` → dicocokkan dengan `===` (perbandingan ketat), urut dari atas.
- `break` → perintah keluar dari `switch`. Tanpa `break`, eksekusi **jatuh** ke `case` berikutnya (disebut *fall-through*).
- `default:` → cabang terakhir kalau tidak ada `case` yang cocok. Opsional, tapi sangat disarankan.

Cara kerja `switch`:
- JavaScript menghitung `ekspresi` sekali di awal.
- Lalu membandingkannya dengan tiap `case` dari atas ke bawah memakai `===`.
- Begitu ada yang cocok, blok `case` itu dijalankan sampai ketemu `break`, lalu `switch` selesai.
- Kalau tidak ada yang cocok sama sekali, blok `default` yang dijalankan.

**Ternary** (`? :`) adalah `if/else` versi satu baris: `kondisi ? nilaiJikaTrue : nilaiJikaFalse`. Hasilnya berupa **nilai**, jadi bisa langsung dimasukkan ke dalam variabel.

## Fungsi
Kalau ada 5 kemungkinan status, `else if` beruntun bisa menghasilkan belasan baris yang isinya berulang. `switch` mengubahnya jadi blok rapi yang mudah dipindai mata, plus punya `default` sebagai jaring pengaman.

Ternary punya peran lain: membuat keputusan **kecil** tanpa memakan empat baris. Ini sering dipakai untuk menyiapkan teks atau label singkat sebelum ditampilkan.

## Cara Pengimplementasian / Code
```js
// Data aplikasi Task Manager
const manager = "Andi";
let tasks = ["Rapat Tim", "Buat Laporan"];
let priority = "high";

// switch: cocokkan SATU variabel dengan banyak nilai
switch (priority) {
  case "high":
    console.log("Prioritas Tinggi");
    break;                                   // keluar dari switch
  case "medium":
    console.log("Prioritas Sedang");
    break;
  case "low":
    console.log("Prioritas Rendah");
    break;
  default:
    console.log("Prioritas tidak dikenal");  // jaring pengaman
}

// Ternary: if/else versi satu baris, hasilnya sebuah nilai
let label = priority === "high" ? "Penting" : "Biasa";
console.log(label);

// Ternary untuk menyiapkan teks ringkasan
let ringkasan = tasks.length === 0 ? "Daftar kosong" : "Isi " + tasks.length + " tugas";
console.log(ringkasan);
```

Cara menjalankan: simpan kode di atas di dalam tag `<script>` pada file `level1.html`, buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita ikut mengikuti komputer.

**Langkah 1 — menyiapkan variabel**
`manager` berisi `"Andi"`, `priority` berisi teks `"high"`, dan `tasks` berisi 2 elemen sehingga `tasks.length` bernilai `2`.

**Langkah 2 — `switch (priority)` mulai bekerja**
JavaScript menghitung isi `priority`, hasilnya `"high"`. Sekarang ia mulai membandingkan dengan `case` dari atas.

**Langkah 3 — cek `case "high"`**
`"high" === "high"` → cocok. JavaScript masuk blok ini dan mencetak `Prioritas Tinggi`.

**Langkah 4 — baris `break` dieksekusi**
`break` artinya "keluar dari switch sekarang". Jadi `case "medium"`, `case "low"`, dan `default` **tidak dicek sama sekali**.

**Langkah 5 — baris `let label = ...`**
Kondisi `priority === "high"` bernilai `true`, jadi `label` mengambil nilai di kiri tanda `?`, yaitu `"Penting"`. Baris `console.log(label)` kemudian mencetak `Penting`.

**Langkah 6 — baris `let ringkasan = ...`**
`tasks.length === 0` → `2 === 0` → `false`, jadi `ringkasan` mengambil nilai di kanan tanda `:`, yaitu `"Isi 2 tugas"`. Baris berikutnya mencetak `Isi 2 tugas`.

**Output akhir:**
```
Prioritas Tinggi
Penting
Isi 2 tugas
```

## Analogi
Di perpustakaan ada meja informasi dengan beberapa jendela berlabel: "Peminjaman", "Pengembalian", dan "Keanggotaan". Pustakawan cukup melihat label pada kartu pengunjung, menuju jendela yang cocok, lalu **berhenti mencari** begitu ketemu — itulah `break`. Kalau labelnya tidak dikenal, pelayanan dialihkan ke jendela umum, itulah `default`. Sedangkan kalau labelnya cuma dua kemungkinan, pustakawan cukup melihat sekali: ini atau itu — itulah ternary.

## Dipakai untuk Apa
- Menentukan aksi dari `taskStatus` ("done", "pending", "cancelled").
- Menu navigasi: memilih fitur dari pilihan pengguna (1. tambah, 2. hapus, 3. keluar).
- Memberi badge warna berdasarkan `priority` tugas.
- Menyiapkan teks label singkat dengan ternary, misal status "Aktif" atau "Nonaktif".
- Menyaring tugas berdasarkan kategori ("feature", "bug", "docs").

## Kesalahan Umum yang Sering Terjadi
- **Lupa `break`**: Setelah `case` pertama jalan tanpa `break`, eksekusi jatuh ke `case` berikutnya. Akibatnya beberapa `console.log` tercetak sekaligus (output dobel). Hindari: tutup tiap `case` dengan `break`, kecuali memang sengaja menjatuhkannya.
- **Lupa `default`**: Kalau nilai yang dicek tidak ada yang cocok, tidak ada blok yang jalan. Akibatnya program diam saja tanpa output dan tanpa error. Hindari: selalu sediakan `default` sebagai jaring pengaman.
- **Salah tipe nilai di `case`**: `switch` memakai `===`, jadi `case 1` tidak akan cocok dengan `"1"` (angka dengan teks). Akibatnya `default` yang jalan padahal kelihatannya sama. Hindari: samakan tipe datanya.
- **Ternary bersarang terlalu dalam**: Bentuk `a ? b : c ? d : e` sulit dibaca. Akibatnya kode gampang salah saat diedit. Hindari: kalau ada lebih dari dua cabang, pakai `if/else` atau `switch` saja.

## Hubungan dengan Materi Sebelumnya
Materi ini adalah kelanjutan langsung dari **materi 7 — if, else, else if — Kontrol Alur Dasar**: `switch` dipakai saat if/else beruntun mulai panjang, sedangkan ternary dipakai kalau keputusannya cukup satu baris. Perbandingan `===` yang dipakai di `case` dan di ternary sudah kamu pelajari di **materi 6 — Operator Aritmatika & Logika — Manipulasi Data**, begitu pula ternary yang disinggung sekali di sana.

Perbedaan `"1"` dan `1` yang bikin `case` meleset dibahas di **materi 5 — Tipe Data — String, Number, Boolean, null, undefined**. Ke depan, kondisi ini akan muncul di dalam perulangan: **materi 9 — for Loop — Looping dengan Counter**.

## Soal Latihan & Jawaban
### Soal
Setiap tugas di Task Manager punya `category` yang berisi salah satu dari `"feature"`, `"bug"`, atau `"docs"`. Buat program yang:
1. Memakai `switch` untuk mencetak `Tugas fitur`, `Tugas bug`, atau `Tugas dokumentasi`, dan `Kategori tidak dikenal` untuk nilai lain.
2. Memakai ternary untuk membuat `tag` berisi `"baru"` kalau `tasks.length` kurang dari 3, selain itu `"rutin"`. Lalu cetak `tag`.

### Jawaban
```js
let tasks = ["Rapat Tim", "Buat Laporan"];
let category = "bug";

switch (category) {
  case "feature":
    console.log("Tugas fitur");
    break;
  case "bug":
    console.log("Tugas bug");          // cabang ini yang jalan
    break;
  case "docs":
    console.log("Tugas dokumentasi");
    break;
  default:
    console.log("Kategori tidak dikenal");
}

let tag = tasks.length < 3 ? "baru" : "rutin";
console.log(tag);
```
