# if, else, else if — Kontrol Alur Dasar

## Penjelasan
`if` adalah perintah untuk membuat program **memilih jalur** berdasarkan kondisi. Kondisi adalah pernyataan yang hasilnya cuma `true` (benar) atau `false` (salah).

Tiga bentuk utamanya:
- `if (kondisi) { ... }` → blok dijalankan **hanya kalau** kondisi bernilai `true`.
- `else if (kondisi) { ... }` → cabang tambahan untuk kemungkinan berikutnya; boleh ditulis lebih dari satu.
- `else { ... }` → **fallback**, dijalankan kalau semua kondisi di atasnya bernilai `false`.

Cara kerjanya berurutan dari atas ke bawah:
- JavaScript mengecek `if` paling atas dulu.
- Kalau `true`, bloknya dijalankan, lalu rangkaian percabangan dilewati (kondisi sesudahnya tidak dicek lagi).
- Kalau `false`, pindah mengecek `else if` berikutnya.
- Kalau semua `false`, barulah blok `else` yang dijalankan.

Aturan penting:
- Kondisi harus menghasilkan boolean. Biasanya berupa perbandingan seperti `===`, `>`, atau `<`.
- Blok ditandai kurung kurawal `{ }`. Tanpa `{ }`, hanya **satu baris** setelah `if` yang ikut.
- `else` bersifat opsional — menulis `if` saja sudah sah.

## Fungsi
Program tanpa percabangan cuma bisa jalan lurus: satu kode, satu hasil, dari awal sampai akhir. Aplikasi Task Manager tidak bisa begitu, karena ia harus **bereaksi terhadap data** — status tugas, jumlah tugas, dan isi form pengguna bisa berbeda tiap saat.

Dengan `if/else`, satu blok kode bisa menghasilkan perilaku yang berbeda-beda tanpa kamu menulis banyak versi program. Itulah alasan kenapa percabangan disebut dasar dari semua logika aplikasi.

## Cara Pengimplementasian / Code
```js
// Data aplikasi Task Manager
const manager = "Andi";
let tasks = ["Rapat Tim", "Buat Laporan"];
let taskStatus = "pending";

// Percabangan: JavaScript memilih SATU blok untuk dijalankan
if (taskStatus === "done") {
  console.log("Tugas sudah selesai");
} else if (taskStatus === "pending") {
  console.log("Tugas masih berjalan");   // cabang ini yang jalan
} else {
  console.log("Status tidak dikenal");
}

// if tanpa else juga boleh
if (tasks.length === 0) {
  console.log("Belum ada tugas");
}

// else if bertingkat: urutan kondisi harus dari yang spesifik
if (tasks.length > 5) {
  console.log("Banyak tugas");
} else if (tasks.length > 1) {
  console.log("Beberapa tugas");         // cabang ini yang jalan
} else {
  console.log("Sedikit tugas");
}
```

Cara menjalankan: simpan kode di atas di dalam tag `<script>` pada file `level1.html`, buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita ikut duduk di depan komputer.

**Langkah 1 — baris `const manager = "Andi";`**
JavaScript membuat variabel `manager` berisi teks `"Andi"`. `const` artinya isinya tidak boleh diganti.

**Langkah 2 — baris `let tasks = [...]`**
Variabel `tasks` dibuat berisi 2 elemen: `"Rapat Tim"` dan `"Buat Laporan"`. Jadi `tasks.length` bernilai `2`.

**Langkah 3 — baris `let taskStatus = "pending";`**
Variabel `taskStatus` berisi teks `"pending"`.

**Langkah 4 — cek `if (taskStatus === "done")`**
`"pending" === "done"` bernilai `false`. Karena hasilnya false, blok `if` pertama **dilewati**.

**Langkah 5 — cek `else if (taskStatus === "pending")`**
`"pending" === "pending"` bernilai `true`. JavaScript masuk blok ini dan mencetak `Tugas masih berjalan`.

**Langkah 6 — blok `else` tidak dicek**
Karena satu cabang sudah `true`, rangkaian percabangan pertama selesai. Blok `else` dilewati.

**Langkah 7 — baris `if (tasks.length === 0)`**
`2 === 0` bernilai `false`, jadi bloknya dilewati. Tidak ada output dari bagian ini.

**Langkah 8 — rangkaian `else if` kedua**
- `tasks.length > 5` → `2 > 5` → `false`, dilewati.
- `tasks.length > 1` → `2 > 1` → `true` → mencetak `Beberapa tugas`.
- Blok `else` (`Sedikit tugas`) tidak dicek lagi karena cabang sebelumnya sudah `true`.

**Output akhir:**
```
Tugas masih berjalan
Beberapa tugas
```

## Analogi
Di perpustakaan, pustakawan membaca kartu status buku lalu memilih satu tindakan: kalau tertulis "dipinjam", dia catat nama peminjamnya; kalau "rusak", dia pindahkan ke rak perbaikan; kalau statusnya tidak dikenal, dia tanyakan ke kepala pustakawan. Satu kartu, satu keputusan — persis seperti `if` / `else if` / `else` yang hanya memilih satu blok untuk dijalankan.

## Dipakai untuk Apa
- Menampilkan pesan berdasarkan `taskStatus` ("done", "pending", "cancelled").
- Menolak input `taskInput` yang kosong saat menambah tugas.
- Mengecek apakah daftar `tasks` masih kosong sebelum menghapus.
- Menentukan hak akses: admin versus pengguna biasa.
- Menampilkan peringatan saat kuota tugas harian terlampaui.

## Kesalahan Umum yang Sering Terjadi
- **`=` (assignment) vs `===` (perbandingan)**: Menulis `if (taskStatus = "done")` memakai satu tanda, yang artinya **menimpa** nilai, bukan membandingkan. Akibatnya `taskStatus` berubah jadi `"done"` dan kondisi selalu `true`, sehingga cabang `else` tidak pernah jalan. Hindari: selalu pakai `===` untuk perbandingan.
- **Lupa kurung kurawal `{ }`**: Tanpa `{ }`, hanya baris pertama yang ikut kondisi. Kalau kamu menambah `console.log` kedua di bawahnya, baris itu tetap jalan terus meski kondisi `false`. Akibatnya output jadi dobel atau salah.
- **Urutan `else if` terbalik**: Kalau kondisi umum diletakkan di atas (misal `tasks.length > 0` sebelum `tasks.length > 5`), kondisi pertama sudah `true` untuk semua nilai. Akibatnya cabang sesudahnya jadi kode mati yang tidak pernah tercapai.
- **Lupa beda huruf besar-kecil**: `"Done"` dan `"done"` adalah teks berbeda. Akibatnya `taskStatus === "done"` bernilai `false` padahal kelihatannya sama. Hindari: samakan format nilainya, atau pakai `.toLowerCase()`.

## Soal Latihan & Jawaban
### Soal
Di aplikasi Task Manager ada `taskStatus` yang isinya salah satu dari `"done"`, `"pending"`, `"cancelled"`, serta `tasks` berisi daftar tugas. Buat program yang:
1. Mencetak `Tugas sudah selesai` kalau statusnya `"done"`.
2. Mencetak `Tugas dibatalkan` kalau statusnya `"cancelled"`.
3. Mencetak `Status tidak dikenal` untuk status lain (termasuk `"pending"`).
4. Setelah itu, cetak `Daftar kosong` kalau `tasks.length === 0`; kalau tidak, cetak `Jumlah tugas: <banyaknya>`.

### Jawaban
```js
let taskStatus = "pending";
let tasks = ["Rapat Tim", "Buat Laporan"];

if (taskStatus === "done") {
  console.log("Tugas sudah selesai");
} else if (taskStatus === "cancelled") {
  console.log("Tugas dibatalkan");
} else {
  console.log("Status tidak dikenal");   // "pending" masuk ke cabang ini
}

if (tasks.length === 0) {
  console.log("Daftar kosong");
} else {
  console.log("Jumlah tugas: " + tasks.length);
}
```
