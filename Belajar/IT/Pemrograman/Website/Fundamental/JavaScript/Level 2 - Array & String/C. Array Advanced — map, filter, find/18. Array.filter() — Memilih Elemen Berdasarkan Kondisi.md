# Array.filter() — Memilih Elemen Berdasarkan Kondisi

## Penjelasan
`filter()` adalah method array yang menjalankan **kondisi** untuk setiap elemen, lalu mengumpulkan **hanya elemen yang lolos** ke dalam array baru.

- Syntax: `array.filter((element, index) => kondisi)`
- Callback harus mengembalikan **boolean**: `true` artinya elemen lolos, `false` artinya tersingkir
- Hasilnya array baru yang isinya bisa **lebih sedikit** (atau bahkan kosong) dari array asal
- Array asal **tidak berubah** — sama seperti `map()`
- Berbeda dengan `map()`, panjang hasil `filter()` **tidak tentu**

Kalau `map()` itu "ubah semua elemen", `filter()` itu "pilih sebagian elemen".

## Fungsi
Banyak fitur task manager berbentuk "pilih sebagian data": tampilkan task yang belum selesai, tampilkan task prioritas tinggi, tampilkan yang judulnya mengandung kata tertentu. Tanpa `filter()`, semua itu harus ditulis sebagai `for` + `if` + push manual ke array kosong — panjang dan rawan salah.

`filter()` menyederhanakan pekerjaan itu jadi satu baris, tanpa merusak data asli.

## Cara Pengimplementasian / Code
```js
// Konteks Task Manager: array of task objects
let tasks = [
  { id: 1, title: "belajar js", completed: false, priority: "high" },
  { id: 2, title: "bikin ui", completed: true, priority: "low" },
  { id: 3, title: "testing", completed: false, priority: "medium" },
  { id: 4, title: "deploy", completed: true, priority: "high" }
];

// 1. Kumpulkan task yang belum selesai
let belumSelesai = tasks.filter(task => task.completed === false);
console.log(belumSelesai);

// 2. Kumpulkan task prioritas "high"
let penting = tasks.filter(task => task.priority === "high");
console.log(penting.length); // 2

// 3. Digabung dengan map (materi 17): saring dulu, baru format tampilan
let daftar = tasks
  .filter(task => !task.completed)
  .map(task => `Task #${task.id}: ${task.title}`);
console.log(daftar);
```
Cara menjalankan: simpan kode di atas ke file `level2.html` di dalam tag `<script>`, buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri bagian `belumSelesai`, yaitu `tasks.filter(task => task.completed === false)`.

**Langkah 1 — `filter()` mulai berjalan**
`filter()` membuat wadah array baru (masih kosong), lalu mengecek elemen pertama.

**Langkah 2 — cek elemen pertama**
`task` berisi objek id 1 dengan `completed: false`. Kondisi `false === false` bernilai `true`, jadi objek id 1 **masuk** ke array baru.

**Langkah 3 — cek elemen kedua**
`task` berisi objek id 2 dengan `completed: true`. Kondisi `true === false` bernilai `false`, jadi objek ini **tidak ikut**.

**Langkah 4 — cek elemen ketiga**
`task` berisi objek id 3 dengan `completed: false`. Lolos, masuk array baru.

**Langkah 5 — cek elemen keempat**
`task` berisi objek id 4 dengan `completed: true`. Tidak lolos.

Elemen sudah habis, lalu `filter()` **mengembalikan array baru** berisi yang lolos saja.

| Putaran | Isi `task` (id / completed) | Kondisi `completed === false`? | Isi array baru |
|---|---|---|---|
| 1 | 1 / false | true (lolos) | [task id 1] |
| 2 | 2 / true | false (gugur) | [task id 1] |
| 3 | 3 / false | true (lolos) | [task id 1, task id 3] |
| 4 | 4 / true | false (gugur) | [task id 1, task id 3] |

**Output akhir:**
```
[ { id: 1, title: 'belajar js', completed: false, priority: 'high' },
  { id: 3, title: 'testing', completed: false, priority: 'medium' } ]
2
[ 'Task #1: belajar js', 'Task #3: testing' ]
```

## Analogi
`filter()` seperti pustakawan yang memindai seluruh rak lalu mengambil hanya buku berlabel "fiksi" untuk dipajang di rak showcase. Buku lain tetap tenang di rak aslinya — pustakawan hanya membuat daftar baru berisi buku yang lolos seleksi.

## Dipakai untuk Apa
- Menampilkan hanya task yang belum selesai di dashboard
- Menyaring task berdasarkan prioritas (high/medium/low)
- Membersihkan array dari data kosong atau null sebelum dipakai
- Mengumpulkan **semua** elemen yang cocok (kalau cuma butuh satu, pakai `find()` di materi 19)

## Kesalahan Umum yang Sering Terjadi
- **Lupa `return` di callback**: Menulis `tasks.filter(t => { t.completed })` dengan kurung kurawal tapi tanpa `return`. Callback mengembalikan `undefined` yang dianggap palsu, jadi semua elemen gugur dan hasilnya array kosong. Hindari: tulis kondisi tanpa kurawal `t => t.completed`, atau tambahkan `return`.
- **Salah pakai `=` di dalam kondisi**: `tasks.filter(t => t.completed = false)` bukan membandingkan, tapi **menimpa** nilai `completed` jadi `false`. Akibatnya tugas asli ikut berubah dan hasilnya selalu kosong. Hindari: selalu pakai `===` untuk membandingkan.
- **Mengira `filter()` mengubah array asal**: `filter()` hanya membuat salinan. Kalau mau menyimpan hasilnya permanen, assign ulang: `tasks = tasks.filter(...)`.
- **Mengira hasil `filter()` berupa satu elemen**: Hasilnya **selalu array**, walau cuma satu elemen yang lolos. Untuk mengambil satu elemen langsung (bukan array), pakai `find()` (materi 19).

## Hubungan dengan Materi Sebelumnya
Kamu sudah tahu cara mengulang array dengan `forEach` (materi 13) — tapi `forEach` hanya looping, tidak menghasilkan data baru. `filter()` adalah langkah lanjutannya: looping yang hasilnya dikumpulkan. Materi 17 (`map()`) mengubah setiap elemen, sedangkan `filter()` memilih elemen — keduanya sering dipakai berantai. Setelah ini, lanjut ke `find()` (materi 19) untuk mengambil satu elemen pertama yang cocok.

## Soal Latihan & Jawaban
### Soal
Dari array `tasks` berikut, buat array baru berisi string `"Task #<id>: <title>"` — **hanya** untuk task yang prioritasnya `"high"` DAN belum selesai.

### Jawaban
```js
let tasks = [
  { id: 1, title: "belajar js", completed: false, priority: "high" },
  { id: 2, title: "bikin ui", completed: true, priority: "low" },
  { id: 3, title: "testing", completed: false, priority: "medium" },
  { id: 4, title: "deploy", completed: true, priority: "high" },
  { id: 5, title: "review PR", completed: false, priority: "high" }
];

// Filter dua kondisi sekaligus dengan &&, lalu map ke format tampilan
let mendesak = tasks
  .filter(task => task.priority === "high" && task.completed === false)
  .map(task => `Task #${task.id}: ${task.title}`);

console.log(mendesak);
// Output:
// [ 'Task #1: belajar js', 'Task #5: review PR' ]

console.log(tasks.length); // 5 — array asal tetap utuh
```
