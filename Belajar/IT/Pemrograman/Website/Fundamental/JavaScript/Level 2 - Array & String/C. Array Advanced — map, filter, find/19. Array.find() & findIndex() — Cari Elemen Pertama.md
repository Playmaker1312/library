# Array.find() & findIndex() — Cari Elemen Pertama

## Penjelasan
`find()` adalah method array yang mengembalikan **elemen pertama** yang cocok dengan kondisi tertentu. `findIndex()` hampir sama, hanya beda hasil: yang dikembalikan adalah **index** elemen itu.

- Syntax: `array.find((element, index) => kondisi)` dan `array.findIndex((element, index) => kondisi)`
- Begitu menemukan yang pertama, keduanya **langsung berhenti** — sisa array tidak diperiksa
- `find()` menghasilkan **elemennya**; `findIndex()` menghasilkan **angka index**
- Kalau tidak ada yang cocok: `find()` → `undefined`, `findIndex()` → `-1`
- Beda dengan `filter()` (materi 18): `filter` mengumpulkan **semua** yang cocok jadi array, `find` hanya mengambil satu

Di aplikasi task manager, `find()` paling sering dipakai untuk mencari satu task berdasarkan `id`.

## Fungsi
Sering kita butuh **satu** data spesifik dari sekumpulan data: task dengan id tertentu, task dengan judul tertentu. Cara lamanya: tulis `for` loop sendiri, tambahkan `if`, lalu `break` kalau ketemu. `find()` melakukan persis itu dalam satu baris.

`findIndex()` berguna saat kamu butuh **posisi** elemennya — misalnya untuk mengubah atau menghapus elemen di index tersebut dengan `splice`.

## Cara Pengimplementasian / Code
```js
// Konteks Task Manager: array of task objects
let tasks = [
  { id: 1, title: "belajar js", completed: false, priority: "high" },
  { id: 2, title: "bikin ui", completed: true, priority: "low" },
  { id: 3, title: "testing", completed: false, priority: "medium" }
];

// 1. Cari task berdasarkan id (paling umum di task manager)
let target = tasks.find(task => task.id === 2);
console.log(target); // { id: 2, title: "bikin ui", completed: true, priority: "low" }

// 2. Cari posisi task yang BELUM selesai pertama kali
let index = tasks.findIndex(task => !task.completed);
console.log(index); // 0 (task id 1 ada di index 0)

// 3. Tidak ada yang cocok → undefined dan -1
let hilang = tasks.find(task => task.id === 99);
console.log(hilang); // undefined

// 4. Pola aman: cari dulu, kalau ketemu baru diubah
let cari = tasks.find(t => t.title === "testing");
if (cari !== undefined) {
  cari.completed = true; // aman, karena cari pasti objek
}
console.log(tasks[2]);
```
Cara menjalankan: simpan kode di atas ke file `level2.html` di dalam tag `<script>`, buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri `tasks.find(task => task.id === 2)`.

**Langkah 1 — `find()` mulai berjalan**
`find()` mulai memeriksa elemen dari awal array, satu per satu.

**Langkah 2 — cek elemen pertama**
`task` berisi objek id 1. Kondisi `1 === 2` bernilai `false`, jadi lanjut ke elemen berikutnya. Belum ada yang dikembalikan.

**Langkah 3 — cek elemen kedua**
`task` berisi objek id 2. Kondisi `2 === 2` bernilai `true`. Karena ketemu, `find()` **langsung berhenti** dan mengembalikan objek ini. Elemen ketiga tidak sempat diperiksa.

**Langkah 4 — hasil disimpan**
Variabel `target` kini berisi `{ id: 2, title: "bikin ui", completed: true, priority: "low" }`.

| Putaran | Isi `task` (id / title) | Kondisi `id === 2`? | Keputusan |
|---|---|---|---|
| 1 | 1 / "belajar js" | false | lanjut |
| 2 | 2 / "bikin ui" | true | berhenti, return objek ini |
| — | 3 / "testing" | tidak diperiksa | — |

**Output akhir:**
```
{ id: 2, title: 'bikin ui', completed: true, priority: 'low' }
0
undefined
{ id: 3, title: 'testing', completed: true, priority: 'medium' }
```

## Analogi
`find()` seperti pustakawan yang mencari satu kartu katalog di laci berdasarkan nomor buku. Dia membuka kartu demi kartu dan **berhenti di kartu pertama** yang nomornya cocok — sisanya tidak perlu dibuka. Kalau laci habis tanpa kecocokan, tangannya pulang kosong (hasilnya `undefined`).

## Dipakai untuk Apa
- Membuka detail satu task berdasarkan `id` (fitur "klik task → lihat detail")
- Mengecek apakah judul task sudah dipakai task lain (deteksi duplikat)
- Mencari posisi task dengan `findIndex()` sebelum mengubah atau menghapusnya
- Mencari elemen pertama yang belum selesai untuk dijadikan tugas berikutnya

## Kesalahan Umum yang Sering Terjadi
- **Mengira `find()` mengembalikan index**: `find()` mengembalikan **elemennya** (bisa object), bukan angka. Untuk angka index, pakai `findIndex()`. Akibat salah pakai: kode seperti `tasks.find(t => t.id === 2)[0]` jadi `undefined` karena yang diakses adalah properti `[0]` dari object.
- **Lupa hasil bisa `undefined`**: Kalau tidak ada yang cocok, `find()` mengembalikan `undefined`. Langsung menulis `hasil.title` akan memunculkan error `TypeError: Cannot read properties of undefined`. Hindari: selalu cek dulu `if (hasil !== undefined)`.
- **Mengira `find()` mencari semua yang cocok**: `find()` berhenti di yang pertama. Kalau kamu butuh **semua** elemen yang cocok, gunakan `filter()` (materi 18).
- **Memakai `indexOf()` untuk mencari object**: `indexOf()` membandingkan nilai secara persis, jadi tidak bisa menemukan object. Untuk mencari di array of objects, gunakan `find()` atau `findIndex()`.

## Hubungan dengan Materi Sebelumnya
Kamu sudah belajar `indexOf()` yang mencari **index** elemen primitif seperti string dan angka (materi 12), lalu `filter()` yang mengumpulkan semua elemen cocok jadi array (materi 18). `find()` dan `findIndex()` melengkapi trio pencarian: `indexOf` untuk nilai primitif, `filter` untuk banyak elemen, `find` untuk satu elemen pertama. Materi 20 dan 21 selanjutnya mendalami bentuk object yang kamu cari-cari ini — karena `find()` hampir selalu dipakai di array of objects seperti `tasks`.

## Soal Latihan & Jawaban
### Soal
Dari array `tasks` berikut, cari task dengan `id` 3. Jika ketemu, tampilkan judulnya lalu ubah statusnya jadi `completed: true`. Jika tidak ketemu, tampilkan pesan `"Task tidak ditemukan"`.

### Jawaban
```js
let tasks = [
  { id: 1, title: "belajar js", completed: false, priority: "high" },
  { id: 2, title: "bikin ui", completed: true, priority: "low" },
  { id: 3, title: "testing", completed: false, priority: "medium" }
];

// Cari task berdasarkan id
let task = tasks.find(t => t.id === 3);

if (task !== undefined) {
  console.log("Judul:", task.title); // "Judul: testing"
  task.completed = true; // ubah langsung objeknya, karena find mengembalikan referensi
} else {
  console.log("Task tidak ditemukan");
}

console.log(tasks[2]);
// Output:
// { id: 3, title: 'testing', completed: true, priority: 'medium' }

// Bonus: cari index task yang belum selesai pertama
let idx = tasks.findIndex(t => !t.completed);
console.log("Task belum selesai pertama ada di index:", idx); // 0
```
