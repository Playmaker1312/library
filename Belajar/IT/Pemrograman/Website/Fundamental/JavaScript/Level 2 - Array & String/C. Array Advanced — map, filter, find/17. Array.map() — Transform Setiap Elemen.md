# Array.map() — Transform Setiap Elemen

## Penjelasan
`map()` adalah method (fungsi bawaan) array yang menjalankan fungsi untuk **setiap elemen**, lalu mengumpulkan hasilnya ke dalam **array baru**. Intinya: setiap elemen lama dipetakan (*mapped*) menjadi versi barunya.

- Syntax: `array.map((element, index) => hasilBaru)`
- Mengembalikan **array baru** dengan panjang yang **sama persis** dengan array asal
- Array asal **tidak pernah berubah** (tidak mutate)
- Callback-nya wajib `return` — nilai yang di-return itulah yang jadi isi array baru
- Parameter callback: `element` (elemen saat ini) dan `index` (posisinya, opsional)

Kalau tujuanmu *memilih* sebagian elemen berdasarkan kondisi, itu bukan pekerjaan `map` — itu `filter` (materi 18).

## Fungsi
Tanpa `map()`, mengubah bentuk data harus pakai `for` loop manual: siapkan array kosong, push satu-satu, jaga-jaga index tidak salah. `map()` meringkas semua itu jadi satu baris yang lebih mudah dibaca.

Yang paling penting: `map()` tidak menyentuh array asal. Data mentah tetap utuh, dan yang kamu pakai untuk tampilan adalah array hasil. Ini membuat kode lebih aman dan mudah dites.

## Cara Pengimplementasian / Code
```js
// Konteks Task Manager: array of task objects
let tasks = [
  { id: 1, title: "belajar js", completed: false, priority: "high" },
  { id: 2, title: "bikin ui", completed: true, priority: "low" },
  { id: 3, title: "testing", completed: false, priority: "medium" }
];

// 1. Transform array of objects → array of string untuk ditampilkan
let display = tasks.map(task =>
  `Task #${task.id}: ${task.title} (${task.completed ? "done" : "not done"})`
);
console.log(display);

// 2. Ambil semua judul lalu kapitalisasi huruf pertama (kombinasi materi 14)
let titles = tasks.map(task => task.title); // ["belajar js", "bikin ui", "testing"]
let rapi = titles.map(t => t.charAt(0).toUpperCase() + t.slice(1));
console.log(rapi);

// 3. Buktikan array asal tidak berubah
console.log(tasks[0].title); // masih "belajar js"
```
Cara menjalankan: simpan kode di atas ke file `level2.html` di dalam tag `<script>`, buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri bagian `display` saja supaya ringkas.

**Langkah 1 — baris `let tasks = [...]`**
JavaScript membuat array `tasks` berisi 3 objek.

**Langkah 2 — `tasks.map(...)` mulai berjalan**
`map()` membuat wadah array baru (masih kosong), lalu memanggil callback untuk elemen pertama.

**Langkah 3 — callback jalan untuk elemen pertama**
`task` berisi `{ id: 1, title: "belajar js", completed: false, priority: "high" }`. Callback mengembalikan string `"Task #1: belajar js (not done)"`. Array baru sekarang berisi 1 elemen.

**Langkah 4 — callback jalan untuk elemen kedua**
`task` berisi objek dengan id 2. Callback mengembalikan `"Task #2: bikin ui (done)"`. Array baru berisi 2 elemen.

**Langkah 5 — callback jalan untuk elemen ketiga**
`task` berisi objek dengan id 3. Callback mengembalikan `"Task #3: testing (not done)"`. Array baru berisi 3 elemen.

Elemen sudah habis, jadi `map()` selesai dan **mengembalikan array baru** ke variabel `display`.

| Putaran | Isi `task` (id / title / completed) | Nilai yang di-return callback |
|---|---|---|
| 1 | 1 / "belajar js" / false | "Task #1: belajar js (not done)" |
| 2 | 2 / "bikin ui" / true | "Task #2: bikin ui (done)" |
| 3 | 3 / "testing" / false | "Task #3: testing (not done)" |

**Output akhir:**
```
[ 'Task #1: belajar js (not done)', 'Task #2: bikin ui (done)', 'Task #3: testing (not done)' ]
[ 'Belajar js', 'Bikin ui', 'Testing' ]
belajar js
```

## Analogi
Di perpustakaan, `map()` seperti pustakawan yang menyalin daftar judul buku ke kartu katalog baru, sekaligus merapikan penulisannya. Rak buku (array asal) tetap utuh — pustakawan hanya membuat salinan daftar yang sudah diformat.

## Dipakai untuk Apa
- Menampilkan daftar task dalam format tertentu ("Task #1: ...")
- Mengambil satu field dari array of objects (misalnya semua `title` saja)
- Mengubah tipe data tiap elemen (string → angka, objek → string)
- Menyiapkan data sebelum dikirim ke tampilan atau ke server

## Kesalahan Umum yang Sering Terjadi
- **Lupa `return` di callback**: Menulis `tasks.map(t => { t.title.toUpperCase() })` dengan kurung kurawal tapi tanpa `return`. Akibatnya array baru berisi `undefined` semua. Hindari: pakai bentuk tanpa kurawal `t => t.title.toUpperCase()`, atau tulis `return` eksplisit di dalam kurawal.
- **Mengira `map()` mengubah array asal**: Hasil `map()` harus disimpan dulu, misalnya `tasks = tasks.map(...)`. Tanpa assignment, array asli tetap apa adanya dan hasilnya hilang percuma.
- **Memakai `map()` untuk menyaring elemen**: `map()` selalu menghasilkan array sepanjang array asal. Untuk memilih sebagian elemen, pakai `filter()` (materi 18).
- **Mengharapkan `map()` menambah atau mengurangi jumlah elemen**: Hasil `map()` selalu sepanjang input. Kalau butuh hasil lebih sedikit atau lebih banyak, `map` bukan method yang tepat.

## Hubungan dengan Materi Sebelumnya
Sebelumnya kamu sudah bisa mengulang array dengan `for` dan `forEach` (materi 13) serta memanipulasi string dengan `charAt`, `slice`, dan `toUpperCase` (materi 14). `map()` di materi ini menggabungkan keduanya: loop yang hasilnya dikumpulkan jadi array baru. Setelah ini, lanjut ke `filter()` (materi 18) untuk menyaring elemen dan `find()` (materi 19) untuk mengambil satu elemen. Kombinasi map + filter ini akan dipakai lagi saat belajar function CRUD di Level 3 (materi 22).

## Soal Latihan & Jawaban
### Soal
Dari array `tasks` berikut, buat array baru berisi string `"Judul: <title> [Priority: <priority>]"` untuk setiap task. Contoh hasil pertama: `"Judul: belajar js [Priority: high]"`. Pastikan array `tasks` asli tidak berubah sama sekali.

### Jawaban
```js
let tasks = [
  { id: 1, title: "belajar js", completed: false, priority: "high" },
  { id: 2, title: "bikin ui", completed: true, priority: "low" },
  { id: 3, title: "testing", completed: false, priority: "medium" }
];

// Map setiap object task menjadi satu string rapi
let laporan = tasks.map(task => `Judul: ${task.title} [Priority: ${task.priority}]`);

console.log(laporan);
// Output:
// [ 'Judul: belajar js [Priority: high]',
//   'Judul: bikin ui [Priority: low]',
//   'Judul: testing [Priority: medium]' ]

console.log(tasks.length); // 3 — array asal tetap utuh
console.log(tasks[0].title); // "belajar js" — tidak berubah
```
