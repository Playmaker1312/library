# Object Literal — Deklarasi & Akses Property

## Penjelasan
Object adalah struktur data **kunci-nilai** (*key-value*). Di dalam satu variabel, kamu bisa menampung banyak data sekaligus — masing-masing punya nama (kunci) dan isi (nilai).

- Deklarasi: `let obj = { key: value, key2: value2 }` (disebut **object literal**, artinya object yang ditulis langsung dengan kurung kurawal)
- Tiap pasangan kunci-nilai disebut **property**
- Kuncinya biasanya string (ditulis tanpa kutip), nilai (`value`)-nya bebas: string, number, boolean, array, bahkan object lain
- Property dipisah **koma**
- Akses nilai dengan **dot notation**: `obj.key`
- Atau **bracket notation**: `obj["key"]` — wajib dipakai kalau nama kuncinya ada di variabel

Kenapa perlu object? Satu task bukan cuma judul — ada id, status, prioritas. Tanpa object, kamu harus membuat banyak variabel terpisah atau array campur aduk yang sulit dikelola.

## Fungsi
Object memungkinkan kamu mengelompokkan data milik **satu hal** dalam satu wadah yang rapi. Semua info tentang satu task ada di dalam satu `task`, bukan tersebar di `taskId`, `taskTitle`, `taskCompleted`, dan seterusnya.

Object juga jadi fondasi penting: array of objects (seperti `tasks` di Task Manager) adalah bentuk data paling umum di aplikasi nyata, dan materi object ini akan kamu lanjutkan sampai ke Class di level berikutnya.

## Cara Pengimplementasian / Code
```js
// Konteks Task Manager: satu task sebagai object literal
let task = {
  id: 1,                          // number
  title: "Belajar JS",            // string
  completed: false,               // boolean
  priority: "high",               // string
  tags: ["js", "level 2"],        // array sebagai value
  detail: { deadline: "Jumat", menit: 30 } // object bersarang (nested)
};

// 1. Akses dengan dot notation
console.log(task.title); // "Belajar JS"

// 2. Akses dengan bracket notation
console.log(task["completed"]); // false

// 3. Nama kunci dari variabel — bracket notation wajib di sini
let field = "priority";
console.log(task[field]); // "high"

// 4. Object bisa menyimpan function (namanya method)
let manager = {
  nama: "Task Manager",
  jumlahTask: 3,
  ringkas: function () {
    return `${this.nama} punya ${this.jumlahTask} task`; // this = objeknya sendiri
  }
};
console.log(manager.ringkas()); // "Task Manager punya 3 task"
```
Cara menjalankan: simpan kode di atas ke file `level2.html` di dalam tag `<script>`, buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri bagian object `task` sampai ke `console.log(task[field])`.

**Langkah 1 — baris `let task = {...}`**
JavaScript membuat satu object. Di dalamnya tersimpan 6 property: `id` (1), `title` ("Belajar JS"), `completed` (false), `priority` ("high"), `tags` (array 2 elemen), dan `detail` (object berisi `deadline` serta `menit`).

**Langkah 2 — `console.log(task.title)`**
JavaScript mencari kunci bernama `title` di dalam `task`, lalu menemukan nilainya `"Belajar JS"`. Kalau kuncinya tidak ada, hasilnya akan `undefined`.

**Langkah 3 — `console.log(task["completed")]`**
Bracket notation mencari kunci `completed`. Hasilnya `false`. Ini cara kerjanya sama persis dengan dot notation.

**Langkah 4 — baris `let field = "priority"`**
Variabel `field` kini berisi string `"priority"`.

**Langkah 5 — `console.log(task[field])`**
JavaScript **membaca isi variabel `field` dulu** (hasilnya `"priority"`), baru mencari kunci itu di `task`. Nilainya `"high"`. Perhatikan: `task.field` tanpa bracket TIDAK bisa dipakai di sini, karena itu berarti mencari kunci bernama literal "field".

**Langkah 6 — `console.log(manager.ringkas())`**
JavaScript mencari kunci `ringkas` di `manager`, menemukan sebuah function, lalu menjalankannya. Di dalam function, `this` menunjuk ke `manager` sendiri, jadi `${this.nama}` jadi `"Task Manager"`.

| Baris | Yang diakses | Hasil |
|---|---|---|
| `task.title` | kunci "title" | "Belajar JS" |
| `task["completed"]` | kunci "completed" | false |
| `task[field]` | kunci "priority" | "high" |
| `manager.ringkas()` | kunci "ringkas" (function) | "Task Manager punya 3 task" |

**Output akhir:**
```
Belajar JS
false
high
Task Manager punya 3 task
```

## Analogi
Object literal seperti **kartu katalog buku** di perpustakaan. Satu kartu punya beberapa kolom bernama — Judul, Pengarang, Tahun Terbit, Status — dan tiap kolom terisi data. Nama kolomnya itu kuncinya (*key*), isinya itu nilainya (*value*). Membaca `task.title` sama dengan "baca kolom Judul pada kartu task".

## Dipakai untuk Apa
- Menyimpan satu task lengkap: `{id, title, completed, priority}`
- Menampung data user yang sedang login
- Bentuk hasil response dari server/API (hampir selalu berbentuk object)
- Konfigurasi aplikasi, misalnya `{theme: "dark", language: "id"}`

## Kesalahan Umum yang Sering Terjadi
- **Lupa koma atau salah tanda baca antar property**: Antar property harus dipisah koma, dan penutupnya kurung kurawal — bukan titik koma. Salah satu saja membuat error `Syntax: Unexpected token` dan seluruh script berhenti.
- **Mengakses property yang tidak ada**: `task.dueDate` tidak error, tapi hasilnya `undefined`. Yang berbahaya kalau kamu menelusuri lebih dalam, misalnya `task.detail.deadline` padahal `task.detail` tidak ada — langsung error `TypeError`.
- **Mengira object bisa diakses pakai nomor urut seperti array**: `task[0]` hasilnya `undefined`. Yang diakses selalu **nama kunci**, bukan nomor urut.
- **Salah pakai dot untuk nama dari variabel**: `task.field` berarti mencari kunci literal bernama "field". Kalau namanya ada di variabel, wajib bracket: `task[field]`.

## Soal Latihan & Jawaban
### Soal
Buat object `task` berisi property `id` (number), `title` (string), `completed` (boolean), dan `priority` (string). Lalu:
1. Tampilkan judul task dengan dot notation.
2. Simpan nama field `"priority"` ke variabel, lalu tampilkan nilainya lewat bracket notation.
3. Tampilkan satu kalimat: `"Task #<id>: <title> — <priority>"`.

### Jawaban
```js
let task = {
  id: 7,
  title: "Belajar Object",
  completed: false,
  priority: "high"
};

// 1. Dot notation
console.log(task.title); // "Belajar Object"

// 2. Bracket notation dengan nama dari variabel
let field = "priority";
console.log(task[field]); // "high"

// 3. Satu kalimat rapi dengan template literal (materi 16)
console.log(`Task #${task.id}: ${task.title} — ${task[field]}`);
// Output:
// Task #7: Belajar Object — high
```
