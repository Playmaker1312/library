# Mengubah & Menambah Property

## Penjelasan
Object di JavaScript bersifat **mutable**, artinya isinya bisa diubah, ditambah, dan dikurangi kapan saja setelah dibuat.

- **Ubah nilai** property yang sudah ada: `obj.key = nilaiBaru`
- **Tambah** property baru: `obj.keyBaru = nilai` — kuncinya langsung dibuat otomatis
- Boleh juga lewat bracket: `obj["key"] = nilai`
- **Hapus** property: `delete obj.key` — kuncinya hilang dari object (mengembalikan `true` kalau berhasil)
- **Cek** apakah property ada: `"key" in obj` atau `obj.hasOwnProperty("key")` — hasilnya `true`/`false`

Catatan penting: `const task = {...}` **tetap bisa diubah isinya**. `const` hanya mengunci variabelnya (tidak bisa di-assign object baru), bukan isi objectnya.

## Fungsi
Task itu data hidup. Saat kamu mencentang "selesai", `completed` harus berubah jadi `true`. Saat user mengganti judul, `title` harus diganti. Saat ingin mencatat tanggal selesai, property baru harus ditambahkan.

Semua operasi hidup-matinya task di aplikasi Task Manager — update, tambah kolom, hapus kolom — berputar di kemampuan mengubah property ini. Inilah separuh dari logika **CRUD** (*Create, Read, Update, Delete*) yang akan kamu bangun di Level 3.

## Cara Pengimplementasian / Code
```js
// Konteks Task Manager: satu task, lalu kita "hidupi"
let task = {
  id: 1,
  title: "belajar js",
  completed: false,
  priority: "high"
};

// 1. Ubah nilai property yang sudah ada
task.completed = true;

// 2. Tambah property baru (kunci "dueDate" belum ada, langsung dibuat)
task.dueDate = "2026-10-20";

// 3. Ubah juga boleh lewat bracket notation
task["priority"] = "medium";

// 4. Hapus property yang tidak dipakai
delete task.dueDate;

// 5. Cek keberadaan property sebelum dipakai
console.log("completed" in task);         // true
console.log(task.hasOwnProperty("dueDate")); // false — sudah di-delete

console.log(task);

// 6. const tidak mengunci isi object — yang dikunci hanya variabelnya
const taskTetap = { id: 2, title: "lama" };
taskTetap.title = "baru"; // boleh!
console.log(taskTetap);
```
Cara menjalankan: simpan kode di atas ke file `level2.html` di dalam tag `<script>`, buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri object `task` dari awal sampai akhir.

**Langkah 1 — `let task = {...}`**
Object dibuat dengan 4 property: `id` = 1, `title` = "belajar js", `completed` = false, `priority` = "high".

**Langkah 2 — `task.completed = true`**
Kunci `completed` sudah ada, jadi nilainya **diganti**: sekarang `true`.

**Langkah 3 — `task.dueDate = "2026-10-20"`**
Kunci `dueDate` belum ada, jadi JavaScript **membuat kunci baru** lalu mengisinya. Object kini punya 5 property.

**Langkah 4 — `task["priority"] = "medium"`**
Nilai `priority` yang tadinya "high" **diganti** jadi "medium".

**Langkah 5 — `delete task.dueDate`**
Kunci `dueDate` **dihapus** dari object. Object kembali punya 4 property. Perhatikan: ini beda dengan mengisi `undefined` — kuncinya benar-benar hilang.

**Langkah 6 — `console.log("completed" in task)`**
JavaScript mengecek apakah kunci `completed` ada di object → `true`.

**Langkah 7 — `console.log(task.hasOwnProperty("dueDate"))`**
`dueDate` sudah dihapus pada Langkah 5 → `false`.

Isi object `task` setiap kali berubah:

| Setelah baris | Isi object `task` |
|---|---|
| deklarasi | `{ id: 1, title: "belajar js", completed: false, priority: "high" }` |
| `task.completed = true` | `{ id: 1, title: "belajar js", completed: true, priority: "high" }` |
| `task.dueDate = ...` | `{ id: 1, title: "belajar js", completed: true, priority: "high", dueDate: "2026-10-20" }` |
| `task["priority"] = "medium"` | `{ ..., priority: "medium", dueDate: "2026-10-20" }` |
| `delete task.dueDate` | `{ id: 1, title: "belajar js", completed: true, priority: "medium" }` |

**Output akhir:**
```
true
false
{ id: 1, title: 'belajar js', completed: true, priority: 'medium' }
{ id: 2, title: 'baru' }
```

## Analogi
Mengubah property seperti **memperbarui kartu katalog** di perpustakaan. Pustakawan menulis ulang kolom Status ("Belum" → "Dipinjam"), menambah kolom baru "Lokasi Rak" yang dulu tidak ada, dan menghapus kolom yang sudah tidak terpakai. Kartunya tetap satu, hanya isinya yang diperbarui.

## Dipakai untuk Apa
- Menandai task selesai: `task.completed = true`
- Mengedit judul atau prioritas task
- Menambahkan field opsional saat user melengkapi data (misal `task.notes`), dan menghapusnya dengan `delete`
- Mengecek data sebelum dipakai agar tidak error (`"key" in obj`)

## Kesalahan Umum yang Sering Terjadi
- **Mengira `const` membuat object tidak bisa diubah**: `const` hanya mencegah kamu menulis ulang variabelnya (`task = {...}` baru). Isi object tetap boleh diubah, ditambah, dan dihapus. Kalau benar-benar mau mengunci total, ada `Object.freeze()`.
- **Typo bikin property tak sengaja**: Menulis `task.titel = "Baru"` padahal kuncinya `title`. Tidak error — object malah punya dua kunci (`title` lama + `titel` baru), dan kamu bingung kenapa perubahan tidak terlihat. Hindari: selalu `console.log(task)` setelah mengubah untuk memastikan.
- **Langsung menelusuri property yang belum tentu ada**: `task.notes.length` error `TypeError` kalau `notes` belum pernah diisi. Hindari: cek dulu `if ("notes" in task)` baru akses isinya.
- **Salah paham `delete` pada array of objects**: `delete tasks[0]` menghapus elemennya tapi **tidak menutup lubangnya** — `tasks.length` tetap dan elemen itu jadi hole. Untuk menghapus elemen array, gunakan `splice` (materi 12), bukan `delete`.

## Hubungan dengan Materi Sebelumnya
Materi 20 (Object Literal) mengajarkan cara **membuat dan membaca** object — materi ini melanjutkannya ke cara **mengubahnya**. Kombinasi keduanya membuat kamu paham siklus penuh sebuah object. Pengetahuan ini langsung dipakai di Level 3: logika CRUD (materi 22 dan seterusnya) pada dasarnya hanya membuat object baru, membaca property, mengubah property, dan menghapusnya — kali ini dibungkus ke dalam function.

## Soal Latihan & Jawaban
### Soal
Dari object `task` di bawah, simulasi penyelesaian task:
1. Ubah `completed` jadi `true`.
2. Tambah property baru `finishedAt` berisi string `"2026-10-15"`.
3. Hapus property `dueDate`.
4. Tampilkan object hasil akhir, lalu buktikan `dueDate` sudah tidak ada dengan `hasOwnProperty`.

### Jawaban
```js
let task = {
  id: 3,
  title: "testing",
  completed: false,
  priority: "medium",
  dueDate: "2026-10-20"
};

// 1. Ubah nilai property
task.completed = true;

// 2. Tambah property baru
task.finishedAt = "2026-10-15";

// 3. Hapus property
delete task.dueDate;

// 4. Tampilkan hasil akhir
console.log(task);
// Output:
// { id: 3, title: 'testing', completed: true,
//   priority: 'medium', finishedAt: '2026-10-15' }

// 5. Buktikan dueDate sudah hilang
console.log(task.hasOwnProperty("dueDate")); // false
console.log("finishedAt" in task);            // true
```
