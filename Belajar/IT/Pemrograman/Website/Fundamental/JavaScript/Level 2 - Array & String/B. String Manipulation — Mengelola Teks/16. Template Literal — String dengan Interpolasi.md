# Template Literal — String dengan Interpolasi

## Penjelasan
Template literal adalah cara menulis string memakai **backtick** (`` ` ``) alih-alih tanda kutip biasa. Dalam backtick kita bisa menyisipkan nilai langsung di dalam teks memakai `${...}` — penyisipan ini disebut **interpolasi**.

Aturannya:
- Penanda: string dibuka dan ditutup dengan backtick, bukan `"` atau `'`.
- `${ekspresi}` akan **dihitung dulu**, lalu hasilnya disisipkan ke posisi itu (bisa variabel, `tasks.length`, sampai expression seperti ternary).
- Template literal boleh **multi-line**: teks bisa lanjut ke baris berikutnya tanpa perlu `\n`.
- Hasilnya tetap string biasa, hanya penulisannya yang lebih ringkas dan mudah dibaca dibanding menggabungkan banyak string dengan `+` (concatenation).

## Fungsi
Membuat kalimat dari banyak data biasanya bikin kode berantakan: `"Halo " + nama + ", kamu punya " + jumlah + " task."`. Template literal merapikan itu menjadi satu string yang terbaca persis seperti keluarannya, plus mendukung beberapa baris sekaligus — cocok untuk menampilkan laporan atau kartu task.

## Cara Pengimplementasian / Code
```js
const manager = "Task Manager";
const tasks = [
  { id: 1, title: "Belajar JS", completed: false },
  { id: 2, title: "Bikin UI", completed: true },
  { id: 3, title: "Testing", completed: false }
];

// Interpolasi: sisipkan nilai variabel pakai ${}
console.log(`Halo pengguna ${manager}!`);
console.log(`Kamu punya ${tasks.length} tasks.`);
console.log(`Task pertama: "${tasks[0].title}"`);

// Multi-line: satu string bisa membentang beberapa baris
const laporan = `
=== Laporan Task ===
Total : ${tasks.length}
Judul : ${tasks[0].title}
Status: ${tasks[0].completed ? "selesai" : "belum selesai"}
`;
console.log(laporan);

// Cara lama dengan concatenation — hasil sama, tapi lebih mudah salah
console.log("Halo " + manager + ", kamu punya " + tasks.length + " tasks.");
```

Cara menjalankan: simpan kode di atas di dalam tag `<script>` pada file `level2.html`, buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita ikut mengikuti komputer.

**Langkah 1 — deklarasi `manager` dan `tasks`**
`manager` berisi teks `"Task Manager"`, `tasks` berisi 3 object task.

**Langkah 2 — `` `Halo pengguna ${manager}!` ``**
JavaScript melihat `${manager}`, mencari isi variabel `manager` (`"Task Manager"`), lalu menyisipkannya ke posisi itu. Hasil akhirnya string `"Halo pengguna Task Manager!"` → console menampilkan `Halo pengguna Task Manager!`.

**Langkah 3 — `` `Kamu punya ${tasks.length} tasks.` ``**
`${tasks.length}` dihitung dulu: `tasks.length` = `3`. Teks jadi `"Kamu punya 3 tasks."` → console menampilkan `Kamu punya 3 tasks.`.

**Langkah 4 — `` `Task pertama: "${tasks[0].title}"` ``**
`tasks[0].title` membaca judul elemen pertama, yaitu `"Belajar JS"` → console menampilkan `Task pertama: "Belajar JS"`.

**Langkah 5 — konstanta `laporan`**
String dibuka dengan backtick lalu langsung pindah baris, jadi ada baris kosong pertama. `${tasks.length}` jadi `3`, `${tasks[0].title}` jadi `Belajar JS`, dan ternary `${tasks[0].completed ? "selesai" : "belum selesai"}` dihitung: `completed` bernilai `false`, jadi hasilnya `belum selesai`. Variabel `laporan` kini berisi teks multi-line lengkap.

**Langkah 6 — `console.log(laporan);` dan baris concatenation**
`laporan` dicetak apa adanya (termasuk baris kosong di awalnya). Baris terakhir memakai `+` dan menghasilkan teks yang sama dengan langkah 2-3 digabung.

**Output akhir:**
```
Halo pengguna Task Manager!
Kamu punya 3 tasks.
Task pertama: "Belajar JS"

=== Laporan Task ===
Total : 3
Judul : Belajar JS
Status: belum selesai
Halo Task Manager, kamu punya 3 tasks.
```

## Analogi
Template literal seperti **formulir cetak perpustakaan** yang sudah punya teks baku dan slot isian yang kosong. Pustakawan tinggal menulis nama anggota, nomor kartu, dan tanggal pinjam ke slot yang tersedia — teks lainnya tidak perlu diketik ulang. `${...}` adalah slot-slot itu: kamu cukup menyiapkan datanya, dan formulir mengisinya sendiri di tempat yang tepat.

## Dipakai untuk Apa
- Menampilkan ringkasan task: `"Kamu punya 3 tasks, 1 selesai"`.
- Membuat laporan multi-line di console (dan nanti di layar lewat DOM).
- Merangkai pesan error/status yang berisi data dinamis.
- Membentuk HTML string berisi data sebelum ditampilkan (nanti di materi DOM).

## Kesalahan Umum yang Sering Terjadi
- **Pakai kutip biasa tapi tetap menulis `${}`**: `"Halo ${nama}"` menampilkan teks literal `Halo ${nama}` — JavaScript tidak pernah menghitung isinya. Wajib pakai backtick.
- **Backtick tidak ditutup atau tercampur kutip**: Satu backtick yang hilang menghasilkan `SyntaxError` dan seluruh script tidak jalan. Kalau ada tanda kutip di dalam teks, biarkan saja — backtick menerima kutip `"` dan `'` tanpa perlu escape.
- **Teks berisi backtick**: Kalau teksnya sendiri memuat `` ` ``, tutup dengan `\`` supaya tidak dianggap penutup string.
- **Menumpuk expression rumit di `${}`**: Ternary bersarang di dalam `${}` bikin baris sulit dibaca dan gampang salah kurung. Simpan hasilnya dulu ke variabel, baru sisipkan variabelnya.

## Soal Latihan & Jawaban
### Soal
Buat kartu task memakai template literal multi-line dari data berikut: `id: 1`, `title: "Belajar JS"`, `completed: false`, dan `manager = "Task Manager"`. Kartu harus menampilkan judul, status (`"selesai"` kalau `completed === true`, kalau tidak `"belum selesai"`), dan baris penutup berisi jumlah task dari `tasks` yang berisi 3 task. Tanpa concatenation `+`.

### Jawaban
```js
const manager = "Task Manager";
const tasks = [
  { id: 1, title: "Belajar JS", completed: false },
  { id: 2, title: "Bikin UI", completed: true },
  { id: 3, title: "Testing", completed: false }
];
const task = tasks[0];

// Kartu task memakai template literal multi-line
const kartu = `
--- Kartu Task ---
#${task.id}: ${task.title}
Status : ${task.completed ? "selesai" : "belum selesai"}
Aplikasi: ${manager}
Total task: ${tasks.length}
`;
console.log(kartu);
```
