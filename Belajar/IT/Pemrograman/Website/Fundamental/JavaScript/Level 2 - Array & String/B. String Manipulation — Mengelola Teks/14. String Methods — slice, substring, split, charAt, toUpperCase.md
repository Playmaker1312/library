# String Methods — slice, substring, split, charAt, toUpperCase

## Penjelasan
String adalah teks yang tersusun dari karakter demi karakter, jadi tiap karakter punya **index** mulai dari `0`. String methods adalah function bawaan untuk memotong, mengambil, dan memecah teks:

- `slice(start, end)` — potong string dari index `start` sampai **sebelum** index `end`.
- `substring(start, end)` — mirip `slice`, alternatif lama yang jarang dipakai.
- `charAt(index)` — ambil satu karakter di index tertentu.
- `split(pemisah)` — pecah string menjadi **array** (misal `"a b".split(" ")` → `["a", "b"]`).
- `toUpperCase()` / `toLowerCase()` — ubah semua huruf jadi kapital / kecil.
- `trim()` — buang spasi di awal dan akhir.

Penting: semua method di atas **tidak mengubah string asli**. Mereka menghasilkan string baru, jadi hasilnya harus disimpan ke variabel.

## Fungsi
Input dari user sering berantakan: ada spasi kebanyakan, huruf kecil semua, atau teks yang harus dipecah dulu sebelum diproses. Dengan string methods kita bisa membersihkan input, memformat judul task, dan mengubah teks jadi array kata — semuanya tanpa menulis logika memotong manual per huruf.

## Cara Pengimplementasian / Code
```js
const taskInput = "  Belajar JavaScript  ";

// trim: buang spasi di awal dan akhir
console.log(taskInput.trim()); // "Belajar JavaScript"

// toUpperCase: semua huruf jadi kapital
console.log(taskInput.toUpperCase()); // "  BELAJAR JAVASCRIPT  "

// slice(2, 8): potong mulai index 2 sampai sebelum index 8
console.log(taskInput.slice(2, 8)); // "Belaj"

// charAt: ambil satu karakter di posisi tertentu
console.log(taskInput.trim().charAt(0)); // "B"

// split: pecah teks menjadi array kata
const judul = "Belajar JS untuk Task Manager";
const kata = judul.split(" ");
console.log(kata);        // ["Belajar", "JS", "untuk", "Task Manager"]
console.log(kata.length); // 4
```

Cara menjalankan: simpan kode di atas di dalam tag `<script>` pada file `level2.html`, buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita ikut mengikuti komputer.

**Langkah 1 — `const taskInput = "  Belajar JavaScript  ";`**
Variabel `taskInput` berisi teks dengan 2 spasi di awal, kata `Belajar JavaScript`, dan 2 spasi di akhir.

**Langkah 2 — `console.log(taskInput.trim());`**
`trim()` membuang spasi di awal dan akhir, menghasilkan string baru `"Belajar JavaScript"`. Karena langsung dibungkus `console.log`, teks itu tampil tanpa spasi. Isi `taskInput` sendiri tidak berubah.

**Langkah 3 — `console.log(taskInput.toUpperCase());`**
Semua huruf dijadikan kapital, spasi tetap ada → console menampilkan `  BELAJAR JAVASCRIPT  `.

**Langkah 4 — `console.log(taskInput.slice(2, 8));`**
Menghitung index: `0` = spasi, `1` = spasi, `2` = `B`, `3` = `e`, `4` = `l`, `5` = `a`, `6` = `j`, `7` = `a`. `slice` mengambil index `2` sampai sebelum `8`, jadi hanya `2-7` → `Belaj`.

**Langkah 5 — `console.log(taskInput.trim().charAt(0));`**
`trim()` menghasilkan `"Belajar JavaScript"`, lalu `charAt(0)` mengambil karakter pertama → `B`.

**Langkah 6 — `const judul = "Belajar JS untuk Task Manager";` dan `judul.split(" ")`**
`split(" ")` memotong teks setiap ketemu spasi. `judul` berubah jadi array 4 kata: `["Belajar", "JS", "untuk", "Task Manager"]` → disimpan di variabel `kata`. Karena `kata` berisi 4 elemen, `kata.length` = `4`.

**Output akhir:**
```
Belajar JavaScript
  BELAJAR JAVASCRIPT  
Belaj
B
[ "Belajar", "JS", "untuk", "Task Manager" ]
4
```

## Analogi
Pustakawan yang mengelola kartu katalog: `slice` dan `charAt` seperti memotong label teks untuk mengambil sebagian nama, `toUpperCase` seperti menulis ulang label dengan huruf kapital semua, dan `trim` seperti menghapus tinta spasi yang tidak perlu di pinggir kartu. Sedangkan `split` ibarat mengambil satu label berisi nama lengkap `"Andi Programmer"` lalu memecahnya jadi dua kartu kata terpisah sesuai tanda spasi.

## Dipakai untuk Apa
- Membersihkan input judul task dari spasi kebanyakan (`trim`).
- Memformat teks agar rapi di layar (`toUpperCase`).
- Mengambil inisial nama anggota dari string nama (`slice`/`charAt`).
- Memecah kalimat deskripsi atau daftar jadi array kata (`split`).

## Kesalahan Umum yang Sering Terjadi
- **Mengira index akhir `slice` ikut terpotong**: `slice(2, 8)` menghasilkan 6 karakter (`8 - 2`), bukan 8 karakter. Akibatnya kehilangan satu karakter terakhir. Hitung selalu `end - start`.
- **Lupa `trim` saat membandingkan input**: `" Belajar "` tidak sama dengan `"Belajar"`, jadi pencarian atau validasi gagal padahal kelihatannya benar. Trim input dulu sebelum dibandingkan.
- **Lupa menyimpan hasil method ke variabel**: `taskInput.trim()` tidak mengubah `taskInput`; kalau hasilnya tidak disimpan, teks yang sudah bersih hilang begitu saja. String di JavaScript tidak bisa diubah, jadi tulis `const bersih = taskInput.trim();`.
- **Salah pemisah di `split`**: `judul.split("")` (tanpa spasi) memecah per huruf, bukan per kata. Untuk per kata pakai `judul.split(" ")`.

## Soal Latihan & Jawaban
### Soal
User mengetik judul task dengan spasi kebanyakan: `const input = "  Bikin Form Login  ";`
1. Bersihkan spasi awal/akhir dengan `trim`.
2. Ambil 4 karakter pertama dari hasil bersih dengan `slice`.
3. Ambil karakter pertama lalu ubah jadi kapital dengan `charAt` + `toUpperCase`.
4. Pecah judul yang sudah bersih menjadi array kata dengan `split(" ")`, lalu tampilkan jumlah katanya.

### Jawaban
```js
const input = "  Bikin Form Login  ";

const bersih = input.trim();                       // 1. "Bikin Form Login"
console.log(bersih);

console.log(bersih.slice(0, 4));                   // 2. "Biki"

const hurufPertama = bersih.charAt(0).toUpperCase(); // 3. "B"
console.log(hurufPertama);

const kata = bersih.split(" ");                    // 4. pecah jadi array
console.log(kata);                                 // ["Bikin", "Form", "Login"]
console.log(kata.length);                          // 3
```
