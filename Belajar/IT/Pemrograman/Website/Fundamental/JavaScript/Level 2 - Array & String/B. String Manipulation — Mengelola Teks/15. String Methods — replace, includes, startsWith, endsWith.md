# String Methods — replace, includes, startsWith, endsWith

## Penjelasan
Kelompok string methods ini fokus pada **mencari dan mengganti** potongan teks:

- `replace(cari, ganti)` — ganti substring **pertama** yang cocok dengan teks baru.
- `replaceAll(cari, ganti)` — ganti **semua** kemunculan (fitur JavaScript modern).
- `includes(substring)` — cek apakah teks mengandung substring → hasil `true`/`false`.
- `startsWith(str)` / `endsWith(str)` — cek apakah teks diawali / diakhiri oleh `str`.
- `indexOf(substring)` — kembalikan **posisi** substring pertama, atau `-1` kalau tidak ada.

Sifat yang perlu diingat:
- Semua method ini **menghasilkan nilai baru**, tidak mengubah string asli.
- Pencocokan bersifat **case-sensitive** (huruf besar dan kecil dianggap beda): `"JS"` tidak cocok dengan `"js"`.
- `includes` menjawab "ada atau tidak", `indexOf` menjawab "di mana posisinya".

## Fungsi
Banyak fitur aplikasi berdiri di atas pencocokan teks: cek apakah judul task mengandung kata kunci, menandai deskripsi yang masih berstatus TODO, memvalidasi format input, atau memformat teks sebelum ditampilkan. Tanpa methods ini, kita harus memeriksa teks satu huruf demi satu huruf secara manual.

## Cara Pengimplementasian / Code
```js
let desc = "Belajar JavaScript di JavaScript";

// replace: ganti substring PERTAMA yang cocok saja
console.log(desc.replace("JavaScript", "JS")); // "Belajar JS di JavaScript"

// replaceAll: ganti semua kemunculan
console.log(desc.replaceAll("JavaScript", "JS")); // "Belajar JS di JS"

// includes: cek ada atau tidaknya substring
console.log(desc.includes("Belajar")); // true
console.log(desc.includes("Python"));  // false

// startsWith / endsWith: cek bagian awal dan akhir teks
const manager = "Task Manager";
console.log(manager.startsWith("Task"));    // true
console.log(manager.endsWith("Manager"));   // true

// indexOf: posisi substring pertama, -1 kalau tidak ketemu
console.log(desc.indexOf("JavaScript")); // 8
```

Cara menjalankan: simpan kode di atas di dalam tag `<script>` pada file `level2.html`, buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita ikut mengikuti komputer.

**Langkah 1 — `let desc = "Belajar JavaScript di JavaScript";`**
Variabel `desc` berisi 29 karakter. Kata `JavaScript` muncul dua kali: pertama di posisi `8`, kedua setelah kata `di`.

**Langkah 2 — `desc.replace("JavaScript", "JS");`**
JavaScript mencari kemunculan pertama `JavaScript` (posisi `8`) dan menggantinya jadi `JS`. Kemunculan kedua dibiarkan → console menampilkan `Belajar JS di JavaScript`. Isi `desc` sendiri tidak berubah.

**Langkah 3 — `desc.replaceAll("JavaScript", "JS");`**
Kali ini semua kemunculan diganti → console menampilkan `Belajar JS di JS`.

**Langkah 4 — `desc.includes("Belajar")` dan `desc.includes("Python")`**
`"Belajar"` ada di awal teks → `true`. `"Python"` tidak muncul sama sekali → `false`.

**Langkah 5 — `manager.startsWith("Task")` dan `manager.endsWith("Manager")`**
`manager` = `"Task Manager"`. Tiga karakter pertamanya adalah `Task` → `true`. Tiga karakter terakhir adalah `Manager` → `true`.

**Langkah 6 — `desc.indexOf("JavaScript")`**
Menghitung dari posisi `0`: `B`(0) `e`(1) `l`(2) `a`(3) `j`(4) `a`(5) `r`(6) spasi(7), lalu `J`(8). Jadi posisinya `8` → console menampilkan `8`.

**Output akhir:**
```
Belajar JS di JavaScript
Belajar JS di JS
true
false
true
true
8
```

## Analogi
Di kartu katalog perpustakaan, `replace` seperti pustakawan menempel stiker koreksi di atas teks lama — stiker pertama tertempel, tapi teks kedua yang sama masih tertulis di bawahnya. Kalau pakai `replaceAll`, semua teks lama ikut tertempel stikernya. `includes` adalah pustakawan memastikan rak ini benar mengandung kata kunci tertentu, sedangkan `startsWith`/`endsWith` memeriksa kode rak seperti `A-03-1` — diawali `A` dan diakhiri `1`.

## Dipakai untuk Apa
- Mencari task berdasarkan kata kunci judul (`includes` + `indexOf`).
- Mengubah status teks deskripsi, misalnya semua `TODO` jadi `Selesai`.
- Validasi format input, misal email harus `startsWith("@")` domain tertentu.
- Mengecek akhiran file/URL, misal alamat diakhiri `.html`.

## Kesalahan Umum yang Sering Terjadi
- **Mengira `replace` mengganti semua**: `replace` hanya menyentuh kemunculan pertama → sisa teks lama masih ada tanpa error apa pun. Kalau mau semua, pakai `replaceAll` (atau regex dengan flag `g`).
- **Lupa sifat case-sensitive**: `desc.replace("javascript", "JS")` menghasilkan string asli karena `javascript` (kecil) tidak cocok dengan `JavaScript` (kapital). Method ini diam-diam tidak mengganti apa pun — cek ejaannya persis atau rapikan dulu dengan `toLowerCase()`.
- **Salah pakai `startsWith` untuk mencari posisi**: `startsWith` selalu memeriksa dari **awal** teks saja. Kalau kamu butuh tahu letak substring di tengah, pakai `indexOf` (dan ingat hasil `-1` berarti tidak ketemu).
- **Lupa hasilnya harus disimpan**: `desc.replace(...)` tidak mengubah `desc`. Kalau hasil gantian tidak ditampung di variabel baru, perubahannya seolah tidak pernah terjadi.

## Soal Latihan & Jawaban
### Soal
Deskripsi sebuah task berisi `const desc = "TODO: bikin form, TODO: bikin test";`. Dengan string methods:
1. Tampilkan versi di mana **semua** `TODO` sudah diganti menjadi `Selesai`.
2. Cek apakah deskripsi mengandung kata `bikin`.
3. Cek apakah deskripsi diawali `TODO`.
4. Tampilkan posisi pertama kata `form` dengan `indexOf`.

### Jawaban
```js
const desc = "TODO: bikin form, TODO: bikin test";

// 1. ganti semua kemunculan TODO
console.log(desc.replaceAll("TODO", "Selesai"));

// 2. cek keberadaan kata
console.log(desc.includes("bikin"));    // true

// 3. cek awalan teks
console.log(desc.startsWith("TODO"));   // true

// 4. posisi kata "form"
console.log(desc.indexOf("form"));      // 12
```
