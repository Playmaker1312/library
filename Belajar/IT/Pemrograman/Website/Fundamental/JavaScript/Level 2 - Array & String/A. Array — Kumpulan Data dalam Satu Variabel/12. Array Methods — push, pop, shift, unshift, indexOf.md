# Array Methods — push, pop, shift, unshift, indexOf

## Penjelasan
Array methods adalah function bawaan array yang sudah disediakan JavaScript, jadi kita tidak perlu menulis logika menambah atau menghapus dari nol. Dari sisi efeknya, methods ini terbagi dua kelompok:

- **Mutating** (mengubah isi array asli): `push(elemen)` menambah di akhir, `pop()` menghapus dari akhir, `unshift(elemen)` menambah di awal, `shift()` menghapus dari awal.
- **Pencarian** (tidak mengubah isi array): `indexOf(elemen)` mengembalikan posisi elemen, `includes(elemen)` mengembalikan `true`/`false`.

Cara menghafal pasangannya:
- `push`/`pop` bekerja di **ujung kanan** (belakang) array.
- `shift`/`unshift` bekerja di **ujung kiri** (depan) array.
- `push` dan `unshift` = **menambah**, `pop` dan `shift` = **menghapus**.
- Kalau elemen tidak ditemukan, `indexOf` mengembalikan `-1`.

## Fungsi
Aplikasi Task Manager pasti berubah isi daftarnya: user menambah task baru, menghapus task yang keliru, atau menyisipkan task mendesak di urutan paling atas. Tanpa methods, kita harus menggeser isi array manual satu per satu — ribet dan rawan salah.

## Cara Pengimplementasian / Code
```js
const tasks = [
  { id: 1, title: "Belajar JS", completed: false },
  { id: 2, title: "Bikin UI", completed: true }
];

// taskInput = data baru dari form; untuk latihan kita buat manual
const taskInput = { id: 3, title: "Testing", completed: false };

// push: tambah elemen di akhir — array asli ikut berubah
tasks.push(taskInput);
console.log(tasks.length);          // 3

// pop: hapus elemen terakhir dan KEMBALIKAN elemen yang dihapus
const terakhir = tasks.pop();
console.log(terakhir.title);        // "Testing"
console.log(tasks.length);          // 2

// unshift: tambah elemen di awal array
tasks.unshift({ id: 0, title: "Baca Aturan", completed: true });
console.log(tasks[0].title);        // "Baca Aturan"

// shift: hapus elemen di awal array
const awal = tasks.shift();
console.log(awal.title);            // "Baca Aturan"
console.log(tasks[0].title);        // "Belajar JS"

// indexOf: cari posisi elemen; -1 berarti tidak ketemu
const kategori = ["kerja", "pribadi", "kuliah"];
console.log(kategori.indexOf("pribadi")); // 1
console.log(kategori.indexOf("liburan")); // -1

// includes: cek ada atau tidaknya elemen
console.log(kategori.includes("kuliah")); // true
```

Cara menjalankan: simpan kode di atas di dalam tag `<script>` pada file `level2.html`, buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita ikut mengikuti komputer.

**Langkah 1 — deklarasi `tasks` dan `taskInput`**
`tasks` berisi 2 elemen (judul `"Belajar JS"` dan `"Bikin UI"`), sedangkan `taskInput` berisi 1 object task `"Testing"`.

**Langkah 2 — `tasks.push(taskInput);`**
Object `taskInput` dimasukkan ke ujung kanan `tasks`. Isi `tasks` jadi 3 elemen dan `tasks.length` berubah dari `2` menjadi `3` → console menampilkan `3`.

**Langkah 3 — `const terakhir = tasks.pop();`**
JavaScript mengambil elemen terakhir (`"Testing"`) keluar dari array, lalu menyimpannya di variabel `terakhir`. Isi `tasks` tinggal 2 elemen. Console menampilkan `Testing` (dari `terakhir.title`), lalu `2` (dari `tasks.length`).

**Langkah 4 — `tasks.unshift({...})`**
Object `"Baca Aturan"` masuk lewat ujung kiri. Urutan `tasks` sekarang: `"Baca Aturan"`, `"Belajar JS"`, `"Bikin UI"` → console menampilkan `Baca Aturan`.

**Langkah 5 — `const awal = tasks.shift();`**
Elemen paling kiri (`"Baca Aturan"`) dikeluarkan dan disimpan di variabel `awal`. Urutan `tasks` kembali jadi `"Belajar JS"`, `"Bikin UI"`. Console menampilkan `Baca Aturan` (isi `awal.title`), lalu `Belajar JS` (isi `tasks[0].title`).

**Langkah 6 — `indexOf` dan `includes` pada `kategori`**
`"pribadi"` ada di posisi `1` → console menampilkan `1`. `"liburan"` tidak ada sama sekali → console menampilkan `-1`. `"kuliah"` ada di array → `includes` menghasilkan `true`.

| Operasi | Yang dikembalikan | Isi `tasks` setelah operasi (judul) |
|---|---|---|
| `push(taskInput)` | panjang baru: `3` | `["Belajar JS", "Bikin UI", "Testing"]` |
| `pop()` | elemen `"Testing"` | `["Belajar JS", "Bikin UI"]` |
| `unshift(...)` | panjang baru: `3` | `["Baca Aturan", "Belajar JS", "Bikin UI"]` |
| `shift()` | elemen `"Baca Aturan"` | `["Belajar JS", "Bikin UI"]` |

**Output akhir:**
```
3
Testing
2
Baca Aturan
Belajar JS
1
-1
true
```

## Analogi
Di perpustakaan, `push` seperti pustakawan menaruh buku baru di **ujung kanan** rak, sedangkan `pop` mengambil buku dari ujung kanan itu. `unshift` dan `shift` melakukan hal yang sama, tapi di **ujung kiri** rak. Sementara `indexOf` ibarat pustakawan membuka kartu katalog untuk mencari nomor slot buku — kalau bukunya tidak ada, di kartu tertulis `-1` (tidak ditemukan).

## Dipakai untuk Apa
- Tombol **Tambah Task** → `push` task baru dari input.
- Tombol **Hapus Task Terakhir** → `pop`.
- Menyisipkan task mendesak di urutan paling atas → `unshift`.
- Cek duplikat judul atau cari posisi kategori → `indexOf` / `includes`.

## Kesalahan Umum yang Sering Terjadi
- **Lupa bahwa mutating method mengubah array asli**: Setelah `pop()`, elemen benar-benar hilang dari `tasks`. Kalau tidak sadar, data "lenyap" tanpa sebab. Menghindari: simpan dulu salinan (`[...tasks]`) kalau array asli harus tetap aman.
- **Langsung pakai hasil `indexOf` tanpa cek `-1`**: `kategori[kategori.indexOf("liburan")]` menghasilkan `undefined` karena `-1` bukan index valid. Selalu cek `if (posisi !== -1)` dulu.
- **Salah arah `shift` vs `unshift`**: `shift` itu **menghapus** dari awal, bukan menambah — dua ini sering ketuker. Ingat pasangannya: kanan `push`/`pop`, kiri `shift`/`unshift`.
- **`indexOf` pada array of object selalu `-1`**: Membandingkan object harus object yang sama persis, bukan object baru yang isinya mirip. Untuk mencari task berdasarkan property, lanjut ke materi **19. Array.find() & findIndex() — Cari Elemen Pertama**.

## Soal Latihan & Jawaban
### Soal
Form task baru menghasilkan `const taskInput = { id: 3, title: "Deploy", completed: false };`. Dari `tasks` yang berisi task "Belajar JS" dan "Bikin UI":
1. Tambahkan `taskInput` ke akhir array dengan `push`.
2. Hapus task paling awal dengan `shift`.
3. Tampilkan dua judul task yang tersisa beserta jumlahnya.
4. Buat `const kategori = ["kerja", "pribadi", "kuliah"];`, tampilkan index `"pribadi"` dan cek apakah `"kampus"` ada di dalamnya.

### Jawaban
```js
const tasks = [
  { id: 1, title: "Belajar JS", completed: false },
  { id: 2, title: "Bikin UI", completed: true }
];
const taskInput = { id: 3, title: "Deploy", completed: false };

tasks.push(taskInput);              // 1. tambah task baru di akhir
const pertama = tasks.shift();      // 2. hapus task paling awal
console.log("Dihapus:", pertama.title);

console.log("Sisa:", tasks[0].title, "|", tasks[1].title); // 3. dua judul tersisa
console.log("Jumlah:", tasks.length);

const kategori = ["kerja", "pribadi", "kuliah"];
console.log("Index:", kategori.indexOf("pribadi")); // 1
console.log("Ada?", kategori.includes("kampus"));   // false
```
