# Looping Array dengan for & forEach

## Penjelasan
Looping array adalah cara menyusuri semua elemen array satu per satu tanpa menulis kode yang sama berulang-ulang. Ada dua cara utama di JavaScript:

- **`for` biasa**: kita atur sendiri index-nya (`i`), dari `0` sampai `tasks.length - 1`. Cocok kalau butuh kendali penuh, misalnya berhenti di tengah.
- **`forEach`**: method array yang menjalankan **callback** untuk tiap elemen secara otomatis. **Callback** adalah function kecil yang dikirim ke method lain, lalu dipanggil sendiri oleh method itu.

Callback `forEach` menerima dua parameter, urutannya `(elemen, index)`:
- `elemen` = isi array di putaran itu (misalnya satu object task).
- `index` = posisi elemen tersebut (mulai dari `0`).

Keduanya menghasilkan urutan yang sama; bedanya hanya siapa yang mengatur putarannya.

## Fungsi
Kalau aplikasi punya 50 task, menampilkan judulnya satu per satu dengan `console.log` manual berarti 50 baris kode yang hampir sama. Looping membuatnya jadi 3 baris: isi array bisa bertambah atau berkurang, kode tampilan tetap berjalan benar tanpa perlu diubah.

## Cara Pengimplementasian / Code
```js
const tasks = [
  { id: 1, title: "Belajar JS", completed: false },
  { id: 2, title: "Bikin UI", completed: true },
  { id: 3, title: "Testing", completed: false }
];

// Cara 1: for loop — kita atur sendiri index-nya
for (let i = 0; i < tasks.length; i++) {
  console.log(i + 1 + ". " + tasks[i].title);
}

// Cara 2: forEach — jalankan callback untuk tiap elemen otomatis
tasks.forEach((task, index) => {
  console.log("Task ke-" + index + ": " + task.title);
});
```

Cara menjalankan: simpan kode di atas di dalam tag `<script>` pada file `level2.html`, buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita ikut mengikuti komputer.

**Langkah 1 — deklarasi `tasks`**
JavaScript membuat array `tasks` berisi 3 object: `"Belajar JS"`, `"Bikin UI"`, `"Testing"`.

**Langkah 2 — `for (let i = 0; i < tasks.length; i++)` mulai jalan**
JavaScript membuat variabel `i` berisi `0`, lalu bertanya "apakah `0 < 3`?" Karena benar, ia masuk ke dalam blok dan mencetak `1. Belajar JS`.

**Langkah 3 — kembali ke `for`**
`i++` menambah `i` jadi `1`. Ditanya lagi: "apakah `1 < 3`?" Benar → mencetak `2. Bikin UI`. Proses ini berulang sampai kondisinya salah.

| Putaran | Nilai `i` | `i < tasks.length`? | Output |
|---|---|---|---|
| 1 | 0 | ya (0 < 3) | `1. Belajar JS` |
| 2 | 1 | ya (1 < 3) | `2. Bikin UI` |
| 3 | 2 | ya (2 < 3) | `3. Testing` |
| — | 3 | tidak (3 < 3) | loop berhenti |

**Langkah 4 — `tasks.forEach((task, index) => {...})` mulai jalan**
JavaScript mengambil elemen pertama, lalu memanggil callback dengan `task` = object task itu dan `index` = `0`. Isi callback dijalankan, lalu JavaScript lanjut ke elemen berikutnya tanpa kita mengatur index.

| Putaran | `index` | `task.title` | Output |
|---|---|---|---|
| 1 | 0 | `Belajar JS` | `Task ke-0: Belajar JS` |
| 2 | 1 | `Bikin UI` | `Task ke-1: Bikin UI` |
| 3 | 2 | `Testing` | `Task ke-2: Testing` |

**Langkah 5 — tidak ada kode lagi**
Kedua loop selesai, JavaScript berhenti menjalankan script.

**Output akhir:**
```
1. Belajar JS
2. Bikin UI
3. Testing
Task ke-0: Belajar JS
Task ke-1: Bikin UI
Task ke-2: Testing
```

## Analogi
Pustakawan yang menyusuri rak buku dari slot pertama sampai slot terakhir sambil mencatat judulnya di buku log — itu `for` loop: pustakawan menghitung nomor slotnya sendiri. Untuk `forEach`, pustakawan cukup menugaskan asisten: "setiap buku yang kamu pegang, begitu diambil, tulis judulnya." Asisten tidak perlu tahu nomor slot, yang penting rak disusuri dari awal sampai akhir tanpa ada yang terlewat.

## Dipakai untuk Apa
- Menampilkan seluruh daftar task di console (dan nanti di layar).
- Menghitung total task yang selesai atau belum selesai.
- Menampilkan daftar buku pinjaman anggota perpustakaan satu per satu.
- Menjalankan aksi yang sama untuk tiap data, misalnya menambah label `[!]` ke task mendesak.

## Kesalahan Umum yang Sering Terjadi
- **Kondisi loop pakai `<=`**: `i <= tasks.length` membuat putaran terakhir membuka index `tasks[3]` yang `undefined` → output "undefined" muncul di akhir daftar. Pakai `i < tasks.length`.
- **Urutan parameter callback tertukar**: callback `forEach` selalu mengirim `(elemen, index)`. Kalau ditulis `(index, task)`, maka `index` berisi object dan `task` berisi angka → output kacau tanpa error. Menghindari: cek lagi urutan parameter saat menulis arrow function.
- **Pakai `break`/`continue` di dalam `forEach`**: langsung error `Illegal break statement`. `forEach` memang tidak bisa dihentikan; kalau butuh `break`, pakai `for` biasa, dan kalau hanya mau melewati satu elemen, pakai `return` di dalam callback.
- **Menambah/menghapus elemen saat array sedang di-loop**: panjang array berubah di tengah jalan sehingga ada elemen yang terlewat atau terbaca dua kali. Sebaiknya ubah array dulu (materi 12), baru loop hasil akhirnya.

## Soal Latihan & Jawaban
### Soal
Di Task Manager, tampilkan semua task lengkap dengan statusnya memakai `for`, dalam format `"<judul> — selesai/belum"`. Setelah itu, hitung berapa task yang sudah `completed === true` memakai `forEach`, lalu tampilkan hasil hitungannya.

### Jawaban
```js
const tasks = [
  { id: 1, title: "Belajar JS", completed: false },
  { id: 2, title: "Bikin UI", completed: true },
  { id: 3, title: "Testing", completed: true }
];

// Menampilkan semua task dengan for
for (let i = 0; i < tasks.length; i++) {
  const status = tasks[i].completed ? "selesai" : "belum";
  console.log(tasks[i].title + " — " + status);
}

// Menghitung task yang selesai dengan forEach
let jumlahSelesai = 0;
tasks.forEach((task) => {
  if (task.completed) {
    jumlahSelesai = jumlahSelesai + 1;
  }
});
console.log("Task selesai:", jumlahSelesai); // 2
```
