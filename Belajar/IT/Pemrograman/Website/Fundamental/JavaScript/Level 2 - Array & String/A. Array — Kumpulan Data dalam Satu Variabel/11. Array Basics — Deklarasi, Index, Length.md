# Array Basics — Deklarasi, Index, Length

## Penjelasan
Array adalah wadah yang menampung banyak nilai sekaligus dalam satu variabel, dan semua nilainya tersusun berurutan. Setiap isi di dalam array disebut **elemen**.

Aturan dasarnya:
- Deklarasi kosong: `let tasks = [];` — wadah kosong yang siap diisi.
- Deklarasi langsung berisi: `let tasks = ["Belajar JS", "Bikin UI"];`
- Setiap elemen punya **index** (posisi) yang dimulai dari **0**, bukan 1.
- Jumlah elemen dibaca lewat properti `length`, misalnya `tasks.length`.
- Elemen terakhir selalu berada di index `tasks.length - 1`.
- Index di luar jangkauan tidak bikin error, hasilnya cuma `undefined`.

Array boleh diisi tipe data campuran, tapi di aplikasi Task Manager kita isi dengan **object** berbentuk `{id, title, completed}` supaya tiap task punya identitas lengkap.

## Fungsi
Tanpa array, menyimpan 100 task berarti membuat 100 variabel terpisah (`task1`, `task2`, ...) yang mustahil dikelola. Array memecahkan masalah itu: semua task tinggal disimpan di satu variabel `tasks`, urut, dan siap diproses otomatis — dicari, diubah, lalu ditampilkan satu per satu.

## Cara Pengimplementasian / Code
```js
// Semua task disimpan dalam satu array
const tasks = [
  { id: 1, title: "Belajar JS", completed: false },
  { id: 2, title: "Bikin UI", completed: true },
  { id: 3, title: "Testing", completed: false }
];

// Akses elemen pertama — index-nya 0
console.log(tasks[0].title);                 // "Belajar JS"

// Status milik elemen kedua
console.log(tasks[1].completed);             // true

// length = jumlah elemen di dalam array
console.log(tasks.length);                   // 3

// Elemen terakhir selalu pakai length - 1
console.log(tasks[tasks.length - 1].title);  // "Testing"

// Mengubah isi elemen — jumlahnya tidak berubah
tasks[1].completed = false;
console.log(tasks[1].completed);             // false

// Array kosong sebagai wadah task berikutnya
const tasksBaru = [];
console.log(tasksBaru.length);               // 0
```

Cara menjalankan: simpan kode di atas di dalam tag `<script>` pada file `level2.html`, buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita ikut mengikuti komputer.

**Langkah 1 — baris `const tasks = [...]`**
JavaScript membuat wadah bernama `tasks` berisi 3 elemen. Isinya: `tasks[0]` = `{id: 1, title: "Belajar JS", completed: false}`, `tasks[1]` = `{id: 2, title: "Bikin UI", completed: true}`, `tasks[2]` = `{id: 3, title: "Testing", completed: false}`.

**Langkah 2 — `console.log(tasks[0].title);`**
JavaScript membuka elemen di index `0`, lalu membaca property `title`-nya. Isinya `"Belajar JS"`, jadi console menampilkan `Belajar JS`.

**Langkah 3 — `console.log(tasks[1].completed);`**
Elemen di index `1` property `completed`-nya bernilai `true`, jadi console menampilkan `true`.

**Langkah 4 — `console.log(tasks.length);`**
`length` menghitung isi array: ada 3 elemen, jadi console menampilkan `3`.

**Langkah 5 — `console.log(tasks[tasks.length - 1].title);`**
`tasks.length` = 3, jadi index yang dibuka = `3 - 1` = `2`. Elemen terakhir judulnya `"Testing"` → console menampilkan `Testing`.

**Langkah 6 — `tasks[1].completed = false;`**
Property `completed` di elemen index 1 diubah dari `true` menjadi `false`. Jumlah elemen tetap 3.

**Langkah 7 — `console.log(tasks[1].completed);`**
Nilai barunya `false`, jadi console menampilkan `false`.

**Langkah 8 — dua baris terakhir**
`tasksBaru` dibuat dalam keadaan kosong, jadi `tasksBaru.length` = `0` → console menampilkan `0`.

**Output akhir:**
```
Belajar JS
true
3
Testing
false
0
```

## Analogi
Array itu seperti **satu rak buku** di perpustakaan yang dibagi jadi slot-slot berurutan. Satu rak = satu variabel `tasks`, dan satu buku = satu elemen. Pustakawan (JavaScript) menghitung slot mulai dari **0**, jadi buku pertama ada di slot 0 dan buku terakhir ada di slot `jumlahSlot - 1`. Kalau kamu minta buku di slot yang tidak ada (misalnya slot 99 di rak berisi 3 buku), raknya memang kosong — pustakawan hanya menjawab `undefined`, bukan marah.

## Dipakai untuk Apa
- Menyimpan seluruh task dalam aplikasi Task Manager.
- Mencatat daftar buku yang sedang dipinjam anggota perpustakaan.
- Menampung riwayat pencarian atau daftar kategori.
- Menjadi wadah hasil pencarian sebelum ditampilkan (lanjutan di materi 18).

## Kesalahan Umum yang Sering Terjadi
- **Menghitung index mulai dari 1**: Menulis `tasks[3]` padahal array berisi 3 elemen → hasilnya `undefined`, bukan task ketiga. Ingat: index = `0` sampai `length - 1`.
- **Langsung membaca property elemen yang tidak ada**: `tasks[5].title` memunculkan error `TypeError` karena `tasks[5]` bernilai `undefined` → program berhenti. Selalu cek `tasks.length` dulu sebelum mengakses.
- **Hardcode index elemen terakhir**: Menulis `tasks[2]` untuk "elemen terakhir" → begitu ada task baru, posisinya sudah tidak terakhir. Pakai `tasks[tasks.length - 1]`.
- **Mengubah `length` untuk menghapus data**: `tasks.length = 1` benar-benar memotong dan **menghapus** elemen index 1 ke atas. Untuk menghapus gunakan `pop()`/`shift()` (materi 12).

## Soal Latihan & Jawaban
### Soal
Task Manager baru menerima 3 task dari pengguna. Buat array `tasks` berisi 3 object `{id, title, completed}` dengan id 1 sampai 3, judul bebas, semuanya `completed: false`. Lalu:
1. Tampilkan judul task pertama.
2. Tampilkan jumlah seluruh task.
3. Tampilkan judul task terakhir memakai `tasks.length - 1`.
4. Tandai task kedua sebagai selesai (`completed: true`), lalu tampilkan status barunya.

### Jawaban
```js
const tasks = [
  { id: 1, title: "Belajar Array", completed: false },
  { id: 2, title: "Bikin Form", completed: false },
  { id: 3, title: "Tes Aplikasi", completed: false }
];

console.log(tasks[0].title);                 // 1. judul task pertama
console.log(tasks.length);                   // 2. jumlah task
console.log(tasks[tasks.length - 1].title);  // 3. judul task terakhir

tasks[1].completed = true;                   // 4. task kedua ditandai selesai
console.log(tasks[1].completed);             // status terbaru
```
