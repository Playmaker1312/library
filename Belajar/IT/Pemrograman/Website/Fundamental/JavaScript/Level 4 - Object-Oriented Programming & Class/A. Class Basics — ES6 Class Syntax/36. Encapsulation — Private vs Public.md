# Encapsulation — Private vs Public

## Penjelasan
Encapsulation (enkapsulasi) berarti **menyembunyikan data internal** dan hanya membuka akses lewat pintu resmi (method). Tujuannya agar data tidak diubah sembarangan dari luar class.

Di JavaScript ada dua gaya:
- **Public**: property bisa diakses langsung, misalnya `manager.tasks`.
- **Private**: hanya bisa diakses dari dalam class.
    - Cara tegas pakai `#`, misalnya `#tasks` (ES2022). Dari luar dipastikan error.
    - Cara "kesepakatan" pakai awalan `_`, misalnya `_tasks`. Ini tetap bisa diakses, hanya penanda "jangan sentuh".

Tambahan yang sering dipakai:
- **Getter** `get nama() {}` dibaca seperti property biasa, tanpa tanda kurung.
- **Setter** `set nama(nilai) {}` dijalankan saat property itu diisi.

## Fungsi
- Melindungi data dari perubahan langsung, misalnya `manager.#tasks = []` akan gagal.
- Menyediakan akses terkontrol lewat method atau getter.
- Menjaga konsistensi: semua perubahan harus lewat satu pintu, sehingga aturan tidak dilewati.

## Cara Pengimplementasian / Code
```js
// level4.js

class TaskManager {
  #tasks = []; // private field: benar-benar tidak bisa diakses dari luar
  #nextId = 1;

  addTask(title) {
    this.#tasks.push({ id: this.#nextId++, title: title, completed: false });
  }

  // method publik sebagai pintu resmi
  getTasks() {
    return [...this.#tasks]; // kembalikan salinan, bukan array aslinya
  }

  // getter: dibaca seperti property, tanpa tanda kurung
  get jumlah() {
    return this.#tasks.length;
  }
}

let manager = new TaskManager();
manager.addTask("Baca buku");
manager.addTask("Tulis review");

console.log(manager.jumlah);            // 2
console.log(manager.getTasks().length); // 2
// console.log(manager.#tasks);         // ERROR: Private field '#tasks'
```

Cara menjalankan: simpan sebagai `level4.js`, muat dari `level4.html`, buka di browser, tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
**Langkah 1 — `class TaskManager { ... }`**
JavaScript mendaftarkan class beserta dua private field: `#tasks` dan `#nextId`. Field ini hanya dikenali di dalam kurung kurawal class.

**Langkah 2 — `let manager = new TaskManager();`**
Constructor implisit jalan. Private field diisi: `#tasks` berisi `[]`, `#nextId` berisi `1`.

**Langkah 3 — `manager.addTask("Baca buku");`**
Method ini ada di dalam class, jadi boleh menyentuh `#tasks`. Ia memakai `#nextId` (nilai `1`), membuat task `{ id: 1, ... }`, mendorongnya ke `#tasks`, dan `#nextId` berubah jadi `2`.

**Langkah 4 — `manager.addTask("Tulis review");`**
Pakai `#nextId` (nilai `2`), dorong task `{ id: 2, ... }`, `#nextId` jadi `3`. Sekarang `#tasks` berisi dua task.

**Langkah 5 — `console.log(manager.jumlah);`**
Getter `jumlah` berjalan, mengembalikan panjang `#tasks` = `2`.

**Langkah 6 — `console.log(manager.getTasks().length);`**
`getTasks` mengembalikan salinan array, lalu `.length` = `2`.

**Langkah 7 — `manager.#tasks` (bila dijalankan)**
Error, karena `#tasks` hanya boleh diakses di dalam class.

**Output akhir:**
```
2
2
```

## Analogi
Private property seperti **buku di balik meja pustakawan**. Pengunjung (kode luar) tidak boleh langsung mengambil buku dari tumpukan belakang meja. Mereka harus bertanya lewat pustakawan (method/getter), dan pustakawan yang menentukan buku mana boleh dipinjam. Dengan begitu tumpukan tetap rapi dan tidak sembarangan diubah.

## Dipakai untuk Apa
- Menjaga `tasks` agar tidak bisa dikosongkan dari luar tanpa lewat method.
- Membuat nilai yang hanya bisa dibaca (read-only) lewat getter.
- Menyembunyikan detail internal seperti cara menyimpan id berikutnya.
- Mencegah bug saat banyak bagian program mengubah data yang sama.

## Kesalahan Umum yang Sering Terjadi
- **Mengakses `#field` dari luar**: Menulis `manager.#tasks` menghasilkan `SyntaxError`. Akses harus lewat method atau getter.
- **Lupa mendeklarasikan field di body class**: Memakai `this.#tasks` padahal `#tasks` tidak pernah dideklarasikan akan error. Deklarasikan dulu, misalnya `#tasks = [];`.
- **Mengembalikan referensi langsung**: `return this.#tasks` (bukan salinan) membuat luar bisa mengubah isi array. Kembalikan salinan dengan `[...this.#tasks]`.
- **Menganggap `_` benar-benar private**: `_tasks` tetap bisa diakses dari luar. Kalau butuh benar-benar tertutup, gunakan `#`.

## Soal Latihan & Jawaban
### Soal
Buat class `TaskManager` dengan private field `#tasks` dan `#nextId`. Tambahkan method `addTask(title)` dan getter `get daftar()` yang mengembalikan salinan array task. Tambahkan dua task, lalu tampilkan panjang daftar dan coba akses `manager.#tasks` (komentari sebagai catatan error).

### Jawaban
```js
class TaskManager {
  #tasks = [];
  #nextId = 1;

  addTask(title) {
    this.#tasks.push({ id: this.#nextId++, title: title, completed: false });
  }

  // getter mengembalikan salinan, aman dari perubahan luar
  get daftar() {
    return [...this.#tasks];
  }
}

let manager = new TaskManager();
manager.addTask("Pinjam buku");
manager.addTask("Kembalikan buku");

console.log(manager.daftar.length); // 2
// console.log(manager.#tasks);     // ERROR: Private field — memang tidak boleh
```
