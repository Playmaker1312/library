# Class Declaration & Constructor

## Penjelasan
Class adalah **cetakan (blueprint)** untuk membuat object. Kalau object adalah wujud nyata berisi data, class adalah rancangannya. Dari satu class, kamu bisa membuat banyak object dengan bentuk yang sama.

- Sintaks dasar: `class NamaClass { constructor(...) { ... } }`.
- `constructor` adalah method khusus yang **otomatis dijalankan saat** object dibuat dengan keyword `new`.
- Di dalam `constructor` kita mengisi **property**, yaitu data yang menempel pada object.
- `this` di dalam `constructor` menunjuk ke object yang sedang dibuat.
- Hasil dari `new NamaClass()` disebut **instance**, yaitu object nyata dari class tersebut.

Yang perlu diingat: class itu sendiri tidak menyimpan data. Data baru ada setelah kamu memanggil `new`. Nama class ditulis dengan **PascalCase** (huruf awal besar), misalnya `TaskManager`.

## Fungsi
Class membuat kode lebih rapi dan terorganisir. Di Level 3, data `tasks` disimpan di variabel global dan function-nya terpisah-pisah. Dengan class, data dan perilaku (behavior) dikumpulkan di satu tempat.

- Menghindari variabel global yang berserakan.
- Membuat banyak object serupa tanpa menulis ulang strukturnya.
- Menjadi dasar untuk inheritance dan encapsulation di materi berikutnya.

## Cara Pengimplementasian / Code
```js
// level4.js

// Cetakan untuk mengelola daftar task
class TaskManager {
  // constructor jalan otomatis saat `new TaskManager(...)` dipanggil
  constructor(owner) {
    this.owner = owner; // nama pemilik daftar task
    this.tasks = [];    // tempat menyimpan semua task
    this.nextId = 1;    // nomor id untuk task berikutnya
  }
}

// Buat instance dari class
let manager = new TaskManager("Perpustakaan Kota");
console.log(manager.owner);  // "Perpustakaan Kota"
console.log(manager.tasks);  // []
console.log(manager.nextId); // 1
```

Cara menjalankan: simpan sebagai `level4.js`, lalu muat dari `level4.html` (`<script src="level4.js"></script>`). Buka di browser, tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas seolah mengikuti komputer.

**Langkah 1 — `class TaskManager { ... }`**
JavaScript mendaftarkan cetakan bernama `TaskManager`. Belum ada data apa pun, karena class masih berupa rancangan.

**Langkah 2 — `let manager = new TaskManager("Perpustakaan Kota");`**
Keyword `new` menyuruh JavaScript menjalankan `constructor`. Parameter `owner` berisi `"Perpustakaan Kota"`. Di dalam constructor, `this` menunjuk object baru yang belum punya nama. Lalu:
- `this.owner = owner` → property `owner` diisi `"Perpustakaan Kota"`.
- `this.tasks = []` → property `tasks` diisi array kosong.
- `this.nextId = 1` → property `nextId` diisi `1`.
Setelah selesai, object itu diberi nama `manager`.

**Langkah 3 — `console.log(manager.owner);`**
Menampilkan isi property `owner`, yaitu `"Perpustakaan Kota"`.

**Langkah 4 — `console.log(manager.tasks);`**
Menampilkan array kosong `[]`.

**Langkah 5 — `console.log(manager.nextId);`**
Menampilkan angka `1`.

**Output akhir:**
```
Perpustakaan Kota
[]
1
```

## Analogi
Class seperti **formulir kosong pendaftaran anggota** di perpustakaan. Formulir itu sendiri bukan anggota, ia hanya memuat kolom-kolom: nama, nomor anggota, tanggal daftar. Saat ada orang mendaftar, kamu menyalin formulir itu dan mengisinya — hasil salinan yang terisi itulah object (instance). Setiap orang dapat formulir salinannya sendiri, jadi data mereka tidak saling bercampur.

## Dipakai untuk Apa
- Membuat struktur data seperti `Task`, `User`, atau `Produk` yang dipakai berulang.
- Mengelola state aplikasi (daftar task, keranjang belanja) dalam satu wadah.
- Menjadi kerangka game, misalnya class `Hero`, `Monster`, dan `Item`.
- Membuat banyak komponen serupa dengan konfigurasi berbeda.

## Kesalahan Umum yang Sering Terjadi
- **Lupa keyword `new`**: Memanggil `TaskManager()` tanpa `new` membuat `this` salah dan property tidak terbentuk. Selalu pakai `new TaskManager()`.
- **Nama class huruf kecil**: `class taskManager` tidak error, tetapi menyalahi konvensi dan membingungkan. Biasakan PascalCase.
- **Mengira `constructor` dipanggil manual**: `constructor` tidak dipanggil dengan namanya, ia otomatis jalan saat `new`. Memanggil `manager.constructor()` malah mengisi ulang datanya.
- **Lupa `this` saat mengisi property**: Menulis `tasks = []` tanpa `this.` membuat variabel biasa, bukan property instance, sehingga tidak tersimpan di object.

## Soal Latihan & Jawaban
### Soal
Buat class `Task` dengan `constructor(title, priority)` yang mengisi property `title`, `priority`, dan `completed` (default `false`). Lalu buat instance `task1` dengan judul `"Pinjam buku"` priority `"normal"`, dan `task2` dengan judul `"Kembalikan buku"` priority `"high"`. Tampilkan `task2.title` dan `task2.priority`.

### Jawaban
```js
class Task {
  constructor(title, priority) {
    this.title = title;
    this.priority = priority;
    this.completed = false; // semua task baru belum selesai
  }
}

let task1 = new Task("Pinjam buku", "normal");
let task2 = new Task("Kembalikan buku", "high");

console.log(task2.title);    // "Kembalikan buku"
console.log(task2.priority); // "high"
```
