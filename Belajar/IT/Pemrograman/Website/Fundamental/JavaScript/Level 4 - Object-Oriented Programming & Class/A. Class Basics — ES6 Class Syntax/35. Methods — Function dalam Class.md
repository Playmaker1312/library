# Methods — Function dalam Class

## Penjelasan
Method adalah **function yang tinggal di dalam class**. Ia menjelaskan apa yang bisa dilakukan sebuah object.

- Ditulis seperti function biasa, tetapi **tanpa kata `function`**.
- Mengakses property instance lewat `this`, misalnya `this.tasks`.
- Otomatis disimpan di **prototype** class, jadi di-share ke semua instance — hemat memori.
- Dipanggil lewat instance: `manager.addTask("...")`.
- Berbeda dengan `constructor`: method tidak jalan sendiri, ia hanya berjalan saat dipanggil.

Karena method berada di prototype, semua instance dari class yang sama memakai method yang sama persis. Yang berbeda hanyalah data di dalam `this`.

## Fungsi
Method membuat object bisa "bertingkah", bukan hanya menyimpan data. Inilah tempat logika CRUD berada.

- Menyatukan data (`this.tasks`) dengan cara mengolahnya (`addTask`, `getTasks`).
- Menghindari penulisan kode berulang karena satu method dipakai semua instance.
- Menjadi jembatan sebelum materi encapsulation, karena method adalah satu-satunya pintu untuk menyentuh data.

## Cara Pengimplementasian / Code
```js
// level4.js

class TaskManager {
  constructor() {
    this.tasks = []; // daftar task
    this.nextId = 1; // id berikutnya
  }

  // method untuk menambah task
  addTask(title) {
    let task = { id: this.nextId++, title: title, completed: false };
    this.tasks.push(task); // simpan ke daftar milik instance ini
    return task;           // kembalikan task yang baru dibuat
  }

  // method untuk mengambil semua task
  getTasks() {
    return this.tasks;
  }

  // method untuk menghitung jumlah task
  count() {
    return this.tasks.length;
  }
}

let manager = new TaskManager();
manager.addTask("Pinjam buku");
manager.addTask("Kembalikan buku");

console.log(manager.count());                    // jumlah task
console.log(JSON.stringify(manager.getTasks())); // isi daftar task
```

Cara menjalankan: simpan sebagai `level4.js`, muat dari `level4.html`, buka di browser, tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
**Langkah 1 — `let manager = new TaskManager();`**
Constructor jalan. `this.tasks` diisi `[]` dan `this.nextId` diisi `1`.

**Langkah 2 — `manager.addTask("Pinjam buku");`**
- `this.nextId++` memakai nilai lama `1`, lalu `this.nextId` berubah jadi `2`.
- `task` berisi `{ id: 1, title: "Pinjam buku", completed: false }`.
- `this.tasks.push(task)` menambahkan task itu ke daftar.

**Langkah 3 — `manager.addTask("Kembalikan buku");`**
- `this.nextId++` memakai nilai `2`, lalu `this.nextId` berubah jadi `3`.
- `task` berisi `{ id: 2, title: "Kembalikan buku", completed: false }`.
- `push` menambahkan ke daftar.

| Panggilan | id dipakai | nextId sesudah | Isi `tasks` |
|---|---|---|---|
| `addTask("Pinjam buku")` | 1 | 2 | 1 task |
| `addTask("Kembalikan buku")` | 2 | 3 | 2 task |

**Langkah 4 — `manager.count();`**
Method `count` membaca `this.tasks.length`, hasilnya `2`.

**Langkah 5 — `JSON.stringify(manager.getTasks());`**
`getTasks` mengembalikan daftar, lalu `stringify` mengubahnya jadi tulisan.

**Output akhir:**
```
2
[{"id":1,"title":"Pinjam buku","completed":false},{"id":2,"title":"Kembalikan buku","completed":false}]
```

## Analogi
Method seperti **kegiatan pustakawan**. Rak buku (data `tasks`) hanyalah tempat menyimpan. Yang bisa "melakukan sesuatu" adalah pustakawan: menambah buku ke rak, membacakan daftar buku, atau menghitung berapa buku yang ada. Satu pustakawan (method) melayani banyak rak, dan cara kerjanya sama untuk semua rak.

## Dipakai untuk Apa
- Menulis logika CRUD (tambah, baca, ubah, hapus task) di dalam class.
- Menghitung ringkasan data, misalnya jumlah task selesai.
- Mengubah state object dengan aturan tertentu, misalnya menandai task selesai.
- Menjadi dasar `this` binding saat method dipakai sebagai callback (materi 39-40).

## Kesalahan Umum yang Sering Terjadi
- **Lupa `this` saat mengakses property**: Menulis `tasks.push(...)` bukan `this.tasks.push(...)` membuat JavaScript bingung karena `tasks` tidak dikenali — muncul `ReferenceError`.
- **Memanggil method tanpa tanda kurung**: `manager.count` hanya mengambil referensinya, bukan menjalankannya. Harus `manager.count()`.
- **Menambah koma antar method**: `addTask() {}, getTasks() {}` tanpa koma. Menulis koma di antara method malah error sintaks.
- **Menaruh logika di dalam `constructor`**: Kode yang mestinya bisa dipanggil berkali-kali malah jalan sekali. Taruh di method.

## Soal Latihan & Jawaban
### Soal
Tambahkan method `getTaskById(id)` pada class `TaskManager` yang mengembalikan task dengan id tertentu, atau `null` jika tidak ada. Uji dengan menambah dua task lalu mencari id `2` dan id `99`.

### Jawaban
```js
class TaskManager {
  constructor() {
    this.tasks = [];
    this.nextId = 1;
  }

  addTask(title) {
    let task = { id: this.nextId++, title: title, completed: false };
    this.tasks.push(task);
    return task;
  }

  // cari task berdasarkan id
  getTaskById(id) {
    return this.tasks.find((t) => t.id === id) || null;
  }
}

let manager = new TaskManager();
manager.addTask("Pinjam buku");
manager.addTask("Kembalikan buku");

console.log(manager.getTaskById(2));  // task "Kembalikan buku"
console.log(manager.getTaskById(99)); // null
```
