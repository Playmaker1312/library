# Inheritance — extends & super

## Penjelasan
Inheritance (pewarisan) memungkinkan sebuah class **mewarisi** property dan method dari class lain. Class yang mewarisi disebut **child** (anak), class yang diwarisi disebut **parent** (induk).

- Sintaks: `class Child extends Parent { ... }`.
- Child otomatis punya semua property dan method milik parent.
- `super(...)` di dalam constructor child memanggil constructor parent.
- `super.method()` memanggil method milik parent dari dalam child.
- Child boleh menambah property/method baru yang tidak dimiliki parent.

Aturan penting: di dalam constructor child, **kamu wajib memanggil `super(...)` sebelum menyentuh `this`**. Kalau tidak, JavaScript melempar error.

## Fungsi
Pewarisan menghindari menulis kode yang sama berulang kali.

- Class `UrgentTask` cukup menulis hal yang membedakannya, sisanya diwarisi dari `Task`.
- Perubahan di parent otomatis menurun ke semua child.
- Menjadi dasar polymorphism di materi berikutnya, karena child bisa mengubah perilaku warisannya.

## Cara Pengimplementasian / Code
```js
// level4.js

// Class induk: sifat umum sebuah task
class Task {
  constructor(title, priority = "normal") {
    this.title = title;       // judul task
    this.priority = priority; // tingkat prioritas
    this.completed = false;   // status selesai
  }

  info() {
    return this.title + " [" + this.priority + "]";
  }
}

// Class anak: task mendesak, mewarisi Task
class UrgentTask extends Task {
  constructor(title) {
    super(title, "high"); // panggil constructor Task dengan priority "high"
    this.dueDate = "besok"; // property tambahan milik UrgentTask
  }
}

let biasa = new Task("Pinjam buku");
let urgent = new UrgentTask("Kembalikan buku");

console.log(biasa.info());     // "Pinjam buku [normal]"
console.log(urgent.info());    // method warisan dari Task
console.log(urgent.priority);  // "high"
console.log(urgent.dueDate);   // "besok"
```

Cara menjalankan: simpan sebagai `level4.js`, muat dari `level4.html`, buka di browser, tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
**Langkah 1 — `class Task { ... }`**
JavaScript mendaftarkan class induk `Task` beserta method `info`.

**Langkah 2 — `class UrgentTask extends Task { ... }`**
JavaScript mendaftarkan class anak `UrgentTask`. Ia mewarisi `info`, tetapi belum punya data apa pun.

**Langkah 3 — `let biasa = new Task("Pinjam buku");`**
Constructor `Task` jalan: `title` = `"Pinjam buku"`, `priority` tidak dikirim sehingga memakai default `"normal"`, `completed` = `false`.

**Langkah 4 — `let urgent = new UrgentTask("Kembalikan buku");`**
Ini bagian penting:
- Constructor `UrgentTask` jalan dengan `title` = `"Kembalikan buku"`.
- Baris `super(title, "high")` memanggil constructor `Task`. `this` yang sama diisi: `title` = `"Kembalikan buku"`, `priority` = `"high"`, `completed` = `false`.
- Setelah `super` selesai, baris `this.dueDate = "besok"` menambah property `dueDate`.

| Object | title | priority | completed | dueDate |
|---|---|---|---|---|
| `biasi` | Pinjam buku | normal | false | — |
| `urgent` | Kembalikan buku | high | false | besok |

**Langkah 5 — `urgent.info();`**
`info` tidak ditulis di `UrgentTask`, jadi JavaScript memakai milik parent. Hasilnya `"Kembalikan buku [high]"`.

**Langkah 6 — `console.log(urgent.priority);`** → `"high"`.
**Langkah 7 — `console.log(urgent.dueDate);`** → `"besok"`.

**Output akhir:**
```
Pinjam buku [normal]
Kembalikan buku [high]
high
besok
```

## Analogi
Inheritance seperti **formulir anggota khusus untuk pelajar**. Perpustakaan punya formulir umum (parent) berisi kolom nama dan nomor anggota. Untuk pelajar dibuat formulir turunan (child) yang otomatis memuat kolom formulir umum, lalu ditambah kolom khusus "nama sekolah". Kamu tidak menulis ulang kolom nama dan nomor — cukup menambah yang baru.

## Dipakai untuk Apa
- Membuat jenis task khusus seperti `UrgentTask`, `RecurringTask`, tanpa mengulang kode dasar.
- Menyusun hierarki data, misalnya `User` → `Member` → `PremiumMember`.
- Membuat komponen UI yang berbagi perilaku dasar.
- Menjadi fondasi polymorphism: anak bisa mengubah method warisan sesuai kebutuhan.

## Kesalahan Umum yang Sering Terjadi
- **Lupa `super()` di constructor child**: Muncul `ReferenceError: Must call super constructor`. Panggil `super(...)` paling atas di constructor anak.
- **Menyentuh `this` sebelum `super()`**: `this.x = ...` sebelum `super()` juga error. Urutannya harus `super` dulu.
- **Child tidak menambah apa pun**: Bila child sama saja dengan parent, class baru jadi mubazir. Buat child kalau memang ada perbedaan.
- **Salah urutan parameter `super`**: `super(title, "high")` harus sesuai urutan constructor parent (`title`, `priority`). Tertukar membuat prioritas berisi judul.

## Soal Latihan & Jawaban
### Soal
Buat class `Task` dengan `constructor(title, priority)` dan method `info()` yang mengembalikan `"<title> [<priority>]"`. Lalu buat class `RecurringTask extends Task` yang memanggil `super(title, "harian")` dan menambah property `repeatCount`. Buat satu instance `RecurringTask("Setor buku", 7)` dan tampilkan `info()` serta `repeatCount`.

### Jawaban
```js
class Task {
  constructor(title, priority) {
    this.title = title;
    this.priority = priority;
    this.completed = false;
  }

  info() {
    return this.title + " [" + this.priority + "]";
  }
}

class RecurringTask extends Task {
  constructor(title, repeatCount) {
    super(title, "harian"); // atur prioritas khusus untuk task berulang
    this.repeatCount = repeatCount;
  }
}

let tugas = new RecurringTask("Setor buku", 7);

console.log(tugas.info());        // "Setor buku [harian]"
console.log(tugas.repeatCount);   // 7
```
