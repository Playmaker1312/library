# Polymorphism — Override Method

## Penjelasan
Polymorphism (polimorfisme) berarti **satu nama method, banyak perilaku**. Class anak boleh menulis ulang (override) method yang diwarisi dari parent dengan versi miliknya sendiri.

- Nama method sama, isinya berbeda.
- Saat dipanggil lewat instance anak, versi anak yang jalan.
- Saat dipanggil lewat instance parent, versi parent yang jalan.
- `super.method()` dipakai bila anak ingin tetap memakai versi parent di dalam override-nya.

Kunci polymorphism: kita bisa memanggil `display()` pada bermacam object tanpa peduli tipe aslinya. JavaScript otomatis memilih versi yang tepat.

## Fungsi
- Memberi perilaku khusus pada tiap jenis object tanpa mengubah parent.
- Membuat kode pemanggil lebih sederhana: cukup satu panggilan untuk banyak tipe.
- Memisahkan tanggung jawab: parent menetapkan "kontrak", anak menyesuaikan detailnya.

## Cara Pengimplementasian / Code
```js
// level4.js

class Task {
  constructor(title, priority = "normal") {
    this.title = title;
    this.priority = priority;
  }

  // method umum
  display() {
    return this.title + " (" + this.priority + ")";
  }
}

class UrgentTask extends Task {
  constructor(title) {
    super(title, "high"); // prioritas tinggi
  }

  // override: versi sendiri untuk task mendesak
  display() {
    return "🔴 " + this.title + " (URGENT)";
  }
}

let daftar = [
  new Task("Pinjam buku"),
  new UrgentTask("Kembalikan buku"),
  new Task("Baca koran", "low"),
];

// satu panggilan, tiga perilaku berbeda
for (let t of daftar) {
  console.log(t.display());
}
```

Cara menjalankan: simpan sebagai `level4.js`, muat dari `level4.html`, buka di browser, tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
**Langkah 1 — `new Task("Pinjam buku")`**
Constructor `Task` jalan: `title` = `"Pinjam buku"`, `priority` = `"normal"`.

**Langkah 2 — `new UrgentTask("Kembalikan buku")`**
Constructor `UrgentTask` memanggil `super(title, "high")`, jadi `title` = `"Kembalikan buku"` dan `priority` = `"high"`. `UrgentTask` juga punya method `display` sendiri.

**Langkah 3 — `new Task("Baca koran", "low")`**
`title` = `"Baca koran"`, `priority` = `"low"`.

**Langkah 4 — loop `for (let t of daftar)`**
JavaScript memanggil `t.display()` untuk tiap object. Karena `UrgentTask` punya `display` sendiri, yang jalan adalah versi anak.

| Putaran | Object | Method yang dipakai | Hasil |
|---|---|---|---|
| 1 | `Task "Pinjam buku"` | `Task.display` | `Pinjam buku (normal)` |
| 2 | `UrgentTask "Kembalikan buku"` | `UrgentTask.display` | `🔴 Kembalikan buku (URGENT)` |
| 3 | `Task "Baca koran"` | `Task.display` | `Baca koran (low)` |

**Output akhir:**
```
Pinjam buku (normal)
🔴 Kembalikan buku (URGENT)
Baca koran (low)
```

## Analogi
Polymorphism seperti **cara pustakawan menyapa pengunjung**. Untuk anggota biasa ia berkata "Selamat datang". Untuk anggota pelajar, ia berkata "Selamat datang, adik". Perintahnya sama ("sapa pengunjung"), tetapi hasilnya menyesuaikan jenis pengunjung yang dihadapi.

## Dipakai untuk Apa
- Menampilkan daftar campuran task biasa dan task mendesak dengan format berbeda.
- Membuat berbagai bentuk "render" untuk tipe data yang beragam.
- Sistem notifikasi yang berperilaku beda per jenis pesan (email, SMS, push).
- Kerangka game: setiap `Monster` punya `attack()` dengan efek berbeda.

## Kesalahan Umum yang Sering Terjadi
- **Salah tulis nama method**: `Display` atau `showTask` bukan override dari `display`, jadi bukan menimpa apa pun. Samakan nama persisnya.
- **Lupa memanggil `super()` di constructor anak**: Sebelum menyentuh `this`, `super()` wajib dipanggil, jika tidak error.
- **Mengubah parent demi satu anak**: Menambah `if` di method parent agar cocok untuk anak membuat parent kotor. Cukup override di anak.
- **Override tidak mengembalikan nilai**: Bila `display()` anak tidak `return`, hasilnya `undefined` saat ditampilkan.

## Hubungan dengan Materi Sebelumnya
Materi ini melanjutkan **37. Inheritance — extends & super**. Setelah anak mewarisi method parent, sekarang anak bisa mengubah method itu. Override ini sering butuh pemahaman `this` yang benar, yang dibahas di **39. this dalam Method — Regular Function vs Arrow**.

## Soal Latihan & Jawaban
### Soal
Buat class `Task` dengan method `label()` yang mengembalikan `"[ ] <title>"`. Buat class `DoneTask extends Task` yang meng-override `label()` menjadi `"[x] <title>"`. Buat array berisi `Task("Pinjam buku")` dan `DoneTask("Kembalikan buku")`, lalu cetak `label()` tiap elemen.

### Jawaban
```js
class Task {
  constructor(title) {
    this.title = title;
  }

  label() {
    return "[ ] " + this.title; // task belum selesai
  }
}

class DoneTask extends Task {
  constructor(title) {
    super(title); // warisi title dari Task
  }

  label() {
    return "[x] " + this.title; // task sudah selesai
  }
}

let daftar = [new Task("Pinjam buku"), new DoneTask("Kembalikan buku")];

for (let t of daftar) {
  console.log(t.label());
}

// Output:
// [ ] Pinjam buku
// [x] Kembalikan buku
```
