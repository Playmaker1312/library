# Static Methods & Properties

## Penjelasan
Static member adalah method atau property yang **melekat pada class, bukan pada instance**. Ia dipakai lewat nama class, bukan lewat object.

- Kata kunci `static` ditulis di depan nama method/property.
- Diakses dengan `ClassName.staticMethod()`, bukan `manager.staticMethod()`.
- Static property **dibagi bersama** semua instance, jadi cocok untuk penghitung atau konfigurasi.
- Di dalam static method, `this` menunjuk ke class itu sendiri (bukan ke instance).

Bedanya jelas: property biasa (`this.tasks`) milik masing-masing object, sedangkan static property milik class dan dipakai bersama.

## Fungsi
- Menyimpan data yang berlaku umum, misalnya "berapa banyak manager pernah dibuat".
- Menyediakan utility/helper yang tidak butuh data instance, misalnya validasi atau info statistik.
- Memisahkan logika tingkat class dari logika tingkat object.

## Cara Pengimplementasian / Code
```js
// level4.js

class TaskManager {
  static totalCreated = 0; // static property: milik class, dipakai bersama

  constructor() {
    this.tasks = [];            // property instance, milik tiap object
    TaskManager.totalCreated++; // naikkan penghitung setiap manager dibuat
  }

  // static method: tidak butuh instance
  static printStats() {
    console.log("Total managers created: " + TaskManager.totalCreated);
  }
}

new TaskManager();
new TaskManager();

TaskManager.printStats(); // akses lewat class, bukan instance

let manager = new TaskManager();
console.log(TaskManager.totalCreated); // 3
// manager.printStats(); // ERROR: bukan method instance
```

Cara menjalankan: simpan sebagai `level4.js`, muat dari `level4.html`, buka di browser, tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
**Langkah 1 — `class TaskManager { ... }`**
JavaScript mendaftarkan class. Static property `totalCreated` dimulai dari `0`.

**Langkah 2 — `new TaskManager();` (pertama)**
Constructor jalan: `this.tasks` diisi `[]`, lalu `TaskManager.totalCreated` naik dari `0` menjadi `1`.

**Langkah 3 — `new TaskManager();` (kedua)**
Constructor jalan lagi untuk object baru. `TaskManager.totalCreated` naik dari `1` menjadi `2`.

**Langkah 4 — `TaskManager.printStats();`**
Static method jalan. Ia membaca `TaskManager.totalCreated` = `2`, lalu mencetak pesan.

**Langkah 5 — `new TaskManager();` (ketiga)**
`TaskManager.totalCreated` naik menjadi `3`.

**Langkah 6 — `console.log(TaskManager.totalCreated);`**
Mencetak `3`.

| Aksi | totalCreated sesudah |
|---|---|
| `new TaskManager()` | 1 |
| `new TaskManager()` | 2 |
| `TaskManager.printStats()` | 2 (cetak) |
| `new TaskManager()` | 3 |

**Output akhir:**
```
Total managers created: 2
3
```

## Analogi
Static property seperti **buku besar pencatatan perpustakaan**. Semua pustakawan (instance) melihat catatan yang sama di buku itu, misalnya "total anggota terdaftar". Buku besar bukan milik satu pustakawan, melainkan milik perpustakaan (class). Siapa pun yang bertanya ke perpustakaan akan mendapat angka yang sama.

## Dipakai untuk Apa
- Menghitung berapa banyak instance yang pernah dibuat.
- Helper/utility murni, misalnya `TaskManager.fromJSON(data)`.
- Menyimpan konfigurasi tingkat class seperti versi atau batas maksimum.
- Membuat "pabrik" (factory) yang mengembalikan instance baru.

## Kesalahan Umum yang Sering Terjadi
- **Mengakses lewat instance**: `manager.printStats()` gagal karena method itu milik class. Pakai `TaskManager.printStats()`.
- **Mengira static property milik tiap object**: `this.totalCreated` di dalam instance menunjuk hal lain; static harus diakses lewat `TaskManager.totalCreated`.
- **Memakai instance data di static method**: Static tidak punya akses ke `this.tasks` instance. Kalau butuh data instance, jadikan method biasa.
- **Lupa `static`**: Menulis `printStats()` tanpa `static` membuatnya method instance, sehingga `TaskManager.printStats()` error.

## Soal Latihan & Jawaban
### Soal
Buat class `Task` dengan static property `counter` mulai dari `0`. Setiap kali `new Task(title)` dipanggil, `Task.counter` naik satu. Tambahkan static method `totalTasks()` yang mencetak `"Total tasks dibuat: N"`. Buat dua task lalu panggil `Task.totalTasks()`.

### Jawaban
```js
class Task {
  static counter = 0; // milik class, dipakai bersama

  constructor(title) {
    this.title = title;
    Task.counter++; // tambah setiap task baru
  }

  static totalTasks() {
    console.log("Total tasks dibuat: " + Task.counter);
  }
}

new Task("Pinjam buku");
new Task("Kembalikan buku");

Task.totalTasks(); // "Total tasks dibuat: 2"
```
