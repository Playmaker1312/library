# CRUD Methods dalam Class — addTask, getTasks, updateTask, deleteTask

## Penjelasan
Di materi ini kita **mengubah kode CRUD Level 3 menjadi method di dalam class**. Fungsinya sama persis, hanya strukturnya lebih rapi.

- `addTask`, `getTasks`, `updateTask`, `deleteTask` menjadi method class.
- Data `tasks` disimpan sebagai property **private** `#tasks`, id berikutnya di `#nextId`.
- `saveTasks` dan `loadTasks` jadi **private method** karena hanya dipakai internal, dan setiap perubahan langsung disimpan ke `localStorage`.

Inilah bentuk "refactor": mengganti function standalone + variabel global menjadi class dengan data dan perilaku yang menyatu.

## Fungsi
- Menggabungkan data dan logika CRUD dalam satu wadah.
- Melindungi data lewat private field sehingga tidak diubah sembarangan.
- Menyimpan otomatis ke `localStorage`, sehingga data tetap ada setelah refresh.

## Cara Pengimplementasian / Code
```js
// level4.js

class TaskManager {
  #tasks = [];  // daftar task (private)
  #nextId = 1;  // id berikutnya (private)

  constructor() {
    this.#loadTasks(); // muat data lama saat aplikasi mulai
  }
  // CREATE: tambah task baru
  addTask(title) {
    if (!title.trim()) return null; // validasi judul kosong
    let task = { id: this.#nextId++, title: title, completed: false };
    this.#tasks.push(task);
    this.#saveTasks();
    return task;
  }
  // READ: ambil semua task (kembalikan salinan)
  getTasks() {
    return [...this.#tasks];
  }
  // UPDATE: ubah task berdasarkan id
  updateTask(id, updates) {
    let task = this.#tasks.find((t) => t.id === id);
    if (!task) return null;
    Object.assign(task, updates); // gabungkan perubahan
    this.#saveTasks();
    return task;
  }
  // DELETE: hapus task berdasarkan id
  deleteTask(id) {
    let index = this.#tasks.findIndex((t) => t.id === id);
    if (index === -1) return null;
    let deleted = this.#tasks.splice(index, 1);
    this.#saveTasks();
    return deleted[0];
  }
  #saveTasks() { // private: simpan ke localStorage
    localStorage.setItem("tasks", JSON.stringify(this.#tasks));
  }
  #loadTasks() { // private: muat dari localStorage
    let stored = localStorage.getItem("tasks");
    this.#tasks = stored ? JSON.parse(stored) : [];
  }
}

let manager = new TaskManager();
manager.addTask("Pinjam buku");
manager.addTask("Kembalikan buku");
manager.updateTask(1, { completed: true });
manager.deleteTask(2);
console.log(JSON.stringify(manager.getTasks()));
```

Cara menjalankan: simpan sebagai `level4.js`, muat dari `level4.html`, buka di browser, tekan F12 → tab Console. Cek data di tab Application → Local Storage.

## Tracing Code (Step-by-Step)
**Langkah 1 — `new TaskManager();`**
Constructor jalan. Ia memanggil `#loadTasks()`. Karena `localStorage` belum berisi apa pun, `#tasks` diisi `[]` dan `#nextId` tetap `1`.

**Langkah 2 — `manager.addTask("Pinjam buku");`**
Judul tidak kosong. Dibuat task `{ id: 1, title: "Pinjam buku", completed: false }`, `#nextId` jadi `2`, task didorong ke `#tasks`, lalu `#saveTasks()` menulis daftar ke `localStorage`.

**Langkah 3 — `manager.addTask("Kembalikan buku");`**
Task `{ id: 2, ... }` dibuat, `#nextId` jadi `3`, lalu disimpan.

**Langkah 4 — `manager.updateTask(1, { completed: true });`**
`find` menemukan task id `1`, `Object.assign` mengubah `completed` jadi `true`, lalu disimpan.

**Langkah 5 — `manager.deleteTask(2);`**
`findIndex` menemukan posisi task id `2`, `splice` mengeluarkannya dari array, lalu disimpan.

| Aksi | Isi `#tasks` sesudah | nextId |
|---|---|---|
| `addTask("Pinjam buku")` | 1 task (id 1) | 2 |
| `addTask("Kembalikan buku")` | 2 task (id 1, 2) | 3 |
| `updateTask(1, {completed:true})` | task 1 completed = true | 3 |
| `deleteTask(2)` | tinggal task id 1 | 3 |

**Output akhir:**
```
[{"id":1,"title":"Pinjam buku","completed":true}]
```

## Analogi
Class ini seperti **meja layanan perpustakaan lengkap**. Di belakang meja ada rak buku (`#tasks`) yang tidak boleh diutak-atik pengunjung, dan buku besar stok (`localStorage`). Pustakawan melayani lewat satu pintu: menerima buku baru (`addTask`), menunjukkan daftar (`getTasks`), memperbarui catatan (`updateTask`), atau mencoret buku (`deleteTask`).

## Dipakai untuk Apa
- Aplikasi to-do list dan task manager yang menyimpan data di browser.
- Menggantikan function CRUD global agar kode lebih terstruktur.
- Dasar sebelum menampilkan data ke HTML (DOM) di Level 5.

## Kesalahan Umum yang Sering Terjadi
- **`getTasks` mengembalikan referensi langsung**: `return this.#tasks` membuat luar bisa mengubah isi private array. Kembalikan salinan dengan `[...this.#tasks]`.
- **Lupa `#saveTasks()` setelah perubahan**: Data berubah di memori tetapi hilang saat refresh. Panggil simpan di setiap add/update/delete.
- **`#nextId` tidak ikut disimpan**: Setelah refresh, `#nextId` kembali ke `1` sehingga id bisa duplikat. Simpan juga nilainya, atau hitung ulang dari id terbesar.
- **Memakai `filter` tanpa menimpa array**: `this.#tasks.filter(...)` menghasilkan array baru yang terbuang. Pakai `splice` atau timpa hasilnya ke `#tasks`.

## Soal Latihan & Jawaban
### Soal
Berdasarkan class `TaskManager` di atas, tambahkan method `toggleTask(id)` yang membalik status `completed` (dari `true` jadi `false`, sebaliknya), lalu menyimpan perubahan. Uji: tambah satu task, panggil `toggleTask(1)` dua kali, dan tampilkan hasilnya.

### Jawaban
```js
class TaskManager {
  #tasks = [];
  #nextId = 1;

  addTask(title) {
    let task = { id: this.#nextId++, title: title, completed: false };
    this.#tasks.push(task);
    return task;
  }

  // balik status selesai / belum selesai
  toggleTask(id) {
    let task = this.#tasks.find((t) => t.id === id);
    if (!task) return null;
    task.completed = !task.completed;
    return task;
  }
}

let manager = new TaskManager();
manager.addTask("Pinjam buku");

console.log(manager.toggleTask(1).completed); // true
console.log(manager.toggleTask(1).completed); // false
```
