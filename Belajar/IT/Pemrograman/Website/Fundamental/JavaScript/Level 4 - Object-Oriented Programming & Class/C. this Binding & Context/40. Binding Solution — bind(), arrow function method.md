# Binding Solution — bind(), arrow function method

## Penjelasan
Binding adalah cara **mengunci nilai `this`** pada sebuah fungsi agar tidak hilang saat fungsi itu dilepas dari object-nya. Setelah tahu masalah `this` hilang di materi sebelumnya, sekarang kita pelajari solusinya.

Ada dua cara utama:
- **`bind()`**: `method.bind(thisContext)` membuat salinan fungsi dengan `this` yang sudah dikunci.
- **Arrow method**: `namaMethod = () => { ... }` menulis method sebagai arrow function, sehingga `this` mengikuti constructor tempat ia dibuat.

Cara lain yang sering dipakai: membungkus pemanggilan dengan arrow function, misalnya `setTimeout(() => manager.tampilNama(), 100)`.

## Fungsi
- Memastikan method tetap mengenali object-nya saat dipakai sebagai callback.
- Mencegah bug "undefined" saat method dikirim ke event listener atau `setTimeout`.
- Memberi dua pilihan: `bind` di constructor, atau arrow method yang lebih ringkas.

## Cara Pengimplementasian / Code
```js
// level4.js

class TaskManager {
  constructor(name) {
    this.name = name;

    // Solusi 1: kunci `this` dengan bind() di constructor
    this.tampilNamaBind = this.tampilNama.bind(this);

    // Solusi 2: arrow method, `this` mengikuti constructor
    this.tampilNamaArrow = () => console.log(this.name);
  }

  // method biasa (akan hilang `this` bila dipanggil lepas)
  tampilNama() {
    console.log(this.name);
  }
}

let manager = new TaskManager("Manajer Perpustakaan");

// Diambil lepas, tetapi `this` tetap terkunci
let lepasBind = manager.tampilNamaBind;
lepasBind(); // "Manajer Perpustakaan"

let lepasArrow = manager.tampilNamaArrow;
lepasArrow(); // "Manajer Perpustakaan"
```

Cara menjalankan: simpan sebagai `level4.js`, muat dari `level4.html`, buka di browser, tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
**Langkah 1 — `new TaskManager("Manajer Perpustakaan");`**
Constructor jalan. `this.name` = `"Manajer Perpustakaan"`. Lalu:
- `this.tampilNama.bind(this)` membuat fungsi baru dengan `this` terkunci ke `manager`, disimpan di `tampilNamaBind`.
- `this.tampilNamaArrow = () => console.log(this.name)` membuat arrow method. Karena dibuat di dalam constructor, `this`-nya ikut ke `manager`, disimpan di `tampilNamaArrow`.

**Langkah 2 — `manager.tampilNamaBind;`**
Mengambil fungsi yang sudah terkunci. `this` di dalamnya tetap `manager`, siapa pun yang memanggil.

**Langkah 3 — `lepasBind();`**
Dipanggil tanpa object, tetapi `this` sudah dikunci, jadi `this.name` = `"Manajer Perpustakaan"`.

**Langkah 4 — `lepasArrow();`**
Arrow method mengambil `this` dari constructor, jadi tetap `manager`. Hasilnya sama.

## Analogi
Binding seperti **pustakawan yang membawa stempel nama sendiri**. Kalau ia hanya "method biasa", stempelnya tertinggal di meja dan hilang saat ia dipanggil ke ruangan lain. Dengan `bind()` ia mengunci stempel di tangannya, dan dengan arrow method ia memang lahir sudah memegang stempel itu. Ke mana pun dipanggil, identitasnya tetap jelas.

## Dipakai untuk Apa
- Mengirim method sebagai callback ke `addEventListener` (mis. tombol "Tambah task").
- Memakai method di dalam `setTimeout` atau `setInterval` tanpa kehilangan konteks.
- Menyimpan method ke variabel untuk dipakai ulang.
- Menjadi pola umum di framework seperti React saat menangani event.

## Kesalahan Umum yang Sering Terjadi
- **Bind di tempat yang salah**: `manager.tampilNama.bind(manager)` saat dipanggil lepas memang jalan, tetapi hasil bind-nya harus disimpan; kalau tidak disimpan, tetap hilang.
- **Memakai arrow untuk semua hal**: Arrow method dibuat ulang tiap instance sehingga lebih boros memori dibanding method biasa di prototype. Pakai seperlunya.
- **`bind` berulang-ulang**: `fn.bind(this)` dua kali membuat lapisan fungsi baru tanpa manfaat. Bind cukup sekali.
- **Menulis arrow method lalu lupa tanda `=`**: `tampilNamaArrow() {}` itu method biasa, bukan arrow method. Harus `tampilNamaArrow = () => {}`.

## Soal Latihan & Jawaban
### Soal
Buat class `TaskManager` dengan property `label`. Tulis method `show()` yang mencetak `"Daftar: " + this.label`. Di constructor, buat `this.showAman` dengan `bind`, dan `this.showArrow` sebagai arrow method. Ambil keduanya lepas dan panggil untuk membuktikan `this` tetap benar.

### Jawaban
```js
class TaskManager {
  constructor(label) {
    this.label = label;

    // kunci this dengan bind, simpan hasilnya
    this.showAman = this.show.bind(this);

    // arrow method: this ikut constructor
    this.showArrow = () => console.log("Daftar: " + this.label);
  }

  show() {
    console.log("Daftar: " + this.label);
  }
}

let manager = new TaskManager("Tugas Harian");

let a = manager.showAman;
let b = manager.showArrow;

a(); // "Daftar: Tugas Harian"
b(); // "Daftar: Tugas Harian"
```
