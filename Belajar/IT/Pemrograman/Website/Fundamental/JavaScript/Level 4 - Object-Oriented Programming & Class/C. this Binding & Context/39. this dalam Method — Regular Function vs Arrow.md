# this dalam Method — Regular Function vs Arrow

## Penjelasan
`this` adalah kata kunci yang menunjuk "konteks siapa yang sedang dijalankan". Nilainya **berbeda-beda tergantung cara pemanggilan**, dan ini sumber kebingungan klasik di JavaScript.

- Pada **regular method**, `this` adalah object yang memanggil method tersebut.
- Pada **arrow function**, `this` tidak ditentukan saat dipanggil, melainkan mengikuti tempat ia didefinisikan (lexical).
- Masalah muncul saat method diambil lalu dipanggil tanpa object, misalnya `let f = manager.displayName; f();`. Di sini `this` kehilangan object-nya.

Aturan sederhana: `this` ditentukan oleh **bagaimana fungsi dipanggil**, bukan di mana ia ditulis — kecuali arrow function yang mengambil `this` dari sekitarnya.

## Fungsi
- Memahami `this` penting agar method bisa membaca data instance dengan benar.
- Menjelaskan kenapa method kadang masih jalan, kadang menghasilkan `undefined`.
- Menjadi dasar untuk solusi binding di materi berikutnya.

## Cara Pengimplementasian / Code
```js
// level4.js

class TaskManager {
  constructor(name) {
    this.name = name; // nama manajer
  }

  // regular method: `this` bergantung cara pemanggilan
  displayName() {
    console.log(this.name);
  }
}

let manager = new TaskManager("Manajer Perpustakaan");

// Dipanggil lewat object: `this` = manager
manager.displayName(); // "Manajer Perpustakaan"

// Method dilepas dari object-nya, lalu dipanggil sendiri
let func = manager.displayName;
func(); // this hilang → undefined
```

Cara menjalankan: simpan sebagai `level4.js`, muat dari `level4.html`, buka di browser, tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
**Langkah 1 — `let manager = new TaskManager("Manajer Perpustakaan");`**
Constructor jalan: `this.name` diisi `"Manajer Perpustakaan"`.

**Langkah 2 — `manager.displayName();`**
Karena dipanggil dengan `manager.` di depan, `this` menunjuk ke `manager`. Jadi `this.name` = `"Manajer Perpustakaan"`.

**Langkah 3 — `let func = manager.displayName;`**
`func` sekarang menyimpan method itu, tetapi **tanpa** keterkaitan ke `manager`. Object-nya tertinggal.

**Langkah 4 — `func();`**
Dipanggil tanpa object di depan. Dalam mode strict (kode class termasuk strict), `this` menjadi `undefined`. Karena itu `this.name` error atau menghasilkan `undefined` saat dibaca lewat `console.log`.

**Output akhir:**
```
Manajer Perpustakaan
undefined
```

## Analogi
`this` seperti **papan nama meja pustakawan**. Selama pustakawan duduk di mejanya (dipanggil lewat `manager.`), papan nama itu menunjuk dirinya dengan benar. Begitu ia dipanggil keluar mejanya (method dilepas), papan namanya tertinggal di meja, sehingga orang tidak tahu siapa yang sedang bekerja.

## Dipakai untuk Apa
- Memastikan method bisa membaca data instance saat dipanggil dari event listener.
- Mendiagnosis bug "undefined" saat method dijadikan callback `setTimeout` atau `addEventListener`.
- Menentukan kapan memakai method biasa dan kapan memakai arrow function.
- Menjadi prasyarat sebelum memakai `bind()` di materi berikutnya.

## Kesalahan Umum yang Sering Terjadi
- **Melepas method dari object**: `let f = manager.displayName; f();` membuat `this` hilang. Panggil lewat object, atau ikat dengan `bind` (materi 40).
- **Memakai method sebagai callback langsung**: `setTimeout(manager.displayName, 100)` melepas `this`. Bungkus dengan arrow: `setTimeout(() => manager.displayName(), 100)`.
- **Mengira arrow punya `this` sendiri**: Arrow function mengambil `this` dari sekitarnya, jadi tidak bisa dipakai untuk mendapatkan konteks baru.
- **Mengandalkan `this` di luar object**: Di console browser, `this` di luar bisa menunjuk `window`, sehingga hasilnya membingungkan.

## Soal Latihan & Jawaban
### Soal
Buat class `TaskManager` dengan constructor `name`. Tambahkan method `greet()` yang mencetak `"Halo, " + this.name`. Panggil sekali lewat object (harus benar), lalu simpan ke variabel dan panggil lepas untuk menunjukkan `this` hilang.

### Jawaban
```js
class TaskManager {
  constructor(name) {
    this.name = name;
  }

  greet() {
    console.log("Halo, " + this.name);
  }
}

let manager = new TaskManager("Manajer Perpustakaan");

manager.greet(); // "Halo, Manajer Perpustakaan" — this = manager

let lepas = manager.greet;
lepas(); // "Halo, undefined" — this hilang saat method dilepas

// Perbaikan cepat: panggil lewat object lagi
manager.greet(); // "Halo, Manajer Perpustakaan"
```
