# reduce — Aggregate Array ke Single Value

## Penjelasan
`reduce()` adalah method array yang menjalankan **callback** berulang untuk tiap elemen, membawa hasil sementara yang disebut **accumulator** (penampung hasil kumulatif), sampai akhirnya menghasilkan **satu nilai tunggal** — bisa angka, object, bahkan array.

- Syntax: `array.reduce((accumulator, element) => nilaiAccBaru, nilaiAwal)`
- `initialValue` (nilai awal accumulator) **sangat disarankan**; tanpa itu, elemen pertama dipakai sebagai awal
- Setiap putaran, callback menerima accumulator hasil putaran sebelumnya, lalu mengembalikan nilai barunya
- Bentuk akhir bebas: number (jumlah), object (pengelompokan), string, dst.
- Array asal tidak diubah; hasil berupa satu nilai, bukan array

Inti pemahamannya: bayangkan `reduce` sebagai mesin yang "memakan" array satu per satu dan terus memperbarui satu wadah (`accumulator`).

## Fungsi
Banyak kebutuhan yang hasilnya **satu angka atau satu object ringkasan**: jumlah task, berapa yang selesai, hitung per kategori. Tanpa `reduce`, kamu harus membuat variabel hitung manual dan menulis loop sendiri — tiap jenis ringkasan butuh loop baru. `reduce` memakai satu pola untuk semua kasus itu: yang kamu ganti hanyalah isi callback-nya. Inilah puncak pola functional — `filter` memilih, `map` mengubah, `reduce` meringkas.

## Cara Pengimplementasian / Code
```js
// Konteks Task Manager: array of task objects
let tasks = [
  { id: 1, title: "Riset", completed: false, priority: "high" },
  { id: 2, title: "Bikin UI", completed: true, priority: "low" },
  { id: 3, title: "Testing", completed: false, priority: "high" },
  { id: 4, title: "Deploy", completed: true, priority: "medium" }
];

// 1. Hitung jumlah task selesai — acc berupa angka
let jumlahSelesai = tasks.reduce(
  (acc, task) => acc + (task.completed ? 1 : 0), // akumulasi +1 jika selesai
  0                                              // nilai awal acc = 0
);
console.log(jumlahSelesai); // 2

// 2. Kelompokkan task per priority — acc berupa object
let perPriority = tasks.reduce((acc, task) => {
  acc[task.priority] = (acc[task.priority] || 0) + 1; // tambah hitungan
  return acc;                                          // wajib return acc
}, {});                                                // awal = object kosong
console.log(perPriority); // { high: 2, low: 1, medium: 1 }

// 3. Kumpulkan judul task selesai — acc berupa array
let judulSelesai = tasks
  .filter(t => t.completed)
  .reduce((acc, t) => [...acc, t.title], []); // spread acc, lalu tambah judul
console.log(judulSelesai); // [ 'Bikin UI', 'Deploy' ]
```

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer. Kita fokus ke `jumlahSelesai` karena accumulator-nya paling terlihat di sana.

```js
let tasks = [
  { id: 1, title: "Riset", completed: false, priority: "high" },
  { id: 2, title: "Bikin UI", completed: true, priority: "low" },
  { id: 3, title: "Testing", completed: false, priority: "high" },
  { id: 4, title: "Deploy", completed: true, priority: "medium" }
];
let jumlahSelesai = tasks.reduce(
  (acc, task) => acc + (task.completed ? 1 : 0),
  0
);
console.log(jumlahSelesai);
let perPriority = tasks.reduce((acc, task) => { acc[task.priority] = (acc[task.priority] || 0) + 1; return acc; }, {});
console.log(perPriority);
let judulSelesai = tasks.filter(t => t.completed).reduce((acc, t) => [...acc, t.title], []);
console.log(judulSelesai);
```

**Langkah 1 — baris `let tasks = [...]`**
JavaScript membuat array `tasks` berisi 4 objek.

**Langkah 2 — `reduce(..., 0)` mulai berjalan**
Sebelum putaran pertama, JavaScript menyiapkan `acc` = nilai awal, yaitu `0`. `task` belum diisi.

**Langkah 3 — putaran 1**
`acc` = `0`, `task` = objek id 1 (`completed` false → tambahannya `0`). Callback mengembalikan `0 + 0 = 0`. Sekarang `acc` berisi `0`.

**Langkah 4 — putaran 2**
`acc` = `0`, `task` = objek id 2 (`completed` true → tambahannya `1`). Callback mengembalikan `0 + 1 = 1`. `acc` kini `1`.

**Langkah 5 — putaran 3**
`acc` = `1`, `task` = objek id 3 (`completed` false → `0`). Callback mengembalikan `1 + 0 = 1`. `acc` tetap `1`.

**Langkah 6 — putaran 4**
`acc` = `1`, `task` = objek id 4 (`completed` true → `1`). Callback mengembalikan `1 + 1 = 2`. `acc` kini `2`.

Elemen sudah habis, jadi `reduce` berhenti dan mengembalikan `acc` terakhir: `2`.

| Putaran | Isi `acc` (mulai) | Isi `task` (id / completed) | Hasil callback | Isi `acc` (selesai) |
|---|---|---|---|---|
| 1 | 0 | 1 / false | 0 + 0 | 0 |
| 2 | 0 | 2 / true | 0 + 1 | 1 |
| 3 | 1 | 3 / false | 1 + 0 | 1 |
| 4 | 1 | 4 / true | 1 + 1 | 2 |

**Langkah 7 — dua ringkasan berikutnya**
`perPriority` memakai object `{}` sebagai awal; setiap putaran menambah hitungan di key priority yang sesuai, sehingga `console.log(perPriority)` menampilkan `{ high: 2, low: 1, medium: 1 }`. `judulSelesai` menyaring task yang selesai lebih dulu, lalu `reduce` dengan awal `[]` mengumpulkan judulnya, sehingga `console.log(judulSelesai)` menampilkan `[ 'Bikin UI', 'Deploy' ]`.

**Output akhir:**
```
2
{ high: 2, low: 1, medium: 1 }
[ 'Bikin UI', 'Deploy' ]
```

## Analogi
Di perpustakaan, `reduce()` seperti pustakawan yang memegang **satu buku catatan**: ia membaca buku satu per satu dari keranjang, lalu mencatat sesuatu yang berjalan di catatan itu — misalnya menambah hitungan tiap kategori. Setelah semua buku selesai dibaca, yang tersisa bukan keranjangnya, melainkan **satu angka di catatan**. Nilai awal = catatan baru yang sudah ditulis angka 0 di halaman pertama.

## Dipakai untuk Apa
- Jumlahkan/rata-ratakan nilai (total poin, total durasi task) sekaligus hitung statistik: berapa selesai, berapa belum, per kategori
- Mengelompokkan array jadi object (`{high: 2, low: 1}`)
- Mengubah array of objects jadi object satu tingkat (index by id)
- Menggantikan `map` + `filter` + `for` dalam satu langkah bila memang butuh satu hasil akhir

## Kesalahan Umum yang Sering Terjadi
- **Lupa `return acc`**: callback dengan kurawal `{ acc[...] = ... }` tanpa `return` membuat accumulator jadi `undefined` di putaran berikutnya → hasil `undefined` atau error. Hindari: tulis `return acc;`, atau pakai kurung kurawal implisit.
- **Tidak memberi nilai awal**: `reduce` tanpa `initialValue` memakai elemen pertama sebagai awal; jika array **kosong** tanpa nilai awal, muncul **TypeError**. Hindari: selalu tulis nilai awal (`0`, `{}`, `[]`).
- **Mengembalikan nilai baru tanpa menyentuh acc (untuk object)**: menulis `acc[task.priority]++` tanpa mengembalikan `acc` juga membuat hasilnya salah. Kunci utamanya: callback harus **mengembalikan** nilai acc untuk putaran berikutnya.
- **Memakai `reduce` untuk hal sederhana**: mengubah tiap elemen tetap lebih jelas dengan `map` (materi 75), menyaring dengan `filter` (materi 76). `reduce` tepatnya untuk **meringkas jadi satu nilai**.

## Soal Latihan & Jawaban
### Soal
Dari array `tasks`, gunakan `reduce` untuk membuat satu object ringkasan berbentuk `{ total: <jumlah semua task>, selesai: <yang completed true>, belum: <yang completed false> }` dengan nilai awal accumulator `{ total: 0, selesai: 0, belum: 0 }`. Tampilkan hasilnya.

### Jawaban
```js
let tasks = [
  { id: 1, title: "Riset", completed: false, priority: "high" },
  { id: 2, title: "Bikin UI", completed: true, priority: "low" },
  { id: 3, title: "Testing", completed: false, priority: "high" },
  { id: 4, title: "Deploy", completed: true, priority: "medium" }
];
// Satu object ringkasan dibangun dari seluruh elemen array
let ringkasan = tasks.reduce(
  (acc, task) => {
    acc.total += 1; // setiap task dihitung ke total
    acc[task.completed ? "selesai" : "belum"] += 1; // cabut hitungan sesuai status
    return acc; // wajib dikembalikan untuk putaran berikutnya
  },
  { total: 0, selesai: 0, belum: 0 } // nilai awal accumulator
);
console.log(ringkasan);
// { total: 4, selesai: 2, belum: 2 }
console.log(tasks.length); // 4 — array asal tidak berubah
```
