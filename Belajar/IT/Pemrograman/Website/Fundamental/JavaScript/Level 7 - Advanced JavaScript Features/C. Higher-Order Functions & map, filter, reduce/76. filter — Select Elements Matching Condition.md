# filter — Select Elements Matching Condition

## Penjelasan
`filter()` adalah method array yang menjalankan **callback** untuk setiap elemen dan **menyimpan elemen yang menghasilkan `true`**. Hasilnya berupa array baru yang hanya berisi elemen lulus uji — elemen yang `false` dibuang, elemen asal tidak disentuh.

- Syntax: `array.filter((element, index) => trueAtauFalse)`
- Callback harus menghasilkan **boolean** (`true`/`false`); nilai non-boolean ikut lolos jika nilainya truthy (misalnya angka bukan 0)
- Panjang hasil **bisa lebih pendek** dari array asal (bahkan kosong `[]` jika tidak ada yang lulus)
- Array asal **tidak pernah diubah**
- Seperti `map`, `filter` adalah **higher-order function** (menerima function sebagai parameter)

Ingat bedanya: `map` mengubah **semua** elemen (panjang tetap), `filter` memilih **sebagian** elemen (panjang bisa berkurang).

## Fungsi
Kebutuhan "tampilkan hanya task yang belum selesai" atau "cari task prioritas high" ada di hampir setiap fitur Task Manager. Tanpa `filter`, kamu harus membuat array kosong, lalu `push` elemen yang lulus kondisi di dalam loop — boilerplate yang selalu sama tiap kali.

`filter` meringkasnya jadi satu ekspresi yang jelas niatnya: *"yang begini saja"*. Hasil berupa array baru membuat data asli aman untuk dirender ulang berkali-kali.

## Cara Pengimplementasian / Code
```js
// Konteks Task Manager: array of task objects
let tasks = [
  { id: 1, title: "Riset", completed: false, priority: "high" },
  { id: 2, title: "Bikin UI", completed: true, priority: "low" },
  { id: 3, title: "Testing", completed: false, priority: "high" },
  { id: 4, title: "Deploy", completed: false, priority: "medium" }
];

// 1. Task yang belum selesai
let pending = tasks.filter(task => !task.completed);
console.log(pending.map(t => t.title)); // [ 'Riset', 'Testing', 'Deploy' ]

// 2. Kondisi gabungan: prioritas high DAN belum selesai
let urgent = tasks.filter(t => t.priority === "high" && !t.completed);
console.log(urgent.map(t => t.id)); // [ 1, 3 ]

// 3. Chain: filter dulu, baru map — hasil akhir berupa array string
let judulPending = tasks
  .filter(t => !t.completed)
  .map(t => t.title.toUpperCase());
console.log(judulPending);
```

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer. Fokus ke `pending`, lalu dua baris sesudahnya.

```js
let tasks = [
  { id: 1, title: "Riset", completed: false, priority: "high" },
  { id: 2, title: "Bikin UI", completed: true, priority: "low" },
  { id: 3, title: "Testing", completed: false, priority: "high" },
  { id: 4, title: "Deploy", completed: false, priority: "medium" }
];
let pending = tasks.filter(task => !task.completed);
console.log(pending.map(t => t.title));
let urgent = tasks.filter(t => t.priority === "high" && !t.completed);
console.log(urgent.map(t => t.id));
let judulPending = tasks
  .filter(t => !t.completed)
  .map(t => t.title.toUpperCase());
console.log(judulPending);
```

**Langkah 1 — baris `let tasks = [...]`**
JavaScript membuat array `tasks` berisi 4 objek.

**Langkah 2 — `tasks.filter(...)` mulai berjalan**
`filter` membuat wadah array baru (masih kosong). Ia memanggil callback untuk elemen pertama.

**Langkah 3 — callback jalan untuk task id 1**
`task.completed` berisi `false`, jadi `!task.completed` = `true`. Karena `true`, objek id 1 **disalin ke array hasil**.

**Langkah 4 — callback jalan untuk task id 2**
`task.completed` berisi `true`, jadi `!task.completed` = `false`. Karena `false`, objek id 2 **dilewati**. Array hasil tetap berisi 1 objek.

**Langkah 5 — callback jalan untuk task id 3 dan 4**
Id 3: `completed` `false` → `true` → disalin. Id 4: `completed` `false` → `true` → disalin. Array hasil kini berisi 3 objek.

**Langkah 6 — `filter` selesai**
Ia mengembalikan array `[task1, task3, task4]` ke variabel `pending`. Lalu `pending.map(t => t.title)` mengubahnya jadi judul-judulnya saja, dan `console.log` menampilkan `[ 'Riset', 'Testing', 'Deploy' ]`.

| Putaran | Isi `task` (id / completed) | Nilai callback `!completed` | Keputusan | Isi `pending` sesudahnya |
|---|---|---|---|---|
| 1 | 1 / false | true | simpan | [task1] |
| 2 | 2 / true | false | lewati | [task1] |
| 3 | 3 / false | true | simpan | [task1, task3] |
| 4 | 4 / false | true | simpan | [task1, task3, task4] |

**Langkah 7 — baris `let urgent = tasks.filter(...)`**
Callback yang sama dijalankan lagi dengan syarat ganda: `priority === "high"` **dan** belum selesai. Hanya id 1 dan id 3 yang lulus, jadi `console.log(urgent.map(t => t.id))` menampilkan `[ 1, 3 ]`.

**Langkah 8 — baris chain `judulPending = tasks.filter(...).map(...)`**
`filter` berjalan seperti Langkah 3-6 (hasilnya lagi-lagi `[task1, task3, task4]`), lalu array hasil itu langsung masuk ke `map` yang mengubah tiap judul jadi huruf kapital. `console.log` terakhir menampilkan `[ 'RISET', 'TESTING', 'DEPLOY' ]`.

**Output akhir:**
```
[ 'Riset', 'Testing', 'Deploy' ]
[ 1, 3 ]
[ 'RISET', 'TESTING', 'DEPLOY' ]
```

## Analogi
Di perpustakaan, `filter()` seperti pustakawan yang menelusuri rak buku lalu menarik keluar **hanya buku yang memenuhi syarat** — misalnya yang sudah lewat tempo — dan menumpukkannya di meja samping. Rak asal tetap penuh seperti semula; yang di meja hanyalah salinan daftar yang lulus uji.

## Dipakai untuk Apa
- Menampilkan task belum selesai (`!completed`)
- Menyaring task berdasarkan prioritas atau kategori
- Fitur pencarian: cocokkan `title` dengan kata kunci (`includes`)
- Membersihkan data array sebelum dikirim ke server atau dirender
- Menghapus item yang sudah tidak valid sebelum perhitungan

## Kesalahan Umum yang Sering Terjadi
- **Lupa `return` atau salah blok**: menulis `filter(t => { t.completed; })` membuat **semua elemen dibuang**, karena blok tanpa `return` menghasilkan `undefined` (falsy). Hindari: `t => t.completed` tanpa kurawal.
- **Mengira hasil `filter` selalu ada isinya**: jika tidak ada elemen yang lulus, hasilnya `[]` (array kosong), bukan `undefined`. Kode seperti `hasil[0].title` akan error — cek dulu panjangnya.
- **`filter` dipakai untuk mengubah**: `filter` tidak pernah mengubah isi elemen. Kalau mau mengubah bentuk elemen, sambungkan dengan `map` (materi 75) setelahnya.
- **Kondisi tertukar**: `tasks.filter(t => t.completed)` mengambil yang **sudah** selesai; `!t.completed` mengambil yang **belum**. Nilai boolean yang terbalik membuat hasil terlihat "janggal" tanpa error.

## Soal Latihan & Jawaban
### Soal
Dari array `tasks` yang tersedia, buat dua array baru:
- `taskMendesak` = task yang `priority === "high"` DAN `completed === false`
- `judulMendesak` = hanya judul dari `taskMendesak`, dalam huruf kapital

Tampilkan kedua hasilnya dan buktikan `tasks` asli tidak berubah.

### Jawaban
```js
let tasks = [
  { id: 1, title: "Riset", completed: false, priority: "high" },
  { id: 2, title: "Bikin UI", completed: true, priority: "low" },
  { id: 3, title: "Testing", completed: false, priority: "high" },
  { id: 4, title: "Deploy", completed: false, priority: "medium" }
];

// Saring dengan dua kondisi sekaligus (AND logika)
let taskMendesak = tasks.filter(t => t.priority === "high" && !t.completed);

// Hasil filter di-chain ke map untuk mengubah bentuknya
let judulMendesak = taskMendesak.map(t => t.title.toUpperCase());

console.log(taskMendesak.map(t => t.id)); // [ 1, 3 ]
console.log(judulMendesak);
// [ 'RISET', 'TESTING' ]
console.log(tasks.length);   // 4 — array asal utuh
console.log(tasks[0].completed); // false — tidak berubah
```
