# map — Transform Array Elements

## Penjelasan
`map()` adalah method array yang menjalankan sebuah **callback** (fungsi kecil yang kita berikan) untuk **setiap elemen**, lalu mengumpulkan hasilnya ke dalam **array baru**. Posisi elemen di array hasil selalu sejajar dengan posisi elemen asal.

- Syntax: `array.map((element, index) => nilaiBaru)`
- Callback wajib mengembalikan nilai (`return`) — nilai itulah yang jadi isi array hasil
- Panjang array hasil **selalu sama** dengan array asal
- Array asal **tidak pernah diubah** (tidak mutate)
- `map` adalah contoh **higher-order function**: yaitu function yang menerima function sebagai parameter

Penting dibedakan: `map` **mengubah bentuk** semua elemen. Kalau tujuanmu **memilih sebagian** elemen, itu pekerjaan `filter` (materi 76).

## Fungsi
Tanpa `map`, mengubah isi array harus pakai `for` loop manual: buat array kosong, hitung index, `push` satu-satu, dan menjaga index tidak salah. Semua itu bisa salah tempat dengan mudah.

`map` meringkasnya jadi satu baris yang fokus pada "apa yang diubah", bukan pada mekanisme loop. Karena hasilnya array baru, data mentah tetap utuh — bagus untuk state aplikasi seperti daftar task.

## Cara Pengimplementasian / Code
```js
// Konteks Task Manager: array of task objects
let tasks = [
  { id: 1, title: "belajar js", completed: false, priority: "high" },
  { id: 2, title: "bikin ui", completed: true, priority: "low" },
  { id: 3, title: "testing", completed: false, priority: "medium" }
];

// 1. Ambil semua judul — objek → string
let titles = tasks.map(task => task.title);
console.log(titles); // [ "belajar js", "bikin ui", "testing" ]

// 2. Ubah data tanpa menyentuh array asal (immutability)
let tasksWithStatus = tasks.map(task => ({
  ...task,                          // salin semua isi task
  status: task.completed ? "done" : "todo"  // tambah field baru
}));
console.log(tasksWithStatus[0].status); // "todo"
console.log(tasks[0].status);           // undefined — asli tidak berubah

// 3. Chain dua map: hasil map pertama jadi input map kedua
let rapi = tasks
  .map(task => task.title)
  .map(title => title.toUpperCase());
console.log(rapi); // [ "BELAJAR JS", "BIKIN UI", "TESTING" ]
```
Cara menjalankan: simpan kode di atas ke file `level7.js`, lalu muat dari `level7.html` (pakai `<script src="level7.js"></script>`), buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer. Fokus ke `titles`, `tasksWithStatus`, dan `rapi`.

```js
let tasks = [
  { id: 1, title: "belajar js", completed: false, priority: "high" },
  { id: 2, title: "bikin ui", completed: true, priority: "low" },
  { id: 3, title: "testing", completed: false, priority: "medium" }
];
let titles = tasks.map(task => task.title);
console.log(titles);
let tasksWithStatus = tasks.map(task => ({
  ...task,
  status: task.completed ? "done" : "todo"
}));
console.log(tasksWithStatus[0].status);
console.log(tasks[0].status);
let rapi = tasks.map(t => t.title).map(title => title.toUpperCase());
console.log(rapi);
```

**Langkah 1 — baris `let tasks = [...]`**
JavaScript membuat array `tasks` berisi 3 objek.

**Langkah 2 — `tasks.map(task => task.title)` mulai berjalan**
`map` membuat wadah array baru (masih kosong), lalu memanggil callback satu per satu.

**Langkah 3 — callback jalan untuk elemen pertama**
`task` berisi `{ id: 1, title: "belajar js", ... }`. Callback mengembalikan `"belajar js"`. Array hasil kini berisi 1 elemen.

**Langkah 4 — callback jalan untuk elemen kedua dan ketiga**
`task` berisi objek id 2 → menghasilkan `"bikin ui"`. Lalu id 3 → `"testing"`. Callback selesai untuk semua elemen, `map` mengembalikan array hasil ke `titles`, dan `console.log(titles)` menampilkan ketiga judul.

**Langkah 5 — baris `let tasksWithStatus = tasks.map(task => ({...}))`**
Callback mengembalikan object hasil salinan (`...task`) plus field `status`: id 1 dan 3 jadi `"todo"`, id 2 jadi `"done"`. `console.log(tasksWithStatus[0].status)` menampilkan `todo`. Variabel `tasks[0].status` tidak ada karena array asli tidak pernah diubah, jadi `console.log` berikutnya menampilkan `undefined`.

**Langkah 6 — baris `rapi = tasks.map(...).map(...)`**
Map pertama berjalan persis seperti Langkah 3-4, menghasilkan `["belajar js", "bikin ui", "testing"]`. Array hasil itu **langsung diserahkan** ke map kedua sebagai inputnya.

**Langkah 7 — map kedua mengubah tiap string**
Callback `title => title.toUpperCase()` dijalankan untuk tiap judul: `"belajar js"` → `"BELAJAR JS"`, dst. `console.log(rapi)` terakhir menampilkan hasilnya.

| Putaran | Isi `task` / `title` | Hasil callback map 1 | Hasil callback map 2 |
|---|---|---|---|
| 1 | id 1 / "belajar js" | "belajar js" | "BELAJAR JS" |
| 2 | id 2 / "bikin ui" | "bikin ui" | "BIKIN UI" |
| 3 | id 3 / "testing" | "testing" | "TESTING" |

**Output akhir:**
```
[ 'belajar js', 'bikin ui', 'testing' ]
'todo'
undefined
[ 'BELAJAR JS', 'BIKIN UI', 'TESTING' ]
```

## Analogi
Di perpustakaan, `map()` seperti pustakawan yang menyalin daftar judul buku ke kartu katalog baru satu per satu — posisi kartu menyesuaikan posisi buku di rak, dan sekaligus merapikan tulisannya. Rak buku asli (array asal) tetap utuh; pustakawan hanya membuat daftar versi barunya.

## Dipakai untuk Apa
- Mengambil satu field dari array of objects (semua `title`, semua `id`)
- Menambahkan field turunan (`status`, `label tampilan`) untuk dirender
- Menyiapkan data API: array objek → array ringkas untuk dikirim
- Meneruskan hasil ke `filter`/`sort` lewat chaining

## Kesalahan Umum yang Sering Terjadi
- **Lupa `return` di callback**: menulis `tasks.map(t => { t.title.toUpperCase() })` dengan kurawal tapi tanpa `return` membuat array hasil berisi `undefined` semua. Hindari: pakai `t => t.title.toUpperCase()` (tanpa kurawal) atau tulis `return` eksplisit.
- **Mengira `map` mengubah array asal**: hasil `map` hilang kalau tidak disimpan. Kalau memang mau mengubah, tulis `tasks = tasks.map(...)`.
- **Memakai `map` untuk menyaring**: hasil `map` selalu sepanjang array asal. Memilih sebagian elemen = `filter` (materi 76).
- **Mengembalikan objek tanpa kurung**: menulis `map(t => { ...t, status: "done" })` adalah SyntaxError, karena kurawal dianggap blok. Hindari: `map(t => ({ ...t, status: "done" }))`.

## Soal Latihan & Jawaban
### Soal
Dari array `tasks`, buat array baru `labelTask` berisi string `"#<id> <TITLE HURUF KAPITAL> (<priority>)"` untuk setiap task, contoh hasil pertama: `"#1 BELAJAR JS (high)"`. Tunjukkan juga bahwa array `tasks` asli tidak berubah sama sekali.

### Jawaban
```js
let tasks = [
  { id: 1, title: "belajar js", completed: false, priority: "high" },
  { id: 2, title: "bikin ui", completed: true, priority: "low" },
  { id: 3, title: "testing", completed: false, priority: "medium" }
];

// Transform tiap objek task menjadi satu string rapi
let labelTask = tasks.map(task =>
  `#${task.id} ${task.title.toUpperCase()} (${task.priority})`
);

console.log(labelTask);
// [ '#1 BELAJAR JS (high)', '#2 BIKIN UI (low)', '#3 TESTING (medium)' ]

console.log(tasks[0].title); // "belajar js" — array asal tetap utuh
console.log(tasks.length);   // 3 — panjang tidak berubah
```
