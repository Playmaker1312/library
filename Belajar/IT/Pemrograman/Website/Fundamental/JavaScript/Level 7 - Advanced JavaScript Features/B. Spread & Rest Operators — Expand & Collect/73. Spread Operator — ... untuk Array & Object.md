# Spread Operator — ... untuk Array & Object

## Penjelasan
Spread operator adalah tiga titik `...` yang **membentangkan (expand)** isi array atau object di dalam sintaks baru — jadi elemennya "terhambur" satu per satu, bukan terbawa sebagai satu nilai utuh.

- Array: `[...arr1, ...arr2]` menggabungkan dua array jadi satu
- Object: `{...obj1, ...obj2}` menggabungkan dua object; key yang sama → **yang belakang menang**
- Salinan dangkal (shallow copy): `[...arr]` dan `{...obj}` membuat salinan baru tanpa menyentuh aslinya
- Bisa dicampur dengan nilai biasa: `[...tasks, taskBaru]`
- Salinan hanya **satu lapis** — object bersarang di dalamnya tetap berupa rujukan yang sama

## Fungsi
Sebelum spread, menggabungkan array harus `push` satu-satu dalam loop, dan menyalin object harus `for...in` atau `Object.assign` yang lebih panjang. Spread menyelesaikan ketiganya (gabung, salin, sisipkan) dalam satu baris yang gampang dibaca.

Untuk aplikasi seperti Task Manager, spread sangat penting karena kamu sering **tidak boleh mengubah array asal**: bikin salinan, tambahkan task baru di salinan itu, lalu tampilkan. State jadi lebih aman dan mudah dites.

## Cara Pengimplementasian / Code
```js
// Konteks Task Manager: array dan object task
const tugasSelesai = [
  { id: 1, title: "Setup" },
  { id: 2, title: "Styling" }
];
const tugasBaru = { id: 3, title: "Testing" };

// 1. Spread array — gabung dua array jadi satu
const semuaTugas = [...tugasSelesai, tugasBaru];
console.log(semuaTugas.length); // 3

// 2. Salinan array dangkal, array asal tidak berubah
const salinan = [...tugasSelesai];
salinan.push({ id: 4, title: "Rilis" });
console.log(tugasSelesai.length); // tetap 2

// 3. Spread object — merge dua object (key sama: yang belakang menang)
const task = { id: 1, title: "Belajar", completed: false, priority: "low" };
const update = { priority: "high", completed: true };
const hasilUpdate = { ...task, ...update };
console.log(hasilUpdate);
// { id: 1, title: "Belajar", completed: true, priority: "high" }

// 4. Ubah satu field tanpa merusak object asal (pola update state)
const taskBaruVersi = { ...task, completed: true };
console.log(task.completed); // false — asli tetap utuh
```

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

```js
const tugasSelesai = [{ id: 1, title: "Setup" }, { id: 2, title: "Styling" }];
const tugasBaru = { id: 3, title: "Testing" };
const semuaTugas = [...tugasSelesai, tugasBaru];
console.log(semuaTugas.length);
const salinan = [...tugasSelesai];
salinan.push({ id: 4, title: "Rilis" });
console.log(tugasSelesai.length);
const task = { id: 1, title: "Belajar", completed: false, priority: "low" };
const update = { priority: "high", completed: true };
const hasilUpdate = { ...task, ...update };
console.log(hasilUpdate);
const taskBaruVersi = { ...task, completed: true };
console.log(task.completed);
```

**Langkah 1 — baris `const tugasSelesai = [...]` dan `const tugasBaru = {...}`**
JavaScript membuat array berisi 2 object, lalu object `tugasBaru` dengan `id` = `3`.

**Langkah 2 — baris `const semuaTugas = [...tugasSelesai, tugasBaru]`**
Isi `tugasSelesai` dibentangkan satu per satu (posisi 1 dan 2), lalu `tugasBaru` menyusul di posisi 3. `semuaTugas` kini berisi 3 object, dan `console.log(semuaTugas.length)` menampilkan `3`. Array `tugasSelesai` asli tidak berubah.

**Langkah 3 — baris `const salinan = [...tugasSelesai]`**
Dibuat salinan baru berisi 2 object. `salinan.push(...)` menambah 1 object **ke salinan saja**, jadi `console.log(tugasSelesai.length)` tetap menampilkan `2`.

**Langkah 4 — baris `const task = {...}` dan `const update = {...}`**
Object `task` dibuat dengan 4 property: `id` = `1`, `title` = `"Belajar"`, `completed` = `false`, `priority` = `"low"`. Object `update` dibuat: `priority` = `"high"`, `completed` = `true`.

**Langkah 5 — baris `const hasilUpdate = { ...task, ...update }`**
JavaScript menulis ulang isi `task` satu per satu ke object baru: `id` = `1`, `title` = `"Belajar"`, `completed` = `false`, `priority` = `"low"`. Lalu `update` dibentangkan juga: key `completed` dan `priority` sudah ada, jadi nilainya **ditimpa** — `completed` jadi `true` dan `priority` jadi `"high"`.

**Langkah 6 — `console.log(hasilUpdate)`**
Menampilkan object gabungan seperti dicatat di atas.

**Langkah 7 — baris `const taskBaruVersi = { ...task, completed: true }`**
Object baru dibuat dari isi `task` (`id` 1, `title` "Belajar", `completed` false, `priority` "low"), lalu `completed` **ditimpa** jadi `true`. `task` asli tidak disentuh, jadi `console.log(task.completed)` terakhir menampilkan `false`.

| Baris | Isi object hasil | Berubahkah object asal? |
|---|---|---|
| `{...task}` | {id: 1, title: "Belajar", completed: false, priority: "low"} | tidak |
| `{...task, ...update}` | {id: 1, title: "Belajar", completed: true, priority: "high"} | tidak |
| `{...task, completed: true}` | {id: 1, title: "Belajar", completed: true, priority: "low"} | tidak |

**Output akhir:**
```
3
2
{ id: 1, title: 'Belajar', completed: true, priority: 'high' }
false
```

## Analogi
Pustakawan ingin memindahkan isi dua keranjang buku ke satu rak baru. Alih-alih memindahkan keranjangnya (yang berarti merusak keranjang asal), ia "menuang" isi keranjang pertama ke rak baru, lalu menuang isi keranjang kedua di atasnya — jika ada buku dengan kategori sama, edisi yang ditaruh terakhir menjadi yang dipajang. Keranjang lama tetap penuh dan utuh.

## Dipakai untuk Apa
- Menggabungkan dua array (misalnya daftar task lama + task impor)
- Menyalin array/object sebelum dimodifikasi (immutability)
- Update satu field object tanpa mengubah object asal
- Menyisipkan nilai ke tengah array: `[awal, ...baru, akhir]`
- Menggabungkan beberapa object konfigurasi jadi satu

## Kesalahan Umum yang Sering Terjadi
- **Mengira spread membuat salinan dalam-dalam (deep copy)**: `{...task}` menyalin property lapis pertama saja; jika `task.owner` berupa object, salinan dan asal tetap menunjuk object yang sama. Hindari: `JSON.parse(JSON.stringify(...))` untuk data polos (materi 32).
- **Salah urutan saat merge**: `{...update, ...task}` menghasilkan hasil berbeda karena **yang belakang menang**. Jika ingin data asli tidak boleh ditimpa, `task` harus paling akhir.
- **Menggunakan `...` di tempat yang salah**: menulis `const x = ...tasks;` (tanpa kurung) adalah SyntaxError. Spread array harus di dalam `[ ]`, object di dalam `{ }` atau saat memanggil function.
- **Lupa bahwa spread tidak mengubah aslinya**: sering kali orang menulis `tasks.push(...baru)` lalu heran data lama ikut bertambah. Kalau mau array asal berubah, itu memang `push`; kalau tidak, simpan hasil spread-nya ke variabel baru.

## Soal Latihan & Jawaban
### Soal
Diberikan:
```js
const daftarLama = [{ id: 1, title: "Riset" }, { id: 2, title: "Desain" }];
const taskImpor = [{ id: 3, title: "Analisa" }];
const profil = { nama: "Andi", tema: "gelap" };
const preferensi = { tema: "terang", notif: true };
```
Buat: (a) `daftarGabung` = gabungan kedua array + `{ id: 4, title: "Dokumentasi" }`, tanpa mengubah `daftarLama`; (b) `profilAkhir` = merge `profil` dan `preferensi` dengan `profil` sebagai pemenang untuk key yang sama. Tampilkan panjang `daftarLama`, isi `daftarGabung`, dan `profilAkhir`.

### Jawaban
```js
const daftarLama = [{ id: 1, title: "Riset" }, { id: 2, title: "Desain" }];
const taskImpor = [{ id: 3, title: "Analisa" }];
const profil = { nama: "Andi", tema: "gelap" };
const preferensi = { tema: "terang", notif: true };

// (a) Spread dua array, lalu sisipkan task baru — daftarLama tidak disentuh
const daftarGabung = [...daftarLama, ...taskImpor, { id: 4, title: "Dokumentasi" }];

// (b) Profil paling akhir, jadi key "tema" tetap "gelap"
const profilAkhir = { ...preferensi, ...profil };

console.log(daftarLama.length); // 2 — asli tetap utuh
console.log(daftarGabung);
// [ {id:1,...}, {id:2,...}, {id:3, title:'Analisa'}, {id:4, title:'Dokumentasi'} ]
console.log(profilAkhir);
// { tema: 'gelap', notif: true, nama: 'Andi' } — key "tema" tetap "gelap"
```
