# Rest Parameter — ... untuk Function Arguments

## Penjelasan
Rest parameter adalah tiga titik `...` di **parameter function** yang mengumpulkan semua argumen berlebih jadi satu array. Kebalikan dari spread (yang membentarkan), rest **mengumpulkan**.

- Syntax: `function fn(...args) { ... }` — `args` berupa array, meski argumennya ditulis terpisah
- Rest harus **paling akhir** di daftar parameter: `function fn(a, ...sisa)`
- Argumen yang tidak masuk rest (parameter biasa di depannya) tetap diambil dulu sesuai urutan
- Kalau tidak ada argumen sama sekali yang tersisa, rest berisi array kosong `[]`
- Beda dengan objek bawaan `arguments` (lawas & bukan array); rest parameter langsung array sungguhan

## Fungsi
Ada function yang jumlah inputnya tidak pasti: penjumlahan 3 atau 30 angka, sapaan untuk 1 atau 5 nama. Sebelum rest parameter, kamu harus mengelola objek bawaan `arguments` yang bukan array (tidak bisa langsung `map`, `filter`, atau `reduce`).

Rest parameter menyelesaikannya: daftar argumen berubah jadi array biasa, sehingga semua method array langsung bisa dipakai.

## Cara Pengimplementasian / Code
```js
// Konteks Task Manager

// 1. Kumpulkan semua argumen jadi satu array bernama numbers
function jumlahkan(...numbers) {
  let total = 0;
  numbers.forEach(n => total += n); // numbers adalah array biasa
  return total;
}
console.log(jumlahkan(1, 2, 3, 4, 5)); // 15
console.log(jumlahkan(10, 20));         // 30

// 2. Parameter biasa di depan, sisanya masuk rest
function sapa(greeting, ...names) {
  names.forEach(n => console.log(greeting + " " + n));
}
sapa("Halo", "Andi", "Budi", "Citra");
// Halo Andi / Halo Budi / Halo Citra

// 3. Tanpa argumen tambahan → rest jadi array kosong
console.log(sapa("Halo")); // tidak ada nama yang disapa
```

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

```js
function jumlahkan(...numbers) {
  let total = 0;
  numbers.forEach(n => total += n);
  return total;
}
console.log(jumlahkan(1, 2, 3, 4, 5));
console.log(jumlahkan(10, 20));

function sapa(greeting, ...names) {
  names.forEach(n => console.log(greeting + " " + n));
}
sapa("Halo", "Andi", "Budi", "Citra");
console.log(sapa("Halo"));
```

**Langkah 1 — baris `function jumlahkan(...numbers)`**
Function didefinisikan. Tanda `...` di parameter memberi tahu JavaScript: semua argumen yang masuk akan dikumpulkan jadi array bernama `numbers`.

**Langkah 2 — `jumlahkan(1, 2, 3, 4, 5)` mulai berjalan**
Function dipanggil dengan 5 angka. JavaScript mengumpulkannya: `numbers` kini berisi array `[1, 2, 3, 4, 5]`.

**Langkah 3 — baris `let total = 0`**
Wadah `total` dibuat, isinya `0`.

**Langkah 4 — `numbers.forEach(...)` jalan 5 kali**
Setiap putaran menambahkan `n` ke `total`. Lihat tabel iterasinya:

| Putaran | Isi `n` | `total` setelah `total += n` |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 2 | 3 |
| 3 | 3 | 6 |
| 4 | 4 | 10 |
| 5 | 5 | 15 |

**Langkah 5 — baris `return total` dan `console.log(...)`**
Function mengembalikan `15` ke tempat pemanggilan, lalu `console.log` menampilkan `15`.

**Langkah 6 — baris `console.log(jumlahkan(10, 20))`**
Pemanggilan kedua mengisi `numbers` = `[10, 20]`. Perulangan yang sama menghasilkan `total` = `30`, dan `console.log` menampilkan `30`.

**Langkah 7 — baris `sapa("Halo", "Andi", "Budi", "Citra")`**
`greeting` diisi `"Halo"` lebih dulu (parameter biasa), sisanya masuk rest: `names` = `["Andi", "Budi", "Citra"]`. Perulangan menampilkan tiga baris sapaan.

**Langkah 8 — baris `console.log(sapa("Halo"))`**
Tanpa argumen tambahan, `names` berisi array kosong `[]`, jadi tidak ada sapaan yang ditampilkan. Function tidak mengembalikan nilai apa pun, sehingga `console.log` menampilkan `undefined`.

**Output akhir:**
```
15
30
Halo Andi
Halo Budi
Halo Citra
undefined
```
*(baris terakhir dari `console.log(sapa("Halo"))` — `names` kosong, tidak ada yang disapa, dan function tidak mengembalikan nilai)*

## Analogi
Seperti formulir pendaftaran anggota perpustakaan yang punya satu kolom wajib (misalnya "Nama"), lalu disusul kolom terbuka "Anggota keluarga lain: ....". Berapa pun jumlah nama tambahan yang ditulis, semuanya terkumpul di satu kolom yang sama — dan kalau tidak ada, kolomnya saja yang kosong.

## Dipakai untuk Apa
- Function penjumlahan/rata-rata dengan jumlah angka bebas
- Menyapa banyak nama atau mengirim notifikasi ke banyak penerima
- Membuat utility generic seperti `console.log` yang menerima argumen sebanyak apa pun
- Meneruskan seluruh argumen ke function lain (`fn(...args)`)

## Kesalahan Umum yang Sering Terjadi
- **Rest bukan di posisi terakhir**: `function fn(...data, terakhir)` adalah **SyntaxError**. Satu rest hanya boleh dan harus paling akhir.
- **Menyamakan rest dengan spread**: keduanya tulisannya sama (`...`), tapi beda peran. Di **parameter** = rest (mengumpulkan); di **array/object/pemanggilan** = spread (membentarkan). Salah tempat → error atau hasil tak terduga.
- **Mengira rest selalu terisi**: memanggil `jumlahkan()` tanpa argumen membuat `numbers` = `[]`, sehingga fungsi mengembalikan `0` (atau nilai default-mu). Sediakan penanganan untuk input kosong.
- **Mengakses `arguments` seperti array**: objek bawaan `arguments` tidak punya method array. Kalau butuh array, pakai rest parameter.

## Soal Latihan & Jawaban
### Soal
Buat function bernama `rekapPrioritas` yang parameter pertamanya berupa string, lalu sisanya dikumpulkan dengan rest. Fungsi harus menampilkan `<string> diikuti: <nama1>, <nama2>, ...`. Contoh pemanggilan: `rekapPrioritas("Task high", "Login", "Bayar", "Integrasi")`. Lalu uji juga tanpa argumen tambahan dan pastikan tidak error.

### Jawaban
```js
// greeting = parameter biasa, task = rest parameter (mengumpulkan sisanya)
function rekapPrioritas(greeting, ...task) {
  // task selalu berupa array, jadi method array aman dipakai
  console.log(greeting + " diikuti: " + task.join(", "));
}

rekapPrioritas("Task high", "Login", "Bayar", "Integrasi");
// Task high diikuti: Login, Bayar, Integrasi

rekapPrioritas("Task urgent");
// Task urgent diikuti:  (task = [], join → string kosong, tidak error)
```
