# Object Destructuring — Extract Object Properties

## Penjelasan
Object destructuring adalah cara mengambil isi property object ke dalam variabel terpisah dalam satu baris, tanpa menulis `obj.prop` berulang kali. Beda dengan array, di sini yang menentukan adalah **nama key-nya**, bukan urutan.

- Syntax dasar: `const {id, title} = task;` — nama variabel harus sama dengan nama key
- Ganti nama variabel: `const {title: judul} = task;` — `judul` berisi nilai `task.title`
- Nilai awal: `const {priority = "normal"} = task;` — dipakai jika `priority` berupa `undefined`
- Kumpulkan sisa property: `const {id, ...others} = task;` — `others` berupa object baru
- Ambil bersarang (nested): `const {author: {name}} = data;` — langsung masuk ke dalam
- Object asal tidak ikut berubah

## Fungsi
Di Task Manager, hampir semua data berupa object task. Tanpa destructuring, kode dipenuhi `task.title`, `task.priority`, `task.completed` yang bikin kalimat panjang dan berulang. Destructuring memangkasnya jadi beberapa nama variabel yang jelas sekali baca.

Fitur rename-nya juga penting: kadang nama key di data tidak cocok dengan nama variabel yang kamu mau pakai, dan destructuring membereskan itu tanpa assignment tambahan.

## Cara Pengimplementasian / Code
```js
// Konteks Task Manager: satu object task
const task = { id: 1, title: "Belajar", completed: false, priority: "high" };

// 1. Ambil property berdasarkan nama key
const { id, title } = task;
console.log(id, title); // 1, "Belajar"

// 2. Rename: {keyLama: namaBaru}
const { title: taskTitle } = task;
console.log(taskTitle); // "Belajar"

// 3. Default value kalau key tidak ada di object
const { category = "umum" } = task;
console.log(category); // "umum"

// 4. Rest ... mengumpulkan sisa property jadi object baru
const { id: taskId, ...others } = task;
console.log(taskId);   // 1
console.log(others);   // { title: "Belajar", completed: false, priority: "high" }

// 5. Nested destructuring — object bersarang
const detail = { owner: { name: "Andi", role: "admin" } };
const { owner: { name } } = detail;
console.log(name); // "Andi"
```
Cara menjalankan: simpan kode di atas ke file `level7.js`, lalu muat dari `level7.html` (pakai `<script src="level7.js"></script>`), buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

```js
const task = { id: 1, title: "Belajar", completed: false, priority: "high" };
const { id, title } = task;
console.log(id, title);
const { title: taskTitle } = task;
console.log(taskTitle);
const { category = "umum" } = task;
console.log(category);
const { id: taskId, ...others } = task;
console.log(taskId);
console.log(others);
const detail = { owner: { name: "Andi", role: "admin" } };
const { owner: { name } } = detail;
console.log(name);
```

**Langkah 1 — baris `const task = {...}`**
JavaScript membuat object `task` dengan 4 property: `id` = `1`, `title` = `"Belajar"`, `completed` = `false`, `priority` = `"high"`.

**Langkah 2 — baris `const { id, title } = task;`**
JavaScript mencari key bernama `id` di `task`, lalu menyalin nilainya ke variabel `id` (jadi `1`). Lalu mencari key `title` dan menyalinkannya ke variabel `title` (jadi `"Belajar"`). Object `task` sendiri tidak berubah.

**Langkah 3 — `console.log(id, title)`**
Menampilkan `1 Belajar`.

**Langkah 4 — baris `const { title: taskTitle } = task;`**
Key yang dicari tetap `title`, tapi nilainya disimpan ke variabel baru: `taskTitle` berisi `"Belajar"`. `console.log(taskTitle)` berikutnya menampilkan `Belajar`.

**Langkah 5 — baris `const { category = "umum" } = task;`**
JavaScript mencari key `category` di `task`. Key itu tidak ada, jadi nilainya `undefined`, sehingga default dipakai: `category` berisi `"umum"`. `console.log(category)` menampilkan `umum`.

**Langkah 6 — baris `const { id: taskId, ...others } = task;`**
Key `id` tetap dicari, tapi nilainya masuk ke variabel baru `taskId` (isi: `1`). Sisa property yang belum diambil (`title`, `completed`, `priority`) dikumpulkan `...` ke object baru `others`. Dua `console.log` sesudahnya menampilkan `1` lalu object `others` selengkapnya.

**Langkah 7 — baris `const { owner: { name } } = detail;`**
Baris sebelumnya membuat object `detail`. Pertama JavaScript masuk ke property `owner` (isinya object `{ name: "Andi", role: "admin" }`), lalu di dalamnya mengambil key `name`. Variabel `name` kini berisi `"Andi"`, dan `console.log(name)` terakhir menampilkan `Andi`.

| Baris destructuring | Variabel yang dibuat | Isi setelah selesai |
|---|---|---|
| `{ id, title }` | id / title | 1 / "Belajar" |
| `{ title: taskTitle }` | taskTitle | "Belajar" |
| `{ category = "umum" }` | category | "umum" |
| `{ id: taskId, ...others }` | taskId / others | 1 / {title, completed, priority} |
| `{ owner: { name } }` | name | "Andi" |

**Output akhir:**
```
1 Belajar
Belajar
umum
1
{ title: 'Belajar', completed: false, priority: 'high' }
Andi
```

## Analogi
Di perpustakaan, setiap formulir anggota punya kolom bernama: `nama`, `alamat`, `noKartu`. Object destructuring seperti pustakawan yang menyalin **kolom tertentu** dari formulir ke kartu jumpaan — yang menentukan adalah **nama kolomnya**, bukan urutannya. Kolom yang tidak dicatat dimasukkan ke map terpisah (rest) supaya tidak ada data hilang.

## Dipakai untuk Apa
- Memangkas akses property berulang di dalam function (`task.title` → `title`)
- Mengubah nama key data menjadi nama variabel yang lebih enak dipakai
- Memecah object respons API jadi variabel-variabel kecil
- Menarik data bersarang (misalnya `data.user.profile.name`) jadi satu langkah

## Kesalahan Umum yang Sering Terjadi
- **Nama variabel tidak sama dengan nama key**: menulis `const { judul } = task;` padahal key-nya `title`, hasilnya `undefined` tanpa error. Hindari: `{ title: judul }` kalau mau nama baru.
- **Pakai kurung siku untuk array**: `const {a, b} = [1, 2];` menghasilkan `undefined` karena array tidak punya key `a`. Hindari: array pakai `[ ]` (materi 70).
- **Default hanya untuk `undefined`**: `const {priority = "normal"} = {priority: null};` membuat `priority` tetap `null`. Kalau mau menangani `null`, cek manual.
- **Nested destructuring terlalu dalam**: `const {a: {b: {c}}} = obj;` error jika `obj.a.b` tidak ada. Hindari: pecah jadi bertahap atau sediakan default.

## Soal Latihan & Jawaban
### Soal
Diberikan object `const task = { id: 5, title: "Review PR", completed: true, priority: "medium", owner: "budi" };`. Buat destructuring yang menghasilkan:
- `idTask` (rename dari `id`)
- `status` (rename dari `completed`)
- `levelPrioritas` (rename dari `priority`)
- `meta` (sisa semua property selain `id`, `completed`, `priority`)

Tampilkan `idTask`, `status`, `levelPrioritas`, dan `meta`.

### Jawaban
```js
const task = { id: 5, title: "Review PR", completed: true, priority: "medium", owner: "budi" };

// Rename tiga key sekaligus, sisanya terkumpul di rest
const { id: idTask, completed: status, priority: levelPrioritas, ...meta } = task;

console.log(idTask);        // 5
console.log(status);        // true
console.log(levelPrioritas); // "medium"
console.log(meta);          // { title: 'Review PR', owner: 'budi' }
```
