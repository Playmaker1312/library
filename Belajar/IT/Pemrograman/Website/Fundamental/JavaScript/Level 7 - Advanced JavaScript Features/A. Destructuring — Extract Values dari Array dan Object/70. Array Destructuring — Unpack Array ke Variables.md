# Array Destructuring — Unpack Array ke Variables

## Penjelasan
Array destructuring adalah cara membongkar isi array ke dalam beberapa variabel dalam satu baris, jadi kamu tidak perlu mengambil elemen satu per satu lewat index. Intinya: tulis nama variabel di sebelah kiri tanda `=`, dan JavaScript mengisi nilainya **berdasarkan urutan posisi**.

- Syntax dasar: `const [a, b] = array;` — tanda kurung siku di kiri menandakan sumbernya array
- Posisi variabel harus mengikuti posisi elemen; yang menentukan adalah urutan, bukan nama
- Lewati elemen dengan slot kosong: `const [a, , c] = array;`
- Kumpulkan sisanya dengan rest: `const [a, ...rest] = array;` — `rest` berupa array baru
- Beri nilai awal (default): `const [a = 10] = array;` — dipakai hanya jika elemennya `undefined`
- Array asal tidak diubah sama sekali oleh destructuring

## Fungsi
Tanpa destructuring, kamu harus menulis `antreanId[0]`, `antreanId[1]`, `antreanId[2]` — rawan salah hitung, apalagi kalau panjang array tidak pasti. Index mentah juga tidak bermakna bagi pembaca kode.

Destructuring membuat deklarasi jadi satu baris dengan nama variabel yang jelas. Pola rest-nya (`...sisa`) sangat membantu saat kamu hanya butuh beberapa elemen pertama dan tidak peduli sisanya.

## Cara Pengimplementasian / Code
```js
// Konteks Task Manager: antrean id task yang sedang diproses
const antreanId = [101, 102, 103, 104, 105];

// 1. Unpack dua elemen pertama ke dua variabel
const [pertama, kedua] = antreanId;
console.log(pertama, kedua); // 101, 102

// 2. Slot kosong = elemen dilewati (di sini 102 tidak diambil)
const [satu, , tiga] = antreanId;
console.log(satu, tiga); // 101, 103

// 3. Rest ... mengumpulkan sisa elemen jadi array baru
const [idUtama, ...antrianSisa] = antreanId;
console.log(idUtama);     // 101
console.log(antrianSisa); // [102, 103, 104, 105]

// 4. Default value dipakai saat elemennya tidak ada (undefined)
const [awal = 0] = [];
console.log(awal); // 0
```

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

```js
const antreanId = [101, 102, 103, 104, 105];
const [pertama, kedua] = antreanId;
console.log(pertama, kedua);
const [satu, , tiga] = antreanId;
console.log(satu, tiga);
const [idUtama, ...antrianSisa] = antreanId;
console.log(idUtama);
console.log(antrianSisa);
const [awal = 0] = [];
console.log(awal);
```

**Langkah 1 — baris `const antreanId = [...]`**
JavaScript membuat array berisi 5 angka. Isinya: `101, 102, 103, 104, 105`.

**Langkah 2 — baris `const [pertama, kedua] = antreanId;`**
JavaScript membaca array dari kiri ke kanan. Elemen posisi 0 (`101`) masuk ke `pertama`, elemen posisi 1 (`102`) masuk ke `kedua`. Sekarang `pertama` berisi `101` dan `kedua` berisi `102`.

**Langkah 3 — `console.log(pertama, kedua)`**
Menampilkan `101 102`.

**Langkah 4 — baris `const [satu, , tiga] = antreanId;`**
Posisi 0 (`101`) masuk ke `satu`. Slot kedua kosong, jadi `102` dilewati. Posisi 2 (`103`) masuk ke `tiga`. Sekarang `satu` = `101`, `tiga` = `103`. Baris `console.log(satu, tiga)` berikutnya menampilkan `101 103`.

**Langkah 5 — baris `const [idUtama, ...antrianSisa] = antreanId;`**
Posisi 0 masuk ke `idUtama` (`101`). Tanda `...` mengumpulkan semua sisanya: `antrianSisa` kini berupa array `[102, 103, 104, 105]`. Dua `console.log` sesudahnya menampilkan `101` lalu `[ 102, 103, 104, 105 ]`.

**Langkah 6 — baris `const [awal = 0] = [];`**
Array sumbernya kosong, jadi posisi 0 tidak berisi apa-apa (`undefined`). Karena `undefined`, JavaScript memakai nilai default: `awal` berisi `0`. Baris `console.log(awal)` terakhir menampilkan `0`.

| Baris destructuring | Variabel yang dibuat | Isi setelah selesai |
|---|---|---|
| `[pertama, kedua]` | pertama / kedua | 101 / 102 |
| `[satu, , tiga]` | satu / tiga | 101 / 103 |
| `[idUtama, ...antrianSisa]` | idUtama / antrianSisa | 101 / [102, 103, 104, 105] |
| `[awal = 0]` | awal | 0 |

**Output akhir:**
```
101 102
101 103
101
[ 102, 103, 104, 105 ]
0
```

## Analogi
Bayangkan kartu katalog perpustakaan yang berisi deretan nomor rak. Pustakawan "membongkar" deretan itu ke laci berlabel: laci pertama diisi kartu urutan pertama, laci kedua kartu urutan kedua, dan ada satu laci besar berlabel "sisa" yang menampung semua kartu setelahnya. Posisi yang menentukan isinya, bukan nama lacinya.

## Dipakai untuk Apa
- Membaca hasil `split()` yang berupa array (misalnya memisah tanggal jadi tahun, bulan, hari)
- Menukar nilai dua variabel dengan satu baris: `[a, b] = [b, a]`
- Mengambil beberapa elemen awal dari data, sisanya disimpan sebagai riwayat
- Membaca data berbasis posisi seperti koordinat `[x, y]`

## Kesalahan Umum yang Sering Terjadi
- **Salah urutan variabel**: `[judul, id] = [id, judul]` akan membuat `judul` berisi angka id. Nilai tertukar diam-diam tanpa error. Hindari: cocokkan posisi dengan urutan di array, bukan dengan nama variabel.
- **Pakai kurawal untuk array**: menulis `const {a, b} = antreanId;` menghasilkan `undefined` semua, karena array tidak punya property bernama `a`. Hindari: array pakai `[ ]`, object pakai `{ }` (materi 71).
- **Rest bukan di posisi terakhir**: `const [...sisa, terakhir] = arr;` membuat **SyntaxError**. Rest harus selalu paling akhir.
- **Salah paham default value**: default hanya dipakai saat nilainya `undefined`. Kalau elemennya `null` atau `0`, variabel tetap dapat `null`/`0`, bukan defaultnya.

## Soal Latihan & Jawaban
### Soal
Saat memproses task, sistem menyimpan info dalam satu array posisi tetap:
`const infoTask = [7, "Refactor CRUD", true, "high", "deadline besok", "tag:urgent"];`
(posisi: id, title, completed, priority, lalu sisanya catatan). Buat destructuring yang menghasilkan variabel `id`, `title`, `completed`, `priority`, serta `catatanTambahan` (berupa array), lalu tampilkan id, title, priority, dan catatanTambahan.

### Jawaban
```js
const infoTask = [7, "Refactor CRUD", true, "high", "deadline besok", "tag:urgent"];

// Empat elemen pertama sesuai urutan, sisanya terkumpul di rest
const [id, title, completed, priority, ...catatanTambahan] = infoTask;

console.log(id, title, completed, priority);
// 7 Refactor CRUD true high
console.log(catatanTambahan);
// [ 'deadline besok', 'tag:urgent' ]
```
