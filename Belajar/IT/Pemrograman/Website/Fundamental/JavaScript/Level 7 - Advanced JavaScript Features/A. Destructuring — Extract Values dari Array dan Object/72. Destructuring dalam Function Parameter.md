# Destructuring dalam Function Parameter

## Penjelasan
Destructuring dalam function parameter artinya kamu langsung "membongkar" object atau array yang masuk menjadi variabel-variabel kecil **di baris parameter**, begitu function dipanggil. Jadi di dalam badan function kamu tinggal memakai `title`, bukan `task.title`.

- Bentuk object: `function tampilkan({title, priority}) { ... }` — pakai kurawal di parameter
- Bisa diberi default: `function tampilkan({title, priority = "normal"}) { ... }`
- Boleh dipakai di arrow function: `const fn = ({title}) => ...`
- Berlaku juga untuk array: `function ambil([pertama, kedua]) { ... }`
- Kalau parameter yang dikirim bukan object, muncul **TypeError** — jadi pastikan pemanggilnya benar

## Fungsi
Saat function menerima object besar (seperti satu task dengan banyak field), gaya lama membuat kamu menulis `task.title`, `task.priority` berkali-kali di dalam function. Sekali lupa menulis `task.`, hasilnya `undefined` dan susah dilacak.

Destructuring menghapus pengulangan itu sekaligus menjadi **dokumentasi**: dari daftar parameter saja sudah terlihat field mana saja yang dipakai function tersebut.

## Cara Pengimplementasian / Code
```js
// Konteks Task Manager: satu object task
const task = { id: 1, title: "Belajar", completed: false, priority: "high" };

// Gaya lama — harus selalu menulis task. di depan
function tampilkanLama(task) {
  console.log(task.title, task.priority);
}

// Gaya baru — object dibongkar langsung di parameter
function tampilkan({ title, priority = "normal" }) {
  console.log(title, priority); // tidak perlu task. lagi
}

tampilkan(task); // "Belajar" "high"

// Arrow function juga bisa
const tandaiSelesai = ({ id, title }) => console.log(`Task #${id} "${title}" selesai`);
tandaiSelesai(task); // Task #1 "Belajar" selesai

// Default value jalan saat key tidak dikirim pemanggil
tampilkan({ title: "Rapihkan folder" }); // "Rapihkan folder" "normal"
```
Cara menjalankan: simpan kode di atas ke file `level7.js`, lalu muat dari `level7.html` (pakai `<script src="level7.js"></script>`), buka file itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

```js
const task = { id: 1, title: "Belajar", completed: false, priority: "high" };

function tampilkan({ title, priority = "normal" }) {
  console.log(title, priority);
}
tampilkan(task);

const tandaiSelesai = ({ id, title }) =>
  console.log(`Task #${id} "${title}" selesai`);
tandaiSelesai(task);
tampilkan({ title: "Rapihkan folder" });
```

**Langkah 1 — baris `const task = {...}`**
JavaScript membuat object `task` berisi `id` = `1`, `title` = `"Belajar"`, `completed` = `false`, `priority` = `"high"`.

**Langkah 2 — baris `function tampilkan({...})`**
Function `tampilkan` didefinisikan. Belum ada yang berjalan — parameter baru akan diisi saat dipanggil. (Gaya lama `tampilkanLama` tidak pernah dipanggil, jadi tidak menghasilkan output.)

**Langkah 3 — baris `tampilkan(task)` mulai berjalan**
Object `task` dikirim masuk. JavaScript langsung membongkarnya: key `title` diambil → variabel `title` berisi `"Belajar"`; key `priority` diambil → variabel `priority` berisi `"high"` (karena ada, default `"normal"` tidak dipakai).

**Langkah 4 — baris `console.log(title, priority)`**
Menampilkan `Belajar high`. Function selesai.

**Langkah 5 — baris `tandaiSelesai(task)`**
Arrow function di atasnya juga membongkar `task`: `id` berisi `1`, `title` berisi `"Belajar"`. Baris `console.log` membentuk kalimat `Task #1 "Belajar" selesai` dan menampilkannya.

**Langkah 6 — baris `tampilkan({ title: "Rapihkan folder" })`**
Object yang dikirim hanya punya key `title`. Variabel `title` berisi `"Rapihkan folder"`. Key `priority` tidak ada → `undefined` → default dipakai, jadi `priority` berisi `"normal"`. `console.log` menampilkan `Rapihkan folder normal`.

| Pemanggilan | Isi `title` | Isi `priority` | Sumber nilai `priority` |
|---|---|---|---|
| `tampilkan(task)` | "Belajar" | "high" | dari object |
| `tampilkan({title: "Rapihkan folder"})` | "Rapihkan folder" | "normal" | default parameter |

**Output akhir:**
```
Belajar high
Task #1 "Belajar" selesai
Rapihkan folder normal
```

## Analogi
Seperti menerima formulir anggota dari tamu, lalu langsung menyalin kolom `nama` dan `alamat`nya ke kartu jumpaan **sebelum** formulir diletakkan di meja. Di dalam function, pustakawan tinggal membaca kartu yang sudah jadi — tidak perlu membuka dan menelusuri formulir utuh berkali-kali.

## Dipakai untuk Apa
- Function yang menampilkan task (`displayTask({title, priority})`)
- Handler event DOM yang menerima object parameter besar
- Fungsi util dengan banyak opsi: `render({container, data, darkMode})`
- Memperjelas function yang hanya memakai sebagian kecil field object

## Kesalahan Umum yang Sering Terjadi
- **Lupa kurawal di parameter**: menulis `function tampilkan(title, priority)` membuat `title` justru diisi **object utuh**, sehingga `console.log(title)` menampilkan `[object Object]`. Hindari: destructuring object wajib pakai `{ }`.
- **Mengirim data yang bukan object**: memanggil `tampilkan("Judul")` pada function berparameter `{title}` memunculkan **TypeError: Cannot destructure property 'title' of ...** karena string tidak punya property `title`.
- **Mengira parameter hasil destructure bisa diubah untuk mengubah object asal**: mengubah `title` di dalam function **tidak mengubah** `task.title` — nilai disalin, bukan dirujuk. Kecuali isinya object/array bersarang.
- **Menamai variabel parameter tidak sama dengan key**: `function f({judul})` padahal key-nya `title` → selalu `undefined`. Hindari: `{ title: judul }`.

## Soal Latihan & Jawaban
### Soal
Buat function arrow bernama `konfirmasi` yang menerima object task langsung di parameter: `({ id, title, priority = "normal" })`. Function harus menampilkan kalimat:
`Task #<id> "<title>" — Prioritas: <priority>`.
Panggil dengan data `{id: 9, title: "Deploy", priority: "high"}` dan dengan `{id: 10, title: "Backup"}` (tanpa priority).

### Jawaban
```js
// Object dibongkar langsung di parameter, priority punya default
const konfirmasi = ({ id, title, priority = "normal" }) =>
  console.log(`Task #${id} "${title}" — Prioritas: ${priority}`);

konfirmasi({ id: 9, title: "Deploy", priority: "high" });
// Task #9 "Deploy" — Prioritas: high

konfirmasi({ id: 10, title: "Backup" });
// Task #10 "Backup" — Prioritas: normal
```
