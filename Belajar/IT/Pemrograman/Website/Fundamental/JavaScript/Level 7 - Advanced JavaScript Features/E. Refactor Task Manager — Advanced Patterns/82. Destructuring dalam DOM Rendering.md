# Destructuring dalam DOM Rendering

## Penjelasan
Destructuring adalah cara mengambil nilai dari object atau array dan langsung menaruhnya di variabel baru dalam satu baris. Saat rendering DOM, tiap task biasanya cuma butuh beberapa field — di situlah destructuring paling pas dipakai.

Aturan yang perlu kamu ingat:
- Ditulis langsung di parameter callback: `tasks.map(({ id, title, completed }) => ...)`.
- Kurung `({ ... })` wajib ada, karena yang dibuka adalah object.
- Bisa sekalian memberi nilai default: `({ title = "(tanpa judul)" })` dipakai kalau property bisa kosong.
- Hasilnya template jadi terbaca seperti bahasa: "pakai id, judul, dan status", bukan `task.id`, `task.title`, `task.completed` berulang-ulang.

## Fungsi
Rendering adalah bagian kode paling "ramai": template HTML, kondisi class, atribut `data-*`, teks tombol. Tanpa destructuring, setiap baris template dipenuhi awalan `task.` yang membuat mata cepat lelah dan salah baca.

Destructuring memangkas pengulangan itu. Kamu menyebut sekali field apa saja yang dipakai di awal, lalu di dalam template tinggal memakai namanya saja.

## Cara Pengimplementasian / Code
```js
// renderTasks versi refactor: destructuring di parameter map
function renderTasks() {
  const tasks = window.manager.getTasks();
  const taskList = document.getElementById("taskList");

  const html = tasks
    .map(({ id, title, completed }) => `<li class="task-item ${completed ? "completed" : ""}" data-id="${id}"><span>${title}</span><button class="btn-complete">${completed ? "Undo" : "Complete"}</button><button class="btn-delete">Delete</button></li>`)
    .join("\n");
  taskList.innerHTML = html;
  console.log(html);
}

// Percobaan cepat: data mock, di project asli datanya dari class TaskManager
window.manager = {
  getTasks: () => [
    { id: 1, title: "Belajar destructuring", completed: false },
    { id: 2, title: "Rapikan renderTasks", completed: true }
  ]
};
renderTasks();
```

HTML pendukungnya (`level7.html`):

```html
<ul id="taskList"></ul>
<script src="level7.js"></script>
```

Cara menjalankan: simpan kode JavaScript sebagai `level7.js`, muat dari `level7.html` seperti di atas, buka file HTML di browser, lalu tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer. Misalkan `window.manager` berisi dua task.

**Langkah 1 — `window.manager.getTasks()`**
Mengembalikan array berisi dua object task. Variabel `tasks` kini berisi `[{id: 1, title: "Belajar destructuring", completed: false}, {id: 2, title: "Rapikan renderTasks", completed: true}]`.

**Langkah 2 — `document.getElementById("taskList")`**
Komputer mencari elemen `<ul id="taskList">` di halaman. Variabel `taskList` kini menunjuk elemen itu. Belum ada yang dicetak.

**Langkah 3 — `tasks.map(...)` memanggil callback untuk tiap task**
Di parameter callback, destructuring memecah object jadi tiga variabel. Untuk task pertama: `id = 1`, `title = "Belajar destructuring"`, `completed = false`. Karena `completed` false, `${completed ? "completed" : ""}` menghasilkan `""` dan tombol menghasilkan teks `"Complete"`.

| Iterasi | `id` | `title` | `completed` | Potongan `<li>` yang dihasilkan |
|---|---|---|---|---|
| 1 | 1 | `"Belajar destructuring"` | `false` | `<li class="task-item " data-id="1">...Complete...</li>` |
| 2 | 2 | `"Rapikan renderTasks"` | `true` | `<li class="task-item completed" data-id="2">...Undo...</li>` |

Task kedua punya `completed = true`, jadi class-nya `"task-item completed"` dan tombolnya bertuliskan `"Undo"`.

**Langkah 4 — `.join("\n")`**
Array dua string `<li>` digabung jadi satu teks besar, dipisah baris baru. Variabel `html` kini berisi dua baris markup.

**Langkah 5 — `taskList.innerHTML = html`**
Elemen `<ul>` di halaman langsung terisi dua `<li>` sekaligus. Halaman kini menampilkan daftar task.

**Langkah 6 — `console.log(html)`**
Console mencetak isi variabel `html` apa adanya.

**Output akhir:**
```
<li class="task-item " data-id="1"><span>Belajar destructuring</span><button class="btn-complete">Complete</button><button class="btn-delete">Delete</button>
<li class="task-item completed" data-id="2"><span>Rapikan renderTasks</span><button class="btn-complete">Undo</button><button class="btn-delete">Delete</button>
```

## Analogi
Saat menyalin daftar buku ke papan pengumuman, pustakawan membawa **kartu katalog** yang isinya lengkap (judul, pengarang, nomor rak, tanggal masuk, status pinjam). Dia tidak menyalin seluruh kartu — hanya mengambil kolom nomor rak, judul, dan status saja (destructuring), lalu menuliskannya ke lembar pengumuman. Hasilnya lebih ringkas dan yang dibaca pengunjung cuma yang penting.

## Dipakai untuk Apa
- Membuat list HTML dari data task: `id`, `title`, `completed`, `priority`
- Mengisi dropdown atau option dari data bertipe `{value, label}`
- Event handler yang butuh beberapa field dari object event (materi 47)
- Menyiapkan parameter fungsi dari object argument (`({ name, age }) => ...`)
- Membaca hasil fetch API yang nested (materi 61-62)

## Kesalahan Umum yang Sering Terjadi
- **Lupa kurung di parameter**: Menulis `tasks.map({id, title} => ...)` membuat JavaScript bingung karena `{` dianggap blok, bukan object. Akibatnya SyntaxError sebelum kode jalan. Tulis `({ id, title })` dengan kurung.
- **Nama property salah eja**: Mendestructure `{ complete }` padahal aslinya `completed` menghasilkan `undefined`. Akibatnya class HTML jadi `"task-item undefined"` dan tombol jadi salah. Selalu cocokkan ejaan dengan bentuk data.
- **Mendestructuring nilai bukan object**: `const { title } = null` atau `undefined` langsung melempar `TypeError: Cannot destructure property 'title'`. Cek dulu datanya ada sebelum dibongkar.
- **Lupa memberi nilai default**: Kalau `title` bisa tidak ada, hasilnya teks `undefined` ikut tercetak di halaman. Beri default: `({ title = "(tanpa judul)" })`.

## Soal Latihan & Jawaban
### Soal
Buat `renderTasks` versi singkat: mendestructure `{ id, title, completed }` dari tiap task, lalu menghasilkan `<li>` berisi centang status dan judul task. Uji dengan dua task (satu selesai, satu belum) dan cetak HTML hasilnya ke Console.

### Jawaban
```js
// Untuk percobaan cepat: buat wadah daftar di halaman
const taskList = document.createElement("ul");
document.body.appendChild(taskList);

const tasks = [
  { id: 1, title: "Belajar destructuring", completed: false },
  { id: 2, title: "Tulis dokumentasi", completed: true }
];

// Destructuring: id, title, completed langsung dipakai di template
taskList.innerHTML = tasks
  .map(
    ({ id, title, completed }) =>
      `<li data-id="${id}" class="${completed ? "done" : ""}">${completed ? "[x]" : "[ ]"} ${title}</li>`
  )
  .join("\n");

console.log(taskList.innerHTML);
// <li data-id="1" class="">[ ] Belajar destructuring</li>
// <li data-id="2" class="done">[x] Tulis dokumentasi</li>
```
