# Filter, Search & Sort Tasks — Using map, filter, reduce

## Penjelasan
Search, filter, dan sort adalah tiga cara membaca ulang daftar task **tanpa mengubah data aslinya**. Ketiganya mengandalkan method array yang sudah kamu kenal:

- **Search**: `filter` task yang judulnya mengandung kata kunci, memakai `includes()` + `toLowerCase()` supaya tidak peduli huruf besar-kecil.
- **Filter**: `filter` task berdasarkan status (`done`/`pending`) atau prioritas (`high`/`normal`/`low`).
- **Sort**: `sort` pada **salinan** array memakai spread `[...tasks]`, supaya urutan data asli tidak ikut berubah.
- **Chain (rantai operasi)**: gabungkan langkah berurutan dalam satu ekspresi, misalnya `filter` dulu baru `sort`, lalu `map`/`reduce` untuk membentuk hasil akhir.

## Fungsi
Task Manager yang cuma bisa "tampil semua" terasa membatas begitu datanya banyak. Pengguna butuh mencari satu task, menyisihkan yang belum selesai, atau mengurutkan yang paling mendesak lebih dulu. Ketiganya aman dilakukan berulang kali karena tidak memutasi array `#tasks` — selama sort-nya kamu lakukan ke salinan.

## Cara Pengimplementasian / Code
```js
class TaskManager {
  #tasks = []; // data privat, hanya bisa diakses dari dalam class
  constructor(tasks = []) { this.#tasks = tasks; }

  // Search: cari task yang judulnya mengandung kata kunci
  searchTasks(keyword) {
    const kata = keyword.toLowerCase();
    return this.#tasks.filter((t) => t.title.toLowerCase().includes(kata));
  }

  // Filter: ambil task berdasarkan status (dipakai tombol All/Pending/Done)
  getTasksByStatus(status) {
    const harusSelesai = status === "done";
    return this.#tasks.filter((t) => t.completed === harusSelesai);
  }

  // Sort: urutkan berdasarkan tanggal atau prioritas (pakai salinan!)
  sortTasks(by = "date") {
    const bobot = { high: 3, normal: 2, low: 1 };
    return [...this.#tasks].sort((a, b) => {
      if (by === "priority") return bobot[b.priority] - bobot[a.priority];
      return b.createdAt - a.createdAt; // tanggal terbaru di atas
    });
  }

  // Chain: kumpulkan yang pending dulu, baru urutkan prioritasnya
  getPendingSortedByPriority() {
    const bobot = { high: 3, normal: 2, low: 1 };
    const pending = this.#tasks.filter((t) => !t.completed);
    return pending.sort((a, b) => bobot[b.priority] - bobot[a.priority]);
  }
}

const tasks = [
  { id: 1, title: "Belajar JavaScript", completed: false, priority: "high", createdAt: 3 },
  { id: 2, title: "Rapikan code style", completed: true, priority: "low", createdAt: 1 },
  { id: 3, title: "Belajar composition", completed: false, priority: "normal", createdAt: 4 },
  { id: 4, title: "Tulis dokumentasi", completed: false, priority: "high", createdAt: 2 }
];

const manager = new TaskManager(tasks); window.manager = manager;
console.log(manager.searchTasks("belajar").map((t) => t.title).join(", "));
console.log(manager.sortTasks("date").map((t) => t.title).join(", "));
console.log(manager.getPendingSortedByPriority().map((t) => t.title).join(", "));

// Reduce: rangkum jadi satu angka untuk badge "1 completed"
const ringkasan = tasks.reduce((acc, t) => {
  acc[t.completed ? "done" : "pending"] += 1;
  return acc;
}, { done: 0, pending: 0 });
console.log(ringkasan);
```

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer. `manager` dibuat dari `new TaskManager(tasks)`, field privat `#tasks` berisi 4 task (id 1 sampai 4), dan belum ada yang dicetak.

**Langkah 1 — `searchTasks("belajar")`**
Variabel `kata` berisi `"belajar"`. Lalu `filter` memanggil callback untuk tiap task; hasilnya task 1 dan task 3, yang kemudian diubah `map` + `join` jadi teks. Method `getTasksByStatus` bekerja dengan pola yang sama, bedanya kondisinya `completed === true` sehingga hasilnya task 2:

| Iterasi | `task.title.toLowerCase()` | `.includes("belajar")` | Masuk hasil? |
|---|---|---|---|
| 1 | `"belajar javascript"` | `true` | ya |
| 2 | `"rapikan code style"` | `false` | tidak |
| 3 | `"belajar composition"` | `true` | ya |
| 4 | `"tulis dokumentasi"` | `false` | tidak |

**Langkah 2 — `sortTasks("date")`**
Karena `by = "date"`, comparator memakai `b.createdAt - a.createdAt`, jadi tanggal terbaru di depan. Salinan array diurutkan: task 3 (createdAt 4), task 1 (3), task 4 (2), task 2 (1). Array `#tasks` asli tidak berubah.

**Langkah 3 — `getPendingSortedByPriority()`**
Dua tahap berurutan. `filter((t) => !t.completed)` menggugurkan task 2, jadi `pending` = `[task 1, task 3, task 4]`. Lalu `sort` memakai bobot `high: 3, normal: 2, low: 1` dan selisih `bobot[b] - bobot[a]` (yang bobotnya lebih besar di depan):

| Urutan | Task | Prioritas | Bobot |
|---|---|---|---|
| 1 | task 1 | high | 3 |
| 2 | task 4 | high | 3 |
| 3 | task 3 | normal | 2 |

**Langkah 4 — `reduce` menghitung ringkasan**
Callback berjalan 4 kali dan mengubah `acc` tiap kali: mulai `{done: 0, pending: 0}` → task 1 `pending` jadi 1 → task 2 `done` jadi 1 → task 3 `pending` jadi 2 → task 4 `pending` jadi 3. `acc` terakhir `{ done: 1, pending: 3 }`.

**Output akhir:**
```
Belajar JavaScript, Belajar composition
Belajar composition, Belajar JavaScript, Tulis dokumentasi, Rapikan code style
Belajar JavaScript, Tulis dokumentasi, Belajar composition
{ done: 1, pending: 3 }
```

## Analogi
Ini seperti pustakawan memilah **kartu katalog** di laci. Search = menarik kartu yang judulnya mengandung kata kunci. Filter = mengambil hanya kartu berstatus "belum dikembalikan". Sort = menyusun ulang kartu di tangan berdasarkan tanggal masuk. Isi kartunya tidak pernah ditulis ulang — pustakawan hanya memilih dan menyusun salinannya.

## Dipakai untuk Apa
- Search box "cari task..." di Task Manager
- Tombol filter All / Pending / Done
- Dropdown sort By Date / By Priority

## Kesalahan Umum yang Sering Terjadi
- **Sort langsung ke array asli**: `this.#tasks.sort(...)` mengubah urutan data permanen sehingga tampilan berantakan setelah beberapa kali ganti filter. Selalu sort salinan: `[...this.#tasks].sort(...)`. Hasil `filter` tidak masalah karena memang mengembalikan array baru.
- **Hanya satu sisi yang di-lowercase**: keyword `"Belajar"` dibandingkan judul lowercase `"belajar composition"` tidak akan cocok, hasilnya kosong padahal seharusnya ada. Samakan kedua sisi dengan `toLowerCase()`.
- **Membandingkan tipe data berbeda**: `t.completed === (status === "done")` benar karena dua-duanya boolean. Kalau ditulis `t.completed === "done"`, hasilnya selalu `false` karena `completed` bertipe boolean, bukan teks.
- **Comparator sort mengembalikan boolean**: `.sort((a, b) => a.priority > b.priority)` mengembalikan `true`/`false`, bukan angka, sehingga urutan tidak menentu. Kembalikan selisih angka (bobot).

## Soal Latihan & Jawaban
### Soal
Buat method `searchAndSort(keyword)` pada `TaskManager` yang mengembalikan task yang judulnya mengandung `keyword`, diurutkan dari yang terbaru (`createdAt` paling besar di depan). Uji dengan keyword `"belajar"`.

### Jawaban
```js
class TaskManager {
  #tasks = [];
  constructor(tasks = []) { this.#tasks = tasks; }

  // Cari dulu (filter), baru urutkan (sort) — satu rantai operasi
  searchAndSort(keyword) {
    const kata = keyword.toLowerCase();
    return this.#tasks
      .filter((t) => t.title.toLowerCase().includes(kata))
      .sort((a, b) => b.createdAt - a.createdAt);
  }
}

const manager = new TaskManager([
  { id: 1, title: "Belajar JavaScript", completed: false, priority: "high", createdAt: 3 },
  { id: 2, title: "Rapikan code style", completed: true, priority: "low", createdAt: 1 },
  { id: 3, title: "Belajar composition", completed: false, priority: "normal", createdAt: 4 }
]);
console.log(manager.searchAndSort("belajar").map((t) => `${t.title} (${t.createdAt})`).join(", "));
// Belajar composition (4), Belajar JavaScript (3)
```
