# Currying — Transform Function dengan Multiple Arguments

## Penjelasan
Currying adalah mengubah satu function yang menerima banyak argument menjadi rangkaian function yang masing-masing menerima satu argument. Pola lamanya `fn(a, b, c)`, pola barunya `fn(a)(b)(c)`.

Cara kerjanya:
- Setiap kali function dipanggil dengan satu argument, dia **mengembalikan function baru** yang masih menunggu argument berikutnya.
- Argument yang sudah masuk "tersimpan" di dalam function berkat closure (materi 26), sampai argument terakhir masuk dan hasil akhirnya dihitung.
- Saat argument terakhir masuk, barulah function paling dalam menjalankan tubuhnya dan mengembalikan nilai bukan function.
- Varian yang sangat berguna: **partial application** — memanggil sebagian argument dulu, lalu menyimpan "sisa" function untuk dipakai berkali-kali.

## Fungsi
Currying membuat kamu bisa "mengunci" argument yang selalu sama, lalu hanya mengisi bagian yang berubah. Untuk Task Manager, kalau hampir semua task baru dibuat dengan prioritas `high`, kamu cukup membuat satu "cetakan" yang prioritasnya sudah dikunci, dan tinggal mengisi judulnya saja tiap kali.

Selain itu, currying membuat function cocok dipakai dalam function composition (materi 80), karena composition lebih rapi kalau semua function menerima satu input dan menghasilkan satu output.

## Cara Pengimplementasian / Code
```js
// ---------- Versi biasa: semua argument masuk sekaligus ----------
function createTask(title, priority, completed) {
  return { title, priority, completed };
}
console.log(createTask("Belajar currying", "high", false));

// ---------- Versi curried: satu argument per panggilan ----------
function curriedCreateTask(title) {
  return function (priority) {
    return function (completed) {
      // argument terakhir masuk → tubuh function dijalankan
      return { title, priority, completed };
    };
  };
}

// Pola pemanggilannya: fn(a)(b)(c)
console.log(curriedCreateTask("Belajar currying")("high")(false));

// ---------- Partial application: kunci argument awal ----------
const bikinPrioritasHigh = curriedCreateTask("Rapikan kode")("high");
// bikinPrioritasHigh kini tinggal menunggu argument completed
console.log(bikinPrioritasHigh(false)); // belum selesai
console.log(bikinPrioritasHigh(true));  // sudah selesai
```

Cara menjalankan: simpan kode di atas sebagai `level7.js`, muat dari `level7.html` (`<script src="level7.js"></script>`), buka file HTML di browser, lalu tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

**Langkah 1 — `createTask("Belajar currying", "high", false)`**
Function biasa langsung bekerja: `title = "Belajar currying"`, `priority = "high"`, `completed = false`. Console mencetak object `{ title: "Belajar currying", priority: "high", completed: false }`.

**Langkah 2 — `curriedCreateTask("Belajar currying")`**
Function paling luar berjalan dengan `title = "Belajar currying"`. Belum ada perhitungan. Function ini mengembalikan function tingkat dua (yang menunggu `priority`). Karena belum dipanggil lagi, belum ada yang dicetak.

**Langkah 3 — `("high")`**
Function tingkat dua berjalan dengan `priority = "high"`, sementara `title` masih tersimpan dari langkah sebelumnya. Function ini mengembalikan function tingkat tiga (yang menunggu `completed`).

**Langkah 4 — `(false)`**
Function tingkat tiga berjalan dengan `completed = false`, `title` dan `priority` masih tersimpan. Sekarang semua argument lengkap, jadi tubuh function dijalankan dan mengembalikan object `{ title: "Belajar currying", priority: "high", completed: false }`. Object itulah yang dicetak Console.

| Tahap | Pemanggilan | Nilai yang tersimpan | Yang dikembalikan |
|---|---|---|---|
| 1 | `curriedCreateTask("Belajar currying")` | `title` | function tingkat dua |
| 2 | `("high")` | `title`, `priority` | function tingkat tiga |
| 3 | `(false)` | `title`, `priority`, `completed` | object hasil |

**Langkah 5 — `curriedCreateTask("Rapikan kode")("high")`**
`title = "Rapikan kode"` tersimpan, lalu `priority = "high"` tersimpan. Hasilnya function tingkat tiga yang disimpan di wadah `bikinPrioritasHigh`. Belum ada yang dicetak.

**Langkah 6 — `bikinPrioritasHigh(false)`**
Argument `completed = false` masuk, semua argument lengkap → mengembalikan `{ title: "Rapikan kode", priority: "high", completed: false }`.

**Langkah 7 — `bikinPrioritasHigh(true)`**
Wadah yang sama dipakai lagi, kali ini `completed = true` → mengembalikan `{ title: "Rapikan kode", priority: "high", completed: true }`.

**Output akhir:**
```
{ title: 'Belajar currying', priority: 'high', completed: false }
{ title: 'Belajar currying', priority: 'high', completed: false }
{ title: 'Rapikan kode', priority: 'high', completed: false }
{ title: 'Rapikan kode', priority: 'high', completed: true }
```

## Analogi
Currying seperti **formulir pendaftaran anggota perpustakaan yang diisi bertahap**. Kamu mengisi kolom nama dulu, formulirnya dikembalikan ke kamu bersama kolom berikutnya (alamat), lalu dikembalikan lagi untuk kolom terakhir (nomor telepon). Setiap tahap "mengunci" isian sebelumnya, dan baru setelah kolom terakhir terisi formulirnya diproses pustakawan. Isian yang sudah dikunci bisa kamu simpan — misalnya formulir yang alamatnya sudah diisi, tinggal dilanjutkan nanti.

## Dipakai untuk Apa
- Partial application: mengunci setting yang jarang berubah (prioritas default, label status, URL endpoint).
- Membuat function khusus seperti `filterPending`, `filterDone` dari satu function induk.
- Menyusun pipeline di function composition (materi 80) yang lebih rapi dengan satu input.
- Membungkus fungsi library supaya lebih mudah dipanggil di banyak tempat (`lodash.curry`).
- Handler event yang butuh beberapa "parameter tetap" seperti `id` dan `status`.

## Kesalahan Umum yang Sering Terjadi
- **Berhenti di tengah rantai**: `console.log(curriedCreateTask("Judul"))` hanya mencetak isi function karena argument belum lengkap. Akibatnya kamu melihat `ƒ function...` di Console, bukan object. Pastikan sampai pemanggilan terakhir `("high")(false)`.
- **Memberi banyak argument sekaligus**: `curriedCreateTask("Judul", "high")` membuat argument kedua diabaikan, karena function tingkat satu memang cuma punya satu parameter. Hasilnya tetap function, bukan object.
- **Lupa `return` di salah satu tingkat**: Rantai `fn(a)(b)(c)` langsung error `is not a function` karena tingkat sebelumnya mengembalikan `undefined`. Selalu tulis `return function (...)` di tiap tingkat.
- **Salah mengira closure sudah hilang**: `bikinPrioritasHigh(false)` dan `bikinPrioritasHigh(true)` memakai `title` dan `priority` yang sama karena tersimpan di closure. Jangan berharap tiap panggilan membuat data baru dari nol.

## Hubungan dengan Materi Sebelumnya
Currying adalah pengembangan langsung dari materi 78 `Higher-Order Function — Function yang Terima-Return Function`: kalau di materi 78 function mengembalikan satu function, sekarang bisa beberapa tingkat. Materi 23 `Parameter & Return Value — Input & Output` menjelaskan dasar argument dan nilai kembali, sedangkan materi 26 `Closure — Function Nesting & Variable Access` adalah "mesin" yang membuat argument lama tetap tersimpan. Sebelumnya kamu juga sudah memakai pola serupa di materi 56 `Callback Function Pattern — Passing Function as Parameter`. Selanjutnya, currying langsung dipakai di materi 80 `Function Composition — Combine Functions`.

## Soal Latihan & Jawaban
### Soal
Buat versi curried dari function pembuat label task. Namanya `buatLabel(status)`, lalu `judul`, sehingga pemanggilannya `buatLabel("done")("Belajar JS")` dan hasilnya string `"[done] Belajar JS"`. Setelah itu, kunci status `done` di satu wadah (partial application) dan pakai untuk mencetak dua judul sekaligus.

### Jawaban
```js
// Curried: satu argument per panggilan
function buatLabel(status) {
  return function (judul) {
    return `[${status}] ${judul}`;
  };
}

console.log(buatLabel("done")("Belajar JS")); // [done] Belajar JS

// Partial application: status "done" sudah dikunci
const labelSelesai = buatLabel("done");
const judulTask = ["Belajar JS", "Rapikan kode"];
console.log(judulTask.map((judul) => labelSelesai(judul)).join(" | "));
// [done] Belajar JS | [done] Rapikan kode
```
