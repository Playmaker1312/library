# Function Composition — Combine Functions

## Penjelasan
Function Composition adalah menggabungkan dua (atau lebih) function kecil menjadi satu function baru, sehingga output dari function pertama menjadi input untuk function berikutnya. Rumus klasiknya: `(f ∘ g)(x) = f(g(x))`, artinya jalankan `g` dulu, hasilnya masuk ke `f`.

Dua nama yang perlu kamu kenal:
- **compose(f, g)** — urutan eksekusinya dari kanan ke kiri: `g` dulu baru `f`. Ini gaya matematika.
- **pipe(g, f)** — kebalikannya, urutan dibaca dari kiri ke kanan: `g` dulu baru `f`. Lebih intuitif untuk banyak step.

Aturan main supaya composition rapi:
- Tiap function sebaiknya menerima **satu input** dan menghasilkan **satu output**.
- Tiap function mengerjakan **satu pekerjaan kecil** dengan nama yang jelas.
- Saat menyusun function, jangan langsung memanggilnya — serahkan function-nya saja, pemanggilannya nanti.

## Fungsi
Composition mengubah kumpulan function kecil yang mudah diuji satu per satu menjadi satu alur besar yang enak dibaca. Kamu tidak perlu menulis function raksasa yang melakukan semuanya sekaligus.

Untuk Task Manager, misalnya, menampilkan judul task butuh beberapa langkah kecil: rapikan spasi, ubah huruf besar semua, tambahkan label. Composition menyatunya jadi satu function `prosesJudul(x)` yang tinggal kamu panggil kapan saja.

## Cara Pengimplementasian / Code
```js
// ---------- Compose: eksekusi dari kanan ke kiri ----------
const compose = (f, g) => (x) => f(g(x));

// Function-function kecil: satu pekerjaan satu function
const rapikanJudul = (judul) => judul.trim();
const hurufBesar = (teks) => teks.toUpperCase();
const beriLabel = (teks) => `[TASK] ${teks}`;

// Susun tiga function jadi satu (yang dijalankan nanti, bukan sekarang)
const prosesJudul = compose(beriLabel, compose(hurufBesar, rapikanJudul));
console.log(prosesJudul("  belajar composition  "));
// [TASK] BELAJAR COMPOSITION

// ---------- Pipe: eksekusi dari kiri ke kanan ----------
const pipe = (g, f) => (x) => f(g(x));

const prosesJudul2 = pipe(rapikanJudul, (teks) => hurufBesar(teks) + "!");
console.log(prosesJudul2("  belajar composition  "));
// BELAJAR COMPOSITION!
```

Cara menjalankan: simpan kode di atas sebagai `level7.js`, muat dari `level7.html` (`<script src="level7.js"></script>`), buka file HTML di browser, lalu tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

**Langkah 1 — `compose(beriLabel, compose(hurufBesar, rapikanJudul))`**
Komputer mengevaluasi dari dalam ke luar dulu. `compose(hurufBesar, rapikanJudul)` membuat function baru, misalnya bernama `gabung1`, yang akan menjalankan `rapikanJudul` lalu `hurufBesar`. Belum ada yang dijalankan, belum ada yang dicetak.

**Langkah 2 — `compose(beriLabel, gabung1)`**
Komputer membuat function baru `prosesJudul` yang akan menjalankan `gabung1` dulu, baru `beriLabel`. Wadah `prosesJudul` kini berisi function itu. Masih belum ada yang dicetak.

**Langkah 3 — `prosesJudul("  belajar composition  ")` mulai berjalan**
Function ini menerima `x = "  belajar composition  "` dan menjalankan `gabung1(x)` lebih dulu.

**Langkah 4 — `gabung1` menjalankan `rapikanJudul` lalu `hurufBesar`**
`rapikanJudul("  belajar composition  ")` menghasilkan `"belajar composition"`. Hasilnya masuk ke `hurufBesar`, menghasilkan `"BELAJAR COMPOSITION"`.

**Langkah 5 — `beriLabel` menerima hasil langkah 4**
`beriLabel("BELAJAR COMPOSITION")` menghasilkan `"[TASK] BELAJAR COMPOSITION"` dan itulah nilai return akhir. Console mencetaknya.

| Tahap | Function yang dijalankan | Input | Hasil |
|---|---|---|---|
| 1 | `rapikanJudul` | `"  belajar composition  "` | `"belajar composition"` |
| 2 | `hurufBesar` | `"belajar composition"` | `"BELAJAR COMPOSITION"` |
| 3 | `beriLabel` | `"BELAJAR COMPOSITION"` | `"[TASK] BELAJAR COMPOSITION"` |

**Langkah 6 — `prosesJudul2("  belajar composition  ")`**
`pipe(rapikanJudul, f2)` menghasilkan function yang menjalankan `rapikanJudul` dulu → `"belajar composition"`, lalu `f2` → `hurufBesar` menghasilkan `"BELAJAR COMPOSITION"` dan langsung ditambah `"!"` → `"BELAJAR COMPOSITION!"`. Console mencetaknya.

```

```

## Analogi
Seperti jalur buku baru di perpustakaan: satu buku datang, lalu melewati tiga petugas berurutan — Petugas A merapikan stiker lama, Petugas B menempel label rak baru, Petugas C menaruhnya ke rak. Tiap petugas hanya satu pekerjaan, tetapi hasil akhirnya buku siap rak. Composition persis begitu: satu buku masuk (satu input), satu buku siap keluar (satu output), dan tiap function di jalurnya adalah satu petugas.

## Dipakai untuk Apa
- Menyusun alur data seperti "format → validasi → simpan" dalam satu baris pemanggilan.
- Pipeline transformasi data di aplikasi: parse JSON → filter → mapping → render.
- React/HOC pattern yang menyusun beberapa fungsi pembungkus komponen.
- Middleware di framework seperti Express, di mana tiap middleware meneruskan hasil ke berikutnya.
- Menyusun handler kompleks Task Manager dari function-function kecil yang mudah diuji.

## Kesalahan Umum yang Sering Terjadi
- **Urutan function terbalik**: `compose(rapikanJudul, beriLabel)` menjalankan `beriLabel` lebih dulu, sehingga label ikut terpotong saat `rapikanJudul` memotong spasi. Akibatnya hasil tidak sesuai harapan. Ingat: argument pertama `compose` adalah yang **paling akhir** dijalankan.
- **Memanggil function saat menyusun**: `compose(beriLabel(x), ...)` membuat nilai berupa string, bukan function. Akibatnya muncul error `f is not a function`. Serahkan function-nya (`beriLabel`), jangan hasilnya.
- **Function yang tidak mengembalikan nilai**: Jika salah satu function tidak punya `return`, hasilnya `undefined` dan function setelahnya langsung error saat menerima `undefined`. Pastikan tiap function selalu mengembalikan nilai.
- **Function dengan banyak parameter**: `f(a, b)` tidak bisa langsung disambung ke composition karena composition hanya meneruskan satu nilai. Bentuk dulu jadi currying (materi 79) supaya satu-satu.

## Soal Latihan & Jawaban
### Soal
Dengan pola `compose(f, g)`, buat function `formatJudul = compose(hurufBesar, rapikanJudul)` untuk Task Manager. Lalu cetak hasilnya untuk judul `"  review pull request  "` — hasil akhirnya harus `REVIEW PULL REQUEST`. Bonus: buat juga versi pipe yang menghasilkan hasil sama.

### Jawaban
```js
// Function kecil: satu pekerjaan satu function
const rapikanJudul = (judul) => judul.trim();
const hurufBesar = (teks) => teks.toUpperCase();

// Compose: argument pertama dijalankan paling akhir
const compose = (f, g) => (x) => f(g(x));
const formatJudul = compose(hurufBesar, rapikanJudul);
console.log(formatJudul("  review pull request  ")); // REVIEW PULL REQUEST

// Pipe: dibaca dari kiri ke kanan (g dulu, baru f)
const pipe = (g, f) => (x) => f(g(x));
const formatJudul2 = pipe(rapikanJudul, hurufBesar);
console.log(formatJudul2("  review pull request  ")); // REVIEW PULL REQUEST
```
