# Higher-Order Function — Function yang Terima-Return Function

## Penjelasan
Higher-Order Function (HOF) adalah function yang melakukan salah satu dari dua hal berikut:
- **Menerima function sebagai parameter**, atau
- **Mengembalikan function sebagai nilai return**.

Hal ini bisa terjadi karena di JavaScript function adalah nilai biasa — boleh disimpan di variabel, dioper ke parameter, dan dikembalikan dari function lain. Istilah kerennya *first-class citizen*, artinya function "warga negara kelas satu" yang diperlakukan sama seperti string atau angka.

Aturan main yang perlu kamu ingat:
- Function yang masuk sebagai parameter sering ditulis langsung di tempat pakai arrow function, jadi tidak perlu diberi nama sendiri.
- HOF tidak menggantikan function biasa. Dia hanya "membungkus" pemanggilan function lain supaya alurnya bisa dipakai ulang.
- Dari pola ini lahir currying (materi 79), function composition (materi 80), factory function, dan decorator.

## Fungsi
Tanpa HOF, kamu akan menulis ulang logika yang sama di banyak tempat. Contohnya, kalau ingin "filter task pending" dan "filter task done", kamu akan menulis dua blok kode yang isinya 90% sama.

HOF memecahkan masalah itu dengan memisahkan **yang berubah** (kondisi atau proses) dari **yang tetap** (alurnya). Alur ditulis sekali, prosesnya bisa ditukar-tukar lewat parameter. Hasilnya kode lebih ringkas, mudah diuji, dan siap dipakai lagi di tempat lain.

## Cara Pengimplementasian / Code
```js
// ---------- HOF 1: menerima function sebagai parameter ----------
function applyTwice(fn, value) {
  // fn adalah function yang dipinjam dari luar, dipanggil dua kali berurutan
  return fn(fn(value));
}

const double = (x) => x * 2;
console.log(applyTwice(double, 3)); // 12

// ---------- HOF 2: mengembalikan function ----------
function makeMultiplier(factor) {
  // mengembalikan function baru; factor masih "tersimpan" di dalamnya (closure)
  return (x) => x * factor;
}

const kaliDua = makeMultiplier(2);
const kaliTiga = makeMultiplier(3);
console.log(kaliDua(5));  // 10
console.log(kaliTiga(5)); // 15

// ---------- HOF untuk Task Manager: pabrik kondisi filter ----------
function createFilter(kondisi) {
  // kondisi adalah function (task) => boolean
  return (tasks) => tasks.filter(kondisi);
}

const tasks = [
  { id: 1, title: "Belajar HOF", completed: false },
  { id: 2, title: "Rapikan kode", completed: true },
  { id: 3, title: "Tulis dokumentasi", completed: false }
];

const filterPending = createFilter((t) => !t.completed);
console.log(filterPending(tasks).map((t) => t.title).join(", "));
```

Cara menjalankan: simpan kode di atas sebagai `level7.js`, muat dari `level7.html` (`<script src="level7.js"></script>`), buka file HTML di browser, lalu tekan F12 → tab Console.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

**Langkah 1 — `const double = (x) => x * 2;`**
JavaScript membuat wadah bernama `double`, isinya sebuah function. Belum ada yang dipanggil.

**Langkah 2 — `applyTwice(double, 3)` mulai dijalankan**
Function `applyTwice` aktif dengan `fn = double` dan `value = 3`.

**Langkah 3 — bagian dalam `fn(fn(value))`, yaitu `fn(value)`**
`fn(3)` artinya `double(3)`, hasilnya `6`.

**Langkah 4 — bagian luar, `fn(6)`**
`double(6)` menghasilkan `12`. Angka `12` di-return ke pemanggil, lalu `console.log` mencetak `12`.

**Langkah 5 — `makeMultiplier(2)` dan `makeMultiplier(3)`**
`makeMultiplier(2)` berjalan dengan `factor = 2`, lalu mengembalikan function baru `(x) => x * 2`. Wadah `kaliDua` kini berisi function itu. Proses yang sama terjadi: `makeMultiplier(3)` mengembalikan `(x) => x * 3` yang disimpan di `kaliTiga`.

**Langkah 6 — `kaliDua(5)` dan `kaliTiga(5)`**
`kaliDua(5)` → `5 * 2 = 10`, console mencetak `10`. `kaliTiga(5)` → `5 * 3 = 15`, console mencetak `15`.

**Langkah 7 — `createFilter((t) => !t.completed)`**
`kondisi` menerima function `(t) => !t.completed`. Lalu function ini mengembalikan function `(tasks) => tasks.filter(kondisi)`. Jadi `filterPending` kini berisi function tersebut, belum ada yang dicetak.

**Langkah 8 — `filterPending(tasks)` menjalankan `filter` dengan callback `kondisi`**

| Iterasi | `task` yang dicek | Hasil `kondisi(task)` | Masuk hasil? | Isi array hasil |
|---|---|---|---|---|
| 1 | `{id: 1, title: "Belajar HOF", completed: false}` | `true` | ya | `["Belajar HOF"]` |
| 2 | `{id: 2, title: "Rapikan kode", completed: true}` | `false` | tidak | `["Belajar HOF"]` |
| 3 | `{id: 3, title: "Tulis dokumentasi", completed: false}` | `true` | ya | `["Belajar HOF", "Tulis dokumentasi"]` |

**Langkah 9 — `.map((t) => t.title).join(", ")`**
`map` mengambil judul tiap task, jadi `["Belajar HOF", "Tulis dokumentasi"]`. Lalu `join(", ")` menggabungkan array jadi satu teks: `"Belajar HOF, Tulis dokumentasi"`.

**Output akhir:**
```
12
10
15
Belajar HOF, Tulis dokumentasi
```

## Analogi
Di perpustakaan, HOF seperti pustakawan yang menerima **selembar aturan seleksi** (function) dari kepala pustakawan. Alur kerja pustakawan tetap sama — ambil buku, cek, catat — hanya aturan yang ditukar: hari ini "buku yang belum dikembalikan", besok "buku kategori sains". Sebaliknya, ada pustakawan yang diminta membuat aturan baru sesuai permintaan; dia menyerahkan selembar aturan baru kepada petugas lain. Yang pertama = menerima function, yang kedua = mengembalikan function.

## Dipakai untuk Apa
- `map`, `filter`, `reduce` itu sendiri adalah HOF — mereka menerima callback sebagai parameter (materi 75-77).
- `addEventListener` menerima function handler saat kamu pasang event di tombol (materi 46).
- Debounce untuk input search Task Manager: `setTimeout` membungkus function yang ditunda beberapa milidetik.
- `.sort((a, b) => ...)` menerima comparator untuk menentukan urutan.
- Pabrik-pabrik seperti `createFilter`, `createValidator`, `createSorter` supaya logika bisa dipakai ulang.

## Kesalahan Umum yang Sering Terjadi
- **Lupa memanggil function yang di-return**: Menulis `console.log(filterPending)` padahal `filterPending` masih berupa function. Akibatnya Console mencetak isi function, bukan hasil filter. Cara menghindarinya: selalu tulis `filterPending(tasks)`.
- **Memanggil parameter terlalu cepat**: `applyTwice(double(3), 3)` membuat `fn` berisi angka `12`, bukan function. Akibatnya muncul error `fn is not a function`. Cara menghindarinya: oper function-nya (`double`), jangan hasilnya (`double(3)`).
- **Lupa `return` di function pengembali function**: `function makeMultiplier(factor) { (x) => x * factor; }` tanpa `return` membuat hasilnya `undefined`. Rantai pemanggilan berikutnya langsung error `is not a function`.
- **Terlalu banyak function bersarang**: Callback berlapis lebih dari 3-4 tingkat sulit dibaca. Akibatnya kode "sekali tulis, tidak bisa dipahami lagi". Pisahkan tiap function ke nama yang jelas.

## Soal Latihan & Jawaban
### Soal
Di Task Manager, kamu butuh "penanda judul" yang bisa dipakai untuk banyak task sekaligus. Buat sebuah HOF bernama `createTagger(label)` yang mengembalikan function untuk menambahkan label di depan judul task. Pakai hasilnya untuk menandai dua judul: "Belajar HOF" dan "Rapikan kode" dengan label `penting`.

### Jawaban
```js
// HOF: mengembalikan function yang masih mengingat label
function createTagger(label) {
  return (title) => `[${label}] ${title}`;
}

// Partial: "penting" sudah dikunci, tinggal pakai berulang
const tagPenting = createTagger("penting");

const judulTask = ["Belajar HOF", "Rapikan kode"];
console.log(judulTask.map((judul) => tagPenting(judul)).join(", "));
// [penting] Belajar HOF, [penting] Rapikan kode
```
