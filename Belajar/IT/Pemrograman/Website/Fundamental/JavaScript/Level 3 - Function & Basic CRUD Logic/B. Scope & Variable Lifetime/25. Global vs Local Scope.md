# Global vs Local Scope

## Penjelasan
Scope adalah **jangkauan variabel**, yaitu di mana sebuah variabel boleh dibaca atau diubah. JavaScript memutuskan ini berdasarkan tempat variabel dideklarasikan.
- **Global scope**: variabel yang dideklarasikan di luar semua function. Bisa diakses dari mana saja di file itu.
- **Local (function) scope**: variabel yang dideklarasikan di dalam function. Hanya bisa diakses di dalam function itu, dan setelah function selesai variabelnya dilepas.
- **Block scope**: `let` dan `const` yang dideklarasikan di dalam kurung kurawal `if`, `for`, atau `while` hanya hidup di blok tersebut.
- `var` tidak menghormati block scope — cakupannya melebar sampai function. Karena itu `var` mulai ditinggalkan, pakai `let`/`const`.
- **Shadowing**: mendeklarasikan variabel dengan nama sama di scope berbeda. Yang di dalam menutupi (*shadow* = bayangi) yang di luar selama berada di scope-nya.
- Aturan praktis: pakai `const` dulu, baru `let` bila nilainya perlu berubah; minimalkan variabel global.

## Fungsi
Scope mencegah variabel saling tabrak. Kalau semua variabel global, satu fungsi bisa mengubah data tanpa sengaja dan bug-nya sulit dilacak. Dengan local scope, tiap function punya "kotak perkakas" sendiri sehingga namanya boleh pendek dan aman dipakai lagi di function lain. Scope juga jadi dasar untuk menyembunyikan data privat di materi closure (26).

## Cara Pengimplementasian / Code
```js
// GLOBAL SCOPE — variabel di luar function, bisa dipakai dari mana saja
let tasks = [];

// LOCAL SCOPE — variabel di dalam function hanya hidup di sini
function tambahTask(judul) {
  let pesan = "Task '" + judul + "' masuk ke daftar"; // hilang setelah function selesai
  tasks.push({ id: tasks.length + 1, title: judul, completed: false });
  console.log(pesan); // pesan aman diakses: masih di dalam function
}

tambahTask("Belajar Scope");
console.log("Jumlah dari luar: " + tasks.length); // tasks (global) tetap terbaca
// console.log(pesan); // ERROR: pesan tidak dikenal di scope global

// BLOCK SCOPE — let di dalam {} hanya hidup di blok itu
for (let i = 1; i <= 2; i++) {
  console.log("Putaran " + i);
}
// console.log(i); // ERROR: i sudah tidak ada setelah loop selesai

// SHADOWING — nama sama, scope berbeda
let status = "dari global";
function periksaStatus() {
  let status = "dari local"; // menutupi status global selama di sini
  console.log("Di dalam: " + status);
}
periksaStatus();
console.log("Di luar: " + status);
```

Cara menjalankan: simpan kode di atas sebagai `level3.js`, lalu buat `level3.html` yang memuatnya dengan `<script src="level3.js"></script>`. Buka `level3.html` di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

**Langkah 1 — baris `let tasks = [];`**
JavaScript membuat variabel global `tasks` berisi array kosong `[]`.

**Langkah 2 — baris deklarasi `function tambahTask(judul)`**
Hanya dicatat nama function-nya. Variabel `pesan` belum ada, karena baru dibuat saat function dipanggil.

**Langkah 3 — baris `tambahTask("Belajar Scope")`**
Parameter `judul` = `"Belajar Scope"`. Di dalam function dibuat variabel lokal `pesan` berisi teks `Task 'Belajar Scope' masuk ke daftar`. Lalu `tasks.push(...)` membuat `tasks` berisi 1 object `{id: 1, title: "Belajar Scope", completed: false}`. `console.log(pesan)` mencetak isi `pesan`. Function selesai, lalu `pesan` dilepas dan tidak bisa diakses lagi.

**Langkah 4 — baris `console.log("Jumlah dari luar: ...")`**
`tasks` tetap berisi 1 element walaupun sudah di luar function, karena `tasks` adalah global. Yang dicetak: `Jumlah dari luar: 1`.

**Langkah 5 — baris `for (let i = 1; i <= 2; i++)`**
Variabel `i` dibuat di dalam blok loop:

| Putaran | Nilai `i` | `i <= 2`? | Output yang dicetak |
|---|---|---|---|
| 1 | 1 | ya | `Putaran 1` |
| 2 | 2 | ya | `Putaran 2` |
| 3 | 3 | tidak | loop berhenti |

Setelah loop, `i` ikut dilepas karena `let` bersifat block scope.

**Langkah 6 — baris `let status = "dari global"` sampai `periksaStatus()`**
Variabel global `status` berisi `"dari global"`. Saat `periksaStatus()` dipanggil, dibuat variabel lokal `status` berisi `"dari local"` yang menutupi yang global hanya di dalam function. Yang dicetak: `Di dalam: dari local`.

**Langkah 7 — baris `console.log("Di luar: " + status)`**
Kembali ke luar function, jadi `status` yang terbaca adalah versi global. Yang dicetak: `Di luar: dari global`.

**Output akhir:**
```
Task 'Belajar Scope' masuk ke daftar
Jumlah dari luar: 1
Putaran 1
Putaran 2
Di dalam: dari local
Di luar: dari global
```

## Analogi
Global scope seperti **pengumuman yang ditempel di papan besar ruang perpustakaan** — semua orang bisa membacanya dari mana saja. Local scope seperti **catatan yang hanya ada di meja kerja pustakawan** — hanya dia yang membacanya selama bekerja, dan begitu pulang catatan itu tidak beredar di ruang lain. Karena itu catatan internal tidak boleh disamarkan jadi pengumuman papan besar.

## Dipakai untuk Apa
- Array `tasks` global agar semua function CRUD (`addTask`, `getAllTasks`, `deleteTask`) bisa memakai data yang sama
- Variabel lokal untuk data sementara seperti pencari, hitungan, dan pesan sementara
- Block scope `let` di dalam loop supaya iterasi tidak saling bocor
- Menjaga nama variabel tetap aman dipakai ulang di banyak function
- Menyiapkan dasar menyembunyikan data agar tidak bisa diubah sembarangan

## Kesalahan Umum yang Sering Terjadi
- **Mengakses variabel local dari luar**: `console.log(pesan)` di luar function memunculkan `ReferenceError: pesan is not defined` dan menghentikan kode. Akses hanya dari dalam function tempat variabel dibuat.
- **Terlalu banyak variabel global**: Semua bagian program bisa mengubah `tasks` kapan saja, akibatnya bug sulit dilacak. Simpan data di function dan batasi variabel global seperlunya.
- **Salah paham soal `var` di dalam loop/blok**: `var` tetap terbaca setelah blok selesai sehingga nilai terakhir "bocor" keluar. Ganti dengan `let` agar block scope bekerja.
- **Shadowing yang tidak disengaja**: Mendeklarasi `let tasks` lagi di dalam function membuatnya menutupi `tasks` global, sehingga perubahan di luar tidak terbaca di dalam. Cek lagi nama variabel yang kembar.
- **Mengira variabel hilang saat function dipanggil**: Variabel luar yang dipakai di dalam function tidak ikut hilang — justru itu yang membuat closure di materi 26 bisa bekerja.

## Soal Latihan & Jawaban
### Soal
Buat function `tambahTask(judul)` yang menambahkan task ke array global `tasks` dan memakai variabel lokal `pesan` untuk konfirmasi. Cetak `pesan` dari dalam function, lalu buktikan `pesan` tidak bisa diakses dari luar dengan `try/catch` — biarkan juga `tasks` global terbaca dari luar.

### Jawaban
```js
// Global scope: dipakai semua function
let tasks = [];

function tambahTask(judul) {
  // Local scope: hanya hidup di dalam function ini
  let pesan = "Task '" + judul + "' berhasil ditambahkan";
  tasks.push({ id: tasks.length + 1, title: judul, completed: false });
  console.log(pesan); // aman: masih di dalam function
}

tambahTask("Belajar Scope");

// Membuktikan pesan tidak bisa diakses dari luar
try {
  console.log(pesan);
} catch (error) {
  console.log("Seperti ditebak, terjadi: " + error.message);
}

console.log("Jumlah tasks: " + tasks.length); // global tetap terbaca: 1
```
