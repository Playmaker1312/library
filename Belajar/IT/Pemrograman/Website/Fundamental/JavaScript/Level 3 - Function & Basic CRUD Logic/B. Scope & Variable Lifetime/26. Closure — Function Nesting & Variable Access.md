# Closure — Function Nesting & Variable Access

## Penjelasan
Closure adalah kemampuan sebuah function untuk **mengingat variabel dari lingkungan tempat ia dibuat**, bahkan setelah function luar tempat variabel itu dibuat sudah selesai berjalan.
Cara kerjanya:
- Ada function luar yang berisi variabel, lalu di dalamnya ada function dalam.
- Function luar mengembalikan function dalam lewat `return`.
- Saat function dalam dipanggil nanti, ia masih punya akses ke variabel function luar. Variabel itulah yang "diingat".
- Variabel yang diingat ini sering disebut **variabel privat** — tidak bisa diakses langsung dari luar, hanya lewat function yang menyediakannya.
- Pola function luar yang "membuat" function/object begini disebut *factory function* (pabrik pembuat).
- Selama function dalam masih dipakai, variabel yang diingat tidak ikut dibuang JavaScript.

## Fungsi
Closure menyembunyikan data dari dunia luar. Untuk Task Manager, array `tasks` dan `nextId` bisa hidup di dalam `buatManager()` tanpa pernah menjadi global, sehingga tidak ada kode sembarangan yang mengubahnya. Closure juga memungkinkan satu "pabrik" membuat banyak instance yang datanya terpisah, dan closure adalah fondasi dari konsep enkapsulasi (data privat) yang akan kamu pakai di materi class.

## Cara Pengimplementasian / Code
```js
// Factory function: membuat "manager" baru setiap kali dipanggil
function buatManager() {
  let tasks = []; // privat — akan diingat oleh function di dalamnya
  let nextId = 1; // privat — penanda id berikutnya

  return {
    addTask: function (judul) {
      let task = { id: nextId, title: judul, completed: false };
      nextId++;
      tasks.push(task);
      return task;
    },
    getAllTasks: function () {
      return tasks;
    },
    hitungTask: function () {
      return tasks.length;
    }
  };
}

let manager = buatManager(); // buatManager() selesai, tapi tasks & nextId tetap diingat
manager.addTask("Belajar Closure");
manager.addTask("Bikin CRUD");
console.log("Jumlah task: " + manager.hitungTask());
console.log("Task pertama: " + manager.getAllTasks()[0].title);
console.log("tasks global? " + typeof tasks); // tidak ada di global
```

Cara menjalankan: simpan kode di atas sebagai `level3.js`, lalu buat `level3.html` yang memuatnya dengan `<script src="level3.js"></script>`. Buka `level3.html` di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

**Langkah 1 — baris `function buatManager() { ... }`**
JavaScript mencatat nama function `buatManager`. Isinya belum dijalankan, jadi `tasks` belum ada.

**Langkah 2 — baris `let manager = buatManager();`**
Parameter tidak ada. Di dalam `buatManager` dibuat `tasks` = `[]` dan `nextId` = `1`. Lalu dibuat object berisi 3 function, dan object itu dikembalikan ke `manager`.
Yang diingat oleh ketiga function di dalamnya: `tasks` (array privat) dan `nextId`. Setelah `return`, `buatManager` selesai berjalan, tapi `tasks` dan `nextId` tidak dibuang karena masih dirujuk oleh function dalam. Sekarang `manager` berisi object dengan `addTask`, `getAllTasks`, dan `hitungTask`.

**Langkah 3 — baris `manager.addTask("Belajar Closure")`**
Parameter `judul` = `"Belajar Closure"`. Dibuat object `{ id: 1, title: "Belajar Closure", completed: false }` — id diambil dari `nextId` yang masih diingat, lalu `nextId` berubah jadi `2`. `tasks.push(task)` membuat `tasks` berisi 1 element. Function mengembalikan object itu, tapi hasilnya tidak disimpan sehingga dibuang.

**Langkah 4 — baris `manager.addTask("Bikin CRUD")`**
Parameter `judul` = `"Bikin CRUD"`. Variabel yang sama dipakai lagi: `nextId` berubah jadi `3`, dan `tasks` kini berisi 2 element (`id: 1` dan `id: 2`).

**Langkah 5 — baris `console.log("Jumlah task: " + manager.hitungTask())`**
`hitungTask()` mengembalikan `tasks.length`, yaitu `2`. Yang dicetak: `Jumlah task: 2`.

**Langkah 6 — baris `console.log("Task pertama: " + ...)`**
`getAllTasks()` mengembalikan array `tasks`. Dari array itu diambil index `0`, lalu properti `title`, yaitu `"Belajar Closure"`. Yang dicetak: `Task pertama: Belajar Closure`.

**Langkah 7 — baris `console.log("tasks global? " + typeof tasks)`**
Variabel `tasks` tidak pernah dideklarasikan di global, jadi `typeof tasks` menghasilkan teks `"undefined"` tanpa error. Yang dicetak: `tasks global? undefined`.

**Output akhir:**
```
Jumlah task: 2
Task pertama: Belajar Closure
tasks global? undefined
```

## Analogi
Bayangkan pustakawan senior menulis **buku catatan pinjaman**, lalu menyerahkannya ke petugas baru dan segera pulang. Petugas baru itu — walau pimpinannya sudah pergi — masih bisa membaca dan menulis buku catatan yang sama setiap ada anggota datang. Buku catatannya "ikut dengannya" karena dia dipegang erat-erat, bukan karena buku itu dipinjam dari luar. Itulah closure: function yang masih memegang data dari lingkungan asalnya.

## Dipakai untuk Apa
- Menyembunyikan data privat: `tasks` dan `nextId` tidak bisa diubah dari luar
- Menghasilkan id unik secara berurutan tanpa variabel global counter
- Membuat banyak instance terpisah, misalnya dua daftar task untuk dua pengguna
- Callback dan event listener yang perlu memakai data dari sekitarnya saat nanti dipanggil
- Dasar modul dan library JavaScript yang menyembunyikan isi internalnya

## Kesalahan Umum yang Sering Terjadi
- **Mengakses variabel privat langsung dari luar**: `manager.tasks` menghasilkan `undefined` karena `tasks` bukan property object, melainkan variabel yang diingat. Selalu sediakan method khusus seperti `getAllTasks()`.
- **Mengira function luar selesai berarti variabel hilang**: Variabel luar tetap hidup selama function dalam masih merujuknya. Justru itu inti closure, bukan error memori yang perlu dikhawatirkan.
- **Lupa `return` function dalam**: Jika `buatManager` tidak mengembalikan apa-apa, `manager` berisi `undefined` dan `manager.addTask(...)` langsung error. Pastikan `return` mengembalikan function/object.
- **Memanggil factory berulang lalu bingung datanya**: Setiap pemanggilan `buatManager()` membuat `tasks` baru yang terpisah. Ini justru fitur — asal kamu tahu bahwa dua instance tidak saling berbagi data.
- **Mengubah hasil `getAllTasks()` tanpa sadar**: Fungsi itu mengembalikan array aslinya (bukan salinan), jadi `manager.getAllTasks().push(...)` tetap mengubah data privat.

## Soal Latihan & Jawaban
### Soal
Buat factory function `buatTodoList(namaPemilik)` yang membuat array privat sendiri tiap kali dipanggil. Kembalikan method `tambah(judul)` dan `jumlah()`, lalu buat dua instance dan buktikan isi keduanya terpisah.

### Jawaban
```js
// Factory: setiap pemanggilan membuat data privat yang terpisah
function buatTodoList(namaPemilik) {
  let daftar = []; // privat — diingat oleh function dalam

  return {
    tambah: function (judul) {
      daftar.push(judul);
      return namaPemilik + " menambah: " + judul;
    },
    jumlah: function () {
      return daftar.length;
    }
  };
}

const daftarKamu = buatTodoList("Kamu");
const daftarTim = buatTodoList("Tim");

console.log(daftarKamu.tambah("Belajar Closure"));
console.log(daftarTim.tambah("Review PR"));
console.log(daftarKamu.tambah("Bikin CRUD"));

// Tiap instance punya hitungan sendiri: 2 vs 1
console.log("Kamu: " + daftarKamu.jumlah() + " | Tim: " + daftarTim.jumlah());
console.log("daftar di luar: " + typeof daftar); // undefined — tetap privat
```
