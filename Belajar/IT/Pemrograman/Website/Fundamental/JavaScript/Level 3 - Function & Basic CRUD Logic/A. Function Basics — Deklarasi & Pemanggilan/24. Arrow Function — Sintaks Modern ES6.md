# Arrow Function — Sintaks Modern ES6

## Penjelasan
Arrow function adalah cara menulis function yang lebih singkat, diperkenalkan di ES6 (ECMAScript 6, versi JavaScript tahun 2015). Namanya diambil dari tanda panah `=>` yang menjadi ciri khasnya.
Aturan dasarnya:
- Bentuk paling umum: `const nama = (param) => nilai;` — hasil ekspresi di kanan panah otomatis jadi nilai `return`.
- Tanpa kurung kurawal, kamu tidak perlu menulis `return`. Ini disebut *implicit return* (return otomatis).
- Kalau pakai kurung kurawal `{ ... }`, maka `return` harus ditulis sendiri.
- Satu parameter boleh tanpa kurung (`task => task.title`), tapi lebih dari satu parameter wajib pakai kurung (`(a, b) => ...`).
- Arrow function dideklarasikan ke variabel (`const`), jadi **tidak** ikut hoisting seperti function declaration — harus sudah dideklarasikan sebelum dipakai.
- Arrow function tidak punya `this` sendiri (`this` = kata penunjuk konteks, dibahas di materi 39), sehingga sangat cocok untuk callback.

## Fungsi
Function biasa untuk tugas pendek terasa panjang dan berisik. Arrow function memangkas boilerplate (tulisan berulang) sehingga kode lebih ringkas dan enak dibaca, terutama saat function dipakai sebagai callback dari `map`, `filter`, atau event listener. Gaya ini juga standar di hampir semua kode JavaScript modern.

## Cara Pengimplementasian / Code
```js
// Data milik aplikasi Task Manager
let tasks = [
  { id: 1, title: "Belajar Arrow Function", completed: false },
  { id: 2, title: "Refactor callback", completed: true }
];

// Bentuk satu baris: tanpa kurung kurawal, return otomatis
const hitungTotal = (daftar) => daftar.length;

// Bentuk multi-baris: pakai kurung kurawal, return harus eksplisit
const sapaPengguna = (nama) => {
  console.log("Halo, " + nama + "!");
  return "Sapaan untuk " + nama;
};

// Sebagai callback — pasangan alami dari map & filter
const judulSaja = tasks.map((task) => task.title);
console.log(judulSaja.join(" | "));

const belumSelesai = tasks.filter((task) => !task.completed);
console.log("Belum selesai: " + belumSelesai.length);
console.log(sapaPengguna("Kamu"));
console.log("Total task: " + hitungTotal(tasks));
```

Cara menjalankan: simpan kode di atas sebagai `level3.js`, lalu buat `level3.html` yang memuatnya dengan `<script src="level3.js"></script>`. Buka `level3.html` di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

**Langkah 1 — baris `let tasks = [...]`**
`tasks` berisi 2 object: task pertama `completed: false`, task kedua `completed: true`.

**Langkah 2 — baris `const hitungTotal = ...` dan `const sapaPengguna = ...`**
JavaScript menyimpan function ke variabel `hitungTotal` dan `sapaPengguna`. Belum ada output, dan kedua function ini menerima satu parameter.

**Langkah 3 — baris `tasks.map((task) => task.title)`**
`map` memproses tiap element dengan callback arrow function. Parameter `task` menerima satu element dalam satu waktu:

| Putaran | Isi `task` | Hasil `task.title` |
|---|---|---|
| 1 | `{id: 1, title: "Belajar Arrow Function", completed: false}` | `Belajar Arrow Function` |
| 2 | `{id: 2, title: "Refactor callback", completed: true}` | `Refactor callback` |

`judulSaja` kini berisi `["Belajar Arrow Function", "Refactor callback"]`. Method `join(" | ")` menggabungkan array jadi satu teks, lalu `console.log` mencetak: `Belajar Arrow Function | Refactor callback`.

**Langkah 4 — baris `tasks.filter((task) => !task.completed)`**
- Task 1: `completed` = `false`, `!false` = `true` → lolos saringan.
- Task 2: `completed` = `true`, `!true` = `false` → tersaring.

`belumSelesai` berisi array berisi task pertama saja, jadi `belumSelesai.length` = `1`. Yang dicetak: `Belum selesai: 1`.

**Langkah 5 — baris `console.log(sapaPengguna("Kamu"))`**
Parameter `nama` = `"Kamu"`. Di dalam function, `console.log` mencetak `Halo, Kamu!`. Lalu `return` mengirim teks `"Sapaan untuk Kamu"` ke pemanggil, dan teks itulah yang dicetak baris ini.

**Langkah 6 — baris `console.log("Total task: " + hitungTotal(tasks))`**
Parameter `daftar` = array berisi 2 task. `daftar.length` = `2`, dan karena tanpa kurung kurawal hasil itu otomatis di-`return`. Yang dicetak: `Total task: 2`.

**Output akhir:**
```
Belajar Arrow Function | Refactor callback
Belum selesai: 1
Halo, Kamu!
Sapaan untuk Kamu
Total task: 2
```

## Analogi
Function biasa seperti SOP lengkap yang dicetak di satu lembar besar; arrow function seperti **label prosedur pendek** yang ditempel pustakawan di kartu katalog. Untuk tugas satu langkah — misalnya "ambil judul dari kartu" — cukup tulis satu baris singkat tanpa membuat lembar SOP penuh. Isi pekerjaannya sama, hanya catatannya yang jauh lebih ringkas.

## Dipakai untuk Apa
- Callback `map`, `filter`, `find`, dan `forEach` yang isinya cuma satu baris
- Event listener singkat, misalnya `button.addEventListener("click", () => render())`
- Fungsi bantu kecil seperti formatter judul atau penghitung ringkasan
- Mengubah function declaration lama jadi sintaks yang lebih ringkas
- Konsistensi gaya di project JavaScript modern

## Kesalahan Umum yang Sering Terjadi
- **Lupa `return` saat pakai kurung kurawal**: Menulis `(a, b) => { a + b; }` menghasilkan `undefined` karena tidak ada perintah `return`. Untuk satu ekspresi, hilangkan kurung kurawalnya saja: `(a, b) => a + b`.
- **Panggil sebelum deklarasi**: Karena disimpan di `const`, memanggil arrow function sebelum baris deklarasinya memunculkan `ReferenceError` — hoisting hanya berlaku untuk function declaration (materi 22).
- **Kurung parameter dilepas saat lebih dari satu**: `a, b => a + b` error saat dibaca JavaScript. Wajib `(a, b) => a + b`.
- **Salah ketik tanda panah**: Menulis `=` atau `->` bikin sintaks error. Ciri arrow function adalah `=>`.
- **Pakai arrow function untuk method yang butuh `this`**: Arrow function tidak punya `this` sendiri, jadi `this`-nya mengacu ke luar dan sering membuat nilai salah. Untuk kasus ini pakai function biasa — dibahas di materi 39 (this dalam Method — Regular Function vs Arrow).

## Soal Latihan & Jawaban
### Soal
Refaktorkan (tulis ulang) function `hitungTaskSelesai` menjadi arrow function satu baris. Lalu buat arrow function `sisaJudul` untuk menampilkan judul semua task yang belum selesai, dipakai sebagai callback `filter`.

### Jawaban
```js
// Data milik aplikasi Task Manager
const tasks = [
  { id: 1, title: "Belajar Arrow Function", completed: false },
  { id: 2, title: "Refactor callback", completed: true }
];

// Arrow function satu baris: return otomatis
const hitungTaskSelesai = (daftar) => daftar.filter((t) => t.completed).length;
console.log("Selesai: " + hitungTaskSelesai(tasks));

// Arrow function sebagai callback filter
const belumSelesai = tasks.filter((task) => !task.completed);
const sisaJudul = belumSelesai.map((task) => task.title);
console.log("Sisa: " + sisaJudul.join(", "));
```
