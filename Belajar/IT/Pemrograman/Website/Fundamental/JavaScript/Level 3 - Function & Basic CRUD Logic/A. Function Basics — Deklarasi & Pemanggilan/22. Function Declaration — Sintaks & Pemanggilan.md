# Function Declaration — Sintaks & Pemanggilan

## Penjelasan
Function declaration adalah cara membungkus blok kode ke dalam satu nama, supaya kode itu bisa dijalankan berulang kali tanpa ditulis ulang.
Aturan dasarnya:
- Sintaks: `function namaFunction() { ... }` — diawali kata kunci `function`, lalu nama, kurung, dan blok kode di dalam kurung kurawal.
- Pemanggilan: `namaFunction()`. Isi function baru dijalankan saat dipanggil, bukan saat baris deklarasinya dibaca.
- Posisi deklarasi bebas. JavaScript melakukan *hoisting* (pengangkatan), yaitu deklarasi function "diangkat" ke bagian atas kode, jadi memanggil function sebelum baris deklarasinya tetap aman.
- Penamaan pakai **camelCase** (`getAllTasks`, `tambahTask`) dan nama yang mendeskripsikan kerjanya.
- Kalau function perlu menghasilkan nilai, pakai `return`. Detail input-output dibahas di materi 23.

## Fungsi
Kode level 1-2 berjalan linear dari atas ke bawah, jadi logika yang sama harus ditulis berkali-kali. Function menyelesaikan masalah itu: cukup tulis sekali, panggil sesering yang kamu butuhkan. Function juga merapikan kode karena satu function berisi satu tugas — misalnya `getAllTasks` khusus membaca data dan `hitungTask` khusus menghitung data.

## Cara Pengimplementasian / Code
```js
// Data milik aplikasi Task Manager
let tasks = [
  { id: 1, title: "Belajar Function Declaration", completed: false },
  { id: 2, title: "Rapikan logika ke function", completed: false }
];

// Function declaration: beri nama "getAllTasks" untuk blok kode di bawah
function getAllTasks() {
  console.log("=== Semua Task ===");
  for (let i = 0; i < tasks.length; i++) {
    console.log(tasks[i].id + ". " + tasks[i].title);
  }
}

// Function kedua: menghitung jumlah task
function hitungTask() {
  console.log("Jumlah task: " + tasks.length);
}

// Baris berikut adalah pemanggilan — baru di sini function dijalankan
getAllTasks();   // jalankan isi function getAllTasks
hitungTask();    // jalankan isi function hitungTask
getAllTasks();   // dipanggil lagi, kode di dalam tidak perlu ditulis ulang
```

Cara menjalankan: simpan kode di atas sebagai `level3.js`, lalu buat `level3.html` yang memuatnya dengan `<script src="level3.js"></script>`. Buka `level3.html` di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

**Langkah 1 — baris `let tasks = [...]`**
JavaScript membuat variabel `tasks` berisi array 2 object: `{id: 1, title: "Belajar Function Declaration", completed: false}` dan `{id: 2, title: "Rapikan logika ke function", completed: false}`.

**Langkah 2 — baris `function getAllTasks() { ... }`**
JavaScript hanya mencatat: "ada function bernama `getAllTasks`". Tidak ada yang dicetak ke console. Function ini tidak punya parameter.

**Langkah 3 — baris `function hitungTask() { ... }`**
Sama seperti langkah 2, JavaScript mencatat nama `hitungTask`. Belum ada output, dan function ini juga tanpa parameter.

**Langkah 4 — baris `getAllTasks();` (pemanggilan pertama)**
JavaScript masuk ke dalam function `getAllTasks`. Perintah pertama mencetak `=== Semua Task ===`. Lalu loop berjalan:

| Putaran | Nilai `i` | `i < tasks.length` (2)? | Output yang dicetak |
|---|---|---|---|
| 1 | 0 | ya | `1. Belajar Function Declaration` |
| 2 | 1 | ya | `2. Rapikan logika ke function` |
| 3 | 2 | tidak | loop berhenti |

Loop selesai, tidak ada `return`, jadi JavaScript keluar dari function dan lanjut ke baris berikutnya. Isi `tasks` tidak berubah.

**Langkah 5 — baris `hitungTask();`**
JavaScript masuk ke `hitungTask`. `tasks` masih berisi 2 element, jadi yang dicetak: `Jumlah task: 2`. Function selesai dan JavaScript kembali ke baris berikutnya.

**Langkah 6 — baris `getAllTasks();` (pemanggilan kedua)**
Prosesnya persis sama dengan langkah 4, jadi isi function dicetak ulang dari awal.

**Output akhir:**
```
=== Semua Task ===
1. Belajar Function Declaration
2. Rapikan logika ke function
Jumlah task: 2
=== Semua Task ===
1. Belajar Function Declaration
2. Rapikan logika ke function
```

## Analogi
Function declaration seperti **SOP (standar operasi prosedur) berlabel** yang ditempel di meja pustakawan. Pustakawan menulis sekali prosedur "cetak daftar pinjaman", lalu setiap ada anggota yang datang dia tinggal memanggil nama SOP itu — tidak perlu menulis prosedur dari nol. Pemanggilan function adalah saat pustakawan membuka dan menjalankan lembar SOP tersebut.

## Dipakai untuk Apa
- Membungkus logika CRUD jadi 4 function terpisah: `createTask`, `getAllTasks`, `updateTask`, `deleteTask`
- Memanggil logika yang sama di banyak tempat tanpa menulis ulang kode
- Merapikan kode panjang jadi potongan kecil yang mudah dibaca dan didebug
- Menyiapkan langkah berulang seperti menampilkan data atau merangkum laporan

## Kesalahan Umum yang Sering Terjadi
- **Lupa kurung saat memanggil**: Menulis `getAllTasks` tanpa `()`. JavaScript menganggapnya nama variabel, bukan perintah menjalankan function, jadi isi function tidak dieksekusi. Selalu tulis `getAllTasks()`.
- **Salah nama atau typo**: Memanggil `getallTasks()` padahal deklarasinya `getAllTasks`. Hasilnya `ReferenceError: getallTasks is not defined`. Hindari dengan menyalin nama dari baris deklarasinya.
- **Mengira function jalan otomatis**: Function hanya dijalankan saat dipanggil. Tanpa `namaFunction()`, tidak akan ada output sama sekali walau deklarasinya sudah benar.
- **Nama tidak deskriptif**: Function `f1()` atau `proses()` bikin kode susah dibaca saat project makin panjang. Pakai nama kerja, misalnya `tambahTask`.
- **Logika seharusnya reusable ditulis global**: Kode yang dipakai berulang malah ditaruh langsung di luar function, akibatnya sulit diuji dan cepat duplikat.

## Soal Latihan & Jawaban
### Soal
Buat function declaration bernama `tampilkanRingkasan` yang menampilkan jumlah task lalu mencetak id + judul tiap task. Panggil function itu dua kali untuk membuktikan kode di dalam tidak perlu ditulis ulang.

### Jawaban
```js
// Data Task Manager
let tasks = [
  { id: 1, title: "Belajar Function", completed: false },
  { id: 2, title: "Bikin CRUD", completed: false }
];

// Tampilkan ringkasan semua task
function tampilkanRingkasan() {
  console.log("Jumlah task: " + tasks.length);
  for (let i = 0; i < tasks.length; i++) {
    console.log(tasks[i].id + ". " + tasks[i].title);
  }
}

tampilkanRingkasan(); // panggil pertama kali
console.log("---");
tampilkanRingkasan(); // panggil lagi, isi function tetap sama
```
