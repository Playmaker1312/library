# Parameter & Return Value — Input & Output

## Penjelasan
Parameter adalah input sebuah function, sedangkan return adalah output-nya. Dengan keduanya, function tidak lagi cuma "menjalankan kode tetap", tapi bisa menerima data dan menghasilkan hasil kerja.
- **Parameter**: nama yang ditulis di dalam kurung deklarasi, misalnya `function addTask(taskList, judul)`.
- **Argument**: nilai nyata yang dikirim saat function dipanggil, misalnya `addTask(tasks, "Belajar")`.
- **`return`**: mengirim nilai keluar dari function sekaligus menghentikan function di baris itu.
- Function bisa `return` apa saja: string, number, boolean, object, array, bahkan function.
- Function tanpa `return` akan menghasilkan `undefined`.
- **Early return**: menaruh `return` di awal function untuk berhenti cepat ketika syarat belum terpenuhi (biasanya untuk validasi).

## Fungsi
Parameter membuat satu function bisa dipakai untuk data apa saja tanpa harus diubah-ubah isinya. Return membuat hasil kerja function bisa disimpan ke variabel, ditampilkan, atau dipakai oleh function lain. Tanpa keduanya, function hanya bisa melakukan tugas tetap dan hasilnya hilang begitu selesai.

## Cara Pengimplementasian / Code
```js
// Data milik aplikasi Task Manager
let tasks = [];
let nextId = 1;

// Parameter (input): taskList dan judul
function addTask(taskList, judul) {
  if (judul.trim() === "") {
    return null; // early return: berhenti duluan kalau judul kosong
  }
  let task = { id: nextId, title: judul, completed: false };
  nextId++;
  taskList.push(task);
  return task; // output: kirim task baru ke pemanggil
}

// Parameter: taskList. Return: angka
function hitungSelesai(taskList) {
  let jumlah = 0;
  for (let i = 0; i < taskList.length; i++) {
    if (taskList[i].completed) {
      jumlah = jumlah + 1;
    }
  }
  return jumlah;
}

let taskBaru = addTask(tasks, "Belajar Parameter"); // hasil return disimpan
console.log("Task baru: #" + taskBaru.id + " " + taskBaru.title);

tasks[0].completed = true;
addTask(tasks, "Belajar Return"); // hasil return tidak disimpan

console.log("Jumlah selesai: " + hitungSelesai(tasks));
console.log("Judul kosong -> " + addTask(tasks, ""));
```

Cara menjalankan: simpan kode di atas sebagai `level3.js`, lalu buat `level3.html` yang memuatnya dengan `<script src="level3.js"></script>`. Buka `level3.html` di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

**Langkah 1 — baris `let tasks = [];` dan `let nextId = 1;`**
`tasks` berisi array kosong `[]`. `nextId` berisi `1`.

**Langkah 2 — baris deklarasi `addTask` dan `hitungSelesai`**
JavaScript mencatat nama kedua function beserta parameternya. Belum ada yang dijalankan.

**Langkah 3 — baris `addTask(tasks, "Belajar Parameter")`**
Parameter masuk: `taskList` = `[]` (menunjuk ke array `tasks`), `judul` = `"Belajar Parameter"`.
- `judul.trim()` tidak kosong, jadi `return null` dilewati.
- Dibuat object `{ id: 1, title: "Belajar Parameter", completed: false }`, lalu `nextId` berubah jadi `2`.
- `taskList.push(task)` membuat `tasks` berisi 1 element.
- `return task` mengirim object itu ke pemanggil, lalu function berhenti. Nilainya disimpan ke `taskBaru`.

**Langkah 4 — baris `console.log("Task baru: ...")`**
`taskBaru.id` = `1` dan `taskBaru.title` = `"Belajar Parameter"`, jadi yang dicetak: `Task baru: #1 Belajar Parameter`.

**Langkah 5 — baris `tasks[0].completed = true`**
Task pertama berubah dari `completed: false` jadi `completed: true`.

**Langkah 6 — baris `addTask(tasks, "Belajar Return")`**
Parameter masuk: `taskList` = array berisi 1 task, `judul` = `"Belajar Return"`.
Dibuat object `{ id: 2, title: "Belajar Return", completed: false }`, `nextId` berubah jadi `3`, `tasks` sekarang berisi 2 element. `return task` mengirim object-nya, tapi hasilnya tidak disimpan siapa-siapa jadi langsung dibuang. Tidak ada output di langkah ini.

**Langkah 7 — baris `console.log("Jumlah selesai: ...")`**
`hitungSelesai(tasks)` dipanggil. Parameter `taskList` = 2 task (yang pertama selesai, yang kedua belum).

| Putaran | Nilai `i` | `taskList[i].completed`? | Isi `jumlah` setelah baris `jumlah = jumlah + 1` |
|---|---|---|---|
| 1 | 0 | ya | 1 |
| 2 | 1 | tidak | 1 |
| 3 | 2 | — | loop berhenti |

Function mengembalikan (return) `1`. Karena `1` digabung dengan teks, yang dicetak: `Jumlah selesai: 1`.

**Langkah 8 — baris `console.log("Judul kosong -> ...")`**
`addTask(tasks, "")` dipanggil. Parameter `judul` = `""`. Karena kosong, `return null` dijalankan di baris pertama — `tasks` dan `nextId` tidak berubah. Yang dicetak: `Judul kosong -> null`.

**Output akhir:**
```
Task baru: #1 Belajar Parameter
Jumlah selesai: 1
Judul kosong -> null
```

## Analogi
Function seperti **loket pustakawan**. Kamu menyerahkan formulir anggota dan judul buku yang ingin dipinjam (parameter), lalu pustakawan mengembalikan struk pinjaman berisi nomor peminjaman (return). Tanpa formulir, pustakawan tidak tahu harus melayani apa; tanpa struk, kamu tidak pernah tahu hasil layanannya.

## Dipakai untuk Apa
- `createTask(judul)` — menerima judul, mengembalikan task baru (materi 27)
- `getAllTasks()` — mengembalikan seluruh array task untuk ditampilkan (materi 28)
- `getTaskById(id)` — menerima id, mengembalikan satu task atau `null`
- Validasi input dengan early return sebelum data diproses
- Menghitung ringkasan, misalnya jumlah task yang belum selesai

## Kesalahan Umum yang Sering Terjadi
- **Lupa `return`**: Function tetap berjalan, tapi hasilnya jadi `undefined`. Variabel penerima ikut `undefined`. Selalu akhiri function dengan `return` bila butuh hasil.
- **Urutan argument terbalik**: Menulis `addTask("Belajar", tasks)` membuat `taskList` berisi teks dan `judul` berisi array, sehingga `push` error atau data tersimpan rusak. Cocokkan urutan argument dengan urutan parameter.
- **Jumlah argument tidak cocok**: Argument kurang berarti parameternya `undefined` sampai muncul error saat dipakai; argument berlebih diam-dibuang. Periksa lagi kurung pemanggilannya.
- **Kode setelah `return` tidak jalan**: `return` langsung menghentikan function, jadi baris di bawahnya mustahil dieksekusi. Taruh `return` sebagai perintah terakhir di cabangnya.
- **Mencetak function, bukan hasilnya**: `console.log(hitungSelesai)` menampilkan isi function, bukan angka. Yang benar: `console.log(hitungSelesai(tasks))`.

## Soal Latihan & Jawaban
### Soal
Buat function `cariTask(taskList, id)` yang mencari task berdasarkan id, lalu mengembalikan object task-nya. Jika tidak ditemukan, kembalikan `null`. Uji dengan id yang ada dan id yang tidak ada.

### Jawaban
```js
// Data Task Manager
let tasks = [
  { id: 1, title: "Belajar Parameter", completed: false },
  { id: 2, title: "Belajar Return", completed: false }
];

// Cari task berdasarkan id, hasilnya dikembalikan ke pemanggil
function cariTask(taskList, id) {
  for (let i = 0; i < taskList.length; i++) {
    if (taskList[i].id === id) {
      return taskList[i]; // ketemu: kirim task-nya keluar
    }
  }
  return null; // tidak ketemu
}

console.log(cariTask(tasks, 2).title); // "Belajar Return"
console.log(cariTask(tasks, 99));       // null
```
