# Integrating localStorage dengan CRUD

## Penjelasan
Sekarang kamu punya dua bagian yang terpisah: fungsi CRUD (27–30) yang bekerja di memori, dan `localStorage` (31–32) yang bisa menyimpan teks secara permanen. **Integrasi** berarti menyambung keduanya supaya setiap perubahan data langsung tersimpan, dan aplikasi selalu memulai dari data tersimpan.

Dua function penyambung:
- `saveTasks()` — `JSON.stringify(tasks)` lalu `localStorage.setItem("tasks", ...)`. Dipanggil **setiap kali** `tasks` berubah: setelah CREATE, UPDATE, dan DELETE.
- `loadTasks()` — ambil kunci `tasks` dari localStorage; kalau ada isinya, `JSON.parse` jadi array; kalau belum ada, pakai array kosong `[]`. Dipanggil **satu kali saat aplikasi mulai**.

Prinsip penting: **array `tasks` adalah sumber utama saat aplikasi berjalan, localStorage hanya salinan yang awet.** Alurnya selalu dua arah — mulai aplikasi: localStorage → `tasks`; ada perubahan: `tasks` → localStorage.

## Fungsi
Tanpa integrasi ini, semua CRUD kamu hilang begitu tombol refresh ditekan — user merasa aplikasinya rusak. Dengan integrasi ini, task yang ditambah, diubah, atau dihapus tetap sama persis saat aplikasi dibuka lagi besok. Ini adalah perbedaan antara aplikasi mainan dan aplikasi yang benar-benar bisa dipakai.

## Cara Pengimplementasian / Code
```js
let tasks = [];
let nextId = 1;

// Simpan semua task ke localStorage (wajib string)
function saveTasks() {
  localStorage.setItem("tasks", JSON.stringify(tasks));
}

// Muat task saat aplikasi mulai; belum ada data → mulai kosong
function loadTasks() {
  let teks = localStorage.getItem("tasks");
  tasks = teks ? JSON.parse(teks) : [];
  // Sesuaikan penghasil ID dengan data yang sudah dimuat
  nextId = tasks.length ? tasks[tasks.length - 1].id + 1 : 1;
}

function createTask(title) {
  if (!title || title.trim() === "") return null;
  let newTask = { id: nextId++, title: title.trim(), completed: false };
  tasks.push(newTask);
  saveTasks(); // persist: simpan perubahan
  return newTask;
}

// UPDATE dan DELETE juga wajib menyimpan — polanya persis sama:
// cari task dulu, ubah/hapus, lalu panggil saveTasks() sebelum return.
// Jadi setiap function yang mengubah `tasks` diakhiri dengan saveTasks().

// WAJIB dipanggil paling awal saat aplikasi start
loadTasks();
console.log("Task awal: " + tasks.length);
```

Cara menjalankan: simpan kode di atas sebagai `level3.js`, lalu buat `level3.html` yang memuatnya dengan `<script src="level3.js"></script>`. Buka file HTML itu di browser, tekan **F12** → tab **Console**, lalu jalankan `createTask("Belajar")` di console dan **refresh halaman (F5)** — task masih ada. Cek isinya di **F12 → tab Application → panel Local Storage**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer. Asumsikan localStorage masih kosong.

```js
loadTasks();
console.log("Task awal: " + tasks.length);
createTask("Belajar CRUD");
loadTasks(); // simulasi refresh: muat ulang dari localStorage
console.log("Setelah muat: " + tasks.length);
```

**Langkah 1 — `loadTasks()` dipanggil saat start**
Baris `localStorage.getItem("tasks")` mengembalikan `null` (belum pernah disimpan). Variabel `teks` berisi `null`.

**Langkah 2 — baris `tasks = teks ? ... : []` dan `nextId = ...`**
Karena `teks` bernilai `null` (disebut *falsy*, yaitu nilai yang dianggap salah), cabang kanan yang dipakai: `tasks` diisi array kosong `[]`. Sekarang `tasks` berisi **0 objek**, jadi `nextId` dihitung dari `tasks.length` yang `0` dan diisi `1`.

**Langkah 3 — `console.log("Task awal: " + tasks.length)`**
Menampilkan `"Task awal: 0"`.

**Langkah 4 — `createTask("Belajar CRUD")`**
Validasi lolos. Objek `{ id: 1, title: "Belajar CRUD", completed: false }` dibuat; `nextId` jadi `2`; task masuk ke array — sekarang `tasks` berisi **1 objek**. Lalu `saveTasks()` berjalan: `tasks` diubah jadi string JSON dan disimpan ke kunci `tasks` di localStorage.

**Langkah 5 — `loadTasks()` dipanggil lagi (simulasi refresh)**
`getItem("tasks")` kini mengembalikan string JSON
`[{"id":1,"title":"Belajar CRUD","completed":false}]`, jadi `teks` berisi teks itu. Karena teks tidak kosong, `JSON.parse` dijalankan: `tasks` kembali berisi **1 objek**. `nextId` dihitung ulang: `1 + 1 = 2` — jadi task berikutnya tetap dapat ID 2, tidak bentrok.

**Langkah 6 — `console.log("Setelah muat: " + tasks.length)`**
Array hasil muat berisi 1 elemen.

**Output akhir:**
```
Task awal: 0
Setelah muat: 1
```

## Analogi
Bayangkan pustakawan punya kebiasaan: setiap kali menambah, mengoreksi, atau membuang kartu katalog, dia **langsung menyalin perubahannya ke buku catatan permanen** (`saveTasks`). Setiap pagi sebelum melayani pengunjung, dia **membaca buku catatan itu dulu** untuk mengisi lacinya (`loadTasks`) — sehingga lacinya selalu persis seperti kondisi terakhir kemarin, meski meja sempat dikosongkan.

## Dipakai untuk Apa
- Membuat task manager yang data-nya bertahan setelah browser ditutup
- Menyimpan hasil form yang belum selesai diisi (draft)
- Mengingat pengaturan aplikasi antar sesi (tema, bahasa)
- Pola umum "save on change + load on start" di hampir semua aplikasi web

## Kesalahan Umum yang Sering Terjadi
- **Lupa `saveTasks()` di akhir function CRUD**: di console semua terlihat benar (array berubah), tapi begitu refresh data hilang. Selalu panggil `saveTasks()` setelah `push`, `Object.assign`, atau `splice`.
- **Lupa `loadTasks()` saat start**: `tasks` tetap kosong, lalu `createTask` pertama memanggil `saveTasks()` dan **menimpa data lama** dengan isi baru — data user hilang selamanya. Pastikan `loadTasks()` jalan sebelum operasi CRUD apa pun.
- **`nextId` tidak ikut dimuat**: `nextId` masih `1` padahal data tersimpan sudah ber-ID 3 → task baru mendapat ID 1 yang sudah dipakai, lalu bentrok dan salah terbaca. Hitung ulang `nextId` di dalam `loadTasks()`.
- **`loadTasks()` dipanggil berulang tanpa perlu**: memanggilnya di tengah sesi akan **membuang perubahan di memori** yang belum sempat disimpan dan menimpa `tasks` dengan data lama. Panggil saat start saja.

## Hubungan dengan Materi Sebelumnya
Semua operasi yang disambungkan berasal dari **27. CREATE — Menambah Task Baru** sampai **30. DELETE — Menghapus Task**. Cara menyimpannya memakai **31. localStorage API — setItem, getItem, removeItem**, dan cara mengubah array menjadi teks memakai **32. Serialize & Deserialize — JSON.stringify & JSON.parse**. Setelah materi ini, Checkpoint Level 3 selesai — kamu sudah punya `level3.js` lengkap dengan CRUD + persistence, lalu lanjut ke **34. ## Soal Latihan & Jawaban
### Soal
Lengkapi aplikasi Task Manager: buat function `resetTasks()` yang mengosongkan array `tasks` **dan** menghapus kunci `tasks` di localStorage. Setelah itu, buktikan dengan memanggil `resetTasks()` lalu `loadTasks()` — jumlah task harus kembali 0.

### Jawaban
```js
let tasks = [];
let nextId = 1;

function saveTasks() {
  localStorage.setItem("tasks", JSON.stringify(tasks));
}

function loadTasks() {
  let teks = localStorage.getItem("tasks");
  tasks = teks ? JSON.parse(teks) : [];
  nextId = tasks.length ? tasks[tasks.length - 1].id + 1 : 1;
}

function createTask(title) {
  if (!title || title.trim() === "") return null;
  let newTask = { id: nextId++, title: title.trim(), completed: false };
  tasks.push(newTask);
  saveTasks(); // persist
  return newTask;
}

// Kosongkan memori DAN penyimpanan permanen sekaligus
function resetTasks() {
  tasks = []; // array jadi kosong
  nextId = 1; // penghasil ID kembali ke awal
  localStorage.removeItem("tasks"); // kunci di localStorage dibuang
}

loadTasks();
createTask("Belajar CRUD");
createTask("Latihan localStorage");
console.log("Sebelum reset: " + tasks.length); // Sebelum reset: 2

resetTasks();
console.log(localStorage.getItem("tasks")); // null
loadTasks();
console.log("Sesudah reset: " + tasks.length); // Sesudah reset: 0
```
