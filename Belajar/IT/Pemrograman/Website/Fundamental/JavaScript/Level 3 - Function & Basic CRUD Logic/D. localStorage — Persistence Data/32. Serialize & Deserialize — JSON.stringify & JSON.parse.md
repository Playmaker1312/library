# Serialize & Deserialize — JSON.stringify & JSON.parse

## Penjelasan
`localStorage` hanya bisa menyimpan **string**. Padahal data task kamu berupa array berisi objek. Di sinilah dua method `JSON` masuk:

- **Serialize** = mengubah objek/array menjadi teks. Caranya: `JSON.stringify(obj)`.
- **Deserialize** = mengembalikan teks menjadi objek/array. Caranya: `JSON.parse(teks)`.

JSON (JavaScript Object Notation) adalah format teks standar untuk bertukar data. Bentuknya mirip object literal JavaScript: pakai kurung kurawal `{}`, kurung siku `[]`, dan kunci wajib pakai tanda kutip.

Alur penyimpanan lengkap:
1. Simpan: objek → `JSON.stringify` → string → `localStorage.setItem`.
2. Muat: `localStorage.getItem` → string → `JSON.parse` → objek.

Aturan penting:
- `JSON.parse` **error** (memunculkan `SyntaxError`) kalau teksnya bukan JSON valid.
- Objek hasil `JSON.parse` adalah objek **baru**, bukan objek yang sama seperti sebelum diserialize.
- `Date` kembali jadi **string** setelah di-parse — kalau butuh tanggal, tulis ulang dengan `new Date(...)`.

## Fungsi
`JSON.stringify` dan `JSON.parse` adalah jembatan antara dunia objek JavaScript dan dunia teks. Tanpanya, data yang disimpan di localStorage rusak jadi `"[object Object]"` dan tidak bisa dipakai lagi. Keduanya juga dipakai di luar localStorage: mengirim data ke server (`fetch`) dan menerima balasan dari server hampir selalu berbentuk JSON.

## Cara Pengimplementasian / Code
```js
// Data contoh: array berisi 2 objek task
let tasks = [
  { id: 1, title: "Belajar CRUD", completed: false },
  { id: 2, title: "Baca dokumentasi", completed: true }
];

// SERIALIZE: objek → string
let teksJSON = JSON.stringify(tasks);
console.log(typeof teksJSON); // "string"
console.log(teksJSON);

// Simpan ke localStorage (wajib string)
localStorage.setItem("tasks", teksJSON);

// DESERIALIZE: string → objek
let muat = JSON.parse(localStorage.getItem("tasks"));
console.log(Array.isArray(muat)); // true — sudah jadi array lagi
console.log(muat[0].title);       // "Belajar CRUD"

// BONUS: satu objek juga bisa diserialize
console.log(JSON.stringify({ id: 3, completed: false }));
console.log(JSON.parse('{"nama":"Andi"}').nama); // "Andi"
```

Cara menjalankan: simpan kode di atas sebagai `level3.js`, lalu buat `level3.html` yang memuatnya dengan `<script src="level3.js"></script>`. Buka file HTML itu di browser, tekan **F12** → tab **Console**. Cek hasil simpannya di **F12 → tab Application → panel Local Storage** — nilai kunci `tasks` akan terlihat sebagai satu teks panjang.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

```js
let tasks = [{ id: 1, title: "Belajar CRUD", completed: false }];
let teksJSON = JSON.stringify(tasks);
localStorage.setItem("tasks", teksJSON);
let muat = JSON.parse(localStorage.getItem("tasks"));
console.log(typeof teksJSON);
console.log(muat[0].title);
```

**Langkah 1 — baris `let tasks = [...]`**
`tasks` berisi **1 objek** bertipe `object`, berisi property `id`, `title`, dan `completed`.

**Langkah 2 — baris `let teksJSON = JSON.stringify(tasks)`**
Array diubah menjadi teks. Sekarang `teksJSON` berisi **string**:
`[{"id":1,"title":"Belajar CRUD","completed":false}]`
Isi lamanya `tasks` tidak berubah — masih array 1 objek.

**Langkah 3 — baris `setItem("tasks", teksJSON)`**
String JSON tadi disimpan ke localStorage di kunci `tasks`.

**Langkah 4 — baris `getItem("tasks")`**
Browser mengembalikan string yang tadi disimpan, yaitu
`[{"id":1,"title":"Belajar CRUD","completed":false}]` — masih teks.

**Langkah 5 — baris `JSON.parse(...)`**
Teks itu dibaca dan diubah kembali menjadi array. Variabel `muat` kini berisi **1 objek** bertipe `object` lagi, isinya sama persis dengan `tasks` awal — tapi ini objek baru yang terpisah.

**Langkah 6 — baris `console.log(typeof teksJSON)`**
`teksJSON` bertipe string, jadi hasilnya `"string"`.

**Langkah 7 — baris `console.log(muat[0].title)`**
`muat[0]` adalah objek task pertama; property `title`-nya berisi `"Belajar CRUD"`.

**Output akhir:**
```
string
Belajar CRUD
```

## Analogi
Bayangkan pustakawan yang harus pindah ke gedung perpustakaan baru. Isi lacinya berupa kartu-kartu (objek) yang tidak bisa langsung dimasukkan ke dalam koper. Dia **menyalin seluruh isi laci menjadi daftar tulis tangan di kertas** (`JSON.stringify`) — muat di koper dan bisa dibawa. Setelah sampai gedung baru, dia **menyalin kembali daftar itu ke kartu-kartu baru** (`JSON.parse`) supaya bisa dipakai seperti sedia kala. Kertasnya tidak bisa dipakai menggantikan kartu sebelum ditulis ulang.

## Dipakai untuk Apa
- Menyimpan array task ke localStorage (kebutuhan utama Task Manager)
- Mengirim data ke server dan membaca balasannya (format standar `fetch`)
- Menyalin objek kompleks menjadi teks untuk dikirim lewat pesan/URL
- Menyimpan konfigurasi aplikasi dalam format yang mudah dibaca manusia
- Debugging: menampilkan isi objek dalam bentuk teks yang rapi

## Kesalahan Umum yang Sering Terjadi
- **`JSON.parse` pada teks yang bukan JSON**: `JSON.parse("belajar")` memunculkan `SyntaxError` dan menghentikan kode. Hindari: cek dulu `let teks = localStorage.getItem("tasks"); let data = teks ? JSON.parse(teks) : [];`
- **Lupa `stringify` saat menyimpan**: nilai jadi `"[object Object]"`, dan saat dibaca kembali `JSON.parse` langsung error karena bukan JSON.
- **Lupa `parse` saat membaca**: `tasks.length` jadi panjang teks bukan jumlah task, dan `tasks.map(...)` error karena string bukan array.
- **Mengira hasil parse identik dengan aslinya**: objek `Date` kembali jadi string (`"2026-10-15T..."`). Kalau butuh tanggal, tulis ulang: `new Date(data.createdAt)`.
- **Mengubah array asli saat menyimpan**: `JSON.stringify` tidak mengubah data asli — tapi sering orang salah mengira `tasks` sudah jadi string padahal masih array. Yang jadi string hanya nilai yang dikembalikan `JSON.stringify`.

## Soal Latihan & Jawaban
### Soal
Simpan objek user `{ username: "andi", login: true }` ke localStorage dengan kunci `userAktif`, lalu muat ulang ke variabel baru. Tampilkan tipenya sebelum dan sesudah di-parse, lalu buktikan isinya sama dengan objek awal.

### Jawaban
```js
let user = { username: "andi", login: true };

// Simpan: object → string → localStorage
let sebelum = JSON.stringify(user);
localStorage.setItem("userAktif", sebelum);
console.log("Sebelum parse:", typeof sebelum); // string

// Muat: localStorage → string → object
let hasil = JSON.parse(localStorage.getItem("userAktif"));
console.log("Sesudah parse:", typeof hasil); // object
console.log("Sama?", hasil.username === user.username); // true
console.log("Login:", hasil.login); // true
```
