# localStorage API — setItem, getItem, removeItem

## Penjelasan
`localStorage` adalah penyimpanan key–value (kunci dan nilai) milik browser yang **persistent** — data tetap ada walaupun tab ditutup atau halaman di-refresh. Key-nya berupa teks, dan nilainya juga wajib berupa teks (string).

Empat method utama:
- `localStorage.setItem(key, value)` — **menyimpan** data. Kalau kunci sudah pernah dipakai, nilai lama **ditimpa**, bukan ditambah.
- `localStorage.getItem(key)` — **mengambil** nilai. Hasilnya string, atau `null` kalau kunci tidak ditemukan.
- `localStorage.removeItem(key)` — **menghapus** satu kunci beserta isinya.
- `localStorage.clear()` — **menghapus semua** kunci di halaman ini. Jauh lebih berbahaya dari `removeItem`.

Aturan penting:
- Hanya menyimpan **string**. Angka, boolean, dan objek harus diubah dulu (lihat materi 32).
- Data dibatasi per **origin** (per alamat website). localStorage dari situs A tidak bisa dibaca situs B.
- Ada batas kapasitas (sekitar 5 MB per origin). Ini bukan tempat menyimpan file besar.

## Fungsi
Selama ini semua data Task Manager cuma hidup di memori komputer. Halaman di-refresh → `tasks` kembali kosong dan semua kerjaan hilang. `localStorage` menyelesaikan masalah itu: data task disimpan di browser, jadi aplikasi bisa membacanya lagi kali berikutnya dibuka. Tanpa `localStorage`, task manager kamu cuma mainan yang harus diketik ulang tiap kali.

## Cara Pengimplementasian / Code
```js
// Simpan data — semua nilainya berupa string
localStorage.setItem("namaUser", "Andi");
localStorage.setItem("sedangLogin", "true");
localStorage.setItem("usia", "25");

// Ambil data — hasilnya selalu string
let nama = localStorage.getItem("namaUser");
console.log(nama);                              // "Andi"
console.log(localStorage.getItem("usia") + 1);  // "251" (string digabung!)
console.log(localStorage.getItem("kunciHilang")); // null (kunci tidak ada)

// Hapus satu kunci
localStorage.removeItem("sedangLogin");

// Hapus SEMUA kunci — hati-hati, tidak bisa diurungkan
// localStorage.clear();
```

Cara menjalankan: simpan kode di atas sebagai `level3.js`, lalu buat `level3.html` yang memuatnya dengan `<script src="level3.js"></script>`. Buka file HTML itu di browser, tekan **F12** → tab **Console**. Untuk melihat isi penyimpanannya: buka **F12 → tab Application → panel Local Storage**, lalu klik file kamu — semua kunci dan nilai terlihat di sana dan bisa dihapus manual.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

```js
localStorage.setItem("namaUser", "Andi");
localStorage.setItem("usia", "25");
let nama = localStorage.getItem("namaUser");
console.log(localStorage.getItem("usia") + 1);
localStorage.removeItem("usia");
console.log(localStorage.getItem("usia"));
```

**Langkah 1 — baris `setItem("namaUser", "Andi")`**
Browser menyimpan pasangan kunci `"namaUser"` dengan nilai `"Andi"`. localStorage kini berisi **1 kunci**.

**Langkah 2 — baris `setItem("usia", "25")`**
Kunci baru ditambahkan. localStorage kini berisi **2 kunci**: `namaUser` → `"Andi"`, `usia` → `"25"`.

**Langkah 3 — baris `let nama = localStorage.getItem("namaUser")`**
Browser mencari kunci `namaUser`, ketemu, lalu mengembalikan string `"Andi"`. Variabel `nama` kini berisi `"Andi"`.

**Langkah 4 — baris `getItem("usia") + 1`**
Nilai `"25"` bertipe string, jadi tanda `+` diartikan **penggabungan string**, bukan penjumlahan. `"25" + 1` menghasilkan `"251"`. Ini bukan 26, dan bukan error — memang salah paham tipe data.

**Langkah 5 — baris `removeItem("usia")`**
Kunci `usia` beserta isinya dihapus. localStorage kini berisi **1 kunci** lagi: `namaUser`.

**Langkah 6 — baris `getItem("usia")`**
Kunci `usia` sudah tidak ada, jadi `getItem` mengembalikan `null`.

**Output akhir:**
```
Andi
251
null
```

## Analogi
`localStorage` adalah **laci arsip permanen di meja pustakawan**. Tiap berkas di laci diberi label nama (kunci) dan isinya ditulis di kertas (nilai) — semuanya berupa tulisan. Pustakawan bisa menulis berkas baru (`setItem`), mengambil berkas berlabel tertentu (`getItem`), atau menarik keluar satu berkas (`removeItem`). Yang penting: laci ini tidak ikut hilang saat pustakawan pulang kerja (browser ditutup) — lacinya tetap terisi besok pagi.

## Dipakai untuk Apa
- Menyimpan daftar task supaya tidak hilang saat refresh
- Mengingat preferensi user: tema gelap/terang, bahasa
- Menyimpan status login sementara di browser
- Menyimpan item keranjang belanja antar kunjungan
- Menyimpan progres permainan atau kuis di browser

## Kesalahan Umum yang Sering Terjadi
- **Menyimpan objek/array langsung**: `localStorage.setItem("tasks", tasks)` mengubah isi menjadi teks `"[object Object]"` — data rusak dan tidak bisa dibaca lagi. Hindari: bungkus dengan `JSON.stringify()` (materi 32).
- **Lupa `getItem` selalu mengembalikan string**: `localStorage.getItem("usia") + 1` menghasilkan `"251"`, bukan `26`. Konversi dulu dengan `Number(...)` kalau butuh angka.
- **Menganggap kunci kosong berarti `undefined`**: kunci yang tidak ada selalu mengembalikan `null`. Cek dengan `if (nilai === null)` atau cukup `if (nilai)`.
- **`clear()` menghapus semuanya**: satu panggilan `localStorage.clear()` membuang semua data aplikasi di origin itu, termasuk kunci lain yang bukan milikmu. Pakai `removeItem` untuk kunci tertentu.
- **Menyimpan dua kali ke kunci yang sama**: nilai lama langsung tertimpa. localStorage bukan array — satu kunci hanya bisa berisi satu nilai.

## Hubungan dengan Materi Sebelumnya
Nilai yang disimpan berhubungan dengan **5. Tipe Data — String, Number, Boolean, null, undefined** — khususnya string dan `null` sebagai tanda "kunci tidak ada". Data yang mau disimpan berasal dari operasi CRUD: **27. CREATE — Menambah Task Baru** sampai **30. DELETE — Menghapus Task**. Karena localStorage hanya bisa menyimpan teks, langkah wajib berikutnya adalah **32. Serialize & Deserialize — JSON.stringify & JSON.parse**.

## Soal Latihan & Jawaban
### Soal
Simpan preferensi user ke localStorage dengan kunci `preferensiUser` berisi objek `{ tema: "dark", bahasa: "id" }`, lalu baca lagi dan tampilkan isi `tema`. Terakhir, hapus kunci itu dan buktikan isinya sudah `null`.

### Jawaban
```js
let preferensi = { tema: "dark", bahasa: "id" };

// Objek tidak bisa disimpan langsung → ubah ke string JSON dulu (materi 32)
localStorage.setItem("preferensiUser", JSON.stringify(preferensi));

// Baca lagi, lalu ubah kembali ke objek
let muat = JSON.parse(localStorage.getItem("preferensiUser"));
console.log("Tema: " + muat.tema); // Tema: dark

// Hapus kunci dan buktikan sudah hilang
localStorage.removeItem("preferensiUser");
console.log(localStorage.getItem("preferensiUser")); // null
```
