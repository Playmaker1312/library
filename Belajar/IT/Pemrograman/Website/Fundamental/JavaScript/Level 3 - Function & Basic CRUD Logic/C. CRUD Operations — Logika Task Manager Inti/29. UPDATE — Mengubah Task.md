# UPDATE — Mengubah Task

## Penjelasan
UPDATE adalah operasi mengubah data yang sudah ada. Di Task Manager, function `updateTask(id, updates)` menerima dua parameter: `id` (ID task yang mau diubah) dan `updates` (objek berisi property baru, misalnya `{ completed: true }`).

Cara kerjanya:
- Cari task memakai `tasks.find(t => t.id === id)`. Kalau tidak ketemu, langsung `return null` — proses berhenti sebelum ada yang diubah.
- Kalau ketemu, jalankan `Object.assign(task, updates)`. `Object.assign(target, source)` adalah cara menyalin semua property dari `source` ke `target` — proses ini sering disebut **merge** (menggabung).
- Karena objek task diubah langsung di tempat, array `tasks` ikut ter-update tanpa perlu `push` apa pun.
- Return task yang sudah berubah supaya pemanggil tahu hasilnya.

Aturan penting: property yang tidak ada di `updates` tidak akan tersentuh. `updateTask(1, { completed: true })` hanya mengubah `completed`; `title`, `id`, dan `createdAt` tetap seperti semula.

## Fungsi
Tanpa UPDATE, satu-satunya cara "mengubah" task adalah menghapusnya lalu membuatnya lagi — dan itu membuang ID serta waktu pembuatannya. UPDATE membuat perubahan jadi murah dan aman: user bisa menandai task selesai, memperbaiki judul yang salah ketik, atau mengubah prioritas, semua pada objek yang sama.

## Cara Pengimplementasian / Code
```js
// Data contoh: 2 task sudah ada
let tasks = [
  { id: 1, title: "Belajar CRUD", completed: false },
  { id: 2, title: "Baca dokumentasi", completed: false }
];

function updateTask(id, updates) {
  // Cari task yang ID-nya cocok
  let task = tasks.find(t => t.id === id);
  if (!task) return null; // tidak ketemu → gagal, tidak ada yang diubah

  // Salin semua property dari updates ke task (merge/gabung)
  Object.assign(task, updates);
  return task; // kembalikan task yang sudah berubah
}

// Contoh pemakaian
console.log(updateTask(1, { completed: true })); // tandai selesai
console.log(updateTask(1, { title: "Mahir CRUD" })); // ganti judul
console.log(updateTask(99, { completed: true })); // tidak ada → null
console.log(tasks[0]);
```

Cara menjalankan: simpan kode di atas sebagai `level3.js`, lalu buat `level3.html` yang memuatnya dengan `<script src="level3.js"></script>`. Buka file HTML itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

```js
console.log(updateTask(1, { completed: true }));
console.log(updateTask(99, { completed: true }));
console.log(tasks[0]);
```

**Langkah 1 — pembacaan awal `tasks`**
`tasks` berisi **2 objek**. Task pertama: `{ id: 1, title: "Belajar CRUD", completed: false }`.

**Langkah 2 — `updateTask(1, { completed: true })` mulai berjalan**
Parameter `id` berisi `1`, parameter `updates` berisi objek `{ completed: true }`.

**Langkah 3 — baris `let task = tasks.find(...)`**
`find` menemukan objek di index 0 karena ID-nya `1`. Variabel `task` kini menunjuk ke objek pertama di array `tasks`. Belum ada yang berubah.

**Langkah 4 — baris `if (!task) return null;`**
`task` ada isinya, jadi kondisi tidak terpenuhi. Eksekusi lanjut ke bawah.

**Langkah 5 — baris `Object.assign(task, updates);`**
Property `completed` dari `updates` disalin ke objek `task`. Sekarang task pertama menjadi `{ id: 1, title: "Belajar CRUD", completed: true }`. Judul dan ID tidak berubah. Karena `task` adalah objek yang sama dengan `tasks[0]`, array `tasks` otomatis ikut berubah — sekarang `tasks` tetap berisi 2 objek, tapi isinya sudah terbarui.

**Langkah 6 — baris `return task;`**
Function mengembalikan task yang sudah berubah, dan `console.log` menampilkannya.

**Langkah 7 — `updateTask(99, { completed: true })`**
`find` memeriksa semua isi `tasks` dan tidak menemukan ID `99`, jadi `task` bernilai `undefined`. Baris `if (!task) return null;` terpenuhi dan function langsung berhenti. `tasks` tidak tersentuh.

**Langkah 8 — `console.log(tasks[0])`**
Menampilkan task pertama yang tadi sudah diubah.

**Output akhir:**
```
{ id: 1, title: 'Belajar CRUD', completed: true }
null
{ id: 1, title: 'Belajar CRUD', completed: true }
```

## Analogi
Bayangkan kartu katalog buku di perpustakaan yang sudah lama ada. Pustakawan tidak membuat kartu baru saat ada koreksi — dia cukup **menempel stiker "sudah dibaca"** atau **mengoreksi tulisan judul** di kartu yang sama. Nomor katalog tetap, kartunya tetap, hanya isinya diperbarui. Kalau kartu dengan nomor yang kamu sebutkan tidak ada di laci, pustakawan bilang "tidak ada" dan tidak melakukan apa-apa (`return null`).

## Dipakai untuk Apa
- Menandai task selesai (centang checkbox)
- Mengganti judul task yang salah ketik
- Mengubah prioritas atau kategori task
- Memperbarui data profil user (nama, email)
- Mengubah status pesanan di aplikasi pemesanan

## Kesalahan Umum yang Sering Terjadi
- **Lupa cek task dulu**: langsung `Object.assign(task, updates)` saat `task` bernilai `undefined` memunculkan error `Cannot convert undefined or null to object`. Hindari: selalu `if (!task) return null;` di awal.
- **ID berupa string**: `updateTask("1", ...)` dibandingkan dengan `=== 1` tidak akan pernah cocok, jadi hasilnya selalu `null`. Hindari: samakan tipe datanya, misalnya `Number(id)`.
- **Mengganti seluruh objek**: menulis `tasks[i] = updates` membuat property lain (seperti `id` dan `createdAt`) hilang. Pakai `Object.assign` supaya hanya property yang diubah yang tersentuh.
- **Mengubah ID lewat updates**: `updateTask(1, { id: 5 })` membuat ID tidak konsisten — `nextId` tidak ikut menyesuaikan, sehingga ID bisa bentrok dengan task lain.
- **Menganggap `updates` wajib lengkap**: cukup kirim property yang mau diubah saja, tidak perlu mengirim seluruh isi task.

## Soal Latihan & Jawaban
### Soal
Buat function `renameTask(id, newTitle)` yang mengubah judul task. Function harus menolak ID yang tidak ada dan menolak judul kosong — keduanya mengembalikan `null`. Task yang berhasil diubah dikembalikan. Uji dengan ID 1 (judul baru valid), ID 1 (judul kosong), dan ID 99.

### Jawaban
```js
let tasks = [
  { id: 1, title: "Belajar CRUD", completed: false },
  { id: 2, title: "Baca dokumentasi", completed: false }
];

function updateTask(id, updates) {
  let task = tasks.find(t => t.id === id);
  if (!task) return null;
  Object.assign(task, updates);
  return task;
}

function renameTask(id, newTitle) {
  // Validasi: judul wajib terisi
  if (!newTitle || newTitle.trim() === "") return null;
  // updateTask mengembalikan null kalau ID tidak ketemu
  return updateTask(id, { title: newTitle.trim() });
}

console.log(renameTask(1, "Mahir CRUD"));   // task dengan judul baru
console.log(renameTask(1, "   "));          // null (judul kosong)
console.log(renameTask(99, "Judul Baru"));  // null (ID tidak ada)
console.log(tasks[0].title);                // Mahir CRUD
```
