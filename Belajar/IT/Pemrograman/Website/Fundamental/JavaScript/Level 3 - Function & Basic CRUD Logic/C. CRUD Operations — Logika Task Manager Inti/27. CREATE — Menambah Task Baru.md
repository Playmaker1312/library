# CREATE — Menambah Task Baru

## Penjelasan
CREATE adalah salah satu dari 4 operasi CRUD. CRUD adalah singkatan dari Create (tambah), Read (baca), Update (ubah), dan Delete (hapus) — empat operasi dasar pada data. Di Task Manager, operasi CREATE diwakili oleh function `createTask(title)` yang memasukkan satu task baru ke dalam array `tasks`.

Cara kerjanya:
- Function menerima parameter `title` (judul task) dari pemanggil.
- **Validasi** dijalankan dulu: judul tidak boleh kosong dan tidak boleh hanya spasi. Kalau tidak valid, function langsung `return null`.
- **ID unik** dibuat memakai penghitung `nextId`. Nilai `nextId` dipakai sebagai ID, lalu ditambah 1 (`nextId++`) supaya task berikutnya dapat nomor lain.
- Objek task baru dibuat berisi `id`, `title`, `completed` (awalnya `false`), dan `createdAt` (waktu pembuatan).
- Objek itu di-`push` ke array `tasks`, lalu function mengembalikan task barunya.

## Fungsi
Tanpa function CREATE, aplikasi tidak bisa menerima data baru dari user — semua task harus ditulis manual di dalam kode. Function ini juga jadi tempat validasi data, supaya data kotor (judul kosong) tidak pernah masuk ke array. Setiap kali kamu menambah todo di aplikasi, function inilah yang bekerja di belakang layar.

## Cara Pengimplementasian / Code
```js
// Array global penyimpan semua task
let tasks = [];
// Penghasil ID unik, mulai dari 1
let nextId = 1;

function createTask(title) {
  // Validasi: judul wajib terisi dan bukan spasi doang
  if (!title || title.trim() === "") {
    return null; // langsung gagal, tidak ada yang ditambah
  }
  let newTask = {
    id: nextId++,          // pakai ID sekarang, lalu nextId naik 1
    title: title.trim(),   // buang spasi di awal dan akhir
    completed: false,      // task baru pasti belum selesai
    createdAt: new Date()  // waktu pembuatan task
  };
  tasks.push(newTask);     // masukkan task ke array
  return newTask;          // kembalikan task yang baru dibuat
}

// Contoh pemakaian
console.log(createTask("Belajar CRUD"));
console.log(createTask("   ")); // judul kosong, ditolak
console.log(tasks.length);      // 1
```

Cara menjalankan: simpan kode di atas sebagai `level3.js`, lalu buat `level3.html` yang memuatnya dengan `<script src="level3.js"></script>`. Buka file HTML itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

```js
let tasks = [];
let nextId = 1;
console.log(createTask("Belajar CRUD"));
console.log(createTask("   "));
console.log(tasks.length);
```

**Langkah 1 — baris `let tasks = [];`**
Komputer membuat array kosong. Sekarang `tasks` berisi 0 objek.

**Langkah 2 — baris `let nextId = 1;`**
Komputer membuat wadah `nextId` berisi angka `1`.

**Langkah 3 — `console.log(createTask("Belajar CRUD"))` mulai berjalan**
Function `createTask` dipanggil. Parameter `title` berisi `"Belajar CRUD"`.

**Langkah 4 — baris `if (!title || title.trim() === "")`**
`title` tidak kosong dan hasil `trim()` bukan string kosong, jadi kondisi ini **tidak terpenuhi**. Eksekusi lanjut melewati `return null`.

**Langkah 5 — blok `let newTask = {...}`**
Objek baru dibuat: `id` `1` (nilai `nextId` saat ini), `title` `"Belajar CRUD"`, `completed` `false`, `createdAt` berisi tanggal sekarang. Karena memakai `nextId++`, `nextId` sekarang berubah jadi `2`.

**Langkah 6 — baris `tasks.push(newTask);`**
Task baru masuk ke array. Sekarang `tasks` berisi **1 objek** (id 1).

**Langkah 7 — baris `return newTask;`**
Function mengembalikan objek task tadi. `console.log` menampilkannya.

**Langkah 8 — `console.log(createTask("   "))` mulai berjalan**
Parameter `title` berisi `"   "`. Hasil `title.trim()` adalah string kosong `""`, jadi kondisi validisi **terpenuhi**. Function langsung `return null` — tidak ada objek baru dibuat. `tasks` tetap berisi 1 objek dan `nextId` tetap `2`.

**Langkah 9 — baris `console.log(tasks.length);`**
Array `tasks` berisi 1 elemen, jadi hasilnya `1`.

**Output akhir:**
```
{ id: 1, title: 'Belajar CRUD', completed: false, createdAt: ... }
null
1
```

## Analogi
Prosesnya seperti kamu mengisi **formulir pendaftaran buku baru** di perpustakaan. Kalau kolom judul dikosongkan, pustakawan langsung menolak formulirnya dan mengembalikannya tanpa diproses (`return null`). Kalau isinya lengkap, pustakawan menulis kartu katalog baru, memberi nomor katalog unik yang belum pernah dipakai (ID), lalu menaruh kartu itu ke dalam laci kartu katalog (`push` ke `tasks`).

## Dipakai untuk Apa
- Menambah todo baru di aplikasi to-do list
- Mendaftarkan buku baru ke sistem katalog perpustakaan
- Menyimpan data form pendaftaran (registrasi akun)
- Menambah item ke keranjang belanja
- Mencatat transaksi baru di aplikasi kasir

## Kesalahan Umum yang Sering Terjadi
- **Lupa validasi judul**: tanpa pengecekan `title.trim() === ""`, task kosong ikut masuk array → nanti tampil sebagai baris kosong di tampilan aplikasi. Hindari: selalu validasi sebelum `push`.
- **ID dari `tasks.length`**: memakai `tasks.length + 1` sebagai ID membuat ID duplikat begitu ada task yang dihapus, karena panjang array bisa berkurang lalu naik lagi. Hindari: pakai counter terpisah `nextId`.
- **Lupa `return`**: function tetap jalan, tapi mengembalikan `undefined` → pemanggil tidak tahu task baru berhasil dibuat atau tidak.
- **ID tidak naik (`id: nextId` tanpa `++`)**: semua task mendapat ID yang sama → `getTaskById` nanti hanya menemukan yang pertama.
- **Menyimpan judul tanpa `trim()`**: judul `" Belajar "` tersimpan bersama spasi berlebih dan tampil aneh.

## Soal Latihan & Jawaban
### Soal
Di aplikasi Task Manager, judul task boleh sama persis dengan yang sudah ada, tapi tidak boleh kosong. Buat function `createTask(title)` yang menolak judul kosong, lalu buat 3 task (dua valid, satu kosong) dan tampilkan jumlah task di akhir.

### Jawaban
```js
let tasks = [];
let nextId = 1;

function createTask(title) {
  // Validasi judul wajib terisi
  if (!title || title.trim() === "") {
    return null;
  }
  let newTask = {
    id: nextId++,
    title: title.trim(),
    completed: false,
    createdAt: new Date()
  };
  tasks.push(newTask);
  return newTask;
}

console.log(createTask("Belajar CRUD").id);       // 1
console.log(createTask("Latihan array").id);       // 2
console.log(createTask(""));                       // null
console.log(createTask("   "));                    // null
console.log("Jumlah task: " + tasks.length);       // Jumlah task: 2
```
