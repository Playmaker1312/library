# DELETE — Menghapus Task

## Penjelasan
DELETE adalah operasi menghapus data. Di Task Manager, function `deleteTask(id)` mengeluarkan satu task dari array `tasks` berdasarkan ID-nya.

Cara kerjanya:
- `tasks.findIndex(t => t.id === id)` mencari **posisi (index)** task yang ID-nya cocok. `findIndex` mengembalikan angka index, atau `-1` kalau tidak ada yang cocok. (Bedanya dengan `find`: `find` mengembalikan objeknya, `findIndex` mengembalikan letaknya.)
- Kalau hasilnya `-1`, function langsung `return null` — tidak ada yang dihapus.
- `tasks.splice(index, 1)` menghapus **1 elemen** di posisi `index`. Method ini mengembalikan array berisi elemen yang terhapus, jadi `deleted[0]` adalah task yang tadi ditarik keluar.
- Task terhapus itu dikembalikan sebagai hasil function, supaya pemanggil tahu persis apa yang hilang.

Aturan penting: setelah dihapus, task itu tidak bisa diakses lagi lewat `getTaskById` — ID-nya sudah tidak ada di array. Jangan pakai `pop()` untuk DELETE, karena `pop()` selalu menghapus elemen **terakhir**, bukan task dengan ID yang dituju.

## Fungsi
User pasti butuh cara membuang task yang sudah tidak relevan: tugas selesai yang memenuhi layar, atau task yang dibuat salah. DELETE menyelesaikan masalah itu tanpa meninggalkan sisa data. Karena function mengembalikan task yang terhapus, aplikasi juga bisa menampilkan pesan "Task 'X' dihapus" atau menawarkan tombol urungkan.

## Cara Pengimplementasian / Code
```js
// Data contoh: 3 task sudah ada
let tasks = [
  { id: 1, title: "Belajar CRUD", completed: false },
  { id: 2, title: "Baca dokumentasi", completed: true },
  { id: 3, title: "Review code", completed: false }
];

function deleteTask(id) {
  // Cari posisi task di array; -1 berarti tidak ada
  let index = tasks.findIndex(t => t.id === id);
  if (index === -1) return null; // tidak ketemu → tidak ada yang dihapus

  // Hapus 1 elemen di posisi index; splice mengembalikan yang terhapus
  let deleted = tasks.splice(index, 1);
  return deleted[0]; // kembalikan task yang tadi dihapus
}

// Contoh pemakaian
console.log(deleteTask(2)); // task yang berhasil dihapus
console.log("Sisa task: " + tasks.length); // 2
console.log(getTaskByIdSafe(2)); // undefined — sudah tidak ada
console.log(deleteTask(99)); // null — ID tidak ada

// Helper kecil untuk pengecekan
function getTaskByIdSafe(id) {
  return tasks.find(t => t.id === id);
}
```


**Langkah 1 — pembacaan awal `tasks`**
`tasks` berisi **3 objek**, ID-nya 1, 2, dan 3.

**Langkah 2 — `deleteTask(2)` mulai berjalan**
Parameter `id` berisi `2`.

**Langkah 3 — baris `let index = tasks.findIndex(...)`**
`findIndex` memeriksa isi array satu per satu:

| Putaran | Index | ID elemen | `id === 2`? | Hasil |
|---|---|---|---|---|
| 1 | 0 | 1 | tidak | lanjut |
| 2 | 1 | 2 | **ya** | berhenti, hasil `1` |

Jadi `index` berisi `1`.

**Langkah 4 — baris `if (index === -1) return null;`**
`index` bernilai `1`, bukan `-1`. Kondisi tidak terpenuhi, eksekusi lanjut.

**Langkah 5 — baris `let deleted = tasks.splice(1, 1);`**
Array dimodifikasi: objek di index 1 (task ID 2) ditarik keluar, lalu sisanya digeser menempel. Sekarang `tasks` berisi **2 objek** (ID 1 dan ID 3). Variabel `deleted` berisi array berisi 1 task, yaitu task ID 2.

**Langkah 6 — baris `return deleted[0]`**
Function mengembalikan task ID 2, dan `console.log` menampilkannya.

**Langkah 7 — baris `"Sisa task: " + tasks.length`**
Panjang array kini `2`, jadi hasil penggabungan string adalah `"Sisa task: 2"`.

**Langkah 8 — `getTaskByIdSafe(99)`**
`find` memeriksa ID 1 dan ID 3, tidak ada yang `99`. Function mengembalikan `undefined` — task ID 2 juga sudah tidak muncul karena sudah terhapus.

## Analogi
Prosesnya seperti pustakawan menarik satu kartu katalog keluar dari laci. Kartu itu diambil dari posisinya (`findIndex`), lalu ditarik dan dibuang (`splice`) — lacinya kini berisi satu kartu lebih sedikit. Sebelum dibuang, pustakawan sempat membaca kartu itu sekali lagi (nilai `return`) supaya dia bisa mencatat buku apa yang barusan dikeluarkan.

## Dipakai untuk Apa
- Menghapus todo yang sudah selesai atau tidak diperlukan
- Mengeluarkan buku dari daftar katalog
- Menghapus akun user atau item keranjang belanja
- Membersihkan data sementara (log, notifikasi)
- Fitur "urungkan hapus" — task yang dikembalikan oleh `deleteTask` disimpan dulu untuk bisa dikembalikan

## Kesalahan Umum yang Sering Terjadi
- **Lupa cek `-1`**: kalau `index === -1` tidak dicek, `tasks.splice(-1, 1)` justru menghapus **elemen terakhir** yang tidak dituju. Hindari: selalu `if (index === -1) return null;` sebelum `splice`.
- **Memakai `pop()`**: `pop()` selalu menghapus elemen terakhir tanpa peduli ID — task yang benar masih ada, task salah yang hilang.
- **Salah parameter `splice`**: `splice(index)` tanpa angka kedua menghapus **semua** elemen setelah posisi itu, dan `splice(index, 2)` menghapus dua elemen. Untuk hapus satu task, pakai `splice(index, 1)`.
- **ID dipakai ulang setelah hapus**: mengambil ID dari `tasks.length` membuat ID hasil DELETE bisa dipakai lagi untuk task baru, sehingga data lama tertimpa. Tetap pakai penghitung `nextId` yang tidak pernah mundur.
- **Menyimpan `deleted[0]` tanpa dicek**: array hasil `splice` pasti berisi elemen kalau `index` valid, tapi `deleted[0]` jadi `undefined` kalau parameternya salah — cek dulu sebelum mengakses property-nya.

## Soal Latihan & Jawaban
### Soal
Buat function `deleteCompletedTasks()` yang menghapus **semua** task berstatus `completed: true` dan mengembalikan **jumlah task yang berhasil dihapus**. Uji pada data yang berisi 2 task selesai dan 1 task belum selesai.

### Jawaban
```js
let tasks = [
  { id: 1, title: "Belajar CRUD", completed: true },
  { id: 2, title: "Baca dokumentasi", completed: false },
  { id: 3, title: "Review code", completed: true }
];

function deleteTask(id) {
  let index = tasks.findIndex(t => t.id === id);
  if (index === -1) return null;
  let deleted = tasks.splice(index, 1);
  return deleted[0];
}

function deleteCompletedTasks() {
  let jumlahHapus = 0;
  // Kumpulkan ID dulu, supaya tidak ada ID yang terlewat saat menghapus
  let idSelesai = tasks.filter(t => t.completed).map(t => t.id);
  for (let i = 0; i < idSelesai.length; i++) {
    let hasil = deleteTask(idSelesai[i]);
    if (hasil) jumlahHapus++; // hitung yang benar-benar terhapus
  }
  return jumlahHapus;
}

console.log("Dihapus: " + deleteCompletedTasks()); // Dihapus: 2
console.log("Sisa: " + tasks.length); // Sisa: 1
console.log(tasks[0].title); // Baca dokumentasi
```
