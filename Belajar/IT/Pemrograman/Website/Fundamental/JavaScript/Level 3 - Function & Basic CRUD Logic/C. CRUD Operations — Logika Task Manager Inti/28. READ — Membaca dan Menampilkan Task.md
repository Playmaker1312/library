# READ — Membaca dan Menampilkan Task

## Penjelasan
READ adalah operasi membaca data tanpa mengubahnya. Di Task Manager ada dua kebutuhan baca: membaca **semua** task dan membaca **satu** task tertentu. Keduanya diwakili oleh dua function kecil:

- `getAllTasks()` — mengembalikan seluruh isi array `tasks`.
- `getTaskById(id)` — mengembalikan satu task yang ID-nya cocok, atau `undefined` kalau tidak ada yang cocok.

Inti dari `getTaskById` adalah method array bernama `find`. `find` bekerja dengan mencari elemen pertama yang memenuhi syarat. Syaratnya ditulis sebagai arrow function, misalnya `t => t.id === id`, yang dibaca: "ambil elemen `t` yang `id`-nya sama persis dengan `id` yang dicari". Kalau ketemu, `find` langsung berhenti dan mengembalikan elemen itu.

Aturan penting READ:
- READ tidak mengubah isi `tasks` — kalau berubah, itu berarti kamu salah operasi.
- Hasil `find` bisa `undefined`, jadi selalu cek dulu sebelum dipakai.
- ID task mulai dari 1, bukan 0 (berbeda dengan index array yang mulai dari 0).

## Fungsi
Semua tampilan data di aplikasi berawal dari READ. Kamu butuh `getAllTasks` untuk menggambar daftar task di layar, dan `getTaskById` untuk menampilkan detail satu task atau memastikan task yang mau diubah memang ada. Tanpa READ, operasi UPDATE dan DELETE jadi buta — mereka harus mencari task dulu sebelum bekerja.

## Cara Pengimplementasian / Code
```js
// Data contoh: 3 task sudah ada di array
let tasks = [
  { id: 1, title: "Belajar CRUD", completed: false },
  { id: 2, title: "Baca dokumentasi", completed: false },
  { id: 3, title: "Review code", completed: true }
];

// Ambil semua task
function getAllTasks() {
  return tasks;
}

// Cari satu task berdasarkan ID
function getTaskById(id) {
  // find berhenti di elemen pertama yang cocok, atau undefined
  return tasks.find(t => t.id === id);
}

// Contoh pemakaian
console.log("Jumlah task: " + getAllTasks().length);
console.log(getTaskById(2));
console.log(getTaskById(99)); // tidak ada, hasilnya undefined
```

Cara menjalankan: simpan kode di atas sebagai `level3.js`, lalu buat `level3.html` yang memuatnya dengan `<script src="level3.js"></script>`. Buka file HTML itu di browser, tekan **F12** → tab **Console**.

## Tracing Code (Step-by-Step)
Kita telusuri kode di atas baris demi baris, seolah-olah kita mengikuti komputer.

```js
console.log("Jumlah task: " + getAllTasks().length);
console.log(getTaskById(2));
console.log(getTaskById(99));
```

**Langkah 1 — pembacaan awal `tasks`**
Array `tasks` berisi **3 objek**, dengan ID 1, 2, dan 3.

**Langkah 2 — `getAllTasks()` dipanggil**
Function tidak menerima parameter apa pun. Baris `return tasks` mengembalikan seluruh array. Jadi `getAllTasks().length` adalah `3`. String `"Jumlah task: "` digabung dengan angka 3.

**Langkah 3 — `getTaskById(2)` dipanggil**
Parameter `id` berisi `2`. `find` mulai memeriksa dari index 0:

| Putaran | Index | ID elemen (`tasks[index].id`) | `id === 2`? | Lanjut? |
|---|---|---|---|---|
| 1 | 0 | 1 | tidak | ya |
| 2 | 1 | 2 | **ya** | berhenti |

`find` berhenti di putaran 2 dan mengembalikan objek di index 1, yaitu `{ id: 2, title: "Baca dokumentasi", completed: false }`.

**Langkah 4 — `getTaskById(99)` dipanggil**
Parameter `id` berisi `99`. `find` memeriksa semua isi `tasks`:

| Putaran | Index | ID elemen | `id === 99`? | Lanjut? |
|---|---|---|---|---|
| 1 | 0 | 1 | tidak | ya |
| 2 | 1 | 2 | tidak | ya |
| 3 | 2 | 3 | tidak | ya (habis) |

Semua elemen sudah diperiksa dan tidak ada yang cocok, jadi `find` mengembalikan `undefined`. Isi `tasks` tetap 3 objek, tidak berubah sama sekali.

**Output akhir:**
```
Jumlah task: 3
{ id: 2, title: 'Baca dokumentasi', completed: false }
undefined
```

## Analogi
Bayangkan laci kartu katalog di perpustakaan. `getAllTasks` adalah pustakawan yang menarik keluar **seluruh isi laci** untuk ditampilkan — semua kartu diaangkat, tidak ada yang diubah. `getTaskById` adalah pustakawan yang mencari **satu kartu saja** berdasarkan nomor katalog lalu mengambilnya. Kartu yang dikeluarkan hanya dibaca isinya, tidak dicoret atau diganti.

## Dipakai untuk Apa
- Menampilkan daftar todo di layar aplikasi
- Menampilkan detail satu task saat diklik
- Mengecek apakah ID tertentu ada sebelum mengubah atau menghapus
- Menghitung jumlah task (total, yang selesai, yang belum)
- Menyiapkan data untuk fitur pencarian dan filter

## Kesalahan Umum yang Sering Terjadi
- **Lupa cek `undefined`**: `getTaskById(999).title` langsung menampilkan error `Cannot read properties of undefined`. Hindari: selalu cek `if (task)` sebelum mengakses property.
- **Menyebut ID sebagai index**: ID task mulai dari 1, sedangkan index array mulai dari 0. `tasks[0]` adalah task ber-ID 1, bukan ber-ID 0.
- **Menyalin hasil `getAllTasks()` lalu mengubahnya**: `let daftar = getAllTasks(); daftar.push(...)` ikut mengubah `tasks`, karena keduanya menunjuk ke array yang sama. Kalau ingin aman, salin dengan `let daftar = [...tasks]`.
- **Salah tanda perbandingan**: `t.id === "1"` (string) tidak akan pernah cocok dengan `id` `1` (angka), jadi `find` selalu menghasilkan `undefined`.
- **Menganggap `find` mengembalikan `null`**: yang dikembalikan adalah `undefined`. Kondisi `if (hasil)` tetap work, tapi `hasil === null` akan salah.

## Soal Latihan & Jawaban
### Soal
Buat function `describeTask(id)` yang mengembalikan string `"Judul — Selesai"` atau `"Judul — Belum selesai"` sesuai isi task. Kalau ID tidak ditemukan, kembalikan `"Task tidak ditemukan"`. Uji dengan ID 1, ID 3, dan ID 99.

### Jawaban
```js
let tasks = [
  { id: 1, title: "Belajar CRUD", completed: false },
  { id: 2, title: "Baca dokumentasi", completed: false },
  { id: 3, title: "Review code", completed: true }
];

function getTaskById(id) {
  return tasks.find(t => t.id === id);
}

function describeTask(id) {
  let task = getTaskById(id); // baca task dulu
  if (!task) {
    return "Task tidak ditemukan"; // ID tidak ada
  }
  // completed true → "Selesai", false → "Belum selesai"
  let status = task.completed ? "Selesai" : "Belum selesai";
  return task.title + " — " + status;
}

console.log(describeTask(1)); // Belajar CRUD — Belum selesai
console.log(describeTask(3)); // Review code — Selesai
console.log(describeTask(99)); // Task tidak ditemukan
```
