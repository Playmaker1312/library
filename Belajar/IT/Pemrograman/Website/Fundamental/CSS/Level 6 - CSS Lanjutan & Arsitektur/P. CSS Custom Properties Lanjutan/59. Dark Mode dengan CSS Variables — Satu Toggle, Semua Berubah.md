# 59. Dark Mode dengan CSS Variables — Satu Toggle, Semua Berubah

## Penjelasan

Dark mode dengan CSS Variables: ubah nilai variable, semua komponen yang menggunakan variable itu otomatis berubah.

```css
:root {
  --color-bg: #ffffff;
  --color-text: #111827;
}

[data-theme="dark"] {
  --color-bg: #0f172a;
  --color-text: #f8fafc;
}
/* Semua komponen yang pakai var(--color-bg) dan var(--color-text) otomatis berubah */
```

## Fungsi

- Dark mode tanpa rewrite CSS — cukup ubah variables
- Konsisten — semua komponen ikut dark mode
- Bisa toggle manual + otomatis dari OS

## Cara Pengimplementasian

```css
/* 1. CSS Variables untuk warna */
:root {
  --color-bg: #ffffff;
  --color-text: #111827;
  --color-surface: #f9fafb;
  --color-border: #e5e7eb;
  --color-primary: #2563eb;
}

/* 2. Dark mode via attribute (toggle manual) */
[data-theme="dark"] {
  --color-bg: #0f172a;
  --color-text: #f8fafc;
  --color-surface: #1e293b;
  --color-border: #334155;
  --color-primary: #60a5fa;
}

/* 3. Auto dark mode dari OS */
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) {
    --color-bg: #0f172a;
    --color-text: #f8fafc;
    --color-surface: #1e293b;
    --color-border: #334155;
    --color-primary: #60a5fa;
  }
}

/* 4. Fine tuning untuk dark mode */
[data-theme="dark"] img {
  opacity: 0.8;
  transition: opacity 0.3s;
}
[data-theme="dark"] img:hover { opacity: 1; }

[data-theme="dark"] {
  --shadow-sm: 0 1px 2px rgba(0, 0, 0, 0.3);
  --shadow-md: 0 4px 6px rgba(0, 0, 0, 0.4);
}
```

**JavaScript toggle:**
```javascript
const toggle = document.getElementById('dark-toggle');
toggle.addEventListener('click', () => {
  const theme = document.documentElement.dataset.theme === 'dark' ? 'light' : 'dark';
  document.documentElement.dataset.theme = theme;
  localStorage.setItem('theme', theme);
});

// Restore dari localStorage
const saved = localStorage.getItem('theme');
if (saved) document.documentElement.dataset.theme = saved;
```

## Analogi

Seperti **saklar lampu utama di rumah**. Alih-alih ganti setiap bohlam satu per satu (mode malam), kamu cukup flip satu saklar — semua lampu berubah dari terang ke redup. CSS Variables adalah saklar itu.

```css
/* Tanpa variables — ganti 50 tempat */
.card { background: #f9fafb; }
.header { background: #f9fafb; }
.section { background: #f9fafb; }

/* Dengan variables — ganti 1 tempat */
:root { --color-surface: #f9fafb; }
/* Mode malam: ganti --color-surface di [data-theme="dark"] */
```

## Dipakai Untuk Apa

- Dark mode toggle di website
- Automatic dark mode dari OS
- High contrast mode

## Kesalahan Umum

- **Hanya toggle, tidak hormati OS**: harus pakai `prefers-color-scheme` sebagai default jika user tidak set toggle
- **Lupa image opacity**: gambar terlalu terang di dark mode — turunkan opacity
- **Shadow tetap hitam**: shadow hitam di dark mode tidak terlihat — gunakan shadow yang lebih terang
- **Kontras kurang di dark mode**: pastikan rasio kontras tetap WCAG AA

## Hubungan dengan Materi Sebelumnya

Poin 53: `prefers-color-scheme` untuk dark mode otomatis. Tapi belum ada toggle manual. Poin 10 & 58: CSS Variables dan design tokens. Dark mode adalah **penerapan sempurna** — dengan variables di :root dan override di [data-theme], satu toggle mengubah seluruh tampilan website.

## Soal Latihan

### Soa1 1
Tulis CSS untuk dark mode dengan attribute `[data-theme="dark"]` yang mengubah bg dan text color.

**Jawaban:**
```css
:root { --color-bg: #fff; --color-text: #111; }
[data-theme="dark"] { --color-bg: #0f172a; --color-text: #f8fafc; }
```

### Soal 2
Bagaimana menggabungkan dark mode otomatis (OS) dengan toggle manual?

**Jawaban:**
Gunakan `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { ... } }` untuk auto, dan `[data-theme="dark"] { ... }` untuk toggle manual override.

### Soal 3
Apa yang perlu disesuaikan selain warna di dark mode?

**Jawaban:**
Opacity gambar (turunkan), shadow (terang, bukan gelap), border (lebih terang), dan image/svg dengan fill gelap (invert atau ganti warna).
