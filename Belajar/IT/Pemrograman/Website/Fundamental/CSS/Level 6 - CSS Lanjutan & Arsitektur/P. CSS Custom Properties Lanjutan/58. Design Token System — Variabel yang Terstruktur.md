# 58. Design Token System — Variabel yang Terstruktur

## Penjelasan

Design token adalah **sistem variabel berlapis**: primitive → semantic → component. Ini adalah evolusi dari CSS Variables yang sudah kita gunakan.

**Tiga lapisan:**
1. **Primitive tokens**: warna dasar, spacing mentah, font mentah — jangan langsung dipakai di komponen
2. **Semantic tokens**: makna dari warna — `--color-primary`, `--color-surface`
3. **Component tokens**: spesifik komponen — `--button-bg`, `--card-radius`

```css
:root {
  /* ===== PRIMITIVE TOKENS ===== */
  --blue-50:  #eff6ff;
  --blue-500: #3b82f6;
  --blue-700: #1d4ed8;
  --gray-100: #f3f4f6;
  --gray-500: #6b7280;
  --gray-900: #111827;
  
  /* ===== SEMANTIC TOKENS ===== */
  --color-primary:       var(--blue-500);
  --color-primary-hover: var(--blue-700);
  --color-surface:       white;
  --color-surface-alt:   var(--gray-100);
  --color-text:          var(--gray-900);
  --color-text-muted:    var(--gray-500);
  
  /* ===== COMPONENT TOKENS ===== */
  --button-bg:       var(--color-primary);
  --button-color:    white;
  --button-radius:   var(--radius-md);
  --card-padding:    var(--space-6);
  --card-radius:     var(--radius-lg);
}
```

## Fungsi

- Skalabilitas — mudah ganti warna brand (ubah satu primitive, semua semantic ikut)
- Konsistensi — tidak ada komponen pakai warna langsung tanpa token
- Dokumentasi — design system yang hidup di CSS

## Cara Pengimplementasian

```css
:root {
  /* === PRIMITIVE === */
  /* Warna */
  --blue-50: #eff6ff; --blue-100: #dbeafe;
  --blue-500: #3b82f6; --blue-600: #2563eb; --blue-700: #1d4ed8;
  --slate-50: #f8fafc; --slate-100: #f1f5f9;
  --slate-700: #334155; --slate-900: #0f172a;
  
  /* === SEMANTIC === */
  --color-brand:       var(--blue-600);
  --color-brand-hover: var(--blue-700);
  --color-surface:     white;
  --color-surface-hover: var(--slate-50);
  --color-text:        var(--slate-900);
  --color-text-secondary: var(--slate-700);
  --color-border:      var(--slate-100);
  
  /* === COMPONENT === */
  --btn-primary-bg:       var(--color-brand);
  --btn-primary-color:    white;
  --btn-primary-radius:   8px;
  --card-bg:              var(--color-surface);
  --card-border-color:    var(--color-border);
  --card-border-radius:   12px;
}

/* Komponen hanya pakai component/semantic tokens */
.btn-primary {
  background-color: var(--btn-primary-bg);
  color: var(--btn-primary-color);
  border-radius: var(--btn-primary-radius);
}

.card {
  background-color: var(--card-bg);
  border: 1px solid var(--card-border-color);
  border-radius: var(--card-border-radius);
}
```

## Analogi

Seperti **katalog cat rumah**:
- **Primitive** = warna dasar di pabrik: "Biru 500", "Merah 200" — warna mentah
- **Semantic** = fungsi warna dalam rumah: "Cat Dinding Luar", "Cat Kamar Tidur"
- **Component** = instruksi spesifik: "Cat Pintu Depan pakai Cat Dinding Luar, lapisan 2"

Keuntungan: jika pemilik rumah berganti selera dari biru ke hijau, cukup ganti `--blue-500: #3b82f6` jadi `--green-500: #10b981` di primitive — semua semantic dan komponen otomatis berubah. Tidak perlu cari satu per satu.

## Dipakai Untuk Apa

- Design system yang scalable
- Theming (multi-brand, dark/light)
- Kolaborasi tim — token sebagai bahasa bersama

## Kesalahan Umum

- **Langsung pakai primitive di komponen**: `background: var(--blue-500)` — jika brand ganti warna, harus ganti satu per satu
- **Terlalu banyak lapisan**: 3 lapisan cukup — primitive → semantic → component
- **Token tidak digunakan**: buat token tapi komponen tetap hardcoded
- **Nama token tidak jelas**: `--c1`, `--clr-main` — gunakan nama yang deskriptif

## Hubungan dengan Materi Sebelumnya

Poin 10: CSS Variables pertama kali diperkenalkan. Tapi variabel masih **flat** — semua campur di satu level. **Design token** menambahkan struktur berlapis. Ini adalah praktik profesional yang digunakan oleh design system besar seperti Material UI, Shopify Polaris, dan Tailwind.

## Soal Latihan

### Soal 1
Sebutkan 3 lapisan design token dan fungsinya.

**Jawaban:**
Primitive — warna/ukuran dasar. Semantic — makna/tujuan. Component — spesifik komponen.

### Soal 2
Mengapa komponen jangan langsung pakai primitive token?

**Jawaban:**
Jika brand berubah warna, harus ganti di setiap komponen. Dengan semantic token, cukup ubah mapping primitive → semantic di satu tempat.

### Soal 3
Berikan contoh hierarchy token untuk tombol primary.

**Jawaban:**
Primitive: `--blue-600: #2563eb`. Semantic: `--color-brand: var(--blue-600)`. Component: `--btn-primary-bg: var(--color-brand)`.
