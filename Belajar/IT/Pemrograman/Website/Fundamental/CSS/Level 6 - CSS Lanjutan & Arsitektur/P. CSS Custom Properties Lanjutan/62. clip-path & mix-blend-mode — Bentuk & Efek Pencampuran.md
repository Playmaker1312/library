# 62. clip-path & mix-blend-mode — Bentuk & Efek Pencampuran

## Penjelasan

- **`clip-path`**: memotong elemen menjadi bentuk tertentu
- **`mix-blend-mode`**: mencampur elemen dengan elemen di belakangnya

```css
.clip-circle { clip-path: circle(50%); }
.clip-diagonal { clip-path: polygon(0 0, 100% 0, 100% 85%, 0 100%); }
.blend-text { mix-blend-mode: multiply; }
```

## Fungsi

- **clip-path**: bentuk kreatif — lingkaran, segitiga, diagonal, bentuk kustom
- **mix-blend-mode**: efek tinta/overlay artistik

## Cara Pengimplementasian

```css
/* CLIP-PATH — berbagai bentuk */
.circle { 
  clip-path: circle(50%); 
}

.triangle { 
  clip-path: polygon(50% 0%, 0% 100%, 100% 100%); 
}

.hexagon { 
  clip-path: polygon(50% 0%, 100% 25%, 100% 75%, 50% 100%, 0% 75%, 0% 25%); 
}

.diagonal-hero {
  clip-path: polygon(0 0, 100% 0, 100% 85%, 0 100%);
  /* efek miring di bagian bawah hero */
}

.parallelogram {
  clip-path: polygon(10% 0%, 100% 0%, 90% 100%, 0% 100%);
}

/* Animasi clip-path */
.element {
  clip-path: circle(0%);
  transition: clip-path 0.5s ease;
}
.element:hover {
  clip-path: circle(100%);
}

/* MIX-BLEND-MODE */
.text-on-image {
  mix-blend-mode: multiply;     /* efek tinta di atas gambar */
  color: white;
}

.darken-bg {
  mix-blend-mode: darken;
}

.lighten-bg {
  mix-blend-mode: lighten;
}

.difference-title {
  mix-blend-mode: difference;   /* efek warna terbalik */
  color: white;
}
```

## Analogi

- **clip-path** = **gunting dan kertas**. Kamu gunting kertas berbentuk lingkaran (circle), segitiga (polygon), atau bentuk bebas. Isi kertas tetap utuh, hanya pinggirnya yang digunting.
- **mix-blend-mode** = **cat air di atas gambar**. Saat cat merah diaplikasikan di atas foto, warnanya bercampur — tergantung mode campuran, hasilnya bisa lebih gelap (multiply), lebih terang (screen), atau terbalik (difference).

clip-path mengubah bentuk, mix-blend-mode mengubah cara warna bercampur.

## Dipakai Untuk Apa

- **clip-path**: hero diagonal, avatar lingkaran, gambar bentuk geometris, section divider
- **mix-blend-mode**: teks di atas gambar, efek tinta, overlay artistik

## Kesalahan Umum

- **clip-path memotong interaksi**: area di luar clip-path tidak bisa diklik — pastikan tombol tidak terpotong
- **mix-blend-mode hanya dengan background gambar**: butuh konten di belakang untuk efek pencampuran
- **Animasi clip-path berat**: animasi polygon kompleks bisa berat — gunakan dengan bijak
- **Accessibility**: pastikan konten di luar clip-path tidak menyembunyikan informasi penting

## Hubungan dengan Materi Sebelumnya

Poin 60-61: aspek rasio, object-fit, filter. **clip-path** dan **mix-blend-mode** melengkapi toolkit visual CSS — memberi kemampuan untuk membentuk ulang elemen dan mencampur warnanya secara artistik. Digunakan dengan bijak, efek ini membuat portofolio standout.

## Soal Latihan

### Soal 1
Tulis CSS untuk hero section dengan potongan diagonal di bagian bawah.

**Jawaban:**
```css
.hero {
  clip-path: polygon(0 0, 100% 0, 100% 85%, 0 100%);
}
```

### Soal 2
Apa fungsi `mix-blend-mode: multiply`?

**Jawaban:**
Warna elemen dikalikan dengan warna di belakangnya — hasilnya selalu lebih gelap. Berguna untuk teks yang menyatu dengan gambar.

### Soal 3
Apa yang perlu diperhatikan saat menggunakan clip-path?

**Jawaban:** Konten di luar clip-path tidak terlihat dan tidak interaktif. Pastikan informasi penting dan elemen interaktif (tombol, link) tidak terpotong.
