# 61. filter & backdrop-filter — Efek Visual Canggih

## Penjelasan

- **`filter`**: efek visual langsung pada elemen (gambar, teks, div)
- **`backdrop-filter`**: efek pada area **di belakang** elemen — efek kaca (glassmorphism)

```css
/* Filter pada elemen */
.grayscale { filter: grayscale(100%); }
.blur { filter: blur(4px); }

/* Filter pada area belakang */
.glass {
  backdrop-filter: blur(12px);
  background-color: rgba(255, 255, 255, 0.1);
}
```

## Fungsi

- **filter**: efek instan pada gambar — grayscale, blur, brightness
- **backdrop-filter**: efek kaca transparan — modern, elegan

## Cara Pengimplementasian

```css
/* FILTER — efek pada elemen */
img {
  transition: filter 0.3s ease;
}

.grayscale {
  filter: grayscale(100%);     /* hitam putih */
}

.sepia {
  filter: sepia(50%);          /* efek vintage */
}

.brightness {
  filter: brightness(1.2);     /* lebih terang */
}

.contrast {
  filter: contrast(150%);      /* kontras tinggi */
}

.blur {
  filter: blur(4px);           /* buram */
}

.shadow {
  filter: drop-shadow(2px 4px 6px black); /* bayangan (ikuti bentuk) */
}

/* Multiple filters */
img:hover {
  filter: brightness(1.1) contrast(110%);
}

/* BACKDROP-FILTER — efek kaca */
.glass-header {
  background-color: rgba(255, 255, 255, 0.7);
  backdrop-filter: blur(10px);
  -webkit-backdrop-filter: blur(10px);
}

.glass-card {
  background: rgba(255, 255, 255, 0.15);
  backdrop-filter: blur(20px);
  border: 1px solid rgba(255, 255, 255, 0.2);
  border-radius: var(--radius-lg);
}

/* Hero dengan overlay + glass */
.hero {
  position: relative;
  background-image: url('hero.jpg');
  background-size: cover;
}

.hero-content {
  background-color: rgba(0, 0, 0, 0.3);
  backdrop-filter: blur(4px);
  padding: var(--space-8);
  color: white;
}
```

## Analogi

- **filter** = **kacamata efek di rumah**. Pakai kacamata hitam (brightness turun), kacamata biru (sepia), atau kacamata buram (blur). Efeknya pada apa yang kamu lihat langsung (elemen itu sendiri).
- **backdrop-filter** = **kaca buram di kamar mandi**. Kaca itu sendiri bening (transparan), tapi yang di belakangnya kelihatan buram. Kamu bisa lihat ada orang di belakang kaca, tapi tidak jelas siapa.

Filter bekerja pada elemen itu sendiri. Backdrop-filter bekerja pada **apa yang ada di belakang** elemen.

## Dipakai Untuk Apa

- **filter**: gambar grayscale → berwarna saat hover, efek loading blur, brightness untuk image hover
- **backdrop-filter**: header glass, card glassmorphism, modal dengan blur di belakang

## Kesalahan Umum

- **backdrop-filter tidak didukung browser lama**: fallback dengan background-color solid — efek kaca hanya hiasan, bukan fungsi utama
- **Lupa -webkit- prefix untuk Safari**: `-webkit-backdrop-filter` untuk iOS Safari
- **Drop-shadow vs box-shadow**: `drop-shadow` mengikuti bentuk elemen (termasuk alpha), `box-shadow` mengikuti box. Untuk gambar PNG transparan, drop-shadow lebih tepat
- **Filter performa**: terlalu banyak filter bisa berat — terutama backdrop-filter di area besar

## Hubungan dengan Materi Sebelumnya

Poin 23: background image dan gradien. **filter dan backdrop-filter** menambahkan efek visual tingkat lanjut — grayscale, blur, glass effect. Ini memberi dimensi artistik pada CSS tanpa gambar editing.

## Soal Latihan

### Soal 1
Tulis CSS untuk membuat gambar grayscale yang berwarna saat hover.

**Jawaban:**
```css
img { filter: grayscale(100%); transition: filter 0.3s ease; }
img:hover { filter: grayscale(0%); }
```

### Soal 2
Apa perbedaan filter dan backdrop-filter?

**Jawaban:**
`filter` memengaruhi elemen itu sendiri. `backdrop-filter` memengaruhi area di **belakang** elemen — elemennya transparan, yang di belakangnya yang kena efek.

### Soal 3
Tulis CSS untuk header dengan efek glass (blur + transparan).

**Jawaban:**
```css
header {
  background-color: rgba(255, 255, 255, 0.7);
  backdrop-filter: blur(10px);
  -webkit-backdrop-filter: blur(10px);
}
```
