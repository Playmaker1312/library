# 46. Kapan Flexbox vs Grid — Aturan Praktis

## Penjelasan

Pertanyaan paling umum: **Kapan pakai flexbox, kapan pakai grid?**

**Gunakan Flexbox untuk:**
- Navigasi (satu baris)
- Tombol dengan ikon
- Card content (stack vertikal)
- Centering elemen
- Komponen kecil
- Layout satu dimensi

**Gunakan Grid untuk:**
- Layout halaman keseluruhan
- Galeri gambar
- Dashboard
- Layout yang butuh alignment di baris DAN kolom
- Layout dua dimensi

## Fungsi

- Memilih tool yang tepat untuk setiap layout
- Menghindari "flexbox untuk semuanya" atau "grid untuk semuanya"

## Cara Pengimplementasian

```css
/* ✅ FLEXBOX — navigasi */
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

/* ✅ FLEXBOX — card dengan footer sticky */
.card {
  display: flex;
  flex-direction: column;
  height: 100%;
}
.card-footer { margin-top: auto; }

/* ✅ FLEXBOX — centering */
.hero { display: flex; align-items: center; justify-content: center; }

/* ✅ GRID — layout halaman */
.page {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}

/* ✅ GRID — galeri foto */
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  gap: var(--space-4);
}

/* ✅ GRID — dashboard */
.dashboard {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-rows: minmax(100px, auto);
  gap: var(--space-4);
}

/* ✅ KOMBINASI — Grid untuk layout macro, Flexbox untuk micro */
/* Grid untuk halaman, flexbox untuk komponen di dalamnya */
```

## Analogi

Flexbox seperti **kemeja dengan satu kancing baris** — mengatur satu baris kancing.

Grid seperti **kemeja dengan kancing baris dan kolom plus saku di dada** — mengatur banyak elemen dalam dua dimensi.

- Mau atur navigasi (satu baris) → Flexbox
- Mau atur halaman penuh (header, sidebar, main, footer) → Grid
- Mau atur tombol di card → Flexbox
- Mau atur galeri 12 foto → Grid
- Mau center sesuatu → Flexbox

## Dipakai Untuk Apa

- Decision-making saat memulai layout
- Code review: apakah layout ini better pakai flexbox atau grid?

## Kesalahan Umum

- **Flexbox untuk layout halaman**: bisa, tapi Grid lebih tepat untuk 2 dimensi
- **Grid untuk navigasi**: overkill — flexbox lebih sederhana
- **Tidak kombinasi**: kadang butuh keduanya — Grid di luar, Flexbox di dalam
- **Mengira grid selalu lebih baik**: flexbox lebih sederhana untuk 1 dimensi

## Hubungan dengan Materi Sebelumnya

Poin 36-45: kita sudah belajar flexbox dan grid secara terpisah. Sekarang kita pahami **kapan menggunakan yang mana**. Ini adalah pertanyaan paling umum dari developer CSS. Jawabannya: flex untuk 1 dimensi, grid untuk 2 dimensi — dan seringkali kombinasi keduanya.

## Soal Latihan

### Soal 1
Sebutkan 3 kasus penggunaan Flexbox dan 3 untuk Grid.

**Jawaban:**
Flexbox: navigasi, centering, tombol dengan ikon. Grid: layout halaman, galeri foto, dashboard.

### Soal 2
Apakah flexbox bisa digunakan untuk layout halaman?

**Jawaban:**
Bisa — tapi Grid lebih tepat untuk layout 2 dimensi. Flexbox untuk layout 1 dimensi lebih sederhana dan mudah diprediksi.

### Soal 3
Bagaimana cara menggabungkan flexbox dan grid?

**Jawaban:**
Gunakan Grid untuk layout halaman/macro (header, sidebar, main, footer). Di dalam masing-masing area, gunakan Flexbox untuk komponen micro (card content, nav items, tombol).
