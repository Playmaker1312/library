# 56. translate, scale & rotate — Transformasi Paling Umum

## Penjelasan

`transform` mengubah tampilan elemen **tanpa menggeser layout** — elemen tetap di posisi aslinya di aliran dokumen.

| Fungsi | Efek | Contoh |
|--------|------|--------|
| `translate()` | Memindahkan | `translateX(20px)`, `translateY(-10px)` |
| `scale()` | Memperbesar/mengecil | `scale(1.1)`, `scaleX(2)` |
| `rotate()` | Memutar | `rotate(45deg)`, `rotate(-180deg)` |
| `skew()` | Memiringkan | `skew(10deg)` |

```css
.card:hover { transform: translateY(-4px) scale(1.02); }
/* urutan penting! */
```

## Fungsi

- Animasi tanpa mengganggu layout
- Card lift effect, zoom image, icon rotation
- Efek visual yang halus

## Cara Pengimplementasian

```css
/* Translate — memindahkan */
.card:hover { transform: translateY(-4px); }
.btn:active { transform: translateY(1px); }
.slide-in   { transform: translateX(-100%); }

/* Scale — memperbesar/memperkecil */
.img-zoom { transition: transform 0.3s ease; }
.img-zoom:hover { transform: scale(1.05); }

.icon { transition: transform 0.2s ease; }
.icon:hover { transform: scale(1.2); }

/* Rotate — memutar */
.arrow { transition: transform 0.3s ease; }
.arrow.open { transform: rotate(180deg); }

.logo-spin { transition: transform 0.5s ease; }
.logo-spin:hover { transform: rotate(360deg); }

/* Kombinasi — urutan penting! */
.card:hover {
  transform: translateY(-4px) scale(1.02);
  /* translate dulu, lalu scale */
}

/* Transform origin — pusat transformasi */
.card:hover {
  transform-origin: center center; /* default */
  transform: scale(1.05);
}
```

## Analogi

Transform seperti **hologram di rumah**:
- **translate** = hologram dipindahkan ke kiri/kanan — posisi asli lemari tetap, tapi hologramnya bergeser
- **scale** = hologram diperbesar/diperkecil — lemari asli tetap ukuran normal
- **rotate** = hologram diputar — lemari tetap di tempatnya, hanya tampilannya yang muter

Karena tidak menggeser layout, transform **sangat efisien** — browser bisa mengandalkan GPU untuk rendering. Ini sebabnya animasi pakai transform lebih smooth daripada animasi margin/padding.

## Dipakai Untuk Apa

- Card hover lift (translateY)
- Image zoom (scale)
- Arrow rotation (rotate)
- Button press effect (translateY)
- Icon hover (scale)
- Modal masuk dari atas (translateY)

## Kesalahan Umum

- **Urutan transform penting**: `translateX(-50%) translateY(-50%)` ≠ `translateY(-50%) translateX(-50%)` — biasanya beda hasil
- **Transform tidak bekerja di inline**: ubah ke inline-block atau block
- **Lupa transition**: transform tanpa transition = instan — tambahkan `transition: transform 0.2s ease`
- **Transform menggantikan transform sebelumnya**: menulis `transform: translateX(10px)` di satu aturan dan `transform: scale(1.1)` di aturan lain — yang terakhir menimpa

## Hubungan dengan Materi Sebelumnya

Poin 54-55: transisi dan animasi. Tapi apa yang di-animasi? **Transform** adalah properti yang paling sering di-animasi — karena smooth secara visual dan tidak menggeser layout. Card lift, zoom, rotate — semua pakai transform.

## Soal Latihan

### Soal 1
Tulis CSS untuk card yang naik 4px dan sedikit membesar saat hover.

**Jawaban:**
```css
.card { transition: transform 0.2s ease; }
.card:hover { transform: translateY(-4px) scale(1.02); }
```

### Soal 2
Apa keunggulan transform dibanding mengubah margin/padding untuk animasi?

**Jawaban:**
Transform tidak menggeser layout — elemen lain tidak bergerak. Juga bisa di-accelerate oleh GPU untuk performa animasi yang lebih smooth.

### Soal 3
Mengapa urutan fungsi transform penting?

**Jawaban:**
Setiap fungsi transformasi memengaruhi sumbu koordinat. `translateX(50px) rotate(45deg)` berbeda dengan `rotate(45deg) translateX(50px)` — yang pertama geser lalu putar, yang kedua putar lalu geser (arah geser berbeda).
