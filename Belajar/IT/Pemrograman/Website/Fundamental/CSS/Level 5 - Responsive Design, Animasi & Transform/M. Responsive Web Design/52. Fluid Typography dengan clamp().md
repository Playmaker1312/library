# 52. Fluid Typography dengan clamp()

## Penjelasan

`clamp(min, preferred, max)` adalah fungsi CSS yang menghasilkan nilai **skalabel** — antara minimum dan maksimum, mengikuti ukuran viewport.

```css
font-size: clamp(1rem, 0.9rem + 0.5vw, 1.125rem);
/* Tidak akan lebih kecil dari 1rem */
/* Tidak akan lebih besar dari 1.125rem */
/* Di antara: 0.9rem + 0.5vw (skala mengikuti viewport) */
```

## Fungsi

- Ukuran font yang halus antara mobile dan desktop — tanpa media query
- Spacing yang skalabel
- Menghilangkan breakpoint typography

## Cara Pengimplementasian

```css
:root {
  /* Fluid typography scale */
  --text-fluid-sm:  clamp(0.75rem, 0.7rem + 0.25vw, 0.875rem);
  --text-fluid-base: clamp(1rem, 0.9rem + 0.5vw, 1.125rem);
  --text-fluid-lg:  clamp(1.125rem, 1rem + 0.625vw, 1.25rem);
  --text-fluid-xl:  clamp(1.25rem, 1rem + 1.25vw, 1.5rem);
  --text-fluid-2xl: clamp(1.5rem, 1.15rem + 1.75vw, 2rem);
  --text-fluid-3xl: clamp(1.875rem, 1.25rem + 3.125vw, 2.5rem);
  --text-fluid-4xl: clamp(2.25rem, 1.5rem + 3.75vw, 3rem);
  --text-fluid-5xl: clamp(3rem, 2rem + 5vw, 4rem);
  
  /* Fluid spacing */
  --space-fluid-sm: clamp(var(--space-4), 4vw, var(--space-8));
  --space-fluid-lg: clamp(var(--space-8), 8vw, var(--space-16));
}

h1 { font-size: var(--text-fluid-5xl); }
h2 { font-size: var(--text-fluid-3xl); }
p { font-size: var(--text-fluid-base); }
```

**Cara membuat clamp() formula:**

Formula umum: `clamp(min, target + viewport-unit, max)`

Untuk skala dari 16px (mobile) ke 20px (desktop 1200px):
```
1rem = 16px → 1.25rem = 20px
clamp(1rem, 0.85rem + 0.5vw, 1.25rem)
```
- Mobile (375px): 0.85rem + 0.5*(3.75) = 0.85 + 1.875% ≈ 1.04rem ≈ 16.6px → clamp ke 1rem
- Desktop (1200px): 0.85rem + 0.5*(12) = 0.85 + 6% ≈ 1.21rem → clamp ke 1.25rem

## Analogi

Seperti **kursi kantor yang bisa diatur ketinggiannya**:
- **min** = posisi terendah (untuk orang pendek / mobile)
- **max** = posisi tertinggi (untuk orang tinggi / desktop)
- **preferred** = posisi ideal yang menyesuaikan — semakin tinggi orang, semakin tinggi kursi

Tanpa clamp(), kamu punya kursi tetap — harus ganti kursi di media query yang berbeda. Dengan clamp(), kursi otomatis menyesuaikan.

## Dipakai Untuk Apa

- Heading sizes yang smooth antar ukuran layar
- Spacing section yang proporsional
- Padding container responsif

## Kesalahan Umum

- **Formula clamp terlalu kompleks**: bisa sulit dibaca — gunakan tools online untuk generate
- **Lupa vw di parameter preferred**: tanpa vw, nilai tidak akan scale
- **Terlalu banyak clamp**: tidak semua properti perlu clamp — gunakan untuk heading dan spacing utama
- **clamp di properti yang tidak didukung browser lama**: fallback dengan nilai fixed

## Hubungan dengan Materi Sebelumnya

Poin 50: mobile-first dengan media query mengubah ukuran di breakpoint tertentu — ada **lompatan**. **clamp()** memberikan transisi yang halus — ukuran berubah gradual mengikuti viewport. Tingkatkan UX dengan fluid typography.

## Soal Latihan

### Soal 1
Tulis clamp untuk heading yang berukuran antara 24px (1.5rem) hingga 48px (3rem).

**Jawaban:**
```css
font-size: clamp(1.5rem, 1rem + 2.5vw, 3rem);
```

### Soal 2
Apa tiga parameter dalam fungsi clamp()?

**Jawaban:**
`clamp(MIN, preferred, MAX)` — nilai tidak akan kurang dari MIN, tidak akan lebih dari MAX, dan mengikuti preferred di antaranya.

### Soal 3
Mengapa clamp() disebut "fluid"?

**Jawaban:**
Karena nilainya berubah secara kontinu (fluida) mengikuti ukuran viewport, bukan melompat di breakpoint tertentu seperti media query.
