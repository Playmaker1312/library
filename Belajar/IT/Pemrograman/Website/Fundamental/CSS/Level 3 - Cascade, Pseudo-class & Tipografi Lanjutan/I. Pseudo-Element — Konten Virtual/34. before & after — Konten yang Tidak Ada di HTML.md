# 34. ::before & ::after — Konten yang Tidak Ada di HTML

## Penjelasan

`::before` dan `::after` adalah pseudo-element yang membuat **konten virtual** di dalam elemen — sebelum atau sesudah konten asli. **WAJIB** punya properti `content`.

```css
.element::before {
  content: "";  /* Wajib — bisa kosong */
  /* ... style ... */
}

.element::after {
  content: "";  /* Wajib */
  /* ... style ... */
}
```

## Fungsi

- Dekorasi murni CSS tanpa mengubah HTML
- Ikon, garis, badge, quote marks
- Clearfix, overlay, tooltip

## Cara Pengimplementasian

```css
/* Garis dekoratif sebelum section title */
.section-title::before {
  content: "";
  display: block;
  width: 48px;
  height: 4px;
  background-color: var(--color-primary);
  margin-bottom: var(--space-4);
  border-radius: var(--radius-full);
}

/* Tanda kutip pada blockquote */
blockquote::before {
  content: "\201C";  /* Unicode: " */
  font-size: 4rem;
  color: var(--color-primary);
  line-height: 0;
  vertical-align: -0.4em;
}

/* Badge "Baru" di sudut card */
.card.is-new::after {
  content: "Baru";
  position: absolute;
  top: var(--space-3);
  right: var(--space-3);
  background-color: var(--color-success);
  color: white;
  padding: var(--space-1) var(--space-3);
  border-radius: var(--radius-full);
  font-size: var(--text-xs);
  font-weight: var(--font-weight-semibold);
}

/* Ikon via emoji/unicode */
.external-link::after {
  content: " ↗";
  font-size: 0.8em;
}
```

## Analogi

::before dan ::after seperti **stiker tempel yang bisa ditempel di furnitur tanpa merusak cat**. Kamu tidak perlu mengganti furnitur (tidak mengubah HTML) — cukup tempel stiker di depan (::before) atau belakang (::after) furnitur.

Contoh: tempel stiker "BARU" di lemari — lemari asli tetap sama, hanya ada stiker yang menempel.

## Dipakai Untuk Apa

- Garis dekoratif sebelum heading
- Tanda kutip otomatis di blockquote
- Badge, label, tag
- Ikon kecil di samping link eksternal
- Overlay gradien di atas gambar

## Kesalahan Umum

- **Lupa `content`**: ::before/::after tidak akan muncul tanpa `content` (bisa `content: ""`)
- **Pseudo-element tidak interaktif**: `a::before` — pseudo-element tidak bisa diklik terpisah dari parent
- **Posisi absolut tanpa parent relative**: ::before/::after dengan `position: absolute` tapi parent tidak `position: relative`

## Hubungan dengan Materi Sebelumnya

Poin 30-33: pseudo-class memilih elemen berdasarkan **state**. Pseudo-element (`::before`, `::after`) memilih **bagian** elemen — konten virtual yang tidak ada di HTML. Ini murni CSS — tidak perlu tambah elemen `<span>` di HTML untuk dekorasi.

## Soal Latihan

### Soal 1
Apa syarat wajib untuk ::before dan ::after?

**Jawaban:**
Properti `content` — walaupun kosong (`content: ""`). Tanpa ini, pseudo-element tidak akan muncul.

### Soal 2
Tulis CSS untuk menambah garis biru 48px di atas section title.

**Jawaban:**
```css
.section-title::before {
  content: "";
  display: block;
  width: 48px;
  height: 4px;
  background-color: #2563eb;
  margin-bottom: 16px;
}
```

### Soal 3
Apa perbedaan `::before` dan `::after`?

**Jawaban:**
`::before` menempatkan konten virtual di **awal** elemen (sebelum konten asli). `::after` di **akhir** elemen (setelah konten asli). Keduanya secara visual di dalam elemen.
