# 31. Pseudo-class Structural — nth-child, first-child, last-child

## Penjelasan

Pseudo-class structural memilih elemen berdasarkan **posisinya** di antara saudara-saudaranya (tanpa perlu menambah class di HTML).

```css
:first-child  /* anak pertama dari parent */
:last-child   /* anak terakhir dari parent */
:nth-child(n) /* anak ke-n dari parent */
:nth-of-type(n) /* anak ke-n dari type tertentu */
```

## Fungsi

- Styling pola berulang — tanpa class tambahan di HTML
- Menghapus border/padding item terakhir
- Alternating row color di tabel

## Cara Pengimplementasian

```css
/* Item pertama: berbeda */
.project-card:first-child {
  grid-column: span 2;  /* lebih lebar */
  border-color: var(--color-primary);
}

/* Item terakhir: tanpa border */
.nav-item:last-child {
  border-bottom: none;
}

/* nth-child — pola genap/ganjil */
tr:nth-child(odd) { background-color: var(--color-surface); }
tr:nth-child(even) { background-color: white; }

/* nth-child dengan rumus */
li:nth-child(3) { }           /* item ke-3 */
li:nth-child(2n) { }          /* genap (2, 4, 6) */
li:nth-child(2n+1) { }        /* ganjil (1, 3, 5) */
li:nth-child(-n+3) { }        /* 3 item pertama */
li:nth-child(n+4) { }         /* item mulai ke-4 */

/* nth-of-type — beda dengan nth-child */
p:nth-of-type(2) { }          /* paragraf ke-2, abaikan elemen lain */
p:nth-child(2) { }            /* anak ke-2, hanya jika dia p */
```

## Analogi

Seperti **kursi di meja makan**:
- **:first-child** = kursi paling ujung kiri — biasanya untuk tuan rumah
- **:last-child** = kursi paling ujung kanan
- **:nth-child(odd)** = semua kursi ganjil — diberi taplak berbeda
- **:nth-child(3)** = kursi nomor 3 dari kiri — hanya satu itu

## Dipakai Untuk Apa

- Tabel: baris genap/ganjil warna berbeda (zebra striping)
- List: item terakhir tanpa border bawah
- Grid: item pertama lebih besar (featured)
- Gallery: pola 3 item per baris, item ke-3n berbeda

## Kesalahan Umum

- **:nth-child vs :nth-of-type tertukar**: `p:nth-child(2)` = anak ke-2 yang harus `p`. `p:nth-of-type(2)` = `p` ke-2 di antara semua `p`
- **:first-child tidak berfungsi**: jika elemen bukan anak pertama karena ada elemen lain sebelumnya (misal comment node atau elemen lain)
- **Rumus nth-child salah**: `2n+1` = ganjil, `2n` = genap, `3n` = setiap ke-3

## Hubungan dengan Materi Sebelumnya

Poin 30: pseudo-class interaksi (:hover, :focus) bereaksi terhadap **tindakan user**. Pseudo-class structural bereaksi terhadap **posisi elemen di HTML**. Berguna untuk pattern styling tanpa harus tambah class di setiap item.

## Soal Latihan

### Soal 1
Tulis CSS untuk memberi background abu-abu di baris genap tabel.

**Jawaban:**
```css
tr:nth-child(even) {
  background-color: #f3f4f6;
}
```

### Soal 2
Apa perbedaan `li:first-child` dan `li:nth-child(1)`?

**Jawaban:**
Tidak ada perbedaan — keduanya memilih `<li>` pertama. `:first-child` lebih singkat. `:nth-child(1)` lebih eksplisit.

### Soal 3
Tulis CSS untuk menyembunyikan border bawah item terakhir di list.

**Jawaban:**
```css
.list-item:last-child {
  border-bottom: none;
}
/* Atau: */
.list-item:not(:last-child) {
  border-bottom: 1px solid var(--color-border);
}
```
