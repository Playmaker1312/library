# 33. Pseudo-class Form — focus, valid, invalid, required

## Penjelasan

Pseudo-class untuk form element berdasarkan **state input**:

| Pseudo-class | Fungsi |
|-------------|--------|
| `:focus` | Input sedang aktif (diklik/di-tab) |
| `:valid` | Input berisi nilai valid (sesuai type/pattern) |
| `:invalid` | Input berisi nilai tidak valid |
| `:required` | Input yang punya atribut required |
| `:optional` | Input tanpa required |
| `:placeholder-shown` | Placeholder masih terlihat |
| `:disabled` | Input di-disable |

## Fungsi

- Validasi visual form tanpa JavaScript
- Memberi feedback real-time — user tahu input yang salah
- Meningkatkan UX form secara signifikan

## Cara Pengimplementasian

```css
/* Default input */
input, textarea, select {
  border: 2px solid var(--color-border);
  border-radius: var(--radius-md);
  padding: var(--space-3) var(--space-4);
  font-family: inherit;
  font-size: var(--text-base);
  transition: border-color 0.2s ease, box-shadow 0.2s ease;
  width: 100%;
}

/* Focus */
input:focus, textarea:focus {
  outline: none;
  border-color: var(--color-primary);
  box-shadow: 0 0 0 3px rgba(37, 99, 235, 0.15);
}

/* Valid — hijau */
input:valid {
  border-color: var(--color-success);
}

/* Invalid — merah (hanya saat sudah diisi) */
input:invalid:not(:placeholder-shown) {
  border-color: var(--color-error);
}

/* Required — tambah asterisk via CSS */
label:has(+ input:required)::after,
label:has(+ textarea:required)::after {
  content: " *";
  color: var(--color-error);
}

/* Disabled */
input:disabled {
  opacity: 0.5;
  cursor: not-allowed;
  background-color: var(--color-surface);
}
```

## Analogi

Seperti **satpam di pintu rumah**:
- **Default**: pintu tertutup — satpam menunggu
- **:focus** = satpam melihat ke arah orang yang mendekat — "Siapa?"
- **:valid** = KTP sesuai — satpam senyum, lampu hijau
- **:invalid** = KTP tidak sesuai — satpam cemberut, lampu merah
- **:placeholder-shown** = tamu masih baca instruksi di papan — "Isi KTP di sini"

## Dipakai Untuk Apa

- Form kontak, pendaftaran, login
- Memberi validasi visual instan
- Menandai field wajib diisi

## Kesalahan Umum

- **:invalid muncul di awal**: input kosong dianggap invalid oleh browser — gunakan `:not(:placeholder-shown)` untuk hanya tampilkan error saat sudah diisi
- **:valid terlalu cepat**: input email dengan "a" dianggap valid oleh beberapa browser karena pattern default longgar
- **Lupa style focus**: form tidak memberikan feedback visual saat user tab antar field

## Hubungan dengan Materi Sebelumnya

Poin 30-32: pseudo-class untuk interaksi dan logika. **Form pseudo-class** adalah penerapan khusus untuk input field. Dengan validasi visual CSS, user langsung tahu apakah input sudah benar — tanpa perlu klik tombol submit.

## Soal Latihan

### Soal 1
Tulis CSS untuk membuat input dengan border hijau saat valid dan merah saat invalid (setelah diisi).

**Jawaban:**
```css
input:valid { border-color: #10b981; }
input:invalid:not(:placeholder-shown) { border-color: #ef4444; }
```

### Soal 2
Apa fungsi `:placeholder-shown`?

**Jawaban:**
Memilih input yang masih menampilkan placeholder — artinya input kosong. Berguna untuk membedakan "input kosong" dari "input sudah diisi".

### Soal 3
Mengapa kita tidak bisa langsung menggunakan `input:invalid` untuk menandai error?

**Jawaban:**
Karena semua input kosong (belum diisi) dianggap `:invalid` oleh browser. Langsung style merah akan membuat semua field tampak error sejak awal. Gunakan `input:invalid:not(:placeholder-shown)` untuk hanya tampilkan error saat input sudah pernah diisi tapi tidak valid.
