# 21. border & border-radius — Garis Tepi & Sudut Melengkung

## Penjelasan

- **`border`**: garis tepi elemen (width, style, color)
- **`border-radius`**: melengkungkan sudut elemen

```css
:root {
  --radius-sm:   4px;
  --radius-md:   8px;
  --radius-lg:   12px;
  --radius-xl:   16px;
  --radius-full: 9999px; /* pill shape */
}

.card {
  border: 1px solid var(--color-border);
  border-radius: var(--radius-lg);
}
```

## Fungsi

- **Border**: memberi batas visual antar elemen
- **Border-radius**: membuat sudut lebih lembut dan modern

## Cara Pengimplementasian

```css
/* Border shorthand: width style color */
border: 1px solid var(--color-border);
border: 2px dashed var(--color-primary);
border: 3px dotted var(--color-success);

/* Border per sisi */
border-top: 2px solid var(--color-primary);
border-bottom: 1px solid var(--color-border);

/* Border style */
border-style: solid;    /* garis lurus — paling umum */
border-style: dashed;   /* garis putus-putus */
border-style: dotted;   /* garis titik-titik */
border-style: double;   /* garis ganda */

/* Border radius */
.card { border-radius: var(--radius-lg); }
.button { border-radius: var(--radius-md); }
.badge { border-radius: var(--radius-full); }
.avatar { border-radius: 50%; }  /* lingkaran sempurna */

/* Border radius per sudut */
border-radius: 8px 8px 0 0;        /* atas melengkung, bawah siku */
border-radius: 50% 50% 0 0;        /* setengah lingkaran di atas */
```

## Analogi

Border seperti **bingkai foto**. Bingkai 1px solid = bingkai tipis minimalis. Bingkai 3px dashed = bingkai putus-putus untuk foto anak-anak. Border-radius seperti **sudut meja yang dibulatkan** — meja dengan sudut lancip terasa kurang ramah, sudut membulat lebih nyaman dan modern.

## Dipakai Untuk Apa

- Card, section — border tipis untuk memisahkan area
- Tombol — border untuk varian outline
- Avatar — border-radius: 50% untuk lingkaran
- Badge — border-radius: 9999px untuk bentuk pil
- Gambar — border-radius untuk sudut lembut

## Kesalahan Umum

- **Lupa `border-style`**: `border: 2px red` tidak bekerja — butuh `solid`
- **Border-radius: 50% vs 9999px**: 50% membuat elips jika elemen tidak persegi. 9999px (atau nilai besar) aman untuk bentuk pil
- **Border nambah ukuran**: tanpa `border-box`, border 5px nambah 10px ke total lebar

## Hubungan dengan Materi Sebelumnya

Poin 16-20: box model, padding, margin, container sudah dipahami. **Border** adalah lapisan ke-3 box model (antara padding dan margin). Sekarang elemen tidak hanya punya ruang (padding/margin), tapi juga **garis tepi** yang membuatnya terlihat terdefinisi.

## Soal Latihan

### Soal 1
Tulis CSS untuk membuat card dengan border 1px solid abu-abu dan sudut 12px.

**Jawaban:**
```css
.card {
  border: 1px solid #d1d5db;
  border-radius: 12px;
}
```

### Soal 2
Apa perbedaan `border-radius: 50%` dan `border-radius: 9999px`?

**Jawaban:**
`50%` membuat bentuk elips — persegi jadi lingkaran, persegi panjang jadi oval. `9999px` membuat sudut sangat membulat tanpa mengubah bentuk dasar — persegi tetap persegi dengan sudut pil.

### Soal 3
Mengapa kode `border: 2px red` tidak berfungsi?

**Jawaban:**
Karena `border-style` tidak disebutkan. Default `border-style` adalah `none`. Lengkapnya: `border: 2px solid red`.
