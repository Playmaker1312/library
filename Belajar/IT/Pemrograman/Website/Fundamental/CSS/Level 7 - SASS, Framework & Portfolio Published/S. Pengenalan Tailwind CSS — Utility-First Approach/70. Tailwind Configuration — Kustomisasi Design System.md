# 70. Tailwind Configuration — Kustomisasi Design System

## Penjelasan

`tailwind.config.js` adalah tempat untuk **menyesuaikan** design system Tailwind dengan brand kita — warna, font, spacing, breakpoints.

```javascript
export default {
  content: ['./*.html'],
  theme: {
    extend: {
      // Tambah/timpa tema default
    },
  },
}
```

## Fungsi

- Menyamakan Tailwind dengan brand yang sudah didefinisikan di CSS Variables
- Menghemat penulisan — class `text-primary` bukan `text-[#2563eb]`

## Cara Pengimplementasian

```javascript
// tailwind.config.js
export default {
  content: ['./*.html'],
  theme: {
    extend: {
      colors: {
        brand: {
          50:  '#eff6ff',
          100: '#dbeafe',
          500: '#3b82f6',
          600: '#2563eb',
          700: '#1d4ed8',
          900: '#1e3a8a',
        },
        surface: {
          DEFAULT: '#ffffff',
          alt: '#f9fafb',
          dark: '#0f172a',
        }
      },
      fontFamily: {
        sans: ['Inter', 'system-ui', 'sans-serif'],
        display: ['Merriweather', 'serif'],
      },
      fontSize: {
        '2xs': ['0.625rem', { lineHeight: '0.875rem' }],
        '3xl': ['2rem', { lineHeight: '2.5rem' }],
      },
      spacing: {
        '18': '4.5rem',
        '88': '22rem',
      },
      borderRadius: {
        '4xl': '2rem',
      },
      maxWidth: {
        'container': '75rem', // 1200px
      },
    },
  },
}
```

**Atau, override total theme:**
```javascript
export default {
  theme: {
    colors: { // override semua warna default
      white: '#ffffff',
      primary: '#2563eb',
      // ... hanya warna yang dipakai
    }
  }
}
```

**Menggunakan nilai kustom di HTML:**
```html
<!-- Tanpa konfigurasi — arbitrary value -->
<div class="bg-[#2563eb] text-[#f8fafc]">...</div>

<!-- Dengan konfigurasi — semantic class -->
<div class="bg-brand-600 text-white">...</div>
```

## Analogi

Tailwind seperti **rumah modular dengan katalog**:
- Default Tailwind = katalog standar IKEA — ukuran, warna, model sudah ditentukan
- `theme.extend` = kustomisasi — "Warna dinding tidak ada di katalog, tapi saya bisa pesan warna khusus"
- `theme` override = "Saya tidak suka katalog IKEA, saya punya toko furnitur sendiri"

Konfigurasi membuat Tailwind sesuai dengan brand kita — warna `primary-600` di Tailwind = `var(--blue-600)` di CSS kita.

## Dipakai Untuk Apa

- Menyesuaikan Tailwind dengan brand project
- Menambah warna, font, spacing kustom
- Membuat design system yang konsisten antara CSS dan Tailwind

## Kesalahan Umum

- **Tidak extend, langsung hardcode di HTML**: `bg-[#2563eb]` di 50 tempat — sulit maintain. Lebih baik konfigurasi sekali, pakai class `bg-brand-600`
- **Override theme sepenuhnya**: kehilangan semua utility default Tailwind — hanya lakukan jika sangat yakin
- **Content path salah**: class baru tidak muncul karena JIT tidak scan file yang benar

## Soal Latihan

### Soal 1
Tulis konfigurasi Tailwind untuk menambah warna primary 600 = #2563eb.

**Jawaban:**
```javascript
theme: { extend: { colors: { primary: { 600: '#2563eb' } } } }
```

### Soal 2
Apa perbedaan `theme.extend` dan override `theme` langsung?

**Jawaban:**
`extend` — menambah/menimpa nilai tertentu, sisanya pakai default Tailwind. Override `theme` — mengganti seluruh nilai, default Tailwind hilang.

### Soal 3
Apa fungsi `content` di tailwind.config.js?

**Jawaban:**
Memberi tahu JIT compiler file mana yang harus di-scan untuk mencari class Tailwind. Hanya class yang ditemukan di file tersebut yang akan di-generate.
