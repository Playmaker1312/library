# 68. SASS Partials & @use — Modularisasi yang Benar

## Penjelasan

- **Partial**: file SCSS dengan awalan `_` (underscore) — tidak dikompilasi sendiri
- **`@use`**: cara modern mengimport partial (pengganti `@import`)

```
scss/
├── abstracts/
│   ├── _variables.scss   ← SASS variables dan config
│   ├── _mixins.scss      ← semua mixin
│   └── _functions.scss   ← fungsi kustom
├── base/
│   ├── _reset.scss
│   ├── _typography.scss
│   └── _variables-css.scss  ← CSS custom properties
├── components/
│   ├── _buttons.scss
│   ├── _cards.scss
│   └── _navigation.scss
├── layout/
│   ├── _header.scss
│   ├── _footer.scss
│   └── _container.scss
└── main.scss             ← entry point (tidak pakai _)
```

## Fungsi

- Modularisasi — pisahkan kode ke file kecil yang fokus
- Namespace — @use mencegah konflik nama
- Satu file compile (`main.scss`) — semua partial digabung

## Cara Pengimplementasian

```scss
// main.scss — entry point
@use 'abstracts/variables' as v;
@use 'abstracts/mixins' as m;
@use 'abstracts/functions' as f;
@use 'base/reset';
@use 'base/typography';
@use 'base/variables-css';
@use 'components/buttons';
@use 'components/cards';
@use 'layout/header';
@use 'layout/footer';
```

**Dengan namespace:**
```scss
// abstracts/_variables.scss
$color-primary: #2563eb;
$breakpoint-md: 768px;

// components/_buttons.scss
@use '../abstracts/variables' as v;

.btn-primary {
  background-color: v.$color-primary; // pakai namespace
}
```

**Tanpa namespace (jika yakin tidak konflik):**
```scss
// components/_buttons.scss
@use '../abstracts/variables' as *;

.btn-primary {
  background-color: $color-primary; // langsung, tanpa namespace
}
```

**Forward — re-export dari satu file:**
```scss
// abstracts/_index.scss
@forward 'variables';
@forward 'mixins';
@forward 'functions';

// main.scss
@use 'abstracts'; // otomatis pakai _index.scss
```

## Analogi

Seperti **lemari arsip rumah tangga**:
- Setiap file partial (`_`) = **satu map folder**: `_tagihan-listrik.scss`, `_kartu-keluarga.scss`
- Map tidak berdiri sendiri — harus dimasukkan ke binder (`@use`)
- Binder utama (`main.scss`) = binder "Semua Dokumen"
- Namespace (`as v`) = label "Listrik:" di setiap dokumen — biar tidak bingung dengan dokumen lain yang juga punya "total tagihan"

## Dipakai Untuk Apa

- Semua project SASS — ini adalah standar modern
- Tim development — setiap anggota kerja di partial berbeda

## Kesalahan Umum

- **Masih pakai @import (lama)**: `@import` sudah deprecated — gunakan `@use`
- **Lupa `as *` atau namespace**: harus pilih salah satu
- **File tanpa `_` dikompilasi sendiri**: setiap file tanpa `_` jadi file CSS terpisah — hanya entry point yang boleh tanpa `_`
- **Path salah**: `@use 'abstracts/variables'` — path relatif ke file yang melakukan @use

## Hubungan dengan Materi Sebelumnya

Poin 64: organisasi file CSS. **SASS partials** mengotomatisasi penggabungan file — tulis `@use` di main.scss, SASS compile jadi satu file CSS. Tidak perlu `@import` CSS manual.

## Soal Latihan

### Soal 1
Apa arti underscore `_` di awal nama file `_variables.scss`?

**Jawaban:**
File partial — tidak dikompilasi menjadi file CSS sendiri, hanya siap untuk di-@use ke file lain.

### Soal 2
Apa perbedaan `@use` dan `@import` di SASS?

**Jawaban:**
`@use` (modern): membuat namespace, setiap file hanya bisa di-@use sekali, mencegah konflik. `@import` (lama): deprecated, semua variable global, bisa konflik.

### Soal 3
Buat struktur folder SASS yang baik untuk project portofolio.

**Jawaban:**
```
scss/
├── abstracts/ (_variables.scss, _mixins.scss)
├── base/ (_reset.scss, _typography.scss)
├── components/ (_buttons.scss, _cards.scss, _navigation.scss)
├── layout/ (_header.scss, _footer.scss, _container.scss)
└── main.scss
```
