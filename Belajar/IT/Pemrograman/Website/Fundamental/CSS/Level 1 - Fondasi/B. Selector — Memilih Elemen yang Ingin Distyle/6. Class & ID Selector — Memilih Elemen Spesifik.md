# 6. Class & ID Selector — Memilih Elemen Spesifik

## Penjelasan

- **Class selector** (`.`): memilih elemen dengan atribut `class` tertentu — bisa dipakai banyak elemen
- **ID selector** (`#`): memilih satu elemen unik dengan atribut `id` — hanya satu per halaman

```css
/* Class: reusable, banyak elemen */
.main-nav { background-color: #1e40af; }
.project-card { border: 1px solid #e5e7eb; }
.btn-primary { background-color: #2563eb; color: white; }

/* ID: unik, hanya satu */
#hero-section { min-height: 100vh; }
#main-content { max-width: 1200px; }
```

## Fungsi

- **Class**: styling yang bisa dipakai berulang di banyak elemen
- **ID**: identifikasi unik (anchor link, JavaScript hook, halaman tunggal)

## Cara Pengimplementasian

```html
<nav class="main-nav">
  <ul>
    <li><a href="#home">Beranda</a></li>
  </ul>
</nav>

<section id="hero" class="hero-section">
  <h1>Selamat Datang</h1>
</section>

<article class="project-card">
  <h3 class="project-card__title">Proyek 1</h3>
</article>
```

```css
.main-nav {
  background-color: #1e40af;
  padding: 16px;
}

.hero-section {
  min-height: 100vh;
  display: flex;
  align-items: center;
}

.project-card {
  background-color: #f9fafb;
  border-radius: 8px;
  padding: 24px;
}
```

## Analogi

**Class** seperti stiker label. Kamu bisa tempel stiker "Barang Berharga" di banyak benda — laptop, vas, lukisan. Semua yang punya stiker itu diperlakukan khusus. **ID** seperti nomor induk KTP — unik, hanya dimiliki satu orang. Tidak ada dua orang dengan nomor KTP yang sama.

## Dipakai Untuk Apa

- **Class**: tombol, card, section, item daftar — apapun yang muncul lebih dari sekali
- **ID**: anchor link (`#section2`), target JavaScript, elemen yang benar-benar unik

## Kesalahan Umum

- **Menggunakan ID untuk styling utama**: ID punya specificity tinggi — sulit di-override. Gunakan class
- **ID duplikat**: HTML valid, tapi JavaScript hanya baca yang pertama — menyebabkan bug
- **Nama class tidak deskriptif**: `.text`, `.box`, `.blue` — tidak jelas fungsinya. Gunakan `.hero-title`, `.project-card`

## Hubungan dengan Materi Sebelumnya

Poin 5: Type/Universal selector memilih berdasarkan **tag**. Tapi tidak semua `<p>` perlu style sama. Di sinilah **Class** berguna — kita kasih label spesifik ke elemen yang perlu style khusus, tanpa memengaruhi elemen lain yang sama tag-nya.

## Soal Latihan

### Soal 1
Apa perbedaan class selector `.card` dengan ID selector `#header`?

**Jawaban:**
`.card` bisa dipakai di banyak elemen, `.card` bisa muncul berkali-kali. `#header` hanya boleh satu per halaman — unik.

### Soal 2
Dari HTML berikut, tulis CSS yang membuat teks di paragraf dengan class `highlight` berwarna kuning.
```html
<p class="highlight">Teks ini kuning</p>
<p>Teks ini normal</p>
```

**Jawaban:**
```css
.highlight {
  background-color: yellow;
}
```

### Soal 3
Mengapa ID tidak disarankan untuk styling utama (dibanding class)?

**Jawaban:**
Karena ID memiliki specificity yang sangat tinggi (0,1,0,0). Jika suatu elemen di-style dengan ID, akan sulit menimpa style tersebut dengan class atau type selector. Gunakan ID hanya untuk keunikan (anchor/JS hook), bukan styling.
