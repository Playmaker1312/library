# 11. color & background-color — Dua Properti Warna Paling Dasar

## Penjelasan

- **`color`**: warna **teks** dari suatu elemen
- **`background-color`**: warna **latar belakang** elemen

```css
body {
  color: var(--color-text);           /* teks hitam */
  background-color: var(--color-bg);  /* latar putih */
}

header {
  background-color: var(--color-primary);  /* latar biru */
  color: white;                              /* teks putih di atas biru */
}

.highlight {
  background-color: var(--color-warning);  /* latar kuning */
  color: #111827;                          /* teks gelap */
}
```

## Fungsi

- `color`: memastikan teks terbaca — kontras dengan background
- `background-color`: memberikan latar pada elemen — section, card, tombol, header

## Cara Pengimplementasian

```css
:root {
  --color-bg: #ffffff;
  --color-surface: #f9fafb;
  --color-text: #111827;
  --color-text-muted: #6b7280;
  --color-primary: #2563eb;
  --color-primary-light: #dbeafe;
}

body {
  color: var(--color-text);
  background-color: var(--color-bg);
}

header {
  background-color: var(--color-primary);
  color: white;
}

.project-card {
  background-color: var(--color-surface);
  color: var(--color-text);
}

.badge {
  background-color: var(--color-primary-light);
  color: var(--color-primary);
}
```

## Analogi

Di rumah, **color** adalah warna cat pada **perabotan** (lemari, meja). **background-color** adalah warna cat **dinding** di belakang perabotan. Lemari coklat di dinding putih — color = coklat, background-color = putih. Keduanya harus punya kontras cukup agar terbaca dengan jelas.

## Dipakai Untuk Apa

- `color`: semua teks — heading, paragraph, link, caption
- `background-color`: body, header, footer, card, section, tombol, badge

## Kesalahan Umum

- **Kontras rendah**: teks abu-abu di atas putih terang — sulit dibaca (terutama di layar redup)
- **Lupa set color saat ganti background**: background gelap tapi teks tetap hitam — teks tidak terbaca
- **Background tidak mencakup padding**: jika ada padding anak yang lebih besar, background tidak terlihat penuh

## Hubungan dengan Materi Sebelumnya

Poin 10: kita punya sistem warna di CSS Variables. Sekarang **terapkan** ke elemen menggunakan `color` dan `background-color`. Ini adalah dua properti yang akan paling sering digunakan — hampir setiap elemen butuh setidaknya salah satu.

## Soal Latihan

### Soal 1
Tulis CSS untuk membuat header dengan background biru dan teks putih.

**Jawaban:**
```css
header {
  background-color: #2563eb;
  color: white;
}
```

### Soal 2
Mengapa penting memastikan kontras antara color dan background-color?

**Jawaban:**
Kontras rendah membuat teks sulit dibaca, terutama bagi pengguna dengan gangguan penglihatan atau di lingkungan dengan cahaya terang/redup. Standar WCAG AA minimal rasio kontras 4.5:1.

### Soal 3
Apa yang terjadi jika kita set `background-color` tapi tidak set `color` pada elemen yang berada di dalam parent dengan background gelap?

**Jawaban:**
`color` akan diwarisi (inherited) dari parent. Jika parent punya `color: white`, maka teks akan putih — cocok untuk background gelap. Tapi jika parent tidak set color, browser menggunakan default (hitam) — teks hitam di background gelap tidak terbaca.
