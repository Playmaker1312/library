# 10. CSS Custom Properties — Sistem Warna yang Terpusat

## Penjelasan

CSS Custom Properties (disebut juga **CSS Variables**) memungkinkan kita mendefinisikan nilai di satu tempat dan menggunakannya di seluruh stylesheet.

```
- Definikan di :root agar global
- Gunakan dengan fungsi var()
- Ubah satu tempat, semua berubah
```

```css
:root {
  /* Brand colors */
  --color-primary: #1e40af;
  --color-primary-light: #3b82f6;
  --color-primary-dark: #1e3a8a;
  
  /* Neutral */
  --color-text: #111827;
  --color-text-muted: #6b7280;
  --color-background: #ffffff;
  --color-border: #e5e7eb;
}

body {
  color: var(--color-text);
  background-color: var(--color-background);
}

h1 {
  color: var(--color-primary);
}
```

## Fungsi

- **Sentralisasi**: semua warna di satu tempat (`:root`)
- **Konsistensi**: tidak ada warna hardcoded yang berbeda tipis
- **Mudah maintenance**: ganti warna brand cukup di satu baris
- **Theming**: dark mode tinggal ubah nilai variable

## Cara Pengimplementasian

```css
/* 1. Definisikan di :root */
:root {
  --color-primary: #2563eb;
  --color-primary-dark: #1d4ed8;
  --color-success: #10b981;
  --color-error: #ef4444;
  --color-warning: #f59e0b;
  --color-bg: #ffffff;
  --color-surface: #f9fafb;
  --color-border: #e5e7eb;
}

/* 2. Gunakan dengan var() */
.card {
  background-color: var(--color-surface);
  border: 1px solid var(--color-border);
  color: var(--color-text);
}

.btn-primary {
  background-color: var(--color-primary);
  color: white;
}

.btn-primary:hover {
  background-color: var(--color-primary-dark);
}

/* 3. Fallback value (jika variable tidak terdefinisi) */
.element {
  color: var(--color-undefined, red); /* fallback ke red */
}
```

## Analogi

CSS Variables seperti **papan warna pusat di toko cat**. Semua tukang cat mengambil dari papan yang sama. Suatu hari pemilik toko ingin mengganti "Biru Brand" dari gelap ke terang — cukup ganti satu botol di papan, semua tukang cat otomatis pakai warna baru. Tanpa papan pusat, setiap tukang harus mengganti cat di ember masing-masing satu per satu.

## Dipakai Untuk Apa

- Warna brand di seluruh website
- Font family dan ukuran
- Spacing system (margin, padding)
- Shadow, border-radius, transisi
- Dark mode / theming
- Design token system

## Kesalahan Umum

- **Lupa prefix `--`**: `primary: blue` tidak valid — harus `--primary: blue`
- **Salah eja nama variable**: `var(--color-primry)` — typo, fallback ke default atau error
- **Variable di selector lokal, dipakai di luar scope**: variable hanya berlaku di selector dan children-nya
- **Mendefinisikan tapi tidak menggunakan**: variable menganggur

## Hubungan dengan Materi Sebelumnya

Poin 9: kita belajar format warna (hex, rgb, hsl). Tapi menulis `#1e40af` di 50 tempat berbahaya — satu typo dan warna berbeda. **CSS Variables** adalah solusinya: tulis sekali di `:root`, pakai di mana saja dengan `var()`. Ini adalah fondasi **design system** yang akan kita bangun di level-level berikutnya.

## Soal Latihan

### Soal 1
Buat CSS variable `--color-primary` dengan value `#2563eb` dan gunakan untuk memberi warna pada tombol.

**Jawaban:**
```css
:root {
  --color-primary: #2563eb;
}

.btn {
  background-color: var(--color-primary);
  color: white;
}
```

### Soal 2
Apa fungsi `:root` dalam CSS Variables?

**Jawaban:**
`:root` adalah selector untuk elemen `<html>`. Mendefinisikan variable di `:root` membuat variable tersebut **global** — bisa diakses dari semua elemen di seluruh stylesheet.

### Soal 3
Apa yang terjadi jika menggunakan `var(--color-undefined)` tanpa fallback?

**Jawaban:**
Browser akan menggunakan nilai **initial** atau **inherited** tergantung properti. Untuk `color`, akan di-inherit dari parent. Untuk `background-color`, akan transparan (initial). Dianjurkan selalu sediakan fallback: `var(--color-undefined, blue)`.
