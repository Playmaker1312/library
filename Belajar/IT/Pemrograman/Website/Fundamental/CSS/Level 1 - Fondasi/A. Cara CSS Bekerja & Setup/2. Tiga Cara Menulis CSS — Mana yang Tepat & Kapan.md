# 2. Tiga Cara Menulis CSS — Mana yang Tepat & Kapan

## Penjelasan

Ada tiga cara menulis CSS:

| Cara | Sintaks | Kelebihan | Kekurangan |
|------|---------|-----------|------------|
| **Inline** | `<p style="color: red;">` | Prioritas tinggi, langsung terlihat | Tidak reusable, campur aduk dengan HTML |
| **Internal** | `<style>` di `<head>` | Cocok untuk satu halaman | Tidak bisa dipakai halaman lain |
| **External** | File `.css` terpisah | Reusable, cacheable, terpisah rapi | Butuh request HTTP tambahan |

## Fungsi

- **Inline**: override cepat, styling dinamis via JavaScript
- **Internal**: prototipe cepat, halaman landing tunggal
- **External**: standar production — satu file untuk semua halaman

## Cara Pengimplementasian

### Inline
```html
<h1 style="color: #1e40af; font-size: 2.5rem;">Judul</h1>
```

### Internal
```html
<head>
  <style>
    h1 { color: #1e40af; font-size: 2.5rem; }
    p { line-height: 1.6; }
  </style>
</head>
```

### External (Yang Akan Kita Gunakan)
```html
<head>
  <link rel="stylesheet" href="styles.css">
</head>
```
```css
/* styles.css */
h1 { color: #1e40af; font-size: 2.5rem; }
```

## Analogi

Masih soal rumah. **Inline** seperti mengecat **satu bata tertentu** dengan warna khusus — cepat tapi hanya untuk satu titik. **Internal** seperti punya **ember cat di dalam ruangan** — cat hanya untuk ruangan itu. **External** seperti punya **gudang cat pusat** — ambil cat yang sama untuk seluruh rumah, dan gudangnya bisa dipakai kembali untuk rumah lain.

## Dipakai Untuk Apa

- **External**: project nyata, website production, kerja tim
- **Internal**: belajar, prototipe, satu halaman sederhana
- **Inline**: sangat jarang, hanya untuk override spesifik atau manipulasi JavaScript

## Kesalahan Umum

- **Inline berlebihan**: membuat HTML sulit dibaca dan CSS tidak terpusat
- **Campur aduk cara**: inline override external → bingung tracking sumber style
- **Lupa tag `<link>`**: file CSS sudah dibuat tapi tidak dihubungkan

## Hubungan dengan Materi Sebelumnya

Dari Poin 1 kita tahu CSS memberi tampilan pada HTML. Sekarang kita pilih **bagaimana cara menulisnya**. External stylesheet adalah pilihan standar karena satu file bisa styling puluhan halaman — tepat untuk project portofolio kita yang punya beberapa halaman.

## Soal Latihan

### Soal 1
Sebutkan 3 cara menulis CSS dan kapan masing-masing paling tepat digunakan.

**Jawaban:**
- **Inline**: override spesifik / styling dinamis JS
- **Internal**: halaman tunggal / prototipe cepat
- **External**: production / multi-halaman

### Soal 2
Apa kode HTML untuk menghubungkan file `style.css`?

**Jawaban:**
```html
<link rel="stylesheet" href="style.css">
```

### Soal 3
Mengapa external stylesheet lebih disarankan untuk project portofolio?

**Jawaban:**
Karena portofolio biasanya punya banyak halaman. External stylesheet bisa dipakai bersama, mudah dipelihara (ubah satu file = semua halaman berubah), dan bisa di-cache browser.
