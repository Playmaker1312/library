# 15. line-height, text-align & text-transform — Keterbacaan Teks

## Penjelasan

- **`line-height`**: jarak antar baris teks (tanpa satuan = relatif ke font-size)
- **`text-align`**: perataan teks (left, center, right, justify)
- **`text-transform`**: kapitalisasi (uppercase, lowercase, capitalize)

```css
:root {
  --leading-tight:  1.25;  /* heading */
  --leading-normal: 1.5;   /* body text */
  --leading-loose:  1.75;  /* konten panjang */
}

body { 
  line-height: var(--leading-normal); 
  text-align: left; 
}

h1, h2, h3 { 
  line-height: var(--leading-tight); 
}

.hero-title { 
  text-align: center; 
}

.section-title { 
  text-transform: uppercase; 
  letter-spacing: 0.05em; 
}
```

## Fungsi

- **line-height**: kenyamanan baca — terlalu rapat (1.0) atau terlalu renggang (2.5) keduanya tidak nyaman
- **text-align**: arah baca yang sesuai (kiri untuk bahasa Indonesia/Inggris)
- **text-transform**: konsistensi kapitalisasi heading atau label

## Cara Pengimplementasian

```css
:root {
  /* Line height */
  --leading-tight:  1.25;
  --leading-snug:   1.375;
  --leading-normal: 1.5;
  --leading-relaxed: 1.625;
  --leading-loose:  2;
}

body {
  font-size: var(--text-base);
  line-height: var(--leading-normal);
}

h1, h2, h3 {
  line-height: var(--leading-tight);
}

p {
  line-height: var(--leading-relaxed);
  text-align: left;
  /* JANGAN justify tanpa hyphens — spacing antar kata jadi tidak rata */
}

/* text-transform */
.nav-link {
  text-transform: uppercase;
  font-size: var(--text-sm);
  letter-spacing: 0.05em;
}
```

## Analogi

Rumah:
- **line-height** = jarak antar rak buku di lemari. Terlalu rapat (1.0) buku susah diambil. Terlalu renggang (2.5) buang-buang ruang. Ideal (1.5) — buku mudah diambil dan nyaman dilihat
- **text-align** = bagaimana kertas ditempel di papan: rata kiri (left), di tengah (center), atau rata kanan (right)
- **text-transform** = semua label "KAMAR TIDUR" pakai huruf kapital — konsisten di seluruh rumah

## Dipakai Untuk Apa

- **line-height**: body text (1.5-1.7), heading (1.2-1.3), paragraf panjang (1.6-1.8)
- **text-align**: body (left), hero title (center), tidak pernah justify tanpa hyphens
- **text-transform**: nav link (uppercase), section title (uppercase), tidak untuk body text

## Kesalahan Umum

- **line-height tanpa satuan vs dengan satuan**: gunakan tanpa satuan (`1.5`) — relatif ke font-size, lebih mudah diprediksi. `line-height: 24px` akan error jika font-size besar
- **text-align: justify tanpa hyphens**: celah antar kata tidak merata — sulit dibaca
- **text-transform: uppercase di body text**: membaca teks kapital panjang sangat melelahkan
- **line-height terlalu kecil di heading**: heading besar dengan line-height 1.0 — baris kedua nabrak baris pertama

## Hubungan dengan Materi Sebelumnya

Poin 12-14: font, ukuran, dan ketebalan sudah diatur. Tapi teks yang enak dibaca butuh **jarak baris yang nyaman** (line-height). Tanpa line-height yang tepat, paragraf terasa sesak. Inilah **sentuhan akhir** tipografi yang membuat website terasa profesional.

## Soal Latihan

### Soal 1
Apa nilai ideal `line-height` untuk body text dan heading?

**Jawaban:**
Body text: 1.5-1.7 (agar nyaman dibaca baris per baris). Heading: 1.2-1.3 (karena heading pendek, tidak butuh ruang sebanyak body).

### Soal 2
Tulis CSS untuk membuat section title uppercase dengan letter spacing.

**Jawaban:**
```css
.section-title {
  text-transform: uppercase;
  letter-spacing: 0.05em;
  font-size: var(--text-sm);
}
```

### Soal 3
Mengapa `text-align: justify` tanpa properti `hyphens` tidak disarankan?

**Jawaban:**
CSS akan menambah spasi antar kata secara tidak merata untuk membuat rata kanan-kiri — menghasilkan "sungai putih" (white rivers) yang mengganggu kenyamanan baca. Hyphens memecah kata dengan tanda hubung agar spacing lebih merata.
