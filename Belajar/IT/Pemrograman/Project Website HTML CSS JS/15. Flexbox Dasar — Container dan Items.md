# 15. Flexbox Dasar — Container dan Items

Flexbox adalah sistem layout satu dimensi (1D) yang mengatur bagaimana elemen-elemen berjajar dalam satu baris atau satu kolom. Ini adalah alat utama untuk menyusun komponen: navbar, kartu, tombol, dan form. Begitu kamu menguasainya, memposisikan elemen tidak lagi menjadi perang memakai margin dan float.

## 1. Penjelasan Singkat & Konsep Dasar

Materi 14 menutup Level 2 dengan box model — kamu sudah paham bahwa setiap elemen adalah kotak dengan margin, padding, border, dan content. Masalahnya, kotak-kotak itu secara default cuma bisa menumpuk ke bawah (block) atau menyamping (inline), dan menengahkan sesuatu butuh trik margin yang rapuh. Flexbox hadir untuk menjawab: bagaimana menata banyak kotak dalam satu arah secara fleksibel dan bisa diprediksi. Ini pintu masuk Level 3 dan dasar sebelum CSS Grid.

Prinsip paling penting: Flexbox punya **dua jenis aktor**. **Flex container** adalah induk yang diberi `display: flex`. **Flex item** adalah *semua direct children* dari container itu — bukan cucu, bukan elemen di dalam child. Aturan layout dari Flexbox hanya berlaku antara container dan item langsungnya. Kalau mau mengatur isi di dalam sebuah item, item itu harus dijadikan container sendiri (boleh nested).

Container mendefinisikan **dua sumbu**. **Main axis** adalah arah utama, ditentukan `flex-direction`: `row` (kiri ke kanan, default) atau `column` (atas ke bawah). **Cross axis** tegak lurus terhadapnya. Semua properti layout sebenarnya adalah jawaban atas dua pertanyaan sederhana: *bagaimana item dibagi di sepanjang sumbu utama* (`justify-content`) dan *bagaimana item disejajarkan di sumbu silang* (`align-items`). Lupa bahwa `justify-content` selalu tentang sumbu utama adalah sumber kebingungan nomor satu pemula.

Item memiliki **dimensi fleksibel**: `flex-grow` (boleh membesar mengisi ruang kosong), `flex-shrink` (boleh mengecil bila ruang kurang), dan `flex-basis` (ukuran awal sebelum grow/shrink). Shorthand `flex` menggabungkan ketiganya, dan `flex: 1` (sama dengan `1 1 0`) adalah pola paling sering untuk "bagi ruang sama rata". Satu item juga bisa menyimpang dari aturan container lewat `align-self` dan `order`.

Properti pendukung yang wajib dihafal: `gap` memberi jarak antar item tanpa repot margin (dan tidak collapsing seperti margin vertikal), `flex-wrap: wrap` mengizinkan item pindah baris bila tidak muat — penting untuk konten yang panjangnya tidak bisa diprediksi. Jangan lupa `align-items: stretch` adalah default, yang membuat semua item setinggi container secara otomatis — itu sebabnya tombol-tombol di dalam baris yang sama bisa sama tingginya.

**Benang merah**: box model (14) memberi tahu berapa besar kotaknya, Flexbox mengatur *di mana* kotak itu duduk dalam satu arah. Di materi 16 kamu akan melihat Grid menangani dua arah sekaligus; di materi 17 Flexbox dan Grid bekerja sama untuk membangun halaman responsif.

## 2. Fungsi & Kegunaan Utama dalam Web

Hampir semua komponen UI di "Perpustakaan Digital Kota" dibangun dengan Flexbox. Ini beberapa peran utamanya:

- **Navbar**: logo di kiri, menu di kanan, dan keduanya sejajar vertikal. `justify-content: space-between` mendorong kedua ujung, `align-items: center` menyelaraskan tingginya. Satu baris CSS menggantikan tiga trik margin.
- **Hero section**: menengahkan judul, tagline, dan tombol di tengah halaman secara sempurna — horizontal dan vertikal. Pola `justify-content: center` + `align-items: center` + `flex-direction: column`.
- **Kartu buku**: isi kartu (judul, penulis, deskripsi) mendorong tombol ke bawah sehingga semua tombol di satu baris kartu sejajar. Ini pola "footer selalu di bawah" lewat `flex-direction: column` + `flex: 1` pada area konten.
- **Form row**: label dan input sebaris, atau tombol "Batal" dan "Simpan" yang berjajar di kanan bawah form.
- **Badge dan ikon kecil**: menyelaraskan angka di dalam lingkaran, atau ikon dengan teks di tombol — `align-items: center` adalah teman sehari-hari.

Pembagian kerja yang akan kamu pegang sampai materi 16: **Flexbox untuk komponen (satu arah), Grid untuk halaman (dua arah)**.

/* ── Navbar: logo kiri, menu kanan ──────────────────────────────────── */
.navbar {
    display: flex;

    text-decoration: none;

    padding: 24px;
}

/* ── Kartu buku: footer tombol selalu menempel di bawah ──────────────── */
.kartu-buku {
    display: flex;

    border-radius: 8px;

}

.kartu-buku__btn {

    color: #ffffff;

/* ── Form row: dua tombol sejajar di kanan ────────────────────────────── */
.form-aksi {
    display: flex;
    justify-content: flex-end;  /* dorong tombol ke kanan */
    gap: 12px;
    padding: 16px 24px;
}

.btn { padding: 10px 20px; border-radius: 6px; cursor: pointer; }
.btn--utama  { background: #2563eb; color: #fff; border: none; }
.btn--kembali { background: #f1f5f9; color: #1e293b; border: 1px solid #e2e8f0; }

/* ── Hero: tengahkan konten di kedua arah ────────────────────────────── */
.hero {
    display: flex;
    flex-direction: column;   /* sumbu utama vertikal: judul → tombol */
    justify-content: center;  /* tengah pada sumbu utama */
    align-items: center;      /* tengah pada sumbu silang */
    min-height: 400px;
    text-align: center;
    gap: 16px;
    background: linear-gradient(135deg, #2563eb, #059669);
    color: #ffffff;

Beberapa poin dari kode di atas: `gap` menggantikan margin antar item dan tidak collapsing; `flex-wrap: wrap` di `.katalog` membuat kartu tidak menyempit tak wajar; `flex: 1` pada deskripsi adalah kunci pola "footer selalu di bawah".

## 4. Analogi Sederhana — Membangun Rumah

Kalau HTML adalah kerangka rumah dan CSS adalah cat serta interiornya, maka Flexbox adalah **menata perabot dalam satu ruangan** — satu baris di sepanjang dinding. Bayangkan kamu menyusun sofa, meja, dan lampu berdampingan di satu dinding.

- `display: flex` adalah keputusan "semua furnitur ini diatur berjajar di dinding ini".
- `flex-direction` memilih dinding mana: `row` = menyusun dari kiri ke kanan di sepanjang dinding, `column` = menyusun dari lantai ke langit-langit (atau dari depan ke belakang ruangan).
- `justify-content` adalah **membagi jarak antar furnitur di dinding** itu: `space-between` = sofa menempel kiri, lampu menempel kanan, meja mengambang di tengah; `center` = ketiganya berkumpul di tengah; `flex-start` = semua rata ke kiri.
- `align-items` adalah seberapa tinggi furnitur disejajarkan: `center` = semua di tengah tinggi dinding, `flex-end` = semua berdiri di lantai (bawah).
- `flex: 1` pada sofa berarti "sofa memakai sisa ruang dinding yang kosong", sehingga meja dan lampu terdorong sampai ujung.
- `flex-wrap` adalah mengizinkan furnitur pindah ke baris kedua (dinding kedua) ketika dinding pertama tidak cukup menampungnya.

Poin kuncinya: Flexbox selalu menata dalam **satu arah pada satu waktu** — kamu memilih dindingnya dulu, baru membagi jaraknya. Grid (materi 16) akan memetakan seluruh denah rumah sekaligus.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

- **Navbar dan header**: satu baris yang isinya logo kiri, menu kanan, hamburger di pojok. Klasik `space-between` + `align-items: center`.
- **Kartu apa pun dengan tombol di bawah**: daftar kartu buku, kartu statistik, kartu berita — `flex-direction: column` + `flex: 1` pada konten membuat semua footer sejajar meski panjang teks berbeda.
- **Menengahkan hero / konten satu dimensi**: section selamat datang, halaman kosong ("Buku tidak ditemukan"), pesan loading. `justify-content` + `align-items` center.
- **Form dan grup aksi**: pasangan label+input sebaris, deretan tombol di pojok form, grup radio/checkbox berjajar.
- **Tombol dengan ikon atau badge**: menyelaraskan ikon, teks, dan angka dalam satu elemen interaktif.

## 6. Poin-poin Penting & Best Practices

- **Gunakan `gap`, bukan margin antar item.** Margin bisa collapsing dan sulit dihitung; `gap` selalu jarak bersih antar item di container flex/grid.
- **`align-items: stretch` (default) itu fitur**: biarkan item setinggi container untuk baris yang rapi (misal tombol setinggi field input).
- **Shorthand `flex` lebih dipahami daripada tiga properti**: `flex: 1` untuk membagi ruang, `flex: none` (`0 0 auto`) untuk "jangan berubah", `flex: 1 0 150px` untuk dasar yang disisipkan. Mulai dari shorthand, pelajari grow/shrink/basis sebagai detail.
- **`flex-shrink: 0` pada logo dan tombol** mencegah elemen penting menyempit saat ruang sempit.
- **Pikirkan arah dulu**: tentukan main axis (row/column) sebelum menyentuh `justify-content` — karena maknanya berubah mengikuti arah.
- **Flexbox satu arah, Grid dua arah**: mulai dari Flexbox untuk komponen, dan pertimbangkan Grid (materi 16) saat kamu mendeskripsikan baris dan kolom sekaligus.
- **Jangan nested Flexbox berlebihan**: dua-tiga lapis masih wajar; lebih dari itu pertanda struktur HTML perlu dipertimbangkan ulang.

## 7. Kesalahan Umum (Common Pitfalls & Bugs)

- **Lupa `flex-wrap: wrap`, konten menyempit.** Satu baris item ditampilkan menyempit tanpa pindah baris. Perbaikan: tambahkan `flex-wrap: wrap` bila jumlah atau panjang item tidak bisa diprediksi (misal katalog).
- **`justify-content` dan `align-items` tertukar.** Kamu ingin menengahkan vertikal tapi menulis `justify-content: center` padahal arahnya `row`. Perbaikan: ingat mantranya — `justify-content` = sumbu utama (arah flex-direction), `align-items` = sumbu silang (tegak lurus). Gambarkan sumbunya dulu.
- **`flex: 1` dipakai pada item yang seharusnya tidak tumbuh.** Semua menu jadi membesar meregang. Perbaikan: gunakan `flex: none` atau biarkan default (`0 1 auto`) untuk item yang ukurannya mengikuti konten.
- **`flex-direction: column` tapi lupa `align-items`.** Item di kolom otomatis meregang penuh (stretch) dan terlihat aneh. Perbaikan: set `align-items: center` atau `flex-start` bila kamu ingin item selebar kontennya.
- **Menata flex item "cucu" lewat container.** Property flex hanya berlaku untuk *direct children*. Perbaikan: jadikan item itu container sendiri bila perlu mengatur isinya.

## 8. Mini Project / Soal Latihan & Kunci Jawaban

### Tantangan

1. **Navbar perpustakaan**: buat header dengan logo kiri, tiga link menu di kanan, semua rata tengah vertikal, jarak antar link 24px. Pastikan logo tidak menyempit saat lebar layar kecil.
2. **Kartu dengan footer selalu di bawah**: buat dua kartu buku dengan tinggi konten berbeda (satu deskripsi panjang, satu pendek) dalam satu baris flex. Tombol "Lihat Detail" harus sejajar di bawah meski isi kartu berbeda.

**Pembahasan**: tantangan 1 selesai dengan `space-between` (logo dan menu terpisah ke dua ujung) + `align-items: center` (rata tengah vertikal) + `gap` (jarak link). Tantangan 2 adalah pola kunci Flexbox: `display: flex` + `flex-direction: column` pada kartu, lalu `flex: 1` pada `.kartu__deskripsi` membuat deskripsi pendek memakan sisa ruang sehingga tombol di kedua kartu terdorong ke garis bawah yang sama. Perhatikan juga `align-items: stretch` pada `.baris-kartu` membuat kedua kartu setinggi baris meski isinya berbeda. Uji di DevTools: matikan `flex: 1` pada deskripsi dan lihat tombolnya tidak lagi sejajar — bukti kerja satu baris itu.
