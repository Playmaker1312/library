# 529. Cara Mengkonfigurasi Continuous Deployment di Netlify dari GitHub Repository

## Definisi & Target
Continuous Deployment (CD) adalah otomatisasi deploy dimana setiap push ke branch GitHub akan langsung me-deploy website terbaru ke Netlify. Netlify terintegrasi dengan GitHub dan secara otomatis build dan deploy saat ada perubahan. Target: website otomatis terupdate setiap kali developer melakukan push ke repository.

## Analogi Alur
Continuous Deployment seperti conveyor belt di pabrik — Anda tinggal meletakkan bahan baku (push kode) di awal ban berjalan, dan produk jadi (website terdeploy) keluar di ujung ban tanpa perlu campur tangan manual.

## Poin-Poin Penting
- Hubungkan Netlify dengan GitHub repository melalui OAuth
- Set build command dan publish directory (untuk website statis, kosongkan)
- Netlify otomatis deploy setiap push ke branch tertentu
- Deploy previews untuk pull request (review sebelum merge)
- Environment variables dapat dikonfigurasi di dashboard

## Cara Integrasi
Di Netlify dashboard, klik "Add new site" > "Import an existing project". Pilih GitHub dan repository yang diinginkan. Biarkan build settings default untuk website statis. Klik "Deploy site". Setiap push ke branch main akan otomatis me-deploy versi terbaru. Untuk menonaktifkan auto-deploy, atur di Deploy settings.
