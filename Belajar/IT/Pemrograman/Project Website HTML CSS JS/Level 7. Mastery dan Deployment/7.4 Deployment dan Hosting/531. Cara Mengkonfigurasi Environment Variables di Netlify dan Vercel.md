# 531. Cara Mengkonfigurasi Environment Variables di Netlify dan Vercel

## Definisi & Target
Environment variables (env vars) adalah nilai konfigurasi yang disimpan di luar kode sumber, seperti API keys, URL endpoint, dan pengaturan environment. Di Netlify dan Vercel, env vars dikonfigurasi melalui dashboard dan diakses melalui JavaScript di browser (dengan prefix `VITE_` atau `NEXT_PUBLIC_`). Target: menyimpan konfigurasi sensitif secara aman tanpa hardcode di kode.

## Analogi Alur
Environment variables seperti loker kunci yang digantung di dinding — setiap orang bisa mengambil kunci yang diperlukan tanpa harus membawa semua kunci. Jika kunci hilang (API key berubah), Anda cukup ganti di loker, tidak perlu membuat ulang semua kunci (kode).

## Poin-Poin Penting
- Di Netlify: Site settings > Environment variables
- Di Vercel: Project Settings > Environment Variables
- Prefix `REACT_APP_` untuk Create React App, `VITE_` untuk Vite
- Variabel dapat dibedakan per environment (production, preview, development)
- Jangan commit file `.env` ke repository — tambahkan ke `.gitignore`

## Cara Integrasi
Buat file `.env` untuk development lokal dan `.env.example` sebagai template. Di Netlify/Vercel dashboard, tambahkan environment variables yang sama. Gunakan prefix yang sesuai framework (`VITE_` untuk Vite, `REACT_APP_` untuk CRA). Akses di kode melalui `import.meta.env.VITE_*` (Vite). Jangan commit file `.env` asli. Gunakan serverless functions untuk API keys yang sensitif.
