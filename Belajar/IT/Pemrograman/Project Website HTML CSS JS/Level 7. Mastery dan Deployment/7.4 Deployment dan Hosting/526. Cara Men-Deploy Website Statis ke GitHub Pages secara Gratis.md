# 526. Cara Men-Deploy Website Statis ke GitHub Pages secara Gratis

## Definisi & Target
GitHub Pages adalah layanan hosting gratis dari GitHub untuk website statis. Website dihosting langsung dari repository GitHub dan dapat diakses melalui URL `username.github.io`. Target: website statis HTML/CSS/JS dapat diakses publik secara online dalam hitungan menit tanpa biaya.

## Analogi Alur
GitHub Pages seperti menyewa lemari penyimpanan gratis di pusat perbelanjaan — Anda tinggal memasukkan barang (file website) ke lemari (repository), dan pengelola (GitHub) menyediakan etalase (URL publik) agar orang bisa melihat barang Anda.

## Poin-Poin Penting
- Repository harus bernama `username.github.io` untuk user site
- Untuk project site, aktifkan GitHub Pages di Settings > Pages
- GitHub Pages mendukung custom domain dan HTTPS otomatis
- Source bisa dari branch `main` atau `/docs` folder
- Build dengan Jekyll didukung untuk website yang lebih kompleks

```yaml
# .github/workflows/deploy.yml - GitHub Actions untuk auto-deploy
name: Deploy to GitHub Pages
on:
  push:
    branches: ["main"]
  workflow_dispatch:
permissions:
  contents: read
  pages: write
  id-token: write
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
      - name: Setup Pages
        uses: actions/configure-pages@v4
      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: '.'
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

## Cara Integrasi
Buat repository GitHub dengan nama `username.github.io`. Push file website ke branch `main`. Buka Settings > Pages, pilih branch `main` dan folder `/ (root)`. Tunggu 2-5 menit, website akan live di `https://username.github.io`. Untuk update, cukup push perubahan ke GitHub dan Pages akan otomatis rebuild.
