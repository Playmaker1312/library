# 530. Cara Men-Deploy Website ke Vercel menggunakan Vercel CLI

## Definisi & Target
Vercel adalah platform hosting untuk frontend dengan dukungan serverless functions. Vercel CLI memungkinkan deploy langsung dari terminal tanpa GUI. Vercel terintegrasi dengan Git dan menyediakan preview deployments, CDN global, dan HTTPS otomatis. Target: deploy website statis menggunakan command line dalam beberapa detik.

## Analogi Alur
Vercel CLI seperti remote control untuk drone — Anda tinggal tekan tombol (perintah CLI) dan drone (Vercel) akan terbang dan menjalankan misi (deploy website). Semua proses otomatis tanpa perlu mengoperasikan joystick manual.

## Poin-Poin Penting
- Install Vercel CLI: `npm install -g vercel`
- Perintah dasar: `vercel` untuk preview, `vercel --prod` untuk production
- Vercel otomatis mendeteksi framework (Vite, Next.js, dll)
- Setiap deploy mendapat URL preview unik
- Integrasi Git: push ke branch akan trigger auto-deploy

## Cara Integrasi
Install Vercel CLI (`npm i -g vercel`). Jalankan `vercel login` untuk autentikasi. Di folder project, jalankan `vercel` untuk deploy preview. Untuk production, jalankan `vercel --prod`. Alternatif, hubungkan repository GitHub di dashboard Vercel untuk auto-deploy. Konfigurasi tambahan melalui file `vercel.json`.
