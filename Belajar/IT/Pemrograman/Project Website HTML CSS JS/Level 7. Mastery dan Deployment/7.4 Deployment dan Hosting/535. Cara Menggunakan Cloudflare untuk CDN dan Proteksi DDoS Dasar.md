# 535. Cara Menggunakan Cloudflare untuk CDN dan Proteksi DDoS Dasar

## Definisi & Target
Cloudflare adalah platform yang menyediakan CDN, keamanan (DDoS protection), dan optimasi performa untuk website. Cloudflare bertindak sebagai reverse proxy antara pengunjung dan server hosting. Target: website lebih cepat (CDN), lebih aman (DDoS protection), dan lebih hemat bandwidth (caching).

## Analogi Alur
Cloudflare seperti pos keamanan di pintu masuk kompleks perumahan. Petugas (Cloudflare) memeriksa setiap pengunjung (DDoS protection), mengarahkan tamu ke rumah yang tepat (CDN ke server terdekat), dan menyimpan paket untuk pengambilan cepat (caching). Penghuni (server) lebih aman dan tidak kewalahan.

## Poin-Poin Penting
- Cloudflare menyediakan paket gratis dengan fitur dasar yang lengkap
- Ubah nameserver di registrar domain ke nameserver Cloudflare
- Fitur utama: CDN, SSL, DDoS protection, Firewall, Caching
- Page Rules untuk caching dan redirect custom
- Cloudflare juga menyediakan analytics dan bot management

## Cara Integrasi
Buat akun Cloudflare dan tambahkan domain. Cloudflare akan memindai DNS records. Ganti nameserver di registrar dengan nameserver Cloudflare. Tunggu propagasi. Atur SSL/TLS ke Full (strict) untuk keamanan maksimal. Aktifkan Auto Minify, Brotli, dan Rocket Loader di tab Speed. Buat Page Rules untuk caching asset statis. Pantau analytics di dashboard Cloudflare.
