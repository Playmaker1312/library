# 532. Cara Menggunakan Netlify Forms untuk Menangani Form Submission Tanpa Backend

## Definisi & Target
Netlify Forms adalah fitur yang menangani form submission tanpa perlu server backend. Cukup tambahkan atribut `netlify` pada tag `<form>` dan Netlify akan otomatis menangkap, menyimpan, dan mengirim notifikasi submission via email atau webhook. Target: form di website statis dapat mengirim data tanpa menulis kode server.

## Analogi Alur
Netlify Forms seperti kotak surat di depan rumah — Anda tinggal menulis surat (mengisi form) dan memasukkannya ke kotak (submit). Petugas pos (Netlify) akan mengambil surat, mencatatnya, dan memberitahu Anda (notifikasi). Tidak perlu membangun kantor pos sendiri (backend).

## Poin-Poin Penting
- Tambahkan atribut `netlify` pada tag `<form>` atau `data-netlify="true"`
- Setiap form harus memiliki atribut `name` yang unik
- Submission dapat dilihat di Netlify Dashboard > Forms
- Notifikasi email dapat diatur per form (Site settings > Form notifications)
- Integrasi webhook untuk mengirim data ke layanan lain (Zapier, Slack)

```html
<!-- AJAX submission ke Netlify Forms -->
<script>
const form = document.querySelector('form');
form.addEventListener('submit', async (e) => {
  e.preventDefault();
  const formData = new FormData(form);
  try {
    const response = await fetch('/', {
      method: 'POST',
      headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
      body: new URLSearchParams(formData).toString()
    });
    if (response.ok) {
      alert('Form submitted successfully!');
    }
  } catch (err) {
    console.error('Form submission error:', err);
  }
});
</script>
```

## Cara Integrasi
Tambahkan atribut `netlify` pada tag `<form>` (atau `data-netlify="true"`). Tambahkan hidden input `form-name` dengan nama form. Setiap form harus memiliki atribut `name` unik. Tambahkan honeypot field untuk anti-spam. Deploy ke Netlify. Lihat submission di Netlify Dashboard > Forms. Atur notifikasi email atau webhook sesuai kebutuhan.
