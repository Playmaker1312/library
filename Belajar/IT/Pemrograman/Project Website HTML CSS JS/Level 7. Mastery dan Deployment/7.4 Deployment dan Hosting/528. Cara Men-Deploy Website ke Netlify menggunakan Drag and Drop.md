# 528. Cara Men-Deploy Website ke Netlify menggunakan Drag and Drop

## Definisi & Target
Netlify adalah platform hosting untuk website statis dengan fitur drag and drop deployment. Cukup drag folder project ke browser dan website langsung live. Netlify menyediakan CDN global, HTTPS otomatis, dan URL staging. Target: deploy website statis dalam hitungan detik tanpa command line.

## Analogi Alur
Netlify drag and drop seperti mengirim file melalui layanan cloud — Anda tinggal drag folder dari komputer ke jendela browser. Dalam beberapa detik, file sudah tersedia secara online. Tidak perlu server, konfigurasi, atau command line.

## Poin-Poin Penting
- Netlify mendukung drag and drop folder project ke dashboard
- URL default: `namaproject.netlify.app` (bisa dikustom)
- HTTPS otomatis aktif dengan sertifikat Let's Encrypt
- Setiap deploy mendapat URL unik untuk preview
- Netlify juga mendukung deploy dari Git (CI/CD)

## Cara Integrasi
Siapkan folder project dengan index.html. Buka app.netlify.com, login. Drag folder project ke area drop. Tunggu deploy selesai. Website langsung live di URL random. Untuk mengganti URL, buka Site Settings > Change site name. Untuk custom domain, buka Domain settings > Add custom domain.
