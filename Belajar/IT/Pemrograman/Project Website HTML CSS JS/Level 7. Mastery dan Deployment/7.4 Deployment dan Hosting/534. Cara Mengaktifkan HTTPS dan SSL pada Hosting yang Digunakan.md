# 534. Cara Mengaktifkan HTTPS dan SSL pada Hosting yang Digunakan

## Definisi & Target
HTTPS (Hypertext Transfer Protocol Secure) mengenkripsi komunikasi antara browser dan server menggunakan SSL/TLS certificate. HTTPS wajib untuk keamanan data, kepercayaan pengguna, dan ranking SEO. Target: semua halaman website dapat diakses melalui HTTPS dengan sertifikat SSL yang valid.

## Analogi Alur
HTTPS seperti amplop tertutup vs kartu pos — kartu pos (HTTP) bisa dibaca siapa saja selama pengiriman. Amplop tertutup (HTTPS) hanya bisa dibaca oleh pengirim dan penerima. Tanpa amplop, informasi sensitif bisa bocor di jalan.

## Poin-Poin Penting
- Let's Encrypt menyediakan SSL certificate gratis dengan validitas 90 hari
- GitHub Pages, Netlify, dan Vercel menyediakan HTTPS otomatis
- Cloudflare menyediakan SSL/HTTPS gratis (Flexible, Full, atau Full Strict)
- Redirect HTTP ke HTTPS wajib untuk menghindari konten campuran
- Setelah HTTPS aktif, perbarui semua internal link ke HTTPS

  <h2>Redirect HTTP ke HTTPS</h2>
  <p>File _redirects (Netlify):</p>
  <pre># Redirect semua HTTP ke HTTPS
http://example.com/* https://example.com/:splat 301</pre>

  <p>Konfigurasi di netlify.toml:</p>
  <pre>[[redirects]]
  from = "http://example.com/*"
  to = "https://example.com/:splat"
  status = 301

[[redirects]]
  from = "http://www.example.com/*"
  to = "https://www.example.com/:splat"
  status = 301</pre>

  <p>Konfigurasi di vercel.json:</p>
  <pre>{
  "redirects": [
    { "source": "http://example.com/(.*)", "destination": "https://example.com/$1", "permanent": true },
    { "source": "http://www.example.com/(.*)", "destination": "https://www.example.com/$1", "permanent": true }

}</pre>

## Cara Integrasi
Untuk GitHub Pages: centang "Enforce HTTPS" di Settings > Pages. Untuk Netlify/Vercel: HTTPS otomatis aktif. Untuk server sendiri: gunakan Certbot dan Let's Encrypt. Pastikan semua link resource menggunakan HTTPS. Redirect HTTP ke HTTPS. Verifikasi dengan SSL Labs SSL Test (ssllabs.com/ssltest/). Perbarui canonical URL ke HTTPS.
