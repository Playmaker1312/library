# 533. Cara Mengkonfigurasi Redirect dan Rewrite Rules di Netlify

## Definisi & Target
Redirect dan rewrite rules di Netlify memungkinkan pengaturan ulang rute URL tanpa server konfigurasi. Redirect mengarahkan browser ke URL lain (dengan kode status 301/302). Rewrite menyajikan konten dari URL lain tanpa mengubah URL di browser (internal). Target: mengelola struktur URL, mencegah broken links, dan mendukung SPA routing.

## Analogi Alur
Redirect seperti petugas info di bandara yang mengarahkan penumpang ke gate yang benar — kadang permanen (penerbangan pindah gate selamanya = 301) atau sementara (gate berubah hari ini = 302). Rewrite seperti jendela informasi yang menampilkan jadwal dari sistem internal tanpa penumpang tahu sumber aslinya.

## Poin-Poin Penting
- File konfigurasi: `_redirects` (plain text) atau `netlify.toml`
- Format `_redirects`: `/sumber /tujuan kode_status`
- Redirect permanen: 301, redirect sementara: 302
- Rewrite untuk SPA: `/* /index.html 200`
- Splats (`*`) dan placeholders (`:param`) untuk pattern matching

## Cara Integrasi
Buat file `_redirects` di root project. Tambahkan rules dengan format `/sumber /tujuan status`. Untuk SPA, tambahkan `/* /index.html 200`. Deploy ke Netlify. Verifikasi dengan curl atau browser. Alternatif, gunakan `[[redirects]]` di `netlify.toml`. Prioritaskan file `_redirects` jika kedua konfigurasi ada.
