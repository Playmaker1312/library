# 527. Cara Mengkonfigurasi Custom Domain di GitHub Pages

## Definisi & Target
Custom domain adalah mengganti URL default GitHub Pages (`username.github.io`) dengan domain sendiri (`www.example.com`). Proses melibatkan konfigurasi DNS dan pengaturan di repository GitHub. Target: website dapat diakses melalui domain kustom dengan HTTPS yang aktif.

## Analogi Alur
Custom domain seperti memasang papan nama toko sendiri di depan gedung — alih-alih "Toko di Lantai 3, Pojok Kiri" (URL GitHub), Anda punya papan "Toko ABC" (domain sendiri) yang lebih profesional dan mudah diingat.

## Poin-Poin Penting
- Buat file `CNAME` di repository dengan isi domain kustom
- Konfigurasi DNS: A records ke IP GitHub Pages atau CNAME ke username.github.io
- GitHub Pages menyediakan HTTPS otomatis untuk custom domain
- Untuk domain apex (example.com), gunakan A records
- Untuk subdomain (www.example.com), gunakan CNAME record

## Cara Integrasi
Beli domain dari registrar. Buat file CNAME di root repository. Konfigurasi DNS dengan A records (apex) atau CNAME (subdomain). Di GitHub Settings > Pages, masukkan custom domain dan centang Enforce HTTPS. Tunggu propagasi DNS (bisa hingga 24 jam). Verifikasi dengan membuka domain di browser.
