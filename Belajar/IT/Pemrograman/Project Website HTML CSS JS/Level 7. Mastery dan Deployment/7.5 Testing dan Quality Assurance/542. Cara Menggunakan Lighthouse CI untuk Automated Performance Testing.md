# 542. Cara Menggunakan Lighthouse CI untuk Automated Performance Testing

## Definisi & Target
Lighthouse CI adalah alat untuk menjalankan audit Lighthouse secara otomatis di pipeline CI/CD. Lighthouse CI membandingkan skor performa antara branch dan mendeteksi regresi. Target: setiap pull request di-audit performanya secara otomatis sebelum di-merge ke branch utama.

## Analogi Alur
Lighthouse CI seperti inspektur bangunan yang datang setiap ada renovasi — sebelum renovasi (baseline) dan sesudah renovasi (PR). Inspektur memberikan laporan (skor) dan menyoroti jika ada penurunan kualitas. Kontraktor (developer) harus memperbaiki sebelum renovasi disetujui (merge).

## Poin-Poin Penting
- Lighthouse CI dapat dijalankan di GitHub Actions, CircleCI, GitLab CI
- Fitur: assert (threshold), budget, report diff, dan summary
- Konfigurasi melalui file `lighthouserc.js` atau `lighthouserc.json`
- Reports disimpan sebagai artifacts atau diupload ke LHCI server
- Integrasi dengan GitHub PR comments untuk notifikasi langsung

  <h2>Konfigurasi Lighthouse CI</h2>
  <pre>// lighthouserc.js
module.exports = {
  ci: {
    collect: {
      url: ['http://localhost:3000'],
      numberOfRuns: 3,

    assert: {
      preset: 'lighthouse:recommended',
      assertions: {
        'categories:performance': ['warn', { minScore: 0.9 }],
        'categories:accessibility': ['error', { minScore: 0.9 }],

      target: 'temporary-public-storage',
    },

  <h2>GitHub Actions Workflow</h2>
  <pre># .github/workflows/lighthouse.yml
name: Lighthouse CI
on: [pull_request]
jobs:
  lighthouse:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - run: npm ci
      - run: npm run build
      - name: Run Lighthouse CI
        run: |
          npm install -g @lhci/cli
          lhci autorun
        env:
          LHCI_GITHUB_APP_TOKEN: ${{ secrets.LHCI_GITHUB_APP_TOKEN }}</pre>

## Cara Integrasi
Install LHCI CLI: `npm install -g @lhci/cli`. Buat file `lighthouserc.js` dengan konfigurasi collect, assert, dan upload. Tambahkan workflow GitHub Actions. Set assertions untuk threshold yang diinginkan. Setiap PR akan mendapatkan komentar dengan skor Lighthouse. Jika ada regresi, PR akan ditandai dan perlu diperbaiki sebelum merge.
