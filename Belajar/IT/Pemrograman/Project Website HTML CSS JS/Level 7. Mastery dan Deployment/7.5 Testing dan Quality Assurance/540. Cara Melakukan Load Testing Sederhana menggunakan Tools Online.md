# 540. Cara Melakukan Load Testing Sederhana menggunakan Tools Online

## Definisi & Target
Load testing adalah proses mengukur performa website di bawah beban lalu lintas tinggi. Tools online seperti Loader.io, K6 (Grafana), dan Pagespeed.web.dev menyediakan load testing gratis dengan simulasi pengguna konkuren. Target: mengetahui kapasitas website dan mengidentifikasi bottleneck sebelum terjadi traffic spike.

## Analogi Alur
Load testing seperti stress test jembatan sebelum dibuka — Anda mengirim ribuan mobil (pengguna) secara bersamaan untuk melihat apakah jembatan (server) mampu menahan beban. Jika ada retakan (bottleneck), Anda perbaiki sebelum jembatan benar-benar digunakan.

## Poin-Poin Penting
- Loader.io: gratis hingga 10.000 concurrent clients, test dari beberapa region
- K6: open-source, scriptable, terintegrasi dengan CI/CD
- Metrics penting: response time, throughput, error rate, CPU/memory usage
- Test types: smoke test, load test, stress test, spike test, soak test
- Threshold: response time < 200ms (p95), error rate < 1%

import http from 'k6/http';
import { check, sleep } from 'k6';
import { Rate } from 'k6/metrics';

const errorRate = new Rate('errors');

export const options = {
  stages: [
    { duration: '1m', target: 50 },
    { duration: '2m', target: 50 },
    { duration: '1m', target: 0 },
  ],
  thresholds: {
    http_req_duration: ['p(95)<500'],
    errors: ['rate<0.01'],
  },
};

export default function () {
  const res = http.get('https://example.com');
  const passed = check(res, {
    'status is 200': (r) => r.status === 200,
    'response time < 500ms': (r) => r.timings.duration < 500,
  });
  errorRate.add(!passed);
  sleep(1);
}</pre>

// Load test dengan performance API client-side
function simulateLoad() {
  const requests = [];
  for (let i = 0; i < 20; i++) {
    const start = performance.now();
    requests.push(
      fetch('/api/health')
        .then(() => performance.now() - start)
        .catch(() => Infinity)
    );
  }
  return Promise.all(requests).then(times => ({
    avg: times.filter(t => t !== Infinity).reduce((a, b) => a + b, 0) / times.length,
    failures: times.filter(t => t === Infinity).length
  }));
}

## Cara Integrasi
Untuk quick test: gunakan Loader.io (gratis, tanpa setup). Untuk test terprogram: install K6 dan tulis script JavaScript. Integrasikan K6 ke CI/CD untuk regression testing. Pantau metrics: response time, error rate, throughput. Tetapkan threshold dan alert jika dilanggar. Lakukan load test sebelum campaign atau rilis besar.
