# 536. Cara Melakukan Cross-Browser Testing menggunakan BrowserStack atau Sauce Labs

## Definisi & Target
Cross-browser testing adalah proses memverifikasi website berfungsi dengan benar di berbagai browser (Chrome, Firefox, Safari, Edge) dan perangkat (desktop, tablet, mobile). BrowserStack dan Sauce Labs menyediakan akses ke browser dan perangkat nyata di cloud. Target: website memberikan pengalaman konsisten di semua browser dan perangkat target.

## Analogi Alur
Cross-browser testing seperti mencicipi masakan di beberapa restoran berbeda — resep yang sama (kode website) mungkin terasa berbeda tergantung koki (browser) dan peralatan dapur (perangkat). Anda perlu memastikan masakan enak di semua tempat.

## Poin-Poin Penting
- BrowserStack menyediakan 3000+ browser/perangkat nyata di cloud
- Sauce Labs mendukung automated testing dengan Selenium
- Fokus pada browser dengan market share tertinggi (Chrome, Safari, Firefox, Edge)
- Mobile testing penting karena mobile-first indexing
- Automated cross-browser testing dapat diintegrasikan ke CI/CD

```javascript
// BrowserStack automated test dengan WebDriverIO
const { remote } = require('webdriverio');
const browserstackConfig = {
  user: process.env.BROWSERSTACK_USERNAME,
  key: process.env.BROWSERSTACK_ACCESS_KEY,
  capabilities: [{
    browserName: 'Chrome',
    browserVersion: 'latest',
    'bstack:options': { os: 'Windows', osVersion: '11' }
  }, {
    browserName: 'Safari',
    browserVersion: 'latest',
    'bstack:options': { os: 'OS X', osVersion: 'Sonoma' }
  }, {
    browserName: 'Firefox',
    browserVersion: 'latest',
    'bstack:options': { os: 'Windows', osVersion: '11' }
  }]
};

async function runCrossBrowserTests() {
  for (const caps of browserstackConfig.capabilities) {
    const browser = await remote({ ...browserstackConfig, capabilities: caps });
    await browser.url('https://example.com');
    const title = await browser.getTitle();
    console.log(`${caps.browserName}: Title is "${title}"`);
    await browser.deleteSession();
  }
}
```

## Cara Integrasi
Identifikasi browser target berdasarkan analytics website. Daftar di BrowserStack atau Sauce Labs. Lakukan manual testing di browser utama. Untuk automated testing, integrasikan dengan Selenium atau WebDriverIO. Gunakan CI/CD pipeline untuk menjalankan cross-browser test otomatis. Catat isu per browser dan perbaiki dengan fallback atau polyfill.
