# 538. Cara Menulis Test Dasar menggunakan Playwright untuk Mengecek Elemen dan Interaksi

## Definisi & Target
Playwright test dasar mencakup: memeriksa elemen muncul di halaman, memverifikasi teks, mengisi form, mengklik tombol, dan memvalidasi hasil. Test dasar ini membentuk fondasi untuk suite pengujian yang komprehensif. Target: menulis test yang andal untuk memvalidasi fungsionalitas inti website.

## Analogi Alur
Menulis test Playwright seperti membuat checklist untuk quality control — "Apakah tombol login muncul?", "Apakah teks error tampil saat form kosong?", "Apakah halaman beranda memuat dalam 5 detik?". Robot (Playwright) menjalankan checklist ini setiap kali ada perubahan kode.

## Poin-Poin Penting
- Gunakan locator strategies: `page.locator()`, `page.getByRole()`, `page.getByText()`
- Auto-wait: Playwright menunggu elemen muncul sebelum berinteraksi
- Assertions: `expect(locator).toHaveText()`, `toBeVisible()`, `toHaveCount()`
- Test struktur: `test('nama test', async ({ page }) => { ... })`
- Hook: `test.beforeEach` dan `test.afterEach` untuk setup/teardown

```javascript
// tests/basic.spec.js
const { test, expect } = require('@playwright/test');

test('halaman memiliki judul yang benar', async ({ page }) => {
  await page.goto('http://localhost:3000');
  await expect(page).toHaveTitle(/Playwright Test Examples/);
});

test('tombol show menampilkan pesan tersembunyi', async ({ page }) => {
  await page.goto('http://localhost:3000');
  const message = page.locator('#hiddenMessage');
  await expect(message).not.toBeVisible();
  await page.click('#showBtn');
  await expect(message).toBeVisible();
  await expect(message).toHaveText('Pesan rahasia');
});

test('form menampilkan error untuk email tidak valid', async ({ page }) => {
  await page.goto('http://localhost:3000');
  await page.fill('#email', 'invalid-email');
  await page.fill('#password', 'rahasia123');
  await page.click('#loginBtn');
  await expect(page.locator('#formAlert')).toHaveText('Email tidak valid');
  await expect(page.locator('#formAlert')).toHaveClass(/error/);
});

test('form menampilkan sukses untuk email valid', async ({ page }) => {
  await page.goto('http://localhost:3000');
  await page.fill('#email', 'user@example.com');
  await page.fill('#password', 'rahasia123');
  await page.click('#loginBtn');
  await expect(page.locator('#formAlert')).toHaveText('Login berhasil!');
  await expect(page.locator('#formAlert')).toHaveClass(/success/);
});

test('menambah dan menghapus item dari list', async ({ page }) => {
  await page.goto('http://localhost:3000');
  await page.click('#addItemBtn');
  await page.click('#addItemBtn');
  await page.click('#addItemBtn');
  await expect(page.locator('.list-item')).toHaveCount(3);
  await page.click('#clearListBtn');
  await expect(page.locator('.list-item')).toHaveCount(0);
});

test('memeriksa tombol memiliki teks yang benar', async ({ page }) => {
  await page.goto('http://localhost:3000');
  const addBtn = page.locator('#addItemBtn');
  await expect(addBtn).toHaveText('Tambah Item');
  await expect(addBtn).toBeEnabled();
});
```

## Cara Integrasi
Buat folder `tests/` di root project. Tulis file test dengan pola `*.spec.js`. Gunakan `page.goto()` untuk navigasi, `page.locator()` untuk menemukan elemen, `expect()` untuk assertions. Jalankan dengan `npx playwright test --headed` untuk melihat browser. Gunakan `--ui` mode untuk debugging visual. Integrasikan ke package.json: `"test": "playwright test"`.
