# 543. Cara Menggunakan W3C Validator untuk Memvalidasi HTML

## Definisi & Target
W3C Markup Validation Service adalah alat resmi dari W3C untuk memeriksa validitas kode HTML. Validator memeriksa kepatuhan terhadap standar HTML5, mendeteksi tag yang tidak ditutup, atribut yang salah, dan nesting error. Target: kode HTML yang valid tanpa error atau warning untuk memastikan kompatibilitas browser dan aksesibilitas.

## Analogi Alur
W3C Validator seperti guru bahasa Indonesia yang memeriksa karangan — memastikan setiap kalimat (tag) dimulai dengan huruf kapital (tag pembuka) dan diakhiri titik (tag penutup), tidak ada kata yang salah eja (atribut salah), dan struktur paragraf (nesting) benar.

## Poin-Poin Penting
- Validator online: validator.w3.org (masukkan URL, upload file, atau paste kode)
- Ekstensi browser: HTML Validator untuk Chrome/Firefox
- Validasi juga dapat dilakukan melalui command line dengan vnu.jar
- HTML valid meningkatkan konsistensi rendering di berbagai browser
- Perbaiki error dari yang paling atas karena error awal sering menyebabkan error lanjutan

```html
    function runValidation() {
      const issues = [];
      const imgs = document.querySelectorAll('img:not([alt])');
      if (imgs.length) issues.push(`Gambar tanpa alt: ${imgs.length}`);
      const ids = {};
      document.querySelectorAll('[id]').forEach(el => {
        if (ids[el.id]) issues.push(`Duplicate ID: ${el.id}`);
        ids[el.id] = true;
      });
      const output = document.getElementById('validationOutput');
      if (issues.length) {
        output.innerHTML = `<div class="invalid-section"><strong>Issues found:</strong><ul>${issues.map(i => `<li>${i}</li>`).join('')}</ul></div>`;
```

```javascript
// Validasi HTML menggunakan Node.js
const { validateText } = require('html-validator');
const fs = require('fs');

const html = fs.readFileSync('index.html', 'utf8');
validateText(html, { format: 'text' })
  .then(result => console.log(result))
  .catch(err => console.error('Validation error:', err));
```

## Cara Integrasi
Validasi HTML secara rutin menggunakan W3C Validator. Untuk otomatisasi, gunakan html-validator npm package di CI/CD. Perbaiki error prioritas: unclosed tags, duplicate IDs, dan invalid nesting. Gunakan ekstensi browser HTML Validator untuk validasi real-time saat development. Standar target: 0 error, 0 warning.
