# 539. Cara Melakukan Visual Regression Testing menggunakan Percy atau Chromatic

## Definisi & Target
Visual regression testing (VRT) adalah teknik membandingkan screenshot halaman website sebelum dan sesudah perubahan untuk mendeteksi perubahan visual yang tidak diinginkan. Percy dan Chromatic adalah tools VRT yang mengotomatisasi perbandingan visual dan menyoroti perbedaan. Target: mendeteksi perubahan visual yang tidak disengaja sebelum masuk ke production.

## Analogi Alur
Visual regression testing seperti fotografer yang mengambil foto sebelum dan sesudah renovasi rumah. Foto dibandingkan pixel-by-pixel untuk melihat perubahan — cat baru (perubahan disengaja) vs retakan dinding (bug visual). Tanpa ini, perubahan kecil bisa terlewat.

## Poin-Poin Penting
- Percy (BrowserStack) terintegrasi dengan Playwright, Cypress, dan Selenium
- Chromatic (Storybook) khusus untuk komponen UI dengan Storybook
- Snapshot baseline disimpan dan dibandingkan dengan snapshot terbaru
- Diff overlay menampilkan perbedaan yang terdeteksi
- VRT idealnya dijalankan di CI/CD setelah pull request

```javascript
// Percy + Playwright integration
const { test, expect } = require('@playwright/test');
const percySnapshot = require('@percy/playwright');

test('halaman utama visual test', async ({ page }) => {
  await page.goto('http://localhost:3000');
  await percySnapshot(page, 'Halaman Utama');
});

test('komponen button visual test', async ({ page }) => {
  await page.goto('http://localhost:3000');
  const buttonCard = page.locator('.card').first();
  await buttonCard.screenshot({ path: 'screenshots/buttons.png' });
  await percySnapshot(page, 'Komponen Button');
});

test('layout grid visual test', async ({ page }) => {
  await page.goto('http://localhost:3000');
  await page.setViewportSize({ width: 1280, height: 800 });
  await percySnapshot(page, 'Layout Desktop');
  await page.setViewportSize({ width: 375, height: 667 });
  await percySnapshot(page, 'Layout Mobile');
});
```

```yaml
# .github/workflows/visual-testing.yml
name: Visual Regression Testing
on: [pull_request]
jobs:
  visual-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - run: npm ci
      - run: npx percy exec -- npx playwright test
        env:
          PERCY_TOKEN: ${{ secrets.PERCY_TOKEN }}
```

## Cara Integrasi
Untuk Percy: daftar di percy.io, dapatkan token. Install `@percy/playwright` dan integrasikan ke test. Jalankan `npx percy exec -- npx playwright test`. Untuk Chromatic: publish Storybook ke chromatic.com dengan `npx chromatic --project-token=TOKEN`. Review visual diff di dashboard masing-masing tools. Approve atau reject perubahan.
