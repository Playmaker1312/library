# 537. Cara Menggunakan Playwright untuk Automated End-to-End Testing Website

## Definisi & Target
Playwright adalah framework automated testing dari Microsoft yang memungkinkan pengujian end-to-end (E2E) website di berbagai browser (Chromium, Firefox, WebKit). Playwright mendukung multiple browser, mobile emulation, dan network interception. Target: otomatisasi pengujian fungsionalitas website untuk mendeteksi regresi.

## Analogi Alur
Playwright seperti robot yang bisa mengoperasikan browser secara otomatis — robot ini bisa membuka halaman, mengklik tombol, mengisi form, dan memeriksa hasilnya. Ini seperti memiliki tester yang tidak pernah lelah dan bekerja 24/7.

## Poin-Poin Penting
- Playwright mendukung Chromium, Firefox, dan WebKit (Safari)
- Test dapat ditulis dalam JavaScript/TypeScript
- Fitur: auto-wait, network mocking, screenshot, video recording
- Playwright Test Runner terintegrasi dengan reporting
- Dapat dijalankan di CI/CD (GitHub Actions, GitLab CI)

```html
    let count = 0;
    const counter = document.getElementById('counter');
    document.getElementById('increment').addEventListener('click', () => { counter.textContent = ++count; });
    document.getElementById('decrement').addEventListener('click', () => { counter.textContent = --count; });
    document.getElementById('reset').addEventListener('click', () => { count = 0; counter.textContent = 0; });

    document.getElementById('addTodo').addEventListener('click', () => {
      const input = document.getElementById('todoInput');
      if (input.value.trim()) {
        const li = document.createElement('li');
        li.textContent = input.value;
        li.addEventListener('click', () => li.classList.toggle('completed'));
        document.getElementById('todoList').appendChild(li);
        input.value = '';
      }
    });

    document.getElementById('testForm').addEventListener('submit', (e) => {
      e.preventDefault();
      const name = document.getElementById('name').value;
      document.getElementById('result').textContent = `Hello, ${name}!`;
    });
  </script>
```

```javascript
// tests/example.spec.js - Playwright Test
const { test, expect } = require('@playwright/test');

test('counter increments correctly', async ({ page }) => {
  await page.goto('http://localhost:3000');
  const counter = page.locator('#counter');
  await expect(counter).toHaveText('0');
  await page.click('#increment');
  await expect(counter).toHaveText('1');
  await page.click('#increment');
  await expect(counter).toHaveText('2');
  await page.click('#decrement');
  await expect(counter).toHaveText('1');
  await page.click('#reset');
  await expect(counter).toHaveText('0');
});

test('todo list works', async ({ page }) => {
  await page.goto('http://localhost:3000');
  await page.fill('#todoInput', 'Belajar Playwright');
  await page.click('#addTodo');
  const todoCount = await page.locator('.todo-list li').count();
  expect(todoCount).toBe(1);
  await page.click('.todo-list li');
  await expect(page.locator('.todo-list li')).toHaveClass(/completed/);
});

test('form submission shows greeting', async ({ page }) => {
  await page.goto('http://localhost:3000');
  await page.fill('#name', 'Budi');
  await page.click('#submitBtn');
  await expect(page.locator('#result')).toHaveText('Hello, Budi!');
});
```

## Cara Integrasi
Install Playwright: `npm init playwright@latest`. Tulis test di folder `tests/`. Jalankan dengan `npx playwright test`. Integrasikan ke CI/CD dengan GitHub Actions. Gunakan Playwright UI Mode untuk debugging interaktif. Tambahkan screenshot dan video untuk test failure. Jalankan di multiple browser untuk cross-browser coverage.
