# 544. Cara Menggunakan CSS Validator untuk Memvalidasi CSS

## Definisi & Target
W3C CSS Validation Service adalah alat resmi untuk memeriksa validitas kode CSS. Validator memeriksa kepatuhan terhadap standar CSS, properti yang tidak dikenal, nilai yang salah, dan syntax error. Target: kode CSS yang valid tanpa error untuk memastikan konsistensi rendering di browser.

## Analogi Alur
CSS Validator seperti inspektur bangunan yang memeriksa cetak biru — memastikan setiap instruksi (properti) menggunakan istilah yang benar (nilai valid), tidak ada instruksi yang salah ketik (typo), dan semua perintah masuk akal (logika CSS). Cetak biru yang baik menghasilkan bangunan yang kokoh.

## Poin-Poin Penting
- Validator online: jigsaw.w3.org/css-validator
- Validasi melalui file upload, URI, atau paste CSS
- CSS valid mengurangi risiko rendering不一致 di browser berbeda
- Vendor prefix (-webkit-, -moz-) akan menghasilkan warning tapi bukan error
- Gunakan CSS linting tools (Stylelint) untuk deteksi otomatis

    document.getElementById('checkCSS').addEventListener('click', () => {
      const sheets = document.styleSheets;
      let issues = [];
      for (const sheet of sheets) {
        try {
          const rules = sheet.cssRules;
          for (const rule of rules) {
            if (rule.type === CSSRule.STYLE_RULE) {
              if (!rule.style.length) {
                issues.push(`Rule "${rule.selectorText}" has no properties`);
              }
            }
          }
        } catch (e) {
          issues.push('Cannot read stylesheet (CORS)');
        }
      }
      const output = document.getElementById('output');
      if (issues.length) {
        output.innerHTML = `<div class="invalid-section">Issues: ${issues.join(', ')}</div>`;
      } else {
        output.innerHTML = `<div class="valid-section">No obvious CSS issues detected!</div>`;
      }

```javascript
// Validasi CSS dengan Node.js
const cssValidator = require('w3c-css-validator');

async function validateCSS(cssText) {
  const result = await cssValidator.validateText(cssText);
  if (result.valid) {
    console.log('CSS is valid!');
  } else {
    result.errors.forEach(err => {
      console.error(`Line ${err.line}: ${err.message}`);
    });
  }
}

validateCSS('body { color: red; }');
```

## Cara Integrasi
Gunakan W3C CSS Validator secara online untuk validasi manual. Integrasikan Stylelint ke dalam workflow development. Tambahkan script `"lint:css": "stylelint **/*.css"` di package.json. Jalankan CSS linting di CI/CD. Target: 0 error CSS. Perhatikan warnings terkait vendor prefix dan CSS3 properties.
