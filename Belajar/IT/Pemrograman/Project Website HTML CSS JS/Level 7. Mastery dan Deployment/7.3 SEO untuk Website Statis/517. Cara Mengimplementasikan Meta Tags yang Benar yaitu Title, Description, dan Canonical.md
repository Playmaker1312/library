# 517. Cara Mengimplementasikan Meta Tags yang Benar yaitu Title, Description, dan Canonical

## Definisi & Target
Meta tags adalah snippet HTML di `<head>` yang memberikan informasi metadata tentang halaman ke mesin pencari. Title tag adalah judul halaman yang muncul di hasil pencarian. Meta description adalah ringkasan konten yang ditampilkan di SERP. Canonical tag menunjukkan URL preferensi untuk konten duplikat. Target: setiap halaman memiliki title unik, description menarik, dan canonical yang benar.

## Analogi Alur
Meta tags seperti label produk di rak toko — title adalah nama produk (judul), description adalah tagline yang menjelaskan produk (cuplikan), canonical adalah kode produk resmi (jika ada produk serupa di rak berbeda). Label yang baik membantu pembeli memilih produk.

## Poin-Poin Penting
- Title tag harus unik per halaman, 50-60 karakter, dengan keyword utama di awal
- Meta description 150-160 karakter, mengandung call-to-action dan keyword
- Canonical tag mencegah masalah konten duplikat dari URL parameter
- Setiap halaman harus memiliki tepat satu title dan satu meta description
- Gunakan Google SERP preview tools untuk melihat tampilan hasil pencarian

```javascript
// Generator meta tags untuk multiple pages
const pages = [
  {
    title: 'Belajar CSS Grid | Tutorial CSS Lengkap untuk Pemula',
    desc: 'Pelajari CSS Grid dari dasar hingga mahir. Panduan lengkap dengan contoh kode.',
    slug: 'belajar-css-grid'
  },
  {
    title: 'Cara Membuat Form HTML | Panduan Form Input Lengkap',
    desc: 'Panduan lengkap membuat form HTML dengan input, select, textarea, dan validasi.',
    slug: 'cara-membuat-form-html'
  },
  {
    title: 'JavaScript Array Methods | Map Filter Reduce Lengkap',
    desc: 'Pelajari method array JavaScript: map, filter, reduce, forEach, find, dan sort.',
    slug: 'javascript-array-methods'
  }
];

function generateMetaTag(page) {
  return `<title>${page.title}</title>
<meta name="description" content="${page.desc}">
<link rel="canonical" href="https://example.com/${page.slug}">
<meta name="robots" content="index, follow">`;
}
```

## Cara Integrasi
Tulis title tag yang unik untuk setiap halaman dengan format "Keyword Utama | Nama Situs". Tulis meta description yang menarik dengan call-to-action. Tambahkan canonical tag yang menunjuk ke URL utama. Gunakan Google Search Console untuk memonitor title dan description yang tampil di SERP. Audit meta tags menggunakan Screaming Frog atau Sitebulb.
