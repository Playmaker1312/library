# 521. Cara Membuat Robots.txt yang Benar

## Definisi & Target
Robots.txt adalah file teks yang memberitahu web crawler (Googlebot, Bingbot) halaman mana yang boleh dan tidak boleh dirayapi. File ini ditempatkan di root domain dan diakses oleh crawler sebelum merayapi halaman. Target: mengontrol akses crawler ke bagian website yang tidak perlu diindeks (halaman admin, file duplikat, halaman staging).

## Analogi Alur
Robots.txt seperti papan petunjuk di pintu masuk gedung — "Area publik: silakan masuk. Area karyawan: dilarang masuk." Petugas kebersihan (crawler) yang baik akan mematuhi petunjuk tersebut. Namun, papan ini tidak menghentikan pencuri (malicious crawler).

## Poin-Poin Penting
- File robots.txt ditempatkan di root domain: example.com/robots.txt
- Format: User-agent diikuti Disallow atau Allow
- Gunakan `Disallow: /` untuk memblokir seluruh website (hati-hati)
- Sitemap URL ditambahkan di robots.txt untuk membantu crawler
- Robots.txt tidak mencegah indexing, hanya crawling. Gunakan meta robots `noindex` untuk mencegah indexing

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```txt
# robots.txt
User-agent: *
Allow: /

# Blokir halaman admin dan internal
Disallow: /admin/
Disallow: /internal/
Disallow: /private/

# Blokir halaman dengan parameter
Disallow: /*?sort=
Disallow: /*?page=

# Blokir file tertentu
Disallow: /*.pdf$
Disallow: /*.doc$

# Blokir folder staging
Disallow: /staging/

# Izinkan crawler gambar Google
User-agent: Googlebot-Image
Allow: /images/

# Beri tahu lokasi sitemap
Sitemap: https://example.com/sitemap.xml
Sitemap: https://example.com/sitemap-articles.xml
```

```javascript
// Verifikasi robots.txt via fetch
async function checkRobotsTxt(url) {
  try {
    const response = await fetch(`${url}/robots.txt`);
    const text = await response.text();
    console.log('Robots.txt content:\n', text);
    if (text.includes('Disallow: /')) {
      console.warn('Seluruh website diblokir dari crawling!');
    }
  } catch (err) {
    console.error('Robots.txt tidak ditemukan atau error:', err);
  }
}
checkRobotsTxt('https://example.com');
```

## Cara Integrasi
Buat file `robots.txt` dan tempatkan di root folder website (sejajar dengan index.html). Izinkan crawler mengakses file CSS, JS, dan gambar. Blokir folder yang tidak perlu diindeks. Cantumkan URL sitemap.xml. Verifikasi di Google Search Console > Robots.txt Tester. Ingat: robots.txt hanya panduan, crawler yang baik akan mematuhinya.
