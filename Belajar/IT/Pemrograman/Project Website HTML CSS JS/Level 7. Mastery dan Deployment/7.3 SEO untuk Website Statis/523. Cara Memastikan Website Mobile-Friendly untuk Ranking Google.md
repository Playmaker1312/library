# 523. Cara Memastikan Website Mobile-Friendly untuk Ranking Google

## Definisi & Target
Mobile-friendly berarti website dirancang dan dioptimasi untuk perangkat mobile (ponsel, tablet). Google menggunakan mobile-first indexing, artinya Google menggunakan versi mobile website untuk ranking dan indexing. Target: website memberikan pengalaman yang optimal di semua ukuran layar, terutama mobile.

## Analogi Alur
Mobile-friendly seperti pakaian yang nyaman dipakai dalam berbagai cuaca — tidak hanya pas di badan (desktop), tapi juga nyaman saat dipakai (mobile). Google sekarang lebih memprioritaskan kenyamanan versi mobile, seperti atasan yang lebih memperhatikan penampilan saat cuaca panas.

## Poin-Poin Penting
- Gunakan viewport meta tag: `<meta name="viewport" content="width=device-width, initial-scale=1">`
- Desain responsive dengan CSS media queries
- Ukuran font minimal 16px untuk mencegah zoom otomatis di iOS
- Target sentuh minimal 48x48px untuk tombol dan link
- Hindari konten yang membutuhkan Flash atau plugin lain yang tidak didukung mobile

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Website Mobile-Friendly Demo</title>
  <style>
    * { box-sizing: border-box; margin: 0; padding: 0; }
    body { font-family: system-ui, sans-serif; line-height: 1.6; color: #333; }
    .container { max-width: 1200px; margin: 0 auto; padding: 1rem; }

    header { background: #1a73e8; color: #fff; }
    .header-inner { max-width: 1200px; margin: 0 auto; padding: 1rem; display: flex; justify-content: space-between; align-items: center; flex-wrap: wrap; gap: 1rem; }
    .logo { font-size: 1.5rem; font-weight: bold; }
    .nav-toggle { display: none; background: none; border: 2px solid #fff; color: #fff; padding: 0.5rem 1rem; border-radius: 4px; cursor: pointer; font-size: 1rem; }
    nav ul { list-style: none; display: flex; gap: 1rem; }
    nav a { color: #fff; text-decoration: none; padding: 0.5rem; }
    nav a:focus { outline: 2px solid #ffd700; }

    .grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 1.5rem; margin: 2rem 0; }
    .card { border: 2px solid #eee; border-radius: 8px; padding: 1.5rem; }
    .card h3 { margin-bottom: 0.5rem; }
    .btn { display: inline-block; padding: 0.75rem 1.5rem; background: #1a73e8; color: #fff; border: none; border-radius: 4px; cursor: pointer; font-size: 1rem; min-height: 48px; min-width: 48px; text-align: center; }

    table { width: 100%; border-collapse: collapse; margin: 1rem 0; overflow-x: auto; display: block; }
    th, td { border: 1px solid #ddd; padding: 0.75rem; text-align: left; }
    th { background: #f5f5f5; }

    img { max-width: 100%; height: auto; }

    @media (max-width: 768px) {
      .nav-toggle { display: block; }
      nav ul { display: none; flex-direction: column; width: 100%; padding: 1rem 0; }
      nav ul.open { display: flex; }
      .grid { grid-template-columns: 1fr; }
      .header-inner { flex-direction: row; }
    }

    @media (max-width: 480px) {
      .container { padding: 0.5rem; }
      .card { padding: 1rem; }
    }
  </style>
</head>
<body>
  <header>
    <div class="header-inner">
      <div class="logo">WebsiteKu</div>
      <button class="nav-toggle" id="navToggle" aria-label="Toggle navigasi">Menu</button>
      <nav id="navMenu">
        <ul>
          <li><a href="#">Beranda</a></li>
          <li><a href="#">Tentang</a></li>
          <li><a href="#">Layanan</a></li>
          <li><a href="#">Kontak</a></li>
        </ul>
      </nav>
    </div>
  </header>

  <div class="container">
    <h1>Website Mobile-Friendly</h1>
    <p>Resize browser untuk melihat perubahan layout. Target sentuh minimal 48x48px.</p>

    <div class="grid">
      <div class="card">
        <h3>Layanan 1</h3>
        <p>Deskripsi layanan yang responsive dan mobile-friendly.</p>
        <button class="btn">Detail</button>
      </div>
      <div class="card">
        <h3>Layanan 2</h3>
        <p>Tombol memiliki ukuran minimal untuk touch target.</p>
        <button class="btn">Detail</button>
      </div>
      <div class="card">
        <h3>Layanan 3</h3>
        <p>Font size 16px untuk mencegah zoom di mobile.</p>
        <button class="btn">Detail</button>
      </div>
    </div>

    <h2>Data Produk</h2>
    <table>
      <thead>
        <tr><th>Produk</th><th>Harga</th><th>Stok</th></tr>
      </thead>
      <tbody>
        <tr><td>Produk A</td><td>Rp 150.000</td><td>Tersedia</td></tr>
        <tr><td>Produk B</td><td>Rp 200.000</td><td>Habis</td></tr>
        <tr><td>Produk C</td><td>Rp 300.000</td><td>Tersedia</td></tr>
      </tbody>
    </table>
  </div>

  <script>
    document.getElementById('navToggle').addEventListener('click', function() {
      const nav = document.getElementById('navMenu').querySelector('ul');
      nav.classList.toggle('open');
      this.textContent = nav.classList.contains('open') ? 'Tutup' : 'Menu';
    });

    if ('ontouchstart' in window) {
      document.body.classList.add('touch-device');
      console.log('Perangkat touch terdeteksi');
    }
  </script>
</body>
</html>
```

## Cara Integrasi
Tambahkan viewport meta tag di `<head>`. Gunakan CSS Grid atau Flexbox untuk layout responsive. Uji dengan Google Mobile-Friendly Test (search.google.com/test/mobile-friendly). Gunakan Chrome DevTools device toolbar untuk menguji berbagai ukuran layar. Pastikan font size minimal 16px, touch target 48x48px, dan tidak ada horizontal scroll.
