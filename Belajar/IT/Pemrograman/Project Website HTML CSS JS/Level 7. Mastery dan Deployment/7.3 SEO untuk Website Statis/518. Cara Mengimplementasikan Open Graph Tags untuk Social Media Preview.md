# 518. Cara Mengimplementasikan Open Graph Tags untuk Social Media Preview

## Definisi & Target
Open Graph (OG) tags adalah meta tags yang mengontrol bagaimana halaman website ditampilkan saat dibagikan di media sosial seperti Facebook, LinkedIn, WhatsApp, dan Telegram. OG tags menentukan judul, deskripsi, gambar, dan URL yang muncul di preview card. Target: setiap halaman memiliki OG tags yang menghasilkan preview menarik dan informatif saat dibagikan.

## Analogi Alur
OG tags seperti pakaian yang Anda kenakan saat difoto — penampilan di foto (social media preview) mungkin berbeda dari penampilan sehari-hari (tampilan halaman). Anda bisa mengatur pose (gambar), pakaian (judul), dan caption (deskripsi) khusus untuk foto.

## Poin-Poin Penting
- OG tag penting: og:title, og:description, og:image, og:url, og:type
- Ukuran gambar OG ideal: 1200x630 pixels (rasio 1.91:1)
- og:type default adalah "website", bisa juga "article" atau "product"
- Facebook Debugger dan LinkedIn Post Inspector untuk validasi OG tags
- WhatsApp mengambil preview dari OG tags (cache di-refresh secara periodik)

```javascript
// Generator OG tags untuk dynamic pages
function generateOGTags(page) {
  const baseURL = 'https://example.com';
  return `
<meta property="og:title" content="${page.title}">
<meta property="og:description" content="${page.description}">
<meta property="og:image" content="${baseURL}/images/og-${page.slug}.png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:url" content="${baseURL}/${page.slug}">
<meta property="og:type" content="${page.type || 'website'}">
<meta property="og:site_name" content="Tutorial Web Dev">
<meta property="og:locale" content="id_ID">
`.trim();
}
```

## Cara Integrasi
Tambahkan OG tags di `<head>` setiap halaman. Buat gambar OG dengan ukuran 1200x630px menggunakan Canva atau Figma. Gunakan Facebook Sharing Debugger (developers.facebook.com/tools/debug/) untuk validasi. Untuk WhatsApp, gunakan WhatsApp API atau third-party tools untuk memeriksa cache. Pastikan gambar OG dapat diakses (tidak diblokir robots.txt).
