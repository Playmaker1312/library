# 519. Cara Mengimplementasikan Twitter Card Tags

## Definisi & Target
Twitter Card tags adalah meta tags khusus yang mengontrol bagaimana halaman website ditampilkan saat dibagikan di Twitter/X. Twitter Cards memiliki beberapa format: summary, summary_large_image, player, dan app. Target: tautan website menampilkan card yang menarik dengan gambar, judul, deskripsi, dan informasi akun Twitter saat dibagikan.

## Analogi Alur
Twitter Card seperti etalase toko di Twitter — saat Anda membagikan produk (link), etalase (card) menampilkan foto produk (gambar), nama toko (site), dan harga (deskripsi). Tanpa etalase, link hanya akan muncul sebagai URL mentah tanpa informasi.

## Poin-Poin Penting
- `twitter:card` — jenis card: summary_large_image (gambar besar) atau summary (gambar kecil)
- `twitter:site` — username Twitter pemilik website (@username)
- `twitter:creator` — username Twitter penulis konten (untuk artikel)
- `twitter:image` — gambar untuk card (rekomendasi 1200x630 untuk large)
- Twitter menggunakan OG tags sebagai fallback jika Twitter Card tags tidak ada

## Cara Integrasi
Pilih jenis card: `summary_large_image` untuk halaman dengan gambar besar (artikel, produk), `summary` untuk halaman biasa. Tambahkan `twitter:site` dengan username website. Jika konten memiliki penulis, tambahkan `twitter:creator`. Gunakan Twitter Card Validator (cards-dev.twitter.com/validator) untuk preview dan debugging. Gambar minimal 120x120px, maksimal 1MB untuk summary_large_image.
