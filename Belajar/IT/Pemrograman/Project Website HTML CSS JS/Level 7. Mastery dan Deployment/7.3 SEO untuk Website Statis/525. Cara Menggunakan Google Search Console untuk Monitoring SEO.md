# 525. Cara Menggunakan Google Search Console untuk Monitoring SEO

## Definisi & Target
Google Search Console (GSC) adalah alat gratis dari Google untuk memonitor dan memelihara kehadiran website di hasil pencarian. GSC memberikan data tentang performa pencarian, status indexing, masalah teknis, dan link. Target: website terdaftar di GSC dan dipantau secara rutin untuk memastikan kesehatan SEO.

## Analogi Alur
Google Search Console seperti dashboard kesehatan mobil — menampilkan performa mesin (search analytics), peringatan masalah (issues), dan riwayat servis (index coverage). Mekanik (webmaster) bisa segera tahu jika ada bagian yang bermasalah.

## Poin-Poin Penting
- Verifikasi kepemilikan domain melalui file HTML, DNS TXT record, atau Google Analytics
- Performance report: klik, impresi, CTR, dan posisi rata-rata
- URL Inspection: periksa status indexing halaman tertentu
- Coverage report: lihat halaman yang diindeks vs error
- Submit sitemap dan monitor manual actions

  const response = await fetch('https://searchconsole.googleapis.com/v1/urlTestingTools/index?siteUrl=' + siteUrl);

}

## Cara Integrasi
Daftarkan website di Google Search Console (search.google.com/search-console). Verifikasi kepemilikan melalui salah satu metode yang tersedia. Submit sitemap.xml. Pantau Performance report secara rutin (mingguan). Perbaiki error yang muncul di Coverage report. Gunakan URL Inspection tool untuk memeriksa halaman baru. Integrasikan dengan Google Analytics untuk data pengguna yang lebih lengkap.
