# 522. Cara Mengimplementasikan Structured Data menggunakan JSON-LD

## Definisi & Target
Structured data (data terstruktur) adalah format standar untuk memberikan informasi tentang halaman dan kontennya kepada mesin pencari. JSON-LD (JavaScript Object Notation for Linked Data) adalah format yang direkomendasikan Google untuk structured data. Target: halaman website memiliki markup structured data yang valid sehingga dapat ditampilkan sebagai rich snippets di hasil pencarian.

## Analogi Alur
Structured data seperti kartu identitas yang ditempel di dahi halaman — Google langsung tahu bahwa ini adalah "resep masakan" dengan "waktu masak 30 menit", bukan sekadar halaman teks biasa. Tanpa structured data, Google harus menebak jenis konten halaman.

## Poin-Poin Penting
- JSON-LD ditempatkan di tag `<script type="application/ld+json">`
- Schema.org adalah vocabulary standar untuk structured data
- Jenis umum: Article, Product, FAQPage, BreadcrumbList, LocalBusiness
- Gunakan Google Rich Results Test untuk validasi structured data
- Structured data dapat meningkatkan CTR melalui rich snippets dan knowledge panel

```javascript
// Generator structured data untuk artikel
function generateArticleLD(title, description, author, date, url) {
  return {
    '@context': 'https://schema.org',
    '@type': 'Article',
    headline: title,
    description: description,
    author: { '@type': 'Person', name: author },
    datePublished: date,
    url: url,
    publisher: {
      '@type': 'Organization',
      name: 'Nama Situs'
    }
  };
}

const articleData = generateArticleLD(
  'Belajar CSS Grid',
  'Panduan lengkap CSS Grid untuk pemula',
  'Penulis',
  '2026-05-25',
  'https://example.com/belajar-css-grid'
);
console.log(JSON.stringify(articleData));
```

## Cara Integrasi
Identifikasi jenis konten setiap halaman (Article, Product, FAQ, dll). Buat objek JSON-LD sesuai schema.org. Tempatkan di tag `<script type="application/ld+json">` di `<head>` atau `<body>`. Validasi menggunakan Google Rich Results Test (search.google.com/test/rich-results). Pantau laporan structured data di Google Search Console.
