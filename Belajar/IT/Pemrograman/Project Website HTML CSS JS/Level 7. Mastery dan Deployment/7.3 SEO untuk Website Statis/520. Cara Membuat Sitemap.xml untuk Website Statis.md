# 520. Cara Membuat Sitemap.xml untuk Website Statis

## Definisi & Target
Sitemap.xml adalah file XML yang berisi daftar semua halaman website yang ingin diindeks oleh mesin pencari. Sitemap membantu Googlebot menemukan dan merayapi halaman, terutama halaman baru atau halaman yang tidak memiliki banyak link internal. Target: semua halaman penting website terdaftar di sitemap.xml dan terindeks oleh Google.

## Analogi Alur
Sitemap.xml seperti daftar isi buku yang diberikan kepada pustakawan (Googlebot) — pustakawan langsung tahu halaman apa saja yang ada di buku tanpa harus membuka setiap halaman satu per satu. Tanpa daftar isi, beberapa halaman mungkin terlewat.

## Poin-Poin Penting
- Sitemap XML menggunakan tag `<urlset>`, `<url>`, `<loc>`, `<lastmod>`, `<changefreq>`, `<priority>`
- Maksimal 50.000 URL per sitemap file (atau 50MB uncompressed)
- Untuk website besar, gunakan sitemap index file
- Kirim sitemap ke Google Search Console dan cantumkan di robots.txt
- Sitemap harus diupdate setiap kali ada halaman baru atau perubahan

```javascript
// Sitemap generator script (Node.js)
const fs = require('fs');

const pages = [
  { url: '/', priority: 1.0, changefreq: 'weekly' },
  { url: '/tentang', priority: 0.8, changefreq: 'monthly' },
  { url: '/blog', priority: 0.9, changefreq: 'weekly' },
  { url: '/kontak', priority: 0.6, changefreq: 'monthly' },
];

function generateSitemap(baseURL, pages) {
  let xml = '<?xml version="1.0" encoding="UTF-8"?>\n';
  xml += '<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">\n';
  pages.forEach(p => {
    xml += '  <url>\n';
    xml += `    <loc>${baseURL}${p.url}</loc>\n`;
    xml += `    <lastmod>${new Date().toISOString().split('T')[0]}</lastmod>\n`;
    xml += `    <changefreq>${p.changefreq}</changefreq>\n`;
    xml += `    <priority>${p.priority}</priority>\n`;
    xml += '  </url>\n';
  });
  xml += '</urlset>';
  return xml;
}

const sitemap = generateSitemap('https://example.com', pages);
fs.writeFileSync('sitemap.xml', sitemap);
console.log('sitemap.xml generated');
```

## Cara Integrasi
Buat file `sitemap.xml` dan letakkan di root folder website (sejajar dengan index.html). Daftarkan semua halaman penting termasuk halaman utama, halaman statis, dan artikel blog. Perbarui sitemap setiap kali ada halaman baru. Kirim URL sitemap ke Google Search Console. Tambahkan referensi sitemap di `robots.txt` dengan baris `Sitemap: https://example.com/sitemap.xml`.
