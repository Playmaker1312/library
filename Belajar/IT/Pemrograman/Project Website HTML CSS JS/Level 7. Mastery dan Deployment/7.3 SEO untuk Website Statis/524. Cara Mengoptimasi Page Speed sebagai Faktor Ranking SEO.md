# 524. Cara Mengoptimasi Page Speed sebagai Faktor Ranking SEO

## Definisi & Target
Page speed (kecepatan halaman) adalah waktu yang dibutuhkan halaman website untuk dimuat sepenuhnya. Google menggunakan page speed sebagai faktor ranking sejak 2010 untuk desktop dan 2018 untuk mobile. Target: mencapai skor performa 90+ di Lighthouse dan memenuhi threshold Core Web Vitals untuk meningkatkan ranking SEO.

## Analogi Alur
Page speed seperti antrian di kasir supermarket — kasir yang lambat (website lambat) membuat pelanggan (pengunjung) pergi ke supermarket lain (website kompetitor). Google lebih merekomendasikan supermarket dengan kasir cepat.

## Poin-Poin Penting
- Google PageSpeed Insights memberikan skor dan rekomendasi spesifik
- Faktor utama: server response time, image optimization, render-blocking resources
- Gunakan compression (Gzip/Brotli), caching, dan CDN
- Minimalkan JavaScript yang memblokir rendering
- Prioritaskan konten above the fold (critical CSS, lazy loading)

## Cara Integrasi
Ukur page speed awal menggunakan Google PageSpeed Insights. Ikuti rekomendasi yang diberikan: optimasi gambar, hilangkan render-blocking resources, aktifkan compression, dan optimasi server. Gunakan Lighthouse di Chrome DevTools untuk pengukuran berulang. Monitor Core Web Vitals di Google Search Console. Target skor 90+ untuk semua metrik.
