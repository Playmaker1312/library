# 516. Memahami Dasar-Dasar SEO Teknis untuk Website HTML CSS JavaScript

## Definisi & Target
SEO (Search Engine Optimization) teknis adalah optimasi infrastruktur website untuk memudahkan mesin pencari (Google, Bing) merayapi, mengindeks, dan memahami konten. Untuk website statis HTML/CSS/JS, SEO teknis mencakup meta tags, struktur URL, kecepatan halaman, mobile-friendliness, dan data terstruktur. Target: peringkat lebih tinggi di hasil pencarian organik.

## Analogi Alur
SEO teknis seperti membuat katalog perpustakaan yang rapi — petugas (Googlebot) harus bisa menemukan buku (halaman), membaca judul (title tag), memahami kategori (heading), dan mengetahui hubungan antar buku (internal linking). Katalog yang berantakan membuat buku sulit ditemukan.

## Poin-Poin Penting
- Googlebot merayapi website melalui link internal dan sitemap.xml
- Title tag dan meta description adalah elemen paling penting untuk SERP
- Kecepatan halaman (Core Web Vitals) adalah faktor ranking sejak 2021
- URL harus bersih, deskriptif, dan menggunakan tanda hubung
- Mobile-first indexing: Google menggunakan versi mobile untuk ranking

## Cara Integrasi
Mulai dengan struktur HTML semantik. Pastikan setiap halaman memiliki title tag unik dan meta description. Buat URL yang bersih dan deskriptif. Optimasi kecepatan halaman dengan kompresi gambar dan minifikasi CSS/JS. Kirim sitemap.xml ke Google Search Console. Pastikan website mobile-friendly.
