# 551. Cara Mendokumentasikan Kode dengan JSDoc

## Definisi & Target
JSDoc adalah standar dokumentasi untuk JavaScript menggunakan komentar multi-baris. JSDoc menjelaskan fungsi, parameter, return value, dan tipe data. Tools seperti JSDoc CLI dapat generate dokumentasi HTML otomatis. Target: kode JavaScript terdokumentasi dengan baik sehingga mudah dipahami oleh developer lain.

## Analogi Alur
JSDoc seperti kartu informasi di museum — setiap patung (fungsi) memiliki kartu yang menjelaskan nama patung (nama fungsi), bahan pembuatan (parameter), dan makna artistik (return value). Pengunjung (developer) bisa memahami patung tanpa harus bertanya kurator.

## Poin-Poin Penting
- Gunakan `/** ... */` untuk komentar JSDoc
- Tag utama: `@param`, `@returns`, `@type`, `@typedef`, `@throws`
- JSDoc mendukung TypeScript type annotations
- IDE (VS Code) menampilkan JSDoc sebagai IntelliSense
- Generate dokumentasi HTML dengan `npx jsdoc ./src -d docs`

```javascript
// jsdoc.json - Konfigurasi JSDoc
{
  "source": {
    "include": ["src"],
    "includePattern": ".js$",
    "excludePattern": "(node_modules/|docs)"
  },
  "plugins": ["plugins/markdown"],
  "templates": {
    "cleverLinks": true,
    "monospaceLinks": true
  },
  "opts": {
    "destination": "./docs",
    "recurse": true,
    "readme": "README.md"
  }
}
```

// Contoh fungsi dengan JSDoc lengkap

function formatDate(date, locale = 'id-ID') {
  return new Date(date).toLocaleDateString(locale, {
    year: 'numeric', month: 'long', day: 'numeric'
  });
}

function generateSlug(text) {
  return text.toLowerCase().replace(/\s+/g, '-').replace(/[^\w-]/g, '');
}

## Cara Integrasi
Tulis JSDoc untuk setiap fungsi publik. VS Code akan menampilkan JSDoc saat hover. Generate dokumentasi HTML: `npm install jsdoc --save-dev` lalu `npx jsdoc src -d docs`. Integrasikan ke CI/CD untuk autoregenerate docs. Gunakan plugin markdown untuk dokumentasi yang lebih kaya. Konsisten dengan format JSDoc di seluruh project.
