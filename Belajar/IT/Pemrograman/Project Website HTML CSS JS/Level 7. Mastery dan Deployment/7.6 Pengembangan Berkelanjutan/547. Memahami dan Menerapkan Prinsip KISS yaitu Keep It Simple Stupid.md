# 547. Memahami dan Menerapkan Prinsip KISS yaitu Keep It Simple Stupid

## Definisi & Target
KISS (Keep It Simple, Stupid) adalah prinsip yang mendorong kesederhanaan dalam desain dan implementasi. Solusi sederhana lebih mudah dipahami, diuji, dipelihara, dan lebih sedikit bug. Target: kode yang mudah dibaca dan dipahami oleh developer lain (dan diri sendiri di masa depan).

## Analogi Alur
KISS seperti instruksi merakit furnitur IKEA — gambar sederhana dengan langkah minimal lebih efektif daripada manual 50 halaman dengan jargon teknis. Solusi sederhana lebih cepat dipahami dan lebih sedikit kesalahan.

## Poin-Poin Penting
- Solusi paling sederhana yang memenuhi requirements adalah yang terbaik
- Hindari over-engineering: jangan tambahkan kompleksitas untuk skenario masa depan yang belum pasti
- Gunakan nama variabel dan fungsi yang jelas dan deskriptif
- Satu fungsi melakukan satu hal (single responsibility)
- Kode sederhana != kode pendek. Kejelasan lebih penting dari keringkasan

    <pre>function getEvenNumbers(arr) {
  return arr.reduce((acc, curr, idx) => {
    if (curr % 2 === 0 && typeof curr === 'number' && !isNaN(curr)) {
      acc.push({ index: idx, value: curr, type: 'even' });
    }

  }, []).map(item => item.value);

    function addTodo() {
      const input = document.getElementById('todoInput');
      const text = input.value.trim();
      if (!text) return;

      const li = document.createElement('li');
      li.innerHTML = `<span>${text}</span> <button class="delete-btn">Hapus</button>`;
      li.querySelector('.delete-btn').addEventListener('click', () => li.remove());
      document.getElementById('todoList').appendChild(li);
      input.value = '';
    }

    document.getElementById('todoInput').addEventListener('keypress', (e) => {
      if (e.key === 'Enter') addTodo();
    });

## Cara Integrasi
Sebelum menulis kode, tanya: "Apakah ada cara lebih sederhana?" Gunakan code review untuk menantang kompleksitas. Prioritaskan readability. Refactor kode kompleks menjadi fungsi-fungsi kecil. Hindari premature optimization. Ikuti prinsip Unix: "Do one thing and do it well."
