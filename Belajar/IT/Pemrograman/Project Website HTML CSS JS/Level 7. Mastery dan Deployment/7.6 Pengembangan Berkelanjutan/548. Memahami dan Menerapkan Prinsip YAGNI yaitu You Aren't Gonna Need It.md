# 548. Memahami dan Menerapkan Prinsip YAGNI yaitu You Aren't Gonna Need It

## Definisi & Target
YAGNI (You Aren't Gonna Need It) adalah prinsip dari Extreme Programming yang menyatakan: jangan menambahkan fungsionalitas sampai benar-benar diperlukan. Fitur yang diprediksi akan berguna di masa depan sering kali tidak pernah digunakan atau berubah kebutuhan. Target: kode minimal yang memenuhi kebutuhan saat ini, tanpa overhead untuk skenario yang belum pasti.

## Analogi Alur
YAGNI seperti Anda pindah ke rumah baru — Anda mungkin tergoda membeli peralatan dapur lengkap "untuk jaga-jaga" (will I need a pasta maker? bread machine?), padahal Anda hanya memasak nasi dan mi instan. Beli saja saat benar-benar butuh.

## Poin-Poin Penting
- Fokus pada requirements yang ada, bukan yang mungkin akan ada
- Fitur yang tidak digunakan adalah wasted effort dan maintenance burden
- Refactor nanti saat kebutuhan benar-benar muncul
- YAGNI != tidak planning. Plan untuk perubahan, tapi tunda implementasi
- Kode lebih mudah ditambahkan daripada dihapus

    <pre>function fetchUsers() { /* ambil dari API */ }

## Cara Integrasi
Tolak godaan untuk menambahkan "fitur keren" yang tidak diminta. Tulis kode untuk kebutuhan hari ini. Jika sebuah fitur diprediksi akan diperlukan, catat di backlog, jangan diimplementasi. Saat code review, tantang setiap kode yang tidak diperlukan saat ini. Gunakan prinsip KISS bersamaan dengan YAGNI untuk kode yang sederhana dan fokus.
