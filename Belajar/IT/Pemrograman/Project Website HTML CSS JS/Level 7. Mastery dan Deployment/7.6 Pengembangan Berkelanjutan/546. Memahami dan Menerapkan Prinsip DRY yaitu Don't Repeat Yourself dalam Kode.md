# 546. Memahami dan Menerapkan Prinsip DRY yaitu Don't Repeat Yourself dalam Kode

## Definisi & Target
DRY (Don't Repeat Yourself) adalah prinsip pengembangan perangkat lunak yang menekankan pengurangan pengulangan kode. Setiap bagian pengetahuan harus memiliki representasi tunggal dalam sistem. Target: kode lebih mudah dipelihara, lebih sedikit bug, dan perubahan hanya perlu dilakukan di satu tempat.

## Analogi Alur
DRY seperti buku resep keluarga — daripada menulis resep nasi goreng di setiap halaman buku (satu buku untuk sarapan, satu untuk makan malam), Anda menulis resep sekali di satu halaman dan merujuknya dari halaman lain. Jika resep berubah, Anda hanya edit satu halaman.

## Poin-Poin Penting
- Jika Anda mengetik kode yang sama dua kali, segera refactor
- Gunakan fungsi, loop, dan komponen untuk menghindari duplikasi
- CSS: gunakan class utilities daripada mengulang properti
- HTML: buat komponen template untuk bagian yang berulang
- Jangan terlalu DRY (over-engineering) — kadang duplikasi lebih baik dari abstraksi prematur

```html
    .product-card h3 { font-size: 1.1rem; margin-bottom: 0.5rem; }

<body>
  <h1>Prinsip DRY (Don't Repeat Yourself)</h1>

  <div class="card">
    <h2>Contoh DRY: Utility Classes CSS</h2>
    <p><span class="badge badge-good">DRY</span> Gunakan class utility daripada mengulang properti:</p>
    <pre>&lt;button class="btn btn-primary"&gt;Simpan&lt;/button&gt;
&lt;button class="btn btn-danger"&gt;Hapus&lt;/button&gt;
&lt;button class="btn btn-secondary btn-small"&gt;Batal&lt;/button&gt;

.btn { display: inline-block; padding: 0.75rem 1.5rem; border-radius: 4px; }</pre>
    <button class="btn btn-primary">Simpan</button>
    <button class="btn btn-danger">Hapus</button>
    <button class="btn btn-secondary btn-small">Batal</button>
  </div>

const price2 = 25000;
const tax2 = price2 * 0.11;
const total2 = price2 + tax2;</pre>

  return price + (price * taxRate);

const total2 = calculateTotal(25000);</pre>

  <script>
    function calculateTotal(price, taxRate = 0.11) {
      return price + (price * taxRate);
    }

    function createProductCard(product) {
      const card = document.createElement('div');
      card.className = 'product-card';
      card.innerHTML = `
        <h3>${product.name}</h3>
        <div class="price">Rp ${product.price.toLocaleString()}</div>

    }

      { name: 'Produk B', price: 250000 },
      { name: 'Produk C', price: 500000 },
    ];

  </script>

```

## Cara Integrasi
Identifikasi duplikasi dalam kode dengan mencari pola berulang. Ekstrak ke fungsi, class utility, atau komponen. Gunakan CSS custom properties untuk nilai berulang. Gunakan template atau komponen untuk HTML berulang. Lakukan code review dengan fokus pada prinsip DRY. Gunakan tools seperti ESLint dengan aturan `no-duplicate` untuk mendeteksi duplikasi.
