# 553. Cara Menggunakan ESLint dan Prettier untuk Menjaga Konsistensi Kode

## Definisi & Target
ESLint adalah linter untuk JavaScript yang mendeteksi error dan pola bermasalah. Prettier adalah formatter yang memformat kode secara otomatis. Kombinasi keduanya menjaga konsistensi kode di seluruh tim. Target: semua kode mengikuti standar yang sama tanpa perlu diskusi formatting manual.

## Analogi Alur
ESLint seperti guru yang memeriksa PR (error, best practices), sedangkan Prettier seperti stylist yang merapikan penampilan (spasi, indentasi, kutip). Guru (ESLint) fokus pada isi, stylist (Prettier) fokus pada penampilan. Keduanya membuat kode lebih profesional.

## Poin-Poin Penting
- ESLint: deteksi unused variables, missing error handling, best practices
- Prettier: formatting otomatis (indentasi, quotes, trailing commas)
- Integrasi dengan VS Code: format on save, lint on save
- Konfigurasi via `.eslintrc.js` dan `.prettierrc`
- Jalankan di CI/CD untuk memvalidasi setiap PR

## Cara Integrasi
Install ESLint dan Prettier: `npm install -D eslint prettier eslint-config-prettier`. Buat file konfigurasi `.eslintrc.js` dan `.prettierrc`. Tambahkan scripts di package.json. Install ekstensi VS Code. Konfigurasi format on save. Jalankan linting di CI/CD. Untuk CSS/Style linting, tambahkan Stylelint.
