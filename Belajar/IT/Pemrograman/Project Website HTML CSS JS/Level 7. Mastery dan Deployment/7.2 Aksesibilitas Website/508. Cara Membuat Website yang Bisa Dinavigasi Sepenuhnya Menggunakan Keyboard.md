# 508. Cara Membuat Website yang Bisa Dinavigasi Sepenuhnya Menggunakan Keyboard

## Definisi & Target
Keyboard navigability berarti semua fungsionalitas website dapat diakses hanya menggunakan keyboard, tanpa mouse. Ini penting untuk pengguna dengan motor disability, power users, dan screen reader users. Target: semua elemen interaktif dapat dijangkau dan dioperasikan dengan tombol Tab, Enter, dan panah.

## Analogi Alur
Keyboard navigasi seperti bermain game tanpa mouse — Anda menggunakan tombol panah untuk bergerak, Enter untuk memilih, dan Esc untuk membatalkan. Game yang dirancang baik memungkinkan navigasi lengkap hanya dengan keyboard.

## Poin-Poin Penting
- Gunakan Tab untuk navigasi maju dan Shift+Tab untuk mundur
- Elemen interaktif native (a, button, input) sudah fokusable secara default
- Gunakan tabindex="0" untuk membuat div fokusable, hindari tabindex > 0
- Visible focus indicator wajib — jangan gunakan outline: none tanpa fallback
- Navigasi logis mengikuti urutan DOM, bukan CSS visual order

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Keyboard Navigasi Demo</title>
  <style>
    * { box-sizing: border-box; margin: 0; padding: 0; }
    body { font-family: system-ui, sans-serif; padding: 2rem; line-height: 1.6; color: #333; }
    nav { background: #f5f5f5; padding: 1rem; margin-bottom: 2rem; }
    nav ul { list-style: none; display: flex; gap: 1rem; }
    nav a { padding: 0.5rem 1rem; text-decoration: none; color: #333; border-radius: 4px; }
    nav a:focus, a:focus, button:focus, input:focus, select:focus, textarea:focus {
      outline: 3px solid #1a73e8;
      outline-offset: 2px;
    }
    .skip-link { position: absolute; top: -40px; left: 0; background: #1a73e8; color: #fff; padding: 0.5rem 1rem; z-index: 100; }
    .skip-link:focus { top: 0; }
    .card { border: 2px solid #eee; border-radius: 8px; padding: 1.5rem; margin-bottom: 1rem; }
    .card:focus-within { border-color: #1a73e8; }
    button { padding: 0.75rem 1.5rem; background: #1a73e8; color: #fff; border: none; border-radius: 4px; cursor: pointer; margin: 0.25rem; font-size: 1rem; }
    .custom-checkbox { display: flex; align-items: center; gap: 0.5rem; cursor: pointer; }
    .custom-checkbox input { width: 1.25rem; height: 1.25rem; cursor: pointer; }
    .toolbar { display: flex; gap: 0.5rem; flex-wrap: wrap; margin-bottom: 1rem; }
    [role="tablist"] { display: flex; gap: 0; border-bottom: 2px solid #ddd; }
    [role="tab"] { padding: 0.75rem 1.5rem; border: none; background: transparent; cursor: pointer; font-size: 1rem; }
    [role="tab"][aria-selected="true"] { border-bottom: 3px solid #1a73e8; font-weight: bold; }
  </style>
</head>
<body>
  <a href="#main" class="skip-link">Lompat ke konten utama</a>
  <nav aria-label="Navigasi utama">
    <ul>
      <li><a href="#beranda">Beranda</a></li>
      <li><a href="#tentang">Tentang</a></li>
      <li><a href="#layanan">Layanan</a></li>
      <li><a href="#kontak">Kontak</a></li>
    </ul>
  </nav>
  <main id="main">
    <h1>Navigasi Keyboard</h1>
    <p>Tekan Tab untuk navigasi, Enter untuk aktivasi. Focus indicator visible.</p>
    <section aria-labelledby="form-heading">
      <h2 id="form-heading">Formulir Demo</h2>
      <form>
        <label for="nama">Nama:</label>
        <input type="text" id="nama" name="nama">
        <label for="email">Email:</label>
        <input type="email" id="email" name="email">
        <button type="submit">Kirim</button>
        <button type="reset">Reset</button>
      </form>
    </section>
    <section aria-labelledby="tab-heading">
      <h2 id="tab-heading">Tab Panel (Keyboard dengan Arrow Keys)</h2>
      <div role="tablist" aria-label="Panel informasi">
        <button role="tab" aria-selected="true" aria-controls="panel1" tabindex="0">Tab 1</button>
        <button role="tab" aria-selected="false" aria-controls="panel2" tabindex="-1">Tab 2</button>
        <button role="tab" aria-selected="false" aria-controls="panel3" tabindex="-1">Tab 3</button>
      </div>
      <div role="tabpanel" id="panel1">Konten Tab 1</div>
      <div role="tabpanel" id="panel2" hidden>Konten Tab 2</div>
      <div role="tabpanel" id="panel3" hidden>Konten Tab 3</div>
    </section>
  </main>
  <script>
    const tabs = document.querySelectorAll('[role="tab"]');
    tabs.forEach((tab, index) => {
      tab.addEventListener('keydown', (e) => {
        let target;
        if (e.key === 'ArrowRight') {
          target = tabs[(index + 1) % tabs.length];
        } else if (e.key === 'ArrowLeft') {
          target = tabs[(index - 1 + tabs.length) % tabs.length];
        }
        if (target) {
          tabs.forEach(t => { t.setAttribute('aria-selected', 'false'); t.tabIndex = -1; });
          target.setAttribute('aria-selected', 'true');
          target.tabIndex = 0;
          target.focus();
        }
      });
    });
  </script>
</body>
</html>
```

## Cara Integrasi
Navigasi seluruh website hanya menggunakan keyboard untuk memastikan semua elemen dapat dijangkau. Pastikan visible focus indicator pada semua elemen interaktif. Gunakan urutan DOM yang logis. Sediakan skip link untuk melompat ke konten utama. Uji dengan Tab, Shift+Tab, Enter, Esc, dan Arrow keys.
