# 512. Cara Menggunakan Heading Hierarchy yang Benar untuk Screen Reader

## Definisi & Target
Heading hierarchy adalah struktur judul dari h1 hingga h6 yang membangun outline konten. Screen reader pengguna menavigasi halaman dengan melompat antar heading. Target: struktur heading yang logis dan hirarkis sehingga outline halaman dapat dipahami tanpa melihat tampilan visual.

## Analogi Alur
Heading hierarchy seperti daftar isi buku — Bab 1 (h1), sub-bab 1.1 (h2), sub-sub-bab 1.1.1 (h3). Pembaca dapat melihat struktur buku dan langsung melompat ke bagian yang diinginkan. Heading yang tidak teratur seperti buku yang sub-bab muncul sebelum bab — membingungkan.

## Poin-Poin Penting
- Satu h1 per halaman (boleh lebih, tapi direkomendasikan satu)
- Jangan melompat level heading (h1 langsung h3, atau h2 langsung h4)
- Heading harus deskriptif dan mencerminkan konten di bawahnya
- Gunakan heading untuk struktur, bukan untuk styling (jangan <h2> hanya karena ingin font besar)
- Screen reader navigation: daftar heading (shortcut H atau D pada NVDA/VoiceOver)

```html
  <h2>Pendahuluan</h2>
  <p>Heading adalah elemen HTML dari h1 sampai h6 yang digunakan untuk membuat struktur konten. Screen reader pengguna menggunakan heading untuk menavigasi halaman dengan cepat.</p>

  <h2>Aturan Dasar Heading</h2>
  <h3>Urutan Hirarkis</h3>
  <p>Heading harus mengikuti urutan logis: h1 diikuti h2, h2 diikuti h3, dan seterusnya. Jangan melompat level.</p>
  <h3>Satu H1 per Halaman</h3>

  <p>Heading harus menjelaskan konten di bawahnya secara jelas dan ringkas.</p>

  <h3>Navigasi Screen Reader</h3>
  <p>Pengguna NVDA tekan H untuk navigasi heading. VoiceOver gunakan rotor (VoiceOver + U).</p>
  <h3>Styling Tanpa Heading</h3>
  <p>Gunakan CSS untuk styling visual, jangan gunakan heading hanya karena tampilannya besar dan tebal.</p>
  <h4>Mengubah Tampilan Heading</h4>
  <p>Anda bisa mengubah tampilan heading dengan CSS tanpa mengubah level heading.</p>

  <p>Gunakan bookmarklet HTML_CodeSniffer untuk memeriksa heading.</p>

  <script>
    function checkHeadingHierarchy() {
      const headings = document.querySelectorAll('h1, h2, h3, h4, h5, h6');
      let lastLevel = 0;
      let issues = [];
      headings.forEach(h => {
        const level = parseInt(h.tagName[1]);
        if (level - lastLevel > 1) {
          issues.push(`Melompat dari h${lastLevel} ke h${level}: "${h.textContent.trim()}"`);
        }
        lastLevel = level;
      });
      return issues;
    }
    const issues = checkHeadingHierarchy();
    if (issues.length > 0) {
      console.warn('Heading hierarchy issues:', issues);
    } else {
      console.log('Heading hierarchy OK');
    }
  </script>
</body>
</html>
```

## Cara Integrasi
Mulai setiap halaman dengan satu `<h1>`. Selanjutnya gunakan `<h2>` untuk bagian utama, `<h3>` untuk sub-bagian, dan seterusnya. Jangan melompat level heading. Gunakan ekstensi browser HeadingsMap untuk memverifikasi struktur heading. Navigasi halaman menggunakan screen reader untuk memastikan outline logis.
