# 506. Memahami Standar Aksesibilitas WCAG 2.1 dan Level A, AA, dan AAA

## Definisi & Target
WCAG (Web Content Accessibility Guidelines) 2.1 adalah standar internasional untuk aksesibilitas web yang dikembangkan oleh W3C. Terdapat tiga level kepatuhan: A (minimum), AA (standar yang direkomendasikan), dan AAA (tingkat tertinggi). Target: mencapai level AA untuk memenuhi standar hukum dan inklusivitas.

## Analogi Alur
WCAG seperti peraturan bangunan universal — Level A seperti ramp untuk kursi roda (dasar), Level AA seperti toilet aksesibel dan pintu lebar (standar), Level AAA seperti guiding block untuk tunanetra (optimal). Sebagian besar gedung umum target Level AA.

## Poin-Poin Penting
- Empat prinsip WCAG: Perceivable, Operable, Understandable, Robust (POUR)
- Level A mencakup 30 kriteria success dasar minimal
- Level AA mencakup 50 kriteria, wajib untuk kepatuhan hukum di banyak negara
- Level AAA mencakup 28 kriteria tambahan, tidak selalu bisa diterapkan
- WCAG 2.2 (rilis 2023) menambahkan kriteria baru untuk accessibility

```html
    body { font-family: system-ui, sans-serif; line-height: 1.6; color: #333; background: #fff; padding: 2rem; }

    .btn { display: inline-block; padding: 0.75rem 1.5rem; background: #1a73e8; color: #fff; border: none; border-radius: 4px; cursor: pointer; font-size: 1rem; }
    .btn:focus { outline: 3px solid #ffd700; outline-offset: 2px; }

  </footer>

</html>
```

## Cara Integrasi
Gunakan WCAG 2.1 sebagai checklist saat membangun website. Prioritaskan level AA sebagai target minimum. Gunakan tools otomatis seperti axe DevTools untuk deteksi awal, lalu lakukan manual testing dengan screen reader. Dokumentasikan tingkat kepatuhan di halaman accessibility statement website.
