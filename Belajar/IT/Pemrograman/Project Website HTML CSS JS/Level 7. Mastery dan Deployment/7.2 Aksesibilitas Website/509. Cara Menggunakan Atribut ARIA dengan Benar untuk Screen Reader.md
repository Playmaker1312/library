# 509. Cara Menggunakan Atribut ARIA dengan Benar untuk Screen Reader

## Definisi & Target
ARIA (Accessible Rich Internet Applications) adalah atribut HTML untuk meningkatkan aksesibilitas elemen dinamis dan komponen UI kompleks. ARIA membantu screen reader memahami peran, state, dan properti elemen. Target: pengguna screen reader mendapatkan informasi yang setara dengan pengguna visual.

## Analogi Alur
ARIA seperti label dan petunjuk pada kotak kardus yang dikirim — bukan bagian dari isi, tapi memberi tahu apa isinya (role), apakah sudah dibuka (state), dan properti lainnya. Tanpa label, penerima harus membuka kotak untuk tahu isinya.

## Poin-Poin Penting
- Aturan emas ARIA: jangan gunakan ARIA jika elemen HTML native sudah memiliki semantik tersebut
- Role: navigasi, button, dialog, alert, tabpanel, dll
- Properties: aria-label, aria-describedby, aria-labelledby
- States: aria-expanded, aria-hidden, aria-selected, aria-disabled, aria-pressed
- ARIA tidak mengubah tampilan visual, hanya semantik untuk assistive technology

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>ARIA Attributes Demo</title>
  <style>
    * { box-sizing: border-box; margin: 0; padding: 0; }
    body { font-family: system-ui, sans-serif; padding: 2rem; color: #333; line-height: 1.6; }
    button { padding: 0.5rem 1rem; cursor: pointer; font-size: 1rem; }
    .accordion { max-width: 600px; margin: 1rem 0; }
    .accordion-header { background: #f5f5f5; padding: 0; }
    .accordion-trigger { width: 100%; text-align: left; padding: 1rem; background: none; border: 2px solid #ddd; border-radius: 4px; display: flex; justify-content: space-between; align-items: center; }
    .accordion-trigger[aria-expanded="true"] { background: #e3f2fd; }
    .accordion-content { padding: 1rem; border: 2px solid #ddd; border-top: none; border-radius: 0 0 4px 4px; }
    .sr-only { position: absolute; width: 1px; height: 1px; padding: 0; margin: -1px; overflow: hidden; clip: rect(0,0,0,0); border: 0; }
    .progress-bar { width: 100%; height: 24px; background: #eee; border-radius: 12px; margin: 1rem 0; overflow: hidden; }
    .progress-fill { height: 100%; background: #1a73e8; transition: width 0.3s; }
    .modal-overlay { display: none; position: fixed; top: 0; left: 0; width: 100%; height: 100%; background: rgba(0,0,0,0.5); z-index: 1000; }
    .modal-overlay.active { display: flex; align-items: center; justify-content: center; }
    .modal-content { background: #fff; padding: 2rem; border-radius: 8px; max-width: 500px; width: 90%; }
  </style>
</head>
<body>
  <h1>ARIA Attributes</h1>

  <section aria-labelledby="accordion-heading">
    <h2 id="accordion-heading">Accordion dengan ARIA</h2>
    <div class="accordion">
      <h3 class="accordion-header">
        <button class="accordion-trigger" aria-expanded="false" aria-controls="content1" id="trigger1">
          Panel 1
          <span aria-hidden="true">&#9660;</span>
        </button>
      </h3>
      <div class="accordion-content" id="content1" role="region" aria-labelledby="trigger1" hidden>
        Konten panel pertama. ARIA membantu screen reader memahami hubungan trigger dan konten.
      </div>
    </div>
  </section>

  <section aria-labelledby="progress-heading">
    <h2 id="progress-heading">Progress Bar dengan ARIA</h2>
    <div class="progress-bar" role="progressbar" aria-valuenow="60" aria-valuemin="0" aria-valuemax="100" aria-label="Progress artikel">
      <div class="progress-fill" style="width: 60%;"></div>
    </div>
  </section>

  <button id="modalBtn" aria-haspopup="dialog">Buka Modal</button>
  <div class="modal-overlay" id="modal" role="dialog" aria-modal="true" aria-labelledby="modal-title" aria-hidden="true">
    <div class="modal-content">
      <h2 id="modal-title">Konfirmasi</h2>
      <p>Apakah Anda yakin ingin melanjutkan?</p>
      <button id="closeModal">Ya, Lanjutkan</button>
      <button id="cancelModal">Batal</button>
    </div>
  </div>

  <script>
    document.querySelector('.accordion-trigger').addEventListener('click', function() {
      const expanded = this.getAttribute('aria-expanded') === 'true';
      this.setAttribute('aria-expanded', !expanded);
      document.getElementById('content1').hidden = expanded;
    });

    document.getElementById('modalBtn').addEventListener('click', () => {
      const modal = document.getElementById('modal');
      modal.setAttribute('aria-hidden', 'false');
      modal.classList.add('active');
    });

    document.getElementById('closeModal').addEventListener('click', closeModal);
    document.getElementById('cancelModal').addEventListener('click', closeModal);
    function closeModal() {
      const modal = document.getElementById('modal');
      modal.setAttribute('aria-hidden', 'true');
      modal.classList.remove('active');
    }
  </script>
</body>
</html>
```

## Cara Integrasi
Gunakan HTML native semantic elements terlebih dahulu (<nav>, <button>, <header>, <main>). Tambahkan ARIA hanya saat membuat komponen kustom yang tidak memiliki padanan HTML. Uji dengan screen reader untuk memastikan ARIA diinterpretasikan dengan benar. Ikuti WAI-ARIA Authoring Practices untuk pola komponen umum.
