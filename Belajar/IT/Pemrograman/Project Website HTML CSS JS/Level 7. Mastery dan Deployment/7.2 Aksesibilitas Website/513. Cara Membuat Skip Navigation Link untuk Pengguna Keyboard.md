# 513. Cara Membuat Skip Navigation Link untuk Pengguna Keyboard

## Definisi & Target
Skip navigation link adalah tautan yang memungkinkan pengguna keyboard dan screen reader melompati blok navigasi berulang dan langsung ke konten utama. Link ini biasanya tersembunyi secara visual dan muncul saat mendapat fokus keyboard. Target: pengguna tidak perlu menekan Tab puluhan kali setiap halaman untuk mencapai konten utama.

## Analogi Alur
Skip navigation seperti pintu VIP di stadion — daripada mengantri di pintu utama bersama semua orang (men-Tab melalui semua navigasi), pengguna dengan kebutuhan khusus bisa langsung masuk ke area utama. Pintu ini tidak terlihat oleh pengunjung biasa yang menggunakan pintu utama.

## Poin-Poin Penting
- Skip link ditempatkan sebagai elemen pertama di `<body>`
- Link harus terlihat saat menerima fokus keyboard (jangan `display: none`)
- Target anchor adalah `<main id="main-content">` atau `id` serupa
- Secara visual, skip link muncul di bagian atas halaman saat di-focus
- Skip link standar: "Lompat ke konten utama" atau "Skip to main content"

```html

      position: absolute;
      top: -100px;
      left: 0;
      z-index: 1000;
      background: #1a73e8;
      color: #fff;
      padding: 0.75rem 1.5rem;
      text-decoration: none;
      font-weight: bold;
      font-size: 1rem;
      transition: top 0.1s;
    }
    .skip-link:focus {
      top: 0;
      outline: 3px solid #ffd700;
    }
    header { background: #f5f5f5; padding: 2rem; }
    nav { background: #333; }
    nav ul { list-style: none; display: flex; gap: 0; }
    nav a {
      display: block;
      padding: 1rem 1.5rem;
      color: #fff;
      text-decoration: none;
    }
    nav a:focus { background: #555; outline: 2px solid #ffd700; }
    main { padding: 2rem; max-width: 800px; }
    .card { border: 2px solid #eee; border-radius: 8px; padding: 1.5rem; margin-bottom: 1rem; }
    .long-nav { background: #f0f0f0; padding: 1rem; margin: 1rem 0; }
    .long-nav a { display: block; padding: 0.5rem; color: #1a73e8; margin-bottom: 0.25rem; }
    button { padding: 0.75rem 1.5rem; background: #1a73e8; color: #fff; border: none; border-radius: 4px; cursor: pointer; margin-top: 1rem; }
    footer { background: #333; color: #fff; padding: 2rem; margin-top: 2rem; }
  </style>
</head>
<body>
  <a href="#main-content" class="skip-link">Lompat ke konten utama</a>

  <header>
    <h1>Skip Navigation Demo</h1>
    <p>Tekan Tab setelah halaman dimuat untuk melihat skip link.</p>
  </header>

  <nav aria-label="Navigasi utama">
    <ul>
      <li><a href="#">Beranda</a></li>
      <li><a href="#">Tentang Kami</a></li>

      <li><a href="#">Portofolio</a></li>
      <li><a href="#">Blog</a></li>
      <li><a href="#">Testimoni</a></li>
      <li><a href="#">FAQ</a></li>
      <li><a href="#">Kontak</a></li>
    </ul>
  </nav>

  <div class="long-nav">
    <h2>Navigasi Tambahan (Sidebar)</h2>
    <a href="#">Artikel Terbaru: Cara Membuat Website</a>
    <a href="#">Artikel Terbaru: Optimasi SEO</a>

    <a href="#">Artikel Terbaru: Desain Responsif</a>
    <a href="#">Artikel Terbaru: Performa Website</a>

    <a href="#">Kategori: CSS</a>
    <a href="#">Kategori: JavaScript</a>
    <a href="#">Kategori: Tools</a>
  </div>

  <main id="main-content">
    <h2>Konten Utama</h2>
    <div class="card">
      <h3>Selamat Datang!</h3>
      <p>Jika Anda menggunakan skip link, Anda langsung melompat ke sini tanpa melewati navigasi yang panjang. Coba tekan Tab beberapa kali dari awal halaman untuk melihat skip link muncul, lalu tekan Enter.</p>
      <button id="focusBtn">Fokus tombol ini dari skip link</button>
    </div>
    <div class="card">
      <h3>Mengapa Skip Link Penting?</h3>
      <p>Pengguna keyboard dan screen reader menghemat waktu dengan melompati navigasi berulang. Ini adalah kriteria WCAG 2.4.1 (Level A).</p>

  </main>

  <footer>
    <p>&copy; 2026 Skip Navigation Demo</p>
  </footer>

  <script>
    document.getElementById('focusBtn').addEventListener('click', () => {
      alert('Skip link berhasil!');
    });
    document.addEventListener('keydown', (e) => {
      if (e.key === 'Tab') {
        const skip = document.querySelector('.skip-link');
        if (document.activeElement === skip) {
          console.log('Skip link menerima fokus');
        }
      }
    });
  </script>
</body>
</html>
```

## Cara Integrasi
Tambahkan `<a href="#main-content" class="skip-link">Lompat ke konten utama</a>` sebagai elemen pertama setelah `<body>`. Tambahkan `id="main-content"` pada elemen `<main>`. Styling: posisi absolut di luar layar, muncul saat `:focus`. Uji dengan menekan Tab setelah halaman dimuat untuk memastikan skip link muncul dan berfungsi.
