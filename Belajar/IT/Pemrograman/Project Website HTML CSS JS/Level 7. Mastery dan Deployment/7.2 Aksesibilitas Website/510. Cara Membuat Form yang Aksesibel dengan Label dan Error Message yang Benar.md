# 510. Cara Membuat Form yang Aksesibel dengan Label dan Error Message yang Benar

## Definisi & Target
Form aksesibel memastikan semua pengguna, termasuk pengguna screen reader, dapat mengisi dan mengirimkan form dengan sukses. Setiap input harus memiliki label yang terasosiasi secara programatis, error message yang jelas, dan instruksi yang mudah dipahami. Target: semua elemen form dapat dioperasikan dengan keyboard dan dipahami melalui screen reader.

## Analogi Alur
Form aksesibel seperti formulir kertas dengan petunjuk jelas — setiap kotak isian memiliki label tempel (label), ada tanda bintang untuk wajib diisi (required), dan ada stiker merah jika ada kesalahan (error message). Petugas (screen reader) dapat membacakan setiap bagian dengan jelas.

## Poin-Poin Penting
- Setiap input harus memiliki `<label>` yang terasosiasi dengan atribut `for`
- Gunakan `aria-required="true"` dan `required` untuk field wajib
- Error message dihubungkan ke input menggunakan `aria-describedby` atau `aria-errormessage`
- Gunakan `aria-invalid="true"` pada input yang error
- Grouping dengan `<fieldset>` dan `<legend>` untuk opsi terkait

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Form Aksesibel Demo</title>
  <style>
    * { box-sizing: border-box; margin: 0; padding: 0; }
    body { font-family: system-ui, sans-serif; padding: 2rem; line-height: 1.6; color: #333; }
    form { max-width: 600px; margin: 0 auto; }
    .form-group { margin-bottom: 1.5rem; }
    label { display: block; margin-bottom: 0.25rem; font-weight: 600; }
    .required { color: #d32f2f; margin-left: 2px; }
    input, select, textarea { width: 100%; padding: 0.75rem; border: 2px solid #ddd; border-radius: 4px; font-size: 1rem; }
    input:focus, select:focus, textarea:focus { outline: 3px solid #1a73e8; outline-offset: 2px; border-color: #1a73e8; }
    input[aria-invalid="true"] { border-color: #d32f2f; }
    .error-message { color: #d32f2f; font-size: 0.875rem; margin-top: 0.25rem; display: none; }
    .error-message.visible { display: block; }
    .hint { color: #666; font-size: 0.875rem; margin-top: 0.25rem; }
    button { padding: 0.75rem 1.5rem; background: #1a73e8; color: #fff; border: none; border-radius: 4px; cursor: pointer; font-size: 1rem; }
    button:focus { outline: 3px solid #ffd700; outline-offset: 2px; }
    fieldset { border: 2px solid #ddd; border-radius: 4px; padding: 1rem; margin-bottom: 1.5rem; }
    legend { font-weight: 600; padding: 0 0.5rem; }
    .radio-group { display: flex; gap: 1rem; }
    .radio-group label { font-weight: normal; display: inline; }
    .sr-only { position: absolute; width: 1px; height: 1px; padding: 0; margin: -1px; overflow: hidden; clip: rect(0,0,0,0); border: 0; }
  </style>
</head>
<body>
  <h1>Form Aksesibel</h1>
  <form id="contactForm" novalidate aria-label="Formulir kontak">
    <div class="form-group">
      <label for="nama">Nama Lengkap <span class="required" aria-hidden="true">*</span></label>
      <input type="text" id="nama" name="nama" required aria-required="true" aria-describedby="nama-hint" aria-errormessage="nama-error">
      <div id="nama-hint" class="hint">Masukkan nama lengkap Anda</div>
      <div id="nama-error" class="error-message" role="alert">Nama lengkap wajib diisi</div>
    </div>
    <div class="form-group">
      <label for="email">Email <span class="required" aria-hidden="true">*</span></label>
      <input type="email" id="email" name="email" required aria-required="true" aria-errormessage="email-error">
      <div id="email-error" class="error-message" role="alert">Email tidak valid</div>
    </div>
    <div class="form-group">
      <label for="telepon">Nomor Telepon</label>
      <input type="tel" id="telepon" name="telepon" aria-describedby="telepon-hint">
      <div id="telepon-hint" class="hint">Format: 0812-3456-7890</div>
    </div>
    <fieldset>
      <legend>Jenis Kelamin</legend>
      <div class="radio-group">
        <input type="radio" id="pria" name="jenis_kelamin" value="pria">
        <label for="pria">Pria</label>
        <input type="radio" id="wanita" name="jenis_kelamin" value="wanita">
        <label for="wanita">Wanita</label>
      </div>
    </fieldset>
    <div class="form-group">
      <label for="pesan">Pesan <span class="required" aria-hidden="true">*</span></label>
      <textarea id="pesan" name="pesan" rows="4" required aria-required="true" aria-errormessage="pesan-error"></textarea>
      <div id="pesan-error" class="error-message" role="alert">Pesan wajib diisi</div>
    </div>
    <button type="submit">Kirim Pesan</button>
  </form>
  <script>
    document.getElementById('contactForm').addEventListener('submit', function(e) {
      e.preventDefault();
      const fields = [
        { id: 'nama', errorId: 'nama-error' },
        { id: 'email', errorId: 'email-error' },
        { id: 'pesan', errorId: 'pesan-error' }
      ];
      let valid = true;
      fields.forEach(f => {
        const input = document.getElementById(f.id);
        const error = document.getElementById(f.errorId);
        if (!input.value.trim()) {
          input.setAttribute('aria-invalid', 'true');
          error.classList.add('visible');
          valid = false;
        } else {
          input.setAttribute('aria-invalid', 'false');
          error.classList.remove('visible');
        }
      });
      if (valid) {
        alert('Form berhasil dikirim!');
      } else {
        const firstError = document.querySelector('[aria-invalid="true"]');
        if (firstError) firstError.focus();
      }
    });
  </script>
</body>
</html>
```

## Cara Integrasi
Pastikan setiap input memiliki `<label>` dengan atribut `for` yang sesuai. Tambahkan `aria-required` dan `required` pada field wajib. Sediakan error message yang terhubung dengan `aria-describedby`. Saat validasi, set `aria-invalid` dan fokus ke field error pertama. Gunakan `<fieldset>` dan `<legend>` untuk grup radio/checkbox.
