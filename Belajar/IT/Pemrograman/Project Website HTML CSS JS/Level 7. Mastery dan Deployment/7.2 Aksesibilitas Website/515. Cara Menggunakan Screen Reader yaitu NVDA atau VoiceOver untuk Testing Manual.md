# 515. Cara Menggunakan Screen Reader yaitu NVDA atau VoiceOver untuk Testing Manual

## Definisi & Target
Screen reader adalah software yang membacakan konten layar menggunakan suara sintetis. NVDA (NonVisual Desktop Access) gratis untuk Windows, sedangkan VoiceOver sudah terintegrasi di macOS dan iOS. Testing manual dengan screen reader diperlukan untuk memvalidasi pengalaman pengguna dengan disabilitas visual. Target: memastikan konten dan interaksi dapat diakses melalui screen reader.

## Analogi Alur
Screen reader seperti pembaca berita yang membacakan koran dengan suara lantang. Pengguna mendengarkan dan menavigasi dengan perintah keyboard — seperti meminta pembaca melompat ke bagian "Olahraga" (heading), membaca paragraf tertentu, atau mendaftar semua gambar dan deskripsinya.

## Poin-Poin Penting
- NVDA shortcut: H untuk heading, B untuk button, L untuk list, D untuk landmark
- VoiceOver: VO+U untuk rotor, VO+Arrow untuk navigasi item
- Uji navigasi dasar: Tab, Arrow, H, B, D dengan screen reader aktif
- Pastikan urutan pembacaan logis sesuai urutan DOM
- Screen reader testing mengungkap masalah yang tidak terdeteksi tools otomatis

## Cara Integrasi
Aktifkan NVDA (Windows) dengan shortcut Ctrl+Alt+N. Navigasi halaman dengan tombol panah untuk membaca baris per baris. Gunakan H untuk heading, B untuk button, D untuk landmark. Di macOS, aktifkan VoiceOver dengan Cmd+F5. Gunakan rotor (VO+U) untuk navigasi cepat. Dokumentasikan masalah yang ditemukan dan perbaiki sebelum deployment.
