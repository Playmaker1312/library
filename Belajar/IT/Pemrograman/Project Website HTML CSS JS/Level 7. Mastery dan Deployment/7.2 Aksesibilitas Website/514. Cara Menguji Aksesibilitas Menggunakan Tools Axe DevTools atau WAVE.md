# 514. Cara Menguji Aksesibilitas Menggunakan Tools Axe DevTools atau WAVE

## Definisi & Target
Axe DevTools dan WAVE adalah alat pengujian aksesibilitas otomatis yang berjalan di browser. Axe (dari Deque Systems) mendeteksi masalah aksesibilitas berdasarkan aturan WCAG. WAVE (dari WebAIM) menampilkan overlay visual dari struktur dan issues aksesibilitas. Target: mengidentifikasi dan memperbaiki pelanggaran aksesibilitas secara sistematis.

## Analogi Alur
Axe/WAVE seperti detektor logam di bandara — mendeteksi potensi masalah tanpa perlu membuka semua koper. Namun, detektor ini tidak bisa menangkap semua masalah (false negative), sehingga tetap perlu pemeriksaan manual (body search) untuk hasil akurat.

## Poin-Poin Penting
- Axe DevTools tersedia sebagai ekstensi Chrome, Firefox, dan Edge
- WAVE tersedia sebagai ekstensi Chrome dan Firefox
- Axe juga tersedia sebagai library Node.js untuk otomatisasi testing
- Axe memberikan kode pelanggaran unik yang dapat dilacak
- Tools otomatis hanya mendeteksi ~30% dari total masalah aksesibilitas

```javascript
// axe-core untuk automated testing (Node.js)
const { AxeBuilder } = require('@axe-core/playwright');
const { chromium } = require('playwright');

async function runAxeTest() {
  const browser = await chromium.launch();
  const page = await browser.newPage();
  await page.goto('https://example.com');

  const results = await new AxeBuilder({ page }).analyze();

  console.log(`Violations found: ${results.violations.length}`);
  results.violations.forEach(v => {
    console.log(`- ${v.id}: ${v.help}`);
    console.log(`  Impact: ${v.impact}`);
    console.log(`  Nodes: ${v.nodes.length}`);
  });

  await browser.close();
}

runAxeTest();
```

## Cara Integrasi
Install ekstensi Axe DevTools atau WAVE dari Chrome Web Store. Buka halaman yang akan diuji, klik ikon ekstensi, dan jalankan audit. Tinjau setiap pelanggaran yang dilaporkan, baca dokumentasi untuk solusi. Perbaiki kode HTML sesuai rekomendasi. Ulangi audit untuk memastikan perbaikan. Integrasikan axe-core ke dalam test suite dengan Playwright atau Cypress.
