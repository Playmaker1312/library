# 507. Cara Memastikan Warna Memiliki Kontras yang Cukup Menggunakan Tools

## Definisi & Target
Rasio kontras warna mengukur perbedaan luminance antara teks dan latar belakang. WCAG 2.1 mensyaratkan rasio kontras minimal 4.5:1 untuk teks normal dan 3:1 untuk teks besar (18px+ bold atau 24px+ regular). Target: semua teks memenuhi rasio kontras minimum untuk aksesibilitas pengguna dengan low vision.

## Analogi Alur
Kontras warna seperti tulisan di papan tulis — kapur putih di papan hitam jelas terbaca (kontras tinggi), sedangkan kapur abu-abu di papan abu-abu sulit dibaca (kontras rendah). Tools kontras seperti light meter yang memastikan pencahayaan cukup.

## Poin-Poin Penting
- Tools populer: WebAIM Contrast Checker, Colorable, Stark (Figma plugin)
- Chrome DevTools memiliki warna picker yang menampilkan rasio kontras langsung
- Jangan hanya andalkan warna untuk menyampaikan informasi (sertakan ikon atau label)
- Pertimbangkan juga color blindness (buta warna) — jangan hanya gunakan merah/hijau
- Mode high contrast pada OS dapat membantu pengguna dengan kebutuhan khusus

    function getContrastRatio(hex1, hex2) {
      const lum1 = getLuminance(hex1);
      const lum2 = getLuminance(hex2);
      const lighter = Math.max(lum1, lum2);
      const darker = Math.min(lum1, lum2);
      return ((lighter + 0.05) / (darker + 0.05)).toFixed(1);
    }
    function getLuminance(hex) {
      let r = parseInt(hex.slice(1, 3), 16) / 255;
      let g = parseInt(hex.slice(3, 5), 16) / 255;
      let b = parseInt(hex.slice(5, 7), 16) / 255;
      r = r <= 0.03928 ? r / 12.92 : Math.pow((r + 0.055) / 1.055, 2.4);
      g = g <= 0.03928 ? g / 12.92 : Math.pow((g + 0.055) / 1.055, 2.4);
      b = b <= 0.03928 ? b / 12.92 : Math.pow((b + 0.055) / 1.055, 2.4);
      return 0.2126 * r + 0.7152 * g + 0.0722 * b;
    }
    console.log('Contrast ratio #333 on #fff:', getContrastRatio('#333', '#fff'));

## Cara Integrasi
Gunakan WebAIM Contrast Checker (webaim.org/resources/contrastchecker/) selama desain. Di Chrome DevTools, inspect elemen teks, buka color picker, dan periksa rasio kontras yang ditampilkan. Pastikan semua teks memenuhi rasio 4.5:1 untuk AA. Gunakan tools seperti Stark di Figma untuk memeriksa kontras saat mendesain.
