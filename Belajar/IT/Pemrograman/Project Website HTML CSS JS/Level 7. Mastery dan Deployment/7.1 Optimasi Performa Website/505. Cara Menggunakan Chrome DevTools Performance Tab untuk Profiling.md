# 505. Cara Menggunakan Chrome DevTools Performance Tab untuk Profiling

## Definisi & Target
Performance tab di Chrome DevTools adalah alat profiling untuk merekam dan menganalisis aktivitas runtime website. Fitur ini menampilkan timeline detail termasuk JavaScript execution, rendering, painting, dan layout. Target: mengidentifikasi bottleneck performa, long tasks, layout thrashing, dan JavaScript yang lambat.

## Analogi Alur
Performance tab seperti dashboard mobil balap yang menampilkan RPM, kecepatan, suhu mesin, dan tekanan ban secara real-time. Mekanik (developer) dapat menganalisis data ini untuk mengetahui bagian mana yang perlu di-tuning.

## Poin-Poin Penting
- Rekam performa dengan tombol record, lalu lakukan interaksi pada halaman
- Main thread activity menunjukkan tugas JavaScript yang berjalan
- Frames bar menunjukkan frame rate — target 60fps (16.7ms per frame)
- Long tasks (lebih dari 50ms) memblokir main thread dan menyebabkan jank
- Bottom-up dan Call Tree tab membantu menemukan fungsi yang paling lambat

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Performance Profiling Demo</title>
  <style>
    * { box-sizing: border-box; margin: 0; padding: 0; }
    body { font-family: system-ui, sans-serif; padding: 2rem; }
    .container { max-width: 800px; margin: 0 auto; }
    button { padding: 0.5rem 1rem; margin: 0.25rem; cursor: pointer; }
    .list { margin-top: 1rem; }
    .list-item { padding: 0.5rem; border-bottom: 1px solid #eee; }
  </style>
</head>
<body>
  <div class="container">
    <h1>Performance Profiling</h1>
    <button id="fastTask">Operasi Cepat</button>
    <button id="slowTask">Operasi Lambat</button>
    <button id="renderTask">Render Ulang</button>
    <div id="output" class="list"></div>
  </div>
  <script>
    document.getElementById('fastTask').addEventListener('click', () => {
      const output = document.getElementById('output');
      output.innerHTML = '<div class="list-item">Operasi cepat selesai</div>';
    });

    document.getElementById('slowTask').addEventListener('click', () => {
      const start = performance.now();
      let result = 0;
      for (let i = 0; i < 100000000; i++) {
        result += Math.sqrt(i);
      }
      const end = performance.now();
      const output = document.getElementById('output');
      output.innerHTML = `<div class="list-item">Operasi lambat: ${(end - start).toFixed(0)}ms, hasil: ${result.toFixed(0)}</div>`;
    });

    document.getElementById('renderTask').addEventListener('click', () => {
      const output = document.getElementById('output');
      output.innerHTML = '';
      for (let i = 0; i < 1000; i++) {
        const item = document.createElement('div');
        item.className = 'list-item';
        item.textContent = `Item ke-${i + 1}`;
        output.appendChild(item);
      }
    });

    if ('performance' in window && 'PerformanceObserver' in window) {
      const observer = new PerformanceObserver(list => {
        list.getEntries().forEach(entry => {
          if (entry.duration > 50) {
            console.warn('Long task detected:', entry.duration, 'ms');
          }
        });
      });
      observer.observe({ entryTypes: ['longtask'] });
    }
  </script>
</body>
</html>
```

## Cara Integrasi
Buka Chrome DevTools (F12), pilih tab "Performance". Klik tombol record (lingkaran), lakukan interaksi di halaman, lalu klik stop. Analisis flame chart untuk melihat fungsi mana yang memakan waktu. Identifikasi long tasks (garis merah di bagian atas). Gunakan tab "Summary" untuk melihat persentase waktu yang dihabiskan untuk Loading, Scripting, Rendering, Painting.
