# 499. Cara Mengimplementasikan Critical CSS untuk Mempercepat Rendering Awal

## Definisi & Target
Critical CSS adalah teknik mengekstrak CSS yang diperlukan untuk merender konten "above the fold" (yang terlihat tanpa scroll) dan menyematkannya langsung di `<head>`. Target: First Contentful Paint (FCP) lebih cepat karena browser tidak perlu menunggu file CSS eksternal selesai diunduh.

## Analogi Alur
Critical CSS seperti menyiapkan baju yang paling terlihat di etalase toko terlebih dahulu, sementara baju lainnya tetap di gudang (file CSS eksternal). Pengunjung langsung melihat tampilan toko tanpa menunggu semua stok diatur.

## Poin-Poin Penting
- Critical CSS ditempatkan di tag `<style>` dalam `<head>` untuk menghindari render blocking
- Sisa CSS dimuat secara asinkron menggunakan atribut `media="print"` lalu diubah ke `media="all"`
- Tools seperti Critical, Penthouse, atau PurifyCSS dapat mengekstrak critical CSS secara otomatis
- Critical CSS harus diperbarui jika tata letak halaman berubah
- Terlalu banyak critical CSS akan membatalkan manfaat karena ukuran HTML membesar

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Critical CSS Demo</title>
  <style>
    * { box-sizing: border-box; margin: 0; padding: 0; }
    body { font-family: system-ui, sans-serif; color: #333; }
    header { background: linear-gradient(135deg, #667eea, #764ba2); color: #fff; padding: 4rem 2rem; text-align: center; }
    header h1 { font-size: 2.5rem; margin-bottom: 0.5rem; }
    header p { font-size: 1.2rem; opacity: 0.9; }
    .cta { display: inline-block; padding: 1rem 2rem; background: #fff; color: #667eea; border-radius: 50px; text-decoration: none; font-weight: bold; margin-top: 1rem; }
  </style>
  <link rel="preload" href="styles.css" as="style" onload="this.onload=null;this.rel='stylesheet'">
  <noscript><link rel="stylesheet" href="styles.css"></noscript>
</head>
<body>
  <header>
    <h1>Critical CSS in Action</h1>
    <p>CSS above the fold dimuat langsung di head</p>
    <a href="#" class="cta">Mulai Sekarang</a>
  </header>
  <main>
    <section class="features">
      <h2>Fitur Lengkap</h2>
      <p>Konten ini menggunakan CSS dari file eksternal yang dimuat asinkron.</p>
    </section>
  </main>
  <script>
    document.addEventListener('DOMContentLoaded', () => {
      const preload = document.querySelector('link[rel="preload"][as="style"]');
      if (preload) {
        preload.addEventListener('load', () => {
          console.log('CSS non-critical berhasil dimuat');
        });
      }
    });
  </script>
</body>
</html>
```

## Cara Integrasi
Gunakan alat Critical (npm package) untuk mengekstrak critical CSS secara otomatis dari halaman hidup. Sematkan CSS tersebut di dalam tag `<style>` di `<head>`. Untuk CSS sisanya, gunakan pola preload dengan fallback noscript. Integrasikan ekstraksi critical CSS ke dalam build tool seperti Webpack atau Gulp.
