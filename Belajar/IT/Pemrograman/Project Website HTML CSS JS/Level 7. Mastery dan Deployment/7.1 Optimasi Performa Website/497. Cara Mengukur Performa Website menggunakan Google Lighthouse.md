# 497. Cara Mengukur Performa Website Menggunakan Google Lighthouse

## Definisi & Target
Google Lighthouse adalah alat audit otomatis untuk mengukur kualitas website. Lighthouse mengukur lima kategori: Performance, Accessibility, Best Practices, SEO, dan Progressive Web App. Skor berkisar dari 0 hingga 100. Target minimum adalah skor 90+ untuk performa dan aksesibilitas.

## Analogi Alur
Lighthouse seperti inspektur bangunan yang memeriksa setiap aspek rumah — fondasi (performa), pintu (aksesibilitas), atap (SEO), pipa (best practices), dan teknologi (PWA). Inspektur memberi skor untuk setiap kategori.

## Poin-Poin Penting
- Lighthouse dapat dijalankan melalui Chrome DevTools, CLI, atau PageSpeed Insights
- Hasil audit mencakup metrik nyata (field data) dan laboratorium (lab data)
- Lighthouse memberikan rekomendasi spesifik untuk perbaikan
- Lighthouse CI memungkinkan otomatisasi audit dalam pipeline CI/CD
- Audit Lighthouse dapat diintegrasikan ke dalam workflow development

## Cara Integrasi
Buka Chrome DevTools (F12), pilih tab Lighthouse, pilih kategori yang ingin diaudit, lalu klik "Generate report". Alternatif, gunakan Lighthouse CLI melalui Node.js: `npx lighthouse https://example.com --view`. Untuk otomatisasi, integrasikan Lighthouse CI ke dalam GitHub Actions.
