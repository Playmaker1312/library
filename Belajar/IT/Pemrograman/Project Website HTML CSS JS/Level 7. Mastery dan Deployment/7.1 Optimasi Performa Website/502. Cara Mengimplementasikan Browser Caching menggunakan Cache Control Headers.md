# 502. Cara Mengimplementasikan Browser Caching menggunakan Cache Control Headers

## Definisi & Target
Browser caching memungkinkan resource statis disimpan di local browser sehingga tidak perlu diunduh lagi saat kunjungan berikutnya. Cache-Control headers memberi instruksi ke browser tentang berapa lama resource harus disimpan. Target: mengurangi jumlah HTTP request dan waktu loading halaman untuk pengunjung returning.

## Analogi Alur
Browser caching seperti lemari dapur — Anda menyimpan bahan makanan (file) yang sering digunakan di lemari (cache) sehingga tidak perlu pergi ke toko (server) setiap kali memasak. Cache-Control memberi tahu berapa lama bahan itu bertahan.

## Poin-Poin Penting
- Cache-Control: max-age=31536000 menyimpan resource selama 1 tahun
- Gunakan fingerprinting (hash pada filename) untuk invalidasi cache saat file berubah
- HTML sebaiknya memiliki cache pendek (max-age=0) atau menggunakan ETag
- Resource statis seperti gambar, CSS, dan JS dapat di-cache dalam waktu lama
- Platform hosting seperti Netlify dan Vercel memiliki fitur caching bawaan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Browser Caching Demo</title>
  <link rel="stylesheet" href="styles.a1b2c3.css">
</head>
<body>
  <h1>Browser Caching</h1>
  <p>Resource di-cache menggunakan Cache-Control headers.</p>
  <img src="logo.r4d5e6.webp" alt="Logo" width="200" height="100">
  <script src="app.x7y8z9.js"></script>
  <script>
    if ('caches' in window) {
      caches.open('v1').then(cache => {
        console.log('Cache storage tersedia:', cache);
      });
    }
  </script>
</body>
</html>
```

```apache
# .htaccess - Konfigurasi Apache
<IfModule mod_expires.c>
  ExpiresActive On
  ExpiresByType image/webp "access plus 1 year"
  ExpiresByType image/jpeg "access plus 1 year"
  ExpiresByType image/png "access plus 1 year"
  ExpiresByType text/css "access plus 1 year"
  ExpiresByType application/javascript "access plus 1 year"
  ExpiresByType text/html "access plus 0 seconds"
</IfModule>
<IfModule mod_headers.c>
  <filesMatch "\.(css|js|webp|jpg|png)$">
    Header set Cache-Control "public, max-age=31536000, immutable"
  </filesMatch>
  <filesMatch "\.html$">
    Header set Cache-Control "public, max-age=0, must-revalidate"
  </filesMatch>
</IfModule>
```

```nginx
# nginx.conf - Konfigurasi Nginx
location ~* \.(css|js|webp|jpg|png)$ {
    expires 1y;
    add_header Cache-Control "public, immutable";
}

location ~* \.html$ {
    expires -1;
    add_header Cache-Control "no-cache, must-revalidate";
}
```

```json
// netlify.toml - Konfigurasi Netlify
[[headers]]
  for = "*.css"
  [headers.values]
    Cache-Control = "public, max-age=31536000, immutable"

[[headers]]
  for = "*.js"
  [headers.values]
    Cache-Control = "public, max-age=31536000, immutable"

[[headers]]
  for = "*.html"
  [headers.values]
    Cache-Control = "public, max-age=0, must-revalidate"
```

## Cara Integrasi
Tentukan kebijakan caching berdasarkan jenis resource. Asset statis dengan hash fingerprint: cache 1 tahun. HTML: tanpa cache atau ETag. Konfigurasi melalui file `.htaccess` (Apache), konfigurasi Nginx, atau dashboard hosting. Verifikasi caching melalui Chrome DevTools Network tab dengan melihat kolom "Size" yang menunjukkan "(disk cache)".
