# 498. Cara Mengoptimasi Gambar menggunakan Format WebP dan Lazy Loading

## Definisi & Target
WebP adalah format gambar modern dari Google yang menyediakan kompresi lossy dan lossless superior dibanding JPEG dan PNG. Lazy loading adalah teknik menunda pemuatan gambar hingga gambar mendekati viewport. Target: ukuran gambar berkurang 25-35% dengan kualitas setara, dan halaman awal hanya memuat gambar yang terlihat.

## Analogi Alur
WebP seperti menggunakan koper vakum dibanding koper biasa — lebih ringan namun isinya sama. Lazy loading seperti eskalator yang hanya bergerak saat ada orang mendekat, bukan bergerak terus menerus.

## Poin-Poin Penting
- WebP mendukung transparansi (seperti PNG) dan animasi (seperti GIF)
- Lazy loading native menggunakan atribut `loading="lazy"` pada tag `<img>` dan `<iframe>`
- Gunakan elemen `<picture>` untuk fallback ke format lama jika browser tidak mendukung WebP
- Konversi gambar batch menggunakan tools seperti Squoosh, Sharp, atau ImageMagick
- Lazy loading mengurangi initial page load dan bandwidth

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Optimasi WebP dan Lazy Loading</title>
  <style>
    .gallery { display: grid; grid-template-columns: repeat(auto-fill, minmax(300px, 1fr)); gap: 1rem; padding: 1rem; }
    .gallery img { width: 100%; height: auto; border-radius: 8px; background: #eee; }
    .gallery img.loaded { animation: fadeIn 0.5s ease; }
    @keyframes fadeIn { from { opacity: 0; } to { opacity: 1; } }
  </style>
</head>
<body>
  <h1>Galeri WebP dengan Lazy Loading</h1>
  <div class="gallery">
    <picture>
      <source srcset="image1.webp" type="image/webp">
      <img src="image1.jpg" alt="Deskripsi gambar 1" loading="lazy" width="600" height="400">
    </picture>
    <picture>
      <source srcset="image2.webp" type="image/webp">
      <img src="image2.jpg" alt="Deskripsi gambar 2" loading="lazy" width="600" height="400">
    </picture>
    <picture>
      <source srcset="image3.webp" type="image/webp">
      <img src="image3.jpg" alt="Deskripsi gambar 3" loading="lazy" width="600" height="400">
    </picture>
    <picture>
      <source srcset="image4.webp" type="image/webp">
      <img src="image4.jpg" alt="Deskripsi gambar 4" loading="lazy" width="600" height="400">
    </picture>
  </div>
  <script>
    document.addEventListener('DOMContentLoaded', () => {
      const images = document.querySelectorAll('img[loading="lazy"]');
      if ('IntersectionObserver' in window) {
        const observer = new IntersectionObserver((entries) => {
          entries.forEach(entry => {
            if (entry.isIntersecting) {
              const img = entry.target;
              img.src = img.src;
              img.classList.add('loaded');
              observer.unobserve(img);
            }
          });
        });
        images.forEach(img => observer.observe(img));
      }
    });
  </script>
</body>
</html>
```

## Cara Integrasi
Konversi gambar eksisting ke WebP menggunakan Squoosh (squoosh.app) atau CLI Sharp. Terapkan lazy loading native dengan menambahkan atribut `loading="lazy"` pada semua tag `<img>`. Untuk kompatibilitas, gunakan elemen `<picture>` dengan `<source>` WebP dan fallback JPEG/PNG. Ukur penghematan bandwidth menggunakan Network tab di DevTools.
