# 503. Cara Menggunakan CDN untuk Mendistribusikan Asset Statis

## Definisi & Target
CDN (Content Delivery Network) adalah jaringan server yang tersebar secara geografis untuk mendistribusikan konten statis. CDN menyajikan file dari server terdekat dengan pengguna, mengurangi latency dan mempercepat loading. Target: mengurangi waktu muat hingga 50% dan mengurangi beban server origin.

## Analogi Alur
CDN seperti jaringan gudang Amazon — daripada semua pelanggan mengambil barang dari satu gudang pusat, barang disimpan di gudang-gudang lokal di berbagai kota. Pelanggan mengambil dari gudang terdekat, sehingga pengiriman lebih cepat.

## Poin-Poin Penting
- CDN bekerja dengan menyimpan cache asset di edge server di seluruh dunia
- CDN umum: Cloudflare, Fastly, AWS CloudFront, jsDelivr, UNPKG
- CDN juga memberikan perlindungan DDoS dan SSL termination
- Untuk library pihak ketiga, gunakan CDN seperti jsDelivr atau CDNJS
- Cache purging diperlukan saat asset statis diperbarui

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CDN Demo</title>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/modern-normalize@2/modern-normalize.min.css">
  <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.0/css/all.min.css">
  <link rel="stylesheet" href="https://unpkg.com/leaflet@1.9/dist/leaflet.css">
</head>
<body>
  <h1>Asset dari CDN</h1>
  <p>Library CSS dan JS dimuat dari jaringan CDN global.</p>
  <i class="fas fa-rocket" style="font-size: 3rem; color: #1a73e8;"></i>
  <div id="map" style="height: 300px; width: 100%;"></div>
  <script src="https://cdn.jsdelivr.net/npm/axios@1/dist/axios.min.js"></script>
  <script src="https://unpkg.com/leaflet@1.9/dist/leaflet.js"></script>
  <script>
    axios.get('https://api.example.com/data')
      .then(response => console.log('Data dari CDN:', response.data))
      .catch(err => console.log('API tidak tersedia'));
    if (typeof L !== 'undefined') {
      const map = L.map('map').setView([-6.2, 106.8], 13);
      L.tileLayer('https://tile.openstreetmap.org/{z}/{x}/{y}.png', {
        attribution: '&copy; OpenStreetMap'
      }).addTo(map);
    }
  </script>
</body>
</html>
```

```json
// Konfigurasi menggunakan CDN sendiri (Cloudflare)
{
  "zone": "example.com",
  "cdn": {
    "provider": "Cloudflare",
    "caching": {
      "static_assets": {
        "extensions": ["css", "js", "png", "jpg", "webp", "svg"],
        "cache_ttl": "31536000",
        "edge_cache_ttl": "31536000"
      }
    },
    "optimization": {
      "auto_minify": ["css", "js", "html"],
      "brotli": true,
      "rocket_loader": true
    }
  }
}
```

## Cara Integrasi
Untuk library pihak ketiga, ganti file lokal dengan URL CDN di tag `<script>` dan `<link>`. Untuk asset sendiri, gunakan layanan seperti Cloudflare (pasang di DNS) atau upload ke AWS CloudFront. Konfigurasi caching rules di dashboard CDN. Verifikasi dengan memeriksa header `cf-cache-status` (Cloudflare) atau `x-cache` (Fastly) di response.
