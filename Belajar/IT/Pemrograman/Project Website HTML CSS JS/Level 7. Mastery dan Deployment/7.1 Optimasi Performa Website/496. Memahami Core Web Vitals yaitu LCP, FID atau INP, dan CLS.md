# 496. Memahami Core Web Vitals yaitu LCP, FID atau INP, dan CLS

## Definisi & Target
Core Web Vitals adalah tiga metrik utama dari Google yang mengukur pengalaman pengguna di website. LCP (Largest Contentful Paint) mengukur kecepatan loading elemen terbesar, target < 2,5 detik. FID (First Input Delay) mengukur responsivitas interaksi pertama, target < 100 ms. CLS (Cumulative Layout Shift) mengukur stabilitas visual, target < 0,1. Pada 2024, INP (Interaction to Next Paint) menggantikan FID.

## Analogi Alur
LCP seperti restoran yang menyajikan hidangan utama — seberapa cepat makanan sampai ke meja. FID/INP seperti kecepatan pelayan merespon panggilan tangan. CLS seperti meja yang tidak goyang saat gelas diletakkan.

## Poin-Poin Penting
- LCP dipengaruhi oleh server response time, render-blocking resources, dan ukuran gambar
- INP mengukur total latency dari semua interaksi pengguna, bukan hanya yang pertama
- CLS disebabkan oleh elemen yang berubah ukuran setelah dimuat seperti gambar tanpa dimensi
- Google menggunakan Core Web Vitals sebagai sinyal ranking SEO
- Tools seperti Lighthouse, PageSpeed Insights, dan Search Console digunakan untuk mengukur

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Core Web Vitals Demo</title>
  <style>
    img, video, iframe { width: 100%; height: auto; }
    .hero { width: 100%; height: 400px; background: #f0f0f0; }
    .content { font-size: 1.2rem; line-height: 1.6; }
  </style>
</head>
<body>
  <div class="hero">
    <img src="hero.webp" width="1200" height="400" alt="Hero image" loading="lazy">
  </div>
  <div class="content">
    <h1>Core Web Vitals</h1>
    <p>LCP, FID/INP, dan CLS adalah metrik penting.</p>
    <button id="interact">Klik Saya</button>
  </div>
  <script>
    document.getElementById('interact').addEventListener('click', () => {
      console.log('Interaksi dicatat untuk INP');
    });
    if ('performance' in window) {
      const observer = new PerformanceObserver((list) => {
        for (const entry of list.getEntries()) {
          if (entry.entryType === 'largest-contentful-paint') {
            console.log('LCP:', entry.startTime, 'ms');
          }
          if (entry.entryType === 'layout-shift') {
            console.log('CLS score:', entry.value);
          }
        }
      });
      observer.observe({ type: 'largest-contentful-paint', buffered: true });
      observer.observe({ type: 'layout-shift', buffered: true });
    }
  </script>
</body>
</html>
```

## Cara Integrasi
Gunakan Chrome DevTools Performance panel atau Lighthouse untuk mengukur ketiga metrik. Optimasi LCP dengan mempercepat server dan mengompres gambar. Kurangi CLS dengan selalu menyertakan atribut width dan height pada elemen media. Pantau INP dengan menghindari long tasks pada main thread.
