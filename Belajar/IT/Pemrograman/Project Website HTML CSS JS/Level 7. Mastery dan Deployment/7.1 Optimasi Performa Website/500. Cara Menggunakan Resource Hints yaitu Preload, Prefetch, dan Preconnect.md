# 500. Cara Menggunakan Resource Hints yaitu Preload, Prefetch, dan Preconnect

## Definisi & Target
Resource hints adalah petunjuk ke browser untuk memuat sumber daya tertentu lebih awal. Preload (`<link rel="preload">`) memuat sumber daya kritis untuk halaman saat ini. Prefetch (`<link rel="prefetch">`) memuat sumber daya untuk halaman berikutnya. Preconnect (`<link rel="preconnect">`) membuka koneksi awal ke origin pihak ketiga untuk mengurangi latency.

## Analogi Alur
Preload seperti menyiapkan alat yang akan segera digunakan di atas meja. Prefetch seperti menyiapkan bahan untuk resep berikutnya sambil memasak resep saat ini. Preconnect seperti membuka pintu restoran sebelum tamu datang sehingga mereka langsung masuk.

## Poin-Poin Penting
- Preload digunakan untuk font, CSS kritis, gambar hero, dan script penting
- Prefetch cocok untuk halaman yang diprediksi akan dikunjungi berdasarkan user behavior
- Preconnect menghemat waktu untuk DNS lookup, TCP handshake, dan TLS negotiation
- Jangan preload semua resource karena akan membuang bandwidth
- Dns-prefetch adalah versi lebih ringan dari preconnect, hanya untuk DNS lookup

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Resource Hints Demo</title>
  <link rel="preload" href="fonts/inter.woff2" as="font" type="font/woff2" crossorigin>
  <link rel="preload" href="hero.webp" as="image">
  <link rel="preload" href="critical.css" as="style">
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://analytics.example.com">
  <link rel="dns-prefetch" href="https://cdn.example.com">
  <link rel="prefetch" href="halaman-lanjutan.html" as="document">
  <link rel="prefetch" href="halaman-lanjutan.css" as="style">
  <link rel="stylesheet" href="styles.css">
  <style>
    body { font-family: 'Inter', system-ui, sans-serif; }
  </style>
</head>
<body>
  <h1>Resource Hints</h1>
  <p>Preload, Prefetch, dan Preconnect bekerja bersama.</p>
  <img src="hero.webp" width="800" height="400" alt="Hero image using preload">
  <script>
    if (window.performance) {
      const resources = performance.getEntriesByType('resource');
      resources.forEach(r => {
        if (r.initiatorType === 'link') {
          console.log('Resource hint used:', r.name);
        }
      });
    }
    if ('connection' in navigator) {
      console.log('Effective connection type:', navigator.connection.effectiveType);
    }
  </script>
</body>
</html>
```

## Cara Integrasi
Identifikasi resource kritis dengan Chrome DevTools Network tab. Tambahkan `<link rel="preload">` untuk resource yang diperlukan segera. Tambahkan `<link rel="preconnect">` untuk origin pihak ketiga yang digunakan. Gunakan `<link rel="prefetch">` untuk halaman yang mungkin dikunjungi berikutnya. Verifikasi penggunaan resource hints melalui tab Coverage di DevTools.
