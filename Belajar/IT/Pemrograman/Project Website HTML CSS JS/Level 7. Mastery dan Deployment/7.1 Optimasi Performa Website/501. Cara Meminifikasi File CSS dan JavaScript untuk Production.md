# 501. Cara Meminifikasi File CSS dan JavaScript untuk Production

## Definisi & Target
Minifikasi adalah proses menghilangkan karakter yang tidak diperlukan dari kode sumber (spasi, komentar, newline) tanpa mengubah fungsionalitas. Target: ukuran file berkurang 30-70%, waktu unduh lebih cepat, dan konsumsi bandwidth lebih rendah.

## Analogi Alur
Minifikasi seperti mengemas pakaian dalam vacuum bag — semua isinya tetap sama namun volumenya jauh lebih kecil. Menghemat ruang koper (bandwidth) dan memudahkan perjalanan (loading time).

## Poin-Poin Penting
- Tools minifikasi: Terser untuk JavaScript, cssnano untuk CSS, HTMLMinifier untuk HTML
- Build tools seperti Webpack, Vite, dan Parcel memiliki plugin minifikasi bawaan
- Minifikasi harus dilakukan hanya untuk environment production, bukan development
- Source maps membantu debugging kode terminiifikasi di production
- Kombinasikan minifikasi dengan bundling untuk hasil optimal

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Minifikasi Demo</title>
  <link rel="stylesheet" href="styles.min.css">
</head>
<body>
  <h1>File Terminiifikasi</h1>
  <p>File CSS dan JS telah diminifikasi untuk production.</p>
  <button id="btn">Klik</button>
  <script src="app.min.js"></script>
</body>
</html>
```

```css
/* styles.min.css */
*{box-sizing:border-box;margin:0;padding:0}body{font-family:system-ui,sans-serif;line-height:1.6;color:#333;padding:2rem}h1{color:#1a73e8;margin-bottom:1rem}button{padding:.75rem 1.5rem;background:#1a73e8;color:#fff;border:none;border-radius:4px;cursor:pointer}button:hover{background:#1557b0}
```

```javascript
// app.min.js
document.getElementById("btn").addEventListener("click",()=>{alert("Tombol diklik!")});
```

```json
// package.json (konfigurasi minifikasi)
{
  "scripts": {
    "minify:css": "npx cssnano styles.css styles.min.css",
    "minify:js": "npx terser app.js -o app.min.js -c -m",
    "build": "npm run minify:css && npm run minify:js"
  }
}
```

## Cara Integrasi
Install Terser (`npm install terser -g`) dan cssnano. Jalankan `npx terser app.js -o app.min.js -c -m` untuk JS. Jalankan `npx cssnano styles.css styles.min.css` untuk CSS. Integrasikan ke dalam script build package.json atau gunakan plugin di Webpack/Vite. Selalu verifikasi hasil minifikasi tidak merusak fungsionalitas.
