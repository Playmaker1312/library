# 355. Mengimplementasikan Drag and Drop untuk Mengubah Urutan Kolom

## Definisi & Target
Mengimplementasikan drag and drop untuk mengubah urutan kolom pada Kanban Board. Targetnya adalah pengguna bisa mengatur ulang posisi kolom sesuai keinginan.

## Analogi Alur
Seperti memindahkan meja di ruangan - Anda bisa menggeser meja ke posisi yang lebih nyaman. Urutan kolom bisa disesuaikan dengan alur kerja.

## Poin-Poin Penting
- Kolom juga bisa di-drag untuk diurutkan ulang
- Indikator visual posisi tujuan
- Update urutan array columns
- Animasi transisi pertukaran posisi

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Urutkan Kolom</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; height: 100vh; }
.header { padding: 16px 24px; background: #16213e; color: #fff; font-size: 18px; }
.board { display: flex; gap: 16px; padding: 20px; height: calc(100vh - 60px); overflow-x: auto; }
.column { min-width: 260px; background: #1e2a4a; border-radius: 10px; padding: 12px; cursor: grab; transition: all 0.2s; color: #fff; display: flex; flex-direction: column; }
.column.dragging { opacity: 0.4; }
.column.drag-over { border-left: 4px solid #64b5f6; transform: translateX(4px); }
.column-body { flex: 1; padding: 8px 0; }
.card { background: #2a3a6a; padding: 10px; border-radius: 6px; margin-bottom: 6px; font-size: 13px; cursor: default; }
</style>
</head>
<body>
<div class="header">📋 Urutkan Kolom</div>
<div class="board" id="board"></div>
<script>
let columns = [
{ id: 'c1', title: 'To Do' }, { id: 'c2', title: 'In Progress' }, { id: 'c3', title: 'Review' }, { id: 'c4', title: 'Done' }
];
function render() {
const board = document.getElementById('board');
board.innerHTML = '';
columns.forEach(col => {
const div = document.createElement('div');
div.className = 'column';
div.draggable = true;
div.dataset.colId = col.id;
div.innerHTML = `<strong>${col.title}</strong><div class="column-body"><div class="card">Card contoh</div></div>`;
div.addEventListener('dragstart', function(e) { this.classList.add('dragging'); e.dataTransfer.setData('text/plain', col.id); });
div.addEventListener('dragend', function() { this.classList.remove('dragging'); });
div.addEventListener('dragover', function(e) { e.preventDefault(); this.classList.add('drag-over'); });
div.addEventListener('dragleave', function() { this.classList.remove('drag-over'); });
div.addEventListener('drop', function(e) {
e.preventDefault();
this.classList.remove('drag-over');
const draggedId = e.dataTransfer.getData('text/plain');
const targetId = this.dataset.colId;
if (draggedId === targetId) return;
const fromIdx = columns.findIndex(c => c.id === draggedId);
const toIdx = columns.findIndex(c => c.id === targetId);
if (fromIdx === -1 || toIdx === -1) return;
const [item] = columns.splice(fromIdx, 1);
columns.splice(toIdx, 0, item);
render();
});
board.appendChild(div);
});
}
render();
</script>
</body>
</html>
```

## Cara Integrasi
Kolom juga diberikan atribut draggable. Saat di-drop, urutan array columns diubah menggunakan splice. Fungsi render() dipanggil ulang untuk menampilkan urutan baru.
