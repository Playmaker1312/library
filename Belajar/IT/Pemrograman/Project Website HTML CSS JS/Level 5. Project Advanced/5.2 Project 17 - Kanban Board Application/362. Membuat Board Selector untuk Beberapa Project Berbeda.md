# 362. Membuat Board Selector untuk Beberapa Project Berbeda

## Definisi & Target
Membuat board selector yang memungkinkan pengguna memiliki beberapa board untuk project yang berbeda. Targetnya adalah manajemen multiple project.

## Analogi Alur
Seperti memiliki beberapa papan tulis untuk project yang berbeda. Anda bisa beralih antar papan sesuai project yang sedang dikerjakan.

## Poin-Poin Penting
- Sidebar atau dropdown untuk memilih board
- Setiap board memiliki data sendiri
- Tombol untuk menambah board baru
- Data semua board disimpan di LocalStorage

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Board Selector</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; height: 100vh; display: flex; }
.sidebar { width: 220px; background: #16213e; padding: 16px; display: flex; flex-direction: column; gap: 8px; }
.sidebar h3 { color: #aaa; font-size: 12px; text-transform: uppercase; letter-spacing: 1px; margin-bottom: 8px; }
.board-item { padding: 10px 12px; background: #1e2a4a; color: #e0e0e0; border-radius: 6px; cursor: pointer; font-size: 13px; transition: background 0.2s; }
.board-item:hover { background: #2a3a6a; }
.board-item.active { background: #4CAF50; color: #fff; }
.add-board { padding: 10px 12px; border: 2px dashed rgba(255,255,255,0.2); border-radius: 6px; color: rgba(255,255,255,0.4); cursor: pointer; text-align: center; font-size: 13px; margin-top: auto; }
.main { flex: 1; display: flex; flex-direction: column; }
.header { padding: 16px 24px; background: #1a1a2e; color: #fff; font-size: 18px; font-weight: 600; border-bottom: 1px solid rgba(255,255,255,0.05); }
.board-content { flex: 1; display: flex; gap: 16px; padding: 20px; overflow-x: auto; }
.column { min-width: 260px; background: #1e2a4a; border-radius: 10px; padding: 12px; }
.col-title { color: #fff; font-weight: 600; margin-bottom: 8px; }
.card { background: #2a3a6a; color: #e0e0e0; padding: 10px; border-radius: 6px; font-size: 13px; margin-bottom: 6px; }
</style>
</head>
<body>
<div class="sidebar">
<h3>Project Boards</h3>
<div id="boardList"></div>
<div class="add-board" id="addBoard">+ Tambah Board</div>
</div>
<div class="main">
<div class="header" id="boardTitle">Pilih Board</div>
<div class="board-content" id="boardContent"><div style="color:#888;padding:40px;text-align:center">Pilih atau buat board baru</div></div>
</div>
<script>
const STORAGE_KEY = 'kanbanBoards';
let boards = JSON.parse(localStorage.getItem(STORAGE_KEY)) || [{ id: 'b1', name: 'Project Website', columns: [{ id: 'c1', title: 'To Do', cards: [] }, { id: 'c2', title: 'Done', cards: [] }] }];
let activeBoardId = boards[0]?.id || null;
function saveBoards() { localStorage.setItem(STORAGE_KEY, JSON.stringify(boards)); }
function getActiveBoard() { return boards.find(b => b.id === activeBoardId); }
function renderSidebar() {
const list = document.getElementById('boardList');
list.innerHTML = '';
boards.forEach(b => {
const div = document.createElement('div');
div.className = `board-item ${b.id === activeBoardId ? 'active' : ''}`;
div.textContent = b.name;
div.addEventListener('click', () => { activeBoardId = b.id; renderSidebar(); renderBoard(); });
list.appendChild(div);
});
}
function renderBoard() {
const board = getActiveBoard();
document.getElementById('boardTitle').textContent = board ? board.name : 'Pilih Board';
const content = document.getElementById('boardContent');
if (!board) { content.innerHTML = '<div style="color:#888;padding:40px;text-align:center">Pilih board</div>'; return; }
content.innerHTML = board.columns.map(col => `<div class="column"><div class="col-title">${col.title}</div>${col.cards.map(c => `<div class="card">${c.title}</div>`).join('')}</div>`).join('');
}
document.getElementById('addBoard').addEventListener('click', () => {
const name = prompt('Nama project baru:');
if (name && name.trim()) {
boards.push({ id: 'b' + Date.now(), name: name.trim(), columns: [{ id: 'c1', title: 'To Do', cards: [] }, { id: 'c2', title: 'Done', cards: [] }] });
saveBoards(); renderSidebar();
}
});
renderSidebar(); renderBoard();
</script>
</body>
</html>
```

## Cara Integrasi
Sidebar menampilkan daftar board yang tersedia. Setiap board memiliki data independen termasuk columns dan cards. Data semua board disimpan di LocalStorage.
