# 365. Memastikan Kanban Board Responsive dengan Mode Scroll yang Baik di Mobile

## Definisi & Target
Membuat Kanban Board responsif untuk mobile dengan horizontal scroll yang nyaman. Targetnya adalah pengalaman mobile yang optimal tanpa mengorbankan fungsionalitas.

## Analogi Alur
Seperti aplikasi catatan di ponsel yang bisa di-scroll ke samping untuk melihat kolom-kolom yang berbeda.

## Poin-Poin Penting
- Touch scroll horizontal yang smooth
- Ukuran kolom yang sesuai di mobile
- Tombol untuk menambah card yang mudah di-tap
- Header yang tetap di posisi atas

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
<title>Kanban Responsive</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; height: 100vh; overflow: hidden; }
.header { padding: 14px 16px; background: #16213e; color: #fff; font-size: 16px; font-weight: 600; position: sticky; top: 0; z-index: 10; }
.board { display: flex; gap: 12px; padding: 12px; height: calc(100vh - 52px); overflow-x: auto; overflow-y: hidden; -webkit-overflow-scrolling: touch; scroll-snap-type: x proximity; }
.column { min-width: 280px; max-width: 280px; background: #1e2a4a; border-radius: 10px; display: flex; flex-direction: column; max-height: 100%; scroll-snap-align: start; }
.col-header { padding: 12px 14px; color: #fff; font-weight: 600; font-size: 14px; border-bottom: 1px solid rgba(255,255,255,0.1); }
.col-body { flex: 1; padding: 8px; overflow-y: auto; -webkit-overflow-scrolling: touch; }
.card { background: #2a3a6a; color: #e0e0e0; padding: 12px 14px; border-radius: 6px; font-size: 14px; margin-bottom: 8px; }
.add-card-btn { padding: 10px; color: rgba(255,255,255,0.4); text-align: center; font-size: 14px; cursor: pointer; border-radius: 6px; margin-top: 4px; }
.add-card-btn:hover { background: rgba(255,255,255,0.05); }
@media (max-width: 640px) {
.column { min-width: 85vw; max-width: 85vw; }
.header { font-size: 14px; padding: 12px 14px; }
.card { font-size: 15px; padding: 14px; }
}
</style>
</head>
<body>
<div class="header">📋 Kanban Board</div>
<div class="board" id="board"></div>
<script>
const data = [
{ id: 'c1', title: 'To Do', cards: [{ id: 'k1', title: 'Buat Wireframe' }, { id: 'k2', title: 'Riset Pengguna' }, { id: 'k3', title: 'Sketsa Layout' }] },
{ id: 'c2', title: 'In Progress', cards: [{ id: 'k4', title: 'Buat Navigation Bar' }, { id: 'k5', title: 'Buat Hero Section' }] },
{ id: 'c3', title: 'Review', cards: [{ id: 'k6', title: 'Review Design' }] },
{ id: 'c4', title: 'Done', cards: [{ id: 'k7', title: 'Setup Project' }] }
];
function render() {
const board = document.getElementById('board');
board.innerHTML = '';
data.forEach(col => {
const colDiv = document.createElement('div');
colDiv.className = 'column';
colDiv.innerHTML = `<div class="col-header">${col.title} (${col.cards.length})</div><div class="col-body">${col.cards.map(c => `<div class="card">${c.title}</div>`).join('')}<div class="add-card-btn">+ Tambah</div></div>`;
board.appendChild(colDiv);
});
}
render();
</script>
</body>
</html>
```

## Cara Integrasi
Gunakan -webkit-overflow-scrolling: touch untuk smooth scrolling di iOS. scroll-snap-type dan scroll-snap-align membantu kolom "snap" ke posisi saat di-scroll. Media query menyesuaikan ukuran kolom di mobile.
