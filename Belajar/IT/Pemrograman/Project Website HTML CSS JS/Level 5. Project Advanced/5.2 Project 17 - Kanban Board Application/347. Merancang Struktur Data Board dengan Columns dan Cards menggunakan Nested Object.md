# 347. Merancang Struktur Data Board dengan Columns dan Cards menggunakan Nested Object

## Definisi & Target
Merancang struktur data untuk Kanban Board menggunakan nested object yang terdiri dari board, columns, dan cards. Targetnya adalah data yang terorganisir dan mudah dimanipulasi.

## Analogi Alur
Seperti lemari arsip dengan beberapa laci (columns) dan setiap laci berisi folder (cards). Struktur hirarkis memudahkan pencarian dan pengelolaan.

## Poin-Poin Penting
- Board memiliki array of columns
- Setiap column memiliki id, title, dan array of cards
- Setiap card memiliki id, title, description, label, priority
- Data disimpan dan dimanipulasi melalui JavaScript

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Struktur Data Kanban</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; display: flex; justify-content: center; padding: 20px; }
pre { background: #1e1e1e; color: #d4d4d4; padding: 20px; border-radius: 8px; max-width: 700px; overflow: auto; font-size: 13px; line-height: 1.6; }
</style>
</head>
<body>
<pre id="dataDisplay"></pre>
<script>
const board = {
id: 'board-1',
title: 'Project Website',
columns: [
{ id: 'col-1', title: 'To Do', cards: [
{ id: 'card-1', title: 'Buat Wireframe', description: 'Membuat sketsa layout', label: 'Design', priority: 'high' },
{ id: 'card-2', title: 'Riset Pengguna', description: 'Wawancara user', label: 'Research', priority: 'medium' }
]},
{ id: 'col-2', title: 'In Progress', cards: [
{ id: 'card-3', title: 'Buat Header', description: 'Implementasi navigation bar', label: 'Frontend', priority: 'high' }
]},
{ id: 'col-3', title: 'Done', cards: [
{ id: 'card-4', title: 'Setup Project', description: 'Inisialisasi repo dan dependencies', label: 'Setup', priority: 'low' }
]}
]
};
document.getElementById('dataDisplay').textContent = JSON.stringify(board, null, 2);
</script>
</body>
</html>
```

## Cara Integrasi
Struktur data ini menjadi sumber kebenaran (source of truth) untuk seluruh aplikasi Kanban. Semua operasi CRUD akan memodifikasi objek board ini.
