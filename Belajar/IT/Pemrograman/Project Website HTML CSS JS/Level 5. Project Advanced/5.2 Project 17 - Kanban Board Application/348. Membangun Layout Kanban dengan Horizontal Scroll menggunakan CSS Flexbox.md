# 348. Membangun Layout Kanban dengan Horizontal Scroll menggunakan CSS Flexbox

## Definisi & Target
Membangun layout utama Kanban Board dengan kolom-kolom yang dapat di-scroll secara horizontal menggunakan CSS Flexbox. Targetnya adalah layout yang fleksibel dan mudah diakses.

## Analogi Alur
Seperti meja panjang yang bisa digeser ke kiri dan kanan untuk melihat semua kolom. Flexbox memungkinkan kolom untuk tetap sejajar dan responsif.

## Poin-Poin Penting
- Container menggunakan display: flex dengan overflow-x: auto
- Setiap kolom memiliki lebar tetap (fixed width)
- Scroll horizontal jika kolom melebihi viewport
- Height penuh viewport dengan vertical scroll per kolom

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Layout Kanban Flexbox</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; height: 100vh; background: #1a1a2e; }
.board-header { padding: 16px 24px; background: #16213e; color: #fff; font-size: 20px; font-weight: 600; }
.board { display: flex; gap: 16px; padding: 20px; height: calc(100vh - 60px); overflow-x: auto; overflow-y: hidden; }
.column { min-width: 300px; max-width: 300px; background: #1e2a4a; border-radius: 12px; display: flex; flex-direction: column; max-height: 100%; }
.column-header { padding: 14px 16px; font-weight: 600; color: #fff; border-bottom: 2px solid rgba(255,255,255,0.1); display: flex; justify-content: space-between; }
.column-body { flex: 1; overflow-y: auto; padding: 8px; }
.add-column { min-width: 300px; max-width: 300px; border: 2px dashed rgba(255,255,255,0.2); border-radius: 12px; display: flex; align-items: center; justify-content: center; cursor: pointer; color: rgba(255,255,255,0.5); font-size: 16px; transition: all 0.2s; }
.add-column:hover { border-color: rgba(255,255,255,0.5); color: rgba(255,255,255,0.8); }
</style>
</head>
<body>
<div class="board-header">📋 Project Website</div>
<div class="board">
<div class="column"><div class="column-header">To Do <span>2</span></div><div class="column-body"></div></div>
<div class="column"><div class="column-header">In Progress <span>1</span></div><div class="column-body"></div></div>
<div class="column"><div class="column-header">Done <span>3</span></div><div class="column-body"></div></div>
<div class="add-column">+ Tambah Kolom</div>
</div>
</body>
</html>
```

## Cara Integrasi
Layout ini menjadi kerangka utama Kanban Board. Kolom-kolom ditambahkan secara dinamis dan di-scroll secara horizontal saat jumlah kolom bertambah.
