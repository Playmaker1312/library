# 346. Merencanakan Fitur Kanban Board yaitu Columns, Cards, Drag and Drop, dan CRUD

## Definisi & Target
Merencanakan fitur utama Kanban Board yang terdiri dari kolom-kolom, kartu-kartu, drag and drop antar kolom, serta operasi CRUD (Create, Read, Update, Delete). Targetnya adalah aplikasi manajemen project yang fungsional.

## Analogi Alur
Seperti papan fisik dengan sticky notes di dinding. Setiap kolom mewakili tahap pekerjaan (To Do, In Progress, Done) dan kartu bisa dipindahkan antar kolom.

## Poin-Poin Penting
- Kolom mewakili status atau tahap pekerjaan
- Kartu berisi tugas atau item pekerjaan
- Drag and drop untuk memindahkan kartu
- CRUD untuk mengelola kolom dan kartu
