# 350. Membuat Card yang Bisa Ditambah ke Setiap Kolom

## Definisi & Target
Membuat fungsionalitas untuk menambahkan kartu ke dalam setiap kolom Kanban. Targetnya adalah pengguna bisa membuat task baru di kolom yang diinginkan.

## Analogi Alur
Seperti menempelkan sticky note baru ke papan di bagian kolom tertentu. Setiap kartu mewakili tugas yang perlu dikerjakan.

## Poin-Poin Penting
- Tombol "Tambah Card" di bagian bawah kolom
- Input inline atau modal untuk judul card
- Card ditambahkan ke kolom yang sesuai
- Setiap card memiliki tombol hapus

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Tambah Card</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; height: 100vh; }
.header { padding: 16px 24px; background: #16213e; color: #fff; font-size: 18px; font-weight: 600; }
.board { display: flex; gap: 16px; padding: 20px; height: calc(100vh - 60px); overflow-x: auto; overflow-y: hidden; }
.column { min-width: 280px; max-width: 280px; background: #1e2a4a; border-radius: 10px; display: flex; flex-direction: column; max-height: 100%; }
.col-header { padding: 12px 14px; color: #fff; font-weight: 600; border-bottom: 1px solid rgba(255,255,255,0.1); }
.col-body { flex: 1; padding: 8px; overflow-y: auto; display: flex; flex-direction: column; gap: 8px; }
.card { background: #2a3a6a; color: #e0e0e0; padding: 10px 12px; border-radius: 6px; font-size: 13px; cursor: pointer; display: flex; justify-content: space-between; align-items: flex-start; }
.card:hover { background: #324a7a; }
.card .del { background: none; border: none; color: #e53935; cursor: pointer; font-size: 14px; opacity: 0; }
.card:hover .del { opacity: 0.7; }
.add-card { padding: 8px; color: rgba(255,255,255,0.4); cursor: pointer; font-size: 13px; text-align: center; border-radius: 6px; }
.add-card:hover { background: rgba(255,255,255,0.05); color: rgba(255,255,255,0.7); }
</style>
</head>
<body>
<div class="header">📋 Project Website</div>
<div class="board" id="board"></div>
<script>
const data = [
{ id: 'c1', title: 'To Do', cards: [{ id: 'k1', title: 'Buat Wireframe' }] },
{ id: 'c2', title: 'In Progress', cards: [{ id: 'k2', title: 'Buat Header' }] },
{ id: 'c3', title: 'Done', cards: [] }
];
function render() {
const board = document.getElementById('board');
board.innerHTML = '';
data.forEach(col => {
const colDiv = document.createElement('div');
colDiv.className = 'column';
let cardsHtml = '';
col.cards.forEach(card => { cardsHtml += `<div class="card"><span>${card.title}</span><button class="del" data-col="${col.id}" data-card="${card.id}">×</button></div>`; });
colDiv.innerHTML = `<div class="col-header">${col.title}</div><div class="col-body">${cardsHtml}<div class="add-card" data-col="${col.id}">+ Tambah Card</div></div>`;
colDiv.querySelectorAll('.del').forEach(btn => btn.addEventListener('click', function(e) {
e.stopPropagation();
const colId = this.dataset.col;
const cardId = this.dataset.card;
const c = data.find(d => d.id === colId);
if (c) { c.cards = c.cards.filter(k => k.id !== cardId); render(); }
}));
colDiv.querySelector('.add-card').addEventListener('click', function() {
const title = prompt('Judul card:');
if (title && title.trim()) {
const c = data.find(d => d.id === this.dataset.col);
if (c) { c.cards.push({ id: 'k' + Date.now(), title: title.trim() }); render(); }
}
});
board.appendChild(colDiv);
});
}
render();
</script>
</body>
</html>
```

## Cara Integrasi
Tombol "Tambah Card" di setiap kolom akan memicu prompt untuk memasukkan judul card. Card baru ditambahkan ke array cards pada kolom yang sesuai.
