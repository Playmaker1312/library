# 354. Mengimplementasikan Visual Feedback saat Card di-Drag yaitu Opacity dan Placeholder

## Definisi & Target
Menambahkan visual feedback saat card di-drag berupa perubahan opacity pada card yang di-drag dan placeholder (area kosong) di posisi asal. Targetnya adalah pengalaman drag yang lebih informatif.

## Analogi Alur
Seperti bayangan yang tertinggal saat Anda mengambil buku dari rak - Anda bisa melihat di mana buku itu berada sebelumnya.

## Poin-Poin Penting
- Card yang di-drag menjadi transparan (opacity 0.5)
- Placeholder muncul di posisi asal card
- Kolom tujuan memiliki highlight
- Transisi halus untuk semua efek

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Visual Feedback Drag</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; height: 100vh; }
.header { padding: 16px 24px; background: #16213e; color: #fff; font-size: 18px; }
.board { display: flex; gap: 16px; padding: 20px; height: calc(100vh - 60px); overflow-x: auto; }
.column { min-width: 280px; background: #1e2a4a; border-radius: 10px; display: flex; flex-direction: column; }
.col-header { padding: 12px 14px; color: #fff; font-weight: 600; border-bottom: 1px solid rgba(255,255,255,0.1); }
.col-body { flex: 1; padding: 8px; overflow-y: auto; display: flex; flex-direction: column; gap: 6px; min-height: 80px; }
.card { background: #2a3a6a; color: #e0e0e0; padding: 10px 12px; border-radius: 6px; font-size: 13px; cursor: grab; transition: all 0.2s; }
.card.dragging { opacity: 0.4; transform: scale(0.95); }
.card.drag-over { border: 2px dashed #64b5f6; background: transparent; }
.column.drag-over { background: #223a5a; }
.column.drag-over .col-body { background: rgba(100,181,246,0.05); border-radius: 8px; }
.placeholder { background: rgba(255,255,255,0.05); border: 2px dashed rgba(255,255,255,0.2); border-radius: 6px; height: 40px; }
</style>
</head>
<body>
<div class="header">📋 Visual Feedback</div>
<div class="board" id="board"></div>
<script>
const data = [
{ id: 'c1', title: 'To Do', cards: [{ id: 'k1', title: 'Buat Wireframe' }, { id: 'k2', title: 'Riset' }] },
{ id: 'c2', title: 'In Progress', cards: [{ id: 'k3', title: 'Header' }] },
{ id: 'c3', title: 'Done', cards: [] }
];
function render() {
const board = document.getElementById('board');
board.innerHTML = '';
data.forEach(col => {
const colDiv = document.createElement('div');
colDiv.className = 'column';
colDiv.dataset.colId = col.id;
colDiv.innerHTML = `<div class="col-header">${col.title}</div><div class="col-body" data-col="${col.id}"></div>`;
const body = colDiv.querySelector('.col-body');
col.cards.forEach(card => {
const cardDiv = document.createElement('div');
cardDiv.className = 'card';
cardDiv.draggable = true;
cardDiv.textContent = card.title;
cardDiv.dataset.cardId = card.id;
cardDiv.addEventListener('dragstart', function(e) {
this.classList.add('dragging');
const ph = document.createElement('div');
ph.className = 'placeholder';
this.parentNode.insertBefore(ph, this.nextSibling);
e.dataTransfer.setData('text/plain', JSON.stringify({ cardId: card.id, colId: col.id }));
});
cardDiv.addEventListener('dragend', function() { this.classList.remove('dragging'); document.querySelector('.placeholder')?.remove(); });
body.appendChild(cardDiv);
});
colDiv.addEventListener('dragover', function(e) { e.preventDefault(); this.classList.add('drag-over'); });
colDiv.addEventListener('dragleave', function() { this.classList.remove('drag-over'); });
colDiv.addEventListener('drop', function(e) {
e.preventDefault();
this.classList.remove('drag-over');
const { cardId, colId } = JSON.parse(e.dataTransfer.getData('text/plain'));
if (colId === this.dataset.colId) return;
const src = data.find(c => c.id === colId);
const dst = data.find(c => c.id === this.dataset.colId);
if (!src || !dst) return;
const idx = src.cards.findIndex(c => c.id === cardId);
if (idx === -1) return;
dst.cards.push(...src.cards.splice(idx, 1));
render();
});
board.appendChild(colDiv);
});
}
render();
</script>
</body>
</html>
```

## Cara Integrasi
Saat drag dimulai, card diberi class dragging dan placeholder ditambahkan. Saat drag berakhir atau di-drop, placeholder dihapus.
