# 359. Mengimplementasikan Fitur Archive Card yang Sudah Selesai

## Definisi & Target
Membuat fitur untuk meng-archive card yang sudah selesai atau tidak diperlukan lagi. Targetnya adalah membersihkan board tanpa kehilangan data.

## Analogi Alur
Seperti memindahkan dokumen lama dari meja kerja ke lemari arsip. Dokumen masih ada tapi tidak mengganggu pandangan.

## Poin-Poin Penting
- Tombol archive pada setiap card
- Card dipindahkan ke kolom arsip atau hidden
- Archive section bisa dibuka/ditutup
- Restore card dari archive

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Archive Card</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; height: 100vh; }
.header { padding: 16px 24px; background: #16213e; color: #fff; display: flex; align-items: center; gap: 16px; }
.board { display: flex; gap: 16px; padding: 20px; height: calc(100vh - 60px); overflow-x: auto; }
.column { min-width: 280px; background: #1e2a4a; border-radius: 10px; display: flex; flex-direction: column; max-height: 100%; }
.col-header { padding: 12px 14px; color: #fff; font-weight: 600; display: flex; justify-content: space-between; border-bottom: 1px solid rgba(255,255,255,0.1); }
.col-body { flex: 1; padding: 8px; overflow-y: auto; display: flex; flex-direction: column; gap: 6px; }
.card { background: #2a3a6a; color: #e0e0e0; padding: 10px 12px; border-radius: 6px; font-size: 13px; display: flex; justify-content: space-between; }
.card .actions { display: flex; gap: 4px; }
.card .actions button { background: none; border: none; cursor: pointer; font-size: 14px; padding: 0 2px; }
.archive-btn { color: #ffb74d; }
.restore-btn { color: #81c784; }
.archive-section { margin-top: 8px; }
.archive-toggle { background: none; border: 1px solid rgba(255,255,255,0.2); color: #aaa; padding: 6px 12px; border-radius: 6px; cursor: pointer; font-size: 12px; }
.archive-cards { display: none; margin-top: 8px; }
.archive-cards.show { display: flex; flex-direction: column; gap: 6px; }
</style>
</head>
<body>
<div class="header">📋 Archive Card</div>
<div class="board" id="board"></div>
<script>
let archivedCards = [];
let showArchive = false;
const data = [
{ id: 'c1', title: 'To Do', cards: [{ id: 'k1', title: 'Buat Wireframe' }] },
{ id: 'c2', title: 'In Progress', cards: [{ id: 'k2', title: 'Header' }] },
{ id: 'c3', title: 'Done', cards: [{ id: 'k3', title: 'Setup Project' }] }
];
function render() {
const board = document.getElementById('board');
board.innerHTML = '';
data.forEach(col => {
const colDiv = document.createElement('div');
colDiv.className = 'column';
let cardsHtml = col.cards.map(c => `<div class="card"><span>${c.title}</span><div class="actions"><button class="archive-btn" data-card="${c.id}" data-col="${col.id}">📦</button></div></div>`).join('');
colDiv.innerHTML = `<div class="col-header">${col.title}</div><div class="col-body">${cardsHtml}</div>`;
colDiv.querySelectorAll('.archive-btn').forEach(btn => btn.addEventListener('click', function() {
const cardId = this.dataset.card;
const colId = this.dataset.col;
const col = data.find(c => c.id === colId);
if (!col) return;
const idx = col.cards.findIndex(c => c.id === cardId);
if (idx === -1) return;
archivedCards.push(col.cards[idx]);
col.cards.splice(idx, 1);
render();
}));
board.appendChild(colDiv);
});
const archiveDiv = document.createElement('div');
archiveDiv.className = 'column';
archiveDiv.style.minWidth = '280px';
archiveDiv.innerHTML = `<div class="col-header">📦 Arsip <button class="archive-toggle" id="archiveToggle">${showArchive ? 'Sembunyikan' : 'Tampilkan'} (${archivedCards.length})</button></div><div class="col-body"><div class="archive-cards ${showArchive ? 'show' : ''}" id="archiveCards">${archivedCards.map(c => `<div class="card"><span>${c.title}</span><div class="actions"><button class="restore-btn" data-card="${c.id}">↩</button></div></div>`).join('')}</div></div>`;
board.appendChild(archiveDiv);
document.getElementById('archiveToggle')?.addEventListener('click', () => { showArchive = !showArchive; render(); });
document.querySelectorAll('.restore-btn').forEach(btn => btn.addEventListener('click', function() {
const cardId = this.dataset.card;
const idx = archivedCards.findIndex(c => c.id === cardId);
if (idx === -1) return;
data[0].cards.push(archivedCards[idx]);
archivedCards.splice(idx, 1);
render();
}));
}
render();
</script>
</body>
</html>
```

## Cara Integrasi
Card yang di-archive dipindahkan dari array cards kolom ke array archivedCards terpisah. Card bisa di-restore kembali ke kolom pertama.
