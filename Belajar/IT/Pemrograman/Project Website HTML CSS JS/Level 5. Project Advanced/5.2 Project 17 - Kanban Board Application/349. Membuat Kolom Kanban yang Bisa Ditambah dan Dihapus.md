# 349. Membuat Kolom Kanban yang Bisa Ditambah dan Dihapus

## Definisi & Target
Membuat fungsionalitas untuk menambah dan menghapus kolom pada Kanban Board. Targetnya adalah pengelolaan kolom yang dinamis dan interaktif.

## Analogi Alur
Seperti menambah atau menghapus laci di lemari arsip. Setiap kolom baru bisa ditambahkan sesuai kebutuhan project.

## Poin-Poin Penting
- Tombol "Tambah Kolom" di akhir daftar kolom
- Modal/prompt untuk memasukkan nama kolom
- Tombol hapus pada header kolom
- Konfirmasi sebelum menghapus kolom

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Tambah Hapus Kolom</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; height: 100vh; }
.header { padding: 16px 24px; background: #16213e; color: #fff; font-size: 18px; font-weight: 600; }
.board { display: flex; gap: 16px; padding: 20px; height: calc(100vh - 60px); overflow-x: auto; overflow-y: hidden; }
.column { min-width: 280px; max-width: 280px; background: #1e2a4a; border-radius: 10px; display: flex; flex-direction: column; max-height: 100%; }
.col-header { padding: 12px 14px; color: #fff; font-weight: 600; display: flex; justify-content: space-between; align-items: center; border-bottom: 1px solid rgba(255,255,255,0.1); }
.col-header .del { background: none; border: none; color: #e53935; cursor: pointer; font-size: 16px; opacity: 0.6; }
.col-header .del:hover { opacity: 1; }
.col-body { flex: 1; padding: 8px; overflow-y: auto; }
.add-col { min-width: 280px; border: 2px dashed rgba(255,255,255,0.2); border-radius: 10px; display: flex; align-items: center; justify-content: center; cursor: pointer; color: rgba(255,255,255,0.5); }
.add-col:hover { border-color: rgba(255,255,255,0.4); color: rgba(255,255,255,0.8); }
</style>
</head>
<body>
<div class="header">📋 Project Website</div>
<div class="board" id="board"></div>
<script>
let columns = [
{ id: 'c1', title: 'To Do' }, { id: 'c2', title: 'In Progress' }, { id: 'c3', title: 'Done' }
];
function render() {
const board = document.getElementById('board');
board.innerHTML = '';
columns.forEach(col => {
const div = document.createElement('div');
div.className = 'column';
div.innerHTML = `<div class="col-header">${col.title}<button class="del" data-id="${col.id}">×</button></div><div class="col-body"></div>`;
div.querySelector('.del').addEventListener('click', () => {
if (confirm(`Hapus kolom "${col.title}"?`)) { columns = columns.filter(c => c.id !== col.id); render(); }
});
board.appendChild(div);
});
const addBtn = document.createElement('div');
addBtn.className = 'add-col';
addBtn.textContent = '+ Tambah Kolom';
addBtn.addEventListener('click', () => {
const title = prompt('Nama kolom baru:');
if (title && title.trim()) { columns.push({ id: 'c' + Date.now(), title: title.trim() }); render(); }
});
board.appendChild(addBtn);
}
render();
</script>
</body>
</html>
```

## Cara Integrasi
Fungsi render() akan membangun ulang seluruh board setiap kali ada perubahan. Kolom baru ditambahkan ke array columns dan di-render ulang.
