# 353. Mengimplementasikan Drag and Drop Card Antar Kolom menggunakan HTML5 Drag and Drop API

## Definisi & Target
Mengimplementasikan drag and drop untuk memindahkan card antar kolom menggunakan HTML5 Drag and Drop API. Targetnya adalah manipulasi card yang intuitif.

## Analogi Alur
Seperti mengambil sticky note dari satu kolom dan menempelkannya ke kolom lain di papan fisik. Proses ini langsung dan visual.

## Poin-Poin Penting
- Atribut draggable pada setiap card
- Event dragstart, dragover, drop pada card dan kolom
- Update data board setelah drop
- Visual feedback saat drag

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Drag and Drop Card</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; height: 100vh; }
.header { padding: 16px 24px; background: #16213e; color: #fff; font-size: 18px; font-weight: 600; }
.board { display: flex; gap: 16px; padding: 20px; height: calc(100vh - 60px); overflow-x: auto; }
.column { min-width: 280px; background: #1e2a4a; border-radius: 10px; display: flex; flex-direction: column; max-height: 100%; }
.col-header { padding: 12px 14px; color: #fff; font-weight: 600; border-bottom: 1px solid rgba(255,255,255,0.1); }
.col-body { flex: 1; padding: 8px; overflow-y: auto; display: flex; flex-direction: column; gap: 6px; min-height: 60px; }
.card { background: #2a3a6a; color: #e0e0e0; padding: 10px 12px; border-radius: 6px; font-size: 13px; cursor: grab; }
.card:active { cursor: grabbing; }
.card.dragging { opacity: 0.5; }
.column.drag-over { background: #253a5a; }
.column.drag-over .col-body { background: rgba(255,255,255,0.05); border-radius: 6px; }
</style>
</head>
<body>
<div class="header">📋 Drag & Drop Kanban</div>
<div class="board" id="board"></div>
<script>
const data = [
{ id: 'c1', title: 'To Do', cards: [{ id: 'k1', title: 'Buat Wireframe' }, { id: 'k2', title: 'Riset Pengguna' }] },
{ id: 'c2', title: 'In Progress', cards: [{ id: 'k3', title: 'Buat Header' }] },
{ id: 'c3', title: 'Done', cards: [] }
];
function render() {
const board = document.getElementById('board');
board.innerHTML = '';
data.forEach(col => {
const colDiv = document.createElement('div');
colDiv.className = 'column';
colDiv.dataset.colId = col.id;
colDiv.innerHTML = `<div class="col-header">${col.title}</div><div class="col-body" data-col="${col.id}"></div>`;
const body = colDiv.querySelector('.col-body');
col.cards.forEach(card => {
const cardDiv = document.createElement('div');
cardDiv.className = 'card';
cardDiv.draggable = true;
cardDiv.textContent = card.title;
cardDiv.dataset.cardId = card.id;
cardDiv.dataset.colId = col.id;
cardDiv.addEventListener('dragstart', function(e) { this.classList.add('dragging'); e.dataTransfer.setData('text/plain', JSON.stringify({ cardId: this.dataset.cardId, colId: this.dataset.colId })); });
cardDiv.addEventListener('dragend', function() { this.classList.remove('dragging'); });
body.appendChild(cardDiv);
});
colDiv.addEventListener('dragover', function(e) { e.preventDefault(); this.classList.add('drag-over'); });
colDiv.addEventListener('dragleave', function() { this.classList.remove('drag-over'); });
colDiv.addEventListener('drop', function(e) {
e.preventDefault();
this.classList.remove('drag-over');
const { cardId, colId } = JSON.parse(e.dataTransfer.getData('text/plain'));
if (colId === this.dataset.colId) return;
const srcCol = data.find(c => c.id === colId);
const dstCol = data.find(c => c.id === this.dataset.colId);
if (!srcCol || !dstCol) return;
const cardIndex = srcCol.cards.findIndex(c => c.id === cardId);
if (cardIndex === -1) return;
const [movedCard] = srcCol.cards.splice(cardIndex, 1);
dstCol.cards.push(movedCard);
render();
});
board.appendChild(colDiv);
});
}
render();
</script>
</body>
</html>
```

## Cara Integrasi
Setiap card memiliki atribut draggable. Event dragstart menyimpan data card yang di-drag. Event drop memproses pemindahan card antar kolom dengan memanipulasi array data.
