# 363. Menambahkan Member Avatar pada Card untuk Assignment

## Definisi & Target
Menambahkan avatar anggota tim pada card untuk menunjukkan siapa yang ditugaskan pada task tersebut. Targetnya adalah visual assignment yang jelas.

## Analogi Alur
Seperti menempelkan foto orang pada sticky note agar semua orang tahu siapa yang mengerjakan tugas tersebut.

## Poin-Poin Penting
- Avatar berbentuk lingkaran dengan inisial
- Warna berbeda untuk setiap member
- Bisa assign multiple member ke satu card
- Avatar ditampilkan di footer card
