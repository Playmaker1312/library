# 356. Menampilkan Counter Jumlah Card di Setiap Kolom

## Definisi & Target
Menambahkan counter yang menampilkan jumlah card di setiap kolom. Targetnya adalah informasi cepat tentang workload setiap kolom.

## Analogi Alur
Seperti papan skor yang menunjukkan jumlah item di setiap bagian. Counter membantu melihat distribusi tugas secara sekilas.

## Poin-Poin Penting
- Angka ditampilkan di samping judul kolom
- Format: "Nama Kolom (jumlah)"
- Counter di-update otomatis saat card berubah
- Styling berupa badge kecil

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Counter Card</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; height: 100vh; }
.header { padding: 16px 24px; background: #16213e; color: #fff; font-size: 18px; }
.board { display: flex; gap: 16px; padding: 20px; height: calc(100vh - 60px); overflow-x: auto; }
.column { min-width: 280px; background: #1e2a4a; border-radius: 10px; display: flex; flex-direction: column; max-height: 100%; }
.col-header { padding: 12px 14px; color: #fff; font-weight: 600; display: flex; align-items: center; gap: 8px; border-bottom: 1px solid rgba(255,255,255,0.1); }
.count-badge { background: rgba(255,255,255,0.1); color: #aaa; font-size: 12px; padding: 2px 8px; border-radius: 10px; font-weight: 500; }
.col-body { flex: 1; padding: 8px; overflow-y: auto; display: flex; flex-direction: column; gap: 6px; }
.card { background: #2a3a6a; color: #e0e0e0; padding: 10px 12px; border-radius: 6px; font-size: 13px; }
</style>
</head>
<body>
<div class="header">📋 Counter Card</div>
<div class="board" id="board"></div>
<script>
const data = [
{ id: 'c1', title: 'To Do', cards: [{ id: 'k1', title: 'Buat Wireframe' }, { id: 'k2', title: 'Riset' }, { id: 'k3', title: 'Sketsa' }] },
{ id: 'c2', title: 'In Progress', cards: [{ id: 'k4', title: 'Header' }, { id: 'k5', title: 'Footer' }] },
{ id: 'c3', title: 'Done', cards: [{ id: 'k6', title: 'Setup' }] }
];
function render() {
const board = document.getElementById('board');
board.innerHTML = '';
data.forEach(col => {
const colDiv = document.createElement('div');
colDiv.className = 'column';
colDiv.innerHTML = `<div class="col-header">${col.title}<span class="count-badge">${col.cards.length}</span></div><div class="col-body">${col.cards.map(c => `<div class="card">${c.title}</div>`).join('')}</div>`;
board.appendChild(colDiv);
});
}
render();
</script>
</body>
</html>
```

## Cara Integrasi
Counter dihitung dari array cards di setiap kolom. Badge diperbarui setiap kali render() dipanggil, memastikan counter selalu akurat.
