# 360. Menyimpan Seluruh State Board ke LocalStorage

## Definisi & Target
Menyimpan seluruh state board (columns, cards, archive) ke LocalStorage agar data tetap ada setelah halaman di-refresh. Targetnya adalah persistensi data.

## Analogi Alur
Seperti memfoto kondisi papan sticky note di akhir hari agar bisa dilihat kembali besok. LocalStorage menyimpan snapshot data board.

## Poin-Poin Penting
- Simpan data board ke LocalStorage setiap ada perubahan
- Load data dari LocalStorage saat halaman dimuat
- Format JSON untuk penyimpanan
- Handle jika data tidak ada (first time)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>LocalStorage Board</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; height: 100vh; }
.header { padding: 16px 24px; background: #16213e; color: #fff; display: flex; justify-content: space-between; align-items: center; }
.header button { padding: 8px 16px; background: #e53935; color: #fff; border: none; border-radius: 6px; cursor: pointer; font-size: 12px; }
.board { display: flex; gap: 16px; padding: 20px; height: calc(100vh - 60px); overflow-x: auto; }
.column { min-width: 280px; background: #1e2a4a; border-radius: 10px; display: flex; flex-direction: column; max-height: 100%; }
.col-header { padding: 12px 14px; color: #fff; font-weight: 600; border-bottom: 1px solid rgba(255,255,255,0.1); }
.col-body { flex: 1; padding: 8px; overflow-y: auto; display: flex; flex-direction: column; gap: 6px; }
.card { background: #2a3a6a; color: #e0e0e0; padding: 10px 12px; border-radius: 6px; font-size: 13px; display: flex; justify-content: space-between; }
.card .del { background: none; border: none; color: #e53935; cursor: pointer; font-size: 14px; }
.add-card { padding: 8px; text-align: center; color: rgba(255,255,255,0.4); cursor: pointer; font-size: 13px; border-radius: 6px; }
.add-card:hover { background: rgba(255,255,255,0.05); color: rgba(255,255,255,0.7); }
</style>
</head>
<body>
<div class="header"><span>📋 LocalStorage Board</span><button id="resetBtn">Reset Data</button></div>
<div class="board" id="board"></div>
<script>
const STORAGE_KEY = 'kanbanBoard';
function getDefaultData() {
return [
{ id: 'c1', title: 'To Do', cards: [{ id: 'k1', title: 'Buat Wireframe' }, { id: 'k2', title: 'Riset' }] },
{ id: 'c2', title: 'In Progress', cards: [{ id: 'k3', title: 'Header' }] },
{ id: 'c3', title: 'Done', cards: [] }
];
}
function loadData() {
const stored = localStorage.getItem(STORAGE_KEY);
if (stored) { try { return JSON.parse(stored); } catch(e) { return getDefaultData(); } }
return getDefaultData();
}
function saveData(data) { localStorage.setItem(STORAGE_KEY, JSON.stringify(data)); }
let data = loadData();
function render() {
const board = document.getElementById('board');
board.innerHTML = '';
data.forEach(col => {
const colDiv = document.createElement('div');
colDiv.className = 'column';
let cardsHtml = col.cards.map(c => `<div class="card"><span>${c.title}</span><button class="del" data-col="${col.id}" data-card="${c.id}">×</button></div>`).join('');
colDiv.innerHTML = `<div class="col-header">${col.title}</div><div class="col-body">${cardsHtml}<div class="add-card" data-col="${col.id}">+ Tambah Card</div></div>`;
colDiv.querySelectorAll('.del').forEach(btn => btn.addEventListener('click', function() {
const col = data.find(c => c.id === this.dataset.col);
if (!col) return;
col.cards = col.cards.filter(c => c.id !== this.dataset.card);
saveData(data); render();
}));
colDiv.querySelector('.add-card').addEventListener('click', function() {
const title = prompt('Judul card:');
if (title && title.trim()) {
const col = data.find(c => c.id === this.dataset.col);
if (col) { col.cards.push({ id: 'k' + Date.now(), title: title.trim() }); saveData(data); render(); }
}
});
board.appendChild(colDiv);
});
}
document.getElementById('resetBtn').addEventListener('click', () => { if (confirm('Reset semua data?')) { data = getDefaultData(); saveData(data); render(); } });
render();
</script>
</body>
</html>
```

## Cara Integrasi
Fungsi saveData() dipanggil setiap kali ada perubahan pada data board. Fungsi loadData() dipanggil saat inisialisasi untuk memuat data yang tersimpan.
