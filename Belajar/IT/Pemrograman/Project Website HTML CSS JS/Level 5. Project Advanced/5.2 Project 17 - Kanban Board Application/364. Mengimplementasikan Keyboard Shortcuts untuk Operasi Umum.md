# 364. Mengimplementasikan Keyboard Shortcuts untuk Operasi Umum

## Definisi & Target
Menambahkan keyboard shortcuts untuk operasi umum seperti membuat card baru, undo, redo, dan navigasi. Targetnya adalah produktivitas pengguna yang lebih tinggi.

## Analogi Alur
Seperti shortcut Ctrl+C dan Ctrl+V di komputer. Shortcut keyboard mempercepat operasi yang sering dilakukan.

## Poin-Poin Penting
- Ctrl+N: Card baru
- Ctrl+Z: Undo
- Ctrl+Shift+Z / Ctrl+Y: Redo
- Ctrl+F: Focus search
- Escape: Tutup modal

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Keyboard Shortcuts</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; height: 100vh; }
.header { padding: 16px 24px; background: #16213e; color: #fff; display: flex; align-items: center; gap: 24px; }
.header .shortcuts { font-size: 12px; color: #888; display: flex; gap: 16px; }
kbd { background: #2a3a6a; padding: 2px 6px; border-radius: 4px; font-size: 11px; color: #ddd; }
.board { display: flex; gap: 16px; padding: 20px; height: calc(100vh - 60px); overflow-x: auto; }
.column { min-width: 280px; background: #1e2a4a; border-radius: 10px; display: flex; flex-direction: column; max-height: 100%; }
.col-header { padding: 12px 14px; color: #fff; font-weight: 600; }
.col-body { flex: 1; padding: 8px; overflow-y: auto; }
.card { background: #2a3a6a; color: #e0e0e0; padding: 10px 12px; border-radius: 6px; font-size: 13px; margin-bottom: 6px; }
.toast { position: fixed; bottom: 20px; right: 20px; background: #4CAF50; color: #fff; padding: 10px 20px; border-radius: 8px; font-size: 13px; display: none; }
.toast.show { display: block; }
</style>
</head>
<body>
<div class="header">
<span>📋 Keyboard Shortcuts</span>
<div class="shortcuts"><span><kbd>Ctrl+N</kbd> Card Baru</span><span><kbd>Ctrl+Z</kbd> Undo</span><span><kbd>Ctrl+Y</kbd> Redo</span></div>
</div>
<div class="board" id="board"></div>
<div class="toast" id="toast"></div>
<script>
const data = [{ id: 'c1', title: 'To Do', cards: [{ id: 'k1', title: 'Card 1' }] }, { id: 'c2', title: 'Done', cards: [] }];
function showToast(msg) { const t = document.getElementById('toast'); t.textContent = msg; t.classList.add('show'); setTimeout(() => t.classList.remove('show'), 1500); }
document.addEventListener('keydown', function(e) {
if (e.ctrlKey && e.key === 'n') {
e.preventDefault();
const title = prompt('Judul card baru:');
if (title && title.trim()) { data[0].cards.push({ id: 'k' + Date.now(), title }); showToast('Card baru dibuat!'); render(); }
}
if (e.ctrlKey && e.key === 'z' && !e.shiftKey) { e.preventDefault(); showToast('Undo (simulasi)'); }
if ((e.ctrlKey && e.key === 'y') || (e.ctrlKey && e.key === 'z' && e.shiftKey)) { e.preventDefault(); showToast('Redo (simulasi)'); }
if (e.key === 'Escape') { showToast('Modal ditutup'); }
if (e.ctrlKey && e.key === 'f') { e.preventDefault(); showToast('Focus search'); }
});
function render() {
const board = document.getElementById('board');
board.innerHTML = '';
data.forEach(col => {
const colDiv = document.createElement('div');
colDiv.className = 'column';
colDiv.innerHTML = `<div class="col-header">${col.title}</div><div class="col-body">${col.cards.map(c => `<div class="card">${c.title}</div>`).join('')}</div>`;
board.appendChild(colDiv);
});
}
render();
</script>
</body>
</html>
```

## Cara Integrasi
Event listener keyboard global menangani shortcut. Setiap shortcut memicu fungsi yang sesuai. Toast notification memberi feedback saat shortcut diaktifkan.
