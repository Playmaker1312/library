# 358. Mengimplementasikan Filter Card Berdasarkan Label atau Priority

## Definisi & Target
Membuat filter untuk menampilkan card berdasarkan label (Frontend, Backend, Design) atau priority (High, Medium, Low). Targetnya adalah visualisasi card yang lebih terfokus.

## Analogi Alur
Seperti kacamata dengan filter warna - hanya melihat sticky note dengan warna tertentu. Filter membantu fokus pada kategori tertentu.

## Poin-Poin Penting
- Dropdown atau button group untuk filter
- Filter berdasarkan label dan priority
- Bisa menggabungkan beberapa filter
- Card yang tidak sesuai disembunyikan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Filter Card</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; height: 100vh; }
.header { padding: 16px 24px; background: #16213e; color: #fff; display: flex; align-items: center; gap: 16px; flex-wrap: wrap; }
.header select { padding: 8px 12px; background: #2a3a6a; color: #fff; border: none; border-radius: 6px; font-size: 13px; outline: none; }
.board { display: flex; gap: 16px; padding: 20px; height: calc(100vh - 60px); overflow-x: auto; }
.column { min-width: 280px; background: #1e2a4a; border-radius: 10px; display: flex; flex-direction: column; max-height: 100%; }
.col-header { padding: 12px 14px; color: #fff; font-weight: 600; border-bottom: 1px solid rgba(255,255,255,0.1); }
.col-body { flex: 1; padding: 8px; overflow-y: auto; display: flex; flex-direction: column; gap: 6px; }
.card { background: #2a3a6a; color: #e0e0e0; padding: 10px 12px; border-radius: 6px; font-size: 13px; }
.card.hidden { display: none; }
.badge { font-size: 10px; padding: 2px 6px; border-radius: 4px; margin-left: 6px; }
.badge-fe { background: rgba(33,150,243,0.3); color: #64b5f6; }
.badge-be { background: rgba(156,39,176,0.3); color: #ce93d8; }
.badge-ds { background: rgba(255,152,0,0.3); color: #ffb74d; }
.badge-high { background: rgba(244,67,54,0.3); color: #ef9a9a; }
.badge-med { background: rgba(255,193,7,0.3); color: #ffd54f; }
.badge-low { background: rgba(76,175,80,0.3); color: #a5d6a7; }
</style>
</head>
<body>
<div class="header">
<span>📋 Filter</span>
<select id="filterLabel"><option value="">Semua Label</option><option value="Frontend">Frontend</option><option value="Backend">Backend</option><option value="Design">Design</option></select>
<select id="filterPriority"><option value="">Semua Priority</option><option value="high">High</option><option value="medium">Medium</option><option value="low">Low</option></select>
</div>
<div class="board" id="board"></div>
<script>
const data = [
{ id: 'c1', title: 'To Do', cards: [
{ id: 'k1', title: 'Buat Wireframe', label: 'Design', priority: 'high' },
{ id: 'k2', title: 'Riset', label: 'Frontend', priority: 'medium' }
]},
{ id: 'c2', title: 'In Progress', cards: [
{ id: 'k3', title: 'Header', label: 'Frontend', priority: 'high' },
{ id: 'k4', title: 'Database', label: 'Backend', priority: 'low' }
]}
];
function getBadge(label, priority) {
const lbl = label ? `<span class="badge badge-${label.toLowerCase().slice(0,2)}">${label}</span>` : '';
const pri = priority ? `<span class="badge badge-${priority}">${priority}</span>` : '';
return lbl + pri;
}
function render() {
const labelFilter = document.getElementById('filterLabel').value;
const priorityFilter = document.getElementById('filterPriority').value;
const board = document.getElementById('board');
board.innerHTML = '';
data.forEach(col => {
const colDiv = document.createElement('div');
colDiv.className = 'column';
let filtered = col.cards;
if (labelFilter) filtered = filtered.filter(c => c.label === labelFilter);
if (priorityFilter) filtered = filtered.filter(c => c.priority === priorityFilter);
colDiv.innerHTML = `<div class="col-header">${col.title}</div><div class="col-body">${filtered.map(c => `<div class="card">${c.title}${getBadge(c.label, c.priority)}</div>`).join('')}</div>`;
board.appendChild(colDiv);
});
}
document.getElementById('filterLabel').addEventListener('change', render);
document.getElementById('filterPriority').addEventListener('change', render);
render();
</script>
</body>
</html>
```

## Cara Integrasi
Filter bekerja dengan menyaring array cards berdasarkan nilai label dan priority sebelum di-render. Dropdown filter memicu ulang render().
