# 357. Mengimplementasikan Fitur Search Card di Seluruh Board

## Definisi & Target
Membuat fitur pencarian card di seluruh board yang memfilter card berdasarkan judul. Targetnya adalah menemukan card tertentu dengan cepat.

## Analogi Alur
Seperti mesin pencari yang memindai semua sticky note di papan dan hanya menampilkan yang cocok dengan kata kunci.

## Poin-Poin Penting
- Input search di header board
- Filter card secara real-time
- Card yang tidak cocok disembunyikan
- Kolom tetap terlihat meskipun tidak ada card yang cocok

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Search Card</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; height: 100vh; }
.header { padding: 16px 24px; background: #16213e; color: #fff; display: flex; align-items: center; gap: 16px; }
.header input { padding: 8px 14px; border: none; border-radius: 6px; font-size: 14px; background: #2a3a6a; color: #fff; outline: none; width: 280px; }
.header input::placeholder { color: #888; }
.board { display: flex; gap: 16px; padding: 20px; height: calc(100vh - 60px); overflow-x: auto; }
.column { min-width: 280px; background: #1e2a4a; border-radius: 10px; display: flex; flex-direction: column; max-height: 100%; }
.col-header { padding: 12px 14px; color: #fff; font-weight: 600; border-bottom: 1px solid rgba(255,255,255,0.1); }
.col-body { flex: 1; padding: 8px; overflow-y: auto; display: flex; flex-direction: column; gap: 6px; }
.card { background: #2a3a6a; color: #e0e0e0; padding: 10px 12px; border-radius: 6px; font-size: 13px; }
.card.hidden { display: none; }
</style>
</head>
<body>
<div class="header"><span>📋 Search Card</span><input type="text" id="searchInput" placeholder="Cari card..."></div>
<div class="board" id="board"></div>
<script>
const data = [
{ id: 'c1', title: 'To Do', cards: [{ id: 'k1', title: 'Buat Wireframe' }, { id: 'k2', title: 'Riset Pengguna' }] },
{ id: 'c2', title: 'In Progress', cards: [{ id: 'k3', title: 'Buat Header Navigation' }, { id: 'k4', title: 'Buat Footer' }] },
{ id: 'c3', title: 'Done', cards: [{ id: 'k5', title: 'Setup Project' }, { id: 'k6', title: 'Buat Database' }] }
];
function render(filter = '') {
const board = document.getElementById('board');
board.innerHTML = '';
data.forEach(col => {
const colDiv = document.createElement('div');
colDiv.className = 'column';
const filtered = filter ? col.cards.filter(c => c.title.toLowerCase().includes(filter.toLowerCase())) : col.cards;
colDiv.innerHTML = `<div class="col-header">${col.title}</div><div class="col-body">${filtered.map(c => `<div class="card">${c.title}</div>`).join('')}</div>`;
board.appendChild(colDiv);
});
}
document.getElementById('searchInput').addEventListener('input', e => render(e.target.value));
render();
</script>
</body>
</html>
```

## Cara Integrasi
Search input di header memicu filter pada semua card. Hanya card yang judulnya mengandung kata kunci yang ditampilkan.
