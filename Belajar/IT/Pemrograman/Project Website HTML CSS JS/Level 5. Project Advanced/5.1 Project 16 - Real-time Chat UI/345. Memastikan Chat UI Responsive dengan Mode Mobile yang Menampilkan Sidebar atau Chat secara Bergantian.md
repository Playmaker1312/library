# 345. Memastikan Chat UI Responsive dengan Mode Mobile yang Menampilkan Sidebar atau Chat secara Bergantian

## Definisi & Target
Membuat chat UI yang responsif untuk mobile dengan mode di mana sidebar dan area chat ditampilkan secara bergantian (toggle). Targetnya adalah pengalaman mobile yang optimal.

## Analogi Alur
Seperti aplikasi chat di ponsel yang hanya menampilkan satu layar dalam satu waktu - daftar chat atau percakapan. Pengguna berpindah dengan menekan tombol back atau memilih kontak.

## Poin-Poin Penting
- Media query untuk mendeteksi layar mobile
- Sidebar dan chat tidak tampil bersamaan di mobile
- Tombol back untuk kembali ke sidebar
- Animasi transisi antar tampilan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Chat Responsive Mobile</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; height: 100vh; background: #f0f2f5; }
.chat-container { display: grid; grid-template-columns: 350px 1fr; height: 100vh; max-width: 1400px; margin: 0 auto; background: #fff; }
.sidebar { background: #fff; border-right: 1px solid #e0e0e0; display: flex; flex-direction: column; }
.main-panel { display: flex; flex-direction: column; background: #f7f8fa; }
.header { padding: 16px; background: #f0f2f5; border-bottom: 1px solid #e0e0e0; font-weight: 600; display: flex; align-items: center; gap: 12px; }
.back-btn { display: none; background: none; border: none; font-size: 20px; cursor: pointer; color: #333; }
.placeholder { flex: 1; display: flex; align-items: center; justify-content: center; color: #888; }
@media (max-width: 768px) {
.chat-container { grid-template-columns: 1fr; position: relative; }
.sidebar { position: absolute; inset: 0; z-index: 2; transition: transform 0.3s; }
.main-panel { position: absolute; inset: 0; z-index: 1; }
.sidebar.hide { transform: translateX(-100%); }
.back-btn { display: block; }
}
</style>
</head>
<body>
<div class="chat-container">
<div class="sidebar" id="sidebar">
<div class="header">Kontak</div>
<div class="placeholder" style="cursor:pointer" onclick="openChat()">Klik untuk buka chat</div>
</div>
<div class="main-panel" id="mainPanel">
<div class="header"><button class="back-btn" id="backBtn" onclick="closeChat()">←</button><span>Percakapan</span></div>
<div class="placeholder">Pilih kontak untuk memulai chat</div>
</div>
</div>
<script>
const sidebar = document.getElementById('sidebar');
const backBtn = document.getElementById('backBtn');
function openChat() { if (window.innerWidth <= 768) sidebar.classList.add('hide'); }
function closeChat() { sidebar.classList.remove('hide'); }
window.addEventListener('resize', () => { if (window.innerWidth > 768) sidebar.classList.remove('hide'); });
</script>
</body>
</html>
```

## Cara Integrasi
Gunakan media query untuk mode mobile. Sidebar dan main panel menggunakan position absolute di mobile dengan toggle class hide untuk bergantian tampil.
