# 344. Membuat Unread Message Separator dalam Percakapan

## Definisi & Target
Menambahkan pemisah visual dalam percakapan yang menunjukkan batas antara pesan yang sudah dibaca dan yang belum dibaca. Targetnya adalah memberikan indikasi pesan baru dalam percakapan.

## Analogi Alur
Seperti garis pemisah di buku yang menandai "Anda berhenti di sini terakhir kali". Separator membantu pengguna menyadari di mana pesan baru dimulai.

## Poin-Poin Penting
- Garis dengan teks "Pesan Baru" di tengah
- Warna berbeda untuk menarik perhatian
- Posisi di antara pesan lama dan baru
- Efek transisi saat muncul

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Unread Separator</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #efeae2; display: flex; justify-content: center; padding: 20px; }
.chat { width: 500px; background: #efeae2; border-radius: 12px; padding: 20px; }
.msg { display: flex; margin-bottom: 8px; }
.msg.left { justify-content: flex-start; }
.msg.right { justify-content: flex-end; }
.bubble { max-width: 75%; padding: 8px 14px; font-size: 14px; border-radius: 8px; }
.msg.left .bubble { background: #fff; }
.msg.right .bubble { background: #dcf8c6; }
.separator { display: flex; align-items: center; margin: 16px 0; gap: 12px; }
.separator::before, .separator::after { content: ''; flex: 1; height: 1px; background: #e53935; }
.separator span { font-size: 12px; font-weight: 600; color: #e53935; background: #efeae2; padding: 0 12px; white-space: nowrap; }
</style>
</head>
<body>
<div class="chat">
<div class="msg left"><div class="bubble">Halo, bagaimana progressnya?</div></div>
<div class="msg right"><div class="bubble">Sudah 80%, tinggal finalisasi</div></div>
<div class="msg left"><div class="bubble">Baik, kapan bisa selesai?</div></div>
<div class="separator"><span>Pesan Baru</span></div>
<div class="msg right"><div class="bubble">Sudah selesai! Saya kirim filenya</div></div>
<div class="msg left"><div class="bubble">Terima kasih, saya cek dulu</div></div>
</div>
</body>
</html>
```

## Cara Integrasi
Separator disisipkan di antara pesan-pesan di area chat. Muncul saat ada pesan baru yang diterima setelah sesi chat sebelumnya.
