# 332. Mengimplementasikan Timestamp pada Setiap Pesan

## Definisi & Target
Menambahkan timestamp (waktu pengiriman) pada setiap bubble chat. Targetnya adalah setiap pesan menampilkan jam pengiriman dengan format yang rapi.

## Analogi Alur
Seperti stempel waktu pada setiap surat yang menunjukkan kapan surat itu dikirim. Pengguna bisa melihat kapan pesan dikirim.

## Poin-Poin Penting
- Timestamp ditempatkan di dalam atau di bawah bubble
- Format waktu: HH:MM (24 jam) atau HH:MM AM/PM
- Timestamp berukuran kecil dengan warna lebih redup
- Posisi timestamp menyesuaikan dengan alignment bubble

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Timestamp Pesan</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #efeae2; display: flex; justify-content: center; padding: 20px; }
.chat { width: 500px; background: #efeae2; border-radius: 12px; padding: 20px; }
.msg { display: flex; margin-bottom: 8px; }
.msg.left { justify-content: flex-start; }
.msg.right { justify-content: flex-end; }
.bubble { max-width: 75%; padding: 8px 14px; font-size: 14px; line-height: 1.45; }
.msg.left .bubble { background: #fff; border-radius: 8px 8px 8px 0; }
.msg.right .bubble { background: #dcf8c6; border-radius: 8px 8px 0 8px; }
.time { font-size: 11px; color: #999; margin-top: 4px; text-align: right; }
</style>
</head>
<body>
<div class="chat">
<div class="msg left"><div class="bubble">Halo, selamat siang!<div class="time">12:30</div></div></div>
<div class="msg right"><div class="bubble">Siang, ada yang bisa dibantu?<div class="time">12:31</div></div></div>
<div class="msg left"><div class="bubble">Saya mau tanya soal status pesanan saya<div class="time">12:32</div></div></div>
<div class="msg right"><div class="bubble">Baik, saya cek dulu ya<div class="time">12:33</div></div></div>
</div>
</body>
</html>
```

## Cara Integrasi
Timestamp ditambahkan sebagai elemen div dengan class time di dalam bubble. JavaScript akan mengisi timestamp otomatis saat pesan dikirim menggunakan new Date().
