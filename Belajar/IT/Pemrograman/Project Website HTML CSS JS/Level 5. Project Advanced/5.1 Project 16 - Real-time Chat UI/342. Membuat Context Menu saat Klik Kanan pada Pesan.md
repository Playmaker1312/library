# 342. Membuat Context Menu saat Klik Kanan pada Pesan

## Definisi & Target
Membangun context menu yang muncul saat pengguna melakukan klik kanan pada bubble chat. Targetnya adalah menyediakan aksi-aksi tambahan seperti copy, delete, atau reply.

## Analogi Alur
Seperti menu yang muncul saat Anda klik kanan pada file di komputer. Menu tersebut menampilkan opsi-opsi yang relevan dengan item yang diklik.

## Poin-Poin Penting
- Context menu muncul di posisi klik kanan
- Menu berisi option: Copy, Forward, Delete, Reply
- Menu hilang saat klik di luar
- Posisi menu menyesuaikan dengan viewport

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Context Menu</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #efeae2; display: flex; justify-content: center; padding: 20px; }
.chat { width: 500px; background: #efeae2; border-radius: 12px; padding: 20px; }
.msg { display: flex; margin-bottom: 8px; }
.msg.left { justify-content: flex-start; }
.msg.right { justify-content: flex-end; }
.bubble { max-width: 75%; padding: 8px 14px; font-size: 14px; border-radius: 8px; cursor: context-menu; }
.msg.left .bubble { background: #fff; }
.msg.right .bubble { background: #dcf8c6; }
.context-menu { display: none; position: fixed; background: #fff; border-radius: 8px; box-shadow: 0 4px 16px rgba(0,0,0,0.15); padding: 4px 0; min-width: 160px; z-index: 1000; }
.context-menu.show { display: block; }
.context-menu div { padding: 10px 16px; font-size: 13px; cursor: pointer; }
.context-menu div:hover { background: #f5f5f5; }
.context-menu .divider { height: 1px; background: #e0e0e0; padding: 0; margin: 4px 0; }
</style>
</head>
<body>
<div class="chat">
<div class="msg left"><div class="bubble" data-msg="Halo, selamat siang">Halo, selamat siang</div></div>
<div class="msg right"><div class="bubble" data-msg="Siang, ada yang bisa dibantu?">Siang, ada yang bisa dibantu?</div></div>
<div class="msg left"><div class="bubble" data-msg="Saya mau tanya soal order">Saya mau tanya soal order</div></div>
</div>
<div class="context-menu" id="contextMenu">
<div onclick="alert('Copy: ' + selectedMsg)">Salin Pesan</div>
<div onclick="alert('Reply to: ' + selectedMsg)">Balas Pesan</div>
<div class="divider"></div>
<div onclick="alert('Forward: ' + selectedMsg)" style="color:#e53935">Hapus Pesan</div>
</div>
<script>
let selectedMsg = '';
document.querySelectorAll('.bubble').forEach(b => {
b.addEventListener('contextmenu', function(e) {
e.preventDefault();
selectedMsg = this.dataset.msg;
const menu = document.getElementById('contextMenu');
menu.style.left = Math.min(e.clientX, window.innerWidth - 180) + 'px';
menu.style.top = Math.min(e.clientY, window.innerHeight - 160) + 'px';
menu.classList.add('show');
});
});
document.addEventListener('click', () => document.getElementById('contextMenu').classList.remove('show'));
</script>
</body>
</html>
```

## Cara Integrasi
Context menu terintegrasi dengan event contextmenu pada setiap bubble. Posisi menu disesuaikan agar tidak keluar dari viewport.
