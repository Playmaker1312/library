# 338. Membuat Typing Indicator yang Muncul saat Kontak Sedang Mengetik

## Definisi & Target
Membuat indikator visual yang menunjukkan bahwa kontak sedang mengetik pesan. Targetnya adalah memberikan feedback real-time tentang aktivitas kontak.

## Analogi Alur
Seperti melihat seseorang sedang menulis di depan Anda - Anda bisa melihat gerakan tangannya. Typing indicator adalah versi digital dari isyarat tersebut.

## Poin-Poin Penting
- Animasi tiga titik (dots) yang bergerak
- Teks "sedang mengetik..." di samping animasi
- Indikator muncul di area chat
- Indikator otomatis hilang setelah beberapa detik

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Typing Indicator</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #efeae2; display: flex; justify-content: center; padding: 20px; }
.chat { width: 500px; background: #efeae2; border-radius: 12px; padding: 20px; }
.msg { display: flex; margin-bottom: 8px; }
.msg.left { justify-content: flex-start; }
.msg.right { justify-content: flex-end; }
.bubble { max-width: 75%; padding: 8px 14px; font-size: 14px; border-radius: 8px; }
.msg.left .bubble { background: #fff; border-bottom-left-radius: 0; }
.msg.right .bubble { background: #dcf8c6; border-bottom-right-radius: 0; }
.typing-indicator { display: none; align-items: center; gap: 8px; padding: 8px 0; }
.typing-indicator.show { display: flex; }
.typing-indicator .avatar { width: 32px; height: 32px; border-radius: 50%; background: #ddd; display: flex; align-items: center; justify-content: center; font-size: 12px; color: #fff; font-weight: 600; }
.typing-indicator .dots { display: flex; gap: 3px; }
.typing-indicator .dots span { width: 6px; height: 6px; background: #888; border-radius: 50%; animation: bounce 1.2s infinite; }
.typing-indicator .dots span:nth-child(2) { animation-delay: 0.2s; }
.typing-indicator .dots span:nth-child(3) { animation-delay: 0.4s; }
@keyframes bounce { 0%,60%,100% { transform: translateY(0); } 30% { transform: translateY(-6px); } }
.typing-text { font-size: 12px; color: #888; }
</style>
</head>
<body>
<div class="chat">
<div class="msg right"><div class="bubble">Halo, selamat sore</div></div>
<div class="msg left"><div class="bubble">Selamat sore, ada yang bisa dibantu?</div></div>
<div class="typing-indicator show" id="typingIndicator">
<div class="avatar" style="background:#4CAF50">B</div>
<div class="dots"><span></span><span></span><span></span></div>
<span class="typing-text">Budi sedang mengetik...</span>
</div>
<button id="toggleTyping" style="margin-top:12px;padding:8px 16px;background:#4CAF50;color:#fff;border:none;border-radius:6px;cursor:pointer;">Toggle Typing</button>
</div>
<script>
const indicator = document.getElementById('typingIndicator');
document.getElementById('toggleTyping').addEventListener('click', () => {
indicator.classList.toggle('show');
});
</script>
</body>
</html>
```

## Cara Integrasi
Typing indicator ditempatkan di bagian bawah area chat, di atas input. Indikator akan muncul saat ada event typing dari kontak dan hilang setelah berhenti mengetik.
