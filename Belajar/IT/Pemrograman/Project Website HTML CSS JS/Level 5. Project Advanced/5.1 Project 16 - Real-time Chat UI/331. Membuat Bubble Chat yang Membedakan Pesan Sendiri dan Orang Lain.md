# 331. Membuat Bubble Chat yang Membedakan Pesan Sendiri dan Orang Lain

## Definisi & Target
Membuat bubble chat dengan gaya visual yang berbeda antara pesan sendiri dan pesan orang lain. Targetnya adalah pembeda yang jelas dan estetis.

## Analogi Alur
Seperti amplop surat dengan warna berbeda - amplop biru untuk surat masuk dan amplop hijau untuk surat keluar. Perbedaan warna memudahkan identifikasi.

## Poin-Poin Penting
- Pesan sendiri: background hijau (#dcf8c6), di kanan
- Pesan orang lain: background putih, di kiri
- Border radius berbeda untuk membedakan arah
- Efek shadow ringan untuk kedalaman

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Bubble Chat</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #e5ddd5; display: flex; justify-content: center; align-items: center; min-height: 100vh; }
.chat-bg { width: 500px; background: #efeae2; border-radius: 12px; padding: 20px; box-shadow: 0 4px 20px rgba(0,0,0,0.1); }
.msg { display: flex; margin-bottom: 8px; }
.msg.left { justify-content: flex-start; }
.msg.right { justify-content: flex-end; }
.bubble { max-width: 75%; padding: 8px 14px; font-size: 14px; line-height: 1.45; position: relative; }
.msg.left .bubble { background: #fff; border-radius: 8px 8px 8px 0; box-shadow: 0 1px 1px rgba(0,0,0,0.05); color: #111; }
.msg.right .bubble { background: #dcf8c6; border-radius: 8px 8px 0 8px; box-shadow: 0 1px 1px rgba(0,0,0,0.05); color: #111; }
</style>
</head>
<body>
<div class="chat-bg">
<div class="msg left"><div class="bubble">Halo, selamat pagi!</div></div>
<div class="msg right"><div class="bubble">Selamat pagi juga, ada yang bisa dibantu?</div></div>
<div class="msg left"><div class="bubble">Saya mau order produk yang kemarin</div></div>
<div class="msg right"><div class="bubble">Baik, silakan klik link ini untuk checkout</div></div>
</div>
</body>
</html>
```

## Cara Integrasi
Gunakan class left dan right untuk membedakan arah pesan. CSS akan mengatur tampilan bubble sesuai dengan class yang diberikan.
