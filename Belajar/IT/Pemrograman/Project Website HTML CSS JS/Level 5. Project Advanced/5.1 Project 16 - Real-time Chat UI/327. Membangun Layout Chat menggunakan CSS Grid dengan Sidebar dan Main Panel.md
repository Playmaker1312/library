# 327. Membangun Layout Chat menggunakan CSS Grid dengan Sidebar dan Main Panel

## Definisi & Target
Mengimplementasikan layout utama aplikasi chat menggunakan CSS Grid agar tata letak lebih fleksibel dan rapi. Targetnya adalah layout yang stabil dan responsif.

## Analogi Alur
Seperti membagi ruangan menjadi dua bagian dengan partisi yang bisa digeser. CSS Grid berfungsi sebagai kerangka partisi yang kokoh.

## Poin-Poin Penting
- CSS Grid membagi halaman menjadi dua kolom utama
- Grid template columns menentukan lebar sidebar dan main panel
- Grid memudahkan pengaturan spacing dan alignment
- Layout bisa dengan mudah diubah untuk mode mobile

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Chat Layout - CSS Grid</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; height: 100vh; background: #f0f2f5; }
.chat-container { display: grid; grid-template-columns: 350px 1fr; height: 100vh; max-width: 1400px; margin: 0 auto; background: #fff; box-shadow: 0 0 20px rgba(0,0,0,0.05); }
.sidebar { background: #fff; border-right: 1px solid #e0e0e0; display: flex; flex-direction: column; overflow: hidden; }
.main-panel { display: flex; flex-direction: column; background: #f7f8fa; overflow: hidden; }
@media (max-width: 768px) { .chat-container { grid-template-columns: 1fr; } }
</style>
</head>
<body>
<div class="chat-container">
<div class="sidebar"></div>
<div class="main-panel"></div>
</div>
</body>
</html>
```

## Cara Integrasi
Terapkan CSS grid ini sebagai layout utama. Semua elemen chat akan ditempatkan di dalam sidebar dan main-panel. Pada mode mobile, grid berubah menjadi satu kolom penuh.
