# 333. Mengimplementasikan Status Pesan yaitu Sent, Delivered, dan Read menggunakan Ikon

## Definisi & Target
Menambahkan indikator status pesan berupa ikon yang menunjukkan apakah pesan sudah terkirim (sent), terkirim (delivered), atau sudah dibaca (read). Targetnya adalah memberikan feedback visual pengiriman pesan.

## Analogi Alur
Seperti tanda centang pada layar pengiriman paket: satu centang berarti sudah dikirim, dua centang berarti sudah sampai, dua centang biru berarti sudah dibaca.

## Poin-Poin Penting
- Sent: satu centang abu-abu
- Delivered: dua centang abu-abu
- Read: dua centang biru
- Ikon ditempatkan di sebelah timestamp

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Status Pesan</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #efeae2; display: flex; justify-content: center; padding: 20px; }
.chat { width: 500px; background: #efeae2; border-radius: 12px; padding: 20px; }
.msg { display: flex; margin-bottom: 8px; justify-content: flex-end; }
.bubble { max-width: 75%; padding: 8px 14px; background: #dcf8c6; border-radius: 8px 8px 0 8px; font-size: 14px; }
.meta { display: flex; align-items: center; justify-content: flex-end; gap: 4px; margin-top: 2px; }
.time { font-size: 11px; color: #999; }
.status { font-size: 14px; }
.status.sent { color: #999; }
.status.delivered { color: #999; }
.status.read { color: #53bdeb; }
</style>
</head>
<body>
<div class="chat">
<div class="msg"><div class="bubble">Halo, apa kabar?<div class="meta"><span class="time">12:30</span><span class="status sent">✓</span></div></div></div>
<div class="msg"><div class="bubble">Tolong cek file yang saya kirim<div class="meta"><span class="time">12:31</span><span class="status delivered">✓✓</span></div></div></div>
<div class="msg"><div class="bubble">Sudah saya baca, terima kasih<div class="meta"><span class="time">12:32</span><span class="status read">✓✓</span></div></div></div>
</div>
<script>
setTimeout(() => {
const statuses = document.querySelectorAll('.status');
statuses.forEach(s => {
if (s.classList.contains('sent')) { s.textContent = '✓'; s.className = 'status sent'; }
else if (s.classList.contains('delivered')) { s.textContent = '✓✓'; s.className = 'status delivered'; }
else if (s.classList.contains('read')) { s.textContent = '✓✓'; s.className = 'status read'; }
});
}, 1000);
</script>
</body>
</html>
```

## Cara Integrasi
Status pesan ditentukan oleh data status dari objek pesan. Ikon centang diganti berdasarkan status: "✓" untuk sent, "✓✓" untuk delivered, dan "✓✓" berwarna biru untuk read.
