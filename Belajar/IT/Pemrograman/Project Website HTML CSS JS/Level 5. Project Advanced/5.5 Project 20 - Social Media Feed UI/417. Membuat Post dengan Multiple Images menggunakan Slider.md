# 417. Membuat Post dengan Multiple Images menggunakan Slider

## Definisi & Target
Membuat post yang bisa menampilkan beberapa gambar dalam bentuk slider/carousel. Targetnya adalah post dengan multiple media.

## Analogi Alur
Seperti album foto yang bisa digeser untuk melihat foto berikutnya. Pengguna bisa melihat beberapa gambar dalam satu post.

## Poin-Poin Penting
- Container slider dengan overflow hidden
- Navigasi dots atau arrow
- Geser (swipe) untuk mobile
- Indikator posisi gambar

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Multiple Images Slider</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; display: flex; justify-content: center; padding: 20px; }
.post { background: #fff; border-radius: 12px; max-width: 500px; width: 100%; box-shadow: 0 1px 4px rgba(0,0,0,0.06); overflow: hidden; }
.slider-container { position: relative; }
.slider { display: flex; overflow: hidden; }
.slider-inner { display: flex; transition: transform 0.3s ease; }
.slider-inner img { width: 100%; flex-shrink: 0; }
.dots { display: flex; justify-content: center; gap: 6px; padding: 10px 0; }
.dots span { width: 8px; height: 8px; border-radius: 50%; background: #ddd; cursor: pointer; }
.dots span.active { background: #1877f2; }
.arrow { position: absolute; top: 50%; transform: translateY(-50%); background: rgba(255,255,255,0.9); border: none; width: 32px; height: 32px; border-radius: 50%; cursor: pointer; font-size: 16px; display: flex; align-items: center; justify-content: center; box-shadow: 0 1px 4px rgba(0,0,0,0.1); }
.arrow.prev { left: 8px; }
.arrow.next { right: 8px; }
</style>
</head>
<body>
<div class="post">
<p style="padding:12px 16px 0;font-size:14px;">Liburan akhir pekan! 🏖️</p>
<div class="slider-container">
<div class="slider"><div class="slider-inner" id="sliderInner">
<img src="https://via.placeholder.com/468x300/4CAF50/fff?text=Photo+1" alt="Photo 1">
<img src="https://via.placeholder.com/468x300/2196F3/fff?text=Photo+2" alt="Photo 2">
<img src="https://via.placeholder.com/468x300/FF9800/fff?text=Photo+3" alt="Photo 3">
</div></div>
<button class="arrow prev" id="prevBtn">‹</button>
<button class="arrow next" id="nextBtn">›</button>
</div>
<div class="dots" id="dots"><span class="active"></span><span></span><span></span></div>
</div>
<script>
const inner = document.getElementById('sliderInner');
const dots = document.querySelectorAll('#dots span');
const prevBtn = document.getElementById('prevBtn');
const nextBtn = document.getElementById('nextBtn');
let current = 0;
const total = 3;
function goTo(index) { current = index; inner.style.transform = `translateX(-${current * 100}%)`; dots.forEach((d, i) => d.classList.toggle('active', i === current)); }
prevBtn.addEventListener('click', () => goTo((current - 1 + total) % total));
nextBtn.addEventListener('click', () => goTo((current + 1) % total));
dots.forEach((d, i) => d.addEventListener('click', () => goTo(i)));
</script>
</body>
</html>
```

## Cara Integrasi
Slider menggunakan transform: translateX untuk bergerak antar gambar. Dots dan arrow memberikan navigasi. Jumlah gambar bisa dinamis sesuai array images post.
