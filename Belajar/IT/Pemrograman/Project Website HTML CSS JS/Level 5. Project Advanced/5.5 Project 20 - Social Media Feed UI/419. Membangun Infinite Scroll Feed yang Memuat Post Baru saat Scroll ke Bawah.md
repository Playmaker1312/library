# 419. Membangun Infinite Scroll Feed yang Memuat Post Baru saat Scroll ke Bawah

## Definisi & Target
Membangun infinite scroll di mana post baru dimuat secara otomatis saat pengguna scroll ke bagian bawah halaman. Targetnya adalah feed yang tidak terbatas.

## Analogi Alur
Seperti majalah yang terus menampilkan halaman baru saat Anda membaca sampai bawah. Post baru dimuat secara otomatis tanpa tombol "Load More".

## Poin-Poin Penting
- Intersection Observer API atau scroll event
- Deteksi ketika scroll mencapai 80% bawah
- Muat post baru dari data
- Loading indicator di bagian bawah

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Infinite Scroll</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; display: flex; justify-content: center; padding: 20px; }
.feed { max-width: 500px; width: 100%; }
.post { background: #fff; border-radius: 12px; padding: 16px; margin-bottom: 12px; box-shadow: 0 1px 4px rgba(0,0,0,0.06); }
.post .user { display: flex; align-items: center; gap: 10px; margin-bottom: 10px; }
.post .avatar { width: 36px; height: 36px; border-radius: 50%; display: flex; align-items: center; justify-content: center; color: #fff; font-weight: 600; font-size: 13px; }
.post .name { font-weight: 600; font-size: 14px; }
.post .text { font-size: 14px; color: #333; }
.loading { text-align: center; padding: 20px; color: #888; font-size: 13px; display: none; }
.loading.show { display: block; }
.spinner { display: inline-block; width: 24px; height: 24px; border: 3px solid #ddd; border-top-color: #1877f2; border-radius: 50%; animation: spin 0.8s linear infinite; margin-bottom: 8px; }
@keyframes spin { to { transform: rotate(360deg); } }
</style>
</head>
<body>
<div class="feed" id="feed">
<div class="loading show" id="loading"><div class="spinner"></div><br>Memuat post...</div>
</div>
<script>
const feed = document.getElementById('feed');
const loading = document.getElementById('loading');
let page = 0;
const samplePosts = [
{ name: 'Budi Santoso', avatar: 'BS', color: '#4CAF50', text: 'Belajar JavaScript seru!' },
{ name: 'Siti Rahmawati', avatar: 'SR', color: '#2196F3', text: 'Hari ini liburan di pantai 🏖️' },
{ name: 'Ahmad Fauzi', avatar: 'AF', color: '#FF9800', text: 'Project baru hampir selesai!' },
{ name: 'Dewi Lestari', avatar: 'DL', color: '#9C27B0', text: 'Belajar CSS Grid hari ini 📐' },
{ name: 'Rudi Hermawan', avatar: 'RH', color: '#F44336', text: 'Ngoding sambil ngopi ☕' }
];
function loadPosts() {
loading.classList.add('show');
setTimeout(() => {
for (let i = 0; i < 3; i++) {
const p = samplePosts[(page * 3 + i) % samplePosts.length];
const div = document.createElement('div');
div.className = 'post';
div.innerHTML = `<div class="user"><div class="avatar" style="background:${p.color}">${p.avatar}</div><div class="name">${p.name}</div></div><div class="text">${p.text} (post #${page * 3 + i + 1})</div>`;
feed.insertBefore(div, loading);
}
page++;
loading.classList.remove('show');
}, 800);
}
window.addEventListener('scroll', () => {
if (window.innerHeight + window.scrollY >= document.body.offsetHeight - 300) loadPosts();
});
loadPosts();
</script>
</body>
</html>
```

## Cara Integrasi
Infinite scroll menggunakan window scroll event. Jika scroll mencapai 300px dari bawah, post baru dimuat. Loading spinner ditampilkan selama proses muat data.
