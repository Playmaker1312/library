# 424. Membangun Modal untuk Membuat Post Baru dengan Preview

## Definisi & Target
Membangun modal untuk membuat post baru yang berisi textarea, upload gambar, dan preview. Targetnya adalah pembuatan post yang mudah dan visual.

## Analogi Alur
Seperti membuka jendela baru untuk menulis status di media sosial. Anda bisa menulis teks, menambahkan foto, dan melihat preview sebelum mempublikasikan.

## Poin-Poin Penting
- Modal dengan form create post
- Textarea untuk konten teks
- Upload gambar dengan preview
- Tombol Post untuk publikasi

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Buat Post Baru</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; display: flex; justify-content: center; padding: 40px; }
.open-btn { padding: 12px 24px; background: #1877f2; color: #fff; border: none; border-radius: 8px; cursor: pointer; font-size: 14px; font-weight: 600; }
.modal { display: none; position: fixed; inset: 0; background: rgba(0,0,0,0.5); align-items: center; justify-content: center; z-index: 100; }
.modal.show { display: flex; }
.modal-content { background: #fff; border-radius: 16px; width: 480px; max-width: 92vw; max-height: 90vh; overflow-y: auto; }
.modal-header { display: flex; justify-content: space-between; align-items: center; padding: 16px 20px; border-bottom: 1px solid #e0e0e0; }
.modal-header h3 { font-size: 16px; }
.modal-header .close { background: none; border: none; font-size: 24px; cursor: pointer; color: #888; }
.modal-body { padding: 16px 20px; }
.modal-body textarea { width: 100%; padding: 12px; border: none; font-size: 14px; font-family: inherit; min-height: 120px; resize: vertical; outline: none; }
.upload-area { border: 2px dashed #ddd; border-radius: 12px; padding: 30px; text-align: center; cursor: pointer; margin-top: 12px; }
.upload-area:hover { border-color: #1877f2; background: #f0f7ff; }
.upload-area p { color: #888; font-size: 13px; }
.preview-area { margin-top: 12px; display: none; position: relative; }
.preview-area img { max-width: 100%; max-height: 250px; border-radius: 8px; }
.preview-area .remove { position: absolute; top: 8px; right: 8px; background: rgba(0,0,0,0.6); color: #fff; border: none; border-radius: 50%; width: 28px; height: 28px; cursor: pointer; font-size: 14px; }
.modal-footer { display: flex; justify-content: flex-end; gap: 10px; padding: 12px 20px; border-top: 1px solid #e0e0e0; }
.modal-footer button { padding: 10px 24px; border: none; border-radius: 8px; cursor: pointer; font-size: 13px; font-weight: 600; }
.btn-post { background: #1877f2; color: #fff; }
.btn-cancel { background: #e0e0e0; color: #333; }
input[type="file"] { display: none; }
</style>
</head>
<body>
<button class="open-btn" id="openModalBtn">📝 Buat Post</button>
<div class="modal" id="createPostModal">
<div class="modal-content">
<div class="modal-header"><h3>Buat Postingan</h3><button class="close" id="closeModalBtn">×</button></div>
<div class="modal-body">
<textarea id="postText" placeholder="Apa yang Anda pikirkan..."></textarea>
<div class="upload-area" id="uploadArea"><p>📷 Tambahkan foto ke postingan Anda</p></div>
<input type="file" id="fileInput" accept="image/*">
<div class="preview-area" id="previewArea"><img id="previewImg"><button class="remove" id="removeImg">×</button></div>
</div>
<div class="modal-footer"><button class="btn-cancel" id="cancelBtn">Batal</button><button class="btn-post" id="postBtn">Posting</button></div>
</div>
</div>
<script>
const modal = document.getElementById('createPostModal');
const openBtn = document.getElementById('openModalBtn');
const closeBtn = document.getElementById('closeModalBtn');
const cancelBtn = document.getElementById('cancelBtn');
const postBtn = document.getElementById('postBtn');
const uploadArea = document.getElementById('uploadArea');
const fileInput = document.getElementById('fileInput');
const previewArea = document.getElementById('previewArea');
const previewImg = document.getElementById('previewImg');
const removeImg = document.getElementById('removeImg');
const postText = document.getElementById('postText');
openBtn.addEventListener('click', () => modal.classList.add('show'));
closeBtn.addEventListener('click', () => modal.classList.remove('show'));
cancelBtn.addEventListener('click', () => modal.classList.remove('show'));
modal.addEventListener('click', (e) => { if (e.target === modal) modal.classList.remove('show'); });
uploadArea.addEventListener('click', () => fileInput.click());
fileInput.addEventListener('change', function() {
if (this.files[0] && this.files[0].type.startsWith('image/')) {
const reader = new FileReader();
reader.onload = (e) => { previewImg.src = e.target.result; previewArea.style.display = 'block'; uploadArea.style.display = 'none'; };
reader.readAsDataURL(this.files[0]);
}
});
removeImg.addEventListener('click', () => { previewArea.style.display = 'none'; uploadArea.style.display = 'block'; fileInput.value = ''; });
postBtn.addEventListener('click', () => {
const text = postText.value.trim();
if (!text) return alert('Silakan tulis sesuatu!');
alert('Postingan berhasil dibuat!\n\n' + text);
modal.classList.remove('show');
postText.value = ''; previewArea.style.display = 'none'; uploadArea.style.display = 'block'; fileInput.value = '';
});
</script>
</body>
</html>
```

## Cara Integrasi
Modal create post dibuka dengan tombol. Textarea untuk konten, upload area untuk gambar dengan preview. Tombol Post memvalidasi dan mempublikasikan post.
