# 409. Membangun Stories Section dengan Horizontal Scroll dan Circle Avatar

## Definisi & Target
Membangun stories section yang menampilkan lingkaran foto profil user secara horizontal dengan scroll. Targetnya adalah fitur stories seperti di media sosial populer.

## Analogi Alur
Seperti carousel foto yang bisa di-scroll ke samping. Setiap lingkaran mewakili story dari seorang teman.

## Poin-Poin Penting
- Container dengan overflow-x: auto untuk horizontal scroll
- Avatar lingkaran dengan border gradient
- Nama user di bawah avatar
- Tombol "Add Story" untuk user sendiri
