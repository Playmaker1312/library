# 415. Mengimplementasikan Add Comment dengan Form Inline

## Definisi & Target
Mengimplementasikan form komentar inline di bawah post yang memungkinkan pengguna menambahkan komentar. Targetnya adalah interaksi komentar yang cepat.

## Analogi Alur
Seperti menulis catatan di bawah artikel - Anda mengetik langsung di kolom yang tersedia dan mengirimnya.

## Poin-Poin Penting
- Input field dengan tombol kirim
- Inline di bawah daftar komentar
- Kirim dengan Enter atau tombol
- Komentar baru muncul di daftar

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Add Comment</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; display: flex; justify-content: center; padding: 20px; }
.post { background: #fff; border-radius: 12px; max-width: 500px; width: 100%; box-shadow: 0 1px 4px rgba(0,0,0,0.06); padding: 16px; }
.comment { display: flex; gap: 10px; margin-bottom: 12px; }
.comment .avatar { width: 32px; height: 32px; border-radius: 50%; display: flex; align-items: center; justify-content: center; color: #fff; font-weight: 600; font-size: 11px; flex-shrink: 0; }
.comment .body { flex: 1; }
.comment .name { font-weight: 600; font-size: 13px; }
.comment .text { font-size: 13px; color: #333; }
.comment-form { display: flex; align-items: center; gap: 8px; margin-top: 12px; padding-top: 12px; border-top: 1px solid #e0e0e0; }
.comment-form input { flex: 1; padding: 10px 14px; border: 1px solid #ddd; border-radius: 24px; font-size: 13px; outline: none; }
.comment-form input:focus { border-color: #1877f2; }
.comment-form button { background: #1877f2; color: #fff; border: none; border-radius: 50%; width: 36px; height: 36px; font-size: 16px; cursor: pointer; display: flex; align-items: center; justify-content: center; }
</style>
</head>
<body>
<div class="post">
<p style="margin-bottom:12px;">Belajar CSS Grid hari ini! 📐</p>
<div id="comments">
<div class="comment"><div class="avatar" style="background:#4CAF50">BS</div><div class="body"><div class="name">Budi Santoso</div><div class="text">Mantap! CSS Grid真的很强大</div></div></div>
</div>
<div class="comment-form">
<input type="text" id="commentInput" placeholder="Tulis komentar...">
<button id="sendComment">➤</button>
</div>
</div>
<script>
const input = document.getElementById('commentInput');
const comments = document.getElementById('comments');
const sendBtn = document.getElementById('sendComment');
function addComment() {
const text = input.value.trim();
if (!text) return;
const div = document.createElement('div');
div.className = 'comment';
div.innerHTML = `<div class="avatar" style="background:#e53935">AK</div><div class="body"><div class="name">Anda</div><div class="text">${text}</div></div>`;
comments.appendChild(div);
input.value = '';
}
sendBtn.addEventListener('click', addComment);
input.addEventListener('keydown', (e) => { if (e.key === 'Enter') addComment(); });
</script>
</body>
</html>
```

## Cara Integrasi
Form komentar inline ditempatkan di bawah daftar komentar. Input menggunakan Enter atau tombol kirim untuk menambahkan komentar baru ke daftar.
