# 423. Mengimplementasikan Post Options Menu yaitu Edit, Delete, dan Report

## Definisi & Target
Mengimplementasikan menu opsi pada post yang berisi pilihan Edit, Delete, dan Report. Targetnya adalah pengelolaan post yang lengkap.

## Analogi Alur
Seperti menu tiga titik di aplikasi media sosial yang memberikan opsi tambahan untuk sebuah post.

## Poin-Poin Penting
- Tombol ⋯ (tiga titik) di header post
- Dropdown menu dengan opsi
- Edit: modal untuk mengubah konten
- Delete: hapus post dengan konfirmasi
- Report: laporkan post

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Post Options Menu</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; display: flex; justify-content: center; padding: 40px; }
.post { background: #fff; border-radius: 12px; max-width: 450px; width: 100%; box-shadow: 0 1px 4px rgba(0,0,0,0.06); padding: 16px; position: relative; }
.post-header { display: flex; align-items: center; gap: 10px; margin-bottom: 12px; }
.post-header .avatar { width: 36px; height: 36px; border-radius: 50%; display: flex; align-items: center; justify-content: center; color: #fff; font-weight: 600; font-size: 13px; }
.post-header .info { flex: 1; }
.post-header .name { font-weight: 600; font-size: 14px; }
.post-header .options-btn { background: none; border: none; font-size: 20px; cursor: pointer; color: #888; padding: 4px; }
.options-menu { display: none; position: absolute; right: 16px; top: 52px; background: #fff; border-radius: 8px; box-shadow: 0 4px 16px rgba(0,0,0,0.12); min-width: 160px; z-index: 10; }
.options-menu.show { display: block; }
.options-menu div { padding: 12px 16px; font-size: 13px; cursor: pointer; display: flex; align-items: center; gap: 8px; }
.options-menu div:hover { background: #f5f5f5; }
.options-menu .danger { color: #e53935; }
.modal { display: none; position: fixed; inset: 0; background: rgba(0,0,0,0.5); align-items: center; justify-content: center; z-index: 100; }
.modal.show { display: flex; }
.modal-content { background: #fff; border-radius: 12px; padding: 24px; width: 360px; max-width: 90vw; }
.modal-content h3 { margin-bottom: 12px; }
.modal-content textarea { width: 100%; padding: 10px; border: 1px solid #ddd; border-radius: 8px; font-size: 14px; min-height: 100px; font-family: inherit; resize: vertical; outline: none; }
.modal-actions { display: flex; gap: 10px; justify-content: flex-end; margin-top: 12px; }
.modal-actions button { padding: 8px 20px; border: none; border-radius: 6px; cursor: pointer; font-size: 13px; }
.btn-primary { background: #1877f2; color: #fff; }
.btn-cancel { background: #e0e0e0; color: #333; }
</style>
</head>
<body>
<div class="post" id="post">
<div class="post-header">
<div class="avatar" style="background:#4CAF50">BS</div>
<div class="info"><div class="name">Budi Santoso</div></div>
<button class="options-btn" id="optionsBtn">⋯</button>
</div>
<div class="options-menu" id="optionsMenu">
<div id="editOption">✏️ Edit</div>
<div id="deleteOption" class="danger">🗑️ Hapus</div>
<div>🚩 Report</div>
</div>
<p id="postContent" style="font-size:14px;color:#333;">Hari ini belajar JavaScript! 🚀</p>
</div>
<div class="modal" id="editModal">
<div class="modal-content">
<h3>Edit Post</h3>
<textarea id="editText">Hari ini belajar JavaScript! 🚀</textarea>
<div class="modal-actions"><button class="btn-cancel" id="cancelEdit">Batal</button><button class="btn-primary" id="saveEdit">Simpan</button></div>
</div>
</div>
<script>
const optionsBtn = document.getElementById('optionsBtn');
const optionsMenu = document.getElementById('optionsMenu');
const postContent = document.getElementById('postContent');
const editModal = document.getElementById('editModal');
const editText = document.getElementById('editText');
optionsBtn.addEventListener('click', (e) => { e.stopPropagation(); optionsMenu.classList.toggle('show'); });
document.addEventListener('click', () => optionsMenu.classList.remove('show'));
document.getElementById('editOption').addEventListener('click', () => { editText.value = postContent.textContent; editModal.classList.add('show'); optionsMenu.classList.remove('show'); });
document.getElementById('cancelEdit').addEventListener('click', () => editModal.classList.remove('show'));
document.getElementById('saveEdit').addEventListener('click', () => { postContent.textContent = editText.value; editModal.classList.remove('show'); });
document.getElementById('deleteOption').addEventListener('click', () => { if (confirm('Hapus post ini?')) { document.getElementById('post').remove(); } optionsMenu.classList.remove('show'); });
editModal.addEventListener('click', (e) => { if (e.target === editModal) editModal.classList.remove('show'); });
</script>
</body>
</html>
```

## Cara Integrasi
Tombol ⋯ membuka dropdown menu. Edit membuka modal dengan textarea. Delete dengan konfirmasi menghapus post. Report bisa memunculkan form laporan.
