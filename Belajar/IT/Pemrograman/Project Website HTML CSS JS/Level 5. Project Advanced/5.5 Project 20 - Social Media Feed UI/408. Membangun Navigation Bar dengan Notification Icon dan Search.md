# 408. Membangun Navigation Bar dengan Notification Icon dan Search

## Definisi & Target
Membangun navigation bar (navbar) untuk aplikasi social media yang berisi logo, search, dan notification icon. Targetnya adalah navigasi yang fungsional dan familiar.

## Analogi Alur
Seperti toolbar di aplikasi media sosial pada umumnya: logo di kiri, search di tengah, notifikasi di kanan.

## Poin-Poin Penting
- Logo atau brand name di kiri
- Search input di tengah
- Notification bell icon dengan badge
- Profile avatar di kanan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Navigation Bar</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; }
.navbar { display: flex; align-items: center; justify-content: space-between; padding: 0 24px; height: 60px; background: #fff; border-bottom: 1px solid #e0e0e0; position: sticky; top: 0; z-index: 100; }
.nav-left { display: flex; align-items: center; gap: 8px; }
.logo { font-size: 22px; font-weight: 700; color: #1877f2; }
.nav-center { flex: 1; max-width: 480px; margin: 0 20px; }
.nav-center input { width: 100%; padding: 10px 16px; border: none; border-radius: 24px; background: #f0f2f5; font-size: 14px; outline: none; }
.nav-right { display: flex; align-items: center; gap: 16px; }
.nav-right button { background: none; border: none; font-size: 22px; cursor: pointer; position: relative; color: #333; }
.nav-right .badge { position: absolute; top: -4px; right: -6px; background: #e53935; color: #fff; font-size: 10px; font-weight: 700; padding: 2px 5px; border-radius: 50%; min-width: 16px; text-align: center; }
.avatar { width: 36px; height: 36px; border-radius: 50%; background: #ddd; display: flex; align-items: center; justify-content: center; font-weight: 600; color: #fff; font-size: 14px; cursor: pointer; }
</style>
</head>
<body>
<nav class="navbar">
<div class="nav-left"><span class="logo">SocialApp</span></div>
<div class="nav-center"><input type="text" placeholder="Cari..."></div>
<div class="nav-right">
<button>🔔<span class="badge">3</span></button>
<button>💬</button>
<div class="avatar" style="background:#4CAF50">BS</div>
</div>
</nav>
</body>
</html>
```

## Cara Integrasi
Navbar ditempatkan di bagian atas halaman dengan posisi sticky. Search input dan notification badge diperbarui secara dinamis berdasarkan data aplikasi.
