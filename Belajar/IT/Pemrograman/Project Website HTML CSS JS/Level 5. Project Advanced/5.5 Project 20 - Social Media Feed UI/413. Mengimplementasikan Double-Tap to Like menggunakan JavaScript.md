# 413. Mengimplementasikan Double-Tap to Like menggunakan JavaScript

## Definisi & Target
Mengimplementasikan fitur double-tap untuk memberikan like pada post, seperti di aplikasi Instagram. Targetnya adalah interaksi like yang intuitif.

## Analogi Alur
Seperti di Instagram - ketuk dua kali pada foto untuk memberikan like dengan animasi heart yang muncul di tengah.

## Poin-Poin Penting
- Deteksi double click/tap dalam waktu tertentu
- Animasi heart besar di tengah post
- Trigger like bersamaan dengan animasi
- Bekerja untuk mouse click dan touch

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Double Tap Like</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; display: flex; justify-content: center; padding: 40px; }
.post { background: #fff; border-radius: 12px; max-width: 400px; box-shadow: 0 1px 4px rgba(0,0,0,0.06); overflow: hidden; position: relative; cursor: pointer; user-select: none; }
.post img { width: 100%; display: block; pointer-events: none; }
.double-tap-heart { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%) scale(0); font-size: 80px; color: #fff; opacity: 0; pointer-events: none; text-shadow: 0 2px 10px rgba(0,0,0,0.3); }
.double-tap-heart.show { animation: heartFloat 0.8s ease forwards; }
@keyframes heartFloat { 0% { transform: translate(-50%, -50%) scale(0); opacity: 1; } 50% { transform: translate(-50%, -50%) scale(1.2); opacity: 1; } 100% { transform: translate(-50%, -50%) scale(1); opacity: 0; } }
.like-bar { padding: 10px 16px; display: flex; align-items: center; gap: 8px; }
.like-bar button { background: none; border: none; font-size: 22px; cursor: pointer; color: #555; }
.like-bar button.liked { color: #e53935; }
.like-bar .count { font-size: 14px; color: #333; }
</style>
</head>
<body>
<div class="post" id="post">
<img src="https://via.placeholder.com/400x300/4CAF50/fff?text=Double+Tap+to+Like" alt="Post">
<div class="double-tap-heart" id="heartAnim">❤</div>
<div class="like-bar">
<button id="likeBtn">❤</button>
<span class="count" id="likeCount">12</span>
</div>
</div>
<script>
const post = document.getElementById('post');
const likeBtn = document.getElementById('likeBtn');
const likeCount = document.getElementById('likeCount');
const heartAnim = document.getElementById('heartAnim');
let lastTap = 0;
let liked = false;
let count = 12;
post.addEventListener('click', function(e) {
const now = Date.now();
if (now - lastTap < 300) {
if (!liked) {
liked = true; count++; likeBtn.classList.add('liked'); likeCount.textContent = count;
heartAnim.classList.remove('show');
void heartAnim.offsetWidth;
heartAnim.classList.add('show');
setTimeout(() => heartAnim.classList.remove('show'), 800);
} else {
liked = false; count--; likeBtn.classList.remove('liked'); likeCount.textContent = count;
}
}
lastTap = now;
});
likeBtn.addEventListener('click', (e) => {
e.stopPropagation();
liked = !liked;
if (liked) { count++; likeBtn.classList.add('liked'); }
else { count--; likeBtn.classList.remove('liked'); }
likeCount.textContent = count;
});
</script>
</body>
</html>
```

## Cara Integrasi
Double-tap dideteksi dengan membandingkan timestamp klik. Jika selisih < 300ms, dianggap double-tap. Animasi heart muncul di tengah post dan memudar.
