# 420. Mengimplementasikan Skeleton Loading untuk Post yang Sedang Dimuat

## Definisi & Target
Mengimplementasikan skeleton loading sebagai placeholder saat post sedang dimuat. Targetnya adalah pengalaman loading yang lebih baik.

## Analogi Alur
Seperti kerangka/frame foto sebelum foto muncul. Skeleton memberikan gambaran layout yang akan muncul sehingga pengguna tidak melihat layar kosong.

## Poin-Poin Penting
- Skeleton berbentuk placeholder abu-abu
- Animasi shimmer/glow pada skeleton
- Bentuk skeleton mirip dengan konten asli
- Skeleton diganti dengan konten saat selesai

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Skeleton Loading</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; display: flex; justify-content: center; padding: 20px; }
.feed { max-width: 500px; width: 100%; }
.skeleton { background: #fff; border-radius: 12px; padding: 16px; margin-bottom: 12px; box-shadow: 0 1px 4px rgba(0,0,0,0.06); }
.skeleton-row { display: flex; gap: 12px; align-items: center; margin-bottom: 14px; }
.skeleton-avatar { width: 40px; height: 40px; border-radius: 50%; background: #e0e0e0; position: relative; overflow: hidden; }
.skeleton-line { height: 14px; background: #e0e0e0; border-radius: 6px; position: relative; overflow: hidden; }
.skeleton-line.w60 { width: 60%; }
.skeleton-line.w80 { width: 80%; }
.skeleton-line.w100 { width: 100%; }
.skeleton-image { width: 100%; height: 200px; background: #e0e0e0; border-radius: 8px; margin-top: 10px; position: relative; overflow: hidden; }
.skeleton-avatar::after, .skeleton-line::after, .skeleton-image::after {
content: ''; position: absolute; inset: 0; background: linear-gradient(90deg, transparent, rgba(255,255,255,0.6), transparent); animation: shimmer 1.5s infinite; }
@keyframes shimmer { 0% { transform: translateX(-100%); } 100% { transform: translateX(100%); } }
.post { display: none; background: #fff; border-radius: 12px; padding: 16px; margin-bottom: 12px; box-shadow: 0 1px 4px rgba(0,0,0,0.06); }
.post.show { display: block; }
.post .user { display: flex; align-items: center; gap: 10px; margin-bottom: 10px; }
.post .avatar { width: 40px; height: 40px; border-radius: 50%; display: flex; align-items: center; justify-content: center; color: #fff; font-weight: 600; }
.post .name { font-weight: 600; }
.post .text { font-size: 14px; color: #333; }
</style>
</head>
<body>
<div class="feed" id="feed">
<div class="skeleton" id="skeleton1">
<div class="skeleton-row"><div class="skeleton-avatar"></div><div class="skeleton-line w60"></div></div>
<div class="skeleton-line w100" style="margin-bottom:8px;"></div>
<div class="skeleton-line w80" style="margin-bottom:8px;"></div>
<div class="skeleton-image"></div>
</div>
<div class="post show" id="post1">
<div class="user"><div class="avatar" style="background:#4CAF50">BS</div><div class="name">Budi Santoso</div></div>
<div class="text">Halo! Ini post pertama setelah loading selesai. 🎉</div>
</div>
</div>
<script>
setTimeout(() => {
document.getElementById('skeleton1').style.display = 'none';
document.getElementById('post1').classList.add('show');
}, 2000);
</script>
</body>
</html>
```

## Cara Integrasi
Skeleton element ditampilkan saat data sedang dimuat. Setelah data siap, skeleton disembunyikan dan post ditampilkan. Animasi shimmer memberikan efek loading yang halus.
