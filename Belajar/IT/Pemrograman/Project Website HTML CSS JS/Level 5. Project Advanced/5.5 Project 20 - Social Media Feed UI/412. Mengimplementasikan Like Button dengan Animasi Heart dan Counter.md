# 412. Mengimplementasikan Like Button dengan Animasi Heart dan Counter

## Definisi & Target
Mengimplementasikan tombol like dengan animasi heart dan counter yang bertambah/berkurang. Targetnya adalah interaksi like yang menarik dan responsif.

## Analogi Alur
Seperti memberikan hati pada postingan - sekali klik, hati muncul dengan animasi; klik lagi untuk membatalkan.

## Poin-Poin Penting
- Toggle like/unlike dengan ikon heart
- Animasi heart scale saat di-like
- Counter jumlah like bertambah/berkurang
- Warna berubah saat di-like (merah)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Like Button</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; display: flex; justify-content: center; padding: 40px; }
.card { background: #fff; border-radius: 12px; padding: 20px 24px; box-shadow: 0 1px 4px rgba(0,0,0,0.06); width: 300px; text-align: center; }
.like-btn { background: none; border: none; font-size: 28px; cursor: pointer; transition: all 0.2s; display: inline-flex; align-items: center; gap: 8px; color: #555; }
.like-btn.liked { color: #e53935; }
.like-btn .count { font-size: 16px; font-family: 'Segoe UI', sans-serif; }
.like-btn:active { transform: scale(0.8); }
.like-btn .heart { display: inline-block; transition: transform 0.2s; }
.like-btn.liked .heart { animation: heartPop 0.3s ease; }
@keyframes heartPop { 0% { transform: scale(1); } 50% { transform: scale(1.3); } 100% { transform: scale(1); } }
</style>
</head>
<body>
<div class="card">
<p style="margin-bottom:16px;color:#333;">Hari ini belajar JavaScript!</p>
<button class="like-btn" id="likeBtn">
<span class="heart" id="heartIcon">❤</span>
<span class="count" id="likeCount">12</span>
</button>
</div>
<script>
const likeBtn = document.getElementById('likeBtn');
const heartIcon = document.getElementById('heartIcon');
const likeCount = document.getElementById('likeCount');
let liked = false;
let count = 12;
likeBtn.addEventListener('click', () => {
liked = !liked;
if (liked) { count++; likeBtn.classList.add('liked'); heartIcon.textContent = '❤'; }
else { count--; likeBtn.classList.remove('liked'); heartIcon.textContent = '❤'; }
likeCount.textContent = count;
});
</script>
</body>
</html>
```

## Cara Integrasi
Like button memiliki state liked/unliked. Saat diklik, class "liked" di-toggle, counter di-update, dan animasi heartPop dijalankan. Warna berubah menjadi merah saat di-like.
