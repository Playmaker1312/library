# 410. Mengimplementasikan Add Story Button dengan Preview

## Definisi & Target
Mengimplementasikan tombol "Add Story" yang memungkinkan pengguna menambahkan story dengan preview. Targetnya adalah pembuatan story yang interaktif.

## Analogi Alur
Seperti tombol kamera untuk mengambil foto story. Setelah mengambil/memilih gambar, preview ditampilkan sebelum dipublikasikan.

## Poin-Poin Penting
- Tombol "+" dengan animasi
- Input file atau kamera
- Preview story sebelum di-post
- Progress ring atau indikator

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Add Story</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; display: flex; justify-content: center; padding: 20px; }
.container { background: #fff; border-radius: 16px; padding: 16px; max-width: 500px; width: 100%; box-shadow: 0 1px 4px rgba(0,0,0,0.06); text-align: center; }
.story-row { display: flex; align-items: center; gap: 16px; }
.add-btn { width: 64px; height: 64px; border-radius: 50%; background: linear-gradient(45deg, #f58529, #dd2a7b); border: none; color: #fff; font-size: 32px; cursor: pointer; display: flex; align-items: center; justify-content: center; box-shadow: 0 2px 8px rgba(0,0,0,0.15); transition: transform 0.2s; }
.add-btn:hover { transform: scale(1.05); }
.add-btn.pulse { animation: pulse 2s infinite; }
@keyframes pulse { 0% { box-shadow: 0 0 0 0 rgba(221,42,123,0.4); } 70% { box-shadow: 0 0 0 12px rgba(221,42,123,0); } 100% { box-shadow: 0 0 0 0 rgba(221,42,123,0); } }
.preview-area { margin-top: 16px; display: none; }
.preview-area img { max-width: 100%; border-radius: 12px; max-height: 300px; }
.preview-area .actions { display: flex; gap: 10px; justify-content: center; margin-top: 12px; }
.preview-area .actions button { padding: 8px 20px; border: none; border-radius: 8px; cursor: pointer; font-size: 13px; color: #fff; }
.btn-share { background: #1877f2; }
.btn-cancel { background: #999; }
input[type="file"] { display: none; }
</style>
</head>
<body>
<div class="container">
<div class="story-row">
<button class="add-btn pulse" id="addStoryBtn">+</button>
<span style="color:#555;font-size:14px;">Tambahkan Story</span>
</div>
<input type="file" id="fileInput" accept="image/*">
<div class="preview-area" id="previewArea">
<img id="previewImg" alt="Preview">
<div class="actions"><button class="btn-cancel" id="cancelBtn">Batal</button><button class="btn-share" id="shareBtn">Bagikan ke Story</button></div>
</div>
</div>
<script>
const addBtn = document.getElementById('addStoryBtn');
const fileInput = document.getElementById('fileInput');
const previewArea = document.getElementById('previewArea');
const previewImg = document.getElementById('previewImg');
addBtn.addEventListener('click', () => fileInput.click());
fileInput.addEventListener('change', function() {
const file = this.files[0];
if (!file || !file.type.startsWith('image/')) return;
const reader = new FileReader();
reader.onload = (e) => { previewImg.src = e.target.result; previewArea.style.display = 'block'; };
reader.readAsDataURL(file);
});
document.getElementById('cancelBtn').addEventListener('click', () => { previewArea.style.display = 'none'; fileInput.value = ''; });
document.getElementById('shareBtn').addEventListener('click', () => { alert('Story dibagikan!'); previewArea.style.display = 'none'; fileInput.value = ''; });
</script>
</body>
</html>
```

## Cara Integrasi
Tombol Add Story memicu input file. Preview muncul setelah gambar dipilih. Tombol share mempublikasikan story ke feed stories.
