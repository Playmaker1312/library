# 411. Membangun Post Card dengan Header User, Konten, dan Action Buttons

## Definisi & Target
Membangun post card yang berisi header (foto profil dan nama user), konten (teks dan gambar), serta action buttons (like, comment, share). Targetnya adalah tampilan post yang informatif.

## Analogi Alur
Seperti kartu pos yang memiliki pengirim (header), isi pesan (konten), dan stempel (action buttons).

## Poin-Poin Penting
- Header: avatar, nama user, timestamp
- Konten: teks dan/atau gambar
- Action buttons: Like, Comment, Share
- Tiga titik (options menu) di header
