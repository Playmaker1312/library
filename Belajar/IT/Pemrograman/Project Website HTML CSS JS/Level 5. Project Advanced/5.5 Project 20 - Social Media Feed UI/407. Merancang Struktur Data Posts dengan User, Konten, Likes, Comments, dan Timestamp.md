# 407. Merancang Struktur Data Posts dengan User, Konten, Likes, Comments, dan Timestamp

## Definisi & Target
Merancang struktur data untuk setiap post yang berisi informasi user, konten, jumlah likes, komentar, dan timestamp. Targetnya adalah data post yang terorganisir.

## Analogi Alur
Seperti kartu indeks yang berisi informasi lengkap: siapa yang posting, apa isinya, berapa like, komentar apa saja, dan kapan diposting.

## Poin-Poin Penting
- Setiap post memiliki id, user, content, image
- likes: array user ID atau jumlah
- comments: array of comment objects
- timestamp: waktu posting
