# 422. Mengimplementasikan Follow dan Unfollow Button dengan State yang Berubah

## Definisi & Target
Mengimplementasikan tombol follow/unfollow yang berubah state saat diklik. Targetnya adalah interaksi follow yang responsif dan informatif.

## Analogi Alur
Seperti tombol berlangganan di YouTube - "Subscribe" berubah menjadi "Subscribed" setelah diklik. Memberikan feedback visual yang jelas.

## Poin-Poin Penting
- Toggle state follow/unfollow
- Teks dan warna tombol berubah
- Animasi transisi state
- Konfirmasi unfollow (opsional)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Follow Unfollow</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; display: flex; justify-content: center; padding: 40px; }
.card { background: #fff; border-radius: 12px; padding: 24px; box-shadow: 0 1px 4px rgba(0,0,0,0.06); width: 320px; }
.friend { display: flex; align-items: center; gap: 14px; margin-bottom: 16px; padding: 12px; border-radius: 8px; border: 1px solid #e0e0e0; }
.friend .avatar { width: 48px; height: 48px; border-radius: 50%; display: flex; align-items: center; justify-content: center; color: #fff; font-weight: 600; font-size: 18px; }
.friend .info { flex: 1; }
.friend .name { font-weight: 600; font-size: 15px; color: #1a1a2e; }
.friend .status { font-size: 12px; color: #888; }
.follow-btn { padding: 6px 20px; border: none; border-radius: 8px; cursor: pointer; font-size: 13px; font-weight: 600; transition: all 0.3s; }
.follow-btn.follow { background: #1877f2; color: #fff; }
.follow-btn.following { background: #e0e0e0; color: #333; }
.follow-btn.follow:hover { background: #166fe5; }
.follow-btn.following:hover { background: #e53935; color: #fff; }
</style>
</head>
<body>
<div class="card">
<div class="friend">
<div class="avatar" style="background:#4CAF50">MS</div>
<div class="info"><div class="name">Maya Sari</div><div class="status">12 teman bersama</div></div>
<button class="follow-btn follow" id="followBtn">Follow</button>
</div>
<div class="friend">
<div class="avatar" style="background:#2196F3">AW</div>
<div class="info"><div class="name">Agus Wijaya</div><div class="status">8 teman bersama</div></div>
<button class="follow-btn following" id="followBtn2">Following</button>
</div>
</div>
<script>
document.querySelectorAll('.follow-btn').forEach(btn => {
btn.addEventListener('click', function() {
if (this.classList.contains('follow')) {
this.classList.remove('follow');
this.classList.add('following');
this.textContent = 'Following';
} else {
if (confirm('Unfollow ' + this.closest('.friend').querySelector('.name').textContent + '?')) {
this.classList.remove('following');
this.classList.add('follow');
this.textContent = 'Follow';
}
}
});
});
</script>
</body>
</html>
```

## Cara Integrasi
Tombol follow memiliki dua class: "follow" dan "following". Saat diklik, class di-toggle. Saat unfollow, konfirmasi ditampilkan sebelum mengubah state.
