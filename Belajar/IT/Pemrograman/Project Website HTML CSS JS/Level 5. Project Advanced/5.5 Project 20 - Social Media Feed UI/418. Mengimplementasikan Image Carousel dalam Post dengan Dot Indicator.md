# 418. Mengimplementasikan Image Carousel dalam Post dengan Dot Indicator

## Definisi & Target
Mengimplementasikan image carousel yang lebih canggih dengan dot indicator yang menunjukkan posisi gambar aktif. Targetnya adalah navigasi gambar yang lebih baik.

## Analogi Alur
Seperti slideshow presentasi - titik-titik di bawah menunjukkan halaman yang sedang aktif dan total halaman.

## Poin-Poin Penting
- Dot indicator dengan highlight posisi
- Auto-slide dengan interval tertentu
- Navigasi dengan klik dot atau swipe
- Transisi yang halus

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Image Carousel</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; display: flex; justify-content: center; padding: 20px; }
.carousel { position: relative; max-width: 500px; border-radius: 12px; overflow: hidden; background: #fff; box-shadow: 0 1px 4px rgba(0,0,0,0.06); }
.track { display: flex; transition: transform 0.4s cubic-bezier(0.25, 0.46, 0.45, 0.94); }
.track img { width: 100%; flex-shrink: 0; }
.dots { position: absolute; bottom: 16px; left: 50%; transform: translateX(-50%); display: flex; gap: 8px; }
.dots span { width: 8px; height: 8px; border-radius: 50%; background: rgba(255,255,255,0.5); cursor: pointer; transition: all 0.3s; }
.dots span.active { background: #fff; width: 24px; border-radius: 4px; }
.arrow { position: absolute; top: 50%; transform: translateY(-50%); background: rgba(255,255,255,0.85); border: none; width: 36px; height: 36px; border-radius: 50%; cursor: pointer; font-size: 20px; display: flex; align-items: center; justify-content: center; box-shadow: 0 2px 8px rgba(0,0,0,0.1); transition: all 0.2s; }
.arrow:hover { background: #fff; }
.arrow.prev { left: 12px; }
.arrow.next { right: 12px; }
.counter { position: absolute; top: 12px; right: 12px; background: rgba(0,0,0,0.6); color: #fff; font-size: 12px; padding: 4px 10px; border-radius: 12px; }
</style>
</head>
<body>
<div class="carousel">
<div class="track" id="track">
<img src="https://via.placeholder.com/500x320/4CAF50/fff?text=Gambar+1" alt="1">
<img src="https://via.placeholder.com/500x320/2196F3/fff?text=Gambar+2" alt="2">
<img src="https://via.placeholder.com/500x320/FF9800/fff?text=Gambar+3" alt="3">
<img src="https://via.placeholder.com/500x320/9C27B0/fff?text=Gambar+4" alt="4">
</div>
<button class="arrow prev" id="prevBtn">‹</button>
<button class="arrow next" id="nextBtn">›</button>
<div class="dots" id="dots"><span class="active"></span><span></span><span></span><span></span></div>
<div class="counter" id="counter">1 / 4</div>
</div>
<script>
const track = document.getElementById('track');
const dots = document.querySelectorAll('#dots span');
const prevBtn = document.getElementById('prevBtn');
const nextBtn = document.getElementById('nextBtn');
const counter = document.getElementById('counter');
let current = 0, total = 4;
function goTo(i) { current = i; track.style.transform = `translateX(-${current * 100}%)`; dots.forEach((d, idx) => d.classList.toggle('active', idx === current)); counter.textContent = `${current + 1} / ${total}`; }
prevBtn.addEventListener('click', () => goTo((current - 1 + total) % total));
nextBtn.addEventListener('click', () => goTo((current + 1) % total));
dots.forEach((d, i) => d.addEventListener('click', () => goTo(i)));
let autoSlide = setInterval(() => goTo((current + 1) % total), 3000);
document.querySelector('.carousel').addEventListener('mouseenter', () => clearInterval(autoSlide));
document.querySelector('.carousel').addEventListener('mouseleave', () => { autoSlide = setInterval(() => goTo((current + 1) % total), 3000); });
</script>
</body>
</html>
```

## Cara Integrasi
Carousel menggunakan track dengan transform X untuk transisi. Dots memiliki style khusus: dot aktif lebih panjang. Counter menunjukkan posisi numerik. Auto-slide dengan interval 3 detik.
