# 416. Mengimplementasikan Nested Reply pada Komentar

## Definisi & Target
Mengimplementasikan reply pada komentar yang membuat thread bersarang (nested). Targetnya adalah percakapan yang terstruktur dalam komentar.

## Analogi Alur
Seperti percakapan berantai di forum - Anda bisa membalas komentar orang lain, dan balasan muncul sebagai anak dari komentar tersebut.

## Poin-Poin Penting
- Tombol "Reply" pada setiap komentar
- Input reply muncul di bawah komentar
- Balasan menjorok (indent) ke kanan
- Tampilkan mention @nama user

document.querySelectorAll('.reply-btn').forEach(btn => btn.addEventListener('click', function() {
const target = this.dataset.target;
const form = document.querySelector(`.reply-form[data-parent="${target}"]`);
form.classList.toggle('open');
form.querySelector('input').focus();
}));
document.querySelectorAll('.send-reply').forEach(btn => btn.addEventListener('click', function() {
const form = this.closest('.reply-form');
const input = form.querySelector('input');
const text = input.value.trim();
if (!text) return;
const parent = form.closest('.comment') || form.closest('.replies');
const replyDiv = document.createElement('div');
replyDiv.className = 'comment';
replyDiv.innerHTML = `<div class="avatar" style="background:#e53935">AK</div><div class="body"><div class="name">Anda</div><div class="text">${text}</div></div>`;
const repliesContainer = parent.querySelector('.replies') || (() => { const r = document.createElement('div'); r.className = 'replies'; parent.appendChild(r); return r; })();
repliesContainer.appendChild(replyDiv);
input.value = '';
form.classList.remove('open');
}));
</script>

## Cara Integrasi
Setiap komentar memiliki tombol Reply yang membuka form input. Balasan ditempatkan di div .replies dengan indentasi. Format @mention digunakan untuk menyebut user.
