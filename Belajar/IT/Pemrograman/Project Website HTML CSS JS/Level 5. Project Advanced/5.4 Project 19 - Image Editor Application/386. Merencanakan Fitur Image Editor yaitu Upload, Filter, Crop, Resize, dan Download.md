# 386. Merencanakan Fitur Image Editor yaitu Upload, Filter, Crop, Resize, dan Download

## Definisi & Target
Merencanakan fitur utama Image Editor yang meliputi upload gambar, filter efek, crop, resize, dan download hasil edit. Targetnya adalah aplikasi editor gambar berbasis web.

## Analogi Alur
Seperti meja kerja fotografer dengan alat-alat untuk memotong, memberi filter, mengubah ukuran, dan mencetak foto.

## Poin-Poin Penting
- Upload: input file dan drag & drop
- Filter: brightness, contrast, saturation, dll
- Crop: memotong area tertentu
- Resize: mengubah dimensi
- Download: menyimpan hasil edit
