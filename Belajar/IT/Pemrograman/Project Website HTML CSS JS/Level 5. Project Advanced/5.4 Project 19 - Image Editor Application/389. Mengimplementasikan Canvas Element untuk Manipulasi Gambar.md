# 389. Mengimplementasikan Canvas Element untuk Manipulasi Gambar

## Definisi & Target
Mengimplementasikan elemen Canvas yang akan digunakan sebagai media untuk memanipulasi gambar. Targetnya adalah canvas yang siap untuk operasi editing.

## Analogi Alur
Seperti kanvas kosong di studio seni yang siap untuk dilukis. Canvas di HTML5 adalah tempat di mana semua manipulasi gambar terjadi.

## Poin-Poin Penting
- Elemen <canvas> dengan ukuran yang sesuai
- Context 2D untuk operasi gambar
- Gambar digambar ke canvas menggunakan drawImage
- Canvas menjadi sumber untuk semua operasi filter

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Canvas Element</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; display: flex; justify-content: center; padding: 40px; flex-direction: column; align-items: center; gap: 16px; }
canvas { border-radius: 12px; max-width: 100%; border: 1px solid rgba(255,255,255,0.1); }
.controls { display: flex; gap: 12px; }
.controls button, .controls input { padding: 8px 16px; border-radius: 6px; border: none; cursor: pointer; font-size: 13px; }
.controls button { background: #4CAF50; color: #fff; }
</style>
</head>
<body>
<canvas id="canvas" width="400" height="300"></canvas>
<div class="controls">
<input type="file" id="fileInput" accept="image/*" style="display:none">
<button id="loadBtn">Muat Gambar</button>
</div>
<script>
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
const fileInput = document.getElementById('fileInput');
document.getElementById('loadBtn').addEventListener('click', () => fileInput.click());
fileInput.addEventListener('change', function() {
const file = this.files[0];
if (!file) return;
const reader = new FileReader();
reader.onload = (e) => {
const img = new Image();
img.onload = () => {
canvas.width = img.width;
canvas.height = img.height;
ctx.drawImage(img, 0, 0);
};
img.src = e.target.result;
};
reader.readAsDataURL(file);
});
ctx.fillStyle = '#2a2a5e';
ctx.fillRect(0, 0, canvas.width, canvas.height);
ctx.fillStyle = '#888';
ctx.font = '16px sans-serif';
ctx.textAlign = 'center';
ctx.fillText('Muat gambar untuk memulai', canvas.width/2, canvas.height/2);
</script>
</body>
</html>
```

## Cara Integrasi
Canvas dibuat dengan ukuran dinamis sesuai gambar. Fungsi drawImage() menggambar gambar ke canvas. Semua operasi editing akan memanipulasi canvas ini.
