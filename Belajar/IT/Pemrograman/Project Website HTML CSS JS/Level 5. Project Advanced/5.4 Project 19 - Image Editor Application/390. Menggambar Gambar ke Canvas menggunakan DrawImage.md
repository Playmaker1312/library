# 390. Menggambar Gambar ke Canvas menggunakan DrawImage

## Definisi & Target
Mengimplementasikan fungsi drawImage untuk menggambar gambar yang sudah diupload ke dalam canvas. Targetnya adalah gambar muncul di canvas dan siap diedit.

## Analogi Alur
Seperti memproyeksikan slide foto ke kanvas kosong. Gambar dari file dipindahkan ke kanvas digital.

## Poin-Poin Penting
- Buat objek Image baru dari sumber gambar
- drawImage(image, x, y) untuk menggambar
- drawImage(image, x, y, width, height) untuk resize
- Sesuaikan ukuran canvas dengan gambar

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>DrawImage</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; display: flex; justify-content: center; flex-direction: column; align-items: center; padding: 20px; gap: 16px; }
canvas { border-radius: 12px; border: 1px solid rgba(255,255,255,0.1); max-width: 100%; }
button { padding: 10px 20px; background: #4CAF50; color: #fff; border: none; border-radius: 8px; cursor: pointer; font-size: 14px; }
input[type="file"] { display: none; }
</style>
</head>
<body>
<canvas id="canvas" width="400" height="300"></canvas>
<input type="file" id="fileInput" accept="image/*">
<button id="loadBtn">Pilih & Muat Gambar</button>
<script>
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
const fileInput = document.getElementById('fileInput');
document.getElementById('loadBtn').addEventListener('click', () => fileInput.click());
fileInput.addEventListener('change', function() {
const file = this.files[0];
if (!file) return;
const reader = new FileReader();
reader.onload = (e) => {
const img = new Image();
img.onload = () => {
canvas.width = Math.min(img.width, 600);
canvas.height = Math.min(img.height, 450);
ctx.drawImage(img, 0, 0, canvas.width, canvas.height);
};
img.src = e.target.result;
};
reader.readAsDataURL(file);
});
ctx.fillStyle = '#2a2a5e';
ctx.fillRect(0, 0, canvas.width, canvas.height);
</script>
</body>
</html>
```

## Cara Integrasi
Gambar dimuat sebagai objek Image JavaScript. Setelah selesai dimuat, drawImage menggambar ke canvas dengan ukuran yang disesuaikan agar tidak melebihi batas.
