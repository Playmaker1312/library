# 391. Mengimplementasikan Filter Brightness menggunakan CSS Filter dan Canvas

## Definisi & Target
Mengimplementasikan filter brightness (kecerahan) untuk mengatur tingkat terang gambar menggunakan CSS Filter dan Canvas. Targetnya adalah kontrol kecerahan gambar.

## Analogi Alur
Seperti mengatur kecerahan lampu di ruangan - semakin tinggi brightness, semakin terang gambar; semakin rendah, semakin gelap.

## Poin-Poin Penting
- CSS filter: brightness() untuk preview cepat
- Canvas pixel manipulation untuk hasil permanen
- Slider untuk mengontrol nilai brightness
- Preview real-time saat slider digerakkan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Filter Brightness</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; display: flex; justify-content: center; flex-direction: column; align-items: center; padding: 20px; gap: 16px; }
canvas { border-radius: 12px; border: 1px solid rgba(255,255,255,0.1); max-width: 100%; }
.controls { display: flex; align-items: center; gap: 12px; background: #16213e; padding: 12px 20px; border-radius: 12px; }
.controls label { color: #aaa; font-size: 13px; }
.controls input[type="range"] { width: 200px; }
.controls span { color: #fff; font-size: 13px; min-width: 30px; text-align: center; }
input[type="file"] { display: none; }
</style>
</head>
<body>
<canvas id="canvas" width="400" height="300"></canvas>
<input type="file" id="fileInput" accept="image/*">
<div class="controls">
<button id="loadBtn" style="padding:8px 16px;background:#4CAF50;color:#fff;border:none;border-radius:6px;cursor:pointer;">Muat</button>
<label>Brightness</label>
<input type="range" id="brightnessSlider" min="0" max="200" value="100">
<span id="brightnessValue">100</span>
</div>
<script>
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
const fileInput = document.getElementById('fileInput');
const brightnessSlider = document.getElementById('brightnessSlider');
const brightnessValue = document.getElementById('brightnessValue');
let originalImage = null;
document.getElementById('loadBtn').addEventListener('click', () => fileInput.click());
fileInput.addEventListener('change', function() {
const file = this.files[0];
if (!file) return;
const reader = new FileReader();
reader.onload = (e) => {
const img = new Image();
img.onload = () => {
canvas.width = Math.min(img.width, 600);
canvas.height = Math.min(img.height, 450);
ctx.drawImage(img, 0, 0, canvas.width, canvas.height);
originalImage = ctx.getImageData(0, 0, canvas.width, canvas.height);
};
img.src = e.target.result;
};
reader.readAsDataURL(file);
});
brightnessSlider.addEventListener('input', function() {
const val = parseInt(this.value);
brightnessValue.textContent = val;
if (!originalImage) return;
const imageData = new ImageData(new Uint8ClampedArray(originalImage.data), originalImage.width, originalImage.height);
const data = imageData.data;
for (let i = 0; i < data.length; i += 4) {
data[i] = Math.min(255, data[i] * (val / 100));
data[i+1] = Math.min(255, data[i+1] * (val / 100));
data[i+2] = Math.min(255, data[i+2] * (val / 100));
}
ctx.putImageData(imageData, 0, 0);
});
</script>
</body>
</html>
```

## Cara Integrasi
Brightness diimplementasikan dengan memanipulasi pixel data canvas. Setiap channel RGB dikalikan dengan rasio brightness/100. ImageData disimpan sebagai original untuk reset.
