# 402. Mengimplementasikan Drawing Tool Sederhana menggunakan Canvas

## Definisi & Target
Mengimplementasikan drawing tool sederhana untuk menggambar bebas di atas gambar menggunakan canvas. Targetnya adalah fitur coretan dan anotasi.

## Analogi Alur
Seperti spidol di atas foto - Anda bisa menggambar garis, lingkaran, atau coretan bebas di atas gambar.

## Poin-Poin Penting
- Mouse event untuk menggambar bebas
- Pilihan warna dan ukuran brush
- Mode: free draw, line, rectangle, circle
- Hasil drawing digambar di atas gambar

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Drawing Tool</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; display: flex; justify-content: center; flex-direction: column; align-items: center; padding: 20px; gap: 12px; }
canvas { border-radius: 12px; border: 1px solid rgba(255,255,255,0.1); max-width: 100%; cursor: crosshair; background: #2a2a5e; }
.panel { background: #16213e; padding: 12px 16px; border-radius: 12px; display: flex; align-items: center; gap: 10px; flex-wrap: wrap; }
.panel input, .panel select { background: #2a3a6a; border: 1px solid rgba(255,255,255,0.1); border-radius: 6px; color: #fff; font-size: 13px; outline: none; }
.panel input[type="color"] { width: 36px; height: 36px; padding: 2px; cursor: pointer; }
.panel input[type="number"] { width: 60px; padding: 6px; }
.panel button { padding: 8px 16px; border: none; border-radius: 6px; cursor: pointer; font-size: 13px; color: #fff; }
.btn-active { background: #4CAF50; }
.btn-inactive { background: #2a3a6a; }
</style>
</head>
<body>
<canvas id="canvas" width="500" height="350"></canvas>
<div class="panel">
<button class="btn-active" data-tool="free" id="toolFree">✏️ Free</button>
<button class="btn-inactive" data-tool="line" id="toolLine">📏 Line</button>
<button class="btn-inactive" data-tool="rect" id="toolRect">⬜ Rect</button>
<input type="color" id="drawColor" value="#ff4444">
<label style="color:#aaa;font-size:12px;">Size</label>
<input type="number" id="brushSize" value="3" min="1" max="30">
<button class="btn-inactive" id="clearBtn">🗑️ Clear</button>
</div>
<script>
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
let tool = 'free';
let isDrawing = false;
let lastX, lastY, startX, startY;
document.querySelectorAll('[data-tool]').forEach(btn => btn.addEventListener('click', function() {
document.querySelectorAll('[data-tool]').forEach(b => b.className = 'btn-inactive');
this.className = 'btn-active';
tool = this.dataset.tool;
}));
canvas.addEventListener('mousedown', (e) => {
isDrawing = true;
const rect = canvas.getBoundingClientRect();
startX = lastX = e.clientX - rect.left;
startY = lastY = e.clientY - rect.top;
});
canvas.addEventListener('mousemove', (e) => {
if (!isDrawing) return;
const rect = canvas.getBoundingClientRect();
const x = e.clientX - rect.left, y = e.clientY - rect.top;
ctx.strokeStyle = document.getElementById('drawColor').value;
ctx.lineWidth = parseInt(document.getElementById('brushSize').value);
ctx.lineCap = 'round';
if (tool === 'free') { ctx.beginPath(); ctx.moveTo(lastX, lastY); ctx.lineTo(x, y); ctx.stroke(); lastX = x; lastY = y; }
});
canvas.addEventListener('mouseup', (e) => {
if (!isDrawing) return;
isDrawing = false;
const rect = canvas.getBoundingClientRect();
const x = e.clientX - rect.left, y = e.clientY - rect.top;
ctx.strokeStyle = document.getElementById('drawColor').value;
ctx.lineWidth = parseInt(document.getElementById('brushSize').value);
if (tool === 'line') { ctx.beginPath(); ctx.moveTo(startX, startY); ctx.lineTo(x, y); ctx.stroke(); }
else if (tool === 'rect') { ctx.strokeRect(startX, startY, x - startX, y - startY); }
});
document.getElementById('clearBtn').addEventListener('click', () => ctx.clearRect(0, 0, canvas.width, canvas.height));
</script>
</body>
</html>
```

## Cara Integrasi
Drawing tool menggunakan mouse event untuk menggambar. Mode free draw mengikuti gerakan mouse. Mode line dan rectangle menggunakan titik awal dan akhir. Warna dan ukuran brush bisa diatur.
