# 399. Mengimplementasikan Resize Gambar dengan Input Width dan Height

## Definisi & Target
Mengimplementasikan fitur resize untuk mengubah dimensi gambar dengan input width dan height. Targetnya adalah pengguna bisa mengubah ukuran gambar sesuai kebutuhan.

## Analogi Alur
Seperti mesin fotokopi yang bisa memperbesar atau memperkecil ukuran salinan. Anda menentukan dimensi baru yang diinginkan.

## Poin-Poin Penting
- Input number untuk width dan height
- Lock aspect ratio (proporsional)
- Preview hasil resize
- Gunakan drawImage dengan ukuran baru

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Resize Gambar</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; display: flex; justify-content: center; flex-direction: column; align-items: center; padding: 20px; gap: 16px; }
canvas { border-radius: 12px; border: 1px solid rgba(255,255,255,0.1); max-width: 100%; }
.resize-panel { background: #16213e; padding: 16px 20px; border-radius: 12px; display: flex; align-items: center; gap: 12px; }
.resize-panel label { color: #aaa; font-size: 13px; }
.resize-panel input[type="number"] { width: 70px; padding: 6px 10px; background: #2a3a6a; border: 1px solid rgba(255,255,255,0.1); border-radius: 6px; color: #fff; font-size: 13px; outline: none; }
.resize-panel input[type="checkbox"] { accent-color: #4CAF50; }
.resize-panel button { padding: 8px 20px; background: #4CAF50; color: #fff; border: none; border-radius: 6px; cursor: pointer; font-size: 13px; }
.controls { display: flex; gap: 10px; }
.controls button { padding: 8px 16px; background: #2a3a6a; color: #fff; border: none; border-radius: 6px; cursor: pointer; font-size: 13px; }
input[type="file"] { display: none; }
</style>
</head>
<body>
<canvas id="canvas" width="400" height="280"></canvas>
<input type="file" id="fileInput" accept="image/*">
<div class="controls">
<button id="loadBtn">📁 Muat</button>
</div>
<div class="resize-panel">
<label>Width</label><input type="number" id="newWidth" min="1" value="400">
<label>Height</label><input type="number" id="newHeight" min="1" value="280">
<label><input type="checkbox" id="lockRatio" checked> 🔒</label>
<button id="resizeBtn">Terapkan</button>
</div>
<script>
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
const fileInput = document.getElementById('fileInput');
let currentImage = null;
let originalW = 400, originalH = 280;
document.getElementById('loadBtn').addEventListener('click', () => fileInput.click());
fileInput.addEventListener('change', function() {
const file = this.files[0];
if (!file) return;
const reader = new FileReader();
reader.onload = (e) => {
const img = new Image();
img.onload = () => { currentImage = img; originalW = img.width; originalH = img.height; canvas.width = Math.min(img.width, 600); canvas.height = Math.min(img.height, 450); ctx.drawImage(img, 0, 0, canvas.width, canvas.height); document.getElementById('newWidth').value = canvas.width; document.getElementById('newHeight').value = canvas.height; };
img.src = e.target.result;
};
reader.readAsDataURL(file);
});
document.getElementById('newWidth').addEventListener('input', function() {
if (document.getElementById('lockRatio').checked) { document.getElementById('newHeight').value = Math.round(this.value * originalH / originalW); }
});
document.getElementById('newHeight').addEventListener('input', function() {
if (document.getElementById('lockRatio').checked) { document.getElementById('newWidth').value = Math.round(this.value * originalW / originalH); }
});
document.getElementById('resizeBtn').addEventListener('click', function() {
if (!currentImage) return;
const w = parseInt(document.getElementById('newWidth').value);
const h = parseInt(document.getElementById('newHeight').value);
if (w < 1 || h < 1) return;
canvas.width = w; canvas.height = h;
ctx.drawImage(currentImage, 0, 0, w, h);
originalW = w; originalH = h;
});
</script>
</body>
</html>
```

## Cara Integrasi
Resize menggunakan drawImage dengan parameter width dan height baru. Lock aspect ratio menjaga proporsi dengan menghitung rasio asli. Canvas diubah ukurannya sesuai dimensi baru.
