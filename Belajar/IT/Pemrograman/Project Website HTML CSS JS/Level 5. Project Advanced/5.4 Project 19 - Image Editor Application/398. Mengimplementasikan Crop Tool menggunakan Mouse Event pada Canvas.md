# 398. Mengimplementasikan Crop Tool menggunakan Mouse Event pada Canvas

## Definisi & Target
Mengimplementasikan crop tool yang memungkinkan pengguna memilih area persegi panjang pada gambar dengan mouse. Targetnya adalah pemotongan gambar yang presisi.

## Analogi Alur
Seperti gunting yang memotong foto - Anda menentukan area yang ingin dipotong dengan menarik garis persegi panjang.

## Poin-Poin Penting
- Mouse event: mousedown, mousemove, mouseup
- Drag untuk menentukan area crop
- Overlay semi-transparan di luar area crop
- Preview area yang akan di-crop

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Crop Tool</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; display: flex; justify-content: center; flex-direction: column; align-items: center; padding: 20px; gap: 16px; }
.canvas-wrapper { position: relative; display: inline-block; }
canvas { border-radius: 12px; border: 1px solid rgba(255,255,255,0.1); display: block; cursor: crosshair; }
.overlay { position: absolute; inset: 0; pointer-events: none; }
.controls { display: flex; gap: 10px; }
.controls button { padding: 10px 20px; background: #2a3a6a; color: #fff; border: none; border-radius: 8px; cursor: pointer; font-size: 14px; }
.controls button.primary { background: #4CAF50; }
input[type="file"] { display: none; }
</style>
</head>
<body>
<div class="canvas-wrapper">
<canvas id="canvas" width="400" height="280"></canvas>
<canvas id="overlay" class="overlay" width="400" height="280"></canvas>
</div>
<input type="file" id="fileInput" accept="image/*">
<div class="controls">
<button id="loadBtn">📁 Muat</button>
<button class="primary" id="cropBtn">✂️ Crop</button>
</div>
<script>
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
const overlay = document.getElementById('overlay');
const oCtx = overlay.getContext('2d');
const fileInput = document.getElementById('fileInput');
let isDragging = false, startX, startY, endX, endY;
let cropActive = false;
document.getElementById('loadBtn').addEventListener('click', () => fileInput.click());
fileInput.addEventListener('change', function() {
const file = this.files[0];
if (!file) return;
const reader = new FileReader();
reader.onload = (e) => {
const img = new Image();
img.onload = () => { canvas.width = Math.min(img.width, 600); canvas.height = Math.min(img.height, 450); overlay.width = canvas.width; overlay.height = canvas.height; ctx.drawImage(img, 0, 0, canvas.width, canvas.height); };
img.src = e.target.result;
};
reader.readAsDataURL(file);
});
canvas.addEventListener('mousedown', (e) => {
const rect = canvas.getBoundingClientRect();
startX = e.clientX - rect.left; startY = e.clientY - rect.top; endX = startX; endY = startY; isDragging = true; cropActive = true;
});
canvas.addEventListener('mousemove', (e) => {
if (!isDragging) return;
const rect = canvas.getBoundingClientRect();
endX = Math.min(Math.max(e.clientX - rect.left, 0), canvas.width);
endY = Math.min(Math.max(e.clientY - rect.top, 0), canvas.height);
drawOverlay();
});
canvas.addEventListener('mouseup', () => { isDragging = false; });
function drawOverlay() {
oCtx.clearRect(0, 0, overlay.width, overlay.height);
const x = Math.min(startX, endX), y = Math.min(startY, endY), w = Math.abs(endX - startX), h = Math.abs(endY - startY);
oCtx.fillStyle = 'rgba(0,0,0,0.4)';
oCtx.fillRect(0, 0, overlay.width, overlay.height);
oCtx.clearRect(x, y, w, h);
oCtx.strokeStyle = '#fff';
oCtx.lineWidth = 2;
oCtx.setLineDash([6, 4]);
oCtx.strokeRect(x, y, w, h);
}
document.getElementById('cropBtn').addEventListener('click', () => {
if (!cropActive) return;
const x = Math.min(startX, endX), y = Math.min(startY, endY), w = Math.abs(endX - startX), h = Math.abs(endY - startY);
if (w < 5 || h < 5) return;
const imgData = ctx.getImageData(x, y, w, h);
canvas.width = w; canvas.height = h; overlay.width = w; overlay.height = h;
ctx.putImageData(imgData, 0, 0);
oCtx.clearRect(0, 0, w, h);
cropActive = false;
});
</script>
</body>
</html>
```

## Cara Integrasi
Overlay canvas transparan digunakan untuk menggambar area crop. Mouse event menentukan koordinat awal dan akhir. getImageData mengambil pixel area yang dipilih.
