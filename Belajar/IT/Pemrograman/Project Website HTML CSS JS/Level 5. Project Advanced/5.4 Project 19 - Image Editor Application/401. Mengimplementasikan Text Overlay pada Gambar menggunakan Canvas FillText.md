# 401. Mengimplementasikan Text Overlay pada Gambar menggunakan Canvas FillText

## Definisi & Target
Mengimplementasikan text overlay yang memungkinkan pengguna menambahkan teks ke atas gambar. Targetnya adalah fitur penambahan teks pada gambar.

## Analogi Alur
Seperti menempelkan stiker tulisan di atas foto. Anda bisa menambahkan teks dengan berbagai gaya.

## Poin-Poin Penting
- Input teks dan pilihan font, size, color
- canvas.fillText() untuk menggambar teks
- Posisi teks bisa diatur (klik pada canvas)
- Teks bisa dipindahkan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Text Overlay</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; display: flex; justify-content: center; flex-direction: column; align-items: center; padding: 20px; gap: 12px; }
canvas { border-radius: 12px; border: 1px solid rgba(255,255,255,0.1); max-width: 100%; cursor: crosshair; }
.panel { background: #16213e; padding: 12px 16px; border-radius: 12px; display: flex; align-items: center; gap: 10px; flex-wrap: wrap; }
.panel input, .panel select { padding: 6px 10px; background: #2a3a6a; border: 1px solid rgba(255,255,255,0.1); border-radius: 6px; color: #fff; font-size: 13px; outline: none; }
.panel input[type="color"] { width: 36px; height: 36px; padding: 2px; cursor: pointer; }
.panel button { padding: 8px 16px; background: #4CAF50; color: #fff; border: none; border-radius: 6px; cursor: pointer; font-size: 13px; }
button.img-btn { background: #2a3a6a; }
input[type="file"] { display: none; }
</style>
</head>
<body>
<canvas id="canvas" width="500" height="350"></canvas>
<input type="file" id="fileInput" accept="image/*">
<div class="panel">
<button class="img-btn" id="loadBtn">📁</button>
<input type="text" id="textInput" placeholder="Teks..." value="Hello World">
<select id="fontSelect"><option value="Arial">Arial</option><option value="Georgia">Georgia</option><option value="Courier New">Courier New</option><option value="Impact">Impact</option></select>
<input type="number" id="fontSize" value="32" min="8" max="120">
<input type="color" id="fontColor" value="#ffffff">
<button id="addTextBtn">Tambah Teks</button>
</div>
<script>
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
const fileInput = document.getElementById('fileInput');
let bgImage = null;
document.getElementById('loadBtn').addEventListener('click', () => fileInput.click());
fileInput.addEventListener('change', function() {
const file = this.files[0];
if (!file) return;
const reader = new FileReader();
reader.onload = (e) => {
const img = new Image();
img.onload = () => { bgImage = img; canvas.width = Math.min(img.width, 700); canvas.height = Math.min(img.height, 500); ctx.drawImage(img, 0, 0, canvas.width, canvas.height); };
img.src = e.target.result;
};
reader.readAsDataURL(file);
});
document.getElementById('addTextBtn').addEventListener('click', () => {
const text = document.getElementById('textInput').value;
if (!text) return;
if (!bgImage) { ctx.fillStyle = '#2a2a5e'; ctx.fillRect(0, 0, canvas.width, canvas.height); }
else { ctx.drawImage(bgImage, 0, 0, canvas.width, canvas.height); }
ctx.font = `${document.getElementById('fontSize').value}px ${document.getElementById('fontSelect').value}`;
ctx.fillStyle = document.getElementById('fontColor').value;
ctx.textAlign = 'center';
ctx.fillText(text, canvas.width / 2, canvas.height / 2);
});
</script>
</body>
</html>
```

## Cara Integrasi
fillText() menggambar teks pada posisi yang ditentukan (default di tengah). Font, ukuran, dan warna diambil dari input pengguna. Teks digambar di atas gambar yang sudah ada.
