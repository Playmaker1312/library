# 397. Mengimplementasikan Flip Horizontal dan Vertical

## Definisi & Target
Mengimplementasikan flip (mencerminkan) gambar secara horizontal dan vertikal. Targetnya adalah transformasi pencerminan gambar.

## Analogi Alur
Seperti melihat bayangan di cermin - flip horizontal seperti bercermin, flip vertikal seperti membalikkan gambar terbalik.

## Poin-Poin Penting
- Flip horizontal: membalik sumbu X
- Flip vertical: membalik sumbu Y
- Gunakan scale(-1, 1) atau scale(1, -1)
- Translate untuk kompensasi posisi

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Flip Gambar</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; display: flex; justify-content: center; flex-direction: column; align-items: center; padding: 20px; gap: 16px; }
canvas { border-radius: 12px; border: 1px solid rgba(255,255,255,0.1); max-width: 100%; }
.controls { display: flex; gap: 10px; }
.controls button { padding: 10px 20px; background: #2a3a6a; color: #fff; border: none; border-radius: 8px; cursor: pointer; font-size: 14px; }
.controls button:hover { background: #3a4a7a; }
input[type="file"] { display: none; }
</style>
</head>
<body>
<canvas id="canvas" width="400" height="280"></canvas>
<input type="file" id="fileInput" accept="image/*">
<div class="controls">
<button id="loadBtn">📁 Muat</button>
<button id="flipH">↔ Horizontal</button>
<button id="flipV">↕ Vertical</button>
</div>
<script>
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
const fileInput = document.getElementById('fileInput');
let currentImage = null;
document.getElementById('loadBtn').addEventListener('click', () => fileInput.click());
fileInput.addEventListener('change', function() {
const file = this.files[0];
if (!file) return;
const reader = new FileReader();
reader.onload = (e) => {
const img = new Image();
img.onload = () => { currentImage = img; canvas.width = Math.min(img.width, 600); canvas.height = Math.min(img.height, 400); ctx.drawImage(img, 0, 0, canvas.width, canvas.height); };
img.src = e.target.result;
};
reader.readAsDataURL(file);
});
function flipHorizontal() {
if (!currentImage) return;
const imgData = ctx.getImageData(0, 0, canvas.width, canvas.height);
const tempCanvas = document.createElement('canvas');
tempCanvas.width = canvas.width; tempCanvas.height = canvas.height;
const tempCtx = tempCanvas.getContext('2d');
tempCtx.translate(canvas.width, 0);
tempCtx.scale(-1, 1);
tempCtx.drawImage(canvas, 0, 0);
ctx.clearRect(0, 0, canvas.width, canvas.height);
ctx.drawImage(tempCanvas, 0, 0);
}
function flipVertical() {
if (!currentImage) return;
const tempCanvas = document.createElement('canvas');
tempCanvas.width = canvas.width; tempCanvas.height = canvas.height;
const tempCtx = tempCanvas.getContext('2d');
tempCtx.translate(0, canvas.height);
tempCtx.scale(1, -1);
tempCtx.drawImage(canvas, 0, 0);
ctx.clearRect(0, 0, canvas.width, canvas.height);
ctx.drawImage(tempCanvas, 0, 0);
}
document.getElementById('flipH').addEventListener('click', flipHorizontal);
document.getElementById('flipV').addEventListener('click', flipVertical);
</script>
</body>
</html>
```

## Cara Integrasi
Flip menggunakan scale negatif pada sumbu yang diinginkan. translate digunakan untuk mengkompensasi perpindahan posisi akibat scale negatif. Hasil digambar ke canvas temporary lalu dikembalikan.
