# 392. Mengimplementasikan Filter Contrast, Saturation, dan Hue-Rotate

## Definisi & Target
Mengimplementasikan filter contrast, saturation, dan hue-rotate untuk memanipulasi tampilan warna gambar. Targetnya adalah kontrol warna yang lengkap.

## Analogi Alur
Seperti remote TV yang bisa mengatur kontras, kejenuhan warna, dan corak warna. Setiap slider mengubah aspek warna yang berbeda.

## Poin-Poin Penting
- Contrast: tingkat perbedaan gelap-terang
- Saturation: kejenuhan warna
- Hue-rotate: perputaran warna
- Semua filter menggunakan pixel manipulation

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Filter Warna</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; display: flex; justify-content: center; flex-direction: column; align-items: center; padding: 20px; gap: 12px; }
canvas { border-radius: 12px; border: 1px solid rgba(255,255,255,0.1); max-width: 100%; }
.controls { background: #16213e; padding: 16px 20px; border-radius: 12px; display: flex; flex-direction: column; gap: 10px; width: 420px; }
.row { display: flex; align-items: center; gap: 10px; }
.row label { color: #aaa; font-size: 12px; width: 80px; }
.row input[type="range"] { flex: 1; }
.row span { color: #fff; font-size: 12px; min-width: 30px; text-align: center; }
button { padding: 8px 16px; background: #4CAF50; color: #fff; border: none; border-radius: 6px; cursor: pointer; font-size: 13px; }
input[type="file"] { display: none; }
</style>
</head>
<body>
<canvas id="canvas" width="400" height="280"></canvas>
<input type="file" id="fileInput" accept="image/*">
<div class="controls">
<div class="row"><label>Contrast</label><input type="range" id="contrastSlider" min="0" max="200" value="100"><span id="contrastVal">100</span></div>
<div class="row"><label>Saturation</label><input type="range" id="saturationSlider" min="0" max="200" value="100"><span id="saturationVal">100</span></div>
<div class="row"><label>Hue</label><input type="range" id="hueSlider" min="0" max="360" value="0"><span id="hueVal">0</span></div>
<button id="loadBtn">Muat Gambar</button>
</div>
<script>
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
const fileInput = document.getElementById('fileInput');
let originalData = null;
document.getElementById('loadBtn').addEventListener('click', () => fileInput.click());
fileInput.addEventListener('change', function() {
const file = this.files[0];
if (!file) return;
const reader = new FileReader();
reader.onload = (e) => {
const img = new Image();
img.onload = () => { canvas.width = Math.min(img.width, 600); canvas.height = Math.min(img.height, 400); ctx.drawImage(img, 0, 0, canvas.width, canvas.height); originalData = ctx.getImageData(0, 0, canvas.width, canvas.height); };
img.src = e.target.result;
};
reader.readAsDataURL(file);
});
function applyFilters() {
if (!originalData) return;
const src = originalData.data;
const imgData = new ImageData(new Uint8ClampedArray(src), originalData.width, originalData.height);
const d = imgData.data;
const contrast = parseInt(document.getElementById('contrastSlider').value) / 100;
const saturation = parseInt(document.getElementById('saturationSlider').value) / 100;
const hue = parseInt(document.getElementById('hueSlider').value) * Math.PI / 180;
for (let i = 0; i < d.length; i += 4) {
let r = d[i], g = d[i+1], b = d[i+2];
r = ((r / 255 - 0.5) * contrast + 0.5) * 255;
g = ((g / 255 - 0.5) * contrast + 0.5) * 255;
b = ((b / 255 - 0.5) * contrast + 0.5) * 255;
const gray = 0.3 * r + 0.59 * g + 0.11 * b;
r = gray + (r - gray) * saturation;
g = gray + (g - gray) * saturation;
b = gray + (b - gray) * saturation;
const cos = Math.cos(hue), sin = Math.sin(hue);
const nr = r * (cos + (1 - cos) / 3) + g * ((1 - cos) / 3 - sin / Math.sqrt(3)) + b * ((1 - cos) / 3 + sin / Math.sqrt(3));
const ng = r * ((1 - cos) / 3 + sin / Math.sqrt(3)) + g * (cos + (1 - cos) / 3) + b * ((1 - cos) / 3 - sin / Math.sqrt(3));
const nb = r * ((1 - cos) / 3 - sin / Math.sqrt(3)) + g * ((1 - cos) / 3 + sin / Math.sqrt(3)) + b * (cos + (1 - cos) / 3);
d[i] = Math.max(0, Math.min(255, nr));
d[i+1] = Math.max(0, Math.min(255, ng));
d[i+2] = Math.max(0, Math.min(255, nb));
}
ctx.putImageData(imgData, 0, 0);
}
document.querySelectorAll('input[type="range"]').forEach(slider => slider.addEventListener('input', function() {
document.getElementById(this.id.replace('Slider', 'Val')).textContent = this.value;
applyFilters();
}));
</script>
</body>
</html>
```

## Cara Integrasi
Ketiga filter diterapkan secara berurutan pada pixel data canvas. Contrast menggunakan faktor pengali, saturation menginterpolasi dengan grayscale, hue-rotate menggunakan matriks rotasi RGB.
