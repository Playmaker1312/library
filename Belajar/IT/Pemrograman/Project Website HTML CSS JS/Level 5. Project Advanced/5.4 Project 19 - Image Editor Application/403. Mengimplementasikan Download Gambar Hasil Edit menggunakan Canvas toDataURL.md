# 403. Mengimplementasikan Download Gambar Hasil Edit menggunakan Canvas toDataURL

## Definisi & Target
Mengimplementasikan fitur download yang memungkinkan pengguna menyimpan gambar hasil edit ke komputer. Targetnya adalah ekspor gambar yang mudah.

## Analogi Alur
Seperti mencetak foto dari printer - Anda mendapatkan hasil fisik dari karya digital Anda. toDataURL mengkonversi canvas ke format gambar.

## Poin-Poin Penting
- canvas.toDataURL() mengkonversi ke format gambar
- Format JPEG atau PNG
- Buat link download dan klik otomatis
- Beri nama file yang sesuai

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Download Gambar</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; display: flex; justify-content: center; flex-direction: column; align-items: center; padding: 20px; gap: 16px; }
canvas { border-radius: 12px; border: 1px solid rgba(255,255,255,0.1); max-width: 100%; background: #2a2a5e; }
.controls { display: flex; gap: 10px; flex-wrap: wrap; justify-content: center; }
.controls button { padding: 10px 20px; border: none; border-radius: 8px; cursor: pointer; font-size: 14px; color: #fff; }
.primary { background: #4CAF50; }
.secondary { background: #2a3a6a; }
input[type="file"] { display: none; }
select { padding: 8px 12px; background: #2a3a6a; color: #fff; border: none; border-radius: 6px; font-size: 13px; outline: none; }
</style>
</head>
<body>
<canvas id="canvas" width="400" height="280"></canvas>
<input type="file" id="fileInput" accept="image/*">
<div class="controls">
<button class="secondary" id="loadBtn">📁 Muat</button>
<button class="secondary" id="drawBtn">🎨 Gambar</button>
<select id="formatSelect"><option value="png">PNG</option><option value="jpeg">JPEG</option></select>
<button class="primary" id="downloadBtn">💾 Download</button>
</div>
<script>
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
const fileInput = document.getElementById('fileInput');
document.getElementById('loadBtn').addEventListener('click', () => fileInput.click());
fileInput.addEventListener('change', function() {
const file = this.files[0];
if (!file) return;
const reader = new FileReader();
reader.onload = (e) => {
const img = new Image();
img.onload = () => { canvas.width = Math.min(img.width, 700); canvas.height = Math.min(img.height, 500); ctx.drawImage(img, 0, 0, canvas.width, canvas.height); };
img.src = e.target.result;
};
reader.readAsDataURL(file);
});
document.getElementById('drawBtn').addEventListener('click', () => {
ctx.fillStyle = '#ff4444'; ctx.font = '40px Arial'; ctx.textAlign = 'center'; ctx.fillText('Hasil Edit', canvas.width/2, canvas.height/2);
ctx.strokeStyle = '#44ff44'; ctx.lineWidth = 4; ctx.strokeRect(20, 20, canvas.width-40, canvas.height-40);
});
document.getElementById('downloadBtn').addEventListener('click', () => {
const format = document.getElementById('formatSelect').value;
const mime = format === 'png' ? 'image/png' : 'image/jpeg';
const dataUrl = canvas.toDataURL(mime);
const link = document.createElement('a');
link.download = `gambar_edit.${format}`;
link.href = dataUrl;
document.body.appendChild(link);
link.click();
document.body.removeChild(link);
});
</script>
</body>
</html>
```

## Cara Integrasi
canvas.toDataURL(mimeType) menghasilkan data URL base64 dari canvas. Link download dibuat secara dinamis, di-klik otomatis, lalu dihapus. Format PNG (lossless) dan JPEG (kompresi) tersedia.
