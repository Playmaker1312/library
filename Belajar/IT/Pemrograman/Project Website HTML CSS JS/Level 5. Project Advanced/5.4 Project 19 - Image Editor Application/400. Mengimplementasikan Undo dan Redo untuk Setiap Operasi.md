# 400. Mengimplementasikan Undo dan Redo untuk Setiap Operasi

## Definisi & Target
Mengimplementasikan undo dan redo untuk setiap operasi editing gambar. Targetnya adalah pengguna bisa membatalkan atau mengulangi perubahan.

## Analogi Alur
Seperti mesin waktu untuk foto - Anda bisa kembali ke versi sebelumnya atau maju ke versi setelahnya. Setiap perubahan disimpan sebagai snapshot.

## Poin-Poin Penting
- Simpan ImageData sebelum setiap operasi
- Stack untuk undo dan redo
- Tombol undo (Ctrl+Z) dan redo (Ctrl+Shift+Z)
- Batas maksimal stack

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Undo Redo Editor</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; display: flex; justify-content: center; flex-direction: column; align-items: center; padding: 20px; gap: 16px; }
canvas { border-radius: 12px; border: 1px solid rgba(255,255,255,0.1); max-width: 100%; }
.controls { display: flex; gap: 10px; }
.controls button { padding: 10px 20px; border: none; border-radius: 8px; cursor: pointer; font-size: 14px; color: #fff; }
.controls button:disabled { opacity: 0.4; cursor: not-allowed; }
.controls button.primary { background: #4CAF50; }
.controls button:not(.primary) { background: #2a3a6a; }
input[type="file"] { display: none; }
</style>
</head>
<body>
<canvas id="canvas" width="400" height="280"></canvas>
<input type="file" id="fileInput" accept="image/*">
<div class="controls">
<button id="loadBtn">📁 Muat</button>
<button id="undoBtn" disabled>↩ Undo</button>
<button id="redoBtn" disabled>↪ Redo</button>
<button id="grayscaleBtn" class="primary">⚫ Grayscale</button>
</div>
<script>
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
const fileInput = document.getElementById('fileInput');
const undoBtn = document.getElementById('undoBtn');
const redoBtn = document.getElementById('redoBtn');
const MAX_STACK = 15;
let undoStack = [];
let redoStack = [];
function saveState() {
undoStack.push(ctx.getImageData(0, 0, canvas.width, canvas.height));
if (undoStack.length > MAX_STACK) undoStack.shift();
redoStack = [];
updateButtons();
}
function updateButtons() { undoBtn.disabled = undoStack.length === 0; redoBtn.disabled = redoStack.length === 0; }
function undo() {
if (undoStack.length === 0) return;
redoStack.push(ctx.getImageData(0, 0, canvas.width, canvas.height));
const state = undoStack.pop();
canvas.width = state.width; canvas.height = state.height;
ctx.putImageData(state, 0, 0);
updateButtons();
}
function redo() {
if (redoStack.length === 0) return;
undoStack.push(ctx.getImageData(0, 0, canvas.width, canvas.height));
const state = redoStack.pop();
canvas.width = state.width; canvas.height = state.height;
ctx.putImageData(state, 0, 0);
updateButtons();
}
undoBtn.addEventListener('click', undo);
redoBtn.addEventListener('click', redo);
document.addEventListener('keydown', (e) => { if (e.ctrlKey && e.key === 'z' && !e.shiftKey) { e.preventDefault(); undo(); } if ((e.ctrlKey && e.key === 'y') || (e.ctrlKey && e.key === 'z' && e.shiftKey)) { e.preventDefault(); redo(); } });
document.getElementById('loadBtn').addEventListener('click', () => fileInput.click());
fileInput.addEventListener('change', function() {
const file = this.files[0];
if (!file) return;
const reader = new FileReader();
reader.onload = (e) => {
const img = new Image();
img.onload = () => { canvas.width = Math.min(img.width, 600); canvas.height = Math.min(img.height, 450); ctx.drawImage(img, 0, 0, canvas.width, canvas.height); saveState(); };
img.src = e.target.result;
};
reader.readAsDataURL(file);
});
document.getElementById('grayscaleBtn').addEventListener('click', () => {
saveState();
const imgData = ctx.getImageData(0, 0, canvas.width, canvas.height);
const d = imgData.data;
for (let i = 0; i < d.length; i += 4) { const g = 0.3 * d[i] + 0.59 * d[i+1] + 0.11 * d[i+2]; d[i] = d[i+1] = d[i+2] = g; }
ctx.putImageData(imgData, 0, 0);
});
</script>
</body>
</html>
```

## Cara Integrasi
Sebelum setiap operasi, saveState() menyimpan ImageData canvas ke undoStack. Undo mengembalikan ImageData dari stack. Redo mengambil dari redoStack. Stack terbatas 15 entry.
