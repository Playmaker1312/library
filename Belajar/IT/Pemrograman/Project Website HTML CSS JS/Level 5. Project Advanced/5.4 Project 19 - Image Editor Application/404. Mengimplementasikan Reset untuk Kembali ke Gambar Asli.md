# 404. Mengimplementasikan Reset untuk Kembali ke Gambar Asli

## Definisi & Target
Mengimplementasikan fitur reset yang mengembalikan gambar ke keadaan asli saat pertama kali diupload. Targetnya adalah pemulihan gambar orisinal.

## Analogi Alur
Seperti tombol "undo semua" yang mengembalikan foto ke kondisi awal sebelum diedit. Semua filter dan perubahan dihapus.

## Poin-Poin Penting
- Simpan salinan gambar asli saat upload
- Tombol reset untuk mengembalikan
- Hapus semua filter dan perubahan
- Konfirmasi sebelum reset

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Reset Gambar</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; display: flex; justify-content: center; flex-direction: column; align-items: center; padding: 20px; gap: 16px; }
canvas { border-radius: 12px; border: 1px solid rgba(255,255,255,0.1); max-width: 100%; background: #2a2a5e; }
.controls { display: flex; gap: 10px; }
.controls button { padding: 10px 20px; border: none; border-radius: 8px; cursor: pointer; font-size: 14px; color: #fff; }
.primary { background: #4CAF50; }
.danger { background: #e53935; }
.secondary { background: #2a3a6a; }
input[type="file"] { display: none; }
</style>
</head>
<body>
<canvas id="canvas" width="400" height="280"></canvas>
<input type="file" id="fileInput" accept="image/*">
<div class="controls">
<button class="secondary" id="loadBtn">📁 Muat</button>
<button class="secondary" id="filterBtn">⚫ Efek</button>
<button class="danger" id="resetBtn">↩ Reset</button>
</div>
<script>
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
const fileInput = document.getElementById('fileInput');
let originalData = null;
document.getElementById('loadBtn').addEventListener('click', () => fileInput.click());
fileInput.addEventListener('change', function() {
const file = this.files[0];
if (!file) return;
const reader = new FileReader();
reader.onload = (e) => {
const img = new Image();
img.onload = () => {
canvas.width = Math.min(img.width, 700);
canvas.height = Math.min(img.height, 500);
ctx.drawImage(img, 0, 0, canvas.width, canvas.height);
originalData = ctx.getImageData(0, 0, canvas.width, canvas.height);
};
img.src = e.target.result;
};
reader.readAsDataURL(file);
});
document.getElementById('filterBtn').addEventListener('click', () => {
if (!originalData) return;
const imgData = new ImageData(new Uint8ClampedArray(originalData.data), originalData.width, originalData.height);
const d = imgData.data;
for (let i = 0; i < d.length; i += 4) {
d[i] = Math.min(255, d[i] * 1.5);
d[i+1] = Math.min(255, d[i+1] * 1.2);
d[i+2] = Math.min(255, d[i+2] * 1.5);
const g = 0.3 * d[i] + 0.59 * d[i+1] + 0.11 * d[i+2];
d[i] = d[i+1] = d[i+2] = g * 0.3 + d[i] * 0.7;
}
ctx.putImageData(imgData, 0, 0);
});
document.getElementById('resetBtn').addEventListener('click', () => {
if (!originalData) return;
if (confirm('Kembalikan ke gambar asli?')) {
canvas.width = originalData.width;
canvas.height = originalData.height;
ctx.putImageData(originalData, 0, 0);
}
});
</script>
</body>
</html>
```

## Cara Integrasi
Saat gambar dimuat, ImageData asli disimpan di variabel originalData. Tombol reset mengembalikan canvas ke originalData menggunakan putImageData. Konfirmasi mencegah reset tidak sengaja.
