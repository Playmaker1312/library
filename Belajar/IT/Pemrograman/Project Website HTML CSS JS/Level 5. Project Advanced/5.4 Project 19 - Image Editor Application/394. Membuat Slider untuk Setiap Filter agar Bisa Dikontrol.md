# 394. Membuat Slider untuk Setiap Filter agar Bisa Dikontrol

## Definisi & Target
Membuat slider interaktif untuk setiap filter agar pengguna bisa mengontrol intensitas filter secara real-time. Targetnya adalah kontrol filter yang presisi dan mudah.

## Analogi Alur
Seperti panel mixing di studio audio yang memiliki banyak slider untuk mengontrol setiap aspek suara. Setiap slider mengontrol satu aspek gambar.

## Poin-Poin Penting
- Slider untuk brightness, contrast, saturation, hue
- Slider untuk grayscale, sepia, invert intensity
- Nilai slider ditampilkan secara real-time
- Semua slider bisa digerakkan bersamaan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Slider Filter</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; display: flex; justify-content: center; flex-direction: column; align-items: center; padding: 20px; gap: 12px; }
canvas { border-radius: 12px; max-width: 100%; border: 1px solid rgba(255,255,255,0.1); }
.panel { background: #16213e; border-radius: 12px; padding: 16px 20px; width: 440px; display: flex; flex-direction: column; gap: 8px; }
.slider-row { display: flex; align-items: center; gap: 8px; }
.slider-row label { color: #aaa; font-size: 12px; width: 90px; }
.slider-row input[type="range"] { flex: 1; }
.slider-row .val { color: #fff; font-size: 12px; min-width: 28px; text-align: center; }
button { padding: 8px 16px; background: #4CAF50; color: #fff; border: none; border-radius: 6px; cursor: pointer; font-size: 13px; }
input[type="file"] { display: none; }
</style>
</head>
<body>
<canvas id="canvas" width="400" height="260"></canvas>
<input type="file" id="fileInput" accept="image/*">
<div class="panel">
<div class="slider-row"><label>Brightness</label><input type="range" class="filter-slider" id="bri" min="0" max="200" value="100"><span class="val" id="briVal">100</span></div>
<div class="slider-row"><label>Contrast</label><input type="range" class="filter-slider" id="con" min="0" max="200" value="100"><span class="val" id="conVal">100</span></div>
<div class="slider-row"><label>Saturation</label><input type="range" class="filter-slider" id="sat" min="0" max="200" value="100"><span class="val" id="satVal">100</span></div>
<div class="slider-row"><label>Grayscale</label><input type="range" class="filter-slider" id="gray" min="0" max="100" value="0"><span class="val" id="grayVal">0</span></div>
<button id="loadBtn">📁 Muat Gambar</button>
</div>
<script>
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
const fileInput = document.getElementById('fileInput');
let originalData = null;
document.getElementById('loadBtn').addEventListener('click', () => fileInput.click());
fileInput.addEventListener('change', function() {
const file = this.files[0];
if (!file) return;
const reader = new FileReader();
reader.onload = (e) => {
const img = new Image();
img.onload = () => { canvas.width = Math.min(img.width, 600); canvas.height = Math.min(img.height, 400); ctx.drawImage(img, 0, 0, canvas.width, canvas.height); originalData = ctx.getImageData(0, 0, canvas.width, canvas.height); };
img.src = e.target.result;
};
reader.readAsDataURL(file);
});
function applyAll() {
if (!originalData) return;
const src = originalData.data;
const imgData = new ImageData(new Uint8ClampedArray(src), originalData.width, originalData.height);
const d = imgData.data;
const b = parseInt(document.getElementById('bri').value) / 100;
const c = parseInt(document.getElementById('con').value) / 100;
const s = parseInt(document.getElementById('sat').value) / 100;
const g = parseInt(document.getElementById('gray').value) / 100;
for (let i = 0; i < d.length; i += 4) {
let r = d[i] * b, g2 = d[i+1] * b, b2 = d[i+2] * b;
r = ((r / 255 - 0.5) * c + 0.5) * 255; g2 = ((g2 / 255 - 0.5) * c + 0.5) * 255; b2 = ((b2 / 255 - 0.5) * c + 0.5) * 255;
const gray = 0.3 * r + 0.59 * g2 + 0.11 * b2;
r = gray + (r - gray) * s; g2 = gray + (g2 - gray) * s; b2 = gray + (b2 - gray) * s;
r = r * (1 - g) + gray * g; g2 = g2 * (1 - g) + gray * g; b2 = b2 * (1 - g) + gray * g;
d[i] = Math.max(0, Math.min(255, r)); d[i+1] = Math.max(0, Math.min(255, g2)); d[i+2] = Math.max(0, Math.min(255, b2));
}
ctx.putImageData(imgData, 0, 0);
}
document.querySelectorAll('.filter-slider').forEach(sl => sl.addEventListener('input', function() { document.getElementById(this.id + 'Val').textContent = this.value; applyAll(); }));
</script>
</body>
</html>
```

## Cara Integrasi
Setiap slider memiliki ID unik. Event input pada semua slider memicu applyAll() yang membaca semua nilai slider dan menerapkan kombinasi filter ke pixel data canvas.
