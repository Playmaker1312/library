# 393. Mengimplementasikan Filter Grayscale, Sepia, dan Invert

## Definisi & Target
Mengimplementasikan filter efek khusus seperti grayscale (hitam-putih), sepia (kuno), dan invert (negatif). Targetnya adalah efek foto yang populer.

## Analogi Alur
Seperti lensa kamera dengan efek khusus: hitam putih untuk foto klasik, sepia untuk foto jadul, dan negatif untuk efek film.

## Poin-Poin Penting
- Grayscale: mengkonversi ke hitam putih
- Sepia: warna kecoklatan klasik
- Invert: membalikkan warna (negatif)
- Setiap filter adalah algoritma pixel

```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Filter Efek</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; display: flex; justify-content: center; flex-direction: column; align-items: center; padding: 20px; gap: 16px; }
canvas { border-radius: 12px; border: 1px solid rgba(255,255,255,0.1); max-width: 100%; }
.controls { display: flex; gap: 10px; flex-wrap: wrap; justify-content: center; }
.controls button { padding: 10px 20px; border: none; border-radius: 8px; cursor: pointer; font-size: 13px; color: #fff; background: #2a3a6a; }
.controls button.active { background: #4CAF50; }
input[type="file"] { display: none; }
</style>

<body>
<canvas id="canvas" width="400" height="280"></canvas>
<input type="file" id="fileInput" accept="image/*">
<div class="controls">
<button id="loadBtn">📁 Muat</button>
<button class="filter-btn" data-filter="grayscale">⚫ Grayscale</button>
<button class="filter-btn" data-filter="sepia">🟫 Sepia</button>
<button class="filter-btn" data-filter="invert">🔄 Invert</button>
<button id="resetBtn">↩ Reset</button>
</div>
<script>
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
const fileInput = document.getElementById('fileInput');
let originalData = null;
document.getElementById('loadBtn').addEventListener('click', () => fileInput.click());
fileInput.addEventListener('change', function() {
const file = this.files[0];
if (!file) return;
const reader = new FileReader();
reader.onload = (e) => {
const img = new Image();
img.onload = () => { canvas.width = Math.min(img.width, 600); canvas.height = Math.min(img.height, 400); ctx.drawImage(img, 0, 0, canvas.width, canvas.height); originalData = ctx.getImageData(0, 0, canvas.width, canvas.height); };
img.src = e.target.result;
};
reader.readAsDataURL(file);
});
function applyFilter(type) {
if (!originalData) return;
const src = originalData.data;
const imgData = new ImageData(new Uint8ClampedArray(src), originalData.width, originalData.height);
const d = imgData.data;
for (let i = 0; i < d.length; i += 4) {
let r = d[i], g = d[i+1], b = d[i+2];
if (type === 'grayscale') { const gray = 0.3 * r + 0.59 * g + 0.11 * b; d[i] = d[i+1] = d[i+2] = gray; }
else if (type === 'sepia') { d[i] = Math.min(255, r * 0.393 + g * 0.769 + b * 0.189); d[i+1] = Math.min(255, r * 0.349 + g * 0.686 + b * 0.168); d[i+2] = Math.min(255, r * 0.272 + g * 0.534 + b * 0.131); }
else if (type === 'invert') { d[i] = 255 - r; d[i+1] = 255 - g; d[i+2] = 255 - b; }
}
ctx.putImageData(imgData, 0, 0);
}
document.querySelectorAll('.filter-btn').forEach(btn => btn.addEventListener('click', function() { document.querySelectorAll('.filter-btn').forEach(b => b.classList.remove('active')); this.classList.add('active'); applyFilter(this.dataset.filter); }));
document.getElementById('resetBtn').addEventListener('click', () => { if (originalData) { ctx.putImageData(originalData, 0, 0); document.querySelectorAll('.filter-btn').forEach(b => b.classList.remove('active')); } });
</script>
</body>
</html>
```

## Cara Integrasi
Setiap filter memiliki algoritma pixel yang berbeda. Grayscale menggunakan rata-rata tertimbang RGB. Sepia menggunakan matrix transformasi. Invert mengurangkan nilai channel dari 255.
