# 405. Memastikan Image Editor Responsive dan Usable di Tablet

## Definisi & Target
Membuat Image Editor responsif dan dapat digunakan dengan baik di perangkat tablet dan mobile. Targetnya adalah pengalaman editing yang nyaman di berbagai perangkat.

## Analogi Alur
Seperti studio foto portabel yang bisa digunakan di mana saja. Tools harus mudah diakses dan digunakan dengan sentuhan jari.

## Poin-Poin Penting
- Layout yang menyesuaikan lebar layar
- Touch events untuk mobile
- UI controls yang touch-friendly
- Canvas scaling yang proporsional

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
<title>Editor Responsive</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; display: flex; justify-content: center; padding: 12px; }
.container { width: 100%; max-width: 800px; }
canvas { width: 100%; height: auto; border-radius: 12px; border: 1px solid rgba(255,255,255,0.1); background: #2a2a5e; touch-action: none; }
.panel { background: #16213e; border-radius: 12px; padding: 12px; margin-top: 12px; display: flex; flex-wrap: wrap; gap: 8px; justify-content: center; }
.panel button { padding: 12px 18px; border: none; border-radius: 8px; cursor: pointer; font-size: 14px; color: #fff; min-height: 44px; min-width: 44px; display: flex; align-items: center; justify-content: center; }
.panel .primary { background: #4CAF50; }
.panel .secondary { background: #2a3a6a; }
.panel .danger { background: #e53935; }
.panel input[type="range"] { width: 120px; }
.panel label { color: #aaa; font-size: 12px; display: flex; align-items: center; gap: 6px; }
input[type="file"] { display: none; }
@media (max-width: 480px) {
.panel { flex-direction: column; align-items: stretch; }
.panel button { justify-content: center; }
.panel input[type="range"] { width: 100%; }
}
</style>
</head>
<body>
<div class="container">
<canvas id="canvas" width="600" height="400"></canvas>
<div class="panel">
<input type="file" id="fileInput" accept="image/*">
<button class="secondary" id="loadBtn">📁 Muat</button>
<button class="secondary" id="grayBtn">⚫</button>
<button class="primary" id="brightBtn">☀️</button>
<label>🔊 <input type="range" id="brightSlider" min="50" max="150" value="100"></label>
<button class="danger" id="resetBtn">↩</button>
</div>
</div>
<script>
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
const fileInput = document.getElementById('fileInput');
let originalData = null;
document.getElementById('loadBtn').addEventListener('click', () => fileInput.click());
fileInput.addEventListener('change', function() {
const file = this.files[0];
if (!file) return;
const reader = new FileReader();
reader.onload = (e) => {
const img = new Image();
img.onload = () => {
const w = Math.min(img.width, 800); const h = Math.min(img.height, 600);
canvas.width = w; canvas.height = h; canvas.style.aspectRatio = w / h;
ctx.drawImage(img, 0, 0, w, h);
originalData = ctx.getImageData(0, 0, w, h);
};
img.src = e.target.result;
};
reader.readAsDataURL(file);
});
document.getElementById('grayBtn').addEventListener('click', () => {
if (!originalData) return;
const imgData = new ImageData(new Uint8ClampedArray(originalData.data), originalData.width, originalData.height);
const d = imgData.data;
for (let i = 0; i < d.length; i += 4) { const g = 0.3 * d[i] + 0.59 * d[i+1] + 0.11 * d[i+2]; d[i] = d[i+1] = d[i+2] = g; }
ctx.putImageData(imgData, 0, 0);
});
document.getElementById('brightSlider').addEventListener('input', function() {
if (!originalData) return;
const imgData = new ImageData(new Uint8ClampedArray(originalData.data), originalData.width, originalData.height);
const d = imgData.data; const f = this.value / 100;
for (let i = 0; i < d.length; i += 4) { d[i] = Math.min(255, d[i] * f); d[i+1] = Math.min(255, d[i+1] * f); d[i+2] = Math.min(255, d[i+2] * f); }
ctx.putImageData(imgData, 0, 0);
});
document.getElementById('resetBtn').addEventListener('click', () => { if (originalData) { ctx.putImageData(originalData, 0, 0); document.getElementById('brightSlider').value = 100; } });
</script>
</body>
</html>
```

## Cara Integrasi
Canvas menggunakan width: 100% dengan height auto untuk responsivitas. Panel tombol menggunakan flex-wrap dan menumpuk di mobile. Touch-action: none mencegah scroll saat menggambar. Ukuran tombol minimal 44px untuk touch target.
