# 395. Mengimplementasikan Preview Real-Time saat Slider Digeser

## Definisi & Target
Memastikan preview gambar berubah secara real-time saat slider digerakkan, tanpa perlu menekan tombol terpisah. Targetnya adalah responsivitas dan kemudahan penggunaan.

## Analogi Alur
Seperti mengatur fokus kamera - Anda bisa langsung melihat perubahan secara real-time saat memutar ring fokus.

## Poin-Poin Penting
- Event input pada slider (bukan change)
- Update canvas setiap kali slider bergerak
- Performa yang baik (tidak lag)
- Debounce jika diperlukan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Preview Real-Time</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; display: flex; justify-content: center; flex-direction: column; align-items: center; padding: 20px; gap: 16px; }
canvas { border-radius: 12px; max-width: 100%; border: 1px solid rgba(255,255,255,0.1); }
.controls { background: #16213e; padding: 16px 20px; border-radius: 12px; width: 400px; }
.row { display: flex; align-items: center; gap: 10px; margin-bottom: 8px; }
.row label { color: #aaa; font-size: 12px; width: 80px; }
.row input[type="range"] { flex: 1; }
.row .val { color: #4CAF50; font-size: 12px; min-width: 30px; text-align: center; font-weight: 600; }
button, input[type="file"] { display: none; }
#loadBtn { display: inline-block; padding: 8px 16px; background: #4CAF50; color: #fff; border: none; border-radius: 6px; cursor: pointer; font-size: 13px; }
</style>
</head>
<body>
<canvas id="canvas" width="400" height="260"></canvas>
<input type="file" id="fileInput" accept="image/*">
<button id="loadBtn" onclick="document.getElementById('fileInput').click()">📁 Muat Gambar</button>
<div class="controls">
<div class="row"><label>Brightness</label><input type="range" class="slider" id="bri" min="0" max="200" value="100"><span class="val" id="briVal">100</span></div>
<div class="row"><label>Contrast</label><input type="range" class="slider" id="con" min="0" max="200" value="100"><span class="val" id="conVal">100</span></div>
<div class="row"><label>Blur</label><input type="range" class="slider" id="blur" min="0" max="10" value="0"><span class="val" id="blurVal">0</span></div>
</div>
<script>
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
const fileInput = document.getElementById('fileInput');
let originalData = null;
fileInput.addEventListener('change', function() {
const file = this.files[0];
if (!file) return;
const reader = new FileReader();
reader.onload = (e) => {
const img = new Image();
img.onload = () => { canvas.width = Math.min(img.width, 600); canvas.height = Math.min(img.height, 400); ctx.drawImage(img, 0, 0, canvas.width, canvas.height); originalData = ctx.getImageData(0, 0, canvas.width, canvas.height); };
img.src = e.target.result;
};
reader.readAsDataURL(file);
});
function update() {
if (!originalData) return;
const src = originalData.data;
const imgData = new ImageData(new Uint8ClampedArray(src), originalData.width, originalData.height);
const d = imgData.data;
const b = parseInt(document.getElementById('bri').value) / 100;
const c = parseInt(document.getElementById('con').value) / 100;
for (let i = 0; i < d.length; i += 4) {
d[i] = Math.max(0, Math.min(255, ((d[i] * b / 255 - 0.5) * c + 0.5) * 255));
d[i+1] = Math.max(0, Math.min(255, ((d[i+1] * b / 255 - 0.5) * c + 0.5) * 255));
d[i+2] = Math.max(0, Math.min(255, ((d[i+2] * b / 255 - 0.5) * c + 0.5) * 255));
}
ctx.putImageData(imgData, 0, 0);
document.getElementById('briVal').textContent = document.getElementById('bri').value;
document.getElementById('conVal').textContent = document.getElementById('con').value;
}
document.querySelectorAll('.slider').forEach(sl => sl.addEventListener('input', update));
</script>
</body>
</html>
```

## Cara Integrasi
Event input (bukan change) pada slider memberikan update real-time tanpa jeda. Setiap perubahan slider langsung memproses ulang pixel dan menggambar ke canvas.
