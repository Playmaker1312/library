# 369. Mengimplementasikan Play dan Pause menggunakan HTML5 Audio API

## Definisi & Target
Mengimplementasikan fungsi Play dan Pause menggunakan HTML5 Audio API. Targetnya adalah kontrol pemutaran audio yang berfungsi dengan baik.

## Analogi Alur
Seperti menekan tombol play pada tape recorder untuk memulai kaset dan tombol pause untuk menghentikan sementara.

## Poin-Poin Penting
- Buat objek Audio baru atau gunakan elemen <audio>
- Method play() dan pause()
- Tombol toggle antara play dan pause
- Ikon tombol berubah sesuai status

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Play Pause</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0a0a1a; display: flex; justify-content: center; align-items: center; min-height: 100vh; }
.player { background: #1a1a3e; border-radius: 20px; padding: 30px; width: 340px; text-align: center; box-shadow: 0 20px 60px rgba(0,0,0,0.5); }
.cover { width: 200px; height: 200px; border-radius: 16px; margin: 0 auto 20px; background: #2a2a5e; overflow: hidden; }
.cover img { width: 100%; height: 100%; object-fit: cover; }
.song-title { color: #fff; font-size: 20px; font-weight: 700; margin-bottom: 4px; }
.artist { color: #888; font-size: 14px; margin-bottom: 20px; }
.controls { display: flex; justify-content: center; gap: 24px; }
.controls button { width: 56px; height: 56px; border-radius: 50%; border: none; cursor: pointer; font-size: 24px; display: flex; align-items: center; justify-content: center; transition: all 0.2s; }
#playBtn { background: #4CAF50; color: #fff; }
#playBtn:hover { transform: scale(1.05); }
.status { color: #888; font-size: 12px; margin-top: 12px; }
</style>
</head>
<body>
<div class="player">
<div class="cover"><img src="https://via.placeholder.com/200/4CAF50/fff?text=Music" alt="Album"></div>
<div class="song-title">Heal the World</div>
<div class="artist">Michael Jackson</div>
<div class="controls"><button id="playBtn">▶</button></div>
<div class="status" id="status">Ready to play</div>
</div>
<audio id="audio" src="https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3"></audio>
<script>
const audio = document.getElementById('audio');
const playBtn = document.getElementById('playBtn');
const status = document.getElementById('status');
playBtn.addEventListener('click', () => {
if (audio.paused) { audio.play(); playBtn.textContent = '⏸'; status.textContent = 'Playing...'; }
else { audio.pause(); playBtn.textContent = '▶'; status.textContent = 'Paused'; }
});
audio.addEventListener('ended', () => { playBtn.textContent = '▶'; status.textContent = 'Finished'; });
</script>
</body>
</html>
```

## Cara Integrasi
Objek Audio HTML5 digunakan untuk memutar lagu. Tombol play/pause toggle berdasarkan status audio.paused. Event ended mendeteksi saat lagu selesai.
