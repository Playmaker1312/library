# 382. Mengimplementasikan Album Art Animation yaitu Berputar saat Play

## Definisi & Target
Menambahkan animasi berputar (spin) pada album art saat lagu sedang diputar. Targetnya adalah visual feedback yang menarik dan dinamis.

## Analogi Alur
Seperti piringan hitam yang berputar di atas meja putar. Semakin kencang putarannya, semakin seru musiknya.

## Poin-Poin Penting
- CSS animation rotasi pada cover image
- Animasi berjalan saat play, berhenti saat pause
- Transisi halus antara play dan pause
- Efek shadow untuk kedalaman

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Album Art Spin</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0a0a1a; display: flex; justify-content: center; align-items: center; min-height: 100vh; }
.player { background: #1a1a3e; border-radius: 24px; padding: 32px; width: 320px; text-align: center; box-shadow: 0 20px 60px rgba(0,0,0,0.5); }
.cover-wrapper { width: 200px; height: 200px; margin: 0 auto 20px; border-radius: 50%; overflow: hidden; box-shadow: 0 8px 30px rgba(0,0,0,0.4); }
.cover-wrapper img { width: 100%; height: 100%; object-fit: cover; }
.cover-wrapper.playing { animation: spin 8s linear infinite; }
.cover-wrapper.paused { animation-play-state: paused; }
@keyframes spin { from { transform: rotate(0deg); } to { transform: rotate(360deg); } }
.title { color: #fff; font-size: 18px; font-weight: 700; margin-bottom: 4px; }
.artist { color: #888; font-size: 14px; margin-bottom: 20px; }
.controls { display: flex; justify-content: center; gap: 20px; }
.controls button { background: none; border: none; color: #fff; font-size: 24px; cursor: pointer; }
#playBtn { width: 56px; height: 56px; border-radius: 50%; background: #4CAF50; font-size: 24px; }
</style>
</head>
<body>
<div class="player">
<div class="cover-wrapper" id="coverWrapper"><img src="https://via.placeholder.com/200/4CAF50/fff?text=Vinyl" alt="Album"></div>
<div class="title">Heal the World</div>
<div class="artist">Michael Jackson</div>
<div class="controls"><button id="playBtn">▶</button></div>
</div>
<audio id="audio" src="https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3"></audio>
<script>
const audio = document.getElementById('audio');
const playBtn = document.getElementById('playBtn');
const cover = document.getElementById('coverWrapper');
playBtn.addEventListener('click', () => {
if (audio.paused) {
audio.play();
playBtn.textContent = '⏸';
cover.classList.add('playing');
cover.classList.remove('paused');
} else {
audio.pause();
playBtn.textContent = '▶';
cover.classList.add('paused');
}
});
audio.addEventListener('ended', () => { playBtn.textContent = '▶'; cover.classList.remove('playing'); cover.classList.remove('paused'); });
</script>
</body>
</html>
```

## Cara Integrasi
CSS keyframes spin digunakan untuk animasi rotasi 360 derajat. Class "playing" ditambahkan saat lagu diputar dan dihapus saat pause. animation-play-state: paused menghentikan animasi tanpa reset posisi.
