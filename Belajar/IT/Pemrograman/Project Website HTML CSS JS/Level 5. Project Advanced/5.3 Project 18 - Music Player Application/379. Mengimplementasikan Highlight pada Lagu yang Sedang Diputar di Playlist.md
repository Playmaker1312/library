# 379. Mengimplementasikan Highlight pada Lagu yang Sedang Diputar di Playlist

## Definisi & Target
Menambahkan efek highlight pada item playlist yang sedang diputar. Targetnya adalah identifikasi visual lagu yang aktif.

## Analogi Alur
Seperti penanda buku yang menunjukkan halaman yang sedang dibaca. Highlight membantu pengguna melihat lagu mana yang sedang aktif.

## Poin-Poin Penting
- Class "active" pada item yang sedang diputar
- Background berbeda untuk lagu aktif
- Scroll otomatis ke item aktif
- Ikon play kecil di samping lagu aktif

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Highlight Lagu Aktif</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0a0a1a; display: flex; justify-content: center; padding: 20px; color: #fff; }
.playlist { background: #1a1a3e; border-radius: 16px; padding: 16px; width: 380px; max-height: 500px; overflow-y: auto; }
.playlist h3 { color: #aaa; font-size: 12px; text-transform: uppercase; margin-bottom: 12px; letter-spacing: 1px; }
.item { display: flex; align-items: center; gap: 10px; padding: 10px 12px; border-radius: 8px; cursor: pointer; transition: all 0.2s; }
.item:hover { background: #2a2a5e; }
.item.active { background: rgba(76,175,80,0.15); border-left: 3px solid #4CAF50; }
.item .num { color: #555; width: 24px; font-size: 12px; }
.item.active .num { color: #4CAF50; }
.item .info { flex: 1; }
.item .info .title { font-size: 14px; font-weight: 500; }
.item .info .artist { font-size: 12px; color: #777; }
.item .playing-icon { display: none; font-size: 14px; }
.item.active .playing-icon { display: block; color: #4CAF50; }
</style>
</head>
<body>
<div class="playlist">
<h3>Now Playing</h3>
<div id="list"></div>
</div>
<audio id="audio"></audio>
<script>
const playlist = [
{ title: 'Heal the World', artist: 'Michael Jackson', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3' },
{ title: 'Imagine', artist: 'John Lennon', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-2.mp3' },
{ title: 'Bohemian Rhapsody', artist: 'Queen', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-3.mp3' },
{ title: 'Hotel California', artist: 'Eagles', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-4.mp3' }
];
const audio = document.getElementById('audio');
const list = document.getElementById('list');
let activeIndex = -1;
function render() {
list.innerHTML = '';
playlist.forEach((s, i) => {
const div = document.createElement('div');
div.className = `item ${i === activeIndex ? 'active' : ''}`;
div.innerHTML = `<span class="num">${i + 1}</span><div class="info"><div class="title">${s.title}</div><div class="artist">${s.artist}</div></div><span class="playing-icon">▶</span>`;
div.addEventListener('click', () => { activeIndex = i; audio.src = s.url; audio.play(); render(); });
list.appendChild(div);
});
if (activeIndex >= 0) list.children[activeIndex]?.scrollIntoView({ block: 'nearest' });
}
render();
</script>
</body>
</html>
```

## Cara Integrasi
Class "active" ditambahkan ke item yang sesuai dengan currentIndex. CSS memberikan background dan border kiri yang berbeda. Ikon play muncul di samping lagu aktif.
