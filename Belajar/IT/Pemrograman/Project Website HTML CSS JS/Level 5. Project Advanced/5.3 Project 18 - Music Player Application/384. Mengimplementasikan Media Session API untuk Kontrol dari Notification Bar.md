# 384. Mengimplementasikan Media Session API untuk Kontrol dari Notification Bar

## Definisi & Target
Mengimplementasikan Media Session API sehingga pengguna bisa mengontrol pemutaran musik dari notification bar/taskbar. Targetnya adalah kontrol media yang lebih luas.

## Analogi Alur
Seperti remote kontrol yang bisa mengoperasikan pemutar musik dari jarak jauh. Media Session API memungkinkan kontrol dari luar halaman web.

## Poin-Poin Penting
- Set Media Session metadata (title, artist, artwork)
- Action handlers: play, pause, next, prev
- Muncul di notification bar browser
- Update metadata saat lagu berganti

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Media Session API</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0a0a1a; display: flex; justify-content: center; align-items: center; min-height: 100vh; }
.player { background: #1a1a3e; border-radius: 20px; padding: 28px; width: 340px; text-align: center; color: #fff; }
.controls button { background: none; border: none; color: #fff; font-size: 22px; cursor: pointer; margin: 0 8px; }
#playBtn { width: 52px; height: 52px; border-radius: 50%; background: #4CAF50; font-size: 22px; }
.info { margin: 16px 0; }
</style>
</head>
<body>
<div class="player">
<div class="info"><div id="title">Heal the World</div><div id="artist" style="color:#888;font-size:14px;">Michael Jackson</div></div>
<div class="controls"><button id="prevBtn">⏮</button><button id="playBtn">▶</button><button id="nextBtn">⏭</button></div>
</div>
<audio id="audio" src="https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3"></audio>
<script>
const audio = document.getElementById('audio');
const playBtn = document.getElementById('playBtn');
let currentIndex = 0;
const playlist = [
{ title: 'Heal the World', artist: 'Michael Jackson', src: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3' },
{ title: 'Imagine', artist: 'John Lennon', src: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-2.mp3' }
];
function updateMediaSession() {
if ('mediaSession' in navigator) {
const s = playlist[currentIndex];
navigator.mediaSession.metadata = new MediaMetadata({ title: s.title, artist: s.artist, artwork: [{ src: 'https://via.placeholder.com/256/4CAF50/fff?text=M', sizes: '256x256', type: 'image/png' }] });
}
}
function loadSong(i) {
currentIndex = i;
const s = playlist[i];
document.getElementById('title').textContent = s.title;
document.getElementById('artist').textContent = s.artist;
audio.src = s.src;
updateMediaSession();
}
if ('mediaSession' in navigator) {
navigator.mediaSession.setActionHandler('play', () => { audio.play(); playBtn.textContent = '⏸'; });
navigator.mediaSession.setActionHandler('pause', () => { audio.pause(); playBtn.textContent = '▶'; });
navigator.mediaSession.setActionHandler('next', () => { loadSong((currentIndex + 1) % playlist.length); audio.play(); });
navigator.mediaSession.setActionHandler('prev', () => { loadSong((currentIndex - 1 + playlist.length) % playlist.length); audio.play(); });
}
playBtn.addEventListener('click', () => { if (audio.paused) { audio.play(); playBtn.textContent = '⏸'; } else { audio.pause(); playBtn.textContent = '▶'; } });
document.getElementById('nextBtn').addEventListener('click', () => { loadSong((currentIndex + 1) % playlist.length); if (!audio.paused) audio.play(); });
document.getElementById('prevBtn').addEventListener('click', () => { loadSong((currentIndex - 1 + playlist.length) % playlist.length); if (!audio.paused) audio.play(); });
loadSong(0);
</script>
</body>
</html>
```

## Cara Integrasi
navigator.mediaSession.metadata menyediakan informasi lagu ke browser. Action handlers mendefinisikan fungsi untuk kontrol play, pause, next, prev dari notification bar.
