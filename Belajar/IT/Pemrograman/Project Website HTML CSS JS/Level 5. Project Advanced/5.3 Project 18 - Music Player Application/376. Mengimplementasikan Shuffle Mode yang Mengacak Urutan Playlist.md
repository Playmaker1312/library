# 376. Mengimplementasikan Shuffle Mode yang Mengacak Urutan Playlist

## Definisi & Target
Mengimplementasikan mode shuffle (acak) yang mengubah urutan playlist sehingga lagu diputar secara random. Targetnya adalah variasi dalam mendengarkan musik.

## Analogi Alur
Seperti mengocok deck kartu - urutan kartu menjadi acak. Setiap kali shuffle diaktifkan, urutan playlist diacak.

## Poin-Poin Penting
- Tombol shuffle dengan status aktif/non-aktif
- Saat shuffle aktif, urutan playlist diacak
- Indikator visual saat shuffle aktif (warna berbeda)
- Bisa toggle kapan saja

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Shuffle Mode</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0a0a1a; display: flex; justify-content: center; align-items: center; min-height: 100vh; }
.player { background: #1a1a3e; border-radius: 20px; padding: 28px; width: 360px; text-align: center; }
.controls { display: flex; justify-content: center; align-items: center; gap: 20px; margin-top: 16px; }
.controls button { background: none; border: none; color: #fff; font-size: 22px; cursor: pointer; }
#playBtn { width: 52px; height: 52px; border-radius: 50%; background: #4CAF50; color: #fff; font-size: 22px; }
#shuffleBtn { font-size: 18px; }
#shuffleBtn.active { color: #4CAF50; }
.info { margin-bottom: 16px; }
.info .title { color: #fff; font-size: 16px; font-weight: 600; }
.info .artist { color: #888; font-size: 13px; }
</style>
</head>
<body>
<div class="player">
<div class="info"><div class="title" id="title">Heal the World</div><div class="artist" id="artist">Michael Jackson</div></div>
<div class="controls"><button id="shuffleBtn">🔀</button><button id="prevBtn">⏮</button><button id="playBtn">▶</button><button id="nextBtn">⏭</button></div>
</div>
<audio id="audio"></audio>
<script>
const playlist = [
{ title: 'Song A', artist: 'Artist 1', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3' },
{ title: 'Song B', artist: 'Artist 2', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-2.mp3' },
{ title: 'Song C', artist: 'Artist 3', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-3.mp3' },
{ title: 'Song D', artist: 'Artist 4', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-4.mp3' },
{ title: 'Song E', artist: 'Artist 5', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-5.mp3' }
];
let order = playlist.map((_, i) => i);
let currentIndex = 0;
let isShuffled = false;
let playOrder = [...order];
let playIndex = 0;
const audio = document.getElementById('audio');
const playBtn = document.getElementById('playBtn');
const shuffleBtn = document.getElementById('shuffleBtn');
function loadSong(idx) {
const s = playlist[playOrder[idx]];
document.getElementById('title').textContent = s.title;
document.getElementById('artist').textContent = s.artist;
audio.src = s.url;
}
shuffleBtn.addEventListener('click', () => {
isShuffled = !isShuffled;
shuffleBtn.classList.toggle('active');
if (isShuffled) {
const current = playOrder[playIndex];
playOrder = [current];
const rest = order.filter(i => i !== current);
for (let i = rest.length - 1; i > 0; i--) { const j = Math.floor(Math.random() * (i + 1)); [rest[i], rest[j]] = [rest[j], rest[i]]; }
playOrder.push(...rest);
playIndex = 0;
} else { playOrder = [...order]; playIndex = currentIndex; }
loadSong(playIndex);
});
document.getElementById('nextBtn').addEventListener('click', () => { playIndex = (playIndex + 1) % playOrder.length; loadSong(playIndex); if (!audio.paused) audio.play(); });
document.getElementById('prevBtn').addEventListener('click', () => { playIndex = (playIndex - 1 + playOrder.length) % playOrder.length; loadSong(playIndex); if (!audio.paused) audio.play(); });
playBtn.addEventListener('click', () => { if (audio.paused) { audio.play(); playBtn.textContent = '⏸'; } else { audio.pause(); playBtn.textContent = '▶'; } });
audio.addEventListener('ended', () => { playIndex = (playIndex + 1) % playOrder.length; loadSong(playIndex); audio.play(); });
loadSong(0);
</script>
</body>
</html>
```

## Cara Integrasi
Shuffle membuat array playOrder baru yang diacak. Lagu saat ini tetap sebagai lagu pertama, sisanya diacak. Toggle shuffle kembali ke urutan asli.
