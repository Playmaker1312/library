# 375. Mengimplementasikan Mute dan Unmute

## Definisi & Target
Menambahkan tombol mute/unmute yang bisa mematikan atau menghidupkan suara dengan cepat. Targetnya adalah kontrol audio yang lebih praktis.

## Analogi Alur
Seperti tombol mute di remote TV - satu tekan untuk mematikan suara, tekan lagi untuk menghidupkannya kembali.

## Poin-Poin Penting
- Tombol toggle untuk mute/unmute
- Ikon berubah sesuai status mute
- Simpan volume sebelum mute
- Kembalikan volume ke nilai sebelumnya saat unmute

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Mute Unmute</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0a0a1a; display: flex; justify-content: center; align-items: center; min-height: 100vh; }
.player { background: #1a1a3e; border-radius: 20px; padding: 28px; width: 340px; text-align: center; }
.volume-row { display: flex; align-items: center; gap: 10px; margin: 16px 0; }
#muteBtn { background: none; border: none; font-size: 24px; cursor: pointer; padding: 4px; }
.volume-row input[type="range"] { flex: 1; -webkit-appearance: none; height: 4px; background: #2a2a5e; border-radius: 2px; outline: none; }
.volume-row input[type="range"]::-webkit-slider-thumb { -webkit-appearance: none; width: 16px; height: 16px; border-radius: 50%; background: #4CAF50; cursor: pointer; }
.controls { margin-top: 12px; }
#playBtn { width: 52px; height: 52px; border-radius: 50%; background: #4CAF50; color: #fff; border: none; font-size: 22px; cursor: pointer; }
</style>
</head>
<body>
<div class="player">
<div class="volume-row"><button id="muteBtn">🔊</button><input type="range" id="volumeSlider" min="0" max="100" value="70"></div>
<div class="controls"><button id="playBtn">▶</button></div>
</div>
<audio id="audio" src="https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3"></audio>
<script>
const audio = document.getElementById('audio');
const volumeSlider = document.getElementById('volumeSlider');
const muteBtn = document.getElementById('muteBtn');
const playBtn = document.getElementById('playBtn');
let prevVolume = 0.7;
audio.volume = prevVolume;
volumeSlider.addEventListener('input', function() {
audio.volume = this.value / 100;
prevVolume = audio.volume || 0.1;
muteBtn.textContent = audio.volume === 0 ? '🔇' : '🔊';
});
muteBtn.addEventListener('click', () => {
if (audio.volume > 0) { prevVolume = audio.volume; audio.volume = 0; volumeSlider.value = 0; muteBtn.textContent = '🔇'; }
else { audio.volume = prevVolume || 0.7; volumeSlider.value = prevVolume * 100; muteBtn.textContent = '🔊'; }
});
playBtn.addEventListener('click', () => { if (audio.paused) { audio.play(); playBtn.textContent = '⏸'; } else { audio.pause(); playBtn.textContent = '▶'; } });
</script>
</body>
</html>
```

## Cara Integrasi
Mute menyimpan volume saat ini ke prevVolume, lalu mengatur audio.volume = 0. Unmute mengembalikan volume ke prevVolume. Ikon berubah sesuai status.
