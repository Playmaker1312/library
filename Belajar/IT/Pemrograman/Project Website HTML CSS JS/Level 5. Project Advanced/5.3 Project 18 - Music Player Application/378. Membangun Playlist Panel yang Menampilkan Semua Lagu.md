# 378. Membangun Playlist Panel yang Menampilkan Semua Lagu

## Definisi & Target
Membangun panel playlist yang menampilkan daftar semua lagu yang tersedia. Targetnya adalah pengguna bisa melihat dan memilih lagu dari daftar.

## Analogi Alur
Seperti daftar isi album yang menampilkan semua track. Pengguna bisa melihat urutan lagu dan memilih langsung lagu yang diinginkan.

## Poin-Poin Penting
- List vertikal berisi semua lagu
- Setiap item menampilkan nomor, judul, artis
- Klik item untuk memutar lagu
- Scroll jika playlist panjang

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Playlist Panel</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0a0a1a; display: flex; justify-content: center; padding: 20px; }
.container { display: flex; gap: 20px; max-width: 700px; }
.player { background: #1a1a3e; border-radius: 16px; padding: 24px; width: 260px; text-align: center; }
.player .cover { width: 120px; height: 120px; border-radius: 12px; margin: 0 auto 12px; background: #2a2a5e; overflow: hidden; }
.player .cover img { width: 100%; height: 100%; object-fit: cover; }
.player .title { color: #fff; font-size: 14px; font-weight: 600; }
.player .artist { color: #888; font-size: 12px; margin-bottom: 12px; }
.playlist { background: #1a1a3e; border-radius: 16px; padding: 16px; flex: 1; max-height: 400px; overflow-y: auto; }
.playlist h3 { color: #aaa; font-size: 12px; text-transform: uppercase; letter-spacing: 1px; margin-bottom: 12px; }
.playlist-item { display: flex; align-items: center; gap: 10px; padding: 8px 10px; border-radius: 8px; cursor: pointer; color: #ccc; font-size: 13px; transition: background 0.2s; }
.playlist-item:hover { background: #2a2a5e; }
.playlist-item .num { color: #555; width: 20px; text-align: right; font-size: 12px; }
.playlist-item .info { flex: 1; }
.playlist-item .info .s-title { color: #e0e0e0; font-weight: 500; }
.playlist-item .info .s-artist { color: #777; font-size: 11px; }
.playlist-item .duration { color: #555; font-size: 11px; }
</style>
</head>
<body>
<div class="container">
<div class="player">
<div class="cover"><img src="https://via.placeholder.com/120/4CAF50/fff?text=A" alt="Cover"></div>

<div class="artist" id="nowArtist">Michael Jackson</div>
</div>
<div class="playlist">
<h3>Playlist</h3>
<div id="playlistItems"></div>
</div>
</div>

<script>
const playlist = [
{ title: 'Heal the World', artist: 'Michael Jackson', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3' },
{ title: 'Imagine', artist: 'John Lennon', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-2.mp3' },
{ title: 'Bohemian Rhapsody', artist: 'Queen', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-3.mp3' },
{ title: 'Hotel California', artist: 'Eagles', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-4.mp3' }
];
const audio = document.getElementById('audio');
const list = document.getElementById('playlistItems');
playlist.forEach((s, i) => {
const div = document.createElement('div');
div.className = 'playlist-item';
div.innerHTML = `<span class="num">${i+1}</span><div class="info"><div class="s-title">${s.title}</div><div class="s-artist">${s.artist}</div></div>`;
div.addEventListener('click', () => {
document.getElementById('nowTitle').textContent = s.title;
document.getElementById('nowArtist').textContent = s.artist;
audio.src = s.url;
audio.play();
});
list.appendChild(div);
});
</script>
</body>
</html>
```

## Cara Integrasi
Playlist panel dirender secara dinamis dari array playlist. Setiap item bisa diklik untuk memuat dan memutar lagu yang sesuai.
