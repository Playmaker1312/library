# 381. Menambahkan Equalizer Visualizer menggunakan Web Audio API dan Canvas

## Definisi & Target
Menambahkan visualizer equalizer yang merespon frekuensi audio menggunakan Web Audio API dan Canvas. Targetnya adalah visualisasi musik yang menarik.

## Analogi Alur
Seperti layar equalizer di音响 yang menampilkan gelombang suara dalam bentuk batang-batang vertikal yang bergerak mengikuti irama musik.

## Poin-Poin Penting
- Web Audio API untuk menganalisis frekuensi
- Canvas untuk menggambar bar equalizer
- Animasi requestAnimationFrame
- Jumlah bar dan warna yang bisa diatur

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Equalizer Visualizer</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0a0a1a; display: flex; justify-content: center; align-items: center; min-height: 100vh; flex-direction: column; gap: 20px; }
canvas { border-radius: 12px; background: #1a1a3e; }
button { padding: 10px 24px; background: #4CAF50; color: #fff; border: none; border-radius: 8px; cursor: pointer; font-size: 14px; }
</style>
</head>
<body>
<canvas id="canvas" width="400" height="200"></canvas>
<button id="playBtn">▶ Play Music</button>
<audio id="audio" src="https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3" crossorigin="anonymous"></audio>
<script>
const audio = document.getElementById('audio');
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
const playBtn = document.getElementById('playBtn');
let audioCtx, analyser, dataArray, source;
function initAudio() {
audioCtx = new (window.AudioContext || window.webkitAudioContext)();
analyser = audioCtx.createAnalyser();
analyser.fftSize = 128;
source = audioCtx.createMediaElementSource(audio);
source.connect(analyser);
analyser.connect(audioCtx.destination);
dataArray = new Uint8Array(analyser.frequencyBinCount);
}
function draw() {
requestAnimationFrame(draw);
if (!analyser) return;
analyser.getByteFrequencyData(dataArray);
ctx.clearRect(0, 0, canvas.width, canvas.height);
const barWidth = canvas.width / dataArray.length;
for (let i = 0; i < dataArray.length; i++) {
const height = dataArray[i] / 255 * canvas.height;
const gradient = ctx.createLinearGradient(0, canvas.height - height, 0, canvas.height);
gradient.addColorStop(0, '#4CAF50');
gradient.addColorStop(0.5, '#8BC34A');
gradient.addColorStop(1, '#CDDC39');
ctx.fillStyle = gradient;
ctx.fillRect(i * barWidth, canvas.height - height, barWidth - 1, height);
}
}
playBtn.addEventListener('click', () => {
if (!audioCtx) initAudio();
if (audio.paused) { audio.play(); playBtn.textContent = '⏸ Pause'; } else { audio.pause(); playBtn.textContent = '▶ Play Music'; }
});
draw();
</script>
</body>
</html>
```

## Cara Integrasi
Web Audio API menganalisis frekuensi audio yang sedang diputar. Data frekuensi digambar sebagai bar vertikal di Canvas menggunakan requestAnimationFrame untuk animasi real-time.
