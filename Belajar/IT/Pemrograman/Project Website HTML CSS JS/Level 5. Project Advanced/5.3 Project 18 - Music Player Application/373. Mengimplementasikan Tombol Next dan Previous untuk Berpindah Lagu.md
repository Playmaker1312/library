# 373. Mengimplementasikan Tombol Next dan Previous untuk Berpindah Lagu

## Definisi & Target
Mengimplementasikan tombol Next dan Previous untuk berpindah ke lagu berikutnya atau sebelumnya dalam playlist. Targetnya adalah navigasi lagu yang lengkap.

## Analogi Alur
Seperti tombol next track dan previous track di pemutar CD. Tekan next untuk lagu berikutnya, previous untuk kembali ke lagu sebelumnya.

## Poin-Poin Penting
- Next: increment index playlist
- Previous: decrement index playlist
- Update cover, judul, artis
- Auto-play jika sedang playing

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Next Previous</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0a0a1a; display: flex; justify-content: center; align-items: center; min-height: 100vh; }
.player { background: #1a1a3e; border-radius: 20px; padding: 28px; width: 360px; text-align: center; }
.cover { width: 180px; height: 180px; border-radius: 16px; margin: 0 auto 16px; overflow: hidden; }
.cover img { width: 100%; height: 100%; object-fit: cover; }
.song-title { color: #fff; font-size: 18px; font-weight: 700; }
.artist { color: #888; font-size: 14px; margin-bottom: 16px; }
.controls { display: flex; justify-content: center; gap: 24px; }
.controls button { background: none; border: none; color: #fff; font-size: 24px; cursor: pointer; }
#playBtn { width: 56px; height: 56px; border-radius: 50%; background: #4CAF50; font-size: 24px; color: #fff; }
</style>
</head>
<body>
<div class="player">
<div class="cover"><img id="coverImg" src="https://via.placeholder.com/180/4CAF50/fff?text=1" alt="Cover"></div>
<div class="song-title" id="title">Heal the World</div>
<div class="artist" id="artist">Michael Jackson</div>
<div class="controls"><button id="prevBtn">⏮</button><button id="playBtn">▶</button><button id="nextBtn">⏭</button></div>
</div>
<audio id="audio"></audio>
<script>
const playlist = [
{ title: 'Heal the World', artist: 'Michael Jackson', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3', cover: 'https://via.placeholder.com/180/4CAF50/fff?text=1' },
{ title: 'Imagine', artist: 'John Lennon', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-2.mp3', cover: 'https://via.placeholder.com/180/2196F3/fff?text=2' },
{ title: 'Bohemian Rhapsody', artist: 'Queen', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-3.mp3', cover: 'https://via.placeholder.com/180/FF9800/fff?text=3' }
];
let currentIndex = 0;
const audio = document.getElementById('audio');
const playBtn = document.getElementById('playBtn');
function loadSong(index) {
const song = playlist[index];
document.getElementById('title').textContent = song.title;
document.getElementById('artist').textContent = song.artist;
document.getElementById('coverImg').src = song.cover;
audio.src = song.url;
}
function playSong() { audio.play(); playBtn.textContent = '⏸'; }
playBtn.addEventListener('click', () => { if (audio.paused) { playSong(); } else { audio.pause(); playBtn.textContent = '▶'; } });
document.getElementById('nextBtn').addEventListener('click', () => { currentIndex = (currentIndex + 1) % playlist.length; loadSong(currentIndex); if (audio.paused === false) playSong(); });
document.getElementById('prevBtn').addEventListener('click', () => { currentIndex = (currentIndex - 1 + playlist.length) % playlist.length; loadSong(currentIndex); if (audio.paused === false) playSong(); });
audio.addEventListener('ended', () => { currentIndex = (currentIndex + 1) % playlist.length; loadSong(currentIndex); playSong(); });
loadSong(0);
</script>
</body>
</html>
```

## Cara Integrasi
Index lagu saat ini (currentIndex) dimodifikasi oleh tombol next/prev. Fungsi loadSong() memperbarui semua elemen UI dan sumber audio. Auto-play jika sedang dalam mode playing.
