# 372. Menampilkan Current Time dan Total Duration Lagu

## Definisi & Target
Menampilkan waktu saat ini (current time) dan total durasi lagu di samping progress bar. Targetnya adalah informasi waktu yang akurat dan real-time.

## Analogi Alur
Seperti jam digital yang menunjukkan berapa lama lagu telah berjalan dan berapa total durasinya. Informasi ini membantu pengguna mengetahui sisa waktu lagu.

## Poin-Poin Penting
- Current time di sebelah kiri progress bar
- Total duration di sebelah kanan
- Format menit:detik (MM:SS)
- Update current time setiap detik

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Current Time Duration</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0a0a1a; display: flex; justify-content: center; align-items: center; min-height: 100vh; }
.player { background: #1a1a3e; border-radius: 20px; padding: 24px 30px; width: 360px; }
.controls { display: flex; justify-content: center; gap: 20px; margin-bottom: 16px; }
.controls button { background: none; border: none; color: #fff; font-size: 22px; cursor: pointer; }
#playBtn { width: 50px; height: 50px; border-radius: 50%; background: #4CAF50; font-size: 20px; }
.progress { width: 100%; height: 5px; background: #2a2a5e; border-radius: 3px; cursor: pointer; }
.progress-fill { height: 100%; width: 0%; background: #4CAF50; border-radius: 3px; }
.time-row { display: flex; justify-content: space-between; color: #888; font-size: 12px; margin-top: 6px; }
.info { text-align: center; color: #fff; margin-bottom: 16px; }
.info .title { font-size: 16px; font-weight: 600; }
.info .artist { font-size: 13px; color: #888; }
</style>
</head>
<body>
<div class="player">
<div class="info"><div class="title" id="songTitle">Heal the World</div><div class="artist" id="songArtist">Michael Jackson</div></div>
<div class="controls"><button id="prevBtn">⏮</button><button id="playBtn">▶</button><button id="nextBtn">⏭</button></div>
<div class="progress" id="progress"><div class="progress-fill" id="progressFill"></div></div>
<div class="time-row"><span id="currentTime">0:00</span><span id="totalTime">0:00</span></div>
</div>
<audio id="audio" src="https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3"></audio>
<script>
const audio = document.getElementById('audio');
const playBtn = document.getElementById('playBtn');
const progressFill = document.getElementById('progressFill');
const progress = document.getElementById('progress');
const currentTimeEl = document.getElementById('currentTime');
const totalTimeEl = document.getElementById('totalTime');
function fmt(s) { const m = Math.floor(s / 60); const sec = Math.floor(s % 60); return m + ':' + (sec < 10 ? '0' : '') + sec; }
playBtn.addEventListener('click', () => { if (audio.paused) { audio.play(); playBtn.textContent = '⏸'; } else { audio.pause(); playBtn.textContent = '▶'; } });
audio.addEventListener('timeupdate', () => {
progressFill.style.width = (audio.currentTime / audio.duration * 100) + '%';
currentTimeEl.textContent = fmt(audio.currentTime);
});
audio.addEventListener('loadedmetadata', () => { totalTimeEl.textContent = fmt(audio.duration); });
progress.addEventListener('click', (e) => { const r = progress.getBoundingClientRect(); audio.currentTime = ((e.clientX - r.left) / r.width) * audio.duration; });
</script>
</body>
</html>
```

## Cara Integrasi
Current time diambil dari properti audio.currentTime yang diupdate melalui event timeupdate. Total duration diambil dari audio.duration setelah metadata dimuat.
