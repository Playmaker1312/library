# 383. Menyimpan Preferensi yaitu Volume, Shuffle, dan Repeat ke LocalStorage

## Definisi & Target
Menyimpan preferensi pengguna seperti volume, mode shuffle, dan mode repeat ke LocalStorage agar pengaturan tetap tersimpan. Targetnya adalah persistensi preferensi.

## Analogi Alur
Seperti radio mobil yang mengingat setelan volume terakhir Anda meskipun mesin dimatikan. Preferensi dikembalikan saat Anda menggunakan lagi.

## Poin-Poin Penting
- Simpan volume, shuffle, repeat ke LocalStorage
- Load preferensi saat inisialisasi
- Update LocalStorage setiap kali preferensi berubah
- Format JSON untuk penyimpanan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Preferensi LocalStorage</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0a0a1a; display: flex; justify-content: center; align-items: center; min-height: 100vh; }
.player { background: #1a1a3e; border-radius: 20px; padding: 28px; width: 340px; text-align: center; }
.controls { display: flex; justify-content: center; align-items: center; gap: 16px; margin: 16px 0; }
.controls button { background: none; border: none; color: #fff; font-size: 20px; cursor: pointer; }
#playBtn { width: 48px; height: 48px; border-radius: 50%; background: #4CAF50; font-size: 20px; }
#shuffleBtn.active { color: #4CAF50; }
#repeatBtn.active { color: #4CAF50; }
.volume-row { display: flex; align-items: center; gap: 8px; }
.volume-row input[type="range"] { flex: 1; }
.status { color: #555; font-size: 11px; margin-top: 8px; }
</style>
</head>
<body>
<div class="player">
<div class="volume-row"><span>🔊</span><input type="range" id="volumeSlider" min="0" max="100"></div>
<div class="controls"><button id="shuffleBtn">🔀</button><button id="prevBtn">⏮</button><button id="playBtn">▶</button><button id="nextBtn">⏭</button><button id="repeatBtn">🔁</button></div>
<div class="status" id="status">Preferensi tersimpan</div>
</div>
<audio id="audio" src="https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3"></audio>
<script>
const STORAGE_KEY = 'musicPlayerPrefs';
let prefs = JSON.parse(localStorage.getItem(STORAGE_KEY)) || { volume: 70, shuffle: false, repeat: false };
const audio = document.getElementById('audio');
const volumeSlider = document.getElementById('volumeSlider');
const shuffleBtn = document.getElementById('shuffleBtn');
const repeatBtn = document.getElementById('repeatBtn');
const playBtn = document.getElementById('playBtn');
const statusEl = document.getElementById('status');
function savePrefs() { localStorage.setItem(STORAGE_KEY, JSON.stringify(prefs)); }
function applyPrefs() {
audio.volume = prefs.volume / 100;
volumeSlider.value = prefs.volume;
shuffleBtn.classList.toggle('active', prefs.shuffle);
repeatBtn.classList.toggle('active', prefs.repeat);
}
volumeSlider.addEventListener('input', function() { prefs.volume = parseInt(this.value); audio.volume = prefs.volume / 100; savePrefs(); });
shuffleBtn.addEventListener('click', () => { prefs.shuffle = !prefs.shuffle; shuffleBtn.classList.toggle('active'); savePrefs(); statusEl.textContent = 'Shuffle: ' + (prefs.shuffle ? 'ON' : 'OFF'); });
repeatBtn.addEventListener('click', () => { prefs.repeat = !prefs.repeat; repeatBtn.classList.toggle('active'); savePrefs(); statusEl.textContent = 'Repeat: ' + (prefs.repeat ? 'ON' : 'OFF'); });
playBtn.addEventListener('click', () => { if (audio.paused) { audio.play(); playBtn.textContent = '⏸'; } else { audio.pause(); playBtn.textContent = '▶'; } });
applyPrefs();
</script>
</body>
</html>
```

## Cara Integrasi
Objek prefs menyimpan volume, shuffle, dan repeat. Fungsi savePrefs() dipanggil setiap kali ada perubahan. Fungsi applyPrefs() dipanggil saat inisialisasi.
