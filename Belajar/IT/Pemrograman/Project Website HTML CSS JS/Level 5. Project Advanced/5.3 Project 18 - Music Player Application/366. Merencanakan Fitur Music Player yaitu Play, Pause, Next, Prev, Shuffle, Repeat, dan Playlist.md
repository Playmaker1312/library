# 366. Merencanakan Fitur Music Player yaitu Play, Pause, Next, Prev, Shuffle, Repeat, dan Playlist

## Definisi & Target
Merencanakan fitur-fitur utama Music Player yang meliputi kontrol pemutaran (play, pause, next, prev), mode shuffle dan repeat, serta playlist. Targetnya adalah aplikasi pemutar musik yang fungsional.

## Analogi Alur
Seperti pemutar CD dengan tombol play, pause, next, prev, dan mode acak. Playlist adalah kumpulan lagu yang siap diputar.

## Poin-Poin Penting
- Kontrol dasar: Play, Pause, Next, Previous
- Mode: Shuffle (acak) dan Repeat (ulang)
- Playlist sebagai daftar lagu
- UI yang menampilkan informasi lagu saat ini
