# 368. Membangun UI Player dengan Album Art, Judul Lagu, dan Artis

## Definisi & Target
Membangun user interface player yang menampilkan album art (cover), judul lagu, dan nama artis. Targetnya adalah tampilan player yang menarik dan informatif.

## Analogi Alur
Seperti cover album fisik yang menampilkan gambar, judul album, dan nama band di bagian depan.

## Poin-Poin Penting
- Cover album berbentuk lingkaran atau persegi dengan border radius
- Judul lagu dengan font yang menonjol
- Nama artis di bawah judul
- Layout vertikal yang rapi

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>UI Player</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0a0a1a; display: flex; justify-content: center; align-items: center; min-height: 100vh; }
.player { background: #1a1a3e; border-radius: 20px; padding: 30px; width: 340px; text-align: center; box-shadow: 0 20px 60px rgba(0,0,0,0.5); }
.cover { width: 200px; height: 200px; border-radius: 16px; margin: 0 auto 20px; background: #2a2a5e; display: flex; align-items: center; justify-content: center; overflow: hidden; }
.cover img { width: 100%; height: 100%; object-fit: cover; }
.song-title { color: #fff; font-size: 20px; font-weight: 700; margin-bottom: 4px; }
.artist { color: #888; font-size: 14px; margin-bottom: 20px; }
</style>
</head>
<body>
<div class="player">
<div class="cover"><img src="https://via.placeholder.com/200/4CAF50/fff?text=Music" alt="Album Art"></div>
<div class="song-title">Heal the World</div>
<div class="artist">Michael Jackson</div>
</div>
</body>
</html>
```

## Cara Integrasi
UI player ini menjadi tampilan utama aplikasi. Cover, judul, dan artis akan di-update secara dinamis saat lagu berganti menggunakan JavaScript.
