# 385. Memastikan Music Player Responsive dan Memiliki Tampilan Mobile yang Baik

## Definisi & Target
Membuat music player responsif yang berfungsi dengan baik di berbagai ukuran layar, terutama mobile. Targetnya adalah pengalaman mendengarkan yang optimal di perangkat apapun.

## Analogi Alur
Seperti pemutar musik portable yang bisa digunakan di mana saja. Tampilan menyesuaikan dengan ukuran genggaman.

## Poin-Poin Penting
- Media query untuk berbagai ukuran layar
- Ukuran font dan elemen yang proporsional
- Touch-friendly buttons
- Layout vertikal di mobile

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
<title>Music Player Responsive</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0a0a1a; display: flex; justify-content: center; align-items: center; min-height: 100vh; padding: 16px; }
.player { background: #1a1a3e; border-radius: 24px; padding: 32px; width: 100%; max-width: 400px; text-align: center; }
.cover { width: 60%; max-width: 220px; aspect-ratio: 1; border-radius: 50%; margin: 0 auto 20px; overflow: hidden; border: 4px solid rgba(255,255,255,0.05); }
.cover img { width: 100%; height: 100%; object-fit: cover; }
.title { color: #fff; font-size: clamp(16px, 4vw, 22px); font-weight: 700; margin-bottom: 4px; }
.artist { color: #888; font-size: clamp(13px, 3vw, 15px); margin-bottom: 20px; }
.controls { display: flex; justify-content: center; align-items: center; gap: clamp(12px, 4vw, 24px); }
.controls button { background: none; border: none; color: #fff; font-size: clamp(20px, 5vw, 26px); cursor: pointer; min-width: 44px; min-height: 44px; display: flex; align-items: center; justify-content: center; }
#playBtn { width: clamp(48px, 12vw, 60px); height: clamp(48px, 12vw, 60px); border-radius: 50%; background: #4CAF50; font-size: clamp(20px, 5vw, 26px); }
.progress { width: 100%; height: 4px; background: #2a2a5e; border-radius: 2px; margin: 20px 0 8px; cursor: pointer; }
.progress-fill { height: 100%; width: 0%; background: #4CAF50; border-radius: 2px; }
.time-row { display: flex; justify-content: space-between; color: #666; font-size: 11px; }
.volume-row { display: flex; align-items: center; gap: 8px; margin-top: 16px; }
.volume-row input[type="range"] { flex: 1; height: 3px; -webkit-appearance: none; background: #2a2a5e; border-radius: 2px; }
.volume-row input[type="range"]::-webkit-slider-thumb { -webkit-appearance: none; width: 14px; height: 14px; border-radius: 50%; background: #4CAF50; }
@media (max-width: 360px) {
.player { padding: 20px 16px; }
.cover { width: 50%; }
}
</style>
</head>
<body>
<div class="player">
<div class="cover"><img src="https://via.placeholder.com/220/4CAF50/fff?text=M" alt="Cover"></div>
<div class="title" id="title">Heal the World</div>
<div class="artist" id="artist">Michael Jackson</div>
<div class="progress" id="progress"><div class="progress-fill" id="progressFill"></div></div>
<div class="time-row"><span id="current">0:00</span><span id="total">0:00</span></div>
<div class="controls"><button id="prevBtn">⏮</button><button id="playBtn">▶</button><button id="nextBtn">⏭</button></div>
<div class="volume-row"><span style="color:#888">🔊</span><input type="range" id="volumeSlider" min="0" max="100" value="70"></div>
</div>
<audio id="audio" src="https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3"></audio>
<script>
const audio = document.getElementById('audio');
const playBtn = document.getElementById('playBtn');
const progressFill = document.getElementById('progressFill');
const progress = document.getElementById('progress');
const current = document.getElementById('current');
const total = document.getElementById('total');
function fmt(s) { const m = Math.floor(s / 60); const sec = Math.floor(s % 60); return m + ':' + (sec < 10 ? '0' : '') + sec; }
playBtn.addEventListener('click', () => { if (audio.paused) { audio.play(); playBtn.textContent = '⏸'; } else { audio.pause(); playBtn.textContent = '▶'; } });
audio.addEventListener('timeupdate', () => { progressFill.style.width = (audio.currentTime / audio.duration * 100) + '%'; current.textContent = fmt(audio.currentTime); });
audio.addEventListener('loadedmetadata', () => { total.textContent = fmt(audio.duration); });
progress.addEventListener('click', (e) => { const r = progress.getBoundingClientRect(); audio.currentTime = ((e.clientX - r.left) / r.width) * audio.duration; });
document.getElementById('volumeSlider').addEventListener('input', function() { audio.volume = this.value / 100; });
</script>
</body>
</html>
```

## Cara Integrasi
Gunakan clamp() untuk ukuran font responsif. Media query untuk layar sangat kecil. Touch-friendly dengan min-width/height 44px pada tombol. Persentase untuk ukuran cover agar proporsional.
