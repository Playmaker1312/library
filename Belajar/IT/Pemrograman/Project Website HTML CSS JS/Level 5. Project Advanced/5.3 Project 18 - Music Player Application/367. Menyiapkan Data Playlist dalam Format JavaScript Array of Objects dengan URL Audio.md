# 367. Menyiapkan Data Playlist dalam Format JavaScript Array of Objects dengan URL Audio

## Definisi & Target
Menyiapkan data playlist dalam format array of objects yang berisi judul lagu, artis, album art, dan URL audio. Targetnya adalah struktur data yang siap digunakan.

## Analogi Alur
Seperti daftar putar (playlist) di aplikasi musik yang berisi informasi setiap lagu: judul, penyanyi, dan lokasi file.

## Poin-Poin Penting
- Array of objects untuk playlist
- Properti: title, artist, cover, url
- URL audio bisa dari file lokal atau online
- Cover art sebagai gambar thumbnail

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Data Playlist</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0a0a1a; display: flex; justify-content: center; padding: 20px; color: #fff; }
pre { background: #1a1a3e; padding: 20px; border-radius: 12px; overflow: auto; max-width: 600px; font-size: 13px; line-height: 1.6; }
</style>
</head>
<body>
<pre id="display"></pre>
<script>
const playlist = [
{ id: 1, title: 'Heal the World', artist: 'Michael Jackson', cover: 'https://via.placeholder.com/150/4CAF50/fff?text=HTW', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3' },
{ id: 2, title: 'Imagine', artist: 'John Lennon', cover: 'https://via.placeholder.com/150/2196F3/fff?text=IMG', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-2.mp3' },
{ id: 3, title: 'Bohemian Rhapsody', artist: 'Queen', cover: 'https://via.placeholder.com/150/FF9800/fff?text=BR', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-3.mp3' },
{ id: 4, title: 'Hotel California', artist: 'Eagles', cover: 'https://via.placeholder.com/150/9C27B0/fff?text=HC', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-4.mp3' },
{ id: 5, title: 'Stairway to Heaven', artist: 'Led Zeppelin', cover: 'https://via.placeholder.com/150/F44336/fff?text=STH', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-5.mp3' }
];
document.getElementById('display').textContent = JSON.stringify(playlist, null, 2);
</script>
</body>
</html>
```

## Cara Integrasi
Data playlist ini akan digunakan di seluruh aplikasi music player. Setiap lagu diakses melalui indeks array dan properti-propertinya digunakan untuk menampilkan informasi.
