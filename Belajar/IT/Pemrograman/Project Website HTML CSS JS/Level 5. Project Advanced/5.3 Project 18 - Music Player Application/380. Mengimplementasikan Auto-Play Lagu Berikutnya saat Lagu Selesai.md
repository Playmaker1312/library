# 380. Mengimplementasikan Auto-Play Lagu Berikutnya saat Lagu Selesai

## Definisi & Target
Mengimplementasikan auto-play yang otomatis memutar lagu berikutnya saat lagu yang sedang diputar selesai. Targetnya adalah pengalaman mendengarkan tanpa interupsi.

## Analogi Alur
Seperti tape recorder yang otomatis memutar sisi B setelah sisi A selesai. Pengguna tidak perlu menekan tombol play lagi.

## Poin-Poin Penting
- Event ended pada elemen audio
- Increment index playlist
- Muat dan putar lagu berikutnya
- Jika di akhir playlist, kembali ke awal

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Auto Play</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0a0a1a; display: flex; justify-content: center; align-items: center; min-height: 100vh; }
.player { background: #1a1a3e; border-radius: 20px; padding: 28px; width: 340px; text-align: center; }
.cover { width: 160px; height: 160px; border-radius: 14px; margin: 0 auto 14px; overflow: hidden; }
.cover img { width: 100%; height: 100%; object-fit: cover; }
.title { color: #fff; font-size: 16px; font-weight: 600; }
.artist { color: #888; font-size: 13px; margin-bottom: 14px; }
.controls { display: flex; justify-content: center; gap: 20px; }
.controls button { background: none; border: none; color: #fff; font-size: 22px; cursor: pointer; }
#playBtn { width: 50px; height: 50px; border-radius: 50%; background: #4CAF50; font-size: 22px; }
.status { color: #555; font-size: 11px; margin-top: 10px; }
</style>
</head>
<body>
<div class="player">
<div class="cover"><img id="coverImg" src="https://via.placeholder.com/160/4CAF50/fff?text=1" alt="Cover"></div>
<div class="title" id="title">Heal the World</div>
<div class="artist" id="artist">Michael Jackson</div>
<div class="controls"><button id="prevBtn">⏮</button><button id="playBtn">▶</button><button id="nextBtn">⏭</button></div>
<div class="status" id="status">Ready</div>
</div>
<audio id="audio"></audio>
<script>
const playlist = [
{ title: 'Song A', artist: 'Artis A', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3', cover: 'https://via.placeholder.com/160/4CAF50/fff?text=A' },
{ title: 'Song B', artist: 'Artis B', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-2.mp3', cover: 'https://via.placeholder.com/160/2196F3/fff?text=B' },
{ title: 'Song C', artist: 'Artis C', url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-3.mp3', cover: 'https://via.placeholder.com/160/FF9800/fff?text=C' }
];
let current = 0;
const audio = document.getElementById('audio');
const playBtn = document.getElementById('playBtn');
const statusEl = document.getElementById('status');
function loadSong(i) {
const s = playlist[i];
document.getElementById('title').textContent = s.title;
document.getElementById('artist').textContent = s.artist;
document.getElementById('coverImg').src = s.cover;
audio.src = s.url;
}
function playCurrent() { audio.play(); playBtn.textContent = '⏸'; statusEl.textContent = 'Playing...'; }
playBtn.addEventListener('click', () => { if (audio.paused) { playCurrent(); } else { audio.pause(); playBtn.textContent = '▶'; statusEl.textContent = 'Paused'; } });
document.getElementById('nextBtn').addEventListener('click', () => { current = (current + 1) % playlist.length; loadSong(current); playCurrent(); });
document.getElementById('prevBtn').addEventListener('click', () => { current = (current - 1 + playlist.length) % playlist.length; loadSong(current); playCurrent(); });
audio.addEventListener('ended', () => { current = (current + 1) % playlist.length; loadSong(current); playCurrent(); statusEl.textContent = 'Auto-playing next...'; });
loadSong(0);
</script>
</body>
</html>
```

## Cara Integrasi
Event ended pada elemen audio memicu fungsi yang increment index dan memuat lagu berikutnya. Jika currentIndex sudah di akhir, kembali ke indeks 0.
