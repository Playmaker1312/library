# 377. Mengimplementasikan Repeat Mode yaitu Repeat All, Repeat One, dan No Repeat

## Definisi & Target
Mengimplementasikan tiga mode repeat: No Repeat (tidak mengulang), Repeat All (mengulang seluruh playlist), dan Repeat One (mengulang lagu yang sama). Targetnya adalah kontrol playback yang lengkap.

## Analogi Alur
Seperti pengulangan di pemutar musik: No Repeat = lagu berhenti setelah selesai, Repeat All = playlist diputar terus, Repeat One = lagu yang sama diulang terus.

## Poin-Poin Penting
- Tombol repeat dengan multiple state
- Siklus: No Repeat → Repeat All → Repeat One
- Indikator visual berbeda untuk setiap mode
- Logika auto-play menyesuaikan mode

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Repeat Mode</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0a0a1a; display: flex; justify-content: center; align-items: center; min-height: 100vh; }
.player { background: #1a1a3e; border-radius: 20px; padding: 28px; width: 360px; text-align: center; }
.controls { display: flex; justify-content: center; align-items: center; gap: 20px; margin-top: 16px; }
.controls button { background: none; border: none; color: #fff; font-size: 20px; cursor: pointer; }
#playBtn { width: 52px; height: 52px; border-radius: 50%; background: #4CAF50; color: #fff; font-size: 22px; }
#repeatBtn { position: relative; }
#repeatBtn.active-one { color: #4CAF50; }

#repeatBtn.active-one .repeat-one-indicator { display: block; }

</style>
</head>
<body>
<div class="player">
<div class="info"><div class="title" id="title">Heal the World</div></div>
<div class="controls"><button id="repeatBtn">🔁<span class="repeat-one-indicator">1</span></button><button id="prevBtn">⏮</button><button id="playBtn">▶</button><button id="nextBtn">⏭</button></div>
</div>
<audio id="audio" src="https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3"></audio>
<script>
const audio = document.getElementById('audio');
const playBtn = document.getElementById('playBtn');
const repeatBtn = document.getElementById('repeatBtn');
const modes = ['none', 'all', 'one'];
let repeatMode = 0;
repeatBtn.addEventListener('click', () => {
repeatMode = (repeatMode + 1) % modes.length;
repeatBtn.className = '';
if (modes[repeatMode] === 'one') { repeatBtn.classList.add('active-one'); }
else if (modes[repeatMode] === 'all') { repeatBtn.classList.add('active-all'); }
});
playBtn.addEventListener('click', () => { if (audio.paused) { audio.play(); playBtn.textContent = '⏸'; } else { audio.pause(); playBtn.textContent = '▶'; } });
audio.addEventListener('ended', () => {
if (modes[repeatMode] === 'one') { audio.currentTime = 0; audio.play(); }
else if (modes[repeatMode] === 'all') { /* next song logic */ audio.currentTime = 0; audio.play(); }
});
</script>
</body>
</html>
```

## Cara Integrasi
Mode repeat disimpan sebagai indeks array. Repeat One: restart lagu yang sama. Repeat All: lanjut ke lagu berikutnya. No Repeat: berhenti saat lagu selesai.
