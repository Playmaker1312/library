# 25. Seleksi Elemen — Temukan Elemen di DOM

Materi ini mengajarkan cara "mencari" elemen HTML dari JavaScript: perintah-perintah seperti `querySelector`, `querySelectorAll`, `getElementById`, dan cara menavigasi antara induk, anak, dan saudara dalam DOM. Inilah gerbang pertama menuju manipulasi halaman — sebelum kamu bisa mengubah sesuatu, kamu harus bisa menemukannya dulu.

## 1. Penjelasan Singkat & Konsep Dasar

Di Level 4 kamu belajar bahasa JavaScript: variabel, array, fungsi, dan method array seperti `map`, `filter`, `reduce`. Tapi semua itu masih berjalan "di udara" — kamu tidak pernah menyentuh halaman yang sedang dilihat user. Level 5, yang dimulai dari materi ini, menghubungkan logika JS dengan halaman nyata melalui **DOM (Document Object Model)**. Semua JavaScript yang kamu pelajari di Level 4 akhirnya menemukan "pekerjaan nyata"-nya di sini: array `katalog` diubah menjadi kartu buku di layar, fungsi pencarian benar-benar memfilter tampilan.

Secara teknis, DOM adalah **pohon object yang dibangun browser dari HTML**. Saat browser membaca file HTML (Level 1), ia tidak menyimpan file itu apa adanya, melainkan mengubahnya menjadi kumpulan **node** di memori. Setiap tag seperti `<div>`, `<p>`, `<button>` menjadi sebuah node (lebih tepatnya: **element node**), teks di antaranya menjadi **text node**, dan atribut menjadi informasi di dalam node. Node-node itu tersusun berjenjang: satu node bisa punya **parent** (induk), **children** (anak-anak), dan **siblings** (saudara). Hubungan inilah yang membentuk "pohon". Root dari pohon tersebut adalah `document`, dan dari sana JavaScript bisa merujuk seluruh halaman.

Karena DOM adalah objek, JavaScript bisa membacanya dan mengubahnya, dan browser otomatis memperbarui tampilan. Kuncinya di sini: kamu tidak membuat ulang halaman, cukup mengubah representasi di memori. Perintah paling penting yang jadi fondasi semua materi berikutnya adalah **seleksi** — mengambil referensi ke sebuah elemen agar bisa dibaca dan dimodifikasi. Ada beberapa cara, dan pilihan yang mana memengaruhi efisiensi dan kemudahan kode.

Metode paling modern dan fleksibel adalah `document.querySelector(selector)` yang menerima **CSS selector** (semua yang kamu pelajari di materi 10: `.class`, `#id`, `tag`, `nav a`, dsb.) dan mengembalikan **elemen pertama** yang cocok — atau `null` jika tidak ada. Saudaranya, `document.querySelectorAll(selector)`, mengembalikan **semua** kecocokan dalam bentuk **NodeList**. Method lama seperti `getElementById`, `getElementsByClassName`, dan `getElementsByTagName` masih ada dan lebih cepat, tetapi sebaiknya gunakan `querySelector*` demi konsistensi selector. Setelah sebuah elemen direferensikan, kamu bisa berpindah-pindah antarelemen lewat properti navigasi: `parentElement`, `children`, `firstElementChild`, `nextElementSibling`, dan seterusnya.

**Benang merah**: data dan logika dari Level 4 (misal `katalog.filter(...)`) sekarang diarahkan ke halaman nyata lewat seleksi. Materi 25 ini adalah fondasi; materi 26 (mengubah konten/gaya), 27 (membuat/menghapus elemen), dan 28 (event) semuanya dimulai dari perintah seleksi yang kamu pelajari di sini.

## 2. Fungsi & Kegunaan Utama dalam Web

Dalam **Perpustakaan Digital Kota**, seleksi elemen dipakai di hampir setiap fitur. Ketika halaman `katalog.html` pertama kali dibuka, JS harus menemukan wadah katalog (`#katalog-grid`) untuk mengisi kartu buku. Saat user mengetik di kotak pencarian, JS membaca nilai `#input-pencarian`; saat tombol filter kategori dipilih, JS membaca pilihan `#filter-kategori`. Semua pengambilan itu butuh seleksi.

Halaman juga terdiri dari banyak elemen yang harus "dipisahkan peran": ada `form` pendaftaran, tombol-tombol aksi (`btn --hapus`), judul koleksi, dan badge ketersediaan. `querySelectorAll` berguna untuk menjangkau sekelompok elemen sekaligus — misalnya meng-counter semua kartu buku yang sedang tampil, atau memberi class tertentu ke setiap badge. Di momen ini pula konsep NodeList penting: hasil `querySelectorAll` punya `forEach`, tapi bukan array penuh dengan `map`/`filter` — kamu akan belajar mengonversinya.

Fungsi terpenting lainnya adalah **debugging**: if kamu ingin tahu kenapa sebuah notifikasi tidak muncul, langkah pertama adalah memastikan elemen yang dituju benar-benar ditemukan. `console.log(document.querySelector("#notifikasi"))` yang menghasilkan `null` langsung menunjukkan bahwa selector salah, elemen belum ada, atau script dijalankan terlalu dini. Banyak bug interaktif di web sebenarnya berawal dari seleksi yang salah.

## 3. Contoh Kode & Implementasi Real-World

Berikut tiga berkas yang bekerja sama. HTML membangun kerangka, CSS memberinya tampilan, dan JavaScript (di akhir `body`) menseleksi elemen-elemennya:

```javascript
// js/main.js
// ─── 1. Seleksi tunggal: querySelector (elemen PERTAMA yang cocok) ───────
const judulHalaman = document.querySelector("#judul-halaman");
console.log(judulHalaman.textContent); // "Perpustakaan Digital Kota"

const kartuPertama = document.querySelector(".kartu-buku");      // kartu pertama saja
const linkPertama  = document.querySelector("nav a");            // link pertama di nav
const linkBacaKatalog = document.querySelector("a[href='#katalog']"); // selector atribut

// ─── 2. Seleksi banyak: querySelectorAll → NodeList ─────────────────────
const semuaKartu    = document.querySelectorAll(".kartu-buku"); // NodeList (3 item)
const semuaKartuMau  = document.querySelectorAll("#katalog .kartu-buku");
const semuaLinkNav  = document.querySelectorAll("#menu-navigasi a");

// NodeList punya forEach — bisa langsung dipakai
semuaKartu.forEach((kartu, i) => {
    console.log(`Kartu ke-${i + 1}:`, kartu.dataset.kategori);
});

// ─── 3. NodeList vs Array ────────────────────────────────────────────────
// NodeList TIDAK punya map, filter, reduce, find, dst.
// Jika butuh method array, konversikan dulu:
const arrayKartu = Array.from(semuaKartu);          // cara 1
const arrayKartu2 = [...semuaKartu];                // cara 2 (spread)

const judulJudul = [...semuaKartu].map(kartu => kartu.textContent.trim());
console.log(judulJudul); // ["Clean Code\nRobert C. Martin", ...]

// ─── 4. getElementById — cepat untuk id tunggal ──────────────────────────
const menu = document.getElementById("menu-navigasi");
console.log(menu === document.querySelector("#menu-navigasi")); // true

// ─── 5. Navigasi DOM: berjalan di pohon ────────────────────────────────
// Mulai dari satu elemen, lompat ke induk / anak / saudara:
const firstKartu = document.querySelector(".kartu-buku");

firstKartu.parentElement;              // <section id="katalog">
firstKartu.parentElement.parentElement; // <main>
firstKartu.children;                   // HTMLCollection: [<h3>, <p>]
firstKartu.firstElementChild;          // <h3>Clean Code</h3>
firstKartu.lastElementChild;           // <p>Robert C. Martin</p>

const kartuKedua  = firstKartu.nextElementSibling;      // kartu Laskar Pelangi
const kembaliPertama = kartuKedua.previousElementSibling; // balik ke kartu pertama
const parentKartuKedua = kartuKedua.parentElement;       // section#katalog
console.log(parentKartuKedua.children.length);           // 3 kartu

// ─── 6. Trik: seleksi di dalam elemen lain ───────────────────────────────
// Memilih elemen tidak harus selalu dari document —
// bisa juga dari elemen yang sudah dipegang ("scoping"):
const judulKartuKedua = kartuKedua.querySelector("h3");
console.log(judulKartuKedua.textContent); // "Laskar Pelangi"

// ─── 7. Aman dari null: bangun kebiasaan cek sebelum pakai ──────────────
const elemenYangBelumAda = document.querySelector("#tidak-ada");
// elemenYangBelumAda.textContent = "..."; // ERROR: null.textContent! ❌

if (elemenYangBelumAda) {
    // baru aman mengakses properties-nya
    console.log("Ditemukan:", elemenYangBelumAda);
} else {
    console.warn("Elemen #tidak-ada tidak ditemukan di halaman.");
}

// Penulisan singkat yang aman:
const nilai = document.querySelector("#opsional")?.textContent ?? "default";
```

## 4. Analogi Sederhana — Membangun Rumah

Dalam analogi rumah kita: **HTML** adalah kerangka rumah dan tata ruangnya, **CSS** adalah cat dan dekorasinya, dan **JavaScript** adalah instalasi listriknya. Di dalam rumah itu ada **panel kontrol listrik** — satu papan yang memetakan semua terminal dan saklar yang tersebar, lengkap dengan denah ruangannya. Itulah gambaran **DOM**: sebuah panel yang merepresentasikan seluruh sistem kelistrikan rumah dalam bentuk peta/denah pohon.

Ketika kamu ingin menyalakan lampu kamar, kamu tidak perlu menyusuri setiap kabel di dinding secara fisik. Kamu cukup melihat ke panel: "terminal mana yang menuju ke ruang tamu?". Itulah seleksi elemen. `document.querySelector("#ruang-tamu")` sama dengan membaca panel lalu menarik terminal yang dituju — kamu mendapatkan pegangan langsung ke perangkatnya, bukan ke bayangan salinannya.

Ada kalanya kamu butuh menangani *semua* saklar sekaligus, misalnya memadamkan semua lampu di lantai dua sebelum tidur. `document.querySelectorAll(".lampu-lantai2")` adalah cara menelusuri peta dan menandai semua perangkat di lantai itu — hasilnya satu kumpulan kabel lampu yang bisa ditangani bersama. Tidak perlu mengecek ruangan satu per satu; panel yang merepresentasikan struktur memberimu daftar lengkap. Dari itulah fitur "tiru dan perbanyak" di materi 26, 27, dan 28 mulai berjalan — semuanya dimulai dari mampu membaca denah panel dengan tepat.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

- **Mengambil referensi elemen sekali saat inisialisasi** — misal menyimpan `#katalog-grid`, `#form-cari`, dan `#btn-reset` ke dalam variabel di awal script agar tidak menseleksi berulang-ulang.
- **Menghitung atau menandai sekelompok elemen** — `querySelectorAll(".kartu-buku").length` untuk menampilkan "X buku ditemukan", atau memberi class tertentu ke semua kartu hasil pencarian.
- **Menemukan elemen berdasarkan data** — `document.querySelector('[data-id="42"]')` atau `.closest()` (materi 28) untuk menargetkan kartu buku yang id-nya sama dengan yang diklik user.
- **Scoping pencarian** — sejak awal memilih dari container tertentu (`katalogGrid.querySelectorAll("h3")`) supaya selector tidak tersebar ke seluruh dokumen dan hasilnya tidak bocor ke bagian halaman lain.
- **Debugging elemen yang tidak muncul** — cek `document.querySelector(...)` kembali `null` untuk membuktikan selector salah, elemen belum dirender, atau script berjalan terlalu dini.

## 6. Poin-poin Penting & Best Practices

- Gunakan **`querySelector`/`querySelectorAll`** sebagai standar karena memakai syntax CSS yang sudah kamu kuasai dari Level 2-3; `getElementById` masih oke untuk id tunggal yang pasti ada.
- Semua seleksi dari `document` mengembalikan referensi **hidup** ke elemen (jika elemen dihapus lalu dibuat ulang, referensi lama menjadi "stale" — pilih ulang setelah render ulang).
- **NodeList bukan Array**: ia punya `forEach` tapi tidak punya `map`, `filter`, `find`, `reduce`. Konversikan dengan `Array.from(nodeList)` atau `[...nodeList]` bila perlu.
- Simpan hasil seleksi yang dipakai berulang dalam variabel — seleksi ulang terus-menerus itu boros dan rawan inkonsistensi.
- Selalu waspadai **`null`**: `querySelector` mengembalikan `null` jika tidak cocok. Bangun kebiasaan cek dengan `if (elemen)` atau optional chaining `elemen?.`.
- Jangan seleksi elemen sebelum DOM siap. Letakkan `<script>` di akhir `body`, atau gunakan `defer`/`DOMContentLoaded` (materi 28).
- Manfaatkan **menjalankan seleksi dari elemen yang sudah dipegang** (`container.querySelector(...)`) untuk membuat selector tetap pendek dan tidak ambigu.

## 7. Kesalahan Umum (Common Pitfalls & Bugs)

- **Mengabaikan hasil `null`, lalu langsung mengakses property.** `document.querySelector("#x").textContent = "..."` melempar `TypeError` jika `#x` tidak ada. Perbaikan: cek dulu `const el = document.querySelector("#tidak-ada"); if (el) { ... }`, atau pakai `?.`.
- **Menyangka `querySelectorAll` mengembalikan array.** Memanggil `.map` langsung di NodeList menghasilkan `TypeError: nodeList.map is not a function`. Perbaikan: `Array.from(nodeList).map(...)` atau `[...nodeList].map(...)`.
- **Selector ditulis salah makna.** `document.querySelector(".btn")` memilih yang pertama saja; jika ingin semua pakai `querySelectorAll`. Juga pastikan peletakkan titik/`#`; `querySelector("kartu-buku")` mencari elemen `<kartu-buku>` (tag), bukan class `.kartu-buku`.
- **Script dijalankan sebelum elemen ada.** Seleksi di `<head>` tanpa `defer` mengembalikan `null` karena HTML belum dibaca. Perbaikan: pindahkan `<script>` ke akhir `body` atau gunakan `defer`.
- **Menggunakan referensi lama setelah render ulang.** Simpan `const kartu = ...` lalu setelah `katalogGrid.innerHTML = ""` referensi itu menunjuk elemen yang sudah lepas dari DOM. Perbaikan: lakukan seleksi ulang setelah setiap render.

## 8. Mini Project / Soal Latihan & Kunci Jawaban

### Tantangan

1. Buat halaman `index.html` dengan: satu `<header>` berisi `<nav>` yang punya **3 link**, dan satu `<main id="katalog">` berisi **4 kartu buku** (`div.kartu-buku`), masing-masing dengan `data-kategori` (teknologi / fiksi / sains). Hubungkan `js/main.js` di akhir `body`.
2. Di `js/main.js`: (a) pakai `querySelectorAll` untuk menampilkan jumlah kartu ke Console; (b) konversi NodeList kartu ke array lalu gunakan `map` untuk mencetak judul tiap kartu; (c) gunakan `querySelector` untuk menemukan kartu **pertama** ber-kategori `teknologi` dan tambahkan class `aktif` lewat `classList.add`; (d) dari kartu kedua, navigasikan ke `parentElement` untuk memastikan induknya adalah `#katalog` dan cetak `tagName`-nya.

### Solusi & Pembahasan

```html
            <li><a href="#tentang">Tentang</a></li>
            <li><a href="#kontak">Kontak</a></li>
        </ul>
    </nav>

    <main id="katalog">
        <div class="kartu-buku" data-kategori="teknologi"><h3>Clean Code</h3></div>
        <div class="kartu-buku" data-kategori="fiksi"><h3>Laskar Pelangi</h3></div>
        <div class="kartu-buku" data-kategori="sains"><h3>Cosmos</h3></div>
        <div class="kartu-buku" data-kategori="teknologi"><h3>Javascript: The Good Parts</h3></div>
```

```javascript
// js/main.js

// (a) Hitung jumlah kartu lewat querySelectorAll
const kartuBuku = document.querySelectorAll(".kartu-buku");
console.log(`Jumlah kartu buku: ${kartuBuku.length}`); // 4

// (b) Konversi NodeList → Array, lalu map untuk ambil judul
const judulJudul = [...kartuBuku].map(
    kartu => kartu.querySelector("h3").textContent
);
console.log("Judul buku:", judulJudul);
// ["Clean Code", "Laskar Pelangi", "Cosmos", "Javascript: The Good Parts"]

// (c) Kartu pertama ber-kategori teknologi → tambah class "aktif"
//     querySelector mengembalikan elemen pertama yang cocok.
const kartuTeknologiPertama = document.querySelector(
    '.kartu-buku[data-kategori="teknologi"]'
);
if (kartuTeknologiPertama) {
    kartuTeknologiPertama.classList.add("aktif");
    console.log("Kartu aktif:", kartuTeknologiPertama.querySelector("h3").textContent);
}

// (d) Dari kartu kedua, navigasi ke parent untuk memastikan induknya #katalog
const kartuKedua = kartuBuku[1];
const indukKatalog = kartuKedua.parentElement;
console.log("parent kartu kedua:", indukKatalog.tagName, indukKatalog.id);
// "SECTION katalog" — membuktikan navigasi parentElement berhasil
```

**Pembahasan**: Latihan ini merangkum semua jenis seleksi. `querySelectorAll` dijalankan di akhir `body`, jadi keempat kartu pasti sudah ditemukan; `.map` baru bisa dipakai setelah NodeList dikonversi dengan spread `[...]`, sesuai konsep NodeList-vs-Array. Selector atribut `[data-kategori="teknologi"]` menargetkan kartu pertama yang cocok, dan `classList.add` (perkenalan singkat yang akan digali di materi 26) menandai kartu terpilih. Terakhir, `parentElement` membuktikan bahwa setiap elemen bisa "berjalan naik" di pohon DOM, tepat seperti yang akan dibutuhkan materi 26-28.
