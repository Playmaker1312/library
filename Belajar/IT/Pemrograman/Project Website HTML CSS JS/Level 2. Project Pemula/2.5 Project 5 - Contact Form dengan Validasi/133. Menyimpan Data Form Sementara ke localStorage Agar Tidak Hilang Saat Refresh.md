# 133. Menyimpan Data Form Sementara ke localStorage Agar Tidak Hilang Saat Refresh

## Definisi & Target
Menyimpan data form ke localStorage browser agar data tidak hilang saat halaman di-refresh, dan mengisi kembali (restore) field form saat halaman dimuat.

## Analogi Alur
Seperti menulis catatan tempel di meja—localStorage menyimpan draft pesan Anda sehingga jika Anda tidak sengaja menutup halaman, data tetap tersimpan.

## Poin-Poin Penting
- Simpan data di `localStorage.setItem()` setiap kali ada perubahan
- Gunakan event `input` untuk menyimpan secara real-time
- Restore data di `window.onload` atau di akhir body
- Gunakan JSON.stringify() untuk objek, JSON.parse() untuk restore
- Hapus data dari localStorage saat form berhasil disubmit
- Beri notifikasi bahwa ada draft tersimpan (opsional)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Contact Form - localStorage</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: 'Segoe UI', sans-serif; background: #f0f2f5; display: flex; justify-content: center; align-items: center; min-height: 100vh; padding: 20px; }
    .form-container { width: 100%; max-width: 500px; background: white; border-radius: 20px; padding: 36px; box-shadow: 0 4px 20px rgba(0,0,0,0.08); }
    h2 { text-align: center; color: #2d3436; margin-bottom: 8px; }
    .subtitle { text-align: center; color: #636e72; font-size: 13px; margin-bottom: 24px; }
    .form-group { margin-bottom: 16px; }
    label { display: block; margin-bottom: 6px; font-weight: 600; font-size: 14px; color: #2d3436; }
    input, textarea { width: 100%; padding: 12px 16px; border: 2px solid #e0e0e0; border-radius: 10px; font-size: 15px; font-family: inherit; transition: 0.3s; }
    input:focus, textarea:focus { outline: none; border-color: #667eea; }
    textarea { min-height: 100px; resize: vertical; }
    .submit-btn { width: 100%; padding: 14px; background: #667eea; color: white; border: none; border-radius: 10px; font-size: 16px; font-weight: 600; cursor: pointer; }
    .draft-notice { display: none; font-size: 12px; color: #f39c12; text-align: center; margin-top: 12px; padding: 8px; background: #fff8e1; border-radius: 8px; }
    .draft-notice.visible { display: block; }
  </style>
</head>
<body>
  <div class="form-container">
    <h2>Hubungi Kami</h2>
    <p class="subtitle">Data akan disimpan otomatis sebagai draft</p>
    <div class="draft-notice" id="draftNotice">Draft tersimpan. Data sebelumnya telah dipulihkan.</div>
    <form id="draftForm" novalidate>
      <div class="form-group">
        <label for="name">Nama</label>
        <input type="text" id="name" placeholder="Nama lengkap">
      </div>
      <div class="form-group">
        <label for="email">Email</label>
        <input type="email" id="email" placeholder="contoh@email.com">
      </div>
      <div class="form-group">
        <label for="subject">Subjek</label>
        <input type="text" id="subject" placeholder="Subjek">
      </div>
      <div class="form-group">
        <label for="message">Pesan</label>
        <textarea id="message" placeholder="Tulis pesan..."></textarea>
      </div>
      <button type="submit" class="submit-btn">Kirim</button>
    </form>
  </div>
  <script>
    const fields = ['name', 'email', 'subject', 'message'];
    const STORAGE_KEY = 'contactFormDraft';
    function saveDraft() {
      const data = {};
      fields.forEach(f => data[f] = document.getElementById(f).value);
      localStorage.setItem(STORAGE_KEY, JSON.stringify(data));
    }
    function restoreDraft() {
      const saved = localStorage.getItem(STORAGE_KEY);
      if (!saved) return;
      try {
        const data = JSON.parse(saved);
        let hasData = false;
        fields.forEach(f => {
          if (data[f]) { document.getElementById(f).value = data[f]; hasData = true; }
        });
        if (hasData) document.getElementById('draftNotice').classList.add('visible');
      } catch(e) {}
    }
    function clearDraft() {
      localStorage.removeItem(STORAGE_KEY);
      document.getElementById('draftNotice').classList.remove('visible');
    }
    fields.forEach(f => document.getElementById(f).addEventListener('input', saveDraft));
    document.getElementById('draftForm').addEventListener('submit', function(e) {
      e.preventDefault();
      alert('Form berhasil dikirim!');
      this.reset();
      clearDraft();
    });
    restoreDraft();
  </script>
</body>
</html>
```

## Cara Integrasi
File ini menyimpan data form ke localStorage secara real-time saat pengguna mengetik. Jika halaman di-refresh, data akan dipulihkan. Setelah submit berhasil, localStorage dibersihkan. Notifikasi draft muncul jika ada data tersimpan.
