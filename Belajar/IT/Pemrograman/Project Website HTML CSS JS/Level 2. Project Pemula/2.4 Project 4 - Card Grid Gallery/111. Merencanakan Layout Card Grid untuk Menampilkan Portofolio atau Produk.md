# 111. Merencanakan Layout Card Grid untuk Menampilkan Portofolio atau Produk

## Definisi & Target
Tahap perencanaan layout grid untuk menampilkan kumpulan card (portofolio/produk) dengan susunan rapi menggunakan sistem grid.

## Analogi Alur
Seperti rak display di galeri—setiap card adalah bingkai yang menampilkan karya, diatur dalam baris dan kolom yang rapi dan mudah dilihat.

## Poin-Poin Penting
- Tentukan jumlah kolom: 1 (mobile), 2 (tablet), 3-4 (desktop)
- Tentukan ukuran card: lebar tetap (fixed) atau fleksibel (auto-fill)
- Tentukan elemen setiap card: gambar, judul, deskripsi, tombol
- Rencanakan jarak antar card (gap)
- Pertimbangkan aspect ratio gambar konsisten
- Rencanakan efek hover dan filter kategori
