# 113. Membuat Responsive Grid Layout Menggunakan CSS Grid dengan Auto-fill

## Definisi & Target
Menerapkan CSS Grid dengan properti `auto-fill` dan `minmax()` untuk membuat layout grid yang responsif tanpa media queries.

## Analogi Alur
CSS Grid dengan auto-fill seperti rak yang bisa menyesuaikan jumlah kolom secara otomatis—semakin lebar rak, semakin banyak kolom yang bisa ditampung.

## Poin-Poin Penting
- Gunakan `display: grid` pada container
- Gunakan `grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))`
- `auto-fill` akan mengisi baris dengan kolom sebanyak mungkin
- `minmax(280px, 1fr)` memastikan card minimal 280px dan maksimal 1fr
- Atur `gap` untuk jarak antar card
- Tanpa media queries, grid sudah responsif secara otomatis
