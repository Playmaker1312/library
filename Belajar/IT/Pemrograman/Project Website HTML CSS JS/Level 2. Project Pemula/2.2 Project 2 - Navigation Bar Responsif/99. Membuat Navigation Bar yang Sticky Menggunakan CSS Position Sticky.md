# 99. Membuat Navigation Bar yang Sticky Menggunakan CSS Position Sticky

## Definisi & Target
Menerapkan CSS `position: sticky` pada navigation bar agar tetap terlihat di bagian atas halaman saat pengguna scroll, tanpa menggunakan JavaScript.

## Analogi Alur
Seperti catatan tempel (sticky note) yang menempel di meja—navbar akan mengikuti saat halaman di-scroll, tetapi tetap diam di posisi awalnya jika belum mencapai batas scroll.

## Poin-Poin Penting
- Gunakan `position: sticky` dengan `top: 0` pada navbar
- Sticky berbeda dengan fixed: sticky tetap dalam aliran dokumen
- Sticky mulai bekerja saat scroll mencapai posisi elemen
- Beri `z-index` tinggi agar navbar di atas konten lain
- Sticky lebih ringan dari fixed karena murni CSS
- Pastikan parent container tidak memiliki `overflow: hidden`

File ini mendemonstrasikan CSS `position: sticky` pada navbar. Perhatikan bahwa banner di atas navbar ikut scroll, tetapi navbar tetap menempel di atas. Sticky lebih baik dari fixed untuk SEO karena tetap dalam DOM flow.
