# 86. Merencanakan Struktur Navigation Bar dengan Logo, Menu, dan Tombol CTA

## Definisi & Target
Tahap perencanaan struktur navigation bar yang mencakup tiga area utama: logo/brand di kiri, menu links di tengah, dan tombol CTA (Call to Action) di kanan.

## Analogi Alur
Seperti peta jalan yang menandai pintu masuk (logo), persimpangan (menu), dan tujuan akhir (CTA)—pengguna navigasi dengan jelas dari satu titik ke titik lain.

## Poin-Poin Penting
- Identifikasi elemen: logo (teks/gambar), menu (Home, About, Services, Contact), CTA (Sign Up)
- Tentukan layout: logo kiri, menu tengah, CTA kanan
- Rencanakan versi mobile: hamburger menu yang menggantikan menu desktop
- Tentukan warna, font, dan ukuran di awal
- Pertimbangkan aksesibilitas dan semantic HTML
