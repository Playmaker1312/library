# 87. Membuat HTML Navigation Menggunakan Tag Nav, Ul, Li, dan A yang Semantik

## Definisi & Target
Membangun struktur HTML yang semantik untuk navigation bar menggunakan elemen `<nav>`, `<ul>`, `<li>`, dan `<a>` sesuai standar aksesibilitas web.

## Analogi Alur
Seperti membangun kerangka rak buku—`<nav>` adalah raknya, `<ul>` adalah sekatnya, `<li>` adalah setiap buku, dan `<a>` adalah label pada setiap buku.

## Poin-Poin Penting
- Gunakan `<nav>` sebagai wrapper utama
- Gunakan `<ul>` dan `<li>` untuk daftar menu (lebih semantik daripada `<div>`)
- Gunakan `<a>` untuk tautan dengan atribut `href`
- Tambahkan logo menggunakan `<a>` atau `<div>` dengan teks/gambar
- Tambahkan tombol CTA sebagai `<a>` atau `<button>`
- Pastikan struktur mudah dibaca dan dimodifikasi

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Navigation Bar - HTML Semantik</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: 'Segoe UI', sans-serif; }
    .navbar { display: flex; justify-content: space-between; align-items: center; padding: 16px 32px; background: #1a1a2e; color: white; }
    .logo { font-size: 22px; font-weight: 700; color: white; text-decoration: none; }
    .nav-menu { display: flex; list-style: none; gap: 24px; }
    .nav-menu a { color: #ccc; text-decoration: none; font-size: 15px; transition: color 0.3s; }
    .nav-menu a:hover { color: white; }
    .cta-button { background: #667eea; color: white; padding: 10px 24px; border-radius: 20px; text-decoration: none; font-weight: 600; font-size: 14px; transition: background 0.3s; }
    .cta-button:hover { background: #764ba2; }
  </style>
</head>
<body>
  <nav class="navbar">
    <a href="#" class="logo">MyBrand</a>
    <ul class="nav-menu">
      <li><a href="#home">Home</a></li>
      <li><a href="#about">About</a></li>
      <li><a href="#services">Services</a></li>
      <li><a href="#contact">Contact</a></li>
    </ul>
    <a href="#" class="cta-button">Sign Up</a>
  </nav>
  <main style="padding: 40px; text-align: center;">
    <h1>Halaman Utama</h1>
    <p>Navigation bar semantik menggunakan nav, ul, li, dan a.</p>
  </main>
</body>
</html>
```

## Cara Integrasi
File ini adalah fondasi HTML navigation bar yang semantik. Struktur ini akan dikembangkan dengan styling lanjutan, efek hover, mobile menu, dan JavaScript di poin-poin berikutnya.
