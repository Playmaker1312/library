# 94. Membuat Navigation Bar yang Berubah Tampilan Saat Di-scroll Menggunakan JavaScript

## Definisi & Target
Membuat navigation bar berubah gaya (misal: background menjadi solid, shadow bertambah) saat pengguna scroll ke bawah halaman menggunakan event listener `scroll`.

## Analogi Alur
Seperti bunglon yang berubah warna sesuai lingkungan—navbar berubah dari transparan menjadi solid saat halaman di-scroll agar tetap terbaca.

## Poin-Poin Penting
- Gunakan `window.addEventListener('scroll', ...)` untuk mendeteksi scroll
- Gunakan `window.scrollY` untuk mengetahui posisi scroll
- Tambahkan kelas `.scrolled` saat scrollY > 0 atau > threshold tertentu
- Ubah background, shadow, ukuran font di CSS untuk kelas `.scrolled`
- Gunakan CSS transition untuk perubahan yang halus
- Hapus kelas saat kembali ke atas

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html

    .navbar.scrolled { background: white; padding: 12px 40px; box-shadow: 0 2px 20px rgba(0,0,0,0.1); }
    .logo { font-size: 22px; font-weight: 800; color: white; text-decoration: none; transition: color 0.3s; }
    .navbar.scrolled .logo { color: #2d3436; }
    .logo span { color: #667eea; }
    .nav-menu { display: flex; list-style: none; gap: 32px; }
    .nav-menu a { color: rgba(255,255,255,0.8); text-decoration: none; font-size: 15px; font-weight: 500; transition: color 0.3s; }

    .navbar.scrolled .nav-menu a:hover { color: #667eea; }

    .cta-button:hover { transform: translateY(-2px); }
    .hero { height: 100vh; background: linear-gradient(135deg, #1a1a2e, #16213e); display: flex; justify-content: center; align-items: center; color: white; text-align: center; }
    .hero h1 { font-size: 48px; margin-bottom: 16px; }
    .hero p { font-size: 18px; opacity: 0.8; }
    .content { padding: 60px 40px; max-width: 800px; margin: 0 auto; }
    .content p { margin-bottom: 24px; font-size: 16px; line-height: 1.8; color: #636e72; }
  </style>
</head>
<body>
  <nav class="navbar" id="navbar">
    <a href="#" class="logo">My<span>Brand</span></a>
    <ul class="nav-menu">
      <li><a href="#home">Home</a></li>
      <li><a href="#about">About</a></li>
      <li><a href="#services">Services</a></li>
      <li><a href="#contact">Contact</a></li>
    </ul>
    <a href="#" class="cta-button">Sign Up</a>
  </nav>
  <section class="hero" id="home">
    <div><h1>Welcome to MyBrand</h1><p>Scroll down to see navbar change</p></div>
  </section>
  <section class="content">
    <p>Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris nisi ut aliquip ex ea commodo consequat.</p>
    <p>Duis aute irure dolor in reprehenderit in voluptate velit esse cillum dolore eu fugiat nulla pariatur. Excepteur sint occaecat cupidatat non proident, sunt in culpa qui officia deserunt mollit anim id est laborum.</p>
    <p>Scroll terus ke bawah untuk melihat perubahan navbar dari transparan menjadi putih solid dengan shadow. Efek ini memberikan kesan profesional dan dinamis pada website.</p>
  </section>
  <script>
    const navbar = document.getElementById('navbar');
    window.addEventListener('scroll', function() {
      if (window.scrollY > 50) {
        navbar.classList.add('scrolled');
      } else {
        navbar.classList.remove('scrolled');
      }
    });
  </script>
</body>
</html>
```

## Cara Integrasi
File ini menambahkan efek scroll-based styling pada navbar. Saat halaman di-scroll > 50px, navbar mendapat kelas `.scrolled` yang mengubah background, shadow, dan warna teks. CSS transition memastikan perubahan halus.
