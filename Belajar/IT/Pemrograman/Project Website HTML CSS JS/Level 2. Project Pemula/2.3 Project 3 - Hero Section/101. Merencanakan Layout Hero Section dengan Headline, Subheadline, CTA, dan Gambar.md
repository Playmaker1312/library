# 101. Merencanakan Layout Hero Section dengan Headline, Subheadline, CTA, dan Gambar

## Definisi & Target
Tahap perencanaan layout hero section yang mencakup headline utama, subheadline pendukung, tombol CTA, dan elemen visual (gambar atau ilustrasi).

## Analogi Alur
Seperti panggung pertunjukan—hero section adalah panggung depan yang paling pertama dilihat penonton, harus menarik dengan elemen-elemen yang tertata rapi.

## Poin-Poin Penting
- Tentukan posisi teks (kiri, tengah, atau kanan)
- Tentukan tata letak gambar (background, samping, atau foreground)
- Buat hierarki tipografi: headline > subheadline > CTA
- Rencanakan warna kontras antara teks dan background
- Pertimbangkan full-height (100vh) atau setengah layar
- Rencanakan elemen dekoratif opsional
