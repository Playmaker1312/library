# 77. Membuat Struktur HTML Profile Card dengan Avatar, Nama, Jabatan, dan Bio

## Definisi & Target
Membuat markup HTML semantik untuk profile card yang berisi elemen avatar (foto profil), nama pengguna, jabatan/posisi, dan deskripsi bio singkat.

## Analogi Alur
Seperti mengisi bingkai foto yang sudah disiapkan—HTML adalah bingkainya, konten adalah foto dan teks yang akan dimasukkan ke dalam bingkai tersebut.

## Poin-Poin Penting
- Gunakan `<div>` sebagai container utama card
- Gunakan `<img>` untuk foto profil dengan atribut `alt`
- Gunakan `<h1>` atau `<h2>` untuk nama
- Gunakan `<p>` untuk jabatan dan bio
- Gunakan class naming yang konsisten (contoh: `profile-card`, `avatar`, `name`, `title`, `bio`)
- Pastikan struktur berurutan sesuai wireframe

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Profile Card</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); display: flex; justify-content: center; align-items: center; min-height: 100vh; padding: 20px; }
    .profile-card { background: white; border-radius: 20px; padding: 30px; width: 100%; max-width: 360px; text-align: center; box-shadow: 0 10px 40px rgba(0,0,0,0.2); }
    .avatar { width: 120px; height: 120px; border-radius: 50%; object-fit: cover; margin-bottom: 16px; border: 4px solid #667eea; }
    .name { font-size: 24px; font-weight: 700; color: #333; margin-bottom: 4px; }
    .title { font-size: 16px; color: #667eea; font-weight: 500; margin-bottom: 12px; }
    .bio { font-size: 14px; color: #666; line-height: 1.6; margin-bottom: 20px; }
  </style>
</head>
<body>
  <div class="profile-card">
    <img class="avatar" src="https://i.pravatar.cc/150?img=1" alt="Foto Profil">
    <h1 class="name">Andi Pratama</h1>
    <p class="title">Frontend Developer</p>
    <p class="bio">Passionate frontend developer with 3 years of experience building responsive and accessible web applications. Love to explore new technologies.</p>
  </div>
</body>
</html>
```

## Cara Integrasi
File ini adalah fondasi dari profile card. Struktur HTML ini akan digunakan kembali dan dikembangkan di poin-poin selanjutnya dengan menambahkan CSS styling lebih lanjut, social media links, tombol, dan JavaScript.
