# 79. Menambahkan Foto Profil dengan Border-radius Circle

## Definisi & Target
Menerapkan CSS `border-radius: 50%` pada elemen `<img>` untuk membuat foto profil berbentuk lingkaran sempurna, serta menambahkan border sebagai bingkai.

## Analogi Alur
Seperti memotong foto menggunakan gunting melingkar—border-radius memotong sudut-sudut persegi menjadi bentuk lingkaran penuh.

## Poin-Poin Penting
- `border-radius: 50%` membuat elemen persegi menjadi lingkaran sempurna
- Pastikan lebar dan tinggi gambar sama (1:1) untuk hasil lingkaran yang presisi
- Gunakan `object-fit: cover` agar gambar tidak terdistorsi
- Tambahkan `border` untuk efek bingkai foto
- Atur `box-shadow` pada avatar untuk efek kedalaman opsional

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Profile Card - Avatar Circle</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: 'Segoe UI', sans-serif; background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); display: flex; justify-content: center; align-items: center; min-height: 100vh; padding: 20px; }
    .profile-card { background: white; border-radius: 20px; padding: 30px; width: 100%; max-width: 360px; display: flex; flex-direction: column; align-items: center; gap: 12px; box-shadow: 0 10px 40px rgba(0,0,0,0.15); }
    .avatar { width: 130px; height: 130px; border-radius: 50%; object-fit: cover; border: 5px solid white; box-shadow: 0 4px 15px rgba(102, 126, 234, 0.4); }
    .avatar-border { width: 140px; height: 140px; border-radius: 50%; display: flex; justify-content: center; align-items: center; background: linear-gradient(135deg, #667eea, #764ba2); margin-bottom: 8px; }
    .name { font-size: 24px; font-weight: 700; color: #2d3436; }
    .title { font-size: 16px; color: #667eea; font-weight: 500; }
    .bio { font-size: 14px; color: #636e72; line-height: 1.6; text-align: center; }
  </style>
</head>
<body>
  <div class="profile-card">
    <div class="avatar-border">
      <img class="avatar" src="https://i.pravatar.cc/150?img=1" alt="Foto Profil">
    </div>
    <h1 class="name">Andi Pratama</h1>
    <p class="title">Frontend Developer</p>
    <p class="bio">Passionate frontend developer with 3 years of experience building responsive and accessible web applications.</p>
  </div>
</body>
</html>
```

## Cara Integrasi
File ini meningkatkan tampilan avatar dengan border-radius lingkaran dan border gradient. Teknik ini akan digunakan konsisten di seluruh proyek yang membutuhkan foto profil lingkaran.
