# 78. Membuat Styling Dasar Profile Card Menggunakan CSS Flexbox

## Definisi & Target
Menerapkan CSS Flexbox untuk mengatur tata letak elemen di dalam profile card secara vertikal (column) dengan alignment yang rapi dan konsisten.

## Analogi Alur
Flexbox seperti rak yang bisa mengatur barang-barang di dalamnya secara otomatis—berjejer, rata tengah, atau renggang sesuai keinginan.

## Poin-Poin Penting
- Gunakan `display: flex` pada container `.profile-card`
- Atur `flex-direction: column` untuk tata letak vertikal
- Gunakan `align-items: center` untuk rata tengah
- Manfaatkan `gap` untuk jarak antar elemen
- Flexbox memudahkan responsivitas tanpa float
- Kombinasikan dengan `justify-content` untuk distribusi ruang

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Profile Card - Flexbox</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: 'Segoe UI', sans-serif; background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); display: flex; justify-content: center; align-items: center; min-height: 100vh; padding: 20px; }
    .profile-card { background: white; border-radius: 20px; padding: 30px; width: 100%; max-width: 360px; display: flex; flex-direction: column; align-items: center; gap: 12px; box-shadow: 0 10px 40px rgba(0,0,0,0.15); }
    .avatar { width: 120px; height: 120px; border-radius: 50%; object-fit: cover; border: 4px solid #667eea; }
    .name { font-size: 24px; font-weight: 700; color: #2d3436; }
    .title { font-size: 16px; color: #667eea; font-weight: 500; }
    .bio { font-size: 14px; color: #636e72; line-height: 1.6; text-align: center; }
  </style>
</head>
<body>
  <div class="profile-card">
    <img class="avatar" src="https://i.pravatar.cc/150?img=1" alt="Foto Profil">
    <h1 class="name">Andi Pratama</h1>
    <p class="title">Frontend Developer</p>
    <p class="bio">Passionate frontend developer with 3 years of experience building responsive and accessible web applications.</p>
  </div>
</body>
</html>
```

## Cara Integrasi
Gunakan file ini sebagai dasar styling layout. Setiap elemen card diatur dengan Flexbox agar rapi. Pengembangan selanjutnya akan menambahkan social media links, tombol interaktif, dan efek-efek visual.
