# 76. Merencanakan Desain Personal Profile Card

## Definisi & Target
Perencanaan desain adalah tahap awal pembuatan profile card yang mencakup pembuatan sketsa, wireframe, dan penentuan layout elemen-elemen seperti avatar, nama, jabatan, bio, social links, serta tombol aksi.

## Analogi Alur
Seperti seorang arsitektur yang membuat blueprint sebelum membangun rumah, kita membuat sketsa card di kertas atau Figma untuk menentukan posisi setiap elemen sebelum menulis kode.

## Poin-Poin Penting
- Tentukan ukuran card (fixed atau responsive)
- Pilih layout: vertikal (stack) atau horizontal
- Tentukan warna tema, font, dan spacing
- Buat wireframe low-fidelity: kotak-kotak untuk setiap elemen
- Tentukan urutan elemen dari atas ke bawah
- Rencanakan versi mobile dan desktop
