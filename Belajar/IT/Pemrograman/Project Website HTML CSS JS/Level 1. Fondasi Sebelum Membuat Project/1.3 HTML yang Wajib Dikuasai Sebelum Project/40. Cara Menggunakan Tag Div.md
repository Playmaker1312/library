# 40. Cara Menggunakan Tag Div sebagai Container Layout

## Definisi & Target
Tag `<div>` adalah container block-level serbaguna yang digunakan untuk mengelompokkan elemen HTML dan menjadi dasar layout dengan CSS.

## Analogi Alur
Div seperti kotak penyimpanan serbaguna. Anda bisa menaruh apa pun di dalamnya, menumpuknya, menyusunnya berdampingan, dan memberi label (class/id) untuk mengidentifikasinya.

## Poin-Poin Penting
- `<div>`: block-level, tidak memiliki style bawaan
- Digunakan untuk grouping elemen
- Tidak memiliki makna semantik (berlawanan dengan tag semantik)
- Biasanya dikombinasikan dengan class atau id
- Merupakan fondasi layout CSS (Flexbox, Grid)
- Jangan gunakan div jika ada tag semantik yang lebih sesuai

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Div Container Demo</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <div class="app-wrapper">
    <div class="header">
      <h1>Layout dengan Div</h1>
    </div>
    <div class="content-wrapper">
      <div class="sidebar">
        <h3>Sidebar</h3>
        <div class="menu-item">Menu 1</div>
        <div class="menu-item">Menu 2</div>
        <div class="menu-item">Menu 3</div>
      </div>
      <div class="main-content">
        <h2>Konten Utama</h2>
        <div class="card-container">
          <div class="card">
            <div class="card-header">Card 1</div>
            <div class="card-body">Ini adalah body card 1.</div>
            <div class="card-footer">Footer</div>
          </div>
          <div class="card">
            <div class="card-header">Card 2</div>
            <div class="card-body">Ini adalah body card 2.</div>
            <div class="card-footer">Footer</div>
          </div>
        </div>
      </div>
    </div>
    <div class="footer">
      <p>&copy; 2024 Layout Div</p>
    </div>
  </div>
</body>
</html>
```

## Cara Integrasi
1. Gunakan `<div>` untuk mengelompokkan elemen yang tidak punya tag semantik
2. Beri class atau id untuk styling CSS
3. Gunakan div bersama Flexbox/Grid untuk layout
4. Prioritaskan tag semantik (<header>, <main>, <section>, dll) di atas div
5. Jangan buat "div soup" - terlalu banyak div bersarang tanpa makna
