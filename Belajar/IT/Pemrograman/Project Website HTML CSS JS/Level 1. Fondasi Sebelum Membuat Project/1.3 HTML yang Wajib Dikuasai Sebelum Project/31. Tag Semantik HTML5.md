# 31. Memahami Tag Semantik HTML5

## Definisi & Target
Tag semantik HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`) memberikan makna pada struktur halaman, bukan hanya styling.

## Analogi Alur
Tag semantik seperti papan nama di gedung perkantoran. `header` adalah lobi, `nav` adalah koridor dengan papan petunjuk, `main` adalah ruang kerja utama, `section` adalah divisi, `article` adalah ruang meeting, `aside` adalah pantry, `footer` adalah basement.

## Poin-Poin Penting
- Meningkatkan SEO (mesin pencari memahami struktur)
- Meningkatkan aksesibilitas (screen reader terbantu)
- Lebih jelas dibanding `<div>` untuk semua hal
- `<header>`: bagian atas halaman/section (logo, judul)
- `<nav>`: navigasi utama
- `<main>`: konten utama (unik per halaman)
- `<section>`: pengelompokan tematik
- `<article>`: konten independen (blog post, berita)
- `<aside>`: konten terkait (sidebar)
- `<footer>`: informasi bawah halaman (copyright, link)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Tag Semantik HTML5</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <header class="site-header">
    <h1>Website Saya</h1>
    <nav>
      <ul>
        <li><a href="#">Beranda</a></li>
        <li><a href="#">Blog</a></li>
        <li><a href="#">Kontak</a></li>
      </ul>
    </nav>
  </header>
  <main>
    <article>
      <h2>Judul Artikel</h2>
      <p>Ini adalah konten artikel utama. Tag article digunakan untuk konten independen.</p>
      <section>
        <h3>Sub-bagian 1</h3>
        <p>Section digunakan untuk mengelompokkan konten bertema sama.</p>
      </section>
    </article>
    <aside>
      <h3>Sidebar</h3>
      <p>Konten terkait atau tambahan.</p>
    </aside>
  </main>
  <footer>
    <p>&copy; 2024 Website Saya</p>
  </footer>
</body>
</html>
```
```css
body { font-family: Arial, sans-serif; margin: 0; padding: 0; display: flex; flex-direction: column; min-height: 100vh; }
.site-header { background: #2c3e50; color: white; padding: 20px; display: flex; justify-content: space-between; align-items: center; }

```

## Cara Integrasi
1. Gunakan `<header>` untuk bagian atas halaman (bukan `<div class="header">`)
2. Gunakan `<nav>` untuk menu navigasi
3. Bungkus konten utama dengan `<main>` (hanya satu per halaman)
4. Gunakan `<article>` untuk konten independen, `<section>` untuk pengelompokan
5. Gunakan `<aside>` untuk sidebar atau konten terkait
6. Gunakan `<footer>` untuk bagian bawah halaman
