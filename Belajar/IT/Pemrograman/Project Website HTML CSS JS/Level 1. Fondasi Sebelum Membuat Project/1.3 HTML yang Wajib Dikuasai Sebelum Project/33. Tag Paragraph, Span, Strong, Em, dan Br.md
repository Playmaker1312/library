# 33. Cara Menggunakan Tag Paragraph, Span, Strong, Em, dan Br

## Definisi & Target
Tag inline dan block untuk teks: `<p>` (paragraph), `<span>` (inline container), `<strong>` (bold/ penting), `<em>` (italic/ penekanan), `<br>` (line break).

## Analogi Alur
Tag teks seperti alat tulis yang berbeda: `<p>` seperti kertas ukuran penuh, `<span>` seperti stabilo (bisa di area kecil), `<strong>` seperti spidol tebal untuk kata penting, `<em>` seperti tulisan miring untuk penekanan, `<br>` seperti enter pada keyboard.

## Poin-Poin Penting
- `<p>`: block-level, punya margin otomatis, untuk paragraf
- `<span>`: inline, tidak punya margin, untuk styling bagian kecil teks
- `<strong>`: inline, makna "penting", default bold, manfaat SEO
- `<em>`: inline, makna "penekanan", default italic
- `<br>`: inline, untuk ganti baris (jangan untuk spacing)
- Jangan gunakan `<strong>` hanya untuk bold visual (gunakan CSS)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Tag Teks HTML</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <div class="content">
    <h1>Tag Teks dalam HTML</h1>

    <p>Ini adalah paragraf normal. Tag p digunakan untuk blok teks. <span class="highlight">Span digunakan untuk menandai bagian tertentu</span> dalam paragraf.</p>

    <p><strong>Strong</strong> menandakan teks penting, biasanya tampil bold. <em>Em</em> menandakan penekanan, biasanya tampil italic.</p>

    <p>Tag br digunakan untuk<br>memisahkan baris<br>tanpa membuat paragraf baru.</p>

    <p class="note">Catatan: gunakan CSS untuk styling visual, simpan HTML untuk struktur dan makna.</p>
  </div>
</body>
</html>
```
```css
body { font-family: 'Georgia', serif; max-width: 700px; margin: 40px auto; padding: 20px; line-height: 1.8; color: #333; }
.content { background: #fafafa; padding: 30px; border-radius: 8px; }
.highlight { background: #fff3cd; padding: 2px 6px; border-radius: 3px; font-weight: 600; }
.note { font-size: 0.9rem; color: #888; border-top: 1px solid #ddd; padding-top: 10px; }
```

## Cara Integrasi
1. Gunakan `<p>` untuk setiap paragraf teks
2. Gunakan `<span>` ketika ingin memberi style khusus pada bagian kecil teks
3. Gunakan `<strong>` untuk kata kunci penting (SEO friendly)
4. Gunakan `<em>` untuk penekanan atau istilah asing
5. Gunakan `<br>` hanya untuk poetry, alamat, atau baris yang memang harus pisah
