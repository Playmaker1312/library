# 34. Cara Membuat Navigation Menggunakan Tag Nav dan Ul Li A

## Definisi & Target
Navigasi website menggunakan `<nav>` (container semantik), `<ul>` (daftar), `<li>` (item daftar), dan `<a>` (link). Ini adalah pola standar yang aksesibel dan SEO-friendly.

## Analogi Alur
Navigasi website seperti papan petunjuk arah di mal. `<nav>` adalah papan petunjuk, `<ul>` adalah daftar tujuan, `<li>` adalah satu tujuan, dan `<a>` adalah arah/tujuan yang bisa diklik.

## Poin-Poin Penting
- `<nav>` menandai area navigasi untuk screen reader
- `<ul>` + `<li>` memberikan struktur daftar yang semantik
- `<a href="">` untuk link dengan atribut href
- Atribut `target="_blank"` untuk buka di tab baru
- Gunakan CSS untuk mengubah tampilan list menjadi horizontal
- Tambahkan class untuk styling dan JavaScript

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Navigasi HTML</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <header>
    <h1>Website Saya</h1>
    <nav class="navbar">
      <ul class="nav-list">
        <li><a href="index.html" class="active">Beranda</a></li>
        <li><a href="tentang.html">Tentang</a></li>
        <li><a href="layanan.html">Layanan</a></li>
        <li><a href="blog.html">Blog</a></li>
        <li><a href="kontak.html">Kontak</a></li>
      </ul>
    </nav>
  </header>
  <main>
    <h2>Halaman Beranda</h2>
    <p>Navigasi menggunakan nav > ul > li > a adalah standar web.</p>
  </main>
  <script src="js/script.js"></script>
</body>
</html>
```
```css
body { font-family: Arial, sans-serif; margin: 0; padding: 0; }
header { background: #2c3e50; color: white; padding: 20px; display: flex; justify-content: space-between; align-items: center; }
.nav-list { list-style: none; display: flex; gap: 20px; margin: 0; padding: 0; }
.nav-list a { color: white; text-decoration: none; padding: 8px 16px; border-radius: 4px; transition: background 0.3s; }
.nav-list a:hover { background: rgba(255,255,255,0.1); }
.nav-list a.active { background: #3498db; }
main { padding: 40px; }
```
```javascript
var links = document.querySelectorAll('.nav-list a');
for (var i = 0; i < links.length; i++) {
  if (links[i].href === window.location.href) {
    links[i].classList.add('active');
  }
}
```

## Cara Integrasi
1. Bungkus navigasi dengan `<nav>`
2. Buat `<ul>` sebagai wadah daftar
3. Setiap `<li>` berisi `<a href="halaman.html">Teks Link</a>`
4. Gunakan CSS `display: flex` atau `grid` untuk membuat horizontal
5. Tambahkan class "active" pada halaman yang sedang dibuka
