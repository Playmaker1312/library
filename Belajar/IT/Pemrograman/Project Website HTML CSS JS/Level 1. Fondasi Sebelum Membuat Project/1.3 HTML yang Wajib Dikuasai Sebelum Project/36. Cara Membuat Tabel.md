# 36. Cara Membuat Tabel Menggunakan Tag Table

## Definisi & Target
Tabel HTML menggunakan `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>` untuk menampilkan data dalam baris dan kolom secara terstruktur.

## Analogi Alur
Tabel seperti spreadsheet Excel. Baris adalah data (tr), kolom adalah kategori (th untuk header, td untuk data). thead adalah header sheet, tbody adalah isi data, tfoot adalah total/ringkasan.

## Poin-Poin Penting
- `<table>`: container tabel
- `<thead>`: bagian header tabel
- `<tbody>`: bagian body/isi tabel
- `<tfoot>`: bagian footer tabel (total, summary)
- `<tr>`: table row (baris)
- `<th>`: table header (judul kolom, bold default)
- `<td>`: table data (sel data)
- `colspan`: menggabungkan kolom
- `rowspan`: menggabungkan baris
- Jangan gunakan tabel untuk layout (gunakan CSS grid/flexbox)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Tabel HTML</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <div class="table-container">
    <h2>Data Penjualan</h2>
    <table>
      <thead>
        <tr>
          <th>Produk</th>
          <th>Kategori</th>
          <th>Harga</th>
          <th>Terjual</th>
          <th>Total</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td>Laptop</td>
          <td>Elektronik</td>
          <td>Rp 10.000.000</td>
          <td>15</td>
          <td>Rp 150.000.000</td>
        </tr>
        <tr>
          <td>Mouse</td>
          <td>Aksesoris</td>
          <td>Rp 150.000</td>
          <td>50</td>
          <td>Rp 7.500.000</td>
        </tr>
        <tr>
          <td>Keyboard</td>
          <td>Aksesoris</td>
          <td>Rp 350.000</td>
          <td>30</td>
          <td>Rp 10.500.000</td>
        </tr>
      </tbody>
      <tfoot>
        <tr>
          <td colspan="3"><strong>Total Keseluruhan</strong></td>
          <td><strong>95</strong></td>
          <td><strong>Rp 168.000.000</strong></td>
        </tr>
      </tfoot>
    </table>
  </div>
</body>
</html>
```
```css
body { font-family: Arial, sans-serif; display: flex; justify-content: center; align-items: center; min-height: 100vh; margin: 0; background: #f5f6fa; }

tfoot td:last-child { color: #27ae60; }
```

## Cara Integrasi
1. Gunakan `<table>` untuk data tabular, BUKAN untuk layout
2. Struktur: `<table>` > `<thead>` + `<tbody>` + `<tfoot>`
3. Setiap baris = `<tr>`, header = `<th>`, data = `<td>`
4. Gunakan `border-collapse: collapse` di CSS untuk garis rapi
5. Untuk tabel responsif, bungkus dengan div yang bisa scroll horizontal
