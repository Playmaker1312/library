# 45. Cara Menggunakan Atribut Data untuk Menyimpan Data Kustom

## Definisi & Target
Atribut `data-*` (data attributes) adalah atribut kustom HTML untuk menyimpan data tambahan di elemen HTML yang bisa diakses via JavaScript.

## Analogi Alur
Data attributes seperti tempelan post-it pada barang. Anda menempelkan informasi tambahan yang tidak terlihat di permukaan, tapi bisa dibaca saat dibutuhkan. Misal: pada buku, tempel "harga: 50000" yang hanya dibaca kasir.

## Poin-Poin Penting
- Format: `data-nama="value"` (nama harus lowercase, gabung dengan strip)
- Diakses via JavaScript: `element.dataset.nama` (camelCase)
- Bisa menyimpan string, number, JSON (perlu parse)
- Tidak mempengaruhi tampilan atau styling
- Berguna untuk menyimpan ID, status, konfigurasi
- Alternatif untuk class atau id ketika butuh data lebih kompleks

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Data Attributes Demo</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <div class="data-demo">
    <h1>Data Attributes (data-*)</h1>

    <div class="product-list">
      <div class="product-card" data-id="101" data-name="Laptop" data-price="10000000" data-category="elektronik" data-stock="true">
        <h3>Laptop</h3>
        <p>Rp 10.000.000</p>
        <button class="btn-detail">Lihat Detail</button>
      </div>
      <div class="product-card" data-id="102" data-name="Mouse" data-price="150000" data-category="aksesoris" data-stock="true">
        <h3>Mouse</h3>
        <p>Rp 150.000</p>
        <button class="btn-detail">Lihat Detail</button>
      </div>
      <div class="product-card" data-id="103" data-name="Keyboard" data-price="350000" data-category="aksesoris" data-stock="false">
        <h3>Keyboard</h3>
        <p>Rp 350.000</p>
        <span class="badge">Stok Habis</span>
        <button class="btn-detail">Lihat Detail</button>
      </div>
    </div>

    <div id="output-panel">
      <h3>Data Produk:</h3>
      <pre id="outputData">Klik "Lihat Detail" pada produk</pre>
    </div>
  </div>
  <script src="js/script.js"></script>
</body>
</html>
```

```javascript
var buttons = document.querySelectorAll('.btn-detail');

for (var i = 0; i < buttons.length; i++) {
  buttons[i].addEventListener('click', function() {
    var card = this.closest('.product-card');
    var data = {
      id: card.dataset.id,
      name: card.dataset.name,
      price: parseInt(card.dataset.price),
      category: card.dataset.category,
      stock: card.dataset.stock === 'true'
    };
    document.getElementById('outputData').textContent = JSON.stringify(data, null, 2);
  });
}
```

## Cara Integrasi
1. Tambahkan `data-nama="value"` ke elemen HTML
2. Gunakan `element.dataset.nama` di JavaScript untuk membaca
3. Untuk nilai multi-kata: `data-user-name` di HTML, `element.dataset.userName` di JS
4. Untuk menyimpan objek: simpan sebagai JSON string, parse dengan `JSON.parse`
5. Atribut data tidak boleh digunakan untuk styling (gunakan class)
