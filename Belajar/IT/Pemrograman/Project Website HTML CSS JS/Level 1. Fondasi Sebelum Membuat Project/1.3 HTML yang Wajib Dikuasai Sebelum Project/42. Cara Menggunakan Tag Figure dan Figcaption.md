# 42. Cara Menggunakan Tag Figure dan Figcaption

## Definisi & Target
`<figure>` dan `<figcaption>` adalah tag HTML5 untuk mengelompokkan konten media (gambar, ilustrasi, diagram, kode) dengan caption/keterangan.

## Analogi Alur
Figure dan figcaption seperti bingkai foto di museum yang dilengkapi label penjelasan. Gambar (figure) ditempel di dinding, dan di bawahnya ada plakat kecil (figcaption) yang menjelaskan gambar tersebut.

## Poin-Poin Penting
- `<figure>`: container untuk konten media
- `<figcaption>`: caption/keterangan (bisa di atas atau bawah)
- Bersifat semantik - membantu SEO dan aksesibilitas
- Bisa berisi gambar, video, ilustrasi, tabel, kutipan, atau kode
- `<figcaption>` opsional, tapi direkomendasikan
- Satu figure bisa punya satu figcaption

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Figure & Figcaption</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <article class="content">
    <h1>Penggunaan Figure & Figcaption</h1>

    <p>Berikut adalah contoh penggunaan tag figure untuk berbagai jenis konten media:</p>

    <figure class="image-figure">
      <img src="https://via.placeholder.com/600x300/3498db/ffffff?text=Contoh+Gambar" alt="Contoh gambar placeholder biru" style="width:100%;height:auto;">
      <figcaption>Gambar 1: Contoh gambar dengan caption di bawah. Figcaption menjelaskan isi gambar.</figcaption>
    </figure>

    <figure class="code-figure">
      <pre><code>function hello() {
  console.log('Hello, World!');
}</code></pre>
      <figcaption>Kode 1: Fungsi hello dalam JavaScript</figcaption>
    </figure>

    <figure class="quote-figure">
      <blockquote>
        "The best way to predict the future is to invent it."
      </blockquote>
      <figcaption>— Alan Kay, <cite>Computer Scientist</cite></figcaption>
    </figure>
  </article>
</body>
</html>
```


## Cara Integrasi
1. Bungkus gambar/media dengan `<figure>`
2. Tambahkan `<figcaption>` untuk deskripsi
3. Figcaption bisa ditempatkan sebelum atau sesudah konten figure
4. Gunakan CSS untuk styling figure dan figcaption
5. Figure bersifat block-level dan bisa dipindahkan (float) dalam layout
