# 32. Cara Menggunakan Heading Tag h1 hingga h6

## Definisi & Target
Heading tags (`<h1>` sampai `<h6>`) mendefinisikan hierarki judul dan subjudul dalam halaman. Penting untuk struktur konten, SEO, dan aksesibilitas.

## Analogi Alur
Heading seperti outline buku: `h1` adalah judul buku, `h2` adalah bab, `h3` adalah sub-bab, `h4` adalah bagian dalam sub-bab, dan seterusnya. Outline yang baik memudahkan pembaca navigasi.

## Poin-Poin Penting
- `<h1>`: hanya satu per halaman (judul utama)
- `<h2>`: sub-judul utama, bisa multiple
- `<h3>`: sub-bagian dari h2
- `<h4>` - `<h6>`: semakin dalam hierarki
- Jangan loncat level (h1 langsung h3) - ini melanggar aksesibilitas
- Ukuran font bisa diubah dengan CSS, yang penting hierarki semantiknya
- Heading membantu SEO (Google memberi bobot lebih)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Heading Tags Demo</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <article>
    <h1>Panduan Lengkap HTML (h1)</h1>
    <p>Ini adalah paragraf pengantar. H1 hanya boleh satu per halaman.</p>

    <h2>1. Dasar HTML (h2)</h2>
    <p>Bab tentang dasar-dasar HTML.</p>

    <h3>1.1 Tag dan Elemen (h3)</h3>
    <p>Sub-bab tentang tag.</p>

    <h3>1.2 Atribut HTML (h3)</h3>
    <p>Sub-bab tentang atribut.</p>

    <h4>1.2.1 Atribut Global (h4)</h4>
    <p>Sub-sub-bab.</p>

    <h2>2. HTML Lanjutan (h2)</h2>
    <p>Bab lanjutan.</p>

    <h3>2.1 Formulir (h3)</h3>
    <p>Sub-bab formulir.</p>
  </article>
</body>
</html>
```
```css
body { font-family: 'Segoe UI', sans-serif; max-width: 800px; margin: 40px auto; padding: 20px; line-height: 1.8; }
h1 { font-size: 2.5rem; color: #2c3e50; border-bottom: 4px solid #3498db; padding-bottom: 10px; }
h2 { font-size: 1.8rem; color: #34495e; margin-top: 2rem; }
h3 { font-size: 1.4rem; color: #555; }
h4 { font-size: 1.1rem; color: #777; }
p { color: #444; }
```

## Cara Integrasi
1. Tentukan satu `<h1>` per halaman - biasanya judul halaman
2. Gunakan `<h2>` untuk bagian utama (bab)
3. Gunakan `<h3>` untuk sub-bagian
4. Jangan lewati level - gunakan CSS untuk mengubah ukuran jika perlu
5. Test dengan screen reader atau alat aksesibilitas untuk verifikasi hierarki
