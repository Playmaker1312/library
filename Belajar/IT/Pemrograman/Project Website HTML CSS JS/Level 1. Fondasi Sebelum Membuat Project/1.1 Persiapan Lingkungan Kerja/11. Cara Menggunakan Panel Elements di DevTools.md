# 11. Cara Menggunakan Panel Elements di DevTools

## Definisi & Target
Panel Elements di DevTools menampilkan struktur DOM HTML dan CSS yang diterapkan. Anda bisa mengedit HTML dan CSS secara real-time untuk debugging dan eksperimen.

## Analogi Alur
Panel Elements seperti blueprint bangunan yang bisa Anda coret-coret langsung. Anda bisa mengubah ukuran jendela, warna dinding, atau struktur ruangan dan melihat hasilnya instan.

## Poin-Poin Penting
- Melihat DOM tree HTML secara hierarkis
- Mengedit teks, atribut, dan struktur HTML langsung
- Melihat dan mengedit CSS di panel Styles
- Menambah/menghapus class CSS sementara
- Melihat box model (margin, border, padding) secara visual
- Perubahan BERSIFAT SEMENTARA, tidak menyimpan ke file

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Elements Panel Demo</title>
  <style>
    .card {
      width: 300px;
      padding: 20px;
      border: 2px solid #2c3e50;
      border-radius: 10px;
      margin: 50px auto;
      background: #ecf0f1;
    }
    .card h2 {
      color: #2c3e50;
      margin-top: 0;
    }
    .card p {
      color: #7f8c8d;
    }
    .highlight {
      background: #f1c40f;
      padding: 5px;
      border-radius: 4px;
    }
  </style>
</head>
<body>
  <div class="card">
    <h2>Judul Card</h2>
    <p>Ini adalah paragraf dalam card. Inspeksi elemen ini menggunakan DevTools.</p>
    <span class="highlight">Highlighted Text</span>
  </div>
</body>
</html>
```

## Cara Integrasi
1. Buka halaman di browser, tekan F12
2. Klik tab "Elements" (Chrome) atau "Inspector" (Firefox)
3. Arahkan kursor ke elemen HTML di panel kiri untuk melihat highlight di halaman
4. Klik kanan elemen > "Edit as HTML" untuk mengubah HTML
5. Di panel Styles (kanan), edit nilai CSS, centang/dicentang properti untuk toggle
