# 06. Cara Menginstal Ekstensi Color Highlight

## Definisi & Target
Color Highlight adalah ekstensi VS Code yang menampilkan preview warna langsung di editor untuk nilai warna CSS seperti hex, rgb, hsl, dan nama warna.

## Analogi Alur
Color Highlight seperti membuka palet cat dan melihat warna asli di samping nama cat. Anda tidak perlu menebak-nebak apakah #FF5733 itu merah atau oranye.

## Poin-Poin Penting
- Menampilkan warna latar belakang di belakang kode warna
- Mendukung format hex, rgb, rgba, hsl, hsla, dan named colors
- Membantu memilih warna yang tepat lebih cepat
- Dapat dikustomisasi jenis format yang di-highlight
- Tidak mengubah kode, hanya visual aid

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Color Highlight Demo</title>
  <style>
    .box {
      width: 100px;
      height: 100px;
      margin: 10px;
    }
  </style>
</head>
<body>
  <div class="box" style="background: #ff5733;">Hex</div>
  <div class="box" style="background: rgb(46, 139, 87);">RGB</div>
  <div class="box" style="background: hsl(200, 100%, 50%);">HSL</div>
</body>
</html>
```
```css
.box {
  border-radius: 8px;
  display: inline-flex;
  align-items: center;
  justify-content: center;
  color: white;
  font-weight: bold;
}
```

## Cara Integrasi
1. Install ekstensi "Color Highlight" dari VS Code marketplace
2. Ekstensi aktif secara otomatis saat file CSS atau HTML dibuka
3. Di VS Code settings, cari "colorHighlight" untuk opsi kustomisasi
4. Semua nilai warna akan memiliki latar belakang sesuai warna tersebut
