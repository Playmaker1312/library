# 04. Cara Menginstal Ekstensi ESLint

## Definisi & Target
ESLint adalah static code analysis tool untuk JavaScript yang mendeteksi error, bug, dan pola kode bermasalah sebelum kode dijalankan.

## Analogi Alur
ESLint seperti proofreader yang memeriksa tulisan Anda sebelum dikirim. Ia menandai kesalahan ketik, kalimat ambigu, dan pelanggaran aturan tata bahasa tanpa mengubah isi.

## Poin-Poin Penting
- Mendeteksi syntax error dan logical error di JavaScript
- Dapat dikonfigurasi dengan rules yang ketat atau longgar
- Mendukung JavaScript modern (ES6+) dan JSX
- Integrasi dengan Prettier untuk formatting
- Wajib untuk project JavaScript yang serius

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>

```
```javascript
const x = 10;

```

## Cara Integrasi
1. Install ekstensi ESLint dari VS Code marketplace
2. Install ESLint global/npm: `npm init -y` lalu `npm install eslint --save-dev`
3. Inisialisasi konfigurasi: `npx eslint --init`
4. Pilih aturan sesuai kebutuhan (Airbnb, Standard, atau custom)
5. ESLint akan otomatis memberi garis merah pada kode bermasalah
6. Jalankan `npx eslint .` untuk scan seluruh project
