# 03. Cara Menginstal Ekstensi Prettier

## Definisi & Target
Prettier adalah opinionated code formatter yang secara otomatis merapikan kode HTML, CSS, JavaScript, dan banyak bahasa lain agar konsisten.

## Analogi Alur
Prettier seperti petugas kerapian yang datang setelah Anda menulis. Ia merapikan meja kerja (kode) agar semua alat dan bahan tertata rapi, tanpa mengubah fungsi alat tersebut.

## Poin-Poin Penting
- Menghilangkan perdebatan soal style kode dalam tim
- Format otomatis saat menyimpan file (format on save)
- Mendukung indentasi, tanda kutip, trailing comma, dll
- Dapat dikonfigurasi melalui file .prettierrc
- Terintegrasi dengan banyak editor

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Contoh Prettier</title>
</head>
<body>
  <p>Hello World</p>
</body>
</html>
```
```css
body {
  font-family: sans-serif;
  margin: 0;
  padding: 20px;
}
```
```javascript
const greet = (name) => {
  return `Hello ${name}`;
};
```

## Cara Integrasi
1. Install ekstensi Prettier dari VS Code marketplace
2. Buka Settings (Ctrl+,), cari "format on save", centang
3. Cari "default formatter", pilih "Prettier - Code formatter"
4. Buat file .prettierrc di root project untuk konfigurasi:
   ```json
   { "semi": true, "singleQuote": true, "tabWidth": 2 }
   ```
5. Setiap Ctrl+S akan otomatis merapikan kode
