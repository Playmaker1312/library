# 07. Cara Menginstal Ekstensi HTML CSS Support

## Definisi & Target
HTML CSS Support adalah ekstensi VS Code yang memberikan autocomplete untuk class dan id HTML yang didefinisikan di file CSS, serta sebaliknya.

## Analogi Alur
HTML CSS Support seperti asisten yang mengingatkan nama-nama style yang sudah Anda buat. Saat mengetik class di HTML, ia menampilkan daftar class yang tersedia di CSS.

## Poin-Poin Penting
- Autocomplete class dan id yang sudah didefinisikan di CSS
- Autocomplete CSS properties dan values di file CSS
- Mendukung scanning file CSS untuk referensi
- Mendukung file CSS internal dan eksternal
- Meningkatkan produktivitas dan mengurangi typo

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>HTML CSS Support Demo</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="card">
    <h1 class="card-title">Judul Card</h1>
    <p class="card-desc">Deskripsi card</p>
    <button class="btn btn-primary">Klik Saya</button>
  </div>
</body>
</html>
```
```css
.card {
  border: 1px solid #ddd;
  padding: 20px;
  border-radius: 8px;
}
.card-title {
  font-size: 24px;
  color: #333;
}
.card-desc {
  color: #666;
}
.btn {
  padding: 10px 20px;
  border: none;
  cursor: pointer;
}
.btn-primary {
  background: #007bff;
  color: white;
}
```

## Cara Integrasi
1. Install ekstensi "HTML CSS Support" dari VS Code marketplace
2. Otomatis aktif tanpa konfigurasi
3. Saat mengetik `class="` di HTML, akan muncul dropdown class yang tersedia
4. Ekstensi membaca class dari file CSS yang terhubung (link tag)
