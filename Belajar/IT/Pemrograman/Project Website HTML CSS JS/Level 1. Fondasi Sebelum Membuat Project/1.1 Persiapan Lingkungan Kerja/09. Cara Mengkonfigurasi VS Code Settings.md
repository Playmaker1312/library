# 09. Cara Mengkonfigurasi VS Code Settings

## Definisi & Target
VS Code Settings memungkinkan Anda mengkustomisasi editor agar optimal untuk pengembangan web. Pengaturan bisa dilakukan secara global atau per project.

## Analogi Alur
Settings VS Code seperti dashboard mobil. Anda bisa menyesuaikan posisi kursi (font size), kaca spion (tab width), dan dashboard (theme) agar nyaman berkendara.

## Poin-Poin Penting
- Settings terdiri dari User Settings (global) dan Workspace Settings (per project)
- GUI settings melalui menu File > Preferences > Settings
- File settings.json untuk konfigurasi manual
- Workspace settings disimpan di .vscode/settings.json
- Settings dapat disinkronkan antar perangkat

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
File `.vscode/settings.json` di root project:
```json
{
  "editor.fontSize": 14,
  "editor.fontFamily": "JetBrains Mono, Consolas, monospace",
  "editor.tabSize": 2,
  "editor.wordWrap": "on",
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.minimap.enabled": false,
  "files.autoSave": "afterDelay",
  "files.autoSaveDelay": 1000,
  "workbench.colorTheme": "One Dark Pro",
  "liveServer.settings.port": 5500,
  "emmet.includeLanguages": {
    "javascript": "javascriptreact"
  }
}
```

## Cara Integrasi
1. Buka Settings UI: File > Preferences > Settings (Ctrl+,)
2. Atau buka settings.json langsung: Ctrl+Shift+P, cari "settings.json"
3. Untuk workspace settings: buat folder `.vscode` dan file `settings.json` di dalamnya
4. Tambahkan pengaturan sesuai kebutuhan di atas
5. Restart VS Code jika diperlukan
