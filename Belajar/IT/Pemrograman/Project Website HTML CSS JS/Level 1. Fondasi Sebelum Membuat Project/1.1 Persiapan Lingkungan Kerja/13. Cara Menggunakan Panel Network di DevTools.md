# 13. Cara Menggunakan Panel Network di DevTools

## Definisi & Target
Panel Network di DevTools memantau semua aktivitas jaringan (HTTP requests) yang terjadi saat halaman dimuat atau berinteraksi, termasuk file HTML, CSS, JavaScript, gambar, dan API calls.

## Analogi Alur
Panel Network seperti CCTV di pintu masuk gedung. Setiap orang (request) yang masuk atau keluar tercatat: siapa, dari mana, berapa lama, dan apakah berhasil atau gagal.

## Poin-Poin Penting
- Melihat semua file yang di-load oleh halaman
- Informasi detail: status code, size, waktu loading
- Filter berdasarkan tipe file (JS, CSS, Img, XHR/Fetch, dll)
- Melihat request headers dan response headers
- Melakukan throttle untuk simulasi koneksi lambat
- Melihat waterfall loading timeline

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Network Panel Demo</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Network Panel Demo</h1>
  <button id="btnFetch">Ambil Data</button>
  <pre id="result"></pre>
  <img src="https://via.placeholder.com/150" alt="placeholder">
  <script src="script.js"></script>
</body>
</html>
```
```css
body { font-family: Arial, sans-serif; padding: 20px; }
button { padding: 10px 20px; margin-bottom: 10px; cursor: pointer; }
pre { background: #f4f4f4; padding: 10px; border-radius: 4px; }
```
```javascript
document.getElementById('btnFetch').addEventListener('click', function() {
  fetch('https://jsonplaceholder.typicode.com/todos/1')
    .then(function(response) {
      return response.json();
    })
    .then(function(data) {
      document.getElementById('result').textContent = JSON.stringify(data, null, 2);
      console.log('Data fetched:', data);
    });
});
```

## Cara Integrasi
1. Buka halaman, tekan F12, pilih tab Network
2. Refresh halaman untuk melihat semua request yang terjadi
3. Klik pada setiap request untuk melihat detail headers, preview, dan timing
4. Gunakan filter (All, XHR, JS, CSS, Img, Media, Font) untuk mempersempit tampilan
5. Centang "Disable cache" untuk simulasi fresh load
