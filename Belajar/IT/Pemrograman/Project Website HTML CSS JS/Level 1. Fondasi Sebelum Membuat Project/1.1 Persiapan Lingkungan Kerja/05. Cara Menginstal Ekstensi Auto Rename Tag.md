# 05. Cara Menginstal Ekstensi Auto Rename Tag

## Definisi & Target
Auto Rename Tag adalah ekstensi VS Code yang secara otomatis mengganti pasangan tag HTML/XML saat Anda mengedit salah satunya.

## Analogi Alur
Auto Rename Tag seperti sistem cermin di pasangan baju: saat Anda mengganti baju di kiri, baju kanan ikut berubah secara otomatis. Anda tidak perlu mengganti satu per satu.

## Poin-Poin Penting
- Menghemat waktu saat mengubah nama tag
- Mencegah bug akibat lupa mengganti tag penutup
- Mendukung HTML, XML, dan JSX
- Bekerja real-time saat mengetik
- Sangat ringan tanpa konfigurasi tambahan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Auto Rename Tag Demo</title>
</head>
<body>
  <div class="container">
    <p>Ubah "p" menjadi "span" di tag pembuka</p>
  </div>
</body>
</html>
```

## Cara Integrasi
1. Buka VS Code Extensions (Ctrl+Shift+X)
2. Cari "Auto Rename Tag" oleh Jun Han
3. Klik Install
4. Tidak perlu konfigurasi tambahan
5. Saat Anda mengganti `<div>` menjadi `<section>`, tag penutup `</div>` otomatis berubah menjadi `</section>`
