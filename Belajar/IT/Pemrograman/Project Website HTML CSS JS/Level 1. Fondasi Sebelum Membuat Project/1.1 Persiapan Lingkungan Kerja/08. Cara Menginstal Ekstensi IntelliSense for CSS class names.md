# 08. Cara Menginstal Ekstensi IntelliSense for CSS class names

## Definisi & Target
IntelliSense for CSS class names adalah ekstensi VS Code yang memberikan autocomplete class CSS berdasarkan class yang ada di project, termasuk dari framework CSS.

## Analogi Alur
Ekstensi ini seperti kamus yang berisi daftar lengkap kosa kata CSS yang tersedia. Saat Anda ingin menulis kata (class), kamus langsung menawarkan kata yang tepat.

## Poin-Poin Penting
- Melengkapi autocomplete class dari file CSS di project
- Mendukung framework seperti Bootstrap, Tailwind, dll
- Mendeteksi class dari berbagai sumber (CSS, SCSS, Less)
- Bekerja di file HTML, JSX, Pug, dll
- Memberi preview nama class dengan ikon

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>IntelliSense Demo</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="hero-section">
    <h1 class="hero-title">Selamat Datang</h1>
    <p class="hero-desc">Ini adalah demo IntelliSense</p>
  </div>
</body>
</html>
```
```css
.hero-section {
  text-align: center;
  padding: 60px 20px;
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  color: white;
}
.hero-title {
  font-size: 2.5rem;
  margin-bottom: 1rem;
}
.hero-desc {
  font-size: 1.2rem;
  opacity: 0.9;
}
```

## Cara Integrasi
1. Install "IntelliSense for CSS class names" dari VS Code marketplace
2. Buka Command Palette (Ctrl+Shift+P), cari "IntelliSense" untuk konfigurasi
3. Ekstensi otomatis membaca class dari file CSS yang terhubung
4. Mulai mengetik class di HTML, dan saran class akan muncul
