# 10. Cara Menggunakan Browser DevTools

## Definisi & Target
Browser DevTools (Chrome DevTools / Firefox Developer Tools) adalah alat debugging bawaan browser yang memungkinkan inspeksi HTML, CSS, JavaScript, Network, dan performa halaman web.

## Analogi Alur
DevTools seperti kamera X-ray untuk website. Anda bisa melihat struktur di balik layar (HTML skeleton), cat (CSS), dan perilaku (JavaScript) dari halaman web.

## Poin-Poin Penting
- Diakses dengan F12 atau Ctrl+Shift+I
- Panel Elements untuk HTML dan CSS
- Panel Console untuk JavaScript
- Panel Network untuk request HTTP
- Panel Sources untuk debugging JavaScript
- Panel Application untuk storage, cache, dan service workers
- Panel Performance untuk profiling

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>DevTools Demo</title>
  <style>
    .demo-box {
      width: 200px;
      height: 200px;
      background: #3498db;
      color: white;
      display: flex;
      align-items: center;
      justify-content: center;
      border-radius: 12px;
      margin: 50px auto;
      cursor: pointer;
      transition: transform 0.3s;
    }
    .demo-box:hover {
      transform: scale(1.1);
    }
  </style>
</head>
<body>
  <div class="demo-box" id="box">Klik Saya</div>
  <script>
    document.getElementById('box').addEventListener('click', function() {
      this.textContent = 'Diklik!';
      this.style.background = '#e74c3c';
      console.log('Box diklik pada:', new Date().toLocaleTimeString());
    });
  </script>
</body>
</html>
```

## Cara Integrasi
1. Buka file HTML di browser (gunakan Live Server atau buka langsung)
2. Tekan F12 atau Ctrl+Shift+I untuk membuka DevTools
3. Gunakan tab Elements untuk melihat HTML/CSS
4. Gunakan tab Console untuk melihat output console.log()
5. Gunakan tab Network untuk memantau request
