# 14. Cara Menggunakan Git dan GitHub untuk Version Control

## Definisi & Target
Git adalah version control system untuk melacak perubahan kode, sementara GitHub adalah platform cloud untuk menyimpan repository Git secara online. Target: memahami dasar Git workflow.

## Analogi Alur
Git seperti mesin waktu untuk kode Anda. Setiap perubahan dicatat (commit) dan bisa dikunjungi kembali kapan saja. GitHub seperti cloud storage untuk mesin waktu itu, bisa diakses tim di mana saja.

## Poin-Poin Penting
- Git menyimpan snapshot perubahan, bukan salinan penuh
- Tiga area: working directory, staging area, repository
- Commit adalah checkpoint yang bisa dikembalikan
- Branch untuk pengembangan fitur terisolasi
- GitHub sebagai remote repository untuk kolaborasi
- Pull request untuk menggabungkan kode

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```bash
# Inisialisasi Git di project
git init

# Cek status file
git status

# Menambahkan file ke staging
git add index.html
git add .
git add *.css

# Membuat commit
git commit -m "Initial commit: struktur dasar"

# Melihat history commit
git log --oneline

# Membuat branch baru
git branch fitur-navbar
git checkout fitur-navbar
# atau: git checkout -b fitur-navbar

# Merge branch ke main
git checkout main
git merge fitur-navbar

# Melihat perbedaan
git diff
```

## Cara Integrasi
1. Install Git dari https://git-scm.com
2. Konfigurasi identitas: `git config --global user.name "Nama"` dan `git config --global user.email "email@example.com"`
3. Buka terminal di VS Code (Ctrl+`)
4. Jalankan `git init` untuk memulai repository
5. Buat file, lalu `git add .` dan `git commit -m "pesan"`
6. Gunakan `git status` untuk cek status file
