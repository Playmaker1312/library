# 01. Cara Menginstal VS Code

## Definisi & Target
VS Code (Visual Studio Code) adalah code editor gratis dan open-source dari Microsoft yang menjadi standar industri untuk pengembangan web. Target: mampu menginstal dan mengenali antarmuka VS Code.

## Analogi Alur
VS Code seperti meja kerja tukang kayu. Meja yang baik menyediakan tempat untuk semua alat (ekstensi), memungkinkan efisiensi, dan nyaman digunakan dalam waktu lama.

## Poin-Poin Penting
- VS Code mendukung banyak bahasa pemrograman secara built-in
- Ringan dan cepat dibandingkan IDE lain
- Memiliki integrated terminal, Git integration, dan debugger
- Ekosistem ekstensi sangat luas
- Tersedia untuk Windows, macOS, dan Linux

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
Tidak ada kode implementasi untuk tools. Namun untuk verifikasi instalasi, buka terminal VS Code dan ketik:
```
code --version
```

## Cara Integrasi
1. Buka https://code.visualstudio.com dan klik Download for Windows
2. Jalankan installer (.exe), ikuti wizard instalasi
3. Centang opsi "Add to PATH" dan "Register as default editor" saat instalasi
4. Buka VS Code, buat file baru (Ctrl+N), simpan sebagai index.html
5. Ketik `!` lalu tekan Tab untuk memicu Emmet HTML boilerplate
6. Buka terminal (Ctrl+`) dan jalankan perintah `code --version` untuk verifikasi
