# 15. Cara Membuat Repository GitHub dan Menghubungkannya

## Definisi & Target
Membuat repository di GitHub dan menghubungkan dengan project lokal menggunakan Git remote, sehingga kode bisa di-push ke cloud dan dikolaborasikan.

## Analogi Alur
Repository GitHub seperti lemari arsip pusat. Anda (lokal) membuat dokumen, lalu mengirim salinannya ke lemari pusat (push). Orang lain bisa mengambil salinan (clone/pull) dari lemari yang sama.

## Poin-Poin Penting
- Remote: URL repository GitHub yang terhubung ke lokal
- Origin: nama default untuk remote utama
- Push: mengirim commit lokal ke remote
- Pull: mengambil commit dari remote ke lokal
- Clone: menyalin repository dari GitHub ke lokal baru
- README.md: file deskripsi project (opsional)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```bash
# Setelah membuat repository di GitHub (tanpa README)

# Hubungkan remote
git remote add origin https://github.com/username/nama-repository.git

# Verifikasi remote
git remote -v

# Push ke GitHub
git push -u origin main

# Jika sudah ada README di GitHub, pull dulu
git pull origin main --allow-unrelated-histories

# Clone repository dari GitHub
git clone https://github.com/username/nama-repository.git

# Update lokal dengan perubahan dari remote
git pull origin main
```

## Cara Integrasi
1. Login ke https://github.com, klik tombol "+" > "New repository"
2. Isi nama repository, pilih public/private, jangan centang README
3. Klik "Create repository"
4. Di VS Code terminal, jalankan: `git remote add origin https://github.com/username/nama-repo.git`
5. Jalankan: `git push -u origin main`
6. Refresh halaman GitHub untuk melihat kode Anda online
