# 02. Cara Menginstal Ekstensi Live Server

## Definisi & Target
Live Server adalah ekstensi VS Code yang menyediakan local development server dengan fitur live reload. Setiap perubahan kode langsung tercermin di browser tanpa refresh manual.

## Analogi Alur
Live Server seperti asisten yang terus memantau厨房 (dapur) kode Anda. Begitu ada perubahan bahan (file), asisten langsung menyajikan hidangan baru ke meja (browser) tanpa perlu diminta.

## Poin-Poin Penting
- Menghemat waktu karena auto-refresh browser
- Menyediakan localhost server dengan port acak
- Mendukung HTTPS untuk development
- Bisa dikustomisasi port dan root directory
- Sangat penting untuk workflow pengembangan web modern

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
Tidak ada kode implementasi untuk tools. Cukup klik kanan file HTML lalu pilih "Open with Live Server".

## Cara Integrasi
1. Buka VS Code, klik ikon Extensions di sidebar kiri (Ctrl+Shift+X)
2. Cari "Live Server" oleh Ritwick Dey
3. Klik Install
4. Buat file index.html, klik kanan di dalam editor, pilih "Open with Live Server"
5. Browser akan terbuka dengan URL http://127.0.0.1:5500
6. Ubah kode HTML dan lihat browser merespons secara real-time
