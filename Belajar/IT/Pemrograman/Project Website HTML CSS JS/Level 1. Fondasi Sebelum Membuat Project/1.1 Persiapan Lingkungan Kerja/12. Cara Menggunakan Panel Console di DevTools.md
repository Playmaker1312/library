# 12. Cara Menggunakan Panel Console di DevTools

## Definisi & Target
Panel Console di DevTools adalah terminal JavaScript interaktif untuk mengeksekusi kode, melihat log, dan debugging aplikasi web secara langsung.

## Analogi Alur
Panel Console seperti walkie-talkie developer. Anda bisa "ngobrol" langsung dengan halaman web, menyuruhnya melakukan sesuatu, dan mendengar responsnya secara instan.

## Poin-Poin Penting
- Menampilkan output console.log(), console.error(), console.warn()
- Menjalankan kode JavaScript secara interaktif
- Mengakses variabel dan fungsi global yang ada di halaman
- Menampilkan error dan warning JavaScript
- Mendukung autocomplete untuk JavaScript
- Bisa menggunakan $0 untuk referensi elemen yang di-inspect

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Console Panel Demo</title>
  <style>
    body { font-family: Arial, sans-serif; padding: 20px; }
    button { padding: 10px 20px; font-size: 16px; cursor: pointer; }
    #output { margin-top: 20px; padding: 10px; background: #f0f0f0; border-radius: 4px; }
  </style>
</head>
<body>
  <button id="btnHitung">Hitung 1+1</button>
  <button id="btnError">Buat Error</button>
  <div id="output">Lihat hasil di Console (F12)</div>
  <script>
    const name = 'John Doe';
    const age = 25;

    document.getElementById('btnHitung').addEventListener('click', function() {
      const result = 1 + 1;
      console.log('Hasil 1+1 =', result);
      document.getElementById('output').textContent = 'Hasil: ' + result;
    });

    document.getElementById('btnError').addEventListener('click', function() {
      console.error('Ini adalah contoh error!');
      console.warn('Ini adalah peringatan!');
    });

    console.log('Halaman dimuat, name:', name, 'age:', age);
    console.table([{ name: 'John', age: 25 }, { name: 'Jane', age: 30 }]);
  </script>
</body>
</html>
```

## Cara Integrasi
1. Buka halaman, tekan F12, pilih tab Console
2. Lihat semua output console.log() muncul di sini
3. Ketik perintah JavaScript langsung, contoh: `document.title`
4. Coba: `document.body.style.background = 'lightblue'`
5. Klik tombol di halaman dan lihat outputnya di Console
