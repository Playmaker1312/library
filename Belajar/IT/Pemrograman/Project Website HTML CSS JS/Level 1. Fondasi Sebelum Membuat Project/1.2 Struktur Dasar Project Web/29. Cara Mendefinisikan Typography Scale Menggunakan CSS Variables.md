# 29. Cara Mendefinisikan Typography Scale Menggunakan CSS Variables

## Definisi & Target
Typography scale adalah sistem ukuran font yang konsisten dan proporsional di seluruh website, biasanya mengikuti rasio tertentu (misal: 1.25 atau major third).

## Analogi Alur
Typography scale seperti tangga nada musik. Setiap ukuran font adalah "nada" yang harmonis dengan nada lainnya. Teks heading, subheading, body, dan caption tidak boleh "fals" - harus selaras.

## Poin-Poin Penting
- Rasio umum: 1.250 (Major Third), 1.333 (Perfect Fourth)
- Base font size biasanya 16px (1rem) untuk body
- Scale: h1 (3rem), h2 (2.25rem), h3 (1.75rem), h4 (1.25rem), body (1rem), small (0.875rem)
- Gunakan `rem` untuk ukuran font (relatif terhadap root)
- Variabel memudahkan perubahan scale global

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Typography Scale Demo</title>
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <article class="typography-demo">
    <h1>Heading 1 - 3rem (48px)</h1>
    <h2>Heading 2 - 2.25rem (36px)</h2>
    <h3>Heading 3 - 1.75rem (28px)</h3>
    <h4>Heading 4 - 1.25rem (20px)</h4>
    <p class="body-text">Body text - 1rem (16px). Lorem ipsum dolor sit amet, consectetur adipiscing elit. Typography scale membuat hierarki visual yang konsisten.</p>
    <p class="small-text">Small text / caption - 0.875rem (14px). Biasanya untuk caption, footer, atau metadata.</p>
    <p class="tiny-text">Tiny text - 0.75rem (12px). Untuk label, badge, atau keterangan kecil.</p>
  </article>
</body>
</html>
```
```css
:root {
  --font-primary: 'Georgia', serif;
  --font-secondary: 'Arial', sans-serif;
  --ratio: 1.25;
  --text-xs: 0.75rem;
  --text-sm: 0.875rem;
  --text-base: 1rem;
  --text-md: 1.125rem;
  --text-lg: 1.25rem;
  --text-xl: 1.5rem;
  --text-2xl: 1.75rem;
  --text-3xl: 2.25rem;
  --text-4xl: 3rem;
  --text-5xl: 3.75rem;
  --leading-tight: 1.2;
  --leading-normal: 1.5;
  --leading-relaxed: 1.75;
}
body { font-family: var(--font-secondary); color: #333; line-height: var(--leading-normal); }
.typography-demo { max-width: 700px; margin: 40px auto; padding: 20px; }
h1 { font-size: var(--text-4xl); font-family: var(--font-primary); line-height: var(--leading-tight); margin-bottom: 0.5rem; }
h2 { font-size: var(--text-3xl); font-family: var(--font-primary); line-height: var(--leading-tight); margin-bottom: 0.5rem; }
h3 { font-size: var(--text-2xl); font-family: var(--font-primary); line-height: var(--leading-tight); margin-bottom: 0.5rem; }
h4 { font-size: var(--text-lg); font-weight: bold; margin-bottom: 0.5rem; }
.body-text { font-size: var(--text-base); line-height: var(--leading-relaxed); margin-bottom: 1rem; }
.small-text { font-size: var(--text-sm); color: #666; }
.tiny-text { font-size: var(--text-xs); color: #999; }
```

## Cara Integrasi
1. Tentukan rasio typography (1.25 adalah pilihan aman)
2. Definisikan variabel ukuran font di `:root`
3. Gunakan `var(--text-base)` untuk body, `var(--text-4xl)` untuk h1, dll.
4. Tambahkan variabel line-height untuk konsistensi
5. Test di berbagai ukuran layar untuk responsive typography
