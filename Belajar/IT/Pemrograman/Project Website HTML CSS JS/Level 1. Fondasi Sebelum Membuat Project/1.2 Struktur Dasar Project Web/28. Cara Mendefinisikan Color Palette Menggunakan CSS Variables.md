# 28. Cara Mendefinisikan Color Palette Menggunakan CSS Variables

## Definisi & Target
Color palette adalah kumpulan warna konsisten yang digunakan di seluruh website. Dengan CSS variables di `:root`, color palette mudah dikelola dan diubah.

## Analogi Alur
Color palette seperti palet cat pelukis. Pelukis memilih warna tertentu di palet sebelum melukis. Jika ingin mengubah suasana lukisan, cukup mengganti warna di palet, tanpa perlu mengecat ulang setiap bagian.

## Poin-Poin Penting
- Gunakan warna dengan format HEX, RGB, atau HSL
- Buat variabel untuk primary, secondary, accent, neutral, dan status colors
- Gunakan naming yang jelas: `--color-primary`, `--color-primary-dark`, `--color-primary-light`
- Variasi gelap/terang memudahkan hover, shadow, dan gradient
- HSL (Hue, Saturation, Lightness) paling mudah untuk variasi warna

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Color Palette Demo</title>
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/style.css">

<body>
  <div class="palette-demo">
    <h1>Color Palette</h1>
    <div class="color-grid">
      <div class="color-swatch" style="background: var(--color-primary);">--color-primary</div>

      <div class="color-swatch" style="background: var(--color-primary-light);">--color-primary-light</div>
      <div class="color-swatch" style="background: var(--color-secondary);">--color-secondary</div>
      <div class="color-swatch" style="background: var(--color-accent);">--color-accent</div>
      <div class="color-swatch" style="background: var(--color-danger);">--color-danger</div>
      <div class="color-swatch" style="background: var(--color-warning);">--color-warning</div>
      <div class="color-swatch" style="background: var(--color-success);">--color-success</div>
```

## Cara Integrasi
1. Tentukan palet warna (primary, secondary, neutral, status) di `:root`
2. Buat variasi (dark, light) untuk warna utama
3. Gunakan `var(--nama-variabel)` di semua file CSS
4. Jangan hardcode nilai warna langsung di properti CSS
5. Untuk dark mode: cukup ubah nilai variabel di `[data-theme="dark"]`
