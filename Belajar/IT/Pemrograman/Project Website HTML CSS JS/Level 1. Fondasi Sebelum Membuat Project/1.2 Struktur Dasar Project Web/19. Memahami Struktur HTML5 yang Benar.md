# 19. Memahami Struktur HTML5 yang Benar

## Definisi & Target
HTML5 memiliki struktur dasar wajib: `<!DOCTYPE html>`, `<html>`, `<head>`, dan `<body>`. Memahami fungsi setiap elemen ini adalah fondasi pembuatan website.

## Analogi Alur
HTML seperti tubuh manusia: `<!DOCTYPE html>` adalah identitas (nama), `<html>` adalah kerangka tubuh, `<head>` adalah otak (metadata, tidak terlihat), `<body>` adalah tubuh fisik (konten yang terlihat).

## Poin-Poin Penting
- `<!DOCTYPE html>`: deklarasi tipe dokumen HTML5
- `<html lang="en">`: elemen root dengan atribut bahasa
- `<head>`: metadata, title, link CSS, meta tags (tidak tampil)
- `<body>`: semua konten yang tampil di browser
- Setiap tag harus ditutup dengan benar
- Struktur yang valid penting untuk SEO dan aksesibilitas

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Struktur HTML5</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <h1>Struktur HTML5</h1>
  <p>DOCTYPE mendeklarasikan bahwa ini adalah dokumen HTML5.</p>
  <p>html adalah elemen root yang membungkus semua konten.</p>
  <p>head berisi metadata yang tidak terlihat di halaman.</p>
  <p>body berisi semua konten yang terlihat oleh pengunjung.</p>
  <script src="js/script.js"></script>
</body>
</html>
```
```css
body { font-family: 'Segoe UI', Tahoma, sans-serif; max-width: 800px; margin: 40px auto; padding: 0 20px; line-height: 1.8; }
h1 { color: #e74c3c; border-bottom: 3px solid #e74c3c; padding-bottom: 10px; }
p { background: #f9f9f9; padding: 12px; border-left: 4px solid #3498db; margin: 10px 0; border-radius: 0 4px 4px 0; }
```
```javascript
console.log('Ini adalah output dari script di body');
console.log('<!DOCTYPE html> :', document.doctype);
```

## Cara Integrasi
1. Selalu mulai dengan `<!DOCTYPE html>` di baris pertama
2. Tambahkan `<html lang="en">` (ganti "en" dengan "id" untuk Indonesia)
3. Di dalam `<head>`, cantumkan meta charset, viewport, title, dan link CSS
4. Di dalam `<body>`, tulis semua konten halaman
5. Tempatkan tag `<script>` sebelum `</body>` untuk performa lebih baik
