# 18. Cara Membuat File index.html sebagai Halaman Utama

## Definisi & Target
index.html adalah file default yang otomatis dibaca web server saat mengakses root direktori. Ini adalah pintu masuk utama website.

## Analogi Alur
index.html seperti halaman depan sebuah buku. Pengunjung website pertama kali melihat halaman ini, dan dari sini mereka menavigasi ke halaman lain.

## Poin-Poin Penting
- Web server (Apache, Nginx, Live Server) mencari index.html secara default
- index.html harus berada di root folder project
- Semua halaman lain bisa di-link dari index.html
- Nama file case-sensitive di beberapa server (Linux)
- Bisa juga index.php, index.asp, dll tergantung teknologi

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Beranda - Nama Website</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <header>
    <h1>Selamat Datang di Website Saya</h1>
    <nav>
      <a href="index.html">Beranda</a>
      <a href="tentang.html">Tentang</a>
      <a href="kontak.html">Kontak</a>
    </nav>
  </header>
  <main>
    <section>
      <h2>Section Utama</h2>
      <p>Ini adalah halaman utama website. Semua pengunjung akan melihat halaman ini pertama kali.</p>
    </section>
  </main>
  <footer>
    <p>&copy; 2024 Website Saya</p>
  </footer>
  <script src="js/script.js"></script>
</body>
</html>
```
```css
body { font-family: Arial, sans-serif; margin: 0; padding: 20px; line-height: 1.6; }
header { background: #2c3e50; color: white; padding: 20px; border-radius: 8px; }
nav a { color: white; margin-right: 15px; text-decoration: none; }
nav a:hover { text-decoration: underline; }
main { padding: 20px 0; }
footer { text-align: center; color: #777; margin-top: 40px; }
```
```javascript
console.log('Halaman utama (index.html) berhasil dimuat');
```

## Cara Integrasi
1. Buat file index.html di root folder project
2. Isi dengan struktur HTML5 dasar
3. Simpan dan buka dengan Live Server
4. Browser akan menampilkan halaman index.html
5. Tambahkan halaman lain (tentang.html, kontak.html) untuk navigasi lengkap
