# 21. Cara Menghubungkan File JavaScript Eksternal ke HTML

## Definisi & Target
JavaScript eksternal adalah file .js terpisah yang dihubungkan ke HTML menggunakan tag `<script>`. Memisahkan logika dari konten dan styling.

## Analogi Alur
HTML adalah panggung teater, CSS adalah tata cahaya dan kostum, JavaScript adalah aktor dan kru yang membuat panggung hidup: bergerak, bereaksi, dan berinteraksi.

## Poin-Poin Penting
- Gunakan `<script src="path/file.js"></script>` untuk file eksternal
- Penempatan script mempengaruhi performa loading
- Letakkan script sebelum `</body>` agar HTML selesai di-render dulu
- Atau gunakan atribut `defer` atau `async` di `<head>`
- Tag `<script>` tidak boleh self-closing

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>JavaScript Eksternal</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <div class="container">
    <h1 id="judul">JavaScript Eksternal</h1>
    <p id="demo">Klik tombol untuk mengubah teks ini.</p>
    <button id="btnUbah">Ubah Teks</button>
    <button id="btnHitung">Hitung Klik</button>
    <p>Klik tombol: <span id="counter">0</span></p>
  </div>
  <script src="js/script.js"></script>
</body>
</html>
```
```css
body { font-family: Arial, sans-serif; display: flex; justify-content: center; align-items: center; min-height: 100vh; margin: 0; background: #1a1a2e; color: white; }
.container { text-align: center; padding: 40px; background: #16213e; border-radius: 16px; box-shadow: 0 8px 32px rgba(0,0,0,0.3); }
button { margin: 8px; padding: 10px 20px; border: none; border-radius: 6px; background: #e94560; color: white; cursor: pointer; font-size: 16px; }
button:hover { background: #c73652; }
#counter { font-weight: bold; font-size: 24px; color: #e94560; }
```
```javascript
var count = 0;

document.getElementById('btnUbah').addEventListener('click', function() {
  document.getElementById('demo').textContent = 'Teks berhasil diubah oleh JavaScript!';
});

document.getElementById('btnHitung').addEventListener('click', function() {
  count++;
  document.getElementById('counter').textContent = count;
});

console.log('JavaScript eksternal berjalan dengan sukses');
```

## Cara Integrasi
1. Buat file `js/script.js`
2. Di HTML, tambahkan `<script src="js/script.js"></script>` sebelum `</body>`
3. Alternatif: letakkan di `<head>` dengan atribut `defer`
   - `<script src="js/script.js" defer></script>`
4. Pastikan path file JavaScript benar
5. Multiple JS files bisa di-load dengan beberapa tag `<script>`
