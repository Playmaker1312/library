# 22. Cara Mengatur Tag Meta Viewport untuk Responsive Design

## Definisi & Target
Meta viewport adalah tag HTML yang mengontrol bagaimana halaman ditampilkan di perangkat mobile, memungkinkan responsive design bekerja dengan benar.

## Analogi Alur
Meta viewport seperti kaca pembesar yang bisa diatur. Tanpa viewport, website desktop dilihat di HP akan tampak kecil dan perlu di-zoom-in. Viewport mengatur "zoom awal" agar halaman pas di layar.

## Poin-Poin Penting
- `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
- `width=device-width` menyamakan lebar viewport dengan lebar perangkat
- `initial-scale=1.0` mengatur level zoom awal
- Wajib untuk semua website modern yang responsive
- Tanpa ini, website tidak akan responsive di mobile

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Viewport Demo</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <div class="container">
    <h1>Responsive dengan Viewport</h1>
    <div class="card-grid">
      <div class="card">Card 1</div>
      <div class="card">Card 2</div>
      <div class="card">Card 3</div>
      <div class="card">Card 4</div>
    </div>
    <p>Resize browser untuk melihat perubahan layout.</p>
  </div>
</body>
</html>
```
```css
body { font-family: Arial, sans-serif; margin: 0; padding: 20px; background: #f5f5f5; }
.container { max-width: 1200px; margin: 0 auto; }
h1 { text-align: center; color: #333; }
.card-grid { display: grid; grid-template-columns: repeat(4, 1fr); gap: 16px; margin: 20px 0; }
.card { background: white; padding: 40px 20px; text-align: center; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1); font-size: 18px; font-weight: bold; color: #555; }
@media (max-width: 768px) { .card-grid { grid-template-columns: repeat(2, 1fr); } }
@media (max-width: 480px) { .card-grid { grid-template-columns: 1fr; } }
```

## Cara Integrasi
1. Tambahkan meta viewport di `<head>` setiap halaman HTML
2. Gunakan CSS media queries untuk layout berbeda di tiap ukuran layar
3. Uji dengan resize browser atau Chrome DevTools mobile mode (ikon phone)
4. Tanpa meta viewport, media queries tidak akan berfungsi optimal di mobile
