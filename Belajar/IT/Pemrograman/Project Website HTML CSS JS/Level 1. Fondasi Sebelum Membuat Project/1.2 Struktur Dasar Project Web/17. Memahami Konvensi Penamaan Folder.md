# 17. Memahami Konvensi Penamaan Folder

## Definisi & Target
Konvensi penamaan folder (css, js, images, fonts, assets) adalah standar industri untuk mengorganisir file project web.

## Analogi Alur
Konvensi penamaan seperti rambu-rambu lalu lintas. Semua pengemudi (developer) tahu bahwa "STOP" berarti berhenti. Demikian pula, folder "css" langsung diketahui berisi stylesheet.

## Poin-Poin Penting
- `css/` : Cascading Style Sheets - file styling (.css)
- `js/` : JavaScript - file script (.js)
- `images/` atau `img/` : gambar (.png, .jpg, .svg, .webp)
- `fonts/` : font files (.woff, .woff2, .ttf)
- `assets/` : aset lain (video, PDF, icon, favicon)
- Gunakan huruf kecil dan tanpa spasi untuk folder
- Konsisten: pilih satu gaya (css/ bukan CSS/ atau Css/)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Struktur Folder</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <h1>Struktur Folder Project Web</h1>
  <ul>
    <li>css/style.css - Styling halaman</li>
    <li>js/script.js - Logika JavaScript</li>
    <li>images/logo.png - Gambar logo</li>
    <li>fonts/custom.woff2 - Font kustom</li>
    <li>assets/icons/ - Kumpulan ikon</li>
  </ul>
  <script src="js/script.js"></script>
</body>
</html>
```
```css
body { font-family: Arial, sans-serif; margin: 40px; }
h1 { color: #2c3e50; }
ul { list-style: none; padding: 0; }
li { padding: 8px 0; color: #555; }
li::before { content: "📁 "; }
```
```javascript
console.log('Struktur folder project terorganisir dengan baik');
```

## Cara Integrasi
1. Buat folder dengan nama lowercase: `css`, `js`, `images`, `fonts`, `assets`
2. Letakkan file sesuai fungsinya di folder masing-masing
3. Saat memanggil file di HTML, gunakan path relatif: `href="css/style.css"`
4. Jangan campur aduk file CSS di folder js atau sebaliknya
