# 30. Cara Membuat File JavaScript Utama dengan Struktur yang Rapi

## Definisi & Target
File JavaScript utama (`script.js`) adalah file pusat untuk logika website. Struktur yang rapi menggunakan fungsi, event listener terorganisir, dan inisialisasi yang jelas.

## Analogi Alur
File JavaScript utama seperti panel kontrol pesawat. Semua tombol dan sakelar (fungsi) tertata rapi di panel, bukan berserakan di lantai. Pilot (developer) tahu persis di mana setiap kontrol berada.

## Poin-Poin Penting
- Gunakan 'use strict' di awal file
- Kelompokkan kode berdasarkan fitur/fungsi
- Inisialisasi event listener di fungsi init()
- Hindari global variables yang berlebihan
- Gunakan命名 yang deskriptif untuk fungsi dan variabel
- Pisahkan logika ke fungsi-fungsi kecil

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```javascript
var App = {
  count: 0,
  items: [],

  init: function() {
    this.cacheDom();
    this.bindEvents();
    this.render();
  },

  cacheDom: function() {
    this.title = document.getElementById('title');
    this.btnToggle = document.getElementById('btnToggle');
    this.btnAdd = document.getElementById('btnAdd');
    this.itemList = document.getElementById('itemList');
    this.counterEl = document.getElementById('counter');
  },

  bindEvents: function() {
    this.btnToggle.addEventListener('click', this.toggleMode.bind(this));
    this.btnAdd.addEventListener('click', this.addItem.bind(this));
  },

  toggleMode: function() {
    document.body.classList.toggle('dark-mode');
    this.title.textContent = document.body.classList.contains('dark-mode') ? 'Dark Mode' : 'Light Mode';
  },

  addItem: function() {
    this.count++;
    this.items.push('Item ' + this.count);
    this.render();
  },

  render: function() {
    this.counterEl.textContent = 'Count: ' + this.count;
    var html = '';
    for (var i = 0; i < this.items.length; i++) {
      html += '<li>' + this.items[i] + '</li>';
    }
    this.itemList.innerHTML = html;
  }
};

document.addEventListener('DOMContentLoaded', function() {
  App.init();
});
```

## Cara Integrasi
1. Buat file `js/script.js`
2. Gunakan pola object literal atau IIFE untuk mengorganisir kode
3. Panggil fungsi inisialisasi setelah DOM siap
4. Link di HTML dengan `<script src="js/script.js"></script>`
5. Gunakan `console.log()` untuk debugging dan verifikasi
