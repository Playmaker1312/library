# 24. Cara Menggunakan Google Fonts dan Menghubungkannya

## Definisi & Target
Google Fonts adalah layanan font gratis yang bisa diintegrasikan ke website melalui link CSS atau @import, memberikan variasi tipografi yang kaya tanpa perlu menyimpan file font.

## Analogi Alur
Google Fonts seperti perpustakaan font raksasa online. Anda tidak perlu membeli atau mengunduh font - cukup "pinjam" dengan memanggilnya dari perpustakaan melalui internet.

## Poin-Poin Penting
- Ratusan font gratis tersedia
- Diintegrasikan via `<link>` di HTML atau `@import` di CSS
- Bisa memilih multiple weights dan styles
- Optimasi loading dengan font-display
- Dapat dikombinasikan dengan font lokal sebagai fallback

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Google Fonts Demo</title>
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&family=Playfair+Display:wght@700&display=swap" rel="stylesheet">
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <h1 class="heading-font">Google Fonts: Playfair Display</h1>
  <p class="body-font">Ini adalah contoh penggunaan Google Fonts. Teks body menggunakan font Inter dengan weight 400.</p>
  <p class="body-font"><strong>Teks tebal</strong> menggunakan weight 700.</p>
</body>
</html>
```
```css
body { margin: 40px; background: #fafafa; }
.heading-font { font-family: 'Playfair Display', serif; font-weight: 700; font-size: 2.5rem; color: #1a1a2e; }
.body-font { font-family: 'Inter', sans-serif; font-weight: 400; font-size: 1.1rem; line-height: 1.8; color: #333; }
.body-font strong { font-weight: 700; }
```
```javascript
console.log('Google Fonts berhasil dimuat');
console.log('Font Playfair Display dan Inter digunakan');
```

## Cara Integrasi
1. Buka https://fonts.google.com, pilih font yang diinginkan
2. Klik "Get font", lalu "Get embed code"
3. Salin tag `<link>` dan tempel di `<head>` HTML
4. Gunakan `font-family` di CSS sesuai nama yang diberikan
5. Tambahkan `font-display: swap` di CSS atau parameter `&display=swap` di URL untuk performa
