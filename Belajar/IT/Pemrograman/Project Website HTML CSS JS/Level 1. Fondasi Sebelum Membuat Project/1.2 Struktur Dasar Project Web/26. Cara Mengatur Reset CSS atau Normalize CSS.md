# 26. Cara Mengatur Reset CSS atau Normalize CSS

## Definisi & Target
Reset CSS dan Normalize CSS adalah file CSS yang menyamakan styling default antar browser (Chrome, Firefox, Safari, Edge) sehingga tampilan konsisten.

## Analogi Alur
Setiap browser punya "kepribadian" sendiri dalam menampilkan HTML - Chrome memberi margin 8px ke body, Firefox sedikit berbeda. Reset CSS seperti seragam sekolah yang membuat semua siswa tampil sama, apa pun latar belakang mereka.

## Poin-Poin Penting
- Reset CSS: menghapus semua style bawaan browser (margin, padding, font-size)
- Normalize CSS: mempertahankan style berguna, hanya menormalkan perbedaan
- Reset membuat styling dari nol
- Normalize lebih "ramah" karena tidak menghapus semuanya
- Keduanya ditempatkan sebelum file CSS utama
- CSS Reset modern: Josh Comeau reset, Andy Bell reset

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CSS Reset Demo</title>
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <h1>Setelah CSS Reset</h1>
  <p>Perhatikan: tidak ada margin bawaan browser.</p>
  <ul>
    <li>List item 1</li>
    <li>List item 2</li>
  </ul>
  <a href="#">Link example</a>
</body>
</html>
```
```css
*,
*::before,
*::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}
html {
  font-size: 16px;
  -webkit-text-size-adjust: 100%;
}
body {
  min-height: 100vh;
  line-height: 1.5;
  -webkit-font-smoothing: antialiased;
}
img, picture, video, canvas, svg {
  display: block;
  max-width: 100%;
}
input, button, textarea, select {
  font: inherit;
}
p, h1, h2, h3, h4, h5, h6 {
  overflow-wrap: break-word;
}
a { text-decoration: none; color: inherit; }
ul, ol { list-style: none; }
```
```css
body { font-family: Arial, sans-serif; padding: 40px; background: #f9f9f9; }
h1 { font-size: 2rem; margin-bottom: 1rem; color: #2c3e50; }
p { margin-bottom: 1rem; color: #555; }
```
```javascript
console.log('CSS Reset telah diterapkan');
console.log('Body margin:', window.getComputedStyle(document.body).margin);
```

## Cara Integrasi
1. Buat file `css/reset.css`
2. Tulis CSS reset di file tersebut
3. Link reset.css SEBELUM style.css di HTML
4. Urutan penting: `reset.css` dulu, baru `style.css`
5. Alternatif: gunakan CDN normalize.css atau reses modern
