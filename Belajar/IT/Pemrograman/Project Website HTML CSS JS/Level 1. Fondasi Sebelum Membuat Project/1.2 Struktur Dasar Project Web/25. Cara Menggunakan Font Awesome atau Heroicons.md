# 25. Cara Menggunakan Font Awesome atau Heroicons

## Definisi & Target
Font Awesome dan Heroicons adalah library ikon berbasis SVG/font yang bisa diintegrasikan ke project web untuk menambahkan ikon tanpa file gambar terpisah.

## Analogi Alur
Library ikon seperti stempel koleksi stiker. Alih-alih menggambar stiker satu per satu (membuat file gambar), Anda cukup memilih stiker dari koleksi dan menstempelnya di tempat yang diinginkan.

## Poin-Poin Penting
- Ikon berupa font/SVG, bisa diubah ukuran dan warna via CSS
- Font Awesome: library ikon terpopuler (ribuan ikon)
- Heroicons: ikon dari pembuat Tailwind CSS, style modern
- Integrasi via CDN atau instalasi package
- Gunakan tag `<i>` atau `<span>` dengan class yang sesuai

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Icon Library Demo</title>
  <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.0/css/all.min.css">
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <div class="icon-demo">
    <h2>Font Awesome Icons</h2>
    <div class="icon-list">
      <span><i class="fas fa-home"></i> Home</span>
      <span><i class="fas fa-user"></i> User</span>
      <span><i class="fas fa-envelope"></i> Email</span>
      <span><i class="fas fa-cog"></i> Settings</span>
      <span><i class="fas fa-trash" style="color: #e74c3c;"></i> Delete</span>
      <span><i class="fas fa-star" style="color: #f1c40f;"></i> Star</span>
    </div>
    <h2>Ikon dengan Ukuran Berbeda</h2>
    <div class="icon-sizes">
      <i class="fas fa-phone fa-xs"></i>
      <i class="fas fa-phone fa-sm"></i>
      <i class="fas fa-phone fa-lg"></i>
      <i class="fas fa-phone fa-2x"></i>
      <i class="fas fa-phone fa-3x"></i>
    </div>
  </div>
</body>
</html>
```
```css
body { font-family: Arial, sans-serif; display: flex; justify-content: center; align-items: center; min-height: 100vh; margin: 0; background: #f5f5f5; }
.icon-demo { background: white; padding: 40px; border-radius: 12px; box-shadow: 0 4px 20px rgba(0,0,0,0.1); }
.icon-list { display: flex; flex-direction: column; gap: 12px; font-size: 18px; }
.icon-list span { display: flex; align-items: center; gap: 10px; }
.icon-sizes { display: flex; align-items: center; gap: 16px; margin-top: 10px; }
```

## Cara Integrasi
1. Untuk Font Awesome: tambahkan CDN di `<head>`:
   `<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.0/css/all.min.css">`
2. Gunakan `<i class="fas fa-nama-ikon"></i>` di HTML
3. Untuk Heroicons: kunjungi https://heroicons.com, copy SVG langsung
4. Ikon bisa di-style dengan CSS (color, font-size untuk FA)
