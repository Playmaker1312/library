# 27. Cara Membuat File CSS Utama dengan Custom Properties

## Definisi & Target
File CSS utama (`style.css`) adalah file styling utama project. Custom properties (CSS variables) memungkinkan penyimpanan nilai reusable seperti warna, font, dan spacing.

## Analogi Alur
CSS custom properties seperti papan pengumuman pusat di kantor. Jika ada informasi baru (misal: warna perusahaan berubah), cukup ganti di papan pengumuman, semua divisi otomatis tahu tanpa perlu diinfokan satu per satu.

## Poin-Poin Penting
- Custom properties didefinisikan dengan `--nama-variabel: nilai`
- Dipanggil dengan `var(--nama-variabel)`
- Biasanya didefinisikan di `:root` (global scope)
- Memudahkan theming dan maintenance
- Bisa diubah via JavaScript untuk dark mode, dll

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CSS Custom Properties</title>
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <header class="header">
    <h1>CSS Custom Properties</h1>
  </header>
  <main class="main">
    <div class="card">
      <h2>Card Title</h2>
      <p>Ini menggunakan warna, spacing, dan font dari custom properties.</p>
      <button class="btn">Tombol</button>
    </div>
    <div class="card card--secondary">
      <h2>Card Secondary</h2>
      <p>Menggunakan warna sekunder dari variabel.</p>
      <button class="btn btn--outline">Outline</button>
    </div>
  </main>
  <script src="js/script.js"></script>
</body>
</html>
```
```css
:root {
  --color-primary: #3498db;
  --color-secondary: #2ecc71;
  --color-danger: #e74c3c;
  --color-text: #2c3e50;
  --color-bg: #f8f9fa;
  --color-white: #ffffff;
  --font-heading: 'Georgia', serif;
  --font-body: 'Arial', sans-serif;
  --spacing-sm: 8px;
  --spacing-md: 16px;
  --spacing-lg: 24px;
  --spacing-xl: 48px;
  --radius: 8px;
  --shadow: 0 2px 8px rgba(0,0,0,0.1);
}
body { font-family: var(--font-body); color: var(--color-text); background: var(--color-bg); }
.header { background: var(--color-primary); color: var(--color-white); padding: var(--spacing-xl); text-align: center; }
.main { max-width: 800px; margin: var(--spacing-xl) auto; padding: 0 var(--spacing-md); display: flex; gap: var(--spacing-lg); }
.card { background: var(--color-white); padding: var(--spacing-lg); border-radius: var(--radius); box-shadow: var(--shadow); flex: 1; }
.card--secondary { border-top: 4px solid var(--color-secondary); }
.btn { background: var(--color-primary); color: var(--color-white); border: none; padding: var(--spacing-sm) var(--spacing-md); border-radius: var(--radius); cursor: pointer; }
.btn--outline { background: transparent; border: 2px solid var(--color-primary); color: var(--color-primary); }
```
```javascript
console.log('CSS Custom Properties digunakan:');
var root = document.documentElement;
var primaryColor = getComputedStyle(root).getPropertyValue('--color-primary').trim();
console.log('Primary color:', primaryColor);
```

## Cara Integrasi
1. Buat file `css/style.css`
2. Definisikan custom properties di `:root`
3. Gunakan `var(--nama-variabel)` di seluruh file CSS
4. Link file di HTML setelah reset.css
5. Untuk mengubah via JS: `document.documentElement.style.setProperty('--color-primary', 'red')`
