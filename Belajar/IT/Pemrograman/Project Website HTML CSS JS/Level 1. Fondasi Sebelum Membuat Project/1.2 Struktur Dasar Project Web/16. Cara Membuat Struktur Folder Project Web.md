# 16. Cara Membuat Struktur Folder Project Web

## Definisi & Target
Struktur folder project web yang terorganisir memudahkan navigasi, pemeliharaan, dan kolaborasi. Target: mampu membuat hirarki folder standar untuk project website.

## Analogi Alur
Struktur folder seperti rak buku di perpustakaan. Setiap kategori punya rak sendiri: fiksi (CSS), non-fiksi (JS), referensi (images), dll. Pengunjung (developer) bisa langsung menemukan buku yang dicari.

## Poin-Poin Penting
- Folder utama project adalah root directory
- Sub-folder memisahkan file berdasarkan fungsi
- Konsistensi penamaan penting untuk skala project
- Struktur bisa berbeda tergantung kebutuhan (sederhana vs kompleks)
- Hindari menaruh semua file di root folder

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```
project-website/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
│   └── logo.png
├── fonts/
│   └── custom-font.woff2
├── assets/
│   ├── icons/
│   ├── videos/
│   └── documents/
└── .vscode/
    └── settings.json
```

## Cara Integrasi
1. Buat folder utama project (contoh: `project-website/`)
2. Di dalamnya, buat folder: `css/`, `js/`, `images/`, `fonts/`, `assets/`
3. Buat file `index.html` di root
4. Buat file `style.css` di dalam `css/`
5. Buat file `script.js` di dalam `js/`
6. Folder `.vscode/` otomatis dibuat VS Code untuk workspace settings
