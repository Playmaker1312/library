# 23. Cara Mengatur Meta Description dan Meta Keywords untuk SEO

## Definisi & Target
Meta description dan meta keywords adalah tag HTML yang memberikan informasi tentang halaman ke mesin pencari (Google, Bing, dll) untuk SEO (Search Engine Optimization).

## Analogi Alur
Meta description seperti cuplikan film di trailer - memberi gambaran singkat tentang isi film agar orang tertarik menonton. Meta keywords adalah genre film yang membantu penonton menemukan film yang sesuai.

## Poin-Poin Penting
- Meta description muncul di hasil pencarian Google sebagai cuplikan
- Meta keywords sudah kurang penting untuk Google, tapi masih dipakai mesin pencari lain
- Setiap halaman harus punya meta description unik
- Panjang ideal description: 150-160 karakter
- Meta tags ditempatkan di dalam `<head>`

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Belajar HTML Dasar - Tutorial Web</title>
  <meta name="description" content="Belajar HTML dasar untuk pemula. Tutorial lengkap struktur HTML5, tag, dan cara membuat website dari nol.">
  <meta name="keywords" content="HTML, tutorial HTML, belajar HTML, HTML dasar, website, pemrograman web">
  <meta name="author" content="Nama Anda">
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <article>
    <h1>Belajar HTML Dasar</h1>
    <p>Halaman ini memiliki meta description yang optimal untuk SEO.</p>
    <p>Lihat hasilnya dengan inspect element > tab Elements > cari tag meta.</p>
  </article>
  <script src="js/script.js"></script>
</body>
</html>
```
```css
body { font-family: 'Segoe UI', sans-serif; max-width: 800px; margin: 50px auto; padding: 20px; line-height: 1.8; color: #333; }
h1 { color: #2c3e50; border-bottom: 2px solid #3498db; padding-bottom: 10px; }
article { background: #f8f9fa; padding: 30px; border-radius: 8px; }
```
```javascript
console.log('Meta tags SEO telah diterapkan');
console.log('Description:', document.querySelector('meta[name="description"]').getAttribute('content'));
```

## Cara Integrasi
1. Tentukan deskripsi unik untuk setiap halaman (max 160 karakter)
2. Tambahkan `<meta name="description" content="...">` di `<head>`
3. Tambahkan `<meta name="keywords" content="...">` (opsional, pisahkan dengan koma)
4. Gunakan Google Search Console untuk memonitor performa SEO
5. Pastikan title tag juga informatif dan mengandung kata kunci
