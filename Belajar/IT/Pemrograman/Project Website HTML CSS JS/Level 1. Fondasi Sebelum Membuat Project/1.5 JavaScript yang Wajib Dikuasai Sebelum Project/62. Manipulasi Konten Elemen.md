# 62. Memahami Manipulasi Konten Elemen

## Definisi & Target
`innerHTML` dan `textContent` adalah properti untuk membaca atau mengubah konten elemen HTML. `innerHTML` memproses HTML, `textContent` hanya teks.

## Analogi Alur
innerHTML seperti pengolah kata yang bisa memformat teks (tebal, miring, list). textContent seperti notepad biasa - hanya teks mentah tanpa format.

## Poin-Poin Penting
- `element.textContent`: mengambil/mengatur teks saja (HTML escaped)
- `element.innerHTML`: mengambil/mengatur HTML (termasuk tag HTML)
- `innerHTML` bisa berbahaya jika berisi input user (XSS vulnerability)
- `textContent` lebih aman dan lebih cepat
- `element.innerText`: mirip textContent tapi memperhitungkan CSS (lebih lambat)
- `element.outerHTML`: termasuk elemen itu sendiri

```javascript
var display = document.getElementById('displayArea');
var input = document.getElementById('userInput');
var info = document.getElementById('infoPanel');

document.getElementById('btnTextContent').addEventListener('click', function() {
  var val = input.value;
  display.textContent = val;
  info.textContent = 'textContent: HTML tidak diproses -> "' + display.textContent + '"';
});

document.getElementById('btnInnerHTML').addEventListener('click', function() {
  var val = input.value;
  display.innerHTML = val;
  info.innerHTML = '<span style="color:#27ae60;">innerHTML:</span> HTML diproses -> ' + display.innerHTML;
});

document.getElementById('btnGetContent').addEventListener('click', function() {
  info.textContent = 'textContent: "' + display.textContent + '" | innerHTML: "' + display.innerHTML + '"';
});

document.getElementById('btnAppend').addEventListener('click', function() {
  display.innerHTML += ' <span style="color:#e74c3c;">[ditambahkan]</span>';
  info.textContent = 'HTML diappend: ' + display.innerHTML;
});

document.getElementById('btnClear').addEventListener('click', function() {
  display.textContent = '';
  info.textContent = 'Display dikosongkan';
});
```

## Cara Integrasi
1. Gunakan `textContent` untuk mengubah teks saja (aman, cepat)
2. Gunakan `innerHTML` hanya jika benar-benar perlu menyisipkan HTML
3. Jangan gunakan `innerHTML` dengan input user tanpa sanitasi
4. Gunakan `textContent` untuk membaca teks dari elemen
5. Hindari `innerHTML` dalam loop - lebih lambat dari manipulasi DOM langsung
