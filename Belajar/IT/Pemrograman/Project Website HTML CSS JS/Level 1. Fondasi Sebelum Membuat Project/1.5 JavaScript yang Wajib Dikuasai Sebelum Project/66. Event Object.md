# 66. Memahami Event Object

## Definisi & Target
Event object (parameter `e` atau `event`) berisi informasi detail tentang event yang terjadi, termasuk `target` (elemen yang memicu event), `preventDefault()` (mencegah perilaku default), dan `stopPropagation()` (menghentikan bubbling).

## Analogi Alur
Event object seperti laporan polisi tentang insiden. Laporan mencatat: di mana kejadian (target), jenis kejadian (type), koordinat (clientX/Y), dan bisa mencegah dampak lebih lanjut (preventDefault) atau menghentikan penyebaran berita (stopPropagation).

## Poin-Poin Penting
- `e.target`: elemen yang memicu event (bukan elemen yang mendengarkan)
- `e.currentTarget`: elemen tempat event listener dipasang
- `e.preventDefault()`: mencegah aksi default (misal: submit form, link navigasi)
- `e.stopPropagation()`: menghentikan event bubbling ke parent
- `e.type`: jenis event ('click', 'keydown', dll)
- `e.clientX` / `e.clientY`: posisi mouse relatif ke viewport
- `e.key`: key yang ditekan (untuk keyboard events)
- `e.code`: kode fisik tombol keyboard

```javascript
var eLog = document.getElementById('eventObjLog');

function logEvent(msg) {
  eLog.textContent = msg;
}

document.getElementById('parent').addEventListener('click', function(e) {
  logEvent('parent: target=' + e.target.id + ', currentTarget=' + e.currentTarget.id + ', type=' + e.type);
});

document.getElementById('child').addEventListener('click', function(e) {
  logEvent('child: target=' + e.target.id + ', currentTarget=' + e.currentTarget.id);
});

document.getElementById('linkPrevent').addEventListener('click', function(e) {
  e.preventDefault();
  logEvent('preventDefault: Link tidak jadi navigasi');
});

document.getElementById('formPrevent').addEventListener('submit', function(e) {
  e.preventDefault();
  logEvent('preventDefault: Form tidak jadi submit');
});

document.getElementById('infoArea').addEventListener('mousemove', function(e) {
  document.getElementById('mouseX').textContent = e.clientX;
  document.getElementById('mouseY').textContent = e.clientY;
  document.getElementById('eventType').textContent = e.type;
});

document.getElementById('infoArea').addEventListener('keydown', function(e) {
  document.getElementById('keyPressed').textContent = e.key + ' (' + e.code + ')';
  document.getElementById('eventType').textContent = e.type;
});

document.getElementById('infoArea').setAttribute('tabindex', '0');
```

## Cara Integrasi
1. Gunakan `e.preventDefault()` untuk mencegah navigasi link atau submit form
2. Gunakan `e.target` untuk tahu elemen mana yang diklik (berguna dalam event delegation)
3. Gunakan `e.clientX/Y` untuk posisi mouse (tooltip, drag, custom cursor)
4. Gunakan `e.key` untuk shortcut keyboard
5. Gunakan `e.stopPropagation()` dengan hati-hati - hanya jika benar perlu
