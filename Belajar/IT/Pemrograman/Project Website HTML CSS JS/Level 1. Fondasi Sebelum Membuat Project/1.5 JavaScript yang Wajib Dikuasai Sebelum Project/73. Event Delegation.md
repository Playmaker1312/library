# 73. Memahami Event Delegation

## Definisi & Target
Event delegation adalah teknik menangani event dengan menempatkan satu event listener pada parent element untuk menangani event dari child elements, termasuk yang ditambahkan secara dinamis.

## Analogi Alur
Event delegation seperti resepsionis di gedung perkantoran. Alih-alih setiap ruangan punya bel sendiri, semua tamu cukup lapor ke resepsionis (parent). Resepsionis yang akan mengarahkan ke ruangan yang tepat (e.target).

## Poin-Poin Penting
- Memanfaatkan event bubbling: event dari child naik ke parent
- Cukup satu event listener untuk banyak elemen
- Event listener tetap bekerja untuk elemen yang ditambahkan setelah listener dipasang
- Gunakan `e.target` untuk mengidentifikasi elemen mana yang memicu event
- Gunakan `e.target.closest('.class')` untuk mencari elemen spesifik
- Lebih efisien memory (tidak perlu listener per elemen)
- Sangat berguna untuk list, tabel, grid, dan konten dinamis

```javascript
var productList = document.getElementById('productList');
var log = document.getElementById('delegationLog');
var nextId = 4;

productList.addEventListener('click', function(e) {
  var target = e.target;

  if (target.classList.contains('btn-buy')) {
    var item = target.closest('.product-item');
    var name = item.querySelector('.product-name').textContent;
    var price = item.querySelector('.product-price').textContent;
    log.textContent = 'Membeli: ' + name + ' seharga ' + price;
  }

  else if (target.classList.contains('btn-delete-item')) {
    var item = target.closest('.product-item');
    var name = item.querySelector('.product-name').textContent;
    item.remove();
    log.textContent = name + ' dihapus dari daftar';
  }

  else if (target.classList.contains('product-item') || target.closest('.product-item')) {
    var item = target.closest('.product-item');
    var id = item.getAttribute('data-id');
    var name = item.querySelector('.product-name').textContent;
    log.textContent = 'Item diklik: ' + name + ' (ID: ' + id + ')';
  }
});

document.getElementById('btnAddProduct').addEventListener('click', function() {
  var products = [
    { name: 'Monitor', price: 'Rp15.000' },
    { name: 'Printer', price: 'Rp20.000' },
    { name: 'Webcam', price: 'Rp8.000' }
  ];
  var p = products[nextId % products.length];
  var li = document.createElement('li');
  li.className = 'product-item';
  li.setAttribute('data-id', nextId);
  li.setAttribute('data-price', nextId * 1000);
  li.innerHTML = '<span class="product-name">' + p.name + ' (baru)</span>' +
    '<span class="product-price">' + p.price + '</span>' +
    '<button class="btn-buy">Beli</button>' +
    '<button class="btn-delete-item">Hapus</button>';
  productList.appendChild(li);
  log.textContent = 'Produk baru ditambahkan: ' + p.name;
  nextId++;
});

document.getElementById('btnClearProducts').addEventListener('click', function() {
  productList.innerHTML = '';
  log.textContent = 'Semua produk dihapus. Tambah produk baru untuk demo delegasi.';
});
```

## Cara Integrasi
1. Tempatkan satu event listener pada parent element (ul, div, tbody)
2. Gunakan `e.target` untuk identifikasi elemen yang diklik
3. Gunakan `e.target.closest('.item-class')` untuk mencari item container
4. Gunakan `classList.contains` atau `matches()` untuk filter jenis aksi
5. Event delegation bekerja otomatis untuk elemen yang ditambahkan secara dinamis
