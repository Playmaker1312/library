# 65. Memahami Cara Menangani Event dengan addEventListener

## Definisi & Target
`addEventListener` adalah metode untuk mendaftarkan event handler pada elemen DOM. Event seperti klik, mouseover, keydown, submit, dan banyak lagi.

## Analogi Alur
addEventListener seperti memasang sensor di pintu. Saat pintu terbuka (event terjadi), sensor mengirim sinyal dan lampu otomatis menyala (fungsi handler dijalankan). Anda bisa pasang banyak sensor di pintu yang sama.

## Poin-Poin Penting
- `element.addEventListener('event', handler)`: mendaftarkan event
- `element.removeEventListener('event', handler)`: menghapus event
- Event umum: 'click', 'mouseover', 'mouseout', 'keydown', 'keyup', 'submit', 'load', 'scroll', 'resize', 'input', 'change', 'focus', 'blur'
- Handler bisa fungsi bernama atau anonymous function
- Satu elemen bisa punya banyak event listener untuk event yang sama
- Lebih baik dari `onclick`, `onmouseover` karena bisa multiple
- Event bubbling: event naik dari child ke parent

```javascript
var log = document.getElementById('logMessages');
var count = 0;

function addLog(msg) {
  count++;
  var entry = document.createElement('div');
  entry.textContent = count + '. ' + msg;
  log.appendChild(entry);
  log.parentElement.scrollTop = log.parentElement.scrollHeight;
}

document.getElementById('btnClick').addEventListener('click', function() {
  addLog('Click: tombol "Klik Saya" diklik');
});

document.getElementById('btnDoubleClick').addEventListener('dblclick', function() {
  addLog('Double Click: tombol didouble-klik');
});

document.getElementById('btnHover').addEventListener('mouseover', function() {
  addLog('Mouseover: mouse masuk ke tombol Hover');
});
document.getElementById('btnHover').addEventListener('mouseout', function() {
  addLog('Mouseout: mouse keluar dari tombol Hover');
});

document.getElementById('textInput').addEventListener('keydown', function(e) {
  addLog('Keydown: tombol "' + e.key + '" ditekan');
});
document.getElementById('textInput').addEventListener('input', function() {
  addLog('Input: nilai berubah menjadi "' + this.value + '"');
});
document.getElementById('textInput').addEventListener('focus', function() {
  addLog('Focus: input menerima fokus');
});
document.getElementById('textInput').addEventListener('blur', function() {
  addLog('Blur: input kehilangan fokus');
});

document.getElementById('selectDemo').addEventListener('change', function() {
  addLog('Change: select berubah menjadi "' + this.value + '"');
});

document.getElementById('mouseArea').addEventListener('mousemove', function(e) {
  document.getElementById('coordX').textContent = e.offsetX;
  document.getElementById('coordY').textContent = e.offsetY;
});

document.getElementById('btnClearLog').addEventListener('click', function() {
  log.innerHTML = '';
  count = 0;
  addLog('Log dibersihkan');
});

addLog('Event listeners siap!');
```

## Cara Integrasi
1. Gunakan `addEventListener` untuk semua event (bukan `onclick` di HTML)
2. Event 'click' untuk tombol, 'submit' untuk form, 'input' untuk text field realtime
3. Event 'keydown' untuk shortcut keyboard, 'scroll' untuk infinite scroll
4. Event 'mouseover'/'mouseout' untuk tooltip dan hover effects
5. Gunakan fungsi bernama jika event handler perlu di-remove dengan `removeEventListener`
