# 63. Memahami Manipulasi Class dengan classList

## Definisi & Target
`classList` adalah properti yang menyediakan metode untuk mengelola class CSS pada elemen: `add`, `remove`, `toggle`, `contains` - lebih praktis daripada mengubah className string.

## Analogi Alur
classList seperti lemari pakaian dengan sistem organizer. `add` menambahkan baju baru, `remove` mengeluarkan baju, `toggle` mengganti baju (jika pakai A jadi B, jika B jadi A), `contains` mengecek apakah baju tertentu ada di lemari.

## Poin-Poin Penting
- `element.classList.add('class')`: menambah class
- `element.classList.remove('class')`: menghapus class
- `element.classList.toggle('class')`: jika ada, hapus; jika tidak ada, tambah
- `element.classList.contains('class')`: cek apakah class ada (return boolean)
- `element.classList.replace('old', 'new')`: mengganti class
- Multiple class: `.add('class1', 'class2')`
- Tidak perlu khawatir spasi atau duplikat class

```javascript
var box = document.getElementById('targetBox');
var currentClass = document.getElementById('currentClass');

function updateClassDisplay() {
  currentClass.textContent = box.className || '(no classes)';
}

document.getElementById('btnAdd').addEventListener('click', function() {
  box.classList.add('active');
  updateClassDisplay();
});

document.getElementById('btnRemove').addEventListener('click', function() {
  box.classList.remove('active');
  updateClassDisplay();
});

document.getElementById('btnToggle').addEventListener('click', function() {
  box.classList.toggle('active');
  updateClassDisplay();
});

document.getElementById('btnContains').addEventListener('click', function() {
  var hasActive = box.classList.contains('active');
  var msg = hasActive ? 'YA, class "active" ada' : 'TIDAK, class "active" tidak ada';
  alert(msg);
});

document.getElementById('btnAddError').addEventListener('click', function() {
  box.classList.remove('success');
  box.classList.add('error');
  updateClassDisplay();
});

document.getElementById('btnReplace').addEventListener('click', function() {
  if (box.classList.contains('error')) {
    box.classList.replace('error', 'success');
  }
  updateClassDisplay();
});

document.getElementById('btnReset').addEventListener('click', function() {
  box.className = 'box-init';
  updateClassDisplay();
});

updateClassDisplay();
```

## Cara Integrasi
1. Gunakan `classList.add()` untuk menambahkan class (misal: menampilkan modal)
2. Gunakan `classList.remove()` untuk menghapus class (menyembunyikan elemen)
3. Gunakan `classList.toggle()` untuk toggle dark mode, menu aktif, dll.
4. Gunakan `classList.contains()` untuk pengecekan sebelum aksi
5. classList lebih bersih daripada string manipulation className
