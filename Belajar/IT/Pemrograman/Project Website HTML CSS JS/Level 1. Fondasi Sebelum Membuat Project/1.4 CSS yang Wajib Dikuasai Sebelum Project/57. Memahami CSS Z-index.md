# 57. Memahami CSS Z-index dan Stacking Context

## Definisi & Target
`z-index` mengontrol tumpukan (stacking order) elemen yang saling tumpang tindih. Stacking context adalah grup elemen yang membentuk konteks tumpukan independen.

## Analogi Alur
z-index seperti lantai gedung bertingkat. Elemen dengan z-index 1 ada di lantai 1, z-index 10 di lantai 10. Tapi dalam gedung berbeda (stacking context berbeda), lantai 1 gedung A bisa berada di atas lantai 10 gedung B.

## Poin-Poin Penting
- `z-index` hanya bekerja pada elemen dengan position non-static
- Nilai: angka (negatif, 0, positif), auto (default = 0)
- Semakin besar angka, semakin "di depan"
- Stacking context baru dibuat oleh: position + z-index, opacity < 1, transform, filter, dll
- Dua elemen dari stacking context berbeda tidak bisa dibandingkan z-index-nya
- Jika parent A z-index 1 dan parent B z-index 2, child A tetap di belakang meskipun child A punya z-index 999

```javascript
document.getElementById('btnShowOverlay').addEventListener('click', function() {
  document.getElementById('overlay').style.display = 'flex';
```

## Cara Integrasi
1. Atur `position: relative` dan `z-index` pada elemen yang perlu ditumpuk
2. Nilai z-index yang lebih tinggi tampil di depan
3. Untuk modal/overlay: gunakan z-index tinggi (9999) dan posisi fixed
4. Hindari z-index sangat besar - atur stacking secara hierarkis
5. Sadari bahwa opacity, transform, filter membuat stacking context baru
