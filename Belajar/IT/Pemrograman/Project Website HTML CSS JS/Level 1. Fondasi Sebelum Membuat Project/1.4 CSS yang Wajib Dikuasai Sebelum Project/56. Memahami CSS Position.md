# 56. Memahami CSS Position

## Definisi & Target
Properti `position` mengontrol bagaimana elemen diposisikan dalam dokumen. Nilai: `static` (default), `relative`, `absolute`, `fixed`, `sticky`.

## Analogi Alur
- `static`: seperti kursi di barisan - tidak bisa digeser dari posisi default
- `relative`: seperti kursi yang bisa digeser sedikit dari tempat aslinya
- `absolute`: seperti poster yang ditempel di dinding - posisi relatif terhadap ruangan terdekat yang punya "relative"
- `fixed`: seperti logo yang selalu terlihat di pojok layar - tidak peduli halaman di-scroll
- `sticky`: seperti stiker yang awalnya di posisi normal, tapi "menempel" saat discroll melewatinya

## Poin-Poin Penting
- `static`: default, tidak bisa diatur top/left/right/bottom
- `relative`: posisi relatif terhadap posisi asli, masih dalam flow dokumen
- `absolute`: keluar dari flow dokumen, posisi relatif ke ancestor terdekat yang tidak static
- `fixed`: keluar dari flow, posisi relatif ke viewport
- `sticky`: campuran relative dan fixed, menempel saat scroll mencapai threshold
- `top`, `right`, `bottom`, `left`: offset positioning
- `z-index`: mengatur tumpukan (stacking order)
- `position: absolute` membutuhkan parent `position: relative` sebagai acuan

## Cara Integrasi
1. Gunakan `position: relative` pada parent untuk anchor `absolute` child
2. Gunakan `position: absolute` untuk overlay, badge, tooltip
3. Gunakan `position: fixed` untuk navbar, back-to-top, floating action button
4. Gunakan `position: sticky` untuk table headers atau section headers yang menempel
5. Selalu atur `top/right/bottom/left` saat menggunakan non-static position
