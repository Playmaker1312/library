# 49. Memahami Media Queries untuk Responsive Design

## Definisi & Target
Media queries adalah fitur CSS yang menerapkan style berbeda berdasarkan kondisi tertentu, terutama ukuran layar (viewport), untuk menciptakan responsive design.

## Analogi Alur
Media queries seperti pakaian yang bisa menyesuaikan ukuran tubuh. Di tubuh besar (desktop), baju longgar (layout grid). Di tubuh kecil (mobile), baju menyempit (layout stack). Satu baju (satu kode) untuk semua ukuran.

## Poin-Poin Penting
- Sintaks: `@media (condition) { CSS rules }`
- `min-width`: ketika layar lebih dari nilai tertentu (mobile-first)
- `max-width`: ketika layar kurang dari nilai tertentu (desktop-first)
- Breakpoint umum: 480px (mobile), 768px (tablet), 1024px (desktop), 1200px (wide)
- Mobile-first: mulai dari style dasar mobile, lalu `min-width` untuk layar lebih besar
- Bisa juga untuk print, prefers-color-scheme (dark mode), prefers-reduced-motion

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Media Queries Demo</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <div class="page">
    <header class="page-header">
      <h1>Responsive Design</h1>
      <nav class="nav">
        <a href="#">Home</a>
        <a href="#">About</a>
        <a href="#">Services</a>
        <a href="#">Contact</a>
      </nav>
    </header>
    <main class="page-main">
      <section class="content-section">
        <h2>Konten Utama</h2>
        <p>Resize browser untuk melihat perubahan layout. Media queries membuat halaman ini responsif di semua ukuran layar.</p>
      </section>
      <aside class="content-sidebar">
        <h3>Sidebar</h3>
        <p>Sidebar akan pindah ke bawah di layar kecil.</p>
      </aside>
    </main>
    <div class="card-grid">
      <div class="card">Card 1</div>
      <div class="card">Card 2</div>
      <div class="card">Card 3</div>
      <div class="card">Card 4</div>
      <div class="card">Card 5</div>
      <div class="card">Card 6</div>
    </div>
    <footer class="page-footer">
      <p>&copy; 2024 Responsive Demo</p>
    </footer>
  </div>
</body>
</html>
```
```css
body { font-family: Arial, sans-serif; margin: 0; padding: 20px; background: #f5f6fa; }
.page { max-width: 1200px; margin: 0 auto; background: white; padding: 20px; border-radius: 12px; }
.page-header { display: flex; justify-content: space-between; align-items: center; flex-wrap: wrap; gap: 10px; }
.nav { display: flex; gap: 16px; }
.nav a { text-decoration: none; color: #3498db; }
.page-main { display: flex; gap: 20px; margin: 20px 0; }
.content-section { flex: 2; }
.content-sidebar { flex: 1; background: #f8f9fa; padding: 20px; border-radius: 8px; }
.card-grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 16px; margin: 20px 0; }
.card { background: #3498db; color: white; padding: 40px; text-align: center; border-radius: 8px; font-weight: bold; }
@media (max-width: 768px) {
  .page-main { flex-direction: column; }
  .card-grid { grid-template-columns: repeat(2, 1fr); }
  .page-header { flex-direction: column; text-align: center; }
}
@media (max-width: 480px) {
  .card-grid { grid-template-columns: 1fr; }
  .nav { flex-direction: column; align-items: center; }
}
```

## Cara Integrasi
1. Tentukan breakpoint berdasarkan konten (bukan perangkat)
2. Gunakan mobile-first dengan `min-width` untuk progressive enhancement
3. Uji di berbagai ukuran dengan DevTools (ikon smartphone)
4. Jangan hanya untuk lebar - pertimbangkan orientasi, resolusi, dan preferensi
5. Mulai dengan layout mobile sederhana, tambah kompleksitas untuk layar besar
