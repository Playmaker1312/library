# 58. Memahami CSS Overflow

## Definisi & Target
Properti `overflow` mengontrol perilaku konten yang melebihi ukuran container. Nilai: `hidden`, `auto`, `scroll`, `visible` (default).

## Analogi Alur
Overflow seperti gelas yang kelebihan air. `visible` membiarkan air tumpah ke meja. `hidden` menahan air dalam gelas (kelebihan air hilang). `scroll` memberi sedotan tambahan (scrollbar) untuk menyerap kelebihan. `auto` otomatis menyediakan scrollbar jika perlu.

## Poin-Poin Penting
- `visible` (default): konten keluar dari container
- `hidden`: konten terpotong, scrollbar tidak ada
- `scroll`: selalu tampilkan scrollbar (horizontal dan vertikal)
- `auto`: scrollbar muncul hanya jika konten overflow
- `overflow-x` dan `overflow-y` untuk kontrol per sumbu
- `text-overflow: ellipsis` untuk teks overflow (harus dengan `overflow: hidden` dan `white-space: nowrap`)
- `overflow: hidden` juga membuat stacking context baru

```css
body { font-family: Arial, sans-serif; background: #f5f6fa; margin: 0; padding: 20px; }

.ov-scroll { overflow: scroll; }

.ov-ellipsis { overflow: hidden; }

.ov-xy { overflow-x: auto; overflow-y: hidden; white-space: nowrap; }
```

## Cara Integrasi
1. Gunakan `overflow: hidden` untuk konten yang harus dipotong (card, slider)
2. Gunakan `overflow: auto` untuk container yang perlu scroll konten
3. Gunakan `overflow: scroll` untuk panel chat, log, atau area yang selalu perlu scroll
4. Gunakan `text-overflow: ellipsis` untuk teks yang dipotong dengan "..."
5. Hati-hati: `overflow: hidden` bisa memotong konten yang tidak diinginkan
