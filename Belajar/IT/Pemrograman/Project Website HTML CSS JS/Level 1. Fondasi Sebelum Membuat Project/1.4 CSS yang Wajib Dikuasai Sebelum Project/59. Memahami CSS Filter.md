# 59. Memahami CSS Filter

## Definisi & Target
CSS Filter menerapkan efek grafis seperti blur, brightness, contrast, grayscale, dan drop-shadow pada elemen, mirip filter di aplikasi editing foto.

## Analogi Alur
CSS Filter seperti lensa kamera dengan efek built-in. Anda bisa memburamkan (blur), mencerahkan (brightness), meningkatkan kontras (contrast), menghitam-putihkan (grayscale), atau menambah bayangan (drop-shadow) tanpa mengedit gambar asli.

## Poin-Poin Penting
- `blur(px)`: efek kabur
- `brightness(%)`: kecerahan (0% = hitam, 100% = normal, >100% = lebih terang)
- `contrast(%)`: kontras
- `grayscale(%)`: hitam putih (0% = warna, 100% = grayscale)
- `sepia(%)`: efek sepia
- `hue-rotate(deg)`: rotasi warna
- `drop-shadow(x, y, blur, color)`: bayangan (mirip box-shadow tapi ikut bentuk elemen)
- Multiple filter: `filter: brightness(1.2) contrast(1.1) blur(2px)`
- `backdrop-filter`: filter pada latar belakang di belakang elemen

## Cara Integrasi
1. Gunakan `filter: grayscale(1)` untuk efek hover pada gambar hitam-putih
2. Gunakan `filter: brightness(0.7)` untuk gambar di latar gelap
3. Gunakan `filter: blur(px)` untuk efek modal background (backdrop-filter)
4. Gunakan `drop-shadow` untuk bayangan yang mengikuti bentuk elemen
5. Gabungkan multiple filter dan animasikan dengan transition
