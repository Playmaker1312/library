# 51. Memahami CSS Pseudo-class

## Definisi & Target
Pseudo-class adalah keyword CSS yang ditambahkan ke selector untuk menargetkan elemen berdasarkan keadaan atau posisinya, seperti `:hover`, `:focus`, `:active`, `:nth-child`, `:first-child`, `:last-child`.

## Analogi Alur
Pseudo-class seperti pengamat yang melihat kondisi suatu benda. Misal: tombol yang disentuh (hover), tombol yang sedang ditekan (active), anak pertama dalam keluarga (first-child), atau anak nomor genap (nth-child even).

## Poin-Poin Penting
- `:hover`: saat mouse di atas elemen
- `:focus`: saat elemen menerima fokus (input, link)
- `:active`: saat elemen sedang diklik
- `:visited`: link yang sudah dikunjungi
- `:nth-child(n)`: anak ke-n dari parent
- `:first-child`: anak pertama
- `:last-child`: anak terakhir
- `:not(selector)`: negasi
- `:empty`: elemen tanpa child
- `:disabled`, `:checked`: untuk form elements

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Pseudo-class Demo</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <div class="pseudo-demo">
    <h1>CSS Pseudo-class</h1>

    <h2>:hover, :focus, :active</h2>
    <div class="interactive-demo">
      <button class="pseudo-btn">Hover & Click Saya</button>
      <input type="text" class="pseudo-input" placeholder="Focus saya" value="">
      <a href="#" class="pseudo-link">Link example</a>
    </div>

    <h2>:first-child, :last-child, :nth-child</h2>
    <ul class="list-demo">
      <li>Item 1 (first-child)</li>
      <li>Item 2</li>
      <li>Item 3</li>
      <li>Item 4</li>
      <li>Item 5 (last-child)</li>
    </ul>

    <h2>:nth-child(even) - genap</h2>
    <ul class="list-striped">
      <li>Baris 1</li>
      <li>Baris 2</li>
      <li>Baris 3</li>
      <li>Baris 4</li>
      <li>Baris 5</li>
      <li>Baris 6</li>
    </ul>

    <h2>:not() dan :empty</h2>
    <div class="not-demo">
      <span class="tag">HTML</span>
      <span class="tag">CSS</span>
      <span class="tag highlight">JS</span>
      <span class="tag">Python</span>
      <div class="empty-box"></div>
      <div class="empty-box">Isi</div>
    </div>
  </div>
</body>
</html>
```
```css
body { font-family: Arial, sans-serif; background: #f5f6fa; margin: 0; padding: 20px; }
```

## Cara Integrasi
1. Gunakan `:hover` untuk interaksi mouse (tombol, link, card)
2. Gunakan `:focus` untuk aksesibilitas keyboard
3. Gunakan `:nth-child(odd/even)` untuk zebra striping tabel/list
4. Gunakan `:first-child` / `:last-child` untuk margin/spacing khusus
5. Gunakan `:not()` untuk mengecualikan elemen tertentu dari styling
