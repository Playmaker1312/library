# 46. Memahami Box Model

## Definisi & Target
Box Model adalah konsep fundamental CSS yang mendefinisikan bagaimana setiap elemen HTML dirender sebagai kotak, terdiri dari: content, padding, border, dan margin.

## Analogi Alur
Box model seperti bingkai foto di dinding. Content adalah foto, padding adalah bantalan kertas di sekeliling foto dalam bingkai, border adalah bingkai fotonya, margin adalah jarak dari bingkai ke foto lain atau ke dinding.

## Poin-Poin Penting
- Content: area konten (teks, gambar)
- Padding: ruang dalam antara konten dan border (transparan)
- Border: garis di sekeliling padding
- Margin: ruang luar di sekeliling border (transparan)
- `box-sizing: border-box`: membuat width/height termasuk padding dan border
- Total lebar = content + padding + border + margin
- Gunakan browser DevTools untuk melihat box model visual

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Box Model Demo</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <div class="box-model-demo">
    <h1>CSS Box Model</h1>
    <div class="box" id="box1">
      <span class="label">Content</span>
    </div>
    <div class="info">
      <p>Total lebar: 300px (content 200px + padding 20px*2 + border 5px*2 + margin 25px*2)</p>
      <p>Inspect elemen ini di DevTools &gt; Computed &gt; Box Model</p>
    </div>
    <div class="box-comparison">
      <div class="box box-content-box">
        <span>content-box</span>
      </div>
      <div class="box box-border-box">
        <span>border-box</span>
      </div>
    </div>
  </div>
</body>
</html>
```
```css
body { font-family: Arial, sans-serif; background: #f5f6fa; display: flex; justify-content: center; align-items: center; min-height: 100vh; margin: 0; }
.box-model-demo { background: white; padding: 40px; border-radius: 12px; box-shadow: 0 4px 20px rgba(0,0,0,0.1); text-align: center; }
.box { width: 200px; height: 200px; margin: 25px auto; padding: 20px; border: 5px solid #e74c3c; background: #3498db; color: white; display: flex; align-items: center; justify-content: center; font-weight: bold; }
.label { background: rgba(0,0,0,0.3); padding: 8px 16px; border-radius: 4px; }
.info { background: #f0f8ff; padding: 15px 20px; border-radius: 8px; margin: 20px 0; text-align: left; font-size: 14px; color: #555; }
.box-comparison { display: flex; gap: 30px; justify-content: center; margin-top: 30px; }
.box-content-box { box-sizing: content-box; width: 200px; background: #e74c3c; margin: 10px; }
.box-border-box { box-sizing: border-box; width: 200px; background: #27ae60; margin: 10px; }
.box-content-box span, .box-border-box span { background: rgba(0,0,0,0.3); padding: 8px; border-radius: 4px; font-size: 12px; }
```

## Cara Integrasi
1. Pahami bahwa total lebar elemen = content + padding + border + margin
2. Set `box-sizing: border-box` di CSS reset untuk memudahkan perhitungan
3. Gunakan DevTools untuk visualisasi Box Model (tab Computed)
4. Padding untuk ruang internal, margin untuk jarak antar elemen
5. Border untuk garis batas yang terlihat
