# 52. Memahami CSS Pseudo-element

## Definisi & Target
Pseudo-element menargetkan bagian spesifik dari elemen, seperti `::before` (sebelum konten), `::after` (setelah konten), `::placeholder` (teks placeholder), `::selection` (teks yang dipilih).

## Analogi Alur
Pseudo-element seperti stiker atau catatan tempel yang ditempel di barang. `::before` adalah stiker di bagian depan buku, `::after` stiker di bagian belakang. `::placeholder` adalah tulisan samar di kolom isian sebelum diisi.

## Poin-Poin Penting
- `::before` dan `::after`: menyisipkan konten sebelum/sesudah elemen (via `content`)
- `::placeholder`: styling teks placeholder di input
- `::selection`: styling teks yang di-highlight user
- `::first-letter`: huruf pertama
- `::first-line`: baris pertama
- Wajib properti `content` untuk `::before` dan `::after` (bisa empty string "")
- Pseudo-element untuk dekorasi, bukan konten penting

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Pseudo-element Demo</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <div class="pe-demo">
    <h1>CSS Pseudo-element</h1>

    <h2>::before dan ::after</h2>
    <div class="icon-list">
      <p class="with-icon">Baca dokumentasi</p>
      <p class="with-icon">Tulis kode</p>
      <p class="with-icon with-icon-after">Testing</p>
    </div>

    <h2>::before untuk dekorasi</h2>
    <div class="decorative-cards">
      <div class="deco-card">Tips: Gunakan CSS variables</div>
      <div class="deco-card warning">Warning: Jangan lupa testing</div>
    </div>

    <h2>::placeholder</h2>
    <div>
      <input type="text" class="custom-placeholder" placeholder="Masukkan nama Anda...">
      <input type="email" class="custom-placeholder" placeholder="email@example.com">
    </div>

    <h2>::selection</h2>
    <p class="selection-demo">Coba select / highlight teks ini. Warna background dan text akan berubah saat diseleksi.</p>

    <h2>::first-letter dan ::first-line</h2>
    <p class="first-letter-demo">Ini adalah contoh penggunaan first-letter. Huruf pertama akan tampil lebih besar. Ini adalah baris pertama yang akan di-style oleh first-line.</p>
  </div>
</body>
</html>
```

## Cara Integrasi
1. Gunakan `::before` dan `::after` untuk ikon dekoratif, badge, atau garis
2. Selalu set properti `content` (bisa `""` untuk dekorasi visual)
3. Gunakan `::placeholder` untuk styling teks placeholder di form
4. Gunakan `::selection` untuk branding konsisten saat teks di-highlight
5. Jangan gunakan pseudo-element untuk konten penting (tidak diakses screen reader)
