# 176. Merencanakan Struktur Portfolio dengan Section Hero, About, Skills, Projects, dan Contact

## Definisi & Target
Portfolio website menampilkan karya dan profil personal. Target: Rencana struktur dengan section: Hero, About, Skills, Projects, Contact.

## Analogi Alur
Seperti portofolio fisik seorang desainer — berisi sampul (hero), biodata (about), keahlian (skills), karya (projects), dan kontak.

## Poin-Poin Penting
- Hero: perkenalan singkat dan CTA
- About: foto, bio, informasi personal
- Skills: daftar keahlian dengan progress bar
- Projects: gallery karya dengan filter
- Contact: form kontak dan informasi

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html

<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Portfolio - Struktur</title>

      a.addEventListener('click', e => {
        e.preventDefault();
        const target = document.querySelector(a.getAttribute('href'));
```

## Cara Integrasi
Gunakan struktur ini sebagai kerangka portfolio. Setiap section akan dikembangkan secara detail di poin-poin berikutnya. Pastikan smooth scrolling antar section.
