# 180. Membangun Section About dengan Foto Profil, Bio, dan Informasi Personal

## Definisi & Target
About section berisi informasi personal. Target: Layout dengan foto profil, bio singkat, dan data personal.

## Analogi Alur
Seperti halaman biodata di buku tahunan — berisi foto, cerita singkat, dan informasi penting tentang seseorang.

## Poin-Poin Penting
- Foto profil (lingkaran) sebagai elemen visual utama
- Bio: cerita singkat tentang diri, pengalaman, minat
- Informasi: nama, lokasi, email, status
- Tombol download CV
