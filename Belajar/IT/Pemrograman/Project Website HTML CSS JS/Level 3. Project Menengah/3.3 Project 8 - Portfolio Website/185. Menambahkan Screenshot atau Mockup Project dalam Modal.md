# 185. Menambahkan Screenshot atau Mockup Project dalam Modal

## Definisi & Target
Menampilkan screenshot atau mockup project di dalam modal detail. Target: Gambar preview project dalam modal.

## Analogi Alur
Seperti melihat contoh jadi di katalog — selain deskripsi, Anda bisa melihat foto asli produk.

## Poin-Poin Penting
- Gambar preview di bagian atas modal
- Bisa menggunakan screenshot asli atau placeholder
- Tambahkan caption atau label pada gambar
- Layout gambar + deskripsi seimbang

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Project Modal with Screenshot</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f8fafc; }
    .container { max-width: 1100px; margin: 0 auto; padding: 60px 20px; text-align: center; }
    .container h2 { color: #1e293b; margin-bottom: 30px; }
    .grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 20px; }
    .card { background: #fff; padding: 30px; border-radius: 12px; border: 1px solid #e2e8f0; cursor: pointer; transition: all 0.3s; }
    .card:hover { transform: translateY(-4px); box-shadow: 0 12px 24px rgba(0,0,0,0.1); }
    .card .icon { font-size: 36px; margin-bottom: 10px; }
    .card h3 { color: #1e293b; }
    .overlay { display: none; position: fixed; inset: 0; background: rgba(0,0,0,0.6); z-index: 1000; align-items: center; justify-content: center; padding: 20px; }
    .overlay.active { display: flex; }
    .modal { background: #fff; border-radius: 20px; max-width: 700px; width: 100%; animation: in 0.3s; overflow: hidden; }
    @keyframes in { from { transform: scale(0.9); opacity: 0; } to { transform: scale(1); opacity: 1; } }
    .modal-img { width: 100%; height: 300px; object-fit: cover; display: block; }
    .modal-img-placeholder { width: 100%; height: 300px; display: flex; align-items: center; justify-content: center; font-size: 64px; }
    .modal-body { padding: 30px; position: relative; }
    .modal-body .close { position: absolute; top: -50px; right: 16px; background: rgba(0,0,0,0.5); color: #fff; border: none; width: 36px; height: 36px; border-radius: 50%; font-size: 20px; cursor: pointer; }
    .modal-body h2 { margin-bottom: 12px; color: #1e293b; }
    .modal-body p { color: #64748b; line-height: 1.7; margin-bottom: 16px; }
    .modal-body .tech { display: flex; gap: 8px; flex-wrap: wrap; margin-bottom: 16px; }
    .modal-body .tech span { padding: 4px 14px; background: #f5f3ff; color: #7c3aed; border-radius: 50px; font-size: 13px; }
    .btn { display: inline-block; padding: 12px 28px; background: #7c3aed; color: #fff; border-radius: 8px; text-decoration: none; }
  </style>
</head>
<body>
  <div class="container">
    <h2>Klik Project untuk Detail</h2>
    <div class="grid">
      <div class="card" onclick="openProject(1)"><div class="icon">🛒</div><h3>E-Commerce App</h3></div>
      <div class="card" onclick="openProject(2)"><div class="icon">📱</div><h3>Task Manager</h3></div>
      <div class="card" onclick="openProject(3)"><div class="icon">🎨</div><h3>Portfolio Design</h3></div>
    </div>
  </div>
  <div class="overlay" id="overlay" onclick="if(event.target===this)closeModal()">
    <div class="modal">
      <div id="modalImage" class="modal-img-placeholder" style="background:#7c3aed;color:#fff;">🛒</div>
      <div class="modal-body">
        <button class="close" onclick="closeModal()">×</button>
        <h2 id="modalTitle">Project Title</h2>
        <p id="modalDesc">Description</p>
        <div class="tech" id="modalTech"></div>
        <a href="#" class="btn">Kunjungi Project</a>
      </div>
    </div>
  </div>
  <script>
    const projects = {
      1: { icon: '🛒', title: 'E-Commerce App', desc: 'Platform e-commerce dengan fitur lengkap: keranjang belanja, checkout, payment gateway, dan dashboard admin. Dibangun dengan arsitektur modern.', tech: ['React', 'Node.js', 'MongoDB'], bg: '#7c3aed' },
      2: { icon: '📱', title: 'Task Manager', desc: 'Aplikasi manajemen tugas dengan kolaborasi real-time, drag-and-drop, dan notifikasi push. Digunakan oleh 500+ tim.', tech: ['React Native', 'Firebase', 'Redux'], bg: '#2563eb' },
      3: { icon: '🎨', title: 'Portfolio Design', desc: 'Desain portfolio modern dengan fokus pada pengalaman pengguna. Menerapkan prinsip desain minimalis dan tipografi yang bersih.', tech: ['Figma', 'Illustrator'], bg: '#059669' }
    };
    function openProject(id) {
      const p = projects[id];
      if (!p) return;
      document.getElementById('modalImage').textContent = p.icon;
      document.getElementById('modalImage').style.background = p.bg;
      document.getElementById('modalTitle').textContent = p.title;
      document.getElementById('modalDesc').textContent = p.desc;
      document.getElementById('modalTech').innerHTML = p.tech.map(t => `<span>${t}</span>`).join('');
      document.getElementById('overlay').classList.add('active');
      document.body.style.overflow = 'hidden';
    }
    function closeModal() {
      document.getElementById('overlay').classList.remove('active');
      document.body.style.overflow = '';
    }
    document.addEventListener('keydown', e => { if (e.key === 'Escape') closeModal(); });
  </script>
</body>
</html>
```

## Cara Integrasi
Ganti placeholder dengan screenshot asli project menggunakan tag `<img>`. Gunakan gambar dengan rasio 16:9 atau 4:3. Pastikan gambar dioptimasi (lazy loading, ukuran kecil).
