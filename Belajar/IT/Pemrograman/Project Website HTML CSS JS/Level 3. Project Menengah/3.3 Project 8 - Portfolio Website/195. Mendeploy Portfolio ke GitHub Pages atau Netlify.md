# 195. Mendeploy Portfolio ke GitHub Pages atau Netlify

## Definisi & Target
Deployment membuat portfolio online dan bisa diakses publik. Target: Mendeploy portfolio statis ke GitHub Pages atau Netlify.

## Analogi Alur
Seperti membuka toko — setelah semua barang (kode) siap, toko (website) harus dibuka agar orang bisa datang (mengakses).

## Poin-Poin Penting
- GitHub Pages: gratis, integrasi dengan GitHub repo
- Netlify: drag-and-drop deploy, form handling, HTTPS
- Pastikan semua path relatif (bukan absolute)
- Siapkan file `index.html` di root
