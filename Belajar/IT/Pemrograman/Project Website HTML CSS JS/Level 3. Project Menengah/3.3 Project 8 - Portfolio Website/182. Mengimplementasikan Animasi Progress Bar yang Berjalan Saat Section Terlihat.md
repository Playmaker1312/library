# 182. Mengimplementasikan Animasi Progress Bar yang Berjalan Saat Section Terlihat

## Definisi & Target
Progress bar terisi saat memasuki viewport. Target: Animasi progress bar dipicu oleh Intersection Observer.

## Analogi Alur
Seperti musik yang mulai dimainkan saat pintu dibuka — progress bar mulai "bermain" (terisi) saat pengguna melihat section skills.

## Poin-Poin Penting
- Intersection Observer memonitor visibilitas section
- Saat terlihat, progress bar terisi dari 0% ke target
- Reset animasi jika diperlukan
- Threshold dan root margin untuk timing

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Animated Skills</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; }
    .spacer { height: 100vh; display: flex; align-items: center; justify-content: center; background: #f8fafc; color: #94a3b8; font-size: 20px; }
    .skills-section { padding: 80px 20px; max-width: 700px; margin: 0 auto; }
    .skills-section h2 { text-align: center; font-size: 32px; color: #1e293b; margin-bottom: 40px; }
    .skill { margin-bottom: 24px; }
    .skill .header { display: flex; justify-content: space-between; margin-bottom: 8px; }
    .skill .header .name { font-weight: 600; color: #1e293b; }
    .skill .header .pct { color: #7c3aed; font-weight: 700; }
    .bar { width: 100%; height: 12px; background: #e2e8f0; border-radius: 6px; overflow: hidden; }
    .bar .fill { height: 100%; border-radius: 6px; width: 0%; transition: width 1s ease; }
    .bar .fill.purple { background: linear-gradient(90deg, #7c3aed, #a78bfa); }
    .bar .fill.blue { background: linear-gradient(90deg, #2563eb, #60a5fa); }
    .bar .fill.amber { background: linear-gradient(90deg, #f59e0b, #fbbf24); }
    .bar .fill.emerald { background: linear-gradient(90deg, #10b981, #34d399); }
    .bar .fill.red { background: linear-gradient(90deg, #ef4444, #f87171); }
    .bar .fill.cyan { background: linear-gradient(90deg, #06b6d4, #22d3ee); }
    .stats { text-align: center; margin-top: 40px; padding: 20px; background: #f5f3ff; border-radius: 12px; }
    .stats p { color: #7c3aed; font-weight: 500; }
  </style>
</head>
<body>
  <div class="spacer">Scroll ke bawah untuk melihat animasi progress bar ⬇</div>
  <section class="skills-section" id="skillsSection">
    <h2>Technical Skills</h2>
    <div class="skill"><div class="header"><span class="name">HTML & CSS</span><span class="pct">95%</span></div><div class="bar"><div class="fill purple" data-target="95"></div></div></div>
    <div class="skill"><div class="header"><span class="name">JavaScript</span><span class="pct">90%</span></div><div class="bar"><div class="fill blue" data-target="90"></div></div></div>
    <div class="skill"><div class="header"><span class="name">React</span><span class="pct">85%</span></div><div class="bar"><div class="fill cyan" data-target="85"></div></div></div>
    <div class="skill"><div class="header"><span class="name">Node.js</span><span class="pct">80%</span></div><div class="bar"><div class="fill emerald" data-target="80"></div></div></div>
    <div class="skill"><div class="header"><span class="name">Git</span><span class="pct">90%</span></div><div class="bar"><div class="fill red" data-target="90"></div></div></div>
    <div class="stats" id="status"><p>⏳ Scroll ke section skills untuk melihat animasi</p></div>
  </section>
  <script>
    function animateBars() {
      document.querySelectorAll('.fill').forEach(bar => {
        bar.style.width = bar.dataset.target + '%';
      });
      document.getElementById('status').innerHTML = '<p>✅ Animasi progress bar selesai!</p>';
    }
    const observer = new IntersectionObserver((entries) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          animateBars();
          observer.unobserve(entry.target);
        }
      });
    }, { threshold: 0.3 });
    observer.observe(document.getElementById('skillsSection'));
  </script>
</body>
</html>
```

## Cara Integrasi
Gunakan Intersection Observer dengan threshold 0.3 (30% section terlihat). Saat observer terpicu, semua progress bar diisi sesuai target. Unobserve setelah animasi untuk performa.
