# 177. Mendefinisikan Personal Branding yaitu Warna, Font, dan Gaya Visual yang Konsisten

## Definisi & Target
Personal branding adalah identitas visual yang konsisten. Target: Mendefinisikan color palette, typography, dan design system untuk portfolio.

## Analogi Alur
Seperti seragam atau seragam sekolah — warna dan gaya yang konsisten membuat orang langsung mengenali brand Anda.

## Poin-Poin Penting
- Pilih 2-3 warna utama (primary, secondary, accent)
- Tentukan font heading dan body
- Konsisten dengan spacing, border-radius, shadow
- Terapkan di semua elemen portfolio
