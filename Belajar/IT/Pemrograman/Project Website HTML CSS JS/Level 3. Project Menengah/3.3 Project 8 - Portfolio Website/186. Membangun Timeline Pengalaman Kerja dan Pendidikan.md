# 186. Membangun Timeline Pengalaman Kerja dan Pendidikan

## Definisi & Target
Timeline menampilkan riwayat karir dan pendidikan secara kronologis. Target: Vertical timeline dengan titik, tanggal, dan deskripsi.

## Analogi Alur
Seperti garis waktu sejarah — setiap peristiwa (pengalaman) ditempatkan di posisi kronologisnya dengan deskripsi singkat.

## Poin-Poin Penting
- Layout vertical dengan garis di tengah atau kiri
- Setiap entry: tahun, judul, institusi, deskripsi
- Bergantian posisi kiri-kanan (desktop)
- Semua di kiri (mobile)
