# 189. Menambahkan Particle Effect atau Animated Background di Hero Section

## Definisi & Target
Particle effect adalah animasi titik-titik bergerak di background. Target: Canvas particle system yang hidup di hero section.

## Analogi Alur
Seperti bintang-bintang yang berkelap-kelip di langit malam — partikel bergerak memberikan kesan hidup dan dinamis.

## Poin-Poin Penting
- Gunakan HTML5 Canvas untuk particle system
- Partikel bergerak dengan kecepatan dan arah acak
- Tambahkan efek koneksi antar partikel (opsional)
- Jangan mengganggu konten utama (low opacity)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Particle Effect Hero</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; }
    .hero { position: relative; min-height: 100vh; display: flex; align-items: center; justify-content: center; background: #0f172a; overflow: hidden; }
    #particleCanvas { position: absolute; inset: 0; width: 100%; height: 100%; }
    .content { position: relative; z-index: 2; text-align: center; color: #fff; padding: 20px; }
    .content h1 { font-size: clamp(36px, 6vw, 56px); font-weight: 800; margin-bottom: 16px; }
    .content h1 span { color: #a78bfa; }
    .content p { font-size: clamp(16px, 2vw, 20px); color: rgba(255,255,255,0.7); max-width: 600px; margin: 0 auto 30px; }
    .btn { display: inline-block; padding: 16px 36px; background: #7c3aed; color: #fff; border-radius: 50px; text-decoration: none; font-weight: 600; transition: all 0.3s; }
    .btn:hover { background: #6d28d9; transform: translateY(-3px); box-shadow: 0 8px 30px rgba(124,58,237,0.4); }
  </style>
</head>
<body>
  <section class="hero">
    <canvas id="particleCanvas"></canvas>
    <div class="content">
      <h1>Halo, Saya <span>John Doe</span></h1>
      <p>Full-Stack Developer yang bersemangat menciptakan solusi digital inovatif.</p>
      <a href="#" class="btn">Lihat Karya Saya</a>
    </div>
  </section>
  <script>
    const canvas = document.getElementById('particleCanvas');
    const ctx = canvas.getContext('2d');
    let particles = [];
    function resize() {
      canvas.width = canvas.parentElement.offsetWidth;
      canvas.height = canvas.parentElement.offsetHeight;
    }
    resize();
    window.addEventListener('resize', resize);
    class Particle {
      constructor() { this.reset(); }
      reset() {
        this.x = Math.random() * canvas.width;
        this.y = Math.random() * canvas.height;
        this.size = Math.random() * 3 + 1;
        this.speedX = (Math.random() - 0.5) * 0.8;
        this.speedY = (Math.random() - 0.5) * 0.8;
        this.opacity = Math.random() * 0.5 + 0.1;
      }
      update() {
        this.x += this.speedX;
        this.y += this.speedY;
        if (this.x < 0 || this.x > canvas.width || this.y < 0 || this.y > canvas.height) this.reset();
      }
      draw() {
        ctx.beginPath();
        ctx.arc(this.x, this.y, this.size, 0, Math.PI * 2);
        ctx.fillStyle = `rgba(167, 139, 250, ${this.opacity})`;
        ctx.fill();
      }
    }
    const particleCount = 100;
    for (let i = 0; i < particleCount; i++) particles.push(new Particle());
    function animate() {
      ctx.clearRect(0, 0, canvas.width, canvas.height);
      particles.forEach(p => { p.update(); p.draw(); });
      for (let i = 0; i < particles.length; i++) {
        for (let j = i + 1; j < particles.length; j++) {
          const dx = particles[i].x - particles[j].x;
          const dy = particles[i].y - particles[j].y;
          const dist = Math.sqrt(dx * dx + dy * dy);
          if (dist < 120) {
            ctx.beginPath();
            ctx.moveTo(particles[i].x, particles[i].y);
            ctx.lineTo(particles[j].x, particles[j].y);
            ctx.strokeStyle = `rgba(167, 139, 250, ${0.08 * (1 - dist / 120)})`;
            ctx.stroke();
          }
        }
      }
      requestAnimationFrame(animate);
    }
    animate();
  </script>
</body>
</html>
```

## Cara Integrasi
Tambahkan canvas di hero section dengan z-index rendah. Partikel bergerak di background tanpa mengganggu konten. Sesuaikan warna partikel dengan brand color.
