# 187. Membangun Section Testimonial atau Rekomendasi

## Definisi & Target
Testimonial menampilkan rekomendasi dari kolega atau klien. Target: Card testimonial dengan foto, nama, jabatan, dan kutipan.

## Analogi Alur
Seperti surat rekomendasi — orang lain menceritakan pengalaman mereka bekerja dengan Anda.

## Poin-Poin Penting
- Foto atau avatar kolega
- Nama, jabatan, perusahaan
- Kutipan testimonial
- Bisa menggunakan grid atau carousel
