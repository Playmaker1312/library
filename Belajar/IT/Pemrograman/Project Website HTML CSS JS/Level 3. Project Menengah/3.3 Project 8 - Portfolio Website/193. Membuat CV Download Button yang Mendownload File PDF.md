# 193. Membuat CV Download Button yang Mendownload File PDF

## Definisi & Target
Tombol download CV (PDF) untuk pengunjung mengunduh resume. Target: Button yang memicu download file PDF.

## Analogi Alur
Seperti mengambil brosur dari rak — satu klik, dan CV Anda langsung "diambil" (download) oleh pengunjung.

## Poin-Poin Penting
- Gunakan anchor tag dengan atribut `download`
- File PDF statis atau generate dengan library
- Tampilkan ukuran file untuk transparansi
- Tracking download events (opsional)
