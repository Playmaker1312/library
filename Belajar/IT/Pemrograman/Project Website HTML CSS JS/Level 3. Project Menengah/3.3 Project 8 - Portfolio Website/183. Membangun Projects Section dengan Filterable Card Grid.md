# 183. Membangun Projects Section dengan Filterable Card Grid

## Definisi & Target
Projects section menampilkan karya dengan filter kategori. Target: Grid card project yang bisa difilter berdasarkan kategori.

## Analogi Alur
Seperti galeri seni dengan label — pengunjung bisa memilih melihat semua lukisan atau hanya kategori tertentu (cat air, minyak, digital).

## Poin-Poin Penting
- Card project: thumbnail, judul, deskripsi, kategori, link
- Filter button: All, Web App, Mobile, Design
- Animasi transisi saat filter berubah
- Bisa diklik untuk melihat detail project

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Projects Portfolio</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f8fafc; }
    .projects { max-width: 1100px; margin: 0 auto; padding: 80px 20px; }
    .projects h2 { text-align: center; font-size: 36px; color: #1e293b; margin-bottom: 8px; }
    .projects > p { text-align: center; color: #64748b; margin-bottom: 30px; }
    .filter-bar { display: flex; gap: 10px; justify-content: center; flex-wrap: wrap; margin-bottom: 40px; }
    .filter-btn { padding: 10px 24px; border: 2px solid #e2e8f0; background: #fff; border-radius: 50px; cursor: pointer; font-size: 14px; font-weight: 500; color: #64748b; transition: all 0.2s; }
    .filter-btn:hover { border-color: #7c3aed; color: #7c3aed; }
    .filter-btn.active { background: #7c3aed; color: #fff; border-color: #7c3aed; }
    .project-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(300px, 1fr)); gap: 24px; }
    .project-card { background: #fff; border-radius: 16px; overflow: hidden; box-shadow: 0 4px 6px -1px rgba(0,0,0,0.05); transition: all 0.3s; border: 1px solid #e2e8f0; }
    .project-card:hover { transform: translateY(-6px); box-shadow: 0 12px 30px rgba(0,0,0,0.1); }
    .project-card .thumb { height: 200px; display: flex; align-items: center; justify-content: center; font-size: 48px; }
    .project-card .body { padding: 24px; }
    .project-card .body .cat { display: inline-block; padding: 4px 12px; background: #f5f3ff; color: #7c3aed; border-radius: 50px; font-size: 12px; font-weight: 600; margin-bottom: 10px; }
    .project-card .body h3 { font-size: 18px; color: #1e293b; margin-bottom: 8px; }
    .project-card .body p { color: #64748b; font-size: 14px; line-height: 1.6; margin-bottom: 16px; }
    .project-card .body .links { display: flex; gap: 12px; }
    .project-card .body .links a { color: #7c3aed; text-decoration: none; font-size: 14px; font-weight: 500; }
    .project-card .body .links a:hover { text-decoration: underline; }
  </style>
</head>
<body>
  <section class="projects">
    <h2>Project Saya</h2>
    <p>Karya yang telah saya buat selama perjalanan karir.</p>
    <div class="filter-bar" id="filterBar"></div>
    <div class="project-grid" id="projectGrid"></div>
  </section>
  <script>
    const projects = [
      { id: 1, title: 'E-Commerce Website', category: 'Web App', desc: 'Platform belanja online dengan fitur lengkap.', thumb: '🛒', thumbBg: '#f5f3ff' },
      { id: 2, title: 'Task Management App', category: 'Mobile', desc: 'Aplikasi manajemen tugas untuk produktivitas.', thumb: '📱', thumbBg: '#eff6ff' },
      { id: 3, title: 'Brand Identity Design', category: 'Design', desc: 'Desain identitas merek untuk startup teknologi.', thumb: '🎨', thumbBg: '#fef3c7' },
      { id: 4, title: 'Dashboard Admin', category: 'Web App', desc: 'Dashboard analitik dengan visualisasi data.', thumb: '📊', thumbBg: '#f3e8ff' },
      { id: 5, title: 'Fitness Tracker', category: 'Mobile', desc: 'Aplikasi pelacak kebugaran dan olahraga.', thumb: '🏃', thumbBg: '#ecfdf5' },
      { id: 6, title: 'Portfolio Website', category: 'Design', desc: 'Website portofolio dengan desain modern.', thumb: '💼', thumbBg: '#fce7f3' }
    ];
    const categories = ['Semua', ...new Set(projects.map(p => p.category))];
    let activeFilter = 'Semua';
    function renderProjects() {
      const filtered = activeFilter === 'Semua' ? projects : projects.filter(p => p.category === activeFilter);
      document.getElementById('projectGrid').innerHTML = filtered.map(p => `<div class="project-card"><div class="thumb" style="background:${p.thumbBg}">${p.thumb}</div><div class="body"><span class="cat">${p.category}</span><h3>${p.title}</h3><p>${p.desc}</p><div class="links"><a href="#">Live Demo</a><a href="#">Source Code</a></div></div></div>`).join('');
      document.querySelectorAll('.filter-btn').forEach(btn => btn.classList.toggle('active', btn.dataset.cat === activeFilter));
    }
    categories.forEach(cat => {
      const btn = document.createElement('button');
      btn.className = `filter-btn${cat === 'Semua' ? ' active' : ''}`;
      btn.dataset.cat = cat;
      btn.textContent = cat;
      btn.addEventListener('click', () => { activeFilter = cat; renderProjects(); });
      document.getElementById('filterBar').appendChild(btn);
    });
    renderProjects();
  </script>
</body>
</html>
```

## Cara Integrasi
Projects section ditempatkan setelah skills. Gunakan kategori yang sesuai dengan jenis project. Filter menggunakan class aktif untuk menandai kategori yang dipilih.
