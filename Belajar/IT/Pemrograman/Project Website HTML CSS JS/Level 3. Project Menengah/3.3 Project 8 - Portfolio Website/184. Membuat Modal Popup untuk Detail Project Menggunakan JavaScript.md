# 184. Membuat Modal Popup untuk Detail Project Menggunakan JavaScript

## Definisi & Target
Modal popup menampilkan detail project saat card diklik. Target: Overlay modal dengan informasi lengkap project.

## Analogi Alur
Seperti membuka kotak hadiah — ketika card project diklik, sebuah "kotak" (modal) terbuka menampilkan isi detail project.

## Poin-Poin Penting
- Modal muncul di atas halaman dengan overlay gelap
- Konten: judul, deskripsi lengkap, gambar, teknologi, link
- Tombol close (×) dan klik di luar modal untuk menutup
- Animasi masuk/keluar modal

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Project Modal</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f8fafc; }
    .container { max-width: 1100px; margin: 0 auto; padding: 60px 20px; }
    h2 { text-align: center; margin-bottom: 40px; color: #1e293b; }
    .grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(300px, 1fr)); gap: 24px; }
    .card { background: #fff; border-radius: 12px; padding: 30px; border: 1px solid #e2e8f0; text-align: center; cursor: pointer; transition: all 0.3s; }
    .card:hover { transform: translateY(-4px); box-shadow: 0 12px 24px rgba(0,0,0,0.1); }
    .card .icon { font-size: 40px; margin-bottom: 12px; }
    .card h3 { color: #1e293b; margin-bottom: 8px; }
    .card p { color: #64748b; font-size: 14px; }
    .modal-overlay { display: none; position: fixed; inset: 0; background: rgba(0,0,0,0.6); z-index: 1000; align-items: center; justify-content: center; padding: 20px; }
    .modal-overlay.active { display: flex; }
    .modal { background: #fff; border-radius: 20px; max-width: 600px; width: 100%; padding: 40px; position: relative; animation: modalIn 0.3s; }
    @keyframes modalIn { from { transform: scale(0.9); opacity: 0; } to { transform: scale(1); opacity: 1; } }
    .modal .close { position: absolute; top: 16px; right: 20px; font-size: 28px; background: none; border: none; cursor: pointer; color: #94a3b8; }
    .modal .close:hover { color: #1e293b; }
    .modal .icon-big { font-size: 64px; text-align: center; margin-bottom: 16px; }
    .modal h2 { color: #1e293b; margin-bottom: 12px; }
    .modal .desc { color: #64748b; line-height: 1.7; margin-bottom: 20px; font-size: 15px; }
    .modal .tech { display: flex; gap: 8px; flex-wrap: wrap; margin-bottom: 20px; }
    .modal .tech span { padding: 4px 14px; background: #f5f3ff; color: #7c3aed; border-radius: 50px; font-size: 13px; }
    .modal .btn { display: inline-block; padding: 12px 28px; background: #7c3aed; color: #fff; border-radius: 8px; text-decoration: none; }
    .modal .btn:hover { background: #6d28d9; }
  </style>
</head>
<body>
  <div class="container">
    <h2>Klik Card untuk Detail</h2>
    <div class="grid">
      <div class="card" onclick="openModal(1)"><div class="icon">🛒</div><h3>E-Commerce App</h3><p>Platform belanja dengan fitur lengkap.</p></div>
      <div class="card" onclick="openModal(2)"><div class="icon">📱</div><h3>Task Manager</h3><p>Aplikasi manajemen tugas produktif.</p></div>
      <div class="card" onclick="openModal(3)"><div class="icon">🎨</div><h3>Brand Identity</h3><p>Desain merek untuk startup.</p></div>
    </div>
  </div>
  <div class="modal-overlay" id="modalOverlay" onclick="closeModal(event)">
    <div class="modal" id="modalContent">
      <button class="close" onclick="closeModal(event)">×</button>
      <div id="modalBody"></div>
    </div>
  </div>
  <script>
    const projectData = {
      1: { icon: '🛒', title: 'E-Commerce App', desc: 'Platform e-commerce lengkap dengan fitur keranjang belanja, checkout, payment gateway, manajemen produk, dan dashboard penjualan. Dibangun menggunakan teknologi modern untuk performa optimal.', tech: ['React', 'Node.js', 'MongoDB', 'Stripe'], link: '#' },
      2: { icon: '📱', title: 'Task Manager', desc: 'Aplikasi manajemen tugas dengan fitur drag-and-drop, kolaborasi tim, deadline tracking, notifikasi, dan laporan produktivitas. Desain intuitif untuk pengalaman pengguna yang maksimal.', tech: ['React Native', 'Firebase', 'Redux'], link: '#' },
      3: { icon: '🎨', title: 'Brand Identity', desc: 'Desain identitas merek komprehensif termasuk logo, color palette, typography, business card, dan brand guidelines. Pendekatan desain yang fokus pada storytelling dan koneksi emosional.', tech: ['Figma', 'Illustrator', 'Photoshop'], link: '#' }
    };
    function openModal(id) {
      const data = projectData[id];
      if (!data) return;
      document.getElementById('modalBody').innerHTML = `<div class="icon-big">${data.icon}</div><h2>${data.title}</h2><p class="desc">${data.desc}</p><div class="tech">${data.tech.map(t => `<span>${t}</span>`).join('')}</div><a href="${data.link}" class="btn">Lihat Project</a>`;
      document.getElementById('modalOverlay').classList.add('active');
      document.body.style.overflow = 'hidden';
    }
    function closeModal(e) {
      if (e.target === document.getElementById('modalOverlay') || e.target.classList.contains('close')) {
        document.getElementById('modalOverlay').classList.remove('active');
        document.body.style.overflow = '';
      }
    }
    document.addEventListener('keydown', (e) => {
      if (e.key === 'Escape') {
        document.getElementById('modalOverlay').classList.remove('active');
        document.body.style.overflow = '';
      }
    });
  </script>
</body>
</html>
```

## Cara Integrasi
Modal dipanggil saat card project diklik. Data project detail bisa diambil dari array atau dari atribut data. Tutup modal dengan tombol X, klik overlay, atau tekan Escape.
