# 190. Mengimplementasikan Cursor Custom Menggunakan JavaScript

## Definisi & Target
Custom cursor mengganti cursor default dengan elemen kustom. Target: Lingkaran kecil yang mengikuti mouse dengan efek.

## Analogi Alur
Seperti senter di ruangan gelap — cursor kustom menjadi "senter" yang mengikuti gerakan tangan Anda.

## Poin-Poin Penting
- Sembunyikan cursor default dengan CSS `cursor: none`
- Buat elemen div yang mengikuti posisi mouse
- Tambahkan efek transisi dan animasi
- Kembalikan cursor default pada elemen interaktif (opsional)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Custom Cursor</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #0f172a; color: #fff; min-height: 100vh; cursor: none; }
    .cursor-dot { width: 8px; height: 8px; background: #a78bfa; border-radius: 50%; position: fixed; pointer-events: none; z-index: 9999; transition: transform 0.1s; }
    .cursor-ring { width: 40px; height: 40px; border: 2px solid rgba(167,139,250,0.5); border-radius: 50%; position: fixed; pointer-events: none; z-index: 9998; transition: all 0.15s ease; }
    .cursor-ring.hover { width: 60px; height: 60px; border-color: rgba(167,139,250,0.8); background: rgba(167,139,250,0.1); }
    .container { max-width: 800px; margin: 0 auto; padding: 80px 40px; }
    h1 { font-size: 48px; margin-bottom: 20px; }
    p { color: #94a3b8; line-height: 1.8; font-size: 18px; margin-bottom: 20px; }
    .btn { display: inline-block; padding: 16px 36px; background: #7c3aed; color: #fff; border: none; border-radius: 12px; font-size: 16px; font-weight: 600; cursor: none; transition: transform 0.3s; }
    .btn:hover { transform: scale(1.05); }
    .cards { display: grid; grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); gap: 20px; margin-top: 40px; }
    .card { background: #1e293b; padding: 30px; border-radius: 16px; text-align: center; cursor: none; }
    .card h3 { color: #a78bfa; margin-bottom: 8px; }
    .card p { color: #64748b; font-size: 14px; }
  </style>
</head>
<body>
  <div class="cursor-dot" id="cursorDot"></div>
  <div class="cursor-ring" id="cursorRing"></div>
  <div class="container">
    <h1>Custom Cursor Effect</h1>
    <p>Gerakkan mouse Anda — cursor default telah diganti dengan lingkaran ungu yang elegan. Kustom cursor ini memberikan kesan yang lebih modern dan interaktif pada portfolio.</p>
    <button class="btn">Hover Saya</button>
    <div class="cards">
      <div class="card"><h3>Interaktif</h3><p>Cursor merespon setiap gerakan dengan halus.</p></div>
      <div class="card"><h3>Modern</h3><p>Tampilan cursor yang unik dan memorable.</p></div>
      <div class="card"><h3>Responsif</h3><p>Besar kecil berubah saat hover elemen.</p></div>
    </div>
  </div>
  <script>
    const dot = document.getElementById('cursorDot');
    const ring = document.getElementById('cursorRing');
    let mouseX = 0, mouseY = 0;
    document.addEventListener('mousemove', (e) => {
      mouseX = e.clientX;
      mouseY = e.clientY;
      dot.style.left = mouseX - 4 + 'px';
      dot.style.top = mouseY - 4 + 'px';
      ring.style.left = mouseX - 20 + 'px';
      ring.style.top = mouseY - 20 + 'px';
    });
    document.querySelectorAll('a, button, .card, .btn').forEach(el => {
      el.addEventListener('mouseenter', () => ring.classList.add('hover'));
      el.addEventListener('mouseleave', () => ring.classList.remove('hover'));
    });
    document.addEventListener('mouseleave', () => {
      dot.style.display = 'none';
      ring.style.display = 'none';
    });
    document.addEventListener('mouseenter', () => {
      dot.style.display = 'block';
      ring.style.display = 'block';
    });
  </script>
</body>
</html>
```

## Cara Integrasi
Tambahkan dua elemen cursor (dot dan ring) di akhir `<body>`. Sembunyikan cursor default dengan CSS `cursor: none`. Tambahkan class `.hover` untuk efek saat mouse di atas elemen interaktif.
