# 194. Mengoptimasi Portfolio untuk SEO Dasar

## Definisi & Target
SEO (Search Engine Optimization) membuat portfolio mudah ditemukan di Google. Target: Menerapkan SEO on-page dasar.

## Analogi Alur
Seperti membuat papan nama yang jelas di depan toko — SEO membantu Google "membaca" dan memahami website Anda.

## Poin-Poin Penting
- Meta title dan description yang unik per halaman
- Heading hierarchy (h1, h2, h3) yang terstruktur
- Alt text pada gambar
- Semantic HTML (article, section, nav, main)
- Meta robots dan sitemap

## Cara Integrasi
Terapkan semua checklist SEO pada portfolio. Gunakan semantic HTML, unique meta tags per halaman, dan structured data untuk Google. Buat sitemap.xml dan robots.txt.
