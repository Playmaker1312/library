# 181. Membangun Skills Section dengan Animated Progress Bar

## Definisi & Target
Skills section menampilkan tingkat keahlian dengan progress bar. Target: Progress bar horizontal yang menunjukkan persentase penguasaan skill.

## Analogi Alur
Seperti pengukur bensin — semakin penuh (tinggi persentase), semakin mahir skill tersebut.

## Poin-Poin Penting
- Setiap skill memiliki nama dan persentase
- Progress bar diisi dengan warna sesuai tingkat
- Tambahkan animasi pengisian saat first load
- Gunakan grid atau list untuk tata letak

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Skills Progress Bar</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f8fafc; }
    .skills { max-width: 800px; margin: 0 auto; padding: 80px 20px; }
    .skills-header { text-align: center; margin-bottom: 50px; }
    .skills-header h2 { font-size: 36px; color: #1e293b; margin-bottom: 8px; }
    .skills-header p { color: #64748b; font-size: 18px; }
    .skills-category { margin-bottom: 40px; }
    .skills-category h3 { font-size: 20px; color: #1e293b; margin-bottom: 20px; padding-bottom: 10px; border-bottom: 2px solid #7c3aed; display: inline-block; }
    .skill-item { margin-bottom: 20px; }
    .skill-info { display: flex; justify-content: space-between; margin-bottom: 6px; }
    .skill-info .name { font-weight: 600; color: #1e293b; font-size: 15px; }
    .skill-info .percent { color: #7c3aed; font-weight: 600; }
    .progress-track { width: 100%; height: 10px; background: #e2e8f0; border-radius: 10px; overflow: hidden; }
    .progress-fill { height: 100%; border-radius: 10px; width: 0%; transition: width 0.5s ease; }
    .progress-fill.html { background: linear-gradient(90deg, #7c3aed, #a78bfa); }
    .progress-fill.css { background: linear-gradient(90deg, #3b82f6, #60a5fa); }
    .progress-fill.js { background: linear-gradient(90deg, #f59e0b, #fbbf24); }
    .progress-fill.react { background: linear-gradient(90deg, #06b6d4, #22d3ee); }
    .progress-fill.node { background: linear-gradient(90deg, #10b981, #34d399); }
    .progress-fill.git { background: linear-gradient(90deg, #ef4444, #f87171); }
  </style>
</head>
<body>
  <section class="skills">
    <div class="skills-header"><h2>Keahlian Saya</h2><p>Teknologi yang saya kuasai dalam pengembangan web.</p></div>
    <div class="skills-category">
      <h3>Frontend</h3>
      <div class="skill-item"><div class="skill-info"><span class="name">HTML & CSS</span><span class="percent">95%</span></div><div class="progress-track"><div class="progress-fill html" data-width="95"></div></div></div>
      <div class="skill-item"><div class="skill-info"><span class="name">JavaScript</span><span class="percent">90%</span></div><div class="progress-track"><div class="progress-fill js" data-width="90"></div></div></div>
      <div class="skill-item"><div class="skill-info"><span class="name">React</span><span class="percent">85%</span></div><div class="progress-track"><div class="progress-fill react" data-width="85"></div></div></div>
    </div>
    <div class="skills-category">
      <h3>Backend & Tools</h3>
      <div class="skill-item"><div class="skill-info"><span class="name">Node.js</span><span class="percent">80%</span></div><div class="progress-track"><div class="progress-fill node" data-width="80"></div></div></div>
      <div class="skill-item"><div class="skill-info"><span class="name">Git & GitHub</span><span class="percent">90%</span></div><div class="progress-track"><div class="progress-fill git" data-width="90"></div></div></div>
    </div>
  </section>
  <script>
    function animateSkills() {
      document.querySelectorAll('.progress-fill').forEach(bar => {
        const width = bar.dataset.width;
        bar.style.width = width + '%';
      });
    }
    const observer = new IntersectionObserver((entries) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          animateSkills();
          observer.unobserve(entry.target);
        }
      });
    });
    observer.observe(document.querySelector('.skills'));
  </script>
</body>
</html>
```

## Cara Integrasi
Skills section ditempatkan setelah about. Progress bar menggunakan CSS transition untuk animasi. Gunakan Intersection Observer untuk memicu animasi saat section terlihat.
