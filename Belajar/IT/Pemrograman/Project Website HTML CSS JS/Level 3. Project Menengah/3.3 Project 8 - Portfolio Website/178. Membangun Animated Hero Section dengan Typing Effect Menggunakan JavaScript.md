# 178. Membangun Animated Hero Section dengan Typing Effect Menggunakan JavaScript

## Definisi & Target
Hero section dengan animasi teks mengetik otomatis. Target: Teks yang mengetik sendiri karakter per karakter.

## Analogi Alur
Seperti mesin tik otomatis — teks muncul satu per satu seolah-olah sedang diketik langsung di depan mata.

## Poin-Poin Penting
- Tampilkan teks karakter per karakter dengan interval waktu
- Efek cursor berkedip di akhir teks
- Loop typing untuk beberapa kalimat
- Animasi transisi yang halus

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Typing Effect Hero</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: 'Segoe UI', system-ui, sans-serif; }
    .hero { min-height: 100vh; display: flex; align-items: center; justify-content: center; text-align: center; background: linear-gradient(135deg, #1e1b4b, #312e81); color: #fff; padding: 20px; position: relative; overflow: hidden; }
    .hero::before { content: ''; position: absolute; width: 500px; height: 500px; border-radius: 50%; background: radial-gradient(circle, rgba(124,58,237,0.2), transparent); top: -100px; right: -100px; }
    .hero::after { content: ''; position: absolute; width: 400px; height: 400px; border-radius: 50%; background: radial-gradient(circle, rgba(245,158,11,0.1), transparent); bottom: -150px; left: -150px; }
    .content { position: relative; z-index: 1; max-width: 700px; }
    .content h1 { font-size: clamp(32px, 6vw, 56px); font-weight: 800; margin-bottom: 16px; line-height: 1.1; }
    .content .subtitle { font-size: clamp(18px, 3vw, 24px); color: rgba(255,255,255,0.7); margin-bottom: 24px; }
    .typing-container { font-size: clamp(20px, 3vw, 28px); color: #a78bfa; font-weight: 600; min-height: 40px; margin-bottom: 30px; }
    .cursor { display: inline-block; width: 3px; height: 28px; background: #a78bfa; margin-left: 4px; animation: blink 0.7s infinite; vertical-align: middle; }
    @keyframes blink { 0%, 100% { opacity: 1; } 50% { opacity: 0; } }
    .btn { display: inline-block; padding: 16px 36px; background: #7c3aed; color: #fff; border-radius: 50px; text-decoration: none; font-weight: 600; font-size: 16px; transition: all 0.3s; }
    .btn:hover { background: #6d28d9; transform: translateY(-3px); box-shadow: 0 8px 30px rgba(124,58,237,0.4); }
    .social-links { margin-top: 30px; display: flex; gap: 16px; justify-content: center; }
    .social-links a { color: rgba(255,255,255,0.6); text-decoration: none; font-size: 14px; transition: color 0.3s; }
    .social-links a:hover { color: #fff; }
  </style>
</head>
<body>
  <section class="hero">
    <div class="content">
      <h1>Halo, Saya John Doe</h1>
      <div class="typing-container">
        <span id="typedText"></span><span class="cursor"></span>
      </div>
      <p class="subtitle">Saya membantu bisnis berkembang melalui solusi digital yang inovatif. Dengan pengalaman di berbagai teknologi modern.</p>
      <a href="#" class="btn">Lihat Project Saya</a>
      <div class="social-links">
        <a href="#">GitHub</a>
        <a href="#">LinkedIn</a>
        <a href="#">Instagram</a>
      </div>
    </div>
  </section>
  <script>
    const roles = [
      'Full-Stack Developer',
      'UI/UX Enthusiast',
      'Problem Solver',
      'Tech Innovator'
    ];
    const typedText = document.getElementById('typedText');
    let roleIndex = 0;
    let charIndex = 0;
    let isDeleting = false;
    function typeEffect() {
      const currentRole = roles[roleIndex];
      if (isDeleting) {
        typedText.textContent = currentRole.substring(0, charIndex - 1);
        charIndex--;
      } else {
        typedText.textContent = currentRole.substring(0, charIndex + 1);
        charIndex++;
      }
      if (!isDeleting && charIndex === currentRole.length) {
        setTimeout(() => isDeleting = true, 2000);
      } else if (isDeleting && charIndex === 0) {
        isDeleting = false;
        roleIndex = (roleIndex + 1) % roles.length;
      }
      const speed = isDeleting ? 50 : 100;
      setTimeout(typeEffect, speed);
    }
    typeEffect();
  </script>
</body>
</html>
```

## Cara Integrasi
Hero section adalah elemen pertama yang dilihat pengunjung. Animasi typing effect menarik perhatian dan memberikan kesan dinamis. Data roles bisa disesuaikan dengan keahlian.
