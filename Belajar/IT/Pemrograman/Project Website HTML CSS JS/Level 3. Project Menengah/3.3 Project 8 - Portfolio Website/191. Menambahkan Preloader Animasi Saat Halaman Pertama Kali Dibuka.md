# 191. Menambahkan Preloader Animasi Saat Halaman Pertama Kali Dibuka

## Definisi & Target
Preloader adalah animasi loading sebelum halaman tampil. Target: Layar loading dengan animasi yang hilang setelah konten siap.

## Analogi Alur
Seperti curtain di teater yang terbuka sebelum pertunjukan dimulai — preloader menutupi proses loading, lalu menghilang saat halaman siap.

## Poin-Poin Penting
- Preloader menutupi seluruh layar saat loading
- Animasi spinner, progress bar, atau logo animasi
- Hilang setelah `window.load` atau setelah waktu tertentu
- Transisi halus saat preloader menghilang

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Preloader Animation</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; }
    .preloader { position: fixed; inset: 0; z-index: 10000; background: #0f172a; display: flex; flex-direction: column; align-items: center; justify-content: center; transition: opacity 0.6s, visibility 0.6s; }
    .preloader.hidden { opacity: 0; visibility: hidden; }
    .preloader .logo { font-size: 48px; font-weight: 800; color: #a78bfa; margin-bottom: 20px; animation: pulse 1.5s infinite; }
    @keyframes pulse { 0%, 100% { transform: scale(1); } 50% { transform: scale(1.1); } }
    .preloader .spinner { width: 50px; height: 50px; border: 3px solid rgba(167,139,250,0.2); border-top-color: #a78bfa; border-radius: 50%; animation: spin 0.8s linear infinite; }
    @keyframes spin { to { transform: rotate(360deg); } }
    .preloader .loading-text { color: #64748b; font-size: 14px; margin-top: 20px; letter-spacing: 2px; text-transform: uppercase; }
    .preloader .progress-track { width: 200px; height: 3px; background: #1e293b; border-radius: 3px; margin-top: 16px; overflow: hidden; }
    .preloader .progress-fill { height: 100%; width: 0%; background: linear-gradient(90deg, #7c3aed, #a78bfa); border-radius: 3px; animation: loading 2s ease forwards; }
    @keyframes loading { to { width: 100%; } }
    .content { max-width: 800px; margin: 0 auto; padding: 80px 40px; }
    .content h1 { font-size: 36px; color: #1e293b; margin-bottom: 16px; }
    .content p { color: #64748b; line-height: 1.8; }
  </style>
</head>
<body>
  <div class="preloader" id="preloader">
    <div class="logo">JD</div>
    <div class="spinner"></div>
    <div class="loading-text">Loading...</div>
    <div class="progress-track"><div class="progress-fill"></div></div>
  </div>
  <div class="content">
    <h1>Halaman Portfolio</h1>
    <p>Preloader akan muncul saat pertama kali halaman dibuka. Simulasi loading ini memberikan kesan profesional dan memastikan semua aset siap sebelum ditampilkan.</p>
    <p>Preloader secara otomatis menghilang setelah halaman selesai dimuat. Animasi yang halus membuat transisi terasa alami.</p>
  </div>
  <script>
    window.addEventListener('load', () => {
      setTimeout(() => {
        document.getElementById('preloader').classList.add('hidden');
      }, 500);
    });
    setTimeout(() => {
      if (!document.getElementById('preloader').classList.contains('hidden')) {
        document.getElementById('preloader').classList.add('hidden');
      }
    }, 4000);
  </script>
</body>
</html>
```

## Cara Integrasi
Preloader ditempatkan sebagai elemen pertama di `<body>`. Class `hidden` dipicu setelah window load. Pastikan preloader tidak menghalangi interaksi setelah hilang (pointer-events: none).
