# 188. Membangun Contact Section dengan Form dan Informasi Kontak

## Definisi & Target
Contact section berisi form kontak dan informasi untuk menghubungi. Target: Layout dua kolom form dan info kontak.

## Analogi Alur
Seperti meja resepsionis — pengunjung bisa langsung berbicara (form) atau melihat papan informasi (kontak, alamat, jam kerja).

## Poin-Poin Penting
- Form: nama, email, subjek, pesan
- Info: email, lokasi, social media
- Validasi form dengan JavaScript
- Responsif: tumpuk di mobile

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Contact Portfolio</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f8fafc; }
    .contact { max-width: 1000px; margin: 0 auto; padding: 80px 20px; }
    .contact h2 { text-align: center; font-size: 36px; color: #1e293b; margin-bottom: 8px; }

    .btn { width: 100%; padding: 14px; background: #7c3aed; color: #fff; border: none; border-radius: 10px; font-size: 16px; font-weight: 600; cursor: pointer; transition: background 0.3s; }
    .btn:hover { background: #6d28d9; }

  <script>
    const form = document.getElementById('contactForm');
    form.addEventListener('submit', (e) => {
      e.preventDefault();
      let valid = true;
      const fields = [
        { id: 'name', group: 'nameGroup', validate: v => v.trim().length > 0 },
        { id: 'email', group: 'emailGroup', validate: v => /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(v) },
        { id: 'subject', group: 'subjectGroup', validate: v => v.trim().length > 0 },
        { id: 'message', group: 'messageGroup', validate: v => v.trim().length >= 10 }
      ];
      fields.forEach(({ id, group, validate }) => {
        const el = document.getElementById(id);
        const grp = document.getElementById(group);
        if (validate(el.value)) { grp.classList.remove('error'); }
        else { grp.classList.add('error'); valid = false; }
      });
      if (valid) {
        document.getElementById('successMsg').style.display = 'block';
        form.reset();
      }
    });
  </script>
```

## Cara Integrasi
Contact section ditempatkan setelah testimonial. Form dua kolom: kiri form, kanan info kontak. Validasi JavaScript sebelum submit.
