# 192. Mengimplementasikan Page Transitions yang Halus

## Definisi & Target
Page transition adalah animasi saat berpindah halaman atau section. Target: Transisi fade/slide saat navigasi antar halaman.

## Analogi Alur
Seperti fade-to-black di film — transisi yang halus antara adegan membuat pengalaman lebih sinematik.

## Poin-Poin Penting
- Gunakan CSS transitions dan animations
- Tambahkan class sebelum navigasi untuk animasi keluar
- Setelah animasi selesai, ganti konten
- Animasi masuk setelah konten baru siap

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Page Transitions</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #0f172a; color: #fff; }
    nav { position: fixed; top: 0; left: 0; right: 0; z-index: 100; padding: 20px; display: flex; justify-content: center; gap: 30px; background: rgba(15,23,42,0.9); backdrop-filter: blur(10px); }
    nav a { color: #94a3b8; text-decoration: none; font-weight: 500; cursor: pointer; transition: color 0.3s; }
    nav a:hover, nav a.active { color: #a78bfa; }
    .container { max-width: 700px; margin: 0 auto; padding: 100px 20px 60px; }
    .page { display: none; }
    .page.active { display: block; }
    .page.fade-out { animation: fadeOut 0.3s forwards; }
    .page.fade-in { animation: fadeIn 0.3s forwards; }
    @keyframes fadeOut { to { opacity: 0; transform: translateY(10px); } }
    @keyframes fadeIn { from { opacity: 0; transform: translateY(10px); } to { opacity: 1; transform: translateY(0); } }
    .transition-overlay { position: fixed; inset: 0; z-index: 99; background: #7c3aed; transform: translateX(-100%); pointer-events: none; }
    .transition-overlay.active { animation: slideOver 0.4s forwards; }
    @keyframes slideOver { 0% { transform: translateX(-100%); } 50% { transform: translateX(0); } 100% { transform: translateX(100%); } }
    .page h1 { font-size: 36px; margin-bottom: 16px; color: #a78bfa; }
    .page p { color: #94a3b8; line-height: 1.8; margin-bottom: 16px; }
    .page .badge { display: inline-block; padding: 4px 14px; background: rgba(124,58,237,0.2); color: #a78bfa; border-radius: 50px; font-size: 13px; margin-bottom: 12px; }
  </style>
</head>
<body>
  <div class="transition-overlay" id="transitionOverlay"></div>
  <nav>
    <a href="#" class="active" onclick="navigate('home')">Home</a>
    <a href="#" onclick="navigate('about')">About</a>
    <a href="#" onclick="navigate('contact')">Contact</a>
  </nav>
  <div class="container">
    <div class="page active" id="page-home">
      <div class="badge">Home</div>
      <h1>Selamat Datang</h1>
      <p>Klik navigasi di atas untuk melihat efek page transition. Setiap pergantian halaman akan dianimasi dengan overlay slide dan fade.</p>
    </div>
    <div class="page" id="page-about">
      <div class="badge">About</div>
      <h1>Tentang Saya</h1>
      <p>Saya adalah Full-Stack Developer dengan pengalaman dalam membangun aplikasi web modern. Transisi halaman ini memberikan pengalaman yang lebih premium.</p>
    </div>
    <div class="page" id="page-contact">
      <div class="badge">Contact</div>
      <h1>Hubungi Saya</h1>
      <p>Jangan ragu untuk menghubungi saya melalui email atau media sosial. Saya selalu terbuka untuk diskusi dan kolaborasi.</p>
    </div>
  </div>
  <script>
    function navigate(page) {
      const currentActive = document.querySelector('.page.active');
      const target = document.getElementById(`page-${page}`);
      if (!target || target === currentActive) return;
      const overlay = document.getElementById('transitionOverlay');
      overlay.classList.add('active');
      setTimeout(() => {
        currentActive.classList.remove('active');
        target.classList.add('active');
        document.querySelectorAll('nav a').forEach(a => a.classList.remove('active'));
        document.querySelector(`nav a[onclick*="${page}"]`).classList.add('active');
        setTimeout(() => overlay.classList.remove('active'), 200);
      }, 400);
    }
  </script>
</body>
</html>
```

## Cara Integrasi
Overlay transisi ditempatkan di antara halaman. Animasi: overlay slide masuk → ganti konten → overlay slide keluar. Durasi total sekitar 600-800ms untuk terasa halus.
