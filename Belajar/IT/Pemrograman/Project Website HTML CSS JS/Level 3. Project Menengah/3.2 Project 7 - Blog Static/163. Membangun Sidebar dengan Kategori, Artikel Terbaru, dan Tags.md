# 163. Membangun Sidebar dengan Kategori, Artikel Terbaru, dan Tags
## Definisi & Target
Sidebar blog berisi navigasi tambahan seperti daftar kategori, artikel terbaru, dan tags. Targetnya adalah membantu pengguna menemukan konten relevan dengan mudah.

## Analogi Alur
Seperti papan pengumuman di perpustakaan yang menampilkan kategori buku, buku terbaru, dan topik-topik populer.

## Poin-Poin Penting
- Widget kategori: daftar kategori dengan jumlah artikel
- Widget artikel terbaru: 5 artikel terakhir dengan link
- Widget tags: cloud tags yang bisa diklik untuk filter
- Sidebar bisa di kiri atau kanan konten utama
- Di mobile, sidebar bisa di bawah konten atau disembunyikan
- Gunakan sticky positioning untuk sidebar agar tetap terlihat
