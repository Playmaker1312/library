# 172. Membuat Related Articles Section di Halaman Detail

## Definisi & Target
Related articles menampilkan artikel lain yang relevan di halaman detail. Target: 3-4 card artikel yang terkait dengan artikel yang dibaca.

## Analogi Alur
Seperti rekomendasi "Pelanggan juga membeli" di toko online — setelah membaca artikel, pengguna disarankan artikel serupa.

## Poin-Poin Penting
- Filter artikel berdasarkan kategori yang sama
- Kecualikan artikel yang sedang dibaca
- Tampilkan 3-4 artikel terkait
- Gunakan card yang sama dengan halaman index

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Related Articles</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f8fafc; padding: 40px 20px; }
    .container { max-width: 900px; margin: 0 auto; }
    .article { background: #fff; padding: 40px; border-radius: 16px; margin-bottom: 40px; }
    .article h1 { color: #1e293b; margin-bottom: 12px; }
    .article p { color: #475569; line-height: 1.9; }
    .related { margin-top: 20px; }
    .related h2 { font-size: 22px; color: #1e293b; margin-bottom: 20px; display: flex; align-items: center; gap: 8px; }
    .related-grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); gap: 20px; }
    .related-card { background: #fff; border-radius: 12px; overflow: hidden; border: 1px solid #e2e8f0; transition: all 0.2s; cursor: pointer; }
    .related-card:hover { transform: translateY(-4px); box-shadow: 0 8px 16px rgba(0,0,0,0.08); }
    .related-card .thumb { height: 140px; display: flex; align-items: center; justify-content: center; font-size: 32px; }
    .related-card .body { padding: 16px; }
    .related-card .body .cat { font-size: 12px; color: #2563eb; font-weight: 600; }
    .related-card .body h3 { font-size: 16px; color: #1e293b; margin: 6px 0; }
    .related-card .body .date { font-size: 12px; color: #94a3b8; }
    .select-article { margin-bottom: 20px; }
    .select-article select { width: 100%; padding: 12px; border: 1px solid #e2e8f0; border-radius: 8px; font-size: 15px; }
  </style>
</head>
<body>
  <div class="container">
    <div class="select-article">
      <label style="font-weight:600;color:#1e293b;">Pilih Artikel:</label>
      <select id="articleSelect" onchange="changeArticle(this.value)" style="margin-top:6px;">
        <option value="">-- Pilih Artikel --</option>
      </select>
    </div>
    <div class="article" id="mainArticle">
      <h1>Pilih artikel untuk melihat rekomendasi</h1>
      <p>Related articles akan menampilkan artikel dengan kategori yang sama.</p>
    </div>
    <div class="related">
      <h2>📖 Artikel Terkait</h2>
      <div class="related-grid" id="relatedGrid"></div>
    </div>
  </div>
  <script>
    const articles = [
      { id: 1, title: 'Panduan Bisnis Online', category: 'Bisnis', date: '1 Jan 2026', thumb: '🚀', thumbBg: '#ecfdf5' },
      { id: 2, title: 'Cara Membuat Website', category: 'Teknologi', date: '15 Des 2025', thumb: '💻', thumbBg: '#eff6ff' },
      { id: 3, title: 'Strategi SEO Dasar', category: 'SEO', date: '20 Nov 2025', thumb: '📈', thumbBg: '#f3e8ff' },
      { id: 4, title: 'Tips Desain UI/UX', category: 'Desain', date: '10 Okt 2025', thumb: '🎨', thumbBg: '#fef3c7' },
      { id: 5, title: 'Framework JavaScript', category: 'Teknologi', date: '5 Sep 2025', thumb: '⚡', thumbBg: '#eff6ff' },
      { id: 6, title: 'Digital Marketing', category: 'Bisnis', date: '1 Agu 2025', thumb: '📊', thumbBg: '#ecfdf5' },
      { id: 7, title: 'Optimasi Kecepatan Web', category: 'Teknologi', date: '15 Jul 2025', thumb: '⚡', thumbBg: '#eff6ff' },
      { id: 8, title: 'Content Marketing', category: 'Bisnis', date: '1 Jun 2025', thumb: '📝', thumbBg: '#ecfdf5' }
    ];
    const select = document.getElementById('articleSelect');
    articles.forEach(a => {
      const opt = document.createElement('option');
      opt.value = a.id;
      opt.textContent = a.title;
      select.appendChild(opt);
    });
    function changeArticle(id) {
      if (!id) return;
      const current = articles.find(a => a.id == id);
      if (!current) return;
      document.getElementById('mainArticle').innerHTML = `<h1>${current.title}</h1><p>Anda sedang membaca artikel tentang ${current.category}. Di bawah ini adalah artikel-artikel terkait yang mungkin menarik bagi Anda.</p>`;
      const related = articles.filter(a => a.category === current.category && a.id !== current.id).slice(0, 4);
      const grid = document.getElementById('relatedGrid');
      if (related.length === 0) {
        grid.innerHTML = '<p style="color:#94a3b8;text-align:center;padding:20px;">Tidak ada artikel terkait.</p>';
      } else {
        grid.innerHTML = related.map(a => `<div class="related-card"><div class="thumb" style="background:${a.thumbBg}">${a.thumb}</div><div class="body"><span class="cat">${a.category}</span><h3>${a.title}</h3><span class="date">${a.date}</span></div></div>`).join('');
      }
    }
  </script>
</body>
</html>
```

## Cara Integrasi
Di halaman detail artikel, filter array artikel berdasarkan kategori yang sama. Kecualikan artikel yang sedang dibaca. Tampilkan maksimal 3-4 related articles.
