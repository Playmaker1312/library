# 174. Membuat Reading Progress Bar Menggunakan Scroll Event

## Definisi & Target
Progress bar menunjukkan seberapa jauh pengguna telah membaca artikel. Target: Bar horizontal di atas halaman yang terisi sesuai scroll position.

## Analogi Alur
Seperti indikator baterai — semakin hijau (terisi), semakin dekat Anda ke akhir artikel.

## Poin-Poin Penting
- Posisi fixed di bagian atas halaman
- Hitung persentase scroll: `(scrollTop) / (scrollHeight - clientHeight)`
- Update lebar bar secara real-time
- Transisi halus untuk pergerakan

## Cara Integrasi
Tambahkan progress bar di halaman detail artikel. Posisi fixed di atas halaman dengan z-index tinggi. Update lebar bar berdasarkan persentase scroll.
