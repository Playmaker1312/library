# 171. Mengimplementasikan Fitur Share ke Social Media

## Definisi & Target
Tombol share untuk membagikan artikel ke social media. Target: Button share ke Twitter, Facebook, WhatsApp, dan copy link.

## Analogi Alur
Seperti menyebarkan brosur ke banyak orang — dengan satu klik, artikel bisa dibagikan ke berbagai platform.

## Poin-Poin Penting
- Gunakan URL share dengan parameter (url, text)
- Platform: Twitter, Facebook, WhatsApp, LinkedIn
- Web Share API untuk mobile devices
- Copy link to clipboard sebagai fallback

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Share Artikel</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f8fafc; padding: 40px 20px; }
    .container { max-width: 700px; margin: 0 auto; }
    .article { background: #fff; padding: 40px; border-radius: 16px; box-shadow: 0 4px 6px -1px rgba(0,0,0,0.05); margin-bottom: 30px; }
    .article h1 { font-size: 28px; color: #1e293b; margin-bottom: 12px; }
    .article p { color: #475569; line-height: 1.9; }
    .share-section h3 { font-size: 18px; color: #1e293b; margin-bottom: 16px; }
    .share-buttons { display: flex; gap: 12px; flex-wrap: wrap; }
    .share-btn { display: inline-flex; align-items: center; gap: 8px; padding: 12px 24px; border: none; border-radius: 10px; cursor: pointer; font-size: 14px; font-weight: 600; color: #fff; transition: transform 0.2s; text-decoration: none; }
    .share-btn:hover { transform: translateY(-2px); }
    .share-btn.twitter { background: #1da1f2; }
    .share-btn.facebook { background: #1877f2; }
    .share-btn.whatsapp { background: #25d366; }
    .share-btn.linkedin { background: #0a66c2; }
    .share-btn.copy { background: #64748b; }
    .toast { position: fixed; bottom: 30px; left: 50%; transform: translateX(-50%); background: #1e293b; color: #fff; padding: 12px 24px; border-radius: 10px; font-size: 14px; opacity: 0; transition: opacity 0.3s; }
    .toast.show { opacity: 1; }
  </style>
</head>
<body>
  <div class="container">
    <div class="article">
      <h1>Cara Membuat Website Modern</h1>
      <p>Artikel ini membahas langkah-langkah membuat website modern menggunakan HTML, CSS, dan JavaScript. Cocok untuk pemula yang ingin belajar pengembangan web dari dasar hingga mahir.</p>
    </div>
    <div class="share-section">
      <h3>Bagikan Artikel Ini</h3>
      <div class="share-buttons">
        <button class="share-btn twitter" onclick="shareTwitter()">🐦 Twitter</button>
        <button class="share-btn facebook" onclick="shareFacebook()">📘 Facebook</button>
        <button class="share-btn whatsapp" onclick="shareWhatsApp()">💬 WhatsApp</button>
        <button class="share-btn linkedin" onclick="shareLinkedIn()">💼 LinkedIn</button>
        <button class="share-btn copy" onclick="copyLink()">🔗 Copy Link</button>
      </div>
    </div>
  </div>
  <div class="toast" id="toast">Link berhasil disalin!</div>
  <script>
    const url = encodeURIComponent(window.location.href);
    const title = encodeURIComponent('Cara Membuat Website Modern');
    function shareTwitter() { window.open(`https://twitter.com/intent/tweet?text=${title}&url=${url}`, '_blank'); }
    function shareFacebook() { window.open(`https://www.facebook.com/sharer/sharer.php?u=${url}`, '_blank'); }
    function shareWhatsApp() { window.open(`https://api.whatsapp.com/send?text=${title}%20${url}`, '_blank'); }
    function shareLinkedIn() { window.open(`https://www.linkedin.com/sharing/share-offsite/?url=${url}`, '_blank'); }
    function copyLink() {
      navigator.clipboard.writeText(window.location.href).then(() => {
        const toast = document.getElementById('toast');
        toast.classList.add('show');
        setTimeout(() => toast.classList.remove('show'), 2000);
      });
    }
    if (navigator.share) {
      document.querySelector('.share-buttons').insertAdjacentHTML('afterbegin', `<button class="share-btn" style="background:#2563eb;" onclick="nativeShare()">📤 Share</button>`);
    }
    function nativeShare() {
      navigator.share({ title: 'Cara Membuat Website Modern', text: 'Baca artikel ini!', url: window.location.href }).catch(() => {});
    }
  </script>
</body>
</html>
```

## Cara Integrasi
Tambahkan tombol share di halaman detail artikel. Gunakan Web Share API untuk mobile. Sediakan alternatif manual share untuk setiap platform.
