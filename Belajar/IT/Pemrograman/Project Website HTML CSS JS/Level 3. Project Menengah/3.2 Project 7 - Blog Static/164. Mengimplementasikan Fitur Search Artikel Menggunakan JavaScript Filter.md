# 164. Mengimplementasikan Fitur Search Artikel Menggunakan JavaScript Filter
## Definisi & Target
Fitur search memungkinkan pengguna mencari artikel berdasarkan kata kunci. Targetnya adalah pencarian real-time yang menampilkan hasil yang relevan.

## Analogi Alur
Seperti mesin pencari di perpustakaan: Anda mengetik judul buku, sistem langsung menampilkan buku-buku yang sesuai.

## Poin-Poin Penting
- Gunakan `.filter()` pada array artikel berdasarkan judul dan konten
- Search case-insensitive dengan `.toLowerCase()`
- Tampilkan hasil search di grid yang sama atau terpisah
- Beri placeholder text yang jelas pada input search
- Tambahkan debounce untuk mengurangi pemrosesan berlebihan
- Tampilkan pesan "Tidak ditemukan" jika tidak ada hasil

Tambahkan input search di bagian atas halaman index blog. Gunakan JavaScript `.filter()` untuk menyaring artikel berdasarkan judul, kategori, atau konten secara real-time.
