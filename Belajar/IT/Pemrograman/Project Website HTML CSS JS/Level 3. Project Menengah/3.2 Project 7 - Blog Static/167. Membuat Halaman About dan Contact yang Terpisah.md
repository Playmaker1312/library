# 167. Membuat Halaman About dan Contact yang Terpisah
## Definisi & Target
Halaman About dan Contact sebagai halaman statis terpisah di blog. Targetnya adalah informasi profil blog dan form kontak dalam layout yang konsisten.

## Analogi Alur
Seperti brosur perusahaan yang memiliki halaman profil dan halaman kontak. Informasi penting disajikan terpisah namun dalam satu kesatuan.

## Poin-Poin Penting
- Halaman About: profil blog, visi misi, bio penulis
- Halaman Contact: form kontak dan informasi kontak
- Navigasi menuju halaman About dan Contact dari navbar
- Layout konsisten dengan halaman blog lainnya
- Gunakan hash routing atau halaman HTML terpisah
- Sertakan social media links di halaman About

## Cara Integrasi
Buat halaman About berisi profil penulis dan deskripsi blog. Halaman Contact berisi form kontak. Navigasi antar halaman menggunakan fungsi JavaScript showPage() dengan hash routing atau toggle display.
