# 162. Menampilkan Konten Artikel Secara Dinamis Berdasarkan ID dari URL
## Definisi & Target
Konten artikel ditampilkan berdasarkan ID yang diterima dari URL. Targetnya adalah halaman detail yang merender konten artikel yang sesuai secara dinamis.

## Analogi Alur
Seperti mesin penjual otomatis: Anda memilih nomor (ID), mesin mengambil produk yang sesuai dari rak dan menyerahkannya kepada Anda.

## Poin-Poin Penting
- Baca ID dari URL menggunakan URLSearchParams
- Cari artikel yang cocok dari array data
- Render konten artikel lengkap: judul, gambar, meta, konten
- Jika ID tidak valid, tampilkan halaman 404 custom
- Update judul halaman (document.title) sesuai artikel
- Sediakan link kembali ke halaman index

## Cara Integrasi
Integrasikan fungsi pencarian artikel berdasarkan ID ke halaman detail. Pastikan semua artikel memiliki ID unik. Handle case artikel tidak ditemukan dengan pesan error yang jelas.
