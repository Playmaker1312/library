# 173. Menyimpan Artikel yang Disukai Menggunakan localStorage

## Definisi & Target
Fitur like/favorit artikel yang persisten menggunakan localStorage. Target: Tombol like yang menyimpan status suka di browser.

## Analogi Alur
Seperti memberi bookmark di buku — Anda menandai halaman favorit dan tandanya tetap ada meskipun buku ditutup.

## Poin-Poin Penting
- Simpan array ID artikel favorit di localStorage
- Toggle like saat tombol diklik
- Tampilkan status like (icon filled/outline)
- Hitung jumlah artikel yang disukai

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Favorit Artikel</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f8fafc; padding: 40px 20px; }
    .container { max-width: 800px; margin: 0 auto; }
    h1 { color: #1e293b; margin-bottom: 8px; }
    .subtitle { color: #64748b; margin-bottom: 30px; }
    .stats { display: flex; gap: 20px; margin-bottom: 30px; }
    .stat-card { background: #fff; padding: 20px 30px; border-radius: 12px; border: 1px solid #e2e8f0; flex: 1; text-align: center; }
    .stat-card .num { font-size: 28px; font-weight: 700; color: #2563eb; }
    .stat-card .lbl { font-size: 13px; color: #64748b; margin-top: 4px; }
    .article-list { display: grid; gap: 16px; }
    .article-item { background: #fff; padding: 20px 24px; border-radius: 12px; border: 1px solid #e2e8f0; display: flex; justify-content: space-between; align-items: center; }
    .article-item .info h3 { color: #1e293b; font-size: 16px; }
    .article-item .info span { color: #94a3b8; font-size: 13px; }
    .like-btn { background: none; border: none; font-size: 28px; cursor: pointer; transition: transform 0.2s; padding: 5px; }
    .like-btn:hover { transform: scale(1.2); }
    .like-btn.liked { animation: pulse 0.3s; }
    @keyframes pulse { 0% { transform: scale(1); } 50% { transform: scale(1.3); } 100% { transform: scale(1); } }
    .filter-bar { display: flex; gap: 10px; margin-bottom: 20px; }
    .filter-btn { padding: 8px 20px; border: 1px solid #e2e8f0; background: #fff; border-radius: 50px; cursor: pointer; font-size: 14px; }
    .filter-btn.active { background: #2563eb; color: #fff; border-color: #2563eb; }
  </style>
</head>
<body>
  <div class="container">
    <h1>Artikel Favorit</h1>
    <p class="subtitle">Klik hati untuk menyukai artikel. Data tersimpan di localStorage.</p>
    <div class="stats">
      <div class="stat-card"><div class="num" id="totalArticles">0</div><div class="lbl">Total Artikel</div></div>
      <div class="stat-card"><div class="num" id="likedCount">0</div><div class="lbl">Disukai</div></div>
    </div>
    <div class="filter-bar">
      <button class="filter-btn active" onclick="filterArticles('all')">Semua</button>
      <button class="filter-btn" onclick="filterArticles('liked')">Disukai</button>
    </div>
    <div class="article-list" id="articleList"></div>
  </div>
  <script>
    const articles = [
      { id: 1, title: 'Panduan Bisnis Online', date: '1 Jan 2026' },
      { id: 2, title: 'Cara Membuat Website', date: '15 Des 2025' },
      { id: 3, title: 'Strategi SEO Dasar', date: '20 Nov 2025' },
      { id: 4, title: 'Tips Desain UI/UX', date: '10 Okt 2025' },
      { id: 5, title: 'Framework JavaScript', date: '5 Sep 2025' }
    ];
    function getLiked() {
      return JSON.parse(localStorage.getItem('likedArticles') || '[]');
    }
    function saveLiked(liked) {
      localStorage.setItem('likedArticles', JSON.stringify(liked));
    }
    function toggleLike(id) {
      let liked = getLiked();
      const idx = liked.indexOf(id);
      if (idx === -1) liked.push(id);
      else liked.splice(idx, 1);
      saveLiked(liked);
      render('all');
    }
    function render(filter) {
      const liked = getLiked();
      document.getElementById('totalArticles').textContent = articles.length;
      document.getElementById('likedCount').textContent = liked.length;
      let filtered = filter === 'liked' ? articles.filter(a => liked.includes(a.id)) : articles;
      const list = document.getElementById('articleList');
      list.innerHTML = filtered.map(a => {
        const isLiked = liked.includes(a.id);
        return `<div class="article-item"><div class="info"><h3>${a.title}</h3><span>${a.date}</span></div><button class="like-btn ${isLiked ? 'liked' : ''}" onclick="toggleLike(${a.id})">${isLiked ? '❤️' : '🤍'}</button></div>`;
      }).join('');
    }
    function filterArticles(filter) {
      document.querySelectorAll('.filter-btn').forEach(b => b.classList.remove('active'));
      event.target.classList.add('active');
      render(filter);
    }
    render('all');
  </script>
</body>
</html>
```

## Cara Integrasi
Fungsi `getLiked()` dan `saveLiked()` adalah utility untuk mengelola localStorage. Panggil `toggleLike(id)` saat tombol like diklik. Render ulang UI setelah perubahan.
