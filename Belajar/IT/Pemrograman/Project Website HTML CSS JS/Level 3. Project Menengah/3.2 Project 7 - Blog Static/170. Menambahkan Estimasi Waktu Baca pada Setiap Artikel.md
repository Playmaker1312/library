# 170. Menambahkan Estimasi Waktu Baca pada Setiap Artikel

## Definisi & Target
Estimasi waktu baca (reading time) memberitahu berapa menit untuk membaca artikel. Target: Menampilkan waktu baca berdasarkan jumlah kata.

## Analogi Alur
Seperti perkiraan waktu di Google Maps — sebelum memulai perjalanan (membaca), Anda tahu berapa lama waktu yang dibutuhkan.

## Poin-Poin Penting
- Hitung jumlah kata dalam konten artikel
- Rata-rata kecepatan baca: 200-250 kata per menit
- Tampilkan "X menit baca" di header artikel
- Bulatkan ke atas, minimal 1 menit

## Cara Integrasi
Hitung waktu baca saat konten artikel di-render. Fungsi `calculateReadingTime` menghitung jumlah kata dan membagi dengan WPM (default 200). Tampilkan di header artikel bersama metadata.
