# 161. Membuat Fungsi untuk Membaca Parameter dari URL Menggunakan URLSearchParams
## Definisi & Target
URLSearchParams adalah API browser untuk membaca parameter query string. Targetnya adalah fungsi reusable untuk mengambil data dari URL.

## Analogi Alur
Seperti resepsionis yang membaca kartu identitas tamu untuk mengetahui kamar yang dipesan. URLSearchParams membaca "kartu identitas" dari URL.

## Poin-Poin Penting
- `new URLSearchParams(window.location.search)` membuat instance
- Gunakan `.get('key')` untuk membaca parameter tertentu
- `.has('key')` untuk mengecek keberadaan parameter
- `.getAll('key')` untuk parameter dengan banyak nilai
- Parameter URL selalu string, konversi sesuai kebutuhan
- Tangani kasus parameter tidak ada dengan default value

```html
    body { font-family: system-ui, sans-serif; background: #f8fafc; padding: 40px; }
    .container { max-width: 700px; margin: 0 auto; }
    h1 { margin-bottom: 24px; font-size: 1.75rem; }
    .card { background: white; border: 1px solid #e2e8f0; border-radius: 12px; padding: 24px; margin-bottom: 16px; }
    .card h3 { margin-bottom: 8px; font-size: 1rem; }
    .card .value { background: #f1f5f9; padding: 12px; border-radius: 8px; font-family: monospace; word-break: break-all; }
    .url-builder { display: flex; gap: 12px; margin-bottom: 20px; flex-wrap: wrap; }
    .url-builder input { flex: 1; padding: 12px; border: 1px solid #e2e8f0; border-radius: 8px; font-size: 0.95rem; min-width: 200px; }

    .demo-links a:hover { background: #2563eb; color: white; }
  </style>
</head>
<body>
  <div class="container">
    <h1>🔍 URL Parameter Reader</h1>
    <div class="demo-links">
      <a href="?id=1&category=css&page=1">Artikel 1</a>
      <a href="?id=2&category=javascript&page=1">Artikel 2</a>
      <a href="?id=3&category=css&page=2">Artikel 3</a>
      <a href="?search=css+grid&page=1">Search CSS</a>
    </div>
    <div class="url-builder">
      <input type="text" id="urlInput" placeholder="?id=1&category=css" value="?id=1&category=css">
      <button onclick="parseCustom()">Parse URL</button>
    </div>
    <div id="result"></div>
  </div>
  <script>
    function parseURLParams(queryString) {
      const params = new URLSearchParams(queryString);
      const result = {};
      for (const [key, value] of params.entries()) {
        const values = params.getAll(key);
        result[key] = values.length > 1 ? values : value;
      }
      return result;
    }
    function displayParams(params) {
      const result = document.getElementById('result');
      const entries = Object.entries(params);
      if (entries.length === 0) {
        result.innerHTML = '<div class="card"><h3>Hasil</h3><div class="value">Tidak ada parameter URL ditemukan. Klik link di atas untuk menambahkan parameter.</div></div>';
        return;
      }
      result.innerHTML = entries.map(([key, value]) => `
        <div class="card">
          <h3>${key}</h3>
          <div class="value">${Array.isArray(value) ? value.join(', ') : value} <small style="color:#94a3b8">(${typeof value})</small></div>
        </div>
      `).join('');
    }
    function parseCustom() {
      const input = document.getElementById('urlInput').value;
      const qs = input.startsWith('?') ? input : '?' + input;
      const params = parseURLParams(qs);
      displayParams(params);
    }
    const params = parseURLParams(window.location.search);
    displayParams(params);
    console.log('Parsed URL params:', params);
  </script>
</body>
</html>
```
## Cara Integrasi
Gunakan fungsi `URLSearchParams` untuk membaca parameter URL di halaman detail artikel. Fungsi ini tersedia di semua browser modern tanpa library tambahan.
