# 205. Mengimplementasikan Add to Cart Functionality Menggunakan JavaScript

## Definisi & Target
Add to cart menambahkan produk ke keranjang. Target: Fungsi JavaScript untuk menyimpan item ke cart array.

## Analogi Alur
Seperti memasukkan barang ke keranjang belanja fisik — setiap item ditambahkan ke dalam keranjang (array JavaScript).

## Poin-Poin Penting
- Cart adalah array of objects
- Setiap item: productId, name, price, quantity, size, color, image
- Cek apakah produk sudah ada di cart (update quantity)
- Tampilkan notifikasi atau animasi saat add to cart

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Add to Cart</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f8fafc; padding: 40px 20px; }
    .container { max-width: 700px; margin: 0 auto; }
    h1 { color: #1e293b; margin-bottom: 8px; }
    .subtitle { color: #64748b; margin-bottom: 30px; }
    .product-card { background: #fff; padding: 30px; border-radius: 16px; border: 1px solid #e2e8f0; display: flex; gap: 20px; align-items: center; margin-bottom: 30px; }
    .product-card .icon { font-size: 48px; background: #eff6ff; padding: 20px; border-radius: 12px; }
    .product-card .detail h3 { color: #1e293b; margin-bottom: 4px; }
    .product-card .detail .price { color: #2563eb; font-weight: 700; }
    .product-card .detail select { padding: 6px 12px; border: 1px solid #e2e8f0; border-radius: 6px; margin-top: 8px; }
    .btn-add { padding: 12px 28px; background: #2563eb; color: #fff; border: none; border-radius: 10px; font-weight: 600; cursor: pointer; transition: all 0.3s; }
    .btn-add:hover { background: #1d4ed8; }
    .btn-add:active { transform: scale(0.95); }
    .cart-panel { background: #fff; padding: 24px; border-radius: 16px; border: 1px solid #e2e8f0; }
    .cart-panel h2 { font-size: 20px; color: #1e293b; margin-bottom: 16px; display: flex; justify-content: space-between; align-items: center; }
    .cart-panel h2 span { background: #2563eb; color: #fff; font-size: 12px; padding: 2px 10px; border-radius: 50px; }
    .cart-item { display: flex; align-items: center; gap: 16px; padding: 12px 0; border-bottom: 1px solid #f1f5f9; }
    .cart-item:last-child { border-bottom: none; }
    .cart-item .name { flex: 1; }
    .cart-item .name h4 { font-size: 14px; color: #1e293b; }
    .cart-item .name .variant { font-size: 12px; color: #94a3b8; }
    .cart-item .qty-price { text-align: right; }
    .cart-item .qty-price .qty { font-size: 14px; color: #475569; }
    .cart-item .qty-price .subtotal { font-weight: 600; color: #1e293b; }
    .cart-empty { text-align: center; padding: 40px; color: #94a3b8; }
    .toast { position: fixed; bottom: 30px; left: 50%; transform: translateX(-50%); background: #065f46; color: #fff; padding: 14px 28px; border-radius: 10px; font-size: 14px; opacity: 0; transition: opacity 0.3s; }
    .toast.show { opacity: 1; }
  </style>
</head>
<body>
  <div class="container">
    <h1>Add to Cart</h1>
    <p class="subtitle">Klik tombol untuk menambahkan produk ke keranjang.</p>
    <div class="product-card">
      <div class="icon">👟</div>
      <div class="detail"><h3>Sepatu Running Pro</h3><div class="price">Rp299.000</div><select id="sizeSelect"><option>39</option><option>40</option><option>41</option><option selected>42</option></select></div>
      <button class="btn-add" onclick="addToCart()">+ Keranjang</button>
    </div>
    <div class="cart-panel">
      <h2>Keranjang <span id="cartCount">0</span></h2>
      <div id="cartItems"><div class="cart-empty">Keranjang masih kosong</div></div>
      <div id="cartTotal" style="text-align:right;font-size:18px;font-weight:700;color:#1e293b;padding-top:12px;border-top:1px solid #e2e8f0;margin-top:12px;display:none;"></div>
    </div>
  </div>
  <div class="toast" id="toast">✓ Produk ditambahkan ke keranjang!</div>
  <script>
    let cart = [];
    function addToCart() {
      const size = document.getElementById('sizeSelect').value;
      const item = { id: 1, name: 'Sepatu Running Pro', price: 299000, size, quantity: 1 };
      const existing = cart.find(i => i.id === item.id && i.size === item.size);
      if (existing) {
        existing.quantity++;
      } else {
        cart.push(item);
      }
      renderCart();
      showToast();
    }
    function removeFromCart(index) {
      cart.splice(index, 1);
      renderCart();
    }
    function renderCart() {
      const container = document.getElementById('cartItems');
      const count = document.getElementById('cartCount');
      const totalEl = document.getElementById('cartTotal');
      count.textContent = cart.reduce((acc, i) => acc + i.quantity, 0);
      if (cart.length === 0) {
        container.innerHTML = '<div class="cart-empty">Keranjang masih kosong</div>';
        totalEl.style.display = 'none';
        return;
      }
      container.innerHTML = cart.map((item, idx) => `
        <div class="cart-item">
          <div class="name"><h4>${item.name}</h4><div class="variant">Ukuran: ${item.size}</div></div>
          <div class="qty-price"><div class="qty">${item.quantity} × Rp${item.price.toLocaleString()}</div><div class="subtotal">Rp${(item.price * item.quantity).toLocaleString()}</div></div>
          <button style="background:none;border:none;color:#ef4444;cursor:pointer;font-size:18px;" onclick="removeFromCart(${idx})">×</button>
        </div>
      `).join('');
      const total = cart.reduce((acc, item) => acc + item.price * item.quantity, 0);
      totalEl.style.display = 'block';
      totalEl.textContent = `Total: Rp${total.toLocaleString()}`;
    }
    function showToast() {
      const toast = document.getElementById('toast');
      toast.classList.add('show');
      setTimeout(() => toast.classList.remove('show'), 2000);
    }
  </script>
</body>
</html>
```

## Cara Integrasi
Cart adalah array global yang menyimpan item yang ditambahkan. Fungsi `addToCart()` menambah item ke array. Render ulang cart setiap ada perubahan.
