# 210. Membangun Related Products Section Menggunakan Horizontal Scroll

## Definisi & Target
Related products menampilkan produk lain yang terkait. Target: Horizontal scroll card produk dengan navigasi geser.

## Analogi Alur
Seperti rak rekomendasi di toko — "Pelanggan juga membeli" dalam baris horizontal yang bisa di-scroll.

## Poin-Poin Penting
- Container dengan `overflow-x: auto` untuk horizontal scroll
- Card produk dalam flex row
- Navigasi prev/next atau scroll alami
- Card berisi gambar, nama, harga, rating

    const scrollContainer = document.getElementById('relatedScroll');
    function scrollRelated(amount) {
      scrollContainer.scrollBy({ left: amount, behavior: 'smooth' });

    let isDown = false;
    let startX;
    let scrollLeft;
    scrollContainer.addEventListener('mousedown', (e) => {
      isDown = true;
      startX = e.pageX - scrollContainer.offsetLeft;
      scrollLeft = scrollContainer.scrollLeft;
    });
    scrollContainer.addEventListener('mouseleave', () => isDown = false);
    scrollContainer.addEventListener('mouseup', () => isDown = false);
    scrollContainer.addEventListener('mousemove', (e) => {
      if (!isDown) return;
      e.preventDefault();
      const x = e.pageX - scrollContainer.offsetLeft;
      const walk = (x - startX) * 2;
      scrollContainer.scrollLeft = scrollLeft - walk;
    });

## Cara Integrasi
Related products ditempatkan setelah product tabs. Gunakan `overflow-x: auto` untuk scroll horizontal. Data produk terkait difilter berdasarkan kategori yang sama.
