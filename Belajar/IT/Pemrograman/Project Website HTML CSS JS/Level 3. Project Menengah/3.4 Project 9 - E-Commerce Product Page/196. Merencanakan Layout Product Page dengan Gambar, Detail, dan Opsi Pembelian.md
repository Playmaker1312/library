# 196. Merencanakan Layout Product Page dengan Gambar, Detail, dan Opsi Pembelian

## Definisi & Target
Product page menampilkan produk dengan gambar, detail, dan opsi pembelian. Target: Layout dua kolom (gambar + info) dengan CTA.

## Analogi Alur
Seperti etalase toko — di sebelah kiri display barang (gambar), di sebelah kanan label harga dan tombol beli.

## Poin-Poin Penting
- Kolom kiri: image gallery (main + thumbnails)
- Kolom kanan: nama, harga, rating, deskripsi, opsi (size/warna), quantity, add to cart
- Layout responsive (tumpuk di mobile)
- Sticky add to cart di mobile

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Product Page Layout</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f8fafc; }
    .product { max-width: 1200px; margin: 0 auto; padding: 40px 20px; display: grid; grid-template-columns: 1fr 1fr; gap: 50px; }
    .gallery { }
    .gallery .main-img { width: 100%; aspect-ratio: 1; background: #fff; border-radius: 20px; border: 1px solid #e2e8f0; display: flex; align-items: center; justify-content: center; font-size: 80px; margin-bottom: 16px; }
    .gallery .thumbs { display: flex; gap: 12px; }
    .gallery .thumbs .thumb { width: 80px; height: 80px; border-radius: 12px; border: 2px solid transparent; cursor: pointer; display: flex; align-items: center; justify-content: center; font-size: 30px; background: #fff; border: 1px solid #e2e8f0; }
    .gallery .thumbs .thumb.active { border-color: #2563eb; }
    .info h1 { font-size: 32px; color: #1e293b; margin-bottom: 8px; }
    .info .price { font-size: 28px; font-weight: 800; color: #2563eb; margin-bottom: 12px; }
    .info .rating { color: #f59e0b; margin-bottom: 16px; font-size: 16px; }
    .info .desc { color: #64748b; line-height: 1.7; margin-bottom: 24px; }
    .info .options { margin-bottom: 24px; }
    .info .options h3 { font-size: 14px; color: #1e293b; margin-bottom: 8px; }
    .info .options .opt-group { display: flex; gap: 10px; }
    .info .options .opt-btn { padding: 10px 20px; border: 1px solid #e2e8f0; border-radius: 8px; background: #fff; cursor: pointer; font-size: 14px; }
    .info .options .opt-btn.active { border-color: #2563eb; background: #eff6ff; color: #2563eb; }
    .info .qty { display: flex; align-items: center; gap: 12px; margin-bottom: 24px; }
    .info .qty button { width: 40px; height: 40px; border: 1px solid #e2e8f0; border-radius: 8px; background: #fff; cursor: pointer; font-size: 18px; }
    .info .qty span { font-size: 18px; font-weight: 600; width: 40px; text-align: center; }
    .btn-cart { width: 100%; padding: 16px; background: #2563eb; color: #fff; border: none; border-radius: 12px; font-size: 18px; font-weight: 600; cursor: pointer; transition: background 0.3s; }
    .btn-cart:hover { background: #1d4ed8; }
    @media (max-width: 768px) { .product { grid-template-columns: 1fr; gap: 30px; } }
  </style>
</head>
<body>
  <div class="product">
    <div class="gallery">
      <div class="main-img">👟</div>
      <div class="thumbs">
        <div class="thumb active">👟</div>
        <div class="thumb">👟</div>
        <div class="thumb">👟</div>
      </div>
    </div>
    <div class="info">
      <h1>Sepatu Running Pro</h1>
      <div class="price">Rp299.000</div>
      <div class="rating">★★★★★ (120 ulasan)</div>
      <p class="desc">Sepatu running dengan teknologi cushioning terbaru. Ringan, nyaman, dan cocok untuk lari jarak jauh maupun pendek.</p>
      <div class="options">
        <h3>Ukuran</h3>
        <div class="opt-group">
          <button class="opt-btn active">40</button>
          <button class="opt-btn">41</button>
          <button class="opt-btn">42</button>
          <button class="opt-btn">43</button>
        </div>
      </div>
      <div class="qty">
        <button onclick="changeQty(-1)">−</button>
        <span id="qtyDisplay">1</span>
        <button onclick="changeQty(1)">+</button>
      </div>
      <button class="btn-cart">+ Keranjang</button>
    </div>
  </div>
  <script>
    let qty = 1;
    function changeQty(delta) {
      qty = Math.max(1, qty + delta);
      document.getElementById('qtyDisplay').textContent = qty;
    }
    document.querySelectorAll('.opt-btn').forEach(btn => {
      btn.addEventListener('click', () => {
        btn.parentElement.querySelectorAll('.opt-btn').forEach(b => b.classList.remove('active'));
        btn.classList.add('active');
      });
    });
    document.querySelectorAll('.thumb').forEach(thumb => {
      thumb.addEventListener('click', () => {
        document.querySelectorAll('.thumb').forEach(t => t.classList.remove('active'));
        thumb.classList.add('active');
      });
    });
  </script>
</body>
</html>
```

## Cara Integrasi
Layout product page menjadi kerangka untuk semua komponen e-commerce. Kembangkan masing-masing komponen (gallery, zoom, cart, tabs) secara bertahap.
