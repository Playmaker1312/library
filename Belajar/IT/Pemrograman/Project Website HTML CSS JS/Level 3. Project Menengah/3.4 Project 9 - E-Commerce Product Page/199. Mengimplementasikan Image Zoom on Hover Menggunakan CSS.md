# 199. Mengimplementasikan Image Zoom on Hover Menggunakan CSS

## Definisi & Target
Image zoom on hover memperbesar bagian gambar saat mouse diarahkan. Target: Efek zoom lensa atau scale up menggunakan CSS.

## Analogi Alur
Seperti menggunakan kaca pembesar — saat mouse diarahkan ke bagian gambar, area tersebut diperbesar untuk melihat detail.

## Poin-Poin Penting
- Gunakan `transform: scale()` untuk zoom
- Atur `transform-origin` sesuai posisi mouse
- CSS `overflow: hidden` pada container
- JavaScript untuk menghitung posisi mouse relatif

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Image Zoom Hover</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f8fafc; display: flex; align-items: center; justify-content: center; min-height: 100vh; padding: 20px; flex-direction: column; }
    .zoom-container { max-width: 500px; width: 100%; }
    .zoom-wrapper { position: relative; width: 100%; aspect-ratio: 1; overflow: hidden; border-radius: 16px; border: 1px solid #e2e8f0; background: #fff; cursor: crosshair; }
    .zoom-image { width: 100%; height: 100%; display: flex; align-items: center; justify-content: center; font-size: 150px; transition: transform 0.05s; }
    .zoom-wrapper:hover .zoom-image { transform: scale(2); }
    .zoom-lens { display: none; position: absolute; width: 120px; height: 120px; border: 2px solid #2563eb; border-radius: 50%; pointer-events: none; z-index: 10; background: rgba(37,99,235,0.1); }
    .info { margin-top: 20px; text-align: center; color: #64748b; font-size: 14px; }
    .zoom-controls { margin-top: 16px; display: flex; gap: 10px; align-items: center; }
    .zoom-controls label { color: #64748b; }
    .zoom-controls input { width: 200px; }
    .zoom-controls span { font-weight: 600; color: #2563eb; min-width: 40px; }
  </style>
</head>
<body>
  <div class="zoom-container">
    <div class="zoom-wrapper" id="zoomWrapper">
      <div class="zoom-image" id="zoomImage" style="background:linear-gradient(135deg,#2563eb,#1d4ed8);color:#fff;">👟</div>
      <div class="zoom-lens" id="zoomLens"></div>
    </div>
    <div class="info">Hover gambar untuk melihat detail lebih dekat</div>
    <div class="zoom-controls">
      <label>Zoom Level:</label>
      <input type="range" id="zoomLevel" min="1.5" max="4" step="0.1" value="2">
      <span id="zoomDisplay">2x</span>
    </div>
  </div>
  <script>
    const wrapper = document.getElementById('zoomWrapper');
    const image = document.getElementById('zoomImage');
    const lens = document.getElementById('zoomLens');
    const zoomControl = document.getElementById('zoomLevel');
    const zoomDisplay = document.getElementById('zoomDisplay');
    let zoom = 2;
    zoomControl.addEventListener('input', () => {
      zoom = parseFloat(zoomControl.value);
      zoomDisplay.textContent = zoom + 'x';
    });
    wrapper.addEventListener('mousemove', (e) => {
      const rect = wrapper.getBoundingClientRect();
      const x = ((e.clientX - rect.left) / rect.width) * 100;
      const y = ((e.clientY - rect.top) / rect.height) * 100;
      image.style.transformOrigin = `${x}% ${y}%`;
      image.style.transform = `scale(${zoom})`;
    });
    wrapper.addEventListener('mouseleave', () => {
      image.style.transformOrigin = 'center center';
      image.style.transform = 'scale(1)';
    });
  </script>
</body>
</html>
```

## Cara Integrasi
Tambahkan zoom effect pada main image gallery. Hitung posisi mouse relatif terhadap container untuk `transform-origin`. Atur zoom level sesuai kebutuhan.
