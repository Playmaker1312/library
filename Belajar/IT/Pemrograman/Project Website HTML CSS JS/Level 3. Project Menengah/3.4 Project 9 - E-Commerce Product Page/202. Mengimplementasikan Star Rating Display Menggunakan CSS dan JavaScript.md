# 202. Mengimplementasikan Star Rating Display Menggunakan CSS dan JavaScript

## Definisi & Target
Star rating menampilkan rating produk dalam bentuk bintang. Target: Bintang penuh, setengah, dan kosong berdasarkan nilai rating.

## Analogi Alur
Seperti sistem penilaian di sekolah — bintang adalah nilai, dari 1 (sangat buruk) sampai 5 (sangat baik).

## Poin-Poin Penting
- Rating dalam angka desimal (misal 4.5)
- Bintang penuh, setengah, dan kosong
- CSS untuk styling bintang
- Tampilkan jumlah ulasan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Star Rating</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f8fafc; padding: 40px 20px; }
    .container { max-width: 700px; margin: 0 auto; }
    h1 { color: #1e293b; margin-bottom: 8px; }
    .subtitle { color: #64748b; margin-bottom: 30px; }
    .demo-card { background: #fff; padding: 30px; border-radius: 16px; border: 1px solid #e2e8f0; margin-bottom: 20px; }
    .demo-card h3 { color: #1e293b; margin-bottom: 12px; }
    .rating-row { display: flex; align-items: center; gap: 12px; margin: 10px 0; }
    .stars { display: flex; gap: 2px; font-size: 24px; }
    .stars .star { color: #e2e8f0; position: relative; }
    .stars .star.filled { color: #f59e0b; }
    .stars .star.half { color: #f59e0b; }
    .stars .star.half::after { content: '★'; position: absolute; left: 0; width: 50%; overflow: hidden; color: #f59e0b; }
    .rating-number { font-weight: 600; color: #1e293b; }
    .rating-count { color: #64748b; font-size: 14px; }
    .interactive .stars { cursor: pointer; }
    .interactive .stars .star { transition: transform 0.2s; }
    .interactive .stars .star:hover { transform: scale(1.2); }
    .star-bars { margin-top: 16px; }
    .star-bar { display: flex; align-items: center; gap: 8px; margin: 4px 0; font-size: 13px; }
    .star-bar .bar { flex: 1; height: 8px; background: #f1f5f9; border-radius: 4px; overflow: hidden; }
    .star-bar .bar .fill { height: 100%; background: #f59e0b; border-radius: 4px; }
    .star-bar .pct { color: #64748b; min-width: 35px; text-align: right; }
  </style>
</head>
<body>
  <div class="container">
    <h1>Star Rating Display</h1>
    <p class="subtitle">Rating produk ditampilkan dengan bintang penuh, setengah, dan kosong.</p>
    <div class="demo-card">
      <h3>Static Rating</h3>
      <div id="staticRatings"></div>
    </div>
    <div class="demo-card">
      <h3>Interactive Rating</h3>
      <p style="color:#64748b;margin-bottom:12px;">Klik bintang untuk memberi rating:</p>
      <div class="rating-row interactive">
        <div class="stars" id="interactiveStars"></div>
        <span class="rating-number" id="interactiveRating">0</span>
        <span class="rating-count">/ 5</span>
      </div>
      <p id="ratingFeedback" style="color:#64748b;font-size:14px;margin-top:8px;"></p>
    </div>
    <div class="demo-card">
      <h3>Rating Distribution</h3>
      <div id="ratingDistribution"></div>
    </div>
  </div>
  <script>
    function renderStars(rating) {
      const full = Math.floor(rating);
      const half = rating % 1 >= 0.5 ? 1 : 0;
      const empty = 5 - full - half;
      return '★'.repeat(full) + (half ? '★' : '') + '☆'.repeat(empty);
    }
    function renderStarsHTML(rating) {
      let html = '';
      for (let i = 1; i <= 5; i++) {
        if (i <= rating) html += '<span class="star filled">★</span>';
        else if (i - 0.5 <= rating) html += '<span class="star half">★</span>';
        else html += '<span class="star">☆</span>';
      }
      return html;
    }
    const products = [
      { name: 'Sepatu Running Pro', rating: 4.5, reviews: 128 },
      { name: 'Tas Ransel Premium', rating: 4.0, reviews: 85 },
      { name: 'Jam Tangan Digital', rating: 3.5, reviews: 220 },
      { name: 'Kacamata Olahraga', rating: 5.0, reviews: 45 }
    ];
    document.getElementById('staticRatings').innerHTML = products.map(p => `
      <div class="rating-row">
        <div class="stars">${renderStarsHTML(p.rating)}</div>
        <span class="rating-number">${p.rating}</span>
        <span class="rating-count">(${p.reviews} ulasan)</span>
        <span style="color:#64748b;font-size:14px;margin-left:8px;">${p.name}</span>
      </div>
    `).join('');
    const interactiveStars = document.getElementById('interactiveStars');
    let currentRating = 0;
    function updateInteractive(highlight) {
      interactiveStars.innerHTML = '';
      for (let i = 1; i <= 5; i++) {
        const star = document.createElement('span');
        star.className = 'star';
        star.textContent = i <= highlight ? '★' : '☆';
        star.style.color = i <= highlight ? '#f59e0b' : '#e2e8f0';
        star.style.cursor = 'pointer';
        star.addEventListener('click', () => {
          currentRating = i;
          document.getElementById('interactiveRating').textContent = currentRating;
          document.getElementById('ratingFeedback').textContent = `Anda memberi rating ${currentRating} dari 5`;
          updateInteractive(currentRating);
        });
        interactiveStars.appendChild(star);
      }
    }
    updateInteractive(0);
    const distribution = { 5: 45, 4: 35, 3: 12, 2: 5, 1: 3 };
    const max = Math.max(...Object.values(distribution));
    document.getElementById('ratingDistribution').innerHTML = [5,4,3,2,1].map(n => `
      <div class="star-bar"><span>${n} ★</span><div class="bar"><div class="fill" style="width:${(distribution[n]/max)*100}%"></div></div><span class="pct">${distribution[n]}%</span></div>
    `).join('');
  </script>
</body>
</html>
```

## Cara Integrasi
Fungsi `renderStarsHTML()` menghasilkan HTML star rating berdasarkan nilai numerik. Gunakan di product info, reviews, dan komponen terkait lainnya.
