# 198. Membangun Image Gallery dengan Thumbnail dan Main Image yang Bisa Diklik

## Definisi & Target
Image gallery dengan thumbnail yang bisa diklik untuk mengganti main image. Target: Gallery interaktif dengan navigasi thumbnail.

## Analogi Alur
Seperti melihat-lihat album foto — thumbnail adalah preview kecil, klik untuk melihat versi besar.

## Poin-Poin Penting
- Main image (besar) sebagai display utama
- Thumbnail di bawah atau samping yang bisa diklik
- Thumbnail aktif diberi border/indikator
- Transisi saat ganti gambar

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Image Gallery</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f8fafc; display: flex; align-items: center; justify-content: center; min-height: 100vh; padding: 20px; }
    .gallery { max-width: 600px; width: 100%; }
    .main-image { width: 100%; aspect-ratio: 1; background: #fff; border-radius: 20px; border: 1px solid #e2e8f0; display: flex; align-items: center; justify-content: center; font-size: 120px; margin-bottom: 16px; transition: all 0.3s; overflow: hidden; position: relative; cursor: zoom-in; }
    .main-image img { width: 100%; height: 100%; object-fit: cover; }
    .thumbnails { display: flex; gap: 12px; }
    .thumb-item { width: 90px; height: 90px; border-radius: 12px; border: 2px solid transparent; cursor: pointer; overflow: hidden; display: flex; align-items: center; justify-content: center; font-size: 40px; background: #fff; border: 2px solid #e2e8f0; transition: all 0.2s; }
    .thumb-item:hover { border-color: #94a3b8; }
    .thumb-item.active { border-color: #2563eb; }
    .thumb-item img { width: 100%; height: 100%; object-fit: cover; }
    .nav-buttons { display: flex; justify-content: space-between; position: absolute; inset: 0; align-items: center; padding: 0 16px; opacity: 0; transition: opacity 0.3s; }
    .main-image:hover .nav-buttons { opacity: 1; }
    .nav-btn { width: 44px; height: 44px; border-radius: 50%; background: rgba(255,255,255,0.9); border: none; cursor: pointer; font-size: 20px; display: flex; align-items: center; justify-content: center; box-shadow: 0 2px 8px rgba(0,0,0,0.1); }
    .nav-btn:hover { background: #fff; }
    .image-counter { position: absolute; bottom: 16px; right: 16px; background: rgba(0,0,0,0.6); color: #fff; padding: 4px 12px; border-radius: 50px; font-size: 13px; }
  </style>
</head>
<body>
  <div class="gallery">
    <div class="main-image" id="mainImage">
      <span id="mainIcon">👟</span>
      <div class="nav-buttons">
        <button class="nav-btn" onclick="changeImage(-1)">‹</button>
        <button class="nav-btn" onclick="changeImage(1)">›</button>
      </div>
      <div class="image-counter" id="imageCounter">1/5</div>
    </div>
    <div class="thumbnails" id="thumbnails"></div>
  </div>
  <script>
    const images = ['👟', '👟', '👟', '👟', '👟'];
    const bgColors = ['#eff6ff', '#ecfdf5', '#fef3c7', '#f3e8ff', '#fce7f3'];
    let currentIndex = 0;
    function renderGallery() {
      document.getElementById('mainIcon').textContent = images[currentIndex];
      document.getElementById('mainImage').style.background = bgColors[currentIndex];
      document.getElementById('imageCounter').textContent = `${currentIndex + 1}/${images.length}`;
      document.querySelectorAll('.thumb-item').forEach((thumb, i) => {
        thumb.classList.toggle('active', i === currentIndex);
      });
    }
    function changeImage(delta) {
      currentIndex = (currentIndex + delta + images.length) % images.length;
      renderGallery();
    }
    const thumbContainer = document.getElementById('thumbnails');
    images.forEach((img, i) => {
      const thumb = document.createElement('div');
      thumb.className = `thumb-item${i === 0 ? ' active' : ''}`;
      thumb.textContent = img;
      thumb.style.background = bgColors[i];
      thumb.addEventListener('click', () => {
        currentIndex = i;
        renderGallery();
      });
      thumbContainer.appendChild(thumb);
    });
    renderGallery();
  </script>
</body>
</html>
```

## Cara Integrasi
Gallery menggunakan data image dari object produk. Setiap thumbnail bisa diklik untuk mengubah main image. Navigasi prev/next untuk browsing gambar.
