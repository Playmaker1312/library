# 201. Membuat Product Information Section dengan Nama, Harga, Rating, dan Stok

## Definisi & Target
Product info section menampilkan detail produk. Target: Informasi lengkap: nama, harga (dengan diskon), rating bintang, status stok.

## Analogi Alur
Seperti label harga di toko — semua informasi penting tentang produk ada di satu tempat.

## Poin-Poin Penting
- Nama produk (h1/h2)
- Harga: harga sekarang, harga asli (coret), persentase diskon
- Rating bintang dengan jumlah ulasan
- Status stok (in stock/out of stock) dengan jumlah
- SKU dan kategori

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html

    function updateStock() {
      document.getElementById('stockDisplay').textContent = `${stock} unit`;
```

## Cara Integrasi
Product info section ditempatkan di kolom kanan product page. Data berasal dari object produk. Update harga dan stok secara dinamis.
