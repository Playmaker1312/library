# 204. Membuat Quantity Selector dengan Tombol Tambah dan Kurang

## Definisi & Target
Quantity selector mengatur jumlah produk yang akan dibeli. Target: Input dengan tombol minus dan plus.

## Analogi Alur
Seperti menghitung barang di keranjang — Anda bisa menambah atau mengurangi jumlah dengan menekan tombol.

## Poin-Poin Penting
- Tombol minus (−) dan plus (+)
- Minimum quantity: 1 (atau stok minimum)
- Maksimum quantity: stok tersedia
- Tampilkan quantity saat ini

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Quantity Selector</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f8fafc; display: flex; align-items: center; justify-content: center; min-height: 100vh; padding: 20px; }
    .qty-card { max-width: 400px; width: 100%; background: #fff; padding: 40px; border-radius: 20px; border: 1px solid #e2e8f0; }
    .qty-card h2 { color: #1e293b; margin-bottom: 8px; }
    .qty-card p { color: #64748b; margin-bottom: 24px; }
    .product-row { display: flex; align-items: center; gap: 16px; padding: 16px; background: #f8fafc; border-radius: 12px; margin-bottom: 24px; }
    .product-row .icon { font-size: 40px; }
    .product-row .info h4 { color: #1e293b; }
    .product-row .info span { color: #2563eb; font-weight: 700; }
    .qty-control { display: flex; align-items: center; justify-content: center; gap: 16px; margin-bottom: 24px; }
    .qty-btn { width: 48px; height: 48px; border: 2px solid #e2e8f0; border-radius: 12px; background: #fff; cursor: pointer; font-size: 22px; display: flex; align-items: center; justify-content: center; transition: all 0.2s; color: #475569; }
    .qty-btn:hover:not(:disabled) { border-color: #2563eb; color: #2563eb; }
    .qty-btn:disabled { opacity: 0.4; cursor: not-allowed; }
    .qty-display { font-size: 28px; font-weight: 700; color: #1e293b; min-width: 50px; text-align: center; }
    .stock-info { text-align: center; color: #64748b; font-size: 14px; }
    .stock-bar { width: 100%; height: 6px; background: #f1f5f9; border-radius: 3px; margin: 12px 0; overflow: hidden; }
    .stock-bar .fill { height: 100%; background: #10b981; border-radius: 3px; transition: width 0.3s; }
    .btn-cart { width: 100%; padding: 16px; background: #2563eb; color: #fff; border: none; border-radius: 12px; font-size: 16px; font-weight: 600; cursor: pointer; margin-top: 16px; }
    .btn-cart:hover { background: #1d4ed8; }
    .total-price { text-align: center; font-size: 18px; color: #1e293b; margin-top: 12px; }
    .total-price span { color: #2563eb; font-weight: 700; }
  </style>
</head>
<body>
  <div class="qty-card">
    <h2>Quantity Selector</h2>
    <p>Atur jumlah produk yang ingin dibeli.</p>
    <div class="product-row">
      <div class="icon">👟</div>
      <div class="info"><h4>Sepatu Running Pro</h4><span>Rp299.000</span></div>
    </div>
    <div class="qty-control">
      <button class="qty-btn" id="minusBtn" onclick="changeQuantity(-1)">−</button>
      <span class="qty-display" id="qtyDisplay">1</span>
      <button class="qty-btn" id="plusBtn" onclick="changeQuantity(1)">+</button>
    </div>
    <div class="stock-info">Stok tersedia: <span id="stockDisplay">45</span> unit</div>
    <div class="stock-bar"><div class="fill" id="stockBar" style="width:45%;"></div></div>
    <div class="total-price">Total: <span id="totalDisplay">Rp299.000</span></div>
    <button class="btn-cart">+ Keranjang</button>
  </div>
  <script>
    const price = 299000;
    let stock = 45;
    let quantity = 1;
    function formatPrice(num) {
      return 'Rp' + num.toLocaleString();
    }
    function changeQuantity(delta) {
      const newQty = quantity + delta;
      if (newQty < 1 || newQty > stock) return;
      quantity = newQty;
      updateDisplay();
    }
    function updateDisplay() {
      document.getElementById('qtyDisplay').textContent = quantity;
      document.getElementById('minusBtn').disabled = quantity <= 1;
      document.getElementById('plusBtn').disabled = quantity >= stock;
      document.getElementById('totalDisplay').textContent = formatPrice(price * quantity);
      const pct = (stock / 100) * 100;
      document.getElementById('stockBar').style.width = Math.min(100, pct) + '%';
    }
    document.getElementById('qtyDisplay').addEventListener('dblclick', () => {
      const input = prompt('Masukkan jumlah:', quantity);
      const val = parseInt(input);
      if (val >= 1 && val <= stock) {
        quantity = val;
        updateDisplay();
      }
    });
    updateDisplay();
  </script>
</body>
</html>
```

## Cara Integrasi
Quantity selector menggunakan batas minimum 1 dan maksimum stok. Tombol minus/plus disabled saat mencapai batas. Hitung total harga otomatis.
