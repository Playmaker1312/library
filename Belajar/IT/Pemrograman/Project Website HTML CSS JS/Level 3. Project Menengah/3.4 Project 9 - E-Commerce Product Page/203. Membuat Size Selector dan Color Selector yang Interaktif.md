# 203. Membuat Size Selector dan Color Selector yang Interaktif

## Definisi & Target
Selector untuk ukuran dan warna produk. Target: Tombol ukuran dan warna yang bisa dipilih (toggle aktif).

## Analogi Alur
Seperti memilih topping untuk es krim — Anda bisa memilih ukuran cone dan rasa (warna) yang diinginkan.

## Poin-Poin Penting
- Size selector: tombol-tombol ukuran (S, M, L, XL)
- Color selector: lingkaran/bulat warna
- Tandai pilihan aktif dengan border/background
- Validasi: warna dan ukuran harus dipilih sebelum add to cart

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Size & Color Selector</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f8fafc; display: flex; align-items: center; justify-content: center; min-height: 100vh; padding: 20px; }
    .selector-card { max-width: 400px; width: 100%; background: #fff; padding: 40px; border-radius: 20px; border: 1px solid #e2e8f0; }
    .selector-card h2 { font-size: 24px; color: #1e293b; margin-bottom: 8px; }
    .selector-card p { color: #64748b; margin-bottom: 24px; }
    .option-group { margin-bottom: 24px; }
    .option-group h3 { font-size: 14px; color: #1e293b; margin-bottom: 10px; font-weight: 600; }
    .option-group h3 .selected-value { color: #64748b; font-weight: 400; }
    .size-options { display: flex; gap: 10px; }
    .size-btn { width: 52px; height: 52px; border: 2px solid #e2e8f0; border-radius: 10px; background: #fff; cursor: pointer; font-size: 15px; font-weight: 600; color: #475569; transition: all 0.2s; }
    .size-btn:hover { border-color: #2563eb; color: #2563eb; }
    .size-btn.active { border-color: #2563eb; background: #eff6ff; color: #2563eb; }
    .color-options { display: flex; gap: 12px; }
    .color-btn { width: 40px; height: 40px; border-radius: 50%; border: 3px solid transparent; cursor: pointer; transition: all 0.2s; position: relative; }
    .color-btn:hover { transform: scale(1.1); }
    .color-btn.active { border-color: #2563eb; box-shadow: 0 0 0 3px rgba(37,99,235,0.2); }
    .color-btn.active::after { content: '✓'; position: absolute; inset: 0; display: flex; align-items: center; justify-content: center; color: #fff; font-size: 16px; font-weight: 700; }
    .btn-cart { width: 100%; padding: 16px; background: #2563eb; color: #fff; border: none; border-radius: 12px; font-size: 16px; font-weight: 600; cursor: pointer; transition: background 0.3s; }
    .btn-cart:hover { background: #1d4ed8; }
    .btn-cart:disabled { background: #94a3b8; cursor: not-allowed; }
    .selection-preview { margin: 20px 0; padding: 16px; background: #f8fafc; border-radius: 10px; font-size: 14px; color: #475569; }
    .error-msg { color: #ef4444; font-size: 13px; margin-top: 8px; display: none; }
  </style>
</head>
<body>
  <div class="selector-card">
    <h2>Sepatu Running Pro</h2>
    <p>Pilih ukuran dan warna yang diinginkan.</p>
    <div class="option-group">
      <h3>Ukuran <span class="selected-value" id="sizeLabel">—</span></h3>
      <div class="size-options">
        <button class="size-btn" onclick="selectSize(this, '39')">39</button>
        <button class="size-btn" onclick="selectSize(this, '40')">40</button>
        <button class="size-btn" onclick="selectSize(this, '41')">41</button>
        <button class="size-btn" onclick="selectSize(this, '42')">42</button>
        <button class="size-btn" onclick="selectSize(this, '43')">43</button>
        <button class="size-btn" onclick="selectSize(this, '44')">44</button>
      </div>
    </div>
    <div class="option-group">
      <h3>Warna <span class="selected-value" id="colorLabel">—</span></h3>
      <div class="color-options">
        <button class="color-btn" style="background:#1e293b;" onclick="selectColor(this, 'Hitam')"></button>
        <button class="color-btn" style="background:#f8fafc;border-color:#e2e8f0;" onclick="selectColor(this, 'Putih')" data-border="true"></button>
        <button class="color-btn" style="background:#2563eb;" onclick="selectColor(this, 'Biru')"></button>
        <button class="color-btn" style="background:#dc2626;" onclick="selectColor(this, 'Merah')"></button>
        <button class="color-btn" style="background:#059669;" onclick="selectColor(this, 'Hijau')"></button>
      </div>
    </div>
    <div class="selection-preview" id="preview">Pilih ukuran dan warna untuk melanjutkan.</div>
    <div class="error-msg" id="errorMsg">Silakan pilih ukuran dan warna terlebih dahulu.</div>
    <button class="btn-cart" id="addToCartBtn" disabled>Pilih Opsi Terlebih Dahulu</button>
  </div>
  <script>
    let selectedSize = null;
    let selectedColor = null;
    function selectSize(btn, size) {
      document.querySelectorAll('.size-btn').forEach(b => b.classList.remove('active'));
      btn.classList.add('active');
      selectedSize = size;
      document.getElementById('sizeLabel').textContent = size;
      updateSelection();
    }
    function selectColor(btn, color) {
      document.querySelectorAll('.color-btn').forEach(b => b.classList.remove('active'));
      btn.classList.add('active');
      selectedColor = color;
      document.getElementById('colorLabel').textContent = color;
      updateSelection();
    }
    function updateSelection() {
      const btn = document.getElementById('addToCartBtn');
      const preview = document.getElementById('preview');
      const error = document.getElementById('errorMsg');
      if (selectedSize && selectedColor) {
        btn.disabled = false;
        btn.textContent = '+ Keranjang';
        preview.textContent = `Ukuran: ${selectedSize} | Warna: ${selectedColor}`;
        error.style.display = 'none';
      } else {
        btn.disabled = true;
        btn.textContent = 'Pilih Opsi Terlebih Dahulu';
        preview.textContent = 'Pilih ukuran dan warna untuk melanjutkan.';
      }
    }
  </script>
</body>
</html>
```

## Cara Integrasi
Size dan color selector adalah komponen wajib di product page. Validasi memastikan pengguna memilih kedua opsi sebelum add to cart.
