# 197. Membuat Data Produk dalam Format JavaScript Object yang Lengkap

## Definisi & Target
Data produk disimpan dalam JavaScript object. Target: Struktur data produk dengan properti lengkap untuk semua kebutuhan.

## Analogi Alur
Seperti katalog produk — setiap barang memiliki data: nama, harga, ukuran, warna, stok, deskripsi, gambar, dan lainnya.

## Poin-Poin Penting
- Properti: id, name, price, images, sizes, colors, description, specs, reviews, stock
- Data bisa langsung digunakan oleh semua komponen
- Gunakan array untuk multiple values (gambar, ukuran)
- Hitung diskon dan harga setelah diskon

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Data Produk</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f8fafc; padding: 40px 20px; }
    .container { max-width: 900px; margin: 0 auto; }
    h1 { color: #1e293b; margin-bottom: 8px; }
    .subtitle { color: #64748b; margin-bottom: 30px; }
    .data-view { background: #1e293b; color: #e2e8f0; padding: 25px; border-radius: 12px; font-family: monospace; font-size: 13px; line-height: 1.6; overflow-x: auto; margin-bottom: 30px; max-height: 300px; overflow-y: auto; }
    .product-display { background: #fff; border-radius: 16px; padding: 30px; border: 1px solid #e2e8f0; display: flex; gap: 30px; }
    .product-display .icon { font-size: 80px; background: #f8fafc; padding: 30px; border-radius: 16px; }
    .product-display .detail h2 { color: #1e293b; margin-bottom: 8px; }
    .product-display .detail .price { font-size: 24px; font-weight: 800; color: #2563eb; margin-bottom: 8px; }
    .product-display .detail .price .original { font-size: 16px; color: #94a3b8; text-decoration: line-through; margin-left: 10px; }
    .product-display .detail .badge { display: inline-block; padding: 4px 12px; border-radius: 50px; font-size: 12px; font-weight: 600; margin: 4px; }
    .product-display .detail .badge.blue { background: #eff6ff; color: #2563eb; }
    .product-display .detail .badge.green { background: #ecfdf5; color: #065f46; }
    .product-display .detail .badge.red { background: #fef2f2; color: #991b1b; }
    .product-display .detail p { color: #64748b; line-height: 1.6; margin: 12px 0; }
    .product-display .detail .info-grid { display: grid; grid-template-columns: 1fr 1fr; gap: 8px; }
    .product-display .detail .info-grid .item { font-size: 14px; color: #475569; }
  </style>
</head>
<body>
  <div class="container">
    <h1>Data Produk (JavaScript Object)</h1>
    <p class="subtitle">Data produk disimpan sebagai object dengan properti lengkap.</p>
    <div class="data-view" id="dataView"></div>
    <div class="product-display">
      <div class="icon" id="productIcon">👟</div>
      <div class="detail" id="productDetail"></div>
    </div>
  </div>
  <script>
    const product = {
      id: 1,
      name: 'Sepatu Running Pro Max',
      brand: 'SportPro',
      price: 299000,
      originalPrice: 399000,
      currency: 'Rp',
      discount: 25,
      images: ['👟', '👟', '👟'],
      sizes: [39, 40, 41, 42, 43, 44],
      colors: [
        { name: 'Hitam', hex: '#1e293b' },
        { name: 'Putih', hex: '#f8fafc' },
        { name: 'Biru', hex: '#2563eb' }
      ],
      category: 'Sepatu Olahraga',
      tags: ['running', 'olahraga', 'sepatu'],
      description: 'Sepatu running dengan teknologi cushioning ProFoam yang memberikan kenyamanan maksimal saat berlari. Sol karet anti-slip dan upper mesh breathable.',
      specs: { 'Berat': '250g', 'Material': 'Mesh + Synthetic', 'Sole': 'Rubber', 'Closure': 'Lace-up' },
      rating: 4.5,
      reviewCount: 128,
      inStock: true,
      stock: 45,
      sku: 'SP-RUN-001'
    };
    document.getElementById('dataView').textContent = JSON.stringify(product, null, 2);
    const detail = document.getElementById('productDetail');
    const discount = Math.round((1 - product.price / product.originalPrice) * 100);
    detail.innerHTML = `
      <h2>${product.name}</h2>
      <div class="price">${product.currency}${product.price.toLocaleString()} <span class="original">${product.currency}${product.originalPrice.toLocaleString()}</span></div>
      <div><span class="badge green">${discount}% OFF</span><span class="badge blue">${product.category}</span>${product.inStock ? '<span class="badge green">In Stock</span>' : '<span class="badge red">Out of Stock</span>'}</div>
      <p>${product.description}</p>
      <div class="info-grid">${Object.entries(product.specs).map(([k, v]) => `<div class="item"><strong>${k}:</strong> ${v}</div>`).join('')}</div>
      <div style="margin-top:12px;font-size:14px;color:#475569;">Rating: ${'★'.repeat(Math.floor(product.rating))}${product.rating % 1 ? '½' : ''} (${product.reviewCount} ulasan) | SKU: ${product.sku}</div>
    `;
  </script>
</body>
</html>
```

## Cara Integrasi
Simpan data produk di file JavaScript terpisah (e.g., `product.js`). Gunakan langsung di seluruh komponen product page. Tambahkan properti baru sesuai kebutuhan.
