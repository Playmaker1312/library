# 222. Mengimplementasikan Fitur Search pada Data Table

## Definisi & Target
Fitur search memungkinkan pengguna memfilter baris tabel berdasarkan kata kunci. Target: input pencarian yang menyaring data secara real-time saat pengguna mengetik.

## Analogi Alur
Seperti kotak pencarian di kontak HP — semakin spesifik kata kunci, semakin sedikit hasil yang muncul. JavaScript membandingkan input dengan setiap baris dan menyembunyikan yang tidak cocok.

## Poin-Poin Penting
- Gunakan input `<input type="text" id="searchInput">` dengan event `keyup` atau `input`
- Filter array asli dengan `Array.prototype.filter()` dan `String.prototype.includes()`
- Lakukan pencarian case-insensitive dengan `.toLowerCase()`
- Render ulang tabel setiap kali nilai input berubah

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Data Table dengan Search</title>
  <style>
    body { font-family: Arial, sans-serif; display: flex; justify-content: center; padding: 40px 20px; margin: 0; background: #f0f2f5; }
    .table-container { width: 800px; max-width: 100%; background: #fff; padding: 24px; border-radius: 16px; box-shadow: 0 6px 20px rgba(0,0,0,0.08); }
    h2 { margin-top: 0; color: #333; }
    .search-bar { margin-bottom: 16px; }
    .search-bar input { width: 100%; padding: 10px 16px; border: 1px solid #ccc; border-radius: 8px; font-size: 15px; box-sizing: border-box; outline: none; }
    .search-bar input:focus { border-color: #4e79a7; box-shadow: 0 0 0 3px rgba(78,121,167,0.15); }
    table { width: 100%; border-collapse: collapse; }
    th, td { padding: 12px 16px; text-align: left; border-bottom: 1px solid #e0e0e0; }
    th { background: #f8f9fa; font-weight: 600; color: #555; }
    tr:hover { background: #f5f7fa; }
    .no-result { text-align: center; padding: 24px; color: #888; }
  </style>
</head>
<body>
  <div class="table-container">
    <h2>Data Produk</h2>
    <div class="search-bar">
      <input type="text" id="searchInput" placeholder="Cari produk...">
    </div>
    <table>
      <thead>
        <tr><th>ID</th><th>Nama Produk</th><th>Kategori</th><th>Harga</th></tr>
      </thead>
      <tbody id="tableBody"></tbody>
    </table>
  </div>
  <script>
    const products = [
      { id: 1, name: 'Laptop ThinkPad', category: 'Elektronik', price: 12000000 },
      { id: 2, name: 'Mouse Wireless', category: 'Aksesoris', price: 150000 },
      { id: 3, name: 'Monitor 24 Inch', category: 'Elektronik', price: 2500000 },
      { id: 4, name: 'Keyboard Mechanical', category: 'Aksesoris', price: 450000 },
      { id: 5, name: 'Webcam HD', category: 'Elektronik', price: 350000 },
      { id: 6, name: 'USB Hub 4 Port', category: 'Aksesoris', price: 85000 },
      { id: 7, name: 'Meja Gaming', category: 'Furnitur', price: 1800000 }
    ];

    function renderTable(data) {
      const tbody = document.getElementById('tableBody');
      if (data.length === 0) {
        tbody.innerHTML = '<tr><td colspan="4" class="no-result">Tidak ada hasil ditemukan</td></tr>';
        return;
      }
      tbody.innerHTML = data.map(p =>
        `<tr><td>${p.id}</td><td>${p.name}</td><td>${p.category}</td><td>Rp ${p.price.toLocaleString()}</td></tr>`
      ).join('');
    }

    document.getElementById('searchInput').addEventListener('keyup', function() {
      const keyword = this.value.toLowerCase().trim();
      const filtered = products.filter(p =>
        p.name.toLowerCase().includes(keyword) ||
        p.category.toLowerCase().includes(keyword) ||
        p.id.toString().includes(keyword)
      );
      renderTable(filtered);
    });

    renderTable(products);
  </script>
</body>
</html>
```

## Cara Integrasi
Tambahkan input search di atas tabel. Di event `keyup`, ambil nilai input, filter array data dengan `.filter()` dan `.includes()`. Render ulang tabel dengan hasil filter. Pastikan pencarian case-insensitive dengan `.toLowerCase()`. Gabungkan dengan sorting untuk fungsionalitas lengkap.
