# 223. Mengimplementasikan Pagination pada Data Table

## Definisi & Target
Pagination membagi data menjadi halaman-halaman untuk menghindari tabel terlalu panjang. Target: kontrol navigasi halaman (Previous, nomor, Next) dengan data per halaman yang bisa diatur.

## Analogi Alur
Seperti buku dengan banyak halaman — kita tidak membaca semua halaman sekaligus, cukup satu halaman per kali. Tombol Previous/Next dan nomor halaman membantu navigasi.

## Poin-Poin Penting
- Tentukan `itemsPerPage` (misal 5) dan hitung total halaman
- Gunakan `.slice(start, end)` untuk mengambil data per halaman
- Render tombol nomor halaman secara dinamis
- Nonaktifkan tombol Previous di halaman pertama, Next di halaman terakhir
- Update tampilan info "Halaman X dari Y"

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Data Table dengan Pagination</title>
  <style>
    body { font-family: Arial, sans-serif; display: flex; justify-content: center; padding: 40px 20px; margin: 0; background: #f0f2f5; }
    .table-container { width: 800px; max-width: 100%; background: #fff; padding: 24px; border-radius: 16px; box-shadow: 0 6px 20px rgba(0,0,0,0.08); }
    h2 { margin-top: 0; color: #333; }
    table { width: 100%; border-collapse: collapse; }
    th, td { padding: 12px 16px; text-align: left; border-bottom: 1px solid #e0e0e0; }
    th { background: #f8f9fa; font-weight: 600; color: #555; }
    tr:hover { background: #f5f7fa; }
    .pagination { display: flex; justify-content: space-between; align-items: center; margin-top: 16px; flex-wrap: wrap; gap: 8px; }
    .page-info { color: #666; font-size: 14px; }
    .page-buttons { display: flex; gap: 4px; }
    .page-btn { padding: 6px 14px; border: 1px solid #ccc; background: #fff; border-radius: 6px; cursor: pointer; font-size: 14px; }
    .page-btn:hover:not(:disabled) { background: #eef1f5; }
    .page-btn.active { background: #4e79a7; color: #fff; border-color: #4e79a7; }
    .page-btn:disabled { opacity: 0.5; cursor: not-allowed; }
  </style>
</head>
<body>
  <div class="table-container">
    <h2>Data Transaksi</h2>
    <table>
      <thead>
        <tr><th>ID</th><th>Pelanggan</th><th>Produk</th><th>Total</th><th>Status</th></tr>
      </thead>
      <tbody id="tableBody"></tbody>
    </table>
    <div class="pagination">
      <span class="page-info" id="pageInfo"></span>
      <div class="page-buttons" id="pageButtons"></div>
    </div>
  </div>
  <script>
    const transactions = [
      { id: 1, customer: 'Budi', product: 'Laptop', total: 12000000, status: 'Selesai' },
      { id: 2, customer: 'Ani', product: 'Mouse', total: 150000, status: 'Diproses' },
      { id: 3, customer: 'Citra', product: 'Monitor', total: 2500000, status: 'Selesai' },
      { id: 4, customer: 'Dedi', product: 'Keyboard', total: 450000, status: 'Dikirim' },
      { id: 5, customer: 'Eko', product: 'Webcam', total: 350000, status: 'Diproses' },
      { id: 6, customer: 'Fina', product: 'USB Hub', total: 85000, status: 'Selesai' },
      { id: 7, customer: 'Gilang', product: 'Meja', total: 1800000, status: 'Dikirim' },
      { id: 8, customer: 'Hana', product: 'Laptop', total: 13500000, status: 'Diproses' },
      { id: 9, customer: 'Indra', product: 'Mouse', total: 200000, status: 'Selesai' },
      { id: 10, customer: 'Joko', product: 'Headset', total: 500000, status: 'Dikirim' },
      { id: 11, customer: 'Karin', product: 'Printer', total: 3200000, status: 'Diproses' },
      { id: 12, customer: 'Lutfi', product: 'Speaker', total: 750000, status: 'Selesai' }
    ];

    const itemsPerPage = 5;
    let currentPage = 1;

    function renderTable(data) {
      document.getElementById('tableBody').innerHTML = data.map(t =>
        `<tr><td>${t.id}</td><td>${t.customer}</td><td>${t.product}</td><td>Rp ${t.total.toLocaleString()}</td><td>${t.status}</td></tr>`
      ).join('');
    }

    function renderPagination() {
      const totalPages = Math.ceil(transactions.length / itemsPerPage);
      const start = (currentPage - 1) * itemsPerPage;
      const end = start + itemsPerPage;
      renderTable(transactions.slice(start, end));

      document.getElementById('pageInfo').textContent = `Halaman ${currentPage} dari ${totalPages} (${transactions.length} data)`;

      const btnContainer = document.getElementById('pageButtons');
      btnContainer.innerHTML = '';

      const prevBtn = document.createElement('button');
      prevBtn.className = 'page-btn';
      prevBtn.textContent = '‹ Prev';
      prevBtn.disabled = currentPage === 1;
      prevBtn.addEventListener('click', () => { if (currentPage > 1) { currentPage--; renderPagination(); } });
      btnContainer.appendChild(prevBtn);

      for (let i = 1; i <= totalPages; i++) {
        const btn = document.createElement('button');
        btn.className = `page-btn ${i === currentPage ? 'active' : ''}`;
        btn.textContent = i;
        btn.addEventListener('click', () => { currentPage = i; renderPagination(); });
        btnContainer.appendChild(btn);
      }

      const nextBtn = document.createElement('button');
      nextBtn.className = 'page-btn';
      nextBtn.textContent = 'Next ›';
      nextBtn.disabled = currentPage === totalPages;
      nextBtn.addEventListener('click', () => { if (currentPage < totalPages) { currentPage++; renderPagination(); } });
      btnContainer.appendChild(nextBtn);
    }

    renderPagination();
  </script>
</body>
</html>
```

## Cara Integrasi
Tentukan `itemsPerPage`. Hitung `totalPages = Math.ceil(data.length / itemsPerPage)`. Gunakan `data.slice((page-1)*itemsPerPage, page*itemsPerPage)` untuk potongan data. Render tombol nomor untuk setiap halaman. Aktifkan/nonaktifkan Previous dan Next sesuai posisi halaman. Gabungkan dengan search dan sorting untuk tabel yang powerfull.
