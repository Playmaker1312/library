# 219. Membuat Line Chart untuk Data Tren Menggunakan Chart.js

## Definisi & Target
Line chart menghubungkan titik data dengan garis, ideal untuk menunjukkan tren dari waktu ke waktu. Target: menampilkan tren pengunjung website selama 6 bulan terakhir.

## Analogi Alur
Seperti grafik心电图 — titik-titik data dihubungkan garis naik-turun yang menunjukkan pola perubahan. Semakin curam garis, semakin besar perubahannya.

## Poin-Poin Penting
- `type: 'line'` untuk line chart
- Gunakan `tension: 0.3` untuk garis melengkung smooth
- `fill: true` mengisi area di bawah garis dengan warna transparan
- `pointRadius` mengatur ukuran titik data

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Line Chart Tren</title>
  <script src="https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js"></script>
  <style>
    body { font-family: Arial, sans-serif; display: flex; justify-content: center; align-items: center; min-height: 100vh; margin: 0; background: #f0f2f5; }
    .chart-card { width: 700px; max-width: 95%; background: #fff; padding: 24px; border-radius: 16px; box-shadow: 0 6px 20px rgba(0,0,0,0.08); }
    h2 { margin-top: 0; color: #333; }
  </style>
</head>
<body>
  <div class="chart-card">
    <h2>Tren Pengunjung Website</h2>
    <canvas id="trendChart"></canvas>
  </div>
  <script>
    const ctx = document.getElementById('trendChart').getContext('2d');
    new Chart(ctx, {
      type: 'line',
      data: {
        labels: ['Jan', 'Feb', 'Mar', 'Apr', 'Mei', 'Jun'],
        datasets: [{
          label: 'Pengunjung',
          data: [1200, 1900, 1700, 2100, 2400, 2800],
          borderColor: '#4e79a7',
          backgroundColor: 'rgba(78, 121, 167, 0.15)',
          fill: true,
          tension: 0.3,
          pointRadius: 5,
          pointBackgroundColor: '#4e79a7',
          borderWidth: 3
        }]
      },
      options: {
        responsive: true,
        plugins: { legend: { display: true, position: 'top' } },
        scales: {
          y: { beginAtZero: true, title: { display: true, text: 'Jumlah Pengunjung' } },
          x: { title: { display: true, text: 'Bulan' } }
        }
      }
    });
  </script>
</body>
</html>
```

## Cara Integrasi
Siapkan data array untuk sumbu X (waktu) dan Y (nilai). Set `type: 'line'` dan atur `tension` sesuai preferensi kelengkungan. Aktifkan `fill` untuk area gradient. Tempatkan di dashboard bagian ringkasan performa.
