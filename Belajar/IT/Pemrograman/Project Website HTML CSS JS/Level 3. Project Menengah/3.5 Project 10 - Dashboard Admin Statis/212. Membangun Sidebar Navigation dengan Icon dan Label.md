# 212. Membangun Sidebar Navigation dengan Icon dan Label

## Definisi & Target
Sidebar navigation berisi menu dengan icon dan label. Target: Navigasi vertikal dengan icon dan teks menu.

## Analogi Alur
Seperti daftar isi di buku — setiap bab (menu) memiliki nomor (icon) dan judul (label).

## Poin-Poin Penting
- Menu items: icon + label
- Hover dan active state
- Item aktif ditandai dengan background atau border
- Bisa ditambahkan badge untuk notifikasi

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html

<html lang="id">

  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Sidebar Navigation</title>

  <script>
    document.querySelectorAll('.sidebar nav a').forEach(link => {
      link.addEventListener('click', (e) => {
        e.preventDefault();
        document.querySelectorAll('.sidebar nav a').forEach(a => a.classList.remove('active'));
```

## Cara Integrasi
Sidebar navigation adalah komponen tetap di dashboard. Gunakan icon yang konsisten. Badge untuk notifikasi atau jumlah item. Bagian bawah untuk profil pengguna.
