# 211. Merencanakan Layout Dashboard dengan Sidebar, Topbar, dan Main Content Area

## Definisi & Target
Layout dashboard admin terdiri dari sidebar, topbar, dan area konten utama. Target: Layout grid dengan tiga area utama.

## Analogi Alur
Seperti meja kerja — di sebelah kiri ada laci (sidebar navigasi), di atas ada kalender dan alat tulis (topbar), di tengah ada kertas kerja (main content).

## Poin-Poin Penting
- Sidebar: navigasi menu di kiri (fixed)
- Topbar: header dengan search, notifikasi, profil
- Main content: area konten utama yang scrollable
- Layout responsive: sidebar collapse di mobile
