# 218. Membuat Bar Chart untuk Data Penjualan Bulanan Menggunakan Chart.js

## Definisi & Target
Bar chart menampilkan data dalam batang vertikal/horizontal. Target: menampilkan data penjualan 12 bulan dengan batang berwarna dan label sumbu.

## Analogi Alur
Bayangkan diagram batang di excel — setiap bulan punya balok yang tingginya mewakili nilai penjualan. Chart.js menggambar semua balok itu dari array data.

## Poin-Poin Penting
- `type: 'bar'` untuk bar chart vertikal, `'horizontalBar'` (sebelum v3) atau gunakan `indexAxis: 'y'` di v3+
- Gunakan `labels` array untuk sumbu X dan `data` array untuk nilai
- Atur `backgroundColor` dengan array untuk warna berbeda tiap batang
- Manfaatkan `scales.y.beginAtZero: true` agar grafik dimulai dari nol

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Bar Chart Penjualan</title>
  <script src="https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js"></script>
  <style>
    body { font-family: Arial, sans-serif; display: flex; justify-content: center; align-items: center; min-height: 100vh; margin: 0; background: #f0f2f5; }
    .chart-card { width: 700px; max-width: 95%; background: #fff; padding: 24px; border-radius: 16px; box-shadow: 0 6px 20px rgba(0,0,0,0.08); }
    h2 { margin-top: 0; color: #333; }
  </style>
</head>
<body>
  <div class="chart-card">
    <h2>Penjualan Bulanan (2025)</h2>
    <canvas id="salesChart"></canvas>
  </div>
  <script>
    const months = ['Jan','Feb','Mar','Apr','Mei','Jun','Jul','Agu','Sep','Okt','Nov','Des'];
    const salesData = [45, 52, 38, 60, 55, 70, 80, 75, 62, 58, 48, 65];
    const colors = ['#4e79a7','#f28e2b','#e15759','#76b7b2','#59a14f','#edc948','#b07aa1','#ff9da7','#9c755f','#bab0ac','#4e79a7','#f28e2b'];

    const ctx = document.getElementById('salesChart').getContext('2d');
    new Chart(ctx, {
      type: 'bar',
      data: {
        labels: months,
        datasets: [{
          label: 'Penjualan (unit)',
          data: salesData,
          backgroundColor: colors,
          borderColor: '#fff',
          borderWidth: 2,
          borderRadius: 4
        }]
      },
      options: {
        responsive: true,
        plugins: { legend: { display: false } },
        scales: {
          y: { beginAtZero: true, title: { display: true, text: 'Unit Terjual' } },
          x: { title: { display: true, text: 'Bulan' } }
        }
      }
    });
  </script>
</body>
</html>
```

## Cara Integrasi
Siapkan array `labels` (bulan) dan `data` (nilai penjualan). Inisialisasi chart dengan `type: 'bar'`. Set `beginAtZero: true` pada sumbu Y. Masukkan ke dalam card dashboard. Ganti angka `salesData` dengan data dari API atau database.
