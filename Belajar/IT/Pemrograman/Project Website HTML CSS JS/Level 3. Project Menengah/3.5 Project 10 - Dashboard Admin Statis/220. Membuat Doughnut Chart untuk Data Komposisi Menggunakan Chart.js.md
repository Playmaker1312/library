# 220. Membuat Doughnut Chart untuk Data Komposisi Menggunakan Chart.js

## Definisi & Target
Doughnut chart (cincin) menampilkan proporsi data sebagai potongan lingkaran. Target: menampilkan komposisi sumber traffic website (organik, direct, referral, sosial media, email).

## Analogi Alur
Seperti pizza yang dipotong — setiap potongan mewakili bagian dari total keseluruhan. Lubang di tengah membedakan doughnut dari pie chart biasa.

## Poin-Poin Penting
- `type: 'doughnut'` untuk doughnut chart
- `cutout: '70%'` mengatur ketebalan cincin (semakin besar persen, semakin tipis)
- Gunakan array `backgroundColor` dengan palet warna kontras
- Tambahkan label di tengah menggunakan plugin atau `datalabels`

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Doughnut Chart Komposisi</title>
  <script src="https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js"></script>
  <style>
    body { font-family: Arial, sans-serif; display: flex; justify-content: center; align-items: center; min-height: 100vh; margin: 0; background: #f0f2f5; }
    .chart-card { width: 500px; max-width: 95%; background: #fff; padding: 24px; border-radius: 16px; box-shadow: 0 6px 20px rgba(0,0,0,0.08); text-align: center; }
    h2 { margin-top: 0; color: #333; }
    .legend { display: flex; flex-wrap: wrap; justify-content: center; gap: 12px; margin-top: 16px; }
    .legend-item { display: flex; align-items: center; gap: 6px; font-size: 14px; }
    .legend-color { width: 14px; height: 14px; border-radius: 4px; }
  </style>
</head>
<body>
  <div class="chart-card">
    <h2>Komposisi Sumber Traffic</h2>
    <canvas id="trafficChart"></canvas>
    <div class="legend" id="legendContainer"></div>
  </div>
  <script>
    const labels = ['Organik', 'Direct', 'Referral', 'Sosial Media', 'Email'];
    const data = [45, 25, 15, 10, 5];
    const colors = ['#4e79a7', '#f28e2b', '#e15759', '#76b7b2', '#59a14f'];

    const ctx = document.getElementById('trafficChart').getContext('2d');
    new Chart(ctx, {
      type: 'doughnut',
      data: {
        labels: labels,
        datasets: [{
          data: data,
          backgroundColor: colors,
          borderColor: '#fff',
          borderWidth: 3
        }]
      },
      options: {
        responsive: true,
        cutout: '70%',
        plugins: { legend: { display: false } }
      }
    });

    const legendContainer = document.getElementById('legendContainer');
    labels.forEach((label, i) => {
      const item = document.createElement('div');
      item.className = 'legend-item';
      item.innerHTML = `<span class="legend-color" style="background:${colors[i]}"></span> ${label} (${data[i]}%)`;
      legendContainer.appendChild(item);
    });
  </script>
</body>
</html>
```

## Cara Integrasi
Siapkan data proporsi dan labels. Set `type: 'doughnut'` dengan `cutout` untuk ketebalan cincin. Sembunyikan legend bawaan dan buat legend kustom jika perlu. Cocok untuk card ringkasan di dashboard.
