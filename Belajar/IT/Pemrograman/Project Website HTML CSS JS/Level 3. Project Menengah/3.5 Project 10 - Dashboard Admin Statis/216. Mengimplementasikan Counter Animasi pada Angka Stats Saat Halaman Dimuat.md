# 216. Mengimplementasikan Counter Animasi pada Angka Stats Saat Halaman Dimuat

## Definisi & Target
Counter animasi membuat angka stats naik dari 0 ke target. Target: Animasi increment number saat halaman pertama dimuat.

## Analogi Alur
Seperti meteran listrik yang berputar cepat — angka berjalan dari 0 hingga mencapai nilai sebenarnya.

## Poin-Poin Penting
- Ambil nilai target dari atribut data atau dari angka
- Increment dengan interval tertentu
- Animasi berhenti saat mencapai target
- Bisa dipicu saat elemen terlihat (Intersection Observer)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Counter Animation</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #0f172a; min-height: 100vh; display: flex; align-items: center; justify-content: center; padding: 20px; }
    .container { max-width: 1000px; width: 100%; }
    h1 { text-align: center; color: #fff; margin-bottom: 60px; font-size: 32px; }
    h1 span { color: #3b82f6; }
    .counter-grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); gap: 30px; }
    .counter-card { text-align: center; background: #1e293b; padding: 40px 20px; border-radius: 16px; border: 1px solid #334155; }
    .counter-card .icon { font-size: 36px; margin-bottom: 16px; }
    .counter-card .number { font-size: 44px; font-weight: 800; color: #fff; line-height: 1; }
    .counter-card .number .suffix { font-size: 24px; }
    .counter-card .label { color: #94a3b8; font-size: 14px; margin-top: 8px; }
    .counter-card .plus { color: #3b82f6; font-size: 24px; vertical-align: super; }
    .replay-btn { display: block; margin: 40px auto 0; padding: 12px 32px; background: #3b82f6; color: #fff; border: none; border-radius: 10px; cursor: pointer; font-size: 15px; font-weight: 600; }
    .replay-btn:hover { background: #2563eb; }
  </style>
</head>
<body>
  <div class="container">
    <h1><span>Counter</span> Animation</h1>
    <div class="counter-grid" id="counterGrid">
      <div class="counter-card"><div class="icon">💰</div><div class="number"><span class="counter-value" data-target="45200">0</span></div><div class="label">Total Revenue (K)</div></div>
      <div class="counter-card"><div class="icon">👥</div><div class="number"><span class="counter-value" data-target="3580">0</span></div><div class="label">Total Customers</div></div>
      <div class="counter-card"><div class="icon">📦</div><div class="number"><span class="counter-value" data-target="1245">0</span></div><div class="label">Orders Completed</div></div>
      <div class="counter-card"><div class="icon">⭐</div><div class="number"><span class="counter-value" data-target="98">0</span><span class="suffix">%</span></div><div class="label">Satisfaction Rate</div></div>
    </div>
    <button class="replay-btn" onclick="replayAnimation()">Replay Animation</button>
  </div>
  <script>
    let countersAnimated = false;
    function animateCounters() {
      if (countersAnimated) return;
      countersAnimated = true;
      document.querySelectorAll('.counter-value').forEach(el => {
        const target = parseInt(el.dataset.target);
        const duration = 2000;
        const startTime = performance.now();
        function update(currentTime) {
          const elapsed = currentTime - startTime;
          const progress = Math.min(elapsed / duration, 1);
          const eased = 1 - Math.pow(1 - progress, 3);
          const current = Math.floor(eased * target);
          el.textContent = current.toLocaleString();
          if (progress < 1) requestAnimationFrame(update);
          else el.textContent = target.toLocaleString();
        }
        requestAnimationFrame(update);
      });
    }
    function replayAnimation() {
      countersAnimated = false;
      document.querySelectorAll('.counter-value').forEach(el => el.textContent = '0');
      animateCounters();
    }
    const observer = new IntersectionObserver((entries) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) { animateCounters(); observer.unobserve(entry.target); }
      });
    }, { threshold: 0.3 });
    observer.observe(document.getElementById('counterGrid'));
    setTimeout(() => { if (!countersAnimated) animateCounters(); }, 500);
  </script>
</body>
</html>
```

## Cara Integrasi
Counter animation menggunakan `requestAnimationFrame` untuk performa smooth. Target angka diambil dari `data-target` attribute. Gunakan Intersection Observer untuk trigger saat scroll.
