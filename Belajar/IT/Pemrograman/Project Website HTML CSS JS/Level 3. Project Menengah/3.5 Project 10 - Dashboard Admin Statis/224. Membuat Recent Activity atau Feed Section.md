# 224. Membuat Recent Activity atau Feed Section

## Definisi & Target
Recent activity menampilkan daftar aktivitas terbaru secara kronologis. Target: section dengan feed aktivitas yang menampilkan ikon, teks, dan timestamp untuk setiap item.

## Analogi Alur
Seperti timeline media sosial — setiap aktivitas adalah postingan singkat dengan ikon, keterangan, dan waktu kejadian. Pengguna bisa melihat riwayat terbaru sekilas.

## Poin-Poin Penting
- Gunakan struktur daftar vertikal dengan ikon/avatar, konten, dan waktu
- Urutkan data berdasarkan timestamp descending (terbaru di atas)
- Tambahkan warna ikon berbeda untuk tiap jenis aktivitas
- Gunakan CSS flexbox untuk layout yang rapi
- Format waktu relatif ("2 menit lalu") menggunakan library sederhana atau manual

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Recent Activity Feed</title>
  <style>
    body { font-family: Arial, sans-serif; display: flex; justify-content: center; padding: 40px 20px; margin: 0; background: #f0f2f5; }
    .feed-card { width: 500px; max-width: 100%; background: #fff; padding: 24px; border-radius: 16px; box-shadow: 0 6px 20px rgba(0,0,0,0.08); }
    h2 { margin-top: 0; color: #333; display: flex; align-items: center; gap: 8px; }
    h2::before { content: '⚡'; }
    .feed-item { display: flex; gap: 14px; padding: 14px 0; border-bottom: 1px solid #f0f0f0; }
    .feed-item:last-child { border-bottom: none; }
    .feed-icon { width: 40px; height: 40px; border-radius: 50%; display: flex; align-items: center; justify-content: center; font-size: 18px; flex-shrink: 0; }
    .feed-icon.new-user { background: #d4edda; }
    .feed-icon.purchase { background: #cce5ff; }
    .feed-icon.edit { background: #fff3cd; }
    .feed-icon.delete { background: #f8d7da; }
    .feed-icon.login { background: #e2e3f5; }
    .feed-content { flex: 1; }
    .feed-text { margin: 0 0 4px; color: #333; font-size: 14px; line-height: 1.4; }
    .feed-text strong { font-weight: 600; }
    .feed-time { color: #999; font-size: 12px; }
  </style>
</head>
<body>
  <div class="feed-card">
    <h2>Aktivitas Terbaru</h2>
    <div id="feedContainer"></div>
  </div>
  <script>
    const activities = [
      { type: 'new-user', icon: '👤', text: '<strong>Budi Santoso</strong> mendaftar sebagai anggota baru', time: new Date(Date.now() - 2*60000) },
      { type: 'purchase', icon: '🛒', text: '<strong>Ani Wijaya</strong> melakukan pembelian produk <strong>Laptop ThinkPad</strong>', time: new Date(Date.now() - 15*60000) },
      { type: 'edit', icon: '✏️', text: '<strong>Citra Dewi</strong> memperbarui profil perusahaan', time: new Date(Date.now() - 1*3600000) },
      { type: 'delete', icon: '🗑️', text: '<strong>Admin</strong> menghapus produk <strong>Mouse lama</strong>', time: new Date(Date.now() - 3*3600000) },
      { type: 'login', icon: '🔐', text: '<strong>Dedi Kurniawan</strong> login dari perangkat baru (Chrome/Windows)', time: new Date(Date.now() - 5*3600000) },
      { type: 'purchase', icon: '🛒', text: '<strong>Eko Prasetyo</strong> melakukan pembelian produk <strong>Monitor 24"</strong>', time: new Date(Date.now() - 8*3600000) },
      { type: 'new-user', icon: '👤', text: '<strong>Fina Amelia</strong> mendaftar sebagai anggota baru', time: new Date(Date.now() - 24*3600000) }
    ];

    function timeAgo(date) {
      const diff = Date.now() - date.getTime();
      const minutes = Math.floor(diff / 60000);
      if (minutes < 1) return 'Baru saja';
      if (minutes < 60) return `${minutes} menit lalu`;
      const hours = Math.floor(minutes / 60);
      if (hours < 24) return `${hours} jam lalu`;
      const days = Math.floor(hours / 24);
      return `${days} hari lalu`;
    }

    function renderFeed() {
      const container = document.getElementById('feedContainer');
      container.innerHTML = activities.map(a =>
        `<div class="feed-item">
          <div class="feed-icon ${a.type}">${a.icon}</div>
          <div class="feed-content">
            <p class="feed-text">${a.text}</p>
            <span class="feed-time">${timeAgo(a.time)}</span>
          </div>
        </div>`
      ).join('');
    }

    renderFeed();
  </script>
</body>
</html>
```

## Cara Integrasi
Buat array activity objects dengan `type`, `icon`, `text`, dan `time`. Render setiap item sebagai `feed-item` dengan ikon lingkaran berwarna sesuai tipe. Fungsi `timeAgo()` mengubah Date menjadi teks relatif. Tempatkan di sidebar kanan atau bagian bawah dashboard.
