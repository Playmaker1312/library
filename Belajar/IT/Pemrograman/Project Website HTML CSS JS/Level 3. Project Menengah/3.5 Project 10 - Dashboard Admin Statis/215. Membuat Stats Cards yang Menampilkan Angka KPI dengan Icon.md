# 215. Membuat Stats Cards yang Menampilkan Angka KPI dengan Icon

## Definisi & Target
Stats cards menampilkan Key Performance Indicators (KPI). Target: Card dengan icon, angka, label, dan perubahan (growth/decline).

## Analogi Alur
Seperti scoreboard di pertandingan — setiap card menunjukkan skor (KPI) untuk area tertentu: penjualan, pengguna, pesanan, dll.

## Poin-Poin Penting
- Card: icon, nilai angka, label, persentase perubahan
- Warna berbeda untuk setiap card
- Icon di pojok atau samping
- Class up (hijau) untuk naik, down (merah) untuk turun

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Stats Cards</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui, sans-serif; background: #f1f5f9; padding: 40px; }
    .container { max-width: 1200px; margin: 0 auto; }
    h1 { color: #1e293b; margin-bottom: 30px; font-size: 28px; }
    .stats-grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)); gap: 24px; }
    .stat-card { background: #fff; border-radius: 16px; padding: 24px; border: 1px solid #e2e8f0; transition: all 0.3s; }
    .stat-card:hover { transform: translateY(-4px); box-shadow: 0 12px 30px rgba(0,0,0,0.06); }
    .stat-card .top { display: flex; justify-content: space-between; align-items: flex-start; margin-bottom: 16px; }
    .stat-card .icon-wrap { width: 48px; height: 48px; border-radius: 12px; display: flex; align-items: center; justify-content: center; font-size: 22px; }
    .stat-card .label { font-size: 13px; color: #94a3b8; font-weight: 500; margin-bottom: 4px; }
    .stat-card .value { font-size: 30px; font-weight: 800; color: #1e293b; line-height: 1.2; }
    .stat-card .change { font-size: 13px; font-weight: 600; display: flex; align-items: center; gap: 4px; margin-top: 8px; }
    .stat-card .change.up { color: #10b981; }
    .stat-card .change.down { color: #ef4444; }
    .stat-card .change.neutral { color: #64748b; }
    .stat-card .period { font-size: 12px; color: #94a3b8; margin-top: 12px; border-top: 1px solid #f1f5f9; padding-top: 12px; }
  </style>
</head>
<body>
  <div class="container">
    <h1>Dashboard Overview</h1>
    <div class="stats-grid" id="statsGrid"></div>
  </div>
  <script>
    const stats = [
      { label: 'Total Revenue', value: 'Rp45.2M', icon: '💰', color: '#3b82f6', bg: '#eff6ff', change: '+12.5%', changeType: 'up', period: 'vs last month' },
      { label: 'Total Orders', value: '1,245', icon: '📦', color: '#10b981', bg: '#ecfdf5', change: '+8.2%', changeType: 'up', period: 'vs last month' },
      { label: 'Total Customers', value: '3,580', icon: '👥', color: '#8b5cf6', bg: '#f5f3ff', change: '+5.7%', changeType: 'up', period: 'vs last month' },
      { label: 'Conversion Rate', value: '3.24%', icon: '📈', color: '#f59e0b', bg: '#fef3c7', change: '-0.8%', changeType: 'down', period: 'vs last month' },
      { label: 'Avg Order Value', value: 'Rp36.3K', icon: '🛒', color: '#ec4899', bg: '#fce7f3', change: '+2.1%', changeType: 'up', period: 'vs last month' },

    grid.innerHTML = stats.map(s => `
      <div class="stat-card">
        <div class="top">
          <div class="icon-wrap" style="background:${s.bg};color:${s.color};">${s.icon}</div>
          <span class="change ${s.changeType}">${s.changeType === 'up' ? '↑' : '↓'} ${s.change}</span>
        </div>
        <div class="label">${s.label}</div>
        <div class="value">${s.value}</div>
        <div class="period">${s.period}</div>
      </div>
    `).join('');
  </script>
</body>
</html>
```

## Cara Integrasi
Stats cards ditempatkan di halaman utama dashboard. Data bisa diubah secara dinamis. Warna icon dan background berbeda untuk setiap card untuk variasi visual.
