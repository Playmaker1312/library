# 221. Membangun Data Table dengan Sorting Menggunakan JavaScript

## Definisi & Target
Data table dengan sorting memungkinkan pengguna mengurutkan data berdasarkan kolom (ascending/descending). Target: membuat tabel dinamis dari array data dengan klik header untuk sorting.

## Analogi Alur
Seperti spreadsheet Excel — klik header kolom "Nama" maka data terurut A-Z, klik lagi menjadi Z-A. JavaScript mengatur ulang array lalu me-render ulang tabel.

## Poin-Poin Penting
- Simpan data dalam array of objects
- Buat fungsi `renderTable(data)` untuk menampilkan baris
- Gunakan method `.sort()` dengan comparator function
- Track state kolom dan arah sorting dengan variabel global
- Tambahkan indikator panah (▲/▼) di header

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Data Table dengan Sorting</title>
  <style>
    body { font-family: Arial, sans-serif; display: flex; justify-content: center; padding: 40px 20px; margin: 0; background: #f0f2f5; }
    .table-container { width: 800px; max-width: 100%; background: #fff; padding: 24px; border-radius: 16px; box-shadow: 0 6px 20px rgba(0,0,0,0.08); }
    h2 { margin-top: 0; color: #333; }
    table { width: 100%; border-collapse: collapse; }
    th, td { padding: 12px 16px; text-align: left; border-bottom: 1px solid #e0e0e0; }
    th { background: #f8f9fa; cursor: pointer; user-select: none; position: relative; font-weight: 600; color: #555; }
    th:hover { background: #eef1f5; }
    th .sort-icon { margin-left: 6px; font-size: 12px; }
    tr:hover { background: #f5f7fa; }
  </style>
</head>
<body>
  <div class="table-container">
    <h2>Data Pengguna</h2>
    <table id="dataTable">
      <thead>
        <tr>
          <th data-key="id" class="sortable">ID <span class="sort-icon"></span></th>
          <th data-key="name" class="sortable">Nama <span class="sort-icon"></span></th>
          <th data-key="email" class="sortable">Email <span class="sort-icon"></span></th>
          <th data-key="role" class="sortable">Role <span class="sort-icon"></span></th>
        </tr>
      </thead>
      <tbody id="tableBody"></tbody>
    </table>
  </div>
  <script>
    const users = [
      { id: 3, name: 'Budi Santoso', email: 'budi@mail.com', role: 'Admin' },
      { id: 1, name: 'Ani Wijaya', email: 'ani@mail.com', role: 'Editor' },
      { id: 4, name: 'Dedi Kurniawan', email: 'dedi@mail.com', role: 'User' },
      { id: 2, name: 'Citra Dewi', email: 'citra@mail.com', role: 'Admin' },
      { id: 5, name: 'Eko Prasetyo', email: 'eko@mail.com', role: 'User' }
    ];

    let currentSort = { key: 'id', asc: true };

    function renderTable(data) {
      const tbody = document.getElementById('tableBody');
      tbody.innerHTML = data.map(row =>
        `<tr><td>${row.id}</td><td>${row.name}</td><td>${row.email}</td><td>${row.role}</td></tr>`
      ).join('');
      document.querySelectorAll('th').forEach(th => {
        const key = th.dataset.key;
        const icon = th.querySelector('.sort-icon');
        if (key === currentSort.key) {
          icon.textContent = currentSort.asc ? ' ▲' : ' ▼';
        } else {
          icon.textContent = '';
        }
      });
    }

    function sortData(key) {
      if (currentSort.key === key) {
        currentSort.asc = !currentSort.asc;
      } else {
        currentSort.key = key;
        currentSort.asc = true;
      }
      const sorted = [...users].sort((a, b) => {
        const valA = a[key];
        const valB = b[key];
        if (valA < valB) return currentSort.asc ? -1 : 1;
        if (valA > valB) return currentSort.asc ? 1 : -1;
        return 0;
      });
      renderTable(sorted);
    }

    document.querySelectorAll('.sortable').forEach(th => {
      th.addEventListener('click', () => sortData(th.dataset.key));
    });

    renderTable(users);
  </script>
</body>
</html>
```

## Cara Integrasi
Gunakan array of objects sebagai sumber data. Pasang event listener `click` di setiap header kolom. Fungsi `sortData` mengurutkan array lalu memanggil `renderTable`. Tampilkan ikon panah untuk menunjukkan status sorting. Cocok untuk tabel pengguna, produk, atau transaksi.
