# 214. Membangun Topbar dengan Search Bar, Notification Bell, dan User Avatar

## Definisi & Target
Topbar dashboard berisi search, notifikasi, dan profil. Target: Header horizontal dengan komponen penting.

## Analogi Alur
Seperti dashboard mobil — di bagian atas ada speedometer (informasi), navigasi (search), dan indikator (notifikasi).

## Poin-Poin Penting
- Search bar dengan input dan icon
- Notification bell dengan badge jumlah
- User avatar dropdown (opsional)
- Breadcrumb atau page title

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
