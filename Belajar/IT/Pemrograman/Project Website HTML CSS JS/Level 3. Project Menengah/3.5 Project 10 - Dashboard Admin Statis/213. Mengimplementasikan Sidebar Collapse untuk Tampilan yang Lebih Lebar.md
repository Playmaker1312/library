# 213. Mengimplementasikan Sidebar Collapse untuk Tampilan yang Lebih Lebar

## Definisi & Target
Sidebar bisa di-collapse menjadi icon-only untuk menghemat ruang. Target: Toggle sidebar antara expanded dan collapsed.

## Analogi Alur
Seperti laci yang bisa didorong masuk — saat tidak perlu, sidebar "masuk" dan hanya menyisakan pegangan (icon).

## Poin-Poin Penting
- Tombol toggle untuk collapse/expand
- Saat collapsed: hanya icon, label disembunyikan
- Animasi transisi lebar sidebar
- State collapsed disimpan (opsional)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript


## Cara Integrasi
Sidebar collapse toggle disimpan di logo area. Saat collapsed, width sidebar mengecil dan label text disembunyikan. Icon tetap terlihat untuk navigasi cepat.
