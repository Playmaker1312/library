# 21. Tipe Data — Mengenal Jenis-Jenis Nilai

Setiap nilai di JavaScript punya "jenis", dan jenis itu menentukan apa yang bisa kamu lakukan padanya: teks bisa dipotong, angka bisa dihitung, dan daftar bisa diubah isinya. Materi ini mengupas tipe-tipe data dasar — primitive dan object — lengkap dengan cara memeriksa, mengubah, dan mengkombinasikannya lewat contoh dari katalog buku perpustakaan.

## 1. Penjelasan Singkat & Konsep Dasar

JavaScript adalah bahasa yang *dinamis*: variabel tidak perlu di-deklarasi jenisnya dan bisa berpindah jenis. Tapi di balik kebebasan itu, setiap nilai tetap punya satu tipe yang menentukan perilakunya. Ada dua keluarga besar tipe data: **primitive** dan **object**.

**Tipe primitive** adalah nilai tunggal, sederhana, dan "direplikasi saat disalin". Empat yang paling sering dipakai:

- **string**: teks, ditulis dengan `"..."`, `'...'`, atau backtick `` `...` `` — misal `"Clean Code"`.
- **number**: angka, tidak ada pemisahan int/float — `150000`, `4.8`, `-5` semuanya number.
- **boolean**: hanya `true` atau `false`, dipakai untuk pengambilan keputusan (`true` = tersedia, `false` = habis).
- **`null`** dan **`undefined`**: dua "tidak ada" yang berbeda. `null` adalah *nilai kosong yang disengaja* (kamu sendiri yang mengisi), sedangkan `undefined` berarti *belum pernah diisi* (JavaScript yang menetapkan).

Selain itu ada satu primitive lagi, `symbol` dan `bigint`, yang jarang dipakai di materi dasar. Sedangkan **object** adalah tipe "kumpulan" — objek literal `{}` untuk data berpasangan, dan **array** `[]` untuk daftar berurutan. Perbedaan penting: object/array disimpan sebagai **referensi**, jadi ketika kamu menyalinnya ke variabel lain, keduanya menunjuk data yang sama (kita sudah sentuh ini di materi 20 lewat konsep mutate).

Untuk melihat jenis nilai, pakai **`typeof`**. Ada quirk legendaris: `typeof null` mengembalikan `"object"` — ini bug lama yang sengaja dipertahankan agar situs lama tidak rusak, dan sampai hari ini pengembang hanya perlu mengingatnya. Sementara itu, `typeof []` juga `"object"`, jadi untuk membedakan array dari objek biasa kamu perlu `Array.isArray([])`.

Karena data di aplikasi sering berupa kombinasi tipe — daftar buku yang setiap bukunya objek berisi string, number, dan boolean — kemampuan memilih dan mengubah tipe dengan benar adalah inti hampir semua logika web.

**Benang merah**: Data yang tadinya hard-code di HTML (Level 1-3) kini hidup sebagai nilai-nilai JavaScript bertipe string, number, boolean, array, dan object. Materi ini membuatmu piawai membentuk dan mengubah "bahan baku" data katalog — yang di Level 5 akan dirender ke DOM.

## 2. Fungsi & Kegunaan Utama dalam Web

Di **Perpustakaan Digital Kota**, tipe data muncul di mana-mana:

- **string** — judul buku, nama pengarang, ISBN, kategori. Operasi string dipakai untuk normalisasi pencarian (huruf kecil), pemotongan judul panjang, atau substitusi istilah.
- **number** — harga, stok, tahun terbit, denda. Perhitungan diasuransikan: `Math.floor`/`Math.ceil` untuk pembulatan, dan `toLocaleString("id-ID")` untuk menampilkan harga sebagai `Rp 150.000`.
- **boolean** — ketersediaan (`stok > 0`), status anggota, checkbox filter "hanya yang tersedia".
- **object** — satu buku adalah objek (`{ judul, pengarang, harga, stok, kategori }`), dan **array of objects** (`katalog`) adalah daftar seluruh koleksinya. Semua pemrosesan katalog — filter, urutkan, cari, hitung total — beroperasi di struktur ini.
- **null/undefined** — menandai data yang belum ada (misal respons API yang kosong), dan menjadi dasar penggunaan nilai default (opsional chaining di materi 22).

Masalah yang diselesaikan: menormalisasi pencarian agar "CLEAN CODE" dan "clean code" cocok, memformat harga agar terbaca manusia (bukan `150000`), menghitung denda tanpa salah pembulatan, serta menyimpan koleksi ribuan buku dalam satu struktur yang bisa diiterasi dan dimodifikasi.

## 3. Contoh Kode & Implementasi Real-World

Materi ini luas, jadi contoh dibagi per tipe. Simpan sebagai `js/main.js` dan lihat hasil di Console.

// js/main.js — tipe data (materi 21)

// ─── Primitive Types ─────────────────────────────────────────────────────
const judul     = "Clean Code";        // string
const harga     = 150000;              // number (int/float tidak dibedakan)

const multiBaris = `

Pengarang: ${pengarang}

`;

const kataKunci = "   clean code   ";
console.log(kataKunci.trim());                       // "clean code" (hapus spasi kiri/kanan)
console.log("clean code".toUpperCase());             // "CLEAN CODE"
console.log("CLEAN CODE".toLowerCase());             // "clean code"

console.log("clean code".startsWith("clean"));       // true
console.log("clean code".endsWith("code"));          // true

const buku = {
    id: 1,
    judul: "Clean Code",
    pengarang: "Robert C. Martin",
    tahun: 2008,
    harga: 150000,
    stok: 5,
    kategori: "Teknologi",

console.log(buku["judul"]);  // akses bracket — berguna utk nama property dinamis

// Spread merge: gabungkan object, key yang sama di kanan menang
const bukuUpdate = { ...buku, stok: 3, rating: 4.5 };
console.log(bukuUpdate.stok, bukuUpdate.rating); // 3 4.5 (buku asli tetap utuh)

## 4. Analogi Sederhana — Membangun Rumah

Lanjut analogi rumah: **tipe data adalah jenis material listrik** yang kamu pakai di gedung.

- **string = kabel berwarna, berlabel.** Ukuran dan isinya teks; saat dipotong (`slice`), diluruskan (`trim`), atau ditulis ulang hurufnya (`toUpperCase`), kamu menangani kabel teks.
- **number = voltase.** Angka yang dihitung: dibulatkan (`Math.round`), dibangunkan ke atas (`Math.ceil`), atau dipatok ke bawah (`Math.floor`). Menyebut voltase sebagai "11.4 volt" dari `0.1+0.2` adalah kecerobohan menghitung presisi — itulah masalah floating point.
- **boolean = saklar on/off.** Hanya dua posisi: apakah lampu menyala (`true`) atau mati (`false`) — persis `stok > 0`.
- **array = panel listrik berisi banyak terminal.** Satu panel berderet terminal yang bisa diisi terminal baru (`push`), dikeluarkan (`pop`), atau disusun ulang (`splice`); setiap terminal bisa diakses nomornya (`katalog[0]`).
- **object = kotak hubungan berisi beberapa komponen berlabel.** Satu kotak punya beberapa komponen yang masing-masing punya label (property) seperti `judul`, `harga`, `stok`; kamu bisa membuka salah satu komponennya (`buku.harga`) tanpa membuka kotak lain.

Jika nanti kamu menambah **TypeScript**, itu seperti **blueprint presisi sebelum memasang**: blueprint menentukan di titik mana kabel harus bertipe number, di mana boolean, dan di mana string — sehingga tukang listrik tidak menyalakan "on/off" ke kabel tegangan. Di fase awal ini, disiplin memilih tipe yang tepat adalah latihanmu sendiri; TypeScript akan mengotomatiskan pengawasannya di project besar.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

- **Normalisasi pencarian katalog** — ubah input user dan judul ke `toLowerCase()` lalu `includes()`; pakai `trim()` agar spasi ekstra tidak menggagalkan pencarian.
- **Format harga agar terbaca** — `harga.toLocaleString("id-ID", { style: "currency", currency: "IDR" })` untuk menampilkan `Rp 150.000`, bukan `150000`.
- **Menghitung dengan pembulatan yang benar** — `Math.floor` untuk jumlah buku yang bisa ditampung rak, `Math.ceil` untuk jumlah kategori yang harus diproses, `Number(x.toFixed(2))` saat bekerja dengan desimal harga.
- **Menampilkan daftar buku dari array of objects** — iterasi `katalog` (forEach/map di materi 23), ambil judul via destructuring `{ judul }`, dan modifikasi daftar dengan `push`/`splice` saat katalog bertambah atau buku dihapus (Level 5).
- **Keputusan boolean di UI** — `stok > 0` menentukan apakah tombol "Pinjam" aktif, badge "Tersedia"/"Habis", atau filter "hanya buku tersedia" dicentang.

## 6. Poin-poin Penting & Best Practices

- Kenali **dua keluarga tipe**: primitive (string, number, boolean, null, undefined, symbol, bigint) vs object/array (referensi). Salinan object kadang menunjuk data yang sama.
- Hafal **quirk `typeof null === "object"`** dan gunakan `Array.isArray(x)` untuk membedakan array dari objek.
- **Gunakan template literal (backtick)** `${...}` daripada concatenation `+` untuk menyusun teks berisi data; jauh lebih mudah dibaca dan mendukung multi-baris.
- Rajin memakai **string methods** (`toUpperCase`, `includes`, `split`, `replace`, `trim`, `slice`, `startsWith`) untuk membersihkan dan memeriksa teks; selalu normalisasi case saat membandingkan input user.
- **Angka:** hindari perbandingan langsung hasil floating point (`0.1 + 0.2 === 0.3` salah); bulatkan dengan `Number(x.toFixed(n))`. Format uang dengan `toLocaleString("id-ID")` daripada menambahkan "Rp" manual.
- **Array/object:** pakai metode immutable-ish (spread, destructuring) untuk salinan bersih; akses property object dengan dot, gunakan bracket untuk nama dinamis; cek membersihkan data dengan `in`/`hasOwnProperty`/`Object.keys`.
- Beda **reassign vs mutate** (materi 20) paling nyata di sini: `const katalog.push(...)` sah, sementara assignment ulang tidak.
- Catatan **Type Safety**: mulailah disiplin memilih tipe saat menyimpan data (jangan simpan angka di variabel yang tadinya string), dan buat struktur object konsisten antar buku (semua buku punya `judul`, `harga`, `stok`). Inilah yang nanti otomatis ditegakkan TypeScript di project besar.

## 7. Kesalahan Umum (Common Pitfalls & Bugs)

- **`0.1 + 0.2 === 0.3` bernilai `false`** — representasi biner desimal tidak presisi. Perbaikan: pakai `Number((0.1 + 0.2).toFixed(2))` untuk perbandingan uang atau tampilan.
- **Menggabungkan string + number tanpa sadar.** `"Harga: " + 150000` menjadi `"Harga: 150000"` (string), dan operasi selanjutnya (misal `+ 50000`) jadi penggabungan yang menghasilkan `"15000050000"`. Perbaikan: simpan harga sebagai number sampai saat menampilkan, lalu baru pakai template literal / `toLocaleString`.
- **`typeof null === "object"` (quirk)** — jangan percaya `typeof` untuk membedakan null; gunakan check eksplisit seperti `nilai === null`.
- **Akses property yang tidak ada mengembalikan `undefined`** — misal `buku.foto` padahal `buku` tidak punya `foto`; chaining `buku?.foto ?? "default"` (materi 22) menghindari error dan menyediakan default.
- **Mengira array di-copy saat di-assign.** `const katalog2 = katalog;` menunjuk data yang sama; mengubah `katalog2` ikut mengubah `katalog`. Perbaikan: pakai spread `[...katalog]` atau `slice()` untuk salinan terpisah.

## 8. Mini Project / Soal Latihan & Kunci Jawaban

### Tantangan

1. Deklarasikan `katalog` sebagai array of objects berisi 4 buku dengan properti `id`, `judul`, `pengarang`, `harga`, `stok`, `kategori` (gunakan `const`).
2. Hitung **total nilai koleksi** (jumlah dari `harga × stok` setiap buku) lalu tampilkan dalam format mata uang `id-ID` (`Rp ...`).
3. Buat **normalisasi pencarian**: terima string acak (`"  CLEAN CODE  "`), simpan sebagai `let` ke versi trim + lowercase, lalu cek apakah cocok dengan judul salah satu buku.
4. Dari satu objek buku, buat objek baru lewat **spread** dengan `stok` berkurang 1 dan tambahan property `tersedia: stok > 0`. Tunjukkan bahwa objek asli tidak berubah.
5. Gunakan **destructuring** untuk mengambil `judul` dan `kategori` dari buku pertama, dengan `judul` di-rename ke `judulBuku`.

### Solusi & Pembahasan

```javascript
// js/latihan-21.js

// 1. Data katalog sebagai array of objects
const katalog = [
    { id: 1, judul: "Clean Code",       pengarang: "Robert C. Martin", harga: 150000, stok: 5,  kategori: "Teknologi" },
    { id: 2, judul: "Laskar Pelangi",   pengarang: "Andrea Hirata",    harga:  95000, stok: 3,  kategori: "Fiksi" },
    { id: 3, judul: "The Great Gatsby", pengarang: "F. Scott Fitzgerald", harga: 120000, stok: 0, kategori: "Fiksi" },
    { id: 4, judul: "Cosmos",           pengarang: "Carl Sagan",       harga: 200000, stok: 8,  kategori: "Sains" },
];

// 2. Total nilai koleksi = Σ (harga × stok)
const totalNilai = katalog.reduce((total, buku) => total + buku.harga * buku.stok, 0);
const totalFormat = totalNilai.toLocaleString("id-ID", {
    style: "currency", currency: "IDR", maximumFractionDigits: 0,
});
console.log(`Total nilai koleksi: ${totalFormat}`); // Rp 2.905.000

// 3. Normalisasi pencarian
let inputUser = "  CLEAN CODE  ";
const kataNormal = inputUser.trim().toLowerCase(); // "clean code"
const ditemukan = katalog.find(buku => buku.judul.toLowerCase() === kataNormal);
console.log(ditemukan ? `Ditemukan: ${ditemukan.judul}` : "Tidak ditemukan");

// 4. Spread merge object → objek baru tanpa mengubah asli
const bukuKeempat = katalog[3]; // { id: 4, judul: "Cosmos", ... stok: 8 }
const bukuDipesan = { ...bukuKeempat, stok: bukuKeempat.stok - 1, tersedia: bukuKeempat.stok - 1 > 0 };
console.log(bukuDipesan.stok);         // 7
console.log(bukuDipesan.tersedia);     // true
console.log(katalog[3].stok);          // 8 — asli tidak berubah (spread membuat salinan)

// 5. Destructuring object dengan rename
const { judul: judulBuku, kategori, ...sisaBuku } = katalog[0];
console.log(judulBuku);   // "Clean Code"
console.log(kategori);    // "Teknologi"
console.log(sisaBuku.stok); // 5 — nama lain bisa diakses saat tidak di-destructure
```

**Pembahasan**: Latihan ini memadukan semua tipe yang baru dipelajari. `reduce` memanfaatkan fakta bahwa nilai `harga × stok` adalah number sehingga bisa diakumulasi, lalu `toLocaleString("id-ID")` mengubah hasil menjadi string mata uang yang terbaca. Normalisasi pencarian mendemonstrasikan kombinasi string methods (`trim` + `toLowerCase`) yang menangkal spasi ekstra dan perbedaan huruf besar/kecil dari input user. Spread object menunjukkan perbedaan penting antara salinan (objek baru tidak memengaruhi `katalog[3]`) versus mutasi langsung — konsisten dengan pelajaran mutate vs reassign di materi 20. Destructuring dengan rename membuat penamaan variabel lokal lebih ekspresif tanpa mengubah struktur data aslinya.
