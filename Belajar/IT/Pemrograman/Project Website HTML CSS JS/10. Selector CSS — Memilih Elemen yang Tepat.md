# 10. Selector CSS — Memilih Elemen yang Tepat

Setelah CSS terhubung ke HTML (materi 9), pertanyaan berikutnya: **elemen mana yang mau di-style dan bagaimana cara menunjuknya dengan tepat?** Jawabannya adalah selector — inti dari CSS. Selector adalah jembatan antara struktur HTML dan aturan tampilan, dan memilihnya dengan benar menentukan apakah style kamu rapi atau berantakan.

## 1. Penjelasan Singkat & Konsep Dasar

Selector adalah pola di CSS yang menentukan elemen mana saja yang menerima property yang ditulis di dalam kurung kurawal. Contoh `<h1>Belajar CSS</h1>` di-*style* dengan `h1 { color: blue; }` — di sini `h1` adalah selector. Browser mencocokkan setiap selector ke elemen-elemen di DOM (pohon elemen yang dibangun dari HTML, ingat materi 1) dan menerapkan property ke semua elemen yang cocok.

Di Level 1 kamu membangun struktur yang kaya: `<header>`, `<nav>`, `<main>`, `<section>`, `<article class="kartu-buku">`, `<h1>` sampai `<h6>`, form dengan `<input>` berbagai tipe, dan elemen `<a>` untuk navigasi. Tanpa selector, kamu tidak bisa membedakan elemen yang satu dari yang lain. Dengan selector, kamu bisa bilang ke browser: "style semua class `kartu-buku`", "style paragraf yang langsung mengikuti heading", atau "style semua input wajib diisi".

Kunci memahami selector adalah mengingat kembali **struktur hierarki HTML**: elemen bisa menumpuk (parent-child), tersusun berurutan (sibling), membawa informasi di atributnya. Setiap cara elemen saling berhubungan itu punya jenis selector-nya masing-masing. Deskripsi kata-kata seperti "link email", "paragraf pertama setelah judul", atau "input yang wajib" bisa diterjemahkan satu-ke-satu menjadi selector CSS.

Ke depannya, selector adalah dasar semua materi CSS berikutnya — layout Flexbox/Grid, animasi, sampai "CSS yang terstruktur" (materi 11 tentang specificity dan cascade). Nama class yang kamu pilih hari ini akan `querySelector`-nya JavaScript pada Level 4. Jadi pilihan nama class bukan sekadar kosmetik — itu kontrak antar layer yang menentukan kerapian seluruh proyek.

## 2. Fungsi & Kegunaan Utama dalam Web

Selector memecahkan masalah "meng-*style* dengan presisi" di aplikasi nyata. Untuk Perpustakaan Digital Kota, selector memungkinkan:

- **Styling berkelompok.** Semua elemen dengan class `btn` di-*style* sekaligus — tidak perlu mengulang CSS per elemen. Ubah satu aturan, semua tombol ikut berubah.
- **Membedakan peran elemen sejenis.** Semua `<article>` di halaman adalah kartu buku, tapi tombol "Lihat Detail" di dalamnya di-*style* berbeda dari tombol "Daftar Anggota" di form pendaftaran — cukup bedakan dengan class atau selector konteks.
- **State interaktif.** Link berubah warna saat di-hover atau dikunjungi (`a:hover`, `a:visited`), input menampilkan border hijau saat isinya valid (`input:valid`). Ini memberikan umpan balik visual yang penting bagi pengguna tanpa JavaScript sama sekali.
- **Tidak menyentuh HTML.** Banyak hal yang tadinya butuh elemen `<span>` tambahan di HTML bisa dilakukan dengan pseudo-element `::before`/`::after`. Contoh: menambahkan tanda "*" pada label wajib tanpa mengubah markup.
- **Aksesibilitas dan validasi.** Attribute selector bisa menandai elemen bermasalah seperti `img[alt=""]` (gambar tanpa teks alternatif) atau `input[required]` yang belum terisi — alat bagus untuk audit kualitas.

## 3. Contoh Kode & Implementasi Real-World

### Selector Dasar

```css
/* ─── Element selector: pilih berdasarkan nama tag ─────────────────────── */
/* Spesifisitas rendah, tidak membedakan elemen sejenis */
h1  { color: #2c3e50; }
p   { line-height: 1.6; }
a   { color: #2563eb; text-decoration: none; }

/* ─── Class selector: pilih berdasarkan class (awali dengan titik) ────── */
/* Cara paling sering dipakai — reusable dan semantik */
.kartu-buku  { background: #ffffff; border-radius: 8px; }
.btn-primary { background: #2563eb; color: #ffffff; }

/* Nama class yang BENAR (semantik — menggambarkan peran/fungsi): */
.kartu-buku           { /* konten buku */ }
.deskripsi-buku       { /* keterangan buku */ }
.tombol-pinjam        { /* tombol untuk meminjam */ }

/* Nama class yang SALAH (deskripsi tampilan — hindari!): */
.teks-merah    { color: red; }      /* kalau nanti warnanya biru, nama ini menipu */
.judul-besar   { font-size: 2rem; } /* ubah ukuran, nama tetap menipu */

/* ─── ID selector: pilih berdasarkan id (awali dengan #) ──────────────── */
/* Gunakan ID untuk JavaScript hook, BUKAN untuk styling */
#form-pendaftaran { max-width: 600px; }
/* Lebih baik: styling dengan class, JS memakai id */

/* ─── Universal selector: semua elemen ────────────────────────────────── */
* {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}
/* Praktik umum untuk reset, tapi hati-hati: bisa mahal secara performa */
```

### Selector Kombinasi

```css
/* Berdasarkan hubungan antar elemen dalam hierarki (struktur DOM Level 1) */

/* Descendant (spasi): elemen DI DALAM elemen lain, di kedalaman mana pun */
/* Semua .judul-buku yang ada di dalam .kartu-buku — berlaku juga ke cucu */
.kartu-buku .judul-buku { font-size: 1.25rem; }

/* Child (>): hanya ANAK LANGSUNG — tidak sampai ke cucu */
nav > ul { list-style: none; }
nav > ul > li { display: inline-block; }

/* Adjacent sibling (+): elemen TEPAT setelah elemen tertentu */
/* Paragraf yang langsung mengikuti h2 — sering dipakai untuk 'lede' */
h2 + p { font-size: 1.1rem; color: #475569; }

/* General sibling (~): SEMUA elemen setelah elemen tertentu */
h2 ~ p { color: #64748b; }

/* Cara membaca yang benar:
   .kartu-buku .judul-buku   = ".judul-buku di dalam .kartu-buku"
   nav > ul                  = "ul anak langsung dari nav"
*/
```

### Attribute Selector

```css
/* Memilih elemen berdasarkan atribut dan nilainya */

/* Punya atribut, tanpa peduli nilainya */
input[required]      { border-left: 3px solid #dc2626; }
img[alt]             { /* gambar yang punya alt */ }
img[alt=""]          { outline: 3px solid #dc2626; }  /* gambar TANPA alt! */

/* ^= : dimulai dengan → link email */
a[href^="mailto:"]   { padding-left: 20px; }

/* $= : diakhiri dengan → link ke dokumen PDF */
a[href$=".pdf"]      { color: #dc2626; }

/* *= : mengandung → URL yang memuat kata 'buku' */
a[href*="buku"]      { font-weight: 600; }

/* Atribut boolean bekerja juga: a[target="_blank"] */
a[target="_blank"]   { padding-right: 16px; }
```

### Pseudo-class — Kondisi / State elemen

```css
/* Dua titik satu (:), memilih STATE — paling sering untuk interaksi */

/* Link dan umpan balik interaksi */
a:hover            { color: #1d4ed8; text-decoration: underline; }
a:focus            { outline: 2px solid #2563eb; outline-offset: 2px; }
a:visited          { color: #6d28d9; }

/* Form: validasi visual tanpa JavaScript */
input:focus        { border-color: #2563eb; }
input:required     { border-left: 3px solid #dc2626; }
input:invalid      { border-color: #dc2626; }
input:valid        { border-color: #16a34a; }
button:disabled    { opacity: 0.5; cursor: not-allowed; }

/* Posisi di antara saudara (sibling) */
li:first-child  { font-weight: 700; }
li:last-child   { border-bottom: none; }
li:nth-child(2) { background: #f1f5f9; }
li:nth-child(odd)  { background: #f8fafc; }  /* ganjil */
li:nth-child(even) { background: #ffffff; }  /* genap */

/* :not() — negasi, sangat berguna untuk pengecualian */
.kartu-buku:not(:last-child) { margin-bottom: 16px; }
```

### Pseudo-element — Bagian / lapisan dari elemen

```css
/* Dua titik dua (::), membuat SEBAGIAN dari elemen atau elemen virtual */

p::first-line   { font-weight: 600; }          /* baris pertama paragraf */
p::first-letter { font-size: 2.5em; float: left; } /* huruf pertama */

/* ::before dan ::after: konten dekoratif yang TIDAK ada di HTML */
/* Wajib menulis property content, jika tidak tidak akan tampil */
.wajib::after {
    content: " *";
    color: #dc2626;
}

a[href$=".pdf"]::after {
    content: " (PDF)";
    font-size: 0.75em;
    color: #64748b;
}

/* Contoh untuk tombol pinjam — ikon kecil tanpa menambah HTML */
.tombol-pinjam::before {
    content: "→";
    margin-right: 4px;
}
```

### Selector untuk Komponen Perpustakaan

```css
/* Menerapkan semua jenis selector di atas untuk navbar & kartu buku */

/* Navbar */
.navbar {
    background: #1e293b;
    padding: 16px 24px;
}

.navbar__menu li a { color: #ffffff; }          /* link dalam menu */
.navbar__menu li a:hover { color: #93c5fd; }    /* hover */
.navbar__menu > li:first-child a { font-weight: 700; } /* item pertama */

/* Kartu buku */
.kartu-buku {
    background: #ffffff;
    border: 1px solid #e2e8f0;
    border-radius: 8px;
    padding: 16px;
}

.kartu-buku h3 { margin-bottom: 8px; }          /* judul buku */
.kartu-buku .kategori { color: #64748b; font-size: 0.875rem; }
.kartu-buku .kategori::before { content: "📖 "; } /* ikon dekoratif */

/* Heading utama perpustakaan */
.hero h1 { font-size: 2.5rem; color: #1e293b; }  /* paud di hero */
.hero p  { color: #475569; max-width: 60ch; }    /* paragraf pendamping */
```

> Catatan: prinsip *naming* di atas (`.navbar__menu`, `.kartu-buku`) adalah contoh pola BEM yang akan dijelaskan lebih lanjut di bagian 6.

## 4. Analogi Sederhana — Membangun Rumah

Melanjutkan analogi rumah dari materi 9: HTML adalah kerangka rumah, CSS adalah cat dan interior, JS adalah listrik. Tukang cat mulai bekerja, dan dia perlu tahu perintah yang jelas tentang dinding mana yang dicat warna apa. **Selector adalah perintah "cat dinding ini saja".**

- **Element selector** — perintah umum: "cat **semua dinding** rumah". Tidak peduli kamar mana, semua dinding kena. Cepat dan merata, tapi tidak presisi.
- **Class selector** — perintah berdasarkan **kelas ruangan**: "cat semua dinding kamar yang ber-label `ruang-tamu`". Tukang cat mencari stiker label di pintu — semua ruangan berlabel `ruang-tamu` dicat. Class adalah label atau stiker yang bisa kamu tempel di banyak ruangan sesukamu.
- **ID selector** — perintah berdasarkan **nomor unik**: "cat dinding kamar **nomor 3**". Kamar nomor 3 cuma satu, tidak ada duanya. Sangat spesifik — itulah kenapa ID digunakan untuk menunjuk elemen unik di JavaScript, bukan untuk hal yang bisa dipakai ulang.
- **Selector kombinasi** — "cat dinding **di dalam ruang tamu** saja" (descendant), atau "cat dinding persis setelah pintu masuk" (adjacent sibling). Kamu menunjukkan lokasi lewat hubungan antar ruangan.
- **Pseudo-class** — perintah berdasarkan **kondisi**: "cat dinding **saat pintunya terbuka**" (`:hover`), "cat dinding **saat lampu menyala**" (`:focus`). Ini state yang bisa berubah-ubah.
- **Attribute selector** — "cat dinding yang punya **plakat nama pemilik**" atau "yang plakatnya hilang" (`img[alt=""]`).

Perhatikan bedanya: HTML menyediakan struktur fisik (ruangan, dinding), dan selector adalah cara berkata dengan presisi tentang bagian mana yang mau dikerjakan. Tanpa selector, satu-satunya pilihan tukang cat adalah "cat semuanya merah" — dan itu tentu bukan desain rumah yang baik.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

- **Gaya global:** tipografi, warna dasar, reset. Pakai element selector (`h1`, `p`, `a`, `body`). Contoh nyata: menetapkan `color` dan `font-family` di `body` agar seluruh halaman perpustakaan konsisten.
- **Komponen yang dipakai ulang:** kartu buku, tombol, form field, badge kategori. Pakai class selector dengan nama BEM. Jika kamu menampilkan 12 kartu buku, kamu hanya menulis `.kartu-buku` sekali dan semua kartu ter-hubung.
- **Navbar dan menu:** pakai child selector `nav > ul > li` untuk mencegah menu di dalam sub-menu ikut kena style, dan pseudo-class `:hover`, `:focus`, `:first-child` untuk highlight item aktif.
- **Form interaktif:** `input:required` menandai yang wajib, `input:invalid`/`:valid` memberi feedback warna, `input:focus` untuk highlight field aktif. Ini user experience yang langsung terasa di form pendaftaran anggota.
- **Link eksternal dibedakan visualnya:** `a[href^="http"]` menandai link keluar situs, `a[href$=".pdf"]` menandai dokumen unduhan, `a[href^="mailto:"]` menandai kontak email — pengguna langsung paham jenis target link tanpa klik dulu.
- **Toast/penanda tanpa mengubah HTML:** tanda "*" pada label wajib, ikon panah pada tombol — dipakai dengan `::before`/`::after`.

## 6. Poin-poin Penting & Best Practices

- **Gunakan class, bukan ID, untuk styling.** ID hanya untuk JS hooks dan anchor unik. Alasan: class bisa dipakai ulang, ID tidak; dan ID spesifisitasnya tinggi sehingga sulit di-override (akan dibahas di materi 11).
- **Nama class harus semantik, bukan deskripsi tampilan.** `.teks-merah`, `.judul-besar`, `.kotak-kiri` dilarang. Gunakan `.peringatan`, `.judul-buku`, `.sidebar`. Ketika desain berubah, nama semantik tidak perlu diubah.
- **Pola penamaan BEM (Block Element Modifier)**:
  - **Block**: komponen mandiri → `.kartu-buku`, `.navbar`
  - **Element**: bagian dari block, dipisah `__` → `.kartu-buku__judul`, `.navbar__menu`
  - **Modifier**: variasi, dipisah `--` → `.btn--besar`, `.kartu-buku--ungggulan`
  - Hasil: selector selalu pendek, spesifisitas rendah, dan jelas asal-usulnya di struktur HTML.
- **Jangan menumpuk selector terlalu dalam.** Maksimal 3 kombinator (misal `.kartu-buku .detail .harga-x`). Semakin dalam, semakin rapuh terhadap perubahan struktur HTML dan semakin tinggi spesifisitasnya. Jika butuh selector dalam, pertimbangkan menambah class langsung di elemennya.
- **Biasakan member sesuai peran:** `.btn--besar`, jangan `.btn.btn--besar.btn--primary.btn--blue` — kombinasikan modifier seminimal mungkin agar spesifisitas tetap rendah.
- **Hati-hati dengan universal selector (`*`)** — selalu jalan, tapi jangan dipakai berlebihan karena memengaruhi semua elemen.
- **Perhatikan urutan penulisan di file:** selector dasar (element) dulu, lalu class, lalu kombinasi/spesifik — walaupun spesifisitas lebih berperan dari urutan (materi 11).
- **Gunakan DevTools untuk memverifikasi** selector mana yang cocok dengan elemen yang di-*inspect* (tab Styles akan menampilkan semua aturan yang berlaku beserta sumbernya).

## 7. Kesalahan Umum (Common Pitfalls & Bugs)

- **Kelas gaya ditulis sebagai nama class.** `.teks-merah { color: red; }` lalu minggu depan desain jadi biru — sekarang nama "merah" menipu semua orang. Perbaikannya: ganti dengan nama semantik `.peringatan` atau `.highlight`, sehingga warna boleh berubah-ubah tanpa merombak nama.
- **Selector terlalu spesifik/dalam.** `#main .content .kartu-buku .detail .tanggal .tahun { ... }` — terlalu rapuh: satu perubahan struktur HTML bikin semua style-nya mati, dan spesifisitasnya nyaris mustahil di-override. Perbaikannya: pangkas menjadi `.kartu-buku .tanggal { ... }` atau beri class langsung pada elemen.
- **Menyalahgunakan ID untuk styling.** Memberi id di setiap elemen lalu menargetkannya dengan `#...` — sulit dipakai ulang dan spesifisitas melonjak. Perbaikannya: gunakan class, simpan id untuk JS.
- **Pseudo-element lupa `content`.** `.label::after { color: red; }` — tidak akan tampil apa-apa karena property `content` wajib. Perbaikannya: selalu sertakan `content: "";` (boleh kosong) pada `::before`/`::after`.
- **Mengira `nav > ul` dan `nav ul` sama.** Keduanya berbeda: `>` hanya anak langsung, spasi mencakup semua keturunan. Salah paham ini bikin style-nya gagal diterapkan seperti yang diharapkan. Perbaikannya: pahami hierarki elemen di HTML sebelum memilih kombinator.
- **Selector benar tapi tidak menampilkan efek.** Bisa jadi karena masalah spesifisitas atau urutan cascade (materi 11), bukan karena selector-nya salah. Selalu cek di DevTools apakah aturan tersebut ada dan apakah tampil *strikethrough* (artinya dikalahkan aturan lain).

Di CSS, gunakan beberapa jenis selector: element selector untuk `h1`, `p`, `a`; class selector untuk `.navbar`, `.kartu-buku`, `.hero`; child selector `nav > ul > li`; dan pseudo-class `:hover` untuk link nav dan `.kartu-buku`. **Pembahasan & analisis selector yang dipakai:**
- `body` (element selector, specificity 0,0,1): dasar agar semua elemen memakai font dan warna yang sama.
- `nav > ul` (child selector, specificity 0,0,2): hanya `<ul>` yang anak langsung dari `<nav>` yang kehilangan bullet. Jika ada `<ul>` di dalam `<li>` (submenu), tidak kena.
- `.kartu-buku h3` (descendant selector, specificity 0,1,1): semua `<h3>` di dalam elemen ber-class `kartu-buku`.
- `.kartu-buku:hover` (class + pseudo-class, specificity 0,2,0): saat kartu disentuh kursor.
- `.kategori::before` (class + pseudo-element, specificity 0,1,1): menghasilkan konten virtual `Kategori: ` di depan teks, tanpa menambah elemen di HTML.

### Tantangan 2

Tuliskan selector untuk kasus-kasus berikut pada halaman perpustakaan:
1. Semua link email di dalam footer.
2. Input yang wajib diisi di form pendaftaran.
3. Item ketiga dalam daftar kategori.
4. Semua gambar yang tidak memiliki atribut `alt`.
5. Paragraf pertama setelah judul utama halaman.

### Solusi & Pembahasan 2

```css
/* 1. Link email — kombinasi descendant + attribute selector */
footer a[href^="mailto:"] {
    color: #2563eb;
}

/* 2. Input wajib — attribute selector dengan pseudo-class */
input[required]:focus {
    border-left: 3px solid #dc2626;
}

/* 3. Item ketiga daftar */
li:nth-child(3) {
    font-weight: 700;
}

/* 4. Gambar tanpa alt — attribute selector nilai kosong */
img[alt=""] {
    outline: 3px solid #dc2626;
}

/* 5. Paragraf pertama setelah h1 — adjacent sibling selector */
h1 + p {
    font-size: 1.2rem;
    color: #475569;
}
```

**Pembahasan:** Semua kasus di atas diterjemahkan dari kebutuhan desain menjadi padanan selector-nya: (1) `footer a` menandai konteks, `[href^="mailto:"]` menandai jenis link; (2) `input[required]` memilih atribut, `:focus` menambahkan state; (3) `:nth-child(3)` berposisi tepat pada item ke-3; (4) formulasi khusus `[alt=""]` menangkap alt yang kosong (hati-hati: `img` tanpa atribut alt sama sekali butuh `img:not([alt])`); (5) `h1 + p` hanya mengambil paragraf yang langsung mengikuti `h1`. Pemahaman struktural hierarki HTML (materi Level 1) adalah kunci menerjemahkan kebutuhan ini dengan benar.
