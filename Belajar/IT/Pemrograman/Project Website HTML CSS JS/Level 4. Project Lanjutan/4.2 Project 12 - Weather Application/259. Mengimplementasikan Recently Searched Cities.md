# 259. Mengimplementasikan Recently Searched Cities

## Definisi & Target
Menyimpan daftar kota yang pernah dicari oleh user dan menampilkannya sebagai chip/button yang bisa diklik untuk mencari lagi.

## Analogi Alur
Recently searched seperti riwayat pencarian di Google: daftar kata kunci yang pernah Anda cari muncul di bawah search bar sehingga Anda bisa mengkliknya tanpa perlu mengetik ulang.

## Poin-Poin Penting
- Simpan array kota ke LocalStorage (max 5-10 item)
- Hindari duplikasi (jika kota sudah ada, pindahkan ke paling atas)
- Tampilkan sebagai chip/button yang dapat diklik
- Beri tombol "Hapus Riwayat" (clear history)
- Urutkan dari yang terbaru ke terlama
- Animasi masuk untuk chip baru
- Persist data antar sesi

```html
<script>
const API_KEY = 'YOUR_API_KEY';
const STORAGE_KEY = 'weather_recent_cities';
let recentCities = JSON.parse(localStorage.getItem(STORAGE_KEY) || '[]');

function saveRecent() { localStorage.setItem(STORAGE_KEY, JSON.stringify(recentCities)); }

function addCity(city) {
recentCities = [city, ...recentCities.filter(c => c.toLowerCase() !== city.toLowerCase())].slice(0, 8);
saveRecent();
renderChips();
}

function clearHistory() { recentCities = []; saveRecent(); renderChips(); }

function renderChips() {
const container = document.getElementById('recentChips');
if (recentCities.length === 0) {
container.innerHTML = '<span class="empty-state">Belum ada riwayat pencarian</span>';
return;
}
container.innerHTML = recentCities.map(c => `<span class="chip fade-in" onclick="searchCity('${c}')">📍 ${c}</span>`).join('');
}

async function searchCity(city) {
city = city || document.getElementById('cityInput').value.trim();
if (!city) return;
document.getElementById('cityInput').value = city;
try {
const res = await fetch(`https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${API_KEY}&units=metric`);
const d = await res.json();
if (!res.ok) return;
document.getElementById('cityName').textContent = `${d.name}, ${d.sys.country}`;
document.getElementById('tempDisplay').textContent = `${Math.round(d.main.temp)}°C`;
document.getElementById('descDisplay').textContent = d.weather[0].description;
document.getElementById('weatherDisplay').classList.add('show');
addCity(d.name);
} catch {}
}

document.getElementById('cityInput').addEventListener('keypress', e => { if (e.key === 'Enter') searchCity(); });
renderChips();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Ganti `YOUR_API_KEY`. Cari beberapa kota. Lihat chip kota muncul di bawah. Klik chip untuk mencari lagi. Klik "Hapus Semua" untuk membersihkan riwayat.
