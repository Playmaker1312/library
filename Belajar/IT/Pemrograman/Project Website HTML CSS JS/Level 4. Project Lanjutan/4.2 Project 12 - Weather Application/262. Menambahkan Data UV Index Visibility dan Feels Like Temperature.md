# 262. Menambahkan Data UV Index, Visibility, dan Feels Like Temperature

## Definisi & Target
Memperkaya tampilan cuaca dengan data tambahan: UV Index (menggunakan One Call API), visibility (jarak pandang), dan feels like temperature (suhu terasa).

## Analogi Alur
Data tambahan seperti panel informasi lengkap di stasiun cuaca: tidak hanya suhu, tapi juga tingkat UV (bahaya sinar matahari), jarak pandang (visibility), dan suhu yang dirasakan tubuh (feels like).

## Poin-Poin Penting
- feels_like dari response current weather
- visibility dari response (dalam meter, konversi ke km)
- UV Index memerlukan One Call API atau library tambahan
- Tampilkan dalam card grid yang rapi
- Ikon yang sesuai untuk setiap data
- Kategori UV: low (1-2), moderate (3-5), high (6-7), very high (8-10), extreme (11+)
- Warna indikator sesuai level UV

<script>
const API_KEY = 'YOUR_API_KEY';

function getUVLevel(uvi) {
if (uvi <= 2) return { label: 'Low', cls: 'uv-low' };
if (uvi <= 5) return { label: 'Moderate', cls: 'uv-moderate' };
if (uvi <= 7) return { label: 'High', cls: 'uv-high' };
if (uvi <= 10) return { label: 'Very High', cls: 'uv-vhigh' };
return { label: 'Extreme', cls: 'uv-extreme' };
}

async function fetchWeather() {
const city = document.getElementById('cityInput').value.trim() || 'Jakarta';
try {
const res = await fetch(`https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${API_KEY}&units=metric`);
const d = await res.json();
if (!res.ok) return;

document.getElementById('cityName').textContent = `${d.name}, ${d.sys.country}`;
document.getElementById('tempDisplay').textContent = `${Math.round(d.main.temp)}°C`;
document.getElementById('descDisplay').textContent = d.weather[0].description;
document.getElementById('feelsLike').textContent = `${Math.round(d.main.feels_like)}°`;
document.getElementById('humidity').textContent = `${d.main.humidity}%`;
document.getElementById('windSpeed').textContent = `${d.wind.speed} m/s`;
document.getElementById('visibility').textContent = `${(d.visibility / 1000).toFixed(1)} km`;
document.getElementById('pressure').textContent = `${d.main.pressure} hPa`;

const uv = getUVLevel(3);
document.getElementById('uvBar').className = `uv-bar ${uv.cls}`;
document.getElementById('uvLabel').textContent = uv.label;
} catch {}
}

document.getElementById('cityInput').addEventListener('keypress', e => { if (e.key === 'Enter') fetchWeather(); });
fetchWeather();
</script>
