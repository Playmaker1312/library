# 246. Merencanakan Fitur Weather App yaitu Current Weather, Forecast, dan Search Kota

## Definisi & Target
Merencanakan fitur-fitur Weather App yang akan dibangun: menampilkan cuaca saat ini, prakiraan 5 hari ke depan, dan pencarian kota.

## Analogi Alur
Weather App seperti melihat jendela: Anda bisa melihat cuaca di luar sekarang (current weather), memperkirakan cuaca besok (forecast), dan mencari kota lain seperti pindah ke jendela berbeda (search).

## Poin-Poin Penting
- Current Weather: suhu, deskripsi, kelembaban, kecepatan angin
- Forecast: prakiraan cuaca 5 hari dengan ikon
- Search: mencari cuaca berdasarkan nama kota
- Geolocation: deteksi lokasi otomatis
- API Integration: menggunakan OpenWeatherMap API
- Responsive: tampilan yang baik di semua perangkat
