# 249. Membangun UI Search Bar untuk Mencari Kota

## Definisi & Target
Membuat antarmuka pencarian kota dengan input field, tombol search, dan suggestions dropdown untuk memudahkan user mencari kota.

## Analogi Alur
Search bar seperti loket informasi bandara: Anda datang ke loket, menyebutkan nama kota, dan petugas memberikan informasi cuaca kota tersebut.

## Poin-Poin Penting
- Input field dengan placeholder yang jelas (e.g., "Cari kota...")
- Tombol search dengan ikon 🔍
- Mendukung Enter untuk submit pencarian
- Loading state saat data sedang diambil
- Styling yang konsisten dengan tema weather app
- Validasi input tidak boleh kosong
- Auto-focus pada input saat halaman dimuat

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Search Bar Weather</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: linear-gradient(135deg, #1e3c72, #2a5298); min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: rgba(255,255,255,0.1); backdrop-filter: blur(15px); border-radius: 20px; padding: 30px; width: 100%; max-width: 500px; border: 1px solid rgba(255,255,255,0.15); }
h1 { text-align: center; color: #fff; margin-bottom: 20px; font-size: 22px; }
.search-container { position: relative; }
.search-bar { display: flex; gap: 10px; }
.search-bar input { flex: 1; padding: 14px 18px; border: 2px solid rgba(255,255,255,0.2); border-radius: 12px; font-size: 16px; background: rgba(255,255,255,0.08); color: #fff; outline: none; transition: border-color 0.3s; }
.search-bar input:focus { border-color: rgba(255,255,255,0.5); }
.search-bar input::placeholder { color: rgba(255,255,255,0.5); }
.search-bar button { padding: 14px 24px; background: rgba(255,255,255,0.15); border: 2px solid rgba(255,255,255,0.2); border-radius: 12px; color: white; font-size: 18px; cursor: pointer; transition: all 0.3s; }
.search-bar button:hover { background: rgba(255,255,255,0.25); }
.suggestions { position: absolute; top: 100%; left: 0; right: 0; background: rgba(26,26,50,0.95); backdrop-filter: blur(10px); border: 1px solid rgba(255,255,255,0.1); border-radius: 12px; margin-top: 5px; display: none; z-index: 10; }
.suggestions.show { display: block; }
.suggestion-item { padding: 12px 18px; color: #ddd; cursor: pointer; transition: background 0.2s; display: flex; align-items: center; gap: 10px; }
.suggestion-item:hover { background: rgba(255,255,255,0.08); }
.suggestion-item:first-child { border-radius: 12px 12px 0 0; }
.suggestion-item:last-child { border-radius: 0 0 12px 12px; }
.suggestion-icon { font-size: 16px; }
.last-searched { margin-top: 20px; display: flex; flex-wrap: wrap; gap: 8px; }
.last-item { padding: 6px 14px; background: rgba(255,255,255,0.08); border: 1px solid rgba(255,255,255,0.1); border-radius: 20px; color: rgba(255,255,255,0.7); font-size: 13px; cursor: pointer; transition: all 0.3s; }
.last-item:hover { background: rgba(255,255,255,0.15); }
</style>
</head>
<body>
<div class="container">
<h1>🔍 Cari Kota</h1>
<div class="search-container">
<div class="search-bar">
<input type="text" id="searchInput" placeholder="Masukkan nama kota..." autofocus>
<button onclick="searchCity()">🔍</button>
</div>
<div class="suggestions" id="suggestions"></div>
</div>
<div id="lastSearched" class="last-searched">
<span style="color:rgba(255,255,255,0.4);font-size:13px">📍 </span>
</div>
</div>
<script>
const cities = ['Jakarta', 'Bandung', 'Surabaya', 'Yogyakarta', 'Bali', 'Medan', 'Makassar', 'Palembang', 'Semarang', 'Malang', 'Tokyo', 'New York', 'London', 'Paris', 'Dubai', 'Sydney', 'Seoul', 'Singapore', 'Kuala Lumpur', 'Bangkok'];
let lastSearched = JSON.parse(localStorage.getItem('weather_cities') || '[]');

document.getElementById('searchInput').addEventListener('input', function() {
const query = this.value.toLowerCase();
const suggestions = document.getElementById('suggestions');
if (query.length < 1) { suggestions.classList.remove('show'); return; }
const filtered = cities.filter(c => c.toLowerCase().includes(query)).slice(0, 5);
if (filtered.length === 0) { suggestions.classList.remove('show'); return; }
suggestions.classList.add('show');
suggestions.innerHTML = filtered.map(c => `<div class="suggestion-item" onclick="selectCity('${c}')"><span class="suggestion-icon">📍</span>${c}</div>`).join('');
});

document.getElementById('searchInput').addEventListener('keypress', function(e) {
if (e.key === 'Enter') searchCity();
});

document.addEventListener('click', function(e) {
if (!e.target.closest('.search-container')) {
document.getElementById('suggestions').classList.remove('show');
}
});

function selectCity(city) {
document.getElementById('searchInput').value = city;
document.getElementById('suggestions').classList.remove('show');
searchCity();
}

function searchCity() {
const city = document.getElementById('searchInput').value.trim();
if (!city) return;
lastSearched = [city, ...lastSearched.filter(c => c !== city)].slice(0, 5);
localStorage.setItem('weather_cities', JSON.stringify(lastSearched));
renderLastSearched();
document.getElementById('suggestions').classList.remove('show');
alert(`Mencari cuaca kota: ${city}`);
}

function renderLastSearched() {
const container = document.getElementById('lastSearched');
container.innerHTML = '<span style="color:rgba(255,255,255,0.4);font-size:13px">🗂️ </span>' +
lastSearched.map(c => `<span class="last-item" onclick="selectCity('${c}')">${c}</span>`).join('');
}
renderLastSearched();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Ketik nama kota untuk melihat suggestions. Klik suggestion atau tekan Enter untuk mencari. Kota terakhir tersimpan di LocalStorage.
