# 252. Mengimplementasikan Weather Icon yang Berubah Sesuai Kondisi Cuaca

## Definisi & Target
Menampilkan ikon cuaca yang berubah secara dinamis berdasarkan kode ikon dari response API OpenWeatherMap.

## Analogi Alur
Weather icon seperti rambu cuaca: saat cerah, matahari bersinar; saat hujan, gambar awan hujan; saat malam, bulan muncul. Ikon berubah otomatis mengikuti kondisi nyata.

## Poin-Poin Penting
- Gunakan URL: https://openweathermap.org/img/wn/{icon}@2x.png
- Kode ikon dari response: weather[0].icon (e.g., '01d', '10n')
- d = day, n = night
- Mapping kode ikon ke deskripsi: 01=clear, 02=few clouds, 03=scattered, 04=broken, 09=shower, 10=rain, 11=thunderstorm, 13=snow, 50=mist
- Fallback jika gambar tidak termuat
- Animasi transisi saat berganti ikon
- Ukuran ikon responsif

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Weather Icons</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1a3e; border-radius: 20px; padding: 30px; width: 100%; max-width: 500px; text-align: center; }
h1 { color: #667eea; margin-bottom: 20px; font-size: 22px; }
.icon-display { background: #12123a; border-radius: 16px; padding: 30px; margin-bottom: 20px; border: 1px solid #2a2a5e; }
.icon-display img { width: 120px; height: 120px; transition: all 0.5s ease; }
.icon-display img.fade { opacity: 0; transform: scale(0.8); }
.condition-name { font-size: 20px; color: #fff; margin-top: 10px; text-transform: capitalize; }
.icon-grid { display: grid; grid-template-columns: repeat(5, 1fr); gap: 8px; }
.icon-btn { background: #12123a; border: 1px solid #2a2a5e; border-radius: 10px; padding: 10px; cursor: pointer; transition: all 0.3s; }
.icon-btn:hover { border-color: #667eea; background: #1a1a4e; }
.icon-btn img { width: 40px; height: 40px; }
.icon-btn.active { border-color: #667eea; background: rgba(102,126,234,0.2); }
.icon-code { color: #666; font-size: 10px; margin-top: 4px; }
</style>
</head>
<body>
<div class="container">
<h1>🌦️ Weather Icons</h1>
<div class="icon-display" id="iconDisplay">
<img id="mainIcon" src="https://openweathermap.org/img/wn/01d@2x.png" alt="cuaca">
<div class="condition-name" id="conditionName">Cerah</div>
</div>
<div class="icon-grid" id="iconGrid"></div>
</div>
<script>
const icons = [
{ code: '01d', name: 'Cerah' }, { code: '02d', name: 'Berawan Ringan' }, { code: '03d', name: 'Berawan' },
{ code: '04d', name: 'Berawan Tebal' }, { code: '09d', name: 'Hujan Gerimis' }, { code: '10d', name: 'Hujan' },
{ code: '11d', name: 'Badai Petir' }, { code: '13d', name: 'Salju' }, { code: '50d', name: 'Kabut' },
{ code: '01n', name: 'Cerah Malam' }
];

const grid = document.getElementById('iconGrid');
const mainIcon = document.getElementById('mainIcon');
const conditionName = document.getElementById('conditionName');

icons.forEach(icon => {
const btn = document.createElement('div');
btn.className = 'icon-btn';
btn.innerHTML = `<img src="https://openweathermap.org/img/wn/${icon.code}@2x.png" alt="${icon.name}"><div class="icon-code">${icon.code}</div>`;
btn.onclick = () => {
document.querySelectorAll('.icon-btn').forEach(b => b.classList.remove('active'));
btn.classList.add('active');
mainIcon.classList.add('fade');
setTimeout(() => {
mainIcon.src = `https://openweathermap.org/img/wn/${icon.code}@2x.png`;
conditionName.textContent = icon.name;
mainIcon.classList.remove('fade');
}, 300);
};
grid.appendChild(btn);
});
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Klik salah satu ikon untuk melihat perubahan. Ikon cuaca dari OpenWeatherMap berubah dengan animasi transisi.
