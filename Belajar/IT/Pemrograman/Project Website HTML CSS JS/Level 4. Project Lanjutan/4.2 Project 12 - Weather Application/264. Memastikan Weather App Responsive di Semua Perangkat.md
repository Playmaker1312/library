# 264. Memastikan Weather App Responsive di Semua Perangkat

## Definisi & Target
Memastikan Weather App dapat ditampilkan dengan baik di semua ukuran layar: desktop, tablet, dan smartphone.

## Analogi Alur
Responsive design seperti air yang mengisi wadah: bentuk air menyesuaikan dengan wadahnya. Website menyesuaikan tata letak dan ukuran elemen sesuai layar perangkat.

## Poin-Poin Penting
- Gunakan CSS Grid dan Flexbox untuk layout fleksibel
- Media queries untuk breakpoint: mobile (< 480px), tablet (768px), desktop (1024px+)
- Ukuran font relatif (rem, em) bukan px
- Images responsif dengan max-width: 100%
- Touch-friendly: tombol minimal 44x44px
- Test di berbagai device menggunakan Chrome DevTools
- Hindari overflow horizontal

const API_KEY = 'YOUR_API_KEY';
async function fetchWeather() {
const city = document.getElementById('cityInput').value.trim() || 'Jakarta';
try {
const res = await fetch(`https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${API_KEY}&units=metric`);
const d = await res.json();
if (!res.ok) return;
document.getElementById('cityName').textContent = `${d.name}, ${d.sys.country}`;
document.getElementById('tempDisplay').textContent = `${Math.round(d.main.temp)}°C`;

} catch {}
}
