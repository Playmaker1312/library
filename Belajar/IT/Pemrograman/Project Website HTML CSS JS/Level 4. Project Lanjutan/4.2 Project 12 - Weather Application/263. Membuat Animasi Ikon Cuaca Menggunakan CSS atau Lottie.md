# 263. Membuat Animasi Ikon Cuaca Menggunakan CSS atau Lottie

## Definisi & Target
Membuat animasi ikon cuaca kustom menggunakan CSS animations atau Lottie untuk memberikan tampilan yang lebih hidup dan menarik.

## Analogi Alur
Animasi ikon cuaca seperti lukisan bergerak: matahari tidak hanya diam, tapi berdenyut dan bersinar; awan bergerak perlahan; hujan turun; memberikan pengalaman visual yang lebih hidup.

## Poin-Poin Penting
- Ikon cuaca statis diganti dengan animasi CSS
- Gunakan @keyframes untuk animasi (pulse, float, rotate)
- Awan: animasi translateX bergerak perlahan
- Matahari: animasi rotate dan pulse
- Hujan: animasi garis turun dengan opacity bergantian
- Lottie: file JSON animasi yang ringan dan scalable
- Fallback ke ikon statis jika animasi tidak mendukung

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Animated Weather Icons</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1a3e; border-radius: 20px; padding: 30px; width: 100%; max-width: 550px; text-align: center; }
h1 { color: #667eea; margin-bottom: 20px; font-size: 22px; }
.icon-grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 15px; }
.icon-card { background: #12123a; border: 1px solid #2a2a5e; border-radius: 16px; padding: 25px 15px; cursor: pointer; transition: all 0.3s; }
.icon-card:hover { border-color: #667eea; transform: translateY(-5px); }
.icon-card.active { border-color: #667eea; background: rgba(102,126,234,0.1); }
.icon-card .icon-name { color: #888; font-size: 12px; margin-top: 10px; }

.sun { width: 60px; height: 60px; background: #ffd93d; border-radius: 50%; margin: 0 auto; box-shadow: 0 0 40px #ffd93d; animation: sunPulse 3s ease-in-out infinite; }
@keyframes sunPulse { 0%,100% { box-shadow: 0 0 40px #ffd93d; transform: scale(1); } 50% { box-shadow: 0 0 60px #ffd93d, 0 0 80px rgba(255,217,61,0.3); transform: scale(1.05); } }

.cloud { width: 80px; height: 30px; background: #b0bec5; border-radius: 30px; margin: 15px auto 0; position: relative; animation: cloudFloat 4s ease-in-out infinite; }
.cloud:before { content: ''; position: absolute; width: 34px; height: 34px; background: #b0bec5; border-radius: 50%; top: -17px; left: 15px; }
.cloud:after { content: ''; position: absolute; width: 24px; height: 24px; background: #b0bec5; border-radius: 50%; top: -12px; left: 40px; }
@keyframes cloudFloat { 0%,100% { transform: translateX(0); } 50% { transform: translateX(8px); } }

.rain { position: relative; width: 60px; height: 60px; margin: 0 auto; }
.rain-drop { position: absolute; width: 3px; height: 12px; background: #4fc3f7; border-radius: 2px; animation: rainFall 1s linear infinite; }
.rain-drop:nth-child(1) { left: 10px; animation-delay: 0s; } .rain-drop:nth-child(2) { left: 25px; animation-delay: 0.3s; } .rain-drop:nth-child(3) { left: 40px; animation-delay: 0.6s; }
@keyframes rainFall { 0% { transform: translateY(-20px); opacity: 0; } 50% { opacity: 1; } 100% { transform: translateY(50px); opacity: 0; } }

.moon { width: 50px; height: 50px; border-radius: 50%; background: transparent; margin: 0 auto; box-shadow: 10px -10px 0 0 #ffd93d; animation: moonGlow 4s ease-in-out infinite; }
@keyframes moonGlow { 0%,100% { box-shadow: 10px -10px 0 0 #ffd93d, 0 0 20px rgba(255,217,61,0.2); } 50% { box-shadow: 10px -10px 0 0 #ffd93d, 0 0 40px rgba(255,217,61,0.4); } }

.snow { position: relative; width: 60px; height: 60px; margin: 0 auto; }
.snow-flake { position: absolute; width: 6px; height: 6px; background: white; border-radius: 50%; animation: snowFall 3s linear infinite; opacity: 0.8; }
.snow-flake:nth-child(1) { left: 10px; animation-delay: 0s; } .snow-flake:nth-child(2) { left: 30px; animation-delay: 1s; } .snow-flake:nth-child(3) { left: 45px; animation-delay: 2s; }
@keyframes snowFall { 0% { transform: translateY(-20px) rotate(0deg); opacity: 0; } 50% { opacity: 1; } 100% { transform: translateY(50px) rotate(360deg); opacity: 0; } }

.storm { position: relative; width: 60px; height: 60px; margin: 0 auto; }
.storm-bolt { font-size: 40px; animation: stormFlash 2s ease-in-out infinite; }
@keyframes stormFlash { 0%,90%,100% { opacity: 0.3; } 92% { opacity: 1; } 95% { opacity: 0.3; } }
</style>
</head>
<body>
<div class="container">
<h1>🎨 Animasi Cuaca CSS</h1>
<div class="icon-grid">
<div class="icon-card" onclick="selectIcon(this)"><div class="sun"></div><div class="icon-name">Cerah</div></div>
<div class="icon-card" onclick="selectIcon(this)"><div class="cloud"></div><div class="icon-name">Berawan</div></div>
<div class="icon-card" onclick="selectIcon(this)"><div class="rain"><div class="rain-drop"></div><div class="rain-drop"></div><div class="rain-drop"></div></div><div class="icon-name">Hujan</div></div>
<div class="icon-card" onclick="selectIcon(this)"><div class="moon"></div><div class="icon-name">Malam</div></div>
<div class="icon-card" onclick="selectIcon(this)"><div class="snow"><div class="snow-flake"></div><div class="snow-flake"></div><div class="snow-flake"></div></div><div class="icon-name">Salju</div></div>
<div class="icon-card" onclick="selectIcon(this)"><div class="storm"><div class="storm-bolt">⚡</div></div><div class="icon-name">Badai</div></div>
</div>
</div>
<script>
function selectIcon(el) {
document.querySelectorAll('.icon-card').forEach(c => c.classList.remove('active'));
el.classList.add('active');
}
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Klik ikon untuk memilih. Semua ikon menggunakan animasi CSS murni tanpa library eksternal.
