# 260. Membuat Background atau Tema yang Berubah Sesuai Kondisi Cuaca

## Definisi & Target
Membuat background gradient atau tema yang berubah secara dinamis berdasarkan kondisi cuaca saat ini (cerah, hujan, malam, dll).

## Analogi Alur
Dynamic theme seperti lampu ruangan yang menyesuaikan dengan cuaca di luar: saat cerah, lampu terang dan hangat; saat hujan, lampu redup dan biru; saat malam, lampu gelap.

## Poin-Poin Penting
- Mapping kode ikon cuaca ke tema warna
- Cerah: oranye/kuning (warna hangat)
- Hujan: biru/abu-abu (warna dingin)
- Malam: gelap/navy
- Salju: putih/biru muda
- Gunakan CSS gradient yang berubah via JavaScript
- Transisi halus saat berganti tema
- Simpan tema di state aplikasi

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Dynamic Weather Theme</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; transition: background 1s ease; }
.container { background: rgba(255,255,255,0.12); backdrop-filter: blur(20px); border-radius: 24px; padding: 35px; width: 100%; max-width: 420px; border: 1px solid rgba(255,255,255,0.2); color: white; text-align: center; }
h1 { margin-bottom: 20px; font-size: 22px; text-shadow: 0 2px 10px rgba(0,0,0,0.3); }
.weather-icon img { width: 100px; height: 100px; filter: drop-shadow(0 4px 15px rgba(0,0,0,0.3)); }
.temp { font-size: 64px; font-weight: 700; margin: 10px 0; text-shadow: 0 2px 20px rgba(0,0,0,0.2); }
.city { font-size: 20px; opacity: 0.9; }
.desc { font-size: 16px; opacity: 0.6; text-transform: capitalize; }
.theme-grid { display: grid; grid-template-columns: repeat(5, 1fr); gap: 8px; margin-top: 25px; }
.theme-btn { padding: 10px; border: 2px solid rgba(255,255,255,0.15); border-radius: 12px; background: rgba(255,255,255,0.05); cursor: pointer; transition: all 0.3s; color: white; font-size: 20px; }
.theme-btn:hover { border-color: rgba(255,255,255,0.4); background: rgba(255,255,255,0.1); }
.theme-btn.active { border-color: white; background: rgba(255,255,255,0.15); }
</style>
</head>
<body id="bodyEl">
<div class="container">
<h1>🎨 Dynamic Theme</h1>
<div class="weather-icon"><img id="weatherIcon" src="https://openweathermap.org/img/wn/01d@2x.png" alt="cuaca"></div>
<div class="temp" id="tempDisplay">30°C</div>
<div class="city" id="cityName">Jakarta</div>
<div class="desc" id="descDisplay">Cerah</div>
<div class="theme-grid">
<div class="theme-btn active" onclick="setTheme('clear')">☀️</div>
<div class="theme-btn" onclick="setTheme('cloudy')">☁️</div>
<div class="theme-btn" onclick="setTheme('rainy')">🌧️</div>
<div class="theme-btn" onclick="setTheme('night')">🌙</div>
<div class="theme-btn" onclick="setTheme('snowy')">❄️</div>
</div>
</div>
<script>
const themes = {
clear: 'linear-gradient(135deg, #f093fb 0%, #f5576c 100%)',
cloudy: 'linear-gradient(135deg, #2c3e50, #bdc3c7)',
rainy: 'linear-gradient(135deg, #1e3c72, #2a5298)',
night: 'linear-gradient(135deg, #0f0c29, #302b63, #24243e)',
snowy: 'linear-gradient(135deg, #e6e9f0, #eef1f5)'
};

function setTheme(type) {
document.querySelectorAll('.theme-btn').forEach(b => b.classList.remove('active'));
event.target.classList.add('active');
document.getElementById('bodyEl').style.background = themes[type];
const textColor = type === 'snowy' ? '#333' : 'white';
document.querySelector('.container').style.color = textColor;
}

const icons = {
'01d': 'clear', '02d': 'cloudy', '03d': 'cloudy', '04d': 'cloudy',
'09d': 'rainy', '10d': 'rainy', '11d': 'rainy', '13d': 'snowy', '50d': 'cloudy',
'01n': 'night', '02n': 'night', '03n': 'night', '04n': 'night'
};

const API_KEY = 'YOUR_API_KEY';
async function fetchWeather() {
try {
const res = await fetch(`https://api.openweathermap.org/data/2.5/weather?q=Jakarta&appid=${API_KEY}&units=metric`);
const d = await res.json();
if (!res.ok) return;
const iconCode = d.weather[0].icon;
document.getElementById('weatherIcon').src = `https://openweathermap.org/img/wn/${iconCode}@2x.png`;
document.getElementById('tempDisplay').textContent = `${Math.round(d.main.temp)}°C`;
document.getElementById('cityName').textContent = d.name;
document.getElementById('descDisplay').textContent = d.weather[0].description;
const theme = icons[iconCode] || 'clear';
setTheme(theme);
document.querySelectorAll('.theme-btn').forEach(b => b.classList.remove('active'));
} catch {}
}
fetchWeather();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Ganti `YOUR_API_KEY`. Klik tombol tema untuk preview. Data API akan mengatur tema otomatis sesuai cuaca.
