# 250. Mengimplementasikan Fetch API untuk Mengambil Data Cuaca Berdasarkan Nama Kota

## Definisi & Target
Menggunakan Fetch API JavaScript untuk mengambil data cuaca dari OpenWeatherMap berdasarkan nama kota yang diinput user.

## Analogi Alur
Fetch API seperti mengirim kurir ke perpustakaan (server OpenWeatherMap) dengan surat berisi nama kota. Kurir kembali membawa buku (data JSON) berisi informasi cuaca kota tersebut.

## Poin-Poin Penting
- Gunakan fetch() dengan URL endpoint current weather
- Sertakan parameter q (city name), appid, dan units
- Konversi response ke JSON dengan response.json()
- Handle response.ok untuk error handling
- Tangkap error network dengan try/catch
- Tampilkan loading state selama fetch
- Simpan API Key di variabel terpisah

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Fetch API Weather</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1a3e; border-radius: 16px; padding: 30px; width: 100%; max-width: 500px; }
h1 { text-align: center; color: #667eea; margin-bottom: 20px; font-size: 22px; }
.input-group { display: flex; gap: 10px; margin-bottom: 20px; }
.input-group input { flex: 1; padding: 12px 16px; border: 2px solid #2a2a5e; border-radius: 10px; font-size: 15px; background: #12123a; color: #fff; outline: none; }
.input-group button { padding: 12px 20px; background: #667eea; border: none; border-radius: 10px; color: white; font-size: 15px; cursor: pointer; }
.result-card { background: #12123a; border: 1px solid #2a2a5e; border-radius: 12px; padding: 20px; display: none; }
.result-card.show { display: block; animation: fadeIn 0.5s ease; }
@keyframes fadeIn { from { opacity: 0; transform: translateY(10px); } to { opacity: 1; transform: translateY(0); } }
.city-name { color: #fff; font-size: 24px; font-weight: 600; }
.temp { font-size: 48px; color: #667eea; font-weight: 600; margin: 10px 0; }
.desc { color: #aaa; font-size: 16px; text-transform: capitalize; }
.details { display: grid; grid-template-columns: repeat(3, 1fr); gap: 10px; margin-top: 15px; }
.detail-item { background: #0f0c29; padding: 10px; border-radius: 8px; text-align: center; }
.detail-label { color: #666; font-size: 11px; }
.detail-value { color: #ddd; font-size: 16px; font-weight: 600; }
.loading { text-align: center; color: #888; padding: 30px; display: none; }
.loading.show { display: block; }
.error-msg { text-align: center; color: #e94560; padding: 20px; display: none; }
.error-msg.show { display: block; }
</style>
</head>
<body>
<div class="container">
<h1>🌤️ Fetch Weather</h1>
<div class="input-group">
<input type="text" id="cityInput" placeholder="Nama kota..." value="Jakarta">
<button onclick="getWeather()">Cari</button>
</div>
<div class="loading show" id="loading">Memuat data...</div>
<div class="result-card" id="resultCard">
<div class="city-name" id="cityName"></div>
<div class="temp" id="temperature"></div>
<div class="desc" id="description"></div>
<div class="details">
<div class="detail-item"><div class="detail-label">Humidity</div><div class="detail-value" id="humidity">-</div></div>
<div class="detail-item"><div class="detail-label">Wind</div><div class="detail-value" id="wind">-</div></div>
<div class="detail-item"><div class="detail-label">Pressure</div><div class="detail-value" id="pressure">-</div></div>
</div>
</div>
<div class="error-msg" id="errorMsg"></div>
</div>
<script>
const API_KEY = 'YOUR_API_KEY'; // Ganti dengan API key Anda

async function getWeather() {
const city = document.getElementById('cityInput').value.trim();
if (!city) return;

const loading = document.getElementById('loading');
const resultCard = document.getElementById('resultCard');
const errorMsg = document.getElementById('errorMsg');

loading.classList.add('show');
resultCard.classList.remove('show');
errorMsg.classList.remove('show');

try {
const res = await fetch(`https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${API_KEY}&units=metric`);
const data = await res.json();

if (!res.ok) {
errorMsg.textContent = `Error ${data.cod}: ${data.message}`;
errorMsg.classList.add('show');
loading.classList.remove('show');
return;
}

document.getElementById('cityName').textContent = `${data.name}, ${data.sys.country}`;
document.getElementById('temperature').textContent = `${Math.round(data.main.temp)}°C`;
document.getElementById('description').textContent = data.weather[0].description;
document.getElementById('humidity').textContent = `${data.main.humidity}%`;
document.getElementById('wind').textContent = `${data.wind.speed} m/s`;
document.getElementById('pressure').textContent = `${data.main.pressure} hPa`;

resultCard.classList.add('show');
} catch (err) {
errorMsg.textContent = `Gagal terhubung: ${err.message}`;
errorMsg.classList.add('show');
}
loading.classList.remove('show');
}

document.getElementById('cityInput').addEventListener('keypress', e => { if (e.key === 'Enter') getWeather(); });
getWeather();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Ganti `YOUR_API_KEY` dengan key OpenWeatherMap Anda. Masukkan nama kota dan klik Cari untuk melihat data cuaca.
