# 248. Memahami Struktur Response API OpenWeatherMap

## Definisi & Target
Mempelajari struktur JSON response dari OpenWeatherMap API untuk current weather dan forecast agar dapat mengekstrak data yang diperlukan.

## Analogi Alur
Struktur response API seperti lemari arsip dengan banyak laci: Anda perlu tahu di laci mana (property) menyimpan suhu, deskripsi cuaca, kelembaban, dll.

## Poin-Poin Penting
- Response JSON memiliki nested objects: main, weather, wind, sys, dll
- main.temp: suhu dalam satuan yang diminta
- weather[0].description: deskripsi cuaca
- weather[0].icon: kode ikon cuaca
- main.humidity: kelembaban dalam persen
- wind.speed: kecepatan angin
- sys.sunrise dan sys.sunset: waktu matahari terbit/terbenam
- Forecast response: list[] berisi data per 3 jam
