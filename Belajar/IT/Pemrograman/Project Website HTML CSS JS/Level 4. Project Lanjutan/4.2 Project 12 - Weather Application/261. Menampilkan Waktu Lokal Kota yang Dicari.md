# 261. Menampilkan Waktu Lokal Kota yang Dicari

## Definisi & Target
Menampilkan waktu lokal dari kota yang sedang ditampilkan berdasarkan timezone offset dari response API.

## Analogi Alur
Waktu lokal kota seperti jam dunia di bandara: Anda bisa melihat jam berapa sekarang di kota yang Anda cari meskipun berbeda zona waktu dengan lokasi Anda.

## Poin-Poin Penting
- Gunakan properti timezone dari response API (offset dalam detik)
- Konversi offset ke zona waktu JavaScript
- Tampilkan jam digital yang berjalan (update setiap detik)
- Format waktu dengan toLocaleString() sesuai locale kota
- Tampilkan perbedaan waktu dengan zona lokal user
- Animasi detik yang real-time
- Informasi sunrise dan sunset dalam waktu lokal

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Local Time Weather</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1a3e; border-radius: 20px; padding: 30px; width: 100%; max-width: 480px; text-align: center; }
h1 { color: #667eea; margin-bottom: 20px; font-size: 22px; }
.time-display { background: #12123a; border: 1px solid #2a2a5e; border-radius: 16px; padding: 25px; margin-bottom: 20px; }
.city-name { color: #fff; font-size: 20px; margin-bottom: 5px; }
.local-time { font-size: 52px; font-weight: 700; color: #fff; font-family: 'Courier New', monospace; letter-spacing: 2px; }
.timezone { color: #888; font-size: 14px; margin-top: 5px; }
.sun-info { display: flex; justify-content: center; gap: 30px; margin-top: 15px; color: #aaa; font-size: 13px; }
.weather-info { background: #12123a; border: 1px solid #2a2a5e; border-radius: 12px; padding: 20px; }
.weather-info .temp { font-size: 36px; color: #667eea; font-weight: 600; }
.weather-info .desc { color: #aaa; font-size: 14px; text-transform: capitalize; }
.input-group { display: flex; gap: 10px; margin-bottom: 20px; }
.input-group input { flex: 1; padding: 12px 16px; border: 2px solid #2a2a5e; border-radius: 10px; background: #12123a; color: #fff; font-size: 15px; outline: none; }
.input-group button { padding: 12px 20px; background: #667eea; border: none; border-radius: 10px; color: white; font-size: 15px; cursor: pointer; }
</style>
</head>
<body>
<div class="container">
<h1>🕐 Waktu Lokal</h1>
<div class="input-group">
<input type="text" id="cityInput" value="Tokyo" placeholder="Nama kota...">
<button onclick="fetchWeather()">Cari</button>
</div>
<div class="time-display">
<div class="city-name" id="cityName">Tokyo, JP</div>
<div class="local-time" id="localTime">--:--:--</div>
<div class="timezone" id="timezone">GMT+9</div>
<div class="sun-info"><span>🌅 <span id="sunrise">-</span></span><span>🌇 <span id="sunset">-</span></span></div>
</div>
<div class="weather-info">
<div class="temp" id="tempDisplay">-</div>
<div class="desc" id="descDisplay">-</div>
</div>

<script>
const API_KEY = 'YOUR_API_KEY';
let timezoneOffset = 0;
let clockInterval = null;

function updateClock() {
const now = new Date();
const utc = now.getTime() + (now.getTimezoneOffset() * 60000);
const local = new Date(utc + (timezoneOffset * 1000));
document.getElementById('localTime').textContent = local.toLocaleTimeString('id-ID', { hour12: false });
}

async function fetchWeather() {
const city = document.getElementById('cityInput').value.trim() || 'Tokyo';
try {
const res = await fetch(`https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${API_KEY}&units=metric`);
const d = await res.json();
if (!res.ok) return;

timezoneOffset = d.timezone;
document.getElementById('cityName').textContent = `${d.name}, ${d.sys.country}`;
const tz = timezoneOffset >= 0 ? `GMT+${timezoneOffset / 3600}` : `GMT${timezoneOffset / 3600}`;
document.getElementById('timezone').textContent = tz;
document.getElementById('sunrise').textContent = new Date((d.sys.sunrise + timezoneOffset) * 1000).toLocaleTimeString('id-ID', { hour12: false, hour: '2-digit', minute: '2-digit' });
document.getElementById('sunset').textContent = new Date((d.sys.sunset + timezoneOffset) * 1000).toLocaleTimeString('id-ID', { hour12: false, hour: '2-digit', minute: '2-digit' });
document.getElementById('tempDisplay').textContent = `${Math.round(d.main.temp)}°C`;
document.getElementById('descDisplay').textContent = d.weather[0].description;

if (clockInterval) clearInterval(clockInterval);
updateClock();
clockInterval = setInterval(updateClock, 1000);
} catch {}
}

document.getElementById('cityInput').addEventListener('keypress', e => { if (e.key === 'Enter') fetchWeather(); });
fetchWeather();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Ganti `YOUR_API_KEY`. Cari kota untuk melihat waktu lokal yang berjalan real-time, sunrise, dan sunset dalam zona waktu kota tersebut.
