# 258. Menyimpan Kota Terakhir yang Dicari ke LocalStorage

## Definisi & Target
Menyimpan nama kota terakhir yang dicari user ke LocalStorage agar saat halaman dimuat ulang, kota tersebut langsung ditampilkan.

## Analogi Alur
Menyimpan kota terakhir seperti bookmark halaman buku: Anda memberi tanda di halaman terakhir yang dibaca. Saat membuka buku lagi, Anda langsung ke halaman itu tanpa perlu mencari dari awal.

## Poin-Poin Penting
- Simpan nama kota ke LocalStorage setiap kali pencarian sukses
- Load kota terakhir saat inisialisasi halaman
- Tampilkan di input field atau sebagai badge
- Jika tidak ada data, gunakan default city (e.g., Jakarta)
- Handle error jika data LocalStorage rusak
- Update value input field dengan kota tersimpan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html

<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Last City Search</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: linear-gradient(135deg, #1e3c72, #2a5298); min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: rgba(255,255,255,0.1); backdrop-filter: blur(15px); border-radius: 20px; padding: 30px; width: 100%; max-width: 480px; border: 1px solid rgba(255,255,255,0.15); color: white; }

.weather-display { background: rgba(255,255,255,0.05); border-radius: 16px; padding: 25px; text-align: center; min-height: 150px; display: flex; flex-direction: column; align-items: center; justify-content: center; }
.weather-display .city { font-size: 22px; font-weight: 600; }

</style>
</head>
<body>
<div class="container">
<h1>💾 Last City</h1>
<p class="subtitle">Kota terakhir tersimpan otomatis</p>
<div class="input-group">
<input type="text" id="cityInput" placeholder="Cari kota...">

</div>

<div class="temp" id="tempDisplay">30°C</div>

</div>

<script>
const API_KEY = 'YOUR_API_KEY';
const STORAGE_KEY = 'weather_last_city';

function loadLastCity() {
try {
return localStorage.getItem(STORAGE_KEY) || 'Jakarta';
} catch { return 'Jakarta'; }
}

function saveLastCity(city) {
try { localStorage.setItem(STORAGE_KEY, city); } catch {}
}

async function searchCity(city) {
city = city || document.getElementById('cityInput').value.trim();
if (!city) city = 'Jakarta';
document.getElementById('cityInput').value = city;

try {
const res = await fetch(`https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${API_KEY}&units=metric`);
const d = await res.json();
if (!res.ok) return;
document.getElementById('cityName').textContent = `${d.name}, ${d.sys.country}`;
document.getElementById('tempDisplay').textContent = `${Math.round(d.main.temp)}°C`;
document.getElementById('descDisplay').textContent = d.weather[0].description;
document.getElementById('statusText').textContent = `💾 Tersimpan: ${d.name}`;
saveLastCity(city);
} catch {}
}

const lastCity = loadLastCity();
document.getElementById('cityInput').value = lastCity;
searchCity(lastCity);

document.getElementById('cityInput').addEventListener('keypress', e => {
if (e.key === 'Enter') searchCity();
});
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Ganti `YOUR_API_KEY`. Cari kota dan data akan tersimpan. Refresh halaman, kota terakhir akan langsung dimuat.
