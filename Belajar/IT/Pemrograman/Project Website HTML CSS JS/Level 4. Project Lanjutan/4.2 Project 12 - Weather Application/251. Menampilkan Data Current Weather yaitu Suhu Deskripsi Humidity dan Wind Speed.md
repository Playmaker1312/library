# 251. Menampilkan Data Current Weather yaitu Suhu, Deskripsi, Humidity, dan Wind Speed

## Definisi & Target
Membangun tampilan utama yang menampilkan data cuaca saat ini: suhu, deskripsi cuaca, kelembaban (humidity), dan kecepatan angin (wind speed).

## Analogi Alur
Tampilan current weather seperti dasbor cuaca di bandara: ada termometer raksasa (suhu), tulisan kondisi (deskripsi), indikator kelembaban, dan alat ukur angin.

## Poin-Poin Penting
- Suhu ditampilkan besar dan menonjol di bagian atas
- Deskripsi cuaca dengan teks yang mudah dibaca
- Humidity ditampilkan dengan ikon 💧
- Wind speed ditampilkan dengan ikon 💨
- Ikon cuaca dari OpenWeatherMap (https://openweathermap.org/weather/conditions)
- Animasi masuk yang halus saat data ditampilkan
- Warna tema menyesuaikan kondisi cuaca (panas, dingin, hujan)

<script>
const API_KEY = 'YOUR_API_KEY';
async function fetchWeather(city = 'Jakarta') {
try {
const res = await fetch(`https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${API_KEY}&units=metric`);
const d = await res.json();
if (!res.ok) return;
document.getElementById('location').textContent = `${d.name}, ${d.sys.country}`;
document.getElementById('date').textContent = new Date().toLocaleDateString('id-ID', { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' });
document.getElementById('weatherIcon').src = `https://openweathermap.org/img/wn/${d.weather[0].icon}@2x.png`;
document.getElementById('tempMain').textContent = `${Math.round(d.main.temp)}°C`;
document.getElementById('tempFeel').textContent = `Terasa ${Math.round(d.main.feels_like)}°C`;
document.getElementById('description').textContent = d.weather[0].description;
document.getElementById('humidity').textContent = `${d.main.humidity}%`;
document.getElementById('windSpeed').textContent = `${d.wind.speed} m/s`;
document.getElementById('visibility').textContent = `${(d.visibility / 1000).toFixed(1)} km`;
} catch (e) { console.log('Gunakan demo data'); }
}
fetchWeather();
</script>

## Cara Integrasi
Simpan sebagai HTML. Ganti `YOUR_API_KEY` dengan key OpenWeatherMap. Data cuaca ditampilkan dengan layout modern dan ikon dinamis.
