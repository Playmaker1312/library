# 255. Mengimplementasikan Toggle antara Celsius dan Fahrenheit

## Definisi & Target
Menambahkan tombol toggle yang memungkinkan user beralih antara satuan suhu Celsius (°C) dan Fahrenheit (°F).

## Analogi Alur
Toggle °C/°F seperti mengganti penggaris: Anda bisa memilih antara sentimeter (Celsius) atau inci (Fahrenheit). Angka berubah tapi suhu yang diukur tetap sama.

## Poin-Poin Penting
- Konversi: °F = (°C × 9/5) + 32
- Toggle button atau switch yang jelas
- Simpan preferensi satuan ke LocalStorage
- Update semua angka suhu saat toggle
- Animasi transisi saat angka berubah
- Tandai satuan aktif dengan gaya berbeda
- Juga konversi feels_like, temp_min, temp_max

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Toggle °C/°F</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: linear-gradient(135deg, #1e3c72, #2a5298); min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: rgba(255,255,255,0.1); backdrop-filter: blur(15px); border-radius: 24px; padding: 30px; width: 100%; max-width: 420px; border: 1px solid rgba(255,255,255,0.15); color: white; text-align: center; }
h1 { margin-bottom: 20px; font-size: 22px; }
.toggle-container { display: flex; justify-content: center; margin-bottom: 25px; }
.toggle-btn { padding: 10px 30px; border: 2px solid rgba(255,255,255,0.2); background: transparent; color: rgba(255,255,255,0.5); cursor: pointer; font-size: 16px; font-weight: 600; transition: all 0.3s; }
.toggle-btn:first-child { border-radius: 10px 0 0 10px; border-right: none; }
.toggle-btn:last-child { border-radius: 0 10px 10px 0; }
.toggle-btn.active { background: rgba(255,255,255,0.15); color: white; border-color: rgba(255,255,255,0.3); }
.temp-display { font-size: 72px; font-weight: 700; margin: 10px 0; transition: all 0.3s; }
.city-name { font-size: 18px; opacity: 0.8; }
.desc { font-size: 16px; opacity: 0.6; text-transform: capitalize; margin-bottom: 20px; }
.details { display: grid; grid-template-columns: repeat(2, 1fr); gap: 10px; }
.detail-box { background: rgba(255,255,255,0.06); padding: 12px; border-radius: 12px; }
.detail-label { font-size: 12px; opacity: 0.5; }
.detail-value { font-size: 18px; font-weight: 600; margin-top: 4px; }
</style>
</head>
<body>
<div class="container">
<h1>🌡️ Toggle Suhu</h1>
<div class="toggle-container">
<button class="toggle-btn active" id="cBtn" onclick="setUnit('metric')">°C</button>
<button class="toggle-btn" id="fBtn" onclick="setUnit('imperial')">°F</button>
</div>
<div class="city-name" id="cityName">Jakarta, ID</div>
<div class="temp-display" id="tempDisplay">30°C</div>
<div class="desc" id="desc">Berawan</div>
<div class="details">
<div class="detail-box"><div class="detail-label">Feels Like</div><div class="detail-value" id="feelsLike">33°</div></div>
<div class="detail-box"><div class="detail-label">Min / Max</div><div class="detail-value" id="minmax">28° / 32°</div></div>
</div>
</div>
<script>
const API_KEY = 'YOUR_API_KEY';
let currentUnit = localStorage.getItem('weather_unit') || 'metric';
let weatherData = null;

function initToggle() {
if (currentUnit === 'imperial') {
document.getElementById('cBtn').classList.remove('active');
document.getElementById('fBtn').classList.add('active');
}
}

async function fetchWeather(city = 'Jakarta') {
try {
const res = await fetch(`https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${API_KEY}&units=${currentUnit}`);
weatherData = await res.json();
if (res.ok) updateDisplay();
} catch (e) {}
}

function updateDisplay() {
if (!weatherData) return;
const d = weatherData;
document.getElementById('cityName').textContent = `${d.name}, ${d.sys.country}`;
const unit = currentUnit === 'metric' ? '°C' : '°F';
document.getElementById('tempDisplay').textContent = `${Math.round(d.main.temp)}${unit}`;
document.getElementById('desc').textContent = d.weather[0].description;
document.getElementById('feelsLike').textContent = `${Math.round(d.main.feels_like)}${unit}`;
document.getElementById('minmax').textContent = `${Math.round(d.main.temp_min)}${unit} / ${Math.round(d.main.temp_max)}${unit}`;
}

function setUnit(unit) {
if (unit === currentUnit) return;
currentUnit = unit;
localStorage.setItem('weather_unit', unit);
document.getElementById('cBtn').classList.toggle('active', unit === 'metric');
document.getElementById('fBtn').classList.toggle('active', unit === 'imperial');
if (weatherData) {
const tempC = weatherData.main.temp;
const feelsC = weatherData.main.feels_like;
const minC = weatherData.main.temp_min;
const maxC = weatherData.main.temp_max;
const unitSym = unit === 'metric' ? '°C' : '°F';
const conv = (t) => unit === 'metric' ? t : (t * 9/5) + 32;
document.getElementById('tempDisplay').textContent = `${Math.round(conv(tempC))}${unitSym}`;
document.getElementById('feelsLike').textContent = `${Math.round(conv(feelsC))}${unitSym}`;
document.getElementById('minmax').textContent = `${Math.round(conv(minC))}${unitSym} / ${Math.round(conv(maxC))}${unitSym}`;
}
}

initToggle();
fetchWeather();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Ganti `YOUR_API_KEY`. Klik °C atau °F untuk toggle satuan suhu. Preferensi tersimpan di LocalStorage.
