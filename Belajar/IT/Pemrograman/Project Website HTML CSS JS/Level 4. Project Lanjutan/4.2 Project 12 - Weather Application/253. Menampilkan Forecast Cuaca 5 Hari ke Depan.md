# 253. Menampilkan Forecast Cuaca 5 Hari ke Depan

## Definisi & Target
Menampilkan prakiraan cuaca untuk 5 hari ke depan menggunakan endpoint forecast OpenWeatherMap API.

## Analogi Alur
Forecast 5 hari seperti kalender cuaca: setiap halaman (hari) berisi ramalan cuaca untuk hari itu. Anda bisa melihat cuaca hari ini, besok, dan seterusnya.

## Poin-Poin Penting
- Gunakan endpoint: api.openweathermap.org/data/2.5/forecast
- Response berisi data per 3 jam (8 data per hari)
- Kelompokkan data per hari untuk ringkasan harian
- Tampilkan suhu max/min, ikon, dan deskripsi per hari
- Format tanggal ke nama hari (Senin, Selasa, dll)
- Scroll horizontal untuk tampilan forecast
- Ikon cuaca sesuai kondisi setiap hari

```html
<div class="container">
<h1>📅 5-Day Forecast</h1>
<p class="subtitle">Prakiraan cuaca 5 hari ke depan</p>

<input type="text" id="cityInput" value="Jakarta" placeholder="Nama kota...">

<script>
const API_KEY = 'YOUR_API_KEY';

async function fetchForecast() {
const city = document.getElementById('cityInput').value.trim() || 'Jakarta';
const container = document.getElementById('forecastContainer');
container.innerHTML = '<div style="text-align:center;padding:20px;opacity:0.5">Memuat data...</div>';

try {
const res = await fetch(`https://api.openweathermap.org/data/2.5/forecast?q=${city}&appid=${API_KEY}&units=metric`);
const data = await res.json();
if (!res.ok) { container.innerHTML = `<div style="text-align:center;padding:20px;color:#e94560">${data.message}</div>`; return; }

const daily = {};
data.list.forEach(item => {
const date = item.dt_txt.split(' ')[0];
if (!daily[date]) daily[date] = [];
daily[date].push(item);
});

const days = Object.keys(daily).slice(0, 5);
const dayNames = ['Minggu', 'Senin', 'Selasa', 'Rabu', 'Kamis', 'Jumat', 'Sabtu'];

container.innerHTML = days.map(date => {
const items = daily[date];
const temps = items.map(i => i.main.temp);
const min = Math.min(...temps);
const max = Math.max(...temps);
const midday = items.find(i => i.dt_txt.includes('12:00')) || items[Math.floor(items.length / 2)];
const dayName = dayNames[new Date(date).getDay()];
const isToday = date === new Date().toISOString().split('T')[0];
return `<div class="day-card">
  <div class="day-name">${isToday ? 'Hari Ini' : dayName}</div>
  <div class="day-icon"><img src="https://openweathermap.org/img/wn/${midday.weather[0].icon}@2x.png" alt="cuaca"></div>
  <div class="day-temp">${Math.round(midday.main.temp)}°C</div>
  <div class="day-desc">${midday.weather[0].description}</div>
  <div class="day-range">${Math.round(min)}° / ${Math.round(max)}°</div>
</div>`;
}).join('');
} catch (e) {
container.innerHTML = '<div style="text-align:center;padding:20px;color:#e94560">Gagal memuat data</div>';
}
}

document.getElementById('cityInput').addEventListener('keypress', e => { if (e.key === 'Enter') fetchForecast(); });
fetchForecast();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Ganti `YOUR_API_KEY`. Masukkan nama kota untuk melihat forecast 5 hari dengan scroll horizontal.
