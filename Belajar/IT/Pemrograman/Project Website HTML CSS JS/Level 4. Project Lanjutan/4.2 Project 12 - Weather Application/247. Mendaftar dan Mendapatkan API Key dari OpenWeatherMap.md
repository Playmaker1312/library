# 247. Mendaftar dan Mendapatkan API Key dari OpenWeatherMap

## Definisi & Target
Proses registrasi akun di OpenWeatherMap, mendapatkan API key gratis, dan memahami cara menggunakannya dalam aplikasi.

## Analogi Alur
API Key seperti kartu anggota gym: Anda mendaftar untuk menjadi member (registrasi), mendapatkan kartu akses (API Key), lalu menggunakan kartu itu setiap kali masuk gym (request API).

## Poin-Poin Penting
- Kunjungi openweathermap.org dan daftar akun gratis
- API Key tersedia di dashboard setelah login
- Aktivasi API Key membutuhkan waktu beberapa jam
- Gunakan key di URL request: api.openweathermap.org/data/2.5/weather?q=Bandung&appid=YOUR_KEY
- Jangan pernah expose API Key di client-side secara publik
- Simpan API Key di environment variable atau config terpisah
- Rate limit untuk free plan: 60 requests/menit

async function testConnection() {

result.className = 'result-box error';
result.textContent = `❌ Error ${data.cod}: ${data.message}`;
}
} catch (err) {
result.className = 'result-box error';
result.textContent = `❌ Gagal terhubung: ${err.message}`;
}
btn.disabled = false; btn.textContent = 'Test Koneksi API';
}
</script>
