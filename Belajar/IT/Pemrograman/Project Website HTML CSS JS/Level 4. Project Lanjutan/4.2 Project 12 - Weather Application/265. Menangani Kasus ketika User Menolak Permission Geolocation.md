# 265. Menangani Kasus ketika User Menolak Permission Geolocation

## Definisi & Target
Menangani skenario ketika user menolak izin geolocation dengan memberikan fallback dan pesan yang informatif.

## Analogi Alur
Penolakan geolocation seperti menolak memberikan alamat rumah ke petugas: petugas tidak bisa mengirim barang ke rumah, tapi masih bisa menggunakan alamat lain (kota default) atau mencari sendiri.

## Poin-Poin Penting
- Deteksi error code: PERMISSION_DENIED (1), POSITION_UNAVAILABLE (2), TIMEOUT (3)
- Tampilkan pesan yang user-friendly sesuai jenis error
- Fallback ke kota default (Jakarta atau kota terakhir)
- Beri tombol "Coba Lagi" untuk mengulang permintaan
- Jangan looping request jika ditolak (browser akan block)
- Simpan preferensi user (tidak meminta lagi)
- Gunakan input manual sebagai alternatif utama

```html
<script>
const API_KEY = 'YOUR_API_KEY';
const DEFAULT = 'Jakarta';

function showNotification(msg, type = 'info') {
const el = document.getElementById('notification');
el.textContent = msg;
el.className = `notification ${type} show`;
setTimeout(() => el.classList.remove('show'), 5000);
}

function requestLocation() {
if (!navigator.geolocation) {
showNotification('Geolocation tidak didukung browser ini', 'warning');
fetchWeather(DEFAULT);
return;
}

showNotification('Meminta izin lokasi...', 'info');

navigator.geolocation.getCurrentPosition(
async (pos) => {
showNotification('✅ Lokasi terdeteksi!', 'success');
const { latitude, longitude } = pos.coords;
try {
const res = await fetch(`https://api.openweathermap.org/data/2.5/weather?lat=${latitude}&lon=${longitude}&appid=${API_KEY}&units=metric`);
const d = await res.json();
if (res.ok) {
document.getElementById('cityName').textContent = `${d.name}, ${d.sys.country}`;
document.getElementById('tempDisplay').textContent = `${Math.round(d.main.temp)}°C`;
}
} catch {}
},
(error) => {
if (error.code === 1) {
showNotification('⚠️ Izin lokasi ditolak. Silakan cari manual atau aktifkan GPS di pengaturan browser.', 'warning');
} else if (error.code === 2) {
showNotification('📍 Posisi tidak tersedia. Gunakan pencarian manual.', 'warning');
} else if (error.code === 3) {
showNotification('⏳ Waktu permintaan habis. Coba lagi.', 'warning');
}
fetchWeather(DEFAULT);
},
{ enableHighAccuracy: true, timeout: 8000, maximumAge: 60000 }
);
}

function searchManual() {
const city = document.getElementById('cityInput').value.trim();
if (city) fetchWeather(city);
}

async function fetchWeather(city) {
try {
const res = await fetch(`https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${API_KEY}&units=metric`);
const d = await res.json();
if (!res.ok) { showNotification(`Kota "${city}" tidak ditemukan`, 'warning'); return; }
document.getElementById('cityName').textContent = `${d.name}, ${d.sys.country}`;
document.getElementById('tempDisplay').textContent = `${Math.round(d.main.temp)}°C`;
} catch {
showNotification('Gagal terhubung ke server', 'warning');
}
}

fetchWeather(DEFAULT);
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Ganti `YOUR_API_KEY`. Klik "Deteksi Lokasi" dan pilih Blokir untuk melihat penanganan penolakan. Gunakan pencarian manual sebagai fallback.
