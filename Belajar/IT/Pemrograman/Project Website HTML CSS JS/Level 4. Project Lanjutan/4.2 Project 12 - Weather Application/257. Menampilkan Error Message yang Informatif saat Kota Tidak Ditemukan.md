# 257. Menampilkan Error Message yang Informatif saat Kota Tidak Ditemukan

## Definisi & Target
Menampilkan pesan error yang ramah dan informatif ketika API mengembalikan error (kota tidak ditemukan, network error, dll).

## Analogi Alur
Error message seperti rambu "Jalan Buntu": alih-alih diam saja dan membiarkan user bingung, Anda memasang rambu yang jelas bahwa jalan tidak ditemukan dan memberikan saran alternatif.

## Poin-Poin Penting
- Tangkap error dari response API (404, 401, dll)
- Tampilkan pesan yang user-friendly, bukan raw JSON
- Bedakan jenis error: invalid city, API key salah, network error
- Sertakan ikon atau ilustrasi yang sesuai
- Tombol "Coba Lagi" untuk memudahkan
- Animasi masuk yang halus untuk error message
- Jangan reset data cuaca sebelumnya jika ada

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Error Handling Weather</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1a3e; border-radius: 20px; padding: 30px; width: 100%; max-width: 500px; }
h1 { text-align: center; color: #667eea; margin-bottom: 20px; font-size: 22px; }
.input-group { display: flex; gap: 10px; margin-bottom: 20px; }
.input-group input { flex: 1; padding: 12px 16px; border: 2px solid #2a2a5e; border-radius: 10px; font-size: 15px; background: #12123a; color: #fff; outline: none; }
.input-group input:focus { border-color: #667eea; }
.input-group button { padding: 12px 20px; background: #667eea; border: none; border-radius: 10px; color: white; font-size: 15px; cursor: pointer; }
.error-container { text-align: center; padding: 30px 20px; border-radius: 12px; background: #12123a; border: 1px solid #2a2a5e; display: none; }
.error-container.show { display: block; animation: shakeIn 0.5s ease; }
@keyframes shakeIn { 0% { transform: translateX(-10px); opacity: 0; } 25% { transform: translateX(10px); } 50% { transform: translateX(-5px); } 100% { transform: translateX(0); opacity: 1; } }
.error-icon { font-size: 48px; margin-bottom: 10px; }
.error-title { color: #e94560; font-size: 18px; font-weight: 600; margin-bottom: 5px; }
.error-desc { color: #aaa; font-size: 14px; margin-bottom: 15px; line-height: 1.5; }
.error-btn { padding: 10px 24px; background: #e94560; border: none; border-radius: 8px; color: white; font-size: 14px; cursor: pointer; }
.error-btn:hover { background: #d63851; }
.result-card { background: #12123a; border: 1px solid #2a2a5e; border-radius: 12px; padding: 20px; display: none; }
.result-card.show { display: block; }
.result-card .city { color: #fff; font-size: 20px; }
.result-card .temp { font-size: 48px; color: #667eea; margin: 10px 0; }
</style>
</head>
<body>
<div class="container">
<h1>🌤️ Weather App</h1>
<div class="input-group">
<input type="text" id="cityInput" placeholder="Nama kota..." value="Jakarta">
<button onclick="searchCity()">Cari</button>
</div>
<div class="error-container" id="errorContainer">
<div class="error-icon" id="errorIcon">😕</div>
<div class="error-title" id="errorTitle">Kota Tidak Ditemukan</div>
<div class="error-desc" id="errorDesc">Kota yang Anda cari tidak ditemukan. Periksa ejaan atau coba kota lain.</div>
<button class="error-btn" onclick="document.getElementById('cityInput').focus()">Coba Lagi</button>
</div>
<div class="result-card" id="resultCard">
<div class="city" id="cityName">Jakarta, ID</div>
<div class="temp" id="tempDisplay">30°C</div>
</div>
</div>
<script>
const API_KEY = 'YOUR_API_KEY';

async function searchCity() {
const city = document.getElementById('cityInput').value.trim();
if (!city) return;
const errorEl = document.getElementById('errorContainer');
const resultEl = document.getElementById('resultCard');
errorEl.classList.remove('show');
resultEl.classList.remove('show');

try {
const res = await fetch(`https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${API_KEY}&units=metric`);
const data = await res.json();
if (!res.ok) {
if (data.cod === '404') {
document.getElementById('errorIcon').textContent = '🤷';
document.getElementById('errorTitle').textContent = `Kota "${city}" Tidak Ditemukan`;
document.getElementById('errorDesc').textContent = 'Pastikan ejaan nama kota benar. Coba gunakan nama kota dalam bahasa Inggris.';
} else if (data.cod === '401') {
document.getElementById('errorIcon').textContent = '🔑';
document.getElementById('errorTitle').textContent = 'API Key Tidak Valid';
document.getElementById('errorDesc').textContent = 'Periksa kembali API Key OpenWeatherMap Anda.';
} else {
document.getElementById('errorIcon').textContent = '⚠️';
document.getElementById('errorTitle').textContent = `Error ${data.cod}`;
document.getElementById('errorDesc').textContent = data.message;
}
errorEl.classList.add('show');
return;
}
document.getElementById('cityName').textContent = `${data.name}, ${data.sys.country}`;
document.getElementById('tempDisplay').textContent = `${Math.round(data.main.temp)}°C`;
resultEl.classList.add('show');
} catch (err) {
document.getElementById('errorIcon').textContent = '🌐';
document.getElementById('errorTitle').textContent = 'Gagal Terhubung';
document.getElementById('errorDesc').textContent = 'Periksa koneksi internet Anda dan coba lagi.';
errorEl.classList.add('show');
}
}
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Ganti `YOUR_API_KEY`. Cari kota yang tidak valid untuk melihat error message informatif dengan ikon dan saran.
