# 256. Menampilkan Loading Skeleton saat Data Sedang Diambil

## Definisi & Target
Membuat skeleton loading screen yang ditampilkan saat data cuaca sedang diambil dari API, memberikan feedback visual bahwa konten sedang dimuat.

## Analogi Alur
Loading skeleton seperti kerangka bangunan yang terlihat sebelum finishing: Anda bisa melihat bentuk dan tata letak (layout) meskipun isi (data) belum ada. Ini lebih baik daripada layar kosong atau spinner.

## Poin-Poin Penting
- Skeleton meniru bentuk konten asli (persegi panjang untuk teks, lingkaran untuk ikon)
- Gunakan animasi shimmer/gradient bergerak
- Tampilkan skeleton segera setelah fetch dimulai
- Skeleton diganti dengan konten asli setelah data diterima
- Animasi CSS @keyframes untuk efek shimmer
- Skeleton harus sesuai dengan layout final (tidak misleading)

## Cara Integrasi
Simpan sebagai HTML. Klik tombol untuk simulasi loading. Skeleton muncul selama 2 detik lalu diganti dengan konten aktual.
