# 254. Mengimplementasikan Geolocation API untuk Deteksi Lokasi Otomatis

## Definisi & Target
Menggunakan Geolocation API browser untuk mendeteksi posisi user secara otomatis dan menampilkan cuaca berdasarkan koordinat tersebut.

## Analogi Alur
Geolocation seperti GPS di ponsel: browser meminta izin untuk mengetahui lokasi Anda, lalu mengirim koordinat ke server cuaca untuk mendapatkan data yang akurat.

## Poin-Poin Penting
- Gunakan navigator.geolocation.getCurrentPosition()
- Dapatkan latitude dan longitude dari posisi user
- Gunakan koordinat untuk fetch cuaca (lat=...&lon=...)
- Tampilkan pesan jika user menolak izin
- Fallback ke kota default jika geolocation gagal
- Loading state selama deteksi lokasi
- Button "Deteksi Lokasiku" untuk trigger manual

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Geolocation Weather</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1a3e; border-radius: 20px; padding: 30px; width: 100%; max-width: 480px; text-align: center; }
h1 { color: #667eea; margin-bottom: 20px; font-size: 22px; }
.weather-display { background: #12123a; border-radius: 16px; padding: 25px; border: 1px solid #2a2a5e; margin-bottom: 20px; min-height: 200px; display: flex; flex-direction: column; align-items: center; justify-content: center; }
.weather-display .loc { color: #fff; font-size: 20px; font-weight: 600; }
.weather-display .temp { font-size: 48px; color: #667eea; font-weight: 600; margin: 10px 0; }
.weather-display .desc { color: #aaa; font-size: 16px; text-transform: capitalize; }
.weather-display .detail { color: #888; font-size: 13px; margin-top: 5px; }
.loading-text { color: #888; font-size: 14px; }
.error-text { color: #e94560; font-size: 14px; }
.geo-btn { padding: 14px 28px; background: #667eea; border: none; border-radius: 12px; color: white; font-size: 16px; cursor: pointer; transition: all 0.3s; width: 100%; }
.geo-btn:hover { background: #5a6fd6; transform: translateY(-2px); }
.geo-btn:disabled { opacity: 0.5; cursor: not-allowed; transform: none; }
.status-text { color: #888; font-size: 13px; margin-top: 15px; }
</style>
</head>
<body>
<div class="container">
<h1>📍 Deteksi Lokasi</h1>
<div class="weather-display" id="weatherDisplay">
<div class="loading-text" id="statusText">Klik tombol untuk deteksi lokasi</div>
</div>
<button class="geo-btn" id="geoBtn" onclick="getLocation()">📍 Deteksi Lokasiku</button>
<div class="status-text" id="infoText">Menggunakan Geolocation API browser</div>
</div>
<script>
const API_KEY = 'YOUR_API_KEY';

function getLocation() {
const btn = document.getElementById('geoBtn');
const statusText = document.getElementById('statusText');
const infoText = document.getElementById('infoText');
btn.disabled = true;
statusText.innerHTML = '⏳ Mendeteksi lokasi...';
infoText.textContent = 'Meminta izin lokasi...';

if (!navigator.geolocation) {
statusText.innerHTML = '<span class="error-text">Geolocation tidak didukung browser</span>';
btn.disabled = false;
return;
}

navigator.geolocation.getCurrentPosition(
async (position) => {
const { latitude, longitude } = position.coords;
infoText.textContent = `Lokasi: ${latitude.toFixed(4)}, ${longitude.toFixed(4)}`;
statusText.innerHTML = '⏳ Mengambil data cuaca...';
try {
const res = await fetch(`https://api.openweathermap.org/data/2.5/weather?lat=${latitude}&lon=${longitude}&appid=${API_KEY}&units=metric`);
const d = await res.json();
if (res.ok) {
const wd = document.getElementById('weatherDisplay');
wd.innerHTML = `
<div class="loc">${d.name}, ${d.sys.country}</div>
<div class="temp">${Math.round(d.main.temp)}°C</div>
<div class="desc">${d.weather[0].description}</div>
<div class="detail">💧 ${d.main.humidity}% &nbsp; 💨 ${d.wind.speed} m/s</div>`;
infoText.textContent = `Lokasi terdeteksi: ${d.name}`;
} else {
statusText.innerHTML = `<span class="error-text">${d.message}</span>`;
}
} catch (e) {
statusText.innerHTML = '<span class="error-text">Gagal mengambil data</span>';
}
btn.disabled = false;
},
(error) {
let msg = 'Gagal mendapatkan lokasi';
if (error.code === 1) msg = 'Izin lokasi ditolak. Aktifkan di pengaturan browser.';
if (error.code === 2) msg = 'Posisi tidak tersedia. Coba lagi.';
if (error.code === 3) msg = 'Waktu habis. Coba lagi.';
statusText.innerHTML = `<span class="error-text">${msg}</span>`;
btn.disabled = false;
infoText.textContent = 'Gunakan tombol untuk mencoba lagi';
},
{ enableHighAccuracy: true, timeout: 10000, maximumAge: 60000 }
);
}
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Ganti `YOUR_API_KEY`. Klik tombol "Deteksi Lokasiku" dan izinkan akses lokasi untuk melihat cuaca berdasarkan posisi Anda.
