# 309. Menampilkan Total Pemasukan, Pengeluaran, dan Saldo

## Definisi & Target
Membuat summary card yang menampilkan total pemasukan, total pengeluaran, dan saldo (selisih) secara real-time.

## Analogi Alur
Summary card seperti tampilan dashboard ATM: Anda bisa langsung melihat saldo akhir, total uang masuk, dan total uang keluar dalam satu tampilan.

## Poin-Poin Penting
- Hitung total dari array transaksi dengan filter type
- Tampilkan dalam 3 card yang rapi
- Update otomatis saat data berubah (tambah/edit/hapus)
- Warna hijau untuk income, merah untuk expense
- Saldo hijau jika positif, merah jika negatif
- Format angka dengan separator ribuan
- Animasi count-up untuk efek visual

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Ringkasan Keuangan</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.card { width: 100%; max-width: 550px; }
h1 { text-align: center; color: #333; margin-bottom: 20px; font-size: 20px; }
.summary-grid { display: grid; grid-template-columns: 1fr 1fr 1fr; gap: 12px; }
.summary-card { background: white; border-radius: 16px; padding: 20px 16px; text-align: center; box-shadow: 0 2px 15px rgba(0,0,0,0.06); }
.summary-icon { font-size: 28px; margin-bottom: 6px; }
.summary-label { font-size: 12px; color: #888; text-transform: uppercase; letter-spacing: 0.5px; }
.summary-amount { font-size: 20px; font-weight: 700; margin-top: 6px; transition: all 0.3s; }
.income-color { color: #2ecc71; }
.expense-color { color: #e74c3c; }
.balance-positive { color: #2ecc71; }
.balance-negative { color: #e74c3c; }
.countup { display: inline-block; }
.form-section { background: white; border-radius: 16px; padding: 20px; margin-top: 16px; box-shadow: 0 2px 15px rgba(0,0,0,0.06); }
.form-row { display: flex; gap: 10px; margin-bottom: 10px; flex-wrap: wrap; }
.form-row input, .form-row select { flex: 1; min-width: 120px; padding: 10px 12px; border: 2px solid #ddd; border-radius: 10px; font-size: 14px; outline: none; }
.form-row input:focus, .form-row select:focus { border-color: #667eea; }
.btn-add { background: #667eea; color: white; border: none; padding: 10px 20px; border-radius: 10px; cursor: pointer; font-size: 14px; }
.btn-add:hover { opacity: 0.9; }
</style>
</head>
<body>
<div class="card">
<h1>💰 Ringkasan Keuangan</h1>
<div class="summary-grid">
<div class="summary-card">
<div class="summary-icon">💰</div>
<div class="summary-label">Pemasukan</div>
<div class="summary-amount income-color" id="totalIncome">Rp0</div>
</div>
<div class="summary-card">
<div class="summary-icon">💸</div>
<div class="summary-label">Pengeluaran</div>
<div class="summary-amount expense-color" id="totalExpense">Rp0</div>
</div>
<div class="summary-card">
<div class="summary-icon">📊</div>
<div class="summary-label">Saldo</div>
<div class="summary-amount" id="balance">Rp0</div>
</div>
</div>
<div class="form-section">
<div class="form-row">
<select id="typeSelect"><option value="income">💰 Pemasukan</option><option value="expense">💸 Pengeluaran</option></select>
<input type="text" id="noteInput" placeholder="Catatan">
<input type="number" id="amountInput" placeholder="Jumlah" min="1">
</div>
<button class="btn-add" onclick="addTransaction()">+ Tambah</button>
</div>
</div>
<script>
let transactions = [
{ id: 1, type: 'income', note: 'Gaji', amount: 5000000 },
{ id: 2, type: 'expense', note: 'Makan', amount: 25000 },
{ id: 3, type: 'expense', note: 'Transport', amount: 100000 },
{ id: 4, type: 'income', note: 'Freelance', amount: 750000 }
];

function formatRp(num) { return 'Rp' + num.toLocaleString('id-ID'); }

function updateSummary() {
const totalIn = transactions.filter(t => t.type === 'income').reduce((s, t) => s + t.amount, 0);
const totalOut = transactions.filter(t => t.type === 'expense').reduce((s, t) => s + t.amount, 0);
const bal = totalIn - totalOut;
document.getElementById('totalIncome').textContent = formatRp(totalIn);
document.getElementById('totalExpense').textContent = formatRp(totalOut);
const balEl = document.getElementById('balance');
balEl.textContent = formatRp(bal);
balEl.className = 'summary-amount ' + (bal >= 0 ? 'balance-positive' : 'balance-negative');
}

function addTransaction() {
const note = document.getElementById('noteInput').value.trim();
const amount = parseInt(document.getElementById('amountInput').value);
const type = document.getElementById('typeSelect').value;
if (!note || !amount || amount <= 0) return;
transactions.push({ id: Date.now(), type, note, amount });
document.getElementById('noteInput').value = '';
document.getElementById('amountInput').value = '';
updateSummary();
}

updateSummary();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Tambah transaksi, summary card otomatis update dengan format Rp dan warna yang sesuai.
