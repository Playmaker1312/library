# 325. Membuat Expense Tracker Responsive dan Accessible

## Definisi & Target
Memastikan Expense Tracker responsif di semua perangkat dan accessible untuk pengguna dengan kebutuhan khusus.

## Analogi Alur
Responsif dan accessible seperti membuat buku kas yang bisa dibaca dalam berbagai kondisi: di layar HP (kecil), tablet (sedang), monitor (besar), dan juga bisa dibaca oleh screen reader.

## Poin-Poin Penting
- CSS Grid/Flexbox responsif
- Mobile-first design
- Media queries: 480px, 768px
- Touch targets minimal 44x44px
- Skip navigation link
- Aria labels untuk form, buttons, tabel
- Focus outline untuk keyboard navigation
- Color contrast ratio sesuai standar WCAG AA
