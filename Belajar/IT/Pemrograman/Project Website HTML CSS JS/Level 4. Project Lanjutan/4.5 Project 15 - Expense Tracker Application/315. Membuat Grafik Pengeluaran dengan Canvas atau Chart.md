# 315. Membuat Grafik Pengeluaran dengan Canvas atau Chart

## Definisi & Target
Membuat grafik visual (chart) pengeluaran per kategori menggunakan elemen Canvas HTML5.

## Analogi Alur
Grafik seperti diagram lingkaran di laporan keuangan: Anda bisa langsung melihat "Oh, makanan menghabiskan 40% dari pengeluaran saya".

## Poin-Poin Penting
- Canvas API untuk menggambar grafik
- Pie chart atau bar chart per kategori
- Warna berbeda untuk setiap kategori
- Label persentase di setiap segmen
- Hanya hitung transaksi tipe expense
- Animasi saat pertama muncul
- Responsif terhadap ukuran container

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Grafik Pengeluaran</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.card { background: white; border-radius: 20px; padding: 30px; width: 100%; max-width: 500px; box-shadow: 0 10px 40px rgba(0,0,0,0.1); text-align: center; }
h1 { text-align: center; color: #333; margin-bottom: 20px; font-size: 20px; }
canvas { max-width: 100%; height: auto; display: block; margin: 0 auto; }
.legend { display: flex; flex-wrap: wrap; gap: 10px; justify-content: center; margin-top: 16px; }
.legend-item { display: flex; align-items: center; gap: 6px; font-size: 13px; color: #555; }
.legend-color { width: 14px; height: 14px; border-radius: 4px; }
.total-spend { font-size: 24px; font-weight: 700; color: #e74c3c; margin: 10px 0; }
</style>
</head>
<body>
<div class="card">
<h1>📊 Grafik Pengeluaran</h1>
<div class="total-spend" id="totalSpend">Rp0</div>
<canvas id="chart" width="400" height="400"></canvas>
<div class="legend" id="legend"></div>
</div>
<script>
const transactions = [
{ type: 'expense', category: 'Makanan', amount: 450000 },
{ type: 'expense', category: 'Makanan', amount: 25000 },
{ type: 'expense', category: 'Transport', amount: 100000 },
{ type: 'expense', category: 'Transport', amount: 50000 },
{ type: 'expense', category: 'Hiburan', amount: 65000 },
{ type: 'expense', category: 'Belanja', amount: 250000 },
{ type: 'expense', category: 'Tagihan', amount: 350000 },
{ type: 'income', category: 'Gaji', amount: 5000000 }
];

const colors = ['#e74c3c', '#3498db', '#f39c12', '#2ecc71', '#9b59b6', '#1abc9c', '#e67e22', '#34495e'];

const expenses = transactions.filter(t => t.type === 'expense');
const grouped = {};
expenses.forEach(t => { grouped[t.category] = (grouped[t.category] || 0) + t.amount; });
const cats = Object.keys(grouped);
const vals = Object.values(grouped);
const total = vals.reduce((s, v) => s + v, 0);

document.getElementById('totalSpend').textContent = 'Rp' + total.toLocaleString('id-ID');

const canvas = document.getElementById('chart');
const ctx = canvas.getContext('2d');
const cx = 200, cy = 200, r = 150;
let startAngle = -Math.PI / 2;

vals.forEach((val, i) => {
const sliceAngle = (val / total) * 2 * Math.PI;
ctx.beginPath();
ctx.moveTo(cx, cy);
ctx.arc(cx, cy, r, startAngle, startAngle + sliceAngle);
ctx.closePath();
ctx.fillStyle = colors[i % colors.length];
ctx.fill();

const midAngle = startAngle + sliceAngle / 2;
const labelR = r * 0.65;
const lx = cx + Math.cos(midAngle) * labelR;
const ly = cy + Math.sin(midAngle) * labelR;
ctx.fillStyle = 'white';
ctx.font = 'bold 13px sans-serif';
ctx.textAlign = 'center';
ctx.textBaseline = 'middle';
const pct = Math.round((val / total) * 100);
ctx.fillText(pct + '%', lx, ly);

startAngle += sliceAngle;
});

const legend = document.getElementById('legend');
cats.forEach((cat, i) => {
const val = grouped[cat];
legend.innerHTML += `<div class="legend-item"><div class="legend-color" style="background:${colors[i % colors.length]}"></div>${cat}: Rp${val.toLocaleString('id-ID')}</div>`;
});
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Pie chart digambar dengan Canvas API menampilkan proporsi pengeluaran per kategori.
