# 306. Perencanaan Project Expense Tracker dan Struktur Data

## Definisi & Target
Merencanakan project Expense Tracker: aplikasi mencatat pemasukan dan pengeluaran dengan fitur budget planning dan laporan.

## Analogi Alur
Expense Tracker seperti buku kas rumah tangga: Anda mencatat setiap uang masuk dan keluar, lalu di akhir bulan bisa melihat ke mana saja uang Anda pergi.

## Poin-Poin Penting
- Struktur data: { id, type (income/expense), category, amount, date, note }
- Fitur utama: CRUD transaksi, filter, total saldo, budget planner
- Kategori: Makanan, Transport, Hiburan, Gaji, dll
- Penyimpanan: LocalStorage
- Teknologi: HTML + CSS + Vanilla JS
