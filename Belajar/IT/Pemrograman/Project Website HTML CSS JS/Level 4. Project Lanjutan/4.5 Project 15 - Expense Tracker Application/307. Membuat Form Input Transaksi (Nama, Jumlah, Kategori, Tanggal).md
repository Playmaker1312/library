# 307. Membuat Form Input Transaksi (Nama, Jumlah, Kategori, Tanggal)

## Definisi & Target
Membuat form untuk menambahkan transaksi baru dengan input nama, jumlah, kategori, tanggal, dan tipe (income/expense).

## Analogi Alur
Form input seperti resi belanja: Anda mengisi apa yang dibeli (note), berapa harganya (amount), kategori apa (food/transport), dan kapan (date).

## Poin-Poin Penting
- Radio button atau toggle untuk tipe income/expense
- Select dropdown untuk kategori
- Input number untuk amount
- Input date untuk tanggal
- Validasi: semua field harus diisi, amount > 0
- Reset form setelah submit
- Tampilkan pesan sukses sementara

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Form Transaksi</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.card { background: white; border-radius: 20px; padding: 30px; width: 100%; max-width: 460px; box-shadow: 0 20px 60px rgba(0,0,0,0.3); }
h1 { text-align: center; color: #333; margin-bottom: 20px; font-size: 20px; }
.form-group { margin-bottom: 16px; }
label { display: block; font-size: 14px; color: #555; margin-bottom: 5px; font-weight: 500; }
input, select { width: 100%; padding: 12px 14px; border: 2px solid #ddd; border-radius: 10px; font-size: 14px; outline: none; transition: border-color 0.3s; }
input:focus, select:focus { border-color: #667eea; }
.type-toggle { display: flex; gap: 10px; margin-bottom: 16px; }
.type-btn { flex: 1; padding: 12px; border: 2px solid #ddd; border-radius: 10px; text-align: center; cursor: pointer; font-weight: 600; font-size: 14px; transition: all 0.3s; }
.type-btn.active.income { background: #e6ffe6; border-color: #2ecc71; color: #27ae60; }
.type-btn.active.expense { background: #ffe6e6; border-color: #e74c3c; color: #c0392b; }
.type-btn:not(.active):hover { border-color: #bbb; }
.btn-submit { width: 100%; padding: 14px; background: linear-gradient(135deg, #667eea, #764ba2); border: none; border-radius: 12px; color: white; font-size: 16px; font-weight: 600; cursor: pointer; }
.btn-submit:hover { opacity: 0.9; }
.toast { background: #2ecc71; color: white; padding: 12px; border-radius: 10px; text-align: center; margin-top: 14px; font-size: 14px; display: none; animation: slideUp 0.3s; }
.toast.error { background: #e74c3c; }
@keyframes slideUp { from { opacity: 0; transform: translateY(10px); } to { opacity: 1; transform: translateY(0); } }
</style>
</head>
<body>
<div class="card">
<h1>➕ Tambah Transaksi</h1>
<div class="type-toggle" id="typeToggle">
<div class="type-btn active income" data-type="income" onclick="setType('income')">💰 Pemasukan</div>
<div class="type-btn expense" data-type="expense" onclick="setType('expense')">💸 Pengeluaran</div>
</div>
<form id="transactionForm">
<div class="form-group">
<label for="note">Catatan</label>
<input type="text" id="note" placeholder="Mis: Nasi goreng, Gaji bulanan..." required>
</div>
<div class="form-group">
<label for="amount">Jumlah (Rp)</label>
<input type="number" id="amount" placeholder="50000" min="1" required>
</div>
<div class="form-group">
<label for="category">Kategori</label>
<select id="category" required>
<option value="">Pilih kategori</option>
<option value="Makanan">Makanan</option>
<option value="Transport">Transport</option>
<option value="Hiburan">Hiburan</option>
<option value="Belanja">Belanja</option>
<option value="Tagihan">Tagihan</option>
<option value="Gaji">Gaji</option>
<option value="Lainnya">Lainnya</option>
</select>
</div>
<div class="form-group">
<label for="date">Tanggal</label>
<input type="date" id="date" required>
</div>
<button type="submit" class="btn-submit">✅ Simpan Transaksi</button>
</form>
<div class="toast" id="toast"></div>
</div>
<script>
let currentType = 'income';

function setType(type) {
currentType = type;
document.querySelectorAll('.type-btn').forEach(btn => {
btn.classList.toggle('active', btn.dataset.type === type);
});
document.getElementById('note').focus();
}

document.getElementById('date').valueAsDate = new Date();

document.getElementById('transactionForm').addEventListener('submit', function(e) {
e.preventDefault();
const data = {
id: Date.now().toString(),
type: currentType,
note: document.getElementById('note').value.trim(),
amount: parseInt(document.getElementById('amount').value),
category: document.getElementById('category').value,
date: document.getElementById('date').value
};

const toast = document.getElementById('toast');
toast.className = 'toast';
toast.style.display = 'block';
toast.textContent = `✅ ${currentType === 'income' ? 'Pemasukan' : 'Pengeluaran'} Rp${data.amount.toLocaleString()} berhasil ditambahkan!`;

this.reset();
document.getElementById('date').valueAsDate = new Date();
document.getElementById('note').focus();

setTimeout(() => { toast.style.display = 'none'; }, 2500);
});
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Form siap menerima input transaksi dengan toggle income/expense.
