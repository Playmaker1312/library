# 322. Dark Mode untuk Expense Tracker

## Definisi & Target
Menambahkan toggle dark mode pada Expense Tracker yang mengubah tema dari terang ke gelap.

## Analogi Alur
Dark mode seperti mengganti kertas laporan dari putih ke hitam: semua informasi tetap sama, tapi tampilannya lebih nyaman di mata saat malam hari.

## Poin-Poin Penting
- Toggle button dengan ikon 🌙/☀️
- CSS custom properties untuk warna tema
- Simpan preferensi tema di LocalStorage
- Terapkan class "dark" di body
- Transisi halus saat berganti tema
- Semua komponen harus mendukung dark mode

const STORAGE_KEY = 'expense_theme';

function getTheme() { return localStorage.getItem(STORAGE_KEY) || 'light'; }

function setTheme(theme) {
document.documentElement.setAttribute('data-theme', theme);
localStorage.setItem(STORAGE_KEY, theme);
document.getElementById('themeToggle').textContent = theme === 'dark' ? '☀️' : '🌙';
}

function toggleTheme() {
const current = getTheme();
setTheme(current === 'dark' ? 'light' : 'dark');
