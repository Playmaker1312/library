# 320. Pencarian Transaksi

## Definisi & Target
Menambahkan fitur search/pencarian untuk menemukan transaksi berdasarkan kata kunci pada catatan atau kategori.

## Analogi Alur
Search seperti mencari nota tertentu di tumpukan bon: Anda tinggal ketik kata kuncinya, dan semua transaksi yang mengandung kata itu akan muncul.

## Poin-Poin Penting
- Input search dengan icon pencarian
- Live search saat mengetik (keyup)
- Filter berdasarkan note, category
- Case-insensitive search
- Highlight kata yang cocok di hasil
- Tampilkan jumlah hasil pencarian
- Kombinasi dengan filter lain (kategori, tanggal)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html

<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Search Transaksi</title>
<style>

</style>
</head>
<body>
<div class="container">
<h1>🔍 Cari Transaksi</h1>
<div class="search-box">
<span>🔍</span>
<input type="text" id="searchInput" placeholder="Cari berdasarkan catatan atau kategori..." oninput="search()" autofocus>

<script>
const transactions = [
{ id: 1, type: 'income', note: 'Gaji Bulanan', category: 'Gaji', amount: 5000000, date: '2025-01-15' },
{ id: 2, type: 'expense', note: 'Nasi Goreng', category: 'Makanan', amount: 25000, date: '2025-01-16' },
{ id: 3, type: 'expense', note: 'Bensin Pertamax', category: 'Transport', amount: 100000, date: '2025-01-17' },
{ id: 4, type: 'income', note: 'Freelance Design', category: 'Lainnya', amount: 750000, date: '2025-01-18' },

{ id: 6, type: 'expense', note: 'Beli Jaket Kulit', category: 'Belanja', amount: 250000, date: '2025-01-20' },

{ id: 8, type: 'expense', note: 'Bensin Motor', category: 'Transport', amount: 50000, date: '2025-01-22' }
];

function formatRp(num) { return 'Rp' + num.toLocaleString('id-ID'); }

function highlight(text, query) {
if (!query) return text;
const regex = new RegExp(`(${query.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')})`, 'gi');
return text.replace(regex, '<mark>$1</mark>');
}

function search() {
const query = document.getElementById('searchInput').value.trim().toLowerCase();
const filtered = query ? transactions.filter(t => 
t.note.toLowerCase().includes(query) || t.category.toLowerCase().includes(query)
) : transactions;

const list = document.getElementById('transactionList');
if (filtered.length === 0) {
list.innerHTML = '<div class="empty">🔍 Tidak ditemukan hasil untuk "' + query + '"</div>';
document.getElementById('resultCount').textContent = 'Tidak ditemukan';
return;
}

list.innerHTML = filtered.map(t => `
<div class="transaction-item">
  <div>
    <div class="t-note">${highlight(t.note, query)}</div>
    <div class="t-meta">${highlight(t.category, query)} • ${new Date(t.date).toLocaleDateString('id-ID')}</div>
  </div>
  <div class="t-amount ${t.type}">${formatRp(t.amount)}</div>
</div>
`).join('');
document.getElementById('resultCount').textContent = `Menampilkan ${filtered.length} dari ${transactions.length} transaksi`;
}

search();
</script>
</body>
</html>
```

Simpan sebagai HTML. Ketik di search box, hasil langsung terfilter secara live dengan highlight kata kunci.
