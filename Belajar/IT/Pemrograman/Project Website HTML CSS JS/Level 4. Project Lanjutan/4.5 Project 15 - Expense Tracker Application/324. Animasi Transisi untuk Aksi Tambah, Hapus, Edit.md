# 324. Animasi Transisi untuk Aksi Tambah, Hapus, Edit

## Definisi & Target
Menambahkan animasi transisi halus saat menambah, menghapus, atau mengedit transaksi untuk meningkatkan user experience.

## Analogi Alur
Animasi transisi seperti efek di PowerPoint: slide tidak langsung muncul tapi meluncur masuk dengan mulus, memberikan kesan profesional dan halus.

## Poin-Poin Penting
- Slide-in untuk item baru
- Fade-out untuk item dihapus
- Highlight flash untuk item diedit
- Gunakan CSS @keyframes dan transition
- Stagger delay jika multiple items
- Jangan mengganggu usability
- Performance: prefer transform dan opacity

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Animasi Transisi</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; padding: 30px; }
.container { max-width: 500px; margin: 0 auto; }
h1 { text-align: center; color: #333; font-size: 20px; margin-bottom: 16px; }
.actions { display: flex; gap: 8px; margin-bottom: 16px; }
.actions button { flex: 1; padding: 10px; border: none; border-radius: 10px; font-size: 14px; font-weight: 600; cursor: pointer; color: white; }
.btn-add { background: #2ecc71; }
.btn-add:hover { background: #27ae60; }
.btn-del { background: #e74c3c; }
.btn-del:hover { background: #c0392b; }
.transaction-list { background: white; border-radius: 14px; box-shadow: 0 2px 15px rgba(0,0,0,0.06); overflow: hidden; }
.transaction-item { display: flex; justify-content: space-between; align-items: center; padding: 14px 18px; border-bottom: 1px solid #f0f0f0; transition: all 0.4s ease; }
.transaction-item:last-child { border-bottom: none; }
.t-note { font-size: 14px; color: #333; }
.t-amount { font-size: 14px; font-weight: 600; }
.t-amount.income { color: #2ecc71; }
.t-amount.expense { color: #e74c3c; }

@keyframes slideIn {
from { opacity: 0; transform: translateX(-30px); }
to { opacity: 1; transform: translateX(0); }
}
@keyframes fadeOut {
from { opacity: 1; transform: scale(1); }
to { opacity: 0; transform: scale(0.8); max-height: 0; padding: 0; margin: 0; }
}
@keyframes flashUpdate {
0% { background: #fff3b0; }
100% { background: transparent; }
}
.item-enter { animation: slideIn 0.4s ease; }
.item-leave { animation: fadeOut 0.4s ease; overflow: hidden; }
.item-update { animation: flashUpdate 0.8s ease; }
.count { text-align: center; margin-top: 12px; color: #888; font-size: 13px; }
</style>
</head>
<body>
<div class="container">
<h1>✨ Animasi Transisi</h1>
<div class="actions">
<button class="btn-add" onclick="addItem()">+ Tambah</button>
<button class="btn-del" onclick="removeLast()">- Hapus</button>
<button class="btn-del" onclick="updateFirst()" style="background:#f39c12">✏️ Edit</button>
</div>
<div class="transaction-list" id="list">
<div class="transaction-item item-enter">
<span class="t-note">Gaji Bulanan</span>
<span class="t-amount income">Rp5.000.000</span>
</div>
<div class="transaction-item item-enter" style="animation-delay:0.1s">
<span class="t-note">Nasi Goreng</span>
<span class="t-amount expense">Rp25.000</span>
</div>
<div class="transaction-item item-enter" style="animation-delay:0.2s">
<span class="t-note">Bensin</span>
<span class="t-amount expense">Rp100.000</span>
</div>
</div>
<div class="count" id="count">3 transaksi</div>
</div>
<script>
let items = [
{ id: 1, note: 'Gaji Bulanan', amount: 5000000, type: 'income' },
{ id: 2, note: 'Nasi Goreng', amount: 25000, type: 'expense' },
{ id: 3, note: 'Bensin', amount: 100000, type: 'expense' }
];

let nextId = 4;

function formatRp(num) { return 'Rp' + num.toLocaleString('id-ID'); }

function render() {
const list = document.getElementById('list');
list.innerHTML = items.map((item, i) => `
<div class="transaction-item" data-id="${item.id}">
  <span class="t-note">${item.note}</span>
  <span class="t-amount ${item.type}">${formatRp(item.amount)}</span>
</div>
`).join('');
document.getElementById('count').textContent = `${items.length} transaksi`;
}

function addItem() {
const newItem = { id: nextId++, note: 'Transaksi Baru', amount: Math.floor(Math.random() * 500000) + 10000, type: Math.random() > 0.5 ? 'income' : 'expense' };
items.push(newItem);
render();
const added = document.querySelector(`[data-id="${newItem.id}"]`);
if (added) added.classList.add('item-enter');
document.getElementById('count').textContent = `${items.length} transaksi`;
}

function removeLast() {
if (items.length === 0) return;
const last = items[items.length - 1];
const el = document.querySelector(`[data-id="${last.id}"]`);
if (el) {
el.classList.add('item-leave');
setTimeout(() => {
items.pop();
render();
document.getElementById('count').textContent = `${items.length} transaksi`;
}, 400);
}
}

function updateFirst() {
if (items.length === 0) return;
const first = items[0];
first.note += ' ✨';
const el = document.querySelector(`[data-id="${first.id}"]`);
if (el) el.classList.add('item-update');
render();
}

render();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Klik Tambah (slide-in), Hapus (fade-out), Edit (flash highlight) untuk melihat animasi.
