# 314. Menyimpan Transaksi ke LocalStorage

## Definisi & Target
Menyimpan dan memuat data transaksi dari LocalStorage agar data tetap ada meskipun browser ditutup.

## Analogi Alur
LocalStorage seperti lemari arsip: Anda menyimpan semua nota (data transaksi) di dalamnya, dan saat kembali, Anda bisa mengeluarkan nota-nota tersebut tanpa harus mengisi ulang.

## Poin-Poin Penting
- Simpan array transaksi sebagai JSON string
- Key: "expense_transactions"
- Load data saat halaman dimulai
- Simpan setiap kali ada perubahan (tambah/edit/hapus)
- Handle error parsing JSON
- Tampilkan data kosong jika belum ada data
- Backup array kosong sebagai default

const STORAGE_KEY = 'expense_transactions';

function loadTransactions() {
try {
const data = localStorage.getItem(STORAGE_KEY);
return data ? JSON.parse(data) : [];
} catch { return []; }
}

function saveTransactions() {
localStorage.setItem(STORAGE_KEY, JSON.stringify(transactions));
}

let transactions = loadTransactions();

function formatRp(num) { return 'Rp' + num.toLocaleString('id-ID'); }

function render() {
const list = document.getElementById('list');
if (transactions.length === 0) {
list.innerHTML = '<div style="padding:30px;text-align:center;color:#888">Belum ada transaksi</div>';
return;
}
list.innerHTML = transactions.map(t => `
<div class="item">
  <span>${t.note} <span style="color:#999;font-size:12px">${t.category}</span></span>
  <span class="amt ${t.type}">${formatRp(t.amount)}</span>
</div>
`).join('');
}

document.getElementById('form').addEventListener('submit', function(e) {
e.preventDefault();
transactions.push({
id: Date.now(),
note: document.getElementById('note').value.trim(),
amount: parseInt(document.getElementById('amount').value),
category: document.getElementById('category').value,
type: document.getElementById('type').value,
date: new Date().toISOString().slice(0,10)
});
saveTransactions();
this.reset();
render();
});

function clearAll() {
if (!confirm('Hapus semua data transaksi?')) return;
transactions = [];
saveTransactions();
render();
}

render();
</script>
</body>
</html>

## Cara Integrasi
Simpan sebagai HTML. Data otomatis tersimpan ke LocalStorage. Refresh halaman, data tetap ada.
