# 310. Filter Transaksi Berdasarkan Kategori

## Definisi & Target
Menambahkan dropdown filter untuk menyaring transaksi berdasarkan kategori.

## Analogi Alur
Filter kategori seperti memilah-milah nota belanja berdasarkan jenisnya: Anda hanya ingin melihat pengeluaran makanan saja, atau transportasi saja.

## Poin-Poin Penting
- Select dropdown berisi daftar kategori + "Semua"
- Event listener onChange untuk memfilter ulang tampilan
- Filter array transaksi dengan filter()
- Update summary card sesuai data yang difilter
- Tampilkan jumlah transaksi yang cocok dengan filter

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Filter Kategori</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; padding: 30px; }
.container { max-width: 600px; margin: 0 auto; }
h1 { text-align: center; color: #333; font-size: 20px; margin-bottom: 16px; }
.filter-bar { display: flex; gap: 10px; margin-bottom: 16px; align-items: center; flex-wrap: wrap; }
.filter-bar label { font-size: 13px; color: #555; font-weight: 600; }
.filter-bar select { flex: 1; min-width: 150px; padding: 10px 12px; border: 2px solid #ddd; border-radius: 10px; font-size: 14px; outline: none; }
.filter-bar select:focus { border-color: #667eea; }
.filter-count { font-size: 13px; color: #888; }
.transaction-list { background: white; border-radius: 14px; box-shadow: 0 2px 15px rgba(0,0,0,0.06); }
.list-header { display: grid; grid-template-columns: 1fr 100px 110px; padding: 12px 16px; background: #f8f9fa; border-bottom: 1px solid #eee; font-size: 12px; color: #888; font-weight: 600; }
.transaction-item { display: grid; grid-template-columns: 1fr 100px 110px; padding: 12px 16px; border-bottom: 1px solid #f0f0f0; align-items: center; }
.transaction-item:last-child { border-bottom: none; }
.t-note { font-size: 14px; color: #333; }
.t-cat { font-size: 11px; color: #999; }
.t-type { font-size: 12px; text-align: center; }
.t-amount { font-size: 14px; font-weight: 600; text-align: right; }
.t-amount.income { color: #2ecc71; }
.t-amount.expense { color: #e74c3c; }
.empty { text-align: center; padding: 30px; color: #888; font-size: 14px; }
</style>
</head>
<body>
<div class="container">
<h1>📁 Filter Kategori</h1>
<div class="filter-bar">
<label for="categoryFilter">Filter:</label>
<select id="categoryFilter" onchange="applyFilter()">
<option value="all">Semua Kategori</option>
<option value="Makanan">Makanan</option>
<option value="Transport">Transport</option>
<option value="Hiburan">Hiburan</option>
<option value="Belanja">Belanja</option>
<option value="Tagihan">Tagihan</option>
<option value="Gaji">Gaji</option>
<option value="Lainnya">Lainnya</option>
</select>
<span class="filter-count" id="filterCount">Menampilkan 6 transaksi</span>
</div>
<div class="transaction-list" id="transactionList"></div>
</div>
<script>
const transactions = [
{ id: 1, type: 'income', note: 'Gaji Bulanan', category: 'Gaji', amount: 5000000, date: '2025-01-15' },
{ id: 2, type: 'expense', note: 'Nasi Goreng', category: 'Makanan', amount: 25000, date: '2025-01-16' },
{ id: 3, type: 'expense', note: 'Bensin', category: 'Transport', amount: 100000, date: '2025-01-17' },
{ id: 4, type: 'income', note: 'Freelance Design', category: 'Lainnya', amount: 750000, date: '2025-01-18' },
{ id: 5, type: 'expense', note: 'Netflix', category: 'Hiburan', amount: 65000, date: '2025-01-19' },
{ id: 6, type: 'expense', note: 'Beli Jaket', category: 'Belanja', amount: 250000, date: '2025-01-20' }
];

function formatRp(num) { return 'Rp' + num.toLocaleString('id-ID'); }

function applyFilter() {
const cat = document.getElementById('categoryFilter').value;
const filtered = cat === 'all' ? transactions : transactions.filter(t => t.category === cat);
const list = document.getElementById('transactionList');

if (filtered.length === 0) {
list.innerHTML = '<div class="empty">Tidak ada transaksi untuk kategori ini</div>';
document.getElementById('filterCount').textContent = 'Tidak ada transaksi';
return;
}

list.innerHTML = `<div class="list-header"><span>Keterangan</span><span>Kategori</span><span style="text-align:right">Jumlah</span></div>` +
filtered.map(t => `
<div class="transaction-item">
  <div><div class="t-note">${t.note}</div><div class="t-cat">${new Date(t.date).toLocaleDateString('id-ID', {day:'numeric', month:'short'})}</div></div>
  <div class="t-type"><span>${t.category}</span></div>
  <div class="t-amount ${t.type}">${formatRp(t.amount)}</div>
</div>
`).join('');
document.getElementById('filterCount').textContent = `Menampilkan ${filtered.length} transaksi`;
}

applyFilter();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Pilih kategori di dropdown, daftar transaksi langsung terfilter sesuai pilihan.
