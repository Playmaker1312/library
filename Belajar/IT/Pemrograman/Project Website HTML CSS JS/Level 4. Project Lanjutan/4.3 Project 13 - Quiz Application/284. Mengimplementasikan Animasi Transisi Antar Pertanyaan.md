# 284. Mengimplementasikan Animasi Transisi Antar Pertanyaan

## Definisi & Target
Menambahkan animasi transisi yang halus ketika berpindah dari satu pertanyaan ke pertanyaan berikutnya.

## Analogi Alur
Transisi antar pertanyaan seperti membolak-balik halaman buku: halaman lama menutup (slide out) dan halaman baru membuka (slide in) dengan gerakan yang halus dan natural.

## Poin-Poin Penting
- Gunakan CSS @keyframes untuk slide in/out
- Animasi: slide ke kiri untuk pertanyaan baru
- Fade out untuk pertanyaan lama, fade in untuk yang baru
- Timer transisi sekitar 300-500ms
- Panggil render baru setelah animasi selesai
- Jangan bisa klik selama transisi (state locking)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Quiz Transitions</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: white; border-radius: 24px; padding: 30px; width: 100%; max-width: 500px; box-shadow: 0 25px 80px rgba(0,0,0,0.15); overflow: hidden; }
h1 { text-align: center; color: #333; margin-bottom: 20px; font-size: 22px; }
.progress-text { color: #888; font-size: 14px; margin-bottom: 10px; }
.question-card { position: relative; }
.question-text { font-size: 18px; color: #333; margin-bottom: 20px; font-weight: 600; }
.options { display: grid; gap: 10px; }
.option { padding: 14px 18px; border: 2px solid #e0e0e0; border-radius: 12px; cursor: pointer; color: #555; font-size: 15px; transition: all 0.3s; }
.option:hover { border-color: #667eea; background: #f5f7ff; }
.option.correct { background: #4caf50; color: white; border-color: #4caf50; }
.option.wrong { background: #e94560; color: white; border-color: #e94560; }
.next-btn { width: 100%; padding: 14px; margin-top: 20px; background: #667eea; color: white; border: none; border-radius: 12px; font-size: 16px; cursor: pointer; font-weight: 600; display: none; }
.next-btn.show { display: block; }

.slide-out { animation: slideOut 0.4s ease forwards; }
.slide-in { animation: slideIn 0.4s ease forwards; }
@keyframes slideOut { 0% { opacity: 1; transform: translateX(0); } 100% { opacity: 0; transform: translateX(-50px); } }
@keyframes slideIn { 0% { opacity: 0; transform: translateX(50px); } 100% { opacity: 1; transform: translateX(0); } }

.fade-out { animation: fadeOut 0.3s ease forwards; }
.fade-in { animation: fadeIn 0.3s ease forwards; }
@keyframes fadeOut { to { opacity: 0; } }
@keyframes fadeIn { from { opacity: 0; } to { opacity: 1; } }
</style>
</head>
<body>
<div class="container">
<h1>✨ Animasi Transisi</h1>
<div class="progress-text" id="progressText">Soal 1 dari 5</div>
<div class="question-card" id="questionCard">
<div class="question-text" id="questionText">Memuat...</div>
<div class="options" id="optionsContainer"></div>
<button class="next-btn" id="nextBtn" onclick="startTransition()">Selanjutnya →</button>
</div>
</div>
<script>
const questions = [
{ q: 'Apa ibu kota Indonesia?', o: ['Jakarta', 'Bandung', 'Surabaya', 'Yogyakarta'], c: 0 },
{ q: 'Siapa presiden pertama RI?', o: ['Soeharto', 'Soekarno', 'Habibie', 'Megawati'], c: 1 },
{ q: 'CSS singkatan dari?', o: ['Cascading Style Sheets', 'Creative System', 'Computer Sheets', 'Colorful Style'], c: 0 },
{ q: 'Planet terdekat matahari?', o: ['Venus', 'Bumi', 'Merkurius', 'Mars'], c: 2 },
{ q: 'HTML singkatan dari?', o: ['Hyper Text Markup Language', 'High Tech Language', 'Home Tool Language', 'Hyperlink Language'], c: 0 }
];
let current = 0, score = 0, answered = false, transitioning = false;

function render() {
const q = questions[current];
answered = false;
transitioning = false;
document.getElementById('progressText').textContent = `Soal ${current + 1} dari ${questions.length}`;
document.getElementById('questionText').textContent = q.q;
document.getElementById('nextBtn').classList.remove('show');
const card = document.getElementById('questionCard');
card.className = 'question-card slide-in';
const container = document.getElementById('optionsContainer');
container.innerHTML = q.o.map((opt, i) => `<div class="option" onclick="selectAnswer(${i})">${opt}</div>`).join('');
}

function selectAnswer(idx) {
if (answered || transitioning) return;
answered = true;
const q = questions[current];
document.querySelectorAll('.option').forEach((el, i) => {
if (i === q.c) el.classList.add('correct');
if (i === idx && idx !== q.c) el.classList.add('wrong');
});
if (idx === q.c) score++;
document.getElementById('nextBtn').classList.add('show');
}

function startTransition() {
if (transitioning) return;
transitioning = true;
const card = document.getElementById('questionCard');
card.className = 'question-card slide-out';
setTimeout(() => {
current++;
if (current < questions.length) render();
else {
document.querySelector('.container').innerHTML = `<h1 style="text-align:center">🎉 Selesai!</h1><p style="text-align:center;font-size:28px;font-weight:600;margin:20px;color:#667eea">Skor: ${score}/${questions.length}</p>`;
}
}, 400);
}

render();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Klik Selanjutnya untuk melihat animasi transisi slide-out/slide-in antar pertanyaan.
