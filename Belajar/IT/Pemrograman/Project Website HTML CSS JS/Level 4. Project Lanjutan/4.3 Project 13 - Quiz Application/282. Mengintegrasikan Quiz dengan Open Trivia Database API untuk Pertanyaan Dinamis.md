# 282. Mengintegrasikan Quiz dengan Open Trivia Database API untuk Pertanyaan Dinamis

## Definisi & Target
Mengambil pertanyaan quiz secara dinamis dari Open Trivia Database API (opentdb.com) sehingga quiz selalu memiliki pertanyaan baru.

## Analogi Alur
Open Trivia API seperti perpustakaan soal raksasa: Anda bisa meminjam (fetch) soal-soal baru setiap kali ingin mengadakan quiz. Tidak perlu membuat soal sendiri.

## Poin-Poin Penting
- Endpoint: https://opentdb.com/api.php?amount=10&type=multiple
- Parameter: amount (jumlah), category (opsional), difficulty (opsional), type (multiple/boolean)
- Response: results[] berisi question, correct_answer, incorrect_answers[]
- Campur correct_answer dengan incorrect_answers dan acak
- Decode HTML entities (use textContent atau DOMParser)
- Handle error jika API tidak reachable dengan fallback questions

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Quiz dengan API</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1a3e; border-radius: 20px; padding: 30px; width: 100%; max-width: 550px; }
h1 { text-align: center; color: #667eea; margin-bottom: 5px; font-size: 22px; }
.subtitle { text-align: center; color: #888; font-size: 13px; margin-bottom: 20px; }
.loading { text-align: center; color: #888; padding: 30px; display: none; }
.loading.show { display: block; }
.quiz-area { display: none; }
.quiz-area.show { display: block; }
.progress { display: flex; justify-content: space-between; color: #888; font-size: 13px; margin-bottom: 15px; }
.question-text { color: #eee; font-size: 18px; margin-bottom: 20px; }
.options { display: grid; gap: 10px; }
.option { padding: 14px 18px; background: #12123a; border: 2px solid #2a2a5e; border-radius: 12px; cursor: pointer; color: #ccc; font-size: 15px; transition: all 0.3s; }
.option:hover { border-color: #667eea; }
.option.correct { background: rgba(76,175,80,0.2); border-color: #4caf50; color: #4caf50; }
.option.wrong { background: rgba(233,69,96,0.2); border-color: #e94560; color: #e94560; }
.next-btn { width: 100%; padding: 14px; margin-top: 15px; background: #667eea; color: white; border: none; border-radius: 12px; font-size: 16px; cursor: pointer; display: none; font-weight: 600; }
.next-btn.show { display: block; }
.fetch-btn { width: 100%; padding: 14px; background: #667eea; color: white; border: none; border-radius: 12px; font-size: 16px; cursor: pointer; margin-bottom: 15px; font-weight: 600; }
.fetch-btn:hover { background: #5a6fd6; }
.error-msg { color: #e94560; text-align: center; padding: 10px; display: none; }
.error-msg.show { display: block; }
</style>
</head>
<body>
<div class="container">
<h1>🌐 Quiz dari API</h1>
<p class="subtitle">Pertanyaan dari Open Trivia DB</p>
<button class="fetch-btn" id="fetchBtn" onclick="fetchQuestions()">🎲 Ambil Pertanyaan Baru</button>
<div class="loading show" id="loading">Memuat pertanyaan...</div>
<div class="error-msg" id="errorMsg"></div>
<div class="quiz-area" id="quizArea">
<div class="progress"><span id="progressText">Soal 1/10</span><span id="scoreText">Skor: 0</span></div>
<div class="question-text" id="questionText">-</div>
<div class="options" id="optionsContainer"></div>
<button class="next-btn" id="nextBtn" onclick="nextQuestion()">Selanjutnya →</button>
</div>
</div>
<script>
let questions = [], current = 0, score = 0, answered = false;

function shuffle(arr) { for (let i = arr.length - 1; i > 0; i--) { const j = Math.floor(Math.random() * (i + 1)); [arr[i], arr[j]] = [arr[j], arr[i]]; } return arr; }

function decodeHTML(html) {
const txt = document.createElement('textarea');
txt.innerHTML = html;
return txt.value;
}

async function fetchQuestions() {
document.getElementById('fetchBtn').disabled = true;
document.getElementById('fetchBtn').textContent = '⏳ Memuat...';
document.getElementById('loading').classList.add('show');
document.getElementById('quizArea').classList.remove('show');
document.getElementById('errorMsg').classList.remove('show');

try {
const res = await fetch('https://opentdb.com/api.php?amount=10&type=multiple');
const data = await res.json();
if (data.response_code !== 0) throw new Error('Gagal mengambil data');

questions = data.results.map((q, idx) => {
const options = shuffle([q.correct_answer, ...q.incorrect_answers]);
return {
id: idx,
question: decodeHTML(q.question),
options: options.map(o => decodeHTML(o)),
correct: options.indexOf(q.correct_answer)
};
});

current = 0; score = 0;
document.getElementById('loading').classList.remove('show');
document.getElementById('quizArea').classList.add('show');
render();

} catch (e) {
document.getElementById('loading').classList.remove('show');
document.getElementById('errorMsg').textContent = '❌ Gagal mengambil pertanyaan. Periksa koneksi internet.';
document.getElementById('errorMsg').classList.add('show');
}
document.getElementById('fetchBtn').disabled = false;
document.getElementById('fetchBtn').textContent = '🎲 Ambil Pertanyaan Baru';
}

function render() {
const q = questions[current];
answered = false;
document.getElementById('progressText').textContent = `Soal ${current + 1}/${questions.length}`;
document.getElementById('scoreText').textContent = `Skor: ${score}`;
document.getElementById('questionText').textContent = q.question;
document.getElementById('nextBtn').classList.remove('show');
document.getElementById('optionsContainer').innerHTML = q.options.map((opt, i) => `<div class="option" onclick="selectAnswer(${i})">${opt}</div>`).join('');
}

function selectAnswer(idx) {
if (answered) return;
answered = true;
const q = questions[current];
document.querySelectorAll('.option').forEach((el, i) => {
if (i === q.correct) el.classList.add('correct');
if (i === idx && idx !== q.correct) el.classList.add('wrong');
});
if (idx === q.correct) score++;
document.getElementById('nextBtn').classList.add('show');
}

function nextQuestion() {
current++;
if (current < questions.length) render();
else {
document.getElementById('quizArea').innerHTML = `<h2 style="color:#667eea;text-align:center">🎉 Selesai!</h2><p style="text-align:center;font-size:24px;color:#fff;margin:20px">Skor: ${score}/${questions.length}</p><button class="fetch-btn" onclick="fetchQuestions()">🔄 Ambil Quiz Baru</button>`;
}
}

// Auto-fetch on load
fetchQuestions();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Klik tombol untuk mengambil pertanyaan baru dari Open Trivia DB. Jawab pertanyaan yang dimuat secara dinamis.
