# 278. Mengimplementasikan Fitur Restart Quiz

## Definisi & Target
Membuat tombol "Coba Lagi" yang mereset quiz ke keadaan awal: skor 0, pertanyaan diacak ulang, dan timer direset.

## Analogi Alur
Restart quiz seperti menekan tombol reset di game: semua progress dihapus, level kembali ke awal, dan Anda bisa memulai petualangan baru dari nol.

## Poin-Poin Penting
- Reset skor, current question index, dan jawaban user
- Shuffle ulang pertanyaan
- Kembali ke welcome screen atau langsung ke soal pertama
- Animasi transisi dari results ke quiz baru
- Konfirmasi jika user ingin restart (opsional)
- Timer direset ke nilai awal
- Array jawaban user dikosongkan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Restart Quiz</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.quiz-card { background: white; border-radius: 24px; padding: 30px; width: 100%; max-width: 500px; box-shadow: 0 25px 80px rgba(0,0,0,0.15); }
h1 { text-align: center; color: #333; margin-bottom: 20px; font-size: 22px; }
.progress-text { color: #888; font-size: 14px; margin-bottom: 10px; }
.question-text { font-size: 18px; color: #333; margin-bottom: 20px; font-weight: 600; }
.options { display: grid; gap: 10px; }
.option { padding: 14px 18px; border: 2px solid #e0e0e0; border-radius: 12px; cursor: pointer; color: #555; font-size: 15px; }
.option:hover { border-color: #667eea; background: #f5f7ff; }
.option.correct { background: #4caf50; color: white; border-color: #4caf50; }
.option.wrong { background: #e94560; color: white; border-color: #e94560; }
.btn-primary, .btn-restart { width: 100%; padding: 14px; margin-top: 15px; border: none; border-radius: 12px; font-size: 16px; cursor: pointer; font-weight: 600; }
.btn-primary { background: #667eea; color: white; display: none; }
.btn-primary.show { display: block; }
.btn-restart { background: #e94560; color: white; margin-top: 10px; }
.result-section { display: none; text-align: center; }
.result-section.show { display: block; animation: fadeIn 0.5s ease; }
@keyframes fadeIn { from { opacity: 0; } to { opacity: 1; } }
.result-section .score { font-size: 48px; font-weight: 700; color: #667eea; margin: 15px 0; }
.result-section .msg { font-size: 18px; color: #333; margin-bottom: 20px; }
</style>
</head>
<body>
<div class="quiz-card" id="quizCard">
<h1>🎯 Quiz</h1>
<div class="progress-text" id="progressText">Soal 1 dari 5</div>
<div class="question-text" id="questionText">Memuat...</div>
<div class="options" id="optionsContainer"></div>
<button class="btn-primary" id="nextBtn" onclick="nextQuestion()">Selanjutnya →</button>
<div class="result-section" id="resultSection">
<h2 style="color:#333">🎉 Quiz Selesai!</h2>
<div class="score" id="finalScore">0/5</div>
<div class="msg" id="finalMsg">Kerja bagus!</div>
<button class="btn-primary show" onclick="restartQuiz()" style="background:#667eea">🔄 Main Lagi</button>
</div>
</div>
<script>
const baseQuestions = [
{ q: 'Apa ibu kota Indonesia?', o: ['Jakarta', 'Bandung', 'Surabaya', 'Yogyakarta'], c: 0 },
{ q: 'Siapa presiden pertama RI?', o: ['Soeharto', 'Soekarno', 'Habibie', 'Megawati'], c: 1 },
{ q: 'CSS singkatan dari?', o: ['Cascading Style Sheets', 'Creative System', 'Computer Sheets', 'Colorful Style'], c: 0 },
{ q: 'Planet terdekat matahari?', o: ['Venus', 'Bumi', 'Merkurius', 'Mars'], c: 2 },
{ q: 'HTML singkatan dari?', o: ['Hyper Text Markup Language', 'High Tech Language', 'Home Tool Language', 'Hyperlink Language'], c: 0 }
];
let questions = [];
let current = 0, score = 0, answered = false;

function shuffle(arr) { for (let i = arr.length - 1; i > 0; i--) { const j = Math.floor(Math.random() * (i + 1)); [arr[i], arr[j]] = [arr[j], arr[i]]; } return arr; }

function initQuiz() {
questions = shuffle([...baseQuestions]);
current = 0;
score = 0;
answered = false;
document.getElementById('resultSection').classList.remove('show');
document.getElementById('nextBtn').classList.remove('show');
render();
}

function render() {
const q = questions[current];
answered = false;
document.getElementById('progressText').textContent = `Soal ${current + 1} dari ${questions.length}`;
document.getElementById('questionText').textContent = q.q;
document.getElementById('nextBtn').classList.remove('show');
document.getElementById('optionsContainer').innerHTML = q.o.map((opt, i) => `<div class="option" onclick="selectAnswer(${i})">${opt}</div>`).join('');
}

function selectAnswer(idx) {
if (answered) return;
answered = true;
const q = questions[current];
document.querySelectorAll('.option').forEach((el, i) => {
if (i === q.c) el.classList.add('correct');
if (i === idx && idx !== q.c) el.classList.add('wrong');
});
if (idx === q.c) score++;
document.getElementById('nextBtn').classList.add('show');
}

function nextQuestion() {
current++;
if (current < questions.length) render();
else {
document.getElementById('quizCard').querySelector('h1').style.display = 'none';
document.getElementById('progressText').style.display = 'none';
document.getElementById('questionText').style.display = 'none';
document.getElementById('optionsContainer').style.display = 'none';
document.getElementById('nextBtn').classList.remove('show');
const rs = document.getElementById('resultSection');
rs.classList.add('show');
document.getElementById('finalScore').textContent = `${score}/${questions.length}`;
const pct = (score / questions.length) * 100;
document.getElementById('finalMsg').textContent = pct >= 80 ? '🎉 Luar biasa!' : pct >= 50 ? '👍 Cukup baik!' : '💪 Semangat belajar!';
}
}

function restartQuiz() {
document.getElementById('quizCard').querySelector('h1').style.display = 'block';
document.getElementById('progressText').style.display = 'block';
document.getElementById('questionText').style.display = 'block';
document.getElementById('optionsContainer').style.display = 'grid';
initQuiz();
}

initQuiz();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Selesaikan quiz, lalu klik "Main Lagi" untuk restart. Quiz direset dengan pertanyaan diacak ulang.
