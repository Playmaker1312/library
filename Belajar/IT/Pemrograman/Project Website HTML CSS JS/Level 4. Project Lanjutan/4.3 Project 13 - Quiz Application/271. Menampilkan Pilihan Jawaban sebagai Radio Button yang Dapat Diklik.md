# 271. Menampilkan Pilihan Jawaban sebagai Radio Button yang Dapat Diklik

## Definisi & Target
Membuat pilihan jawaban yang menggunakan desain radio button kustom yang dapat diklik, dengan feedback visual saat dipilih.

## Analogi Alur
Radio button seperti pemilih pada mesin voting: Anda hanya bisa memilih satu opsi, dan pilihan Anda ditandai dengan lingkaran terisi. Tidak bisa memilih lebih dari satu.

## Poin-Poin Penting
- Gunakan input type="radio" dengan label kustom
- Hanya satu opsi yang bisa dipilih dalam satu waktu
- Tampilkan lingkaran radio yang indah dengan CSS
- Sembunyikan input asli, tampilkan label kustom
- State checked ditandai dengan fill atau border berbeda
- Keyboard accessible (tab dan arrow keys)
- Validasi bahwa satu opsi harus dipilih sebelum lanjut

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Radio Button Quiz</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #16213e; border-radius: 20px; padding: 30px; width: 100%; max-width: 500px; }
h1 { text-align: center; color: #e94560; margin-bottom: 20px; font-size: 22px; }
.question-text { color: #eee; font-size: 18px; margin-bottom: 20px; font-weight: 600; }
.radio-group { display: grid; gap: 12px; }
.radio-option { position: relative; }
.radio-option input[type="radio"] { display: none; }
.radio-option label { display: flex; align-items: center; gap: 14px; padding: 14px 18px; background: #0f3460; border: 2px solid #1a3a6e; border-radius: 12px; cursor: pointer; transition: all 0.3s; font-size: 15px; color: #ccc; }

.radio-option input[type="radio"]:checked + label { border-color: #667eea; background: rgba(102,126,234,0.15); color: #fff; }
.radio-custom { width: 22px; height: 22px; border: 2px solid #555; border-radius: 50%; display: flex; align-items: center; justify-content: center; flex-shrink: 0; transition: all 0.3s; }
.radio-custom:after { content: ''; width: 10px; height: 10px; border-radius: 50%; background: transparent; transition: all 0.3s; }
.radio-option input[type="radio"]:checked + label .radio-custom { border-color: #667eea; }
.radio-option input[type="radio"]:checked + label .radio-custom:after { background: #667eea; }

<div class="container">

<div class="radio-option"><input type="radio" name="answer" id="opt1" value="1"><label for="opt1"><span class="radio-custom"></span>Bandung</label></div>

</div>

<div class="result" id="result"></div>
</div>
<script>
const correct = 0;
function submitAnswer() {
const selected = document.querySelector('input[name="answer"]:checked');
const result = document.getElementById('result');
if (!selected) {
result.textContent = '⚠️ Silakan pilih jawaban terlebih dahulu!';
result.style.color = '#e94560';
result.classList.add('show');
return;
}
const val = parseInt(selected.value);
if (val === correct) {
result.textContent = '✅ Benar! Jakarta adalah ibu kota Indonesia.';
result.style.color = '#4caf50';
} else {
result.textContent = `❌ Salah. Jawaban yang benar adalah Jakarta.`;
result.style.color = '#e94560';
}
result.classList.add('show');
}
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Klik salah satu opsi radio, lalu Submit. Radio button kustom dengan animasi lingkaran terisi saat dipilih.
