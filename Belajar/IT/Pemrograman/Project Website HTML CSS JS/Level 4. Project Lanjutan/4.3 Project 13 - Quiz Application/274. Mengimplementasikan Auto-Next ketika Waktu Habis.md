# 274. Mengimplementasikan Auto-Next ketika Waktu Habis

## Definisi & Target
Saat timer mencapai 0, secara otomatis pindah ke pertanyaan berikutnya setelah menampilkan feedback bahwa waktu habis.

## Analogi Alur
Auto-next seperti mesin otomatis di pabrik: ketika satu item selesai diproses (waktu habis), ban berjalan bergerak otomatis membawa item berikutnya tanpa perlu menekan tombol.

## Poin-Poin Penting
- Saat timer = 0, tampilkan feedback jawaban yang benar
- Tandai bahwa waktu habis (timeout state)
- Setelah jeda 2-3 detik, otomatis lanjut ke soal berikutnya
- Hitung jawaban sebagai salah jika timeout
- Gunakan setTimeout untuk delay auto-next
- Timer tetap terlihat saat timeout

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Auto-Next Timer</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1a3e; border-radius: 20px; padding: 30px; width: 100%; max-width: 500px; }
h1 { text-align: center; color: #e94560; margin-bottom: 20px; font-size: 22px; }
.timer-display { text-align: center; margin-bottom: 20px; }
.timer-circle { width: 64px; height: 64px; border-radius: 50%; margin: 0 auto; display: flex; align-items: center; justify-content: center; font-size: 24px; font-weight: 600; font-family: monospace; border: 4px solid #667eea; color: #fff; transition: all 0.3s; }
.timer-circle.warning { border-color: #f39c12; color: #f39c12; }
.timer-circle.danger { border-color: #e94560; color: #e94560; animation: pulse 0.5s infinite; }
@keyframes pulse { 0%,100% { transform: scale(1); } 50% { transform: scale(1.1); } }
.question-text { color: #eee; font-size: 18px; margin-bottom: 20px; }
.options { display: grid; gap: 10px; }
.option { padding: 14px 18px; background: #12123a; border: 2px solid #2a2a5e; border-radius: 12px; cursor: pointer; color: #ccc; font-size: 15px; }
.option.correct { background: rgba(76,175,80,0.2); border-color: #4caf50; color: #4caf50; }
.option.disabled { opacity: 0.4; cursor: not-allowed; }
.auto-badge { text-align: center; color: #f39c12; font-size: 13px; margin-top: 10px; display: none; }
.auto-badge.show { display: block; animation: blink 0.5s ease 3; }
@keyframes blink { 0%,100% { opacity: 1; } 50% { opacity: 0.3; } }
</style>
</head>
<body>
<div class="container">
<h1>⏩ Auto-Next</h1>
<div class="timer-display"><div class="timer-circle" id="timerCircle">10</div></div>
<div class="question-text" id="questionText">Memuat...</div>
<div class="options" id="optionsContainer"></div>
<div class="auto-badge" id="autoBadge">⏩ Auto-next dalam 2 detik...</div>
</div>
<script>
const questions = [
{ q: 'Apa ibu kota Indonesia?', o: ['Jakarta', 'Bandung', 'Surabaya', 'Yogyakarta'], c: 0 },
{ q: 'Siapa presiden pertama RI?', o: ['Soeharto', 'Soekarno', 'Habibie', 'Megawati'], c: 1 },
{ q: 'CSS singkatan dari?', o: ['Cascading Style Sheets', 'Creative System', 'Computer Sheets', 'Colorful Style'], c: 0 }
];
let current = 0, score = 0, timeLeft = 10, answered = false;
let timerInterval = null, autoTimer = null;

function render() {
const q = questions[current];
answered = false;
clearInterval(timerInterval);
clearTimeout(autoTimer);
timeLeft = 10;
updateTimer();
document.getElementById('questionText').textContent = q.q;
document.getElementById('autoBadge').classList.remove('show');
const container = document.getElementById('optionsContainer');
container.innerHTML = q.o.map((opt, i) => `<div class="option" onclick="selectAnswer(${i})">${opt}</div>`).join('');
timerInterval = setInterval(tick, 1000);
}

function tick() {
timeLeft--;
updateTimer();
if (timeLeft <= 0) {
clearInterval(timerInterval);
handleTimeout();
}
}

function updateTimer() {
const circle = document.getElementById('timerCircle');
circle.textContent = timeLeft;
circle.classList.toggle('warning', timeLeft <= 3 && timeLeft > 1);
circle.classList.toggle('danger', timeLeft <= 1);
}

function selectAnswer(idx) {
if (answered) return;
answered = true;
clearInterval(timerInterval);
clearTimeout(autoTimer);
const q = questions[current];
const options = document.querySelectorAll('.option');
options.forEach((el, i) => {
if (i === q.c) el.classList.add('correct');
el.classList.add('disabled');
});
if (idx === q.c) score++;
autoTimer = setTimeout(nextQuestion, 1500);
}

function handleTimeout() {
if (answered) return;
answered = true;
const q = questions[current];
document.querySelectorAll('.option').forEach((el, i) => {
if (i === q.c) el.classList.add('correct');
el.classList.add('disabled');
});
document.getElementById('autoBadge').classList.add('show');
autoTimer = setTimeout(nextQuestion, 2000);
}

function nextQuestion() {
current++;
if (current < questions.length) render();
else document.querySelector('.container').innerHTML = `<h1 style="text-align:center;color:#667eea">🎉 Selesai!</h1><p style="text-align:center;font-size:24px;color:#fff;margin:20px">Skor: ${score}/${questions.length}</p>`;
}
render();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Biarkan timer habis untuk melihat auto-next. Atau jawab untuk lanjut manual dengan jeda. Timer detik terakhir berwarna merah dan berdenyut.
