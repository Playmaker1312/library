# 277. Menampilkan Summary Jawaban Benar dan Salah di Results Screen

## Definisi & Target
Menampilkan ringkasan detail setiap pertanyaan di results screen, menunjukkan mana yang dijawab benar, salah, atau tidak dijawab.

## Analogi Alur
Summary jawaban seperti lembar jawaban ujian yang dikembalikan guru: setiap soal diberi tanda centang (✓) atau silang (✕) lengkap dengan jawaban yang benar.

## Poin-Poin Penting
- List semua pertanyaan dengan status jawaban
- Ikon: hijau (✓) untuk benar, merah (✕) untuk salah, abu-abu (-) untuk tidak dijawab
- Tampilkan jawaban user dan jawaban yang benar
- Scrollable list jika banyak pertanyaan
- Kelompokkan berdasarkan status (opsional)
- Animasi muncul bertahap per item

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Quiz Summary</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1a3e; border-radius: 20px; padding: 30px; width: 100%; max-width: 600px; }
h1 { text-align: center; color: #667eea; margin-bottom: 5px; font-size: 22px; }
.subtitle { text-align: center; color: #888; font-size: 13px; margin-bottom: 20px; }
.summary-header { display: flex; justify-content: space-around; background: #12123a; border-radius: 12px; padding: 15px; margin-bottom: 20px; }
.summary-stat { text-align: center; }

.summary-item .q-text { color: #ddd; font-size: 15px; margin-bottom: 8px; }

.answer-badge.correct { background: rgba(76,175,80,0.15); color: #4caf50; border: 1px solid rgba(76,175,80,0.3); }

.status-icon { font-size: 18px; }

<body>
<div class="container">
<h1>📋 Summary Jawaban</h1>
<p class="subtitle">Detail jawaban untuk setiap pertanyaan</p>
<div class="summary-header">
<div class="summary-stat"><div class="number green" id="correctNum">7</div><div class="label">✅ Benar</div></div>
<div class="summary-stat"><div class="number red" id="wrongNum">2</div><div class="label">❌ Salah</div></div>

</div>

</div>
<script>
const quizResults = [
{ question: 'Apa ibu kota Indonesia?', options: ['Jakarta', 'Bandung', 'Surabaya', 'Yogyakarta'], correct: 0, userAnswer: 0 },
{ question: 'Siapa presiden pertama RI?', options: ['Soeharto', 'Soekarno', 'Habibie', 'Megawati'], correct: 1, userAnswer: 2 },
{ question: 'CSS singkatan dari?', options: ['Cascading Style Sheets', 'Creative System', 'Computer Sheets', 'Colorful Style'], correct: 0, userAnswer: 0 },
{ question: 'Planet terdekat dari matahari?', options: ['Venus', 'Bumi', 'Merkurius', 'Mars'], correct: 2, userAnswer: 3 },
{ question: 'HTML singkatan dari?', options: ['Hyper Text Markup Language', 'High Tech Language', 'Home Tool Language', 'Hyperlink Language'], correct: 0, userAnswer: 0 },
{ question: 'Tahun Indonesia merdeka?', options: ['1942', '1945', '1948', '1950'], correct: 1, userAnswer: 1 },
{ question: 'Apa itu API?', options: ['Application Programming Interface', 'Automated Program Interface', 'Advanced Programming Internet', 'Application Process Integration'], correct: 0, userAnswer: 0 },
{ question: 'Fungsi tag <a>?', options: ['Membuat tombol', 'Membuat link', 'Membuat gambar', 'Membuat tabel'], correct: 1, userAnswer: 1 },
{ question: 'LocalStorage menyimpan data di?', options: ['Server', 'Database', 'Browser', 'File'], correct: 2, userAnswer: 2 },
{ question: 'CSS Flexbox digunakan untuk?', options: ['Layout', 'Animasi', 'Database', 'Network'], correct: 0, userAnswer: null }
];

function renderSummary() {
const list = document.getElementById('summaryList');
let correct = 0, wrong = 0, skipped = 0;

list.innerHTML = quizResults.map((q, i) => {
const isCorrect = q.userAnswer === q.correct;
const isSkipped = q.userAnswer === null || q.userAnswer === undefined;
if (isSkipped) skipped++;
else if (isCorrect) correct++;
else wrong++;

let status, statusIcon, badgeClass;
if (isSkipped) { status = 'Tidak dijawab'; statusIcon = '⏭️'; badgeClass = 'skipped'; }
else if (isCorrect) { status = 'Benar'; statusIcon = '✅'; badgeClass = 'correct'; }
else { status = 'Salah'; statusIcon = '❌'; badgeClass = 'wrong'; }

const userAnswerText = !isSkipped ? q.options[q.userAnswer] : '-';
const correctAnswerText = q.options[q.correct];

return `<div class="summary-item" style="animation-delay:${i * 0.1}s">
  <div class="q-text"><span class="status-icon">${statusIcon}</span> ${i + 1}. ${q.question}</div>
  <div class="answers">
    <span class="answer-badge ${badgeClass}">Anda: ${userAnswerText}</span>
    ${!isCorrect ? `<span class="answer-badge correct">Jawaban: ${correctAnswerText}</span>` : ''}
  </div>
</div>`;
}).join('');

document.getElementById('correctNum').textContent = correct;
document.getElementById('wrongNum').textContent = wrong;
document.getElementById('skippedNum').textContent = skipped;
}

renderSummary();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Lihat summary detail setiap pertanyaan dengan status benar (hijau), salah (merah), atau tidak dijawab (abu-abu).
