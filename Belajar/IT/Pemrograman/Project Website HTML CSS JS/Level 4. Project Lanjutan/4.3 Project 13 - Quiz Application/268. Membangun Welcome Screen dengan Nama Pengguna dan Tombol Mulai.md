# 268. Membangun Welcome Screen dengan Nama Pengguna dan Tombol Mulai

## Definisi & Target
Membuat layar selamat datang yang meminta nama pengguna sebelum memulai quiz, dengan tombol mulai yang menarik.

## Analogi Alur
Welcome screen seperti meja pendaftaran lomba: Anda menulis nama, lalu panitia memberi aba-aba untuk memulai. Tanpa nama, Anda tidak bisa ikut serta.

## Poin-Poin Penting
- Input field untuk nama pengguna
- Validasi nama tidak boleh kosong
- Tombol "Mulai Quiz" dengan desain menarik
- Animasi masuk untuk welcome screen
- Layout yang bersih dan fokus pada satu tujuan
- Nama ditampilkan di layar selanjutnya
- Opsional: pilih kategori atau level kesulitan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Welcome Quiz</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.welcome-card { background: white; border-radius: 24px; padding: 40px; width: 100%; max-width: 450px; box-shadow: 0 25px 80px rgba(0,0,0,0.2); text-align: center; animation: slideUp 0.6s ease; }
@keyframes slideUp { from { opacity: 0; transform: translateY(30px); } to { opacity: 1; transform: translateY(0); } }
.welcome-icon { font-size: 64px; margin-bottom: 15px; }
h1 { color: #333; font-size: 28px; margin-bottom: 8px; }
p { color: #888; font-size: 14px; margin-bottom: 25px; line-height: 1.5; }
.input-group { margin-bottom: 20px; }
.input-group input { width: 100%; padding: 14px 18px; border: 2px solid #e0e0e0; border-radius: 12px; font-size: 16px; outline: none; transition: border-color 0.3s; text-align: center; }
.input-group input:focus { border-color: #667eea; }
.start-btn { width: 100%; padding: 16px; background: linear-gradient(135deg, #667eea, #764ba2); color: white; border: none; border-radius: 12px; font-size: 18px; font-weight: 600; cursor: pointer; transition: transform 0.2s, box-shadow 0.2s; }
.start-btn:hover { transform: translateY(-2px); box-shadow: 0 10px 30px rgba(102,126,234,0.4); }
.start-btn:active { transform: translateY(0); }
.quiz-screen { display: none; background: white; border-radius: 24px; padding: 40px; width: 100%; max-width: 450px; box-shadow: 0 25px 80px rgba(0,0,0,0.2); text-align: center; }
.quiz-screen.show { display: block; animation: slideUp 0.5s ease; }
</style>
</head>
<body>
<div class="welcome-card" id="welcomeScreen">
<div class="welcome-icon">🎯</div>
<h1>Quiz Cerdas</h1>
<p>Uji pengetahuan Anda dengan quiz interaktif!<br>Jawab 10 pertanyaan dan raih skor tertinggi!</p>
<div class="input-group">
<input type="text" id="nameInput" placeholder="Masukkan nama Anda..." autofocus maxlength="20">
</div>
<button class="start-btn" onclick="startQuiz()">🚀 Mulai Quiz</button>
</div>
<div class="quiz-screen" id="quizScreen">
<div class="welcome-icon">🎉</div>
<h1 id="greeting">Halo, User!</h1>
<p id="readyText">Quiz akan segera dimulai. Siapkan diri Anda!</p>
<button class="start-btn" onclick="alert('Quiz dimulai!')" style="margin-top:10px">Lanjutkan</button>
</div>
<script>
function startQuiz() {
const name = document.getElementById('nameInput').value.trim();
if (!name) {
document.getElementById('nameInput').style.borderColor = '#e94560';
setTimeout(() => document.getElementById('nameInput').style.borderColor = '#e0e0e0', 1000);
return;
}
document.getElementById('welcomeScreen').style.display = 'none';
const quizScreen = document.getElementById('quizScreen');
quizScreen.classList.add('show');
document.getElementById('greeting').textContent = `Halo, ${name}! 👋`;
document.getElementById('readyText').textContent = `Kamu akan menjawab 10 pertanyaan. Semoga berhasil, ${name}!`;
}

document.getElementById('nameInput').addEventListener('keypress', function(e) {
if (e.key === 'Enter') startQuiz();
});
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Masukkan nama dan klik Mulai. Welcome screen akan berganti ke layar siap quiz dengan sapaan personal.
