# 267. Membuat Data Pertanyaan dalam Format JSON dengan Jawaban yang Benar

## Definisi & Target
Membuat struktur data pertanyaan dalam format JSON array of objects, berisi soal, pilihan jawaban, dan indeks jawaban benar.

## Analogi Alur
Data pertanyaan JSON seperti buku soal ujian: setiap halaman berisi satu soal, daftar pilihan, dan kunci jawaban di halaman belakang. Komputer membaca buku ini untuk menguji user.

## Poin-Poin Penting
- Array of objects dengan properti: question, options[], correct (index)
- options adalah array berisi 4 pilihan jawaban
- correct adalah index dari jawaban benar (0-3)
- Bisa menambah properti lain: category, difficulty, explanation
- JSON dapat di-load dari file eksternal atau inline
- Minimal 10 pertanyaan untuk quiz yang berarti
- Pertanyaan bisa di-shuffle menggunakan algoritma Fisher-Yates

