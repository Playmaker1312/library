# 269. Mengimplementasikan Shuffle Pertanyaan secara Acak menggunakan Fisher-Yates Algorithm

## Definisi & Target
Mengacak urutan pertanyaan menggunakan algoritma Fisher-Yates (Knuth shuffle) agar setiap kali quiz dimulai, pertanyaan muncul dalam urutan berbeda.

## Analogi Alur
Fisher-Yates seperti mengocok kartu remi: Anda mengambil satu per satu kartu dari tumpukan dan menukarnya dengan kartu lain secara acak. Hasilnya adalah urutan yang benar-benar random.

## Poin-Poin Penting
- Algoritma: iterasi dari akhir ke awal, tukar dengan index acak
- Kompleksitas O(n) - sangat efisien
- Setiap permutasi memiliki probabilitas yang sama
- Implementasi: for (let i = arr.length - 1; i > 0; i--) { const j = Math.floor(Math.random() * (i + 1)); [arr[i], arr[j]] = [arr[j], arr[i]]; }
- Shuffle dilakukan saat quiz dimulai
- Simpan array asli jika ingin reset
