# 272. Mengimplementasikan Feedback Visual yaitu Hijau untuk Benar dan Merah untuk Salah

## Definisi & Target
Memberikan feedback visual instan setelah user memilih jawaban: warna hijau untuk jawaban benar dan merah untuk jawaban salah.

## Analogi Alur
Feedback visual seperti lampu lalu lintas: hijau berarti Anda benar (jalan terus), merah berarti Anda salah (berhenti). Anda langsung tahu hasil tanpa perlu membaca penjelasan.

## Poin-Poin Penting
- Tambahkan class CSS 'correct' (hijau) dan 'wrong' (merah) pada opsi
- Opsi yang benar tetap hijau meskipun user salah pilih
- Animasi transisi warna yang halus
- Tampilkan ikon centang (✓) atau silang (✕)
- Jeda sebelum lanjut ke pertanyaan berikutnya
- Efek shake untuk jawaban salah
- Confetti atau sparkle untuk jawaban benar (opsional)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Feedback Visual Quiz</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1a3e; border-radius: 20px; padding: 30px; width: 100%; max-width: 500px; }
h1 { text-align: center; color: #667eea; margin-bottom: 20px; font-size: 22px; }
.question-text { color: #eee; font-size: 18px; margin-bottom: 20px; }
.options { display: grid; gap: 10px; }
.option { padding: 14px 18px; background: #12123a; border: 2px solid #2a2a5e; border-radius: 12px; cursor: pointer; transition: all 0.4s; font-size: 15px; color: #ccc; display: flex; align-items: center; gap: 10px; }
.option:hover { border-color: #667eea; }
.option.correct { background: rgba(76,175,80,0.2); border-color: #4caf50; color: #4caf50; animation: pulseGreen 0.5s ease; }
@keyframes pulseGreen { 0% { transform: scale(1); } 50% { transform: scale(1.02); } 100% { transform: scale(1); } }
.option.wrong { background: rgba(233,69,96,0.2); border-color: #e94560; color: #e94560; animation: shake 0.4s ease; }
@keyframes shake { 0%,100% { transform: translateX(0); } 20% { transform: translateX(-8px); } 40% { transform: translateX(8px); } 60% { transform: translateX(-4px); } 80% { transform: translateX(4px); } }
.option .icon { font-size: 18px; }
.option .letter { color: #555; font-weight: 600; min-width: 20px; }
.score-bar { display: flex; justify-content: space-between; color: #888; font-size: 14px; margin-bottom: 20px; padding-bottom: 15px; border-bottom: 1px solid #2a2a5e; }
.next-btn { width: 100%; padding: 14px; margin-top: 15px; background: #667eea; border: none; border-radius: 12px; color: white; font-size: 16px; cursor: pointer; font-weight: 600; display: none; }
.next-btn.show { display: block; }
</style>
</head>
<body>
<div class="container">
<h1>✅ Feedback Visual</h1>
<div class="score-bar"><span id="progressText">Soal 1 dari 5</span><span id="scoreText">Skor: 0</span></div>
<div class="question-text" id="questionText">Apa ibu kota Indonesia?</div>
<div class="options" id="optionsContainer"></div>
<button class="next-btn" id="nextBtn" onclick="nextQuestion()">Soal Berikutnya →</button>
</div>
<script>
const questions = [
{ q: 'Apa ibu kota Indonesia?', o: ['Jakarta', 'Bandung', 'Surabaya', 'Yogyakarta'], c: 0 },
{ q: 'Siapa presiden pertama RI?', o: ['Soeharto', 'Soekarno', 'Habibie', 'Megawati'], c: 1 },
{ q: 'CSS adalah singkatan dari?', o: ['Cascading Style Sheets', 'Creative Style System', 'Computer Style Sheets', 'Colorful Style Sheets'], c: 0 },
{ q: 'Planet terdekat dari matahari?', o: ['Venus', 'Bumi', 'Merkurius', 'Mars'], c: 2 },
{ q: 'HTML adalah singkatan dari?', o: ['Hyper Text Markup Language', 'High Tech Modern Language', 'Home Tool Markup Language', 'Hyperlink Text Management Language'], c: 0 }
];
let current = 0, score = 0, answered = false;

function render() {
const q = questions[current];
document.getElementById('progressText').textContent = `Soal ${current + 1} dari ${questions.length}`;
document.getElementById('scoreText').textContent = `Skor: ${score}`;
document.getElementById('questionText').textContent = q.q;
document.getElementById('nextBtn').classList.remove('show');
answered = false;
const container = document.getElementById('optionsContainer');
container.innerHTML = q.o.map((opt, i) => `
<div class="option" onclick="selectAnswer(${i})">
  <span class="letter">${String.fromCharCode(65 + i)}</span>
  <span>${opt}</span>
</div>`).join('');
}

function selectAnswer(idx) {
if (answered) return;
answered = true;
const q = questions[current];
const options = document.querySelectorAll('.option');
options.forEach((el, i) => {
if (i === q.c) { el.classList.add('correct'); el.innerHTML = `<span class="icon">✓</span><span>${q.o[i]}</span>`; }
if (i === idx && idx !== q.c) { el.classList.add('wrong'); el.innerHTML = `<span class="icon">✕</span><span>${q.o[i]}</span>`; }
if (i === idx && idx === q.c) { score++; }
});
document.getElementById('scoreText').textContent = `Skor: ${score}`;
document.getElementById('nextBtn').classList.add('show');
}

function nextQuestion() {
current++;
if (current < questions.length) { render(); }
else {
document.querySelector('.container').innerHTML = `<h1 style="text-align:center;color:#667eea">🎉 Selesai!</h1><p style="text-align:center;font-size:24px;color:#fff;margin-top:20px">Skor: ${score}/${questions.length}</p>`;
}
}

render();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Pilih jawaban - feedback langsung dengan warna hijau (benar) atau merah (salah) dan ikon ✓/✕.
