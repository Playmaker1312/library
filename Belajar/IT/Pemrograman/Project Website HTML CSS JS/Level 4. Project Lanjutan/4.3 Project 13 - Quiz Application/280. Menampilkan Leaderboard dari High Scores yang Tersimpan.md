# 280. Menampilkan Leaderboard dari High Scores yang Tersimpan

## Definisi & Target
Membuat leaderboard yang menampilkan daftar skor tertinggi dari beberapa sesi permainan yang tersimpan di LocalStorage.

## Analogi Alur
Leaderboard seperti papan peringkat di sekolah: nama-nama siswa dengan nilai tertinggi ditampilkan di papan pengumuman. Semua orang bisa melihat siapa yang terbaik.

## Poin-Poin Penting
- Array of high scores objects { name, score, date }
- Simpan ke LocalStorage sebagai JSON array
- Urutkan dari skor tertinggi ke terendah
- Tampilkan peringkat (1, 2, 3) dengan ikon medali
- Batasi jumlah entry (misal 10 teratas)
- Tampilkan nama, skor, dan tanggal
- Animasi muncul untuk setiap entry

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Leaderboard</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1a3e; border-radius: 20px; padding: 30px; width: 100%; max-width: 500px; }
h1 { text-align: center; color: #667eea; margin-bottom: 5px; font-size: 22px; }
.subtitle { text-align: center; color: #888; font-size: 13px; margin-bottom: 20px; }
.leaderboard-item { display: flex; align-items: center; gap: 12px; background: #12123a; border: 1px solid #2a2a5e; border-radius: 12px; padding: 14px 16px; margin-bottom: 8px; animation: slideUp 0.3s ease; }
@keyframes slideUp { from { opacity: 0; transform: translateY(10px); } to { opacity: 1; transform: translateY(0); } }
.rank { font-size: 20px; font-weight: 700; min-width: 36px; text-align: center; }
.rank.gold { color: #ffd700; } .rank.silver { color: #c0c0c0; } .rank.bronze { color: #cd7f32; }
.rank.other { color: #555; }
.player-info { flex: 1; }
.player-name { color: #ddd; font-size: 15px; font-weight: 600; }
.player-date { color: #555; font-size: 11px; }
.player-score { font-size: 22px; font-weight: 700; color: #667eea; }
.empty-state { text-align: center; color: #555; padding: 30px; }
.add-score-section { margin-top: 20px; padding-top: 20px; border-top: 1px solid #2a2a5e; display: flex; gap: 10px; }
.add-score-section input { flex: 1; padding: 10px 14px; border: 1px solid #2a2a5e; border-radius: 8px; background: #12123a; color: #fff; font-size: 14px; outline: none; }
.add-score-section button { padding: 10px 20px; background: #667eea; border: none; border-radius: 8px; color: white; font-size: 14px; cursor: pointer; }
</style>
</head>
<body>
<div class="container">
<h1>🏆 Leaderboard</h1>
<p class="subtitle">10 skor tertinggi</p>
<div id="leaderboardList"></div>
<div class="add-score-section">
<input type="text" id="nameInput" placeholder="Nama kamu..." maxlength="15">
<button onclick="addScore()">Simpan Skor</button>
</div>
</div>
<script>
const STORAGE_KEY = 'quiz_leaderboard';
let scores = [];

function loadScores() {
try { scores = JSON.parse(localStorage.getItem(STORAGE_KEY)) || []; } catch { scores = []; }
}

function saveScores() {
try { localStorage.setItem(STORAGE_KEY, JSON.stringify(scores)); } catch {}
}

function addScore() {
const name = document.getElementById('nameInput').value.trim();
if (!name) return;
const newScore = Math.floor(Math.random() * 5) + 6;
scores.push({ name, score: newScore, date: new Date().toLocaleDateString('id-ID') });
scores.sort((a, b) => b.score - a.score);
if (scores.length > 10) scores = scores.slice(0, 10);
saveScores();
document.getElementById('nameInput').value = '';
renderLeaderboard();
}

function getRankIcon(rank) {
if (rank === 0) return '🥇';
if (rank === 1) return '🥈';
if (rank === 2) return '🥉';
return `#${rank + 1}`;
}

function getRankClass(rank) {
if (rank === 0) return 'gold';
if (rank === 1) return 'silver';
if (rank === 2) return 'bronze';
return 'other';
}

function renderLeaderboard() {
const list = document.getElementById('leaderboardList');
if (scores.length === 0) {
list.innerHTML = '<div class="empty-state">Belum ada skor. Mainkan quiz untuk mengisi leaderboard!</div>';
return;
}
list.innerHTML = scores.map((s, i) => `
<div class="leaderboard-item" style="animation-delay:${i * 0.05}s">
  <div class="rank ${getRankClass(i)}">${getRankIcon(i)}</div>
  <div class="player-info">
    <div class="player-name">${s.name}</div>
    <div class="player-date">${s.date}</div>
  </div>
  <div class="player-score">${s.score}/10</div>
</div>
`).join('');
}

loadScores();
renderLeaderboard();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Klik "Simpan Skor" untuk menambah entry random. Leaderboard menampilkan 10 skor tertinggi dengan medali untuk top 3.
