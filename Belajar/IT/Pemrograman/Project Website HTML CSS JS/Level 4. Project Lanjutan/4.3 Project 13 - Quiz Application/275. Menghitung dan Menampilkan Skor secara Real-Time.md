# 275. Menghitung dan Menampilkan Skor secara Real-Time

## Definisi & Target
Menghitung skor berdasarkan jawaban benar dan menampilkannya secara real-time di header quiz.

## Analogi Alur
Skor real-time seperti papan skor di pertandingan olahraga: setiap kali seorang pemain mencetak angka, papan skor langsung berubah. Penonton bisa melihat perkembangan skor kapan saja.

## Poin-Poin Penting
- Variabel global score untuk akumulasi jawaban benar
- Tambah score setiap kali user menjawab benar
- Tampilkan di header atau sidebar
- Format: "Skor: 7 / 10"
- Animasi saat skor bertambah (counter up)
- Skor per kategori (jika ada beberapa kategori)
- Jangan berubah jika user mengulang pertanyaan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Real-Time Score</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: white; border-radius: 24px; padding: 30px; width: 100%; max-width: 500px; box-shadow: 0 25px 80px rgba(0,0,0,0.15); }
.header { display: flex; justify-content: space-between; align-items: center; margin-bottom: 20px; }
h1 { font-size: 20px; color: #333; }
.score-display { background: linear-gradient(135deg, #667eea, #764ba2); color: white; padding: 8px 20px; border-radius: 20px; font-size: 18px; font-weight: 600; }
.score-display span { display: inline-block; min-width: 30px; text-align: center; }
.progress-text { color: #888; font-size: 14px; margin-bottom: 10px; }
.progress-bar { height: 6px; background: #e0e0e0; border-radius: 3px; margin-bottom: 20px; overflow: hidden; }
.progress-fill { height: 100%; background: linear-gradient(90deg, #667eea, #764ba2); border-radius: 3px; transition: width 0.5s ease; }
.question-text { font-size: 18px; color: #333; margin-bottom: 20px; font-weight: 600; }
.options { display: grid; gap: 10px; }
.option { padding: 14px 18px; border: 2px solid #e0e0e0; border-radius: 12px; cursor: pointer; color: #555; font-size: 15px; transition: all 0.3s; }
.option:hover { border-color: #667eea; background: #f5f7ff; }
.option.correct { background: #4caf50; color: white; border-color: #4caf50; }
.option.wrong { background: #e94560; color: white; border-color: #e94560; }
.next-btn { width: 100%; padding: 14px; margin-top: 20px; background: #667eea; color: white; border: none; border-radius: 12px; font-size: 16px; cursor: pointer; font-weight: 600; display: none; }
.next-btn.show { display: block; }
@keyframes scoreUp { 0% { transform: scale(1); } 50% { transform: scale(1.2); } 100% { transform: scale(1); } }
.score-pop { animation: scoreUp 0.3s ease; }
</style>
</head>
<body>
<div class="container">
<div class="header">
<h1>🎯 Quiz</h1>
<div class="score-display">🏆 <span id="scoreDisplay">0</span> / <span id="totalDisplay">5</span></div>
</div>
<div class="progress-text" id="progressText">Soal 1 dari 5</div>
<div class="progress-bar"><div class="progress-fill" id="progressFill" style="width:20%"></div></div>
<div class="question-text" id="questionText">Memuat...</div>
<div class="options" id="optionsContainer"></div>
<button class="next-btn" id="nextBtn" onclick="nextQuestion()">Selanjutnya →</button>
</div>
<script>
const questions = [
{ q: 'Apa ibu kota Indonesia?', o: ['Jakarta', 'Bandung', 'Surabaya', 'Yogyakarta'], c: 0 },
{ q: 'Siapa presiden pertama RI?', o: ['Soeharto', 'Soekarno', 'Habibie', 'Megawati'], c: 1 },
{ q: 'CSS singkatan dari?', o: ['Cascading Style Sheets', 'Creative System', 'Computer Sheets', 'Colorful Style'], c: 0 },
{ q: 'Planet terdekat matahari?', o: ['Venus', 'Bumi', 'Merkurius', 'Mars'], c: 2 },
{ q: 'HTML singkatan dari?', o: ['Hyper Text Markup Language', 'High Tech Language', 'Home Tool Language', 'Hyperlink Language'], c: 0 }
];
let current = 0, score = 0, answered = false;

function render() {
const q = questions[current];
answered = false;
document.getElementById('progressText').textContent = `Soal ${current + 1} dari ${questions.length}`;
document.getElementById('progressFill').style.width = `${((current) / questions.length) * 100}%`;
document.getElementById('totalDisplay').textContent = questions.length;
document.getElementById('questionText').textContent = q.q;
document.getElementById('nextBtn').classList.remove('show');
const container = document.getElementById('optionsContainer');
container.innerHTML = q.o.map((opt, i) => `<div class="option" onclick="selectAnswer(${i})">${opt}</div>`).join('');
}

function selectAnswer(idx) {
if (answered) return;
answered = true;
const q = questions[current];
document.querySelectorAll('.option').forEach((el, i) => {
if (i === q.c) el.classList.add('correct');
if (i === idx && idx !== q.c) el.classList.add('wrong');
});
if (idx === q.c) {
score++;
const el = document.getElementById('scoreDisplay');
el.textContent = score;
el.classList.remove('score-pop');
void el.offsetWidth;
el.classList.add('score-pop');
}
document.getElementById('nextBtn').classList.add('show');
}

function nextQuestion() {
current++;
if (current < questions.length) render();
else {
document.querySelector('.container').innerHTML = `<h1 style="text-align:center">🎉 Selesai!</h1><p style="text-align:center;font-size:28px;font-weight:600;margin:20px;color:#667eea">Skor: ${score}/${questions.length}</p><p style="text-align:center;color:#888">${score === questions.length ? '🎯 Sempurna!' : score >= 3 ? '👍 Bagus!' : '💪 Semangat!'}</p>`;
}
}
render();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Jawab pertanyaan dan lihat skor bertambah secara real-time di header dengan animasi pop.
