# 270. Menampilkan Pertanyaan Satu per Satu dengan Progress Indicator

## Definisi & Target
Menampilkan satu pertanyaan dalam satu waktu dengan indikator progress yang menunjukkan posisi user (soal ke-berapa dari total).

## Analogi Alur
Progress indicator seperti odometer di mobil: menunjukkan seberapa jauh Anda sudah menempuh perjalanan dan berapa sisa jarak yang harus ditempuh.

## Poin-Poin Penting
- Tampilkan teks "Pertanyaan 3 dari 10"
- Progress bar visual (persentase atau step indicator)
- Navigasi otomatis ke pertanyaan berikutnya
- Animasi transisi antar pertanyaan
- Current question index sebagai state variable
- Tombol atau fungsi untuk pindah ke soal berikutnya

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Quiz Progress</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: white; border-radius: 24px; padding: 30px; width: 100%; max-width: 550px; box-shadow: 0 25px 80px rgba(0,0,0,0.15); }
.progress-header { display: flex; justify-content: space-between; align-items: center; margin-bottom: 15px; }
.progress-text { color: #888; font-size: 14px; }
.progress-bar { width: 100%; height: 6px; background: #e0e0e0; border-radius: 3px; margin-bottom: 25px; overflow: hidden; }
.progress-fill { height: 100%; background: linear-gradient(90deg, #667eea, #764ba2); border-radius: 3px; transition: width 0.5s ease; }
.question-card { animation: fadeIn 0.4s ease; }
@keyframes fadeIn { from { opacity: 0; transform: translateX(20px); } to { opacity: 1; transform: translateX(0); } }
.question-number { color: #667eea; font-size: 14px; font-weight: 600; margin-bottom: 8px; }
.question-text { font-size: 20px; color: #333; margin-bottom: 20px; font-weight: 600; }
.options { display: grid; gap: 10px; }
.option { padding: 14px 18px; border: 2px solid #e0e0e0; border-radius: 12px; cursor: pointer; transition: all 0.3s; font-size: 15px; color: #555; }
.option:hover { border-color: #667eea; background: #f5f7ff; }
.option.selected { border-color: #667eea; background: #667eea; color: white; }
.option.correct { border-color: #4caf50; background: #4caf50; color: white; }
.option.wrong { border-color: #e94560; background: #e94560; color: white; }
.btn-next { width: 100%; padding: 14px; margin-top: 20px; background: #667eea; color: white; border: none; border-radius: 12px; font-size: 16px; cursor: pointer; font-weight: 600; transition: all 0.3s; }
.btn-next:disabled { background: #ccc; cursor: not-allowed; }
</style>
</head>
<body>
<div class="container">
<div class="progress-header">
<span class="progress-text" id="progressText">Pertanyaan 1 dari 5</span>
<span class="progress-text" id="scoreText">Skor: 0</span>
</div>
<div class="progress-bar"><div class="progress-fill" id="progressFill" style="width:20%"></div></div>
<div class="question-card" id="questionCard">
<div class="question-number" id="qNumber">Soal #1</div>
<div class="question-text" id="qText">Apa ibu kota Indonesia?</div>
<div class="options" id="optionsContainer">
<div class="option" onclick="selectOption(0)">Jakarta</div>
<div class="option" onclick="selectOption(1)">Bandung</div>
<div class="option" onclick="selectOption(2)">Surabaya</div>
<div class="option" onclick="selectOption(3)">Yogyakarta</div>
</div>
<button class="btn-next" id="nextBtn" onclick="nextQuestion()" disabled>Selanjutnya →</button>
</div>
</div>
<script>
const questions = [
{ q: 'Apa ibu kota Indonesia?', o: ['Jakarta', 'Bandung', 'Surabaya', 'Yogyakarta'], c: 0 },
{ q: 'Siapa presiden pertama RI?', o: ['Soeharto', 'Soekarno', 'Habibie', 'Megawati'], c: 1 },
{ q: 'CSS adalah singkatan dari?', o: ['Cascading Style Sheets', 'Creative Style System', 'Computer Style Sheets', 'Colorful Style Sheets'], c: 0 },
{ q: 'Apa fungsi JavaScript?', o: ['Styling', 'Struktur', 'Interaktivitas', 'Database'], c: 2 },
{ q: 'Tahun berapa Indonesia merdeka?', o: ['1942', '1945', '1948', '1950'], c: 1 }
];
let current = 0, score = 0, selected = null;

function renderQuestion() {
const q = questions[current];
document.getElementById('progressText').textContent = `Pertanyaan ${current + 1} dari ${questions.length}`;
document.getElementById('progressFill').style.width = `${((current + 1) / questions.length) * 100}%`;
document.getElementById('scoreText').textContent = `Skor: ${score}`;
document.getElementById('qNumber').textContent = `Soal #${current + 1}`;
document.getElementById('qText').textContent = q.q;
const optContainer = document.getElementById('optionsContainer');
optContainer.innerHTML = q.o.map((opt, i) => `<div class="option" onclick="selectOption(${i})">${opt}</div>`).join('');
document.getElementById('nextBtn').disabled = true;
selected = null;
}

function selectOption(idx) {
selected = idx;
document.querySelectorAll('.option').forEach((el, i) => {
el.classList.remove('selected', 'correct', 'wrong');
if (i === idx) el.classList.add('selected');
});
document.getElementById('nextBtn').disabled = false;
}

function nextQuestion() {
const correct = questions[current].c;
document.querySelectorAll('.option').forEach((el, i) => {
el.classList.remove('selected');
el.classList.add(i === correct ? 'correct' : 'wrong');
});
if (selected === correct) score++;
current++;
if (current < questions.length) {
setTimeout(renderQuestion, 800);
} else {
document.getElementById('questionCard').innerHTML = `<h2 style="text-align:center;padding:20px">🎉 Quiz Selesai!</h2><p style="text-align:center;font-size:20px">Skor: ${score}/${questions.length}</p>`;
document.getElementById('progressFill').style.width = '100%';
document.getElementById('progressText').textContent = 'Selesai!';
}
}

renderQuestion();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Pilih jawaban, lalu klik Selanjutnya. Progress bar dan indikator soal akan bergerak maju.
