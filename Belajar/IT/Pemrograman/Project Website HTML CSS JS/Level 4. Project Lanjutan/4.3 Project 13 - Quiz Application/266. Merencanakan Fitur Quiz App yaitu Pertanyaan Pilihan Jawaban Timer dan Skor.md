# 266. Merencanakan Fitur Quiz App yaitu Pertanyaan, Pilihan Jawaban, Timer, dan Skor

## Definisi & Target
Merencanakan fitur-fitur Quiz App: sistem pertanyaan, pilihan jawaban, timer countdown, dan perhitungan skor.

## Analogi Alur
Quiz App seperti permainan cerdas cermat di TV: pembawa acara memberikan pertanyaan, peserta memilih jawaban dari opsi yang diberikan, waktu terbatas, dan skor dihitung berdasarkan jawaban benar.

## Poin-Poin Penting
- Pertanyaan dengan 4 pilihan jawaban (A, B, C, D)
- Timer countdown untuk setiap pertanyaan
- Feedback visual benar/salah setelah menjawab
- Skor akumulasi dari jawaban benar
- Progress bar menunjukkan posisi pertanyaan
- Welcome screen dan Results screen
- High score dan leaderboard
