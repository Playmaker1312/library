# 285. Memastikan Quiz App Accessible dan Bisa Dimainkan dengan Keyboard

## Definisi & Target
Memastikan Quiz App dapat digunakan oleh semua pengguna termasuk yang menggunakan keyboard saja (tanpa mouse) dan screen reader.

## Analogi Alur
Accessibility seperti membangun pintu yang lebar: tidak hanya untuk kursi roda, tapi juga memudahkan semua orang. Desain yang inklusif membuat aplikasi dapat digunakan oleh siapa saja.

## Poin-Poin Penting
- Semua elemen interaktif harus dapat di-focus dengan Tab
- Gunakan tabindex dan aria-label yang sesuai
- Feedback visual untuk focus outline
- Navigasi dengan arrow keys untuk pilihan jawaban
- Enter/Space untuk memilih jawaban
- Role="radiogroup" untuk opsi jawaban
- Warna kontras yang memadai (WCAG AA)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Accessible Quiz</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #16213e; border-radius: 20px; padding: 30px; width: 100%; max-width: 550px; }
h1 { text-align: center; color: #e94560; margin-bottom: 5px; font-size: 22px; }
.sr-only { position: absolute; width: 1px; height: 1px; padding: 0; margin: -1px; overflow: hidden; clip: rect(0,0,0,0); border: 0; }
.progress-text { color: #888; font-size: 14px; margin-bottom: 10px; }
.question-text { color: #eee; font-size: 18px; margin-bottom: 20px; font-weight: 600; }
.options { display: grid; gap: 10px; }
.option { display: flex; align-items: center; gap: 12px; padding: 14px 18px; background: #0f3460; border: 2px solid #1a3a6e; border-radius: 12px; cursor: pointer; color: #ccc; font-size: 15px; transition: all 0.2s; }
.option:hover { border-color: #667eea; background: #1a3a6e; }
.option:focus-within { outline: 2px solid #667eea; outline-offset: 2px; }
.option input[type="radio"] { appearance: none; -webkit-appearance: none; width: 20px; height: 20px; border: 2px solid #555; border-radius: 50%; flex-shrink: 0; position: relative; transition: all 0.2s; }
.option input[type="radio"]:checked { border-color: #667eea; background: #667eea; }
.option input[type="radio"]:checked:after { content: ''; position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); width: 8px; height: 8px; border-radius: 50%; background: white; }
.option input[type="radio"]:focus-visible { outline: 2px solid #667eea; }
.option.correct { border-color: #4caf50; background: rgba(76,175,80,0.15); }
.option.wrong { border-color: #e94560; background: rgba(233,69,96,0.15); }
.submit-btn { width: 100%; padding: 14px; margin-top: 20px; background: #667eea; border: none; border-radius: 12px; color: white; font-size: 16px; cursor: pointer; font-weight: 600; }
.submit-btn:focus-visible { outline: 2px solid #fff; outline-offset: 2px; }
.submit-btn:disabled { opacity: 0.4; cursor: not-allowed; }
.skip-link { position: absolute; top: -40px; left: 0; background: #e94560; color: white; padding: 8px 16px; z-index: 100; transition: top 0.2s; }
.skip-link:focus { top: 0; }
.result { text-align: center; color: #4caf50; font-size: 18px; margin-top: 15px; display: none; }
.result.show { display: block; }
.result.error { color: #e94560; }
</style>
</head>
<body>
<a href="#quiz-content" class="skip-link">Langsung ke konten quiz</a>
<div class="container" id="quiz-content" role="main">
<h1>♿ Accessible Quiz</h1>
<p class="progress-text" id="progressText" aria-live="polite">Soal 1 dari 3</p>
<div class="question-text" id="questionText" tabindex="-1">Apa ibu kota Indonesia?</div>
<div class="options" id="optionsContainer" role="radiogroup" aria-label="Pilihan jawaban"></div>
<button class="submit-btn" id="submitBtn" onclick="submitAnswer()" disabled>Submit Jawaban</button>
<div class="result" id="result" role="alert"></div>
</div>
<script>
const questions = [
{ q: 'Apa ibu kota Indonesia?', o: ['Jakarta', 'Bandung', 'Surabaya', 'Yogyakarta'], c: 0 },
{ q: 'Siapa presiden pertama RI?', o: ['Soeharto', 'Soekarno', 'Habibie', 'Megawati'], c: 1 },
{ q: 'CSS singkatan dari?', o: ['Cascading Style Sheets', 'Creative System', 'Computer Sheets', 'Colorful Style'], c: 0 }
];
let current = 0, score = 0, answered = false;

function render() {
const q = questions[current];
answered = false;
document.getElementById('progressText').textContent = `Soal ${current + 1} dari ${questions.length}`;
document.getElementById('questionText').textContent = q.q;
document.getElementById('result').classList.remove('show');
document.getElementById('submitBtn').disabled = true;
const container = document.getElementById('optionsContainer');
container.innerHTML = q.o.map((opt, i) => `
<label class="option" tabindex="0">
  <input type="radio" name="answer" value="${i}" onchange="enableSubmit()">
  <span>${opt}</span>
</label>`).join('');
document.getElementById('questionText').focus();
}

function enableSubmit() {
document.getElementById('submitBtn').disabled = false;
}

function submitAnswer() {
const selected = document.querySelector('input[name="answer"]:checked');
const result = document.getElementById('result');
if (!selected) {
result.textContent = 'Silakan pilih jawaban terlebih dahulu.';
result.className = 'result show error';
return;
}
if (answered) return;
answered = true;

const q = questions[current];
const idx = parseInt(selected.value);
document.querySelectorAll('.option').forEach((el, i) => {
if (i === q.c) el.classList.add('correct');
if (i === idx && idx !== q.c) el.classList.add('wrong');
});
if (idx === q.c) { score++; result.textContent = '✅ Benar!'; result.className = 'result show'; }
else { result.textContent = `❌ Salah. Jawaban: ${q.o[q.c]}`; result.className = 'result show error'; }
document.getElementById('submitBtn').disabled = true;

setTimeout(() => {
current++;
if (current < questions.length) render();
else {
document.querySelector('.container').innerHTML = `<h1 style="text-align:center;color:#e94560" tabindex="-1">🎉 Selesai!</h1><p style="text-align:center;color:#fff;font-size:24px;margin:20px" aria-live="assertive">Skor akhir: ${score}/${questions.length}</p>`;
}
}, 2000);
}

document.addEventListener('keydown', function(e) {
if (e.key === 'Enter' && !document.getElementById('submitBtn').disabled) submitAnswer();
});

render();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Navigasi dengan Tab, pilih dengan arrow keys/Enter. Skip link untuk screen reader. Focus outline untuk aksesibilitas keyboard.
