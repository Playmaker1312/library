# 230. Mengimplementasikan Rendering Todo List dari Data Array ke DOM

## Definisi & Target
Membuat fungsi render yang mengambil data dari array todos dan menampilkannya ke DOM sebagai elemen HTML yang terstruktur. Setiap perubahan pada array harus direfleksikan ke tampilan.

## Analogi Alur
Rendering seperti mencetak foto dari roll film (array) ke kertas foto (DOM). Setiap kali ada foto baru atau diedit, Anda mencetak ulang seluruh album agar konsisten.

## Poin-Poin Penting
- Fungsi render dipanggil setiap kali data berubah
- Gunakan map() untuk mengubah array menjadi string HTML
- InnerHTML untuk memasukkan ke DOM (atau createElement untuk performa)
- Setiap todo item harus memiliki data-id attribute untuk referensi
- Tampilkan teks, status, dan timestamp
- Handle empty state ketika array kosong
- Animasi transisi untuk item baru

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Rendering Todo List</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; background: linear-gradient(to right, #24243e, #302b63, #0f0c29); min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: rgba(255,255,255,0.05); backdrop-filter: blur(10px); border-radius: 20px; padding: 30px; width: 100%; max-width: 550px; border: 1px solid rgba(255,255,255,0.1); }
h1 { text-align: center; color: #fff; margin-bottom: 5px; font-size: 24px; }
.subtitle { text-align: center; color: #888; font-size: 13px; margin-bottom: 20px; }
.input-group { display: flex; gap: 10px; margin-bottom: 20px; }
.input-group input { flex: 1; padding: 14px 18px; border: 2px solid rgba(255,255,255,0.1); border-radius: 12px; font-size: 15px; background: rgba(255,255,255,0.05); color: #fff; outline: none; }
.input-group input:focus { border-color: #667eea; }
.input-group input::placeholder { color: #666; }
.input-group button { background: linear-gradient(135deg, #667eea, #764ba2); color: white; border: none; padding: 14px 24px; border-radius: 12px; font-size: 15px; cursor: pointer; font-weight: 600; }
.todo-item { background: rgba(255,255,255,0.05); border: 1px solid rgba(255,255,255,0.1); padding: 14px 18px; border-radius: 12px; margin-bottom: 10px; display: flex; align-items: center; gap: 12px; transition: all 0.3s; }
.todo-item:hover { background: rgba(255,255,255,0.08); }
.todo-check { width: 22px; height: 22px; border: 2px solid #667eea; border-radius: 50%; cursor: pointer; display: flex; align-items: center; justify-content: center; color: white; font-size: 12px; transition: all 0.3s; }
.todo-check.done { background: #4caf50; border-color: #4caf50; }
.todo-text { flex: 1; color: #eee; font-size: 15px; }
.todo-text.done { text-decoration: line-through; color: #666; }
.todo-time { font-size: 11px; color: #555; }
.empty-state { text-align: center; padding: 40px 20px; color: #555; }
.empty-icon { font-size: 48px; margin-bottom: 10px; }
</style>
</head>
<body>
<div class="container">
<h1>Todo List</h1>
<p class="subtitle">Rendering dari Array ke DOM</p>
<div class="input-group">
<input type="text" id="todoInput" placeholder="Tambah tugas..." autofocus>
<button onclick="addTodo()">Tambah</button>
</div>
<div id="todoList"></div>
</div>
<script>
let todos = [
{ id: 1, text: 'Belajar JavaScript', completed: false, createdAt: '28/05/2026' },
{ id: 2, text: 'Membuat Project', completed: true, createdAt: '28/05/2026' },
{ id: 3, text: 'Olahraga', completed: false, createdAt: '28/05/2026' }
];

function addTodo() {
const input = document.getElementById('todoInput');
const text = input.value.trim();
if (!text) return;
todos.push({ id: Date.now(), text, completed: false, createdAt: new Date().toLocaleDateString('id-ID') });
input.value = '';
renderTodos();
}

function renderTodos() {
const list = document.getElementById('todoList');
if (todos.length === 0) {
list.innerHTML = '<div class="empty-state"><div class="empty-icon">📋</div><p>Belum ada tugas</p></div>';
return;
}
list.innerHTML = todos.map(t => `
<div class="todo-item" data-id="${t.id}">
  <div class="todo-check ${t.completed ? 'done' : ''}" onclick="toggleTodo(${t.id})">${t.completed ? '✓' : ''}</div>
  <span class="todo-text ${t.completed ? 'done' : ''}">${t.text}</span>
  <span class="todo-time">${t.createdAt}</span>
</div>
`).join('');
}

function toggleTodo(id) {
const todo = todos.find(t => t.id === id);
if (todo) { todo.completed = !todo.completed; renderTodos(); }
}

renderTodos();
document.getElementById('todoInput').addEventListener('keypress', e => { if (e.key === 'Enter') addTodo(); });
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML dan buka di browser. Lihat bagaimana data dari array langsung dirender menjadi elemen visual. Setiap perubahan data akan memicu render ulang.
