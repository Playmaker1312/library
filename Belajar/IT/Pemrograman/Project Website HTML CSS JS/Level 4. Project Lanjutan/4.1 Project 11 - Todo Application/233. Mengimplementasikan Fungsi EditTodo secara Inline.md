# 233. Mengimplementasikan Fungsi EditTodo secara Inline

## Definisi & Target
Membuat fungsi EditTodo yang memungkinkan user mengubah teks todo langsung di tempat (inline editing) tanpa modal atau halaman terpisah.

## Analogi Alur
Edit inline seperti menggunakan sticky note yang bisa ditimpa tulisannya: Anda klik pada teks, teks berubah jadi kolom input, Anda ketik ulang, lalu klik simpan atau tekan Enter.

## Poin-Poin Penting
- Saat diklik (atau tombol edit), teks berubah menjadi input field
- Input field auto-focus dan memuat teks lama
- Tekan Enter atau klik di luar (blur) untuk menyimpan
- Tekan Escape untuk membatalkan perubahan
- Update array todos dengan teks baru
- Render ulang untuk menampilkan teks yang diedit
- Animasi transisi antara mode tampil dan mode edit

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Edit Todo Inline</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: linear-gradient(135deg, #0c0c1d, #1a1a3e); min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: rgba(255,255,255,0.03); backdrop-filter: blur(20px); border: 1px solid rgba(255,255,255,0.08); border-radius: 20px; padding: 30px; width: 100%; max-width: 520px; }
h1 { text-align: center; color: #fff; margin-bottom: 20px; font-size: 22px; }
.todo-item { background: rgba(255,255,255,0.05); border: 1px solid rgba(255,255,255,0.08); padding: 12px 16px; border-radius: 12px; margin-bottom: 10px; display: flex; align-items: center; gap: 10px; }
.todo-text { flex: 1; color: #ddd; font-size: 15px; cursor: text; padding: 4px 8px; border-radius: 6px; transition: background 0.2s; }
.todo-text:hover { background: rgba(255,255,255,0.05); }
.todo-text.editing { background: transparent; }
.edit-input { flex: 1; padding: 4px 8px; font-size: 15px; border: 1px solid #667eea; border-radius: 6px; background: rgba(255,255,255,0.1); color: #fff; outline: none; }
.btn-edit, .btn-save { background: none; border: none; color: #667eea; cursor: pointer; font-size: 16px; padding: 4px 8px; border-radius: 6px; transition: background 0.2s; }
.btn-edit:hover, .btn-save:hover { background: rgba(102,126,234,0.2); }
.hint { text-align: center; color: #555; font-size: 12px; margin-top: 15px; }
</style>
</head>
<body>
<div class="container">
<h1>✏️ Edit Inline</h1>
<div id="todoList"></div>
<p class="hint">Klik ikon ✏️ untuk edit • Enter simpan • Escape batal</p>
</div>
<script>
let todos = [
{ id: 1, text: 'Belajar edit inline' },
{ id: 2, text: 'Implementasi Enter dan Escape' },
{ id: 3, text: 'Testing fitur edit' }
];
let editingId = null;

function startEdit(id) {
editingId = id;
renderTodos();
const input = document.querySelector('.edit-input');
if (input) { input.focus(); input.select(); }
}

function saveEdit(id, newText) {
const trimmed = newText.trim();
if (trimmed) {
const todo = todos.find(t => t.id === id);
if (todo) todo.text = trimmed;
}
editingId = null;
renderTodos();
}

function cancelEdit() {
editingId = null;
renderTodos();
}

function renderTodos() {
const list = document.getElementById('todoList');
list.innerHTML = todos.map(t => {
if (t.id === editingId) {
return `<div class="todo-item">
  <input class="edit-input" value="${t.text}" id="editInput"
    onkeydown="if(event.key==='Enter')saveEdit(${t.id},this.value);if(event.key==='Escape')cancelEdit()"
    onblur="saveEdit(${t.id},this.value)">
</div>`;
}
return `<div class="todo-item">
  <span class="todo-text">${t.text}</span>
  <button class="btn-edit" onclick="startEdit(${t.id})">✏️</button>
</div>`;
}).join('');
}
renderTodos();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Klik ikon pensil untuk mengedit todo. Tekan Enter untuk simpan, Escape untuk batal. Edit terjadi inline tanpa modal.
