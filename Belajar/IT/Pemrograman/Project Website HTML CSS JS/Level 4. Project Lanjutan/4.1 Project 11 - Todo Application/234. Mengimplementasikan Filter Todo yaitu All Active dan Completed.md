# 234. Mengimplementasikan Filter Todo yaitu All, Active, dan Completed

## Definisi & Target
Membuat sistem filter yang memungkinkan user menampilkan semua todo (All), hanya yang belum selesai (Active), atau hanya yang sudah selesai (Completed).

## Analogi Alur
Filter seperti memakai kacamata berwarna: kacamata bening (All) melihat semua, kacamata biru (Active) hanya melihat todo aktif, kacamata merah (Completed) hanya melihat todo selesai.

## Poin-Poin Penting
- Gunakan variabel state untuk menyimpan filter aktif ('all', 'active', 'completed')
- Fungsi getFilteredTodos() mengembalikan todos sesuai filter
- Tampilkan tombol filter dengan status aktif (active class)
- Filter tidak menghapus data, hanya mengubah tampilan
- Jumlah todo yang ditampilkan berubah sesuai filter
- Counter tetap menghitung total semua todo
- Animasi transisi saat filter berubah

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Filter Todo</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #16213e; border-radius: 16px; padding: 30px; width: 100%; max-width: 550px; }
h1 { text-align: center; color: #e94560; margin-bottom: 20px; font-size: 22px; }
.filters { display: flex; gap: 8px; margin-bottom: 20px; flex-wrap: wrap; }
.filter-btn { padding: 8px 20px; border: 2px solid #0f3460; border-radius: 8px; background: transparent; color: #888; cursor: pointer; font-size: 14px; transition: all 0.3s; }
.filter-btn:hover { border-color: #e94560; color: #e94560; }
.filter-btn.active { background: #e94560; border-color: #e94560; color: white; }
.todo-item { background: #0f3460; padding: 12px 16px; border-radius: 10px; margin-bottom: 8px; display: flex; align-items: center; gap: 10px; }
.todo-text { flex: 1; color: #eee; font-size: 15px; }
.todo-text.done { text-decoration: line-through; color: #666; }
.counter { text-align: center; color: #666; font-size: 13px; margin-top: 15px; }
.empty-filter { text-align: center; color: #555; padding: 30px; }
</style>
</head>
<body>
<div class="container">
<h1>🔍 Filter Todo</h1>
<div class="filters">
<button class="filter-btn active" onclick="setFilter('all')" id="f-all">All</button>
<button class="filter-btn" onclick="setFilter('active')" id="f-active">Active</button>
<button class="filter-btn" onclick="setFilter('completed')" id="f-completed">Completed</button>
</div>
<div id="todoList"></div>
<div class="counter" id="counter">Menampilkan 0 todo</div>
</div>
<script>
let todos = [
{ id: 1, text: 'Belajar Filter', completed: false },
{ id: 2, text: 'Membuat UI Filter', completed: true },
{ id: 3, text: 'Testing All Filter', completed: false },
{ id: 4, text: 'Active Filter', completed: false },
{ id: 5, text: 'Completed Filter', completed: true },
{ id: 6, text: 'Integrasi dengan Render', completed: true }
];
let currentFilter = 'all';

function setFilter(filter) {
currentFilter = filter;
document.querySelectorAll('.filter-btn').forEach(b => b.classList.remove('active'));
document.getElementById('f-' + filter).classList.add('active');
renderTodos();
}

function toggleTodo(id) {
const todo = todos.find(t => t.id === id);
if (todo) { todo.completed = !todo.completed; renderTodos(); }
}

function renderTodos() {
const filtered = currentFilter === 'all' ? todos :
currentFilter === 'active' ? todos.filter(t => !t.completed) :
todos.filter(t => t.completed);
const list = document.getElementById('todoList');
document.getElementById('counter').textContent = `Menampilkan ${filtered.length} dari ${todos.length} todo`;
if (filtered.length === 0) {
list.innerHTML = `<div class="empty-filter">Tidak ada todo ${currentFilter === 'active' ? 'aktif' : 'selesai'}</div>`;
return;
}
list.innerHTML = filtered.map(t => `
<div class="todo-item" onclick="toggleTodo(${t.id})" style="cursor:pointer">
  <span class="todo-text ${t.completed ? 'done' : ''}">${t.completed ? '✓ ' : '○ '}${t.text}</span>
</div>
`).join('');
}
renderTodos();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Klik tombol filter (All/Active/Completed) untuk menyaring tampilan todo. Data tidak hilang, hanya difilter saat render.
