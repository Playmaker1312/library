# 237. Mengimplementasikan Due Date pada Todo dengan Date Picker

## Definisi & Target
Menambahkan input tanggal jatuh tempo (due date) pada setiap todo menggunakan HTML date picker, sehingga user bisa menetapkan deadline untuk setiap tugas.

## Analogi Alur
Due date seperti tenggat waktu di kalender: setiap tugas diberi stempel tanggal deadline. Jika tanggal sudah lewat, tugas dianggap overdue dan mendapat peringatan visual.

## Poin-Poin Penting
- Gunakan input type="date" untuk date picker native
- Simpan dueDate sebagai properti di object todo
- Tampilkan tanggal di samping teks todo
- Beri warna berbeda untuk todo yang overdue (lewat deadline)
- Format tanggal ke locale Indonesia
- Todo tanpa due date tetap valid
- Urutkan todo berdasarkan due date (opsional)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Todo dengan Due Date</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #16213e; border-radius: 16px; padding: 30px; width: 100%; max-width: 550px; }
h1 { text-align: center; color: #e94560; margin-bottom: 20px; font-size: 22px; }
.input-group { display: flex; gap: 10px; margin-bottom: 15px; flex-wrap: wrap; }
.input-group input[type="text"] { flex: 1; min-width: 150px; padding: 12px 16px; border: 2px solid #0f3460; border-radius: 10px; font-size: 15px; background: #0f3460; color: #fff; outline: none; }
.input-group input[type="date"] { padding: 12px 16px; border: 2px solid #0f3460; border-radius: 10px; font-size: 14px; background: #0f3460; color: #fff; outline: none; }
.input-group button { padding: 12px 24px; background: #e94560; color: white; border: none; border-radius: 10px; font-size: 15px; cursor: pointer; font-weight: 600; }
.todo-item { background: #0f3460; padding: 14px 18px; border-radius: 12px; margin-bottom: 10px; display: flex; align-items: center; gap: 12px; }
.todo-text { flex: 1; color: #eee; font-size: 15px; }
.todo-text.done { text-decoration: line-through; color: #666; }
.due-date { font-size: 12px; padding: 4px 10px; border-radius: 6px; }
.due-date.normal { background: #1a3a6e; color: #667eea; }
.due-date.overdue { background: #3e1a1a; color: #e94560; }
.due-date.done-date { background: #1a3e1a; color: #4caf50; }
.empty-state { text-align: center; color: #555; padding: 30px; }
</style>
</head>
<body>
<div class="container">
<h1>📅 Due Date Todo</h1>
<div class="input-group">
<input type="text" id="todoInput" placeholder="Nama tugas...">
<input type="date" id="dateInput">
<button onclick="addTodo()">Tambah</button>
</div>
<div id="todoList"></div>
</div>
<script>
let todos = [];

function addTodo() {
const text = document.getElementById('todoInput').value.trim();
if (!text) return;
const dueDate = document.getElementById('dateInput').value;
todos.unshift({
id: Date.now(),
text,
completed: false,
dueDate
});
document.getElementById('todoInput').value = '';
document.getElementById('dateInput').value = '';
renderTodos();
}

function toggleTodo(id) {
const todo = todos.find(t => t.id === id);
if (todo) { todo.completed = !todo.completed; renderTodos(); }
}

function renderTodos() {
const list = document.getElementById('todoList');
if (todos.length === 0) { list.innerHTML = '<div class="empty-state">Belum ada tugas</div>'; return; }
const today = new Date().toISOString().split('T')[0];
list.innerHTML = todos.map(t => {
let dateClass = 'normal';
if (t.dueDate && !t.completed) {
dateClass = t.dueDate < today ? 'overdue' : 'normal';
}
if (t.completed) dateClass = 'done-date';
return `<div class="todo-item" onclick="toggleTodo(${t.id})" style="cursor:pointer">
  <span class="todo-text ${t.completed ? 'done' : ''}">${t.completed ? '✓ ' : '○ '}${t.text}</span>
  ${t.dueDate ? `<span class="due-date ${dateClass}">${new Date(t.dueDate).toLocaleDateString('id-ID')}</span>` : ''}
</div>`;
}).join('');
}
renderTodos();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Tambah todo dengan due date menggunakan date picker. Todo yang melewati deadline akan berwarna merah (overdue).
