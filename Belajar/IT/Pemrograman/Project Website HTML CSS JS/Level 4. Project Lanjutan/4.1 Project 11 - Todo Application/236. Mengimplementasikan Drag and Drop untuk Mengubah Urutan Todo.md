# 236. Mengimplementasikan Drag and Drop untuk Mengubah Urutan Todo

## Definisi & Target
Membuat fitur drag and drop yang memungkinkan user mengubah urutan todo dengan cara menyeret (drag) item ke posisi baru.

## Analogi Alur
Drag and drop seperti memindahkan kartu indeks di atas meja: Anda mengambil satu kartu (drag) dan meletakkannya di posisi berbeda (drop). Urutan kartu berubah sesuai keinginan.

## Poin-Poin Penting
- Gunakan HTML5 Drag and Drop API (dragstart, dragover, drop, dragend)
- Atribut draggable="true" pada todo item
- Simpan id item yang di-drag di dataTransfer
- Tentukan posisi drop berdasarkan posisi mouse relatif terhadap item target
- Update array todos dengan method splice()
- Tampilkan visual indicator (garis atau highlight) saat drag
- Animasi transisi untuk perubahan urutan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Drag and Drop Todo</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: linear-gradient(45deg, #0c0c1d, #1a1a3e, #0c0c1d); min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: rgba(255,255,255,0.02); backdrop-filter: blur(20px); border: 1px solid rgba(255,255,255,0.06); border-radius: 20px; padding: 30px; width: 100%; max-width: 520px; }
h1 { text-align: center; color: #fff; margin-bottom: 5px; font-size: 22px; }
.hint { text-align: center; color: #555; font-size: 12px; margin-bottom: 20px; }
.todo-item { background: rgba(255,255,255,0.04); border: 1px solid rgba(255,255,255,0.08); padding: 14px 18px; border-radius: 12px; margin-bottom: 8px; display: flex; align-items: center; gap: 12px; cursor: grab; transition: all 0.3s; }
.todo-item:hover { background: rgba(255,255,255,0.08); border-color: rgba(102,126,234,0.3); }
.todo-item.dragging { opacity: 0.3; }
.todo-item.drag-over { border-color: #667eea; transform: scale(1.02); }
.drag-handle { color: #555; font-size: 18px; cursor: grab; user-select: none; }
.todo-text { flex: 1; color: #ddd; font-size: 15px; }
.todo-order { color: #555; font-size: 12px; min-width: 24px; }
</style>
</head>
<body>
<div class="container">
<h1>↕️ Drag & Drop</h1>
<p class="hint">Seret item untuk mengubah urutan</p>
<div id="todoList"></div>
</div>
<script>
let todos = [
{ id: 1, text: 'Belajar Drag & Drop API' },
{ id: 2, text: 'Implementasi HTML5 DnD' },
{ id: 3, text: 'Update Array dengan Splice' },
{ id: 4, text: 'Visual Indicator saat Drag' },
{ id: 5, text: 'Testing Urutan Baru' }
];
let draggedId = null;

function handleDragStart(e) {
draggedId = Number(e.target.dataset.id);
e.target.classList.add('dragging');
e.dataTransfer.effectAllowed = 'move';
}

function handleDragOver(e) {
e.preventDefault();
e.dataTransfer.dropEffect = 'move';
const item = e.target.closest('.todo-item');
if (item) item.classList.add('drag-over');
}

function handleDragLeave(e) {
const item = e.target.closest('.todo-item');
if (item) item.classList.remove('drag-over');
}

function handleDrop(e) {
e.preventDefault();
const targetItem = e.target.closest('.todo-item');
if (!targetItem) return;
targetItem.classList.remove('drag-over');
const targetId = Number(targetItem.dataset.id);
if (draggedId === targetId) return;

const fromIdx = todos.findIndex(t => t.id === draggedId);
const toIdx = todos.findIndex(t => t.id === targetId);
const [moved] = todos.splice(fromIdx, 1);
todos.splice(toIdx, 0, moved);
renderTodos();
}

function handleDragEnd(e) {
e.target.classList.remove('dragging');
document.querySelectorAll('.todo-item').forEach(el => el.classList.remove('drag-over'));
}

function renderTodos() {
const list = document.getElementById('todoList');
list.innerHTML = todos.map((t, i) => `
<div class="todo-item" draggable="true" data-id="${t.id}"
  ondragstart="handleDragStart(event)" ondragover="handleDragOver(event)"
  ondragleave="handleDragLeave(event)" ondrop="handleDrop(event)" ondragend="handleDragEnd(event)">
  <span class="drag-handle">⠿</span>
  <span class="todo-order">#${i + 1}</span>
  <span class="todo-text">${t.text}</span>
</div>
`).join('');
}
renderTodos();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Seret (drag) item todo menggunakan handle ⠿ dan lepaskan di posisi baru. Urutan akan berubah sesuai posisi drop.
