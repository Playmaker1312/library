# 239. Mengimplementasikan Kategori atau Label pada Todo

## Definisi & Target
Menambahkan fitur kategori/label pada todo sehingga user bisa mengelompokkan tugas berdasarkan jenis seperti Pekerjaan, Pribadi, Belajar, dll.

## Analogi Alur
Kategori seperti folder atau map arsip: Anda memasukkan surat ke dalam folder yang sesuai (Pekerjaan, Pribadi, Belajar). Surat dalam folder yang sama mudah ditemukan bersama.

## Poin-Poin Penting
- Setiap todo memiliki properti category (string)
- Beberapa kategori default: Personal, Work, Learning, Health
- Tampilkan label kategori dengan warna berbeda
- User bisa menambah kategori kustom
- Filter todo berdasarkan kategori
- Kombinasikan dengan filter status dan search

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Kategori Todo</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: linear-gradient(135deg, #141e30, #243b55); min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: rgba(255,255,255,0.03); backdrop-filter: blur(10px); border: 1px solid rgba(255,255,255,0.08); border-radius: 16px; padding: 30px; width: 100%; max-width: 560px; }
h1 { text-align: center; color: #fff; margin-bottom: 20px; font-size: 22px; }
.input-group { display: flex; gap: 10px; margin-bottom: 15px; flex-wrap: wrap; }
.input-group input { flex: 1; min-width: 120px; padding: 12px 16px; border: 1px solid rgba(255,255,255,0.1); border-radius: 10px; font-size: 15px; background: rgba(255,255,255,0.05); color: #fff; outline: none; }
.input-group select, .input-group button { padding: 12px 16px; border: 1px solid rgba(255,255,255,0.1); border-radius: 10px; background: rgba(255,255,255,0.05); color: #fff; font-size: 14px; outline: none; }
.input-group button { background: #667eea; border-color: #667eea; cursor: pointer; font-weight: 600; }
.category-filters { display: flex; gap: 8px; margin-bottom: 20px; flex-wrap: wrap; }
.cat-btn { padding: 6px 16px; border: 1px solid rgba(255,255,255,0.1); border-radius: 20px; background: transparent; color: #aaa; cursor: pointer; font-size: 13px; transition: all 0.3s; }
.cat-btn:hover { border-color: #667eea; color: #667eea; }
.cat-btn.active { background: #667eea; color: white; border-color: #667eea; }
.todo-item { background: rgba(255,255,255,0.03); border: 1px solid rgba(255,255,255,0.06); padding: 14px 18px; border-radius: 12px; margin-bottom: 8px; display: flex; align-items: center; gap: 12px; }
.todo-text { flex: 1; color: #ddd; font-size: 15px; }
.category-label { font-size: 11px; padding: 3px 12px; border-radius: 20px; font-weight: 500; }
.cat-personal { background: #e94560; color: white; }
.cat-work { background: #667eea; color: white; }
.cat-learning { background: #4caf50; color: white; }
.cat-health { background: #f39c12; color: #1a1a1a; }
.empty-state { text-align: center; color: #555; padding: 30px; }
</style>
</head>
<body>
<div class="container">
<h1>📂 Kategori Todo</h1>
<div class="input-group">
<input type="text" id="todoInput" placeholder="Tugas...">
<select id="catSelect">
<option value="Personal">Personal</option>
<option value="Work">Work</option>
<option value="Learning">Learning</option>
<option value="Health">Health</option>
</select>
<button onclick="addTodo()">Tambah</button>
</div>
<div class="category-filters" id="catFilters">
<button class="cat-btn active" onclick="filterCat('All')">All</button>
</div>
<div id="todoList"></div>
</div>
<script>
let todos = [
{ id: 1, text: 'Beli bahan makanan', category: 'Personal' },
{ id: 2, text: 'Selesaikan laporan', category: 'Work' },
{ id: 3, text: 'Belajar JavaScript Array', category: 'Learning' },
{ id: 4, text: 'Jogging pagi', category: 'Health' }
];
let currentCat = 'All';

function addTodo() {
const text = document.getElementById('todoInput').value.trim();
if (!text) return;
const cat = document.getElementById('catSelect').value;
todos.unshift({ id: Date.now(), text, category: cat });
document.getElementById('todoInput').value = '';
updateCatFilters();
renderTodos();
}

function filterCat(cat) {
currentCat = cat;
document.querySelectorAll('.cat-btn').forEach(b => b.classList.remove('active'));
document.querySelectorAll('.cat-btn').forEach(b => { if (b.textContent === cat) b.classList.add('active'); });
renderTodos();
}

function updateCatFilters() {
const cats = [...new Set(todos.map(t => t.category))];
const container = document.getElementById('catFilters');
container.innerHTML = `<button class="cat-btn ${currentCat === 'All' ? 'active' : ''}" onclick="filterCat('All')">All</button>` +
cats.map(c => `<button class="cat-btn ${currentCat === c ? 'active' : ''}" onclick="filterCat('${c}')">${c}</button>`).join('');
}

function renderTodos() {
const list = document.getElementById('todoList');
const filtered = currentCat === 'All' ? todos : todos.filter(t => t.category === currentCat);
if (filtered.length === 0) { list.innerHTML = '<div class="empty-state">Tidak ada todo</div>'; return; }
const colorMap = { Personal: 'cat-personal', Work: 'cat-work', Learning: 'cat-learning', Health: 'cat-health' };
list.innerHTML = filtered.map(t => `
<div class="todo-item">
  <span class="todo-text">${t.text}</span>
  <span class="category-label ${colorMap[t.category] || 'cat-personal'}">${t.category}</span>
</div>
`).join('');
}
updateCatFilters();
renderTodos();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Pilih kategori dari dropdown saat menambah todo. Gunakan filter kategori untuk menampilkan todo berdasarkan kategori tertentu.
