# 241. Mengimplementasikan Fitur Clear Completed untuk Menghapus Semua Todo Selesai

## Definisi & Target
Membuat tombol "Clear Completed" yang menghapus semua todo yang sudah ditandai selesai (completed) sekaligus dari array dan LocalStorage.

## Analogi Alur
Clear Completed seperti membersihkan meja kerja: Anda mengambil semua dokumen yang sudah selesai diproses dan memasukkannya ke tempat sampah sekaligus, bukan satu per satu.

## Poin-Poin Penting
- Tombol Clear Completed hanya muncul jika ada todo completed
- Gunakan filter() untuk menyisakan todo yang belum selesai
- Tampilkan jumlah todo yang akan dihapus
- Animasi fade-out untuk item yang dihapus
- Konfirmasi opsional sebelum menghapus
- Update LocalStorage setelah clear
- Render ulang tampilan setelah penghapusan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Clear Completed</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1a3e; border-radius: 16px; padding: 30px; width: 100%; max-width: 520px; }
h1 { text-align: center; color: #667eea; margin-bottom: 20px; font-size: 22px; }
.todo-item { background: #12123a; border: 1px solid #2a2a5e; padding: 14px 18px; border-radius: 12px; margin-bottom: 8px; display: flex; align-items: center; gap: 12px; cursor: pointer; transition: all 0.3s; }
.todo-item:hover { border-color: #667eea; }
.todo-text { flex: 1; color: #ddd; font-size: 15px; }
.todo-text.done { text-decoration: line-through; color: #555; }
.check-circle { width: 22px; height: 22px; border: 2px solid #555; border-radius: 50%; display: flex; align-items: center; justify-content: center; font-size: 12px; transition: all 0.3s; }
.check-circle.done { background: #4caf50; border-color: #4caf50; color: white; }
.action-bar { display: flex; justify-content: space-between; align-items: center; margin-top: 20px; padding-top: 15px; border-top: 1px solid #2a2a5e; }
.counter { color: #888; font-size: 14px; }
.clear-btn { padding: 10px 20px; border: none; border-radius: 8px; background: #e94560; color: white; font-size: 14px; cursor: pointer; opacity: 0.5; transition: all 0.3s; pointer-events: none; }
.clear-btn.active { opacity: 1; pointer-events: auto; }
.clear-btn:hover { background: #d63851; }
.fade-out { animation: fadeOut 0.3s ease forwards; }
@keyframes fadeOut { to { opacity: 0; transform: translateY(-10px); } }
.empty-state { text-align: center; color: #555; padding: 30px; }
</style>
</head>
<body>
<div class="container">
<h1>🧹 Clear Completed</h1>
<div id="todoList"></div>
<div class="action-bar">
<span class="counter" id="counter">0 tugas tersisa</span>
<button class="clear-btn" id="clearBtn" onclick="clearCompleted()">Clear Completed (0)</button>
</div>
</div>
<script>
let todos = [
{ id: 1, text: 'Belajar JavaScript', completed: true },
{ id: 2, text: 'Membuat Todo App', completed: false },
{ id: 3, text: 'Belajar React', completed: true },
{ id: 4, text: 'Olahraga', completed: false },
{ id: 5, text: 'Membaca Buku', completed: false }
];

function toggleTodo(id) {
const todo = todos.find(t => t.id === id);
if (todo) { todo.completed = !todo.completed; renderTodos(); }
}

function clearCompleted() {
const completedCount = todos.filter(t => t.completed).length;
if (completedCount === 0) return;
const items = document.querySelectorAll('.todo-item');
items.forEach(el => {
const id = Number(el.dataset.id);
const todo = todos.find(t => t.id === id);
if (todo && todo.completed) el.classList.add('fade-out');
});
setTimeout(() => {
todos = todos.filter(t => !t.completed);
renderTodos();
}, 300);
}

function renderTodos() {
const list = document.getElementById('todoList');
const remaining = todos.filter(t => !t.completed).length;
const completed = todos.filter(t => t.completed).length;
document.getElementById('counter').textContent = `${remaining} tugas tersisa`;
const clearBtn = document.getElementById('clearBtn');
clearBtn.textContent = `Clear Completed (${completed})`;
clearBtn.classList.toggle('active', completed > 0);
if (todos.length === 0) { list.innerHTML = '<div class="empty-state">Semua tugas selesai! 🎉</div>'; return; }
list.innerHTML = todos.map(t => `
<div class="todo-item" data-id="${t.id}" onclick="toggleTodo(${t.id})">
  <div class="check-circle ${t.completed ? 'done' : ''}">${t.completed ? '✓' : ''}</div>
  <span class="todo-text ${t.completed ? 'done' : ''}">${t.text}</span>
</div>
`).join('');
}
renderTodos();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Tandai todo selesai dengan mengkliknya. Klik "Clear Completed" untuk menghapus semua todo yang sudah selesai sekaligus dengan animasi.
