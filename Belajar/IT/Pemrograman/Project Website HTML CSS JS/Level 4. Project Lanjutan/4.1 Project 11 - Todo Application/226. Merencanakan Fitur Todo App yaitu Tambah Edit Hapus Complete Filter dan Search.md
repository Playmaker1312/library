# 226. Merencanakan Fitur Todo App yaitu Tambah, Edit, Hapus, Complete, Filter, dan Search

## Definisi & Target
Perencanaan fitur adalah tahap awal pengembangan Todo App untuk mendefinisikan semua fungsionalitas yang akan dibangun. Targetnya adalah aplikasi pengelola tugas dengan fitur CRUD (Create, Read, Update, Delete), penyelesaian tugas, penyaringan, dan pencarian.

## Analogi Alur
Todo App seperti papan tugas fisik: Anda menulis task di sticky note (Tambah), menempel di papan (Render), mencoret jika selesai (Complete), membuang jika tidak perlu (Hapus), mengganti isi (Edit), memfilter berdasarkan status, dan mencari task tertentu.

## Poin-Poin Penting
- Fitur Tambah untuk memasukkan todo baru ke dalam daftar
- Fitur Edit untuk mengubah teks todo yang sudah ada
- Fitur Hapus untuk menghapus todo dari daftar
- Fitur Complete untuk menandai todo sebagai selesai
- Fitur Filter untuk menampilkan All, Active, atau Completed
- Fitur Search untuk mencari todo berdasarkan kata kunci
- Data disimpan dalam array of objects di JavaScript
