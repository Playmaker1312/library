# 228. Membangun UI Input untuk Menambahkan Todo Baru

## Definisi & Target
Membangun antarmuka pengguna (UI) berupa input field dan tombol untuk menambahkan todo baru. Fokus pada tampilan dan interaksi dasar sebelum menghubungkan ke logika data.

## Analogi Alur
UI Input seperti meja resepsionis: ada formulir (input field) untuk menulis pesan dan tombol kirim (submit button) untuk menyerahkan pesan ke sistem.

## Poin-Poin Penting
- Input field dengan placeholder yang jelas
- Tombol submit dengan ikon atau teks yang intuitif
- Styling yang konsisten dengan tema aplikasi
- Input harus dapat menerima teks dan merespon tombol Enter
- Form wrapping untuk aksesibilitas dan semantic HTML
- Validasi input tidak boleh kosong sebelum submit

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Todo Input UI</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: white; border-radius: 16px; padding: 30px; width: 100%; max-width: 500px; box-shadow: 0 20px 60px rgba(0,0,0,0.3); }
h1 { text-align: center; color: #333; margin-bottom: 20px; font-size: 22px; }
.input-group { display: flex; gap: 10px; }
.input-group input { flex: 1; padding: 12px 16px; border: 2px solid #e0e0e0; border-radius: 10px; font-size: 15px; outline: none; transition: border-color 0.3s; }
.input-group input:focus { border-color: #667eea; }
.input-group button { background: #667eea; color: white; border: none; padding: 12px 20px; border-radius: 10px; font-size: 15px; cursor: pointer; font-weight: 600; transition: background 0.3s, transform 0.1s; display: flex; align-items: center; gap: 5px; }
.input-group button:hover { background: #5a6fd6; }
.input-group button:active { transform: scale(0.95); }
.demo-list { margin-top: 20px; }
.demo-item { background: #f5f7ff; padding: 12px 16px; border-radius: 8px; margin-bottom: 8px; color: #666; font-size: 14px; display: flex; align-items: center; gap: 8px; }
.demo-item:before { content: '📝'; }
</style>
</head>
<body>
<div class="container">
<h1>Tambah Todo Baru</h1>
<div class="input-group">
<input type="text" id="todoInput" placeholder="Tulis tugas baru..." autofocus>
<button onclick="addTodo()">+ Tambah</button>
</div>
<div class="demo-list" id="demoList">
<div class="demo-item">Todo akan muncul di sini</div>
</div>
</div>
<script>
function addTodo() {
const input = document.getElementById('todoInput');
const text = input.value.trim();
if (!text) {
input.style.borderColor = '#ff4444';
setTimeout(() => input.style.borderColor = '#e0e0e0', 1000);
return;
}
const list = document.getElementById('demoList');
const item = document.createElement('div');
item.className = 'demo-item';
item.textContent = text;
list.appendChild(item);
input.value = '';
input.focus();
}
document.getElementById('todoInput').addEventListener('keypress', function(e) {
if (e.key === 'Enter') addTodo();
});
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai file HTML dan buka di browser. Ketik todo dan klik Tambah atau tekan Enter. Input akan divalidasi dan todo langsung ditambahkan ke daftar demo.
