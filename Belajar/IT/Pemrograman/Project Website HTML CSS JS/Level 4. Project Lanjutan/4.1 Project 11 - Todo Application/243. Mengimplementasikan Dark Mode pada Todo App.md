# 243. Mengimplementasikan Dark Mode pada Todo App

## Definisi & Target
Menambahkan fitur dark mode yang memungkinkan user beralih antara tema terang (light) dan gelap (dark) dengan satu klik tombol.

## Analogi Alur
Dark mode seperti mengganti wallpaper dan lampu ruangan: dengan satu saklar, seluruh ruangan berubah dari terang ke gelap atau sebaliknya. Semua elemen menyesuaikan diri.

## Poin-Poin Penting
- Gunakan CSS custom properties (variables) untuk warna
- Toggle class 'dark-mode' pada body atau root element
- Simpan preferensi tema ke LocalStorage
- Deteksi preferensi sistem dengan prefers-color-scheme
- Tombol toggle dengan ikon matahari/bulan
- Transisi halus saat berganti tema
- Semua komponen harus mendukung kedua tema

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Dark Mode Todo</title>
<style>
:root { --bg: #f5f5f5; --card: #ffffff; --text: #333; --text-secondary: #666; --border: #e0e0e0; --accent: #667eea; --todo-bg: #f8f9fa; --hover: #eee; --shadow: rgba(0,0,0,0.1); }
.dark-mode { --bg: #1a1a2e; --card: #16213e; --text: #eee; --text-secondary: #888; --border: #0f3460; --accent: #e94560; --todo-bg: #0f3460; --hover: #1a3a6e; --shadow: rgba(0,0,0,0.5); }
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: var(--bg); min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; transition: background 0.3s; }
.container { background: var(--card); border-radius: 16px; padding: 30px; width: 100%; max-width: 500px; box-shadow: 0 20px 60px var(--shadow); transition: all 0.3s; }
.header { display: flex; justify-content: space-between; align-items: center; margin-bottom: 20px; }
h1 { color: var(--text); font-size: 22px; }
.toggle-btn { background: none; border: 2px solid var(--border); border-radius: 50%; width: 44px; height: 44px; cursor: pointer; font-size: 20px; display: flex; align-items: center; justify-content: center; transition: all 0.3s; }
.toggle-btn:hover { border-color: var(--accent); }
.input-group { display: flex; gap: 10px; margin-bottom: 20px; }
.input-group input { flex: 1; padding: 12px 16px; border: 2px solid var(--border); border-radius: 10px; font-size: 15px; background: var(--todo-bg); color: var(--text); outline: none; }
.input-group button { padding: 12px 20px; background: var(--accent); color: white; border: none; border-radius: 10px; font-size: 15px; cursor: pointer; }
.todo-item { background: var(--todo-bg); padding: 12px 16px; border-radius: 10px; margin-bottom: 8px; display: flex; align-items: center; gap: 10px; cursor: pointer; transition: background 0.3s; }
.todo-item:hover { background: var(--hover); }
.todo-text { flex: 1; color: var(--text); font-size: 15px; }
.todo-text.done { text-decoration: line-through; color: var(--text-secondary); }
</style>
</head>
<body>
<div class="container">
<div class="header">
<h1>🌓 Dark Mode</h1>
<button class="toggle-btn" id="themeToggle" onclick="toggleTheme()">☀️</button>
</div>
<div class="input-group">
<input type="text" id="todoInput" placeholder="Tambah tugas...">
<button onclick="addTodo()">Tambah</button>
</div>
<div id="todoList"></div>
</div>
<script>
let todos = [
{ id: 1, text: 'Belajar CSS Variables', completed: false },
{ id: 2, text: 'Implementasi Dark Mode', completed: true },
{ id: 3, text: 'Testing Toggle Theme', completed: false }
];

function toggleTheme() {
document.body.classList.toggle('dark-mode');
const isDark = document.body.classList.contains('dark-mode');
document.getElementById('themeToggle').textContent = isDark ? '🌙' : '☀️';
localStorage.setItem('todo_theme', isDark ? 'dark' : 'light');
}

function loadTheme() {
const saved = localStorage.getItem('todo_theme');
if (saved === 'dark') {
document.body.classList.add('dark-mode');
document.getElementById('themeToggle').textContent = '🌙';
}
}

function addTodo() {
const input = document.getElementById('todoInput');
const text = input.value.trim();
if (!text) return;
todos.push({ id: Date.now(), text, completed: false });
input.value = '';
renderTodos();
}

function toggleTodo(id) {
const todo = todos.find(t => t.id === id);
if (todo) { todo.completed = !todo.completed; renderTodos(); }
}

function renderTodos() {
const list = document.getElementById('todoList');
list.innerHTML = todos.map(t => `
<div class="todo-item" onclick="toggleTodo(${t.id})">
  <span class="todo-text ${t.completed ? 'done' : ''}">${t.completed ? '✓ ' : '○ '}${t.text}</span>
</div>
`).join('');
}
loadTheme();
renderTodos();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Klik tombol matahari/bulan untuk toggle dark mode. Preferensi tema tersimpan di LocalStorage. Semua warna berubah secara konsisten.
