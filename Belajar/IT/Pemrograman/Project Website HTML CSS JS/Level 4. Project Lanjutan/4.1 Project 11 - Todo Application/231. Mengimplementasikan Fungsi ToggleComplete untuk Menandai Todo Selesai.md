# 231. Mengimplementasikan Fungsi ToggleComplete untuk Menandai Todo Selesai

## Definisi & Target
Membuat fungsi toggleComplete yang mengubah properti completed pada todo dari false ke true atau sebaliknya, kemudian merender ulang tampilan dengan status baru.

## Analogi Alur
ToggleComplete seperti saklar lampu: sekali klik, lampu menyala (completed = true); klik lagi, lampu mati (completed = false). Status todo berubah bolak-balik.

## Poin-Poin Penting
- Fungsi menerima id todo sebagai parameter
- Cari todo di array berdasarkan id menggunakan find() atau findIndex()
- Balikkan nilai completed dengan operator NOT (!)
- Render ulang list setelah perubahan
- Update tampilan checkbox/status visual
- Animasi untuk transisi status
- Todo yang completed tampil dengan gaya coretan (line-through)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Toggle Complete</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #2b2d42; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1b2e; border-radius: 16px; padding: 30px; width: 100%; max-width: 500px; box-shadow: 0 20px 60px rgba(0,0,0,0.5); }
h1 { text-align: center; color: #edf2f4; margin-bottom: 20px; font-size: 22px; }
.stats { display: flex; justify-content: center; gap: 20px; margin-bottom: 20px; }
.stat { background: #2b2d42; padding: 10px 20px; border-radius: 10px; text-align: center; }
.stat-label { color: #888; font-size: 12px; }
.stat-value { color: #edf2f4; font-size: 18px; font-weight: 600; }
.todo-item { background: #2b2d42; padding: 14px 18px; border-radius: 12px; margin-bottom: 10px; display: flex; align-items: center; gap: 12px; cursor: pointer; transition: all 0.3s; }
.todo-item:hover { background: #353750; }
.checkbox { width: 24px; height: 24px; border: 2px solid #8d99ae; border-radius: 6px; display: flex; align-items: center; justify-content: center; transition: all 0.3s; flex-shrink: 0; font-size: 14px; color: white; }
.checkbox.checked { background: #2ecc71; border-color: #2ecc71; transform: scale(1.05); }
.todo-text { flex: 1; color: #edf2f4; font-size: 15px; transition: all 0.3s; }
.todo-text.checked { text-decoration: line-through; color: #6c6f7f; }
.todo-delete { color: #e74c3c; font-size: 18px; opacity: 0; transition: opacity 0.3s; cursor: pointer; }
.todo-item:hover .todo-delete { opacity: 1; }
.fade-in { animation: fadeIn 0.3s ease; }
@keyframes fadeIn { from { opacity: 0; transform: translateY(-10px); } to { opacity: 1; transform: translateY(0); } }
</style>
</head>
<body>
<div class="container">
<h1>Toggle Complete</h1>
<div class="stats">
<div class="stat"><div class="stat-value" id="totalCount">0</div><div class="stat-label">Total</div></div>
<div class="stat"><div class="stat-value" id="doneCount">0</div><div class="stat-label">Selesai</div></div>
<div class="stat"><div class="stat-value" id="pendingCount">0</div><div class="stat-label">Pending</div></div>
</div>
<div id="todoList"></div>
</div>
<script>
let todos = [
{ id: 1, text: 'Belajar Array Methods', completed: false },
{ id: 2, text: 'Membuat Fungsi Toggle', completed: true },
{ id: 3, text: 'Render Ulang Tampilan', completed: false },
{ id: 4, text: 'Animasi Transisi', completed: false },
{ id: 5, text: 'Testing Aplikasi', completed: true }
];

function toggleComplete(id) {
const todo = todos.find(t => t.id === id);
if (todo) {
todo.completed = !todo.completed;
renderTodos();
}
}

function renderTodos() {
const list = document.getElementById('todoList');
document.getElementById('totalCount').textContent = todos.length;
document.getElementById('doneCount').textContent = todos.filter(t => t.completed).length;
document.getElementById('pendingCount').textContent = todos.filter(t => !t.completed).length;
list.innerHTML = todos.map(t => `
<div class="todo-item fade-in" onclick="toggleComplete(${t.id})">
  <div class="checkbox ${t.completed ? 'checked' : ''}">${t.completed ? '✓' : ''}</div>
  <span class="todo-text ${t.completed ? 'checked' : ''}">${t.text}</span>
  <span class="todo-delete">✕</span>
</div>
`).join('');
}
renderTodos();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML dan buka di browser. Klik todo untuk toggle status selesai/belum. Statistik total, selesai, dan pending akan diperbarui secara real-time.
