# 238. Mengimplementasikan Priority Level pada Todo yaitu High, Medium, dan Low

## Definisi & Target
Menambahkan level prioritas pada setiap todo (High, Medium, Low) yang mempengaruhi tampilan dan urutan. Todo prioritas High tampil lebih menonjol.

## Analogi Alur
Priority level seperti label warna di folder: merah untuk penting (High), kuning untuk sedang (Medium), hijau untuk biasa (Low). Anda bisa langsung melihat mana yang perlu dikerjakan duluan.

## Poin-Poin Penting
- Select dropdown atau button group untuk memilih prioritas
- Setiap todo memiliki properti priority: 'high', 'medium', 'low'
- Tampilkan badge dengan warna sesuai prioritas
- Urutkan todo berdasarkan prioritas (High di atas)
- Beri ikon atau indikator visual yang jelas
- Priority bisa diubah setelah todo dibuat
- Warna: High=merah, Medium=kuning/oranye, Low=hijau

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Priority Todo</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1a3e; border-radius: 16px; padding: 30px; width: 100%; max-width: 550px; }
h1 { text-align: center; color: #667eea; margin-bottom: 20px; font-size: 22px; }
.input-group { display: flex; gap: 10px; margin-bottom: 20px; flex-wrap: wrap; }
.input-group input { flex: 1; min-width: 120px; padding: 12px 16px; border: 2px solid #2a2a5e; border-radius: 10px; font-size: 15px; background: #12123a; color: #fff; outline: none; }
.priority-select { padding: 12px 16px; border: 2px solid #2a2a5e; border-radius: 10px; background: #12123a; color: #fff; font-size: 14px; outline: none; }
.input-group button { padding: 12px 24px; background: #667eea; color: white; border: none; border-radius: 10px; font-size: 15px; cursor: pointer; }
.todo-item { padding: 14px 18px; border-radius: 12px; margin-bottom: 10px; display: flex; align-items: center; gap: 12px; border-left: 4px solid; }
.todo-item.high { background: #2a1a1a; border-color: #e94560; }
.todo-item.medium { background: #2a2a1a; border-color: #f39c12; }
.todo-item.low { background: #1a2a1a; border-color: #4caf50; }
.todo-text { flex: 1; color: #ddd; font-size: 15px; }
.priority-badge { font-size: 11px; padding: 3px 10px; border-radius: 20px; font-weight: 600; text-transform: uppercase; }
.priority-badge.high { background: #e94560; color: white; }
.priority-badge.medium { background: #f39c12; color: #1a1a1a; }
.priority-badge.low { background: #4caf50; color: white; }
.empty-state { text-align: center; color: #555; padding: 30px; }
</style>
</head>
<body>
<div class="container">
<h1>🏷️ Priority Level</h1>
<div class="input-group">
<input type="text" id="todoInput" placeholder="Nama tugas...">
<select class="priority-select" id="prioritySelect">
<option value="high">🔴 High</option>
<option value="medium" selected>🟡 Medium</option>
<option value="low">🟢 Low</option>
</select>
<button onclick="addTodo()">Tambah</button>
</div>
<div id="todoList"></div>
</div>
<script>
let todos = [
{ id: 1, text: 'Server Down - Fix ASAP!', priority: 'high', completed: false },
{ id: 2, text: 'Meeting dengan Klien', priority: 'high', completed: false },
{ id: 3, text: 'Review Pull Request', priority: 'medium', completed: false },
{ id: 4, text: 'Update Dokumentasi', priority: 'low', completed: false },
{ id: 5, text: 'Belajar Framework Baru', priority: 'low', completed: false }
];

function addTodo() {
const text = document.getElementById('todoInput').value.trim();
if (!text) return;
const priority = document.getElementById('prioritySelect').value;
todos.unshift({ id: Date.now(), text, priority, completed: false });
document.getElementById('todoInput').value = '';
renderTodos();
}

function toggleTodo(id) {
const todo = todos.find(t => t.id === id);
if (todo) { todo.completed = !todo.completed; renderTodos(); }
}

function renderTodos() {
const list = document.getElementById('todoList');
if (todos.length === 0) { list.innerHTML = '<div class="empty-state">Belum ada tugas</div>'; return; }
const priorityOrder = { high: 0, medium: 1, low: 2 };
const sorted = [...todos].sort((a, b) => priorityOrder[a.priority] - priorityOrder[b.priority]);
list.innerHTML = sorted.map(t => `
<div class="todo-item ${t.priority}" onclick="toggleTodo(${t.id})" style="cursor:pointer">
  <span class="todo-text" style="${t.completed ? 'text-decoration:line-through;color:#666' : ''}">${t.completed ? '✓ ' : '○ '}${t.text}</span>
  <span class="priority-badge ${t.priority}">${t.priority}</span>
</div>
`).join('');
}
renderTodos();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Pilih prioritas dari dropdown saat menambah todo. Todo akan diurutkan berdasarkan prioritas dengan warna border dan badge yang berbeda.
