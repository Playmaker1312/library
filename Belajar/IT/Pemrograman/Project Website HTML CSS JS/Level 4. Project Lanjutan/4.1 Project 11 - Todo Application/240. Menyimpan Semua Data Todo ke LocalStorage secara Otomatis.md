# 240. Menyimpan Semua Data Todo ke LocalStorage secara Otomatis

## Definisi & Target
Mengimplementasikan penyimpanan data todo ke LocalStorage browser agar data tetap tersimpan meskipun halaman ditutup atau di-refresh.

## Analogi Alur
LocalStorage seperti lemari besi pribadi di browser. Setiap kali Anda mengubah data (tambah/edit/hapus), data otomatis disimpan ke lemari besi. Saat halaman dibuka lagi, data diambil dari lemari besi.

## Poin-Poin Penting
- Gunakan localStorage.setItem() untuk menyimpan data
- Gunakan localStorage.getItem() untuk mengambil data
- Konversi array ke JSON dengan JSON.stringify()
- Parse JSON kembali ke array dengan JSON.parse()
- Simpan setiap kali data berubah (tambah, edit, hapus, toggle)
- Load data di awal saat halaman dimuat
- Handle error jika data rusak atau tidak ada

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Todo LocalStorage</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #2b2d42; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1b2e; border-radius: 16px; padding: 30px; width: 100%; max-width: 500px; }
h1 { text-align: center; color: #edf2f4; margin-bottom: 5px; font-size: 22px; }
.subtitle { text-align: center; color: #888; font-size: 12px; margin-bottom: 20px; }
.input-group { display: flex; gap: 10px; margin-bottom: 20px; }
.input-group input { flex: 1; padding: 12px 16px; border: 2px solid #2b2d42; border-radius: 10px; font-size: 15px; background: #2b2d42; color: #fff; outline: none; }
.input-group input:focus { border-color: #e94560; }
.input-group button { background: #e94560; color: white; border: none; padding: 12px 20px; border-radius: 10px; font-size: 15px; cursor: pointer; font-weight: 600; }
.todo-item { background: #2b2d42; padding: 12px 16px; border-radius: 10px; margin-bottom: 8px; display: flex; align-items: center; gap: 10px; cursor: pointer; }
.todo-text { flex: 1; color: #edf2f4; font-size: 15px; }
.todo-text.done { text-decoration: line-through; color: #6c6f7f; }
.status-dot { width: 10px; height: 10px; border-radius: 50%; flex-shrink: 0; }
.status-dot.active { background: #e94560; }
.status-dot.done { background: #4caf50; }
.info-bar { display: flex; justify-content: space-between; color: #666; font-size: 12px; margin-top: 15px; padding-top: 15px; border-top: 1px solid #2b2d42; }
</style>
</head>
<body>
<div class="container">
<h1>💾 Auto-Save</h1>
<p class="subtitle">Data tersimpan otomatis ke LocalStorage</p>
<div class="input-group">
<input type="text" id="todoInput" placeholder="Tambah tugas..." autofocus>
<button onclick="addTodo()">Tambah</button>
</div>
<div id="todoList"></div>
<div class="info-bar">
<span id="countInfo">0 tugas</span>
<span id="saveInfo">💾 Tersimpan</span>
</div>
</div>
<script>
const STORAGE_KEY = 'todos_data';

function loadTodos() {
try {
const data = localStorage.getItem(STORAGE_KEY);
return data ? JSON.parse(data) : [];
} catch { return []; }
}

function saveTodos() {
localStorage.setItem(STORAGE_KEY, JSON.stringify(todos));
document.getElementById('saveInfo').textContent = '💾 Tersimpan ' + new Date().toLocaleTimeString('id-ID');
}

let todos = loadTodos();

function addTodo() {
const input = document.getElementById('todoInput');
const text = input.value.trim();
if (!text) return;
todos.push({ id: Date.now(), text, completed: false });
input.value = '';
saveTodos();
renderTodos();
}

function toggleTodo(id) {
const todo = todos.find(t => t.id === id);
if (todo) { todo.completed = !todo.completed; saveTodos(); renderTodos(); }
}

function renderTodos() {
const list = document.getElementById('todoList');
document.getElementById('countInfo').textContent = `${todos.length} tugas`;
if (todos.length === 0) { list.innerHTML = '<div style="text-align:center;color:#555;padding:30px">Belum ada tugas</div>'; return; }
list.innerHTML = todos.map(t => `
<div class="todo-item" onclick="toggleTodo(${t.id})">
  <div class="status-dot ${t.completed ? 'done' : 'active'}"></div>
  <span class="todo-text ${t.completed ? 'done' : ''}">${t.text}</span>
</div>
`).join('');
}
renderTodos();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Tambah atau klik todo untuk toggle. Data otomatis tersimpan ke LocalStorage. Refresh halaman untuk melihat data tetap ada.
