# 235. Mengimplementasikan Fitur Search Todo secara Real-Time

## Definisi & Target
Membuat fitur pencarian yang memfilter todo berdasarkan kata kunci secara real-time saat user mengetik di search bar.

## Analogi Alur
Search real-time seperti asisten yang langsung mencari catatan saat Anda mengetik kata kunci. Setiap huruf yang diketik langsung mempersempit hasil pencarian tanpa perlu tekan tombol cari.

## Poin-Poin Penting
- Input search dengan event listener keyup atau input
- Filter array todos menggunakan method filter() dan includes()
- Gunakan toLowerCase() untuk pencarian case-insensitive
- Render ulang setiap kali input berubah
- Kombinasikan dengan filter status (All/Active/Completed)
- Tampilkan pesan "Tidak ditemukan" jika tidak ada hasil
- Debounce opsional untuk performa pada data besar
- Highlight kata kunci pada hasil pencarian

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Search Todo Real-Time</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1a3e; border-radius: 16px; padding: 30px; width: 100%; max-width: 550px; }
h1 { text-align: center; color: #667eea; margin-bottom: 20px; font-size: 22px; }
.search-box { width: 100%; padding: 12px 16px 12px 40px; border: 2px solid #2a2a5e; border-radius: 10px; font-size: 15px; background: #12123a; color: #fff; outline: none; margin-bottom: 20px; }
.search-box:focus { border-color: #667eea; }
.search-wrap { position: relative; }
.search-wrap:before { content: '🔍'; position: absolute; left: 12px; top: 50%; transform: translateY(-50%); font-size: 16px; }
.todo-item { background: #12123a; padding: 12px 16px; border-radius: 10px; margin-bottom: 8px; display: flex; align-items: center; gap: 10px; border: 1px solid #2a2a5e; }
.todo-text { flex: 1; color: #ddd; font-size: 15px; }
.todo-text.done { text-decoration: line-through; color: #555; }
mark { background: #667eea; color: white; padding: 0 4px; border-radius: 3px; }
.result-count { text-align: center; color: #666; font-size: 13px; margin-top: 15px; }
.no-result { text-align: center; color: #555; padding: 30px; }
</style>
</head>
<body>
<div class="container">
<h1>🔎 Search Real-Time</h1>
<div class="search-wrap"><input class="search-box" type="text" id="searchInput" placeholder="Cari todo..." autofocus></div>
<div id="todoList"></div>
<div class="result-count" id="resultCount"></div>
</div>
<script>
let todos = [
{ id: 1, text: 'Belajar JavaScript Dasar', completed: false },
{ id: 2, text: 'Membuat Todo App', completed: true },
{ id: 3, text: 'Belajar React JS', completed: false },
{ id: 4, text: 'Olahraga Pagi Lari', completed: false },
{ id: 5, text: 'Membaca Buku JavaScript', completed: true },
{ id: 6, text: 'Belajar CSS Flexbox', completed: false },
{ id: 7, text: 'Project Portfolio Website', completed: false },
{ id: 8, text: 'Belajar Node.js Backend', completed: true }
];

function searchTodos() {
const query = document.getElementById('searchInput').value.toLowerCase();
const filtered = todos.filter(t => t.text.toLowerCase().includes(query));
const list = document.getElementById('todoList');
document.getElementById('resultCount').textContent = `Ditemukan ${filtered.length} dari ${todos.length} todo`;

if (filtered.length === 0) {
list.innerHTML = `<div class="no-result">Tidak ada todo dengan kata kunci "${query}"</div>`;
return;
}

list.innerHTML = filtered.map(t => {
const highlighted = query ? t.text.replace(new RegExp(`(${query})`, 'gi'), '<mark>$1</mark>') : t.text;
return `<div class="todo-item">
  <span class="todo-text ${t.completed ? 'done' : ''}">${t.completed ? '✓ ' : '○ '}${highlighted}</span>
</div>`;
}).join('');
}

document.getElementById('searchInput').addEventListener('input', searchTodos);
searchTodos();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Ketik kata kunci di search box. Hasil akan terfilter secara real-time dengan kata kunci di-highlight.
