# 227. Merancang Struktur Data Todo menggunakan JavaScript Array of Objects

## Definisi & Target
Merancang struktur data todo sebagai array of objects di JavaScript. Setiap todo memiliki properti id, text, completed, createdAt, dan properti lain yang diperlukan.

## Analogi Alur
Array of objects seperti lemari arsip: setiap laci (object) berisi data spesifik tentang satu todo, dan semua laci disusun dalam satu lemari (array) yang mudah diakses dan diurutkan.

## Poin-Poin Penting
- Setiap todo direpresentasikan sebagai object dengan properti-properti tertentu
- Array menyimpan semua todo secara terurut
- Setiap object memiliki id unik (bisa menggunakan Date.now() atau crypto.randomUUID())
- Properti completed (boolean) untuk status selesai
- createdAt menyimpan timestamp pembuatan
- Struktur data ini menjadi sumber kebenaran (single source of truth)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Struktur Data Todo</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #16213e; border-radius: 16px; padding: 30px; width: 100%; max-width: 700px; box-shadow: 0 20px 60px rgba(0,0,0,0.5); }
h1 { color: #e94560; text-align: center; margin-bottom: 5px; font-size: 22px; }
.subtitle { color: #aaa; text-align: center; margin-bottom: 20px; font-size: 13px; }
pre { background: #0f3460; color: #e0e0e0; padding: 20px; border-radius: 10px; font-size: 13px; overflow-x: auto; white-space: pre-wrap; word-break: break-all; }
.data-preview { margin-top: 20px; }
.item { background: #1a1a40; padding: 12px 16px; border-radius: 8px; margin-bottom: 8px; display: flex; align-items: center; gap: 10px; }
.status { width: 20px; height: 20px; border-radius: 50%; border: 2px solid #e94560; flex-shrink: 0; display: flex; align-items: center; justify-content: center; font-size: 12px; }
.status.done { background: #e94560; color: white; }
.text { color: #fff; flex: 1; }
.text.done { text-decoration: line-through; color: #888; }
.time { color: #666; font-size: 12px; }
.btn-refresh { background: #e94560; color: white; border: none; padding: 10px 20px; border-radius: 8px; cursor: pointer; font-size: 14px; margin-top: 15px; width: 100%; }
.btn-refresh:hover { background: #d63851; }
</style>
</head>
<body>
<div class="container">
<h1>Struktur Data Todo</h1>
<p class="subtitle">Array of Objects - Satu sumber kebenaran</p>
<pre id="dataDisplay">[]</pre>
<div class="data-preview" id="todoList"></div>
<button class="btn-refresh" onclick="addSampleTodo()">Tambah Sample Todo</button>
</div>
<script>
let todos = [];

function addSampleTodo() {
const sampleTexts = ['Belajar JavaScript', 'Membuat Todo App', 'Olahraga Pagi', 'Membaca Buku', 'Project React'];
const randomText = sampleTexts[Math.floor(Math.random() * sampleTexts.length)];
const newTodo = {
id: Date.now(),
text: randomText,
completed: Math.random() > 0.5,
createdAt: new Date().toLocaleString('id-ID')
};
todos.push(newTodo);
renderAll();
}

function renderAll() {
document.getElementById('dataDisplay').textContent = JSON.stringify(todos, null, 2);
const list = document.getElementById('todoList');
list.innerHTML = todos.map(todo => `
<div class="item">
  <div class="status ${todo.completed ? 'done' : ''}">${todo.completed ? '✓' : ''}</div>
  <span class="text ${todo.completed ? 'done' : ''}">${todo.text}</span>
  <span class="time">${todo.createdAt}</span>
</div>
`).join('');
}
renderAll();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai file HTML dan buka di browser. Klik tombol untuk menambah sample todo. Perhatikan struktur data di preview JSON dan bagaimana data dirender ke DOM.
