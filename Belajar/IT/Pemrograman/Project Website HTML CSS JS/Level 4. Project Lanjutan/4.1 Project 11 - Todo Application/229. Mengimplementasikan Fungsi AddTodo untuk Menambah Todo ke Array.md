# 229. Mengimplementasikan Fungsi AddTodo untuk Menambah Todo ke Array

## Definisi & Target
Membuat fungsi JavaScript yang mengambil nilai dari input, membuat object todo baru, menambahkannya ke array todos, dan merender ulang tampilan.

## Analogi Alur
Fungsi AddTodo seperti menulis surat (membuat object), memasukkan ke dalam kotak surat (array), lalu memperbarui papan pengumuman (render) agar semua orang bisa melihat surat baru tersebut.

## Poin-Poin Penting
- Ambil nilai input dan validasi tidak kosong
- Buat object todo dengan id unik (Date.now())
- Set completed default ke false
- Push object ke array todos
- Panggil fungsi render setelah menambah
- Bersihkan input setelah berhasil
- Beri feedback visual jika input kosong

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>AddTodo Function</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: linear-gradient(135deg, #2c3e50, #3498db); min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: white; border-radius: 16px; padding: 30px; width: 100%; max-width: 500px; box-shadow: 0 20px 60px rgba(0,0,0,0.3); }
h1 { text-align: center; color: #2c3e50; margin-bottom: 5px; font-size: 22px; }
.counter { text-align: center; color: #888; font-size: 13px; margin-bottom: 20px; }
.input-group { display: flex; gap: 10px; margin-bottom: 20px; }
.input-group input { flex: 1; padding: 12px 16px; border: 2px solid #e0e0e0; border-radius: 10px; font-size: 15px; outline: none; }
.input-group input:focus { border-color: #3498db; }
.input-group button { background: #3498db; color: white; border: none; padding: 12px 20px; border-radius: 10px; font-size: 15px; cursor: pointer; font-weight: 600; transition: background 0.3s; }
.input-group button:hover { background: #2980b9; }
.todo-list { list-style: none; }
.todo-item { background: #f8f9fa; padding: 12px 16px; border-radius: 8px; margin-bottom: 8px; display: flex; align-items: center; gap: 10px; animation: slideIn 0.3s ease; }
@keyframes slideIn { from { opacity: 0; transform: translateX(-20px); } to { opacity: 1; transform: translateX(0); } }
.todo-text { flex: 1; color: #333; }
.todo-time { font-size: 11px; color: #aaa; }
.empty { text-align: center; color: #bbb; padding: 30px; font-size: 14px; }
</style>
</head>
<body>
<div class="container">
<h1>Todo List</h1>
<p class="counter" id="counter">0 tugas</p>
<div class="input-group">
<input type="text" id="todoInput" placeholder="Tambah tugas baru..." autofocus>
<button onclick="addTodo()">Tambah</button>
</div>
<ul class="todo-list" id="todoList">
<li class="empty">Belum ada tugas</li>
</ul>
</div>
<script>
let todos = [];

function addTodo() {
const input = document.getElementById('todoInput');
const text = input.value.trim();
if (!text) return;

const todo = {
id: Date.now(),
text: text,
completed: false,
createdAt: new Date().toLocaleString('id-ID')
};

todos.push(todo);
input.value = '';
input.focus();
renderTodos();
}

function renderTodos() {
const list = document.getElementById('todoList');
const counter = document.getElementById('counter');
counter.textContent = `${todos.length} tugas`;

if (todos.length === 0) {
list.innerHTML = '<li class="empty">Belum ada tugas</li>';
return;
}

list.innerHTML = todos.map(todo => `
<li class="todo-item">
  <span class="todo-text">${todo.text}</span>
  <span class="todo-time">${todo.createdAt}</span>
</li>
`).join('');
}

document.getElementById('todoInput').addEventListener('keypress', e => {
if (e.key === 'Enter') addTodo();
});
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai file HTML. Buka di browser, ketik tugas, dan klik Tambah. Perhatikan bagaimana setiap todo masuk ke array dan langsung dirender. Counter memperbarui jumlah todo.
