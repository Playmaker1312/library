# 232. Mengimplementasikan Fungsi DeleteTodo dengan Animasi Slide-Out

## Definisi & Target
Membuat fungsi deleteTodo yang menghapus todo dari array dan menambahkan animasi slide-out pada elemen DOM sebelum elemen benar-benar dihapus.

## Analogi Alur
DeleteTodo dengan animasi seperti menghapus tulisan di papan tulis: Anda menghapusnya dengan gerakan menyamping (slide-out), bukan langsung hilang instant. Memberi efek visual yang halus.

## Poin-Poin Penting
- Fungsi menerima id todo sebagai parameter
- Filter array untuk menghapus item dengan id tertentu
- Tambahkan class CSS untuk animasi slide-out sebelum menghapus
- Gunakan setTimeout untuk menunggu animasi selesai sebelum render
- Beri konfirmasi visual dengan ikon atau efek hover
- Handle edge case jika todo tidak ditemukan
- Transisi CSS menggunakan transform: translateX dan opacity

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Delete Todo dengan Animasi</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #16213e; border-radius: 16px; padding: 30px; width: 100%; max-width: 500px; box-shadow: 0 20px 60px rgba(0,0,0,0.5); }
h1 { text-align: center; color: #e94560; margin-bottom: 20px; font-size: 22px; }
.todo-item { background: #0f3460; padding: 14px 18px; border-radius: 12px; margin-bottom: 10px; display: flex; align-items: center; gap: 12px; transition: all 0.3s; cursor: pointer; }
.todo-item:hover { background: #1a3a6e; }
.todo-text { flex: 1; color: #eee; font-size: 15px; }
.todo-text.done { text-decoration: line-through; color: #666; }
.delete-btn { background: none; border: none; color: #e94560; font-size: 20px; cursor: pointer; opacity: 0; transition: opacity 0.3s; padding: 0 5px; }
.todo-item:hover .delete-btn { opacity: 1; }
.slide-out { animation: slideOut 0.4s ease forwards; }
@keyframes slideOut { 0% { opacity: 1; transform: translateX(0); } 100% { opacity: 0; transform: translateX(100px); } }
.slide-in { animation: slideIn 0.3s ease; }
@keyframes slideIn { from { opacity: 0; transform: translateX(-20px); } to { opacity: 1; transform: translateX(0); } }
.empty-state { text-align: center; color: #555; padding: 40px; font-size: 14px; }
</style>
</head>
<body>
<div class="container">
<h1>🗑️ Delete with Animation</h1>
<div id="todoList"></div>
</div>
<script>
let todos = [
{ id: 1, text: 'Belajar CSS Animation' },
{ id: 2, text: 'Implementasi Slide-Out' },
{ id: 3, text: 'Filter Array Method' },
{ id: 4, text: 'Testing Transisi' }
];

function deleteTodo(id) {
const items = document.querySelectorAll('.todo-item');
items.forEach(el => {
if (el.dataset.id == id) {
el.classList.add('slide-out');
}
});
setTimeout(() => {
todos = todos.filter(t => t.id !== id);
renderTodos();
}, 400);
}

function renderTodos() {
const list = document.getElementById('todoList');
if (todos.length === 0) {
list.innerHTML = '<div class="empty-state">Semua todo telah dihapus ✨</div>';
return;
}
list.innerHTML = todos.map(t => `
<div class="todo-item slide-in" data-id="${t.id}">
  <span class="todo-text">${t.text}</span>
  <button class="delete-btn" onclick="deleteTodo(${t.id})">✕</button>
</div>
`).join('');
}
renderTodos();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Hover di atas todo untuk melihat tombol delete. Klik ✕ untuk menghapus dengan efek slide-out ke kanan.
