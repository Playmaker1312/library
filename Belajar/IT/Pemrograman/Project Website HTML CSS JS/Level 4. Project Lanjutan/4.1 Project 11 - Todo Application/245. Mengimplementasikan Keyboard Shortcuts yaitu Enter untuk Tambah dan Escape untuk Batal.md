# 245. Mengimplementasikan Keyboard Shortcuts yaitu Enter untuk Tambah dan Escape untuk Batal

## Definisi & Target
Menambahkan shortcut keyboard seperti Enter untuk menambah todo dan Escape untuk membatalkan operasi (seperti edit atau menutup modal).

## Analogi Alur
Keyboard shortcuts seperti remote control TV: satu tombol (Enter) untuk menyalakan/menambah, tombol lain (Escape) untuk mematikan/membatalkan. Lebih cepat daripada menggunakan mouse.

## Poin-Poin Penting
- Enter pada input field menambah todo
- Escape untuk membatalkan edit inline atau menutup modal
- Gunakan event listener keydown atau keypress
- Cegah default behavior jika perlu (preventDefault)
- Tampilkan petunjuk shortcut di UI
- Shortcut juga berfungsi di mode edit
- Konsisten dengan shortcut aplikasi web pada umumnya

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Keyboard Shortcuts</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #16213e; border-radius: 16px; padding: 30px; width: 100%; max-width: 520px; }
h1 { text-align: center; color: #e94560; margin-bottom: 5px; font-size: 22px; }
.shortcuts-hint { text-align: center; color: #666; font-size: 12px; margin-bottom: 20px; }
kbd { background: #0f3460; border: 1px solid #1a3a6e; border-radius: 4px; padding: 2px 8px; font-size: 12px; color: #aaa; font-family: monospace; }
.input-group { display: flex; gap: 10px; margin-bottom: 20px; }
.input-group input { flex: 1; padding: 12px 16px; border: 2px solid #0f3460; border-radius: 10px; font-size: 15px; background: #0f3460; color: #fff; outline: none; }
.input-group input:focus { border-color: #e94560; }
.input-group button { padding: 12px 20px; background: #e94560; color: white; border: none; border-radius: 10px; font-size: 15px; cursor: pointer; }
.todo-item { background: #0f3460; padding: 14px 18px; border-radius: 12px; margin-bottom: 8px; display: flex; align-items: center; gap: 12px; cursor: pointer; }
.todo-item.editing { padding: 10px 14px; }
.todo-item input { flex: 1; padding: 8px 12px; border: 2px solid #e94560; border-radius: 8px; font-size: 15px; background: #1a1a3e; color: #fff; outline: none; }
.todo-text { flex: 1; color: #eee; font-size: 15px; }
.todo-text.done { text-decoration: line-through; color: #555; }
.edit-btn { background: none; border: none; color: #667eea; cursor: pointer; font-size: 14px; padding: 4px 8px; border-radius: 4px; }
.edit-btn:hover { background: rgba(102,126,234,0.2); }
.empty-state { text-align: center; color: #555; padding: 30px; }
</style>
</head>
<body>
<div class="container">
<h1>⌨️ Keyboard Shortcuts</h1>
<p class="shortcuts-hint"><kbd>Enter</kbd> Tambah todo • <kbd>Escape</kbd> Batal edit</p>
<div class="input-group">
<input type="text" id="todoInput" placeholder="Tambah tugas..." autofocus>
<button onclick="addTodo()">Tambah</button>
</div>
<div id="todoList"></div>
</div>
<script>
let todos = [
{ id: 1, text: 'Belajar Keyboard Events', completed: false },
{ id: 2, text: 'Implementasi Enter & Escape', completed: false },
{ id: 3, text: 'Testing Shortcuts', completed: true }
];
let editingId = null;

document.addEventListener('keydown', function(e) {
if (e.key === 'Enter' && editingId === null) {
const input = document.getElementById('todoInput');
if (document.activeElement === input) addTodo();
}
if (e.key === 'Escape') {
if (editingId !== null) {
cancelEdit();
}
document.getElementById('todoInput').blur();
}
});

function addTodo() {
const input = document.getElementById('todoInput');
const text = input.value.trim();
if (!text) return;
todos.push({ id: Date.now(), text, completed: false });
input.value = '';
renderTodos();
}

function startEdit(id, currentText) {
editingId = id;
renderTodos();
setTimeout(() => {
const input = document.querySelector('.edit-input');
if (input) { input.focus(); input.value = currentText; input.select(); }
}, 0);
}

function saveEdit(id) {
const input = document.querySelector('.edit-input');
if (!input) return;
const text = input.value.trim();
if (text) { const todo = todos.find(t => t.id === id); if (todo) todo.text = text; }
editingId = null;
renderTodos();
}

function cancelEdit() { editingId = null; renderTodos(); }

function toggleTodo(id) {
const todo = todos.find(t => t.id === id);
if (todo) { todo.completed = !todo.completed; renderTodos(); }
}

function renderTodos() {
const list = document.getElementById('todoList');
if (todos.length === 0) { list.innerHTML = '<div class="empty-state">Belum ada tugas</div>'; return; }
list.innerHTML = todos.map(t => {
if (t.id === editingId) {
return `<div class="todo-item editing">
  <input class="edit-input" value="${t.text}" onkeydown="if(event.key==='Enter')saveEdit(${t.id});if(event.key==='Escape')cancelEdit()">
  <button class="edit-btn" onclick="saveEdit(${t.id})">💾</button>
</div>`;
}
return `<div class="todo-item" onclick="toggleTodo(${t.id})">
  <span class="todo-text ${t.completed ? 'done' : ''}">${t.completed ? '✓ ' : '○ '}${t.text}</span>
  <button class="edit-btn" onclick="event.stopPropagation();startEdit(${t.id},'${t.text}')">✏️</button>
</div>`;
}).join('');
}
renderTodos();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Tekan Enter untuk menambah todo. Klik edit lalu Enter simpan / Escape batal. Shortcuts bekerja secara global di halaman.
