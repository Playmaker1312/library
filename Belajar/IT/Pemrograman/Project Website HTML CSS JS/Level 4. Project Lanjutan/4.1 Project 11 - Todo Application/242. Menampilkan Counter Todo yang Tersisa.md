# 242. Menampilkan Counter Todo yang Tersisa

## Definisi & Target
Menampilkan jumlah todo yang belum selesai (remaining count) di bagian bawah daftar todo sebagai indikator progress.

## Analogi Alur
Counter todo seperti meteran tugas: menunjukkan berapa banyak item yang masih perlu dikerjakan dari total daftar. Semakin kecil angkanya, semakin dekat Anda ke penyelesaian.

## Poin-Poin Penting
- Hitung jumlah todo dengan completed === false
- Tampilkan counter di bagian footer atau header
- Update counter setiap kali data berubah
- Tampilkan teks yang user-friendly (e.g., "3 tugas tersisa")
- Gunakan plural handling (tugas vs tugas jika >1)
- Counter harus konsisten dengan filter yang aktif

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Todo Counter</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #16213e; border-radius: 16px; padding: 30px; width: 100%; max-width: 500px; }
h1 { text-align: center; color: #e94560; margin-bottom: 20px; font-size: 22px; }
.input-group { display: flex; gap: 10px; margin-bottom: 20px; }
.input-group input { flex: 1; padding: 12px 16px; border: 2px solid #0f3460; border-radius: 10px; font-size: 15px; background: #0f3460; color: #fff; outline: none; }
.input-group button { padding: 12px 20px; background: #e94560; color: white; border: none; border-radius: 10px; font-size: 15px; cursor: pointer; }
.todo-item { background: #0f3460; padding: 12px 16px; border-radius: 10px; margin-bottom: 8px; display: flex; align-items: center; gap: 10px; cursor: pointer; transition: all 0.3s; }
.todo-item:hover { background: #1a3a6e; }
.todo-text { flex: 1; color: #eee; font-size: 15px; }
.todo-text.done { text-decoration: line-through; color: #555; }
.counter-bar { display: flex; justify-content: space-between; align-items: center; margin-top: 20px; padding-top: 15px; border-top: 1px solid #0f3460; }
.counter-text { color: #888; font-size: 14px; }
.progress-ring { width: 40px; height: 40px; border-radius: 50%; background: conic-gradient(#e94560 var(--pct, 0%), #0f3460 var(--pct, 0%)); display: flex; align-items: center; justify-content: center; }
.progress-ring-inner { width: 32px; height: 32px; border-radius: 50%; background: #16213e; display: flex; align-items: center; justify-content: center; color: #fff; font-size: 11px; font-weight: 600; }
.empty-state { text-align: center; color: #555; padding: 30px; }
</style>
</head>
<body>
<div class="container">
<h1>📊 Todo Counter</h1>
<div class="input-group">
<input type="text" id="todoInput" placeholder="Tambah tugas..." autofocus>
<button onclick="addTodo()">Tambah</button>
</div>
<div id="todoList"></div>
<div class="counter-bar">
<span class="counter-text" id="counterText">0 tugas tersisa</span>
<div class="progress-ring" id="progressRing"><div class="progress-ring-inner" id="progressInner">0%</div></div>
</div>
</div>
<script>
let todos = [
{ id: 1, text: 'Belajar JavaScript', completed: false },
{ id: 2, text: 'Membuat Todo App', completed: true },
{ id: 3, text: 'Belajar CSS', completed: false },
{ id: 4, text: 'Olahraga', completed: false },
{ id: 5, text: 'Membaca Buku', completed: true }
];

function addTodo() {
const input = document.getElementById('todoInput');
const text = input.value.trim();
if (!text) return;
todos.push({ id: Date.now(), text, completed: false });
input.value = '';
renderTodos();
}

function toggleTodo(id) {
const todo = todos.find(t => t.id === id);
if (todo) { todo.completed = !todo.completed; renderTodos(); }
}

function renderTodos() {
const list = document.getElementById('todoList');
const remaining = todos.filter(t => !t.completed).length;
const total = todos.length;
const pct = total > 0 ? Math.round((total - remaining) / total * 100) : 0;
document.getElementById('counterText').textContent = `${remaining} ${remaining === 1 ? 'tugas tersisa' : 'tugas tersisa'}`;
const ring = document.getElementById('progressRing');
ring.style.setProperty('--pct', `${pct}%`);
document.getElementById('progressInner').textContent = `${pct}%`;
if (todos.length === 0) { list.innerHTML = '<div class="empty-state">Belum ada tugas</div>'; return; }
list.innerHTML = todos.map(t => `
<div class="todo-item" onclick="toggleTodo(${t.id})">
  <span class="todo-text ${t.completed ? 'done' : ''}">${t.completed ? '✓ ' : '○ '}${t.text}</span>
</div>
`).join('');
}
renderTodos();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Counter di bagian bawah menunjukkan jumlah tugas tersisa dengan progress ring visual. Update otomatis saat todo ditambah atau ditandai selesai.
