# 298. Mengimplementasikan Filter Berdasarkan Genre, Tahun, dan Rating

## Definisi & Target
Menambahkan filter untuk menyaring film berdasarkan genre, tahun rilis, dan rating.

## Analogi Alur
Filter seperti saringan kopi: Anda memilih ukuran saringan (genre), suhu air (tahun), dan kekuatan kopi (rating). Hasilnya hanya film yang sesuai kriteria.

## Poin-Poin Penting
- Dropdown atau button group untuk genre
- Range slider atau input untuk tahun
- Rating filter dengan bintang atau range
- Kombinasi filter (AND logic)
- Render ulang setelah filter berubah
- Reset filter button
- Tampilkan jumlah hasil filter

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Movie Filters</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; min-height: 100vh; padding: 20px; display: flex; justify-content: center; }
.container { max-width: 1000px; width: 100%; }
h1 { text-align: center; color: #e94560; margin-bottom: 20px; font-size: 24px; }
.filters { display: flex; gap: 15px; margin-bottom: 20px; flex-wrap: wrap; align-items: center; }
.filter-group { display: flex; flex-direction: column; gap: 4px; }
.filter-group label { color: #888; font-size: 12px; }
.filter-group select, .filter-group input { padding: 8px 14px; border: 1px solid #2a2a5e; border-radius: 8px; background: #12123a; color: #fff; font-size: 13px; outline: none; }
.filter-group input[type="range"] { padding: 0; background: none; }
.rating-value { color: #f39c12; font-size: 14px; font-weight: 600; }
.reset-btn { padding: 8px 20px; background: #e94560; color: white; border: none; border-radius: 8px; cursor: pointer; font-size: 13px; margin-top: 16px; }
.result-count { color: #888; font-size: 14px; margin-bottom: 15px; }
.movie-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(160px, 1fr)); gap: 14px; }
.movie-card { background: #0f3460; border-radius: 12px; overflow: hidden; }
.movie-poster { width: 100%; aspect-ratio: 2/3; background: #1a3a6e; display: flex; align-items: center; justify-content: center; font-size: 36px; }
.movie-info { padding: 10px 12px; }
.movie-title { color: #eee; font-size: 13px; font-weight: 600; }
.movie-meta { display: flex; justify-content: space-between; font-size: 11px; color: #888; margin-top: 3px; }
.movie-rating { color: #f39c12; }
</style>
</head>
<body>
<div class="container">
<h1>🎯 Filter Film</h1>
<div class="filters">
<div class="filter-group">
<label>Genre</label>
<select id="genreFilter" onchange="applyFilters()">
<option value="all">Semua Genre</option>
<option value="action">Action</option>
<option value="drama">Drama</option>
<option value="sci-fi">Sci-Fi</option>
<option value="comedy">Comedy</option>
</select>
</div>
<div class="filter-group">
<label>Tahun Minimal</label>
<select id="yearFilter" onchange="applyFilters()">
<option value="0">Semua Tahun</option>
<option value="2000">2000+</option>
<option value="2005">2005+</option>
<option value="2010">2010+</option>
<option value="2015">2015+</option>
<option value="2020">2020+</option>
</select>
</div>
<div class="filter-group">
<label>Rating Minimal: <span class="rating-value" id="ratingLabel">5</span></label>
<input type="range" id="ratingFilter" min="0" max="10" value="5" step="0.5" oninput="document.getElementById('ratingLabel').textContent=this.value;applyFilters()">
</div>
<button class="reset-btn" onclick="resetFilters()">↺ Reset</button>
</div>
<div class="result-count" id="resultCount">Menampilkan 6 film</div>
<div class="movie-grid" id="movieGrid"></div>
</div>
<script>
const movies = [
{ title: 'Inception', year: 2010, rating: 8.8, genre: 'action' },
{ title: 'The Dark Knight', year: 2008, rating: 9.0, genre: 'action' },
{ title: 'Interstellar', year: 2014, rating: 8.6, genre: 'sci-fi' },
{ title: 'Parasite', year: 2019, rating: 8.5, genre: 'drama' },
{ title: 'Spirited Away', year: 2001, rating: 8.6, genre: 'drama' },
{ title: 'The Matrix', year: 1999, rating: 8.7, genre: 'sci-fi' },
{ title: 'Your Name', year: 2016, rating: 8.4, genre: 'drama' },
{ title: 'Avengers: Endgame', year: 2019, rating: 8.4, genre: 'action' },
{ title: 'Joker', year: 2019, rating: 8.4, genre: 'drama' },
{ title: 'The Batman', year: 2022, rating: 7.8, genre: 'action' }
];

function applyFilters() {
const genre = document.getElementById('genreFilter').value;
const minYear = parseInt(document.getElementById('yearFilter').value);
const minRating = parseFloat(document.getElementById('ratingFilter').value);

const filtered = movies.filter(m => {
if (genre !== 'all' && m.genre !== genre) return false;
if (minYear > 0 && m.year < minYear) return false;
if (m.rating < minRating) return false;
return true;
});

const grid = document.getElementById('movieGrid');
document.getElementById('resultCount').textContent = `Menampilkan ${filtered.length} film`;
grid.innerHTML = filtered.map(m => `
<div class="movie-card">
  <div class="movie-poster">🎬</div>
  <div class="movie-info">
    <div class="movie-title">${m.title}</div>
    <div class="movie-meta"><span>${m.year}</span><span class="movie-rating">★ ${m.rating}</span></div>
  </div>
</div>
`).join('');
}

function resetFilters() {
document.getElementById('genreFilter').value = 'all';
document.getElementById('yearFilter').value = '0';
document.getElementById('ratingFilter').value = '5';
document.getElementById('ratingLabel').textContent = '5';
applyFilters();
}

applyFilters();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Pilih genre, tahun, dan rating untuk memfilter film. Hasil diperbarui secara real-time.
