# 287. Mendaftar dan Mendapatkan API Key dari OMDB API atau TMDB API

## Definisi & Target
Proses registrasi dan mendapatkan API key dari TMDB (The Movie Database) untuk mengakses data film.

## Analogi Alur
API Key TMDB seperti kartu anggota perpustakaan film: Anda mendaftar sebagai anggota, mendapatkan kartu, dan bisa meminjam data film kapan saja.

## Poin-Poin Penting
- Kunjungi themoviedb.org dan daftar akun
- API Key tersedia di Settings > API
- TMDB v3 API: api.themoviedb.org/3/
- Parameter api_key di setiap request
- Image base URL: image.tmdb.org/t/p/w500
- Rate limit: 50 requests per detik
- Jangan expose API Key di client-side
