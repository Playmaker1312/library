# 302. Membuat Skeleton Loading yang Menarik saat Data Dimuat

## Definisi & Target
Membuat skeleton loading screen untuk Movie App yang meniru bentuk card film saat data sedang dimuat.

## Analogi Alur
Skeleton loading seperti kerangka rumah yang sedang dibangun: Anda bisa melihat bentuk kamar-kamar (layout card) meskipun interior (data film) belum ada.

## Poin-Poin Penting
- Skeleton card dengan bentuk poster dan teks
- Animasi shimmer (gradien bergerak)
- Jumlah skeleton sesuai dengan jumlah card yang diharapkan
- Skeleton muncul saat fetch data
- Skeleton diganti dengan card asli setelah data diterima
- Transisi yang halus antara skeleton dan konten

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Skeleton Loading Movies</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; padding: 20px; display: flex; justify-content: center; }
.container { max-width: 1100px; width: 100%; }
h1 { text-align: center; color: #667eea; margin: 20px 0; font-size: 22px; }
.movie-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(180px, 1fr)); gap: 16px; }
.movie-card { background: #1a1a3e; border-radius: 14px; overflow: hidden; border: 1px solid #2a2a5e; }
.movie-poster { width: 100%; aspect-ratio: 2/3; display: flex; align-items: center; justify-content: center; font-size: 40px; }
.movie-info { padding: 12px 14px; }
.movie-title { color: #eee; font-size: 14px; font-weight: 600; }
.movie-year { color: #888; font-size: 12px; }

.skeleton { background: linear-gradient(90deg, #1a3a6e 25%, #2a4a8e 50%, #1a3a6e 75%); background-size: 200% 100%; animation: shimmer 1.5s infinite; border-radius: 6px; }
@keyframes shimmer { 0% { background-position: 200% 0; } 100% { background-position: -200% 0; } }
.skel-poster { width: 100%; aspect-ratio: 2/3; border-radius: 14px 14px 0 0; }
.skel-line { height: 14px; margin: 8px 12px; border-radius: 6px; }
.skel-line.w60 { width: 60%; }
.skel-line.w40 { width: 40%; }

.hidden { display: none; }
.fade-in { animation: fadeIn 0.4s ease; }
@keyframes fadeIn { from { opacity: 0; transform: translateY(10px); } to { opacity: 1; transform: translateY(0); } }
.btn-load { display: block; margin: 20px auto; padding: 14px 40px; background: #667eea; color: white; border: none; border-radius: 12px; font-size: 16px; cursor: pointer; }
.btn-load:hover { background: #5a6fd6; }
</style>
</head>
<body>
<div class="container">
<h1>⏳ Skeleton Loading</h1>
<div class="movie-grid" id="skeletonGrid"></div>
<div class="movie-grid hidden" id="movieGrid"></div>
<button class="btn-load" onclick="simulateLoad()">🔄 Simulasikan Loading</button>
</div>
<script>
const movies = [
{ title: 'Inception', year: 2010, rating: 8.8 },
{ title: 'The Dark Knight', year: 2008, rating: 9.0 },
{ title: 'Interstellar', year: 2014, rating: 8.6 },
{ title: 'Parasite', year: 2019, rating: 8.5 },
{ title: 'Spirited Away', year: 2001, rating: 8.6 },
{ title: 'The Matrix', year: 1999, rating: 8.7 }
];

function showSkeleton() {
document.getElementById('skeletonGrid').classList.remove('hidden');
document.getElementById('movieGrid').classList.add('hidden');
const skelGrid = document.getElementById('skeletonGrid');
skelGrid.innerHTML = Array(6).fill(0).map(() => `
<div class="movie-card">
  <div class="skel-poster skeleton"></div>
  <div class="skel-line w60 skeleton"></div>
  <div class="skel-line w40 skeleton"></div>
</div>
`).join('');
}

function showMovies() {
document.getElementById('skeletonGrid').classList.add('hidden');
const grid = document.getElementById('movieGrid');
grid.classList.remove('hidden');
grid.innerHTML = movies.map(m => `
<div class="movie-card fade-in">
  <div class="movie-poster">🎬</div>
  <div class="movie-info">
    <div class="movie-title">${m.title}</div>
    <div class="movie-year">${m.year} • ★ ${m.rating}</div>
  </div>
</div>
`).join('');
}

function simulateLoad() {
showSkeleton();
setTimeout(showMovies, 1500);
}

showSkeleton();
setTimeout(showMovies, 1500);
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Klik tombol untuk simulasi loading. Skeleton dengan animasi shimmer muncul sebelum konten.
