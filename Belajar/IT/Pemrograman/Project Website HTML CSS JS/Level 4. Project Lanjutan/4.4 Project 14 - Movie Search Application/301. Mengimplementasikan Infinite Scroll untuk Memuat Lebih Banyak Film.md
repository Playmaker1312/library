# 301. Mengimplementasikan Infinite Scroll untuk Memuat Lebih Banyak Film

## Definisi & Target
Menambahkan infinite scroll yang memuat halaman hasil berikutnya saat user scroll ke bawah.

## Analogi Alur
Infinite scroll seperti gulungan kertas yang tak berujung: semakin Anda menarik ke bawah, semakin banyak konten yang muncul. Tidak perlu klik "Next Page".

## Poin-Poin Penting
- Intersection Observer API untuk deteksi scroll
- Loading spinner di bagian bawah
- Increment page number setiap load
- Append hasil baru ke grid (bukan replace)
- Cegah multiple request bersamaan (isLoading flag)
- Tampilkan "Tidak ada lagi film" jika sudah habis
- Fallback jika IntersectionObserver tidak didukung

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Infinite Scroll Movies</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; padding: 20px; display: flex; justify-content: center; }
.container { max-width: 1100px; width: 100%; }
h1 { text-align: center; color: #667eea; margin: 20px 0; font-size: 22px; }
.movie-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(170px, 1fr)); gap: 14px; }
.movie-card { background: #1a1a3e; border: 1px solid #2a2a5e; border-radius: 12px; overflow: hidden; transition: all 0.3s; }
.movie-card:hover { border-color: #667eea; }
.movie-poster { width: 100%; aspect-ratio: 2/3; background: #12123a; display: flex; align-items: center; justify-content: center; font-size: 36px; }
.movie-info { padding: 10px 12px; }
.movie-title { color: #eee; font-size: 13px; font-weight: 600; }
.movie-year { color: #888; font-size: 11px; }
.loading-spinner { text-align: center; padding: 30px; color: #888; display: none; }
.loading-spinner.show { display: block; }
.end-message { text-align: center; padding: 20px; color: #555; font-size: 14px; display: none; }
.end-message.show { display: block; }
.sentinel { height: 20px; }
</style>
</head>
<body>
<div class="container">
<h1>♾️ Infinite Scroll</h1>
<div class="movie-grid" id="movieGrid"></div>
<div class="loading-spinner show" id="loadingSpinner">⏳ Memuat film lainnya...</div>
<div class="end-message" id="endMessage">📦 Semua film telah dimuat</div>
<div class="sentinel" id="sentinel"></div>
</div>
<script>
const allMovies = [
'Inception', 'The Dark Knight', 'Interstellar', 'Parasite', 'Spirited Away',
'The Matrix', 'Your Name', 'Avengers: Endgame', 'Joker', 'The Batman',
'Dune', 'Oppenheimer', 'Barbie', 'John Wick 4', 'Top Gun Maverick',
'Everything Everywhere All at Once', 'The Whale', 'Puss in Boots 2', 'Suzume', 'Guardians of the Galaxy 3'
];

let loadedCount = 0;
const BATCH_SIZE = 6;
let isLoading = false;
let allLoaded = false;

function loadMore() {
if (isLoading || allLoaded) return;
isLoading = true;
document.getElementById('loadingSpinner').classList.add('show');

setTimeout(() => {
const batch = allMovies.slice(loadedCount, loadedCount + BATCH_SIZE);
if (batch.length === 0) {
allLoaded = true;
document.getElementById('loadingSpinner').classList.remove('show');
document.getElementById('endMessage').classList.add('show');
isLoading = false;
return;
}

const grid = document.getElementById('movieGrid');
batch.forEach(title => {
const card = document.createElement('div');
card.className = 'movie-card';
card.innerHTML = `<div class="movie-poster">🎬</div><div class="movie-info"><div class="movie-title">${title}</div><div class="movie-year">Film ${loadedCount + 1}</div></div>`;
grid.appendChild(card);
loadedCount++;
});

document.getElementById('loadingSpinner').classList.remove('show');
isLoading = false;
}, 500);
}

const observer = new IntersectionObserver((entries) => {
if (entries[0].isIntersecting) loadMore();
}, { threshold: 0.1 });

observer.observe(document.getElementById('sentinel'));

loadMore();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Scroll ke bawah untuk memuat lebih banyak film. Intersection Observer mendeteksi saat mendekati akhir halaman.
