# 291. Menampilkan Hasil Pencarian Film dalam Grid Card

## Definisi & Target
Menampilkan hasil pencarian film dalam bentuk grid card yang rapi dengan poster, judul, tahun, dan rating.

## Analogi Alur
Grid card seperti deretan DVD di toko: setiap DVD (card) menampilkan sampul (poster), judul, dan harga (rating). Susunannya rapi dalam baris dan kolom.

## Poin-Poin Penting
- CSS Grid dengan auto-fill dan minmax untuk responsif
- Setiap card: poster, judul, tahun, rating, overview singkat
- Poster menggunakan tmdb image URL
- Rating ditampilkan dengan bintang atau badge warna
- Hover effect untuk interaktivitas
- Loading skeleton selama fetch
- Empty state jika tidak ada hasil

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Movie Grid Cards</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; padding: 20px; display: flex; justify-content: center; align-items: flex-start; }
.container { max-width: 1100px; width: 100%; margin: 0 auto; }
h1 { text-align: center; color: #667eea; margin: 20px 0; font-size: 24px; }
.movie-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(180px, 1fr)); gap: 16px; }
.movie-card { background: #1a1a3e; border-radius: 14px; overflow: hidden; transition: transform 0.3s, box-shadow 0.3s; cursor: pointer; border: 1px solid #2a2a5e; }
.movie-card:hover { transform: translateY(-6px); box-shadow: 0 12px 40px rgba(0,0,0,0.4); }
.movie-poster { width: 100%; aspect-ratio: 2/3; background: #12123a; display: flex; align-items: center; justify-content: center; font-size: 48px; color: #2a2a5e; overflow: hidden; }
.movie-poster img { width: 100%; height: 100%; object-fit: cover; }
.movie-info { padding: 14px; }
.movie-title { color: #eee; font-size: 14px; font-weight: 600; margin-bottom: 5px; white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }
.movie-meta { display: flex; justify-content: space-between; align-items: center; }
.movie-year { color: #888; font-size: 12px; }
.movie-rating { background: #f39c12; color: #1a1a1a; padding: 2px 8px; border-radius: 4px; font-size: 12px; font-weight: 600; }
.rating-high { background: #4caf50; }
.rating-mid { background: #f39c12; }
.rating-low { background: #e94560; }
.skeleton { background: linear-gradient(90deg, #1a3a6e 25%, #2a4a8e 50%, #1a3a6e 75%); background-size: 200% 100%; animation: shimmer 1.5s infinite; border-radius: 6px; }
@keyframes shimmer { 0% { background-position: 200% 0; } 100% { background-position: -200% 0; } }
.skel-poster { width: 100%; aspect-ratio: 2/3; border-radius: 14px; margin-bottom: 10px; }
.skel-text { height: 14px; width: 70%; margin-bottom: 8px; }
.skel-text.small { width: 40%; height: 12px; }
</style>
</head>
<body>
<div class="container">
<h1>🎬 Movie Grid</h1>
<div class="movie-grid" id="movieGrid"></div>
</div>
<script>
const movies = [
{ title: 'Inception', year: 2010, rating: 8.8, poster: '🎬' },
{ title: 'The Dark Knight', year: 2008, rating: 9.0, poster: '🎬' },
{ title: 'Interstellar', year: 2014, rating: 8.6, poster: '🎬' },
{ title: 'Parasite', year: 2019, rating: 8.5, poster: '🎬' },
{ title: 'Spirited Away', year: 2001, rating: 8.6, poster: '🎬' },
{ title: 'The Matrix', year: 1999, rating: 8.7, poster: '🎬' },
{ title: 'Your Name', year: 2016, rating: 8.4, poster: '🎬' },
{ title: 'Avengers: Endgame', year: 2019, rating: 8.4, poster: '🎬' }
];

function getRatingClass(rating) {
if (rating >= 8.5) return 'rating-high';
if (rating >= 7) return 'rating-mid';
return 'rating-low';
}

function renderMovies() {
const grid = document.getElementById('movieGrid');
grid.innerHTML = movies.map(m => `
<div class="movie-card">
  <div class="movie-poster"><span style="font-size:48px">🎬</span></div>
  <div class="movie-info">
    <div class="movie-title">${m.title}</div>
    <div class="movie-meta">
      <span class="movie-year">${m.year}</span>
      <span class="movie-rating ${getRatingClass(m.rating)}">★ ${m.rating}</span>
    </div>
  </div>
</div>
`).join('');
}

renderMovies();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Lihat grid card film responsif dengan poster, judul, tahun, dan rating berwarna.
