# 304. Menampilkan Related Movies atau Recommendations

## Definisi & Target
Menampilkan film-film terkait (related/recommended) berdasarkan film yang sedang dilihat detailnya.

## Analogi Alur
Related movies seperti "Pelanggan juga membeli" di toko online: jika Anda melihat film A, sistem menampilkan film-film serupa yang mungkin Anda sukai.

## Poin-Poin Penting
- Endpoint TMDB: /movie/{id}/recommendations atau /similar
- Tampilkan di bagian bawah modal detail
- Grid horizontal scroll atau grid kecil
- Hanya tampilkan jika ada data
- Card dengan poster dan judul
- Klik untuk membuka detail film tersebut
- Batasi jumlah (6-8 film)
