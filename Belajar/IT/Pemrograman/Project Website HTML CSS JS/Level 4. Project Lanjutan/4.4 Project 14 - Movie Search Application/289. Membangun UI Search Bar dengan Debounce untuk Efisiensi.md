# 289. Membangun UI Search Bar dengan Debounce untuk Efisiensi

## Definisi & Target
Membangun search bar untuk mencari film dengan input field, tombol search, dan debounce untuk mengurangi jumlah request API.

## Analogi Alur
Search bar dengan debounce seperti asisten yang menunggu Anda selesai berbicara sebelum merespon: tidak merespon setiap kata, tapi menunggu jeda setelah Anda selesai mengetik.

## Poin-Poin Penting
- Input field dengan placeholder "Cari film..."
- Tombol search dengan ikon 🔍
- Debounce function dengan delay 500ms
- Event listener 'input' untuk real-time search
- Loading spinner selama pencarian
- Clear button untuk menghapus input
- Auto-focus pada input

<script>
let debounceTimer = null;

function debounce(func, delay) {
return function(...args) {
clearTimeout(debounceTimer);
debounceTimer = setTimeout(() => func.apply(this, args), delay);
};
}

function performSearch() {
const query = document.getElementById('searchInput').value.trim();
const indicator = document.getElementById('debounceIndicator');
if (query.length < 2) {
indicator.textContent = 'Ketik minimal 2 karakter';
return;
}
indicator.textContent = `🔍 Mencari "${query}"...`;
setTimeout(() => {
indicator.textContent = `✅ Hasil untuk "${query}" (simulasi)`;
}, 800);
}

const debouncedSearch = debounce(performSearch, 500);

document.getElementById('searchInput').addEventListener('input', function() {
document.getElementById('debounceIndicator').textContent = `⏳ Menunggu selesai mengetik...`;
debouncedSearch();
});

document.getElementById('searchInput').addEventListener('keypress', function(e) {
if (e.key === 'Enter') {
clearTimeout(debounceTimer);
performSearch();
}
});

function searchMovie() {
clearTimeout(debounceTimer);
performSearch();
}
</script>
</body>

## Cara Integrasi
Simpan sebagai HTML. Ketik di search bar - debounce menunggu 500ms setelah berhenti mengetik sebelum "mencari".
