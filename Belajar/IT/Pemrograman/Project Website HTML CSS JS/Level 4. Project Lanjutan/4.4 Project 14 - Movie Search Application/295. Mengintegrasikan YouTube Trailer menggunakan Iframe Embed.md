# 295. Mengintegrasikan YouTube Trailer menggunakan Iframe Embed

## Definisi & Target
Menambahkan trailer film dari YouTube dengan iframe embed pada modal detail film.

## Analogi Alur
Trailer embed seperti jendela ke YouTube di dalam aplikasi Anda: tanpa meninggalkan halaman, user bisa menonton preview film langsung.

## Poin-Poin Penting
- Dapatkan YouTube video key dari TMDB API (videos endpoint)
- Buat iframe dengan src: https://www.youtube.com/embed/{KEY}
- Set parameter: autoplay=0, rel=0
- Container dengan aspect ratio 16:9 (padding-bottom: 56.25%)
- Responsive iframe (width: 100%, height: absolute)
- Tampilkan hanya jika ada trailer
- Fallback jika tidak ada trailer

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>YouTube Trailer Embed</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; display: flex; justify-content: center; align-items: center; padding: 20px; }
.container { background: #1a1a3e; border-radius: 20px; padding: 30px; width: 100%; max-width: 650px; }
h1 { text-align: center; color: #667eea; margin-bottom: 5px; font-size: 22px; }
.subtitle { text-align: center; color: #888; font-size: 13px; margin-bottom: 20px; }
.movie-selector { display: flex; gap: 10px; margin-bottom: 20px; flex-wrap: wrap; }
.movie-selector button { padding: 10px 20px; background: #12123a; border: 1px solid #2a2a5e; border-radius: 10px; color: #aaa; cursor: pointer; font-size: 14px; transition: all 0.3s; }
.movie-selector button:hover { border-color: #667eea; color: #fff; }
.movie-selector button.active { border-color: #667eea; background: rgba(102,126,234,0.15); color: #667eea; }
.trailer-wrapper { position: relative; padding-bottom: 56.25%; height: 0; overflow: hidden; border-radius: 14px; background: #000; }
.trailer-wrapper iframe { position: absolute; top: 0; left: 0; width: 100%; height: 100%; border: none; }
.no-trailer { text-align: center; padding: 60px 20px; color: #555; background: #12123a; border-radius: 14px; }
.info { display: flex; justify-content: space-between; margin-top: 12px; color: #888; font-size: 13px; }
</style>
</head>
<body>
<div class="container">
<h1>🎬 Trailer Film</h1>
<p class="subtitle">Pilih film untuk melihat trailer</p>
<div class="movie-selector" id="movieSelector"></div>
<div id="trailerContainer">
<div class="trailer-wrapper">
<iframe src="https://www.youtube.com/embed/YoHD9XEInc0" title="Trailer" allowfullscreen></iframe>
</div>
<div class="info"><span id="movieName">Inception (2010)</span><span>▶️ YouTube Trailer</span></div>
</div>
</div>
<script>
const movies = [
{ title: 'Inception', year: 2010, key: 'YoHD9XEInc0' },
{ title: 'Interstellar', year: 2014, key: 'zSWdZVtXT7E' },
{ title: 'The Dark Knight', year: 2008, key: 'EXeTwQWrcwY' },
{ title: 'Parasite', year: 2019, key: '5xH0HfJHsaY' }
];

let currentKey = 'YoHD9XEInc0';

function renderSelectors() {
const container = document.getElementById('movieSelector');
container.innerHTML = movies.map((m, i) => `<button class="${i === 0 ? 'active' : ''}" onclick="selectMovie(${i})">${m.title} (${m.year})</button>`).join('');
}

function selectMovie(idx) {
const m = movies[idx];
currentKey = m.key;
document.querySelectorAll('.movie-selector button').forEach((b, i) => b.classList.toggle('active', i === idx));
const tc = document.getElementById('trailerContainer');
tc.innerHTML = `<div class="trailer-wrapper"><iframe src="https://www.youtube.com/embed/${m.key}" title="${m.title} Trailer" allowfullscreen></iframe></div><div class="info"><span>${m.title} (${m.year})</span><span>▶️ YouTube Trailer</span></div>`;
}

renderSelectors();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Klik tombol film untuk mengganti trailer. Menggunakan iframe embed YouTube dengan aspect ratio 16:9.
