# 299. Mengimplementasikan Sorting Berdasarkan Popularitas, Rating, dan Tahun Rilis

## Definisi & Target
Menambahkan fitur sorting yang memungkinkan user mengurutkan film berdasarkan popularitas, rating, atau tahun rilis.

## Analogi Alur
Sorting seperti mengatur buku di rak: Anda bisa mengurutkan berdasarkan judul A-Z, tahun terbit, atau rating. Setiap cara memberikan perspektif berbeda.

## Poin-Poin Penting
- Dropdown sort options: Popularity, Rating, Tahun
- Arah sorting: ascending/descending
- Gunakan array.sort() dengan comparator function
- Tampilkan indikator arah sorting (↑↓)
- Kombinasikan dengan filter yang ada
- Default sorting berdasarkan popularitas
- Animasi saat sorting berubah

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Movie Sorting</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; padding: 20px; display: flex; justify-content: center; }
.container { max-width: 1000px; width: 100%; }
h1 { text-align: center; color: #667eea; margin: 20px 0; font-size: 22px; }
.controls { display: flex; gap: 15px; margin-bottom: 20px; flex-wrap: wrap; align-items: center; justify-content: center; }
.controls select { padding: 10px 16px; border: 1px solid #2a2a5e; border-radius: 10px; background: #12123a; color: #fff; font-size: 14px; outline: none; }
.sort-btn { padding: 10px 16px; border: 1px solid #2a2a5e; border-radius: 10px; background: #12123a; color: #888; cursor: pointer; font-size: 14px; transition: all 0.3s; }
.sort-btn:hover { border-color: #667eea; color: #fff; }
.sort-btn.active { background: #667eea; color: white; border-color: #667eea; }
.movie-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(170px, 1fr)); gap: 14px; }
.movie-card { background: #1a1a3e; border: 1px solid #2a2a5e; border-radius: 12px; overflow: hidden; transition: all 0.3s; }
.movie-card:hover { border-color: #667eea; }
.movie-poster { width: 100%; aspect-ratio: 2/3; background: #12123a; display: flex; align-items: center; justify-content: center; font-size: 36px; }
.movie-info { padding: 10px 12px; }
.movie-title { color: #eee; font-size: 13px; font-weight: 600; }
.movie-meta { display: flex; justify-content: space-between; font-size: 11px; color: #888; margin-top: 3px; }
.movie-pop { font-size: 10px; color: #555; }
</style>
</head>
<body>
<div class="container">
<h1>🔀 Sort Film</h1>
<div class="controls">
<select id="sortBy" onchange="sortMovies()">
<option value="rating">Rating</option>
<option value="year">Tahun Rilis</option>
<option value="title">Judul A-Z</option>
</select>
<button class="sort-btn active" id="orderBtn" onclick="toggleOrder()">↓ Descending</button>
</div>
<div class="movie-grid" id="movieGrid"></div>
</div>
<script>
let ascending = false;

const movies = [
{ title: 'Inception', year: 2010, rating: 8.8, popularity: 85 },
{ title: 'The Dark Knight', year: 2008, rating: 9.0, popularity: 92 },
{ title: 'Interstellar', year: 2014, rating: 8.6, popularity: 88 },
{ title: 'Parasite', year: 2019, rating: 8.5, popularity: 90 },
{ title: 'Spirited Away', year: 2001, rating: 8.6, popularity: 78 },
{ title: 'The Matrix', year: 1999, rating: 8.7, popularity: 82 },
{ title: 'Your Name', year: 2016, rating: 8.4, popularity: 75 },
{ title: 'Avengers: Endgame', year: 2019, rating: 8.4, popularity: 95 },
{ title: 'The Batman', year: 2022, rating: 7.8, popularity: 80 },
{ title: 'Joker', year: 2019, rating: 8.4, popularity: 86 }
];

function toggleOrder() {
ascending = !ascending;
document.getElementById('orderBtn').textContent = ascending ? '↑ Ascending' : '↓ Descending';
sortMovies();
}

function sortMovies() {
const sortBy = document.getElementById('sortBy').value;
const sorted = [...movies].sort((a, b) => {
let valA, valB;
if (sortBy === 'rating') { valA = a.rating; valB = b.rating; }
else if (sortBy === 'year') { valA = a.year; valB = b.year; }
else { valA = a.title.toLowerCase(); valB = b.title.toLowerCase(); }
if (typeof valA === 'string') return ascending ? valA.localeCompare(valB) : valB.localeCompare(valA);
return ascending ? valA - valB : valB - valA;
});

const grid = document.getElementById('movieGrid');
grid.innerHTML = sorted.map(m => `
<div class="movie-card">
  <div class="movie-poster">🎬</div>
  <div class="movie-info">
    <div class="movie-title">${m.title}</div>
    <div class="movie-meta"><span>${m.year}</span><span class="movie-pop">★ ${m.rating} • Pop ${m.popularity}</span></div>
  </div>
</div>
`).join('');
}

sortMovies();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Pilih kriteria sorting dan toggle ascending/descending. Grid langsung berubah urutannya.
