# 303. Mengimplementasikan Recently Viewed Movies menggunakan LocalStorage

## Definisi & Target
Menyimpan daftar film yang pernah dilihat detailnya oleh user ke LocalStorage dan menampilkannya sebagai riwayat.

## Analogi Alur
Recently viewed seperti riwayat tontonan di Netflix: Anda bisa melihat film-film yang sudah pernah Anda buka detailnya, sehingga mudah untuk kembali ke film yang tertinggal.

## Poin-Poin Penting
- Array film yang pernah diklik untuk melihat detail
- Simpan id, title, timestamp ke LocalStorage
- Tampilkan di halaman utama atau sidebar
- Urutkan dari yang terbaru
- Batasi jumlah (misal 10)
- Hapus duplikasi jika film yang sama diklik lagi
- Klik untuk langsung membuka detail

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Recently Viewed Movies</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #1a1a2e; min-height: 100vh; padding: 20px; display: flex; justify-content: center; }
.container { max-width: 1000px; width: 100%; }
h1 { text-align: center; color: #e94560; margin-bottom: 5px; font-size: 22px; }
.subtitle { text-align: center; color: #888; font-size: 13px; margin-bottom: 20px; }
.section-title { color: #667eea; font-size: 16px; font-weight: 600; margin-bottom: 12px; display: flex; align-items: center; gap: 8px; }
.movie-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(160px, 1fr)); gap: 14px; margin-bottom: 30px; }
.movie-card { background: #0f3460; border-radius: 12px; overflow: hidden; cursor: pointer; transition: all 0.3s; border: 1px solid #1a3a6e; }
.movie-card:hover { border-color: #667eea; transform: translateY(-3px); }
.movie-poster { width: 100%; aspect-ratio: 2/3; background: #1a3a6e; display: flex; align-items: center; justify-content: center; font-size: 32px; }
.movie-info { padding: 10px 12px; }
.movie-title { color: #eee; font-size: 13px; font-weight: 600; white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }
.movie-time { color: #888; font-size: 10px; margin-top: 2px; }
.recent-bar { display: flex; gap: 12px; overflow-x: auto; padding-bottom: 10px; }
.recent-bar .movie-card { min-width: 130px; }
.recent-bar::-webkit-scrollbar { height: 4px; }
.recent-bar::-webkit-scrollbar-thumb { background: #2a2a5e; border-radius: 4px; }
.empty-state { color: #555; font-size: 14px; padding: 20px; text-align: center; }
</style>
</head>
<body>
<div class="container">
<h1>🕓 Recently Viewed</h1>
<p class="subtitle">Film yang pernah Anda lihat detailnya</p>

<div class="section-title">📋 Semua Film</div>
<div class="movie-grid" id="allMovies"></div>

<div class="section-title">🕓 Baru Dilihat</div>
<div class="recent-bar" id="recentBar"></div>
</div>
<script>
const STORAGE_KEY = 'movie_recently_viewed';

const allMovies = [
{ id: 1, title: 'Inception', year: 2010 },
{ id: 2, title: 'The Dark Knight', year: 2008 },
{ id: 3, title: 'Interstellar', year: 2014 },
{ id: 4, title: 'Parasite', year: 2019 },
{ id: 5, title: 'Spirited Away', year: 2001 },
{ id: 6, title: 'The Matrix', year: 1999 }
];

let recentMovies = JSON.parse(localStorage.getItem(STORAGE_KEY) || '[]');

function saveRecent() { localStorage.setItem(STORAGE_KEY, JSON.stringify(recentMovies)); }

function viewMovie(id) {
const movie = allMovies.find(m => m.id === id);
if (!movie) return;
recentMovies = [movie, ...recentMovies.filter(m => m.id !== id)].slice(0, 8);
saveRecent();
renderRecent();
alert(`Membuka detail: ${movie.title}`);
}

function removeRecent(id) {
recentMovies = recentMovies.filter(m => m.id !== id);
saveRecent();
renderRecent();
}

function renderAll() {
const grid = document.getElementById('allMovies');
grid.innerHTML = allMovies.map(m => `
<div class="movie-card" onclick="viewMovie(${m.id})">
  <div class="movie-poster">🎬</div>
  <div class="movie-info">
    <div class="movie-title">${m.title}</div>
  </div>
</div>
`).join('');
}

function renderRecent() {
const bar = document.getElementById('recentBar');
if (recentMovies.length === 0) {
bar.innerHTML = '<div class="empty-state">Belum ada film yang dilihat. Klik film di atas.</div>';
return;
}
bar.innerHTML = recentMovies.map(m => `
<div class="movie-card" onclick="viewMovie(${m.id})" style="cursor:pointer">
  <div class="movie-poster">🎬</div>
  <div class="movie-info">
    <div class="movie-title">${m.title}</div>
    <div class="movie-time">${m.year}</div>
  </div>
</div>
`).join('');
}

renderAll();
renderRecent();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Klik film untuk menambah ke recently viewed. Scroll horizontal di bagian bawah menampilkan riwayat.
