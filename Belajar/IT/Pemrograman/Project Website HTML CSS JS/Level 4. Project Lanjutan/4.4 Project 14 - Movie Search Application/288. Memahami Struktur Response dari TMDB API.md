# 288. Memahami Struktur Response dari TMDB API

## Definisi & Target
Mempelajari struktur JSON response dari TMDB API untuk search movie, movie details, dan trending.

## Analogi Alur
Struktur response TMDB seperti lemari arsip film: setiap film adalah folder dengan properti seperti judul, poster, rating, genre, dll.

## Poin-Poin Penting
- Search response: page, results[], total_pages, total_results
- Setiap movie: id, title, poster_path, overview, vote_average, release_date
- poster_path perlu digabung dengan base image URL
- genre_ids perlu di-mapping ke nama genre
- Detail movie: budget, revenue, runtime, genres[], cast[], crew[]
- Image URL format: https://image.tmdb.org/t/p/w500/{poster_path}
