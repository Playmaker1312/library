# 305. Memastikan Movie App Responsive dan Accessible

## Definisi & Target
Memastikan Movie App responsif di semua perangkat dan accessible untuk semua pengguna termasuk screen reader dan keyboard-only.

## Analogi Alur
Responsif dan accessible seperti membangun gedung dengan pintu lebar dan jalur kursi roda: tidak hanya untuk kebutuhan tertentu, tapi memudahkan semua orang mengakses.

## Poin-Poin Penting
- CSS Grid dengan auto-fit/auto-fill untuk responsif
- Media queries untuk mobile (< 480px), tablet (768px)
- Ukuran font relative (rem/em)
- Touch targets minimal 44x44px
- Alt text untuk poster gambar
- Skip navigation link
- Focus outline untuk keyboard navigation
- Aria labels untuk interactive elements
- Color contrast ratio WCAG AA
