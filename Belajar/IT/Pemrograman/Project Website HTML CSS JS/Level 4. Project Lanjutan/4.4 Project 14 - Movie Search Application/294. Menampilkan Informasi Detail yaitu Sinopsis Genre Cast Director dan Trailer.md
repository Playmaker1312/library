# 294. Menampilkan Informasi Detail yaitu Sinopsis, Genre, Cast, Director, dan Trailer

## Definisi & Target
Memperkaya modal detail film dengan informasi lengkap: sinopsis, genre, cast, director, dan trailer.

## Analogi Alur
Informasi detail seperti halaman Wikipedia film: semua informasi penting ada di satu halaman - cerita (sinopsis), kategori (genre), pemain (cast), sutradara (director), dan video (trailer).

## Poin-Poin Penting
- Sinopsis: paragraf overview
- Genre: badge/chip
- Cast: grid foto+karakter
- Director: nama sutradara
- Trailer: iframe YouTube embed
- Tabs atau seksi terpisah untuk informasi
- Data dari TMDB API detail endpoint
