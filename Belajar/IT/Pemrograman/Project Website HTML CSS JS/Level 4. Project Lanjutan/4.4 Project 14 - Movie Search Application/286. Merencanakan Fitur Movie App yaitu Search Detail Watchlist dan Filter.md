# 286. Merencanakan Fitur Movie App yaitu Search, Detail, Watchlist, dan Filter

## Definisi & Target
Merencanakan fitur-fitur Movie Search App: pencarian film, detail film, watchlist, dan filter.

## Analogi Alur
Movie App seperti katalog film di bioskop: Anda bisa mencari film (search), melihat sinopsis (detail), menyimpan film favorit (watchlist), dan memfilter berdasarkan genre.

## Poin-Poin Penting
- Search film dengan debounce
- Detail film: poster, sinopsis, genre, cast, rating
- Watchlist: simpan film ke daftar tontonan
- Filter: genre, tahun, rating
- Integrasi dengan TMDB API
- Infinite scroll untuk banyak hasil
- Responsive grid layout
