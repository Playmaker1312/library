# 300. Menampilkan Trending Movies menggunakan Endpoint Trending dari TMDB

## Definisi & Target
Menampilkan film-film yang sedang tren menggunakan endpoint trending dari TMDB API.

## Analogi Alur
Trending movies seperti papan trending di Twitter/X: menampilkan apa yang sedang populer saat ini. Film-film yang banyak dibicarakan dan ditonton muncul di sini.

## Poin-Poin Penting
- Endpoint: /trending/movie/week (atau /day)
- Tampilkan di halaman utama sebagai default
- Grid card yang sama dengan hasil search
- Auto-fetch saat halaman dimuat
- Badge "Trending" pada card
- Update periodik (setiap beberapa jam dari API)
- Sorting berdasarkan popularity dari API

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Trending Movies</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; padding: 20px; display: flex; justify-content: center; }
.container { max-width: 1100px; width: 100%; }
h1 { text-align: center; color: #667eea; margin: 20px 0; font-size: 24px; }
h1 span { color: #e94560; }
.subtitle { text-align: center; color: #888; font-size: 13px; margin-bottom: 20px; }
.movie-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(180px, 1fr)); gap: 16px; }
.movie-card { background: #1a1a3e; border: 1px solid #2a2a5e; border-radius: 14px; overflow: hidden; transition: all 0.3s; position: relative; }
.movie-card:hover { transform: translateY(-5px); border-color: #667eea; }
.trending-badge { position: absolute; top: 10px; left: 10px; background: rgba(233,69,96,0.9); color: white; padding: 4px 10px; border-radius: 6px; font-size: 11px; font-weight: 600; }
.movie-poster { width: 100%; aspect-ratio: 2/3; background: #12123a; display: flex; align-items: center; justify-content: center; font-size: 40px; }
.movie-info { padding: 12px 14px; }
.movie-title { color: #eee; font-size: 14px; font-weight: 600; white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }
.movie-meta { display: flex; justify-content: space-between; font-size: 12px; color: #888; margin-top: 4px; }
.movie-rating { color: #f39c12; }
.loading { text-align: center; padding: 40px; color: #888; display: none; }
.loading.show { display: block; }
.error-msg { text-align: center; padding: 30px; color: #e94560; display: none; }
.error-msg.show { display: block; }
</style>
</head>
<body>
<div class="container">
<h1>🔥 <span>Trending</span> Movies</h1>
<p class="subtitle">Film yang sedang populer minggu ini</p>
<div class="loading show" id="loading">⏳ Memuat film trending...</div>
<div class="error-msg" id="errorMsg">❌ Gagal memuat data. Gunakan data demo.</div>
<div class="movie-grid" id="movieGrid"></div>
</div>
<script>
const API_KEY = 'YOUR_TMDB_KEY';

const trendingMovies = [
{ title: 'Dune: Part Two', year: 2024, rating: 8.9, poster: '🎬' },
{ title: 'Deadpool & Wolverine', year: 2024, rating: 8.5, poster: '🎬' },
{ title: 'Inside Out 2', year: 2024, rating: 8.4, poster: '🎬' },
{ title: 'Kingdom of the Planet of the Apes', year: 2024, rating: 8.1, poster: '🎬' },
{ title: 'Furiosa', year: 2024, rating: 8.0, poster: '🎬' },
{ title: 'The Fall Guy', year: 2024, rating: 7.9, poster: '🎬' },
{ title: 'Godzilla x Kong', year: 2024, rating: 7.8, poster: '🎬' },
{ title: 'Civil War', year: 2024, rating: 7.7, poster: '🎬' }
];

async function fetchTrending() {
document.getElementById('loading').classList.add('show');
try {
const res = await fetch(`https://api.themoviedb.org/3/trending/movie/week?api_key=${API_KEY}`);
const data = await res.json();
if (!res.ok) throw new Error('API Error');
renderMovies(data.results.slice(0, 12));
} catch {
document.getElementById('errorMsg').classList.add('show');
renderMovies(trendingMovies);
}
document.getElementById('loading').classList.remove('show');
}

function renderMovies(movies) {
const grid = document.getElementById('movieGrid');
grid.innerHTML = movies.map(m => `
<div class="movie-card">
  <div class="trending-badge">🔥 Trending</div>
  <div class="movie-poster">${m.poster || '🎬'}</div>
  <div class="movie-info">
    <div class="movie-title">${m.title}</div>
    <div class="movie-meta">
      <span>${m.year || m.release_date?.split('-')[0] || 'N/A'}</span>
      <span class="movie-rating">★ ${m.rating || m.vote_average?.toFixed(1) || '?'}</span>
    </div>
  </div>
</div>
`).join('');
}

fetchTrending();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Ganti `YOUR_TMDB_KEY` dengan API key TMDB. Menampilkan film trending dengan badge "🔥 Trending".
