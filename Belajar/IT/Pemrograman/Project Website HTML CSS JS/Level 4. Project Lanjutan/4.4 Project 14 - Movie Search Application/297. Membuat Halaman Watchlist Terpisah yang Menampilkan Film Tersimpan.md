# 297. Membuat Halaman Watchlist Terpisah yang Menampilkan Film Tersimpan

## Definisi & Target
Membuat halaman terpisah yang menampilkan semua film yang sudah disimpan user ke watchlist.

## Analogi Alur
Halaman watchlist seperti rak buku pribadi: Anda bisa melihat semua film yang sudah Anda "beli" (simpan) untuk ditonton nanti, lengkap dengan informasi singkat.

## Poin-Poin Penting
- Halaman khusus watchlist yang hanya menampilkan film tersimpan
- Data dari LocalStorage, difilter dari daftar film lengkap
- Layout grid card yang sama dengan halaman utama
- Tampilkan pesan jika watchlist kosong
- Tombol hapus dari watchlist di setiap card
- Tombol "Hapus Semua" (clear all)
- Navigasi antara halaman utama dan watchlist

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>My Watchlist</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; padding: 20px; display: flex; justify-content: center; }
.container { max-width: 1000px; width: 100%; }
.nav { display: flex; gap: 10px; margin-bottom: 20px; }
.nav a { padding: 10px 24px; border-radius: 10px; text-decoration: none; font-size: 14px; font-weight: 600; transition: all 0.3s; }
.nav a.active { background: #667eea; color: white; }
.nav a:not(.active) { background: #12123a; color: #888; }
.header { display: flex; justify-content: space-between; align-items: center; margin-bottom: 20px; }
h1 { color: #667eea; font-size: 24px; }
.clear-btn { background: #e94560; color: white; border: none; padding: 8px 20px; border-radius: 8px; cursor: pointer; font-size: 13px; }
.clear-btn:hover { background: #d63851; }
.movie-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(180px, 1fr)); gap: 16px; }
.movie-card { background: #1a1a3e; border-radius: 14px; overflow: hidden; border: 1px solid #2a2a5e; position: relative; }
.movie-poster { width: 100%; aspect-ratio: 2/3; background: #12123a; display: flex; align-items: center; justify-content: center; font-size: 40px; }
.remove-btn { position: absolute; top: 10px; right: 10px; background: rgba(233,69,96,0.8); border: none; color: white; width: 32px; height: 32px; border-radius: 50%; cursor: pointer; font-size: 16px; display: flex; align-items: center; justify-content: center; }
.movie-info { padding: 12px 14px; }
.movie-title { color: #eee; font-size: 14px; font-weight: 600; }
.movie-year { color: #888; font-size: 12px; }
.empty-state { text-align: center; padding: 60px 20px; color: #555; background: #1a1a3e; border-radius: 16px; border: 1px solid #2a2a5e; }
.empty-state .icon { font-size: 48px; margin-bottom: 10px; }
.empty-state h3 { color: #888; margin-bottom: 5px; }
.empty-state p { color: #555; font-size: 14px; }
</style>
</head>
<body>
<div class="container">
<div class="nav">
<a href="#" class="active">📋 My Watchlist</a>
</div>
<div class="header">
<h1>📋 Watchlist Saya</h1>
<button class="clear-btn" onclick="clearAll()">🗑️ Hapus Semua</button>
</div>
<div class="movie-grid" id="movieGrid"></div>
</div>
<script>
const STORAGE_KEY = 'movie_watchlist';
const allMovies = [
{ id: 1, title: 'Inception', year: 2010 },
{ id: 2, title: 'The Dark Knight', year: 2008 },
{ id: 3, title: 'Interstellar', year: 2014 },
{ id: 4, title: 'Parasite', year: 2019 },
{ id: 5, title: 'Spirited Away', year: 2001 },
{ id: 6, title: 'The Matrix', year: 1999 },
{ id: 7, title: 'Your Name', year: 2016 },
{ id: 8, title: 'Avengers: Endgame', year: 2019 }
];

let watchlist = JSON.parse(localStorage.getItem(STORAGE_KEY) || '[]');

function save() { localStorage.setItem(STORAGE_KEY, JSON.stringify(watchlist)); }

function removeFromWatchlist(id) {
watchlist = watchlist.filter(w => w !== id);
save();
render();
}

function clearAll() {
if (watchlist.length === 0) return;
if (confirm('Hapus semua film dari watchlist?')) {
watchlist = [];
save();
render();
}
}

function render() {
const grid = document.getElementById('movieGrid');
const savedMovies = allMovies.filter(m => watchlist.includes(m.id));

if (savedMovies.length === 0) {
grid.innerHTML = `<div class="empty-state"><div class="icon">🎬</div><h3>Watchlist masih kosong</h3><p>Cari film dan klik ♡ untuk menambah ke watchlist</p></div>`;
return;
}

grid.innerHTML = savedMovies.map(m => `
<div class="movie-card">
  <div class="movie-poster">🎬</div>
  <button class="remove-btn" onclick="removeFromWatchlist(${m.id})">✕</button>
  <div class="movie-info">
    <div class="movie-title">${m.title}</div>
    <div class="movie-year">${m.year}</div>
  </div>
</div>
`).join('');
}

render();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Lihat daftar film yang disimpan. Klik ✕ untuk hapus satu film atau "Hapus Semua" untuk membersihkan watchlist.
