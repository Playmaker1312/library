# 296. Mengimplementasikan Fitur Watchlist menggunakan LocalStorage

## Definisi & Target
Membuat fitur watchlist yang memungkinkan user menyimpan film ke daftar tontonan menggunakan LocalStorage.

## Analogi Alur
Watchlist seperti keranjang belanja di toko online: Anda memasukkan film yang ingin ditonton nanti ke dalam keranjang. Data tetap ada meskipun Anda meninggalkan toko (menutup browser).

## Poin-Poin Penting
- Array watchlist di LocalStorage
- Tombol "Tambah ke Watchlist" / "Hapus dari Watchlist"
- Toggle icon: bookmark kosong/terisi
- Cegah duplikasi film
- Film yang sudah di watchlist ditandai (bookmark filled)
- Tampilkan jumlah film di watchlist (badge)
- Sinkronkan antar halaman dengan storage event

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Movie Watchlist</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: linear-gradient(135deg, #1a1a2e, #16213e); min-height: 100vh; padding: 20px; display: flex; justify-content: center; }
.container { max-width: 1000px; width: 100%; }
.header { display: flex; justify-content: space-between; align-items: center; margin-bottom: 20px; }
h1 { color: #e94560; font-size: 24px; }
.watchlist-count { background: #e94560; color: white; padding: 6px 14px; border-radius: 20px; font-size: 14px; font-weight: 600; }
.movie-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(180px, 1fr)); gap: 16px; }
.movie-card { background: #0f3460; border-radius: 14px; overflow: hidden; position: relative; }
.movie-poster { width: 100%; aspect-ratio: 2/3; background: #1a3a6e; display: flex; align-items: center; justify-content: center; font-size: 40px; }
.watchlist-btn { position: absolute; top: 10px; right: 10px; background: rgba(0,0,0,0.6); border: none; color: white; width: 36px; height: 36px; border-radius: 50%; cursor: pointer; font-size: 18px; display: flex; align-items: center; justify-content: center; transition: all 0.3s; }
.watchlist-btn:hover { transform: scale(1.15); }
.watchlist-btn.active { color: #e94560; background: rgba(233,69,96,0.2); }
.movie-info { padding: 12px 14px; }
.movie-title { color: #eee; font-size: 14px; font-weight: 600; }
.movie-year { color: #888; font-size: 12px; }
</style>
</head>
<body>
<div class="container">
<div class="header">
<h1>🎬 Watchlist</h1>
<span class="watchlist-count" id="watchlistCount">📋 0</span>
</div>
<div class="movie-grid" id="movieGrid"></div>
</div>
<script>
const STORAGE_KEY = 'movie_watchlist';
let watchlist = JSON.parse(localStorage.getItem(STORAGE_KEY) || '[]');

const movies = [
{ id: 1, title: 'Inception', year: 2010 },
{ id: 2, title: 'The Dark Knight', year: 2008 },
{ id: 3, title: 'Interstellar', year: 2014 },
{ id: 4, title: 'Parasite', year: 2019 },
{ id: 5, title: 'Spirited Away', year: 2001 },
{ id: 6, title: 'The Matrix', year: 1999 }
];

function saveWatchlist() { localStorage.setItem(STORAGE_KEY, JSON.stringify(watchlist)); }

function toggleWatchlist(id) {
const idx = watchlist.indexOf(id);
if (idx === -1) watchlist.push(id);
else watchlist.splice(idx, 1);
saveWatchlist();
renderCards();
}

function isInWatchlist(id) { return watchlist.includes(id); }

function renderCards() {
document.getElementById('watchlistCount').textContent = `📋 ${watchlist.length}`;
const grid = document.getElementById('movieGrid');
grid.innerHTML = movies.map(m => {
const inList = isInWatchlist(m.id);
return `<div class="movie-card">
  <div class="movie-poster">🎬</div>
  <button class="watchlist-btn ${inList ? 'active' : ''}" onclick="toggleWatchlist(${m.id})">${inList ? '♥' : '♡'}</button>
  <div class="movie-info">
    <div class="movie-title">${m.title}</div>
    <div class="movie-year">${m.year}</div>
  </div>
</div>`;
}).join('');
}

renderCards();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Klik ikon hati untuk menambah/hapus dari watchlist. Counter di header menunjukkan jumlah film tersimpan.
