# 293. Mengimplementasikan Modal Detail Film dengan Informasi Lengkap

## Definisi & Target
Membuat modal yang menampilkan informasi detail film ketika user mengklik card film.

## Analogi Alur
Modal detail seperti membuka amplop berisi brosur film: dari sampul (card) Anda melihat sekilas, lalu membuka amplop (modal) untuk membaca informasi lengkapnya.

## Poin-Poin Penting
- Modal overlay dengan background semi-transparan
- Konten modal: poster besar, judul, tahun, rating, sinopsis, genre
- Tombol close (X) dan klik di luar modal untuk menutup
- Animasi masuk/keluar modal (fade in, scale)
- Scrollable jika konten panjang
- Aksesibilitas: focus trap, escape to close
- Data detail bisa dari API atau data statis

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript
```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Movie Detail Modal</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #0f0c29; min-height: 100vh; padding: 20px; display: flex; justify-content: center; }

h1 { text-align: center; color: #667eea; margin: 20px 0; font-size: 24px; }

.movie-info { padding: 12px 14px; }

.movie-year { color: #888; font-size: 12px; }

<body>

<div class="modal-content">

</div>
</div>
</div>
<script>
const movies = [
{ title: 'Inception', year: 2010, rating: 8.8, overview: 'A thief who steals corporate secrets through dream-sharing technology is given the task of planting an idea into the mind of a CEO.', genres: ['Action', 'Sci-Fi', 'Thriller'] },
{ title: 'The Dark Knight', year: 2008, rating: 9.0, overview: 'When the menace known as the Joker wreaks havoc and chaos on Gotham, Batman must accept one of the greatest tests.', genres: ['Action', 'Crime', 'Drama'] },
{ title: 'Interstellar', year: 2014, rating: 8.6, overview: "A team of explorers travel through a wormhole in space in an attempt to ensure humanity's survival.", genres: ['Adventure', 'Drama', 'Sci-Fi'] }
];

function renderCards() {
const grid = document.getElementById('movieGrid');
grid.innerHTML = movies.map((m, i) => `
<div class="movie-card" onclick="openModal(${i})">
  <div class="movie-poster">🎬</div>
  <div class="movie-info">
    <div class="movie-title">${m.title}</div>
    <div class="movie-year">${m.year}</div>
  </div>
</div>
`).join('');
}

function openModal(idx) {
const m = movies[idx];
document.getElementById('modalTitle').textContent = m.title;
document.getElementById('modalYear').textContent = `${m.year} • ${m.genres.join(', ')}`;
document.getElementById('modalRating').textContent = `★ ${m.rating}`;
document.getElementById('modalGenres').innerHTML = m.genres.map(g => `<span class="genre">${g}</span>`).join('');
document.getElementById('modalOverview').textContent = m.overview;
document.getElementById('modal').classList.add('show');
document.body.style.overflow = 'hidden';
}

function closeModal() {
document.getElementById('modal').classList.remove('show');
document.body.style.overflow = '';
}

document.getElementById('modal').addEventListener('click', function(e) {
if (e.target === this) closeModal();
});
document.addEventListener('keydown', function(e) { if (e.key === 'Escape') closeModal(); });

renderCards();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai HTML. Klik card film untuk membuka modal detail. Klik di luar modal atau tekan Escape untuk menutup.
