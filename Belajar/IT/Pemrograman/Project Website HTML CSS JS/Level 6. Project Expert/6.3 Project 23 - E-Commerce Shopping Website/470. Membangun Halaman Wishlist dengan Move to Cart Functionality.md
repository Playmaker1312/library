# 470. Membangun Halaman Wishlist dengan Move to Cart Functionality

## Definisi & Target
Membangun halaman wishlist yang lengkap dengan fitur move to cart. User bisa memindahkan item dari wishlist ke cart, menghapus item, atau menambahkan semua item ke cart sekaligus.

## Analogi Alur
Seperti memindahkan barang dari "daftar incaran" ke "keranjang belanja": saat Anda siap membeli, satu klik untuk memindahkan barang dari wishlist ke cart.

## Poin-Poin Penting
- Halaman wishlist dengan grid produk
- Tombol "Move to Cart" per item
- Tombol "Add All to Cart" untuk semua item
- Badge counter di navbar
- Konfirmasi sebelum move to cart
- Empty state saat wishlist kosong

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Wishlist - Move to Cart</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f8f9fa; padding: 20px; }
.container { max-width: 900px; margin: 0 auto; }
header { display: flex; justify-content: space-between; align-items: center; margin-bottom: 30px; }
header h1 { color: #333; }
.header-actions { display: flex; gap: 10px; align-items: center; }
.header-actions .count { color: #888; font-size: 14px; }
.btn-add-all { padding: 10px 20px; background: #667eea; color: white; border: none; border-radius: 8px; cursor: pointer; font-size: 14px; font-weight: 600; }
.btn-add-all:hover { background: #5a6fd6; }
.wishlist-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(260px, 1fr)); gap: 20px; }
.wishlist-item {
  background: white;
  border-radius: 12px;
  overflow: hidden;
  box-shadow: 0 2px 8px rgba(0,0,0,0.06);
  transition: transform 0.3s;
  position: relative;
}
.wishlist-item:hover { transform: translateY(-5px); }
.wishlist-item .img { height: 200px; background: linear-gradient(135deg, #f0f2ff, #e8e8ff); display: flex; align-items: center; justify-content: center; font-size: 48px; }
.wishlist-item .info { padding: 15px; }
.wishlist-item .info h3 { font-size: 15px; color: #333; }
.wishlist-item .info .price { font-size: 20px; font-weight: bold; color: #e94560; margin: 5px 0; }
.wishlist-item .info .rating { color: #ffd93d; font-size: 13px; }
.wishlist-item .info .stock { font-size: 12px; color: #388e3c; margin: 5px 0; }
.wishlist-item .actions { padding: 0 15px 15px; display: flex; gap: 8px; }
.wishlist-item .actions button { flex: 1; padding: 10px; border: none; border-radius: 6px; cursor: pointer; font-size: 13px; font-weight: 600; transition: transform 0.2s; }
.wishlist-item .actions button:hover { transform: scale(1.02); }
.btn-move-cart { background: #667eea; color: white; }
.btn-remove { background: #ffe8e8; color: #e94560; }
.remove-icon { position: absolute; top: 10px; right: 10px; width: 32px; height: 32px; background: white; border-radius: 50%; display: flex; align-items: center; justify-content: center; cursor: pointer; box-shadow: 0 2px 8px rgba(0,0,0,0.1); font-size: 14px; }
.empty-state { text-align: center; padding: 60px; color: #888; grid-column: 1 / -1; }
.empty-state .icon { font-size: 64px; margin-bottom: 15px; }
.toast { position: fixed; bottom: 20px; right: 20px; background: #53d769; color: #1a1a2e; padding: 12px 24px; border-radius: 8px; font-weight: 600; font-size: 14px; transform: translateY(100px); opacity: 0; transition: all 0.3s; z-index: 200; }
.toast.show { transform: translateY(0); opacity: 1; }
</style>
</head>
<body>
<div class="container">
  <header>
    <h1>My Wishlist</h1>
    <div class="header-actions">
      <span class="count" id="wishlistCount">0 items</span>
      <button class="btn-add-all" id="addAllBtn" onclick="addAllToCart()">Add All to Cart</button>
    </div>
  </header>
  <div class="wishlist-grid" id="wishlistGrid"></div>
</div>
<div class="toast" id="toast"></div>
<script>
let wishlist = JSON.parse(localStorage.getItem('wishlist')) || [];
let products = [
  { id: 1, name: 'Wireless Headphones', price: 299, rating: 4.5, emoji: '🎧', inStock: true },
  { id: 2, name: 'Casual T-Shirt', price: 79, rating: 4.2, emoji: '👕', inStock: true },
  { id: 3, name: 'Smart Watch', price: 299, rating: 4.7, emoji: '⌚', inStock: true },
  { id: 4, name: 'Desk Lamp', price: 89, rating: 4.0, emoji: '💡', inStock: false },
  { id: 5, name: 'Backpack', price: 159, rating: 4.4, emoji: '🎒', inStock: true },
  { id: 6, name: 'Running Shoes', price: 249, rating: 4.6, emoji: '👟', inStock: true }
];

function showToast(msg) {
  const t = document.getElementById('toast');
  t.textContent = msg;
  t.classList.add('show');
  setTimeout(() => t.classList.remove('show'), 2000);
}

function getCart() { return JSON.parse(localStorage.getItem('cart')) || []; }
function saveCart(cart) { localStorage.setItem('cart', JSON.stringify(cart)); }

function moveToCart(id) {
  let cart = getCart();
  const product = products.find(p => p.id === id);
  if (!product) return;
  const existing = cart.find(c => c.id === id);
  if (existing) existing.qty = (existing.qty || 1) + 1;
  else cart.push({ ...product, qty: 1 });
  saveCart(cart);
  wishlist = wishlist.filter(w => w !== id);
  localStorage.setItem('wishlist', JSON.stringify(wishlist));
  render();
  showToast('✅ Moved to cart: ' + product.name);
}

function addAllToCart() {
  const items = products.filter(p => wishlist.includes(p.id) && p.inStock);
  if (items.length === 0) { showToast('No items to move'); return; }
  let cart = getCart();
  items.forEach(product => {
    const existing = cart.find(c => c.id === product.id);
    if (existing) existing.qty = (existing.qty || 1) + 1;
    else cart.push({ ...product, qty: 1 });
  });
  saveCart(cart);
  wishlist = [];
  localStorage.setItem('wishlist', JSON.stringify(wishlist));
  render();
  showToast('✅ Added ' + items.length + ' items to cart!');
}

function removeItem(id) {
  wishlist = wishlist.filter(w => w !== id);
  localStorage.setItem('wishlist', JSON.stringify(wishlist));
  render();
}

function render() {
  const grid = document.getElementById('wishlistGrid');
  const items = products.filter(p => wishlist.includes(p.id));
  document.getElementById('wishlistCount').textContent = items.length + ' items';
  document.getElementById('addAllBtn').style.display = items.length > 0 ? 'inline-block' : 'none';
  if (items.length === 0) {
    grid.innerHTML = '<div class="empty-state"><div class="icon">❤️</div><p>Your wishlist is empty</p></div>';
    return;
  }
  grid.innerHTML = items.map(p => `
    <div class="wishlist-item">
      <div class="remove-icon" onclick="removeItem(${p.id})">✕</div>
      <div class="img">${p.emoji}</div>
      <div class="info">
        <h3>${p.name}</h3>
        <div class="rating">${'★'.repeat(Math.floor(p.rating))}</div>
        <div class="price">Rp${p.price}k</div>
        <div class="stock">${p.inStock ? '✓ In Stock' : '✗ Out of Stock'}</div>
      </div>
      <div class="actions">
        <button class="btn-move-cart" onclick="moveToCart(${p.id})" ${p.inStock ? '' : 'disabled style="opacity:0.4"'}>🛒 Move to Cart</button>
        <button class="btn-remove" onclick="removeItem(${p.id})">🗑️ Remove</button>
      </div>
    </div>
  `).join('');
}

if (wishlist.length === 0) {
  wishlist = [1, 3, 5, 6];
  localStorage.setItem('wishlist', JSON.stringify(wishlist));
}
render();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan file HTML, buka di browser. Wishlist menampilkan produk dengan tombol "Move to Cart" per item. "Add All to Cart" untuk memindahkan semua item. Produk yang habis (out of stock) tidak bisa dipindahkan.
