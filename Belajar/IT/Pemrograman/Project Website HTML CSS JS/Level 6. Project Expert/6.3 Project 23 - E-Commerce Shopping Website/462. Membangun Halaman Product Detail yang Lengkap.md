# 462. Membangun Halaman Product Detail yang Lengkap

## Definisi & Target
Membangun halaman detail produk yang lengkap dengan image gallery, informasi produk, pilihan varian (ukuran/warna), tombol add to cart, dan bagian review.

## Analogi Alur
Seperti melihat barang di etalase toko: Anda bisa melihat dari berbagai sudut (gallery), membaca spesifikasi, memilih ukuran/warna, dan melihat review pembeli lain.

## Poin-Poin Penting
- Image gallery dengan thumbnail navigasi
- Nama produk, harga, rating, dan deskripsi
- Pilihan varian (ukuran, warna) dengan radio button
- Tombol Add to Cart dengan quantity selector
- Tab section: Description, Reviews, Shipping Info

<script>
function changeImage(img, el) {
  document.getElementById('mainImage').textContent = img;
  document.querySelectorAll('.thumbnail').forEach(t => t.classList.remove('active'));
  el.classList.add('active');
}
function changeQty(delta) {
  const input = document.getElementById('qty');
  let val = parseInt(input.value) + delta;
  if (val < 1) val = 1;
  input.value = val;
}
function addToCart() { alert('Added to cart! Quantity: ' + document.getElementById('qty').value); }
function toggleWishlist() { alert('Added to wishlist!'); }
function switchTab(btn, tab) {
  document.querySelectorAll('.tab-nav button').forEach(b => b.classList.remove('active'));
  document.querySelectorAll('.tab-content').forEach(t => t.classList.remove('active'));
  btn.classList.add('active');
  document.getElementById('tab-' + tab).classList.add('active');
}
</script>
