# 466. Membangun Halaman Checkout dengan Form yang Lengkap

## Definisi & Target
Membangun halaman checkout dengan form lengkap untuk mengumpulkan informasi pengiriman, alamat, dan metode pembayaran. Form mencakup validasi input.

## Analogi Alur
Seperti mengisi formulir pemesanan di kasir: Anda menulis nama, alamat pengiriman, nomor telepon, dan memilih cara pembayaran sebelum pesanan diproses.

## Poin-Poin Penting
- Form informasi pribadi (nama, email, telepon)
- Form alamat pengiriman (jalan, kota, provinsi, kode pos)
- Pilihan metode pengiriman (regular, express)
- Pilihan metode pembayaran (transfer, COD, kartu)
- Validasi form sebelum submit

<script>
function placeOrder() {
  let valid = true;
  const required = ['firstName', 'email', 'phone', 'address', 'city', 'postal'];
  required.forEach(id => {
    const el = document.getElementById(id);
    const err = document.getElementById('err-' + id);
    if (!el.value.trim()) {
      el.classList.add('input-error');
      if (err) err.style.display = 'block';
      valid = false;
    } else {
      el.classList.remove('input-error');
      if (err) err.style.display = 'none';
    }
  });
  if (!valid) { alert('Please fill in all required fields'); return; }
  const shipping = document.getElementById('shipping').value;
  const total = shipping === 'express' ? 731000 : 706000;
  document.getElementById('totalDisplay').textContent = 'Rp' + total.toLocaleString();
  alert('Order placed successfully!');
}

document.getElementById('shipping').onchange = function() {
  const total = this.value === 'express' ? 731000 : 706000;
  document.getElementById('totalDisplay').textContent = 'Rp' + total.toLocaleString();
  document.getElementById('shippingLabel').textContent = this.value === 'express' ? 'Rp25.000' : 'Free';
};
</script>

## Cara Integrasi
Simpan file HTML, buka di browser. Isi form checkout lengkap dengan informasi kontak, alamat pengiriman, dan metode pembayaran. Validasi form sebelum submit. Shipping method mempengaruhi total harga.
