# 460. Mengimplementasikan Sorting Berdasarkan Harga, Popularitas, dan Terbaru

## Definisi & Target
Mengimplementasikan fitur sorting untuk produk berdasarkan harga (termurah-termahal), popularitas (rating), dan terbaru (tanggal ditambahkan). User bisa memilih opsi sorting dari dropdown.

## Analogi Alur
Seperti mengatur buku di rak: Anda bisa menyusun dari harga termurah, rating tertinggi, atau yang baru masuk. Sorting membantu menemukan produk yang sesuai preferensi.

## Poin-Poin Penting
- Dropdown select untuk opsi sorting
- Opsi: Price Low-High, Price High-Low, Highest Rated, Newest
- Produk diurutkan ulang secara real-time
- Indikator arah sorting (ascending/descending)
- Default sorting berdasarkan popularitas

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html

<html lang="id">
<head>

.product-card .info .rating { color: #ffd93d; font-size: 13px; }
.product-card .info .date { font-size: 12px; color: #aaa; margin-top: 5px; }

</head>
<body>

      <label for="sortSelect">Sort by:</label>
      <select id="sortSelect" onchange="render()">

        <option value="price-asc">Price: Low to High</option>
        <option value="price-desc">Price: High to Low</option>

        <option value="oldest">Oldest First</option>

  </div>

<script>
const products = [
  { id: 1, name: 'Wireless Headphones', price: 149, rating: 4.5, date: '2025-06-01', emoji: '🎧' },
  { id: 2, name: 'Casual T-Shirt', price: 79, rating: 4.2, date: '2025-05-20', emoji: '👕' },
  { id: 3, name: 'Smart Watch', price: 299, rating: 4.7, date: '2025-06-10', emoji: '⌚' },

  { id: 6, name: 'Running Shoes', price: 249, rating: 4.6, date: '2025-06-12', emoji: '👟' },
  { id: 7, name: 'Bluetooth Speaker', price: 199, rating: 4.3, date: '2025-05-28', emoji: '🔊' },
  { id: 8, name: 'Throw Pillow', price: 49, rating: 3.8, date: '2025-04-20', emoji: '🛋️' },
  { id: 9, name: 'Sunglasses', price: 129, rating: 4.1, date: '2025-06-08', emoji: '🕶️' },
  { id: 10, name: 'Tablet Stand', price: 69, rating: 3.9, date: '2025-05-10', emoji: '📱' }
];

function sortProducts(products, sortBy) {
  const sorted = [...products];
  switch(sortBy) {
    case 'price-asc': sorted.sort((a, b) => a.price - b.price); break;
    case 'price-desc': sorted.sort((a, b) => b.price - a.price); break;
    case 'popular': sorted.sort((a, b) => b.rating - a.rating); break;
    case 'newest': sorted.sort((a, b) => new Date(b.date) - new Date(a.date)); break;
    case 'oldest': sorted.sort((a, b) => new Date(a.date) - new Date(b.date)); break;
    default: sorted.sort((a, b) => b.rating - a.rating);
  }
  return sorted;
}

function render() {
  const sortBy = document.getElementById('sortSelect').value;
  const sorted = sortProducts(products, sortBy);
  document.getElementById('resultCount').textContent = `Showing ${sorted.length} products`;
  const grid = document.getElementById('productGrid');
  grid.innerHTML = sorted.map(p => `
    <div class="product-card">
      <div class="img">${p.emoji}</div>
      <div class="info">
        <h3>${p.name}</h3>
        <div class="meta">
          <span class="price">Rp${p.price}k</span>
          <span class="rating">★ ${p.rating}</span>
        </div>
        <div class="date">Added: ${new Date(p.date).toLocaleDateString()}</div>
      </div>
    </div>
  `).join('');
}

render();
</script>
```

## Cara Integrasi
