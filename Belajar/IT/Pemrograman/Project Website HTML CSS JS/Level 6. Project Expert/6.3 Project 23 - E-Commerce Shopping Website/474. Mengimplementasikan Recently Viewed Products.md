# 474. Mengimplementasikan Recently Viewed Products

## Definisi & Target
Mengimplementasikan fitur recently viewed products yang menampilkan produk-produk yang pernah dilihat user. Data disimpan di LocalStorage dengan batasan jumlah produk yang disimpan.

## Analogi Alur
Seperti jejak kaki di pasir: saat Anda berjalan (melihat produk), jejak (riwayat) tertinggal dan bisa Anda lihat kembali untuk mengingat produk apa saja yang sudah Anda lihat.

## Poin-Poin Penting
- Array recently viewed disimpan di LocalStorage
- Setiap kali user melihat detail produk, id produk ditambahkan
- Maksimal 10 produk terakhir disimpan
- Duplikat dihilangkan (pindahkan ke posisi terbaru)
- Tampilkan di halaman home atau sidebar

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Recently Viewed</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f8f9fa; padding: 20px; }

<body>

  <div class="section recently-viewed">
    <h2>🕐 Recently Viewed <span class="count" id="recentCount">(0)</span></h2>
    <div class="product-grid" id="recentGrid"></div>
  </div>
  <div class="section all-products">
    <h2>📦 All Products</h2>
    <div class="product-grid" id="allGrid"></div>

<script>
const allProducts = [
  { id: 1, name: 'Wireless Headphones', price: 299, rating: 4.5, emoji: '🎧' },
  { id: 2, name: 'Casual T-Shirt', price: 79, rating: 4.2, emoji: '👕' },
  { id: 3, name: 'Smart Watch', price: 299, rating: 4.7, emoji: '⌚' },
  { id: 4, name: 'Desk Lamp', price: 89, rating: 4.0, emoji: '💡' },
  { id: 5, name: 'Backpack', price: 159, rating: 4.4, emoji: '🎒' },
  { id: 6, name: 'Running Shoes', price: 249, rating: 4.6, emoji: '👟' },
  { id: 7, name: 'Bluetooth Speaker', price: 199, rating: 4.3, emoji: '🔊' },
  { id: 8, name: 'Sunglasses', price: 129, rating: 4.1, emoji: '🕶️' },
  { id: 9, name: 'Tablet Stand', price: 69, rating: 3.9, emoji: '📱' },
  { id: 10, name: 'Throw Pillow', price: 49, rating: 3.8, emoji: '🛋️' }
];

function getRecent() {
  return JSON.parse(localStorage.getItem('recentlyViewed')) || [];
}

function saveRecent(recent) {
  localStorage.setItem('recentlyViewed', JSON.stringify(recent));
}

function viewProduct(id) {
  let recent = getRecent();
  recent = recent.filter(r => r.id !== id);
  const product = allProducts.find(p => p.id === id);
  if (product) {
    recent.unshift({ ...product, viewedAt: new Date().toISOString() });
    if (recent.length > 10) recent = recent.slice(0, 10);
    saveRecent(recent);
    render();
  }
}

function render() {
  const recent = getRecent();
  document.getElementById('recentCount').textContent = '(' + recent.length + ')';

  const recentGrid = document.getElementById('recentGrid');
  if (recent.length === 0) {
    recentGrid.innerHTML = '<div class="empty-state">No recently viewed products. Click on products below to add them here.</div>';
  } else {
    recentGrid.innerHTML = recent.map(p => {
      const timeAgo = getTimeAgo(new Date(p.viewedAt));
      return `<div class="product-card" onclick="viewProduct(${p.id})">
        <div class="badge">Viewed</div>
        <div class="img">${p.emoji}</div>
        <div class="info">
          <h3>${p.name}</h3>
          <div class="rating">${'★'.repeat(Math.floor(p.rating))}</div>
          <div class="price">Rp${p.price}k</div>
          <div class="view-time">${timeAgo}</div>
        </div>
      </div>`;
    }).join('');
  }

  const allGrid = document.getElementById('allGrid');
  allGrid.innerHTML = allProducts.map(p => `
    <div class="product-card" onclick="viewProduct(${p.id})">
      <div class="img">${p.emoji}</div>
      <div class="info">
        <h3>${p.name}</h3>
        <div class="rating">${'★'.repeat(Math.floor(p.rating))}</div>
        <div class="price">Rp${p.price}k</div>
      </div>
    </div>
  `).join('');
}

function getTimeAgo(date) {
  const sec = Math.floor((new Date() - date) / 1000);
  if (sec < 60) return 'Just now';
  const min = Math.floor(sec / 60);
  if (min < 60) return min + 'm ago';
  const hr = Math.floor(min / 60);
  if (hr < 24) return hr + 'h ago';
  const day = Math.floor(hr / 24);
  return day + 'd ago';
}

render();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan file HTML, buka di browser. Klik produk di bagian "All Products" untuk menambahkannya ke "Recently Viewed". Panggil `viewProduct(id)` dari halaman detail produk untuk mencatat kunjungan.
