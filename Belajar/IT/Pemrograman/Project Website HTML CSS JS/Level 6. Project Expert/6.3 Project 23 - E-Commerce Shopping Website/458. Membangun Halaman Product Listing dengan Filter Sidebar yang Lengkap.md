# 458. Membangun Halaman Product Listing dengan Filter Sidebar yang Lengkap

## Definisi & Target
Membangun halaman product listing dengan sidebar filter yang lengkap. Sidebar berisi filter kategori, rentang harga, rating, dan ketersediaan stok.

## Analogi Alur
Seperti katalog toko offline: Anda bisa memfilter berdasarkan jenis barang (kategori), harga, dan rating untuk menemukan produk yang tepat dengan cepat.

## Poin-Poin Penting
- Sidebar filter di kiri, grid produk di kanan
- Filter kategori menggunakan checkbox
- Filter harga dengan range slider
- Filter rating dengan bintang
- Jumlah produk yang cocok ditampilkan

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html

<html lang="id">

<title>Product Listing</title>
<style>

      <label><input type="checkbox" class="filter-category" value="home" checked> Home & Living</label>

<script>
const allProducts = [
  { id: 1, name: 'Wireless Headphones', price: 149, rating: 4.5, category: 'electronics', emoji: '🎧', inStock: true },
  { id: 2, name: 'Casual T-Shirt', price: 79, rating: 4.2, category: 'fashion', emoji: '👕', inStock: true },
  { id: 3, name: 'Smart Watch', price: 299, rating: 4.7, category: 'electronics', emoji: '⌚', inStock: true },
  { id: 4, name: 'Desk Lamp', price: 89, rating: 4.0, category: 'home', emoji: '💡', inStock: false },
  { id: 5, name: 'Backpack', price: 159, rating: 4.4, category: 'fashion', emoji: '🎒', inStock: true },
  { id: 6, name: 'Running Shoes', price: 249, rating: 4.6, category: 'fashion', emoji: '👟', inStock: true },
  { id: 7, name: 'Bluetooth Speaker', price: 199, rating: 4.3, category: 'electronics', emoji: '🔊', inStock: true },
  { id: 8, name: 'Throw Pillow', price: 49, rating: 3.8, category: 'home', emoji: '🛋️', inStock: true },
  { id: 9, name: 'Sunglasses', price: 129, rating: 4.1, category: 'fashion', emoji: '🕶️', inStock: true },
  { id: 10, name: 'Tablet Stand', price: 69, rating: 3.9, category: 'electronics', emoji: '📱', inStock: false }
];

function filterProducts() {
  const selectedCategories = Array.from(document.querySelectorAll('.filter-category:checked')).map(cb => cb.value);
  const maxPrice = parseInt(document.getElementById('priceFilter').value);
  const selectedRatings = Array.from(document.querySelectorAll('.filter-rating:checked')).map(cb => parseFloat(cb.value));
  const stockOnly = document.getElementById('stockFilter').checked;

  return allProducts.filter(p => {
    if (!selectedCategories.includes(p.category)) return false;
    if (p.price > maxPrice) return false;
    if (selectedRatings.length > 0 && !selectedRatings.some(r => p.rating >= r)) return false;
    if (stockOnly && !p.inStock) return false;
    return true;
  });
}

function renderProducts() {
  const filtered = filterProducts();
  document.getElementById('resultCount').textContent = `Showing ${filtered.length} of ${allProducts.length} products`;
  const grid = document.getElementById('productGrid');
  grid.innerHTML = filtered.map(p => `
    <div class="product-card">
      <div class="img">${p.emoji}</div>
      <div class="info">
        <h3>${p.name}</h3>
        <div class="rating">${'★'.repeat(Math.floor(p.rating))} ${p.rating}</div>
        <div class="price">Rp${p.price}k</div>
        <div class="stock ${p.inStock ? '' : 'out'}">${p.inStock ? '✓ In Stock' : '✗ Out of Stock'}</div>
      </div>
    </div>
  `).join('');
  if (filtered.length === 0) grid.innerHTML = '<div style="grid-column:1/-1;text-align:center;padding:40px;color:#888">No products match your filters</div>';
}

function resetFilters() {
  document.querySelectorAll('.filter-category').forEach(cb => cb.checked = true);
  document.getElementById('priceFilter').value = 500;
  document.getElementById('priceLabel').textContent = 'Rp500k+';
  document.querySelectorAll('.filter-rating').forEach(cb => cb.checked = false);
  document.getElementById('stockFilter').checked = false;
  renderProducts();
}

document.querySelectorAll('.filter-category, .filter-rating, #stockFilter').forEach(el => el.addEventListener('change', renderProducts));
document.getElementById('priceFilter').addEventListener('input', function() {
  document.getElementById('priceLabel').textContent = 'Rp' + this.value + 'k+';
  renderProducts();
});

renderProducts();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan file HTML, buka di browser. Sidebar filter di kiri dengan opsi kategori, harga, rating, dan stok. Produk terfilter secara real-time. Reset untuk mengembalikan semua filter ke default.
