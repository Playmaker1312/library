# 461. Mengimplementasikan View Toggle antara Grid dan List View

## Definisi & Target
Mengimplementasikan toggle view untuk menampilkan produk dalam format grid (card) atau list (baris). User bisa memilih tampilan yang paling nyaman untuk browsing produk.

## Analogi Alur
Seperti melihat koleksi sepatu: Grid view seperti melihat sepatu di rak display (banyak sekaligus), List view seperti melihat katalog dengan informasi detail setiap sepatu.

## Poin-Poin Penting
- Tombol toggle icon untuk grid dan list view
- Grid view: card dalam grid 3-4 kolom
- List view: baris horizontal dengan gambar di kiri, info di kanan
- View preference disimpan di LocalStorage
- Animasi transisi saat berganti view
