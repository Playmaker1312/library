# 468. Membangun Halaman Order Confirmation

## Definisi & Target
Membangun halaman konfirmasi pesanan yang muncul setelah user berhasil melakukan checkout. Halaman ini menampilkan detail pesanan, nomor order, estimasi pengiriman, dan ucapan terima kasih.

## Analogi Alur
Seperti struk pembayaran setelah checkout di supermarket: Anda mendapat bukti pembelian dengan nomor order, daftar barang, total pembayaran, dan informasi pengiriman.

## Poin-Poin Penting
- Animasi sukses (centang hijau)
- Nomor order unik (auto-generated)
- Detail pesanan: items, total, alamat pengiriman
- Estimasi pengiriman
- Tombol untuk lanjut belanja atau lihat order history
