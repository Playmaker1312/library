# 472. Membangun Halaman User Account dengan Order History

## Definisi & Target
Membangun halaman user account yang menampilkan profil user dan riwayat pesanan (order history). User bisa melihat daftar pesanan yang sudah dilakukan beserta statusnya.

## Analogi Alur
Seperti buku tabungan: Anda bisa melihat riwayat transaksi yang sudah dilakukan, status setiap pesanan (diproses, dikirim, selesai), dan detailnya.

## Poin-Poin Penting
- Sidebar navigasi akun (Profile, Orders, Wishlist, Settings)
- Daftar order history dengan status
- Setiap order menampilkan nomor order, tanggal, total, status
- Status dengan indikator warna
- Klik order untuk melihat detail
