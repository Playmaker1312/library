# 464. Membangun Halaman Cart dengan Quantity Control dan Subtotal

## Definisi & Target
Membangun halaman cart yang menampilkan daftar produk yang akan dibeli dengan kontrol quantity (+, -), subtotal per item, dan total keseluruhan. Fitur ini adalah pengembangan dari cart dasar.

## Analogi Alur
Seperti struk belanja yang bisa diedit: Anda bisa menambah/mengurangi jumlah barang, melihat harga per item dan total, sebelum menuju ke kasir.

## Poin-Poin Penting
- Quantity control dengan tombol plus/minus
- Subtotal per item (price x quantity)
- Total keseluruhan cart
- Update real-time saat quantity berubah
- Validasi stok saat menambah quantity

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Cart - Quantity Control</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f8f9fa; padding: 20px; }
.container { max-width: 900px; margin: 0 auto; }
h1 { color: #333; margin-bottom: 25px; }
.cart-layout { display: grid; grid-template-columns: 1fr 320px; gap: 25px; align-items: start; }
.cart-items { background: white; border-radius: 12px; padding: 20px; box-shadow: 0 2px 8px rgba(0,0,0,0.06); }
.cart-item { display: flex; gap: 15px; padding: 15px 0; border-bottom: 1px solid #f0f0f0; align-items: center; }
.cart-item:last-child { border-bottom: none; }
.cart-item .img { width: 80px; height: 80px; background: #f0f2ff; border-radius: 10px; display: flex; align-items: center; justify-content: center; font-size: 36px; flex-shrink: 0; }
.cart-item .details { flex: 1; }
.cart-item .details h3 { font-size: 15px; color: #333; margin-bottom: 3px; }
.cart-item .details .price { color: #888; font-size: 13px; }
.cart-item .details .remove { color: #e94560; font-size: 12px; cursor: pointer; margin-top: 5px; display: inline-block; }
.cart-item .qty-price { text-align: right; }
.qty-group { display: flex; align-items: center; gap: 5px; margin-bottom: 5px; justify-content: flex-end; }
.qty-group button { width: 32px; height: 32px; border: 1px solid #ddd; border-radius: 6px; background: white; cursor: pointer; font-size: 16px; display: flex; align-items: center; justify-content: center; }
.qty-group button:hover { background: #f0f2ff; }
.qty-group span { min-width: 30px; text-align: center; font-weight: 500; font-size: 15px; }
.cart-item .subtotal { font-weight: 600; color: #e94560; font-size: 16px; }
.summary-card { background: white; border-radius: 12px; padding: 25px; box-shadow: 0 2px 8px rgba(0,0,0,0.06); position: sticky; top: 20px; }
.summary-card h3 { color: #333; margin-bottom: 20px; font-size: 18px; }
.summary-row { display: flex; justify-content: space-between; padding: 8px 0; color: #555; font-size: 14px; }
.summary-row.total { font-weight: bold; font-size: 20px; color: #333; border-top: 2px solid #eee; padding-top: 15px; margin-top: 10px; }
.summary-row .value { font-weight: 500; }
.coupon-input { display: flex; gap: 8px; margin: 15px 0; }
.coupon-input input { flex: 1; padding: 10px; border: 1px solid #ddd; border-radius: 6px; font-size: 14px; }
.coupon-input button { padding: 10px 15px; background: #667eea; color: white; border: none; border-radius: 6px; cursor: pointer; font-size: 13px; }
.checkout-btn { width: 100%; padding: 14px; background: #e94560; color: white; border: none; border-radius: 8px; font-size: 16px; font-weight: 600; cursor: pointer; margin-top: 15px; }
.checkout-btn:hover { background: #d63851; }
.empty-state { text-align: center; padding: 60px; color: #888; }
</style>
</head>
<body>
<div class="container">
  <h1>Shopping Cart</h1>
  <div class="cart-layout">
    <div class="cart-items" id="cartItems"></div>
    <div class="summary-card" id="summaryCard"></div>
  </div>
</div>
<script>
let cart = JSON.parse(localStorage.getItem('cart')) || [];

function save() {
  localStorage.setItem('cart', JSON.stringify(cart));
  render();
}

function updateQty(id, delta) {
  const item = cart.find(i => i.id === id);
  if (!item) return;
  item.qty += delta;
  if (item.qty <= 0) {
    cart = cart.filter(i => i.id !== id);
  }
  save();
}

function removeItem(id) {
  cart = cart.filter(i => i.id !== id);
  save();
}

function render() {
  const itemsEl = document.getElementById('cartItems');
  const summaryEl = document.getElementById('summaryCard');
  if (cart.length === 0) {
    itemsEl.innerHTML = '<div class="empty-state"><div style="font-size:60px;margin-bottom:15px">🛒</div><p>Your cart is empty</p></div>';
    summaryEl.innerHTML = '';
    return;
  }
  let subtotal = 0;
  itemsEl.innerHTML = cart.map(item => {
    const total = item.price * item.qty;
    subtotal += total;
    return `<div class="cart-item">
      <div class="img">${item.emoji || '📦'}</div>
      <div class="details">
        <h3>${item.name}</h3>
        <div class="price">Rp${(item.price * 1000).toLocaleString()} each</div>
        <span class="remove" onclick="removeItem('${item.id}')">✕ Remove</span>
      </div>
      <div class="qty-price">
        <div class="qty-group">
          <button onclick="updateQty('${item.id}', -1)">−</button>
          <span>${item.qty}</span>
          <button onclick="updateQty('${item.id}', 1)">+</button>
        </div>
        <div class="subtotal">Rp${(total * 1000).toLocaleString()}</div>
      </div>
    </div>`;
  }).join('');

  const shipping = subtotal >= 500 ? 0 : 20;
  const total = subtotal + shipping;
  summaryEl.innerHTML = `
    <h3>Order Summary</h3>
    <div class="summary-row"><span>Subtotal</span><span class="value">Rp${(subtotal * 1000).toLocaleString()}</span></div>
    <div class="summary-row"><span>Shipping</span><span class="value">${shipping === 0 ? 'Free' : 'Rp' + (shipping * 1000).toLocaleString()}</span></div>
    <div class="coupon-input">
      <input type="text" placeholder="Coupon code">
      <button>Apply</button>
    </div>
    <div class="summary-row total"><span>Total</span><span class="value">Rp${(total * 1000).toLocaleString()}</span></div>
    <button class="checkout-btn" onclick="checkout()">Proceed to Checkout</button>
  `;
}

function checkout() { alert('Checkout with ' + cart.length + ' items. Total: Rp' + (cart.reduce((s,i)=>s+i.price*i.qty,0)*1000).toLocaleString()); }

if (cart.length === 0) {
  cart = [
    { id: 1, name: 'Wireless Headphones', price: 299, qty: 1, emoji: '🎧' },
    { id: 2, name: 'Casual T-Shirt', price: 79, qty: 2, emoji: '👕' },
    { id: 3, name: 'Running Shoes', price: 249, qty: 1, emoji: '👟' }
  ];
  save();
}
render();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan file HTML, buka di browser. Cart menampilkan quantity control (plus/minus), subtotal per item, dan total di summary card. Gratis ongkir untuk pembelian di atas Rp500.000.
