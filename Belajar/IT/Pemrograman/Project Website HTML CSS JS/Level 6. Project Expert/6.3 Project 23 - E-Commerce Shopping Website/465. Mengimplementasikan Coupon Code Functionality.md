# 465. Mengimplementasikan Coupon Code Functionality

## Definisi & Target
Mengimplementasikan fitur kupon diskon yang bisa diaplikasikan ke cart. Kode kupon yang valid akan memberikan persentase diskon atau nominal potongan tertentu.

## Analogi Alur
Seperti memotong kupon belanja di koran: Anda membawa kode kupon ke kasir, dan harga akan dipotong sesuai ketentuan kupon tersebut.

## Poin-Poin Penting
- Input field untuk memasukkan kode kupon
- Daftar kupon valid dengan tipe diskon (persen/nominal)
- Validasi kupon (aktif, belum expired, minimum purchase)
- Tampilkan diskon di summary
- Pesan error untuk kupon tidak valid

```html
<script>
const coupons = {
  'WELCOME10': { type: 'percent', value: 10, minPurchase: 0, desc: '10% off' },
  'SAVE50': { type: 'nominal', value: 50000, minPurchase: 300000, desc: 'Rp50.000 off' },
  'FREESHIP': { type: 'freeship', value: 0, minPurchase: 0, desc: 'Free shipping' }
};

let subtotal = 706000;
let activeCoupon = null;

function formatPrice(val) { return 'Rp' + val.toLocaleString(); }

function applyCoupon() {
  const code = document.getElementById('couponInput').value.trim().toUpperCase();
  const msg = document.getElementById('couponMsg');
  if (!code) { msg.className = 'coupon-msg error'; msg.textContent = 'Please enter a coupon code'; return; }
  if (!coupons[code]) { msg.className = 'coupon-msg error'; msg.textContent = 'Invalid coupon code'; return; }
  useCoupon(code);
}

function useCoupon(code) {
  const c = coupons[code];
  const msg = document.getElementById('couponMsg');
  document.getElementById('couponInput').value = code;
  if (subtotal < c.minPurchase) {
    msg.className = 'coupon-msg error';
    msg.textContent = 'Minimum purchase Rp' + c.minPurchase.toLocaleString() + ' required';
    return;
  }
  activeCoupon = code;
  msg.className = 'coupon-msg success';
  msg.textContent = 'Coupon applied: ' + c.desc;
  updateTotal();
}

function updateTotal() {
  const discRow = document.getElementById('discountRow');
  const discAmt = document.getElementById('discountAmount');
  const totalEl = document.getElementById('total');
  let discount = 0;
  if (activeCoupon) {
    const c = coupons[activeCoupon];
    if (c.type === 'percent') discount = subtotal * c.value / 100;
    else if (c.type === 'nominal') discount = c.value;
    discRow.style.display = 'flex';
    discAmt.textContent = '-' + formatPrice(discount);
  } else {
    discRow.style.display = 'none';
  }
  const total = subtotal - discount;
  totalEl.textContent = formatPrice(total);
}

function checkout() {
  const total = document.getElementById('total').textContent;
  alert('Checkout completed! Total payment: ' + total);
}

document.getElementById('couponInput').addEventListener('input', function() {
  if (!this.value) { activeCoupon = null; updateTotal(); document.getElementById('couponMsg').className = 'coupon-msg'; }
});

updateTotal();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan file HTML, buka di browser. Masukkan kode kupon (WELCOME10, SAVE50, FREESHIP) atau klik tombol "Use" di samping kupon. Diskon akan langsung terhitung di total. Validasi kupon termasuk minimum purchase.
