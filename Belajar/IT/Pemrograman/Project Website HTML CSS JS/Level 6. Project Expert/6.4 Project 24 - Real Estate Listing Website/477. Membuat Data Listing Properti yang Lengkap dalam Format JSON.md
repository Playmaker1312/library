# 477. Membuat Data Listing Properti yang Lengkap dalam Format JSON

## Definisi & Target
Membuat data properti dalam format JSON yang lengkap dengan field: id, judul, harga, lokasi, luas tanah, luas bangunan, kamar tidur, kamar mandi, deskripsi, gambar, fasilitas, dan koordinat.

## Analogi Alur
Seperti database agen properti: setiap properti memiliki kartu data lengkap yang mencatat semua informasi penting untuk ditampilkan ke calon pembeli.

## Poin-Poin Penting
- Data properti dalam array of objects
- Setiap properti memiliki ID unik
- Field lengkap: alamat, harga, spesifikasi, fasilitas
- Koordinat lat/lng untuk peta
- URL gambar (placeholder) untuk gallery
