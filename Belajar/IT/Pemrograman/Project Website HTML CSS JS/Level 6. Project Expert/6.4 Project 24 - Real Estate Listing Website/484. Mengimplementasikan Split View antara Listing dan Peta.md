# 484. Mengimplementasikan Split View antara Listing dan Peta

## Definisi & Target
Mengimplementasikan split view layout dengan listing properti di sisi kiri dan peta interaktif di sisi kanan. Saat properti di listing diklik, peta akan fokus ke marker tersebut.

## Analogi Alur
Seperti dashboard dengan dua panel: panel kiri berisi daftar properti (seperti katalog), panel kanan berisi peta (seperti navigasi). Keduanya terhubung dan sinkron.

## Poin-Poin Penting
- Layout dua kolom: listing (40%) dan peta (60%)
- Listing properti dalam scrollable list
- Klik item listing → peta zoom ke marker
- Klik marker → listing highlight item
- Responsive: stack vertikal di mobile

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Split View - Listing & Map</title>
<link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css">
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; height: 100vh; overflow: hidden; }
.split-view { display: flex; height: 100vh; }
.listing-panel { width: 400px; min-width: 300px; background: #f8f9fa; display: flex; flex-direction: column; border-right: 2px solid #e0e0e0; }
.listing-panel .header { padding: 20px; background: white; border-bottom: 1px solid #eee; }
.listing-panel .header h1 { color: #2c3e50; font-size: 20px; }
.listing-panel .header .count { color: #888; font-size: 14px; margin-top: 3px; }
.listing-items { flex: 1; overflow-y: auto; padding: 10px; }
.listing-item { background: white; border-radius: 8px; padding: 12px; margin-bottom: 8px; cursor: pointer; display: flex; gap: 12px; transition: all 0.2s; border: 2px solid transparent; }
.listing-item:hover { border-color: #3498db; }
.listing-item.active { border-color: #3498db; background: #f0f7ff; }
.listing-item .thumb { width: 70px; height: 70px; background: linear-gradient(135deg, #e8f4fd, #d1ecf1); border-radius: 8px; display: flex; align-items: center; justify-content: center; font-size: 28px; flex-shrink: 0; }
.listing-item .info { flex: 1; }
.listing-item .info h3 { font-size: 14px; color: #2c3e50; margin-bottom: 3px; }
.listing-item .info .price { font-size: 16px; font-weight: bold; color: #e74c3c; }
.listing-item .info .meta { font-size: 12px; color: #888; margin-top: 3px; }
.map-panel { flex: 1; }
#map { width: 100%; height: 100%; }
@media (max-width: 768px) {
  .split-view { flex-direction: column; }
  .listing-panel { width: 100%; height: 50%; border-right: none; border-bottom: 2px solid #e0e0e0; }
  .map-panel { height: 50%; }
}
</style>
</head>
<body>
<div class="split-view">
  <div class="listing-panel">
    <div class="header">
      <h1>Properties</h1>
      <div class="count" id="propertyCount">8 listings</div>
    </div>
    <div class="listing-items" id="listingItems"></div>
  </div>
  <div class="map-panel">
    <div id="map"></div>
  </div>
</div>
<script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"></script>
<script>
const properties = [
  { id: 1, title: "Modern Apartment", price: 850, beds: 3, baths: 2, lat: -6.2088, lng: 106.8456, emoji: "🏢" },
  { id: 2, title: "Luxury Villa", price: 2500, beds: 5, baths: 4, lat: -8.5069, lng: 115.2625, emoji: "🏡" },
  { id: 3, title: "Cozy Family House", price: 1200, beds: 4, baths: 3, lat: -6.9147, lng: 107.6098, emoji: "🏠" },
  { id: 4, title: "Studio Apartment", price: 450, beds: 1, baths: 1, lat: -6.2383, lng: 106.8316, emoji: "🏢" },
  { id: 5, title: "Minimalist House", price: 950, beds: 3, baths: 2, lat: -6.2418, lng: 106.9924, emoji: "🏠" },
  { id: 6, title: "Beachfront Villa", price: 3500, beds: 6, baths: 5, lat: -8.7099, lng: 115.1686, emoji: "🏡" },
  { id: 7, title: "Downtown Apartment", price: 650, beds: 2, baths: 1, lat: -6.1754, lng: 106.8272, emoji: "🏢" },
  { id: 8, title: "Garden House", price: 1500, beds: 4, baths: 3, lat: -6.5972, lng: 106.8067, emoji: "🏠" }
];

const map = L.map('map').setView([-6.5, 107], 7);
L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png', { maxZoom: 19 }).addTo(map);

const markers = {};
let activeId = null;

properties.forEach(p => {
  const marker = L.marker([p.lat, p.lng]).addTo(map);
  marker.bindPopup(`<strong>${p.title}</strong><br>Rp${p.price}M`);
  marker.on('click', () => highlightProperty(p.id));
  markers[p.id] = marker;
});

const bounds = properties.map(p => [p.lat, p.lng]);
map.fitBounds(bounds, { padding: [30, 30] });

const listingEl = document.getElementById('listingItems');
listingEl.innerHTML = properties.map(p => `
  <div class="listing-item" id="item-${p.id}" onclick="highlightProperty(${p.id})">
    <div class="thumb">${p.emoji}</div>
    <div class="info">
      <h3>${p.title}</h3>
      <div class="price">Rp${p.price}M</div>
      <div class="meta">🛏️ ${p.beds} · 🛁 ${p.baths}</div>
    </div>
  </div>
`).join('');

document.getElementById('propertyCount').textContent = properties.length + ' listings';

function highlightProperty(id) {
  if (activeId === id) return;
  if (activeId) document.getElementById('item-' + activeId)?.classList.remove('active');
  activeId = id;
  document.getElementById('item-' + id)?.classList.add('active');
  const p = properties.find(x => x.id === id);
  if (p) {
    map.setView([p.lat, p.lng], 14);
    markers[id].openPopup();
  }
}
</script>
</body>
</html>
```

## Cara Integrasi
Simpan file HTML, buka di browser. Daftar properti di kiri, peta di kanan. Klik item listing akan zoom peta ke marker. Klik marker akan highlight item di listing. Responsive di mobile (stack vertikal).
