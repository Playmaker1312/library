# 478. Membangun Halaman Home dengan Hero Search dan Featured Listings

## Definisi & Target
Membangun halaman utama real estate dengan hero section yang memiliki search bar besar, featured listings, dan statistik properti.

## Analogi Alur
Seperti papan reklame agen properti: gambar besar properti unggulan, form pencarian di tengah, dan daftar properti featured di bawahnya.

## Poin-Poin Penting
- Hero section dengan background gradient dan search bar
- Search bar untuk lokasi, tipe properti, dan harga
- Featured listings (properti unggulan)
- Statistik (jumlah properti, klien, dll)
- CTA untuk menghubungi agent
