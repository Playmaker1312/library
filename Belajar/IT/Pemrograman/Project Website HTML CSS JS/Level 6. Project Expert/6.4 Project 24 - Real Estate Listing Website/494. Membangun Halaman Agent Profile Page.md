# 494. Membangun Halaman Agent Profile Page

## Definisi & Target
Membangun halaman profil agen properti yang menampilkan informasi agen, daftar properti yang dijual, rating, ulasan klien, dan fitur kontak. Halaman ini membantu membangun kepercayaan pembeli.

## Analogi Alur
Seperti kartu nama digital seorang agen properti: foto, nama, nomor telepon, spesialisasi, dan testimoni dari klien sebelumnya — semua dalam satu halaman.

## Poin-Poin Penting
- Foto profil dan informasi agen
- Statistik (properti terjual, pengalaman, rating)
- Daftar properti listing milik agen
- Ulasan dan testimoni klien
- Formulir kontak agen
- Tombol WhatsApp dan telepon
