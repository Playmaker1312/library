# 481. Mengimplementasikan Filter Berdasarkan Tipe, Harga, Kamar, dan Lokasi

## Definisi & Target
Mengimplementasikan filter properti berdasarkan tipe (rumah, apartemen, villa), rentang harga, jumlah kamar, dan lokasi. Filter bekerja secara real-time saat user memilih opsi.

## Analogi Alur
Seperti menyaring properti di katalog: Anda memilih tipe properti, menentukan budget, jumlah kamar yang diinginkan, dan lokasi. Hasil akan muncul sesuai kriteria.

## Poin-Poin Penting
- Filter tipe dengan dropdown select
- Filter harga dengan input min-max
- Filter kamar tidur dengan dropdown
- Filter lokasi dengan input text
- Kombinasi filter (AND logic)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Property Filters</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background: #f0f2f5; padding: 20px; }
.container { max-width: 1200px; margin: 0 auto; }
h1 { color: #2c3e50; margin-bottom: 20px; }
.filter-bar {
  display: flex;
  gap: 15px;
  margin-bottom: 25px;

  border-radius: 12px;

.card .body h3 { font-size: 15px; color: #2c3e50; }

</head>
<body>
<div class="container">
  <h1>Find Property</h1>
  <div class="filter-bar">
    <div class="filter-group">
      <label>Location</label>
      <input type="text" id="fLocation" placeholder="Search location..." oninput="filter()">
    </div>
    <div class="filter-group">
      <label>Type</label>
      <select id="fType" onchange="filter()">
        <option value="">All Types</option>
        <option value="house">House</option>
        <option value="apartment">Apartment</option>
        <option value="villa">Villa</option>
      </select>
    </div>
    <div class="filter-group">
      <label>Min Price (Million)</label>
      <select id="fMinPrice" onchange="filter()">
        <option value="0">No Min</option>
        <option value="500">Rp500M</option>
        <option value="1000">Rp1M</option>
        <option value="2000">Rp2M</option>
        <option value="5000">Rp5M</option>
      </select>
    </div>
    <div class="filter-group">
      <label>Max Price (Million)</label>
      <select id="fMaxPrice" onchange="filter()">
        <option value="100000">No Max</option>
        <option value="500">Rp500M</option>
        <option value="1000">Rp1M</option>
        <option value="2000">Rp2M</option>
        <option value="5000">Rp5M</option>
      </select>
    </div>
    <div class="filter-group">
      <label>Bedrooms</label>
      <select id="fBeds" onchange="filter()">
        <option value="0">Any</option>

        <option value="2">2+</option>
        <option value="3">3+</option>
        <option value="4">4+</option>

  </div>
  <div class="result-count" id="resultCount">Showing 0 properties</div>

</div>
<script>
const properties = [
  { id: 1, title: "Modern Apartment City Center", price: 850, beds: 3, type: "apartment", location: "Jakarta Pusat", emoji: "🏢" },
  { id: 2, title: "Luxury Villa with Pool", price: 2500, beds: 5, type: "villa", location: "Bali", emoji: "🏡" },
  { id: 3, title: "Cozy Family House", price: 1200, beds: 4, type: "house", location: "Bandung", emoji: "🏠" },
  { id: 4, title: "Studio Apartment", price: 450, beds: 1, type: "apartment", location: "Jakarta Selatan", emoji: "🏢" },
  { id: 5, title: "Minimalist House", price: 950, beds: 3, type: "house", location: "Bekasi", emoji: "🏠" },
  { id: 6, title: "Beachfront Villa", price: 3500, beds: 6, type: "villa", location: "Bali", emoji: "🏡" },
  { id: 7, title: "Downtown Apartment", price: 650, beds: 2, type: "apartment", location: "Jakarta Pusat", emoji: "🏢" },
  { id: 8, title: "Garden House", price: 1500, beds: 4, type: "house", location: "Bogor", emoji: "🏠" }
];

function filter() {
  const location = document.getElementById('fLocation').value.toLowerCase();
  const type = document.getElementById('fType').value;
  const minPrice = parseInt(document.getElementById('fMinPrice').value);
  const maxPrice = parseInt(document.getElementById('fMaxPrice').value);
  const minBeds = parseInt(document.getElementById('fBeds').value);

  const result = properties.filter(p => {
    if (location && !p.location.toLowerCase().includes(location)) return false;
    if (type && p.type !== type) return false;
    if (p.price < minPrice) return false;
    if (p.price > maxPrice) return false;
    if (minBeds > 0 && p.beds < minBeds) return false;
    return true;
  });

  document.getElementById('resultCount').textContent = `Showing ${result.length} of ${properties.length} properties`;
  const grid = document.getElementById('propertyGrid');
  grid.innerHTML = result.map(p => `
    <div class="card">
      <div class="img">${p.emoji}</div>
      <div class="body">
        <h3>${p.title}</h3>
        <div class="price">Rp${p.price}M</div>
        <div class="details"><span>📍 ${p.location}</span><span>🛏️ ${p.beds}</span><span>🏷️ ${p.type}</span></div>
      </div>
    </div>
  `).join('');
  if (result.length === 0) grid.innerHTML = '<div style="grid-column:1/-1;text-align:center;padding:50px;color:#888">No properties found</div>';
}

function resetFilters() {
  document.getElementById('fLocation').value = '';
  document.getElementById('fType').value = '';
  document.getElementById('fMinPrice').value = '0';
  document.getElementById('fMaxPrice').value = '100000';
  document.getElementById('fBeds').value = '0';
  filter();
}

filter();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan file HTML, buka di browser. Filter bar di atas dengan opsi lokasi, tipe, harga min/max, dan kamar tidur. Hasil filter update real-time. Reset untuk mengembalikan ke default.
