# 493. Menambahkan Walkscore & School Rating pada Detail Properti

## Definisi & Target
Menambahkan indikator walk score dan rating sekolah pada halaman detail properti. Walk score menunjukkan seberapa ramah lingkungan untuk pejalan kaki, sementara school rating menampilkan kualitas sekolah di sekitar.

## Analogi Alur
Seperti ulasan Google yang menampilkan rating bintang — pembeli bisa langsung melihat skor lingkungan dan kualitas pendidikan sekitar properti tanpa riset manual.

## Poin-Poin Penting
- Walk score visual dengan progress bar berwarna
- School rating dengan bintang dan ulasan singkat
- Data dummy yang realistis
- Tampilan ringkas cocok untuk sidebar detail
- Kategori walk score (Walker's Paradise, Very Walkable, dll)

const schools = [
  { name: 'SDN 01 Menteng', type: 'SD', rating: 5, distance: '300 m', icon: '🏫' },

function init() {
  let score = 92;
  let circle = document.getElementById('wsCircle');

function renderSchools() {
  let list = document.getElementById('schoolList');
  list.innerHTML = schools.map(s => {
    let stars = '';
    for (let i = 1; i <= 5; i++) stars += `<span class="star ${i > s.rating ? 'empty' : ''}">&#9733;</span>`;

        <div class="type">${s.type} - ${s.distance}</div>

}
