# 489. Mengimplementasikan Mortgage Calculator menggunakan JavaScript

## Definisi & Target
Mengimplementasikan kalkulator KPR (mortgage) yang menghitung cicilan bulanan berdasarkan harga properti, uang muka (DP), suku bunga, dan tenor pinjaman.

## Analogi Alur
Seperti kalkulator pinjaman bank: Anda memasukkan harga rumah, DP, bunga, dan lama cicilan. Kalkulator akan menghitung berapa yang harus dibayar setiap bulan.

## Poin-Poin Penting
- Input: harga properti, DP (%), suku bunga (%), tenor (tahun)
- Hitung jumlah pinjaman (harga - DP)
- Hitung cicilan bulanan menggunakan formula anuitas
- Tabel amortisasi (opsional)
- Grafik perbandingan DP vs cicilan

function formatMoney(val) {
  return 'Rp' + Math.round(val).toLocaleString('id-ID');
}

function calculate() {
  const price = parseFloat(document.getElementById('price').value) || 0;
  const dpPercent = parseFloat(document.getElementById('dpPercent').value) || 0;
  const annualRate = parseFloat(document.getElementById('rate').value) || 0;
  const years = parseFloat(document.getElementById('tenure').value) || 1;

  const dp = price * (dpPercent / 100);
  const loan = price - dp;
  const months = years * 12;
  const monthlyRate = (annualRate / 100) / 12;

  let monthly;
  if (monthlyRate === 0) {
    monthly = loan / months;
  } else {
    monthly = loan * (monthlyRate * Math.pow(1 + monthlyRate, months)) / (Math.pow(1 + monthlyRate, months) - 1);
  }

  const totalPayment = monthly * months;
  const totalInterest = totalPayment - loan;

  document.getElementById('monthlyPayment').textContent = formatMoney(monthly);
  document.getElementById('loanAmount').textContent = formatMoney(loan);
  document.getElementById('totalPayment').textContent = formatMoney(totalPayment);
  document.getElementById('totalInterest').textContent = formatMoney(totalInterest);
}

function syncPrice(val) {
  document.getElementById('price').value = val;
  calculate();
}

function syncDP(val) {
  document.getElementById('dpPercent').value = val;
  calculate();
}

function syncRate(val) {
  document.getElementById('rate').value = val;
  calculate();
}

function syncTenure(val) {
  document.getElementById('tenure').value = val;
  calculate();
}

calculate();
</script>

Simpan file HTML, buka di browser. Masukkan harga properti, DP, bunga, dan tenor. Cicilan bulanan dihitung otomatis dengan formula anuitas. Detail pinjaman, total pembayaran, dan total bunga ditampilkan.
