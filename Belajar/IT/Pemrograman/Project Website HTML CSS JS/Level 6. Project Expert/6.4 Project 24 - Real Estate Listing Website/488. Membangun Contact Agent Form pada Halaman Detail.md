# 488. Membangun Contact Agent Form pada Halaman Detail

## Definisi & Target
Membangun form contact agent pada halaman detail properti. Form mengirimkan pesan ke agent properti dengan informasi nama, email, telepon, dan pesan dari calon pembeli.

## Analogi Alur
Seperti meninggalkan pesan di meja resepsionis: Anda menulis nama, kontak, dan pesan untuk agen properti. Agen akan menghubungi Anda kembali.

## Poin-Poin Penting
- Form dengan fields: name, email, phone, message
- Validasi input sebelum submit
- Pilihan jadwal tour (schedule)
- Submit button dengan feedback
- Informasi kontak agent (telepon, email)

function submitForm(e) {
  e.preventDefault();
  const name = document.getElementById('fName').value.trim();
  const email = document.getElementById('fEmail').value.trim();
  const phone = document.getElementById('fPhone').value.trim();
  if (!name || !email || !phone) {
    showToast('Please fill in required fields');
    return false;
  }
  showToast('✅ Message sent! Agent will contact you soon.');
  document.getElementById('contactForm').reset();
  return false;
}

function showToast(msg) {
  const t = document.getElementById('toast');
  t.textContent = msg;
  t.classList.add('show');
  setTimeout(() => t.classList.remove('show'), 3000);
}
</script>
