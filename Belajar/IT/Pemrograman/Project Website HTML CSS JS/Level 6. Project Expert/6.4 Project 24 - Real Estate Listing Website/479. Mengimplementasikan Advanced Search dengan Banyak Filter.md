# 479. Mengimplementasikan Advanced Search dengan Banyak Filter

## Definisi & Target
Mengimplementasikan advanced search dengan banyak filter untuk properti. Filter mencakup lokasi, tipe properti, rentang harga, jumlah kamar, luas tanah/bangunan, dan fasilitas.

## Analogi Alur
Seperti agen properti yang menanyakan preferensi detail: "Mau rumah atau apartemen? Budget berapa? Berapa kamar? Ada fasilitas apa saja?" untuk menemukan properti yang tepat.

## Poin-Poin Penting
- Filter lokasi dengan input text
- Filter tipe properti (house, apartment, villa)
- Rentang harga min-max
- Jumlah kamar tidur minimum
- Fasilitas checkbox (AC, Pool, Garage, etc.)

```html
<script>
const properties = [
  { id: 1, title: "Modern Apartment City Center", price: 850, beds: 3, baths: 2, type: "apartment", location: "Jakarta Pusat", emoji: "🏢", fasilitas: ["AC", "Security", "Parkir"] },
  { id: 2, title: "Luxury Villa with Pool", price: 2500, beds: 5, baths: 4, type: "villa", location: "Bali", emoji: "🏡", fasilitas: ["AC", "Pool", "Garage"] },
  { id: 3, title: "Cozy Family House", price: 1200, beds: 4, baths: 3, type: "house", location: "Bandung", emoji: "🏠", fasilitas: ["AC", "Security", "Garage"] },
  { id: 4, title: "Studio Apartment", price: 450, beds: 1, baths: 1, type: "apartment", location: "Jakarta Selatan", emoji: "🏢", fasilitas: ["AC", "Security"] },
  { id: 5, title: "Minimalist House", price: 950, beds: 3, baths: 2, type: "house", location: "Bekasi", emoji: "🏠", fasilitas: ["AC", "Garage"] },
  { id: 6, title: "Beachfront Villa", price: 3500, beds: 6, baths: 5, type: "villa", location: "Bali", emoji: "🏡", fasilitas: ["AC", "Pool", "Garage", "Security"] },
  { id: 7, title: "Downtown Apartment", price: 650, beds: 2, baths: 1, type: "apartment", location: "Jakarta Pusat", emoji: "🏢", fasilitas: ["AC", "Security"] }
];

function filter() {
  const location = document.getElementById('fLocation').value.toLowerCase();
  const type = document.getElementById('fType').value;
  const priceMin = parseFloat(document.getElementById('fPriceMin').value) || 0;
  const priceMax = parseFloat(document.getElementById('fPriceMax').value) || Infinity;
  const minBeds = parseInt(document.getElementById('fBeds').value);
  const selectedFas = Array.from(document.querySelectorAll('.fFas:checked')).map(cb => cb.value);

  const result = properties.filter(p => {
    if (location && !p.location.toLowerCase().includes(location)) return false;
    if (type && p.type !== type) return false;
    if (p.price < priceMin || p.price > priceMax) return false;
    if (minBeds > 0 && p.beds < minBeds) return false;
    if (selectedFas.length > 0 && !selectedFas.every(f => p.fasilitas.includes(f))) return false;
    return true;
  });

  document.getElementById('resultCount').textContent = `Showing ${result.length} properties`;
  const grid = document.getElementById('listingGrid');
  grid.innerHTML = result.map(p => `
    <div class="card">
      <div class="img">${p.emoji}</div>
      <div class="body">
        <h3>${p.title}</h3>
        <div class="price">Rp${p.price}M</div>
        <div class="meta">📍 ${p.location} · 🛏️ ${p.beds} · 🛁 ${p.baths}</div>
        <div class="fas">${p.fasilitas.join(' · ')}</div>
      </div>
    </div>
  `).join('');
  if (result.length === 0) grid.innerHTML = '<div style="grid-column:1/-1;text-align:center;padding:40px;color:#888">No properties match your criteria</div>';
}

function resetFilters() {
  document.getElementById('fLocation').value = '';
  document.getElementById('fType').value = '';
  document.getElementById('fPriceMin').value = '';
  document.getElementById('fPriceMax').value = '';
  document.getElementById('fBeds').value = '0';
  document.querySelectorAll('.fFas').forEach(cb => cb.checked = false);
  filter();
}

filter();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan file HTML, buka di browser. Gunakan filter di sidebar untuk menyaring properti: lokasi, tipe, harga, kamar, dan fasilitas. Reset untuk mengembalikan ke default.
