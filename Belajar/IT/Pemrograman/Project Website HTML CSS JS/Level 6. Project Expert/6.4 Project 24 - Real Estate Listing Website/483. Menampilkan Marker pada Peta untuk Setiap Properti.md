# 483. Menampilkan Marker pada Peta untuk Setiap Properti

## Definisi & Target
Menampilkan marker pada peta untuk setiap properti. Marker memiliki icon kustom dan popup yang menampilkan informasi properti. Marker bisa diklik untuk melihat detail.

## Analogi Alur
Seperti pin di peta: setiap properti ditandai dengan pin berwarna. Pin yang berbeda warna bisa menandakan tipe properti (rumah, apartemen, villa).

## Poin-Poin Penting
- Marker untuk setiap properti dari data JSON
- Custom icon untuk marker (emoji atau icon)
- Popup dengan info: judul, harga, gambar
- Klik marker untuk zoom ke lokasi
- Cluster markers jika terlalu rapat

Simpan file HTML, buka di browser. Marker kustom dengan warna berbeda per tipe properti. Hover untuk melihat popup. Legend di pojok kanan bawah. Peta otomatis menyesuaikan zoom ke semua marker.
