# 487. Menampilkan Virtual Tour menggunakan Iframe Embed

## Definisi & Target
Menampilkan virtual tour properti menggunakan iframe embed dari platform seperti YouTube, Google Street View, atau Matterport. Virtual tour memberikan pengalaman melihat properti secara 360 derajat.

## Analogi Alur
Seperti melihat rumah secara online dengan Google Street View: Anda bisa "berjalan" di dalam properti secara virtual, melihat setiap sudut ruangan tanpa harus datang langsung.

## Poin-Poin Penting
- Virtual tour section di halaman detail properti
- Embed iframe untuk konten 360
- Tab toggle antara foto dan virtual tour
- Loading state saat iframe dimuat
- Responsive aspect ratio

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html

function switchTab(el, name) {
  document.querySelectorAll('.tab').forEach(t => t.classList.remove('active'));
```

## Cara Integrasi
Simpan file HTML, buka di browser. Tab "Virtual Tour" menampilkan video 360 embed. Tab "Photos" menampilkan gallery. Ganti URL iframe dengan embed link dari platform virtual tour yang digunakan.
