# 444. Mengkonfigurasi CodeMirror untuk HTML, CSS, dan JavaScript

## Definisi & Target
Mengkonfigurasi CodeMirror secara optimal untuk setiap bahasa (HTML, CSS, JavaScript) dengan fitur seperti auto-closing tags, auto-complete, bracket matching, indent guides, dan key bindings.

## Analogi Alur
Seperti menyetel editor favorit: Anda mengatur font, tab size, shortcut, dan fitur bantuan agar coding lebih produktif. Ini adalah kustomisasi editor untuk kenyamanan maksimal.

## Poin-Poin Penting
- Konfigurasi spesifik per bahasa editor
- Fitur autoCloseTags untuk HTML, autoCloseBrackets untuk JS
- Tab size, indent unit, line wrapping
- Key bindings (default, emacs, vim, sublime)
- Extra keys untuk shortcut umum

const baseConfig = {
  lineNumbers: true,
  styleActiveLine: true,
  matchBrackets: true,
  foldGutter: true,
  gutters: ['CodeMirror-linenumbers', 'CodeMirror-foldgutter'],
  extraKeys: {'Ctrl-Q': function(cm){ cm.foldCode(cm.getCursor()); }},
  indentUnit: 2,
  tabSize: 2,
  indentWithTabs: false,
  lineWrapping: true
};

const htmlEditor = CodeMirror.fromTextArea(document.getElementById('htmlEditor'), {
  ...baseConfig,
  mode: 'xml',
  autoCloseTags: true,
  theme: 'dracula'
});

const cssEditor = CodeMirror.fromTextArea(document.getElementById('cssEditor'), {
  ...baseConfig,
  mode: 'css',
  theme: 'dracula'
});

const jsEditor = CodeMirror.fromTextArea(document.getElementById('jsEditor'), {
  ...baseConfig,
  mode: 'javascript',
  autoCloseBrackets: true,
  theme: 'dracula'
});

const editors = [htmlEditor, cssEditor, jsEditor];
const preview = document.getElementById('preview');

function updatePreview() {
  const doc = `<!DOCTYPE html>
<html><head><style>${cssEditor.getValue()}</style></head>
<body>${htmlEditor.getValue()}
<script>${jsEditor.getValue()}<\/script>
</body></html>`;
  preview.srcdoc = doc;
}

editors.forEach(e => e.on('change', updatePreview));

function changeTheme(theme) { editors.forEach(e => e.setOption('theme', theme)); }
function changeFontSize(size) { editors.forEach(e => e.getWrapperElement().style.fontSize = size + 'px'); }
function changeTabSize(size) { editors.forEach(e => { e.setOption('tabSize', Number(size)); e.setOption('indentUnit', Number(size)); }); }
function toggleWrap(val) { editors.forEach(e => e.setOption('lineWrapping', val)); }

updatePreview();
</script>
</body>
</html>

## Cara Integrasi
Simpan file HTML, buka di browser. Toolbar untuk mengatur theme, font size, tab size, dan line wrap. Konfigurasi optimal untuk setiap bahasa dengan auto-closing, bracket matching, folding, dan active line highlighting.
