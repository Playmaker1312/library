# 445. Mengimplementasikan Live Preview yang Update saat Kode Berubah

## Definisi & Target
Mengimplementasikan live preview yang memperbarui tampilan secara otomatis saat kode di editor HTML, CSS, atau JavaScript berubah. Preview menggunakan iframe dengan srcdoc attribute.

## Analogi Alur
Seperti cermin ajaib: apa yang Anda tulis di editor langsung terlihat hasilnya di preview. Setiap perubahan karakter langsung dirender ulang tanpa perlu refresh manual.

## Poin-Poin Penting
- Menggunakan iframe dengan attribute srcdoc
- Update preview setiap kali editor content berubah (change event)
- Membangun HTML dokumen lengkap dari ketiga editor
- Script di-inject dengan aman ke dalam iframe
- Preview tidak memiliki akses ke halaman induk (sandboxed)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Live Preview</title>
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/codemirror.min.css">
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/theme/dracula.min.css">
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; height: 100vh; overflow: hidden; background: #1a1a2e; }
.app { display: grid; grid-template-rows: 1fr 1fr; height: 100vh; }
.top-panel {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 4px;
  padding: 4px;
  background: #0f3460;
}
.editor-panel { display: flex; flex-direction: column; background: #16213e; border-radius: 6px; overflow: hidden; }
.editor-panel .header { background: #0f3460; padding: 8px 12px; font-size: 12px; color: #e94560; display: flex; justify-content: space-between; }
.editor-panel .CodeMirror { flex: 1; height: auto !important; font-size: 13px; }
.bottom-panel { background: #0f3460; padding: 4px; position: relative; }
.preview-frame { width: 100%; height: 100%; background: white; border-radius: 6px; border: none; }
.status-bar {
  position: absolute;
  bottom: 12px;
  right: 12px;
  background: rgba(0,0,0,0.7);
  color: #53d769;
  padding: 4px 10px;
  border-radius: 4px;
  font-size: 11px;
  pointer-events: none;
}
</style>
</head>
<body>
<div class="app">
  <div class="top-panel">
    <div class="editor-panel">
      <div class="header"><span>HTML</span><span id="htmlStatus">0 lines</span></div>
      <textarea id="htmlEditor"><div style="padding:20px;font-family:Arial">
  <h1>Live Preview</h1>
  <p>Type here to see changes</p>
</div></textarea>
    </div>
    <div class="editor-panel">
      <div class="header"><span>CSS</span><span id="cssStatus">0 lines</span></div>
      <textarea id="cssEditor">h1 { color: #667eea; }
p { font-size: 18px; }</textarea>
    </div>
    <div class="editor-panel">
      <div class="header"><span>JavaScript</span><span id="jsStatus">0 lines</span></div>
      <textarea id="jsEditor">console.log('Preview updated');
document.querySelector('h1').style.borderBottom = '2px solid #e94560';</textarea>
    </div>
  </div>
  <div class="bottom-panel">
    <iframe class="preview-frame" id="preview" sandbox="allow-scripts"></iframe>
    <div class="status-bar" id="previewStatus">Ready</div>
  </div>
</div>
<script src="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/codemirror.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/mode/xml/xml.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/mode/css/css.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/mode/javascript/javascript.min.js"></script>
<script>
const htmlEditor = CodeMirror.fromTextArea(document.getElementById('htmlEditor'), { mode: 'xml', theme: 'dracula', lineNumbers: true });
const cssEditor = CodeMirror.fromTextArea(document.getElementById('cssEditor'), { mode: 'css', theme: 'dracula', lineNumbers: true });
const jsEditor = CodeMirror.fromTextArea(document.getElementById('jsEditor'), { mode: 'javascript', theme: 'dracula', lineNumbers: true });
const preview = document.getElementById('preview');
const previewStatus = document.getElementById('previewStatus');

function updatePreview() {
  const html = htmlEditor.getValue();
  const css = cssEditor.getValue();
  const js = jsEditor.getValue();

  const doc = ko.observableArray`<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<style>${css}</style>
</head>
<body>${html}
<script>${js}<\/script>
</body>
</html>`;

  preview.srcdoc = doc;
  previewStatus.textContent = 'Updated ' + new Date().toLocaleTimeString();
}

htmlEditor.on('change', () => {
  document.getElementById('htmlStatus').textContent = htmlEditor.lineCount() + ' lines';
  updatePreview();
});
cssEditor.on('change', () => {
  document.getElementById('cssStatus').textContent = cssEditor.lineCount() + ' lines';
  updatePreview();
});
jsEditor.on('change', () => {
  document.getElementById('jsStatus').textContent = jsEditor.lineCount() + ' lines';
  updatePreview();
});

updatePreview();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan file HTML, buka di browser. Setiap perubahan di editor (HTML, CSS, atau JS) akan langsung memperbarui preview. Status bar menunjukkan waktu update terakhir. Line count ditampilkan di setiap header editor.
