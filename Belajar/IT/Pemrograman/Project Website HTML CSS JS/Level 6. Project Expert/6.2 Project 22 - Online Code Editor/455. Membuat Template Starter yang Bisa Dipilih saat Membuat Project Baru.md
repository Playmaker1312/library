# 455. Membuat Template Starter yang Bisa Dipilih saat Membuat Project Baru

## Definisi & Target
Membuat template starter yang bisa dipilih user saat membuat project baru. Template adalah kode awal siap pakai untuk berbagai jenis project seperti halaman kosong, landing page, form, dashboard, dll.

## Analogi Alur
Seperti template dokumen di Microsoft Word: saat membuat dokumen baru, Anda bisa memilih template (resume, surat, laporan) yang sudah memiliki struktur dan konten awal.

## Poin-Poin Penting
- Daftar template: Blank, Landing Page, Contact Form, Dashboard, Portfolio, Blog
- Setiap template memiliki HTML, CSS, JS lengkap
- Modal pemilihan template sebelum project dibuat
- Preview thumbnail atau deskripsi template
- Template dimuat ke editor saat dipilih
