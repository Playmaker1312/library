# 446. Mengimplementasikan Debounce pada Update Preview untuk Performa

## Definisi & Target
Mengimplementasikan debounce pada update preview untuk mencegah terlalu banyak render ulang saat user mengetik dengan cepat. Debounce menunda eksekusi hingga user berhenti mengetik selama periode tertentu.

## Analogi Alur
Seperti menunggu percakapan telepon selesai sebelum mencatat pesan: tidak perlu mencatat setiap kata yang diucapkan, cukup catat setelah lawan bicara selesai berbicara (berhenti sejenak).

## Poin-Poin Penting
- Debounce menunda update preview 300ms setelah user berhenti mengetik
- Mencegah layout shift dan lag pada preview
- Mengurangi beban render iframe
- Implementasi debounce function murni JavaScript
- Visual feedback (spinner/indicator) saat menunggu update

const htmlEditor = CodeMirror.fromTextArea(document.getElementById('htmlEditor'), { mode: 'xml', theme: 'dracula', lineNumbers: true });
const cssEditor = CodeMirror.fromTextArea(document.getElementById('cssEditor'), { mode: 'css', theme: 'dracula', lineNumbers: true });
const jsEditor = CodeMirror.fromTextArea(document.getElementById('jsEditor'), { mode: 'javascript', theme: 'dracula', lineNumbers: true });
const preview = document.getElementById('preview');
const statusBar = document.getElementById('statusBar');
const debounceIndicator = document.getElementById('debounceIndicator');

function debounce(fn, delay) {
  let timer = null;
  return function(...args) {
    if (timer) clearTimeout(timer);
    debounceIndicator.classList.add('active');
    timer = setTimeout(() => {
      fn.apply(this, args);
      timer = null;
      debounceIndicator.classList.remove('active');
      statusBar.textContent = 'Updated ' + new Date().toLocaleTimeString();
    }, delay);
  };
}

function updatePreview() {
  const html = htmlEditor.getValue();
  const css = cssEditor.getValue();
  const js = jsEditor.getValue();
  const doc = `<!DOCTYPE html>
<html><head><meta charset="UTF-8">
<style>${css}</style></head>
<body>${html}
<script>${js}<\/script>
</body></html>`;
  preview.srcdoc = doc;
}

const debouncedUpdate = debounce(updatePreview, 300);

htmlEditor.on('change', debouncedUpdate);
cssEditor.on('change', debouncedUpdate);
jsEditor.on('change', debouncedUpdate);

updatePreview();
statusBar.textContent = 'Ready';
</script>
</body>
</html>

## Cara Integrasi
Simpan file HTML, buka di browser. Ketik dengan cepat di editor manapun. Indicator "⏳ Waiting..." muncul saat debounce aktif. Preview hanya update setelah 300ms idle. Status bar menunjukkan waktu update terakhir.
