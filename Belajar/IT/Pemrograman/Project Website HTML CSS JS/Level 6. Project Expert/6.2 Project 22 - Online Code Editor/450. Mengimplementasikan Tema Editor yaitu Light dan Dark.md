# 450. Mengimplementasikan Tema Editor yaitu Light dan Dark

## Definisi & Target
Mengimplementasikan pergantian tema editor antara light dan dark. Tema mencakup warna background editor, syntax highlighting, warna panel, dan tampilan preview.

## Analogi Alur
Seperti mode gelap/terang di aplikasi modern: satu tombol untuk mengubah seluruh tampilan dari tema gelap (dark) ke tema terang (light) sesuai preferensi user.

## Poin-Poin Penting
- Toggle button untuk switch light/dark theme
- Tema dark: dracula atau monokai
- Tema light: default, eclipse, atau xq-light
- Menyimpan preferensi tema di LocalStorage
- Animasi transisi saat berganti tema

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">

<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/theme/dracula.min.css">

<style>

}
body.dark .theme-toggle button { background: #e94560; color: white; }

<body class="dark" id="appBody">

  <div class="toolbar">
    <h2 style="font-size:18px">⚡ Code Editor</h2>

      <span id="themeLabel">Dark Theme</span>
      <button onclick="toggleTheme()" id="themeBtn">☀️ Light</button>

  <div class="top-panel">
    <div class="editor-panel">
      <div class="header">HTML</div>
      <textarea id="htmlEditor"><h1>Theme Demo</h1><p>Switch between light and dark</p></textarea>

  </div>

<script src="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/codemirror.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/mode/xml/xml.min.js"></script>

<script src="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/mode/javascript/javascript.min.js"></script>
<script>
let isDark = true;

const htmlEditor = CodeMirror.fromTextArea(document.getElementById('htmlEditor'), {
  mode: 'xml', theme: 'dracula', lineNumbers: true
});
const cssEditor = CodeMirror.fromTextArea(document.getElementById('cssEditor'), {
  mode: 'css', theme: 'dracula', lineNumbers: true
});
const jsEditor = CodeMirror.fromTextArea(document.getElementById('jsEditor'), {
  mode: 'javascript', theme: 'dracula', lineNumbers: true
});

const editors = [htmlEditor, cssEditor, jsEditor];
const preview = document.getElementById('preview');
const body = document.getElementById('appBody');
const themeLabel = document.getElementById('themeLabel');
const themeBtn = document.getElementById('themeBtn');

function updatePreview() {
  const doc = `<!DOCTYPE html><html><head><style>${cssEditor.getValue()}</style></head><body>${htmlEditor.getValue()}<script>${jsEditor.getValue()}<\/script></body></html>`;
  preview.srcdoc = doc;
}

function toggleTheme() {
  isDark = !isDark;
  const theme = isDark ? 'dracula' : 'eclipse';
  const label = isDark ? 'Dark Theme' : 'Light Theme';
  const btnText = isDark ? '☀️ Light' : '🌙 Dark';
  const bodyClass = isDark ? 'dark' : 'light';

  body.className = bodyClass;
  themeLabel.textContent = label;
  themeBtn.textContent = btnText;
  editors.forEach(e => e.setOption('theme', theme));
  localStorage.setItem('editorTheme', isDark ? 'dark' : 'light');
}

const saved = localStorage.getItem('editorTheme');
if (saved === 'light') toggleTheme();

editors.forEach(e => e.on('change', updatePreview));
updatePreview();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan file HTML, buka di browser. Klik tombol untuk toggle antara tema dark (Dracula) dan light (Eclipse). Preferensi tema disimpan di LocalStorage. Semua panel ikut berubah warna mengikuti tema yang dipilih.
