# 454. Mengimplementasikan Fitur Export Kode sebagai File HTML

## Definisi & Target
Mengimplementasikan fitur export yang menggabungkan kode HTML, CSS, dan JavaScript menjadi satu file HTML yang bisa di-download. File hasil export bisa langsung dibuka di browser.

## Analogi Alur
Seperti "Save As" untuk mengekspor dokumen: semua kode yang ada di editor digabung menjadi satu file HTML lengkap dengan inline CSS dan JavaScript, siap untuk di-deploy atau dibagikan.

## Poin-Poin Penting
- Tombol "Export" yang mendownload file HTML
- Menggabungkan HTML, CSS, JS menjadi satu file
- Format HTML dengan doctype, head, dan body lengkap
- Nama file berdasarkan nama project
- Opsi export format (HTML file atau ZIP)

```html
<script>
const htmlEditor = CodeMirror.fromTextArea(document.getElementById('htmlEditor'), { mode: 'xml', theme: 'dracula', lineNumbers: true });
const cssEditor = CodeMirror.fromTextArea(document.getElementById('cssEditor'), { mode: 'css', theme: 'dracula', lineNumbers: true });
const jsEditor = CodeMirror.fromTextArea(document.getElementById('jsEditor'), { mode: 'javascript', theme: 'dracula', lineNumbers: true });
const preview = document.getElementById('preview');

function updatePreview() {
  const doc = buildFullHTML();
  preview.srcdoc = doc;
}

function buildFullHTML() {
  const html = htmlEditor.getValue();
  const css = cssEditor.getValue();
  const js = jsEditor.getValue();
  return `<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<style>${css}</style>
</head>
<body>
${html}
<script>${js}<\/script>
</body>
</html>`;
}

function exportHTML() {
  const fullHTML = buildFullHTML();
  const blob = new Blob([fullHTML], { type: 'text/html' });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = 'exported-page.html';
  a.click();
  URL.revokeObjectURL(url);
  showToast('✅ File exported as exported-page.html');
}

function copyHTML() {
  const fullHTML = buildFullHTML();
  navigator.clipboard.writeText(fullHTML).then(() => {
    showToast('📋 HTML copied to clipboard!');
  }).catch(() => {
    const ta = document.createElement('textarea');
    ta.value = fullHTML;
    document.body.appendChild(ta);
    ta.select();
    document.execCommand('copy');
    document.body.removeChild(ta);
    showToast('📋 HTML copied to clipboard!');
  });
}

function showToast(msg) {
  const t = document.getElementById('toast');
  t.textContent = msg;
  t.classList.add('show');
  setTimeout(() => t.classList.remove('show'), 2500);
}

[htmlEditor, cssEditor, jsEditor].forEach(e => e.on('change', updatePreview));
updatePreview();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan file HTML, buka di browser. Klik "Export HTML" untuk mendownload file HTML lengkap. Klik "Copy HTML" untuk menyalin kode ke clipboard. File hasil export bisa langsung dibuka di browser manapun.
