# 442. Membangun Layout Tiga Panel yaitu HTML Editor, CSS Editor, JavaScript Editor, dan Preview

## Definisi & Target
Membangun layout tiga panel untuk code editor dengan dua baris: baris atas berisi tiga editor (HTML, CSS, JS) dan baris bawah berisi panel preview. Menggunakan CSS Grid dan Flexbox untuk layout responsif.

## Analogi Alur
Seperti meja kerja dengan tiga monitor: monitor kiri untuk HTML, tengah untuk CSS, kanan untuk JavaScript, dan monitor besar di bawah untuk melihat hasil render.

## Poin-Poin Penting
- Layout menggunakan CSS Grid dengan dua baris
- Baris atas: tiga kolom untuk editor (masing-masing 1/3 lebar)
- Baris bawah: satu kolom penuh untuk preview
- Tab system untuk beralih antar editor di mobile
- Resize handle untuk mengubah ukuran panel

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Three Panel Layout</title>
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body {
  font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
  height: 100vh;
  overflow: hidden;
  background: #1a1a2e;
  color: #eee;
}
.app {
  display: grid;
  grid-template-rows: 1fr 1fr;
  height: 100vh;
}
.top-panel {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 4px;
  padding: 4px;
  background: #0f3460;
}
.editor-panel {
  display: flex;
  flex-direction: column;
  background: #16213e;
  border-radius: 6px;
  overflow: hidden;
}
.editor-panel .header {
  background: #0f3460;
  padding: 10px 15px;
  font-size: 13px;
  font-weight: 600;
  color: #e94560;
  display: flex;
  justify-content: space-between;
  align-items: center;
}
.editor-panel .header .lang {
  font-size: 11px;
  color: #53d769;
  background: #1a1a2e;
  padding: 2px 8px;
  border-radius: 4px;
}
.editor-panel textarea {
  flex: 1;
  background: #1a1a2e;
  color: #eee;
  border: none;
  padding: 15px;
  font-family: 'Consolas', 'Courier New', monospace;
  font-size: 14px;
  line-height: 1.6;
  resize: none;
  outline: none;
}
.bottom-panel {
  background: #0f3460;
  padding: 4px;
}
.preview-frame {
  width: 100%;
  height: 100%;
  background: white;
  border-radius: 6px;
  border: none;
}
@media (max-width: 768px) {
  .top-panel {
    grid-template-columns: 1fr;
    grid-template-rows: 1fr 1fr 1fr;
  }
}
</style>
</head>
<body>
<div class="app">
  <div class="top-panel">
    <div class="editor-panel">
      <div class="header"><span>HTML</span><span class="lang">.html</span></div>
      <textarea id="htmlEditor"><h1>Hello World</h1>
<p>This is HTML content</p></textarea>
    </div>
    <div class="editor-panel">
      <div class="header"><span>CSS</span><span class="lang">.css</span></div>
      <textarea id="cssEditor">body { font-family: Arial; }
h1 { color: #667eea; }</textarea>
    </div>
    <div class="editor-panel">
      <div class="header"><span>JavaScript</span><span class="lang">.js</span></div>
      <textarea id="jsEditor">console.log('Hello from JS!');
document.body.style.background = '#f0f2ff';</textarea>
    </div>
  </div>
  <div class="bottom-panel">
    <iframe class="preview-frame" id="preview"></iframe>
  </div>
</div>
<script>
const htmlEditor = document.getElementById('htmlEditor');
const cssEditor = document.getElementById('cssEditor');
const jsEditor = document.getElementById('jsEditor');
const preview = document.getElementById('preview');

function updatePreview() {
  const html = htmlEditor.value;
  const css = cssEditor.value;
  const js = jsEditor.value;
  const doc = `
<!DOCTYPE html>
<html><head><style>${css}</style></head>
<body>${html}
<script>${js}<\/script>
</body></html>`;
  preview.srcdoc = doc;
}

[htmlEditor, cssEditor, jsEditor].forEach(el => {
  el.addEventListener('input', updatePreview);
});

updatePreview();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan file HTML, buka di browser. Tiga panel editor di baris atas, preview di baris bawah. Ketik kode di editor, hasil render muncul di preview. Layout responsif dengan stack vertikal di mobile.
