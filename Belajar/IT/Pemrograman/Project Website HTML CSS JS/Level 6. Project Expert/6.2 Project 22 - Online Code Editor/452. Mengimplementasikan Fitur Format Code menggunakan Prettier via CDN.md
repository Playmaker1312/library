# 452. Mengimplementasikan Fitur Format Code menggunakan Prettier via CDN

## Definisi & Target
Mengimplementasikan fitur format code yang merapikan kode HTML, CSS, dan JavaScript menggunakan Prettier library yang di-load via CDN. User bisa menekan tombol format untuk merapikan kode secara otomatis.

## Analogi Alur
Seperti menyetrika baju: kode yang berantakan (kusut) dirapikan (disetrika) menjadi rapi dan terstruktur dengan indentasi yang konsisten.

## Poin-Poin Penting
- Load Prettier dan plugin dari CDN (unpkg)
- Tombol "Format Code" untuk setiap editor atau semua
- Format HTML dengan plugin html
- Format CSS dengan plugin postcss
- Format JavaScript dengan plugin babel
- Konfigurasi prettier options (tab width, semicolons, quotes)

const statusEl = document.getElementById('formatStatus');

async function formatCode(editor, code, parser, plugin) {
  try {
    const result = await prettier.format(code, { parser, plugins: [plugin], tabWidth: 2, semi: true, singleQuote: true });
    editor.setValue(result);
    statusEl.textContent = '✓ Formatted successfully';
  } catch(e) {
    statusEl.textContent = '✗ Format error: ' + e.message;
  }
}

function formatHTML() { formatCode(htmlEditor, htmlEditor.getValue(), 'html', prettierPlugins.html); }
function formatCSS() { formatCode(cssEditor, cssEditor.getValue(), 'css', prettierPlugins.postcss); }
function formatJS() { formatCode(jsEditor, jsEditor.getValue(), 'babel', prettierPlugins.babel); }

async function formatAll() {
  statusEl.textContent = '⏳ Formatting all...';
  await formatHTML();
  await formatCSS();
  await formatJS();
  statusEl.textContent = '✓ All files formatted!';
}

## Cara Integrasi
Simpan file HTML, buka di browser. Ketik kode yang berantakan di editor, klik tombol "Format" per panel atau "Format All" untuk merapikan semua. Prettier dijalankan via CDN dengan parser sesuai bahasa.
