# 451. Mengimplementasikan Font Size dan Font Family Selector untuk Editor

## Definisi & Target
Mengimplementasikan kontrol untuk mengubah font size dan font family pada editor. User bisa memilih ukuran font dari 10px hingga 24px dan memilih antara monospace font yang tersedia.

## Analogi Alur
Seperti pengaturan tampilan di IDE: Anda bisa memperbesar teks agar lebih mudah dibaca atau mengganti font sesuai preferensi (Consolas, Fira Code, atau monospace default).

## Poin-Poin Penting
- Selector font size (10-24px) dengan live preview
- Selector font family (Consolas, Courier New, Fira Code, monospace)
- Perubahan diterapkan ke semua editor secara real-time
- Preferensi disimpan di LocalStorage
- Preview tidak terpengaruh (hanya editor yang berubah)

## Kode Implementasi (Gabungan) - HTML, CSS, JavaScript

```html
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Font Settings</title>
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/codemirror.min.css">
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/theme/dracula.min.css">
<style>
* { margin: 0; padding: 0; box-sizing: border-box; }
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; height: 100vh; overflow: hidden; background: #1a1a2e; }
.app { display: grid; grid-template-rows: auto 1fr 1fr; height: 100vh; }
.toolbar {
  background: #0f3460;
  padding: 10px 15px;
  display: flex;
  gap: 20px;
  align-items: center;
  flex-wrap: wrap;
}
.toolbar label { color: #aaa; font-size: 13px; display: flex; align-items: center; gap: 8px; }
.toolbar select, .toolbar input[type="range"] {
  padding: 5px 10px;
  background: #1a1a2e;
  color: #eee;
  border: 1px solid #333;
  border-radius: 5px;
  font-size: 13px;
}
.toolbar .font-size-display {
  color: #53d769;
  font-weight: bold;
  min-width: 40px;
  text-align: center;
}
.top-panel { display: grid; grid-template-columns: 1fr 1fr 1fr; gap: 4px; padding: 4px; background: #0f3460; }
.editor-panel { display: flex; flex-direction: column; background: #16213e; border-radius: 6px; overflow: hidden; }
.editor-panel .header { background: #0f3460; padding: 8px 12px; font-size: 12px; color: #e94560; }
.editor-panel .CodeMirror { flex: 1; height: auto !important; }
.bottom-panel { background: #0f3460; padding: 4px; }
.preview-frame { width: 100%; height: 100%; background: white; border-radius: 6px; border: none; }
</style>
</head>
<body>
<div class="app">
  <div class="toolbar">
    <label>
      Font Size:
      <input type="range" id="fontSizeSlider" min="10" max="24" value="14" step="1" oninput="changeFontSize(this.value)">
      <span class="font-size-display" id="fontSizeDisplay">14</span>
    </label>
    <label>
      Font Family:
      <select id="fontFamilySelect" onchange="changeFontFamily(this.value)">
        <option value="Consolas, monospace">Consolas</option>
        <option value="'Courier New', monospace">Courier New</option>
        <option value="'Fira Code', monospace" selected>Fira Code</option>
        <option value="'JetBrains Mono', monospace">JetBrains Mono</option>
        <option value="monospace">Default Monospace</option>
      </select>
    </label>
    <span style="color:#888;font-size:12px;margin-left:auto">Live preview of font changes</span>
  </div>
  <div class="top-panel">
    <div class="editor-panel">
      <div class="header">HTML</div>
      <textarea id="htmlEditor"><div>
  <h1>Font Settings Demo</h1>
  <p>Adjust font size and family</p>
</div></textarea>
    </div>
    <div class="editor-panel">
      <div class="header">CSS</div>
      <textarea id="cssEditor">body { font-family: Arial; }
h1 { color: #667eea; }</textarea>
    </div>
    <div class="editor-panel">
      <div class="header">JavaScript</div>
      <textarea id="jsEditor">console.log('Font test');
document.querySelector('h1').style.color = '#e94560';</textarea>
    </div>
  </div>
  <div class="bottom-panel">
    <iframe class="preview-frame" id="preview"></iframe>
  </div>
</div>
<script src="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/codemirror.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/mode/xml/xml.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/mode/css/css.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.65.16/mode/javascript/javascript.min.js"></script>
<script>
const htmlEditor = CodeMirror.fromTextArea(document.getElementById('htmlEditor'), { mode: 'xml', theme: 'dracula', lineNumbers: true });
const cssEditor = CodeMirror.fromTextArea(document.getElementById('cssEditor'), { mode: 'css', theme: 'dracula', lineNumbers: true });
const jsEditor = CodeMirror.fromTextArea(document.getElementById('jsEditor'), { mode: 'javascript', theme: 'dracula', lineNumbers: true });
const editors = [htmlEditor, cssEditor, jsEditor];
const preview = document.getElementById('preview');

function updatePreview() {
  const doc = `<!DOCTYPE html><html><head><style>${cssEditor.getValue()}</style></head><body>${htmlEditor.getValue()}<script>${jsEditor.getValue()}<\/script></body></html>`;
  preview.srcdoc = doc;
}

function changeFontSize(size) {
  document.getElementById('fontSizeDisplay').textContent = size;
  editors.forEach(e => {
    e.getWrapperElement().style.fontSize = size + 'px';
  });
  localStorage.setItem('editorFontSize', size);
}

function changeFontFamily(family) {
  editors.forEach(e => {
    e.getWrapperElement().style.fontFamily = family;
  });
  localStorage.setItem('editorFontFamily', family);
}

const savedSize = localStorage.getItem('editorFontSize');
const savedFamily = localStorage.getItem('editorFontFamily');
if (savedSize) {
  document.getElementById('fontSizeSlider').value = savedSize;
  changeFontSize(savedSize);
}
if (savedFamily) {
  document.getElementById('fontFamilySelect').value = savedFamily;
  changeFontFamily(savedFamily);
}

editors.forEach(e => e.on('change', updatePreview));
updatePreview();
</script>
</body>
</html>
```

## Cara Integrasi
Simpan file HTML, buka di browser. Gunakan slider untuk mengubah font size secara real-time. Pilih font family dari dropdown. Perubahan diterapkan ke semua editor dan disimpan di LocalStorage.
