# 441. Merencanakan Fitur Code Editor yaitu HTML, CSS, JS Editor dan Live Preview

## Definisi & Target
Merencanakan fitur online code editor yang terdiri dari tiga panel editor (HTML, CSS, JavaScript) dan satu panel live preview. Editor akan menampilkan hasil rendering kode secara real-time.

## Analogi Alur
Seperti CodePen atau JSFiddle: developer menulis kode di panel kiri, hasilnya langsung terlihat di panel kanan. Ini adalah lingkungan pengembangan web yang berjalan di browser.

## Poin-Poin Penting
- Tiga panel editor terpisah untuk HTML, CSS, dan JavaScript
- Live preview yang update otomatis saat kode berubah
- Integrasi CodeMirror untuk syntax highlighting
- Debounce untuk performa update preview
- Fitur export, save, dan template starter
