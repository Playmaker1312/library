# 447. Membuat Preview menggunakan Iframe dengan Srcdoc Attribute

## Definisi & Target
Membuat panel preview menggunakan iframe dengan attribute srcdoc untuk merender kode HTML, CSS, dan JavaScript secara langsung tanpa file terpisah. Iframe memberikan isolasi yang aman antara kode user dan halaman utama.

## Analogi Alur
Seperti etalase kaca: kode yang Anda tulis ditampilkan di dalam kotak kaca (iframe) yang terisolasi dari lingkungan sekitarnya. Aman dan bersih.

## Poin-Poin Penting
- iframe dengan srcdoc attribute berisi HTML lengkap
- Sandbox attribute untuk keamanan (allow-scripts)
- Tidak perlu membuat file HTML terpisah
- Isolasi CSS: style di halaman utama tidak mempengaruhi preview
- Isolasi JavaScript: script di preview tidak bisa mengakses parent

Simpan file HTML, buka di browser. Textarea berisi kode HTML lengkap yang langsung dirender di iframe. Attribute srcdoc memuat konten HTML tanpa perlu file terpisah. Update preview secara real-time saat kode diubah.
