# 431. Mengimplementasikan Task Dependencies dalam Gantt Chart

## Definisi & Target
Mengimplementasikan dependencies antar task dalam Gantt Chart. Dependencies menunjukkan relasi "task A harus selesai sebelum task B dimulai" (finish-to-start) dengan panah atau indikator visual.

## Analogi Alur
Seperti proses perakitan mobil: body mobil harus selesai dulu sebelum pengecatan, pengecatan harus selesai sebelum perakitan interior. Setiap tahap bergantung pada tahap sebelumnya.

## Poin-Poin Penting
- Dependencies menggunakan finish-to-start relationship
- Task yang memiliki dependency tidak bisa dimulai sebelum task dependen selesai
- Visualisasi dengan garis panah antar task bar
- Peringatan jika ada circular dependency
- Validasi saat mengubah tanggal task

```html
.gantt-header {

}

  cursor: help;
}

  position: absolute;
  height: 32px;
  border-radius: 6px;
  display: flex;
  align-items: center;

  color: white;
  font-weight: 600;
  top: 9px;
  cursor: pointer;
  transition: transform 0.2s;
}

.gantt-bar.done { background: linear-gradient(135deg, #11998e, #38ef7d); }

<body>
<div class="container">
  <h1>Task Dependencies</h1>
  <p class="subtitle">Garis merah = dependencies (finish-to-start)</p>
  <div class="gantt-wrapper" id="ganttWrapper">
    <div class="gantt-header">
      <div class="task-label-header">Task</div>
      <div id="dayHeaders"></div>
    </div>
    <div id="ganttBody" style="position:relative"></div>
  </div>

<script>
const tasks = [
  { id: 't1', title: 'Research', startDay: 0, duration: 5, status: 'done', deps: [] },
  { id: 't2', title: 'Design', startDay: 5, duration: 7, status: 'done', deps: ['t1'] },
  { id: 't3', title: 'Frontend', startDay: 12, duration: 10, status: 'in_progress', deps: ['t2'] },
  { id: 't4', title: 'Backend', startDay: 12, duration: 12, status: 'in_progress', deps: ['t2'] },
  { id: 't5', title: 'Integration', startDay: 24, duration: 4, status: 'todo', deps: ['t3', 't4'] },
  { id: 't6', title: 'Testing', startDay: 28, duration: 5, status: 'todo', deps: ['t5'] }
];
const totalDays = 35;
const cellWidth = 40;
const rowHeight = 51;

const dayHeaders = document.getElementById('dayHeaders');
for (let d = 1; d <= totalDays; d++) {
  const div = document.createElement('div');
  div.className = 'day-label';
  div.textContent = 'D' + d;
  dayHeaders.appendChild(div);
}

const ganttBody = document.getElementById('ganttBody');
ganttBody.style.position = 'relative';

tasks.forEach((task, idx) => {
  const row = document.createElement('div');
  row.className = 'gantt-row';
  row.dataset.index = idx;

  const info = document.createElement('div');
  info.className = 'task-info';
  const depText = task.deps.length ? `<span class="dep-indicator">⬅ ${task.deps.length} dep</span>` : '';
  info.innerHTML = `${task.title} ${depText}`;
  row.appendChild(info);

  for (let i = 0; i < totalDays; i++) {
    const cell = document.createElement('div');
    cell.style.cssText = 'border-right:1px solid #1a1a2e;';
    row.appendChild(cell);
  }

  const taskStatus = task.deps.some(d => !tasks.find(t => t.id === d)?.status === 'done') && task.status === 'todo' ? 'waiting' : task.status;

  const bar = document.createElement('div');
  bar.className = `gantt-bar ${taskStatus}`;
  bar.style.cssText = `left: ${task.startDay * cellWidth + 2}px; width: ${task.duration * cellWidth - 4}px;`;
  bar.textContent = task.duration + 'd';
  row.appendChild(bar);

  ganttBody.appendChild(row);
});

const svg = document.createElementNS('http://www.w3.org/2000/svg', 'svg');
svg.style.cssText = 'position:absolute;top:0;left:0;width:100%;height:100%;pointer-events:none;z-index:5;';
svg.setAttribute('width', '100%');
svg.setAttribute('height', '100%');
ganttBody.appendChild(svg);

tasks.forEach((task, idx) => {
  task.deps.forEach(depId => {
    const depIdx = tasks.findIndex(t => t.id === depId);
    if (depIdx === -1) return;
    const y1 = depIdx * rowHeight + rowHeight / 2 + 9;
    const y2 = idx * rowHeight + rowHeight / 2 + 9;
    const depTask = tasks[depIdx];
    const x1 = (depTask.startDay + depTask.duration) * cellWidth;
    const x2 = task.startDay * cellWidth;
    const line = document.createElementNS('http://www.w3.org/2000/svg', 'line');
    line.setAttribute('x1', x1);
    line.setAttribute('y1', y1);
    line.setAttribute('x2', x2);
    line.setAttribute('y2', y2);
    line.setAttribute('stroke', '#e94560');
    line.setAttribute('stroke-width', '2');
    line.setAttribute('stroke-dasharray', '5,3');
    line.setAttribute('marker-end', 'url(#arrowhead)');
    svg.appendChild(line);
  });
});

const defs = document.createElementNS('http://www.w3.org/2000/svg', 'defs');
const marker = document.createElementNS('http://www.w3.org/2000/svg', 'marker');
marker.setAttribute('id', 'arrowhead');
marker.setAttribute('markerWidth', '10');
marker.setAttribute('markerHeight', '7');
marker.setAttribute('refX', '9');
marker.setAttribute('refY', '3.5');
marker.setAttribute('orient', 'auto');
const polygon = document.createElementNS('http://www.w3.org/2000/svg', 'polygon');
polygon.setAttribute('points', '0 0, 10 3.5, 0 7');
polygon.setAttribute('fill', '#e94560');
marker.appendChild(polygon);
defs.appendChild(marker);
svg.appendChild(defs);
</script>
</body>
</html>
```

## Cara Integrasi
Simpan sebagai file HTML, buka di browser. Array tasks memiliki properti `deps` yang berisi ID task dependen. SVG lines digambar dari task yang sudah selesai ke task yang bergantung. Task dengan dep yang belum selesai akan berstatus `waiting` (greyed out).
