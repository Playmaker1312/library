# 438. Membangun Calendar View untuk Melihat Deadline

## Definisi & Target
Membangun calendar view yang menampilkan deadline task dan project dalam format kalender bulanan. Setiap task dengan deadline ditampilkan sebagai event pada tanggal yang sesuai.

## Analogi Alur
Seperti Google Calendar: Anda bisa melihat semua deadline task dalam tampilan bulanan. Setiap task muncul sebagai card pada tanggal deadline-nya dengan warna sesuai prioritas.

## Poin-Poin Penting
- Navigasi bulan sebelumnya dan berikutnya
- Grid 7x6 untuk menampilkan hari dalam bulan
- Task/todo ditampilkan sebagai card di tanggal deadline
- Warna card berbeda berdasarkan prioritas task
- Klik tanggal untuk melihat detail task

```html
<script>
let currentDate = new Date();
const dayNames = ['Sun', 'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat'];
const monthNames = ['January', 'February', 'March', 'April', 'May', 'June', 'July', 'August', 'September', 'October', 'November', 'December'];

const tasks = [
  { title: 'Design Review', date: '2025-06-05', priority: 'high' },
  { title: 'Frontend Sprint', date: '2025-06-10', priority: 'high' },
  { title: 'API Integration', date: '2025-06-15', priority: 'medium' },
  { title: 'Testing Phase', date: '2025-06-20', priority: 'medium' },
  { title: 'Deployment', date: '2025-06-28', priority: 'low' },
  { title: 'Client Meeting', date: '2025-07-02', priority: 'high' },
  { title: 'Database Backup', date: '2025-07-08', priority: 'low' },
  { title: 'Security Audit', date: '2025-06-25', priority: 'high' },
  { title: 'Code Review', date: '2025-06-12', priority: 'medium' },
  { title: 'Documentation', date: '2025-07-15', priority: 'low' }
];

function getTasksForDate(dateStr) {
  return tasks.filter(t => t.date === dateStr);
}

function renderCalendar() {
  const year = currentDate.getFullYear();
  const month = currentDate.getMonth();
  document.getElementById('monthYear').textContent = monthNames[month] + ' ' + year;

  const firstDay = new Date(year, month, 1).getDay();
  const daysInMonth = new Date(year, month + 1, 0).getDate();
  const prevMonthDays = new Date(year, month, 0).getDate();
  const today = new Date();

  const grid = document.getElementById('calendarGrid');
  grid.innerHTML = dayNames.map(d => `<div class="day-header">${d}</div>`).join('');

  const totalCells = Math.ceil((firstDay + daysInMonth) / 7) * 7;

  for (let i = 0; i < totalCells; i++) {
    let dayNum, isOtherMonth = false, dateStr;
    if (i < firstDay) {
      dayNum = prevMonthDays - firstDay + i + 1;
      isOtherMonth = true;
      const pm = month === 0 ? 11 : month - 1;
      const py = month === 0 ? year - 1 : year;
      dateStr = py + '-' + String(pm + 1).padStart(2, '0') + '-' + String(dayNum).padStart(2, '0');
    } else if (i >= firstDay + daysInMonth) {
      dayNum = i - firstDay - daysInMonth + 1;
      isOtherMonth = true;
      const nm = month === 11 ? 0 : month + 1;
      const ny = month === 11 ? year + 1 : year;
      dateStr = ny + '-' + String(nm + 1).padStart(2, '0') + '-' + String(dayNum).padStart(2, '0');
    } else {
      dayNum = i - firstDay + 1;
      dateStr = year + '-' + String(month + 1).padStart(2, '0') + '-' + String(dayNum).padStart(2, '0');
    }

    const isToday = today.getFullYear() === year && today.getMonth() === month && today.getDate() === dayNum;
    const dayTasks = getTasksForDate(dateStr);

    const cell = document.createElement('div');
    cell.className = `day-cell ${isOtherMonth ? 'other-month' : ''} ${isToday ? 'today' : ''}`;
    cell.innerHTML = `<div class="date">${dayNum}</div>`;
    dayTasks.forEach(t => {
      const ev = document.createElement('div');
      ev.className = `event ${t.priority}`;
      ev.textContent = t.title;
      cell.appendChild(ev);
    });
    grid.appendChild(cell);
  }
}

function navigate(dir) {
  currentDate.setMonth(currentDate.getMonth() + dir);
  renderCalendar();
}

function goToday() {
  currentDate = new Date();
  renderCalendar();
}

renderCalendar();
</script>

```

## Cara Integrasi
Simpan file HTML, buka di browser. Kalender menampilkan bulan dengan deadline task sebagai event card. Navigasi untuk berpindah bulan. Task dengan prioritas high berwarna merah, medium oranye, low hijau. Data array tasks bisa diganti dari LocalStorage.
