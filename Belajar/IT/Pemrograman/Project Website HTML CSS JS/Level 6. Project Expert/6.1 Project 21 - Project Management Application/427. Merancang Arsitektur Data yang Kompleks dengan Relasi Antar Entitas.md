# 427. Merancang Arsitektur Data yang Kompleks dengan Relasi Antar Entitas

## Definisi & Target
Merancang struktur data untuk project management dengan relasi antar entitas seperti Project, Task, Team Member, Comment, Activity Log, dan File Attachment. Data disimpan di LocalStorage dengan format JSON yang terorganisir.

## Analogi Alur
Seperti arsitek yang membuat blueprint bangunan: setiap entitas adalah ruangan, relasi adalah koridor yang menghubungkan ruangan, dan semua tersimpan dalam satu gedung (LocalStorage).

## Poin-Poin Penting
- Data disimpan dalam object tunggal di LocalStorage dengan key "pmApp"
- Setiap entitas memiliki id unik menggunakan Date.now()
- Relasi menggunakan foreign key (projectId, taskId, etc.)
- Struktur data menggunakan Map-like object untuk akses cepat
- Semua fungsi CRUD terpusat di DataStore
