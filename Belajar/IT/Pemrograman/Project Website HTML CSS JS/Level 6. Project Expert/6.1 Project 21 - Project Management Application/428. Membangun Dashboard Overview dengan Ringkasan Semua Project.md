# 428. Membangun Dashboard Overview dengan Ringkasan Semua Project

## Definisi & Target
Membangun halaman dashboard yang menampilkan ringkasan semua project. Dashboard menampilkan total project, task progress, statistik status, dan timeline aktivitas terbaru.

## Analogi Alur
Seperti papan kontrol di ruang kapten kapal: semua informasi penting tentang perjalanan (project) ditampilkan dalam satu layar untuk pengambilan keputusan cepat.

## Poin-Poin Penting
- Kartu statistik untuk total project, active tasks, completed tasks, dan team members
- Grafik progress menggunakan progress bar
- Daftar project terbaru dengan status masing-masing
- Aktivitas terbaru dari activity log
- Semua data diambil dari LocalStorage
