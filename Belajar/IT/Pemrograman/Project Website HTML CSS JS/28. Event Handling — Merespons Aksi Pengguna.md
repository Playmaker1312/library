# 28. Event Handling — Merespons Aksi Pengguna

Materi ini mengajarkan cara membuat halaman bereaksi: `addEventListener`, objek event, `preventDefault`/`stopPropagation`, **event delegation** untuk elemen dinamis, event form (submit dengan FormData), keyboard (Escape), mouse, scroll/resize, hingga `DOMContentLoaded` vs `load` — plus catatan arrow function dan `this`. Materi ini adalah lapisan terakhir yang membuat DOM "hidup".

## 1. Penjelasan Singkat & Konsep Dasar

Sampai materi 27, semua manipulasi DOM masih terjadi karena kita menulis perintahnya di dalam file JS yang berjalan sekali saat halaman dimuat. Tapi di dunia nyata, sebuah aplikasi tidak menarik kalau halamannya diam: user mengeklik tombol pinjam, mengetik di kolom pencarian, menekan Escape untuk menutup modal, atau memindahkan jendela. JavaScript harus bisa **mendengarkan** aksi itu dan menjalankan fungsi sebagai tanggapan. Itulah **event handling** — jembatan dari "halaman yang diubah oleh kode" ke "halaman yang berubah karena user".

Cara paling benar mendaftarkan respons adalah `elemen.addEventListener("click", handler)`. `handler` adalah fungsi yang dipanggil saat event terjadi, dan secara otomatis menerima sebuah **event object** (sering ditulis `e` atau `event`) berisi informasi detail: `e.target` (elemen yang sebenarnya menerima event), `e.type`, `e.key` untuk keyboard, `e.preventDefault()`, `e.stopPropagation()`, dan seterusnya. Gunakan `addEventListener` sebagai pengganti assignment langsung seperti `elemen.onclick = fn` karena ia mendukung banyak handler sekaligus, mudah dibuang dengan `removeEventListener`, dan tidak menimpa handler yang sudah ada.

Konsep kunci yang membedakan materi ini dari yang lain adalah **bubbling dan delegation**. Ketika tombol di dalam kartu diklik, event sebenarnya "naik" (bubble) dari tombol ke kartu, ke section, ke body, sampai `document`. Ini membuka pola bernama **event delegation**: kamu memasang satu listener di elemen induk (misal `#katalog-grid`), lalu di dalam handler memeriksa `event.target.closest(".btn-pinjam")` untuk mencari tahu elemen mana yang diklik. Pola ini **wajib** untuk elemen yang dibuat secara dinamis (hasil render materi 27), karena listener yang menempel langsung ke tombol tidak akan terpasang pada tombol yang lahir setelah listener didaftarkan.

Berbagai jenis event punya peran sendiri. Form menawarkan `submit` (paling sering dipakai: baca seluruh field dengan `new FormData(form)` lalu `preventDefault()` agar halaman tidak reload), `input` (real-time setiap perubahan nilai), `change` (setelah blur dan nilai berubah), `focus`/`blur`. Keyboard memberi `keydown`/`keyup` (untuk menutup modal dengan Escape). Mouse menyediakan `click`, `mouseenter`, `mouseleave`. `window` memberi `scroll` dan `resize` (debounce sering diperlukan). Terakhir, **timing**: `DOMContentLoaded` dijalankan begitu HTML selesai di-parse (script di akhir body sebenarnya sudah cukup), sedangkan `load` menunggu semua resource (gambar, CSS) selesai dimuat.

Satu catatan penting soal arrow function: arrow **tidak mengikat `this` sendiri** — ia memakai `this` dari lingkup luarnya. Pada handler biasa (`function(e){ this... }`), `this` menunjuk elemen yang memasang listener; pada arrow, `this` adalah objek luar (sering `window` atau scope modul). Karena itu, hindari mengandalkan `this` di dalam arrow untuk merujuk elemen; gunakan `e.currentTarget` atau pegang elemen lewat variabel. Sebaliknya, arrow sangat berguna karena `this` tetap lexically scoped di dalam class (seperti pola modal di materi 30).

**Benang merah**: materi 25 menemukan elemen, 26 mengubahnya, 27 membuat/menghapusnya. Semua itu baru bermakna penuh ketika **user** yang memicu: klik, ketikan, keypress, scroll. Materi 28 menyatukan semuanya menjadi aplikasi interaktif. Fitur pencarian real-time (materi 29) dibangun dari event `input`; modal dan notifikasi (materi 30) dari event `click`, `keydown`, dan `submit`; dan seluruh kartu dinamis (materi 27) terikat ke user melalui event delegation.

## 2. Fungsi & Kegunaan Utama dalam Web

Hampir setiap piksel interaktif di **Perpustakaan Digital Kota** dikendalikan oleh event. Pencarian katalog memakai event `input` di kotak pencarian — setiap ketikan memfilter array lalu me-render ulang grid (sering dibungkus **debounce** agar tidak mengeksekusi filter pada setiap keystroke). Dropdown filter kategori memakai `change`; tombol "Hanya tersedia" memakai `change` dan membaca `e.target.checked`.

Katalog dinamis dari materi 27 menjadi hidup lewat **event delegation** pada `#katalog-grid`: satu listener `click` di grid menangkap tombol "Pinjam", tombol "Hapus", dan klik kartu itu sendiri menggunakan `event.target.closest(...)`. Karena tombol-tombolnya lahir dan mati setiap render, delegation adalah satu-satunya cara yang masuk akal. Form tambah buku memakai `submit` + `FormData` untuk membaca semua field, lalu memanggil fungsi `tambahBuku` dari materi 27.

Modal detail buku dibuka dengan klik pada kartu, dan ditutup dengan klik tombol X, klik overlay, atau tekan **Escape** (`keydown` → `e.key === "Escape"`). Notifikasi "Buku berhasil dipinjam" dibuat lewat `createElement` (materi 27) segera setelah event, lalu dihapus dengan `remove()` setelah `setTimeout`. `DOMContentLoaded` menjadi titik aman inisialisasi semua listener. Bahkan `scroll` dipakai untuk tombol "kembali ke atas" yang hanya muncul setelah halaman digulir melewati ambang tertentu.

```javascript
// js/main.js

// ─── Data awal ─────────────────────────────────────────────────────────────
let katalog = [
    { id: 1, judul: "Clean Code",     pengarang: "Robert C. Martin", stok: 3 },
    { id: 2, judul: "Laskar Pelangi", pengarang: "Andrea Hirata",    stok: 0 },
    { id: 3, judul: "Cosmos",         pengarang: "Carl Sagan",       stok: 5 },
];

const gridCari = document.querySelector("#katalog-grid");

// ─── Rendering (ringkasan materi 27) ───────────────────────────────────────
function buatKartu(buku) {
    const kartu = document.createElement("article");
    kartu.className = "kartu-buku";
    kartu.dataset.id = buku.id;

    const judul = document.createElement("h3");
    judul.textContent = buku.judul;

    const badge = document.createElement("span");
    badge.className = `badge ${buku.stok > 0 ? "baik" : "habis"}`;
    badge.textContent = buku.stok > 0 ? `Stok: ${buku.stok}` : "Habis";

    const tombolHapus = document.createElement("button");
    tombolHapus.className = "btn-hapus";
    tombolHapus.textContent = "Hapus";
    tombolHapus.dataset.id = buku.id;

    kartu.append(judul, badge, tombolHapus);
    return kartu;
}

function renderKatalog() {
    gridCari.innerHTML = "";
    const fragment = document.createDocumentFragment();
    katalog.forEach(buku => fragment.appendChild(buatKartu(buku)));
    gridCari.appendChild(fragment);
    document.querySelector("#info-hasil").textContent =
        `Menampilkan ${katalog.length} buku.`;
}

// ─── 1. addEventListener + event object + delegation ─────────────────────
// Listener DIPASANG DI PARENT (grid), bukan di setiap tombol.
// Ini bekerja untuk tombol yang dibuat DINAMIS oleh renderKatalog().
gridCari.addEventListener("click", (event) => {
    // e.target: elemen paling dalam yang diklik (bisa tombol, badge, h3, dsb.)
    const tombolHapus = event.target.closest(".btn-hapus"); // naik cari tombol
    const kartu       = event.target.closest(".kartu-buku");

    if (tombolHapus) {
        // Jangan biarkan klik tombol juga membuka modal kartu:
        event.stopPropagation();
        hapusBuku(Number(tombolHapus.dataset.id));
        return;
    }

    if (kartu) bukaModal(kartu); // klik di kartu (selain tombol hapus) → detail
});

function hapusBuku(id) {
    katalog = katalog.filter(buku => buku.id !== id);
    renderKatalog();
    // notifikasi (contoh singkat; lengkapnya materi 30)
    tampilkanNotifikasi("Buku dihapus dari katalog.");
}

// ─── 2. Form submit + FormData ─────────────────────────────────────────────
const formTambah = document.querySelector("#form-tambah");
formTambah.addEventListener("submit", (event) => {
    // Tanpa ini, halaman RELOAD dan semua state hilang.
    event.preventDefault();

    // FormData: baca semua field bertanpa querySelector satu-satu.
    const data = new FormData(formTambah); // butuh atribut name pada input
    const judul = data.get("judul")?.trim();

    if (!judul) return;

    katalog.push({
        id: Date.now(),
        judul,
        pengarang: "Penulis Baru",
        stok: Number(data.get("stok")) || 0,
    });
    renderKatalog();
    formTambah.reset();
    formTambah.querySelector("#input-judul").focus();
    tampilkanNotifikasi(`Buku "${judul}" berhasil ditambahkan.`);
});
// Catatan: agar FormData bekerja, input di HTML butuh atribut name — pada
// contoh di atas beri name="judul" dan name="stok" pada kedua input.

// ─── 3. Event input — pencarian real-time ─────────────────────────────────
const inputCari = document.querySelector("#input-cari");
inputCari.addEventListener("input", (event) => {
    const kataKunci = event.target.value.trim().toLowerCase();
    const hasil = katalog.filter(buku =>
        buku.judul.toLowerCase().includes(kataKunci) ||
        buku.pengarang.toLowerCase().includes(kataKunci)
    );

    gridCari.innerHTML = "";
    if (hasil.length === 0) {
        const pesan = document.createElement("p");
        pesan.textContent = "Tidak ada buku yang cocok.";
        gridCari.appendChild(pesan);
    } else {
        const fragment = document.createDocumentFragment();
        hasil.forEach(buku => fragment.appendChild(buatKartu(buku)));
        gridCari.appendChild(fragment);
    }
    document.querySelector("#info-hasil").textContent =
        `Menampilkan ${hasil.length} buku.`;
});

// ─── 4. Modal + keyboard Escape + arrow function & this ──────────────────
const modal = document.querySelector("#modal-detail");

function bukaModal(kartu) {
    const id = Number(kartu.dataset.id);
    const buku = katalog.find(b => b.id === id);
    if (!buku) return;

    modal.querySelector("#modal-judul").textContent = buku.judul;
    modal.querySelector("#modal-stok").textContent =
        `Stok: ${buku.stok} (${buku.pengarang})`;

    modal.classList.add("aktif");
    modal.setAttribute("aria-hidden", "false");
    modal.querySelector("#modal-tutup").focus(); // aksesibilitas: pindahkan fokus
}

function tutupModal() {
    modal.classList.remove("aktif");
    modal.setAttribute("aria-hidden", "true");
}

document.querySelector("#modal-tutup").addEventListener("click", tutupModal);
modal.querySelector(".modal-overlay").addEventListener("click", tutupModal);

// Keyboard: Escape menutup modal — dipasang di document, selalu aktif
document.addEventListener("keydown", (event) => {
    if (event.key === "Escape" && modal.classList.contains("aktif")) {
        tutupModal();
    }
});

// Catatan THIS: pada arrow function, `this` adalah lingkup luar (window),
// sehingga tidak bisa dipakai untuk merujuk elemen. Bandingkan:
//   btn.addEventListener("click", function() { this.textContent = "OK"; });
//   // this → elemen yang memicu (btn)
//   btn.addEventListener("click", () => { this.textContent = "OK"; });
//   // this → window/lexical scope, BUKAN btn. Gunakan event.currentTarget.
// Karena itu dalam handler gunakan `event.target` / `event.currentTarget`.

// ─── 5. Window events + DOMContentLoaded vs load ──────────────────────────
let lastScroll = 0;
window.addEventListener("scroll", () => {
    const posisi = window.scrollY;
    if (posisi > lastScroll) console.log("Scroll ke bawah:", posisi);
    lastScroll = posisi;
}, { passive: true }); // passive: biarkan scroll tetap mulus

window.addEventListener("resize", () => {
    // debounce disarankan untuk pekerjaan berat (materi 29)
    console.log("Jendela diubah ukurannya:", window.innerWidth);
});

// DOMContentLoaded: jalankan saat HTML selesai di-parse.
// Karena script ini ditaruh di akhir body, inisialisasi di bawah sudah aman.
// Tapi jika script dipindah ke <head>, bungkus semua inisialisasi di sini:
document.addEventListener("DOMContentLoaded", () => {
    renderKatalog();
});

// `load`: menunggu semua resource (gambar/CSS) selesai — lebih lambat.
// window.addEventListener("load", () => { ... });

// notifikasi sederhana (dibuat & dihapus dinamis — materi 27)
function tampilkanNotifikasi(pesan) {
    const div = document.createElement("div");
    div.textContent = pesan;
    Object.assign(div.style, {
        position: "fixed", bottom: "16px", right: "16px",
        background: "#2563eb", color: "white", padding: "10px 16px",
        borderRadius: "8px", zIndex: 100,
    });
    document.body.appendChild(div);
    setTimeout(() => div.remove(), 2500);
}
```

## 4. Analogi Sederhana — Membangun Rumah

Di rumah analogi kita, **HTML** adalah kerangka dan tata ruang, **CSS** adalah cat dan dekorasi, dan **JavaScript** adalah instalasi listrik. Materi 28 berbicara tentang **saklar yang merespons sentuhan**. Dinding rumah penuh saklar; tanpa event handling, saklar hanya hiasan — lampu tidak akan menyala walau kamu menekannya. `addEventListener` adalah cara memasang "mekanisme respons" pada saklar: begitu jari menyentuh, rumah bereaksi.

Tapi perhatikan rumah yang terus direnovasi (katalog yang di-render ulang). Setiap kali ada ruangan baru, saklar barunya juga baru dipasang — jika mekanisme responsnya dipasang satu per satu di tiap saklar saat dibangun, satu langkah lupa dan saklar itu "mati" (listener tidak terpasang pada elemen dinamis). Solusinya **event delegation**: satu **panel pusat** yang menerima semua laporan dari banyak saklar. Alih-alih menempelkan mekanisme di tiap saklar, panel pusat hanya perlu tahu "laporan ini berasal dari saklar mana?" — itulah `event.target` dan `.closest(".btn-hapus")`. Panel tetap terpasang walau seratus saklar baru ditambah; efisien karena satu titik pengatur untuk seluruh rumah.

`preventDefault` bisa diibaratkan **menghentikan kebiasaan default rumah**. Biasanya, menekan tombol "Kirim" pada form otomatis memuat ulang halaman (seperti pintu yang selalu terbanting sendiri setiap tombol ditekan). Dengan `preventDefault`, kita bilang: "hentikan pintu terbanting; biarkan aku yang mengelola." Sementara `stopPropagation` adalah **menyuruh laporan berhenti** di satu ruangan: klik tombol hapus tidak perlu terus diteruskan hingga ke panel pembuka modal — cukup ditangani di titiknya saja, jangan sampai klik itu juga memicu hal lain di ruangan lain.

`DOMContentLoaded` vs `load` ibarat dua momen kesiapan rumah: yang pertama saat **rangka dan dinding sudah jadi** (HTML ter-parse) — sudah cukup untuk memasang saklar dan menyambung kabel; yang kedua saat **semua perabot dan lukisan sudah terpasang** (gambar, CSS, aset lain selesai dimuat) — lebih lengkap tapi lebih lambat. Untuk memasang kelistrikan, kita tidak perlu menunggu lukisan; karena itu `DOMContentLoaded` biasanya pilihan yang tepat.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

- **Event delegation pada katalog dinamis** — satu listener `click` di `#katalog-grid` menangani tombol pinjam, tombol hapus, dan klik kartu, walau kartu dibuat ulang setiap render.
- **Form submit tanpa reload** — `form.addEventListener("submit", e => { e.preventDefault(); ... })` membaca field via `FormData` dan menambahkan buku baru (materi 27).
- **Pencarian real-time** — `input` pada kotak pencarian memfilter array dan me-render ulang grid setiap kali user mengetik (di materi 29 dibungkus debounce).
- **Modal yang bisa ditutup dengan Escape** — `keydown` di `document` mendeteksi `event.key === "Escape"` dan menutup modal; plus `click` pada overlay/tombol tutup.
- **Aksi jendela** — `window.resize` untuk responsivitas dinamis, `window.scroll` untuk tombol "kembali ke atas" yang muncul setelah melewati ambang scroll.

## 6. Poin-poin Penting & Best Practices

- Selalu pakai **`addEventListener`**, bukan assignment `onclick`/`onmouseover` (yang menimpa handler sebelumnya dan menyulitkan pembersihan).
- Gunakan **event delegation** untuk semua elemen yang dibuat dinamis: pasang listener di container tetap (`#katalog-grid`), lalu tentukan target dengan **`event.target.closest(selector)`**. Jangan memasang listener per item di dalam loop render.
- **`preventDefault()`** untuk menghentikan perilaku default (reload form, navigasi link); **`stopPropagation()`** untuk mencegah event terus naik ke elemen lain.
- Untuk akses elemen pemasang listener, lebih aman pakai **`event.currentTarget`** daripada `this` — terutama karena **arrow function tidak mengikat `this`** ke elemen.
- Baca seluruh form dengan **`new FormData(form)`**; pastikan input punya atribut `name`. Akses `data.get("judul")`, `data.get("stok")`.
- Keyboard: **`event.key`** memberi nilai logis ("Escape", "Enter"); `event.code` memberi kode fisik. Untuk "salin", cek juga platform (`e.ctrlKey` di Windows, `e.metaKey` di macOS).
- Inisialisasi di **`DOMContentLoaded`** (atau letakkan script di akhir `body`); `load` hanya jika perlu menunggu resource besar.
- Untuk `scroll`/`resize`, pertimbangkan **debounce** (materi 29) dan opsional `{ passive: true }` agar scroll tetap mulus.
- Aksesibilitas: modal diberi `role="dialog"`, `aria-modal`, `aria-hidden`, dan fokus dipindahkan saat dibuka; jangan andalkan interaksi hanya dengan mouse.

## 7. Kesalahan Umum (Common Pitfalls & Bugs)

- **Listener dipasang ke elemen dinamis yang belum ada.** `document.querySelectorAll(".btn-hapus").forEach(b => b.addEventListener(...))` dijalankan sekali saat load, padahal tombol baru dibuat setelahnya → tombol baru tidak responsif. Perbaikan: event delegation di parent yang permanen.
- **Form reload halaman tanpa sengaja.** Semua `submit` default me-reload; tanpa `event.preventDefault()` state aplikasi hilang. Perbaikan: panggil `preventDefault()` di awal handler submit.
- **XSS muncul lagi lewat handler.** Menggabungkan `innerHTML` dengan nilai dari `event.target.value`/`FormData` membuka XSS. Perbaikan: `textContent` untuk data user (kembali ke materi 26-27).
- **`this` tidak seperti yang diduga di arrow function.** `btn.addEventListener("click", () => { this.textContent = ... })` → `this` adalah `window`, bukan `btn`. Perbaikan: gunakan `event.currentTarget` atau referensi variabel.
- **`event.target` disamakan begitu saja.** Klik pada tombol di dalam kartu membuat `event.target` = tombol, bukan kartu; membandingkannya dengan kartu selalu gagal. Perbaikan: pakai `event.target.closest(".kartu-buku")`.
- **Pencarian tanpa debounce** — setiap keystroke memanggil render ulang penuh dan bisa membuat lag saat koleksi besar. Perbaikan: debounce (materi 29) atau minimal throttling.

```javascript
// js/main.js
let katalog = [
    { id: 1, judul: "Clean Code",     pengarang: "Robert C. Martin", stok: 2 },
    { id: 2, judul: "Laskar Pelangi", pengarang: "Andrea Hirata",    stok: 0 },
    { id: 3, judul: "Cosmos",         pengarang: "Carl Sagan",       stok: 1 },
];

const grid = document.querySelector("#katalog-grid");
const formTambah = document.querySelector("#form-tambah");
const modal = document.querySelector("#modal-detail");

function buatKartu(buku) {
    const kartu = document.createElement("article");
    kartu.className = "kartu-buku";
    kartu.dataset.id = buku.id;

    const judul = document.createElement("h3");
    judul.textContent = buku.judul;

    const badge = document.createElement("span");
    badge.className = `badge ${buku.stok > 0 ? "baik" : "habis"}`;
    badge.textContent = buku.stok > 0 ? `Stok: ${buku.stok}` : "Habis";

    const pinjam = document.createElement("button");
    pinjam.className = "btn-pinjam";
    pinjam.textContent = "Pinjam";
    pinjam.disabled = buku.stok === 0;
    pinjam.dataset.id = buku.id;

    const hapus = document.createElement("button");
    hapus.className = "btn-hapus";
    hapus.textContent = "Hapus";
    hapus.dataset.id = buku.id;

    kartu.append(judul, badge, pinjam, hapus);
    return kartu;
}

function renderKatalog() {
    grid.innerHTML = "";
    const fragment = document.createDocumentFragment();
    katalog.forEach(buku => fragment.appendChild(buatKartu(buku)));
    grid.appendChild(fragment);
}

// (a) Event delegation: pinjam & hapus & buka modal, semua dari satu listener
grid.addEventListener("click", (event) => {
    const btnPinjam = event.target.closest(".btn-pinjam");
    const btnHapus  = event.target.closest(".btn-hapus");
    const kartu     = event.target.closest(".kartu-buku");

    if (btnPinjam) {
        const id = Number(btnPinjam.dataset.id);
        const buku = katalog.find(b => b.id === id);
        if (buku && buku.stok > 0) {
            buku.stok -= 1;              // ubah data dulu
            renderKatalog();             // tampilan mengikuti data
        }
        return;
    }

    if (btnHapus) {
        event.stopPropagation();         // jangan sampai ikut membuka modal
        katalog = katalog.filter(b => b.id !== Number(btnHapus.dataset.id));
        renderKatalog();
        return;
    }

    if (kartu) bukaModal(kartu);
});

// (b) Form submit + FormData
formTambah.addEventListener("submit", (event) => {
    event.preventDefault();
    const data = new FormData(formTambah);
    const judul = data.get("judul").trim();
    if (!judul) return;

    katalog.push({
        id: Date.now(),
        judul,
        pengarang: "Penulis Baru",
        stok: Number(data.get("stok")) || 0,
    });
    renderKatalog();
    formTambah.reset();
});

// (c) Pencarian real-time
document.querySelector("#input-cari").addEventListener("input", (event) => {
    const kata = event.target.value.trim().toLowerCase();
    const hasil = katalog.filter(b =>
        b.judul.toLowerCase().includes(kata) ||
        b.pengarang.toLowerCase().includes(kata)
    );
    grid.innerHTML = "";
    const fragment = document.createDocumentFragment();
    hasil.forEach(b => fragment.appendChild(buatKartu(b)));
    grid.appendChild(fragment);
});

// (d) Modal + Escape
function bukaModal(kartu) {
    const buku = katalog.find(b => b.id === Number(kartu.dataset.id));
    if (!buku) return;
    modal.querySelector("#modal-judul").textContent = buku.judul;
    modal.querySelector("#modal-stok").textContent =
        `Stok: ${buku.stok} — ${buku.pengarang}`;
    modal.classList.add("aktif");
    modal.setAttribute("aria-hidden", "false");
}

function tutupModal() {
    modal.classList.remove("aktif");
    modal.setAttribute("aria-hidden", "true");
}

document.querySelector("#modal-tutup").addEventListener("click", tutupModal);
modal.querySelector(".modal-overlay").addEventListener("click", tutupModal);
document.addEventListener("keydown", (event) => {
    if (event.key === "Escape" && modal.classList.contains("aktif")) tutupModal();
});

// Bonus: tombol kembali ke atas saat scroll
const tombolAtas = document.querySelector("#ke-atas");
window.addEventListener("scroll", () => {
    tombolAtas.classList.toggle("tampil", window.scrollY > 300);
}, { passive: true });
tombolAtas.addEventListener("click", () => window.scrollTo({ top: 0, behavior: "smooth" }));

// Inisialisasi
document.addEventListener("DOMContentLoaded", () => renderKatalog());
```

**Pembahasan**: Latihan ini menggabungkan semua konsep event. Listener tunggal di `grid` menangani tiga aksi berbeda lewat `event.target.closest(...)` — itulah **event delegation**: tombol Pinjam/Hapus dibuat ulang tiap render tapi tetap berfungsi karena listener menempel di grid yang permanen. Untuk pinjam, data diubah dulu (`buku.stok -= 1`) lalu `renderKatalog()`; tombol otomatis `disabled` saat stok 0 karena atribut `disabled` di-set saat kartu dibangun. `event.stopPropagation()` di tombol Hapus mencegah klik tersebut juga membuka modal. Form memakai `FormData` dengan atribut `name` pada input dan `preventDefault` agar tidak reload. Pencarian mendengarkan `input` (real-time) dan me-render ulang hasilnya. Modal ditutup dari tiga jalan: tombol X, overlay, dan **Escape** via `keydown` di `document`. `DOMContentLoaded` memastikan render pertama aman dijalankan setelah HTML siap, dan `scroll` memanfaatkan `{ passive: true }` agar halaman tetap mulus digulir.
