# 29. Pencarian dan Filter Real-time

Materi ini merangkai semuanya menjadi fitur sungguhan: pencarian judul yang berjalan **real-time tanpa lag** berkat debounce, filter kategori, checkbox "hanya tersedia", urutkan field dengan arah naik/turun, penghitung hasil, dan tombol reset — semuanya digerakkan oleh satu **state** terpusat.

## 1. Penjelasan Singkat & Konsep Dasar

Di materi 25-28 kamu belajar seleksi elemen, manipulasi konten, membuat/menghapus elemen, dan menangani event. Masalahnya, pendekatan lama sering asal-asalan: event handler menyentuh DOM langsung di sana-sini, setiap keystroke langsung me-render ulang, dan logika filter tersebar di beberapa tempat. Materi 29 mengenalkan cara berpikir yang diadopsi aplikasi modern: **pisahkan data dan tampilan**. Semua data tinggal di satu objek **state**, dan tampilan adalah "gambar" dari state itu. Kalau state berubah, render ulang; kalau tidak, DOM tidak disentuh.

State aplikasi disimpan dalam satu objek yang menjadi **satu sumber kebenaran (single source of truth)**: `semuaBuku` berisi data asli, `hasilFilter` berisi hasil setelah difilter dan diurutkan, `filter` berisi kondisi aktif (`keyword`, `kategori`, `hanya_tersedia`), dan `urutan` berisi petunjuk sort seperti `"judul-asc"`. Setiap kali salah satu filter berubah, kita hanya meng-update state, lalu memanggil **satu fungsi render**. Tampilan tidak pernah dihitung dari apa yang tampil di layar, tapi selalu dari data.

Kunci kedua adalah **debounce**. Event `input` (materi 28) terpantik setiap kali user mengetik satu huruf. Kalau halaman langsung memfilter dan me-render ulang ribuan buku setiap huruf, browser jadi berat dan ada jeda yang mengganggu. Debounce menunda eksekusi: fungsi baru dijalankan **300ms setelah user berhenti mengetik**, bukan pada setiap ketukan. Secara teknis, setiap keystroke membatalkan timer sebelumnya (`clearTimeout`) lalu memasang timer baru (`setTimeout`). Hanya keystroke terakhir yang "bertahan" dan memicu pencarian.

Logika filternya sendiri sederhana tapi rapi, dibangun dari array methods materi 23. Keyword dicocokkan ke `judul` dan `pengarang` memakai `includes`, dengan keduanya diubah dulu ke huruf kecil (`toLowerCase`) agar pencarian tidak peka huruf besar/kecil. Kategori dicocokkan dengan `===`, dan "hanya tersedia" memfilter `stok > 0`. Urutan dibedah dari string `"judul-asc"` menjadi `field` dan `arah`, lalu `sort` membandingkan nilai dengan aturan: jadikan huruf kecil dulu untuk string (agar `"amazon"` dan `"Amazon"` berdampingan), bandingkan dengan `<`/`>`, dan kembalikan `-1`/`1` sesuai arah. Fungsi `filterDanSortBuku()` adalah jantungnya: ia membaca state, menghasilkan array baru, menyimpannya ke `state.hasilFilter`, lalu me-render dan meng-update teks jumlah hasil.

**Benang merah**: materi 25 memilih elemen, 26 mengubahnya, 27 membuatnya, 28 mendengarkan aksi user. Materi 29 menyatukan keempatnya menjadi perilaku yang terasa "cerdas": ketikan user mengubah state, dan grid tinggal mengikuti. Ini juga jembatan ke **Level 6 (async & data)**: saat data datang dari `fetch` alias API, prinsip yang sama bertahan, tapi kamu perlu menambah penanganan **race condition** (respons lama tidak boleh menimpa respons baru) dan state `loading`/`error`.

## 2. Fungsi & Kegunaan Utama dalam Web

Di **Perpustakaan Digital Kota**, kotak pencarian menjadi gerbang utama koleksi. User mengetik judul atau nama pengarang — hasilnya muncul sendiri tanpa menekan tombol "Cari". Dropdown kategori ("Semua", "Fiksi", "Teknologi", "Sains", ...) membatasi hasil sesuai bidang. Checkbox "Hanya yang tersedia" memisahkan buku yang bisa dipinjam sekarang dari yang sedang keluar. Select urutan membiarkan user memilih "Judul A→Z", "Harga Termurah", atau "Terbit Terbaru". Di atas grid ada baris info ber-`role="status"` (`aria-live="polite"`) yang mengumumkan "Menampilkan X buku" — screen reader ikut membacakan jumlah hasil.

Semua kontrol ini saling berinteraksi tanpa reload: ketikan ditambah kategori ditambah checkbox digabungkan secara berurutan di dalam satu pipeline filter. Tombol "Reset Filter" mengembalikan state ke kondisi awal dan me-render ulang. Pola ini persis yang dipakai marketplace (Tokopedia, Shopee), situs berita, atau dashboard analitik — bedanya di sini data masih array lokal; di Level 6 array itu akan datang dari server.

```javascript
// js/katalog.js

// ─── 1. STATE — semua data dan kondisi hidup di satu objek ────────────────
const state = {
    semuaBuku: [                       // data asli: sumber kebenaran
        { id: 1, judul: "Clean Code",         pengarang: "Robert C. Martin", kategori: "Teknologi",  harga: 150000, tahun: 2008, stok: 5 },
        { id: 2, judul: "Laskar Pelangi",     pengarang: "Andrea Hirata",     kategori: "Fiksi",      harga: 95000,  tahun: 2005, stok: 3 },
        { id: 3, judul: "Cosmos",             pengarang: "Carl Sagan",        kategori: "Sains",       harga: 120000, tahun: 1980, stok: 0 },
        { id: 4, judul: "The Great Gatsby",   pengarang: "F. Scott Fitzgerald", kategori: "Fiksi",    harga: 110000, tahun: 1925, stok: 2 },
        { id: 5, judul: "Atomic Habits",      pengarang: "James Clear",       kategori: "Non-Fiksi",   harga: 135000, tahun: 2018, stok: 7 },
        { id: 6, judul: "Sejarah Dunia",      pengarang: "John Smith",        kategori: "Sejarah",     harga: 98000,  tahun: 2012, stok: 1 },
    ],
    hasilFilter: [],                   // hasil setelah filter & sort
    filter: {                          // kondisi aktif
        keyword: "",
        kategori: "semua",
        hanya_tersedia: false,
    },
    urutan: "judul-asc",               // format: "field-arah"
};

// Cache elemen DOM yang dipakai berulang agar tidak dicari lagi setiap render
const inputCari     = document.querySelector("#input-pencarian");
const selectKat     = document.querySelector("#filter-kategori");
const checkTersedia = document.querySelector("#filter-tersedia");
const selectUrutan  = document.querySelector("#urutan");
const infoHasil     = document.querySelector("#info-hasil");
const gridKatalog   = document.querySelector("#katalog-grid");

// ─── 2. DEBOUNCE — jalankan fungsi hanya setelah jeda mengetik ────────────
function debounce(fungsi, delay = 300) {
    let timerId;
    return function (...args) {
        clearTimeout(timerId);                                  // batalkan panggilan sebelumnya
        timerId = setTimeout(() => fungsi.apply(this, args), delay); // pasang yang baru
    };
}

// ─── 3. INTI — baca state → filter → sort → render (satu pipeline) ───────
function filterDanSortBuku() {
    // Salin array agar state.semuaBuku tidak ikut ter-sort (materi 23: sort mutasi array)
    let hasil = [...state.semuaBuku];

    // a) Keyword: cocokkan di judul & pengarang, tanpa peduli huruf besar/kecil
    const kw = state.filter.keyword.toLowerCase();
    if (kw) {
        hasil = hasil.filter(buku =>
            buku.judul.toLowerCase().includes(kw) ||
            buku.pengarang.toLowerCase().includes(kw)
        );
    }

    // b) Kategori
    if (state.filter.kategori !== "semua") {
        hasil = hasil.filter(buku => buku.kategori === state.filter.kategori);
    }

    // c) Hanya yang tersedia
    if (state.filter.hanya_tersedia) {
        hasil = hasil.filter(buku => buku.stok > 0);
    }

    // d) Sort: bedah "judul-asc" → field="judul", arah="asc"
    const [field, arah] = state.urutan.split("-");
    hasil.sort((a, b) => {
        let nilaiA = a[field];
        let nilaiB = b[field];
        if (typeof nilaiA === "string") {   // judul: samakan huruf dulu agar urutannya logis
            nilaiA = nilaiA.toLowerCase();
            nilaiB = nilaiB.toLowerCase();
        }
        if (nilaiA < nilaiB) return arah === "asc" ? -1 : 1;
        if (nilaiA > nilaiB) return arah === "asc" ? 1 : -1;
        return 0;
    });

    // Simpan hasil, lalu SATU titik yang menyentuh DOM
    state.hasilFilter = hasil;
    renderKatalog(hasil);
    updateInfoHasil(hasil.length);
}

// ─── 4. RENDER — murni dari data, bukan dari elemen yang ada ──────────────
function buatKartu(buku) {
    const kartu = document.createElement("article");
    kartu.className = "kartu-buku";
    kartu.dataset.id = buku.id;

    const judul = document.createElement("h3");
    judul.textContent = buku.judul;

    const pengarang = document.createElement("p");
    pengarang.className = "kartu-buku__pengarang";
    pengarang.textContent = buku.pengarang;

    const meta = document.createElement("p");
    meta.className = "kartu-buku__meta";
    meta.textContent =
        `${buku.kategori} · ${buku.tahun} · Rp ${buku.harga.toLocaleString("id-ID")}`;

    const badge = document.createElement("span");
    badge.className = `badge ${buku.stok > 0 ? "badge--tersedia" : "badge--habis"}`;
    badge.textContent = buku.stok > 0 ? `Tersedia (${buku.stok})` : "Habis";

    kartu.append(judul, pengarang, meta, badge);
    return kartu;
}

function renderKatalog(daftar) {
    gridKatalog.innerHTML = "";

    // Empty state: jangan biarkan grid tampil kosong tanpa kejelasan
    if (daftar.length === 0) {
        const kosong = document.createElement("p");
        kosong.className = "pesan-kosong";
        kosong.textContent = "Tidak ada buku yang cocok dengan filter saat ini.";
        gridKatalog.appendChild(kosong);
        return;
    }

    const fragment = document.createDocumentFragment();  // satu update DOM, bukan per kartu
    daftar.forEach(buku => fragment.appendChild(buatKartu(buku)));
    gridKatalog.appendChild(fragment);
}

function updateInfoHasil(jumlah) {
    infoHasil.textContent = `Menampilkan ${jumlah} buku.`;
}

// ─── 5. LISTENER — semua hanya memperbarui state, render mengikuti ─────────
function setupListener() {
    // Pencarian real-time: TIDAK dipanggil tiap keystroke, tunggu 300ms jeda
    const handleCari = debounce((event) => {
        state.filter.keyword = event.target.value.trim();   // buang spasi tepi
        filterDanSortBuku();
    }, 300);
    inputCari.addEventListener("input", handleCari);

    selectKat.addEventListener("change", (event) => {
        state.filter.kategori = event.target.value;
        filterDanSortBuku();
    });

    checkTersedia.addEventListener("change", (event) => {
        state.filter.hanya_tersedia = event.target.checked;
        filterDanSortBuku();
    });

    selectUrutan.addEventListener("change", (event) => {
        state.urutan = event.target.value;
        filterDanSortBuku();
    });

    // Reset: balikkan state ke awal DAN perbarui tampilan kontrolnya
    document.querySelector("#btn-reset-filter").addEventListener("click", () => {
        state.filter = { keyword: "", kategori: "semua", hanya_tersedia: false };
        state.urutan = "judul-asc";

        inputCari.value = "";
        selectKat.value = "semua";
        checkTersedia.checked = false;
        selectUrutan.value = "judul-asc";

        filterDanSortBuku();
    });
}

// ─── 6. JALANKAN ───────────────────────────────────────────────────────────
setupListener();
filterDanSortBuku();   // render pertama saat halaman dimuat
```

## 4. Analogi Sederhana — Membangun Rumah

Di rumah analogi kita, **HTML** adalah kerangka dan tata ruang, **CSS** adalah cat dan dekorasi interior, sedangkan **JavaScript** adalah instalasi listrik dan otomatisasi. Materi 29 tentang **pintu masuk dan saluran otomatis di rumah**.

**Debounce** adalah pengelola rumah yang sedang menjaga pintu utama. Penghuni datang mengetuk pintu satu per satu — pintu tidak perlu dibuka di setiap ketukan, karena satu penghuni bisa saja mengetuk lima kali dalam satu detik beruntun. Pengelola menunggu sebentar (300ms) sampai ketukan **berhenti**, baru membuka pintu untuk siapa pun yang ketukan terakhirnya. Kalau langsung dibuka di setiap ketukan, pengelola lelah bolak-balik dan penghuni lain ikut menunggu — begitulah juga browser yang kehilangan performa kalau me-render ulang setiap huruf. Dengan debounce, hanya "ketukan terakhir" yang menentukan: hasil pencarian muncul setelah jeda, bukan setiap pengetikan.

**Filter** adalah pintu dan aksen di tiap lorong rumah yang menyaring siapa yang boleh lewat. Pintu kategori hanya membuka untuk tamu berjenis "Fiksi"; pintu ketersediaan hanya untuk tamu yang inventarisnya masih ada; pintu kata kunci hanya untuk tamu yang namanya cocok dengan daftar. Semua pintu bekerja berurutan: tamu harus melewati pintu yang tersedia dulu, setelah itu dicocokkan dengan kategori, lalu boleh masuk ruangan. Aksen lorong (urutan) bukan pintu — ia hanya mengatur siapa yang jalan paling depan. Dalam kode, "siapa boleh masuk" itu fungsi `filter()` yang berlapis, dan "siapa paling depan" itu `sort()`.

Dan semua daftar tamu tidak dicatat di dinding (DOM) satu per satu; pengelola mencatatnya di satu buku besar (**state**), lalu setiap ada perubahan, papan pengumuman di ruang tamu digambar ulang sekali (**render**) dari buku besar itu. Selama catatan di buku besar benar, tampilan rumah pasti benar.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

- **Pencarian katalog dengan keyboard** — user mengetik judul/pengarang dan hasil muncul otomatis; debounce mencegah render per keystroke yang membuat aplikasi terasa lambat.
- **Marketplace / toko online** — filter kategori + checkbox "stok tersedia" + sort harga termurah/termahal; pola pencarian toko besar di internet persis seperti ini.
- **Dashboard atau tabel data (admin perpustakaan)** — memfilter daftar peminjaman berdasarkan status, petugas, atau rentang tanggal, dengan urutan kolom naik/turun yang bisa dibalik.
- **Situs berita / blog** — filter artikel berdasarkan tag dan kategori, ditambah pencarian judul, agar pembaca menemukan konten relevan cepat.
- **Reset / clear semua filter** — tombol yang mengembalikan halaman ke kondisi penuh; penting di aplikasi dengan banyak kontrol filter yang saling menumpuk.

## 6. Poin-poin Penting & Best Practices

- **State terpusat**: simpan `semuaBuku`, `hasilFilter`, `filter`, dan `urutan` di satu objek. Jangan biarkan setiap event bikin variabel sendiri di luar state — itu sumber inkonsistensi.
- **Pure render**: render **selalu dari data**, bukan dari isi DOM saat ini. Satu fungsi `renderKatalog(daftar)` dan satu `updateInfoHasil(jumlah)` adalah satu-satunya tempat yang menyentuh grid.
- **Debounce untuk input real-time**: jangan jalankan filter pada setiap `keydown`/`input`; tunggu jeda ±300ms setelah berhenti mengetik. Pakai `clearTimeout` + `setTimeout` agar hanya ketikan terakhir yang dieksekusi.
- **Kecilkan pekerjaan sampai benar-benar diperlukan**: `trim()` keyword, `toLowerCase()` kedua sisi (data dan keyword) agar pencarian case-insensitive, dan salin array (`[...state.semuaBuku]`) sebelum `sort()` agar data asli tidak termutasi.
- **Event delegation** (materi 28) tetap berlaku: jika nanti kartu berisi tombol (Pinjam, Hapus), pasang listener di `#katalog-grid`, bukan di per tombol.
- **Handle empty state**: teks "Tidak ada buku yang cocok" lebih baik daripada grid yang tiba-tiba kosong tanpa penjelasan; info jumlah hasil (`role="status"` + `aria-live`) juga membantu aksesibilitas.
- **Jangan ambil shortcut DOM**: kalau kamu butuh menampilkan hasil, jangan tanya "berapa kartu di grid sekarang" lewat `querySelectorAll` — selalu hitung dari `state.hasilFilter`.
- Siapkan diri untuk **Level 6**: saat data di-fetch dari API, debounce tetap dipakai, tapi pastikan kamu menangani juga respons yang tiba tidak berurutan (race condition, misal dengan `AbortController` atau token nomor urut) dan state loading/error.

## 7. Kesalahan Umum (Common Pitfalls & Bugs)

- **Pencarian jalan di setiap keystroke → lag.** Setiap huruf memicu `filter()` dan render penuh; dengan 10.000 buku halaman tersendat. Perbaikan: bungkus handler dengan `debounce` (±300ms) dan simpan hasil filter terakhir di state agar render hanya terjadi saat benar-benar perlu.
- **Race condition saat data async (Level 6).** User mengetik "pyth", hasil lama baru tiba setelah hasil "python" — layar menampilkan hasil yang salah. Perbaikan: simpan `sequence`/`requestId` yang naik setiap pencarian, atau pakai `AbortController.abort()` untuk membatalkan request sebelumnya.
- **Lupa empty state.** Grid `innerHTML = ""` tanpa pesan membuat halaman tampak rusak saat tidak ada yang cocok. Perbaikan: selalu cek `daftar.length === 0` lalu render pesan "Tidak ada buku yang cocok dengan filter saat ini."
- **Sort string tanpa menormalkan huruf.** `sort()` default membandingkan kode UTF-16, jadi `"amazon"` bisa muncul sebelum `"Amazon"` dan `"C"` sebelum `"b"`. Perbaikan: `toLowerCase()` dulu (atau `localeCompare`) sebelum membandingkan dengan `<`/`>`.
- **State yang termutasi tanpa sengaja.** `state.semuaBuku.sort(...)` mengubah data asli, sehingga reset filter tidak pernah mengembalikan urutan awal. Perbaikan: `[...state.semuaBuku]` sebelum sort.
- **Render tersebar di banyak tempat.** Setiap handler me-render ulang grid sendiri dengan logika yang sedikit berbeda → hasil tidak konsisten dan sulit di-debug. Perbaikan: satu fungsi `filterDanSortBuku()` sebagai satu-satunya jalan mengubah tampilan.

## 8. Mini Project / Soal Latihan & Kunci Jawaban

### Tantangan

1. Bangun katalog buku (minimal 6 data: judul, pengarang, kategori, harga, stok) yang punya: kotak pencarian real-time dengan **debounce 300ms**, dropdown **filter kategori**, dan baris info **"Menampilkan X buku."**. Pastikan ada empty state saat tidak ada yang cocok.
2. Kembangkan: tambahkan checkbox **"Hanya yang tersedia"**, select **urutan** (judul naik/turun dan harga naik/turun), dan tombol **"Reset Filter"** yang mengembalikan semua kontrol ke nilai awal.

### Solusi & Pembahasan

```html
<!-- index.html -->
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Perpustakaan Digital Kota — Latihan 29</title>
    <style>
        * { box-sizing: border-box; }
        body { font-family: system-ui, sans-serif; max-width: 760px; margin: 0 auto; padding: 16px; }
        .kontrol { display: flex; flex-wrap: wrap; gap: 10px; align-items: center; margin-bottom: 8px; }
        input[type="search"], select, button { padding: 6px 10px; border: 1px solid #cbd5e1; border-radius: 6px; }
        input[type="search"] { flex: 1 1 200px; }
        #info-hasil { font-size: 0.9rem; color: #64748b; }
        #katalog-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)); gap: 12px; }
        .kartu-buku { border: 1px solid #e2e8f0; border-radius: 8px; padding: 12px; background: #fff; }
        .kartu-buku h3 { margin: 0 0 4px; font-size: 1rem; }
        .kartu-buku p { margin: 0; color: #64748b; font-size: 0.85rem; }
        .pesan-kosong { grid-column: 1 / -1; background: #fefce8; border: 1px dashed #facc15; padding: 16px; text-align: center; }
    </style>
</head>
<body>
    <h1>Perpustakaan Digital Kota</h1>

    <div class="kontrol">
        <input type="search" id="input-pencarian" placeholder="Cari judul atau pengarang...">
        <select id="filter-kategori">
            <option value="semua">Semua Kategori</option>
            <option value="Fiksi">Fiksi</option>
            <option value="Sains">Sains</option>
            <option value="Teknologi">Teknologi</option>
        </select>
        <label><input type="checkbox" id="filter-tersedia"> Hanya tersedia</label>
        <select id="urutan">
            <option value="judul-asc">Judul A→Z</option>
            <option value="judul-desc">Judul Z→A</option>
            <option value="harga-asc">Harga ↑</option>
            <option value="harga-desc">Harga ↓</option>
        </select>
        <button id="btn-reset-filter" type="button">Reset</button>
    </div>

    <p id="info-hasil" role="status" aria-live="polite"></p>
    <section id="katalog-grid"></section>

    <script>
    // ─── State ─────────────────────────────────────────────────────────────
    const state = {
        semuaBuku: [
            { judul: "Clean Code",       pengarang: "Robert C. Martin", kategori: "Teknologi", harga: 150000, stok: 5 },
            { judul: "Laskar Pelangi",   pengarang: "Andrea Hirata",     kategori: "Fiksi",     harga: 95000,  stok: 3 },
            { judul: "Cosmos",           pengarang: "Carl Sagan",        kategori: "Sains",      harga: 120000, stok: 0 },
            { judul: "The Great Gatsby", pengarang: "F. Scott Fitzgerald", kategori: "Fiksi",   harga: 110000, stok: 2 },
            { judul: "Atomic Habits",    pengarang: "James Clear",       kategori: "Teknologi", harga: 135000, stok: 7 },
        ],
        hasilFilter: [],
        filter: { keyword: "", kategori: "semua", hanya_tersedia: false },
        urutan: "judul-asc",
    };

    const grid = document.querySelector("#katalog-grid");
    const info = document.querySelector("#info-hasil");

    // ─── Debounce ──────────────────────────────────────────────────────────
    function debounce(fungsi, delay = 300) {
        let timerId;
        return (...args) => {
            clearTimeout(timerId);
            timerId = setTimeout(() => fungsi.apply(this, args), delay);
        };
    }

    // ─── Filter + sort → render ─────────────────────────────────────────────
    function filterDanSortBuku() {
        let hasil = [...state.semuaBuku];
        const kw = state.filter.keyword.toLowerCase();

        if (kw) {
            hasil = hasil.filter(b =>
                b.judul.toLowerCase().includes(kw) || b.pengarang.toLowerCase().includes(kw));
        }
        if (state.filter.kategori !== "semua") {
            hasil = hasil.filter(b => b.kategori === state.filter.kategori);
        }
        if (state.filter.hanya_tersedia) {
            hasil = hasil.filter(b => b.stok > 0);
        }

        const [field, arah] = state.urutan.split("-");
        hasil.sort((a, b) => {
            let na = a[field], nb = b[field];
            if (typeof na === "string") { na = na.toLowerCase(); nb = nb.toLowerCase(); }
            if (na < nb) return arah === "asc" ? -1 : 1;
            if (na > nb) return arah === "asc" ? 1 : -1;
            return 0;
        });

        state.hasilFilter = hasil;
        render(hasil);
        info.textContent = `Menampilkan ${hasil.length} buku.`;
    }

    // REnder murni dari data + empty state
    function render(daftar) {
        grid.innerHTML = "";
        if (daftar.length === 0) {
            const pesan = document.createElement("p");
            pesan.className = "pesan-kosong";
            pesan.textContent = "Tidak ada buku yang cocok dengan filter saat ini.";
            grid.appendChild(pesan);
            return;
        }
        const frag = document.createDocumentFragment();
        daftar.forEach(b => {
            const kartu = document.createElement("article");
            kartu.className = "kartu-buku";
            const judul = document.createElement("h3");
            judul.textContent = b.judul;
            const meta = document.createElement("p");
            meta.textContent = `${b.pengarang} · ${b.kategori} · Rp ${b.harga.toLocaleString("id-ID")}` +
                              (b.stok > 0 ? ` · Stok: ${b.stok}` : " · HABIS");
            kartu.append(judul, meta);
            frag.appendChild(kartu);
        });
        grid.appendChild(frag);
    }

    // ─── Listener ───────────────────────────────────────────────────────────
    document.querySelector("#input-pencarian").addEventListener("input",
        debounce(e => {
            state.filter.keyword = e.target.value.trim();
            filterDanSortBuku();
        }, 300));

    document.querySelector("#filter-kategori").addEventListener("change", e => {
        state.filter.kategori = e.target.value;
        filterDanSortBuku();
    });

    document.querySelector("#filter-tersedia").addEventListener("change", e => {
        state.filter.hanya_tersedia = e.target.checked;
        filterDanSortBuku();
    });

    document.querySelector("#urutan").addEventListener("change", e => {
        state.urutan = e.target.value;
        filterDanSortBuku();
    });

    document.querySelector("#btn-reset-filter").addEventListener("click", () => {
        state.filter = { keyword: "", kategori: "semua", hanya_tersedia: false };
        state.urutan = "judul-asc";
        document.querySelector("#input-pencarian").value = "";
        document.querySelector("#filter-kategori").value = "semua";
        document.querySelector("#filter-tersedia").checked = false;
        document.querySelector("#urutan").value = "judul-asc";
        filterDanSortBuku();
    });

    filterDanSortBuku();  // render pertama
    </script>
</body>
</html>
```

**Pembahasan**: Semua kontrol hanya menulis ke `state`, lalu memanggil satu pintu `filterDanSortBuku()`. Pencarian memakai `debounce(..., 300)` sehingga hasil baru dihitung setelah jeda mengetik, bukan per huruf. Pipeline filter berurutan (keyword → kategori → ketersediaan) memakai `filter()`, dan hasil disortir dengan memecah `"judul-asc"` menjadi field + arah; string dibandingkan dalam huruf kecil agar urutannya natural. Render diambil dari `hasilFilter` (data), bukan dari DOM; empty state menampilkan pesan kuning saat hasil kosong. Tombol Reset mengembalikan state dan nilai controlnya baru memanggil render — sekali lagi, tampilan selalu mengikuti state, cara berpikir yang akan kamu butuhkan saat data datang dari API di Level 6.
