# 22. File Upload dan Storage
## 22.4 Menyimpan file ke disk
**Definisi Singkap:** Multer dapat dikonfigurasi untuk menyimpan file ke disk dengan `diskStorage`, mengatur lokasi penyimpanan, dan nama file kustom (UUID, timestamp).

**Analogi:** Menyimpan file ke disk seperti menata arsip di lemari — Anda tentukan laci (folder), nama map (filename), dan bagaimana cara menamai setiap dokumen.

**Poin-Poin Penting:**
- **`diskStorage({ destination, filename })`** — Simpan ke disk lokal
- **`destination`** — Folder tujuan (buat dengan `fs.mkdirSync` jika perlu)
- **`filename`** — Function untuk generate nama file
- **UUID/Date** — Hindari nama file asli untuk mencegah konflik
- **`serve-static`** — Sajikan file statis via `@nestjs/serve-static`

**Contoh Kode:**
```typescript
// upload.controller.ts — Disk storage
import { Controller, Post, UseInterceptors, UploadedFile } from '@nestjs/common';
import { FileInterceptor } from '@nestjs/platform-express';
import { diskStorage } from 'multer';
import { extname, join } from 'path';
import { v4 as uuid } from 'uuid';
import * as fs from 'fs';

@Controller('upload')
export class UploadController {
  @Post('avatar')
  @UseInterceptors(
    FileInterceptor('file', {
      storage: diskStorage({
        destination: (req, file, callback) => {
          const uploadPath = './uploads/avatars';
          if (!fs.existsSync(uploadPath)) {
            fs.mkdirSync(uploadPath, { recursive: true });
          }
          callback(null, uploadPath);
        },
        filename: (req, file, callback) => {
          const uniqueName = `${uuid()}${extname(file.originalname)}`;
          callback(null, uniqueName);
        },
      }),
    }),
  )
  uploadAvatar(@UploadedFile() file: Express.Multer.File) {
    return {
      url: `/uploads/avatars/${file.filename}`,
      filename: file.filename,
    };
  }
}

// main.ts — Serve static files
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { join } from 'path';
import * as express from 'express';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.use('/uploads', express.static(join(__dirname, '..', 'uploads')));
  await app.listen(3000);
}
bootstrap();
```

**Kasus Penggunaan Nyata:** Upload foto produk e-commerce disimpan di `./uploads/products/` dengan nama UUID, kemudian bisa diakses via URL `/uploads/products/abc-123.jpg`.
