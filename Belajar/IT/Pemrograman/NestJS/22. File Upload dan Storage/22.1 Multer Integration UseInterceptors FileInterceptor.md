# 22. File Upload dan Storage
## 22.1 Multer Integration UseInterceptors FileInterceptor
**Definisi Singkat:** NestJS mengintegrasikan Multer (middleware file upload Express) melalui decorator `@UseInterceptors(FileInterceptor('file'))` untuk menangani upload file dari multipart/form-data.

**Analogi:** Multer seperti petugas bagasi di bandara — Anda serahkan koper (file), petugas menanganinya (parse), menyimpannya (storage), dan memberi Anda tanda terima (file info).

**Poin-Poin Penting:**
- **`FileInterceptor('fieldName')`** — Interceptor untuk single file
- **`@UploadedFile()`** — Decorator untuk akses file yang diupload
- **`@UseInterceptors()`** — Aplikasikan interceptor ke handler
- **Multer options** — `limits`, `fileFilter`, `storage` via `@nestjs/platform-express`

**Contoh Kode:**
```typescript
// app.module.ts
import { Module } from '@nestjs/common';
import { MulterModule } from '@nestjs/platform-express';

@Module({
  imports: [
    MulterModule.register({
      dest: './uploads',
    }),
  ],
})
export class AppModule {}

// upload.controller.ts
import { Controller, Post, UseInterceptors, UploadedFile } from '@nestjs/common';
import { FileInterceptor } from '@nestjs/platform-express';

@Controller('upload')
export class UploadController {
  @Post()
  @UseInterceptors(FileInterceptor('file'))
  uploadFile(@UploadedFile() file: Express.Multer.File) {
    return {
      originalName: file.originalname,
      filename: file.filename,
      size: file.size,
      mimetype: file.mimetype,
    };
  }
}
```

**Kasus Penggunaan Nyata:** Endpoint `POST /upload/avatar` yang menerima file gambar dari form data, Multer memproses dan menyimpannya ke folder `/uploads`.
