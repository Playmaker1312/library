# 22. File Upload dan Storage
## 22.2 Single dan Multiple File Upload
**Definisi Singkat:** NestJS mendukung upload single file dengan `FileInterceptor`, multiple file dengan `FilesInterceptor` (array), atau banyak field dengan `FileFieldsInterceptor`.

**Analogi:** Single upload seperti ambil satu foto passport; multiple upload seperti upload galeri foto liburan (banyak file, satu field); file fields seperti upload KTP + foto selfie (beda field).

**Poin-Poin Penting:**
- **`FileInterceptor('file')`** — Satu file di satu field
- **`FilesInterceptor('files', maxCount)`** — Banyak file di satu field (array)
- **`FileFieldsInterceptor([...])`** — Banyak file di beberapa field berbeda
- **`@UploadedFiles()`** — Untuk multiple files (array atau object)

**Contoh Kode:**
```typescript
// upload.controller.ts
import { Controller, Post, UseInterceptors, UploadedFile, UploadedFiles } from '@nestjs/common';
import { FileInterceptor, FilesInterceptor, FileFieldsInterceptor } from '@nestjs/platform-express';

@Controller('upload')
export class UploadController {
  // Single file
  @Post('single')
  @UseInterceptors(FileInterceptor('file'))
  uploadSingle(@UploadedFile() file: Express.Multer.File) {
    return { file: file.originalname };
  }

  // Multiple files (satu field)
  @Post('multiple')
  @UseInterceptors(FilesInterceptor('files', 5))
  uploadMultiple(@UploadedFiles() files: Express.Multer.File[]) {
    return { count: files.length, files: files.map((f) => f.originalname) };
  }

  // Multiple fields (beda field name)
  @Post('fields')
  @UseInterceptors(
    FileFieldsInterceptor([
      { name: 'avatar', maxCount: 1 },
      { name: 'documents', maxCount: 3 },
    ]),
  )
  uploadFields(@UploadedFiles() files: { avatar?: Express.Multer.File[]; documents?: Express.Multer.File[] }) {
    return {
      avatar: files.avatar?.[0]?.originalname,
      documents: files.documents?.map((f) => f.originalname),
    };
  }
}
```

**Kasus Penggunaan Nyata:** Form registrasi user — upload avatar (single) + upload KTP dan ijazah (file fields) dalam satu request.
