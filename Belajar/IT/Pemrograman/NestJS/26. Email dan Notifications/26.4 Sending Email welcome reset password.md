# 26. Email dan Notifications

## 26.4. Sending Email: Welcome, Reset Password

**Definisi Singkat:**
Pengiriman email untuk use case umum seperti email selamat datang setelah registrasi dan email reset password ketika user lupa password, dengan fokus pada security, UX, dan deliverability.

**Analogi:**
- **Welcome Email**: Seperti ucapan selamat datang dari resepsionis hotel saat kamu check-in - memberikan informasi penting dan membuat kamu merasa diterima
- **Reset Password Email**: Seperti petugas keamanan yang memberimu kunci baru setelah kamu kehilangan kunci asli - dengan verifikasi identitas yang ketat

**Poin-Poin Penting:**
- Welcome Email: Kirim segera setelah registrasi, berisi info akun, CTA login
- Reset Password: Token harus expired (misal: 24 jam), satu token per request
- Security: Token harus random, tidak bisa ditebak, hash di database
- UX: Link yang jelas, informasi kedaluwarsa, instruksi jika tidak meminta
- Error Handling: Jika email gagal, log dan beri tahu user (atau queue untuk retry)

// ========== TOKEN SERVICE (UNTUK RESET PASSWORD) ==========

import { Injectable } from '@nestjs/common';
import { randomBytes, createHash } from 'crypto';
import { UserRepository } from './user.repository';

@Injectable()
export class TokenService {
  constructor(private readonly userRepository: UserRepository) {}

  // Generate secure random token
  generateResetToken(): { token: string; hashedToken: string } {
    // Generate 32 bytes random = 64 hex characters
    const token = randomBytes(32).toString('hex');
    
    // Hash token untuk disimpan di database (jika DB bocor, token tidak bisa dipakai)
    const hashedToken = this.hashToken(token);
    
    return { token, hashedToken };
  }

  // Hash token dengan SHA-256
  hashToken(token: string): string {
    return createHash('sha256').update(token).digest('hex');
  }

  // Verifikasi token
  async validateResetToken(email: string, token: string): Promise<boolean> {
    const user = await this.userRepository.findByEmail(email);
    
    if (!user) return false;
    if (!user.resetToken) return false;
    if (!user.resetTokenExpiry) return false;
    
    // Cek apakah token sudah expired
    if (new Date() > user.resetTokenExpiry) {
      return false;
    }
    
    // Hash token yang diberikan dan bandingkan dengan yang ada di DB
    const hashedToken = this.hashToken(token);
    
    return hashedToken === user.resetToken;
  }

  // Generate token untuk email verification
  generateEmailVerificationToken(): { token: string; hashedToken: string } {
    return this.generateResetToken();
  }
}

// ========== USER REPOSITORY (SIMULASI) ==========

export interface User {
  id: string;
  email: string;
  name: string;
  password: string;
  isVerified: boolean;
  verificationToken?: string;
  verificationTokenExpiry?: Date;
  resetToken?: string;
  resetTokenExpiry?: Date;
  createdAt: Date;
}

@Injectable()
export class UserRepository {
  private users: Map<string, User> = new Map();
  private emailToId: Map<string, string> = new Map();

  async create(userData: Omit<User, 'id' | 'createdAt' | 'isVerified'>): Promise<User> {
    const id = 'usr_' + Date.now();
    const user: User = {
      ...userData,
      id,
      isVerified: false,
      createdAt: new Date(),
    };
    
    this.users.set(id, user);
    this.emailToId.set(user.email, id);
    
    return user;
  }

  async findByEmail(email: string): Promise<User | null> {
    const id = this.emailToId.get(email);
    if (!id) return null;
    return this.users.get(id) || null;
  }

  async findById(id: string): Promise<User | null> {
    return this.users.get(id) || null;
  }

  async update(id: string, updates: Partial<User>): Promise<User> {
    const user = this.users.get(id);
    if (!user) throw new Error('User not found');
    
    const updatedUser = { ...user, ...updates };
    this.users.set(id, updatedUser);
    
    return updatedUser;
  }

  async clearResetToken(id: string): Promise<void> {
    const user = this.users.get(id);
    if (user) {
      user.resetToken = undefined;
      user.resetTokenExpiry = undefined;
    }
  }
}

// ========== EMAIL QUEUE SERVICE ==========

import { Injectable, Logger } from '@nestjs/common';
import { InjectQueue } from '@nestjs/bull';
import { Queue } from 'bull';

@Injectable()
export class EmailQueueService {
  private readonly logger = new Logger(EmailQueueService.name);

  constructor(
    @InjectQueue('email') private readonly emailQueue: Queue,
  ) {}

  // Queue welcome email
  async queueWelcomeEmail(user: { email: string; name: string }) {
    const job = await this.emailQueue.add(
      'send-welcome',
      {
        email: user.email,
        name: user.name,
      },
      {
        priority: 2,
        delay: 3000, // Kirim setelah 3 detik
      },
    );

    this.logger.log(`Welcome email queued for ${user.email}, job ID: ${job.id}`);
    return job.id;
  }

  // Queue reset password email
  async queueResetPasswordEmail(
    email: string,
    name: string,
    resetToken: string,
  ) {
    const resetUrl = `${process.env.APP_URL}/reset-password?token=${resetToken}&email=${encodeURIComponent(email)}`;

    const job = await this.emailQueue.add(
      'send-reset-password',
      {
        email,
        name,
        resetToken,
        resetUrl,
        expiryHours: 24,
      },
      {
        priority: 1, // Priority tinggi - user sedang menunggu
        attempts: 3,
        removeOnComplete: true,
      },
    );

    this.logger.log(`Reset password email queued for ${email}, job ID: ${job.id}`);
    return job.id;
  }

  // Queue email verification
  async queueVerificationEmail(
    email: string,
    name: string,
    verificationToken: string,
  ) {
    const verifyUrl = `${process.env.APP_URL}/verify-email?token=${verificationToken}&email=${encodeURIComponent(email)}`;

    const job = await this.emailQueue.add(
      'send-verification',
      {
        email,
        name,
        verificationToken,
        verifyUrl,
        expiryHours: 48,
      },
      {
        priority: 2,
      },
    );

    return job.id;
  }
}

// ========== EMAIL PROCESSOR (CONSUMER) ==========

import { Processor, Process } from '@nestjs/bull';
import { Job } from 'bull';
import { Injectable, Logger } from '@nestjs/common';
import { MailerService } from '@nestjs-modules/mailer';

@Injectable()
@Processor('email')
export class EmailProcessor {
  private readonly logger = new Logger(EmailProcessor.name);

  constructor(private readonly mailerService: MailerService) {}

  @Process('send-welcome')
  async sendWelcome(job: Job) {
    const { email, name } = job.data;
    
    this.logger.log(`Sending welcome email to ${email} (attempt ${job.attemptsMade + 1})`);

    await this.mailerService.sendMail({
      to: email,
      subject: 'Selamat Datang di My Store! 🎉',
      template: './emails/welcome',
      context: {
        name,
        email,
        loginUrl: `${process.env.APP_URL}/login`,
        appUrl: process.env.APP_URL,
        supportEmail: 'support@mystore.com',
        year: new Date().getFullYear(),
      },
    });

    await job.progress(100);
    this.logger.log(`Welcome email sent to ${email}`);

    return { success: true, email };
  }

  @Process('send-reset-password')
  async sendResetPassword(job: Job) {
    const { email, name, resetUrl, expiryHours } = job.data;
    
    this.logger.log(`Sending reset password email to ${email}`);

    await this.mailerService.sendMail({
      to: email,
      subject: 'Reset Password - My Store',
      template: './emails/reset-password',
      context: {
        name,
        resetUrl,
        expiryHours,
        appUrl: process.env.APP_URL,
        year: new Date().getFullYear(),
      },
    });

    this.logger.log(`Reset password email sent to ${email}`);
    return { success: true };
  }

  @Process('send-verification')

        name,
        verifyUrl,
        expiryHours,
        appUrl: process.env.APP_URL,
      },
    });

    return { success: true };
  }
}

// ========== AUTH SERVICE (BUSINESS LOGIC) ==========

import { Injectable, Logger, BadRequestException, NotFoundException } from '@nestjs/common';
import { UserRepository } from './user.repository';
import { TokenService } from './token.service';
import { EmailQueueService } from './email-queue.service';
import * as bcrypt from 'bcrypt';

@Injectable()
export class AuthService {
  private readonly logger = new Logger(AuthService.name);

  constructor(
    private readonly userRepository: UserRepository,
    private readonly tokenService: TokenService,
    private readonly emailQueueService: EmailQueueService,
  ) {}

  // ========== REGISTRASI + WELCOME EMAIL ==========
  async register(email: string, password: string, name: string) {
    // 1. Cek apakah email sudah terdaftar
    const existingUser = await this.userRepository.findByEmail(email);
    if (existingUser) {
      throw new BadRequestException('Email sudah terdaftar');
    }

    // 2. Hash password
    const hashedPassword = await bcrypt.hash(password, 12);

    // 3. Generate verification token
    const { token: verificationToken, hashedToken } = 
      this.tokenService.generateEmailVerificationToken();

    // 4. Simpan user ke database
    const user = await this.userRepository.create({
      email,
      name,
      password: hashedPassword,
      verificationToken: hashedToken,
      verificationTokenExpiry: new Date(Date.now() + 48 * 60 * 60 * 1000), // 48 jam
    });

    // 5. Queue welcome email
    await this.emailQueueService.queueWelcomeEmail({
      email: user.email,
      name: user.name,
    });

    // 6. Queue verification email
    await this.emailQueueService.queueVerificationEmail(
      user.email,
      user.name,
      verificationToken,
    );

    this.logger.log(`User registered: ${email}`);

    return {
      success: true,
      message: 'Registrasi berhasil. Silakan cek email untuk verifikasi.',
      userId: user.id,
    };
  }

  // ========== REQUEST RESET PASSWORD ==========
  async requestPasswordReset(email: string) {
    // 1. Cari user berdasarkan email
    const user = await this.userRepository.findByEmail(email);

    // Security: Jangan beri tahu apakah email terdaftar atau tidak
    // untuk mencegah email enumeration attack
    if (!user) {
      this.logger.warn(`Password reset requested for non-existent email: ${email}`);
      return {
        success: true,
        message: 'Jika email terdaftar, link reset password akan dikirim.',
      };
    }

    // 2. Generate reset token
    const { token: resetToken, hashedToken } = 
      this.tokenService.generateResetToken();

    // 3. Simpan token ke database (hash + expiry)
    await this.userRepository.update(user.id, {
      resetToken: hashedToken,
      resetTokenExpiry: new Date(Date.now() + 24 * 60 * 60 * 1000), // 24 jam
    });

    // 4. Queue reset password email
    await this.emailQueueService.queueResetPasswordEmail(
      user.email,
      user.name,
      resetToken,
    );

    this.logger.log(`Password reset requested for: ${email}`);

    return {
      success: true,
      message: 'Jika email terdaftar, link reset password akan dikirim.',
    };
  }

  // ========== RESET PASSWORD DENGAN TOKEN ==========
  async resetPassword(email: string, token: string, newPassword: string) {
    // 1. Validasi token
    const isValid = await this.tokenService.validateResetToken(email, token);
    
    if (!isValid) {
      throw new BadRequestException('Token reset password tidak valid atau sudah kedaluwarsa');
    }

    // 2. Dapatkan user
    const user = await this.userRepository.findByEmail(email);
    if (!user) {
      throw new NotFoundException('User tidak ditemukan');
    }

    // 3. Hash password baru
    const hashedPassword = await bcrypt.hash(newPassword, 12);

    // 4. Update password dan hapus token
    await this.userRepository.update(user.id, {
      password: hashedPassword,
      resetToken: undefined,
      resetTokenExpiry: undefined,
    });

    this.logger.log(`Password reset successfully for: ${email}`);

    return {
      success: true,
      message: 'Password berhasil direset. Silakan login dengan password baru.',
    };
  }

  // ========== VERIFIKASI EMAIL ==========
  async verifyEmail(email: string, token: string) {
    const user = await this.userRepository.findByEmail(email);
    
    if (!user) {
      throw new NotFoundException('User tidak ditemukan');
    }

    if (user.isVerified) {
      return {
        success: true,
        message: 'Email sudah terverifikasi',
      };
    }

    // Validasi token
    const hashedToken = this.tokenService.hashToken(token);
    
    if (hashedToken !== user.verificationToken) {
      throw new BadRequestException('Token verifikasi tidak valid');
    }

    if (new Date() > user.verificationTokenExpiry) {
      throw new BadRequestException('Token verifikasi sudah kedaluwarsa');
    }

    // Update status
    await this.userRepository.update(user.id, {
      isVerified: true,
      verificationToken: undefined,
      verificationTokenExpiry: undefined,
    });

    this.logger.log(`Email verified: ${email}`);

    return {
      success: true,
      message: 'Email berhasil diverifikasi!',
    };
  }
}

// ========== AUTH CONTROLLER ==========

import { Controller, Post, Body, Get, Query, HttpCode, HttpStatus } from '@nestjs/common';
import { AuthService } from './auth.service';

@Controller('auth')
export class AuthController {
  constructor(private readonly authService: AuthService) {}

  @Post('register')
  @HttpCode(HttpStatus.CREATED)
  async register(
    @Body('email') email: string,
    @Body('password') password: string,
    @Body('name') name: string,
  ) {
    return this.authService.register(email, password, name);
  }

  @Post('forgot-password')
  @HttpCode(HttpStatus.OK)
  async forgotPassword(@Body('email') email: string) {
    return this.authService.requestPasswordReset(email);
  }

  @Post('reset-password')
  @HttpCode(HttpStatus.OK)
  async resetPassword(
    @Body('email') email: string,
    @Body('token') token: string,
    @Body('newPassword') newPassword: string,
  ) {
    return this.authService.resetPassword(email, token, newPassword);
  }

  @Get('verify-email')
  async verifyEmail(
    @Query('email') email: string,
    @Query('token') token: string,
  ) {
    return this.authService.verifyEmail(email, token);
  }
}

**Kasus Penggunaan Nyata:**

### Welcome Email Flow:
1. User mendaftar di website dengan email dan password
2. Sistem menyimpan user ke database
3. Welcome email di-queue ke Bull Queue (tidak blocking)
4. User mendapatkan respons "Registrasi berhasil" segera
5. Worker Bull memproses queue dan mengirim email via SMTP
6. User menerima email selamat datang dengan info akun dan link login

### Reset Password Flow:
1. User klik "Lupa Password" dan memasukkan email
2. Sistem mengecek apakah email ada (tapi tidak memberi tahu user untuk security)
3. Generate random token 32 bytes (64 karakter hex)
4. Hash token dengan SHA-256, simpan hash + expiry (24 jam) ke DB
5. Kirim email dengan link: `https://app.com/reset-password?token=abc123&email=user@example.com`
6. User klik link, masukkan password baru
7. Sistem validasi token (hash yang diberikan vs yang di DB, cek expiry)
8. Jika valid, update password dan hapus token dari DB

### Security Best Practices:
- **Token Random**: Gunakan `crypto.randomBytes(32)` - tidak bisa ditebak
- **Token Hashing**: Simpan hash token di DB, bukan token asli (jika DB bocor)
- **Token Expiry**: Maksimal 24 jam untuk reset password, 48 jam untuk verifikasi
- **One Token Per Request**: Setiap request reset password invalidate token sebelumnya
- **Rate Limiting**: Batasi request reset password per email (misal: 5x per jam)
- **No Email Enumeration**: Jangan beri tahu apakah email terdaftar atau tidak
- **HTTPS Only**: Link reset password hanya bisa diakses via HTTPS
- **Invalidate After Use**: Token tidak bisa dipakai lagi setelah password direset
