# 26. Email dan Notifications

## 26.6. Push Notification: Pengenalan

**Definisi Singkat:**
Push Notification adalah pesan yang dikirim dari server ke aplikasi mobile/web secara real-time tanpa user harus meminta, digunakan untuk mengirim notifikasi penting, update, atau promosi bahkan ketika aplikasi tidak dibuka.

**Analogi:**
Seperti notifikasi di ponselmu dari WhatsApp, Instagram, atau email - pesan yang muncul di layar lockscreen meskipun kamu tidak membuka aplikasi tersebut.

**Poin-Poin Penting:**
- **Mobile**: Firebase Cloud Messaging (FCM) untuk Android/iOS
- **Web**: Web Push API dengan service worker
- **Provider**: FCM, APNS, Pusher, OneSignal, Pushwoosh
- **Target**: Token per device, topic, segment
- **Payload**: Title, body, icon, data tambahan

// Firebase Admin Initialization

// ========== DEVICE TOKEN REPOSITORY ==========

export interface DeviceToken {
  id: string;
  userId: string;
  token: string;
  deviceType: 'android' | 'ios' | 'web';
  deviceModel?: string;
  appVersion?: string;
  isActive: boolean;
  createdAt: Date;
  lastUsedAt: Date;
}

@Injectable()
export class DeviceTokenRepository {
  private tokens: Map<string, DeviceToken> = new Map();
  private userIdToTokens: Map<string, Set<string>> = new Map();

  async register(
    userId: string,
    token: string,
    deviceType: 'android' | 'ios' | 'web',
    deviceInfo?: {
      deviceModel?: string;
      appVersion?: string;
    },
  ): Promise<DeviceToken> {
    const id = 'dt_' + Date.now();
    const deviceToken: DeviceToken = {
      id,
      userId,
      token,
      deviceType,
      deviceModel: deviceInfo?.deviceModel,
      appVersion: deviceInfo?.appVersion,
      isActive: true,
      createdAt: new Date(),
      lastUsedAt: new Date(),
    };

    this.tokens.set(id, deviceToken);
    
    if (!this.userIdToTokens.has(userId)) {
      this.userIdToTokens.set(userId, new Set());
    }
    this.userIdToTokens.get(userId)!.add(id);

    return deviceToken;
  }

  async findByUserId(userId: string): Promise<DeviceToken[]> {
    const tokenIds = this.userIdToTokens.get(userId);
    if (!tokenIds) return [];
    
    const tokens: DeviceToken[] = [];
    for (const id of tokenIds) {
      const token = this.tokens.get(id);
      if (token && token.isActive) {
        tokens.push(token);
      }
    }
    
    return tokens;
  }

  async markAsInactive(token: string): Promise<void> {
    for (const deviceToken of this.tokens.values()) {
      if (deviceToken.token === token) {
        deviceToken.isActive = false;
        break;
      }
    }
  }

  async updateLastUsed(token: string): Promise<void> {
    for (const deviceToken of this.tokens.values()) {
      if (deviceToken.token === token) {
        deviceToken.lastUsedAt = new Date();
        break;
      }
    }
  }
}

// ========== PUSH NOTIFICATION SERVICE ==========

import { Injectable, Inject, Logger } from '@nestjs/common';
import * as admin from 'firebase-admin';
import { DeviceTokenRepository } from './device-token.repository';
import { messaging } from 'firebase-admin';

export interface PushNotificationPayload {
  title: string;
  body: string;
  imageUrl?: string;
  icon?: string;
  data?: Record<string, string>;
  priority?: 'high' | 'normal';
  collapseKey?: string;
}

@Injectable()
export class PushNotificationService {
  private readonly logger = new Logger(PushNotificationService.name);
  private messaging: messaging.Messaging;

  constructor(
    @Inject('FIREBASE_ADMIN') private readonly firebaseAdmin: typeof admin,
    private readonly deviceTokenRepository: DeviceTokenRepository,
  ) {
    this.messaging = firebaseAdmin.messaging();
  }

  // ========== KIRIM KE SATU DEVICE ==========
  async sendToDevice(
    token: string,
    payload: PushNotificationPayload,
  ): Promise<{ success: boolean; messageId?: string; error?: string }> {
    try {
      const message: messaging.Message = {
        token,
        notification: {
          title: payload.title,
          body: payload.body,
          imageUrl: payload.imageUrl,
        },
        data: payload.data,
        android: {
          priority: payload.priority === 'high' ? 'high' : 'normal',
          notification: {
            icon: payload.icon || 'ic_notification',
            color: '#667eea',
            clickAction: 'FLUTTER_NOTIFICATION_CLICK',
          },
        },
        apns: {
          payload: {
            aps: {
              sound: 'default',
              badge: 1,
            },
          },
        },
        webpush: {
          notification: {
            icon: payload.icon || '/assets/icon.png',
            badge: '/assets/badge.png',
          },
          fcmOptions: {
            link: payload.data?.clickUrl,
          },
        },
      };

      const response = await this.messaging.send(message);
      
      this.logger.log(`Push notification sent to device: token=${token.substring(0, 20)}..., messageId=${response}`);
      
      // Update last used
      await this.deviceTokenRepository.updateLastUsed(token);

      return { success: true, messageId: response };
    } catch (error) {
      this.logger.error(`Failed to send push notification: ${error.message}`);
      
      // Handle invalid token
      if (error.code === 'messaging/invalid-registration-token' ||
          error.code === 'messaging/registration-token-not-registered') {
        await this.deviceTokenRepository.markAsInactive(token);
      }

      return { success: false, error: error.message };
    }
  }

  // ========== KIRIM KE USER (SEMUA DEVICE) ==========
  async sendToUser(
    userId: string,
    payload: PushNotificationPayload,
  ): Promise<{ total: number; success: number; failed: number }> {
    const devices = await this.deviceTokenRepository.findByUserId(userId);
    
    if (devices.length === 0) {
      this.logger.warn(`No active devices found for user: ${userId}`);
      return { total: 0, success: 0, failed: 0 };
    }

    let success = 0;
    let failed = 0;

    for (const device of devices) {
      const result = await this.sendToDevice(device.token, payload);
      if (result.success) success++;
      else failed++;
    }

    this.logger.log(`Push notification to user ${userId}: total=${devices.length}, success=${success}, failed=${failed}`);
    
    return { total: devices.length, success, failed };
  }

  // ========== KIRIM MULTICAST (KE BANYAK DEVICE) ==========
  async sendMulticast(
    tokens: string[],
    payload: PushNotificationPayload,
  ): Promise<{ success: number; failed: number; results: Array<{ token: string; success: boolean }> }> {
    if (tokens.length === 0) {
      return { success: 0, failed: 0, results: [] };
    }

    // FCM batch max 500 tokens per request
    const batchSize = 500;
    let totalSuccess = 0;
    let totalFailed = 0;
    const allResults: Array<{ token: string; success: boolean }> = [];

    for (let i = 0; i < tokens.length; i += batchSize) {
      const batchTokens = tokens.slice(i, i + batchSize);
      
      const message: messaging.MulticastMessage = {
        tokens: batchTokens,
        notification: {
          title: payload.title,
          body: payload.body,
        },
        data: payload.data,
      };

      const response = await this.messaging.sendMulticast(message);
      
      totalSuccess += response.successCount;
      totalFailed += response.failureCount;

      // Handle failed tokens
      response.responses.forEach((resp, index) => {
        const token = batchTokens[index];
        allResults.push({ token, success: resp.success });
        
        if (!resp.success && resp.error) {
          if (resp.error.code === 'messaging/invalid-registration-token' ||
              resp.error.code === 'messaging/registration-token-not-registered') {
            this.deviceTokenRepository.markAsInactive(token);
          }
        }
      });
    }

    this.logger.log(`Multicast push: total=${tokens.length}, success=${totalSuccess}, failed=${totalFailed}`);
    
    return { success: totalSuccess, failed: totalFailed, results: allResults };
  }

  // ========== KIRIM KE TOPIC (SUBSCRIPTION) ==========
  async sendToTopic(
    topic: string,
    payload: PushNotificationPayload,
  ): Promise<{ success: boolean; messageId: string }> {
    const message: messaging.Message = {
      topic,
      notification: {
        title: payload.title,
        body: payload.body,
      },
      data: payload.data,
    };

    const messageId = await this.messaging.send(message);
    
    this.logger.log(`Push notification sent to topic: ${topic}, messageId=${messageId}`);
    
    return { success: true, messageId };
  }

  // ========== SUBSCRIBE KE TOPIC ==========
  async subscribeToTopic(tokens: string[], topic: string): Promise<void> {
    await this.messaging.subscribeToTopic(tokens, topic);
    this.logger.log(`Subscribed ${tokens.length} tokens to topic: ${topic}`);
  }

  async unsubscribeFromTopic(tokens: string[], topic: string): Promise<void> {
    await this.messaging.unsubscribeFromTopic(tokens, topic);
    this.logger.log(`Unsubscribed ${tokens.length} tokens from topic: ${topic}`);
  }

  // ========== CONVENIENCE METHODS ==========

  // Order notification
  async sendOrderCreatedNotification(
    userId: string,
    orderId: string,
    orderTotal: number,
  ) {
    return this.sendToUser(userId, {
      title: 'Order Berhasil Dibuat! 🎉',
      body: `Order #${orderId} dengan total Rp ${orderTotal.toLocaleString('id-ID')} sedang diproses.`,
      data: {
        type: 'order_created',
        orderId,
        clickUrl: `${process.env.APP_URL}/orders/${orderId}`,
      },
      priority: 'high',
    });
  }

  // Shipping notification
  async sendOrderShippedNotification(
    userId: string,
    orderId: string,
    trackingNumber: string,
  ) {
    return this.sendToUser(userId, {
      title: 'Order Dikirim! 🚚',
      body: `Order #${orderId} telah dikirim. No. Resi: ${trackingNumber}`,
      data: {
        type: 'order_shipped',
        orderId,
        trackingNumber,
      },
      priority: 'high',
    });
  }

  // Payment reminder
  async sendPaymentReminderNotification(
    userId: string,
    orderId: string,
    remainingMinutes: number,
  ) {
    return this.sendToUser(userId, {
      title: 'Segera Selesaikan Pembayaran! ⏰',
      body: `Order #${orderId} akan dibatalkan dalam ${remainingMinutes} menit.`,
      data: {
        type: 'payment_reminder',
        orderId,
      },
      priority: 'high',
    });
  }

  // Promotion notification
  async sendPromotionNotification(
    userIds: string[],
    title: string,
    body: string,
    promoCode: string,
  ) {
    const allTokens: string[] = [];
    
    for (const userId of userIds) {
      const devices = await this.deviceTokenRepository.findByUserId(userId);
      allTokens.push(...devices.map(d => d.token));
    }

    return this.sendMulticast(allTokens, {
      title,
      body,
      data: {
        type: 'promotion',
        promoCode,
      },
      priority: 'normal',
    });
  }

  // Security alert
  async sendSecurityAlertNotification(
    userId: string,
    message: string,
  ) {
    return this.sendToUser(userId, {
      title: 'Peringatan Keamanan 🔒',
      body: message,
      data: {
        type: 'security_alert',
      },
      priority: 'high',
    });
  }
}

// ========== PUSH NOTIFICATION CONTROLLER ==========

import { Controller, Post, Body, Get, Param, Delete } from '@nestjs/common';
import { PushNotificationService, PushNotificationPayload } from './push-notification.service';
import { DeviceTokenRepository } from './device-token.repository';

@Controller('push-notifications')
export class PushNotificationController {
  constructor(
    private readonly pushNotificationService: PushNotificationService,
    private readonly deviceTokenRepository: DeviceTokenRepository,
  ) {}

  // Register device token
  @Post('register')
  async registerToken(
    @Body('userId') userId: string,
    @Body('token') token: string,
    @Body('deviceType') deviceType: 'android' | 'ios' | 'web',
    @Body('deviceModel') deviceModel?: string,
    @Body('appVersion') appVersion?: string,
  ) {
    const deviceToken = await this.deviceTokenRepository.register(
      userId,
      token,
      deviceType,
      { deviceModel, appVersion },
    );
    return { success: true, deviceTokenId: deviceToken.id };
  }

  // Send to specific device
  @Post('send')
  async sendNotification(
    @Body('token') token: string,
    @Body('title') title: string,
    @Body('body') body: string,
    @Body('data') data?: Record<string, string>,
  ) {
    const payload: PushNotificationPayload = { title, body, data };
    return this.pushNotificationService.sendToDevice(token, payload);
  }

  // Send to user
  @Post('send-to-user/:userId')
  async sendToUser(
    @Param('userId') userId: string,
    @Body('title') title: string,
    @Body('body') body: string,
  ) {
    return this.pushNotificationService.sendToUser(userId, { title, body });
  }

  // Send test order notification
  @Post('test-order-notification')
  async testOrderNotification(
    @Body('userId') userId: string,
    @Body('orderId') orderId: string,
    @Body('total') total: number,
  ) {
    return this.pushNotificationService.sendOrderCreatedNotification(
      userId,
      orderId,
      total,
    );
  }

  // Send to topic
  @Post('send-to-topic')
  async sendToTopic(
    @Body('topic') topic: string,
    @Body('title') title: string,
    @Body('body') body: string,
  ) {
    return this.pushNotificationService.sendToTopic(topic, { title, body });
  }

  // Subscribe to topic
  @Post('subscribe-topic')
  async subscribeToTopic(
    @Body('tokens') tokens: string[],
    @Body('topic') topic: string,
  ) {
    await this.pushNotificationService.subscribeToTopic(tokens, topic);
    return { success: true, message: `Subscribed to ${topic}` };
  }

  // Get user devices
  @Get('user-devices/:userId')
  async getUserDevices(@Param('userId') userId: string) {
    return this.deviceTokenRepository.findByUserId(userId);
  }
}

**Kasus Penggunaan Nyata:**

### 1. E-commerce Order Updates:
- User buat order -> Push notification "Order Berhasil Dibuat"
- Admin konfirmasi pembayaran -> Push "Pembayaran Diterima"
- Paket dikirim -> Push "Order Dikirim" dengan nomor resi
- Paket diterima -> Push "Order Selesai" + ajak review

### 2. Chat/Messaging App:
- Ada pesan baru -> Push dengan preview pesan
- User di-tag di grup -> Push notifikasi khusus
- Voice/video call incoming -> Push dengan high priority

### 3. Social Media:
- Ada yang like/komentar postingan -> Push notifikasi
- Ada yang follow -> Push "User X mulai mengikuti Anda"
- Live stream mulai -> Push ke followers

### 4. Security:
- Login dari device baru -> Push alert
- Password diubah -> Push notifikasi
- 2FA diaktifkan -> Push konfirmasi

### 5. Marketing/Promosi:
- Flash sale mulai -> Push ke semua user yang berlangganan topic "promo"
- Diskon personal -> Push berdasarkan riwayat belanja
- Restock produk favorit -> Push ke user yang pernah wishlist

### Push vs Email:
| Fitur               | Push Notification           | Email                      |
|---------------------|-----------------------------|----------------------------|
| Real-time           | Ya (instant)                | Tidak (delay bervariasi)   |
| Open Rate           | Tinggi (user sering cek)    | Lebih rendah               |
| Engagement          | Tinggi (tap langsung ke app) | Bervariasi                 |
| Content Length      | Pendek (title + body)        | Panjang, detail            |
| Rich Media          | Terbatas                     | Full HTML, images, attach  |
| Opt-out             | User bisa disable di setting | Unsubscribe link           |
| Use Case            | Alert, update, time-sensitive | Newsletter, detail, receipt |
