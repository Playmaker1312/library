# 26. Email dan Notifications

## 26.3. Email Templates: Handlebars, Pug

**Definisi Singkat:**
Email Templates adalah file template yang memisahkan struktur dan desain email dari kode logika, menggunakan template engine seperti Handlebars atau Pug untuk memasukkan data dinamis (nama user, order ID, dll).

**Analogi:**
Seperti surat undangan kosong yang sudah ada desainnya - kamu hanya perlu mengisi nama tamu, tanggal, dan tempat tanpa perlu mendesain ulang setiap kali.

**Poin-Poin Penting:**
- **Handlebars**: Template engine dengan syntax `{{variable}}`, paling populer untuk email
- **Pug**: Template engine dengan syntax indentasi-based, ringkas dan ekspresif
- **Context**: Data yang dimasukkan ke template (nama, order, dll)
- **Helpers**: Fungsi custom untuk formatting (date, currency, dll)
- **Partials**: Template parsial untuk komponen reusable (header, footer)

**Contoh Kode:**

// ========== HANDLEBARS TEMPLATE ENGINE ==========

// Install: npm install handlebars @nestjs-modules/mailer

import { Module } from '@nestjs/common';
import { MailerModule } from '@nestjs-modules/mailer';
import { HandlebarsAdapter } from '@nestjs-modules/mailer/dist/adapters/handlebars.adapter';
import { join } from 'path';

@Module({
  imports: [
    MailerModule.forRoot({
      transport: {
        host: 'smtp.gmail.com',
        port: 587,
        auth: {
          user: process.env.MAIL_USER,
          pass: process.env.MAIL_PASSWORD,
        },
      },
      defaults: {
        from: '"My App" <no-reply@example.com>',
      },
      template: {
        dir: join(__dirname, 'templates'),
        adapter: new HandlebarsAdapter({
          // Custom Helpers
          formatDate: (date: Date) => {
            return new Date(date).toLocaleDateString('id-ID', {
              year: 'numeric',
              month: 'long',
              day: 'numeric',
            });
          },
          formatCurrency: (amount: number, currency: string = 'IDR') => {
            return new Intl.NumberFormat('id-ID', {
              style: 'currency',
              currency: currency,
            }).format(amount);
          },
          formatNumber: (num: number) => {
            return new Intl.NumberFormat('id-ID').format(num);
          },
          ifEquals: (arg1: any, arg2: any, options: any) => {
            return arg1 === arg2 ? options.fn(this) : options.inverse(this);
          },
          truncate: (text: string, length: number) => {
            if (text.length <= length) return text;
            return text.substring(0, length) + '...';
          },
        }),
        options: {
          strict: true,
        },
      },
    }),
  ],
})
export class HandlebarsMailModule {}

// Install: npm install pug @nestjs-modules/mailer

import { Module } from '@nestjs/common';
import { MailerModule } from '@nestjs-modules/mailer';
import { PugAdapter } from '@nestjs-modules/mailer/dist/adapters/pug.adapter';
import { join } from 'path';

@Module({
  imports: [
    MailerModule.forRoot({
      transport: {
        host: process.env.MAIL_HOST,
        port: parseInt(process.env.MAIL_PORT),
        auth: {
          user: process.env.MAIL_USER,
          pass: process.env.MAIL_PASSWORD,
        },
      },
      template: {
        dir: join(__dirname, 'templates-pug'),
        adapter: new PugAdapter(),
        options: {
          pretty: true,
        },
      },
    }),
  ],
})
export class PugMailModule {}

// ========== MAIL SERVICE DENGAN TEMPLATE ==========

import { Injectable, Logger } from '@nestjs/common';
import { MailerService } from '@nestjs-modules/mailer';

@Injectable()
export class TemplateMailService {
  private readonly logger = new Logger(TemplateMailService.name);

  constructor(private readonly mailerService: MailerService) {}

  // Send welcome email
  async sendWelcomeEmail(user: {
    id: string;
    email: string;
    name: string;
    registeredAt: Date;
  }) {
    await this.mailerService.sendMail({
      to: user.email,
      subject: 'Selamat Datang di My Store! 🎉',
      template: './welcome',
      context: {
        name: user.name,
        email: user.email,
        registeredAt: user.registeredAt,
        loginUrl: `${process.env.APP_URL}/login`,
        appUrl: process.env.APP_URL,
        year: new Date().getFullYear(),
      },
    });
    this.logger.log(`Welcome email sent to ${user.email}`);
  }

  // Send order confirmation
  async sendOrderConfirmation(order: {
    id: string;
    customerName: string;
    customerEmail: string;
    items: Array<{
      productName: string;
      quantity: number;
      price: number;
      subtotal: number;
    }>;
    subtotal: number;
    shippingCost: number;
    total: number;
    status: string;
    orderDate: Date;
    shippingAddress: {
      name: string;
      street: string;
      city: string;
      province: string;
    };
    courier: string;
    paymentDueDate?: Date;
  }) {
    await this.mailerService.sendMail({
      to: order.customerEmail,
      subject: `Konfirmasi Order #${order.id}`,
      template: './order-confirmation',
      context: {
        orderId: order.id,
        customerName: order.customerName,
        items: order.items,
        subtotal: order.subtotal,
        shippingCost: order.shippingCost,
        total: order.total,
        status: order.status,
        orderDate: order.orderDate,
        shippingAddress: order.shippingAddress,
        courier: order.courier,
        paymentDueDate: order.paymentDueDate,
        orderDetailUrl: `${process.env.APP_URL}/orders/${order.id}`,
        appUrl: process.env.APP_URL,
        year: new Date().getFullYear(),
      },
    });
    this.logger.log(`Order confirmation sent for order #${order.id}`);
  }

  // Send reset password
  async sendResetPassword(
    email: string,
    name: string,
    resetToken: string,
  ) {
    const resetUrl = `${process.env.APP_URL}/reset-password?token=${resetToken}`;
    
    await this.mailerService.sendMail({
      to: email,
      subject: 'Reset Password - My Store',
      template: './reset-password',
      context: {
        name,
        resetUrl,
        expiryHours: 24,
        appUrl: process.env.APP_URL,
        year: new Date().getFullYear(),
      },
    });
    this.logger.log(`Reset password email sent to ${email}`);
  }
}

// ========== PERBANDINGAN HANDLEBARS VS PUG ==========

/*
| Fitur               | Handlebars                         | Pug                              |
|---------------------|------------------------------------|----------------------------------|
| Syntax              | {{variable}}, {{#if}}, {{#each}}  | #variable, if condition, each   |
| Style               | HTML-like dengan curly braces     | Indentation-based, minimal      |
| Popularitas         | Paling populer untuk email         | Kurang umum untuk email          |
| Readability         | Mudah dibaca (mirip HTML)         | Ringkas tapi butuh belajar      |
| Partials            | {{> partialName}}                  | include partialName              |
| Helpers             | Mudah ditambahkan                  | Fungsi JavaScript                |
| Error Handling      | Strict mode opsional               | Error saat compile               |
*/

// ========== BEST PRACTICES EMAIL TEMPLATES ==========

/*
1. **CSS Inline**: Kebanyakan email client tidak support external CSS
2. **Table Layout**: Untuk layout yang konsisten di semua client
3. **Web Safe Fonts**: Arial, Verdana, Georgia, Times New Roman
4. **Max Width 600px**: Standar untuk email
5. **Plain Text Fallback**: Sediakan versi teks biasa
6. **Test di Berbagai Client**: Gmail, Outlook, Yahoo, Apple Mail
7. **Responsive Design**: Media query untuk mobile
8. **Avoid JavaScript**: Hampir semua client memblokir JS
9. **Absolute URLs**: Semua link dan gambar harus absolute
10. **Alt Text**: Selalu tambahkan alt text untuk gambar
*/

1. **E-commerce Transactional Email**: Welcome, order confirmation, shipping update, review reminder - semua menggunakan template Handlebars dengan data order dinamis
2. **SaaS Onboarding**: Email seri onboarding (Day 0: Welcome, Day 1: Getting Started, Day 3: Tips & Tricks) dengan template yang konsisten
3. **Newsletter**: Template newsletter dengan bagian header, featured content, CTA buttons, footer unsubscribe yang reusable
4. **Invoice/Receipt**: Template faktur dengan tabel items dinamis, perhitungan total menggunakan helper formatCurrency
5. **Notification System**: Berbagai template notifikasi (security alert, payment reminder, account update) dengan styling yang konsisten
