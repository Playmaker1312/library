# 26. Email dan Notifications

## 26.2. SMTP Configuration

**Definisi Singkat:**
SMTP (Simple Mail Transfer Protocol) Configuration adalah pengaturan koneksi ke server email untuk mengirim email, mencakup host, port, authentication, dan opsi keamanan seperti TLS/SSL.

**Analogi:**
Seperti konfigurasi alamat kantor pos - kamu perlu tahu alamat lengkap (host), nomor lantai (port), dan kunci gedung (username/password) untuk bisa mengirim surat.

**Poin-Poin Penting:**
- **Host**: Alamat server SMTP (smtp.gmail.com, smtp.sendgrid.net)
- **Port**: 25 (non-secure), 587 (STARTTLS), 465 (SSL/TLS)
- **Secure**: `true` untuk port 465, `false` untuk port 587
- **Auth**: `user` dan `pass` untuk authentication
- **TLS**: Transport Layer Security untuk enkripsi
- **Pooling**: Reuse koneksi untuk performance

          rejectUnauthorized: true,
        },
      },
      defaults: {
        from: '"My App" <your.email@gmail.com>',
      },

@Module({
  imports: [
    MailerModule.forRootAsync({
      imports: [ConfigModule],
      useFactory: (configService: ConfigService) => ({
        transport: {
          // Basic connection
          host: configService.get('MAIL_HOST'),
          port: configService.get('MAIL_PORT'),
          secure: configService.get('MAIL_SECURE'),
          
          // Authentication
          auth: {
            user: configService.get('MAIL_USER'),
            pass: configService.get('MAIL_PASSWORD'),
          },
          
          // TLS/SSL Options
          tls: {
            rejectUnauthorized: configService.get('NODE_ENV') === 'production',
            // Untuk custom certificate
            // ca: fs.readFileSync('/path/to/ca.pem'),
            // cert: fs.readFileSync('/path/to/cert.pem'),

          // Connection Pooling (Performance optimization)

// ========== TESTING SMTP CONNECTION ==========

import { Injectable, Logger } from '@nestjs/common';
import { MailerService } from '@nestjs-modules/mailer';
import * as nodemailer from 'nodemailer';

@Injectable()
export class SmtpTestingService {
  private readonly logger = new Logger(SmtpTestingService.name);

  constructor(private readonly mailerService: MailerService) {}

  // Test koneksi SMTP
  async testConnection(): Promise<{ success: boolean; message: string }> {
    try {
      // Akses transporter dari mailerService
      const transporter = (this.mailerService as any).transport;
      
      // Verify connection
      await transporter.verify();
      
      this.logger.log('SMTP connection verified successfully');
      return { success: true, message: 'SMTP connection OK' };
    } catch (error) {
      this.logger.error(`SMTP connection failed: ${error.message}`);
      return { success: false, message: error.message };
    }
  }

  // Kirim test email dengan nodemailer langsung
  async sendTestEmailDirect(): Promise<void> {
    // Buat transporter secara langsung untuk testing
    const transporter = nodemailer.createTransport({
      host: process.env.MAIL_HOST,
      port: parseInt(process.env.MAIL_PORT),
      secure: process.env.MAIL_SECURE === 'true',
      auth: {
        user: process.env.MAIL_USER,
        pass: process.env.MAIL_PASSWORD,
      },
    });

    // Test connection
    await transporter.verify();
    this.logger.log('SMTP Connection OK');

    // Kirim test email
    const info = await transporter.sendMail({
      from: process.env.MAIL_FROM,
      to: 'test@example.com',
      subject: 'Test Email',
      text: 'This is a test email',
      html: '<b>This is a test email</b>',
    });

    this.logger.log(`Email sent: ${info.messageId}`);
    this.logger.log(`Preview URL: ${nodemailer.getTestMessageUrl(info)}`);
  }
}

**Kasus Penggunaan Nyata:**
1. **Production dengan SendGrid**: Menggunakan SendGrid untuk email transactional (welcome, reset password) dengan deliverability tinggi
2. **Development dengan Mailtrap**: Semua email development di-catch oleh Mailtrap, tidak terkirim ke user asli
3. **High Volume Marketing**: Menggunakan Mailgun untuk newsletter dan email marketing dengan volume ribuan per hari
4. **Enterprise dengan AWS SES**: Perusahaan besar menggunakan AWS SES untuk scalability dan integration dengan AWS ecosystem
5. **Fallback Configuration**: Jika provider utama down, otomatis switch ke provider cadangan (SendGrid -> Mailgun)
6. **Multi-environment Config**: Development menggunakan Mailtrap, Staging menggunakan Ethereal, Production menggunakan SendGrid
