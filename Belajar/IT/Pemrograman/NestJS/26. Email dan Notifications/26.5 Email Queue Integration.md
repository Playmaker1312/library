# 26. Email dan Notifications

## 26.5. Email Queue Integration

**Definisi Singkat:**
Email Queue Integration adalah praktik mengintegrasikan sistem email dengan Bull Queue untuk mengirim email secara asynchronous, dengan fitur retry, rate limiting, dan monitoring untuk memastikan email terkirim dengan andal.

**Analogi:**
Seperti sistem pengiriman surat yang efisien: alih-alih mengirim satu per satu sambil menunggu (sync), kamu memasukkan semua surat ke dalam kotak pos (queue), dan kurir (worker) akan mengantarkannya satu per satu dengan optimal.

**Poin-Poin Penting:**
- **Async Processing**: User tidak menunggu email terkirim
- **Retry Mechanism**: Jika SMTP error, coba lagi dengan backoff
- **Rate Limiting**: Hindari terblokir oleh provider email
- **Monitoring**: Lacak email yang terkirim, gagal, pending
- **Queue Management**: Pause, resume, retry failed jobs

          port: configService.get('REDIS_PORT'),

// ========== EMAIL TYPES & DTO ==========

export enum EmailType {
  WELCOME = 'welcome',
  RESET_PASSWORD = 'reset-password',
  ORDER_CONFIRMATION = 'order-confirmation',
  SHIPPING_UPDATE = 'shipping-update',
  NEWSLETTER = 'newsletter',
  VERIFICATION = 'verification',
  PROMOTION = 'promotion',
  SECURITY_ALERT = 'security-alert',
}

export interface EmailJobData {
  type: EmailType;
  to: string;
  toName?: string;
  subject?: string;
  context: Record<string, any>;
  priority?: 'high' | 'normal' | 'low';
  tags?: string[];
  metadata?: Record<string, any>;
}

export interface EmailLog {
  id: string;
  jobId: string;
  type: EmailType;
  to: string;
  status: 'queued' | 'sending' | 'sent' | 'failed' | 'retried';
  attempts: number;
  maxAttempts: number;
  error?: string;
  sentAt?: Date;
  queuedAt: Date;
  updatedAt: Date;
  tags?: string[];
  metadata?: Record<string, any>;
}

// ========== EMAIL QUEUE SERVICE (PRODUCER) ==========

import { Injectable, Logger } from '@nestjs/common';
import { InjectQueue } from '@nestjs/bull';
import { Queue, Job } from 'bull';
import { EmailType, EmailJobData, EmailLog } from './email.types';
import { EmailLogRepository } from './email-log.repository';

@Injectable()
export class EmailQueueService {
  private readonly logger = new Logger(EmailQueueService.name);

  constructor(
    @InjectQueue('email') private readonly emailQueue: Queue,
    private readonly emailLogRepository: EmailLogRepository,
  ) {}

  // ========== PRIORITY MAPPING ==========
  private priorityMap = {
    high: 1,
    normal: 5,
    low: 10,
  };

  // ========== QUEUE EMAIL GENERIC ==========
  async queueEmail(emailData: EmailJobData): Promise<{ jobId: string; logId: string }> {
    const priority = this.priorityMap[emailData.priority || 'normal'];
    
    // 1. Buat log entry
    const emailLog = await this.emailLogRepository.create({
      type: emailData.type,
      to: emailData.to,
      status: 'queued',
      attempts: 0,
      maxAttempts: 5,
      queuedAt: new Date(),
      updatedAt: new Date(),
      tags: emailData.tags,
      metadata: emailData.metadata,
    });

    // 2. Queue ke Bull
    const job = await this.emailQueue.add(
      emailData.type,
      {
        ...emailData,
        logId: emailLog.id,
      },
      {
        priority,
        jobId: `email-${emailData.type}-${Date.now()}`,
        // attempts dan backoff sudah di default job options
      },
    );

    // 3. Update log dengan job ID
    await this.emailLogRepository.update(emailLog.id, {
      jobId: job.id,
    });

    this.logger.log(
      `Email queued: type=${emailData.type}, to=${emailData.to}, jobId=${job.id}`,
    );

    return { jobId: job.id, logId: emailLog.id };
  }

  // ========== CONVENIENCE METHODS ==========

  async queueWelcomeEmail(user: { email: string; name: string }): Promise<string> {
    const result = await this.queueEmail({
      type: EmailType.WELCOME,
      to: user.email,
      toName: user.name,
      priority: 'high',
      context: {
        name: user.name,
        email: user.email,
        loginUrl: `${process.env.APP_URL}/login`,
        appUrl: process.env.APP_URL,
      },
      tags: ['onboarding', 'welcome'],
      metadata: {
        userId: 'user_' + Date.now(),
      },
    });
    return result.jobId;
  }

  async queueResetPasswordEmail(
    email: string,
    name: string,
    resetToken: string,
  ): Promise<string> {
    const resetUrl = `${process.env.APP_URL}/reset-password?token=${resetToken}&email=${encodeURIComponent(email)}`;
    
    const result = await this.queueEmail({
      type: EmailType.RESET_PASSWORD,
      to: email,
      toName: name,
      priority: 'high', // User sedang menunggu
      context: {
        name,
        resetUrl,
        expiryHours: 24,
      },
      tags: ['security', 'reset-password'],
    });
    return result.jobId;
  }

  async queueOrderConfirmation(
    email: string,
    order: {
      id: string;
      customerName: string;
      items: any[];
      total: number;
    },
  ): Promise<string> {
    const result = await this.queueEmail({
      type: EmailType.ORDER_CONFIRMATION,
      to: email,
      toName: order.customerName,
      priority: 'normal',
      context: {
        orderId: order.id,
        customerName: order.customerName,
        items: order.items,
        total: order.total,
        orderDetailUrl: `${process.env.APP_URL}/orders/${order.id}`,
      },
      tags: ['transactional', 'order'],
      metadata: {
        orderId: order.id,
      },
    });
    return result.jobId;
  }

  async queueNewsletter(
    recipients: { email: string; name: string }[],
    newsletter: {
      subject: string;
      content: string;
    },
  ): Promise<string[]> {
    const jobIds: string[] = [];
    
    for (const recipient of recipients) {
      const result = await this.queueEmail({
        type: EmailType.NEWSLETTER,
        to: recipient.email,
        toName: recipient.name,
        subject: newsletter.subject,
        priority: 'low', // Newsletter tidak urgent
        context: {
          name: recipient.name,
          content: newsletter.content,
          unsubscribeUrl: `${process.env.APP_URL}/unsubscribe?email=${encodeURIComponent(recipient.email)}`,
        },
        tags: ['marketing', 'newsletter'],
      });
      jobIds.push(result.jobId);
      
      // Tambahkan delay kecil untuk rate limiting
      await new Promise(resolve => setTimeout(resolve, 100));
    }
    
    return jobIds;
  }

  // ========== QUEUE MANAGEMENT ==========

  async getQueueStats(): Promise<{
    waiting: number;
    active: number;
    completed: number;
    failed: number;
    delayed: number;
  }> {
    const [waiting, active, completed, failed, delayed] = await Promise.all([
      this.emailQueue.getWaitingCount(),
      this.emailQueue.getActiveCount(),
      this.emailQueue.getCompletedCount(),
      this.emailQueue.getFailedCount(),
      this.emailQueue.getDelayedCount(),
    ]);

    return { waiting, active, completed, failed, delayed };
  }

  async retryFailedJobs(): Promise<number> {
    const failedJobs = await this.emailQueue.getFailed();
    let retried = 0;
    
    for (const job of failedJobs) {
      await job.retry();
      retried++;
      
      // Update log
      const log = await this.emailLogRepository.findByJobId(job.id.toString());
      if (log) {
        await this.emailLogRepository.update(log.id, {
          status: 'retried',
          attempts: log.attempts + 1,
          updatedAt: new Date(),
        });
      }
    }
    
    this.logger.log(`Retried ${retried} failed jobs`);
    return retried;
  }

  async pauseQueue(): Promise<void> {
    await this.emailQueue.pause();
    this.logger.log('Email queue paused');
  }

  async resumeQueue(): Promise<void> {
    await this.emailQueue.resume();
    this.logger.log('Email queue resumed');
  }

  async clearQueue(): Promise<void> {
    await this.emailQueue.empty();
    this.logger.log('Email queue cleared');
  }
}

// ========== EMAIL PROCESSOR (CONSUMER) ==========

import {
  Processor,
  Process,
  OnQueueActive,
  OnQueueCompleted,
  OnQueueFailed,
  OnQueueError,
} from '@nestjs/bull';
import { Job } from 'bull';
import { Injectable, Logger } from '@nestjs/common';
import { MailerService } from '@nestjs-modules/mailer';
import { EmailType, EmailJobData } from './email.types';
import { EmailLogRepository } from './email-log.repository';

@Injectable()
@Processor({
  name: 'email',
  concurrency: 5, // 5 email secara concurrent
})
export class EmailProcessor {
  private readonly logger = new Logger(EmailProcessor.name);

  constructor(
    private readonly mailerService: MailerService,
    private readonly emailLogRepository: EmailLogRepository,
  ) {}

  // ========== TEMPLATE MAPPING ==========
  private templateMap: Record<EmailType, string> = {
    [EmailType.WELCOME]: './emails/welcome',
    [EmailType.RESET_PASSWORD]: './emails/reset-password',
    [EmailType.ORDER_CONFIRMATION]: './emails/order-confirmation',
    [EmailType.SHIPPING_UPDATE]: './emails/shipping-update',
    [EmailType.NEWSLETTER]: './emails/newsletter',
    [EmailType.VERIFICATION]: './emails/verify-email',
    [EmailType.PROMOTION]: './emails/promotion',
    [EmailType.SECURITY_ALERT]: './emails/security-alert',
  };

  private subjectMap: Record<EmailType, string> = {
    [EmailType.WELCOME]: 'Selamat Datang di My Store! 🎉',
    [EmailType.RESET_PASSWORD]: 'Reset Password - My Store',
    [EmailType.ORDER_CONFIRMATION]: 'Konfirmasi Order #{orderId}',
    [EmailType.SHIPPING_UPDATE]: 'Update Pengiriman Order #{orderId}',
    [EmailType.NEWSLETTER]: 'Newsletter Bulanan My Store',
    [EmailType.VERIFICATION]: 'Verifikasi Email Anda',
    [EmailType.PROMOTION]: 'Diskon Spesial untuk Anda!',
    [EmailType.SECURITY_ALERT]: 'Peringatan Keamanan Akun',
  };

  // ========== GENERIC EMAIL PROCESSOR ==========
  @Process()
  async processEmail(job: Job<EmailJobData & { logId: string }>) {
    const { type, to, toName, context, logId } = job.data;
    const attempt = job.attemptsMade + 1;

    this.logger.log(
      `Processing email (attempt ${attempt}): type=${type}, to=${to}, jobId=${job.id}`,
    );

    // Update status log
    await this.emailLogRepository.update(logId, {
      status: 'sending',
      attempts: attempt,
      updatedAt: new Date(),
    });

    try {
      // Generate subject (dengan placeholder jika ada)
      let subject = this.subjectMap[type] || job.data.subject;
      
      // Replace placeholder di subject
      for (const [key, value] of Object.entries(context)) {
        if (typeof value === 'string' || typeof value === 'number') {
          subject = subject.replace(`{${key}}`, String(value));
        }
      }

      // Kirim email
      await this.mailerService.sendMail({
        to,
        from: process.env.MAIL_FROM,
        subject,
        template: this.templateMap[type],
        context: {
          ...context,
          appUrl: process.env.APP_URL,
          year: new Date().getFullYear(),
        },
      });

      // Update status ke sent
      await this.emailLogRepository.update(logId, {
        status: 'sent',
        sentAt: new Date(),
        updatedAt: new Date(),
      });

      this.logger.log(`Email sent successfully: to=${to}, jobId=${job.id}`);

      await job.progress(100);
      return { success: true, sentAt: new Date().toISOString() };
    } catch (error) {
      this.logger.error(
        `Failed to send email (attempt ${attempt}): to=${to}, error=${error.message}`,
      );

      // Update log dengan error
      await this.emailLogRepository.update(logId, {
        status: attempt >= 5 ? 'failed' : 'retried',
        error: error.message,
        updatedAt: new Date(),
      });

      // Re-throw untuk trigger retry
      throw error;
    }
  }

  // ========== EVENT LISTENERS ==========

  @OnQueueActive()
  onActive(job: Job) {
    this.logger.debug(
      `Job started: id=${job.id}, name=${job.name}, attempt=${job.attemptsMade + 1}`,
    );
  }

  @OnQueueCompleted()
  onCompleted(job: Job, result: any) {
    this.logger.log(
      `Job completed: id=${job.id}, result=${JSON.stringify(result)}`,
    );
  }

  @OnQueueFailed()
  onFailed(job: Job, err: Error) {
    this.logger.error(
      `Job failed: id=${job.id}, attempt=${job.attemptsMade}/${job.opts.attempts}, error=${err.message}`,
    );

    // Jika sudah mencapai max attempts, kirim alert
    if (job.attemptsMade >= job.opts.attempts) {
      this.sendAlertForPermanentFailure(job, err);
    }
  }

  @OnQueueError()
  onQueueError(error: Error) {
    this.logger.error(`Queue error: ${error.message}`);
  }

  private sendAlertForPermanentFailure(job: Job, error: Error) {
    this.logger.error(
      `PERMANENT FAILURE: Job ${job.id} failed after ${job.opts.attempts} attempts. Error: ${error.message}`,
    );
    // TODO: Kirim alert ke Slack/email admin
  }
}

// ========== EMAIL LOG REPOSITORY ==========

import { Injectable } from '@nestjs/common';
import { EmailLog } from './email.types';

@Injectable()
export class EmailLogRepository {
  private logs: Map<string, EmailLog> = new Map();

  async create(data: Omit<EmailLog, 'id'>): Promise<EmailLog> {
    const id = 'el_' + Date.now() + '_' + Math.random().toString(36).substr(2, 9);
    const log: EmailLog = { ...data, id };
    this.logs.set(id, log);
    return log;
  }

  async update(id: string, updates: Partial<EmailLog>): Promise<EmailLog> {
    const log = this.logs.get(id);
    if (!log) throw new Error('Email log not found');
    const updated = { ...log, ...updates };
    this.logs.set(id, updated);
    return updated;
  }

  async findByJobId(jobId: string): Promise<EmailLog | null> {
    for (const log of this.logs.values()) {
      if (log.jobId === jobId) return log;
    }
    return null;
  }

  async findByEmail(to: string): Promise<EmailLog[]> {
    const results: EmailLog[] = [];
    for (const log of this.logs.values()) {
      if (log.to === to) results.push(log);
    }
    return results.sort((a, b) => b.queuedAt.getTime() - a.queuedAt.getTime());
  }

  async getStats(): Promise<{
    total: number;
    sent: number;
    failed: number;
    queued: number;
  }> {
    let total = 0, sent = 0, failed = 0, queued = 0;
    
    for (const log of this.logs.values()) {
      total++;
      if (log.status === 'sent') sent++;
      else if (log.status === 'failed') failed++;
      else if (log.status === 'queued') queued++;
    }
    
    return { total, sent, failed, queued };
  }
}

// ========== EMAIL CONTROLLER ==========

import { Controller, Get, Post, Delete, Body, Param } from '@nestjs/common';
import { EmailQueueService } from './email-queue.service';
import { EmailLogRepository } from './email-log.repository';

@Controller('email-queue')
export class EmailController {
  constructor(
    private readonly emailQueueService: EmailQueueService,
    private readonly emailLogRepository: EmailLogRepository,
  ) {}

  @Get('stats')
  async getStats() {
    const queueStats = await this.emailQueueService.getQueueStats();
    const logStats = await this.emailLogRepository.getStats();
    
    return {
      queue: queueStats,
      logs: logStats,
    };
  }

  @Post('retry-failed')
  async retryFailed() {
    const count = await this.emailQueueService.retryFailedJobs();
    return { message: `Retried ${count} failed jobs` };
  }

  @Post('pause')
  async pauseQueue() {
    await this.emailQueueService.pauseQueue();
    return { message: 'Queue paused' };
  }

  @Post('resume')
  async resumeQueue() {
    await this.emailQueueService.resumeQueue();
    return { message: 'Queue resumed' };
  }

  @Delete('clear')
  async clearQueue() {
    await this.emailQueueService.clearQueue();
    return { message: 'Queue cleared' };
  }

  @Get('logs/:email')
  async getEmailLogs(@Param('email') email: string) {
    return this.emailLogRepository.findByEmail(email);
  }

  // Test endpoint
  @Post('test-welcome')
  async testWelcome(@Body('email') email: string, @Body('name') name: string) {
    const jobId = await this.emailQueueService.queueWelcomeEmail({ email, name });
    return { jobId, message: 'Welcome email queued' };
  }
}

**Kasus Penggunaan Nyata:**

### 1. E-commerce Transactional Emails:
- Order confirmation dikirim segera setelah pembayaran
- Shipping update saat paket dikirim
- Review reminder 7 hari setelah order diterima
- Semua menggunakan async queue agar checkout cepat

### 2. Onboarding Email Series:
- Welcome email saat registrasi (delay 3 detik)
- Getting Started email (delay 24 jam)
- Tips & Tricks email (delay 48 jam)
- Semua di-schedule dengan Bull delayed jobs

### 3. Newsletter Marketing:
- Kirim ke 50.000 subscriber
- Rate limiting: 10 email per detik
- Concurrency: 5 worker
- Retry jika gagal dengan exponential backoff
- Monitoring jumlah yang terkirim, gagal, dibaca

### 4. Security Notifications:
- Password change alert (high priority)
- Login from new device (high priority)
- 2FA enabled confirmation
- Semua dikirim segera dengan priority tinggi

### Benefits Email Queue Integration:
1. **User Experience**: User tidak menunggu email terkirim
2. **Reliability**: Auto-retry jika SMTP error
3. **Rate Limiting**: Hindari terblokir oleh ESP
4. **Monitoring**: Lacak semua email yang diproses
5. **Scalability**: Tambah worker sesuai kebutuhan
6. **Debugging**: Lihat failed jobs dan retry jika perlu
