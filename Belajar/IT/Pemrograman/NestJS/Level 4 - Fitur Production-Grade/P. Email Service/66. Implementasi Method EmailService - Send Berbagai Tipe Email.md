# 66. Implementasi Method EmailService — Send Berbagai Tipe Email

## Penjelasan

Setelah template Handlebars siap, langkah terakhir di EmailService adalah membuat method-method spesifik untuk setiap tipe email. Method-method ini akan: (1) menerima data yang diperlukan, (2) merender template dengan data tersebut menggunakan Handlebars, (3) memanggil `sendMail()` internal untuk mengirim. Pendekatan ini mengikuti **Single Responsibility Principle** — setiap method bertanggung jawab atas satu tipe email.

Method `renderTemplate()` adalah helper internal yang memuat file `.hbs`, mengkompilasinya dengan Handlebars, dan mengembalikan string HTML. File template di-cache setelah kompilasi pertama agar tidak perlu baca disk setiap kali. Method `sendLoanConfirmation()` misalnya, akan memanggil `renderTemplate('loan-confirmation', { userName, bookTitle, dueDate })` dan mengirim hasilnya.

## Fungsi

Method-method di EmailService berfungsi sebagai API publik untuk mengirim berbagai tipe email. Module-module lain (LoansModule, AuthModule, ScheduleModule) cukup memanggil `emailService.sendLoanConfirmation(data)` tanpa perlu tahu detail template, rendering, atau transport SMTP.

## Cara Implementasi / Code

### 1. EmailService Lengkap

```typescript
// src/email/services/email.service.ts
import { Injectable, Logger, OnModuleInit } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import * as nodemailer from 'nodemailer';
import * as fs from 'fs';
import * as path from 'path';
import * as Handlebars from 'handlebars';

@Injectable()
export class EmailService implements OnModuleInit {
  private readonly logger = new Logger(EmailService.name);
  private transporter: nodemailer.Transporter;
  private readonly from: string;
  private readonly fromName: string;
  private templateCache: Map<string, HandlebarsTemplateDelegate> = new Map();
  private readonly templateDir: string;

  constructor(private readonly configService: ConfigService) {
    this.from = this.configService.get<string>('email.from');
    this.fromName = this.configService.get<string>('email.fromName');
    this.templateDir = path.join(__dirname, '..', 'templates');
    this.initializeTransporter();
  }

  async onModuleInit() {
    await this.registerPartials();
    this.logger.log(`Template directory: ${this.templateDir}`);
  }

  private initializeTransporter() {
    const host = this.configService.get<string>('email.host');
    const port = this.configService.get<number>('email.port');
    const user = this.configService.get<string>('email.user');
    const pass = this.configService.get<string>('email.pass');

    this.transporter = nodemailer.createTransport({
      host,
      port,
      secure: this.configService.get<boolean>('email.secure'),
      ignoreTLS: this.configService.get<boolean>('email.ignoreTLS'),
      ...(user && pass ? { auth: { user, pass } } : {}),
    });
  }

  private async registerPartials() {
    const layoutsDir = path.join(this.templateDir, 'layouts');
    if (fs.existsSync(layoutsDir)) {
      const files = fs.readdirSync(layoutsDir);
      for (const file of files) {
        if (file.endsWith('.hbs')) {
          const name = path.parse(file).name;
          const content = fs.readFileSync(path.join(layoutsDir, file), 'utf-8');
          Handlebars.registerPartial(name, content);
          this.logger.log(`Registered partial: ${name}`);
        }
      }
    }
  }

  private async renderTemplate(
    templateName: string,
    context: Record<string, any>,
  ): Promise<string> {
    // Cek cache
    if (!this.templateCache.has(templateName)) {
      const templatePath = path.join(this.templateDir, `${templateName}.hbs`);

      if (!fs.existsSync(templatePath)) {
        throw new Error(`Template ${templateName}.hbs tidak ditemukan`);
      }

      const content = fs.readFileSync(templatePath, 'utf-8');
      const compiled = Handlebars.compile(content);
      this.templateCache.set(templateName, compiled);
    }

    const template = this.templateCache.get(templateName);
    return template!(context);
  }

  async sendMail(options: {
    to: string;
    subject: string;
    html: string;
    text?: string;
  }): Promise<void> {
    try {
      await this.transporter.sendMail({
        from: `"${this.fromName}" <${this.from}>`,
        to: options.to,
        subject: options.subject,
        html: options.html,
        text: options.text || options.html.replace(/<[^>]*>/g, ''),
      });
      this.logger.log(`Email sent to ${options.to}: ${options.subject}`);
    } catch (error) {
      this.logger.error(`Failed to send email: ${error.message}`);
      throw error;
    }
  }

  // ========== PUBLIC METHODS ==========

  async sendLoanConfirmation(data: {
    to: string;
    userName: string;
    bookTitle: string;
    borrowedAt?: string;
    dueDate: string;
  }): Promise<void> {
    const html = await this.renderTemplate('loan-confirmation', {
      userName: data.userName,
      bookTitle: data.bookTitle,
      borrowedAt: data.borrowedAt || new Date().toLocaleDateString('id-ID'),
      dueDate: data.dueDate,
    });

    await this.sendMail({
      to: data.to,
      subject: 'Konfirmasi Peminjaman Buku',
      html,
    });
  }

  async sendWelcomeEmail(data: {
    to: string;
    userName: string;
    dashboardUrl?: string;
  }): Promise<void> {
    const html = await this.renderTemplate('welcome', {
      userName: data.userName,
      dashboardUrl: data.dashboardUrl || 'http://localhost:3000/dashboard',
    });

    await this.sendMail({
      to: data.to,
      subject: 'Selamat Datang di Perpustakaan Digital',
      html,
    });
  }

  async sendReturnReminder(data: {
    to: string;
    userName: string;
    bookTitle: string;
    dueDate: string;
    extendUrl?: string;
  }): Promise<void> {
    const html = await this.renderTemplate('return-reminder', {
      userName: data.userName,
      bookTitle: data.bookTitle,
      dueDate: data.dueDate,
      extendUrl: data.extendUrl || '#',
    });

    await this.sendMail({
      to: data.to,
      subject: 'Pengingat Pengembalian Buku',
      html,
    });
  }

  async sendOverdueNotice(data: {
    to: string;
    userName: string;
    bookTitle: string;
    daysOverdue: number;
  }): Promise<void> {
    const html = await this.renderTemplate('overdue-notice', {
      userName: data.userName,
      bookTitle: data.bookTitle,
      daysOverdue: data.daysOverdue,
    });

    await this.sendMail({
      to: data.to,
      subject: `Peringatan Keterlambatan — ${data.bookTitle}`,
      html,
    });
  }

  async sendDailyReport(data: {
    to: string;
    reportDate: string;
    borrowed: number;
    returned: number;
    overdue: number;
  }): Promise<void> {
    const html = await this.renderTemplate('daily-report', {
      reportDate: data.reportDate,
      borrowed: data.borrowed,
      returned: data.returned,
      overdue: data.overdue,
    });

    await this.sendMail({
      to: data.to,
      subject: `Laporan Harian — ${data.reportDate}`,
      html,
    });
  }
}
```

## Analogi

Petugas perpustakaan memiliki **5 stempel berbeda** di mejanya: stempel "Konfirmasi Pinjam", "Selamat Datang", "Pengingat Kembali", "Peringatan Terlambat", dan "Laporan Harian". Setiap stempel memiliki tinta warna berbeda dan format tulisan yang berbeda. Ketika butuh mengirim surat tertentu, petugas tinggal mengambil stempel yang tepat, menekannya ke surat (render template), dan memasukkannya ke amplop. Method-method di EmailService adalah stempel-stempel ini — masing-masing untuk satu tujuan spesifik.

## Penggunaan

Method-method ini dipanggil dari berbagai tempat:
- **LoansService**: setelah pinjam → `sendLoanConfirmation()`
- **AuthService**: setelah registrasi → `sendWelcomeEmail()`
- **CronJob**: H-1 due date → `sendReturnReminder()`
- **CronJob**: setiap hari → `sendOverdueNotice()` + `sendDailyReport()`

## Kesalahan Umum yang Sering Terjadi

1. **Template tidak ditemukan di production** — path file berubah setelah build. Pastikan `templateDir` mengarah ke direktori yang benar di `dist/`. Gunakan `path.join(__dirname, '..', 'templates')`.
2. **Data undefined di template** — jika `data.bookTitle` undefined, template akan menampilkan string kosong. Tidak error, tapi email terlihat rusak. Validasi data sebelum render.
3. **Cache template tidak di-reset** — di development, perubahan template tidak terlihat sampai restart. Matikan cache di development: `this.templateCache = new Map()`.
4. **Email masuk spam** — HTML email tanpa `List-Unsubscribe` header, terlalu banyak gambar, atau markup mencurigakan. Ikuti best practice email deliverability.
5. **Async error tidak di-catch** — jika renderTemplate gagal (file tidak ada), error akan propagate ke caller. Pastikan ada try-catch di processor.

## Soal Latihan

**Soal:**
Buat method `sendBulkOverdueNotices()` yang menerima array data overdue dan mengirim email satu per satu menggunakan `Promise.allSettled`. Method ini harus tetap melanjutkan pengiriman meskipun salah satu gagal, dan mengembalikan ringkasan (berapa sukses, berapa gagal).

**Jawaban:**

```typescript
async sendBulkOverdueNotices(
  notices: Array<{
    to: string;
    userName: string;
    bookTitle: string;
    daysOverdue: number;
  }>,
): Promise<{ success: number; failed: number; errors: string[] }> {
  const results = await Promise.allSettled(
    notices.map((notice) => this.sendOverdueNotice(notice)),
  );

  const summary = { success: 0, failed: 0, errors: [] as string[] };

  for (const result of results) {
    if (result.status === 'fulfilled') {
      summary.success++;
    } else {
      summary.failed++;
      summary.errors.push(result.reason.message);
    }
  }

  this.logger.log(
    `Bulk overdue notices: ${summary.success} sent, ${summary.failed} failed`,
  );

  return summary;
}
```
