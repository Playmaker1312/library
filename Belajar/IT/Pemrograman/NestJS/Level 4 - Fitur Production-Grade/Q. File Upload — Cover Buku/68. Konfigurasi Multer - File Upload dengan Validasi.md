# 68. Konfigurasi Multer — File Upload dengan Validasi

## Penjelasan

**Multer** adalah middleware Node.js untuk menangani `multipart/form-data` — format yang digunakan untuk upload file. NestJS membungkus Multer dalam decorator `@UseInterceptors(FileInterceptor)` dan menyediakan tipe `Express.Multer.File`. Untuk aplikasi production, kita perlu mengkonfigurasi Multer dengan aturan yang ketat: batas ukuran file, tipe MIME yang diizinkan, dan filter file.

Konfigurasi Multer yang baik mencegah berbagai masalah keamanan dan teknis: upload file terlalu besar yang membebani server, upload file berbahaya (exe, script), dan file dengan tipe tidak sesuai (PDF diupload sebagai cover buku). Kita akan membuat `multer.config.ts` yang berisi `fileFilter` dan `limits`, lalu menggunakannya di controller upload.

## Fungsi

Konfigurasi Multer berfungsi sebagai gerbang keamanan untuk upload file. Ia memvalidasi bahwa hanya file gambar (JPEG, PNG, WebP) dengan ukuran maksimal 2MB yang bisa diupload sebagai cover buku. File yang tidak memenuhi kriteria akan ditolak dengan pesan error yang jelas.

## Cara Implementasi / Code

### 1. Buat Multer Config

```typescript
// src/common/config/multer.config.ts
import { BadRequestException } from '@nestjs/common';
import { diskStorage } from 'multer';
import { extname, join } from 'path';
import { existsSync, mkdirSync } from 'fs';

// Tipe MIME yang diizinkan
export const ALLOWED_MIME_TYPES = [
  'image/jpeg',
  'image/png',
  'image/webp',
  'image/avif',
];

export const MAX_FILE_SIZE = 2 * 1024 * 1024; // 2MB

// Filter file berdasarkan MIME type
export const imageFileFilter = (
  req: any,
  file: Express.Multer.File,
  callback: (error: Error | null, acceptFile: boolean) => void,
) => {
  if (!ALLOWED_MIME_TYPES.includes(file.mimetype)) {
    return callback(
      new BadRequestException(
        `Tipe file ${file.mimetype} tidak diizinkan. Gunakan: ${ALLOWED_MIME_TYPES.join(', ')}`,
      ),
      false,
    );
  }
  callback(null, true);
};

// Konfigurasi penyimpanan disk
export const storageConfig = diskStorage({
  destination: (req, file, callback) => {
    const uploadPath = join(process.cwd(), 'uploads', 'covers');

    // Buat folder jika belum ada
    if (!existsSync(uploadPath)) {
      mkdirSync(uploadPath, { recursive: true });
    }

    callback(null, uploadPath);
  },
  filename: (req, file, callback) => {
    // Generate nama file unik: timestamp-random.ext
    const uniqueSuffix = `${Date.now()}-${Math.round(Math.random() * 1e9)}`;
    const ext = extname(file.originalname).toLowerCase();
    callback(null, `cover-${uniqueSuffix}${ext}`);
  },
});
```

### 2. Gunakan di Controller

```typescript
// src/books/controllers/books.controller.ts
import {
  Post, UseInterceptors, UploadedFile,
  ParseFilePipeBuilder, HttpStatus, Param,
} from '@nestjs/common';
import { FileInterceptor } from '@nestjs/platform-express';

@Post(':id/cover')
@UseGuards(JwtAuthGuard, RolesGuard)
@Roles('ADMIN')
@UseInterceptors(
  FileInterceptor('file', {
    storage: storageConfig,
    fileFilter: imageFileFilter,
    limits: {
      fileSize: MAX_FILE_SIZE,
    },
  }),
)
async uploadCover(
  @Param('id') id: string,
  @UploadedFile(
    new ParseFilePipeBuilder()
      .addFileTypeValidator({
        fileType: /(jpg|jpeg|png|webp|avif)$/,
      })
      .addMaxSizeValidator({
        maxSize: MAX_FILE_SIZE,
      })
      .build({
        errorHttpStatusCode: HttpStatus.UNPROCESSABLE_ENTITY,
      }),
  )
  file: Express.Multer.File,
) {
  return this.booksService.updateCover(id, file);
}
```

### 3. Serve Static Files untuk Upload

```typescript
// src/main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { NestExpressApplication } from '@nestjs/platform-express';
import { join } from 'path';

async function bootstrap() {
  const app = await NestFactory.create<NestExpressApplication>(AppModule);

  // Serve file statis dari folder uploads
  app.useStaticAssets(join(process.cwd(), 'uploads'), {
    prefix: '/uploads/',
  });

  await app.listen(3000);
}
```

### 4. Error Handling untuk File Too Large

```typescript
// src/common/filters/file-exception.filter.ts
import {
  ExceptionFilter, Catch, ArgumentsHost, HttpStatus,
} from '@nestjs/common';
import { PayloadTooLargeException } from '@nestjs/common';

@Catch(PayloadTooLargeException)
export class FileSizeExceptionFilter implements ExceptionFilter {
  catch(exception: PayloadTooLargeException, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse();

    response.status(HttpStatus.PAYLOAD_TOO_LARGE).json({
      statusCode: HttpStatus.PAYLOAD_TOO_LARGE,
      message: 'Ukuran file terlalu besar. Maksimal 2MB.',
      error: 'Payload Too Large',
    });
  }
}
```

## Analogi

Di perpustakaan, ada **meja penerimaan** khusus untuk sampul buku baru. Meja ini memiliki aturan ketat: hanya menerima sampul berbahan kertas (bukan plastik atau logam — analogi MIME type filter), ukuran tidak boleh lebih besar dari A4 (maks 2MB), dan harus dalam kondisi baik. Jika ada yang mencoba menyerahkan sampul yang tidak sesuai, petugas akan menolak dengan sopan. Setelah lolos seleksi, sampul diberi label unik (nama file) dan disimpan di lemari arsip khusus (folder uploads). Meja penerimaan ini adalah **Multer configuration**.

## Penggunaan

Konfigurasi Multer yang sudah dibuat digunakan di:
- **Upload cover buku**: endpoint `POST /books/:id/cover`
- **Upload avatar user**: endpoint `POST /users/:id/avatar`
- **Upload lampiran laporan**: fitur admin
- **Upload bukti pembayaran denda**: fitur anggota

## Kesalahan Umum yang Sering Terjadi

1. **File size validator ganda** — Multer `limits.fileSize` dan `ParseFilePipe.maxSize` keduanya memvalidasi. Jika salah satu lupa dikonfigurasi, proteksi tidak berjalan optimal.
2. **Folder upload tidak ada** — Multer tidak membuat folder otomatis. Pastikan folder dibuat di `destination` callback atau saat aplikasi start.
3. **Nama file tidak unik** — tanpa timestamp/random, file bisa tertimpa jika nama sama. Selalu generate nama unik.
4. **Static assets tidak diserve** — setelah upload, file tidak bisa diakses via browser karena path `/uploads/` tidak terdaftar. Tambahkan `app.useStaticAssets()`.
5. **Tidak handle error Multer** — error seperti file terlalu besar menghasilkan `PayloadTooLargeException`. Tangkap dengan exception filter agar response JSON, bukan HTML error.

## Soal Latihan

**Soal:**
Buat konfigurasi Multer untuk upload multiple file (sampai 5 file) dengan nama `cover-images[]` (array). Setiap file maksimal 1MB, hanya PNG dan WebP. Simpan di folder `uploads/covers/multiple/`.

**Jawaban:**

```typescript
// Gunakan FilesInterceptor untuk multiple files
import { FilesInterceptor } from '@nestjs/platform-express';

@Post(':id/covers')
@UseGuards(JwtAuthGuard, RolesGuard)
@Roles('ADMIN')
@UseInterceptors(
  FilesInterceptor('cover-images[]', 5, {
    storage: diskStorage({
      destination: join(process.cwd(), 'uploads', 'covers', 'multiple'),
      filename: (req, file, cb) => {
        const name = `cover-${Date.now()}-${Math.round(Math.random() * 1e9)}${extname(file.originalname)}`;
        cb(null, name);
      },
    }),
    fileFilter: (req, file, cb) => {
      if (!['image/png', 'image/webp'].includes(file.mimetype)) {
        return cb(new BadRequestException('Hanya PNG dan WebP'), false);
      }
      cb(null, true);
    },
    limits: { fileSize: 1 * 1024 * 1024 },
  }),
)
async uploadMultipleCovers(
  @Param('id') id: string,
  @UploadedFiles() files: Array<Express.Multer.File>,
) {
  return this.booksService.updateMultipleCovers(id, files);
}
```
