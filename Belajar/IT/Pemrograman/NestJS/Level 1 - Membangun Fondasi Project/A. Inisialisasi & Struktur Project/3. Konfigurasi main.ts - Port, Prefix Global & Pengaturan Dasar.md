# Konfigurasi main.ts — Port, Prefix Global & Pengaturan Dasar

## Penjelasan

File `main.ts` adalah entry point aplikasi NestJS. Di sinilah kita melakukan berbagai konfigurasi global yang akan mempengaruhi seluruh aplikasi. NestJS menyediakan beberapa method penting pada instance aplikasi yang bisa digunakan di `main.ts`, seperti `setGlobalPrefix()`, `enableShutdownHooks()`, `useGlobalPipes()`, `enableCors()`, dan lain-lain. Konfigurasi di `main.ts` bersifat global karena diterapkan sebelum module dan controller diproses.

Salah satu konfigurasi yang paling sering digunakan adalah **global prefix**. Dengan `app.setGlobalPrefix('api/v1')`, semua route di aplikasi akan otomatis memiliki prefix `/api/v1`. Ini sangat berguna untuk versioning API dan memudahkan ketika ada perubahan versi di masa depan. Misalnya, jika nanti ingin merilis API versi 2, cukup buat aplikasi baru dengan prefix `/api/v2` tanpa mengganggu versi 1.

Selain itu, **shutdown hooks** (`app.enableShutdownHooks()`) memungkinkan aplikasi menjalankan kode tertentu saat menerima sinyal penghentian (seperti SIGTERM). Ini penting di production untuk membersihkan koneksi database, menyelesaikan request yang sedang berlangsung, atau menutup file descriptor. Sedangkan untuk **port**, sebaiknya menggunakan environment variable agar port bisa dikonfigurasi tanpa mengubah kode.

## Fungsi

Konfigurasi di `main.ts` berfungsi sebagai **lapisan pengaturan global** yang mempengaruhi seluruh aspek aplikasi. `setGlobalPrefix()` untuk versioning route, `enableCors()` untuk mengizinkan akses dari domain lain, `enableShutdownHooks()` untuk graceful shutdown, `useGlobalPipes()` untuk validasi global, dan `useLogger()` untuk mengganti logger default. Semua ini adalah pengaturan yang sebaiknya dilakukan sebelum aplikasi berjalan.

## Cara Implementasi / Code

Berikut adalah implementasi lengkap `main.ts` yang sudah dikonfigurasi:

```typescript
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { Logger } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // 1. Global Prefix — semua route akan diawali /api/v1
  app.setGlobalPrefix('api/v1', {
    exclude: ['/health', '/'], // Route yang tidak perlu prefix
  });

  // 2. CORS — mengizinkan akses dari frontend
  app.enableCors({
    origin: ['http://localhost:3001', 'https://frontend-app.com'],
    methods: 'GET,HEAD,PUT,PATCH,POST,DELETE',
    credentials: true,
  });

  // 3. Shutdown Hooks — bersih-bersih sebelum aplikasi mati
  app.enableShutdownHooks();

  // 4. Konfigurasi port dari environment variable
  const port = process.env.PORT || 3000;

  await app.listen(port);

  // 5. Logger untuk memberi tahu developer
  Logger.log(
    `Aplikasi berjalan di http://localhost:${port}`,
    'Bootstrap',
  );
  Logger.log(
    `API dokumentasi: http://localhost:${port}/api/v1`,
    'Bootstrap',
  );
}
bootstrap();
```

### Penjelasan Detail Konfigurasi:

**Global Prefix dengan Pengecualian:**
```typescript
app.setGlobalPrefix('api/v1', {
  exclude: ['/health', '/'],
});
```
Dengan kode di atas, semua route akan memiliki prefix `/api/v1`, kecuali route `/health` dan `/` (root). Ini berguna jika ada endpoint yang memang harus diakses tanpa prefix, seperti health check endpoint.

**CORS Configuration:**
```typescript
app.enableCors({
  origin: ['http://localhost:3001'],
  methods: 'GET,HEAD,PUT,PATCH,POST,DELETE',
  credentials: true,
});
```
CORS (Cross-Origin Resource Sharing) diperlukan jika frontend dan backend berjalan di domain/port yang berbeda. `credentials: true` mengizinkan pengiriman cookie atau header otentikasi.

**Environment Variable untuk Port:**
```typescript
const port = process.env.PORT || 3000;
```
Gunakan environment variable agar port bisa diubah tanpa mengedit kode. Untuk mengatur environment variable di Windows PowerShell:
```powershell
$env:PORT = 4000
pnpm run start:dev
```
Atau buat file `.env` (akan dibahas di materi terpisah).

### Cara menjalankan dengan port berbeda:

```bash
# Windows PowerShell
$env:PORT=4000; pnpm run start:dev

# Atau simpan di file .env (perlu package dotenv/nestjs/config)
# PORT=4000
```

## Analogi

Bayangkan Anda adalah **kepala perpustakaan** yang sedang mengatur **pintu masuk utama** perpustakaan. Beberapa keputusan perlu dibuat:

- **Global Prefix (`api/v1`)** seperti **papan nama besar** di depan perpustakaan yang bertuliskan "Perpustakaan Kota — Lantai 1". Semua pengunjung harus melewati papan ini sebelum menuju rak buku tertentu. Jika nanti ada perluasan ke lantai 2, cukup ganti papan menjadi "Lantai 2" tanpa mengubah papan petunjuk di dalam gedung.

- **CORS** seperti **aturan pengunjung dari luar kota** — apakah Anda mengizinkan orang dari luar daerah (domain berbeda) masuk ke perpustakaan? Boleh, asalkan mereka mengikuti aturan yang sudah ditetapkan.

- **Shutdown Hooks** seperti **prosedur tutup perpustakaan** — sebelum semua lampu dimatikan, petugas harus memastikan tidak ada pengunjung yang masih di dalam, semua pintu terkunci, dan sistem alarm aktif.

- **Environment Variable untuk Port** seperti memiliki **pintu masuk cadangan** — jika pintu utama (port 3000) sedang diperbaiki, cukup ganti petunjuk ke pintu samping (port 4000) tanpa perlu membongkar bangunan.

## Penggunaan

Konfigurasi `main.ts` dipakai di **setiap project NestJS**. Global prefix wajib digunakan jika API akan diakses oleh banyak versi klien (mobile app versi lama vs baru). CORS wajib dikonfigurasi jika frontend terpisah dari backend. Shutdown hooks penting untuk production deployment di Docker atau Kubernetes. Port dari environment variable adalah standar industri agar aplikasi bisa di-deploy di berbagai lingkungan tanpa perubahan kode.

## Kesalahan Umum yang Sering Terjadi

1. **Meletakkan konfigurasi setelah `await app.listen()`** — Baris kode setelah `app.listen()` tidak akan pernah dieksekusi karena `listen()` adalah asynchronous dan aplikasi sudah berjalan. Semua konfigurasi harus dilakukan **sebelum** `app.listen()`.

2. **Menggunakan `setGlobalPrefix` tanpa pengecualian** — Kadang ada endpoint seperti health check yang tidak perlu prefix. Jika lupa mengecualikannya, endpoint health check harus diakses di `/api/v1/health` yang mungkin tidak sesuai dengan harapan load balancer.

3. **Lupa mengaktifkan CORS** — Saat frontend mencoba mengakses API, browser akan memblokir request dengan error CORS jika CORS tidak dikonfigurasi. Ini adalah kesalahan yang sangat umum terjadi.

4. **Hardcode port** — Menulis `3000` langsung di `app.listen()` tanpa environment variable menyulitkan deployment. Tim DevOps tidak bisa mengubah port tanpa mengedit kode sumber.

5. **Tidak mengaktifkan shutdown hooks** — Di environment container seperti Docker, aplikasi yang tidak memiliki shutdown hooks akan langsung dimatikan paksa, berpotensi merusak data yang sedang diproses.

## Hubungan dengan Materi Sebelumnya

Di materi ke-1 kita membuat project dengan `nest new`, di materi ke-2 kita memahami setiap file yang dihasilkan termasuk `main.ts`. Sekarang kita memodifikasi `main.ts` dengan konfigurasi yang lebih matang. Konfigurasi ini akan digunakan terus sepanjang pengembangan project. Materi ini juga menjadi dasar untuk materi-materi selanjutnya seperti global exception filter (materi 14) dan validation pipe (materi 16) yang juga akan didaftarkan di `main.ts`.

## Soal Latihan

**Soal:** Modifikasi file `main.ts` pada project `perpustakaan-api` sehingga:
1. Semua route diawali prefix `/library/api/v1`
2. Route `/ping` dan `/status` dikecualikan dari prefix
3. CORS diaktifkan untuk origin `http://localhost:5173` (Vite default port)
4. Port diambil dari environment variable dengan fallback ke 4000
5. Menampilkan log dengan format: "Server siap melayani di port {port}"

**Jawaban:**

```typescript
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { Logger } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // 1 & 2: Global prefix dengan pengecualian
  app.setGlobalPrefix('library/api/v1', {
    exclude: ['/ping', '/status'],
  });

  // 3: CORS untuk Vite default port
  app.enableCors({
    origin: ['http://localhost:5173'],
    methods: 'GET,HEAD,PUT,PATCH,POST,DELETE',
    credentials: true,
  });

  // 4: Shutdown hooks untuk graceful shutdown
  app.enableShutdownHooks();

  // 5: Port dari environment variable dengan fallback 4000
  const port = process.env.PORT || 4000;
  await app.listen(port);

  // 6: Log server siap
  Logger.log(`Server siap melayani di port ${port}`, 'Bootstrap');
}
bootstrap();
```

**Verifikasi:**
- Akses `http://localhost:4000/library/api/v1` — harusnya response Hello World!
- Akses `http://localhost:4000/ping` — harusnya response tanpa prefix
- Akses `http://localhost:4000/status` — harusnya response tanpa prefix
