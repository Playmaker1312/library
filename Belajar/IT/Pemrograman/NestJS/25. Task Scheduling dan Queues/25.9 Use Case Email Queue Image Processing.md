# 25. Task Scheduling dan Queues

## 25.9. Use Case: Email Queue, Image Processing

**Definisi Singkat:**
Contoh implementasi nyata menggunakan Bull Queue untuk dua use case umum: **Email Queue** (mengirim email secara async dengan retry) dan **Image Processing** (resize, compress, watermark gambar secara parallel).

**Analogi:**
- **Email Queue**: Seperti kantor pos - surat (email) dikumpulkan di kantor pos (queue), lalu kurir (worker) mengantarkan satu per satu. Jika alamat salah, dicoba lagi beberapa kali.
- **Image Processing**: Seperti bengkel modifikasi mobil - mobil (gambar) masuk ke antrean, montir (worker) memodifikasi (resize, watermark), beberapa montir bisa bekerja secara parallel.

**Poin-Poin Penting:**
- Email Queue: Non-blocking, retry logic, template support, rate limiting
- Image Processing: CPU intensive, concurrency control, progress tracking, multiple variants
- Keduanya menggunakan Bull + Redis
- Cocok untuk operasi yang lambat dan bisa di-background

// email-queue.service.ts (Producer)
import { Injectable } from '@nestjs/common';
import { InjectQueue } from '@nestjs/bull';
import { Queue } from 'bull';

@Injectable()
export class EmailQueueService {
  constructor(
    @InjectQueue('email') private readonly emailQueue: Queue,
  ) {}

  // Send welcome email after registration
  async sendWelcomeEmail(user: { email: string; name: string }) {
    const job = await this.emailQueue.add(
      'send-welcome',
      {
        email: user.email,
        name: user.name,
      },
      {
        priority: 2, // High priority
        delay: 5000, // Send after 5 seconds
      },
    );

    return { jobId: job.id };
  }

  // Send password reset email
  async sendResetPasswordEmail(
    email: string,
    resetToken: string,
    userName: string,
  ) {
    const job = await this.emailQueue.add(
      'send-reset-password',
      {
        email,
        name: userName,
        resetToken,
        resetUrl: `${process.env.APP_URL}/reset-password?token=${resetToken}`,
      },
      {
        priority: 1, // Highest priority - user is waiting
        attempts: 3,
      },
    );

    return { jobId: job.id };
  }

  // Send order confirmation
  async sendOrderConfirmation(
    email: string,
    order: { id: string; items: any[]; total: number },
  ) {
    const job = await this.emailQueue.add(
      'send-order-confirmation',
      {
        email,
        orderId: order.id,
        items: order.items,
        total: order.total,
      },
      {
        priority: 2,
      },
    );

    return { jobId: job.id };
  }

  // Send newsletter to multiple recipients
  async sendNewsletter(
    recipients: { email: string; name: string }[],
    newsletter: { subject: string; content: string },
  ) {
    const jobs = [];
    
    for (const recipient of recipients) {
      const job = await this.emailQueue.add(
        'send-newsletter',
        {
          email: recipient.email,
          name: recipient.name,
          subject: newsletter.subject,
          content: newsletter.content,
        },
        {
          priority: 10, // Low priority
          attempts: 2,
        },
      );
      jobs.push(job.id);
    }

    return { scheduled: jobs.length, jobIds: jobs };
  }
}

// email.processor.ts (Consumer)
import { Processor, Process } from '@nestjs/bull';
import { Job } from 'bull';
import { Injectable, Logger } from '@nestjs/common';
import { MailerService } from '@nestjs-modules/mailer';

@Injectable()
@Processor({
  name: 'email',
  concurrency: 5, // Process 5 emails concurrently
})
export class EmailProcessor {
  private readonly logger = new Logger(EmailProcessor.name);

  constructor(private readonly mailerService: MailerService) {}

  @Process('send-welcome')
  async sendWelcome(job: Job) {
    const { email, name } = job.data;
    
    this.logger.log(`Sending welcome email to ${email} (attempt ${job.attemptsMade + 1})`);

    try {
      await this.mailerService.sendMail({
        to: email,
        subject: 'Welcome to My App! 🎉',
        template: './welcome',
        context: {
          name,
          email,
          loginUrl: process.env.APP_URL + '/login',
        },
      });

      this.logger.log(`Welcome email sent to ${email}`);
      
      await job.progress(100);
      return { success: true, email };
    } catch (error) {
      this.logger.error(`Failed to send welcome email to ${email}: ${error.message}`);
      throw error; // Trigger retry
    }
  }

  @Process('send-reset-password')
  async sendResetPassword(job: Job) {
    const { email, name, resetUrl } = job.data;
    
    this.logger.log(`Sending reset password email to ${email}`);

    await this.mailerService.sendMail({
      to: email,
      subject: 'Reset Your Password',
      template: './reset-password',
      context: {
        name,
        resetUrl,
        expiryHours: 24,
      },
    });

    return { success: true };
  }

  @Process('send-order-confirmation')
  async sendOrderConfirmation(job: Job) {
    const { email, orderId, items, total } = job.data;
    
    await this.mailerService.sendMail({
      to: email,
      subject: `Order Confirmation #${orderId}`,
      template: './order-confirmation',
      context: {
        orderId,
        items,
        total,
        orderDate: new Date().toLocaleDateString('id-ID'),
      },
    });

    return { success: true };
  }

  @Process('send-newsletter')
  async sendNewsletter(job: Job) {
    const { email, name, subject, content } = job.data;
    
    // Rate limiting: add small delay to avoid spam filter
    await new Promise(resolve => setTimeout(resolve, 100));
    
    await this.mailerService.sendMail({
      to: email,
      subject,
      template: './newsletter',
      context: {
        name,
        content,
        unsubscribeUrl: process.env.APP_URL + '/unsubscribe',
      },
    });

    return { success: true };
  }
}

// image-queue.service.ts (Producer)
import { Injectable } from '@nestjs/common';
import { InjectQueue } from '@nestjs/bull';
import { Queue } from 'bull';

@Injectable()
export class ImageQueueService {
  constructor(
    @InjectQueue('image-processing') private readonly imageQueue: Queue,
  ) {}

  // Process uploaded image: create multiple sizes + watermark
  async processProductImage(
    imageId: string,
    originalUrl: string,
    options: {
      withWatermark?: boolean;
      sizes?: ('thumbnail' | 'small' | 'medium' | 'large')[];
    } = {},
  ) {
    const defaultSizes = ['thumbnail', 'small', 'medium', 'large'];
    
    const job = await this.imageQueue.add(
      'process-product-image',
      {
        imageId,
        originalUrl,
        sizes: options.sizes || defaultSizes,
        withWatermark: options.withWatermark ?? true,
      },
      {
        priority: 5,
      },
    );

    return { jobId: job.id, imageId };
  }

  // Bulk process images (e.g., import products)
  async bulkProcessImages(images: { imageId: string; url: string }[]) {
    const jobs = [];
    
    for (const image of images) {
      const job = await this.imageQueue.add(
        'process-product-image',
        {
          imageId: image.imageId,
          originalUrl: image.url,
          sizes: ['thumbnail', 'medium'],
          withWatermark: true,
        },
        {
          priority: 10, // Lower priority for bulk
        },
      );
      jobs.push(job.id);
    }

    return { total: jobs.length, jobIds: jobs };
  }

  // Generate thumbnail for user avatar
  async processAvatar(userId: string, originalUrl: string) {
    const job = await this.imageQueue.add(
      'process-avatar',
      {
        userId,
        originalUrl,
      },
      {
        priority: 2, // Higher priority for user avatars
      },
    );

    return { jobId: job.id };
  }
}

// image.processor.ts (Consumer)
import { Processor, Process } from '@nestjs/bull';
import { Job } from 'bull';
import { Injectable, Logger } from '@nestjs/common';
import * as sharp from 'sharp';
import { S3Service } from './s3.service';

@Injectable()
@Processor({
  name: 'image-processing',
  concurrency: 3, // Limit concurrency to avoid CPU overload
})
export class ImageProcessor {
  private readonly logger = new Logger(ImageProcessor.name);

  constructor(private readonly s3Service: S3Service) {}

  private readonly SIZE_CONFIGS = {
    thumbnail: { width: 150, height: 150, fit: 'cover' as const },
    small: { width: 400, height: null, fit: 'inside' as const },
    medium: { width: 800, height: null, fit: 'inside' as const },
    large: { width: 1200, height: null, fit: 'inside' as const },
  };

  @Process('process-product-image')
  async processProductImage(job: Job) {
    const { imageId, originalUrl, sizes, withWatermark } = job.data;
    
    this.logger.log(`Processing image ${imageId} (attempt ${job.attemptsMade + 1})`);

    try {
      // 1. Download original image
      await job.progress(10);
      const originalBuffer = await this.s3Service.download(originalUrl);
      
      await job.progress(20);

      // 2. Process each size
      const results = [];
      const totalSizes = sizes.length;
      
      for (let i = 0; i < sizes.length; i++) {
        const sizeName = sizes[i];
        const config = this.SIZE_CONFIGS[sizeName];
        
        this.logger.log(`Resizing ${imageId} to ${sizeName}`);
        
        let image = sharp(originalBuffer)
          .resize(config.width, config.height, {
            fit: config.fit,
            withoutEnlargement: true,
          })
          .jpeg({ quality: 85 });

        // Add watermark if needed
        if (withWatermark && sizeName !== 'thumbnail') {
          image = await this.addWatermark(image);
        }

        const resizedBuffer = await image.toBuffer();
        
        await job.progress(20 + ((i + 1) / totalSizes) * 60);

        // Upload to S3
        const s3Key = `products/${imageId}/${sizeName}.jpg`;
        const url = await this.s3Service.upload(s3Key, resizedBuffer, 'image/jpeg');
        
        results.push({
          size: sizeName,
          url,
          width: config.width,
        });
      }

      await job.progress(85);

      // 3. Update database with image URLs
      await this.updateProductImageUrls(imageId, results);
      
      await job.progress(100);

      this.logger.log(`Image ${imageId} processing completed`);

      return {
        success: true,
        imageId,
        variants: results,
      };
    } catch (error) {
      this.logger.error(`Failed to process image ${imageId}: ${error.message}`);
      throw error;
    }
  }

  @Process('process-avatar')
  async processAvatar(job: Job) {
    const { userId, originalUrl } = job.data;
    
    this.logger.log(`Processing avatar for user ${userId}`);

    const originalBuffer = await this.s3Service.download(originalUrl);
    
    // Resize to square avatar
    const avatarBuffer = await sharp(originalBuffer)
      .resize(200, 200, { fit: 'cover', position: 'center' })
      .jpeg({ quality: 80 })
      .toBuffer();

    const s3Key = `users/${userId}/avatar.jpg`;
    const url = await this.s3Service.upload(s3Key, avatarBuffer, 'image/jpeg');

    // Update user avatar in DB
    await this.updateUserAvatar(userId, url);

    return { success: true, userId, avatarUrl: url };
  }

  private async addWatermark(image: sharp.Sharp): Promise<sharp.Sharp> {
    // Load watermark image
    const watermarkBuffer = await this.s3Service.download('assets/watermark.png');
    
    const metadata = await image.metadata();
    const watermarkWidth = Math.floor(metadata.width * 0.3); // 30% of image width
    
    const resizedWatermark = await sharp(watermarkBuffer)
      .resize(watermarkWidth, null, { fit: 'inside' })
      .png()
      .toBuffer();

    return image.composite([
      {
        input: resizedWatermark,
        gravity: 'southeast',
        opacity: 0.3,
      },
    ]);
  }

  private async updateProductImageUrls(imageId: string, urls: any[]) {
    // Update database
    this.logger.log(`Updated DB for image ${imageId}`);
  }

  private async updateUserAvatar(userId: string, url: string) {
    // Update database
    this.logger.log(`Updated avatar for user ${userId}`);
  }
}

// s3.service.ts
import { Injectable } from '@nestjs/common';
import { S3Client, PutObjectCommand, GetObjectCommand } from '@aws-sdk/client-s3';
import { getSignedUrl } from '@aws-sdk/s3-request-presigner';

@Injectable()
export class S3Service {
  private s3Client: S3Client;

  constructor() {
    this.s3Client = new S3Client({
      region: process.env.AWS_REGION,
      credentials: {
        accessKeyId: process.env.AWS_ACCESS_KEY_ID,
        secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY,
      },
    });
  }

  async upload(key: string, buffer: Buffer, contentType: string): Promise<string> {
    const command = new PutObjectCommand({
      Bucket: process.env.S3_BUCKET,
      Key: key,
      Body: buffer,
      ContentType: contentType,
      ACL: 'public-read',
    });

    await this.s3Client.send(command);

    // Return public URL
    return `https://${process.env.S3_BUCKET}.s3.${process.env.AWS_REGION}.amazonaws.com/${key}`;
  }

  async download(url: string): Promise<Buffer> {
    // Simplified - in real app, parse URL and use GetObjectCommand
    const response = await fetch(url);
    const arrayBuffer = await response.arrayBuffer();
    return Buffer.from(arrayBuffer);
  }
}

// ========== CONTOH PENGGUNAAN DI CONTROLLER ==========

import { Controller, Post, UploadedFile, UseInterceptors, Body } from '@nestjs/common';
import { FileInterceptor } from '@nestjs/platform-express';
import { EmailQueueService } from './email-queue.service';
import { ImageQueueService } from './image-queue.service';
import { S3Service } from './s3.service';

@Controller('api')
export class AppController {
  constructor(
    private readonly emailQueue: EmailQueueService,
    private readonly imageQueue: ImageQueueService,
    private readonly s3Service: S3Service,
  ) {}

  @Post('register')
  async register(@Body() body: { email: string; name: string }) {
    // 1. Save user to database
    // 2. Queue welcome email (async, non-blocking)
    await this.emailQueue.sendWelcomeEmail({
      email: body.email,
      name: body.name,
    });

    return {
      success: true,
      message: 'Registration successful. Welcome email will be sent shortly.',
    };
  }

  @Post('forgot-password')
  async forgotPassword(@Body() body: { email: string }) {
    // 1. Generate reset token
    const resetToken = 'generated-token';
    // 2. Queue reset password email
    await this.emailQueue.sendResetPasswordEmail(
      body.email,
      resetToken,
      'User Name',
    );

    return {
      success: true,
      message: 'Reset password link sent to your email.',
    };
  }

  @Post('upload-product-image')
  @UseInterceptors(FileInterceptor('image'))
  async uploadProductImage(
    @UploadedFile() file: Express.Multer.File,
    @Body('productId') productId: string,
  ) {
    // 1. Upload original to S3
    const imageId = `prod-${productId}-${Date.now()}`;
    const s3Key = `products/original/${imageId}.jpg`;
    const originalUrl = await this.s3Service.upload(s3Key, file.buffer, file.mimetype);

    // 2. Queue image processing (async)
    await this.imageQueue.processProductImage(
      imageId,
      originalUrl,
      {
        sizes: ['thumbnail', 'small', 'medium', 'large'],
        withWatermark: true,
      },
    );

    return {
      success: true,
      message: 'Image uploaded and processing in background',
      imageId,
    };
  }
}

**Kasus Penggunaan Nyata:**

### Email Queue:
1. **User Registration**: Setelah user daftar, kirim welcome email secara async - user tidak menunggu 2-3 detik untuk email terkirim
2. **Password Reset**: User meminta reset password, token dibuat dan email di-queue dengan priority tinggi
3. **Order Confirmation**: Setelah pembayaran sukses, kirim email konfirmasi dengan detail order
4. **Newsletter**: Kirim 10.000 email newsletter secara bertahap dengan concurrency limit dan rate limiting agar tidak terkena spam filter
5. **Notification System**: Berbagai notifikasi (order status, promo, reminder) yang tidak real-time critical

### Image Processing:
1. **E-commerce Product Images**: Setelah upload gambar produk, otomatis buat berbagai ukuran (thumbnail, small, medium, large) dengan watermark
2. **User Avatars**: Upload foto profil, buat ukuran square 200x200 untuk konsistensi
3. **Content Management System**: Editor upload gambar artikel, otomatis compress dan buat multiple resolutions untuk responsive design
4. **Social Media App**: User upload foto, buat thumbnail untuk feed dan full size untuk detail view, tambahkan watermark logo app
5. **Real Estate App**: Upload 20 gambar properti sekaligus, proses semua secara parallel dengan concurrency control agar tidak membebani CPU
