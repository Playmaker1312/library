# 25. Task Scheduling dan Queues

## 25.8. Queue Dashboard: Bull Board

**Definisi Singkat:**
Bull Board adalah dashboard UI untuk memantau dan mengelola Bull queues, memungkinkan melihat job status, retry failed jobs, pause/resume queue, dan melihat statistik secara visual melalui browser.

**Analogi:**
Seperti panel kontrol di pusat operasi - kamu bisa melihat semua antrean, status setiap tugas, mengatur ulang yang gagal, dan memantau kesehatan sistem secara real-time.

**Poin-Poin Penting:**
- Package: `@bull-board/api` + `@bull-board/express` atau `@bull-board/fastify`
- Mendukung Bull dan BullMQ
- Fitur: Lihat job, retry, pause queue, hapus job, statistik
- Dapat di-protect dengan auth (Basic Auth, JWT, dll)
- Dapat di-embed ke NestJS app sebagai route
- Support multiple queues

// bull-board.setup.ts
import { INestApplication } from '@nestjs/common';
import { Queue } from 'bull';
import { createBullBoard } from '@bull-board/api';
import { BullAdapter } from '@bull-board/api/bullAdapter';
import { ExpressAdapter } from '@bull-board/express';

export function setupBullBoard(
  app: INestApplication,
  queues: Queue[],
) {
  // Buat adapters untuk setiap queue
  const queueAdapters = queues.map(queue => new BullAdapter(queue));

  // Buat server adapter
  const serverAdapter = new ExpressAdapter();
  serverAdapter.setBasePath('/admin/queues');

  // Setup Bull Board
  createBullBoard({
    queues: queueAdapters,
    serverAdapter,
  });

  // Mount ke Express app
  const expressApp = app.getHttpAdapter().getInstance();
  expressApp.use('/admin/queues', serverAdapter.getRouter());

  console.log('Bull Board available at: http://localhost:3000/admin/queues');
}

// jwt-auth.guard.ts
import { CanActivate, ExecutionContext, Injectable } from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';

@Injectable()
export class JwtAuthGuard implements CanActivate {
  constructor(private jwtService: JwtService) {}

  canActivate(context: ExecutionContext): boolean {
    const request = context.switchToHttp().getRequest();
    const authHeader = request.headers.authorization;

    if (!authHeader) {
      return false;
    }

    const [, token] = authHeader.split(' ');
    
    try {
      const payload = this.jwtService.verify(token);
      return payload.role === 'admin'; // Hanya admin
    } catch {
      return false;
    }
  }
}

@Injectable()
export class QueueTestService {
  constructor(
    @InjectQueue('email') private readonly emailQueue: Queue,
    @InjectQueue('payments') private readonly paymentQueue: Queue,
  ) {}

  // Tambahkan job untuk testing dashboard
  async createTestJobs() {
    // Job sukses
    await this.emailQueue.add(
      'send-welcome',
      { email: 'success@example.com', shouldFail: false },
      { attempts: 3 },
    );

    // Job yang akan gagal
    await this.emailQueue.add(
      'send-welcome',
      { email: 'fail@example.com', shouldFail: true },
      { attempts: 2 },
    );

    // Job dengan delay
    await this.emailQueue.add(
      'send-scheduled',
      { email: 'delayed@example.com' },
      { delay: 5 * 60 * 1000 }, // 5 menit
    );

    // Job dengan priority berbeda
    await this.paymentQueue.add(
      'process',
      { amount: 1000000, priority: 'high' },
      { priority: 1 },
    );
    await this.paymentQueue.add(
      'process',
      { amount: 10000, priority: 'low' },
      { priority: 10 },
    );

    return { message: 'Test jobs created - check Bull Board!' };
  }

  // Cleanup semua job untuk testing
  async cleanupAllJobs() {
    await Promise.all([
      this.emailQueue.empty(),
      this.paymentQueue.empty(),
    ]);
    return { message: 'All queues emptied' };
  }
}

// ========== FALLBACK: MONITORING VIA API ==========

@Controller('api/queues')
export class QueueApiController {
  constructor(
    @InjectQueue('email') private readonly emailQueue: Queue,
    @InjectQueue('orders') private readonly ordersQueue: Queue,
  ) {}

  @Get('stats')
  async getStats() {
    const queues = {
      email: await this.getQueueStats(this.emailQueue),
      orders: await this.getQueueStats(this.ordersQueue),
    };
    return queues;
  }

  @Post(':queueName/retry-failed')
  async retryFailed(@Param('queueName') queueName: string) {
    const queue = queueName === 'email' ? this.emailQueue : this.ordersQueue;
    const failedJobs = await queue.getFailed();
    
    for (const job of failedJobs) {
      await job.retry();
    }
    
    return { retried: failedJobs.length };
  }

  private async getQueueStats(queue: Queue) {
    return {
      name: queue.name,
      counts: {
        waiting: await queue.getWaitingCount(),
        active: await queue.getActiveCount(),
        completed: await queue.getCompletedCount(),
        failed: await queue.getFailedCount(),
        delayed: await queue.getDelayedCount(),
      },
    };
  }
}

**Kasus Penggunaan Nyata:**
1. **Production Monitoring**: Tim DevOps menggunakan Bull Board untuk memantau kesehatan queues secara real-time, melihat apakah ada job yang menumpuk atau gagal
2. **Debugging Failed Jobs**: Developer melihat detail failed job (payload, error message, stacktrace) langsung dari UI tanpa perlu query Redis atau database
3. **Retry Failed Jobs**: Setelah memperbaiki bug, tim ops me-retry semua failed jobs dengan satu klik di dashboard, tidak perlu deploy ulang
4. **Demo dan Testing**: Saat demo fitur async, tim QA menggunakan Bull Board untuk memastikan job ter-queue dan terproses dengan benar
5. **Emergency Pause**: Saat ada insiden (misal: payment gateway error), admin pause queue payments sementara untuk mencegah lebih banyak failed jobs
6. **Performance Analysis**: Melihat statistik: berapa banyak job per jam, average processing time, mana yang paling banyak gagal, untuk optimasi
