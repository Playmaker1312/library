# 25. Task Scheduling dan Queues

## 25.6. Producer dan Consumer Pattern

**Definisi Singkat:**
Producer-Consumer Pattern adalah desain pattern di mana ada pihak yang membuat tugas (Producer) dan pihak lain yang memproses tugas tersebut (Consumer), dipisahkan oleh Queue sebagai middleware. Ini memungkinkan decoupling dan async processing.

**Analogi:**
- **Producer**: Koki yang menyiapkan pesanan dan meletakkannya di meja pengambilan
- **Queue**: Meja pengambilan pesanan
- **Consumer**: Pelayan yang mengambil pesanan dari meja dan mengantarkannya ke meja pelanggan

Koki tidak perlu menunggu pelayan (decoupled), dan jika banyak pesanan, antrean menampungnya dulu.

**Poin-Poin Penting:**
- **Producer**: Menambahkan job ke queue
- **Consumer/Worker**: Memproses job dari queue
- **Queue**: Buffer penyimpanan job (Redis-backed di Bull)
- Decoupling: Producer tidak tahu detail Consumer
- Scalability: Bisa menambah Consumer tanpa mengubah Producer
- Backpressure: Queue menampung job jika Consumer lambat

**Contoh Kode:**
```typescript
// ========== PRODUCER SIDE ==========

import { Injectable } from '@nestjs/common';
import { InjectQueue } from '@nestjs/bull';
import { Queue } from 'bull';

@Injectable()
export class OrderProducer {
  constructor(
    @InjectQueue('orders') private readonly orderQueue: Queue,
    @InjectQueue('notifications') private readonly notificationQueue: Queue,
    @InjectQueue('analytics') private readonly analyticsQueue: Queue,
  ) {}

  // Producer untuk order processing
  async createOrder(orderData: any) {
    // 1. Simpan order ke database (synchronous)
    const order = await this.saveOrderToDatabase(orderData);

    // 2. Kirim ke berbagai queue untuk processing async (Producer)
    await Promise.all([
      // Queue untuk memproses pembayaran
      this.orderQueue.add(
        'process-payment',
        { orderId: order.id, amount: order.amount },
        { priority: 1, attempts: 3 },
      ),

      // Queue untuk mengirim notifikasi
      this.notificationQueue.add(
        'order-created',
        { orderId: order.id, userId: order.userId, email: order.email },
        { priority: 2, delay: 1000 },
      ),

      // Queue untuk analytics tracking
      this.analyticsQueue.add(
        'track-order',
        { orderId: order.id, userId: order.userId, items: order.items },
        { priority: 10 },
      ),
    ]);

    return order;
  }

  // Producer dengan berbagai opsi job
  async scheduleOrderCancellation(orderId: string, minutes: number = 30) {
    const job = await this.orderQueue.add(
      'cancel-order',
      { orderId, reason: 'Payment timeout' },
      {
        delay: minutes * 60 * 1000, // 30 menit delay
        jobId: `cancel-order-${orderId}`, // ID unik untuk cancel nanti
        removeOnComplete: true,
      },
    );

    return { jobId: job.id };
  }

  // Batch producer
  async sendBulkNotifications(userIds: string[], message: any) {
    const jobs = [];
    
    for (const userId of userIds) {
      const job = await this.notificationQueue.add(
        'push-notification',
        { userId, ...message },
        {
          priority: 5,
          attempts: 2,
        },
      );
      jobs.push(job.id);
    }

    return { scheduledJobs: jobs.length, jobIds: jobs };
  }

  private async saveOrderToDatabase(orderData: any) {
    return {
      id: 'ORD-' + Date.now(),
      ...orderData,
      status: 'pending',
    };
  }
}

// ========== CONSUMER SIDE ==========

import { Processor, Process, OnQueueActive, OnQueueCompleted, OnQueueFailed, OnQueueError } from '@nestjs/bull';
import { Job } from 'bull';
import { Injectable, Logger } from '@nestjs/common';

@Injectable()
@Processor({
  name: 'orders',
  concurrency: 3, // 3 worker threads
})
export class OrderConsumer {
  private readonly logger = new Logger(OrderConsumer.name);

  // Consumer untuk payment processing
  @Process('process-payment')
  async processPayment(job: Job) {
    this.logger.log(`[Consumer] Processing payment for order: ${job.data.orderId}`);
    
    const { orderId, amount } = job.data;

    // Update progress
    await job.progress(10);

    try {
      // Simulasi call payment gateway
      await new Promise(resolve => setTimeout(resolve, 2000));
      
      await job.progress(50);

      // Simulasi verifikasi pembayaran
      const paymentSuccess = Math.random() > 0.1; // 90% success rate

      if (!paymentSuccess) {
        throw new Error('Payment gateway rejected');
      }

      await job.progress(100);

      this.logger.log(`[Consumer] Payment successful for order: ${orderId}`);

      return {
        orderId,
        status: 'paid',
        transactionId: 'TXN-' + Date.now(),
      };
    } catch (error) {
      this.logger.error(`[Consumer] Payment failed for order ${orderId}: ${error.message}`);
      throw error; // Trigger retry
    }
  }

  // Consumer untuk order cancellation
  @Process('cancel-order')
  async cancelOrder(job: Job) {
    this.logger.log(`[Consumer] Cancelling order: ${job.data.orderId}`);
    
    const { orderId, reason } = job.data;

    // Cek apakah order sudah dibayar
    const order = await this.getOrder(orderId);
    
    if (order.status === 'paid') {
      this.logger.log(`[Consumer] Order ${orderId} already paid, skipping cancellation`);
      return { skipped: true, reason: 'Already paid' };
    }

    // Batalkan order
    await this.updateOrderStatus(orderId, 'cancelled', reason);

    this.logger.log(`[Consumer] Order ${orderId} cancelled: ${reason}`);

    return {
      orderId,
      status: 'cancelled',
      reason,
    };
  }

  // Consumer default untuk job tanpa nama
  @Process()
  async processDefault(job: Job) {
    this.logger.log(`[Consumer] Processing default job: ${job.id}`);
    return { processed: true };
  }

  // ========== EVENT LISTENERS ==========

  @OnQueueActive()
  onActive(job: Job) {
    this.logger.verbose(
      `Job ${job.id} (${job.name}) started processing`,
    );
  }

  @OnQueueCompleted()
  onCompleted(job: Job, result: any) {
    this.logger.log(
      `Job ${job.id} (${job.name}) completed. Result: ${JSON.stringify(result)}`,
    );
  }

  @OnQueueFailed()
  onFailed(job: Job, err: Error) {
    this.logger.error(
      `Job ${job.id} (${job.name}) failed. Attempt: ${job.attemptsMade}/${job.opts.attempts}. Error: ${err.message}`,
    );
    
    // Jika sudah mencapai max attempts, kirim alert
    if (job.attemptsMade >= job.opts.attempts) {
      this.sendAlert(job, err);
    }
  }

  @OnQueueError()
  onError(error: Error) {
    this.logger.error(`Queue error: ${error.message}`);
  }

  // ========== HELPER METHODS ==========

  private async getOrder(orderId: string) {
    return { id: orderId, status: 'pending' };
  }

  private async updateOrderStatus(orderId: string, status: string, reason?: string) {
    // Update database
  }

  private sendAlert(job: Job, error: Error) {
    this.logger.error(`ALERT: Job ${job.id} failed permanently - ${error.message}`);
    // Kirim ke Slack/Email
  }
}

// ========== FLOW: PRODUCER -> QUEUE -> CONSUMER ==========

// Contoh alur lengkap di Controller
import { Controller, Post, Body, Get, Param } from '@nestjs/common';
import { OrderProducer } from './order.producer';

@Controller('orders')
export class OrderController {
  constructor(private readonly orderProducer: OrderProducer) {}

  @Post()
  async createOrder(@Body() orderData: any) {
    // 1. Producer: Menerima request dan membuat job
    const order = await this.orderProducer.createOrder(orderData);
    
    // 2. Queue: Job disimpan di Redis
    // 3. Consumer: Memproses job secara async
    
    return {
      success: true,
      orderId: order.id,
      message: 'Order created and being processed',
    };
  }

  @Post(':id/cancel-scheduled')
  async scheduleCancellation(
    @Param('id') orderId: string,
    @Body('minutes') minutes: number,
  ) {
    const result = await this.orderProducer.scheduleOrderCancellation(orderId, minutes);
    return {
      success: true,
      jobId: result.jobId,
      message: `Order cancellation scheduled in ${minutes} minutes`,
    };
  }
}

// ========== PATTERN ADVANCED: FANOUT / CHAINING ==========

@Injectable()
export class OrderWorkflowService {
  constructor(
    @InjectQueue('orders') private orderQueue: Queue,
    @InjectQueue('inventory') private inventoryQueue: Queue,
    @InjectQueue('shipping') private shippingQueue: Queue,
  ) {}

  // Chain: Payment -> Inventory -> Shipping
  async createOrderWithWorkflow(orderData: any) {
    // Mulai dengan payment
    await this.orderQueue.add(
      'start-workflow',
      { 
        orderData,
        nextSteps: ['inventory-check', 'shipping-arrange']
      },
    );

    return { message: 'Workflow started' };
  }
}

// Consumer yang melanjutkan workflow
@Processor('orders')
export class WorkflowConsumer {
  constructor(
    @InjectQueue('inventory') private inventoryQueue: Queue,
    @InjectQueue('shipping') private shippingQueue: Queue,
  ) {}

  @Process('start-workflow')
  async startWorkflow(job: Job) {
    const { orderData, nextSteps } = job.data;

    // 1. Process payment
    const paymentResult = await this.processPayment(orderData);

    // 2. Lanjut ke step berikutnya (Fan-out)
    await Promise.all([
      nextSteps.includes('inventory-check') && this.inventoryQueue.add(
        'check-inventory',
        { orderData, paymentResult },
      ),
      nextSteps.includes('shipping-arrange') && this.shippingQueue.add(
        'arrange-shipping',
        { orderData, paymentResult },
      ),
    ]);

    return { workflow: 'started' };
  }

  private async processPayment(orderData: any) {
    return { success: true, transactionId: 'TXN-123' };
  }
}
```

**Kasus Penggunaan Nyata:**
1. **E-commerce Checkout**: User klik "Bayar" -> Producer menyimpan order dan kirim ke queue -> Consumer memproses pembayaran, kurangi stok, kirim konfirmasi email (semua async, user tidak menunggu)
2. **Upload Video**: User upload video -> Producer menyimpan file dan kirim ke encoding queue -> Multiple Consumers encode ke berbagai resolusi (480p, 720p, 1080p) secara parallel
3. **Newsletter System**: Admin kirim newsletter ke 100.000 subscriber -> Producer membagi ke 100.000 job -> 20 Consumer memproses secara parallel, masing-masing mengirim 5000 email dengan rate limiting
4. **Order Timeout**: User buat order tapi belum bayar -> Producer buat delayed job untuk cancel dalam 30 menit -> Jika user bayar sebelum 30 menit, Producer cancel job tersebut
5. **Event Sourcing**: Setiap perubahan data memicu event -> Producer mengirim event ke berbagai queue -> Consumers yang berbeda memproses untuk keperluan berbeda (audit log, analytics, search indexing)
