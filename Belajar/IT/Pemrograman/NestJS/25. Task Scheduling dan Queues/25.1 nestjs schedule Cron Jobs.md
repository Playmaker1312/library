# 25. Task Scheduling dan Queues

## 25.1. nestjs/schedule: Cron Jobs

**Definisi Singkat:**
`@nestjs/schedule` adalah modul scheduling resmi NestJS yang memungkinkan menjalankan tugas secara otomatis pada waktu tertentu, interval, atau timeout berdasarkan cron expressions atau decorator.

**Analogi:**
Seperti alarm yang berbunyi pada waktu yang ditentukan - setiap pagi jam 7 untuk bangun tidur, atau setiap 30 menit untuk minum air.

**Poin-Poin Penting:**
- Package: `@nestjs/schedule`
- Berdasarkan library `node-cron`
- Decorator: `@Cron()`, `@Interval()`, `@Timeout()`
- Mendukung cron expressions
- Dapat menjadwalkan secara dinamis
- Integration dengan NestJS DI system
- Harus mengimport `ScheduleModule.forRoot()`

**Contoh Kode:**
```typescript
// Install: npm install @nestjs/schedule

// schedule.module.ts
import { Module } from '@nestjs/common';
import { ScheduleModule } from '@nestjs/schedule';
import { TasksService } from './tasks.service';

@Module({
  imports: [
    ScheduleModule.forRoot(),  // Wajib di-root module
  ],
  providers: [TasksService],
})
export class AppModule {}

// tasks.service.ts - Basic Cron Jobs
import { Injectable, Logger } from '@nestjs/common';
import { Cron, CronExpression } from '@nestjs/schedule';

@Injectable()
export class TasksService {
  private readonly logger = new Logger(TasksService.name);

  // Cron Expression: * * * * * *
  // ┬ ┬ ┬ ┬ ┬ ┬
  // │ │ │ │ │ │
  // │ │ │ │ │ └── day of week (0 - 7) (0 or 7 is Sun)
  // │ │ │ │ └──── month (1 - 12)
  // │ │ │ └────── day of month (1 - 31)
  // │ │ └──────── hour (0 - 23)
  // │ └────────── minute (0 - 59)
  // └──────────── second (0 - 59) (optional)

  // Setiap detik
  @Cron('* * * * * *')
  handleCronEverySecond() {
    this.logger.debug('Called every second');
  }

  // Menggunakan CronExpression enum
  @Cron(CronExpression.EVERY_MINUTE)
  handleCronEveryMinute() {
    this.logger.log('Called every minute');
  }

  // Setiap jam tepat
  @Cron(CronExpression.EVERY_HOUR)
  handleCronEveryHour() {
    this.logger.log('Called every hour');
  }

  // Setiap hari jam 3 pagi
  @Cron('0 0 3 * * *')
  handleCronDailyAt3AM() {
    this.logger.log('Running daily backup at 3:00 AM');
    this.performDatabaseBackup();
  }

  // Setiap hari Senin-Jumat jam 9 pagi
  @Cron('0 0 9 * * 1-5')
  handleCronWeekdayAt9AM() {
    this.logger.log('Sending daily report at 9:00 AM (weekdays)');
    this.sendDailyReport();
  }

  // Setiap 15 menit pada jam kerja (9-17)
  @Cron('0 */15 9-17 * * *')
  handleCronEvery15MinutesDuringWorkHours() {
    this.logger.log('Checking system health');
    this.checkSystemHealth();
  }

  // Akhir bulan (hari terakhir bulan)
  @Cron('0 0 0 L * *')
  handleCronLastDayOfMonth() {
    this.logger.log('Generating monthly report on last day');
    this.generateMonthlyReport();
  }

  // Cron dengan nama untuk manajemen
  @Cron('*/10 * * * * *', {
    name: 'system_health_check',
    timeZone: 'Asia/Jakarta',
  })
  handleNamedCron() {
    this.logger.log('System health check (named cron)');
  }

  // Private methods
  private performDatabaseBackup() {
    this.logger.log('Database backup completed');
  }

  private sendDailyReport() {
    this.logger.log('Daily report sent');
  }

  private checkSystemHealth() {
    this.logger.log('System health OK');
  }

  private generateMonthlyReport() {
    this.logger.log('Monthly report generated');
  }
}
```

**Kasus Penggunaan Nyata:**
1. **Database Backup**: Menjalankan backup database setiap hari jam 3 pagi saat traffic rendah
2. **Log Rotation & Cleanup**: Menghapus log lama setiap minggu untuk menghemat ruang disk
3. **Daily Report**: Mengirim email laporan penjualan harian ke manajemen setiap jam 9 pagi
4. **Sync Data External**: Men-sinkronkan data dari sistem eksternal (payment gateway, shipping) setiap 30 menit
5. **Cache Warming**: Memanaskan cache data populer setiap pagi sebelum jam kerja dimulai
6. **Reminder Notifications**: Mengirim notifikasi reminder untuk tagihan yang jatuh tempo
