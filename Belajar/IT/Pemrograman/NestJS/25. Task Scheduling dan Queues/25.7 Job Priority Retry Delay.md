# 25. Task Scheduling dan Queues

## 25.7. Job Priority, Retry, Delay

**Definisi Singkat:**
Job Priority, Retry, dan Delay adalah fitur Bull untuk mengontrol bagaimana job diproses: Priority menentukan urutan, Retry mengatur percobaan ulang jika gagal, Delay menunda eksekusi job sampai waktu tertentu.

**Analogi:**
- **Priority**: Seperti antrean bandara - penumpang bisnis class (priority tinggi) naik pesawat lebih dulu
- **Retry**: Seperti menelepon teman yang tidak mengangkat - coba lagi beberapa kali dengan interval sebelum menyerah
- **Delay**: Seperti mengirim pesan WhatsApp dengan "schedule message" - pesan terkirim pada waktu yang ditentukan

**Poin-Poin Penting:**
- **Priority**: Angka lebih kecil = prioritas lebih tinggi (1 > 10)
- **Retry**: `attempts` + `backoff` (exponential/fixed)
- **Delay**: Eksekusi tertunda X milidetik dari sekarang
- Kombinasi: Job dengan priority tinggi, retry 5x, delay 1 jam
- `removeOnComplete`/`removeOnFail`: Pembersihan job otomatis

**Contoh Kode:**
```typescript
import { Injectable, Logger } from '@nestjs/common';
import { InjectQueue } from '@nestjs/bull';
import { Queue, Job } from 'bull';

@Injectable()
export class JobFeaturesService {
  private readonly logger = new Logger(JobFeaturesService.name);

  constructor(
    @InjectQueue('orders') private readonly orderQueue: Queue,
    @InjectQueue('notifications') private readonly notificationQueue: Queue,
    @InjectQueue('payments') private readonly paymentQueue: Queue,
  ) {}

  // ========== JOB PRIORITY ==========

  async createJobsWithPriority() {
    // Priority 1 (TERTINGGI) - Order dari VIP
    await this.orderQueue.add(
      'process-order',
      { orderId: 'VIP-001', userId: 'user-vip', amount: 10000000 },
      { priority: 1 },
    );

    // Priority 5 - Order reguler
    await this.orderQueue.add(
      'process-order',
      { orderId: 'REG-001', userId: 'user-reguler', amount: 100000 },
      { priority: 5 },
    );

    // Priority 10 (RENDAH) - Laporan bulanan
    await this.orderQueue.add(
      'generate-report',
      { reportType: 'monthly', month: 'January' },
      { priority: 10 },
    );

    this.logger.log('Jobs with different priorities added');

    // Urutan eksekusi yang diharapkan:
    // 1. VIP-001 (priority 1)
    // 2. REG-001 (priority 5)
    // 3. generate-report (priority 10)
  }

  // Contoh penggunaan priority nyata
  async addPaymentJob(amount: number, isVip: boolean) {
    const priority = isVip ? 1 : 5;
    
    await this.paymentQueue.add(
      'process-payment',
      { amount, isVip },
      { priority },
    );
  }

  // ========== JOB RETRY ==========

  async addJobWithRetry() {
    // Basic retry: 3x percobaan
    await this.notificationQueue.add(
      'send-email',
      { to: 'user@example.com', subject: 'Welcome' },
      {
        attempts: 3, // Maksimal 3x coba
      },
    );

    // Retry dengan exponential backoff
    await this.paymentQueue.add(
      'charge-card',
      { cardToken: 'tok_visa', amount: 50000 },
      {
        attempts: 5,
        backoff: {
          type: 'exponential',
          delay: 1000, // Delay awal 1 detik
          // Delay berikutnya: 2s, 4s, 8s, 16s
        },
      },
    );

    // Retry dengan fixed delay
    await this.notificationQueue.add(
      'send-sms',
      { phone: '+628123456789', message: 'Your OTP is 123456' },
      {
        attempts: 3,
        backoff: {
          type: 'fixed',
          delay: 5000, // Selalu 5 detik setiap retry
        },
      },
    );

    // Custom retry logic
    await this.paymentQueue.add(
      'process-refund',
      { orderId: 'ORD-123', amount: 100000 },
      {
        attempts: 5,
        backoff: (attemptsMade: number, type: string, err: Error) => {
          // Custom delay berdasarkan error type
          if (err.message.includes('rate limit')) {
            return 30000; // Tunggu 30 detik jika rate limited
          }
          return attemptsMade * 5000; // Exponential manual
        },
      },
    );

    this.logger.log('Jobs with retry added');
  }

  // ========== JOB DELAY ==========

  async addJobWithDelay() {
    // Delay 5 detik dari sekarang
    await this.notificationQueue.add(
      'send-email',
      { to: 'user@example.com', subject: 'Thanks for joining!' },
      {
        delay: 5000, // 5 detik
      },
    );

    // Schedule untuk waktu spesifik
    const sendAt = new Date();
    sendAt.setHours(9, 0, 0, 0); // Jam 9 pagi
    
    // Jika sudah lewat jam 9, schedule besok
    if (sendAt < new Date()) {
      sendAt.setDate(sendAt.getDate() + 1);
    }

    const delayUntil9AM = sendAt.getTime() - Date.now();

    await this.notificationQueue.add(
      'send-daily-report',
      { recipients: ['manager@company.com'] },
      {
        delay: delayUntil9AM,
        jobId: 'daily-report-' + sendAt.toISOString().split('T')[0],
      },
    );

    this.logger.log(`Scheduled daily report at ${sendAt.toISOString()}`);
  }

  // Order timeout pattern
  async createOrderWithTimeout(orderData: any) {
    const orderId = 'ORD-' + Date.now();
    
    // 1. Buat order
    const order = { id: orderId, ...orderData, status: 'pending' };
    
    // 2. Schedule pembatalan otomatis dalam 30 menit
    const cancellationJob = await this.orderQueue.add(
      'cancel-order',
      { orderId, reason: 'Payment timeout' },
      {
        delay: 30 * 60 * 1000, // 30 menit
        jobId: `cancel-${orderId}`,
        removeOnComplete: true,
      },
    );

    this.logger.log(`Order ${orderId} created, cancellation scheduled in 30 minutes`);

    return {
      order,
      cancellationJobId: cancellationJob.id,
    };
  }

  // Batalkan timeout jika pembayaran sukses
  async cancelOrderTimeout(orderId: string) {
    const jobId = `cancel-${orderId}`;
    const job = await this.orderQueue.getJob(jobId);
    
    if (job) {
      // Cek apakah job masih waiting/delayed
      const state = await job.getState();
      
      if (state === 'delayed' || state === 'waiting') {
        await job.remove();
        this.logger.log(`Order ${orderId} timeout cancelled - payment received`);
        return { success: true };
      }
    }

    this.logger.warn(`Cancellation job for order ${orderId} not found or already executed`);
    return { success: false, reason: 'Job not found' };
  }

  // ========== KOMBINASI SEMUA FITUR ==========

  async createAdvancedJob() {
    const job = await this.paymentQueue.add(
      'process-subscription',
      { 
        subscriptionId: 'SUB-789',
        userId: 'user-123',
        amount: 99000,
        cardToken: 'tok_visa_123',
      },
      {
        // Priority: Tinggi karena subscription penting
        priority: 2,
        
        // Retry: 5x dengan exponential backoff
        attempts: 5,
        backoff: {
          type: 'exponential',
          delay: 2000,
        },
        
        // Delay: Coba 1 jam dari sekarang (untuk scheduled charge)
        // delay: 60 * 60 * 1000,
        
        // Auto remove setelah selesai
        removeOnComplete: true,
        removeOnFail: false, // Simpan yang gagal untuk analisis
        
        // Job ID untuk tracking
        jobId: `subscription-charge-SUB-789-${Date.now()}`,
      },
    );

    this.logger.log(`Advanced job created: ${job.id}`);
    return job.id;
  }
}

// ========== PROCESSOR DENGAN RETRY LOGIC ==========

import { Processor, Process } from '@nestjs/bull';
import { Job } from 'bull';

@Processor('payments')
export class PaymentProcessor {
  private readonly logger = new Logger(PaymentProcessor.name);

  @Process('process-payment')
  async processPayment(job: Job) {
    this.logger.log(
      `Processing payment, attempt ${job.attemptsMade + 1}/${job.opts.attempts}`,
    );

    const { amount, cardToken } = job.data;

    try {
      // Simulasi call payment gateway yang sering gagal
      const result = await this.callPaymentGateway(amount, cardToken);
      
      this.logger.log(`Payment successful: ${result.transactionId}`);
      
      return result;
    } catch (error) {
      this.logger.error(
        `Payment failed (attempt ${job.attemptsMade + 1}): ${error.message}`,
      );

      // Contoh: jika error adalah card expired, jangan retry
      if (error.code === 'card_expired') {
        // Tidak throw = job dianggap sukses (tapi dengan status failed)
        // Atau gunakan moveToFailed secara manual
        await job.moveToFailed({ message: 'Card expired - will not retry' }, true);
        return { error: 'Card expired', noRetry: true };
      }

      // Untuk error lain, throw untuk trigger retry
      throw error;
    }
  }

  private async callPaymentGateway(amount: number, cardToken: string) {
    // Simulasi 70% failure rate untuk demo retry
    if (Math.random() < 0.7) {
      const errors = [
        { code: 'network_error', message: 'Network timeout' },
        { code: 'rate_limit', message: 'Rate limit exceeded' },
        { code: 'gateway_down', message: 'Payment gateway unavailable' },
      ];
      const randomError = errors[Math.floor(Math.random() * errors.length)];
      throw new Error(randomError.message);
    }

    return {
      transactionId: 'TXN-' + Date.now(),
      amount,
      status: 'success',
    };
  }
}

// ========== MONITORING JOB STATUS ==========

@Injectable()
export class JobMonitorService {
  constructor(
    @InjectQueue('orders') private readonly orderQueue: Queue,
  ) {}

  async getQueueStats() {
    const [
      waiting,
      active,
      completed,
      failed,
      delayed,
    ] = await Promise.all([
      this.orderQueue.getWaitingCount(),
      this.orderQueue.getActiveCount(),
      this.orderQueue.getCompletedCount(),
      this.orderQueue.getFailedCount(),
      this.orderQueue.getDelayedCount(),
    ]);

    return {
      queueName: 'orders',
      waiting,
      active,
      completed,
      failed,
      delayed,
    };
  }

  async getJobDetails(jobId: string) {
    const job = await this.orderQueue.getJob(jobId);
    
    if (!job) {
      return { error: 'Job not found' };
    }

    return {
      id: job.id,
      name: job.name,
      data: job.data,
      state: await job.getState(),
      progress: job.progress(),
      attemptsMade: job.attemptsMade,
      maxAttempts: job.opts.attempts,
      failedReason: job.failedReason,
      stacktrace: job.stacktrace,
      processedOn: job.processedOn,
      finishedOn: job.finishedOn,
      delay: job.opts.delay,
      priority: job.opts.priority,
    };
  }

  // Retry manual job yang gagal
  async retryFailedJob(jobId: string) {
    const job = await this.orderQueue.getJob(jobId);
    
    if (job && await job.getState() === 'failed') {
      await job.retry();
      return { success: true, message: `Job ${jobId} retried` };
    }

    return { error: 'Job not found or not in failed state' };
  }

  // Retry semua failed jobs
  async retryAllFailed() {
    const failedJobs = await this.orderQueue.getFailed();
    
    for (const job of failedJobs) {
      await job.retry();
    }

    return { retried: failedJobs.length };
  }
}
```

**Kasus Penggunaan Nyata:**
1. **Payment Processing**: Job dengan priority tinggi, retry 5x dengan exponential backoff (1s, 2s, 4s, 8s, 16s) - jika payment gateway error karena network, coba lagi nanti
2. **Order Timeout**: Delay 30 menit untuk cancel order jika tidak dibayar, dan cancel delay tersebut jika user bayar sebelum 30 menit
3. **Email Campaign**: 10.000 email dengan priority rendah (10), retry 2x dengan fixed delay 5 menit - tidak mendesak, tapi harus sampai
4. **OTP SMS**: Priority tinggi (1), retry 3x dengan delay 1 menit - user menunggu kode OTP, harus cepat dan reliable
5. **Scheduled Reports**: Delay sampai jam 9 pagi besok, retry 1x jika gagal - laporan harus diterima tepat waktu
6. **Webhook Delivery**: Exponential backoff yang sangat panjang (delay awal 1 menit, max 24 jam) - third-party bisa down lama, kita harus terus mencoba
