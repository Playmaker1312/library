# 33. gRPC ## 33.5 Streaming Server Client Bidirectional

**Definisi Singkat:** gRPC mendukung 4 jenis streaming: Unary (single request-response), Server Streaming (server mengirim multiple responses), Client Streaming (client mengirim multiple requests), dan Bidirectional Streaming (keduanya streaming simultan via HTTP/2).

**Analogi:** Streaming bidirectional seperti percakapan telepon dua arah — bukan seperti surat (unary) yang harus menunggu balasan, kedua pihak bisa bicara kapan saja secara real-time.

**Poin-Poin Penting:**
- **@GrpcStreamMethod** decorator untuk bidirectional handler
- **Observable** untuk handle stream di server/client
- **Subject** untuk push data ke stream
- **HTTP/2 multiplexing** memungkinkan multiple stream simultan
- **backpressure** handling untuk flow control

**Contoh Kode:**
```typescript
// chat.proto
syntax = "proto3";

package chat;

service ChatService {
  rpc Chat (stream ChatMessage) returns (stream ChatMessage) {}
  rpc ServerStream (ChatRequest) returns (stream ChatMessage) {}
  rpc ClientStream (stream ChatMessage) returns (ChatSummary) {}
}

message ChatMessage {
  string userId = 1;
  string text = 2;
  int64 timestamp = 3;
}

message ChatRequest {
  string roomId = 1;
  int32 limit = 2;
}

message ChatSummary {
  int32 totalMessages = 1;
  repeated string participants = 2;
}
```

```typescript
// chat.controller.ts
import { Controller } from '@nestjs/common';
import { GrpcStreamMethod } from '@nestjs/microservices';
import { Observable, Subject } from 'rxjs';
import { ChatService } from './chat.service';

interface ChatMessage {
  userId: string;
  text: string;
  timestamp: number;
}

@Controller()
export class ChatController {
  constructor(private readonly chatService: ChatService) {}

  @GrpcStreamMethod('ChatService', 'Chat')
  chat(messages: Observable<ChatMessage>): Observable<ChatMessage> {
    const subject = new Subject<ChatMessage>();

    messages.subscribe({
      next: (msg) => {
        const reply = this.chatService.processMessage(msg);
        subject.next(reply);
      },
      error: (err) => subject.error(err),
      complete: () => subject.complete(),
    });

    return subject.asObservable();
  }

  @GrpcStreamMethod('ChatService', 'ServerStream')
  serverStream(data: { roomId: string; limit: number }): Observable<ChatMessage> {
    return this.chatService.getRoomHistory(data.roomId, data.limit);
  }

  @GrpcStreamMethod('ChatService', 'ClientStream')
  clientStream(messages: Observable<ChatMessage>): Observable<{ totalMessages: number; participants: string[] }> {
    return this.chatService.summarizeMessages(messages);
  }
}
```

```typescript
// chat.service.ts
import { Injectable } from '@nestjs/common';
import { Observable, Subject } from 'rxjs';

interface ChatMessage {
  userId: string;
  text: string;
  timestamp: number;
}

@Injectable()
export class ChatService {
  private roomMessages: Map<string, ChatMessage[]> = new Map();

  processMessage(msg: ChatMessage): ChatMessage {
    const room = 'general';
    if (!this.roomMessages.has(room)) {
      this.roomMessages.set(room, []);
    }
    this.roomMessages.get(room).push(msg);

    return {
      userId: 'bot',
      text: `Echo: ${msg.text}`,
      timestamp: Date.now(),
    };
  }

  getRoomHistory(roomId: string, limit: number): Observable<ChatMessage> {
    const subject = new Subject<ChatMessage>();
    const messages = this.roomMessages.get(roomId) || [];

    messages.slice(-limit).forEach((msg) => subject.next(msg));
    subject.complete();

    return subject.asObservable();
  }

  summarizeMessages(messages: Observable<ChatMessage>): Observable<{ totalMessages: number; participants: string[] }> {
    const subject = new Subject<{ totalMessages: number; participants: string[] }>();
    const msgs: ChatMessage[] = [];

    messages.subscribe({
      next: (msg) => msgs.push(msg),
      complete: () => {
        const participants = [...new Set(msgs.map((m) => m.userId))];
        subject.next({ totalMessages: msgs.length, participants });
        subject.complete();
      },
    });

    return subject.asObservable();
  }
}
```

**Kasus Penggunaan Nyata:** Real-time chat application — client mengirim pesan, server memproses dan broadcast ke participant lain. Juga cocok untuk live streaming data seperti harga saham, log monitoring, atau GPS tracking.
