# 33. gRPC ## 33.3 gRPC Server di NestJS

**Definisi Singkat:** gRPC Server di NestJS diimplementasikan dengan decorator `@GrpcMethod` untuk menangani RPC calls. Server berjalan di atas transport layer NestJS microservice dengan konfigurasi proto file.

**Analogi:** gRPC server seperti customer service yang punya SOP (proto) — setiap permintaan masuk dicocokkan dengan SOP, diproses, dan dikembalikan sesuai format yang sudah ditentukan.

**Poin-Poin Penting:**
- **@GrpcMethod('service', 'method')** decorator handler
- **@GrpcStreamMethod** untuk streaming handler
- **@Payload()** extract parameter dari request
- **@Metadata()** akses metadata gRPC
- **Observable** untuk response streaming

**Contoh Kode:**
```typescript
// hero.controller.ts
import { Controller, Get } from '@nestjs/common';
import { GrpcMethod, GrpcStreamMethod } from '@nestjs/microservices';
import { Observable, Subject } from 'rxjs';
import { HeroService } from './hero.service';

interface HeroById {
  id: number;
}

interface Hero {
  id: number;
  name: string;
  power: number;
}

@Controller()
export class HeroController {
  constructor(private readonly heroService: HeroService) {}

  @GrpcMethod('HeroService', 'FindOne')
  findOne(data: HeroById, metadata: any): Hero {
    return this.heroService.findOne(data.id);
  }

  @GrpcStreamMethod('HeroService', 'FindMany')
  findMany(messages: Observable<HeroById>): Observable<Hero> {
    const subject = new Subject<Hero>();

    messages.subscribe({
      next: (msg) => {
        const hero = this.heroService.findOne(msg.id);
        subject.next(hero);
      },
      error: (err) => subject.error(err),
      complete: () => subject.complete(),
    });

    return subject.asObservable();
  }
}
```

```typescript
// hero.service.ts
import { Injectable } from '@nestjs/common';

interface Hero {
  id: number;
  name: string;
  power: number;
}

@Injectable()
export class HeroService {
  private heroes: Hero[] = [
    { id: 1, name: 'Superman', power: 100 },
    { id: 2, name: 'Batman', power: 85 },
    { id: 3, name: 'Flash', power: 95 },
  ];

  findOne(id: number): Hero {
    return this.heroes.find((h) => h.id === id);
  }
}
```

```typescript
// app.module.ts
import { Module } from '@nestjs/common';
import { join } from 'path';

@Module({
  controllers: [HeroController],
  providers: [HeroService],

```

**Kasus Penggunaan Nyata:** Service user management di backend yang menerima request dari service lain — validasi token, query database, dan return user data via gRPC dengan latency rendah.
