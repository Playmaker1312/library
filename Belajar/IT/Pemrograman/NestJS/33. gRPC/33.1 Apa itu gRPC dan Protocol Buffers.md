# 33. gRPC ## 33.1 Apa itu gRPC dan Protocol Buffers

**Definisi Singkat:** gRPC adalah framework RPC (Remote Procedure Call) open-source dari Google yang menggunakan HTTP/2 untuk transport dan Protocol Buffers sebagai interface definition language. Protocol Buffers adalah format serialisasi data terstruktur yang lebih cepat dan lebih kecil dari JSON.

**Analogi:** gRPC seperti kurir ekspres yang punya kontrak pengiriman ketat (proto file) — dibanding JSON yang seperti surat biasa, gRPC mengemas data lebih rapat, mengirim lebih cepat, dan bisa melakukan streaming dua arah seperti telepon.

**Poin-Poin Penting:**
- **@GrpcMethod** decorator untuk method handler server
- **@GrpcStreamMethod** decorator untuk streaming handler
- **@GrpcStreamCall** decorator client streaming
- **proto file** sebagai kontrak service definition
- **HTTP/2** multiplexing dan bidirectional streaming

**Contoh Kode:**
```typescript
// hero.proto
syntax = "proto3";

package hero;

service HeroService {
  rpc FindOne (HeroById) returns (Hero) {}
  rpc FindMany (stream HeroById) returns (stream Hero) {}
}

message HeroById {
  int32 id = 1;
}

message Hero {
  int32 id = 1;
  string name = 2;
  int32 power = 3;
}
```

```typescript
// main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { MicroserviceOptions, Transport } from '@nestjs/microservices';
import { join } from 'path';

async function bootstrap() {
  const app = await NestFactory.createMicroservice<MicroserviceOptions>(
    AppModule,
    {
      transport: Transport.GRPC,
      options: {
        package: 'hero',
        protoPath: join(__dirname, 'hero/hero.proto'),
        url: '0.0.0.0:50051',
      },
    },
  );
  await app.listen();
}
bootstrap();
```

**Kasus Penggunaan Nyata:** Microservice internal komunikasi antar-service di perusahaan — pengganti REST API untuk service-to-service communication dengan performa tinggi dan strict contract.
