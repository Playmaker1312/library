# 33. gRPC ## 33.4 gRPC Client di NestJS

**Definisi Singkat:** gRPC Client di NestJS menggunakan `ClientGrpc` yang diinjeksi melalui decorator `@Client()` untuk memanggil service gRPC remote. Client mendapatkan typed proxy service untuk invoke RPC methods.

**Analogi:** gRPC Client seperti remote control TV — tanpa tahu detail internal TV, remote bisa mengirim perintah (channel up, volume down) dan TV merespons. Proto file seperti buku panduan remote.

**Poin-Poin Penting:**
- **@Client()** decorator untuk inject gRPC client
- **ClientGrpc.getService<T>()** mendapatkan typed service
- **onModuleInit** lifecycle untuk inisialisasi client
- **Transport.GRPC** konfigurasi transport
- **Observable** untuk async response

**Contoh Kode:**
```typescript
// hero-client.module.ts
import { Module } from '@nestjs/common';
import { ClientsModule, Transport } from '@nestjs/microservices';
import { join } from 'path';
import { HeroClientController } from './hero-client.controller';
import { HeroClientService } from './hero-client.service';

@Module({
  imports: [
    ClientsModule.register([
      {
        name: 'HERO_PACKAGE',
        transport: Transport.GRPC,
        options: {
          package: 'hero',
          protoPath: join(__dirname, '../proto/hero.proto'),
          url: 'localhost:50051',
        },
      },
    ]),
  ],
  controllers: [HeroClientController],
  providers: [HeroClientService],
})
export class HeroClientModule {}
```

```typescript
// hero-client.service.ts
import { Injectable, OnModuleInit } from '@nestjs/common';
import { ClientGrpc } from '@nestjs/microservices';
import { Inject } from '@nestjs/common';
import { Observable } from 'rxjs';

interface HeroService {
  findOne(data: { id: number }): Observable<{ id: number; name: string; power: number }>;
}

@Injectable()
export class HeroClientService implements OnModuleInit {
  private heroService: HeroService;

  constructor(@Inject('HERO_PACKAGE') private client: ClientGrpc) {}

  onModuleInit() {
    this.heroService = this.client.getService<HeroService>('HeroService');
  }

  getHero(id: number): Observable<{ id: number; name: string; power: number }> {
    return this.heroService.findOne({ id });
  }
}
```

```typescript
// hero-client.controller.ts
import { Controller, Get, Param } from '@nestjs/common';
import { HeroClientService } from './hero-client.service';
import { Observable } from 'rxjs';

@Controller('heroes')
export class HeroClientController {
  constructor(private readonly heroClient: HeroClientService) {}

  @Get(':id')
  findOne(@Param('id') id: number): Observable<{ id: number; name: string; power: number }> {
    return this.heroClient.getHero(id);
  }
}
```

**Kasus Penggunaan Nyata:** API Gateway yang menerima HTTP request dari client frontend dan meneruskannya ke berbagai microservice backend via gRPC — mengurangi latency dan beban network internal.
