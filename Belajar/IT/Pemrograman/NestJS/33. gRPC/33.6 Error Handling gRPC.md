# 33. gRPC ## 33.6 Error Handling gRPC

**Definisi Singkat:** gRPC memiliki mekanisme error handling terstruktur menggunakan status codes standar (seperti HTTP status codes) dan pesan error detail. NestJS menyediakan `RpcException` untuk melempar error gRPC.

**Analogi:** Error handling gRPC seperti kode diagnosa di bengkel mobil — setiap kode error (404 = part not found, 500 = engine failure) punya arti spesifik, bukan sekadar "mobil rusak". Mekanik (server) harus memberitahu pelanggan (client) dengan kode yang tepat.

**Poin-Poin Penting:**
- **RpcException** untuk throw error gRPC
- **@UseFilters(RpcExceptionFilter)** filter untuk gRPC
- **status** codes: NOT_FOUND, INVALID_ARGUMENT, INTERNAL, dll
- **metadata** untuk error details
- **try-catch** di client interceptor

**Contoh Kode:**
```typescript
// grpc-error.filter.ts
import { Catch, RpcExceptionFilter, ArgumentsHost } from '@nestjs/common';
import { Observable, throwError } from 'rxjs';
import { RpcException } from '@nestjs/microservices';

@Catch(RpcException)
export class GrpcExceptionFilter implements RpcExceptionFilter<RpcException> {
  catch(exception: RpcException, host: ArgumentsHost): Observable<any> {
    const error = exception.getError();
    const metadata = {
      timestamp: new Date().toISOString(),
      service: 'hero-service',
    };

    return throwError(() => ({
      code: error['code'] || 2, // default UNKNOWN
      message: error['message'] || 'Internal server error',
      details: JSON.stringify({ ...metadata, ...error['details'] }),
    }));
  }
}
```

```typescript
// hero.controller.with-errors.ts
import { Controller } from '@nestjs/common';
import { GrpcMethod, RpcException } from '@nestjs/microservices';
import { status } from '@grpc/grpc-js';

@Controller()
export class HeroControllerWithErrors {
  private heroes = [
    { id: 1, name: 'Superman' },
    { id: 2, name: 'Batman' },
  ];

  @GrpcMethod('HeroService', 'FindOne')
  findOne(data: { id: number }) {
    const hero = this.heroes.find((h) => h.id === data.id);

    if (!hero) {
      throw new RpcException({
        code: status.NOT_FOUND,
        message: `Hero with id ${data.id} not found`,
        details: {
          requestedId: data.id,
          availableIds: this.heroes.map((h) => h.id),
        },
      });
    }

    if (data.id <= 0) {
      throw new RpcException({
        code: status.INVALID_ARGUMENT,
        message: 'ID must be a positive integer',
      });
    }

    return hero;
  }

  @GrpcMethod('HeroService', 'CreateHero')
  createHero(data: { name: string; power: number }) {
    if (!data.name || data.name.trim().length === 0) {
      throw new RpcException({
        code: status.INVALID_ARGUMENT,
        message: 'Hero name is required',
      });
    }

    if (data.power < 0 || data.power > 100) {
      throw new RpcException({
        code: status.OUT_OF_RANGE,
        message: 'Power must be between 0 and 100',
      });
    }

    return { id: this.heroes.length + 1, ...data };
  }
}
```

```typescript
// client-error-handling.ts
// Di client, handle error gRPC
import { Injectable } from '@nestjs/common';
import { ClientGrpc } from '@nestjs/microservices';
import { Inject } from '@nestjs/common';
import { Observable, throwError } from 'rxjs';
import { catchError } from 'rxjs/operators';

@Injectable()
export class HeroClientService {
  private heroService: any;

  constructor(@Inject('HERO_PACKAGE') private client: ClientGrpc) {
    this.heroService = client.getService('HeroService');
  }

  getHero(id: number): Observable<any> {
    return this.heroService.findOne({ id }).pipe(
      catchError((error) => {
        console.error(`gRPC Error [${error.code}]: ${error.message}`);
        console.error('Details:', error.details);

        if (error.code === 5) {
          // NOT_FOUND
          return throwError(() => new Error(`Hero ${id} tidak ditemukan`));
        }

        return throwError(() => new Error('Service tidak tersedia'));
      }),
    );
  }
}
```

**Kasus Penggunaan Nyata:** Payment processing service — validation error (INVALID_ARGUMENT) untuk data pembayaran salah, NOT_FOUND untuk order tidak terdaftar, FAILED_PRECONDITION jika saldo tidak cukup, UNAUTHENTICATED jika token tidak valid.
