# 33. gRPC ## 33.7 gRPC vs REST Performance

**Definisi Singkat:** gRPC umumnya lebih cepat dari REST API karena menggunakan HTTP/2, binary serialization (Protobuf), dan multiplexing. Penelitian menunjukkan gRPC bisa 7-10x lebih cepat terutama untuk payload besar dan komunikasi internal.

**Analogi:** REST seperti sistem pos — setiap amplop (request) harus lengkap dengan alamat, perangko, dan isi surat dalam teks. gRPC seperti panggilan telepon — koneksi terbuka, data dikirim efisien dalam bentuk digital (binary), dan bisa saling bicara bersamaan.

**Poin-Poin Penting:**
- **HTTP/2 multiplexing** mengurangi overhead koneksi
- **Protobuf binary** 3-10x lebih kecil dari JSON
- **Streaming** mengurangi latency untuk real-time data
- **Strong typing** tanpa parsing overhead
- **Bidirectional** komunikasi lebih efisien

**Contoh Kode:**
```typescript
// performance-comparison.controller.ts
import { Controller, Get, Param } from '@nestjs/common';
import { PerformanceService } from './performance.service';

@Controller('performance')
export class PerformanceComparisonController {
  constructor(private readonly service: PerformanceService) {}

  @Get('rest/:count')
  async testRest(@Param('count') count: number) {
    const start = Date.now();
    const results = [];

    for (let i = 0; i < count; i++) {
      const response = await this.service.restCall();
      results.push(response);
    }

    return {
      method: 'REST',
      count,
      duration: Date.now() - start,
      avgMs: (Date.now() - start) / count,
    };
  }

  @Get('grpc/:count')
  async testGrpc(@Param('count') count: number) {
    const start = Date.now();
    const results = [];

    for (let i = 0; i < count; i++) {
      const response = await this.service.grpcCall();
      results.push(response);
    }

    return {
      method: 'gRPC',
      count,
      duration: Date.now() - start,
      avgMs: (Date.now() - start) / count,
    };
  }
}
```

```typescript
// performance.service.ts
import { Injectable } from '@nestjs/common';
import { HttpService } from '@nestjs/axios';
import { Inject } from '@nestjs/common';
import { ClientGrpc } from '@nestjs/microservices';
import { lastValueFrom } from 'rxjs';

interface UserService {
  getUser(data: { id: number }): any;
}

@Injectable()
export class PerformanceService {
  private userService: UserService;

  constructor(
    private readonly httpService: HttpService,
    @Inject('USER_PACKAGE') private client: ClientGrpc,
  ) {
    this.userService = this.client.getService<UserService>('UserService');
  }

  async restCall(): Promise<any> {
    const response = await lastValueFrom(
      this.httpService.get('http://localhost:3000/api/users/1', {
        headers: { 'Content-Type': 'application/json' },
      }),
    );
    return response.data;
  }

  async grpcCall(): Promise<any> {
    return lastValueFrom(this.userService.getUser({ id: 1 }));
  }
}
```

```typescript
// ringkasan perbandingan
// | Aspek          | REST                          | gRPC                           |
// |---------------|-------------------------------|--------------------------------|
// | Transport     | HTTP/1.1 (kebanyakan)         | HTTP/2                         |
// | Data Format   | JSON (text)                   | Protobuf (binary)              |
// | Payload Size  | Besar (verbose)               | Kecil (3-10x lebih kecil)      |
// | Speed         | Lebih lambat parsing JSON     | Lebih cepat parsing binary     |
// | Streaming     | SSE/WebSocket (tidak native)  | Native bidirectional streaming |
// | Best for      | Public APIs, browser clients  | Microservices, internal comm   |
```

**Kasus Penggunaan Nyata:** Netflix dan Square beralih ke gRPC untuk internal microservices — mengurangi latency 50-80% dan bandwidth hingga 70% dibanding REST JSON untuk komunikasi antar service di data center.
