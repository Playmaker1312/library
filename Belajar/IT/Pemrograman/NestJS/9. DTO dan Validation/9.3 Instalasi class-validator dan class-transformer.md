# 9. DTO dan Validation

## 9.3. Instalasi class-validator dan class-transformer

**Definisi Singkat:** `class-validator` menyediakan dekorator validasi, `class-transformer` mengubah plain object menjadi class instance.

**Analogi:** Seperti petugas imigrasi — `class-validator` memeriksa kelengkapan dokumen, `class-transformer` mengubah data mentah menjadi data resmi.

**Poin-Poin Penting:**
- Install via npm: `npm i class-validator class-transformer`
- `class-validator` untuk validasi dekorator
- `class-transformer` untuk transformasi tipe
- Keduanya digunakan oleh `ValidationPipe` NestJS

**Contoh Kode:**
```bash
# Terminal
npm install class-validator class-transformer
```

```typescript
// Setelah instalasi, import di module
import { IsString, IsEmail } from 'class-validator';
import { Type } from 'class-transformer';
```

**Kasus Penggunaan Nyata:** Setiap proyek NestJS yang membutuhkan validasi input pasti menginstall kedua package ini sebagai dependency inti.
