# 9. DTO dan Validation

## 9.1. Apa itu DTO Data Transfer Object

**Definisi Singkat:** DTO adalah objek yang digunakan untuk mentransfer data antara client dan server, mendefinisikan bentuk data yang valid untuk request/response.

**Analogi:** Seperti formulir pendaftaran — kamu tidak bisa sembarang mengisi, harus sesuai kolom yang disediakan.

**Poin-Poin Penting:**
- DTO bukan class entity/model database
- DTO menentukan shape data yang masuk/keluar
- Membantu validasi dan serialisasi data
- Best practice untuk memisahkan DTO dari entity

**Contoh Kode:**
```typescript
// Tanpa DTO — tidak terstruktur
@Post()
createUser(@Body() body: any) {
  // body bisa berisi apa saja
}

// Dengan DTO — terstruktur
@Post()
createUser(@Body() dto: CreateUserDto) {
  // dto sudah terdefinisi jelas
}
```

**Kasus Penggunaan Nyata:** Saat membuat endpoint registrasi user, DTO `CreateUserDto` memastikan hanya field `email`, `password`, `name` yang diterima, bukan field `role` atau `isAdmin` yang disalahgunakan.
