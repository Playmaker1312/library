# 9. DTO dan Validation

## 9.6. whitelist forbidNonWhitelisted transform

**Definisi Singkat:** Opsi pada `ValidationPipe` untuk mengontrol perilaku validasi: membersihkan data, menolak properti asing, dan mentransformasi tipe.

**Analogi:** Seperti satpam dengan tiga mode: (1) `whitelist` — buang barang ilegal, (2) `forbidNonWhitelisted` — tolak orang bawa barang ilegal, (3) `transform` — ubah KTP kertas jadi KTP elektronik.

**Poin-Poin Penting:**
- `whitelist: true` — hapus properti tanpa dekorator validasi
- `forbidNonWhitelisted: true` — throw error jika ada properti tidak dikenal
- `transform: true` — ubah tipe data (string "1" jadi number 1)
- `transform` juga mengubah plain object jadi instance DTO class

**Contoh Kode:**
```typescript
import { NestFactory } from '@nestjs/core';
import { ValidationPipe } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.useGlobalPipes(
    new ValidationPipe({
      whitelist: true,
      forbidNonWhitelisted: true,
      transform: true,
    }),
  );

  await app.listen(3000);
}
```

**Kasus Penggunaan Nyata:** Mencegah serangan Mass Assignment — jika user mengirim `{ "name": "John", "role": "admin" }` dan field `role` tidak ada di DTO, request langsung ditolak (forbidNonWhitelisted) atau field role dihapus (whitelist).
