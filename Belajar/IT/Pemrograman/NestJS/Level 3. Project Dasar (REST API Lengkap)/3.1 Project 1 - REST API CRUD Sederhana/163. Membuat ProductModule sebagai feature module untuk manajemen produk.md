# 163. Membuat ProductModule sebagai feature module untuk manajemen produk

## Definisi & Target
ProductModule adalah feature module yang mengelompokkan semua komponen terkait produk (controller, service, DTO). NestJS akan mendaftarkan module ini ke AppModule agar dapat digunakan.

## Komponen & Nest CLI Command
```bash
nest g module products
nest g controller products --no-spec
nest g service products --no-spec
```

File yang dimodifikasi:
- `src/products/products.module.ts`
- `src/app.module.ts` — registrasi ProductsModule

## Kode Implementasi (Per File)
```typescript
// src/products/products.module.ts
import { Module } from '@nestjs/common';
import { ProductsController } from './products.controller';
import { ProductsService } from './products.service';

@Module({
  controllers: [ProductsController],
  providers: [ProductsService],
  exports: [ProductsService],
})
export class ProductsModule {}
```

```typescript
// src/app.module.ts
import { Module } from '@nestjs/common';
import { ProductsModule } from './products/products.module';

@Module({
  imports: [ProductsModule],
})
export class AppModule {}
```

## Cara Integrasi & Pengujian
NestJS CLI otomatis mendaftarkan ProductsModule ke AppModule ketika menggunakan `nest g module`. Jalankan `npm run start:dev` — tidak ada error saat server menyala.
