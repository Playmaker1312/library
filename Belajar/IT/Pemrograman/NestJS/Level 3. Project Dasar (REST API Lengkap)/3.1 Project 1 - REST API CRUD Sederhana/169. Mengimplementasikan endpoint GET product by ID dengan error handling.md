# 169. Mengimplementasikan endpoint GET product by ID dengan error handling

## Definisi & Target
Endpoint `GET /products/:id` mengembalikan satu produk berdasarkan ID. Jika produk tidak ditemukan, service melempar NotFoundException yang otomatis menghasilkan response 404.

## Komponen & Nest CLI Command
Tidak ada command baru. Modifikasi di controller dan service.

## Kode Implementasi (Per File)
```typescript
// src/products/products.controller.ts
import { Controller, Get, Param } from '@nestjs/common';
import { ProductsService } from './products.service';

@Controller('products')
export class ProductsController {
  constructor(private readonly productsService: ProductsService) {}

  @Get(':id')
  findOne(@Param('id') id: string) {
    return this.productsService.findOne(+id);
  }
}
```

```typescript
// src/products/products.service.ts
import { Injectable, NotFoundException } from '@nestjs/common';

@Injectable()
export class ProductsService {
  private products = [];
  private nextId = 1;

  findOne(id: number) {
    const product = this.products.find((p) => p.id === id && p.isActive);
    if (!product) {
      throw new NotFoundException(`Product with ID #${id} not found`);
    }
    return { data: product };
  }
}
```

## Cara Integrasi & Pengujian
```bash
# Produk ditemukan
curl http://localhost:3000/products/1
# Response: { "data": { "id": 1, "name": "Laptop", ... } }

# Produk tidak ditemukan
curl http://localhost:3000/products/999
# Response: 404 Not Found
# { "message": "Product with ID #999 not found", "error": "Not Found", "statusCode": 404 }
```
