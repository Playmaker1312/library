# 172. Mengimplementasikan endpoint DELETE product dengan soft delete

## Definisi & Target
Endpoint `DELETE /products/:id` melakukan soft delete: produk tidak benar-benar dihapus dari array, melainkan properti `isActive` diubah menjadi `false`. Dengan cara ini, data masih tersimpan tetapi tidak muncul di response GET.

## Komponen & Nest CLI Command
Tidak ada command baru. Modifikasi controller dan service.

## Kode Implementasi (Per File)
```typescript
// src/products/products.controller.ts
import { Controller, Delete, Param } from '@nestjs/common';
import { ProductsService } from './products.service';

@Controller('products')
export class ProductsController {
  constructor(private readonly productsService: ProductsService) {}

  @Delete(':id')
  remove(@Param('id') id: string) {
    return this.productsService.remove(+id);
  }
}
```

```typescript
// src/products/products.service.ts
import { Injectable, NotFoundException } from '@nestjs/common';

@Injectable()
export class ProductsService {
  private products = [];
  private nextId = 1;

  remove(id: number) {
    const index = this.products.findIndex((p) => p.id === id && p.isActive);
    if (index === -1) {
      throw new NotFoundException(`Product with ID #${id} not found`);
    }
    this.products[index].isActive = false;
    return { message: 'Product deleted successfully' };
  }
}
```

## Cara Integrasi & Pengujian
```bash
# Hapus produk
curl -X DELETE http://localhost:3000/products/1
# Response: 200 OK
# { "message": "Product deleted successfully" }

# Coba GET produk yang sudah dihapus
curl http://localhost:3000/products/1
# Response: 404 Not Found

# Coba DELETE produk yang sudah dihapus/tidak ada
curl -X DELETE http://localhost:3000/products/999
# Response: 404 Not Found

# Daftar produk hanya menampilkan yang isActive = true
curl http://localhost:3000/products
# Response: { "data": [...] } — produk yang di-soft-delete tidak muncul
```
