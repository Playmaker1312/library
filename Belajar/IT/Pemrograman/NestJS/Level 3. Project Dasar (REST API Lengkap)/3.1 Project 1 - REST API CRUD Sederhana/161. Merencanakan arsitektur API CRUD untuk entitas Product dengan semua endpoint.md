# 161. Merencanakan arsitektur API CRUD untuk entitas Product dengan semua endpoint

## Definisi & Target
API CRUD untuk entitas Product memungkinkan client melakukan operasi Create, Read, Update, dan Delete terhadap data produk. Alur request-response dimulai dari client mengirim HTTP request ke controller, controller meneruskan ke service, service memproses data, lalu mengembalikan response terstruktur.

## Komponen & Nest CLI Command
Tidak ada CLI command untuk perencanaan. Ini adalah fase desain sebelum coding.

Endpoint yang direncanakan:

| Method | Endpoint | Deskripsi |
|--------|----------|-----------|
| GET | /products | Mendapatkan daftar produk (dengan pagination & filter) |
| GET | /products/:id | Mendapatkan satu produk berdasarkan ID |
| POST | /products | Membuat produk baru |
| PUT | /products/:id | Mengupdate seluruh data produk |
| PATCH | /products/:id | Mengupdate sebagian data produk |
| DELETE | /products/:id | Menghapus produk (soft delete) |

Struktur data Product:
- id: number (auto-increment)
- name: string
- description: string
- price: number
- stock: number
- isActive: boolean (untuk soft delete)
- createdAt: Date
- updatedAt: Date
