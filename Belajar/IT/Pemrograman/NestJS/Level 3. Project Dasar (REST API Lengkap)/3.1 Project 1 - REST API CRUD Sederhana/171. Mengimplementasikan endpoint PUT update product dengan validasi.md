# 171. Mengimplementasikan endpoint PUT update product dengan validasi

## Definisi & Target
Endpoint `PUT /products/:id` mengupdate seluruh data produk. Karena menggunakan PartialType, semua field bersifat opsional — client hanya perlu mengirim field yang ingin diubah. Validasi tetap berjalan untuk nilai yang dikirim.

## Komponen & Nest CLI Command
Tidak ada command baru. Modifikasi controller dan service.

## Kode Implementasi (Per File)
```typescript
// src/products/products.controller.ts
import { Controller, Put, Param, Body } from '@nestjs/common';
import { ProductsService } from './products.service';
import { UpdateProductDto } from './dto/update-product.dto';

@Controller('products')
export class ProductsController {
  constructor(private readonly productsService: ProductsService) {}

  @Put(':id')
  update(@Param('id') id: string, @Body() updateProductDto: UpdateProductDto) {
    return this.productsService.update(+id, updateProductDto);
  }
}
```

```typescript
// src/products/products.service.ts
import { Injectable, NotFoundException } from '@nestjs/common';
import { UpdateProductDto } from './dto/update-product.dto';

@Injectable()
export class ProductsService {
  private products = [];
  private nextId = 1;

  update(id: number, dto: UpdateProductDto) {
    const index = this.products.findIndex((p) => p.id === id && p.isActive);
    if (index === -1) {
      throw new NotFoundException(`Product with ID #${id} not found`);
    }
    this.products[index] = {
      ...this.products[index],
      ...dto,
      updatedAt: new Date(),
    };
    return { data: this.products[index], message: 'Product updated successfully' };
  }
}
```

## Cara Integrasi & Pengujian
```bash
# Update beberapa field
curl -X PUT http://localhost:3000/products/1 \
  -H "Content-Type: application/json" \
  -d '{"name":"Laptop Gaming","price":18000}'
# Response: 200 OK

# ID tidak ditemukan
curl -X PUT http://localhost:3000/products/999 \
  -H "Content-Type: application/json" \
  -d '{"name":"Test"}'
# Response: 404 Not Found

# Validasi gagal (price harus number)
curl -X PUT http://localhost:3000/products/1 \
  -H "Content-Type: application/json" \
  -d '{"price":"bukan angka"}'
# Response: 400 Bad Request
```
