# 167. Membuat UpdateProductDto menggunakan PartialType dari CreateProductDto

## Definisi & Target
UpdateProductDto digunakan untuk request body saat update produk. Dengan PartialType dari `@nestjs/mapped-types`, semua field CreateProductDto otomatis menjadi opsional, sehingga client bisa mengirim sebagian field saja.

## Komponen & Nest CLI Command
```bash
npm install @nestjs/mapped-types
```

File yang dibuat:
- `src/products/dto/update-product.dto.ts`

## Kode Implementasi (Per File)
```typescript
// src/products/dto/update-product.dto.ts
import { PartialType } from '@nestjs/mapped-types';
import { CreateProductDto } from './create-product.dto';

export class UpdateProductDto extends PartialType(CreateProductDto) {}
```

```typescript
// src/products/dto/create-product.dto.ts
import {
  IsString, IsNumber, IsOptional, Min, MaxLength,
} from 'class-validator';

export class CreateProductDto {
  @IsString()
  @MaxLength(100)
  name: string;

  @IsString()
  @IsOptional()
  description?: string;

  @IsNumber()
  @Min(0)
  price: number;

  @IsNumber()
  @Min(0)
  stock: number;
}
```

## Cara Integrasi & Pengujian
```bash
curl -X PUT http://localhost:3000/products/1 \
  -H "Content-Type: application/json" \
  -d '{"price": 17000}'

# Response: 200 OK, data produk diupdate dengan field yang dikirim saja
# Jika field tidak valid: 400 Bad Request

curl -X PATCH http://localhost:3000/products/1 \
  -H "Content-Type: application/json" \
  -d '{"stock": 20}'

# PATCH juga menggunakan UpdateProductDto yang sama
```
