# 166. Membuat CreateProductDto dengan validasi menggunakan class-validator

## Definisi & Target
CreateProductDto adalah Data Transfer Object yang mendefinisikan struktur data untuk request body saat membuat produk baru. class-validator menyediakan decorator untuk validasi otomatis.

## Komponen & Nest CLI Command
```bash
npm install class-validator class-transformer
nest g module products --no-spec  # jika belum ada
```

File yang dibuat:
- `src/products/dto/create-product.dto.ts`

File yang dimodifikasi:
- `src/main.ts` — memasang global ValidationPipe

## Kode Implementasi (Per File)
```typescript
// src/products/dto/create-product.dto.ts
import {
  IsString, IsNumber, IsOptional, Min, MaxLength,
} from 'class-validator';

export class CreateProductDto {
  @IsString()
  @MaxLength(100)
  name: string;

  @IsString()
  @IsOptional()
  description?: string;

  @IsNumber()
  @Min(0)
  price: number;

  @IsNumber()
  @Min(0)
  stock: number;
}
```

```typescript
// src/main.ts
import { NestFactory } from '@nestjs/core';
import { ValidationPipe } from '@nestjs/common';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.useGlobalPipes(new ValidationPipe({ whitelist: true, forbidNonWhitelisted: true }));
  await app.listen(3000);
}
bootstrap();
```

## Cara Integrasi & Pengujian
```bash
curl -X POST http://localhost:3000/products \
  -H "Content-Type: application/json" \
  -d '{"name":"Laptop","price":15000,"stock":10}'

# Response: { "data": { "id": 1, ... }, "message": "Product created successfully" }
# Jika name tidak diisi: 400 Bad Request dengan detail error validasi
```
