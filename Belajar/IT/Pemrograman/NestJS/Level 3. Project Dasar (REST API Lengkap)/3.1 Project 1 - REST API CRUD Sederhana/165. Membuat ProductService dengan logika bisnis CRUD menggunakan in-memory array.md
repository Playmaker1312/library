# 165. Membuat ProductService dengan logika bisnis CRUD menggunakan in-memory array

## Definisi & Target
ProductService berisi logika bisnis untuk operasi CRUD produk. Data disimpan sementara dalam array di memory untuk memudahkan pembelajaran sebelum terintegrasi dengan database.

## Komponen & Nest CLI Command
```bash
nest g service products --no-spec
```

File yang dimodifikasi:
- `src/products/products.service.ts`
- `src/products/products.module.ts`

## Kode Implementasi (Per File)
```typescript
// src/products/products.service.ts
import { Injectable, NotFoundException } from '@nestjs/common';
import { CreateProductDto } from './dto/create-product.dto';
import { UpdateProductDto } from './dto/update-product.dto';

export interface Product {
  id: number;
  name: string;
  description: string;
  price: number;
  stock: number;
  isActive: boolean;
  createdAt: Date;
  updatedAt: Date;
}

@Injectable()
export class ProductsService {
  private products: Product[] = [];
  private nextId = 1;

  findAll(query: { page?: number; limit?: number; search?: string }) {
    let filtered = this.products.filter((p) => p.isActive);
    if (query.search) {
      filtered = filtered.filter((p) =>
        p.name.toLowerCase().includes(query.search.toLowerCase()),
      );
    }
    const page = query.page || 1;
    const limit = query.limit || 10;
    const start = (page - 1) * limit;
    const items = filtered.slice(start, start + limit);
    return { data: items, total: filtered.length, page, limit };
  }

  findOne(id: number) {
    const product = this.products.find((p) => p.id === id && p.isActive);
    if (!product) throw new NotFoundException(`Product #${id} not found`);
    return { data: product };
  }

  create(dto: CreateProductDto) {
    const product: Product = {
      id: this.nextId++,
      ...dto,
      isActive: true,
      createdAt: new Date(),
      updatedAt: new Date(),
    };
    this.products.push(product);
    return { data: product, message: 'Product created successfully' };
  }

  update(id: number, dto: UpdateProductDto) {
    const index = this.products.findIndex((p) => p.id === id && p.isActive);
    if (index === -1) throw new NotFoundException(`Product #${id} not found`);
    this.products[index] = {
      ...this.products[index],
      ...dto,
      updatedAt: new Date(),
    };
    return { data: this.products[index], message: 'Product updated successfully' };
  }

  remove(id: number) {
    const index = this.products.findIndex((p) => p.id === id && p.isActive);
    if (index === -1) throw new NotFoundException(`Product #${id} not found`);
    this.products[index].isActive = false;
    return { message: 'Product deleted successfully' };
  }
}
```

## Cara Integrasi & Pengujian
Service sudah direturnturn oleh module. Uji endpoint `POST /products` dengan body JSON via curl atau Postman untuk mulai menambahkan data.
