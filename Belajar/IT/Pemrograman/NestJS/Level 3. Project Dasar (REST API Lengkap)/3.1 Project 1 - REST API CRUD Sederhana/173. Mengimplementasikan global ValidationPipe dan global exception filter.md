# 173. Mengimplementasikan global ValidationPipe dan global exception filter

## Definisi & Target
Global ValidationPipe diterapkan di seluruh aplikasi untuk memvalidasi semua request body secara otomatis. Global exception filter menangkap semua error yang tidak tertangani dan mengembalikan response yang konsisten.

## Komponen & Nest CLI Command
```bash
nest g filter common/filters/http-exception --no-spec
```

File yang dimodifikasi:
- `src/main.ts`
- File baru: `src/common/filters/http-exception.filter.ts`

## Kode Implementasi (Per File)
```typescript
// src/main.ts
import { NestFactory } from '@nestjs/core';
import { ValidationPipe } from '@nestjs/common';
import { AppModule } from './app.module';
import { HttpExceptionFilter } from './common/filters/http-exception.filter';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.useGlobalPipes(
    new ValidationPipe({
      whitelist: true,
      forbidNonWhitelisted: true,
      transform: true,
      transformOptions: { enableImplicitConversion: true },
    }),
  );
  app.useGlobalFilters(new HttpExceptionFilter());
  await app.listen(3000);
}
bootstrap();
```

```typescript
// src/common/filters/http-exception.filter.ts
import {
  ExceptionFilter, Catch, ArgumentsHost, HttpException, HttpStatus,
} from '@nestjs/common';
import { Response } from 'express';

@Catch()
export class HttpExceptionFilter implements ExceptionFilter {
  catch(exception: unknown, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();
    let status = HttpStatus.INTERNAL_SERVER_ERROR;
    let message = 'Internal server error';

    if (exception instanceof HttpException) {
      status = exception.getStatus();
      const res = exception.getResponse();
      message = typeof res === 'string' ? res : (res as any).message || message;
    }

    response.status(status).json({
      statusCode: status,
      message,
      timestamp: new Date().toISOString(),
    });
  }
}
```

## Cara Integrasi & Pengujian
```bash
# Validasi bekerja global — error akan formatnya konsisten
curl -X POST http://localhost:3000/products \
  -H "Content-Type: application/json" \
  -d '{}'
# Response: 400 Bad Request
# { "statusCode": 400, "message": ["name must be a string", ...], "timestamp": "..." }

# Error 404 dari service juga tertangkap filter
curl http://localhost:3000/products/999
# Response: 404
# { "statusCode": 404, "message": "Product with ID #999 not found", "timestamp": "..." }
```
