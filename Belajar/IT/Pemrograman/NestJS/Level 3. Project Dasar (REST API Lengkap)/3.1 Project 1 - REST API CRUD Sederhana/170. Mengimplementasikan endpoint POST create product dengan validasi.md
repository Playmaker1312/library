# 170. Mengimplementasikan endpoint POST create product dengan validasi

## Definisi & Target
Endpoint `POST /products` menerima data produk dari body request, memvalidasinya menggunakan CreateProductDto, lalu menyimpannya. Global ValidationPipe di main.ts menolak data yang tidak valid dengan response 400.

## Komponen & Nest CLI Command
Tidak ada command baru. Modifikasi di controller dan service.

## Kode Implementasi (Per File)
```typescript
// src/products/products.controller.ts
import { Controller, Post, Body } from '@nestjs/common';
import { ProductsService } from './products.service';
import { CreateProductDto } from './dto/create-product.dto';

@Controller('products')
export class ProductsController {
  constructor(private readonly productsService: ProductsService) {}

  @Post()
  create(@Body() createProductDto: CreateProductDto) {
    return this.productsService.create(createProductDto);
  }
}
```

```typescript
// src/products/products.service.ts
import { Injectable } from '@nestjs/common';
import { CreateProductDto } from './dto/create-product.dto';

export interface Product {
  id: number;
  name: string;
  description: string;
  price: number;
  stock: number;
  isActive: boolean;
  createdAt: Date;
  updatedAt: Date;
}

@Injectable()
export class ProductsService {
  private products: Product[] = [];
  private nextId = 1;

  create(dto: CreateProductDto) {
    const product: Product = {
      id: this.nextId++,
      ...dto,
      description: dto.description || '',
      isActive: true,
      createdAt: new Date(),
      updatedAt: new Date(),
    };
    this.products.push(product);
    return { data: product, message: 'Product created successfully' };
  }
}
```

## Cara Integrasi & Pengujian
```bash
# Sukses
curl -X POST http://localhost:3000/products \
  -H "Content-Type: application/json" \
  -d '{"name":"Laptop","price":15000,"stock":10}'
# Response: 201 Created

# Validasi gagal (name tidak diisi)
curl -X POST http://localhost:3000/products \
  -H "Content-Type: application/json" \
  -d '{"price":15000}'
# Response: 400 Bad Request
# { "message": ["name must be a string"], "error": "Bad Request", "statusCode": 400 }

# Field tidak dikenal (forbidNonWhitelisted)
curl -X POST http://localhost:3000/products \
  -H "Content-Type: application/json" \
  -d '{"name":"Test","price":100,"stock":5,"extraField":"x"}'
# Response: 400 Bad Request
```
