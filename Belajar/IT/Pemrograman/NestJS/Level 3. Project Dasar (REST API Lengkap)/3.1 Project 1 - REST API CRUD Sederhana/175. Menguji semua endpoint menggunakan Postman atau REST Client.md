# 175. Menguji semua endpoint menggunakan Postman atau REST Client

## Definisi & Target
Menguji keenam endpoint CRUD Product menggunakan Postman atau ekstensi REST Client (VS Code). Tujuannya memastikan semua fitur berjalan sesuai harapan: pagination, filter, validasi, error handling, soft delete, dan response wrapper.

## Komponen & Nest CLI Command
Tidak ada command. Gunakan tools testing.

## Kode Implementasi (Per File)
File REST Client (.http):

```http
### Create Product
POST http://localhost:3000/products
Content-Type: application/json

{
  "name": "Laptop ASUS ROG",
  "description": "Gaming laptop high-end",
  "price": 25000000,
  "stock": 5
}

### Create Product 2
POST http://localhost:3000/products
Content-Type: application/json

{
  "name": "Mouse Logitech",
  "description": "Wireless mouse",
  "price": 450000,
  "stock": 20
}

### Get All Products
GET http://localhost:3000/products

### Get Products with Pagination
GET http://localhost:3000/products?page=1&limit=2

### Get Products with Search
GET http://localhost:3000/products?search=laptop

### Get Product by ID
GET http://localhost:3000/products/1

### Get Product Not Found
GET http://localhost:3000/products/999

### Update Product (PUT)
PUT http://localhost:3000/products/1
Content-Type: application/json

{
  "price": 26000000,
  "stock": 3
}

### Partial Update (PATCH)
PATCH http://localhost:3000/products/2
Content-Type: application/json

{
  "stock": 15
}

### Delete Product (Soft Delete)
DELETE http://localhost:3000/products/1

### Get Deleted Product (should 404)
GET http://localhost:3000/products/1

### Validation Error
POST http://localhost:3000/products
Content-Type: application/json

{
  "price": "not-a-number"
}
```

## Cara Integrasi & Pengujian
1. Jalankan server: `npm run start:dev`
2. Buka Postman atau instal REST Client di VS Code
3. Buat file `test-products.http` dan jalankan semua request
4. Verifikasi response:
   - POST 201 → `{ "success": true, "data": { ... }, "message": "Product created successfully" }`
   - GET 200 → `{ "success": true, "data": [...], "meta": { ... } }`
   - GET by ID 200 → `{ "success": true, "data": { ... } }`
   - PUT/PATCH 200 → `{ "success": true, "data": { ... } }`
   - DELETE 200 → `{ "success": true, "data": { "message": "Product deleted successfully" } }`
   - Not Found 404 → `{ "statusCode": 404, "message": "..." }`
   - Validation Error 400 → `{ "statusCode": 400, "message": [...] }`
