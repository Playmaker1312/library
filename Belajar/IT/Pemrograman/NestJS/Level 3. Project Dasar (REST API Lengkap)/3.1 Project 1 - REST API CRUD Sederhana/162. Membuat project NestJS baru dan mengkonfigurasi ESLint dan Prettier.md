# 162. Membuat project NestJS baru dan mengkonfigurasi ESLint dan Prettier

## Definisi & Target
Membuat project NestJS dari awal menggunakan CLI dan mengkonfigurasi ESLint serta Prettier untuk menjaga konsistensi kode. Target akhir adalah project siap pakai dengan code style yang terstandarisasi.

## Komponen & Nest CLI Command
```bash
npm i -g @nestjs/cli
nest new product-api --package-manager npm
cd product-api
```

File konfigurasi yang dihasilkan:
- `.eslintrc.js` — aturan ESLint
- `.prettierrc` — aturan Prettier
- `tsconfig.json` — konfigurasi TypeScript
- `nest-cli.json` — konfigurasi NestJS CLI

## Kode Implementasi (Per File)
```json
// .prettierrc
{
  "singleQuote": true,
  "trailingComma": "all",
  "tabWidth": 2,
  "semi": true,
  "printWidth": 100
}
```

```js
// .eslintrc.js
module.exports = {
  parser: '@typescript-eslint/parser',
  parserOptions: {
    project: 'tsconfig.json',
    tsconfigRootDir: __dirname,
    sourceType: 'module',
  },
  plugins: ['@typescript-eslint/eslint-plugin'],
  extends: [
    'plugin:@typescript-eslint/recommended',
    'plugin:prettier/recommended',
  ],
  root: true,
  env: { node: true, jest: true },
  ignorePatterns: ['.eslintrc.js'],
  rules: {
    '@typescript-eslint/no-unused-vars': 'error',
    '@typescript-eslint/explicit-function-return-type': 'off',
  },
};
```

## Cara Integrasi & Pengujian
```bash
npm run lint        # Mengecek kode dengan ESLint
npm run format      # Memformat kode dengan Prettier
npm run start:dev   # Menjalankan server di http://localhost:3000
```

Server berjalan dan merespon `Hello World!` di endpoint `GET /`.
