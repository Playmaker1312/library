# 191. Memahami keunggulan Prisma dibanding TypeORM dalam konteks NestJS

## Definisi & Target
Prisma adalah ORM generasi baru yang menggunakan schema-based approach. Tidak seperti TypeORM yang dekoratif, Prisma menghasilkan type-safe client dari file schema. Ini memberikan developer experience yang lebih baik.

Perbandingan TypeORM vs Prisma:

| Aspek | TypeORM | Prisma |
|-------|---------|--------|
| Definisi | Decorator di entity class | File `schema.prisma` terpisah |
| Type Safety | Partial | Full type-safe (auto-generated) |
| Migration | Berbasis class | Berbasis file SQL |
| Query Builder | `.createQueryBuilder()` | Prisma Client API |
| Learning Curve | Lebih curam (banyak decorator) | Lebih landai |
| Performance | Middle ground | Cepat (optimized queries) |
| Relations | Decorator `@ManyToOne` dll | `relation` di schema |

Keunggulan Prisma:
- Type safety penuh — autocomplete untuk semua query
- Schema sebagai single source of truth
- Prisma Studio — GUI database visual
- Migration yang jelas dan mudah
- Relasi di-handle dengan elegan (include, select, nested write)
