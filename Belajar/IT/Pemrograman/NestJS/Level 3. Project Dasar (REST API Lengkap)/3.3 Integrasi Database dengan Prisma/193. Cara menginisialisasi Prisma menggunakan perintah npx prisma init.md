# 193. Cara menginisialisasi Prisma menggunakan perintah npx prisma init

## Definisi & Target
`npx prisma init` membuat file `prisma/schema.prisma` dan file `.env` dengan konfigurasi database URL. Ini adalah langkah awal untuk menggunakan Prisma di project NestJS.

## Komponen & Nest CLI Command
```bash
# Inisialisasi Prisma di project NestJS
npx prisma init

# Untuk menggunakan database tertentu:
npx prisma init --datasource-provider postgresql
npx prisma init --datasource-provider mysql
npx prisma init --datasource-provider sqlite
```

File yang dibuat:
- `prisma/schema.prisma`
- `.env`

## Kode Implementasi (Per File)
```prisma
// prisma/schema.prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```

```env
# .env
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/product_db?schema=public"
```

Contoh untuk SQLite (development):
```env
DATABASE_URL="file:./dev.db"
```

```prisma
// prisma/schema.prisma (untuk SQLite)
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "sqlite"
  url      = env("DATABASE_URL")
}
```

## Cara Integrasi & Pengujian
```bash
# Setelah npx prisma init, struktur folder:
# prisma/
#   └── schema.prisma
# .env

# Edit .env sesuai konfigurasi database Anda
# Edit schema.prisma untuk menambahkan model (poin 194-195)
```
