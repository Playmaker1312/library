# 205. Cara menggunakan Prisma Studio untuk manajemen data secara visual

## Definisi & Target
Prisma Studio adalah GUI visual untuk melihat dan memanipulasi data database. Ini alternatif modern untuk phpMyAdmin atau DBeaver, terintegrasi langsung dengan schema Prisma.

## Komponen & Nest CLI Command
```bash
# Jalankan Prisma Studio
npx prisma studio

# Atau dengan port khusus
npx prisma studio --port 5555

# Atau dengan browser non-default
npx prisma studio --browser none
```

## Kode Implementasi (Per File)
Tidak ada implementasi kode — ini penggunaan tool visual.

Fitur Prisma Studio:
- **Browse data** — lihat semua record per model/tabel
- **Filter & sort** — filter data langsung di UI
- **Add record** — tambah data baru dengan form
- **Edit inline** — edit value langsung di cell
- **Delete** — hapus record dengan konfirmasi
- **Relation navigation** — klik relasi untuk lihat data terkait
- **Search** — cari data di seluruh field
- **Dark mode** — tampilan gelap

## Cara Integrasi & Pengujian
```bash
# 1. Jalankan di terminal terpisah
npx prisma studio

# 2. Browser terbuka ke http://localhost:5555
# 3. Lihat model Product, filter, edit, atau tambah data
# 4. Setiap perubahan langsung tersimpan di database

# Catatan:
# - Jangan tutup terminal saat menggunakan Studio
# - Studio membaca data dari database, bukan dari Prisma Client
# - Perubahan di Studio langsung tercermin di API
# - Gunakan untuk debugging data selama development
```
