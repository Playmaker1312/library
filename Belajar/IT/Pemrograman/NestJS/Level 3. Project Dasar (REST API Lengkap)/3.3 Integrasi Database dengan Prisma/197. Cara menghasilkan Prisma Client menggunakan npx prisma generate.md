# 197. Cara menghasilkan Prisma Client menggunakan npx prisma generate

## Definisi & Target
`npx prisma generate` membaca file `schema.prisma` dan menghasilkan Prisma Client (`@prisma/client`) dengan type definitions yang sesuai. Client ini kemudian digunakan di service NestJS untuk query database.

## Komponen & Nest CLI Command
```bash
# Generate Prisma Client setelah mengubah schema
npx prisma generate

# Generate untuk development (watch mode)
npx prisma generate --watch
```

File yang dihasilkan:
- `node_modules/.prisma/client/index.js`
- `node_modules/.prisma/client/index.d.ts` — type definitions

## Kode Implementasi (Per File)
```prisma
// prisma/schema.prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

model Product {
  id        Int      @id @default(autoincrement())
  name      String
  price     Float
  stock     Int      @default(0)
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  @@map("products")
}
```

Cek type yang dihasilkan:
```typescript
// Type yang dihasilkan oleh Prisma Client (auto-generated)
// Cara akses di VS Code CTRL+Click pada import
import { PrismaClient, Product } from '@prisma/client';

// Prisma akan menghasilkan:
// - Product type (interface)
// - PrismaClient dengan method:
//   prisma.product.findMany()
//   prisma.product.findUnique()
//   prisma.product.create()
//   prisma.product.update()
//   prisma.product.delete()
```

## Cara Integrasi & Pengujian
```bash
# Generate setelah mengubah schema
npx prisma generate
# Output: ✔ Generated Prisma Client (v5.x.x) to .\node_modules\.prisma\client

# Jika ada error, perbaiki schema.prisma dan generate ulang
# Setiap kali schema berubah, generate ulang untuk update type definitions
```
