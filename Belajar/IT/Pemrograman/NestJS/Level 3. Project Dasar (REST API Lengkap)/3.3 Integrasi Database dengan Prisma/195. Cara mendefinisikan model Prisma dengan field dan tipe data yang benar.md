# 195. Cara mendefinisikan model Prisma dengan field dan tipe data yang benar

## Definisi & Target
Model Prisma mewakili tabel database. Setiap field memiliki tipe data dan atribut opsional seperti default value, unique constraint, atau relasi.

## Komponen & Nest CLI Command
Tidak ada CLI command. Edit `prisma/schema.prisma` manual.

## Kode Implementasi (Per File)
```prisma
// prisma/schema.prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

enum ProductStatus {
  ACTIVE
  INACTIVE
  DRAFT
}

model Product {
  id          Int           @id @default(autoincrement())
  name        String        @db.VarChar(100)
  slug        String        @unique @db.VarChar(150)
  description String?       @db.Text
  price       Decimal       @db.Decimal(10, 2)
  stock       Int           @default(0)
  status      ProductStatus @default(ACTIVE)
  isFeatured  Boolean       @default(false)
  tags        String[]      // array of strings
  metadata    Json?         // JSON object
  rating      Float?        @default(0)
  createdAt   DateTime      @default(now())
  updatedAt   DateTime      @updatedAt
  deletedAt   DateTime?

  @@index([status, isFeatured])
  @@map("products")
}
```

Tipe data Prisma yang umum:

| Tipe Prisma | Database | Keterangan |
|-------------|----------|------------|
| `String` | VARCHAR/TEXT | Panjang default 255 |
| `String @db.VarChar(100)` | VARCHAR(100) | String dengan panjang tertentu |
| `Int` | INTEGER | Angka bulat 32-bit |
| `Float` | REAL/FLOAT | Angka desimal |
| `Decimal` | DECIMAL/NUMERIC | Presisi tinggi |
| `Boolean` | BOOLEAN | true/false |
| `DateTime` | TIMESTAMP | Tanggal dan waktu |
| `Json` | JSON/JSONB | Objek JSON (PostgreSQL) |
| `String[]` | TEXT[] | Array (PostgreSQL) |

## Cara Integrasi & Pengujian
```bash
# Setelah mendefinisikan model, jalankan:
npx prisma migrate dev --name add_full_product_model
# Prisma akan membuat tabel dengan semua kolom yang didefinisikan
```
