# 198. Cara membuat PrismaService yang memperluas PrismaClient

## Definisi & Target
PrismaService adalah service NestJS yang membungkus PrismaClient. Dengan membuat class yang extends PrismaClient, kita bisa menginjeksikannya ke seluruh module NestJS melalui dependency injection.

## Komponen & Nest CLI Command
```bash
nest g service prisma/prisma --no-spec --flat
```

File yang dibuat:
- `src/prisma/prisma.service.ts`
- `src/prisma/prisma.module.ts`

## Kode Implementasi (Per File)
```typescript
// src/prisma/prisma.service.ts
import { Injectable, OnModuleInit, OnModuleDestroy } from '@nestjs/common';
import { PrismaClient } from '@prisma/client';

@Injectable()
export class PrismaService extends PrismaClient implements OnModuleInit, OnModuleDestroy {
  async onModuleInit() {
    await this.$connect();
  }

  async onModuleDestroy() {
    await this.$disconnect();
  }
}
```

```typescript
// src/prisma/prisma.module.ts
import { Global, Module } from '@nestjs/common';
import { PrismaService } from './prisma.service';

@Global()
@Module({
  providers: [PrismaService],
  exports: [PrismaService],
})
export class PrismaModule {}
```

```typescript
// src/app.module.ts
import { Module } from '@nestjs/common';
import { PrismaModule } from './prisma/prisma.module';
import { ProductsModule } from './products/products.module';

@Module({
  imports: [PrismaModule, ProductsModule],
})
export class AppModule {}
```

## Cara Integrasi & Pengujian
```bash
# Pastikan PrismaModule diimport di AppModule
# Setelah server start, PrismaService otomatis connect ke database
npm run start:dev
# Output: [Nest] App started...
# Jika koneksi gagal, cek DATABASE_URL di .env
```
