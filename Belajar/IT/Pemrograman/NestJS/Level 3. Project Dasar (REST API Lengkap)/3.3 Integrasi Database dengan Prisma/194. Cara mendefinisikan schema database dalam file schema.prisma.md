# 194. Cara mendefinisikan schema database dalam file schema.prisma

## Definisi & Target
File `schema.prisma` adalah pusat konfigurasi database Prisma. Di sini kita mendefinisikan datasource (koneksi database), generator (Prisma Client), dan semua model (tabel).

## Komponen & Nest CLI Command
```bash
# Setelah inisialisasi, edit prisma/schema.prisma secara manual
# Tidak ada CLI untuk menambah model — lakukan manual
```

File yang dimodifikasi:
- `prisma/schema.prisma`

## Kode Implementasi (Per File)
```prisma
// prisma/schema.prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

model Product {
  id          Int      @id @default(autoincrement())
  name        String   @db.VarChar(100)
  description String?
  price       Float
  stock       Int      @default(0)
  isActive    Boolean  @default(true)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  deletedAt   DateTime?

  @@map("products")
}
```

Penjelasan bagian schema:
- `datasource` — konfigurasi koneksi database
- `generator` — menentukan Prisma Client sebagai generator
- `model` — definisi tabel dengan field dan tipe
- `@id` — primary key
- `@default(autoincrement())` — auto-increment
- `@db.VarChar(100)` — tipe database spesifik
- `?` — nullable field
- `@@map("products")` — nama tabel di database

## Cara Integrasi & Pengujian
```bash
# Setelah mendefinisikan model, generate Prisma Client
npx prisma generate

# Jalankan migration
npx prisma migrate dev --name init
```
