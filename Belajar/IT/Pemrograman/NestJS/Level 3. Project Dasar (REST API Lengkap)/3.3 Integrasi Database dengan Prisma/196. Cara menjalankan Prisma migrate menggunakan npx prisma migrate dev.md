# 196. Cara menjalankan Prisma migrate menggunakan npx prisma migrate dev

## Definisi & Target
`prisma migrate dev` membuat migration SQL dari perubahan schema, menerapkannya ke database, dan menghasilkan Prisma Client yang diperbarui. Ini adalah pengganti `synchronize: true` dari TypeORM.

## Komponen & Nest CLI Command
```bash
# Migration development (membuat + menjalankan)
npx prisma migrate dev --name init

# Migration dengan nama spesifik
npx prisma migrate dev --name add_category_model

# Reset database (hapus semua data + migration)
npx prisma migrate reset

# Cek status migration
npx prisma migrate status
```

Struktur folder setelah migration:
```
prisma/
├── schema.prisma
├── migrations/
│   ├── 20240101000000_init/
│   │   ├── migration.sql
│   │   └── README.md
│   └── 20240102000000_add_category_model/
│       └── migration.sql
```

## Kode Implementasi (Per File)
Contoh migration file yang dihasilkan:
```sql
-- prisma/migrations/20240101000000_init/migration.sql
-- CreateTable
CREATE TABLE "products" (
    "id" SERIAL NOT NULL,
    "name" VARCHAR(100) NOT NULL,
    "description" TEXT,
    "price" DECIMAL(10,2) NOT NULL,
    "stock" INTEGER NOT NULL DEFAULT 0,
    "isActive" BOOLEAN NOT NULL DEFAULT true,
    "createdAt" TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,
    "updatedAt" TIMESTAMP(3) NOT NULL,
    "deletedAt" TIMESTAMP(3),

    CONSTRAINT "products_pkey" PRIMARY KEY ("id")
);
```

## Cara Integrasi & Pengujian
```bash
# 1. Edit prisma/schema.prisma
# 2. Jalankan migration
npx prisma migrate dev --name initial_products

# 3. Cek database — tabel products sudah ada
# 4. Untuk melihat SQL migration:
cat prisma/migrations/*/migration.sql

# 5. Jika ada error, rollback:
npx prisma migrate reset
```
