# 192. Cara menginstal Prisma dan Prisma Client dalam project NestJS

## Definisi & Target
Menginstal Prisma CLI sebagai dev dependency dan Prisma Client sebagai runtime dependency. Prisma Client adalah auto-generated type-safe query builder yang digunakan di service NestJS.

## Komponen & Nest CLI Command
```bash
# Instal Prisma CLI sebagai dev dependency
npm install prisma --save-dev

# Instal Prisma Client sebagai runtime dependency
npm install @prisma/client

# Inisialisasi Prisma (membuat folder prisma/ dan file schema.prisma)
npx prisma init
```

Struktur folder setelah instalasi:
```
project-root/
├── prisma/
│   └── schema.prisma    # Schema database
├── src/
│   └── prisma/
│       └── prisma.service.ts  # Service wrapper (akan dibuat)
├── package.json
└── .env                 # Database URL
```

Verifikasi package.json:
```json
{
  "dependencies": {
    "@prisma/client": "^5.0.0"
  },
  "devDependencies": {
    "prisma": "^5.0.0"
  }
}
```

## Kode Implementasi (Per File)
Tidak ada implementasi kode — hanya instalasi package.

## Cara Integrasi & Pengujian
```bash
# Cek instalasi
npx prisma --version

# Output menunjukkan versi Prisma CLI, Prisma Client, dan engine
# Jika berhasil, lanjut ke inisialisasi (poin 193)
```
