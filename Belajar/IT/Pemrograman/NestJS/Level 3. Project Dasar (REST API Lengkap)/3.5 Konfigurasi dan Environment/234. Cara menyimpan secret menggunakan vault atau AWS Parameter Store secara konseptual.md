# 234. Cara menyimpan secret menggunakan vault atau AWS Parameter Store secara konseptual

## Definisi & Target
Secret management menyimpan kredensial sensitif (DB password, API key, JWT secret) di tempat aman terpisah dari kode. Pendekatan umum: HashiCorp Vault, AWS Secrets Manager, atau AWS Parameter Store.

## Komponen & Nest CLI Command
Tidak ada CLI command — ini konseptual.

## Kode Implementasi (Per File)

Best practices secret management:
1. **Never commit .env.production** ke git (tambahkan ke .gitignore)
2. **Gunakan vault/cloud secret manager** untuk production
3. **Set secret via environment variable sistem** di container/CI/CD
4. **Rotasi secret secara berkala** (password, JWT secret)
5. **Akses control** — hanya service tertentu yang bisa read secret

## Cara Integrasi & Pengujian
Untuk development, simpan .env lokal. Untuk production, gunakan vault/cloud dan inject secret sebagai environment variable sistem sebelum menjalankan aplikasi.
