# 233. Cara mengkonfigurasi environment berbeda yaitu development, staging, dan production

## Definisi & Target
Setiap environment (development, staging, production) memiliki kebutuhan konfigurasi berbeda. NestJS menggunakan variabel `NODE_ENV` dan file `.env` terpisah untuk mengelola perbedaan ini.

## Komponen & Nest CLI Command
Tidak ada CLI command.

## Kode Implementasi (Per File)
```env
# .env.development
PORT=3000
NODE_ENV=development
DB_HOST=localhost
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=postgres
DB_DATABASE=blog_dev
LOG_LEVEL=debug
CORS_ORIGINS=*
```

```env
# .env.staging
PORT=3000
NODE_ENV=staging
DB_HOST=staging-db.internal
DB_PORT=5432
DB_USERNAME=blog_app
DB_PASSWORD=${STAGING_DB_PASSWORD}
DB_DATABASE=blog_staging
LOG_LEVEL=info
CORS_ORIGINS=https://staging.example.com
```

```env
# .env.production
PORT=8080
NODE_ENV=production
DB_HOST=${DB_HOST}
DB_PORT=${DB_PORT}
DB_USERNAME=${DB_USERNAME}
DB_PASSWORD=${DB_PASSWORD}
DB_DATABASE=${DB_DATABASE}
LOG_LEVEL=warn
CORS_ORIGINS=https://example.com,https://www.example.com
```

```typescript
// src/app.module.ts
import { Module } from '@nestjs/common';
import { ConfigModule } from '@nestjs/config';

const envFile = `.env.${process.env.NODE_ENV || 'development'}`;

@Module({
  imports: [
    ConfigModule.forRoot({
      isGlobal: true,
      envFilePath: [envFile, '.env'],
    }),
  ],
})
export class AppModule {}
```

```json
// package.json - scripts per environment
{
  "scripts": {
    "start:dev": "NODE_ENV=development nest start --watch",
    "start:staging": "NODE_ENV=staging node dist/main",
    "start:prod": "NODE_ENV=production node dist/main",
    "build": "nest build"
  }
}
```

```typescript
// src/main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { Logger } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  const logger = new Logger('Bootstrap');

  const port = process.env.PORT || 3000;
  const nodeEnv = process.env.NODE_ENV || 'development';

  app.enableCors({
    origin: process.env.CORS_ORIGINS?.split(',') || '*',
  });

  await app.listen(port);
  logger.log(`App running on port ${port} in ${nodeEnv} mode`);
}
bootstrap();
```

## Cara Integrasi & Pengujian
```bash
# Development
npm run start:dev   # Membaca .env.development, log level: debug

# Staging
NODE_ENV=staging node dist/main  # Membaca .env.staging, DB: staging

# Production
npm run start:prod  # Membaca .env.production, log level: warn
```
