# 221. Cara menginstal dan menggunakan ConfigModule dari NestJS

## Definisi & Target
ConfigModule dari `@nestjs/config` mengelola konfigurasi aplikasi melalui environment variables. Ini membaca file `.env` dan menyediakan `ConfigService` untuk mengakses nilai konfigurasi secara terpusat.

## Komponen & Nest CLI Command
```bash
npm install @nestjs/config
```

File yang dimodifikasi:
- `src/app.module.ts`
- File baru: `.env`

## Kode Implementasi (Per File)
```typescript
// src/app.module.ts
import { Module } from '@nestjs/common';
import { ConfigModule } from '@nestjs/config';

@Module({
  imports: [
    ConfigModule.forRoot({
      isGlobal: true,
      envFilePath: '.env',
    }),
  ],
})
export class AppModule {}
```

```env
# .env
PORT=3000
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/blog_db"
JWT_SECRET="my-super-secret-key"
NODE_ENV=development
```

```typescript
// src/app.controller.ts
import { Controller, Get } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';

@Controller()
export class AppController {
  constructor(private configService: ConfigService) {}

  @Get('config-check')
  checkConfig() {
    return {
      port: this.configService.get<number>('PORT'),
      environment: this.configService.get<string>('NODE_ENV'),
      dbHost: this.configService.get<string>('DATABASE_URL'),
    };
  }
}
```

## Cara Integrasi & Pengujian
```bash
# Setelah ConfigModule terinstal, ConfigService bisa di-inject di mana saja
npm run start:dev

curl http://localhost:3000/config-check
# Response: { "port": 3000, "environment": "development", "dbHost": "postgresql://..." }
```
