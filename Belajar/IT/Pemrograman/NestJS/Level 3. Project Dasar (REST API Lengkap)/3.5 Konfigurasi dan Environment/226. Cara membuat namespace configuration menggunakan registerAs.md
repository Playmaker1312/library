# 226. Cara membuat namespace configuration menggunakan registerAs

## Definisi & Target
`registerAs` membuat namespace configuration terpisah untuk area tertentu (database, jwt, redis). Ini mengorganisir konfigurasi menjadi bagian-bagian yang terstruktur dan type-safe.

## Komponen & Nest CLI Command
Tidak ada CLI command.

## Kode Implementasi (Per File)
```typescript
// src/config/database.config.ts
import { registerAs } from '@nestjs/config';

export default registerAs('database', () => ({
  host: process.env.DB_HOST || 'localhost',
  port: parseInt(process.env.DB_PORT || '5432', 10),
  username: process.env.DB_USERNAME,
  password: process.env.DB_PASSWORD,
  database: process.env.DB_DATABASE,
  synchronize: process.env.NODE_ENV !== 'production',
}));
```

```typescript
// src/config/jwt.config.ts
import { registerAs } from '@nestjs/config';

export default registerAs('jwt', () => ({
  secret: process.env.JWT_SECRET,
  expiration: process.env.JWT_EXPIRATION || '7d',
  issuer: process.env.JWT_ISSUER || 'blog-api',
}));
```

```typescript
// src/config/redis.config.ts
import { registerAs } from '@nestjs/config';

export default registerAs('redis', () => ({
  host: process.env.REDIS_HOST || 'localhost',
  port: parseInt(process.env.REDIS_PORT || '6379', 10),
}));
```

```typescript
// src/app.module.ts
import { Module } from '@nestjs/common';
import { ConfigModule } from '@nestjs/config';
import databaseConfig from './config/database.config';
import jwtConfig from './config/jwt.config';
import redisConfig from './config/redis.config';

@Module({
  imports: [
    ConfigModule.forRoot({
      isGlobal: true,
      load: [databaseConfig, jwtConfig, redisConfig],
    }),
  ],
})
export class AppModule {}
```

## Cara Integrasi & Pengujian
```typescript
// src/products/products.service.ts
import { Injectable } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class ProductsService {
  constructor(private configService: ConfigService) {
    // Akses namespace configuration
    const dbHost = this.configService.get<string>('database.host');
    const jwtSecret = this.configService.get<string>('jwt.secret');
    console.log(`Connected to DB at ${dbHost}`);
  }
}
```

## Cara Integrasi & Pengujian
```bash
# Namespace configuration bisa diakses via dot notation
# configService.get('database.host') -> 'localhost'
# configService.get('jwt.secret') -> dari .env JWT_SECRET
```
