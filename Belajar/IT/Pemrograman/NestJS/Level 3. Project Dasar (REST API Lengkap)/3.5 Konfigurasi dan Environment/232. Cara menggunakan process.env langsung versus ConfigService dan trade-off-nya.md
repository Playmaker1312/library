# 232. Cara menggunakan process.env langsung versus ConfigService dan trade-off-nya

## Definisi & Target
Membandingkan penggunaan `process.env` langsung dengan ConfigService. Masing-masing punya kelebihan dan kekurangan tergantung konteks penggunaannya.

## Komponen & Nest CLI Command
Tidak ada CLI command.

## Kode Implementasi (Per File)
```typescript
// Pendekatan 1: process.env langsung (tidak direkomendasikan)
// Kelebihan: sederhana, tanpa dependency
// Kekurangan: tidak type-safe, susah di-test, tidak ada default value
export class DatabaseServiceRaw {
  private host = process.env.DB_HOST;
  private port = parseInt(process.env.DB_PORT, 10);
}

// Pendekatan 2: ConfigService (direkomendasikan)
// Kelebihan: type-safe, testable via ConfigModule, default value, validasi Joi
// Kekurangan: harus inject ConfigService, boilerplate kecil
import { Injectable } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class DatabaseService {
  constructor(private configService: ConfigService) {
    const host = this.configService.get<string>('DB_HOST', 'localhost');
    const port = this.configService.get<number>('DB_PORT', 5432);
  }
}
```

```typescript
// Pendekatan hybrid — process.env untuk nilai static di top-level, ConfigService untuk inject
// prisma/schema.prisma tetap menggunakan process.env
// datasource db {
//   provider = "postgresql"
//   url      = env("DATABASE_URL")
// }

// src/main.ts — process.env OK untuk bootstrap cepat
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  await app.listen(process.env.PORT || 3000);
}
bootstrap();
```

| Aspek | process.env | ConfigService |
|-------|-------------|---------------|
| Type safety | Tidak | Ya (dengan interface) |
| Default value | Manual `\|\|` | Parameter `.get()` |
| Testing | Susah (mock env) | Mudah (ConfigModule) |
| Validasi | Manual | Joi integration |
| NestJS integration | Tidak | Ya (DI, module) |
| Performance | Langsung | Cache |

## Cara Integrasi & Pengujian
```bash
# Gunakan ConfigService untuk service/business logic
# Gunakan process.env hanya untuk:
# - main.ts (bootstrap, port)
# - schema.prisma (DATABASE_URL)
# - Library yang tidak terintegrasi dengan NestJS DI
```
