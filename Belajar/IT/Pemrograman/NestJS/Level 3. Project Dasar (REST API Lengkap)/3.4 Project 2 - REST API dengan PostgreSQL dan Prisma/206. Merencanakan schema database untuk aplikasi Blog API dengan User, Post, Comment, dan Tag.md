# 206. Merencanakan schema database untuk aplikasi Blog API

## Definisi & Target
Blog API memiliki empat entitas utama: User (penulis), Post (artikel), Comment (komentar), dan Tag (kategori/label). Setiap entitas memiliki relasi: User memiliki banyak Post, Post memiliki banyak Comment, dan Post memiliki banyak Tag (many-to-many).

## Komponen & Nest CLI Command
```bash
nest new blog-api --package-manager npm
cd blog-api
npm install prisma @prisma/client
npx prisma init --datasource-provider postgresql
```

Relasi yang direncanakan:
- **User 1→* Post**: Satu user bisa menulis banyak post
- **Post 1→* Comment**: Satu post bisa memiliki banyak komentar
- **Post *↔* Tag**: Banyak post bisa memiliki banyak tag (melalui tabel pivot)
- **User 1→* Comment**: Satu user bisa menulis banyak komentar

Endpoint yang direncanakan:

| Method | Endpoint | Deskripsi |
|--------|----------|-----------|
| GET | /users | Daftar user |
| GET | /users/:id | Detail user dengan posts |
| POST | /users | Buat user baru |
| GET | /posts | Daftar post (pagination, filter) |
| GET | /posts/:id | Detail post dengan comments & tags |
| POST | /posts | Buat post baru |
| PUT | /posts/:id | Update post |
| DELETE | /posts/:id | Soft delete post |
| GET | /posts/:postId/comments | Komentar dari post |
| POST | /posts/:postId/comments | Tambah komentar |
| GET | /tags | Daftar tag |
| POST | /tags | Buat tag baru |
