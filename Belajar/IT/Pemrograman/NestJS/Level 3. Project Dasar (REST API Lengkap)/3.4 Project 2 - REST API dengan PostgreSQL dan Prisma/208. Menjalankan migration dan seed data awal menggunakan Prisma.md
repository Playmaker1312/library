# 208. Menjalankan migration dan seed data awal menggunakan Prisma

## Definisi & Target
Migration membuat tabel di database sesuai schema. Seed data mengisi tabel dengan data awal untuk development/testing. Prisma mendukung seeding melalui file TypeScript/JavaScript.

## Komponen & Nest CLI Command
```bash
# Migration
npx prisma migrate dev --name init

# Setup seed
npm install ts-node --save-dev
npm install @types/node --save-dev
```

File yang dibuat:
- `prisma/seed.ts`
- Update `package.json` dengan `prisma.seed`

## Kode Implementasi (Per File)
```typescript
// prisma/seed.ts
import { PrismaClient, PostStatus } from '@prisma/client';

const prisma = new PrismaClient();

async function main() {
  const user = await prisma.user.create({
    data: {
      email: 'admin@blog.com',
      name: 'Admin',
      password: '$2b$10$hashedpassword',
      bio: 'Blog administrator',
    },
  });

  const tag1 = await prisma.tag.create({ data: { name: 'Technology' } });
  const tag2 = await prisma.tag.create({ data: { name: 'Programming' } });

  const post = await prisma.post.create({
    data: {
      title: 'Getting Started with NestJS',
      slug: 'getting-started-with-nestjs',
      content: 'NestJS is a progressive Node.js framework...',
      status: PostStatus.PUBLISHED,
      authorId: user.id,
      tags: {
        create: [
          { tagId: tag1.id },
          { tagId: tag2.id },
        ],
      },
    },
  });

  await prisma.comment.create({
    data: {
      content: 'Great article! Very helpful.',
      postId: post.id,
      authorId: user.id,
    },
  });

  console.log('Seed completed');
}

main()
  .catch((e) => { console.error(e); process.exit(1); })
  .finally(async () => await prisma.$disconnect());
```

```json
// package.json (tambahkan)
{
  "prisma": {
    "seed": "ts-node prisma/seed.ts"
  }
}
```

## Cara Integrasi & Pengujian
```bash
# 1. Jalankan migration
npx prisma migrate dev --name init

# 2. Jalankan seed
npx prisma db seed

# 3. Cek data di Prisma Studio
npx prisma studio
# Data user, tag, post, dan comment sudah terisi
```
