# 190. Cara menggunakan TypeORM subscriber untuk event-driven database operations

## Definisi & Target
Subscriber mendengarkan event database seperti `beforeInsert`, `afterUpdate`, `beforeRemove` pada entity tertentu. Berguna untuk logging, validasi otomatis, atau mengisi field komputasi.

## Komponen & Nest CLI Command
```bash
nest g provider common/subscribers/product-subscriber --no-spec
```

File yang dibuat:
- `src/common/subscribers/product-subscriber.ts`

File yang dimodifikasi:
- `src/app.module.ts` atau `src/products/products.module.ts`

## Kode Implementasi (Per File)
```typescript
// src/common/subscribers/product-subscriber.ts
import {
  DataSource, EntitySubscriberInterface, EventSubscriber,
  InsertEvent, UpdateEvent, RemoveEvent,
} from 'typeorm';
import { Injectable } from '@nestjs/common';
import { Product } from '../../products/entities/product.entity';

@Injectable()
@EventSubscriber()
export class ProductSubscriber implements EntitySubscriberInterface<Product> {
  constructor(dataSource: DataSource) {
    dataSource.subscribers.push(this);
  }

  listenTo() {
    return Product;
  }

  async beforeInsert(event: InsertEvent<Product>) {
    console.log(`Before inserting product: ${event.entity.name}`);
    if (!event.entity.createdAt) {
      event.entity.createdAt = new Date();
    }
  }

  async afterInsert(event: InsertEvent<Product>) {
    console.log(`Product inserted: ${event.entity.id}`);
  }

  async beforeUpdate(event: UpdateEvent<Product>) {
    event.entity.updatedAt = new Date();
    console.log(`Before updating product: ${event.entity.id}`);
  }

  async beforeRemove(event: RemoveEvent<Product>) {
    console.log(`Before removing product: ${event.entity?.id}`);
  }
}
```

```typescript
// src/products/products.module.ts
import { Module } from '@nestjs/common';
import { TypeOrmModule } from '@nestjs/typeorm';
import { ProductsController } from './products.controller';
import { ProductsService } from './products.service';
import { Product } from './entities/product.entity';
import { ProductSubscriber } from '../common/subscribers/product-subscriber';

@Module({
  imports: [TypeOrmModule.forFeature([Product])],
  controllers: [ProductsController],
  providers: [ProductsService, ProductSubscriber],
})
export class ProductsModule {}
```

## Cara Integrasi & Pengujian
```bash
# Saat create/update produk, subscriber akan otomatis terpanggil
curl -X POST http://localhost:3000/products -H "Content-Type: application/json" -d '{"name":"Test","price":1000,"stock":5}'
# Console akan menampilkan: "Before inserting product: Test"
# createdAt dan updatedAt terisi otomatis oleh subscriber
```
