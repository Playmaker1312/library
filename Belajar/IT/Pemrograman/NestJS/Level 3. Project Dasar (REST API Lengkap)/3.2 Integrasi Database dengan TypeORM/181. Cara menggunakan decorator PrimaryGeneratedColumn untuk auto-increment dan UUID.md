# 181. Cara menggunakan decorator PrimaryGeneratedColumn untuk auto-increment dan UUID

## Definisi & Target
`@PrimaryGeneratedColumn()` mendefinisikan primary key yang otomatis di-generate. Dua strategi utama: auto-increment integer untuk aplikasi internal, dan UUID untuk distribusi atau microservices.

## Komponen & Nest CLI Command
Tidak ada CLI command.

## Kode Implementasi (Per File)
```typescript
// src/products/entities/product.entity.ts
import { Entity, PrimaryGeneratedColumn, Column } from 'typeorm';

// Strategi 1: Auto-increment integer
@Entity('products')
export class Product {
  @PrimaryGeneratedColumn('increment')
  id: number;

  @Column()
  name: string;
}
```

```typescript
// Strategi 2: UUID (lebih aman untuk exposure publik)
@Entity('products')
export class Product {
  @PrimaryGeneratedColumn('uuid')
  id: string;

  @Column()
  name: string;
}
```

```typescript
// Strategi 3: Identity (PostgreSQL 10+)
@Entity('products')
export class Product {
  @PrimaryGeneratedColumn('identity')
  id: number;

  @Column()
  name: string;
}
```

Perbandingan:

| Strategi | Tipe | Kelebihan | Kekurangan |
|----------|------|-----------|------------|
| `increment` | number | Ringan, cepat | Bisa ditebak, masalah di distributed system |
| `uuid` | string | Unik global, aman | Lebih besar storage, lebih lambat |
| `identity` | number | Standar SQL:2016 | Hanya PostgreSQL 10+ |

## Cara Integrasi & Pengujian
Pilih salah satu strategi dan terapkan di entity. Jika menggunakan UUID, sesuaikan tipe ID di service dari `number` menjadi `string`.

```typescript
// Contoh service dengan UUID
async findOne(id: string) {
  return await this.productRepository.findOneBy({ id });
}
```
