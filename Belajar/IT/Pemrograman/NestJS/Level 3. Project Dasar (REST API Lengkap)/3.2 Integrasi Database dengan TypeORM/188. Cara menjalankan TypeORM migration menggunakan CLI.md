# 188. Cara menjalankan TypeORM migration menggunakan CLI

## Definisi & Target
Migration adalah cara version-control untuk skema database. TypeORM CLI menyediakan perintah untuk generate, run, dan revert migration. Migration lebih aman daripada `synchronize: true` untuk production.

## Komponen & Nest CLI Command
```bash
# Install TypeORM CLI global (opsional)
npm i -g typeorm

# Atau gunakan npx
npx typeorm -d src/config/typeorm.config.ts migration:create src/migrations/CreateProductTable
npx typeorm -d src/config/typeorm.config.ts migration:generate src/migrations/AddCategoryToProduct
npx typeorm -d src/config/typeorm.config.ts migration:run
npx typeorm -d src/config/typeorm.config.ts migration:revert
```

File konfigurasi yang diperlukan:
- `src/config/typeorm.config.ts`

## Kode Implementasi (Per File)
```typescript
// src/config/typeorm.config.ts
import { DataSource } from 'typeorm';
import { config } from 'dotenv';
config();

export default new DataSource({
  type: 'postgres',
  host: process.env.DB_HOST || 'localhost',
  port: parseInt(process.env.DB_PORT || '5432'),
  username: process.env.DB_USERNAME || 'postgres',
  password: process.env.DB_PASSWORD || 'postgres',
  database: process.env.DB_DATABASE || 'product_db',
  entities: ['src/**/*.entity{.ts,.js}'],
  migrations: ['src/migrations/*{.ts,.js}'],
});
```

```bash
# package.json - tambahkan script
# "migration:generate": "typeorm -d src/config/typeorm.config.ts migration:generate src/migrations/Migration",
# "migration:run": "typeorm -d src/config/typeorm.config.ts migration:run",
# "migration:revert": "typeorm -d src/config/typeorm.config.ts migration:revert"
```

## Cara Integrasi & Pengujian
```bash
# 1. Set synchronize: false di AppModule
# 2. Generate migration
npx typeorm -d src/config/typeorm.config.ts migration:generate src/migrations/InitialSchema

# 3. Jalankan migration
npx typeorm -d src/config/typeorm.config.ts migration:run

# 4. Cek tabel di database
# 5. Jika error, revert
npx typeorm -d src/config/typeorm.config.ts migration:revert
```
