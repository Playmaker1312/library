# 178. Cara mengkonfigurasi TypeORM menggunakan TypeOrmModule.forRoot di AppModule

## Definisi & Target
TypeOrmModule.forRoot() mengkonfigurasi koneksi database global untuk seluruh aplikasi. Konfigurasi meliputi tipe database, host, port, username, password, dan entity yang akan digunakan.

## Komponen & Nest CLI Command
Tidak ada CLI command.

File yang dimodifikasi:
- `src/app.module.ts`

## Kode Implementasi (Per File)
```typescript
// src/app.module.ts
import { Module } from '@nestjs/common';
import { TypeOrmModule } from '@nestjs/typeorm';
import { ProductsModule } from './products/products.module';

@Module({
  imports: [
    TypeOrmModule.forRoot({
      type: 'postgres',
      host: 'localhost',
      port: 5432,
      username: 'postgres',
      password: 'postgres',
      database: 'product_db',
      entities: [__dirname + '/**/*.entity{.ts,.js}'],
      synchronize: true,
    }),
    ProductsModule,
  ],
})
export class AppModule {}
```

Konfigurasi untuk SQLite (development):
```typescript
TypeOrmModule.forRoot({
  type: 'sqlite',
  database: 'data/database.sqlite',
  entities: [__dirname + '/**/*.entity{.ts,.js}'],
  synchronize: true,
})
```

## Cara Integrasi & Pengujian
```bash
# Pastikan database PostgreSQL sudah running
# Atau gunakan SQLite untuk testing tanpa perlu install database server

npm run start:dev
# Jika konfigurasi benar, tidak ada error saat server start
# TypeORM akan membuat tabel otomatis (karena synchronize: true)
```
