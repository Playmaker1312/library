# 189. Cara membuat migration secara manual dan otomatis menggunakan TypeORM

## Definisi & Target
Migration otomatis membandingkan state entity dengan database dan menghasilkan SQL yang diperlukan. Migration manual memberikan kontrol penuh atas SQL yang dijalankan.

## Komponen & Nest CLI Command
```bash
# Migration otomatis (generate dari perubahan entity)
npx typeorm -d src/config/typeorm.config.ts migration:generate src/migrations/AddPriceColumn

# Migration manual (template kosong)
npx typeorm migration:create src/migrations/CustomMigration
```

## Kode Implementasi (Per File)
```typescript
// src/config/typeorm.config.ts
import { DataSource } from 'typeorm';

export default new DataSource({
  type: 'postgres',
  host: 'localhost',
  port: 5432,
  username: 'postgres',
  password: 'postgres',
  database: 'product_db',
  entities: ['src/**/*.entity{.ts,.js}'],
  migrations: ['src/migrations/*{.ts,.js}'],
});
```

## Cara Integrasi & Pengujian
```bash
# Generate migration otomatis setelah mengubah entity
npx typeorm -d src/config/typeorm.config.ts migration:generate src/migrations/AutoMigration

# Cek file migration yang dihasilkan di folder src/migrations/
# Jalankan migration
npx typeorm -d src/config/typeorm.config.ts migration:run
```
