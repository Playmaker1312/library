# 186. Cara menggunakan find, findOne, findOneBy, save, update, delete, dan softDelete

## Definisi & Target
Penjelasan detail method-method repository TypeORM yang paling sering digunakan. Setiap method memiliki kegunaan spesifik untuk operasi database.

## Komponen & Nest CLI Command
Tidak ada CLI command.

## Kode Implementasi (Per File)
```typescript
// src/products/products.service.ts
import { Injectable } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository, FindOptionsWhere } from 'typeorm';
import { Product } from './entities/product.entity';

@Injectable()
export class ProductsService {
  constructor(
    @InjectRepository(Product)
    private productRepository: Repository<Product>,
  ) {}

  async findByMethods() {
    // find - semua record
    const all: Product[] = await this.productRepository.find();

    // find dengan where clause
    const active: Product[] = await this.productRepository.find({
      where: { isActive: true },
      order: { createdAt: 'DESC' },
      take: 10,
      skip: 0,
    });

    // findOne - record pertama yang cocok
    const one: Product | null = await this.productRepository.findOne({
      where: { name: 'Laptop' },
    });

    // findOneBy - lebih sederhana
    const byId: Product | null = await this.productRepository.findOneBy({ id: 1 });

    // findOneOrFail - throw error jika tidak ditemukan
    const orFail: Product = await this.productRepository.findOneOrFail({
      where: { id: 1 },
    });
  }

  async saveMethods(data: Partial<Product>) {
    // create + save (approach 1)
    const product = this.productRepository.create(data);
    const saved: Product = await this.productRepository.save(product);

    // save langsung (approach 2)
    const direct: Product = await this.productRepository.save(data);

    // preload + save (untuk update partial)
    const preloaded = await this.productRepository.preload({ id: 1, ...data });
    if (preloaded) await this.productRepository.save(preloaded);
  }

  async deleteMethods(id: number) {
    // delete - hard delete
    await this.productRepository.delete(id);

    // softDelete - isi deletedAt
    await this.productRepository.softDelete(id);

    // restore - batalkan soft delete
    await this.productRepository.restore(id);
  }
}
```

## Cara Integrasi & Pengujian
Gunakan method sesuai kebutuhan. `softDelete` memerlukan entity yang memiliki `@DeleteDateColumn()`. Method `restore()` mengembalikan record yang di-soft-delete.
