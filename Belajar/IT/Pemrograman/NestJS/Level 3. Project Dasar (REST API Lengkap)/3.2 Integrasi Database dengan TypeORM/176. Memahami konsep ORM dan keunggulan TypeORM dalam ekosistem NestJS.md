# 176. Memahami konsep ORM dan keunggulan TypeORM dalam ekosistem NestJS

## Definisi & Target
ORM (Object-Relational Mapping) memetakan tabel database ke objek JavaScript/TypeScript. TypeORM adalah ORM populer untuk TypeScript yang terintegrasi erat dengan NestJS melalui decorator dan dependency injection.

## Komponen & Nest CLI Command
Tidak ada command. Ini materi konseptual.

Keunggulan TypeORM di NestJS:
- Decorator `@Entity()`, `@Column()`, `@ManyToOne()` — langsung di entity class
- `TypeOrmModule.forRoot()` — konfigurasi database global
- `@InjectRepository()` — injeksi repository ke service
- Active Record dan Data Mapper patterns didukung
- Migration, subscriber, dan query builder bawaan

Perbandingan dengan query SQL langsung:

| SQL Langsung | TypeORM |
|-------------|---------|
| `SELECT * FROM products` | `productRepository.find()` |
| `INSERT INTO products ...` | `productRepository.save(data)` |
| `UPDATE products SET ...` | `productRepository.update(id, data)` |
| `DELETE FROM products ...` | `productRepository.delete(id)` |
| Join manual | `relations: ['category']` |
| Mapping manual | Decorator entity otomatis |
