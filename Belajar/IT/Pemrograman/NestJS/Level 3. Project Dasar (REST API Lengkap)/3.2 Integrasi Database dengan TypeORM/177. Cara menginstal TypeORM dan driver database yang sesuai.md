# 177. Cara menginstal TypeORM dan driver database yang sesuai

## Definisi & Target
Menginstal package TypeORM dan driver database (MySQL/PostgreSQL/SQLite) ke dalam project NestJS. TypeORM membutuhkan driver yang sesuai dengan database yang digunakan.

## Komponen & Nest CLI Command
```bash
# Instal TypeORM dan @nestjs/typeorm
npm install @nestjs/typeorm typeorm

# Instal driver database (pilih salah satu sesuai kebutuhan)
npm install mysql2          # MySQL / MariaDB
npm install pg              # PostgreSQL
npm install sqlite3         # SQLite (untuk development/testing)
```

Verifikasi package.json:

```json
// package.json (sebagian)
{
  "dependencies": {
    "@nestjs/typeorm": "^10.0.0",
    "typeorm": "^0.3.0",
    "pg": "^8.11.0",
    "@nestjs/common": "^10.0.0",
    "@nestjs/core": "^10.0.0",
    ...
  }
}
```

## Kode Implementasi (Per File)
Tidak ada implementasi kode — hanya instalasi package.

## Cara Integrasi & Pengujian
```bash
# Cek apakah package terinstal
npm list @nestjs/typeorm typeorm pg

# Output harus menunjukkan versi package
# Jika error, ulangi instalasi
```
