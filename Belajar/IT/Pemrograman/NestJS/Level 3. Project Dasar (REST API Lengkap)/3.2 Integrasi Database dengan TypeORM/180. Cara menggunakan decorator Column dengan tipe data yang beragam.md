# 180. Cara menggunakan decorator Column dengan tipe data yang beragam

## Definisi & Target
Decorator `@Column()` memiliki berbagai opsi untuk mendefinisikan tipe data, panjang, nullable, default value, dan lainnya. Pemilihan tipe data yang tepat penting untuk integritas database.

## Komponen & Nest CLI Command
Tidak ada CLI command. Modifikasi entity.

## Kode Implementasi (Per File)
```typescript
// src/products/entities/product.entity.ts
import { Entity, Column, PrimaryGeneratedColumn } from 'typeorm';

@Entity('products')
export class Product {
  @PrimaryGeneratedColumn()
  id: number;

  @Column({ length: 100 })
  name: string;

  @Column({ type: 'text', nullable: true })
  description: string;

  @Column({ type: 'decimal', precision: 10, scale: 2 })
  price: number;

  @Column({ type: 'int', unsigned: true, default: 0 })
  stock: number;

  @Column({ type: 'varchar', length: 50, default: 'active' })
  status: string;

  @Column({ type: 'boolean', default: false })
  isFeatured: boolean;

  @Column({ type: 'json', nullable: true })
  metadata: Record<string, any>;

  @Column({ type: 'float', nullable: true })
  rating: number;

  @Column('simple-array', { nullable: true })
  tags: string[];
}
```

Tipe data yang umum:

| Decorator | Tipe Database | Keterangan |
|-----------|--------------|------------|
| `@Column()` | varchar(255) | String default |
| `@Column('text')` | text | Teks panjang |
| `@Column('int')` | integer | Angka bulat |
| `@Column('decimal', { precision: 10, scale: 2 })` | decimal(10,2) | Desimal presisi |
| `@Column('boolean')` | boolean | true/false |
| `@Column('json')` | json | Objek JSON |
| `@Column('simple-array')` | text | Array string dipisah koma |
| `@Column({ nullable: true })` | nullable | Boleh kosong |
| `@Column({ default: value })` | default | Nilai default |

## Cara Integrasi & Pengujian
Setelah menambahkan kolom baru, restart server. Jika `synchronize: true`, TypeORM akan menambahkan kolom baru ke tabel yang sudah ada.
