# 39. Architecture Patterns dan Best Practices ## 39.7 Monorepo dengan NestJS Nx Turborepo

**Definisi Singkat:** Monorepo menyimpan multiple project (apps dan libraries) dalam satu repository. Nx dan Turborepo adalah build system yang mengoptimasi monorepo dengan dependency graph, caching, dan parallel execution.

**Analogi:** Monorepo seperti kompleks apartemen — banyak unit (apps) berbagi infrastruktur yang sama (shared libraries), lift (build cache), dan utilitas (tooling). Lebih efisien daripada rumah terpisah-pisah (multi-repo) dengan masing-masing listrik sendiri.

**Poin-Poin Penting:**
- **Nx** build system dengan dependency graph
- **Turborepo** build caching dan parallel tasks
- **Shared libraries** common code (DTOs, utils, types)
- **Dependency graph** only rebuild affected projects
- **Computation caching** skip cache untuk build/test
- **Distributed task execution** parallel di CI

**Contoh Kode:**
```typescript
// nx.json (Nx workspace config)
{
  "extends": "nx/presets/npm.json",
  "tasksRunnerOptions": {
    "default": {
      "runner": "nx/tasks-runners/default",
      "options": {
        "cacheableOperations": ["build", "test", "lint"],
        "parallel": 3
      }
    }
  },
  "targetDefaults": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": ["{projectRoot}/dist"]
    },
    "test": {
      "dependsOn": ["build"]
    }
  }
}
```

```typescript
// package.json (root)
{
  "name": "my-monorepo",
  "private": true,
  "workspaces": [
    "apps/*",
    "libs/*"
  ],
  "scripts": {
    "nx": "nx",
    "start:api": "nx serve api",
    "start:admin": "nx serve admin",
    "build:all": "nx run-many --target=build --all",
    "test:affected": "nx affected --target=test",
    "lint:all": "nx run-many --target=lint --all",
    "dep-graph": "nx dep-graph"
  },
  "devDependencies": {
    "nx": "latest",
    "@nx/workspace": "latest",
    "@nx/nest": "latest",
    "@nx/node": "latest"
  }
}
```

```typescript
// apps/api/project.json (NestJS app)
{
  "root": "apps/api",
  "sourceRoot": "apps/api/src",
  "projectType": "application",
  "targets": {
    "build": {
      "executor": "@nx/nest:build",
      "outputs": ["{options.outputPath}"],
      "options": {
        "outputPath": "dist/apps/api",
        "main": "apps/api/src/main.ts",
        "tsConfig": "apps/api/tsconfig.app.json"
      }
    },
    "serve": {
      "executor": "@nx/node:execute",
      "options": {
        "buildTarget": "api:build"
      }
    },
    "test": {
      "executor": "@nx/jest:jest",
      "options": {
        "jestConfig": "apps/api/jest.config.ts"
      }
    }
  },
  "implicitDependencies": ["@myorg/shared-types", "@myorg/utils"]
}
```

```typescript
// libs/shared/types/project.json (Shared library)
{
  "root": "libs/shared/types",
  "sourceRoot": "libs/shared/types/src",
  "projectType": "library",
  "targets": {
    "build": {
      "executor": "@nx/js:tsc",
      "outputs": ["{options.outputPath}"],
      "options": {
        "outputPath": "dist/libs/shared/types",
        "main": "libs/shared/types/src/index.ts",
        "tsConfig": "libs/shared/types/tsconfig.lib.json"
      }
    }
  }
}
```

```typescript
// turbo.json (Turborepo config)
{
  "$schema": "https://turbo.build/schema.json",
  "globalDependencies": ["**/.env.*local"],
  "pipeline": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": ["dist/**", ".next/**"]
    },
    "test": {
      "dependsOn": ["^build"],
      "outputs": []
    },
    "lint": {
      "outputs": []
    },
    "dev": {
      "cache": false,
      "persistent": true
    }
  }
}
```

**Kasus Penggunaan Nyata:** Enterprise dengan 3 NestJS apps (API Gateway, Admin Panel, Public API) dan 5 shared libraries (types, utils, database, auth, logging). Nx memastikan ketika shared auth library diubah, hanya apps yang depend ke auth yang di-rebuild dan di-test.
