# 39. Architecture Patterns dan Best Practices ## 39.4 Service Layer Pattern

**Definisi Singkat:** Service Layer Pattern memisahkan business logic dari controller dan repository. Service menjadi middleware yang mengoordinasikan operasi bisnis, transaksi, dan komunikasi antar komponen domain.

**Analogi:** Service Layer seperti manajer restoran — tidak memasak (seperti koki = repository) dan tidak melayani meja (seperti pelayan = controller). Manajer mengoordinasikan: menerima pesanan, memastikan dapur memasak, memanggil pelayan, menangani komplain.

**Poin-Poin Penting:**
- **@Injectable()** decorator untuk service
- **Business logic** di service, bukan controller
- **Coordination** multiple repository/domain service calls
- **Transaction management** di service layer
- **DTO transformation** input/output
- **Separation of concerns** controller hanya routing

**Contoh Kode:**
```typescript
// application/services/checkout.service.ts
import { Injectable, BadRequestException } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { Order } from '../entities/order.entity';
import { ProductService } from './product.service';
import { PaymentService } from './payment.service';
import { InventoryService } from './inventory.service';
import { NotificationService } from './notification.service';
import { CreateOrderDto } from '../dto/create-order.dto';
import { OrderResponseDto } from '../dto/order-response.dto';

@Injectable()
export class CheckoutService {
  constructor(
    @InjectRepository(Order)
    private readonly orderRepository: Repository<Order>,
    private readonly productService: ProductService,
    private readonly paymentService: PaymentService,
    private readonly inventoryService: InventoryService,
    private readonly notificationService: NotificationService,
  ) {}

  async checkout(dto: CreateOrderDto, userId: string): Promise<OrderResponseDto> {
    // 1. Validasi produk
    const products = await Promise.all(
      dto.items.map((item) => this.productService.findById(item.productId)),
    );

    for (const product of products) {
      if (!product) throw new BadRequestException('Product not found');
    }

    // 2. Cek stok
    for (const item of dto.items) {
      const available = await this.inventoryService.checkStock(item.productId, item.quantity);
      if (!available) {
        throw new BadRequestException(`Insufficient stock for product ${item.productId}`);
      }
    }

    // 3. Hitung total
    const total = products.reduce((sum, product, index) => {
      return sum + product.price * dto.items[index].quantity;
    }, 0);

    // 4. Proses pembayaran
    const payment = await this.paymentService.charge({
      amount: total,
      currency: 'USD',
      paymentMethod: dto.paymentMethod,
      userId,
    });

    // 5. Buat order
    const order = this.orderRepository.create({
      userId,
      items: dto.items,
      total,
      paymentId: payment.id,
      status: 'confirmed',
    });

    await this.orderRepository.save(order);

    // 6. Update stok
    await this.inventoryService.reserveItems(dto.items);

    // 7. Kirim notifikasi
    await this.notificationService.sendOrderConfirmation(userId, order.id);

    return new OrderResponseDto(order);
  }

  async getOrderHistory(userId: string, page: number) {
    const [orders, total] = await this.orderRepository.findAndCount({
      where: { userId },
      skip: (page - 1) * 10,
      take: 10,
      order: { createdAt: 'DESC' },
    });

    return {
      data: orders.map((o) => new OrderResponseDto(o)),
      total,
      page,
    };
  }
}
```

```typescript
// application/services/reports.service.ts
import { Injectable } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { Order } from '../entities/order.entity';

@Injectable()
export class ReportsService {
  constructor(
    @InjectRepository(Order)
    private readonly orderRepository: Repository<Order>,
  ) {}

  async getDailySales(date: Date) {
    const start = new Date(date);
    start.setHours(0, 0, 0, 0);

    const end = new Date(date);
    end.setHours(23, 59, 59, 999);

    const result = await this.orderRepository
      .createQueryBuilder('order')
      .select('COUNT(order.id)', 'totalOrders')
      .addSelect('SUM(order.total)', 'totalRevenue')
      .where('order.createdAt BETWEEN :start AND :end', { start, end })
      .andWhere('order.status = :status', { status: 'confirmed' })
      .getRawOne();

    return {
      date: date.toISOString().split('T')[0],
      totalOrders: parseInt(result.totalOrders) || 0,
      totalRevenue: parseFloat(result.totalRevenue) || 0,
    };
  }
}
```

**Kasus Penggunaan Nyata:** E-commerce checkout flow — service layer mengoordinasikan 6 langkah (validasi, stok, pricing, payment, order, notifikasi) dalam satu transaksi. Controller hanya menerima HTTP POST dan return response. Jika payment gagal, service handle rollback.
