# 39. Architecture Patterns dan Best Practices ## 39.3 Repository Pattern abstraksi database

**Definisi Singkat:** Repository Pattern memisahkan logika akses data dari business logic dengan menyediakan interface koleksi-like untuk domain objects. Database implementation detail disembunyikan di belakang interface repository.

**Analogi:** Repository seperti katalog perpustakaan — Anda (business logic) mencari buku (domain object) tanpa tahu di rak mana buku itu disimpan (database implementation). Petugas perpustakaan (repository) yang tahu persis di mana buku dan bagaimana mengelolanya.

**Poin-Poin Penting:**
- **Repository interface** di domain layer
- **Implementation** di infrastructure layer
- **CRUD operations** find, save, delete
- **Specification pattern** untuk query kompleks
- **Unit of Work** untuk transaksi
- **TypeORM/Prisma** sudah memiliki repository-like pattern

**Contoh Kode:**
```typescript
// domain/repositories/product.repository.ts
export interface ProductRepository {
  findById(id: string): Promise<Product | null>;
  findBySku(sku: string): Promise<Product | null>;
  findFeatured(limit: number): Promise<Product[]>;
  search(query: string, page: number, limit: number): Promise<{ data: Product[]; total: number }>;
  save(product: Product): Promise<void>;
  update(id: string, data: Partial<Product>): Promise<void>;
  delete(id: string): Promise<void>;
}
```

// domain/repositories/specifications/product.specification.ts
export interface Specification<T> {
  isSatisfiedBy(item: T): boolean;
  toQuery(): Record<string, any>;
}

export class ProductInCategorySpec implements Specification<Product> {
  constructor(private readonly categoryId: string) {}

  isSatisfiedBy(product: Product): boolean {
    return product.categoryId === this.categoryId;
  }

  toQuery() {
    return { categoryId: this.categoryId };
  }
}

export class PriceRangeSpec implements Specification<Product> {
  constructor(private readonly min: number, private readonly max: number) {}

  isSatisfiedBy(product: Product): boolean {
    return product.price >= this.min && product.price <= this.max;
  }

  toQuery() {
    return { price: { gte: this.min, lte: this.max } };
  }
}

```typescript
// infrastructure/persistence/prisma-product.repository.ts
import { Injectable } from '@nestjs/common';
import { PrismaService } from '../prisma.service';
import { ProductRepository } from '../../../domain/repositories/product.repository';
import { Product } from '../../../domain/entities/product.entity';

@Injectable()
export class PrismaProductRepository implements ProductRepository {
  constructor(private readonly prisma: PrismaService) {}

  async findById(id: string): Promise<Product | null> {
    const record = await this.prisma.product.findUnique({ where: { id } });
    return record ? this.toDomain(record) : null;
  }

  async findBySku(sku: string): Promise<Product | null> {
    const record = await this.prisma.product.findUnique({ where: { sku } });
    return record ? this.toDomain(record) : null;
  }

  async findFeatured(limit: number): Promise<Product[]> {
    const records = await this.prisma.product.findMany({
      where: { featured: true, active: true },
      take: limit,
      orderBy: { createdAt: 'desc' },
    });
    return records.map((r) => this.toDomain(r));
  }

  async search(query: string, page: number, limit: number) {
    const [data, total] = await Promise.all([
      this.prisma.product.findMany({
        where: {
          OR: [
            { name: { contains: query, mode: 'insensitive' } },
            { description: { contains: query, mode: 'insensitive' } },
          ],
        },
        skip: (page - 1) * limit,
        take: limit,
      }),
      this.prisma.product.count({
        where: {
          OR: [
            { name: { contains: query, mode: 'insensitive' } },
            { description: { contains: query, mode: 'insensitive' } },
          ],
        },
      }),
    ]);

    return { data: data.map((r) => this.toDomain(r)), total };
  }

  async save(product: Product): Promise<void> {
    await this.prisma.product.create({ data: this.toPersistence(product) });
  }

  async update(id: string, data: Partial<Product>): Promise<void> {
    await this.prisma.product.update({ where: { id }, data });
  }

  async delete(id: string): Promise<void> {
    await this.prisma.product.delete({ where: { id } });
  }

  private toDomain(record: any): Product {
    return new Product(record.id, record.name, record.sku, record.price, record.categoryId);
  }

  private toPersistence(product: Product): any {
    return { id: product.id, name: product.name, sku: product.sku, price: product.price, categoryId: product.categoryId };
  }
}
```

```typescript
// application/services/product.service.ts
import { Injectable } from '@nestjs/common';
import { ProductRepository } from '../../domain/repositories/product.repository';

@Injectable()
export class ProductService {
  constructor(private readonly productRepo: ProductRepository) {}

  async getFeaturedProducts() {
    return this.productRepo.findFeatured(10);
  }

  async searchProducts(query: string, page: number) {
    return this.productRepo.search(query, page, 20);
  }
}
```

**Kasus Penggunaan Nyata:** Startup yang migrasi dari MongoDB ke PostgreSQL — cukup buat implementasi repository baru (MongoProductRepository atau PostgresProductRepository) dan ganti provider DI. Service layer tidak perlu perubahan kode.
