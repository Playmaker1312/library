# 39. Architecture Patterns dan Best Practices ## 39.10 Graceful Shutdown

**Definisi Singkat:** Graceful shutdown memastikan aplikasi berhenti dengan aman: selesai memproses request yang sedang berjalan, menutup koneksi database, membersihkan resources, dan memberitahu load balancer untuk tidak mengirim traffic baru.

**Analogi:** Graceful shutdown seperti toko yang tutup — bukan langsung menutup pintu (hard shutdown) saat jam 21:00 tepat, tapi mengumumkan "kami akan tutup sebentar lagi", melayani customer yang sudah di antrian, lalu menutup perlahan. Customer baru tidak boleh masuk setelah jam tutup.

**Poin-Poin Penting:**
- **enableShutdownHooks()** aktifkan listener lifecycle
- **SIGTERM** sinyal Kubernetes/PM2 untuk shutdown
- **SIGINT** sinyal Ctrl+C terminal
- **app.close()** method untuk graceful shutdown NestJS
- **Connection draining** database, Redis, message queue
- **Timeout** maksimal waktu tunggu shutdown

**Contoh Kode:**
```typescript
// main.ts — graceful shutdown lengkap
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { Logger } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  const logger = new Logger('Bootstrap');

  // Aktifkan shutdown hooks
  app.enableShutdownHooks();

  // Graceful shutdown untuk Kubernetes/PM2
  app.enableShutdownHooks();

  await app.listen(process.env.PORT || 3000);
  logger.log('Application started');

  // Handle SIGTERM (Kubernetes, PM2)
  process.on('SIGTERM', async () => {
    logger.log('SIGTERM received, shutting down gracefully...');
    await gracefulShutdown(app);
  });

  // Handle SIGINT (Ctrl+C)
  process.on('SIGINT', async () => {
    logger.log('SIGINT received, shutting down gracefully...');
    await gracefulShutdown(app);
  });
}

async function gracefulShutdown(app: any) {
  const logger = new Logger('GracefulShutdown');
  const timeoutMs = parseInt(process.env.SHUTDOWN_TIMEOUT || '10000', 10);

  // Buat promise dengan timeout
  const shutdownPromise = new Promise<void>((resolve) => {
    const timer = setTimeout(() => {
      logger.warn(`Forced shutdown after ${timeoutMs}ms timeout`);
      resolve();
    }, timeoutMs);

    // Tutup aplikasi NestJS
    app.close().then(() => {
      clearTimeout(timer);
      resolve();
    });
  });

  await shutdownPromise;

  // Tutup koneksi database
  // if (dataSource) await dataSource.destroy();
  // Tutup Redis
  // if (redisClient) await redisClient.quit();
  // Tutup message queue
  // if (mqClient) await mqClient.close();

  logger.log('All connections closed. Goodbye!');
  process.exit(0);
}

bootstrap();
```

@Injectable()

  private readonly logger = new Logger(GracefulShutdownService.name);

  constructor(
    @InjectDataSource() private readonly dataSource: DataSource,
    private readonly redisService: RedisService,
  ) {}

  async onApplicationShutdown(signal?: string) {
    this.logger.log(`Received ${signal}, cleaning up resources...`);

      this.closeDatabase().then(() => this.logger.log('Database connections closed')),

**Kasus Penggunaan Nyata:** Kubernetes pod di rolling update — saat pod lama diganti pod baru, Kubernetes kirim SIGTERM. NestJS berhenti menerima request baru (load balancer sudah tahu), selesaikan request dalam 10s, tutup database connection pool, Redis, dan RabbitMQ. Jika >30s, K8s force kill.
