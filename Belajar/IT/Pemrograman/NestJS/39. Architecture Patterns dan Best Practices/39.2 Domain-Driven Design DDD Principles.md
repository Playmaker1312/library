# 39. Architecture Patterns dan Best Practices ## 39.2 Domain-Driven Design DDD Principles

**Definisi Singkat:** DDD adalah pendekatan pengembangan software yang berfokus pada model domain kompleks, dengan kolaborasi erat antara developer dan domain expert. Ubiquitous Language, Bounded Context, dan Entities/Value Objects adalah konsep inti.

**Analogi:** DDD seperti membuat software dengan arsitek yang paham bangunan (domain expert) dan kontraktor (developer) menggunakan istilah yang sama — "dinding" bukan "wall_structure_01". Setiap ruangan (bounded context) punya aturan sendiri, tidak campur aduk dengan ruang lain.

**Poin-Poin Penting:**
- **Ubiquitous Language** bahasa yang sama antara dev dan bisnis
- **Bounded Context** batasan model dalam konteks tertentu
- **Entities** objek dengan identity unik
- **Value Objects** objek immutable tanpa identity
- **Domain Events** kejadian penting di domain
- **Aggregates** cluster objek dengan root

**Contoh Kode:**
```typescript
// domain/value-objects/money.ts
export class Money {
  constructor(
    private readonly amount: number,
    private readonly currency: string,
  ) {
    if (amount < 0) throw new Error('Amount cannot be negative');
  }

  add(other: Money): Money {
    if (this.currency !== other.currency) {
      throw new Error('Currency mismatch');
    }
    return new Money(this.amount + other.amount, this.currency);
  }

  multiply(factor: number): Money {
    return new Money(this.amount * factor, this.currency);
  }

  getAmount(): number { return this.amount; }
  getCurrency(): string { return this.currency; }
}
```

```typescript
// domain/entities/order.ts (Aggregate Root)
import { AggregateRoot } from '@nestjs/cqrs';
import { OrderCreatedEvent } from '../events/order-created.event';
import { OrderItem } from '../value-objects/order-item';

export class Order extends AggregateRoot {
  private items: OrderItem[] = [];
  private status: string;

  private constructor(
    public readonly id: string,
    public readonly customerId: string,
  ) {
    super();
    this.status = 'draft';
  }

  static create(id: string, customerId: string, items: OrderItem[]): Order {
    const order = new Order(id, customerId);
    items.forEach((item) => order.addItem(item));
    order.apply(new OrderCreatedEvent(id, customerId, items));
    return order;
  }

  addItem(item: OrderItem): void {
    if (this.status !== 'draft') {
      throw new Error('Cannot modify non-draft order');
    }
    this.items.push(item);
  }

  submit(): void {
    if (this.items.length === 0) {
      throw new Error('Cannot submit empty order');
    }
    this.status = 'submitted';
    this.apply(new OrderSubmittedEvent(this.id));
  }

  getTotal(): Money {
    return this.items.reduce(
      (total, item) => total.add(item.getSubtotal()),
      new Money(0, 'USD'),
    );
  }
}
```

```typescript
// domain/services/pricing.service.ts (Domain Service)
export class PricingService {
  calculateDiscount(items: OrderItem[], customerTier: string): Money {
    const total = items.reduce((sum, item) => sum.add(item.getSubtotal()), new Money(0, 'USD'));

    if (customerTier === 'gold' && total.getAmount() > 100) {
      return total.multiply(0.1); // 10% discount
    }

    return new Money(0, 'USD');
  }
}
```
