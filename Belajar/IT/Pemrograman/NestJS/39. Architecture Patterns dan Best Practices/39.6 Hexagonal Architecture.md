# 39. Architecture Patterns dan Best Practices ## 39.6 Hexagonal Architecture

**Definisi Singkat:** Hexagonal Architecture (Ports and Adapters) membagi aplikasi menjadi inner (domain) dan outer (infrastructure). Ports adalah interface di boundary, Adapters adalah implementasi konkrit untuk setiap port.

**Analogi:** Hexagonal seperti stop kontak listrik (port) dengan berbagai adapter — colokan Eropa, US, UK semuanya bisa (port sama). Perangkat elektronik (domain core) tidak peduli colokan apa, yang penting listrik masuk. Adaptor menyesuaikan antara port dan infrastructure.

**Poin-Poin Penting:**
- **Port** interface di boundary domain
- **Adapter** implementasi port untuk infrastructure
- **Domain core** pure business logic tanpa dependencies
- **Driver adapters** HTTP controller, CLI, GraphQL (inbound)
- **Driven adapters** database, message queue, API (outbound)
- **Dependency Rule** dependensi dari luar ke dalam

**Contoh Kode:**
```typescript
// domain/ports/inbound/create-order.port.ts (Inbound Port)
export interface CreateOrderUseCase {
  execute(input: CreateOrderInput): Promise<OrderResponse>;
}

export interface CreateOrderInput {
  customerId: string;
  items: Array<{ productId: string; quantity: number }>;
  paymentMethod: string;
}

export interface OrderResponse {
  orderId: string;
  status: string;
  total: number;
}
```

```typescript
// domain/ports/outbound/order-repository.port.ts (Outbound Port)
export interface OrderRepositoryPort {
  save(order: Order): Promise<void>;
  findById(id: string): Promise<Order | null>;
  findByCustomerId(customerId: string): Promise<Order[]>;
}

export interface PaymentServicePort {
  charge(amount: number, method: string): Promise<PaymentResult>;
}

export interface InventoryServicePort {
  reserve(productId: string, quantity: number): Promise<boolean>;
}

export interface NotificationPort {
  sendOrderConfirmation(userId: string, orderId: string): Promise<void>;
}
```

```typescript
// domain/use-cases/create-order.use-case.ts (Domain Service)
export class CreateOrderUseCaseImpl implements CreateOrderUseCase {
  constructor(
    private readonly orderRepo: OrderRepositoryPort,
    private readonly paymentService: PaymentServicePort,
    private readonly inventoryService: InventoryServicePort,
    private readonly notification: NotificationPort,
  ) {}

  async execute(input: CreateOrderInput): Promise<OrderResponse> {
    const items = await Promise.all(
      input.items.map(async (item) => {
        const reserved = await this.inventoryService.reserve(item.productId, item.quantity);
        if (!reserved) throw new Error('Insufficient stock');
        return item;
      }),
    );

    const total = items.reduce((sum, item) => sum + item.price * item.quantity, 0);
    const payment = await this.paymentService.charge(total, input.paymentMethod);

    const order = Order.create(input.customerId, items, total, payment.transactionId);
    await this.orderRepo.save(order);

    await this.notification.sendOrderConfirmation(input.customerId, order.getId());

    return { orderId: order.getId(), status: order.getStatus(), total };
  }
}
```

```typescript
@Injectable()
export class TypeOrmOrderAdapter implements OrderRepositoryPort {
  constructor(@InjectRepository(OrderEntity) private repo: Repository<OrderEntity>) {}

  async save(order: Order): Promise<void> {
    await this.repo.save(this.toEntity(order));
  }

  async findById(id: string): Promise<Order | null> {
    const entity = await this.repo.findOne({ where: { id } });
```

```typescript
// infrastructure/adapters/inbound/order.controller.ts (Driver Adapter)
@Controller('orders')
export class OrderController {
  constructor(private readonly createOrderUseCase: CreateOrderUseCase) {}

  @Post()
  async create(@Body() dto: CreateOrderDto): Promise<OrderResponse> {
    return this.createOrderUseCase.execute(dto);
  }
}
```
