# 39. Architecture Patterns dan Best Practices ## 39.9 Feature Flags

**Definisi Singkat:** Feature flags (feature toggles) memungkinkan mengaktifkan/menonaktifkan fitur tanpa deploy ulang. Cocok untuk canary release, A/B testing, kill switch, dan gradual rollout.

**Analogi:** Feature flags seperti saklar lampu di panel kontrol — Anda bisa nyalakan/matikan fitur tertentu kapan saja tanpa harus ganti kabel (deploy). Lampu kamar tamu (fitur baru) bisa dinyalakan hanya untuk tamu tertentu (user segment) untuk testing.

**Poin-Poin Penting:**
- **LaunchDarkly** enterprise feature flag platform
- **Flagsmith** open-source alternative
- **Config-based** via environment variables
- **Database-backed** flags persist dan real-time
- **User targeting** specific user/group untuk test
- **Gradual rollout** persentase users bertahap

```typescript
// feature-flags/feature-flag.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';

export enum FeatureFlag {
  NEW_CHECKOUT = 'NEW_CHECKOUT',
  AI_RECOMMENDATIONS = 'AI_RECOMMENDATIONS',
  DASHBOARD_V2 = 'DASHBOARD_V2',
  DARK_MODE = 'DARK_MODE',
}

@Injectable()
export class FeatureFlagService {
  private readonly logger = new Logger(FeatureFlagService.name);
  private flags: Map<string, boolean>;

  constructor(private readonly configService: ConfigService) {
    this.flags = new Map();
    this.loadFlags();
  }

  private loadFlags() {
    // Load dari environment variables config
    const flagConfig = this.configService.get('featureFlags') || {};
    Object.keys(flagConfig).forEach((key) => {
      this.flags.set(key, flagConfig[key] === true);
    });
    this.logger.log(`Loaded ${this.flags.size} feature flags`);
  }

  isEnabled(flag: FeatureFlag, userId?: string): boolean {
    const enabled = this.flags.get(flag.toString());

    // Jika ada userId, cek user-specific targeting
    if (userId && this.isUserInTestGroup(userId, flag)) {
      return true;
    }

    return enabled ?? false;
  }

  private isUserInTestGroup(userId: string, flag: FeatureFlag): boolean {
    // Simple hash-based user targeting (10% users)
    const hash = this.hashString(userId + flag.toString());
    return hash % 100 < 10; // 10% of users
  }

  private hashString(str: string): number {
    let hash = 0;
    for (let i = 0; i < str.length; i++) {
      hash = ((hash << 5) - hash) + str.charCodeAt(i);
      hash |= 0;
    }
    return Math.abs(hash);
  }

  // Refresh flags tanpa restart
  refresh(): void {
    this.loadFlags();
  }
}
```

```typescript
// feature-flags/feature-flag.guard.ts
import { Injectable, CanActivate, ExecutionContext } from '@nestjs/common';
import { FeatureFlagService, FeatureFlag } from './feature-flag.service';

@Injectable()
export class FeatureFlagGuard implements CanActivate {
  constructor(
    private readonly featureFlagService: FeatureFlagService,
    private readonly flag: FeatureFlag,
  ) {}

  canActivate(context: ExecutionContext): boolean {
    const request = context.switchToHttp().getRequest();
    const userId = request.user?.id;
    return this.featureFlagService.isEnabled(this.flag, userId);
  }
}
```

```typescript
// checkout.controller.ts — menggunakan feature flag
import { Controller, Post, UseGuards } from '@nestjs/common';
import { FeatureFlag } from '../feature-flags/feature-flag.service';
import { FeatureFlagGuard } from '../feature-flags/feature-flag.guard';

@Controller('checkout')
export class CheckoutController {
  @Post()
  @UseGuards(new FeatureFlagGuard(FeatureFlag.NEW_CHECKOUT))
  async newCheckout() {
    // New checkout flow — hanya aktif jika flag ON
    return { message: 'New checkout flow' };
  }

  @Post('legacy')
  async legacyCheckout() {
    // Legacy checkout — selalu available
    return { message: 'Legacy checkout flow' };
  }
}
```

import { FeatureFlagService, FeatureFlag } from './feature-flag.service';

// Pilih implementasi berdasarkan flag
const paymentProviderFactory = {
  provide: 'PAYMENT_SERVICE',
  useFactory: (flagService: FeatureFlagService) => {
    return flagService.isEnabled(FeatureFlag.NEW_CHECKOUT)
      ? new StripePaymentService()
      : new LegacyPaymentService();
  },
  inject: [FeatureFlagService],
};

**Kasus Penggunaan Nyata:** E-commerce platform — fitur "AI Product Recommendations" di-rolling out ke 5% users dulu. Jika metrik membaik (conversion rate naik), persentase dinaikkan ke 25%, 50%, 100%. Jika ada bug, kill switch langsung matikan fitur tanpa deploy.
