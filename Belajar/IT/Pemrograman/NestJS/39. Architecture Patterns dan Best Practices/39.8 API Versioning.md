# 39. Architecture Patterns dan Best Practices ## 39.8 API Versioning

**Definisi Singkat:** API Versioning memungkinkan API berkembang tanpa merusak client yang sudah ada. NestJS mendukung beberapa strategy: URI versioning, Header versioning, dan Media Type versioning.

**Analogi:** API Versioning seperti versi Android — Android 13 (v1), 14 (v2), 15 (v3) semuanya bisa berjalan bersamaan. Aplikasi lama yang build di API level 13 tetap jalan di device Android 15. Versi baru boleh punya fitur baru tanpa mengganggu yang lama.

**Poin-Poin Penting:**
- **URI Versioning** `/api/v1/users`, `/api/v2/users`
- **Header Versioning** `Accept: application/json; version=1`
- **Media Type Versioning** `Accept: application/vnd.myapp.v1+json`
- **enableVersioning()** method di main.ts
- **@Version()** decorator di controller/method
- **Default version** untuk backward compatibility

**Contoh Kode:**
```typescript
// main.ts — URI Versioning
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { VersioningType } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.enableVersioning({
    type: VersioningType.URI,
    prefix: 'api/v', // menghasilkan /api/v1/users
    defaultVersion: '1',
  });

  await app.listen(3000);
}
bootstrap();
```

```typescript
// main.ts — Header Versioning
app.enableVersioning({
  type: VersioningType.HEADER,
  header: 'X-API-Version', // X-API-Version: 1
  defaultVersion: '1',
});

// atau Media Type
app.enableVersioning({
  type: VersioningType.MEDIA_TYPE,
  key: 'v', // Accept: application/json;v=2
  defaultVersion: '1',
});
```

```typescript
// user.controller.ts — multi-version controller
import { Controller, Get, Param, Version } from '@nestjs/common';

@Controller('users')
export class UserController {
  // Method ini untuk v1 dan v2
  @Get()
  @Version(['1', '2'])
  findAll() {
    return [{ id: 1, name: 'John', email: 'john@example.com' }];
  }

  // Method ini hanya untuk v2
  @Get(':id')
  @Version('2')
  findOneV2(@Param('id') id: string) {
    return { id, name: 'John', email: 'john@example.com', profileComplete: true };
  }

  // Method ini hanya untuk v1
  @Get(':id')
  @Version('1')
  findOneV1(@Param('id') id: string) {
    return { id, name: 'John' };
  }
}
```

```typescript
// user-v2.controller.ts — controller khusus v2
import { Controller, Get, Param } from '@nestjs/common';

@Controller({
  path: 'users',
  version: '2',
})
export class UserV2Controller {
  @Get(':id')
  findOne(@Param('id') id: string) {
    return {
      id,
      name: 'John',
      email: 'john@example.com',
      avatar: 'https://example.com/avatar.jpg',
      joinedAt: '2024-01-01',
    };
  }
}
```

```typescript
// app.module.ts
import { Module } from '@nestjs/common';
import { UserController } from './user.controller';
import { UserV2Controller } from './user-v2.controller';
import { UserService } from './user.service';

@Module({
  controllers: [UserController, UserV2Controller],
  providers: [UserService],
})
export class UserModule {}
```

**Kasus Penggunaan Nyata:** Mobile API — v1 masih support untuk pengguna app versi lama yang belum update. v2 menambahkan field baru dan mengubah format response. NestJS route request ke controller yang sesuai berdasarkan version yang dikirim client.
