# 39. Architecture Patterns dan Best Practices ## 39.5 SOLID Principles dalam konteks NestJS

**Definisi Singkat:** SOLID adalah 5 prinsip desain OOP: Single Responsibility, Open-Closed, Liskov Substitution, Interface Segregation, Dependency Inversion. NestJS dengan dependency injection dan decorator sangat mendukung penerapan SOLID.

**Analogi:** SOLID seperti aturan organisasi perusahaan — setiap departemen punya satu tugas (S), divisi bisa ditambah tanpa mengubah existing (O), karyawan baru bisa gantikan senior tanpa chaos (L), departemen punya job desk spesifik bukan umum (I), atasan dan bawahan komunikasi via SOP (D).

**Poin-Poin Penting:**
- **S** Single Responsibility — satu class satu alasan berubah
- **O** Open-Closed — terbuka ekstensi, tertutup modifikasi
- **L** Liskov Substitution — subclass bisa gantikan parent
- **I** Interface Segregation — interface spesifik, bukan general
- **D** Dependency Inversion — depend ke abstraksi, bukan konkrit

**Contoh Kode:**
```typescript
// S — Single Responsibility Principle
// Controller hanya handle HTTP routing
@Controller('users')
export class UserController {
  constructor(private readonly userService: UserService) {}
  @Get(':id')
  findOne(@Param('id') id: string) {
    return this.userService.findById(id);
  }
}

// Service handle business logic
@Injectable()
export class UserService {
  constructor(private readonly userRepository: UserRepository) {}
  async findById(id: string) { return this.userRepository.findById(id); }
}

// Repository handle data access
@Injectable()
export class UserRepository {
  constructor(@InjectRepository(UserEntity) private repo: Repository<UserEntity>) {}
  async findById(id: string) { return this.repo.findOne({ where: { id } }); }
}
```

```typescript
// O — Open-Closed Principle
// Tambah payment method tanpa mengubah existing code
interface PaymentProcessor {
  process(amount: number, currency: string): Promise<PaymentResult>;
}

@Injectable()
export class StripeProcessor implements PaymentProcessor {
  async process(amount: number, currency: string): Promise<PaymentResult> {
    // Stripe integration
    return { success: true, transactionId: 'ch_xxx' };
  }
}

@Injectable()
export class MidtransProcessor implements PaymentProcessor {
  async process(amount: number, currency: string): Promise<PaymentResult> {
    // Midtrans integration
    return { success: true, transactionId: 'mt_xxx' };
  }
}

// PaymentService terbuka untuk processor baru tanpa modifikasi kode
@Injectable()
export class PaymentService {
  private processors: Map<string, PaymentProcessor> = new Map();

  constructor(
    private readonly stripe: StripeProcessor,
    private readonly midtrans: MidtransProcessor,
  ) {
    this.processors.set('stripe', stripe);
    this.processors.set('midtrans', midtrans);
  }

  async pay(method: string, amount: number, currency: string) {
    const processor = this.processors.get(method);
    if (!processor) throw new Error('Unsupported payment method');
    return processor.process(amount, currency);
  }
}
```

```typescript
// D — Dependency Inversion Principle
// Jangan: class Service { constructor(private repo: PostgresRepository) {} }
// Lakukan:
export interface UserRepository {
  findById(id: string): Promise<User | null>;
}

@Injectable()
export class PostgresUserRepository implements UserRepository {}

@Injectable()
export class MongoUserRepository implements UserRepository {}

// Service depend ke interface, bukan konkrit
@Injectable()
export class UserService {
  constructor(private readonly userRepository: UserRepository) {}
}
```

```typescript
// I — Interface Segregation
// Buruk: interface besar mencakup semua
interface UserOperations {
  create(dto: any): Promise<any>;
  findById(id: string): Promise<any>;
  update(id: string, dto: any): Promise<any>;
  delete(id: string): Promise<void>;
  sendEmail(userId: string): Promise<void>;
  generateReport(): Promise<any>;
}

// Baik: interface spesifik
interface UserRepository { findById(id: string): Promise<User | null>; create(data: any): Promise<User>; }
interface EmailService { sendWelcome(user: User): Promise<void>; }
interface ReportGenerator { generateUserReport(): Promise<any>; }
```

**Kasus Penggunaan Nyata:** Payment gateway integration — dengan OCP, menambah payment method baru (GoPay, DANA) cukup buat class baru implement PaymentProcessor, tidak perlu ubah PaymentService. DI modules cukup register processor baru.
