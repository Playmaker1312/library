# 23. Logging

## 23.6. Structured Logging (JSON format)

**Definisi Singkat:**
Structured Logging adalah praktik mencatat log dalam format terstruktur (biasanya JSON) yang memudahkan mesin untuk memparsing, mencari, dan menganalisis log secara otomatis.

**Analogi:**
Alih-alih menulis catatan di kertas dengan format bebas (unstructured), structured logging seperti mengisi form dengan kolom-kolom yang jelas (tanggal, kejadian, pelaku, lokasi) sehingga mudah dicari dan dianalisis.

**Poin-Poin Penting:**
- Format JSON dengan key-value pairs yang konsisten
- Memudahkan pencarian dan filtering dengan tools seperti Elasticsearch
- Dapat menyertakan metadata tambahan (requestId, userId, serviceName)
- Kompatibel dengan log management tools (ELK Stack, Datadog, New Relic)
- Winston dan Pino mendukung JSON secara native

**Contoh Kode:**
```typescript
// structured-logger.service.ts
import { Injectable, LoggerService } from '@nestjs/common';
import * as winston from 'winston';
import { utilities, WinstonModule } from 'nest-winston';

@Injectable()
export class StructuredLogger implements LoggerService {
  private logger: winston.Logger;

  constructor() {
    this.logger = winston.createLogger({
      level: process.env.LOG_LEVEL || 'info',
      format: winston.format.combine(
        winston.format.timestamp({ format: 'YYYY-MM-DD HH:mm:ss' }),
        winston.format.errors({ stack: true }),
        this.structuredFormat(),
      ),
      defaultMeta: {
        service: 'user-service',
        environment: process.env.NODE_ENV || 'development',
        version: process.env.npm_package_version || '1.0.0',
      },
      transports: [
        new winston.transports.Console({
          format: winston.format.combine(
            winston.format.colorize(),
            winston.format.printf((info) => {
              const { timestamp, level, message, ...meta } = info;
              const metaStr = Object.keys(meta).length > 0 
                ? JSON.stringify(meta, null, 2) 
                : '';
              return `[${timestamp}] ${level}: ${message} ${metaStr}`;
            }),
          ),
        }),
        new winston.transports.File({
          filename: 'logs/app.log',
          format: winston.format.json(),
        }),
      ],
    });
  }

  private structuredFormat() {
    return winston.format((info) => {
      const { level, message, timestamp, ...meta } = info;
      
      // Struktur log yang konsisten
      return {
        timestamp,
        level: level.toUpperCase(),
        message,
        ...meta,
      };
    })();
  }

  // Helper method untuk logging dengan metadata
  info(message: string, meta?: Record<string, any>) {
    this.logger.info(message, meta);
  }

  error(message: string, trace?: string, meta?: Record<string, any>) {
    this.logger.error(message, {
      ...meta,
      stack: trace,
    });
  }

  warn(message: string, meta?: Record<string, any>) {
    this.logger.warn(message, meta);
  }

  debug(message: string, meta?: Record<string, any>) {
    this.logger.debug(message, meta);
  }

  verbose(message: string, meta?: Record<string, any>) {
    this.logger.verbose(message, meta);
  }

  // Implementasi LoggerService interface
  log(message: any, ...optionalParams: any[]) {
    const meta = optionalParams.length > 0 ? optionalParams[0] : {};
    this.info(message, meta);
  }
}

// Menggunakan Structured Logger di Service
import { Injectable } from '@nestjs/common';
import { StructuredLogger } from './structured-logger.service';

@Injectable()
export class OrderService {
  constructor(private readonly logger: StructuredLogger) {}

  async createOrder(userId: string, orderData: any) {
    this.logger.info('Creating new order', {
      userId,
      orderItems: orderData.items,
      totalAmount: orderData.total,
      event: 'order.create',
    });

    try {
      // Validasi
      if (!orderData.items || orderData.items.length === 0) {
        this.logger.warn('Order created with no items', {
          userId,
          orderData,
          event: 'order.warning.empty_items',
        });
      }

      // Simulasi create order
      const orderId = 'ORD_' + Date.now();

      this.logger.info('Order created successfully', {
        orderId,
        userId,
        totalAmount: orderData.total,
        event: 'order.created',
        latency: 150,
      });

      return { orderId, status: 'success' };
    } catch (error) {
      this.logger.error('Failed to create order', error.stack, {
        userId,
        orderData,
        errorMessage: error.message,
        errorCode: error.code,
        event: 'order.create_failed',
      });
      throw error;
    }
  }
}

// Menggunakan Pino untuk structured logging
import { LoggerModule } from 'nestjs-pino';

@Module({
  imports: [
    LoggerModule.forRoot({
      pinoHttp: {
        base: {
          service: 'api-gateway',
          environment: process.env.NODE_ENV,
        },
        customProps: (req) => ({
          requestId: req.headers['x-request-id'],
          userId: req.user?.id,
        }),
        formatters: {
          level: (label) => ({ level: label.toUpperCase() }),
          log: (object) => object,
        },
        timestamp: () => `,"timestamp":"${new Date().toISOString()}"`,
      },
    }),
  ],
})
export class AppModule {}
```

**Kasus Penggunaan Nyata:**
Menyimpan log ke Elasticsearch untuk dianalisis dengan Kibana, mencari semua log yang berkaitan dengan `userId` tertentu dalam hitungan detik, membuat alert otomatis ketika ada lebih dari 10 error dengan `event: "payment.failed"` dalam 1 menit, dan melakukan root cause analysis dengan melacak semua log yang memiliki `correlationId` yang sama.
