# 23. Logging

## 23.7. Log Rotation

**Definisi Singkat:**
Log Rotation adalah mekanisme untuk mengelola file log agar tidak tumbuh tak terbatas, dengan cara membagi log berdasarkan ukuran atau waktu, dan menghapus log lama secara otomatis.

**Analogi:**
Seperti buku harian bulanan - setiap bulan mulai buku baru, dan buku yang terlalu lama bisa diarsipkan atau dibuang untuk menghemat ruang.

**Poin-Poin Penting:**
- Berdasarkan ukuran file (size-based) atau waktu (time-based)
- Tools populer: `winston-daily-rotate-file` untuk Winston
- Konfigurasi: max size, max files, date pattern, compression
- Penting untuk production environment mencegah disk full
- Dapat mengompres file lama untuk menghemat ruang

**Contoh Kode:**
```typescript
// Install: npm install winston-daily-rotate-file

// winston-rotation-logger.ts
import * as winston from 'winston';
import 'winston-daily-rotate-file';

const createRotatingLogger = () => {
  // Transport untuk error log - rotate setiap hari
  const errorTransport = new (winston.transports as any).DailyRotateFile({
    level: 'error',
    dirname: 'logs/errors',
    filename: 'error-%DATE%.log',
    datePattern: 'YYYY-MM-DD',
    maxSize: '20m',      // 20MB per file
    maxFiles: '14d',     // Simpan 14 hari terakhir
    zippedArchive: true, // Kompres file lama
    format: winston.format.combine(
      winston.format.timestamp(),
      winston.format.errors({ stack: true }),
      winston.format.json(),
    ),
  });

  // Transport untuk combined log - rotate setiap jam
  const combinedTransport = new (winston.transports as any).DailyRotateFile({
    level: 'info',
    dirname: 'logs/combined',
    filename: 'combined-%DATE%.log',
    datePattern: 'YYYY-MM-DD-HH',  // Rotate setiap jam
    maxSize: '50m',
    maxFiles: '7d',
    zippedArchive: true,
    format: winston.format.combine(
      winston.format.timestamp(),
      winston.format.json(),
    ),
  });

  // Console transport untuk development
  const consoleTransport = new winston.transports.Console({
    level: process.env.NODE_ENV === 'production' ? 'info' : 'debug',
    format: winston.format.combine(
      winston.format.colorize(),
      winston.format.timestamp({ format: 'YYYY-MM-DD HH:mm:ss' }),
      winston.format.printf(
        ({ timestamp, level, message, context, ...meta }) => {
          let log = `[${timestamp}] ${level}: ${message}`;
          if (context) log += ` [${context}]`;
          if (Object.keys(meta).length > 0) {
            log += ` ${JSON.stringify(meta)}`;
          }
          return log;
        },
      ),
    ),
  });

  // Event listener untuk rotasi (opsional)
  combinedTransport.on('rotate', (oldFilename: string, newFilename: string) => {
    console.log(`Rotating log file from ${oldFilename} to ${newFilename}`);
  });

  combinedTransport.on('archive', (zipFilename: string) => {
    console.log(`Log file archived: ${zipFilename}`);
  });

  return winston.createLogger({
    level: process.env.LOG_LEVEL || 'info',
    defaultMeta: {
      service: 'api-service',
      environment: process.env.NODE_ENV,
    },
    transports: [
      consoleTransport,
      errorTransport,
      combinedTransport,
    ],
    // Handle uncaught exceptions
    exceptionHandlers: [
      new (winston.transports as any).DailyRotateFile({
        dirname: 'logs/exceptions',
        filename: 'exceptions-%DATE%.log',
        datePattern: 'YYYY-MM-DD',
        maxSize: '10m',
        maxFiles: '30d',
        zippedArchive: true,
      }),
    ],
    // Handle unhandled promise rejections
    rejectionHandlers: [
      new (winston.transports as any).DailyRotateFile({
        dirname: 'logs/rejections',
        filename: 'rejections-%DATE%.log',
        datePattern: 'YYYY-MM-DD',
        maxSize: '10m',
        maxFiles: '30d',
        zippedArchive: true,
      }),
    ],
    exitOnError: false, // Jangan exit setelah menangkap exception
  });
};

export const rotatingLogger = createRotatingLogger();

// pino-rotation.config.ts
import * as pino from 'pino';

const pinoLogger = pino({
  level: process.env.LOG_LEVEL || 'info',
  transport: {
    target: 'pino-rotation-file',
    options: {
      file: 'logs/pino-app.log',
      // Rotate setiap hari pada jam 00:00
      period: '1d',
      // Atau berdasarkan ukuran: 10MB
      // size: '10m',
      // Simpan maksimal 10 file
      maxFiles: 10,
      // Kompres file lama
      compress: 'gzip',
    },
  },
  base: {
    service: 'user-service',
    env: process.env.NODE_ENV,
  },
  timestamp: () => `,"time":"${new Date().toISOString()}"`,
});

export { pinoLogger };

├── exceptions/
│   └── exceptions-2024-01-15.log
└── rejections/
    └── rejections-2024-01-15.log
*/

// ========== Service menggunakan rotating logger ==========
import { Injectable } from '@nestjs/common';
import { WINSTON_MODULE_PROVIDER } from 'nest-winston';
import { Logger } from 'winston';
import { Inject } from '@nestjs/common';

@Injectable()
export class HighVolumeService {
  constructor(
    @Inject(WINSTON_MODULE_PROVIDER) private readonly logger: Logger,
  ) {}

  async processTransaction(transactionId: string, data: any) {
    this.logger.info('Processing transaction', {
      transactionId,
      amount: data.amount,
      timestamp: new Date().toISOString(),
    });

    try {
      // High volume logic
      for (let i = 0; i < 1000; i++) {
        // Proses item...
        if (i % 100 === 0) {
          this.logger.debug(`Processed ${i} items`, { transactionId });
        }
      }

      this.logger.info('Transaction completed', {
        transactionId,
        itemsProcessed: 1000,
        duration: 150,
      });
    } catch (error) {
      this.logger.error('Transaction failed', {
        transactionId,
        error: error.message,
        stack: error.stack,
      });
      throw error;
    }
  }
}
```

**Kasus Penggunaan Nyata:**
Pada aplikasi e-commerce dengan 1 juta request per hari, log bisa tumbuh hingga 5GB per hari. Dengan log rotation:
- Setiap file log maksimal 50MB
- Rotate setiap jam atau ketika mencapai ukuran
- Simpan hanya 7 hari terakhir
- File lama dikompres menjadi .gz (hemat 80-90% ruang)
- Mencegah disk full yang bisa menyebabkan aplikasi crash
