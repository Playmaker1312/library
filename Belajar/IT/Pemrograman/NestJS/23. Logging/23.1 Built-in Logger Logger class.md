# 23. Logging

## 23.1. Built-in Logger: Logger class

**Definisi Singkat:**
Logger class adalah komponen bawaan NestJS untuk mencatat pesan log dengan berbagai tingkat keparahan (log levels). Berdasarkan kelas `Logger` dari `@nestjs/common`.

**Analogi:**
Seperti buku catatan yang mencatat semua kejadian penting di aplikasi, mulai dari informasi umum hingga error kritis.

**Poin-Poin Penting:**
- Import dari `@nestjs/common`
- Dapat di-inject menggunakan `@InjectLogger()` decorator
- Mendukung multiple log contexts
- Dapat digunakan di service, controller, atau komponen mana pun
- Metode: `log()`, `error()`, `warn()`, `debug()`, `verbose()`, `fatal()`

**Contoh Kode:**
```typescript
import { Injectable, Logger, Inject } from '@nestjs/common';

@Injectable()
export class UserService {
  private readonly logger = new Logger(UserService.name);

  constructor(@Inject('USER_REPOSITORY') private userRepository: any) {}

  async findAll() {
    this.logger.log('Fetching all users');
    
    try {
      const users = await this.userRepository.find();
      this.logger.verbose(`Found ${users.length} users`);
      return users;
    } catch (error) {
      this.logger.error('Failed to fetch users', error.stack);
      throw error;
    }
  }

  async create(userData: any) {
    this.logger.debug(`Creating user with data: ${JSON.stringify(userData)}`);
    
    try {
      const user = await this.userRepository.save(userData);
      this.logger.log(`User created with ID: ${user.id}`);
      return user;
    } catch (error) {
      this.logger.error(`Failed to create user: ${error.message}`);
      throw error;
    }
  }
}

// Dengan InjectLogger decorator
import { Injectable } from '@nestjs/common';
import { InjectLogger, Logger } from '@nestjs/common';

@Injectable()
export class ProductService {
  constructor(@InjectLogger('ProductModule') private logger: Logger) {}

  updateProduct(id: number, data: any) {
    this.logger.log(`Updating product #${id}`);
  }
}

// Di main.ts untuk mengkonfigurasi logger global
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { Logger } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule, {
    logger: ['log', 'error', 'warn', 'debug', 'verbose'],
  });
  
  const logger = new Logger('Bootstrap');
  const port = 3000;
  
  await app.listen(port);
  logger.log(`Application running on port ${port}`);
}
bootstrap();
```

**Kasus Penggunaan Nyata:**
Mencatat setiap permintaan API yang masuk (endpoint, method, response time), mencatat error ketika database gagal terkoneksi, atau melacak aktivitas user untuk keperluan audit trail di sistem e-commerce.
