# 23. Logging

## 23.2. Log Levels: log, error, warn, debug, verbose

**Definisi Singkat:**
Log levels adalah tingkatan prioritas pesan log yang membantu memfilter dan mengelola output log berdasarkan tingkat kepentingannya (dari yang paling penting ke kurang penting).

**Analogi:**
Seperti alarm di rumah: tingkat "fatal" seperti alarm kebakaran (paling penting), "debug" seperti catatan harian (hanya untuk development).

**Poin-Poin Penting:**
- Urutan tingkat (dari tertinggi ke terendah): `fatal`, `error`, `warn`, `log`, `debug`, `verbose`
- Level default: `['log', 'error', 'warn', 'fatal']`
- Dapat dikonfigurasi saat bootstrap aplikasi
- Setiap level mencakup level di atasnya
- `fatal` (v10+): untuk error kritis yang menghentikan aplikasi

**Contoh Kode:**
```typescript
// main.ts - Konfigurasi log levels
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { Logger, LogLevel } from '@nestjs/common';

async function bootstrap() {
  // Menentukan log levels berdasarkan environment
  const isProduction = process.env.NODE_ENV === 'production';
  
  const logLevels: LogLevel[] = isProduction
    ? ['log', 'error', 'warn', 'fatal']  // Production: hanya level penting
    : ['log', 'error', 'warn', 'debug', 'verbose', 'fatal'];  // Development: semua

  const app = await NestFactory.create(AppModule, {
    logger: logLevels,
  });

  // Atau menggunakan boolean untuk enable/disable
  // logger: false,  // Matikan semua log
  // logger: console, // Gunakan console sebagai logger

  await app.listen(3000);
}
bootstrap();

// Service dengan berbagai log levels
import { Injectable, Logger } from '@nestjs/common';

@Injectable()
export class PaymentService {
  private readonly logger = new Logger(PaymentService.name);

  processPayment(amount: number, cardNumber: string) {
    // verbose: Detail paling rendah, untuk tracing mendalam
    this.logger.verbose(`Processing payment: amount=${amount}, cardMask=****${cardNumber.slice(-4)}`);

    // debug: Untuk development, informasi debug
    this.logger.debug(`Payment processor initialized for amount: ${amount}`);

    try {
      if (amount <= 0) {
        // warn: Peringatan, tidak menghentikan flow
        this.logger.warn(`Attempted payment with invalid amount: ${amount}`);
        throw new Error('Invalid payment amount');
      }

      // log: Informasi umum, operasi normal
      this.logger.log(`Processing payment of $${amount}`);

      // Simulasi sukses
      const transactionId = 'TXN_' + Date.now();
      this.logger.log(`Payment successful. Transaction ID: ${transactionId}`);

      return { success: true, transactionId };
    } catch (error) {
      // error: Error yang perlu ditangani
      this.logger.error(
        `Payment processing failed: ${error.message}`,
        error.stack,  // Stack trace (opsional)
        'PaymentService.processPayment'  // Context tambahan
      );
      throw error;
    }
  }

  criticalFailure() {
    // fatal: Error kritis (NestJS v10+)
    this.logger.fatal('Database connection failed - application cannot continue');
    process.exit(1);
  }
}

// Mengubah log level secara runtime
import { LoggerService } from '@nestjs/common';

@Injectable()
export class LogLevelService {
  constructor(private logger: LoggerService) {}

  updateLogLevels() {
    // Menggunakan Logger instance untuk mengubah level
    const customLogger = this.logger as any;
    if (customLogger.setLogLevels) {
      customLogger.setLogLevels(['log', 'error', 'warn', 'debug']);
    }
  }
}
```

**Kasus Penggunaan Nyata:**
Di environment production, hanya menampilkan `log`, `error`, `warn` untuk mengurangi noise, sementara di development menampilkan semua level termasuk `debug` dan `verbose` untuk debugging. Ketika ada issue di production, bisa mengaktifkan `debug` sementara tanpa restart aplikasi.
