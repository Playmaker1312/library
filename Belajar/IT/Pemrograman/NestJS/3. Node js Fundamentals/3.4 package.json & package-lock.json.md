## 3.4 package.json & package-lock.json

### Definisi Singkat

**`package.json`** adalah file manifes yang berisi informasi umum proyek dan daftar pustaka (_library_) yang dibutuhkan. **`package-lock.json`** adalah catatan teknis yang sangat detail tentang versi spesifik dan struktur pohon setiap pustaka yang terinstal.

### Analogi

Bayangkan kamu ingin merakit sebuah **Lego (Proyek NestJS)**:

- **`package.json`** adalah **Buku Instruksi Utama**. Di situ tertulis: "Kamu butuh 4 roda besar, 2 kaca depan, dan 1 mesin." Ini adalah daftar belanja umum.
    
- **`package-lock.json`** adalah **Kwitansi Gudang yang Sangat Detail**. Di situ tertulis: "Roda besar merek X seri 1.0.2 diproduksi pabrik A tanggal sekian, kaca depan merek Y seri 2.1.0 dari pabrik B." Ini memastikan jika temanmu merakit Lego yang sama, dia mendapatkan barang yang **identik** hingga ke baut terkecilnya.
    

### Poin-Poin Penting

- **`package.json`**:
    
    - **Scripts**: Berisi perintah pendek (seperti `npm run start:dev`) untuk menjalankan aplikasi NestJS.
        
    - **Dependencies**: Daftar library yang dibutuhkan agar aplikasi bisa berjalan (misal: `@nestjs/core`).
        
    - **DevDependencies**: Library yang hanya dibutuhkan saat _coding_ (seperti TypeScript atau alat tes), tapi tidak dibawa ke server produksi.
        
- **`package-lock.json`**:
    
    - Dibuat otomatis oleh NPM saat kamu menginstal sesuatu.
        
    - Mengunci versi library agar tidak berubah secara otomatis saat ada update kecil (mencegah kode rusak tiba-tiba).
        
    - Berisi _hash_ keamanan untuk memastikan file library yang diunduh tidak dimodifikasi oleh pihak jahat.
        

### Contoh Implementasi

Potongan isi **`package.json`** di proyek NestJS:

JSON

```
{
  "name": "my-nest-app",
  "version": "1.0.0",
  "scripts": {
    "start:dev": "nest start --watch"
  },
  "dependencies": {
    "@nestjs/common": "^10.0.0",
    "reflect-metadata": "^0.1.13"
  },
  "devDependencies": {
    "typescript": "^5.0.0"
  }
}
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, kedua file ini sangat krusial karena:

1. **Automation**: NestJS CLI menggunakan `package.json` untuk mengetahui skrip mana yang harus dijalankan saat kamu mengetik `nest start`.
    
2. **Deployment**: Saat kamu mengunggah kode ke server (seperti Docker), server akan menjalankan `npm ci` yang membaca `package-lock.json` untuk menjamin aplikasi berjalan dengan lingkungan yang sama persis seperti di laptopmu.
    
3. **Security Audit**: NPM bisa memindai `package-lock.json` untuk mencari apakah ada library yang memiliki celah keamanan (vulnerability) dan memberitahumu untuk segera memperbaikinya.
