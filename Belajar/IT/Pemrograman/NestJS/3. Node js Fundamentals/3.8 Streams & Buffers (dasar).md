## 3.8 Streams & Buffers (Dasar)

### Definisi Singkat

**Buffer** adalah ruang penyimpanan sementara (memori) yang menampung data mentah dalam bentuk biner sebelum diproses. **Stream** adalah aliran data yang dikirimkan secara bertahap (potongan demi potongan) dari satu tempat ke tempat lain tanpa harus menunggu seluruh data siap di memori.

### Analogi

Bayangkan kamu sedang menonton sebuah **Film**:

- **Buffer**: Seperti saat kamu mendownload seluruh file film (misal 2GB) sampai selesai, baru kemudian kamu menontonnya. Laptopmu harus punya sisa RAM minimal 2GB untuk menampung file itu. Jika file-nya 100GB, laptopmu mungkin akan meledak (_crash_).
    
- **Stream**: Seperti **YouTube/Netflix Streaming**. Kamu tidak perlu menunggu seluruh film terdownload. Komputer hanya mengambil potongan kecil (misal 5MB), memutarnya, membuang potongan yang sudah ditonton, lalu mengambil potongan berikutnya. Hemat memori dan sangat cepat.
    

### Poin-Poin Penting

- **Buffer**: Bekerja dengan data biner (0 dan 1). Digunakan saat kita perlu memanipulasi data sebelum diproses sepenuhnya.
    
- **Stream (Writable, Readable, Duplex, Transform)**:
    
    - _Readable_: Aliran untuk membaca data (misal: membaca file).
        
    - _Writable_: Aliran untuk menulis data (misal: menulis ke file).
        
- **Pipe (`.pipe()`)**: Menghubungkan _Readable Stream_ langsung ke _Writable Stream_. Bayangkan seperti menyambungkan selang air dari keran ke ember.
    
- **Memory Efficiency**: Dengan Stream, Node.js bisa memproses file berukuran 10GB meskipun server hanya memiliki RAM 512MB.
    

### Contoh Implementasi

Berikut adalah perbandingan membaca file besar menggunakan cara biasa vs Stream:

JavaScript

```
const fs = require('fs');

// --- Cara Biasa (Memenuhi RAM) ---
fs.readFile('video_besar.mp4', (err, data) => {
    if (err) throw err;
    // 'data' di sini adalah Buffer yang berisi seluruh file video
    console.log('Seluruh file sudah masuk RAM');
});

// --- Cara Stream (Efisien) ---
const reader = fs.createReadStream('video_besar.mp4');

reader.on('data', (chunk) => {
    // 'chunk' adalah potongan kecil file yang masuk satu per satu
    console.log(`Menerima potongan data sebesar: ${chunk.length} bytes`);
});

reader.on('end', () => {
    console.log('Selesai membaca seluruh file secara bertahap.');
});
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, konsep ini sangat krusial saat kamu membuat:

1. **File Download/Export**: Saat user mendownload laporan PDF atau Excel yang sangat besar, kamu akan mengirimkannya sebagai Stream agar server tidak terbebani.
    
2. **File Upload**: Saat user mengunggah foto atau video, NestJS (via Multer) bisa memproses file tersebut sebagai Stream untuk langsung disimpan ke Cloud (seperti AWS S3) tanpa menyimpannya di memori server terlebih dahulu.
    
3. **Video Streaming**: Jika kamu membangun aplikasi seperti Netflix sederhana, kamu akan menggunakan _Stream_ untuk mengirimkan data video ke browser secara bertahap.
    
4. **Logging**: Sistem log yang terus-menerus menulis ke file biasanya menggunakan _Writable Stream_.
