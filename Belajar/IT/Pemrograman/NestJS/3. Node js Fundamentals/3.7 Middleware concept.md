## 3.7 Middleware Concept

### Definisi Singkat

**Middleware** adalah sebuah fungsi yang dipanggil **sebelum** _route handler_ (logika utama di Controller) dieksekusi. Fungsi ini memiliki akses ke objek permintaan (_request_), objek tanggapan (_response_), dan fungsi berikutnya (`next()`) dalam siklus permintaan-tanggapan aplikasi.

### Analogi

Bayangkan kamu sedang mengunjungi sebuah **Gedung Perkantoran Mewah**:

- **User Request**: Adalah kamu yang ingin masuk ke gedung tersebut.
    
- **Middleware**: Adalah **Petugas Keamanan (Security)** di lobi.
    
    - Mereka mengecek identitasmu (**Authentication**).
        
    - Mereka mencatat jam kedatanganmu di buku tamu (**Logging**).
        
    - Mereka memastikan kamu memakai pakaian yang rapi (**Validation**).
        
- **Next()**: Jika semua oke, petugas berkata "Silakan masuk ke lift nomor 4". Kamu lanjut ke tujuan utama.
    
- **Blocking**: Jika kamu tidak punya ID, petugas menghentikanmu di lobi dan kamu tidak pernah sampai ke kantor tujuan.
    

### Poin-Poin Penting

- **Akses Penuh**: Middleware bisa melihat semua data yang dikirim user (Header, Body, Query).
    
- **Modifikasi Data**: Middleware bisa mengubah objek `req` atau `res` sebelum sampai ke Controller (misalnya menambahkan data user yang sedang login).
    
- **Fungsi `next()`**: Ini adalah instruksi paling krusial. Jika Middleware tidak memanggil `next()`, permintaan akan "tergantung" selamanya dan tidak akan pernah sampai ke Controller.
    
- **Urutan Eksekusi**: Middleware dijalankan secara berurutan. Middleware yang didaftarkan pertama akan berjalan lebih dulu.
    

### Contoh Implementasi

Berikut adalah gambaran sederhana Middleware dalam JavaScript/Node.js:

JavaScript

```
function loggerMiddleware(req, res, next) {
    console.log(`[${new Date().toISOString()}] Request ke: ${req.url}`);
    
    // Melanjutkan ke proses berikutnya
    next(); 
}

// Contoh Middleware untuk memblokir akses
function authMiddleware(req, res, next) {
    const token = req.headers['authorization'];
    
    if (token === 'RAHASIA123') {
        next(); // Token benar, lanjut!
    } else {
        res.status(401).send('Akses Ditolak: Token Salah'); // Berhenti di sini
    }
}
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, Middleware digunakan untuk tugas-tugas yang sifatnya umum (_cross-cutting concerns_):

1. **Logging**: Mencatat setiap aktivitas user yang masuk ke server untuk keperluan audit atau _debugging_.
    
2. **Authentication**: Memeriksa apakah user sudah login (misal mengecek JWT Token) sebelum mengizinkan mereka mengakses data sensitif.
    
3. **Request Transformation**: Melakukan _parsing_ atau pembersihan data (sanitasi) pada body request agar aman dari serangan seperti XSS.
    
4. **Compression**: Mengecilkan ukuran data yang dikirim balik ke user agar website terasa lebih cepat.
