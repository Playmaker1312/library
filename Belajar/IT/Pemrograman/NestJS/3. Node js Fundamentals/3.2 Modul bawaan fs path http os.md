# 3. Node.js Fundamentals

## 3.2. Modul Bawaan: `fs`, `path`, `http`, `os`

**Definisi Singkat:** Node.js menyediakan modul bawaan untuk operasi umum: `fs` (file system), `path` (manipulasi path), `http` (server/client HTTP), `os` (informasi sistem operasi).

**Analogi:** Seperti toolkit tukang — `fs` adalah gergaji (potong file), `path` adalah meteran (ukur jalur), `http` adalah telepon (komunikasi), `os` adalah buku manual rumah (info lingkungan).

**Poin-Poin Penting:**
- `fs.promises` API untuk async/await — `readFile`, `writeFile`, `unlink`
- `path.join()` dan `path.resolve()` untuk cross-platform path
- `http.createServer()` untuk HTTP server dasar (NestJS abstraction di atas ini)
- `os.cpus()`, `os.totalmem()` untuk system info
- NestJS biasanya tidak langsung menggunakan modul ini, tapi penting untuk scripts dan config

**Contoh Kode:**
```typescript
import * as fs from 'fs/promises';
import * as path from 'path';
import * as os from 'os';

// Config loader — membaca file konfigurasi
async function loadConfig(): Promise<Record<string, unknown>> {
  const configPath = path.join(process.cwd(), 'config.json');
  const raw = await fs.readFile(configPath, 'utf-8');
  return JSON.parse(raw);
}

// Logger dengan info sistem
function logSystemInfo(): void {
  console.log({
    platform: os.platform(),
    cpus: os.cpus().length,
    memory: `${(os.totalmem() / 1024 / 1024 / 1024).toFixed(2)} GB`,
    hostname: os.hostname(),
    uptime: `${(os.uptime() / 3600).toFixed(1)} hours`,
  });
}

// HTTP module — dasar dari NestJS HTTP layer
import { createServer, IncomingMessage, ServerResponse } from 'http';

const server = createServer((req: IncomingMessage, res: ServerResponse) => {
  res.writeHead(200, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({ message: 'Hello from Node.js' }));
});
```

**Kasus Penggunaan Nyata:**
`fs` untuk file uploads/static files, `path` untuk asset routing, `os` untuk health check endpoint / cluster management, `http` untuk health check server terpisah. NestJS menggunakan modul-modul ini di internal.
