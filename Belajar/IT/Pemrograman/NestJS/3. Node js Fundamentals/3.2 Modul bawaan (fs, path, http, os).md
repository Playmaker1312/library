## 3.2 Modul Bawaan (fs, path, http, os)

### Definisi Singkat

Modul bawaan adalah _library_ standar Node.js yang menyediakan fungsi dasar untuk berinteraksi dengan sistem operasi, mengelola file, menangani jalur direktori, dan membuat server web.

### Analogi

Bayangkan Node.js adalah sebuah **Smartphone Baru**:

- **`os`**: Seperti menu "Settings > About Phone" yang memberi tahu spesifikasi baterai dan RAM.
    
- **`fs`**: Seperti aplikasi "File Manager" untuk membuka, mengedit, atau menghapus foto dan dokumen.
    
- **`path`**: Seperti sistem navigasi/folder yang memastikan kamu tidak salah menaruh file di folder "Download" atau "DCIM".
    
- **`http`**: Seperti antena sinyal yang memungkinkan HP berkomunikasi dengan dunia luar melalui internet.
    

### Poin-Poin Penting

- **`fs` (File System)**: Digunakan untuk operasi I/O (Input/Output) file. Tersedia dalam versi sinkronus (blocking) dan asinkronus (non-blocking).
    
- **`path`**: Membantu mengelola jalur file/folder agar kode kamu bisa berjalan di Windows (yang pakai backslash `\`) maupun Linux/Mac (yang pakai forward slash `/`).
    
- **`http`**: Dasar dari semua framework web Node.js. Modul ini memungkinkan Node.js menerima dan mengirim data melalui protokol HTTP.
    
- **`os` (Operating System)**: Menyediakan informasi mengenai sistem operasi komputer tempat aplikasi berjalan (jumlah CPU, memori bebas, nama host, dll).
    

### Contoh Implementasi

JavaScript

```
// Mengimpor modul bawaan
const fs = require('fs');
const path = require('path');
const os = require('os');

// 1. OS: Cek sisa memori dalam Gigabyte
const freeMemory = os.freemem() / 1024 / 1024 / 1024;
console.log(`Sisa RAM: ${freeMemory.toFixed(2)} GB`);

// 2. PATH: Menggabungkan folder dengan aman
const fullPath = path.join(__dirname, 'data', 'catatan.txt');
console.log(`Lokasi file: ${fullPath}`);

// 3. FS: Menulis file secara asinkronus
fs.writeFile(fullPath, 'Halo dari Node.js!', (err) => {
    if (err) throw err;
    console.log('File berhasil disimpan!');
});
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, modul-modul ini biasanya tidak dipanggil secara mentah, tapi tetap sangat krusial:

1. **File Upload**: Saat kamu membuat fitur unggah foto di NestJS, kamu akan menggunakan modul `fs` (atau library yang berbasis `fs`) untuk menyimpan file tersebut ke folder server.
    
2. **Static Files**: NestJS menggunakan modul `path` untuk menentukan di mana letak folder "public" agar gambar atau file CSS bisa diakses melalui browser.
    
3. **Cross-Platform**: Dengan modul `path`, aplikasi NestJS yang kamu buat di Windows akan tetap berjalan lancar saat dideploy ke server Linux (seperti AWS atau DigitalOcean).
    
4. **Under the Hood**: Framework seperti Express (yang digunakan NestJS secara default) sebenarnya adalah abstraksi tingkat tinggi yang dibangun di atas modul `http`.
