# 3. Node.js Fundamentals

## 3.8. Streams dan Buffers Dasar

**Definisi Singkat:** Stream adalah sequence data yang tersedia seiring waktu — membaca/menulis data secara bertahap, bukan sekaligus. Buffer adalah penyimpanan sementara data biner di memori.

**Analogi:** Stream seperti air ledeng — Anda buka kran, air mengalir terus tanpa harus menampung seluruh sungai di bak mandi. Buffer seperti gelas — menampung air sementara sebelum diminum.

**Poin-Poin Penting:**
- 4 jenis stream: Readable, Writable, Duplex, Transform
- `pipe()` menghubungkan stream — readable.pipe(writable)
- Stream cocok untuk file besar, network response, video
- Buffer diperlukan untuk binary data (file, image, encoding)
- NestJS menggunakan stream untuk file upload, response streaming
- Stream menghemat memory dibanding load seluruh data

**Contoh Kode:**
```typescript
import { createReadStream, createWriteStream } from 'fs';
import { Transform, pipeline } from 'stream';
import { promisify } from 'util';

const pipelineAsync = promisify(pipeline);

// Transform stream — uppercase converter
const upperCaseTransform = new Transform({
  transform(chunk: Buffer, encoding: string, callback: Function) {
    this.push(chunk.toString().toUpperCase());
    callback();
  },
});

// Stream file besar — tanpa load seluruh file ke memory
async function streamFile(): Promise<void> {
  await pipelineAsync(
    createReadStream('input.txt', { encoding: 'utf-8' }),
    upperCaseTransform,
    createWriteStream('output.txt'),
  );
  console.log('File processed via stream');
}

// Buffer dasar — untuk binary data
const buffer = Buffer.from('Hello NestJS', 'utf-8');
console.log(buffer.toString());       // 'Hello NestJS'
console.log(buffer.byteLength);       // 12 bytes
console.log(buffer.toJSON());          // byte array

// NestJS file upload — menggunakan stream
import { Injectable } from '@nestjs/common';
import { createWriteStream } from 'fs';

@Injectable()
export class FileService {
  async uploadFile(file: Express.Multer.File): Promise<string> {
    const path = `./uploads/${Date.now()}-${file.originalname}`;
    // file.buffer bisa di-stream ke disk
    const writer = createWriteStream(path);
    writer.write(file.buffer);
    writer.end();
    return path;
  }
}
```

**Kasus Penggunaan Nyata:**
Streaming file upload/download di NestJS (FileInterceptor), streaming large JSON/CSV responses, piping database query results ke HTTP response, processing media files (video/audio) tanpa memory penuh.
