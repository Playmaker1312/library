# 3. Node.js Fundamentals

## 3.6. Membuat HTTP Server Sederhana Tanpa Framework

**Definisi Singkat:** Node.js `http` module dapat membuat web server tanpa framework. Memahami ini membantu mengapresiasi apa yang NestJS otomatisasi — routing, parsing, middleware, error handling.

**Analogi:** Seperti membangun restoran dari nol — Anda harus membuat meja, kursi, dapur, kasir sendiri. NestJS menyediakan semua furnitur siap pakai.

**Poin-Poin Penting:**
- `http.createServer()` menerima callback `(req, res) => {}`
- Manual routing dengan `req.url` dan `req.method`
- Manual parsing body dengan `req.on('data')` dan `req.on('end')`
- Manual setting `Content-Type` dan status codes
- NestJS mengabstraksi semua ini dengan decorators dan modules

**Contoh Kode:**
```typescript
import { createServer, IncomingMessage, ServerResponse } from 'http';
import { readFile } from 'fs/promises';
import { parse } from 'url';

const server = createServer(async (req: IncomingMessage, res: ServerResponse) => {
  const { pathname } = parse(req.url || '', true);

  // Manual routing — NestJS @Controller @Get melakukan ini otomatis
  if (req.method === 'GET' && pathname === '/users') {
    const users = JSON.parse(await readFile('./users.json', 'utf-8'));
    res.writeHead(200, { 'Content-Type': 'application/json' });
    res.end(JSON.stringify(users));
  } else if (req.method === 'POST' && pathname === '/users') {
    let body = '';
    req.on('data', (chunk) => (body += chunk));
    req.on('end', () => {
      const user = JSON.parse(body);
      res.writeHead(201, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ ...user, id: Date.now() }));
    });
  } else {
    res.writeHead(404);
    res.end('Not Found');
  }
});

server.listen(3000, () => console.log('Server running on port 3000'));
```

**Kasus Penggunaan Nyata:**
NestJS menggunakan Express/Fastify sebagai HTTP adapter. Dengan memahami HTTP server dasar, Anda bisa lebih mudah mengerti middleware, guards, interceptors, dan error handling yang disediakan NestJS.
