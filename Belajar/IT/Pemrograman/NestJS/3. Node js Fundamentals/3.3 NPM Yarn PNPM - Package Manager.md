# 3. Node.js Fundamentals

## 3.3. NPM, Yarn, PNPM — Package Manager

**Definisi Singkat:** Package manager mengelola dependensi project JavaScript/TypeScript. NPM (default), Yarn (Meta), PNPM (space-efficient) — NestJS CLI menggunakan NPM secara default, bisa dikonfigurasi ke Yarn/PNPM.

**Analogi:** Seperti supermarket aplikasi — Anda datang dengan daftar belanja (package.json), kasir (CLI) mengambil barang dari gudang (registry), dan Anda pulang dengan belanjaan (node_modules).

**Poin-Poin Penting:**
- `npm install <package>` — instal dependensi
- `npm install -g @nestjs/cli` — global instalasi NestJS CLI
- `package.json` mencatat dependensi dan scripts
- `node_modules` — folder berisi semua dependensi terinstal
- PNPM menggunakan hard links — hemat disk space
- lockfile (`package-lock.json`, `yarn.lock`) mengunci versi eksak

**Contoh Kode:**
```bash
# NPM — membuat project NestJS
npm install -g @nestjs/cli
nest new my-project

# Yarn
yarn global add @nestjs/cli
yarn create nest-app my-project

# PNPM
pnpm add -g @nestjs/cli
pnpm create nest-app my-project

# Menambah dependensi
npm install @nestjs/config
npm install -D @types/node typescript

# Menjalankan script
npm run start:dev
```

**Kasus Penggunaan Nyata:**
Setiap project NestJS menggunakan package manager. Pilih NPM untuk default, Yarn untuk monorepo (workspaces), PNPM untuk tim dengan banyak project — disk space efisien dan install lebih cepat.
