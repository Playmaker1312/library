# 3. Node.js Fundamentals

## 3.1. Apa itu Node.js dan Event Loop

**Definisi Singkat:** Node.js adalah runtime JavaScript berbasis V8 engine yang menggunakan event loop non-blocking I/O untuk menangani ribuan koneksi simultan dalam satu thread. NestJS berjalan di atas Node.js.

**Analogi:** Seperti barista di kafe — satu orang (single thread) menerima pesanan, menyuruh mesin kopi bekerja (I/O), lalu melayani pelanggan lain sambil menunggu. Event loop adalah sistem gilirannya.

**Poin-Poin Penting:**
- Single-threaded dengan event loop untuk concurrency
- Non-blocking I/O — operasi seperti file/database tidak menghentikan eksekusi
- Event loop phases: timers → pending callbacks → idle → poll → check → close
- `process.nextTick()` dan `Promise microtask` jalan di antara phases
- NestJS menggunakan async/await yang memanfaatkan event loop

**Contoh Kode:**
```typescript
// Event loop demonstration
function eventLoopPhases() {
  console.log('1. Synchronous code — langsung jalan');

  setTimeout(() => console.log('2. Timer phase (setTimeout)'), 0);

  Promise.resolve().then(() => console.log('3. Microtask (Promise.then)'));

  process.nextTick(() => console.log('4. Next tick — sebelum microtask'));

  setImmediate(() => console.log('5. Check phase (setImmediate)'));

  console.log('6. Masih synchronous — sebelum event loop mulai');
}

// Non-blocking I/O — NestJS pattern
import { Injectable } from '@nestjs/common';

@Injectable()
export class DataService {
  async getData(): Promise<string> {
    // Non-blocking — tidak menghentikan event loop
    const data = await this.fetchFromDatabase();
    return data;
  }

  private fetchFromDatabase(): Promise<string> {
    return new Promise(resolve => {
      setTimeout(() => resolve('Data from DB'), 100);
    });
  }
}
```

**Kasus Penggunaan Nyata:**
NestJS HTTP server menggunakan event loop untuk melayani ribuan request. Setiap request async memanfaatkan event loop — database query, file read, API call external tidak saling memblokir.
