# 3. Node.js Fundamentals

## 3.4. `package.json` dan `package-lock.json`

**Definisi Singkat:** `package.json` adalah manifest project — berisi metadata, dependensi, scripts, dan konfigurasi. `package-lock.json` mengunci versi eksak setiap dependensi dan sub-dependensi untuk reproducible builds.

**Analogi:** `package.json` seperti daftar bahan resep — tepung, telur, gula (tanpa jumlah pasti). `package-lock.json` seperti resep detail — 250g tepung, 2 telur ukuran besar, 100g gula pasir — hasilnya selalu sama.

**Poin-Poin Penting:**
- `dependencies` — runtime dependencies (NestJS, RxJS, dll)
- `devDependencies` — dev-only (TypeScript, ts-node, ESLint)
- `scripts` — `start`, `build`, `test`, `lint`
- Semver: `^1.0.0` (major), `~1.0.0` (minor), `1.0.0` (exact)
- `package-lock.json` harus di-commit ke git
- NestJS CLI menambahkan script `start:dev`, `start:prod`, `build`

**Contoh Kode:**
```json
{
  "name": "my-nestjs-api",
  "version": "1.0.0",
  "description": "NestJS REST API",
  "private": true,
  "scripts": {
    "build": "nest build",
    "start": "nest start",
    "start:dev": "nest start --watch",
    "start:prod": "node dist/main",
    "lint": "eslint \"{src,test}/**/*.ts\"",
    "test": "jest",
    "test:e2e": "jest --config ./test/jest-e2e.json"
  },
  "dependencies": {
    "@nestjs/common": "^10.0.0",
    "@nestjs/core": "^10.0.0",
    "@nestjs/platform-express": "^10.0.0",
    "reflect-metadata": "^0.1.13",
    "rxjs": "^7.8.0"
  },
  "devDependencies": {
    "@nestjs/cli": "^10.0.0",
    "@types/node": "^20.0.0",
    "typescript": "^5.0.0"
  }
}
```

**Kasus Penggunaan Nyata:**
Setiap project NestJS memiliki kedua file ini. `package.json` untuk setup awal dan menambah dependensi baru. Lockfile memastikan semua developer dan CI/CD memiliki versi dependensi yang identik.
