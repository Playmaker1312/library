## 3.6 Membuat HTTP Server Sederhana (Tanpa Framework)

### Definisi Singkat

Membuat HTTP server tanpa framework berarti menggunakan modul bawaan Node.js bernama `http` untuk mendengarkan permintaan (_request_) dari browser dan mengirimkan tanggapan (_response_) secara manual.

### Analogi

Sering diibaratkan seperti **Membangun Rumah dari Kayu Gelondongan**:

- **Tanpa Framework**: Kamu harus menebang pohon sendiri, menyerut kayu, dan memaku setiap sudut secara manual. Melelahkan, tapi kamu jadi paham fungsi setiap paku dan sambungan kayu.
    
- **Dengan Framework (NestJS)**: Kamu membeli rumah "prefabrikasi" yang sudah jadi. Kamu tinggal menentukan warna cat dan tata letak perabotannya. Jauh lebih cepat, tapi kamu mungkin tidak tahu apa yang ada di balik dindingnya.
    

### Poin-Poin Penting

- **`http.createServer`**: Fungsi utama untuk membuat server yang menerima fungsi _callback_ dengan dua parameter penting: `req` (request) dan `res` (response).
    
- **Request (`req`)**: Berisi semua informasi dari user (URL yang dibuka, metode GET/POST, data yang dikirim).
    
- **Response (`res`)**: Alat kita untuk membalas user (mengirim status code seperti 200 atau 404, serta mengirim data/teks).
    
- **`.listen()`**: Perintah untuk membuat server tetap "bangun" dan menunggu di port tertentu (misal port 3000).
    

### Contoh Implementasi

Buat file bernama `server.js` dan jalankan dengan perintah `node server.js`:

JavaScript

```
const http = require('http');

const server = http.createServer((req, res) => {
    // Menentukan header respon agar browser tahu ini adalah teks plain/html
    res.writeHead(200, { 'Content-Type': 'text/plain' });

    // Logika Routing Sederhana
    if (req.url === '/') {
        res.end('Selamat datang di Home Page!');
    } else if (req.url === '/about') {
        res.end('Ini adalah halaman About.');
    } else {
        res.writeHead(404);
        res.end('Halaman tidak ditemukan!');
    }
});

// Jalankan server di port 3000
server.listen(3000, '127.0.0.1', () => {
    console.log('Server berjalan di http://127.0.0.1:3000');
});
```

### Koneksi dengan Web Development (NestJS)

Mengapa kita melakukan ini?

1. **Memahami Abstraksi**: Di NestJS, kamu hanya perlu menulis dekorator `@Get('/')`, namun di balik layar, NestJS melakukan logika `if (req.url === '/')` yang serupa dengan contoh di atas.
    
2. **Status Codes**: Kamu belajar bahwa setiap respon harus memiliki status (seperti 200 untuk sukses atau 404 untuk error). NestJS mengotomatiskan ini, tapi kamu harus tahu dasarnya agar bisa mengubahnya jika diperlukan.
    
3. **Performance**: Kamu menyadari bahwa setiap baris kode yang kamu tulis di dalam `createServer` akan dijalankan setiap kali ada orang yang mengakses websitemu. Ini alasan mengapa efisiensi kode di _Service_ NestJS sangat penting.
