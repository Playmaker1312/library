# 47. Setup Swagger di main.ts - Konfigurasi Dasar

## Penjelasan

Swagger (OpenAPI) adalah standar industri untuk mendokumentasikan REST API. Dengan `@nestjs/swagger`, kita bisa secara otomatis menghasilkan dokumentasi API interaktif dari dekorator-dekorator yang sudah kita tulis di controller dan DTO. Dokumentasi ini bisa diakses melalui browser di endpoint `/api` dan memungkinkan developer untuk melihat, memahami, dan menguji endpoint langsung dari UI.

Setup dasar Swagger melibatkan pembuatan `DocumentBuilder` untuk mengkonfigurasi informasi API (judul, deskripsi, versi), membuat dokumen OpenAPI dengan `SwaggerModule.createDocument()`, dan menyajikannya melalui `SwaggerModule.setup()`. NestJS secara otomatis akan membaca dekorator dari controller dan DTO untuk menghasilkan dokumentasi yang lengkap.

## Fungsi

Setup Swagger di main.ts berfungsi untuk: (1) mengaktifkan dokumentasi API interaktif di aplikasi NestJS, (2) menyediakan antarmuka visual untuk mengeksplorasi dan menguji endpoint, (3) mengkonfigurasi metadata API seperti judul, deskripsi, versi, dan server, (4) mengintegrasikan autentikasi Bearer token di UI Swagger agar developer bisa melakukan testing langsung.

## Cara Implementasi / Code

**1. Install package Swagger:**

```bash
npm install @nestjs/swagger swagger-ui-express
```

**2. Setup Swagger di `main.ts`:**

```typescript
import { NestFactory } from '@nestjs/core';
import { ValidationPipe } from '@nestjs/common';
import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // Global validation pipe
  app.useGlobalPipes(
    new ValidationPipe({
      whitelist: true,
      forbidNonWhitelisted: true,
      transform: true,
    }),
  );

  // Swagger Configuration
  const config = new DocumentBuilder()
    .setTitle('Library Management API')
    .setDescription(
      'API untuk mengelola perpustakaan digital. ' +
      'Mendukung autentikasi JWT, manajemen buku, dan role-based access control.',
    )
    .setVersion('1.0')
    .addServer('http://localhost:3000', 'Development Server')
    // Tambahkan bearer auth untuk JWT
    .addBearerAuth(
      {
        type: 'http',
        scheme: 'bearer',
        bearerFormat: 'JWT',
        description: 'Masukkan JWT access token yang didapat dari login',
      },
      'JWT-auth', // Nama security scheme
    )
    .build();

  const document = SwaggerModule.createDocument(app, config);
  SwaggerModule.setup('api', app, document, {
    swaggerOptions: {
      persistAuthorization: true, // Simpan token di session browser
      tagsSorter: 'alpha', // Urutkan tag secara alfabet
      operationsSorter: 'method', // Urutkan operasi berdasarkan method
    },
  });

  await app.listen(3000);
  console.log('Application is running on: http://localhost:3000');
  console.log('Swagger documentation: http://localhost:3000/api');
}
bootstrap();
```

**3. Konfigurasi tambahan (opsional) — custom CSS/theme:**

```typescript
SwaggerModule.setup('api', app, document, {
  customCss: `
    .topbar { display: none; }
    .swagger-ui .topbar { display: none; }
  `,
  customSiteTitle: 'Library API Documentation',
  customfavIcon: 'https://nestjs.com/img/favicon.ico',
});
```

**4. Update `nest-cli.json` untuk kompilasi swagger plugin (opsional):**

```json
{
  "collection": "@nestjs/schematics",
  "sourceRoot": "src",
  "compilerOptions": {
    "plugins": [
      {
        "name": "@nestjs/swagger",
        "options": {
          "dtoFileNameSuffix": [".dto.ts", ".entity.ts"],
          "controllerFileNameSuffix": [".controller.ts"],
          "classValidatorShim": true,
          "introspectComments": true
        }
      }
    ]
  }
}
```

Plugin Swagger akan secara otomatis membaca dekorator class-validator (seperti `@IsString`, `@IsEmail`) dan menghasilkan properti swagger yang sesuai. Ini mengurangi boilerplate penulisan `@ApiProperty()` di DTO.

**5. Akses Swagger UI:**

Buka browser dan akses: `http://localhost:3000/api`

Anda akan melihat halaman Swagger UI yang menampilkan semua endpoint yang terdaftar, dikelompokkan berdasarkan tag controller. Setiap endpoint bisa di-klik untuk melihat detail parameter, response, dan bisa diuji langsung.

## Analogi

Setup Swagger di main.ts seperti **membuat peta perpustakaan interaktif** yang ditempel di dinding dekat pintu masuk. Peta ini (DocumentBuilder) mencantumkan:
- **Judul peta**: "Library Management API"
- **Deskripsi**: "Peta lengkap area perpustakaan digital"
- **Versi**: "1.0"
- **Server**: "Gedung A, Lt. 1" (http://localhost:3000)
- **Keamanan**: "Pintu dengan kartu akses" (Bearer auth)

Peta ini ditempel di `/api` (SwaggerModule.setup) dan bisa diakses semua pengunjung. Setiap ruangan (endpoint) di peta bisa diklik untuk melihat detailnya — mirip seperti Google Maps untuk API.

## Penggunaan

Swagger digunakan oleh: (1) developer frontend untuk memahami API yang akan dikonsumsi, (2) developer backend untuk testing endpoint selama pengembangan, (3) QA engineer untuk membuat test case, (4) stakeholder untuk melihat kemampuan API secara visual. Swagger juga bisa diekspor ke format JSON/YAML untuk diimpor ke tools seperti Postman.

## Kesalahan Umum yang Sering Terjadi

1. **Lupa install `swagger-ui-express`**: Swagger UI membutuhkan package ini untuk merender halaman HTML.
2. **Swagger tidak menampilkan endpoint**: Pastikan controller sudah didekorasi dengan `@ApiTags()` dan terdaftar di module.
3. **Bearer auth tidak muncul**: Jika lupa menambahkan `.addBearerAuth()` di config, tombol "Authorize" tidak akan muncul di Swagger UI.
4. **Plugin swagger tidak aktif**: Tanpa plugin, kita harus menulis `@ApiProperty()` secara manual di setiap DTO.

## Soal Latihan

**Soal 1:** Bagaimana cara mengganti URL Swagger dari `/api` menjadi `/docs`?

**Jawaban:** Ubah parameter pertama di `SwaggerModule.setup()`:

```typescript
SwaggerModule.setup('docs', app, document);
```

Sekarang Swagger bisa diakses di `http://localhost:3000/docs`.

**Soal 2:** Bagaimana cara menambahkan multiple server di Swagger (development, staging, production)?

**Jawaban:**

```typescript
const config = new DocumentBuilder()
  .setTitle('Library API')
  .setVersion('1.0')
  .addServer('http://localhost:3000', 'Development')
  .addServer('https://staging-api.example.com', 'Staging')
  .addServer('https://api.example.com', 'Production')
  .build();
```

**Soal 3:** Bagaimana cara mengekspor spesifikasi OpenAPI ke file JSON?

**Jawaban:**

```typescript
import { writeFileSync } from 'fs';

// Setelah createDocument
const document = SwaggerModule.createDocument(app, config);

// Ekspor ke file JSON
writeFileSync('./swagger-spec.json', JSON.stringify(document, null, 2));
```
