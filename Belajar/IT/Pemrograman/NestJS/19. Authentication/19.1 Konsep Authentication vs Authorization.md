# 19. Authentication
## 19.1 Konsep Authentication vs Authorization
**Definisi Singkat:** Authentication (AuthN) adalah verifikasi identitas user ("siapa Anda?"), sedangkan Authorization (AuthZ) adalah penentuan akses ("apa yang boleh Anda lakukan?").

**Analogi:** Authentication seperti check-in di hotel — tunjukkan KTP (siapa Anda). Authorization seperti akses lift — kartu Anda hanya bisa ke lantai tertentu (apa yang boleh Anda akses).

**Poin-Poin Penting:**
- **Authentication** — Login, verifikasi password, JWT, session
- **Authorization** — Role, permission, policy, guard
- **Urutan** — AuthN dulu, baru AuthZ
- **NestJS tools** — Passport (AuthN), Guards (AuthZ)

**Contoh Kode:**
```typescript
// auth.controller.ts — Login (Authentication)
import { Controller, Post, Body } from '@nestjs/common';
import { AuthService } from './auth.service';

@Controller('auth')
export class AuthController {
  constructor(private authService: AuthService) {}

  @Post('login')
  async login(@Body() dto: { email: string; password: string }) {
    // 1. AuthN — Verifikasi kredensial
    const token = await this.authService.authenticate(dto);
    return { accessToken: token };
  }
}

// user.controller.ts — Hanya admin (Authorization)
import { Controller, Get, UseGuards } from '@nestjs/common';
import { JwtAuthGuard } from './guards/jwt-auth.guard';
import { RolesGuard } from './guards/roles.guard';
import { Roles } from './decorators/roles.decorator';

@Controller('users')
@UseGuards(JwtAuthGuard, RolesGuard)
export class UserController {
  @Get()
  @Roles('admin')
  async findAll() {
    // 2. AuthZ — Hanya user dengan role 'admin' bisa akses
    return this.userService.findAll();
  }
}
```

**Kasus Penggunaan Nyata:** Endpoint `/admin/delete-user`: pertama user login (AuthN → JWT), kemudian dicek rolenya (AuthZ → hanya admin).
