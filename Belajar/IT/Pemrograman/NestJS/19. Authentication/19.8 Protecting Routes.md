# 19. Authentication
## 19.8 Protecting Routes
**Definisi Singkat:** Route protection adalah penerapan guard pada controller atau method handler untuk memastikan hanya request terautentikasi yang bisa mengakses endpoint tertentu.

**Analogi:** Protecting routes seperti area VIP di konser — hanya yang punya akses khusus (token valid) yang boleh masuk; yang lain ditolak di pintu.

**Poin-Poin Penting:**
- **`@UseGuards(JwtAuthGuard)`** — di level controller (semua route) atau method
- **`@UseGuards(AuthGuard('jwt'))`** — Langsung tanpa custom guard
- **Global guard** — Daftarkan di `APP_GUARD` untuk semua controller
- **Public routes** — Buat custom decorator `@Public()` untuk bypass guard global

**Contoh Kode:**
```typescript
// app.module.ts — Global guard
import { Module } from '@nestjs/common';
import { APP_GUARD } from '@nestjs/core';
import { JwtAuthGuard } from './auth/guards/jwt-auth.guard';

@Module({
  providers: [
    {
      provide: APP_GUARD,
      useClass: JwtAuthGuard,
    },
  ],
})
export class AppModule {}

// decorators/public.decorator.ts
import { SetMetadata } from '@nestjs/common';

export const IS_PUBLIC_KEY = 'isPublic';
export const Public = () => SetMetadata(IS_PUBLIC_KEY, true);

// guards/jwt-auth.guard.ts — Skip untuk route public
import { Reflector } from '@nestjs/core';
import { IS_PUBLIC_KEY } from '../decorators/public.decorator';

@Injectable()
export class JwtAuthGuard extends AuthGuard('jwt') {
  constructor(private reflector: Reflector) {
    super();
  }

  canActivate(context: ExecutionContext) {
    const isPublic = this.reflector.getAllAndOverride<boolean>(IS_PUBLIC_KEY, [
      context.getHandler(),
      context.getClass(),
    ]);
    if (isPublic) return true;
    return super.canActivate(context);
  }
}

// auth.controller.ts — Public route
@Controller('auth')
export class AuthController {
  @Public()
  @Post('login')
  async login(@Body() dto: LoginDto) {
    return this.authService.login(dto);
  }
}
```

**Kasus Penggunaan Nyata:** Endpoint `POST /auth/login` dan `POST /auth/register` bersifat public, sementara `GET /users/profile` dan `DELETE /products/:id` terproteksi.
