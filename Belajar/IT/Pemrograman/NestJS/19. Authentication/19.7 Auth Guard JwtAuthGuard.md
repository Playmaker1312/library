# 19. Authentication
## 19.7 Auth Guard JwtAuthGuard
**Definisi Singkat:** JwtAuthGuard adalah custom guard yang extends `AuthGuard('jwt')` dari `@nestjs/passport` untuk melindungi route dari request tanpa token valid.

**Analogi:** JwtAuthGuard seperti satpam di pintu masuk — Anda harus tunjukkan tiket (token) yang valid; jika tidak, ditolak masuk.

**Poin-Poin Penting:**
- **`AuthGuard('jwt')`** — Guard bawaan Passport untuk JWT strategy
- **`canActivate()`** — Method yang menentukan akses diizinkan atau tidak
- **`handleRequest()`** — Custom error handling untuk invalid/expired token
- **`@UseGuards(JwtAuthGuard)`** — Aplikasikan ke controller/route

**Contoh Kode:**
```typescript
// guards/jwt-auth.guard.ts
import { Injectable, ExecutionContext, UnauthorizedException } from '@nestjs/common';
import { AuthGuard } from '@nestjs/passport';

@Injectable()
export class JwtAuthGuard extends AuthGuard('jwt') {
  handleRequest(err: any, user: any, info: any, context: ExecutionContext) {
    if (err || !user) {
      if (info?.name === 'TokenExpiredError') {
        throw new UnauthorizedException('Token expired');
      }
      throw err || new UnauthorizedException('Invalid token');
    }
    return user;
  }
}

// user.controller.ts
import { Controller, Get, UseGuards } from '@nestjs/common';
import { JwtAuthGuard } from './guards/jwt-auth.guard';
import { UserService } from './user.service';

@Controller('users')
export class UserController {
  constructor(private userService: UserService) {}

  @UseGuards(JwtAuthGuard)
  @Get('profile')
  getProfile(@Req() req) {
    return req.user; // User dari JWT payload
  }
}
```

**Kasus Penggunaan Nyata:** Endpoint `GET /users/profile` hanya bisa diakses jika request menyertakan JWT valid di header Authorization.
