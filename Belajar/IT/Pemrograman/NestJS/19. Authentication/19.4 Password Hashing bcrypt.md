# 19. Authentication
## 19.4 Password Hashing bcrypt
**Definisi Singkat:** bcrypt adalah library hashing password yang aman dengan salt otomatis dan cost factor. Password tidak boleh disimpan sebagai plain text di database.

**Analogi:** bcrypt seperti mesin pencacah dokumen — password Anda dihancurkan jadi kode acak (hash) yang tidak bisa dikembalikan ke bentuk asli.

**Poin-Poin Penting:**
- **`bcrypt.hash()`** — Hash password dengan salt
- **`bcrypt.compare()`** — Bandingkan password dengan hash
- **Salt rounds** — Semakin tinggi, semakin aman tapi lambat (default 10-12)
- **Cost factor** — Menentukan seberapa berat hashing (anti brute force)

**Contoh Kode:**
```typescript
// password.service.ts
import { Injectable } from '@nestjs/common';
import * as bcrypt from 'bcrypt';

@Injectable()
export class PasswordService {
  private readonly saltRounds = 12;

  async hashPassword(password: string): Promise<string> {
    return bcrypt.hash(password, this.saltRounds);
  }

  async comparePassword(password: string, hash: string): Promise<boolean> {
    return bcrypt.compare(password, hash);
  }
}

// auth.service.ts — Registrasi & validasi
import { Injectable, UnauthorizedException } from '@nestjs/common';
import { PasswordService } from './password.service';
import { PrismaService } from '../prisma/prisma.service';

@Injectable()
export class AuthService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly passwordService: PasswordService,
  ) {}

  async register(email: string, password: string) {
    const hashedPassword = await this.passwordService.hashPassword(password);
    return this.prisma.user.create({
      data: { email, password: hashedPassword },
    });
  }

  async validateUser(email: string, password: string) {
    const user = await this.prisma.user.findUnique({ where: { email } });
    if (!user) throw new UnauthorizedException();

    const valid = await this.passwordService.comparePassword(password, user.password);
    if (!valid) throw new UnauthorizedException();

    return user;
  }
}
```

**Kasus Penggunaan Nyata:** Registrasi user baru — password di-hash dengan bcrypt sebelum disimpan ke database; login bandingkan hash dengan bcrypt.compare.
