# 19. Authentication
## 19.2 nestjs passport Integrasi Passport.js
**Definisi Singkat:** `@nestjs/passport` adalah modul integrasi Passport.js dengan NestJS, menyediakan abstract guard dan mekanisme strategy yang reusable.

**Analogi:** Passport seperti petugas imigrasi di bandara — dia punya berbagai cara (strategy) untuk memeriksa identitas: passport (JWT), SIM (Local), atau KTP (OAuth).

**Poin-Poin Penting:**
- **`@nestjs/passport`** — Package integrasi Passport.js
- **`passport`** — Strategy pattern untuk autentikasi
- **`AuthGuard()`** — Guard NestJS dari Passport
- **`PassportModule`** — Registrasi modul Passport

**Contoh Kode:**
```typescript
// auth.module.ts
import { Module } from '@nestjs/common';
import { PassportModule } from '@nestjs/passport';
import { AuthService } from './auth.service';
import { AuthController } from './auth.controller';
import { LocalStrategy } from './strategies/local.strategy';
import { JwtStrategy } from './strategies/jwt.strategy';

@Module({
  imports: [
    PassportModule.register({ defaultStrategy: 'jwt' }),
  ],
  controllers: [AuthController],
  providers: [AuthService, LocalStrategy, JwtStrategy],
})
export class AuthModule {}
```

**Kasus Penggunaan Nyata:** Aplikasi yang menggunakan Local Strategy untuk login dengan email/password dan JWT Strategy untuk melindungi API endpoints.
