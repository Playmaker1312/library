# 19. Authentication
## 19.6 Access Token dan Refresh Token
**Definisi Singkat:** Access Token (short-lived, ~15 menit) digunakan untuk otentikasi request API. Refresh Token (long-lived, ~7 hari) digunakan untuk mendapatkan Access Token baru tanpa login ulang.

**Analogi:** Access Token seperti pas masuk gym harian — berlaku terbatas. Refresh Token seperti member card tahunan — dipakai untuk ambil pas masuk baru saat habis.

**Poin-Poin Penting:**
- **Access Token** — Umur pendek (15m-1h), disimpan di memory/header
- **Refresh Token** — Umur panjang (7-30 hari), disimpan di httpOnly cookie
- **`/auth/refresh`** — Endpoint untuk refresh access token
- **Rotate** — Refresh token baru setiap kali di-refresh (security)

**Contoh Kode:**
```typescript
// auth.service.ts
import { Injectable, UnauthorizedException } from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class AuthService {
  constructor(
    private jwtService: JwtService,
    private configService: ConfigService,
  ) {}

  async login(user: { id: number; email: string; role: string }) {
    const payload = { sub: user.id, email: user.email, role: user.role };

    return {
      accessToken: this.jwtService.sign(payload, { expiresIn: '15m' }),  // access
      refreshToken: this.jwtService.sign(payload, { expiresIn: '7d' }),  // refresh
    };
  }

  async refreshToken(token: string) {
    try {
      const payload = this.jwtService.verify(token);
      return {
        accessToken: this.jwtService.sign(
          { sub: payload.sub, email: payload.email, role: payload.role },
          { expiresIn: '15m' },
        ),
        refreshToken: this.jwtService.sign(
          { sub: payload.sub, email: payload.email, role: payload.role },
          { expiresIn: '7d' },
        ),
      };
    } catch {
      throw new UnauthorizedException('Invalid refresh token');
    }
  }
}

// auth.controller.ts
@Controller('auth')
export class AuthController {
  constructor(private authService: AuthService) {}

  @Post('refresh')
  async refresh(@Body('refreshToken') token: string) {
    return this.authService.refreshToken(token);
  }
}
```

**Kasus Penggunaan Nyata:** SPA (React/Angular) menyimpan Access Token di memory, Refresh Token di httpOnly cookie. Saat 401, auto-refresh tanpa logout paksa.
