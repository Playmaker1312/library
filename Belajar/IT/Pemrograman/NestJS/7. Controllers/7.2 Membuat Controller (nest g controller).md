## 7.2 Membuat Controller (`nest g controller`)

### Perintah Utama

Buka terminal di dalam folder project kamu, lalu jalankan perintah berikut:

Bash

```
nest generate controller products
```

Atau versi singkatnya:

Bash

```
nest g co products
```

### Apa yang Terjadi di Balik Layar?

NestJS CLI akan melakukan tiga aksi otomatis yang sangat membantu:

1. **CREATE Folder & File**: Jika folder `products` belum ada, CLI akan membuatnya. Kemudian, ia menciptakan file `products.controller.ts`.
    
2. **CREATE Test File**: CLI juga membuatkan file `products.controller.spec.ts`. File ini digunakan untuk menulis unit test agar kamu bisa memastikan controllermu tidak error di masa depan.
    
3. **UPDATE Module**: Ini yang paling penting. CLI akan mencari `products.module.ts` (atau `app.module.ts` jika modul spesifik tidak ditemukan) dan **otomatis mendaftarkan** controller baru tersebut ke dalam array `controllers`.
    

### Hasil Kode Default

Jika kamu membuka file `src/products/products.controller.ts`, kamu akan melihat kode seperti ini:

TypeScript

```
import { Controller } from '@nestjs/common';

@Controller('products') // Prefix URL
export class ProductsController {}
```

### Penjelasan Bagian Kode:

- **`@Controller('products')`**: String `'products'` di dalam kurung disebut sebagai **Path Prefix**. Artinya, semua fungsi (endpoint) yang kamu buat di dalam kelas ini secara otomatis akan diawali dengan alamat `localhost:3000/products`.
    
- **Export Class**: Seperti biasa, kelas ini harus di-export agar bisa dibaca oleh sistem modul NestJS.
    

### Tips Tambahan CLI

1. **Tanpa Folder Tambahan**: Jika kamu ingin membuat controller tanpa dibuatkan folder baru (misalnya ingin ditaruh di root `src`), gunakan flag `--no-spec` jika tidak ingin file test:
    
    Bash
    
    ```
    nest g co products --no-spec
    ```
    
2. **Menentukan Folder Spesifik**: Jika kamu ingin menaruh controller di dalam folder tertentu yang sudah ada:
    
    Bash
    
    ```
    nest g co fitur/orders
    ```

### Kesimpulan

Perintah `nest g co` adalah cara standar industri untuk menambah titik akses baru dalam aplikasi. Dengan melakukan ini melalui CLI, kamu memastikan bahwa controller-mu sudah terhubung dengan modulnya secara benar tanpa perlu melakukan pengetikan manual yang rawan salah (_typo_).
