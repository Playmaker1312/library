# 7. Controllers

## 7.11. `@Redirect` — Redirect Response

**Definisi Singkat:** `@Redirect()` decorator mengirim HTTP redirect response (3xx) ke URL lain. Bisa digunakan dengan URL statis atau dinamis berdasarkan return value dari handler.

**Analogi:** Seperti petugas informasi di mal — Anda tanya "di mana toilet?" dan petugas bilang "belok kiri, lurus" — Anda di-redirect ke lokasi yang benar.

**Poin-Poin Penting:**
- `@Redirect('url', statusCode)` — redirect ke URL dengan status tertentu
- Status default: 302 (Found) — temporary redirect
- 301 (Moved Permanently) — untuk URL yang永久 berubah
- Bisa override URL dan status dengan return object `{ url, statusCode }`
- Handler tetap dijalankan — Anda bisa logic sebelum redirect
- Redirect eksternal (beda domain) atau internal

**Contoh Kode:**
```typescript
import { Controller, Get, Redirect, Param, Query } from '@nestjs/common';

@Controller('links')
export class LinksController {
  // Static redirect — selalu ke URL tetap
  @Get('docs')
  @Redirect('https://docs.nestjs.com', 302)
  goToDocs() {
    // Redirect langsung ke docs NestJS
  }

  // Dynamic redirect berdasarkan return value
  @Get('products/:id')
  @Redirect('https://shop.example.com/products', 302)
  async goToProduct(@Param('id') id: string) {
    // Logic untuk menentukan URL tujuan
    const productUrl = `https://shop.example.com/products/${id}`;

    // Return object akan override decorator
    return { url: productUrl, statusCode: 301 };
  }

  // Conditional redirect
  @Get('legacy-users')
  async legacyUsers(@Query('format') format?: string) {
    if (format === 'json') {
      return { url: '/api/v1/users', statusCode: 301 };
    }
    return { url: '/users/list', statusCode: 302 };
  }
}
```

**Kasus Penggunaan Nyata:**
Redirect setelah login (`/auth/login` → `/dashboard`), legacy URL ke URL baru (301 Moved Permanently), short link expansion, A/B testing redirect, redirect to payment gateway, dan redirect ke CDN untuk assets.
