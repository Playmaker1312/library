# 7. Controllers

## 7.6. `@Query` — Query Parameters

**Definisi Singkat:** `@Query()` decorator mengekstrak query parameters dari URL (bagian setelah `?`). Digunakan untuk filter, pagination, sorting, dan opsi tambahan.

**Analogi:** Seperti filter di toko online — `?category=elektronik&harga_max=1000000&sort=terbaru`. Query params adalah opsi tambahan, bukan identifier resource.

**Poin-Poin Penting:**
- Diambil dari URL setelah `?`: `/users?page=1&limit=10`
- `@Query('page')` — ambil parameter spesifik
- `@Query()` tanpa argumen — seluruh query string sebagai object
- Nilai selalu string — perlu parsing number/boolean
- Bisa menggunakan class-validator DTO untuk validasi
- Biasa untuk: pagination, filtering, searching, sorting

**Contoh Kode:**
```typescript
import { Controller, Get, Query } from '@nestjs/common';
import { IsOptional, IsInt, Min, Max, IsString } from 'class-validator';
import { Type } from 'class-transformer';

// DTO dengan validasi
class FindAllUsersQuery {
  @IsOptional()
  @IsInt()
  @Min(1)
  @Type(() => Number)
  page?: number;

  @IsOptional()
  @IsInt()
  @Min(1)
  @Max(100)
  @Type(() => Number)
  limit?: number;

  @IsOptional()
  @IsString()
  search?: string;

  @IsOptional()
  @IsString()
  sortBy?: string;
}

@Controller('users')
export class UsersController {
  // Query parameter individual
  @Get()
  findAll(
    @Query('page') page: string = '1',
    @Query('limit') limit: string = '10',
    @Query('search') search?: string,
  ) {
    return { page: +page, limit: +limit, search, data: [] };
  }

  // Query dengan DTO
  @Get('search')
  search(@Query() query: FindAllUsersQuery) {
    return {
      filters: query,
      data: [],
    };
  }

  // Semua query params sebagai object
  @Get('debug')
  debug(@Query() allParams: Record<string, string>) {
    return allParams; // ?a=1&b=2 → { a: '1', b: '2' }
  }
}
```

**Kasus Penggunaan Nyata:**
Pagination: `GET /users?page=2&limit=20`. Filtering: `GET /products?category=electronics&minPrice=100&maxPrice=1000`. Searching: `GET /users?q=john`. Sorting: `GET /products?sortBy=price&order=desc`.
