# 7. Controllers

## 7.3. Decorator `@Controller` dan Route Prefix

**Definisi Singkat:** `@Controller('prefix')` mendefinisikan class sebagai controller dan menentukan route prefix untuk semua method di dalamnya. Prefix adalah string path yang ditambahkan sebelum setiap route handler.

**Analogi:** Seperti nomor ekstensi kantor — `@Controller('sales')` berarti semua panggilan ke `sales/*` masuk ke resepsionis bagian sales. `@Controller()` tanpa prefix seperti operator utama.

**Poin-Poin Penting:**
- `@Controller()` — tanpa prefix, route di root (`/`)
- `@Controller('users')` — semua route diawali `/users`
- `@Controller('api/v1/users')` — multi-level prefix
- Prefix bisa string literal atau gabungan
- Method decorator path ditambahkan setelah prefix
- Route akhir: `/{controller-prefix}/{method-path}`

**Contoh Kode:**
```typescript
import { Controller, Get } from '@nestjs/common';

// Tanpa prefix — route di root
@Controller()
export class AppController {
  @Get()
  root(): string {
    return 'Home page';         // GET /
  }

  @Get('health')
  health(): string {
    return 'OK';                // GET /health
  }
}

// Dengan prefix 'users'
@Controller('users')
export class UsersController {
  @Get()
  findAll(): string {
    return 'All users';         // GET /users
  }

  @Get('profile')
  getProfile(): string {
    return 'Profile';           // GET /users/profile
  }

  @Get(':id')
  findOne(@Param('id') id: string): string {
    return `User ${id}`;        // GET /users/:id
  }
}

// Multi-level prefix
@Controller('api/v1/products')
export class ProductsController {
  @Get()
  findAll(): string {
    return 'Products';          // GET /api/v1/products
  }
}
```

**Kasus Penggunaan Nyata:**
Versioning API: `@Controller('api/v1/users')` vs `@Controller('api/v2/users')`. Organisasi per domain: `@Controller('admin/users')` untuk admin endpoints. Global prefix bisa diatur di `main.ts` via `app.setGlobalPrefix('api')`.
