## 7.3 Decorator @Controller() dan Route Prefix

### Definisi Singkat

**`@Controller()`** adalah dekorator kelas yang wajib ada untuk menandakan bahwa sebuah kelas bertugas sebagai pengatur lalu lintas data (routing). **Route Prefix** adalah string yang kita masukkan di dalam kurung dekorator tersebut untuk mengelompokkan semua rute di bawah satu nama jalur yang sama.

### Analogi: Folder dalam Komputer

Bayangkan kamu sedang mengelola file di komputer:

- **Controller**: Adalah sebuah **Folder Utama**.
    
- **Route Prefix**: Adalah **Nama Folder** tersebut (misal: "Dokumen_Pribadi").
    
- **Semua isi di dalamnya**: (misal: "KTP.pdf", "Ijazah.pdf") otomatis berada di bawah jalur folder tersebut.
    
- Jika nama foldernya diubah, maka semua jalur akses file di dalamnya ikut berubah secara otomatis.
    

### Cara Kerja Route Prefix

Ketika kamu menulis `@Controller('auth')`, kamu sedang memberi tahu NestJS: _"Semua permintaan yang dimulai dengan `/auth` harus masuk ke kelas ini."_

TypeScript

```
import { Controller, Get } from '@nestjs/common';

@Controller('auth') // <-- Ini adalah Route Prefix
export class AuthController {

  @Get('login') // Jalurnya menjadi: /auth/login
  handleLogin() {
    return 'Halaman Login';
  }

  @Get('register') // Jalurnya menjadi: /auth/register
  handleRegister() {
    return 'Halaman Daftar';
  }
}
```

### Keuntungan Menggunakan Route Prefix

1. **Pengelompokan yang Rapi**: Kamu tidak perlu menulis `/auth/login`, `/auth/logout`, `/auth/profile` berulang kali. Cukup tulis prefix-nya sekali di atas.
    
2. **Kemudahan Refactoring**: Jika suatu saat bosmu ingin mengubah semua jalur `/auth` menjadi `/v1/auth`, kamu hanya perlu mengubah satu baris di dekorator `@Controller()`.
    
3. **Readability**: Developer lain bisa langsung tahu bahwa kelas `ProductsController` hanya menangani segala hal yang berhubungan dengan produk karena prefix-nya sudah jelas.
    

### Karakteristik Penting

- **Opsional tapi Disarankan**: Kamu bisa saja membiarkan `@Controller()` kosong, yang berarti jalurnya adalah root (`/`). Namun, ini sangat tidak disarankan untuk aplikasi nyata agar tidak terjadi tabrakan rute.
    
- **Hanya Kata Benda**: Sesuai prinsip REST API (Materi 4.3), gunakan kata benda jamak untuk prefix, contohnya: `@Controller('users')`, bukan `@Controller('getUsers')`.
    

---

### Kesimpulan

`@Controller()` adalah pengenal, dan _Route Prefix_ adalah alamat rumahnya. Tanpa alamat yang jelas, client tidak akan pernah bisa menemukan di mana "pintu" aplikasi kamu berada.

Setelah alamat rumahnya ditentukan, sekarang kita perlu tahu bagaimana tamu bisa masuk (apakah lewat pintu depan, pintu belakang, atau jendela). Materi berikutnya adalah **7.4 HTTP Methods (Get, Post, Put, Patch, Delete)**.

Relevant follow-up: Jika kamu membuat `@Controller('v1/products')` dan di dalamnya ada fungsi dengan dekorator `@Get('detail')`, apa alamat URL lengkap yang harus diketik user di browser?
