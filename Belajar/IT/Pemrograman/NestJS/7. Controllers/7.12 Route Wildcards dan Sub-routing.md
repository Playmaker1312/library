# 7. Controllers

## 7.12. Route Wildcards dan Sub-routing

**Definisi Singkat:** Route wildcards menggunakan karakter khusus (`*`, `?`, `+`) dalam path untuk mencocokkan berbagai variasi URL. Sub-routing adalah nesting controller dengan prefix bertingkat.

**Analogi:** Wildcard seperti "isi bebas" dalam formulir — `users/*` berarti semua halaman di bawah `/users/`. Sub-routing seperti alamat bertingkat: gedung/lantai/ruangan.

**Poin-Poin Penting:**
- `*` — wildcard, cocok dengan karakter apa pun (termasuk slash)
- `:param?` — parameter opsional (dengan `?`)
- `:param*` — parameter yang menangkap multi-segment
- Sub-routing dengan nested controllers
- Route order matters — specific routes before wildcards
- Hindari wildcard berlebihan — bisa menyebabkan routing konflik

**Contoh Kode:**
```typescript
import { Controller, Get, Param, Post } from '@nestjs/common';

// Wildcard — menangkap semua sub-path
@Controller('pages')
export class PagesController {
  @Get(':slug*')
  findPage(@Param() params: Record<string, string>) {
    // GET /pages/about → params.slug = 'about'
    // GET /pages/blog/hello-world → params.slug = 'blog/hello-world'
    const slug = params.slug ?? 'home';
    return `Rendering page: ${slug}`;
  }
}

// Optional parameter
@Controller('products')
export class ProductsController {
  @Get(':category?')
  findAll(@Param('category') category?: string) {
    // GET /products — category undefined
    // GET /products/electronics — category = 'electronics'
    return { category: category ?? 'all' };
  }
}

// Sub-routing — controller di-daftar di module parent
@Controller('admin')
export class AdminController {
  @Get()
  dashboard() {
    return 'Admin dashboard';
  }
}

@Controller('admin/users')
export class AdminUsersController {
  @Get()
  manageUsers() {
    return 'Manage users';
  }
}

// Module — daftarkan kedua controller
@Module({
  controllers: [AdminController, AdminUsersController],
})
export class AdminModule {}
```

**Kasus Penggunaan Nyata:**
Wildcard untuk CMS pages (`/:slug*`), file serving (`/files/:path*`), catch-all routes (`*` untuk 404 handler). Sub-routing untuk admin panel (`/admin/users`, `/admin/settings`), API versioning (`/api/v1/...`).
