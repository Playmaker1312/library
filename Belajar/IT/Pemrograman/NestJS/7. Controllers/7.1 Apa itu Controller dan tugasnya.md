# 7. Controllers

## 7.1. Apa itu Controller dan Tugasnya

**Definisi Singkat:** Controller adalah class yang menangani HTTP request masuk dan mengembalikan response ke client. Bertugas sebagai penerima request, validasi awal, dan delegasi ke service.

**Analogi:** Seperti resepsionis hotel — menerima tamu (request), mengecek reservasi (validasi), memanggil bellboy (service), dan memberitahu tamu nomor kamar (response). Resepsionis tidak membersihkan kamar (business logic) — itu tugas housekeeping (service).

**Poin-Poin Penting:**
- Decorator `@Controller()` mendefinisikan class sebagai controller
- Route prefix opsional: `@Controller('users')` → `/users`
- Method handler dengan decorator HTTP: `@Get()`, `@Post()`
- Parameter decorator: `@Param()`, `@Query()`, `@Body()`
- Controller tidak berisi business logic — delegasikan ke Service
- Single Responsibility — hanya handle request/response

**Contoh Kode:**
```typescript
import { Controller, Get, Post, Param, Body } from '@nestjs/common';
import { UsersService } from './users.service';

@Controller('users')
export class UsersController {
  constructor(private readonly usersService: UsersService) {}

  @Get()
  async findAll() {
    // Controller hanya delegasi ke service
    return this.usersService.findAll();
  }

  @Get(':id')
  async findOne(@Param('id') id: string) {
    return this.usersService.findOne(+id);
  }

  @Post()
  async create(@Body() createUserDto: { name: string; email: string }) {
    return this.usersService.create(createUserDto);
  }
}

// Service — business logic ada di sini
@Injectable()
export class UsersService {
  findAll() { return []; }
  findOne(id: number) { return { id }; }
  create(dto: { name: string; email: string }) { return dto; }
}
```

**Kasus Penggunaan Nyata:**
Setiap entity memiliki controller sendiri: UsersController, ProductsController, OrdersController. Controller tipis (thin controller) — hanya routing dan delegasi. Logic berat di Service layer. Testing controller mudah dengan mocking service.
