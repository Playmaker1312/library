# 7. Controllers

## 7.8. `@Headers` — Request Headers

**Definisi Singkat:** `@Headers()` decorator mengekstrak nilai dari HTTP request headers. Headers membawa metadata seperti authentication token, content type, user-agent, dan custom headers.

**Analogi:** Seperti amplop surat — headers adalah informasi di luar amplop (pengirim, stempel, alamat kembali). Body adalah surat di dalam amplop.

**Poin-Poin Penting:**
- `@Headers('name')` — ambil header spesifik
- `@Headers()` tanpa argumen — seluruh headers object
- Header names case-insensitive (NestJS handle otomatis)
- Biasa untuk: Authorization, Content-Type, User-Agent, Accept-Language
- Custom headers: `X-Request-Id`, `X-Api-Key`
- Jangan simpan sensitive data di custom headers tanpa HTTPS

**Contoh Kode:**
```typescript
import { Controller, Get, Post, Headers, UnauthorizedException } from '@nestjs/common';

@Controller('orders')
export class OrdersController {
  // Ambil header spesifik
  @Get()
  findAll(
    @Headers('authorization') auth: string,
    @Headers('accept-language') lang: string,
  ) {
    if (!auth) {
      throw new UnauthorizedException('No auth token');
    }
    return {
      lang: lang || 'en',
      data: [],
    };
  }

  // Seluruh headers
  @Get('debug')
  debug(@Headers() headers: Record<string, string>) {
    return {
      userAgent: headers['user-agent'],
      contentType: headers['content-type'],
      accept: headers['accept'],
      allHeaders: headers,
    };
  }

  // Validasi API key dari header
  @Post()
  create(
    @Body() body: unknown,
    @Headers('x-api-key') apiKey: string,
  ) {
    if (apiKey !== 'secret-key-123') {
      throw new UnauthorizedException('Invalid API key');
    }
    return { created: true };
  }
}
```

**Kasus Penggunaan Nyata:**
`Authorization: Bearer <jwt-token>` untuk otentikasi. `Content-Type: application/json` untuk format body. `X-Request-Id` untuk tracing request. `Accept-Language` untuk i18n. `User-Agent` untuk logging/analytics.
