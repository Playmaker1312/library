# 7. Controllers

## 7.7. `@Body` — Request Body

**Definisi Singkat:** `@Body()` decorator mengekstrak body dari HTTP request. Biasanya digunakan dengan `POST`, `PUT`, dan `PATCH`. NestJS otomatis meng-parse JSON body.

**Analogi:** Seperti formulir pendaftaran — saat Anda isi dan kirim (POST), data di formulir (body) diterima oleh petugas. Petugas (controller) membaca formulir dan memprosesnya.

**Poin-Poin Penting:**
- `@Body()` tanpa parameter — seluruh body object
- `@Body('field')` — ambil field spesifik dari body
- Bisa menggunakan class DTO dengan `class-validator` untuk validasi
- `ValidationPipe` otomatis validasi DTO jika dipasang global
- NestJS menggunakan `body-parser` (Express) atau setara (Fastify)
- Bisa terima JSON, URL-encoded, multipart (file)

**Contoh Kode:**
```typescript
import { Controller, Post, Put, Body } from '@nestjs/common';
import { IsString, IsEmail, IsOptional, MinLength } from 'class-validator';

// DTO dengan validasi
class CreateUserDto {
  @IsString()
  @MinLength(3)
  name!: string;

  @IsEmail()
  email!: string;

  @IsOptional()
  @IsString()
  bio?: string;
}

class UpdateUserDto {
  @IsOptional()
  @IsString()
  name?: string;

  @IsOptional()
  @IsEmail()
  email?: string;
}

@Controller('users')
export class UsersController {
  @Post()
  create(
    @Body() createDto: CreateUserDto, // seluruh body ter-validasi
  ) {
    return {
      message: 'User created',
      user: createDto,
    };
  }

  @Put(':id')
  update(
    @Param('id') id: string,
    @Body() updateDto: UpdateUserDto,
  ) {
    return {
      message: `User ${id} updated`,
      changes: updateDto,
    };
  }

  // Akses field spesifik
  @Post('change-email')
  changeEmail(
    @Body('email') email: string,
    @Body('password') password: string,
  ) {
    return `Changing email to ${email}`;
  }
}
```

**Kasus Penggunaan Nyata:**
`POST /users` dengan body `{ "name": "Alice", "email": "alice@test.com" }` → create user. `PUT /users/1` dengan partial body → update. `POST /auth/login` dengan `{ "email": "...", "password": "..." }` → authentication.
