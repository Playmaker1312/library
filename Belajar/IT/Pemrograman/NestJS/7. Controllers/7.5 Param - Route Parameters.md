# 7. Controllers

## 7.5. `@Param` — Route Parameters

**Definisi Singkat:** `@Param()` decorator mengekstrak parameter dari URL path. Route parameter didefinisikan dengan `:` di path dekorator dan diambil namanya di `@Param('name')`.

**Analogi:** Seperti alamat rumah — `/rumah/123/ruang-tamu` — `123` adalah nomor rumah (route param). Anda mengambil nomor itu untuk mencari data penduduk.

**Poin-Poin Penting:**
- Definisi: `@Get(':id')` → akses dengan `@Param('id')`
- Nilai selalu string — konversi dengan `+id` atau `parseInt()`
- Bisa multiple params: `@Get(':userId/posts/:postId')`
- Semua params: `@Param()` tanpa argumen mengembalikan object seluruh params
- Biasa untuk identifikasi resource spesifik
- Gunakan `ParseIntPipe` atau `ParseUUIDPipe` untuk validasi

**Contoh Kode:**
```typescript
import { Controller, Get, Param, ParseIntPipe } from '@nestjs/common';

@Controller('users')
export class UsersController {
  // Single param
  @Get(':id')
  findOne(@Param('id') id: string) {
    return `User ${id}`; // GET /users/42 → "User 42"
  }

  // Dengan pipe transform
  @Get(':id/detail')
  findOneDetail(@Param('id', ParseIntPipe) id: number) {
    return `User with numeric ID: ${id}`; // id bertipe number
  }

  // Multiple params
  @Get(':userId/posts/:postId')
  findPost(
    @Param('userId') userId: string,
    @Param('postId') postId: string,
  ) {
    return `User ${userId}, Post ${postId}`;
  }

  // Semua params sekaligus
  @Get(':category/:id')
  findByCategory(@Param() params: Record<string, string>) {
    return `Category: ${params.category}, ID: ${params.id}`;
  }
}
```

**Kasus Penggunaan Nyata:**
`GET /users/:id` (detail user), `GET /products/:productId/reviews/:reviewId` (nested resource), `GET /orders/:orderId/items/:itemId` (order items). Route params untuk identifier — gunakan ParseIntPipe atau ParseUUIDPipe untuk validasi otomatis.
