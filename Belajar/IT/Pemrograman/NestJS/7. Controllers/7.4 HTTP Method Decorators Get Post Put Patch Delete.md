# 7. Controllers

## 7.4. HTTP Method Decorators: `@Get`, `@Post`, `@Put`, `@Patch`, `@Delete`

**Definisi Singkat:** Decorator method yang memetakan handler function ke HTTP method tertentu. Setiap decorator bisa menerima path opsional untuk sub-routing.

**Analogi:** Seperti tombol di remote TV — `@Get()` seperti tombol "Ch+" (minta data), `@Post()` seperti "OK" (kirim data), `@Delete()` seperti "Power" (hapus). Masing-masing tombol menjalankan fungsi berbeda.

**Poin-Poin Penting:**
- `@Get()` — membaca data (default: `/` jika tanpa path)
- `@Post()` — membuat data baru
- `@Put()` — mengganti data seluruhnya
- `@Patch()` — mengubah data sebagian
- `@Delete()` — menghapus data
- `@All()` — menangani semua HTTP methods
- Path bisa string literal atau parameter: `@Get(':id')`
- Bisa multiple decorator per method (jarang)

**Contoh Kode:**
```typescript
import { Controller, Get, Post, Put, Patch, Delete, All, Param, Body } from '@nestjs/common';

@Controller('products')
export class ProductsController {
  @Get()
  findAll() {
    return 'GET /products — list all';
  }

  @Get(':id')
  findOne(@Param('id') id: string) {
    return `GET /products/${id} — detail`;
  }

  @Post()
  create(@Body() dto: Record<string, unknown>) {
    return `POST /products — created ${JSON.stringify(dto)}`;
  }

  @Put(':id')
  replace(@Param('id') id: string, @Body() dto: unknown) {
    return `PUT /products/${id} — replaced`;
  }

  @Patch(':id')
  update(@Param('id') id: string, @Body() dto: unknown) {
    return `PATCH /products/${id} — updated`;
  }

  @Delete(':id')
  remove(@Param('id') id: string) {
    return `DELETE /products/${id} — deleted`;
  }

  @All('inventory')
  inventory() {
    return 'ALL /products/inventory — any method';
  }
}
```

**Kasus Penggunaan Nyata:**
CRUD endpoints: `GET /users` (list), `GET /users/:id` (detail), `POST /users` (create), `PUT /users/:id` (full update), `PATCH /users/:id` (partial update), `DELETE /users/:id` (delete). Setiap method handler delegasikan ke service.
