# 7. Controllers

## 7.9. `@Res` dan `@Req` — Akses Langsung ke Response/Request

**Definisi Singkat:** `@Res()` dan `@Req()` memberikan akses langsung ke object response (`express.Response`) dan request (`express.Request`) asli dari Node.js/Express. Digunakan untuk kontrol tingkat rendah.

**Analogi:** Seperti mengemudi manual — biasanya Anda pakai mobil matic (NestJS handle response). Tapi kadang Anda perlu gigi manual (`@Res()`) untuk situasi khusus seperti menanjak.

**Poin-Poin Penting:**
- `@Req()` — akses request object Express/Fastify asli
- `@Res()` — akses response object Express/Fastify asli
- NestJS menangani response secara otomatis — hindari @Res() jika tidak perlu
- Jika menggunakan `@Res()`, Anda harus manual kirim response (`res.json()`, `res.send()`)
- Kombinasi response manual dan NestJS bisa menyebabkan bug
- Gunakan `passthrough: true` untuk tetap menggunakan NestJS response handling

**Contoh Kode:**
```typescript
import { Controller, Get, Post, Req, Res, HttpStatus } from '@nestjs/common';
import { Request, Response } from 'express';

@Controller('users')
export class UsersController {
  // @Req — akses request object
  @Get('profile')
  getProfile(@Req() req: Request) {
    console.log('Headers:', req.headers);
    console.log('IP:', req.ip);
    console.log('Path:', req.path);
    return { userAgent: req.headers['user-agent'] };
  }

  // @Res — response manual (hati-hati!)
  @Get('legacy')
  getLegacy(@Res() res: Response) {
    // NestJS tidak akan mengirim response — Anda harus manual
    res.status(HttpStatus.OK).json({ legacy: true });
  }

  // @Res passthrough — tetap manfaatkan NestJS interceptors/filters
  @Get('stream')
  getStream(@Res({ passthrough: true }) res: Response) {
    res.setHeader('X-Custom', 'value');
    return { data: 'NestJS tetap handle response body' };
  }
}

// Streaming file — kasus penggunaan @Res yang tepat
@Controller('files')
export class FilesController {
  @Get(':id')
  download(@Param('id') id: string, @Res() res: Response) {
    const fileStream = createReadStream(`./uploads/${id}`);
    fileStream.pipe(res);
  }
}
```

**Kasus Penggunaan Nyata:**
Gunakan `@Res()` untuk: streaming file/download, custom HTTP response (multi-part), integrasi dengan library Express yang butuh response object, dan response dengan header kompleks. Sebisa mungkin hindari dan gunakan NestJS response handling otomatis.
