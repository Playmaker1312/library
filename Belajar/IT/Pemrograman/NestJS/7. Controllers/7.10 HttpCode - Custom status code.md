# 7. Controllers

## 7.10. `@HttpCode` — Custom Status Code

**Definisi Singkat:** `@HttpCode()` decorator mengubah default HTTP status code untuk response. Tanpa decorator, NestJS mengembalikan 200 untuk GET, 201 untuk POST, dll.

**Analogi:** Seperti memberi stempel warna berbeda pada dokumen — biasanya hijau (200), kadang Anda perlu stempel biru (201) untuk dokumen baru, atau merah (204) untuk dokumen yang dihapus.

**Poin-Poin Penting:**
- Default NestJS: GET=200, POST=201, PUT=200, PATCH=200, DELETE=200
- `@HttpCode(204)` — untuk DELETE response tanpa body
- `@HttpCode(202)` — accepted (untuk async processing)
- Bisa digabung dengan `@Header()` untuk response header
- Menggunakan `HttpStatus` enum dari `@nestjs/common`
- Tidak mempengaruhi error cases — hanya sukses response

**Contoh Kode:**
```typescript
import {
  Controller, Get, Post, Put, Patch, Delete,
  HttpCode, HttpStatus, Header,
} from '@nestjs/common';

@Controller('users')
export class UsersController {
  @Post()
  @HttpCode(HttpStatus.CREATED) // 201 — default POST
  create() {
    return { message: 'Created' };
  }

  @Delete(':id')
  @HttpCode(HttpStatus.NO_CONTENT) // 204 — tanpa response body
  remove() {
    // Tidak perlu return value — NestJS kirim response tanpa body
  }

  @Post('async')
  @HttpCode(HttpStatus.ACCEPTED) // 202 — request diterima, proses di background
  asyncProcess() {
    return { message: 'Processing started' };
  }

  @Post('reset')
  @HttpCode(HttpStatus.RESET_CONTENT) // 205
  @Header('Cache-Control', 'no-cache')
  reset() {
    return { message: 'Reset' };
  }
}
```

**Kasus Penggunaan Nyata:**
`201 Created` untuk response POST, `204 No Content` untuk DELETE (tanpa body), `202 Accepted` untuk async job queuing, `205 Reset Content` untuk form reset. Gunakan `HttpStatus` enum untuk kode yang readable.
