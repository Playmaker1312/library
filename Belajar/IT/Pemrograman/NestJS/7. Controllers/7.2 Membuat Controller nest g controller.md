# 7. Controllers

## 7.2. Membuat Controller: `nest g controller`

**Definisi Singkat:** `nest g controller <name>` adalah CLI command untuk generate controller boilerplate. File controller dibuat di folder yang sesuai dan otomatis terdaftar di module terdekat.

**Analogi:** Seperti merekrut resepsionis baru — HRD (CLI) menyiapkan seragam (boilerplate), meja (file), dan memberitahu manajer (module) bahwa resepsionis baru siap bekerja.

**Poin-Poin Penting:**
- Sintaks: `nest g controller <nama>`
- Membuat file: `src/<nama>/<nama>.controller.ts`
- Update module: registrasi controller di module terdekat
- Opsi `--flat` — tanpa subfolder
- Opsi `--path` — custom path
- Opsi `--no-spec` — skip test file
- CRUD generator: `nest g resource <nama>` (controller + service + module)

**Contoh Kode:**
```bash
# Generate controller untuk users
nest g controller users
# CREATE src/users/users.controller.ts
# UPDATE src/users/users.module.ts

# Generate dengan path spesifik
nest g controller admin/dashboard
# CREATE src/admin/dashboard/dashboard.controller.ts

# Flat — di folder yang sama
nest g controller common/health --flat
# CREATE src/common/health.controller.ts

# Skip spec file
nest g controller users --no-spec
```

```typescript
// Hasil generate — users.controller.ts
import { Controller } from '@nestjs/common';

@Controller('users')
export class UsersController {
  constructor() {}
}

// Module terupdate — users.module.ts
import { Module } from '@nestjs/common';
import { UsersController } from './users.controller';

@Module({
  controllers: [UsersController],
})
export class UsersModule {}
```

**Kasus Penggunaan Nyata:**
Untuk setiap fitur baru: `nest g module users`, `nest g controller users`, `nest g service users`. Atau langsung `nest g resource users` untuk CRUD lengkap dengan REST API endpoints siap pakai.
