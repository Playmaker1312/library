## 1.5 Template Literals

### Definisi Singkat

**Template Literals** adalah cara baru untuk mendefinisikan string menggunakan tanda _backtick_ (`` ` ``) yang memungkinkan kita menyisipkan ekspresi variabel secara langsung dan membuat teks multi-baris tanpa karakter khusus.

### Analogi

Bayangkan kamu sedang menulis **Surat Undangan fisik**:

- **Dulu (String Biasa):** Kamu menulis teks di kertas, lalu menggunting kertas kecil berisi nama orang, lalu menempelkannya dengan lem, lalu menyambung kalimat lagi dengan isolasi. Sangat repot dan berantakan.
    
- **Sekarang (Template Literals):** Kamu menggunakan template digital di komputer. Kamu cukup menulis kalimat utuh dan memberikan "slot kosong" bertanda `${}` yang otomatis akan terisi data saat dicetak. Lebih rapi, cepat, dan presisi.
    

### Poin-Poin Penting

- **Backticks (`` ` ``):** Menggunakan tanda kutip miring (biasanya di bawah tombol Esc), bukan kutip satu (`'`) atau dua (`"`).
    
- **String Interpolation:** Kita bisa memasukkan variabel atau logika JavaScript langsung ke dalam string menggunakan sintaks `${ekspresi}`.
    
- **Multi-line Strings:** Kamu bisa menekan tombol Enter di tengah string tanpa menyebabkan error atau membutuhkan karakter `\n`.
    
- **Expression Evaluation:** Di dalam `${}`, kamu bisa melakukan operasi matematika, memanggil fungsi, atau menggunakan _ternary operator_.
    

### Contoh Implementasi

JavaScript

```
const name = "Budi";
const role = "Admin";
const hour = new Date().getHours();

// 1. Interpolasi Variabel & Logika Sederhana
const greeting = `Halo ${name}, Anda login sebagai ${role}. 
Waktu saat ini adalah jam ${hour}. 
Status: ${hour < 12 ? 'Pagi' : 'Siang/Malam'}`;

console.log(greeting);

// 2. Multi-line String (Sangat bersih untuk query atau HTML)
const query = `
    SELECT * FROM users
    WHERE role = 'admin'
    ORDER BY created_at DESC
`;

console.log(query);
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, Template Literals sangat membantu dalam:

1. **Logging:** Mencetak log ke terminal dengan format yang jelas, misalnya mencetak method HTTP dan URL secara bersamaan: ``console.log(`[${method}] request to ${url}`)``.
    
2. **Database Query:** Jika kamu menggunakan TypeORM atau Sequelize (biasa dipasangkan dengan NestJS) untuk menulis _raw query_, template literals membuat SQL kamu jauh lebih mudah dibaca.
    
3. **Error Messages:** Membuat pesan error yang dinamis untuk dikirim kembali ke client, misalnya: ``throw new BadRequestException(`User dengan ID ${id} tidak ditemukan`);``.
    
4. **Pathing:** Mengatur path file atau direktori saat bekerja dengan modul _File System_ (fs).
