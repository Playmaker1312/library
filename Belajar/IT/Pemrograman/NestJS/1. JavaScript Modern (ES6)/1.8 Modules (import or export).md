## 1.8 Modules (Import & Export)

### Definisi Singkat

**Modules** adalah mekanisme untuk membagi kode JavaScript ke dalam file terpisah. Dengan `export`, kita mengizinkan fungsi, objek, atau class dari satu file untuk digunakan di file lain, sementara `import` digunakan untuk mengambil fitur tersebut.

### Analogi

Bayangkan kamu sedang merakit sebuah **PC Gaming**:

- **File Tanpa Module**: Seperti mencoba membuat seluruh komponen PC (prosesor, RAM, GPU) dalam satu cetakan besi yang sama. Jika ada yang rusak sedikit, kamu harus membuang semuanya.
    
- **ES6 Modules**: Seperti komponen PC modern. Ada modul RAM, modul GPU, dan modul Motherboard.
    
    - **`export`**: Adalah pabrik yang memproduksi RAM dan memberikan "konektor" agar bisa dipasang.
        
    - **`import`**: Adalah tindakan mencolokkan RAM tersebut ke Motherboard agar PC bisa menyala. Kamu hanya mengambil komponen yang kamu butuhkan.
        

### Poin-Poin Penting

- **Named Export:** Mengekspor banyak hal dari satu file. Saat di-import, namanya harus sama persis (menggunakan kurung kurawal `{}`).
    
- **Default Export:** Digunakan jika satu file hanya mengekspor satu hal utama. Saat di-import, kamu bebas memberi nama apa saja tanpa kurung kurawal.
    
- **Reusability:** Kode yang sudah di-export bisa digunakan berkali-kali di berbagai bagian aplikasi tanpa menulis ulang.
    
- **Namespace Import:** Mengambil semua yang di-export dari satu file dan menjadikannya sebuah objek (menggunakan `import * as Name`).
    

### Contoh Implementasi

**File 1: `math-utility.js` (Eksportir)**

JavaScript

```
// Named Export
export const Tambah = (a, b) => a + b;
export const Kurang = (a, b) => a - b;

// Default Export
const kalkulator = "Versi 1.0";
export default kalkulator;
```

**File 2: `app.js` (Importir)**

JavaScript

```
// Import Default (bebas nama) dan Named (harus sesuai & pakai {})
import VersiKalkulator, { Tambah, Kurang } from './math-utility.js';

console.log(VersiKalkulator); // Output: Versi 1.0
console.log(Tambah(5, 3));    // Output: 8
```

### Koneksi dengan Web Development (NestJS)

Sistem module adalah jantung dari **NestJS**:

1. **Struktur Aplikasi:** NestJS membagi aplikasi menjadi `Module`, `Controller`, dan `Service`. Setiap bagian berada di file terpisah dan saling dihubungkan menggunakan `import` dan `export`.
    
2. **Library Access:** Setiap kali kamu menulis `import { Controller, Get } from '@nestjs/common';`, kamu sedang menggunakan sistem ES6 Module untuk mengambil fitur dari library NestJS.
    
3. **Encapsulation:** Kamu bisa menentukan mana _service_ yang boleh diakses oleh module lain (dengan memasukkannya ke array `exports` di dekorator `@Module`) dan mana yang tetap menjadi rahasia internal file tersebut.
