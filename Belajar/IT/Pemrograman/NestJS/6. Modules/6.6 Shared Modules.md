# 6. Modules

## 6.6. Shared Modules

**Definisi Singkat:** Shared module adalah module yang menyediakan provider umum yang digunakan oleh banyak module lain — seperti logging, caching, database connection, atau utility services.

**Analogi:** Seperti pantry bersama di kantor — ada dispenser air (DatabaseService), kulkas (CacheService), microwave (LoggerService). Setiap departemen (module) bisa menggunakannya tanpa harus punya sendiri.

**Poin-Poin Penting:**
- Provider di-share dengan cara di-export dari module
- Module lain import shared module untuk akses provider-nya
- Providers adalah singleton — satu instance untuk seluruh app
- Jangan export controller dari shared module (kecuali sengaja)
- Contoh shared: DatabaseModule, LoggerModule, CacheModule, ConfigModule
- NestJS built-in modules: `@nestjs/config`, `@nestjs/cache-manager`

**Contoh Kode:**
```typescript
// common/shared.module.ts
import { Module, Global } from '@nestjs/common';
import { LoggerService } from './logger.service';
import { CacheService } from './cache.service';
import { EncryptionService } from './encryption.service';

@Global() // otomatis tersedia di semua module — tanpa import
@Module({
  providers: [
    LoggerService,
    CacheService,
    EncryptionService,
  ],
  exports: [
    LoggerService,
    CacheService,
    EncryptionService,
  ],
})
export class SharedModule {}

// Atau non-global — module lain harus import
@Module({
  providers: [DatabaseService],
  exports: [DatabaseService],
})
export class DatabaseModule {}

// Penggunaan di feature module
@Module({
  imports: [DatabaseModule], // import untuk akses DatabaseService
  controllers: [UsersController],
  providers: [UsersService],
})
export class UsersModule {
  constructor(
    private readonly db: DatabaseService, // inject dari DatabaseModule
    private readonly logger: LoggerService, // inject dari SharedModule (global)
  ) {}
}
```

**Kasus Penggunaan Nyata:**
SharedModule untuk provider lintas fitur: LoggerService untuk logging terpusat, CacheService untuk Redis caching, EncryptionService untuk hashing/JWT, DatabaseService untuk koneksi TypeORM/Prisma. GlobalModule untuk provider yang benar-benar universal.
