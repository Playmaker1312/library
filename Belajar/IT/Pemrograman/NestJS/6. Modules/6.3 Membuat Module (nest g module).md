## 6.3 Membuat Module (`nest g module`)

### Definisi Singkat

Meskipun kita bisa membuat file modul secara manual, NestJS menyediakan perintah `generate` (disingkat `g`) untuk membuat modul secara otomatis dengan struktur yang benar dan langsung mendaftarkannya ke sistem.

### Perintah Utama

Buka terminal di dalam folder project kamu, lalu jalankan perintah berikut:

Bash

```
nest generate module users
```

Atau gunakan versi singkatnya (lebih sering digunakan oleh profesional):

Bash

```
nest g mo users
```

### Apa yang Terjadi Saat Perintah Dijalankan?

Ada dua hal otomatis yang dilakukan oleh NestJS CLI:

1. **CREATE**: Membuat folder baru `src/users/` dan file `users.module.ts` di dalamnya. File ini berisi _boilerplate_ dasar sebuah modul kosong.
    
2. **UPDATE**: Mencari file `app.module.ts` dan **otomatis menambahkan** `UsersModule` ke dalam array `imports`. Ini adalah fitur favorit developer karena mencegah kita lupa mendaftarkan modul baru.
    

### Bedah File Hasil Generate

Isi dari `src/users/users.module.ts` akan terlihat seperti ini:

TypeScript

```
import { Module } from '@nestjs/common';

@Module({})
export class UsersModule {}
```

Meskipun terlihat kosong (objek `{}`), file ini sudah siap untuk diisi dengan `controllers` dan `providers` (Service) yang nanti akan kita buat.

### Kapan Kamu Harus Membuat Modul Baru?

Gunakan prinsip **"Satu Fitur, Satu Modul"**. Kamu harus membuat modul baru jika:

- Kamu membuat fitur baru yang memiliki tabel database sendiri (misal: `Products`, `Categories`).
    
- Kamu membuat fitur utilitas yang besar (misal: `AuthModule` untuk login, `MailModule` untuk kirim email).
    
- Kamu ingin membagi tugas dalam tim (Anggota A mengerjakan `UserModule`, Anggota B di `ProductModule`).
    

### Tips CLI: Dry Run

Jika kamu ragu dan ingin melihat apa yang akan dilakukan CLI tanpa benar-benar membuat filenya, tambahkan flag `--dry-run` atau `-d`:

Bash

```
nest g mo orders --dry-run
```

CLI akan menampilkan daftar file yang _akan_ dibuat dan diubah tanpa menyentuh harddisk kamu.

### Kesimpulan

Perintah `nest g mo` adalah langkah pertama setiap kali kamu ingin memulai fitur baru di NestJS. Ini memastikan struktur folder kamu tetap konsisten dan terorganisir sejak awal.
