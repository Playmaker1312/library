# 6. Modules

## 6.4. `imports`, `controllers`, `providers`, `exports`

**Definisi Singkat:** Empat properti utama decorator `@Module()`: `imports` (module dependensi), `controllers` (routes), `providers` (services/logic), `exports` (provider yang di-share).

**Analogi:** Seperti departemen perusahaan: `imports` = kolaborasi dengan departemen lain, `controllers` = resepsionis, `providers` = staff ahli, `exports` = staff yang bisa dipinjam departemen lain.

**Poin-Poin Penting:**
- `imports` — array module yang dibutuhkan (mengimpor provider mereka)
- `controllers` — array controller yang terdaftar di module ini
- `providers` — array provider yang tersedia via DI di module ini
- `exports` — provider yang bisa digunakan module lain yang import module ini
- Provider adalah singleton — instance dibagikan ke semua yang meng-import
- Jika provider tidak di-export, module lain tidak bisa mengaksesnya

**Contoh Kode:**
```typescript
import { Module } from '@nestjs/common';

// DatabaseModule — menyediakan koneksi database
@Module({
  providers: [DatabaseService],
  exports: [DatabaseService], // bisa dipakai module lain
})
export class DatabaseModule {}

// UsersModule — butuh database
@Module({
  imports: [DatabaseModule], // import provider dari DatabaseModule
  controllers: [UsersController],
  providers: [UsersService],
  exports: [UsersService], // UserService bisa dipakai OrdersModule
})
export class UsersModule {}

// OrdersModule — butuh UsersModule
@Module({
  imports: [UsersModule], // bisa akses UsersService yang di-export
  controllers: [OrdersController],
  providers: [OrdersService],
})
export class OrdersModule {}

// Visual dependency:
// OrdersModule → UsersModule → DatabaseModule
//             → (UsersService.export)
//                          → (DatabaseService.export)
```

**Kasus Penggunaan Nyata:**
DatabaseModule di-import oleh semua feature modules. UsersService di-export untuk OrdersModule. AuthModule di-import oleh module yang butuh proteksi. SharedModule untuk utility providers (logger, cache, config).
