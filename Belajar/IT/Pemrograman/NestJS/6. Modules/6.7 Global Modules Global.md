# 6. Modules

## 6.7. Global Modules (`@Global`)

**Definisi Singkat:** `@Global()` decorator membuat module menjadi global — provider-nya tersedia di seluruh aplikasi tanpa perlu di-import di setiap module. Berguna untuk provider yang hampir semua module butuh.

**Analogi:** Seperti AC sentral di gedung — semua ruangan (module) mendapat AC tanpa harus minta izin. Bandingkan dengan kipas angin portable (non-global) yang hanya dipinjam ke ruangan tertentu.

**Poin-Poin Penting:**
- Tambahkan `@Global()` di atas `@Module({})`
- Hanya daftarkan sekali di AppModule
- Ideal untuk: logger, config, database connection
- Kurangi boilerplate import module
- Hati-hati — global module bisa membuat dependency sulit dilacak
- NestJS built-in global: `ConfigModule.forRoot({ isGlobal: true })`

**Contoh Kode:**
```typescript
// common/logger/logger.module.ts — global module
import { Global, Module } from '@nestjs/common';
import { LoggerService } from './logger.service';

@Global()
@Module({
  providers: [LoggerService],
  exports: [LoggerService],
})
export class LoggerModule {}

// common/config/config.module.ts — global config
import { Global, Module } from '@nestjs/common';
import { ConfigModule } from '@nestjs/config';

@Global()
@Module({
  imports: [ConfigModule.forRoot()],
  exports: [ConfigModule],
})
export class AppConfigModule {}

// AppModule — hanya import sekali
@Module({
  imports: [
    LoggerModule,    // global — semua module bisa inject LoggerService
    AppConfigModule, // global — semua module bisa inject ConfigService
    UsersModule,
    ProductsModule,
  ],
})
export class AppModule {}

// Feature module — langsung inject tanpa import module
@Injectable()
export class UsersService {
  constructor(
    private readonly logger: LoggerService, // dari global module
    private readonly config: ConfigService,  // dari global module
  ) {
    this.logger.log('UsersService initialized');
    const dbUrl = this.config.get('DATABASE_URL');
  }
}
```

**Kasus Penggunaan Nyata:**
Gunakan `@Global()` untuk LoggerModule, ConfigModule, DatabaseModule utama — provider yang 90% module butuh. Jangan global-kan feature modules. NestJS ConfigModule punya opsi `isGlobal: true` — manfaatkan itu.
