# 6. Modules

## 6.8. Dynamic Modules (Pengenalan)

**Definisi Singkat:** Dynamic module adalah module yang dikonfigurasi saat runtime melalui static method (biasanya `forRoot()` atau `forFeature()`). Memungkinkan modul dikustomisasi sesuai kebutuhan consumer.

**Analogi:** Seperti mesin kopi yang bisa diatur — saat dibeli (forRoot) Anda set ukuran cangkir, kekuatan kopi. Setiap ruangan (forFeature) bisa punya setting sendiri tanpa mengubah mesin pusat.

**Poin-Poin Penting:**
- Static method pada class module (misal: `ConfigModule.forRoot()`)
- Mengembalikan `DynamicModule` — object dengan properti `@Module`
- `forRoot()` — konfigurasi global (biasanya dipanggil di AppModule)
- `forFeature()` — konfigurasi spesifik per fitur
- `register()` — untuk konfigurasi per module consumer
- NestJS built-in: `ConfigModule.forRoot()`, `TypeOrmModule.forRoot()`, `GraphQLModule.forRoot()`

**Contoh Kode:**
```typescript
import { Module, DynamicModule, Provider } from '@nestjs/common';

// Database module dengan dynamic configuration
@Module({})
export class DatabaseModule {
  static forRoot(config: {
    host: string;
    port: number;
    database: string;
  }): DynamicModule {
    const providers: Provider[] = [
      {
        provide: 'DATABASE_CONFIG',
        useValue: config,
      },
      DatabaseService,
    ];

    return {
      module: DatabaseModule,
      providers,
      exports: [DatabaseService],
      global: true,
    };
  }

  static forFeature(entity: string): DynamicModule {
    return {
      module: DatabaseModule,
      providers: [
        {
          provide: `${entity}_REPOSITORY`,
          useFactory: (db: DatabaseService) => db.getRepository(entity),
          inject: [DatabaseService],
        },
      ],
      exports: [`${entity}_REPOSITORY`],
    };
  }
}

// Penggunaan
@Module({
  imports: [
    DatabaseModule.forRoot({
      host: 'localhost',
      port: 5432,
      database: 'mydb',
    }),
  ],
})
export class AppModule {}

@Module({
  imports: [DatabaseModule.forFeature('User')],
  providers: [UsersService],
})
export class UsersModule {}
```

**Kasus Penggunaan Nyata:**
`TypeOrmModule.forRoot()` di AppModule dengan konfigurasi database, `TypeOrmModule.forFeature([User])` di setiap feature module. `ConfigModule.forRoot({ isGlobal: true })`. `GraphQLModule.forRoot()`. Pattern ini membuat library reusable dan konfigurable.
