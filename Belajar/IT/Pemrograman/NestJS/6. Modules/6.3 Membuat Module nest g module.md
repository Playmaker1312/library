# 6. Modules

## 6.3. Membuat Module: `nest g module`

**Definisi Singkat:** `nest g module <name>` adalah CLI command untuk generate module boilerplate. Module baru otomatis dibuat di folder `src/<name>/` dan di-import ke AppModule.

**Analogi:** Seperti menekan tombol "Tambah Laci Baru" di lemari — lemari (AppModule) otomatis membuat laci (folder module) dan menambahkan rel (import) untuk laci tersebut.

**Poin-Poin Penting:**
- Sintaks: `nest g module <nama>` atau `nest generate module <nama>`
- Nama otomatis lowercase dan singular
- Folder: `src/<nama>/<nama>.module.ts`
- Module class ditambahkan decorator `@Module({})`
- CLI otomatis update AppModule imports (jika fitur aktif)
- Gunakan `--no-spec` untuk skip test file
- Bisa generate di subfolder: `nest g module modules/users`

**Contoh Kode:**
```bash
# Generate module
nest g module users
# CREATE src/users/users.module.ts
# UPDATE src/app.module.ts

nest g module products
# CREATE src/products/products.module.ts
# UPDATE src/app.module.ts

# Generate dengan path
nest g module modules/orders
# CREATE src/modules/orders/orders.module.ts

# Skip spec file
nest g module invoices --no-spec
```

```typescript
// Hasil generate — src/users/users.module.ts
import { Module } from '@nestjs/common';

@Module({})
export class UsersModule {}

// AppModule otomatis terupdate
// src/app.module.ts
import { Module } from '@nestjs/common';
import { UsersModule } from './users/users.module';
import { ProductsModule } from './products/products.module';

@Module({
  imports: [UsersModule, ProductsModule],
})
export class AppModule {}
```

**Kasus Penggunaan Nyata:**
Setiap fitur baru dalam aplikasi dimulai dengan `nest g module <nama>`. Lalu `nest g controller <nama>` dan `nest g service <nama>` untuk melengkapi fitur. Untuk CRUD lengkap, `nest g resource <nama>` membuat semuanya sekaligus.
