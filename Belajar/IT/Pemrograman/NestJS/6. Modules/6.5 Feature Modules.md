# 6. Modules

## 6.5. Feature Modules

**Definisi Singkat:** Feature module adalah module yang mengorganisir kode untuk fitur/domain tertentu — misalnya UsersModule, ProductsModule, OrdersModule. Setiap module punya scope sendiri dengan controller, service, dan entity terkait.

**Analogi:** Seperti toko serba ada — setiap bagian (elektronik, pakaian, makanan) adalah feature module mandiri. Masing-masing punya staf (service), rak display (controller), dan gudang (repository) sendiri.

**Poin-Poin Penting:**
- Satu module per domain fitur
- Berisi semua komponen terkait fitur tsb
- Bisa import module lain untuk akses provider mereka
- Bisa di-export provider untuk digunakan module lain
- Memudahkan parallel development tim
- Memudahkan testing — domain terisolasi
- Memudahkan lazy loading (microservices)

**Contoh Kode:**
```typescript
// users/users.module.ts — feature module untuk Users
import { Module } from '@nestjs/common';
import { UsersController } from './users.controller';
import { UsersService } from './users.service';
import { UsersRepository } from './users.repository';

@Module({
  controllers: [UsersController],
  providers: [
    UsersService,
    UsersRepository,
  ],
  exports: [UsersService],
})
export class UsersModule {}
```

```typescript
// orders/orders.module.ts — feature module untuk Orders
import { Module } from '@nestjs/common';
import { OrdersController } from './orders.controller';
import { OrdersService } from './orders.service';
import { UsersModule } from '../users/users.module';
import { ProductsModule } from '../products/products.module';

@Module({
  imports: [
    UsersModule,    // butuh user data
    ProductsModule, // butuh product data
  ],
  controllers: [OrdersController],
  providers: [OrdersService],
})
export class OrdersModule {}
```

**Kasus Penggunaan Nyata:**
Aplikasi e-commerce: AuthModule, UsersModule, ProductsModule, CategoriesModule, CartModule, OrdersModule, PaymentsModule, ShippingModule, ReviewsModule, NotificationsModule — masing-masing feature module terpisah dengan tanggungjawab jelas.
