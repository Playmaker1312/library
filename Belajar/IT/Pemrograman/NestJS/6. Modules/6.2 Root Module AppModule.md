# 6. Modules

## 6.2. Root Module (AppModule)

**Definisi Singkat:** AppModule adalah root module — titik awal NestJS application. Semua module lain di-import di sini. NestJS memulai dari AppModule untuk meresolve dependency graph aplikasi.

**Analogi:** Seperti pintu utama rumah — semua tamu (request) masuk lewat sini. Dari sini Anda bisa ke ruang tamu (UsersModule), dapur (ProductsModule), atau kamar (OrdersModule).

**Poin-Poin Penting:**
- Dibuat otomatis oleh `nest new` — `src/app.module.ts`
- Meng-import semua feature modules
- Bisa mendaftarkan global providers (guards, pipes, interceptors)
- Tidak boleh memiliki terlalu banyak logic — hanya orchestrator
- Bisa meng-import `ConfigModule.forRoot()` di sini
- Controllers di AppModule untuk root endpoints (`GET /`)

**Contoh Kode:**
```typescript
// src/app.module.ts — root module
import { Module } from '@nestjs/common';
import { ConfigModule } from '@nestjs/config';
import { UsersModule } from './users/users.module';
import { ProductsModule } from './products/products.module';
import { OrdersModule } from './orders/orders.module';
import { DatabaseModule } from './database/database.module';
import { LoggerService } from './common/logger.service';
import { APP_GUARD } from '@nestjs/core';
import { AuthGuard } from './common/guards/auth.guard';

@Module({
  imports: [
    // Core modules
    ConfigModule.forRoot({ isGlobal: true }),
    DatabaseModule,

    // Feature modules
    UsersModule,
    ProductsModule,
    OrdersModule,
  ],
  controllers: [], // bisa untuk root route
  providers: [
    LoggerService,
    {
      provide: APP_GUARD,
      useClass: AuthGuard, // global guard
    },
  ],
})
export class AppModule {}
```

**Kasus Penggunaan Nyata:**
AppModule adalah file yang diedit setiap kali menambah fitur baru — Anda import module baru di sini. Setup global configuration, database connection, global guards/interceptors. Untuk testing, AppModule di-import untuk integration test.
