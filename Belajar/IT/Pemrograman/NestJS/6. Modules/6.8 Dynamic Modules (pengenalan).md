## 6.8 Dynamic Modules (Pengenalan)

### Definisi Singkat

**Dynamic Module** adalah modul yang perilakunya (provider, controller, dll) dapat dikonfigurasi secara dinamis saat modul tersebut di-_import_. Alih-alih hanya menulis `imports: [ConfigModule]`, kamu bisa menulis `imports: [ConfigModule.register({ folder: './config' })]`.

### Analogi

Pikirkan modul-modul sebelumnya sebagai **Menu Paket di Restoran**:

- **Static Module**: Seperti memesan "Paket Nasi Timbel". Isinya sudah pasti (nasi, ayam, tahu, tempe). Kamu tidak bisa mengubah ayamnya jadi ikan.
    
- **Dynamic Module**: Seperti **Menu Buffet atau Custom Pizza**. Kamu memesan "Pizza", tapi kamu bisa menentukan sendiri _topping_-nya (nasi, jagung, atau keju) di meja kasir. Modulnya sama (PizzaModule), tapi isinya berbeda-beda tergantung pesananmu.
    

### Contoh Penggunaan Nyata

Kamu akan sering menemui Dynamic Modules saat menggunakan library pihak ketiga, seperti:

1. **ConfigModule**: `ConfigModule.forRoot({ isGlobal: true })` — Kamu memberi tahu modul ini agar menjadi global.
    
2. **TypeOrmModule**: `TypeOrmModule.forRoot({ host: 'localhost', database: 'test' })` — Kamu mengirimkan alamat database agar modul tahu ke mana harus terhubung.
    
3. **JwtModule**: `JwtModule.register({ secret: 'SANGAT_RAHASIA' })` — Kamu memberikan kunci rahasia untuk keamanan login.
    

### Mengapa Kita Membutuhkannya?

- **Konfigurasi Berbeda**: Kamu mungkin butuh modul database yang terhubung ke "Database A" untuk fitur User, tapi terhubung ke "Database B" untuk fitur Log.
    
- **Fleksibilitas**: Memungkinkan modul untuk menyesuaikan diri dengan variabel lingkungan (`.env`) atau kebutuhan spesifik di tengah jalan.
    
- **Reusability Tinggi**: Kamu bisa membuat satu modul yang sangat umum (misal: `MailModule`) dan membiarkan orang lain mengkonfigurasinya sendiri (misal: memberikan API Key yang berbeda-beda).
    

### Struktur Kode (Sekilas)

Dynamic Module biasanya menggunakan fungsi statis dengan nama standar seperti `register()`, `forRoot()`, atau `forFeature()`. Fungsi ini akan mengembalikan objek yang strukturnya mirip dengan dekorator `@Module()`.

TypeScript

```
// Contoh pemanggilan di AppModule
@Module({
  imports: [
    DatabaseModule.forRoot('localhost:5432'), // Mengirim konfigurasi secara dinamis
  ],
})
export class AppModule {}
```

### Kesimpulan

Dynamic Modules adalah fitur yang membuat NestJS sangat _powerful_ untuk membangun aplikasi skala besar. Kamu mungkin tidak akan sering **membuat** Dynamic Module sendiri di awal belajar, tapi kamu akan sangat sering **menggunakannya** dari library NestJS.
