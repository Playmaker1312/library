# 37. Deployment ## 37.10 Zero-downtime Deployment

**Definisi Singkat:** Zero-downtime deployment memungkinkan aplikasi diperbarui tanpa memutus koneksi user yang sedang aktif. Teknik utama: rolling update (PM2 reload), blue-green deployment, dan canary release.

**Analogi:** Zero-downtime seperti mengganti roda mobil saat jalan — Anda tidak berhenti total (downtime). Satu per satu roda diganti tanpa menghentikan mobil. Penumpang (user) tidak merasakan perubahan terjadi.

**Poin-Poin Penting:**
- **PM2 reload** rolling restart instances
- **Graceful shutdown** tunggu request selesai
- **Health checks** pastikan server baru siap
- **Blue-green deployment** dua environment identik
- **Rollback plan** jika deployment gagal
- **Database migration backward compatible**

**Contoh Kode:**
```typescript
// main.ts — graceful shutdown
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { Logger } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  const logger = new Logger('Bootstrap');

  await app.listen(process.env.PORT || 3000);
  logger.log('Application started');

  // Graceful shutdown
  const signals = ['SIGTERM', 'SIGINT'];
  signals.forEach((signal) => {
    process.on(signal, async () => {
      logger.log(`Received ${signal}, shutting down gracefully...`);

      // Stop accepting new connections
      await app.close();

      // Close database connections
      // await dataSource.destroy();

      // Close Redis connections
      // await redisClient.quit();

      logger.log('Application shut down');
      process.exit(0);
    });
  });
}
bootstrap();
```

module.exports = {
  apps: [

      name: 'nestjs-app',
      script: 'dist/main.js',
      instances: 4,

      // Health check sebelum traffic dialihkan
      // PM2 akan menunggu app listen sebelum kirim traffic

```typescript
// deploy-with-migrations.ts
// Script untuk zero-downtime dengan database migration
import { execSync } from 'child_process';

async function deploy() {
  // 1. Backup database
  execSync('pg_dump mydb > backup.sql');

  try {
    // 2. Run backward-compatible migrations
    execSync('npm run migration:run');

    // 3. Deploy new code (PM2 rolling restart)
    execSync('npm run build');
    execSync('pm2 reload ecosystem.config.js');

    // 4. Run data migration jika perlu
    execSync('npm run migration:data');

    console.log('Deployment successful!');
  } catch (error) {
    // Rollback
    execSync('psql mydb < backup.sql');
    execSync('pm2 reload ecosystem.config.js'); // reload old code
    console.error('Deployment failed, rolled back:', error);
    process.exit(1);
  }
}

deploy();
```

**Kasus Penggunaan Nyata:** E-commerce dengan 100k concurrent users — deployment menggunakan GitHub Actions + PM2 reload. Setiap instance (dari 8) di-restart bergantian. Graceful shutdown menunggu request selesai (max 10s). Health check memastikan instance baru siap sebelum instance lama dimatikan. User tidak merasakan downtime.
