# 37. Deployment ## 37.9 SSL Certificate Let Encrypt

**Definisi Singkat:** Let's Encrypt adalah Certificate Authority gratis yang menyediakan SSL/TLS certificate. Certbot adalah tool untuk mengotomatisasi pembuatan, instalasi, dan perpanjangan certificate di server Nginx.

**Analogi:** Let's Encrypt seperti kantor pembuatan SIM gratis — Anda datang (request cert), menunjukkan identitas (verifikasi domain via DNS/HTTP challenge), dapat SIM (certificate) berlaku 90 hari, dan harus diperpanjang (auto-renewal) sebelum habis.

**Poin-Poin Penting:**
- **Let's Encrypt** free SSL certificates
- **Certbot** tool untuk certificate management
- **HTTP challenge** verifikasi via file di server
- **DNS challenge** verifikasi via DNS record
- **Auto-renewal** cron job atau systemd timer
- **Wildcard certificate** untuk *.domain.com

**Contoh Kode:**
```bash
# Install Certbot di Ubuntu/Debian
# sudo apt update
# sudo apt install certbot python3-certbot-nginx

# Generate certificate dengan Nginx plugin
# sudo certbot --nginx -d api.example.com -d www.api.example.com

# Dry run untuk test renewal
# sudo certbot renew --dry-run

# Lihat certificate status
# sudo certbot certificates
```

```bash
# DNS Challenge (untuk wildcard certificate)
# sudo certbot certonly --manual \
#   --preferred-challenges dns \
#   -d *.example.com \
#   -d example.com

# Tambahkan TXT record _acme-challenge.example.com di DNS provider
```

```nginx
# /etc/nginx/sites-available/nestjs-ssl.conf
server {
    listen 443 ssl http2;
    server_name api.example.com;

    # Let's Encrypt certificates
    ssl_certificate /etc/letsencrypt/live/api.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.example.com/privkey.pem;

    # Perfect forward secrecy
    ssl_dhparam /etc/letsencrypt/ssl-dhparams.pem;

    # Modern TLS configuration
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-ECDSA-CHACHA20-POLY1305:ECDHE-RSA-CHACHA20-POLY1305:DHE-RSA-AES128-GCM-SHA256:DHE-RSA-AES256-GCM-SHA384;
    ssl_prefer_server_ciphers off;

    # HSTS
    add_header Strict-Transport-Security "max-age=63072000" always;

    # OCSP Stapling
    ssl_stapling on;
    ssl_stapling_verify on;
    resolver 8.8.8.8 8.8.4.4 valid=300s;
    resolver_timeout 5s;

    # Proxy ke NestJS
    location / {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # Let's Encrypt renewal challenge
    location ~ /.well-known/acme-challenge/ {
        root /var/www/html;
    }
}

# Redirect HTTP ke HTTPS
server {
    listen 80;
    server_name api.example.com;

    location ~ /.well-known/acme-challenge/ {
        root /var/www/html;
    }

    location / {
        return 301 https://$server_name$request_uri;
    }
}
```

**Kasus Penggunaan Nyata:** Aplikasi production di DigitalOcean droplet — Nginx + Let's Encrypt SSL dengan auto-renewal. Certbot cron job berjalan 2x/hari, memperpanjang certificate otomatis 30 hari sebelum expiry. Tidak ada downtime untuk renewal karena reload Nginx via renewal hook.
