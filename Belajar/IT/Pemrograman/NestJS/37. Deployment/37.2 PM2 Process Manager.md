# 37. Deployment ## 37.2 PM2 Process Manager

**Definisi Singkat:** PM2 adalah production process manager untuk Node.js yang menyediakan load balancing (cluster mode), auto-restart on crash, log management, zero-downtime reload, dan monitoring.

**Analogi:** PM2 seperti manajer toko yang mengawasi kasir — jika satu kasir (worker) sakit (crash), manajer langsung menggantikannya (auto-restart). Jika terlalu banyak antrian (high traffic), manajer menambah kasir baru (cluster mode). Semua aktivitas dicatat (log management).

**Poin-Poin Penting:**
- **pm2 start** jalankan aplikasi
- **Cluster mode** multi-instance (max CPU cores)
- **pm2 reload** zero-downtime restart
- **pm2 monit** monitoring terminal
- **Ecosystem file** konfigurasi YAML/JS
- **Log management** rotate, combine

**Contoh Kode:**
```typescript
// ecosystem.config.js
module.exports = {
  apps: [
    {
      name: 'nestjs-app',
      script: 'dist/main.js',
      instances: 'max', // atau angka: 2, 4, dll
      exec_mode: 'cluster', // cluster mode for load balancing
      watch: false,
      env: {
        NODE_ENV: 'production',
        PORT: 3000,
      },
      env_file: '.env.production',
      // Log configuration
      log_date_format: 'YYYY-MM-DD HH:mm:ss Z',
      error_file: './logs/error.log',
      out_file: './logs/output.log',
      merge_logs: true,
      log_type: 'json',
      // Restart configuration
      max_restarts: 10,
      restart_delay: 5000,
      min_uptime: 10000,
      // Memory configuration
      max_memory_restart: '500M',
      // Graceful shutdown
      kill_timeout: 5000,
      listen_timeout: 3000,
      shutdown_with_message: true,
    },
  ],
};
```

```typescript
// main.ts — graceful shutdown untuk PM2
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // PM2 graceful start
  await app.listen(process.env.PORT || 3000, () => {
    // Kirim sinyal "ready" ke PM2
    if (process.send) {
      process.send('ready');
    }
  });

  // PM2 graceful shutdown
  process.on('SIGINT', async () => {
    await app.close();
    process.exit(0);
  });
}
bootstrap();
```

**Kasus Penggunaan Nyata:** Aplikasi NestJS di VPS 4-core — PM2 cluster mode menjalankan 4 instances (1 per CPU core) dengan load balancing round-robin. Jika satu instance crash karena memory leak, PM2 restart otomatis tanpa downtime. Log dirotasi setiap 100MB.
