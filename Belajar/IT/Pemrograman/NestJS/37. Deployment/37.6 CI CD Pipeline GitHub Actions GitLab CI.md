# 37. Deployment ## 37.6 CI CD Pipeline GitHub Actions GitLab CI

**Definisi Singkat:** CI/CD Pipeline mengotomatisasi build, test, dan deployment aplikasi NestJS. GitHub Actions dan GitLab CI adalah platform CI/CD populer yang terintegrasi dengan repository.

**Analogi:** CI/CD seperti pabrik otomatis — kode yang di-push (bahan mentah) masuk ke conveyor belt (pipeline), melewati quality check (lint & test), perakitan (build), dan packing (deploy). Semua otomatis tanpa campur tangan manusia.

**Poin-Poin Penting:**
- **GitHub Actions** YAML workflow di .github/
- **GitLab CI** YAML .gitlab-ci.yml
- **Build stage** compile TypeScript
- **Test stage** unit + integration tests
- **Lint stage** ESLint check
- **Deploy stage** push ke server/cloud
- **Environment secrets** untuk credential

**Contoh Kode:**
```typescript
// .github/workflows/ci-cd.yml
name: NestJS CI/CD

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]

env:
  NODE_VERSION: '20'
  REGISTRY: ghcr.io
  IMAGE_NAME: ${{ github.repository }}

jobs:
  # --- CI: Quality Check ---
  quality:
    name: Quality Check
    runs-on: ubuntu-latest

    services:
      postgres:
        image: postgres:16-alpine
        env:
          POSTGRES_PASSWORD: testpass
          POSTGRES_DB: nestjs_test
        ports:
          - 5432:5432
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5

    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - name: Lint
        run: npm run lint

      - name: Type check
        run: npx tsc --noEmit

      - name: Run tests
        run: npm run test
        env:
          DATABASE_URL: postgresql://postgres:testpass@localhost:5432/nestjs_test

      - name: Run e2e tests
        run: npm run test:e2e
        env:
          DATABASE_URL: postgresql://postgres:testpass@localhost:5432/nestjs_test

  # --- CI: Build ---
  build:
    name: Build
    needs: quality
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - name: Build
        run: npm run build

      - name: Upload build artifact
        uses: actions/upload-artifact@v4
        with:
          name: dist
          path: dist/

  # --- CD: Deploy to Production ---
  deploy:
    name: Deploy to Production
    needs: build
    runs-on: ubuntu-latest
    if: github.ref == 'refs/heads/main'

    steps:
      - uses: actions/checkout@v4

      - name: Log in to GitHub Container Registry
        uses: docker/login-action@v3
        with:
          registry: ${{ env.REGISTRY }}
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}

      - name: Build and push Docker image
        uses: docker/build-push-action@v5
        with:
          context: .
          push: true
          tags: |
            ${{ env.REGISTRY }}/${{ env.IMAGE_NAME }}:latest
            ${{ env.REGISTRY }}/${{ env.IMAGE_NAME }}:${{ github.sha }}

      - name: Deploy to VPS
        uses: appleboy/ssh-action@v1.0.3
        with:
          host: ${{ secrets.VPS_HOST }}
          username: ${{ secrets.VPS_USER }}
          key: ${{ secrets.VPS_SSH_KEY }}
          script: |
            cd /opt/myapp
            docker-compose pull app
            docker-compose up -d --no-deps app
            docker image prune -f
```

```typescript
// .gitlab-ci.yml
image: node:20-alpine

stages:
  - lint
  - test
  - build
  - deploy

variables:
  NODE_ENV: development
  DOCKER_IMAGE: $CI_REGISTRY_IMAGE:$CI_COMMIT_SHORT_SHA

cache:
  key: ${CI_COMMIT_REF_SLUG}
  paths:
    - node_modules/
    - dist/

lint:
  stage: lint
  script:
    - npm ci
    - npm run lint

test:
  stage: test
  services:
    - postgres:16-alpine
  variables:
    DATABASE_URL: postgresql://postgres:postgres@postgres:5432/nestjs_test
    POSTGRES_PASSWORD: postgres
    POSTGRES_DB: nestjs_test
  script:
    - npm ci
    - npm run test

build:
  stage: build
  script:
    - npm ci
    - npm run build
  artifacts:
    paths:
      - dist/

deploy:
  stage: deploy
  image: docker:latest
  services:
    - docker:dind
  only:
    - main
  script:
    - docker login -u $CI_REGISTRY_USER -p $CI_REGISTRY_PASSWORD $CI_REGISTRY
    - docker build -t $DOCKER_IMAGE .
    - docker push $DOCKER_IMAGE
    - apk add --no-cache openssh-client
    - ssh $DEPLOY_USER@$DEPLOY_HOST "cd /app && docker-compose pull && docker-compose up -d"
```

**Kasus Penggunaan Nyata:** Monorepo NestJS di GitHub — setiap PR ke `develop` menjalankan lint + test (15 checks). Merge ke `main` trigger build Docker image, push ke GitHub Container Registry, lalu deploy otomatis ke staging server via SSH. Production deploy manual via workflow_dispatch.
