# 37. Deployment ## 37.7 Deploy ke Cloud AWS GCP DigitalOcean Railway

**Definisi Singkat:** Deploy NestJS ke cloud platform seperti AWS (ECS/EC2/Lambda), Google Cloud Run, DigitalOcean App Platform, atau Railway — masing-masing dengan pendekatan dan konfigurasi berbeda.

**Analogi:** Cloud platform seperti berbagai jenis hotel — AWS adalah hotel mewah dengan banyak layanan (bisa sewa kamar, restoran, kolam renang). Railway seperti hostel praktis (cukup colok dan jalan). Pilih sesuai budget dan kebutuhan.

**Poin-Poin Penting:**
- **AWS ECS** Docker container orchestration
- **AWS Lambda** serverless functions
- **Google Cloud Run** managed containers
- **DigitalOcean App Platform** PaaS simple
- **Railway** effortless deployment
- **Environment variables** untuk config
- **Health checks** endpoint /health

**Contoh Kode:**
```typescript
// main.ts — health check endpoint
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // Health check untuk cloud load balancer
  app.getHttpAdapter().get('/health', (req, res) => {
    res.status(200).json({
      status: 'healthy',
      timestamp: new Date().toISOString(),
      uptime: process.uptime(),
    });
  });

  // Cloud platform biasanya set PORT via env
  const port = process.env.PORT || 3000;
  await app.listen(port);
}
bootstrap();
```

```typescript
// serverless.ts — untuk AWS Lambda dengan @vendia/serverless-express
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { ExpressAdapter } from '@nestjs/platform-express';
import serverlessExpress from '@vendia/serverless-express';
import { Callback, Context, Handler } from 'aws-lambda';

let server: Handler;

async function bootstrap(): Promise<Handler> {
  const app = await NestFactory.create(
    AppModule,
    new ExpressAdapter(),
  );
  app.enableCors();
  await app.init();

  const expressApp = app.getHttpAdapter().getInstance();
  return serverlessExpress({ app: expressApp });
}

export const handler: Handler = async (
  event: any,
  context: Context,
  callback: Callback,
) => {
  server = server ?? (await bootstrap());
  return server(event, context, callback);
};
```
