# 37. Deployment ## 37.1 Build Production npm run build

**Definisi Singkat:** Build production adalah proses kompilasi TypeScript ke JavaScript, optimasi bundle, dan persiapan aplikasi NestJS untuk production environment menggunakan perintah `npm run build` atau `nest build`.

**Analogi:** Build production seperti proses pengepakan sebelum pindah rumah — Anda mengemas barang (TypeScript source) ke dalam kotak (JavaScript output), membuang yang tidak perlu (dev dependencies), dan memastikan semuanya rapi dan siap di rumah baru (production server).

**Poin-Poin Penting:**
- **nest build** compile TypeScript dengan tsc
- **tsconfig.build.json** konfigurasi build
- **outDir** direktori output (dist/)
- **exclude** test dan file development
- **optimization** tree shaking, minification
- **sourceMap** di production (opsional untuk debugging)

**Contoh Kode:**
```typescript
// tsconfig.build.json
{
  "extends": "./tsconfig.json",
  "compilerOptions": {
    "outDir": "./dist",
    "declaration": true,
    "declarationMap": true,
    "sourceMap": false,
    "removeComments": true
  },
  "include": ["src/**/*"],
  "exclude": [
    "node_modules",
    "dist",
    "test",
    "**/*spec.ts",
    "**/*test.ts",
    "**/mocks/**",
    "**/benchmark/**"
  ]
}
```

```typescript
// main.ts — production port
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { Logger } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  const port = process.env.PORT || 3000;
  const logger = new Logger('Bootstrap');

  // Hanya aktifkan CORS untuk domain tertentu di production
  if (process.env.NODE_ENV === 'production') {
    app.enableCors({
      origin: process.env.ALLOWED_ORIGINS?.split(',') || [],
    });
  }

  await app.listen(port);
  logger.log(`Application running on port ${port} in ${process.env.NODE_ENV} mode`);
}
bootstrap();
```

**Kasus Penggunaan Nyata:** CI/CD pipeline di GitHub Actions — setiap push ke branch `main` menjalankan `npm run build:prod`, hasil build (dist/) di-deploy ke server production. Source maps dinonaktifkan, komentar dihapus, dan hanya production dependencies yang diinstall.
