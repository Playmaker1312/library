# 37. Deployment ## 37.5 Docker Compose App DB Redis

**Definisi Singkat:** Docker Compose mengatur multi-container setup untuk aplikasi NestJS beserta dependensinya (PostgreSQL/MySQL, Redis) dengan satu file YAML, memudahkan development dan production deployment.

**Analogi:** Docker Compose seperti konduktor orkestra — dia mengoordinasikan kapan musisi (container) mulai bermain, volume suara (resource limits), dan komunikasi antar alat musik (networking). Semua pemain tidak perlu mikir koordinasi, konduktor yang atur.

**Poin-Poin Penting:**
- **docker-compose.yml** definisi service
- **depends_on** urutan startup
- **volumes** persistent data
- **networks** komunikasi antar service
- **environment** variables
- **healthcheck** kondisi siap
- **.env file** untuk secrets

**Contoh Kode:**
```typescript
// docker-compose.yml
version: '3.8'

services:
  # NestJS Application
  app:
    build:
      context: .
      dockerfile: Dockerfile
      target: production
    ports:
      - "${PORT:-3000}:3000"
    env_file:
      - .env.production
    environment:
      - NODE_ENV=production
      - DB_HOST=db
      - DB_PORT=5432
      - REDIS_HOST=redis
      - REDIS_PORT=6379
    depends_on:
      db:
        condition: service_healthy
      redis:
        condition: service_started
    restart: unless-stopped
    networks:
      - app-network
    logging:
      driver: "json-file"
      options:
        max-size: "10m"
        max-file: "3"

  # PostgreSQL Database
  db:
    image: postgres:16-alpine
    container_name: nestjs-db
    volumes:
      - postgres-data:/var/lib/postgresql/data
      - ./init.sql:/docker-entrypoint-initdb.d/init.sql
    environment:
      POSTGRES_DB: ${DB_NAME}
      POSTGRES_USER: ${DB_USER}
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    ports:
      - "${DB_PORT:-5432}:5432"
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U ${DB_USER} -d ${DB_NAME}"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 10s
    restart: unless-stopped
    networks:
      - app-network

  # Redis Cache
  redis:
    image: redis:7-alpine
    container_name: nestjs-redis
    command: redis-server --appendonly yes --requirepass ${REDIS_PASSWORD}
    volumes:
      - redis-data:/data
    ports:
      - "${REDIS_PORT:-6379}:6379"
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 10s
      timeout: 3s
      retries: 5
    restart: unless-stopped
    networks:
      - app-network

  # Redis Commander (opsional — untuk admin UI)
  redis-commander:
    image: rediscommander/redis-commander:latest
    container_name: nestjs-redis-commander
    environment:
      - REDIS_HOST=redis
      - REDIS_PORT=6379
      - REDIS_PASSWORD=${REDIS_PASSWORD}
    ports:
      - "8081:8081"
    depends_on:
      - redis
    profiles:
      - dev
    networks:
      - app-network

volumes:
  postgres-data:
    driver: local
  redis-data:
    driver: local

networks:
  app-network:
    driver: bridge
```

```typescript
// .env.production
PORT=3000
NODE_ENV=production

# Database
DB_NAME=nestjs_prod
DB_USER=postgres
DB_PASSWORD=strong_password_here
DB_PORT=5432

# Redis
REDIS_PASSWORD=redis_password_here
REDIS_PORT=6379

# JWT
JWT_SECRET=super_secret_jwt_key_change_me
JWT_EXPIRES_IN=3600s
```

```typescript
// docker-compose commands
// docker-compose up -d                    # Start semua service
// docker-compose up -d --build app        # Rebuild dan start app
// docker-compose down                     # Stop semua service
// docker-compose logs -f app              # Lihat log app
// docker-compose exec app sh              # Masuk ke container app
// docker-compose exec db psql -U postgres  # Masuk ke database
// docker-compose --profile dev up -d      # Dengan profile dev (redis-commander)
```

**Kasus Penggunaan Nyata:** Full-stack application setup untuk development — `docker-compose up -d` menjalankan NestJS app (hot reload via volume), PostgreSQL 16, Redis 7, dan Mailhog (email testing). Semua environment variable di `.env` file, data persist di Docker volumes.
