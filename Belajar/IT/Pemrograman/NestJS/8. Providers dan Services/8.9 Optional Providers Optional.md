# 8. Providers dan Services

## 8.9. Optional Providers (`@Optional`)

**Definisi Singkat:** `@Optional()` decorator menandai dependency sebagai opsional — jika provider tidak terdaftar, NestJS akan meng-inject `null` atau `undefined` daripada melempar error.

**Analogi:** Seperti power bank — Anda bawa (inject) jika ada, tapi tidak masalah jika tidak punya. HP tetap bisa dipakai tanpa power bank, hanya tidak bisa charge.

**Poin-Poin Penting:**
- `@Optional()` sebelum dependency di constructor
- Jika provider tidak ditemukan → `undefined` (bukan error)
- Berguna untuk fitur opsional (caching, logging, analytics)
- Harus handle `undefined` di kode — conditional logic
- Kombinasi dengan `@Inject('TOKEN')` untuk custom token
- Jangan gunakan untuk dependency esensial — hanya yang benar-benar opsional

**Contoh Kode:**
```typescript
import { Injectable, Optional, Inject } from '@nestjs/common';

// Cache service — opsional
interface CacheService {
  get(key: string): Promise<string | null>;
  set(key: string, value: string): Promise<void>;
}

@Injectable()
export class UsersService {
  constructor(
    @Optional()
    @Inject('CACHE_SERVICE')
    private readonly cache?: CacheService,
  ) {
    if (this.cache) {
      console.log('Cache service available — akan caching users');
    } else {
      console.log('No cache service — langsung ke database');
    }
  }

  async findOne(id: number): Promise<{ id: number; name: string }> {
    // Gunakan cache jika tersedia
    if (this.cache) {
      const cached = await this.cache.get(`user:${id}`);
      if (cached) return JSON.parse(cached);
    }

    // Query database
    const user = { id, name: 'Alice' };

    // Simpan ke cache jika tersedia
    if (this.cache) {
      await this.cache.set(`user:${id}`, JSON.stringify(user));
    }

    return user;
  }
}

// Optional logger — bisa di-enable/disable
@Injectable()
export class PaymentService {
  constructor(
    @Optional()
    private readonly logger?: LoggerService,
  ) {
    this.logger?.log('PaymentService initialized');
  }

  processPayment(amount: number) {
    this.logger?.log(`Processing payment: $${amount}`);
    return { success: true };
  }
}
```

**Kasus Penggunaan Nyata:**
Cache service yang opsional — Redis kadang tersedia kadang tidak. Logger opsional untuk environment tertentu. Analytics/telemetry yang bisa di-enable/disable. Feature flags sebagai optional provider. Extension/hook points untuk plugin system.
