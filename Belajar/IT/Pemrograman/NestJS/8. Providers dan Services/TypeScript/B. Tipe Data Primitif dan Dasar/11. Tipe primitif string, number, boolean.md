### 11. Tipe Primitif: String, Number, Boolean

Inilah "bahan bangunan" paling dasar dalam TypeScript. Meskipun JavaScript juga memiliki tipe-tipe ini, TypeScript memberikan kepastian bahwa sebuah variabel tidak akan berubah wujud di tengah jalan.

---

### Definisi Singkat

**Tipe Primitif** adalah tipe data paling sederhana yang tidak memiliki properti atau metode kompleks di dalamnya. Tiga yang paling sering digunakan adalah `string` (teks), `number` (angka), dan `boolean` (logika benar/salah).

---

### Analogi

Bayangkan Anda sedang memilah sampah di rumah (Variabel).

- **`string`** adalah kotak untuk **Kertas/Surat**. Anda bisa memasukkan kalimat, kata, atau bahkan angka asalkan ditulis di atas kertas (dalam kutip).
    
- **`number`** adalah kotak untuk **Koin/Uang**. Hanya angka murni yang bisa masuk. Tidak peduli apakah itu koin bulat (bilangan bulat) atau koin pecahan (desimal).
    
- **`boolean`** adalah **Sakelar Lampu**. Hanya ada dua kondisi: Nyala (`true`) atau Mati (`false`). Tidak ada kondisi "setengah nyala".
    

---

### Poin-Poin Penting

1. **`string`**: Digunakan untuk data tekstual. Bisa menggunakan kutip tunggal (`' '`), kutip ganda (`" "`), atau _backtick_ (`` ` ``) untuk _template strings_.
    
2. **`number`**: TypeScript tidak membedakan antara `integer` (bilangan bulat) dan `float` (desimal). Semuanya masuk kategori `number`. Ia juga mendukung format heksadesimal, biner, dan oktal.
    
3. **`boolean`**: Sangat sederhana, hanya berisi `true` atau `false`. Sangat krusial untuk logika pengkondisian (`if/else`).
    
4. **Case Sensitive**: Pastikan menulisnya dengan huruf kecil (`string`, bukan `String`). Huruf besar merujuk pada objek pembungkus JavaScript, yang sebaiknya dihindari dalam anotasi tipe.
    

---

### Contoh Implementasi

TypeScript

```
// String
let username: string = "Budi_Developer";
let bio: string = `Halo, nama saya ${username}`; // Template string

// Number
let saldo: number = 50000;      // Bilangan bulat
let rating: number = 4.8;       // Desimal
let hutang: number = -1000;     // Negatif

// Boolean
let isPremium: boolean = true;
let hasDiscount: boolean = false;

// Contoh Error:
// @ts-expect-error
isPremium = "yes"; // Error: Type 'string' is not assignable to type 'boolean'.
```

---

### Koneksi dalam Bidang Web Development

Dalam pengembangan **Web Development**, penggunaan tipe primitif ini sangat terasa pada:

- **Manipulasi DOM:** Saat Anda mengambil nilai dari `<input type="text">`, hasilnya selalu `string`. Jika Anda ingin menjumlahkannya, TypeScript akan memaksa Anda mengubahnya menjadi `number` terlebih dahulu agar tidak terjadi kesalahan `1 + 1 = "11"`.
    
- **State Management (React/Vue):** Saat membuat _state_ untuk menampilkan _loading spinner_, Anda akan menggunakan `boolean` (misal: `isLoading: true`). TypeScript memastikan Anda tidak sengaja mengisi _state_ tersebut dengan data lain yang bisa merusak tampilan UI.
    
- **API Payloads:** Saat mengirim data ke backend, Anda bisa memastikan ID pengguna adalah `number` dan alamat email adalah `string`, sehingga data yang dikirim selalu valid sesuai skema database.
