### 10. Type Annotation — Sintaks Dasar (Variabel Colon Tipe)

Inilah fondasi utama dari TypeScript. _Type Annotation_ adalah cara kita memberi tahu TypeScript jenis data apa yang boleh disimpan dalam sebuah variabel.

---

### Definisi Singkat

**Type Annotation** adalah sintaks yang menggunakan tanda titik dua (`:`) setelah nama variabel untuk menentukan tipe datanya secara eksplisit. Dengan anotasi ini, TypeScript akan mengunci variabel tersebut agar hanya bisa menerima nilai yang sesuai dengan tipenya.

---

### Analogi

Bayangkan Anda sedang menata barang di gudang menggunakan **Kotak Berlabel**.

- Di JavaScript, Anda punya kotak kosong tanpa label. Anda bisa memasukkan sepatu, lalu besoknya mengeluarkannya dan memasukkan sup ayam (kekacauan!).
    
- Di TypeScript, Anda memberikan **Label Permanen** pada kotak tersebut, misalnya label **"KHUSUS SEPATU"**. Jika Anda mencoba memasukkan sup ayam ke dalam kotak bertanda "KHUSUS SEPATU", sistem gudang akan langsung menghentikan Anda karena barang tersebut tidak sesuai dengan label kotaknya.
    

---

### Poin-Poin Penting

Sintaks dasar penulisan anotasi tipe adalah: `let namaVariabel: tipeData = nilai;`

- **Explicit Typing:** Anda menyatakan tipenya secara terang-terangan.
    
- **Tipe Dasar (Primitives):**
    
    - `string`: Untuk teks.
        
    - `number`: Untuk angka (bulat maupun desimal).
        
    - `boolean`: Untuk nilai `true` atau `false`.
        
- **Pengecekan Ketat:** Jika Anda sudah menandai variabel sebagai `: number`, Anda tidak bisa mengisinya dengan `"10"` (teks), harus `10` (angka).
    
- **Anotasi pada Fungsi:** Tidak hanya variabel, parameter fungsi dan hasil kembalian (_return value_) juga bisa diberi anotasi.
    

---

### Contoh Implementasi

**1. Pada Variabel Sederhana:**

TypeScript

```
let nama: string = "Andi";
let umur: number = 25;
let sedangBelajar: boolean = true;

// Error jika salah tipe:
// @ts-expect-error
umur = "Dua puluh lima"; // Error: Type 'string' is not assignable to type 'number'.
```

**2. Pada Parameter dan Return Function:**

TypeScript

```
function hitungLuas(panjang: number, lebar: number): number {
    return panjang * lebar;
}

const hasil = hitungLuas(10, 5); // Benar
// const gagal = hitungLuas(10, "5"); // Error!
```

---

### Koneksi dalam Bidang Web Development

Dalam pengembangan **Web Development**, _Type Annotation_ sangat membantu saat:

1. **Form Handling:** Ketika mengambil input dari user di website, Anda bisa memastikan data "Umur" yang masuk benar-benar berupa `number` sebelum dikirim ke database, mencegah error _data corruption_.
    
2. **API Integration:** Saat Anda membuat fungsi untuk mengambil data profil user, Anda bisa mendefinisikan bahwa fungsi tersebut _harus_ mengembalikan objek dengan tipe `string` untuk nama, sehingga komponen UI Anda tidak akan "pecah" karena mencoba menampilkan data yang salah.
    
3. **Readability:** Saat Anda bekerja dalam tim dan membuka file buatan rekan Anda, Anda langsung tahu variabel `totalPrice` itu tipenya apa tanpa harus menelusuri ratusan baris kode ke atas.
    

Apakah Anda ingin lanjut mempelajari **Type Inference**, di mana TypeScript bisa menebak tipe data tanpa kita tulis titik duanya?
