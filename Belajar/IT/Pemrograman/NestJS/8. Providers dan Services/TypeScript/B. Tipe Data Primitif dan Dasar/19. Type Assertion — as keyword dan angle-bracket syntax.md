### 19. Type Assertion — `as` Keyword dan Angle-Bracket Syntax

Terkadang, Anda sebagai pengembang tahu lebih banyak tentang tipe data suatu variabel daripada yang bisa diketahui oleh TypeScript. **Type Assertion** adalah cara Anda memberi tahu TypeScript: "Percayalah padaku, aku tahu apa yang aku lakukan."

---

### Definisi Singkat

**Type Assertion** adalah mekanisme untuk memberi tahu compiler tipe data spesifik dari suatu nilai secara manual. Ini bukan konversi tipe data (_type casting_) yang mengubah nilai saat aplikasi berjalan, melainkan hanya instruksi bagi compiler untuk memperlakukan suatu variabel sebagai tipe tertentu selama proses pengecekan kode.

---

### Analogi

Bayangkan Anda sedang berada di sebuah **Pesta Topeng**.

- **TypeScript** adalah petugas keamanan yang hanya melihat orang berdasarkan topeng yang mereka pakai (misal: topeng "Tamu Misterius").
    
- **Type Assertion** adalah ketika Anda mendekati petugas itu dan berbisik, "Hei, di balik topeng ini, aku sebenarnya adalah sang Walikota."
    
- Petugas tersebut akan memperlakukan Anda sebagai Walikota karena Anda yang mengatakannya, meskipun ia sendiri tidak bisa melihat wajah Anda. Namun, jika Anda berbohong dan ternyata Anda bukan Walikota, masalah akan muncul saat Anda mencoba berpidato (menjalankan kode).
    

---

### Poin-Poin Penting

1. **Sintaks `as` (Disarankan):** Menggunakan kata kunci `as`, misalnya `variabel as string`. Ini adalah cara standar dan kompatibel dengan JSX (React).
    
2. **Sintaks Angle-Bracket:** Menggunakan tanda kurung siku, misalnya `<string>variabel`. **Catatan:** Cara ini tidak bisa digunakan di file `.tsx` karena bentrok dengan sintaks komponen React.
    
3. **Bukan Konversi:** Assertion tidak mengubah angka menjadi string atau sebaliknya. Ia hanya "melabeli" ulang tipe data di mata compiler.
    
4. **Risiko:** Jika Anda salah melakukan assertion (misal: memaksa `any` yang isinya angka dianggap sebagai `string`), TypeScript tidak akan protes, tetapi aplikasi bisa _crash_ saat dijalankan.

### Contoh Implementasi

**Kasus: Mengambil elemen dari DOM (Sering terjadi di Web Dev)**

TypeScript

```
// TypeScript mengira ini adalah 'HTMLElement' biasa (masih umum)
const tombolSumbit = document.getElementById("btn-submit");

// Kita tahu pasti ini adalah 'HTMLButtonElement' yang punya properti .disabled
// Gunakan 'as' untuk akses fitur spesifik button:
const button = tombolSumbit as HTMLButtonElement;
button.disabled = true; 

// Sintaks Angle-Bracket (Alternatif, tapi hindari di React):
let nilaiInput: any = "Halo Dunia";
let panjangString = (<string>nilaiInput).length;
```

---

### Koneksi dalam Bidang Web Development

Dalam pengembangan **Web Development**, Type Assertion sangat sering digunakan untuk:

1. **DOM Manipulation:** Seperti contoh di atas, saat mengambil elemen dengan `querySelector` atau `getElementById`, TypeScript seringkali hanya memberikan tipe dasar. Assertion membantu kita mengakses properti spesifik (seperti `.value` pada `HTMLInputElement`).
    
2. **Handling API Responses:** Jika Anda menerima data `any` atau `unknown` dari API pihak ketiga dan Anda yakin dengan strukturnya, Anda bisa menggunakan `as MyInterface` untuk mendapatkan fitur _autocomplete_.
    
3. **Event Handling:** Saat menangani event klik, Anda mungkin perlu melakukan assertion pada `event.target` agar bisa mengakses properti spesifik dari elemen yang diklik.
