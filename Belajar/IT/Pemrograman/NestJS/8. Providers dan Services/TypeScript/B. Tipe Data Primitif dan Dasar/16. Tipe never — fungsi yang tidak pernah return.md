### 16. Tipe `never` — Fungsi yang Tidak Pernah Selesai

Tipe `never` sering dianggap membingungkan karena mirip dengan `void`, namun secara teknis dan logika, keduanya sangat berbeda. `never` mewakili nilai yang **tidak akan pernah ada**.

---

### Definisi Singkat

**`never`** adalah tipe data yang digunakan untuk fungsi yang benar-benar tidak pernah mengembalikan kontrol ke pemanggilnya. Ini terjadi jika fungsi tersebut melemparkan pengecualian (_error/exception_) atau terjebak dalam perulangan tak terbatas (_infinite loop_).

---

### Analogi

Bayangkan Anda sedang memesan makanan di sebuah restoran (Fungsi).

- **`void` (Petugas Kebersihan):** Anda memanggilnya untuk membersihkan meja. Dia bekerja, selesai, lalu pergi. Dia kembali ke posisi semula setelah tugasnya beres.
    
- **`never` (Lubang Hitam/Kiamat):** Anda memanggil koki, tapi tiba-tiba dapur meledak atau restoran tersebut tertelan lubang hitam. Koki tersebut tidak pernah kembali ke meja Anda, bukan karena dia selesai bekerja, tapi karena dunianya "berhenti" atau hancur sebelum tugasnya selesai.
    

---

### Poin-Poin Penting

- **Unreachable Code:** `never` menunjukkan bahwa baris kode setelah pemanggilan fungsi tersebut tidak akan pernah dieksekusi.
    
- **Exhaustive Checking:** `never` sering digunakan dalam logika `switch-case` untuk memastikan bahwa semua kemungkinan tipe data telah ditangani (jika sampai ke blok `never`, berarti ada tipe yang terlewat).
    
- **Perbedaan dengan `void`:** * `void` = Selesai bekerja, tapi tidak bawa apa-apa (mengembalikan `undefined`).
    
    - `never` = Tidak pernah selesai bekerja (program berhenti atau berputar selamanya).
        

---

### Contoh Implementasi

**1. Fungsi yang Melemparkan Error:**

TypeScript

```
function tampilkanError(pesan: string): never {
    throw new Error(pesan);
    // Baris di bawah ini tidak akan pernah dijalankan
}
```

**2. Exhaustive Checking (Keamanan Tambahan):**

TypeScript

```
type Hewan = "Kucing" | "Anjing";

function suaraHewan(hewan: Hewan) {
    switch (hewan) {
        case "Kucing":
            return "Meong";
        case "Anjing":
            return "Guk";
        default:
            // Jika kita menambah tipe baru ke 'Hewan' tapi lupa update switch,
            // variabel 'check' di bawah akan error karena bukan lagi 'never'.
            const check: never = hewan;
            return check;
    }
}
```

---

### Koneksi dalam Bidang Web Development

Dalam pengembangan **Web Development**, `never` sangat berguna untuk:

1. **Global Error Handling:** Saat Anda membuat fungsi bantuan untuk menangani _error_ aplikasi atau kegagalan otentikasi yang harus segera menghentikan eksekusi kode.
    
2. **Type Safety yang Ketat:** Memastikan bahwa logika aplikasi Anda sudah mencakup semua skenario. Jika Anda mengintegrasikan API dengan banyak status (misal: `loading`, `success`, `error`), `never` akan membantu mendeteksi jika ada status baru yang belum Anda tangani di kode _frontend_.
    
3. **Hadir dalam Library:** Banyak library _routing_ atau _state management_ menggunakan `never` di balik layar untuk memastikan tipe data yang mustahil tidak akan pernah masuk ke dalam sistem.
