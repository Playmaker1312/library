### 15. Tipe `void` — Untuk Fungsi Tanpa Return

Dalam TypeScript, setiap fungsi biasanya menghasilkan sesuatu. Namun, ada kalanya sebuah fungsi hanya bertugas melakukan aksi tanpa memberikan jawaban balik. Di sinilah `void` berperan.

---

### Definisi Singkat

**`void`** adalah tipe data yang digunakan khusus untuk menyatakan bahwa sebuah fungsi **tidak mengembalikan nilai** (_return value_). Jika sebuah fungsi didefinisikan dengan tipe `void`, maka fungsi tersebut hanya menjalankan instruksi di dalamnya lalu selesai.

---

### Analogi

Bayangkan Anda sedang memberikan instruksi kepada dua jenis staf di sebuah restoran:

- **Koki (Fungsi dengan Return):** Anda meminta koki membuat burger. Koki bekerja, lalu **memberikan** burger itu kepada Anda. Ada "benda" yang dikembalikan.
    
- **Petugas Kebersihan (Fungsi `void`):** Anda meminta petugas untuk mengelap meja. Petugas bekerja, meja menjadi bersih, lalu petugas pergi. Petugas **tidak memberikan** benda apa pun kepada Anda; mereka hanya melakukan tugasnya.
    

---

### Poin-Poin Penting

- **Indikator Aksi:** `void` biasanya digunakan untuk fungsi yang melakukan _side effects_, seperti mencetak log, mengubah variabel global, atau memanipulasi tampilan (DOM).
    
- **Default Behavior:** Di JavaScript, fungsi yang tidak punya kata kunci `return` secara teknis mengembalikan `undefined`. Namun di TypeScript, kita menggunakan `void` untuk memperjelas niat kita bahwa fungsi tersebut memang tidak didesain untuk menghasilkan nilai.
    
- **Bukan untuk Variabel:** Meskipun secara teknis Anda bisa membuat variabel `let x: void`, hal ini hampir tidak pernah berguna karena variabel tersebut hanya bisa diisi dengan `undefined`.
    

---

### Contoh Implementasi

**1. Penulisan Dasar:**

TypeScript

```
function logPesan(pesan: string): void {
    console.log("LOG SYSTEM: " + pesan);
    // Tidak ada baris 'return ...' di sini
}

const hasil = logPesan("User login"); 
// 'hasil' akan bertipe void (isinya undefined jika dipaksa cetak)
```

**2. Error Jika Mencoba Mengembalikan Nilai:**

TypeScript

```
// @ts-expect-error
function hapusData(): void {
    const sukses = true;
    return sukses; // Error: Type 'boolean' is not assignable to type 'void'.
}
```

---

### Koneksi dalam Bidang Web Development

Dalam pengembangan **Web Development**, tipe `void` sangat sering muncul pada:

1. **Event Handlers:** Fungsi yang dijalankan saat tombol diklik (misal: `onClick`) biasanya bertipe `void` karena mereka hanya memicu aksi (seperti membuka modal atau mengirim data) tanpa perlu mengembalikan nilai ke tombol tersebut.
    
2. **Logging & Analytics:** Fungsi yang mengirim data statistik ke server di latar belakang sering kali bertipe `void`.
    
3. **State Updaters (React):** Fungsi seperti `setCount(prev => prev + 1)` di dalam komponen sering kali dibungkus dalam fungsi pembantu yang bertipe `void` untuk memperjelas bahwa fungsi tersebut hanya bertugas mengubah data, bukan menghasilkan data baru untuk variabel lain.
