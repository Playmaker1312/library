### 7. Menulis dan Menjalankan Program TypeScript Pertama

Ini adalah momen "Hello World" Anda. Di sini, kita akan mempraktikkan semua materi sebelumnya—mulai dari menulis kode, mengatur struktur folder, hingga melakukan kompilasi.

---

### Definisi Singkat

**Menjalankan program TypeScript** adalah siklus pengembangan di mana Anda menulis kode dalam file `.ts`, mengonversinya menjadi `.js` menggunakan perintah `tsc`, dan mengeksekusi hasilnya menggunakan _environment_ seperti Browser atau Node.js.

---

### Analogi

Bayangkan Anda sedang menulis sebuah **Resep Rahasia** (TypeScript).

1. **Menulis:** Anda menulis resep tersebut dengan catatan kaki yang sangat detail (tipe data).
    
2. **Kompilasi:** Anda memberikan resep itu ke asisten (Compiler) untuk disalin ke selembar kertas bersih tanpa coretan teknis (JavaScript).
    
3. **Menjalankan:** Kertas bersih itulah yang akhirnya dibawa ke dapur (Node.js/Browser) untuk dimasak menjadi hidangan nyata.
    

---

### Poin-Poin Penting

- **Struktur Folder:** Sangat disarankan memisahkan kode sumber (`src/`) dan hasil jadi (`dist/`).
    
- **Ekstensi File:** Selalu gunakan `.ts` untuk file TypeScript.
    
- **Workflow Standar:**
    
    1. Tulis kode di `src/index.ts`.
        
    2. Jalankan `npx tsc` (untuk membaca `tsconfig.json`).
        
    3. Jalankan file hasil di `dist/index.js` menggunakan `node`.
        
- **Mode Watch:** Gunakan perintah `tsc -w` agar compiler otomatis bekerja setiap kali Anda menekan tombol _Save_ (Ctrl+S).
    

---

### Contoh Implementasi

**1. Persiapan Struktur Folder:**

Bash

```
mkdir projek-pertama
cd projek-pertama
mkdir src
npm init -y
npm install --save-dev typescript
npx tsc --init
```

**2. Menulis Kode (`src/index.ts`):**

TypeScript

```
const pesan: string = "Halo, TypeScript!";

function tampilkanPesan(teks: string): void {
    console.log(teks);
}

tampilkanPesan(pesan);
```

**3. Menjalankan (Terminal):** Sesuaikan `tsconfig.json` Anda (set `outDir: "./dist"` dan `rootDir: "./src"`), lalu:

Bash

```
# Kompilasi
npx tsc

# Jalankan hasil JavaScript-nya
node dist/index.js
```

_Output: Halo, TypeScript!_

---

### Koneksi dalam Bidang Web Development

Dalam rutinitas **Web Development**:

1. **Fast Feedback Loop:** Pengembang biasanya tidak menjalankan `tsc` secara manual setiap saat. Kita menggunakan alat seperti **ts-node** atau **Vite** yang memungkinkan kita melihat perubahan secara instan tanpa menunggu proses kompilasi manual.
    
2. **Error Prevention:** Saat Anda menulis `tampilkanPesan(123)` di langkah 2, VS Code akan langsung memberikan garis merah sebelum Anda sempat menjalankan perintah `node`. Inilah "kekuatan utama" yang membuat development web jadi lebih stabil.
    
3. **Modern Build Tools:** Di proyek nyata (React/Next.js), langkah "Menjalankan" ini sudah diotomatisasi oleh _bundler_, sehingga Anda cukup fokus pada file `.ts` saja.
    

Apakah Anda ingin tahu cara membuat proses ini lebih cepat menggunakan alat otomatis seperti `ts-node`?
