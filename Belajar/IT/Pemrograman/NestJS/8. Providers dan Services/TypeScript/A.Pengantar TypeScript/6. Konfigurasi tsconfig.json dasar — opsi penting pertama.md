### 6. Konfigurasi tsconfig.json Dasar — Opsi Penting Pertama

Jika `tsc` adalah mesinnya, maka `tsconfig.json` adalah buku manual atau panel kendali yang mengatur bagaimana mesin tersebut bekerja.

---

### Definisi Singkat

**tsconfig.json** adalah file konfigurasi dalam format JSON yang terletak di akar proyek TypeScript. File ini memberi tahu compiler file mana saja yang harus diproses dan aturan apa saja (seperti ketat atau longgar) yang harus diterapkan saat mengubah kode ke JavaScript.

---

### Analogi

Bayangkan Anda memiliki robot koki (Compiler).

- Tanpa `tsconfig.json`, Anda harus memberi perintah satu per satu setiap hari: "Masak telur, jangan terlalu asin, gunakan api kecil, pakai piring putih."
    
- Dengan `tsconfig.json`, Anda cukup menuliskan semua preferensi Anda di selembar kertas dan menempelkannya di dinding. Setiap kali Anda bilang "Masak!", si robot akan membaca kertas tersebut dan bekerja sesuai aturan yang sudah Anda tetapkan secara otomatis.
    

---

### Poin-Poin Penting

Ada beberapa opsi utama yang biasanya menjadi fokus pertama:

- **`target`**: Menentukan versi JavaScript hasil akhir (misal: `ES5` untuk browser lama atau `ESNext` untuk fitur terbaru).
    
- **`module`**: Mengatur sistem modul yang digunakan (misal: `CommonJS` untuk Node.js atau `ESNext` untuk web modern).
    
- **`outDir`**: Menentukan folder tujuan tempat file `.js` hasil kompilasi akan disimpan (biasanya folder `dist` atau `build`).
    
- **`rootDir`**: Menentukan di mana file sumber `.ts` berada (biasanya folder `src`).
    
- **`strict`**: Jika `true`, TypeScript akan mengaktifkan mode "Sangat Ketat", memaksa Anda menulis kode yang lebih aman dan tanpa celah.
    
- **`include` & `exclude`**: Memberi tahu compiler folder mana yang harus dipantau dan mana yang harus diabaikan (seperti `node_modules`).
    

---

### Contoh Implementasi

Untuk membuat file ini, Anda bisa menjalankan perintah: `npx tsc --init`. Berikut adalah contoh isi `tsconfig.json` yang minimalis namun fungsional:

JSON

```
{
  "compilerOptions": {
    "target": "ES6",                // Hasil akhir adalah JavaScript ES6
    "module": "CommonJS",           // Menggunakan format modul Node.js
    "rootDir": "./src",             // Cari file .ts di folder src
    "outDir": "./dist",             // Simpan file .js di folder dist
    "strict": true,                 // Aktifkan semua pengecekan ketat
    "esModuleInterop": true         // Memudahkan impor modul CommonJS
  },
  "include": ["src/**/*"],          // Kompilasi semua file di dalam src
  "exclude": ["node_modules"]       // Abaikan folder node_modules
}
```

---

### Koneksi dalam Bidang Web Development

Dalam pengembangan web, `tsconfig.json` sangat vital untuk:

1. **Konsistensi Tim:** Memastikan semua developer dalam tim menggunakan aturan "ketat" yang sama, sehingga tidak ada kode "berantakan" yang masuk ke repositori.
    
2. **Optimasi Build:** Dengan mengatur `outDir` dan `rootDir`, Anda menjaga struktur proyek tetap rapi (kode sumber terpisah dari kode produksi).
    
3. **Kecocokan Browser:** Anda bisa menulis kode dengan fitur tercanggih, namun tetap bisa berjalan di browser lama hanya dengan mengubah opsi `target` tanpa menyentuh satu baris kode pun.
