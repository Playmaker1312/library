### 9. Integrasi TypeScript dengan VS Code (Extensions, Settings, IntelliSense)

TypeScript dan Visual Studio Code (VS Code) keduanya diciptakan oleh Microsoft, sehingga "chemistry" di antara keduanya sangat luar biasa. VS Code sebenarnya sudah memiliki mesin TypeScript bawaan.

---

### Definisi Singkat

**Integrasi TypeScript di VS Code** adalah pemanfaatan fitur editor yang memberikan umpan balik instan, saran kode otomatis (**IntelliSense**), dan alat navigasi yang memudahkan pengembang menulis kode TypeScript tanpa harus sering-sering menjalankan compiler secara manual.

---

### Analogi

Bayangkan Anda sedang menulis buku menggunakan mesin tik (Editor teks biasa) dibandingkan dengan menggunakan **Aplikasi Penulisan Modern dengan AI** (VS Code + TypeScript).

- Pada mesin tik, jika Anda salah mengeja nama tokoh di halaman 100, tidak ada yang memberi tahu Anda.
    
- Pada aplikasi modern, saat Anda baru mengetik huruf pertama nama tokoh tersebut, aplikasi langsung memberikan saran nama lengkapnya. Jika Anda salah ketik, muncul garis bawah merah seketika. Anda bahkan bisa klik kanan pada nama tokoh tersebut untuk melihat di halaman mana saja ia pernah muncul.
    

---

### Poin-Poin Penting

- **IntelliSense:** Fitur yang memberikan saran otomatis saat Anda mengetik. Ia tahu properti apa saja yang tersedia dalam sebuah objek atau parameter apa yang dibutuhkan oleh sebuah fungsi.
    
- **Built-in Support:** VS Code sudah mendukung TypeScript secara _out-of-the-box_. Namun, Anda bisa menambahkan ekstensi seperti **"ESLint"** untuk merapikan kode atau **"Pretty TypeScript Errors"** agar pesan error lebih mudah dibaca.
    
- **Hover Information:** Cukup arahkan kursor ke sebuah variabel atau fungsi, VS Code akan menampilkan "kartu info" yang menjelaskan tipe data dan dokumentasinya.
    
- **Go to Definition (F12):** Memungkinkan Anda melompat langsung ke asal-usul sebuah fungsi atau tipe data, meskipun berada di file yang berbeda.
    
- **Refactoring Tools:** Fitur seperti _Rename Symbol_ (F2) yang akan mengubah nama variabel di seluruh proyek secara akurat tanpa merusak logika kode.
    

---

### Contoh Implementasi

**Pengaturan `settings.json` di VS Code:** Anda bisa memaksa VS Code untuk selalu menggunakan versi TypeScript yang ada di dalam proyek (lokal) daripada versi bawaan editor:

1. Buka Command Palette (`Ctrl+Shift+P`).
    
2. Ketik "Open User Settings (JSON)".
    
3. Tambahkan/pastikan baris ini ada untuk meningkatkan kenyamanan:
    

JSON

```
{
  "typescript.suggest.completeFunctionCalls": true, // Otomatis isi tanda kurung fungsi
  "editor.formatOnSave": true,                      // Rapikan kode saat simpan
  "typescript.updateImportsOnFileMove.enabled": "always" // Update path import jika file dipindah
}
```

---

### Koneksi dalam Bidang Web Development

Dalam rutinitas **Web Development**, integrasi ini sangat vital karena:

1. **Mencegah Konteks Switching:** Anda tidak perlu terus-menerus membuka dokumentasi library (seperti dokumentasi React atau Tailwind). Cukup ketik kodenya, dan IntelliSense akan memberi tahu opsi yang tersedia.
    
2. **Kecepatan Coding:** Fitur _Auto-Import_ di VS Code akan otomatis menambahkan baris `import` di bagian atas file saat Anda menggunakan komponen dari file lain.
    
3. **Kualitas Kode:** Dengan fitur _Error Squiggles_ (garis bergelombang merah/kuning), Anda bisa memperbaiki kesalahan logika sebelum kode tersebut sempat dicoba di browser, menghemat waktu proses _debugging_ hingga 50%.
