# 8. Providers dan Services

## 8.6. Constructor-based Injection

**Definisi Singkat:** Constructor-based injection adalah cara mendeklarasikan dependency di parameter constructor. NestJS DI Container membaca tipe parameter dan menyediakan instance yang sesuai.

**Analogi:** Seperti mesin kopi yang menerima "kapsul kopi" di slot-nya — Anda tinggal memasukkan kapsul (dependency), mesin (DI) otomatis mengekstrak kopi. Tidak perlu merakit mesin sendiri.

**Poin-Poin Penting:**
- Dependency dideklarasikan di constructor: `constructor(private svc: UsersService)`
- TypeScript type inference — NestJS tahu tipe dari type annotation
- `private`/`public`/`protected` otomatis membuat `this.property`
- Bisa inject multiple dependencies
- Circular dependency — gunakan `@Inject(forwardRef(() => Service))`
- Optional dependency — `@Optional()` decorator

**Contoh Kode:**
```typescript
import { Injectable, Optional, Inject, forwardRef } from '@nestjs/common';

// Standard constructor injection
@Injectable()
export class UsersService {
  constructor(
    private readonly db: DatabaseService,
    private readonly logger: LoggerService,
    private readonly mailer: MailerService,
  ) {
    // this.db, this.logger, this.mailer sudah tersedia
    this.logger.log('UsersService initialized');
  }
}

// Optional dependency — tidak wajib
@Injectable()
export class OptionalService {
  constructor(
    @Optional()
    @Inject('CACHE_SERVICE')
    private readonly cache?: CacheService,
  ) {
    if (this.cache) {
      console.log('Cache available');
    }
  }
}

// Circular dependency — @Inject(forwardRef)
@Injectable()
export class ServiceA {
  constructor(
    @Inject(forwardRef(() => ServiceB))
    private readonly serviceB: ServiceB,
  ) {}
}

// Controller juga constructor injection
@Controller('users')
export class UsersController {
  constructor(
    private readonly usersService: UsersService,
    private readonly logger: LoggerService,
  ) {}

  @Get()
  findAll() {
    this.logger.log('Finding all users');
    return this.usersService.findAll();
  }
}
```

**Kasus Penggunaan Nyata:**
Setiap class NestJS menggunakan constructor injection: Controller inject Service, Service inject Repository/Service lain, Guard inject AuthService, Pipe inject ConfigService. Ini adalah DI pattern utama di NestJS.
