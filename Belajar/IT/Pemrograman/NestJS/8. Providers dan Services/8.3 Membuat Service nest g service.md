# 8. Providers dan Services

## 8.3. Membuat Service: `nest g service`

**Definisi Singkat:** `nest g service <name>` adalah CLI command untuk generate service — class dengan `@Injectable()` yang berisi business logic aplikasi.

**Analogi:** Seperti merekrut staf ahli — `nest g service users` sama dengan memasang ik lowongan "Staff Ahli Users". HRD (CLI) menyiapkan kontrak (`@Injectable()`) dan mendaftarkannya ke departemen (module).

**Poin-Poin Penting:**
- Sintaks: `nest g service <nama>`
- Generate: `src/<nama>/<nama>.service.ts`
- Update module: daftarkan di `providers`
- Opsi `--flat` — tanpa subfolder
- Opsi `--no-spec` — skip test file
- Otomatis ditambahkan `@Injectable()`
- Best practice: service dipanggil controller, service panggil repository

**Contoh Kode:**
```bash
# Generate service
nest g service users
# CREATE src/users/users.service.ts
# UPDATE src/users/users.module.ts

# Generate di path spesifik
nest g service common/mailer
# CREATE src/common/mailer/mailer.service.ts

# Flat — langsung di folder src
nest g service health --flat
# CREATE src/health.service.ts
```

```typescript
// Hasil generate — users.service.ts
import { Injectable } from '@nestjs/common';

@Injectable()
export class UsersService {
  constructor() {}

  findAll(): string {
    return 'All users';
  }
}

// Module terupdate
import { Module } from '@nestjs/common';
import { UsersController } from './users.controller';
import { UsersService } from './users.service';

@Module({
  controllers: [UsersController],
  providers: [UsersService], // service terdaftar
})
export class UsersModule {}
```

**Kasus Penggunaan Nyata:**
Setiap fitur punya service: `UsersService`, `ProductsService`, `OrdersService`. Service bisa inject service lain dan repository. Gunakan `nest g resource` untuk generate controller + service + module sekaligus.
