# 8. Providers dan Services

## 8.2. Apa itu Provider

**Definisi Singkat:** Provider adalah class yang dapat di-inject sebagai dependency ke class lain — ditandai dengan decorator `@Injectable()`. Service, Repository, Factory, Helper — semuanya adalah provider.

**Analogi:** Provider seperti "staff ahli" di perusahaan — Anda tidak perlu merekrut sendiri, HRD (DI Container) yang menyediakan. Ada berbagai tipe staff: full-time (useClass), kontraktor (useValue), atau anak magang (useFactory).

**Poin-Poin Penting:**
- Decorator `@Injectable()` menandai class sebagai provider
- Provider bisa berupa: class, value, factory, atau alias
- Terdaftar di `@Module({ providers: [...] })`
- Bisa di-inject ke controller, service, guard, interceptor, pipe
- Bisa di-export untuk module lain
- Default scope: singleton (satu instance untuk seluruh app)

**Contoh Kode:**
```typescript
import { Injectable, Module, Inject } from '@nestjs/common';

// Provider standar — class dengan @Injectable()
@Injectable()
export class LoggerService {
  log(message: string) {
    console.log(`[LOG]: ${message}`);
  }
}

@Injectable()
export class EmailService {
  constructor(private readonly logger: LoggerService) {}

  send(email: string, subject: string) {
    this.logger.log(`Sending email to ${email}: ${subject}`);
    return { sent: true };
  }
}

// Provider bisa di-inject di mana saja
@Injectable()
export class AuthGuard {
  constructor(private readonly logger: LoggerService) {}

  canActivate(): boolean {
    this.logger.log('Checking auth...');
    return true;
  }
}

@Controller('users')
export class UsersController {
  constructor(
    private readonly emailService: EmailService,
    private readonly logger: LoggerService,
  ) {}

  @Post()
  create() {
    this.logger.log('Creating user...');
    this.emailService.send('user@test.com', 'Welcome!');
    return { created: true };
  }
}
```

**Kasus Penggunaan Nyata:**
Semua class dengan `@Injectable()` adalah provider: Service (business logic), Repository (data access), MailService (email), CacheService (caching), NotificationService (push/notif), PaymentService (payment processing).
