# 8. Providers dan Services

## 8.8. Custom Providers: `useClass`, `useValue`, `useFactory`

**Definisi Singkat:** Custom providers adalah cara mendaftarkan provider dengan token dan implementasi kustom — `useClass` (alias class), `useValue` (nilai/object langsung), `useFactory` (factory function).

**Analogi:**
- `useClass` = "Staff Ahli" → "Kontraktor" (ganti implementasi, interface sama)
- `useValue` = "Resep masakan" (nilai langsung, bukan class)
- `useFactory` = "Mesin Custom" (fabrikasi sesuai kebutuhan dengan parameter)

**Poin-Poin Penting:**
- `provide` — token inject (bisa string atau class)
- `useClass` — class yang akan di-instantiate
- `useValue` — nilai tetap (object, string, config)
- `useFactory` — function yang mengembalikan nilai (bisa inject dependencies)
- `useExisting` — alias untuk provider yang sudah ada
- Custom token di-inject dengan `@Inject('TOKEN')`

**Contoh Kode:**
```typescript
import { Module, Injectable, Inject } from '@nestjs/common';

// useValue — config object
const DATABASE_CONFIG = { host: 'localhost', port: 5432 };

// useClass — dynamic implementation
interface Logger {
  log(message: string): void;
}

class FileLogger implements Logger {
  log(message: string) {
    console.log(`[File]: ${message}`);
  }
}

class CloudLogger implements Logger {
  log(message: string) {
    console.log(`[Cloud]: ${message}`);
  }
}

// useFactory — factory dengan dependencies
@Injectable()
class DatabaseConnection {
  constructor(private readonly config: typeof DATABASE_CONFIG) {
    console.log(`Connected to ${config.host}:${config.port}`);
  }
}

@Module({
  providers: [
    // useValue — static value
    { provide: 'DATABASE_CONFIG', useValue: DATABASE_CONFIG },

    // useClass — dynamic implementation
    {
      provide: 'LOGGER',
      useClass: process.env.NODE_ENV === 'production'
        ? CloudLogger
        : FileLogger,
    },

    // useFactory — factory function
    {
      provide: DatabaseConnection,
      useFactory: (config: typeof DATABASE_CONFIG) => {
        return new DatabaseConnection(config);
      },
      inject: ['DATABASE_CONFIG'],
    },
  ],
})
export class AppModule {}

// Inject custom provider
@Injectable()
export class UsersService {
  constructor(
    @Inject('LOGGER') private readonly logger: Logger,
    @Inject('DATABASE_CONFIG') private readonly dbConfig: typeof DATABASE_CONFIG,
  ) {}
}
```

**Kasus Penggunaan Nyata:**
`useValue` untuk konfigurasi/nilai tetap. `useClass` untuk strategi bergantung environment (dev vs prod). `useFactory` untuk koneksi database dengan parameter dinamis, Redis client, atau konfigurasi berdasarkan env vars.
