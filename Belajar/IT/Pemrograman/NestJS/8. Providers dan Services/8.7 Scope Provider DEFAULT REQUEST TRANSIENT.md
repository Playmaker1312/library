# 8. Providers dan Services

## 8.7. Scope Provider: DEFAULT, REQUEST, TRANSIENT

**Definisi Singkat:** Scope provider menentukan siklus hidup instance provider — DEFAULT (singleton, satu instance untuk semua), REQUEST (instance baru per request), TRANSIENT (instance baru setiap kali di-inject).

**Analogi:**
- DEFAULT = chef utama (satu orang untuk semua meja)
- REQUEST = waiter khusus (satu waiter per meja)
- TRANSIENT = tissu dapur (baru setiap kali diambil, tidak di-share)

**Poin-Poin Penting:**
- `Scope.DEFAULT` — singleton, satu instance untuk seluruh app (default)
- `Scope.REQUEST` — instance baru setiap HTTP request
- `Scope.TRANSIENT` — instance baru setiap consumer injection
- REQUEST scope bisa inject `REQUEST` object (akses request context)
- TRANSIENT tidak di-cache — setiap inject instance baru
- Hati-hati dengan memory dan performance — REQUEST/TRANSIENT lebih berat

**Contoh Kode:**
```typescript
import { Injectable, Scope, Inject, Module } from '@nestjs/common';
import { REQUEST } from '@nestjs/core';
import { Request } from 'express';

// DEFAULT — singleton (default, tidak perlu deklarasi)
@Injectable()
export class ConfigService {
  private readonly config = { port: 3000, env: 'development' };

  get(key: string): unknown {
    return this.config[key as keyof typeof this.config];
  }
}

// REQUEST — baru per request
@Injectable({ scope: Scope.REQUEST })
export class RequestContextService {
  constructor(@Inject(REQUEST) private readonly request: Request) {
    console.log('New instance per request:', request.url);
  }

  getUserId(): string | undefined {
    return (this.request as any).user?.id;
  }

  getUrl(): string {
    return this.request.url;
  }
}

// TRANSIENT — baru setiap inject
@Injectable({ scope: Scope.TRANSIENT })
export class TransientLoggerService {
  private readonly instanceId = Math.random().toString(36).slice(2);

  log(message: string) {
    console.log(`[Logger-${this.instanceId}] ${message}`);
  }
}
```

**Kasus Penggunaan Nyata:**
DEFAULT untuk service, repository, config — hemat memory. REQUEST untuk request context (tenant ID, user ID, tracing). TRANSIENT untuk helper/utility yang butuh state terisolasi. Hati-hati: REQUEST scope di service bisa merambat ke dependennya.
