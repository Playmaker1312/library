# 29. Testing
## 29.2 Unit Testing Jest Setup
**Definisi Singkat:** NestJS menggunakan Jest sebagai default testing framework dengan konfigurasi yang sudah terintegrasi melalui `@nestjs/testing`, menyediakan `Test.createTestingModule()` untuk membuat modul test isolasi.
**Analogi:** Seperti meja kerja tukang jam — Jest adalah meja dengan alat-alat standar (matchers, mocking, spies), dan `TestingModule` adalah dudukan khusus untuk memasang komponen jam yang akan diuji.
**Poin-Poin Penting:**
- Jest pre-configured di project NestJS
- `@nestjs/testing` TestModule
- `Test.createTestingModule({})` API
- `compile()` dan `get()` untuk akses provider
**Contoh Kode:**
```typescript
// package.json — konfigurasi Jest (auto-generated oleh NestJS CLI)
{
  "jest": {
    "moduleFileExtensions": ["js", "json", "ts"],
    "rootDir": "src",
    "testRegex": ".*\\.spec\\.ts$",
    "transform": {
      "^.+\\.(t|j)s$": "ts-jest"
    },
    "collectCoverageFrom": ["**/*.(t|j)s"],
    "coverageDirectory": "../coverage",
    "testEnvironment": "node",
    "moduleNameMapper": {
      "^@/(.*)$": "<rootDir>/$1"
    }
  }
}
```
```typescript
// jest.config.ts — konfigurasi manual (alternatif)
import type { Config } from 'jest';

const config: Config = {
  moduleFileExtensions: ['js', 'json', 'ts'],
  rootDir: 'src',
  testRegex: '.*\\.spec\\.ts$',
  transform: {
    '^.+\\.(t|j)s$': 'ts-jest',
  },
  collectCoverageFrom: [
    '**/*.(t|j)s',
    '!**/*.module.ts',
    '!**/*.dto.ts',
    '!**/*.entity.ts',
    '!**/*.interface.ts',
    '!main.ts',
  ],
  coverageDirectory: '../coverage',
  testEnvironment: 'node',
  coverageThreshold: {
    global: {
      branches: 80,
      functions: 80,
      lines: 80,
      statements: 80,
    },
  },
  coverageReporters: ['text', 'lcov', 'html'],
  verbose: true,
  // Timeout untuk async test
  testTimeout: 30000,
};

export default config;
```
```typescript
// Setup dasar unit test — users.service.spec.ts
import { Test, TestingModule } from '@nestjs/testing';
import { UsersService } from './users.service';
import { getRepositoryToken } from '@nestjs/typeorm';
import { User } from './entities/user.entity';

describe('UsersService', () => {
  let service: UsersService;
  let mockUserRepository: any;

  // Setup sebelum setiap test
  beforeEach(async () => {
    // Buat mock repository
    mockUserRepository = {
      find: jest.fn(),
      findOneBy: jest.fn(),
      save: jest.fn(),
      delete: jest.fn(),
    };

    // Buat testing module
    const module: TestingModule = await Test.createTestingModule({
      providers: [
        UsersService,
        {
          provide: getRepositoryToken(User),
          useValue: mockUserRepository,  // Gunakan mock
        },
      ],
    }).compile();

    service = module.get<UsersService>(UsersService);
  });

  // Test dasar — service terdefinisi
  it('should be defined', () => {
    expect(service).toBeDefined();
  });

  describe('findAll', () => {
    it('should return an array of users', async () => {
      // Arrange
      const expectedUsers = [{ id: 1, name: 'John' }];
      mockUserRepository.find.mockResolvedValue(expectedUsers);

      // Act
      const result = await service.findAll();

      // Assert
      expect(result).toEqual(expectedUsers);
      expect(mockUserRepository.find).toHaveBeenCalledTimes(1);
    });
  });
});
```
**Kasus Penggunaan Nyata:** Saat menambahkan fitur baru, developer menulis unit test di file `.spec.ts` yang bersebelahan dengan file produksi. `npm test` menjalankan semua test, memberikan feedback cepat apakah perubahan merusak fungsionalitas yang sudah ada.
