# 29. Testing
## 29.9 Database Testing in-memory test DB
**Definisi Singkat:** Database testing menggunakan SQLite in-memory (`:memory:`) sebagai pengganti database production, memungkinkan test berjalan cepat, tanpa instalasi database, dan langsung cleanup setelah test selesai.
**Analogi:** Seperti coretan di whiteboard — Anda bisa menulis, menghapus, dan menulis ulang tanpa perlu kertas (file database). Semua data hilang saat whiteboard dibersihkan (test selesai).
**Poin-Poin Penting:**
- SQLite `:memory:` untuk test cepat
- `synchronize: true` untuk auto-create schema
- Setup `TypeOrmModule.forRoot()` khusus test
- Isolasi antar test dengan `clear()` atau `transaction rollback`
**Contoh Kode:**
```typescript
// test-database.module.ts — konfigurasi database test
import { TypeOrmModule } from '@nestjs/typeorm';
import { User } from '../src/users/entities/user.entity';
import { Order } from '../src/orders/entities/order.entity';

// Gunakan SQLite in-memory untuk testing
export const TestDatabaseModule = TypeOrmModule.forRoot({
  type: 'sqlite',
  database: ':memory:',
  entities: [User, Order],
  synchronize: true,  // Auto-create table dari entity
  dropSchema: true,   // Drop table setelah test
  logging: false,     // Matikan logging SQL untuk test
});
```
```typescript
// users.service.integration.spec.ts — integration test dengan SQLite
import { Test, TestingModule } from '@nestjs/testing';
import { INestApplication } from '@nestjs/common';
import { TypeOrmModule, getRepositoryToken } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { User } from './entities/user.entity';
import { UsersService } from './users.service';

describe('UsersService — SQLite Integration', () => {
  let app: INestApplication;
  let service: UsersService;
  let repository: Repository<User>;

  beforeAll(async () => {
    const module: TestingModule = await Test.createTestingModule({
      imports: [
        // Database in-memory untuk test
        TypeOrmModule.forRoot({
          type: 'sqlite',
          database: ':memory:',
          entities: [User],
          synchronize: true,
        }),
        TypeOrmModule.forFeature([User]),
      ],
      providers: [UsersService],
    }).compile();

    app = module.createNestApplication();
    await app.init();

    service = module.get<UsersService>(UsersService);
    repository = module.get<Repository<User>>(getRepositoryToken(User));
  });

  afterAll(async () => {
    await app.close();
  });

  // Bersihkan data sebelum setiap test
  beforeEach(async () => {
    await repository.clear();
  });

  describe('CRUD Operations', () => {
    it('should create a new user', async () => {
      const user = await service.create({
        name: 'John Doe',
        email: 'john@test.com',
      });

      expect(user.id).toBeDefined();
      expect(user.name).toBe('John Doe');
      expect(user.email).toBe('john@test.com');
    });

    it('should find all users', async () => {
      // Seed data
      await repository.save([
        { name: 'User 1', email: 'user1@test.com' },
        { name: 'User 2', email: 'user2@test.com' },
      ]);

      const users = await service.findAll();
      expect(users).toHaveLength(2);
    });

    it('should find user by id', async () => {
      const created = await repository.save({
        name: 'Test User',
        email: 'test@test.com',
      });

      const found = await service.findOne(created.id);
      expect(found).toBeDefined();
      expect(found.name).toBe('Test User');
    });

    it('should update user', async () => {
      const created = await repository.save({
        name: 'Original',
        email: 'original@test.com',
      });

      const updated = await service.update(created.id, { name: 'Updated' });
      expect(updated.name).toBe('Updated');
    });

    it('should delete user', async () => {
      const created = await repository.save({
        name: 'To Delete',
        email: 'delete@test.com',
      });

      await service.remove(created.id);

      const found = await service.findOne(created.id);
      expect(found).toBeNull();
    });
  });

  describe('Error Handling', () => {
    it('should handle duplicate email', async () => {
      await repository.save({
        name: 'First',
        email: 'duplicate@test.com',
      });

      await expect(
        service.create({
          name: 'Second',
          email: 'duplicate@test.com',
        }),
      ).rejects.toThrow();
    });
  });
});

// test-container setup — alternatif dengan TestContainers (PostgreSQL)
// Untuk test yang membutuhkan PostgreSQL asli:
import { PostgreSqlContainer, StartedPostgreSqlContainer } from '@testcontainers/postgresql';

describe('PostgreSQL Integration Test', () => {
  let container: StartedPostgreSqlContainer;

  beforeAll(async () => {
    container = await new PostgreSqlContainer().start();
    // Gunakan container.getConnectionUri() untuk koneksi
  }, 60000);  // Timeout 60 detik

  afterAll(async () => {
    await container.stop();
  });

  // Gunakan container.getConnectionUri() di TypeOrmModule.forRoot()
});
```
**Kasus Penggunaan Nyata:** Setiap developer menjalankan database integration test secara lokal dengan SQLite in-memory sebelum push. Test memverifikasi query database, constraint, dan relasi entity berfungsi — tanpa perlu menginstall PostgreSQL/MySQL di mesin lokal. Di CI/CD, test yang sama juga bisa dijalankan dengan PostgreSQL asli menggunakan TestContainers.
