# 29. Testing
## 29.6 Test createTestingModule Testing Module
**Definisi Singkat:** `Test.createTestingModule()` adalah API utama dari `@nestjs/testing` untuk membuat modul NestJS terisolasi dalam environment test, mensimulasikan Dependency Injection tanpa menjalankan aplikasi penuh.
**Analogi:** Seperti simulator penerbangan — Anda bisa "menerbangkan" pesawat dalam lingkungan terkendali tanpa harus benar-benar terbang. Semua instrumen (provider) bisa dikonfigurasi sesuai skenario test.
**Poin-Poin Penting:**
- `Test.createTestingModule({ imports, controllers, providers })`
- Method `.compile()` menginisialisasi modul
- Method `.get()` dan `.get<Type>()` untuk akses instance
- `.overrideProvider()`, `.overrideGuard()` untuk override
**Contoh Kode:**
```typescript
// TestingModule — basic usage
import { Test, TestingModule } from '@nestjs/testing';
import { UsersService } from './users.service';
import { UsersController } from './users.controller';
import { getRepositoryToken } from '@nestjs/typeorm';
import { User } from './entities/user.entity';

describe('TestingModule advanced usage', () => {
  let module: TestingModule;
  let service: UsersService;
  let controller: UsersController;

  beforeAll(async () => {
    module = await Test.createTestingModule({
      imports: [],  // Import modul lain jika perlu
      controllers: [UsersController],
      providers: [
        UsersService,
        {
          provide: getRepositoryToken(User),
          useValue: {
            find: jest.fn().mockResolvedValue([]),
            findOneBy: jest.fn().mockResolvedValue(null),
            save: jest.fn().mockResolvedValue({}),
          },
        },
      ],
    }).compile();

    service = module.get<UsersService>(UsersService);
    controller = module.get<UsersController>(UsersController);
  });

  it('should compile successfully', () => {
    expect(module).toBeDefined();
    expect(service).toBeDefined();
    expect(controller).toBeDefined();
  });
});
```
```typescript
// Override provider — ganti implementasi spesifik untuk test
import { Test, TestingModule } from '@nestjs/testing';
import { PaymentService } from './payment.service';
import { PaymentGateway } from './payment.gateway';

describe('TestingModule — overrideProvider', () => {
  it('should use mocked payment gateway', async () => {
    const mockPaymentGateway = {
      charge: jest.fn().mockResolvedValue({ status: 'success' }),
      refund: jest.fn().mockResolvedValue({ status: 'refunded' }),
    };

    const module = await Test.createTestingModule({
      providers: [
        PaymentService,
        {
          provide: PaymentGateway,
          useValue: {
            charge: jest.fn().mockRejectedValue(new Error('Real API error')),
          },
        },
      ],
    })
      .overrideProvider(PaymentGateway)  // Override provider setelah deklarasi
      .useValue(mockPaymentGateway)
      .compile();

    const service = module.get<PaymentService>(PaymentService);
    const result = await service.processPayment(100);

    expect(result).toEqual({ status: 'success' });
  });
});
```
```typescript
// Override Guard — nonaktifkan guard untuk test
import { Test, TestingModule } from '@nestjs/testing';
import { AuthGuard } from '@nestjs/passport';
import { UsersController } from './users.controller';
import { UsersService } from './users.service';

describe('TestingModule — overrideGuard', () => {
  it('should bypass auth guard for testing', async () => {
    const module = await Test.createTestingModule({
      controllers: [UsersController],
      providers: [
        {
          provide: UsersService,
          useValue: { findAll: jest.fn().mockResolvedValue([]) },
        },
      ],
    })
      .overrideGuard(AuthGuard('jwt'))  // Bypass JWT guard
      .useValue({ canActivate: () => true })
      .compile();

    const controller = module.get<UsersController>(UsersController);
    const result = await controller.findAll();
    expect(result).toEqual([]);
  });
});
```
```typescript
// Custom provider dengan useFactory
import { Test, TestingModule } from '@nestjs/testing';
import { ConfigService } from '@nestjs/config';

describe('TestingModule — useFactory', () => {
  it('should use custom factory provider', async () => {
    const module = await Test.createTestingModule({
      providers: [
        {
          provide: 'DATABASE_CONFIG',
          useFactory: (configService: ConfigService) => ({
            host: configService.get('DB_HOST'),
            port: configService.get('DB_PORT'),
          }),
          inject: [ConfigService],
        },
        {
          provide: ConfigService,
          useValue: {
            get: jest.fn((key: string) => {
              const config = { DB_HOST: 'localhost', DB_PORT: '5432' };
              return config[key];
            }),
          },
        },
      ],
    }).compile();

    const dbConfig = module.get('DATABASE_CONFIG');
    expect(dbConfig).toEqual({ host: 'localhost', port: '5432' });
  });
});
```
**Kasus Penggunaan Nyata:** Integration test untuk service yang bergantung pada database. Dengan `Test.createTestingModule()`, developer bisa mengkonfigurasi modul test dengan repository mock, override guard yang authenticasi, dan mengatur environment variable — semua dalam lingkungan yang terisolasi, cepat, dan tanpa perlu database sungguhan.
