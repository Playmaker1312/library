## 7.1 Apa itu Controller & Tugasnya

### Definisi Singkat

**Controller** adalah komponen di NestJS yang bertanggung jawab untuk menangani **Incoming Requests** (permintaan yang masuk) dan mengirimkan **Responses** (jawaban) kembali ke klien. Controller bertindak sebagai gerbang pertama yang berinteraksi langsung dengan dunia luar (browser, mobile app, atau Postman).

### Analogi: Resepsionis Hotel

Bayangkan aplikasi kamu adalah sebuah **Hotel Mewah**:

- **Client (User)**: Tamu yang datang ke hotel.
    
- **Controller**: Adalah **Resepsionis** di meja depan.
    
    - Tugas resepsionis adalah menyapa tamu, menanyakan apa yang mereka butuhkan (Request), dan memeriksa apakah mereka punya kartu identitas atau reservasi.
        
    - Resepsionis tidak memasak makanan atau membersihkan kamar sendiri. Dia akan menelepon bagian dapur atau bagian kebersihan (**Service**) untuk melakukan tugas tersebut.
        
    - Setelah urusan di dapur selesai, resepsionis akan memberikan kunci kamar atau informasi yang dibutuhkan kepada tamu (**Response**).
        

### Tugas Utama Controller

1. **Routing (Mengarahkan Jalan)**: Menentukan URL mana yang harus ditangani oleh fungsi mana. Contoh: Jika user mengakses `/users`, arahkan ke fungsi `findAll()`.
    
2. **Input Handling**: Menerima data yang dikirim oleh user, baik itu melalui URL (_Params_), link (_Query_), maupun isi pesan (_Body_).
    
3. **Validation (Basic)**: Memastikan data yang masuk memiliki format yang benar sebelum diteruskan ke bagian logika.
    
4. **Response Orchestration**: Menentukan status kode (seperti 200 OK, 201 Created, atau 404 Not Found) dan membungkus data dalam format JSON untuk dikirim balik.
    

### Prinsip Penting: "Lean Controllers"

Salah satu aturan emas di NestJS adalah **Controller harus tetap ramping (tipis)**.

- **JANGAN** menaruh logika bisnis yang rumit (seperti rumus matematika berat atau query database langsung) di dalam Controller.
    
- **LAKUKAN** pemanggilan Service untuk urusan logika tersebut. Controller hanya bertugas sebagai pengatur lalu lintas.
    

### Cara Mengenali Controller

Di dalam kode NestJS, sebuah kelas ditandai sebagai Controller jika memiliki dekorator `@Controller()` di atas namanya.

TypeScript

```
@Controller('books') // Ini berarti semua URL di sini akan diawali dengan /books
export class BooksController {
  // Fungsi-fungsi penangan request (Handler) akan ditulis di sini
}
```
