# 27. Event-driven Architecture
## 27.7 Wildcard Events
**Definisi Singkat:** Dengan mengaktifkan opsi `wildcard: true` di EventEmitter2, listener bisa mendaftar ke pola event menggunakan wildcard (`*`) untuk menangkap beberapa event sekaligus.
**Analogi:** Seperti petugas kebersihan di mal — dia tidak perlu tahu setiap toko spesifik, cukup dengan pola "semua toko di lantai 2" (`floor2.*`), dia akan membersihkan semua toko di lantai itu.
**Poin-Poin Penting:**
- `wildcard: true` di konfigurasi
- `delimiter` (default: '.') sebagai pemisah namespace
- Pattern `user.*` untuk semua event user
**Contoh Kode:**
```typescript
// app.module.ts dengan wildcard
import { Module } from '@nestjs/common';
import { EventEmitterModule } from '@nestjs/event-emitter';
import { WildcardListenerService } from './wildcard-listener.service';
import { LoggingService } from './logging.service';

@Module({
  imports: [
    EventEmitterModule.forRoot({
      wildcard: true,  // AKTIFKAN wildcard
      delimiter: '.',   // Pemisah namespace
      maxListeners: 50,
    }),
  ],
  providers: [WildcardListenerService, LoggingService],
})
export class AppModule {}
```
```typescript
// wildcard-listener.service.ts
import { Injectable } from '@nestjs/common';
import { OnEvent } from '@nestjs/event-emitter';

@Injectable()
export class WildcardListenerService {
  // Menangkap semua event yang berakhiran '.created'
  @OnEvent('*.created')
  handleAllCreatedEvents(payload: any) {
    console.log('[Wildcard *.created] Sesuatu telah dibuat:', payload);
    // Akan terpanggil untuk: user.created, order.created, product.created, dll
  }

  // Menangkap semua event dalam namespace 'user'
  @OnEvent('user.*')
  handleAllUserEvents(payload: any) {
    console.log('[Wildcard user.*] Event user terjadi:', payload);
    // Akan terpanggil untuk: user.registered, user.updated, user.deleted
  }

  // Menangkap semua event (global wildcard)
  @OnEvent('**')
  handleAllEvents(payload: any) {
    // Akan terpanggil untuk SEMUA event — hati-hati dengan performa
    console.log('[Global Wildcard] Event terdeteksi');
  }

  // Multi-level wildcard — menangkap order.shipped, order.cancelled, dll
  @OnEvent('order.*')
  handleAllOrderEvents(payload: any) {
    console.log('[Wildcard order.*] Event order terjadi');

    // Payload juga membawa informasi event name
    // Jika ada properti event, kita bisa tahu event spesifik
  }

  // Wildcard di tengah namespace
  @OnEvent('*.updated')
  handleAllUpdatedEvents(payload: any) {
    console.log('[Wildcard *.updated] Data diperbarui:', payload);
    // user.updated, product.updated, order.updated
  }
}
```
```typescript
// logging.service.ts
import { Injectable } from '@nestjs/common';
import { OnEvent } from '@nestjs/event-emitter';

@Injectable()
export class LoggingService {
  // Audit log — catat SEMUA event untuk kepentingan audit
  @OnEvent('**')
  auditLog(event: any) {
    // Untuk wildcard global, parameter pertama adalah object event
    // yang memiliki properti event, domain, dan data
    console.log(`[AUDIT] Event: ${event.event}, Data:`, event.data);
  }

  // Logging spesifik namespace
  @OnEvent('payment.*')
  logPaymentEvents(payload: any) {
    console.log(`[PAYMENT LOG]`, payload);
  }

  // Logging dengan pola multiple level
  @OnEvent('notification.*.*')
  logNotificationEvents(payload: any) {
    // Akan menangkap: notification.email.sent, notification.push.sent
    console.log('[NOTIFICATION LOG]', payload);
  }
}
```
```typescript
// emitter-wildcard.demo.ts
import { Injectable } from '@nestjs/common';
import { EventEmitter2 } from '@nestjs/event-emitter';

@Injectable()
export class EmitterWildcardDemo {
  constructor(private eventEmitter: EventEmitter2) {}

  demoWildcard() {
    // Semua listener dengan pola yang cocok akan terpanggil:
    
    // 'user.registered' → cocok dengan 'user.*' dan '*.created'
    this.eventEmitter.emit('user.registered', { userId: 1, email: 'test@test.com' });

    // 'order.created' → cocok dengan '*.created' dan 'order.*'
    this.eventEmitter.emit('order.created', { orderId: 100 });

    // 'product.updated' → cocok dengan '*.updated'
    this.eventEmitter.emit('product.updated', { productId: 5, name: 'New Name' });

    // 'payment.completed' → cocok dengan 'payment.*'
    this.eventEmitter.emit('payment.completed', { transactionId: 'TXN-001' });
  }
}
```
**Kasus Penggunaan Nyata:** Sistem audit dan monitoring. Dengan wildcard `**`, tim DevOps bisa membuat service logging yang menangkap SEMUA event di sistem untuk kepentingan debugging dan compliance tanpa harus mendaftar satu per satu. Cukup tambahkan satu listener dan semua event tercatat otomatis.
