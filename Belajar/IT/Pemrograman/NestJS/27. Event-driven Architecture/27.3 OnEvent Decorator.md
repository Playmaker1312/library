# 27. Event-driven Architecture
## 27.3 OnEvent Decorator
**Definisi Singkat:** `@OnEvent()` decorator menandai method dalam NestJS provider sebagai event listener yang akan dipanggil secara otomatis ketika event tertentu di-emit.
**Analogi:** Seperti memasang alarm kebakaran — Anda pasang sensor (decorator) di tempat strategis, dan saat ada api (event), alarm akan berbunyi (listener tereksekusi).
**Poin-Poin Penting:**
- `@OnEvent('event.name')` dari `@nestjs/event-emitter`
- Mendukung `async` listener
- Opsi `{ suppressErrors: true }` dan `{ async: true }`
**Contoh Kode:**
```typescript
// email.service.ts
import { Injectable } from '@nestjs/common';
import { OnEvent } from '@nestjs/event-emitter';

@Injectable()
export class EmailService {
  // Listener synchronous sederhana
  @OnEvent('user.registered')
  handleUserRegistration(payload: { email: string; name: string }) {
    console.log(`Mengirim email selamat datang ke ${payload.email}`);
    // Kirim email
  }

  // Listener asynchronous dengan promise
  @OnEvent('order.placed', { async: true })
  async handleOrderConfirmation(payload: { orderId: number; email: string }) {
    const emailBody = await this.generateEmailTemplate(payload);
    await this.sendEmail(payload.email, 'Konfirmasi Pesanan', emailBody);
  }

  // Listener dengan suppressErrors agar tidak mengganggu proses utama
  @OnEvent('log.error', { suppressErrors: true })
  handleErrorLog(payload: { message: string; stack: string }) {
    // Error di sini tidak akan mempengaruhi emitter
    console.error(`[ERROR LOG]: ${payload.message}`);
  }

  // Multiple event dalam satu listener (manual dispatch)
  @OnEvent('user.updated')
  handleUserUpdated(payload: any) {
    // Kirim notifikasi perubahan data
    console.log(`User ${payload.id} updated at ${new Date()}`);
  }

  private async generateEmailTemplate(data: any): Promise<string> {
    return `<h1>Halo ${data.name}</h1>`;
  }

  private async sendEmail(to: string, subject: string, body: string): Promise<void> {
    // Implementasi pengiriman email
    console.log(`Email terkirim ke ${to}: ${subject}`);
  }
}
```

**Kasus Penggunaan Nyata:** Sistem notifikasi multi-channel. Saat user mendaftar (`user.registered`), `EmailService` mengirim email selamat datang, `SMSService` mengirim SMS verifikasi, dan `AnalyticsService` mencatat event registrasi — semua terpicu oleh satu event, terdesentralisasi, dan mudah ditambahkan/dihapus.
