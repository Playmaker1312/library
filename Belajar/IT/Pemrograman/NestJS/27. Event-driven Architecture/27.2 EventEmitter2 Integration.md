# 27. Event-driven Architecture
## 27.2 EventEmitter2 Integration
**Definisi Singkat:** `@nestjs/event-emitter` dibangun di atas library `eventemitter2`, yang merupakan versi modern dari EventEmitter Node.js dengan fitur wildcard, namespace, dan kontrol async.
**Analogi:** Seperti upgrade dari telepon kabel (EventEmitter bawaan) ke smartphone (EventEmitter2) — lebih banyak fitur, lebih fleksibel, dan bisa handle banyak panggilan sekaligus.
**Poin-Poin Penting:**
- `eventemitter2` sebagai dependency internal
- Konfigurasi `wildcard`, `delimiter`, `newListener`
- `EventEmitterModule.forRoot()` dengan options
**Contoh Kode:**
```typescript
// app.module.ts dengan konfigurasi EventEmitter2
import { Module } from '@nestjs/common';
import { EventEmitterModule } from '@nestjs/event-emitter';

@Module({
  imports: [
    EventEmitterModule.forRoot({
      // Gunakan delimiter untuk namespace event
      delimiter: '.',
      // Aktifkan wildcard untuk pattern matching
      wildcard: true,
      // Batas listener per event
      maxListeners: 20,
      // Izinkan listener baru ditambahkan
      newListener: false,
      // Hapus listener saat event dihapus
      removeListener: false,
      // Ukuran maximum untuk wildcard cache
      verboseMemoryLeak: false,
      // Ignore errors dari listener
      ignoreErrors: false,
    }),
  ],
})
export class AppModule {}
```
```typescript
// events.config.ts
import { EventEmitterModuleOptions } from '@nestjs/event-emitter';

export const eventEmitterConfig: EventEmitterModuleOptions = {
  wildcard: true,
  delimiter: '.',
  maxListeners: 20,
  // Kirim event error ke error handler terpusat
  ignoreErrors: false,
};

// Gunakan konfigurasi terpisah untuk test environment
export const testEventEmitterConfig: EventEmitterModuleOptions = {
  wildcard: true,
  delimiter: '.',
  maxListeners: 5,
};
```
```typescript
// Mengakses EventEmitter2 instance langsung
import { Injectable } from '@nestjs/common';
import { EventEmitter2 } from '@nestjs/event-emitter';

@Injectable()
export class AnalyticsService {
  constructor(private eventEmitter: EventEmitter2) {}

  getEventEmitterStats() {
    // Mendapatkan daftar semua event yang terdaftar
    const events = this.eventEmitter.eventNames();
    
    // Mendapatkan jumlah listener per event
    const listenerCounts = events.map((event) => ({
      event,
      listeners: this.eventEmitter.listenerCount(event),
    }));

    return {
      totalEvents: events.length,
      listenerCounts,
      maxListeners: this.eventEmitter.getMaxListeners(),
    };
  }
}
```
**Kasus Penggunaan Nyata:** Aplikasi analytics yang memonitor semua event di sistem. Dengan EventEmitter2, developer bisa mengatur namespace event seperti `user.created`, `user.updated`, `order.shipped` dan menggunakan wildcard `user.*` untuk menangkap semua event terkait user.
