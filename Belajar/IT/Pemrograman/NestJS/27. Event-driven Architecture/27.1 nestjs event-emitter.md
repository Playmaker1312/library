# 27. Event-driven Architecture
## 27.1 nestjs event-emitter
**Definisi Singkat:** Modul `@nestjs/event-emitter` menyediakan implementasi event-driven architecture di NestJS, memungkinkan komunikasi loose-coupled antar komponen melalui event.
**Analogi:** Seperti stasiun radio — penyiar (emitter) mengirim sinyal tanpa tahu siapa pendengarnya, dan pendengar (listener) bisa menangkap siaran yang relevan tanpa tahu siapa penyiarnya.
**Poin-Poin Penting:**
- `@nestjs/event-emitter` package
- `EventEmitterModule.forRoot()` registrasi global
**Contoh Kode:**
```typescript
// app.module.ts
import { Module } from '@nestjs/common';
import { EventEmitterModule } from '@nestjs/event-emitter';
import { OrderService } from './order.service';
import { NotificationService } from './notification.service';

@Module({
  imports: [
    // Registrasi EventEmitterModule secara global
    EventEmitterModule.forRoot({
      // Set true jika ingin event berjalan asynchronous
      wildcard: false,
      // Batas maksimal listener per event
      maxListeners: 10,
      // Set true untuk mengaktifkan console.log setiap event
      verboseMemoryLeak: false,
      // Set true jika event harus diproses secara synchronous
      global: true,
    }),
  ],
  providers: [OrderService, NotificationService],
})
export class AppModule {}
```
```typescript
// order.service.ts
import { Injectable } from '@nestjs/common';
import { EventEmitter2 } from '@nestjs/event-emitter';

@Injectable()
export class OrderService {
  constructor(private eventEmitter: EventEmitter2) {}

  createOrder(orderData: any) {
    // Logika bisnis pembuatan order
    const order = { id: Date.now(), ...orderData };

    // Emit event setelah order berhasil dibuat
    this.eventEmitter.emit('order.created', order);

    return order;
  }
}
```
```typescript
// notification.service.ts
import { Injectable } from '@nestjs/common';
import { OnEvent } from '@nestjs/event-emitter';

@Injectable()
export class NotificationService {
  @OnEvent('order.created')
  handleOrderCreatedEvent(order: any) {
    // Listener akan dipanggil saat event 'order.created' di-emit
    console.log(`Mengirim notifikasi untuk order #${order.id}`);
    // Logika pengiriman email/push notification
  }
}
```
**Kasus Penggunaan Nyata:** Sistem e-commerce di mana `OrderService` memicu event `order.created`, dan beberapa listener seperti `NotificationService`, `InventoryService`, dan `ShippingService` merespon secara independen tanpa saling terikat.
