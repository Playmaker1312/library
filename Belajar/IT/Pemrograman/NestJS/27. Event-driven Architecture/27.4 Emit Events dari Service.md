# 27. Event-driven Architecture
## 27.4 Emit Events dari Service
**Definisi Singkat:** Service di NestJS dapat mengeluarkan (emit) events menggunakan `EventEmitter2.emit()` atau `EventEmitter2.emitAsync()` untuk memberi tahu komponen lain tentang sesuatu yang terjadi.
**Analogi:** Seperti seorang manajer toko yang mengumumkan "Stok habis!" melalui pengeras suara — siapa pun yang berkepentingan (gudang, purchasing, marketing) bisa mendengar dan bertindak tanpa harus dipanggil satu per satu.
**Poin-Poin Penting:**
- `eventEmitter.emit(event, payload)` untuk sync
- `eventEmitter.emitAsync(event, payload)` untuk async
- `emitAsync` mengembalikan Promise dengan hasil semua listener
**Contoh Kode:**
```typescript
// payment.service.ts
import { Injectable } from '@nestjs/common';
import { EventEmitter2 } from '@nestjs/event-emitter';

@Injectable()
export class PaymentService {
  constructor(private eventEmitter: EventEmitter2) {}

  async processPayment(orderId: number, amount: number) {
    // Proses pembayaran
    const paymentResult = { success: true, transactionId: `TXN-${Date.now()}` };

    if (paymentResult.success) {
      // Emit event synchronous — langsung return setelah semua listener selesai
      this.eventEmitter.emit('payment.completed', {
        orderId,
        transactionId: paymentResult.transactionId,
        amount,
        timestamp: new Date(),
      });

      return { status: 'success', transactionId: paymentResult.transactionId };
    } else {
      // Emit event untuk payment gagal
      this.eventEmitter.emit('payment.failed', { orderId, amount, reason: 'Insufficient funds' });
      return { status: 'failed' };
    }
  }
}
```
```typescript
// order.service.ts
import { Injectable } from '@nestjs/common';
import { EventEmitter2 } from '@nestjs/event-emitter';

@Injectable()
export class OrderService {
  constructor(private eventEmitter: EventEmitter2) {}

  async placeOrder(items: any[]) {
    const order = { id: Date.now(), items, status: 'pending', createdAt: new Date() };

    // Emit event asynchronous — menunggu semua listener selesai
    const results = await this.eventEmitter.emitAsync('order.placed', order);
    
    // results adalah array dari return value semua listener
    // Misal: [ { inventoryUpdated: true }, { invoiceCreated: true } ]
    const allSuccess = results.every((r) => r !== false);

    if (allSuccess) {
      order.status = 'confirmed';
      this.eventEmitter.emit('order.confirmed', order);
    } else {
      order.status = 'failed';
      this.eventEmitter.emit('order.failed', order);
    }

    return order;
  }

  async cancelOrder(orderId: number) {
    // Emit event dengan payload bertipe kompleks
    this.eventEmitter.emit('order.cancelled', {
      orderId,
      cancelledAt: new Date(),
      reason: 'Cancelled by user',
      refundRequired: true,
    });
  }
}
```
```typescript
// analytics.service.ts
import { Injectable } from '@nestjs/common';
import { EventEmitter2 } from '@nestjs/event-emitter';

@Injectable()
export class AnalyticsService {
  constructor(private eventEmitter: EventEmitter2) {}

  trackPageView(page: string, userId: string) {
    // Emit untuk pencatatan analytics
    this.eventEmitter.emit('analytics.pageview', { page, userId, timestamp: new Date() });
  }

  trackEvent(category: string, action: string, label?: string) {
    this.eventEmitter.emit('analytics.event', { category, action, label });
  }
}
```
**Kasus Penggunaan Nyata:** Di platform e-commerce, setelah pembayaran sukses, `PaymentService` emit `payment.completed`. Event ini men-trigger `InventoryService` untuk update stok, `ShippingService` untuk membuat label pengiriman, `InvoiceService` untuk generate invoice, dan `NotificationService` untuk kirim email konfirmasi — semua terjadi secara decoupled.
