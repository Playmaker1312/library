# 38. Monitoring dan Observability ## 38.2 Custom Health Indicators

**Definisi Singkat:** Custom Health Indicator memungkinkan Anda membuat health check untuk komponen spesifik aplikasi seperti Redis queue, external API, Kafka broker, atau business logic tertentu.

**Analogi:** Custom health indicator seperti alat ukur khusus di pabrik — selain alat standar (tekanan darah, suhu), pabrik Anda mungkin perlu mengukur getaran mesin tertentu (Redis queue length) atau level bahan baku (Kafka topic lag).

**Poin-Poin Terting:**
- **HealthIndicator** base class dari @nestjs/terminus
- **getStatus()** method untuk report status
- **Custom check** untuk service spesifik
- **Async check** dengan Promise/Observable
- **Business health** untuk domain-specific metrics

**Contoh Kode:**
```typescript
// health/indicators/redis.health.ts
import { Injectable } from '@nestjs/common';
import { HealthIndicator, HealthIndicatorResult, HealthCheckError } from '@nestjs/terminus';
import { RedisService } from '../../redis/redis.service';

@Injectable()
export class RedisHealthIndicator extends HealthIndicator {
  constructor(private readonly redisService: RedisService) {
    super();
  }

  async isHealthy(key: string): Promise<HealthIndicatorResult> {
    try {
      await this.redisService.ping();
      return this.getStatus(key, true);
    } catch (error) {
      throw new HealthCheckError(
        'Redis health check failed',
        this.getStatus(key, false, { message: error.message }),
      );
    }
  }
}
```

```typescript
// health/indicators/external-api.health.ts
import { Injectable } from '@nestjs/common';
import { HealthIndicator, HealthIndicatorResult, HealthCheckError } from '@nestjs/terminus';
import { HttpService } from '@nestjs/axios';
import { lastValueFrom } from 'rxjs';

@Injectable()
export class ExternalApiHealthIndicator extends HealthIndicator {
  constructor(private readonly httpService: HttpService) {
    super();
  }

  async checkPaymentGateway(key: string): Promise<HealthIndicatorResult> {
    try {
      const response = await lastValueFrom(
        this.httpService.get('https://api.payment.com/health', {
          timeout: 5000,
        }),
      );

      const isHealthy = response.status === 200;

      if (isHealthy) {
        return this.getStatus(key, true, {
          latency: response.headers['x-response-time'],
        });
      }

      throw new HealthCheckError(
        'Payment gateway unhealthy',
        this.getStatus(key, false),
      );
    } catch (error) {
      throw new HealthCheckError(
        'Payment gateway check failed',
        this.getStatus(key, false, { message: error.message }),
      );
    }
  }
}
```

```typescript
// health/indicators/kafka.health.ts
import { Injectable } from '@nestjs/common';
import { HealthIndicator, HealthIndicatorResult, HealthCheckError } from '@nestjs/terminus';

@Injectable()
export class KafkaHealthIndicator extends HealthIndicator {
  constructor(private readonly kafkaService: any) { // Inject Kafka service
    super();
  }

  async isHealthy(key: string): Promise<HealthIndicatorResult> {
    try {
      const admin = this.kafkaService.admin();
      await admin.connect();
      const metadata = await admin.fetchTopicMetadata();
      await admin.disconnect();

      return this.getStatus(key, true, {
        topics: metadata.topics.length,
      });
    } catch (error) {
      throw new HealthCheckError(
        'Kafka health check failed',
        this.getStatus(key, false, { message: error.message }),
      );
    }
  }
}
```

```typescript
// health/indicators/queue.health.ts
import { Injectable } from '@nestjs/common';
import { HealthIndicator, HealthIndicatorResult, HealthCheckError } from '@nestjs/terminus';

@Injectable()
export class QueueHealthIndicator extends HealthIndicator {
  constructor(private readonly queueService: any) {
    super();
  }

  async checkQueueLength(key: string, maxQueueSize: number): Promise<HealthIndicatorResult> {
    const queueLength = await this.queueService.getQueueLength();

    const isHealthy = queueLength < maxQueueSize;

    const result = this.getStatus(key, isHealthy, {
      queueLength,
      maxQueueSize,
    });

    if (!isHealthy) {
      throw new HealthCheckError('Queue is too long', result);
    }

    return result;
  }
}
```

```typescript
// health.controller.ts (dengan custom indicators)
import { Controller, Get } from '@nestjs/common';
import { HealthCheck, HealthCheckService } from '@nestjs/terminus';
import { RedisHealthIndicator } from './indicators/redis.health';
import { ExternalApiHealthIndicator } from './indicators/external-api.health';
import { QueueHealthIndicator } from './indicators/queue.health';

@Controller('health')
export class HealthController {
  constructor(
    private health: HealthCheckService,
    private redis: RedisHealthIndicator,
    private externalApi: ExternalApiHealthIndicator,
    private queue: QueueHealthIndicator,
  ) {}

  @Get()
  @HealthCheck()
  check() {
    return this.health.check([
      () => this.redis.isHealthy('redis'),
      () => this.externalApi.checkPaymentGateway('payment-gateway'),
      () => this.queue.checkQueueLength('email-queue', 10000),
    ]);
  }
}
```

```typescript
// health.module.ts
import { Module } from '@nestjs/common';
import { TerminusModule } from '@nestjs/terminus';
import { HttpModule } from '@nestjs/axios';
import { HealthController } from './health.controller';
import { RedisHealthIndicator } from './indicators/redis.health';
import { ExternalApiHealthIndicator } from './indicators/external-api.health';
import { QueueHealthIndicator } from './indicators/queue.health';
import { RedisModule } from '../redis/redis.module';

@Module({
  imports: [
    TerminusModule,
    HttpModule,
    RedisModule,
  ],
  controllers: [HealthController],
  providers: [
    RedisHealthIndicator,
    ExternalApiHealthIndicator,
    QueueHealthIndicator,
  ],
})
export class HealthModule {}
```

**Kasus Penggunaan Nyata:** Platform SaaS dengan beberapa external dependencies — custom health indicator memonitor payment gateway, SMTP server, Elasticsearch cluster, dan Redis queue length. Jika one indicator merah, ops team dapat alert via Slack/PagerDuty.
