# 38. Monitoring dan Observability ## 38.8 APM Application Performance Monitoring

**Definisi Singkat:** APM (Application Performance Monitoring) memberikan visibilitas end-to-end tentang performa aplikasi — termasuk response time, throughput, error rate, database queries, external calls, dan infrastructure metrics. Tools populer: Datadog, New Relic, Elastic APM.

**Analogi:** APM seperti CCTV + sensor di seluruh pabrik — Anda bisa lihat real-time: mesin mana yang lambat (slow database query), jalur konveyor mana yang macet (bottleneck), dan produk mana yang cacat (error). Semua terpusat di satu dashboard.

**Poin-Poin Penting:**
- **Datadog APM** auto-instrumentation Node.js
- **New Relic** Node.js agent
- **Elastic APM** open-source APM agent
- **Auto-instrumentation** tanpa perubahan kode
- **Distributed tracing** across services
- **Database monitoring** query performance
- **Infrastructure metrics** CPU, memory, disk

**Contoh Kode:**

```typescript
// apm.service.ts — custom instrumentation dengan Elastic APM
import { Injectable, Logger } from '@nestjs/common';
import { Inject, Optional } from '@nestjs/common';

@Injectable()
export class ApmService {
  private readonly logger = new Logger(ApmService.name);
  private apm: any;

  constructor() {
    try {
      this.apm = require('elastic-apm-node');
    } catch {
      this.logger.warn('APM agent not available');
    }
  }

  startTransaction(name: string, type?: string) {
    if (!this.apm) return null;
    return this.apm.startTransaction(name, type);
  }

  startSpan(name: string, options?: any) {
    if (!this.apm) return null;
    return this.apm.startSpan(name, options);
  }

  captureError(error: Error) {
    if (this.apm) {
      this.apm.captureError(error);
    }
  }

  setCustomContext(context: Record<string, any>) {
    if (this.apm) {
      this.apm.setCustomContext(context);
    }
  }

  setUserContext(user: Record<string, any>) {
    if (this.apm) {
      this.apm.setUserContext(user);
    }
  }

  measureQuery(query: string, duration: number) {
    this.apm?.setCustomContext({
      db: { statement: query, type: 'sql', duration },
    });
  }
}
```

```typescript
// apm.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable } from 'rxjs';
import { tap } from 'rxjs/operators';
import { ApmService } from './apm.service';

@Injectable()
export class ApmInterceptor implements NestInterceptor {
  constructor(private readonly apmService: ApmService) {}

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const request = context.switchToHttp().getRequest();
    const transaction = this.apmService.startTransaction(
      `${request.method} ${request.route?.path || request.url}`,
      'request',
    );

    return next.handle().pipe(
      tap({
        next: () => {
          if (transaction) transaction.end();
        },
        error: (error) => {
          this.apmService.captureError(error);
          if (transaction) transaction.end();
        },
      }),
    );
  }
}
```

**Kasus Penggunaan Nyata:** E-commerce platform dengan Datadog APM — dashboard menunjukkan bahwa endpoint `/search` punya p95 latency 2s. APM trace mengungkap penyebab: N+1 query di Elasticsearch dan kurangnya index. Setelah optimasi, p95 turun ke 200ms. APM alert jika latency melebihi threshold.
