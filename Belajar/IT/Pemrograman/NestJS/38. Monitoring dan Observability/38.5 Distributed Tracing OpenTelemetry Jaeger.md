# 38. Monitoring dan Observability ## 38.5 Distributed Tracing OpenTelemetry Jaeger

**Definisi Singkat:** Distributed tracing melacak request saat melewati multiple services, menunjukkan latency di setiap hop. OpenTelemetry adalah standar untuk instrumentasi, Jaeger adalah backend untuk visualisasi traces.

**Analogi:** Distributed tracing seperti melacak paket JNE — Anda bisa lihat kapan paket sampai di sortir (Service A), transit (Message Queue), kurir (Service B), dan sampai tujuan. Setiap titik punya timestamp, jadi Anda tahu di mana delay terjadi.

**Poin-Poin Penting:**
- **@opentelemetry/node** auto-instrumentation
- **@opentelemetry/instrumentation-http** HTTP traces
- **@opentelemetry/instrumentation-express** Express traces
- **@opentelemetry/exporter-jaeger** export ke Jaeger
- **Trace ID** propagasi via headers
- **Span** unit kerja individual
- **Root span** trace awal hingga selesai

**Contoh Kode:**
```typescript
// tracing.ts (OpenTelemetry setup)
import { NodeSDK } from '@opentelemetry/sdk-node';
import { getNodeAutoInstrumentations } from '@opentelemetry/auto-instrumentations-node';
import { JaegerExporter } from '@opentelemetry/exporter-jaeger';
import { Resource } from '@opentelemetry/resources';
import { SemanticResourceAttributes } from '@opentelemetry/semantic-conventions';

const jaegerExporter = new JaegerExporter({
  endpoint: process.env.JAEGER_URL || 'http://localhost:14268/api/traces',
});

const sdk = new NodeSDK({
  resource: new Resource({
    [SemanticResourceAttributes.SERVICE_NAME]: 'nestjs-app',
    [SemanticResourceAttributes.SERVICE_VERSION]: '1.0.0',
    [SemanticResourceAttributes.DEPLOYMENT_ENVIRONMENT]: process.env.NODE_ENV,
  }),
  traceExporter: jaegerExporter,
  instrumentations: [
    getNodeAutoInstrumentations({
      '@opentelemetry/instrumentation-http': {
        ignoreIncomingPaths: ['/health', '/metrics'],
      },
    }),
  ],
});

sdk.start();

process.on('SIGTERM', () => {
  sdk.shutdown().then(() => process.exit(0));
});

export default sdk;
```

```typescript
// custom-span.service.ts
import { Injectable } from '@nestjs/common';
import { trace, Span, context } from '@opentelemetry/api';

@Injectable()
export class TracingService {
  private readonly tracer = trace.getTracer('nestjs-app');

  createSpan(name: string, fn: () => Promise<any>): Promise<any> {
    return this.tracer.startActiveSpan(name, async (span: Span) => {
      try {
        const result = await fn();
        span.setStatus({ code: 1 }); // OK
        return result;
      } catch (error) {
        span.setStatus({
          code: 2, // ERROR
          message: error.message,
        });
        span.recordException(error);
        throw error;
      } finally {
        span.end();
      }
    });
  }

  async traceDatabaseQuery(query: string, params: any[], fn: () => Promise<any>) {
    const span = this.tracer.startSpan('database.query');
    span.setAttribute('db.query', query);
    span.setAttribute('db.params', JSON.stringify(params));

    try {
      const result = await fn();
      span.setStatus({ code: 1 });
      return result;
    } catch (error) {
      span.setStatus({ code: 2, message: error.message });
      throw error;
    } finally {
      span.end();
    }
  }
}
```

```typescript
// tracing.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable } from 'rxjs';
import { tap } from 'rxjs/operators';
import { trace, context as otelContext } from '@opentelemetry/api';

@Injectable()
export class TracingInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const request = context.switchToHttp().getRequest();
    const method = request.method;
    const path = request.route?.path || request.url;

    const tracer = trace.getTracer('nestjs-interceptor');

    return tracer.startActiveSpan(`${method} ${path}`, (span) => {
      span.setAttribute('http.method', method);
      span.setAttribute('http.url', path);
      span.setAttribute('controller', context.getClass().name);
      span.setAttribute('handler', context.getHandler().name);

      return next.handle().pipe(
        tap({
          next: () => {
            span.setAttribute('http.status_code', request.res.statusCode);
            span.end();
          },
          error: (error) => {
            span.setAttribute('http.status_code', error.status || 500);
            span.setStatus({ code: 2, message: error.message });
            span.end();
          },
        }),
      );
    });
  }
}
```

**Kasus Penggunaan Nyata:** Microservice architecture — request dari API Gateway melewati Auth Service → Order Service → Payment Service → Notification Service. Jika ada slow response, Jaeger trace menunjukkan bahwa 80% waktu dihabiskan di Payment Service (external payment gateway latency).
