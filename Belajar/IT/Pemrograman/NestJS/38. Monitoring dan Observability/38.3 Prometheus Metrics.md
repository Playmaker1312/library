# 38. Monitoring dan Observability ## 38.3 Prometheus Metrics

**Definisi Singkat:** Prometheus adalah sistem monitoring dan alerting open-source yang mengumpulkan metrics dari aplikasi via HTTP endpoint. NestJS bisa mengekspos metrics melalui `@willsoto/nestjs-prometheus` package.

**Analogi:** Prometheus seperti petugas sensus yang rutin mendatangi setiap rumah (aplikasi) untuk mencatat data: jumlah penghuni (request count), suhu rumah (CPU), listrik (memory), dll. Data dicatat dengan label (nama, alamat) dan disimpan di database time-series.

**Poin-Poin Penting:**
- **@willsoto/nestjs-prometheus** package
- **PrometheusModule** register metrics
- **Counter** hitungan (total requests, errors)
- **Gauge** nilai saat ini (memory usage, connections)
- **Histogram** distribusi durasi (latency buckets)
- **Summary** quantiles latency
- **/metrics** endpoint untuk Prometheus scrape

**Contoh Kode:**
```typescript
// app.module.ts
import { Module } from '@nestjs/common';
import { PrometheusModule } from '@willsoto/nestjs-prometheus';
import { MetricsController } from './metrics.controller';

@Module({
  imports: [
    PrometheusModule.register({
      path: '/metrics', // endpoint default
      defaultMetrics: {
        enabled: true, // collect default Node.js metrics
      },
    }),
  ],
  controllers: [MetricsController],
})
export class AppModule {}
```

```typescript
// metrics.service.ts
import { Injectable } from '@nestjs/common';
import { InjectMetric } from '@willsoto/nestjs-prometheus';
import { Counter, Gauge, Histogram } from 'prom-client';

@Injectable()
export class MetricsService {
  constructor(
    @InjectMetric('http_requests_total')
    private readonly requestCounter: Counter<string>,

    @InjectMetric('http_request_duration_seconds')
    private readonly requestDuration: Histogram<string>,

    @InjectMetric('active_users')
    private readonly activeUsers: Gauge<string>,

    @InjectMetric('errors_total')
    private readonly errorCounter: Counter<string>,
  ) {}

  incrementRequestCounter(method: string, path: string, statusCode: number) {
    this.requestCounter.inc({ method, path, status: statusCode.toString() });
  }

  observeRequestDuration(method: string, path: string, durationMs: number) {
    this.requestDuration.observe(
      { method, path },
      durationMs / 1000,
    );
  }

  setActiveUsers(count: number) {
    this.activeUsers.set(count);
  }

  incrementErrors(type: string) {
    this.errorCounter.inc({ type });
  }
}
```

```typescript
// metrics.controller.ts
import { Controller, Get } from '@nestjs/common';
import { MetricsService } from './metrics.service';

@Controller('api/metrics')
export class MetricsController {
  constructor(private readonly metricsService: MetricsService) {}

  @Get('stats')
  getStats() {
    return {
      activeUsers: 150,
      uptime: process.uptime(),
      memory: process.memoryUsage(),
    };
  }
}
```

```typescript
// metrics.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable } from 'rxjs';
import { tap } from 'rxjs/operators';
import { MetricsService } from './metrics.service';
import { Request, Response } from 'express';

@Injectable()
export class MetricsInterceptor implements NestInterceptor {
  constructor(private readonly metricsService: MetricsService) {}

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const request = context.switchToHttp().getRequest<Request>();
    const response = context.switchToHttp().getResponse<Response>();
    const start = Date.now();

    const { method, path } = request;

    return next.handle().pipe(
      tap(() => {
        const duration = Date.now() - start;
        const statusCode = response.statusCode;

        this.metricsService.incrementRequestCounter(method, path, statusCode);
        this.metricsService.observeRequestDuration(method, path, duration);

        if (statusCode >= 400) {
          this.metricsService.incrementErrors(statusCode >= 500 ? 'server' : 'client');
        }
      }),
    );
  }
}
```

```typescript
scrape_configs:
  - job_name: 'nestjs-app'
    scrape_interval: 15s
    metrics_path: '/metrics'
    static_configs:
      - targets:
          - 'localhost:3000'
          - 'localhost:3001'
    relabel_configs:
      - source_labels: [__address__]
        target_label: instance
```

**Kasus Penggunaan Nyata:** Monitoring platform microservices — setiap service NestJS mengekspos metrics di `/metrics`. Prometheus server meng-scrape semua services setiap 15 detik. Grafana dashboard menampilkan request rate, error rate, latency p99, dan memory usage per service.
