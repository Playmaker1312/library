# 38. Monitoring dan Observability ## 38.1 Health Checks nestjs terminus

**Definisi Singkat:** Health checks adalah endpoint yang memonitor status aplikasi dan dependensinya (database, cache, external services). @nestjs/terminus menyediakan health check indicators siap pakai untuk berbagai komponen.

**Analogi:** Health check seperti check-up rutin di dokter — tekanan darah (database connection), detak jantung (CPU usage), dan gula darah (memory). Dokter (terminus) memberi laporan lengkap: sehat atau ada masalah.

**Poin-Poin Penting:**
- **@nestjs/terminus** health checks package
- **TerminusModule** import module
- **HealthCheck** decorator untuk endpoint
- **TypeOrmHealthIndicator** health database
- **MongooseHealthIndicator** health MongoDB
- **MemoryHealthIndicator** memory usage
- **DiskHealthIndicator** disk space
- **Custom health indicator** untuk service spesifik

**Contoh Kode:**
```typescript
// app.module.ts
import { Module } from '@nestjs/common';
import { TerminusModule } from '@nestjs/terminus';
import { HttpModule } from '@nestjs/axios';
import { HealthController } from './health.controller';

@Module({
  imports: [
    TerminusModule.forRoot({
      errorLogStyle: 'json', // format error JSON
      gracefulShutdownTimeoutMs: 1000,
    }),
    HttpModule, // untuk external service health check
  ],
  controllers: [HealthController],
})
export class AppModule {}
```

```typescript
// health.controller.ts
import { Controller, Get } from '@nestjs/common';
import {
  HealthCheck,
  HealthCheckService,
  TypeOrmHealthIndicator,
  MemoryHealthIndicator,
  DiskHealthIndicator,
  HttpHealthIndicator,
  MongooseHealthIndicator,
} from '@nestjs/terminus';

@Controller('health')
export class HealthController {
  constructor(
    private health: HealthCheckService,
    private db: TypeOrmHealthIndicator,
    private memory: MemoryHealthIndicator,
    private disk: DiskHealthIndicator,
    private http: HttpHealthIndicator,
  ) {}

  @Get()
  @HealthCheck()
  check() {
    return this.health.check([
      // Database health
      () => this.db.pingCheck('database', { timeout: 3000 }),

      // Memory health (heap > 200MB = warning)
      () => this.memory.checkHeap('memory_heap', 200 * 1024 * 1024),

      // RSS memory ( > 300MB = warning)
      () => this.memory.checkRSS('memory_rss', 300 * 1024 * 1024),

      // Disk storage
      () => this.disk.checkStorage('disk', {
        thresholdPercent: 0.9, // 90% usage = unhealthy
        path: '/',
      }),

      // External API Health
      () => this.http.pingCheck('external-api', 'https://api.external.com/health'),
    ]);
  }

  @Get('/liveness')
  @HealthCheck()
  liveness() {
    // Probe sederhana — aplikasi hidup?
    return this.health.check([
      () => this.db.pingCheck('database'),
      () => this.memory.checkHeap('memory_heap', 500 * 1024 * 1024),
    ]);
  }

  @Get('/readiness')
  @HealthCheck()
  readiness() {
    // Probe siap terima traffic?
    return this.health.check([
      () => this.db.pingCheck('database'),
      () => this.http.pingCheck('redis', 'http://redis:6379/ping'),
    ]);
  }
}
```

**Kasus Penggunaan Nyata:** Kubernetes cluster — liveness probe endpoint `/health/liveness` (app hidup?), readiness probe `/health/readiness` (siap terima traffic?). Jika health check gagal 3x, Kubernetes restart pod otomatis. Digunakan juga di load balancer untuk routing traffic.
