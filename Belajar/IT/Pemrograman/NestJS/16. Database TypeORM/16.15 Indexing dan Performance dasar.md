# 16. Database TypeORM
## 16.15 Indexing dan Performance dasar
**Definisi Singkat:** Index mempercepat pencarian dengan membuat struktur data terpisah untuk kolom tertentu. TypeORM mendukung deklarasi index via decorator `@Index()`.

**Analogi:** Index seperti daftar isi buku — tanpa index Anda harus baca halaman satu per satu; dengan index langsung ke halaman yang dicari.

**Poin-Poin Penting:**
- **`@Index()`** — Buat index pada kolom atau composite (beberapa kolom)
- **`@Index({ unique: true })`** — Unique index (sama dengan `@Column({ unique: true })`)
- **Composite index** — Gabungan beberapa kolom untuk query multi-kondisi
- **Full-text search** — Index khusus untuk pencarian teks (tergantung database)
- **Query optimization** — Gunakan `EXPLAIN` untuk analisis performa

**Contoh Kode:**
```typescript
// product.entity.ts
import { Entity, PrimaryGeneratedColumn, Column, Index } from 'typeorm';

@Entity('products')
@Index('idx_product_name_price', ['name', 'price'])
export class Product {
  @PrimaryGeneratedColumn()
  id: number;

  @Index()
  @Column({ length: 200 })
  name: string;

  @Column('decimal', { precision: 10, scale: 2 })
  price: number;

  @Index('idx_product_category')
  @Column()
  categoryId: number;

  @Column({ default: true })
  isActive: boolean;
}

// product.module.ts
import { Module } from '@nestjs/common';
import { TypeOrmModule } from '@nestjs/typeorm';
import { Product } from './product.entity';
import { ProductService } from './product.service';

@Module({
  imports: [TypeOrmModule.forFeature([Product])],
  providers: [ProductService],
})
export class ProductModule {}
```

**Kasus Penggunaan Nyata:** Index pada kolom `email` di tabel `users` mempercepat query login dari ratusan milidetik ke bawah 10ms.
