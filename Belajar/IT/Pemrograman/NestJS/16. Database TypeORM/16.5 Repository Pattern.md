# 16. Database TypeORM
## 16.5 Repository Pattern
**Definisi Singkat:** Repository adalah abstraksi data layer yang menyediakan metode CRUD standar. TypeORM menggunakan `Repository<T>` yang di-inject via `@InjectRepository()`.

**Analogi:** Repository seperti asisten pribadi — Anda suruh "cari user id 5" tanpa perlu tahu bagaimana dia mencari di database.

**Poin-Poin Penting:**
- **`Repository<T>`** — Class TypeORM untuk operasi database per entity
- **`@InjectRepository(Entity)`** — Decorator NestJS untuk inject repository
- **CRUD methods** — `find()`, `findOne()`, `save()`, `update()`, `delete()`
- **Custom methods** — Bisa extends Repository atau gunakan QueryBuilder

**Contoh Kode:**
```typescript
// user.service.ts
import { Injectable } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { User } from './user.entity';

@Injectable()
export class UserService {
  constructor(
    @InjectRepository(User)
    private readonly userRepository: Repository<User>,
  ) {}

  findAll(): Promise<User[]> {
    return this.userRepository.find();
  }

  findOne(id: number): Promise<User | null> {
    return this.userRepository.findOneBy({ id });
  }

  async create(data: Partial<User>): Promise<User> {
    const user = this.userRepository.create(data);
    return this.userRepository.save(user);
  }
}
```

**Kasus Penggunaan Nyata:** Service `UserService` yang menggunakan `UserRepository` untuk registrasi, login, dan manajemen profil user.
