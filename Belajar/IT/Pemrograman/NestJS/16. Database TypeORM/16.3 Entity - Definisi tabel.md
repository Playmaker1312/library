# 16. Database TypeORM
## 16.3 Entity - Definisi tabel
**Definisi Singkat:** Entity adalah class yang dipetakan ke tabel database. Setiap properti class merepresentasikan kolom tabel. Dideklarasikan dengan decorator `@Entity()`.

**Analogi:** Entity seperti cetakan kue — bentuknya menentukan seperti apa tabel di database; setiap properti adalah kolom, setiap instance adalah baris.

**Poin-Poin Penting:**
- **`@Entity('nama_tabel')`** — Decorator untuk menandai class sebagai entity
- **`@PrimaryGeneratedColumn()`** — Kolom primary key auto-increment
- **`@Column()`** — Kolom biasa
- **Registrasi** — Entity harus didaftarkan di `TypeOrmModule.forFeature()`

**Contoh Kode:**
```typescript
// user.entity.ts
import { Entity, PrimaryGeneratedColumn, Column } from 'typeorm';

@Entity('users')
export class User {
  @PrimaryGeneratedColumn()
  id: number;

  @Column({ length: 100 })
  name: string;

  @Column({ unique: true })
  email: string;

  @Column({ default: true })
  isActive: boolean;

  @Column({ type: 'timestamp', default: () => 'CURRENT_TIMESTAMP' })
  createdAt: Date;
}

// user.module.ts
import { Module } from '@nestjs/common';
import { TypeOrmModule } from '@nestjs/typeorm';
import { User } from './user.entity';
import { UserService } from './user.service';

@Module({
  imports: [TypeOrmModule.forFeature([User])],
  providers: [UserService],
})
export class UserModule {}
```

**Kasus Penggunaan Nyata:** Entity `Product` untuk e-commerce dengan kolom id, name, price, stock, categoryId.
