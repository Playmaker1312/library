# 16. Database TypeORM
## 16.9 Relations Many-to-Many
**Definisi Singkat:** Relasi banyak-ke-banyak menghubungkan banyak baris di tabel A dengan banyak baris di tabel B melalui tabel pivot/junction.

**Analogi:** Seperti siswa dan kelas — satu siswa bisa mengambil banyak kelas, satu kelas diikuti banyak siswa. Membutuhkan tabel pendaftaran sebagai penghubung.

**Poin-Poin Penting:**
- **`@ManyToMany(() => Course)`** — Decorator di kedua entity
- **`@JoinTable()`** — Ditempatkan di satu sisi (pemilik relasi)
- **Tabel pivot** — Dibuat otomatis oleh TypeORM
- **Cascade** — Bisa menghapus relasi berantai

**Contoh Kode:**
```typescript
// student.entity.ts
import { Entity, PrimaryGeneratedColumn, Column, ManyToMany, JoinTable } from 'typeorm';
import { Course } from './course.entity';

@Entity('students')
export class Student {
  @PrimaryGeneratedColumn()
  id: number;

  @Column()
  name: string;

  @ManyToMany(() => Course, (course) => course.students)
  @JoinTable({ name: 'enrollments' })
  courses: Course[];
}

// course.entity.ts
import { Entity, PrimaryGeneratedColumn, Column, ManyToMany } from 'typeorm';
import { Student } from './student.entity';

@Entity('courses')
export class Course {
  @PrimaryGeneratedColumn()
  id: number;

  @Column()
  title: string;

  @ManyToMany(() => Student, (student) => student.courses)
  students: Student[];
}

// student.module.ts
import { Module } from '@nestjs/common';
import { TypeOrmModule } from '@nestjs/typeorm';
import { Student } from './student.entity';
import { Course } from './course.entity';
import { StudentService } from './student.service';

@Module({
  imports: [TypeOrmModule.forFeature([Student, Course])],
  providers: [StudentService],
})
export class StudentModule {}
```

**Kasus Penggunaan Nyata:** Relasi `Product` ↔ `Order` di e-commerce — satu produk bisa ada di banyak order, satu order bisa berisi banyak produk.
