# 16. Database TypeORM
## 16.12 Migrations Membuat dan menjalankan
**Definisi Singkat:** Migration adalah file yang merekam perubahan skema database (tambah kolom, ubah tipe) secara version-controlled, lebih aman daripada `synchronize: true`.

**Analogi:** Migration seperti catatan renovasi rumah — Anda tahu kapan tembok dipasang, kapan dicat ulang, dan bisa mundur ke versi sebelumnya.

**Poin-Poin Penting:**
- **`typeorm migration:create`** — Membuat file migration kosong
- **`typeorm migration:generate`** — Generate migration dari perubahan entity
- **`typeorm migration:run`** — Menjalankan migration yang pending
- **`typeorm migration:revert`** — Membatalkan migration terakhir
- **`synchronize: false`** — Matikan di production, gunakan migration

**Contoh Kode:**
```typescript
// data-source.ts — Konfigurasi CLI
import { DataSource } from 'typeorm';
import { config } from 'dotenv';
config();

export default new DataSource({
  type: 'postgres',
  host: process.env.DB_HOST,
  port: +process.env.DB_PORT,
  username: process.env.DB_USER,
  password: process.env.DB_PASS,
  database: process.env.DB_NAME,
  entities: ['dist/**/*.entity.js'],
  migrations: ['dist/migrations/*.js'],
});

// migration — otomatis generate
// npm run typeorm -- migration:generate migrations/AddPriceToProduct

// Hasil generate:
// migrations/1700000000000-AddPriceToProduct.ts
import { MigrationInterface, QueryRunner, TableColumn } from 'typeorm';

export class AddPriceToProduct1700000000000 implements MigrationInterface {
  name = 'AddPriceToProduct1700000000000';

  async up(queryRunner: QueryRunner): Promise<void> {
    await queryRunner.addColumn(
      'products',
      new TableColumn({ name: 'price', type: 'decimal', precision: 10, scale: 2, default: 0 }),
    );
  }

  async down(queryRunner: QueryRunner): Promise<void> {
    await queryRunner.dropColumn('products', 'price');
  }
}
```

**Kasus Penggunaan Nyata:** Tim backend menggunakan migration untuk menambahkan kolom `discountPrice` tanpa mengganggu production database.
