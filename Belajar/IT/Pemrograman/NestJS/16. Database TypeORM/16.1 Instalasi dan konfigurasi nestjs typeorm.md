# 16. Database TypeORM
## 16.1 Instalasi dan konfigurasi nestjs typeorm
**Definisi Singkat:** Mengintegrasikan TypeORM dengan NestJS melalui `@nestjs/typeorm` untuk menyediakan akses database deklaratif. Konfigurasi dilakukan di `TypeOrmModule.forRoot()` dalam AppModule.

**Analogi:** TypeORM adalah ORM yang membuat tabel database menjadi class TypeScript, seperti mencetak stempel — Anda tinggal pakai tanpa menulis SQL manual.

**Poin-Poin Penting:**
- **`@nestjs/typeorm`** — Package integrasi resmi NestJS untuk TypeORM
- **`TypeOrmModule.forRoot()`** — Method konfigurasi global database
- **`type`** — Jenis database (postgres, mysql, sqlite, mssql)
- **`autoLoadEntities: true`** — Memuat entity secara otomatis dari module

**Contoh Kode:**
```typescript
// app.module.ts
import { Module } from '@nestjs/common';
import { TypeOrmModule } from '@nestjs/typeorm';

@Module({
  imports: [
    TypeOrmModule.forRoot({
      type: 'postgres',
      host: 'localhost',
      port: 5432,
      username: 'postgres',
      password: 'password',
      database: 'nestdb',
      autoLoadEntities: true,
      synchronize: true, // hanya untuk development
    }),
  ],
})
export class AppModule {}
```

**Kasus Penggunaan Nyata:** Backend REST API yang membutuhkan koneksi ke PostgreSQL untuk menyimpan data user, produk, dan transaksi.
