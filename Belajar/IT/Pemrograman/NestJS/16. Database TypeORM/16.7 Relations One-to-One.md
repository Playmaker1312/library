# 16. Database TypeORM
## 16.7 Relations One-to-One
**Definisi Singkat:** Relasi satu-ke-satu menghubungkan satu baris di tabel A dengan tepat satu baris di tabel B menggunakan `@OneToOne()` dan `@JoinColumn()`.

**Analogi:** Seperti KTP dan seseorang — satu orang punya tepat satu KTP, satu KTP milik tepat satu orang.

**Poin-Poin Penting:**
- **`@OneToOne(() => Profile)`** — Mendefinisikan relasi one-to-one
- **`@JoinColumn()`** — Ditempatkan di sisi yang memiliki foreign key
- **Cascade** — `{ cascade: true }` untuk operasi berantai
- **Eager/lazy** — Bisa eager loading dengan `{ eager: true }`

**Contoh Kode:**
```typescript
// user.entity.ts
import { Entity, PrimaryGeneratedColumn, Column, OneToOne, JoinColumn } from 'typeorm';
import { Profile } from './profile.entity';

@Entity('users')
export class User {
  @PrimaryGeneratedColumn()
  id: number;

  @Column()
  name: string;

  @OneToOne(() => Profile, (profile) => profile.user, { cascade: true })
  @JoinColumn()
  profile: Profile;
}

// profile.entity.ts
import { Entity, PrimaryGeneratedColumn, Column, OneToOne } from 'typeorm';
import { User } from './user.entity';

@Entity('profiles')
export class Profile {
  @PrimaryGeneratedColumn()
  id: number;

  @Column()
  bio: string;

  @Column({ nullable: true })
  avatarUrl: string;

  @OneToOne(() => User, (user) => user.profile)
  user: User;
}

// user.module.ts
import { Module } from '@nestjs/common';
import { TypeOrmModule } from '@nestjs/typeorm';
import { User } from './user.entity';
import { Profile } from './profile.entity';

@Module({
  imports: [TypeOrmModule.forFeature([User, Profile])],
  providers: [UserService],
  exports: [UserService],
})
export class UserModule {}
```

**Kasus Penggunaan Nyata:** Relasi `User` ↔ `Profile` di aplikasi sosial media — setiap user memiliki satu profil detail.
