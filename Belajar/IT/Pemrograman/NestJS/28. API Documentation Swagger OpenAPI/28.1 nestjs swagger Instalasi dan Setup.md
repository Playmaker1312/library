# 28. API Documentation Swagger OpenAPI
## 28.1 nestjs swagger Instalasi dan Setup
**Definisi Singkat:** `@nestjs/swagger` adalah modul resmi untuk mengintegrasikan OpenAPI (Swagger) ke aplikasi NestJS, memungkinkan dokumentasi API otomatis berdasarkan decorator.
**Analogi:** Seperti membuat buku manual untuk mobil — daripada menulis manual terpisah, Anda pasang sensor di setiap komponen dan buku manual ter-generate otomatis berdasarkan sensor tersebut.
**Poin-Poin Penting:**
- `@nestjs/swagger` dan `swagger-ui-express`
- `npm install @nestjs/swagger swagger-ui-express`
- Setup di `bootstrap()` dengan `SwaggerModule`
**Contoh Kode:**
```typescript
// main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { DocumentBuilder, SwaggerModule } from '@nestjs/swagger';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // 1. Buat konfigurasi dokumen Swagger
  const config = new DocumentBuilder()
    .setTitle('Aplikasi E-commerce API')
    .setDescription('Dokumentasi API untuk platform e-commerce')
    .setVersion('1.0')
    .addTag('auth', 'Autentikasi dan otorisasi')
    .addTag('users', 'Manajemen pengguna')
    .addTag('products', 'Manajemen produk')
    .addTag('orders', 'Manajemen pesanan')
    .build();

  // 2. Buat dokumen OpenAPI
  const document = SwaggerModule.createDocument(app, config);

  // 3. Setup Swagger UI di endpoint /api
  SwaggerModule.setup('api', app, document, {
    swaggerOptions: {
      persistAuthorization: true,
    },
    customCss: '.swagger-ui .topbar { display: none }',
    customSiteTitle: 'API Documentation',
  });

  await app.listen(3000);
  console.log(`Aplikasi berjalan di http://localhost:3000`);
  console.log(`Dokumentasi API di http://localhost:3000/api`);
}
bootstrap();
```
