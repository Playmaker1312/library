# 28. API Documentation Swagger OpenAPI
## 28.6 ApiBearerAuth Auth di Swagger
**Definisi Singkat:** `@ApiBearerAuth()` decorator menambahkan indikasi bahwa endpoint memerlukan autentikasi Bearer Token (JWT) di dokumentasi Swagger, lengkap dengan tombol "Authorize" untuk memasukkan token.
**Analogi:** Seperti pintu VIP di klub — `@ApiBearerAuth()` adalah tanda "Akses Khusus Member" di pintu, dan penjaga (auth guard) akan memeriksa kartu member (token JWT) sebelum mengizinkan masuk.
**Poin-Poin Penting:**
- `@ApiBearerAuth()` di controller atau method
- `DocumentBuilder.addBearerAuth()` untuk konfigurasi global
- `ApiSecurity('bearer')` alternatif
- Integrasi dengan `AuthGuard`
**Contoh Kode:**
```typescript
// main.ts — setup bearer auth global
import { NestFactory } from '@nestjs/core';
import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  const config = new DocumentBuilder()
    .setTitle('E-commerce API')
    .setVersion('1.0')
    // Konfigurasi Bearer Auth global
    .addBearerAuth(
      {
        type: 'http',
        scheme: 'bearer',
        bearerFormat: 'JWT',
        name: 'JWT',
        description: 'Masukkan JWT token',
        in: 'header',
      },
      'JWT-auth', // Nama security scheme
    )
    .build();

  const document = SwaggerModule.createDocument(app, config);
  SwaggerModule.setup('api', app, document);

  await app.listen(3000);
}
bootstrap();
```
```typescript
// auth.controller.ts — endpoint login menghasilkan token
import { Controller, Post, Body } from '@nestjs/common';
import { ApiTags, ApiOperation, ApiOkResponse, ApiUnauthorizedResponse } from '@nestjs/swagger';
import { AuthService } from './auth.service';
import { LoginDto } from './dto/login.dto';
import { TokenResponseDto } from './dto/token-response.dto';

@ApiTags('auth')
@Controller('auth')
export class AuthController {
  constructor(private readonly authService: AuthService) {}

  @Post('login')
  @ApiOperation({ summary: 'Login pengguna' })
  @ApiOkResponse({
    description: 'Login berhasil, mengembalikan token',
    type: TokenResponseDto,
  })
  @ApiUnauthorizedResponse({ description: 'Email atau password salah' })
  login(@Body() loginDto: LoginDto) {
    return this.authService.login(loginDto);
  }
}
```
```typescript
// protected.controller.ts — endpoint yang butuh autentikasi
import { Controller, Get, Post, UseGuards } from '@nestjs/common';
import { ApiTags, ApiOperation, ApiBearerAuth, ApiUnauthorizedResponse, ApiOkResponse } from '@nestjs/swagger';
import { AuthGuard } from '@nestjs/passport';

@ApiTags('orders')
@ApiBearerAuth('JWT-auth')  // Tandai semua endpoint perlu auth
@ApiUnauthorizedResponse({ description: 'Token tidak valid atau expired' })
@Controller('orders')
export class OrdersController {
  @Get()
  @ApiOperation({ summary: 'Mendapatkan daftar pesanan (perlu login)' })
  @ApiOkResponse({ description: 'Daftar pesanan berhasil diambil' })
  @UseGuards(AuthGuard('jwt'))
  findAll() {
    return [];
  }

  @Post()
  @ApiOperation({ summary: 'Membuat pesanan baru (perlu login)' })
  @ApiBearerAuth('JWT-auth')  // Bisa di level method juga
  @UseGuards(AuthGuard('jwt'))
  create() {
    return { message: 'Order created' };
  }

  // Endpoint publik — tidak perlu @ApiBearerAuth
  @Get('public')
  @ApiOperation({ summary: 'Endpoint publik (tanpa auth)' })
  // Tidak ada @ApiBearerAuth dan @UseGuards
  publicEndpoint() {
    return { message: 'Public data' };
  }
}
```
```typescript
// dto/token-response.dto.ts
import { ApiProperty } from '@nestjs/swagger';

export class TokenResponseDto {
  @ApiProperty({
    description: 'JWT access token',
    example: 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...',
  })
  accessToken: string;

  @ApiProperty({
    description: 'Token type',
    example: 'Bearer',
  })
  tokenType: string;

  @ApiProperty({
    description: 'Token expiration time in seconds',
    example: 3600,
  })
  expiresIn: number;
}
```
**Kasus Penggunaan Nyata:** API e-commerce dengan endpoint publik (melihat produk) dan endpoint privat (membuat pesanan, melihat riwayat). Di Swagger UI, pengguna bisa mengklik tombol "Authorize" di kanan atas, memasukkan token JWT yang didapat dari endpoint `/auth/login`, dan semua endpoint yang terproteksi dengan `@ApiBearerAuth()` bisa diuji langsung dari browser.
