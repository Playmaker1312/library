# 28. API Documentation Swagger OpenAPI
## 28.2 SwaggerModule setup
**Definisi Singkat:** `SwaggerModule` adalah kelas utama dari `@nestjs/swagger` yang menyediakan method `createDocument()` untuk membangun spesifikasi OpenAPI dan `setup()` untuk menampilkan Swagger UI.
**Analogi:** Seperti sutradara film — `createDocument()` adalah proses produksi (membuat film berdasarkan naskah) dan `setup()` adalah premiere (menayangkan film ke penonton).
**Poin-Poin Penting:**
- `SwaggerModule.createDocument(app, config, options?)`
- `SwaggerModule.setup(path, app, document, options?)`
- Options termasuk `deepScanRoutes`, `include`, `extraModels`
**Contoh Kode:**
```typescript
// main.ts — variasi konfigurasi SwaggerModule
import { NestFactory } from '@nestjs/core';
import { SwaggerModule, DocumentBuilder, SwaggerDocumentOptions } from '@nestjs/swagger';
import { AppModule } from './app.module';
import { AdminModule } from './admin/admin.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  const config = new DocumentBuilder()
    .setTitle('Main API')
    .setDescription('API utama aplikasi')
    .setVersion('1.0')
    .addBearerAuth()
    .build();

  // Options untuk createDocument — kontrol endpoint mana yang diinclude
  const options: SwaggerDocumentOptions = {
    // Hanya include modul tertentu (default: semua)
    include: [AppModule],
    // Scan routes secara recursive
    deepScanRoutes: true,
    // Tambahkan model tambahan yang tidak terdeteksi otomatis
    extraModels: [],
    // Abaikan global prefix
    ignoreGlobalPrefix: false,
  };

  const document = SwaggerModule.createDocument(app, config, options);

  // Setup Swagger UI dengan custom options
  SwaggerModule.setup('api-docs', app, document, {
    // Tampilkan Swagger UI di production sekalipun
    useGlobalPrefix: false,
    // Custom CSS
    customCss: `
      .topbar-wrapper { content: url('/logo.png'); }
      .swagger-ui .topbar { background-color: #1a1a2e; }
    `,
    // Custom JS
    customJs: '/custom-swagger.js',
    // Custom favicon
    customfavIcon: '/favicon.ico',
    // URL untuk Swagger UI dari CDN alternatif
    customCssUrl: 'https://cdn.jsdelivr.net/npm/swagger-ui-dist@5/swagger-ui.css',
    // Opsi Swagger UI
    swaggerOptions: {
      docExpansion: 'list',
      filter: true,
      showRequestDuration: true,
      defaultModelsExpandDepth: 3,
    },
  });

  await app.listen(3000);
}
bootstrap();
```
```typescript
// admin-setup terpisah — buat dokumentasi khusus admin
import { INestApplication } from '@nestjs/common';
import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger';

export function setupAdminSwagger(app: INestApplication) {
  const adminConfig = new DocumentBuilder()
    .setTitle('Admin API')
    .setDescription('Endpoint khusus untuk admin panel')
    .setVersion('1.0')
    .addBearerAuth({ type: 'http', scheme: 'bearer', bearerFormat: 'JWT' }, 'admin-jwt')
    .build();

  const adminDocument = SwaggerModule.createDocument(app, adminConfig, {
    include: [], // Include modul admin spesifik
  });

  SwaggerModule.setup('api/admin', app, adminDocument, {
    swaggerOptions: { defaultModelsExpandDepth: -1 },
  });
}
```
**Kasus Penggunaan Nyata:** Aplikasi dengan role-based access — dokumentasi API untuk pengguna biasa menampilkan endpoint `/users`, `/products`, sementara dokumentasi admin di `/api/admin` menampilkan endpoint manajemen yang lebih sensitif dengan autentikasi terpisah.
