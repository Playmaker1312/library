# 28. API Documentation Swagger OpenAPI
## 28.8 Multiple Swagger Documents
**Definisi Singkat:** NestJS mendukung pembuatan multiple dokumen Swagger dari satu aplikasi, memungkinkan API didokumentasikan secara terpisah untuk audiens berbeda (public, admin, internal).
**Analogi:** Seperti sebuah hotel yang punya brosur berbeda — satu untuk tamu (menampilkan fasilitas umum), satu untuk staf (menampilkan ruang servis), dan satu untuk manajemen (menampilkan data keuangan) — semua dari hotel yang sama.
**Poin-Poin Penting:**
- Multiple `SwaggerModule.createDocument()` calls
- Setiap dokumen bisa include modul berbeda
- Setiap dokumen punya endpoint UI terpisah
- Filter endpoint dengan tags atau path
**Contoh Kode:**
```typescript
// main.ts — multiple Swagger documents
import { NestFactory } from '@nestjs/core';
import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // --- DOKUMEN 1: Public API ---
  const publicConfig = new DocumentBuilder()
    .setTitle('Public API')
    .setDescription('API publik untuk aplikasi mobile & web')
    .setVersion('1.0')
    .addBearerAuth({ type: 'http', scheme: 'bearer', bearerFormat: 'JWT' }, 'public-jwt')
    .build();

  const publicDocument = SwaggerModule.createDocument(app, publicConfig, {
    // Include hanya modul publik
    include: [],  // Include specific modules here
    // Filter operasi berdasarkan tags
    operationIdFactory: (controllerKey: string, methodKey: string) => methodKey,
  });

  SwaggerModule.setup('api/public', app, publicDocument, {
    swaggerOptions: {
      docExpansion: 'list',
      filter: true,
    },
    customSiteTitle: 'Public API Documentation',
  });

  // --- DOKUMEN 2: Admin API ---
  const adminConfig = new DocumentBuilder()
    .setTitle('Admin API')
    .setDescription('API internal untuk admin panel — memerlukan role admin')
    .setVersion('1.0')
    .addBearerAuth({ type: 'http', scheme: 'bearer', bearerFormat: 'JWT' }, 'admin-jwt')
    .build();

  const adminDocument = SwaggerModule.createDocument(app, adminConfig, {
    // Include modul admin spesifik
    deepScanRoutes: true,
  });

  SwaggerModule.setup('api/admin', app, adminDocument, {
    swaggerOptions: {
      docExpansion: 'none',
      defaultModelsExpandDepth: -1,
    },
    customSiteTitle: 'Admin API Documentation',
    // Proteksi dengan basic auth
    customCss: '.swagger-ui .topbar { background-color: #2d2d2d; }',
  });

  // --- DOKUMEN 3: Internal Service API ---
  const internalConfig = new DocumentBuilder()
    .setTitle('Internal Service API')
    .setDescription('Dokumentasi untuk komunikasi antar microservice')
    .setVersion('1.0')
    .addBearerAuth({ type: 'http', scheme: 'bearer', bearerFormat: 'JWT' }, 'service-jwt')
    .build();

  const internalDocument = SwaggerModule.createDocument(app, internalConfig, {
    // Hanya endpoint dengan path /internal/*
    operationIdFactory: (controllerKey: string, methodKey: string) => `${controllerKey}_${methodKey}`,
  });

  SwaggerModule.setup('api/internal', app, internalDocument, {
    customSiteTitle: 'Internal API Documentation',
  });

  await app.listen(3000);
  console.log('Public API docs: http://localhost:3000/api/public');
  console.log('Admin API docs: http://localhost:3000/api/admin');
  console.log('Internal API docs: http://localhost:3000/api/internal');
}
bootstrap();
```
```typescript
// Dengan pemisahan berdasarkan tag — hanya expose endpoint tertentu
import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger';
import { INestApplication } from '@nestjs/common';

export function setupSwaggerDocuments(app: INestApplication) {
  // Dokumen untuk public — hanya tag 'auth', 'products', 'orders'
  const publicDoc = SwaggerModule.createDocument(app, 
    new DocumentBuilder().setTitle('Public API').setVersion('1.0').build(),
  );

  // Dokumen untuk admin — hanya tag 'admin'
  const adminDoc = SwaggerModule.createDocument(app,
    new DocumentBuilder().setTitle('Admin API').setVersion('1.0')
      .addBearerAuth()
      .build(),
  );

  SwaggerModule.setup('docs/public', app, publicDoc);
  SwaggerModule.setup('docs/admin', app, adminDoc);
}
```
```typescript
// Filter berdasarkan path prefix
import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger';
import { INestApplication } from '@nestjs/common';
import * as path from 'path';

export function setupFilteredDocs(app: INestApplication) {
  const config = new DocumentBuilder()
    .setTitle('Filtered API')
    .setVersion('1.0')
    .build();

  // Buat dokumen utama dulu
  const fullDocument = SwaggerModule.createDocument(app, config);

  // Filter path untuk public API (hapus path /admin dan /internal)
  const publicPaths = {};
  for (const [path, methods] of Object.entries(fullDocument.paths)) {
    if (!path.startsWith('/admin') && !path.startsWith('/internal')) {
      publicPaths[path] = methods;
    }
  }
  fullDocument.paths = publicPaths;

  SwaggerModule.setup('docs', app, fullDocument);
}
```
**Kasus Penggunaan Nyata:** Startup e-commerce yang menyediakan API publik untuk mobile app (hanya endpoint produk, auth, orders), API admin untuk dashboard internal (manajemen produk, user, laporan keuangan), dan API internal untuk komunikasi antar microservice — semua dari satu codebase NestJS, dengan dokumentasi terpisah di endpoint berbeda.
