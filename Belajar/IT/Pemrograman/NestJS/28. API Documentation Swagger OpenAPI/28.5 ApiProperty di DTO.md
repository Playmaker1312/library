# 28. API Documentation Swagger OpenAPI
## 28.5 ApiProperty di DTO
**Definisi Singkat:** `@ApiProperty()` decorator digunakan di class DTO (Data Transfer Object) untuk mendokumentasikan properti request/response body di spesifikasi Swagger secara otomatis.
**Analogi:** Seperti label gizi di kemasan makanan — memberi tahu konsumen (frontend developer) apa saja isi dari request/response, tipe data, dan contoh nilai yang valid.
**Poin-Poin Penting:**
- `@ApiProperty({ type, example, description })`
- `@ApiPropertyOptional()` untuk field opsional
- Integrasi dengan `class-validator` decorator
- `required`, `default`, `enum`, `minimum`, `maximum`
**Contoh Kode:**
```typescript
// dto/create-user.dto.ts
import { ApiProperty, ApiPropertyOptional } from '@nestjs/swagger';
import { IsEmail, IsString, MinLength, IsOptional, IsEnum, IsNumber } from 'class-validator';

export enum UserRole {
  USER = 'user',
  ADMIN = 'admin',
  MODERATOR = 'moderator',
}

export class CreateUserDto {
  @ApiProperty({
    description: 'Nama lengkap pengguna',
    example: 'John Doe',
    minLength: 3,
    maxLength: 100,
  })
  @IsString()
  @MinLength(3)
  name: string;

  @ApiProperty({
    description: 'Alamat email pengguna',
    example: 'john@example.com',
    format: 'email',
  })
  @IsEmail()
  email: string;

  @ApiProperty({
    description: 'Password untuk akun (min 8 karakter)',
    example: 'secureP@ss123',
    minLength: 8,
    writeOnly: true,  // Tidak ditampilkan di response
  })
  @IsString()
  @MinLength(8)
  password: string;

  @ApiPropertyOptional({
    description: 'Nomor telepon (opsional)',
    example: '+6281234567890',
  })
  @IsOptional()
  @IsString()
  phone?: string;

  @ApiProperty({
    description: 'Role pengguna',
    enum: UserRole,
    default: UserRole.USER,
    example: UserRole.USER,
  })
  @IsEnum(UserRole)
  role: UserRole;

  @ApiPropertyOptional({
    description: 'Umur pengguna',
    example: 25,
    minimum: 17,
    maximum: 120,
  })
  @IsOptional()
  @IsNumber()
  age?: number;
}
```
```typescript
// dto/pagination.dto.ts
import { ApiPropertyOptional } from '@nestjs/swagger';
import { Type } from 'class-transformer';
import { IsOptional, IsInt, Min, Max } from 'class-validator';

export class PaginationDto {
  @ApiPropertyOptional({
    description: 'Halaman yang diminta',
    default: 1,
    minimum: 1,
    example: 1,
  })
  @IsOptional()
  @Type(() => Number)
  @IsInt()
  @Min(1)
  page?: number = 1;

  @ApiPropertyOptional({
    description: 'Jumlah item per halaman',
    default: 10,
    minimum: 1,
    maximum: 100,
    example: 10,
  })
  @IsOptional()
  @Type(() => Number)
  @IsInt()
  @Min(1)
  @Max(100)
  limit?: number = 10;
}
```

```typescript
// dto/create-product.dto.ts
import { ApiProperty, ApiPropertyOptional } from '@nestjs/swagger';
import { IsString, IsNumber, IsOptional, Min, MaxLength } from 'class-validator';

export class CreateProductDto {
  @ApiProperty({ description: 'Nama produk', example: 'Nike Air Max' })
  @IsString()
  @MaxLength(200)
  name: string;

  @ApiProperty({ description: 'Harga produk dalam Rupiah', example: 1500000, minimum: 0 })
  @IsNumber()
  @Min(0)
  price: number;

  @ApiPropertyOptional({ description: 'Deskripsi produk', example: 'Sepatu olahraga premium' })
  @IsOptional()
  @IsString()
  description?: string;
}
```
**Kasus Penggunaan Nyata:** Tim frontend mengirim request `POST /users` dengan body JSON. Dengan `@ApiProperty` di DTO, Swagger secara otomatis menampilkan schema request, contoh nilai, validasi (required/opsional), dan tipe data — memudahkan frontend developer menyusun request body yang benar.
