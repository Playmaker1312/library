# 28. API Documentation Swagger OpenAPI
## 28.3 ApiTags Grouping endpoints
**Definisi Singkat:** `@ApiTags()` decorator digunakan untuk mengelompokkan endpoint-endpoint controller ke dalam kategori tertentu di dokumentasi Swagger, membuat navigasi lebih terstruktur.
**Analogi:** Seperti rak buku di perpustakaan — daripada semua buku ditumpuk jadi satu, Anda kelompokkan berdasarkan genre (fiksi, non-fiksi, sains) sehingga pengunjung mudah menemukan yang dicari.
**Poin-Poin Penting:**
- `@ApiTags('nama-tag')` di controller
- Bisa multiple tags: `@ApiTags('users', 'admin')`
- Tags didefinisikan di `DocumentBuilder.addTag()`
- `@ApiTags()` di level method untuk override
**Contoh Kode:**
```typescript
// products.controller.ts
import { Controller, Get, Post, Body, Param } from '@nestjs/common';
import { ApiTags, ApiOperation } from '@nestjs/swagger';
import { ProductsService } from './products.service';
import { CreateProductDto } from './dto/create-product.dto';

@ApiTags('products')  // Semua endpoint di controller ini masuk grup 'products'
@Controller('products')
export class ProductsController {
  constructor(private readonly productsService: ProductsService) {}

  @Get()
  @ApiOperation({ summary: 'Mendapatkan semua produk' })
  findAll() {
    return this.productsService.findAll();
  }

  @Get(':id')
  @ApiOperation({ summary: 'Mendapatkan produk berdasarkan ID' })
  findOne(@Param('id') id: string) {
    return this.productsService.findOne(+id);
  }

  @Post()
  @ApiOperation({ summary: 'Membuat produk baru' })
  create(@Body() createProductDto: CreateProductDto) {
    return this.productsService.create(createProductDto);
  }
}
```
```typescript
// users.controller.ts
import { Controller, Get, Post, Body, Param } from '@nestjs/common';
import { ApiTags, ApiOperation } from '@nestjs/swagger';
import { UsersService } from './users.service';

@ApiTags('users')  // Grup terpisah untuk users
@Controller('users')
export class UsersController {
  constructor(private readonly usersService: UsersService) {}

  @Get()
  @ApiOperation({ summary: 'Mendapatkan daftar pengguna' })
  findAll() {
    return this.usersService.findAll();
  }

  @Post()
  @ApiOperation({ summary: 'Mendaftarkan pengguna baru' })
  create(@Body() createUserDto: any) {
    return this.usersService.create(createUserDto);
  }
}
```

```typescript
// admin.controller.ts — multi tags
import { Controller, Get } from '@nestjs/common';
import { ApiTags, ApiOperation } from '@nestjs/swagger';

@ApiTags('admin', 'users')  // Masuk ke dua grup sekaligus
@Controller('admin/users')
export class AdminUsersController {
  @Get()
  @ApiOperation({ summary: 'Admin: manajemen pengguna' })
  manageUsers() {
    return { message: 'Admin panel users' };
  }
}
```
```typescript
// main.ts — registrasi tags di DocumentBuilder
import { NestFactory } from '@nestjs/core';
import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  const config = new DocumentBuilder()
    .setTitle('E-commerce API')
    .setVersion('1.0')
    // Daftarkan semua tags dengan deskripsi
    .addTag('products', 'Operasi terkait produk')
    .addTag('users', 'Operasi terkait pengguna')
    .addTag('orders', 'Operasi terkait pesanan')
    .addTag('auth', 'Endpoint autentikasi')
    .addTag('admin', 'Endpoint khusus admin (perlu role admin)')
    .build();

  const document = SwaggerModule.createDocument(app, config);
  SwaggerModule.setup('api', app, document);

  await app.listen(3000);
}
bootstrap();
```
**Kasus Penggunaan Nyata:** API publik untuk mobile app dan web app. Tags seperti `auth`, `users`, `products`, `orders`, `payments` membantu frontend developer dan tim QA untuk fokus pada grup endpoint yang relevan dengan fitur yang sedang mereka kerjakan.
