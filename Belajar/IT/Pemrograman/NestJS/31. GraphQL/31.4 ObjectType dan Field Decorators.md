# 31. GraphQL
## 31.4 ObjectType dan Field Decorators
**Definisi Singkat:** `@ObjectType()` dan `@Field()` decorators mendefinisikan tipe GraphQL (model/entity) langsung dari class TypeScript, menentukan field apa saja yang tersedia di schema dan tipe datanya.
**Analogi:** Seperti formulir pendaftaran — `@ObjectType()` adalah judul formulir (Pendaftaran User), `@Field()` adalah kolom isian (Nama, Email, Umur) beserta tipe datanya (String, String, Int).
**Poin-Poin Penting:**
- `@ObjectType()` untuk mendeklarasikan GraphQL type
- `@Field(returnType, options)` untuk setiap properti
- `@Field(() => [Post])` untuk relasi array
- `@Int`, `@Float`, `@ID` untuk tipe spesifik
**Contoh Kode:**
```typescript
// entities/user.entity.ts — Code-first ObjectType
import { ObjectType, Field, Int, ID, Float, registerEnumType } from '@nestjs/graphql';
import { Post } from './post.entity';

// Enum GraphQL
export enum UserRole {
  ADMIN = 'ADMIN',
  USER = 'USER',
  MODERATOR = 'MODERATOR',
}

// Register enum agar bisa digunakan di GraphQL schema
registerEnumType(UserRole, {
  name: 'UserRole',
  description: 'Role pengguna dalam sistem',
});

@ObjectType({ description: 'Model pengguna' })
export class User {
  @Field(() => ID, { description: 'ID unik pengguna' })
  id: number;

  @Field(() => String, { description: 'Nama lengkap pengguna' })
  name: string;

  @Field(() => String, { description: 'Alamat email' })
  email: string;

  @Field(() => String, {
    description: 'URL avatar',
    nullable: true,  // Field opsional
    defaultValue: null,
  })
  avatar?: string;

  @Field(() => Int, {
    description: 'Umur pengguna',
    nullable: true,
  })
  age?: number;

  @Field(() => Float, {
    description: 'Saldo pengguna',
  })
  balance: number;

  @Field(() => UserRole, {
    description: 'Role pengguna',
    defaultValue: UserRole.USER,
  })
  role: UserRole;

  @Field(() => Boolean, {
    description: 'Apakah akun aktif',
  })
  isActive: boolean;

  @Field(() => Date, { description: 'Tanggal registrasi' })
  createdAt: Date;

  @Field(() => Date, { description: 'Tanggal update terakhir' })
  updatedAt: Date;

  // Field yang TIDAK muncul di GraphQL schema
  // (tanpa @Field decorator)
  password: string;

  // Relasi — resolver terpisah
  @Field(() => [Post], {
    description: 'Postingan milik user',
    nullable: 'items',
  })
  posts: Post[];
}
```
```typescript
// entities/post.entity.ts
import { ObjectType, Field, Int, ID } from '@nestjs/graphql';
import { User } from './user.entity';

@ObjectType({ description: 'Model postingan' })
export class Post {
  @Field(() => ID)
  id: number;

  @Field(() => String)
  title: string;

  @Field(() => String, { nullable: true })
  content?: string;

  @Field(() => Boolean, { defaultValue: false })
  published: boolean;

  @Field(() => Int)
  authorId: number;

  // Relasi ke User — tanpa @Field (di-resolve terpisah)
  @Field(() => User, { description: 'Penulis postingan' })
  author: User;

  @Field(() => [String], {
    description: 'Tags postingan',
    nullable: 'items',
  })
  tags: string[];

  @Field(() => Int, {
    description: 'Jumlah views',
    defaultValue: 0,
  })
  viewCount: number;
}
```
```typescript
// Complex types — custom scalar, nested object
import { ObjectType, Field, Int, Float } from '@nestjs/graphql';

@ObjectType()
export class Address {
  @Field(() => String)
  street: string;

  @Field(() => String)
  city: string;

  @Field(() => String)
  country: string;

  @Field(() => String)
  zipCode: string;
}

@ObjectType()
export class Product {
  @Field(() => ID)
  id: number;

  @Field(() => String)
  name: string;

  @Field(() => Float)
  price: number;

  @Field(() => Address, { description: 'Alamat toko tempat produk tersedia' })
  storeAddress: Address;

  @Field(() => [String])
  categories: string[];
}
```

**Kasus Penggunaan Nyata:** Dashboard manajemen user. Dengan `@ObjectType()` dan `@Field()`, frontend bisa query hanya field yang dibutuhkan — misalnya, halaman daftar user hanya perlu `id`, `name`, `email` — tanpa `password`, `balance`, atau `posts` yang tidak relevan.
