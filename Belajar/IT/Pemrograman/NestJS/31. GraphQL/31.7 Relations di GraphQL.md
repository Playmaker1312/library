# 31. GraphQL
## 31.7 Relations di GraphQL
**Definisi Singkat:** Relasi di GraphQL didefinisikan dengan `@Field(() => RelatedType)` dan `@ResolveField()` decorator, memungkinkan query data berelasi (one-to-many, many-to-one, many-to-many) dalam satu request.
**Analogi:** Seperti pohon keluarga — dari satu orang (User) Anda bisa melihat anak-anaknya (Posts) dan dari setiap anak Anda bisa melihat pasangannya (Comments on Post). GraphQL memungkinkan navigasi relasi ini secara depth-flexible.
**Poin-Poin Penting:**
- `@Field(() => [Post])` untuk one-to-many
- `@Field(() => User)` untuk many-to-one
- `@ResolveField()` untuk resolver relasi
- Batch dengan DataLoader untuk optimasi N+1
**Contoh Kode:**
```typescript
// entities/user.entity.ts
import { ObjectType, Field, Int, ID } from '@nestjs/graphql';
import { Post } from './post.entity';

@ObjectType()
export class User {
  @Field(() => ID)
  id: number;

  @Field(() => String)
  name: string;

  @Field(() => String)
  email: string;

  // Relasi one-to-many: User memiliki banyak Posts
  // Data posts di-resolve oleh method terpisah
  @Field(() => [Post], {
    nullable: 'items',
    description: 'Postingan milik user ini',
  })
  posts: Post[];
}
```
```typescript
// entities/post.entity.ts
import { ObjectType, Field, Int, ID } from '@nestjs/graphql';
import { User } from './user.entity';
import { Comment } from './comment.entity';

@ObjectType()
export class Post {
  @Field(() => ID)
  id: number;

  @Field(() => String)
  title: string;

  @Field(() => String, { nullable: true })
  content?: string;

  // Relasi many-to-one: Post milik satu User
  @Field(() => User, { nullable: false, description: 'Penulis postingan' })
  author: User;

  @Field(() => Int)
  authorId: number;

  // Relasi one-to-many: Post memiliki banyak Comments
  @Field(() => [Comment], { nullable: 'items' })
  comments: Comment[];
}
```
```typescript
// entities/comment.entity.ts
import { ObjectType, Field, Int, ID } from '@nestjs/graphql';
import { Post } from './post.entity';

@ObjectType()
export class Comment {
  @Field(() => ID)
  id: number;

  @Field(() => String)
  text: string;

  @Field(() => Int)
  postId: number;

  @Field(() => Post, { description: 'Postingan tempat komentar ini' })
  post: Post;
}
```
```typescript
// users.resolver.ts — ResolveField untuk relasi
import { Resolver, ResolveField, Parent, Query, Args, Int } from '@nestjs/graphql';
import { User } from './entities/user.entity';
import { Post } from './entities/post.entity';
import { PostsService } from './posts.service';

@Resolver(() => User)
export class UsersResolver {
  constructor(private postsService: PostsService) {}

  @Query(() => [User])
  async users() {
    // Fetch users tanpa posts
  }

  // 🎯 ResolveField: Cara GraphQL mengisi field 'posts'
  // Dipanggil OTOMATIS saat client query 'posts' dalam user
  @ResolveField(() => [Post], {
    description: 'Mengambil postingan milik user ini',
  })
  async posts(@Parent() user: User): Promise<Post[]> {
    // @Parent() memberikan akses ke object User parent
    return this.postsService.findByUserId(user.id);
  }
}
```
```typescript
// posts.resolver.ts — multiple ResolveField
import { Resolver, ResolveField, Parent, Mutation, Args } from '@nestjs/graphql';
import { Post } from './entities/post.entity';
import { User } from './entities/user.entity';
import { Comment } from './entities/comment.entity';
import { UsersService } from './users.service';
import { CommentsService } from './comments.service';

@Resolver(() => Post)
export class PostsResolver {
  constructor(
    private usersService: UsersService,
    private commentsService: CommentsService,
  ) {}

  // Resolve author untuk setiap Post
  @ResolveField(() => User, {
    description: 'Penulis postingan',
    nullable: true,
  })
  async author(@Parent() post: Post): Promise<User> {
    // GraphQL panggil ini saat client query 'author' dalam post
    // Gunakan DataLoader untuk batch (hindari N+1)
    return this.usersService.findOne(post.authorId);
  }

  // Resolve comments untuk setiap Post
  @ResolveField(() => [Comment], {
    description: 'Komentar pada postingan',
    nullable: 'items',
  })
  async comments(@Parent() post: Post): Promise<Comment[]> {
    return this.commentsService.findByPostId(post.id);
  }
}
```

**Kasus Penggunaan Nyata:** Halaman profil user yang menampilkan user info, daftar postingan, dan komentar — semua dalam satu query GraphQL. Tanpa GraphQL, frontend perlu panggil REST endpoints: `GET /users/1`, `GET /users/1/posts`, `GET /posts/1/comments` (bisa puluhan request untuk banyak user).
