# 31. GraphQL
## 31.10 Apollo Studio Playground
**Definisi Singkat:** Apollo Studio / GraphQL Playground adalah IDE visual berbasis web untuk mengeksplorasi dan menguji GraphQL API — menampilkan schema, dokumentasi, query builder, dan riwayat query.
**Analogi:** Seperti SQL Workbench untuk database — Anda bisa menulis query GraphQL, melihat schema yang tersedia (seperti melihat tabel), auto-completion (seperti SQL intellisense), dan melihat response langsung.
**Poin-Poin Penting:**
- `playground: true` atau `ApolloStudioPlugin`
- Schema exploration dan documentation
- Query auto-completion
- Query history dan tab management
- Headers management untuk auth
**Contoh Kode:**
```typescript
// app.module.ts — konfigurasi Playground
import { Module } from '@nestjs/common';
import { GraphQLModule } from '@nestjs/graphql';
import { ApolloDriver, ApolloDriverConfig } from '@nestjs/apollo';
import { ApolloServerPluginLandingPageLocalDefault } from '@apollo/server/plugin/landingPage/default';
import { ApolloServerPluginLandingPageProductionDefault } from '@apollo/server/plugin/landingPage/default';

@Module({
  imports: [
    GraphQLModule.forRoot<ApolloDriverConfig>({
      driver: ApolloDriver,
      autoSchemaFile: 'schema.gql',

      // DEVELOPMENT — Apollo Sandbox (modern playground)
      playground: false,  // Matikan built-in playground
      plugins: [
        // Sandbox untuk development — UI modern dengan auto-update
        ApolloServerPluginLandingPageLocalDefault({
          embed: true,                    // Embed mode (compact)
          variables: {
            endpoint: '/graphql',          // GraphQL endpoint
          },
          document: `# Selamat datang di GraphQL API
# Coba query berikut:
query {
  users {
    id
    name
    email
  }
}
`,
        }),
      ],
    }),
  ],
})
export class AppModule {}
```
```typescript
// app.module.ts — konfigurasi untuk environment berbeda
import { Module } from '@nestjs/common';
import { GraphQLModule } from '@nestjs/graphql';
import { ApolloDriver, ApolloDriverConfig } from '@nestjs/apollo';
import {
  ApolloServerPluginLandingPageLocalDefault,
  ApolloServerPluginLandingPageProductionDefault,
} from '@apollo/server/plugin/landingPage/default';

@Module({
  imports: [
    GraphQLModule.forRoot<ApolloDriverConfig>({
      driver: ApolloDriver,
      autoSchemaFile: 'schema.gql',

      // Environment-aware konfigurasi
      playground: process.env.NODE_ENV !== 'production',

      // Playground klasik (NestJS default)
      ...(process.env.NODE_ENV !== 'production' && {
        playground: {
          settings: {
            'editor.theme': 'dark',            // Dark mode
            'editor.cursorShape': 'line',       // Cursor style
            'editor.fontSize': 14,              // Font size
            'editor.reuseHeaders': true,        // Reuse headers
            'editor.validation': false,          // Disable validation
            'general.betaUpdates': false,
            'request.credentials': 'include',    // Include cookies
            'tracing.hideTracingResponse': true,
            'schema.polling.enable': true,       // Schema polling
            'schema.polling.interval': 2000,     // 2 detik
          },
        },
      }),

      // Production — landing page dengan link ke Apollo Studio
      ...(process.env.NODE_ENV === 'production' && {
        plugins: [
          ApolloServerPluginLandingPageProductionDefault({
            graphRef: 'myapp@current',           // Apollo Studio graph ref
            embed: true,
          }),
        ],
      }),
    }),
  ],
})
export class AppModule {}
```
```typescript
// main.ts — konfigurasi CORS dan global prefix
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // CORS untuk Playground
  app.enableCors({
    origin: [
      'http://localhost:3000',
      'https://studio.apollographql.com',  // Apollo Studio
      'https://sandbox.apollo.dev',         // Apollo Sandbox
    ],
    credentials: true,
  });

  // Global prefix — Playground tetap di /graphql
  app.setGlobalPrefix('api', {
    exclude: ['/graphql'],  // GraphQL endpoint tidak kena prefix
  });

  await app.listen(3000);
  console.log(`🚀 GraphQL endpoint: http://localhost:3000/graphql`);
  console.log(`🚀 Playground: http://localhost:3000/graphql`);
}
bootstrap();
```

**Kasus Penggunaan Nyata:** Tim frontend membuka `http://localhost:3000/graphql` di browser untuk mengeksplorasi schema GraphQL. Mereka bisa melihat semua query/mutation yang tersedia, tipe data, dokumentasi, dan menguji query dengan data real — tanpa perlu menulis kode atau membaca dokumentasi terpisah.
