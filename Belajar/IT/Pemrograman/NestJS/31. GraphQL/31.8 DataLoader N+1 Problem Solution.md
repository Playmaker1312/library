# 31. GraphQL
## 31.8 DataLoader N+1 Problem Solution
**Definisi Singkat:** N+1 problem terjadi ketika GraphQL resolver memanggil database secara terpisah untuk setiap item dalam array. DataLoader (`dataloader`) adalah library yang me-batch dan me-cache query untuk mencegah N+1.
**Analogi:** Seperti pergi ke perpustakaan — N+1 adalah meminta asisten mengambil satu buku dari rak, lalu kembali lagi untuk buku berikutnya, bolak-balik 100 kali. DataLoader seperti meminta semua buku sekaligus — beri daftar judul buku (batch), dan asisten mengambil semuanya dalam satu trip.
**Poin-Poin Penting:**
- `dataloader` npm package (bukan @nestjs)
- Batch function: menerima array keys, return array values
- Cache per request — buat instance baru tiap request
- Implementasi di `ResolveField` untuk relasi
**Contoh Kode:**
```typescript
// dataloader/user-loader.ts — DataLoader untuk User
import * as DataLoader from 'dataloader';
import { Injectable } from '@nestjs/common';
import { UsersService } from './users.service';

@Injectable()
export class UserLoader {
  constructor(private usersService: UsersService) {}

  // Batch function: terima array of IDs, return array of Users (sesuai urutan)
  createLoader() {
    return new DataLoader<number, any>(async (ids: number[]) => {
      // 1️⃣ Panggil database SEKALI untuk semua IDs
      const users = await this.usersService.findByIds(ids);

      // 2️⃣ Buat Map untuk akses cepat
      const userMap = new Map(users.map((user) => [user.id, user]));

      // 3️⃣ Kembalikan array sesuai urutan IDs input
      return ids.map((id) => userMap.get(id) || null);
    });
  }
}
```
```typescript
// dataloader/post-loader.ts — DataLoader untuk Post
import * as DataLoader from 'dataloader';
import { Injectable } from '@nestjs/common';
import { PostsService } from './posts.service';

@Injectable()
export class PostLoader {
  constructor(private postsService: PostsService) {}

  // Batch load posts by userId
  createPostsByUserLoader() {
    return new DataLoader<number, any[]>(async (userIds: number[]) => {
      const posts = await this.postsService.findByUserIds(userIds);

      // Group posts by userId
      const postsByUser = new Map<number, any[]>();
      userIds.forEach((id) => postsByUser.set(id, []));
      posts.forEach((post) => {
        postsByUser.get(post.authorId)?.push(post);
      });

      return userIds.map((id) => postsByUser.get(id) || []);
    });
  }
}
```

```typescript
// graphql.context.ts — inject DataLoader ke GraphQL context
import * as DataLoader from 'dataloader';
import { UserLoader } from './user-loader';
import { PostLoader } from './post-loader';

// Interface untuk GraphQL context
export interface GraphQLContext {
  userLoader: DataLoader<number, any>;
  postsByUserLoader: DataLoader<number, any[]>;
}

// Factory function — buat context per request
export function createGraphQLContext(userLoader: UserLoader, postLoader: PostLoader): GraphQLContext {
  return {
    // Buat instance DataLoader BARU setiap request
    userLoader: userLoader.createLoader(),
    postsByUserLoader: postLoader.createPostsByUserLoader(),
  };
}
```
```typescript
// app.module.ts — setup context factory
import { Module, Context } from '@nestjs/common';
import { GraphQLModule } from '@nestjs/graphql';
import { ApolloDriver, ApolloDriverConfig } from '@nestjs/apollo';
import { DataloaderModule } from './dataloader/dataloader.module';
import { UserLoader } from './dataloader/user-loader';
import { PostLoader } from './dataloader/post-loader';
import { createGraphQLContext } from './dataloader/graphql.context';

@Module({
  imports: [
    GraphQLModule.forRootAsync<ApolloDriverConfig>({
      driver: ApolloDriver,
      imports: [DataloaderModule],
      inject: [UserLoader, PostLoader],
      useFactory: (userLoader: UserLoader, postLoader: PostLoader) => ({
        autoSchemaFile: 'schema.gql',
        context: (): Promise<GraphQLContext> | GraphQLContext =>
          createGraphQLContext(userLoader, postLoader),
      }),
    }),
  ],
})
export class AppModule {}
```
```typescript
// users.resolver.ts — menggunakan DataLoader dari context
import { Resolver, ResolveField, Parent, Context } from '@nestjs/graphql';
import { User } from './entities/user.entity';
import { Post } from './entities/post.entity';
import { GraphQLContext } from './dataloader/graphql.context';

@Resolver(() => User)
export class UsersResolver {
  // Tanpa DataLoader — N+1 problem! 🚫
  // @ResolveField(() => [Post])
  // async posts(@Parent() user: User) {
  //   return this.postsService.findByUserId(user.id); // Dipanggil N kali!
  // }

  // DENGAN DataLoader — batch query ✅
  @ResolveField(() => [Post])
  async posts(
    @Parent() user: User,
    @Context() context: GraphQLContext,  // Akses context
  ): Promise<Post[]> {
    // DataLoader akan mengumpulkan semua userId
    // dan memanggil database SEKALI
    return context.postsByUserLoader.load(user.id);
  }
}
```
```typescript
// posts.resolver.ts — DataLoader di multiple resolvers
@Resolver(() => Post)
export class PostsResolver {
  @ResolveField(() => User)
  async author(
    @Parent() post: Post,
    @Context() context: GraphQLContext,
  ): Promise<User> {
    // Batch load user by post.authorId
    return context.userLoader.load(post.authorId);
  }
}
```
**Kasus Penggunaan Nyata:** Query `users { posts { author { name } } }` untuk 100 user. Tanpa DataLoader: 1 (get users) + 100 (get posts per user) + 100 (get author per post) = 201 queries. Dengan DataLoader: 1 (get users) + 1 (batch get posts) + 1 (batch get authors) = 3 queries. Dramatisasi performa.
