# 31. GraphQL
## 31.6 GraphQL Validation
**Definisi Singkat:** GraphQL validation di NestJS menggunakan `class-validator` decorators bersama `ValidationPipe` yang terintegrasi dengan GraphQL, memvalidasi input data sebelum diproses oleh resolver.
**Analogi:** Seperti satpam di pintu masuk mall — sebelum pengunjung (data) masuk ke dalam mall (resolver), satpam (validator) memeriksa apakah pengunjung memenuhi syarat (bawa masker, pakai baju, dll).
**Poin-Poin Penting:**
- `class-validator` decorators di InputType
- `ValidationPipe` global untuk GraphQL
- Custom error formatting di GraphQL
- `@UsePipes()` untuk pipe spesifik
**Contoh Kode:**
```typescript
// app.module.ts — setup ValidationPipe untuk GraphQL
import { Module, ValidationPipe } from '@nestjs/common';
import { GraphQLModule } from '@nestjs/graphql';
import { ApolloDriver, ApolloDriverConfig } from '@nestjs/apollo';
import { APP_PIPE } from '@nestjs/core';

@Module({
  imports: [
    GraphQLModule.forRoot<ApolloDriverConfig>({
      driver: ApolloDriver,
      autoSchemaFile: 'schema.gql',
      // Gunakan validation pipeline untuk GraphQL
      validationPipe: new ValidationPipe({
        whitelist: true,                    // Hapus field yang tidak didekorasi
        forbidNonWhitelisted: true,         // Tolak field yang tidak dikenal
        transform: true,                    // Transform input ke instance class
        transformOptions: {
          enableImplicitConversion: true,   // Konversi tipe otomatis
        },
        disableErrorMessages: process.env.NODE_ENV === 'production',
        exceptionFactory: (errors) => {
          // Format error untuk GraphQL
          const formattedErrors = errors.map((error) => ({
            field: error.property,
            constraints: error.constraints,
          }));
          return new Error(JSON.stringify(formattedErrors));
        },
      }),
    }),
  ],
  providers: [
    // Global validation pipe
    {
      provide: APP_PIPE,
      useFactory: () =>
        new ValidationPipe({
          whitelist: true,
          forbidNonWhitelisted: true,
          transform: true,
        }),
    },
  ],
})
export class AppModule {}
```
```typescript
// dto/create-user.input.ts — validasi lengkap
import { InputType, Field, Int, Float } from '@nestjs/graphql';
import {
  IsEmail,
  IsString,
  MinLength,
  MaxLength,
  IsOptional,
  IsEnum,
  IsInt,
  Min,
  Max,
  IsBoolean,
  Matches,
  IsArray,
  ArrayMinSize,
  ValidateNested,
  IsUrl,
} from 'class-validator';
import { Type } from 'class-transformer';
import { UserRole } from '../entities/user.entity';

@InputType()
class ProfileInput {
  @Field(() => String, { nullable: true })
  @IsOptional()
  @IsString()
  @MaxLength(500)
  bio?: string;

  @Field(() => String, { nullable: true })
  @IsOptional()
  @IsUrl()
  website?: string;
}

@InputType({ description: 'Input untuk registrasi pengguna baru' })
export class CreateUserInput {
  @Field(() => String)
  @IsString()
  @MinLength(3, { message: 'Nama minimal 3 karakter' })
  @MaxLength(100, { message: 'Nama maksimal 100 karakter' })
  name: string;

  @Field(() => String)
  @IsEmail({}, { message: 'Format email tidak valid' })
  email: string;

  @Field(() => String)
  @IsString()
  @MinLength(8, { message: 'Password minimal 8 karakter' })
  @MaxLength(50, { message: 'Password maksimal 50 karakter' })
  @Matches(/(?=.*[a-z])(?=.*[A-Z])(?=.*[0-9])/, {
    message: 'Password harus mengandung huruf besar, huruf kecil, dan angka',
  })
  password: string;

  @Field(() => UserRole)
  @IsEnum(UserRole, { message: 'Role harus ADMIN, USER, atau MODERATOR' })
  role: UserRole;

  @Field(() => Int, { nullable: true })
  @IsOptional()
  @IsInt()
  @Min(17, { message: 'Minimal umur 17 tahun' })
  @Max(120, { message: 'Umur tidak valid' })
  age?: number;

  @Field(() => Float, { nullable: true })
  @IsOptional()
  @Min(0)
  balance?: number;

  @Field(() => Boolean, { nullable: true })
  @IsOptional()
  @IsBoolean()
  isActive?: boolean;

  @Field(() => [String], { nullable: true })
  @IsOptional()
  @IsArray()
  @ArrayMinSize(1)
  @IsString({ each: true })
  interests?: string[];

  @Field(() => ProfileInput, { nullable: true })
  @IsOptional()
  @ValidateNested()
  @Type(() => ProfileInput)
  profile?: ProfileInput;
}
```

**Kasus Penggunaan Nyata:** API registrasi user. Validasi mencakup: email format benar, password cukup kuat (min 8 karakter, kombinasi huruf besar/kecil/angka), nama tidak kosong, umur minimal 17 tahun. Error validation dikembalikan dalam format GraphQL standar, dan frontend menampilkan pesan error di masing-masing field form.
