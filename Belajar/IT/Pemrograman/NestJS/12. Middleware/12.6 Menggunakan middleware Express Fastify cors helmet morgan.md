# 12. Middleware

## 12.6. Menggunakan middleware Express/Fastify (cors, helmet, morgan)

**Definisi Singkat:** NestJS dapat menggunakan middleware ekosistem Express/Fastify langsung seperti `cors`, `helmet`, dan `morgan`.

**Analogi:** Seperti colokan universal — laptop (NestJS) bisa pakai charger merek lain (Express middleware) asalkan colokannya cocok.

**Poin-Poin Penting:**
- NestJS default menggunakan Express (bisa switch ke Fastify)
- Middleware Express bisa langsung dipasang dengan `app.use()`
- `cors` — mengatur Cross-Origin Resource Sharing
- `helmet` — keamanan header HTTP
- `morgan` — HTTP request logger
- Install via npm lalu `app.use()`

**Contoh Kode:**
```bash
npm install cors helmet morgan
npm install @types/cors @types/morgan -D
```

```typescript
import { NestFactory } from '@nestjs/core';
import * as cors from 'cors';
import * as helmet from 'helmet';
import * as morgan from 'morgan';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // Express middleware langsung
  app.use(cors({ origin: 'https://frontend.com' }));
  app.use(helmet());
  app.use(morgan('combined'));

  // Atau pakai NestJS built-in
  // app.enableCors({ origin: 'https://frontend.com' });

  await app.listen(3000);
}
```

**Kasus Penggunaan Nyata:** Aplikasi NestJS di production menggunakan `helmet()` untuk proteksi header HTTP, `cors()` agar frontend di domain berbeda bisa akses API, dan `morgan('combined')` untuk logging request ke file log.
