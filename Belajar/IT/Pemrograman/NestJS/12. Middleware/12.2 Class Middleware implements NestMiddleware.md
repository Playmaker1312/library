# 12. Middleware

## 12.2. Class Middleware implements NestMiddleware

**Definisi Singkat:** Middleware berbasis class dengan implement `NestMiddleware` interface, bisa menggunakan Dependency Injection.

**Analogi:** Seperti petugas keamanan resmi — punya seragam (decorator), gaji (DI), dan wewenang resmi.

**Poin-Poin Penting:**
- Class `@Injectable()` implement `NestMiddleware`
- Method `use(req, res, next)` — tiga parameter
- Bisa inject service lain via constructor
- Cocok untuk middleware kompleks dengan dependencies
- Support async dengan `await next()`

**Contoh Kode:**
```typescript
import { Injectable, NestMiddleware } from '@nestjs/common';
import { Request, Response, NextFunction } from 'express';
import { AuthService } from './auth.service';

@Injectable()
export class AuthMiddleware implements NestMiddleware {
  constructor(private readonly authService: AuthService) {}

  async use(req: Request, res: Response, next: NextFunction) {
    const token = req.headers.authorization?.split(' ')[1];

    if (!token) {
      return res.status(401).json({ message: 'Token tidak ditemukan' });
    }

    try {
      const user = await this.authService.validateToken(token);
      (req as any).user = user;
      next();
    } catch (error) {
      return res.status(401).json({ message: 'Token tidak valid' });
    }
  }
}
```

**Kasus Penggunaan Nyata:** `AuthMiddleware` dengan inject `AuthService` memvalidasi JWT token di setiap request, lalu menyimpan data user ke `req.user` agar bisa diakses handler tanpa perlu validasi ulang.
