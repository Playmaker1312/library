# 258. Cara menggunakan decorator UseInterceptors dengan FilesInterceptor untuk multiple files

## Definisi & Target
`FilesInterceptor` menangani upload beberapa file sekaligus dari field form-data yang sama. File tersedia sebagai array di `@UploadedFiles()`.

## Komponen & Nest CLI Command
Tambahkan di controller yang sudah ada.

## Kode Implementasi (Per File)
// src/upload/upload.controller.ts
```typescript
import { Controller, Post, UseInterceptors, UploadedFiles } from '@nestjs/common';
import { FilesInterceptor } from '@nestjs/platform-express';

@Controller('upload')
export class UploadController {
  @Post('multiple')
  @UseInterceptors(FilesInterceptor('files', 5))
  uploadMultiple(@UploadedFiles() files: Array<Express.Multer.File>) {
    return files.map((file) => ({
      originalName: file.originalname,
      filename: file.filename,
      size: file.size,
      mimetype: file.mimetype,
    }));
  }
}
```

## Cara Integrasi & Pengujian
```bash
curl -X POST http://localhost:3000/upload/multiple \
  -F "files=@image1.jpg" \
  -F "files=@image2.jpg" \
  -F "files=@image3.jpg"
```

Parameter kedua `FilesInterceptor('files', 5)` adalah maxCount (maksimal 5 file). Response berupa array metadata setiap file.
