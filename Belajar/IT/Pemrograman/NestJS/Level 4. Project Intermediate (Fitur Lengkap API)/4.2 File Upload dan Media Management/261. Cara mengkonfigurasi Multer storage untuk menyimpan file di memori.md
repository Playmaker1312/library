# 261. Cara mengkonfigurasi Multer storage untuk menyimpan file di memori

## Definisi & Target
Memory storage menyimpan file sebagai buffer di memori, berguna saat akan diupload ke cloud storage (S3, Cloudinary) tanpa menyimpan ke disk lokal.

## Komponen & Nest CLI Command
Gunakan `multer.memoryStorage()`.

## Kode Implementasi (Per File)
// src/upload/upload.controller.ts
```typescript
import { Controller, Post, UseInterceptors, UploadedFile } from '@nestjs/common';
import { FileInterceptor } from '@nestjs/platform-express';
import { memoryStorage } from 'multer';

@Controller('upload')
export class UploadController {
  @Post('memory')
  @UseInterceptors(
    FileInterceptor('file', {
      storage: memoryStorage(),
    }),
  )
  uploadMemory(@UploadedFile() file: Express.Multer.File) {
    return {
      originalName: file.originalname,
      size: file.size,
      mimetype: file.mimetype,
      bufferLength: file.buffer.length,
    };
  }
}
```

## Cara Integrasi & Pengujian
File tersedia di `file.buffer` sebagai `Buffer`. Tidak ada file yang ditulis ke disk. Sangat cocok untuk di-stream langsung ke S3 atau Cloudinary. Perhatikan batas memori untuk file besar.
