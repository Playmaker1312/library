# 270. Cara mengimplementasikan file serving yang dilindungi autentikasi

## Definisi & Target
File serving yang dilindungi autentikasi: file hanya bisa diakses oleh user yang memiliki token valid. Berguna untuk konten privat seperti dokumen atau foto profil.

## Komponen & Nest CLI Command
```bash
nest g controller media --no-spec
```

## Kode Implementasi (Per File)
// src/media/media.controller.ts
```typescript
import { Controller, Get, Param, Res, UseGuards } from '@nestjs/common';
import { Response } from 'express';
import { AuthGuard } from '@nestjs/passport';
import { S3Service } from './s3.service';
import { PrismaService } from '../prisma/prisma.service';

@Controller('media')
export class MediaController {
  constructor(
    private readonly s3Service: S3Service,
    private readonly prisma: PrismaService,
  ) {}

  @Get('files/:id')
  @UseGuards(AuthGuard('jwt'))
  async serveFile(@Param('id') id: string, @Res() res: Response) {
    const file = await this.prisma.file.findUnique({ where: { id } });
    if (!file) return res.status(404).json({ message: 'File not found' });
    const { Body, ContentType } = await this.s3Service.download(file.key);
    res.setHeader('Content-Type', ContentType);
    (Body as any).pipe(res);
  }

  @Get('protected/:key')
  @UseGuards(AuthGuard('jwt'))
  async serveProtected(@Param('key') key: string, @Res() res: Response) {
    const signedUrl = await this.s3Service.getSignedUrl(key, 60);
    return res.redirect(signedUrl);
  }
}
```

// src/media/media.module.ts (tambahkan ServeStatic untuk file lokal)
```typescript
import { Module } from '@nestjs/common';
import { ServeStaticModule } from '@nestjs/serve-static';
import { join } from 'path';
import { MediaController } from './media.controller';
import { S3Service } from './s3.service';

@Module({
  imports: [
    ServeStaticModule.forRoot({
      rootPath: join(__dirname, '../../uploads'),
      serveRoot: '/uploads',
      exclude: ['/api/*'],
    }),
  ],
  controllers: [MediaController],
  providers: [S3Service],
})
export class MediaModule {}
```

## Cara Integrasi & Pengujian
Akses `GET /media/files/:id` dengan Bearer token. File lokal diakses via `GET /uploads/filename` (tanpa auth). Untuk file privat, gunakan guard JWT.
