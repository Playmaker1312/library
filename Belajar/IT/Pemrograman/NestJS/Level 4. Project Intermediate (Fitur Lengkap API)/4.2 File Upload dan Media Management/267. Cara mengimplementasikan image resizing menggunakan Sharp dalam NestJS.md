# 267. Cara mengimplementasikan image resizing menggunakan Sharp dalam NestJS

## Definisi & Target
Sharp adalah library high-performance untuk transformasi gambar: resize, format conversion, compression. Berguna untuk membuat thumbnail atau versi optimal.

## Komponen & Nest CLI Command
```bash
npm install sharp
```

## Kode Implementasi (Per File)
// src/media/image.service.ts
```typescript
import { Injectable } from '@nestjs/common';
import * as sharp from 'sharp';

@Injectable()
export class ImageService {
  async resize(buffer: Buffer, width: number, height: number): Promise<Buffer> {
    return sharp(buffer).resize(width, height, { fit: 'cover', position: 'center' }).toBuffer();
  }

  async createThumbnail(buffer: Buffer): Promise<Buffer> {
    return sharp(buffer).resize(150, 150, { fit: 'cover' }).jpeg({ quality: 80 }).toBuffer();
  }

  async convertToWebp(buffer: Buffer, quality = 80): Promise<Buffer> {
    return sharp(buffer).webp({ quality }).toBuffer();
  }

  async getMetadata(buffer: Buffer): Promise<sharp.Metadata> {
    return sharp(buffer).metadata();
  }
}
```

// src/upload/upload.controller.ts
```typescript
import { Controller, Post, UseInterceptors, UploadedFile } from '@nestjs/common';
import { FileInterceptor } from '@nestjs/platform-express';
import { ImageService } from '../media/image.service';
import { S3Service } from '../media/s3.service';

@Controller('upload')
export class UploadController {
  constructor(
    private readonly imageService: ImageService,
    private readonly s3Service: S3Service,
  ) {}

  @Post('with-thumbnail')
  @UseInterceptors(FileInterceptor('image'))
  async uploadWithThumbnail(@UploadedFile() file: Express.Multer.File) {
    const thumbnail = await this.imageService.createThumbnail(file.buffer);
    const webp = await this.imageService.convertToWebp(file.buffer);
    const mainUrl = await this.s3Service.upload(`images/${file.originalname}`, file.buffer, file.mimetype);
    const thumbUrl = await this.s3Service.upload(`thumbnails/${file.originalname}`, thumbnail, 'image/jpeg');
    const webpUrl = await this.s3Service.upload(`webp/${file.originalname}.webp`, webp, 'image/webp');
    return { mainUrl, thumbUrl, webpUrl };
  }
}
```

## Cara Integrasi & Pengujian
Sharp memproses buffer gambar. Buat thumbnail 150x150 dan konversi ke WebP untuk performa. Upload hasilnya ke S3 atau simpan di disk.
