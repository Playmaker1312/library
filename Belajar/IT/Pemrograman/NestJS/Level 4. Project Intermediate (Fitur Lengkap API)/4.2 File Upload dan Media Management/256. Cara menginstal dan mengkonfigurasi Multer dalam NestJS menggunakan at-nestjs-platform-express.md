# 256. Cara menginstal dan mengkonfigurasi Multer dalam NestJS menggunakan @nestjs/platform-express

## Definisi & Target
Multer adalah middleware Express untuk menangani `multipart/form-data`. NestJS sudah menyertakan Multer via `@nestjs/platform-express` secara default.

## Komponen & Nest CLI Command
```bash
npm install @nestjs/platform-express
npm install @types/multer --save-dev
```

Multer sudah terintegrasi di NestFactory:
```typescript
const app = await NestFactory.create(AppModule);
```
Tidak perlu konfigurasi tambahan untuk basic upload.

## Kode Implementasi (Per File)
// src/app.module.ts
```typescript
import { Module } from '@nestjs/common';
import { MulterModule } from '@nestjs/platform-express';

@Module({
  imports: [
    MulterModule.register({
      dest: './uploads',
    }),
  ],
})
export class AppModule {}
```

Konfigurasi global bisa juga melalui `Main.ts`:
```typescript
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.setGlobalPrefix('api');
  await app.listen(3000);
}
bootstrap();
```

## Cara Integrasi & Pengujian
File upload siap digunakan. Gunakan `FileInterceptor` atau `FilesInterceptor` di controller. File akan tersimpan di folder `./uploads` secara default.
