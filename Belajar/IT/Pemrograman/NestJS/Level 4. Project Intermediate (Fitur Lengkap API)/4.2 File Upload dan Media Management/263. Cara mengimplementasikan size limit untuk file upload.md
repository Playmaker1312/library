# 263. Cara mengimplementasikan size limit untuk file upload

## Definisi & Target
Size limit mencegah upload file terlalu besar yang bisa membebani server. Batas bisa diatur global di MulterModule atau per-endpoint.

## Komponen & Nest CLI Command
Gunakan properti `limits` di Interceptor atau `MaxFileSizeValidator`.

## Kode Implementasi (Per File)
// src/upload/upload.controller.ts (via interceptor)
```typescript
import { Controller, Post, UseInterceptors, UploadedFile } from '@nestjs/common';
import { FileInterceptor } from '@nestjs/platform-express';

@Controller('upload')
export class UploadController {
  @Post('limited')
  @UseInterceptors(
    FileInterceptor('file', {
      limits: {
        fileSize: 2 * 1024 * 1024,
      },
    }),
  )
  uploadLimited(@UploadedFile() file: Express.Multer.File) {
    return { filename: file.filename, size: file.size };
  }
}
```

// src/upload/upload.controller.ts (via ParseFilePipe)
```typescript
import { Controller, Post, UseInterceptors, UploadedFile, ParseFilePipe, MaxFileSizeValidator } from '@nestjs/common';
import { FileInterceptor } from '@nestjs/platform-express';

@Controller('upload')
export class UploadController {
  @Post('validated-size')
  @UseInterceptors(FileInterceptor('file'))
  uploadValidated(
    @UploadedFile(
      new ParseFilePipe({
        validators: [
          new MaxFileSizeValidator({ maxSize: 5 * 1024 * 1024 }),
        ],
      }),
    )
    file: Express.Multer.File,
  ) {
    return { filename: file.originalname, size: file.size };
  }
}
```

// src/main.ts (global limit)
```typescript
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.useBodyParser('json', { limit: '10mb' });
  await app.listen(3000);
}
```

## Cara Integrasi & Pengujian
Upload file > 2MB akan ditolak dengan error `File too large` (413). Atur `maxFileSize` sesuai kebutuhan aplikasi.
