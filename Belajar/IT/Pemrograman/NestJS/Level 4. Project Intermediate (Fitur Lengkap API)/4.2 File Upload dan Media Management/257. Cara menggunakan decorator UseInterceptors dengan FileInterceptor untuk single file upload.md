# 257. Cara menggunakan decorator UseInterceptors dengan FileInterceptor untuk single file upload

## Definisi & Target
`FileInterceptor` menangani upload satu file dari field form-data tertentu. File otomatis diekstrak dan tersedia di `@UploadedFile()`.

## Komponen & Nest CLI Command
```bash
nest g controller upload --no-spec
```

## Kode Implementasi (Per File)
// src/upload/upload.controller.ts
```typescript
import { Controller, Post, UseInterceptors, UploadedFile } from '@nestjs/common';
import { FileInterceptor } from '@nestjs/platform-express';

@Controller('upload')
export class UploadController {
  @Post('single')
  @UseInterceptors(FileInterceptor('file'))
  uploadSingle(@UploadedFile() file: Express.Multer.File) {
    return {
      originalName: file.originalname,
      filename: file.filename,
      size: file.size,
      mimetype: file.mimetype,
      path: file.path,
    };
  }
}
```

## Cara Integrasi & Pengujian
```bash
curl -X POST http://localhost:3000/upload/single \
  -F "file=@/path/to/image.jpg"
```

Response:
```json
{
  "originalName": "image.jpg",
  "filename": "d8f7a6b5c4e3f2a1b0c9d8e7.jpg",
  "size": 1024000,
  "mimetype": "image/jpeg",
  "path": "uploads/d8f7a6b5c4e3f2a1b0c9d8e7.jpg"
}
```
