# 260. Cara mengkonfigurasi Multer storage untuk menyimpan file ke disk

## Definisi & Target
Disk storage menyimpan file ke folder lokal dengan kontrol penuh atas nama file dan direktori tujuan.

## Komponen & Nest CLI Command
Gunakan `multer.diskStorage()` untuk konfigurasi.

## Kode Implementasi (Per File)
// src/upload/upload.controller.ts
```typescript
import { Controller, Post, UseInterceptors, UploadedFile } from '@nestjs/common';
import { FileInterceptor } from '@nestjs/platform-express';
import { diskStorage } from 'multer';
import { extname, join } from 'path';

@Controller('upload')
export class UploadController {
  @Post('disk')
  @UseInterceptors(
    FileInterceptor('file', {
      storage: diskStorage({
        destination: join(__dirname, '../../uploads'),
        filename: (req, file, callback) => {
          const uniqueName = `${Date.now()}-${Math.round(Math.random() * 1e9)}${extname(file.originalname)}`;
          callback(null, uniqueName);
        },
      }),
    }),
  )
  uploadDisk(@UploadedFile() file: Express.Multer.File) {
    return { url: `/uploads/${file.filename}` };
  }
}
```

## Cara Integrasi & Pengujian
File akan tersimpan di folder `uploads/` dengan nama unik berbasis timestamp. Pastikan folder `uploads/` sudah ada atau buat secara otomatis. File bisa diakses secara statis dengan konfigurasi `ServeStaticModule`.
