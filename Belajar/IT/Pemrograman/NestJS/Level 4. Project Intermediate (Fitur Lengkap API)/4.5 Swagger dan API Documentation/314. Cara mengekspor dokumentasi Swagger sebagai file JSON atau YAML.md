# 314. Cara mengekspor dokumentasi Swagger sebagai file JSON atau YAML

## Definisi & Target
Dokumentasi Swagger bisa diekspor sebagai file JSON atau YAML untuk digunakan oleh tools eksternal (Postman, code generator, CI/CD).

## Komponen & Nest CLI Command
Buat endpoint khusus untuk ekspor atau simpan ke file saat startup.

## Kode Implementasi (Per File)
// src/main.ts (simpan ke file saat startup)
```typescript
import { NestFactory } from '@nestjs/core';
import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger';
import { AppModule } from './app.module';
import * as fs from 'fs';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  const config = new DocumentBuilder()
    .setTitle('E-Commerce API')
    .setDescription('Full API documentation')
    .setVersion('1.0')
    .addBearerAuth()
    .build();

  const document = SwaggerModule.createDocument(app, config);

  fs.writeFileSync('./swagger.json', JSON.stringify(document, null, 2));
  console.log('Swagger JSON exported to swagger.json');

  SwaggerModule.setup('api/docs', app, document);

  await app.listen(3000);
}
bootstrap();
```

// src/common/controllers/docs.controller.ts (endpoint runtime)
```typescript
import { Controller, Get, Res } from '@nestjs/common';
import { ApiExcludeController } from '@nestjs/swagger';
import { Response } from 'express';
import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger';
import { AppModule } from '../../app.module';

@ApiExcludeController()
@Controller('docs')
export class DocsController {
  @Get('json')
  getSwaggerJson(@Res() res: Response) {
    const config = new DocumentBuilder().setTitle('API').setVersion('1.0').build();
    const document = SwaggerModule.createDocument(global.app, config);
    res.json(document);
  }

  @Get('yaml')
  getSwaggerYaml(@Res() res: Response) {
    const config = new DocumentBuilder().setTitle('API').setVersion('1.0').build();
    const document = SwaggerModule.createDocument(global.app, config);
    const yaml = require('js-yaml').dump(document, { indent: 2 });
    res.setHeader('Content-Type', 'text/yaml');
    res.send(yaml);
  }
}
```

## Cara Integrasi & Pengujian
```bash
# Akses langsung
GET http://localhost:3000/api/docs-json
GET http://localhost:3000/api/docs-yaml

# Atau gunakan endpoint /api/docs dan klik "Download" / "Export"
```
Gunakan `npm install js-yaml` jika perlu ekspor YAML.
