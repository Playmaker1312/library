# 315. Cara menggunakan Swagger UI untuk testing API secara interaktif

## Definisi & Target
Swagger UI menyediakan antarmuka web untuk mengeksplorasi dan menguji endpoint API secara langsung tanpa tools eksternal.

## Komponen & Nest CLI Command
```bash
npm install @nestjs/swagger
```

## Kode Implementasi (Per File)
// src/main.ts
```typescript
import { NestFactory } from '@nestjs/core';
import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  const config = new DocumentBuilder()
    .setTitle('E-Commerce API')
    .setDescription('Interactive API testing')
    .setVersion('1.0')
    .addBearerAuth({ type: 'http', scheme: 'bearer', bearerFormat: 'JWT' }, 'access-token')
    .build();

  const document = SwaggerModule.createDocument(app, config);

  SwaggerModule.setup('api', app, document, {
    swaggerOptions: {
      persistAuthorization: true,
      tryItOutEnabled: true,
      displayRequestDuration: true,
      filter: true,
      syntaxHighlight: { theme: 'monokai' },
    },
    customSiteTitle: 'E-Commerce API Docs',
    customfavIcon: 'https://nestjs.com/img/logo-small.svg',
    customCss: '.swagger-ui .topbar { display: none }',
  });

  await app.listen(3000);
  console.log(`Swagger UI: http://localhost:3000/api`);
}
bootstrap();
```

## Cara Integrasi & Pengujian
1. Buka `http://localhost:3000/api`
2. Klik "Authorize" -> masukkan token JWT -> Authorize
3. Buka section "Products" -> klik `GET /products` -> "Try it out" -> "Execute"
4. Response akan muncul lengkap dengan status code, headers, dan body

Fitur Swagger UI:
- `persistAuthorization`: token tetap tersimpan
- `tryItOutEnabled`: tombol Try it out aktif default
- `filter`: search endpoint
- `displayRequestDuration`: tampilkan waktu response
