# 301. Memahami kegunaan Swagger untuk dokumentasi API yang interaktif

## Definisi & Target
Swagger (OpenAPI) adalah standar dokumentasi API yang interaktif. NestJS menyediakan `@nestjs/swagger` untuk mendekorasi controller, DTO, dan entity secara otomatis menghasilkan dokumentasi.

## Komponen & Nest CLI Command
Swagger menyediakan:
- UI interaktif untuk testing endpoint (Swagger UI)
- Spesifikasi OpenAPI dalam format JSON/YAML
- Auto-generate dokumentasi dari dekorator TypeScript

Akses `http://localhost:3000/api` setelah konfigurasi. UI Swagger menampilkan semua endpoint, schema, dan response. Bisa testing langsung dari halaman tersebut.
