# 311. Cara menggunakan decorator `@ApiProperty` dan `@ApiPropertyOptional` pada DTO

## Definisi & Target
`@ApiProperty` mendokumentasikan properti DTO di Swagger. `@ApiPropertyOptional` untuk properti opsional. Menampilkan tipe, contoh, dan deskripsi.

## Komponen & Nest CLI Command
Gunakan di class DTO.

## Kode Implementasi (Per File)
// src/products/dto/create-product.dto.ts
```typescript
import { IsString, IsNumber, Min, IsOptional, IsArray, MinLength } from 'class-validator';
import { ApiProperty, ApiPropertyOptional } from '@nestjs/swagger';
import { Type } from 'class-transformer';

export class VariantDto {
  @ApiProperty({ example: 'Red / M', description: 'Variant name (size/color)' })
  @IsString()
  name: string;

  @ApiProperty({ example: 100000, description: 'Variant price' })
  @Type(() => Number)
  @IsNumber()
  @Min(0)
  price: number;

  @ApiProperty({ example: 50, description: 'Variant stock' })
  @Type(() => Number)
  @IsNumber()
  @Min(0)
  stock: number;

  @ApiProperty({ example: 'TS-RM-001', description: 'SKU code' })
  @IsString()
  sku: string;
}

export class CreateProductDto {
  @ApiProperty({ example: 'T-Shirt', description: 'Product name' })
  @IsString()
  @MinLength(3)
  name: string;

  @ApiProperty({ example: 't-shirt', description: 'URL slug' })
  @IsString()
  slug: string;

  @ApiPropertyOptional({ example: 'High quality cotton t-shirt', description: 'Product description' })
  @IsOptional()
  @IsString()
  description?: string;

  @ApiProperty({ example: 100000, description: 'Base price' })
  @Type(() => Number)
  @IsNumber()
  @Min(0)
  price: number;

  @ApiProperty({ example: 100, description: 'Stock quantity' })
  @Type(() => Number)
  @IsNumber()
  @Min(0)
  stock: number;

  @ApiPropertyOptional({ type: [VariantDto], description: 'Product variants' })
  @IsOptional()
  @IsArray()
  @Type(() => VariantDto)
  variantData?: VariantDto[];
}
```

## Cara Integrasi & Pengujian
Swagger UI menampilkan schema DTO dengan tipe data, contoh, dan deskripsi. `@ApiPropertyOptional` menandai field sebagai tidak wajib.
