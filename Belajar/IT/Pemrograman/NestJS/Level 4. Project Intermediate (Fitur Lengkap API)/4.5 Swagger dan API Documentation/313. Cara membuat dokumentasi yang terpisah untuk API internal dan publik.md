# 313. Cara membuat dokumentasi yang terpisah untuk API internal dan publik

## Definisi & Target
Memisahkan dokumentasi Swagger untuk API publik (customer) dan internal (admin). Masing-masing memiliki endpoint dan keamanan berbeda.

## Komponen & Nest CLI Command
Tidak ada CLI. Modifikasi `main.ts`.

## Kode Implementasi (Per File)
// src/main.ts
```typescript
import { NestFactory } from '@nestjs/core';
import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  const publicConfig = new DocumentBuilder()
    .setTitle('Public API')
    .setDescription('Endpoints for customer-facing application')
    .setVersion('1.0')
    .addBearerAuth({ type: 'http', scheme: 'bearer' }, 'access-token')
    .build();

  const publicDocument = SwaggerModule.createDocument(app, publicConfig, {
    include: [],
    deepScanRoutes: true,
    operationIdFactory: (controllerKey: string, methodKey: string) => `${controllerKey}_${methodKey}`,
  });

  SwaggerModule.setup('api/docs/public', app, publicDocument);

  const adminConfig = new DocumentBuilder()
    .setTitle('Admin API')
    .setDescription('Internal endpoints for admin dashboard')
    .setVersion('1.0')
    .addBearerAuth({ type: 'http', scheme: 'bearer' }, 'admin-token')
    .build();

  const adminDocument = SwaggerModule.createDocument(app, adminConfig);
  SwaggerModule.setup('api/docs/admin', app, adminDocument);

  await app.listen(3000);
}
bootstrap();
```

Pendekatan alternatif: gunakan `@ApiExcludeEndpoint()` untuk menyembunyikan endpoint dari dokumentasi tertentu.

## Cara Integrasi & Pengujian
Akses `http://localhost:3000/api/docs/public` dan `http://localhost:3000/api/docs/admin`. Masing-masing menampilkan endpoint yang relevan.
