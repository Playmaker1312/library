# 303. Cara mengkonfigurasi SwaggerModule dan DocumentBuilder di main.ts

## Definisi & Target
Konfigurasi Swagger dilakukan di `main.ts` menggunakan `SwaggerModule` dan `DocumentBuilder` untuk membuat dokumen OpenAPI.

## Komponen & Nest CLI Command
Tidak ada CLI command. Edit `main.ts`.

## Kode Implementasi (Per File)
// src/main.ts
```typescript
import { NestFactory } from '@nestjs/core';
import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger';
import { AppModule } from './app.module';
import { ValidationPipe } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.setGlobalPrefix('api');
  app.useGlobalPipes(new ValidationPipe({ transform: true, whitelist: true }));

  const config = new DocumentBuilder()
    .setTitle('E-Commerce API')
    .setDescription('API documentation for E-Commerce application')
    .setVersion('1.0')
    .addBearerAuth({ type: 'http', scheme: 'bearer', bearerFormat: 'JWT' }, 'access-token')
    .addTag('auth', 'Authentication endpoints')
    .addTag('users', 'User management')
    .addTag('products', 'Product catalog')
    .build();

  const document = SwaggerModule.createDocument(app, config);
  SwaggerModule.setup('api/docs', app, document, {
    swaggerOptions: { persistAuthorization: true },
  });

  await app.listen(3000);
}
bootstrap();
```

## Cara Integrasi & Pengujian
Jalankan aplikasi, buka `http://localhost:3000/api/docs`. Swagger UI menampilkan dokumentasi lengkap. Opsi `persistAuthorization: true` menjaga token tetap terisi.
