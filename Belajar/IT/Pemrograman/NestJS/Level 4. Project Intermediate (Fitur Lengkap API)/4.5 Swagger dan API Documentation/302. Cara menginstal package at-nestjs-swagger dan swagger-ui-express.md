# 302. Cara menginstal package @nestjs/swagger dan swagger-ui-express

## Definisi & Target
`@nestjs/swagger` menyediakan dekorator untuk dokumentasi. `swagger-ui-express` menampilkan UI interaktif. NestJS sekarang sudah menyertakan `@nestjs/swagger` yang mencakup UI.

## Komponen & Nest CLI Command
```bash
npm install @nestjs/swagger
```

Package `@nestjs/swagger` sudah termasuk:
- `SwaggerModule` dan `DocumentBuilder`
- Dekorator: `@ApiTags`, `@ApiOperation`, `@ApiResponse`, dll
- `SwaggerUI` terintegrasi

## Kode Implementasi (Per File)
// package.json (dependencies)
```json
{
  "dependencies": {
    "@nestjs/swagger": "^7.0.0",
    "@nestjs/common": "^10.0.0",
    "@nestjs/core": "^10.0.0"
  }
}
```

## Cara Integrasi & Pengujian
Setelah instalasi, konfigurasi Swagger di `main.ts`. Jangan lupa `npm install` ulang. Swagger siap digunakan di seluruh aplikasi.
