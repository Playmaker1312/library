# 293. Mengimplementasikan product search dengan full-text search

## Definisi & Target
Full-text search memungkinkan pencarian produk berdasarkan nama, deskripsi, dengan ranking relevansi. PostgreSQL memiliki built-in full-text search via Prisma.

## Komponen & Nest CLI Command
```bash
npm install @prisma/client
```

## Kode Implementasi (Per File)
// src/products/products.service.ts
```typescript
import { Injectable, NotFoundException } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service';
import { Prisma } from '@prisma/client';

@Injectable()
export class ProductsService {
  constructor(private readonly prisma: PrismaService) {}

  async search(query: string, page = 1, limit = 10) {
    const skip = (page - 1) * limit;

    const searchQuery: Prisma.ProductFindManyArgs = {
      where: {
        OR: [
          { name: { contains: query, mode: 'insensitive' } },
          { description: { contains: query, mode: 'insensitive' } },
        ],
      },
      orderBy: { createdAt: 'desc' },
      skip,
      take: limit,
      include: {
        variants: true,
        category: true,
        _count: { select: { reviews: true } },
      },
    };

    const [products, total] = await this.prisma.$transaction([
      this.prisma.product.findMany(searchQuery),
      this.prisma.product.count({ where: searchQuery.where }),
    ]);

    return {
      data: products,
      meta: { total, page, limit, totalPages: Math.ceil(total / limit) },
    };
  }

  async searchFullText(query: string) {
    return this.prisma.$queryRaw`
      SELECT *, ts_rank(to_tsvector('simple', name || ' ' || COALESCE(description, '')), plainto_tsquery('simple', ${query})) AS rank
      FROM "Product"
      WHERE to_tsvector('simple', name || ' ' || COALESCE(description, '')) @@ plainto_tsquery('simple', ${query})
      ORDER BY rank DESC
      LIMIT 20
    `;
  }
}
```

## Cara Integrasi & Pengujian
```bash
GET /products/search?q=baju+merah&page=1&limit=10
```

Untuk PostgreSQL full-text search, pastikan telah membuat index GIN di kolom name dan description.
