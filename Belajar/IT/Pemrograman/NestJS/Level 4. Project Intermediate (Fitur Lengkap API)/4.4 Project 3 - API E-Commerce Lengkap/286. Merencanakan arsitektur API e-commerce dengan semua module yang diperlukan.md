# 286. Merencanakan arsitektur API e-commerce dengan semua module yang diperlukan

## Definisi & Target
API e-commerce lengkap dengan modul: Auth, Users, Categories, Products, Cart, Orders, Reviews, Coupons. Setiap modul memiliki CRUD dan relasi database.

## Komponen & Nest CLI Command
```
nest g module auth && nest g module users && nest g module categories
nest g module products && nest g module cart && nest g module orders
nest g module reviews && nest g module coupons
```

```bash
npm install @nestjs/config @nestjs/jwt @nestjs/passport passport passport-jwt bcrypt
npm install @prisma/client prisma --save-dev
npm install class-validator class-transformer
```

## Kode Implementasi (Per File)
Arsitektur module:
```
src/
  prisma/           # PrismaService global
  auth/             # register, login, refresh
  users/            # profile, address book
  categories/       # nested categories
  products/         # CRUD, variants, search
  cart/             # add, remove, merge guest/user
  orders/           # create from cart, status flow
  reviews/          # rating & comments
  coupons/          # discount codes
  common/           # guards, decorators, filters
```

## Cara Integrasi & Pengujian
Semua module diimport di AppModule. Gunakan Prisma sebagai ORM. Proteksi endpoint dengan JwtAuthGuard. Role-based access untuk admin routes.
