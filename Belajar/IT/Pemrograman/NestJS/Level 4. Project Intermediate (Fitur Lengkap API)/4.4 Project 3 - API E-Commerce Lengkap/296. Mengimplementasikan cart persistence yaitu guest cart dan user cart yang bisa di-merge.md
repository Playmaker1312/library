# 296. Mengimplementasikan cart persistence yaitu guest cart dan user cart yang bisa di-merge

## Definisi & Target
Guest cart menyimpan keranjang untuk user yang belum login (via sessionId/deviceId). Saat login, guest cart di-merge ke user cart.

## Komponen & Nest CLI Command
Modifikasi CartService dengan field deviceId opsional.

## Kode Implementasi (Per File)
// prisma/schema.prisma (tambahkan model GuestCart)
```prisma
model GuestCart {
  id        String      @id @default(uuid())
  deviceId  String
  items     GuestCartItem[]
  createdAt DateTime    @default(now())
  updatedAt DateTime    @updatedAt
}

model GuestCartItem {
  id        String    @id @default(uuid())
  cartId    String
  cart      GuestCart @relation(fields: [cartId], references: [id])
  productId String
  quantity  Int       @default(1)
}
```

// src/cart/cart.service.ts (bagian merge cart)
```typescript
import { Injectable, NotFoundException } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service';

@Injectable()
export class CartService {
  constructor(private readonly prisma: PrismaService) {}

  async addGuestItem(deviceId: string, productId: string, quantity = 1) {
    let cart = await this.prisma.guestCart.findUnique({ where: { deviceId }, include: { items: true } });
    if (!cart) {
      cart = await this.prisma.guestCart.create({
        data: { deviceId },
        include: { items: true },
      });
    }
    const existing = cart.items.find((i) => i.productId === productId);
    if (existing) {
      return this.prisma.guestCartItem.update({
        where: { id: existing.id },
        data: { quantity: existing.quantity + quantity },
      });
    }
    return this.prisma.guestCartItem.create({
      data: { cartId: cart.id, productId, quantity },
    });
  }

  async mergeGuestCart(deviceId: string, userId: string) {
    const guestCart = await this.prisma.guestCart.findUnique({
      where: { deviceId },
      include: { items: true },
    });
    if (!guestCart || guestCart.items.length === 0) return;

    let userCart = await this.prisma.cart.findUnique({ where: { userId }, include: { items: true } });
    if (!userCart) {
      userCart = await this.prisma.cart.create({ data: { userId }, include: { items: true } });
    }

    for (const guestItem of guestCart.items) {
      const existingItem = userCart.items.find((i) => i.productId === guestItem.productId);
      if (existingItem) {
        await this.prisma.cartItem.update({
          where: { id: existingItem.id },
          data: { quantity: existingItem.quantity + guestItem.quantity },
        });
      } else {
        await this.prisma.cartItem.create({
          data: { cartId: userCart.id, productId: guestItem.productId, quantity: guestItem.quantity },
        });
      }
    }

    await this.prisma.guestCartItem.deleteMany({ where: { cartId: guestCart.id } });
    await this.prisma.guestCart.delete({ where: { id: guestCart.id } });

    return this.prisma.cart.findUnique({ where: { userId }, include: { items: { include: { product: true } } } });
  }
}
```

## Cara Integrasi & Pengujian
Guest: `POST /cart/guest/add` dengan header `x-device-id: abc123`. Setelah login: `POST /auth/merge-cart` dengan `x-device-id`.
