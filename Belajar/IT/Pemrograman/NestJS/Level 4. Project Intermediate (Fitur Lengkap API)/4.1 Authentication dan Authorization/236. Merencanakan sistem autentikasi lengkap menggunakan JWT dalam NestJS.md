# 236. Merencanakan sistem autentikasi lengkap menggunakan JWT dalam NestJS

## Definisi & Target
Sistem autentikasi JWT memungkinkan user login, mendapat access token (short-lived), dan refresh token (long-lived). Alur: Register -> Login -> Dapat JWT -> Sertakan JWT di header Authorization untuk akses protected route -> Refresh token saat access token expired.

## Komponen & Nest CLI Command
```
nest g module auth
nest g service auth
nest g controller auth
nest g module users
nest g service users
```

Dependencies:
- `@nestjs/jwt`, `@nestjs/passport`, `passport`, `passport-jwt`, `passport-local`
- `bcrypt`, `@types/bcrypt`
- Prisma/TypeORM untuk database user & refresh token

## Kode Implementasi (Per File)
Tidak ada implementasi detail di file ini. Fokus pada perencanaan arsitektur:
- AuthModule sebagai module pusat autentikasi
- JwtModule dikonfigurasi via registerAsync
- LocalStrategy untuk validasi email/password
- JwtStrategy untuk validasi access token
- JwtRefreshStrategy untuk validasi refresh token
- AuthService menangani register, login, refresh token, logout
- AuthController menyediakan endpoint REST

## Cara Integrasi & Pengujian
Module ini menjadi fondasi untuk seluruh fitur yang membutuhkan proteksi akses. Semua modul lain akan menggunakannya melalui JwtAuthGuard.
