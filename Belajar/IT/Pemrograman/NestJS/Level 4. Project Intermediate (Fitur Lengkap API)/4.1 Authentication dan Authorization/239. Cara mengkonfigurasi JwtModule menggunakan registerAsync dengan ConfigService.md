# 239. Cara mengkonfigurasi JwtModule menggunakan registerAsync dengan ConfigService

## Definisi & Target
`registerAsync` memungkinkan konfigurasi JwtModule dari environment variables via ConfigService. Ini menghindari hardcoded secret dan membuat konfigurasi lebih fleksibel.

## Komponen & Nest CLI Command
```bash
npm install @nestjs/config
```

## Kode Implementasi (Per File)
// src/auth/auth.module.ts
```typescript
import { Module } from '@nestjs/common';
import { JwtModule } from '@nestjs/jwt';
import { PassportModule } from '@nestjs/passport';
import { ConfigModule, ConfigService } from '@nestjs/config';

@Module({
  imports: [
    PassportModule.register({ defaultStrategy: 'jwt' }),
    JwtModule.registerAsync({
      imports: [ConfigModule],
      inject: [ConfigService],
      useFactory: async (configService: ConfigService) => ({
        secret: configService.get<string>('JWT_SECRET'),
        signOptions: {
          expiresIn: configService.get<string>('JWT_EXPIRES_IN') || '15m',
        },
      }),
    }),
  ],
})
export class AuthModule {}
```

## Cara Integrasi & Pengujian
Pastikan `.env` memiliki `JWT_SECRET=your-secret-key` dan `JWT_EXPIRES_IN=15m`. ConfigModule harus diimpor di AppModule atau module yang relevan. JwtService yang dihasilkan akan menggunakan konfigurasi dari environment.
