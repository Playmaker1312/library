# 238. Cara menginstal package jsonwebtoken dan NestJS JWT module

## Definisi & Target
`@nestjs/jwt` adalah wrapper NestJS untuk library `jsonwebtoken`. Memudahkan pembuatan dan verifikasi token JWT dengan konfigurasi terpusat.

## Komponen & Nest CLI Command
```bash
npm install @nestjs/jwt jsonwebtoken
npm install @types/jsonwebtoken --save-dev
```

Fitur `@nestjs/jwt`:
- `JwtModule` dan `JwtService`
- Sign token dengan payload
- Verify token
- Konfigurasi secret, expiry, issuer

## Kode Implementasi (Per File)
// src/auth/auth.module.ts
```typescript
import { Module } from '@nestjs/common';
import { JwtModule } from '@nestjs/jwt';
import { PassportModule } from '@nestjs/passport';

@Module({
  imports: [
    PassportModule,
    JwtModule.register({
      secret: process.env.JWT_SECRET || 'fallback-secret',
      signOptions: { expiresIn: '15m' },
    }),
  ],
})
export class AuthModule {}
```

## Cara Integrasi & Pengujian
Gunakan `JwtService` di dalam AuthService untuk sign token: `this.jwtService.sign(payload)`. Untuk verifikasi: `this.jwtService.verify(token)`. Konfigurasi secret dan expiry bisa diatur di `register()` atau `registerAsync()`.
