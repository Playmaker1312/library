# 243. Cara membuat LocalStrategy menggunakan passport-local untuk login dengan email dan password

## Definisi & Target
LocalStrategy menangani autentikasi berbasis email dan password. Strategy ini dipanggil secara otomatis oleh Passport saat route menggunakan `@AuthGuard('local')`.

## Komponen & Nest CLI Command
```bash
npm install passport-local
npm install @types/passport-local --save-dev
```

## Kode Implementasi (Per File)
// src/auth/strategies/local.strategy.ts
```typescript
import { Injectable, UnauthorizedException } from '@nestjs/common';
import { PassportStrategy } from '@nestjs/passport';
import { Strategy } from 'passport-local';
import { AuthService } from '../auth.service';

@Injectable()
export class LocalStrategy extends PassportStrategy(Strategy) {
  constructor(private readonly authService: AuthService) {
    super({ usernameField: 'email' });
  }

  async validate(email: string, password: string): Promise<any> {
    const user = await this.authService.validateUser(email, password);
    if (!user) {
      throw new UnauthorizedException('Invalid email or password');
    }
    return user;
  }
}
```

## Cara Integrasi & Pengujian
Daftarkan LocalStrategy di providers AuthModule. Gunakan `@UseGuards(AuthGuard('local'))` di controller. Setting `usernameField: 'email'` memberitahu Passport untuk membaca field email, bukan username default.
