# 237. Cara menginstal package Passport dan NestJS Passport adapter

## Definisi & Target
Passport adalah middleware autentikasi untuk Node.js. `@nestjs/passport` adalah adapter resmi yang mengintegrasikan Passport ke dalam NestJS dengan dekorator dan guard.

## Komponen & Nest CLI Command
```bash
npm install @nestjs/passport passport
npm install @types/passport --save-dev
```

Package yang diinstal:
- `passport`: library autentikasi Express
- `@nestjs/passport`: adapter NestJS yang menyediakan `AuthGuard`, dekorator `@AuthGuard()`, dan integrasi strategi

## Kode Implementasi (Per File)
// src/auth/strategies/jwt.strategy.ts
```typescript
import { Injectable } from '@nestjs/common';
import { PassportStrategy } from '@nestjs/passport';
import { ExtractJwt, Strategy } from 'passport-jwt';

@Injectable()
export class JwtStrategy extends PassportStrategy(Strategy) {
  constructor() {
    super({
      jwtFromRequest: ExtractJwt.fromAuthHeaderAsBearerToken(),
      ignoreExpiration: false,
      secretOrKey: process.env.JWT_SECRET,
    });
  }

  async validate(payload: any) {
    return { userId: payload.sub, email: payload.email, role: payload.role };
  }
}
```

## Cara Integrasi & Pengujian
Setelah instalasi, daftarkan strategi di AuthModule menggunakan `providers`. Guard `@AuthGuard('jwt')` akan otomatis menggunakan JwtStrategy yang sudah terdaftar.
