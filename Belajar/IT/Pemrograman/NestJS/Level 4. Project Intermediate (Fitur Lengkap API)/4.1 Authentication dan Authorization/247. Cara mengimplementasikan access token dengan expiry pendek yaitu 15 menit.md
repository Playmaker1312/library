# 247. Cara mengimplementasikan access token dengan expiry pendek yaitu 15 menit

## Definisi & Target
Access token memiliki masa berlaku pendek (15 menit) untuk meminimalkan risiko jika token bocor. NestJS JWT module mengatur expiry ini via `signOptions`.

## Komponen & Nest CLI Command
Konfigurasi di JwtModule.registerAsync atau saat memanggil jwtService.sign().

## Kode Implementasi (Per File)
// src/auth/auth.module.ts (bagian konfigurasi JWT)
```typescript
import { Module } from '@nestjs/common';
import { JwtModule } from '@nestjs/jwt';
import { ConfigModule, ConfigService } from '@nestjs/config';

@Module({
  imports: [
    JwtModule.registerAsync({
      imports: [ConfigModule],
      inject: [ConfigService],
      useFactory: (config: ConfigService) => ({
        secret: config.get('JWT_SECRET'),
        signOptions: {
          expiresIn: config.get('JWT_ACCESS_EXPIRY') || '15m',
        },
      }),
    }),
  ],
})
export class AuthModule {}
```

Atau override per token di service:
```typescript
const accessToken = this.jwtService.sign(payload, { expiresIn: '15m' });
```

## Cara Integrasi & Pengujian
Setelah 15 menit, access token akan ditolak dengan error 401. Client harus menggunakan refresh token untuk mendapat access token baru. Atur `JWT_ACCESS_EXPIRY` di `.env`.
