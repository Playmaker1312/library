# 252. Cara mengimplementasikan decorator Public untuk route yang tidak perlu autentikasi

## Definisi & Target
Decorator `@Public()` menandai route tertentu agar tidak melewati autentikasi, berguna saat global guard dipasang di controller atau module.

## Komponen & Nest CLI Command
```bash
nest g decorator auth/decorators/public --no-spec --flat
```

## Kode Implementasi (Per File)
// src/auth/decorators/public.decorator.ts
```typescript
import { SetMetadata } from '@nestjs/common';

export const IS_PUBLIC_KEY = 'isPublic';
export const Public = () => SetMetadata(IS_PUBLIC_KEY, true);
```

// src/auth/guards/jwt-auth.guard.ts
```typescript
import { Injectable, ExecutionContext, UnauthorizedException } from '@nestjs/common';
import { AuthGuard } from '@nestjs/passport';
import { Reflector } from '@nestjs/core';
import { IS_PUBLIC_KEY } from '../decorators/public.decorator';

@Injectable()
export class JwtAuthGuard extends AuthGuard('jwt') {
  constructor(private readonly reflector: Reflector) {
    super();
  }

  canActivate(context: ExecutionContext): boolean | Promise<boolean> {
    const isPublic = this.reflector.getAllAndOverride<boolean>(IS_PUBLIC_KEY, [
      context.getHandler(),
      context.getClass(),
    ]);

    if (isPublic) return true;
    return super.canActivate(context);
  }
}
```

## Cara Integrasi & Pengujian
Pasang `JwtAuthGuard` secara global di AppModule:
```typescript
providers: [{ provide: APP_GUARD, useClass: JwtAuthGuard }]
```
Lalu gunakan `@Public()` di endpoint yang tidak perlu auth:
```typescript
@Public()
@Get('public-endpoint')
someMethod() { return 'open to all'; }
```
