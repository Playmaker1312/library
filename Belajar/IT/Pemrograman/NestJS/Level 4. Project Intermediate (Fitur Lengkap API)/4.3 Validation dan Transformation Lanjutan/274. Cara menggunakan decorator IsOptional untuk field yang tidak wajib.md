# 274. Cara menggunakan decorator `@IsOptional` untuk field yang tidak wajib

## Definisi & Target
`@IsOptional` menandai field sebagai opsional. Validasi lain hanya dijalankan jika nilai disertakan (tidak null/undefined).

## Komponen & Nest CLI Command
Tambahkan di DTO untuk field optional.

## Kode Implementasi (Per File)
// src/users/dto/update-user.dto.ts
```typescript
import { IsString, IsEmail, IsOptional, MinLength, IsUrl, IsEnum } from 'class-validator';
import { Gender } from '../../common/enums/gender.enum';

export class UpdateUserDto {
  @IsOptional()
  @IsString()
  @MinLength(2)
  name?: string;

  @IsOptional()
  @IsEmail()
  email?: string;

  @IsOptional()
  @IsString()
  @MinLength(8)
  password?: string;

  @IsOptional()
  @IsEnum(Gender)
  gender?: Gender;

  @IsOptional()
  @IsUrl()
  avatarUrl?: string;

  @IsOptional()
  @IsString()
  bio?: string;
}
```

## Cara Integrasi & Pengujian
```bash
PATCH /users/profile {"name": "John", "bio": "Hello!"}
```

Field yang tidak disertakan tidak akan divalidasi. `@IsOptional` mencegah error saat field tidak ada di request. Gunakan untuk PATCH endpoint (partial update).
