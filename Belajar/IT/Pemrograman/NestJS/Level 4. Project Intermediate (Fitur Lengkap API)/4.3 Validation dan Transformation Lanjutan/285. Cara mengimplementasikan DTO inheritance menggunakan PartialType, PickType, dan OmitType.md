# 285. Cara mengimplementasikan DTO inheritance menggunakan `PartialType`, `PickType`, dan `OmitType`

## Definisi & Target
`@nestjs/swagger` / `@nestjs/mapped-types` menyediakan utility type untuk membuat DTO turunan: `PartialType` (semua opsional), `PickType` (pilih field), `OmitType` (hapus field), `IntersectionType` (gabung).

## Komponen & Nest CLI Command
```bash
npm install @nestjs/mapped-types
```

## Kode Implementasi (Per File)
// src/users/dto/create-user.dto.ts
```typescript
import { IsEmail, IsString, MinLength, IsOptional, IsEnum } from 'class-validator';
import { Role } from '../../common/enums/role.enum';

export class CreateUserDto {
  @IsEmail()
  email: string;

  @IsString()
  @MinLength(8)
  password: string;

  @IsString()
  name: string;

  @IsOptional()
  @IsEnum(Role)
  role?: Role;
}
```

// src/users/dto/update-user.dto.ts
```typescript
import { PartialType } from '@nestjs/mapped-types';
import { CreateUserDto } from './create-user.dto';

export class UpdateUserDto extends PartialType(CreateUserDto) {}
```

// src/users/dto/login-user.dto.ts
```typescript
import { PickType } from '@nestjs/mapped-types';
import { CreateUserDto } from './create-user.dto';

export class LoginUserDto extends PickType(CreateUserDto, ['email', 'password'] as const) {}
```

// src/users/dto/user-response.dto.ts
```typescript
import { OmitType } from '@nestjs/mapped-types';
import { CreateUserDto } from './create-user.dto';

export class UserResponseDto extends OmitType(CreateUserDto, ['password'] as const) {}
```

// src/users/dto/filter-user.dto.ts
```typescript
import { PartialType, PickType } from '@nestjs/mapped-types';
import { CreateUserDto } from './create-user.dto';

export class FilterUserDto extends PartialType(
  PickType(CreateUserDto, ['email', 'name', 'role'] as const),
) {}
```

## Cara Integrasi & Pengujian
`UpdateUserDto` otomatis memiliki semua field opsional. `LoginUserDto` hanya email+password. `UserResponseDto` semua field kecuali password. Hindari duplikasi kode DTO.
