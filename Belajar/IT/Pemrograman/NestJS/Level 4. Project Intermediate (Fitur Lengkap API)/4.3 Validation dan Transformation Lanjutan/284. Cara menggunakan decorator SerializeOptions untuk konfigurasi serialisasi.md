# 284. Cara menggunakan decorator `@SerializeOptions` untuk konfigurasi serialisasi

## Definisi & Target
`@SerializeOptions` mengatur opsi global class-transformer seperti strategy exclusion, version, groups, dan enableCircularCheck.

## Komponen & Nest CLI Command
```bash
npm install class-transformer
```

## Kode Implementasi (Per File)
// src/users/entities/user.entity.ts
```typescript
import { Exclude, Expose, Transform } from 'class-transformer';

export class UserEntity {
  id: string;
  email: string;
  name: string;

  @Exclude({ toPlainOnly: true })
  password: string;

  @Expose({ groups: ['admin'] })
  role: string;

  @Expose({ groups: ['admin', 'internal'] })
  lastLoginAt: Date;

  @Expose({ name: 'joinedAt' })
  createdAt: Date;

  @Expose({ groups: ['detail'] })
  bio: string;

  constructor(partial: Partial<UserEntity>) {
    Object.assign(this, partial);
  }
}
```

// src/users/users.controller.ts
```typescript
import { Controller, Get, SerializeOptions, Req, UseGuards } from '@nestjs/common';
import { AuthGuard } from '@nestjs/passport';
import { UsersService } from './users.service';
import { UserEntity } from './entities/user.entity';
import { Serialize } from '../common/decorators/serialize.decorator';

@Controller('users')
@Serialize(UserEntity)
export class UsersController {
  constructor(private readonly usersService: UsersService) {}

  @UseGuards(AuthGuard('jwt'))
  @Get('profile')
  @SerializeOptions({ groups: ['detail'], strategy: 'excludeAll' })
  async getProfile(@Req() req: any) {
    return this.usersService.findById(req.user.id);
  }

  @UseGuards(AuthGuard('jwt'))
  @Get('admin')
  @SerializeOptions({ groups: ['admin'], version: 2 })
  async getAdminData(@Req() req: any) {
    return this.usersService.findById(req.user.id);
  }
}
```

## Cara Integrasi & Pengujian
Opsi `groups` memfilter properti berdasarkan group. `strategy: 'excludeAll'` mengecualikan semua kecuali yang di-`@Expose()`. `version` untuk API versioning.
