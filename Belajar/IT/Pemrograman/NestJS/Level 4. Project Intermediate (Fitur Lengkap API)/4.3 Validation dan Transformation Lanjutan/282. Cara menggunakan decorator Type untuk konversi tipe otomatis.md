# 282. Cara menggunakan decorator `@Type` untuk konversi tipe otomatis

## Definisi & Target
`@Type(() => TypeClass)` dari class-transformer mengonversi plain object ke instance kelas yang benar. Penting untuk nested object dan deserialisasi tipe primitif.

## Komponen & Nest CLI Command
```bash
npm install class-transformer
```

## Kode Implementasi (Per File)
// src/orders/dto/create-order.dto.ts
```typescript
import { IsArray, ValidateNested, ArrayMinSize, IsNumber, Min, IsString, IsDateString } from 'class-validator';
import { Type } from 'class-transformer';

export class OrderItemDto {
  @IsString()
  productId: string;

  @Type(() => Number)
  @IsNumber()
  @Min(1)
  quantity: number;

  @Type(() => Number)
  @IsNumber()
  @Min(0)
  price: number;
}

export class CreateOrderDto {
  @Type(() => OrderItemDto)
  @IsArray()
  @ArrayMinSize(1)
  @ValidateNested({ each: true })
  items: OrderItemDto[];

  @IsDateString()
  orderDate: string;
}
```

// src/payments/dto/create-payment.dto.ts
```typescript
import { IsNumber, Min, IsEnum, IsString } from 'class-validator';
import { Type } from 'class-transformer';

export enum PaymentMethod {
  CC = 'credit_card',
  VA = 'virtual_account',
}

export class CreatePaymentDto {
  @IsEnum(PaymentMethod)
  method: PaymentMethod;

  @Type(() => Number)
  @IsNumber()
  @Min(1000)
  amount: number;
}
```

## Cara Integrasi & Pengujian
Tanpa `@Type(() => Number)`, properti `quantity` dari form-data akan tetap string. Dengan `@Type`, otomatis dikonversi ke number sebelum validasi.
