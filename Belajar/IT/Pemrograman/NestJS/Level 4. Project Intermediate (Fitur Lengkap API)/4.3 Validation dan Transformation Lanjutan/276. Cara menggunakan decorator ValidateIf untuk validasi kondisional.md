# 276. Cara menggunakan decorator `@ValidateIf` untuk validasi kondisional

## Definisi & Target
`@ValidateIf` menjalankan validasi hanya jika kondisi tertentu terpenuhi. Berguna untuk validasi bergantung pada nilai field lain.

## Komponen & Nest CLI Command
Tambahkan di DTO dengan conditional validation.

## Kode Implementasi (Per File)
// src/payments/dto/create-payment.dto.ts
```typescript
import { IsString, IsEnum, IsNumber, IsOptional, ValidateIf, Min } from 'class-validator';

export enum PaymentMethod {
  CREDIT_CARD = 'credit_card',
  BANK_TRANSFER = 'bank_transfer',
  E_WALLET = 'e_wallet',
}

export class CreatePaymentDto {
  @IsEnum(PaymentMethod)
  method: PaymentMethod;

  @IsNumber()
  @Min(0)
  amount: number;

  @ValidateIf((o) => o.method === PaymentMethod.CREDIT_CARD)
  @IsString()
  cardNumber?: string;

  @ValidateIf((o) => o.method === PaymentMethod.CREDIT_CARD)
  @IsString()
  cardHolder?: string;

  @ValidateIf((o) => o.method === PaymentMethod.BANK_TRANSFER)
  @IsString()
  bankName?: string;

  @ValidateIf((o) => o.method === PaymentMethod.BANK_TRANSFER)
  @IsString()
  accountNumber?: string;

  @IsOptional()
  @IsString()
  notes?: string;
}
```

## Cara Integrasi & Pengujian
```bash
POST /payments {
  "method": "credit_card",
  "amount": 100000,
  "cardNumber": "4111111111111111",
  "cardHolder": "John Doe"
}
```

Jika method `bank_transfer`, validasi membutuhkan `bankName` dan `accountNumber`. Field yang tidak sesuai kondisi tidak divalidasi.
