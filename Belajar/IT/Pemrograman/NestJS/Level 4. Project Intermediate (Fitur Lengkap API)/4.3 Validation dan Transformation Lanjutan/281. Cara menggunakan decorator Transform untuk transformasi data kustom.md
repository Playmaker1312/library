# 281. Cara menggunakan decorator `@Transform` untuk transformasi data kustom

## Definisi & Target
`@Transform` dari class-transformer memodifikasi nilai properti selama serialisasi/deserialisasi. Berguna untuk format tanggal, uppercase, parsing, dll.

## Komponen & Nest CLI Command
```bash
npm install class-transformer
```

## Kode Implementasi (Per File)
// src/products/dto/create-product.dto.ts
```typescript
import { IsString, IsNumber, Min, IsArray, IsOptional } from 'class-validator';
import { Transform, Type } from 'class-transformer';

export class CreateProductDto {
  @IsString()
  @Transform(({ value }) => value.trim().toLowerCase())
  name: string;

  @Transform(({ value }) => parseFloat(value))
  @IsNumber()
  @Min(0)
  price: number;

  @IsOptional()
  @Transform(({ value }) => value?.toUpperCase())
  sku?: string;

  @IsOptional()
  @IsArray()
  @Transform(({ value }) => (typeof value === 'string' ? value.split(',') : value))
  tags?: string[];

  @IsOptional()
  @Transform(({ value }) => new Date(value), { toClassOnly: true })
  launchDate?: Date;
}
```

// src/products/entities/product.entity.ts
```typescript
import { Expose, Transform } from 'class-transformer';

export class ProductEntity {
  id: string;
  name: string;
  price: number;

  @Expose()
  @Transform(({ value }) => `Rp ${value.toLocaleString('id-ID')}`)
  get formattedPrice(): number {
    return this.price;
  }

  constructor(partial: Partial<ProductEntity>) {
    Object.assign(this, partial);
  }
}
```

## Cara Integrasi & Pengujian
`name` otomatis di-trim dan lowercase. `price` dikonversi dari string ke number. `tags` bisa dikirim sebagai string `"a,b,c"` dan diubah ke array.
