# 280. Cara menggunakan decorator `@Expose` dan `@Exclude` dari class-transformer

## Definisi & Target
`@Exclude` menyembunyikan properti dari output serialisasi (misal: password). `@Expose` memaksa properti untuk tetap ditampilkan atau menambahkan properti virtual.

## Komponen & Nest CLI Command
```bash
npm install class-transformer
```

## Kode Implementasi (Per File)
// src/users/entities/user.entity.ts
```typescript
import { Exclude, Expose, Transform } from 'class-transformer';

export class UserEntity {
  id: string;
  email: string;
  name: string;

  @Exclude()
  password: string;

  @Exclude()
  refreshToken: string;

  @Expose()
  get fullName(): string {
    return `${this.name}`;
  }

  @Expose({ name: 'createdAt' })
  @Transform(({ value }) => value?.toISOString())
  createdAt: Date;

  constructor(partial: Partial<UserEntity>) {
    Object.assign(this, partial);
  }
}
```

// src/users/users.controller.ts
```typescript
import { Controller, Get, UseGuards, Req } from '@nestjs/common';
import { AuthGuard } from '@nestjs/passport';
import { UsersService } from './users.service';
import { UserEntity } from './entities/user.entity';

@Controller('users')
export class UsersController {
  constructor(private readonly usersService: UsersService) {}

  @UseGuards(AuthGuard('jwt'))
  @Get('profile')
  async getProfile(@Req() req: any) {
    const user = await this.usersService.findById(req.user.id);
    return new UserEntity(user);
  }
}
```

## Cara Integrasi & Pengujian
Response `GET /users/profile` tidak akan menyertakan `password` dan `refreshToken`. Properti `fullName` akan muncul sebagai field tambahan.
