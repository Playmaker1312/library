# 273. Cara menggunakan decorator `@IsArray` dan `@ArrayMinSize` untuk validasi array

## Definisi & Target
`@IsArray` memvalidasi bahwa nilai adalah array. `@ArrayMinSize` / `@ArrayMaxSize` memvalidasi panjang array.

## Komponen & Nest CLI Command
Tambahkan di DTO dengan field array.

## Kode Implementasi (Per File)
// src/products/dto/create-product.dto.ts
```typescript
import { IsString, IsNumber, IsArray, ArrayMinSize, ArrayMaxSize, IsUrl, ValidateNested, Min } from 'class-validator';
import { Type } from 'class-transformer';

export class CreateProductDto {
  @IsString()
  name: string;

  @IsNumber()
  @Min(0)
  price: number;

  @IsArray()
  @ArrayMinSize(1, { message: 'At least one image is required' })
  @ArrayMaxSize(10)
  @IsUrl({}, { each: true })
  images: string[];

  @IsArray()
  @ArrayMinSize(1)
  @ValidateNested({ each: true })
  @Type(() => VariantDto)
  variants: VariantDto[];
}

export class VariantDto {
  @IsString()
  name: string;

  @IsNumber()
  @Min(0)
  price: number;
}
```

## Cara Integrasi & Pengujian
```bash
POST /products {
  "name": "T-Shirt",
  "price": 100000,
  "images": ["https://example.com/img1.jpg"],
  "variants": [{"name": "Red", "price": 100000}]
}
```

Array kosong akan ditolak. Jumlah item array bisa dibatasi dengan `@ArrayMaxSize`.
