# 272. Cara menggunakan decorator `@IsDate` dan `@IsDateString` untuk validasi tanggal

## Definisi & Target
`@IsDate` memvalidasi bahwa nilai adalah Date object. `@IsDateString` memvalidasi string ISO 8601 (contoh: `2024-01-01T00:00:00.000Z`).

## Komponen & Nest CLI Command
Tambahkan di DTO yang memiliki field tanggal.

## Kode Implementasi (Per File)
// src/events/dto/create-event.dto.ts
```typescript
import { IsString, IsDateString, IsDate, IsOptional, MinDate } from 'class-validator';
import { Type } from 'class-transformer';

export class CreateEventDto {
  @IsString()
  title: string;

  @IsDateString()
  startDate: string;

  @IsOptional()
  @IsDateString()
  endDate?: string;

  @IsOptional()
  @Type(() => Date)
  @IsDate()
  @MinDate(new Date())
  publishedAt?: Date;
}
```

## Cara Integrasi & Pengujian
```bash
POST /events {
  "title": "Workshop NestJS",
  "startDate": "2024-06-15T09:00:00Z",
  "endDate": "2024-06-15T17:00:00Z"
}
```

`@IsDateString()` menerima format ISO 8601. `@IsDate()` untuk properti bertipe `Date` (biasanya dari database). `@Type(() => Date)` melakukan konversi string ke Date.
