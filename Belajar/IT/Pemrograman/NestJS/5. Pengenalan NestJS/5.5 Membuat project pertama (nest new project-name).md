## 5.5 Membuat Project Pertama (`nest new`)

### Eksekusi Perintah

Buka terminal di folder tempat kamu biasa menyimpan tugas atau project, lalu ketik:

Bash

```
nest new belajar-nest
```

Setelah kamu menekan Enter, akan muncul proses pemilihan **Package Manager**. Seperti yang sudah kita bahas di materi 3.3, saya sarankan pilih **npm** atau **pnpm** (jika sudah terinstall) untuk efisiensi.

### Apa Saja yang Dibuat?

NestJS CLI tidak hanya membuat folder kosong, ia menyiapkan **Boilerplate** (kerangka kerja lengkap). Berikut adalah komponen kunci yang otomatis dibuat:

- **`main.ts`**: Pintu masuk utama. Di sini aplikasi "dinyalakan".
    
- **`app.module.ts`**: Modul pusat yang mengatur seluruh bagian aplikasi.
    
- **`app.controller.ts`**: Tempat kamu mendefinisikan URL/Endpoint (secara default ada `/`).
    
- **`app.service.ts`**: Tempat logika bisnis (secara default berisi fungsi pengembali teks "Hello World!").
    

### Menjalankan Server (Running the App)

Setelah proses instalasi selesai, masuk ke folder tersebut:

Bash

```
cd belajar-nest
```

Ada beberapa cara untuk menjalankan aplikasi ini, lihat pada file `package.json` di bagian `scripts`:

1. **`npm run start`**: Menjalankan aplikasi secara normal.
    
2. **`npm run start:dev` (Sangat Direkomendasikan)**: Menjalankan aplikasi dalam mode **Watch**. Artinya, setiap kali kamu mengubah kode dan menekan `Ctrl + S`, server akan otomatis _restart_. Kamu tidak perlu mematikan dan menyalakan terminal berulang kali.
    

### Mencoba Output Pertama

1. Jalankan `npm run start:dev`.
    
2. Tunggu sampai muncul log di terminal bertulisan: `Nest application successfully started`.
    
3. Buka browser atau Postman (materi 4.7), lalu akses: `http://localhost:3000`.
    

> **Hasil:** Kamu akan melihat tulisan **"Hello World!"**.

### Eksperimen Sederhana (Opsional)

Coba buka file `src/app.service.ts`, lalu ubah tulisan `"Hello World!"` menjadi `"Halo dari NestJS!"`. Simpan filenya, lalu cek kembali browsermu. Perubahan akan terjadi secara instan!

---

### Mengapa Struktur Ini Penting?

Dengan menggunakan `nest new`, kamu mengikuti **Standar Industri**. Jika suatu saat kamu bekerja di perusahaan besar yang menggunakan NestJS, struktur foldernya akan 90% mirip dengan apa yang baru saja kamu buat. Tidak ada lagi perdebatan di mana harus menaruh file.

Siap untuk membedah lebih dalam setiap file yang ada di folder `src` tersebut? Kita akan lanjut ke **5.6 Penjelasan Main.ts, AppModule, Controller, Service**.
