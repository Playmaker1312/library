## 5.7 Menjalankan Server Development

### Skrip Utama di NestJS

Jika kamu membuka file `package.json`, kamu akan melihat bagian `"scripts"`. Ada tiga cara utama untuk menjalankan server:

1. **`npm run start`**: Menjalankan aplikasi secara normal menggunakan `node`. Ini biasanya digunakan hanya untuk mengecek apakah aplikasi bisa menyala tanpa error sebelum dideploy.
    
2. **`npm run start:dev` (Wajib untuk Coding)**: Ini adalah mode yang paling sering kamu gunakan. Skrip ini menjalankan aplikasi dengan fitur **Watch Mode**.
    
    - Setiap kali kamu mengubah kode dan menekan `Ctrl + S`, server akan mendeteksi perubahan tersebut.
        
    - Server melakukan _re-compile_ dan _restart_ secara otomatis dalam hitungan detik.
        
3. **`npm run start:debug`**: Sama seperti mode dev, tetapi membuka _port_ khusus (biasanya 9229) agar kamu bisa menghubungkan _debugger_ dari VS Code untuk menelusuri kode baris demi baris.
    

---

### Apa yang Terjadi Saat Kamu Menjalankan `start:dev`?

Ketika kamu mengetik `npm run start:dev` di terminal, NestJS melakukan urutan proses berikut:

1. **Checking Types**: TypeScript mengecek apakah ada kesalahan pengetikan atau tipe data di kodemu.
    
2. **Mapping**: Nest-CLI memetakan file-file di folder `src/` (TypeScript) ke folder `dist/` (JavaScript hasil _compile_).
    
3. **Bootstrap**: Menjalankan fungsi `bootstrap()` di file `main.ts`.
    
4. **Module Initialization**: NestJS mulai mendaftarkan semua Modul, Controller, dan Service yang kamu buat.
    
5. **Listening**: Server membuka pintu komunikasi di port `3000` (sesuai pengaturan di `main.ts`).
    

---

### Tips Produktivitas di Terminal

- **Melihat Log**: Perhatikan warna log di terminal. Jika berwarna **Hijau/Cyan**, berarti aman. Jika muncul warna **Merah**, berarti ada error kodingan yang harus diperbaiki sebelum server bisa jalan lagi.
    
- **Menghentikan Server**: Tekan `Ctrl + C` pada terminal untuk mematikan server.
    
- **Port Sibuk**: Jika muncul error `EADDRINUSE`, itu berarti ada server lain (mungkin dari project lama) yang masih berjalan di port 3000. Kamu harus mematikannya atau mengubah port di `main.ts`.
    

---

### Mengapa Tidak Menggunakan `nodemon` Saja?

Jika kamu pernah belajar Node.js biasa, kamu mungkin terbiasa dengan `nodemon`. NestJS memiliki sistemnya sendiri melalui **Nest CLI** yang lebih cerdas karena ia tidak hanya merestart server, tapi juga menangani proses _transpiling_ TypeScript menjadi JavaScript secara bersamaan.

---

**Latihan Kecil:**

1. Jalankan `npm run start:dev` di terminalmu.
    
2. Buka browser ke `localhost:3000`.
    
3. Ubah teks di `app.service.ts`, simpan, dan langsung _refresh_ browsermu.
