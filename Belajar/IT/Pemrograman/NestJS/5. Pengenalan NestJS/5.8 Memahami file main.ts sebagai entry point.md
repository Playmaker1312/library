## 5.8 Memahami file main.ts sebagai Entry Point

### Definisi Singkat

**`main.ts`** adalah titik masuk (_entry point_) utama aplikasi. Fungsinya mirip dengan fungsi `main()` pada bahasa pemrograman seperti C++ atau Java. Tanpa file ini, Node.js tidak akan tahu bagian mana dari kode NestJS yang harus dijalankan pertama kali.

### Analogi

Bayangkan aplikasi NestJS adalah sebuah **Gedung Perkantoran Raksasa**:

- **`main.ts`** adalah **Resepsionis di Lobi Utama**.
    
- Dialah yang memegang kunci utama, menyalakan lampu seluruh gedung, memastikan listrik (port) mengalir, dan membuka pintu agar orang (request) bisa masuk.
    
- Jika resepsionis ini tidak masuk kerja, meskipun semua divisi (Module/Controller) sudah siap di lantai atas, gedung tersebut tetap akan gelap dan terkunci bagi publik.
    

### Bedah Kode Default main.ts

Saat kamu membuka file `src/main.ts`, kamu akan melihat kode seperti ini:

TypeScript

```
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  // 1. Menciptakan instance aplikasi
  const app = await NestFactory.create(AppModule);

  // 2. Menjalankan server pada port tertentu
  await app.listen(3000);
}
// 3. Memanggil fungsi untuk menyalakan server
bootstrap();
```

### Penjelasan Bagian-Bagian Penting:

1. **`NestFactory`**: Ini adalah kelas inti dari NestJS yang bertugas menciptakan _instance_ aplikasi. Ia berfungsi sebagai "pabrik" yang merakit semua modul menjadi satu aplikasi utuh.
    
2. **`AppModule`**: Ini adalah modul akar (_root module_). `main.ts` harus tahu modul mana yang menjadi pusat agar ia bisa melacak controller dan service lainnya.
    
3. **`bootstrap()`**: Nama fungsi ini adalah standar industri (berasal dari kata _bootstrapping_). Artinya proses memuat instruksi dasar untuk menjalankan sistem yang lebih kompleks.
    
4. **`app.listen(3000)`**: Ini adalah instruksi untuk membuka jalur komunikasi. Angka **3000** adalah nomor pintu (port). Kamu bisa mengubahnya menjadi 4000 atau 5000 jika port 3000 sudah terpakai.
    

### Apa Saja yang Biasanya Ditambahkan di main.ts?

Seiring berkembangnya aplikasi, `main.ts` tidak hanya berisi kode default. Kamu akan sering menambahkan konfigurasi global di sini, seperti:

- **Global Prefix**: Menambahkan `/api` ke semua URL (contoh: `localhost:3000/api/users`).
    
- **Validation Pipes**: Mengaktifkan pemeriksaan data otomatis untuk setiap request yang masuk.
    
- **CORS**: Mengizinkan aplikasi frontend (seperti React atau Vue) untuk mengakses API ini.
    
- **Swagger**: Menyiapkan dokumentasi API otomatis.

### Kesimpulan

Jika kamu ingin mengubah perilaku aplikasi secara menyeluruh (global), **`main.ts`** adalah tempatnya. Namun, untuk logika bisnis atau fitur spesifik, jangan tulis di sini; gunakan Controller atau Service.
