## 5.6 Struktur Folder & File Project NestJS

### 1. Folder Root (Luar)

File di sini berfungsi sebagai konfigurasi sistem dan lingkungan pengembangan:

- **`node_modules/`**: Tempat semua library yang diinstal (NPM) berada. Jangan menyentuh folder ini.
    
- **`.env`**: (Perlu dibuat manual) Tempat menyimpan rahasia seperti password database (Materi 3.5).
    
- **`package.json`**: Daftar library dan skrip perintah (Materi 3.4).
    
- **`tsconfig.json`**: Pengaturan TypeScript (cara kode diubah menjadi JS).
    
- **`nest-cli.json`**: Konfigurasi untuk alat bantu NestJS CLI.
    

### 2. Folder `src/` (Jantung Aplikasi)

Di sinilah 99% waktumu akan dihabiskan untuk menulis kode.

|**File**|**Fungsi Utama**|
|---|---|
|**`main.ts`**|**Pintu Masuk.** File yang pertama kali dijalankan oleh Node.js untuk menyalakan server.|
|**`app.module.ts`**|**Pusat Pengaturan.** Modul utama yang membungkus Controller dan Service.|
|**`app.controller.ts`**|**Penerima Tamu.** Menangani permintaan (Request) dari browser/client.|
|**`app.service.ts`**|**Koki Dapur.** Berisi logika bisnis (perhitungan, ambil data ke DB).|
|**`app.controller.spec.ts`**|**Unit Test.** File untuk mengetes apakah controller berjalan dengan benar.|

### Membedah File Inti

#### **A. main.ts**

Bayangkan ini sebagai tombol "Power" pada komputer.

TypeScript

```
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule); // Membuat aplikasi dari modul utama
  await app.listen(3000); // Menjalankan server di port 3000
}
bootstrap();
```

#### **B. app.module.ts**

Ini adalah "Daftar Inventaris". NestJS perlu tahu siapa saja Controller dan Service yang ada di aplikasi melalui file ini.

TypeScript

```
@Module({
  imports: [],
  controllers: [AppController], // Mendaftarkan Controller
  providers: [AppService],      // Mendaftarkan Service
})
export class AppModule {}
```

#### **C. app.controller.ts**

Di sinilah kamu menentukan alamat URL (Routing).

TypeScript

```
@Controller() // Menandakan ini adalah pengelola request
export class AppController {
  constructor(private readonly appService: AppService) {}

  @Get() // Jika ada yang akses URL '/' dengan metode GET
  getHello(): string {
    return this.appService.getHello(); // Panggil fungsi di Service
  }
}
```

---

### Alur Kerja Singkat

1. **Request** datang dari browser ke port 3000.
    
2. **`main.ts`** mengarahkan ke **`AppModule`**.
    
3. **`AppModule`** mencocokkan URL dengan **`AppController`**.
    
4. **`AppController`** meminta data ke **`AppService`**.
    
5. **`AppService`** memberikan data ke **`AppController`**.
    
6. **`AppController`** mengirimkan data tersebut sebagai **Response** ke browser.
    

### Tips Pro

Saat nanti proyekmu bertambah besar (misal ada fitur `users`, `products`, `orders`), kamu akan membuat folder baru di dalam `src/` untuk masing-masing fitur tersebut. Setiap folder akan memiliki modul, controller, dan service-nya sendiri.
