# 5. Pengenalan NestJS

## 5.6. Struktur Folder dan File Project NestJS

**Definisi Singkat:** Project NestJS memiliki struktur folder standar — `src/` untuk kode utama, `test/` untuk e2e test, dan file konfigurasi di root. Setiap fitur diorganisir dalam module folder sendiri.

**Analogi:** Seperti rumah dengan ruangan khusus — `src/` adalah ruang keluarga (aktivitas utama), `test/` adalah ruang uji (quality check), `node_modules/` adalah gudang, config files adalah buku panduan rumah.

**Poin-Poin Penting:**
```
my-nestjs-api/
├── src/                          # Kode sumber utama
│   ├── main.ts                   # Entry point aplikasi
│   ├── app.module.ts             # Root module
│   ├── app.controller.ts         # Basic controller
│   ├── app.controller.spec.ts    # Unit test controller
│   └── app.service.ts            # Basic service
├── test/                         # End-to-end test
│   ├── app.e2e-spec.ts
│   └── jest-e2e.json
├── node_modules/                 # Dependencies
├── dist/                         # Compiled JavaScript (hasil build)
├── nest-cli.json                 # Konfigurasi NestJS CLI
├── tsconfig.json                 # TypeScript config
├── tsconfig.build.json           # TypeScript build config
├── package.json                  # Project manifest
├── .eslintrc.js                  # ESLint config
└── .prettierrc                   # Prettier config
```

**Contoh Kode:**
```typescript
// nest-cli.json — konfigurasi CLI
{
  "$schema": "https://json.schemastore.org/nest-cli",
  "collection": "@nestjs/schematics",
  "sourceRoot": "src",
  "compilerOptions": {
    "deleteOutDir": true
  }
}

// Struktur setelah generate module:
// src/
// ├── users/
// │   ├── users.module.ts
// │   ├── users.controller.ts
// │   ├── users.controller.spec.ts
// │   ├── users.service.ts
// │   ├── users.service.spec.ts
// │   ├── dto/
// │   │   ├── create-user.dto.ts
// │   │   └── update-user.dto.ts
// │   └── entities/
// │       └── user.entity.ts
// ├── products/
// │   ├── products.module.ts
// │   ├── products.controller.ts
// │   ├── products.service.ts
// │   └── ...
// ├── common/          # Shared resources
// │   ├── guards/
// │   ├── pipes/
// │   └── decorators/
// └── main.ts
```

**Kasus Penggunaan Nyata:**
Setiap fitur menjadi folder terpisah di `src/`. Struktur ini memudahkan navigasi, memisahkan concerns, dan siap untuk monorepo. Folder `common/` untuk resources yang di-share antar module (guards, pipes, interceptors, filters).
