# 5. Pengenalan NestJS

## 5.5. Membuat Project Pertama: `nest new project-name`

**Definisi Singkat:** `nest new` membuat project NestJS baru dengan struktur folder lengkap — konfigurasi TypeScript, ESLint, Jest, Prettier, dan file `src/main.ts` siap pakai.

**Analogi:** Seperti membeli rumah baru yang sudah jadi — fondasi, rangka, atap, listrik, plumbing sudah siap. Anda tinggal masuk dan mulai dekorasi (coding).

**Poin-Poin Penting:**
- `nest new my-project` — buat folder `my-project`
- Pilih package manager (npm/yarn/pnpm) saat diminta
- Generate: `src/`, `test/`, `tsconfig.json`, `package.json`, `nest-cli.json`
- `src/main.ts` — entry point aplikasi
- `src/app.module.ts` — root module
- `src/app.controller.ts` — basic controller
- `src/app.service.ts` — basic service

**Contoh Kode:**
```bash
# Membuat project baru
nest new my-nestjs-api

# Output:
# ? Which package manager would you like to use? (npm/yarn/pnpm)
# Choose npm

# Struktur project yang dibuat:
# my-nestjs-api/
# ├── src/
# │   ├── main.ts
# │   ├── app.module.ts
# │   ├── app.controller.ts
# │   ├── app.controller.spec.ts
# │   └── app.service.ts
# ├── test/
# │   ├── app.e2e-spec.ts
# │   └── jest-e2e.json
# ├── node_modules/
# ├── nest-cli.json
# ├── tsconfig.json
# ├── tsconfig.build.json
# ├── package.json
# ├── .eslintrc.js
# ├── .prettierrc
# └── README.md
```

```typescript
// src/main.ts — entry point setelah project dibuat
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  await app.listen(3000);
  console.log('Application is running on: http://localhost:3000');
}
bootstrap();
```

**Kasus Penggunaan Nyata:**
Setiap project NestJS dimulai dengan `nest new`. Untuk monorepo, gunakan `nest new --monorepo` atau `--strict`. Untuk tim, setup ini memastikan semua developer mulai dengan konfigurasi identik.
