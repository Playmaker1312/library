# 5. Pengenalan NestJS

## 5.1. Apa itu NestJS dan Mengapa Menggunakannya

**Definisi Singkat:** NestJS adalah framework Node.js progresif untuk membangun server-side application yang efisien dan scalable, menggunakan TypeScript dengan arsitektur modular terinspirasi Angular.

**Analogi:** Seperti kontraktor bangunan — Anda tidak merancang fondasi, listrik, plumbing dari nol. NestJS memberi blueprint dan komponen siap pakai, Anda tinggal merancang ruangannya (business logic).

**Poin-Poin Penting:**
- Dibuat oleh Kamil Mysliwiec, rilis 2017
- Menggunakan TypeScript secara default
- Arsitektur modular → kode terorganisir per fitur
- Dependency Injection built-in
- Mendukung Express (default) dan Fastify
- Ekosistem kaya: TypeORM, Prisma, GraphQL, WebSockets, Microservices
- Coroutine: HTTP, WebSocket, gRPC, MQ dalam satu app

**Contoh Kode:**
```typescript
import { NestFactory } from '@nestjs/core';
import { Module, Controller, Get, Injectable } from '@nestjs/common';

// Entry point
async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  await app.listen(3000);
}

@Injectable()
export class AppService {
  getHello(): string {
    return 'Hello from NestJS!';
  }
}

@Controller()
export class AppController {
  constructor(private readonly appService: AppService) {}

  @Get()
  getHello(): string {
    return this.appService.getHello();
  }
}

@Module({
  imports: [],
  controllers: [AppController],
  providers: [AppService],
})
export class AppModule {}

bootstrap();
```

**Kasus Penggunaan Nyata:**
Pilih NestJS untuk REST API production-grade, microservices architecture, real-time apps (chat, notifications), GraphQL gateways, atau full-stack TypeScript apps (NestJS + Angular/React). Cocok untuk tim yang butuh struktur dan best practices.
