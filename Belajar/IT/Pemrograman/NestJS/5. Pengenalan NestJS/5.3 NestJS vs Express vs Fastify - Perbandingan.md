# 5. Pengenalan NestJS

## 5.3. NestJS vs Express vs Fastify — Perbandingan

**Definisi Singkat:** Express adalah framework minimalis dan flexible. Fastify lebih cepat dengan performa tinggi. NestJS adalah framework opinionated yang bisa menggunakan Express atau Fastify sebagai HTTP engine.

**Analogi:** Express = mobil manual (bebas modifikasi). Fastify = mobil sport (cepat, ringan). NestJS = mobil dengan fitur lengkap + ADAS (parking assist, lane keep — built-in). NestJS pakai mesin Express atau Fastify.

**Poin-Poin Penting:**
| Fitur | Express | Fastify | NestJS |
|-------|---------|---------|--------|
| Tipe | Minimalis | Performa | Opinionated |
| TypeScript | Opsional | Opsional | Default |
| Struktur | Bebas | Plugin-based | Modular |
| DI | Manual | Manual | Built-in |
| Performa | Sedang | Tinggi | Tergantung engine |
| Ekosistem | Besar | Sedang | Bertumbuh |
| Learning Curve | Rendah | Rendah | Sedang |

**Contoh Kode:**
```typescript
// Express — callback-based, manual routing
import express from 'express';
const app = express();
app.get('/users', (req, res) => res.json([]));

// NestJS dengan Express (default) — decorator-based
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { ExpressAdapter } from '@nestjs/platform-express';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  await app.listen(3000);
}

// NestJS dengan Fastify — performa lebih tinggi
import { FastifyAdapter } from '@nestjs/platform-fastify';

async function bootstrapFastify() {
  const app = await NestFactory.create(
    AppModule,
    new FastifyAdapter(),
  );
  await app.listen(3000);
  console.log('Using Fastify engine');
}
```

**Kasus Penggunaan Nyata:**
Gunakan Express (default) jika ekosistem middleware Express dibutuhkan. Gunakan Fastify untuk high-throughput APIs. NestJS dengan Express cocok untuk tim yang butuh struktur. NestJS + Fastify untuk microservices yang sensitif latency.
