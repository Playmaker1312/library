## 5.4 Instalasi NestJS CLI

### Definisi Singkat

**NestJS CLI** adalah alat baris perintah yang digunakan untuk menginisialisasi, mengembangkan, dan memelihara aplikasi NestJS. Dengan CLI, kamu tidak perlu membuat file `.ts` secara manual; cukup ketik satu perintah, dan NestJS akan menyiapkan semuanya.

### Analogi

Pikirkan NestJS CLI sebagai **Alat Cetakan Bangunan Otomatis**:

- **Tanpa CLI**: Kamu harus mengaduk semen, menyusun bata satu-satu, dan memasang kabel sendiri.
    
- **Dengan CLI**: Kamu cukup menekan tombol "Buat Kamar Tidur", dan mesin otomatis akan membangunkan satu ruangan lengkap dengan tembok, lampu, dan colokan listriknya yang sudah sesuai standar.
    

### Langkah-Langkah Instalasi

Pastikan kamu sudah menginstal **Node.js** di komputermu. Buka Terminal atau Command Prompt, lalu ikuti langkah berikut:

#### 1. Install CLI secara Global

Gunakan perintah ini agar kamu bisa memanggil perintah `nest` dari folder mana pun di komputermu.

Bash

```
npm install -g @nestjs/cli
```

_(Catatan: Jika kamu menggunakan Linux/Mac dan muncul error "Permission Denied", tambahkan `sudo` di depannya)._

#### 2. Verifikasi Instalasi

Cek apakah instalasi berhasil dengan melihat versi NestJS yang terpasang:

Bash

```
nest --version
```

## Membuat Project Pertama

Setelah CLI terpasang, mari kita buat project pertama kita:

#### 1. Jalankan Perintah Create

Ganti `nama-project-kamu` dengan nama folder yang kamu inginkan.

Bash

```
nest new nama-project-kamu
```

#### 2. Pilih Package Manager

CLI akan menanyakan package manager mana yang ingin kamu gunakan.

- **NPM**: Pilihan standar dan paling aman bagi pemula.
    
- **Yarn / PNPM**: Pilih jika kamu ingin proses instalasi library yang lebih cepat.
    

#### 3. Masuk ke Folder & Jalankan

Setelah selesai, masuk ke foldernya dan jalankan server dalam mode _development_:

Bash

```
cd nama-project-kamu
npm run start:dev
```

_Flag `--watch` (yang ada di dalam skrip `start:dev`) akan memantau perubahan kodemu. Setiap kali kamu menekan **Save**, server akan otomatis restart._

### Apa yang Terjadi di Balik Layar?

Saat kamu menjalankan `nest new`, CLI melakukan banyak hal untukmu:

1. Membuat struktur folder sesuai arsitektur terbaik (Best Practices).
    
2. Membuat file konfigurasi TypeScript (`tsconfig.json`).
    
3. Mengatur _Linter_ dan _Formatter_ (ESLint & Prettier) agar kodemu rapi.
    
4. Menyiapkan folder `test` untuk _Unit Testing_.
    
5. Membuat file `main.ts` yang merupakan pintu masuk utama aplikasi.
    

---

Sekarang coba buka browser dan akses `http://localhost:3000`. Jika muncul tulisan **"Hello World!"**, selamat! Kamu sudah berhasil menjalankan server NestJS pertama kamu.

Siap untuk membedah isi folder yang baru saja dibuat? Kita akan lanjut ke **5.5 Struktur Folder & File Default**.
