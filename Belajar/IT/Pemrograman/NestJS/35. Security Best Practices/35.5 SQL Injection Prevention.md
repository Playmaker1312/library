# 35. Security Best Practices ## 35.5 SQL Injection Prevention

**Definisi Singkat:** SQL Injection adalah serangan yang menyisipkan query SQL berbahaya melalui input user. Pencegahan utama adalah menggunakan parameterized queries atau ORM yang sudah memiliki built-in protection, dan tidak pernah menggabungkan input langsung ke query string.

**Analogi:** SQL Injection seperti orang yang menulis perintah di kolom "Nama" di form pendaftaran: `Robert'); DROP TABLE Students;--`. Jika sistem tidak aman, perintah itu akan dijalankan. Seperti tukang pos yang membaca amplop alamat sebagai perintah baru, bukan sekadar alamat.

**Poin-Poin Penting:**
- **Parameterized queries** dengan placeholder ($1, ?, :name)
- **ORM** (TypeORM, Prisma, Sequelize) inject-safe by default
- **Input validation** dengan class-validator
- **Escape input** jika terpaksa raw query
- **Stored procedures** mengurangi risiko
- **Least privilege** database user

**Contoh Kode:**
```typescript
// RENTAN SQL INJECTION — JANGAN TIRU
@Get('users/unsafe')
async getUsersUnsafe(@Query('name') name: string) {
  const query = `SELECT * FROM users WHERE name = '${name}'`;
  return this.entityManager.query(query);
}
// Input: "' OR 1=1 --" akan return semua users!
```

```typescript
// AMAN — menggunakan TypeORM parameterized query
import { Injectable } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { User } from './user.entity';

@Injectable()
export class UserService {
  constructor(
    @InjectRepository(User)
    private readonly userRepository: Repository<User>,
  ) {}

  // AMAN — ORM parameterized
  async findByName(name: string): Promise<User[]> {
    return this.userRepository.find({
      where: { name },
    });
  }

  // AMAN — QueryBuilder dengan parameters
  async searchUsers(searchTerm: string): Promise<User[]> {
    return this.userRepository
      .createQueryBuilder('user')
      .where('user.name LIKE :search', { search: `%${searchTerm}%` })
      .orWhere('user.email LIKE :email', { email: `%${searchTerm}%` })
      .getMany();
  }

  // AMAN — Raw query dengan parameter
  async customQuery(userId: number): Promise<any> {
    return this.userRepository.query(
      'SELECT * FROM users WHERE id = $1',
      [userId],
    );
  }
}
```

**Kasus Penggunaan Nyata:** E-commerce application — form search produk, login, registrasi, dan checkout semuanya menggunakan ORM dengan parameterized queries. Walaupun ada ribuan request per hari, SQL injection tidak mungkin karena semua input melalui TypeORM repository.
