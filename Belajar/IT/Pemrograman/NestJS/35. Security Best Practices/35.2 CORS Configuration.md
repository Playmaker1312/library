# 35. Security Best Practices ## 35.2 CORS Configuration

**Definisi Singkat:** CORS (Cross-Origin Resource Sharing) adalah mekanisme keamanan browser yang mengontrol akses resource dari domain berbeda. NestJS menyediakan konfigurasi CORS melalui method `enableCors()` atau dengan Fastify plugin.

**Analogi:** CORS seperti daftar tamu di pesta eksklusif — hanya tamu yang namanya ada di daftar (allowed origins) yang boleh masuk. Jika ada tamu tidak dikenal mencoba masuk, satpam (browser) menolaknya.

**Poin-Poin Penting:**
- **app.enableCors()** method global
- **origin** daftar domain yang diizinkan
- **methods** HTTP methods yang diizinkan
- **credentials** izinkan cookie/auth headers
- **allowedHeaders** headers yang diizinkan
- **preflight** OPTIONS request handling

**Contoh Kode:**
```typescript
// main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // CORS basic — allow all (hanya untuk development)
  app.enableCors();

  // CORS production — specific origins
  app.enableCors({
    origin: [
      'https://example.com',
      'https://admin.example.com',
      'https://www.example.com',
    ],
    methods: ['GET', 'POST', 'PUT', 'PATCH', 'DELETE', 'OPTIONS'],
    credentials: true,
    allowedHeaders: [
      'Content-Type',
      'Authorization',
      'X-Requested-With',
      'Accept',
    ],
    exposedHeaders: ['X-Total-Count', 'X-Pagination'],
    maxAge: 3600,
  });

  // CORS dengan dynamic origin
  app.enableCors({
    origin: (origin, callback) => {
      const whitelist = ['https://example.com', 'https://app.example.com'];

      if (!origin || whitelist.includes(origin)) {
        callback(null, true);
      } else {
        callback(new Error('Not allowed by CORS'));
      }
    },
    credentials: true,
  });

  await app.listen(3000);
}
bootstrap();
```

**Kasus Penggunaan Nyata:** Aplikasi SaaS dengan frontend React di `app.example.com` dan backend API di `api.example.com` — CORS dikonfigurasi untuk hanya mengizinkan origin frontend dan subdomain admin, dengan credentials true untuk cookie session.
