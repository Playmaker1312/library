# 35. Security Best Practices ## 35.1 Helmet HTTP Security Headers

**Definisi Singkat:** Helmet adalah middleware keamanan untuk Express yang mengatur berbagai HTTP headers untuk melindungi aplikasi dari serangan web umum seperti XSS, clickjacking, MIME sniffing, dan lainnya. NestJS menyediakan integrasi via `helmet` package.

**Analogi:** Helmet seperti satpam di pintu masuk gedung — dia memeriksa setiap orang yang masuk (request headers), memastikan mereka membawa identitas yang benar (CSP), tidak membawa senjata (XSS protection), dan tidak menyamar sebagai orang lain (HSTS).

**Poin-Poin Penting:**
- **helmet()** middleware global untuk Express
- **Content-Security-Policy** cegah XSS dan data injection
- **X-Frame-Options** cegah clickjacking
- **Strict-Transport-Security** paksa HTTPS
- **X-Content-Type-Options** cegah MIME sniffing
- **Referrer-Policy** kontrol informasi referer

**Contoh Kode:**
```typescript
// main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import helmet from 'helmet';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.use(helmet());

  // Atau dengan konfigurasi kustom
  app.use(
    helmet({
      contentSecurityPolicy: {
        directives: {
          defaultSrc: ["'self'"],
          styleSrc: ["'self'", "'unsafe-inline'"],
          scriptSrc: ["'self'"],
          imgSrc: ["'self'", 'data:', 'https://trusted-cdn.com'],
          connectSrc: ["'self'", 'https://api.example.com'],
          fontSrc: ["'self'", 'https://fonts.gstatic.com'],
          objectSrc: ["'none'"],
          upgradeInsecureRequests: [],
        },
      },
      frameguard: { action: 'deny' },
      hidePoweredBy: true,
      hsts: { maxAge: 31536000, includeSubDomains: true, preload: true },
      referrerPolicy: { policy: 'same-origin' },
      xssFilter: true,
      noSniff: true,
    }),
  );

  await app.listen(3000);
}
bootstrap();
```

**Kasus Penggunaan Nyata:** Aplikasi fintech yang memproses data keuangan pengguna — Helmet headers melindungi dari XSS attack pada form input, mencegah clickjacking via iframe, dan memaksa koneksi HTTPS untuk semua resource.
