# 35. Security Best Practices ## 35.4 CSRF Protection

**Definisi Singkat:** CSRF (Cross-Site Request Forgery) adalah serangan yang memaksa user yang sudah login untuk mengeksekusi aksi yang tidak diinginkan. Proteksi CSRF menggunakan token unik yang divalidasi untuk setiap request yang mengubah state.

**Analogi:** CSRF seperti tanda tangan basah pada dokumen penting — bank tidak akan memproses transfer tanpa tanda tangan asli Anda. CSRF token adalah "tanda tangan digital" yang memastikan request benar-benar berasal dari aplikasi Anda, bukan dari situs jahat.

**Poin-Poin Penting:**
- **csurf** atau **csurf-csrf** middleware
- **Double Submit Cookie** pattern
- **SameSite cookie** attribute (Lax, Strict, None)
- **Token rotasi** setiap session
- **Origin/Referer header** validation
- **Stateful vs Stateless** CSRF token

**Contoh Kode:**
```typescript
// main.ts — dengan csurf (Express)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import * as cookieParser from 'cookie-parser';
import * as csurf from 'csurf';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.use(cookieParser());

  // CSRF protection
  app.use(
    csurf({
      cookie: {
        httpOnly: true,
        secure: process.env.NODE_ENV === 'production',
        sameSite: 'strict',
      },
    }),
  );

  // Expose CSRF token endpoint
```

```typescript
// csrf.module.ts
import { Module, NestModule, MiddlewareConsumer, RequestMethod } from '@nestjs/common';
import * as csurf from 'csurf';
import * as cookieParser from 'cookie-parser';

@Module({})
export class CsrfModule implements NestModule {
  configure(consumer: MiddlewareConsumer) {
    consumer
      .apply(
        cookieParser(),
        csurf({
          cookie: {
            httpOnly: true,
            secure: process.env.NODE_ENV === 'production',
            sameSite: 'strict',
          },
        }),
      )
      .forRoutes({ path: '*', method: RequestMethod.ALL });
  }
}
```

```typescript
// csrf.controller.ts
import { Controller, Get, Req, Res } from '@nestjs/common';
import { Request, Response } from 'express';

@Controller('csrf')
export class CsrfController {
  @Get('token')
  getToken(@Req() req: Request, @Res() res: Response) {
    const token = req.csrfToken();

    res.cookie('XSRF-TOKEN', token, {
      httpOnly: false, // JavaScript perlu baca
      secure: process.env.NODE_ENV === 'production',
      sameSite: 'strict',
      maxAge: 3600000, // 1 jam
    });

    return { token };
  }
}
```

**Kasus Penggunaan Nyata:** Aplikasi perbankan online — proteksi CSRF mencegah attacker mengirim link berbahaya yang mentransfer uang dari akun korban. Setiap form transfer menyertakan CSRF token yang divalidasi server-side.
