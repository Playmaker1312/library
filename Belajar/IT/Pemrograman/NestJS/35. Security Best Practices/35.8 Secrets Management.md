# 35. Security Best Practices ## 35.8 Secrets Management

**Definisi Singkat:** Secrets management adalah praktik menyimpan dan mengelola kredensial sensitif (API keys, database passwords, JWT secrets) secara aman, tidak pernah di codebase, melainkan di environment variables, vault services, atau secret managers.

**Analogi:** Secrets management seperti brankas di bank — Anda tidak menyimpan uang di meja resepsionis (codebase). Uang disimpan di brankas (vault), dan hanya orang tertentu dengan kunci (role-based access) yang bisa mengaksesnya. Resepsionis (aplikasi) hanya tahu cara memanggil petugas (API call) untuk mengambil uang.

**Poin-Poin Penting:**
- **@nestjs/config** untuk env variables
- **.env** file (tidak di-commit)
- **ValidationSchema** untuk validasi env
- **AWS Secrets Manager / GCP Secret Manager / HashiCorp Vault**
- **Environment-specific** config files
- **Jangan hardcode** secrets di source code

```typescript
// config/env.validation.ts
import { plainToClass } from 'class-transformer';
import { IsString, IsNumber, IsOptional, validateSync } from 'class-validator';

class EnvironmentVariables {
  @IsString()
  DATABASE_HOST: string;

  @IsNumber()
  DATABASE_PORT: number;

  @IsString()
  DATABASE_PASSWORD: string;

  @IsString()
  JWT_SECRET: string;

  @IsString()
  @IsOptional()
  SENDGRID_API_KEY?: string;
}

export function validate(config: Record<string, unknown>) {
  const validatedConfig = plainToClass(EnvironmentVariables, config, {
    enableImplicitConversion: true,
  });

  const errors = validateSync(validatedConfig, {
    skipMissingProperties: false,
  });

  if (errors.length > 0) {
    throw new Error(errors.toString());
  }

  return validatedConfig;
}
```

```typescript
// app.module.ts
import { Module } from '@nestjs/common';
import { ConfigModule } from '@nestjs/config';
import { validate } from './config/env.validation';
import configuration from './config/configuration';

@Module({
  imports: [
    ConfigModule.forRoot({
      isGlobal: true,
      load: [configuration],
      validate: validate,
      envFilePath: [`.env.${process.env.NODE_ENV}`, '.env'],
    }),
  ],
})
export class AppModule {}
```
