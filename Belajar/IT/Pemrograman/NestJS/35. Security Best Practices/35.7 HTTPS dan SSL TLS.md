# 35. Security Best Practices ## 35.7 HTTPS dan SSL TLS

**Definisi Singkat:** HTTPS (HTTP Secure) mengenkripsi komunikasi antara client dan server menggunakan SSL/TLS certificate. Di produksi, HTTPS di-handle oleh reverse proxy (Nginx, Load Balancer) atau diaktifkan langsung di NestJS untuk development.

**Analogi:** HTTPS seperti amplop kedap suara dan terkunci — tanpa HTTPS, data dikirim seperti kartu pos yang bisa dibaca siapa pun saat transit. Dengan HTTPS, data dikirim dalam amplop bersegel yang hanya bisa dibuka oleh penerima sah.

**Poin-Poin Penting:**
- **SSL/TLS certificate** dari CA (Let's Encrypt)
- **HTTPS redirect** paksa semua traffic ke HTTPS
- **HSTS header** browser harus HTTPS
- **Self-signed cert** untuk development
- **Nginx/AWS LB** handle SSL termination
- **Let's Encrypt** free SSL certificates

**Contoh Kode:**
```typescript
// main.ts — HTTPS untuk development/local
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import * as fs from 'fs';
import * as https from 'https';
import { ExpressAdapter } from '@nestjs/platform-express';
import * as express from 'express';

async function bootstrap() {
  const server = express();
  const app = await NestFactory.create(
    AppModule,
    new ExpressAdapter(server),
  );

  // Redirect HTTP ke HTTPS
  app.use((req, res, next) => {
    if (!req.secure && req.headers['x-forwarded-proto'] !== 'https') {
      return res.redirect(301, `https://${req.headers.host}${req.url}`);
    }
    next();
  });

  // HTTPS server (development)
  if (process.env.NODE_ENV === 'development') {
    const httpsOptions = {
      key: fs.readFileSync('./certs/private-key.pem'),
      cert: fs.readFileSync('./certs/public-certificate.pem'),
    };

    await app.init();
    https.createServer(httpsOptions, server).listen(443);
    console.log('HTTPS Server running on https://localhost:443');
  }

  // HTTP server
  await app.listen(3000);
  console.log('HTTP Server running on http://localhost:3000');
}
bootstrap();
```

```typescript
// main.ts — Production (HTTPS via reverse proxy)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import helmet from 'helmet';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // Trust proxy untuk mendapatkan IP asli
  app.set('trust proxy', 1);

  app.use(
    helmet({
      hsts: {
        maxAge: 31536000,
        includeSubDomains: true,
        preload: true,
      },
    }),
  );

  await app.listen(process.env.PORT || 3000);
}
bootstrap();
```

```typescript
// https-redirect.middleware.ts
import { Injectable, NestMiddleware } from '@nestjs/common';
import { Request, Response } from 'express';

@Injectable()
export class HttpsRedirectMiddleware implements NestMiddleware {
  use(req: Request, res: Response, next: () => void) {
    if (
      !req.secure &&
      req.headers['x-forwarded-proto'] !== 'https' &&
      process.env.NODE_ENV === 'production'
    ) {
      return res.redirect(301, `https://${req.headers.host}${req.url}`);
    }
    next();
  }
}
```

```typescript
// app.module.ts
import { Module, NestModule, MiddlewareConsumer } from '@nestjs/common';

@Module({})
export class AppModule implements NestModule {
  configure(consumer: MiddlewareConsumer) {
    consumer
      .apply(HttpsRedirectMiddleware)
      .forRoutes('*');
  }
}
```

**Kasus Penggunaan Nyata:** Aplikasi kesehatan (healthtech) yang menyimpan data medis pasien — regulasi HIPAA mewajibkan enkripsi data in-transit. HTTPS dengan TLS 1.3 diaktifkan via AWS Load Balancer + Certificate Manager, dengan HSTS header memaksa browser selalu HTTPS.
