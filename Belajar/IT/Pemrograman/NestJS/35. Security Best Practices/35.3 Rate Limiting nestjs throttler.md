# 35. Security Best Practices ## 35.3 Rate Limiting nestjs throttler

**Definisi Singkat:** Rate limiting membatasi jumlah request dari suatu IP dalam periode waktu tertentu untuk mencegah abuse, DDoS attacks, dan brute force. NestJS menyediakan `@nestjs/throttler` package untuk implementasi mudah.

**Analogi:** Rate limiting seperti antrian di ATM — hanya satu orang boleh transaksi dalam satu waktu, dan setiap orang hanya boleh 3x transaksi per hari. Jika ada yang mencoba 100x dalam 1 menit, mesin akan menolak (429 Too Many Requests).

**Poin-Poin Penting:**
- **@nestjs/throttler** package resmi
- **@Throttle()** decorator kustom limit per endpoint
- **@SkipThrottle()** skip rate limit
- **ThrottlerGuard** global guard
- **ttl** (time-to-live) dan **limit** (max requests)
- **Storage** memory, Redis, atau database

**Contoh Kode:**
```typescript
// app.module.ts
import { Module } from '@nestjs/common';
import { ThrottlerModule, ThrottlerGuard } from '@nestjs/throttler';
import { APP_GUARD } from '@nestjs/core';

@Module({
  imports: [
    ThrottlerModule.forRoot([
      {
        ttl: 60000, // 60 detik
        limit: 100, // max 100 request per 60 detik
      },
    ]),
  ],
  providers: [
    {
      provide: APP_GUARD,
      useClass: ThrottlerGuard,
    },
  ],
})
export class AppModule {}
```

```typescript
// auth.controller.ts
import { Controller, Post, Body } from '@nestjs/common';
import { Throttle, SkipThrottle } from '@nestjs/throttler';

@Controller('auth')
export class AuthController {
  @Post('login')
  @Throttle({ default: { ttl: 60000, limit: 5 } }) // 5 login attempts per menit
  async login(@Body() body: { email: string; password: string }) {
    // login logic
  }

  @Post('register')
  @Throttle({ default: { ttl: 3600000, limit: 3 } }) // 3 registrations per jam
  async register(@Body() body: any) {
    // register logic
  }

  @SkipThrottle()
  @Get('health')
  async health() {
    return { status: 'ok' };
  }
}
```

```typescript
// throttler-behind-proxy.guard.ts
import { Injectable } from '@nestjs/common';
import { ThrottlerGuard } from '@nestjs/throttler';
import { ExecutionContext } from '@nestjs/common';

@Injectable()
export class ThrottlerBehindProxyGuard extends ThrottlerGuard {
  protected getTracker(req: Record<string, any>): string {
    return req.ips.length ? req.ips[0] : req.ip;
  }
}
```

```typescript
// app.module.ts (dengan Redis storage)
import { ThrottlerModule, ThrottlerStorageRedisService } from '@nestjs/throttler-storage-redis';

// npm install @nestjs/throttler-storage-redis ioredis

@Module({
  imports: [
    ThrottlerModule.forRoot([
      {
        ttl: 60000,
        limit: 100,
        storage: new ThrottlerStorageRedisService({
          host: 'localhost',
          port: 6379,
        }),
      },
    ]),
  ],
})
export class AppModule {}
```

**Kasus Penggunaan Nyata:** API publik untuk layanan cuaca — user gratis dibatasi 1000 request/hari, user premium 10000 request/jam. Endpoint `/api/weather` menggunakan rate limiter dengan storage Redis untuk konsistensi di multiple server.
