# 35. Security Best Practices ## 35.6 Input Sanitization

**Definisi Singkat:** Input sanitization adalah proses membersihkan dan memvalidasi input user untuk menghilangkan karakter atau skrip berbahaya. Di NestJS, ini bisa dilakukan dengan ValidationPipe, class-validator, class-transformer, dan library seperti dompurify atau xss.

**Analogi:** Input sanitization seperti saringan di pintu masuk bandara — semua barang (input) diperiksa: pisau (tag HTML) disita, cairan berbahaya (JavaScript injection) dibuang, hanya barang aman yang diizinkan masuk ke pesawat (database).

**Poin-Poin Penting:**
- **ValidationPipe** global transform & validate
- **class-validator** decorator validation
- **class-transformer** sanitasi tipe data
- **whitelist: true** hapus properti tidak dikenal
- **forbidNonWhitelisted** tolak properti unknown
- **transform: true** konversi tipe otomatis
- **XSS sanitization** library khusus

**Contoh Kode:**
```typescript
// main.ts — Global ValidationPipe dengan sanitasi
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { ValidationPipe } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.useGlobalPipes(
    new ValidationPipe({
      whitelist: true, // hapus properti yang tidak didekorasi
      forbidNonWhitelisted: true, // throw error jika ada properti tidak dikenal
      transform: true, // konversi tipe data ke tipe yang didefinisikan
      transformOptions: {
        enableImplicitConversion: true,
      },
    }),
  );

  await app.listen(3000);
}
bootstrap();
```

```typescript
// create-user.dto.ts
import {
  IsString,
  IsEmail,
  MinLength,
  MaxLength,
  Matches,
  IsOptional,
  IsEnum,
  Trim,
  ToLowerCase,
} from 'class-validator';

export enum UserRole {
  USER = 'user',
  ADMIN = 'admin',
}

export class CreateUserDto {
  @IsString()
  @MinLength(2)
  @MaxLength(50)
  @Matches(/^[a-zA-Z0-9 ]+$/, { message: 'Name can only contain letters, numbers, and spaces' })
  name: string;

  @IsEmail()
  @MaxLength(255)
  email: string;

  @IsString()
  @MinLength(8)
  @MaxLength(100)
  @Matches(/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&])/, {
    message: 'Password too weak',
  })
  password: string;

  @IsOptional()
  @IsEnum(UserRole)
  role: UserRole;
}
```

```typescript
// sanitize.interceptor.ts
import {
  Injectable,
  NestInterceptor,
  ExecutionContext,
  CallHandler,
} from '@nestjs/common';
import { Observable } from 'rxjs';
import * as sanitizeHtml from 'sanitize-html';

@Injectable()
export class SanitizeInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const request = context.switchToHttp().getRequest();

    if (request.body) {
      request.body = this.sanitizeObject(request.body);
    }

    if (request.query) {
      request.query = this.sanitizeObject(request.query);
    }

    return next.handle();
  }

  private sanitizeObject(obj: any): any {
    if (typeof obj === 'string') {
      return sanitizeHtml(obj, {
        allowedTags: [],
        allowedAttributes: {},
      });
    }

    if (Array.isArray(obj)) {
      return obj.map((item) => this.sanitizeObject(item));
    }

    if (obj && typeof obj === 'object') {
      const sanitized: any = {};
      for (const [key, value] of Object.entries(obj)) {
        sanitized[key] = this.sanitizeObject(value);
      }
      return sanitized;
    }

    return obj;
  }
}
```

```typescript
// app.module.ts
import { Module } from '@nestjs/common';
import { APP_PIPE, APP_INTERCEPTOR } from '@nestjs/core';

@Module({
  providers: [
    {
      provide: APP_PIPE,
      useClass: ValidationPipe, // global validation
    },
    {
      provide: APP_INTERCEPTOR,
      useClass: SanitizeInterceptor, // global sanitization
    },
  ],
})
export class AppModule {}
```

**Kasus Penggunaan Nyata:** Aplikasi forum atau blog — user bisa mengirim komentar. Input sanitization mencegah XSS attack melalui komentar (strip `<script>` tags), sementara validation memastikan panjang komentar tidak melebihi 1000 karakter dan tidak mengandung URL berbahaya.
