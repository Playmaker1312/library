# 35. Security Best Practices ## 35.9 OAuth2 dan Social Login Google GitHub

**Definisi Singkat:** OAuth2 adalah protokol authorization yang memungkinkan aplikasi mengakses resource user di layanan lain tanpa mengetahui password mereka. Social Login memungkinkan user login dengan akun Google, GitHub, Facebook, dll.

**Analogi:** OAuth2 seperti sistem "valet key" di hotel — Anda memberikan kunci terbatas (token) ke petugas valet untuk memarkir mobil, bukan kunci utama Anda. Petugas hanya bisa memarkir dan mengambil mobil, tidak bisa membuka bagasi atau menggunakan mobil untuk keperluan lain.

**Poin-Poin Penting:**
- **@nestjs/passport** integrasi Passport.js
- **passport-google-oauth20** strategy Google
- **passport-github** strategy GitHub
- **AuthGuard** untuk proteksi endpoint
- **Access Token & Refresh Token**
- **OAuth2 scopes** permission granular

**Contoh Kode:**
```typescript
// auth.module.ts
import { Module } from '@nestjs/common';
import { PassportModule } from '@nestjs/passport';
import { JwtModule } from '@nestjs/jwt';
import { AuthController } from './auth.controller';
import { AuthService } from './auth.service';
import { GoogleStrategy } from './strategies/google.strategy';
import { GithubStrategy } from './strategies/github.strategy';
import { JwtStrategy } from './strategies/jwt.strategy';
import { UserModule } from '../user/user.module';
import { ConfigModule, ConfigService } from '@nestjs/config';

@Module({
  imports: [
    PassportModule.register({ defaultStrategy: 'jwt' }),
    JwtModule.registerAsync({
      imports: [ConfigModule],
      useFactory: (config: ConfigService) => ({
        secret: config.get('app.jwt.secret'),
        signOptions: { expiresIn: config.get('app.jwt.expiresIn') },
      }),
      inject: [ConfigService],
    }),
    UserModule,
  ],
  controllers: [AuthController],
  providers: [AuthService, GoogleStrategy, GithubStrategy, JwtStrategy],
})
export class AuthModule {}
```

```typescript
// strategies/google.strategy.ts
import { Injectable } from '@nestjs/common';
import { PassportStrategy } from '@nestjs/passport';
import { Strategy, VerifyCallback } from 'passport-google-oauth20';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class GoogleStrategy extends PassportStrategy(Strategy, 'google') {
  constructor(configService: ConfigService) {
    super({
      clientID: configService.get('app.google.clientId'),
      clientSecret: configService.get('app.google.clientSecret'),
      callbackURL: configService.get('app.google.callbackUrl'),
      scope: ['email', 'profile'],
    });
  }

  async validate(
    accessToken: string,
    refreshToken: string,
    profile: any,
    done: VerifyCallback,
  ): Promise<any> {
    const { name, emails, photos } = profile;

    const user = {
      email: emails[0].value,
      firstName: name.givenName,
      lastName: name.familyName,
      picture: photos[0].value,
      accessToken,
    };

    done(null, user);
  }
}
```

```typescript
// auth.controller.ts
import { Controller, Get, Req, UseGuards } from '@nestjs/common';
import { AuthGuard } from '@nestjs/passport';
import { AuthService } from './auth.service';

@Controller('auth')
export class AuthController {
  constructor(private readonly authService: AuthService) {}

  @Get('google')
  @UseGuards(AuthGuard('google'))
  async googleAuth() {
    // redirect ke Google login
  }

  @Get('google/callback')
  @UseGuards(AuthGuard('google'))
  async googleAuthRedirect(@Req() req) {
    return this.authService.socialLogin(req.user);
  }

  @Get('github')
  @UseGuards(AuthGuard('github'))
  async githubAuth() {
    // redirect ke GitHub login
  }

  @Get('github/callback')
  @UseGuards(AuthGuard('github'))
  async githubAuthRedirect(@Req() req) {
    return this.authService.socialLogin(req.user);
  }
}
```

```typescript
// auth.service.ts
import { Injectable } from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';
import { UserService } from '../user/user.service';

@Injectable()
export class AuthService {
  constructor(
    private readonly jwtService: JwtService,
    private readonly userService: UserService,
  ) {}

  async socialLogin(profile: any) {
    let user = await this.userService.findByEmail(profile.email);

    if (!user) {
      user = await this.userService.create({
        email: profile.email,
        name: profile.firstName || profile.username,
        picture: profile.picture,
        provider: profile.provider,
      });
    }

    const payload = { sub: user.id, email: user.email };

    return {
      accessToken: this.jwtService.sign(payload),
      user,
    };
  }
}
```

**Kasus Penggunaan Nyata:** Aplikasi SaaS dashboard — user bisa login via Google Workspace (perusahaan) atau GitHub (developer). OAuth2 Google memberikan akses ke email dan profil, cukup untuk registrasi tanpa password. Integrasi dengan Passport.js memudahkan penambahan provider baru.
