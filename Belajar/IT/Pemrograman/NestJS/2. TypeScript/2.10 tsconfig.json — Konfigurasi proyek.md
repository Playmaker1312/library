## 2.10 tsconfig.json — Konfigurasi Proyek

### Definisi Singkat

**tsconfig.json** adalah file konfigurasi berformat JSON yang mendikte perilaku compiler TypeScript (`tsc`) dalam sebuah proyek, mulai dari versi target JavaScript hingga aturan ketat pengecekan kode.

### Analogi

Bayangkan seorang **Penerjemah Bahasa**:

- **File .ts**: Adalah naskah asli dalam bahasa yang sangat formal dan teknis.
    
- **tsconfig.json**: Adalah **Buku Panduan Instruksi** untuk si penerjemah. Di dalamnya tertulis: "Terjemahkan naskah ini ke bahasa gaul tahun 2015 (ES6)", "Jangan biarkan ada kata yang ambigu (Strict Mode)", dan "Simpan hasil terjemahannya di folder khusus (OutDir)". Tanpa panduan ini, si penerjemah akan bingung harus menggunakan gaya bahasa yang mana.
    

### Poin-Poin Penting

Ada beberapa opsi utama yang sering kamu modifikasi dalam proyek NestJS:

- **`target`**: Menentukan versi JavaScript hasil _compile_ (misal: `ES2021` atau `ESNext`).
    
- **`module`**: Mengatur sistem modul yang digunakan (NestJS biasanya menggunakan `commonjs`).
    
- **`outDir`**: Menentukan folder tempat menyimpan file `.js` hasil kompilasi (biasanya folder `dist`).
    
- **`rootDir`**: Menentukan di mana lokasi file sumber `.ts` (biasanya folder `src`).
    
- **`strict`**: Jika `true`, TypeScript akan sangat galak dan memastikan tidak ada tipe data yang tidak jelas atau berpotensi error.
    
- **`experimentalDecorators`**: Harus bernilai `true` agar fitur dekorator (`@`) di NestJS bisa berfungsi.
    
- **`emitMetadata`**: Diperlukan NestJS untuk proses _Dependency Injection_.
    

### Contoh Implementasi

Berikut adalah potongan isi `tsconfig.json` yang umum digunakan pada project NestJS:

JSON

```
{
  "compilerOptions": {
    "module": "commonjs",
    "declaration": true,
    "removeComments": true,
    "emitDecoratorMetadata": true,
    "experimentalDecorators": true,
    "allowSyntheticDefaultImports": true,
    "target": "ES2021",
    "sourceMap": true,
    "outDir": "./dist",
    "baseUrl": "./",
    "incremental": true,
    "skipLibCheck": true,
    "strictNullChecks": false,
    "noImplicitAny": false,
    "strictBindCallApply": false,
    "forceConsistentCasingInFileNames": false,
    "noFallthroughCasesInSwitch": false
  }
}
```

### Koneksi dengan Web Development (NestJS)

Mengapa file ini sangat vital di NestJS?

1. **Debugging**: Dengan mengaktifkan `sourceMap: true`, kamu bisa melakukan _debug_ langsung pada file `.ts` meskipun yang berjalan di server adalah file `.js`.
    
2. **Kesiapan Produksi**: Saat kamu menjalankan perintah `npm run build`, compiler akan membaca `outDir` untuk membuang semua kode "sampah" dan menyisakan kode JavaScript murni di folder `dist` yang siap dideploy.
    
3. **Path Mapping**: Kamu bisa membuat alias folder (misal: `@app/*` merujuk ke `src/*`) agar proses _import_ file tidak terlalu panjang (misal: `../../../../service` menjadi `@services/user`).
