## 2.7 Utility Types (Partial, Pick, Omit, Record)

### Definisi Singkat

**Utility Types** adalah fungsi tipe bawaan TypeScript yang menerima satu tipe data sebagai input dan menghasilkan tipe data baru sebagai output berdasarkan aturan tertentu (seperti mengambil sebagian, membuang sebagian, atau mengubah status opsional).

### Analogi

Bayangkan sebuah **Template CV Digital**:

- **`Partial`**: Seperti mencentang mode "Opsional" pada semua kolom. Kamu tidak wajib mengisi alamat atau nomor telepon jika tidak mau.
    
- **`Pick`**: Seperti mencetak CV versi singkat yang **Hanya Mengambil** kolom Nama dan Pengalaman Kerja saja.
    
- **`Omit`**: Seperti mencetak CV namun **Membuang/Menghapus** kolom yang bersifat rahasia seperti Gaji.
    
- **`Record`**: Seperti membuat **Daftar Kontak** di mana setiap Nama (Key) harus berpasangan dengan nomor telepon (Value) yang formatnya seragam.
    

### Poin-Poin Penting

- **`Partial<T>`**: Mengubah semua properti dalam tipe `T` menjadi opsional (`?`).
    
- **`Pick<T, K>`**: Membuat tipe baru dengan hanya mengambil sekumpulan properti `K` dari tipe `T`.
    
- **`Omit<T, K>`**: Membuat tipe baru dengan mengambil semua properti dari `T` kecuali properti `K`.
    
- **`Record<K, T>`**: Membuat tipe objek dengan kunci (_key_) bertipe `K` dan nilai (_value_) bertipe `T`.
    

### Contoh Implementasi

TypeScript

```
interface User {
  id: number;
  name: string;
  email: string;
  role: string;
}

// 1. Partial: Semua jadi opsional (Cocok untuk Update/Patch)
const updateData: Partial<User> = { name: "Budi" }; 

// 2. Pick: Hanya ambil id dan name
const simpleUser: Pick<User, 'id' | 'name'> = { id: 1, name: "Andi" };

// 3. Omit: Ambil semua kecuali email
const publicProfile: Omit<User, 'email'> = { id: 1, name: "Andi", role: "Admin" };

// 4. Record: Membuat objek koleksi (Key: string, Value: User)
const userCache: Record<string, User> = {
  "user_01": { id: 1, name: "Andi", email: "a@b.com", role: "User" }
};
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, utility types adalah kunci dalam pembuatan:

1. **Update DTO (Data Transfer Object)**: Saat membuat fungsi `update`, kita sering menggunakan `PartialType` (versi NestJS dari `Partial`) agar client boleh mengirimkan satu atau dua field saja untuk diupdate.
    
2. **Data Filtering**: Saat ingin mengembalikan data ke client, kita menggunakan `Omit` untuk membuang field sensitif seperti `password` atau `internalNotes`.
    
3. **Mapped Types**: NestJS secara internal menggunakan logika ini untuk menghubungkan _class validation_ dengan tipe data TypeScript.
    
4. **Dictionary Data**: Menggunakan `Record` untuk menyimpan hasil translasi (i18n) atau konfigurasi sistem yang berbentuk pasangan _key-value_.
