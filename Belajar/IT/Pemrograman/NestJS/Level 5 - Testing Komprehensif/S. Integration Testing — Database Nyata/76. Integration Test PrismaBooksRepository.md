# 76. Integration Test PrismaBooksRepository

## Penjelasan

`PrismaBooksRepository` adalah implementasi konkret dari `IBooksRepository` yang berinteraksi langsung dengan database PostgreSQL melalui Prisma ORM. Integration test untuk repository ini memverifikasi bahwa query SQL yang dihasilkan benar, data tersimpan dan terbaca dengan benar, constraint database bekerja (seperti unique constraint pada ISBN), dan error handling untuk kasus seperti koneksi terputus atau data tidak ditemukan berfungsi sebagaimana mestinya. Tidak seperti unit test yang menggunakan mock, integration test menggunakan database nyata yang sudah disiapkan di file 75.

Pendekatan integration test untuk repository menggunakan pola `beforeAll`/`afterAll` untuk setup dan teardown koneksi database, serta `beforeEach`/`afterEach` untuk membersihkan data antar test. Pembersihan data sangat penting karena setiap test harus dimulai dari state yang bersih — tidak ada data sisa dari test sebelumnya. Metode pembersihan yang umum adalah `TRUNCATE TABLE ... CASCADE` atau `DELETE FROM ...`. Untuk Prisma, kita bisa menggunakan `prisma.book.deleteMany()` di `afterEach`. Namun perlu hati-hati dengan referential integrity — urutan penghapusan tabel harus benar.

Salah satu aspek penting dalam integration test repository adalah pengujian constraint database. Misalnya, field `isbn` di tabel book memiliki constraint `UNIQUE`. Jika kita mencoba membuat dua buku dengan ISBN yang sama, database harus melempar error `P2002` (unique constraint violation dari Prisma). Integration test memverifikasi bahwa repository menangkap error Prisma ini dan mengubahnya menjadi exception yang sesuai (seperti `ConflictException`). Hal yang sama berlaku untuk constraint `NOT NULL`, foreign key, dan constraint validasi lainnya yang didefinisikan di schema Prisma.

## Fungsi

- Memverifikasi operasi CRUD dasar: create, findById, findAll, update, delete
- Menguji constraint database: unique ISBN, NOT NULL, foreign key
- Memvalidasi error handling: data tidak ditemukan, duplicate entry
- Menguji query filtering dan sorting: findAll dengan pagination, filter by genre
- Memverifikasi interaksi Prisma: transaction, select fields, include relations
- Mendeteksi masalah mapping antara entity TypeScript dan tabel database

### 1. Test Module Setup

```typescript
// test/integration/prisma-books.repository.spec.ts
import { Test, TestingModule } from '@nestjs/testing';
import { PrismaClient } from '@prisma/client';
import { PrismaBooksRepository } from '../../src/books/repositories/prisma-books.repository';
import { PrismaModule } from '../../src/prisma/prisma.module';
import { PrismaService } from '../../src/prisma/prisma.service';
import { CreateBookDto } from '../../src/books/dto/create-book.dto';
import { UpdateBookDto } from '../../src/books/dto/update-book.dto';

describe('PrismaBooksRepository (Integration)', () => {
  let repository: PrismaBooksRepository;
  let prisma: PrismaClient;
  let moduleRef: TestingModule;

  // Data test yang akan digunakan
  const testBook = {
    title: 'Test Driven Development',
    author: 'Kent Beck',
    isbn: '978-0321146533',
    publishedYear: 2002,
    genre: 'Software Engineering',
    stock: 3,
  };

  beforeAll(async () => {
    // Kompilasi modul NestJS dengan dependency nyata
    moduleRef = await Test.createTestingModule({
      imports: [PrismaModule],
      providers: [PrismaBooksRepository],
    }).compile();

    repository = moduleRef.get<PrismaBooksRepository>(PrismaBooksRepository);
    prisma = moduleRef.get<PrismaService>(PrismaService);
  });

  afterAll(async () => {
    await moduleRef.close();
  });

  // Bersihkan data sebelum setiap test
  beforeEach(async () => {
    await prisma.book.deleteMany();
  });

  // ============== CREATE ==============

  describe('create', () => {
    it('should create a new book in the database', async () => {
      const dto: CreateBookDto = { ...testBook };

      const result = await repository.create(dto);

      expect(result).toBeDefined();
      expect(result.id).toBeDefined();
      expect(result.title).toBe('Test Driven Development');
      expect(result.author).toBe('Kent Beck');
      expect(result.isbn).toBe('978-0321146533');
      expect(result.createdAt).toBeInstanceOf(Date);
      expect(result.updatedAt).toBeInstanceOf(Date);
    });

    it('should throw ConflictException when ISBN already exists', async () => {
      const dto: CreateBookDto = { ...testBook };

      // Buat buku pertama
      await repository.create(dto);

      // Coba buat buku kedua dengan ISBN yang sama
      await expect(repository.create(dto)).rejects.toThrow();
      // Prisma error code P2002 = unique constraint violation
    });

    it('should create a book with minimal fields', async () => {
      const minimalDto: CreateBookDto = {
        title: 'Minimal Book',
        author: 'Author',
        isbn: '978-0000000001',
        publishedYear: 2024,
        genre: 'Fiction',
        stock: 0,
      };

      const result = await repository.create(minimalDto);

      expect(result.title).toBe('Minimal Book');
      expect(result.stock).toBe(0);
    });
  });

  // ============== FIND BY ID ==============

  describe('findById', () => {
    it('should find a book by its ID', async () => {
      const created = await repository.create({ ...testBook });

      const result = await repository.findById(created.id);

      expect(result).toBeDefined();
      expect(result!.id).toBe(created.id);
      expect(result!.title).toBe(created.title);
    });

    it('should return null when book does not exist', async () => {
      const result = await repository.findById('non-existent-id');

      expect(result).toBeNull();
    });

    it('should return null for empty string ID', async () => {
      const result = await repository.findById('');

      expect(result).toBeNull();
    });
  });

  // ============== FIND BY ISBN ==============

  describe('findByIsbn', () => {
    it('should find a book by its ISBN', async () => {
      await repository.create({ ...testBook });

      const result = await repository.findByIsbn('978-0321146533');

      expect(result).toBeDefined();
      expect(result!.isbn).toBe('978-0321146533');
    });

    it('should return null when ISBN does not exist', async () => {
      const result = await repository.findByIsbn('978-0000000000');

      expect(result).toBeNull();
    });
  });

  // ============== FIND ALL ==============

  describe('findAll', () => {
    it('should return all books', async () => {
      await repository.create({ ...testBook });
      await repository.create({
        title: 'Clean Code',
        author: 'Robert C. Martin',
        isbn: '978-0132350884',
        publishedYear: 2008,
        genre: 'Software Engineering',
        stock: 5,
      });

      const result = await repository.findAll();

      expect(result).toHaveLength(2);
    });

    it('should return empty array when no books exist', async () => {
      const result = await repository.findAll();

      expect(result).toEqual([]);
    });

    it('should return books sorted by createdAt descending', async () => {
      const book1 = await repository.create({ ...testBook });

      // Tunggu sebentar agar createdAt berbeda
      await new Promise((r) => setTimeout(r, 10));

      const book2 = await repository.create({
        title: 'Refactoring',
        author: 'Martin Fowler',
        isbn: '978-0201485677',
        publishedYear: 1999,
        genre: 'Software Engineering',
        stock: 2,
      });

      const result = await repository.findAll();

      expect(result[0].id).toBe(book2.id); // Terbaru di index 0
      expect(result[1].id).toBe(book1.id);
    });
  });

  // ============== UPDATE ==============

  describe('update', () => {
    it('should update a book successfully', async () => {
      const created = await repository.create({ ...testBook });
      const updateDto: UpdateBookDto = {
        title: 'TDD (Updated Edition)',
        stock: 10,
      };

      const result = await repository.update(created.id, updateDto);

      expect(result.title).toBe('TDD (Updated Edition)');
      expect(result.stock).toBe(10);
      expect(result.author).toBe('Kent Beck'); // Field lain tidak berubah
    });

    it('should throw NotFoundException when updating non-existent book', async () => {
      const updateDto: UpdateBookDto = { title: 'New Title' };

      await expect(
        repository.update('non-existent-id', updateDto),
      ).rejects.toThrow();
    });

    it('should update only provided fields', async () => {
      const created = await repository.create({ ...testBook });
      const updateDto: UpdateBookDto = { stock: 100 };

      const result = await repository.update(created.id, updateDto);

      expect(result.stock).toBe(100);
      expect(result.title).toBe('Test Driven Development'); // Tidak berubah
    });
  });

  // ============== DELETE ==============

  describe('delete', () => {
    it('should delete a book successfully', async () => {
      const created = await repository.create({ ...testBook });

      await repository.delete(created.id);

      const found = await repository.findById(created.id);
      expect(found).toBeNull();
    });

    it('should throw NotFoundException when deleting non-existent book', async () => {
      await expect(repository.delete('non-existent-id')).rejects.toThrow();
    });

    it('should not affect other books when deleting', async () => {
      const book1 = await repository.create({ ...testBook });
      const book2 = await repository.create({
        title: 'Clean Code',
        author: 'Robert C. Martin',
        isbn: '978-0132350884',
        publishedYear: 2008,
        genre: 'Software Engineering',
        stock: 5,
      });

      await repository.delete(book1.id);

      const allBooks = await repository.findAll();
      expect(allBooks).toHaveLength(1);
      expect(allBooks[0].id).toBe(book2.id);
    });
  });

  // ============== BULK OPERATIONS ==============

  describe('bulk operations', () => {
    it('should handle creating many books in sequence', async () => {
      const books = [
        { ...testBook },
        {
          title: 'Clean Code',
          author: 'Robert C. Martin',
          isbn: '978-0132350884',
          publishedYear: 2008,
          genre: 'Software Engineering',
          stock: 5,
        },
      ];

      for (const book of books) {
        await repository.create(book);
      }

      const result = await repository.findAll();
      expect(result).toHaveLength(2);
    });

    it('should rollback on duplicate ISBN in sequence', async () => {
      await repository.create({ ...testBook });

      await expect(repository.create({ ...testBook })).rejects.toThrow();

      // Pastikan hanya ada 1 buku
      const result = await repository.findAll();
      expect(result).toHaveLength(1);
    });
  });

  // ============== EDGE CASES ==============

  describe('edge cases', () => {
    it('should handle books with very long title', async () => {
      const longTitle = 'A'.repeat(500);
      const dto: CreateBookDto = {
        title: longTitle,
        author: 'Author',
        isbn: '978-9999999999',
        publishedYear: 2024,
        genre: 'Fiction',
        stock: 1,
      };

      const result = await repository.create(dto);
      expect(result.title).toBe(longTitle);
    });

    it('should handle ISBN with leading/trailing whitespace', async () => {
      const dto: CreateBookDto = {
        ...testBook,
        isbn: '  978-0321146533  ',
      };

      const result = await repository.create(dto);

      // Database mungkin menyimpan dengan spasi, tergantung implementasi
      expect(result.isbn).toBeDefined();
    });
  });
});
```

## Analogi

Bayangkan perpustakaan ingin menguji **sistem pencatatan peminjaman buku yang baru**. Kali ini, mereka tidak menggunakan kertas catatan palsu (mock), melainkan **buku besar asli** yang sama dengan yang digunakan sehari-hari. Mereka mengambil sebuah **buku besar kosong (test database)** dan mencoba menulis data peminjaman (create), mencari catatan (findById), memperbarui status pengembalian (update), dan menghapus catatan yang salah (delete). Mereka juga sengaja membuat kesalahan — menulis dua catatan dengan ID anggota yang sama (constraint) — untuk melihat apakah sistem menolaknya. Setelah semua pengujian selesai, mereka menghapus semua catatan uji coba dari buku besar (cleanup), meninggalkannya dalam keadaan bersih untuk pengujian berikutnya. Hasilnya, staf perpustakaan yakin bahwa sistem pencatatan benar-benar berfungsi dengan buku besar sungguhan, bukan hanya di atas kertas.

## Penggunaan

- Memvalidasi implementasi repository sebelum digunakan di production
- Mendeteksi masalah mapping data antara TypeScript dan PostgreSQL
- Memastikan constraint database (unique, not null) di-handle dengan benar
- Verifikasi migration Prisma sesuai dengan kode repository
- Regression test saat mengubah schema database

## Kesalahan Umum yang Sering Terjadi

1. **Data test tidak independen**: Test saling mempengaruhi karena data dari test sebelumnya tidak dihapus. Solusi: selalu panggil `prisma.book.deleteMany()` (atau truncate) di `beforeEach`.

2. **Menggunakan ID statis**: Test menggunakan ID hardcoded yang mungkin sudah ada di database. Solusi: selalu gunakan ID yang dikembalikan dari operasi `create` atau gunakan UUID generator.

3. **Tidak mengurutkan hasil query**: `findAll` mengembalikan data dalam urutan tak tentu, menyebabkan test flaky. Solusi: tambahkan `orderBy` di query atau sort hasil di test assertion.

4. **Test untuk error handling tidak spesifik**: Hanya assert `rejects.toThrow()` tanpa memeriksa tipe error atau pesan yang spesifik. Solusi: tambahkan assertion spesifik seperti `rejects.toThrow(ConflictException)`.

5. **Lupa menjalankan migrasi**: Database test tidak memiliki tabel yang diperlukan. Solusi: otomatisasi migrasi di `globalSetup` atau dokumentasikan langkahnya dengan jelas.

6. **Koneksi database tidak ditutup**: Proses Jest tidak keluar setelah test. Solusi: panggil `moduleRef.close()` di `afterAll` dan set `forceExit: true` di Jest config.
