# 71. Unit Test BooksService — Mock Repository dengan Jest

## Penjelasan

Unit testing adalah pengujian pada level terkecil dari aplikasi — biasanya sebuah method dalam class — dengan mengisolasi komponen tersebut dari dependency eksternalnya. Dalam konteks NestJS, `BooksService` memiliki dependency ke `IBooksRepository` (abstraksi database), `CacheManager` (Redis), dan kemungkinan `Logger`. Untuk menguji `BooksService` secara murni, kita perlu **mock** semua dependency tersebut sehingga test hanya menguji logika bisnis di dalam service, bukan integrasi dengan database atau cache.

Mocking dilakukan dengan `jest.fn()` atau `jest.spyOn()` untuk menggantikan fungsi asli dengan implementasi palsu. Kita bisa mengontrol apa yang dikembalikan oleh mock (return value), apakah mock throws error, atau apakah mock dipanggil dengan argumen tertentu. Teknik ini memungkinkan kita mensimulasikan skenario sukses, skenario gagal, edge cases, dan exception tanpa harus benar-benar terhubung ke database atau Redis. Pendekatan ini membuat test berjalan sangat cepat (milidetik) dan deterministik.

Dalam testing NestJS, kita menggunakan `Test.createTestingModule` untuk membuat modul testing yang mirip dengan modul asli tetapi dengan provider yang di-mock. Kita mengganti `IBooksRepository` dengan object mock yang berisi method-method seperti `create`, `findById`, `findAll`, `update`, dan `delete`. Setiap method mock bisa dikonfigurasi per-test case menggunakan `mockResolvedValue` (untuk Promise) atau `mockReturnValue` (untuk synchronous). Ini memberikan fleksibilitas penuh untuk menguji semua jalur kode, termasuk error handling.

## Fungsi

- Memverifikasi logika bisnis `BooksService` berjalan benar tanpa ketergantungan database
- Menguji skenario sukses: buku berhasil dibuat, ditemukan, diperbarui, dihapus
- Menguji skenario error: buku tidak ditemukan, duplikasi judul, validasi gagal
- Menguji interaksi dengan cache: data diambil dari cache vs dari database
- Memastikan exception handling service berfungsi — error dari repository di-throw dengan benar
- Memberikan feedback cepat saat development (test selesai dalam < 100ms)

### 3. `books.service.spec.ts` — File Utama

```typescript
// src/books/books.service.spec.ts
import { Test, TestingModule } from '@nestjs/testing';
import { NotFoundException, ConflictException } from '@nestjs/common';
import { BooksService } from './books.service';
import { CreateBookDto } from './dto/create-book.dto';
import { UpdateBookDto } from './dto/update-book.dto';
import { IBooksRepository } from './repositories/books.repository.interface';
import { CACHE_MANAGER } from '@nestjs/cache-manager';
import { mockBook, mockBooksRepository, mockCacheManager } from '../../test/mocks/repositories.mock';
import { Book } from './entities/book.entity';

describe('BooksService', () => {
  let service: BooksService;
  let repository: jest.Mocked<IBooksRepository>;
  let cacheManager: jest.Mocked<typeof mockCacheManager>;

  beforeEach(async () => {
    const module: TestingModule = await Test.createTestingModule({
      providers: [
        BooksService,
        {
          provide: 'IBooksRepository',
          useValue: mockBooksRepository,
        },
        {
          provide: CACHE_MANAGER,
          useValue: mockCacheManager,
        },
      ],
    }).compile();

    service = module.get<BooksService>(BooksService);
    repository = module.get('IBooksRepository') as jest.Mocked<IBooksRepository>;
    cacheManager = module.get(CACHE_MANAGER) as jest.Mocked<typeof mockCacheManager>;

    // Reset semua mock sebelum setiap test
    jest.clearAllMocks();
  });

  // ============== CREATE ==============

  describe('create', () => {
    it('should create a book successfully', async () => {
      const dto: CreateBookDto = {
        title: 'NestJS Mastery',
        author: 'John Doe',
        isbn: '978-1234567890',
        publishedYear: 2024,
        genre: 'Technology',
        stock: 5,
      };

      repository.findByIsbn.mockResolvedValue(null);
      repository.create.mockResolvedValue(mockBook);

      const result = await service.create(dto);

      expect(result).toEqual(mockBook);
      expect(repository.findByIsbn).toHaveBeenCalledWith(dto.isbn);
      expect(repository.create).toHaveBeenCalledWith(dto);
      expect(cacheManager.del).toHaveBeenCalledWith('books:all');
    });

    it('should throw ConflictException if ISBN already exists', async () => {
      const dto: CreateBookDto = {
        title: 'NestJS Mastery',
        author: 'John Doe',
        isbn: '978-1234567890',
        publishedYear: 2024,
        genre: 'Technology',
        stock: 5,
      };

      repository.findByIsbn.mockResolvedValue(mockBook);

      await expect(service.create(dto)).rejects.toThrow(ConflictException);
      expect(repository.create).not.toHaveBeenCalled();
    });

    it('should propagate repository error on create', async () => {
      const dto: CreateBookDto = {
        title: 'NestJS Mastery',
        author: 'John Doe',
        isbn: '978-1234567890',
        publishedYear: 2024,
        genre: 'Technology',
        stock: 5,
      };

      repository.findByIsbn.mockResolvedValue(null);
      repository.create.mockRejectedValue(new Error('Database connection lost'));

      await expect(service.create(dto)).rejects.toThrow('Database connection lost');
    });
  });

  // ============== FIND ALL ==============

  describe('findAll', () => {
    it('should return books from cache if available', async () => {
      const cachedBooks: Book[] = [mockBook];
      cacheManager.get.mockResolvedValue(cachedBooks);

      const result = await service.findAll();

      expect(result).toEqual(cachedBooks);
      expect(cacheManager.get).toHaveBeenCalledWith('books:all');
      expect(repository.findAll).not.toHaveBeenCalled();
    });

    it('should fetch books from repository and cache them', async () => {
      cacheManager.get.mockResolvedValue(null);
      repository.findAll.mockResolvedValue([mockBook]);

      const result = await service.findAll();

      expect(result).toEqual([mockBook]);
      expect(repository.findAll).toHaveBeenCalled();
      expect(cacheManager.set).toHaveBeenCalledWith(
        'books:all',
        [mockBook],
        expect.any(Number),
      );
    });
  });

  // ============== FIND BY ID ==============

  describe('findById', () => {
    it('should return a book by ID', async () => {
      repository.findById.mockResolvedValue(mockBook);

      const result = await service.findById(mockBook.id);

      expect(result).toEqual(mockBook);
      expect(repository.findById).toHaveBeenCalledWith(mockBook.id);
    });

    it('should throw NotFoundException if book not found', async () => {
      repository.findById.mockResolvedValue(null);

      await expect(service.findById('non-existent-id')).rejects.toThrow(
        NotFoundException,
      );
    });
  });

  // ============== UPDATE ==============

  describe('update', () => {
    it('should update a book successfully', async () => {
      const dto: UpdateBookDto = { title: 'NestJS Advanced' };
      const updatedBook = { ...mockBook, title: 'NestJS Advanced' };

      repository.findById.mockResolvedValue(mockBook);
      repository.update.mockResolvedValue(updatedBook);

      const result = await service.update(mockBook.id, dto);

      expect(result.title).toBe('NestJS Advanced');
      expect(repository.findById).toHaveBeenCalledWith(mockBook.id);
      expect(repository.update).toHaveBeenCalledWith(mockBook.id, dto);
      expect(cacheManager.del).toHaveBeenCalledWith('books:all');
    });

    it('should throw NotFoundException if book to update does not exist', async () => {
      repository.findById.mockResolvedValue(null);

      await expect(
        service.update('non-existent-id', { title: 'Test' }),
      ).rejects.toThrow(NotFoundException);
    });
  });

  // ============== DELETE ==============

  describe('delete', () => {
    it('should delete a book successfully', async () => {
      repository.findById.mockResolvedValue(mockBook);
      repository.delete.mockResolvedValue(undefined);

      await service.delete(mockBook.id);

      expect(repository.findById).toHaveBeenCalledWith(mockBook.id);
      expect(repository.delete).toHaveBeenCalledWith(mockBook.id);
      expect(cacheManager.del).toHaveBeenCalledWith('books:all');
    });

    it('should throw NotFoundException if book to delete does not exist', async () => {
      repository.findById.mockResolvedValue(null);

      await expect(service.delete('non-existent-id')).rejects.toThrow(
        NotFoundException,
      );
    });
  });
});
```

## Analogi

Bayangkan perpustakaan ingin menguji **petugas loket** tanpa mengganggu seluruh sistem. Petugas loket (BooksService) bertugas melayani peminjaman, pengembalian, dan pencarian buku. Untuk mengujinya secara terisolasi, kita menggunakan **pengunjung palsu** (mock repository) yang datanya sudah kita ketahui sebelumnya. Pengunjung palsu ini selalu memberikan jawaban yang bisa diprediksi: ketika ditanya "apakah buku ini ada?", dia bilang "ada" atau "tidak ada" sesuai keinginan kita. Kita juga menggunakan **katalog palsu** (mock cache) yang menyimpan catatan sementara. Dengan cara ini, kita bisa menguji apakah petugas loket memberikan respons yang benar (menerima buku, menolak duplikasi, melaporkan buku hilang) tanpa harus menunggu pengunjung sungguhan datang atau mengakses database asli.

## Penggunaan

- Digunakan saat menulis fitur baru untuk memvalidasi logika bisnis sebelum integrasi
- Dipakai di development loop (test watch) untuk feedback cepat saat refactoring
- Menguji edge cases seperti buku tidak ditemukan, ISBN duplikat, atau database error
- Memvalidasi interaksi dengan cache — apakah data disimpan/dihapus dari cache dengan benar
- Sebagai dokumentasi hidup yang menunjukkan bagaimana service seharusnya digunakan

## Kesalahan Umum yang Sering Terjadi

1. **Mock tidak di-reset antar test**: Test menjadi flaky karena mock masih menyimpan state dari test sebelumnya. Solusi: gunakan `jest.clearAllMocks()` atau `beforeEach` untuk reset semua mock.

2. **Mock method tidak dikembalikan Promise**: `repository.findById` mengembalikan Promise, tapi mock menggunakan `mockReturnValue` bukan `mockResolvedValue`. Solusi: selalu gunakan `mockResolvedValue` untuk async method.

3. **Over-mocking**: Terlalu banyak mock membuat test rapuh — perubahan kecil pada implementasi mematahkan test. Solusi: mock hanya dependency langsung service, bukan dependency dari dependency.

4. **Test assertion kurang spesifik**: Hanya assert result tanpa memeriksa interaksi mock (apakah method dipanggil dengan argumen yang benar). Solusi: tambahkan `toHaveBeenCalledWith` untuk memverifikasi argumen.

5. **Mengabaikan test case negatif**: Hanya menulis test untuk skenario sukses, lupa menguji error handling. Solusi: setiap method harus memiliki minimal satu test case gagal.
