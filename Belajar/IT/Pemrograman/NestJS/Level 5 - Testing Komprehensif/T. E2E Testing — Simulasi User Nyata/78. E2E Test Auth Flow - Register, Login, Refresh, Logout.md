# 78. E2E Test Auth Flow — Register, Login, Refresh, Logout

## Penjelasan

Auth flow adalah fondasi keamanan aplikasi NestJS. E2E test untuk auth flow menguji seluruh siklus hidup autentikasi pengguna dari awal hingga akhir: registrasi akun baru, login dengan kredensial yang benar, mendapatkan access token dan refresh token, menggunakan refresh token untuk memperbarui access token yang expired, dan logout yang menghapus refresh token. Setiap langkah dalam flow ini harus diuji secara berurutan maupun terpisah untuk memastikan tidak ada celah keamanan.

Pengujian auth flow memerlukan perhatian khusus pada state token. Access token umumnya memiliki masa berlaku singkat (15 menit), sementara refresh token lebih lama (7 hari). Dalam E2E test, kita perlu memverifikasi bahwa access token yang expired benar-benar ditolak, dan refresh token yang valid bisa menghasilkan access token baru. Kita juga perlu menguji skenario keamanan seperti registrasi dengan email yang sudah terdaftar (409 Conflict), login dengan password salah (401 Unauthorized), dan akses ke endpoint terproteksi tanpa token (401 Unauthorized).

Implementasi E2E test auth flow menggunakan `supertest` untuk mengirim request HTTP ke aplikasi NestJS. Setiap test case harus independen — data pengguna dibuat, digunakan, dan dibersihkan dalam satu test case atau dibersihkan di `afterEach`. Kita menggunakan helper method untuk menyederhanakan operasi berulang seperti registrasi dan login. Penting untuk menyimpan token yang dihasilkan dari login dan menggunakannya di request berikutnya dalam flow yang sama.

## Fungsi

- Memvalidasi seluruh siklus auth: register → login → refresh → logout
- Menguji validasi input: email format, password strength, field required
- Memverifikasi error handling: duplicate email, wrong password, invalid token
- Menguji token lifecycle: access token expired, refresh token rotation
- Memastikan endpoint terproteksi benar-benar memblokir request tanpa token
- Mendokumentasikan flow autentikasi lengkap sebagai acceptance criteria

### 1. `test/auth.e2e-spec.ts` — Auth Flow Lengkap

```typescript
// test/auth.e2e-spec.ts
import { INestApplication, ValidationPipe } from '@nestjs/common';
import { Test, TestingModule } from '@nestjs/testing';
import * as request from 'supertest';
import * as cookieParser from 'cookie-parser';
import { AppModule } from '../src/app.module';
import { PrismaService } from '../src/prisma/prisma.service';
import { GlobalExceptionFilter } from '../src/common/filters/global-exception.filter';

describe('Auth Flow (E2E)', () => {
  let app: INestApplication;
  let prisma: PrismaService;
  let httpServer: any;

  // Data test
  const testUser = {
    email: 'e2e-test@example.com',
    password: 'StrongPass123!',
    name: 'E2E Test User',
  };

  beforeAll(async () => {
    const moduleFixture: TestingModule = await Test.createTestingModule({
      imports: [AppModule],
    }).compile();

    app = moduleFixture.createNestApplication();
    app.useGlobalPipes(
      new ValidationPipe({
        whitelist: true,
        forbidNonWhitelisted: true,
        transform: true,
      }),
    );
    app.useGlobalFilters(new GlobalExceptionFilter());
    app.use(cookieParser());
    app.setGlobalPrefix('api');

    await app.init();
    httpServer = app.getHttpServer();
    prisma = app.get<PrismaService>(PrismaService);
  });

  afterAll(async () => {
    await prisma.user.deleteMany({
      where: { email: { contains: 'e2e-test' } },
    });
    await app.close();
  });

  // Bersihkan data test sebelum setiap test
  beforeEach(async () => {
    await prisma.user.deleteMany({
      where: { email: { contains: 'e2e-test' } },
    });
  });

  // ============== REGISTER ==============

  describe('POST /api/auth/register', () => {
    it('should register a new user successfully', async () => {
      const response = await request(httpServer)
        .post('/api/auth/register')
        .send(testUser)
        .expect(201);

      expect(response.body).toHaveProperty('accessToken');
      expect(response.body).toHaveProperty('refreshToken');
      expect(response.body.user).toBeDefined();
      expect(response.body.user.email).toBe(testUser.email);
      expect(response.body.user.name).toBe(testUser.name);
      // Password tidak boleh dikembalikan
      expect(response.body.user).not.toHaveProperty('password');
    });

    it('should reject registration with duplicate email', async () => {
      // Register pertama
      await request(httpServer)
        .post('/api/auth/register')
        .send(testUser)
        .expect(201);

      // Register kedua — harus gagal
      const response = await request(httpServer)
        .post('/api/auth/register')
        .send(testUser)
        .expect(409);

      expect(response.body.message).toContain('email') ||
        expect(response.body.message).toContain('already exists');
    });

    it('should reject registration with invalid email', async () => {
      const response = await request(httpServer)
        .post('/api/auth/register')
        .send({
          email: 'invalid-email',
          password: 'StrongPass123!',
          name: 'Test User',
        })
        .expect(400);

      expect(response.body.message).toEqual(
        expect.arrayContaining([expect.stringContaining('email')]),
      );
    });

    it('should reject registration with weak password', async () => {
      const response = await request(httpServer)
        .post('/api/auth/register')
        .send({
          email: 'weak@example.com',
          password: '123',
          name: 'Test User',
        })
        .expect(400);

      expect(response.body.message).toEqual(
        expect.arrayContaining([expect.stringContaining('password')]),
      );
    });

    it('should reject registration without required fields', async () => {
      const response = await request(httpServer)
        .post('/api/auth/register')
        .send({})
        .expect(400);

      expect(Array.isArray(response.body.message)).toBe(true);
      expect(response.body.message.length).toBeGreaterThanOrEqual(1);
    });
  });

  // ============== LOGIN ==============

  describe('POST /api/auth/login', () => {
    beforeEach(async () => {
      // Setup: register user sebelum login test
      await request(httpServer)
        .post('/api/auth/register')
        .send(testUser);
    });

    it('should login successfully with valid credentials', async () => {
      const response = await request(httpServer)
        .post('/api/auth/login')
        .send({
          email: testUser.email,
          password: testUser.password,
        })
        .expect(200);

      expect(response.body).toHaveProperty('accessToken');
      expect(response.body).toHaveProperty('refreshToken');
      expect(response.body.user.email).toBe(testUser.email);
    });

    it('should reject login with wrong password', async () => {
      const response = await request(httpServer)
        .post('/api/auth/login')
        .send({
          email: testUser.email,
          password: 'WrongPassword!',
        })
        .expect(401);

      expect(response.body.message).toContain('Invalid') ||
        expect(response.body.message).toContain('wrong');
    });

    it('should reject login for non-existent email', async () => {
      const response = await request(httpServer)
        .post('/api/auth/login')
        .send({
          email: 'nonexistent@example.com',
          password: testUser.password,
        })
        .expect(401);
    });

    it('should return consistent response structure on success', async () => {
      const response = await request(httpServer)
        .post('/api/auth/login')
        .send({
          email: testUser.email,
          password: testUser.password,
        });

      expect(response.body).toMatchObject({
        accessToken: expect.any(String),
        refreshToken: expect.any(String),
        user: {
          id: expect.any(String),
          email: testUser.email,
          name: testUser.name,
        },
      });
    });
  });

  // ============== REFRESH TOKEN ==============

  describe('POST /api/auth/refresh', () => {
    let currentRefreshToken: string;

    beforeEach(async () => {
      // Setup: register & login untuk mendapatkan refresh token
      await request(httpServer)
        .post('/api/auth/register')
        .send(testUser);

      const loginResponse = await request(httpServer)
        .post('/api/auth/login')
        .send({
          email: testUser.email,
          password: testUser.password,
        });

      currentRefreshToken = loginResponse.body.refreshToken;
    });

    it('should refresh tokens successfully', async () => {
      const response = await request(httpServer)
        .post('/api/auth/refresh')
        .send({ refreshToken: currentRefreshToken })
        .expect(200);

      expect(response.body).toHaveProperty('accessToken');
      expect(response.body).toHaveProperty('refreshToken');
      // Refresh token baru harus berbeda dari yang lama (rotation)
      expect(response.body.refreshToken).not.toBe(currentRefreshToken);
    });

    it('should reject expired refresh token', async () => {
      // Token expired: 'eyJ...' (token palsu)
      const expiredToken = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiJ0ZXN0IiwiZXhwIjoxNTE2MjM5MDIyfQ';

      const response = await request(httpServer)
        .post('/api/auth/refresh')
        .send({ refreshToken: expiredToken })
        .expect(401);
    });

    it('should reject invalid refresh token format', async () => {
      const response = await request(httpServer)
        .post('/api/auth/refresh')
        .send({ refreshToken: 'invalid-token-format' })
        .expect(401);
    });

    it('should reject already-used refresh token (rotation)', async () => {
      // Gunakan refresh token pertama kali — sukses
      const firstRefresh = await request(httpServer)
        .post('/api/auth/refresh')
        .send({ refreshToken: currentRefreshToken })
        .expect(200);

      // Gunakan refresh token yang SAMA kedua kali — harus gagal (rotation)
      const secondRefresh = await request(httpServer)
        .post('/api/auth/refresh')
        .send({ refreshToken: currentRefreshToken })
        .expect(401);

      // Tapi token baru dari firstRefresh harus valid
      await request(httpServer)
        .post('/api/auth/refresh')
        .send({ refreshToken: firstRefresh.body.refreshToken })
        .expect(200);
    });

    it('should reject empty refresh token', async () => {
      await request(httpServer)
        .post('/api/auth/refresh')
        .send({})
        .expect(400);
    });
  });

  // ============== LOGOUT ==============

  describe('POST /api/auth/logout', () => {
    let accessToken: string;

    beforeEach(async () => {
      // Setup: register & login
      await request(httpServer)
        .post('/api/auth/register')
        .send(testUser);

      const loginResponse = await request(httpServer)
        .post('/api/auth/login')
        .send({
          email: testUser.email,
          password: testUser.password,
        });

      accessToken = loginResponse.body.accessToken;
    });

    it('should logout successfully', async () => {
      const response = await request(httpServer)
        .post('/api/auth/logout')
        .set('Authorization', `Bearer ${accessToken}`)
        .expect(200);

      expect(response.body.message).toContain('success') ||
        expect(response.body.message).toContain('logout');
    });

    it('should invalidate refresh token after logout', async () => {
      const loginResponse = await request(httpServer)
        .post('/api/auth/login')
        .send({
          email: testUser.email,
          password: testUser.password,
        });

      const refreshToken = loginResponse.body.refreshToken;

      // Logout
      await request(httpServer)
        .post('/api/auth/logout')
        .set('Authorization', `Bearer ${loginResponse.body.accessToken}`)
        .expect(200);

      // Coba refresh dengan token yang sudah di-invalidate
      await request(httpServer)
        .post('/api/auth/refresh')
        .send({ refreshToken })
        .expect(401);
    });

    it('should reject logout without authentication', async () => {
      await request(httpServer)
        .post('/api/auth/logout')
        .expect(401);
    });

    it('should reject logout with invalid token', async () => {
      await request(httpServer)
        .post('/api/auth/logout')
        .set('Authorization', 'Bearer invalid-token')
        .expect(401);
    });
  });

  // ============== PROTECTED ENDPOINT ACCESS ==============

  describe('Protected Endpoint Access', () => {
    it('should allow access with valid access token', async () => {
      // Register & login
      await request(httpServer)
        .post('/api/auth/register')
        .send(testUser);

      const loginResponse = await request(httpServer)
        .post('/api/auth/login')
        .send({
          email: testUser.email,
          password: testUser.password,
        });

      const accessToken = loginResponse.body.accessToken;

      // Akses protected endpoint
      const response = await request(httpServer)
        .get('/api/books')
        .set('Authorization', `Bearer ${accessToken}`);

      expect([200, 403]).toContain(response.status);
    });

    it('should deny access without token (401)', async () => {
      await request(httpServer)
        .get('/api/books')
        .expect(401);
    });

    it('should deny access with malformed token', async () => {
      await request(httpServer)
        .get('/api/books')
        .set('Authorization', 'Bearer ')
        .expect(401);
    });
  });
});
```

## Analogi

Bayangkan perpustakaan memiliki **sistem keanggotaan elektronik** baru. Seorang penguji berperan sebagai **pengunjung baru** yang ingin mendaftar menjadi anggota. Pengunjung mengisi formulir (register), mendapatkan kartu anggota sementara (access token) dan kartu akses jangka panjang (refresh token). Kemudian pengunjung masuk perpustakaan (login) dengan menunjukkan kartu. Setelah kartu sementara habis masa berlakunya, pengunjung menggunakan kartu jangka panjang untuk mendapatkan kartu sementara baru (refresh). Sebelum pulang, pengunjung mengembalikan kedua kartu (logout). Penguji juga mencoba berbagai skenario nakal: mendaftar dengan nama yang sama, masuk dengan kata sandi yang salah, menggunakan kartu yang sudah dikembalikan, dan mencoba masuk tanpa kartu sama sekali. Semua skenario ini diuji untuk memastikan sistem keanggotaan benar-benar aman.

## Penggunaan

- Validasi lengkap flow autentikasi sebelum deployment
- Regression test saat mengubah strategi JWT (misalnya dari access+refresh ke session-based)
- Memastikan token rotation berfungsi untuk mencegah replay attack
- Verifikasi bahwa error response auth tidak membocorkan informasi sensitif
- Acceptance criteria untuk fitur autentikasi

## Kesalahan Umum yang Sering Terjadi

1. **Test tidak independen**: Data user dari test sebelumnya masih ada di database. Solusi: hapus data test di `beforeEach` menggunakan prisma.

2. **Token tidak disimpan dengan benar**: Token dari response login tidak disimpan ke variabel untuk digunakan di test berikutnya. Solusi: simpan token di variabel `let` di level describe.

3. **Tidak menguji token rotation**: Setelah refresh token digunakan, token lama seharusnya tidak bisa dipakai lagi. Banyak developer lupa menguji skenario ini. Solusi: tambahkan test yang menggunakan token lama setelah refresh.

4. **Assertion terlalu umum**: Hanya assert status code 200/401 tanpa memeriksa body response. Solusi: tambahkan assertion untuk format body, termasuk properti seperti `accessToken`, `refreshToken`, dll.

5. **Lupa menunggu Promise**: Async operation tidak di-await, menyebabkan test false positive. Solusi: selalu gunakan `await` untuk request supertest.

6. **Database cleanup tidak sempurna**: Ada data sisa yang menyebabkan test berikutnya gagal. Solusi: gunakan pola `email: { contains: 'e2e-test' }` untuk menghapus semua data test.
