# 21. Serialization dan Response Shaping
## 21.4 Serialization Groups
**Definisi Singkat:** Serialization groups memungkinkan output berbeda untuk konteks berbeda (public vs admin) menggunakan parameter `groups` di decorator `@Expose()`/`@Exclude()`/`@Transform()`.

**Analogi:** Groups seperti mode tampilan — mode "public" menunjukkan foto profil dan nama; mode "admin" juga menunjukkan email, IP, dan log aktivitas.

**Poin-Poin Penting:**
- **`@Expose({ groups: ['admin'] })`** — Hanya tampil untuk group admin
- **`@Exclude({ groups: ['public'] })`** — Sembunyi untuk group public
- **`@SerializeOptions({ groups: ['admin'] })`** — Set group aktif di controller
- **Multiple groups** — Satu properti bisa di beberapa group

**Contoh Kode:**
```typescript
// user.entity.ts
import { Entity, PrimaryGeneratedColumn, Column } from 'typeorm';
import { Exclude, Expose } from 'class-transformer';

@Entity('users')
export class User {
  @PrimaryGeneratedColumn()
  id: number;

  @Column()
  @Expose({ groups: ['public', 'admin'] })
  name: string;

  @Column()
  @Expose({ groups: ['public'] })
  avatarUrl: string;

  @Column()
  @Expose({ groups: ['admin'] })
  email: string; // Hanya admin lihat email

  @Column()
  @Exclude({ groups: ['public'] })
  @Expose({ groups: ['admin'] })
  lastLoginIp: string; // Hanya admin

  @Column()
  @Exclude()
  password: string; // Tidak pernah tampil
}

// user.controller.ts
import { Controller, Get, SerializeOptions } from '@nestjs/common';
import { UserService } from './user.service';

@Controller('users')
export class UserController {
  constructor(private userService: UserService) {}

  @Get()
  @SerializeOptions({ groups: ['public'] })
  findAll() {
    return this.userService.findAll(); // Output terbatas
  }

  @Get('admin')
  @SerializeOptions({ groups: ['admin'] })
  findAllForAdmin() {
    return this.userService.findAll(); // Output lengkap
  }
}
```

**Kasus Penggunaan Nyata:** Endpoint `GET /users` (public) hanya menampilkan nama dan avatar; `GET /admin/users` (admin) menampilkan email, IP, dan status akun.
