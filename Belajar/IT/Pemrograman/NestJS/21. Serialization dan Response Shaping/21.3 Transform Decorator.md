# 21. Serialization dan Response Shaping
## 21.3 Transform Decorator
**Definisi Singkat:** `@Transform()` dari class-transformer memungkinkan transformasi kustom nilai properti saat serialisasi — format tanggal, potong teks, gabung data, konversi tipe.

**Analogi:** Transform seperti filter foto Instagram — Anda ambil foto asli (nilai properti), lalu apply filter (transformasi) sebelum diposting (dikirim ke client).

**Poin-Poin Penting:**
- **`@Transform(({ value }) => ...)`** — Transform value saat serialize/deserialize
- **`({ value, key, obj, type })`** — Parameter: value, key, object asal, tipe transformasi
- **Format tanggal** — Ubah Date ke format tertentu
- **Case conversion** — Ubah snake_case ke camelCase, dll

**Contoh Kode:**
```typescript
// user.entity.ts
import { Entity, PrimaryGeneratedColumn, Column, CreateDateColumn } from 'typeorm';
import { Transform } from 'class-transformer';

@Entity('users')
export class User {
  @PrimaryGeneratedColumn()
  id: number;

  @Column()
  name: string;

  @CreateDateColumn()
  @Transform(({ value }) => value.toISOString().split('T')[0])
  createdAt: Date; // Output: "2026-05-24" (bukan full ISO)

  @Column({ nullable: true })
  @Transform(({ value }) => value ?? 'Not set')
  bio: string; // null jadi 'Not set'

  @Column('simple-array', { nullable: true })
  @Transform(({ value }) => (value ? value.join(', ') : ''))
  tags: string[]; // ['a','b','c'] jadi "a, b, c"

  @Column({ type: 'decimal' })
  @Transform(({ value }) => Number(value))
  price: number; // String dari DB diubah ke number
}

// user.module.ts
import { Module } from '@nestjs/common';
import { TypeOrmModule } from '@nestjs/typeorm';
import { User } from './user.entity';
import { UserService } from './user.service';

@Module({
  imports: [TypeOrmModule.forFeature([User])],
  providers: [UserService],
})
export class UserModule {}
```

**Kasus Penggunaan Nyata:** API e-commerce — harga produk dari database (decimal string) di-Transform ke number, deskripsi kosong jadi "No description available".
