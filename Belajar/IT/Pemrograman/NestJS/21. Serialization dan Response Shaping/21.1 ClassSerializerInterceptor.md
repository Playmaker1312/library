# 21. Serialization dan Response Shaping
## 21.1 ClassSerializerInterceptor
**Definisi Singkat:** `ClassSerializerInterceptor` adalah interceptor NestJS yang menggunakan `class-transformer` untuk mentransformasi response object (misal entity) sebelum dikirim ke client — berguna untuk menyembunyikan field sensitif.

**Analogi:** ClassSerializerInterceptor seperti sensor sensor otomatis — Anda punya KTP (entity) dengan banyak data, sensor menyensor nomor KTP dan tanda tangan sebelum difotokopi (response).

**Poin-Poin Penting:**
- **`ClassSerializerInterceptor`** — Interceptor dari `@nestjs/common`
- **`@SerializeOptions()`** — Konfigurasi serialization (exposeUnsetItems, dll)
- **Global interceptor** — Daftarkan di `APP_INTERCEPTOR`
- **Bekerja dengan** — decorator `@Exclude()`, `@Expose()`, `@Transform()`

**Contoh Kode:**
```typescript
// app.module.ts — Global interceptor
import { Module } from '@nestjs/common';
import { APP_INTERCEPTOR } from '@nestjs/core';
import { ClassSerializerInterceptor } from '@nestjs/common';

@Module({
  providers: [
    {
      provide: APP_INTERCEPTOR,
      useClass: ClassSerializerInterceptor,
    },
  ],
})
export class AppModule {}

// user.entity.ts
import { Entity, PrimaryGeneratedColumn, Column } from 'typeorm';
import { Exclude } from 'class-transformer';

@Entity('users')
export class User {
  @PrimaryGeneratedColumn()
  id: number;

  @Column()
  email: string;

  @Column()
  @Exclude()
  password: string; // Tersembunyi dari response!
}

// user.controller.ts
import { Controller, Get } from '@nestjs/common';
import { UserService } from './user.service';

@Controller('users')
export class UserController {
  constructor(private userService: UserService) {}

  @Get()
  findAll() {
    return this.userService.findAll(); // password otomatis di-exclude
  }
}
```

**Kasus Penggunaan Nyata:** API user yang mengembalikan data user — field `password` dan `refreshToken` otomatis di-exclude dari JSON response tanpa manual mapping.
