# 21. Serialization dan Response Shaping
## 21.5 Custom Serialization Interceptor
**Definisi Singkat:** Custom serialization interceptor memberikan kontrol penuh atas transformasi response — format seragam, wrap response, mapping data, atau logika kustom.

**Analogi:** Custom interceptor seperti jalur perakitan pabrik — setiap produk (response) melewati serangkaian stasiun (transformasi) sebelum dikemas dan dikirim ke pelanggan.

**Poin-Poin Penting:**
- **`NestInterceptor`** — Interface untuk membuat interceptor
- **`map()` operator** — Transform response stream dengan RxJS
- **`response.data`** — Bungkus response dalam object standar
- **`response.statusCode`** — Tambahkan metadata

**Contoh Kode:**
```typescript
// interceptors/response-wrapper.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable } from 'rxjs';
import { map } from 'rxjs/operators';

export interface WrappedResponse<T> {
  statusCode: number;
  message: string;
  data: T;
  timestamp: string;
}

@Injectable()
export class ResponseWrapperInterceptor<T>
  implements NestInterceptor<T, WrappedResponse<T>>
{
  intercept(
    context: ExecutionContext,
    next: CallHandler,
  ): Observable<WrappedResponse<T>> {
    const statusCode = context.switchToHttp().getResponse().statusCode;

    return next.handle().pipe(
      map((data) => ({
        statusCode,
        message: 'Success',
        data,
        timestamp: new Date().toISOString(),
      })),
    );
  }
}

// app.module.ts
import { Module } from '@nestjs/common';
import { APP_INTERCEPTOR } from '@nestjs/core';
import { ResponseWrapperInterceptor } from './interceptors/response-wrapper.interceptor';

@Module({
  providers: [
    { provide: APP_INTERCEPTOR, useClass: ResponseWrapperInterceptor },
  ],
})
export class AppModule {}

// Response akan selalu:
// {
//   "statusCode": 200,
//   "message": "Success",
//   "data": { ... },
//   "timestamp": "2026-05-24T10:30:00.000Z"
// }
```

**Kasus Penggunaan Nyata:** Semua endpoint REST API membungkus response dalam format standar `{ data, statusCode, message, timestamp }` untuk konsistensi frontend.
