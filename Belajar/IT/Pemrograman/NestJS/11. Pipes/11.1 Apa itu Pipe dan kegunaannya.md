# 11. Pipes

## 11.1. Apa itu Pipe dan kegunaannya

**Definisi Singkat:** Pipe adalah class yang memproses data sebelum sampai ke handler, berfungsi untuk transformasi dan validasi data.

**Analogi:** Seperti pipa air — air kotor masuk, air bersih keluar. Atau seperti filter air yang menyaring kotoran sebelum diminum.

**Poin-Poin Penting:**
- Dua fungsi utama: transformasi data dan validasi data
- Data diproses sebelum mencapai method controller
- Bisa melempar exception jika data tidak valid
- Bisa digunakan di parameter, method, controller, atau global
- Pipe sudah include `ValidationPipe`, `ParseIntPipe`, dll

**Contoh Kode:**
```typescript
// Pipe mengubah input sebelum diproses
@Get(':id')
findOne(@Param('id', ParseIntPipe) id: number) {
  // id sudah number, bukan string
  return this.userService.findById(id);
}
```

**Kasus Penggunaan Nyata:** Parameter `id` dari URL adalah string, `ParseIntPipe` mengubahnya jadi number sehingga tidak perlu manual `parseInt(id)` di setiap handler.
