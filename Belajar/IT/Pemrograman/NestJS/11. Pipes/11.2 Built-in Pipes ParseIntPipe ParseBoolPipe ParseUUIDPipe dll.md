# 11. Pipes

## 11.2. Built-in Pipes ParseIntPipe ParseBoolPipe ParseUUIDPipe dll

**Definisi Singkat:** NestJS menyediakan pipe bawaan untuk transformasi dan validasi tipe data umum.

**Analogi:** Seperti alat dapur siap pakai — tinggal pakai, tidak perlu buat sendiri dari nol.

**Poin-Poin Penting:**
- `ParseIntPipe` — string ke number, error jika bukan angka
- `ParseBoolPipe` — string ke boolean
- `ParseUUIDPipe` — validasi UUID format
- `ParseArrayPipe` — validasi array
- `DefaultValuePipe` — nilai default jika parameter kosong
- Semua melempar `BadRequestException` jika gagal

**Contoh Kode:**
```typescript
import { ParseIntPipe, ParseBoolPipe, ParseUUIDPipe, DefaultValuePipe } from '@nestjs/common';

@Get(':id')
findOne(@Param('id', ParseUUIDPipe) id: string) {
  return this.userService.findById(id);
}

@Get()
findAll(
  @Query('page', new DefaultValuePipe(1), ParseIntPipe) page: number,
  @Query('active', new DefaultValuePipe(false), ParseBoolPipe) active: boolean,
) {
  return this.userService.findAll({ page, active });
}
```

**Kasus Penggunaan Nyata:** Endpoint `GET /users?page=1&active=true` — `ParseIntPipe` memvalidasi `page` harus angka, `ParseBoolPipe` mengubah string `"true"` jadi boolean `true`.
