# 11. Pipes

## 11.3. Pipe Level parameter method controller global

**Definisi Singkat:** Pipe dapat dipasang di berbagai level: parameter, method, controller, atau global — menentukan sejauh mana pipe tersebut berlaku.

**Analogi:** Seperti aturan keamanan — aturan kamar (parameter), aturan lantai (method), aturan gedung (controller), aturan negara (global).

**Poin-Poin Penting:**
- **Parameter level:** pipe hanya untuk satu parameter
- **Method level:** `@UsePipes(pipe)` untuk satu handler
- **Controller level:** `@UsePipes(pipe)` untuk semua handler di controller
- **Global level:** `app.useGlobalPipes(pipe)` untuk seluruh aplikasi
- Semakin spesifik level, semakin tinggi prioritas

**Contoh Kode:**
```typescript
import { UsePipes, ParseIntPipe, ValidationPipe } from '@nestjs/common';

// Parameter level
@Get(':id')
findOne(@Param('id', ParseIntPipe) id: number) { }

// Method level
@Post()
@UsePipes(new ValidationPipe({ transform: true }))
create(@Body() dto: CreateUserDto) { }

// Controller level
@Controller('users')
@UsePipes(new ValidationPipe())
export class UserController { }

// Global level — di main.ts
app.useGlobalPipes(new ValidationPipe());
```

**Kasus Penggunaan Nyata:** `ValidationPipe` dipasang global untuk validasi semua request, tapi `ParseIntPipe` khusus untuk parameter `id` yang perlu diubah dari string ke number.
