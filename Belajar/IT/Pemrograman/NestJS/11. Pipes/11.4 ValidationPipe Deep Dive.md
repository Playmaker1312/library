# 11. Pipes

## 11.4. ValidationPipe Deep Dive

**Definisi Singkat:** `ValidationPipe` menggabungkan `class-validator` dan `class-transformer` untuk validasi dan transformasi DTO secara otomatis.

**Analogi:** Seperti satpam plus resepsionis — sekaligus periksa identitas (validasi) dan catat data (transformasi).

**Poin-Poin Penting:**
- Internal: pakai `class-validator` untuk validasi
- Internal: pakai `class-transformer` untuk transformasi
- Opsi lengkap: `whitelist`, `forbidNonWhitelisted`, `transform`
- `transform: true` mengubah plain object jadi instance class DTO
- Bisa validasi nested object (perlu `@ValidateNested()`)
- Error response otomatis `BadRequestException`

**Contoh Kode:**
```typescript
import { ValidationPipe } from '@nestjs/common';

// Konfigurasi lengkap
app.useGlobalPipes(
  new ValidationPipe({
    whitelist: true,
    forbidNonWhitelisted: true,
    transform: true,
    disableErrorMessages: false, // Set true di production
    exceptionFactory: (errors) => {
      // Kustomisasi format error
      const messages = errors.map(e => ({
        field: e.property,
        constraints: Object.values(e.constraints || {}),
      }));
      return new BadRequestException(messages);
    },
  }),
);
```

**Kasus Penggunaan Nyata:** `ValidationPipe` global dengan `exceptionFactory` kustom mengembalikan error seperti `[{ field: "email", constraints: ["email harus format valid"] }]` yang lebih mudah diparsing frontend daripada format default.
