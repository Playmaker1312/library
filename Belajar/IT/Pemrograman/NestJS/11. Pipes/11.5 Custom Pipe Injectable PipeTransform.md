# 11. Pipes

## 11.5. Custom Pipe Injectable PipeTransform

**Definisi Singkat:** Pipe kustom dibuat dengan class yang implement `PipeTransform` dan decorator `@Injectable()`.

**Analogi:** Seperti membuat alat filter khusus — kalau filter bawaan tidak cukup, bikin sendiri.

**Poin-Poin Penting:**
- Implement interface `PipeTransform<T, R>`
- Method `transform(value: T, metadata: ArgumentMetadata): R`
- `@Injectable()` agar bisa DI
- Bisa async
- `metadata` berisi type, data (nama parameter), metatype (tipe)
- Melempar `BadRequestException` jika validasi gagal

**Contoh Kode:**
```typescript
import { PipeTransform, Injectable, ArgumentMetadata, BadRequestException } from '@nestjs/common';

@Injectable()
export class ParsePositiveIntPipe implements PipeTransform<string, number> {
  transform(value: string, metadata: ArgumentMetadata): number {
    const parsed = parseInt(value, 10);

    if (isNaN(parsed) || parsed <= 0) {
      throw new BadRequestException(
        `Nilai ${metadata.data} harus angka positif`,
      );
    }

    return parsed;
  }
}

// Penggunaan
@Get(':id')
findOne(@Param('id', ParsePositiveIntPipe) id: number) { }
```

**Kasus Penggunaan Nyata:** Endpoint yang membutuhkan ID positif — `ParsePositiveIntPipe` memastikan parameter `id` bukan hanya number valid tapi juga positif, mencegah ID negatif atau nol.
