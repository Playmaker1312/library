# 533. Cara mengimplementasikan SQL injection prevention menggunakan parameterized query

## Definisi & Target
SQL injection terjadi ketika user input dimasukkan langsung ke query SQL. Target: gunakan parameterized query via Prisma (selalu aman) atau raw query dengan binding parameter.

## Komponen & Nest CLI Command
```
npm install @prisma/client prisma
```

## Kode Implementasi (Per File)

```
// src/prisma/prisma.service.ts (Prisma sudah aman dari SQL injection)
import { Injectable, OnModuleInit, OnModuleDestroy } from '@nestjs/common';
import { PrismaClient } from '@prisma/client';

@Injectable()
export class PrismaService extends PrismaClient implements OnModuleInit, OnModuleDestroy {
  async onModuleInit() {
    await this.$connect();
  }

  async onModuleDestroy() {
    await this.$disconnect();
  }

  async searchUsers(searchTerm: string) {
    return this.user.findMany({
      where: {
        OR: [
          { name: { contains: searchTerm, mode: 'insensitive' } },
          { email: { contains: searchTerm, mode: 'insensitive' } },
        ],
      },
    });
  }

  async rawQueryWithParams(userId: string) {
    return this.$queryRawUnsafe(
      'SELECT * FROM "User" WHERE id = $1',
      userId,
    );
  }
}
```

```
// src/modules/users/users.service.ts (contoh raw query aman)
import { Injectable } from '@nestjs/common';
import { PrismaService } from '../../prisma/prisma.service';

@Injectable()
export class UsersService {
  constructor(private prisma: PrismaService) {}

  async search(query: string) {
    return this.prisma.searchUsers(query);
  }

  async getUserStats() {
    return this.prisma.$queryRawUnsafe(
      'SELECT plan, COUNT(*) as count FROM "Tenant" GROUP BY plan',
    );
  }
}
```

## Cara Integrasi & Pengujian
Prisma secara otomatis menggunakan parameterized query — tidak perlu sanitasi manual. Untuk raw query, selalu gunakan binding (`$1`, `$2`) jangan string concatenation. Uji: kirim `"'; DROP TABLE users; --"` sebagai input → aman.
