# 531. Cara mengimplementasikan request size limiting untuk mencegah payload terlalu besar

## Definisi & Target
Batasi ukuran body request untuk mencegah serangan DoS via payload raksasa. Target: body JSON maksimal 1MB, file upload maksimal 10MB.

## Komponen & Nest CLI Command
Konfigurasi di `main.ts` via NestJS `INestApplication` options.

## Kode Implementasi (Per File)

```
// src/main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { json, urlencoded } from 'express';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.use(json({ limit: '1mb' }));
  app.use(urlencoded({ extended: true, limit: '1mb' }));

  await app.listen(3000);
}
```

```
// src/modules/files/files.controller.ts
import { Controller, Post, UseInterceptors, UploadedFile, MaxFileSizeValidator, ParseFilePipe } from '@nestjs/common';
import { FileInterceptor } from '@nestjs/platform-express';

@Controller('files')
export class FilesController {
  @Post('upload')
  @UseInterceptors(FileInterceptor('file', { limits: { fileSize: 10 * 1024 * 1024 } }))
  upload(
    @UploadedFile(
      new ParseFilePipe({
        validators: [new MaxFileSizeValidator({ maxSize: 10 * 1024 * 1024 })],
      }),
    )
    file: Express.Multer.File,
  ) {
    return { filename: file.originalname, size: file.size };
  }
}
```

## Cara Integrasi & Pengujian
Kirim request dengan body >1MB → 413 Payload Too Large. Upload file >10MB → error validasi. Request normal → berhasil.
