# 530. Cara mengimplementasikan rate limiting per endpoint menggunakan @nestjs/throttler

## Definisi & Target
Rate limiting membatasi jumlah request per waktu untuk mencegah abuse dan DDoS. Target: throttle berbeda per endpoint — login (ketat), public API (sedang), internal (longgar).

## Komponen & Nest CLI Command
```
npm install @nestjs/throttler
nest g module common/throttle
```

## Kode Implementasi (Per File)

```
// src/common/throttle/throttle.module.ts
import { Module } from '@nestjs/common';
import { ThrottlerModule, ThrottlerGuard } from '@nestjs/throttler';
import { APP_GUARD } from '@nestjs/core';

@Module({
  imports: [
    ThrottlerModule.forRoot([
      {
        name: 'global',
        ttl: 60000,
        limit: 100,
      },
      {
        name: 'strict',
        ttl: 60000,
        limit: 5,
      },
      {
        name: 'loose',
        ttl: 60000,
        limit: 1000,
      },
    ]),
  ],
  providers: [
    { provide: APP_GUARD, useClass: ThrottlerGuard },
  ],
})
export class ThrottleModule {}
```

```
// src/modules/auth/auth.controller.ts
import { Controller, Post } from '@nestjs/common';
import { SkipThrottle, Throttle } from '@nestjs/throttler';

@Controller('auth')
export class AuthController {
  @Post('login')
  @Throttle({ strict: { limit: 5, ttl: 60000 } })
  login() {
    // login logic
  }

  @Post('register')
  @Throttle({ strict: { limit: 3, ttl: 60000 } })
  register() {
    // register logic
  }
}
```

```
// src/modules/public/public.controller.ts
import { Controller, Get } from '@nestjs/common';
import { SkipThrottle } from '@nestjs/throttler';

@Controller('public')
export class PublicController {
  @Get('health')
  @SkipThrottle()
  health() {
    return { status: 'ok' };
  }
}
```

## Cara Integrasi & Pengujian
Import `ThrottleModule`. Uji: kirim >5 request ke `/auth/login` dalam 1 menit → 429 Too Many Requests.
