# 527. Cara mengimplementasikan input validation yang komprehensif untuk mencegah injection

## Definisi & Target
Validasi input dari user menggunakan `class-validator` DTO + `ValidationPipe` global. Target: semua input tervalidasi sebelum diproses, cegah injection (SQL, NoSQL, command).

## Komponen & Nest CLI Command
```
npm install class-validator class-transformer
nest g pipe common/validation
```

## Kode Implementasi (Per File)

```
// src/common/pipes/validation.pipe.ts
import { PipeTransform, Injectable, ArgumentMetadata, BadRequestException } from '@nestjs/common';
import { validate } from 'class-validator';
import { plainToClass } from 'class-transformer';

@Injectable()
export class ValidationPipe implements PipeTransform<any> {
  async transform(value: any, { metatype }: ArgumentMetadata) {
    if (!metatype || !this.toValidate(metatype)) return value;

    const object = plainToClass(metatype, value);
    const errors = await validate(object);

    if (errors.length > 0) {
      const messages = errors.map((err) => ({
        property: err.property,
        constraints: err.constraints,
      }));
      throw new BadRequestException({ message: 'Validation failed', errors: messages });
    }

    return object;
  }

  private toValidate(metatype: Function): boolean {
    const types: Function[] = [String, Boolean, Number, Array, Object];
    return !types.includes(metatype);
  }
}
```

```
// src/modules/users/dto/create-user.dto.ts
import { IsEmail, IsString, MinLength, MaxLength, Matches } from 'class-validator';

export class CreateUserDto {
  @IsEmail()
  email: string;

  @IsString()
  @MinLength(8)
  @MaxLength(32)
  @Matches(/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&])[A-Za-z\d@$!%*?&]+$/, {
    message: 'Password too weak',
  })
  password: string;

  @IsString()
  @MinLength(2)
  @MaxLength(50)
  @Matches(/^[a-zA-Z0-9_ ]+$/, { message: 'Invalid characters in name' })
  name: string;
}
```

```
// src/main.ts
import { ValidationPipe } from './common/pipes/validation.pipe';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.useGlobalPipes(new ValidationPipe({ whitelist: true, forbidNonWhitelisted: true }));
  await app.listen(3000);
}
```

## Cara Integrasi & Pengujian
Pasang `ValidationPipe` global di `main.ts`. Buat DTO dengan decorator class-validator. Uji: kirim payload invalid → 400 Bad Request dengan detail error.
