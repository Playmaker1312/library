# 539. Cara melakukan penetration testing dasar pada API NestJS

## Definisi & Target
Penetration testing menemukan celah keamanan sebelum attacker. Target: tools dan skrip untuk menguji API dari serangan umum.

## Komponen & Nest CLI Command
```
npm install -g zaproxy
npm install -g httpx
```

## Kode Implementasi (Per File)

```
# penetration-test-checklist.sh — test manual
#!/bin/bash

BASE_URL="https://api.mysaas.com"

echo "=== SQL Injection ==="
curl "$BASE_URL/users?id=1' OR '1'='1"
curl "$BASE_URL/users?id=1 UNION SELECT * FROM users"

echo "=== NoSQL Injection ==="
curl -X POST "$BASE_URL/login" \
  -H "Content-Type: application/json" \
  -d '{"email": {"$gt": ""}, "password": {"$gt": ""}}'

echo "=== XSS ==="
curl "$BASE_URL/search?q=<script>alert(1)</script>"

echo "=== IDOR ==="
curl "$BASE_URL/users/123" -H "Authorization: Bearer $TOKEN_OWNER"
curl "$BASE_URL/users/456" -H "Authorization: Bearer $TOKEN_OWNER"

echo "=== Rate Limit ==="
for i in $(seq 1 200); do
  curl -s -o /dev/null -w "%{http_code}\n" "$BASE_URL/auth/login" -X POST
done

echo "=== Mass Assignment ==="
curl -X POST "$BASE_URL/users" \
  -H "Content-Type: application/json" \
  -d '{"email":"test@test.com","password":"Test123!","role":"super_admin"}'
```

```
// src/common/testing/pen-test.utils.ts — automated test helper
import { INestApplication } from '@nestjs/common';
import * as request from 'supertest';

export async function runSecurityTests(app: INestApplication) {
  const http = request(app.getHttpServer());

  await http.get('/users?id=1; DROP TABLE users').expect(400);
  await http.post('/auth/login').send({ email: { $gt: '' }, password: { $gt: '' } }).expect(400);
  await http.post('/users').send({
    email: 'test@test.com',
    role: 'super_admin',
  }).expect(400);
  await http.get('/health').set('Origin', 'https://evil.com').expect(403);
}
```

## Cara Integrasi & Pengujian
Jalankan checklist manual. Gunakan OWASP ZAP untuk automated scan: `zap-cli quick-scan --self-contained -s xss,sqli https://api.mysaas.com`. Perbaiki celah yang ditemukan.
