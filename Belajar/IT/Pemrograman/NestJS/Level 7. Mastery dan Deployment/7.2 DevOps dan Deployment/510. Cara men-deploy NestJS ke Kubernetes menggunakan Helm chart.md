# 510. Cara men-deploy NestJS ke Kubernetes menggunakan Helm chart

## Definisi & Target
Helm adalah package manager untuk Kubernetes. Target: deploy NestJS dengan satu perintah `helm install` — konfigurasi terpusat di `values.yaml`.

## Komponen & Nest CLI Command
```
helm create nestjs-chart
helm install nestjs-app ./nestjs-chart
helm upgrade nestjs-app ./nestjs-chart
```

## Kode Implementasi (Per File)

```
# nestjs-chart/Chart.yaml
apiVersion: v2
name: nestjs-app
description: Helm chart for NestJS application
version: 1.0.0
appVersion: 1.0.0
```

```
# nestjs-chart/values.yaml
replicaCount: 3
image:
  repository: ghcr.io/myorg/nestjs-app
  tag: latest
  pullPolicy: Always
service:
  port: 80
  targetPort: 3000
ingress:
  enabled: true
  host: api.mysaas.com
resources:
  limits:
    cpu: 500m
    memory: 512Mi
  requests:
    cpu: 250m
    memory: 256Mi
env:
  NODE_ENV: production
  DATABASE_URL: postgresql://user:pass@postgres:5432/nestjs
  REDIS_HOST: redis-master
probes:
  livenessPath: /health/live
  readinessPath: /health/ready
```

```
# nestjs-chart/templates/deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: {{ .Values.nameOverride | default .Chart.Name }}
spec:
  replicas: {{ .Values.replicaCount }}
  selector:
    matchLabels:
      app: {{ .Chart.Name }}
  template:
    metadata:
      labels:
        app: {{ .Chart.Name }}
    spec:
      containers:
      - name: {{ .Chart.Name }}
        image: "{{ .Values.image.repository }}:{{ .Values.image.tag }}"
        imagePullPolicy: {{ .Values.image.pullPolicy }}
        ports:
        - containerPort: {{ .Values.service.targetPort }}
        env:
        {{- range $key, $val := .Values.env }}
        - name: {{ $key }}
          value: {{ $val | quote }}
        {{- end }}
        livenessProbe:
          httpGet:
            path: {{ .Values.probes.livenessPath }}
            port: {{ .Values.service.targetPort }}
        readinessProbe:
          httpGet:
            path: {{ .Values.probes.readinessPath }}
            port: {{ .Values.service.targetPort }}
        resources:
          {{- toYaml .Values.resources | nindent 10 }}
```

## Cara Integrasi & Pengujian
Jalankan `helm install nestjs-app ./nestjs-chart`. Verifikasi: `helm list`, `kubectl get pods`. Update: `helm upgrade nestjs-app ./nestjs-chart --set image.tag=v2`.
