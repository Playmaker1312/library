# 496. Cara membuat Dockerfile yang optimal untuk aplikasi NestJS

## Definisi & Target
Dockerfile yang optimal menggunakan multi-stage build: `development` → `build` → `production`. Target: image kecil, cepat build, aman untuk production.

## Komponen & Nest CLI Command
```
docker build -t nestjs-app .
```

## Kode Implementasi (Per File)

```
# Dockerfile
FROM node:20-alpine AS development
WORKDIR /usr/src/app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM node:20-alpine AS production
WORKDIR /usr/src/app
COPY --from=development /usr/src/app/dist ./dist
COPY --from=development /usr/src/app/node_modules ./node_modules
COPY package*.json ./
EXPOSE 3000
CMD ["node", "dist/main"]
```

```
# .dockerignore
node_modules
dist
.git
*.md
.env
.env.local
```

## Cara Integrasi & Pengujian
Jalankan `docker build -t nestjs-app .` lalu `docker run -p 3000:3000 nestjs-app`. Akses `http://localhost:3000`. Lihat ukuran image dengan `docker images`.
