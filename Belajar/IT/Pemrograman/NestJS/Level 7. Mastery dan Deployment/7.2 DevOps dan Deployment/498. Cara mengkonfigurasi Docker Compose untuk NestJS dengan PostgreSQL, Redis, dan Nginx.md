# 498. Cara mengkonfigurasi Docker Compose untuk NestJS dengan PostgreSQL, Redis, dan Nginx

## Definisi & Target
Docker Compose untuk production-like environment: NestJS app, PostgreSQL, Redis, Nginx sebagai reverse proxy. Target: satu perintah `docker compose up` untuk semua service.

## Komponen & Nest CLI Command
```
docker compose up -d
docker compose ps
```

## Kode Implementasi (Per File)

```
# docker-compose.yml
version: '3.8'

services:
  app:
    build:
      context: .
      target: production
    ports:
      - '3000:3000'
    environment:
      - DATABASE_URL=postgresql://user:pass@db:5432/nestjs
      - REDIS_HOST=redis
    depends_on:
      - db
      - redis
    restart: unless-stopped

  db:
    image: postgres:16-alpine
    environment:
      POSTGRES_USER: user
      POSTGRES_PASSWORD: pass
      POSTGRES_DB: nestjs
    volumes:
      - pgdata:/var/lib/postgresql/data
    ports:
      - '5432:5432'

  redis:
    image: redis:7-alpine
    ports:
      - '6379:6379'
    volumes:
      - redisdata:/data

  nginx:
    image: nginx:alpine
    ports:
      - '80:80'
      - '443:443'
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
    depends_on:
      - app

volumes:
  pgdata:
  redisdata:
```

## Cara Integrasi & Pengujian
Jalankan `docker compose up -d`. Pastikan semua container running dengan `docker compose ps`. Akses `http://localhost` — Nginx forward ke NestJS app.
