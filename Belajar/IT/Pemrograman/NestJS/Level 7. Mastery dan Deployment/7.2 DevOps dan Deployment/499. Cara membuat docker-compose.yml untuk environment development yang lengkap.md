# 499. Cara membuat docker-compose.yml untuk environment development yang lengkap

## Definisi & Target
Docker Compose untuk development: hot-reload, volume bind mount, database seeding, dan debugging tools. Target: developer bisa `docker compose up` dan langsung coding dengan auto-reload.

## Komponen & Nest CLI Command
```
docker compose -f docker-compose.dev.yml up
```

## Kode Implementasi (Per File)

```
# docker-compose.dev.yml
version: '3.8'

services:
  app:
    build:
      context: .
      target: dev
    ports:
      - '3000:3000'
      - '9229:9229'
    volumes:
      - .:/usr/src/app
      - /usr/src/app/node_modules
    environment:
      - NODE_ENV=development
      - DATABASE_URL=postgresql://user:pass@db:5432/nestjs_dev
      - REDIS_HOST=redis
    command: npm run start:dev
    depends_on:
      - db
      - redis

  db:
    image: postgres:16-alpine
    environment:
      POSTGRES_USER: user
      POSTGRES_PASSWORD: pass
      POSTGRES_DB: nestjs_dev
    ports:
      - '5432:5432'
    volumes:
      - pgdata_dev:/var/lib/postgresql/data

  redis:
    image: redis:7-alpine
    ports:
      - '6379:6379'

  adminer:
    image: adminer
    ports:
      - '8080:8080'
    depends_on:
      - db

volumes:
  pgdata_dev:
```

## Cara Integrasi & Pengujian
Jalankan `docker compose -f docker-compose.dev.yml up`. Edit file TypeScript — NestJS akan hot-reload. Akses Adminer di `http://localhost:8080` untuk manage database.
