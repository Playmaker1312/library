# 509. Cara mengimplementasikan zero-downtime deployment menggunakan rolling update

## Definisi & Target
Rolling update mengganti pod lama dengan pod baru secara bertahap tanpa downtime. Target: deploy versi baru tanpa mengganggu traffic yang sedang berlangsung.

## Komponen & Nest CLI Command
```
kubectl set image deployment/nestjs-app app=ghcr.io/myorg/app:v2
kubectl rollout status deployment/nestjs-app
```

## Kode Implementasi (Per File)

```
# k8s-rolling-update.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nestjs-app
spec:
  replicas: 5
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 1
      maxUnavailable: 0
  selector:
    matchLabels:
      app: nestjs-app
  template:
    metadata:
      labels:
        app: nestjs-app
    spec:
      terminationGracePeriodSeconds: 60
      containers:
      - name: app
        image: ghcr.io/myorg/nestjs-app:latest
        ports:
        - containerPort: 3000
        lifecycle:
          preStop:
            exec:
              command: ["sh", "-c", "sleep 30"]
        livenessProbe:
          httpGet:
            path: /health/live
            port: 3000
          initialDelaySeconds: 10
          periodSeconds: 5
        readinessProbe:
          httpGet:
            path: /health/ready
            port: 3000
          initialDelaySeconds: 5
          periodSeconds: 3
```

```
# k8s-service.yaml
apiVersion: v1
kind: Service
metadata:
  name: nestjs-app-service
spec:
  selector:
    app: nestjs-app
  ports:
  - port: 80
    targetPort: 3000
  type: LoadBalancer
```

## Cara Integrasi & Pengujian
Deploy dengan strategi rolling update. Update image: `kubectl set image ...`. Pantau: `kubectl rollout status`. Selama deploy, akses API terus — tidak ada 503.
