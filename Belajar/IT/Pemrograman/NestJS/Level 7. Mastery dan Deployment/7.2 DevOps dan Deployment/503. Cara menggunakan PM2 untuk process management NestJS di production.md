# 503. Cara menggunakan PM2 untuk process management NestJS di production

## Definisi & Target
PM2 adalah process manager untuk Node.js production — auto-restart saat crash, log management, dan cluster mode. Target: aplikasi NestJS berjalan 24/7 tanpa downtime.

## Komponen & Nest CLI Command
```
npm install -g pm2
pm2 start dist/main.js --name nestjs-app
pm2 save
pm2 startup
```

## Kode Implementasi (Per File)

```
# Tidak perlu file khusus — PM2 via CLI:
pm2 start dist/main.js --name nestjs-app --instances max --update-env

# Commands penting:
pm2 status              # cek status semua process
pm2 logs nestjs-app     # lihat log realtime
pm2 monit              # dashboard monitoring
pm2 reload all         # reload tanpa downtime
pm2 restart nestjs-app # restart aplikasi
pm2 delete nestjs-app  # stop & hapus
```

## Cara Integrasi & Pengujian
Build app (`npm run build`), lalu `pm2 start dist/main.js --name app`. Cek `pm2 status`. Matikan process dengan `pm2 stop app` lalu `pm2 start app` — app restart otomatis. `pm2 startup` untuk auto-start saat VPS reboot.
