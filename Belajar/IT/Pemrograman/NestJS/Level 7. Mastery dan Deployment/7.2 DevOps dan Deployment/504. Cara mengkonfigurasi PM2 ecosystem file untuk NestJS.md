# 504. Cara mengkonfigurasi PM2 ecosystem file untuk NestJS

## Definisi & Target
`ecosystem.config.js` adalah konfigurasi PM2 dalam file — environment variables, cluster mode, log rotation, dan health monitoring terpusat.

## Komponen & Nest CLI Command
```
pm2 start ecosystem.config.js
pm2 restart ecosystem.config.js
```

## Kode Implementasi (Per File)

```
// ecosystem.config.js
module.exports = {
  apps: [{
    name: 'nestjs-app',
    script: 'dist/main.js',
    instances: 'max',
    exec_mode: 'cluster',
    env: {
      NODE_ENV: 'development',
    },
    env_production: {
      NODE_ENV: 'production',
      PORT: 3000,
    },
    max_memory_restart: '500M',
    log_date_format: 'YYYY-MM-DD HH:mm:ss',
    error_file: './logs/err.log',
    out_file: './logs/out.log',
    merge_logs: true,
    max_restarts: 10,
    restart_delay: 5000,
    min_uptime: '30s',
    listen_timeout: 3000,
    kill_timeout: 5000,
    watch: false,
  }],
};
```

```
// package.json (scripts)
{
  "scripts": {
    "pm2:start": "pm2 start ecosystem.config.js --env production",
    "pm2:stop": "pm2 stop ecosystem.config.js",
    "pm2:restart": "pm2 restart ecosystem.config.js",
    "pm2:logs": "pm2 logs nestjs-app",
    "pm2:monit": "pm2 monit"
  }
}
```

## Cara Integrasi & Pengujian
Buat `ecosystem.config.js`. Jalankan `npm run pm2:start`. Cek cluster mode: `pm2 status` → beberapa instance berjalan. Uji dengan mematikan satu instance — PM2 restart otomatis.
