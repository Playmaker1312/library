# 497. Cara menggunakan multi-stage build untuk menghasilkan Docker image yang lebih kecil

## Definisi & Target
Multi-stage build memisahkan environment build dari runtime, menghasilkan image production yang ringan karena tidak menyertakan dev dependencies dan source code.

## Komponen & Nest CLI Command
```
docker build --target production -t nestjs-app:latest .
```

## Kode Implementasi (Per File)

```
# Dockerfile (multi-stage optimized)
FROM node:20-alpine AS base
WORKDIR /usr/src/app
COPY package*.json ./

FROM base AS deps
RUN npm ci --only=production

FROM deps AS build
RUN npm ci
COPY . .
RUN npm run build

FROM node:20-alpine AS production
RUN apk add --no-cache tini
WORKDIR /usr/src/app
COPY --from=deps /usr/src/app/node_modules ./node_modules
COPY --from=build /usr/src/app/dist ./dist
EXPOSE 3000
USER node
ENTRYPOINT ["/sbin/tini", "--"]
CMD ["node", "dist/main"]

FROM production AS dev
RUN npm ci && npm install -g @nestjs/cli
COPY . .
CMD ["npm", "run", "start:dev"]
```

## Cara Integrasi & Pengujian
Build dengan target `production`: `docker build --target production -t app .`. Bandingkan ukuran: image multi-stage biasanya 80-120MB vs ~1GB tanpa multi-stage.
