# 501. Cara mengkonfigurasi SSL menggunakan Let's Encrypt dan Certbot

## Definisi & Target
Amanakan API dengan SSL/TLS gratis dari Let's Encrypt. Target: Nginx menggunakan sertifikat SSL yang diperbaharui otomatis via Certbot.

## Komponen & Nest CLI Command
```
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d api.mysaas.com
```

## Kode Implementasi (Per File)

```
# nginx.ssl.conf
server {
    listen 443 ssl http2;
    server_name api.mysaas.com;

    ssl_certificate /etc/letsencrypt/live/api.mysaas.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.mysaas.com/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;
    ssl_session_cache shared:SSL:10m;
    ssl_session_timeout 10m;

    location / {
        proxy_pass http://nestjs_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

server {
    listen 80;
    server_name api.mysaas.com;
    return 301 https://$server_name$request_uri;
}
```

```
# docker-compose.ssl.yml (Certbot sidecar)
services:
  certbot:
    image: certbot/certbot
    volumes:
      - certbot-etc:/etc/letsencrypt
      - certbot-var:/var/lib/letsencrypt
      - ./nginx.conf:/etc/nginx/nginx.conf
    entrypoint: "/bin/sh -c 'trap exit TERM; while :; do certbot renew; sleep 12h & wait $${!}; done;'"
```

## Cara Integrasi & Pengujian
Jalankan Certbot untuk domain. Set auto-renewal dengan cron `0 0 * * * certbot renew`. Uji: akses `https://api.mysaas.com` — koneksi aman.
