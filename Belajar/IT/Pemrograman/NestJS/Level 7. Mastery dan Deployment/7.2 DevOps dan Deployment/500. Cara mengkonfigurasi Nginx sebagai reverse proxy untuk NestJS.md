# 500. Cara mengkonfigurasi Nginx sebagai reverse proxy untuk NestJS

## Definisi & Target
Nginx menerima request dari internet dan meneruskannya ke NestJS app (backend). Target: konfigurasi proxy_pass, load balancing (jika multiple instance), dan static file serving.

## Komponen & Nest CLI Command
```
sudo nginx -t
sudo systemctl reload nginx
```

## Kode Implementasi (Per File)

```
# nginx.conf
events {
    worker_connections 1024;
}

http {
    upstream nestjs_backend {
        server app:3000;
        server app:3001;
    }

    server {
        listen 80;
        server_name api.mysaas.com;

        location / {
            proxy_pass http://nestjs_backend;
            proxy_http_version 1.1;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection 'upgrade';
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_cache_bypass $http_upgrade;

            client_max_body_size 10M;
            proxy_read_timeout 60s;
        }

        location /health {
            proxy_pass http://nestjs_backend;
            access_log off;
            return 200 "healthy\n";
        }
    }
}
```

## Cara Integrasi & Pengujian
Letakkan `nginx.conf` di folder project. Di docker-compose, mount file ini ke `/etc/nginx/nginx.conf`. Reload Nginx dan akses endpoint API melalui port 80.
