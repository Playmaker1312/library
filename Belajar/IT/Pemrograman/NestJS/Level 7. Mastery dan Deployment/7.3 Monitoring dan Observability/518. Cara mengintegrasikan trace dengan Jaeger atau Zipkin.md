# 518. Cara mengintegrasikan trace dengan Jaeger atau Zipkin

## Definisi & Target
Jaeger/Zipkin adalah UI untuk visualisasi distributed tracing. Target: trace dari NestJS muncul di Jaeger UI sebagai waterfall diagram.

## Komponen & Nest CLI Command
```
docker run -d --name jaeger -p 16686:16686 -p 4318:4318 jaegertracing/all-in-one:latest
```

## Kode Implementasi (Per File)

```
// docker-compose.observability.yml
version: '3.8'

services:
  jaeger:
    image: jaegertracing/all-in-one:latest
    ports:
      - '16686:16686'
      - '4318:4318'
      - '4317:4317'
    environment:
      - COLLECTOR_OTLP_ENABLED=true

  zipkin:
    image: openzipkin/zipkin:latest
    ports:
      - '9411:9411'
```

```
// src/telemetry/opentelemetry.config.ts (Jaeger OTLP)
import { OTLPTraceExporter } from '@opentelemetry/exporter-trace-otlp-http';

const jaegerExporter = new OTLPTraceExporter({
  url: process.env.JAEGER_URL || 'http://localhost:4318/v1/traces',
});
```

```
// src/telemetry/zipkin-exporter.config.ts
import { ZipkinExporter } from '@opentelemetry/exporter-zipkin';

const zipkinExporter = new ZipkinExporter({
  url: process.env.ZIPKIN_URL || 'http://localhost:9411/api/v2/spans',
  serviceName: 'nestjs-app',
});
```

## Cara Integrasi & Pengujian
Jalankan `docker compose -f docker-compose.observability.yml up`. Kirim request ke NestJS. Buka Jaeger UI di `http://localhost:16686` atau Zipkin di `http://localhost:9411`. Cari service `nestjs-app` — lihat trace detail.
