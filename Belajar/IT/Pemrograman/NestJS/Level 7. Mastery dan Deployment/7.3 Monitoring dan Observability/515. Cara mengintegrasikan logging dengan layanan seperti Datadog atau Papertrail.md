# 515. Cara mengintegrasikan logging dengan layanan seperti Datadog atau Papertrail

## Definisi & Target
Kirim log dari NestJS ke layanan eksternal (Datadog, Papertrail, Logstash) untuk agregasi dan analisis. Target: log terpusat dari semua instance.

## Komponen & Nest CLI Command
```
npm install winston winston-datadog-transport winston-papertrail-transport
```

## Kode Implementasi (Per File)

```
// src/logger/cloud-logger.config.ts
import { WinstonModule } from 'nest-winston';
import * as winston from 'winston';

const datadogTransport = new winston.transports.Http({
  host: 'http-intake.logs.datadoghq.com',
  path: `/api/v2/logs?dd-api-key=${process.env.DD_API_KEY}&ddsource=nodejs&service=nestjs-app`,
  ssl: true,
  format: winston.format.json(),
});

const papertrailTransport = new winston.transports.Http({
  host: process.env.PAPERTRAIL_HOST,
  port: parseInt(process.env.PAPERTRAIL_PORT),
  format: winston.format.printf(({ timestamp, level, message, context }) => {
    return `${timestamp} ${level} [${context}] ${message}`;
  }),
});

export const cloudLoggerConfig = WinstonModule.createLogger({
  transports: [
    new winston.transports.Console(),
    ...(process.env.DD_API_KEY ? [datadogTransport] : []),
    ...(process.env.PAPERTRAIL_HOST ? [papertrailTransport] : []),
  ],
});
```

```
// src/logger/logger.module.ts
import { Module } from '@nestjs/common';
import { WinstonModule } from 'nest-winston';
import { cloudLoggerConfig } from './cloud-logger.config';

@Module({
  imports: [WinstonModule.forRoot(cloudLoggerConfig)],
  exports: [WinstonModule],
})
export class LoggerModule {}
```

## Cara Integrasi & Pengujian
Set environment variables (`DD_API_KEY`, `PAPERTRAIL_HOST`). Jalankan app. Cek Datadog/Papertrail dashboard — log akan muncul real-time.
