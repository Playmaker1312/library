# 514. Cara menggunakan Pino sebagai alternatif logger yang lebih cepat

## Definisi & Target
Pino adalah logger tercepat untuk Node.js (~5x lebih cepat dari Winston). Target: mengganti Winston dengan Pino untuk performa lebih tinggi.

## Komponen & Nest CLI Command
```
npm install pino pino-pretty nestjs-pino
```

## Kode Implementasi (Per File)

```
// src/logger/pino-logger.config.ts
import { LoggerModule } from 'nestjs-pino';
import { DestinationStream } from 'pino';

export const pinoLoggerConfig = LoggerModule.forRoot({
  pinoHttp: {
    level: process.env.NODE_ENV === 'production' ? 'warn' : 'debug',
    transport: process.env.NODE_ENV !== 'production'
      ? { target: 'pino-pretty', options: { colorize: true, translateTime: true } }
      : undefined,
    serializers: {
      req: (req) => ({ method: req.method, url: req.url }),
      res: (res) => ({ statusCode: res.statusCode }),
    },
    customProps: (req) => ({
      correlationId: req.headers['x-correlation-id'],
    }),
  },
});
```

```
// src/main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule, { bufferLogs: true });
  app.flushLogs();
  await app.listen(3000);
}
bootstrap();
```

```
// src/app.module.ts
import { Module } from '@nestjs/common';
import { LoggerModule } from 'nestjs-pino';
import { pinoLoggerConfig } from './logger/pino-logger.config';

@Module({
  imports: [LoggerModule.forRoot(pinoLoggerConfig)],
})
export class AppModule {}
```

## Cara Integrasi & Pengujian
Jalankan app — log muncul dengan format pino-pretty (colorized). Bandingkan memory usage dengan Winston. Untuk production, gunakan `pino` tanpa `pino-pretty` → JSON output.
