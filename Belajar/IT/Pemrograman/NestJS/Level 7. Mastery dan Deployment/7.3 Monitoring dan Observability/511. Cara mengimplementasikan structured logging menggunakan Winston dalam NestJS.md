# 511. Cara mengimplementasikan structured logging menggunakan Winston dalam NestJS

## Definisi & Target
Winston adalah logging library untuk Node.js dengan dukungan transport (file, console, cloud) dan format structured JSON. Target: log terstruktur yang mudah dianalisis.

## Komponen & Nest CLI Command
```
npm install winston nest-winston
```

## Kode Implementasi (Per File)

```
// src/logger/winston.config.ts
import { WinstonModule } from 'nest-winston';
import * as winston from 'winston';

export const winstonConfig = WinstonModule.createLogger({
  transports: [
    new winston.transports.Console({
      format: winston.format.combine(
        winston.format.timestamp({ format: 'YYYY-MM-DD HH:mm:ss' }),
        winston.format.errors({ stack: true }),
        winston.format.json(),
      ),
    }),
    new winston.transports.File({
      filename: 'logs/error.log',
      level: 'error',
      format: winston.format.json(),
    }),
    new winston.transports.File({
      filename: 'logs/combined.log',
      format: winston.format.json(),
    }),
  ],
});
```

```
// src/app.module.ts
import { Module } from '@nestjs/common';
import { WinstonModule } from 'nest-winston';
import { winstonConfig } from './logger/winston.config';

@Module({
  imports: [
    WinstonModule.forRoot(winstonConfig),
  ],
})
export class AppModule {}
```

```
// src/logger/logger.service.ts (penggunaan di service)
import { Injectable } from '@nestjs/common';
import { InjectLogger, Logger } from 'nest-winston';

@Injectable()
export class SampleService {
  constructor(@InjectLogger() private readonly logger: Logger) {}

  doSomething() {
    this.logger.info('Processing request', { module: 'billing', action: 'charge' });
  }
}
```

## Cara Integrasi & Pengujian
Inject `Logger` di service. Jalankan app, lihat log di console (JSON). Cek file `logs/combined.log`. Error log masuk ke `logs/error.log`.
