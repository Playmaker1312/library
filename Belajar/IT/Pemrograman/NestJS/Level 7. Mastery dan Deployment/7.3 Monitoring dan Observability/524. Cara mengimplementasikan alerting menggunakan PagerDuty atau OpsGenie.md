# 524. Cara mengimplementasikan alerting menggunakan PagerDuty atau OpsGenie

## Definisi & Target
Alerting otomatis ketika health check gagal atau metrics melebihi threshold. Target: notifikasi ke PagerDuty/OpsGenie saat aplikasi bermasalah.

## Komponen & Nest CLI Command
```
npm install @pagerduty/pdjs
```

## Kode Implementasi (Per File)

```
// src/alerting/alerting.service.ts
import { Injectable } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class AlertingService {
  constructor(private config: ConfigService) {}

  async sendAlert(severity: string, summary: string, details: any) {
    if (this.config.get('ALERTING_PROVIDER') === 'pagerduty') {
      await this.sendPagerDuty(severity, summary, details);
    } else if (this.config.get('ALERTING_PROVIDER') === 'opsgenie') {
      await this.sendOpsGenie(severity, summary, details);
    }
  }

  private async sendPagerDuty(severity: string, summary: string, details: any) {
    const response = await fetch('https://events.pagerduty.com/v2/enqueue', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        routing_key: this.config.get('PAGERDUTY_ROUTING_KEY'),
        event_action: 'trigger',
        payload: {
          summary,
          severity,
          source: 'nestjs-app',
          custom_details: details,
        },
      }),
    });
    return response.json();
  }

  private async sendOpsGenie(severity: string, summary: string, details: any) {
    const response = await fetch('https://api.opsgenie.com/v2/alerts', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        Authorization: `GenieKey ${this.config.get('OPSGENIE_API_KEY')}`,
      },
      body: JSON.stringify({
        message: summary,
        priority: severity === 'critical' ? 'P1' : 'P3',
        details,
      }),
    });
    return response.json();
  }
}
```

```
// src/alerting/alerting.module.ts
import { Global, Module } from '@nestjs/common';
import { AlertingService } from './alerting.service';

@Global()
@Module({
  providers: [AlertingService],
  exports: [AlertingService],
})
export class AlertingModule {}
```

## Cara Integrasi & Pengujian
Set `PAGERDUTY_ROUTING_KEY` atau `OPSGENIE_API_KEY`. Panggil `alerting.sendAlert('critical', 'App down', { error: 'Database connection failed' })`. Cek PagerDuty/OpsGenie dashboard.
