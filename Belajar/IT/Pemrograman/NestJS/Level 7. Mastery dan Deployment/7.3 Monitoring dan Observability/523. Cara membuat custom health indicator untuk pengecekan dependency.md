# 523. Cara membuat custom health indicator untuk pengecekan dependency

## Definisi & Target
Custom health indicator mengecek dependency spesifik aplikasi (e.g., Stripe API, external service, queue). Target: implementasi `HealthIndicator` untuk dependency kustom.

## Komponen & Nest CLI Command
```
nest g service health/custom-indicator
```

## Kode Implementasi (Per File)

```
// src/health/stripe-health.indicator.ts
import { Injectable } from '@nestjs/common';
import { HealthIndicator, HealthIndicatorResult, HealthCheckError } from '@nestjs/terminus';
import { StripeConfigService } from '../../billing/stripe-config.service';

@Injectable()
export class StripeHealthIndicator extends HealthIndicator {
  constructor(private stripe: StripeConfigService) {
    super();
  }

  async isHealthy(key: string): Promise<HealthIndicatorResult> {
    try {
      await this.stripe.stripe.ping();
      return this.getStatus(key, true);
    } catch (error) {
      throw new HealthCheckError(
        'Stripe health check failed',
        this.getStatus(key, false, { message: error.message }),
      );
    }
  }
}
```

```
// src/health/queue-health.indicator.ts
import { Injectable } from '@nestjs/common';
import { HealthIndicator, HealthIndicatorResult, HealthCheckError } from '@nestjs/terminus';

@Injectable()
export class QueueHealthIndicator extends HealthIndicator {
  constructor() {
    super();
  }

  async isHealthy(key: string): Promise<HealthIndicatorResult> {
    try {
      const queueSize = 0;
      const isHealthy = queueSize < 1000;
      return this.getStatus(key, isHealthy, { queueSize });
    } catch (error) {
      throw new HealthCheckError('Queue check failed', this.getStatus(key, false));
    }
  }
}
```

```
// src/health/health.controller.ts (extended)
@Controller('health')
export class HealthController {
  constructor(
    private health: HealthCheckService,
    private stripe: StripeHealthIndicator,
    private queue: QueueHealthIndicator,
  ) {}

  @Get()
  @HealthCheck()
  check() {
    return this.health.check([
      () => this.stripe.isHealthy('stripe-api'),
      () => this.queue.isHealthy('job-queue'),
    ]);
  }
}
```

## Cara Integrasi & Pengujian
Daftarkan `StripeHealthIndicator` dan `QueueHealthIndicator` di module. Akses `GET /health` → cek status `stripe-api` dan `job-queue`.
