# 520. Cara membuat custom metrics untuk business-specific monitoring

## Definisi & Target
Buat metrics khusus bisnis: total registrasi, active tenants, revenue, API calls per plan. Target: metrics ini muncul di endpoint `/metrics` dan bisa di-query Prometheus.

## Komponen & Nest CLI Command
```
npm install prom-client
```

## Kode Implementasi (Per File)

```
// src/metrics/custom-metrics.service.ts
import { Injectable, OnModuleInit } from '@nestjs/common';
import { Counter, Histogram, Gauge } from 'prom-client';

@Injectable()
export class CustomMetricsService implements OnModuleInit {
  public httpRequestDuration: Histogram<string>;
  public activeTenants: Gauge<string>;
  public totalRegistrations: Counter<string>;
  public revenueTotal: Counter<string>;
  public apiCallsByPlan: Counter<string>;

  onModuleInit() {
    this.httpRequestDuration = new Histogram({
      name: 'http_request_duration_seconds',
      help: 'Duration of HTTP requests in seconds',
      labelNames: ['method', 'route', 'status'],
      buckets: [0.01, 0.05, 0.1, 0.5, 1, 5],
    });

    this.activeTenants = new Gauge({
      name: 'active_tenants_total',
      help: 'Total number of active tenants',
    });

    this.totalRegistrations = new Counter({
      name: 'tenant_registrations_total',
      help: 'Total number of tenant registrations',
    });

    this.revenueTotal = new Counter({
      name: 'revenue_total_usd',
      help: 'Total revenue in USD',
    });

    this.apiCallsByPlan = new Counter({
      name: 'api_calls_by_plan_total',
      help: 'API calls count by plan',
      labelNames: ['plan'],
    });
  }
}
```

```
// src/metrics/metrics.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable, tap } from 'rxjs';
import { CustomMetricsService } from './custom-metrics.service';

@Injectable()
export class MetricsInterceptor implements NestInterceptor {
  constructor(private metrics: CustomMetricsService) {}

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const req = context.switchToHttp().getRequest();
    const start = Date.now();

    return next.handle().pipe(
      tap(() => {
        const duration = (Date.now() - start) / 1000;
        this.metrics.httpRequestDuration.observe(
          { method: req.method, route: req.route?.path, status: 200 },
          duration,
        );
      }),
    );
  }
}
```

## Cara Integrasi & Pengujian
Registrasikan `MetricsInterceptor` global. Panggil `this.metrics.activeTenants.inc()` saat tenant baru. Query di Prometheus: `active_tenants_total`, `tenant_registrations_total`.
