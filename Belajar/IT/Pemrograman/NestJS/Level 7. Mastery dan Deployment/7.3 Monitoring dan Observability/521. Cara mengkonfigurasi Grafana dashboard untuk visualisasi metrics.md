# 521. Cara mengkonfigurasi Grafana dashboard untuk visualisasi metrics

## Definisi & Target
Grafana menampilkan metrics Prometheus dalam bentuk dashboard visual. Target: dashboard real-time untuk HTTP requests, error rate, memory, dan business metrics.

## Komponen & Nest CLI Command
```
docker run -d -p 3001:3000 grafana/grafana
```

## Kode Implementasi (Per File)

```
# docker-compose.grafana.yml
version: '3.8'

services:
  grafana:
    image: grafana/grafana:latest
    ports:
      - '3001:3000'
    environment:
      - GF_SECURITY_ADMIN_PASSWORD=admin
      - GF_INSTALL_PLUGINS=grafana-piechart-panel
    volumes:
      - grafana-storage:/var/lib/grafana
      - ./grafana/datasources:/etc/grafana/provisioning/datasources
      - ./grafana/dashboards:/etc/grafana/provisioning/dashboards

  prometheus:
    image: prom/prometheus:latest
    ports:
      - '9090:9090'
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml

volumes:
  grafana-storage:
```

```
# grafana/datasources/datasource.yml
apiVersion: 1
datasources:
  - name: Prometheus
    type: prometheus
    access: proxy
    url: http://prometheus:9090
    isDefault: true
```

```
# grafana/dashboards/nestjs-dashboard.json
{
  "title": "NestJS App Dashboard",
  "panels": [
    {
      "title": "HTTP Request Rate",
      "type": "graph",
      "targets": [{ "expr": "rate(http_requests_total[5m])" }]
    },
    {
      "title": "Request Duration (p95)",
      "type": "graph",
      "targets": [{ "expr": "histogram_quantile(0.95, rate(http_request_duration_seconds_bucket[5m]))" }]
    },
    {
      "title": "Active Tenants",
      "type": "stat",
      "targets": [{ "expr": "active_tenants_total" }]
    },
    {
      "title": "Revenue",
      "type": "stat",
      "targets": [{ "expr": "revenue_total_usd" }]
    }
  ]
}
```

## Cara Integrasi & Pengujian
Jalankan Grafana & Prometheus. Login Grafana `http://localhost:3001` (admin/admin). Add Prometheus datasource. Import dashboard JSON. Lihat visualisasi real-time.
