# 546. Cara menggunakan nestjs-cls yaitu Continuation Local Storage untuk request context

## Definisi & Target
`nestjs-cls` adalah wrapper CLS (AsyncLocalStorage) untuk NestJS. Target: menyimpan context request (user, tenantId, correlationId) tanpa dependency injection berantai.

## Komponen & Nest CLI Command
```
npm install nestjs-cls
```

## Kode Implementasi (Per File)

```
// src/cls/cls.module.ts
import { Global, Module } from '@nestjs/common';
import { ClsModule } from 'nestjs-cls';
import { randomUUID } from 'crypto';

@Global()
@Module({
  imports: [
    ClsModule.forRoot({
      middleware: { mount: true, generateId: true, idGenerator: () => randomUUID() },
      global: true,
    }),
  ],
})
export class ClsContextModule {}
```

```
// src/cls/context.service.ts
import { Injectable } from '@nestjs/common';
import { ClsService } from 'nestjs-cls';

@Injectable()
export class RequestContextService {
  constructor(private readonly cls: ClsService) {}

  get requestId(): string {
    return this.cls.getId();
  }

  get tenantId(): string | undefined {
    return this.cls.get('tenantId');
  }

  setTenantId(id: string) {
    this.cls.set('tenantId', id);
  }

  get userId(): string | undefined {
    return this.cls.get('userId');
  }

  setUserId(id: string) {
    this.cls.set('userId', id);
  }

  get correlationId(): string | undefined {
    return this.cls.get('correlationId');
  }

  setCorrelationId(id: string) {
    this.cls.set('correlationId', id);
  }
}
```

```
// src/modules/sample/sample.service.ts
import { Injectable } from '@nestjs/common';
import { RequestContextService } from '../../cls/context.service';

@Injectable()
export class SampleService {
  constructor(private ctx: RequestContextService) {}

  doSomething() {
    console.log({
      requestId: this.ctx.requestId,
      tenantId: this.ctx.tenantId,
      userId: this.ctx.userId,
    });
  }
}
```

## Cara Integrasi & Pengujian
Import `ClsContextModule`. Di middleware, panggil `context.setTenantId(id)`. Di service manapun, inject `RequestContextService` dan akses context tanpa parameter.
