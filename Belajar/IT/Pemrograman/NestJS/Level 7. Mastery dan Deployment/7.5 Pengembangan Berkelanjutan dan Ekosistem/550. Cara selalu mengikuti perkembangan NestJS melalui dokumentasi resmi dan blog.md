# 550. Cara selalu mengikuti perkembangan NestJS melalui dokumentasi resmi dan blog

## Definisi & Target
Ekosistem NestJS terus berkembang. Target: tetap update dengan fitur baru, best practices, dan perubahan breaking melalui sumber resmi.

## Komponen & Nest CLI Command
```
npm update -g @nestjs/cli
npm outdated
```

## Kode Implementasi (Per File)

```
// UPDATE_CHECKLIST.md
# NestJS Update Checklist

## Sumber Informasi
- 📖 Dokumentasi Resmi: https://docs.nestjs.com
- 🐦 Twitter/X: @nestframework
- 📝 Blog: https://trilon.io/blog
- 💬 Discord: https://discord.gg/nestjs
- 📺 YouTube: NestJS官方
- 📦 GitHub: https://github.com/nestjs/nest
- 📰 Changelog: https://github.com/nestjs/nest/blob/master/CHANGELOG.md
- 📚 Awesome NestJS: https://github.com/juliandavidmr/awesome-nestjs

## Rutin Bulanan
- [ ] Cek rilis baru NestJS di GitHub Releases
- [ ] Baca changelog untuk breaking changes
- [ ] Update @nestjs/core, @nestjs/common, @nestjs/cli
- [ ] Cek deprecated decorators/features
- [ ] Review migration guide jika major version baru

## Perubahan Major (v9 → v10 → v11)
- Ikuti migration guide: https://docs.nestjs.com/migration-guide
- Cek peer dependencies (RxJS, TypeScript, Node.js)
- Test komprehensif sebelum upgrade production

## Tools untuk Tetap Update
- `npm outdated` — lihat package yang perlu diupdate
- `npx npm-check-updates` — interactive update
- Dependabot / Renovate — auto PR untuk update
- GitHub Watch Releases — notifikasi rilis baru
```

```
// .github/renovate.json — auto dependency updates
{
  "$schema": "https://docs.renovatebot.com/renovate-schema.json",
  "extends": ["config:base"],
  "labels": ["dependencies"],
  "packageRules": [
    {
      "matchPackagePrefixes": ["@nestjs/"],
      "groupName": "NestJS packages",
      "automerge": false
    },
    {
      "matchUpdateTypes": ["patch"],
      "automerge": true
    }
  ]
}
```

## Cara Integrasi & Pengujian
Subscribe ke NestJS newsletter. Set Dependabot/Renovate untuk auto-update. Jadwalkan review bulanan: cek changelog, update package, jalankan test.
