# 542. Cara menggunakan NestJS CLI plugins untuk meningkatkan produktivitas

## Definisi & Target
NestJS CLI plugins (swagger, graphql, prisma) mengotomatiskan boilerplate dan menjaga konsistensi. Target: generate dan synchronize kode secara otomatis.

## Komponen & Nest CLI Command
```
nest g application
nest g library
nest g resource
nest g class
nest g interface
```

## Kode Implementasi (Per File)

```
// nest-cli.json — konfigurasi CLI plugins
{
  "$schema": "https://json.schemastore.org/nest-cli",
  "collection": "@nestjs/schematics",
  "sourceRoot": "src",
  "compilerOptions": {
    "deleteOutDir": true,
    "plugins": [
      {
        "name": "@nestjs/swagger",
        "options": {
          "classValidatorShim": true,
          "introspectComments": true,
          "dtoKeyOfComment": "description",
          "controllerKeyOfComment": "description"
        }
      },
      {
        "name": "@nestjs/graphql",
        "options": {
          "typePaths": ["**/*.graphql"]
        }
      }
    ]
  },
  "generateOptions": {
    "spec": false,
    "flat": false
  }
}
```

```
// package.json — script CLI custom
{
  "scripts": {
    "generate:resource": "nest g resource",
    "generate:module": "nest g module",
    "generate:service": "nest g service",
    "generate:guard": "nest g guard",
    "generate:interceptor": "nest g interceptor",
    "generate:pipe": "nest g pipe",
    "generate:filter": "nest g filter",
    "generate:decorator": "nest g decorator",
    "generate:middleware": "nest g middleware",
    "generate:all": "nest g resource $NAME --no-spec && nest g service $NAME && nest g guard $NAME"
  }
}
```

## Cara Integrasi & Pengujian
Install `@nestjs/cli` global. Gunakan `nest g resource users` — CLI generate CRUD lengkap. Tambahkan plugin Swagger di `nest-cli.json` → decorator otomatis ter-generate.
