# 549. Cara membangun dan mempublish NestJS library ke npm registry

## Definisi & Target
Publikasikan NestJS module ke npm agar bisa digunakan oleh developer lain. Target: library dengan konfigurasi async, proper typing, dan dokumentasi.

## Komponen & Nest CLI Command
```
nest g library nestjs-rate-limiter
npm run build:nestjs-rate-limiter
npm publish
```

## Kode Implementasi (Per File)

```
// nest-cli.json (monorepo)
{
  "projects": {
    "rate-limiter": {
      "type": "library",
      "root": "libs/rate-limiter",
      "entryFile": "index",
      "sourceRoot": "libs/rate-limiter/src",
      "compilerOptions": { "tsConfigPath": "libs/rate-limiter/tsconfig.lib.json" }
    }
  }
}
```

```
// libs/rate-limiter/package.json
{
  "name": "@myorg/nestjs-rate-limiter",
  "version": "1.0.0",
  "description": "Rate limiter module for NestJS",
  "main": "dist/index.js",
  "types": "dist/index.d.ts",
  "publishConfig": {
    "access": "public"
  },
  "keywords": ["nestjs", "rate-limit", "throttle"],
  "peerDependencies": {
    "@nestjs/common": "^10.0.0",
    "@nestjs/core": "^10.0.0",
    "rxjs": "^7.0.0"
  },
  "files": ["dist"],
  "scripts": {
    "build": "nest build rate-limiter",
    "prepublishOnly": "npm run build"
  }
}
```

```
// libs/rate-limiter/src/index.ts
export { RateLimiterModule } from './rate-limiter.module';
export { RateLimiterService } from './rate-limiter.service';
export { RateLimit } from './rate-limit.decorator';
export { RateLimiterOptions, RATE_LIMITER_OPTIONS } from './rate-limiter-options.interface';
```

```
// libs/rate-limiter/src/rate-limiter-options.interface.ts
export interface RateLimiterOptions {
  ttl: number;
  limit: number;
  storage?: 'memory' | 'redis';
  redisHost?: string;
  redisPort?: number;
  global?: boolean;
}

export const RATE_LIMITER_OPTIONS = 'RATE_LIMITER_OPTIONS';
```

```
// publish.sh — script publish
#!/bin/bash
set -e

npm run build:rate-limiter
cp libs/rate-limiter/package.json dist/libs/rate-limiter/
cp libs/rate-limiter/README.md dist/libs/rate-limiter/
cd dist/libs/rate-limiter
npm publish --access public
```

## Cara Integrasi & Pengujian
Test lokal: `npm link`, install di project lain. Pastikan `peerDependencies` benar. Publikasikan: `npm login`, lalu `npm publish`. Cek di `npmjs.com/package/@myorg/nestjs-rate-limiter`.
