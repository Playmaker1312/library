# 490. Cara menginstal dan mengkonfigurasi Stripe dalam NestJS

## Definisi & Target
Instalasi dan konfigurasi Stripe SDK di NestJS agar siap dipakai untuk payment processing. Target: Stripe client yang terkoneksi dengan secret key dan API version terbaru.

## Komponen & Nest CLI Command
```
npm install stripe @stripe/stripe-js
nest g module billing
nest g service billing/stripe-config
```

## Kode Implementasi (Per File)

```
// src/billing/stripe-config.service.ts
import { Injectable, OnModuleInit } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import Stripe from 'stripe';

@Injectable()
export class StripeConfigService implements OnModuleInit {
  public stripe: Stripe;

  constructor(private config: ConfigService) {}

  onModuleInit() {
    this.stripe = new Stripe(this.config.get('STRIPE_SECRET_KEY'), {
      apiVersion: '2025-02-24.acacia',
      typescript: true,
    });
  }

  async constructWebhookEvent(payload: Buffer, signature: string) {
    return this.stripe.webhooks.constructEvent(
      payload,
      signature,
      this.config.get('STRIPE_WEBHOOK_SECRET'),
    );
  }
}
```

```
// .env
STRIPE_SECRET_KEY=sk_test_XXXXXXXXXXXXXXXXXXXX
STRIPE_WEBHOOK_SECRET=whsec_XXXXXXXXXXXXXXXXXXXX

```

## Cara Integrasi & Pengujian
Buat akun Stripe, ambil API keys dari Dashboard. Uji: inject `StripeConfigService` dan panggil `this.stripe.customers.create({ email: 'test@test.com' })`. Cek customer muncul di Stripe Dashboard.
