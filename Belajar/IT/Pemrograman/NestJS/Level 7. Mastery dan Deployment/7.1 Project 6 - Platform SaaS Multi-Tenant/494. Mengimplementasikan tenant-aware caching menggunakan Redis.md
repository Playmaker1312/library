# 494. Mengimplementasikan tenant-aware caching menggunakan Redis

## Definisi & Target
Cache yang terisolasi per tenant — data tenant A tidak bisa diakses tenant B. Gunakan prefix key dengan `tenantId`. Target: Redis module yang otomatis menambahkan prefix tenant.

## Komponen & Nest CLI Command
```
npm install @nestjs/cache-manager cache-manager redis
nest g module redis-cache
nest g service redis-cache/cache
```

## Kode Implementasi (Per File)

```
// src/redis-cache/cache.service.ts
import { Injectable } from '@nestjs/common';
import { CacheService } from '@nestjs/cache-manager';
import { TenantContextService } from '../../tenancy/tenant-context.service';

@Injectable()
export class TenantCacheService {
  constructor(
    private readonly cache: CacheService,
    private readonly context: TenantContextService,
  ) {}

  private prefixKey(key: string): string {
    const tenantId = this.context.getTenantId();
    return `tenant:${tenantId}:${key}`;
  }

  async get<T>(key: string): Promise<T | undefined> {
    return this.cache.get<T>(this.prefixKey(key));
  }

  async set<T>(key: string, value: T, ttl?: number): Promise<void> {
    return this.cache.set(this.prefixKey(key), value, ttl);
  }

  async del(key: string): Promise<void> {
    return this.cache.del(this.prefixKey(key));
  }

  async reset(): Promise<void> {
    return this.cache.reset();
  }
}
```

```
// src/redis-cache/redis-cache.module.ts
import { Module, CacheModule } from '@nestjs/common';
import { redisStore } from 'cache-manager-redis';
import { TenantCacheService } from './cache.service';
import { TenancyModule } from '../../tenancy/tenancy.module';

@Module({
  imports: [
    CacheModule.registerAsync({
      useFactory: () => ({
        store: redisStore,
        host: process.env.REDIS_HOST || 'localhost',
        port: parseInt(process.env.REDIS_PORT || '6379'),
      }),
    }),
    TenancyModule,
  ],
  providers: [TenantCacheService],
  exports: [TenantCacheService],
})
export class RedisCacheModule {}
```

## Cara Integrasi & Pengujian
Pastikan Redis running. Inject `TenantCacheService` di service, panggil `set('data', {...})`. Uji: tenant A set cache → tenant B `get('data')` → undefined.
