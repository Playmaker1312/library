# 489. Membangun subscription dan billing system menggunakan Stripe

## Definisi & Target
Integrasi Stripe Subscription untuk menagih tenant berdasarkan plan (monthly/yearly). Target: webhook Stripe → update status subscription tenant.

## Komponen & Nest CLI Command
```
npm install @stripe/stripe-js stripe
nest g module billing
nest g service billing/stripe
nest g controller billing/webhook
```

## Kode Implementasi (Per File)

```
// src/billing/stripe.service.ts
import { Injectable } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import Stripe from 'stripe';

@Injectable()
export class StripeService {
  public stripe: Stripe;

  constructor(private config: ConfigService) {
    this.stripe = new Stripe(this.config.get('STRIPE_SECRET_KEY'), {
      apiVersion: '2025-02-24.acacia',
    });
  }

  async createSubscription(customerId: string, priceId: string) {
    return this.stripe.subscriptions.create({
      customer: customerId,
      items: [{ price: priceId }],
      payment_behavior: 'default_incomplete',
      expand: ['latest_invoice.payment_intent'],
    });
  }

  async cancelSubscription(subscriptionId: string) {
    return this.stripe.subscriptions.cancel(subscriptionId);
  }
}
```

```
// src/billing/billing.module.ts
import { Module } from '@nestjs/common';
import { StripeService } from './stripe.service';
import { WebhookController } from './webhook.controller';

@Module({
  providers: [StripeService],
  controllers: [WebhookController],
  exports: [StripeService],
})
export class BillingModule {}
```

## Cara Integrasi & Pengujian
Set `STRIPE_SECRET_KEY` dan `STRIPE_WEBHOOK_SECRET` di `.env`. Uji: buat subscription via Stripe dashboard, pastikan webhook diterima dan status tenant berubah.
