# 487. Mengimplementasikan tenant provisioning yaitu pembuatan tenant baru dengan schema database

## Definisi & Target
Saat tenant baru mendaftar, sistem harus: (1) membuat database baru, (2) menjalankan migrasi, (3) mencatat tenant di master DB. Target: provisioning otomatis via API.

## Komponen & Nest CLI Command
```
nest g service tenancy/provisioning
npm install @nestjs/config
```

## Kode Implementasi (Per File)

```
// src/tenancy/provisioning.service.ts
import { Injectable } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import { execSync } from 'child_process';
import { PrismaClient } from '@prisma/client';

@Injectable()
export class ProvisioningService {
  private masterPrisma = new PrismaClient();

  constructor(private config: ConfigService) {}

  async provisionTenant(tenantId: string, dbName: string, dbPassword: string) {
    const dbUrl = `postgresql://${dbName}:${dbPassword}@${this.config.get('DB_HOST')}:5432/${dbName}`;

    execSync(`createdb -U postgres ${dbName}`);
    execSync(`DATABASE_URL="${dbUrl}" npx prisma migrate deploy`, {
      env: { ...process.env, DATABASE_URL: dbUrl },
    });

    await this.masterPrisma.tenant.create({
      data: {
        id: tenantId,
        dbName,
        dbUrl,
        isActive: true,
      },
    });

    return { tenantId, dbUrl };
  }
}
```

## Cara Integrasi & Pengujian
Panggil `provisionTenant` dari registration endpoint. Pastikan PostgreSQL terinstall dan `psql` accessible. Uji: buat tenant baru, cek database muncul, lalu akses API tenant.
