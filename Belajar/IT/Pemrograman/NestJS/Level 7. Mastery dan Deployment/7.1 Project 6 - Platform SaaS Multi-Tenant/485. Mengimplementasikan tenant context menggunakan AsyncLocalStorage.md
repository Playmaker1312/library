# 485. Mengimplementasikan tenant context menggunakan AsyncLocalStorage

## Definisi & Target
`AsyncLocalStorage` dari Node.js menyimpan konteks tenant secara asynchronous tanpa perlu meneruskan parameter secara eksplisit. Target: akses `tenantId` dari mana pun dalam request lifecycle tanpa dependency injection.

## Komponen & Nest CLI Command
```
nest g service tenancy/tenant-context
```

## Kode Implementasi (Per File)

```
// src/tenancy/tenant-context.service.ts
import { Injectable } from '@nestjs/common';
import { AsyncLocalStorage } from 'async_hooks';

@Injectable()
export class TenantContextService {
  private readonly storage = new AsyncLocalStorage<string>();

  run(tenantId: string, callback: () => void) {
    this.storage.run(tenantId, callback);
  }

  getTenantId(): string | undefined {
    return this.storage.getStore();
  }
}
```

```
// src/common/decorators/tenant-id.decorator.ts
import { createParamDecorator, ExecutionContext } from '@nestjs/common';
import { TenantContextService } from '../../tenancy/tenant-context.service';

export const TenantId = createParamDecorator(
  (data: unknown, ctx: ExecutionContext): string | undefined => {
    const contextService = ctx.switchToHttp().getRequest().next
      ? undefined
      : undefined;
    return ctx.switchToHttp().getRequest().tenantId;
  },
);
```

## Cara Integrasi & Pengujian
Inject `TenantContextService` di service manapun dan panggil `getTenantId()`. Pastikan `TenantMiddleware` memanggil `context.run()` sebelum handler. Uji dengan dua request concurrent — masing-masing harus memiliki tenantId yang benar.
