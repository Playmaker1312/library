# 491. Mengimplementasikan Stripe webhook handling untuk event subscription

## Definisi & Target
Stripe mengirim event webhook (checkout.session.completed, invoice.paid, customer.subscription.deleted). Target: update status subscription tenant di database berdasarkan event Stripe.

## Komponen & Nest CLI Command
```
nest g controller billing/webhook
```

## Kode Implementasi (Per File)

```
// src/billing/webhook.controller.ts
import { Controller, Post, Headers, Req } from '@nestjs/common';
import { Request } from 'express';
import { StripeConfigService } from './stripe-config.service';
import { StripeWebhookService } from './stripe-webhook.service';

@Controller('billing/webhook')
export class WebhookController {
  constructor(
    private readonly config: StripeConfigService,
    private readonly handler: StripeWebhookService,
  ) {}

  @Post()
  async handleWebhook(
    @Req() req: Request,
    @Headers('stripe-signature') signature: string,
  ) {
    const event = await this.config.constructWebhookEvent(
      req.body as unknown as Buffer,
      signature,
    );

    switch (event.type) {
      case 'checkout.session.completed':
        await this.handler.handleCheckoutCompleted(event.data.object);
        break;
      case 'invoice.paid':
        await this.handler.handleInvoicePaid(event.data.object);
        break;
      case 'customer.subscription.deleted':
        await this.handler.handleSubscriptionDeleted(event.data.object);
        break;
    }

    return { received: true };
  }
}
```

```
// src/billing/stripe-webhook.service.ts
import { Injectable } from '@nestjs/common';
import { PrismaService } from '../../tenancy/prisma.service';

@Injectable()
export class StripeWebhookService {
  constructor(private readonly prisma: PrismaService) {}

  async handleCheckoutCompleted(session: any) {
    const { client_reference_id: tenantId, subscription, customer } = session;
    await this.prisma.getClient().tenant.update({
      where: { id: tenantId },
      data: {
        stripeSubscriptionId: subscription,
        stripeCustomerId: customer,
        status: 'active',
      },
    });
  }

  async handleInvoicePaid(invoice: any) {
    // Update subscription period
  }

  async handleSubscriptionDeleted(subscription: any) {
    await this.prisma.getClient().tenant.update({
      where: { stripeSubscriptionId: subscription.id },
      data: { status: 'cancelled' },
    });
  }
}
```

## Cara Integrasi & Pengujian
Expose endpoint di internet (ngrok untuk dev). Set webhook URL di Stripe Dashboard. Uji: checkout Stripe → cek status tenant berubah jadi 'active'.
