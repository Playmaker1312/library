# 493. Membangun feature flag system untuk mengontrol fitur berdasarkan plan

## Definisi & Target
Kontrol fitur mana yang bisa diakses tenant berdasarkan subscription plan (Free, Pro, Enterprise). Target: guard/decorator yang mengecek feature flag sebelum eksekusi handler.

## Komponen & Nest CLI Command
```
nest g module feature-flags
nest g service feature-flags/flag
nest g guard feature-flags/feature
```

## Kode Implementasi (Per File)

```
// src/feature-flags/flag.service.ts
import { Injectable } from '@nestjs/common';

interface FeatureConfig {
  [plan: string]: string[];
}

@Injectable()
export class FlagService {
  private features: FeatureConfig = {
    free: ['basic-read'],
    pro: ['basic-read', 'basic-write', 'export'],
    enterprise: ['basic-read', 'basic-write', 'export', 'audit-log', 'sso'],
  };

  getFeaturesForPlan(plan: string): string[] {
    return this.features[plan] ?? this.features.free;
  }

  isFeatureEnabled(plan: string, feature: string): boolean {
    return this.getFeaturesForPlan(plan).includes(feature);
  }
}
```

```
// src/feature-flags/feature.guard.ts
import { Injectable, CanActivate, ExecutionContext } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { FlagService } from './flag.service';
import { FEATURE_KEY } from './feature.decorator';

@Injectable()
export class FeatureGuard implements CanActivate {
  constructor(
    private readonly reflector: Reflector,
    private readonly flag: FlagService,
  ) {}

  canActivate(context: ExecutionContext): boolean {
    const feature = this.reflector.getAllAndOverride<string>(FEATURE_KEY, [
      context.getHandler(),
      context.getClass(),
    ]);

    if (!feature) return true;

    const req = context.switchToHttp().getRequest();
    const plan = req.tenant?.plan ?? 'free';

    return this.flag.isFeatureEnabled(plan, feature);
  }
}
```

```
// src/feature-flags/feature.decorator.ts
import { SetMetadata } from '@nestjs/common';

export const FEATURE_KEY = 'feature';
export const RequireFeature = (feature: string) => SetMetadata(FEATURE_KEY, feature);
```

## Cara Integrasi & Pengujian
Pasang `@RequireFeature('export')` di controller. Uji: tenant Free akses endpoint export → 403. Tenant Pro → 200.
