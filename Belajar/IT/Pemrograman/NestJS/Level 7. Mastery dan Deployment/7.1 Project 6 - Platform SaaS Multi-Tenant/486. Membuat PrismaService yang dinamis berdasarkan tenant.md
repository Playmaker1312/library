# 486. Membuat PrismaService yang dinamis berdasarkan tenant

## Definisi & Target
`PrismaService` dinamis — setiap tenant punya koneksi Prisma ke database masing-masing. Target: request ke tenant A menggunakan database tenant A, tanpa bocor data ke tenant B.

## Komponen & Nest CLI Command
```
npm install @prisma/client prisma
nest g service tenancy/prisma
```

## Kode Implementasi (Per File)

```
// src/tenancy/prisma.service.ts
import { Injectable, OnModuleDestroy } from '@nestjs/common';
import { PrismaClient } from '@prisma/client';
import { TenantContextService } from './tenant-context.service';

@Injectable()
export class PrismaService implements OnModuleDestroy {
  private clients: Map<string, PrismaClient> = new Map();

  constructor(private readonly context: TenantContextService) {}

  getClient(): PrismaClient {
    const tenantId = this.context.getTenantId();
    if (!tenantId) throw new Error('Tenant context not found');

    if (!this.clients.has(tenantId)) {
      const dbUrl = process.env[`DATABASE_URL_${tenantId.toUpperCase()}`]
        ?? process.env.DATABASE_URL;

      this.clients.set(tenantId, new PrismaClient({
        datasources: { db: { url: dbUrl } },
      }));
    }

    return this.clients.get(tenantId);
  }

  async onModuleDestroy() {
    for (const client of this.clients.values()) {
      await client.$disconnect();
    }
  }
}
```

```
// src/tenancy/tenancy.module.ts
import { Global, Module } from '@nestjs/common';
import { PrismaService } from './prisma.service';
import { TenantContextService } from './tenant-context.service';

@Global()
@Module({
  providers: [PrismaService, TenantContextService],
  exports: [PrismaService, TenantContextService],
})
export class TenancyModule {}
```

## Cara Integrasi & Pengujian
Import `TenancyModule` di `AppModule`. Di service, inject `PrismaService` dan panggil `this.prisma.getClient().user.findMany()`. Uji: akses endpoint dengan tenant berbeda dan pastikan data terisolasi.
