# 483. Mengimplementasikan tenant identification menggunakan subdomain atau header

## Definisi & Target
Ekstrak identitas tenant dari setiap request — dari **subdomain** (`tenant1.app.com`) atau **header** (`X-Tenant-ID`). Target: middleware membaca request dan menyimpan tenant ID untuk dipakai downstream.

## Komponen & Nest CLI Command
```
nest g middleware tenancy/tenant
```

## Kode Implementasi (Per File)

```
// src/tenancy/tenant-identification.service.ts
import { Injectable, Scope } from '@nestjs/common';
import { REQUEST } from '@nestjs/core';

@Injectable({ scope: Scope.REQUEST })
export class TenantIdentificationService {
  private _tenantId: string;

  get tenantId(): string {
    return this._tenantId;
  }

  extractFromSubdomain(host: string): string | null {
    const parts = host.split('.');
    if (parts.length >= 3) return parts[0];
    return null;
  }

  extractFromHeader(headerValue: string): string {
    return headerValue;
  }

  setTenantId(id: string) {
    this._tenantId = id;
  }
}
```

## Cara Integrasi & Pengujian
Registrasikan `TenantIdentificationService` sebagai provider. Panggil `extractFromSubdomain` atau `extractFromHeader` di middleware. Uji: kirim request dengan header `X-Tenant-ID: tenant-abc` dan pastikan `tenantId` terbaca.
