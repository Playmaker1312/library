# 492. Mengimplementasikan usage-based billing dengan Stripe Metering

## Definisi & Target
Tagih tenant berdasarkan pemakaian (e.g., jumlah API calls, storage). Stripe Metering memungkinkan pelaporan usage real-time. Target: kirim usage metrics ke Stripe setiap kali tenant menggunakan resource.

## Komponen & Nest CLI Command
```
nest g service billing/usage-metering
```

## Kode Implementasi (Per File)

```
// src/billing/usage-metering.service.ts
import { Injectable } from '@nestjs/common';
import { StripeConfigService } from './stripe-config.service';
import { TenantContextService } from '../../tenancy/tenant-context.service';
import { PrismaService } from '../../tenancy/prisma.service';

@Injectable()
export class UsageMeteringService {
  constructor(
    private readonly stripe: StripeConfigService,
    private readonly context: TenantContextService,
    private readonly prisma: PrismaService,
  ) {}

  async reportUsage(metricName: string, quantity: number) {
    const tenantId = this.context.getTenantId();
    const tenant = await this.prisma.getClient().tenant.findUnique({
      where: { id: tenantId },
    });

    if (!tenant?.stripeSubscriptionId) return;

    await this.stripe.stripe.subscriptionItems.list({
      subscription: tenant.stripeSubscriptionId,
    }).then(async (items) => {
      for (const item of items.data) {
        await this.stripe.stripe.subscriptionItems.createUsageRecord(
          item.id,
          { quantity, timestamp: Math.floor(Date.now() / 1000) },
        );
      }
    });
  }

  async getCurrentUsage(tenantId: string) {
    return this.prisma.getClient().usageRecord.groupBy({
      by: ['metric'],
      where: { tenantId },
      _sum: { quantity: true },
    });
  }
}
```

## Cara Integrasi & Pengujian
Set price Stripe dengan metered billing. Panggil `reportUsage('api_calls', 1)` setiap request. Uji: akses endpoint beberapa kali → cek usage di Stripe Dashboard.
