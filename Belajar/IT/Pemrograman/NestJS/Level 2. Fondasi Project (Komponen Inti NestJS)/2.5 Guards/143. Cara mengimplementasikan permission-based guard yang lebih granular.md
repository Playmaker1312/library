# 143. Cara mengimplementasikan permission-based guard yang lebih granular

## Definisi & Target
Permission-based guard memberikan kontrol akses lebih detail daripada role. Misalnya, user bisa memiliki permission `read:users`, `write:users`, `delete:users`. Guard memeriksa permission spesifik yang dibutuhkan suatu endpoint, bukan hanya role general.

## Komponen & Nest CLI Command
```
nest g guard common/permission --no-spec
```
File: `src/common/guards/permission.guard.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/decorators/permission.decorator.ts
import { SetMetadata } from '@nestjs/common';

export const PERMISSIONS_KEY = 'permissions';
export const RequirePermissions = (...permissions: string[]) =>
  SetMetadata(PERMISSIONS_KEY, permissions);
```

```typescript
// src/common/guards/permission.guard.ts
import { Injectable, CanActivate, ExecutionContext, ForbiddenException } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { PERMISSIONS_KEY } from '../decorators/permission.decorator';

@Injectable()
export class PermissionGuard implements CanActivate {
  constructor(private readonly reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    const requiredPermissions = this.reflector.getAllAndOverride<string[]>(PERMISSIONS_KEY, [
      context.getHandler(),
      context.getClass(),
    ]);

    if (!requiredPermissions || requiredPermissions.length === 0) {
      return true;
    }

    const request = context.switchToHttp().getRequest();
    const user = request.user;
    const userPermissions: string[] = user?.permissions || [];

    const hasAllPermissions = requiredPermissions.every(p => userPermissions.includes(p));

    if (!hasAllPermissions) {
      const missing = requiredPermissions.filter(p => !userPermissions.includes(p));
      throw new ForbiddenException(
        `Missing permissions: ${missing.join(', ')}`,
      );
    }

    return true;
  }
}
```

```typescript
// src/users/users.controller.ts
import { Controller, Get, Post, Delete, UseGuards } from '@nestjs/common';
import { RequirePermissions } from '../common/decorators/permission.decorator';
import { PermissionGuard } from '../common/guards/permission.guard';

@Controller('users')
export class UsersController {
  @Get()
  @UseGuards(PermissionGuard)
  @RequirePermissions('users:read')
  findAll() {
    return [{ id: 1, name: 'User' }];
  }

  @Post()
  @UseGuards(PermissionGuard)
  @RequirePermissions('users:create')
  create() {
    return { message: 'Created' };
  }

  @Delete(':id')
  @UseGuards(PermissionGuard)
  @RequirePermissions('users:delete')
  remove() {
    return { message: 'Deleted' };
  }
}
```

## Cara Integrasi & Pengujian

Permission lebih granular daripada role. Satu user bisa memiliki banyak permission.

**Test dengan curl:**
```bash
curl -H "Authorization: Bearer token" http://localhost:3000/users
# user.permissions = ['users:read', 'users:create'] -> 200

curl -H "Authorization: Bearer token" http://localhost:3000/users -X DELETE
# {"message":"Missing permissions: users:delete","statusCode":403}
```
