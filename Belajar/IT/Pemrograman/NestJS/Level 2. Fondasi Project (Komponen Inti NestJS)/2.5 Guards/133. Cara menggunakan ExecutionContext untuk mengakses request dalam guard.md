# 133. Cara menggunakan ExecutionContext untuk mengakses request dalam guard

## Definisi & Target
`ExecutionContext` menyediakan akses ke request object dan informasi eksekusi saat ini. Method `switchToHttp().getRequest()` mengembalikan request Express/ Fastify. Guard membaca data request (headers, user, params) untuk membuat keputusan otorisasi.

## Komponen & Nest CLI Command
Tidak ada CLI command.
File: `src/common/guards/request-context.guard.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/guards/request-context.guard.ts
import { Injectable, CanActivate, ExecutionContext } from '@nestjs/common';
import { Request } from 'express';

@Injectable()
export class RequestContextGuard implements CanActivate {
  canActivate(context: ExecutionContext): boolean {
    const request = context.switchToHttp().getRequest<Request>();

    const userAgent = request.headers['user-agent'];
    const ip = request.ip;
    const method = request.method;
    const path = request.route?.path || request.url;

    console.log(`[Guard] ${method} ${path} - IP: ${ip} - Agent: ${userAgent}`);

    const apiKey = request.headers['x-api-key'];
    if (apiKey === 'internal-service-key') {
      (request as any).serviceName = 'internal';
    }

    return true;
  }
}
```

```typescript
// src/common/guards/extraction-demo.guard.ts
import { Injectable, CanActivate, ExecutionContext, UnauthorizedException } from '@nestjs/common';
import { Request } from 'express';

@Injectable()
export class ExtractionDemoGuard implements CanActivate {
  canActivate(context: ExecutionContext): boolean {
    const request = context.switchToHttp().getRequest<Request>();

    const authHeader = request.headers['authorization'];
    if (!authHeader) {
      throw new UnauthorizedException();
    }

    const parts = authHeader.split(' ');
    if (parts.length !== 2 || parts[0] !== 'Bearer') {
      throw new UnauthorizedException('Invalid auth header format');
    }

    const token = parts[1];

    try {
      const decoded = JSON.parse(Buffer.from(token.split('.')[1], 'base64').toString());
      (request as any).user = decoded;
    } catch {
      throw new UnauthorizedException('Invalid token');
    }

    return true;
  }
}
```

## Cara Integrasi & Pengujian

Guard bisa membaca semua properti request dan memodifikasinya (misalnya menambahkan `request.user`) sebelum mencapai handler.

**Test dengan curl:**
```bash
curl -H "x-api-key: internal-service-key" http://localhost:3000/internal
# Console: [Guard] GET /internal - IP: ::1 - Agent: curl/8.0
```
