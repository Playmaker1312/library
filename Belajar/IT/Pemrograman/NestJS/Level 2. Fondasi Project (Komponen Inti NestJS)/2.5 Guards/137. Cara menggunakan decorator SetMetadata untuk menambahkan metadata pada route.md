# 137. Cara menggunakan decorator SetMetadata untuk menambahkan metadata pada route

## Definisi & Target
`@SetMetadata()` menambahkan metadata kustom ke route handler. Metadata ini bisa dibaca oleh guard atau interceptor menggunakan `Reflector`. Berguna untuk menentukan role yang diizinkan, permission yang diperlukan, atau flag publik/private pada suatu endpoint.

## Komponen & Nest CLI Command
Tidak ada CLI command.
File: `src/users/users.controller.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/decorators/roles.decorator.ts
import { SetMetadata } from '@nestjs/common';

export const ROLES_KEY = 'roles';
export const Roles = (...roles: string[]) => SetMetadata(ROLES_KEY, roles);
```

```typescript
// src/common/decorators/permissions.decorator.ts
import { SetMetadata } from '@nestjs/common';

export const PERMISSIONS_KEY = 'permissions';
export const Permissions = (...perms: string[]) => SetMetadata(PERMISSIONS_KEY, perms);
```

```typescript
// src/users/users.controller.ts
import { Controller, Get, Post, Delete, SetMetadata } from '@nestjs/common';
import { Roles, ROLES_KEY } from '../common/decorators/roles.decorator';

@Controller('users')
export class UsersController {
  @Get()
  @SetMetadata('isPublic', true)
  findAll() {
    return [{ id: 1, name: 'Public' }];
  }

  @Post()
  @Roles('admin')
  create() {
    return { message: 'Created' };
  }

  @Delete(':id')
  @Roles('admin', 'superadmin')
  @SetMetadata('auditLog', true)
  remove() {
    return { message: 'Deleted' };
  }
}
```

```typescript
// src/common/guards/metadata-reader.guard.ts
import { Injectable, CanActivate, ExecutionContext } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { ROLES_KEY } from '../decorators/roles.decorator';

@Injectable()
export class MetadataReaderGuard implements CanActivate {
  constructor(private readonly reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    const roles = this.reflector.getAllAndOverride<string[]>(ROLES_KEY, [
      context.getHandler(),
      context.getClass(),
    ]);

    console.log('Required roles for this route:', roles);

    return true;
  }
}
```

## Cara Integrasi & Pengujian

Metadata bisa berupa string, number, boolean, atau object. Baca metadata di guard menggunakan `Reflector`.

**Test dengan curl:**
```bash
curl http://localhost:3000/users
# Console: Required roles for this route: undefined (karena @SetMetadata('isPublic'))
}
```
