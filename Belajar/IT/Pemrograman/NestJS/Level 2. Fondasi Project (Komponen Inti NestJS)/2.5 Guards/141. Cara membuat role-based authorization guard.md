# 141. Cara membuat role-based authorization guard

## Definisi & Target
Role-based guard membatasi akses berdasarkan role user (admin, user, moderator, dll). Guard membaca role dari `request.user` (yang sudah di-set oleh authentication guard sebelumnya) dan membandingkannya dengan role yang diizinkan di metadata route.

## Komponen & Nest CLI Command
```
nest g guard common/role --no-spec
```
File: `src/common/guards/role.guard.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/decorators/roles.decorator.ts
import { SetMetadata } from '@nestjs/common';

export const ROLES_KEY = 'roles';
export const Roles = (...roles: string[]) => SetMetadata(ROLES_KEY, roles);
```

```typescript
// src/common/guards/role.guard.ts
import { Injectable, CanActivate, ExecutionContext, ForbiddenException } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { ROLES_KEY } from '../decorators/roles.decorator';

@Injectable()
export class RoleGuard implements CanActivate {
  constructor(private readonly reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    const requiredRoles = this.reflector.getAllAndOverride<string[]>(ROLES_KEY, [
      context.getHandler(),
      context.getClass(),
    ]);

    if (!requiredRoles) {
      return true;
    }

    const request = context.switchToHttp().getRequest();
    const user = request.user;

    if (!user) {
      throw new ForbiddenException('Authentication required');
    }

    const hasRole = requiredRoles.includes(user.role);

    if (!hasRole) {
      throw new ForbiddenException(
        `Requires one of these roles: ${requiredRoles.join(', ')}. Your role: ${user.role}`,
      );
    }

    return true;
  }
}
```

```typescript
// src/users/users.controller.ts
import { Controller, Get, Delete, UseGuards } from '@nestjs/common';
import { Roles } from '../common/decorators/roles.decorator';
import { RoleGuard } from '../common/guards/role.guard';

@Controller('users')
export class UsersController {
  @Get()
  @Roles('admin', 'user', 'moderator')
  @UseGuards(RoleGuard)
  findAll() {
    return [{ id: 1, name: 'User' }];
  }

  @Delete(':id')
  @Roles('admin')
  @UseGuards(RoleGuard)
  remove() {
    return { message: 'Deleted' };
  }

  @Get('moderator')
  @Roles('moderator', 'admin')
  @UseGuards(RoleGuard)
  moderatorArea() {
    return { area: 'Moderator only' };
  }
}
```

## Cara Integrasi & Pengujian

Biasanya dipasang bersama authentication guard. Auth guard dulu yang menentukan siapa user, lalu role guard memeriksa otorisasi.

**Test dengan curl:**
```bash
curl -H "Authorization: Bearer token" http://localhost:3000/users/1 -X DELETE
# 403 jika user.role bukan 'admin'

curl -H "Authorization: Bearer token" http://localhost:3000/users
# 200 jika user.role adalah 'admin', 'user', atau 'moderator'
```
