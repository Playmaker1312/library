# 134. Cara mendaftarkan guard pada route menggunakan decorator UseGuards

## Definisi & Target
Decorator `@UseGuards()` digunakan untuk mendaftarkan guard di level controller atau method. Bisa menerima satu atau lebih guard (dalam array). Guard didaftarkan sebagai class reference (bukan instance) agar bisa memanfaatkan DI.

## Komponen & Nest CLI Command
```
nest g guard common/auth --no-spec
```
File: `src/users/users.controller.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/guards/auth.guard.ts
import { Injectable, CanActivate, ExecutionContext } from '@nestjs/common';

@Injectable()
export class AuthGuard implements CanActivate {
  canActivate(context: ExecutionContext): boolean {
    const request = context.switchToHttp().getRequest();
    return !!request.headers['authorization'];
  }
}
```

```typescript
// src/common/guards/admin.guard.ts
import { Injectable, CanActivate, ExecutionContext, ForbiddenException } from '@nestjs/common';

@Injectable()
export class AdminGuard implements CanActivate {
  canActivate(context: ExecutionContext): boolean {
    const request = context.switchToHttp().getRequest();
    const user = (request as any).user;

    if (!user || user.role !== 'admin') {
      throw new ForbiddenException('Admin access required');
    }

    return true;
  }
}
```

```typescript
// src/users/users.controller.ts
import { Controller, Get, Post, UseGuards } from '@nestjs/common';
import { AuthGuard } from '../common/guards/auth.guard';
import { AdminGuard } from '../common/guards/admin.guard';

@Controller('users')
@UseGuards(AuthGuard)
export class UsersController {
  @Get()
  findAll() {
    return [{ id: 1, name: 'User' }];
  }

  @Post()
  create() {
    return { message: 'Created' };
  }

  @Get('admin')
  @UseGuards(AdminGuard)
  getAdminData() {
    return { secret: 'admin-data' };
  }
}
```

## Cara Integrasi & Pengujian

Guard di level controller berlaku untuk semua method. Guard di level method hanya berlaku untuk method tersebut.

**Test dengan curl:**
```bash
curl http://localhost:3000/users
# 401 (AuthGuard di controller)

curl -H "Authorization: Bearer token" http://localhost:3000/users/admin
# 403 (AdminGuard di method)

curl -H "Authorization: Bearer token" http://localhost:3000/users
# 200 (lolos AuthGuard, tidak kena AdminGuard)
```
