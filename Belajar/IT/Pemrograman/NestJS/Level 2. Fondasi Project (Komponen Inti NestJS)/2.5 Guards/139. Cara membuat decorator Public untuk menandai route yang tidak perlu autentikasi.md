# 139. Cara membuat decorator Public untuk menandai route yang tidak perlu autentikasi

## Definisi & Target
Decorator `@Public()` menandai endpoint yang boleh diakses tanpa autentikasi. Ini berguna ketika ada guard global, tetapi beberapa route (seperti login, register, health check) harus tetap bisa diakses publik. Guard membaca metadata `isPublic` untuk melewati validasi.

## Komponen & Nest CLI Command
Tidak ada CLI command.
File: `src/common/decorators/public.decorator.ts`, `src/common/guards/jwt-auth.guard.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/decorators/public.decorator.ts
import { SetMetadata } from '@nestjs/common';

export const IS_PUBLIC_KEY = 'isPublic';
export const Public = () => SetMetadata(IS_PUBLIC_KEY, true);
```

```typescript
// src/common/guards/jwt-auth.guard.ts
import { Injectable, ExecutionContext } from '@nestjs/common';
import { AuthGuard } from '@nestjs/passport';
import { Reflector } from '@nestjs/core';
import { IS_PUBLIC_KEY } from '../decorators/public.decorator';

@Injectable()
export class JwtAuthGuard extends AuthGuard('jwt') {
  constructor(private readonly reflector: Reflector) {
    super();
  }

  canActivate(context: ExecutionContext) {
    const isPublic = this.reflector.getAllAndOverride<boolean>(IS_PUBLIC_KEY, [
      context.getHandler(),
      context.getClass(),
    ]);

    if (isPublic) {
      return true;
    }

    return super.canActivate(context);
  }
}
```

```typescript
// src/app.module.ts
import { Module } from '@nestjs/common';
import { APP_GUARD } from '@nestjs/core';
import { JwtAuthGuard } from './common/guards/jwt-auth.guard';

@Module({
  providers: [
    {
      provide: APP_GUARD,
      useClass: JwtAuthGuard,
    },
  ],
})
export class AppModule {}
```

```typescript
// src/auth/auth.controller.ts
import { Controller, Post, Body } from '@nestjs/common';
import { Public } from '../common/decorators/public.decorator';

@Controller('auth')
export class AuthController {
  @Public()
  @Post('login')
  login(@Body() body: any) {
    return { token: 'jwt-token-here' };
  }

  @Public()
  @Get('health')
  health() {
    return { status: 'ok' };
  }
}
```

## Cara Integrasi & Pengujian

Dengan `@Public()`, endpoint login dan health tetap bisa diakses meskipun ada JWT guard global.

**Test dengan curl:**
```bash
curl http://localhost:3000/auth/login -X POST \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"secret"}'
# {"token":"jwt-token-here"}

curl http://localhost:3000/users
# {"message":"Unauthorized","statusCode":401}
```
