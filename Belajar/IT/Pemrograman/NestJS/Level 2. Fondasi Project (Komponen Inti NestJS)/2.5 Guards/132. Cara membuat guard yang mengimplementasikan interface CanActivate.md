# 132. Cara membuat guard yang mengimplementasikan interface CanActivate

## Definisi & Target
Semua guard harus mengimplementasikan interface `CanActivate` yang mewajibkan method `canActivate(context: ExecutionContext): boolean | Promise<boolean>`. Return `true` melanjutkan request; return `false` atau throw exception menghentikan request dengan response 403 Forbidden.

## Komponen & Nest CLI Command
```
nest g guard common/role --no-spec
```
File: `src/common/guards/role.guard.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/guards/role.guard.ts
import { Injectable, CanActivate, ExecutionContext, ForbiddenException } from '@nestjs/common';
import { Observable } from 'rxjs';
import { Request } from 'express';

@Injectable()
export class RoleGuard implements CanActivate {
  constructor(private readonly allowedRoles: string[]) {}

  canActivate(context: ExecutionContext): boolean | Promise<boolean> | Observable<boolean> {
    const request = context.switchToHttp().getRequest<Request>();
    const user = (request as any).user;

    if (!user) {
      throw new ForbiddenException('User not authenticated');
    }

    const hasRole = this.allowedRoles.includes(user.role);
    if (!hasRole) {
      throw new ForbiddenException(`Requires one of roles: ${this.allowedRoles.join(', ')}`);
    }

    return true;
  }
}
```

```typescript
// src/common/guards/ip-whitelist.guard.ts
import { Injectable, CanActivate, ExecutionContext, ForbiddenException } from '@nestjs/common';
import { Request } from 'express';

@Injectable()
export class IpWhitelistGuard implements CanActivate {
  private readonly whitelist = ['127.0.0.1', '::1', '192.168.1.100'];

  canActivate(context: ExecutionContext): boolean {
    const request = context.switchToHttp().getRequest<Request>();
    const ip = request.ip;

    if (!this.whitelist.includes(ip)) {
      throw new ForbiddenException(`Access denied for IP: ${ip}`);
    }

    return true;
  }
}
```

```typescript
// src/users/users.controller.ts
import { Controller, Get, UseGuards } from '@nestjs/common';
import { RoleGuard } from '../common/guards/role.guard';
import { IpWhitelistGuard } from '../common/guards/ip-whitelist.guard';

@Controller('admin')
export class AdminController {
  @Get('dashboard')
  @UseGuards(new RoleGuard(['admin']))
  getDashboard() {
    return { data: 'Admin dashboard' };
  }

  @Get('internal')
  @UseGuards(IpWhitelistGuard)
  getInternal() {
    return { data: 'Internal only' };
  }
}
```

## Cara Integrasi & Pengujian

Guard bisa menerima parameter melalui constructor (misalnya `new RoleGuard(['admin'])`).

**Test dengan curl:**
```bash
curl -H "Authorization: Bearer token" http://localhost:3000/admin/dashboard
# {"message":"Requires one of roles: admin","statusCode":403}
```
