# 135. Cara mendaftarkan guard secara global menggunakan app.useGlobalGuards

## Definisi & Target
Guard global didaftarkan melalui `app.useGlobalGuards()` dan berlaku untuk seluruh endpoint aplikasi. Cocok untuk autentikasi dasar yang harus ada di semua route. Guard global tidak bisa menggunakan DI—jika perlu DI, gunakan `APP_GUARD` provider di AppModule.

## Komponen & Nest CLI Command
Tidak ada CLI command.
File: `src/main.ts`, `src/common/guards/api-key.guard.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/guards/api-key.guard.ts
import { Injectable, CanActivate, ExecutionContext, UnauthorizedException } from '@nestjs/common';
import { Request } from 'express';

@Injectable()
export class ApiKeyGuard implements CanActivate {
  canActivate(context: ExecutionContext): boolean {
    const request = context.switchToHttp().getRequest<Request>();
    const apiKey = request.headers['x-api-key'];

    if (!apiKey || apiKey !== 'my-secret-api-key') {
      throw new UnauthorizedException('Invalid or missing API key');
    }

    return true;
  }
}
```

```typescript
// Opsi 1: Global guard via main.ts (tanpa DI)
// src/main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { ApiKeyGuard } from './common/guards/api-key.guard';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.useGlobalGuards(new ApiKeyGuard());
  await app.listen(3000);
}
bootstrap();
```

```typescript
// Opsi 2: Global guard dengan DI via APP_GUARD provider
// src/app.module.ts
import { Module } from '@nestjs/common';
import { APP_GUARD } from '@nestjs/core';
import { ApiKeyGuard } from './common/guards/api-key.guard';

@Module({
  providers: [
    {
      provide: APP_GUARD,
      useClass: ApiKeyGuard,
    },
  ],
})
export class AppModule {}
```

## Cara Integrasi & Pengujian

Dengan guard global, semua route (termasuk yang tidak punya `@UseGuards`) akan dilindungi.

**Test dengan curl:**
```bash
curl http://localhost:3000/health
# {"message":"Invalid or missing API key","statusCode":401}

curl -H "x-api-key: my-secret-api-key" http://localhost:3000/health
# 200 OK
```
