# 112. Cara menggunakan ArgumentsHost untuk mendapatkan konteks request dan response

## Definisi & Target
`ArgumentsHost` menyediakan akses ke konteks eksekusi—termasuk request dan response object. Method `switchToHttp()` mengembalikan `HttpArgumentsHost` dengan `getRequest()` dan `getResponse()`. Ini memungkinkan exception filter membaca data request saat memformat error response.

## Komponen & Nest CLI Command
Tidak ada CLI command.
File: `src/common/filters/context-aware.filter.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/filters/context-aware.filter.ts
import { ExceptionFilter, Catch, ArgumentsHost, HttpException } from '@nestjs/common';
import { Request, Response } from 'express';

@Catch(HttpException)
export class ContextAwareFilter implements ExceptionFilter {
  catch(exception: HttpException, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const request = ctx.getRequest<Request>();
    const response = ctx.getResponse<Response>();
    const status = exception.getStatus();

    const errorBody = {
      statusCode: status,
      message: exception.message,
      timestamp: new Date().toISOString(),
      path: request.originalUrl,
      method: request.method,
      ip: request.ip,
      userAgent: request.headers['user-agent'] || 'unknown',
      requestId: (request as any).requestId || null,
    };

    response.status(status).json(errorBody);
  }
}
```

```typescript
// src/common/filters/arguments-host-demo.ts
import { ExceptionFilter, Catch, ArgumentsHost, HttpException } from '@nestjs/common';

@Catch(HttpException)
export class ArgumentsHostDemoFilter implements ExceptionFilter {
  catch(exception: HttpException, host: ArgumentsHost) {
    const type = host.getType();

    if (type === 'http') {
      const ctx = host.switchToHttp();
      const req = ctx.getRequest();
      const res = ctx.getResponse();
      const status = exception.getStatus();

      res.status(status).json({
        type: 'REST',
        statusCode: status,
        path: req.url,
      });
    } else if (type === 'graphql') {
      const gqlCtx = host.switchToRpc();
    }
  }
}
```

## Cara Integrasi & Pengujian

`ArgumentsHost` bisa membedakan context type (http, rpc, ws, graphql). Gunakan `getType()` untuk menentukan konteks eksekusi.

**Test dengan curl:**
```bash
curl http://localhost:3000/users/999

```
