# 108. Cara mendaftarkan exception filter secara global menggunakan app.useGlobalFilters

## Definisi & Target
Filter global didaftarkan menggunakan `app.useGlobalFilters()` di `main.ts`. Filter akan berlaku untuk seluruh aplikasi. Cocok untuk menerapkan format response error yang konsisten di semua endpoint.

## Komponen & Nest CLI Command
Tidak ada CLI command.
File: `src/main.ts`, `src/common/filters/global-exception.filter.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/filters/global-exception.filter.ts
import { ExceptionFilter, Catch, ArgumentsHost, HttpException, HttpStatus } from '@nestjs/common';
import { Request, Response } from 'express';

@Catch()
export class GlobalExceptionFilter implements ExceptionFilter {
  catch(exception: unknown, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();
    const request = ctx.getRequest<Request>();

    let status = HttpStatus.INTERNAL_SERVER_ERROR;
    let message = 'Internal server error';
    let stack: string | undefined;

    if (exception instanceof HttpException) {
      status = exception.getStatus();
      const res = exception.getResponse();
      message = typeof res === 'string' ? res : (res as any).message || exception.message;
    } else if (exception instanceof Error) {
      message = exception.message;
      stack = process.env.NODE_ENV === 'development' ? exception.stack : undefined;
    }

    response.status(status).json({
      statusCode: status,
      message,
      timestamp: new Date().toISOString(),
      path: request.url,
      ...(stack ? { stack } : {}),
    });
  }
}
```

```typescript
// src/main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { GlobalExceptionFilter } from './common/filters/global-exception.filter';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.useGlobalFilters(new GlobalExceptionFilter());

  await app.listen(3000);
}
bootstrap();
```

## Cara Integrasi & Pengujian

Filter global via `app.useGlobalFilters()` tidak bisa menggunakan DI. Jika perlu DI, gunakan pendekatan `APP_FILTER` provider.

**Test dengan curl:**
```bash
curl http://localhost:3000/nonexistent
# {"statusCode":404,"message":"Cannot GET /nonexistent","timestamp":"2026-06-01T09:00:00.000Z","path":"/nonexistent"}

curl http://localhost:3000/throw-error
# {"statusCode":500,"message":"Internal server error","timestamp":"...","path":"/throw-error"}
```
