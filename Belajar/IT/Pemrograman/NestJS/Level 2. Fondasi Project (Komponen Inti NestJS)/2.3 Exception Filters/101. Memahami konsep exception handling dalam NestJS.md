# 101. Memahami konsep exception handling dalam NestJS

## Definisi & Target
Exception handling di NestJS menggunakan layer khusus yang disebut Exception Filter. Ketika kode melempar exception (misalnya `NotFoundException`), filter akan menangkapnya dan mengubahnya menjadi response HTTP yang terstruktur. Ini memisahkan logika error dari business logic.

## Komponen & Nest CLI Command
```
nest g filter common/exception --no-spec
```
File: `src/common/filters/`, `src/common/exceptions/`

## Kode Implementasi (Per File)

```typescript
// src/common/exceptions/business.exception.ts
export class BusinessException extends Error {
  constructor(
    public readonly code: string,
    message: string,
    public readonly statusCode: number = 400,
  ) {
    super(message);
    this.name = 'BusinessException';
  }
}
```

```typescript
// src/common/filters/exception.filter.ts
import { ExceptionFilter, Catch, ArgumentsHost, HttpException } from '@nestjs/common';
import { Request, Response } from 'express';

@Catch()
export class AllExceptionsFilter implements ExceptionFilter {
  catch(exception: unknown, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();
    const request = ctx.getRequest<Request>();

    let status = 500;
    let message = 'Internal server error';

    if (exception instanceof HttpException) {
      status = exception.getStatus();
      message = exception.message;
    }

    response.status(status).json({
      statusCode: status,
      message,
      timestamp: new Date().toISOString(),
      path: request.url,
    });
  }
}
```

## Cara Integrasi & Pengujian

Exception filter bisa didaftarkan di level controller, method, atau global. NestJS memiliki lapisan exception handling otomatis—tanpa filter, tetap ada default response.

**Test dengan curl:**
```bash
curl http://localhost:3000/nonexistent
# {"statusCode":404,"message":"Cannot GET /nonexistent","timestamp":"2026-06-01T09:00:00.000Z","path":"/nonexistent"}
```
