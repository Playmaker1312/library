# 101. Memahami konsep exception handling dalam NestJS

## Definisi & Target
Exception handling adalah mekanisme untuk menangani error yang terjadi selama eksekusi aplikasi. Dalam NestJS, exception handling memungkinkan pengembang menangkap, memproses, dan merespons error secara terpusat dan konsisten. Target utamanya adalah menyediakan mekanisme error handling yang robust, maintainable, dan mengikuti standar HTTP status codes. NestJS menggunakan built-in exception layer yang memproses unhandled exceptions secara otomatis dan mengirimkan response error yang user-friendly ke client.

## Prasyarat
- Dasar TypeScript (class, interface, decorator)
- Pemahaman Controller dan Route Handler
- Kenali HTTP Status Codes (200, 400, 401, 404, 500)
- NestJS CLI terinstall (`npm i -g @nestjs/cli`)
- Project NestJS sudah dibuat (`nest new project-name`)

## Langkah-langkah Implementasi (Step-by-Step)

### 1. Memahami Flow Exception Handling
NestJS memiliki built-in exception layer yang menangkap semua unhandled exceptions. Ketika exception dilempar di controller/service, layer ini:
- Mencari exception filter yang cocok (berdasarkan tipe exception)
- Jika ditemukan filter custom, gunakan filter tersebut
- Jika tidak, gunakan built-in global exception filter
- Format response error secara standar

### 2. Jenis-jenis Exception di NestJS
- **HttpException**: Base class untuk HTTP exceptions
- **Built-in HTTP Exceptions**: `BadRequestException`, `UnauthorizedException`, `NotFoundException`, `ForbiddenException`, `InternalServerErrorException`, dll
- **Custom Exception**: Class yang extends `HttpException`
- **Unknown Exception**: Error biasa (Error, TypeError, dll) yang tidak extends HttpException

### 3. Default Behavior
Tanpa custom filter, NestJS mengembalikan response:
```json
{
  "statusCode": 500,
  "message": "Internal server error",
  "error": "Internal Server Error"
}
```

## Kode Implementasi (Per File)

### File: `src/main.ts` - Bootstrap dengan global filter
```typescript
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { HttpExceptionFilter } from './common/filters/http-exception.filter';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.useGlobalFilters(new HttpExceptionFilter());
  await app.listen(3000);
}
bootstrap();
```

### File: `src/common/filters/http-exception.filter.ts` - Basic Exception Filter
```typescript
import {
  ExceptionFilter,
  Catch,
  ArgumentsHost,
  HttpException,
  HttpStatus,
} from '@nestjs/common';
import { Request, Response } from 'express';

@Catch()
export class HttpExceptionFilter implements ExceptionFilter {
  catch(exception: unknown, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();
    const request = ctx.getRequest<Request>();

    let status = HttpStatus.INTERNAL_SERVER_ERROR;
    let message = 'Internal server error';
    let error = 'Internal Server Error';

    if (exception instanceof HttpException) {
      status = exception.getStatus();
      const exceptionResponse = exception.getResponse();
      
      if (typeof exceptionResponse === 'object' && exceptionResponse !== null) {
        message = (exceptionResponse as any).message || exception.message;
        error = (exceptionResponse as any).error || exception.name;
      } else {
        message = exceptionResponse as string;
        error = exception.name;
      }
    } else if (exception instanceof Error) {
      message = exception.message;
      error = exception.name;
    }

    response.status(status).json({
      statusCode: status,
      timestamp: new Date().toISOString(),
      path: request.url,
      method: request.method,
      error,
      message,
    });
  }
}
```

## Konfigurasi & Integrasi
- **Global Registration**: `app.useGlobalFilters(new HttpExceptionFilter())` di `main.ts`
- **Controller Level**: `@UseFilters(HttpExceptionFilter)` pada class controller
- **Method Level**: `@UseFilters(HttpExceptionFilter)` pada method handler
- **Module Level**: Daftarkan di `providers` array module dengan `APP_FILTER` token

### Unit Test dengan Jest
```typescript
// http-exception.filter.spec.ts
import { HttpExceptionFilter } from './http-exception.filter';
import { HttpException, HttpStatus, ArgumentsHost } from '@nestjs/common';
import { Request, Response } from 'express';

describe('HttpExceptionFilter', () => {
  let filter: HttpExceptionFilter;
  let mockResponse: Partial<Response>;
  let mockRequest: Partial<Request>;
  let mockHost: Partial<ArgumentsHost>;

  beforeEach(() => {
    filter = new HttpExceptionFilter();
    mockResponse = {
      status: jest.fn().mockReturnThis(),
      json: jest.fn().mockReturnThis(),
    };
    mockRequest = {
      url: '/test',
      method: 'GET',
    };
    mockHost = {
      switchToHttp: jest.fn().mockReturnValue({
        getResponse: () => mockResponse,
        getRequest: () => mockRequest,
      }),
    };
  });

  it('should handle HttpException', () => {
    const exception = new HttpException('Not Found', HttpStatus.NOT_FOUND);
    filter.catch(exception, mockHost as ArgumentsHost);
    
    expect(mockResponse.status).toHaveBeenCalledWith(404);
    expect(mockResponse.json).toHaveBeenCalledWith(
      expect.objectContaining({
        statusCode: 404,
        message: 'Not Found',
      })
    );
  });

  it('should handle unknown error', () => {
    const exception = new Error('Database connection failed');
    filter.catch(exception, mockHost as ArgumentsHost);
    
    expect(mockResponse.status).toHaveBeenCalledWith(500);
    expect(mockResponse.json).toHaveBeenCalledWith(
      expect.objectContaining({
        statusCode: 500,
        message: 'Database connection failed',
      })
    );
  });
});
```

## Troubleshooting & Common Issues

### 1. Filter tidak menangkap exception
**Penyebab**: Filter tidak terdaftar dengan benar atau decorator `@Catch()` tidak sesuai
**Solusi**: 
- Pastikan filter terdaftar di `main.ts` via `app.useGlobalFilters()`
- Periksa `@Catch(HttpException)` atau `@Catch()` untuk semua exception
- Pastikan import `ExceptionFilter` dari `@nestjs/common`

### 2. Status code selalu 500
**Penyebab**: Exception bukan instance of `HttpException` atau `getStatus()` tidak dipanggil
**Solusi**:
- Gunakan built-in exceptions (`NotFoundException`, `BadRequestException`)
- Custom exception harus extends `HttpException`
- Periksa logic `instanceof HttpException` di filter

### 3. Logging tidak muncul
**Penyebab**: Logger tidak di-inject atau tidak dikonfigurasi
**Solusi**:
- Inject `Logger` dari `@nestjs/common`
- Gunakan `console.log` untuk debug sementara
- Konfigurasi logger di `main.ts` dengan `app.useLogger()`

## Best Practices
1. **Gunakan built-in exceptions** untuk kasus standar (400, 401, 404, 409)
2. **Buat custom exception** untuk business logic errors spesifik
3. **Global filter** untuk format response konsisten di seluruh aplikasi
4. **Specific filter** per controller/method untuk handling khusus
5. **Log error** dengan context yang cukup (request ID, user ID, timestamp)
6. **Jangan expose sensitive info** di production error response
7. **Gunakan HttpStatus enum** bukan magic numbers
