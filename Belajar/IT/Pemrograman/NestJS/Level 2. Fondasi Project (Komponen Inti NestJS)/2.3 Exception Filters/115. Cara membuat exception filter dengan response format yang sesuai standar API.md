# 115. Cara membuat exception filter dengan response format yang sesuai standar API

## Definisi & Target
Standar API (seperti JSON:API atau RFC 7807 Problem Details) mendefinisikan format error response yang konsisten. Exception filter NestJS bisa dikustomisasi untuk menghasilkan format yang sesuai standar, memudahkan konsumen API dari berbagai platform.

## Komponen & Nest CLI Command
```
nest g filter common/api-standard --no-spec
```
File: `src/common/filters/api-standard.filter.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/interfaces/api-response.ts
export interface ApiSuccessResponse<T> {
  success: true;
  data: T;
  timestamp: string;
}

export interface ApiErrorResponse {
  success: false;
  error: {
    code: string;
    message: string;
    details?: any;
  };
  timestamp: string;
  traceId?: string;
}
```

```typescript
// src/common/filters/api-standard.filter.ts
import { ExceptionFilter, Catch, ArgumentsHost, HttpException, HttpStatus } from '@nestjs/common';
import { Request, Response } from 'express';
import { v4 as uuidv4 } from 'uuid';

@Catch()
export class ApiStandardFilter implements ExceptionFilter {
  catch(exception: unknown, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();
    const request = ctx.getRequest<Request>();

    let status = HttpStatus.INTERNAL_SERVER_ERROR;
    let code = 'INTERNAL_ERROR';
    let message = 'An unexpected error occurred';
    let details: any = undefined;

    if (exception instanceof HttpException) {
      status = exception.getStatus();
      const res = exception.getResponse();

      code = this.mapStatusToCode(status);
      message = typeof res === 'string' ? res : (res as any).message || exception.message;
      details = (res as any).errors || undefined;

      if (Array.isArray(message)) {
        details = message;
        message = 'Validation failed';
      }
    }

    response.status(status).json({
      success: false,
      error: {
        code,
        message,
        ...(details ? { details } : {}),
      },
      timestamp: new Date().toISOString(),
      traceId: uuidv4(),
      path: request.originalUrl,
    });
  }

  private mapStatusToCode(status: number): string {
    const map: Record<number, string> = {
      400: 'BAD_REQUEST',
      401: 'UNAUTHORIZED',
      403: 'FORBIDDEN',
      404: 'NOT_FOUND',
      409: 'CONFLICT',
      422: 'UNPROCESSABLE_ENTITY',
      429: 'TOO_MANY_REQUESTS',
      500: 'INTERNAL_ERROR',
      503: 'SERVICE_UNAVAILABLE',
    };
    return map[status] || 'UNKNOWN_ERROR';
  }
}
```

```typescript
// src/main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { ApiStandardFilter } from './common/filters/api-standard.filter';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.useGlobalFilters(new ApiStandardFilter());
  await app.listen(3000);
}
bootstrap();
```

## Cara Integrasi & Pengujian

Format mengikuti standar error API dengan `success: false`, kode error yang jelas, dan trace ID untuk debugging.

**Test dengan curl:**
```bash
curl http://localhost:3000/users/999
# {"success":false,"error":{"code":"NOT_FOUND","message":"User #999 not found"},"timestamp":"2026-06-01T09:00:00.000Z","traceId":"abc-123-def","path":"/users/999"}
```
