# 111. Cara menangkap exception Prisma atau TypeORM dalam exception filter

## Definisi & Target
Database ORM seperti Prisma atau TypeORM memiliki exception sendiri. Exception filter khusus diperlukan untuk menangkap error database dan menerjemahkannya ke HTTP response yang sesuai. Misalnya, `Prisma.PrismaClientKnownRequestError` untuk duplicate key atau record not found.

## Komponen & Nest CLI Command
```
npm install @prisma/client
nest g filter common/prisma-exception --no-spec
```
File: `src/common/filters/prisma-exception.filter.ts`

## Kode Implementasi (Per File)

```typescript
// Dengan Prisma:
import { Prisma } from '@prisma/client';

// src/common/filters/prisma-exception.filter.ts
import { ExceptionFilter, Catch, ArgumentsHost, HttpStatus } from '@nestjs/common';
import { Response } from 'express';

@Catch(Prisma.PrismaClientKnownRequestError)
export class PrismaExceptionFilter implements ExceptionFilter {
  catch(exception: Prisma.PrismaClientKnownRequestError, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();

    let status = HttpStatus.INTERNAL_SERVER_ERROR;
    let message = 'Database error';

    switch (exception.code) {
      case 'P2002':
        status = HttpStatus.CONFLICT;
        message = `Unique constraint violation on ${exception.meta?.target}`;
        break;
      case 'P2025':
        status = HttpStatus.NOT_FOUND;
        message = 'Record not found';
        break;
      case 'P2003':
        status = HttpStatus.BAD_REQUEST;
        message = 'Foreign key constraint failed';
        break;
      case 'P2014':
        status = HttpStatus.BAD_REQUEST;
        message = 'Required relation violation';
        break;
    }

    response.status(status).json({
      statusCode: status,
      message,
      code: exception.code,
      timestamp: new Date().toISOString(),
    });
  }
}
```

```typescript
// Dengan TypeORM:
import { TypeORMError, QueryFailedError, EntityNotFoundError } from 'typeorm';

// src/common/filters/typeorm-exception.filter.ts
import { ExceptionFilter, Catch, ArgumentsHost, HttpStatus } from '@nestjs/common';
import { Response } from 'express';
import { QueryFailedError, EntityNotFoundError } from 'typeorm';

@Catch(QueryFailedError, EntityNotFoundError)
export class TypeOrmExceptionFilter implements ExceptionFilter {
  catch(exception: QueryFailedError | EntityNotFoundError, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();

    let status = HttpStatus.INTERNAL_SERVER_ERROR;
    let message = 'Database error';

    if (exception instanceof EntityNotFoundError) {
      status = HttpStatus.NOT_FOUND;
      message = 'Resource not found';
    } else if (exception instanceof QueryFailedError) {
      const driverError = exception.driverError;
      if (driverError?.code === '23505') {
        status = HttpStatus.CONFLICT;
        message = 'Duplicate entry - resource already exists';
      }
    }

    response.status(status).json({ statusCode: status, message });
  }
}
```

## Cara Integrasi & Pengujian

Daftarkan filter secara global atau per controller. Exception ORM akan diterjemahkan ke HTTP response yang bersih.

**Test dengan curl (Prisma duplicate):**
```bash
curl -X POST http://localhost:3000/users \
  -H "Content-Type: application/json" \
  -d '{"email":"duplicate@test.com"}'
# {"statusCode":409,"message":"Unique constraint violation on email","code":"P2002","timestamp":"..."}
```
