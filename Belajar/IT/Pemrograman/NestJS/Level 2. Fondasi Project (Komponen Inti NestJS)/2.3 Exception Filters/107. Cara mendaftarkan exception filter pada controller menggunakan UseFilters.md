# 107. Cara mendaftarkan exception filter pada controller menggunakan UseFilters

## Definisi & Target
Decorator `@UseFilters()` mendaftarkan exception filter di level controller atau method tertentu. Filter hanya akan aktif untuk route dalam controller tersebut. Cocok ketika ingin menerapkan format error berbeda per modul.

## Komponen & Nest CLI Command
```
nest g filter common/exception --no-spec
```
File: `src/users/users.controller.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/filters/custom-http.filter.ts
import { ExceptionFilter, Catch, ArgumentsHost, HttpException } from '@nestjs/common';
import { Response } from 'express';

@Catch(HttpException)
export class CustomHttpFilter implements ExceptionFilter {
  catch(exception: HttpException, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const res = ctx.getResponse<Response>();
    const status = exception.getStatus();
    const msg = exception.getResponse();

    res.status(status).json({
      success: false,
      code: `ERR_${status}`,
      data: null,
      error: typeof msg === 'string' ? msg : (msg as any).message,
    });
  }
}
```

```typescript
// src/users/users.controller.ts
import { Controller, Get, Param, UseFilters } from '@nestjs/common';
import { UsersService } from './users.service';
import { CustomHttpFilter } from '../common/filters/custom-http.filter';

@Controller('users')
@UseFilters(CustomHttpFilter)
export class UsersController {
  constructor(private readonly usersService: UsersService) {}

  @Get()
  findAll() {
    return this.usersService.findAll();
  }

  @Get(':id')
  @UseFilters(CustomHttpFilter)
  findOne(@Param('id') id: number) {
    return this.usersService.findOne(id);
  }
}
```

## Cara Integrasi & Pengujian

`@UseFilters()` bisa di level class (semua method) atau method spesifik. Filter akan diterapkan untuk exception yang terjadi di dalam scope tersebut.

**Test dengan curl:**
```bash
curl http://localhost:3000/users/999
# {"success":false,"code":"ERR_404","data":null,"error":"User #999 not found"}
```
