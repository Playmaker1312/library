# 103. Cara melempar HTTP exception menggunakan throw new NotFoundException

## Definisi & Target
Cara paling sederhana untuk menghasilkan error response adalah dengan `throw new NamaException()`. NestJS akan menangkap exception dan mengirimkan response JSON dengan status code yang sesuai. Exception bisa dikustomisasi dengan pesan dan opsi tambahan.

## Komponen & Nest CLI Command
Tidak ada CLI command.
File: `src/articles/articles.service.ts`

## Kode Implementasi (Per File)

```typescript
// src/articles/articles.service.ts
import { Injectable, NotFoundException, BadRequestException } from '@nestjs/common';

@Injectable()
export class ArticlesService {
  private articles = [
    { id: 1, title: 'NestJS Basics', published: true },
    { id: 2, title: 'Advanced DI', published: false },
  ];

  findOne(id: number) {
    const article = this.articles.find(a => a.id === id);

    if (!article) {
      throw new NotFoundException({
        statusCode: 404,
        message: `Article #${id} not found`,
        error: 'Not Found',
      });
    }

    return article;
  }

  publish(id: number) {
    const article = this.articles.find(a => a.id === id);

    if (!article) {
      throw new NotFoundException(`Article with ID ${id} does not exist`);
    }

    if (article.published) {
      throw new BadRequestException('Article is already published');
    }

    article.published = true;
    return article;
  }
}
```

```typescript
// src/articles/articles.controller.ts
import { Controller, Get, Param, Post } from '@nestjs/common';
import { ArticlesService } from './articles.service';

@Controller('articles')
export class ArticlesController {
  constructor(private readonly articlesService: ArticlesService) {}

  @Get(':id')
  findOne(@Param('id') id: number) {
    return this.articlesService.findOne(id);
  }

  @Post(':id/publish')
  publish(@Param('id') id: number) {
    return this.articlesService.publish(id);
  }
}
```

## Cara Integrasi & Pengujian

Exception akan melewati exception filter (bawaan atau kustom). Format response default adalah `{ message, statusCode, error }`.

**Test dengan curl:**
```bash
curl http://localhost:3000/articles/999
# {"message":"Article #999 not found","error":"Not Found","statusCode":404}

curl -X POST http://localhost:3000/articles/2/publish
# {"id":2,"title":"Advanced DI","published":true}

curl -X POST http://localhost:3000/articles/1/publish
# {"message":"Article is already published","statusCode":400}
```
