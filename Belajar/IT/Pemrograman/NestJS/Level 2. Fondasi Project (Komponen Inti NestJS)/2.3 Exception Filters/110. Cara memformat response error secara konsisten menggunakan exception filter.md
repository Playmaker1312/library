# 110. Cara memformat response error secara konsisten menggunakan exception filter

## Definisi & Target
Response error yang konsisten memudahkan client (frontend/mobile) dalam menangani error. Format standar biasanya mencakup `statusCode`, `message`, `timestamp`, dan `path`. Exception filter adalah tempat ideal untuk menerapkan format ini di seluruh aplikasi.

## Komponen & Nest CLI Command
```
nest g filter common/exception --no-spec
```
File: `src/common/filters/standard-error.filter.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/interfaces/api-response.interface.ts
export interface ApiErrorResponse {
  success: false;
  statusCode: number;
  message: string;
  error: string;
  timestamp: string;
  path: string;
  stack?: string;
}
```

```typescript
// src/common/filters/standard-error.filter.ts
import { ExceptionFilter, Catch, ArgumentsHost, HttpException } from '@nestjs/common';
import { Request, Response } from 'express';

@Catch(HttpException)
export class StandardErrorFilter implements ExceptionFilter {
  catch(exception: HttpException, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();
    const request = ctx.getRequest<Request>();

    const status = exception.getStatus();
    const exceptionRes = exception.getResponse();

    const errorResponse = {
      success: false,
      statusCode: status,
      message: typeof exceptionRes === 'string' ? exceptionRes : (exceptionRes as any).message || exception.message,
      error: typeof exceptionRes === 'string' ? exceptionRes : (exceptionRes as any).error || 'Error',
      timestamp: new Date().toISOString(),
      path: request.originalUrl,
    };

    response.status(status).json(errorResponse);
  }
}
```

```typescript
// src/main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { StandardErrorFilter } from './common/filters/standard-error.filter';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.useGlobalFilters(new StandardErrorFilter());
  await app.listen(3000);
}
bootstrap();
```

## Cara Integrasi & Pengujian

Semua error response akan memiliki format yang sama, memudahkan client membuat error handler generik.

**Test dengan curl:**
```bash
curl http://localhost:3000/users/999
# {"success":false,"statusCode":404,"message":"User #999 not found","error":"Not Found","timestamp":"2026-06-01T09:00:00.000Z","path":"/users/999"}

curl -X POST http://localhost:3000/users -H "Content-Type: application/json" -d '{}'
# {"success":false,"statusCode":400,"message":"Validation failed","error":"Bad Request","timestamp":"...","path":"/users"}
```
