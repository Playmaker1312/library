# 102. Memahami built-in HTTP exceptions yaitu NotFoundException, BadRequestException, UnauthorizedException, dll

## Definisi & Target
NestJS menyediakan class exception built-in yang mewarisi `HttpException`. Masing-masing memiliki HTTP status code tetap. Gunakan exception yang sesuai dengan semantic error untuk menghasilkan response yang konsisten dan mudah dipahami client.

## Komponen & Nest CLI Command
Tidak ada CLI command—import langsung dari `@nestjs/common`.
File: `src/users/users.service.ts`

## Kode Implementasi (Per File)

```typescript
// src/users/users.service.ts
import {
  Injectable,
  NotFoundException,
  BadRequestException,
  UnauthorizedException,
  ForbiddenException,
  ConflictException,
  InternalServerErrorException,
  GatewayTimeoutException,
  RequestTimeoutException,
} from '@nestjs/common';

@Injectable()
export class UsersService {
  private users = [{ id: 1, name: 'Alice', email: 'alice@test.com' }];

  findOne(id: number) {
    const user = this.users.find(u => u.id === id);
    if (!user) {
      throw new NotFoundException(`User with id ${id} not found`);
    }
    return user;
  }

  create(userData: { name: string; email: string }) {
    if (!userData.name || !userData.email) {
      throw new BadRequestException('Name and email are required');
    }

    const exists = this.users.find(u => u.email === userData.email);
    if (exists) {
      throw new ConflictException('Email already registered');
    }

    const newUser = { id: this.users.length + 1, ...userData };
    this.users.push(newUser);
    return newUser;
  }

  login(email: string, password: string) {
    if (!password) {
      throw new UnauthorizedException('Password required');
    }
    return { token: 'mock-jwt-token' };
  }
}
```

```typescript
// Built-in HTTP Exceptions reference:
// BadRequestException       -> 400

// ForbiddenException         -> 403
// ConflictException          -> 409
// RequestTimeoutException    -> 408
// GatewayTimeoutException    -> 504
// InternalServerErrorException -> 500
// NotImplementedException    -> 501
// ServiceUnavailableException -> 503
```

## Cara Integrasi & Pengujian

Lempar exception langsung di service atau controller. NestJS akan menangkapnya dan mengembalikan response JSON dengan status code yang sesuai.

**Test dengan curl:**
```bash
curl http://localhost:3000/users/999
# {"message":"User with id 999 not found","statusCode":404}

curl -X POST http://localhost:3000/users -H "Content-Type: application/json" -d '{}'
# {"message":"Name and email are required","statusCode":400}
```
