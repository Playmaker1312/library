# 102. Memahami built-in HTTP exceptions yaitu NotFoundException, BadRequestException, UnauthorizedException, dll

## Definisi & Target
NestJS menyediakan sekumpulan built-in HTTP exceptions yang mewakili standar HTTP status codes. Setiap exception class extends `HttpException` dan secara otomatis mengatur status code yang sesuai. Target adalah memahami kapan dan bagaimana menggunakan setiap built-in exception untuk error handling yang semantik dan standar.

## Langkah-langkah Implementasi (Step-by-Step)

### 1. Daftar Lengkap Built-in HTTP Exceptions

| Exception Class | Status Code | HTTP Status | Use Case |
|----------------|-------------|-------------|----------|
| `BadRequestException` | 400 | Bad Request | Validasi gagal, malformed request |
| `UnauthorizedException` | 401 | Unauthorized | Token invalid/expired, credential salah |
| `ForbiddenException` | 403 | Forbidden | Akses ditolak, role tidak cukup |
| `NotFoundException` | 404 | Not Found | Resource tidak ditemukan |
| `ConflictException` | 409 | Conflict | Duplicate resource, version conflict |
| `GoneException` | 410 | Gone | Resource sudah dihapus permanen |
| `PayloadTooLargeException` | 413 | Payload Too Large | Upload file terlalu besar |
| `UnsupportedMediaTypeException` | 415 | Unsupported Media Type | Content-Type tidak didukung |
| `UnprocessableEntityException` | 422 | Unprocessable Entity | Validasi semantic gagal |
| `TooManyRequestsException` | 429 | Too Many Requests | Rate limiting |
| `InternalServerErrorException` | 500 | Internal Server Error | Error server tidak terduga |
| `ServiceUnavailableException` | 503 | Service Unavailable | Service down, maintenance |

### 2. Constructor Parameters
Semua built-in exceptions menerima parameter yang sama:
```typescript
// Constructor signature
constructor(message?: string | object, options?: ErrorOptions)

// message: string atau object untuk response body
// options: { cause?: Error, description?: string }
```

### 3. Penggunaan Dasar
```typescript
// Melempar exception dengan message default
throw new NotFoundException();

// Melempar exception dengan custom message
throw new NotFoundException('User dengan ID 123 tidak ditemukan');

// Melempar exception dengan response object
throw new BadRequestException({
  message: 'Validasi gagal',
  errors: ['email wajib diisi', 'password minimal 8 karakter'],
  error: 'Bad Request',
});
```

## Kode Implementasi (Per File)

### File: `src/users/users.controller.ts` - Contoh penggunaan berbagai exceptions
```typescript
import {
  Controller,
  Get,
  Post,
  Put,
  Delete,
  Body,
  Param,
  Query,
  HttpCode,
  HttpStatus,
  NotFoundException,
  BadRequestException,
  UnauthorizedException,
  ForbiddenException,
  ConflictException,
  InternalServerErrorException,
} from '@nestjs/common';
import { UsersService } from './users.service';
import { CreateUserDto, UpdateUserDto } from './dto/user.dto';

@Controller('users')
export class UsersController {
  constructor(private readonly usersService: UsersService) {}

  @Get(':id')
  async findOne(@Param('id') id: string) {
    const user = await this.usersService.findById(id);
    if (!user) {
      throw new NotFoundException(`User dengan ID ${id} tidak ditemukan`);
    }
    return user;
  }

  @Post()
  @HttpCode(HttpStatus.CREATED)
  async create(@Body() createUserDto: CreateUserDto) {
    // Validasi manual
    if (!createUserDto.email || !createUserDto.password) {
      throw new BadRequestException({
        message: 'Email dan password wajib diisi',
        errors: ['email is required', 'password is required'],
        error: 'Bad Request',
      });
    }

    // Cek duplicate email
    const existingUser = await this.usersService.findByEmail(createUserDto.email);
    if (existingUser) {
      throw new ConflictException('Email sudah terdaftar');
    }

    return this.usersService.create(createUserDto);
  }

  @Put(':id')
  async update(@Param('id') id: string, @Body() updateUserDto: UpdateUserDto) {
    const user = await this.usersService.findById(id);
    if (!user) {
      throw new NotFoundException(`User dengan ID ${id} tidak ditemukan`);
    }

    // Cek authorization (simulasi)
    const currentUserId = 'current-user-id'; // dari JWT guard
    if (user.id !== currentUserId) {
      throw new ForbiddenException('Anda tidak memiliki akses untuk mengupdate user ini');
    }

    return this.usersService.update(id, updateUserDto);
  }

  @Delete(':id')
  @HttpCode(HttpStatus.NO_CONTENT)
  async delete(@Param('id') id: string) {
    const user = await this.usersService.findById(id);
    if (!user) {
      throw new NotFoundException(`User dengan ID ${id} tidak ditemukan`);
    }

    // Simulasi cek role admin
    const isAdmin = false; // dari JWT guard
    if (!isAdmin) {
      throw new ForbiddenException('Hanya admin yang dapat menghapus user');
    }

    await this.usersService.delete(id);
  }

  @Get()
  async findAll(@Query('page') page = 1, @Query('limit') limit = 10) {
    try {
      return await this.usersService.findAll(page, limit);
    } catch (error) {
      throw new InternalServerErrorException('Gagal mengambil daftar user');
    }
  }
}
```

### File: `src/auth/auth.controller.ts` - Auth exceptions
```typescript
import {
  Controller,
  Post,
  Body,
  HttpCode,
  HttpStatus,
  UnauthorizedException,
  BadRequestException,
  TooManyRequestsException,
} from '@nestjs/common';
import { AuthService } from './auth.service';
import { LoginDto, RegisterDto } from './dto/auth.dto';

@Controller('auth')
export class AuthController {
  constructor(private readonly authService: AuthService) {}

  @Post('login')
  @HttpCode(HttpStatus.OK)
  async login(@Body() loginDto: LoginDto) {
    // Rate limiting check (simulasi)
    const attemptCount = await this.authService.getLoginAttempts(loginDto.email);
    if (attemptCount >= 5) {
      throw new TooManyRequestsException('Terlalu banyak percobaan login, coba lagi nanti');
    }

    const user = await this.authService.validateUser(loginDto.email, loginDto.password);
    if (!user) {
      throw new UnauthorizedException('Email atau password salah');
    }

    return this.authService.login(user);
  }

  @Post('register')
  @HttpCode(HttpStatus.CREATED)
  async register(@Body() registerDto: RegisterDto) {
    if (registerDto.password !== registerDto.confirmPassword) {
      throw new BadRequestException('Password dan konfirmasi password tidak cocok');
    }

    if (registerDto.password.length < 8) {
      throw new BadRequestException('Password minimal 8 karakter');
    }

    return this.authService.register(registerDto);
  }

  @Post('refresh')
  @HttpCode(HttpStatus.OK)
  async refresh(@Body('refreshToken') refreshToken: string) {
    if (!refreshToken) {
      throw new BadRequestException('Refresh token wajib diisi');
    }

    const tokens = await this.authService.refreshToken(refreshToken);
    if (!tokens) {
      throw new UnauthorizedException('Refresh token invalid atau expired');
    }

    return tokens;
  }
}
```

## Cara Pengujian & Verifikasi

### Unit Test
```typescript
// users.controller.spec.ts
import { UsersController } from './users.controller';
import { NotFoundException, BadRequestException, ConflictException } from '@nestjs/common';

describe('UsersController Exceptions', () => {
  let controller: UsersController;
  let mockService: any;

  beforeEach(() => {
    mockService = {
      findById: jest.fn(),
      findByEmail: jest.fn(),
      create: jest.fn(),
      update: jest.fn(),
      delete: jest.fn(),
    };
    controller = new UsersController(mockService);
  });

  it('should throw NotFoundException when user not found', async () => {
    mockService.findById.mockResolvedValue(null);
    
    await expect(controller.findOne('999')).rejects.toThrow(NotFoundException);
    await expect(controller.findOne('999')).rejects.toThrow('User dengan ID 999 tidak ditemukan');
  });

  it('should throw BadRequestException when email/password missing', async () => {
    await expect(controller.create({})).rejects.toThrow(BadRequestException);
  });

  it('should throw ConflictException when email exists', async () => {
    mockService.findByEmail.mockResolvedValue({ id: '1', email: 'test@test.com' });
    
    await expect(controller.create({ email: 'test@test.com', password: '12345678' }))
      .rejects.toThrow(ConflictException);
  });
});
```

## Troubleshooting & Common Issues

### 1. Exception tidak dilempar dengan benar
**Penyebab**: Lupa `throw` keyword atau salah import
**Solusi**: Pastikan `throw new NotFoundException()` bukan `new NotFoundException()`

### 2. Status code tidak sesuai ekspektasi
**Penyebab**: Menggunakan exception class yang salah
**Solusi**: Periksa mapping tabel status code di atas, gunakan class yang tepat

### 3. Response body tidak terformat dengan baik
**Penyebab**: Melempar string langsung bukan exception
**Solusi**: Selalu gunakan `throw new HttpException(...)` atau built-in exceptions

### 4. Custom message tidak muncul
**Penyebab**: Global exception filter mengoverride message
**Solusi**: Periksa filter implementation, pastikan `exception.getResponse()` dibaca dengan benar

## Best Practices
1. **Gunakan exception yang paling spesifik** - jangan gunakan `HttpException` generic jika ada built-in yang cocok
2. **400 untuk validasi input**, 422 untuk validasi bisnis yang kompleks
3. **401 untuk authentication**, 403 untuk authorization
4. **404 untuk resource tidak ditemukan**, 410 untuk resource yang memang sudah dihapus permanen
5. **409 untuk conflict** (duplicate, version mismatch)
6. **500 hanya untuk error server yang tidak terduga**, bukan business logic error
7. **Berikan message yang informatif** tapi jangan expose sensitive data
