# 105. Cara membuat custom exception filter menggunakan decorator Catch

## Definisi & Target
Decorator `@Catch()` menentukan tipe exception yang akan ditangani oleh filter. Bisa satu atau beberapa tipe exception sekaligus. Filter akan aktif hanya untuk exception yang disebutkan di `@Catch()`.

## Komponen & Nest CLI Command
```
nest g filter common/exception --no-spec
```
File: `src/common/filters/http-exception.filter.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/filters/http-exception.filter.ts
import { ExceptionFilter, Catch, ArgumentsHost, HttpException } from '@nestjs/common';
import { Request, Response } from 'express';

@Catch(HttpException)
export class HttpExceptionFilter implements ExceptionFilter {
  catch(exception: HttpException, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();
    const request = ctx.getRequest<Request>();

    const status = exception.getStatus();
    const exceptionResponse = exception.getResponse();

    const errorBody = {
      statusCode: status,
      timestamp: new Date().toISOString(),
      path: request.url,
      method: request.method,
      ...(typeof exceptionResponse === 'string'
        ? { message: exceptionResponse }
        : exceptionResponse),
    };

    response.status(status).json(errorBody);
  }
}
```

## Cara Integrasi & Pengujian

`@Catch(HttpException)` berarti filter ini hanya menangkap exception yang mewarisi `HttpException`. Exception lain akan diteruskan ke filter berikutnya atau default NestJS.

**Test dengan curl:**
```bash
curl http://localhost:3000/nonexistent
# {"statusCode":404,"timestamp":"2026-06-01T09:00:00.000Z","path":"/nonexistent","method":"GET","message":"Cannot GET /nonexistent"}
```
