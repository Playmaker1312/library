# 158. Cara menggunakan ExecutionContext dalam interceptor untuk konteks request

## Definisi & Target
`ExecutionContext` memberi akses ke informasi konteks eksekusi: request/response object, class handler, method handler, dan argumen. Interceptor bisa membaca data ini untuk mengambil keputusan, seperti melewati transformasi untuk route tertentu atau membaca header.

## Komponen & Nest CLI Command
Tidak ada CLI command.
File: `src/common/interceptors/context.interceptor.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/interceptors/context.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable, map } from 'rxjs';

@Injectable()
export class ContextInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const request = context.switchToHttp().getRequest();
    const response = context.switchToHttp().getResponse();

    const handlerName = context.getHandler().name;
    const className = context.getClass().name;
    const isAdminRoute = request.url.startsWith('/admin');

    return next.handle().pipe(
      map(data => {
        const meta = {
          handler: `${className}.${handlerName}`,
          timestamp: new Date().toISOString(),
          version: '1.0',
        };

        if (isAdminRoute) {
          response.setHeader('X-Admin-Access', 'true');
        }

        if (data?.__raw) {
          return data;
        }

        return { ...meta, data };
      }),
    );
  }
}
```

```typescript
// src/common/interceptors/handler-info.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler, Logger } from '@nestjs/common';
import { Observable, tap } from 'rxjs';

@Injectable()
export class HandlerInfoInterceptor implements NestInterceptor {
  private readonly logger = new Logger('Handler');

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const handler = context.getHandler();
    const controller = context.getClass();
    const methodName = handler.name;
    const controllerName = controller.name;

    const args = context.getArgByIndex(0);

    this.logger.log(`Executing ${controllerName}.${methodName}()`);

    return next.handle().pipe(
      tap(data => {
        this.logger.log(`${controllerName}.${methodName}() completed`);
      }),
    );
  }
}
```

## Cara Integrasi & Pengujian

Interceptor bisa mengakses nama handler/controller untuk logging, conditional logic, atau metadata.
