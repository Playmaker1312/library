# 148. Cara menggunakan Observable dan rxjs dalam interceptor

## Definisi & Target
Interceptor menggunakan `Observable` dari RxJS untuk memanipulasi response stream. Operator seperti `map`, `tap`, `catchError`, `timeout`, dan `retry` bisa digunakan untuk transformasi, logging, error handling, atau mengubah flow eksekusi.

## Komponen & Nest CLI Command
Tidak perlu instalasi—RxJS sudah include di NestJS.
File: `src/common/interceptors/rxjs-demo.interceptor.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/interceptors/rxjs-demo.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable, map, tap, catchError, throwError, timeout, TimeoutError } from 'rxjs';

@Injectable()
export class RxjsDemoInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    return next.handle().pipe(
      tap({
        next: (value) => console.log('Handler executed successfully:', typeof value),
        error: (err) => console.error('Handler threw error:', err.message),
      }),

      map(data => ({
        original: data,
        wrapped: true,
        timestamp: new Date().toISOString(),
      })),

      timeout(5000),

      catchError(err => {
        if (err instanceof TimeoutError) {
          return throwError(() => new Error('Request timed out'));
        }
        return throwError(() => err);
      }),
    );
  }
}
```

```typescript
// src/common/interceptors/cache.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable, of, tap } from 'rxjs';

@Injectable()
export class CacheInterceptor implements NestInterceptor {
  private cache = new Map<string, any>();

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const request = context.switchToHttp().getRequest();
    const key = `${request.method}-${request.url}`;

    const cached = this.cache.get(key);
    if (cached) {
      return of(cached);
    }

    return next.handle().pipe(
      tap(data => {
        this.cache.set(key, data);
        setTimeout(() => this.cache.delete(key), 60000);
      }),
    );
  }
}
```

## Cara Integrasi & Pengujian

RxJS operators memungkinkan manipulasi response stream secara deklaratif.

**Test dengan curl:**
```bash
curl http://localhost:3000/users
```
