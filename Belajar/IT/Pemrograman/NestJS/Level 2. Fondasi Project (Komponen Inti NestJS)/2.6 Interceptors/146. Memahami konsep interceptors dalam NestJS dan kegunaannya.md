# 146. Memahami konsep interceptors dalam NestJS dan kegunaannya

## Definisi & Target
Interceptor adalah class yang membungkus eksekusi route handler menggunakan pola Aspect-Oriented Programming. Interceptor bisa menjalankan logika SEBELUM dan SETELAH handler dieksekusi, memodifikasi request/response, menangani error, atau bahkan membatalkan eksekusi. Interceptor dieksekusi setelah guard dan sebelum pipe.

## Komponen & Nest CLI Command
```
nest g interceptor common/transform --no-spec
nest g interceptor common/logging --no-spec
```
File: `src/common/interceptors/`

## Kode Implementasi (Per File)

```typescript
// src/common/interceptors/logging.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable, tap } from 'rxjs';

@Injectable()
export class LoggingInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const start = Date.now();
    const request = context.switchToHttp().getRequest();

    console.log(`Before: ${request.method} ${request.url}`);

    return next.handle().pipe(
      tap(() => {
        const duration = Date.now() - start;
        console.log(`After: ${request.method} ${request.url} - ${duration}ms`);
      }),
    );
  }
}
```

```typescript
// src/common/interceptors/transform.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable, map } from 'rxjs';

@Injectable()
export class TransformInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    return next.handle().pipe(
      map(data => ({
        success: true,
        data,
        timestamp: new Date().toISOString(),
      })),
    );
  }
}
```

## Cara Integrasi & Pengujian

Interceptor bisa dipasang di level controller, method, atau global. Gunakan `next.handle()` untuk melanjutkan eksekusi ke handler.

**Test dengan curl:**
```bash
curl http://localhost:3000/users
# Console: Before: GET /users
# Console: After: GET /users - 5ms
# Response: {"success":true,"data":[...],"timestamp":"2026-06-01T09:00:00.000Z"}
```
