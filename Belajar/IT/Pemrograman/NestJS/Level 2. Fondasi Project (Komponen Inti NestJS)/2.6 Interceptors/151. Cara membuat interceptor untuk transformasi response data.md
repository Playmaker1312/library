# 151. Cara membuat interceptor untuk transformasi response data

## Definisi & Target
Interceptor transformasi memodifikasi data yang dikembalikan oleh handler sebelum dikirim ke client. Contoh: mengubah format tanggal, menyensor data sensitif, menambahkan field, atau mengubah struktur response.

## Komponen & Nest CLI Command
```
nest g interceptor common/transform --no-spec
```
File: `src/common/interceptors/transform.interceptor.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/interceptors/exclude-sensitive.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable, map } from 'rxjs';

@Injectable()
export class ExcludeSensitiveInterceptor implements NestInterceptor {
  private sensitiveFields = ['password', 'secret', 'token', 'creditCard'];

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    return next.handle().pipe(
      map(data => {
        if (Array.isArray(data)) {
          return data.map(item => this.sanitize(item));
        }
        return this.sanitize(data);
      }),
    );
  }

  private sanitize(obj: any): any {
    if (!obj || typeof obj !== 'object') return obj;

    const result = { ...obj };
    for (const field of this.sensitiveFields) {
      delete result[field];
    }
    return result;
  }
}
```

```typescript
// src/common/interceptors/date-format.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable, map } from 'rxjs';

@Injectable()
export class DateFormatInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    return next.handle().pipe(
      map(data => {
        const formatted = { ...data };
        if (formatted.createdAt) {
          formatted.createdAt = new Date(formatted.createdAt).toISOString();
        }
        if (formatted.updatedAt) {
          formatted.updatedAt = new Date(formatted.updatedAt).toISOString();
        }
        return formatted;
      }),
    );
  }
}
```

```typescript
// src/users/users.controller.ts
import { Controller, Get, UseInterceptors } from '@nestjs/common';
import { ExcludeSensitiveInterceptor } from '../common/interceptors/exclude-sensitive.interceptor';

@Controller('users')
@UseInterceptors(ExcludeSensitiveInterceptor)
export class UsersController {
  @Get()
  findAll() {
    return [
      { id: 1, name: 'Alice', email: 'alice@test.com', password: 'secret123' },
      { id: 2, name: 'Bob', email: 'bob@test.com', password: 'password456' },
    ];
  }
}
```

## Cara Integrasi & Pengujian

Data sensitif akan otomatis dihapus sebelum dikirim ke client.

**Test dengan curl:**
```bash
curl http://localhost:3000/users
# [{"id":1,"name":"Alice","email":"alice@test.com"},{"id":2,"name":"Bob","email":"bob@test.com"}]
# (field password dihapus)
```
