# 156. Cara membuat interceptor untuk menangani error secara terpusat

## Definisi & Target
Interceptor juga bisa menangani error yang dilempar oleh handler menggunakan operator `catchError` dari RxJS. Ini melengkapi exception filter—interceptor menangkap error di level stream, sedangkan exception filter menangani error yang sudah dikonversi ke HTTP response.

## Komponen & Nest CLI Command
```
nest g interceptor/common/error-handler --no-spec
```
File: `src/common/interceptors/error-handler.interceptor.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/interceptors/error-handler.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler, HttpException, HttpStatus, Logger } from '@nestjs/common';
import { Observable, throwError, catchError } from 'rxjs';

@Injectable()
export class ErrorHandlerInterceptor implements NestInterceptor {
  private readonly logger = new Logger('ErrorHandler');

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    return next.handle().pipe(
      catchError(err => {
        const request = context.switchToHttp().getRequest();

        this.logger.error(`Error in ${request.method} ${request.url}: ${err.message}`);

        let status = HttpStatus.INTERNAL_SERVER_ERROR;
        let message = 'Internal server error';

        if (err instanceof HttpException) {
          status = err.getStatus();
          const res = err.getResponse();
          message = typeof res === 'string' ? res : (res as any).message || err.message;
        } else if (err instanceof Error) {
          message = err.message;
        }

        return throwError(() => ({
          statusCode: status,
          message,
          timestamp: new Date().toISOString(),
          path: request.url,
        }));
      }),
    );
  }
}
```

```typescript
// src/common/interceptors/fallback.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler, HttpStatus } from '@nestjs/common';
import { Observable, throwError, catchError, of } from 'rxjs';

@Injectable()
export class FallbackInterceptor implements NestInterceptor {
  private readonly fallbackData = { message: 'Service temporarily unavailable' };

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    return next.handle().pipe(
      catchError(err => {
        const response = context.switchToHttp().getResponse();
        response.status(HttpStatus.SERVICE_UNAVAILABLE);

        return of(this.fallbackData);
      }),
    );
  }
}
```

## Cara Integrasi & Pengujian

Error handler interceptor menangkap error dan mengembalikan format error yang konsisten.

**Test dengan curl:**
```bash
curl http://localhost:3000/users/error
# {"statusCode":500,"message":"Something went wrong","timestamp":"2026-06-01T09:00:00.000Z","path":"/users/error"}
```
