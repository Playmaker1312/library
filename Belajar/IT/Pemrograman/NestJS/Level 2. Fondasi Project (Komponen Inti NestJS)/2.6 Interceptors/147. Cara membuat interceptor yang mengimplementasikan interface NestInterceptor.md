# 147. Cara membuat interceptor yang mengimplementasikan interface NestInterceptor

## Definisi & Target
Semua interceptor harus mengimplementasikan interface `NestInterceptor<T, R>` dengan method `intercept(context: ExecutionContext, next: CallHandler): Observable<R>`. `CallHandler.handle()` mengembalikan Observable yang mewakili response dari route handler.

## Komponen & Nest CLI Command
```
nest g interceptor common/timing --no-spec
```
File: `src/common/interceptors/timing.interceptor.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/interceptors/timing.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable, tap } from 'rxjs';

@Injectable()
export class TimingInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const request = context.switchToHttp().getRequest();
    const method = request.method;
    const url = request.url;

    console.log(`[TimingInterceptor] Executing ${method} ${url}`);

    const startTime = Date.now();

    return next.handle().pipe(
      tap(() => {
        const elapsed = Date.now() - startTime;
        console.log(`[TimingInterceptor] ${method} ${url} completed in ${elapsed}ms`);
      }),
    );
  }
}
```

```typescript
// src/common/interceptors/empty-response.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable, map } from 'rxjs';

@Injectable()
export class EmptyResponseInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    return next.handle().pipe(
      map(data => {
        if (data === null || data === undefined) {
          return { message: 'No content', statusCode: 204 };
        }
        if (Array.isArray(data) && data.length === 0) {
          return { data: [], total: 0 };
        }
        return data;
      }),
    );
  }
}
```

```typescript
// src/users/users.controller.ts
import { Controller, Get, UseInterceptors } from '@nestjs/common';
import { TimingInterceptor } from '../common/interceptors/timing.interceptor';
import { EmptyResponseInterceptor } from '../common/interceptors/empty-response.interceptor';

@Controller('users')
@UseInterceptors(TimingInterceptor, EmptyResponseInterceptor)
export class UsersController {
  @Get()
  findAll() {
    return [{ id: 1, name: 'Alice' }];
  }

  @Get('empty')
  getEmpty() {
    return [];
  }
}
```

## Cara Integrasi & Pengujian

Interceptor membungkus handler. `next.handle()` harus dipanggil—tanpa itu, handler tidak akan dieksekusi.

**Test dengan curl:**
```bash
curl http://localhost:3000/users/empty
# {"data":[],"total":0}
# Console: [TimingInterceptor] Executing GET /users/empty
# Console: [TimingInterceptor] GET /users/empty completed in 2ms
```
