# 149. Cara mendaftarkan interceptor pada controller menggunakan UseInterceptors

## Definisi & Target
Decorator `@UseInterceptors()` mendaftarkan interceptor di level controller (semua method) atau method spesifik. Bisa menerima satu atau lebih interceptor. Interceptor didaftarkan sebagai class reference agar bisa memanfaatkan DI.

## Komponen & Nest CLI Command
```
nest g interceptor common/wrap --no-spec
```
File: `src/users/users.controller.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/interceptors/wrap-response.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable, map } from 'rxjs';

@Injectable()
export class WrapResponseInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    return next.handle().pipe(
      map(data => ({
        success: true,
        data,
        timestamp: new Date().toISOString(),
      })),
    );
  }
}
```

```typescript
// src/common/interceptors/header.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable, tap } from 'rxjs';
import { Response } from 'express';

@Injectable()
export class HeaderInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const response = context.switchToHttp().getResponse<Response>();

    return next.handle().pipe(
      tap(() => {
        response.setHeader('X-Powered-By', 'NestJS');
        response.setHeader('X-API-Version', '1.0');
      }),
    );
  }
}
```

```typescript
// src/users/users.controller.ts
import { Controller, Get, Post, UseInterceptors } from '@nestjs/common';
import { WrapResponseInterceptor } from '../common/interceptors/wrap-response.interceptor';
import { HeaderInterceptor } from '../common/interceptors/header.interceptor';

@Controller('users')
@UseInterceptors(WrapResponseInterceptor, HeaderInterceptor)
export class UsersController {
  @Get()
  findAll() {
    return [{ id: 1, name: 'Alice' }];
  }

  @Post()
  create() {
    return { id: 2, name: 'Bob' };
  }

  @Get('raw')
  @UseInterceptors()
  getRaw() {
    return { raw: true };
  }
}
```

## Cara Integrasi & Pengujian

Interceptor di level controller membungkus semua response method. `@UseInterceptors()` kosong meng-override interceptor class-level untuk method tertentu.

**Test dengan curl:**
```bash
curl http://localhost:3000/users
# {"success":true,"data":[{"id":1,"name":"Alice"}],"timestamp":"..."}
# Header: X-Powered-By: NestJS

curl http://localhost:3000/users/raw
# {"raw":true}  <- Tanpa wrapper
```
