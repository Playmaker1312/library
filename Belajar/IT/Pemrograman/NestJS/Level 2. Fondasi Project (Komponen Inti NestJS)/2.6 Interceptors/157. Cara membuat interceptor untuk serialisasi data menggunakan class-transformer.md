# 157. Cara membuat interceptor untuk serialisasi data menggunakan class-transformer

## Definisi & Target
Interceptor serialisasi menggunakan `class-transformer` (`plainToInstance` / `instanceToPlain`) untuk mengontrol bagaimana data dikirim ke client. Berguna untuk menyembunyikan field (`@Exclude`), menambahkan field virtual (`@Transform`), atau mengubah format properti.

## Komponen & Nest CLI Command
```
npm install class-transformer
nest g interceptor common/serialize --no-spec
```
File: `src/common/interceptors/serialize.interceptor.ts`

## Kode Implementasi (Per File)

```typescript
// src/users/entities/user.entity.ts
import { Exclude, Expose, Transform } from 'class-transformer';

export class UserEntity {
  id: number;
  name: string;
  email: string;

  @Exclude()
  password: string;

  @Exclude()
  secretToken: string;

  @Expose()
  get displayName(): string {
    return this.name.toUpperCase();
  }

  @Transform(({ value }) => value?.toISOString())
  createdAt: Date;

  constructor(partial: Partial<UserEntity>) {
    Object.assign(this, partial);
  }
}
```

```typescript
// src/common/interceptors/serialize.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable, map } from 'rxjs';
import { instanceToPlain } from 'class-transformer';

@Injectable()
export class SerializeInterceptor implements NestInterceptor {
  constructor(private readonly dto: any) {}

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    return next.handle().pipe(
      map(data => {
        if (Array.isArray(data)) {
          return data.map(item => this.serialize(item));
        }
        return this.serialize(data);
      }),
    );
  }

  private serialize(data: any) {
    const instance = new this.dto(data);
    return instanceToPlain(instance);
  }
}
```

```typescript
// src/users/users.controller.ts
import { Controller, Get, UseInterceptors } from '@nestjs/common';
import { SerializeInterceptor } from '../common/interceptors/serialize.interceptor';
import { UserEntity } from './entities/user.entity';

@Controller('users')
@UseInterceptors(new SerializeInterceptor(UserEntity))
export class UsersController {
  @Get()
  findAll() {
    return [
      new UserEntity({
        id: 1,
        name: 'Alice',
        email: 'alice@test.com',
        password: 'secret123',
        secretToken: 'abc',
        createdAt: new Date(),
      }),
    ];
  }
}
```

## Cara Integrasi & Pengujian

Field dengan `@Exclude()` dihapus dari response. `@Expose()` dan `@Transform()` memodifikasi data.

**Test dengan curl:**
```bash
curl http://localhost:3000/users
# [{"id":1,"name":"Alice","email":"alice@test.com","displayName":"ALICE","createdAt":"2026-06-01T09:00:00.000Z"}]
# (password dan secretToken tidak muncul)
```
