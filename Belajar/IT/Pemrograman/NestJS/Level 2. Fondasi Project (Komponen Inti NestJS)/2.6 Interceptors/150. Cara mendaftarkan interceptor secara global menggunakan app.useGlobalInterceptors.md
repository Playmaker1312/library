# 150. Cara mendaftarkan interceptor secara global menggunakan app.useGlobalInterceptors

## Definisi & Target
Interceptor global didaftarkan melalui `app.useGlobalInterceptors()` di `main.ts` dan berlaku untuk seluruh endpoint. Untuk interceptor yang membutuhkan DI, gunakan provider `APP_INTERCEPTOR` di AppModule.

## Komponen & Nest CLI Command
Tidak ada CLI command.
File: `src/main.ts`, `src/app.module.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/interceptors/global-wrap.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable, map } from 'rxjs';

@Injectable()
export class GlobalWrapInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    return next.handle().pipe(
      map(data => ({
        success: true,
        data,
        timestamp: new Date().toISOString(),
      })),
    );
  }
}
```

```typescript
// Opsi 1: Global via main.ts (tanpa DI)
// src/main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { GlobalWrapInterceptor } from './common/interceptors/global-wrap.interceptor';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.useGlobalInterceptors(new GlobalWrapInterceptor());

  await app.listen(3000);
}
bootstrap();
```

```typescript
// Opsi 2: Global dengan DI via APP_INTERCEPTOR
// src/app.module.ts
import { Module } from '@nestjs/common';
import { APP_INTERCEPTOR } from '@nestjs/core';
import { GlobalWrapInterceptor } from './common/interceptors/global-wrap.interceptor';

@Module({
  providers: [
    {
      provide: APP_INTERCEPTOR,
      useClass: GlobalWrapInterceptor,
    },
  ],
})
export class AppModule {}
```

## Cara Integrasi & Pengujian

Semua response dari endpoint mana pun akan melewati interceptor global.

**Test dengan curl:**
```bash
curl http://localhost:3000/users
# {"success":true,"data":[...],"timestamp":"2026-06-01T09:00:00.000Z"}

curl http://localhost:3000/products
# {"success":true,"data":[...],"timestamp":"2026-06-01T09:00:00.000Z"}
```
