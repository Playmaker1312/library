# 117. Memahami built-in pipes yaitu ValidationPipe, ParseIntPipe, ParseBoolPipe, ParseUUIDPipe, dll

## Definisi & Target
NestJS menyediakan beberapa pipe bawaan yang siap pakai. Pipe-parse (ParseIntPipe, ParseUUIDPipe, dll.) mengonversi string parameter menjadi tipe tertentu. `ValidationPipe` melakukan validasi object DTO secara otomatis.

## Komponen & Nest CLI Command
Tidak perlu instalasi—import dari `@nestjs/common`.
File: `src/users/users.controller.ts`

## Kode Implementasi (Per File)

```typescript
// src/users/users.controller.ts
import {
  Controller,
  Get,
  Post,
  Param,
  Query,
  Body,
  ParseIntPipe,
  ParseBoolPipe,
  ParseUUIDPipe,
  DefaultValuePipe,
  ParseArrayPipe,
  ParseEnumPipe,
} from '@nestjs/common';

enum UserRole {
  ADMIN = 'admin',
  USER = 'user',
}

@Controller('users')
export class UsersController {
  @Get(':id')
  findOne(
    @Param('id', ParseIntPipe) id: number,
  ) {
    return { id, type: typeof id };
  }

  @Get()
  findAll(
    @Query('active', new DefaultValuePipe(false), ParseBoolPipe) active: boolean,
    @Query('role', new DefaultValuePipe(UserRole.USER), new ParseEnumPipe(UserRole)) role: UserRole,
  ) {
    return { active, role };
  }

  @Post('bulk')
  createBulk(
    @Body(new ParseArrayPipe({ items: String, separator: ',' })) names: string[],
  ) {
    return { names, count: names.length };
  }

  @Get('uuid/:id')
  findByUuid(
    @Param('id', ParseUUIDPipe) id: string,
  ) {
    return { uuid: id, valid: true };
  }
}
```

## Cara Integrasi & Pengujian

Pipe built-in langsung di-inject sebagai parameter ke decorator parameter. Pipe akan otomatis memvalidasi/mentransformasi.

**Test dengan curl:**
```bash
curl "http://localhost:3000/users/123"
# {"id":123,"type":"number"}

curl "http://localhost:3000/users/uuid/not-a-uuid"
# {"message":"Validation failed (uuid is expected)","statusCode":400}

curl "http://localhost:3000/users?active=true&role=admin"
# {"active":true,"role":"admin"}
```
