# 118. Cara menggunakan ParseIntPipe untuk mengonversi parameter string ke integer

## Definisi & Target
`ParseIntPipe` adalah pipe built-in yang mengonversi string parameter (dari URL) menjadi integer. Jika konversi gagal (misalnya input bukan angka), pipe akan melempar `BadRequestException` secara otomatis.

## Komponen & Nest CLI Command
Tidak perlu instalasi.
File: `src/products/products.controller.ts`

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts
import { Controller, Get, Post, Param, Query, ParseIntPipe, Body } from '@nestjs/common';

@Controller('products')
export class ProductsController {
  private products = [
    { id: 1, name: 'Laptop', price: 15000 },
    { id: 2, name: 'Mouse', price: 200 },
  ];

  @Get(':id')
  findOne(
    @Param('id', ParseIntPipe) id: number,
  ) {
    const product = this.products.find(p => p.id === id);
    if (!product) return { error: 'Not found' };
    return product;
  }

  @Get()
  findByPrice(
    @Query('minPrice', ParseIntPipe) minPrice: number,
    @Query('maxPrice', ParseIntPipe) maxPrice: number,
  ) {
    return this.products.filter(p => p.price >= minPrice && p.price <= maxPrice);
  }

  @Post()
  create(
    @Body('price', ParseIntPipe) price: number,
    @Body('name') name: string,
  ) {
    return { name, price, type: typeof price };
  }
}
```

## Cara Integrasi & Pengujian

Pipe akan mengonversi string "123" menjadi number 123. Jika string tidak bisa dikonversi, error 400 akan dikembalikan.

**Test dengan curl:**
```bash
curl http://localhost:3000/products/1
# {"id":1,"name":"Laptop","price":15000}

curl http://localhost:3000/products/abc
# {"message":"Validation failed (numeric string is expected)","statusCode":400}

curl "http://localhost:3000/products?minPrice=100&maxPrice=1000"
# [{"id":2,"name":"Mouse","price":200}]
```
