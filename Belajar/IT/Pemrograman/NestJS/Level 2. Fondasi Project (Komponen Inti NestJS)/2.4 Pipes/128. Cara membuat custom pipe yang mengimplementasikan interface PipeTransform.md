# 128. Cara membuat custom pipe yang mengimplementasikan interface PipeTransform

## Definisi & Target
Custom pipe mengimplementasikan interface `PipeTransform<T, R>` dengan method `transform(value: T, metadata: ArgumentMetadata): R`. Pipe bisa melakukan transformasi data (misalnya parsing, formatting) atau validasi (melempar exception jika tidak valid).

## Komponen & Nest CLI Command
```
nest g pipe common/file-validation --no-spec
nest g pipe common/trim --no-spec
```
File: `src/common/pipes/`

## Kode Implementasi (Per File)

```typescript
// src/common/pipes/trim.pipe.ts
import { PipeTransform, Injectable, ArgumentMetadata } from '@nestjs/common';

@Injectable()
export class TrimPipe implements PipeTransform {
  transform(value: any, metadata: ArgumentMetadata) {
    if (typeof value === 'string') {
      return value.trim();
    }
    if (typeof value === 'object' && value !== null) {
      Object.keys(value).forEach(key => {
        if (typeof value[key] === 'string') {
          value[key] = value[key].trim();
        }
      });
    }
    return value;
  }
}
```

```typescript
// src/common/pipes/file-validation.pipe.ts
import { PipeTransform, Injectable, ArgumentMetadata, BadRequestException } from '@nestjs/common';

@Injectable()
export class FileValidationPipe implements PipeTransform {
  constructor(
    private readonly options: {
      maxSize?: number;
      allowedMimeTypes?: string[];
    } = {},
  ) {}

  transform(value: Express.Multer.File, metadata: ArgumentMetadata) {
    if (!value) {
      throw new BadRequestException('File is required');
    }

    if (this.options.maxSize && value.size > this.options.maxSize) {
      throw new BadRequestException(
        `File size exceeds limit of ${this.options.maxSize / 1024 / 1024}MB`,
      );
    }

    if (this.options.allowedMimeTypes && !this.options.allowedMimeTypes.includes(value.mimetype)) {
      throw new BadRequestException(
        `File type ${value.mimetype} is not allowed. Allowed: ${this.options.allowedMimeTypes.join(', ')}`,
      );
    }

    return value;
  }
}
```

```typescript
// src/users/users.controller.ts
import { Controller, Post, Body, UsePipes } from '@nestjs/common';
import { TrimPipe } from '../common/pipes/trim.pipe';

@Controller('users')
export class UsersController {
  @Post()
  @UsePipes(TrimPipe)
  create(@Body() body: any) {
    return { data: body };
  }
}
```

## Cara Integrasi & Pengujian

Custom pipe bisa dipasang di level parameter, method (`@UsePipes`), controller, atau global.

**Test dengan curl:**
```bash
curl -X POST http://localhost:3000/users \
  -H "Content-Type: application/json" \
  -d '{"name":"  Alice  ","email":"  alice@test.com  "}'
# {"data":{"name":"Alice","email":"alice@test.com"}}  <- whitespace ter-trim
```
