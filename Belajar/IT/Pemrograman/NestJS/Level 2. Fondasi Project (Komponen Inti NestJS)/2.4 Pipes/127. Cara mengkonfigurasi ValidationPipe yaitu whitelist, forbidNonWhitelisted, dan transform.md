# 127. Cara mengkonfigurasi ValidationPipe yaitu whitelist, forbidNonWhitelisted, dan transform

## Definisi & Target
Tiga opsi konfigurasi utama ValidationPipe: `whitelist: true` menghapus properti yang tidak ada decorator validasi; `forbidNonWhitelisted: true` melempar error jika ada properti ekstra; `transform: true` mengubah plain object menjadi instance DTO class dan melakukan type coercion.

## Komponen & Nest CLI Command
Tidak ada CLI command.
File: `src/main.ts`

## Kode Implementasi (Per File)

```typescript
// src/main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { ValidationPipe } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.useGlobalPipes(
    new ValidationPipe({
      whitelist: true,
      forbidNonWhitelisted: true,
      transform: true,
      transformOptions: {
        enableImplicitConversion: true,
      },
    }),
  );

  await app.listen(3000);
}
bootstrap();
```

```typescript
// src/users/dto/update-profile.dto.ts
import { IsString, IsOptional, IsInt, Min } from 'class-validator';

export class UpdateProfileDto {
  @IsOptional()
  @IsString()
  displayName?: string;

  @IsOptional()
  @IsInt()
  @Min(1)
  age?: number;
}
```

```typescript
// src/users/users.controller.ts
import { Controller, Patch, Body, Param, ParseIntPipe } from '@nestjs/common';
import { UpdateProfileDto } from './dto/update-profile.dto';

@Controller('users')
export class UsersController {
  @Patch(':id')
  updateProfile(
    @Param('id', ParseIntPipe) id: number,
    @Body() dto: UpdateProfileDto,
  ) {
    return {
      message: 'Profile updated',
      id,
      data: dto,
    };
  }
}
```

## Cara Integrasi & Pengujian

Dengan konfigurasi di atas, properti ekstra akan ditolak, tipe data dikonversi otomatis, dan hanya properti dengan decorator validasi yang dipertahankan.

**Test dengan curl:**
```bash
# Properti ekstra "role" akan ditolak
curl -X PATCH http://localhost:3000/users/1 \
  -H "Content-Type: application/json" \
  -d '{"displayName":"Alice","age":"25","role":"admin"}'
# {"message":["property role should not exist"],"statusCode":400,"error":"Bad Request"}

# Valid - age string "25" dikonversi ke number
curl -X PATCH http://localhost:3000/users/1 \
  -H "Content-Type: application/json" \
  -d '{"displayName":"Alice","age":"25"}'
# {"message":"Profile updated","id":1,"data":{"displayName":"Alice","age":25}}
```
