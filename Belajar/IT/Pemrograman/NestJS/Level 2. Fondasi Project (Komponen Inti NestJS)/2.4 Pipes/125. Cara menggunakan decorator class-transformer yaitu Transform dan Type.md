# 125. Cara menggunakan decorator class-transformer yaitu Transform dan Type

## Definisi & Target
`class-transformer` menyediakan `@Transform()` untuk kustom transformasi nilai dan `@Type()` untuk menentukan tipe properti (berguna untuk nested object/array). Keduanya bekerja dengan `ValidationPipe` ketika `transform: true` diaktifkan.

## Komponen & Nest CLI Command
```
npm install class-transformer
```
File: `src/users/dto/create-user.dto.ts`

## Kode Implementasi (Per File)

```typescript
// src/users/dto/create-user.dto.ts
import {
  IsString, IsEmail, IsDate, IsArray, ValidateNested,
} from 'class-validator';
import { Transform, Type } from 'class-transformer';

export class AddressDto {
  @IsString()
  street: string;

  @IsString()
  city: string;

  @IsString()
  zipCode: string;
}

export class CreateUserDto {
  @IsString()
  @Transform(({ value }) => value?.trim())
  name: string;

  @IsEmail()
  @Transform(({ value }) => value?.toLowerCase())
  email: string;

  @Type(() => Date)
  @IsDate()
  birthDate: Date;

  @IsArray()
  @ValidateNested({ each: true })
  @Type(() => AddressDto)
  addresses: AddressDto[];

  @Transform(({ value }) => (value ? value.split(',').map(s => s.trim()) : []))
  @IsString({ each: true })
  interests: string[];

  @Transform(({ value }) => parseInt(value, 10))
  age: number;
}
```

```typescript
// src/users/users.controller.ts
import { Controller, Post, Body } from '@nestjs/common';
import { CreateUserDto } from './dto/create-user.dto';

@Controller('users')
export class UsersController {
  @Post()
  create(@Body() dto: CreateUserDto) {
    return {
      name: dto.name,
      email: dto.email,
      birthDate: dto.birthDate instanceof Date ? dto.birthDate.toISOString() : dto.birthDate,
      addresses: dto.addresses,
      interests: dto.interests,
    };
  }
}
```

## Cara Integrasi & Pengujian

`@Transform` memodifikasi nilai saat deserialisasi. `@Type` memastikan nested object di-instanciasi sebagai class yang benar.

**Test dengan curl:**
```bash
curl -X POST http://localhost:3000/users \
  -H "Content-Type: application/json" \
  -d '{"name":"  Alice  ","email":"ALICE@TEST.COM","birthDate":"2000-01-15","addresses":[{"street":"Jl. Merdeka","city":"Jakarta","zipCode":"12345"}],"interests":"coding,gaming,reading","age":"25"}'
# {"name":"Alice","email":"alice@test.com","birthDate":"2000-01-15T00:00:00.000Z","addresses":[...],"interests":["coding","gaming","reading"]}
```
