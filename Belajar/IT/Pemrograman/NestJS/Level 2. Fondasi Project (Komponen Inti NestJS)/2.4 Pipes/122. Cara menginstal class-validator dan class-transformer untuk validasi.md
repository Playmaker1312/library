# 122. Cara menginstal class-validator dan class-transformer untuk validasi

## Definisi & Target
`class-validator` menyediakan decorator validasi (IsString, IsEmail, dll.) untuk properti class. `class-transformer` mengubah plain JSON object menjadi instance class DTO dan menyediakan decorator transformasi. Keduanya diperlukan `ValidationPipe` untuk bekerja secara optimal.

## Komponen & Nest CLI Command
```
npm install class-validator class-transformer
```
File: `package.json` (dependency akan tercatat otomatis)

## Kode Implementasi (Per File)

```typescript
// package.json (setelah install)
// "dependencies": {
//   "class-validator": "^0.14.0",
//   "class-transformer": "^0.5.0"
// }
```

```typescript
// src/auth/dto/register.dto.ts
import {
  IsString,
  IsEmail,
  MinLength,
  MaxLength,
  Matches,
  IsOptional,
} from 'class-validator';
import { Transform } from 'class-transformer';

export class RegisterDto {
  @IsString()
  @MinLength(3)
  @MaxLength(50)
  @Transform(({ value }) => value?.trim())
  username: string;

  @IsEmail()
  @Transform(({ value }) => value?.toLowerCase())
  email: string;

  @IsString()
  @MinLength(8)
  @MaxLength(32)
  @Matches(/(?=.*[a-z])(?=.*[A-Z])(?=.*\d)/, {
    message: 'Password must contain uppercase, lowercase, and number',
  })
  password: string;

  @IsOptional()
  @IsString()
  referralCode?: string;
}
```

```typescript
// src/main.ts (cek versi di console)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { ValidationPipe } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.useGlobalPipes(
    new ValidationPipe({
      transform: true,
      whitelist: true,
      forbidNonWhitelisted: true,
    }),
  );

  await app.listen(3000);
}
bootstrap();
```

## Cara Integrasi & Pengujian

Setelah instalasi, decorators dari kedua package tersedia. `ValidationPipe` dengan `transform: true` akan mengubah plain object menjadi instance DTO class.

**Test dengan curl:**
```bash
curl -X POST http://localhost:3000/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"  John  ","email":"JOHN@EXAMPLE.COM","password":"Weak1"}'
# {"message":["password too weak"],"statusCode":400}
# username akan di-trim, email lowercase
```
