# 116. Memahami konsep pipes dalam NestJS untuk transformasi dan validasi data

## Definisi & Target
Pipes dalam NestJS adalah class yang dianotasi dengan `@Injectable()` dan mengimplementasikan interface `PipeTransform`. Pipes memiliki dua kasus penggunaan utama: **transformasi** (mengubah data input menjadi bentuk yang diinginkan, misal string ke integer) dan **validasi** (memeriksa apakah data input memenuhi kriteria tertentu, melempar exception jika tidak valid). Pipes berjalan di antara client request dan route handler, memungkinkan preprocessing data sebelum mencapai logic bisnis. Ini penting untuk pengembangan NestJS karena memisahkan concern validasi/transformasi dari business logic, meningkatkan reusability, dan memastikan data integrity secara konsisten di seluruh aplikasi.

## Langkah-langkah Implementasi (Step-by-Step)
1. **Buat custom pipe** yang implement `PipeTransform<T, R>` dengan method `transform(value: T, metadata: ArgumentMetadata): R`
2. **Gunakan built-in pipes** seperti `ParseIntPipe`, `ParseBoolPipe`, `ParseUUIDPipe` langsung di parameter controller
3. **Implementasi ValidationPipe** untuk validasi otomatis berbasis DTO dengan class-validator
4. **Daftarkan pipe** secara global, per-controller, atau per-method/parameter

## Kode Implementasi (Per File)

### Custom Pipe Dasar
```typescript
// src/pipes/validation.pipe.ts
import { PipeTransform, Injectable, ArgumentMetadata, BadRequestException } from '@nestjs/common';

@Injectable()
export class ValidationPipe implements PipeTransform<any> {
  transform(value: any, metadata: ArgumentMetadata): any {
    console.log(`Transforming ${metadata.type}: ${metadata.metatype?.name}`);
    return value;
  }
}
```

### Controller Menggunakan Pipes
```typescript
// src/users/users.controller.ts
import { Controller, Get, Post, Body, Param, Query, ParseIntPipe, ValidationPipe } from '@nestjs/common';
import { CreateUserDto } from './dto/create-user.dto';

@Controller('users')
export class UsersController {
  @Post()
  create(@Body(ValidationPipe) createUserDto: CreateUserDto) {
    return createUserDto;
  }

  @Get(':id')
  findOne(@Param('id', ParseIntPipe) id: number) {
    return { id };
  }

  @Get()
  findAll(@Query('limit', ParseIntPipe) limit: number = 10) {
    return { limit };
  }
}
```

## Konfigurasi & Integrasi
```typescript
// main.ts - Global ValidationPipe
import { ValidationPipe } from '@nestjs/common';

app.useGlobalPipes(new ValidationPipe({
  whitelist: true,
  forbidNonWhitelisted: true,
  transform: true,
  disableErrorMessages: false,
}));
```

## Troubleshooting & Common Issues
| Error | Penyebab | Solusi |
|-------|----------|--------|
| Validation tidak berjalan | ValidationPipe tidak terdaftar | Daftarkan global atau gunakan `@UsePipes()` |
| Transform tidak applied | `transform: true` tidak diset | Set `transform: true` di ValidationPipe options |
| Whitelist stripping data | `whitelist: true` tapi DTO tidak pakai decorator | Tambahkan `@IsOptional()` atau decorator validasi di DTO |

## Best Practices
- Gunakan **built-in pipes** untuk transformasi sederhana (ParseInt, ParseBool, ParseUUID)
- Buat **custom pipes** hanya untuk logic validasi/transformasi kompleks yang reusable
- Selalu aktifkan `whitelist: true` dan `forbidNonWhitelisted: true` di production
- Gunakan **validation groups** untuk skenario validasi kondisional
- Hindari logic bisnis di dalam pipes; pipes hanya untuk validasi/transformasi data
