# 116. Memahami konsep pipes dalam NestJS untuk transformasi dan validasi data

## Definisi & Target
Pipe adalah class yang menangani dua tugas: **transformasi** (mengubah input) dan **validasi** (menilai apakah input valid). Pipe dieksekusi sebelum route handler—jika pipe melempar exception, handler tidak akan dijalankan. Posisi pipe dalam pipeline adalah setelah guard tetapi sebelum controller.

## Komponen & Nest CLI Command
```
nest g pipe nama-pipe --no-spec
nest g pipe common/parse-int  --no-spec
```
File: `src/common/pipes/`

## Kode Implementasi (Per File)

```typescript
// src/common/pipes/parse-int.pipe.ts
import { PipeTransform, Injectable, ArgumentMetadata, BadRequestException } from '@nestjs/common';

@Injectable()
export class ParseIntPipe implements PipeTransform<string, number> {
  transform(value: string, metadata: ArgumentMetadata): number {
    const val = parseInt(value, 10);
    if (isNaN(val)) {
      throw new BadRequestException(`"${value}" is not a valid number`);
    }
    return val;
  }
}
```

```typescript
// src/common/pipes/uppercase.pipe.ts
import { PipeTransform, Injectable, ArgumentMetadata } from '@nestjs/common';

@Injectable()
export class UpperCasePipe implements PipeTransform<string, string> {
  transform(value: string, metadata: ArgumentMetadata): string {
    return value.toUpperCase();
  }
}
```

```typescript
// src/common/pipes/validation.pipe.ts
import { PipeTransform, Injectable, ArgumentMetadata, BadRequestException } from '@nestjs/common';

@Injectable()
export class SimpleValidationPipe implements PipeTransform {
  transform(value: any, metadata: ArgumentMetadata) {
    if (!value) {
      throw new BadRequestException(`${metadata.data} should not be empty`);
    }
    return value;
  }
}
```

## Cara Integrasi & Pengujian

Pipe bisa dipasang di level parameter, method, controller, atau global. Urutan eksekusi: Guard -> Interceptor (sebelum) -> Pipe -> Handler.

**Test dengan curl:**
```bash
curl http://localhost:3000/users/abc
# {"message":"\"abc\" is not a valid number","statusCode":400}

curl http://localhost:3000/transform/test
# Response: TEST (diubah ke uppercase)
```
