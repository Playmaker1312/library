# 129. Cara membuat pipe untuk sanitasi input.md
## Definisi & Target
Sanitasi input membersihkan data dari konten berbahaya seperti script injection (XSS), karakter kontrol, atau HTML tags. Pipe sanitasi dijalankan sebelum data mencapai route handler dan/atau disimpan ke database.

## Komponen & Nest CLI Command
```
nest g pipe common/sanitize --no-spec
```
File: `src/common/pipes/sanitize.pipe.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/pipes/sanitize.pipe.ts
import { PipeTransform, Injectable, ArgumentMetadata } from '@nestjs/common';

@Injectable()
export class SanitizePipe implements PipeTransform {
  transform(value: any, metadata: ArgumentMetadata) {
    if (typeof value === 'string') {
      return this.sanitizeString(value);
    }
    if (typeof value === 'object' && value !== null) {
      Object.keys(value).forEach(key => {
        if (typeof value[key] === 'string') {
          value[key] = this.sanitizeString(value[key]);
        }
      });
    }
    return value;
  }

  private sanitizeString(input: string): string {
    return input
      .replace(/</g, '&lt;')
      .replace(/>/g, '&gt;')
      .replace(/"/g, '&quot;')
      .replace(/'/g, '&#x27;')
      .replace(/\//g, '&#x2F;')
      .replace(/\\/g, '&#x5C;')
      .replace(/`/g, '&#96;')
      .trim();
  }
}
```

```typescript
// src/common/pipes/strip-html.pipe.ts
import { PipeTransform, Injectable, ArgumentMetadata } from '@nestjs/common';

@Injectable()
export class StripHtmlPipe implements PipeTransform {
  transform(value: any, metadata: ArgumentMetadata) {
    if (typeof value === 'string') {
      return value.replace(/<[^>]*>/g, '');
    }
    if (typeof value === 'object' && value !== null) {
      Object.keys(value).forEach(key => {
        if (typeof value[key] === 'string') {
          value[key] = value[key].replace(/<[^>]*>/g, '');
        }
      });
    }
    return value;
  }
}
```

```typescript
// src/comments/comments.controller.ts
import { Controller, Post, Body, UsePipes } from '@nestjs/common';
import { SanitizePipe } from '../common/pipes/sanitize.pipe';

@Controller('comments')
export class CommentsController {
  @Post()
  @UsePipes(SanitizePipe)
  create(@Body() body: { content: string }) {
    return {
      original: body.content,
      safe: true,
    };
  }
}
```

## Cara Integrasi & Pengujian

Pipe sanitasi meng-encode karakter HTML berbahaya sehingga tidak bisa dieksekusi sebagai script.

**Test dengan curl:**
```bash
curl -X POST http://localhost:3000/comments \
  -H "Content-Type: application/json" \
  -d '{"content":"<script>alert(\"xss\")</script>Hello"}'
# {"original":"&lt;script&gt;alert(&quot;xss&quot;)&lt;&#x2F;script&gt;Hello","safe":true}
```
