# 120. Cara menggunakan DefaultValuePipe untuk memberikan nilai default pada parameter

## Definisi & Target
`DefaultValuePipe` memberikan nilai default ketika parameter query atau path tidak disediakan. Biasanya digunakan bersama pipe lain (misalnya `ParseIntPipe`) sebagai fallback—jika parameter kosong, default diberikan sebelum pipe transformasi berjalan.

## Komponen & Nest CLI Command
Tidak perlu instalasi.
File: `src/users/users.controller.ts`

## Kode Implementasi (Per File)

```typescript
// src/users/users.controller.ts
import { Controller, Get, Query, DefaultValuePipe, ParseIntPipe, ParseBoolPipe } from '@nestjs/common';

@Controller('users')
export class UsersController {
  private users = [
    { id: 1, name: 'Alice', active: true },
    { id: 2, name: 'Bob', active: false },
    { id: 3, name: 'Charlie', active: true },
  ];

  @Get()
  findAll(
    @Query('page', new DefaultValuePipe(1), ParseIntPipe) page: number,
    @Query('limit', new DefaultValuePipe(10), ParseIntPipe) limit: number,
    @Query('active', new DefaultValuePipe(false), ParseBoolPipe) active: boolean,
    @Query('search', new DefaultValuePipe('')) search: string,
  ) {
    let result = this.users;

    if (active) {
      result = result.filter(u => u.active);
    }
    if (search) {
      result = result.filter(u => u.name.toLowerCase().includes(search.toLowerCase()));
    }

    return {
      data: result,
      pagination: { page, limit },
    };
  }
}
```

## Cara Integrasi & Pengujian

Tanpa `DefaultValuePipe`, jika query parameter tidak diberikan, value akan `undefined` dan pipe lain bisa error. DefaultValuePipe memastikan ada nilai awal.

**Test dengan curl:**
```bash
curl "http://localhost:3000/users"
# {"data":[...],"pagination":{"page":1,"limit":10}}

curl "http://localhost:3000/users?page=2&limit=5&active=true"
# {"data":[{"id":1,"name":"Alice","active":true},{"id":3,"name":"Charlie","active":true}],"pagination":{"page":2,"limit":5}}
```
