# 124. Cara menggunakan decorator class-validator yaitu IsString, IsEmail, IsNumber, IsNotEmpty, dll

## Definisi & Target
Decorator `class-validator` ditempatkan di properti DTO untuk mendefinisikan aturan validasi. Setiap decorator memeriksa satu aspek—tipe data, panjang, format, rentang, dll. Ketika validasi gagal, `ValidationPipe` menghasilkan pesan error yang jelas.

## Komponen & Nest CLI Command
```
npm install class-validator
```
File: `src/products/dto/create-product.dto.ts`

## Kode Implementasi (Per File)

```typescript
// src/products/dto/create-product.dto.ts
import {
  IsString,
  IsNumber,
  IsNotEmpty,
  IsPositive,
  IsOptional,
  MinLength,
  MaxLength,
  Min,
  Max,
  IsUrl,
  IsArray,
  ArrayMinSize,
  IsEnum,
  IsBoolean,
} from 'class-validator';

export enum ProductCategory {
  ELECTRONICS = 'electronics',
  CLOTHING = 'clothing',
  FOOD = 'food',
}

export class CreateProductDto {
  @IsString()
  @IsNotEmpty()
  @MinLength(3)
  @MaxLength(100)
  name: string;

  @IsString()
  @IsOptional()
  @MaxLength(500)
  description?: string;

  @IsNumber()
  @IsPositive()
  @Min(1000)
  @Max(100000000)
  price: number;

  @IsNumber()
  @IsPositive()
  @Min(0)
  stock: number;

  @IsEnum(ProductCategory)
  category: ProductCategory;

  @IsArray()
  @ArrayMinSize(1)
  @IsString({ each: true })
  tags: string[];

  @IsBoolean()
  @IsOptional()
  isActive?: boolean;

  @IsUrl()
  @IsOptional()
  imageUrl?: string;
}
```

```typescript
// src/products/products.controller.ts
import { Controller, Post, Body, ValidationPipe } from '@nestjs/common';
import { CreateProductDto } from './dto/create-product.dto';

@Controller('products')
export class ProductsController {
  @Post()
  create(@Body(ValidationPipe) product: CreateProductDto) {
    return { message: 'Product created', product };
  }
}
```

## Cara Integrasi & Pengujian

Decorator divalidasi berurutan. Jika ada pelanggaran, NestJS mengembalikan array pesan error.

**Test dengan curl:**
```bash
curl -X POST http://localhost:3000/products \
  -H "Content-Type: application/json" \
  -d '{"name":"Ab","price":500,"category":"invalid","tags":[]}'
# {"message":["name must be longer than or equal to 3 characters","price must not be less than 1000","category must be a valid enum value","tags must contain at least 1 elements"],"statusCode":400,"error":"Bad Request"}
```
