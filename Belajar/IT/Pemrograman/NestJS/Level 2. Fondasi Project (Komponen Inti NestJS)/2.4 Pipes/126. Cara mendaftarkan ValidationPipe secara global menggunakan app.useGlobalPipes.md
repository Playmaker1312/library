# 126. Cara mendaftarkan ValidationPipe secara global menggunakan app.useGlobalPipes

## Definisi & Target
`app.useGlobalPipes(new ValidationPipe())` mendaftarkan ValidationPipe ke seluruh aplikasi. Semua endpoint akan otomatis memvalidasi DTO tanpa perlu menambahkan `@Body(ValidationPipe)` di setiap controller. Ini pendekatan yang paling efisien untuk aplikasi produksi.

## Komponen & Nest CLI Command
Tidak ada CLI command.
File: `src/main.ts`

## Kode Implementasi (Per File)

```typescript
// src/main.ts (pendaftaran global sederhana)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { ValidationPipe } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.useGlobalPipes(new ValidationPipe());

  await app.listen(3000);
}
bootstrap();
```

```typescript
// src/main.ts (dengan konfigurasi lengkap)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { ValidationPipe } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.useGlobalPipes(
    new ValidationPipe({
      transform: true,
      whitelist: true,
      forbidNonWhitelisted: true,
      disableErrorMessages: process.env.NODE_ENV === 'production',
      validationError: {
        target: false,
        value: false,
      },
    }),
  );

  await app.listen(3000);
}
bootstrap();
```

```typescript
// src/auth/dto/login.dto.ts
import { IsString, IsNotEmpty } from 'class-validator';

export class LoginDto {
  @IsString()
  @IsNotEmpty()
  username: string;

  @IsString()
  @IsNotEmpty()
  password: string;
}
```

```typescript
// src/auth/auth.controller.ts
import { Controller, Post, Body } from '@nestjs/common';
import { LoginDto } from './dto/login.dto';

@Controller('auth')
export class AuthController {
  @Post('login')
  login(@Body() loginDto: LoginDto) {
    return { message: 'Login success', loginDto };
  }
}
```

## Cara Integrasi & Pengujian

Setelah global ValidationPipe terdaftar, semua DTO otomatis divalidasi tanpa perlu `@Body(new ValidationPipe())`.

**Test dengan curl:**
```bash
curl -X POST http://localhost:3000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":""}'
# {"message":["username should not be empty","password should not be empty"],"statusCode":400,"error":"Bad Request"}
```
