# 71. Memahami konsep provider dalam NestJS yaitu service, repository, factory, helper

## Definisi & Target
Provider adalah class atau nilai yang dapat di-inject sebagai dependency ke class lain melalui NestJS Dependency Injection (DI) container. Di NestJS, **semua class yang didekorasi dengan `@Injectable()` adalah provider**. Jenis provider utama:
- **Service** - Berisi business logic (mis: `UsersService`, `AuthService`)
- **Repository** - Abstraksi akses data (mis: `UserRepository`, `ProductRepository`)
- **Factory** - Membuat instance secara dinamis (mis: `ConfigFactory`, `ConnectionFactory`)
- **Helper** - Utilitas stateless (mis: `StringHelper`, `DateHelper`)

**Tujuan**: Memisahkan concern, memudahkan testing, dan mengaktifkan inversion of control. DI container mengelola lifecycle instance secara otomatis.

## Prasyarat
- Paham dasar TypeScript: class, interface, decorator
- Paham konsep Module NestJS (`@Module`, `imports`, `providers`, `exports`)
- Telah setup project NestJS (`nest new project-name`)
- Node.js v18+ dan npm/yarn/pnpm

## Komponen & Nest CLI Command
```bash
# Membuat service (provider paling umum)
nest g service users          # atau: nest g s users
nest g service users --flat   # tanpa folder terpisah

# Membuat custom provider (factory, value, class)
nest g provider config        # membuat file provider custom

# Struktur file yang dihasilkan:
# src/users/users.service.ts
# src/users/users.module.ts
# src/users/users.controller.ts (optional)
```

## Langkah-langkah Implementasi (Step-by-Step)

### 1. Buat Service (Provider Dasar)
```bash
nest g service users
```
Nest CLI membuat `users.service.ts` dengan decorator `@Injectable()` dan mendaftarkannya di `users.module.ts`.

### 2. Buat Repository Pattern
Buat interface dan implementasinya terpisah untuk abstraksi database.

### 3. Buat Factory Provider
Gunakan `useFactory` untuk logic pembuatan instance kompleks.

### 4. Buat Helper Class
Class utilitas stateless tanpa state internal.

### 5. Daftarkan Semua ke Module
Tambahkan ke array `providers` di `@Module()`.

## Kode Implementasi (Per File)

### Service - Business Logic
```typescript
// src/users/users.service.ts
import { Injectable, NotFoundException } from '@nestjs/common';
import { User } from './interfaces/user.interface';

@Injectable()
export class UsersService {
  private readonly users: User[] = [
    { id: 1, name: 'Alice', email: 'alice@example.com' },
    { id: 2, name: 'Bob', email: 'bob@example.com' },
  ];

  findAll(): User[] {
    return this.users;
  }

  findOne(id: number): User {
    const user = this.users.find(u => u.id === id);
    if (!user) throw new NotFoundException(`User #${id} tidak ditemukan`);
    return user;
  }

  create(user: Omit<User, 'id'>): User {
    const newUser = { id: Date.now(), ...user };
    this.users.push(newUser);
    return newUser;
  }
}
```

### Repository - Data Access Abstraction
```typescript
// src/users/repositories/user.repository.ts
import { Injectable } from '@nestjs/common';
import { User } from '../interfaces/user.interface';

export interface UserRepository {
  findAll(): Promise<User[]>;
  findById(id: number): Promise<User | null>;
  save(user: User): Promise<User>;
}

@Injectable()
export class InMemoryUserRepository implements UserRepository {
  private users: User[] = [];

  async findAll(): Promise<User[]> {
    return this.users;
  }

  async findById(id: number): Promise<User | null> {
    return this.users.find(u => u.id === id) ?? null;
  }

  async save(user: User): Promise<User> {
    this.users.push(user);
    return user;
  }
}
```

### Factory Provider - Dynamic Creation
```typescript
// src/config/providers/database.factory.ts
import { FactoryProvider } from '@nestjs/common';
import { DatabaseConfig } from '../interfaces/database-config.interface';

export const databaseFactory: FactoryProvider<DatabaseConfig> = {
  provide: 'DATABASE_CONFIG',
  useFactory: (): DatabaseConfig => ({
    host: process.env.DB_HOST ?? 'localhost',
    port: parseInt(process.env.DB_PORT ?? '5432', 10),
    username: process.env.DB_USER ?? 'postgres',
    password: process.env.DB_PASS ?? 'postgres',
    database: process.env.DB_NAME ?? 'app_db',
    synchronize: process.env.NODE_ENV !== 'production',
  }),
};
```

### Helper - Stateless Utilities
```typescript
// src/common/helpers/string.helper.ts
export class StringHelper {
  static toSlug(text: string): string {
    return text
      .toLowerCase()
      .trim()
      .replace(/\s+/g, '-')
      .replace(/[^\w-]/g, '');
  }

  static truncate(text: string, length: number): string {
    if (text.length <= length) return text;
    return text.substring(0, length).trim() + '...';
  }

  static capitalize(text: string): string {
    return text.charAt(0).toUpperCase() + text.slice(1).toLowerCase();
  }
}
```

### Module Registration
```typescript
// src/users/users.module.ts
import { Module } from '@nestjs/common';
import { UsersService } from './users.service';
import { UsersController } from './users.controller';
import { InMemoryUserRepository } from './repositories/user.repository';
import { databaseFactory } from '../config/providers/database.factory';
import { StringHelper } from '../common/helpers/string.helper';

@Module({
  controllers: [UsersController],
  providers: [
    UsersService,
    InMemoryUserRepository,
    databaseFactory,
    StringHelper,
  ],
  exports: [UsersService, InMemoryUserRepository],
})
export class UsersModule {}
```

## Konfigurasi & Integrasi
- **providers array**: Semua provider harus terdaftar di sini agar DI container mengenali
- **exports array**: Provider yang diekspor bisa di-inject oleh module lain yang import module ini
- **Injection token**: Default pakai class name (`UsersService`), custom pakai string (`'DATABASE_CONFIG'`)

### Unit Test Service dengan Jest Mock
```typescript
// src/users/users.service.spec.ts
import { Test, TestingModule } from '@nestjs/testing';
import { UsersService } from './users.service';
import { InMemoryUserRepository } from './repositories/user.repository';

describe('UsersService', () => {
  let service: UsersService;
  let repo: InMemoryUserRepository;

  beforeEach(async () => {
    const module: TestingModule = await Test.createTestingModule({
      providers: [
        UsersService,
        { provide: InMemoryUserRepository, useValue: { findAll: jest.fn(), findById: jest.fn(), save: jest.fn() } },
      ],
    }).compile();

    service = module.get<UsersService>(UsersService);
    repo = module.get<InMemoryUserRepository>(InMemoryUserRepository);
  });

  it('should be defined', () => {
    expect(service).toBeDefined();
  });

  it('findAll returns users from repository', async () => {
    const mockUsers = [{ id: 1, name: 'Test', email: 'test@test.com' }];
    jest.spyOn(repo, 'findAll').mockResolvedValue(mockUsers);
    expect(await service.findAll()).toEqual(mockUsers);
  });
});
```

## Troubleshooting & Common Issues

| Error | Penyebab | Solusi |
|-------|----------|--------|
| `Nest can't resolve dependencies of the UsersService` | Provider tidak terdaftar di module | Tambahkan ke `providers` array di `@Module()` |
| `Cannot find module './users.service'` | Path import salah | Gunakan relative path benar: `./users.service` |
| `Circular dependency detected` | Module A import B, B import A | Gunakan `forwardRef()` atau pisah shared module |

## Best Practices
- **Single Responsibility**: Satu service satu domain logic
- **Interface-based**: Inject interface/repository, bukan implementasi konkret
- **Stateless Helper**: Helper class tanpa state, gunakan static method
- **Factory untuk Config**: Gunakan `useFactory` untuk config yang butuh env/async
- **Export Minimal**: Hanya export yang benar-benar dibutuhkan module lain
