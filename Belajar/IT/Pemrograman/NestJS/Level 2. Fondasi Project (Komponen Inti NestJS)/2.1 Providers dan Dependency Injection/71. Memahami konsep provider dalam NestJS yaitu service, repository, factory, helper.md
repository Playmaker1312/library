# 71. Memahami konsep provider dalam NestJS yaitu service, repository, factory, helper

## Definisi & Target
Provider adalah class yang dapat di-inject sebagai dependency ke class lain. Service, repository, factory, dan helper semuanya adalah provider—NestJS mengelolanya melalui Dependency Injection container. Saat controller membutuhkan service, NestJS secara otomatis menginisiasi instance service dan menyuntikkannya ke controller.

## Komponen & Nest CLI Command
```
nest g provider nama-provider    # atau nest g s, nest g service
nest g service nama-service
```
File utama: `src/nama-module/nama-module.module.ts`, `src/nama-module/nama-module.service.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/providers/config.factory.ts
import { FactoryProvider } from '@nestjs/common';

export interface AppConfig {
  port: number;
  databaseUrl: string;
}

export const configFactory: FactoryProvider<AppConfig> = {
  provide: 'APP_CONFIG',
  useFactory: () => {
    return {
      port: parseInt(process.env.PORT, 10) || 3000,
      databaseUrl: process.env.DATABASE_URL || 'postgres://localhost:5432/mydb',
    };
  },
};
```

```typescript
// src/common/helpers/string.helper.ts
export class StringHelper {
  static toSlug(text: string): string {
    return text.toLowerCase().replace(/\s+/g, '-').replace(/[^\w-]/g, '');
  }

  static truncate(text: string, length: number): string {
    return text.length > length ? text.substring(0, length) + '...' : text;
  }
}
```

```typescript
// src/users/users.service.ts
import { Injectable } from '@nestjs/common';

@Injectable()
export class UsersService {
  private users = [{ id: 1, name: 'Alice' }, { id: 2, name: 'Bob' }];

  findAll() {
    return this.users;
  }

  findOne(id: number) {
    return this.users.find(user => user.id === id);
  }
}
```

```typescript
// src/users/users.module.ts
import { Module } from '@nestjs/common';
import { UsersService } from './users.service';
import { UsersController } from './users.controller';

@Module({
  controllers: [UsersController],
  providers: [UsersService],
})
export class UsersModule {}
```

```typescript
// src/users/users.controller.ts
import { Controller, Get, Param } from '@nestjs/common';
import { UsersService } from './users.service';

@Controller('users')
export class UsersController {
  constructor(private readonly usersService: UsersService) {}

  @Get()
  findAll() {
    return this.usersService.findAll();
  }

  @Get(':id')
  findOne(@Param('id') id: number) {
    return this.usersService.findOne(id);
  }
}
```

## Cara Integrasi & Pengujian

Setiap provider harus didaftarkan di array `providers` pada dekorator `@Module`. Setelah itu, cukup inject di constructor class yang membutuhkan.

**Test dengan curl:**
```bash
curl http://localhost:3000/users
# Response: [{"id":1,"name":"Alice"},{"id":2,"name":"Bob"}]

curl http://localhost:3000/users/1
# Response: {"id":1,"name":"Alice"}
```
