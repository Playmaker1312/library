# 81. Cara menggunakan optional dependency menggunakan decorator Optional

## Definisi & Target
Decorator `@Optional()` memberitahu NestJS bahwa suatu dependency bersifat opsional. Jika provider tidak terdaftar, NestJS akan menginjeksi `undefined` alih-alih melempar error. Berguna untuk fitur yang bisa diaktifkan/dinonaktifkan secara opsional.

## Komponen & Nest CLI Command
Tidak ada CLI command.
File: `src/analytics/analytics.service.ts`

## Kode Implementasi (Per File)

```typescript
// src/analytics/analytics.service.ts
import { Injectable, Inject, Optional } from '@nestjs/common';

export interface AnalyticsProvider {
  track(event: string, data: any): void;
}

@Injectable()
export class AnalyticsService {
  constructor(
    @Optional() @Inject('ANALYTICS_PROVIDER')
    private readonly analyticsProvider?: AnalyticsProvider,
  ) {
    if (!this.analyticsProvider) {
      console.log('Analytics provider not configured. Events will be logged only.');
    }
  }

  track(event: string, data: any = {}) {
    if (this.analyticsProvider) {
      this.analyticsProvider.track(event, data);
    } else {
      console.log(`[Analytics] ${event}`, data);
    }
  }
}
```

```typescript
// src/analytics/analytics.controller.ts
import { Controller, Post, Body } from '@nestjs/common';
import { AnalyticsService } from './analytics.service';

@Controller('analytics')
export class AnalyticsController {
  constructor(private readonly analyticsService: AnalyticsService) {}

  @Post('track')
  track(@Body() body: { event: string; data?: any }) {
    this.analyticsService.track(body.event, body.data);
    return { tracked: true };
  }
}
```

```typescript
// src/analytics/analytics.module.ts
import { Module } from '@nestjs/common';
import { AnalyticsController } from './analytics.controller';
import { AnalyticsService } from './analytics.service';

@Module({
  controllers: [AnalyticsController],
  providers: [AnalyticsService],
})
export class AnalyticsModule {}
```

## Cara Integrasi & Pengujian

Jika provider dengan token `ANALYTICS_PROVIDER` tidak ada, `analyticsProvider` akan bernilai `undefined`. Service tetap berfungsi dengan fallback console log.

**Test dengan curl:**
```bash
curl -X POST http://localhost:3000/analytics/track \
  -H "Content-Type: application/json" \
  -d '{"event":"page_view","data":{"url":"/home"}}'
# {"tracked":true}
# Console: [Analytics] page_view { url: '/home' }
```
