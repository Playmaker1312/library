# 74. Cara menginjeksi service ke dalam service lain

## Definisi & Target
Service bisa saling bergantung satu sama lain. NestJS memungkinkan injeksi service A ke service B melalui constructor, sama seperti injeksi ke controller. Ini menerapkan prinsip separation of concerns dan reusability.

## Komponen & Nest CLI Command
```
nest g service orders
nest g service notifications
```
File: `src/orders/orders.service.ts`, `src/notifications/notifications.service.ts`

## Kode Implementasi (Per File)

```typescript
// src/notifications/notifications.service.ts
import { Injectable } from '@nestjs/common';

@Injectable()
export class NotificationsService {
  sendEmail(to: string, subject: string, body: string) {
    console.log(`Email sent to ${to}: ${subject}`);
    return { success: true, to, subject };
  }

  sendSMS(phone: string, message: string) {
    console.log(`SMS sent to ${phone}: ${message}`);
    return { success: true, phone, message };
  }
}
```

```typescript
// src/orders/orders.service.ts
import { Injectable } from '@nestjs/common';
import { NotificationsService } from '../notifications/notifications.service';

@Injectable()
export class OrdersService {
  constructor(private readonly notificationsService: NotificationsService) {}

  private orders = [];

  create(order: { item: string; qty: number }) {
    const newOrder = { id: this.orders.length + 1, ...order };
    this.orders.push(newOrder);

    this.notificationsService.sendEmail(
      'admin@shop.com',
      'New Order',
      `Order ${newOrder.id} created`,
    );

    return newOrder;
  }
}
```

```typescript
// src/orders/orders.module.ts
import { Module } from '@nestjs/common';
import { OrdersService } from './orders.service';
import { OrdersController } from './orders.controller';
import { NotificationsService } from '../notifications/notifications.service';

@Module({
  controllers: [OrdersController],
  providers: [OrdersService, NotificationsService],
})
export class OrdersModule {}
```

## Cara Integrasi & Pengujian

Kedua service harus didaftarkan di `providers` module yang sama. Jika `NotificationsService` berada di module terpisah, export dan import module tersebut.

**Test dengan curl:**
```bash
curl -X POST http://localhost:3000/orders \
  -H "Content-Type: application/json" \
  -d '{"item":"Keyboard","qty":1}'
# {"id":1,"item":"Keyboard","qty":1}
# Console: Email sent to admin@shop.com: New Order
```
