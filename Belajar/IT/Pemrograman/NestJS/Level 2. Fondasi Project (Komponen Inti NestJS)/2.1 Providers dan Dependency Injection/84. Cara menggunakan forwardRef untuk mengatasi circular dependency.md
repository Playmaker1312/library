# 84. Cara menggunakan forwardRef untuk mengatasi circular dependency

## Definisi & Target
Circular dependency terjadi ketika Module A meng-import Module B dan Module B meng-import Module A. NestJS menyediakan `forwardRef()` untuk menunda resolusi dependency. Gunakan di kedua sisi—baik di `@Module` imports maupun di constructor `@Inject()`.

## Komponen & Nest CLI Command
```
nest g module cats
nest g module dogs
nest g service cats
nest g service dogs
```
File: `src/cats/`, `src/dogs/`

## Kode Implementasi (Per File)

```typescript
// src/cats/cats.service.ts
import { Injectable, Inject, forwardRef } from '@nestjs/common';
import { DogsService } from '../dogs/dogs.service';

@Injectable()
export class CatsService {
  constructor(
    @Inject(forwardRef(() => DogsService))
    private readonly dogsService: DogsService,
  ) {}

  getCatFact(): string {
    return 'Cats have 32 muscles in each ear.';
  }

  getCombined(): string {
    return `${this.getCatFact()} And ${this.dogsService.getDogFact()}`;
  }
}
```

```typescript
// src/dogs/dogs.service.ts
import { Injectable, Inject, forwardRef } from '@nestjs/common';
import { CatsService } from '../cats/cats.service';

@Injectable()
export class DogsService {
  constructor(
    @Inject(forwardRef(() => CatsService))
    private readonly catsService: CatsService,
  ) {}

  getDogFact(): string {
    return 'Dogs have about 1,700 taste buds.';
  }

  getCombined(): string {
    return `${this.getDogFact()} Also ${this.catsService.getCatFact()}`;
  }
}
```

```typescript
// src/cats/cats.module.ts
import { Module, forwardRef } from '@nestjs/common';
import { CatsService } from './cats.service';
import { CatsController } from './cats.controller';
import { DogsModule } from '../dogs/dogs.module';

@Module({
  imports: [forwardRef(() => DogsModule)],
  controllers: [CatsController],
  providers: [CatsService],
  exports: [CatsService],
})
export class CatsModule {}
```

```typescript
// src/dogs/dogs.module.ts
import { Module, forwardRef } from '@nestjs/common';
import { DogsService } from './dogs.service';
import { DogsController } from './dogs.controller';
import { CatsModule } from '../cats/cats.module';

@Module({
  imports: [forwardRef(() => CatsModule)],
  controllers: [DogsController],
  providers: [DogsService],
  exports: [DogsService],
})
export class DogsModule {}
```

```typescript
// src/cats/cats.controller.ts
import { Controller, Get } from '@nestjs/common';
import { CatsService } from './cats.service';

@Controller('cats')
export class CatsController {
  constructor(private readonly catsService: CatsService) {}

  @Get()
  getFact() {
    return { fact: this.catsService.getCatFact() };
  }
}
```

```typescript
// src/dogs/dogs.controller.ts
import { Controller, Get } from '@nestjs/common';
import { DogsService } from './dogs.service';

@Controller('dogs')
export class DogsController {
  constructor(private readonly dogsService: DogsService) {}

  @Get()
  getFact() {
    return { fact: this.dogsService.getDogFact() };
  }
}
```

## Cara Integrasi & Pengujian

Gunakan `forwardRef()` di imports module dan di `@Inject()` constructor. Tanpa `forwardRef`, NestJS akan melempar error circular dependency.

**Test dengan curl:**
```bash
curl http://localhost:3000/cats
# {"fact":"Cats have 32 muscles in each ear."}
```
