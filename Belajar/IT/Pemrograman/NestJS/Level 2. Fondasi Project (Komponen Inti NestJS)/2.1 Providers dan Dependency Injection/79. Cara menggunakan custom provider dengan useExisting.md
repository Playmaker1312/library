# 79. Cara menggunakan custom provider dengan useExisting

## Definisi & Target
`useExisting` membuat alias untuk provider yang sudah ada. Ketika suatu token di-inject, NestJS akan mengembalikan instance yang sama dari provider asli. Berguna untuk memberikan banyak nama ke instance yang sama atau backward compatibility.

## Komponen & Nest CLI Command
Tidak ada CLI command—modifikasi langsung di module.
File: `src/logger/logger.module.ts`

## Kode Implementasi (Per File)

```typescript
// src/logger/logger.service.ts
import { Injectable } from '@nestjs/common';

@Injectable()
export class LoggerService {
  log(message: string) {
    console.log(`[LOG] ${message}`);
  }

  error(message: string) {
    console.error(`[ERROR] ${message}`);
  }

  warn(message: string) {
    console.warn(`[WARN] ${message}`);
  }
}
```

```typescript
// src/logger/logger.module.ts
import { Module } from '@nestjs/common';
import { LoggerService } from './logger.service';

@Module({
  providers: [
    LoggerService,
    {
      provide: 'ILogger',
      useExisting: LoggerService,
    },
    {
      provide: 'AppLogger',
      useExisting: LoggerService,
    },
  ],
  exports: [LoggerService, 'ILogger', 'AppLogger'],
})
export class LoggerModule {}
```

```typescript
// src/logger/logger.controller.ts
import { Controller, Get, Inject } from '@nestjs/common';
import { LoggerService } from './logger.service';

@Controller('logger')
export class LoggerController {
  constructor(
    private readonly loggerService: LoggerService,
    @Inject('ILogger') private readonly iLogger: LoggerService,
    @Inject('AppLogger') private readonly appLogger: LoggerService,
  ) {}

  @Get()
  testLogging() {
    this.loggerService.log('Original service');
    this.iLogger.log('Via ILogger alias');
    this.appLogger.log('Via AppLogger alias');

    const areSame = this.loggerService === this.iLogger && this.iLogger === this.appLogger;
    return { sameInstance: areSame };
  }
}
```

## Cara Integrasi & Pengujian

`useExisting` tidak membuat instance baru—semua token merujuk ke instance singleton yang sama.

**Test dengan curl:**
```bash
curl http://localhost:3000/logger
# {"sameInstance":true}
# Console:
# [LOG] Original service
# [LOG] Via ILogger alias
# [LOG] Via AppLogger alias
```
