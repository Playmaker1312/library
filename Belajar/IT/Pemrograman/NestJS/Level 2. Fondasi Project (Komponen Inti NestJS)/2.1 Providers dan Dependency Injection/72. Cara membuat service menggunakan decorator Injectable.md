# 72. Cara membuat service menggunakan decorator Injectable

## Definisi & Target
Decorator `@Injectable()` menandai sebuah class sebagai provider yang dapat dikelola oleh NestJS DI container. Dengan decorator ini, NestJS tahu bahwa class tersebut bisa menerima dependency melalui constructor dan bisa di-inject ke class lain.

## Komponen & Nest CLI Command
```
nest g service nama-service
nest g s nama-service        # shorthand
```
File yang dibuat: `src/nama-module/nama-service.service.ts` dan `src/nama-module/nama-service.service.spec.ts`

## Kode Implementasi (Per File)

```typescript
// src/products/products.service.ts
import { Injectable } from '@nestjs/common';

@Injectable()
export class ProductsService {
  private products = [
    { id: 1, name: 'Laptop', price: 15000000 },
    { id: 2, name: 'Mouse', price: 250000 },
  ];

  findAll() {
    return this.products;
  }

  findOne(id: number) {
    return this.products.find(p => p.id === id);
  }

  create(product: { name: string; price: number }) {
    const newProduct = { id: this.products.length + 1, ...product };
    this.products.push(newProduct);
    return newProduct;
  }
}
```

```typescript
// src/products/products.module.ts
import { Module } from '@nestjs/common';
import { ProductsService } from './products.service';
import { ProductsController } from './products.controller';

@Module({
  controllers: [ProductsController],
  providers: [ProductsService],
})
export class ProductsModule {}
```

```typescript
// src/products/products.controller.ts
import { Controller, Get, Post, Body, Param } from '@nestjs/common';
import { ProductsService } from './products.service';

@Controller('products')
export class ProductsController {
  constructor(private readonly productsService: ProductsService) {}

  @Get()
  findAll() {
    return this.productsService.findAll();
  }

  @Get(':id')
  findOne(@Param('id') id: number) {
    return this.productsService.findOne(id);
  }

  @Post()
  create(@Body() body: { name: string; price: number }) {
    return this.productsService.create(body);
  }
}
```

## Cara Integrasi & Pengujian

Cukup tambahkan `ProductsService` di array `providers` module. NestJS akan secara otomatis membuat singleton instance-nya.

**Test dengan curl:**
```bash
curl http://localhost:3000/products
# [{"id":1,"name":"Laptop","price":15000000},{"id":2,"name":"Mouse","price":250000}]

curl -X POST http://localhost:3000/products \
  -H "Content-Type: application/json" \
  -d '{"name":"Keyboard","price":500000}'
# {"id":3,"name":"Keyboard","price":500000}
```
