# 75. Memahami scope provider yaitu DEFAULT, REQUEST, dan TRANSIENT

## Definisi & Target
Scope menentukan siklus hidup instance provider. DEFAULT (singleton): satu instance untuk seluruh aplikasi. REQUEST: instance baru per request HTTP. TRANSIENT: instance baru setiap kali di-inject. Pilih scope sesuai kebutuhan—DEFAULT untuk stateless service, REQUEST untuk data per-user seperti request context.

## Komponen & Nest CLI Command
```
nest g service sessions
```
Tidak ada CLI khusus untuk scope—tambahkan properti `scope` pada decorator `@Injectable()`.

## Kode Implementasi (Per File)

```typescript
// src/sessions/session.service.ts
import { Injectable, Scope } from '@nestjs/common';

@Injectable({ scope: Scope.REQUEST })
export class SessionService {
  private readonly requestId: string;

  constructor() {
    this.requestId = `req-${Date.now()}-${Math.random().toString(36).substring(2, 8)}`;
    console.log(`SessionService created: ${this.requestId}`);
  }

  getRequestId() {
    return this.requestId;
  }
}
```

```typescript
// src/sessions/transient-logger.service.ts
import { Injectable, Scope } from '@nestjs/common';

@Injectable({ scope: Scope.TRANSIENT })
export class TransientLoggerService {
  private readonly id: string;

  constructor() {
    this.id = Math.random().toString(36).substring(2, 8);
    console.log(`TransientLogger created: ${this.id}`);
  }

  log(message: string) {
    console.log(`[Logger-${this.id}] ${message}`);
  }
}
```

```typescript
// src/sessions/sessions.controller.ts
import { Controller, Get } from '@nestjs/common';
import { SessionService } from './session.service';

@Controller('sessions')
export class SessionsController {
  constructor(
    private readonly sessionService: SessionService,
  ) {}

  @Get()
  getSession() {
    return { requestId: this.sessionService.getRequestId() };
  }
}
```

```typescript
// src/sessions/sessions.module.ts
import { Module } from '@nestjs/common';
import { SessionsController } from './sessions.controller';
import { SessionService } from './session.service';

@Module({
  controllers: [SessionsController],
  providers: [SessionService],
})
export class SessionsModule {}
```

## Cara Integrasi & Pengujian

Scope REQUEST membuat instance baru untuk setiap request HTTP. Ketika di-refresh, `requestId` akan berbeda.

**Test dengan curl:**
```bash
curl http://localhost:3000/sessions
# {"requestId":"req-1718000000-a1b2c3"}
curl http://localhost:3000/sessions
# {"requestId":"req-1718000001-d4e5f6"}  <- Berbeda!
```
