# 80. Cara menggunakan token injection menggunakan decorator Inject

## Definisi & Target
Decorator `@Inject()` digunakan ketika dependency tidak bisa di-resolve secara otomatis berdasarkan tipe (misalnya custom provider dengan token string atau symbol). `@Inject('TOKEN')` memberitahu NestJS provider mana yang harus disuntikkan.

## Komponen & Nest CLI Command
Tidak ada CLI command.
File: `src/config/config.module.ts`, `src/config/config.service.ts`

## Kode Implementasi (Per File)

```typescript
// src/config/config.constants.ts
export const CONFIG_OPTIONS = 'CONFIG_OPTIONS';
export const DB_CONFIG = 'DB_CONFIG';
```

```typescript
// src/config/config.module.ts
import { Module } from '@nestjs/common';
import { CONFIG_OPTIONS, DB_CONFIG } from './config.constants';

@Module({
  providers: [
    {
      provide: CONFIG_OPTIONS,
      useValue: {
        environment: process.env.NODE_ENV || 'development',
        debug: false,
      },
    },
    {
      provide: DB_CONFIG,
      useFactory: (options: any) => {
        return {
          url: `mongodb://${options.host || 'localhost'}:27017/mydb`,
        };
      },
      inject: [CONFIG_OPTIONS],
    },
    {
      provide: 'REDIS_CLIENT',
      useValue: {
        host: 'localhost',
        port: 6379,
        ping: () => 'PONG',
      },
    },
  ],
  exports: [CONFIG_OPTIONS, DB_CONFIG, 'REDIS_CLIENT'],
})
export class ConfigModule {}
```

```typescript
// src/config/config.service.ts
import { Inject, Injectable } from '@nestjs/common';
import { CONFIG_OPTIONS, DB_CONFIG } from './config.constants';

@Injectable()
export class ConfigService {
  constructor(
    @Inject(CONFIG_OPTIONS) private readonly options: any,
    @Inject(DB_CONFIG) private readonly dbConfig: any,
    @Inject('REDIS_CLIENT') private readonly redis: any,
  ) {}

  getEnvironment() {
    return this.options.environment;
  }

  getDbUrl() {
    return this.dbConfig.url;
  }

  pingRedis() {
    return this.redis.ping();
  }
}
```

```typescript
// src/config/config.controller.ts
import { Controller, Get } from '@nestjs/common';
import { ConfigService } from './config.service';

@Controller('config')
export class ConfigController {
  constructor(private readonly configService: ConfigService) {}

  @Get()
  getConfig() {
    return {
      env: this.configService.getEnvironment(),
      dbUrl: this.configService.getDbUrl(),
      redis: this.configService.pingRedis(),
    };
  }
}
```

## Cara Integrasi & Pengujian

Gunakan `@Inject()` dengan token yang sama persis seperti yang didaftarkan di `providers`. Token bisa berupa string, symbol, atau class reference.

**Test dengan curl:**
```bash
curl http://localhost:3000/config
# {"env":"development","dbUrl":"mongodb://localhost:27017/mydb","redis":"PONG"}
```
