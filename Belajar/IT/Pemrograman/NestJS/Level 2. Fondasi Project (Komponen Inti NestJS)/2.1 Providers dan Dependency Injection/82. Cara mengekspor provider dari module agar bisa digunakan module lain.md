# 82. Cara mengekspor provider dari module agar bisa digunakan module lain

## Definisi & Target
Provider bersifat private secara default dalam satu module. Untuk mengizinkan module lain menggunakan service, kita harus mendaftarkannya di array `exports` pada dekorator `@Module`. Module pengguna kemudian meng-import module yang mengekspor service tersebut.

## Komponen & Nest CLI Command
```
nest g module database
nest g service database
```
File: `src/database/database.module.ts`, `src/database/database.service.ts`

## Kode Implementasi (Per File)

```typescript
// src/database/database.service.ts
import { Injectable } from '@nestjs/common';

@Injectable()
export class DatabaseService {
  private connected = false;

  connect() {
    this.connected = true;
    console.log('Database connected');
    return { status: 'connected' };
  }

  disconnect() {
    this.connected = false;
    console.log('Database disconnected');
  }

  isConnected() {
    return this.connected;
  }
}
```

```typescript
// src/database/database.module.ts
import { Module } from '@nestjs/common';
import { DatabaseService } from './database.service';

@Module({
  providers: [DatabaseService],
  exports: [DatabaseService],
})
export class DatabaseModule {}
```

```typescript
// src/users/users.module.ts
import { Module } from '@nestjs/common';
import { DatabaseModule } from '../database/database.module';
import { UsersService } from './users.service';
import { UsersController } from './users.controller';

@Module({
  imports: [DatabaseModule],
  controllers: [UsersController],
  providers: [UsersService],
})
export class UsersModule {}
```

```typescript
// src/users/users.service.ts
import { Injectable } from '@nestjs/common';
import { DatabaseService } from '../database/database.service';

@Injectable()
export class UsersService {
  constructor(private readonly databaseService: DatabaseService) {
    this.databaseService.connect();
  }

  getStatus() {
    return { dbConnected: this.databaseService.isConnected() };
  }
}
```

```typescript
// src/users/users.controller.ts
import { Controller, Get } from '@nestjs/common';
import { UsersService } from './users.service';

@Controller('users')
export class UsersController {
  constructor(private readonly usersService: UsersService) {}

  @Get('status')
  getStatus() {
    return this.usersService.getStatus();
  }
}
```

## Cara Integrasi & Pengujian

Module A harus meng-import Module B. Module B harus mengekspor provider yang ingin digunakan bersama.

**Test dengan curl:**
```bash
curl http://localhost:3000/users/status
# {"dbConnected":true}
# Console: Database connected
```
