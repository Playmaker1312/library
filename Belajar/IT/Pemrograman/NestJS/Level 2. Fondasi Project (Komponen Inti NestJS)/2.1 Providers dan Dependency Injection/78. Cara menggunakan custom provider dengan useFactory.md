# 78. Cara menggunakan custom provider dengan useFactory

## Definisi & Target
`useFactory` membuat provider melalui fungsi factory yang bisa menerima dependency lain dan logic inisialisasi yang kompleks. Cocok untuk koneksi database, konfigurasi dinamis, atau object yang membutuhkan async initialization.

## Komponen & Nest CLI Command
```
npm install node-fetch    # contoh dependency
```
Tidak ada CLI command—tulis langsung di module.
File: `src/cache/cache.module.ts`

## Kode Implementasi (Per File)

```typescript
// src/cache/cache-manager.ts
export interface CacheManager {
  get(key: string): Promise<any>;
  set(key: string, value: any, ttl?: number): Promise<void>;
}

export class InMemoryCache implements CacheManager {
  private store = new Map<string, { value: any; expiry: number }>();

  async get(key: string) {
    const item = this.store.get(key);
    if (!item) return null;
    if (Date.now() > item.expiry) {
      this.store.delete(key);
      return null;
    }
    return item.value;
  }

  async set(key: string, value: any, ttl = 300) {
    this.store.set(key, { value, expiry: Date.now() + ttl * 1000 });
  }
}
```

```typescript
// src/cache/cache.module.ts
import { Module, Global } from '@nestjs/common';
import { CacheManager, InMemoryCache } from './cache-manager';

@Global()
@Module({
  providers: [
    {
      provide: 'CACHE_MANAGER',
      useFactory: async (options?: { ttl: number }) => {
        const cache = new InMemoryCache();
        const defaultTtl = options?.ttl || 300;
        console.log(`Cache initialized with TTL: ${defaultTtl}s`);
        return cache;
      },
      inject: [],
    },
  ],
  exports: ['CACHE_MANAGER'],
})
export class CacheModule {}
```

```typescript
// src/cache/cache.service.ts
import { Inject, Injectable } from '@nestjs/common';
import { CacheManager } from './cache-manager';

@Injectable()
export class CacheService {
  constructor(
    @Inject('CACHE_MANAGER') private readonly cache: CacheManager,
  ) {}

  async get(key: string) {
    return this.cache.get(key);
  }

  async set(key: string, value: any, ttl?: number) {
    await this.cache.set(key, value, ttl);
  }
}
```

```typescript
// src/cache/cache.controller.ts
import { Controller, Get, Query } from '@nestjs/common';
import { CacheService } from './cache.service';

@Controller('cache')
export class CacheController {
  constructor(private readonly cacheService: CacheService) {}

  @Get()
  async getCache(@Query('key') key: string) {
    const value = await this.cacheService.get(key);
    return { key, value };
  }
}
```

## Cara Integrasi & Pengujian

`useFactory` bisa menerima parameter dari `inject` array. Factory akan dipanggil sekali saat aplikasi start (singleton).

**Test dengan curl:**
```bash
curl "http://localhost:3000/cache?key=test"
# {"key":"test","value":null}
```
