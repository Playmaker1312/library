# 77. Cara menggunakan custom provider dengan useClass

## Definisi & Target
`useClass` memungkinkan kita mengganti implementasi class provider secara dinamis. NestJS akan menginisiasi class yang ditentukan di `useClass` meskipun token-nya menggunakan class berbeda. Berguna untuk strategi, environment-based implementation, atau A/B testing.

## Komponen & Nest CLI Command
Tidak ada CLI command—modifikasi langsung pada `providers` di module.
File: `src/payment/payment.module.ts`, `src/payment/payment.service.ts`

## Kode Implementasi (Per File)

```typescript
// src/payment/interfaces/payment-provider.interface.ts
export interface PaymentProvider {
  processPayment(amount: number, currency: string): Promise<any>;
}
```

```typescript
// src/payment/services/stripe-payment.service.ts
import { Injectable } from '@nestjs/common';
import { PaymentProvider } from '../interfaces/payment-provider.interface';

@Injectable()
export class StripePaymentService implements PaymentProvider {
  async processPayment(amount: number, currency: string) {
    return {
      provider: 'stripe',
      amount,
      currency,
      status: 'success',
      transactionId: `str_${Date.now()}`,
    };
  }
}
```

```typescript
// src/payment/payment.module.ts
import { Module } from '@nestjs/common';
import { PaymentController } from './payment.controller';
import { StripePaymentService } from './services/stripe-payment.service';
import { PaymentProvider } from './interfaces/payment-provider.interface';

const isProduction = process.env.NODE_ENV === 'production';

@Module({
  controllers: [PaymentController],
  providers: [
    {
      provide: 'PAYMENT_PROVIDER',
      useClass: isProduction ? StripePaymentService : StripePaymentService,
    },
  ],
})
export class PaymentModule {}
```

```typescript
// src/payment/payment.controller.ts
import { Controller, Post, Body, Inject } from '@nestjs/common';
import { PaymentProvider } from './interfaces/payment-provider.interface';

@Controller('payment')
export class PaymentController {
  constructor(
    @Inject('PAYMENT_PROVIDER') private readonly paymentProvider: PaymentProvider,
  ) {}

  @Post()
  async pay(@Body() body: { amount: number; currency: string }) {
    return this.paymentProvider.processPayment(body.amount, body.currency);
  }
}
```

## Cara Integrasi & Pengujian

`useClass` menentukan class mana yang akan diinisiasi oleh NestJS. Ganti class sesuai environment tanpa mengubah kode controller.

**Test dengan curl:**
```bash
curl -X POST http://localhost:3000/payment \
  -H "Content-Type: application/json" \
  -d '{"amount":50000,"currency":"IDR"}'
# {"provider":"stripe","amount":50000,"currency":"IDR","status":"success","transactionId":"str_1718000000"}
```
