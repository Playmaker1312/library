# 76. Cara menggunakan custom provider dengan useValue

## Definisi & Target
`useValue` memungkinkan kita mendaftarkan nilai atau object langsung sebagai provider, tanpa perlu class. Cocok untuk menyuntikkan konfigurasi, constant, atau mock object untuk testing tanpa membuat class terpisah.

## Komponen & Nest CLI Command
Tidak ada CLI command—modifikasi langsung file module.
File: `src/app.module.ts` atau `src/nama-module/nama-module.module.ts`

## Kode Implementasi (Per File)

```typescript
// src/config/app.config.ts
export interface AppConfig {
  appName: string;
  version: string;
  port: number;
}

export const APP_CONFIG: AppConfig = {
  appName: 'NestJS E-Commerce',
  version: '1.0.0',
  port: 3000,
};
```

```typescript
// src/config/database.config.ts
export const DATABASE_CONFIG = {
  provide: 'DATABASE_CONFIG',
  useValue: {
    host: process.env.DB_HOST || 'localhost',
    port: parseInt(process.env.DB_PORT, 10) || 5432,
    username: process.env.DB_USER || 'postgres',
    password: process.env.DB_PASS || 'secret',
    database: process.env.DB_NAME || 'nestjs_db',
  },
};
```

```typescript
// src/app.module.ts
import { Module } from '@nestjs/common';
import { APP_CONFIG } from './config/app.config';
import { DATABASE_CONFIG } from './config/database.config';
import { AppController } from './app.controller';
import { AppService } from './app.service';

@Module({
  imports: [],
  controllers: [AppController],
  providers: [
    AppService,
    APP_CONFIG,
    DATABASE_CONFIG,
  ],
})
export class AppModule {}
```

```typescript
// src/app.service.ts
import { Inject, Injectable } from '@nestjs/common';
import { AppConfig } from './config/app.config';

@Injectable()
export class AppService {
  constructor(
    @Inject('APP_CONFIG') private readonly appConfig: AppConfig,
    @Inject('DATABASE_CONFIG') private readonly dbConfig: any,
  ) {}

  getConfig() {
    return {
      app: this.appConfig,
      database: this.dbConfig,
    };
  }
}
```

```typescript
// src/app.controller.ts
import { Controller, Get } from '@nestjs/common';
import { AppService } from './app.service';

@Controller()
export class AppController {
  constructor(private readonly appService: AppService) {}

  @Get('config')
  getConfig() {
    return this.appService.getConfig();
  }
}
```

## Cara Integrasi & Pengujian

Gunakan decorator `@Inject('TOKEN_NAME')` untuk mengakses provider yang didaftarkan dengan `useValue`. Token bisa berupa string atau symbol.

**Test dengan curl:**
```bash
curl http://localhost:3000/config
# {"app":{"appName":"NestJS E-Commerce","version":"1.0.0","port":3000},"database":{"host":"localhost","port":5432,"username":"postgres","password":"secret","database":"nestjs_db"}}
```
