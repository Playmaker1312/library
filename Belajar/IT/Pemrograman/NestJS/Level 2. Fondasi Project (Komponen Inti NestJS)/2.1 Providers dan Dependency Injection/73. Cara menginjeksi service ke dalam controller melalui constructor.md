# 73. Cara menginjeksi service ke dalam controller melalui constructor

## Definisi & Target
Dependency injection di controller dilakukan melalui parameter constructor. NestJS secara otomatis menyediakan instance service yang sudah terdaftar di module. Ini memisahkan logika bisnis (service) dari handler route (controller).

## Komponen & Nest CLI Command
```
nest g service orders
nest g controller orders
```
File: `src/orders/orders.controller.ts`, `src/orders/orders.service.ts`

## Kode Implementasi (Per File)

```typescript
// src/orders/orders.service.ts
import { Injectable } from '@nestjs/common';

@Injectable()
export class OrdersService {
  private orders = [
    { id: 1, item: 'Laptop', qty: 1 },
    { id: 2, item: 'Mouse', qty: 2 },
  ];

  findAll() {
    return this.orders;
  }

  getTotal() {
    return this.orders.reduce((sum, o) => sum + o.qty, 0);
  }
}
```

```typescript
// src/orders/orders.controller.ts
import { Controller, Get } from '@nestjs/common';
import { OrdersService } from './orders.service';

@Controller('orders')
export class OrdersController {
  constructor(private readonly ordersService: OrdersService) {}

  @Get()
  getAllOrders() {
    return this.ordersService.findAll();
  }

  @Get('total')
  getTotalQty() {
    return { total: this.ordersService.getTotal() };
  }
}
```

```typescript
// src/orders/orders.module.ts
import { Module } from '@nestjs/common';
import { OrdersController } from './orders.controller';
import { OrdersService } from './orders.service';

@Module({
  controllers: [OrdersController],
  providers: [OrdersService],
})
export class OrdersModule {}
```

## Cara Integrasi & Pengujian

NestJS membaca tipe parameter constructor secara otomatis dan mencari provider yang cocok di module. Pastikan `OrdersService` ada di array `providers`.

**Test dengan curl:**
```bash
curl http://localhost:3000/orders
# [{"id":1,"item":"Laptop","qty":1},{"id":2,"item":"Mouse","qty":2}]

curl http://localhost:3000/orders/total
# {"total":3}
```
