# 87. Cara membuat middleware class yang mengimplementasikan NestMiddleware

## Definisi & Target
Membuat middleware class dengan mengimplementasikan interface `NestMiddleware` dari `@nestjs/common`. Class harus memiliki method `use` dengan tiga parameter: `Request`, `Response`, dan `NextFunction`. NestJS akan mengelola lifecycle middleware melalui DI container.

## Komponen & Nest CLI Command
```
nest g middleware logger --no-spec
```
Atau buat manual: `src/common/middleware/logger.middleware.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/middleware/logger.middleware.ts
import { Injectable, NestMiddleware } from '@nestjs/common';
import { Request, Response, NextFunction } from 'express';

@Injectable()
export class LoggerMiddleware implements NestMiddleware {
  use(req: Request, res: Response, next: NextFunction) {
    const start = Date.now();

    res.on('finish', () => {
      const duration = Date.now() - start;
      console.log(`${req.method} ${req.originalUrl} ${res.statusCode} ${duration}ms`);
    });

    next();
  }
}
```

```typescript
// src/common/common.module.ts
import { Module, NestModule, MiddlewareConsumer } from '@nestjs/common';
import { LoggerMiddleware } from './middleware/logger.middleware';

@Module({})
export class CommonModule implements NestModule {
  configure(consumer: MiddlewareConsumer) {
    consumer
      .apply(LoggerMiddleware)
      .forRoutes('*');
  }
}
```

## Cara Integrasi & Pengujian

Implement `NestModule` pada module class, lalu definisikan method `configure`. Gunakan `MiddlewareConsumer` untuk mendaftarkan middleware.

curl http://localhost:3000/test
