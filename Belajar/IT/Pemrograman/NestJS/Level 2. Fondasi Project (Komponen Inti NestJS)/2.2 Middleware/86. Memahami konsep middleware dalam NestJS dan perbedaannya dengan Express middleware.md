# 86. Memahami konsep middleware dalam NestJS dan perbedaannya dengan Express middleware

## Definisi & Target
Middleware adalah fungsi yang dijalankan sebelum route handler. Di NestJS, middleware mirip Express middleware tetapi dibungkus dalam class dengan implementasi `NestMiddleware`. Middleware bisa memodifikasi request/response, menghentikan pipeline, atau melanjutkan ke middleware berikutnya. Eksekusi middleware terjadi SEBELUM guard, interceptor, dan pipe.

## Komponen & Nest CLI Command
```
nest g middleware nama-middleware --no-spec
```
File: `src/common/middleware/nama-middleware.middleware.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/middleware/express-vs-nest.ts
import { Injectable, NestMiddleware } from '@nestjs/common';
import { Request, Response, NextFunction } from 'express';

@Injectable()
export class ExpressVsNestMiddleware implements NestMiddleware {
  use(req: Request, res: Response, next: NextFunction) {
    console.log('NestJS middleware running before Express middleware layer');
    console.log(`Method: ${req.method}, Path: ${req.originalUrl}`);
    next();
  }
}
```

```typescript
// src/app.module.ts (partial)
import { Module, NestModule, MiddlewareConsumer } from '@nestjs/common';
import { ExpressVsNestMiddleware } from './common/middleware/express-vs-nest.middleware';

@Module({})
export class AppModule implements NestModule {
  configure(consumer: MiddlewareConsumer) {
    consumer
      .apply(ExpressVsNestMiddleware)
      .forRoutes('*');
  }
}
```

## Cara Integrasi & Pengujian

Class middleware mengimplementasikan `NestMiddleware` dengan method `use(req, res, next)`. Bedanya dengan Express: Nest middleware bisa memanfaatkan DI, bisa dibatasi ke route tertentu, dan terintegrasi dengan module system.

**Test dengan curl:**
```bash
curl http://localhost:3000/any-route
# Console: NestJS middleware running before Express middleware layer
# Console: Method: GET, Path: /any-route
```
