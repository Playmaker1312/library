# 86. Memahami konsep middleware dalam NestJS dan perbedaannya dengan Express middleware

## Definisi & Target
Middleware dalam NestJS adalah fungsi yang memiliki akses ke objek request (req), response (res), dan fungsi next() dalam siklus request-response aplikasi. Middleware dapat mengeksekusi kode, memodifikasi request/response objects, mengakhiri siklus request-response, atau memanggil middleware berikutnya dalam stack. NestJS middleware sepenuhnya kompatibel dengan Express middleware karena NestJS dibangun di atas Express (secara default). Perbedaan utamanya: NestJS middleware menggunakan class-based approach dengan decorator `@Injectable()` dan mengimplementasikan interface `NestMiddleware`, sedangkan Express middleware menggunakan fungsi biasa. NestJS juga menyediakan `MiddlewareConsumer` untuk registrasi yang lebih terstruktur dan type-safe.

## Prasyarat
- Memahami dasar NestJS: Module, Controller, Provider
- Memahami siklus request-response HTTP
- Node.js dan npm terinstall
- NestJS CLI terinstall (`npm i -g @nestjs/cli`)

## Langkah-langkah Implementasi (Step-by-Step)
1. **Membuat Middleware Class**: Buat class yang mengimplementasikan `NestMiddleware` dengan method `use(req, res, next)`
2. **Registrasi di Module**: Implementasikan `NestModule` dan gunakan `MiddlewareConsumer` di method `configure()`
3. **Target Route**: Gunakan `forRoutes()` untuk menerapkan ke route tertentu
4. **Global Middleware**: Gunakan `app.use()` di `main.ts` untuk middleware global

## Kode Implementasi (Per File)

### logger.middleware.ts
```typescript
import { Injectable, NestMiddleware } from '@nestjs/common';
import { Request, Response, NextFunction } from 'express';

@Injectable()
export class LoggerMiddleware implements NestMiddleware {
  use(req: Request, res: Response, next: NextFunction) {
    console.log(`[${new Date().toISOString()}] ${req.method} ${req.url}`);
    next();
  }
}
```

### app.module.ts
```typescript
import { Module, NestModule, MiddlewareConsumer } from '@nestjs/common';
import { LoggerMiddleware } from './logger.middleware';
import { CatsController } from './cats/cats.controller';

@Module({
  imports: [],
  controllers: [CatsController],
  providers: [],
})
export class AppModule implements NestModule {
  configure(consumer: MiddlewareConsumer) {
    consumer
      .apply(LoggerMiddleware)
      .forRoutes('cats');
  }
}
```

### main.ts (Global Middleware)
```typescript
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { LoggerMiddleware } from './logger.middleware';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  
  // Global middleware - applies to all routes
  app.use(LoggerMiddleware);
  
  await app.listen(3000);
}
bootstrap();
```

## Konfigurasi & Integrasi
- **MiddlewareConsumer**: Interface untuk mendaftarkan middleware di module
- **forRoutes()**: Menargetkan controller, route path, atau objek `{ path, method }`
- **exclude()**: Mengecualikan route tertentu dari middleware
- **app.use()**: Menerapkan middleware secara global di level aplikasi

## Troubleshooting & Common Issues
1. **Middleware tidak dieksekusi**: Pastikan module mengimplementasikan `NestModule` dan method `configure()` dipanggil dengan benar
2. **TypeError: Cannot read property 'apply' of undefined**: Pastikan import `MiddlewareConsumer` dari `@nestjs/common`
3. **Middleware global tidak bekerja**: Periksa urutan `app.use()` sebelum `app.listen()` di main.ts

## Best Practices
- Gunakan class-based middleware untuk logic kompleks yang memerlukan dependency injection
- Gunakan functional middleware untuk logic sederhana
- Urutan middleware matters: global middleware dijalankan sebelum route-specific
- Hindari blocking operations di middleware (gunakan async/await dengan hati-hati)
- Pisahkan middleware per concern (logging, auth, validation)
