# 88. Cara mendefinisikan logika dalam metode use pada middleware

## Definisi & Target
Method `use(req, res, next)` adalah entry point middleware. Di sinilah logika ditempatkan—mulai dari logging, modifikasi request, validasi, hingga blocking request sebelum mencapai route handler. Panggil `next()` untuk melanjutkan ke middleware berikutnya atau route handler.

## Komponen & Nest CLI Command
```
nest g middleware auth --no-spec
```
File: `src/common/middleware/auth.middleware.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/middleware/auth.middleware.ts
import { Injectable, NestMiddleware, UnauthorizedException } from '@nestjs/common';
import { Request, Response, NextFunction } from 'express';

@Injectable()
export class AuthMiddleware implements NestMiddleware {
  use(req: Request, res: Response, next: NextFunction) {
    const token = req.headers['authorization'];

    if (!token) {
      throw new UnauthorizedException('Missing authorization header');
    }

    const [type, credentials] = token.split(' ');

    if (type !== 'Bearer' || !credentials) {
      throw new UnauthorizedException('Invalid token format');
    }

    const decoded = Buffer.from(credentials, 'base64').toString('utf-8');
    (req as any).user = { username: decoded };

    next();
  }
}
```

```typescript
// src/common/middleware/block.middleware.ts
import { Injectable, NestMiddleware, ForbiddenException } from '@nestjs/common';
import { Request, Response, NextFunction } from 'express';

@Injectable()
export class BlockMiddleware implements NestMiddleware {
  private blockedIps = ['192.168.1.100', '10.0.0.50'];

  use(req: Request, res: Response, next: NextFunction) {
    const ip = req.ip;

    if (this.blockedIps.includes(ip)) {
      throw new ForbiddenException('Your IP has been blocked');
    }

    next();
  }
}
```

## Cara Integrasi & Pengujian

Logika dalam `use()` bisa synchronous atau asynchronous (gunakan `async/await`). Jangan lupa panggil `next()` agar request dilanjutkan.

**Test dengan curl:**
```bash
curl -H "Authorization: Bearer YWxpY2U=" http://localhost:3000/protected
# Request proceeds

curl http://localhost:3000/protected
# {"message":"Missing authorization header","statusCode":401}
```
