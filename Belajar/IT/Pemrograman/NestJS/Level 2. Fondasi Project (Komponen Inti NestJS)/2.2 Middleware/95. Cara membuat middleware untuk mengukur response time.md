# 95. Cara membuat middleware untuk mengukur response time

## Definisi & Target
Middleware response time mencatat durasi yang dibutuhkan server untuk memproses request, dari diterima hingga response dikirim. Informasi ini bisa ditambahkan sebagai header HTTP `X-Response-Time` dan/atau dicatat di log untuk monitoring performa API.

## Komponen & Nest CLI Command
```
nest g middleware response-time --no-spec
```
File: `src/common/middleware/response-time.middleware.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/middleware/response-time.middleware.ts
import { Injectable, NestMiddleware } from '@nestjs/common';
import { Request, Response, NextFunction } from 'express';

@Injectable()
export class ResponseTimeMiddleware implements NestMiddleware {
  use(req: Request, res: Response, next: NextFunction) {
    const start = process.hrtime();

    res.on('finish', () => {
      const [seconds, nanoseconds] = process.hrtime(start);
      const durationMs = (seconds * 1000 + nanoseconds / 1e6).toFixed(2);

      res.setHeader('X-Response-Time', `${durationMs}ms`);

      const threshold = 1000;
      if (parseFloat(durationMs) > threshold) {
        console.warn(`SLOW REQUEST: ${req.method} ${req.originalUrl} took ${durationMs}ms`);
      }
    });

    next();
  }
}
```

```typescript
// src/app.module.ts (partial)
import { Module, NestModule, MiddlewareConsumer } from '@nestjs/common';
import { ResponseTimeMiddleware } from './common/middleware/response-time.middleware';

@Module({})
export class AppModule implements NestModule {
  configure(consumer: MiddlewareConsumer) {
    consumer
      .apply(ResponseTimeMiddleware)
      .forRoutes('*');
  }
}
```

## Cara Integrasi & Pengujian

Gunakan `process.hrtime()` untuk presisi tinggi dalam mengukur durasi, lebih akurat daripada `Date.now()`.

**Test dengan curl:**
```bash
curl -I http://localhost:3000/users
# HTTP/1.1 200 OK
# X-Response-Time: 2.35ms

# Jika response > 1 detik:
# Console: SLOW REQUEST: GET /heavy-report took 1500.42ms
```
