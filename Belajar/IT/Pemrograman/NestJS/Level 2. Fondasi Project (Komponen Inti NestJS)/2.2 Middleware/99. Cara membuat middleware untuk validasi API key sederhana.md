# 99. Cara membuat middleware untuk validasi API key sederhana

## Definisi & Target
Middleware API key memvalidasi request berdasarkan key yang dikirim melalui header. Cocok untuk autentikasi sederhana antara service-to-service. Middleware akan memblokir request yang tidak memiliki API key valid sebelum mencapai controller.

## Komponen & Nest CLI Command
```
nest g middleware api-key --no-spec
```
File: `src/common/middleware/api-key.middleware.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/middleware/api-key.middleware.ts
import { Injectable, NestMiddleware, UnauthorizedException } from '@nestjs/common';
import { Request, Response, NextFunction } from 'express';

@Injectable()
export class ApiKeyMiddleware implements NestMiddleware {
  private readonly validApiKeys = [
    'sk-live-a1b2c3d4',
    'sk-test-x1y2z3',
  ];

  use(req: Request, res: Response, next: NextFunction) {
    const apiKey = req.headers['x-api-key'] as string;

    if (!apiKey) {
      throw new UnauthorizedException('API key is missing');
    }

    if (!this.validApiKeys.includes(apiKey)) {
      throw new UnauthorizedException('Invalid API key');
    }

    (req as any).apiKey = apiKey;

    next();
  }
}
```

```typescript
// src/common/middleware/api-key-env.middleware.ts
import { Injectable, NestMiddleware, UnauthorizedException } from '@nestjs/common';
import { Request, Response, NextFunction } from 'express';

@Injectable()
export class ApiKeyEnvMiddleware implements NestMiddleware {
  use(req: Request, res: Response, next: NextFunction) {
    const apiKey = req.headers['x-api-key'] as string;
    const expectedKey = process.env.API_KEY || 'default-secret-key';

    if (!apiKey) {
      throw new UnauthorizedException('x-api-key header required');
    }

    if (apiKey !== expectedKey) {
      throw new UnauthorizedException('Invalid API key');
    }

    next();
  }
}
```

```typescript
// src/app.module.ts
import { Module, NestModule, MiddlewareConsumer } from '@nestjs/common';
import { ApiKeyMiddleware } from './common/middleware/api-key.middleware';

@Module({})
export class AppModule implements NestModule {
  configure(consumer: MiddlewareConsumer) {
    consumer
      .apply(ApiKeyMiddleware)
      .exclude(
        { path: 'health', method: RequestMethod.GET },
        { path: 'public', method: RequestMethod.ALL },
      )
      .forRoutes('*');
  }
}
```

## Cara Integrasi & Pengujian

Gunakan header `x-api-key` di setiap request. Route yang di-exclude tidak perlu API key.

**Test dengan curl:**
```bash
curl http://localhost:3000/users
# {"message":"API key is missing","statusCode":401}

curl -H "x-api-key: sk-live-a1b2c3d4" http://localhost:3000/users
# 200 OK

curl -H "x-api-key: wrong-key" http://localhost:3000/users
# {"message":"Invalid API key","statusCode":401}
```
