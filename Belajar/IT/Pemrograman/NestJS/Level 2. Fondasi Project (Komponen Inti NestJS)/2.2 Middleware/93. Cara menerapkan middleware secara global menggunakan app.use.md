# 93. Cara menerapkan middleware secara global menggunakan app.use

## Definisi & Target
Middleware global bisa didaftarkan langsung melalui instance `INestApplication` menggunakan `app.use()`. Middleware akan dijalankan untuk setiap request tanpa terkecuali. Cocok untuk middleware yang benar-benar perlu menjangkau seluruh aplikasi seperti logging, CORS sederhana, atau rate limiting.

## Komponen & Nest CLI Command
Tidak ada CLI command.
File: `src/main.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/middleware/global-logger.middleware.ts
import { Request, Response, NextFunction } from 'express';

export function globalLogger(req: Request, res: Response, next: NextFunction) {
  console.log(`[Global] ${new Date().toISOString()} ${req.ip} ${req.method} ${req.originalUrl}`);
  next();
}
```

```typescript
// src/main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { globalLogger } from './common/middleware/global-logger.middleware';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.use(globalLogger);

  await app.listen(3000);
  console.log('Application running on http://localhost:3000');
}
bootstrap();
```

## Cara Integrasi & Pengujian

Panggil `app.use()` SEBELUM `app.listen()`. Middleware global via `app.use()` hanya bisa menerima functional middleware, bukan class middleware.

**Test dengan curl:**
```bash
curl http://localhost:3000/anything
# Console: [Global] 2026-06-01T09:00:00.000Z ::1 GET /anything
```
