# 91. Cara mengecualikan route dari middleware menggunakan exclude

## Definisi & Target
`exclude()` memungkinkan kita mengecualikan route tertentu dari middleware yang sudah didaftarkan. Berguna ketika middleware berlaku luas (misalnya semua route `/users`) tetapi beberapa sub-route perlu di-skip (misalnya `/users/login` atau `/users/register`).

## Komponen & Nest CLI Command
Tidak ada CLI command.
File: `src/app.module.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/middleware/auth.middleware.ts
import { Injectable, NestMiddleware, UnauthorizedException } from '@nestjs/common';
import { Request, Response, NextFunction } from 'express';

@Injectable()
export class AuthMiddleware implements NestMiddleware {
  use(req: Request, res: Response, next: NextFunction) {
    const token = req.headers['authorization'];
    if (!token) {
      throw new UnauthorizedException('Authentication required');
    }
    next();
  }
}
```

```typescript
// src/app.module.ts
import { Module, NestModule, MiddlewareConsumer, RequestMethod } from '@nestjs/common';
import { AuthMiddleware } from './common/middleware/auth.middleware';

@Module({
  imports: [],
})
export class AppModule implements NestModule {
  configure(consumer: MiddlewareConsumer) {
    consumer
      .apply(AuthMiddleware)
      .exclude(
        { path: 'auth/login', method: RequestMethod.POST },
        { path: 'auth/register', method: RequestMethod.POST },
        { path: 'health', method: RequestMethod.GET },
      )
      .forRoutes('*');
  }
}
```

## Cara Integrasi & Pengujian

Route yang ada di `exclude()` akan dilewati middleware. Route lainnya tetap melewati middleware. Urutan: `apply()` -> `exclude()` -> `forRoutes()`.

**Test dengan curl:**
```bash
# Tanpa token - berhasil karena di-exclude
curl -X POST http://localhost:3000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"secret"}'
# 200 OK

# Tanpa token - gagal karena tidak di-exclude
curl http://localhost:3000/users
# {"message":"Authentication required","statusCode":401}
```
