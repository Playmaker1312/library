# 92. Cara membuat functional middleware sebagai alternatif class middleware

## Definisi & Target
Functional middleware adalah middleware berbentuk fungsi biasa (tanpa class/`@Injectable`). Cocok untuk middleware sederhana yang tidak membutuhkan dependency injection. Lebih ringan dan cepat karena tidak perlu instansiasi class.

## Komponen & Nest CLI Command
Tidak ada CLI command—buat file fungsi biasa.
File: `src/common/middleware/functional.middleware.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/middleware/functional.middleware.ts
import { Request, Response, NextFunction } from 'express';

export function functionalMiddleware(req: Request, res: Response, next: NextFunction) {
  const start = Date.now();

  res.on('finish', () => {
    const duration = Date.now() - start;
    console.log(`[Functional] ${req.method} ${req.originalUrl} - ${duration}ms`);
  });

  next();
}
```

```typescript
// src/common/middleware/cors-headers.middleware.ts
import { Request, Response, NextFunction } from 'express';

export function corsHeadersMiddleware(req: Request, res: Response, next: NextFunction) {
  res.setHeader('Access-Control-Allow-Origin', '*');
  res.setHeader('Access-Control-Allow-Methods', 'GET, POST, PUT, DELETE');
  res.setHeader('Access-Control-Allow-Headers', 'Content-Type, Authorization');

  if (req.method === 'OPTIONS') {
    res.sendStatus(204);
    return;
  }

  next();
}
```

```typescript
// src/app.module.ts
import { Module, NestModule, MiddlewareConsumer } from '@nestjs/common';
import { functionalMiddleware } from './common/middleware/functional.middleware';
import { corsHeadersMiddleware } from './common/middleware/cors-headers.middleware';

@Module({})
export class AppModule implements NestModule {
  configure(consumer: MiddlewareConsumer) {
    consumer
      .apply(functionalMiddleware, corsHeadersMiddleware)
      .forRoutes('*');
  }
}
```

## Cara Integrasi & Pengujian

Functional middleware tidak perlu decorator `@Injectable()`. Cukup gunakan langsung di `apply()`. Beberapa middleware bisa digabung dalam satu `apply()`.

**Test dengan curl:**
```bash
curl http://localhost:3000/test
# Console: [Functional] GET /test - 3ms
# Header: Access-Control-Allow-Origin: *
```
