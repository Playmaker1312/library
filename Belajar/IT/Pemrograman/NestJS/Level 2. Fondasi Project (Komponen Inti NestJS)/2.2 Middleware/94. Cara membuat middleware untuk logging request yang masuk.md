# 94. Cara membuat middleware untuk logging request yang masuk

## Definisi & Target
Logging request adalah use case middleware paling umum. Middleware ini mencatat method, path, headers, query params, dan body dari setiap request yang masuk. Berguna untuk debugging, audit trail, dan monitoring aplikasi.

## Komponen & Nest CLI Command
```
nest g middleware request-logger --no-spec
```
File: `src/common/middleware/request-logger.middleware.ts`

## Kode Implementasi (Per File)

```typescript
// src/common/middleware/request-logger.middleware.ts
import { Injectable, NestMiddleware, Logger } from '@nestjs/common';
import { Request, Response, NextFunction } from 'express';

@Injectable()
export class RequestLoggerMiddleware implements NestMiddleware {
  private readonly logger = new Logger('HTTP');

  use(req: Request, res: Response, next: NextFunction) {
    const { method, originalUrl, query, body, headers } = req;

    this.logger.log(`>>> ${method} ${originalUrl}`);
    this.logger.log(`Query: ${JSON.stringify(query)}`);

    if (method === 'POST' || method === 'PUT' || method === 'PATCH') {
      this.logger.log(`Body: ${JSON.stringify(body)}`);
    }

    this.logger.log(`User-Agent: ${headers['user-agent'] || 'unknown'}`);

    res.on('finish', () => {
      this.logger.log(`<<< ${method} ${originalUrl} ${res.statusCode}`);
    });

    next();
  }
}
```

```typescript
// src/app.module.ts (partial)
import { Module, NestModule, MiddlewareConsumer } from '@nestjs/common';
import { RequestLoggerMiddleware } from './common/middleware/request-logger.middleware';

@Module({})
export class AppModule implements NestModule {
  configure(consumer: MiddlewareConsumer) {
    consumer
      .apply(RequestLoggerMiddleware)
      .forRoutes('*');
  }
}
```

## Cara Integrasi & Pengujian

Daftarkan middleware di module. Gunakan NestJS `Logger` agar output terformat rapi sesuai framework.

**Test dengan curl:**
```bash
curl http://localhost:3000/users?page=1
# Console:
# [Nest] LOG [HTTP] >>> GET /users?page=1
# [Nest] LOG [HTTP] Query: {"page":"1"}
# [Nest] LOG [HTTP] User-Agent: curl/8.0
# [Nest] LOG [HTTP] <<< GET /users?page=1 200
```
