# 97. Cara menggunakan middleware helmet untuk security headers

## Definisi & Target
Helmet adalah kumpulan middleware keamanan untuk Express/NestJS yang menambahkan berbagai HTTP security headers. Melindungi dari serangan umum seperti XSS, clickjacking, MIME sniffing, dan lainnya. Cukup pasang dan daftarkan sebagai middleware global.

## Komponen & Nest CLI Command
```
npm install helmet
```
File: `src/main.ts`

## Kode Implementasi (Per File)

```typescript
// src/main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import helmet from 'helmet';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.use(helmet());

  await app.listen(3000);
  console.log('Server running with Helmet security headers');
}
bootstrap();
```

```typescript
// src/main.ts (dengan konfigurasi kustom)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import helmet from 'helmet';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.use(helmet({
    contentSecurityPolicy: {
      directives: {
        defaultSrc: ["'self'"],
        scriptSrc: ["'self'", "'unsafe-inline'"],
        styleSrc: ["'self'", "'unsafe-inline'"],
        imgSrc: ["'self'", "data:", "https:"],
      },
    },
    referrerPolicy: { policy: 'same-origin' },
    frameguard: { action: 'deny' },
  }));

  await app.listen(3000);
}
bootstrap();
```

## Cara Integrasi & Pengujian

Helmet menambahkan banyak header sekaligus. Periksa dengan curl atau browser dev tools.

**Test dengan curl:**
```bash
curl -I http://localhost:3000
# HTTP/1.1 200 OK
# X-Content-Type-Options: nosniff
# X-Frame-Options: DENY
# X-XSS-Protection: 0
# Strict-Transport-Security: max-age=15552000; includeSubDomains
# Content-Security-Policy: default-src 'self';...
```
