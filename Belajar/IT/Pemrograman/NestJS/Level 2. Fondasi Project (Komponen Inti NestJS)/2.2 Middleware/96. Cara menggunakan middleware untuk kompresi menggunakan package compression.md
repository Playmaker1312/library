# 96. Cara menggunakan middleware untuk kompresi menggunakan package compression

## Definisi & Target
Middleware kompresi menggunakan package `compression` untuk memperkecil ukuran response HTTP (gzip/deflate). Ini mengurangi bandwidth dan mempercepat loading. Cukup daftarkan sebagai middleware global menggunakan `app.use()` atau `MiddlewareConsumer`.

## Komponen & Nest CLI Command
```
npm install compression
```
File: `src/main.ts` atau `src/app.module.ts`

## Kode Implementasi (Per File)

```typescript
// src/main.ts (opsi 1 - global via app.use)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import * as compression from 'compression';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.use(compression());

  await app.listen(3000);
  console.log('Server running with compression enabled');
}
bootstrap();
```

```typescript
// src/app.module.ts (opsi 2 - via MiddlewareConsumer)
import { Module, NestModule, MiddlewareConsumer } from '@nestjs/common';
import * as compression from 'compression';

@Module({})
export class AppModule implements NestModule {
  configure(consumer: MiddlewareConsumer) {
    consumer
      .apply(compression())
      .forRoutes('*');
  }
}
```

## Cara Integrasi & Pengujian

Compression akan secara otomatis menambahkan header `Content-Encoding: gzip` dan mengompres response. Browser akan mendekompres secara otomatis.

**Test dengan curl:**
```bash
curl -H "Accept-Encoding: gzip" -I http://localhost:3000/users
# HTTP/1.1 200 OK
# Content-Encoding: gzip
# Vary: Accept-Encoding

# Tanpa Accept-Encoding:
curl -I http://localhost:3000/users
# HTTP/1.1 200 OK
# (tidak ada Content-Encoding)
```
