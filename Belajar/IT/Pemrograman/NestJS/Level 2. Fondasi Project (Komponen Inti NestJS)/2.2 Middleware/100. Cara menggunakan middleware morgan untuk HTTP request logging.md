# 100. Cara menggunakan middleware morgan untuk HTTP request logging

## Definisi & Target
Morgan adalah HTTP request logger middleware populer dari Express. Morgan menyediakan format logging siap pakai (combined, dev, common, dll) dan bisa dikustomisasi. Di NestJS, morgan bisa digunakan sebagai functional middleware.

## Komponen & Nest CLI Command
```
npm install morgan
npm install -D @types/morgan
```
File: `src/main.ts`

## Kode Implementasi (Per File)

```typescript
// src/main.ts (opsi 1 - format dev)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import * as morgan from 'morgan';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.use(morgan('dev'));

  await app.listen(3000);
}
bootstrap();
```

```typescript
// src/main.ts (opsi 2 - format combined dengan kustomisasi)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import * as morgan from 'morgan';
import { Logger } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  const logger = new Logger('Morgan');

  const morganStream = {
    write: (message: string) => {
      logger.log(message.trim());
    },
  };

  app.use(morgan('combined', { stream: morganStream }));

  await app.listen(3000);
}
bootstrap();
```

```typescript
// src/main.ts (opsi 3 - format kustom)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import * as morgan from 'morgan';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  const customFormat = ':remote-addr - :remote-user ":method :url HTTP/:http-version" :status :res[content-length] ":referrer" ":user-agent" :response-time ms';

  app.use(morgan(customFormat));

  await app.listen(3000);
}
bootstrap();
```

## Cara Integrasi & Pengujian

Morgan akan mencatat setiap request ke console dengan format yang dipilih.

**Test dengan curl:**
```bash
curl http://localhost:3000/users
# Console (format dev):
# GET /users 200 5.123 ms - 42

# Console (format combined):
# ::1 - - [01/Jun/2026:09:00:00 +0000] "GET /users HTTP/1.1" 200 42 "-" "curl/8.0"
```
