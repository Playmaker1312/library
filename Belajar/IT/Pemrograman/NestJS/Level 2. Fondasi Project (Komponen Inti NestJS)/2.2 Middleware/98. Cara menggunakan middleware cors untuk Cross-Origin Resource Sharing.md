# 98. Cara menggunakan middleware cors untuk Cross-Origin Resource Sharing

## Definisi & Target
CORS (Cross-Origin Resource Sharing) mengontrol domain mana yang diizinkan mengakses API. NestJS menyediakan konfigurasi CORS bawaan melalui method `app.enableCors()` atau package `cors` sebagai middleware. Penting untuk keamanan aplikasi web yang melayani frontend dari domain berbeda.

## Komponen & Nest CLI Command
Tidak perlu instalasi—NestJS sudah include CORS.
File: `src/main.ts`

## Kode Implementasi (Per File)

```typescript
// src/main.ts (opsi 1 - enableCors bawaan)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.enableCors({
    origin: ['https://frontend.example.com', 'http://localhost:3001'],
    methods: ['GET', 'POST', 'PUT', 'DELETE', 'PATCH'],
    credentials: true,
    allowedHeaders: ['Content-Type', 'Authorization'],
    exposedHeaders: ['X-Response-Time'],
    maxAge: 3600,
  });

  await app.listen(3000);
}
bootstrap();
```

```typescript
// src/main.ts (opsi 2 - CORS untuk semua origin)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.enableCors();

  await app.listen(3000);
}
bootstrap();
```

```typescript
// src/main.ts (opsi 3 - dynamic CORS berdasarkan origin)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  const whitelist = ['https://myapp.com', 'https://admin.myapp.com'];

  app.enableCors({
    origin: (origin, callback) => {
      if (!origin || whitelist.includes(origin)) {
        callback(null, true);
      } else {
        callback(new Error('Not allowed by CORS'));
      }
    },
    credentials: true,
  });

  await app.listen(3000);
}
bootstrap();
```

## Cara Integrasi & Pengujian

CORS response headers akan muncul di setiap response. Browser akan melakukan preflight request (OPTIONS) sebelum request utama.

**Test dengan curl:**
```bash
curl -I -H "Origin: https://frontend.example.com" http://localhost:3000/users
# HTTP/1.1 200 OK
# Access-Control-Allow-Origin: https://frontend.example.com
# Access-Control-Allow-Credentials: true

# Preflight request:
curl -X OPTIONS -H "Origin: https://frontend.example.com" \
  -H "Access-Control-Request-Method: POST" \
  http://localhost:3000/users
# HTTP/1.1 204 No Content
# Access-Control-Allow-Methods: GET,POST,PUT,DELETE,PATCH
```
