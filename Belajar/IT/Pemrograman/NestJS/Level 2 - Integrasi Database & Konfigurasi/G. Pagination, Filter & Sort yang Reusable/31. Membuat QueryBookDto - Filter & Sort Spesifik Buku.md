# Membuat QueryBookDto — Filter & Sort Spesifik Buku

## Penjelasan

Setelah PaginationDto reusable selesai, kita perlu membuat DTO spesifik untuk entity Book yang menambahkan kemampuan filtering dan sorting. QueryBookDto mengextend PaginationDto, sehingga mewarisi field `page` dan `limit`, lalu menambahkan field-field baru seperti `search` (pencarian berdasarkan judul atau penulis), `sortBy` (field yang digunakan untuk sorting), `sortOrder` (asc/desc), `genre` (filter genre), `year` (filter tahun terbit), dan `minStock` (filter stok minimum).

Filter `search` menggunakan `@IsOptional()` dan `@IsString()` karena berupa teks bebas. Field `sortBy` menggunakan enum khusus yang membatasi nilai yang valid — misalnya hanya bisa 'title', 'author', 'publishedYear', atau 'createdAt'. Ini mencegah SQL injection-style attack melalui sorting field. Field `sortOrder` dibatasi hanya 'asc' atau 'desc' menggunakan decorator `@IsIn(['asc', 'desc'])`.

Dengan menggunakan inheritance, kita tidak perlu mengulang definisi `page` dan `limit` di setiap DTO. Jika suatu saat kita mengubah PaginationDto (misalnya menambah field `offset`), semua DTO yang mewarisinya akan otomatis mendapat perubahan tersebut. Ini adalah contoh penerapan prinsip DRY (Don't Repeat Yourself) dalam desain API.

## Fungsi

Menyediakan DTO untuk query parameter endpoint GET /books yang mendukung pagination, search, filter (genre, tahun, stok), dan sorting dengan validasi ketat.

## Cara Implementasi / Code

Buat enum untuk sortable fields:

```typescript
// src/books/dto/sort-by.enum.ts
export enum SortByField {
  TITLE = 'title',
  AUTHOR = 'author',
  PUBLISHED_YEAR = 'publishedYear',
  CREATED_AT = 'createdAt',
  STOCK = 'stock',
}
```

Buat `src/books/dto/query-book.dto.ts`:

```typescript
// src/books/dto/query-book.dto.ts
import {
  IsOptional,
  IsString,
  IsEnum,
  IsIn,
  IsInt,
  Min,
} from 'class-validator';
import { Type } from 'class-transformer';
import { PaginationDto } from '../../common/dto/pagination.dto';
import { BookGenre } from '@prisma/client';
import { SortByField } from './sort-by.enum';

export class QueryBookDto extends PaginationDto {
  @IsOptional()
  @IsString()
  search?: string;

  @IsOptional()
  @IsEnum(BookGenre)
  genre?: BookGenre;

  @IsOptional()
  @Type(() => Number)
  @IsInt()
  @Min(1900)
  year?: number;

  @IsOptional()
  @Type(() => Number)
  @IsInt()
  @Min(0)
  minStock?: number;

  @IsOptional()
  @IsEnum(SortByField)
  sortBy?: SortByField = SortByField.CREATED_AT;

  @IsOptional()
  @IsIn(['asc', 'desc'])
  sortOrder?: 'asc' | 'desc' = 'desc';
}
```

Buat index file:

```typescript
// src/books/dto/index.ts
export * from './query-book.dto';
export * from './sort-by.enum';
export * from './create-book.dto';
export * from './update-book.dto';
```

Contoh URL yang dihasilkan:

```
GET /books?page=1&limit=10&search=nestjs&genre=TEKNOLOGI&year=2024&sortBy=title&sortOrder=asc
GET /books?search=si&minStock=5
GET /books?genre=FIKSI&sortBy=publishedYear&sortOrder=desc
```

Cara menggunakan di controller:

```typescript
@Get()
async findAll(@Query() query: QueryBookDto) {
  return this.booksService.findAllPaginated(query);
}
```

## Analogi

QueryBookDto adalah **formulir pencarian buku lanjutan** di perpustakaan. Jika PaginationDto hanya mengatur nomor antrian (halaman berapa, berapa banyak buku per halaman), QueryBookDto menambahkan kolom-kolom spesifik:

- **Search**: "Cari buku yang judulnya mengandung kata 'NestJS'"
- **Genre**: "Hanya buku bergenre Teknologi"
- **Year**: "Buku terbit tahun 2024 saja"
- **MinStock**: "Buku yang stoknya minimal 5"
- **SortBy**: "Urutkan berdasarkan judul"
- **SortOrder**: "Urutan ascending A-Z"

Petugas perpustakaan (controller) menerima formulir ini, lalu meneruskannya ke bagian pencarian (service). Bagian pencarian akan mencari di rak buku sesuai kriteria yang diminta, lalu mengembalikan hasilnya dalam bentuk paketan (paginated). Formulir ini sudah memiliki aturan yang jelas: kolom "Tahun" hanya boleh diisi angka minimal 1900, kolom "Urutkan" hanya boleh diisi "judul", "penulis", atau "tahun" — tidak boleh asal-asalan. Ini mencegah pengunjung meminta pengurutan berdasarkan kolom yang tidak ada.

## Penggunaan

Dipakai khusus di endpoint `GET /books` dan method `findAllPaginated` di BooksService. QueryBookDto bisa diperluas untuk endpoint lain seperti `GET /members` atau `GET /loans` dengan membuat DTO serupa yang juga mengextend PaginationDto.

## Kesalahan Umum yang Sering Terjadi

1. **SortByField enum tidak sesuai field Prisma**: Misalnya `sortBy: 'title'` tapi di Prisma namanya `title` (case sensitif).
2. **Lupa `@Type(() => Number)` untuk `year` dan `minStock`**: Nilai tetap string, `@IsInt()` gagal.
3. **Search tidak case-insensitive**: Query `?search=nestjs` tidak menemukan "NestJS" karena case berbeda. Handle di repository dengan `mode: 'insensitive'`.
4. **Tidak sanitasi search input**: User bisa memasukkan karakter khusus yang merusak query. Gunakan validasi panjang maksimal.
5. **SortBy tidak divalidasi**: User bisa mengirim `sortBy=password_hash`, berpotensi mengekspos data sensitif.
6. **Lupa set default sortOrder**: Jika tidak dikirim, `sortOrder` undefined, error di Prisma.

## Hubungan dengan Materi Sebelumnya

QueryBookDto mengextend PaginationDto (materi 30) yang sudah reusable. DTO ini akan digunakan oleh repository (materi 24) dan service (materi 26) untuk melakukan query dengan filter dan sorting. Hasilnya akan dibungkus dalam PaginatedResult type (materi 32) untuk response yang standar.

import { IsOptional, IsString, IsEnum, IsIn } from 'class-validator';
import { PaginationDto } from '../../common/dto/pagination.dto';

export enum SortByMemberField {
  NAME = 'name',
  EMAIL = 'email',
  CREATED_AT = 'createdAt',
}

export class QueryMemberDto extends PaginationDto {
  @IsOptional()
  @IsString()
  search?: string;

  @IsOptional()
  @IsEnum(SortByMemberField)
  sortBy?: SortByMemberField = SortByMemberField.CREATED_AT;

  @IsOptional()
  @IsIn(['asc', 'desc'])
  sortOrder?: 'asc' | 'desc' = 'asc';
}

**Soal 2:** Tulis query Prisma yang menggunakan search (case-insensitive), filter genre, filter year, sortBy, dan sortOrder.

<details>
<summary>Jawaban</summary>

```typescript
async findAllPaginated(query: QueryBookDto) {
  const { page, limit, search, genre, year, sortBy, sortOrder } = query;
  const skip = (page - 1) * limit;

  const where: any = { isDeleted: false };

  if (search) {
    where.OR = [
      { title: { contains: search, mode: 'insensitive' } },
      { author: { contains: search, mode: 'insensitive' } },
    ];
  }

  if (genre) {
    where.genre = genre;
  }

  if (year) {
    where.publishedYear = year;
  }

  return this.prisma.book.findMany({
    skip,
    take: limit,
    where,
    orderBy: { [sortBy]: sortOrder },
  });
}
```
