# 1. JavaScript Modern (ES6)

## 1.3. Destructuring Object dan Array

**Definisi Singkat:** Destructuring mengekstrak nilai dari object/array ke variabel individual dengan sintaks yang mirip dengan literal object/array.

**Analogi:** Seperti membuka koper dan mengeluarkan isinya satu per satu — daripada mengambil seluruh koper, Anda langsung mengambil baju, celana, sepatu ke tangan masing-masing.

**Poin-Poin Penting:**
- Destructuring object menggunakan `{}` dengan key matching; bisa rename dengan `:`
- Destructuring array menggunakan `[]` dengan positional matching
- Bisa memberikan default value dengan `=`
- Nested destructuring untuk object/array bersarang
- Rest pattern `...` untuk sisa elemen/properti

**Contoh Kode:**
```typescript
// Object destructuring — umum di NestJS untuk config
const config = { host: 'localhost', port: 3000, db: { user: 'admin' } };
const { host, port: serverPort, db: { user } } = config;

// Array destructuring — untuk tuple/value pairs
const [error, data] = [null, { id: 1 }];

// Function parameters destructuring
function printUser({ name, age = 25 }: { name: string; age?: number }) {
  console.log(`${name} is ${age}`);
}

interface ResponseResult<T> {
  success: boolean;
  data: T | null;
}

function handleResponse<T>({ success, data }: ResponseResult<T>) {
  if (success && data) return data;
  throw new Error('Request failed');
}
```

**Kasus Penggunaan Nyata:**
Digunakan setiap hari di NestJS: destructuring `@Body()`, `@Param()`, `@Query()` di controller, destructuring config service, error-first pattern di Promise results, dan response DTO assignments.
