## 1.2 Arrow Functions & Regular Functions

### Definisi Singkat

**Regular Function** adalah cara tradisional mendeklarasikan fungsi menggunakan kata kunci `function`, sedangkan **Arrow Function** adalah sintaksis baru (ES6) yang lebih ringkas menggunakan tanda panah `=>` dan memiliki perilaku _binding_ konteks yang berbeda.

### Analogi

Bayangkan fungsi adalah seorang **Pekerja**:

- **Regular Function** adalah **Pekerja Kontrak**: Setiap kali dia masuk ke ruangan (konteks) baru, dia menyesuaikan diri dengan siapa "bos" (`this`) di ruangan itu. Dia fleksibel tapi sering membingungkan jika kamu lupa siapa bosnya.
    
- **Arrow Function** adalah **Pekerja dari Kantor Pusat**: Dia membawa "bos" aslinya dari tempat dia berasal. Dia tidak peduli di ruangan mana dia bekerja sekarang, dia tetap setia pada bos tempat dia pertama kali diciptakan.
    

### Poin-Poin Penting

- **Sintaksis:** Arrow function menghilangkan kata kunci `function`. Jika hanya satu baris, ia memiliki _implicit return_ (tidak perlu menulis `return`).
    
- **Konteks `this`:**
    
    - **Regular:** Nilai `this` ditentukan oleh bagaimana fungsi dipanggil (dinamis).
        
    - **Arrow:** Tidak memiliki `this` sendiri. Ia mengambil `this` dari lingkup sekitarnya (leksikal).
        
- **Constructor:** Regular function bisa dijadikan _constructor_ (menggunakan `new`), sedangkan Arrow function tidak bisa.
    
- **Arguments Object:** Regular function punya akses ke variabel `arguments` (semua parameter yang dikirim), Arrow function tidak punya.
    

### Contoh Implementasi

JavaScript

```
// --- 1. Perbedaan Sintaksis ---
// Regular Function
function multiply(a, b) {
    return a * b;
}

// Arrow Function (Ringkas & Implicit Return)
const multiplyArrow = (a, b) => a * b;


// --- 2. Perbedaan Konteks 'this' ---
const person = {
    name: "Budi",
    // Regular Function
    sayName: function() {
        console.log("Halo, saya " + this.name);
    },
    // Arrow Function
    sayNameArrow: () => {
        // 'this' di sini bukan merujuk ke 'person', tapi ke global scope
        console.log("Halo, saya " + this.name); 
    }
};

person.sayName();      // Output: Halo, saya Budi
person.sayNameArrow(); // Output: Halo, saya undefined (atau kosong)
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, Arrow Function sangat sering ditemukan pada:

1. **RxJS Observables:** Saat kamu melakukan transformasi data di _service_ menggunakan `.map()` atau `.filter()`, Arrow function digunakan agar `this` tetap merujuk ke _class service_ tersebut, bukan ke fungsi internal RxJS.
    
2. **Callback dalam Middleware/Interceptors:** Memastikan konteks _class_ tetap terjaga saat menjalankan logika tambahan.
    
3. **Clean Code:** Membuat kode _controller_ atau _service_ lebih bersih, terutama untuk fungsi-fungsi pembantu yang sederhana.
