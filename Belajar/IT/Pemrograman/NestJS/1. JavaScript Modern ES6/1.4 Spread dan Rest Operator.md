# 1. JavaScript Modern (ES6)

## 1.4. Spread dan Rest Operator (`...`)

**Definisi Singkat:** Rest operator mengumpulkan sisa elemen menjadi array. Spread operator menyebarkan elemen array/object ke tempat lain. Keduanya menggunakan sintaks `...`.

**Analogi:** Rest sepertiember — menampung air hujan dari atap. Spread seperti sprinkler — menyebarkan air ke seluruh halaman.

**Poin-Poin Penting:**
- Rest `...args` di parameter function mengumpulkan arguments menjadi array
- Spread `...arr` di array literal menyebar elemen
- Spread `...obj` di object literal melakukan shallow copy properti
- Spread untuk immutable update — tidak mutasi original

**Contoh Kode:**
```typescript
// Rest — menangkap sisa parameter
function logSemua(...args: (string | number)[]) {
  args.forEach(arg => console.log(arg));
}

// Spread array — menggabungkan
const defaults = [1, 2];
const all = [...defaults, 3, 4]; // [1, 2, 3, 4]

// Spread object — immutable update pattern (sering di NestJS)
interface User { id: number; name: string; role: string }
const user: User = { id: 1, name: 'Alice', role: 'user' };
const updatedUser: User = { ...user, role: 'admin' };

// Rest di destructuring
const { role, ...rest } = updatedUser;
// rest = { id: 1, name: 'Alice' }
```

**Kasus Penggunaan Nyata:**
Spread object untuk update DTO secara immutable, rest parameters untuk variadic function arguments, spread array untuk menggabungkan query results, dan cloning object sebelum mutasi di NestJS services.
