# 1. JavaScript Modern (ES6)

## 1.2. Arrow Functions dan Regular Functions

**Definisi Singkat:** Arrow functions `() => {}` tidak memiliki binding `this` sendiri dan tidak bisa digunakan sebagai constructor. Regular functions memiliki dynamic `this` binding.

**Analogi:** Regular function seperti remote TV — `this` tergantung cara dipencet. Arrow function seperti saklar dinding — `this` tetap dari ruangan tempat dipasang.

**Poin-Poin Penting:**
- Arrow functions mewarisi `this` dari lexical scope (parent scope)
- Regular functions mendapatkan `this` dari cara dipanggil (call-site)
- Arrow functions tidak punya `arguments` object, tidak bisa `new`, tidak punya `prototype`
- Gunakan arrow function untuk callback, regular function method di object/class

**Contoh Kode:**
```typescript
class KoneksiDatabase {
  private url: string;

  constructor(url: string) {
    this.url = url;
  }

  // Regular function — butuh own this binding
  async connect() {
    console.log(`Connecting to ${this.url}`);
  }

  // Arrow sebagai callback — lexical this
  logAfter(ms: number) {
    setTimeout(() => {
      console.log(`Still connected to ${this.url}`);
    }, ms);
  }
}

// Arrow function — concise, no this binding
const double = (x: number): number => x * 2;
```

**Kasus Penggunaan Nyata:**
Gunakan arrow function untuk array methods (map/filter), Promise chains, dan async callbacks. Gunakan regular function untuk methods di class Service NestJS agar binding `this` tetap aman saat dipanggil framework.
