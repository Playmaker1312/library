## 1.6 Promises & Callbacks

### Definisi Singkat

**Callback** adalah fungsi yang dilewatkan sebagai argumen ke fungsi lain untuk dieksekusi setelah suatu tugas selesai. **Promise** adalah objek yang merepresentasikan keberhasilan atau kegagalan dari sebuah operasi asinkronus di masa depan.

### Analogi

Bayangkan kamu sedang memesan **Kopi di Kafe**:

- **Callback**: Kamu berdiri di depan kasir menunggu kopi dibuatkan. Kasir baru akan melayani orang berikutnya setelah kopimu jadi. Jika kopinya lama, antrean macet (**Blocking**).
    
- **Promise**: Kasir memberimu sebuah **alat getar (buzzer)**. Kamu bisa duduk atau main HP (melakukan tugas lain). Alat itu adalah "janji" (Promise). Jika alat bergetar, kopi siap (**Resolved**). Jika alat merah berbunyi tanda air habis, pesanan batal (**Rejected**).
    

### Poin-Poin Penting

- **Callback:** Metode lama. Jika terlalu banyak proses berurutan, akan terjadi **Callback Hell** (kode menjorok ke kanan dan sulit dibaca).
    
- **Promise States:** * _Pending_: Sedang diproses.
    
    - _Fulfilled (Resolved)_: Berhasil selesai.
        
    - _Rejected_: Terjadi kesalahan.
        
- **`.then()` & `.catch()`:** Cara Promise menangani hasil. `.then()` untuk sukses, `.catch()` untuk error.
    
- **Non-blocking:** Memungkinkan JavaScript menjalankan baris kode berikutnya tanpa harus menunggu proses asinkronus yang sedang berjalan selesai.
    

### Contoh Implementasi

JavaScript

```
// --- 1. Pendekatan Callback (Kuno) ---
function ambilData(callback) {
    setTimeout(() => {
        callback("Data berhasil diambil via Callback");
    }, 1000);
}

ambilData((hasil) => {
    console.log(hasil);
});


// --- 2. Pendekatan Promise (Modern) ---
const ambilDataPromise = new Promise((resolve, reject) => {
    const sukses = true;
    setTimeout(() => {
        if (sukses) {
            resolve("Data berhasil diambil via Promise");
        } else {
            reject("Gagal mengambil data");
        }
    }, 1000);
});

ambilDataPromise
    .then((hasil) => console.log(hasil))
    .catch((err) => console.error(err));
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, Promise adalah tulang punggung aplikasi:

1. **Database Operations:** Semua _query_ menggunakan TypeORM atau Prisma bersifat asinkronus dan mengembalikan Promise.
    
2. **Controller Returns:** NestJS secara otomatis bisa menangani _return_ berupa Promise. Jika fungsi di controller mengembalikan Promise, NestJS akan menunggu hingga _resolved_ sebelum mengirimkan response ke user.
    
3. **Refactoring:** Promise adalah dasar sebelum kamu bisa menggunakan sintaks `async/await` yang jauh lebih bersih (yang akan kita bahas di materi selanjutnya).
