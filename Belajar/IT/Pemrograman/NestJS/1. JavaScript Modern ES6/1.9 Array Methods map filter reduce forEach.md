# 1. JavaScript Modern (ES6)

## 1.9. Array Methods: `map`, `filter`, `reduce`, `forEach`

**Definisi Singkat:** Array methods functional untuk transformasi data: `map` (transform setiapelemen), `filter` (seleksi), `reduce` (akumulasi), `forEach` (iterasi side-effect).

**Analogi:**
- `map` seperti mesin pabrik — setiap bahan mentah masuk, barang jadi keluar
- `filter` seperti saringan — hanya yang lolos yang lewat
- `reduce` seperti blender — semua bahan masuk, satu hasil keluar
- `forEach` seperti petugas absen — melakukan sesuatu untuk setiap orang, tanpa mengubah

**Poin-Poin Penting:**
- `map` mengembalikan array baru dengan panjang sama
- `filter` mengembalikan array baru dengan panjang ≤ original
- `reduce` mengembalikan satu nilai (tipe apapun)
- `forEach` mengembalikan `undefined` — untuk side effects saja
- Semua immutable — tidak mengubah array original

**Contoh Kode:**
```typescript
interface User {
  id: number;
  name: string;
  age: number;
  isActive: boolean;
}

const users: User[] = [
  { id: 1, name: 'Alice', age: 30, isActive: true },
  { id: 2, name: 'Bob', age: 17, isActive: false },
  { id: 3, name: 'Charlie', age: 25, isActive: true },
];

// map — transformasi data (sering di NestJS response)
const userIds: number[] = users.map(u => u.id);

// filter — seleksi
const activeUsers: User[] = users.filter(u => u.isActive && u.age >= 18);

// reduce — agregasi (seperti SQL SUM/COUNT)
const totalAge: number = users.reduce((sum, u) => sum + u.age, 0);
const groupedByStatus: Record<string, User[]> = users.reduce((acc, u) => {
  const key = u.isActive ? 'active' : 'inactive';
  (acc[key] ??= []).push(u);
  return acc;
}, {} as Record<string, User[]>);

// forEach — side effect (logging)
users.forEach(u => console.log(`Processing: ${u.name}`));
```

**Kasus Penggunaan Nyata:**
`map` untuk transform DTO ke response, `filter` untuk validasi/authorization lists, `reduce` untuk agregasi data laporan, `forEach` untuk batch processing di service NestJS.
