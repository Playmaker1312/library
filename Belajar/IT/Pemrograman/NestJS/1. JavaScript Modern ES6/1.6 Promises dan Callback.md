# 1. JavaScript Modern (ES6)

## 1.6. Promises dan Callback

**Definisi Singkat:** Promise adalah object yang merepresentasikan nilai masa depan (sukses/gagal) dari operasi asynchronous. Callback adalah function yang dipanggil setelah operasi selesai.

**Analogi:** Promise seperti kupon restoran — Anda dapatkannya sekarang, makan nanti. Callback seperti nomor antrian — Anda tinggalkan nomor, dipanggil saat giliran tiba.

**Poin-Poin Penting:**
- Promise memiliki 3 state: `pending`, `fulfilled`, `rejected`
- `.then()` untuk sukses, `.catch()` untuk error, `.finally()` untuk cleanup
- Callback Hell terjadi saat callback bersarang — Promise/flat chain solves this
- `Promise.all()` untuk parallel, `Promise.race()` untuk yang tercepat
- Setiap `.then()` mengembalikan Promise baru — chainable

**Contoh Kode:**
```typescript
// Callback style
function readFileCb(path: string, cb: (err: Error | null, data?: string) => void) {
  if (path === 'error') cb(new Error('not found'));
  else cb(null, 'file content');
}

// Promise style
function readFilePromise(path: string): Promise<string> {
  return new Promise((resolve, reject) => {
    readFileCb(path, (err, data) => {
      if (err) reject(err);
      else resolve(data!);
    });
  });
}

// Chaining — pattern umum di NestJS service
readFilePromise('config.json')
  .then(data => JSON.parse(data))
  .then(config => console.log(config.port))
  .catch(err => console.error('Failed:', err.message));

// Parallel execution
Promise.all([
  readFilePromise('users.json'),
  readFilePromise('posts.json'),
]).then(([users, posts]) => {
  // Process both results
});
```

**Kasus Penggunaan Nyata:**
Setiap operasi database NestJS (TypeORM/Prisma) mengembalikan Promise. HTTP calls menggunakan Axios/Got juga Promise-based. Promise.all untuk parallel database queries di service method.
