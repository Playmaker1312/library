## 1.4 Spread & Rest Operator (`...`)

### Definisi Singkat

**Spread Operator** digunakan untuk "menyebarkan" atau membongkar isi array/objek menjadi elemen individu, sedangkan **Rest Operator** digunakan untuk "mengumpulkan" sisa elemen atau argumen yang tersebar menjadi satu wadah (array atau objek).

### Analogi

- **Spread (Menyebar):** Bayangkan kamu punya **kotak Lego yang sudah dirakit**. Spread adalah aksi membongkar rakitan itu sehingga semua kepingan batanya terhampar di lantai agar bisa digabungkan dengan kepingan lain untuk membuat rakitan baru yang lebih besar.
    
- **Rest (Mengumpulkan):** Bayangkan kamu sedang **membereskan mainan**. Kamu mengambil semua mainan yang terserak di lantai (sisa-sisa yang belum masuk kotak) dan memasukkannya ke dalam satu kantong besar bernama "Lain-lain".
    

### Poin-Poin Penting

- **Spread Operator:**
    
    - Digunakan untuk menyalin (_copying_) array atau objek tanpa merusak referensi aslinya.
        
    - Digunakan untuk menggabungkan (_merging_) dua atau lebih array/objek.
        
- **Rest Operator:**
    
    - Digunakan di dalam parameter fungsi untuk menerima jumlah argumen yang tidak pasti.
        
    - Digunakan dalam _destructuring_ untuk menangkap sisa properti yang tidak diekstrak secara spesifik.
        
- **Urutan:** Rest operator harus selalu berada di posisi terakhir (ujung kanan) dalam daftar parameter atau destructuring.
    

### Contoh Implementasi

JavaScript

```
// --- 1. Spread Operator (Menyebarkan) ---
const dataLama = { nama: 'Andi', role: 'User' };
const dataBaru = { ...dataLama, role: 'Admin', status: 'Aktif' }; 
// role 'User' tertimpa oleh 'Admin'

const hobi = ['Main Game', 'Coding'];
const hobiLengkap = [...hobi, 'Membaca']; 
// Hasil: ['Main Game', 'Coding', 'Membaca']


// --- 2. Rest Operator (Mengumpulkan) ---
// Dalam Fungsi
function hitungTotal(...angka) {
    // angka menjadi sebuah array: [1, 2, 3, 4]
    return angka.reduce((total, n) => total + n, 0);
}
console.log(hitungTotal(1, 2, 3, 4));

// Dalam Destructuring
const produk = { id: 1, nama: 'Laptop', harga: 15000000, stok: 5 };
const { id, ...detailLainnya } = produk;
// id = 1
// detailLainnya = { nama: 'Laptop', harga: 15000000, stok: 5 }
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, kedua operator ini krusial untuk:

1. **Update Data (PATCH Request):** Saat melakukan update data di database, kita sering mengambil data lama lalu menimpanya dengan data baru dari `dto` menggunakan Spread.
    
    - `const updatedUser = { ...oldUser, ...updateUserDto };`
        
2. **Filter Sensitive Data:** Menggunakan Rest operator untuk memisahkan data sensitif sebelum dikirim ke client.
    
    - `const { password, ...userWithoutPassword } = user;`
        
3. **Dynamic Service Parameters:** Rest operator berguna pada fungsi _logging_ atau _utility_ yang menerima parameter dalam jumlah dinamis.
