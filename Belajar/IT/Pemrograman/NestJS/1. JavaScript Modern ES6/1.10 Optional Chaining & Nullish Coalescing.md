## 1.10 Optional Chaining (`?.`) & Nullish Coalescing (`??`)

### Definisi Singkat

**Optional Chaining (`?.`)** adalah operator yang memungkinkan kita membaca nilai properti yang terletak jauh di dalam struktur objek tanpa harus memvalidasi apakah setiap tingkatan objek itu ada. **Nullish Coalescing (`??`)** adalah operator logika yang memberikan nilai _fallback_ (cadangan) hanya jika nilai yang diperiksa adalah `null` atau `undefined`.

### Analogi

- **Optional Chaining (`?.`)**: Bayangkan kamu mencari sebuah buku di sebuah rak di perpustakaan. Daripada kamu harus mengecek: "Apakah perpustakaannya buka? Apakah raknya ada? Apakah bukunya ada?", kamu langsung saja mencoba mengambil bukunya. Jika di tengah jalan ada yang tidak ada, kamu cukup mengangkat tangan dan berkata "Tidak ada", tanpa harus merusak seluruh perpustakaan.
    
- **Nullish Coalescing (`??`)**: Bayangkan kamu sedang menyiapkan minuman. Kamu bertanya "Apakah ada Gula?". Jika **sama sekali tidak ada** (habis total), baru kamu menggunakan Madu. Tapi jika gulanya ada meskipun cuma sedikit (misal: nol), kamu tetap pakai gula itu.
    

### Poin-Poin Penting

- **Optional Chaining (`?.`)**:
    
    - Mencegah error `TypeError: Cannot read property 'x' of undefined`.
        
    - Jika bagian sebelum `?.` adalah `null` atau `undefined`, ia langsung mengembalikan `undefined` bukannya melempar error.
        
- **Nullish Coalescing (`??`)**:
    
    - Berbeda dengan operator `||` (OR).
        
    - `??` hanya beraksi pada `null` dan `undefined`.
        
    - Nilai "Falsy" lain seperti `0`, `false`, atau `""` (string kosong) dianggap sebagai nilai yang valid dan **tidak** akan memicu nilai cadangan.
        

### Contoh Implementasi

JavaScript

```
const user = {
    profile: {
        name: "Gemini",
        // address tidak ada
    },
    settings: {
        theme: "", // string kosong (falsy)
        retry: 0   // angka nol (falsy)
    }
};

// 1. Tanpa Optional Chaining (Error!)
// console.log(user.profile.address.city); 

// 2. Dengan Optional Chaining (Aman)
const city = user.profile.address?.city; 
console.log(city); // Output: undefined (tidak error)


// 3. Perbedaan || vs ??
const themeOR = user.settings.theme || "Dark";
const themeNullish = user.settings.theme ?? "Dark";

console.log(themeOR);      // Output: "Dark" (karena "" dianggap false)
console.log(themeNullish); // Output: "" (karena "" bukan null/undefined)

const retry = user.settings.retry ?? 5;
console.log(retry); // Output: 0 (0 dianggap nilai valid)
```

### Koneksi dengan Web Development (NestJS)

Di dalam **NestJS**, fitur ini sangat sering digunakan untuk:

1. **Handling API Response**: Saat mengambil data dari microservice lain, kita sering menggunakan `?.` untuk mengecek isi data yang strukturnya dalam tanpa takut aplikasi kita mati jika service tersebut mengirim data kosong.
    
2. **Configuration & Environment**: Mengambil nilai dari file `.env`.
    
    - `const port = configService.get('PORT') ?? 3000;` (Gunakan 3000 jika PORT tidak didefinisikan).
        
3. **Database Relations**: Saat melakukan _join_ antar tabel (misal: User dan Profile). Jika seorang User belum punya Profile, `user.profile?.avatar` akan mencegah error saat kita mencoba menampilkan foto profilnya di frontend.
