# 1. JavaScript Modern (ES6)

## 1.7. Async dan Await

**Definisi Singkat:** `async` membuat function mengembalikan Promise. `await` menunggu Promise selesai — membuat kode asynchronous terlihat synchronous.

**Analogi:** Seperti membuat kopi — Anda menekan tombol mesin (async), lalu menunggu (await) sampai kopi keluar sebelum mengambilnya. Tanpa await, Anda mengambil gelas kosong.

**Poin-Poin Penting:**
- `async function` selalu mengembalikan Promise (implicit wrapping)
- `await` hanya bisa di dalam `async function`
- Error handling dengan `try/catch` — lebih clean daripada `.catch()`
- `await Promise.all([...])` untuk parallel execution
- Top-level await tersedia di ES2022+ (module scope)

**Contoh Kode:**
```typescript
// Service method NestJS — async/await
class UsersService {
  private users: Array<{ id: number; name: string }> = [];

  async findByEmail(email: string): Promise<{ id: number; name: string } | null> {
    try {
      const user = await this.queryDatabase(`SELECT * FROM users WHERE email = $1`, [email]);
      return user;
    } catch (error) {
      console.error(`Database error for email ${email}:`, (error as Error).message);
      throw error; // Re-throw untuk controller
    }
  }

  async getAllUsers(): Promise<Array<{ id: number; name: string }>> {
    const [users, count] = await Promise.all([
      this.queryDatabase('SELECT * FROM users'),
      this.queryDatabase('SELECT COUNT(*) FROM users'),
    ]);
    console.log(`Total users: ${count[0].count}`);
    return users;
  }

  private queryDatabase(sql: string, params?: unknown[]): Promise<any> {
    // Simulasi database call
    return Promise.resolve(this.users);
  }
}
```

**Kasus Penggunaan Nyata:**
Setiap service method di NestJS yang berinteraksi dengan database menggunakan async/await. Controller endpoints juga async. Pattern: Controller → await Service → await Repository/ORM.
