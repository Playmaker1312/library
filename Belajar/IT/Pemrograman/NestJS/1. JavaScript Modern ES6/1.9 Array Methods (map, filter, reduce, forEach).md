## 1.9 Array Methods (map, filter, reduce, forEach)

### Definisi Singkat

**Array Methods** adalah fungsi bawaan JavaScript yang digunakan untuk memanipulasi data di dalam array secara deklaratif (fokus pada _apa_ yang ingin dilakukan, bukan _bagaimana_ urutan teknisnya).

### Analogi

Bayangkan kamu memiliki sebuah **Keranjang Buah** (Array):

- **`forEach`**: Seperti memeriksa setiap buah satu per satu untuk sekadar melihat kondisinya tanpa mengubah posisi atau jumlah buah.
    
- **`map`**: Seperti mengambil setiap buah, lalu mengupasnya. Hasilnya adalah satu keranjang buah yang semuanya sudah terkelupas (ukuran keranjang tetap sama, tapi isinya berubah).
    
- **`filter`**: Seperti memisahkan buah yang busuk. Hasilnya adalah keranjang baru yang hanya berisi buah-buah segar (ukuran keranjang jadi lebih kecil).
    
- **`reduce`**: Seperti memasukkan semua buah ke dalam blender untuk dijadikan satu gelas jus (banyak item diolah menjadi satu nilai tunggal).
    

### Poin-Poin Penting

- **`forEach`**: Digunakan untuk eksekusi sampingan (_side effects_), misalnya mencetak log. Tidak mengembalikan nilai apa pun.
    
- **`map`**: Membuat **array baru** dengan panjang yang sama. Sangat berguna untuk transformasi data.
    
- **`filter`**: Membuat **array baru** yang berisi elemen-elemen yang lolos tes kondisi tertentu.
    
- **`reduce`**: Menjalankan fungsi "akumulator" pada setiap elemen untuk menghasilkan nilai tunggal (angka, string, atau objek baru).
    

### Contoh Implementasi

JavaScript

```
const users = [
    { id: 1, name: 'Andi', role: 'admin', gaji: 5000 },
    { id: 2, name: 'Budi', role: 'user', gaji: 3000 },
    { id: 3, name: 'Cici', role: 'user', gaji: 4000 }
];

// 1. Filter: Ambil yang role-nya 'user' saja
const usersOnly = users.filter(user => user.role === 'user');

// 2. Map: Ambil namanya saja menjadi array of string
const userNames = users.map(user => user.name); 

// 3. Reduce: Hitung total gaji semua user
const totalGaji = users.reduce((total, user) => total + user.gaji, 0);

// 4. ForEach: Cetak pesan ke konsol
users.forEach(user => console.log(`Memproses user: ${user.name}`));
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, metode ini sangat krusial di lapisan _Service_:

1. **Data Transformation (DTO Mapping):** Saat mengambil data dari database, mungkin ada field sensitif (seperti password). Kamu bisa menggunakan `.map()` untuk membuang field tersebut sebelum dikirim ke Controller.
    
2. **Search & Filtering:** Menggunakan `.filter()` untuk mengolah data secara cepat di memori jika data yang diambil tidak terlalu besar.
    
3. **Reporting/Statistics:** Menggunakan `.reduce()` untuk menghitung total transaksi atau rata-rata nilai dari sekumpulan data yang ditarik oleh Repository.
    
4. **Chaining:** Kamu bisa menggabungkan ketiganya: `users.filter(...).map(...).reduce(...)` untuk pengolahan data yang sangat kompleks namun tetap rapi.
