# 1. JavaScript Modern (ES6)

## 1.1. Variabel `let`, `const`, dan `var` serta Scope

**Definisi Singkat:** `var` memiliki function-scope dan bisa di-declare ulang; `let` dan `const` memiliki block-scope. `const` tidak bisa di-reassign.

**Analogi:** `var` seperti papan tulis umum — siapa pun bisa menimpa. `let` seperti locker pribadi. `const` seperti brankas terkunci permanen.

**Poin-Poin Penting:**
- `var` scoped ke function, bukan block — hoisted dengan nilai `undefined`
- `let` block-scoped, bisa diubah, tidak bisa di-declare ulang di scope sama
- `const` block-scoped, harus diinisialisasi, tidak bisa reassign (tapi object/array tetap bisa dimutasi)
- Temporal Dead Zone (TDZ) berlaku untuk `let` dan `const`

**Contoh Kode:**
```typescript
function contohScope() {
  if (true) {
    var a = 'var: visible outside block';
    let b = 'let: only inside block';
    const c = 'const: only inside block';
  }
  console.log(a); // 'var: visible outside block'
  console.log(typeof b); // 'undefined' — reference error jika dijalankan
}

const obj = { nama: 'NestJS' };
obj.nama = 'TypeScript'; // allowed — properti bisa diubah
// obj = {}; // Error: Assignment to constant variable
```

**Kasus Penggunaan Nyata:**
Gunakan `const` untuk sebagian besar deklarasi (module imports, config, service instances), `let` untuk counter/iterator, hindari `var` dalam kode NestJS modern.
