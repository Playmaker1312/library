# 1. JavaScript Modern (ES6)

## 1.10. Optional Chaining (`?.`) dan Nullish Coalescing (`??`)

**Definisi Singkat:** Optional chaining `?.` mengakses properti tanpa error jika parent null/undefined. Nullish coalescing `??` memberikan default hanya untuk `null`/`undefined` (bukan falsy lain).

**Analogi:** Optional chaining seperti senter di gua — jika lorong buntu (null), Anda berhenti tanpa jatuh. Nullish coalescing seperti jaring pengaman — jika kosong, pakai cadangan.

**Poin-Poin Penting:**
- `obj?.prop` — return `undefined` jika `obj` null/undefined, tanpa error
- `obj?.[key]` — bracket notation optional
- `func?.()` — panggil function hanya jika ada
- `a ?? b` — return `b` hanya jika `a` adalah `null` atau `undefined`
- `||` mengembalikan default untuk SEMUA falsy (`''`, `0`, `false`)

**Contoh Kode:**
```typescript
interface Config {
  database?: {
    host?: string;
    port?: number;
    credentials?: {
      user?: string;
    };
  };
}

function getDbHost(config: Config): string {
  // Optional chaining — chain aman tanpa if-bertingkat
  const host = config?.database?.host ?? 'localhost';
  const port = config?.database?.port ?? 5432;
  const user = config?.database?.credentials?.user ?? 'default';

  return `${user}@${host}:${port}`;
}

// Array optional chaining
interface ApiResponse {
  data?: { items?: Array<{ id: number }> };
}

function firstItemId(res: ApiResponse): number | undefined {
  return res?.data?.items?.[0]?.id;
}
```

**Kasus Penggunaan Nyata:**
Mengakses nested config object, optional response API, chaining di template rendering, memberikan default port/config di NestJS. Mencegah `Cannot read property of undefined` errors.
