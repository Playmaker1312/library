# 1. JavaScript Modern (ES6)

## 1.8. Modules: `import` dan `export`

**Definisi Singkat:** ES6 Modules memungkinkan kode dipecah ke file terpisah dengan `export` (mengirim) dan `import` (menerima). Sistem module default di TypeScript/NestJS.

**Analogi:** Seperti perpustakaan — buku (module) diambil dari rak (import), buku ditulis dan diletakkan di rak (export). Setiap rak terorganisir berdasarkan kategori.

**Poin-Poin Penting:**
- `export default` — satu export utama per module
- `export named` — multiple exports dengan nama spesifik
- `import * as alias` — import semua sebagai namespace
- Tree-shaking dengan named exports — hanya ambil yang dipakai
- Relative path `./` atau `../` untuk file lokal

**Contoh Kode:**
```typescript
// auth.service.ts — named exports
export interface JwtPayload {
  userId: number;
  email: string;
}

export class AuthService {
  async validateToken(token: string): Promise<JwtPayload> {
    return { userId: 1, email: 'user@example.com' };
  }
}

// auth.module.ts — import
import { Module } from '@nestjs/common';
import { AuthService } from './auth.service';

@Module({
  providers: [AuthService],
  exports: [AuthService],
})
export class AuthModule {}

// users.controller.ts — import beberapa
import { Controller, Get } from '@nestjs/common';
import { AuthService, JwtPayload } from './auth.service';
```

**Kasus Penggunaan Nyata:**
Setiap file NestJS adalah module — service, controller, module, guard, interceptor semuanya menggunakan ES6 imports. NestJS CLI generate files dengan import statements otomatis.
