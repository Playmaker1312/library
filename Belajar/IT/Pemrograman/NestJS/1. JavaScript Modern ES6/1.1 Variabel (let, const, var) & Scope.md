## 1.1 Variabel (let, const, var) & Scope

### Definisi Singkat

Variabel adalah wadah untuk menyimpan nilai data, sedangkan **Scope** adalah aturan yang menentukan di mana variabel tersebut dapat diakses atau digunakan dalam kode kita. Dalam JS Modern, kita beralih dari `var` ke `let` dan `const` untuk kontrol alur data yang lebih terprediksi.

### Analogi

Bayangkan variabel adalah **label pada kotak penyimpanan** di sebuah gedung kantor:

- **`var`**: Seperti label yang ditempel di lorong utama. Siapa saja di lantai itu bisa melihat dan mengubah isinya, bahkan jika kotak itu seharusnya hanya untuk satu ruangan tertentu.
    
- **`let` & `const`**: Seperti label di dalam loker pribadi. Hanya orang di dalam ruangan tersebut yang bisa melihatnya (**Block Scope**).
    
- **`const`**: Seperti kotak yang isinya sudah disegel mati—kamu tidak bisa mengganti isinya dengan barang lain setelah disimpan.
    

### Poin-Poin Penting

- **`var` (Function Scope):** Variabel yang dideklarasikan dengan `var` dapat diakses di seluruh fungsi tempat ia berada. Ia juga mengalami _hoisting_ (bisa dipanggil sebelum dideklarasikan, meski nilainya `undefined`).
    
- **`let` (Block Scope):** Hanya bisa diakses di dalam kurung kurawal `{ ... }` tempat ia dideklarasikan. Sangat berguna untuk variabel yang nilainya akan berubah, seperti dalam _looping_.
    
- **`const` (Block Scope & Immutable Reference):** Mirip dengan `let`, tapi nilainya tidak bisa diubah (_re-assigned_) setelah didefinisikan. **Catatan:** Jika isinya adalah Object atau Array, properti di dalamnya masih bisa diubah, tapi variabelnya tidak bisa diisi ulang dengan objek baru.
    
- **Global vs Local Scope:** Variabel di luar fungsi bersifat global, sedangkan di dalam fungsi/blok bersifat lokal.
    

### Contoh Implementasi

JavaScript

```
// Penggunaan const untuk nilai tetap
const PORT = 3000; 

// Penggunaan let untuk nilai yang berubah
let counter = 0;
counter += 1;

function testScope() {
    if (true) {
        var functionScoped = "Saya var, saya bocor keluar blok if!";
        let blockScoped = "Saya let, saya aman di dalam sini.";
        console.log(blockScoped);
    }
    console.log(functionScoped); // Berhasil dipanggil
    // console.log(blockScoped); // Error: blockScoped is not defined
}

testScope();
```

### Koneksi dengan Web Development (NestJS)

Dalam pengembangan **NestJS**, pemahaman ini sangat vital karena:

1. **Keamanan State:** Kita hampir selalu menggunakan `const` untuk mengimpor _module_, _service_, atau _controller_ agar tidak sengaja tertimpa di tengah jalan.
    
2. **Dependency Injection:** Saat kita menyuntikkan (inject) _service_ ke dalam _constructor_, kita biasanya menggunakan akses `private readonly`, yang secara konsep mirip dengan `const` di level _class_.
    
3. **Clean Code:** Menghindari `var` mencegah _bug_ aneh akibat variabel yang "bocor" antar blok logika, yang sering terjadi pada aplikasi skala besar seperti NestJS.
