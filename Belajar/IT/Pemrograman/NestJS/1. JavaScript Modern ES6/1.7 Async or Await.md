## 1.7 Async & Await

### Definisi Singkat

**Async/Await** adalah _syntactic sugar_ (cara penulisan yang lebih manis) di atas Promises. Ia memungkinkan kita menulis kode asinkronus dengan gaya penulisan kode sinkronus (berurutan dari atas ke bawah), sehingga lebih mudah dibaca dan dikelola.

### Analogi

Bayangkan kamu sedang berada di **Layanan Drive-Thru**:

- **Promise (`.then`)**: Kamu memesan, lalu diberi struk. Kamu harus terus melihat struk itu dan menunggu instruksi "Jika sudah bunyi, maka lakukan X". Kamu harus menyiapkan rencana cadangan secara terpisah jika pesanan gagal.
    
- **Async/Await**: Kamu memesan dan berkata pada diri sendiri, "**Tunggu** di sini sampai burger datang." Kamu tidak melakukan apa pun sampai burger ada di tangan. Jika terjadi kesalahan (misal: burger habis), kamu langsung berteriak (menggunakan `try-catch`). Kamu tidak perlu mengelola struk atau instruksi "Jika-Maka" yang rumit; kamu cukup menunggu prosesnya selesai sebelum lanjut ke langkah berikutnya.
    

### Poin-Poin Penting

- **`async` Keyword**: Digunakan sebelum deklarasi fungsi. Fungsi yang ditandai `async` secara otomatis akan selalu mengembalikan sebuah **Promise**.
    
- **`await` Keyword**: Hanya bisa digunakan di dalam fungsi `async`. Ia memerintahkan JavaScript untuk "menunggu" hingga Promise selesai (_resolved_) sebelum mengeksekusi baris kode berikutnya.
    
- **Error Handling**: Tidak lagi menggunakan `.catch()`, melainkan menggunakan blok **`try...catch`** yang jauh lebih familiar bagi programmer.
    
- **Clean Code**: Menghilangkan "Chaining" atau deretan `.then()` yang panjang, membuat alur logika terlihat linear.
    

### Contoh Implementasi

JavaScript

```
// Simulasi fungsi mengambil data dari database (Promise)
const getDatabaseUser = (id) => {
    return new Promise((resolve) => {
        setTimeout(() => resolve({ id, name: 'Gemini User' }), 1000);
    });
};

// --- Implementasi Async/Await ---
async function displayUser() {
    try {
        console.log("Mencari user...");
        
        // Menunggu hasil promise tanpa .then()
        const user = await getDatabaseUser(1); 
        
        console.log(`User ditemukan: ${user.name}`);
    } catch (error) {
        // Menangani error jika promise rejected
        console.error("Terjadi kesalahan:", error);
    }
}

displayUser();
```

### Koneksi dengan Web Development (NestJS)

Di dalam **NestJS**, kamu akan menggunakan ini hampir di mana saja:

1. **Controller Methods**: Hampir semua method di Controller bersifat `async`.
    
    - `async findAll(): Promise<User[]> { return await this.userService.findAll(); }`
        
2. **Service Layer**: Saat memanggil database atau API eksternal, kamu menggunakan `await` untuk memastikan data sudah didapat sebelum melakukan manipulasi data lebih lanjut.
    
3. **Database Transaction**: Mengelola transaksi database yang kompleks menjadi sangat mudah dibaca dengan urutan `await` yang jelas, daripada terjebak dalam _callback hell_.
