## 1.3 Destructuring (Object & Array)

### Definisi Singkat

**Destructuring** adalah cara ringkas untuk mengekstrak atau "membongkar" nilai dari properti objek atau elemen array ke dalam variabel terpisah hanya dalam satu baris kode.

### Analogi

Bayangkan kamu memesan **Paket Makanan Komplit** (Object/Array).

- **Tanpa Destructuring:** Kamu harus mengambil satu per satu: ambil ayamnya taruh piring A, ambil nasinya taruh piring B, ambil sambalnya taruh piring C.
    
- **Dengan Destructuring:** Kamu punya "nampan khusus" yang sudah ada cetakan bentuknya. Begitu paket datang, kamu cukup menempelkan nampan itu, dan ayam, nasi, serta sambal langsung berpindah ke lubang masing-masing secara otomatis.
    

### Poin-Poin Penting

- **Object Destructuring:** Menggunakan kurung kurawal `{}`. Nama variabel **harus sama** dengan nama properti di dalam objek (kecuali menggunakan alias).
    
- **Array Destructuring:** Menggunakan kurung siku `[]`. Pengambilan nilai berdasarkan **urutan (indeks)**, bukan nama.
    
- **Default Values:** Kamu bisa menentukan nilai default jika properti yang diekstrak ternyata tidak ada (`undefined`).
    
- **Rest Operator (`...`):** Sering dikombinasikan dengan destructuring untuk mengambil "sisa" elemen atau properti yang tidak disebutkan secara spesifik.
    

### Contoh Implementasi

JavaScript

```
// --- 1. Object Destructuring ---
const user = {
    id: 101,
    username: 'gemini_user',
    email: 'user@example.com'
};

// Mengambil username dan email saja
const { username, email } = user;
console.log(username); // Output: gemini_user

// Menggunakan Alias dan Default Value
const { id: userId, role = 'guest' } = user;
console.log(userId); // Output: 101 (id berubah jadi variabel userId)
console.log(role);   // Output: guest (karena di objek user tidak ada role)


// --- 2. Array Destructuring ---
const koordinat = [10, 20, 30];

// Mengambil berdasarkan urutan
const [x, y] = koordinat; 
console.log(x, y); // Output: 10 20

// Mengambil sisa dengan Rest Operator
const [first, ...others] = koordinat;
console.log(others); // Output: [20, 30]
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, teknik ini adalah "makanan sehari-hari" karena:

1. **Request Handling:** Saat kamu menerima data dari Client di Controller, kamu sering melakukan destructuring pada `@Body()` untuk mengambil field tertentu saja.
    
    - `create(@Body() { name, email }: CreateUserDto) { ... }`
        
2. **Config Service:** Mengambil variabel lingkungan (env) dari objek konfigurasi besar secara efisien.
    
3. **Module Imports:** Saat melakukan _import_ class dari library NestJS, kamu sebenarnya sedang melakukan destructuring dari package tersebut.
    
    - `import { Controller, Get, Post } from '@nestjs/common';`
