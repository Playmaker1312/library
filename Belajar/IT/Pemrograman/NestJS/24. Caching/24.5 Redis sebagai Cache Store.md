# 24. Caching

## 24.5. Redis sebagai Cache Store

**Definisi Singkat:**
Redis adalah in-memory data store yang sering digunakan sebagai distributed cache, mendukung berbagai struktur data dan fitur advanced seperti persistence, replication, dan cluster untuk caching skala besar.

**Analogi:**
Jika in-memory cache seperti kulkas di rumahmu sendiri, Redis seperti gudang pendingin pusat yang bisa diakses oleh banyak rumah (aplikasi/instances) sekaligus.

**Poin-Poin Penting:**
- Package: `cache-manager-redis-store` atau `cache-manager-redis-yet`
- Mendukung distributed caching (multiple app instances)
- Data tetap ada meskipun aplikasi restart
- Mendukung TTL, Pub/Sub, Lua scripts
- Cocok untuk microservices dan cluster environment
- Fitur tambahan: persistence, replication, sentinel, cluster

**Contoh Kode:**

// Service menggunakan Redis Cache
import { Injectable, Inject } from '@nestjs/common';
import { Cache } from 'cache-manager';
import { CACHE_MANAGER } from '@nestjs/cache-manager';

@Injectable()
export class ProductService {
  constructor(@Inject(CACHE_MANAGER) private cacheManager: Cache) {}

  // Get with cache-aside pattern
  async getProduct(id: number): Promise<any> {
    const cacheKey = `products:${id}`;
    
    // Coba dapatkan dari Redis
    const cached = await this.cacheManager.get<any>(cacheKey);
    
    if (cached) {
      console.log('Cache HIT - Redis');
      return cached;
    }

    console.log('Cache MISS - Querying Database');
    const product = await this.fetchFromDatabase(id);
    
    // Simpan ke Redis
    await this.cacheManager.set(cacheKey, product, 300000); // 5 menit
    
    return product;
  }

  // Menggunakan Redis native methods (jika butuh)
  async getProductWithRedisNative(): Promise<any> {
    // Akses redis client secara langsung
    const redisClient = (this.cacheManager.store as any).getClient();
    
    // Gunakan Redis commands langsung
    const cached = await redisClient.get('products:123');
    
    if (cached) {
      return JSON.parse(cached);
    }
    
    return null;
  }

  // Cache dengan TTL berbeda
  async createProduct(data: any): Promise<any> {
    const product = await this.saveToDatabase(data);
    
    // Cache product baru
    await this.cacheManager.set(`products:${product.id}`, product, 600000); // 10 menit
    
    // Invalidate cache list
    await this.cacheManager.del('products:list');
    await this.cacheManager.del('products:featured');
    
    return product;
  }

  // Bulk operations
  async getMultipleProducts(ids: number[]): Promise<any[]> {
    const results = [];
    const cacheKeys = ids.map(id => `products:${id}`);
    
    // Coba dapatkan dari cache dulu
    for (let i = 0; i < ids.length; i++) {
      const cached = await this.cacheManager.get<any>(cacheKeys[i]);
      if (cached) {
        results.push(cached);
      } else {
        const product = await this.fetchFromDatabase(ids[i]);
        await this.cacheManager.set(cacheKeys[i], product);
        results.push(product);
      }
    }
    
    return results;
  }

  private async fetchFromDatabase(id: number) {
    return { id, name: `Product ${id}`, price: 100000 };
  }

  private async saveToDatabase(data: any) {
    return { id: Date.now(), ...data };
  }
}

// Health Check untuk Redis
import { Injectable } from '@nestjs/common';
import { HealthIndicator, HealthCheckError } from '@nestjs/terminus';
import { Cache } from 'cache-manager';
import { CACHE_MANAGER } from '@nestjs/cache-manager';
import { Inject } from '@nestjs/common';

@Injectable()
export class RedisHealthIndicator extends HealthIndicator {
  constructor(@Inject(CACHE_MANAGER) private cacheManager: Cache) {
    super();
  }

  async isHealthy(key: string) {
    try {
      // Test connection dengan SET/GET
      const testKey = 'health:check';
      await this.cacheManager.set(testKey, 'ok', 10000);
      const result = await this.cacheManager.get(testKey);
      
      const isHealthy = result === 'ok';
      
      return this.getStatus(key, isHealthy, {
        message: isHealthy ? 'Redis connection healthy' : 'Redis connection failed',
      });
    } catch (error) {
      throw new HealthCheckError(
        'Redis check failed',
        this.getStatus(key, false, { message: error.message }),
      );
    }
  }
}

// Contoh pattern dengan Redis
const redisPatterns = {

  rateLimit: (clientId: string) => `ratelimit:${clientId}`,

**Kasus Penggunaan Nyata:**
- **Microservices Architecture**: 3 instance API Gateway menggunakan Redis sebagai shared cache, sehingga request yang sama ke instance manapun mendapatkan cache hit
- **Session Management**: Menyimpan session user di Redis sehingga tidak perlu sticky session di load balancer
- **Rate Limiting**: Menggunakan Redis untuk rate limiting API yang terdistribusi
- **Leaderboard/Counter**: Menggunakan Redis Sorted Set untuk real-time leaderboard di game
- **Pub/Sub untuk Cache Invalidation**: Ketika data berubah di satu service, kirim pesan ke Redis Pub/Sub untuk meng-invalidate cache di semua instance
