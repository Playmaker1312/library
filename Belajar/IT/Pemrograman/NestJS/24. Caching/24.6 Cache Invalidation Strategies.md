# 24. Caching

## 24.6. Cache Invalidation Strategies

**Definisi Singkat:**
Cache Invalidation Strategies adalah teknik-teknik untuk menghapus atau memperbarui data cache yang sudah tidak valid (stale) ketika data asli di database berubah, agar pengguna selalu mendapatkan data yang akurat.

**Analogi:**
Seperti memperbarui papan pengumuman di sekolah - ketika ada perubahan jadwal, papan lama harus dihapus atau diganti dengan yang baru agar siswa tidak datang di waktu yang salah.

**Poin-Poin Penting:**
- Cache invalidation adalah salah satu masalah tersulit di CS
- Strategi: Cache-Aside, Write-Through, Write-Behind, Time-to-Live (TTL)
- Decorator `@CacheEvict()` dan `@CachePut()`
- Pattern: Cache Stampede Prevention
- Penting untuk menghindari stale data sambil tetap mendapatkan manfaat caching

**Contoh Kode:**
```typescript
import { Injectable, Inject } from '@nestjs/common';
import { Cache } from 'cache-manager';
import { CACHE_MANAGER } from '@nestjs/cache-manager';

// ========== STRATEGI 1: CACHE-ASIDE (LAZY LOADING) ==========
// Cache di-update hanya ketika dibutuhkan (saat ada request)
@Injectable()
export class CacheAsideStrategy {
  constructor(@Inject(CACHE_MANAGER) private cacheManager: Cache) {}

  async getProduct(id: number): Promise<any> {
    const cacheKey = `products:${id}`;
    
    // 1. Cek cache terlebih dahulu
    let product = await this.cacheManager.get<any>(cacheKey);
    
    if (product) {
      return product; // Cache HIT
    }
    
    // 2. Cache MISS - ambil dari database
    product = await this.fetchFromDatabase(id);
    
    if (product) {
      // 3. Simpan ke cache untuk request berikutnya
      await this.cacheManager.set(cacheKey, product, 300000); // 5 menit TTL
    }
    
    return product;
  }

  // Invalidate cache saat update
  async updateProduct(id: number, data: any): Promise<any> {
    // 1. Update database
    const updatedProduct = await this.updateInDatabase(id, data);
    
    // 2. Hapus cache yang sudah stale
    const cacheKey = `products:${id}`;
    await this.cacheManager.del(cacheKey);
    
    // Tambahan: hapus juga cache list yang mengandung product ini
    await this.cacheManager.del('products:list');
    await this.cacheManager.del('products:featured');
    
    return updatedProduct;
  }

  private async fetchFromDatabase(id: number) {
    return { id, name: 'Product ' + id };
  }

  private async updateInDatabase(id: number, data: any) {
    return { id, ...data };
  }
}

// ========== STRATEGI 2: WRITE-THROUGH CACHING ==========
// Cache di-update SECARA BERSAMAAN dengan database
@Injectable()
export class WriteThroughStrategy {
  constructor(@Inject(CACHE_MANAGER) private cacheManager: Cache) {}

  async createProduct(data: any): Promise<any> {
    // 1. Simpan ke database
    const product = await this.saveToDatabase(data);
    
    // 2. Langsung simpan ke cache (write-through)
    const cacheKey = `products:${product.id}`;
    await this.cacheManager.set(cacheKey, product, 600000); // 10 menit
    
    return product;
  }

  async updateProduct(id: number, data: any): Promise<any> {
    // 1. Update database
    const updatedProduct = await this.updateInDatabase(id, data);
    
    // 2. Update cache secara langsung (bukan delete)
    const cacheKey = `products:${id}`;
    await this.cacheManager.set(cacheKey, updatedProduct);
    
    return updatedProduct;
  }

  private async saveToDatabase(data: any) {
    return { id: Date.now(), ...data };
  }

  private async updateInDatabase(id: number, data: any) {
    return { id, ...data };
  }
}

// ========== STRATEGI 3: TTL-BASED INVALIDATION ==========
// Invalidate otomatis berdasarkan waktu (sederhana tapi bisa stale)
@Injectable()
export class TtlBasedStrategy {
  constructor(@Inject(CACHE_MANAGER) private cacheManager: Cache) {}

  // Data yang jarang berubah - TTL panjang
  async getCategories(): Promise<any[]> {
    const cacheKey = 'categories:all';
    
    let categories = await this.cacheManager.get<any[]>(cacheKey);
    
    if (!categories) {
      categories = await this.fetchCategories();
      // TTL 1 jam - kategori jarang berubah
      await this.cacheManager.set(cacheKey, categories, 3600000);
    }
    
    return categories;
  }

  // Data yang sering berubah - TTL pendek
  async getLiveStockPrices(): Promise<any[]> {
    const cacheKey = 'stocks:live';
    
    let prices = await this.cacheManager.get<any[]>(cacheKey);
    
    if (!prices) {
      prices = await this.fetchStockPrices();
      // TTL 10 detik - harga saham berubah cepat
      await this.cacheManager.set(cacheKey, prices, 10000);
    }
    
    return prices;
  }

  private async fetchCategories() {
    return [{ id: 1, name: 'Electronics' }];
  }

  private async fetchStockPrices() {
    return [{ symbol: 'AAPL', price: 175.50 }];
  }
}

// ========== STRATEGI 4: CACHE EVICT DENGAN DECORATOR ==========
import { CacheEvict, CachePut, Cacheable } from '@nestjs/cache-manager';

@Injectable()
export class DecoratorBasedStrategy {
  private products = [];

  @Cacheable({ key: 'products:all', ttl: 300 })
  async findAll(): Promise<any[]> {
    console.log('Querying database...');
    return this.products;
  }

  @Cacheable({ key: 'product_{id}', ttl: 600 })
  async findOne(id: number): Promise<any> {
    console.log(`Querying database for id: ${id}`);
    return this.products.find(p => p.id === id);
  }

  // @CachePut: Update cache setelah operasi
  @CachePut({ key: 'product_{id}' })
  async update(id: number, data: any): Promise<any> {
    const index = this.products.findIndex(p => p.id === id);
    if (index !== -1) {
      this.products[index] = { ...this.products[index], ...data };
    }
    return this.products[index];
  }

  // @CacheEvict: Hapus cache setelah operasi
  @CacheEvict({ key: 'products:all' })
  async create(data: any): Promise<any> {
    const newProduct = { id: Date.now(), ...data };
    this.products.push(newProduct);
    return newProduct;
  }

  // Hapus multiple cache keys
  @CacheEvict({ keys: ['products:all', 'products:featured', 'products:new'] })
  async bulkUpdate(updates: any[]): Promise<void> {
    // Logic bulk update
  }

  // Hapus berdasarkan pattern (wildcard)
  @CacheEvict({ pattern: 'products:*' })
  async clearAllProductsCache(): Promise<void> {
    // Menghapus semua cache dengan prefix 'products:'
  }
}

// ========== STRATEGI 5: PREVENTING CACHE STAMPEDE ==========
// Masalah: Banyak request serentak saat cache miss, semua query DB
@Injectable()
export class CacheStampedePrevention {
  constructor(@Inject(CACHE_MANAGER) private cacheManager: Cache) {}

  private locks = new Map<string, Promise<any>>();

  // Strategi 1: Lock / Mutex per key
  async getProductWithLock(id: number): Promise<any> {
    const cacheKey = `products:${id}`;
    const lockKey = `lock:${cacheKey}`;

    // Cek cache dulu
    const cached = await this.cacheManager.get<any>(cacheKey);
    if (cached) return cached;

    // Cek apakah ada lock untuk key ini
    if (this.locks.has(lockKey)) {
      // Request lain sedang mengambil data - tunggu hasilnya
      return this.locks.get(lockKey);
    }

    // Buat promise baru sebagai lock
    const fetchPromise = this.fetchFromDatabase(id)
      .then(async (product) => {
        // Simpan ke cache
        await this.cacheManager.set(cacheKey, product, 300000);
        // Hapus lock
        this.locks.delete(lockKey);
        return product;
      })
      .catch((error) => {
        this.locks.delete(lockKey);
        throw error;
      });

    // Simpan lock
    this.locks.set(lockKey, fetchPromise);
    
    return fetchPromise;
  }

  // Strategi 2: Early TTL Refresh
  async getProductWithEarlyRefresh(id: number): Promise<any> {
    const cacheKey = `products:${id}`;
    
    // Simpan metadata bersama data (waktu expiry)
    const wrapper = await this.cacheManager.get<any>(cacheKey);
    
    if (wrapper) {
      const { data, expiresAt } = wrapper;
      const timeUntilExpiry = expiresAt - Date.now();
      
      // Jika sisa 30 detik lagi, refresh di background
      if (timeUntilExpiry < 30000 && timeUntilExpiry > 0) {
        // Refresh tanpa menunggu (fire and forget)
        this.refreshCacheInBackground(id, cacheKey);
      }
      
      return data;
    }
    
    // Cache miss - ambil dan simpan
    return this.refreshCacheInBackground(id, cacheKey);
  }

  private async refreshCacheInBackground(id: number, cacheKey: string) {
    const data = await this.fetchFromDatabase(id);
    const wrapper = {
      data,
      expiresAt: Date.now() + 300000, // 5 menit dari sekarang
    };
    await this.cacheManager.set(cacheKey, wrapper);
    return data;
  }

  private async fetchFromDatabase(id: number) {
    return { id, name: 'Product ' + id };
  }
}
```

**Kasus Penggunaan Nyata:**
1. **E-commerce Product Catalog**: Menggunakan Cache-Aside dengan TTL 5 menit, ditambah explicit invalidation ketika admin mengupdate produk
2. **Real-time Dashboard**: Menggunakan TTL pendek (10-30 detik) untuk data yang selalu berubah tanpa perlu explicit invalidation
3. **High-Traffic Flash Sale**: Menggunakan Cache Stampede Prevention (locking + early refresh) untuk mencegah ribuan request menembus database saat cache miss
4. **User Session Management**: Write-through - setiap update session langsung disimpan ke database dan cache
5. **Multi-region Cache**: Menggunakan Redis Pub/Sub untuk broadcast invalidasi ke semua region ketika data berubah
