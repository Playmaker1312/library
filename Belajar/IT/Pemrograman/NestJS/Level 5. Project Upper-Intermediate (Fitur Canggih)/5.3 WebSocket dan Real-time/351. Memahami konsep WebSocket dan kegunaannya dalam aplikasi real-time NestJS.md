# 351. Memahami konsep WebSocket dan kegunaannya dalam aplikasi real-time NestJS

## Definisi & Target
WebSocket adalah protokol komunikasi full-duplex yang memungkinkan pertukaran data real-time antara client dan server melalui satu koneksi persisten, berbeda dengan HTTP yang bersifat request-response.

## Konsep Dasar
- **Full-duplex**: Server dan client bisa kirim data kapan saja
- **Persistent connection**: Koneksi tetap terbuka, tidak seperti HTTP yang dibuka-tutup
- **Low latency**: Tidak ada overhead HTTP handshake setiap request
- **Event-driven**: Komunikasi berbasis event

## Kegunaan WebSocket dalam NestJS
| Use Case | Contoh |
|----------|--------|
| Chat aplikasi | Pesan real-time antar user |
| Live notification | Notifikasi muncul tanpa refresh |
| Real-time dashboard | Data update grafik/table otomatis |
| Collaborative editing | Google Docs-style collaboration |
| Live tracking | GPS tracking, delivery status |
| Gaming | Game state synchronization |
| Financial data | Stock price ticker |

## Perbandingan HTTP vs WebSocket
```
HTTP: Client -> Request -> Server -> Response -> Close
WS:   Client ----connect----> Server (persistent)
      Client <---bi-directional---> Server (real-time)
```
