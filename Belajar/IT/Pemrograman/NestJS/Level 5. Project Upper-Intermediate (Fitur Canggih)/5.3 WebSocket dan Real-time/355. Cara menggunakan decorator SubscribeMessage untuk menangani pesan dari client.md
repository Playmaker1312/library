# 355. Cara menggunakan decorator SubscribeMessage untuk menangani pesan dari client

## Definisi & Target
Decorator `@SubscribeMessage()` menangani event tertentu yang dikirim client, memungkinkan gateway merespon pesan spesifik.

## Komponen
File yang dimodifikasi: `src/chat/chat.gateway.ts`

## Kode Implementasi

```typescript
// src/chat/chat.gateway.ts (Gateway)
import { WebSocketGateway, SubscribeMessage } from '@nestjs/websockets';
import { Socket } from 'socket.io';

@WebSocketGateway({ cors: { origin: '*' } })
export class ChatGateway {
  @SubscribeMessage('message')
  handleMessage(client: Socket, payload: { room: string; text: string }) {
    console.log(`Message from ${client.id}: ${payload.text}`);
    return {
      event: 'message',
      data: {
        from: client.id,
        text: payload.text,
        timestamp: Date.now(),
      },
    };
  }

  @SubscribeMessage('join')
  handleJoin(client: Socket, payload: { room: string }) {
    client.join(payload.room);
    return { status: 'joined', room: payload.room };
  }

  @SubscribeMessage('leave')
  handleLeave(client: Socket, payload: { room: string }) {
    client.leave(payload.room);
    return { status: 'left', room: payload.room };
  }

  @SubscribeMessage('typing')
  handleTyping(client: Socket, payload: { room: string; isTyping: boolean }) {
    client.to(payload.room).emit('typing', {
      userId: client.id,
      isTyping: payload.isTyping,
    });
  }
}
```

## Return Value dari Handler
| Return Type | Behavior |
|-------------|----------|
| `string` / `object` | Dikirim sebagai response event (acknowledgement) |
| `void` / `undefined` | Tidak ada response otomatis |
| `Observable` | Multiple responses over time |
