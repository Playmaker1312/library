# 352. Cara menginstal package @nestjs/websockets dan @nestjs/platform-socket.io

## Definisi & Target
Menginstal package resmi NestJS untuk WebSocket dengan Socket.IO, framework WebSocket paling populer untuk Node.js.

## Perintah Instalasi
```bash
npm install @nestjs/websockets @nestjs/platform-socket.io socket.io
npm install --save-dev @types/socket.io
```

## Daftar Package
| Package | Fungsi |
|---------|--------|
| `@nestjs/websockets` | Modul WebSocket resmi NestJS |
| `@nestjs/platform-socket.io` | Adapter Socket.IO untuk NestJS |
| `socket.io` | Library WebSocket untuk server dan client |
| `@types/socket.io` | Type definitions |

## Konfigurasi main.ts
```typescript
// src/main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.enableCors({
    origin: ['http://localhost:3001'],
    credentials: true,
  });
  await app.listen(3000);
  console.log(`Application is running on: ${await app.getUrl()}`);
}
bootstrap();
```

## Verifikasi Instalasi
```bash
nest info
# Pastikan @nestjs/websockets terdaftar di dependencies
```
