# 353. Cara membuat Gateway menggunakan decorator WebSocketGateway

## Definisi & Target
Membuat WebSocket gateway menggunakan decorator `@WebSocketGateway()` yang bertindak sebagai entry point untuk semua koneksi WebSocket.

## Komponen & Nest CLI Command
```bash
nest g mo chat
nest g ga chat/chat
```

## Kode Implementasi

```typescript
// src/chat/chat.gateway.ts (Gateway)
import { WebSocketGateway, WebSocketServer, SubscribeMessage, OnGatewayConnection, OnGatewayDisconnect } from '@nestjs/websockets';
import { Server, Socket } from 'socket.io';

@WebSocketGateway({
  cors: {
    origin: '*',
    credentials: true,
  },
})
export class ChatGateway implements OnGatewayConnection, OnGatewayDisconnect {
  @WebSocketServer()
  server: Server;

  handleConnection(client: Socket) {
    console.log(`Client connected: ${client.id}`);
    client.emit('connected', { message: 'Welcome to the chat!' });
  }

  handleDisconnect(client: Socket) {
    console.log(`Client disconnected: ${client.id}`);
  }
}
```

```typescript
// src/chat/chat.module.ts (Module)
import { Module } from '@nestjs/common';
import { ChatGateway } from './chat.gateway';

@Module({
  providers: [ChatGateway],
})
export class ChatModule {}
```

## Opsi WebSocketGateway
| Option | Type | Keterangan |
|--------|------|------------|
| `namespace` | `string` | Namespace Socket.IO |
| `cors` | `object` | CORS configuration |
| `port` | `number` | Port berbeda dari HTTP (opsional) |
| `path` | `string` | Custom path untuk WS |

## Cara Integrasi & Pengujian
```bash
# Client test dengan browser console
const socket = io('http://localhost:3000');
socket.on('connect', () => console.log('Connected:', socket.id));
socket.on('connected', (data) => console.log(data.message));
```
