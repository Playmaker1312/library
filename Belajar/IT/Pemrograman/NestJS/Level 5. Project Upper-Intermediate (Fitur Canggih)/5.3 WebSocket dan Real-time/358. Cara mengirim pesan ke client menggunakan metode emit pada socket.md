# 358. Cara mengirim pesan ke client menggunakan metode emit pada socket

## Definisi & Target
Mengirim pesan ke client spesifik menggunakan method `client.emit()` untuk komunikasi one-to-one, berguna untuk notifikasi personal.

## Komponen
File yang dimodifikasi: `src/chat/chat.gateway.ts`

## Kode Implementasi

```typescript
// src/chat/chat.gateway.ts (Gateway)
import { WebSocketGateway, SubscribeMessage, ConnectedSocket } from '@nestjs/websockets';
import { Socket } from 'socket.io';

@WebSocketGateway({ cors: { origin: '*' } })
export class ChatGateway {
  @SubscribeMessage('ping')
  handlePing(@ConnectedSocket() client: Socket) {
    client.emit('pong', { message: 'Server is alive', timestamp: Date.now() });
  }

  @SubscribeMessage('request-notification')
  async handleRequestNotification(@ConnectedSocket() client: Socket) {
    for (let i = 1; i <= 3; i++) {
      await new Promise((resolve) => setTimeout(resolve, 1000));
      client.emit('notification', {
        id: i,
        title: `Notification ${i}`,
        message: `This is notification number ${i}`,
      });
    }
    client.emit('notification-complete', { count: 3 });
  }
}
```

```typescript
import { Server } from 'socket.io';

@WebSocketGateway({ cors: { origin: '*' } })
export class NotificationGateway {
  @WebSocketServer()
  server: Server;

  sendToUser(userId: string, event: string, data: any) {
    const socketId = this.getUserSocket(userId);
    if (socketId) {
      this.server.to(socketId).emit(event, data);
    }
```

## Method Emit
| Method | Target |
|--------|--------|
| `client.emit(event, data)` | Socket spesifik |
| `client.broadcast.emit(event, data)` | Semua kecuali pengirim |
| `server.emit(event, data)` | Semua client |
| `server.to(room).emit(event, data)` | Semua di room |

## Cara Integrasi & Pengujian
```javascript
const socket = io('http://localhost:3000');
socket.emit('ping');
socket.on('pong', (data) => console.log('Pong:', data));

socket.emit('request-notification');
socket.on('notification', (data) => console.log('Notif:', data));
socket.on('notification-complete', (data) => console.log('Done:', data));
```
