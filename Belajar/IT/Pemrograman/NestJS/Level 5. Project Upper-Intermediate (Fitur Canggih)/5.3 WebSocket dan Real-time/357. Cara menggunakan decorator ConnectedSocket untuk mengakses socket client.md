# 357. Cara menggunakan decorator ConnectedSocket untuk mengakses socket client

## Definisi & Target
Decorator `@ConnectedSocket()` digunakan untuk mengakses instance Socket client yang mengirim pesan, untuk mengirim response pribadi atau mengelola koneksi.

## Komponen
File yang dimodifikasi: `src/chat/chat.gateway.ts`

## Kode Implementasi

```typescript
// src/chat/chat.gateway.ts (Gateway)
import { WebSocketGateway, SubscribeMessage, MessageBody, ConnectedSocket } from '@nestjs/websockets';
import { Socket } from 'socket.io';

@WebSocketGateway({ cors: { origin: '*' } })
export class ChatGateway {
  @SubscribeMessage('private-message')
  handlePrivateMessage(
    @MessageBody() payload: { to: string; text: string },
    @ConnectedSocket() client: Socket,
  ) {
    client.broadcast.to(payload.to).emit('private-message', {
      from: client.id,
      text: payload.text,
    });
    return { sent: true, to: payload.to };
  }

  @SubscribeMessage('get-my-id')
  handleGetMyId(@ConnectedSocket() client: Socket) {
    return { id: client.id };
  }

  @SubscribeMessage('disconnect-me')
  async handleDisconnectMe(@ConnectedSocket() client: Socket) {
    client.disconnect();
    return { disconnected: true };
  }

  @SubscribeMessage('set-nickname')
  handleSetNickname(
    @ConnectedSocket() client: Socket,
    @MessageBody('nickname') nickname: string,
  ) {
    client.data.nickname = nickname;
    return { nickname: client.data.nickname };
  }
}
```

## Property Socket yang Berguna
| Property | Tipe | Deskripsi |
|----------|------|-----------|
| `client.id` | `string` | ID unik socket |
| `client.rooms` | `Set<string>` | Rooms yang diikuti |
| `client.data` | `any` | Data khusus socket |
| `client.handshake` | `object` | Info handshake (headers, query) |
| `client.conn` | `object` | Koneksi transport |

## Cara Integrasi & Pengujian
```javascript
const socket = io('http://localhost:3000');
```
