# 356. Cara menggunakan decorator MessageBody untuk mengakses payload pesan

## Definisi & Target
Decorator `@MessageBody()` digunakan untuk mengekstrak payload yang dikirim client secara type-safe, mirip dengan `@Body()` pada controller HTTP.

## Komponen
File yang dimodifikasi: `src/chat/chat.gateway.ts`

## Kode Implementasi

```typescript
// src/chat/chat.gateway.ts (Gateway)
import { WebSocketGateway, SubscribeMessage, MessageBody } from '@nestjs/websockets';
import { Socket } from 'socket.io';

interface ChatMessage {
  room: string;
  text: string;
  sender: string;
}

@WebSocketGateway({ cors: { origin: '*' } })
export class ChatGateway {
  @SubscribeMessage('send-message')
  handleSendMessage(
    @MessageBody() payload: ChatMessage,
  ) {
    console.log(`[${payload.room}] ${payload.sender}: ${payload.text}`);
    return {
      success: true,
      message: payload,
    };
  }

  @SubscribeMessage('send-typing')
  handleTyping(
    @MessageBody('isTyping') isTyping: boolean,
    @MessageBody('room') room: string,
  ) {
    console.log(`User is ${isTyping ? 'typing' : 'stopped'} in ${room}`);
    return { isTyping, room };
  }

  @SubscribeMessage('update-profile')
  handleUpdateProfile(
    @MessageBody() body: { name: string; avatar: string },
  ) {
    return { updated: true, ...body };
  }
}
```

## Perbandingan Parameter
| Decorator | Mengambil | Contoh |
|-----------|-----------|--------|
| `@MessageBody()` | Seluruh payload | `{ room: 'a', text: 'hi' }` |
| `@MessageBody('room')` | Properti spesifik | `'a'` |
| `@Payload()` | Alias dari MessageBody | Sama |

## Cara Integrasi & Pengujian
```javascript
const socket = io('http://localhost:3000');
socket.emit('send-message', { room: 'general', text: 'Hello!', sender: 'Alice' });

socket.emit('send-typing', { isTyping: true, room: 'general' });

socket.emit('update-profile', { name: 'Alice', avatar: 'alice.jpg' });
```
