# 364. Cara menggunakan adapter Redis untuk Socket.io scaling horizontal

## Definisi & Target
Redis adapter memungkinkan Socket.io berbagi state antar instance server (horizontal scaling), sehingga pesan dari satu server bisa diteruskan ke client di server lain.

## Komponen & Perintah Instalasi
```bash
npm install @socket.io/redis-adapter ioredis
```

## Kode Implementasi

```typescript
// src/main.ts (Main with Redis adapter)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { IoAdapter } from '@nestjs/platform-socket.io';
import { createAdapter } from '@socket.io/redis-adapter';
import Redis from 'ioredis';

class RedisIoAdapter extends IoAdapter {
  createIOServer(port: number, options?: any) {
    const server = super.createIOServer(port, {
      ...options,
      cors: { origin: '*' },
    });

    const pubClient = new Redis({
      host: process.env.REDIS_HOST || 'localhost',
      port: parseInt(process.env.REDIS_PORT, 10) || 6379,
    });

    const subClient = pubClient.duplicate();

    server.adapter(createAdapter(pubClient, subClient));
    return server;
  }
}

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.useWebSocketAdapter(new RedisIoAdapter(app));
  await app.listen(3000);
}
bootstrap();
```

```typescript
// src/chat/chat.gateway.ts (Gateway - unchanged, works across instances)
import { WebSocketGateway, WebSocketServer, SubscribeMessage } from '@nestjs/websockets';
import { Server, Socket } from 'socket.io';

@WebSocketGateway({ cors: { origin: '*' } })
export class ChatGateway {
  @WebSocketServer()
  server: Server;

  @SubscribeMessage('message')
  handleMessage(client: Socket, payload: { room: string; text: string }) {
    this.server.to(payload.room).emit('message', {
      from: client.id,
      text: payload.text,
    });
    return { status: 'sent' };
  }
}
```

## Arsitektur Scaling
```
                    [Redis Pub/Sub]
                   /               \
[Server Instance 1]               [Server Instance 2]
    |     |                           |     |
  Client Client                   Client Client
```

# Jalankan 2 instance server
PORT=3000 npm run start:dev &
