# 360. Cara menggunakan rooms dalam Socket.io untuk grouping client

## Definisi & Target
Rooms memungkinkan pengelompokan client ke dalam channel terpisah, sehingga pesan hanya dikirim ke anggota room tertentu. Cocok untuk chat room atau group notification.

## Komponen
File yang dimodifikasi: `src/chat/chat.gateway.ts`

## Kode Implementasi

```typescript
// src/chat/chat.gateway.ts (Gateway)
import { WebSocketGateway, WebSocketServer, SubscribeMessage, ConnectedSocket, MessageBody } from '@nestjs/websockets';
import { Server, Socket } from 'socket.io';

@WebSocketGateway({ cors: { origin: '*' } })
export class ChatGateway {
  @WebSocketServer()
  server: Server;

  @SubscribeMessage('join-room')
  handleJoinRoom(
    @ConnectedSocket() client: Socket,
    @MessageBody('room') room: string,
  ) {
    client.join(room);
    client.to(room).emit('user-joined', { userId: client.id, room });
    return { joined: room };
  }

  @SubscribeMessage('leave-room')
  handleLeaveRoom(
    @ConnectedSocket() client: Socket,
    @MessageBody('room') room: string,
  ) {
    client.leave(room);
    client.to(room).emit('user-left', { userId: client.id, room });
    return { left: room };
  }

  @SubscribeMessage('room-message')
  handleRoomMessage(
    @ConnectedSocket() client: Socket,
    @MessageBody() payload: { room: string; text: string },
  ) {
    this.server.to(payload.room).emit('room-message', {
      from: client.id,
      text: payload.text,
      room: payload.room,
      timestamp: Date.now(),
    });
    return { sent: true, room: payload.room };
  }

  @SubscribeMessage('list-rooms')
  handleListRooms(@ConnectedSocket() client: Socket) {
    const rooms = Array.from(client.rooms);
    return { rooms: rooms.filter((r) => r !== client.id) };
  }
}
```

## Konsep Rooms
```
Room: 'general'          Room: 'random'          Room: 'support'
  [client-1]               [client-3]              [client-5]
  [client-2]               [client-4]
```

| Method | Keterangan |
|--------|------------|
| `client.join(room)` | Masuk ke room |
| `client.leave(room)` | Keluar dari room |
| `server.to(room).emit()` | Kirim ke semua di room |
| `client.to(room).emit()` | Kirim ke room kecuali pengirim |
| `server.sockets.adapter.rooms` | Daftar semua rooms |

## Cara Integrasi & Pengujian
```javascript
const socket = io('http://localhost:3000');
socket.emit('join-room', { room: 'general' });

socket.emit('room-message', { room: 'general', text: 'Hello room!' });
socket.on('room-message', (data) => console.log(data));

socket.emit('list-rooms', {}, (rooms) => console.log('My rooms:', rooms));
```
