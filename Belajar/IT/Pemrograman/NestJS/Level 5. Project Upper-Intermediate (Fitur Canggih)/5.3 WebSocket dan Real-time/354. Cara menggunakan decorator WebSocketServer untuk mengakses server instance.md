# 354. Cara menggunakan decorator WebSocketServer untuk mengakses server instance

## Definisi & Target
Decorator `@WebSocketServer()` digunakan untuk meng-inject instance Server Socket.IO ke dalam gateway, memungkinkan broadcast pesan ke semua client.

## Komponen
File yang dimodifikasi: `src/chat/chat.gateway.ts`

## Kode Implementasi

```typescript
// src/chat/chat.gateway.ts (Gateway)
import { WebSocketGateway, WebSocketServer, SubscribeMessage } from '@nestjs/websockets';
import { Server, Socket } from 'socket.io';

@WebSocketGateway({ cors: { origin: '*' } })
export class ChatGateway {
  @WebSocketServer()
  server: Server;

  @SubscribeMessage('broadcast')
  handleBroadcast(client: Socket, payload: { message: string }) {
    this.server.emit('broadcast', {
      from: client.id,
      message: payload.message,
      timestamp: new Date().toISOString(),
    });
    return { status: 'broadcasted', to: 'all' };
  }

  @SubscribeMessage('stats')
  handleStats() {
    const count = this.server.engine.clientsCount;
    return { connectedClients: count };
  }

  @SubscribeMessage('server-info')
  handleServerInfo() {
    const rooms = this.server.sockets.adapter.rooms;
    const sockets = this.server.sockets.adapter.sockets;
    return {
      totalClients: this.server.engine.clientsCount,
      totalRooms: rooms.size,
      rooms: Array.from(rooms.keys()),
    };
  }
}
```

## Properti Server Socket.IO
| Property | Deskripsi |
|----------|-----------|
| `server.sockets` | Semua koneksi socket |
| `server.emit()` | Broadcast ke semua client |
| `server.to(room)` | Kirim ke room tertentu |
| `server.engine` | Engine.IO instance |
| `server.sockets.adapter` | Adapter (Rooms, Redis, dll) |
