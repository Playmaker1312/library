# 369. Cara membuat email template yang responsif untuk berbagai kebutuhan

## Definisi & Target
Membuat template email yang responsif dan kompatibel dengan berbagai email client (Gmail, Outlook, Yahoo) untuk berbagai keperluan.

## Komponen
Folder: `src/mail/templates/`

## Kode Implementasi

```html
<!-- src/mail/templates/order-confirmation.hbs -->
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <style>
    body, table, td, p { font-family: Arial, Helvetica, sans-serif; }
    table { border-collapse: collapse; width: 100%; }
    .email-wrapper { max-width: 600px; margin: 0 auto; }
    .header { background: #059669; padding: 24px; text-align: center; }
    .header h1 { color: white; margin: 0; font-size: 24px; }
    .body { padding: 24px; background: #ffffff; }
    .order-details { background: #F3F4F6; padding: 16px; border-radius: 8px; margin: 16px 0; }
    .item { padding: 8px 0; border-bottom: 1px solid #E5E7EB; }
    .total { font-size: 18px; font-weight: bold; text-align: right; padding-top: 12px; }
    .button { background: #059669; color: white; padding: 12px 32px; text-decoration: none; border-radius: 6px; display: inline-block; }
    .footer { padding: 16px; text-align: center; font-size: 12px; color: #6B7280; }
    @media only screen and (max-width: 480px) {
      .header h1 { font-size: 20px; }
      .body { padding: 16px; }
    }
  </style>
</head>
<body>
  <table class="email-wrapper" role="presentation">
    <tr><td>
      <div class="header">
        <h1>Order Confirmed!</h1>
      </div>
    </td></tr>
    <tr><td>
      <div class="body">
        <p>Hi <strong>{{ customerName }}</strong>,</p>
        <p>Your order <strong>#{{ orderId }}</strong> has been confirmed.</p>

        <div class="order-details">
          <h3>Order Summary</h3>
          {{#each items}}
          <div class="item">
            <p><strong>{{ this.name }}</strong> x {{ this.quantity }}</p>
            <p style="text-align: right;">Rp {{ formatPrice this.price }}</p>
          </div>
          {{/each}}
          <div class="total">Total: Rp {{ formatPrice total }}</div>
        </div>

        <p style="text-align: center;">
          <a href="{{ orderUrl }}" class="button">View Order</a>
        </p>
      </div>
    </td></tr>
    <tr><td>
      <div class="footer">
        <p>{{ siteName }} | {{ supportEmail }} | {{ supportPhone }}</p>
      </div>
    </td></tr>
  </table>
</body>
</html>
```
