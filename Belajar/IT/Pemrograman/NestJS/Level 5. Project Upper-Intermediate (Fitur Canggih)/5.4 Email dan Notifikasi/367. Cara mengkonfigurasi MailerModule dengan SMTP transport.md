# 367. Cara mengkonfigurasi MailerModule dengan SMTP transport

## Definisi & Target
Mengkonfigurasi MailerModule dengan koneksi SMTP server untuk mengirim email melalui provider email seperti Gmail, SendGrid, atau Mailgun.

## Komponen
File yang dimodifikasi: `src/app.module.ts`

## Kode Implementasi

```typescript
// src/app.module.ts (AppModule)
import { Module } from '@nestjs/common';
import { MailerModule } from '@nestjs-modules/mailer';
import { HandlebarsAdapter } from '@nestjs-modules/mailer/dist/adapters/handlebars.adapter';
import { join } from 'path';

@Module({
  imports: [
    MailerModule.forRoot({
      transport: {
        host: process.env.SMTP_HOST || 'smtp.gmail.com',
        port: parseInt(process.env.SMTP_PORT, 10) || 587,
        secure: false,
        auth: {
          user: process.env.SMTP_USER,
          pass: process.env.SMTP_PASS,
        },
      },
      defaults: {
        from: '"No Reply" <noreply@example.com>',
      },
      template: {
        dir: join(__dirname, '..', 'mail', 'templates'),
        adapter: new HandlebarsAdapter(),
        options: {
          strict: true,
        },
      },
    }),
  ],
})
export class AppModule {}
```

```env
# .env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password
```

## Opsi Transport Umum
| Provider | Host | Port | Secure |
|----------|------|------|--------|
| Gmail | `smtp.gmail.com` | 587 | `false` |
| SendGrid | `smtp.sendgrid.net` | 587 | `false` |
| Mailgun | `smtp.mailgun.org` | 587 | `false` |
| Mailtrap (test) | `sandbox.smtp.mailtrap.io` | 2525 | `false` |
