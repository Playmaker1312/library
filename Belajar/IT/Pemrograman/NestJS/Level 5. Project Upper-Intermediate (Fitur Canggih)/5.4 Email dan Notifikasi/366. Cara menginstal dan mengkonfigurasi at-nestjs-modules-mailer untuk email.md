# 366. Cara menginstal dan mengkonfigurasi @nestjs-modules/mailer untuk email

## Definisi & Target
Menginstal dan mengkonfigurasi `@nestjs-modules/mailer`, modul NestJS untuk mengirim email dengan dukungan multiple transport dan template engine.

## Perintah Instalasi
```bash
npm install @nestjs-modules/mailer nodemailer
npm install --save-dev @types/nodemailer
```

## Daftar Package
| Package | Fungsi |
|---------|--------|
| `@nestjs-modules/mailer` | Modul email untuk NestJS |
| `nodemailer` | Library pengiriman email untuk Node.js |
| `@types/nodemailer` | Type definitions |

## Struktur Folder
```
src/
  mail/
    mail.module.ts
    mail.service.ts
    mail.controller.ts
    templates/
      welcome.hbs
      reset-password.hbs
      order-confirmation.hbs
```
