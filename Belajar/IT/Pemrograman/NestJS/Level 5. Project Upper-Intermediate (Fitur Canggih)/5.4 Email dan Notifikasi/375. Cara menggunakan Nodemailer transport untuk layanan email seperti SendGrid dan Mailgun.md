# 375. Cara menggunakan Nodemailer transport untuk layanan email seperti SendGrid dan Mailgun

## Definisi & Target
Mengkonfigurasi Nodemailer transport untuk berbagai provider email seperti SendGrid (via SMTP atau API), Mailgun, Amazon SES, dan Mailtrap untuk testing.

## Kode Implementasi

```typescript
// src/mail/mail.module.ts (Module - multiple transports)
import { Module } from '@nestjs/common';
import { MailerModule } from '@nestjs-modules/mailer';
import { HandlebarsAdapter } from '@nestjs-modules/mailer/dist/adapters/handlebars.adapter';

@Module({
  imports: [
    MailerModule.forRoot({
      transport: {
        // SendGrid via SMTP
        host: 'smtp.sendgrid.net',
        port: 587,
        auth: { user: 'apikey', pass: process.env.SENDGRID_API_KEY },
      },
      defaults: { from: '"MyApp" <noreply@myapp.com>' },
      template: {
        dir: __dirname + '/templates',
        adapter: new HandlebarsAdapter(),
      },
    }),
  ],
})
export class MailModule {}
```

```typescript
// src/mail/providers/mailgun.transport.ts (Mailgun transport)
import { Injectable } from '@nestjs/common';
import * as nodemailer from 'nodemailer';

@Injectable()
export class MailgunTransport {
  createTransport() {
    return nodemailer.createTransport({
      host: 'smtp.mailgun.org',
      port: 587,
      auth: {
        user: process.env.MAILGUN_USER,
        pass: process.env.MAILGUN_PASS,
      },
    });
  }
}
```

```typescript

```

```typescript
// src/mail/providers/amazon-ses.transport.ts (Amazon SES)
import { Injectable } from '@nestjs/common';
import * as nodemailer from 'nodemailer';

@Injectable()
export class AmazonSesTransport {
  createTransport() {
    return nodemailer.createTransport({
      host: 'email-smtp.ap-southeast-1.amazonaws.com',
      port: 587,
      auth: {
        user: process.env.SES_SMTP_USER,
        pass: process.env.SES_SMTP_PASS,
      },
    });
  }
}
```

## Comparison Provider
| Provider | SMTP Host | Port | Kelebihan |
|----------|-----------|------|-----------|
| SendGrid | `smtp.sendgrid.net` | 587/465 | 100 email/hari gratis |
| Mailgun | `smtp.mailgun.org` | 587/465 | 5000 email/bulan gratis |
| Mailtrap | `sandbox.smtp.mailtrap.io` | 2525 | Testing, email tidak terkirim |
| Amazon SES | `email-smtp.region.amazonaws.com` | 587/465 | Murah untuk volume besar |
| Gmail | `smtp.gmail.com` | 587 | Gratis, terbatas 500/hari |
