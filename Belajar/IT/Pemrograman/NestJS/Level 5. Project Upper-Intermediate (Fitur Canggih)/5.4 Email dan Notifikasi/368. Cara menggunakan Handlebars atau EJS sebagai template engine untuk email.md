# 368. Cara menggunakan Handlebars atau EJS sebagai template engine untuk email

## Definisi & Target
Menggunakan template engine (Handlebars atau EJS) untuk membuat template email yang dinamis dengan variable interpolation.

## Komponen & Perintah Instalasi
```bash
npm install handlebars
# atau
npm install ejs
```

## Kode Implementasi

```typescript
// src/app.module.ts (AppModule - Handlebars)
import { Module } from '@nestjs/common';
import { MailerModule } from '@nestjs-modules/mailer';
import { HandlebarsAdapter } from '@nestjs-modules/mailer/dist/adapters/handlebars.adapter';
import { join } from 'path';

@Module({
  imports: [
    MailerModule.forRoot({
      transport: {
        host: process.env.SMTP_HOST,
        port: parseInt(process.env.SMTP_PORT, 10),
        auth: { user: process.env.SMTP_USER, pass: process.env.SMTP_PASS },
      },
      template: {
        dir: join(__dirname, '..', 'mail', 'templates'),
        adapter: new HandlebarsAdapter(),
        options: { strict: true },
      },
    }),
  ],
})
export class AppModule {}
```
