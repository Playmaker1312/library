# 333. Cara mengkonfigurasi BullModule dengan koneksi Redis

## Definisi & Target
Mengkonfigurasi BullModule di root AppModule agar semua queue terhubung ke Redis server yang sama.

## Komponen
File yang dimodifikasi: `src/app.module.ts`

## Kode Implementasi

```typescript
// src/app.module.ts (AppModule)
import { Module } from '@nestjs/common';
import { BullModule } from '@nestjs/bull';

@Module({
  imports: [
    BullModule.forRoot({
      redis: {
        host: process.env.REDIS_HOST || 'localhost',
        port: parseInt(process.env.REDIS_PORT, 10) || 6379,
        password: process.env.REDIS_PASSWORD || undefined,
      },
      defaultJobOptions: {
        attempts: 3,
        backoff: {
          type: 'exponential',
          delay: 2000,
        },
        removeOnComplete: true,
        removeOnFail: false,
      },
    }),
  ],
})
export class AppModule {}
```

```env
# .env
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=
```

## Cara Integrasi & Pengujian
Konfigurasi ini bersifat global. Setelah ini, queue dapat didaftarkan di module spesifik menggunakan `BullModule.registerQueue()`.
