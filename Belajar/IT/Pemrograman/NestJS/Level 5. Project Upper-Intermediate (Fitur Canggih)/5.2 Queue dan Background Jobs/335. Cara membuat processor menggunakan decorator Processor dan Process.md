# 335. Cara membuat processor menggunakan decorator Processor dan Process

## Definisi & Target
Membuat processor yang akan menangani job dari queue. Processor menjalankan logika bisnis secara asynchronous ketika job diambil dari queue.

## Komponen & Nest CLI Command
```bash
nest g mo email
nest g pr email/email
```

## Kode Implementasi

```typescript
// src/email/email.processor.ts (Processor)
import { Processor, Process } from '@nestjs/bull';
import { Job } from 'bull';

@Processor('email')
export class EmailProcessor {
  @Process('send-welcome')
  async handleWelcomeEmail(job: Job<{ userId: string; email: string }>) {
    const { userId, email } = job.data;
    await this.sendEmail(email, 'Welcome to our platform!', `<h1>Hi ${userId}!</h1>`);
    return { status: 'sent', userId };
  }

  @Process('send-reset-password')
  async handleResetPassword(job: Job<{ email: string; token: string }>) {
    const { email, token } = job.data;
    await this.sendEmail(email, 'Reset Password', `Your token: ${token}`);
    return { status: 'sent', email };
  }

  @Process()
  async handleDefault(job: Job) {
    console.log(`Processing job ${job.id} of type ${job.name}`);
    await this.sendEmail(job.data.email, job.data.subject, job.data.body);
  }

  private async sendEmail(to: string, subject: string, html: string): Promise<void> {
    console.log(`Sending email to ${to}: ${subject}`);
    await new Promise((resolve) => setTimeout(resolve, 1000));
  }
}
```

```typescript
// src/email/email.module.ts (Module)
import { Module } from '@nestjs/common';
import { BullModule } from '@nestjs/bull';
import { EmailProcessor } from './email.processor';

@Module({
  imports: [BullModule.registerQueue({ name: 'email' })],
  providers: [EmailProcessor],
})
export class EmailModule {}
```

## Cara Integrasi & Pengujian
Job akan diproses otomatis oleh `EmailProcessor` ketika ada job yang masuk ke queue `email`.
