# 348. Cara mengimplementasikan worker yang dapat diskalakan secara horizontal

## Definisi & Target
Worker yang scalable horizontal berarti kita bisa menjalankan banyak instance worker di server berbeda yang semuanya memproses job dari Redis queue yang sama, tanpa konflik.

## Konsep
```
[API Server 1] --add job--> [Redis Queue] <--consume-- [Worker Instance 1]
[API Server 2] --add job--> [Redis Queue] <--consume-- [Worker Instance 2]
                                       <--consume-- [Worker Instance 3]
```

## Kode Implementasi

```typescript
// src/workers/email.worker.ts (Worker - standalone process)
import { Worker } from 'bullmq';
import { config } from 'dotenv';
config();

const worker = new Worker('email', async (job) => {
  console.log(`[Worker ${process.pid}] Processing job ${job.id}: ${job.name}`);
  switch (job.name) {
    case 'send-welcome':
      await sendEmail(job.data.email, 'Welcome!', '<h1>Welcome</h1>');
      break;
    case 'send-notification':
      await sendEmail(job.data.email, 'Notification', job.data.body);
      break;
  }
  return { success: true, pid: process.pid };
}, {
  connection: {
    host: process.env.REDIS_HOST || 'localhost',
    port: parseInt(process.env.REDIS_PORT, 10) || 6379,
  },
  concurrency: 10,
  limiter: {
    max: 100,
    duration: 1000,
  },
});

async function sendEmail(to: string, subject: string, html: string) {
  console.log(`Sending email to ${to}: ${subject}`);
  await new Promise((resolve) => setTimeout(resolve, 500));
}

worker.on('completed', (job) => {
  console.log(`Job ${job.id} completed by worker ${process.pid}`);
});

worker.on('failed', (job, err) => {
  console.error(`Job ${job.id} failed: ${err.message}`);
});
```

```json
// package.json (scripts)
{
  "scripts": {
    "start:worker": "ts-node src/workers/email.worker.ts",
    "start:worker:prod": "node dist/workers/email.worker.js"
  }
}
```

## Scaling Command
```bash
# Jalankan 4 worker secara parallel
npm run start:worker &
npm run start:worker &
npm run start:worker &
npm run start:worker &

# Atau gunakan PM2
npm install -g pm2
pm2 start dist/workers/email.worker.js -i 4 --name email-worker
```
