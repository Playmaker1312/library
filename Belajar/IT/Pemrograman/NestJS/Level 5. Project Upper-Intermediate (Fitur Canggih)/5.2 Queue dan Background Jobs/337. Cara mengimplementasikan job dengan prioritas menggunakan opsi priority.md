# 337. Cara mengimplementasikan job dengan prioritas menggunakan opsi priority

## Definisi & Target
Mengatur prioritas job agar job penting (misalnya email verifikasi) diproses lebih dulu daripada job yang kurang penting.

## Komponen
File yang dimodifikasi: `src/email/email.controller.ts`

## Kode Implementasi

```typescript
// src/email/email.controller.ts (Controller)
import { Controller, Post, Body } from '@nestjs/common';
import { InjectQueue } from '@nestjs/bull';
import { Queue } from 'bull';

@Controller('email')
export class EmailController {
  constructor(@InjectQueue('email') private emailQueue: Queue) {}

  @Post('send-verification')
  async sendVerification(@Body('email') email: string, @Body('token') token: string) {
    const job = await this.emailQueue.add('send-verification', { email, token }, {
      priority: 1,
      attempts: 5,
    });
    return { message: 'Priority: High', jobId: job.id };
  }

  @Post('send-newsletter')
  async sendNewsletter(@Body('email') email: string) {
    const job = await this.emailQueue.add('send-newsletter', { email }, {
      priority: 10,
      attempts: 2,
    });
    return { message: 'Priority: Low', jobId: job.id };
  }

  @Post('send-promo')
  async sendPromo(@Body('email') email: string) {
    const job = await this.emailQueue.add('send-promo', { email }, {
      priority: 5,
      attempts: 3,
    });
    return { message: 'Priority: Medium', jobId: job.id };
  }
}
```

## Prioritas Job
| Nilai priority | Prioritas |
|----------------|-----------|
| 1 | Tertinggi (diproses first) |
| 5 | Medium |
| 10 | Terendah |
