# 334. Cara mendaftarkan queue menggunakan BullModule.registerQueue

## Definisi & Target
Mendaftarkan queue spesifik menggunakan `BullModule.registerQueue()` di module agar dapat digunakan oleh producer (inject queue) dan consumer (processor).

## Komponen & Nest CLI Command
```bash
nest g mo email
```

## Kode Implementasi

```typescript
// src/email/email.module.ts (Module)
import { Module } from '@nestjs/common';
import { BullModule } from '@nestjs/bull';
import { EmailController } from './email.controller';
import { EmailProcessor } from './email.processor';

@Module({
  imports: [
    BullModule.registerQueue({
      name: 'email',
      defaultJobOptions: {
        attempts: 3,
        backoff: { type: 'exponential', delay: 2000 },
      },
    }),
    BullModule.registerQueue({
      name: 'notification',
      defaultJobOptions: {
        attempts: 5,
        backoff: { type: 'fixed', delay: 5000 },
      },
    }),
  ],
  controllers: [EmailController],
  providers: [EmailProcessor],
})
export class EmailModule {}
```

## Cara Integrasi & Pengujian
Queue `email` dan `notification` sekarang terdaftar. Controller dapat meng-inject queue dengan decorator `@InjectQueue('email')`, dan processor menggunakan `@Processor('email')`.
