# 336. Cara mendispatch job ke queue menggunakan InjectQueue dan metode add

## Definisi & Target
Mengirim job ke queue dari controller atau service menggunakan `@InjectQueue()` dan method `queue.add()`.

## Komponen & Nest CLI Command
```bash
nest g co email
```

## Kode Implementasi

```typescript
// src/email/email.controller.ts (Controller)
import { Controller, Post, Body } from '@nestjs/common';
import { InjectQueue } from '@nestjs/bull';
import { Queue } from 'bull';

@Controller('email')
export class EmailController {
  constructor(@InjectQueue('email') private emailQueue: Queue) {}

  @Post('send-welcome')
  async sendWelcome(@Body('userId') userId: string, @Body('email') email: string) {
    const job = await this.emailQueue.add('send-welcome', { userId, email });
    return { message: 'Welcome email queued', jobId: job.id };
  }

  @Post('send-reset-password')
  async sendResetPassword(@Body('email') email: string, @Body('token') token: string) {
    const job = await this.emailQueue.add('send-reset-password', { email, token });
    return { message: 'Reset password email queued', jobId: job.id };
  }

  @Post('send-custom')
  async sendCustom(@Body() body: { to: string; subject: string; body: string }) {
    const job = await this.emailQueue.add(body);
    return { message: 'Custom email queued', jobId: job.id };
  }
}
```

## Method `queue.add()`
| Parameter | Type | Keterangan |
|-----------|------|------------|
| `name` | `string` | Nama job (untuk di-match ke @Process) |
| `data` | `object` | Data yang dikirim ke processor |
| `opts` | `JobOptions` | Opsi seperti priority, delay, attempts |
