# 332. Cara menginstal package @nestjs/bull dan bull untuk queue management

## Definisi & Target
Menginstal Bull (queue management berbasis Redis) dan integrasinya dengan NestJS untuk memproses background job.

## Perintah Instalasi
```bash
npm install @nestjs/bull bull
npm install --save-dev @types/bull
```

## Daftar Package
| Package | Fungsi |
|---------|--------|
| `@nestjs/bull` | Modul NestJS untuk integrasi Bull queue |
| `bull` | Library queue management berbasis Redis |
| `@types/bull` | Type definitions untuk TypeScript |

## Verifikasi Instalasi
```bash
npm list @nestjs/bull bull
# Pastikan terdaftar di node_modules
```

## Persyaratan
- Redis server harus berjalan (Bull menggunakan Redis sebagai backend)
- Redis URL dikonfigurasi di environment variable
