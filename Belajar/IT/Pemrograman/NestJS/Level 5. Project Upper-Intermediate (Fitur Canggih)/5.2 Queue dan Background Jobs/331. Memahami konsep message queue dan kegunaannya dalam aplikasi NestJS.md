# 331. Memahami konsep message queue dan kegunaannya dalam aplikasi NestJS

## Definisi & Target
Message queue adalah mekanisme komunikasi asynchronous dimana producer mengirim pesan ke queue dan consumer memprosesnya kemudian. Ini memungkinkan aplikasi untuk menangani tugas berat di background tanpa memblokir response HTTP.

## Konsep Dasar
- **Producer**: Aplikasi yang mengirim job ke queue
- **Queue**: Tempat penyimpanan sementara job yang menunggu diproses
- **Consumer/Worker**: Proses yang mengambil dan mengeksekusi job dari queue
- **Job**: Unit pekerjaan yang dikirim ke queue

## Kegunaan dalam NestJS
| Use Case | Contoh |
|----------|--------|
| Email sending | Kirim email konfirmasi tanpa menunggu proses SMTP |
| Image processing | Resize/kompres gambar secara async |
| Report generation | Generate laporan PDF di background |
| Notification | Push notification ke banyak user |
| Webhook calls | Panggil API eksternal secara async |
| Data sync | Sinkronisasi data ke sistem lain |

## Arsitektur
```
Client -> Controller -> Queue (Redis/Bull) -> Worker/Processor
                          |
                    [Job disimpan di Redis]
                          |
                    Worker memproses job
                          |
                    Complete/Failed
```
