# 346. Cara menggunakan BullMQ sebagai versi terbaru Bull dalam NestJS

## Definisi & Target
BullMQ adalah penerus Bull dengan performa lebih baik, TypeScript native, dan fitur worker yang lebih modern. Menggunakan BullMQ sebagai pengganti Bull.

## Komponen & Perintah Instalasi
```bash
npm install @nestjs/bullmq bullmq
```

## Kode Implementasi

```typescript
// src/app.module.ts (AppModule)
import { Module } from '@nestjs/common';
import { BullModule } from '@nestjs/bullmq';

@Module({
  imports: [
    BullModule.forRoot({
      connection: {
        host: process.env.REDIS_HOST || 'localhost',
        port: parseInt(process.env.REDIS_PORT, 10) || 6379,
      },
      defaultJobOptions: {
        attempts: 3,
        backoff: { type: 'exponential', delay: 2000 },
      },
    }),
  ],
})
export class AppModule {}
```

```typescript
// src/email/email.module.ts (Module)
import { Module } from '@nestjs/common';
import { BullModule } from '@nestjs/bullmq';
import { EmailController } from './email.controller';

@Module({
  imports: [
    BullModule.registerQueue({ name: 'email' }),
  ],
  controllers: [EmailController],
  providers: [],
})
export class EmailModule {}
```

```typescript
// src/email/email.controller.ts (Controller)
import { Controller, Post, Body } from '@nestjs/common';
import { InjectQueue } from '@nestjs/bullmq';
import { Queue } from 'bullmq';

@Controller('email')
export class EmailController {
  constructor(@InjectQueue('email') private emailQueue: Queue) {}

  @Post('send')
  async send(@Body('to') to: string) {
    const job = await this.emailQueue.add('send-welcome', { to });
    return { jobId: job.id };
  }
}
```

```typescript
// src/email/email.worker.ts (Worker)
import { Worker, Job } from 'bullmq';
import { Processor, WorkerHost } from '@nestjs/bullmq';
import { Job } from 'bullmq';

@Processor('email')
export class EmailWorker extends WorkerHost {
  async process(job: Job): Promise<any> {
    switch (job.name) {
      case 'send-welcome':
        console.log(`Sending welcome email to ${job.data.to}`);
        break;
    }
    return { processed: job.id };
  }
}
```

## Perbedaan Bull vs BullMQ
| Fitur | Bull | BullMQ |
|-------|------|--------|
| Bahasa | JavaScript | TypeScript native |
| Package | `@nestjs/bull` | `@nestjs/bullmq` |
| Worker | Decorator-based | Class WorkerHost |
| Flow | Manual | Flow Producer |
| Rate Limiter | Terbatas | Built-in |
| Sandbox | Tidak ada | Ada |
