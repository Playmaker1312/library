# 339. Cara mengimplementasikan job retry menggunakan opsi attempts dan backoff

## Definisi & Target
Mengatur mekanisme retry otomatis ketika job gagal, dengan backoff strategy (eksponensial atau fixed) untuk menghindari banjir retry.

## Komponen
File yang dimodifikasi: `src/email/email.controller.ts`

## Kode Implementasi

```typescript
// src/email/email.controller.ts (Controller)
import { Controller, Post, Body } from '@nestjs/common';
import { InjectQueue } from '@nestjs/bull';
import { Queue } from 'bull';

@Controller('email')
export class EmailController {
  constructor(@InjectQueue('email') private emailQueue: Queue) {}

  @Post('send-with-retry')
  async sendWithRetry(@Body('email') email: string) {
    const job = await this.emailQueue.add('send-with-retry', { email }, {
      attempts: 5,
      backoff: {
        type: 'exponential',
        delay: 2000,
      },
      removeOnFail: false,
    });
    return { message: 'Job queued with retry', jobId: job.id };
  }
}
```

```typescript
// src/email/email.processor.ts (Processor)
import { Processor, Process } from '@nestjs/bull';
import { Job } from 'bull';

@Processor('email')
export class EmailProcessor {
  @Process('send-with-retry')
  async handleWithRetry(job: Job<{ email: string }>) {
    const { email } = job.data;
    const currentAttempt = job.attemptsMade + 1;

    console.log(`Attempt ${currentAttempt}/${job.opts.attempts} for ${email}`);

    try {
      const success = await this.deliverEmail(email);
      if (!success) throw new Error('SMTP unavailable');
      return { status: 'sent', email, attempts: currentAttempt };
    } catch (error) {
      console.log(`Failed attempt ${currentAttempt}: ${error.message}`);
      throw error;
    }
  }

  private async deliverEmail(email: string): Promise<boolean> {
    return Math.random() > 0.6;
  }
}
```

## Backoff Strategy
| Type | Delay Pattern |
|------|---------------|
| `exponential` | 2s, 4s, 8s, 16s, ... |
| `fixed` | 5s, 5s, 5s, ... |
