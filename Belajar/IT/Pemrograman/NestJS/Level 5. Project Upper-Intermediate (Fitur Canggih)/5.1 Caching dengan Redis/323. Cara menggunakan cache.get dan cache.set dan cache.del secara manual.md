# 323. Cara menggunakan cache.get dan cache.set dan cache.del secara manual

## Definisi & Target
Menggunakan method `cache.get()`, `cache.set()`, dan `cache.del()` secara langsung untuk kontrol penuh atas operasi cache tanpa bergantung pada decorator.

## Komponen
File yang dimodifikasi: `src/products/products.service.ts`

## Kode Implementasi

```typescript
// src/products/products.service.ts (Service)
import { Injectable, Inject, CACHE_MANAGER } from '@nestjs/common';
import { Cache } from 'cache-manager';

@Injectable()
export class ProductsService {
  private products = [
    { id: '1', name: 'Laptop', price: 15000000 },
    { id: '2', name: 'Mouse', price: 250000 },
  ];

  constructor(@Inject(CACHE_MANAGER) private cache: Cache) {}

  async findAll(): Promise<any[]> {
    const cacheKey = 'products:all';
    const cached = await this.cache.get<any[]>(cacheKey);
    if (cached) return cached;

    const data = this.products;
    await this.cache.set(cacheKey, data, 60);
    return data;
  }

  async findOne(id: string): Promise<any> {
    const cacheKey = `products:${id}`;
    const cached = await this.cache.get<any>(cacheKey);
    if (cached) return cached;

    const data = this.products.find((p) => p.id === id);
    if (data) await this.cache.set(cacheKey, data, 120);
    return data;
  }

  async update(id: string, updateData: any): Promise<any> {
    const index = this.products.findIndex((p) => p.id === id);
    if (index === -1) return null;
    this.products[index] = { ...this.products[index], ...updateData };
    await this.cache.del(`products:${id}`);
    await this.cache.del('products:all');
    return this.products[index];
  }
}
```

## Method Reference
| Method | Signature | Keterangan |
|--------|-----------|------------|
| `get` | `<T>(key: string) => Promise<T>` | Ambil data dari cache |
| `set` | `(key: string, value: any, ttl?: number) => Promise<void>` | Simpan data ke cache |
| `del` | `(key: string) => Promise<void>` | Hapus data dari cache |
| `reset` | `() => Promise<void>` | Hapus semua cache |
