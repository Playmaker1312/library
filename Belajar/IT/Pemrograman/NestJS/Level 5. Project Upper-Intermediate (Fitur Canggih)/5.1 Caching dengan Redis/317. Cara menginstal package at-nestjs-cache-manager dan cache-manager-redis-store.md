# 317. Cara menginstal package @nestjs/cache-manager dan cache-manager-redis-store

## Definisi & Target
Menginstal semua dependensi yang diperlukan untuk mengintegrasikan Redis sebagai cache store dalam aplikasi NestJS.

## Perintah Instalasi
```bash
npm install @nestjs/cache-manager cache-manager-redis-store redis
npm install --save-dev @types/cache-manager-redis-store
```

## Daftar Package
| Package | Fungsi |
|---------|--------|
| `@nestjs/cache-manager` | Modul resmi NestJS untuk integrasi cache |
| `cache-manager-redis-store` | Redis store adapter untuk cache-manager |
| `redis` | Redis client (ioredis atau node-redis) |
| `@types/cache-manager-redis-store` | Type definitions untuk TypeScript |

## Catatan Versi
```json
// package.json (dependencies)
"@nestjs/cache-manager": "^2.0.0",
"cache-manager-redis-store": "^3.0.0",
"cache-manager": "^5.0.0",
"redis": "^4.6.0"
```

## Verifikasi Instalasi
```bash
nest info
# Pastikan @nestjs/cache-manager terdaftar di package.json
```
