# 319. Cara menggunakan decorator CacheInterceptor untuk caching response otomatis

## Definisi & Target
Menggunakan `CacheInterceptor` untuk secara otomatis menyimpan response GET endpoint ke Redis dan mengembalikannya tanpa mengeksekusi handler pada request berikutnya dalam durasi TTL.

## Komponen & Nest CLI Command
```bash
nest g mo products
nest g co products
nest g s products
```

## Kode Implementasi

```typescript
// src/products/products.controller.ts (Controller)
import { Controller, Get, Param, UseInterceptors, CacheInterceptor } from '@nestjs/common';
import { ProductsService } from './products.service';

@Controller('products')
@UseInterceptors(CacheInterceptor)
export class ProductsController {
  constructor(private readonly productsService: ProductsService) {}

  @Get()
  findAll() {
    return this.productsService.findAll();
  }

  @Get(':id')
  findOne(@Param('id') id: string) {
    return this.productsService.findOne(id);
  }
}
```

```typescript
// src/products/products.service.ts (Service)
import { Injectable } from '@nestjs/common';

@Injectable()
export class ProductsService {
  private products = [
    { id: '1', name: 'Laptop', price: 15000000 },
    { id: '2', name: 'Mouse', price: 250000 },
  ];

  findAll() {
    return this.products;
  }

  findOne(id: string) {
    return this.products.find((p) => p.id === id);
  }
}
```

## Cara Integrasi & Pengujian
```bash
curl http://localhost:3000/products
# Response pertama: slow (cache miss)
# Response kedua: fast (cache hit - langsung dari Redis)
curl http://localhost:3000/products/1
```
