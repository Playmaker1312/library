# 321. Cara menggunakan decorator CacheKey untuk mengatur key cache per route

## Definisi & Target
Mengatur kunci cache secara eksplisit menggunakan decorator `@CacheKey()` agar lebih mudah diidentifikasi dan di-invalidate.

## Komponen
File yang dimodifikasi: `src/products/products.controller.ts`

## Kode Implementasi

```typescript
// src/products/products.controller.ts (Controller)
import { Controller, Get, Param, UseInterceptors, CacheInterceptor, CacheKey, CacheTTL } from '@nestjs/common';
import { ProductsService } from './products.service';

@Controller('products')
@UseInterceptors(CacheInterceptor)
export class ProductsController {
  constructor(private readonly productsService: ProductsService) {}

  @Get()
  @CacheKey('products-all')
  @CacheTTL(30)
  findAll() {
    return this.productsService.findAll();
  }

  @Get(':id')
  @CacheKey('products-one')
  @CacheTTL(120)
  findOne(@Param('id') id: string) {
    return this.productsService.findOne(id);
  }
}
```

## Cara Integrasi & Pengujian
```bash
curl http://localhost:3000/products
# Key di Redis: products-all

curl http://localhost:3000/products/1
# Key di Redis: products-one-1
```

Cache key default `CacheInterceptor` menggunakan URL path. Dengan `@CacheKey()` kita bisa menimpa default tersebut untuk kontrol manual. Biasanya dipasangkan dengan `@CacheTTL()`.
