# 318. Cara mengkonfigurasi CacheModule menggunakan Redis store

## Definisi & Target
Mengkonfigurasi CacheModule global dengan Redis sebagai store penyimpanan, menggantikan cache in-memory default.

## Komponen & Konfigurasi
Modul: `src/cache-config/cache-config.module.ts`

## Kode Implementasi

```typescript
// src/cache-config/cache-config.module.ts (Module)
import { Module, CacheModule } from '@nestjs/common';
import { CacheModuleAsyncOptions } from '@nestjs/cache-manager';
import { redisStore } from 'cache-manager-redis-store';

@Module({
  imports: [
    CacheModule.registerAsync({
      useFactory: async () => ({
        store: await redisStore({
          socket: {
            host: process.env.REDIS_HOST || 'localhost',
            port: parseInt(process.env.REDIS_PORT, 10) || 6379,
          },
          password: process.env.REDIS_PASSWORD || undefined,
          ttl: 60,
        }),
      }),
      isGlobal: true,
    } as CacheModuleAsyncOptions),
  ],
  exports: [CacheModule],
})
export class CacheConfigModule {}
```

```typescript
// src/app.module.ts (AppModule)
import { Module } from '@nestjs/common';
import { CacheConfigModule } from './cache-config/cache-config.module';
import { ProductsModule } from './products/products.module';

@Module({
  imports: [CacheConfigModule, ProductsModule],
})
export class AppModule {}
```

## Konfigurasi Environment
```env
# .env
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=
CACHE_TTL=60
```
