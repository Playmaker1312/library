# 322. Cara menginjeksi CACHE_MANAGER untuk operasi cache manual

## Definisi & Target
Menginjeksi `CACHE_MANAGER` dari `@nestjs/cache-manager` ke dalam service untuk melakukan operasi cache secara manual (get, set, del) tanpa menggunakan interceptor.

## Komponen & Nest CLI Command
```bash
nest g mo products
nest g s products
```

## Kode Implementasi

```typescript
// src/products/products.module.ts (Module)
import { Module, CacheModule } from '@nestjs/common';
import { ProductsService } from './products.service';

@Module({
  imports: [CacheModule.register()],
  providers: [ProductsService],
  exports: [ProductsService],
})
export class ProductsModule {}
```

```typescript
// src/products/products.service.ts (Service)
import { Injectable, Inject, CACHE_MANAGER } from '@nestjs/common';
import { Cache } from 'cache-manager';

@Injectable()
export class ProductsService {
  constructor(@Inject(CACHE_MANAGER) private cacheManager: Cache) {}

  async getCachedData(key: string): Promise<any> {
    return this.cacheManager.get(key);
  }

  async setCachedData(key: string, data: any, ttl: number = 60): Promise<void> {
    await this.cacheManager.set(key, data, ttl);
  }

  async deleteCachedData(key: string): Promise<void> {
    await this.cacheManager.del(key);
  }

  async resetCache(): Promise<void> {
    await this.cacheManager.reset();
  }
}
```

## Cara Integrasi & Pengujian
```typescript
// Contoh penggunaan di controller
@Get('manual/:key')
async getManual(@Param('key') key: string) {
  const cached = await this.productsService.getCachedData(key);
  if (cached) return { source: 'cache', data: cached };
  const data = { message: 'fresh data' };
  await this.productsService.setCachedData(key, data, 60);
  return { source: 'database', data };
}
```
