# 320. Cara menggunakan decorator CacheTTL untuk mengatur durasi cache per route

## Definisi & Target
Mengatur TTL (Time-To-Live) yang berbeda per endpoint menggunakan decorator `@CacheTTL()`, sehingga masing-masing route bisa memiliki durasi cache yang berbeda.

## Komponen
File yang dimodifikasi: `src/products/products.controller.ts`

## Kode Implementasi

```typescript
// src/products/products.controller.ts (Controller)
import { Controller, Get, Param, UseInterceptors, CacheInterceptor, CacheTTL } from '@nestjs/common';
import { ProductsService } from './products.service';

@Controller('products')
@UseInterceptors(CacheInterceptor)
export class ProductsController {
  constructor(private readonly productsService: ProductsService) {}

  @Get()
  @CacheTTL(30)
  findAll() {
    return this.productsService.findAll();
  }

  @Get(':id')
  @CacheTTL(120)
  findOne(@Param('id') id: string) {
    return this.productsService.findOne(id);
  }
}
```

## Cara Integrasi & Pengujian
```bash
curl http://localhost:3000/products
# Cache selama 30 detik

curl http://localhost:3000/products/1
# Cache selama 120 detik
```

Nilai TTL dalam detik. Jika tidak ditentukan, menggunakan TTL default dari konfigurasi CacheModule.
