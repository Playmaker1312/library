# 424. Cara mengintegrasikan RabbitMQ sebagai message broker dalam NestJS microservices

## Definisi & Target
RabbitMQ adalah message broker yang mengimplementasikan AMQP protocol. NestJS bisa menggunakan RabbitMQ sebagai transport layer untuk komunikasi antar service dengan fitur queue persistent, routing, dan reliable delivery.

## Komponen & Nest CLI Command
Instalasi: `npm install --save @nestjs/microservices amqplib amqp-connection-manager`

```
Infrastruktur:
  RabbitMQ server (localhost:5672)
  Management UI (localhost:15672)
```

## Kode Implementasi (Per File)
```typescript
// apps/billing-service/src/main.ts
import { NestFactory } from '@nestjs/core';
import { MicroserviceOptions, Transport } from '@nestjs/microservices';
import { BillingModule } from './billing.module';

async function bootstrap() {
  const app = await NestFactory.createMicroservice<MicroserviceOptions>(
    BillingModule,
    {
      transport: Transport.RMQ,
      options: {
        urls: ['amqp://guest:guest@localhost:5672'],
        queue: 'billing_queue',
        queueOptions: { durable: true },
        noAck: false,
        prefetchCount: 1,
      },
    },
  );
  await app.listen();
}
bootstrap();
```

```typescript
// apps/billing-service/src/billing.controller.ts
import { Controller } from '@nestjs/common';
import { MessagePattern, EventPattern, Payload } from '@nestjs/microservices';

@Controller()
export class BillingController {
  @MessagePattern({ cmd: 'create_invoice' })
  createInvoice(@Payload() data: { orderId: string; amount: number; customerId: string }) {
    return {
      invoiceId: `INV-${Date.now()}`,
      orderId: data.orderId,
      amount: data.amount,
      status: 'pending',
    };
  }

  @EventPattern('payment_confirmed')
  handlePaymentConfirmed(@Payload() data: { invoiceId: string }) {
    console.log(`Invoice ${data.invoiceId} marked as paid`);
  }
}
```

## Cara Integrasi & Pengujian
Jalankan RabbitMQ via Docker: `docker run -d --name rabbitmq -p 5672:5672 -p 15672:15672 rabbitmq:management`. Test dengan menjalankan service.
