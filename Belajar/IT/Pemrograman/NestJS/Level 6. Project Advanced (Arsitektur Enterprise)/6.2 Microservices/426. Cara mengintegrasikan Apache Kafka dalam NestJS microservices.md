# 426. Cara mengintegrasikan Apache Kafka dalam NestJS microservices

## Definisi & Target
Apache Kafka adalah distributed event streaming platform untuk high-throughput data pipelines. NestJS mendukung Kafka sebagai transport layer dengan consumer group, partitioning, dan offset management.

## Komponen & Nest CLI Command
Instalasi: `npm install --save @nestjs/microservices kafkajs`

```
Infrastruktur:
  Kafka broker (localhost:9092)
  Zookeeper (localhost:2181)
```

## Kode Implementasi (Per File)
```typescript
// apps/event-service/src/main.ts
import { NestFactory } from '@nestjs/core';
import { MicroserviceOptions, Transport } from '@nestjs/microservices';
import { EventModule } from './event.module';

async function bootstrap() {
  const app = await NestFactory.createMicroservice<MicroserviceOptions>(
    EventModule,
    {
      transport: Transport.KAFKA,
      options: {
        client: {
          brokers: ['localhost:9092'],
          clientId: 'event-service',
        },
        consumer: {
          groupId: 'event-consumer-group',
          allowAutoTopicCreation: true,
        },
        subscribe: {
          fromBeginning: false,
        },
      },
    },
  );
  await app.listen();
}
bootstrap();
```

```typescript
// apps/event-service/src/event.controller.ts
import { Controller } from '@nestjs/common';
import { MessagePattern, EventPattern, Payload, Ctx, KafkaContext } from '@nestjs/microservices';

@Controller()
export class EventController {
  @EventPattern('user_events')
  handleUserEvent(@Payload() message: any, @Ctx() context: KafkaContext) {
    const { offset, partition } = context.getPartition();
    console.log(`Processing event from partition ${partition} offset ${offset}`);
    return { status: 'processed' };
  }

  @MessagePattern('order_topic')
  handleOrderMessage(@Payload() message: { key: string; value: any }) {
    return { received: true, data: message.value };
  }
}
```

```typescript
// apps/api-gateway/src/kafka-client.module.ts
import { Module } from '@nestjs/common';
import { ClientsModule, Transport } from '@nestjs/microservices';

@Module({
  imports: [
    ClientsModule.register([
      {
        name: 'KAFKA_SERVICE',
        transport: Transport.KAFKA,
        options: {
          client: {
            brokers: ['localhost:9092'],
            clientId: 'api-gateway',
          },
          producer: {
            allowAutoTopicCreation: true,
          },
        },
      },
    ]),
  ],
})
export class KafkaClientModule {}
```

## Cara Integrasi & Pengujian
Jalankan Kafka via Docker. Gunakan `@Ctx()` dan `KafkaContext` untuk akses metadata seperti offset, partition, dan timestamp.
