# 423. Cara mengimplementasikan event-based pattern menggunakan emit

## Definisi & Target
Event-based pattern menggunakan `client.emit()` yang mengirim event tanpa menunggu response. Cocok untuk notifikasi, logging, dan operasi background. Targetnya adalah komunikasi asynchronous antar service.

## Komponen & Nest CLI Command
```
client.emit(pattern, data) -> Observable<T>
  - pattern: harus cocok dengan @EventPattern()
  - data: payload event
  - return: Observable (biasanya diabaikan)
```

## Kode Implementasi (Per File)
```typescript
// apps/analytics-service/src/analytics.controller.ts
import { Controller } from '@nestjs/common';
import { EventPattern, Payload } from '@nestjs/microservices';

@Controller()
export class AnalyticsController {
  private events: any[] = [];

  @EventPattern('page_viewed')
  handlePageViewed(@Payload() data: { page: string; userId: string; timestamp: Date }) {
    this.events.push(data);
    console.log(`Analytics: page ${data.page} viewed by ${data.userId}`);
  }

  @EventPattern('product_searched')
  handleProductSearched(@Payload() data: { query: string; userId: string }) {
    this.events.push(data);
    console.log(`Analytics: searched "${data.query}"`);
  }

  @EventPattern('order_completed')
  handleOrderCompleted(@Payload() data: { orderId: string; total: number }) {
    this.events.push(data);
    console.log(`Analytics: order ${data.orderId} completed`);
  }
}
```

```typescript
// apps/web-app/src/app.service.ts
import { Injectable, Inject } from '@nestjs/common';
import { ClientProxy } from '@nestjs/microservices';

@Injectable()
export class AppService {
  constructor(
    @Inject('ANALYTICS_SERVICE') private readonly analyticsClient: ClientProxy,
    @Inject('LOGGING_SERVICE') private readonly loggingClient: ClientProxy,
  ) {}

  trackPageView(page: string, userId: string) {
    this.analyticsClient.emit('page_viewed', { page, userId, timestamp: new Date() });
  }

  searchProduct(query: string, userId: string) {
    this.loggingClient.emit('search_performed', { query, userId });
    return `Searching for: ${query}`;
  }
}
```

## Cara Integrasi & Pengujian
Panggil `client.emit()` tanpa `await`. Event akan diproses secara asynchronous oleh consumer. Jika perlu memastikan event terkirim, gunakan `await lastValueFrom(client.emit(...))`.
