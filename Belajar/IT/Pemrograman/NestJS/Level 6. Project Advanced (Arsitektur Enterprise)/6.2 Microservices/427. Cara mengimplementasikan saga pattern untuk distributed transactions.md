# 427. Cara mengimplementasikan saga pattern untuk distributed transactions

## Definisi & Target
Saga pattern mengelola distributed transactions dengan memecah transaksi besar menjadi serangkaian local transactions yang memiliki aksi kompensasi jika gagal. Targetnya adalah menjaga data consistency tanpa menggunakan distributed lock.

## Komponen & Nest CLI Command
```
Saga flow (Order -> Payment -> Inventory):
  1. Create Order (pending)
  2. Process Payment (compensation: refund)
  3. Reserve Inventory (compensation: release stock)
  4. All success -> mark order confirmed
  Jika gagal di step 3 -> run compensation step 2
```

## Kode Implementasi (Per File)
```typescript
// apps/order-service/src/saga/create-order.saga.ts
import { Injectable, Inject } from '@nestjs/common';
import { ClientProxy } from '@nestjs/microservices';
import { lastValueFrom } from 'rxjs';

@Injectable()
export class CreateOrderSaga {
  private sagaState: { orderId?: string; paymentId?: string; inventoryReserved?: boolean } = {};

  constructor(
    @Inject('PAYMENT_SERVICE') private paymentClient: ClientProxy,
    @Inject('INVENTORY_SERVICE') private inventoryClient: ClientProxy,
    @Inject('ORDER_REPO') private orderRepo: any,
  ) {}

  async execute(orderData: { productId: string; quantity: number; amount: number }) {
    try {
      const order = await this.orderRepo.create({ status: 'pending', ...orderData });
      this.sagaState.orderId = order.id;

      const payment = await lastValueFrom(
        this.paymentClient.send({ cmd: 'process_payment' }, {
          orderId: order.id,
          amount: orderData.amount,
        }),
      );
      this.sagaState.paymentId = payment.transactionId;

      const inventory = await lastValueFrom(
        this.inventoryClient.send({ cmd: 'reserve_stock' }, {
          productId: orderData.productId,
          quantity: orderData.quantity,
        }),
      );
      this.sagaState.inventoryReserved = true;

      await this.orderRepo.update(order.id, { status: 'confirmed' });
      return { success: true, orderId: order.id };
    } catch (error) {
      await this.compensate(error);
      throw error;
    }
  }

  private async compensate(error: Error) {
    console.log(`Compensating saga due to: ${error.message}`);

    if (this.sagaState.inventoryReserved) {
      await lastValueFrom(
        this.inventoryClient.emit('release_stock', { orderId: this.sagaState.orderId }),
      );
    }

    if (this.sagaState.paymentId) {
      await lastValueFrom(
        this.paymentClient.send({ cmd: 'refund_payment' }, {
          transactionId: this.sagaState.paymentId,
        }),
      );
    }

    if (this.sagaState.orderId) {
      await this.orderRepo.update(this.sagaState.orderId, { status: 'failed' });
    }
  }
}
```

## Cara Integrasi & Pengujian
Test saga dengan membuat skenario: payment sukses tapi inventory gagal -> pastikan refund dilakukan. Gunakan timeout untuk handle saga yang terlalu lama.
