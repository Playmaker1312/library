# 428. Cara mengimplementasikan API Gateway menggunakan NestJS

## Definisi & Target
API Gateway adalah single entry point untuk semua client yang meneruskan request ke microservice yang sesuai. NestJS sebagai gateway bisa melakukan routing, authentication, rate limiting, dan response aggregation.

## Komponen & Nest CLI Command
```
Generate API Gateway:
  nest new api-gateway
  nest g module gateway
  nest g controller gateway
```

## Kode Implementasi (Per File)
```typescript
// apps/api-gateway/src/app.module.ts
import { Module } from '@nestjs/common';
import { ClientsModule, Transport } from '@nestjs/microservices';
import { GatewayController } from './gateway.controller';

@Module({
  imports: [
    ClientsModule.register([
      { name: 'USER_SERVICE', transport: Transport.TCP, options: { port: 3001 } },
      { name: 'PRODUCT_SERVICE', transport: Transport.TCP, options: { port: 3002 } },
      { name: 'ORDER_SERVICE', transport: Transport.TCP, options: { port: 3003 } },
    ]),
  ],
  controllers: [GatewayController],
})
export class AppModule {}
```

```typescript
// apps/api-gateway/src/gateway.controller.ts
import { Controller, Get, Post, Put, Delete, Param, Body, Inject } from '@nestjs/common';
import { ClientProxy } from '@nestjs/microservices';
import { lastValueFrom } from 'rxjs';

@Controller('api')
export class GatewayController {
  constructor(
    @Inject('USER_SERVICE') private userClient: ClientProxy,
    @Inject('PRODUCT_SERVICE') private productClient: ClientProxy,
    @Inject('ORDER_SERVICE') private orderClient: ClientProxy,
  ) {}

  @Get('users/:id')
  getUser(@Param('id') id: string) {
    return lastValueFrom(this.userClient.send({ cmd: 'get_user' }, { id }));
  }

  @Get('products')
  getProducts() {
    return lastValueFrom(this.productClient.send({ cmd: 'get_products' }, {}));
  }

  @Post('orders')
  createOrder(@Body() orderData: any) {
    return lastValueFrom(this.orderClient.send({ cmd: 'create_order' }, orderData));
  }

  @Get('dashboard')
  async getDashboard() {
    const [users, products] = await Promise.all([
      lastValueFrom(this.userClient.send({ cmd: 'get_users_summary' }, {})),
      lastValueFrom(this.productClient.send({ cmd: 'get_products_summary' }, {})),
    ]);
    return { users, products };
  }
}
```

## Cara Integrasi & Pengujian
Jalankan semua microservice terlebih dahulu, lalu API Gateway. Gateway akan listen di port 3000. Semua request masuk via gateway.
