# 429. Cara mengimplementasikan service discovery sederhana

## Definisi & Target
Service discovery memungkinkan service menemukan lokasi (host:port) service lain secara dinamis. Untuk project kecil, kita bisa implementasi sederhana menggunakan registry pattern tanpa tools external seperti Consul.

## Komponen & Nest CLI Command
Tidak ada CLI khusus. Buat service registry sendiri.

```
Flow:
  Service A register ke ServiceRegistry saat startup
  Service B query ServiceRegistry untuk menemukan Service A
```

## Kode Implementasi (Per File)
```typescript
// apps/service-registry/src/service-registry.service.ts
import { Injectable } from '@nestjs/common';

interface ServiceInstance {
  name: string;
  host: string;
  port: number;
  status: 'UP' | 'DOWN';
  lastHeartbeat: Date;
}

@Injectable()
export class ServiceRegistryService {
  private services: Map<string, ServiceInstance> = new Map();

  register(instance: Omit<ServiceInstance, 'status' | 'lastHeartbeat'>) {
    this.services.set(`${instance.name}:${instance.port}`, {
      ...instance,
      status: 'UP',
      lastHeartbeat: new Date(),
    });
  }

  unregister(name: string, port: number) {
    this.services.delete(`${name}:${port}`);
  }

  discover(name: string): ServiceInstance | undefined {
    return this.services.get(name);
  }

  discoverAll(name: string): ServiceInstance[] {
    return Array.from(this.services.values()).filter((s) => s.name === name && s.status === 'UP');
  }

  heartbeat(name: string, port: number) {
    const key = `${name}:${port}`;
    const instance = this.services.get(key);
    if (instance) {
      instance.lastHeartbeat = new Date();
      instance.status = 'UP';
    }
  }
}
```

```typescript
// apps/service-registry/src/registry.module.ts
import { Module, OnModuleDestroy } from '@nestjs/common';
import { ServiceRegistryService } from './service-registry.service';

@Module({
  providers: [ServiceRegistryService],
  exports: [ServiceRegistryService],
})
export class RegistryModule implements OnModuleDestroy {
  constructor(private registry: ServiceRegistryService) {}

  onModuleDestroy() {
    // cleanup stale instances
  }
}
```

```typescript
// apps/user-service/src/main.ts
import { NestFactory } from '@nestjs/core';
import { UserModule } from './user.module';
import { ServiceRegistryService } from '../service-registry/service-registry.service';

async function bootstrap() {
  const app = await NestFactory.create(UserModule);
  const registry = app.get(ServiceRegistryService);
  registry.register({ name: 'user-service', host: 'localhost', port: 3001 });
  await app.listen(3001);
}
bootstrap();
```

## Cara Integrasi & Pengujian
Service registry bisa berjalan sebagai HTTP service terpisah atau library bersama. Untuk production, gunakan Consul, etcd, atau Kubernetes DNS-based discovery.
