# 417. Memahami transport layer dalam NestJS microservices

## Definisi & Target
Transport layer adalah mekanisme komunikasi antar service. NestJS mendukung TCP, Redis, RabbitMQ, Kafka, MQTT, NATS, dan gRPC. Targetnya adalah memahami perbedaan dan kapan menggunakan masing-masing transport.

## Komponen & Nest CLI Command
```
Transport options:
  TCP:         default, sederhana, cocok untuk internal network
  Redis:       pub/sub, lightweight message broker
  RabbitMQ:    AMQP protocol, reliable, persistent queue
  Kafka:       high throughput, event streaming, partitioned log
  gRPC:        high performance, typed contract, HTTP/2
  MQTT:        IoT, low bandwidth
  NATS:        lightweight, high performance cloud messaging
```

## Kode Implementasi (Per File)
```typescript
// src/common/transport-comparison.ts
import { Transport } from '@nestjs/microservices';

export const TRANSPORT_CONFIGS = {
  [Transport.TCP]: {
    host: 'localhost',
    port: 3001,
  },
  [Transport.REDIS]: {
    host: 'localhost',
    port: 6379,
    retryAttempts: 5,
    retryDelay: 1000,
  },
  [Transport.RMQ]: {
    urls: ['amqp://localhost:5672'],
    queue: 'my_queue',
    queueOptions: { durable: true },
  },
  [Transport.KAFKA]: {
    client: { brokers: ['localhost:9092'] },
    consumer: { groupId: 'my-group' },
  },
  [Transport.GRPC]: {
    url: 'localhost:5000',
    package: 'hero',
    protoPath: 'hero.proto',
  },
};
```

## Cara Integrasi & Pengujian
Pilih transport berdasarkan kebutuhan: TCP untuk sederhana, RabbitMQ/Kafka untuk production dengan reliability tinggi, gRPC untuk performance tinggi.
