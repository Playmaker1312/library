# 422. Cara mengimplementasikan request-response pattern menggunakan send

## Definisi & Target
Request-response pattern menggunakan `client.send()` yang mengembalikan Observable. Client mengirim pesan dan menunggu response dari microservice. Targetnya adalah komunikasi synchronous antar service.

## Komponen & Nest CLI Command
```
client.send(pattern, data) -> Observable<T>
  - pattern: harus cocok dengan @MessagePattern()
  - data: payload yang dikirim
  - return: Observable yang bisa di-toPromise()
```

## Kode Implementasi (Per File)
```typescript
// apps/inventory-service/src/inventory.controller.ts
import { Controller } from '@nestjs/common';
import { MessagePattern, Payload } from '@nestjs/microservices';

@Controller()
export class InventoryController {
  @MessagePattern({ cmd: 'check_stock' })
  checkStock(@Payload() data: { productId: string; quantity: number }) {
    const available = Math.random() > 0.3;
    return { productId: data.productId, available, currentStock: available ? 50 : 0 };
  }

  @MessagePattern({ cmd: 'reserve_stock' })
  reserveStock(@Payload() data: { productId: string; quantity: number }) {
    return { success: true, reserved: data.quantity, productId: data.productId };
  }
}
```

```typescript
// apps/order-service/src/order.service.ts
import { Injectable, Inject } from '@nestjs/common';
import { ClientProxy } from '@nestjs/microservices';
import { lastValueFrom } from 'rxjs';

@Injectable()
export class OrderService {
  constructor(
    @Inject('INVENTORY_SERVICE') private readonly inventoryClient: ClientProxy,
  ) {}

  async createOrder(orderData: { productId: string; quantity: number; customerId: string }) {
    const stockCheck = await lastValueFrom(
      this.inventoryClient.send({ cmd: 'check_stock' }, {
        productId: orderData.productId,
        quantity: orderData.quantity,
      }),
    );

    if (!stockCheck.available) {
      throw new Error('Insufficient stock');
    }

    const reservation = await lastValueFrom(
      this.inventoryClient.send({ cmd: 'reserve_stock' }, {
        productId: orderData.productId,
        quantity: orderData.quantity,
      }),
    );

    return { orderId: `ORD-${Date.now()}`, status: 'confirmed', ...reservation };
  }
}
```

## Cara Integrasi & Pengujian
Gunakan `lastValueFrom()` dari RxJS untuk mengkonversi Observable ke Promise. Pastikan pattern cocok antara send dan MessagePattern.
