# 430. Cara mengimplementasikan circuit breaker pattern dalam NestJS microservices

## Definisi & Target
Circuit breaker mencegah cascading failure dengan menghentikan sementara request ke service yang gagal. NestJS bisa menggunakan library seperti `opossum` untuk implementasi circuit breaker.

## Komponen & Nest CLI Command
Instalasi: `npm install --save opossum`

```
Circuit states:
  CLOSED -> normal, request dikirim
  OPEN -> request langsung ditolak (failure threshold exceeded)
  HALF_OPEN -> trial request untuk test recovery
```

## Kode Implementasi (Per File)
```typescript
// src/common/circuit-breaker.decorator.ts
import { Injectable, Logger } from '@nestjs/common';
import * as CircuitBreaker from 'opossum';

export function CircuitBreakerDecorator(options?: CircuitBreaker.Options) {
  return (target: any, propertyKey: string, descriptor: PropertyDescriptor) => {
    const originalMethod = descriptor.value;
    const logger = new Logger('CircuitBreaker');

    descriptor.value = async function (...args: any[]) {
      const breaker = new CircuitBreaker(originalMethod.bind(this, ...args), {
        timeout: options?.timeout ?? 5000,
        errorThresholdPercentage: options?.errorThresholdPercentage ?? 50,
        resetTimeout: options?.resetTimeout ?? 30000,
        name: `${target.constructor.name}.${propertyKey}`,
      });

      breaker.on('open', () => logger.warn(`${breaker.name} circuit opened`));
      breaker.on('halfOpen', () => logger.log(`${breaker.name} circuit half-open`));
      breaker.on('close', () => logger.log(`${breaker.name} circuit closed`));

      return breaker.fire(...args);
    };

    return descriptor;
  };
}
```

```typescript
// src/orders/orders.service.ts
import { Injectable, Inject } from '@nestjs/common';
import { ClientProxy } from '@nestjs/microservices';
import { lastValueFrom } from 'rxjs';
import { CircuitBreakerDecorator } from '../common/circuit-breaker.decorator';

@Injectable()
export class OrdersService {
  constructor(@Inject('PAYMENT_SERVICE') private paymentClient: ClientProxy) {}

  @CircuitBreakerDecorator({ timeout: 3000, errorThresholdPercentage: 60, resetTimeout: 15000 })
  async processPayment(orderId: string, amount: number) {
    return lastValueFrom(
      this.paymentClient.send({ cmd: 'process_payment' }, { orderId, amount }),
    );
  }

  @CircuitBreakerDecorator({ timeout: 2000 })
  async checkInventory(productId: string, quantity: number) {
    return lastValueFrom(
      this.inventoryClient.send({ cmd: 'check_stock' }, { productId, quantity }),
    );
  }
}
```

## Cara Integrasi & Pengujian
Simulasi failure dengan mematikan service target. Circuit breaker akan `OPEN` setelah threshold tercapai. Setelah `resetTimeout`, circuit akan `HALF_OPEN` dan mencoba lagi.
