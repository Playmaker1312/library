# 425. Cara mengkonfigurasi RmqOptions untuk koneksi RabbitMQ

## Definisi & Target
`RmqOptions` adalah interface konfigurasi untuk transport RabbitMQ. Targetnya adalah mengatur koneksi, queue, dan perilaku consumer seperti retry, prefetch, dan dead letter exchange.

## Komponen & Nest CLI Command
```
RmqOptions key options:
  urls: string[]              // RabbitMQ server URLs
  queue: string               // Queue name
  queueOptions: object        // durable, exclusive, autoDelete
  noAck: boolean              // manual ack jika false
  prefetchCount: number       // max unacked messages
  socketOptions: object       // heartbeat, timeout
```

## Kode Implementasi (Per File)
```typescript
// apps/payment-service/src/rmq.config.ts
import { RmqOptions, Transport } from '@nestjs/microservices';

export const paymentQueueConfig: RmqOptions = {
  transport: Transport.RMQ,
  options: {
    urls: ['amqp://user:password@rabbitmq-cluster:5672'],
    queue: 'payment_events',
    queueOptions: {
      durable: true,
      deadLetterExchange: 'payment_dlx',
      deadLetterRoutingKey: 'payment_dlq',
    },
    noAck: false,
    prefetchCount: 5,
    persistent: true,
    socketOptions: {
      heartbeatIntervalInSeconds: 60,
      reconnectTimeInSeconds: 10,
    },
  },
};
```

```typescript
// apps/payment-service/src/main.ts
import { NestFactory } from '@nestjs/core';
import { MicroserviceOptions } from '@nestjs/microservices';
import { PaymentModule } from './payment.module';
import { paymentQueueConfig } from './rmq.config';

async function bootstrap() {
  const app = await NestFactory.createMicroservice<MicroserviceOptions>(
    PaymentModule,
    paymentQueueConfig,
  );
  await app.listen();
}
bootstrap();
```

```typescript
// apps/order-service/src/order.module.ts (client)
import { Module } from '@nestjs/common';
import { ClientsModule, Transport } from '@nestjs/microservices';

@Module({
  imports: [
    ClientsModule.register([
      {
        name: 'PAYMENT_SERVICE',
        transport: Transport.RMQ,
        options: {
          urls: ['amqp://user:password@localhost:5672'],
          queue: 'payment_events',
        },
      },
    ]),
  ],
})
export class OrderModule {}
```

## Cara Integrasi & Pengujian
Sesuaikan `urls` dengan environment. Gunakan `noAck: false` untuk memastikan pesan tidak hilang jika consumer crash. PrefetchCount mengatur berapa banyak pesan yang diproses secara paralel.
