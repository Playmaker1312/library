# 421. Cara menggunakan decorator EventPattern untuk menangani event di microservice

## Definisi & Target
`@EventPattern()` adalah decorator untuk menangani event (fire-and-forget). Berbeda dengan `@MessagePattern`, event tidak mengembalikan response ke pengirim. Targetnya adalah implementasi publish-subscribe pattern.

## Komponen & Nest CLI Command
```
Event pattern:
  @EventPattern('user_created')
  @EventPattern('order_placed')
  @EventPattern('payment_received')
```

## Kode Implementasi (Per File)
```typescript
// apps/notification-service/src/notification.controller.ts
import { Controller } from '@nestjs/common';
import { EventPattern, Payload } from '@nestjs/microservices';

@Controller()
export class NotificationController {
  @EventPattern('user_created')
  handleUserCreated(@Payload() data: { userId: string; email: string }) {
    console.log(`Send welcome email to ${data.email}`);
  }

  @EventPattern('order_placed')
  handleOrderPlaced(@Payload() data: { orderId: string; total: number }) {
    console.log(`Send order confirmation for ${data.orderId}`);
  }

  @EventPattern('payment_received')
  handlePaymentReceived(@Payload() data: { transactionId: string; amount: number }) {
    console.log(`Update payment status for ${data.transactionId}`);
  }
}
```

```typescript
// apps/notification-service/src/main.ts
import { NestFactory } from '@nestjs/core';
import { MicroserviceOptions, Transport } from '@nestjs/microservices';
import { NotificationModule } from './notification.module';

async function bootstrap() {
  const app = await NestFactory.createMicroservice<MicroserviceOptions>(
    NotificationModule,
    { transport: Transport.TCP, options: { port: 3003 } },
  );
  await app.listen();
}
bootstrap();
```

```typescript
// apps/order-service/src/order.controller.ts (pengirim event)
import { Controller, Post, Body } from '@nestjs/common';
import { ClientProxy, EventPattern } from '@nestjs/microservices';

@Controller('orders')
export class OrderController {
  constructor(@Inject('NOTIFICATION_SERVICE') private readonly notifClient: ClientProxy) {}

  @Post()
  async placeOrder(@Body() orderData: any) {
    const order = await this.orderService.create(orderData);
    this.notifClient.emit('order_placed', { orderId: order.id, total: order.total });
    return order;
  }
}
```

## Cara Integrasi & Pengujian
Gunakan `client.emit()` untuk mengirim event. Tidak perlu `await` karena fire-and-forget. Multiple service bisa subscribe ke event yang sama.
