# 420. Cara menggunakan decorator MessagePattern untuk menangani pesan di microservice

## Definisi & Target
`@MessagePattern()` adalah decorator yang digunakan di microservice untuk mendefinisikan handler pesan. Pattern bisa berupa string, object, atau wildcard. Targetnya adalah menerima dan memproses request dari client.

## Komponen & Nest CLI Command
```
Pattern types:
  @MessagePattern({ cmd: 'get_users' })     // Object pattern
  @MessagePattern('get_users')               // String pattern
  @MessagePattern('users.*')                 // Wildcard (Redis)
```

## Kode Implementasi (Per File)
```typescript
// apps/product-service/src/product.controller.ts
import { Controller } from '@nestjs/common';
import { MessagePattern, Payload } from '@nestjs/microservices';
import { ProductService } from './product.service';

@Controller()
export class ProductController {
  constructor(private readonly productService: ProductService) {}

  @MessagePattern({ cmd: 'get_products' })
  getProducts(@Payload() data: { page: number; limit: number }) {
    return this.productService.findAll(data);
  }

  @MessagePattern({ cmd: 'get_product' })
  getProduct(@Payload() data: { id: string }) {
    return this.productService.findById(data.id);
  }

  @MessagePattern({ cmd: 'create_product' })
  createProduct(@Payload() data: { name: string; price: number; stock: number }) {
    return this.productService.create(data);
  }

  @MessagePattern({ cmd: 'update_stock' })
  updateStock(@Payload() data: { id: string; quantity: number }) {
    return this.productService.updateStock(data.id, data.quantity);
  }
}
```

```typescript
// apps/product-service/src/product.service.ts
import { Injectable } from '@nestjs/common';

@Injectable()
export class ProductService {
  private products = [
    { id: 'p1', name: 'Laptop', price: 15000000, stock: 10 },
    { id: 'p2', name: 'Mouse', price: 150000, stock: 50 },
  ];

  findAll(data: { page: number; limit: number }) {
    return this.products.slice(0, data.limit);
  }

  findById(id: string) {
    return this.products.find((p) => p.id === id);
  }

  create(data: { name: string; price: number; stock: number }) {
    const product = { id: `p${Date.now()}`, ...data };
    this.products.push(product);
    return product;
  }

  updateStock(id: string, quantity: number) {
    const product = this.products.find((p) => p.id === id);
    if (product) product.stock = quantity;
    return product;
  }
}
```

## Cara Integrasi & Pengujian
Pattern di `@MessagePattern` harus cocok dengan pattern yang dikirim client via `client.send()`. Response dikembalikan sebagai return value dari method.
