# 455. Cara mengimplementasikan database connection pooling yang optimal

## Definisi & Target
Connection pooling mengelola kumpulan koneksi database yang reusable, mengurangi overhead pembuatan koneksi baru. Targetnya adalah mengoptimalkan jumlah koneksi database agar tidak overload.

## Komponen & Nest CLI Command
```
Connection pool config:
  Prisma: connection_limit di datasource
  PgBouncer: external connection pooler untuk PostgreSQL
  Pool size: CPU cores * 2 + effective disk spindles
```

## Kode Implementasi (Per File)
```prisma
// prisma/schema.prisma (connection pooling)
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
  relationMode = "prisma"
}

generator client {
  provider = "prisma-client-js"
  previewFeatures = ["driverAdapters"]
}
```

```typescript
// src/prisma/prisma.service.ts (with pool config)
import { Injectable, OnModuleDestroy, OnModuleInit } from '@nestjs/common';
import { PrismaClient } from '@prisma/client';

@Injectable()
export class PrismaService extends PrismaClient implements OnModuleInit, OnModuleDestroy {
  constructor() {
    super({
      log: process.env.NODE_ENV === 'development' ? ['query', 'warn', 'error'] : ['error'],
      errorFormat: 'minimal',
      datasourceUrl: process.env.DATABASE_URL,
    });
  }

  async onModuleInit() {
    await this.$connect();
  }

  async onModuleDestroy() {
    await this.$disconnect();
  }
}
```

```typescript
// src/prisma/prisma.module.ts (pool config via env)
import { Module } from '@nestjs/common';
import { PrismaService } from './prisma.service';

@Module({
  providers: [
    {
      provide: PrismaService,
      useFactory: () => {
        return new PrismaService();
      },
    },
  ],
  exports: [PrismaService],
})
export class PrismaModule {}
```

```properties
// .env (connection pool config)
# Connection pool: minimum 2, maximum 10
DATABASE_URL="postgresql://user:pass@localhost:5432/mydb?connection_limit=10&pool_timeout=30"
PGUSER=user
PGPASSWORD=pass
PGHOST=localhost
PGPORT=5432
PGDATABASE=mydb
PGAPPNAME=nestjs-app
```

## Cara Integrasi & Pengujian
Monitor active connections dengan `SELECT * FROM pg_stat_activity;`. Sesuaikan `connection_limit` berdasarkan beban aplikasi. Untuk high traffic, gunakan PgBouncer.
