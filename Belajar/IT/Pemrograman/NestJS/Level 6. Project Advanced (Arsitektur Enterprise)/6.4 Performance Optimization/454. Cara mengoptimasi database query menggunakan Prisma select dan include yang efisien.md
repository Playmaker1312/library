# 454. Cara mengoptimasi database query menggunakan Prisma select dan include

## Definisi & Target
Prisma `select` dan `include` membatasi kolom/relasi yang diambil dari database. Targetnya adalah mengurangi data transfer dan mempercepat query dengan hanya mengambil field yang diperlukan.

## Komponen & Nest CLI Command
```
Prisma query optimizations:
  select: { field: true }     // Ambil field tertentu saja
  include: { relation: true } // Include relasi
  omit: ['field']             // Eksklusi field (Prisma 5+)
```

## Kode Implementasi (Per File)
```typescript
// src/users/users.service.ts (optimized queries)
import { Injectable } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service';

@Injectable()
export class UsersService {
  constructor(private readonly prisma: PrismaService) {}

  async getUserProfile(id: string) {
    return this.prisma.user.findUnique({
      where: { id },
      select: {
        id: true,
        name: true,
        email: true,
        avatar: true,
        posts: {
          select: {
            id: true,
            title: true,
            createdAt: true,
          },
          take: 10,
          orderBy: { createdAt: 'desc' },
        },
        _count: { select: { posts: true, comments: true } },
      },
    });
  }

  async getUserList() {
    return this.prisma.user.findMany({
      select: { id: true, name: true, email: true },
      orderBy: { name: 'asc' },
    });
  }

  async updateUser(id: string, data: { name?: string; bio?: string }) {
    return this.prisma.user.update({
      where: { id },
      data,
      select: { id: true, name: true, bio: true },
    });
  }
}
```

```typescript
// src/posts/posts.service.ts (efficient include)
import { Injectable } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service';

@Injectable()
export class PostsService {
  constructor(private readonly prisma: PrismaService) {}

  async getPostWithMinimalAuthor(id: string) {
    return this.prisma.post.findUnique({
      where: { id },
      include: {
        author: { select: { id: true, name: true } },
        tags: { select: { name: true } },
      },
    });
  }

  async getPostsPage(page: number, limit: number) {
    return this.prisma.post.findMany({
      skip: (page - 1) * limit,
      take: limit,
      select: {
        id: true,
        title: true,
        excerpt: true,
        createdAt: true,
        author: { select: { name: true } },
        _count: { select: { comments: true } },
      },
      orderBy: { createdAt: 'desc' },
    });
  }
}
```

## Cara Integrasi & Pengujian
Gunakan `select` untuk menghindari SELECT *. Monitor query di Prisma Studio atau log query. Bandingkan performance dengan dan tanpa select.
