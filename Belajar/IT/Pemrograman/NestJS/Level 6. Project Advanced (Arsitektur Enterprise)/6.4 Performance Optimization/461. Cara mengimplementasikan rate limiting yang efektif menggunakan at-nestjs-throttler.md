# 461. Cara mengimplementasikan rate limiting menggunakan @nestjs/throttler

## Definisi & Target
Rate limiting membatasi jumlah request dari client dalam periode waktu tertentu. `@nestjs/throttler` menyediakan decorator-based rate limiting yang mudah diintegrasikan.

## Komponen & Nest CLI Command
Instalasi: `npm install @nestjs/throttler`

```
Decorators:
  @Throttle(limit: number, ttl: number)  // Override limit per endpoint
  @SkipThrottle()                         // Skip rate limiting
```

## Kode Implementasi (Per File)
```typescript
// src/app.module.ts
import { Module } from '@nestjs/common';
import { ThrottlerModule, ThrottlerGuard } from '@nestjs/throttler';
import { APP_GUARD } from '@nestjs/core';

@Module({
  imports: [
    ThrottlerModule.forRoot([
      {
        name: 'short',
        ttl: 1000,
        limit: 3,
      },
      {
        name: 'medium',
        ttl: 10000,
        limit: 20,
      },
      {
        name: 'long',
        ttl: 60000,
        limit: 100,
      },
    ]),
  ],
  providers: [
    {
      provide: APP_GUARD,
      useClass: ThrottlerGuard,
    },
  ],
})
export class AppModule {}
```

```typescript
// src/auth/auth.controller.ts
import { Controller, Post, UseGuards } from '@nestjs/common';
import { Throttle, SkipThrottle } from '@nestjs/throttler';

@Controller('auth')
export class AuthController {
  @Post('login')
  @Throttle({ default: { limit: 5, ttl: 60000 } })
  login() {
    return { message: 'Login endpoint, max 5 requests per minute' };
  }

  @Post('register')
  @Throttle({ default: { limit: 2, ttl: 60000 } })
  register() {
    return { message: 'Register endpoint, max 2 per minute' };
  }

  @SkipThrottle()
  @Post('health')
  healthCheck() {
    return { status: 'ok' };
  }
}
```

```typescript
// src/config/throttler.config.ts
import { ThrottlerModuleOptions } from '@nestjs/throttler';

export const throttlerConfig: ThrottlerModuleOptions = [
  {
    name: 'global',
    ttl: 60000,
    limit: 60,
  },
  {
    name: 'sensitive',
    ttl: 60000,
    limit: 5,
  },
];
```

## Cara Integrasi & Pengujian
Test rate limiting dengan mengirim request cepat:
```bash
for ($i=0; $i -lt 10; $i++) { curl http://localhost:3000/auth/login -X POST; }
```
Setelah limit tercapai, akan return 429 Too Many Requests.
