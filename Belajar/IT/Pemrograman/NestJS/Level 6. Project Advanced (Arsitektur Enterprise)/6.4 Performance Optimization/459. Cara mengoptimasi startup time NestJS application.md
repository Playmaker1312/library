# 459. Cara mengoptimasi startup time NestJS application

## Definisi & Target
Startup time yang cepat penting untuk development workflow dan container orchestration. Targetnya adalah mengurangi waktu yang dibutuhkan aplikasi NestJS untuk siap menerima request.

## Komponen & Nest CLI Command
```
Strategi optimasi:
  1. Lazy loading modules
  2. Tree shaking (eliminasi unused code)
  3. Compiler optimizations (swc)
  4. Minimal dependencies
  5. Externalize large packages
```

## Kode Implementasi (Per File)
```typescript
// nest-cli.json (swc builder)
{
  "$schema": "https://json.schemastore.org/nest-cli",
  "collection": "@nestjs/schematics",
  "sourceRoot": "src",
  "compilerOptions": {
    "builder": "swc",
    "typeCheck": false,

    "deleteOutDir": true,

      { "include": "**/*.proto", "outDir": "./dist" },

    ]
  }
}
```

```typescript
// src/main.ts (lazy bootstrap)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const startTime = Date.now();
  const app = await NestFactory.create(AppModule, {
    logger: process.env.NODE_ENV === 'production'
      ? ['error', 'warn']
      : ['log', 'error', 'warn', 'debug', 'verbose'],
    snapshot: process.env.NODE_ENV !== 'production',
    bufferLogs: true,
    autoFlushLogs: false,
  });

  await app.listen(3000);
  console.log(`Startup time: ${Date.now() - startTime}ms`);
}
bootstrap();
```

```typescript

```

## Cara Integrasi & Pengujian
Ukur startup time dengan `console.time`. Gunakan SWC builder (lebih cepat dari tsc). Nonaktifkan logging verbose di production.
