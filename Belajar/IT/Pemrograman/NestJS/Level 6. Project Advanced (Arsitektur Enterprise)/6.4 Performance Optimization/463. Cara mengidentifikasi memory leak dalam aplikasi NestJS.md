# 463. Cara mengidentifikasi memory leak dalam aplikasi NestJS

## Definisi & Target
Memory leak terjadi ketika memory tidak dikembalikan ke sistem setelah tidak digunakan. Targetnya adalah mengidentifikasi dan memperbaiki memory leak menggunakan tools dan teknik profiling.

## Komponen & Nest CLI Command
```
Common causes of memory leaks:
  1. Event listeners yang tidak di-unsubscribe
  2. Global variables / cache tanpa batas
  3. Closure references
  4. Large object graphs
  5. Streams tidak di-destroy
```

## Kode Implementasi (Per File)
```typescript
// src/monitoring/memory-monitor.service.ts
import { Injectable, Logger } from '@nestjs/common';
import * as v8 from 'v8';

@Injectable()
export class MemoryMonitorService {
  private readonly logger = new Logger(MemoryMonitorService.name);
  private interval: NodeJS.Timeout | null = null;

  startMonitoring(intervalMs: number = 30000) {
    this.interval = setInterval(() => {
      const usage = process.memoryUsage();
      const heapStats = v8.getHeapStatistics();

      this.logger.log({
        rss: `${Math.round(usage.rss / 1024 / 1024)} MB`,
        heapTotal: `${Math.round(usage.heapTotal / 1024 / 1024)} MB`,
        heapUsed: `${Math.round(usage.heapUsed / 1024 / 1024)} MB`,
        external: `${Math.round(usage.external / 1024 / 1024)} MB`,
        heapLimit: `${Math.round(heapStats.heap_size_limit / 1024 / 1024)} MB`,
        mallocedMemory: `${Math.round(heapStats.malloced_memory / 1024 / 1024)} MB`,
      });

      if (usage.heapUsed / heapStats.heap_size_limit > 0.8) {
        this.logger.warn('Memory usage above 80% limit');
      }
    }, intervalMs);
  }

  stopMonitoring() {
    if (this.interval) {
      clearInterval(this.interval);
      this.interval = null;
    }
  }

  takeHeapSnapshot() {
    const snapshot = v8.getHeapSnapshot();
    const fileName = `heap-${Date.now()}.heapsnapshot`;
    const fs = require('fs');
    snapshot.pipe(fs.createWriteStream(fileName));
    this.logger.log(`Heap snapshot saved: ${fileName}`);
    return fileName;
  }
}
```

```typescript
// src/main.ts (monitoring setup)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { MemoryMonitorService } from './monitoring/memory-monitor.service';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  if (process.env.NODE_ENV === 'development') {
    const monitor = app.get(MemoryMonitorService);
    monitor.startMonitoring(15000);
  }

  await app.listen(3000);
}
bootstrap();
```

## Cara Integrasi & Pengujian
Amati memory usage via `process.memoryUsage()`. Gunakan Chrome DevTools untuk analisis heap snapshot. Bandingkan memory setelah banyak request untuk deteksi leak.
