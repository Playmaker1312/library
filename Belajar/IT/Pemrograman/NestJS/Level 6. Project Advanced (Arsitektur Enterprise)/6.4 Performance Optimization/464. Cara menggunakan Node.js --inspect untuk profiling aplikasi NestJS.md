# 464. Cara menggunakan Node.js --inspect untuk profiling aplikasi NestJS

## Definisi & Target
`--inspect` flag mengaktifkan Chrome DevTools Protocol untuk debugging dan profiling. Targetnya adalah menganalisa CPU usage, heap memory, dan performance bottlenecks.

## Komponen & Nest CLI Command
```
Commands:
  node --inspect dist/main.js
  node --inspect-brk dist/main.js (pause di awal)
  node --inspect=0.0.0.0:9229 (remote debugging)
```

## Kode Implementasi (Per File)
```json
// package.json (scripts)
{
  "scripts": {
    "start:debug": "nest start --debug --watch",
    "start:inspect": "node --inspect=0.0.0.0:9229 dist/main.js",
    "start:inspect:brk": "node --inspect-brk=0.0.0.0:9229 dist/main.js",
    "profile:cpu": "node --prof dist/main.js",
    "profile:heap": "node --inspect --max-old-space-size=4096 dist/main.js"
  }
}
```

```typescript
// src/main.ts (profiling helpers)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { writeFileSync } from 'fs';

async function bootstrap() {
  const startTime = process.hrtime.bigint();

  const app = await NestFactory.create(AppModule);
  await app.listen(3000);

  const endTime = process.hrtime.bigint();
  const startupMs = Number(endTime - startTime) / 1_000_000;

  if (process.env.PROFILE_STARTUP) {
    writeFileSync('startup-metrics.json', JSON.stringify({
      startupTimeMs: startupMs,
      memoryUsage: process.memoryUsage(),
      pid: process.pid,
      timestamp: new Date().toISOString(),
    }));
  }

  console.log(`Startup time: ${startupMs.toFixed(2)}ms`);
}
bootstrap();
```

```bash
# Perintah profiling di terminal terpisah
# 1. Generate CPU profile
node --prof dist/main.js

# 2. Proses hasil profiling
node --prof-process isolate-*.log > profile.txt

# 3. Heap snapshot via Chrome DevTools
# Buka chrome://inspect -> klik "Open dedicated DevTools for Node"
```

## Cara Integrasi & Pengujian
Jalankan dengan `npm run start:inspect`. Buka Chrome DevTools via `chrome://inspect`. Gunakan tab Memory untuk heap snapshot, tab Performance untuk CPU profiling.
