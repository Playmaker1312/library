# 453. Cara mengimplementasikan response compression menggunakan middleware

## Definisi & Target
Response compression memperkecil ukuran response body (JSON, text) dengan algoritma gzip/brotli. Targetnya adalah mengurangi bandwidth dan mempercepat waktu load client.

## Komponen & Nest CLI Command
Instalasi:
```
Express: npm install compression
Fastify: npm install @fastify/compress
```

## Kode Implementasi (Per File)
```typescript
// src/main.ts (Express with compression)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import * as compression from 'compression';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.use(compression({
    level: 6,
    threshold: 1024,
    filter: (req, res) => {
      if (req.headers['x-no-compression']) return false;
      return compression.filter(req, res);
    },
  }));
  await app.listen(3000);
}
bootstrap();
```

```typescript
// src/main.ts (Fastify with compression)
import { NestFactory } from '@nestjs/core';
import { FastifyAdapter, NestFastifyApplication } from '@nestjs/platform-fastify';
import fastifyCompress from '@fastify/compress';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create<NestFastifyApplication>(
    AppModule,
    new FastifyAdapter(),
  );

  await app.register(fastifyCompress, {
    global: true,
    threshold: 1024,
    encodings: ['gzip', 'deflate', 'br'],
    brotli: require('zlib').constants.BROTLI_MODE_TEXT,
  });

  await app.listen(3000);
}
bootstrap();
```

```typescript
// src/config/compression.config.ts
export const compressionConfig = {
  level: 6,
  threshold: 1024,
  memLevel: 8,
  strategy: 0,
  chunkSize: 16 * 1024,
};
```

## Cara Integrasi & Pengujian
Test dengan curl untuk cek header `Content-Encoding: gzip`. Bandingkan ukuran response dengan dan tanpa compression menggunakan `curl --compressed`.
