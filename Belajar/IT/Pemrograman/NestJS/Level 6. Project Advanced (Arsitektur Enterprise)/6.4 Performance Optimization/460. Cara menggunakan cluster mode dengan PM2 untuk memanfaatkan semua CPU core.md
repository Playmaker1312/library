# 460. Cara menggunakan cluster mode dengan PM2 untuk memanfaatkan semua CPU core

## Definisi & Target
Cluster mode menjalankan multiple instance aplikasi di CPU core yang berbeda, memanfaatkan paralelisme. PM2 adalah process manager yang mendukung cluster mode dengan mudah.

## Komponen & Nest CLI Command
Instalasi: `npm install --save-dev pm2` atau `npm install -g pm2`

```
Cluster mode:
  PM2 fork -> multiple processes
  Load balancer distribusi request ke semua instance
  Zero-downtime restart
```

## Kode Implementasi (Per File)
```javascript
// ecosystem.config.js
module.exports = {
  apps: [
    {
      name: 'nestjs-app',
      script: 'dist/main.js',
      instances: 'max',
      exec_mode: 'cluster',
      env: {
        NODE_ENV: 'production',
        PORT: 3000,
      },
      env_development: {
        NODE_ENV: 'development',
        PORT: 3000,
      },
      watch: false,
      max_memory_restart: '1G',
      error_file: './logs/err.log',
      out_file: './logs/out.log',
      merge_logs: true,
      log_date_format: 'YYYY-MM-DD HH:mm:ss',
      kill_timeout: 5000,
      listen_timeout: 3000,
      shutdown_with_message: true,
    },
  ],
};
```

```typescript
// src/main.ts (graceful shutdown)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.enableShutdownHooks();

  process.on('SIGINT', async () => {
    console.log('Gracefully shutting down...');
    await app.close();
    process.exit(0);
  });

  process.on('SIGTERM', async () => {
    console.log('Gracefully shutting down...');
    await app.close();
    process.exit(0);
  });

  await app.listen(process.env.PORT || 3000);
}
bootstrap();
```

```json
// package.json (scripts)
{
  "scripts": {
    "build": "nest build",
    "start:prod": "node dist/main",
    "start:cluster": "pm2 start ecosystem.config.js --env production",
    "start:cluster:dev": "pm2 start ecosystem.config.js --env development",
    "pm2:stop": "pm2 stop nestjs-app",
    "pm2:restart": "pm2 restart nestjs-app",
    "pm2:logs": "pm2 logs nestjs-app",
    "pm2:status": "pm2 status"
  }
}
```

## Cara Integrasi & Pengujian
Jalankan `npm run build && npm run start:cluster`. Cek `pm2 status` untuk melihat jumlah instance. Jumlah instance = jumlah CPU core.
