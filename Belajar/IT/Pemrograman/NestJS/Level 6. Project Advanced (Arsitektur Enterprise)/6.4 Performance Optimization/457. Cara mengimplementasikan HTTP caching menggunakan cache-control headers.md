# 457. Cara mengimplementasikan HTTP caching menggunakan cache-control headers

## Definisi & Target
HTTP caching memungkinkan browser atau CDN menyimpan response. Cache-Control headers mengatur bagaimana dan berapa lama response di-cache. Targetnya adalah mengurangi request ke server untuk data statis atau jarang berubah.

## Komponen & Nest CLI Command
```
Cache-Control directives:
  public: dapat di-cache oleh siapa saja
  private: hanya untuk browser client
  max-age: durasi cache dalam detik
  s-maxage: durasi cache untuk CDN
  no-cache: revalidate sebelum pakai cache
  no-store: jangan cache sama sekali
```

## Kode Implementasi (Per File)
```typescript
// src/common/interceptors/cache-control.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable } from 'rxjs';
import { map } from 'rxjs/operators';
import { FastifyReply } from 'fastify';

@Injectable()
export class CacheControlInterceptor implements NestInterceptor {
  constructor(private readonly maxAge: number = 60) {}

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const ctx = context.switchToHttp();
    const response = ctx.getResponse<FastifyReply>();

    return next.handle().pipe(
      map((data) => {
        response.header('Cache-Control', `public, max-age=${this.maxAge}, s-maxage=${this.maxAge * 2}`);
        response.header('Vary', 'Accept-Encoding');
        response.header('ETag', this.generateEtag(JSON.stringify(data)));
        return data;
      }),
    );
  }

  private generateEtag(payload: string): string {
    const crypto = require('crypto');
    return `"${crypto.createHash('md5').update(payload).digest('hex')}"`;
  }
}
```

```typescript
// src/posts/posts.controller.ts (applying cache)
import { Controller, Get, Param, UseInterceptors } from '@nestjs/common';
import { CacheControlInterceptor } from '../common/interceptors/cache-control.interceptor';
import { PostsService } from './posts.service';

@Controller('posts')
export class PostsController {
  constructor(private readonly postsService: PostsService) {}

  @Get()
  @UseInterceptors(new CacheControlInterceptor(300))
  findAll() {
    return this.postsService.findAll();
  }

  @Get(':id')
  @UseInterceptors(new CacheControlInterceptor(600))
  findOne(@Param('id') id: string) {
    return this.postsService.findOne(id);
  }
}
```

```typescript
// src/common/decorators/cache.decorator.ts
import { CacheControlInterceptor } from '../interceptors/cache-control.interceptor';

export function CacheControl(maxAge: number) {
  return UseInterceptors(new CacheControlInterceptor(maxAge));
}
```

## Cara Integrasi & Pengujian
Cek response headers: `curl -I http://localhost:3000/posts`. Bandingkan response time request pertama vs kedua (browser cache).
