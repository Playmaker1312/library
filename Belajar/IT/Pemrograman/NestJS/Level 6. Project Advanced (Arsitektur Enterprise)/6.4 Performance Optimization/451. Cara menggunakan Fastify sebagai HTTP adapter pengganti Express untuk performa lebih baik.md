# 451. Cara menggunakan Fastify sebagai HTTP adapter pengganti Express

## Definisi & Target
Fastify adalah HTTP framework yang lebih cepat dari Express (hingga 2-3x). NestJS mendukung Fastify sebagai alternatif adapter. Targetnya adalah mengganti Express dengan Fastify untuk performa lebih baik.

## Komponen & Nest CLI Command
Instalasi:
```
npm install @nestjs/platform-fastify fastify
npm install @types/close-with-grace (optional)
```

## Kode Implementasi (Per File)
```typescript
// src/main.ts (Fastify adapter)
import { NestFactory } from '@nestjs/core';
import { FastifyAdapter, NestFastifyApplication } from '@nestjs/platform-fastify';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create<NestFastifyApplication>(
    AppModule,
    new FastifyAdapter({
      logger: true,
      bodyLimit: 1048576,
    }),
  );

  app.enableCors({
    origin: ['http://localhost:3000'],
    methods: ['GET', 'POST', 'PUT', 'DELETE'],
  });

  await app.listen(3000, '0.0.0.0');
  console.log(`Application running on: ${await app.getUrl()}`);
}
bootstrap();
```

```typescript
// src/common/filters/fastify-exception.filter.ts
import { ExceptionFilter, Catch, ArgumentsHost, HttpException } from '@nestjs/common';
import { FastifyReply } from 'fastify';

@Catch(HttpException)
export class FastifyExceptionFilter implements ExceptionFilter {
  catch(exception: HttpException, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<FastifyReply>();
    const status = exception.getStatus();

    response.status(status).send({
      statusCode: status,
      message: exception.message,
      timestamp: new Date().toISOString(),
    });
  }
}
```

## Cara Integrasi & Pengujian
Perbedaan utama: Fastify menggunakan `FastifyReply` bukan `Express Response`. Middleware dan beberapa library yang spesifik Express mungkin perlu adaptasi.
