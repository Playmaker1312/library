# 452. Cara mengkonfigurasi NestJS dengan Fastify adapter

## Definisi & Target
Konfigurasi Fastify adapter mencakup pengaturan body limit, logger, compression, hooks, dan plugins. Targetnya adalah mengoptimalkan konfigurasi Fastify untuk production.

## Komponen & Nest CLI Command
```
Fastify instance options:
  logger: boolean | object
  bodyLimit: number (bytes)
  maxParamLength: number
  ignoreTrailingSlash: boolean
  pluginTimeout: number
  trustProxy: boolean | string | string[]
```

## Kode Implementasi (Per File)
```typescript
// src/main.ts (Fastify advanced config)
import { NestFactory } from '@nestjs/core';
import { FastifyAdapter, NestFastifyApplication } from '@nestjs/platform-fastify';
import fastifyCompress from '@fastify/compress';
import fastifyHelmet from '@fastify/helmet';
import fastifyRateLimit from '@fastify/rate-limit';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create<NestFastifyApplication>(
    AppModule,
    new FastifyAdapter({
      logger: {
        level: process.env.NODE_ENV === 'production' ? 'info' : 'debug',
        transport: {
          target: 'pino-pretty',
          options: { colorize: true },
        },
      },
      bodyLimit: 5 * 1024 * 1024,
      requestTimeout: 30000,
      ignoreTrailingSlash: true,
      trustProxy: ['127.0.0.1', '::1'],
      maxParamLength: 100,
    }),
  );

  await app.register(fastifyCompress, { global: true });
  await app.register(fastifyHelmet, { contentSecurityPolicy: false });
  await app.register(fastifyRateLimit, { max: 100, timeWindow: '1 minute' });

  app.enableShutdownHooks();
  await app.listen(3000, '0.0.0.0');
}
bootstrap();
```

```typescript
// src/common/interceptors/fastify-logging.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable } from 'rxjs';
import { tap } from 'rxjs/operators';
import { FastifyRequest, FastifyReply } from 'fastify';

@Injectable()
export class FastifyLoggingInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const ctx = context.switchToHttp();
    const request = ctx.getRequest<FastifyRequest>();
    const { method, url } = request;
    const now = Date.now();

    return next.handle().pipe(
      tap(() => console.log(`${method} ${url} ${Date.now() - now}ms`)),
    );
  }
}
```

## Cara Integrasi & Pengujian
Fastify plugins didaftarkan via `app.register()`. Beberapa NestJS middleware mungkin perlu diadaptasi karena perbedaan interface.
