# 465. Cara menggunakan Clinic.js untuk diagnosa masalah performa

## Definisi & Target
Clinic.js adalah tool suite untuk menganalisa performance Node.js applications. Terdiri dari Doctor (quick check), Bubbleprof (async tracing), Flame (CPU profiling), dan HeapProfiler (memory).

## Komponen & Nest CLI Command
Instalasi: `npm install -g clinic` atau `npx clinic`

```
Tools:
  clinic doctor      -> Diagnosa umum
  clinic flame       -> CPU flamegraph
  clinic bubbleprof  -> Async latency
  clinic heapprofiler -> Memory allocation
```

## Kode Implementasi (Per File)
```json
// package.json
{
  "scripts": {
    "profile:doctor": "clinic doctor -- node dist/main.js",
    "profile:flame": "clinic flame -- node dist/main.js",
    "profile:bubble": "clinic bubbleprof -- node dist/main.js",
    "profile:heap": "clinic heapprofiler -- node dist/main.js"
  }
}
```

```typescript
// src/main.ts (autocannon load test helper)
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  await app.listen(3000);

  if (process.env.RUN_LOAD_TEST === 'true') {
    const autocannon = require('autocannon');
    const instance = autocannon({
      url: 'http://localhost:3000',
      connections: 100,
      duration: 30,
      requests: [
        { method: 'GET', path: '/api/users' },
        { method: 'GET', path: '/api/posts' },
        { method: 'POST', path: '/api/users', body: JSON.stringify({ name: 'Test' }) },
      ],
    });

    autocannon.track(instance);
    instance.on('done', async () => {
      console.log('Load test completed');
      await app.close();
      process.exit(0);
    });
  }
}
bootstrap();
```

```bash
# Cara menjalankan profiling:
# 1. Build aplikasi
npm run build

# 2. Jalankan clinic doctor
npx clinic doctor -- node dist/main.js

# 3. Di terminal lain, kirim load test
npx autocannon http://localhost:3000/api/users -c 50 -d 20

# 4. Stop aplikasi (Ctrl+C), Clinic akan generate laporan HTML
```

## Cara Integrasi & Pengujian
Jalankan Clinic dengan aplikasi NestJS. Kirim request selama profiling. Clinic akan generate visual report (flamegraph, bubble chart) yang menunjukkan bottleneck.
