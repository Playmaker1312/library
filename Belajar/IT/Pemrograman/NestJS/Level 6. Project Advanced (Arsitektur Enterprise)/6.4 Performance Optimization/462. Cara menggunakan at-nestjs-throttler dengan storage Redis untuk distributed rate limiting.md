# 462. Cara menggunakan @nestjs/throttler dengan Redis untuk distributed rate limiting

## Definisi & Target
Rate limiting perlu disimpan di centralized store (Redis) agar konsisten di semua instance aplikasi (cluster mode). Tanpa Redis, setiap instance punya counter sendiri yang tidak akurat.

## Komponen & Nest CLI Command
Instalasi: `npm install @nestjs/throttler @nestjs/throttler-storage-redis ioredis`

```
Distributed rate limiting:
  Instance A + Instance B -> Redis shared counter
  Konsisten meskipun request di-handle instance berbeda
```

## Kode Implementasi (Per File)
```typescript
// src/app.module.ts (Redis throttler storage)
import { Module } from '@nestjs/common';
import { ThrottlerModule, ThrottlerGuard } from '@nestjs/throttler';
import { ThrottlerStorageRedisService } from '@nestjs/throttler-storage-redis';
import { APP_GUARD } from '@nestjs/core';
import Redis from 'ioredis';

@Module({
  imports: [
    ThrottlerModule.forRootAsync({
      useFactory: () => ({
        throttlers: [
          { name: 'short', ttl: 1000, limit: 3 },
          { name: 'medium', ttl: 10000, limit: 20 },
          { name: 'long', ttl: 60000, limit: 100 },
        ],
        storage: new ThrottlerStorageRedisService(
          new Redis({
            host: process.env.REDIS_HOST || 'localhost',
            port: parseInt(process.env.REDIS_PORT || '6379'),
            password: process.env.REDIS_PASSWORD,
            keyPrefix: 'throttle:',
          }),
        ),
      }),
    }),
  ],
  providers: [
    { provide: APP_GUARD, useClass: ThrottlerGuard },
  ],
})
export class AppModule {}
```

```typescript
// src/auth/auth.controller.ts (sensitive endpoints)
import { Controller, Post } from '@nestjs/common';
import { Throttle, SkipThrottle } from '@nestjs/throttler';

@Controller('auth')
export class AuthController {
  @Post('login')
  @Throttle({ sensitive: { limit: 5, ttl: 60000 } })
  login() {
    return { message: 'Rate limited via Redis' };
  }

  @Post('reset-password')
  @Throttle({ sensitive: { limit: 3, ttl: 60000 } })
  resetPassword() {
    return { message: 'Max 3 requests per minute per IP' };
  }
}
```

version: '3.8'

## Cara Integrasi & Pengujian
Test dengan 2 instance aplikasi: limit tetap konsisten meskipun request bergantian antar instance. Redis key akan otomatis expire setelah TTL.
