# 443. Cara mengimplementasikan authentication dan authorization dalam GraphQL resolver

## Definisi & Target
Autentikasi di GraphQL bisa menggunakan Guard yang sama seperti di REST, diakses via context. Targetnya adalah melindungi resolver dari akses yang tidak terotorisasi.

## Komponen & Nest CLI Command
```
Auth flow:
  1. Client kirim JWT di header Authorization
  2. GraphQL context extract user dari token
  3. Guard memeriksa role/permission user
  4. Resolver menerima user di context
```

## Kode Implementasi (Per File)
```typescript
// src/common/decorators/current-user.decorator.ts
import { createParamDecorator, ExecutionContext } from '@nestjs/common';
import { GqlExecutionContext } from '@nestjs/graphql';

export const CurrentUser = createParamDecorator(
  (data: unknown, context: ExecutionContext) => {
    const ctx = GqlExecutionContext.create(context);
    return ctx.getContext().req.user;
  },
);
```

```typescript
// src/common/guards/gql-auth.guard.ts
import { Injectable, ExecutionContext } from '@nestjs/common';
import { AuthGuard } from '@nestjs/passport';
import { GqlExecutionContext } from '@nestjs/graphql';

@Injectable()
export class GqlAuthGuard extends AuthGuard('jwt') {
  getRequest(context: ExecutionContext) {
    const ctx = GqlExecutionContext.create(context);
    return ctx.getContext().req;
  }
}
```

```typescript
// src/common/guards/roles.guard.ts (GraphQL compatible)
import { Injectable, ExecutionContext } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { GqlExecutionContext } from '@nestjs/graphql';

@Injectable()
export class GqlRolesGuard {
  constructor(private reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    const requiredRoles = this.reflector.getAllAndOverride<string[]>('roles', [
      context.getHandler(),
      context.getClass(),
    ]);
    if (!requiredRoles) return true;

    const ctx = GqlExecutionContext.create(context);
    const user = ctx.getContext().req.user;
    return requiredRoles.some((role) => user.role === role);
  }
}
```

```typescript
// src/posts/posts.resolver.ts (dengan auth)
import { UseGuards } from '@nestjs/common';
import { Resolver, Query, Mutation, Args } from '@nestjs/graphql';
import { GqlAuthGuard } from '../common/guards/gql-auth.guard';
import { GqlRolesGuard } from '../common/guards/roles.guard';
import { Roles } from '../common/decorators/roles.decorator';
import { CurrentUser } from '../common/decorators/current-user.decorator';
import { Post } from './models/post.model';

@Resolver(() => Post)
export class PostsResolver {
  @Query(() => [Post])
  @UseGuards(GqlAuthGuard)
  myPosts(@CurrentUser() user: any) {
    return this.postsService.findByAuthor(user.id);
  }

  @Mutation(() => Post)
  @UseGuards(GqlAuthGuard, GqlRolesGuard)
  @Roles('ADMIN')
  createPost(@Args('input') input: CreatePostInput) {
    return this.postsService.create(input);
  }
}
```

## Cara Integrasi & Pengujian
Kirim Authorization header di Playground:
```json
{
  "Authorization": "Bearer <token>"
}
```
Query yang require auth akan gagal jika token tidak valid.
