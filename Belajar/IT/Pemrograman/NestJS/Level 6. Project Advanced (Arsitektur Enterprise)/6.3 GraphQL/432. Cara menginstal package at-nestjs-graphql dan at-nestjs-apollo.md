# 432. Cara menginstal package @nestjs/graphql dan @nestjs/apollo

## Definisi & Target
`@nestjs/graphql` adalah official NestJS package untuk integrasi GraphQL, sementara `@nestjs/apollo` menyediakan driver Apollo Server. Targetnya adalah setup GraphQL dalam project NestJS.

## Komponen & Nest CLI Command
```
Instalasi:
  npm install @nestjs/graphql @nestjs/apollo @apollo/server graphql
  npm install graphql-upload (optional, untuk file upload)
```

## Kode Implementasi (Per File)
```typescript
// package.json (dependencies)
{
  "dependencies": {
    "@nestjs/graphql": "^12.0.0",
    "@nestjs/apollo": "^12.0.0",
    "@apollo/server": "^4.0.0",
    "graphql": "^16.0.0",
    "graphql-upload": "^15.0.0"
  }
}
```

```typescript
// src/app.module.ts
import { Module } from '@nestjs/common';
import { GraphQLModule } from '@nestjs/graphql';
import { ApolloDriver, ApolloDriverConfig } from '@nestjs/apollo';
import { join } from 'path';
import { CatsModule } from './cats/cats.module';

@Module({
  imports: [
    GraphQLModule.forRoot<ApolloDriverConfig>({
      driver: ApolloDriver,
      autoSchemaFile: join(process.cwd(), 'src/schema.gql'),
      sortSchema: true,
      playground: true,
    }),
    CatsModule,
  ],
})
export class AppModule {}
```

```typescript
// src/main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  await app.listen(3000);
  console.log('GraphQL playground: http://localhost:3000/graphql');
}
bootstrap();
```

## Cara Integrasi & Pengujian
Jalankan `npm run start:dev`. Buka `http://localhost:3000/graphql` untuk GraphQL Playground. Schema akan otomatis digenerate dari decorator.
