# 434. Cara membuat Object Type menggunakan decorator ObjectType dan Field

## Definisi & Target
`@ObjectType()` dan `@Field()` digunakan untuk mendefinisikan GraphQL object types dalam kode TypeScript. Decorator ini secara otomatis menghasilkan bagian dari GraphQL schema.

## Komponen & Nest CLI Command
```
Decorators:
  @ObjectType()           // Deklarasi class sebagai GraphQL type
  @Field()                // Deklarasi property sebagai field
  @Field(() => [String])  // Array type
  @Field({ nullable: true }) // Optional field
  @Field(() => Int)       // Specific scalar type
```

## Kode Implementasi (Per File)
```typescript
// src/authors/models/author.model.ts
import { ObjectType, Field, Int, ID, Directive } from '@nestjs/graphql';

@ObjectType({ description: 'Author of posts' })
@Directive('@key(fields: "id")')
export class Author {
  @Field(() => ID)
  id: string;

  @Field()
  name: string;

  @Field({ nullable: true })
  email?: string;

  @Field(() => Int)
  age: number;

  @Field(() => [String])
  genres: string[];

  @Field(() => Boolean)
  isActive: boolean;

  @Field(() => Date)
  createdAt: Date;
}
```

```typescript
// src/posts/models/post.model.ts
import { ObjectType, Field, ID, Int, Float } from '@nestjs/graphql';

@ObjectType()
export class Post {
  @Field(() => ID)
  id: string;

  @Field()
  title: string;

  @Field({ nullable: true })
  content?: string;

  @Field(() => Int)
  viewCount: number;

  @Field(() => Float)
  averageRating: number;

  @Field(() => Boolean)
  published: boolean;
}
```

## Cara Integrasi & Pengujian
Import model di resolver. Setiap `@Field()` akan muncul di GraphQL schema. Gunakan `@Directive` untuk federation directives. Jalankan app dan cek schema yang digenerate.
