# 448. Cara mendokumentasikan GraphQL schema menggunakan GraphQL Playground

## Definisi & Target
GraphQL Playground menyediakan IDE interaktif untuk mengeksplorasi dokumentasi schema, menjalankan query, dan melihat schema types. Targetnya adalah memudahkan developer memahami API GraphQL.

## Komponen & Nest CLI Command
```
Playground aktif secara default di development:
  URL: http://localhost:3000/graphql
  
Fitur:
  - Schema explorer (Docs tab)
  - Query execution
  - History
  - Settings
  - Download schema as SDL
```

## Kode Implementasi (Per File)
```typescript
// src/app.module.ts (playground config)
import { Module } from '@nestjs/common';
import { GraphQLModule } from '@nestjs/graphql';
import { ApolloDriver, ApolloDriverConfig } from '@nestjs/apollo';

@Module({
  imports: [
    GraphQLModule.forRoot<ApolloDriverConfig>({
      driver: ApolloDriver,
      autoSchemaFile: 'src/schema.gql',
      playground: {
        settings: {
          'editor.theme': 'dark',
          'editor.cursorShape': 'line',
          'editor.fontSize': 14,
          'editor.fontFamily': "'Fira Code', 'Source Code Pro', monospace",
          'request.credentials': 'include',
          'schema.polling.enable': true,
          'schema.polling.interval': 2000,
        },
        tabs: [
          {
            name: 'Example Queries',
            query: `
              query GetUsers {
                users { id name email }
              }
              mutation CreateUser {
                createUser(input: { name: "Test", email: "test@test.com" }) {
                  id name
                }
              }
            `,
          },
        ],
      },
      introspection: process.env.NODE_ENV !== 'production',
    }),
  ],
})
export class AppModule {}
```

```typescript
// src/common/decorators/description.decorator.ts
// Gunakan field { description } untuk dokumentasi
@ObjectType({ description: 'Represents a registered user in the system' })
export class User {
  @Field(() => ID, { description: 'Unique identifier (UUID)' })
  id: string;

  @Field({ description: 'User email address (unique)' })
  email: string;

  @Field({ description: 'Display name' })
  name: string;
}
```

## Cara Integrasi & Pengujian
Buka `http://localhost:3000/graphql`. Cek tab "Docs" untuk melihat dokumentasi schema yang otomatis tergenerate dari decorator. Nonaktifkan di production dengan `playground: false`.
