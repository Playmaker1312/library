# 450. Cara mengimplementasikan GraphQL federation untuk microservices

## Definisi & Target
GraphQL Federation memungkinkan multiple GraphQL service digabung menjadi satu unified graph. Setiap service mendefinisikan bagian dari schema dan NestJS menyediakan `ApolloFederationDriver` untuk implementasi.

## Komponen & Nest CLI Command
```
Arsitektur:
  Gateway (single endpoint) -> [User Service, Post Service, Review Service]
  Setiap service punya schema masing-masing
  Gateway menggabungkan schema dari semua service
```

## Kode Implementasi (Per File)
```typescript
// apps/user-service/src/main.ts (federated service)
import { NestFactory } from '@nestjs/core';
import { GraphQLModule } from '@nestjs/graphql';
import { ApolloFederationDriver, ApolloFederationDriverConfig } from '@nestjs/apollo';
import { UserModule } from './user.module';

async function bootstrap() {
  const app = await NestFactory.create(UserModule);
  await app.listen(3001);
}
bootstrap();
```

```typescript
// apps/user-service/src/user.module.ts
import { Module } from '@nestjs/common';
import { GraphQLModule } from '@nestjs/graphql';
import { ApolloFederationDriver, ApolloFederationDriverConfig } from '@nestjs/apollo';
import { UsersResolver } from './users.resolver';

@Module({
  imports: [
    GraphQLModule.forRoot<ApolloFederationDriverConfig>({
      driver: ApolloFederationDriver,
      autoSchemaFile: { federation: 2 },
    }),
  ],
  providers: [UsersResolver],
})
export class UserModule {}
```

```typescript
// apps/user-service/src/users.resolver.ts
import { Resolver, Query, ResolveReference, Args, ID } from '@nestjs/graphql';
import { User } from './models/user.model';

@Resolver(() => User)
export class UsersResolver {
  @Query(() => [User])
  users() {
    return [
      { id: '1', name: 'John', email: 'john@test.com' },
      { id: '2', name: 'Jane', email: 'jane@test.com' },
    ];
  }

  @ResolveReference()
  resolveReference(ref: { __typename: string; id: string }) {
    return { id: ref.id, name: 'John', email: 'john@test.com' };
  }
}
```

```typescript
// apps/gateway/src/app.module.ts (Gateway)
import { Module } from '@nestjs/common';
import { GraphQLModule } from '@nestjs/graphql';
import { ApolloGatewayDriver, ApolloGatewayDriverConfig } from '@nestjs/apollo';
import { IntrospectAndCompose } from '@apollo/gateway';

@Module({
  imports: [
    GraphQLModule.forRoot<ApolloGatewayDriverConfig>({
      driver: ApolloGatewayDriver,
      gateway: {
        supergraphSdl: new IntrospectAndCompose({
          subgraphs: [
            { name: 'users', url: 'http://localhost:3001/graphql' },
            { name: 'posts', url: 'http://localhost:3002/graphql' },
          ],
        }),
      },
    }),
  ],
})
export class AppModule {}
```

## Cara Integrasi & Pengujian
Jalankan semua service (user:3001, posts:3002) lalu gateway. Gateway akan mengkomposisi schema dan melayani query yang melintasi multiple service.
