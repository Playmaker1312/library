# 446. Cara mengintegrasikan GraphQL dengan Prisma dalam NestJS

## Definisi & Target
Integrasi GraphQL dengan Prisma memungkinkan resolver membaca/menulis data langsung dari database. Targetnya adalah GraphQL resolver yang menggunakan PrismaService untuk query database.

## Komponen & Nest CLI Command
```
Flow:
  Client -> GraphQL Query -> Resolver -> PrismaService -> Database
```

## Kode Implementasi (Per File)
```typescript
// src/prisma/prisma.service.ts
import { Injectable, OnModuleDestroy, OnModuleInit } from '@nestjs/common';
import { PrismaClient } from '@prisma/client';

@Injectable()
export class PrismaService extends PrismaClient implements OnModuleInit, OnModuleDestroy {
  async onModuleInit() { await this.$connect(); }
  async onModuleDestroy() { await this.$disconnect(); }
}
```

```typescript
// src/users/models/user.model.ts
import { ObjectType, Field, ID, Directive } from '@nestjs/graphql';

@ObjectType()
@Directive('@key(fields: "id")')
export class User {
  @Field(() => ID) id: string;
  @Field() email: string;
  @Field() name: string;
  @Field({ nullable: true }) avatar?: string;
  @Field(() => Date) createdAt: Date;
  @Field(() => Date) updatedAt: Date;
}
```

```typescript
// src/users/users.resolver.ts
import { Resolver, Query, Mutation, Args, ID } from '@nestjs/graphql';
import { User } from './models/user.model';
import { PrismaService } from '../prisma/prisma.service';
import { CreateUserInput } from './dto/create-user.input';

@Resolver(() => User)
export class UsersResolver {
  constructor(private readonly prisma: PrismaService) {}

  @Query(() => [User])
  async users() {
    return this.prisma.user.findMany();
  }

  @Query(() => User, { nullable: true })
  async user(@Args('id', { type: () => ID }) id: string) {
    return this.prisma.user.findUnique({ where: { id } });
  }

  @Mutation(() => User)
  async createUser(@Args('input') input: CreateUserInput) {
    return this.prisma.user.create({ data: input });
  }

  @Mutation(() => User)
  async updateUser(
    @Args('id', { type: () => ID }) id: string,
    @Args('input') input: CreateUserInput,
  ) {
    return this.prisma.user.update({ where: { id }, data: input });
  }

  @Mutation(() => Boolean)
  async deleteUser(@Args('id', { type: () => ID }) id: string) {
    await this.prisma.user.delete({ where: { id } });
    return true;
  }
}
```

## Cara Integrasi & Pengujian
Jalankan migrasi Prisma. Resolver akan otomatis membaca/ menulis ke database. Test query dan mutation di Playground.
