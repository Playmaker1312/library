# 431. Memahami konsep GraphQL dan kegunaannya sebagai alternatif REST dalam NestJS

## Definisi & Target
GraphQL adalah query language untuk API yang memungkinkan client meminta data spesifik yang dibutuhkan. Berbeda dengan REST yang memiliki multiple endpoints, GraphQL menggunakan single endpoint dengan query yang fleksibel.

## Komponen & Nest CLI Command
```
Perbandingan REST vs GraphQL:
  REST: GET /users, GET /users/:id, POST /users
  GraphQL: POST /graphql { query { users { id name } } }

Keunggulan GraphQL:
  - Client menentukan struktur response
  - Mengurangi over-fetching dan under-fetching
  - Single endpoint
  - Strongly typed schema
  - Subscriptions untuk real-time
```

## Kode Implementasi (Per File)
```typescript
// perbandingan-rest-graphql.md
# REST vs GraphQL

## Contoh Request REST
GET /users/1 -> { id: 1, name: "John", email: "john@test.com", createdAt: "2024-01-01" }
Client hanya butuh name, tapi terima semua field (over-fetching).

## Contoh Request GraphQL
query { user(id: 1) { name } }
Response: { data: { user: { name: "John" } } }
Client hanya dapat name (no over-fetching).

## NestJS Implementation
REST: @Get(), @Post(), @Controller()
GraphQL: @Query(), @Mutation(), @Subscription(), @Resolver()
```

## Cara Integrasi & Pengujian
Pilih GraphQL jika client memiliki kebutuhan data yang bervariasi, atau jika ada banyak client (mobile, web, third-party) dengan kebutuhan berbeda.
