# 447. Cara menggunakan Pothos atau TypeGraphQL sebagai alternatif code-first

## Definisi & Target
Pothos (sebelumnya Pothos GraphQL) dan TypeGraphQL adalah library code-first GraphQL untuk TypeScript. NestJS secara native menggunakan decorator-nya sendiri, tapi bisa diintegrasikan dengan Pothos untuk fleksibilitas lebih.

## Komponen & Nest CLI Command
Instalasi Pothos:
```
npm install @pothos/core @pothos/plugin-prisma
npm install @pothos/plugin-validation @pothos/plugin-scope-auth
```

## Kode Implementasi (Per File)
```typescript
// src/graphql/builder.ts (Pothos setup)
import SchemaBuilder from '@pothos/core';
import PrismaPlugin from '@pothos/plugin-prisma';
import type PrismaTypes from '@pothos/plugin-prisma/generated';
import { PrismaClient } from '@prisma/client';

const prisma = new PrismaClient();

export const builder = new SchemaBuilder<{
  PrismaTypes: PrismaTypes;
  Context: { user: { id: string; role: string } | null };
}>({
  plugins: [PrismaPlugin],
  prisma: { client: prisma },
});

builder.queryType({});
builder.mutationType({});
```

```typescript
// src/graphql/schema.ts (Pothos types)
import { builder } from './builder';
import { Prisma } from '@prisma/client';

builder.prismaObject('User', {
  fields: (t) => ({
    id: t.exposeID('id'),
    email: t.exposeString('email'),
    name: t.exposeString('name'),
    posts: t.relation('posts'),
  }),
});

builder.prismaObject('Post', {
  fields: (t) => ({
    id: t.exposeID('id'),
    title: t.exposeString('title'),
    content: t.exposeString('content', { nullable: true }),
    author: t.relation('author'),
  }),
});

builder.queryFields((t) => ({
  users: t.prismaField({
    type: ['User'],
    resolve: (query, _parent, _args, ctx) =>
      prisma.user.findMany({ ...query }),
  }),
  post: t.prismaField({
    type: 'Post',
    nullable: true,
    args: { id: t.arg.id({ required: true }) },
    resolve: (query, _parent, args) =>
      prisma.post.findUnique({ ...query, where: { id: args.id } }),
  }),
}));
```

```typescript
// src/graphql/graphql.module.ts
import { Module } from '@nestjs/common';
import { GraphQLModule } from '@nestjs/graphql';
import { ApolloDriver, ApolloDriverConfig } from '@nestjs/apollo';
import { builder } from './builder';
import { schema } from './schema';

@Module({
  imports: [
    GraphQLModule.forRoot<ApolloDriverConfig>({
      driver: ApolloDriver,
      schema: builder.toSchema(),
    }),
  ],
})
export class GraphqlModule {}
```

## Cara Integrasi & Pengujian
Pilih Pothos jika butuh plugin rich ecosystem (validation, auth). NestJS native decorator lebih sederhana untuk project kecil.
