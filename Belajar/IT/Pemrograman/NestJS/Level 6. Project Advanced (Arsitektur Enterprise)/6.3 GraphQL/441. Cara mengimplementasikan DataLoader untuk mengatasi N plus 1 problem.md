# 441. Cara mengimplementasikan DataLoader untuk mengatasi N plus 1 problem

## Definisi & Target
N+1 problem terjadi ketika resolver memanggil database berulang kali untuk setiap item. DataLoader melakukan batching dan caching untuk menggabungkan banyak request menjadi satu query. Targetnya adalah optimasi query GraphQL.

## Komponen & Nest CLI Command
Instalasi: `npm install --save dataloader`

```
Problem: Query { posts { author { name } } }
  -> 1 query untuk posts
  -> N query untuk author (N = jumlah posts)

Solution: DataLoader batch authors jadi 1 query
```

## Kode Implementasi (Per File)
```typescript
// src/common/dataloaders/authors.dataloader.ts
import * as DataLoader from 'dataloader';
import { AuthorsService } from '../../authors/authors.service';
import { Author } from '../../authors/models/author.model';

export function createAuthorsLoader(authorsService: AuthorsService) {
  return new DataLoader<string, Author | null>(async (ids: readonly string[]) => {
    const authors = await authorsService.findByIds(ids as string[]);
    const authorMap = new Map(authors.map((a) => [a.id, a]));
    return ids.map((id) => authorMap.get(id) || null);
  });
}
```

```typescript
// src/posts/posts.resolver.ts (dengan DataLoader)
import { Resolver, ResolveField, Parent, Context } from '@nestjs/graphql';
import { Post } from './models/post.model';
import { Author } from '../authors/models/author.model';

@Resolver(() => Post)
export class PostsResolver {
  @ResolveField(() => Author, { nullable: true })
  async author(@Parent() post: Post, @Context('authorsLoader') authorsLoader: any) {
    if (!post.authorId) return null;
    return authorsLoader.load(post.authorId);
  }
}
```

```typescript
// src/app.module.ts (setup DataLoader context)
import { Module } from '@nestjs/common';
import { GraphQLModule } from '@nestjs/graphql';
import { ApolloDriver, ApolloDriverConfig } from '@nestjs/apollo';
import { AuthorsService } from './authors/authors.service';
import { createAuthorsLoader } from './common/dataloaders/authors.dataloader';

@Module({
  imports: [
    GraphQLModule.forRoot<ApolloDriverConfig>({
      driver: ApolloDriver,
      autoSchemaFile: 'src/schema.gql',
      context: ({ req }) => {
        const authorsService = new AuthorsService();
        return {
          req,
          authorsLoader: createAuthorsLoader(authorsService),
        };
      },
    }),
  ],
})
export class AppModule {}
```

## Cara Integrasi & Pengujian
Tanpa DataLoader: N+1 query. Dengan DataLoader: hanya 2 query (1 posts + 1 batch authors). Monitoring query di log.
