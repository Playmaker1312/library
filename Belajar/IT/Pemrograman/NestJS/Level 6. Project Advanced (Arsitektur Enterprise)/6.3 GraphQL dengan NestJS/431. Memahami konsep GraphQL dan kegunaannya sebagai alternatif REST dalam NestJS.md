# 431. Memahami konsep GraphQL dan kegunaannya sebagai alternatif REST dalam NestJS

## Definisi & Target
GraphQL adalah query language untuk API dan runtime untuk memenuhi query tersebut dengan data existing. Berbeda dengan REST yang menggunakan multiple endpoints untuk berbagai resource, GraphQL menyediakan single endpoint yang memungkinkan client meminta exactly data yang mereka butuhkan. Dalam NestJS, GraphQL diimplementasikan melalui package `@nestjs/graphql` yang terintegrasi dengan Apollo Server. Keuntungan utama: mengatasi over-fetching dan under-fetching, strong typing dengan schema, real-time capabilities via subscriptions, dan introspection untuk documentation otomatis.

## Prasyarat
- Pemahaman dasar REST API dan kekurangannya
- Konsep TypeScript interfaces dan decorators
- NestJS modules, providers, dan dependency injection
- Dasar-dasar GraphQL: Query, Mutation, Subscription, Schema, Resolver

## Komponen & Nest CLI Command
```bash
npm install @nestjs/graphql @nestjs/apollo graphql apollo-server-express
nest g module graphql
nest g resolver user
```

## Langkah-langkah Implementasi (Step-by-Step)
1. Install package GraphQL dan Apollo Server untuk NestJS
2. Konfigurasi GraphQLModule di AppModule dengan code-first approach
3. Buat ObjectType untuk mendefinisikan schema entity
4. Buat Resolver dengan Query, Mutation, Subscription
5. Register Resolver di module GraphQL
6. Akses GraphQL Playground di `/graphql` untuk testing

## Kode Implementasi (Per File)

### app.module.ts
```typescript
import { Module } from '@nestjs/common';
import { GraphQLModule } from '@nestjs/graphql';
import { ApolloDriver, ApolloDriverConfig } from '@nestjs/apollo';
import { join } from 'path';
import { UserModule } from './user/user.module';

@Module({
  imports: [
    GraphQLModule.forRoot<ApolloDriverConfig>({
      driver: ApolloDriver,
      autoSchemaFile: join(process.cwd(), 'src/schema.gql'),
      playground: true,
      introspection: true,
    }),
    UserModule,
  ],
})
export class AppModule {}
```

### user/user.module.ts
```typescript
import { Module } from '@nestjs/common';
import { UserResolver } from './user.resolver';
import { UserService } from './user.service';

@Module({
  providers: [UserResolver, UserService],
  exports: [UserService],
})
export class UserModule {}
```

### user/user.resolver.ts
```typescript
import { Resolver, Query, Mutation, Args, Subscription } from '@nestjs/graphql';
import { User } from './user.model';
import { UserService } from './user.service';
import { CreateUserInput } from './create-user.input';
import { PubSub } from 'graphql-subscriptions';

const pubSub = new PubSub();

@Resolver(() => User)
export class UserResolver {
  constructor(private userService: UserService) {}

  @Query(() => [User], { name: 'users' })
  async getUsers(): Promise<User[]> {
    return this.userService.findAll();
  }

  @Query(() => User, { name: 'user', nullable: true })
  async getUser(@Args('id') id: string): Promise<User | null> {
    return this.userService.findById(id);
  }

  @Mutation(() => User)
  async createUser(@Args('input') input: CreateUserInput): Promise<User> {
    const user = await this.userService.create(input);
    pubSub.publish('userCreated', { userCreated: user });
    return user;
  }

  @Subscription(() => User, {
    filter: (payload, variables) => payload.userCreated.id === variables.id,
    resolve: (payload) => payload.userCreated,
  })
  userCreated(@Args('id') id: string) {
    return pubSub.asyncIterator('userCreated');
  }
}
```

### user/user.model.ts
```typescript
import { ObjectType, Field, ID } from '@nestjs/graphql';

@ObjectType()
export class User {
  @Field(() => ID)
  id: string;

  @Field()
  name: string;

  @Field()
  email: string;

  @Field({ nullable: true })
  avatar?: string;

  @Field()
  createdAt: Date;
}
```

### user/create-user.input.ts
```typescript
import { InputType, Field } from '@nestjs/graphql';
import { IsEmail, IsString, MinLength } from 'class-validator';

@InputType()
export class CreateUserInput {
  @Field()
  @IsString()
  @MinLength(2)
  name: string;

  @Field()
  @IsEmail()
  email: string;
}
```

## Konfigurasi & Integrasi
- `GraphQLModule.forRoot()`: driver ApolloDriver, autoSchemaFile untuk code-first, playground enabled untuk development
- `@ObjectType()`: mendefinisikan GraphQL type dari class TypeScript
- `@Field()`: mendefinisikan field dengan optional type dan nullable
- `@Resolver()`: class yang handle Query/Mutation/Subscription
- `@Args()`: mengakses argument dari query/mutation

## Troubleshooting & Common Issues
1. **Schema not generating**: Pastikan `autoSchemaFile` path benar dan folder `src` writable. Gunakan `join(process.cwd(), 'src/schema.gql')`
2. **Playground not accessible**: Set `playground: true` dan `introspection: true` di GraphQLModule config. Di production disable keduanya
3. **Subscription not working**: Pastikan Apollo Server config include `subscriptions: { path: '/graphql' }` dan client connect via WebSocket

## Best Practices
- Gunakan code-first approach untuk type safety dan single source of truth
- Pisahkan InputType dan ObjectType untuk separation of concerns
- Gunakan class-validator untuk validation di InputType
- Implementasikan DataLoader untuk N+1 problem
- Batasi query depth dan complexity untuk防止 DoS
