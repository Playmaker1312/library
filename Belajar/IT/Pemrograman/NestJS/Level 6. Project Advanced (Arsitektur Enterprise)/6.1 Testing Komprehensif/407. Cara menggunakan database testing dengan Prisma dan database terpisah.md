# 407. Cara menggunakan database testing dengan Prisma dan database terpisah

## Definisi & Target
Gunakan database terpisah (misal `nestjs_test`) untuk integration/e2e test agar tidak mengganggu database development. Targetnya adalah isolasi data test dan cleanup otomatis setelah test selesai.

## Komponen & Nest CLI Command
Buat database test di PostgreSQL. Atur `DATABASE_URL` di environment test.

```
.env.test:
  DATABASE_URL=postgresql://user:pass@localhost:5432/nestjs_test
```

## Kode Implementasi (Per File)
```typescript
// src/prisma/prisma-test.service.ts
import { Injectable, OnModuleDestroy, OnModuleInit } from '@nestjs/common';
import { PrismaClient } from '@prisma/client';

@Injectable()
export class PrismaTestService extends PrismaClient implements OnModuleInit, OnModuleDestroy {
  async onModuleInit() {
    await this.$connect();
  }

  async onModuleDestroy() {
    await this.$disconnect();
  }

  async cleanDatabase() {
    const tables = await this.$queryRawUnsafe<Array<{ tablename: string }>>(
      `SELECT tablename FROM pg_tables WHERE schemaname='public';`,
    );
    for (const { tablename } of tables) {
      await this.$executeRawUnsafe(`TRUNCATE TABLE "${tablename}" CASCADE;`);
    }
  }
}
```

```typescript
// test/database-test.module.ts
import { Module } from '@nestjs/common';
import { PrismaTestService } from './prisma-test.service';

@Module({
  providers: [PrismaTestService],
  exports: [PrismaTestService],
})
export class DatabaseTestModule {}
```

```typescript
// src/cats/cats.e2e-spec.ts
import { PrismaTestService } from '../prisma/prisma-test.service';

beforeEach(async () => {
  const prisma = app.get(PrismaTestService);
  await prisma.cleanDatabase();
});
```

## Cara Integrasi & Pengujian
Set `DATABASE_URL` di `globalSetup` atau file `.env.test`. Jalankan migrasi dengan `npx prisma migrate deploy` sebelum test.
