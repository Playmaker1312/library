# 414. Cara mengimplementasikan contract testing menggunakan Pact

## Definisi & Target
Contract testing dengan Pact memverifikasi bahwa komunikasi antara consumer dan service provider sesuai dengan kontrak yang disepakati. Targetnya adalah mendeteksi breaking changes di API sebelum deployment.

## Komponen & Nest CLI Command
Instalasi: `npm install --save-dev @pact-foundation/pact`

```
Komponen:
  PactV3: untuk membuat contract test
  MatchersV3: untuk mendefinisikan interaksi
  Verifier: untuk verifikasi di provider side
```

## Kode Implementasi (Per File)
```typescript
// test/pact/consumer.pact.spec.ts
import { PactV3, MatchersV3 } from '@pact-foundation/pact';
import { CatsService } from '../../src/cats/cats.service';

const { like, eachLike, string } = MatchersV3;

describe('Consumer Pact Test', () => {
  const provider = new PactV3({
    consumer: 'CatApp',
    provider: 'CatApi',
    port: 4000,
  });

  describe('GET /cats/:id', () => {
    it('should return a cat', async () => {
      provider
        .uponReceiving('a request for a cat by ID')
        .withRequest({ method: 'GET', path: '/cats/1' })
        .willRespondWith({
          status: 200,
          body: like({ id: '1', name: string('Tom'), breed: string('Persian') }),
        });

      await provider.executeTest(async (mockServer) => {
        const service = new CatsService(null as any);
        const result = await service.findOne('1');
        expect(result).toMatchSnapshot();
      });
    });
  });
});
```

```typescript
// test/pact/provider.pact.spec.ts
import { Verifier } from '@pact-foundation/pact';
import { Test } from '@nestjs/testing';
import { AppModule } from '../../src/app.module';

describe('Provider Pact Verification', () => {
  let app: INestApplication;

  beforeAll(async () => {
    const module = await Test.createTestingModule({
      imports: [AppModule],
    }).compile();
    app = module.createNestApplication();
    await app.listen(3000);
  });

  it('should verify consumer contracts', async () => {
    const verifier = new Verifier({
      provider: 'CatApi',
      providerBaseUrl: 'http://localhost:3000',
      pactBrokerUrl: 'http://localhost:9292',
      pactUrls: ['http://localhost:9292/pacts/provider/CatApi/consumer/CatApp/latest'],
    });

    await verifier.verifyProvider();
  });

  afterAll(async () => {
    await app.close();
  });
});
```

## Cara Integrasi & Pengujian
Jalankan consumer test dulu untuk generate pact file. Upload ke Pact Broker. Provider test membaca kontrak dari broker dan verifikasi endpoint.
