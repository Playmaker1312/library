# 399. Cara membuat mock untuk dependency yang diinjeksi dalam unit test

## Definisi & Target
Mock dependency menggantikan provider asli dengan objek tiruan yang bisa dikontrol perilakunya. Targetnya adalah mengisolasi komponen yang diuji dari dependency eksternal seperti database, API, atau service lain.

## Komponen & Nest CLI Command
Gunakan `jest.fn()`, `jest.mock()`, dan `{ provide: ..., useValue: ... }`.

```
Pola umum:
  { provide: RealDependency, useValue: mockObject }
  { provide: RealDependency, useClass: MockClass }
  { provide: RealDependency, useFactory: () => mockObject }
```

## Kode Implementasi (Per File)
```typescript
// src/orders/orders.service.spec.ts
import { Test } from '@nestjs/testing';
import { OrdersService } from './orders.service';
import { PrismaService } from '../prisma/prisma.service';
import { EmailService } from '../email/email.service';
import { PaymentService } from '../payment/payment.service';

describe('OrdersService', () => {
  let service: OrdersService;
  const mockPrisma = {
    order: { create: jest.fn(), findMany: jest.fn(), update: jest.fn() },
  };
  const mockEmail = { sendOrderConfirmation: jest.fn() };
  const mockPayment = { processPayment: jest.fn() };

  beforeEach(async () => {
    const module = await Test.createTestingModule({
      providers: [
        OrdersService,
        { provide: PrismaService, useValue: mockPrisma },
        { provide: EmailService, useValue: mockEmail },
        { provide: PaymentService, useValue: mockPayment },
      ],
    }).compile();

    service = module.get<OrdersService>(OrdersService);
  });

  it('should create order successfully', async () => {
    const dto = { productId: 'p1', quantity: 2 };
    mockPrisma.order.create.mockResolvedValue({ id: 'o1', ...dto, status: 'pending' });
    mockPayment.processPayment.mockResolvedValue({ success: true });
    mockEmail.sendOrderConfirmation.mockResolvedValue(true);

    const result = await service.create(dto);
    expect(result.status).toEqual('pending');
    expect(mockPayment.processPayment).toHaveBeenCalledTimes(1);
    expect(mockEmail.sendOrderConfirmation).toHaveBeenCalledTimes(1);
  });
});
```

## Cara Integrasi & Pengujian
Pastikan setiap dependency di-provider map dengan mock object. Semua method mock bisa dipanggil dengan `.mockResolvedValue()`, `.mockRejectedValue()`, atau `.mockReturnValue()`.
