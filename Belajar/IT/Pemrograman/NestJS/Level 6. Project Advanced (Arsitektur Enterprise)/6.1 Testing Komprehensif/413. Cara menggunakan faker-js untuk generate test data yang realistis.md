# 413. Cara menggunakan faker-js untuk generate test data yang realistis

## Definisi & Target
Faker-js adalah library untuk generate data palsu yang realistis (nama, email, alamat, dll). Targetnya adalah membuat test data yang bervariasi dan mirip data asli tanpa hardcode.

## Komponen & Nest CLI Command
Instalasi: `npm install --save-dev @faker-js/faker`

```
Kategori data:
  faker.internet.email()
  faker.person.fullName()
  faker.location.streetAddress()
  faker.number.int()
  faker.date.past()
  faker.string.uuid()
```

## Kode Implementasi (Per File)
```typescript
// test/factories/transaction.factory.ts
import { faker } from '@faker-js/faker';

interface TransactionFactoryOptions {
  amount?: number;
  type?: 'INCOME' | 'EXPENSE';
  category?: string;
  accountId?: string;
}

export function createTransactionFactory(overrides: TransactionFactoryOptions = {}) {
  return {
    amount: faker.number.int({ min: 1000, max: 10000000 }),
    type: faker.helpers.arrayElement(['INCOME', 'EXPENSE'] as const),
    category: faker.finance.transactionType(),
    description: faker.finance.transactionDescription(),
    date: faker.date.recent({ days: 30 }),
    reference: faker.string.alphanumeric(10).toUpperCase(),
    ...overrides,
  };
}
```

```typescript
// test/factories/bank-account.factory.ts
import { faker } from '@faker-js/faker';

export function createBankAccountFactory(overrides: Partial<{
  accountNumber: string;
  bankName: string;
  balance: number;
  currency: string;
}> = {}) {
  return {
    accountNumber: faker.finance.accountNumber(16),
    bankName: faker.company.name() + ' Bank',
    balance: faker.number.int({ min: 0, max: 100000000 }),
    currency: 'IDR',
    ...overrides,
  };
}
```

```typescript
// src/transactions/transactions.service.spec.ts
import { createTransactionFactory } from '../../test/factories/transaction.factory';
import { faker } from '@faker-js/faker';

describe('TransactionsService', () => {
  it('should create transaction with faker data', async () => {
    const txData = createTransactionFactory({
      amount: 50000,
      type: 'INCOME',
    });

    mockPrisma.transaction.create.mockResolvedValue({
      id: faker.string.uuid(),
      ...txData,
    });

    const result = await service.create(txData);
    expect(result.amount).toBe(50000);
    expect(result.type).toBe('INCOME');
  });
});
```

## Cara Integrasi & Pengujian
Import faker di factory atau langsung di test. Gunakan `faker.helpers.arrayElement` untuk nilai random dari daftar. Pastikan data konsisten dengan menyimpan hasil faker ke variable.
