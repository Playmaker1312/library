# 401. Cara menggunakan jest.spyOn untuk memantau pemanggilan metode

## Definisi & Target
`jest.spyOn` digunakan untuk membungkus metode yang sudah ada dengan spy, memungkinkan kita memantau apakah metode dipanggil, berapa kali dipanggil, dan dengan argumen apa. Targetnya adalah verifikasi interaksi antar komponen tanpa mengganti implementasi.

## Komponen & Nest CLI Command
Gunakan `jest.spyOn(object, 'methodName')`.

```
Metode:
  jest.spyOn(service, 'method')
  jest.spyOn(service, 'method').mockReturnValue(value)
  jest.spyOn(service, 'method').mockImplementation(() => { ... })
  expect(spy).toHaveBeenCalled()
  expect(spy).toHaveBeenCalledWith(...args)
```

## Kode Implementasi (Per File)
```typescript
// src/logs/logs.service.spec.ts
import { Test } from '@nestjs/testing';
import { LogsService } from './logs.service';
import { LogsRepository } from './logs.repository';

describe('LogsService', () => {
  let service: LogsService;
  let repo: LogsRepository;

  beforeEach(async () => {
    const module = await Test.createTestingModule({
      providers: [
        LogsService,
        {
          provide: LogsRepository,
          useValue: { save: jest.fn(), findAll: jest.fn() },
        },
      ],
    }).compile();

    service = module.get<LogsService>(LogsService);
    repo = module.get<LogsRepository>(LogsRepository);
  });

  it('should call repository save with correct data', async () => {
    const repoSpy = jest.spyOn(repo, 'save');
    const logData = { action: 'LOGIN', userId: 'u1' };

    await service.logAction(logData);
    expect(repoSpy).toHaveBeenCalledWith(logData);
    expect(repoSpy).toHaveBeenCalledTimes(1);
  });

  it('should spy on private method via public method', () => {
    const formatSpy = jest.spyOn(service as any, 'formatMessage');
    service.getFormattedLog('test');
    expect(formatSpy).toHaveBeenCalledWith('test');
  });
});
```

## Cara Integrasi & Pengujian
Gunakan `jest.spyOn` untuk memverifikasi interaksi. Untuk mengembalikan mock value, gunakan `.mockReturnValue()` atau `.mockResolvedValue()`. Jangan lupa panggil `mockRestore()` setelah test jika perlu.
