# 412. Cara membuat factory functions untuk membuat test data yang konsisten

## Definisi & Target
Factory functions adalah fungsi reusable untuk membuat objek data test dengan nilai default yang bisa di-override. Targetnya adalah mengurangi duplikasi kode pembuatan data test dan menjaga konsistensi.

## Komponen & Nest CLI Command
Buat folder `src/common/factories/` atau `test/factories/`.

## Kode Implementasi (Per File)
```typescript
// test/factories/user.factory.ts
import { faker } from '@faker-js/faker';

interface UserFactoryOptions {
  email?: string;
  name?: string;
  role?: 'USER' | 'ADMIN';
  isActive?: boolean;
}

export function createUserFactory(overrides: UserFactoryOptions = {}) {
  return {
    email: faker.internet.email(),
    name: faker.person.fullName(),
    role: 'USER' as const,
    isActive: true,
    ...overrides,
  };
}

export function createAdminFactory(overrides: UserFactoryOptions = {}) {
  return createUserFactory({ role: 'ADMIN', ...overrides });
}
```

```typescript
// test/factories/post.factory.ts
import { faker } from '@faker-js/faker';

interface PostFactoryOptions {
  title?: string;
  content?: string;
  authorId: string;
  published?: boolean;
}

export function createPostFactory(authorId: string, overrides: Partial<PostFactoryOptions> = {}) {
  return {
    title: faker.lorem.sentence(),
    content: faker.lorem.paragraphs(2),
    authorId,
    published: true,
    ...overrides,
  };
}
```

```typescript
// src/posts/posts.service.spec.ts
import { createUserFactory, createPostFactory } from '../../test/factories';

describe('PostsService', () => {
  it('should create post from factory data', async () => {
    const userData = createUserFactory({ role: 'ADMIN' });
    const postData = createPostFactory('u1', { title: 'Custom Title' });

    mockPrisma.user.create.mockResolvedValue({ id: 'u1', ...userData });
    mockPrisma.post.create.mockResolvedValue({ id: 'p1', ...postData });

    const user = await service.createUser(userData);
    const post = await service.createPost(postData);

    expect(post.title).toEqual('Custom Title');
    expect(user.role).toEqual('ADMIN');
  });
});
```

## Cara Integrasi & Pengujian
Import factory di file test. Gunakan spread operator untuk override field tertentu. Factory bisa digunakan di unit, integration, dan e2e test.
