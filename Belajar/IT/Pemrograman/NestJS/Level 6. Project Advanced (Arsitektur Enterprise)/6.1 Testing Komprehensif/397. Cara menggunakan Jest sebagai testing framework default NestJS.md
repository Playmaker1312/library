# 397. Cara menggunakan Jest sebagai testing framework default NestJS

## Definisi & Target
Jest adalah testing framework default bawaan NestJS. Menyediakan test runner, assertion library, mocking, dan code coverage dalam satu paket. Targetnya adalah memahami konfigurasi Jest dan perintah dasarnya.

## Komponen & Nest CLI Command
Tidak perlu instalasi tambahan. Konfigurasi ada di `package.json` dan `nest-cli.json`.

```
package.json:
  "jest": { ... }       // konfigurasi Jest
  "scripts": {
    "test": "jest",
    "test:watch": "jest --watch",
    "test:cov": "jest --coverage",
    "test:e2e": "jest --config ./test/jest-e2e.json"
  }
```

## Kode Implementasi (Per File)
```json
// package.json (bagian jest)
{
  "jest": {
    "moduleFileExtensions": ["js", "json", "ts"],
    "rootDir": "src",
    "testRegex": ".*\\.spec\\.ts$",
    "transform": {
      "^.+\\.(t|j)s$": "ts-jest"
    },
    "collectCoverageFrom": ["**/*.(t|j)s"],
    "coverageDirectory": "../coverage",
    "testEnvironment": "node"
  }
}
```

## Cara Integrasi & Pengujian
Jalankan `npm test` untuk menjalankan semua `*.spec.ts` file. Gunakan `npm test -- --watch` untuk mode watch. Coverage report ada di folder `coverage/`.
