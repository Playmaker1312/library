# 400. Cara menggunakan Test.createTestingModule untuk membuat testing module

## Definisi & Target
`Test.createTestingModule` adalah utilitas NestJS untuk membuat module terisolasi untuk testing. Metode ini meniru `@Module()` dekorator dan memungkinkan override provider, import module nyata, atau mengganti dependency dengan mock.

## Komponen & Nest CLI Command
Import dari `@nestjs/testing`.

```
Methods chain:
  Test.createTestingModule({ imports, controllers, providers, exports })
    .overrideProvider(SomeProvider).useValue(mock)
    .compile()
```

## Kode Implementasi (Per File)
```typescript
// src/users/users.service.spec.ts
import { Test } from '@nestjs/testing';
import { UsersService } from './users.service';
import { UsersRepository } from './users.repository';
import { ConfigService } from '@nestjs/config';

describe('UsersService', () => {
  let service: UsersService;

  beforeEach(async () => {
    const module = await Test.createTestingModule({
      imports: [],
      providers: [
        UsersService,
        {
          provide: UsersRepository,
          useValue: {
            create: jest.fn(),
            findByEmail: jest.fn(),
          },
        },
        {
          provide: ConfigService,
          useValue: { get: jest.fn().mockReturnValue('secret-key') },
        },
      ],
    }).compile();

    service = module.get<UsersService>(UsersService);
  });

  it('should create user', async () => {
    const dto = { email: 'test@test.com', name: 'Test' };
    const repo = module.get(UsersRepository);
    repo.create.mockResolvedValue({ id: 'u1', ...dto });
    const result = await service.create(dto);
    expect(result.email).toEqual('test@test.com');
  });
});
```

## Cara Integrasi & Pengujian
Gunakan `.compile()` untuk menyelesaikan module. Akses service dengan `module.get<Type>(ServiceName)`. Untuk override, gunakan `.overrideProvider().useValue()` sebelum `.compile()`.
