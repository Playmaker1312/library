# 409. Cara mengukur code coverage dan menetapkan threshold minimum

## Definisi & Target
Code coverage mengukur persentase kode yang di-cover oleh test. Targetnya adalah memastikan minimal coverage tertentu (misal 80%) dengan threshold yang akan membuat test gagal jika di bawah batas.

## Komponen & Nest CLI Command
Konfigurasi di `package.json` (bagian jest) atau file jest konfigurasi terpisah.

```
Metrics:
  statements: persentase pernyataan yang dieksekusi
  branches: persentase percabangan yang diuji
  functions: persentase fungsi yang dipanggil
  lines: persentase baris yang dieksekusi
```

## Kode Implementasi (Per File)
```json
// package.json (bagian jest)
{
  "jest": {
    "collectCoverage": true,
    "coverageDirectory": "coverage",
    "coverageReporters": ["text", "lcov", "html"],
    "coverageThreshold": {
      "global": {
        "statements": 80,
        "branches": 75,
        "functions": 80,
        "lines": 80
      },
      "./src/domain/**/*.ts": {
        "statements": 90,
        "branches": 85,
        "functions": 90,
        "lines": 90
      }
    },
    "collectCoverageFrom": [
      "src/**/*.ts",
      "!src/**/*.module.ts",
      "!src/main.ts",
      "!src/**/*.d.ts"
    ]
  }
}
```

```typescript
// jest.config.ts
import type { Config } from 'jest';

const config: Config = {
  moduleFileExtensions: ['js', 'json', 'ts'],
  rootDir: 'src',
  testRegex: '.*\\.spec\\.ts$',
  transform: { '^.+\\.(t|j)s$': 'ts-jest' },
  collectCoverageFrom: ['**/*.(t|j)s', '!**/*.module.ts', '!main.ts'],
  coverageDirectory: '../coverage',
  coverageThreshold: {
    global: {
      statements: 80,
      branches: 75,
      functions: 80,
      lines: 80,
    },
  },
  testEnvironment: 'node',
};

export default config;
```

## Cara Integrasi & Pengujian
Jalankan `npx jest --coverage`. Hasil coverage akan muncul di terminal (text) dan folder `coverage/` (html). Jika threshold tidak terpenuhi, Jest akan exit dengan kode error.
