# 408. Cara mengimplementasikan database seeding khusus untuk testing

## Definisi & Target
Database seeding untuk testing menyediakan data awal yang konsisten di setiap test run. Targetnya adalah memastikan test memiliki data yang predictable tanpa bergantung pada state database sebelumnya.

## Komponen & Nest CLI Command
Buat file seeder terpisah. Panggil di `beforeEach` test.

```
File:
  test/seed/test-seed.ts
  src/common/factories/user.factory.ts
```

## Kode Implementasi (Per File)
```typescript
// test/seed/test-seed.ts
import { PrismaClient } from '@prisma/client';

export async function seedTestData(prisma: PrismaClient) {
  const user = await prisma.user.create({
    data: {
      email: 'test@example.com',
      name: 'Test User',
      role: 'USER',
    },
  });

  const category = await prisma.category.create({
    data: { name: 'General', userId: user.id },
  });

  await prisma.post.createMany({
    data: [
      { title: 'Post 1', content: 'Content 1', authorId: user.id, categoryId: category.id },
      { title: 'Post 2', content: 'Content 2', authorId: user.id, categoryId: category.id },
    ],
  });

  return { user, category };
}
```

```typescript
// src/posts/posts.e2e-spec.ts
import * as request from 'supertest';
import { PrismaClient } from '@prisma/client';
import { seedTestData } from '../test/seed/test-seed';

describe('Posts E2E', () => {
  let app: INestApplication;
  let prisma: PrismaClient;
  let seededData: Awaited<ReturnType<typeof seedTestData>>;

  beforeEach(async () => {
    const prismaService = app.get(PrismaClient);
    await prismaService.post.deleteMany();
    await prismaService.user.deleteMany();
    seededData = await seedTestData(prismaService);
  });

  it('GET /posts should return seeded posts', async () => {
    const res = await request(app.getHttpServer()).get('/posts');
    expect(res.body.length).toEqual(2);
    expect(res.body[0].authorId).toEqual(seededData.user.id);
  });
});
```

## Cara Integrasi & Pengujian
Panggil `seedTestData` di `beforeEach` setelah cleanup. Gunakan return value untuk referensi ID di assertions.
