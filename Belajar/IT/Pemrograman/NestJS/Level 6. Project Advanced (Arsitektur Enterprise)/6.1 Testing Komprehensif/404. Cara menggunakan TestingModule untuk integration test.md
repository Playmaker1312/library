# 404. Cara menggunakan TestingModule untuk integration test

## Definisi & Target
`TestingModule` adalah hasil compile dari `Test.createTestingModule` yang menyediakan akses ke seluruh dependency. Untuk integration test, kita import module asli (bukan mock) agar komponen nyata digunakan.

## Komponen & Nest CLI Command
Import module asli di `imports`, gunakan override hanya jika perlu.

```
Methods:
  module.createNestApplication() -> untuk buat app instance
  module.get<Type>(Token) -> untuk akses provider
  module.select(Module) -> untuk seleksi module tertentu
```

## Kode Implementasi (Per File)
```typescript
// src/users/users.service.int-spec.ts
import { Test, TestingModule } from '@nestjs/testing';
import { UsersService } from './users.service';
import { UsersModule } from './users.module';
import { PrismaModule } from '../prisma/prisma.module';
import { PrismaService } from '../prisma/prisma.service';

describe('UsersService Integration', () => {
  let module: TestingModule;
  let service: UsersService;
  let prisma: PrismaService;

  beforeAll(async () => {
    module = await Test.createTestingModule({
      imports: [UsersModule, PrismaModule],
    }).compile();

    service = module.get<UsersService>(UsersService);
    prisma = module.get<PrismaService>(PrismaService);
    await prisma.$connect();
  });

  beforeEach(async () => {
    await prisma.user.deleteMany();
  });

  afterAll(async () => {
    await prisma.$disconnect();
    await module.close();
  });

  it('should create and persist user', async () => {
    const user = await service.create({ email: 'test@test.com', name: 'Test' });
    const found = await prisma.user.findUnique({ where: { id: user.id } });
    expect(found).not.toBeNull();
    expect(found!.email).toEqual('test@test.com');
  });
});
```

## Cara Integrasi & Pengujian
Gunakan `module.get()` untuk mendapatkan service nyata. Pastikan koneksi database diinisialisasi di `beforeAll` dan dibersihkan di `afterAll`.
