# 403. Cara membuat integration test untuk controller dengan database nyata

## Definisi & Target
Integration test menguji controller bersama service dan database nyata (bukan mock). Targetnya adalah memverifikasi seluruh alur dari request HTTP hingga database berfungsi dengan benar. Gunakan database terpisah (test database) untuk isolasi.

## Komponen & Nest CLI Command
Buat file `*.spec.ts` di sebelah controller. Gunakan `Test.createTestingModule` dengan import module asli.

```
Dependencies tambahan:
  @nestjs/testing
  supertest (untuk HTTP request)
```

## Kode Implementasi (Per File)
```typescript
// src/cats/cats.controller.int-spec.ts
import { Test } from '@nestjs/testing';
import { INestApplication } from '@nestjs/common';
import * as request from 'supertest';
import { CatsModule } from './cats.module';
import { PrismaService } from '../prisma/prisma.service';

describe('CatsController (Integration)', () => {
  let app: INestApplication;
  let prisma: PrismaService;

  beforeAll(async () => {
    const module = await Test.createTestingModule({
      imports: [CatsModule],
    }).compile();

    app = module.createNestApplication();
    prisma = module.get<PrismaService>(PrismaService);
    await app.init();
  });

  beforeEach(async () => {
    await prisma.cat.deleteMany();
    await prisma.cat.create({ data: { name: 'Tom', breed: 'Persian' } });
  });

  afterAll(async () => {
    await prisma.$disconnect();
    await app.close();
  });

  it('GET /cats should return all cats', async () => {
    const res = await request(app.getHttpServer()).get('/cats');
    expect(res.status).toBe(200);
    expect(res.body.length).toBeGreaterThan(0);
    expect(res.body[0].name).toEqual('Tom');
  });
});
```

## Cara Integrasi & Pengujian
Jalankan dengan `npx jest cats.controller.int-spec.ts`. Pastikan DATABASE_URL mengarah ke database test. Gunakan `beforeEach` untuk reset data.
