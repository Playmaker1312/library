# 402. Cara membuat unit test untuk guard, pipe, interceptor, dan filter

## Definisi & Target
Setiap custom NestJS component (guard, pipe, interceptor, exception filter) bisa di-test secara terisolasi. Targetnya adalah memastikan logika auth, transformasi data, logging, dan error handling berfungsi dengan benar.

## Komponen & Nest CLI Command
Tidak ada CLI khusus. Test komponen dengan membuat instance langsung.

## Kode Implementasi (Per File)
```typescript
// src/auth/roles.guard.spec.ts
import { RolesGuard } from './roles.guard';
import { Reflector } from '@nestjs/core';
import { ExecutionContext } from '@nestjs/common';

describe('RolesGuard', () => {
  let guard: RolesGuard;
  let reflector: Reflector;

  beforeEach(() => {
    reflector = new Reflector();
    guard = new RolesGuard(reflector);
  });

  it('should allow access if role matches', () => {
    const mockContext = {
      getHandler: () => null,
      switchToHttp: () => ({
        getRequest: () => ({ user: { role: 'admin' } }),
      }),
    } as unknown as ExecutionContext;

    jest.spyOn(reflector, 'get').mockReturnValue(['admin']);
    expect(guard.canActivate(mockContext)).toBe(true);
  });

  it('should deny access if role does not match', () => {
    const mockContext = {
      getHandler: () => null,
      switchToHttp: () => ({
        getRequest: () => ({ user: { role: 'user' } }),
      }),
    } as unknown as ExecutionContext;

    jest.spyOn(reflector, 'get').mockReturnValue(['admin']);
    expect(guard.canActivate(mockContext)).toBe(false);
  });
});
```

```typescript
// src/common/validation.pipe.spec.ts
import { ValidationPipe } from '@nestjs/common';

describe('ValidationPipe', () => {
  let pipe: ValidationPipe;

  beforeEach(() => {
    pipe = new ValidationPipe({ transform: true });
  });

  it('should throw on invalid data', async () => {
    const invalidData = { email: 'not-an-email' };
    await expect(pipe.transform(invalidData, {
      type: 'body',
      metatype: class { email!: string },
    } as any)).rejects.toThrow();
  });
});
```

## Cara Integrasi & Pengujian
Instantiate komponen langsung di test tanpa perlu module. Mock ExecutionContext, ArgumentsHost, atau CallHandler sesuai kebutuhan.
