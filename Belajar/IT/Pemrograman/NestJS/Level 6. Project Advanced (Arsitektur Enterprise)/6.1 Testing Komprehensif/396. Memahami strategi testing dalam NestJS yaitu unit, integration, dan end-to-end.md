# 396. Memahami strategi testing dalam NestJS yaitu unit, integration, dan end-to-end

## Definisi & Target
Testing dalam NestJS dibagi tiga level: unit test (mengisolasi satu komponen), integration test (menguji interaksi antar komponen dengan database nyata), dan end-to-end test (menguji seluruh sistem dari request HTTP hingga response). Targetnya adalah memastikan setiap lapisan aplikasi berfungsi dengan benar.

```
Alur testing:
Unit Test -> Mock semua dependency, test satu kelas
Integration Test -> Test module dengan database nyata/nyata
E2E Test -> Test HTTP endpoint lengkap dengan Supertest
```

## Komponen & Nest CLI Command
Tidak ada CLI khusus. Gunakan Jest yang sudah terintegrasi.

```
File test diletakkan bersebelahan:
  service.ts -> service.spec.ts
  controller.ts -> controller.spec.ts
  e2e/ -> folder khusus untuk e2e test
```

## Cara Integrasi & Pengujian
Jalankan `npm test` untuk unit/integration test dan `npm run test:e2e` untuk e2e test. Gunakan `--coverage` untuk laporan coverage.
