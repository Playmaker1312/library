# 410. Cara mengintegrasikan testing ke dalam GitHub Actions CI pipeline

## Definisi & Target
GitHub Actions CI pipeline menjalankan test secara otomatis setiap kali ada push atau pull request. Targetnya adalah memastikan semua test lulus sebelum kode di-merge ke branch utama.

## Komponen & Nest CLI Command
Buat file `.github/workflows/ci.yml`.

```
Workflow stages:
  checkout -> setup Node -> install dependencies -> lint -> test -> coverage upload
```

## Kode Implementasi (Per File)
```yaml
// .github/workflows/ci.yml
name: CI Pipeline

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest

    services:
      postgres:
        image: postgres:15
        env:
          POSTGRES_USER: test
          POSTGRES_PASSWORD: test
          POSTGRES_DB: nestjs_test
        ports:
          - 5432:5432
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5

    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'

      - run: npm ci
      - run: npm run lint
      - run: npx prisma generate
      - run: npx prisma migrate deploy
        env:
          DATABASE_URL: postgresql://test:test@localhost:5432/nestjs_test

      - run: npm test
        env:
          DATABASE_URL: postgresql://test:test@localhost:5432/nestjs_test
          JWT_SECRET: test-secret

      - run: npm run test:e2e
        env:
          DATABASE_URL: postgresql://test:test@localhost:5432/nestjs_test

      - uses: codecov/codecov-action@v3
        with:
          files: ./coverage/lcov.info
```

## Cara Integrasi & Pengujian
Push file `.github/workflows/ci.yml` ke repository. GitHub akan otomatis menjalankan pipeline. Cek tab "Actions" di repository untuk melihat hasil.
