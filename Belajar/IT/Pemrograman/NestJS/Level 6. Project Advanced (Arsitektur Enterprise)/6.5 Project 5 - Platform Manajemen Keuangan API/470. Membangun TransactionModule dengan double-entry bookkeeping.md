# 470. Membangun TransactionModule dengan double-entry bookkeeping

## Definisi & Target
Double-entry bookkeeping mencatat setiap transaksi dalam dua sisi (debit dan kredit). Setiap transaksi memiliki journal entries yang menjaga keseimbangan akuntansi (debit = kredit).

## Komponen & Nest CLI Command
```
Double-entry rules:
  Aset (+) = Debit, Aset (-) = Kredit
  Kewajiban (+) = Kredit, Kewajiban (-) = Debit
  Ekuitas (+) = Kredit, Ekuitas (-) = Debit
  Pendapatan (+) = Kredit
  Beban (+) = Debit
```

## Kode Implementasi (Per File)
```typescript
// src/transaction/transaction.service.ts
import { Injectable } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service';
import { IdempotencyService } from './idempotency.service';

@Injectable()
export class TransactionService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly idempotency: IdempotencyService,
  ) {}

  async createTransfer(data: {
    fromAccountId: string;
    toAccountId: string;
    amount: number;
    description?: string;
    idempotencyKey: string;
  }) {
    await this.idempotency.check(data.idempotencyKey);

    return this.prisma.$transaction(async (tx) => {
      const transaction = await tx.transaction.create({
        data: {
          accountId: data.fromAccountId,
          type: 'DEBIT',
          amount: data.amount,
          description: data.description,
          referenceId: `REF-${Date.now()}`,
          entries: {
            create: [
              { accountId: data.fromAccountId, amount: data.amount, side: 'DEBIT' },
              { accountId: data.toAccountId, amount: data.amount, side: 'CREDIT' },
            ],
          },
        },
        include: { entries: true },
      });

      await tx.account.update({
        where: { id: data.fromAccountId },
        data: { balance: { decrement: data.amount } },
      });

      await tx.account.update({
        where: { id: data.toAccountId },
        data: { balance: { increment: data.amount } },
      });

      await this.idempotency.mark(data.idempotencyKey, transaction.id);
      return transaction;
    });
  }

  async getBalance(accountId: string) {
    const debitSum = await this.prisma.journalEntry.aggregate({
      where: { accountId, side: 'DEBIT' },
      _sum: { amount: true },
    });

    const creditSum = await this.prisma.journalEntry.aggregate({
      where: { accountId, side: 'CREDIT' },
      _sum: { amount: true },
    });

    return (debitSum._sum.amount || 0) - (creditSum._sum.amount || 0);
  }
}
```

Test transfer antar akun: ambil saldo awal, lakukan transfer, verifikasi saldo akhir (debit = kredit). Gunakan database transaction untuk atomicity.
