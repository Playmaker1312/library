# 480. Mengimplementasikan IP whitelist untuk akses API yang lebih aman

## Definisi & Target
IP whitelist membatasi akses ke endpoint tertentu hanya dari alamat IP yang terdaftar. Targetnya adalah melindungi endpoint admin, webhook callback, dan internal API dari akses publik.

## Komponen & Nest CLI Command
```
Implementasi:
  IP whitelist guard -> memeriksa IP address
  Dynamic whitelist -> bisa diupdate via database
  CIDR support -> 192.168.1.0/24
```

## Kode Implementasi (Per File)
```typescript
// src/common/guards/ip-whitelist.guard.ts
import { Injectable, CanActivate, ExecutionContext, ForbiddenException } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { Observable } from 'rxjs';
import * as netmask from 'netmask';

@Injectable()
export class IpWhitelistGuard implements CanActivate {
  constructor(private readonly reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean | Promise<boolean> | Observable<boolean> {
    const whitelist = this.reflector.get<string[]>('whitelist', context.getHandler());
    if (!whitelist || whitelist.length === 0) return true;

    const request = context.switchToHttp().getRequest();
    const clientIp = this.extractIp(request);

    const isAllowed = whitelist.some((allowed) => {
      if (allowed.includes('/')) {
        const block = new netmask.Netmask(allowed);
        return block.contains(clientIp);
      }
      return allowed === clientIp;
    });

    if (!isAllowed) {
      throw new ForbiddenException('Access denied: IP not whitelisted');
    }
    return true;
  }

  private extractIp(request: any): string {
    return request.headers['x-forwarded-for']?.split(',')[0]?.trim()
      || request.headers['x-real-ip']
      || request.ip
      || request.socket?.remoteAddress;
  }
}
```

```typescript
// src/admin/admin.controller.ts
import { Controller, Get, UseGuards } from '@nestjs/common';
import { JwtAuthGuard } from '../auth/guards/jwt-auth.guard';
import { IpWhitelistGuard } from '../common/guards/ip-whitelist.guard';
import { Whitelist } from '../common/decorators/whitelist.decorator';
import { AdminService } from './admin.service';

@Controller('admin')
@UseGuards(JwtAuthGuard, IpWhitelistGuard)
@Whitelist('10.0.0.0/8', '192.168.1.100', '103.123.45.67')
export class AdminController {
  constructor(private readonly adminService: AdminService) {}

  @Get('dashboard')
  getDashboard() {
    return this.adminService.getDashboard();
  }

  @Get('users')
  getAllUsers() {
    return this.adminService.getAllUsers();
  }

  @Post('recalculate')
  recalculateBalances() {
    return this.adminService.recalculateAllBalances();
  }
}
```

import { Controller, Post, Body } from '@nestjs/common';

export class InternalController {
  constructor(private readonly webhookService: WebhookService) {}

  @Post('retry-webhooks')
  retryFailedWebhooks() {
    return { message: 'Only accessible from internal network' };
  }
}

## Cara Integrasi & Pengujian
Coba akses endpoint admin dari IP yang tidak terdaftar -> 403 Forbidden. Whitelist mendukung IP tunggal dan CIDR range.
