# 472. Mengimplementasikan database transactions untuk konsistensi data keuangan

## Definisi & Target
Database transactions memastikan atomicity operasi keuangan: semua operasi berhasil atau semua gagal. Ini critical untuk transfer uang, update saldo, dan double-entry bookkeeping.

## Komponen & Nest CLI Command
```
Prisma transaction methods:
  prisma.$transaction([...])  -> Sequential batch
  prisma.$transaction(async (tx) => { ... })  -> Interactive transaction
  Isolation levels: SERIALIZABLE (strictest) untuk finance
```

## Kode Implementasi (Per File)
```typescript
// src/account/account.service.ts (with transaction)
import { Injectable } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service';

@Injectable()
export class AccountService {
  constructor(private readonly prisma: PrismaService) {}

  async transferMoney(fromId: string, toId: string, amount: number) {
    return this.prisma.$transaction(
      async (tx) => {
        const fromAccount = await tx.account.findUniqueOrThrow({
          where: { id: fromId },
        });

        if (fromAccount.balance < amount) {
          throw new Error('Insufficient balance');
        }

        await tx.account.update({
          where: { id: fromId },
          data: { balance: { decrement: amount } },
        });

        await tx.account.update({
          where: { id: toId },
          data: { balance: { increment: amount } },
        });

        const txRecord = await tx.transaction.create({
          data: {
            accountId: fromId,
            type: 'DEBIT',
            amount,
            entries: {
              create: [
                { accountId: fromId, amount, side: 'DEBIT' },
                { accountId: toId, amount, side: 'CREDIT' },
              ],
            },
          },
        });

        return txRecord;
      },
      {
        maxWait: 5000,
        timeout: 10000,
        isolationLevel: 'Serializable',
      },
    );
  }

  async bulkTransfer(transfers: Array<{ from: string; to: string; amount: number }>) {
    return this.prisma.$transaction(
      transfers.map((t) =>
        this.prisma.$executeRaw`UPDATE account SET balance = balance - ${t.amount} WHERE id = ${t.from}`,
      ),
    );
  }
}
```

```typescript
// src/common/interceptors/transaction.interceptor.ts
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable } from 'rxjs';
import { PrismaService } from '../../prisma/prisma.service';

@Injectable()
export class TransactionInterceptor implements NestInterceptor {
  constructor(private readonly prisma: PrismaService) {}

  async intercept(context: ExecutionContext, next: CallHandler): Promise<Observable<any>> {
    return this.prisma.$transaction(async () => {
      return next.handle();
    });
  }
}
```

## Cara Integrasi & Pengujian
Test dengan sengaja membuat error di tengah transaksi: semua perubahan harus di-rollback. Verifikasi saldo tidak berubah jika transaksi gagal.
