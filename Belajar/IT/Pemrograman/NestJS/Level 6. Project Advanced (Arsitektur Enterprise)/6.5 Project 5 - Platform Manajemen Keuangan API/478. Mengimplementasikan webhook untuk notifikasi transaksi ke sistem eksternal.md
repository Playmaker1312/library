# 478. Mengimplementasikan webhook untuk notifikasi transaksi ke sistem eksternal

## Definisi & Target
Webhook mengirim notifikasi HTTP ke URL eksternal saat event terjadi (misal transaksi baru). Targetnya adalah integrasi dengan sistem akuntansi, CRM, atau notifikasi real-time.

## Komponen & Nest CLI Command
```
Generate:
  nest g module webhook
  nest g service webhook
  nest g controller webhook
```

## Kode Implementasi (Per File)
```typescript
// prisma/schema.prisma (tambahan)
model Webhook {
  id        String   @id @default(uuid())
  userId    String
  url       String
  secret    String
  events    String[]
  isActive  Boolean  @default(true)
  createdAt DateTime @default(now())
}

model WebhookDelivery {
  id         String   @id @default(uuid())
  webhookId  String
  event      String
  payload    Json
  status     Int?
  response   String?
  duration   Int?
  createdAt  DateTime @default(now())
}
```

```typescript
// src/webhook/webhook.service.ts
import { Injectable } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service';
import axios from 'axios';
import * as crypto from 'crypto';

@Injectable()
export class WebhookService {
  constructor(private readonly prisma: PrismaService) {}

  async register(userId: string, data: { url: string; events: string[] }) {
    const secret = crypto.randomBytes(32).toString('hex');
    return this.prisma.webhook.create({
      data: { ...data, userId, secret },
    });
  }

  async deliver(event: string, payload: any, userId: string) {
    const webhooks = await this.prisma.webhook.findMany({
      where: { userId, events: { has: event }, isActive: true },
    });

    for (const webhook of webhooks) {
      const startTime = Date.now();
      const signature = crypto
        .createHmac('sha256', webhook.secret)
        .update(JSON.stringify(payload))
        .digest('hex');

      try {
        const response = await axios.post(webhook.url, payload, {
          headers: {
            'Content-Type': 'application/json',
            'X-Webhook-Signature': signature,
            'X-Webhook-Event': event,
            'X-Webhook-Timestamp': new Date().toISOString(),
          },
          timeout: 5000,
        });

        await this.prisma.webhookDelivery.create({
          data: {
            webhookId: webhook.id,
            event,
            payload,
            status: response.status,
            response: JSON.stringify(response.data),
            duration: Date.now() - startTime,
          },
        });
      } catch (error: any) {
        await this.prisma.webhookDelivery.create({
          data: {
            webhookId: webhook.id,
            event,
            payload,
            status: error.response?.status || 0,
            response: error.message,
            duration: Date.now() - startTime,
          },
        });
      }
    }
  }
}
```

```typescript
// src/transaction/transaction.service.ts (trigger webhook)
import { WebhookService } from '../webhook/webhook.service';

@Injectable()
export class TransactionService {
  constructor(private readonly webhook: WebhookService) {}

  async create(data: any) {
    const transaction = await this.prisma.transaction.create({ data });
    await this.webhook.deliver('transaction.created', transaction, data.userId);
    return transaction;
  }
}
```

## Cara Integrasi & Pengujian
Register webhook URL (gunakan webhook.site untuk testing). Buat transaksi, cek webhook.site menerima notifikasi dengan signature yang valid.
