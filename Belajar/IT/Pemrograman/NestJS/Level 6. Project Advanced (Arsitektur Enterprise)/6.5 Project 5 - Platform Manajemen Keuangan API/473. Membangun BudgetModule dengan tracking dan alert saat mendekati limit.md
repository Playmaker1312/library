# 473. Membangun BudgetModule dengan tracking dan alert mendekati limit

## Definisi & Target
Budget module memungkinkan user menetapkan batas pengeluaran per kategori. Sistem akan memberi peringatan saat pengeluaran mendekati limit (misal 80%). Targetnya adalah membantu user mengontrol keuangan.

## Komponen & Nest CLI Command
```
Generate:
  nest g module budget
  nest g service budget
  nest g controller budget
  nest g class budget/dto/create-budget.dto
```

## Kode Implementasi (Per File)
```typescript
// src/budget/budget.service.ts
import { Injectable } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service';

@Injectable()
export class BudgetService {
  constructor(private readonly prisma: PrismaService) {}

  async create(userId: string, data: { categoryId: string; amount: number; period: string }) {
    const now = new Date();
    const endDate = this.calculateEndDate(data.period, now);
    return this.prisma.budget.create({
      data: { ...data, userId, startDate: now, endDate },
    });
  }

  async getBudgetStatus(userId: string, budgetId: string) {
    const budget = await this.prisma.budget.findUniqueOrThrow({
      where: { id: budgetId },
      include: { category: true },
    });

    const spent = await this.prisma.transaction.aggregate({
      where: {
        account: { userId },
        categoryId: budget.categoryId,
        type: 'DEBIT',
        createdAt: { gte: budget.startDate, lte: budget.endDate },
      },
      _sum: { amount: true },
    });

    const totalSpent = spent._sum.amount || 0;
    const percentage = (totalSpent / budget.amount) * 100;

    return {
      budget: budget.amount,
      spent: totalSpent,
      remaining: budget.amount - totalSpent,
      percentage: Math.round(percentage * 100) / 100,
      isAlert: percentage >= budget.alertAt,
    };
  }

  async checkAlerts(userId: string) {
    const budgets = await this.prisma.budget.findMany({
      where: { userId, endDate: { gte: new Date() } },
    });
    const alerts: Array<{ budgetId: string; category: string; percentage: number }> = [];
    for (const budget of budgets) {
      const status = await this.getBudgetStatus(userId, budget.id);
      if (status.isAlert) {
        alerts.push({ budgetId: budget.id, category: budget.categoryId, percentage: status.percentage });
      }
    }
    return alerts;
  }

  private calculateEndDate(period: string, start: Date): Date {
    const end = new Date(start);
    if (period === 'WEEKLY') end.setDate(end.getDate() + 7);
    else if (period === 'MONTHLY') end.setMonth(end.getMonth() + 1);
    else if (period === 'YEARLY') end.setFullYear(end.getFullYear() + 1);
    return end;
  }
}
```

## Cara Integrasi & Pengujian
Buat budget, lakukan transaksi yang melebihi threshold alert, verifikasi alert terpicu. Alert bisa dikirim via email atau notifikasi in-app.
