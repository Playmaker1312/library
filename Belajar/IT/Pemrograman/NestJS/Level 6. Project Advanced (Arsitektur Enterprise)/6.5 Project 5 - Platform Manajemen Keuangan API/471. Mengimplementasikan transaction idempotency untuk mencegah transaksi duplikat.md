# 471. Mengimplementasikan transaction idempotency untuk mencegah duplikat

## Definisi & Target
Idempotency memastikan transaksi hanya diproses sekali meskipun request dikirim berulang kali (karena network retry, double-click, dll). Setiap request memiliki unique idempotency key.

## Komponen & Nest CLI Command
```
Idempotency flow:
  1. Client kirim idempotency-key header
  2. Cek key di database -> jika ada, return response sebelumnya
  3. Jika tidak ada, proses transaksi dan simpan key
  4. Key expires setelah waktu tertentu
```

## Kode Implementasi (Per File)
```typescript
// src/transaction/idempotency.service.ts
import { Injectable, ConflictException } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service';

@Injectable()
export class IdempotencyService {
  private readonly cache = new Map<string, { response: any; expiresAt: number }>();

  constructor(private readonly prisma: PrismaService) {}

  async check(key: string): Promise<void> {
    const existing = await this.prisma.idempotencyRecord.findUnique({
      where: { key },
    });

    if (existing) {
      throw new ConflictException({
        statusCode: 409,
        message: 'Idempotency key already used',
        existingResponse: existing.response,
      });
    }
  }

  async mark(key: string, transactionId: string): Promise<void> {
    await this.prisma.idempotencyRecord.create({
      data: {
        key,
        response: { transactionId, status: 'completed' },
        expiresAt: new Date(Date.now() + 24 * 60 * 60 * 1000),
      },
    });
  }
}
```

```prisma
// prisma/schema.prisma (tambahan)
model IdempotencyRecord {
  id        String   @id @default(uuid())
  key       String   @unique
  response  Json
  createdAt DateTime @default(now())
  expiresAt DateTime

  @@index([expiresAt])
}
```

```typescript
// src/transaction/transaction.controller.ts
import { Controller, Post, Body, Headers } from '@nestjs/common';
import { TransactionService } from './transaction.service';

@Controller('transactions')
export class TransactionController {
  constructor(private readonly transactionService: TransactionService) {}

  @Post('transfer')
  async transfer(
    @Body() data: any,
    @Headers('idempotency-key') idempotencyKey: string,
  ) {
    if (!idempotencyKey) {
      throw new Error('idempotency-key header is required');
    }
    return this.transactionService.createTransfer({ ...data, idempotencyKey });
  }
}
```

## Cara Integrasi & Pengujian
Kirim request yang sama dua kali dengan idempotency key yang sama. Request kedua akan return 409 Conflict. Key expired otomatis setelah 24 jam.
