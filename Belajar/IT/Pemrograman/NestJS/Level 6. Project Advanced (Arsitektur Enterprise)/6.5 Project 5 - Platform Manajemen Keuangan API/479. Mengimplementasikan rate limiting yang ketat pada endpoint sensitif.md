# 479. Mengimplementasikan rate limiting ketat pada endpoint sensitif

## Definisi & Target
Endpoint sensitif (login, transfer, register) perlu rate limiting lebih ketat untuk mencegah brute force dan abuse. Targetnya adalah menerapkan multiple rate limit tiers per endpoint.

## Komponen & Nest CLI Command
```
Rate limit tiers:
  Global: 60 req/min
  Login: 5 req/min per IP
  Register: 2 req/min per IP
  Transfer: 10 req/min per user
  Password reset: 3 req/15min
```

```typescript
// src/auth/auth.controller.ts (ketat)
import { Controller, Post, Body, UseGuards } from '@nestjs/common';
import { Throttle, ThrottlerGuard } from '@nestjs/throttler';
import { AuthService } from './auth.service';

@Controller('auth')
export class AuthController {
  constructor(private readonly authService: AuthService) {}

  @Post('login')
  @Throttle({ login: { limit: 5, ttl: 60000 } })
  async login(@Body() credentials: any) {
    return this.authService.login(credentials);
  }

  @Post('register')
  @Throttle({ register: { limit: 2, ttl: 60000 } })
  async register(@Body() data: any) {
    return this.authService.register(data);
  }

  @Post('forgot-password')
  @Throttle({ 'password-reset': { limit: 3, ttl: 900000 } })
  async forgotPassword(@Body('email') email: string) {
    return this.authService.sendPasswordReset(email);
  }

  @Post('verify-2fa')
  @Throttle({ login: { limit: 5, ttl: 60000 } })
  async verify2fa(@Body() data: { userId: string; token: string }) {
    return this.authService.verify2fa(data);
  }
}
```

```typescript
// src/transaction/transaction.controller.ts
import { Controller, Post, Body, UseGuards } from '@nestjs/common';
import { Throttle } from '@nestjs/throttler';
import { JwtAuthGuard } from '../auth/guards/jwt-auth.guard';
import { TransactionService } from './transaction.service';

@Controller('transactions')
@UseGuards(JwtAuthGuard)
export class TransactionController {
  constructor(private readonly transactionService: TransactionService) {}

  @Post('transfer')
  @Throttle({ transfer: { limit: 10, ttl: 60000 } })
  async transfer(@Body() data: any) {
    return this.transactionService.createTransfer(data);
  }

  @Post('bulk')
  @Throttle({ transfer: { limit: 3, ttl: 60000 } })
  async bulkTransfer(@Body() data: any) {
    return this.transactionService.bulkTransfer(data.transfers);
  }
}
```

## Cara Integrasi & Pengujian
Gunakan script untuk mengirim request cepat ke endpoint login. Setelah 5 request, akan return 429. Rate limit di-reset setelah 1 menit.
