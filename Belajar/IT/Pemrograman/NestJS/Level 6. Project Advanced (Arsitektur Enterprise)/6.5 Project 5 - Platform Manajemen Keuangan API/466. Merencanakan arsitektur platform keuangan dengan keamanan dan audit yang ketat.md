# 466. Merencanakan arsitektur platform keuangan dengan keamanan dan audit yang ketat

## Definisi & Target
Platform keuangan membutuhkan arsitektur yang mengutamakan keamanan, audit trail, dan data consistency. Targetnya adalah merancang struktur modular yang mendukung double-entry bookkeeping, enkripsi, dan logging otomatis.

## Komponen & Nest CLI Command
```
Struktur modul:
  AuthModule           -> 2FA, JWT, session management
  AccountModule       -> Rekening pengguna
  TransactionModule   -> Double-entry bookkeeping
  CategoryModule      -> Kategori transaksi
  BudgetModule        -> Budget & alert
  ReportModule        -> Aggregasi & export
  AuditLogModule      -> Semua perubahan tercatat
  WebhookModule       -> Notifikasi eksternal
```

## Kode Implementasi (Per File)
```typescript
// src/app.module.ts
import { Module } from '@nestjs/common';
import { ConfigModule } from '@nestjs/config';
import { ThrottlerModule, ThrottlerGuard } from '@nestjs/throttler';
import { APP_GUARD } from '@nestjs/core';
import { AuthModule } from './auth/auth.module';
import { AccountModule } from './account/account.module';
import { TransactionModule } from './transaction/transaction.module';
import { BudgetModule } from './budget/budget.module';
import { ReportModule } from './report/report.module';
import { AuditLogModule } from './audit-log/audit-log.module';
import { WebhookModule } from './webhook/webhook.module';

@Module({
  imports: [
    ConfigModule.forRoot({ isGlobal: true, validationSchema: Joi.object({ ... }) }),
    ThrottlerModule.forRoot([{ ttl: 60000, limit: 60 }]),
    AuthModule, AccountModule, TransactionModule,
    BudgetModule, ReportModule, AuditLogModule, WebhookModule,
  ],
  providers: [{ provide: APP_GUARD, useClass: ThrottlerGuard }],
})
export class AppModule {}
```

## Cara Integrasi & Pengujian
Setiap modul independen dengan database-nya sendiri atau tabel terpisah. AuditLogModule mencatat semua perubahan via event system. Enkripsi AES untuk data sensitif.
