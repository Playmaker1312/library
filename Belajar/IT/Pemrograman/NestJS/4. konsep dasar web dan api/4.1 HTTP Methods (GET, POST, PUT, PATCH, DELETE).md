## 4.1 HTTP Methods (GET, POST, PUT, PATCH, DELETE)

### Definisi Singkat

**HTTP Methods** (atau sering disebut HTTP Verbs) adalah kumpulan instruksi standar yang digunakan untuk memberi tahu server tentang tindakan apa yang ingin dilakukan terhadap suatu data (resource).

### Analogi

Bayangkan sebuah **Perpustakaan**:

- **GET**: Kamu datang untuk **Membaca** buku. Kamu tidak mengubah apa pun, hanya mengambil informasi.
    
- **POST**: Kamu datang untuk **Menyumbangkan** buku baru ke perpustakaan.
    
- **PUT**: Kamu ingin **Mengganti** buku lama yang rusak dengan buku baru yang identik di rak yang sama (mengganti seluruh isi).
    
- **PATCH**: Kamu hanya ingin **Memperbaiki** halaman yang robek pada sebuah buku (hanya mengubah sebagian).
    
- **DELETE**: Kamu meminta pustakawan untuk **Membuang** buku yang sudah tidak layak pakai dari rak.
    

### Poin-Poin Penting

- **GET**: Mengambil data. Tidak boleh mengirim data sensitif melalui _body_, data dikirim melalui URL (Query/Param). Bersifat _Safe_ (tidak mengubah state di server).
    
- **POST**: Membuat data baru. Data dikirim melalui _Request Body_. Biasanya menghasilkan ID baru di database.
    
- **PUT**: Memperbarui data secara keseluruhan. Jika ada field yang tidak dikirim, biasanya field tersebut akan dihapus atau di-reset.
    
- **PATCH**: Memperbarui data secara parsial (sebagian). Hanya field yang dikirim saja yang akan diubah di database.
    
- **DELETE**: Menghapus data berdasarkan pengidentifikasi unik (ID).
    

### Contoh Implementasi

Dalam NestJS, kita menggunakan dekorator untuk setiap metode ini:

TypeScript

```
@Controller('produk')
export class ProdukController {

  @Get() // Mengambil semua produk
  findAll() {
    return 'Daftar semua produk';
  }

  @Post() // Menambah produk baru
  create(@Body() data: any) {
    return 'Produk berhasil ditambahkan';
  }

  @Put(':id') // Mengupdate seluruh data produk ID tertentu
  updateAll(@Param('id') id: string, @Body() data: any) {
    return `Produk ${id} telah diganti sepenuhnya`;
  }

  @Patch(':id') // Hanya mengupdate harga produk ID tertentu
  updatePartial(@Param('id') id: string, @Body() data: any) {
    return `Harga produk ${id} telah diperbarui`;
  }

  @Delete(':id') // Menghapus produk
  remove(@Param('id') id: string) {
    return `Produk ${id} telah dihapus`;
  }
}
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, penggunaan HTTP Methods yang tepat sangat penting karena:

1. **Standardisasi API**: Memudahkan developer frontend memahami kegunaan setiap endpoint tanpa harus membaca dokumentasi yang sangat panjang.
    
2. **Idempotency**: Memahami bahwa `GET`, `PUT`, dan `DELETE` harus memberikan hasil yang konsisten jika dipanggil berkali-kali, sedangkan `POST` akan terus menambah data baru.
    
3. **Security**: Kita bisa membatasi akses, misalnya method `GET` boleh untuk semua orang, tapi `DELETE` hanya boleh untuk Admin.
    
4. **Swagger Integration**: NestJS secara otomatis akan mengelompokkan API berdasarkan warnanya (Biru untuk GET, Hijau untuk POST, dll) di dokumentasi Swagger.
