## 4.5 Headers, Body, Query, & Route Params

### Definisi Singkat

Ini adalah empat tempat utama di mana data dapat disisipkan dalam sebuah permintaan HTTP. **Headers** untuk informasi meta, **Body** untuk data besar/kompleks, **Query Params** untuk filter/pencarian, dan **Route Params** untuk identitas spesifik.

### Analogi

Bayangkan kamu mengirim **Paket Lewat Ekspedisi**:

- **Headers**: Adalah **Label Pengiriman** di luar kardus. Isinya informasi penting seperti "Jangan Dibanting" (Content-Type) atau "ID Pengirim" (Authorization).
    
- **Body**: Adalah **Isi di Dalam Kardus**. Ini adalah barang utama yang ingin kamu kirim (data user, detail produk, dll).
    
- **Route Params**: Adalah **Nomor Rumah Spesifik** tujuan. Kamu tidak bisa mengirim paket tanpa alamat yang jelas: `/jalan-mawar/nomor/101`.
    
- **Query Params**: Adalah **Catatan Tambahan** untuk kurir. "Tolong kirim yang warna merah ya" atau "Cari paket yang beratnya di bawah 1kg".
    

### Poin-Poin Penting & Implementasi NestJS

|**Jenis**|**Lokasi**|**Kegunaan Utama**|**Dekorator NestJS**|
|---|---|---|---|
|**Route Params**|Bagian dari URL path (`/users/:id`)|Menunjuk satu data spesifik secara unik.|`@Param('id')`|
|**Query Params**|Setelah tanda tanya (`?sort=asc`)|Menyaring (_filtering_), mengurutkan, atau _pagination_.|`@Query('sort')`|
|**Body**|Tersembunyi di dalam _request payload_|Mengirim data kompleks atau rahasia (JSON/Form).|`@Body()`|
|**Headers**|Bagian _header_ permintaan HTTP|Autentikasi, metadata, atau tipe konten.|`@Headers('key')`|

### Contoh Kode dalam NestJS

TypeScript

```
@Controller('products')
export class ProductsController {

  // URL: GET /products/101
  @Get(':id')
  getDetail(@Param('id') id: string) {
    return `Mencari produk dengan ID: ${id}`;
  }

  // URL: GET /products?category=elektronik&limit=10
  @Get()
  search(@Query('category') cat: string, @Query('limit') lim: number) {
    return `Cari produk ${cat} maksimal ${lim} item`;
  }

  // URL: POST /products (Data dikirim di Body)
  @Post()
  create(@Body() data: any, @Headers('authorization') token: string) {
    return {
      message: 'Produk dibuat',
      payload: data,
      tokenUsed: token // Mengambil data dari Header
    };
  }
}
```

### Koneksi dengan Web Development (NestJS)

Mengapa pemisahan ini sangat penting?

1. **Security**: Jangan pernah menaruh password atau token di **Query Params** karena URL akan tercatat di log server dan histori browser. Gunakan **Body** atau **Headers**.
    
2. **SEO & Readability**: Menggunakan **Route Params** membuat URL lebih cantik dan mudah dibaca (misal: `/blog/belajar-nestjs` lebih baik daripada `/blog?id=123`).
    
3. **Standardisasi**: NestJS memudahkan pengambilan data ini melalui dekorator sehingga kamu tidak perlu melakukan _parsing_ manual dari objek `req` Node.js yang rumit.
    
4. **Validation**: Dengan bantuan `class-validator` di NestJS, kamu bisa memvalidasi **Body** dan **Query Params** secara otomatis untuk memastikan data yang masuk tidak rusak.
