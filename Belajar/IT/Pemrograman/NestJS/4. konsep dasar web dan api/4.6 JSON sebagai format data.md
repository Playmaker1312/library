## 4.6 JSON sebagai Format Data

### Definisi Singkat

**JSON** adalah format pertukaran data berbasis teks yang ringan, mudah dibaca oleh manusia, dan mudah diuraikan (_parsed_) oleh komputer. JSON digunakan untuk mengirimkan data antara server dan klien dalam bentuk pasangan **Key** (kunci) dan **Value** (nilai).

### Analogi

Bayangkan JSON sebagai **Formulir Pendaftaran Standar Internasional**:

- Tidak peduli apakah kamu orang Indonesia, Amerika, atau Jepang, formulir ini memiliki format yang sama:
    
    - `Nama: [Isi di sini]`
        
    - `Umur: [Angka di sini]`
        
- Karena formatnya seragam dan kaku (harus ada tanda kutip, kurung kurawal, dll.), mesin fotokopi otomatis di seluruh dunia (server-server di internet) bisa membaca isinya tanpa salah paham.
    

### Poin-Poin Penting Aturan JSON

JSON memiliki aturan penulisan yang lebih ketat daripada objek JavaScript biasa:

- **Key harus menggunakan tanda kutip ganda (`" "`)**: Di JS objek, `"nama"` bisa ditulis `nama`, tapi di JSON wajib `"nama"`.
    
- **Value yang diizinkan**: Hanya boleh berupa `string`, `number`, `object`, `array`, `boolean`, atau `null`.
    
- **Tidak boleh ada fungsi**: Kamu tidak bisa mengirim fungsi/metode di dalam JSON.
    
- **Tanda koma**: Jangan ada koma di item terakhir dalam sebuah list (koma gantung/trailing comma dilarang).
    

### Contoh Perbandingan

**Objek JavaScript (di dalam kode .ts):**

TypeScript

```
const user = {
  id: 1,
  username: 'gemini_dev',
  isAdmin: true, // Boleh tanpa kutip di key
};
```

**Format JSON (saat dikirim lewat jaringan):**

JSON

```
{
  "id": 1,
  "username": "gemini_dev",
  "isAdmin": true
}
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, JSON adalah "jantung" dari komunikasi data:

1. **Otomatisasi**: Secara default, jika kamu me-return sebuah objek atau array dari Controller, NestJS akan otomatis mengubahnya (_stringify_) menjadi format JSON sebelum dikirim ke client.
    
2. **Request Parsing**: Saat client mengirim data ke endpoint `@Post()`, NestJS secara otomatis mengubah teks JSON tersebut kembali menjadi objek JavaScript agar bisa kamu olah di dalam kode.
    
3. **Content-Type**: NestJS secara otomatis mengatur Header `Content-Type: application/json` pada setiap respon agar browser tahu bahwa data yang datang adalah JSON, bukan teks biasa.
    
4. **DTO Validation**: Kita menggabungkan JSON dengan DTO (Data Transfer Object) untuk memastikan bahwa "Key" dan "Value" yang dikirim oleh client sudah sesuai dengan aturan yang kita buat.
