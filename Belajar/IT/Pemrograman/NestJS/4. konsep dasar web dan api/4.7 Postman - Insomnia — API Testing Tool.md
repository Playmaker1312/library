## 4.7 Postman & Insomnia — API Testing Tool

### Definisi Singkat

**API Testing Tools** adalah aplikasi perangkat lunak yang berfungsi sebagai "Client" (seperti browser, tapi lebih canggih) untuk mengirim berbagai jenis permintaan HTTP ke server dan melihat hasilnya secara detail.

### Analogi

Bayangkan kamu sedang membangun sebuah **Remote Control Universal**:

- **Browser (Chrome/Edge)**: Seperti remote yang hanya punya satu tombol: "Nyalakan TV". Kamu tidak bisa mengatur frekuensi, tidak bisa melihat sinyal di dalamnya, kamu hanya bisa melihat hasil akhirnya di layar.
    
- **Postman/Insomnia**: Seperti **Alat Teknisi Elektronik**. Kamu bisa mengatur frekuensi secara manual, mengubah tegangan (Headers/Body), mencoba mengirim sinyal berkali-kali, dan melihat log teknis yang terjadi di balik layar. Alat ini membantu teknisi memastikan remote-nya bekerja sebelum diberikan ke pengguna.
    

### Poin-Poin Penting

Alat-alat ini memungkinkan kamu untuk melakukan hal-hal yang **tidak bisa dilakukan oleh browser biasa**:

- **Mengirim POST, PUT, DELETE**: Browser biasa secara default hanya bisa melakukan `GET` (saat kamu mengetik URL).
    
- **Mengatur Headers**: Kamu bisa menyisipkan token autentikasi atau mengubah `Content-Type` secara manual.
    
- **Mengirim Body JSON**: Kamu bisa mengetik data JSON yang kompleks untuk dikirim ke server NestJS.
    
- **Melihat Response Detail**: Kamu bisa melihat _Status Code_ (201, 404, dll), waktu respon (milidetik), dan ukuran data yang diterima.
    
- **Environment Variables**: Kamu bisa menyimpan alamat server (lokal vs produksi) dan menggantinya dengan satu klik.
    

### Mengapa Ada Dua Pilihan?

1. **Postman**: Yang paling populer dan fiturnya sangat lengkap (termasuk testing otomatis, dokumentasi, dan kolaborasi tim). Namun, terkadang terasa agak "berat" bagi sebagian komputer.
    
2. **Insomnia**: Lebih ringan, tampilannya lebih bersih (_clean_), dan sangat fokus pada kecepatan desain API. Sangat cocok bagi kamu yang menyukai kesederhanaan.
    

### Contoh Alur Kerja (Workflow)

1. Kamu menulis kode `@Post('/users')` di NestJS.
    
2. Kamu membuka **Postman**.
    
3. Kamu memilih metode **POST**, memasukkan URL `http://localhost:3000/users`.
    
4. Kamu mengisi bagian **Body** dengan JSON: `{"name": "Budi"}`.
    
5. Klik **Send**.
    
6. Postman akan menampilkan apakah servermu menjawab dengan `201 Created` atau malah `500 Error`.
    

### Koneksi dengan Web Development (NestJS)

Di NestJS, kita sangat bergantung pada alat ini karena:

1. **Development Tanpa Frontend**: Kamu bisa menyelesaikan seluruh logika backend (login, database, dll) tanpa perlu menunggu tim Frontend membuat tampilannya.
    
2. **Debugging**: Jika ada error, Postman akan menampilkan pesan error JSON yang dikirim oleh NestJS, sehingga kamu tahu persis di mana letak kesalahannya.
    
3. **API Documentation**: Koleksi request yang kamu buat di Postman bisa diekspor dan diberikan ke orang lain agar mereka tahu cara menggunakan API buatanmu.
