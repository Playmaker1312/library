## 4.2 HTTP Status Codes (2xx, 3xx, 4xx, 5xx)

### Definisi Singkat

**HTTP Status Codes** adalah kode angka 3 digit yang dikirimkan oleh server sebagai bagian dari respon HTTP untuk memberitahu klien apakah permintaan mereka berhasil, dialihkan, atau mengalami kesalahan.

### Analogi

Bayangkan kamu sedang memesan makanan di **Restoran**:

- **2xx (Success)**: Pelayan datang membawa makananmu sambil tersenyum. Pesanan berhasil!
    
- **3xx (Redirection)**: Pelayan bilang, "Maaf, meja kamu dipindah ke lantai 2, silakan ke sana."
    
- **4xx (Client Error)**: Kamu memesan menu yang tidak ada di buku menu, atau kamu mencoba memesan tanpa membawa uang. Ini kesalahanmu.
    
- **5xx (Server Error)**: Pelayan panik dan bilang, "Maaf, dapur kami sedang kebakaran/kebanjiran." Ini kesalahan restoran.
    

### Poin-Poin Penting

Berikut adalah pembagian kategori yang wajib kamu hafal:

- **2xx (Success)**: Permintaan diterima dengan baik.
    
    - `200 OK`: Sukses umum (GET/PUT/PATCH).
        
    - `201 Created`: Berhasil membuat data baru (POST).
        
- **3xx (Redirection)**: Butuh tindakan tambahan untuk menyelesaikan permintaan.
    
    - `301 Moved Permanently`: URL sudah pindah selamanya.
        
    - `304 Not Modified`: Data belum berubah (hemat kuota).
        
- **4xx (Client Error)**: Ada yang salah dengan permintaan klien.
    
    - `400 Bad Request`: Data yang dikirim salah/tidak lengkap.
        
    - `401 Unauthorized`: Belum login.
        
    - `403 Forbidden`: Sudah login, tapi tidak punya akses (misal: user biasa mau akses admin).
        
    - `404 Not Found`: Data/URL tidak ditemukan.
        
- **5xx (Server Error)**: Server gagal memproses permintaan yang sebenarnya benar.
    
    - `500 Internal Server Error`: Ada bug/error di kode server.
        
    - `503 Service Unavailable`: Server sedang mati/kelebihan beban.
        

### Contoh Implementasi

Dalam **NestJS**, kamu bisa mengatur status code menggunakan dekorator `@HttpCode()` atau melempar _exception_ bawaan:

TypeScript

```
import { Controller, Get, Post, HttpCode, HttpStatus, HttpException, BadRequestException } from '@nestjs/common';

@Controller('orders')
export class OrderController {
  
  @Post()
  @HttpCode(201) // Mengatur secara manual ke 201 Created
  create() {
    return { message: 'Order berhasil dibuat' };
  }

  @Get(':id')
  findOne(id: string) {
    if (id === '0') {
      // Melempar error 400 otomatis
      throw new BadRequestException('ID tidak valid'); 
    }
    // Jika data tidak ada, lempar 404
    throw new HttpException('Order tidak ada', HttpStatus.NOT_FOUND);
  }
}
```

### Koneksi dengan Web Development (NestJS)

Mengapa status code ini sangat krusial di NestJS?

1. **Frontend Logic**: Developer Frontend menggunakan kode ini untuk menentukan UI. Jika `401`, arahkan ke halaman login. Jika `201`, tampilkan notifikasi "Berhasil".
    
2. **Standardized Error Handling**: NestJS memiliki `Global Exception Filter` yang menangkap error dan otomatis mengubahnya menjadi format JSON dengan status code yang tepat.
    
3. **SEO**: Mesin pencari seperti Google menggunakan status code (seperti `301` atau `404`) untuk memetakan website kamu dengan benar.
    
4. **Monitoring**: Sistem pemantau server (seperti Sentry atau Datadog) akan memberikan peringatan jika jumlah status `5xx` meningkat, menandakan aplikasi kamu sedang bermasalah.
