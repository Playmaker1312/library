# 14. Interceptors

## 14.4. Response Mapping atau Transformation

**Definisi Singkat:** Interceptor mengubah response handler menjadi format standar (misal: membungkus dengan properti `data`, `success`, dll).

**Analogi:** Seperti jasa bungkus kado — kamu beli boneka, dikasih kotak + pita + kartu ucapan, tanpa mengubah bonekanya.

**Poin-Poin Penting:**
- Gunakan operator `map()` dari RxJS
- Transformasi response tanpa mengubah handler
- Bisa untuk format standar response API
- Bisa juga untuk serialize/exclude field sensitif
- Konsisten di semua endpoint

**Contoh Kode:**
```typescript
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable } from 'rxjs';
import { map } from 'rxjs/operators';

export interface StandardResponse<T> {
  success: boolean;
  data: T;
  timestamp: string;
}

@Injectable()
export class TransformInterceptor<T> implements NestInterceptor<T, StandardResponse<T>> {
  intercept(context: ExecutionContext, next: CallHandler): Observable<StandardResponse<T>> {
    return next.handle().pipe(
      map(data => ({
        success: true,
        data,
        timestamp: new Date().toISOString(),
      })),
    );
  }
}

// Penggunaan — response asli { id: 1, name: "John" }
// menjadi { success: true, data: { id: 1, name: "John" }, timestamp: "2025-01-01T00:00:00Z" }
```

**Kasus Penggunaan Nyata:** Frontend selalu menerima format `{ success: true, data: ... }` dari semua endpoint API — memudahkan error handling seragam di sisi client tanpa adaptasi tiap endpoint.
