# 14. Interceptors

## 14.2. Membuat Interceptor NestInterceptor intercept

**Definisi Singkat:** Interceptor dibuat dengan class `@Injectable()` yang implement `NestInterceptor` dengan method `intercept()`.

**Analogi:** Seperti membuat plugin — colokkan ke sistem, otomatis jalan di setiap request tanpa ubah kode handler.

**Poin-Poin Penting:**
- Decorator `@Injectable()`
- Implement `NestInterceptor<T, R>`
- Method `intercept(context: ExecutionContext, next: CallHandler): Observable<R>`
- `context` — akses request/response dan metadata
- `next.handle()` — memanggil handler berikutnya
- Return Observable untuk memproses response

**Contoh Kode:**
```typescript
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable } from 'rxjs';

@Injectable()
export class TimingInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const start = Date.now();
    const method = context.getHandler().name;

    return next.handle().pipe(
      tap(() => {
        const duration = Date.now() - start;
        console.log(`${method} selesai dalam ${duration}ms`);
      }),
    );
  }
}

// Penggunaan
@UseInterceptors(TimingInterceptor)
@Get()
findAll() { }
```

**Kasus Penggunaan Nyata:** `TimingInterceptor` mencatat durasi setiap request — membantu developer menemukan endpoint yang lambat dengan melihat log "findAll selesai dalam 2500ms".
