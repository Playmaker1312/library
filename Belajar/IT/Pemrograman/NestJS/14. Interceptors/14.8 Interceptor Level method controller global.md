# 14. Interceptors

## 14.8. Interceptor Level method controller global

**Definisi Singkat:** Interceptor bisa dipasang di berbagai level: method, controller, atau global menggunakan `@UseInterceptors()` atau `app.useGlobalInterceptors()`.

**Analogi:** Seperti aturan di kantor: aturan global (semua karyawan), aturan divisi (controller), aturan individu (method).

**Poin-Poin Penting:**
- **Method level:** `@UseInterceptors(Interceptor)` untuk satu handler
- **Controller level:** `@UseInterceptors(Interceptor)` untuk semua handler
- **Global level:** `app.useGlobalInterceptors(Interceptor)` di main.ts
- Urutan eksekusi: global > controller > method
- Bisa multiple interceptor dalam satu level

**Contoh Kode:**
```typescript
import { Controller, UseInterceptors, Get } from '@nestjs/common';
import { LoggingInterceptor } from './logging.interceptor';
import { TransformInterceptor } from './transform.interceptor';
import { TimeoutInterceptor } from './timeout.interceptor';

// Global — di main.ts
app.useGlobalInterceptors(new LoggingInterceptor());

@Controller('users')
@UseInterceptors(TransformInterceptor) // Controller level
export class UserController {

  @Get()
  findAll() { } // Aplikasi: Logging > Transform

  @Get('slow')
  @UseInterceptors(new TimeoutInterceptor(3000)) // Method level
  findSlow() { } // Aplikasi: Logging > Transform > Timeout
}

// Multiple interceptor
@UseInterceptors(Interceptor1, Interceptor2)
@Get()
findAll() { }
```

**Kasus Penggunaan Nyata:** `LoggingInterceptor` global mencatat semua request, `TransformInterceptor` di controller level membungkus response dengan format standar, dan `TimeoutInterceptor` khusus untuk endpoint lambat.
