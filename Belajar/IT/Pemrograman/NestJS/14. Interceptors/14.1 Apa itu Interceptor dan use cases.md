# 14. Interceptors

## 14.1. Apa itu Interceptor dan use cases

**Definisi Singkat:** Interceptor adalah class yang membungkus method handler untuk menambahkan logika sebelum/sesudah eksekusi, memanfaatkan RxJS Observable.

**Analogi:** Seperti asisten pribadi — menyiapkan sebelum meeting (before), mencatat hasil meeting (after), dan mengemas ulang laporannya (transform).

**Poin-Poin Penting:**
- Berdasarkan AOP (Aspect Oriented Programming)
- Berjalan sebelum handler dipanggil
- Berjalan setelah handler selesai (akses response)
- Menggunakan RxJS Observable untuk stream
- Use cases: logging, transform response, cache, timeout, error handling
- Bisa mengubah atau mengganti response entirely

**Contoh Kode:**
```typescript
import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common';
import { Observable } from 'rxjs';
import { map, tap } from 'rxjs/operators';

@Injectable()
export class ExampleInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    console.log('Before handler...');

    return next.handle().pipe(
      tap(() => console.log('After handler...')),
    );
  }
}
```

**Kasus Penggunaan Nyata:** `LoggingInterceptor` mencatat waktu mulai sebelum handler, lalu mencatat durasi eksekusi setelah handler selesai — membantu monitoring performa endpoint.
