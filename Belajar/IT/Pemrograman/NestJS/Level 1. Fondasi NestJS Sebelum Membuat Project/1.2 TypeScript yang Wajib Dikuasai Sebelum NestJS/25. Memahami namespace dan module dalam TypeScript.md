# 25. Memahami namespace dan module dalam TypeScript

## Definisi & Target
Module (ES Modules) adalah cara standar mengorganisir kode dengan `import`/`export`. Namespace adalah fitur lama TypeScript untuk mengelompokkan kode. NestJS menggunakan ES Modules (dengan `import`/`export`) dan menambahkan layer modularitas sendiri melalui `@Module()`.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Contoh module dan namespace.

## Kode Implementasi (Per File)

```typescript
// types/product.types.ts
export interface IProduct {
  id: number;
  name: string;
  price: number;
}

export type ProductStatus = 'active' | 'inactive';

export const PRODUCT_CATEGORIES = ['Electronics', 'Books', 'Clothing'] as const;

// services/product.service.ts
import { IProduct } from '../types/product.types';

class ProductService {
  private products: IProduct[] = [];

  addProduct(product: IProduct): void {
    this.products.push(product);
  }
}

// Namespace (jarang dipakai, lebih ke legacy)
namespace ProductUtils {
  export function formatPrice(price: number): string {
    return `Rp${price.toLocaleString()}`;
  }

  export function isExpensive(price: number): boolean {
    return price > 1000000;
  }
}
```

## Cara Integrasi & Pengujian
Di project NestJS, gunakan `import`/`export` (ES Modules) — bukan namespaces. Setiap file adalah module. Organisasi kode diatur oleh `@Module()` NestJS yang mengelompokkan controller, service, dan provider terkait. Namespace jarang diperlukan di proyek modern.
