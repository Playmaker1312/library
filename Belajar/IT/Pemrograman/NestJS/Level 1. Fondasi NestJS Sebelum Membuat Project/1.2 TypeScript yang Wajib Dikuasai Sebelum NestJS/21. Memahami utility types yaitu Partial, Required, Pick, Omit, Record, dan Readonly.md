# 21. Memahami utility types yaitu Partial, Required, Pick, Omit, Record, dan Readonly

## Definisi & Target
Utility types adalah generic bawaan TypeScript untuk memanipulasi tipe. Di NestJS, utility types sangat berguna untuk DTO update (Partial), response tanpa field sensitif (Omit), dan mapping (Record).

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Contoh langsung di file TypeScript.

## Kode Implementasi (Per File)

```typescript
interface IUser {
  id: number;
  name: string;
  email: string;
  password: string;
  createdAt: Date;
}

// Partial: semua properti jadi opsional — berguna untuk update DTO
type UpdateUserDTO = Partial<IUser>;

// Required: semua properti jadi wajib
type FullUser = Required<Partial<IUser>>;

// Pick: ambil properti tertentu — untuk response ringkas
type UserProfile = Pick<IUser, 'id' | 'name' | 'email'>;

// Omit: hapus properti tertentu — untuk hide sensitive field
type PublicUser = Omit<IUser, 'password'>;

// Record: tipe object dengan key-value pattern
type UserMap = Record<number, PublicUser>;

// Readonly: semua properti jadi immutable
type FrozenUser = Readonly<IUser>;
```

## Cara Integrasi & Pengujian
Gunakan `Partial<T>` untuk `UpdateDto` agar field tidak wajib diisi semua. Gunakan `Omit<T, 'password'>` untuk response user tanpa password. `Pick<T, K>` untuk memilih field tertentu. Utility types ini mengurangi boilerplate kode secara signifikan.
