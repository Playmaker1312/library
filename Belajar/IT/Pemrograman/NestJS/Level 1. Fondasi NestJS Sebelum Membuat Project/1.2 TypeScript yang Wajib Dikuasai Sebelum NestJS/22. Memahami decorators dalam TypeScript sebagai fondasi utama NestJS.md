# 22. Memahami decorators dalam TypeScript sebagai fondasi utama NestJS

## Definisi & Target
Decorators adalah fungsi khusus yang memodifikasi class, method, properti, atau parameter. NestJS sangat bergantung pada decorators — `@Module()`, `@Controller()`, `@Injectable()`, `@Get()` — untuk mendefinisikan struktur aplikasi.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Contoh decorator langsung di file TypeScript.

## Kode Implementasi (Per File)

```typescript
// Class decorator
function LogClass(target: Function) {
  console.log(`Class ${target.name} initialized`);
}

@LogClass
class ProductsController {}

// Method decorator
function LogMethod(target: any, key: string, descriptor: PropertyDescriptor) {
  const original = descriptor.value;
  descriptor.value = function (...args: any[]) {
    console.log(`Calling ${key} with args:`, args);
    return original.apply(this, args);
  };
}

class ProductsService {
  @LogMethod
  findAll() {
    return ['Product 1', 'Product 2'];
  }
}

// Parameter decorator
function LogParam(target: any, key: string, index: number) {
  console.log(`Parameter at index ${index} in ${key}`);
}
```

## Cara Integrasi & Pengujian
Aktifkan `"experimentalDecorators": true` di `tsconfig.json` (sudah default di NestJS). Decorators adalah fondasi NestJS — setiap `@Controller()`, `@Get()`, `@Injectable()` adalah decorators yang mendefinisikan bagaimana aplikasi berperilaku.
