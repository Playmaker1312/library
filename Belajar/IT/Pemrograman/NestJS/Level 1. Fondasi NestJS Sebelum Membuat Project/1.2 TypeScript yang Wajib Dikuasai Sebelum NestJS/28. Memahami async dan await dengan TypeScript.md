# 28. Memahami async dan await dengan TypeScript

## Definisi & Target
Async/await adalah cara modern menangani operasi asynchronous di TypeScript. NestJS menggunakan async/await di semua operasi database, HTTP request eksternal, dan queue processing. Targetnya adalah menulis kode asynchronous yang bersih dan terstruktur.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Contoh async/await di file TypeScript.

## Kode Implementasi (Per File)

```typescript
// Service dengan async/await — pattern standar NestJS
// src/products/products.service.ts

import { Injectable } from '@nestjs/common';

interface IProduct {
  id: number;
  name: string;
  price: number;
}

@Injectable()
export class ProductsService {
  private products: IProduct[] = [];

  async findAll(): Promise<IProduct[]> {
    return this.products;
  }

  async findById(id: number): Promise<IProduct | null> {
    const product = this.products.find(p => p.id === id);
    return product ?? null;
  }

  async create(data: Omit<IProduct, 'id'>): Promise<IProduct> {
    const newProduct: IProduct = {
      id: this.products.length + 1,
      ...data,
    };
    this.products.push(newProduct);
    return newProduct;
  }
}
```

## Cara Integrasi & Pengujian
Semua method service di NestJS harus mengembalikan `Promise<T>` atau `Observable<T>`. Gunakan `async/await` di controller untuk menunggu hasil service. NestJS secara otomatis menangani error — jika Promise reject, NestJS akan melemparkan `HttpException` yang sesuai.
