# 19. Memahami generic types dan cara menggunakannya

## Definisi & Target
Generic types memungkinkan pembuatan komponen yang bekerja dengan berbagai tipe. NestJS menggunakan generic di banyak tempat — misal `Promise<T>`, `Observable<T>`, `InjectRepository<T>`, dan `ApiResponse<T>`.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Contoh generic di file TypeScript.

## Kode Implementasi (Per File)

```typescript
// Generic function
function firstElement<T>(arr: T[]): T {
  return arr[0];
}

const num = firstElement<number>([1, 2, 3]);
const str = firstElement<string>(['a', 'b']);

// Generic interface (sering dipakai untuk API response di NestJS)
interface ApiResponse<T> {
  statusCode: number;
  message: string;
  data: T;
}

type UserResponse = ApiResponse<{ id: number; name: string }>;
type ProductResponse = ApiResponse<{ id: number; title: string; price: number }>;

// Generic class dengan constraint
class Repository<T extends { id: number }> {
  private items: T[] = [];

  findById(id: number): T | undefined {
    return this.items.find(item => item.id === id);
  }

  save(item: T): void {
    this.items.push(item);
  }
}
```

## Cara Integrasi & Pengujian
Generic akan sering muncul saat menggunakan TypeORM (`Repository<Product>`), Mongoose (`Model<ProductDocument>`), atau membuat custom pipes/guards. Latihan: buat fungsi `wrapResponse<T>(data: T): ApiResponse<T>` untuk standarisasi response API.
