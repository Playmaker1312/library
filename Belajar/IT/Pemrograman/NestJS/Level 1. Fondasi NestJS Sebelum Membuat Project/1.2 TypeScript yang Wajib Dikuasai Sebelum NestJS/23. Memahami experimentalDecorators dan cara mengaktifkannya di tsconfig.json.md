# 23. Memahami experimentalDecorators dan cara mengaktifkannya di tsconfig.json

## Definisi & Target
Decorators adalah fitur eksperimental di TypeScript yang harus diaktifkan secara eksplisit. NestJS bergantung penuh pada fitur ini. Targetnya adalah memastikan konfigurasi `tsconfig.json` mendukung decorators.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Modifikasi `tsconfig.json` di project NestJS.

## Kode Implementasi (Per File)

```json
// tsconfig.json — NestJS sudah mengatur ini secara default
{
  "compilerOptions": {
    "experimentalDecorators": true,
    "emitDecoratorMetadata": true,
    "target": "ES2021",
    "module": "commonjs",
    "strict": true,
    "outDir": "./dist",
    "rootDir": "./src",
    "baseUrl": "./",
    "paths": {
      "@/*": ["src/*"]
    }
  }
}
```

Penjelasan:
| Opsi | Fungsi |
|------|--------|
| `experimentalDecorators: true` | Mengaktifkan decorators |
| `emitDecoratorMetadata: true` | Menyediakan metadata tipe ke decorators — dibutuhkan NestJS untuk Dependency Injection |

## Cara Integrasi & Pengujian
Kedua opsi ini sudah aktif otomatis saat membuat project dengan `nest new`. Jika membuat project manual, pastikan keduanya ada di `tsconfig.json`. Tanpa `emitDecoratorMetadata`, Dependency Injection NestJS tidak akan berfungsi dengan benar.
