# 24. Memahami abstract class dan abstract method dalam TypeScript

## Definisi & Target
Abstract class adalah class yang tidak bisa diinstansiasi langsung, hanya bisa dijadikan basis untuk subclass. NestJS menggunakannya untuk pattern seperti BaseService, BaseRepository, atau custom guard yang membutuhkan implementasi spesifik.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Contoh abstract class di file TypeScript.

## Kode Implementasi (Per File)

```typescript
// Abstract class sebagai base service
abstract class BaseService<T> {
  abstract findAll(): Promise<T[]>;
  abstract findById(id: number): Promise<T | null>;

  protected logError(error: Error): void {
    console.error(`[${this.constructor.name}]`, error.message);
  }
}

// Implementasi konkret
interface IProduct {
  id: number;
  name: string;
}

class ProductService extends BaseService<IProduct> {
  async findAll(): Promise<IProduct[]> {
    return [{ id: 1, name: 'Laptop' }];
  }

  async findById(id: number): Promise<IProduct | null> {
    return { id, name: 'Laptop' };
  }
}

// Abstract method di custom Guard (pattern NestJS)
abstract class AuthGuard {
  abstract canActivate(context: any): boolean | Promise<boolean>;

  protected getUserFromRequest(context: any): any {
    return context.switchToHttp().getRequest().user;
  }
}
```

## Cara Integrasi & Pengujian
Gunakan abstract class ketika ada sekelompok class yang berbagi logic umum tapi memiliki beberapa method yang harus diimplementasi berbeda. NestJS sendiri menggunakan abstract class pada `ValidationPipe`, `AuthGuard`, dan `BaseRepository` TypeORM.
