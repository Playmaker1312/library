# 16. Memahami tipe dasar TypeScript yaitu string, number, boolean, array, tuple, dan enum

## Definisi & Target
Tipe dasar TypeScript digunakan di seluruh NestJS — dari deklarasi DTO, parameter controller, hingga return type service. Targetnya adalah menguasai deklarasi tipe dasar.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Cukup buat file `.ts` untuk latihan.

## Kode Implementasi (Per File)

```typescript
// src/tipe-dasar.ts

// String
let nama: string = 'NestJS';
let pesan: string = `Halo ${nama}`;

// Number
let port: number = 3000;
let harga: number = 99.99;

// Boolean
let isProduction: boolean = false;
let isActive: boolean = true;

// Array
let numbers: number[] = [1, 2, 3];
let names: Array<string> = ['Alice', 'Bob'];

// Tuple — array dengan jumlah dan tipe tetap
let pair: [string, number] = ['version', 10];
// pair[0] harus string, pair[1] harus number

// Enum
enum HttpStatus {
  OK = 200,
  CREATED = 201,
  BAD_REQUEST = 400,
  NOT_FOUND = 404,
}

let status: HttpStatus = HttpStatus.OK;
```

## Cara Integrasi & Pengujian
Simpan kode di file `tipe-dasar.ts`. Compile dengan `npx tsc tipe-dasar.ts` atau jalankan dengan `npx ts-node tipe-dasar.ts`. Tipe-tipe ini akan sering muncul di NestJS — misal `string` untuk parameter, `number` untuk port, `enum` untuk status code.
