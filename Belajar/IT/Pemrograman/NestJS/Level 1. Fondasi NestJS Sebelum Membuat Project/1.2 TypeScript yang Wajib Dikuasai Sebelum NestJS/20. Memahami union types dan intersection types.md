# 20. Memahami union types dan intersection types

## Definisi & Target
Union types (`|`) memungkinkan sebuah nilai memiliki salah satu dari beberapa tipe. Intersection types (`&`) menggabungkan beberapa tipe menjadi satu. Keduanya sangat berguna untuk DTO dan response di NestJS.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Contoh langsung di file TypeScript.

## Kode Implementasi (Per File)

```typescript
// Union type: nilai bisa salah satu dari tipe yang disebutkan
type ID = string | number;

function findProduct(id: ID) {
  if (typeof id === 'string') {
    console.log(`Searching by slug: ${id}`);
  } else {
    console.log(`Searching by numeric ID: ${id}`);
  }
}

// Union dengan literal types
type OrderStatus = 'pending' | 'confirmed' | 'shipped' | 'delivered';

function processOrder(status: OrderStatus) {
  // Harga menerima 4 nilai string tersebut
}

// Intersection type: menggabungkan properti dari dua tipe
interface IBaseEntity {
  id: number;
  createdAt: Date;
}

interface IProductData {
  name: string;
  price: number;
}

type ProductEntity = IBaseEntity & IProductData;

const product: ProductEntity = {
  id: 1,
  createdAt: new Date(),
  name: 'Laptop',
  price: 15000000,
};
```

## Cara Integrasi & Pengujian
Union types sering untuk parameter ID yang bisa `string | number`. Intersection types berguna saat membuat entity yang menggabungkan base fields (id, createdAt) dengan data spesifik. Di NestJS, keduanya banyak dipakai di DTO dan response types.
