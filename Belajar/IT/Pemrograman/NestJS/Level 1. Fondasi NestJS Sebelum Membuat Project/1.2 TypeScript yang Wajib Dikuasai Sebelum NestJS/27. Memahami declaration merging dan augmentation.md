# 27. Memahami declaration merging dan augmentation

## Definisi & Target
Declaration merging memungkinkan TypeScript menggabungkan beberapa deklarasi dengan nama yang sama. Augmentation memungkinkan menambah properti ke tipe yang sudah ada. Di NestJS, ini berguna untuk menambah field ke `Request` Express (misal `req.user`).

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Contoh declaration merging.

## Kode Implementasi (Per File)

```typescript
// Declaration merging pada interface
// File 1: models/product.ts
interface IProduct {
  id: number;
  name: string;
}

// File 2: models/product-extended.ts
interface IProduct {
  price: number;
  category: string;
}

// Hasil merging: IProduct memiliki id, name, price, category
// Semua deklarasi dengan nama yang sama akan digabung

// Module augmentation — menambah tipe ke Express Request
// src/types/express.d.ts
declare namespace Express {
  interface Request {
    user?: {
      id: number;
      email: string;
      role: string;
    };
  }
}

// Sekarang req.user bisa diakses di controller manapun
// @Req() req // req.user tersedia setelah auth middleware
```

## Cara Integrasi & Pengujian
Declaration merging paling sering digunakan di NestJS untuk menambah properti `user` ke objek `Request` Express. Buat file `*.d.ts` di folder `src/types/` dengan deklarasi `namespace Express { interface Request { user: ... } }`. Setelah itu, `req.user` akan terdeteksi TypeScript.
