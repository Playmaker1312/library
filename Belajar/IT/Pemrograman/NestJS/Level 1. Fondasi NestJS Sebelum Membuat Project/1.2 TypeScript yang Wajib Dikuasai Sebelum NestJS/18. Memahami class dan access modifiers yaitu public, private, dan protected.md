# 18. Memahami class dan access modifiers yaitu public, private, dan protected

## Definisi & Target
Class dan access modifiers adalah fondasi utama NestJS. Service, Controller, dan Entity semuanya adalah class. Access modifiers mengontrol visibilitas properti dan method.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Contoh class dengan access modifiers.

## Kode Implementasi (Per File)

```typescript
// src/users/user.entity.ts

class UserEntity {
  public id: number;
  private password: string;
  protected role: string;

  constructor(id: number, password: string, role: string) {
    this.id = id;
    this.password = password;
    this.role = role;
  }

  public getDisplayName(): string {
    return `User #${this.id}`;
  }

  private hashPassword(): string {
    return this.password.split('').reverse().join('');
  }

  protected hasPermission(action: string): boolean {
    return this.role === 'admin';
  }
}

class AdminUser extends UserEntity {
  public canDeleteAny(): boolean {
    return this.hasPermission('delete');
  }
}
```

## Cara Integrasi & Pengujian
Di NestJS, service menggunakan `@Injectable()` dan properti biasanya `private readonly` untuk dependency injection. Gunakan `public` untuk method yang dipanggil dari luar, `private` untuk internal logic, `protected` untuk method yang diwariskan ke subclass.
