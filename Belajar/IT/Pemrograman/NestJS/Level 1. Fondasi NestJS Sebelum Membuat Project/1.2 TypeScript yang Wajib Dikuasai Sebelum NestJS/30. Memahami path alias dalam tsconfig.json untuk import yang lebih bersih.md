# 30. Memahami path alias dalam tsconfig.json untuk import yang lebih bersih

## Definisi & Target
Path alias memungkinkan import menggunakan path pendek seperti `@/products/product.service` daripada `../../../products/product.service`. NestJS sudah mendukung ini dengan konfigurasi di `tsconfig.json` dan `nest-cli.json`.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Modifikasi `tsconfig.json`.

## Kode Implementasi (Per File)

```json
// tsconfig.json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"],
      "@modules/*": ["src/modules/*"],
      "@common/*": ["src/common/*"]
    }
  }
}
```

```json
// nest-cli.json — tambahkan compilerOptions untuk build
{
  "collection": "@nestjs/schematics",
  "sourceRoot": "src",
  "compilerOptions": {
    "tsConfigPath": "tsconfig.build.json"
  }
}
```

Sebelum (tanpa alias):
```typescript
import { ProductsService } from '../../../products/products.service';
import { LoggerService } from '../../common/logger.service';
```

Sesudah (dengan alias):
```typescript
import { ProductsService } from '@modules/products/products.service';
import { LoggerService } from '@common/logger.service';
```

## Cara Integrasi & Pengujian
Pastikan `baseUrl` dan `paths` di `tsconfig.json` sudah diatur. Untuk production build, pastikan `tsconfig.build.json` mewarisi konfigurasi `paths`. Restart IDE setelah perubahan. Import seperti `@/products/products.service` akan dikenali TypeScript.
