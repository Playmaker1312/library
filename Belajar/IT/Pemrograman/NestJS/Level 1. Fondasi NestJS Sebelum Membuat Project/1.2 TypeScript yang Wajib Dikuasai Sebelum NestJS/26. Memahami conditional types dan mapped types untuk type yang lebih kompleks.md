# 26. Memahami conditional types dan mapped types untuk type yang lebih kompleks

## Definisi & Target
Conditional types memilih tipe berdasarkan kondisi (`T extends U ? X : Y`). Mapped types membuat tipe baru dengan memproses properti tipe yang ada. Ini berguna untuk membuat tipe utilitas kustom di NestJS.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Contoh conditional dan mapped types.

## Kode Implementasi (Per File)

```typescript
// Conditional type
type IsString<T> = T extends string ? 'yes' : 'no';
type A = IsString<string>; // 'yes'
type B = IsString<number>; // 'no'

// Conditional untuk API response
type ApiResponse<T> = T extends void
  ? { success: true; message: string }
  : { success: true; data: T };

type DeleteResponse = ApiResponse<void>;
type GetUserResponse = ApiResponse<{ id: number; name: string }>;

// Mapped type — membuat semua properti nullable
type Nullable<T> = {
  [K in keyof T]: T[K] | null;
};

interface IProduct {
  id: number;
  name: string;
  price: number;
}

type NullableProduct = Nullable<IProduct>;
// { id: number | null; name: string | null; price: number | null }

// Mapped type dengan modifier
type ReadonlyDeep<T> = {
  readonly [K in keyof T]: T[K] extends object ? ReadonlyDeep<T[K]> : T[K];
};
```

## Cara Integrasi & Pengujian
Conditional types berguna untuk membuat tipe yang adaptif — misal response berbeda untuk `findAll` vs `delete`. Mapped types digunakan di utility types bawaan (`Partial<T>`, `Required<T>`, dll). Pelajari ini untuk membuat type helpers kustom yang powerful.
