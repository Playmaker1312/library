# 29. Memahami error handling dengan TypeScript menggunakan try catch dan custom error types

## Definisi & Target
Error handling yang baik penting untuk aplikasi production. NestJS memiliki exception filters bawaan, tapi memahami try/catch dan custom error types di TypeScript adalah fondasi sebelum mempelajari fitur tersebut.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Contoh error handling di file TypeScript.

## Kode Implementasi (Per File)

```typescript
// Custom error class
class NotFoundError extends Error {
  constructor(resource: string, id: number) {
    super(`${resource} with id ${id} not found`);
    this.name = 'NotFoundError';
  }
}

class ValidationError extends Error {
  constructor(errors: string[]) {
    super(`Validation failed: ${errors.join(', ')}`);
    this.name = 'ValidationError';
  }
}

// Service dengan error handling
class ProductsService {
  async findById(id: number): Promise<IProduct> {
    try {
      const product = await this.getFromDatabase(id);
      if (!product) {
        throw new NotFoundError('Product', id);
      }
      return product;
    } catch (error) {
      if (error instanceof NotFoundError) {
        throw error;
      }
      throw new Error(`Database error: ${(error as Error).message}`);
    }
  }

  private async getFromDatabase(id: number): Promise<IProduct | null> {
    return null;
  }
}
```

## Cara Integrasi & Pengujian
Di NestJS, cukup throw `NotFoundException` atau `BadRequestException` dari `@nestjs/common`. NestJS akan menangkapnya dan mengirim response error yang sesuai. Custom error types berguna untuk kode yang lebih ekspresif dan testable.
