# 17. Memahami interface dan type alias serta kapan menggunakan masing-masing

## Definisi & Target
`interface` dan `type` digunakan untuk mendefinisikan bentuk data. Di NestJS, keduanya dipakai untuk DTO (Data Transfer Object) dan entity. Interface bisa di-extends/diimplement, type lebih fleksibel untuk union/intersection.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Deklarasi tipe di file `.ts`.

## Kode Implementasi (Per File)

```typescript
// Gunakan interface untuk object shape yang akan diimplement class
interface IProduct {
  id: number;
  name: string;
  price: number;
  readonly createdAt: Date;
}

// Gunakan type untuk union, intersection, atau tipe kompleks
type ProductStatus = 'active' | 'inactive' | 'archived';

type ProductWithStatus = IProduct & {
  status: ProductStatus;
};

type ApiResponse<T> = {
  success: boolean;
  data: T;
  message?: string;
};

// Interface bisa di-extends
interface IBook extends IProduct {
  author: string;
  pages: number;
}
```

## Cara Integrasi & Pengujian
Gunakan `interface` saat mendefinisikan kontrak object yang akan diimplement berkali-kali (misal entity). Gunakan `type` untuk union (misal `'active' | 'inactive'`), intersection, atau tipe conditional. Di NestJS, DTO biasanya menggunakan `class` dengan `@IsString()` decorator dari `class-validator`.
