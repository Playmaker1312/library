# 15. Cara menginstal TablePlus atau DBeaver sebagai GUI database client

## Definisi & Target
GUI database client memudahkan melihat, mengedit, dan mengelola data dalam database tanpa menggunakan command line. TablePlus ringan dan modern, DBeaver lebih lengkap dan gratis.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Download installer dari website resmi.

## Kode Implementasi (Per File)

```bash
# Instal TablePlus via winget
winget install TablePlus.TablePlus

# Instal DBeaver via winget
winget install DBeaver.DBeaver

# Atau download manual:
# TablePlus: https://tableplus.com/download
# DBeaver: https://dbeaver.io/download
```

Langkah koneksi ke PostgreSQL di TablePlus:
1. Buka TablePlus, klik **Create New Connection**
2. Pilih **PostgreSQL**
3. Isi:
   - Host: `localhost`
   - Port: `5432`
   - User: `nestuser`
   - Password: `nestpass`
   - Database: `nestdb`
4. Klik **Test** lalu **Connect**

## Cara Integrasi & Pengujian
Pastikan container database berjalan (`docker ps`). Buat koneksi baru dengan credential yang sesuai. Jika koneksi berhasil, kamu bisa melihat tabel, menjalankan query SQL, dan mengedit data langsung dari GUI.
