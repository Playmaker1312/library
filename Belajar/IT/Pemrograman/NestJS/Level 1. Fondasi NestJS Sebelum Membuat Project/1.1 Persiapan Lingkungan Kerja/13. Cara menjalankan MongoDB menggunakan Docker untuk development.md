# 13. Cara menjalankan MongoDB menggunakan Docker untuk development

## Definisi & Target
MongoDB adalah database NoSQL yang populer untuk aplikasi NestJS. Docker memudahkan menjalankan MongoDB tanpa instalasi native, cocok untuk development dan prototyping.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Gunakan Docker CLI atau Docker Compose.

## Kode Implementasi (Per File)

```yaml
# docker-compose.yml
services:
  mongodb:
    image: mongo:7
    container_name: nestjs-mongodb
    environment:
      MONGO_INITDB_ROOT_USERNAME: nestuser
      MONGO_INITDB_ROOT_PASSWORD: nestpass
    ports:
      - "27017:27017"
    volumes:
      - mongo_data:/data/db

volumes:
  mongo_data:
```

```bash
# Jalankan container
docker compose up -d

# Verifikasi
docker exec -it nestjs-mongodb mongosh -u nestuser -p nestpass

# Matikan container
docker compose down
```

String koneksi untuk NestJS (Mongoose):
```
mongodb://nestuser:nestpass@localhost:27017/nestdb?authSource=admin
```

## Cara Integrasi & Pengujian
Jalankan `docker compose up -d`. Cek container berjalan dengan `docker ps`. Gunakan MongoDB Compass atau terminal untuk connect ke `localhost:27017`. Database `nestdb` akan otomatis terbentuk saat pertama kali data disimpan.
