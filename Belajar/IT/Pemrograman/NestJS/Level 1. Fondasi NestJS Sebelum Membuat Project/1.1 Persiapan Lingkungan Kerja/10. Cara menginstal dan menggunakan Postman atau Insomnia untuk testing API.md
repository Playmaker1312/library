# 10. Cara menginstal dan menggunakan Postman atau Insomnia untuk testing API

## Definisi & Target
Postman dan Insomnia adalah GUI client untuk menguji API endpoint selama development. Keduanya mendukung berbagai metode HTTP, environment variables, dan koleksi request yang terorganisir.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Download installer dari website resmi.

## Kode Implementasi (Per File)

```bash
# Instal Postman via winget
winget install Postman.Postman

# Instal Insomnia via winget
winget install Insomnia.Insomnia
```

Langkah-langkah penggunaan Postman:
1. Buka Postman, klik **New > HTTP Request**
2. Pilih method (GET, POST, PUT, DELETE, dll)
3. Masukkan URL: `http://localhost:3000/products`
4. Untuk POST/PUT, buka tab **Body**, pilih **raw > JSON**
5. Isi body, misal: `{ "name": "Laptop", "price": 15000000 }`
6. Klik **Send**

Environment variables di Postman:
```
BaseURL: http://localhost:3000
→ {{BaseURL}}/products
```

## Cara Integrasi & Pengujian
Pastikan server NestJS berjalan (`npm run start:dev`). Kirim request GET ke `http://localhost:3000`. Jika mendapat response JSON (meskipun `[]` atau `404`), koneksi berhasil. Gunakan Collections untuk menyimpan kumpulan endpoint.
