# 8. Cara menginstal ekstensi Prettier dan ESLint di VS Code untuk kode yang konsisten

## Definisi & Target
Prettier memformat kode secara otomatis agar konsisten, sedangkan ESLint mendeteksi kesalahan sintaks dan best practice. NestJS sudah menyertakan konfigurasi keduanya saat project dibuat.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Instal kedua ekstensi melalui marketplace VS Code.

## Kode Implementasi (Per File)

```bash
# Instal ESLint
code --install-extension dbaeumer.vscode-eslint

# Instal Prettier
code --install-extension esbenp.prettier-vscode
```

Konfigurasi VS Code (`settings.json`) untuk otomatisasi:

```json
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": true
  }
}
```

## Cara Integrasi & Pengujian
Buka file `.ts` project NestJS, tulis kode dengan format berantakan (misal indentasi acak), lalu simpan (`Ctrl+S`). Jika kode otomatis rapi, Prettier bekerja. Jika ada garis merah yang menunjukkan error ESLint, ESLint juga aktif.
