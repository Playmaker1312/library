# 7. Cara menginstal ekstensi TypeScript Hero di VS Code untuk manajemen import

## Definisi & Target
TypeScript Hero adalah ekstensi VS Code yang membantu mengelola import statement secara otomatis — menambahkan, mengorganisir, dan membersihkan import yang tidak terpakai dalam file TypeScript.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Instal melalui marketplace VS Code.

## Kode Implementasi (Per File)

```bash
# Instal via terminal
code --install-extension rbbit.typescript-hero

# Alternatif: Cari "TypeScript Hero" di Extensions panel (Ctrl+Shift+X)
# Klik Install pada ekstensi oleh "Rbbit"
```

Fitur utama TypeScript Hero:
| Fitur | Fungsi |
|-------|--------|
| `Add import` | Menambahkan import secara otomatis saat mengetik |
| `Organize imports` | Mengurutkan dan mengelompokkan import |
| `Remove unused imports` | Menghapus import yang tidak dipakai |
| `Code Assist` | Membantu menulis kode TypeScript lebih cepat |

## Cara Integrasi & Pengujian
Buka file NestJS, hapus salah satu import lalu ketik ulang nama class yang diimpor. Jika muncul suggestion untuk menambahkan import secara otomatis, ekstensi berfungsi. Gunakan shortcut `Alt+Shift+O` untuk mengorganisir import.
