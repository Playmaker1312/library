# 9. Cara menginstal ekstensi REST Client di VS Code untuk testing API

## Definisi & Target
REST Client adalah ekstensi VS Code yang memungkinkan testing API endpoint langsung dari editor, tanpa perlu aplikasi terpisah seperti Postman. Cukup buat file `.http` dan kirim request.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Instal melalui marketplace VS Code.

## Kode Implementasi (Per File)

```bash
# Instal REST Client
code --install-extension humao.rest-client
```

Contoh file `test-api.http` untuk testing endpoint NestJS:

```http
### Get all products
GET http://localhost:3000/products
Content-Type: application/json

### Create a product
POST http://localhost:3000/products
Content-Type: application/json

{
  "name": "Laptop",
  "price": 15000000
}

### Get product by ID
GET http://localhost:3000/products/1

### Delete product
DELETE http://localhost:3000/products/1
```

## Cara Integrasi & Pengujian
Buat file `api.http` di project NestJS. Jalankan server NestJS dengan `npm run start:dev`. Klik tombol "Send Request" yang muncul di atas setiap blok request. Response akan muncul di panel terpisah.
