# 11. Cara menginstal Docker Desktop untuk kebutuhan containerisasi database

## Definisi & Target
Docker Desktop memungkinkan menjalankan database (PostgreSQL, MongoDB, Redis) dalam container tanpa instalasi natives yang rumit. NestJS bisa terkoneksi ke container database seperti ke database biasa.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Download installer Docker Desktop.

## Kode Implementasi (Per File)

```bash
# Instal Docker Desktop via winget
winget install Docker.DockerDesktop

# Atau download dari https://www.docker.com/products/docker-desktop

# Setelah instalasi, verifikasi
docker --version
# Contoh output: Docker version 27.0.0

docker compose version
# Contoh output: Docker Compose version v2.28.0
```

## Cara Integrasi & Pengujian
Buka Docker Desktop dan pastikan statusnya "Running". Jalankan `docker run hello-world` di terminal. Jika muncul pesan selamat datang, Docker berfungsi. NestJS akan menggunakan container database yang terhubung via `localhost` dengan port yang di-expose oleh container.
