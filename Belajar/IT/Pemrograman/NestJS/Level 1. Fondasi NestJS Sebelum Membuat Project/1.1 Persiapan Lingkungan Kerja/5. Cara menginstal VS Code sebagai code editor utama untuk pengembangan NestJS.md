# 5. Cara menginstal VS Code sebagai code editor utama untuk pengembangan NestJS

## Definisi & Target
Visual Studio Code adalah editor kode gratis dan ringan dengan dukungan ekstensi yang luas, sangat cocok untuk pengembangan NestJS karena integrasi TypeScript, debugging, dan terminal bawaan.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Cukup download dan instal VS Code.

## Kode Implementasi (Per File)

```bash
# Opsi 1: Download manual
# Buka https://code.visualstudio.com dan klik Download for Windows

# Opsi 2: Menggunakan winget (Windows 10+)
winget install Microsoft.VisualStudioCode

# Opsi 3: Menggunakan Chocolatey
choco install vscode

# Setelah instalasi, buka VS Code dari terminal
code .
```

## Cara Integrasi & Pengujian
Buka VS Code, buka menu `Help > About` untuk melihat versi. Buat file baru `test.ts`, ketik `const msg: string = "Hello NestJS";` — jika tidak ada error sintaks, TypeScript sudah terdeteksi secara native oleh VS Code.
