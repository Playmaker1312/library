# 4. Cara memverifikasi instalasi NestJS CLI menggunakan perintah nest --version

## Definisi & Target
Memastikan NestJS CLI telah terinstal dengan benar dan siap digunakan untuk membuat serta mengelola project NestJS.

## Komponen & Nest CLI Command
Perintah `nest --version` dan `nest --help`.

## Kode Implementasi (Per File)

```bash
# Cek versi NestJS CLI
nest --version
# Contoh output: 10.4.5

# Cek bantuan dan daftar perintah yang tersedia
nest --help

# Output yang diharapkan:
# Usage: nest <command> [options]
# Commands:
#   new|n [name]          Generate Nest application
#   build                 Build Nest application
#   start                 Run Nest application
#   generate|g [name]     Generate Nest artifact
#   ...
```

## Cara Integrasi & Pengujian
Buka terminal baru dan ketik `nest --version`. Jika muncul error "command not found" atau "nest is not recognized", instalasi belum berhasil. Coba restart terminal atau instal ulang dengan `npm install -g @nestjs/cli`.
