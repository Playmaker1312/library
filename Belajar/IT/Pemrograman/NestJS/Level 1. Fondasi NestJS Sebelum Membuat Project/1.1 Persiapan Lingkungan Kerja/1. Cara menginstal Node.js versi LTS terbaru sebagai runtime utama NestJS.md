# 1. Cara menginstal Node.js versi LTS terbaru sebagai runtime utama NestJS

## Definisi & Target
Node.js adalah runtime JavaScript berbasis V8 engine yang memungkinkan eksekusi kode JavaScript di sisi server. NestJS dibangun di atas Node.js dan memerlukan versi LTS (Long Term Support) untuk stabilitas, keamanan, dan dukungan jangka panjang. Versi LTS menerima patch keamanan dan perbaikan bug selama 30 bulan. Target: menginstal Node.js LTS terbaru (v20.x atau v22.x) sebagai fondasi runtime NestJS.

## Prasyarat
- Sistem Operasi: Windows 10/11, macOS 12+, atau Linux (Ubuntu 20.04+, Debian 11+, Fedora 38+)
- Akses internet untuk mengunduh installer
- Hak administrator/sudo untuk instalasi system-wide
- Minimal 4GB RAM, 2GB ruang disk bebas
- Tidak ada versi Node.js yang konflik (disarankan uninstall versi lama)

## Komponen & Nest CLI Command
```bash
# Verifikasi versi Node.js setelah instalasi
node --version
# Output contoh: v20.18.0

# Verifikasi npm (termasuk dalam Node.js installer)
npm --version
# Output contoh: 10.8.2

# Cek arsitektur sistem (untuk memilih installer yang benar)
# Windows: wmic os get osarchitecture
# macOS/Linux: uname -m
```

## Langkah-langkah Implementasi (Step-by-Step)

### Windows
1. Buka browser ke https://nodejs.org/en/download/
2. Pilih tab **LTS** (berlabel "Recommended for Most Users")
3. Unduh **Windows Installer (.msi)** untuk arsitektur sistem Anda (x64 untuk 64-bit, arm64 untuk ARM)
4. Jalankan file `.msi` yang diunduh
5. Ikuti wizard instalasi:
   - Accept license agreement → Next
   - Pilih instalasi destination (default: `C:\Program Files\nodejs\`) → Next
   - **Custom Setup**: Pastikan "Node.js runtime", "npm package manager", "Add to PATH" dicentang → Next
   - Install → Finish
6. Buka **Command Prompt baru** (penting: restart terminal agar PATH ter-update)
7. Verifikasi: `node --version` dan `npm --version`

### macOS
**Opsi A: Installer PKG (Rekomendasi untuk pemula)**
1. Unduh `.pkg` dari nodejs.org LTS
2. Jalankan installer, ikuti wizard standar
3. Verifikasi di Terminal baru

**Opsi B: Homebrew (Rekomendasi untuk developer)**
```bash
brew update
brew install node@20  # atau node@22 untuk LTS terbaru
echo 'export PATH="/opt/homebrew/opt/node@20/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
node --version
```

### Linux (Ubuntu/Debian)
**Opsi A: NodeSource Repository (Rekomendasi - versi terbaru)**
```bash
# Untuk Node.js 20 LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# Untuk Node.js 22 LTS
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs

node --version
npm --version
```

**Opsi B: nvm (Node Version Manager) - Fleksibel multi-versi**
```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc  # atau ~/.zshrc
nvm install --lts
nvm use --lts
node --version
```

## Kode Implementasi (Per File)
Tidak ada file kode untuk instalasi Node.js. Verifikasi instalasi berhasil dengan membuat file test sederhana:

**File: `test-node.js`**
```javascript
// Test Node.js runtime
console.log('Node.js version:', process.version);
console.log('Platform:', process.platform);
console.log('Architecture:', process.arch);
console.log('Memory usage:', process.memoryUsage());
console.log('✅ Node.js LTS terinstal dengan benar!');
```

Jalankan: `node test-node.js`

## Konfigurasi & Integrasi
**Environment Variables (Windows):**
- `NODE_PATH`: Secara otomatis disetel oleh installer
- `PATH`: Termasuk `C:\Program Files\nodejs\` (system-wide) atau `%APPDATA%\npm` (user)

**package.json scripts (untuk project NestJS nanti):**
```json
{
  "scripts": {
    "start": "nest start",
    "start:dev": "nest start --watch",
    "start:debug": "nest start --debug --watch",
    "build": "nest build",
    "test": "jest",
    "lint": "eslint \"{src,apps,libs,test}/**/*.ts\""
  },
  "engines": {
    "node": ">=20.0.0"
  }
}
```

## Cara Pengujian & Verifikasi
```bash
# 1. Verifikasi versi Node.js (harus LTS: 20.x atau 22.x)
node --version

# 2. Verifikasi npm
npm --version

# 3. Test eksekusi file JS sederhana
node -e "console.log('Hello from Node.js', process.version)"

# 4. Test npm registry access
npm ping
# Output: "npm notice PING https://registry.npmjs.org/"

# 5. Cek lokasi instalasi
which node        # macOS/Linux
where node        # Windows

# 6. Test global package install (dry-run)
npm install -g --dry-run typescript
```

## Troubleshooting & Common Issues

| Error | Penyebab | Solusi |
|-------|----------|--------|
| `'node' is not recognized as an internal or external command` | PATH tidak ter-update / terminal belum restart | Restart terminal/Command Prompt/PowerShell; atau restart PC |
| `npm ERR! code EACCES` | Permission denied pada folder global npm | Gunakan nvm; atau fix permission: `sudo chown -R $(whoami) $(npm config get prefix)/{lib/node_modules,bin,share}` |
| Versi Node.js lama (v16/v18) tetap terdeteksi | Multiple installations, PATH conflict | Uninstall versi lama via Control Panel / `brew uninstall node` / `apt remove nodejs`; gunakan nvm |
| `node: command not found` setelah install via nvm | Shell config tidak di-source | `source ~/.bashrc` / `source ~/.zshrc`; tambahkan ke shell profile |
| Installer Windows blocked by antivirus | False positive | Whitelist installer; download ulang dari nodejs.org resmi |

## Best Practices
1. **Selalu gunakan versi LTS** - Hindari versi Current/Stable untuk production
2. **Gunakan nvm/fnm** untuk manajemen versi Node.js multi-project
3. **Set `engines.node` di package.json** - Memastikan konsistensi tim
4. **Enable Corepack** untuk package manager modern: `corepack enable` (Node.js 16.9+)
5. **Update berkala** - LTS mendapat security patch bulanan
6. **Jangan gunakan `sudo npm install -g`** - Risiko permission & security
7. **Verifikasi checksum** installer untuk keamanan (SHA256 di nodejs.org)
