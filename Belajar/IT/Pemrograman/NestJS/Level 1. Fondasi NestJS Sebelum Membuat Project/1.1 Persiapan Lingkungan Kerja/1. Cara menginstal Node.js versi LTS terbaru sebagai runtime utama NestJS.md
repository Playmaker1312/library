# 1. Cara menginstal Node.js versi LTS terbaru sebagai runtime utama NestJS

## Definisi & Target
Node.js adalah runtime JavaScript yang menjalankan kode NestJS di sisi server. Targetnya adalah menginstal Node.js versi LTS (Long Term Support) agar lingkungan development stabil dan kompatibel dengan ekosistem NestJS.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Cukup download installer dari website resmi Node.js atau gunakan package manager.

## Kode Implementasi (Per File)

```bash
# Opsi 1: Download langsung dari nodejs.org
# Buka https://nodejs.org dan klik tombol LTS (disarankan)

# Opsi 2: Menggunakan winget (Windows)
winget install OpenJS.NodeJS.LTS

# Opsi 3: Menggunakan fnm (Node Version Manager untuk Windows)
fnm install --lts
fnm use lts-latest

# Verifikasi instalasi
node --version
# Contoh output: v20.18.0

npm --version
# Contoh output: 10.8.2
```

## Cara Integrasi & Pengujian
Buka terminal atau Command Prompt, jalankan `node --version`. Jika muncul versi Node.js (misal `v20.18.0`) maka instalasi berhasil. NestJS membutuhkan Node.js versi 16 atau lebih baru — semakin baru versi LTS, semakin baik dukungan fiturnya.
