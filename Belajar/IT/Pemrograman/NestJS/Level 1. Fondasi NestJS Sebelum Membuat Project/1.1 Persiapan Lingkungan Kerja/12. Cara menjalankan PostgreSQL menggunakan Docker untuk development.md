# 12. Cara menjalankan PostgreSQL menggunakan Docker untuk development

## Definisi & Target
PostgreSQL adalah database relasional yang sering digunakan bersama NestJS. Menjalankannya via Docker container memudahkan setup tanpa instalasi database server secara native.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Gunakan Docker CLI atau Docker Compose.

## Kode Implementasi (Per File)

```yaml
# docker-compose.yml
services:
  postgres:
    image: postgres:16-alpine
    container_name: nestjs-postgres
    environment:
      POSTGRES_USER: nestuser
      POSTGRES_PASSWORD: nestpass
      POSTGRES_DB: nestdb
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

volumes:
  postgres_data:
```

```bash
# Jalankan container
docker compose up -d

# Verifikasi koneksi
docker exec -it nestjs-postgres psql -U nestuser -d nestdb

# Matikan container
docker compose down
```

String koneksi untuk NestJS:
```
postgresql://nestuser:nestpass@localhost:5432/nestdb
```

## Cara Integrasi & Pengujian
Jalankan `docker compose up -d` di folder project. Cek dengan `docker ps` untuk memastikan container berjalan. Gunakan TablePlus/DBeaver atau `psql` untuk connect ke `localhost:5432` dengan user `nestuser` dan password `nestpass`.
