# 6. Cara menginstal ekstensi NestJS Snippets di VS Code untuk produktivitas

## Definisi & Target
Ekstensi NestJS Snippets menyediakan potongan kode (snippets) untuk mempercepat penulisan kode NestJS seperti module, controller, service, decorator, dan DTO.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Instal melalui marketplace VS Code.

## Kode Implementasi (Per File)

```bash
# Instal via terminal VS Code (Ctrl+Shift+P > Install Extensions)
code --install-extension abusaidm.ness-nestjs-snippets

# Atau cari "NestJS Snippets" di Extensions panel (Ctrl+Shift+X)
# Pilih yang paling populuar, misal oleh "NestJS" atau "AbuSaidM"
```

Contoh snippet yang tersedia setelah instalasi:
- `n-module` → membuat module NestJS
- `n-controller` → membuat controller NestJS
- `n-service` → membuat service NestJS
- `n-gateway` → membuat WebSocket gateway
- `n-decorator` → membuat custom decorator

## Cara Integrasi & Pengujian
Buka file `.ts` dalam project NestJS, ketik `n-module` lalu tekan Enter. Jika snippet muncul dan menghasilkan kode module, ekstensi berfungsi. Snippets sangat membantu menghindari boilerplate manual.
