# 3. Cara menginstal NestJS CLI secara global menggunakan perintah npm install -g @nestjs/cli

## Definisi & Target
NestJS CLI adalah alat baris perintah untuk membuat dan mengelola project NestJS. Dengan CLI, kamu bisa generate module, controller, service, dan boilerplate kode dengan cepat.

## Komponen & Nest CLI Command
Instalasi global NestJS CLI via npm/yarn/pnpm.

## Kode Implementasi (Per File)

```bash
# Instal NestJS CLI secara global menggunakan npm
npm install -g @nestjs/cli

# Atau menggunakan yarn
yarn global add @nestjs/cli

# Atau menggunakan pnpm
pnpm add -g @nestjs/cli
```

## Cara Integrasi & Pengujian
Setelah instalasi, jalankan `nest --version` di terminal. Jika muncul versi NestJS CLI (misal `10.0.0`), CLI siap digunakan. NestJS CLI menyediakan perintah seperti `nest new`, `nest generate` (alias `nest g`), `nest build`, dan `nest start`.
