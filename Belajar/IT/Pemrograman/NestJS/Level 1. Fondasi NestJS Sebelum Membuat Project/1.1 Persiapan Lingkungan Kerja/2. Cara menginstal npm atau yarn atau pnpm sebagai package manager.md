# 2. Cara menginstal npm atau yarn atau pnpm sebagai package manager

## Definisi & Target
Package manager mengelola dependensi project NestJS. npm sudah termasuk dalam Node.js, namun Yarn dan pnpm menawarkan kecepatan dan efisiensi penyimpanan yang lebih baik.

## Komponen & Nest CLI Command
Tidak ada perintah Nest CLI. Pilih salah satu package manager dan instal jika diperlukan.

## Kode Implementasi (Per File)

```bash
# npm (sudah terinstal otomatis bersama Node.js)
npm --version

# Yarn Classic
npm install -g yarn
yarn --version

# Yarn Berry (v2+)
npm install -g @yarnpkg/cli
yarn set version berry

# pnpm
npm install -g pnpm
pnpm --version
```

## Cara Integrasi & Pengujian
Jalankan perintah `npm --version`, `yarn --version`, atau `pnpm --version` di terminal. Jika muncul nomor versi, package manager siap digunakan. NestJS CLI kompatibel dengan ketiganya; gunakan `nest new project --package-manager yarn` saat ingin memilih package manager tertentu.
