# 66. Cara menggunakan decorator HttpCode untuk mengatur HTTP status code response

## Definisi & Target
Decorator `@HttpCode()` mengubah HTTP status code response default. Tanpa decorator, NestJS mengembalikan `200` untuk GET/PUT/PATCH/DELETE dan `201` untuk POST.

## Komponen & Nest CLI Command
Decorator `@HttpCode()` dari `@nestjs/common`.

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts

import { Controller, Get, Post, Delete, HttpCode } from '@nestjs/common';

@Controller('products')
export class ProductsController {
  @Post()
  @HttpCode(201)
  create() {
    return { message: 'Created' };
  }

  @Delete(':id')
  @HttpCode(204)
  remove() {
    return;
  }

  @Get('cached')
  @HttpCode(304)
  getCached() {
    return;
  }

  @Post('queue')
  @HttpCode(202)
  addToQueue() {
    return { message: 'Accepted for processing' };
  }
}
```

## Cara Integrasi & Pengujian

**Request:**
```http
POST http://localhost:3000/products
```

**Response:** Status `201 Created`
```json
{
  "message": "Created"
}
```

**Request:**
```http
DELETE http://localhost:3000/products/1
```

**Response:** Status `204 No Content` (tanpa body)

| Status Code | Penggunaan |
|-------------|-----------|
| `200` | Default success |
| `201` | Resource created |
| `202` | Accepted (async) |
| `204` | No content (delete success) |
| `304` | Not modified (cached) |
