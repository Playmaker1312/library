# 68. Cara menggunakan decorator Redirect untuk melakukan redirect

## Definisi & Target
Decorator `@Redirect()` mengarahkan client ke URL lain. Berguna untuk legacy route yang dipindahkan, atau redirect setelah aksi tertentu.

## Komponen & Nest CLI Command
Decorator `@Redirect()` dari `@nestjs/common`.

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts

import { Controller, Get, Redirect, Param } from '@nestjs/common';

@Controller('products')
export class ProductsController {
  @Get('legacy')
  @Redirect('/products', 301)
  redirectToProducts() {
    // Redirect permanent (301) ke /products
  }

  @Get('old-category/:slug')
  @Redirect()
  redirectOldCategory(@Param('slug') slug: string) {
    return {
      url: `/products?category=${slug}`,
      statusCode: 302,
    };
  }

  @Get('promo')
  @Redirect('https://example.com/promo', 302)
  redirectToExternal() {
    // Redirect ke URL eksternal
  }
}
```

## Cara Integrasi & Pengujian

**Request:**
```http
GET http://localhost:3000/products/legacy
```

**Response:** Status `301 Moved Permanently` dengan header `Location: /products`

**Request — dynamic redirect:**
```http
GET http://localhost:3000/products/old-category/electronics
```

**Response:** Status `302 Found` dengan header `Location: /products?category=electronics`

`@Redirect()` bisa dengan URL statis atau dinamis dengan mengembalikan object `{ url, statusCode }`.
