# 64. Cara menggunakan decorator Headers untuk mengakses request headers

## Definisi & Target
Decorator `@Headers()` digunakan untuk membaca HTTP headers dari request yang masuk. Berguna untuk mengambil token autentikasi, API key, atau custom headers.

## Komponen & Nest CLI Command
Decorator `@Headers()` dari `@nestjs/common`.

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts

import { Controller, Get, Post, Headers } from '@nestjs/common';

@Controller('products')
export class ProductsController {
  @Get()
  findAll(@Headers('authorization') auth: string) {
    return {
      authPresent: !!auth,
      tokenPrefix: auth?.split(' ')[0] || 'none',
    };
  }

  @Post()
  create(
    @Headers('x-api-key') apiKey: string,
    @Headers('user-agent') userAgent: string,
  ) {
    return {
      apiKeyValid: apiKey === 'secret-key',
      userAgent,
    };
  }

  @Get('headers')
  allHeaders(@Headers() headers: Record<string, string>) {
    return {
      totalHeaders: Object.keys(headers).length,
      sampleKeys: Object.keys(headers).slice(0, 5),
    };
  }
}
```

## Cara Integrasi & Pengujian

**Request:**
```http
GET http://localhost:3000/products
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9
```

**Response:**
```json
{
  "authPresent": true,
  "tokenPrefix": "Bearer"
}
```

`@Headers()` tanpa argumen mengembalikan semua headers sebagai object. `@Headers('name')` mengembalikan header spesifik. Header names bersifat case-insensitive.
