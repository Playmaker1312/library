# 70. Cara menggunakan wildcard route dalam NestJS

## Definisi & Target
Wildcard route menggunakan pola `*` atau `:param*` untuk mencocokkan multiple path segments. Berguna untuk catch-all routes, file serving, atau routing dinamis.

## Komponen & Nest CLI Command
Pattern path di decorator `@Get()`, `@Post()`, dll.

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts

import { Controller, Get, Post, Param } from '@nestjs/common';

@Controller('products')
export class ProductsController {
  @Get('search/*')
  searchWildcard(@Param() params: any) {
    return {
      message: 'Wildcard route',
      params,
      path: params[0],    // Bagian setelah search/
    };
  }

  @Get('category/:path(*)')
  catchAllPath(@Param('path') path: string) {
    return {
      fullPath: path,
      segments: path.split('/'),
    };
  }

  @Post('*')
  fallback() {
    return { message: 'Catch-all POST route' };
  }
}
```

Pengujian terpisah — file `api.http`:
```http
### Test wildcard
GET http://localhost:3000/products/search/laptop/gaming/2024

### Test multi-segment category
GET http://localhost:3000/products/category/electronics/laptops/gaming
```

**Response wildcard:**
```json
{
  "message": "Wildcard route",
  "params": { "0": "laptop/gaming/2024" },
  "path": "laptop/gaming/2024"
}
```

**Response multi-segment:**
```json
{
  "fullPath": "electronics/laptops/gaming",
  "segments": ["electronics", "laptops", "gaming"]
}
```

Wildcard `*` menangkap sisa path. Gunakan `(.*)` atau `(*)` sebagai parameter untuk mengakses konten wildcard. Letakkan wildcard route di bagian bawah agar tidak menghalangi route spesifik.
