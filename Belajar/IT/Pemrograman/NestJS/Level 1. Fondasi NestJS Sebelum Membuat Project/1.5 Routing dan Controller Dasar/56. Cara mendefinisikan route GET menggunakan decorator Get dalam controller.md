# 56. Cara mendefinisikan route GET menggunakan decorator Get dalam controller

## Definisi & Target
Decorator `@Get()` menandai method controller sebagai handler untuk HTTP GET request. GET biasanya digunakan untuk mengambil data (read operations).

## Komponen & Nest CLI Command
`nest g controller products` atau buat manual. Decorator `@Get()` dari `@nestjs/common`.

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts

import { Controller, Get } from '@nestjs/common';

@Controller('products')
export class ProductsController {
  @Get()
  findAll() {
    return { message: 'Get all products' };
  }

  @Get(':id')
  findOne() {
    return { message: 'Get single product' };
  }

  @Get('featured/top')
  findFeatured() {
    return { message: 'Get featured products' };
  }
}
```

## Cara Integrasi & Pengujian

**Request:**
```http
GET http://localhost:3000/products
```

**Response:**
```json
{
  "message": "Get all products"
}
```

**Request:**
```http
GET http://localhost:3000/products/featured/top
```

**Response:**
```json
{
  "message": "Get featured products"
}
```

Perhatikan bahwa route spesifik (`featured/top`) harus dideklarasikan sebelum route parameter (`:id`) agar tidak terhalang.
