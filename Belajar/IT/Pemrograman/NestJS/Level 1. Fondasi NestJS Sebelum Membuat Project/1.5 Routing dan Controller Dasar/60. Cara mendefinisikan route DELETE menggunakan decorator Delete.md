# 60. Cara mendefinisikan route DELETE menggunakan decorator Delete

## Definisi & Target
Decorator `@Delete()` menandai method controller sebagai handler untuk HTTP DELETE request. DELETE digunakan untuk menghapus resource.

## Komponen & Nest CLI Command
Decorator `@Delete()` dari `@nestjs/common`.

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts

import { Controller, Delete, Param, HttpCode } from '@nestjs/common';

@Controller('products')
export class ProductsController {
  @Delete(':id')
  @HttpCode(204)
  remove(@Param('id') id: string) {
    // Logika hapus produk
    return;
  }

  @Delete()
  removeMultiple(@Body() ids: number[]) {
    return {
      message: `${ids.length} products deleted`,
      deletedIds: ids,
    };
  }
}
```

## Cara Integrasi & Pengujian

**Request — hapus single:**
```http
DELETE http://localhost:3000/products/1
```

**Response:** `204 No Content` (tidak ada body)

**Request — hapus multiple:**
```http
DELETE http://localhost:3000/products
Content-Type: application/json

[1, 2, 3]
```

**Response:**
```json
{
  "message": "3 products deleted",
  "deletedIds": [1, 2, 3]
}
```

DELETE biasanya mengembalikan status `200` dengan body konfirmasi, atau `204` tanpa body.
