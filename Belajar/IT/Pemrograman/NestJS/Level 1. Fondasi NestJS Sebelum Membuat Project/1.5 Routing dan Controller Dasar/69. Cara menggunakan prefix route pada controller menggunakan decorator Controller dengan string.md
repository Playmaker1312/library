# 69. Cara menggunakan prefix route pada controller menggunakan decorator Controller dengan string

## Definisi & Target
Prefix route di `@Controller('prefix')` menambahkan awalan ke semua route dalam controller. Misal `@Controller('products')` membuat semua route di dalamnya dimulai dengan `/products`.

## Komponen & Nest CLI Command
String argumen di decorator `@Controller()`.

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts
import { Controller, Get, Post, Param } from '@nestjs/common';

@Controller('products')
export class ProductsController {
  @Get()            // → GET /products
  findAll() { return []; }

  @Post()           // → POST /products
  create() { return 'created'; }

  @Get(':id')       // → GET /products/:id
  findOne(@Param('id') id: string) { return { id }; }
}
```

```typescript
// src/users/users.controller.ts
import { Controller, Get } from '@nestjs/common';

@Controller('admin/users')
export class UsersController {
  @Get()            // → GET /admin/users
  findAll() { return []; }

  @Get('profile')   // → GET /admin/users/profile
  getProfile() { return {}; }
}
```

```typescript
// Beberapa controller dengan prefix berbeda
// @Controller('api/v1/products') → GET /api/v1/products
// @Controller('cms/articles')    → GET /cms/articles
// @Controller()                   → GET / (tanpa prefix)
```

## Cara Integrasi & Pengujian

**Request:**
```http
GET http://localhost:3000/admin/users
```

**Response:**
```json
[]
```

Prefix memudahkan pengelompokan endpoint. Setiap endpoint dalam controller otomatis memiliki prefix yang sama. Prefix bisa bertingkat seperti `admin/users`.
