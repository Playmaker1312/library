# 63. Cara menggunakan decorator Body untuk mengakses request body

## Definisi & Target
Decorator `@Body()` digunakan untuk mengakses data yang dikirim dalam request body (biasanya JSON). Wajib digunakan di method POST, PUT, dan PATCH.

## Komponen & Nest CLI Command
Decorator `@Body()` dari `@nestjs/common`.

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts

import { Controller, Post, Put, Patch, Body } from '@nestjs/common';

@Controller('products')
export class ProductsController {
  @Post()
  create(@Body() body: any) {
    return {
      message: 'Created',
      receivedData: body,
    };
  }

  @Put(':id')
  update(@Body('name') name: string, @Body('price') price: number) {
    return {
      message: `Updated name: ${name}, price: ${price}`,
    };
  }

  @Patch(':id')
  partialUpdate(@Body() partialData: Record<string, any>) {
    return {
      updatedFields: Object.keys(partialData),
    };
  }
}
```

## Cara Integrasi & Pengujian

**Request:**
```http
POST http://localhost:3000/products
Content-Type: application/json

{
  "name": "Laptop",
  "price": 15000000,
  "category": "electronics"
}
```

**Response:**
```json
{
  "message": "Created",
  "receivedData": {
    "name": "Laptop",
    "price": 15000000,
    "category": "electronics"
  }
}
```

`@Body()` tanpa argumen mengembalikan seluruh body. `@Body('property')` mengembalikan properti spesifik. Pastikan header `Content-Type: application/json` disertakan.
