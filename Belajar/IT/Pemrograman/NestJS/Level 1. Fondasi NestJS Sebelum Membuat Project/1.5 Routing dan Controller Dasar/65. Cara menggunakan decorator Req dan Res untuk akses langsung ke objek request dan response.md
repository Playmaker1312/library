# 65. Cara menggunakan decorator Req dan Res untuk akses langsung ke objek request dan response

## Definisi & Target
Decorator `@Req()` dan `@Res()` memberikan akses langsung ke objek native Express/Fastify `Request` dan `Response`. Gunakan hanya jika benar-benar diperlukan — NestJS decorator spesifik lebih direkomendasikan.

## Komponen & Nest CLI Command
Decorator `@Req()` dan `@Res()` dari `@nestjs/common`.

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts

import { Controller, Get, Req, Res } from '@nestjs/common';
import { Request, Response } from 'express';

@Controller('products')
export class ProductsController {
  @Get('request-info')
  getRequestInfo(@Req() req: Request) {
    return {
      method: req.method,
      url: req.originalUrl,
      ip: req.ip,
      hostname: req.hostname,
    };
  }

  @Get('custom-response')
  customResponse(@Res() res: Response) {
    res.status(201).json({
      message: 'Custom response using @Res()',
    });
  }
}
```

## Cara Integrasi & Pengujian

**Request:**
```http
GET http://localhost:3000/products/request-info
```

**Response:**
```json
{
  "method": "GET",
  "url": "/products/request-info",
  "ip": "::1",
  "hostname": "localhost"
}
```

**Peringatan:** Menggunakan `@Res()` mengharuskan kamu memanggil `res.json()`/`res.send()` secara manual — NestJS tidak akan mengirim response otomatis. Hindari penggunaan `@Res()` kecuali untuk response streaming atau custom.
