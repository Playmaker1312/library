# 61. Cara menggunakan decorator Param untuk mengakses route parameter

## Definisi & Target
Decorator `@Param()` digunakan untuk menangkap parameter dinamis dari URL path. Misal `GET /products/:id` — nilai `:id` bisa diakses dengan `@Param('id')`.

## Komponen & Nest CLI Command
Decorator `@Param()` dari `@nestjs/common`.

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts

import { Controller, Get, Param } from '@nestjs/common';

@Controller('products')
export class ProductsController {
  @Get(':id')
  findById(@Param('id') id: string) {
    return { id: +id, name: 'Product detail' };
  }

  @Get(':category/:id')
  findByCategoryAndId(
    @Param('category') category: string,
    @Param('id') id: string,
  ) {
    return { category, id: +id };
  }

  @Get()
  findAll(@Param() params: any) {
    // @Param() tanpa argumen mengembalikan semua params
    return params;
  }
}
```

## Cara Integrasi & Pengujian

**Request:**
```http
GET http://localhost:3000/products/42
```

**Response:**
```json
{
  "id": 42,
  "name": "Product detail"
}
```

**Request — multiple params:**
```http
GET http://localhost:3000/products/electronics/5
```

**Response:**
```json
{
  "category": "electronics",
  "id": 5
}
```

`@Param('name')` mengembalikan string. Konversi ke number dengan `+id` atau `Number(id)` jika diperlukan.
