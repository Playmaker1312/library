# 57. Cara mendefinisikan route POST menggunakan decorator Post

## Definisi & Target
Decorator `@Post()` menandai method controller sebagai handler untuk HTTP POST request. POST digunakan untuk membuat resource baru.

## Komponen & Nest CLI Command
Decorator `@Post()` dari `@nestjs/common`.

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts

import { Controller, Post, Body } from '@nestjs/common';

@Controller('products')
export class ProductsController {
  @Post()
  create(@Body() createProductDto: any) {
    return {
      message: 'Product created',
      data: createProductDto,
    };
  }

  @Post('bulk')
  createBulk(@Body() products: any[]) {
    return {
      message: `${products.length} products created`,
      count: products.length,
    };
  }
}
```

## Cara Integrasi & Pengujian

**Request:**
```http
POST http://localhost:3000/products
Content-Type: application/json

{
  "name": "Laptop",
  "price": 15000000
}
```

**Response:**
```json
{
  "message": "Product created",
  "data": {
    "name": "Laptop",
    "price": 15000000
  }
}
```

Gunakan `@Body()` untuk mengakses request body. Jangan lupa `Content-Type: application/json` di header.
