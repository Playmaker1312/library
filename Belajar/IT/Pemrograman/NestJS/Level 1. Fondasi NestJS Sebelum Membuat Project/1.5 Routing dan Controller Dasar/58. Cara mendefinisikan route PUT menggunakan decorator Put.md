# 58. Cara mendefinisikan route PUT menggunakan decorator Put

## Definisi & Target
Decorator `@Put()` menandai method controller sebagai handler untuk HTTP PUT request. PUT digunakan untuk memperbarui resource secara keseluruhan (full update).

## Komponen & Nest CLI Command
Decorator `@Put()` dari `@nestjs/common`.

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts

import { Controller, Put, Param, Body } from '@nestjs/common';

@Controller('products')
export class ProductsController {
  @Put(':id')
  update(@Param('id') id: string, @Body() updateProductDto: any) {
    return {
      message: `Product ${id} updated`,
      data: { id: +id, ...updateProductDto },
    };
  }
}
```

## Cara Integrasi & Pengujian

**Request:**
```http
PUT http://localhost:3000/products/1
Content-Type: application/json

{
  "name": "Laptop Gaming",
  "price": 18000000
}
```

**Response:**
```json
{
  "message": "Product 1 updated",
  "data": {
    "id": 1,
    "name": "Laptop Gaming",
    "price": 18000000
  }
}
```

PUT bersifat idempoten — request yang sama berkali-kali menghasilkan efek yang sama. PUT biasanya mengirim seluruh data resource, bukan hanya field yang berubah.
