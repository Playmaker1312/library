# 59. Cara mendefinisikan route PATCH menggunakan decorator Patch

## Definisi & Target
Decorator `@Patch()` menandai method controller sebagai handler untuk HTTP PATCH request. PATCH digunakan untuk memperbarui sebagian field resource (partial update), berbeda dengan PUT yang mengupdate seluruh resource.

## Komponen & Nest CLI Command
Decorator `@Patch()` dari `@nestjs/common`.

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts

import { Controller, Patch, Param, Body } from '@nestjs/common';

@Controller('products')
export class ProductsController {
  @Patch(':id')
  partialUpdate(@Param('id') id: string, @Body() partialData: any) {
    return {
      message: `Product ${id} partially updated`,
      fieldsUpdated: Object.keys(partialData),
    };
  }
}
```

## Cara Integrasi & Pengujian

**Request — hanya update price:**
```http
PATCH http://localhost:3000/products/1
Content-Type: application/json

{
  "price": 17000000
}
```

**Response:**
```json
{
  "message": "Product 1 partially updated",
  "fieldsUpdated": ["price"]
}
```

PATCH tidak idempoten. Gunakan PATCH ketika client hanya mengirim field yang berubah. Gunakan PUT ketika seluruh data resource dikirim.
