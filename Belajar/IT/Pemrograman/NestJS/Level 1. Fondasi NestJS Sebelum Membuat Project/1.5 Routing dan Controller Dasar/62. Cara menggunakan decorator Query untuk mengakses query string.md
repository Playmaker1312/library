# 62. Cara menggunakan decorator Query untuk mengakses query string

## Definisi & Target
Decorator `@Query()` digunakan untuk menangkap parameter query string dari URL. Misal `GET /products?page=1&limit=10` — nilai `page` dan `limit` bisa diakses dengan `@Query()`.

## Komponen & Nest CLI Command
Decorator `@Query()` dari `@nestjs/common`.

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts

import { Controller, Get, Query } from '@nestjs/common';

@Controller('products')
export class ProductsController {
  @Get()
  findAll(
    @Query('page') page: string,
    @Query('limit') limit: string,
    @Query('search') search?: string,
  ) {
    return {
      page: +page || 1,
      limit: +limit || 10,
      search: search || '',
    };
  }

  @Get('filter')
  filter(@Query() filters: Record<string, string>) {
    return {
      appliedFilters: filters,
      count: Object.keys(filters).length,
    };
  }
}
```

## Cara Integrasi & Pengujian

**Request:**
```http
GET http://localhost:3000/products?page=2&limit=20&search=laptop
```

**Response:**
```json
{
  "page": 2,
  "limit": 20,
  "search": "laptop"
}
```

**Request — semua query params:**
```http
GET http://localhost:3000/products/filter?category=electronics&minPrice=1000&maxPrice=5000
```

**Response:**
```json
{
  "appliedFilters": {
    "category": "electronics",
    "minPrice": "1000",
    "maxPrice": "5000"
  },
  "count": 3
}
```

Query string selalu bertipe string. Konversi ke number dengan `+` jika diperlukan.
