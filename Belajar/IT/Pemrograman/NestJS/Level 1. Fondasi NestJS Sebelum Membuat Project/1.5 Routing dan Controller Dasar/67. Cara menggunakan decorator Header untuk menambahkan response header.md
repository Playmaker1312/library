# 67. Cara menggunakan decorator Header untuk menambahkan response header

## Definisi & Target
Decorator `@Header()` menambahkan custom header ke HTTP response. Berguna untuk cache control, content type khusus, atau header keamanan.

## Komponen & Nest CLI Command
Decorator `@Header()` dari `@nestjs/common`.

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts

import { Controller, Get, Post, Header } from '@nestjs/common';

@Controller('products')
export class ProductsController {
  @Get()
  @Header('Cache-Control', 'no-store')
  findAll() {
    return [];
  }

  @Get('download')
  @Header('Content-Type', 'application/json')
  @Header('Content-Disposition', 'attachment; filename="products.json"')
  download() {
    return [{ id: 1, name: 'Laptop' }];
  }

  @Post()
  @Header('X-Custom-Header', 'CustomValue')
  @Header('X-Request-Id', '12345')
  create() {
    return { message: 'Created' };
  }
}
```

## Cara Integrasi & Pengujian

**Request:**
```http
GET http://localhost:3000/products
```

**Response Headers:**
```
Cache-Control: no-store
Content-Type: application/json; charset=utf-8
```

**Request:**
```http
GET http://localhost:3000/products/download
```

**Response Headers:**
```
Content-Type: application/json
Content-Disposition: attachment; filename="products.json"
```

Gunakan multiple `@Header()` decorators untuk menambah beberapa header. Header names bersifat case-insensitive.
