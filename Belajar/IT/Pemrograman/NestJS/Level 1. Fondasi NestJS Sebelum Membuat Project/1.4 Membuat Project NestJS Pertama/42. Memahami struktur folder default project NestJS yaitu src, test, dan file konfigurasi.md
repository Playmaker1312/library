# 42. Memahami struktur folder default project NestJS yaitu src, test, dan file konfigurasi

## Definisi & Target
Setelah `nest new`, project memiliki struktur standar. Memahami struktur ini penting agar tidak bingung saat menambah fitur baru.

## Komponen & Nest CLI Command
Tidak ada perintah CLI. Struktur hasil `nest new`.

## Kode Implementasi (Per File)

```
my-nest-app/
├── src/                      # Kode sumber aplikasi
│   ├── main.ts               # Entry point aplikasi
│   ├── app.module.ts         # Root module
│   ├── app.controller.ts     # Root controller
│   ├── app.controller.spec.ts# Unit test controller
│   ├── app.service.ts        # Root service
│   └── app.service.spec.ts   # Unit test service
├── test/                     # Integration/e2e tests
│   ├── app.e2e-spec.ts
│   └── jest-e2e.json
├── node_modules/             # Dependencies (auto-generated)
├── dist/                     # Hasil build (auto-generated)
├── .eslintrc.js              # Konfigurasi ESLint
├── .prettierrc               # Konfigurasi Prettier
├── nest-cli.json             # Konfigurasi NestJS CLI
├── tsconfig.json             # Konfigurasi TypeScript
├── tsconfig.build.json       # TypeScript build config
├── package.json              # Dependencies dan scripts
└── README.md
```

## Cara Integrasi & Pengujian
Semua kode baru yang kamu buat menggunakan `nest g` akan masuk ke folder `src/` secara otomatis. Folder `test/` untuk integration test. File konfigurasi di root project sebaiknya tidak dihapus karena diperlukan untuk build dan linting.
