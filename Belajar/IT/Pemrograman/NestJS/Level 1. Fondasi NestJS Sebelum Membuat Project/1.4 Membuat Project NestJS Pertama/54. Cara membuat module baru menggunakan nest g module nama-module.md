# 54. Cara membuat module baru menggunakan nest g module nama-module

## Definisi & Target
`nest g module` membuat file module baru yang akan mengelompokkan controller, service, dan provider untuk suatu fitur. Module adalah unit organisasi utama di NestJS.

## Komponen & Nest CLI Command
`nest g module <nama>` — membuat file `src/<nama>/<nama>.module.ts`.

## Kode Implementasi (Per File)

```bash
# Buat products module
nest g module products

# Buat users module
nest g module users

# Buat module dengan path bertingkat
nest g module modules/products

# Buat module tanpa folder (flat)
nest g module products --flat
```

Hasil perintah `nest g module products`:
```
src/products/
└── products.module.ts
```

```typescript
// src/products/products.module.ts — hasil generate

import { Module } from '@nestjs/common';

@Module({})
export class ProductsModule {}
```

## Cara Integrasi & Pengujian
Setelah module dibuat, tambahkan ke `imports` di `app.module.ts`:
```typescript
@Module({
  imports: [ProductsModule],
})
export class AppModule {}
```
Kemudian generate controller dan service di dalam module yang sama.
