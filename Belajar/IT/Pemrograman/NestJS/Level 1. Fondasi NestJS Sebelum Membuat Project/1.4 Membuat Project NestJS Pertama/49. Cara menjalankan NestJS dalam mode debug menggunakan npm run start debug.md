# 49. Cara menjalankan NestJS dalam mode debug menggunakan npm run start:debug

## Definisi & Target
Mode debug memungkinkan developer menghubungkan debugger (dari VS Code atau IDE lain) ke aplikasi NestJS yang sedang berjalan. Berguna untuk melacak alur eksekusi dan memeriksa nilai variabel.

## Komponen & Nest CLI Command
`npm run start:debug` — menjalankan Nest dengan `--debug` flag.

## Kode Implementasi (Per File)

```json
// package.json — script debug
{
  "scripts": {
    "start:debug": "nest start --debug --watch",
    "start:dev": "nest start --watch"
  }
}
```

Konfigurasi VS Code `.vscode/launch.json`:
```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "node",
      "request": "attach",
      "name": "Attach NestJS Debug",
      "port": 9229,
      "restart": true,
      "sourceMaps": true
    }
  ]
}
```

```bash
# Jalankan mode debug
npm run start:debug
# Output: Debugger listening on ws://127.0.0.1:9229
```

## Cara Integrasi & Pengujian
Jalankan `npm run start:debug`. Di VS Code, buka tab Run & Debug (`Ctrl+Shift+D`), pilih "Attach NestJS Debug", lalu klik play. Pasang breakpoint di file `.ts` manapun. Saat endpoint dipanggil, eksekusi akan berhenti di breakpoint.
