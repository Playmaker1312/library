# 41. Cara membuat project NestJS baru menggunakan perintah nest new nama-project

## Definisi & Target
Perintah `nest new` membuat project NestJS baru dengan struktur folder default, konfigurasi TypeScript, ESLint, Prettier, dan package dependencies yang sudah siap pakai.

## Komponen & Nest CLI Command
`nest new <nama-project>` — perintah utama.

## Kode Implementasi (Per File)

```bash
# Buat project baru
nest new my-nest-app

# Atau tentukan package manager
nest new my-nest-app --package-manager npm
nest new my-nest-app --package-manager yarn
nest new my-nest-app --package-manager pnpm

# Gunakan strict mode
nest new my-nest-app --strict

# Skip git initialization
nest new my-nest-app --skip-git

# Gunakan npm registry alternatif
nest new my-nest-app --registry https://registry.npmjs.org
```

Saat menjalankan `nest new`, CLI akan:
1. Membuat folder project
2. Menginstal dependencies (`@nestjs/core`, `@nestjs/common`, dll)
3. Membuat struktur folder `src/` dan `test/`
4. Membuat konfigurasi `tsconfig.json`, `nest-cli.json`, `.eslintrc.js`, `.prettierrc`

## Cara Integrasi & Pengujian
Jalankan `nest new my-nest-app`. Masuk ke folder: `cd my-nest-app`. Jalankan `npm run start:dev` untuk memastikan server berjalan di `http://localhost:3000`.
