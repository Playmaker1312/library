# 41. Cara membuat project NestJS baru menggunakan perintah nest new nama-project

## Definisi & Target
`nest new` adalah perintah CLI NestJS untuk membuat project baru dengan struktur standar, konfigurasi TypeScript, ESLint, Prettier, dan testing utilities. Perintah ini mengotomatisasi setup boilerplate sehingga developer bisa langsung fokus pada business logic. Target: memahami cara membuat project NestJS baru, pilihan package manager, dan struktur awal yang dihasilkan.

## Prasyarat
- Node.js >= 18.x (LTS recommended)
- npm >= 9.x atau yarn/pnpm
- NestJS CLI terinstall global: `npm i -g @nestjs/cli`
- VS Code dengan ekstensi TypeScript dan NestJS snippets
- Git untuk version control

## Komponen & Nest CLI Command
```bash
# Basic usage
nest new nama-project

# With specific package manager
nest new nama-project --package-manager npm
nest new nama-project --package-manager yarn
nest new nama-project --package-manager pnpm

# Skip git initialization
nest new nama-project --skip-git

# Dry run (preview without creating)
nest new nama-project --dry-run

# Strict mode (stricter TypeScript config)
nest new nama-project --strict
```

## Langkah-langkah Implementasi (Step-by-Step)
1. **Install NestJS CLI globally**
   ```bash
   npm i -g @nestjs/cli
   # Verify installation
   nest --version
   ```

2. **Create new project**
   ```bash
   nest new my-nest-app
   # Pilih package manager: npm (default), yarn, atau pnpm
   # Tunggu instalasi dependencies selesai
   ```

3. **Navigate to project directory**
   ```bash
   cd my-nest-app
   ```

4. **Verify project structure**
   ```bash
   ls -la
   # Expected: src/, test/, node_modules/, package.json, tsconfig.json, nest-cli.json, .eslintrc.js, .prettierrc
   ```

5. **Run development server**
   ```bash
   npm run start:dev
   # Server running at http://localhost:3000
   ```

## Konfigurasi & Integrasi
- **package.json scripts**: `start:dev` untuk hot reload, `start:prod` untuk production, `build` untuk compile TypeScript
- **tsconfig.json**: Target ES2021, module commonjs, strict mode enabled
- **nest-cli.json**: sourceRoot: "src", compilerOptions untuk plugins
- **Git**: Auto-initialized kecuali flag `--skip-git`

## Troubleshooting & Common Issues
| Error | Penyebab | Solusi |
|-------|----------|--------|
| `nest: command not found` | NestJS CLI tidak terinstall global | `npm i -g @nestjs/cli` |
| `EACCES: permission denied` | Permission npm global folder | Gunakan `npx @nestjs/cli new` atau fix npm prefix |
| `Cannot find module '@nestjs/common'` | Dependencies belum terinstall | `npm install` di folder project |
| `Port 3000 already in use` | Port konflik | Ubah port di main.ts atau kill process: `npx kill-port 3000` |
| `TypeScript version mismatch` | TS version tidak cocok dengan @nestjs/cli | Update TypeScript: `npm i -D typescript@latest` |

## Best Practices
- Gunakan `npx @nestjs/cli new` untuk versi CLI terbaru tanpa install global
- Selalu commit `package-lock.json` untuk konsistensi dependencies
- Aktifkan `--strict` untuk TypeScript strict mode di project baru
- Gunakan pnpm untuk performa install lebih cepat dan disk space hemat
- Setup Husky + lint-staged untuk pre-commit hooks
