# 51. Memahami file konfigurasi nest-cli.json dan kegunaannya

## Definisi & Target
`nest-cli.json` adalah file konfigurasi khusus untuk NestJS CLI. File ini mengatur bagaimana CLI berperilaku — seperti direktori sumber, kompilasi, dan bahasa (TypeScript atau JavaScript).

## Komponen & Nest CLI Command
Tidak ada perintah CLI. File dibuat otomatis saat `nest new`.

## Kode Implementasi (Per File)

```json
// nest-cli.json
{
  "$schema": "https://json.schemastore.org/nest-cli",
  "collection": "@nestjs/schematics",
  "sourceRoot": "src",
  "compilerOptions": {
    "deleteOutDir": true,
    "tsConfigPath": "tsconfig.build.json",
    "webpack": false,
    "assets": ["**/*.proto", "**/*.json"],
    "watchAssets": true,
    "manualRestart": false
  },
  "generateOptions": {
    "spec": true,
    "flat": false
  }
}
```

| Opsi | Fungsi |
|------|--------|
| `sourceRoot` | Folder utama kode sumber (`src/`) |
| `deleteOutDir` | Hapus folder `dist/` sebelum build |
| `collection` | Collection schematics (default NestJS) |
| `generateOptions.spec` | Generate file test otomatis |

## Cara Integrasi & Pengujian
File ini penting jika ingin mengubah perilaku CLI — misal menambah asset yang ikut di-copy ke `dist/` atau mengubah lokasi generate file. Default sudah optimal untuk sebagian besar project.
