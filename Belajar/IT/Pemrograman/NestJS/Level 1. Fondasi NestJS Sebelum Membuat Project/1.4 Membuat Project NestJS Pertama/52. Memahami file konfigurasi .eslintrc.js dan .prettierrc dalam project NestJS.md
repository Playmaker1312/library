# 52. Memahami file konfigurasi .eslintrc.js dan .prettierrc dalam project NestJS

## Definisi & Target
ESLint mendeteksi error dan best practice kode TypeScript. Prettier memformat kode secara otomatis untuk konsistensi gaya. NestJS sudah menyertakan konfigurasi keduanya.

## Komponen & Nest CLI Command
Tidak ada perintah CLI. File dibuat otomatis saat `nest new`.

## Kode Implementasi (Per File)

```javascript
// .eslintrc.js
module.exports = {
  parser: '@typescript-eslint/parser',
  parserOptions: {
    project: 'tsconfig.json',
    tsconfigRootDir: __dirname,
    sourceType: 'module',
  },
  plugins: ['@typescript-eslint/eslint-plugin'],
  extends: [
    'plugin:@typescript-eslint/recommended',
    'plugin:prettier/recommended',
  ],
  root: true,
  env: { node: true, jest: true },
  ignorePatterns: ['.eslintrc.js'],
  rules: {
    '@typescript-eslint/no-explicit-any': 'off',
    '@typescript-eslint/no-unused-vars': ['warn', { argsIgnorePattern: '^_' }],
  },
};
```

```json
// .prettierrc
{
  "singleQuote": true,
  "trailingComma": "all",
  "tabWidth": 2,
  "semi": true,
  "printWidth": 100
}
```

## Cara Integrasi & Pengujian
Jalankan `npm run lint` untuk mengecek error ESLint. Jalankan `npx prettier --check src/` untuk cek formatting. Di VS Code dengan ekstensi terinstal, error akan muncul langsung saat mengetik dan formatting otomatis saat save.
