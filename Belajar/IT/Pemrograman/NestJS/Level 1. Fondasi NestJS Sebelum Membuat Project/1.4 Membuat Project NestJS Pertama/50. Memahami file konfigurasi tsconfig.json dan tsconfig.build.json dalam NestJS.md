# 50. Memahami file konfigurasi tsconfig.json dan tsconfig.build.json dalam NestJS

## Definisi & Target
`tsconfig.json` adalah konfigurasi TypeScript utama untuk development dan linting. `tsconfig.build.json` adalah konfigurasi khusus untuk production build, biasanya lebih ketat dan mengecualikan file test.

## Komponen & Nest CLI Command
Tidak ada perintah CLI. File dibuat otomatis saat `nest new`.

## Kode Implementasi (Per File)

```json
// tsconfig.json
{
  "compilerOptions": {
    "module": "commonjs",
    "declaration": true,
    "removeComments": true,
    "emitDecoratorMetadata": true,
    "experimentalDecorators": true,
    "target": "ES2021",
    "sourceMap": true,
    "outDir": "./dist",
    "baseUrl": "./",
    "incremental": true,
    "skipLibCheck": true,
    "strictNullChecks": true,
    "noImplicitAny": true,
    "strictBindCallApply": true,
    "forceConsistentCasingInFileNames": true,
    "noFallthroughCasesInSwitch": true,
    "paths": {
      "@/*": ["src/*"]
    }
  }
}
```

```json
// tsconfig.build.json
{
  "extends": "./tsconfig.json",
  "exclude": ["node_modules", "test", "dist", "**/*spec.ts"]
}
```

## Cara Integrasi & Pengujian
`tsconfig.json` digunakan untuk development dan IDE. `tsconfig.build.json` digunakan saat `nest build`. Perbedaan utama: build config mengecualikan file test (`*.spec.ts`) yang tidak perlu diikutkan ke production.
