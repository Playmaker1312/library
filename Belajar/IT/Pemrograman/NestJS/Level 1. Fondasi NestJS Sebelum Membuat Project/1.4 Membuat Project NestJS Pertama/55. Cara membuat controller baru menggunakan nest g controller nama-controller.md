# 55. Cara membuat controller baru menggunakan nest g controller nama-controller

## Definisi & Target
`nest g controller` membuat file controller baru untuk menangani HTTP request. Controller akan otomatis terdaftar di module terdekat jika module sudah ada.

## Komponen & Nest CLI Command
`nest g controller <nama>` — membuat controller di folder sesuai nama.

## Kode Implementasi (Per File)

```bash
# Buat controller untuk products (jika sudah ada products module)
nest g controller products

# Buat controller dengan path spesifik
nest g controller modules/products

# Buat controller tanpa test file
nest g controller products --no-spec
```

Hasil perintah:
```
src/products/
├── products.controller.ts
└── products.controller.spec.ts
```

```typescript
// src/products/products.controller.ts — hasil generate

import { Controller } from '@nestjs/common';

@Controller('products')
export class ProductsController {}
```

Module akan otomatis diperbarui:
```typescript
@Module({
  controllers: [ProductsController],
})
export class ProductsModule {}
```

## Cara Integrasi & Pengujian
Setelah controller dibuat, tambahkan method dengan decorator route (`@Get()`, `@Post()`, dll). Module akan otomatis mendaftarkan controller. Jalankan server dan akses endpoint sesuai prefix controller.
