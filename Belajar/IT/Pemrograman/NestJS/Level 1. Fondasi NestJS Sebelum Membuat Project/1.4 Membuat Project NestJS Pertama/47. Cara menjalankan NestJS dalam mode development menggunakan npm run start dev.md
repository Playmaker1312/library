# 47. Cara menjalankan NestJS dalam mode development menggunakan npm run start:dev

## Definisi & Target
Mode development menggunakan `nest start --watch` yang secara otomatis me-restart aplikasi setiap kali ada perubahan file. Ini mempercepat proses development karena tidak perlu manual restart.

## Komponen & Nest CLI Command
`npm run start:dev` — script yang ada di `package.json`.

## Kode Implementasi (Per File)

```json
// package.json — script start:dev
{
  "scripts": {
    "start:dev": "nest start --watch",
    "build": "nest build",
    "start": "nest start"
  }
}
```

Menjalankan mode development:
```bash
# Jalankan mode development dengan watch
npm run start:dev

# Output:
# [Nest] LOG [NestFactory] Starting Nest application...
# [Nest] LOG [NestFactory] Application is running on: http://localhost:3000

# Saat file diubah, Nest akan rebuild dan restart otomatis
```

## Cara Integrasi & Pengujian
Ubah file `src/app.controller.ts` — ganti `getHello()` return value. Setelah disimpan, terminal akan menunjukkan proses rebuild dan application restart. Refresh browser di `http://localhost:3000`, perubahan akan terlihat tanpa restart manual.
