# 53. Cara menggunakan perintah nest generate atau nest g untuk membuat file baru

## Definisi & Target
`nest generate` (alias `nest g`) adalah perintah CLI untuk membuat berbagai komponen NestJS secara otomatis — module, controller, service, guard, pipe, filter, interceptor, dan lainnya.

## Komponen & Nest CLI Command
`nest g <schematic> <nama>` — perintah utama.

## Kode Implementasi (Per File)

```bash
# Daftar schematics yang tersedia
nest g module products      # ProductsModule
nest g controller products  # ProductsController
nest g service products     # ProductsService
nest g class products/dto/create-product        # Class
nest g interface products/interfaces/product    # Interface
nest g guard auth/jwt-auth                      # Guard
nest g pipe products/validation                 # Pipe
nest g filter common/http-error                 # Exception filter
nest g interceptor common/logging               # Interceptor
nest g middleware common/logger                 # Middleware
nest g decorator common/public                  # Decorator (custom)

# Opsi tambahan
nest g service products --no-spec     # Tanpa file test
nest g module products --flat         # Tanpa folder terpisah
nest g service products --dry-run     # Simulasi tanpa membuat file
```

## Cara Integrasi & Pengujian
Semua perintah di atas akan menghasilkan file di folder `src/` secara otomatis. Misal `nest g module products` akan membuat `src/products/products.module.ts`. Gunakan `--dry-run` dulu untuk melihat file apa saja yang akan dibuat.
