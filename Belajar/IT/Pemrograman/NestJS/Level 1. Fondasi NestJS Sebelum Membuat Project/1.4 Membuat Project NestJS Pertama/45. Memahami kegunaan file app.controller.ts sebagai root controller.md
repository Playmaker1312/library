# 45. Memahami kegunaan file app.controller.ts sebagai root controller

## Definisi & Target
`app.controller.ts` adalah controller default yang dibuat saat project baru. Biasanya digunakan untuk endpoint root (`GET /`) atau health check. Untuk aplikasi production, controller ini bisa dihapus setelah module fitur dibuat.

## Komponen & Nest CLI Command
Tidak ada perintah CLI. File sudah ada sejak `nest new`.

## Kode Implementasi (Per File)

```typescript
// src/app.controller.ts

import { Controller, Get } from '@nestjs/common';
import { AppService } from './app.service';

@Controller()
export class AppController {
  constructor(private readonly appService: AppService) {}

  @Get()
  getHello(): string {
    return this.appService.getHello();
  }
}
```

Untuk health check endpoint:
```typescript
// src/app.controller.ts — versi health check

@Controller()
export class AppController {
  constructor(private readonly appService: AppService) {}

  @Get('health')
  healthCheck() {
    return { status: 'ok', timestamp: new Date().toISOString() };
  }
}
```

## Cara Integrasi & Pengujian
Endpoint `GET /` akan mengembalikan `"Hello World!"` secara default. Kamu bisa mengubahnya atau mengganti dengan health check. Jika sudah memiliki module fitur (misal `ProductsModule`), controller ini bisa disederhanakan atau dihapus.
