# 46. Memahami kegunaan file app.service.ts sebagai root service

## Definisi & Target
`app.service.ts` adalah service default yang menyediakan logika untuk root controller. Dalam aplikasi nyata, service ini biasanya diganti atau dihapus setelah module fitur ditambahkan.

## Komponen & Nest CLI Command
Tidak ada perintah CLI. File sudah ada sejak `nest new`.

## Kode Implementasi (Per File)

```typescript
// src/app.service.ts

import { Injectable } from '@nestjs/common';

@Injectable()
export class AppService {
  getHello(): string {
    return 'Hello World!';
  }

  getVersion(): string {
    return '1.0.0';
  }
}
```

## Cara Integrasi & Pengujian
Service ini hanyalah placeholder. Dalam aplikasi riil, kamu akan membuat banyak service spesifik per fitur (misal `ProductsService`, `UsersService`). Root service bisa dihapus jika tidak digunakan — cukup hapus dari `app.module.ts` dan `app.controller.ts`.
