# 48. Cara menjalankan NestJS dalam mode production menggunakan npm run start:prod

## Definisi & Target
Mode production menjalankan aplikasi dari folder `dist/` (hasil build) tanpa TypeScript compiler. Lebih cepat dan ringan karena hanya menjalankan JavaScript murni.

## Komponen & Nest CLI Command
`npm run build` lalu `npm run start:prod`.

## Kode Implementasi (Per File)

```json
// package.json — script production
{
  "scripts": {
    "build": "nest build",
    "start:prod": "node dist/main",
    "prebuild": "rimraf dist"
  }
}
```

Langkah menjalankan production:
```bash
# 1. Build aplikasi — hasil di folder dist/
npm run build

# 2. Jalankan dari folder dist/
npm run start:prod

# Atau langsung:
nest build && node dist/main
```

## Cara Integrasi & Pengujian
Pastikan tidak ada error saat `npm run build`. Hasil build ada di folder `dist/`. Jalankan `npm run start:prod` dan akses `http://localhost:3000`. Mode production tidak memiliki watch — jika ada perubahan kode, harus build ulang dan restart manual.
