# 44. Memahami kegunaan file app.module.ts sebagai root module

## Definisi & Target
`app.module.ts` adalah root module (module utama) yang menjadi entry point bagi NestJS untuk membangun dependency graph. Semua module lain harus diimpor oleh root module agar dikenali aplikasi.

## Komponen & Nest CLI Command
Tidak ada perintah CLI. File sudah ada sejak `nest new`.

## Kode Implementasi (Per File)

```typescript
// src/app.module.ts

import { Module } from '@nestjs/common';
import { AppController } from './app.controller';
import { AppService } from './app.service';

@Module({
  imports: [],         // Module lain diimpor di sini
  controllers: [AppController],
  providers: [AppService],
})
export class AppModule {}
```

Saat menambah module fitur baru:
```typescript
// src/app.module.ts — setelah menambah ProductsModule

@Module({
  imports: [
    ProductsModule,   // Import module fitur
    UsersModule,      // Import module fitur lain
  ],
  controllers: [AppController],
  providers: [AppService],
})
export class AppModule {}
```

## Cara Integrasi & Pengujian
Root module adalah tempat semua module fitur di-import. Jangan taruh controller atau service bisnis di root module — buat module terpisah untuk setiap fitur. Root module hanya untuk konfigurasi global aplikasi.
