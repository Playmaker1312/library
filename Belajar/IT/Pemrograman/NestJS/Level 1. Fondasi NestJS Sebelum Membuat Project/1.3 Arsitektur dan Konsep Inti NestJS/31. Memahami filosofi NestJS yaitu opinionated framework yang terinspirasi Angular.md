# 31. Memahami filosofi NestJS yaitu opinionated framework yang terinspirasi Angular

## Definisi & Target
NestJS adalah framework Node.js opinionated (memiliki cara kerja yang sudah ditentukan) yang terinspirasi oleh Angular. Artinya, NestJS mendorong pengguna untuk mengikuti pola arsitektur tertentu — modular, decorator-based, dan dependency injection — untuk menjaga konsistensi dan scalability.

## Komponen & Nest CLI Command
Tidak ada perintah spesifik. Ini adalah konsep arsitektural.

## Kode Implementasi (Per File)

```typescript
// Inspirasi Angular di NestJS:

// 1. Modules — sama seperti Angular
// Angular: @NgModule({ declarations: [...], imports: [...] })
// NestJS:  @Module({ controllers: [...], providers: [...] })

// 2. Decorators — fondasi utama kedua framework
// Angular: @Component(), @Injectable(), @Directive()
// NestJS:  @Controller(), @Injectable(), @Module()

// 3. Dependency Injection — mirip dengan Angular
// Angular: constructor(private http: HttpClient)
// NestJS:  constructor(private productService: ProductService)

// 4. Lifecycle hooks — terinspirasi dari Angular lifecycle
// Angular: ngOnInit(), ngOnDestroy()
// NestJS:  OnModuleInit(), OnApplicationBootstrap()
```

## Cara Integrasi & Pengujian
Pahami bahwa NestJS "opinionated" berarti ada satu cara yang direkomendasikan untuk melakukan sesuatu. Ini berbeda dengan Express yang bebas (unopinionated). Dengan mengikuti pola NestJS, project akan lebih terstruktur, testable, dan mudah dipelihara — terutama untuk tim besar.
