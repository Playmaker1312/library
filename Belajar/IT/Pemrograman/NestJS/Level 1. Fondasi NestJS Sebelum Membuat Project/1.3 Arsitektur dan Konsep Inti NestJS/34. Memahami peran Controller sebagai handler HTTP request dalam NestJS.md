# 34. Memahami peran Controller sebagai handler HTTP request dalam NestJS

## Definisi & Target
Controller adalah layer pertama yang menerima HTTP request dan mengembalikan response. Controller tidak berisi logika bisnis — tugasnya hanya menerima request, memanggil service, dan mengembalikan response.

## Komponen & Nest CLI Command
`nest g controller <nama>` — membuat controller baru.

## Kode Implementasi (Per File)

```typescript
// src/products/products.controller.ts

import { Controller, Get, Post, Body, Param } from '@nestjs/common';
import { ProductsService } from './products.service';

@Controller('products')
export class ProductsController {
  constructor(private readonly productsService: ProductsService) {}

  @Get()
  async findAll() {
    return this.productsService.findAll();
  }

  @Get(':id')
  async findOne(@Param('id') id: string) {
    return this.productsService.findById(+id);
  }

  @Post()
  async create(@Body() createProductDto: any) {
    return this.productsService.create(createProductDto);
  }
}
```

## Cara Integrasi & Pengujian
Jalankan `nest g controller products` untuk generate controller. Decorator `@Controller('products')` menentukan prefix route `products`. Method `@Get()`, `@Post()`, dll menentukan HTTP method. Controller hanya memanggil service — jangan taruh logika bisnis di sini.
