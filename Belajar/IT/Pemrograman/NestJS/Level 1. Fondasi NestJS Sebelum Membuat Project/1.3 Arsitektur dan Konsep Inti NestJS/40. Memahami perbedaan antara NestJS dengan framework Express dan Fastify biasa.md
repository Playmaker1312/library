# 40. Memahami perbedaan antara NestJS dengan framework Express dan Fastify biasa

## Definisi & Target
Express dan Fastify adalah framework HTTP minimalis (unopinionated), sedangkan NestJS adalah framework opinionated yang dibangun di atas keduanya. NestJS menyediakan arsitektur modular, DI, decorators, dan berbagai abstraksi yang tidak dimiliki Express/Fastify.

## Komponen & Nest CLI Command
Tidak ada perintah CLI. Konsep perbandingan arsitektur.

```typescript
/*
| Aspek          | Express/Fastify            | NestJS                              |
|---------------|----------------------------|-------------------------------------|
| Architecture  | Bebas (unopinionated)      | Terstruktur (opinionated)           |
| Modular       | Tidak ada konsep module    | Module, Controller, Service         |
| Decorators    | Tidak ada                  | @Controller, @Get, @Injectable      |
| DI            | Manual atau library lain   | Built-in DI container               |
| Middleware    | Manual (app.use)           | Guards, Interceptors, Pipes, Filters |
| TypeScript    | Opsional                   | Wajib                               |
| Testing       | Manual setup               | Testing module bawaan               |
| HTTP Engine   | Express/Fastify langsung   | Platform-agnostic (bisa ganti)      |
*/
```

## Cara Integrasi & Pengujian
NestJS menggunakan Express secara default (atau Fastify dengan `npm install @nestjs/platform-fastify`). Keuntungan NestJS: kamu bisa mengganti HTTP engine tanpa mengubah kode aplikasi. Pilih NestJS untuk project besar/tim; pilih Express untuk API sederhana/solo.
