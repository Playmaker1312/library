# 35. Memahami peran Provider dan Service sebagai business logic dalam NestJS

## Definisi & Target
Provider (termasuk Service) adalah class yang berisi logika bisnis aplikasi. Service didekorasi dengan `@Injectable()` dan di-inject ke controller atau service lain melalui constructor. Service adalah tempat untuk memproses data, berinteraksi dengan database, dan memanggil API eksternal.

## Komponen & Nest CLI Command
`nest g service <nama>` — membuat service baru.

## Kode Implementasi (Per File)

```typescript
// src/products/products.service.ts

import { Injectable } from '@nestjs/common';

@Injectable()
export class ProductsService {
  private products: any[] = [];

  async findAll() {
    return this.products;
  }

  async findById(id: number) {
    return this.products.find(p => p.id === id) ?? null;
  }

  async create(data: any) {
    const newProduct = { id: this.products.length + 1, ...data };
    this.products.push(newProduct);
    return newProduct;
  }

  async update(id: number, data: any) {
    const index = this.products.findIndex(p => p.id === id);
    if (index === -1) return null;
    this.products[index] = { ...this.products[index], ...data };
    return this.products[index];
  }

  async delete(id: number) {
    const index = this.products.findIndex(p => p.id === id);
    if (index === -1) return false;
    this.products.splice(index, 1);
    return true;
  }
}
```

## Cara Integrasi & Pengujian
Service harus selalu menggunakan `@Injectable()` agar bisa di-inject. Logika bisnis (validasi, transformasi, kalkulasi) dilakukan di sini, bukan di controller. Service juga bisa meng-inject service lain atau repository untuk akses database.
