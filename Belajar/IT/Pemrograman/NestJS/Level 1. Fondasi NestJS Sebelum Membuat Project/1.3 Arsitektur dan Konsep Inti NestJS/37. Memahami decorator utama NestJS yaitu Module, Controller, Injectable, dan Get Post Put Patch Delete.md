# 37. Memahami decorator utama NestJS yaitu Module, Controller, Injectable, dan Get Post Put Patch Delete

## Definisi & Target
Decorators adalah inti dari NestJS. Decorator class mengubah class menjadi komponen NestJS (module, controller, provider), sedangkan decorator method menentukan HTTP method dan route. Targetnya adalah menguasai decorator utama yang dipakai setiap hari.

## Komponen & Nest CLI Command
Tidak ada perintah CLI. Decorators dipakai di file yang sudah digenerate.

## Kode Implementasi (Per File)

```typescript
// src/items/items.controller.ts

import {
  Controller, Get, Post, Put, Patch, Delete,
  Injectable, Module,
} from '@nestjs/common';

@Injectable()
export class ItemsService {
  private items: any[] = [];
  findAll() { return this.items; }
}

@Controller('items')
export class ItemsController {
  constructor(private readonly service: ItemsService) {}

  @Get()        findAll()   { return this.service.findAll(); }
  @Post()       create()    { return 'created'; }
  @Put(':id')   update()    { return 'updated'; }
  @Patch(':id') partial()   { return 'patched'; }
  @Delete(':id') remove()   { return 'deleted'; }
}

@Module({
  controllers: [ItemsController],
  providers: [ItemsService],
})
export class ItemsModule {}
```

| Decorator | Target | Fungsi |
|-----------|--------|--------|
| `@Module()` | Class | Mendefinisikan module |
| `@Controller()` | Class | Mendefinisikan controller |
| `@Injectable()` | Class | Mendefinisikan provider/service |
| `@Get()` | Method | HTTP GET handler |
| `@Post()` | Method | HTTP POST handler |
| `@Put()` | Method | HTTP PUT handler |
| `@Patch()` | Method | HTTP PATCH handler |
| `@Delete()` | Method | HTTP DELETE handler |

## Cara Integrasi & Pengujian
Decorator adalah fondasi NestJS. Hafalkan kelima decorator HTTP method dan tiga decorator class utama. Semua kode NestJS dimulai dengan decorator ini.
