# 33. Memahami peran Module sebagai unit organisasi kode dalam NestJS

## Definisi & Target
Module adalah unit organisasi utama dalam NestJS yang mengelompokkan controller, service, dan provider terkait. Module didekorasi dengan `@Module()` dan bisa mengimpor module lain serta mengekspor provider untuk digunakan module lain.

## Komponen & Nest CLI Command
`nest g module <nama>` — membuat module baru.

## Kode Implementasi (Per File)

```typescript
// src/products/products.module.ts

import { Module } from '@nestjs/common';
import { ProductsController } from './products.controller';
import { ProductsService } from './products.service';

@Module({
  imports: [],       // Module lain yang dibutuhkan
  controllers: [ProductsController],  // Controller dalam module ini
  providers: [ProductsService],       // Service/provider dalam module ini
  exports: [ProductsService],         // Service yang bisa dipakai module lain
})
export class ProductsModule {}
```

Properti `@Module()`:
| Properti | Fungsi |
|----------|--------|
| `imports` | Daftar module yang diimpor |
| `controllers` | Controller yang terdaftar di module ini |
| `providers` | Service, repository, factory yang terdaftar |
| `exports` | Provider yang bisa digunakan module lain |

## Cara Integrasi & Pengujian
Setiap fitur bisnis sebaiknya memiliki module sendiri. Module root (`AppModule`) mengimpor semua module lain. Dengan CLI, cukup jalankan `nest g module products` dan file `products.module.ts` akan terbuat otomatis.
