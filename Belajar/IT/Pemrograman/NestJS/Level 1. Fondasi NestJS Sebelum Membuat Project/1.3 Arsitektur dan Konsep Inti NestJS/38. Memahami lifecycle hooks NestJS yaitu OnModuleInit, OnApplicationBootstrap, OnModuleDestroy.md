# 38. Memahami lifecycle hooks NestJS yaitu OnModuleInit, OnApplicationBootstrap, OnModuleDestroy

## Definisi & Target
Lifecycle hooks adalah method yang dipanggil NestJS secara otomatis pada tahap tertentu dalam siklus hidup aplikasi. Berguna untuk inisialisasi koneksi, seed data, atau cleanup saat aplikasi mati.

## Komponen & Nest CLI Command
Tidak ada perintah CLI. Implementasi interface di service/provider.

## Kode Implementasi (Per File)

```typescript
// src/seeds/seed.service.ts

import { Injectable, OnModuleInit, OnModuleDestroy, OnApplicationBootstrap } from '@nestjs/common';

@Injectable()
export class SeedService implements OnModuleInit, OnApplicationBootstrap, OnModuleDestroy {
  async onModuleInit() {
    // Dipanggil setelah module diinisialisasi
    // Cocok untuk: koneksi database, load konfigurasi
    console.log('SeedService initialized');
    await this.seedInitialData();
  }

  async onApplicationBootstrap() {
    // Dipanggil setelah semua module siap
    // Cocok untuk: start server tambahan, cron job
    console.log('Application fully started');
  }

  async onModuleDestroy() {
    // Dipanggil saat aplikasi dimatikan (graceful shutdown)
    // Cocok untuk: cleanup, tutup koneksi
    console.log('Cleaning up resources');
  }

  private async seedInitialData() {
    // Logika seed data awal
  }
}
```

| Hook | Waktu Panggil | Use Case |
|------|--------------|----------|
| `onModuleInit()` | Setelah module di-load | Inisialisasi koneksi |
| `onApplicationBootstrap()` | Semua module siap | Start secondary services |
| `onModuleDestroy()` | Graceful shutdown | Cleanup resources |

## Cara Integrasi & Pengujian
Implementasikan interface yang sesuai di service. NestJS akan mendeteksi dan memanggil method tersebut secara otomatis. Untuk graceful shutdown, pastikan `app.enableShutdownHooks()` dipanggil di `main.ts`.
