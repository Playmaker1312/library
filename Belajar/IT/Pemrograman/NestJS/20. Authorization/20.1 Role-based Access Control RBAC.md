# 20. Authorization
## 20.1 Role-based Access Control RBAC
**Definisi Singkat:** RBAC adalah model otorisasi di mana akses diberikan berdasarkan peran (role) user seperti admin, user, atau moderator. NestJS mengimplementasikannya dengan Guard + Custom Decorator.

**Analogi:** RBAC seperti level akses di game — user biasa bisa main di stage 1-5, moderator bisa edit level, admin bisa hapus game dan ban pemain.

**Poin-Poin Penting:**
- **Role** — Atribut user: `admin`, `user`, `moderator`, `superadmin`
- **Guard** — `RolesGuard` membaca role dari request user
- **Custom decorator** — `@Roles('admin')` untuk menandai endpoint
- **`Reflector`** — Membaca metadata decorator di guard

**Contoh Kode:**
```typescript
// enums/role.enum.ts
export enum Role {
  USER = 'user',
  MODERATOR = 'moderator',
  ADMIN = 'admin',
}

// decorators/roles.decorator.ts
import { SetMetadata } from '@nestjs/common';
import { Role } from '../enums/role.enum';

export const ROLES_KEY = 'roles';
export const Roles = (...roles: Role[]) => SetMetadata(ROLES_KEY, roles);
```

**Kasus Penggunaan Nyata:** Aplikasi CMS — role `admin` bisa create/edit/delete semua konten, `moderator` hanya bisa edit, `user` hanya bisa baca.
