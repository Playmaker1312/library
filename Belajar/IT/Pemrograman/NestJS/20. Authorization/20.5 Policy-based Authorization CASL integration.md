# 20. Authorization
## 20.5 Policy-based Authorization CASL integration
**Definisi Singkat:** CASL (CASL.js) adalah library authorization universal yang menggunakan policy/ability — object yang mendefinisikan "siapa bisa ngapain terhadap resource apa" secara deklaratif.

**Analogi:** CASL seperti buku aturan perusahaan — tertulis "Admin bisa hapus produk apapun", "User hanya bisa edit produk milik sendiri". Setiap aksi dicek ke buku aturan ini.

**Poin-Poin Penting:**
- **`AbilityBuilder`** — Mendefinisikan ability untuk user
- **`defineAbility()`** — Buat ability berdasarkan role/claims
- **`ability.can(action, subject)`** — Cek izin di service
- **`@casl/ability`** — Package CASL untuk NestJS
- **Policy-based** — Aturan kompleks: kondisi, field, owned resource

**Contoh Kode:**
```typescript
// abilities/app.ability.ts
import { AbilityBuilder, Ability, AbilityClass, ExtractSubjectType } from '@casl/ability';
import { Injectable } from '@nestjs/common';
import { User, Post } from '@prisma/client';

type AppActions = 'create' | 'read' | 'update' | 'delete';
type AppSubjects = User | Post | 'all';

export type AppAbility = Ability<[AppActions, AppSubjects]>;
export const AppAbility = Ability as AbilityClass<AppAbility>;

@Injectable()
export class CaslAbilityFactory {
  createForUser(user: User) {
    const { can, cannot, build } = new AbilityBuilder(AppAbility);

    if (user.role === 'admin') {
      can('create', 'all');
      can('read', 'all');
      can('update', 'all');
      can('delete', 'all');
    } else {
      can('read', 'all');
      can('create', Post);
      can('update', Post, { authorId: user.id }); // Hanya milik sendiri
      can('delete', Post, { authorId: user.id });
      cannot('delete', User);
    }

    return build({
      detectSubjectType: (item) => item.constructor.name as ExtractSubjectType<AppSubjects>,
    });
  }
}

// post.service.ts — Cek ability di service
import { Injectable, ForbiddenException } from '@nestjs/common';
import { CaslAbilityFactory } from '../abilities/app.ability';

@Injectable()
export class PostService {
  constructor(private caslAbilityFactory: CaslAbilityFactory) {}

  async deletePost(user: User, postId: number) {
    const ability = this.caslAbilityFactory.createForUser(user);
    const post = await this.prisma.post.findUnique({ where: { id: postId } });

    if (!ability.can('delete', post)) {
      throw new ForbiddenException('You can only delete your own posts');
    }

    return this.prisma.post.delete({ where: { id: postId } });
  }
}
```

**Kasus Penggunaan Nyata:** Blog platform — admin bisa hapus post apapun, user biasa hanya bisa hapus post milik sendiri. Dicek via CASL ability di service layer.
