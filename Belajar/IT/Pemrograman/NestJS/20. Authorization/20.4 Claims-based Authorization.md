# 20. Authorization
## 20.4 Claims-based Authorization
**Definisi Singkat:** Claims-based authorization menggunakan klaim (claims) spesifik seperti `can:delete:user` atau `can:approve:order`, bukan role general. Lebih granular daripada RBAC.

**Analogi:** Claims seperti daftar izin kerja — bukan hanya "Manager", tapi "boleh akses laporan keuangan", "boleh approve cuti", "boleh edit data karyawan". Setiap izin spesifik.

**Poin-Poin Penting:**
- **Claims** — Key-value pair: `{ subject: 'user', action: 'delete' }`
- **Granular** — Lebih detail dari role-based
- **Custom guard** — Guard membaca claims dari user atau token
- **Flexibility** — Bisa kombinasi: role + claims

**Contoh Kode:**
```typescript
// decorators/claims.decorator.ts
import { SetMetadata } from '@nestjs/common';

export const CLAIMS_KEY = 'claims';
export const Claims = (...claims: string[]) => SetMetadata(CLAIMS_KEY, claims);

// guards/claims.guard.ts
import { Injectable, CanActivate, ExecutionContext, ForbiddenException } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { CLAIMS_KEY } from '../decorators/claims.decorator';

@Injectable()
export class ClaimsGuard implements CanActivate {
  constructor(private reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    const requiredClaims = this.reflector.getAllAndOverride<string[]>(CLAIMS_KEY, [
      context.getHandler(),
      context.getClass(),
    ]);

    if (!requiredClaims) return true;

    const { user } = context.switchToHttp().getRequest();
    const userClaims = user.claims || [];

    const hasClaims = requiredClaims.every((claim) => userClaims.includes(claim));

    if (!hasClaims) {
      throw new ForbiddenException('Missing required permissions');
    }

    return true;
  }
}

// invoice.controller.ts — Penggunaan claims
import { Controller, Post, UseGuards } from '@nestjs/common';
import { JwtAuthGuard } from '../auth/guards/jwt-auth.guard';
import { ClaimsGuard } from '../auth/guards/claims.guard';
import { Claims } from '../auth/decorators/claims.decorator';

@Controller('invoices')
@UseGuards(JwtAuthGuard, ClaimsGuard)
export class InvoiceController {
  @Post('approve')
  @Claims('invoice:approve')
  approveInvoice() {
    return { message: 'Invoice approved' };
  }
}
```

**Kasus Penggunaan Nyata:** Aplikasi finance — user A punya claim `invoice:read` dan `invoice:approve`, user B hanya `invoice:read`. User B tidak bisa approve invoice.
