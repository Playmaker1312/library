# 2. TypeScript Wajib

## 2.3. Interface dan Type Alias

**Definisi Singkat:** Interface (`interface`) mendefinisikan kontrak bentuk suatu object. Type Alias (`type`) bisa untuk object, union, tuple, dan tipe kompleks lainnya.

**Analogi:** Interface seperti cetakan kue — bentuknya pasti, bisa diperluas dengan cetakan lain. Type seperti resep — bisa kombinasi berbagai bahan (union, intersection).

**Poin-Poin Penting:**
- Interface bisa di-extend/di-merge (declaration merging)
- Type alias tidak bisa di-merge; bisa untuk union/intersection/primitive
- Interface lebih disukai untuk object shapes di NestJS
- `readonly` modifier untuk properti immutable
- Optional properties dengan `?`

**Contoh Kode:**
```typescript
// Interface — kontrak object
interface User {
  readonly id: number;
  email: string;
  name?: string; // optional
}

interface Admin extends User {
  role: 'admin' | 'superadmin';
  permissions: string[];
}

// Type Alias — untuk union dan complex types
type Status = 'active' | 'inactive' | 'pending';
type ApiResult<T> = { success: true; data: T } | { success: false; error: string };
type StringOrNumber = string | number;

// Implementasi di NestJS
interface CreateUserDto {
  email: string;
  password: string;
  name?: string;
}

interface UserResponse {
  id: number;
  email: string;
  createdAt: Date;
}

@Injectable()
export class UsersService {
  async create(dto: CreateUserDto): Promise<UserResponse> {
    // Implementasi
    return { id: 1, email: dto.email, createdAt: new Date() };
  }
}
```

**Kasus Penggunaan Nyata:**
Interface dipakai setiap saat di NestJS untuk: DTOs, response objects, service method contracts, entity definitions, dan configuration shapes. Pilih interface untuk object, type untuk union/utility.
