## 2.1 Mengapa TypeScript — Static Typing

### Definisi Singkat

**Static Typing** adalah fitur di mana tipe data dari sebuah variabel (seperti string, number, atau boolean) diperiksa pada saat kode ditulis atau dikompilasi, bukan saat kode dijalankan. Ini memungkinkan pendeteksian kesalahan (_error_) jauh sebelum aplikasi sampai ke tangan pengguna.

### Analogi

Bayangkan kamu sedang membangun sebuah **Jalur Kereta Api**:

- **JavaScript (Dynamic Typing)**: Seperti memasang rel sambil kereta sedang melaju kencang. Kamu baru sadar ada rel yang putus atau salah ukuran setelah keretanya anjlok/kecelakaan (**Runtime Error**).
    
- **TypeScript (Static Typing)**: Seperti memiliki sistem **Blueprint Digital** dan inspektur bangunan. Jika kamu mencoba memasang baut yang ukurannya salah pada rel, sistem akan berbunyi "Bip!" dan menolak pemasangan itu sebelum keretanya mulai jalan (**Compile-time Error**).
    

### Poin-Poin Penting

- **Predictability:** Kamu tahu pasti apa isi dari sebuah variabel. Jika sebuah fungsi butuh angka, kamu tidak bisa memasukkan teks secara tidak sengaja.
    
- **Self-Documenting:** Kode jadi lebih mudah dibaca karena tipe datanya tertulis jelas. Orang lain (atau kamu di masa depan) tidak perlu menebak-nebak isi sebuah variabel.
    
- **Auto-Completion (IntelliSense):** Karena editor (seperti VS Code) tahu tipe datanya, dia bisa memberikan saran otomatis yang sangat akurat tentang fungsi atau properti apa yang tersedia.
    
- **Refactoring Aman:** Jika kamu mengubah nama properti di satu tempat, TypeScript akan menunjukkan semua tempat lain yang rusak akibat perubahan tersebut.
    

### Contoh Implementasi

**JavaScript (Beresiko):**

JavaScript

```
function tambahGaji(gaji, bonus) {
    return gaji + bonus;
}

// Tidak ada error saat menulis kode, tapi hasilnya kacau saat dijalankan
console.log(tambahGaji(5000, "1000")); // Output: "50001000" (String concatenation)
```

**TypeScript (Aman):**

TypeScript

```
function tambahGaji(gaji: number, bonus: number): number {
    return gaji + bonus;
}

// Editor akan langsung memberikan garis merah (error) sebelum kode dijalankan
// tambahGaji(5000, "1000"); // Error: Argument of type 'string' is not assignable to parameter of type 'number'.
```

### Koneksi dengan Web Development (NestJS)

Dalam ekosistem **NestJS**, Static Typing sangat krusial karena:

1. **Enterprise Grade:** NestJS didesain untuk aplikasi skala besar. Tanpa tipe data yang jelas, mengelola ribuan file akan menjadi mimpi buruk.
    
2. **DTO (Data Transfer Object):** NestJS menggunakan Class dan Interface untuk mendefinisikan bentuk data yang masuk dari client. Jika data tidak sesuai tipe, NestJS bisa otomatis menolaknya.
    
3. **Dependency Injection:** Sistem "suntik-menyuntik" komponen di NestJS sangat bergantung pada tipe data agar NestJS tahu _class_ mana yang harus dimasukkan ke dalam _constructor_.
