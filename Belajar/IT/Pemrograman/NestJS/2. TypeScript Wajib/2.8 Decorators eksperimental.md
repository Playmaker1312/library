# 2. TypeScript Wajib

## 2.8. Decorators (Eksperimental)

**Definisi Singkat:** Decorators adalah fungsi khusus yang memodifikasi class, method, property, atau parameter. NestJS sangat bergantung pada decorators untuk mendefinisikan module, controller, dan injectable.

**Analogi:** Seperti stempel pada dokumen — Anda menambahkan informasi (metadata) tanpa mengubah isi dokumen. Stempel bisa di kelas (class decorator), paragraf (method), atau kata (parameter).

**Poin-Poin Penting:**
- `@Injectable()`, `@Controller()`, `@Module()` adalah decorators NestJS
- Class decorator — menerima constructor function
- Method decorator — menerima target, propertyKey, descriptor
- Parameter decorator — menerima target, propertyKey, parameterIndex
- `@nestjs/common` menyediakan decorators built-in
- Custom decorator bisa dibuat dengan `SetMetadata` atau `createParamDecorator`

**Contoh Kode:**
```typescript
import { Injectable, Controller, Get, Post, Param, Body } from '@nestjs/common';

// Decorator class — membuat class menjadi provider
@Injectable()
export class LoggerService {
  log(message: string): void {
    console.log(`[${new Date().toISOString()}] ${message}`);
  }
}

// Decorator class + method — endpoint definitions
@Controller('products')
export class ProductsController {
  constructor(private readonly logger: LoggerService) {}

  @Get()
  findAll(): string {
    this.logger.log('Fetching all products');
    return 'List of products';
  }

  @Get(':id')
  findOne(@Param('id') id: string): string {
    return `Product ${id}`;
  }

  @Post()
  create(@Body() createDto: Record<string, unknown>): string {
    return 'Product created';
  }
}

@Module({
  controllers: [ProductsController],
  providers: [LoggerService],
})
export class ProductsModule {}
```

**Kasus Penggunaan Nyata:**
Semua aspek NestJS menggunakan decorators: routing (`@Get`, `@Post`), parameter extraction (`@Body`, `@Param`), DI (`@Injectable`), validation (`@UsePipes`), auth (`@UseGuards`), metadata (`@SetMetadata`).
