# 2. TypeScript Wajib

## 2.9. Abstract Class dan Access Modifiers

**Definisi Singkat:** Abstract class adalah class yang tidak bisa di-instantiate langsung, berfungsi sebagai base class dengan method abstract (tanpa body). Access modifiers (`public`, `private`, `protected`) mengontrol visibilitas anggota class.

**Analogi:** Abstract class seperti blueprint mobil — Anda tidak bisa "mengendarai" blueprint, tapi semua mobil nyata dibuat dari blueprint itu. Access modifiers seperti area di rumah — public (ruang tamu), private (kamar tidur), protected (halaman belakang).

**Poin-Poin Penting:**
- `abstract class` — tidak bisa `new`, bisa punya method abstract dan konkret
- `abstract method` — dipaksa diimplementasikan di subclass
- `public` — bisa diakses dari mana saja (default)
- `private` — hanya dalam class yang sama
- `protected` — dalam class dan subclass
- `readonly` — hanya bisa di-assign sekali (di constructor/inisialisasi)

**Contoh Kode:**
```typescript
// Abstract class sebagai base service
export abstract class BaseRepository<T> {
  protected abstract tableName: string;

  async findAll(): Promise<T[]> {
    return this.query(`SELECT * FROM ${this.tableName}`);
  }

  async findById(id: number): Promise<T | null> {
    const results = await this.query(`SELECT * FROM ${this.tableName} WHERE id = $1`, [id]);
    return results[0] ?? null;
  }

  protected abstract query(sql: string, params?: unknown[]): Promise<T[]>;
}

// Implementasi konkret
@Injectable()
export class UserRepository extends BaseRepository<User> {
  protected readonly tableName = 'users';
  private readonly cacheKey = 'users:all';

  async findByEmail(email: string): Promise<User | null> {
    const results = await this.query('SELECT * FROM users WHERE email = $1', [email]);
    return results[0] ?? null;
  }

  protected async query(sql: string, params?: unknown[]): Promise<User[]> {
    // Implementasi query ke database
    return [];
  }
}
```

**Kasus Penggunaan Nyata:**
Abstract class untuk base service/repository pattern di NestJS, access modifiers melindungi internal implementation, `private` untuk helper methods, `protected` untuk methods yang di-share ke subclass.
