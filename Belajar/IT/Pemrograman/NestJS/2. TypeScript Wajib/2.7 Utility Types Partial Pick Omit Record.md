# 2. TypeScript Wajib

## 2.7. Utility Types: `Partial`, `Pick`, `Omit`, `Record`

**Definisi Singkat:** Utility types adalah generic types bawaan TypeScript untuk transformasi tipe umum. `Partial` membuat semua properti optional, `Pick` memilih subset, `Omit` mengecualikan, `Record` membuat object dengan key-value tertentu.

**Analogi:** Seperti cetakan kue dengan fitur: Partial = cetakan yang bisa dilepas bagiannya, Pick = ambil beberapa sisi saja, Omit = buang sisi tertentu, Record = laci dengan label seragam.

**Poin-Poin Penting:**
- `Partial<T>` — semua properti optional
- `Required<T>` — semua properti wajib
- `Pick<T, K>` — ambil subset properti T dengan key K
- `Omit<T, K>` — T tanpa properti K
- `Record<K, V>` — object dengan key K dan value V
- `Readonly<T>` — semua properti readonly

**Contoh Kode:**
```typescript
interface User {
  id: number;
  name: string;
  email: string;
  password: string;
  role: 'admin' | 'user';
}

// Partial — untuk update DTO (semua optional)
type UpdateUserDto = Partial<Omit<User, 'id'>>;

// Pick — untuk response tanpa sensitive fields
type UserResponse = Pick<User, 'id' | 'name' | 'email'>;

// Omit — seperti Pick tapi kebalikan
type PublicUser = Omit<User, 'password'>;

// Record — mapping key-value
type UserRole = 'admin' | 'editor' | 'viewer';
type RolePermissions = Record<UserRole, string[]>;

const permissions: RolePermissions = {
  admin: ['create', 'read', 'update', 'delete'],
  editor: ['read', 'update'],
  viewer: ['read'],
};

// Implementasi di NestJS Service
@Injectable()
export class UsersService {
  async update(id: number, dto: UpdateUserDto): Promise<UserResponse> {
    // dto hanya berisi field yang boleh diupdate
    return { id, name: dto.name!, email: dto.email! };
  }
}
```

**Kasus Penggunaan Nyata:**
`Partial` untuk update DTO, `Pick`/`Omit` untuk response shaping (hide passwords), `Record` untuk mapping config/permissions, `Readonly` untuk constants, `Required` untuk validasi final.
