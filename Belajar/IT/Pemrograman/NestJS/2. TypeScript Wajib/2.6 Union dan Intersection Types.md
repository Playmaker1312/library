# 2. TypeScript Wajib

## 2.6. Union dan Intersection Types

**Definisi Singkat:** Union (`|`) mengizinkan nilai menjadi salah satu dari beberapa tipe. Intersection (`&`) menggabungkan beberapa tipe menjadi satu tipe dengan semua properti.

**Analogi:** Union seperti pintu dengan beberapa kunci — salah satu kunci bisa membuka. Intersection seperti KTP + SIM — Anda memiliki semua informasi dari keduanya.

**Poin-Poin Penting:**
- Union: `typeA | typeB` — nilai bisa typeA ATAU typeB
- Intersection: `typeA & typeB` — nilai harus memiliki SEMUA properti
- Discriminated union — union dengan properti literal (`kind`) untuk narrowing
- Type narrowing dengan `typeof`, `in`, atau switch
- Intersection sering dipakai untuk menggabungkan interface

**Contoh Kode:**
```typescript
// Union — response bisa sukses atau error
type ApiResult<T> =
  | { status: 'success'; data: T }
  | { status: 'error'; message: string; code: number };

// Intersection — menggabungkan entity dengan metadata
interface BaseEntity {
  id: number;
  createdAt: Date;
}

interface UserData {
  name: string;
  email: string;
}

type User = BaseEntity & UserData;
// User memiliki: id, createdAt, name, email

// Discriminated union — narrowing otomatis
function handleResult<T>(result: ApiResult<T>): T | never {
  if (result.status === 'success') {
    return result.data; // TypeScript tahu ini success branch
  }
  throw new Error(`${result.code}: ${result.message}`);
}

// Partial + Intersection pattern di NestJS
interface CreateUserDto {
  name: string;
  email: string;
  password: string;
}

type UpdateUserDto = Partial<CreateUserDto> & { id: number };
```

**Kasus Penggunaan Nyata:**
Union untuk `ApiResponse<T>` success/error, nullable types `T | null`, discriminated union untuk event types di CQRS. Intersection untuk combining entity dengan timestamp/metadata, DTO assembly.
