## 2.4 Enum (Enumeration)

### Definisi Singkat

**Enum** adalah tipe data khusus yang memungkinkan kita mendefinisikan sekumpulan konstanta bernama (label) untuk mewakili nilai-nilai tertentu. Daripada menggunakan angka atau string manual yang tersebar di mana-mana, kita menggunakan nama yang deskriptif.

### Analogi

Bayangkan sebuah **Sakelar Lampu**:

- **Tanpa Enum**: Kamu harus ingat bahwa angka `0` artinya MATI, `1` artinya NYALA, dan `2` artinya REDUP. Jika kamu salah tulis angka `3`, sistem akan bingung.
    
- **Dengan Enum**: Kamu membuat label resmi: `StatusLampu.MATI`, `StatusLampu.NYALA`. Kamu tidak perlu lagi menghafal angka di baliknya; kamu cukup memilih label yang sudah tersedia.
    

### Poin-Poin Penting

- **Numeric Enum**: Secara default, Enum menyimpan nilai angka mulai dari `0, 1, 2...` dan seterusnya.
    
- **String Enum**: Kamu bisa memberikan nilai string secara eksplisit. Ini lebih populer di web development karena saat di-_debug_, nilainya lebih mudah dibaca daripada sekadar angka.
    
- **Type Safety**: Jika sebuah fungsi membutuhkan tipe Enum tertentu, kamu tidak bisa memasukkan string sembarangan di luar daftar Enum tersebut.
    
- **Auto-completion**: Editor akan memberikan saran otomatis saat kamu mengetik nama Enum, sehingga mempercepat proses coding.
    

### Contoh Implementasi

TypeScript

```
// --- 1. String Enum (Paling sering digunakan di NestJS) ---
enum UserRole {
  ADMIN = 'ADMIN',
  EDITOR = 'EDITOR',
  USER = 'USER',
}

// Penggunaan pada Object
interface User {
  username: string;
  role: UserRole; // Menggunakan tipe Enum
}

const userBaru: User = {
  username: 'gemini_dev',
  role: UserRole.ADMIN // Sangat jelas dan aman dari typo
};

// --- 2. Pengecekan Kondisi ---
if (userBaru.role === UserRole.ADMIN) {
  console.log("Akses diberikan ke dashboard admin.");
}
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, Enum adalah "sahabat terbaik" saat menangani:

1. **Database Seeding & Schema**: Menentukan kolom "Role" atau "Status" di database (misal menggunakan TypeORM) agar nilainya konsisten (misal: 'PENDING', 'SUCCESS', 'FAILED').
    
2. **Validation Pipe**: NestJS memiliki decorator `@IsEnum()` yang secara otomatis menolak _request_ dari client jika nilai yang dikirim tidak sesuai dengan daftar Enum yang kita buat.
    
3. **Swagger Documentation**: Jika kamu menggunakan Swagger untuk dokumentasi API, Enum akan otomatis ditampilkan sebagai pilihan _dropdown_ yang tersedia bagi pengguna API kamu.
