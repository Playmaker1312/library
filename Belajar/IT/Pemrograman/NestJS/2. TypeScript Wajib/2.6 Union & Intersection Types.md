## 2.6 Union (`|`) & Intersection (`&`) Types

### Definisi Singkat

**Union Types** memungkinkan sebuah variabel memiliki salah satu dari beberapa tipe data yang ditentukan (logika "ATAU"). **Intersection Types** menggabungkan beberapa tipe data menjadi satu tipe baru yang memiliki semua properti dari tipe-tipe pembentuknya (logika "DAN").

### Analogi

- **Union Types (`|`)**: Bayangkan sebuah **Mesin Penjual Otomatis**. Mesin ini hanya menerima pembayaran dalam bentuk **Koin** `ATAU` **Uang Kertas**. Kamu tidak bisa memasukkan kartu kredit, tapi kamu punya pilihan di antara dua metode yang diizinkan tersebut.
    
- **Intersection Types (`&`)**: Bayangkan sebuah **Smartphone**. Smartphone adalah hasil gabungan dari fungsi **Telepon** `DAN` **Kamera** `DAN` **Komputer**. Produk akhirnya harus memiliki semua fitur dari ketiga benda tersebut agar bisa disebut Smartphone.
    

### Poin-Poin Penting

- **Union (`|`)**:
    
    - Menggunakan simbol pipa/garis tegak.
        
    - Sering digunakan untuk variabel yang nilainya bisa berupa `string` atau `number`.
        
    - Sangat berguna untuk membatasi nilai string tertentu (_Literal Types_).
        
- **Intersection (`&`)**:
    
    - Menggunakan simbol ampersand.
        
    - Biasanya digunakan untuk menggabungkan dua `interface` atau `type alias` menjadi satu struktur objek yang lebih besar.
        
    - Wajib memenuhi semua properti yang ada di kedua tipe yang digabungkan.
        

### Contoh Implementasi

TypeScript

```
// --- 1. Union Types ---
type ID = string | number;

function printId(id: ID) {
    console.log(`ID anda adalah: ${id}`);
}

printId(101);      // OK
printId("ABC-01"); // OK


// --- 2. Intersection Types ---
interface Karyawan {
    nama: string;
    idKaryawan: number;
}

interface AksesAdmin {
    levelAkses: number;
}

// Menggabungkan keduanya
type AdminGudang = Karyawan & AksesAdmin;

const stafBaru: AdminGudang = {
    nama: "Budi",
    idKaryawan: 123,
    levelAkses: 1 // Wajib ada karena hasil gabungan
};
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, konsep ini muncul pada:

1. **API Responses**: Terkadang sebuah fungsi bisa mengembalikan data sukses atau pesan error. Kamu bisa menggunakan Union: `Promise<User | ErrorResponse>`.
    
2. **Configuration**: Menggabungkan tipe konfigurasi dasar dengan konfigurasi spesifik database menggunakan Intersection agar objek konfigurasi memiliki semua properti yang dibutuhkan.
    
3. **Data Transformation**: Saat melakukan _mapping_ data, kamu mungkin menggabungkan data dari dua tabel berbeda (misal: User dan Profile) menjadi satu objek gabungan menggunakan Intersection sebelum dikirim ke Frontend.
