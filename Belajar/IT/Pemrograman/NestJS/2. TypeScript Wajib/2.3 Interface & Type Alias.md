## 2.1 Lanjutan: Tipe Data Khusus (unknown, void, never)

### Definisi Singkat

Tipe data ini digunakan untuk situasi yang tidak biasa: **`unknown`** adalah tipe yang lebih aman dari `any`, **`void`** digunakan untuk fungsi yang tidak menghasilkan nilai, dan **`never`** digunakan untuk fungsi yang tidak pernah mencapai titik akhir.

### Analogi

- **`unknown` (Kotak Misteri yang Terkunci)**: Kamu menerima paket, tapi tidak tahu isinya. Kamu dilarang menggunakannya sampai kamu membukanya dan memeriksa isinya (melakukan pengecekan tipe).
    
- **`void` (Mesin ATM yang Hanya Cetak Resi)**: Kamu memasukkan perintah, mesin memprosesnya, tapi tidak mengeluarkan uang (nilai). Dia hanya melakukan tugasnya lalu selesai.
    
- **`never` (Lubang Hitam)**: Begitu sesuatu masuk ke sana, ia tidak pernah kembali. Ini seperti fungsi yang menyebabkan program berhenti atau meledak (error), sehingga tidak ada jalan keluar.
    

### Poin-Poin Penting

- **`unknown`**:
    
    - Mirip `any`, bisa diisi apa saja.
        
    - **Bedanya**: Kamu tidak bisa memanggil properti atau method dari variabel `unknown` sebelum melakukan _type checking_ (misal dengan `typeof`).
        
    - _Best Practice_: Gunakan ini sebagai pengganti `any` agar kode lebih aman.
        
- **`void`**:
    
    - Hampir selalu digunakan sebagai tipe pengembalian (_return type_) sebuah fungsi.
        
    - Artinya fungsi tersebut menjalankan logika (seperti _logging_ atau simpan data) tapi tidak memberikan hasil untuk diolah lagi.
        
- **`never`**:
    
    - Digunakan untuk fungsi yang selalu melempar _exception_ (`throw Error`) atau memiliki _infinite loop_.
        
    - Artinya, baris kode setelah pemanggilan fungsi `never` tidak akan pernah dieksekusi.
        

### Contoh Implementasi

TypeScript

```
// --- 1. Unknown ---
let dataMasuk: unknown;
dataMasuk = "Halo";

// console.log(dataMasuk.toUpperCase()); // Error! TypeScript tidak yakin ini string.

if (typeof dataMasuk === "string") {
    console.log(dataMasuk.toUpperCase()); // Aman, sudah dicek.
}


// --- 2. Void ---
function logPesan(pesan: string): void {
    console.log("LOG: " + pesan);
    // Tidak ada 'return ...' di sini
}


// --- 3. Never ---
function laporError(pesan: string): never {
    throw new Error(pesan); 
    // Fungsi ini tidak akan pernah selesai (berhenti di throw)
}
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, tipe-tipe ini muncul dalam skenario berikut:

1. **`unknown`**: Saat kamu menerima _payload_ dari API pihak ketiga yang strukturnya tidak menentu. Kamu menandainya sebagai `unknown` lalu memvalidasinya sebelum digunakan.
    
2. **`void`**: Sangat umum digunakan pada method di dalam _Service_ yang tugasnya hanya melakukan aksi, seperti `deleteUser(id: string): void`.
    
3. **`never`**: Sering ditemukan pada _Global Error Handler_ atau fungsi utilitas yang menangani _exception_ kustom di NestJS untuk memastikan alur program berhenti saat terjadi error fatal.
