# 2. TypeScript Wajib

## 2.2. Tipe Data Dasar: `string`, `number`, `boolean`, `array`, `tuple`

**Definisi Singkat:** Tipe data dasar TypeScript mencakup primitives (`string`, `number`, `boolean`), koleksi (`array`, `tuple`), dan tipe spesial (`any`, `void`, `never`).

**Analogi:** Seperti lemari dengan laci khusus — laci piring (string), laci sendok (number), laci catatan (boolean). Setiap barang masuk ke laci yang sesuai.

**Poin-Poin Penting:**
- `string`, `number`, `boolean` — lowercase (bukan `String`, `Number`)
- Array: `type[]` atau `Array<type>` (generics)
- Tuple: array dengan panjang dan tipe tetap per indeks
- `void` untuk function tanpa return
- `never` untuk function yang tidak pernah selesai (throw/loop)
- Hindari `any` — gunakan `unknown` jika tipe belum diketahui

**Contoh Kode:**
```typescript
// Primitives
const name: string = 'NestJS';
const version: number = 10;
const isStable: boolean = true;

// Array
const tags: string[] = ['node', 'typescript', 'backend'];
const ports: Array<number> = [3000, 3001, 4000];

// Tuple — fixed length & types
const route: [string, number] = ['/api/users', 1]; // path, version
const httpResponse: [number, string] = [200, 'OK'];

// Function types
function logError(message: string): void {
  console.error(message);
}

function throwError(message: string): never {
  throw new Error(message);
}

// Union untuk parameter fleksibel
function formatId(id: string | number): string {
  return `ID-${id}`;
}
```

**Kasus Penggunaan Nyata:**
Digunakan di setiap file NestJS: tipe parameter/return service, DTO properties, entity fields, controller parameter type decoration, dan database query results.
