## 2.5 Generics

### Definisi Singkat

**Generics** adalah cara untuk membuat komponen (fungsi, interface, atau class) yang dapat bekerja dengan berbagai jenis tipe data, namun tetap menjaga informasi tipe data tersebut tanpa harus menggunakan `any`.

### Analogi

Bangangkan sebuah **Botol Minuman**:

- **Tanpa Generics**: Kamu punya satu botol khusus hanya untuk air, satu botol khusus untuk susu, dan satu botol khusus untuk jus. Terlalu banyak botol yang fungsinya sebenarnya sama.
    
- **Menggunakan `any`**: Kamu punya satu botol untuk apa saja, tapi kamu kehilangan informasi isinya. Saat mau minum, kamu tidak tahu apakah itu air atau cuka.
    
- **Dengan Generics**: Kamu punya **Botol Template**. Kamu bisa bilang "Ini botol untuk [Tipe Cairan]". Saat kamu mengisinya dengan Susu, botol itu otomatis menjadi "Botol Susu". Kamu tetap punya satu desain botol, tapi kamu tahu persis apa isinya.
    

### Poin-Poin Penting

- **Type Parameter (`<T>`)**: `T` adalah kependekan dari _Type_. Ini adalah variabel untuk tipe data yang akan ditentukan saat komponen tersebut digunakan.
    
- **Reusability**: Memungkinkan kita menulis logika satu kali dan menggunakannya untuk berbagai tipe data (string, number, objek kustom, dll).
    
- **Type Safety**: Berbeda dengan `any`, Generics tidak "mematikan" pengecekan tipe data. TypeScript akan melacak tipe data yang dimasukkan ke dalam Generics tersebut.
    
- **Constraints**: Kita bisa membatasi tipe apa saja yang boleh masuk ke dalam Generics menggunakan kata kunci `extends`.
    

### Contoh Implementasi

TypeScript

```
// --- 1. Fungsi Generic ---
function bungkusDalamArray<T>(item: T): T[] {
    return [item];
}

const angka = bungkusDalamArray<number>(10); // Menjadi number[]
const teks = bungkusDalamArray<string>("NestJS"); // Menjadi string[]


// --- 2. Interface Generic (Sering di NestJS) ---
interface ResponseApi<T> {
    data: T;
    status: number;
    message: string;
}

// Digunakan untuk data User
interface User { name: string; }
const userResponse: ResponseApi<User> = {
    data: { name: "Andi" },
    status: 200,
    message: "Berhasil"
};

// Digunakan untuk data Product
interface Product { title: string; price: number; }
const productResponse: ResponseApi<Product> = {
    data: { title: "Laptop", price: 1500 },
    status: 200,
    message: "Berhasil"
};
```

### Koneksi dengan Web Development (NestJS)

Dalam **NestJS**, Generics adalah "makanan sehari-hari" pada bagian:

1. **Repository Pattern**: Saat kamu bekerja dengan database (TypeORM/Prisma), Repository menggunakan Generics untuk mengetahui entitas apa yang sedang dikelola (misal: `Repository<UserEntity>`).
    
2. **Base Services**: Seringkali pengembang membuat `BaseService<T>` yang berisi fungsi CRUD standar (Create, Read, Update, Delete) sehingga tidak perlu menulis ulang logika yang sama untuk setiap tabel.
    
3. **API Response Wrapper**: Seperti contoh di atas, Generics digunakan untuk membungkus semua response API agar memiliki format yang seragam (misal: selalu ada field `data`, `status`, dan `message`) terlepas dari apa pun isi datanya.
