## 2.8 Decorators (Eksperimental)

### Definisi Singkat

**Decorators** adalah fungsi khusus yang diawali dengan simbol `@` yang ditempelkan pada deklarasi _class_, _method_, _property_, atau _parameter_. Fungsinya adalah untuk mengubah perilaku atau memberikan informasi tambahan (metadata) pada kode tersebut tanpa mengubah logika intinya.

### Analogi

Bayangkan sebuah **Bangunan Apartemen**:

- **Class**: Adalah struktur dasar apartemennya (dinding, lantai, langit-langit).
    
- **Decorators**: Adalah **Stiker Sertifikasi** atau **Papan Penanda** yang ditempel di pintu:
    
    - Stiker `@DilarangMerokok`: Memberi aturan tambahan pada ruangan tersebut.
        
    - Papan `@KamarVIP`: Memberi identitas bahwa ruangan ini punya perlakuan khusus.
        
    - Stiker `@DisewaOleh(Budi)`: Menyimpan informasi (metadata) tentang siapa penghuninya. Stiker ini tidak mengubah bentuk ruangan, tapi mengubah cara orang (sistem) berinteraksi dengan ruangan tersebut.
        

### Poin-Poin Penting

- **Simbol `@`**: Penulisan dekorator selalu diawali dengan `@` tepat di atas target yang ingin "dihias".
    
- **Metadata**: Dekorator sering digunakan untuk menyimpan data yang nantinya akan dibaca oleh _library_ atau _framework_ (dalam hal ini NestJS).
    
- **Jenis-Jenis**:
    
    - **Class Decorators**: Menghias seluruh class (contoh: `@Controller()`, `@Module()`).
        
    - **Method Decorators**: Menghias fungsi di dalam class (contoh: `@Get()`, `@Post()`).
        
    - **Property Decorators**: Menghias variabel di dalam class.
        
    - **Parameter Decorators**: Menghias input fungsi (contoh: `@Body()`, `@Param()`).
        
- **Experimental**: Kamu harus mengaktifkan `experimentalDecorators: true` di file `tsconfig.json` agar fitur ini bisa digunakan.
    

### Contoh Implementasi

TypeScript

```
// Contoh dekorator sederhana buatan sendiri (konseptual)
function Logger(target: any) {
    console.log(`Class ${target.name} telah dibuat!`);
}

@Logger
class UserService {
    // Saat class ini dibaca, dekorator @Logger akan berjalan
}

// Contoh penggunaan dekorator di NestJS
@Controller('users') // Class Decorator: Menandai ini sebagai Controller
export class UserController {
    
    @Get() // Method Decorator: Menandai fungsi ini untuk menangani HTTP GET
    findAll(@Query('role') role: string) { // Parameter Decorator: Mengambil data dari query string
        return `Menampilkan semua user dengan role ${role}`;
    }
}
```

### Koneksi dengan Web Development (NestJS)

Di **NestJS**, kamu tidak bisa hidup tanpa Decorators. Mereka digunakan untuk:

1. **Dependency Injection**: Menggunakan `@Injectable()` agar sebuah class bisa digunakan secara otomatis di class lain.
    
2. **Routing**: Menggunakan `@Get()`, `@Post()`, `@Put()`, dan `@Delete()` untuk menentukan jalur URL API.
    
3. **Validation**: Menggunakan dekorator dari `class-validator` (seperti `@IsEmail()`, `@IsInt()`) untuk memvalidasi data yang masuk dari user secara otomatis.
    
4. **Authorization**: Menggunakan `@UseGuards()` untuk membatasi siapa saja yang boleh mengakses endpoint tertentu (misal: hanya Admin).
