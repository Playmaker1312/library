# 2. TypeScript Wajib

## 2.10. `tsconfig.json` — Konfigurasi Proyek

**Definisi Singkat:** `tsconfig.json` adalah file konfigurasi TypeScript yang menentukan compiler options, file yang termasuk, dan module resolution. NestJS CLI meng-generate file ini secara otomatis.

**Analogi:** Seperti buku panduan assembli — menentukan suku cadang mana yang dipakai, berapa besar mesin, dan bagaimana komponen terhubung. Tanpa ini, pabrik tidak bisa mulai produksi.

**Poin-Poin Penting:**
- `target` — versi JavaScript output (ES2021 untuk NestJS 10)
- `module` — system module (CommonJS atau NodeNext)
- `experimentalDecorators: true` — WAJIB untuk NestJS
- `emitDecoratorMetadata: true` — WAJIB untuk DI NestJS
- `outDir` — folder output compiled JS
- `strict: true` — strict mode type checking
- `paths` — alias path mapping

**Contoh Kode:**
```json
{
  "compilerOptions": {
    "module": "commonjs",
    "declaration": true,
    "removeComments": true,
    "emitDecoratorMetadata": true,
    "experimentalDecorators": true,
    "allowSyntheticDefaultImports": true,
    "target": "ES2021",
    "sourceMap": true,
    "outDir": "./dist",
    "baseUrl": "./",
    "incremental": true,
    "skipLibCheck": true,
    "strictNullChecks": true,
    "noImplicitAny": true,
    "strictBindCallApply": true,
    "forceConsistentCasingInFileNames": true,
    "noFallthroughCasesInSwitch": true,
    "paths": {
      "@/*": ["src/*"]
    }
  },
  "include": ["src/**/*"]
}
```

**Kasus Penggunaan Nyata:**
Setiap project NestJS memiliki `tsconfig.json`. Setting `experimentalDecorators` dan `emitDecoratorMetadata` adalah kunci agar decorator NestJS berfungsi. Path aliases `@/` memudahkan import absolute.
