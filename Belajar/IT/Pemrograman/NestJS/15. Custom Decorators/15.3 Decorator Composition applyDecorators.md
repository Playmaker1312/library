# 15. Custom Decorators

## 15.3. Decorator Composition applyDecorators

**Definisi Singkat:** `applyDecorators` menggabungkan beberapa decorator menjadi satu decorator tunggal untuk mengurangi pengulangan.

**Analogi:** Seperti paket bundling — daripada beli sabun, sampo, sikat gigi terpisah, beli satu paket perlengkapan mandi.

**Poin-Poin Penting:**
- Import `applyDecorators` dari `@nestjs/common`
- Menggabungkan decorator NestJS dan/atau TypeScript
- Mengurangi baris kode di controller
- Meningkatkan readability
- Contoh: gabung `@UseGuards`, `@SetMetadata`, dll

**Contoh Kode:**
```typescript
import { applyDecorators, UseGuards, SetMetadata, Delete } from '@nestjs/common';
import { AuthGuard } from '../guards/auth.guard';
import { RolesGuard } from '../guards/roles.guard';
import { Roles } from './roles.decorator';

// Custom decorator komposit
export function AdminDelete(path: string) {
  return applyDecorators(
    Delete(path),
    UseGuards(AuthGuard, RolesGuard),
    Roles('admin'),
    // Swagger documentation
    // ApiBearerAuth(),
    // ApiOperation({ summary: 'Hapus data (Admin only)' }),
  );
}

// Penggunaan — satu baris, banyak decorator
@Controller('users')
export class UserController {
  @AdminDelete(':id')
  deleteUser(@Param('id') id: string) {
    return this.userService.delete(id);
  }
}
```

**Kasus Penggunaan Nyata:** Setiap endpoint admin yang butuh autentikasi, role check, dan dokumentasi Swagger cukup pakai `@AdminDelete()` — mengurangi 5 baris decorator menjadi 1 baris.
