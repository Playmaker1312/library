# 15. Custom Decorators

## 15.5. Contoh CurrentUser Roles Public

**Definisi Singkat:** Tiga custom decorator paling umum: `@CurrentUser()` untuk user login, `@Roles()` untuk RBAC, dan `@Public()` untuk endpoint publik.

**Analogi:** Seperti tiga stempel berbeda: "PETUGAS" (CurrentUser), "IZIN AKSES" (Roles), "GRATIS" (Public).

**Poin-Poin Penting:**
- `@CurrentUser()` — ambil user dari request, bisa dengan field spesifik
- `@Roles()` — set metadata role untuk RBAC
- `@Public()` — skip autentikasi untuk endpoint tertentu
- Decorator ini sangat sering digunakan di proyek nyata
- Kombinasikan dengan Guard untuk hasil maksimal

**Contoh Kode:**
```typescript
import { createParamDecorator, ExecutionContext, SetMetadata } from '@nestjs/common';

// 1. CurrentUser Decorator
export const CurrentUser = createParamDecorator(
  (data: string, ctx: ExecutionContext) => {
    const request = ctx.switchToHttp().getRequest();
    const user = request.user;
    return data ? user?.[data] : user;
  },
);

// 2. Roles Decorator (untuk RBAC)
export const Roles = (...roles: string[]) => SetMetadata('roles', roles);

// 3. Public Decorator (skip auth)
export const IS_PUBLIC_KEY = 'isPublic';
export const Public = () => SetMetadata(IS_PUBLIC_KEY, true);

// Penggunaan lengkap
@Controller('users')
export class UserController {
  @Public() // Tidak perlu autentikasi
  @Post('register')
  register(@Body() dto: RegisterDto) { }

  @Roles('admin') // Hanya admin
  @UseGuards(RolesGuard)
  @Delete(':id')
  deleteUser(@Param('id') id: string) { }

  @Get('profile')
  getProfile(@CurrentUser() user: User) {
    return user;
  }

  @Get('email')
  getEmail(@CurrentUser('email') email: string) {
    return { email };
  }
}
```

**Kasus Penggunaan Nyata:** `@Public()` di endpoint login/register (tanpa token), `@Roles('admin')` di endpoint hapus data, `@CurrentUser('email')` di endpoint profile — semuanya menggunakan custom decorator untuk kode yang bersih dan ekspresif.
