# 15. Custom Decorators

## 15.2. createParamDecorator Parameter Decorator

**Definisi Singkat:** `createParamDecorator` membuat decorator kustom untuk parameter handler (seperti `@Body()`, `@Param()`, tapi kustom).

**Analogi:** Seperti membuat colokan listrik khusus — bukan colokan biasa (Body, Param), tapi colokan dengan fitur tambahan.

**Poin-Poin Penting:**
- Import dari `@nestjs/common`
- `createParamDecorator((data, ctx) => {})`
- `data` — argumen yang dikirim ke decorator
- `ctx` — ExecutionContext
- Bisa akses request, response, dll
- Contoh: `@CurrentUser()`, `@IpAddress()`, `@UserAgent()`

**Contoh Kode:**
```typescript
import { createParamDecorator, ExecutionContext } from '@nestjs/common';

// Decorator untuk mengambil IP address
export const IpAddress = createParamDecorator(
  (data: unknown, ctx: ExecutionContext) => {
    const request = ctx.switchToHttp().getRequest();
    return request.ip || request.connection.remoteAddress;
  },
);

// Decorator untuk mengambil User Agent
export const UserAgent = createParamDecorator(
  (data: unknown, ctx: ExecutionContext) => {
    const request = ctx.switchToHttp().getRequest();
    return request.headers['user-agent'];
  },
);

// Penggunaan
@Get()
trackVisitor(
  @IpAddress() ip: string,
  @UserAgent() userAgent: string,
) {
  return { ip, userAgent };
}
```

**Kasus Penggunaan Nyata:** Endpoint tracking visitor menggunakan `@IpAddress()` untuk mendapatkan IP user dan `@UserAgent()` untuk mendapatkan browser/device info — tanpa akses request object langsung.
