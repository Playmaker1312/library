# 30. WebSockets dan Real-time Communication
## 30.4 WebSocket Lifecycle Hooks
**Definisi Singkat:** WebSocket Gateway di NestJS memiliki lifecycle hooks — `OnGatewayInit`, `OnGatewayConnection`, `OnGatewayDisconnect` — yang memungkinkan eksekusi kode pada berbagai fase siklus hidup koneksi WebSocket.
**Analogi:** Seperti siklus hidup tanaman — `OnGatewayInit` adalah saat menanam benih (setup awal), `OnGatewayConnection` saat tunas muncul (client baru terhubung), `OnGatewayDisconnect` saat tanaman layu (client terputus).
**Poin-Poin Penting:**
- `OnGatewayInit` → `afterInit(server: Server)`
- `OnGatewayConnection` → `handleConnection(client: Socket)`
- `OnGatewayDisconnect` → `handleDisconnect(client: Socket)`
- Middleware via `server.use()`
**Contoh Kode:**
```typescript
// lifecycle.gateway.ts — semua lifecycle hooks
import {
  WebSocketGateway,
  WebSocketServer,
  OnGatewayInit,
  OnGatewayConnection,
  OnGatewayDisconnect,
} from '@nestjs/websockets';
import { Server, Socket } from 'socket.io';
import { Logger, Injectable } from '@nestjs/common';

@Injectable()
@WebSocketGateway({
  cors: { origin: '*' },
  namespace: '/lifecycle',
})
export class LifecycleGateway
  implements OnGatewayInit, OnGatewayConnection, OnGatewayDisconnect
{
  private readonly logger = new Logger(LifecycleGateway.name);
  private connectedClients: Map<string, { id: string; connectedAt: Date }> = new Map();

  @WebSocketServer()
  server: Server;

  // 1️⃣ INIT — dipanggil SETELAH gateway siap
  afterInit(server: Server) {
    this.logger.log('✅ Gateway diinisialisasi');
    this.logger.log(`Namespace: ${server._nsps.size} namespaces`);

    // Middleware global — validasi autentikasi sebelum koneksi diterima
    server.use(async (socket, next) => {
      try {
        const token = socket.handshake.auth.token;
        if (!token) {
          return next(new Error('Token tidak ditemukan'));
        }
        // Validasi token (contoh: decode JWT)
        // const user = await this.authService.validateToken(token);
        // socket.data.user = user;
        next();
      } catch (error) {
        next(new Error('Autentikasi gagal'));
      }
    });

    // Event listener untuk error
    server.on('error', (error) => {
      this.logger.error(`Server error: ${error.message}`);
    });
  }

  // 2️⃣ CONNECTION — dipanggil saat client baru terkoneksi
  async handleConnection(client: Socket) {
    this.logger.log(`🔗 Client terhubung: ${client.id}`);

    // Dapatkan informasi dari handshake
    const { auth, query, headers } = client.handshake;
    const userAgent = headers['user-agent'] || 'unknown';

    this.logger.log(`  - User Agent: ${userAgent}`);
    this.logger.log(`  - Auth: ${JSON.stringify(auth)}`);
    this.logger.log(`  - Query: ${JSON.stringify(query)}`);

    // Simpan data client
    this.connectedClients.set(client.id, {
      id: client.id,
      connectedAt: new Date(),
    });

    // Kirim event 'connected' ke client — konfirmasi koneksi
    client.emit('connected', {
      clientId: client.id,
      message: 'Koneksi WebSocket berhasil',
      serverTime: new Date().toISOString(),
    });

    // Broadcast ke semua client (kecuali pengirim) bahwa user baru online
    client.broadcast.emit('userOnline', {
      clientId: client.id,
      onlineUsers: this.connectedClients.size,
    });

    // Set timeout — disconnect jika tidak ada aktivitas dalam 5 menit
    client.data.inactivityTimer = setTimeout(() => {
      this.logger.warn(`Client ${client.id} timeout karena tidak ada aktivitas`);
      client.emit('timeout', { message: 'Koneksi terputus karena timeout' });
      client.disconnect();
    }, 5 * 60 * 1000);

    // Reset timer saat ada aktivitas
    client.on('activity', () => {
      clearTimeout(client.data.inactivityTimer);
    });
  }

  // 3️⃣ DISCONNECT — dipanggil saat client terputus
  handleDisconnect(client: Socket) {
    this.logger.log(`❌ Client terputus: ${client.id}`);

    // Hapus dari daftar client
    this.connectedClients.delete(client.id);

    // Bersihkan timer
    if (client.data.inactivityTimer) {
      clearTimeout(client.data.inactivityTimer);
    }

    // Log alasan disconnect
    const reason = client.handshake?.close?.reason || 'unknown';
    this.logger.log(`  - Alasan: ${reason}`);

    // Broadcast user offline (dengan pengecualian)
    client.broadcast.emit('userOffline', {
      clientId: client.id,
      onlineUsers: this.connectedClients.size,
    });

    // Cleanup — leave all rooms
    client.rooms.forEach((room) => {
      if (room !== client.id) {
        client.leave(room);
        this.logger.log(`  - Leave room: ${room}`);
      }
    });
  }

  // Utility — dapatkan jumlah client terhubung
  getConnectedClientsCount(): number {
    return this.connectedClients.size;
  }

  // Utility — dapatkan informasi semua client
  getConnectedClientsInfo() {
    return Array.from(this.connectedClients.entries()).map(([id, info]) => ({
      id,
      connectedAt: info.connectedAt,
    }));
  }
}
```
**Kasus Penggunaan Nyata:** Dashboard admin yang menampilkan jumlah user online real-time. Setiap kali user connect/disconnect, gateway mem-broadcast jumlah online users. Middleware `afterInit` memvalidasi token JWT sebelum koneksi diterima, mencegah akses tidak sah. Inactivity timer menghemat resource server.
