# 30. WebSockets dan Real-time Communication
## 30.2 Gateway WebSocketGateway
**Definisi Singkat:** `@WebSocketGateway()` adalah decorator yang menandai class sebagai WebSocket gateway — komponen yang menangani koneksi WebSocket, event, dan komunikasi real-time di NestJS.
**Analogi:** Seperti pintu gerbang utama stadion — semua pengunjung (client) masuk lewat sini, petugas (gateway) mencatat siapa yang masuk/keluar, dan mengarahkan mereka ke sektor yang sesuai (room/namespace).
**Poin-Poin Penting:**
- `@WebSocketGateway()` decorator class
- Opsi: `port`, `namespace`, `cors`, `path`
- `@WebSocketServer()` untuk akses Server instance
- Implements lifecycle interfaces
**Contoh Kode:**
```typescript
// notification.gateway.ts — gateway dengan konfigurasi lengkap
import {
  WebSocketGateway,
  WebSocketServer,
  OnGatewayInit,
  OnGatewayConnection,
  OnGatewayDisconnect,
} from '@nestjs/websockets';
import { Server, Socket } from 'socket.io';
import { Logger } from '@nestjs/common';

@WebSocketGateway({
  // Port spesifik untuk WebSocket (default: sama dengan HTTP)
  port: 3001,

  // Path kustom
  path: '/ws',

  // CORS configuration
  cors: {
    origin: ['http://localhost:3000', 'https://example.com'],
    methods: ['GET', 'POST'],
    credentials: true,
  },

  // Transport options
  transports: ['websocket', 'polling'],

  // Allow upgrade
  allowUpgrades: true,

  // Ping interval untuk keep-alive
  pingInterval: 10000,
  pingTimeout: 5000,

  // Max HTTP buffer size
  maxHttpBufferSize: 1e6,  // 1 MB
})
export class NotificationGateway
  implements OnGatewayInit, OnGatewayConnection, OnGatewayDisconnect
{
  private readonly logger = new Logger(NotificationGateway.name);

  @WebSocketServer()
  server: Server;

  // Dipanggil setelah gateway diinisialisasi
  afterInit(server: Server) {
    this.logger.log('WebSocket Gateway initialized');
    // Middleware untuk autentikasi
    server.use((socket, next) => {
      const token = socket.handshake.auth.token;
      if (token) {
        // Validasi token
        next();
      } else {
        next(new Error('Authentication required'));
      }
    });
  }

  // Dipanggil saat client terhubung
  handleConnection(client: Socket) {
    this.logger.log(`Client connected: ${client.id}`);

    // Join room berdasarkan user ID (dari auth)
    const userId = client.handshake.auth.userId;
    if (userId) {
      client.join(`user:${userId}`);
    }
  }

  // Dipanggil saat client terputus
  handleDisconnect(client: Socket) {
    this.logger.log(`Client disconnected: ${client.id}`);
  }
}
```
```typescript
// multiple-gateways.module.ts — multiple gateway dalam satu module
import { Module } from '@nestjs/common';
import { ChatGateway } from './chat.gateway';
import { NotificationGateway } from './notification.gateway';
import { AnalyticsGateway } from './analytics.gateway';

@Module({
  providers: [
    ChatGateway,           // Menangani chat real-time
    NotificationGateway,   // Menangani notifikasi
    AnalyticsGateway,      // Menangani live analytics
  ],
})
export class RealtimeModule {}
```
```typescript
// analytics.gateway.ts — gateway dengan namespace
import {
  WebSocketGateway,
  WebSocketServer,
} from '@nestjs/websockets';
import { Server } from 'socket.io';

// Gunakan namespace '/analytics' — terpisah dari chat
@WebSocketGateway({
  namespace: '/analytics',
  cors: { origin: '*' },
})
export class AnalyticsGateway {
  @WebSocketServer()
  server: Server;

  // Method untuk broadcast data analytics
  sendAnalyticsData(data: any) {
    this.server.emit('analytics:update', data);
  }
}
```
**Kasus Penggunaan Nyata:** Aplikasi dashboard monitoring dengan tiga gateway terpisah: `ChatGateway` untuk live chat support, `NotificationGateway` untuk push notifikasi real-time, dan `AnalyticsGateway` untuk live graph data. Masing-masing punya port dan namespace sendiri.
