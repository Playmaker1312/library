# 30. WebSockets dan Real-time Communication
## 30.3 SubscribeMessage Decorator
**Definisi Singkat:** `@SubscribeMessage()` decorator menandai method dalam WebSocket gateway sebagai handler untuk event tertentu yang dikirim oleh client, mirip seperti routing di HTTP controller.
**Analogi:** Seperti remote control — setiap tombol (event name) dipetakan ke fungsi tertentu. Saat client menekan tombol "kirim pesan" (`sendMessage`), fungsi handler-nya langsung dijalankan.
**Poin-Poin Penting:**
- `@SubscribeMessage('event-name')` method handler
- Method menerima `client: Socket` dan `payload: any`
- Return value otomatis dikirim sebagai response event
- Response dikirim via callback atau return
**Contoh Kode:**
```typescript
// chat.gateway.ts — message handlers
import {
  WebSocketGateway,
  SubscribeMessage,
  WebSocketServer,
  ConnectedSocket,
  MessageBody,
} from '@nestjs/websockets';
import { Server, Socket } from 'socket.io';

@WebSocketGateway({
  cors: { origin: '*' },
  namespace: '/chat',
})
export class ChatGateway {
  @WebSocketServer()
  server: Server;

  // Handler untuk event 'joinRoom'
  @SubscribeMessage('joinRoom')
  handleJoinRoom(
    @ConnectedSocket() client: Socket,
    @MessageBody() payload: { room: string; username: string },
  ): void {
    client.join(payload.room);
    // Kirim notifikasi ke room bahwa user bergabung
    this.server.to(payload.room).emit('notification', {
      type: 'join',
      message: `${payload.username} bergabung ke room`,
    });
  }

  // Handler untuk event 'sendMessage'
  @SubscribeMessage('sendMessage')
  handleMessage(
    @ConnectedSocket() client: Socket,
    @MessageBody() payload: { room: string; message: string; username: string },
  ): void {
    // Broadcast pesan ke semua client di room (termasuk pengirim)
    this.server.to(payload.room).emit('newMessage', {
      username: payload.username,
      message: payload.message,
      timestamp: new Date().toISOString(),
    });
  }

  // Handler dengan response — return value dikirim sebagai ack
  @SubscribeMessage('getOnlineUsers')
  handleGetOnlineUsers(
    @ConnectedSocket() client: Socket,
    @MessageBody() payload: { room: string },
  ): { onlineUsers: number } {
    // Dapatkan jumlah client di room
    const room = this.server.sockets.adapter.rooms.get(payload.room);
    const onlineUsers = room ? room.size : 0;

    return { onlineUsers };
  }

  // Handler untuk private message
  @SubscribeMessage('privateMessage')
  handlePrivateMessage(
    @ConnectedSocket() client: Socket,
    @MessageBody() payload: { to: string; message: string },
  ): void {
    // Kirim pesan ke user spesifik
    this.server.to(`user:${payload.to}`).emit('privateMessage', {
      from: client.id,
      message: payload.message,
    });
  }

  // Handler typing indicator
  @SubscribeMessage('typing')
  handleTyping(
    @ConnectedSocket() client: Socket,
    @MessageBody() payload: { room: string; username: string; isTyping: boolean },
  ): void {
    client.to(payload.room).emit('userTyping', {
      username: payload.username,
      isTyping: payload.isTyping,
    });
  }
}
```

```typescript
// game.gateway.ts — multiple SubscribeMessage
import { SubscribeMessage, WebSocketGateway } from '@nestjs/websockets';
import { Socket } from 'socket.io';

@WebSocketGateway({ namespace: '/game', cors: { origin: '*' } })
export class GameGateway {
  // Mengelola state game sederhana
  private games = new Map<string, any>();

  @SubscribeMessage('createGame')
  handleCreateGame(client: Socket, payload: { playerName: string }) {
    const gameId = Math.random().toString(36).substring(7);
    this.games.set(gameId, {
      id: gameId,
      players: [{ id: client.id, name: payload.playerName }],
      state: 'waiting',
    });
    client.join(`game:${gameId}`);
    return { gameId };
  }

  @SubscribeMessage('joinGame')
  handleJoinGame(client: Socket, payload: { gameId: string; playerName: string }) {
    const game = this.games.get(payload.gameId);
    if (!game) return { error: 'Game not found' };
    if (game.players.length >= 2) return { error: 'Game is full' };

    game.players.push({ id: client.id, name: payload.playerName });
    client.join(`game:${payload.gameId}`);

    if (game.players.length === 2) {
      game.state = 'playing';
      this.server.to(`game:${payload.gameId}`).emit('gameStart', { game });
    }

    return { success: true, game };
  }

  @SubscribeMessage('makeMove')
  handleMakeMove(client: Socket, payload: { gameId: string; move: any }) {
    const game = this.games.get(payload.gameId);
    // Proses move
    this.server.to(`game:${payload.gameId}`).emit('moveMade', {
      playerId: client.id,
      move: payload.move,
    });
  }
}
```
**Kasus Penggunaan Nyata:** Aplikasi live chat support di e-commerce. Agent dan customer terhubung via WebSocket. Client emit event `sendMessage` ke room spesifik, gateway menerima dan broadcast `newMessage` ke semua peserta room. Fitur `typing` indicator memberitahu sedang mengetik, `joinRoom` untuk routing ke agent yang tepat.
