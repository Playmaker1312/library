# 30. WebSockets dan Real-time Communication
## 30.8 Scaling WebSockets Redis Adapter
**Definisi Singkat:** Redis Adapter (`@nestjs/platform-socket.io` + `socket.io-redis`) memungkinkan WebSocket di-scale secara horizontal dengan menggunakan Redis sebagai pub/sub message broker antar instance server.
**Analogi:** Seperti walkie-talkie yang terhubung ke repeater pusat — jika ada 10 petugas keamanan dengan walkie-talkie di gedung berbeda, repeater (Redis) memastikan semua petugas mendengar pesan yang sama, meskipun mereka ada di lantai/gedung berbeda.
**Poin-Poin Penting:**
- `socket.io-redis` atau `@socket.io/redis-adapter`
- `redis` package untuk koneksi Redis
- Pub/sub mechanism untuk broadcast lintas instance
- Setup di `main.ts` atau gateway
**Contoh Kode:**
```typescript
// main.ts — setup Redis adapter untuk scale WebSocket
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { createAdapter } from '@socket.io/redis-adapter';
import { createClient } from 'redis';
import { IoAdapter } from '@nestjs/platform-socket.io';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // Buat koneksi Redis untuk pub/sub
  const pubClient = createClient({
    url: process.env.REDIS_URL || 'redis://localhost:6379',
    // Untuk production dengan password:
    // password: process.env.REDIS_PASSWORD,
  });
  const subClient = pubClient.duplicate();

  // Tunggu koneksi Redis siap
  await Promise.all([pubClient.connect(), subClient.connect()]);

  // Buat custom IoAdapter dengan Redis adapter
  const redisAdapter = createAdapter(pubClient, subClient, {
    // Key prefix untuk membedakan dengan aplikasi lain
    key: 'myapp-websocket',
    // Request timeout (ms)
    requestTimeout: 5000,
    // Success rate monitoring
    successRateThreshold: 0.9,
    // Health check interval
    healthCheckInterval: 30000,
  });

  // Gunakan Redis adapter
  const appIoAdapter = new IoAdapter(app);
  appIoAdapter.createIOServer = (port, options) => {
    const server = require('socket.io')(port, {
      ...options,
      cors: { origin: '*' },
    });
    server.adapter(redisAdapter);
    return server;
  };

  app.useWebSocketAdapter(appIoAdapter);

  await app.listen(3000);
  console.log(`Server berjalan di port 3000`);
  console.log(`WebSocket Redis adapter aktif`);
}
bootstrap();
```
```typescript
// redis-io-adapter.ts — custom adapter class
import { IoAdapter } from '@nestjs/platform-socket.io';
import { ServerOptions } from 'socket.io';
import { createAdapter } from '@socket.io/redis-adapter';
import { createClient } from 'redis';
import { Logger } from '@nestjs/common';

export class RedisIoAdapter extends IoAdapter {
  private readonly logger = new Logger(RedisIoAdapter.name);
  private adapterConstructor: ReturnType<typeof createAdapter>;

  async connectToRedis(url: string): Promise<void> {
    try {
      const pubClient = createClient({ url });
      const subClient = pubClient.duplicate();

      await Promise.all([pubClient.connect(), subClient.connect()]);

      this.adapterConstructor = createAdapter(pubClient, subClient, {
        key: 'nestjs-chat',
        requestTimeout: 10000,
      });

      this.logger.log('Redis adapter untuk WebSocket berhasil dikonfigurasi');
    } catch (error) {
      this.logger.error(`Gagal konek ke Redis: ${error.message}`);
      throw error;
    }
  }

  createIOServer(port: number, options?: ServerOptions): any {
    const server = super.createIOServer(port, {
      ...options,
      cors: { origin: '*' },
    });

    if (this.adapterConstructor) {
      server.adapter(this.adapterConstructor);
      this.logger.log('Redis adapter terpasang ke Socket.IO server');
    }

    return server;
  }
}
```

**Kasus Penggunaan Nyata:** Aplikasi chat dengan 100.000 concurrent users. Satu server tidak cukup — perlu di-scale ke 10 server. Tanpa Redis adapter, user di server A tidak bisa chat dengan user di server B. Redis adapter bertindak sebagai "bus" yang meneruskan event antar server, sehingga semua user merasa terhubung ke satu server meskipun sebenarnya terdistribusi.
