# 30. WebSockets dan Real-time Communication
## 30.1 nestjs websockets dan nestjs platform-socket io
**Definisi Singkat:** `@nestjs/websockets` dan `@nestjs/platform-socket.io` menyediakan integrasi WebSocket di NestJS menggunakan library Socket.IO, memungkinkan komunikasi bidirectional real-time antara server dan client.
**Analogi:** Seperti telepon — HTTP adalah surat (request-response, satu arah), WebSocket adalah panggilan telepon (koneksi persistent, dua arah real-time). Socket.IO adalah "smartphone"-nya dengan fitur tambahan seperti auto-reconnect dan fallback.
**Poin-Poin Penting:**
- `@nestjs/websockets` package
- `@nestjs/platform-socket.io` package
- Socket.IO server dan client
- `npm i @nestjs/websockets @nestjs/platform-socket.io`
**Contoh Kode:**
```typescript
// app.module.ts — registrasi WebSocket module
import { Module } from '@nestjs/common';
import { ChatModule } from './chat/chat.module';

@Module({
  imports: [
    ChatModule,  // Module yang berisi WebSocket gateway
  ],
})
export class AppModule {}
```
```typescript
// chat/chat.module.ts
import { Module } from '@nestjs/common';
import { ChatGateway } from './chat.gateway';
import { ChatService } from './chat.service';

@Module({
  providers: [ChatGateway, ChatService],
})
export class ChatModule {}
```
```typescript
// chat/chat.gateway.ts — WebSocket Gateway sederhana
import {
  WebSocketGateway,
  WebSocketServer,
  SubscribeMessage,
  OnGatewayConnection,
  OnGatewayDisconnect,
} from '@nestjs/websockets';
import { Server, Socket } from 'socket.io';

@WebSocketGateway({
  cors: {
    origin: '*',  // Izinkan semua origin (dev)
    credentials: true,
  },
  namespace: '/chat',  // Namespace opsional
})
export class ChatGateway implements OnGatewayConnection, OnGatewayDisconnect {
  @WebSocketServer()
  server: Server;

  handleConnection(client: Socket) {
    console.log(`Client terhubung: ${client.id}`);
    // Kirim pesan selamat datang ke client yang baru terhubung
    client.emit('welcome', { message: `Selamat datang ${client.id}!` });
  }

  handleDisconnect(client: Socket) {
    console.log(`Client terputus: ${client.id}`);
  }
}
```
```typescript
// app.gateway.ts — Gateway tanpa namespace (default)
import { WebSocketGateway, WebSocketServer } from '@nestjs/websockets';
import { Server } from 'socket.io';

@WebSocketGateway({
  cors: { origin: '*' },
  // port: 3001,  // Port terpisah (opsional)
  // namespace: '/', // Default root namespace
})
export class AppGateway {
  @WebSocketServer()
  server: Server;
}
```
**Kasus Penggunaan Nyata:** Aplikasi chat real-time, notifikasi live, dashboard monitoring, kolaborasi dokumen, atau game multiplayer. Socket.IO dipilih karena kompatibel dengan browser, memiliki fallback ke long-polling, dan fitur room/namespace yang powerful.
