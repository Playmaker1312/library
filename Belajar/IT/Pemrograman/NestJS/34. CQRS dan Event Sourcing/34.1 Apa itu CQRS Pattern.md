# 34. CQRS dan Event Sourcing ## 34.1 Apa itu CQRS Pattern

**Definisi Singkat:** CQRS (Command Query Responsibility Segregation) adalah pattern yang memisahkan operasi read (queries) dan write (commands) ke model yang berbeda, tidak seperti CRUD tradisional yang menggunakan model sama untuk baca dan tulis.

**Analogi:** CQRS seperti restoran: koki (command) menerima pesanan dan memasak, sementara pelayan (query) menyajikan menu dan memberitahu status. Pekerjaan memasak dan menyajikan informasi dipisahkan, masing-masing optimalisasi sendiri.

**Poin-Poin Penting:**
- **Command** mengubah state (Create, Update, Delete) — void return
- **Query** membaca state — tidak mengubah data
- **Command Handler** business logic untuk command
- **Query Handler** optimized data retrieval
- **Separate models** untuk read dan write
- **CQRS Module** dari @nestjs/cqrs

**Contoh Kode:**
```typescript
// app.module.ts
import { Module } from '@nestjs/common';
import { CqrsModule } from '@nestjs/cqrs';
import { UserModule } from './user/user.module';

@Module({
  imports: [
    CqrsModule.forRoot(),
    UserModule,
  ],
})
export class AppModule {}
```

```typescript
// user.module.ts
import { Module } from '@nestjs/common';
import { CqrsModule } from '@nestjs/cqrs';
import { UserController } from './user.controller';
import { CreateUserHandler } from './commands/create-user.handler';
import { GetUserHandler } from './queries/get-user.handler';
import { UserRepository } from './user.repository';

@Module({
  imports: [CqrsModule],
  controllers: [UserController],
  providers: [
    CreateUserHandler,
    GetUserHandler,
    UserRepository,
  ],
})
export class UserModule {}
```

```typescript
// user.controller.ts
import { Controller, Post, Get, Body, Param } from '@nestjs/common';
import { CommandBus, QueryBus } from '@nestjs/cqrs';
import { CreateUserCommand } from './commands/create-user.command';
import { GetUserQuery } from './queries/get-user.query';

@Controller('users')
export class UserController {
  constructor(
    private readonly commandBus: CommandBus,
    private readonly queryBus: QueryBus,
  ) {}

  @Post()
  async create(@Body() body: { name: string; email: string }) {
    return this.commandBus.execute(
      new CreateUserCommand(body.name, body.email),
    );
  }

  @Get(':id')
  async get(@Param('id') id: string) {
    return this.queryBus.execute(new GetUserQuery(id));
  }
}
```

**Kasus Penggunaan Nyata:** Sistem e-commerce dengan traffic tinggi — command handle checkout di write model (validasi stok, proses payment), sementara query model menggunakan cache dan data denormalized untuk product listing cepat tanpa mengganggu proses transaksi.
