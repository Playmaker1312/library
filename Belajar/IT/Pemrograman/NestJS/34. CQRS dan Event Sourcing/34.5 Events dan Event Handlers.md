# 34. CQRS dan Event Sourcing ## 34.5 Events dan Event Handlers

**Definisi Singkat:** Event adalah object yang merepresentasikan sesuatu yang telah terjadi di system (past tense). Event Handler adalah class yang merespons event dan menjalankan side effects seperti update read model, kirim email, atau notifikasi.

**Analogi:** Event seperti pengumuman di mal — ketika "Toko A buka cabang baru" (event), berbagai pihak bereaksi: security membuka pintu, marketing memasang spanduk, management update denah. Event handler masing-masing melakukan tugasnya tanpa saling mengganggu.

**Poin-Poin Penting:**
- **IEvent** interface untuk event
- **@EventHandler(Event)** decorator handler
- **EventBus.publish()** publish event
- **Multiple handlers** bisa subscribe ke event yang sama
- **Event** bersifat immutable dan past tense
- **Side effects** terisolasi di event handler

**Contoh Kode:**
```typescript
// events/order-created.event.ts
import { IEvent } from '@nestjs/cqrs';

export class OrderCreatedEvent implements IEvent {
  constructor(
    public readonly orderId: string,
    public readonly userId: string,
    public readonly total: number,
    public readonly items: Array<{ productId: string; quantity: number; price: number }>,
    public readonly createdAt: Date = new Date(),
  ) {}
}
```

```typescript
// events/order-created.handler.ts
import { EventsHandler, IEventHandler } from '@nestjs/cqrs';
import { OrderCreatedEvent } from './order-created.event';
import { EmailService } from '../services/email.service';
import { InventoryService } from '../services/inventory.service';
import { AnalyticsService } from '../services/analytics.service';

@EventsHandler(OrderCreatedEvent)
export class OrderCreatedHandler implements IEventHandler<OrderCreatedEvent> {
  constructor(
    private readonly emailService: EmailService,
    private readonly inventoryService: InventoryService,
    private readonly analyticsService: AnalyticsService,
  ) {}

  async handle(event: OrderCreatedEvent) {
    const { orderId, userId, total, items } = event;

    await Promise.all([
      this.emailService.sendOrderConfirmation(userId, orderId, items, total),
      this.inventoryService.reserveItems(items),
      this.analyticsService.trackOrderCreated(orderId, userId, total),
    ]);
  }
}
```

```typescript
// events/order-cancelled.handler.ts
import { EventsHandler, IEventHandler } from '@nestjs/cqrs';
import { OrderCancelledEvent } from './order-cancelled.event';
import { EmailService } from '../services/email.service';
import { InventoryService } from '../services/inventory.service';
import { RefundService } from '../services/refund.service';

@EventsHandler(OrderCancelledEvent)
export class OrderCancelledHandler implements IEventHandler<OrderCancelledEvent> {
  constructor(
    private readonly emailService: EmailService,
    private readonly inventoryService: InventoryService,
    private readonly refundService: RefundService,
  ) {}

  async handle(event: OrderCancelledEvent) {
    const { orderId, reason } = event;

    await Promise.all([
      this.emailService.sendCancellationNotice(orderId, reason),
      this.inventoryService.releaseItems(orderId),
      this.refundService.processRefund(orderId),
    ]);
  }
}
```
