# 34. CQRS dan Event Sourcing ## 34.2 nestjs cqrs Instalasi

**Definisi Singkat:** @nestjs/cqrs adalah package resmi NestJS yang menyediakan CQRS pattern utilities termasuk CommandBus, QueryBus, EventBus, dan Saga. Instalasi sederhana via npm.

**Analogi:** Instalasi @nestjs/cqrs seperti memasang panel kontrol baru di dashboard mobil — memberikan kemampuan untuk memisahkan gas (command), speedometer (query), dan indikator (event) tanpa mengubah mesin asli.

**Poin-Poin Penting:**
- **npm install @nestjs/cqrs** instalasi package
- **CqrsModule.forRoot()** import module
- **CommandBus** untuk execute commands
- **QueryBus** untuk execute queries
- **EventBus** untuk publish events
- **CommandHandler, QueryHandler, EventHandler** decorators

**Contoh Kode:**
```typescript
// instalasi
// npm install @nestjs/cqrs @nestjs/event-emitter
```

```typescript
// app.module.ts
import { Module } from '@nestjs/common';
import { CqrsModule } from '@nestjs/cqrs';
import { EventEmitterModule } from '@nestjs/event-emitter';
import { OrderModule } from './order/order.module';

@Module({
  imports: [
    CqrsModule.forRoot(),
    EventEmitterModule.forRoot({
      wildcard: true,
      delimiter: '.',
    }),
    OrderModule,
  ],
})
export class AppModule {}
```

```typescript
// order.module.ts
import { Module } from '@nestjs/common';
import { CqrsModule } from '@nestjs/cqrs';
import { OrderController } from './order.controller';
import { CreateOrderHandler } from './commands/create-order.handler';
import { CancelOrderHandler } from './commands/cancel-order.handler';
import { GetOrderHandler } from './queries/get-order.handler';
import { GetOrdersHandler } from './queries/get-orders.handler';
import { OrderCreatedHandler } from './events/order-created.handler';
import { OrderRepository } from './order.repository';
import { OrderSaga } from './sagas/order.saga';

@Module({
  imports: [CqrsModule],
  controllers: [OrderController],
  providers: [
    CreateOrderHandler,
    CancelOrderHandler,
    GetOrderHandler,
    GetOrdersHandler,
    OrderCreatedHandler,
    OrderRepository,
    OrderSaga,
  ],
})
export class OrderModule {}
```
