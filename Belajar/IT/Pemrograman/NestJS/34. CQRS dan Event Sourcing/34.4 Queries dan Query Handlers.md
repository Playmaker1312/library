# 34. CQRS dan Event Sourcing ## 34.4 Queries dan Query Handlers

**Definisi Singkat:** Query adalah object yang merepresentasikan permintaan data tanpa mengubah state. Query Handler adalah class yang mengambil data dari read model (bisa database terpisah, cache, atau view table) dan mengembalikan DTO.

**Analogi:** Query seperti melihat menu restoran — Anda hanya melihat daftar makanan (data), tidak memesan apapun (tidak mengubah state). Pelayan (query handler) mengambil menu dan menunjukkannya tanpa mempengaruhi dapur.

**Poin-Poin Penting:**
- **IQuery** interface untuk query
- **@QueryHandler(Query)** decorator handler
- **queryBus.execute()** menjalankan query
- **Return data** (tidak void)
- **Read model** bisa berbeda dari write model
- **Cache** friendly untuk optimasi

**Contoh Kode:**
```typescript
// queries/get-order.query.ts
export class GetOrderQuery {
  constructor(
    public readonly orderId: string,
    public readonly includeItems?: boolean,
  ) {}
}
```

```typescript
// queries/get-order.handler.ts
import { QueryHandler, IQueryHandler } from '@nestjs/cqrs';
import { GetOrderQuery } from './get-order.query';
import { OrderRepository } from '../order.repository';
import { NotFoundException } from '@nestjs/common';

@QueryHandler(GetOrderQuery)
export class GetOrderHandler implements IQueryHandler<GetOrderQuery> {
  constructor(private readonly orderRepository: OrderRepository) {}

  async execute(query: GetOrderQuery): Promise<any> {
    const { orderId, includeItems } = query;

    const order = await this.orderRepository.findById(orderId);
    if (!order) {
      throw new NotFoundException('Order not found');
    }

    if (!includeItems) {
      const { items, ...orderWithoutItems } = order;
      return orderWithoutItems;
    }

    return order;
  }
}
```

```typescript
// queries/get-orders.query.ts
export class GetOrdersQuery {
  constructor(
    public readonly userId: string,
    public readonly page: number = 1,
    public readonly limit: number = 10,
    public readonly status?: string,
```

```typescript
// queries/get-orders.handler.ts
import { QueryHandler, IQueryHandler } from '@nestjs/cqrs';
import { GetOrdersQuery } from './get-orders.query';
import { OrderRepository } from '../order.repository';

@QueryHandler(GetOrdersQuery)
export class GetOrdersHandler implements IQueryHandler<GetOrdersQuery> {
  constructor(private readonly orderRepository: OrderRepository) {}

  async execute(query: GetOrdersQuery): Promise<{ data: any[]; total: number; page: number }> {
    const { userId, page, limit, status } = query;

    const filters: any = { userId };
    if (status) {
      filters.status = status;
    }

    const [data, total] = await Promise.all([
      this.orderRepository.findMany(filters, { page, limit }),
      this.orderRepository.count(filters),
    ]);

    return {
      data,
      total,
      page,
    };
  }
}
```

```typescript
// order.controller.ts (bagian query)
import { Controller, Get, Param, Query, DefaultValuePipe, ParseIntPipe } from '@nestjs/common';
import { QueryBus } from '@nestjs/cqrs';
import { GetOrderQuery } from './queries/get-order.query';
import { GetOrdersQuery } from './queries/get-orders.query';

@Controller('orders')
export class OrderController {
  constructor(private readonly queryBus: QueryBus) {}

  @Get(':id')
  async getOrder(
    @Param('id') id: string,
    @Query('includeItems') includeItems?: boolean,
  ) {
    return this.queryBus.execute(new GetOrderQuery(id, includeItems));
  }

  @Get()
  async getOrders(
    @Query('userId') userId: string,
    @Query('page', new DefaultValuePipe(1), ParseIntPipe) page: number,
    @Query('limit', new DefaultValuePipe(10), ParseIntPipe) limit: number,
    @Query('status') status?: string,
  ) {
    return this.queryBus.execute(new GetOrdersQuery(userId, page, limit, status));
  }
}
```

**Kasus Penggunaan Nyata:** Dashboard admin dengan ribuan transaksi per hari — `GetDashboardQuery` menggunakan query handler yang membaca dari read-optimized database (Elasticsearch atau materialized view) untuk agregasi cepat tanpa membebani database transaksional.
