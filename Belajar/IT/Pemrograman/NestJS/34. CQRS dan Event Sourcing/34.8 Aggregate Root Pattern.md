# 34. CQRS dan Event Sourcing ## 34.8 Aggregate Root Pattern

**Definisi Singkat:** Aggregate Root adalah class domain yang menjadi root entity untuk sekelompok objek yang terkait, menjamin konsistensi transaksional dari seluruh aggregate. Semua operasi pada aggregate harus melalui root.

**Analogi:** Aggregate Root seperti mobil — Anda tidak bisa memutar roda secara langsung (hanya melalui setir), tidak bisa menekan gas langsung (hanya melalui pedal). Mobil (aggregate root) adalah satu kesatuan yang menjamin semua komponen bekerja konsisten.

**Poin-Poin Penting:**
- **Aggregate Root** entity utama yang mengontrol akses
- **Transactional boundary** konsistensi dalam satu aggregate
- **Invariant** business rules yang harus selalu terpenuhi
- **Domain Events** dihasilkan oleh aggregate
- **Version** untuk optimistic concurrency
- **Factory method** untuk create aggregate

**Contoh Kode:**
```typescript
// domain/order.aggregate.ts
import { AggregateRoot } from '@nestjs/cqrs';
import { OrderCreatedEvent } from '../events/order-created.event';
import { OrderItemAddedEvent } from '../events/order-item-added.event';
import { OrderShippedEvent } from '../events/order-shipped.event';
import { OrderCancelledEvent } from '../events/order-cancelled.event';

interface OrderItem {
  productId: string;
  name: string;
  quantity: number;
  price: number;
}

export class OrderAggregate extends AggregateRoot {
  private id: string;
  private userId: string;
  private items: OrderItem[] = [];
  private total: number = 0;
  private status: string;
  private shippingAddress: any;
  private version: number = 0;

  constructor(id: string) {
    super();
    this.id = id;
  }

  // Factory method
  static create(id: string, userId: string, items: OrderItem[], address: any): OrderAggregate {
    const order = new OrderAggregate(id);
    order.apply(new OrderCreatedEvent(id, userId, 0, items));
    return order;
  }

  addItem(productId: string, name: string, quantity: number, price: number): void {
    if (this.status !== 'pending') {
      throw new Error('Cannot add items to non-pending order');
    }

    this.apply(new OrderItemAddedEvent(this.id, productId, name, quantity, price));
  }

  ship(): void {
    if (this.status !== 'pending') {
      throw new Error('Only pending orders can be shipped');
    }

    if (this.items.length === 0) {
      throw new Error('Cannot ship empty order');
    }

    this.apply(new OrderShippedEvent(this.id));
  }

  cancel(reason: string): void {
    if (this.status === 'shipped' || this.status === 'delivered') {
      throw new Error('Cannot cancel shipped or delivered order');
    }

    this.apply(new OrderCancelledEvent(this.id, reason));
  }

  // Event handlers (apply state changes)
  private onOrderCreatedEvent(event: OrderCreatedEvent) {
    this.userId = event.userId;
    this.items = event.items;
    this.total = event.total;
    this.status = 'pending';
    this.version++;
  }

  private onOrderItemAddedEvent(event: OrderItemAddedEvent) {
    this.items.push({
      productId: event.productId,
      name: event.name,
      quantity: event.quantity,
      price: event.price,
    });
    this.total += event.quantity * event.price;
    this.version++;
  }

  private onOrderShippedEvent(event: OrderShippedEvent) {
    this.status = 'shipped';
    this.version++;
  }

  private onOrderCancelledEvent(event: OrderCancelledEvent) {
    this.status = 'cancelled';
    this.version++;
  }

  getState() {
    return {
      id: this.id,
      userId: this.userId,
      items: this.items,
      total: this.total,
      status: this.status,
      version: this.version,
    };
  }
}
```
