# 34. CQRS dan Event Sourcing ## 34.6 Sagas

**Definisi Singkat:** Saga adalah class yang mendefinisikan business process yang panjang (long-running transactions) dengan mendengarkan events dan mengeksekusi commands sebagai respons, menggunakan RxJS untuk orchestration.

**Analogi:** Saga seperti resep masakan kompleks — Anda menunggu air mendidih (event), lalu memasukkan mie (command), menunggu 3 menit (delay), lalu tiriskan (command lain). Saga mengkoordinasikan langkah-langkah berdasarkan event yang terjadi.

**Poin-Poin Penting:**
- **@Saga()** decorator method
- **Observable** stream events
- **pipe(map())** konversi event ke command
- **ofType()** operator filter specific event
- **delay, debounceTime, throttleTime** RxJS operators
- **Compensating action** untuk rollback

**Contoh Kode:**
```typescript
// sagas/order.saga.ts
import { Injectable } from '@nestjs/common';
import { ICommand, Saga, ofType } from '@nestjs/cqrs';
import { Observable } from 'rxjs';
import { delay, map, filter } from 'rxjs/operators';
import { OrderCreatedEvent } from '../events/order-created.event';
import { PaymentTimeoutEvent } from '../events/payment-timeout.event';
import { CancelOrderCommand } from '../commands/cancel-order.command';
import { ProcessPaymentCommand } from '../commands/process-payment.command';
import { SendNotificationCommand } from '../commands/send-notification.command';

@Injectable()
export class OrderSaga {
  @Saga()
  orderCreated = (events$: Observable<any>): Observable<ICommand> => {
    return events$.pipe(
      ofType(OrderCreatedEvent),
      delay(1000),
      map((event) => {
        console.log(`Saga: Processing payment for order ${event.orderId}`);
        return new ProcessPaymentCommand(event.orderId, event.total);
      }),
    );
  };

  @Saga()
  paymentTimeout = (events$: Observable<any>): Observable<ICommand> => {
    return events$.pipe(
      ofType(PaymentTimeoutEvent),
      delay(5000),
      filter((event) => event.retryCount < 3),
      map((event) => {
        console.log(`Saga: Retrying payment for order ${event.orderId}`);
        return new ProcessPaymentCommand(event.orderId, event.total);
      }),
    );
  };

  @Saga()
  paymentFailed = (events$: Observable<any>): Observable<ICommand> => {
    return events$.pipe(
      ofType(PaymentFailedEvent),
      map((event) => {
        console.log(`Saga: Cancelling order ${event.orderId} due to payment failure`);
        return new CancelOrderCommand(event.orderId, 'Payment failed');
      }),
    );
  };
}
```

```typescript
// sagas/fulfillment.saga.ts
import { Injectable } from '@nestjs/common';
import { ICommand, Saga, ofType } from '@nestjs/cqrs';
import { Observable } from 'rxjs';
import { delay, map } from 'rxjs/operators';
import { PaymentCompletedEvent } from '../events/payment-completed.event';
import { OrderShippedEvent } from '../events/order-shipped.event';
import { PrepareShipmentCommand } from '../commands/prepare-shipment.command';
import { UpdateOrderStatusCommand } from '../commands/update-order-status.command';
import { SendTrackingEmailCommand } from '../commands/send-tracking-email.command';

@Injectable()
export class FulfillmentSaga {
  @Saga()
  paymentCompleted = (events$: Observable<any>): Observable<ICommand> => {
    return events$.pipe(
      ofType(PaymentCompletedEvent),
      delay(500),
      map((event) => {
        return new PrepareShipmentCommand(event.orderId);
      }),
    );
  };

  @Saga()
  orderShipped = (events$: Observable<any>): Observable<ICommand> => {
    return events$.pipe(
      ofType(OrderShippedEvent),
      delay(300),
      map((event) => {
        return new SendTrackingEmailCommand(event.orderId, event.trackingNumber);
      }),
    );
  };
}
```

**Kasus Penggunaan Nyata:** Sistem booking hotel — saga menangani proses: BookRoom → ProcessPayment (timeout 15 menit) → ConfirmBooking → SendConfirmation. Jika payment gagal, saga menjalankan CancelBooking sebagai compensating action.
