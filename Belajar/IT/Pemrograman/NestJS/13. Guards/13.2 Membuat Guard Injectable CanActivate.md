# 13. Guards

## 13.2. Membuat Guard Injectable CanActivate

**Definisi Singkat:** Guard dibuat dengan class `@Injectable()` yang implement interface `CanActivate` dengan method `canActivate()`.

**Analogi:** Seperti membuat kartu akses — tinggal program: "siapa yang boleh masuk" dan "pintu mana yang boleh dibuka".

**Poin-Poin Penting:**
- Decorator `@Injectable()`
- Implement `CanActivate` interface
- Method `canActivate(context: ExecutionContext): boolean | Promise<boolean> | Observable<boolean>`
- Return `true` = request diproses
- Return `false` = NestJS otomatis throw `ForbiddenException`
- Bisa inject service lain

**Contoh Kode:**
```typescript
import { Injectable, CanActivate, ExecutionContext, ForbiddenException } from '@nestjs/common';

@Injectable()
export class AuthGuard implements CanActivate {
  canActivate(context: ExecutionContext): boolean {
    const request = context.switchToHttp().getRequest();
    const token = request.headers.authorization;

    if (!token) {
      throw new ForbiddenException('Akses ditolak');
    }

    // Validasi token...
    request.user = { id: 1, role: 'user' };
    return true;
  }
}

// Penggunaan di controller
@Controller('users')
export class UserController {
  @UseGuards(AuthGuard)
  @Get('profile')
  getProfile() { }
}
```

**Kasus Penggunaan Nyata:** `AuthGuard` memvalidasi JWT token di header Authorization — jika valid, request dilanjutkan; jika tidak, Guard otomatis melempar `ForbiddenException` (403).
