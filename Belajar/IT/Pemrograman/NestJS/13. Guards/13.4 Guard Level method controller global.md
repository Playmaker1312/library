# 13. Guards

## 13.4. Guard Level method controller global

**Definisi Singkat:** Guard dapat dipasang di level method, controller, atau global menggunakan `@UseGuards()` atau `app.useGlobalGuards()`.

**Analogi:** Seperti aturan akses — kartu khusus untuk ruang server (method), kartu departemen (controller), atau kartu umum (global).

**Poin-Poin Penting:**
- **Method level:** `@UseGuards(Guard)` di atas method
- **Controller level:** `@UseGuards(Guard)` di atas class controller
- **Global level:** `app.useGlobalGuards(Guard)` di main.ts
- Global guard berlaku untuk semua endpoint
- Bisa kombinasi multiple guard

**Contoh Kode:**
```typescript
import { Controller, UseGuards, Get, Post } from '@nestjs/common';
import { AuthGuard } from './auth.guard';
import { AdminGuard } from './admin.guard';

@Controller('users')
@UseGuards(AuthGuard) // Controller level — semua method butuh auth
export class UserController {

  @Get('profile')
  getProfile() { } // Auto diproteksi AuthGuard

  @Delete(':id')
  @UseGuards(AdminGuard) // Method level — tambahan AdminGuard
  deleteUser() { } // Butuh AuthGuard + AdminGuard
}

// Global — di main.ts
app.useGlobalGuards(new AuthGuard());
```

**Kasus Penggunaan Nyata:** `AuthGuard` dipasang global untuk seluruh endpoint, tapi `AdminGuard` khusus untuk method `deleteUser()` — user biasa bisa lihat profil tapi tidak bisa hapus user.
