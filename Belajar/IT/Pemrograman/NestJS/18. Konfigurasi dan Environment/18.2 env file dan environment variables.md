# 18. Konfigurasi dan Environment
## 18.2 env file dan environment variables
**Definisi Singkat:** File `.env` menyimpan konfigurasi dalam format key=value yang dibaca oleh `@nestjs/config`. NestJS juga mendukung environment variables sistem dengan prioritas lebih tinggi.

**Analogi:** `.env` seperti kartu identitas aplikasi — berisi nama, alamat, dan rahasia yang berbeda-beda tergantung lingkungan (development/staging/production).

**Poin-Poin Penting:**
- **`.env`** — File lokal untuk development (jangan di-commit)
- **`.env.example`** — Template yang di-commit (isi dummy)
- **Priority** — Environment variable sistem > `.env` file
- **`process.env`** — Fallback langsung tanpa ConfigService
- **Multi file** — `.env.development`, `.env.production`

**Contoh Kode:**
```text
# .env
PORT=3000
DATABASE_URL=postgresql://user:pass@localhost:5432/nestdb
JWT_SECRET=my-super-secret-key
JWT_EXPIRATION=15m
CORS_ORIGIN=http://localhost:4200
```

```typescript
// app.module.ts — Multi env file
import { Module } from '@nestjs/common';
import { ConfigModule } from '@nestjs/config';

@Module({
  imports: [
    ConfigModule.forRoot({
      envFilePath: `.env.${process.env.NODE_ENV || 'development'}`,
      isGlobal: true,
    }),
  ],
})
export class AppModule {}
```

**Kasus Penggunaan Nyata:** Developer punya `.env.development` dengan database lokal, CI/CD menggunakan `.env.production` dengan koneksi production database.
