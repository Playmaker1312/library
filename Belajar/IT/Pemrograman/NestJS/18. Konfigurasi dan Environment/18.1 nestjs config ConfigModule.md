# 18. Konfigurasi dan Environment
## 18.1 nestjs config ConfigModule
**Definisi Singkat:** `@nestjs/config` adalah package resmi NestJS untuk mengelola konfigurasi aplikasi, membaca `.env` file, dan menyediakan `ConfigService` secara global.

**Analogi:** ConfigModule seperti panel kontrol pusat — semua pengaturan aplikasi (port, database, API key) diatur dari satu tempat, bukan tersebar di kode.

**Poin-Poin Penting:**
- **`ConfigModule.forRoot()`** — Registrasi config module global
- **`isGlobal: true`** — Tersedia di semua module tanpa import ulang
- **`envFilePath`** — Lokasi file `.env`
- **`ignoreEnvFile`** — Untuk production (gunakan env sistem)

**Contoh Kode:**
```typescript
// app.module.ts
import { Module } from '@nestjs/common';
import { ConfigModule } from '@nestjs/config';

@Module({
  imports: [
    ConfigModule.forRoot({
      isGlobal: true,
      envFilePath: '.env',
    }),
    UserModule,
  ],
})
export class AppModule {}
```

**Kasus Penggunaan Nyata:** Aplikasi NestJS yang menggunakan file `.env` untuk menyimpan konfigurasi database, JWT secret, dan port server secara terpusat.
