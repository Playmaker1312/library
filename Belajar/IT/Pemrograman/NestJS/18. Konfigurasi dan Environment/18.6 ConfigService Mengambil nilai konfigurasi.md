# 18. Konfigurasi dan Environment
## 18.6 ConfigService Mengambil nilai konfigurasi
**Definisi Singkat:** `ConfigService` adalah service injectable untuk mengakses nilai konfigurasi dengan method `get()` yang mendukung nested key, type casting, dan default values.

**Analogi:** ConfigService seperti resepsionis hotel — Anda minta "kunci kamar database" (config key), resepsionis ambilkan dari filing cabinet (konfigurasi) yang tepat.

**Poin-Poin Penting:**
- **`configService.get('key')`** — Ambil nilai berdasarkan key
- **`configService.get<string>('PORT')`** — Generic type
- **`configService.get('database.host')`** — Nested key dengan dot notation
- **`configService.get('key', defaultValue)`** — Default value jika tidak ada
- **`configService.get<Type>(namespace, 'key')`** — Type-safe dengan namespace

**Contoh Kode:**
```typescript
// database.service.ts
import { Injectable } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class DatabaseService {
  constructor(private configService: ConfigService) {
    // Cara 1: Langsung
    const port = this.configService.get<number>('PORT', 3000);

    // Cara 2: Nested (jika pakai registerAs)
    const dbHost = this.configService.get<string>('database.host');
    const dbPort = this.configService.get<number>('database.port');

    // Cara 3: Namespace (type-safe)
    const dbConfig = this.configService.get('database');
    // dbConfig.host, dbConfig.port, dll.

    // Cara 4: Dengan inferensi environment variable
    const nodeEnv = this.configService.get<string>('NODE_ENV', 'development');
  }

  getDatabaseUrl(): string {
    const host = this.configService.get<string>('DB_HOST', 'localhost');
    const port = this.configService.get<number>('DB_PORT', 5432);
    const user = this.configService.get<string>('DB_USER', 'postgres');
    const pass = this.configService.get<string>('DB_PASS', '');
    const name = this.configService.get<string>('DB_NAME', 'nestdb');
    return `postgresql://${user}:${pass}@${host}:${port}/${name}`;
  }
}
```

**Kasus Penggunaan Nyata:** Service `MailService` menggunakan ConfigService untuk mengambil SMTP_HOST, SMTP_PORT, SMTP_USER, dan SMTP_PASS dari konfigurasi environment.
