# 18. Konfigurasi dan Environment
## 18.4 Configuration Namespaces
**Definisi Singkat:** Configuration namespaces memungkinkan pengelompokan konfigurasi berdasarkan fitur (database, jwt, aws) menggunakan `ConfigModule` dengan pendekatan partial registration.

**Analogi:** Namespace seperti laci-laci filing cabinet — masing-masing laci (database, JWT, AWS) berisi dokumen terkait, tidak tercampur aduk.

**Poin-Poin Penting:**
- **`ConfigModule.forFeature()`** — Registrasi namespace spesifik per module
- **`registerAs()`** — Function untuk mendefinisikan namespace dengan tipe
- **Organized** — Pisahkan konfigurasi per domain fitur
- **Type safety** — Namespace memberikan tipe spesifik untuk ConfigService

**Contoh Kode:**
```typescript
// config/database.config.ts
import { registerAs } from '@nestjs/config';

export default registerAs('database', () => ({
  host: process.env.DB_HOST || 'localhost',
  port: +process.env.DB_PORT || 5432,
  username: process.env.DB_USER,
  password: process.env.DB_PASS,
  name: process.env.DB_NAME,
}));

// config/jwt.config.ts
import { registerAs } from '@nestjs/config';

export default registerAs('jwt', () => ({
  secret: process.env.JWT_SECRET,
  expiresIn: process.env.JWT_EXPIRATION || '15m',
}));

// app.module.ts
import { Module } from '@nestjs/common';
import { ConfigModule } from '@nestjs/config';
import databaseConfig from './config/database.config';
import jwtConfig from './config/jwt.config';

@Module({
  imports: [
    ConfigModule.forRoot({
      isGlobal: true,
      load: [databaseConfig, jwtConfig],
    }),
  ],
})
export class AppModule {}

// auth.service.ts — Mengakses namespace
import { Injectable } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class AuthService {
  constructor(private configService: ConfigService) {
    const jwtSecret = this.configService.get<string>('jwt.secret');
    const expiresIn = this.configService.get<string>('jwt.expiresIn');
  }
}
```

**Kasus Penggunaan Nyata:** Module `DatabaseModule` mendaftarkan namespace database sendiri, terpisah dari `AuthModule` yang menggunakan namespace JWT.
