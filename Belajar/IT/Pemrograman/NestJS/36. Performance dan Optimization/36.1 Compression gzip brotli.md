# 36. Performance dan Optimization ## 36.1 Compression gzip brotli

**Definisi Singkat:** Kompresi HTTP mengurangi ukuran response dengan mengompres body menggunakan algoritma gzip atau brotli sebelum dikirim ke client. NestJS mendukung kompresi via middleware compression (Express) atau plugin (Fastify).

**Analogi:** Kompresi seperti menekan baju ke dalam koper vakum — baju yang sama jadi lebih kecil (60-80% lebih kecil), sehingga lebih banyak yang bisa dibawa dalam satu perjalanan (bandwidth lebih efisien). Client hanya perlu "mengeluarkan" (decompress) baju setelah sampai.

**Poin-Poin Penting:**
- **compression()** middleware Express
- **@fastify/compress** untuk Fastify
- **gzip** standar lama, kompatibilitas tinggi
- **brotli** rasio kompresi lebih baik, CPU lebih berat
- **Threshold** minimum size untuk kompresi
- **Accept-Encoding** content negotiation

**Contoh Kode:**
```typescript
// main.ts — Express dengan compression
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import * as compression from 'compression';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.use(
    compression({
      level: 6, // 0-9, higher = more compression but slower
      threshold: 1024, // min 1KB untuk dikompres
      filter: (req, res) => {
        if (req.headers['x-no-compression']) {
          return false;
        }
        return compression.filter(req, res);
      },
    }),
  );

  await app.listen(3000);
}
bootstrap();
```

```typescript
// main.ts — Fastify dengan @fastify/compress
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { FastifyAdapter } from '@nestjs/platform-fastify';
import compression from '@fastify/compress';

async function bootstrap() {
  const app = await NestFactory.create(
    AppModule,
    new FastifyAdapter(),
  );

  await app.register(compression, {
    global: true,
    encodings: ['br', 'gzip', 'deflate'],
    threshold: 1024,
    brotli: {
      quality: 4, // 0-11, brotli quality vs speed
    },
  });

  await app.listen(3000);
}
bootstrap();
```

```typescript
// compression.config.ts
export const compressionConfig = {
  level: 6,
  threshold: 1024,
  brotli: {
    enabled: true,
    quality: 4,
  },
  gzip: {
    enabled: true,
    level: 6,
  },
  // Skip kompresi untuk gambar/video yang sudah terkompres
  filter: (req, res) => {
    const contentType = res.getHeader('Content-Type');
    if (typeof contentType === 'string') {
      const skipTypes = ['image/', 'video/', 'audio/'];
      if (skipTypes.some((t) => contentType.startsWith(t))) {
        return false;
      }
    }
    return true;
  },
};
```

**Kasus Penggunaan Nyata:** REST API untuk mobile app — response JSON 500KB dikompres brotli jadi ~80KB, menghemat bandwidth dan mempercepat loading di jaringan seluler. Static assets (CSS, JS) juga dikompres dengan caching headers.
