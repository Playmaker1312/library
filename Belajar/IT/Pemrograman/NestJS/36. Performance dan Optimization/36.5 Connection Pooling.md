# 36. Performance dan Optimization ## 36.5 Connection Pooling

**Definisi Singkat:** Connection pooling adalah teknik menyimpan kumpulan koneksi database yang sudah jadi untuk digunakan kembali, menghindari overhead membuat koneksi baru setiap request. ORM seperti TypeORM dan Prisma sudah memiliki built-in connection pool.

**Analogi:** Connection pooling seperti taksi di stasiun — daripada setiap penumpang memesan taksi baru (membuat koneksi baru) yang butuh waktu tiba, pool taksi sudah siap menunggu. Saat penumpang datang, taksi langsung bisa digunakan. Setelah selesai, taksi kembali ke pool untuk penumpang berikutnya.

**Poin-Poin Penting:**
- **Pool size** jumlah maksimal koneksi simultan
- **Connection timeout** waktu maksimal menunggu koneksi
- **Idle timeout** koneksi tidak terpakai ditutup
- **Retry logic** ketika koneksi gagal
- **TypeORM DataSource** pool configuration
- **Prisma** connection limit di connection string

**Contoh Kode:**
```typescript
// database.config.ts
import { TypeOrmModuleOptions } from '@nestjs/typeorm';

export const databaseConfig: TypeOrmModuleOptions = {
  type: 'postgres',
  host: process.env.DB_HOST,
  port: parseInt(process.env.DB_PORT, 10) || 5432,
  username: process.env.DB_USER,
  password: process.env.DB_PASSWORD,
  database: process.env.DB_NAME,
  entities: [__dirname + '/**/*.entity{.ts,.js}'],

  // Connection Pool Configuration
  extra: {
    max: 20, // max connections in pool
    min: 4, // min connections in pool
    idleTimeoutMillis: 30000, // close idle connections after 30s
    connectionTimeoutMillis: 5000, // timeout after 5s
    maxUses: 7500, // recreate connection after usage
    validationQuery: 'SELECT 1',
    testOnBorrow: true,
  },

  // Query logging
  logging: process.env.NODE_ENV !== 'production',
  maxQueryExecutionTime: 1000, // log slow queries (>1s)
};
```

```typescript
// database.service.ts — monitoring connection pool
import { Injectable, Logger } from '@nestjs/common';
import { InjectDataSource } from '@nestjs/typeorm';
import { DataSource } from 'typeorm';

@Injectable()
export class DatabaseMonitorService {
  private readonly logger = new Logger(DatabaseMonitorService.name);

  constructor(@InjectDataSource() private dataSource: DataSource) {
    // Monitor pool size secara periodik
    setInterval(() => {
      const pool = this.dataSource.driver as any;
      if (pool && pool.master) {
        this.logger.log(`Pool total: ${pool.master.totalCount}, idle: ${pool.master.idleCount}, waiting: ${pool.master.waitingCount}`);
      }
    }, 60000);
  }
}
```

```typescript
// .env — database pool configuration
DB_HOST=localhost
DB_PORT=5432
DB_USER=myapp
DB_PASSWORD=strongpassword
DB_NAME=mydb
DB_POOL_MIN=4
DB_POOL_MAX=20
DB_POOL_IDLE_TIMEOUT=30000
DB_POOL_CONNECTION_TIMEOUT=5000
```

**Kasus Penggunaan Nyata:** API e-commerce dengan traffic spike saat flash sale — connection pool dikonfigurasi dengan max 50 connections, min 10 idle connections. Pool monitoring mendeteksi saat antrian menunggu > 5 (waitingCount), triggering auto-scaling database read replicas.
