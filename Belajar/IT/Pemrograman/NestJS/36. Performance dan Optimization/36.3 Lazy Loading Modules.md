# 36. Performance dan Optimization ## 36.3 Lazy Loading Modules

**Definisi Singkat:** Lazy loading modules memungkinkan modul NestJS dimuat hanya saat dibutuhkan (on-demand), bukan saat aplikasi startup. Ini mempercepat waktu startup awal dan mengurangi memory usage untuk fitur yang jarang digunakan.

**Analogi:** Lazy loading seperti membuka buku hanya pada halaman yang Anda butuhkan — tidak perlu membaca seluruh buku dari awal (startup lambat). Halaman yang jarang dibaca (admin panel, report) hanya dibuka saat benar-benar diperlukan.

**Poin-Poin Penting:**
- **LazyModuleLoader** class untuk load module
- **lazy import()** dynamic import JavaScript
- **@nestjs/core** LazyModuleLoader
- **onApplicationBootstrap** lifecycle
- **Module reference** untuk dynamic loading
- **Cache** module yang sudah di-load

**Contoh Kode:**
```typescript
// lazy.module.ts
import { Module } from '@nestjs/common';
import { LazyController } from './lazy.controller';
import { LazyService } from './lazy.service';

@Module({
  controllers: [LazyController],
  providers: [LazyService],
})
export class LazyModule {}
```

```typescript
// lazy.service.ts
import { Injectable } from '@nestjs/common';

@Injectable()
export class LazyService {
  getHello(): string {
    return 'Module loaded lazily!';
  }
}
```

```typescript
// lazy.controller.ts
import { Controller, Get } from '@nestjs/common';
import { LazyService } from './lazy.service';

@Controller('lazy')
export class LazyController {
  constructor(private readonly lazyService: LazyService) {}

  @Get()
  getHello() {
    return this.lazyService.getHello();
  }
}
```

```typescript
// app.module.ts
import { Module } from '@nestjs/common';
import { AppController } from './app.controller';
import { AppService } from './app.service';

@Module({
  controllers: [AppController],
  providers: [AppService],
})
export class AppModule {}
```

```typescript
// app.controller.ts
import { Controller, Get, Post } from '@nestjs/common';
import { LazyModuleLoader } from '@nestjs/core';

@Controller()
export class AppController {
  constructor(private lazyModuleLoader: LazyModuleLoader) {}

  @Post('load-lazy')
  async loadLazy() {
    // Lazy load module hanya saat endpoint ini dipanggil
    const moduleRef = await this.lazyModuleLoader.load(() =>
      import('./lazy/lazy.module').then((m) => m.LazyModule),
    );

    const lazyService = moduleRef.get(LazyService);
    return lazyService.getHello();
  }

  @Get('heavy-report')
  async getHeavyReport() {
    const moduleRef = await this.lazyModuleLoader.load(() =>
      import('./reports/reports.module').then((m) => m.ReportsModule),
    );

    const reportService = moduleRef.get(ReportsService);
    return reportService.generateReport();
  }
}
```

```typescript
// app.module.ts (dengan eager modules dan lazy modules)
import { Module } from '@nestjs/common';
import { CoreModule } from './core/core.module'; // dimuat saat startup
// LazyModule TIDAK diimpor di sini

@Module({
  imports: [CoreModule], // hanya module penting
  controllers: [AppController],
})
export class AppModule {}
```

**Kasus Penggunaan Nyata:** Aplikasi SaaS dengan fitur admin panel yang jarang diakses — admin module di-lazy-load hanya saat admin login. Fitur report generation yang berat juga di-lazy-load, mengurangi memory baseline dari 500MB ke 200MB.
