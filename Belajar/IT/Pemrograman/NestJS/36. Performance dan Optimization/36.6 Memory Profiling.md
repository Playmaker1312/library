# 36. Performance dan Optimization ## 36.6 Memory Profiling

**Definisi Singkat:** Memory profiling adalah proses menganalisis penggunaan memory aplikasi untuk mendeteksi memory leak, garbage collection issues, dan optimasi memory. Tools seperti clinic.js, heapdump, dan Chrome DevTools bisa digunakan dengan NestJS.

**Analogi:** Memory profiling seperti dokter yang melakukan cek kesehatan — mengukur tekanan darah (heap usage), detak jantung (GC frequency), dan mencari penyumbatan (memory leak) sebelum menjadi masalah serius.

**Poin-Poin Penting:**
- **clinic.js** memory profiling tool
- **heapdump** snapshot memory
- **Chrome DevTools** Memory tab
- **Node --inspect** flag untuk debugging
- **GC (Garbage Collection)** monitoring
- **Memory leak detection** dengan heap diff

**Contoh Kode:**

```typescript
// profiling.controller.ts
import { Controller, Get, Post } from '@nestjs/common';
import { ProfilingService } from './profiling.service';

@Controller('profiling')
export class ProfilingController {
  constructor(private readonly profilingService: ProfilingService) {}

  @Get('memory')
  getMemoryUsage() {
    const usage = process.memoryUsage();
    return {
      rss: `${Math.round(usage.rss / 1024 / 1024)} MB`,
      heapTotal: `${Math.round(usage.heapTotal / 1024 / 1024)} MB`,
      heapUsed: `${Math.round(usage.heapUsed / 1024 / 1024)} MB`,
      external: `${Math.round(usage.external / 1024 / 1024)} MB`,
    };
  }

  @Post('gc')
  triggerGC() {
    if (global.gc) {
      global.gc();
      return { message: 'GC triggered' };
    }
    return { message: 'GC not available — run with --expose-gc flag' };
  }

  @Get('heapdump')
  async takeHeapSnapshot() {
    return this.profilingService.takeHeapSnapshot();
  }
}
```

```typescript
// profiling.service.ts
import { Injectable, Logger } from '@nestjs/common';

@Injectable()
export class ProfilingService {
  private readonly logger = new Logger(ProfilingService.name);
  private memoryHistory: any[] = [];

  constructor() {
    // Monitor memory setiap 5 menit
    setInterval(() => {
      this.recordMemoryUsage();
    }, 300000);
  }

  private recordMemoryUsage() {
    const usage = process.memoryUsage();
    this.memoryHistory.push({
      timestamp: new Date().toISOString(),
      heapUsed: usage.heapUsed,
      heapTotal: usage.heapTotal,
      rss: usage.rss,
    });

    // Hanya simpan 100 entry terakhir
    if (this.memoryHistory.length > 100) {
      this.memoryHistory.shift();
    }

    // Alert jika memory usage > 80% dari heap total
    if (usage.heapUsed / usage.heapTotal > 0.8) {
      this.logger.warn('High memory usage detected!');
    }
  }
```

**Kasus Penggunaan Nyata:** Aplikasi real-time dashboard dengan Websocket — memory profiling menemukan bahwa setiap koneksi Websocket tidak dihapus dari Map setelah disconnect, menyebabkan memory leak 5MB/jam. Fix dengan cleanup listener di `OnGatewayDisconnect` lifecycle.
