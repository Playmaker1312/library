# 36. Performance dan Optimization ## 36.4 Database Query Optimization

**Definisi Singkat:** Database query optimization mencakup indexing, query planning, N+1 problem prevention, eager/lazy loading, pagination, dan penggunaan query builder yang efisien untuk mengurangi waktu response database.

**Analogi:** Query optimization seperti pustakawan yang merapikan buku — tanpa indeks (katalog), mencari buku butuh periksa satu per satu rak (full table scan). Dengan indeks, pustakawan langsung tahu di mana buku berada. Juga, mengambil semua buku terkait sekaligus (eager loading) lebih efisien daripada bolak-balik (N+1).

**Poin-Poin Penting:**
- **Database indexing** pada kolom yang sering di-query
- **Eager Loading** (relations) hindari N+1
- **Pagination** (skip/take) bukan get all
- **QueryBuilder** untuk query kompleks
- **Caching** query hasil yang sama
- **Select only needed columns** (tidak select *)

**Contoh Kode:**
```typescript
// user.service.ts — N+1 Problem (JANGAN)
@Injectable()
export class UserService {
  constructor(@InjectRepository(User) private repo: Repository<User>) {}

  async getUsersWithPostsBad(): Promise<User[]> {
    const users = await this.repo.find(); // 1 query
    for (const user of users) {
      user.posts = await this.postRepo.find({ where: { userId: user.id } });
      // N query — jika 100 users = 101 total queries!
    }
    return users;
  }
}
```

```typescript
// user.service.ts — Eager Loading (SOLUSI)
import { Injectable } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { User } from './user.entity';

@Injectable()
export class UserService {
  constructor(
    @InjectRepository(User)
    private readonly userRepository: Repository<User>,
  ) {}

  // EAGER LOADING — 1 query dengan JOIN
  async getUsersWithPosts(): Promise<User[]> {
    return this.userRepository.find({
      relations: ['posts', 'profile'],
      where: { isActive: true },
    });
  }

  // SELECT specific columns
  async getUserNames(): Promise<User[]> {
    return this.userRepository.find({
      select: ['id', 'name', 'email'],
      take: 100,
    });
  }

  // PAGINATION
  async getUsersPaginated(page: number, limit: number) {
    const [users, total] = await this.userRepository.findAndCount({
      skip: (page - 1) * limit,
      take: limit,
      order: { createdAt: 'DESC' },
    });

    return {
      data: users,
      total,
      page,
      totalPages: Math.ceil(total / limit),
    };
  }

  // QUERY BUILDER untuk complex queries
  async searchUsers(search: string) {
    return this.userRepository
      .createQueryBuilder('user')
      .leftJoinAndSelect('user.posts', 'post')
      .where('user.name LIKE :search', { search: `%${search}%` })
      .orWhere('user.email LIKE :search', { search: `%${search}%` })
      .andWhere('user.isActive = :active', { active: true })
      .orderBy('user.createdAt', 'DESC')
      .take(20)
      .getMany();
  }
}
```

```typescript
// post.entity.ts — Index dekorator
import { Entity, Column, Index, ManyToOne, JoinColumn } from 'typeorm';
import { User } from './user.entity';

@Entity()
@Index(['title', 'status']) // Composite index
export class Post {
  @PrimaryGeneratedColumn()
  id: number;

  @Index() // Index pada kolom yang sering di-filter
  @Column()
  title: string;

  @Column()
  content: string;

  @Index()
  @Column({ default: 'draft' })
  status: string;

  @Index()
  @Column()
  userId: number;

  @ManyToOne(() => User, (user) => user.posts)
  @JoinColumn({ name: 'userId' })
  user: User;
}
```

```typescript
import { Injectable } from '@nestjs/common';
import { InjectEntityManager } from '@nestjs/typeorm';
import { EntityManager } from 'typeorm';

@Injectable()
export class ProductService {
  constructor(@InjectEntityManager() private entityManager: EntityManager) {}

  async getExpensiveProducts() {
    return this.entityManager
      .createQueryBuilder(Product, 'product')
      .where('product.price > :price', { price: 1000 })

      .getMany();
  }
}
```
