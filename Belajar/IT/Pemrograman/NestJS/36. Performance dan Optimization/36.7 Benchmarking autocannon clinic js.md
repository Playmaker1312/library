# 36. Performance dan Optimization ## 36.7 Benchmarking autocannon clinic js

**Definisi Singkat:** Benchmarking tools seperti autocannon (load testing) dan clinic.js (performance profiling) digunakan untuk mengukur throughput, latency, dan mengidentifikasi bottleneck di aplikasi NestJS.

**Analogi:** Benchmarking seperti uji coba crash test mobil — Anda sengaja memberikan beban ekstrem (tabrakan) untuk melihat di mana titik lemahnya. Autocannon menabrakkan ribuan request, clinic.js menganalisis kerusakan (bottleneck).

**Poin-Poin Penting:**
- **autocannon** HTTP load testing tool
- **clinic.js** doctor, bubbleprof, flame
- **wrk** benchmarking tool
- **k6** scripting load testing
- **artillery** YAML-based load testing
- **Metrics** throughput (req/s), latency (ms), error rate

**Contoh Kode:**
```typescript
// benchmark/load-test.ts
import autocannon from 'autocannon';
import { PassThrough } from 'stream';

async function runBenchmark() {
  const instance = autocannon({
    url: 'http://localhost:3000',
    connections: 100, // concurrent connections
    duration: 30, // test duration in seconds
    requests: [
      {
        method: 'GET',
        path: '/api/users',
        headers: { 'Content-Type': 'application/json' },
      },
      {
        method: 'POST',
        path: '/api/users',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          name: 'Test User',
          email: 'test@example.com',
        }),
      },
    ],
    // Pipeline requests
    pipelining: 1,
    // Connection timeout
    timeout: 10,
  });

  // Events
  instance.on('tick', (counters) => {
    console.log(`Progress: ${counters.requests} requests`);
  });

  instance.on('done', (result) => {
    console.log('=== BENCHMARK RESULTS ===');
    console.log(`Duration: ${result.duration}s`);
    console.log(`Requests total: ${result.requests.total}`);
    console.log(`Throughput: ${result.requests.average} req/s`);
    console.log(`Latency average: ${result.latency.average} ms`);
    console.log(`Latency p99: ${result.latency.p99} ms`);
    console.log(`Errors: ${result.errors}`);
    console.log(`Timeouts: ${result.timeouts}`);
    console.log(`Throughput (bytes): ${result.throughput.average} bytes/s`);
  });

  autocannon.track(instance, { renderProgressBar: true });
}

runBenchmark();
```

**Kasus Penggunaan Nyata:** Tim backend melakukan benchmark setiap rilis — membandingkan throughput sebelum dan sesudah optimasi. Target: response time p99 < 200ms, throughput > 5000 req/s. Jika ada regresi performa, CI/CD pipeline otomatis reject deployment.
