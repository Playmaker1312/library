# 36. Performance dan Optimization ## 36.2 Fastify sebagai HTTP Adapter pengganti Express

**Definisi Singkat:** Fastify adalah HTTP framework untuk Node.js yang lebih cepat dari Express, dengan throughput hingga 2-3x lebih tinggi dan overhead lebih rendah. NestJS mendukung Fastify sebagai alternatif HTTP adapter via `@nestjs/platform-fastify`.

**Analogi:** Fastify seperti mobil sport dibanding Express yang seperti sedan keluarga — sama-sama bisa membawa Anda ke tujuan, tapi Fastify lebih ringan, lebih cepat, dan handling lebih responsif, terutama saat banyak permintaan (traffic padat).

**Poin-Poin Penting:**
- **@nestjs/platform-fastify** package adapter
- **FastifyAdapter** gantikan ExpressAdapter
- **2-3x lebih cepat** dari Express
- **Schema-based serialization** lebih cepat
- **Plugin ecosystem** @fastify/*
- **Hooks system** lifecycle request
- **Tidak kompatibel** dengan beberapa Express middleware

**Contoh Kode:**
```typescript
// main.ts — Fastify Adapter
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { FastifyAdapter, NestFastifyApplication } from '@nestjs/platform-fastify';

async function bootstrap() {
  const app = await NestFactory.create<NestFastifyApplication>(
    AppModule,
    new FastifyAdapter({
      logger: true,
      bodyLimit: 1048576, // 1MB max body
      // http2: true, // enable HTTP/2
    }),
  );

  app.enableCors({
    origin: ['http://localhost:3000'],
    credentials: true,
  });

  await app.listen(3000, '0.0.0.0');
}
bootstrap();
```

```typescript
// fastify-hooks.ts
import { Injectable } from '@nestjs/common';
import { FastifyInstance } from 'fastify';

@Injectable()
export class FastifyHooks {
  setupHooks(fastify: FastifyInstance) {
    fastify.addHook('onRequest', async (request, reply) => {
      // Log setiap request
      request.log.info(`Incoming request: ${request.method} ${request.url}`);
    });

    fastify.addHook('onSend', async (request, reply, payload) => {
      // Tambahkan header di response
      reply.header('X-Response-Time', reply.elapsedTime);
      return payload;
    });

    fastify.addHook('onError', async (request, reply, error) => {
      // Global error handler
      console.error('Fastify Error:', error);
    });
  }
}
```

**Kasus Penggunaan Nyata:** API gateway dengan ribuan request per detik — migrasi dari Express ke Fastify meningkatkan throughput dari ~15k ke ~40k requests/detik. NestJS tetap sama kodenya, hanya ganti adapter. Cocok untuk high-throughput microservices.
