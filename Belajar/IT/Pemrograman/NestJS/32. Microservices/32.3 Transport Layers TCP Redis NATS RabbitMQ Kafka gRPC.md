# 32. Microservices
## 32.3 Transport Layers TCP Redis NATS RabbitMQ Kafka gRPC
**Definisi Singkat:** NestJS microservices mendukung berbagai transport layer — TCP (sederhana), Redis pub/sub, NATS, RabbitMQ (message broker), Kafka (event streaming), dan gRPC (high-performance RPC).
**Analogi:** Seperti memilih kendaraan untuk mengirim paket — TCP seperti sepeda motor (langsung, sederhana), Redis seperti pos kilat (cepat, best-effort), RabbitMQ seperti kurir terorganisir (reliable, queue), Kafka seperti sistem pos massal (high-throughput, log-based), gRPC seperti mobil balap (cepat, strongly-typed).
**Poin-Poin Penting:**
- `Transport.TCP` — simple, langsung, tidak ada broker
- `Transport.REDIS` — pub/sub, lightweight
- `Transport.RABBITMQ` — message queue, reliable
- `Transport.KAFKA` — event streaming, high throughput
- `Transport.GRPC` — high performance, bidirectional streaming
**Contoh Kode:**
```typescript
// main.ts — berbagai transport layer

// TCP — simple, langsung ke IP:port
const tcpApp = await NestFactory.createMicroservice<MicroserviceOptions>(AppModule, {
  transport: Transport.TCP,
  options: {
    host: '0.0.0.0',
    port: 3001,
    retryAttempts: 5,
    retryDelay: 1000,
  },
});

// REDIS — pub/sub, butuh Redis server
const redisApp = await NestFactory.createMicroservice<MicroserviceOptions>(AppModule, {
  transport: Transport.REDIS,
  options: {
    host: 'localhost',
    port: 6379,
    retryAttempts: 5,
    retryDelay: 1000,
  },
});

// RABBITMQ — message broker lengkap
const rabbitApp = await NestFactory.createMicroservice<MicroserviceOptions>(AppModule, {
  transport: Transport.RMQ,
  options: {
    urls: ['amqp://guest:guest@localhost:5672'],
    queue: 'orders_queue',
    queueOptions: {
      durable: true,          // Queue survive restart
      deadLetterExchange: 'dlx', // Dead letter exchange
    },
    prefetchCount: 1,         // Ambil 1 message per kali
    noAck: false,             // Manual acknowledgment
  },
});

// KAFKA — event streaming platform
const kafkaApp = await NestFactory.createMicroservice<MicroserviceOptions>(AppModule, {
  transport: Transport.KAFKA,
  options: {
    client: {
      brokers: ['localhost:9092'],
      clientId: 'order-service',
    },
    consumer: {
      groupId: 'order-consumer',
      maxBytesPerPartition: 1048576,
    },
    subscribe: {
      fromBeginning: true,
    },
  },
});

// NATS — lightweight messaging
const natsApp = await NestFactory.createMicroservice<MicroserviceOptions>(AppModule, {
  transport: Transport.NATS,
  options: {
    servers: ['nats://localhost:4222'],
    queue: 'orders_queue',
  },
});

// gRPC — high performance RPC
const grpcApp = await NestFactory.createMicroservice<MicroserviceOptions>(AppModule, {
  transport: Transport.GRPC,
  options: {
    package: 'orders',
    protoPath: join(__dirname, 'orders.proto'),
    url: 'localhost:50051',
    loader: {
      keepCase: true,
      longs: String,
      enums: String,
      defaults: true,
      oneofs: true,
    },
  },
});
```
```typescript
// clients.module.ts — registrasi multiple clients
import { Module } from '@nestjs/common';
import { ClientsModule, Transport } from '@nestjs/microservices';

@Module({
  imports: [
    ClientsModule.register([
      {
        name: 'TCP_SERVICE',
        transport: Transport.TCP,
        options: { host: 'localhost', port: 3001 },
      },
      {
        name: 'REDIS_SERVICE',
        transport: Transport.REDIS,
        options: { host: 'localhost', port: 6379 },
      },
      {
        name: 'RABBITMQ_SERVICE',
        transport: Transport.RMQ,
        options: {
          urls: ['amqp://localhost:5672'],
          queue: 'main_queue',
        },
      },
      {
        name: 'KAFKA_SERVICE',
        transport: Transport.KAFKA,
        options: {
          client: { brokers: ['localhost:9092'] },
          consumer: { groupId: 'main-consumer' },
        },
      },
    ]),
  ],
})
export class ClientsModule {}
```
```typescript
// Perbandingan transport:
//
// Transport    Use Case                    Kelebihan              Kekurangan
// -------------------------------------------------------------------------
// TCP          Simple CRUD, internal       Gampang setup, no      Tidak reliable
//              low-traffic                 extra dependency       No message persistence
//
// Redis        Pub/sub, caching,           Cepat, ringan,         Pesan hilang jika
//              notifikasi real-time        mudah scale            consumer offline
//
// RabbitMQ     Reliable queue,             Pesan persistent,      Perlu RabbitMQ server
//              task distribution           ACK mechanism          Setup lebih kompleks
//
// Kafka        Event sourcing,             High throughput,       Overhead tinggi
//              streaming, log              replay capability      untuk traffic kecil
//
// NATS         Lightweight messaging,      Super cepat,           Fitur terbatas
//              IoT, real-time              mudah dioperasikan     dibanding RMQ/Kafka
//
// gRPC         Inter-service RPC,          Performa tinggi,       Butuh .proto files
//              high-performance API        strongly typed         Kompleksitas setup
```
**Kasus Penggunaan Nyata:** Sistem e-commerce microservices. Order service menggunakan RabbitMQ untuk mengirim task ke Inventory dan Payment service (reliable, persistent), Notification service menggunakan Redis pub/sub (best-effort, kecepatan tinggi), Analytics service menggunakan Kafka (high-throughput event streaming), dan inter-service queries menggunakan gRPC (low latency, typed contracts).
