# 32. Microservices
## 32.5 Event Pattern EventPattern
**Definisi Singkat:** `@EventPattern()` decorator menandai method sebagai handler untuk event — berbeda dengan `@MessagePattern()` yang request-response, event bersifat fire-and-forget (publisher tidak menunggu response).
**Analogi:** Seperti sirine ambulans — pengemudi ambulans (publisher) menyalakan sirine (event) tanpa tahu atau peduli siapa yang mendengar. Polisi, pengguna jalan, dan rumah sakit (consumers) mendengar sirine dan bertindak sesuai peran mereka.
**Poin-Poin Penting:**
- `@EventPattern('event-name')` — fire-and-forget
- Publisher: `client.emit('event', data)` — no response
- Cocok untuk notifikasi, logging, analytics
- Multiple consumer bisa handle event yang sama
**Contoh Kode:**
```typescript
// order.events.controller.ts — Event handler
import { Controller } from '@nestjs/common';
import { EventPattern, Payload, Ctx, RmqContext } from '@nestjs/microservices';

@Controller()
export class OrderEventsController {
  // Event handler — fire-and-forget
  // Tidak ada return value yang dikirim ke publisher
  @EventPattern('order_created')
  async handleOrderCreated(@Payload() data: any) {
    // Log event
    console.log(`[EVENT] Order dibuat: ${data.orderId}`);

    // Proses async — email, inventory, analytics
    await this.sendEmail(data);
    await this.updateInventory(data);
    await this.trackAnalytics(data);
  }

  @EventPattern('order_updated')
  async handleOrderUpdated(@Payload() data: any) {
    console.log(`[EVENT] Order diupdate: ${data.orderId}`);
  }

  @EventPattern('order_cancelled')
  async handleOrderCancelled(@Payload() data: any) {
    console.log(`[EVENT] Order dibatalkan: ${data.orderId}`);
    // Refund, release stock, kirim notifikasi
  }

  // Multiple handler untuk event yang sama — keduanya akan dipanggil
  @EventPattern('payment_completed')
  async updateOrderStatus(@Payload() data: any) {
    // Handler 1: Update status order
  }

  @EventPattern('payment_completed')
  async sendPaymentNotification(@Payload() data: any) {
    // Handler 2: Kirim notifikasi
  }
}
```

```typescript
// inventory.events.controller.ts — service lain handle event yang sama
@Controller()
export class InventoryEventsController {
  @EventPattern('order_created')
  async reserveStock(@Payload() data: any) {
    // Reserve stock untuk order baru
    console.log(`[INVENTORY] Reserve stock untuk order ${data.orderId}`);
  }

  @EventPattern('order_cancelled')
  async releaseStock(@Payload() data: any) {
    // Release stock untuk order yang dibatalkan
    console.log(`[INVENTORY] Release stock untuk order ${data.orderId}`);
  }
}
```

```typescript
// analytics.events.controller.ts — event untuk analytics
@Controller()
export class AnalyticsEventsController {
  // Catch-all event pattern — dengan wildcard
  @EventPattern('*')
  async logAllEvents(@Payload() data: any) {
    // Ini akan menangkap SEMUA event
    console.log(`[ANALYTICS] Event captured:`, data);
  }
}
```

```typescript
// Client side — emit event (fire-and-forget)
import { Injectable, Inject } from '@nestjs/common';
import { ClientProxy } from '@nestjs/microservices';

@Injectable()
export class OrderService {
  constructor(
    @Inject('ORDER_SERVICE') private client: ClientProxy,
  ) {}

  async placeOrder(orderData: any) {
    const order = await this.saveOrderToDatabase(orderData);

    // Emit event — TIDAK menunggu response dari consumer
    // Consumer akan memproses secara asynchronous
    this.client.emit('order_created', {
      orderId: order.id,
      userId: order.userId,
      items: order.items,
      total: order.total,
      timestamp: new Date(),
    });

    // Langsung return — tidak menunggu consumer selesai
    return order;
  }

  async cancelOrder(orderId: number) {
    await this.updateOrderStatus(orderId, 'cancelled');

    // Fire-and-forget event
    this.client.emit('order_cancelled', {
      orderId,
      reason: 'User requested cancellation',
      timestamp: new Date(),
    });
  }
}
```
```typescript
// @EventPattern vs @MessagePattern — perbandingan:
//
// Aspek            @MessagePattern          @EventPattern
// ------------------------------------------------------------
// Model            Request-Response         Fire-and-forget
// Return value     Yes — dikirim ke client  Tidak ada
// Blocking         Client menunggu          Client langsung lanjut
// Use case         CRUD, query             Notifikasi, logging
// Error effect     Return error ke client   Error di-log, proses lanjut
// Multiple consumer  Satu handler           Banyak handler bisa
//                   yang cocok              untuk event sama
//
// Pilih @MessagePattern saat:
// - Client butuh response (sukses/gagal)
// - Operasi synchronous yang butuh konfirmasi
// - Query data dari service lain
//
// Pilih @EventPattern saat:
// - Tidak perlu response
// - Ingin broadcast ke multiple consumers
// - Operasi background (email, analytics, logging)
```
**Kasus Penggunaan Nyata:** Saat user checkout di e-commerce, `order-service` emit event `order_placed`. Event ini di-handle oleh: `inventory-service` (reserve stock), `payment-service` (process payment), `notification-service` (send email), `analytics-service` (track conversion) — semua berjalan paralel tanpa menunggu satu sama lain.
