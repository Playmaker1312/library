# 32. Microservices
## 32.6 Hybrid Application HTTP dan Microservice
**Definisi Singkat:** Hybrid application adalah aplikasi NestJS yang berjalan sebagai HTTP server sekaligus microservice secara bersamaan, melayani request REST dan komunikasi internal dalam satu proses.
**Analogi:** Seperti restoran yang melayani dine-in (HTTP) dan juga menerima pesanan online (microservice). Dapur (logic) sama, tapi channel penyampaian berbeda — keduanya berjalan bersamaan.
**Poin-Poin Penting:**
- `app.createMicroservice()` untuk hybrid
- `app.connectMicroservice()` di main.ts
- Satu aplikasi bisa listen di HTTP + transport lain
- Berguna untuk transisi monolith ke microservices
**Contoh Kode:**
```typescript
// main.ts — Hybrid application: HTTP + TCP Microservice
import { NestFactory } from '@nestjs/core';
import { Transport, MicroserviceOptions } from '@nestjs/microservices';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // 1️⃣ HTTP Server (REST API)
  app.setGlobalPrefix('api');
  app.enableCors();

  // 2️⃣ Microservice TCP — untuk komunikasi internal
  app.connectMicroservice<MicroserviceOptions>({
    transport: Transport.TCP,
    options: {
      host: '0.0.0.0',
      port: 3001,
    },
  });

  // 3️⃣ Microservice Redis — untuk event pub/sub
  app.connectMicroservice<MicroserviceOptions>({
    transport: Transport.REDIS,
    options: {
      host: 'localhost',
      port: 6379,
    },
  });

  // 4️⃣ Microservice RabbitMQ — untuk reliable messaging
  app.connectMicroservice<MicroserviceOptions>({
    transport: Transport.RMQ,
    options: {
      urls: ['amqp://guest:guest@localhost:5672'],
      queue: 'hybrid_queue',
      queueOptions: { durable: true },
    },
  });

  // Start semua microservices
  await app.startAllMicroservices();

  // Start HTTP server
  await app.listen(3000);

  console.log(`🚀 HTTP server: http://localhost:3000/api`);
  console.log(`🔌 TCP microservice: localhost:3001`);
  console.log(`📨 Redis microservice: localhost:6379`);
  console.log(`🐰 RabbitMQ microservice: amqp://localhost:5672`);
}
bootstrap();
```
```typescript
// users.controller.ts — hybrid: REST + MessagePattern
import { Controller, Get, Post, Body } from '@nestjs/common';
import { MessagePattern, Payload } from '@nestjs/microservices';
import { UsersService } from './users.service';

@Controller('users')  // REST endpoint
export class UsersController {
  constructor(private readonly usersService: UsersService) {}

  // 🔵 REST endpoint — diakses via HTTP
  @Get()
  async findAll() {
    return this.usersService.findAll();
  }

  @Post()
  async create(@Body() createUserDto: any) {
    return this.usersService.create(createUserDto);
  }

  // 🟢 Microservice message handler — diakses via TCP/Redis/RMQ
  @MessagePattern({ cmd: 'get_users' })
  async getUsersViaMessage(@Payload() data: any) {
    return this.usersService.findAll(data);
  }

  @MessagePattern({ cmd: 'create_user' })
  async createUserViaMessage(@Payload() data: any) {
    return this.usersService.create(data);
  }

  // 🟡 Event handler — fire-and-forget
  @EventPattern('user_created')
  async handleUserCreated(@Payload() data: any) {
    console.log(`[EVENT] User created via microservice:`, data);
  }
}
```
```typescript
// hybrid.module.ts — module dengan hybrid strategy
import { Module } from '@nestjs/common';
import { UsersModule } from './users/users.module';
import { OrdersModule } from './orders/orders.module';
import { ClientsModule, Transport } from '@nestjs/microservices';

@Module({
  imports: [
    UsersModule,   // Service yang punya HTTP + MessagePattern
    OrdersModule,  // Service yang punya HTTP + MessagePattern

    // Client untuk komunikasi antar komponen hybrid
    ClientsModule.register([
      {
        name: 'HYBRID_SERVICE',
        transport: Transport.TCP,
        options: { host: 'localhost', port: 3001 },
      },
    ]),
  ],
})
export class AppModule {}
```
```typescript
// app.controller.ts — contoh penggunaan hybrid
import { Controller, Get, Inject } from '@nestjs/common';
import { ClientProxy } from '@nestjs/microservices';

@Controller()
export class AppController {
  constructor(
    @Inject('HYBRID_SERVICE') private client: ClientProxy,
    private readonly usersService: UsersService,
  ) {}

  @Get('internal-users')
  async getInternalUsers() {
    // HTTP endpoint ini memanggil microservice INTERNAL
    // (yang sebenernya ada di aplikasi yang sama)
    const result = await this.client
      .send({ cmd: 'get_users' }, {})
      .toPromise();
    return result;
  }

  @Get('external-users')
  async getExternalUsers() {
    // Langsung panggil service (tanpa microservice)
    return this.usersService.findAll();
  }
}
```
**Kasus Penggunaan Nyata:** Strategi migrasi monolith-to-microservices. Tim memulai dengan hybrid — satu aplikasi NestJS melayani HTTP dan juga terhubung ke message broker. Perlahan-lahan, fitur di-extract ke aplikasi terpisah. Hybrid memungkinkan transisi bertahap tanpa "big bang rewrite".
