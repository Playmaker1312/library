# 32. Microservices
## 32.4 Message Pattern MessagePattern
**Definisi Singkat:** `@MessagePattern()` decorator menandai method sebagai handler untuk pesan request-response — client mengirim pesan, microservice memproses, dan mengembalikan response (mirip seperti HTTP request-response).
**Analogi:** Seperti teller bank — Anda mengirim slip permintaan (message request) ke teller, teller memproses (transaksi), lalu mengembalikan tanda terima (response). Proses ini synchronous — Anda tunggu sampai selesai.
**Poin-Poin Penting:**
- `@MessagePattern(pattern)` — string atau object pattern
- Method return value dikirim sebagai response
- `@Payload()` untuk akses data
- `@Ctx()` untuk akses context
**Contoh Kode:**
```typescript
// orders.controller.ts — MessagePattern handler
import { Controller } from '@nestjs/common';
import { MessagePattern, Payload, Ctx, RmqContext } from '@nestjs/microservices';

@Controller()
export class OrdersController {
  // Pattern sederhana — string
  @MessagePattern('get_orders')
  async getOrders(@Payload() data: { userId: number }) {
    // Proses dan return response
    return { orders: [], total: 0 };
  }

  // Pattern kompleks — object
  @MessagePattern({ cmd: 'create_order', version: 2 })
  async createOrder(@Payload() data: any) {
    // Versi 2 dari create order
    return { id: Date.now(), ...data, version: 2 };
  }

  // Pattern dengan context — untuk RabbitMQ ACK
  @MessagePattern('process_payment')
  async processPayment(
    @Payload() data: { orderId: number; amount: number },
    @Ctx() context: RmqContext,
  ) {
    try {
      // Proses pembayaran
      const result = { success: true, transactionId: 'TXN-123' };

      // Manual ACK untuk RabbitMQ
      const channel = context.getChannelRef();
      const originalMsg = context.getMessage();
      channel.ack(originalMsg);

      return result;
    } catch (error) {
      // NACK — message akan di-re-queue
      const channel = context.getChannelRef();
      const originalMsg = context.getMessage();
      channel.nack(originalMsg, false, true); // requeue = true
      throw error;
    }
  }

  // Pattern dengan wildcard/namespace
  @MessagePattern('user.*')  // Akan menangkap 'user.get', 'user.update', dll
  async handleUserEvents(@Payload() data: any) {
    return { handled: true, pattern: 'user.*' };
  }
}
```
```typescript
// Multiple handlers untuk pattern yang sama — dengan konteks berbeda
@Controller()
export class InventoryController {
  @MessagePattern({ cmd: 'check_stock' })
  async checkStock(@Payload() data: { productId: number }) {
    return { available: true, quantity: 10 };
  }

  // Response streaming — Observable
  @MessagePattern('stream_updates', { transport: Transport.TCP })
  async streamUpdates(@Payload() data: any) {
    // Bisa return Observable untuk streaming
    return { message: 'Streaming not applicable here' };
  }
}
```
```typescript
// Client side — cara mengirim message dan menerima response
import { Injectable, Inject } from '@nestjs/common';
import { ClientProxy } from '@nestjs/microservices';
import { lastValueFrom } from 'rxjs';

@Injectable()
export class OrderClient {
  constructor(@Inject('ORDER_SERVICE') private client: ClientProxy) {}

  async getOrders(userId: number) {
    // Kirim pesan 'get_orders' dan tunggu response
    const result = await lastValueFrom(
      this.client.send('get_orders', { userId })
    );
    return result;
  }

  async createOrder(data: any) {
    // Kirim dengan pattern object
    const result = await lastValueFrom(
      this.client.send({ cmd: 'create_order', version: 2 }, data)
    );
    return result;
  }

  async checkHealth() {
    try {
      const result = await lastValueFrom(
        this.client.send('ping', {}),
        { defaultValue: null }
      );
      return { status: 'ok', result };
    } catch {
      return { status: 'error' };
    }
  }
}
```
```typescript
// Request-response lifecycle:
//
// 1. Client panggil: client.send({ cmd: 'create_order' }, orderData)
// 2. ClientProxy membuat koneksi ke microservice
// 3. Kirim pattern + payload via transport (TCP/RMQ/Kafka...)
// 4. Microservice terima, cari handler dengan @MessagePattern yang cocok
// 5. Handler dieksekusi dengan payload
// 6. Return value dikirim kembali ke client sebagai response
// 7. Client menerima response via Observable
// 8. lastValueFrom() mengkonversi Observable ke Promise
```
**Kasus Penggunaan Nyata:** Service `API Gateway` menerima request HTTP dari client, lalu menggunakan `ClientProxy.send()` ke berbagai microservices — `order-service` untuk create order, `payment-service` untuk proses pembayaran, `user-service` untuk data user. Gateway mengagregasi response dan mengembalikan ke client.
