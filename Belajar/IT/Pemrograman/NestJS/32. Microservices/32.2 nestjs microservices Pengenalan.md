# 32. Microservices
## 32.2 nestjs microservices Pengenalan
**Definisi Singkat:** `@nestjs/microservices` adalah modul resmi untuk membangun microservices di NestJS, menyediakan abstraksi transport layer (TCP, Redis, NATS, RabbitMQ, Kafka, gRPC) dan decorator untuk message/event handling.
**Analogi:** Seperti sistem POS di mal — setiap toko (microservice) punya mesin POS sendiri, tapi semua terhubung ke jaringan yang sama. `@nestjs/microservices` menyediakan standar komunikasi antar mesin POS tersebut.
**Poin-Poin Penting:**
- `@nestjs/microservices` package
- Transport strategy: TCP, Redis, NATS, RabbitMQ, Kafka, gRPC
- `@MessagePattern()` dan `@EventPattern()`
- `ClientProxy` untuk komunikasi dari service lain
**Contoh Kode:**
```typescript
// math-service/main.ts — Microservice sederhana dengan TCP
import { NestFactory } from '@nestjs/core';
import { Transport, MicroserviceOptions } from '@nestjs/microservices';
import { MathModule } from './math.module';

async function bootstrap() {
  // Buat microservice dengan transport TCP
  const app = await NestFactory.createMicroservice<MicroserviceOptions>(
    MathModule,
    {
      transport: Transport.TCP,  // Transport layer: TCP
      options: {
        host: '127.0.0.1',
        port: 3001,
      },
    },
  );

  await app.listen();
  console.log('Math microservice berjalan di port 3001');
}
bootstrap();
```

```typescript
// math/math.controller.ts — Message handler
import { Controller } from '@nestjs/common';
import { MessagePattern, Payload } from '@nestjs/microservices';

@Controller()
export class MathController {
  @MessagePattern({ cmd: 'add' })  // Pattern-based message
  accumulate(@Payload() data: number[]): number {
    return (data || []).reduce((a, b) => a + b, 0);
  }

  @MessagePattern({ cmd: 'multiply' })
  multiply(@Payload() data: { a: number; b: number }): number {
    return data.a * data.b;
  }

  @MessagePattern({ cmd: 'ping' })  // Health check
  ping(): string {
    return 'pong';
  }
}
```
```typescript
// Client — cara memanggil microservice
// app.module.ts (client app)
import { Module } from '@nestjs/common';
import { ClientsModule, Transport } from '@nestjs/microservices';
import { AppController } from './app.controller';

@Module({
  imports: [
    ClientsModule.register([
      {
        name: 'MATH_SERVICE',  // Token untuk injection
        transport: Transport.TCP,
        options: {
          host: '127.0.0.1',
          port: 3001,
        },
      },
    ]),
  ],
  controllers: [AppController],
})
export class AppModule {}
```
```typescript
// app.controller.ts — panggil microservice
import { Controller, Get, Inject } from '@nestjs/common';
import { ClientProxy } from '@nestjs/microservices';

@Controller()
export class AppController {
  constructor(@Inject('MATH_SERVICE') private client: ClientProxy) {}

  @Get('add')
  async add() {
    // Kirim pesan ke microservice dan tunggu response
    const result = await this.client.send(
      { cmd: 'add' },      // Pattern
      [1, 2, 3, 4, 5],     // Payload
    ).toPromise();

    return { result };  // { result: 15 }
  }

  @Get('ping')
  async ping() {
    return this.client.send({ cmd: 'ping' }, {}).toPromise();
  }
}
```
**Kasus Penggunaan Nyata:** Aplikasi dengan service komputasi berat (misal: image processing, PDF generation, complex calculation). Service utama HTTP tetap responsif dengan mengirim task ke microservice via TCP, dan microservice memproses secara独立 tanpa mempengaruhi performa main API.
