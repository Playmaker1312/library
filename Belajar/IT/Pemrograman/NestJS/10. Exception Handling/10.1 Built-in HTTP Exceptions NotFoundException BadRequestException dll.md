# 10. Exception Handling

## 10.1. Built-in HTTP Exceptions NotFoundException BadRequestException dll

**Definisi Singkat:** NestJS menyediakan class exception bawaan yang otomatis menghasilkan HTTP response dengan status code yang sesuai.

**Analogi:** Seperti menu restoran — tinggal pilih mau error 400, 404, atau 500, semuanya sudah disediakan.

**Poin-Poin Penting:**
- `BadRequestException` — 400
- `UnauthorizedException` — 401
- `ForbiddenException` — 403
- `NotFoundException` — 404
- `ConflictException` — 409
- `InternalServerErrorException` — 500
- Semua extend `HttpException`

**Contoh Kode:**
```typescript
import { NotFoundException, BadRequestException, UnauthorizedException } from '@nestjs/common';

@Get(':id')
findOne(@Param('id') id: string) {
  const user = this.userService.findById(id);
  if (!user) {
    throw new NotFoundException(`User dengan id ${id} tidak ditemukan`);
  }
  return user;
}

@Post()
create(@Body() dto: CreateUserDto) {
  if (dto.password.length < 6) {
    throw new BadRequestException('Password minimal 6 karakter');
  }
}
```

**Kasus Penggunaan Nyata:** Saat user mencari data yang tidak ada, `NotFoundException` mengembalikan response JSON `{ "statusCode": 404, "message": "User dengan id 5 tidak ditemukan", "error": "Not Found" }`.
