# 10. Exception Handling

## 10.4. Exception Filters Catch

**Definisi Singkat:** Exception Filter adalah class yang menangkap exception dan mengubahnya menjadi response yang terkontrol menggunakan `@Catch()`.

**Analogi:** Sejak seperti jaring pengaman — semua error yang jatuh tertangkap dan diatur, tidak ada yang jatuh ke lantai.

**Poin-Poin Penting:**
- Decorator `@Catch(ExceptionType)` menentukan jenis exception
- Implement `ExceptionFilter` interface
- Method `catch(exception, host)` berisi logika penanganan
- Bisa menangkap satu atau banyak jenis exception
- Mengakses `ArgumentsHost` untuk response context

**Contoh Kode:**
```typescript
import { ExceptionFilter, Catch, ArgumentsHost, HttpException } from '@nestjs/common';
import { Response } from 'express';

@Catch(HttpException)
export class HttpExceptionFilter implements ExceptionFilter {
  catch(exception: HttpException, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();
    const status = exception.getStatus();

    response.status(status).json({
      statusCode: status,
      message: exception.message,
      timestamp: new Date().toISOString(),
    });
  }
}
```

**Kasus Penggunaan Nyata:** Exception Filter digunakan untuk menangkap `BusinessException` dan mengubahnya menjadi response JSON konsisten dengan field `errorCode` yang bisa diparsing oleh frontend.
