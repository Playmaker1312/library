# 10. Exception Handling

## 10.5. Global Exception Filter useGlobalFilters

**Definisi Singkat:** Mendaftarkan Exception Filter secara global agar menangani semua exception di seluruh aplikasi.

**Analogi:** Seperti CCTV di seluruh gedung — semua kejadian terpantau dari satu pusat kontrol.

**Poin-Poin Penting:**
- Daftarkan di `main.ts` dengan `app.useGlobalFilters(new Filter())`
- Bisa juga dengan decorator `@UseFilters()` di controller/method
- Global filter menangani semua exception dari semua module
- Bisa multiple filter untuk exception berbeda
- Urutan: method > controller > global filter

**Contoh Kode:**
```typescript
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { HttpExceptionFilter } from './common/filters/http-exception.filter';
import { AllExceptionsFilter } from './common/filters/all-exceptions.filter';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // Global filters
  app.useGlobalFilters(
    new AllExceptionsFilter(),    // catch all
    new HttpExceptionFilter(),    // HTTP specific
  );

  await app.listen(3000);
}
bootstrap();
```

**Kasus Penggunaan Nyata:** `AllExceptionsFilter` global memastikan error yang tidak terduga (misal database timeout) tetap mengembalikan response JSON rapi `{ statusCode: 500, message: "Internal server error" }` bukan HTML `500` bawaan Express.
