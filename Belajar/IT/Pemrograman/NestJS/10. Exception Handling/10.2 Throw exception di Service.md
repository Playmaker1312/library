# 10. Exception Handling

## 10.2. Throw exception di Service

**Definisi Singkat:** Exception dilempar dari Service layer, bukan Controller, agar business logic dan error handling terpusat.

**Analogi:** Seperti pegawai pabrik yang menemukan barang rusak — langsung lapor, bukan menunggu atasan yang nanya.

**Poin-Poin Penting:**
- Service melempar exception jika kondisi tidak terpenuhi
- Controller tidak perlu try-catch untuk error bisnis
- Exception Filter akan menangani sisanya
- Membuat service lebih aman dan predictable
- Pisahkan validation error dari business logic error

**Contoh Kode:**
```typescript
import { Injectable, NotFoundException, ConflictException } from '@nestjs/common';

@Injectable()
export class UserService {
  private users = [];

  findById(id: string) {
    const user = this.users.find(u => u.id === id);
    if (!user) {
      throw new NotFoundException(`User ${id} tidak ditemukan`);
    }
    return user;
  }

  create(dto: CreateUserDto) {
    const exists = this.users.find(u => u.email === dto.email);
    if (exists) {
      throw new ConflictException('Email sudah terdaftar');
    }
    // logic create user...
  }
}
```

**Kasus Penggunaan Nyata:** Service `UserService.findById()` melempar `NotFoundException` jika user tidak ada, sehingga Controller hanya perlu memanggil method tersebut tanpa khawatir menangani error manual.
