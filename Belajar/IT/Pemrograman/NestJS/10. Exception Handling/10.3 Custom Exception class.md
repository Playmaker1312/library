# 10. Exception Handling

## 10.3. Custom Exception class

**Definisi Singkat:** Membuat class exception kustom dengan extend `HttpException` untuk error spesifik aplikasi dengan properti tambahan.

**Analogi:** Seperti membuat jenis alarm khusus — bukan hanya "kebakaran" tapi "kebakaran di lantai 3, sayap barat".

**Poin-Poin Penting:**
- Extend class `HttpException`
- Bisa menambah properti kustom (error code, timestamp, dll)
- Constructor menerima message dan status code
- Mempermudah penanganan error terpusat
- Memberikan konteks lebih pada error

**Contoh Kode:**
```typescript
import { HttpException, HttpStatus } from '@nestjs/common';

export class BusinessException extends HttpException {
  public readonly errorCode: string;

  constructor(message: string, errorCode: string, status: HttpStatus = HttpStatus.BAD_REQUEST) {
    super({ message, errorCode, status }, status);
    this.errorCode = errorCode;
  }
}

// Penggunaan
export class PaymentService {
  processPayment(amount: number) {
    if (amount <= 0) {
      throw new BusinessException(
        'Jumlah pembayaran tidak valid',
        'INVALID_AMOUNT',
        HttpStatus.BAD_REQUEST,
      );
    }
  }
}
```

**Kasus Penggunaan Nyata:** Di sistem pembayaran, `BusinessException` dengan `errorCode` seperti `INSUFFICIENT_BALANCE` atau `PAYMENT_EXPIRED` memudahkan frontend menampilkan pesan error yang sesuai bahasa Indonesia.
