# 237. Memahami TypeScript Performance Wiki **Definisi Singkat:** TypeScript Performance Wiki adalah dokumentasi resmi yang mengumpulkan tips, trik, dan praktik terbaik untuk menjaga kecepatan kompilasi. **Analogi:** Performance wiki seperti buku manual mobil—memberi tahu cara merawat mesin agar tetap bertenaga dan tidak cepat rusak. **Poin-Poin Penting:** - Tersedia di GitHub microsoft/TypeScript/wiki/Performance - Mencakup preactice type, project references, incremental build - Harus dibaca tim sebelum codebase mencapai 100k+ baris **Contoh Kode:** ```typescript // BENAR: // Prefer interface over type intersection for better performance interface User { name: string; } interface Admin extends User { role: string; } // ERROR: // Menghindari pattern yang lambat: type User = { name: string } type Admin = User & { role: string }; // Intersection lebih lambat ``` **Kasus Penggunaan Nyata:** Tim engineering yang mengelola codebase besar (>500k lines) dan ingin mempertahankan waktu kompilasi di bawah 30 detik.
