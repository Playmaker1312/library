# 243. Tips menghindari deep recursive types **Definisi Singkat:** TypeScript memiliki batas kedalaman rekursi tipe (~50 level)—melampauinya menyebabkan error "Type instantiation is excessively deep". **Analogi:** Deep recursive type seperti lubang kelinci Alice in Wonderland—semakin dalam Anda masuk, semakin sulit kembali, dan kompiler akan berhenti sebelum tenggelam. **Poin-Poin Penting:** - Batasi rekursi maksimal 10-20 level untuk aman - Gunakan iterasi dengan mapped types jika memungkinkan - Tail-recursive types di TypeScript 4.5+ lebih efisien **Contoh Kode:** ```typescript // BENAR: type TupleOf<T, N extends number, Acc extends any[] = []> = Acc["length"] extends N ? Acc : TupleOf<T, N, [...Acc, T]>; type ThreeStrings = TupleOf<string, 3>; // [string, string, string] // ERROR: type DeepRecursive<T> = T extends object ? { [K in keyof T]: DeepRecursive<T[K]> } : T; // Jika terlalu dalam >50, error: type instantiation is excessively deep ``` **Kasus Penggunaan Nyata:** JSON validator di level tipe—membatasi kedalaman maksimum rekursi untuk mencegah crash kompiler saat menerima input JSON bersarang tak terbatas.
