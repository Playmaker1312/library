# 240. Profiling TypeScript compiler - diagnostics extendedDiagnostics **Definisi Singkat:** Flag `--extendedDiagnostics` menampilkan statistik detail tentang waktu kompilasi, jumlah tipe, dan penggunaan memori. **Analogi:** extendedDiagnostics seperti dashboard mobil—menunjukkan RPM, kecepatan, suhu mesin, dan konsumsi bahan bakar secara real-time. **Poin-Poin Penting:** - Aktifkan dengan `tsc --extendedDiagnostics` - Menampilkan: Files, Lines, Identifiers, Symbols, Types, Instantiations - Berguna untuk mengidentifikasi bottleneck kompilasi **Contoh Kode:** ```typescript // BENAR: // Jalankan di terminal: // tsc --extendedDiagnostics // Output: // Files:             150 // Lines:           45000 // Identifiers:     32000 // Symbols:         28000 // Types:           12000 // Instantiations: 89000 // Memory used:   245000K // ERROR: // Tidak ada flag diagnostics di tsconfig.json → harus via CLI ``` **Kasus Penggunaan Nyata:** Sebelum dan sesudah optimasi, jalankan `--extendedDiagnostics` untuk mengukur dampak perubahan pada performa kompilasi.
