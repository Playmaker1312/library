# 239. Interface vs Type - dampak performa **Definisi Singkat:** Interface dan type alias memiliki perbedaan performa kompilasi—interface umumnya lebih cepat karena deklarasi merging dan caching yang lebih efisien. **Analogi:** Interface seperti lemari dengan rak tetap—TypeScript bisa langsung tahu di mana mencari, sedangkan type alias seperti tumpukan kertas yang perlu diurai ulang setiap kali. **Poin-Poin Penting:** - Interface bisa di-merging dan di-cache lebih baik - Type intersections (`&`) lebih lambat daripada `extends` - Gunakan interface untuk object shapes, type untuk union/utility **Contoh Kode:** ```typescript // BENAR: (lebih cepat) interface User { name: string } interface Admin extends User { role: string } // ERROR: (lebih lambat) type User = { name: string } type Admin = User & { role: string }; // Intersection lebih berat ``` **Kasus Penggunaan Nyata:** Di codebase besar dengan ribuan tipe, migrasi dari type intersections ke interface bisa memangkas waktu kompilasi 20-30%.
