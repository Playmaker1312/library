# 245. Project References untuk monorepo besar **Definisi Singkat:** Project References memungkinkan struktur TypeScript dipecah menjadi proyek-proyek kecil yang bisa dikompilasi secara independen dan incremental. **Analogi:** Project References seperti membagi novel tebal menjadi beberapa bab—Anda bisa membaca (mengompilasi) bab 5 tanpa harus membaca ulang bab 1-4. **Poin-Poin Penting:** - Setiap sub-proyek punya tsconfig sendiri dengan `composite: true` - Proyek root memiliki `references` ke sub-proyek - Build dengan flag `--build` untuk kompilasi incremental **Contoh Kode:** ```typescript // BENAR: // packages/core/tsconfig.json { "compilerOptions": { "composite": true, "outDir": "./dist" } } // packages/ui/tsconfig.json { "compilerOptions": { "composite": true, "outDir": "./dist" }, "references": [{ "path": "../core" }] } // Root tsconfig.json { "files": [], "references": [ { "path": "./packages/core" }, { "path": "./packages/ui" } ] } // Build: tsc --build // ERROR: // Lupa set composite: true → error "rootDir is expected to contain all source files" ``` **Kasus Penggunaan Nyata:** Monorepo dengan shared core library, beberapa aplikasi frontend, dan backend service—masing-masing bisa dikompilasi terpisah.
