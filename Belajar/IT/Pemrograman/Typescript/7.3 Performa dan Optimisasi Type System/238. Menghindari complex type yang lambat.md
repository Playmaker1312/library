# 238. Menghindari complex type yang lambat **Definisi Singkat:** Complex types yang melibatkan rekursi dalam, distribusi conditional, atau conditional type bersarang dapat memperlambat kompiler secara drastis. **Analogi:** Complex type seperti teka-teki labirin yang sangat rumit—kompiler harus menjelajahi setiap jalur untuk menemukan jawaban, memakan waktu dan memori. **Poin-Poin Penting:** - Batasi kedalaman rekursi tipe (<10 level) - Hindari distributive conditional types pada union besar - Gunakan type alias sederhana dan modular **Contoh Kode:** ```typescript // BENAR: type SimpleFlatten<T> = T extends Array<infer U> ? U : T; type Simple = SimpleFlatten<string[]>; // string // ERROR: // Distributive conditional pada union besar sangat lambat type Slow<T> = T extends string ? T : T extends number ? T : T extends boolean ? T : T extends symbol ? T : never; type Huge = Slow<string | number | boolean | symbol | null | undefined>; ``` **Kasus Penggunaan Nyata:** Memigrasi ulang conditional types kompleks di library utility types yang menyebabkan waktu kompilasi >10 detik hanya untuk satu deklarasi.
