# 242. Tips mengurangi type instantiation **Definisi Singkat:** Setiap kali TypeScript mengevaluasi generic type, itu membuat instantiation baru—semakin banyak instantiation, semakin lambat kompilasi. **Analogi:** Type instantiation seperti mencetak dokumen—setiap kali Anda mencetak ulang dokumen yang sama, printer perlu memproses dari awal, boros waktu dan tinta. **Poin-Poin Penting:** - Hindari generic yang menghasilkan banyak varian unik - Gunakan type alias untuk men-cache hasil evaluasi - Batasi penggunaan conditional types pada union besar **Contoh Kode:** ```typescript // BENAR: // Pre-compute type alias (cache) type Cached<T> = T extends any ? { value: T } : never; type Result = Cached<string>; // instantiated sekali // ERROR: // Inline berkali-kali menyebabkan multiple instantiation function bad<T>(x: T): T extends any ? { value: T } : never { return { value: x } as any; } // Setiap panggilan membuat instantiation baru ``` **Kasus Penggunaan Nyata:** Library yang mengekspor generic utility types—menggunakan type alias internal untuk caching mengurangi waktu kompilasi pengguna library.
