# 244. Optimizing large codebases **Definisi Singkat:** Codebase besar (>500k baris) memerlukan strategi khusus untuk menjaga waktu kompilasi tetap cepat dan produktivitas tim tinggi. **Analogi:** Mengelola codebase besar seperti mengelola kota—butuh tata kota (arsitektur), jalan tol (project references), dan transportasi umum (incremental build). **Poin-Poin Penting:** - Gunakan Project References untuk memecah monolit - Aktifkan `incremental` dan `skipLibCheck` - Batasi penggunaan `strict` di area kritis saja **Contoh Kode:** ```typescript // BENAR: // tsconfig.json { "compilerOptions": { "incremental": true, "skipLibCheck": true, "outDir": "./dist" }, "references": [ { "path": "./packages/core" }, { "path": "./packages/ui" } ] } // ERROR: // Satu tsconfig untuk seluruh monorepo tanpa references → semua file dikompilasi ulang setiap kali ``` **Kasus Penggunaan Nyata:** Monorepo besar dengan 50+ package—setiap package punya tsconfig sendiri dengan references, kompilasi hanya package yang berubah.
