# 241. Tracing type resolution - generateTrace **Definisi Singkat:** Flag `--generateTrace` menghasilkan file trace yang bisa divisualisasikan dengan Chrome DevTools untuk melihat proses resolusi tipe. **Analogi:** generateTrace seperti rekaman CCTV—Anda bisa memutar ulang dan melihat persis apa yang dilakukan kompiler langkah demi langkah. **Poin-Poin Penting:** - Jalankan: `tsc --generateTrace traceDir` - Visualisasikan di `chrome://tracing` - Mengidentifikasi type instantiation yang berlebihan **Contoh Kode:** ```typescript // BENAR: // Terminal: // tsc --generateTrace ./trace // // Lalu buka Chrome → chrome://tracing → Load trace file // // Lihat flame chart untuk type resolution bottlenecks // ERROR: // Menjalankan generateTrace di production → overhead tidak perlu ``` **Kasus Penggunaan Nyata:** Mengidentifikasi penyebab "Type instantiation is excessively deep and possibly infinite" dengan melihat stack trace resolusi tipe di visualizer.
