# 246. Strategi migrasi JavaScript ke TypeScript **Definisi Singkat:** Migrasi JS→TS adalah proses bertahap mengubah basis kode JavaScript menjadi TypeScript dengan gangguan minimal pada produktivitas tim. **Analogi:** Migrasi seperti merenovasi rumah sambil tetap tinggal di dalamnya—Anda perbaiki kamar demi kamar tanpa harus pindah sementara. **Poin-Poin Penting:** - Mulai dari bagian paling kritis dan stabil - Gunakan `allowJs` untuk campuran JS/TS - Prioritaskan modul dengan banyak bug atau sering berubah **Contoh Kode:** ```typescript // BENAR: // Langkah 1: Rename .js ke .ts, biarkan ada error // Langkah 2: Tambah // @ts-nocheck di file yang belum siap // Langkah 3: Aktifkan strict secara bertahap per file // Langkah 4: Hapus @ts-nocheck saat file sudah aman // ERROR: // Migrasi all-at-once → tim berhenti produksi berminggu-minggu ``` **Kasus Penggunaan Nyata:** Startup dengan codebase 200k baris JavaScript—migrasi 5-10 file per sprint, dalam 6 bulan seluruh codebase sudah TypeScript terverifikasi.
