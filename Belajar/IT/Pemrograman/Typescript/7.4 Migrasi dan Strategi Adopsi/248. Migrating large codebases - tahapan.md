# 248. Migrating large codebases - tahapan **Definisi Singkat:** Migrasi codebase besar membutuhkan tahapan terstruktur: assessment, foundation, migration, dan stabilization. **Analogi:** Migrasi besar seperti ekspedisi mendaki gunung—butuh persiapan (base camp), pendakian bertahap (pos per pos), dan istirahat untuk aklimatisasi. **Poin-Poin Penting:** - Tahap 1: Audit codebase dan buat type declaration untuk dependencies - Tahap 2: Setup toolchain (tsconfig, build pipeline) - Tahap 3: Migrasi module by module dengan prioritas tertinggi - Tahap 4: Strict mode dan refactor **Contoh Kode:** ```typescript // BENAR: // Tahap 1: Buat .d.ts untuk library tanpa types // declare module "legacy-lib" { export function doStuff(x: number): string; } // Tahap 2: tsconfig minimal { "compilerOptions": { "target": "ES2020", "module": "commonjs", "allowJs": true, "outDir": "./dist" } } // Tahap 3: Migrasi file per file, dimulai dari entry point // ERROR: // Langsung migrate semua file tanpa testing → bencana ``` **Kasus Penggunaan Nyata:** Perusahaan dengan 1M+ baris JavaScript—migrasi memakan waktu 6-12 bulan dengan tim khusus yang fokus pada type safety.
