# 247. Gradual Adoption - allowJs checkJs **Definisi Singkat:** `allowJs` dan `checkJs` adalah opsi kompiler yang memungkinkan file JavaScript hidup berdampingan dengan TypeScript dalam proyek yang sama. **Analogi:** allowJs/checkJs seperti jembatan sementara—karyawan lama (JS) dan baru (TS) bisa bekerja bersama sementara renovasi berlangsung. **Poin-Poin Penting:** - `allowJs: true` → mengimpor file .js dari .ts - `checkJs: true` → TypeScript memeriksa file .js juga - `// @ts-check` di file .js untuk enable checking per-file **Contoh Kode:** ```typescript // BENAR: // tsconfig.json { "compilerOptions": { "allowJs": true, "checkJs": false, "outDir": "./dist" }, "include": ["src/**/*"] } // file.ts bisa import file.js: import { legacyFunction } from "./legacy"; // ERROR: // allowJs: false → tidak bisa import .js dari .ts ``` **Kasus Penggunaan Nyata:** Tim yang ingin migrasi bertahap—file baru ditulis .ts, file lama tetap .js, TypeScript mengcompile keduanya bersama.
