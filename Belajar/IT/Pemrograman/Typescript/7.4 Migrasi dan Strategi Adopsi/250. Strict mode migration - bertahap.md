# 250. Strict mode migration - bertahap **Definisi Singkat:** Migrasi ke strict mode adalah proses mengaktifkan semua flag strict TypeScript secara bertahap, bukan sekaligus. **Analogi:** Strict mode seperti peraturan lalu lintas yang semakin ketat—mulai dari batas kecepatan, lalu sabuk pengaman, akhirnya airbag—setiap level meningkatkan keselamatan. **Poin-Poin Penting:** - Strict mode terdiri dari: `strictNullChecks`, `noImplicitAny`, `strictFunctionTypes`, dll. - Aktifkan satu flag per sprint atau per milestone - Gunakan `// @ts-ignore` untuk file yang belum siap **Contoh Kode:** ```typescript // BENAR: // tsconfig.json - strict bertahap { "compilerOptions": { "strictNullChecks": true, // Sprint 1 "noImplicitAny": true,   // Sprint 2 "strictFunctionTypes": true // Sprint 3 } } // ERROR: // "strict": true langsung → ribuan error baru muncul sekaligus, tim kewalahan ``` **Kasus Penggunaan Nyata:** Tim yang sudah menggunakan TypeScript tanpa strict mode—migrasi bertahap per quarter, setiap flag strict diaktifkan setelah codebase siap.
