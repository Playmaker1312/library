# 253. TypeScript governance dalam tim besar **Definisi Singkat:** TypeScript governance adalah kebijakan dan praktik untuk menjaga konsistensi, kualitas, dan performa tipe di tim developer berskala besar. **Analogi:** Governance seperti tata kota—ada aturan zonasi (arsitektur), izin bangunan (code review), dan standar konstruksi (style guide) agar kota tidak kacau. **Poin-Poin Penting:** - Bentuk TypeScript Working Group yang merumuskan kebijakan - Buat style guide dan best practices tertulis - Lakukan regular type audit dan performance review **Contoh Kode:** ```typescript // BENAR: // Contoh kebijakan governance: // 1. Setiap PR harus lolos tsc --noEmit // 2. Dilarang menambah any baru tanpa approval // 3. Library baru harus punya @types atau buat sendiri // 4. Strict mode wajib untuk semua package baru // 5. Audit tipe setiap quarter // eslint rule // '@typescript-eslint/no-explicit-any': 'error', // ERROR: // Tanpa governance → setiap developer bebas pakai any, strict beda-beda, codebase kacau ``` **Kasus Penggunaan Nyata:** Perusahaan dengan 50+ developer TypeScript—memiliki TypeScript Guild yang bertemu bulanan untuk review tipe, update kebijakan, dan sharing best practices.
