# 249. Mengatasi any debt **Definisi Singkat:** Any debt adalah akumulasi penggunaan `any` di codebase yang mengurangi manfaat type safety dan harus dibayar dengan refactoring bertahap. **Analogi:** Any debt seperti utang kartu kredit—memang enak sekarang (cepat selesai), tapi bunganya menumpuk (bug tidak terdeteksi) dan harus dibayar nanti. **Poin-Poin Penting:** - Gunakan ESLint rule `no-explicit-any` - Ganti `any` dengan `unknown` jika tipe tidak diketahui - Prioritaskan file dengan `any` terbanyak **Contoh Kode:** ```typescript // BENAR: function parseJson(text: string): unknown { return JSON.parse(text); } const data = parseJson('{"name":"test"}'); if (typeof data === "object" && data && "name" in data) { console.log((data as { name: string }).name); } // ERROR: function parseJson(text: string): any { // ❌ any debt return JSON.parse(text); } const name = parseJson('{"name":"test"}').name; // Tidak ada error jika properti salah ``` **Kasus Penggunaan Nyata:** Sprint khusus "any debt reduction" setiap bulan—target mengurangi jumlah `any` sebesar 10-20% per sprint.
