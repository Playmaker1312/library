# 251. Automating migration - ts-migrate codemods **Definisi Singkat:** ts-migrate adalah tool dari Airbnb yang mengotomatisasi migrasi JavaScript ke TypeScript menggunakan codemod untuk transformasi kode massal. **Analogi:** ts-migrate seperti alat pencetak batu bata—daripada membuat satu per satu tangan, Anda cetak ribuan bata dengan kualitas seragam dalam waktu singkat. **Poin-Poin Penting:** - Dikembangkan oleh Airbnb untuk migrasi internal mereka - Melakukan: rename .js→.ts, tambah tipe dasar, tambah `any` sementara - Hasilnya perlu direview dan diperbaiki manual **Contoh Kode:** ```typescript // BENAR: // Instal: npx ts-migrate init // Jalankan: npx ts-migrate migrate <path> // Hasil: // Input JS: function add(a, b) { return a + b; } // Output TS: function add(a: any, b: any): any { return a + b; } // ERROR: // Hasil ts-migrate masih banyak any → perlu refactor manual ``` **Kasus Penggunaan Nyata:** Airbnb menggunakan ts-migrate untuk migrasi 250k+ baris JavaScript ke TypeScript dalam waktu bulan, bukan tahun.
