# 105. Mapped Types - sintaks bracket \[K in keyof T\]

**Definisi Singkat:** Mapped types memungkinkan pembuatan tipe baru dengan mengiterasi key dari tipe yang sudah ada menggunakan sintaks `[K in keyof T]`.

**Analogi:** Seperti mesin stempel di pabrik — kamu punya daftar produk (keyof T) dan mesin akan menstempel setiap produk dengan label tertentu (tipe baru), satu per satu.

**Poin-Poin Penting:**
- Sintaks dasar: `{ [K in keyof T]: T[K] }`
- Bisa menambahkan modifier: `readonly`, `?`, `+`, `-`
- Landasan dari semua utility type seperti `Partial`, `Readonly`, dll.

**Contoh Kode:**
```typescript
interface User {
  id: number;
  name: string;
  email: string;
}

// BENAR: mapped type manual
type Nullable<T> = { [K in keyof T]: T[K] | null };
type NullableUser = Nullable<User>;
// NullableUser = { id: number | null; name: string | null; email: string | null }

const user: NullableUser = { id: null, name: "Budi", email: null }; // ✅

// BENAR: membuat semua properti boolean
type Booleanify<T> = { [K in keyof T]: boolean };
type BoolUser = Booleanify<User>; // { id: boolean; name: boolean; email: boolean }

// ERROR: key tidak dikenal
// type T = { [K in keyof "bukan tipe"]: any }; // ❌
```

**Kasus Penggunaan Nyata:** Mengubah tipe data secara massal, misalnya membuat versi serializable atau nullable dari tipe database.
