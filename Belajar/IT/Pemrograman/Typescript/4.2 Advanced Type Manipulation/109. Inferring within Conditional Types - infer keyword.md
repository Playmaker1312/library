# 109. Inferring within Conditional Types - infer keyword

**Definisi Singkat:** Keyword `infer` dalam conditional types memungkinkan kamu "menangkap" dan menyimpan sebagian tipe dari dalam struktur yang lebih besar untuk digunakan di branch true.

**Analogi:** Seperti detektor logam yang menemukan koin di dalam pasir — `infer` mengambil (menangkap) bentuk koin dari dalam pasir dan menyimpannya untuk diproses lebih lanjut.

**Poin-Poin Penting:**
- Hanya bisa digunakan dalam conditional type di posisi `extends` clause
- Contoh klasik: `infer R` untuk menangkap return type fungsi
- `infer` bisa digunakan di array, tuple, promise, function, dll.

**Contoh Kode:**
```typescript
// BENAR: infer return type
type MyReturnType<T> = T extends (...args: any[]) => infer R ? R : never;

function greet(): string { return "hello"; }
type R = MyReturnType<typeof greet>; // string ✅

// BENAR: infer element type dari array
type ElementType<T> = T extends (infer U)[] ? U : never;
type E = ElementType<number[]>; // number ✅

// BENAR: infer dari Promise
type Unwrap<T> = T extends Promise<infer U> ? U : T;
type U = Unwrap<Promise<string>>; // string ✅

// ERROR: infer di luar conditional type
// type Bad<T> = infer R; // ❌ infer hanya di dalam conditional
```

**Kasus Penggunaan Nyata:** Utility type seperti `ReturnType`, `Parameters`, `ConstructorParameters` semuanya menggunakan `infer` untuk mengekstrak tipe dari struktur yang kompleks.
