# 108. Conditional Types - T extends U ? X : Y

**Definisi Singkat:** Conditional types memilih tipe berdasarkan kondisi `T extends U` — jika true pilih X, jika false pilih Y.

**Analogi:** Seperti jalur kereta api yang bisa diubah — jika kereta (T) cocok dengan rel (U), maka arahkan ke stasiun X; jika tidak, ke stasiun Y.

**Poin-Poin Penting:**
- Sintaks: `T extends U ? X : Y` mirip ternary operator di JavaScript
- Bisa dinested dan dikombinasikan dengan infer
- Membuka kemampuan type-level programming yang powerful

**Contoh Kode:**
```typescript
// BENAR: conditional type sederhana
type IsString<T> = T extends string ? "yes" : "no";

type A = IsString<string>;  // "yes"
type B = IsString<number>;  // "no"

// BENAR: conditional type bersarang
type TypeName<T> =
  T extends string ? "string" :
  T extends number ? "number" :
  T extends boolean ? "boolean" :
  "other";

type C = TypeName<true>;  // "boolean"

// ERROR: conditional type tidak bisa di-runtime
// function check<T>(x: T): T extends string ? string : number { } // ❌ perlu return type yang konkret
```

**Kasus Penggunaan Nyata:** Membuat tipe yang adaptif berdasarkan input — misalnya `APIResponse<T>` yang tipenya berbeda kalau T adalah `void` vs objek.
