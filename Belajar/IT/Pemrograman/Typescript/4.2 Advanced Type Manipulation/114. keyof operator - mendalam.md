# 114. keyof operator - mendalam

**Definisi Singkat:** `keyof T` mengembalikan union dari semua key (property names) yang ada di tipe T, memungkinkan operasi type-level pada nama properti.

**Analogi:** Seperti daftar isi buku — `keyof` memberi tahu semua judul bab (nama properti) yang ada di dalam buku (tipe), tanpa membaca isi setiap bab.

**Poin-Poin Penting:**
- `keyof T` menghasilkan `string | number | symbol` tergantung tipe T
- Untuk object dengan index signature, `keyof` mengembalikan key type dari signature
- Bisa dikombinasikan dengan mapped types, conditional types, indexed access

**Contoh Kode:**
```typescript
interface User {
  id: number;
  name: string;
  email: string;
}

// BENAR: keyof menghasilkan union literal
type UserKeys = keyof User; // "id" | "name" | "email"

// BENAR: mapped type menggunakan keyof
type Optional<T> = { [K in keyof T]?: T[K] };

// BENAR: keyof dengan index signature
interface Dict<T> {
  [key: string]: T;
}
type DictKey = keyof Dict<number>; // string | number

// BENAR: constraint generic dengan keyof
function pluck<T, K extends keyof T>(items: T[], key: K): T[K][] {
  return items.map(item => item[key]);
}

// ERROR: keyof dengan tipe primitif terbatas
// type S = keyof string; // "length" | "charAt" | ... (banyak)
```

**Kasus Penggunaan Nyata:** Membuat fungsi utility yang generic seperti `pluck`, `groupBy`, atau mapper yang beroperasi pada properti objek secara type-safe.
