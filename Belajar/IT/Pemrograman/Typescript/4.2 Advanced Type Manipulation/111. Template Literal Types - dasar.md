# 111. Template Literal Types - dasar

**Definisi Singkat:** Template literal types menggunakan sintaks template literal JavaScript (backtick) untuk membentuk string literal types baru dari kombinasi tipe-tipe lain.

**Analogi:** Seperti mesin pembuat kalung nama — kamu bisa menggabungkan potongan huruf (string literal types) menjadi kalung dengan nama lengkap yang unik.

**Poin-Poin Penting:**
- Sintaks: `` `prefix${T}suffix` ``
- Bekerja dengan string literal types, number literal types, bigint, boolean, null, undefined
- Hasilnya adalah semua kemungkinan kombinasi (produk kartesian)

**Contoh Kode:**
```typescript
// BENAR: template literal type sederhana
type EventName = "click" | "focus" | "blur";
type Handler = `on${Capitalize<EventName>}`;
// Handler = "onClick" | "onFocus" | "onBlur"

type Version = `v${1 | 2 | 3}`;
// Version = "v1" | "v2" | "v3"

type Horizontal = "left" | "right";
type Vertical = "top" | "bottom";
type Position = `${Horizontal}-${Vertical}`;
// Position = "left-top" | "left-bottom" | "right-top" | "right-bottom"

// ERROR: template literal dengan tipe non-literal menghasilkan string
// type X = `test${string}`; // string (bukan literal)
```

**Kasus Penggunaan Nyata:** Membuat pattern untuk string matching seperti route paths, CSS class combinations, atau event handler names secara type-safe.
