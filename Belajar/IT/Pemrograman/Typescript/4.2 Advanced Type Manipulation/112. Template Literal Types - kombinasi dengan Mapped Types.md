# 112. Template Literal Types - kombinasi dengan Mapped Types

**Definisi Singkat:** Template literal types dan mapped types bisa dikombinasikan untuk membuat dan mentransformasi key names secara dinamis di level tipe.

**Analogi:** Seperti percetakan custom stiker — mapped type menyediakan daftar produk (keys), template literal mencetak label baru untuk setiap produk.

**Poin-Poin Penting:**
- Template literal dalam `as` clause mengubah nama key
- Kombinasi dengan `Capitalize`, `Lowercase`, dll sangat umum
- Memungkinkan pembuatan tipe getter/setter otomatis

**Contoh Kode:**
```typescript
interface User {
  id: number;
  name: string;
  email: string;
}

// BENAR: mapped type + template literal untuk getters
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};

type UserGetters = Getters<User>;
// UserGetters = { getId: () => number; getName: () => string; getEmail: () => string }

// BENAR: membuat setters
type Setters<T> = {
  [K in keyof T as `set${Capitalize<string & K>}`]: (value: T[K]) => void;
};

// BENAR: transform snake_case ke camelCase (sederhana)
type CamelKeys<T> = {
  [K in keyof T as K extends string ? Uncapitalize<K> : K]: T[K];
};

// ERROR: template literal butuh string key
// type Bad = { [K in keyof User as `get${K}`]: () => User[K] }; // ❌ K bisa jadi symbol
```

**Kasus Penggunaan Nyata:** ORM (Object-Relational Mapping) yang otomatis membuat method query seperti `findById`, `findByName` dari field model.
