# 110. Distributive Conditional Types

**Definisi Singkat:** Conditional types bersifat distributif — jika T adalah bare type parameter berupa union, kondisi akan diterapkan ke setiap anggota union secara terpisah.

**Analogi:** Seperti mesin pemilah koin — saat kamu memasukkan campuran koin (union), mesin memproses setiap koin satu per satu, bukan sekaligus sebagai campuran.

**Poin-Poin Penting:**
- Distribusi terjadi hanya pada **bare type parameter** (T langsung, bukan `T[]` atau `Promise<T>`)
- Setiap anggota union diproses sendiri, lalu hasilnya digabung kembali sebagai union
- Dapat dicegah dengan membungkus T: `[T] extends [U]`

**Contoh Kode:**
```typescript
// BENAR: distributive conditional type
type ToArray<T> = T extends any ? T[] : never;
type Result = ToArray<string | number>;
// Secara distributif: string[] | number[] (bukan (string | number)[])

// BENAR: filter union dengan distribusi
type FilterString<T> = T extends string ? T : never;
type StringsOnly = FilterString<string | number | boolean>;
// Distribusi: (string extends string ? string : never) | (number extends string ? never) | ...
// Hasil: string ✅

// Mencegah distribusi dengan wrapping
type NoDistribute<T> = [T] extends [string] ? T[] : never;
type R2 = NoDistribute<string | number>; // never (karena [string|number] tidak extends [string])

// ERROR: distribusi tidak terjadi pada non-bare parameter
// type T = (string | number)[] extends any[] ? true : false; // single condition, bukan distribusi
```

**Kasus Penggunaan Nyata:** Filter tipe dalam union (`Exclude`, `Extract`), transformasi massal tipe dalam union, atau conditional yang perlu union sebagai input tunggal.
