# 106. Mapped Type Modifiers - plus minus readonly optional

**Definisi Singkat:** Mapped types bisa menambah (`+`) atau menghapus (`-`) modifier `readonly` dan `optional` (`?`) pada properti yang dihasilkan.

**Analogi:** Seperti remote kontrol dengan tombol + dan - — kamu bisa menambah volume (add readonly/optional) atau mengurangi (remove readonly/optional).

**Poin-Poin Penting:**
- `+readonly` / `readonly` — menambah readonly
- `-readonly` — menghapus readonly
- `+?` / `?` — menambah optional
- `-?` — menghapus optional (seperti pada `Required<T>`)

**Contoh Kode:**
```typescript
interface Config {
  readonly apiKey: string;
  timeout?: number;
  retry?: boolean;
}

// BENAR: hapus readonly dan optional
type Mutable_Required<T> = {
  -readonly [K in keyof T]-?: T[K];
};

type EditableConfig = Mutable_Required<Config>;
// EditableConfig = { apiKey: string; timeout: number; retry: boolean }

const config: EditableConfig = { apiKey: "abc", timeout: 5000, retry: true };
config.apiKey = "xyz"; // ✅ mutable sekarang

// ERROR: tanpa -readonly, tidak bisa mengubah
// type StillReadonly = { readonly [K in keyof Config]: Config[K] };
// StillReadonly["apiKey"] masih readonly
```

**Kasus Penggunaan Nyata:** Konversi antara DTO (Data Transfer Object) yang immutable ke mutable object untuk form editing.
