# 113. Indexed Access Types - T\[K\]

**Definisi Singkat:** Indexed access types menggunakan sintaks `T[K]` untuk mengambil tipe dari properti tertentu di object type T dengan key K.

**Analogi:** Seperti melihat isi lemari arsip dengan nomor laci tertentu — kamu membuka laci (key K) dan melihat apa yang ada di dalamnya (tipe value).

**Poin-Poin Penting:**
- Sintaks: `T[K]` di mana K adalah key yang valid dari T
- Bisa menggunakan union key: `T["name" | "email"]`
- Bisa menggunakan type variable: `T[K]` dalam generic context
- Juga disebut lookup types

**Contoh Kode:**
```typescript
interface User {
  id: number;
  name: string;
  email: string;
  address: { city: string; zip: string };
}

// BENAR: indexed access type
type NameType = User["name"];        // string
type IdOrName = User["id" | "name"]; // number | string
type AddressType = User["address"];   // { city: string; zip: string }
type CityType = User["address"]["city"]; // string (nested)

// BENAR: dengan generic
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}
const name = getProperty({ name: "Budi", age: 30 }, "name"); // string ✅

// ERROR: key tidak ada di T
// type Bad = User["nonexistent"]; // ❌
```

**Kasus Penggunaan Nyata:** Fungsi generic getter/setter yang type-safe, atau mengekstrak tipe dari properti tertentu dalam object yang kompleks.
