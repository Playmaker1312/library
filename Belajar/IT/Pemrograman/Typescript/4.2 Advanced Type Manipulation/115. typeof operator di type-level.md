# 115. typeof operator di type-level

**Definisi Singkat:** `typeof` pada level tipe (type context) mengambil tipe dari suatu value JavaScript, berbeda dengan `typeof` di runtime yang mengembalikan string.

**Analogi:** Seperti mesin fotokopi untuk tipe — kamu memberikan benda (value) dan mesin mengeluarkan "cetakan tipe"-nya yang bisa digunakan di dunia type-level.

**Poin-Poin Penting:**
- Di type context, `typeof value` mengembalikan tipe TypeScript dari value tersebut
- Berguna untuk mendapatkan tipe dari literal, fungsi, atau objek yang sudah didefinisikan
- Sering dikombinasikan dengan `ReturnType`, `Parameters`, dll.

**Contoh Kode:**
```typescript
// BENAR: typeof dari value literal
const name = "Budi";
type NameType = typeof name; // string ✅

const config = {
  apiUrl: "https://api.example.com",
  timeout: 5000,
};
type ConfigType = typeof config;
// ConfigType = { apiUrl: string; timeout: number } ✅

// BENAR: typeof dengan fungsi
function add(a: number, b: number): number {
  return a + b;
}
type AddFn = typeof add; // (a: number, b: number) => number
type AddReturn = ReturnType<typeof add>; // number ✅

// ERROR: typeof di runtime vs type-level
// console.log(typeof name); // "string" (runtime, beda dengan type-level typeof)
```

**Kasus Penggunaan Nyata:** Mendapatkan tipe dari konstanta atau konfigurasi yang sudah didefinisikan tanpa perlu membuat interface terpisah (DRY).
