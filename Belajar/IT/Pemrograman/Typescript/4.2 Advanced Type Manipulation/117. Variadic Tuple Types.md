# 117. Variadic Tuple Types

**Definisi Singkat:** Variadic tuple types memungkinkan penggunaan `...T` (spread) dalam tuple types untuk menangkap jumlah elemen yang bervariasi, diperkenalkan di TypeScript 4.0.

**Analogi:** Seperti kereta api dengan gerbong yang bisa ditambah atau dikurangi — `...` memungkinkan kita bekerja dengan jumlah gerbong (elemen) yang tidak tetap secara type-safe.

**Poin-Poin Penting:**
- Sintaks: `[...T, ...U]` — spread di dalam tuple types
- Bisa menggabungkan, memisah, dan memanipulasi tuple types
- Memungkinkan typing fungsi dengan parameter yang fleksibel

**Contoh Kode:**
```typescript
// BENAR: concat dua tuple
type Concat<T extends any[], U extends any[]> = [...T, ...U];
type Result = Concat<[number, string], [boolean]>;
// Result = [number, string, boolean] ✅

// BENAR: tail dari tuple (buang elemen pertama)
type Tail<T extends any[]> = T extends [infer First, ...infer Rest] ? Rest : [];
type T1 = Tail<[number, string, boolean]>; // [string, boolean] ✅

// BENAR: push type ke tuple
type Push<T extends any[], V> = [...T, V];
type T2 = Push<[number, string], boolean>; // [number, string, boolean] ✅

// ERROR: tuple spread hanya di type-level
// function bad(...args: ...[number, string]) {} // ❌
```

**Kasus Penggunaan Nyata:** Typing untuk fungsi variadic seperti `Promise.all`, partial application, curry, atau tuple manipulation utility.
