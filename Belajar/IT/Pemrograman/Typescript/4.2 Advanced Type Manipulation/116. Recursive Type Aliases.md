# 116. Recursive Type Aliases

**Definisi Singkat:** Recursive type aliases adalah tipe yang merujuk pada dirinya sendiri, memungkinkan representasi tipe data yang bersarang (nested) secara rekursif.

**Analogi:** Seperti boneka kayu Rusia (Matryoshka) — setiap boneka berisi boneka yang lebih kecil dengan bentuk yang sama, bisa terus ke dalam tanpa batas.

**Poin-Poin Penting:**
- Sejak TypeScript 4.1, recursive type aliases lebih mudah digunakan
- Membutuhkan indirection (biasanya melalui object type) agar kompiler bisa memprosesnya
- Berguna untuk tree, linked list, JSON, dan struktur data rekursif

**Contoh Kode:**
```typescript
// BENAR: recursive type untuk JSON
type JSONValue =
  | string
  | number
  | boolean
  | null
  | JSONValue[]
  | { [key: string]: JSONValue };

const data: JSONValue = {
  name: "Budi",
  age: 30,
  hobbies: ["coding", { type: "outdoor", name: "hiking" }],
}; // ✅

// BENAR: recursive untuk tree
type TreeNode<T> = {
  value: T;
  children: TreeNode<T>[];
};

const tree: TreeNode<number> = {
  value: 1,
  children: [
    { value: 2, children: [] },
    { value: 3, children: [{ value: 4, children: [] }] },
  ],
}; // ✅

// ERROR: recursive tanpa object wrapper bisa error
// type Infinite = { data: Infinite }; // ✅ ini fine
// type InfiniteArr = InfiniteArr[]; // ❌ perlu objek wrapper
```

**Kasus Penggunaan Nyata:** Mendefinisikan tipe untuk JSON, AST (Abstract Syntax Tree), comment threads yang nested, atau struktur folder/file.
