# 107. Key Remapping dalam Mapped Types - as keyword

**Definisi Singkat:** Key remapping menggunakan keyword `as` dalam mapped type untuk mengubah nama key, bukan hanya tipe value-nya. Tersedia sejak TypeScript 4.1.

**Analogi:** Seperti pabrik yang mengubah nomor seri produk — kamu bisa mengganti label setiap item (key) dengan format baru tanpa mengubah barangnya (value type).

**Poin-Poin Penting:**
- Sintaks: `{ [K in keyof T as NewKey]: T[K] }`
- `NewKey` bisa menggunakan template literal types
- Bisa menyaring key dengan conditional: `as K extends Something ? never : K`

**Contoh Kode:**
```typescript
interface User {
  id: number;
  name: string;
  email: string;
}

// BENAR: tambahkan prefix "get" pada setiap key
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};

type UserGetters = Getters<User>;
// UserGetters = { getId: () => number; getName: () => string; getEmail: () => string }

// BENAR: saring key yang tipenya string
type StringKeys<T> = {
  [K in keyof T as T[K] extends string ? K : never]: T[K];
};
type UserStrings = StringKeys<User>; // { name: string; email: string }

// ERROR: key hasil remapping harus valid
// type Bad = { [K in keyof User as 123]: User[K] }; // ❌ 123 bukan string key
```

**Kasus Penggunaan Nyata:** Membuat tipe untuk wrapper seperti `Getters`, `Setters`, atau transform key format (snake_case ke camelCase) di level tipe.
