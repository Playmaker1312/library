# 28. Mengetik parameter dan return type **Definisi Singkat:** Setiap parameter fungsi dan nilai return dapat diberi anotasi tipe secara eksplisit. **Analogi:** Seperti resep masakan yang mencantumkan bahan (parameter) dan hasil akhir (return) secara spesifik. **Poin-Poin Penting:** - Parameter ditulis `nama: Tipe` - Return type ditulis setelah `)` dengan `: Tipe` - TypeScript akan memvalidasi jumlah dan tipe argumen **Contoh Kode:** ```typescript // BENAR (valid):
function greet(name: string, age: number): string {
  return `${name} berusia ${age} tahun`;
}
const result: string = greet("Andi", 25);

// ERROR (type-error):
function add(a: number, b: number): number {
  return a + b;
}
add(5, "10"); // error: Argument of type 'string' is not assignable to parameter of type 'number' /* error */ ``` **Kasus Penggunaan Nyata:** Membangun fungsi API handler yang menerima request bertipe dan mengembalikan response bertipe, sehingga seluruh pipeline terjamin keamanan tipenya.
