# 29. Optional Parameters - param question mark type **Definisi Singkat:** Parameter yang boleh diisi atau tidak, ditandai dengan `?` setelah nama parameter. **Analogi:** Seperti topping tambahan pada pizza — boleh ada, boleh tidak, tanpa mempengaruhi proses utama. **Poin-Poin Penting:** - Ditulis `param?: Tipe` secara otomatis menjadi `Tipe | undefined` - Optional parameter harus ditempatkan setelah required parameter - Tidak memberikan argumen sama dengan `undefined` **Contoh Kode:** ```typescript // BENAR (valid):
function createUser(name: string, age?: number): string {
  return `${name}${age !== undefined ? `, ${age}` : ""}`;
}
createUser("Budi");       // valid
createUser("Budi", 30);   // valid

// ERROR (type-error):
// Optional params cannot precede required params
function wrong(opt?: string, req: number) {} // error: Required parameters may not follow optional parameters /* error */ ``` **Kasus Penggunaan Nyata:** Konfigurasi fungsi dengan opsi yang tidak selalu diperlukan, seperti parameter `options?` pada fetch API.
