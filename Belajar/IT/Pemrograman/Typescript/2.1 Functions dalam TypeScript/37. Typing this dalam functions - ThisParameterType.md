# 37. Typing this dalam functions - ThisParameterType **Definisi Singkat:** TypeScript memungkinkan pengetikan eksplisit untuk konteks `this` dalam fungsi menggunakan parameter palsu `this: Tipe` . **Analogi:** Seperti kontrak kerja yang secara spesifik menyebutkan "dalam konteks ini, 'saya' merujuk kepada..." sehingga tidak ambigu. **Poin-Poin Penting:** - Parameter `this` dideklarasikan sebagai parameter pertama - Ini hanya untuk type-checking, tidak mempengaruhi runtime - Berguna untuk callback dengan konteks spesifik **Contoh Kode:** ```typescript // BENAR (valid):
interface User {
  name: string;
  age: number;
}

function getUserInfo(this: User): string {
  return `${this.name} berusia ${this.age} tahun`;
}

const user: User = { name: "Eko", age: 28 };
const bound = getUserInfo.bind(user); // valid, this adalah User

// ERROR (type-error):
getUserInfo.call({ name: "Eko" }); // error: Property 'age' is missing in type '{ name: string; }' /* error */

// ThisParameterType utility
type ThisType = ThisParameterType<typeof getUserInfo>; // User
``` **Kasus Penggunaan Nyata:** Event handler yang membutuhkan konteks DOM element tertentu, atau method dalam class-style programming tanpa class.
