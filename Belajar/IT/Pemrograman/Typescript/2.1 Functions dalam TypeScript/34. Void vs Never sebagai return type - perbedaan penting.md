# 34. Void vs Never sebagai return type - perbedaan penting **Definisi Singkat:** `void` berarti fungsi selesai tanpa nilai berguna; `never` berarti fungsi tidak pernah selesai (selalu error/looping tak terbatas). **Analogi:** `void` seperti kurir yang mengantar paket lalu pergi tanpa membawa apa-apa; `never` seperti lubang hitam — tidak ada yang keluar dan tidak pernah berhenti. **Poin-Poin Penting:** - `void`: fungsi mengembalikan undefined, eksekusi normal - `never`: fungsi tidak pernah mencapai akhir eksekusi - `never` adalah subtype dari semua tipe, tapi tidak ada tipe yang subtype dari never **Contoh Kode:** ```typescript // BENAR (valid):
function logMessage(msg: string): void {
  console.log(msg);
  // tidak perlu return
}

function throwError(msg: string): never {
  throw new Error(msg);
}

function infiniteLoop(): never {
  while (true) { /* loop terus */ }
}

// ERROR (type-error):
function returnVoid(): void {
  return 42; // error: Type '42' is not assignable to type 'void' /* error */ ``` **Kasus Penggunaan Nyata:** `void` untuk event handler / logger; `never` untuk fungsi error handling, assertion function, atau infinite loop di aplikasi real-time.
