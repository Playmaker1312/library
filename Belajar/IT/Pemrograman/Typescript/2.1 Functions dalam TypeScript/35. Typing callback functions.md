# 35. Typing callback functions **Definisi Singkat:** Callback adalah fungsi yang dikirim sebagai argumen ke fungsi lain; tipe callback harus dideklarasikan agar aman. **Analogi:** Seperti nomor telepon yang Anda berikan ke resepsionis — mereka akan menghubungi Anda kembali dengan format pesan tertentu. **Poin-Poin Penting:** - Callback dideklarasikan dengan function type expression - Callback bisa void (tidak pakai return) atau mengembalikan nilai - Callback type bisa dioverload **Contoh Kode:** ```typescript // BENAR (valid):
function processArray(
  items: number[],
  callback: (item: number, index: number) => string
): string[] {
  return items.map(callback);
}

const result = processArray([1, 2, 3], (n, i) => `Index ${i}: ${n}`);

type EventHandler = (event: MouseEvent) => void;
const handleClick: EventHandler = (e) => console.log(e.clientX);

// ERROR (type-error):
processArray([1], (n: string) => n); // error: Parameter 'n' type 'string' is not assignable to parameter type 'number' /* error */ ``` **Kasus Penggunaan Nyata:** Array method seperti `map`, `filter`, `reduce`, event listeners DOM, async callback pattern, dan middleware pattern.
