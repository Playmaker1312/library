# 30. Default Parameters dengan type inference **Definisi Singkat:** Parameter dapat diberi nilai default; TypeScript akan menginfer tipe dari nilai default tersebut. **Analogi:** Seperti kursi cadangan di ruang seminar — jika tidak ada kursi tambahan, telah tersedia kursi standar. **Poin-Poin Penting:** - Syntax: `param: Tipe = nilaiDefault` - Tipe diinfer dari nilai default jika tidak dianotasi eksplisit - Default parameter otomatis menjadi optional **Contoh Kode:** ```typescript // BENAR (valid):
function greet(name: string, greeting: string = "Halo"): string {
  return `${greeting}, ${name}!`;
}
greet("Dewi");              // "Halo, Dewi!"
greet("Dewi", "Selamat");   // valid

// ERROR (type-error):
function multiply(a: number, b = 2): number {
  return a * b;
}
multiply(3, "4"); // error: Argument of type 'string' is not assignable to parameter of type 'number' /* error */ ``` **Kasus Penggunaan Nyata:** Fungsi HTTP client dengan default timeout atau default headers yang tetap memiliki fleksibilitas untuk diubah.
