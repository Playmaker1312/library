# 36. Function Overloading - multiple signatures **Definisi Singkat:** Mendeklarasikan beberapa signature fungsi untuk tipe parameter yang berbeda, dengan satu implementasi yang menangani semuanya. **Analogi:** Seperti mesin ATM — bisa tarik tunai, transfer, atau cek saldo, semuanya lewat satu mesin tapi dengan input dan output yang berbeda. **Poin-Poin Penting:** - Tulis multiple signature (overload signatures) lalu satu implementation signature - Implementation signature harus kompatibel dengan semua overload - Hanya overload signatures yang terlihat oleh pemanggil **Contoh Kode:** ```typescript // BENAR (valid):
function makeDate(timestamp: number): Date;
function makeDate(year: number, month: number, day: number): Date;
function makeate(yearOrTs: number, month?: number, day?: number): Date {
  if (month !== undefined && day !== undefined) {
    return new Date(yearOrTs, month, day);
  }
  return new Date(yearOrTs);
}

makeDate(1700000000);           // valid
makeDate(2024, 5, 24);         // valid

// ERROR (type-error):
makeDate(2024, 5); // error: No overload expects 2 arguments, but overloads exist that expect either 1 or 3 arguments /* error */ ``` **Kasus Penggunaan Nyata:** Library seperti `createElement` di React, fungsi `querySelector`, atau utility function yang bisa menerima string, number, atau object.
