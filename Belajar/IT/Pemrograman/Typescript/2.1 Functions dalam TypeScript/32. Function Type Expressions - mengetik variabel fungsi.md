# 32. Function Type Expressions - mengetik variabel fungsi **Definisi Singkat:** Mendeklarasikan tipe untuk variabel yang menampung fungsi menggunakan syntax `(param: Tipe) => ReturnType` . **Analogi:** Seperti job description yang mendeskripsikan kualifikasi yang harus dimiliki seorang pelamar. **Poin-Poin Penting:** - Syntax: `let fn: (x: Tipe) => ReturnType` - Berbeda dengan fungsi biasa — hanya mendeskripsikan signature - Sangat berguna untuk callback dan higher-order functions **Contoh Kode:** ```typescript // BENAR (valid):
let greeter: (name: string) => string;
greeter = (n) => `Halo ${n}`; // valid, sesuai signature

type MathOp = (a: number, b: number) => number;
const add: MathOp = (x, y) => x + y;

// ERROR (type-error):
greeter = (n: number) => n.toString(); // error: Type '(n: number) => string' is not assignable to type '(name: string) => string' /* error */ ``` **Kasus Penggunaan Nyata:** Mendefinisikan tipe untuk event handler, callback transform data, atau middleware di Express/Koa.
