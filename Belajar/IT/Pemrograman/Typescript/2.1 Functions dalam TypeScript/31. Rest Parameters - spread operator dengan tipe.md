# 31. Rest Parameters - spread operator dengan tipe **Definisi Singkat:** Menangkap banyak argumen menjadi satu array dengan tipe tertentu menggunakan `...` . **Analogi:** Seperti keranjang belanja — berapapun jumlah barang yang dimasukkan, semuanya tertampung dalam satu wadah. **Poin-Poin Penting:** - Syntax: `...params: Tipe[]` - Rest parameter harus menjadi parameter terakhir - Tipe harus berupa array **Contoh Kode:** ```typescript // BENAR (valid):
function sum(...numbers: number[]): number {
  return numbers.reduce((a, b) => a + b, 0);
}
sum(1, 2, 3, 4);            // 10

function teamLead(name: string, ...members: string[]): string {
  return `${name} memimpin ${members.join(", ")}`;
}

// ERROR (type-error):
function wrong(...items: number[], extra: string) {} // error: Rest parameter must be last /* error */ ``` **Kasus Penggunaan Nyata:** Logger yang menerima banyak pesan, atau fungsi `Promise.all` yang menerima array Promise dalam jumlah dinamis.
