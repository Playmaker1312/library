# 33. Call Signatures - function type dalam object type **Definisi Singkat:** Mengetik fungsi yang juga memiliki properti, menggunakan syntax `(param: Tipe): ReturnType` dalam object type. **Analogi:** Seperti pisau Swiss Army — ia adalah alat (bisa dipanggil) sekaligus memiliki fitur tambahan (properti). **Poin-Poin Penting:** - Ditulis dengan `:` bukan `=>` - Memungkinkan fungsi memiliki properti statis - Berguna untuk fungsi dengan metadata **Contoh Kode:** ```typescript // BENAR (valid):
type DescribableFn = {
  description: string;
  (someArg: number): boolean;
};

function doSomething(fn: DescribableFn) {
  console.log(fn.description);
  return fn(42);
}

const myFn: DescribableFn = (n: number) => n > 10;
myFn.description = "Memeriksa apakah > 10";

// ERROR (type-error):
const wrong: DescribableFn = (n: string) => true; // error: Type '(n: string) => boolean' is not assignable to type '(someArg: number) => boolean' /* error */ ``` **Kasus Penggunaan Nyata:** Validator functions yang memiliki properti `name` atau `message`, atau factory functions dengan properti konfigurasi.
