# 213. TypeScript sebagai bahasa fungsional di level tipe **Definisi Singkat:** TypeScript memiliki sistem tipe Turing-complete yang mendukung pola fungsional seperti conditional types, infer, dan recursive types. **Analogi:** Level tipe ibarat "kompiler mini" di dalam kompiler—ia mengeksekusi logika pada waktu kompilasi, bukan runtime. **Poin-Poin Penting:** - Tipe adalah fungsi murni (pure functions) tanpa efek samping - Conditional types bertindak seperti `if/else` di level tipe - Type inference mirip pattern matching di Haskell **Contoh Kode:** ```typescript // BENAR: type IsString<T> = T extends string ? "yes" : "no"; type A = IsString<"hello">; // "yes" type B = IsString<42>; // "no" // ERROR: type Invalid<T> = T extends string ? console.log(T) : never; // Tidak bisa punya side effect ``` **Kasus Penggunaan Nyata:** Menerjemahkan logika bisnis kompleks ke level tipe sehingga error terdeteksi saat kompilasi, bukan runtime.
