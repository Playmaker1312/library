# 214. Arithmetika di level tipe - Tuple-based counting **Definisi Singkat:** Aritmetika level tipe menggunakan panjang tuple untuk merepresentasikan dan memanipulasi angka natural. **Analogi:** Tuple-based counting seperti menggunakan jari untuk menghitung—setiap elemen tuple adalah satu "jari". **Poin-Poin Penting:** - Angka `N` direpresentasikan sebagai tuple dengan panjang `N` - Operasi `+` dilakukan dengan menggabungkan dua tuple - Operasi `-` dilakukan dengan `Conditional Types` dan `infer` **Contoh Kode:** ```typescript // BENAR: type Zero = []; type Succ<N extends any[]> = [...N, any]; type One = Succ<Zero>; // [any] type Two = Succ<One>; // [any, any] type Add<A extends any[], B extends any[]> = [...A, ...B]; type Three = Add<One, Two>; // [any, any, any] type Length<T extends any[]> = T["length"]; type ThreeLen = Length<Three>; // 3 // ERROR: type Neg<T extends number> = T - 1; // Tidak bisa langsung ``` **Kasus Penggunaan Nyata:** Membangun tipe yang memerlukan validasi panjang minimum/maksimum tuple di level tipe.
