# 219. Type Challenges dari type-challenges repository **Definisi Singkat:** type-challenges adalah repositori GitHub berisi tantangan tipe TypeScript dari level mudah hingga ekstrem. **Analogi:** Type challenges seperti teka-teki sudoku untuk sistem tipe—setiap tantangan menguji kemampuan memanipulasi tipe dengan batasan tertentu. **Poin-Poin Penting:** - Tersedia level easy, medium, hard, dan extreme - Mencakup Pick, Readonly, TupleToUnion, DeepReadonly, dll. - Setiap solusi mengajarkan teknik type-level programming **Contoh Kode:** ```typescript // BENAR: // Implementasikan MyPick<T, K> type MyPick<T, K extends keyof T> = { [P in K]: T[P] }; type User = { id: number; name: string; age: number }; type NameOnly = MyPick<User, "name" | "age">; // { name: string; age: number } // ERROR: type BadPick = MyPick<User, "email">; // ❌ "email" tidak ada di keyof User ``` **Kasus Penggunaan Nyata:** Latihan sistematis untuk menguasai advanced types sebelum mengerjakan proyek nyata yang membutuhkan type safety tinggi.
