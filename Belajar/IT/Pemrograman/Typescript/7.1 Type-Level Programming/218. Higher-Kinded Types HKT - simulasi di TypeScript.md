# 218. Higher-Kinded Types HKT - simulasi di TypeScript **Definisi Singkat:** Higher-Kinded Types (HKT) memungkinkan abstraksi atas type constructor seperti `Option<T>` atau `Array<T>`, yang tidak didukung langsung TypeScript. **Analogi:** HKT seperti fungsi yang menerima fungsi lain (higher-order function), tapi di level tipe—ia menerima type constructor dan mengembalikan type constructor. **Poin-Poin Penting:** - TypeScript tidak memiliki HKT native seperti Haskell - Simulasi menggunakan generic interface dengan method `map` - Library seperti `fp-ts` dan `effect-ts` mengimplementasikan ini **Contoh Kode:** ```typescript // BENAR: interface Functor<F> { map: <A, B>(fa: F<A>, f: (a: A) => B) => F<B>; } // Simulasi HKT dengan module-signature interface HKT<F, A> { _URI: F; _A: A; } type URItoType<URI extends string, A> = URI extends "Option" ? Option<A> : URI extends "Array" ? Array<A> : never; // ERROR: type Map<F, A, B> = F<A> extends F<infer _> ? F<B> : never; // F<A> tidak valid di TypeScript ``` **Kasus Penggunaan Nyata:** Library functional programming seperti `fp-ts` menggunakan simulasi HKT untuk menyediakan operasi generik atas berbagai struktur data.
