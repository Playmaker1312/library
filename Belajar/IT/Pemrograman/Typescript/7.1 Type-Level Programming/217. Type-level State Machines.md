# 217. Type-level State Machines **Definisi Singkat:** State Machine dapat dimodelkan di level tipe sehingga transisi state yang invalid terdeteksi saat kompilasi. **Analogi:** Type-level state machine seperti pintu otomatis dengan sensor—hanya transisi tertentu yang diizinkan (terbuka→tertutup, bukan terbuka→terbuka). **Poin-Poin Penting:** - Setiap state adalah union type literal - Transisi direpresentasikan sebagai generic type dengan conditional - Membatasi operasi hanya pada state yang valid **Contoh Kode:** ```typescript // BENAR: type DoorState = "open" | "closed" | "locked"; type Transition<S extends DoorState> = S extends "open" ? "closed" : S extends "closed" ? "open" | "locked" : S extends "locked" ? "closed" : never; type Next = Transition<"open">; // "closed" type Invalid = Transition<"open"> extends "locked" ? true : false; // false // ERROR: type Bad = Transition<"ajar">; // never karena "ajar" bukan DoorState ``` **Kasus Penggunaan Nyata:** Modeling form wizard, koneksi WebSocket, atau proses checkout di e-commerce agar state invalid tidak mungkin terjadi.
