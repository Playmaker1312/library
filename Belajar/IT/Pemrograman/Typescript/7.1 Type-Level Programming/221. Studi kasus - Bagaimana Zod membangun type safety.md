# 221. Studi kasus - Bagaimana Zod membangun type safety **Definisi Singkat:** Zod adalah library validasi skema yang menginfers TypeScript types secara otomatis dari runtime validator. **Analogi:** Zod seperti petugas imigrasi yang memeriksa paspor—ia memvalidasi data di runtime sekaligus memberi tahu petugas (TypeScript) bentuk data yang diharapkan. **Poin-Poin Penting:** - `z.infer<typeof schema>` mengekstrak tipe dari skema - Single source of truth: skema Zod = tipe TypeScript - Mendukung transformasi, default value, dan custom validation **Contoh Kode:** ```typescript // BENAR: import { z } from "zod"; const UserSchema = z.object({ id: z.number(), name: z.string().min(1), email: z.string().email(), }); type User = z.infer<typeof UserSchema>; // { id: number; name: string; email: string } const result = UserSchema.parse({ id: 1, name: "Alice", email: "alice@test.com" }); // OK // ERROR: UserSchema.parse({ id: "1", name: "Alice", email: "invalid" }); // ❌ runtime error + type error ``` **Kasus Penggunaan Nyata:** API validation di backend (Express/Fastify) dan form validation di frontend (React) dengan single source of truth untuk tipe dan validasi.
