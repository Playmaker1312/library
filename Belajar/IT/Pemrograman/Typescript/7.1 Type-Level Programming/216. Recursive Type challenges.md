# 216. Recursive Type challenges **Definisi Singkat:** Recursive types memungkinkan tipe mereferensi dirinya sendiri untuk memproses struktur data bertingkat. **Analogi:** Recursive type seperti boneka Matryoshka—di dalamnya ada struktur yang sama, terus berulang sampai mencapai kasus dasar. **Poin-Poin Penting:** - Harus memiliki base case agar rekursi berhenti - TypeScript membatasi kedalaman rekursi (~50 level) - Sering digunakan dengan conditional types dan variadic tuples **Contoh Kode:** ```typescript // BENAR: type DeepReadonly<T> = T extends object ? { readonly [K in keyof T]: DeepReadonly<T[K]> } : T; interface User { name: string; address: { city: string; zip: number; }; } type ReadonlyUser = DeepReadonly<User>; // Semua properti readonly recursive // ERROR: type Infinite<T> = Infinite<T>; // Type alias 'Infinite' circularly references itself ``` **Kasus Penggunaan Nyata:** Immutable state management di Redux atau Zustand dengan tipe readonly yang menjangkau seluruh objek secara nested.
