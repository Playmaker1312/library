# 215. String parsing di level tipe **Definisi Singkat:** TypeScript 4.1+ memungkinkan template literal types untuk melakukan parsing string pada waktu kompilasi. **Analogi:** String parsing di level tipe seperti membaca sandi dengan pola tertentu—setiap karakter diperiksa dan diurai berdasarkan template. **Poin-Poin Penting:** - Template literal types dengan `infer` bisa memisahkan string - Recursive conditional types bisa memproses karakter satu per satu - Berguna untuk routing, format validation, dan DSL **Contoh Kode:** ```typescript // BENAR: type ParseRoute<T extends string> = T extends `/${infer Seg}` ? Seg : T; type GetSegment = ParseRoute<"/users">; // "users" type Split<T extends string, D extends string> = T extends `${infer A}${D}${infer B}` ? [A, ...Split<B, D>] : [T]; type Parts = Split<"a,b,c", ",">; // ["a", "b", "c"] // ERROR: type AddOne<T extends string> = T extends `${infer N extends number}` ? N + 1 : never; // Operator '+' tidak bisa di level tipe ``` **Kasus Penggunaan Nyata:** Type-safe routing di framework seperti Next.js atau Express—path parameter di-parse dan divalidasi di level tipe.
