# 220. Studi kasus - Bagaimana Prisma membangun type safety **Definisi Singkat:** Prisma menggunakan code generation untuk menghasilkan tipe TypeScript yang fully type-safe dari skema database. **Analogi:** Prisma seperti arsitek yang membaca cetak biru database dan membuat peta jalan yang sangat detail—setiap kolom, relasi, dan constraint diterjemahkan ke tipe. **Poin-Poin Penting:** - Prisma Client di-generate dari schema.prisma - Setiap query divalidasi di level tipe (select, include, where) - Hasil query secara otomatis memiliki tipe yang sesuai **Contoh Kode:** ```typescript // BENAR: // schema.prisma: // model User { //   id   Int    @id @default(autoincrement()) //   name String //   posts Post[] // } const user = await prisma.user.findUnique({ where: { id: 1 }, include: { posts: true } }); // user.name: string (type-safe) // user.posts: Post[] (type-safe) // ERROR: await prisma.user.findUnique({ where: { email: "test@test.com" } }); // ❌ error jika 'email' tidak ada di model User ``` **Kasus Penggunaan Nyata:** Menggantikan ORM tradisional yang mengembalikan `any` dengan fully typed database client yang mendeteksi error query saat kompilasi.
