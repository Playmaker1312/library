# 51. Intersection Types - tipe A dan B **Definisi Singkat:** Intersection type menggabungkan beberapa tipe menjadi satu tipe yang memiliki semua properti dari tipe-tipe tersebut, ditulis dengan `&` . **Analogi:** Seperti persilangan antara smartphone dan kamera DSLR — hasilnya memiliki kemampuan menelepon (dari smartphone) dan juga lensa profesional (dari kamera). **Poin-Poin Penting:** - Syntax: `TipeA & TipeB` - Nilai harus memenuhi semua tipe anggota - Berguna untuk komposisi object dan mixins **Contoh Kode:** ```typescript // BENAR (valid):
interface HasName { name: string; }
interface HasAge { age: number; }

type Person = HasName & HasAge;

const person: Person = { name: "Nina", age: 27 }; // valid — memiliki kedua properti

type WithID = { id: string };
type WithTimestamp = { createdAt: Date };
type Entity = WithID & WithTimestamp;
const entity: Entity = { id: "1", createdAt: new Date() };

// ERROR (type-error):
const wrong: Person = { name: "Nina" }; // error: Property 'age' is missing /* error */ ``` **Kasus Penggunaan Nyata:** Menggabungkan tipe dari berbagai sumber (seperti User & Permissions), pattern mixins, atau memperluas tipe bawaan library.
