# 54. Type Narrowing - konsep fundamental **Definisi Singkat:** Proses di mana TypeScript mempersempit tipe dari union type menjadi tipe yang lebih spesifik berdasarkan kondisi logika dalam kode. **Analogi:** Seperti detektif yang menyelidiki — awalnya ada beberapa tersangka (union), setelah mendapatkan bukti (kondisi), tersangka dipersempit ke satu orang (specific type). **Poin-Poin Penting:** - TypeScript mengikuti alur kontrol (control flow analysis) - Narrowing terjadi setelah `typeof`, `instanceof`, `in`, equality check, dll - Memungkinkan akses ke properti spesifik yang sebelumnya tidak aman **Contoh Kode:** ```typescript // BENAR (valid):
function padLeft(value: string, padding: string | number): string {
  if (typeof padding === "number") {
    // Di sini padding adalah number
    return " ".repeat(padding) + value;
  }
  // Di sini padding adalah string
  return padding + value;
}

// ERROR (type-error):
function example(val: string | number): void {
  val.toFixed(2); // error: Property 'toFixed' does not exist on type 'string | number'
  if (typeof val === "number") {
    val.toFixed(2); // OK — narrowed ke number
  }
} ``` **Kasus Penggunaan Nyata:** Semua fungsi yang menerima union type harus melakukan narrowing sebelum menggunakan properti spesifik — ini adalah konsep paling fundamental dalam TypeScript daily use.
