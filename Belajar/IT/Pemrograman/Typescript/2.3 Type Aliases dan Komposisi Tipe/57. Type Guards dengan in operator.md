# 57. Type Guards dengan in operator **Definisi Singkat:** Operator `in` memeriksa apakah suatu properti ada dalam object, dan TypeScript menggunakannya untuk narrow tipe dalam discriminated union. **Analogi:** Seperti mengecek apakah kulkas memiliki fitur "dispenser air" — jika ada, berarti kulkas tersebut adalah tipe tertentu (premium). **Poin-Poin Penting:** - Syntax: `"property" in object` - Mempersempit union berdasarkan keberadaan properti - Lebih berguna ketika tidak ada literal discriminant yang jelas **Contoh Kode:** ```typescript // BENAR (valid):
type Circle = { radius: number };
type Square = { side: number };
type Shape = Circle | Square;

function getArea(shape: Shape): number {
  if ("radius" in shape) {
    return Math.PI * shape.radius ** 2; // narrowed ke Circle
  }
  return shape.side ** 2; // narrowed ke Square
}

type Fish = { swim: () => void };
type Bird = { fly: () => void };

function move(animal: Fish | Bird): void {
  if ("swim" in animal) {
    animal.swim(); // narrowed ke Fish
  } else {
    animal.fly();  // narrowed ke Bird
  }
} ``` **Kasus Penggunaan Nyata:** Ketika varian union tidak memiliki tag literal eksplisit, `in` bisa mendeteksi varian berdasarkan properti unik yang dimiliki masing-masing.
