# 52. Literal Types dalam Union - membuat enum-like types **Definisi Singkat:** Menggunakan nilai literal (string, number, boolean) sebagai tipe dalam union untuk membatasi nilai yang diperbolehkan. **Analogi:** Seperti lampu lalu lintas — hanya tiga warna yang valid: merah, kuning, hijau. Tidak boleh biru atau ungu. **Poin-Poin Penting:** - Nilai literal menjadi tipe: `"red" | "yellow" | "green"` - Lebih aman daripada string biasa karena divalidasi - Bisa dikombinasikan dengan tipe lain dalam union **Contoh Kode:** ```typescript // BENAR (valid):
type Direction = "up" | "down" | "left" | "right";
type Status = "success" | "error" | "loading";
type OddNumber = 1 | 3 | 5 | 7 | 9;

function move(direction: Direction): void {
  console.log(`Bergerak ${direction}`);
}
move("up");  // valid
// move("back"); // error: Argument of type '"back"' is not assignable to parameter of type 'Direction' /* error */

// ERROR (type-error):
type TrafficLight = "red" | "yellow" | "green";
const light: TrafficLight = "blue"; // error: Type '"blue"' is not assignable to type 'TrafficLight' /* error */ ``` **Kasus Penggunaan Nyata:** State machine (loading | success | error), routing paths, action types di Redux, konfigurasi mode, dan parameter terbatas.
