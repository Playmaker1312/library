# 59. Nullable Types dan Non-null Assertion Operator **Definisi Singkat:** Tipe bisa null/undefined secara eksplisit dengan union; Non-null assertion (`!`) memberi tahu TS bahwa suatu nilai pasti tidak null/undefined. **Analogi:** Non-null assertion seperti menandatangani surat pernyataan "saya jamin orang ini ada" — Anda mengambil risiko sendiri jika ternyata tidak. **Poin-Poin Penting:** - Nullable: `type T = string | null | undefined` - Non-null assertion: `value!.property` — percaya bahwa value tidak null - Strict Null Checks: `strictNullChecks` di tsconfig **Contoh Kode:** ```typescript // BENAR (valid):
type User = { name: string; email?: string | null };

function getEmail(user: User): string {
  // Non-null assertion — kita yakin email ada
  return user.email!.toUpperCase();
}

function getName(user: User | null): string {
  if (user !== null) {
    return user.name; // narrowed, aman
  }
  return "Guest";
}

// ERROR (type-error):
function example(x?: string | null): void {
  const length: number = x.length; // error: Object is possibly 'undefined' or 'null'
  // Harus narrowing: if (x) { x.length } atau x!.length
}

// Non-null assertion yang salah di runtime
const el = document.getElementById("nonexistent")!; // el: HTMLElement, tapi runtime null!
``` **Kasus Penggunaan Nyata:** Mengakses DOM element yang pasti ada, refs di framework, atau data yang sudah divalidasi sebelumnya namun TS belum mengetahuinya.
