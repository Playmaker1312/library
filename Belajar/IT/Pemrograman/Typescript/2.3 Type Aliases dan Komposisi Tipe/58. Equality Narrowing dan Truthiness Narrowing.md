# 58. Equality Narrowing dan Truthiness Narrowing **Definisi Singkat:** TypeScript mempersempit tipe berdasarkan pemeriksaan kesamaan nilai (`===`, `!==`, `==`, `!=`) dan truthiness/falsiness. **Analogi:** Seperti penyortiran koin — jika sama dengan 1000 (equality), masukkan ke tabung seribu; jika ada isinya (truthy), proses, jika kosong (falsy), buang. **Poin-Poin Penting:** - Equality narrowing: membandingkan dengan literal atau tipe lain - Truthiness narrowing: `if (val)` akan filter falsy (null, undefined, 0, "", false, NaN) - Berguna untuk nullable types dan union **Contoh Kode:** ```typescript // BENAR (valid):
// Equality narrowing
function getStatus(status: "active" | "inactive" | "deleted"): string {
  if (status === "active") return "Aktif";
  if (status === "inactive") return "Non-aktif";
  return "Dihapus";
}

// Truthiness narrowing
function printLength(text?: string | null): void {
  if (text) {
    console.log(text.length); // narrowed: string (truthy, bukan null/undefined)
  } else {
    console.log("Tidak ada teks");
  }
}

// ERROR (type-error):
function example(x: string | number): void {
  if (x === "hello") {
    x.toFixed(2); // error: Property 'toFixed' does not exist on type 'string' — narrowed ke string /* error */
  }
} ``` **Kasus Penggunaan Nyata:** Filter falsy values sebelum diproses, membandingkan status literal, dan menghindari null/undefined di runtime.
