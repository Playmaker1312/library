# 55. Type Guards dengan typeof **Definisi Singkat:** Menggunakan operator `typeof` di runtime untuk memeriksa tipe primitif, yang sekaligus mempersempit tipe di TypeScript. **Analogi:** Seperti petugas bandara yang memeriksa paspor — melihat jenis dokumen (KTP/SIM/Paspor) untuk menentukan tindakan selanjutnya. **Poin-Poin Penting:** - `typeof` bisa memeriksa: string, number, boolean, symbol, undefined, object, function, bigint - Tidak bisa membedakan antar object types (null juga termasuk object) - Harus hati-hati dengan `typeof null === "object"` **Contoh Kode:** ```typescript // BENAR (valid):
function printValue(value: string | number | boolean): void {
  if (typeof value === "string") {
    console.log(`String: ${value.toUpperCase()}`);
  } else if (typeof value === "number") {
    console.log(`Number: ${value.toFixed(2)}`);
  } else {
    console.log(`Boolean: ${value}`);
  }
}

// ERROR (type-error):
function process(input: string | Date): void {
  if (typeof input === "object") {
    // Masih string | Date — typeof Date adalah "object", tapi string juga lolos? Tidak.
    // Sebenarnya ini tidak masalah, tapi tidak bisa narrowing Date spesifik
    input.getTime(); // error: Property 'getTime' does not exist on type 'string | Date' ?
    // Hati-hati: typeof string === "string", jadi ini aman, tapi TS tidak narrow ke Date
    // typeof tidak cukup untuk object types — perlu instanceof
  }
} ``` **Kasus Penggunaan Nyata:** Memvalidasi input dari user, parsing data API yang belum diketahui tipenya, atau handling fungsi polymorphic sederhana dengan primitif.
