# 48. Type Alias - deklarasi dengan keyword type **Definisi Singkat:** Type alias adalah cara memberi nama untuk suatu tipe, baik primitif, union, tuple, atau object, menggunakan keyword `type` . **Analogi:** Seperti nickname atau panggilan — daripada memanggil "Saudara laki-laki dari ibu saya" terus-menerus, cukup panggil "Paman". **Poin-Poin Penting:** - Syntax: `type Nama = Tipe` - Bisa untuk tipe apa pun — tidak terbatas pada object - Tidak bisa declaration merging (berbeda dengan interface) **Contoh Kode:** ```typescript // BENAR (valid):
type ID = string | number;
type Point = { x: number; y: number };
type Callback = (err: Error | null, result?: string) => void;

let userId: ID = "abc123";
userId = 456; // valid, union type

const origin: Point = { x: 0, y: 0 };

// ERROR (type-error):
type MyType = { a: string };
type MyType = { b: number }; // error: Duplicate identifier 'MyType' — tidak bisa declaration merging /* error */ ``` **Kasus Penggunaan Nyata:** Membuat alias untuk tipe kompleks seperti union type, tuple, atau fungsi callback yang digunakan berulang kali di codebase.
