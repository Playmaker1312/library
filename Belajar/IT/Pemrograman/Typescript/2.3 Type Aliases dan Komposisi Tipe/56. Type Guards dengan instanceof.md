# 56. Type Guards dengan instanceof **Definisi Singkat:** Operator `instanceof` memeriksa apakah suatu object adalah instance dari class tertentu, dan TypeScript mempersempit tipe berdasarkan itu. **Analogi:** Seperti memeriksa merek mobil — jika `instanceof Tesla`, Anda tahu mobil itu listrik dan punya Autopilot. **Poin-Poin Penting:** - Bekerja dengan class dan constructor functions - Memeriksa prototype chain — tidak untuk interface (karena interface hanya type-level) - Berguna untuk hierarchy class **Contoh Kode:** ```typescript // BENAR (valid):
class Bird {
  fly(): string { return "terbang"; }
}
class Fish {
  swim(): string { return "berenang"; }
}

function move(pet: Bird | Fish): string {
  if (pet instanceof Bird) {
    return pet.fly(); // narrowed ke Bird
  }
  return pet.swim();  // narrowed ke Fish
}

// ERROR (type-error):
interface Vehicle { drive(): void; }
class Car implements Vehicle { drive() { console.log("vroom"); } }

function test(v: Vehicle) {
  // instanceof hanya untuk class, bukan interface
  if (v instanceof Car) { /* OK — Car adalah class */ }
  // if (v instanceof Vehicle) {} // error: 'Vehicle' hanya refers to a type, but is being used as a value here /* error */
} ``` **Kasus Penggunaan Nyata:** Error handling dengan custom Error classes, DOM element type checking, atau sistem plugin dengan class hierarchy.
