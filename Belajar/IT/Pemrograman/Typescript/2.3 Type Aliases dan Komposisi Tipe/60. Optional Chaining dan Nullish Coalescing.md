# 60. Optional Chaining dan Nullish Coalescing **Definisi Singkat:** Optional chaining (`?.`) mengakses properti secara aman dari null/undefined; Nullish coalescing (`??`) memberikan fallback hanya untuk null/undefined. **Analogi:** Optional chaining seperti senter di gua — menerangi langkah selanjutnya, dan jika tidak ada jalan, berhenti tanpa jatuh. Nullish coalescing seperti kursi cadangan — hanya digunakan jika kursi utama kosong (bukan jika kursi sengaja dikosongkan). **Poin-Poin Penting:** - `?.` : `obj?.prop` — jika obj null/undefined, return undefined (tidak error) - `??` : `val ?? fallback` — fallback hanya jika val adalah null/undefined - Bukan `||` : `||` juga fallback untuk falsy (0, "", false) **Contoh Kode:** ```typescript // BENAR (valid):
interface User { name: string; address?: { city: string; zip?: string } }

function getCity(user: User): string {
  return user.address?.city ?? "Kota tidak diketahui";
}

// Optional chaining untuk method dan indexing
const result = someArray?.[0]?.toUpperCase() ?? "default";

// ERROR (type-error):
// Optional chaining menghasilkan undefined jika null — perlu handling
function getZip(user: User): string {
  // user.address?.zip bisa undefined
  return user.address?.zip; // error: Type 'string | undefined' is not assignable to type 'string'
  // Perbaikan: return user.address?.zip ?? "No zip";
}

// Perbedaan ?? dan ||
const count = 0;
const withOr = count || 10;   // 10 (karena 0 falsy)
const withNullish = count ?? 10; // 0 (karena 0 bukan null/undefined)
``` **Kasus Penggunaan Nyata:** Mengakses data nested dari API response, konfigurasi dengan default value, chaining method yang mungkin tidak ada.
