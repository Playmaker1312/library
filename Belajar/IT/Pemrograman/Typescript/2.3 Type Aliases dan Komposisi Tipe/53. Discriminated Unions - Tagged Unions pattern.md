# 53. Discriminated Unions - Tagged Unions pattern **Definisi Singkat:** Union type dengan satu properti literal (discriminant) yang membedakan setiap varian, memungkinkan type narrowing otomatis. **Analogi:** Seperti amplop dengan stempel "PENTING", "RAHASIA", atau "BIASA" — isi amplop berbeda tergantung stempelnya, dan Anda tahu cara menanganinya. **Poin-Poin Penting:** - Setiap varian memiliki properti diskriminan dengan literal type - TypeScript mempersempit tipe berdasarkan diskriminan - Pattern umum: `type Result = Success | Error` **Contoh Kode:** ```typescript // BENAR (valid):
type Shape =
  | { kind: "circle"; radius: number }
  | { kind: "square"; side: number }
  | { kind: "triangle"; base: number; height: number };

function area(s: Shape): number {
  switch (s.kind) {
    case "circle":   return Math.PI * s.radius ** 2;   // narrowed ke circle
    case "square":   return s.side ** 2;                // narrowed ke square
    case "triangle": return (s.base * s.height) / 2;    // narrowed ke triangle
  }
}

// ERROR (type-error):
const bad: Shape = { kind: "hexagon", side: 5 }; // error: Type '"hexagon"' is not comparable to type ... /* error */ ``` **Kasus Penggunaan Nyata:** State management (loading/success/error), Redux actions, protocol parsers, form field validasi dengan berbagai tipe nilai.
