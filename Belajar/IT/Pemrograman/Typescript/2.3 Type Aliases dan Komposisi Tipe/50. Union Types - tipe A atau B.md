# 50. Union Types - tipe A atau B **Definisi Singkat:** Union type menyatakan bahwa suatu nilai bisa berupa salah satu dari beberapa tipe, ditulis dengan operator `|` . **Analogi:** Seperti stopkontak universal — bisa menerima colokan tipe A, B, atau C, selama sesuai salah satunya. **Poin-Poin Penting:** - Syntax: `TipeA | TipeB | TipeC` - Nilai harus memenuhi setidaknya satu tipe anggota - TypeScript hanya mengizinkan akses ke properti/method yang umum (common) di semua anggota **Contoh Kode:** ```typescript // BENAR (valid):
type StringOrNumber = string | number;

function printValue(val: StringOrNumber): void {
  if (typeof val === "string") {
    console.log(val.toUpperCase());
  } else {
    console.log(val.toFixed(2));
  }
}

printValue("hello");
printValue(42);

// ERROR (type-error):
function getLength(val: string | number): number {
  return val.length; // error: Property 'length' does not exist on type 'number' /* error */
  // Harus narrowing dulu
}
``` **Kasus Penggunaan Nyata:** Parameter fungsi yang bisa menerima berbagai tipe input (seperti `string | string[]`), hasil API yang bisa sukses atau error, atau state machine dengan beberapa bentuk state.
