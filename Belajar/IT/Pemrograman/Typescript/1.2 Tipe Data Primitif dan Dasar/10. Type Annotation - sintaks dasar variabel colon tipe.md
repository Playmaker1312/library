# 10. Type Annotation - sintaks dasar variabel colon tipe

**Definisi Singkat:** Type annotation adalah sintaks `: type` setelah nama variabel/parameter/fungsi untuk memberi tahu TypeScript tipe data apa yang diharapkan.

**Analogi:** Seperti label "Isi: Susu" pada botol — memberi tahu isi tanpa harus membuka tutupnya. Kode jadi self-documenting.

**Poin-Poin Penting:**
- Sintaks: `let nama: tipe = nilai;` atau `const nama: tipe = nilai;`
- Type annotation opsional — TypeScript bisa infer tipe otomatis
- Bisa digunakan di: variabel, parameter fungsi, return type fungsi, properti objek

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid):
let nama: string = "Andi";
let umur: number = 25;
function sapa(nama: string): string {
  return "Halo " + nama;
}

// Contoh yang akan ERROR (type-error):
let umur: number = "dua puluh lima"; // /* error: Type 'string' is not assignable to type 'number' */
```

**Kasus Penggunaan Nyata:**
Di API response handler, setiap field response diberi type annotation — memastikan data dari server sesuai format yang diharapkan sebelum diproses lebih lanjut.
