# 15. Tipe void - untuk fungsi tanpa return

**Definisi Singkat:** `void` adalah tipe return untuk fungsi yang tidak mengembalikan nilai (`return` tanpa value, atau tidak ada `return` sama sekali).

**Analogi:** Seperti petugas MC yang bilang "selanjutnya..." lalu turun panggung — ia melakukan tugas (berbicara) tapi tidak membawa benda apapun (return value).

**Poin-Poin Penting:**
- Fungsi `void` bisa mengembalikan `undefined` (default JS) atau tidak return sama sekali
- `void` bukan tipe yang bisa diisi variabel secara manual — beda dengan `undefined`
- Di TS, fungsi `void` tidak boleh digunakan di assignment yang butuh nilai return

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid):
function logMessage(msg: string): void {
  console.log(msg);
  // tidak ada return — valid
}

// Contoh yang akan ERROR (type-error):
function getValue(): void {
  return 42; // /* error: Type 'number' is not assignable to type 'void' */
}
```

**Kasus Penggunaan Nyata:**
Event handler seperti `button.onClick` — fungsi handler biasanya `void` karena hanya melakukan aksi (log, state update) tanpa mengembalikan nilai yang berarti.
