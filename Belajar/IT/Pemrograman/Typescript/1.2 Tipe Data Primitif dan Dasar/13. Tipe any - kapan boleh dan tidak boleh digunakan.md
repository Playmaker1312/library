# 13. Tipe any - kapan boleh dan tidak boleh digunakan

**Definisi Singkat:** `any` adalah tipe "jalan keluar" dari type system — variabel `any` bisa diisi nilai apa saja dan semua operasi diizinkan tanpa type checking.

**Analogi:** `any` seperti papan catur tanpa aturan — pion bisa jalan seperti kuda, kuda bisa terbang. Kadang menyenangkan, tapi kacau balau untuk permainan serius.

**Poin-Poin Penting:**
- `any` mematikan type checking untuk variabel itu — akses properti apapun diizinkan
- Jangan gunakan di kode baru — gunakan `unknown` jika belum tahu tipenya
- Satu-satunya tempat `any` wajar: migrasi JS ke TS bertahap, atau nilai dari library tanpa tipe

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid) — tapi sebaiknya dihindari:
let data: any = "hello";
data = 42;         // OK
data.toUpperCase() // OK saat runtime (tapi error jika number)
console.log(data);

// Contoh yang akan ERROR — any membuat error runtime tidak terdeteksi:
let data2: any = 42;
data2.toUpperCase(); // /* error: Runtime error — data2.toUpperCase is not a function (TS tidak tangkap!) */
```

**Kasus Penggunaan Nyata:**
Saat migrasi bertahap kode JS 100.000 baris ke TS — gunakan `any` sebagai "to-do" untuk fungsi yang belum diberi tipe, dengan eslint rule `no-explicit-any` sebagai pengingat.
