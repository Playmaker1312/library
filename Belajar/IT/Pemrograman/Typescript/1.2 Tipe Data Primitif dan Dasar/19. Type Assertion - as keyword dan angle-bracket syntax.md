# 19. Type Assertion - as keyword dan angle-bracket syntax

**Definisi Singkat:** Type assertion memberi tahu TypeScript bahwa Anda lebih tahu tipe data sebenarnya — menggunakan keyword `as` atau syntax `<Tipe>`. Tidak mengubah runtime, hanya mengubah persepsi tipe.

**Analogi:** Seperti memberi tahu petugas keamanan "saya tamu undangan" sambil menunjukkan ID — Anda meyakinkan TypeScript bahwa nilai ini aman digunakan sebagai tipe tertentu, meski terlihat berbeda.

**Poin-Poin Penting:**
- Dua sintaks: `value as Type` (lebih umum, rekomended di JSX) dan `<Type>value` (tidak bisa di JSX)
- Type assertion tidak melakukan validasi runtime — jika salah, error baru ketahuan saat runtime
- Tidak bisa assert antara tipe yang tidak terkait — misal `number as string` error

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid):
const input: unknown = "hello world";
const panjang = (input as string).length; // OK — kita tahu itu string

// Contoh yang akan ERROR (type-error):
const angka = 42;
const str = angka as string; // /* error: Conversion of type 'number' to type 'string' may be a mistake */
```

**Kasus Penggunaan Nyata:**
DOM manipulation — `document.getElementById("btn")` return `HTMLElement | null`; gunakan `as HTMLButtonElement` untuk mengakses properti spesifik button seperti `disabled`.
