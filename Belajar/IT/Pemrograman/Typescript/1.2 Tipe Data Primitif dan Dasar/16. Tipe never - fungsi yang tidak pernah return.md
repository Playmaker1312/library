# 16. Tipe never - fungsi yang tidak pernah return

**Definisi Singkat:** `never` adalah tipe untuk fungsi yang tidak pernah selesai (infinite loop) atau pasti melempar error — tidak pernah mencapai akhir eksekusi normal.

**Analogi:** Seperti lubang hitam di luar angkasa — apapun yang masuk ke dalamnya tidak akan pernah keluar lagi (tidak pernah return). Atau seperti tombol "self-destruct" — sekali ditekan, sistem berhenti total.

**Poin-Poin Penting:**
- `never` berbeda dari `void` — `void` fungsi selesai tanpa nilai, `never` fungsi tidak pernah selesai
- Berguna untuk exhaustive checking di switch/if-else
- Variabel `never` hanya bisa diisi oleh nilai `never` (hanya dari fungsi `never`)

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid):
function throwError(msg: string): never {
  throw new Error(msg);
}

function infiniteLoop(): never {
  while (true) { /* infinite */ }
}

// Contoh yang akan ERROR (type-error):
function normalFunc(): never {
  return; // /* error: A function returning 'never' cannot have a reachable end point */
}
```

**Kasus Penggunaan Nyata:**
Exhaustive switch — memastikan semua kemungkinan union type telah di-handle. Jika ada anggota union baru yang ditambahkan, TypeScript akan error.
