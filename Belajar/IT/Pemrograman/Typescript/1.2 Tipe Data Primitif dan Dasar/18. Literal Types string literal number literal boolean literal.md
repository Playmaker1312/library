# 18. Literal Types - string literal number literal boolean literal

**Definisi Singkat:** Literal types memungkinkan tipe dispesifikasikan ke nilai persis (bukan kategori umum) — misal string `"success"`, number `42`, boolean `true`.

**Analogi:** Seperti menu restoran — bukan "minuman" (umum) tapi spesifik "Es Teh Manis" atau "Kopi Hitam" (literal). Server (TypeScript) tahu persis apa yang harus disajikan.

**Poin-Poin Penting:**
- Sintaks: `type Status = "success" | "error" | "loading"` — union dari literal
- Sering dikombinasi dengan union type untuk membuat opsi terbatas (discriminated union)
- Literal type dengan `const` otomatis — `const x = "hello"` → tipe `"hello"` (bukan `string`)

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid):
type Direction = "left" | "right" | "up" | "down";
function move(dir: Direction) { /* ... */ }
move("left");  // OK

// Contoh yang akan ERROR (type-error):
move("forward"); // /* error: Argument of type '"forward"' is not assignable to parameter of type 'Direction' */
```

**Kasus Penggunaan Nyata:**
State machine di frontend — tipe `"idle" | "loading" | "success" | "error"` memastikan state transisi hanya bisa ke state yang valid, mencegah bug state illegal.
