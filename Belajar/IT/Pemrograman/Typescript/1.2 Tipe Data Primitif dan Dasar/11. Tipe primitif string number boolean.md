# 11. Tipe primitif string number boolean

**Definisi Singkat:** `string`, `number`, dan `boolean` adalah tiga tipe primitif dasar TypeScript yang mewakili teks, angka, dan nilai kebenaran.

**Analogi:** Seperti tiga warna primer dalam seni — merah (string=teks), biru (number=angka), kuning (boolean=true/false). Semua tipe lain adalah turunan atau kombinasi dari ini.

**Poin-Poin Penting:**
- `string`: petik tunggal, ganda, atau backtick (template literal) — semua valid
- `number`: integer dan float — tidak ada `int`/`float` terpisah, semua `number`
- `boolean`: hanya `true` atau `false` — truthy/falsy JS tetap ada tapi tipe harus boolean

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid):
let teks: string = "Halo";
let angka: number = 3.14;
let isDone: boolean = false;

// Contoh yang akan ERROR (type-error):
let angka2: number = "tiga"; // /* error: Type 'string' is not assignable to type 'number' */
let bool: boolean = 0;       // /* error: Type 'number' is not assignable to type 'boolean' */
```

**Kasus Penggunaan Nyata:**
Form validation — field `email: string` dipastikan string, `age: number` divalidasi numerik, `isSubscribed: boolean` untuk status — mencegah data salah masuk database.
