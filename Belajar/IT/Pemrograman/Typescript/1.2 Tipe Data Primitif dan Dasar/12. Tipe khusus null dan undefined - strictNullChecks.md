# 12. Tipe khusus null dan undefined - strictNullChecks

**Definisi Singkat:** Di TypeScript, `null` dan `undefined` adalah tipe terpisah; dengan `strictNullChecks: true`, keduanya tidak bisa ditugaskan ke tipe lain secara otomatis.

**Analogi:** Seperti pintu masuk gedung dengan security — tanpa strictNullChecks semua orang bisa masuk seenaknya; dengan strictNullChecks, hanya orang dengan undangan (tipe yang sesuai) yang diizinkan.

**Poin-Poin Penting:**
- `strictNullChecks: true` (diaktifkan via `strict: true`) — null/undefined tidak bisa diassign ke tipe lain
- Gunakan union type: `string | null` atau `string | undefined` untuk mengizinkannya
- `null` dan `undefined` berbeda tipe — `null === null` dan `undefined === undefined`

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid):
let nama: string | null = null;
nama = "Budi"; // OK — bisa null atau string

// Contoh yang akan ERROR (type-error):
let umur: number = null; // /* error: Type 'null' is not assignable to type 'number' */
```

**Kasus Penggunaan Nyata:**
Database query — field `middleName: string | null` pada user profile; jika user tidak punya nama tengah, nilainya `null`, bukan string kosong — perbedaan semantik penting.
