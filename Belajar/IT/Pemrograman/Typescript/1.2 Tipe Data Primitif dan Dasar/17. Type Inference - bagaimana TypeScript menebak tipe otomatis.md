# 17. Type Inference - bagaimana TypeScript menebak tipe otomatis

**Definisi Singkat:** Type Inference adalah kemampuan TypeScript menebak tipe data secara otomatis dari nilai yang diberikan, tanpa perlu type annotation eksplisit.

**Analogi:** Seperti detektif yang menyimpulkan profesi seseorang dari pakaiannya — Anda tidak perlu bilang "saya programmer", kemeja flanel dan laptop sudah cukup memberi tahu.

**Poin-Poin Penting:**
- TypeScript infer tipe dari nilai inisialisasi: `let x = 5` → `x: number`
- Return type fungsi diinfer dari nilai `return` di dalamnya
- Inference tidak sempurna — untuk fungsi kompleks atau publik API, annotation eksplisit lebih baik

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid) — inference bekerja:
let nama = "Andi";         // TypeScript infer: string
let umur = 25;             // infer: number
let isActive = true;       // infer: boolean

// Contoh yang akan ERROR — inference menyelamatkan:
let nilai = "seratus";
nilai = 100; // /* error: Type 'number' is not assignable to type 'string' */
```

**Kasus Penggunaan Nyata:**
Mapping array dengan `.map()` — TypeScript infer tipe elemen array dan tipe return callback, sehingga hasil mapping otomatis memiliki tipe array yang benar tanpa anotasi manual.
