# 14. Tipe unknown - alternatif aman untuk any

**Definisi Singkat:** `unknown` seperti `any` tapi aman — variabel `unknown` bisa diisi apa saja, tetapi tidak bisa dioperasikan sebelum tipenya dipersempit (type narrowing).

**Analogi:** `unknown` seperti koper tertutup di bandara — isinya bisa apa saja, tapi harus diperiksa dulu (type narrowing) sebelum diizinkan masuk ke pesawat (dipakai operasinya).

**Poin-Poin Penting:**
- Sama seperti `any`: bisa menampung nilai apa pun
- Beda dengan `any`: tidak boleh dipanggil method/property tanpa type narrowing dulu
- Narrowing: `typeof`, `instanceof`, atau type guard function

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid):
let data: unknown = "hello";
if (typeof data === "string") {
  console.log(data.toUpperCase()); // OK — sudah diperiksa
}

// Contoh yang akan ERROR (type-error):
let data2: unknown = "hello";
data2.toUpperCase(); // /* error: 'data2' is of type 'unknown' */
```

**Kasus Penggunaan Nyata:**
Parser JSON dari API eksternal — `JSON.parse()` return `any`; wrapping dengan `unknown` memaksa developer melakukan validasi tipe sebelum data dipakai, mencegah runtime crash.
