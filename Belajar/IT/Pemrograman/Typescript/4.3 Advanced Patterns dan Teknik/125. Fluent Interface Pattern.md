# 125. Fluent Interface Pattern

**Definisi Singkat:** Fluent interface pattern menggunakan method chaining dengan setiap method mengembalikan `this`, memungkinkan sintaks yang terbaca seperti kalimat bahasa Inggris.

**Analogi:** Seperti bermain Lego — kamu menyambung satu balok (method) ke balok lain, dan hasil sambungannya masih bisa disambung lagi dengan balok berikutnya.

**Poin-Poin Penting:**
- Setiap method mengembalikan `this` sehingga bisa dirantai
- Menggunakan return type `this` (polymorphic this type)
- Sangat umum di builder pattern, query builder, dan konfigurasi API

**Contoh Kode:**
```typescript
// BENAR: fluent interface
class QueryBuilder {
  private query: string[] = [];

  select(fields: string[]): this {
    this.query.push(`SELECT ${fields.join(", ")}`);
    return this;
  }

  from(table: string): this {
    this.query.push(`FROM ${table}`);
    return this;
  }

  where(condition: string): this {
    this.query.push(`WHERE ${condition}`);
    return this;
  }

  orderBy(field: string, dir: "ASC" | "DESC" = "ASC"): this {
    this.query.push(`ORDER BY ${field} ${dir}`);
    return this;
  }

  build(): string {
    return this.query.join(" ");
  }
}

const sql = new QueryBuilder()
  .select(["id", "name"])
  .from("users")
  .where("age > 18")
  .orderBy("name")
  .build(); // ✅ "SELECT id, name FROM users WHERE age > 18 ORDER BY name ASC"

// ERROR: jika method tidak mengembalikan this, chaining terputus
// new QueryBuilder().select(["id"]).from("users").where(""); // ✅
```

**Kasus Penggunaan Nyata:** API client configuration, query builders ORM, pipeline/stream processing, atau pembuatan report/export configuration secara berantai.
