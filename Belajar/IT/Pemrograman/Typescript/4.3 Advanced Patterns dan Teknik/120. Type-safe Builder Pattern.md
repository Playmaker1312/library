# 120. Type-safe Builder Pattern

**Definisi Singkat:** Builder pattern dengan TypeScript memungkinkan pembuatan objek kompleks secara bertahap dengan method chaining yang tetap type-safe.

**Analogi:** Seperti merakit mobil di bengkel — kamu memasang komponen satu per satu (mesin dulu, lalu roda, dll.) dengan panduan yang memastikan urutan yang benar.

**Poin-Poin Penting:**
- Menggunakan `this` return type untuk method chaining
- Bisa dikombinasikan dengan generic untuk memvalidasi urutan/state builder
- Mencegah pembuatan objek dengan konfigurasi yang tidak lengkap

**Contoh Kode:**
```typescript
// BENAR: builder pattern sederhana
class UserBuilder {
  private user: { name?: string; age?: number; email?: string } = {};

  setName(name: string): this {
    this.user.name = name;
    return this;
  }

  setAge(age: number): this {
    this.user.age = age;
    return this;
  }

  setEmail(email: string): this {
    this.user.email = email;
    return this;
  }

  build(): { name: string; age: number; email: string } {
    return this.user as { name: string; age: number; email: string };
  }
}

const user = new UserBuilder()
  .setName("Budi")
  .setAge(25)
  .setEmail("budi@mail.com")
  .build(); // ✅

// ERROR: build sebelum semua required field terisi
// new UserBuilder().setName("Budi").build(); // runtime undefined, tidak ada compile check
```

**Kasus Penggunaan Nyata:** Membangun konfigurasi kompleks, query builder database, atau pembuatan objek DTO dengan banyak field opsional.
