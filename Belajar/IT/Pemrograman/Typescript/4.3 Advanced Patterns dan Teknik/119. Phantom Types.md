# 119. Phantom Types

**Definisi Singkat:** Phantom types adalah tipe yang memiliki parameter type yang tidak digunakan dalam struktur data, hanya digunakan untuk melacak informasi type-level tambahan.

**Analogi:** Seperti stiker "Fragile" di kotak barang — stiker tidak mengubah isi kotak, tapi memberi informasi tambahan (type parameter) tentang bagaimana kotak harus diperlakukan.

**Poin-Poin Penting:**
- Parameter type tidak muncul di representasi runtime
- Berguna untuk encoding state, unit, atau permission di level tipe
- Tidak menambah overhead runtime karena type parameter hilang setelah kompilasi

**Contoh Kode:**
```typescript
// BENAR: phantom type untuk state
enum State { Unvalidated, Validated }

class Data<T extends State> {
  constructor(public value: string) {}
}

function validate(data: Data<State.Unvalidated>): Data<State.Validated> {
  return new Data<State.Validated>(data.value);
}

function process(data: Data<State.Validated>): void {
  console.log("Processing:", data.value);
}

const raw = new Data<State.Unvalidated>("some data");
const validated = validate(raw);
process(validated); // ✅

// ERROR: data belum divalidasi
// process(raw); // ❌ Unvalidated tidak assignable ke Validated
```

**Kasus Penggunaan Nyata:** State machine di level tipe — memastikan data melalui tahapan tertentu (validasi, otorisasi) sebelum diproses, tanpa biaya runtime.
