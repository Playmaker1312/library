# 118. Branded Types atau Opaque Types

**Definisi Singkat:** Branded types membuat tipe unik secara nominal dengan menambahkan "brand" (cap) meskipun struktur datanya identik, mencegah pertukaran nilai yang tidak disengaja.

**Analogi:** Seperti gelang identitas rumah sakit — setiap pasien punya gelang dengan warna/kode berbeda meskipun bentuk gelangnya sama, sehingga tidak tertukar.

**Poin-Poin Penting:**
- Menggunakan intersection dengan `{ __brand: unique symbol }` atau properti brand
- Mencegah kasus di mana dua tipe dengan struktur sama bisa dipertukarkan
- Bersifat compile-time only, tidak ada overhead runtime

**Contoh Kode:**
```typescript
// BENAR: branded type
type UserId = string & { __brand: "UserId" };
type ProductId = string & { __brand: "ProductId" };

function createUserId(id: string): UserId {
  return id as UserId;
}

function getUser(id: UserId): void {
  console.log(id);
}

const uid = createUserId("U-001");
getUser(uid); // ✅

// ERROR: tercegah tertukar
// const pid: ProductId = "P-001" as ProductId;
// getUser(pid); // ❌ ProductId tidak assignable ke UserId
```

**Kasus Penggunaan Nyata:** Mencegah tertukarnya ID antar entitas (User ID vs Product ID), atau unit value (Meters vs Inches) yang punya struktur tipe sama (number).
