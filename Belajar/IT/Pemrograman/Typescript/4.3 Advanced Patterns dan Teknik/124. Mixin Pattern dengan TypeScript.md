# 124. Mixin Pattern dengan TypeScript

**Definisi Singkat:** Mixin pattern memungkinkan komposisi perilaku (behavior) dari beberapa class source ke satu class target tanpa menggunakan inheritance tunggal.

**Analogi:** Seperti membuat kustom pizza — kamu bisa memilih topping (mixin) dari berbagai bahan yang tersedia dan menggabungkannya ke satu pizza (class target).

**Poin-Poin Penting:**
- Menggunakan class expression dan `constructor return` pattern
- TypeScript membutuhkan constraint `Constructor` type untuk mendukung mixin
- Alternatif untuk multiple inheritance yang tidak didukung JavaScript

**Contoh Kode:**
```typescript
// BENAR: Constructor type helper
type Constructor<T = {}> = new (...args: any[]) => T;

function TimestampMixin<TBase extends Constructor>(Base: TBase) {
  return class extends Base {
    timestamp = new Date();

    getTimestamp() {
      return this.timestamp;
    }
  };
}

function LoggerMixin<TBase extends Constructor>(Base: TBase) {
  return class extends Base {
    log(msg: string) {
      console.log(`[${new Date().toISOString()}] ${msg}`);
    }
  };
}

class User {
  constructor(public name: string) {}
}

// Gabung mixin
const EnhancedUser = TimestampMixin(LoggerMixin(User));
const user = new EnhancedUser("Budi");
user.log("User created"); // ✅
console.log(user.getTimestamp()); // ✅
console.log(user.name); // "Budi" ✅

// ERROR: mixin harus dipanggil dengan class constructor
// const Bad = TimestampMixin({}); // ❌
```

**Kasus Penggunaan Nyata:** Menambahkan logging, timestamping, event emitting, atau validasi ke berbagai class tanpa duplikasi kode.
