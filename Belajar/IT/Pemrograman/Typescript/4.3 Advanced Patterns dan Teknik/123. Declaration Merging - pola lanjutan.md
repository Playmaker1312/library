# 123. Declaration Merging - pola lanjutan

**Definisi Singkat:** Declaration merging adalah kemampuan TypeScript menggabungkan beberapa deklarasi dengan nama yang sama menjadi satu entitas, umum pada interface dan namespace.

**Analogi:** Seperti papan catatan tempel — beberapa orang bisa menempelkan catatan di papan yang sama (nama yang sama), dan hasilnya adalah kumpulan semua catatan tersebut.

**Poin-Poin Penting:**
- Interface: deklarasi dengan nama yang sama akan digabung propertinya
- Namespace: bisa digabung dengan class, function, atau enum
- Biasa digunakan untuk augmentasi library atau module pihak ketiga

**Contoh Kode:**
```typescript
// BENAR: declaration merging pada interface
interface User {
  name: string;
}

interface User {
  age: number;
}

// Hasil merger: User = { name: string; age: number }
const user: User = { name: "Budi", age: 25 }; // ✅

// BENAR: namespace merging dengan class
class Logger {
  log(msg: string) { console.log(msg); }
}

namespace Logger {
  export const level = "info";
  export function format(msg: string): string {
    return `[${Logger.level}] ${msg}`;
  }
}

// Logger sekarang punya method log dan static property level serta format
Logger.format("test"); // ✅

// ERROR: type alias tidak bisa merge
// type A = { x: number };
// type A = { y: number }; // ❌ Duplicate identifier
```

**Kasus Penggunaan Nyata:** Menambah deklarasi properti ke library eksternal (module augmentation), memperluas express Request untuk menambah user property.
