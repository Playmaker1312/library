# 132. DefinitelyTyped dan types packages

**Definisi Singkat:** DefinitelyTyped adalah repositori raksasa berisi ribuan declaration files untuk library JavaScript populer, diakses melalui package `@types/nama-package`.

**Analogi:** Seperti toko suku cadang universal — Anda tidak perlu membuat sendiri komponen (tipe) untuk setiap mesin (library), karena sudah tersedia.

**Poin-Poin Penting:**
- Diinstal via npm: `npm install -D @types/express`
- TypeScript otomatis mencari tipe di `node_modules/@types`
- Beberapa library sudah menyertakan tipe bawaan (built-in types)
- Kontribusi terbuka untuk semua orang di github.com/DefinitelyTyped

**Contoh Kode:**
```bash
# Menginstal tipe untuk express
npm install -D @types/express

# Atau untuk lodash
npm install -D @types/lodash
```

```typescript
import express from 'express';
// BENAR: TypeScript tahu semua tipe express
const app = express();
app.get('/', (req, res) => {
  res.send('Hello');
});

// ERROR: tanpa @types, req/res akan any
// atau error module not found
```

**Kasus Penggunaan Nyata:** Mendapatkan type safety instan untuk ribuan library JavaScript populer tanpa menulis deklarasi manual.
