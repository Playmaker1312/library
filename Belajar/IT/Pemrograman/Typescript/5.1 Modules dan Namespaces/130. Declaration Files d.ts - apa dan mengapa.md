# 130. Declaration Files d.ts - apa dan mengapa

**Definisi Singkat:** Declaration files (`.d.ts`) adalah file yang berisi definisi tipe TypeScript saja — tanpa implementasi. Mereka memberi tahu TypeScript tentang bentuk kode JavaScript biasa.

**Analogi:** Seperti buku manual mesin — Anda tidak perlu membongkar mesin (source code JS), cukup tahu tombol apa (tipe) yang ada dan fungsinya.

**Poin-Poin Penting:**
- Hanya berisi deklarasi tipe, bukan logika
- Memungkinkan TypeScript memahami library JavaScript
- Dihasilkan otomatis dengan `declaration: true` di tsconfig
- Juga bisa ditulis manual untuk library yang tidak memiliki tipe

**Contoh Kode:**
```typescript
// types.d.ts
export interface User {
  name: string;
  age: number;
}
export function greet(user: User): void;

// BENAR: TypeScript tahu tipe dari declaration file
import { User } from './types';

// ERROR: declaration file tidak bisa berisi implementasi
export function greet(user: User) {
  console.log(user.name); // ❌ tidak boleh ada body
}
```

**Kasus Penggunaan Nyata:** Menyediakan type safety saat menggunakan library JavaScript yang tidak memiliki tipe bawaan.
