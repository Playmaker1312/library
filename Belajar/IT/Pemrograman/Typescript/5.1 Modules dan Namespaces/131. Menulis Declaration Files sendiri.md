# 131. Menulis Declaration Files sendiri

**Definisi Singkat:** Menulis `.d.ts` manual diperlukan ketika Anda menggunakan library JavaScript tanpa tipe, atau ingin membuat deklarasi khusus untuk lingkungan tertentu.

**Analogi:** Seperti membuat petunjuk penggunaan untuk alat yang belum memiliki buku manual — Anda menuliskan sendiri agar orang lain bisa menggunakannya dengan aman.

**Poin-Poin Penting:**
- Gunakan `declare` untuk memberitahu TypeScript bahwa sesuatu ada di runtime
- Declaration file bisa untuk variabel, fungsi, class, dan module
- Tempatkan deklarasi global atau module sesuai konteks

**Contoh Kode:**
```typescript
// globals.d.ts
declare const VERSION: string;
declare function log(message: string): void;

// modules.d.ts untuk library tanpa tipe
declare module 'old-library' {
  export function doSomething(input: number): string;
  export const version: number;
}

// BENAR: menggunakan deklarasi sendiri
console.log(VERSION); // string
log('hello');

// ERROR: tipe tidak cocok dengan deklarasi
log(123); // ❌ harus string
```

**Kasus Penggunaan Nyata:** Membungkus library JavaScript legacy atau internal yang tidak memiliki tipe agar tetap type-safe.
