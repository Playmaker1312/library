# 129. Path Mapping - paths dan baseUrl di tsconfig

**Definisi Singkat:** Path mapping memungkinkan Anda mendefinisikan alias untuk path module, sehingga import tidak perlu menggunakan path relatif panjang seperti `../../../../utils`.

**Analogi:** Seperti pintasan (shortcut) di desktop — Anda bisa mengakses folder yang dalam hanya dengan satu klik, tanpa harus menelusuri hirarki.

**Poin-Poin Penting:**
- `baseUrl` menetapkan direktori dasar untuk semua import non-relatif
- `paths` mendefinisikan alias custom untuk module
- Path mapping hanya untuk TypeScript, perlu di-resolve juga oleh bundler/runtime

**Contoh Kode:**
```typescript
// tsconfig.json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@utils/*": ["src/utils/*"],
      "@components/*": ["src/components/*"]
    }
  }
}

// BENAR: menggunakan alias
import { formatDate } from '@utils/date';

// ERROR: alias tidak dikenal
import { formatDate } from '@helpers/date';

// Tanpa alias (tidak disarankan)
import { formatDate } from '../../utils/date';
```

**Kasus Penggunaan Nyata:** Membersihkan struktur import yang berantakan pada proyek besar dengan banyak folder bersarang.
