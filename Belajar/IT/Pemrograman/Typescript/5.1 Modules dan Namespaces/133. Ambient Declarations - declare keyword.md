# 133. Ambient Declarations - declare keyword

**Definisi Singkat:** Ambient declarations menggunakan kata kunci `declare` untuk memberi tahu TypeScript bahwa suatu variabel, fungsi, atau class ada di lingkungan runtime (browser, Node.js) tanpa perlu menyediakan implementasi.

**Analogi:** Seperti Anda memberi tahu teman bahwa "ada pintu di sana" tanpa harus membangun pintunya — Anda hanya mendeklarasikan keberadaannya.

**Poin-Poin Penting:**
- `declare` tidak menghasilkan kode JavaScript
- Sering digunakan untuk mendeklarasikan API lingkungan (window, process)
- Bisa digunakan untuk variabel, fungsi, class, enum, namespace, dan module

**Contoh Kode:**
```typescript
// Ambient variable
declare var __DEV__: boolean;

// Ambient function
declare function fetch(url: string): Promise<Response>;

// Ambient class
declare class Player {
  constructor(name: string);
  play(): void;
}

// BENAR: menggunakan deklarasi ambient
if (__DEV__) console.log('dev mode');

// ERROR: mencoba mengimplementasi
declare function foo() { return 1; } // ❌ tidak boleh ada body
```

**Kasus Penggunaan Nyata:** Mendefinisikan tipe untuk global variables yang disediakan oleh bundler (seperti `process.env.NODE_ENV`) atau CDN scripts.
