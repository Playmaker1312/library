# 128. Module Resolution Strategies - node classic bundler

**Definisi Singkat:** Strategi module resolution menentukan bagaimana TypeScript mencari file module ketika menggunakan `import`. Pilihan utamanya adalah `node`, `node16`, `nodenext`, dan `bundler`.

**Analogi:** Seperti petunjuk arah — strategi yang berbeda memberi rute berbeda untuk menemukan alamat (file) yang Anda cari.

**Poin-Poin Penting:**
- `node` (klasik) meniru mekanisme resolusi Node.js lama
- `node16`/`nodenext` mendukung ES Modules dan CJS secara kondisional
- `bundler` mengoptimalkan untuk tools bundler seperti Webpack/Vite
- `classic` adalah strategi lama (default sebelum TS 2.0)

**Contoh Kode:**
```typescript
// tsconfig.json (contoh)
{
  "compilerOptions": {
    "moduleResolution": "bundler",  // Untuk Vite/Webpack
    "module": "esnext"
  }
}

// BENAR: bundler strategy lebih longgar
import { foo } from 'some-lib'; // tanpa ekstensi file

// ERROR: node16 membutuhkan ekstensi .js
import { foo } from './utils'; // harus './utils.js'
```

**Kasus Penggunaan Nyata:** Memilih strategi resolution yang tepat sangat penting untuk kompatibilitas dengan runtime (Node.js, Deno, Bun) dan bundler yang digunakan.
