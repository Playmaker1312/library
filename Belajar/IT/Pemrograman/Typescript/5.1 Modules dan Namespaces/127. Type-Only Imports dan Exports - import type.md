# 127. Type-Only Imports dan Exports - import type

**Definisi Singkat:** `import type` dan `export type` memungkinkan import/export hanya untuk tipe TypeScript tanpa menghasilkan kode JavaScript saat kompilasi.

**Analogi:** Seperti melihat katalog (tipe) tanpa membawa barang fisiknya — Anda hanya perlu tahu bentuknya, bukan implementasinya.

**Poin-Poin Penting:**
- Menggunakan `import type` menghilangkan import dari output JavaScript
- Berguna untuk menghindari circular dependency dan mengurangi bundle size
- Didukung penuh sejak TypeScript 3.8

**Contoh Kode:**
```typescript
// types.ts
export interface User { name: string; age: number; }
export type Status = 'active' | 'inactive';

// service.ts
import type { User, Status } from './types.js';
// BENAR: hanya mengimport tipe
function processUser(u: User, s: Status) {}

// ERROR: mencoba menggunakan nilai dari import type
import type { someValue } from './types.js';
```

**Kasus Penggunaan Nyata:** Memisahkan tipe dari implementasi untuk menjaga keamanan tree-shaking dan menghindari bundling yang tidak perlu.
