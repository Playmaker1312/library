# 135. Global Augmentation

**Definisi Singkat:** Global augmentation memungkinkan Anda menambahkan properti atau method ke scope global (seperti `window`, `global`, atau `console`) di TypeScript.

**Analogi:** Seperti menambahkan tombol baru ke dashboard mobil — semua pengemudi (semua kode) bisa melihat dan menggunakannya.

**Poin-Poin Penting:**
- Gunakan `declare global` di dalam file module (.ts)
- File harus berupa module (ada import/export) agar tidak dianggap global declaration
- Berguna untuk polyfill atau API kustom browser

**Contoh Kode:**
```typescript
// global-augment.ts
export {}; // buat file menjadi module

declare global {
  interface Window {
    myApp: { version: string };
  }
  function trackEvent(name: string): void;
}

// app.ts
// BENAR: window.myApp tersedia global
window.myApp = { version: '1.0' };
trackEvent('page_view');

// ERROR: properti tidak dideklarasikan
window.undefinedProp = 'test';
```

**Kasus Penggunaan Nyata:** Mendeklarasikan API global yang disuntikkan oleh CMS atau platform hosting ke dalam window object.
