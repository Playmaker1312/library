# 134. Module Augmentation

**Definisi Singkat:** Module augmentation memungkinkan Anda menambahkan properti atau method baru ke module yang sudah ada, termasuk module dari npm atau file lain, tanpa mengubah source aslinya.

**Analogi:** Seperti menambahkan rak baru ke lemari yang sudah ada — Anda memperluas fungsionalitas tanpa merusak lemari aslinya.

**Poin-Poin Penting:**
- Gunakan `declare module 'nama-module'` di file tersendiri
- Hanya perluasan tipe, tidak mengubah implementasi asli
- Berguna untuk menambahkan properti ke library pihak ketiga

**Contoh Kode:**
```typescript
// augmentations.d.ts
import 'express';

declare module 'express' {
  interface Request {
    user?: { id: number; name: string };
  }
}

// app.ts
import express from 'express';
const app = express();
app.use((req, res, next) => {
  // BENAR: req.user tersedia berkat augmentation
  req.user = { id: 1, name: 'Alice' };
  next();
});

// ERROR: tanpa augmentation, req.user tidak dikenal
```

**Kasus Penggunaan Nyata:** Menambahkan properti kustom ke `express.Request` untuk middleware autentikasi.
