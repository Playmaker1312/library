# 126. ES Modules dalam TypeScript - import export

**Definisi Singkat:** ES Modules adalah standar resmi JavaScript untuk mengorganisir kode ke dalam file terpisah. TypeScript mendukung penuh sintaks `import` dan `export` ES Modules.

**Analogi:** Seperti perpustakaan — setiap buku (module) bisa dipinjam (import) dan dikembalikan (export) oleh anggota perpustakaan lain.

**Poin-Poin Penting:**
- `export` digunakan untuk mengekspos fungsi, class, atau variabel dari sebuah module
- `import` digunakan untuk mengambil konten dari module lain
- TypeScript mendukung default export dan named export

**Contoh Kode:**
```typescript
// math.ts
export function add(a: number, b: number): number {
  return a + b;
}
export const PI = 3.14;
export default class Calculator {}

// app.ts
import Calculator, { add, PI } from './math.js';
// BENAR: import default dan named bersamaan
console.log(add(PI, 2)); // 5.14

// ERROR: default import tanpa nama
import { default } from './math.js';
```

**Kasus Penggunaan Nyata:** Memisahkan kode ke dalam modul-modul kecil untuk memudahkan pengelolaan, pengujian, dan kolaborasi tim.
