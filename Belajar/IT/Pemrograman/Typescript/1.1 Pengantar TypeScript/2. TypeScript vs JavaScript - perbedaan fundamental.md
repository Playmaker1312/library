# 2. TypeScript vs JavaScript - perbedaan fundamental

**Definisi Singkat:** TypeScript adalah superset JavaScript — semua kode JS adalah TS valid, tapi TS memiliki type system, interfaces, dan fitur tambahan yang tidak ada di JS.

**Analogi:** JavaScript seperti pensil — bisa menulis apa saja tanpa aturan. TypeScript seperti pulpen dengan templat — ada aturan yang mencegah kesalahan sebelum terjadi.

**Poin-Poin Penting:**
- TypeScript butuh kompilasi (transpile) → JavaScript; JS langsung dijalankan
- TS punya type annotation, enum, interface, generics; JS tidak punya
- File TS berekstensi `.ts`, file JS `.js`; TS bisa import JS tapi tidak sebaliknya

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid):
function add(a: number, b: number): number {
  return a + b;
}

// Contoh yang akan ERROR (type-error):
function addWrong(a: number, b: number): number {
  return a + b + "extra"; // /* error: Type 'string' is not assignable to type 'number' */
}
```

**Kasus Penggunaan Nyata:**
Migrasi kode JS ke TS bertahap — cukup rename `.js` ke `.ts` lalu tambahkan tipe secara gradual tanpa mengubah runtime behavior program.
