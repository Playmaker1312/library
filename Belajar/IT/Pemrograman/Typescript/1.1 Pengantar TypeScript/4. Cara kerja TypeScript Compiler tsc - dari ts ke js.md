# 4. Cara kerja TypeScript Compiler tsc - dari ts ke js

**Definisi Singkat:** `tsc` (TypeScript Compiler) membaca file `.ts`, memeriksa type errors, lalu mentranspile ke file `.js` yang bisa dijalankan Node/browser.

**Analogi:** tsc seperti compiler C++ — source code (TS) → type checking → output code (JS). Bedanya output JS tetap readable, bukan binary.

**Poin-Poin Penting:**
- tsc menjalankan: parsing → type checking → code generation (emit)
- Jika ada type error, tsc tetap menghasilkan file JS kecuali `noEmitOnError: true`
- `tsc --noEmit` untuk cek type saja tanpa generate file JS (biasa di CI/CD)

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid) - input app.ts:
const age: number = 25;
console.log(age);

// Contoh yang akan ERROR - output tetap digenerate (default):
const age: number = "twenty"; // /* error: Type 'string' is not assignable to type 'number' */
// tsc tetap menghasilkan app.js: var age = "twenty"; console.log(age);
```

**Kasus Penggunaan Nyata:**
Di pipeline CI, jalankan `tsc --noEmit` untuk memvalidasi semua tipe tanpa menghasilkan file — memastikan tidak ada type error sebelum build produksi.
