# 8. TypeScript Playground - eksperimen online

**Definisi Singkat:** TypeScript Playground (typescriptlang.org/play) adalah editor online resmi untuk menulis TS dan melihat hasil JS secara real-time tanpa instalasi.

**Analogi:** Seperti laboratorium virtual — bisa mencoba reaksi kimia (eksperimen kode) tanpa harus ke lab fisik (instalasi lokal). Cocok untuk prototyping cepat.

**Poin-Poin Penting:**
- Bisa dipakai tanpa login — cukup buka browser dan tulis TS
- Menampilkan output JS di panel sebelah kanan secara live
- Bisa ganti versi TS, target, dan melihat type definitions (file .d.ts)

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid) - coba di playground:
const arr = [1, 2, 3];
arr.push(4); // OK
console.log(arr);

// Contoh yang akan ERROR:
arr.push("hello"); // /* error: Argument of type 'string' is not assignable to parameter of type 'number' */
```

**Kasus Penggunaan Nyata:**
Developer ingin mencoba fitur TypeScript baru (misal `satisfies` operator) sebelum memutuskan upgrade versi di proyek — cukup buka Playground dan tes instan.
