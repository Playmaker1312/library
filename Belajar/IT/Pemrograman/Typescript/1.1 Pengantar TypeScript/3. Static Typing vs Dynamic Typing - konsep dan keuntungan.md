# 3. Static Typing vs Dynamic Typing - konsep dan keuntungan

**Definisi Singkat:** Static typing (TS) memeriksa tipe saat kompilasi; dynamic typing (JS) memeriksa tipe saat runtime — perbedaan fundamental yang menentukan keamanan kode.

**Analogi:** Static typing seperti melewati metal detector di bandara sebelum naik pesawat; dynamic typing seperti mengecek barang bawaan hanya saat turbulensi terjadi.

**Poin-Poin Penting:**
- Static typing tangkap error di development (compile-time); dynamic typing baru ketahuan saat aplikasi jalan (runtime)
- Static typing butuh deklarasi tipe; dynamic typing tidak perlu
- Static typing memberikan dokumentasi built-in dan autocompletion yang lebih baik

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid) - static typing:
function greet(name: string): string {
  return `Hello ${name.toUpperCase()}`;
}

// Contoh yang akan ERROR - dynamic typing JS baru error di runtime:
function greetJS(name) {
  return `Hello ${name.toUpperCase()}`; // TS error dulu!
}
greetJS(42); // /* error: Runtime error — name.toUpperCase is not a function */
```

**Kasus Penggunaan Nyata:**
API endpoint handler yang menerima request body — dengan static typing, seluruh struktur data divalidasi saat kompilasi, bukan saat pengguna mengirim request yang salah.
