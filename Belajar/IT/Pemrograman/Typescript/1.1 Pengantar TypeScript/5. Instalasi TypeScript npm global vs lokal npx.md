# 5. Instalasi TypeScript npm global vs lokal npx

**Definisi Singkat:** TypeScript bisa diinstall secara global (`npm i -g typescript`) untuk akses `tsc` di seluruh sistem, atau lokal per proyek dan dijalankan via `npx tsc`.

**Analogi:** Global seperti membawa gunting sendiri kemana-mana (versi bisa beda antar proyek). Lokal seperti gunting yang disediakan masing-masing ruangan — konsisten untuk tim.

**Poin-Poin Penting:**
- Global: `npm i -g typescript` → panggil `tsc` langsung; versi global dipakai semua proyek
- Lokal: `npm i -D typescript` → panggil `npx tsc`; versi sesuai proyek
- Best practice: install lokal per proyek dengan `--save-dev` agar versi konsisten antar developer

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid) - instalasi lokal:
// npm i -D typescript
// npx tsc --init        (buat tsconfig.json)
// npx tsc               (kompilasi)

// Contoh yang akan ERROR:
// Jika typeScript tidak terinstall:
tsc --version // /* error: 'tsc' is not recognized as an internal or external command */
```

**Kasus Penggunaan Nyata:**
Tim dengan 10 developer menggunakan `npx tsc` agar semua anggota tim menggunakan versi TypeScript yang sama sesuai `package.json`, menghindari "works on my machine" karena perbedaan versi.
