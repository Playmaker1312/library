# 6. Konfigurasi tsconfig.json dasar - opsi penting pertama

**Definisi Singkat:** `tsconfig.json` adalah file konfigurasi root untuk TypeScript project, mengatur bagaimana tsc mengkompilasi file dan memeriksa tipe.

**Analogi:** `tsconfig.json` seperti papan kontrol pilot — mengatur semua parameter penerbangan (target, strictness, module system) sebelum takeoff.

**Poin-Poin Penting:**
- Dibuat dengan `tsc --init` — menghasilkan file dengan komentar opsi-opsi
- Opsi kunci: `target` (ES5/ES6/ES2020), `module` (CommonJS/ESNext), `strict: true`, `outDir`, `rootDir`
- `strict: true` mengaktifkan semua type-checking ketat termasuk `strictNullChecks` dan `noImplicitAny`

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid) - tsconfig.json minimal:
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "strict": true,
    "outDir": "./dist",
    "rootDir": "./src"
  },
  "include": ["src"]
}

// Contoh yang akan ERROR - jika rootDir tidak sesuai:
// File ada di src/, tapi tsconfig point ke source/
// /* error: File 'src/index.ts' is not under 'rootDir' 'source' */
```

**Kasus Penggunaan Nyata:** Proyek monorepo dengan struktur `packages/*` — setiap package punya tsconfig sendiri dengan `references` ke package lain, memungkinkan type-checking lintas package.
