# 9. Integrasi TypeScript dengan VS Code extensions settings IntelliSense

**Definisi Singkat:** VS Code memiliki TypeScript support built-in (IntelliSense, autocompletion, error highlighting) yang bisa diperkuat dengan ekstensi dan setting khusus.

**Analogi:** VS Code seperti asisten coding yang sudah tahu aturan TypeScript — ia menyarikan kode (autocomplete) dan menunjukkan error selagi Anda mengetik, tanpa perlu kompilasi manual.

**Poin-Poin Penting:**
- VS Code: IntelliSense, Go to Definition, Refactoring — semua pakai TS server bawaan
- Ekstensi populer: ESLint, Prettier, Path Intellisense, Error Lens
- Setting penting: `"typescript.validate.enable": true`, `"typescript.preferences.importModuleSpecifier": "relative"`

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid) - IntelliSense akan menyarankan:
interface User {
  name: string;
  age: number;
}
const user: User = { name: "Budi", age: 25 }; // autocomplete muncul

// Contoh yang akan ERROR - IntelliSense tandai merah:
const user2: User = { name: "Budi" }; // /* error: Property 'age' is missing in type '{ name: string; }' */
```

**Kasus Penggunaan Nyata:**
Developer menekan Ctrl+Space untuk melihat properti apa saja yang tersedia di objek API response — IntelliSense menampilkan field yang didefinisikan di interface, mempercepat coding 2-3x lipat.
