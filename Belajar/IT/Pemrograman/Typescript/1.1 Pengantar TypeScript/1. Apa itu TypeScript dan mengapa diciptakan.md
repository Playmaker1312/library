# 1. Apa itu TypeScript dan mengapa diciptakan

**Definisi Singkat:** TypeScript adalah superset JavaScript yang diketik secara statis (static typing), dikembangkan oleh Microsoft untuk mengatasi keterbatasan JS dalam aplikasi skala besar.

**Analogi:** TypeScript seperti menambahkan cetak biru/blueprint ke kode JavaScript — seperti arsitek yang menggambar denah sebelum tukang membangun rumah.

**Poin-Poin Penting:**
- TypeScript bukan bahasa baru — ia adalah JavaScript + type system (ES6/ESNext + tipe)
- Diciptakan oleh Anders Hejlsberg (bapak C#) di Microsoft, rilis 2012
- Kode TS dikompilasi ke JS — browser/node hanya menjalankan JS

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid):
const message: string = "Hello TypeScript";
console.log(message);

// Contoh yang akan ERROR (type-error):
const count: number = "hello"; // /* error: Type 'string' is not assignable to type 'number' */
```

**Kasus Penggunaan Nyata:**
Di proyek frontend dengan tim 10+ developer, TypeScript mencegah bug type mismatch di API response, membantu refactoring kode, dan memberikan IntelliSense yang akurat di editor.
