# 7. Menulis dan menjalankan program TypeScript pertama

**Definisi Singkat:** Program TS pertama adalah file `.ts` sederhana yang dikompilasi ke `.js` lalu dijalankan dengan Node.js — atau langsung via `ts-node` / `tsx`.

**Analogi:** Seperti belajar bahasa baru — pertama kita menulis kalimat sederhana ("Hello World"), lalu menerjemahkannya agar bisa dimengerti mesin (JS).

**Poin-Poin Penting:**
- Tulis file `.ts` → kompilasi dengan `tsc` → hasil `.js` di `outDir` → jalankan dengan `node`
- Alternatif cepat: `npx tsx file.ts` atau `npx ts-node file.ts` — kompilasi + jalan sekali
- Untuk development: `tsc --watch` + nodemon atau `tsx watch file.ts`

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid) - hello.ts:
function sayHello(name: string): string {
  return `Halo, ${name}! Selamat belajar TypeScript.`;
}
console.log(sayHello("Andi"));

// Contoh yang akan ERROR:
// Jika lupa kompilasi sebelum run JS:
function sayHello(name: string): string {
  return 123; // /* error: Type 'number' is not assignable to type 'string' */
}
console.log(sayHello("Andi"));
```

**Kasus Penggunaan Nyata:**
Developer membuat utility script CLI dalam TypeScript dan menjalankannya dengan `npx tsx script.ts` tanpa setup build pipeline — ideal untuk tool internal tim.
