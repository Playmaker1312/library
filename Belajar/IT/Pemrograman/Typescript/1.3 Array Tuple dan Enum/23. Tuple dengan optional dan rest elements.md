# 23. Tuple dengan optional dan rest elements

**Definisi Singkat:** Tuple bisa memiliki elemen opsional (`?`) di akhir dan rest element (`...T[]`) untuk menampung jumlah elemen variabel di posisi tertentu.

**Analogi:** Seperti paket internet — kuota utama fix (tuple wajib), kuota bonus bisa ada atau tidak (optional), dan kuota malam unlimited (rest) untuk sisanya.

**Poin-Poin Penting:**
- Optional: `[string, number?]` — elemen kedua boleh ada boleh tidak
- Rest: `[string, ...number[]]` — string pertama, sisanya number berapapun
- Optional hanya diperbolehkan di akhir tuple; rest bisa di tengah/akhir

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid):
let tuple1: [string, number?] = ["Andi"];
let tuple2: [string, number?] = ["Andi", 25];
let tuple3: [string, ...number[]] = ["nilai", 90, 85, 92];

// Contoh yang akan ERROR (type-error):
tuple1 = ["Andi", "hello"]; // /* error: Type 'string' is not assignable to type 'number | undefined' */
```

**Kasus Penggunaan Nyata:**
Fungsi logging dengan format — `[string, ...unknown[]]` di parameter rest, memungkinkan format string diikuti data tambahan yang jumlahnya variabel.
