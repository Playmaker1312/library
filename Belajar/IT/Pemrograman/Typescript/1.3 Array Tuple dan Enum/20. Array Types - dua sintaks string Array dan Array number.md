# 20. Array Types - dua sintaks string Array dan Array number

**Definisi Singkat:** Array di TypeScript bisa ditulis dengan dua sintaks: `T[]` (bracket syntax) atau `Array<T>` (generic syntax); keduanya identik secara fungsional.

**Analogi:** Seperti dua cara memesan kopi — "Kopi Hitam" (`T[]`) atau "Black Coffee" (`Array<T>`). Rasanya sama, hanya beda penyebutan dan konteks.

**Poin-Poin Penting:**
- `T[]`: `string[]`, `number[]`, `boolean[]` — sintaks pendek, paling umum
- `Array<T>`: `Array<string>`, `Array<number>` — sintaks generik, cocok untuk tipe kompleks
- Array di TS masih bisa push/pop, tapi isinya harus sesuai tipe elemen

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid):
let fruits: string[] = ["apel", "mangga"];
let numbers: Array<number> = [1, 2, 3];
fruits.push("jeruk"); // OK

// Contoh yang akan ERROR (type-error):
fruits.push(123); // /* error: Argument of type 'number' is not assignable to parameter of type 'string' */
```

**Kasus Penggunaan Nyata:**
Daftar produk dari API — `Product[]` memastikan setiap elemen array memiliki struktur Product yang valid, sehingga mapping ke komponen React aman tanpa null check berlebihan.
