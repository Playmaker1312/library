# 22. Tuple Types - array dengan panjang dan tipe tetap

**Definisi Singkat:** Tuple adalah array dengan jumlah elemen tetap dan tiap posisi memiliki tipe spesifik — seperti `[string, number]` untuk pasangan nama-umur.

**Analogi:** Seperti formulir pendaftaran — kolom 1 harus Nama (string), kolom 2 harus Umur (number), kolom 3 harus Aktif (boolean). Urutan dan tipe tidak boleh tertukar.

**Poin-Poin Penting:**
- Sintaks: `[string, number]`, `[boolean, string, number]` — tipe per posisi
- Berbeda dengan array biasa (`string[]`) — panjang dan tiap posisi tidak diketahui
- Tuple bisa di-destructure dengan aman karena panjangnya fix

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid):
let person: [string, number] = ["Andi", 25];
const [nama, umur] = person; // destructure aman

// Contoh yang akan ERROR (type-error):
person = [25, "Andi"]; // /* error: Type 'number' is not assignable to type 'string' */
person = ["Andi"];     // /* error: Source has 1 element(s) but target requires 2 */
```

**Kasus Penggunaan Nyata:**
CSV parser — setiap baris CSV diparse ke tuple `[string, number, Date]` dengan tipe yang pasti, memudahkan validasi data sebelum dimasukkan ke database.
