# 27. Enum alternatives - kapan tidak menggunakan enum

**Definisi Singkat:** Kadang enum bukan pilihan terbaik — alternatif seperti union of literal types, `as const` objects, atau `Map` bisa lebih fleksibel dan tree-shakeable.

**Analogi:** Enum seperti set LEGO spesifik (tema kastil) — bagus untuk use case tertentu. Tapi kadang Anda butuh LEGO dasar (union type, object const) yang lebih modular dan bisa dikombinasikan bebas.

**Poin-Poin Penting:**
- Union literal: `type Status = "active" | "inactive"` — lebih ringan, tidak ada runtime overhead
- `as const` object: `const Status = { Active: "active", Inactive: "inactive" } as const` — fleksibel seperti enum
- Enum punya runtime overhead (objek JS); union types zero-cost
- Enum tidak tree-shakeable di beberapa bundler karena side effects

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid) - alternatif union:
type Status = "active" | "inactive";
let s: Status = "active";

// Alternatif as const:
const Color = { Red: "red", Blue: "blue" } as const;
type Color = (typeof Color)[keyof typeof Color];

// Contoh yang akan ERROR - union lebih ketat:
s = "banned"; // /* error: Type '"banned"' is not assignable to type 'Status' */
```

**Kasus Penggunaan Nyata:**
Library yang di-tree-shake — menggunakan union of literal types daripada enum memastikan pengguna library bisa tree-shake kode yang tidak dipakai, mengurangi bundle size final.
