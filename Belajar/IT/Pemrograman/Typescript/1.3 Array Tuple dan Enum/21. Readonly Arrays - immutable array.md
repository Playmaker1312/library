# 21. Readonly Arrays - immutable array

**Definisi Singkat:** `readonly T[]` atau `ReadonlyArray<T>` adalah array yang isinya tidak bisa dimutasi — tidak ada `push`, `pop`, `splice`, atau assignment index.

**Analogi:** Seperti buku perpustakaan yang di-scan — Anda bisa membaca semua halaman (`map`, `filter`, `forEach`) tapi tidak boleh mencoret, merobek, atau menambah halaman baru.

**Poin-Poin Penting:**
- Sintaks: `readonly number[]` atau `ReadonlyArray<number>` — mirip array biasa tapi immutable
- Method mutasi (`push`, `pop`, `splice`) tidak tersedia
- Method non-mutasi (`map`, `filter`, `concat`) tetap bisa — return array baru (bisa mutable)

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid):
const arr: readonly number[] = [1, 2, 3];
const doubled = arr.map(x => x * 2); // OK — return number[] baru
console.log(doubled);

// Contoh yang akan ERROR (type-error):
arr.push(4); // /* error: Property 'push' does not exist on type 'readonly number[]' */
```

**Kasus Penggunaan Nyata:**
State management (Redux/Zustand) — reducer harus immutable. `readonly` array di parameter memastikan developer tidak sengaja memutasi state lama.
