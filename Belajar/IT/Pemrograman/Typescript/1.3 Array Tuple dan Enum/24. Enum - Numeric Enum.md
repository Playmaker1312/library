# 24. Enum - Numeric Enum

**Definisi Singkat:** Numeric enum adalah enum dengan nilai number otomatis (mulai 0, increment 1) atau yang ditentukan manual sebagai konstanta terurut.

**Analogi:** Seperti nomor antrean di bank — Anda dapat nomor 0, 1, 2 (otomatis) atau minta nomor spesifik 100, 101 (manual). Setiap nomor mewakili satu layanan.

**Poin-Poin Penting:**
- Default: `enum A { X, Y, Z }` → X=0, Y=1, Z=2
- Bisa set manual: `enum A { X = 10, Y = 20, Z = 30 }`
- Bisa reverse mapping — `A[0]` menghasilkan `"X"` (hanya numeric enum)

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid):
enum Status {
  Pending,    // 0
  Approved,   // 1
  Rejected    // 2
}
let s: Status = Status.Approved;
console.log(Status[1]); // "Approved" — reverse mapping

// Contoh yang akan ERROR (type-error):
s = 5; // /* error: Type '5' is not assignable to type 'Status' (tapi 0,1,2 ok di enum numeric tanpa strict) */
```

**Kasus Penggunaan Nyata:**
Status pesanan di e-commerce — `OrderStatus.Pending | OrderStatus.Paid | OrderStatus.Shipped | OrderStatus.Delivered` — kode lebih readable daripada angka 0/1/2/3.
