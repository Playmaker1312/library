# 25. Enum - String Enum

**Definisi Singkat:** String enum adalah enum yang setiap anggotanya diinisialisasi dengan string literal, memberikan nilai yang lebih bermakna saat di-debug atau di-log.

**Analogi:** Seperti lencana nama di event — bukan nomor peserta (numerik) tapi nama lengkap (string) yang langsung terbaca. "Panitia-A" lebih jelas daripada "1".

**Poin-Poin Penting:**
- Setiap anggota harus diinisialisasi dengan string: `enum A { X = "x-value", Y = "y-value" }`
- Tidak ada reverse mapping (beda dengan numeric enum)
- String enum lebih "safe" karena nilainya eksplisit dan tidak bisa ditukar dengan number sembarang

**Contoh Kode:**
```typescript
// Contoh yang BENAR (valid):
enum Color {
  Red = "MERAH",
  Green = "HIJAU",
  Blue = "BIRU"
}
let c: Color = Color.Red;
console.log(c); // "MERAH"

// Contoh yang akan ERROR (type-error):
c = "MERAH"; // /* error: Type '"MERAH"' is not assignable to type 'Color' */
```

**Kasus Penggunaan Nyata:**
Logging action di Redux — `ActionType.AddTodo = "ADD_TODO"` lebih informatif saat di-debug dengan Redux DevTools dibanding angka 0.
