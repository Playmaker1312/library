# 175. Typing Refs dengan useRef generic

**Definisi Singkat:** Menggunakan generic type pada `useRef` untuk menentukan tipe dari DOM element atau nilai mutable yang akan direferensikan, memastikan akses yang type-safe ke ref tersebut.

**Analogi:** Seperti remote control yang hanya bekerja dengan TV tertentu - generic type menentukan "perangkat" apa yang ref ini bisa kontrol (HTMLInputElement, HTMLDivElement, dll).

**Poin-Poin Penting:**
- `useRef<HTMLInputElement>(null)` untuk DOM element
- Akses melalui `ref.current` yang bisa `null`
- Untuk mutable values (bukan DOM): `useRef<number>(0)`
- `!` non-null assertion bisa digunakan jika yakin current tidak null
- `ref.current` bersifat mutable tanpa trigger re-render

**Contoh Kode:**
```typescript
// BENAR: Ref untuk DOM input element
function FocusInput() {
  const inputRef = useRef<HTMLInputElement>(null);

  const focusInput = () => {
    inputRef.current?.focus();  // Optional chaining aman
  };

  return (
    <div>
      <input ref={inputRef} type="text" />
      <button onClick={focusInput}>Focus Input</button>
    </div>
  );
}

// BENAR: Ref sebagai mutable value (bukan DOM)
function Timer() {
  const intervalRef = useRef<number | null>(null);
  const [count, setCount] = useState(0);

  useEffect(() => {
    intervalRef.current = window.setInterval(() => {
      setCount(c => c + 1);
    }, 1000);

    return () => {
      if (intervalRef.current) {
        clearInterval(intervalRef.current);
      }
    };
  }, []);

  return <div>Count: {count}</div>;
}

// ERROR: Ref tanpa generic mengakses properti spesifik
const inputRef = useRef(null);  // Tipe: React.MutableRefObject<null>
inputRef.current?.value;  // Error: current bertipe null, tidak ada .value

// ERROR: Menggunakan tipe DOM yang salah
const divRef = useRef<HTMLDivElement>(null);
<input ref={divRef} />  // Error: HTMLDivElement tidak compatible dengan input
```

**Kasus Penggunaan Nyata:**
- Akses method DOM element seperti `focus()`, `scrollIntoView()` dengan aman
- Menyimpan nilai yang perlu bertahan antar render tanpa trigger re-render
- Menyimpan ID interval/timeout untuk cleanup di useEffect
- Membuat referensi ke komponen child dengan forwardRef
