# 170. Setup project React dan TypeScript - Vite CRA Next.js

**Definisi Singkat:** Cara menginisialisasi project React dengan TypeScript menggunakan berbagai tool seperti Vite, Create React App (CRA), dan Next.js untuk mendapatkan type safety sejak awal.

**Analogi:** Seperti membangun rumah dengan blueprint yang jelas (TypeScript) menggunakan alat bangunan yang berbeda (Vite/CRA/Next.js) - masing-masing memiliki cara setup sendiri tapi tujuan akhirnya sama.

**Poin-Poin Penting:**
- Vite: `npm create vite@latest my-app -- --template react-ts`
- CRA: `npx create-react-app my-app --template typescript`
- Next.js: `npx create-next-app@latest --typescript`
- Semua otomatis membuat `tsconfig.json` dan file `.tsx`
- File React dengan TypeScript menggunakan ekstensi `.tsx` (bukan `.jsx`)

**Contoh Kode:**
```typescript
// BENAR: Struktur project Vite React TypeScript
// my-app/
// ├── src/
// │   ├── App.tsx          // Komponen utama .tsx
// │   ├── main.tsx         // Entry point .tsx
// │   └── vite-env.d.ts    // Type definitions untuk Vite
// ├── tsconfig.json        // Konfigurasi TypeScript
// ├── tsconfig.node.json
// └── package.json

// BENAR: Inisialisasi project
// npm create vite@latest todo-app -- --template react-ts
// cd todo-app
// npm install
// npm run dev

// ERROR: Mencoba menggunakan file .jsx di project TypeScript
// src/App.jsx  // Error: Gunakan .tsx untuk konsistensi dan type safety
```

**Kasus Penggunaan Nyata:**
- Memulai project baru dengan type safety sejak awal menghindari banyak bug runtime
- Autocomplete dan IntelliSense yang lebih baik di IDE selama development
- Refactoring yang lebih aman tanpa takut merusak fitur lain
- Team collaboration lebih mudah karena tipe menjadi dokumentasi hidup
