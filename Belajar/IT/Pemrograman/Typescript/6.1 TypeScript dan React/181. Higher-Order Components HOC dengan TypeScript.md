# 181. Higher-Order Components HOC dengan TypeScript

**Definisi Singkat:** Higher-Order Component (HOC) adalah fungsi yang menerima komponen dan mengembalikan komponen baru dengan props tambahan. Dengan TypeScript, kita dapat men-tipe transformasi props yang terjadi.

**Analogi:** Seperti dekorasi kue - HOC adalah tukang dekorasi yang mengambil kue (komponen) polos, menambahkan hiasan (props tambahan), dan mengembalikan kue yang lebih menarik.

**Poin-Poin Penting:**
- HOC: `function withFeature<P>(Component: ComponentType<P>): ComponentType<...>`
- Gunakan `React.ComponentType<P>` untuk tipe komponen yang diterima
- Injected props: props yang ditambahkan HOC ke wrapped component
- Gunakan `Omit` untuk menghapus injected props dari props luar
- `React.forwardRef` sering dibutuhkan untuk meneruskan ref

**Contoh Kode:**
```typescript
// BENAR: HOC sederhana dengan injected props
interface WithLoadingProps {
  isLoading: boolean;
}

// HOC menerima komponen yang butuh isLoading, 
// mengembalikan komponen yang TIDAK butuh isLoading (diambil dari context)
function withLoading<P extends WithLoadingProps>(
  WrappedComponent: React.ComponentType<P>
) {
  return function WithLoadingComponent(props: Omit<P, keyof WithLoadingProps>) {
    const { isLoading } = useLoadingContext();
    
    // Cast karena TypeScript tidak tahu Omit<P, ...> + isLoading = P
    return <WrappedComponent {...(props as P)} isLoading={isLoading} />;
  };
}

// Komponen yang butuh isLoading
interface DataTableProps extends WithLoadingProps {
  data: string[];
  title: string;
}

function DataTable({ data, title, isLoading }: DataTableProps) {
  if (isLoading) return <div>Loading...</div>;
  return (
    <div>
      <h3>{title}</h3>
      <ul>{data.map(item => <li key={item}>{item}</li>)}</ul>
    </div>
  );
}

// Membuat komponen baru dengan HOC
const DataTableWithLoading = withLoading(DataTable);

// Penggunaan - isLoading tidak perlu lagi!
<DataTableWithLoading 
  data={['a', 'b', 'c']} 
  title="Daftar Item" 
/>

// BENAR: HOC dengan generic dan forwardRef
function withLogger<P extends object>(
  WrappedComponent: React.ComponentType<P>
) {
  const displayName = WrappedComponent.displayName || WrappedComponent.name || 'Component';

  const WithLogger = React.forwardRef<
    React.ElementRef<React.ComponentType<P>>,
    P
  >((props, ref) => {
    useEffect(() => {
      console.log(`${displayName} mounted`);
      return () => console.log(`${displayName} unmounted`);
    }, []);

    return <WrappedComponent ref={ref} {...props} />;
  });

  WithLogger.displayName = `withLogger(${displayName})`;
  return WithLogger;
}

// ERROR: HOC yang tidak menangani tipe dengan benar
function badWithSomething<P>(Component: React.ComponentType<P>) {
  return function(props: any) {  // ❌ Gunakan any, hilang type safety
    return <Component {...props} extra="foo" />;
  };
}
```

**Kasus Penggunaan Nyata:**
- Menambahkan logic umum (logging, error handling, loading) ke banyak komponen
- Mengambil data dari context dan meneruskannya sebagai props ke komponen
- Menerapkan autentikasi/otorisasi pada komponen yang membutuhkan
- Reuse logic lintas komponen tanpa duplikasi kode
