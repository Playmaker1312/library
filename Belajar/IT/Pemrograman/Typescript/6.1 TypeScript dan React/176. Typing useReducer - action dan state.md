# 176. Typing useReducer - action dan state

**Definisi Singkat:** Mendefinisikan tipe untuk state dan action pada `useReducer` agar dispatch hanya menerima action yang valid, dan reducer mengembalikan state dengan tipe yang konsisten.

**Analogi:** Seperti mesin pesanan - state adalah status pesanan saat ini, action adalah perintah (seperti "tambah item", "hapus item") yang harus sesuai format agar mesin bisa memprosesnya.

**Poin-Poin Penting:**
- Definisikan `State` interface untuk shape state
- Definisikan union type untuk semua `Action` yang mungkin
- Setiap action biasanya punya `type` dan opsional `payload`
- `useReducer<Reducer<State, Action>>` atau biarkan inference
- `dispatch` hanya menerima action yang sesuai union type

**Contoh Kode:**
```typescript
// BENAR: State dan Action types yang jelas
interface TodoState {
  todos: { id: number; text: string; done: boolean }[];
  filter: 'all' | 'active' | 'completed';
}

type TodoAction =
  | { type: 'ADD_TODO'; payload: string }
  | { type: 'TOGGLE_TODO'; payload: number }
  | { type: 'DELETE_TODO'; payload: number }
  | { type: 'SET_FILTER'; payload: TodoState['filter'] };

function todoReducer(state: TodoState, action: TodoAction): TodoState {
  switch (action.type) {
    case 'ADD_TODO':
      return {
        ...state,
        todos: [...state.todos, { 
          id: Date.now(), 
          text: action.payload,  // Tipe: string
          done: false 
        }]
      };
    case 'TOGGLE_TODO':
      return {
        ...state,
        todos: state.todos.map(todo =>
          todo.id === action.payload  // Tipe: number
            ? { ...todo, done: !todo.done }
            : todo
        )
      };
    // ...cases lainnya
    default:
      return state;
  }
}

// Penggunaan
const initialState: TodoState = { todos: [], filter: 'all' };
const [state, dispatch] = useReducer(todoReducer, initialState);

dispatch({ type: 'ADD_TODO', payload: 'Belajar TypeScript' });  // OK
dispatch({ type: 'SET_FILTER', payload: 'active' });              // OK

// ERROR: Action type atau payload yang salah
dispatch({ type: 'ADD_TODO', payload: 123 });  // Error: payload harus string
dispatch({ type: 'INVALID_TYPE' });              // Error: type tidak dikenal
```

**Kasus Penggunaan Nyata:**
- Mengelola state kompleks dengan banyak transisi yang berbeda
- Memastikan setiap action memiliki format yang benar sebelum sampai ke reducer
- Autocomplete untuk action.type dan payload yang sesuai
- Refactoring action tidak akan merusak bagian lain tanpa error
