# 174. Typing Events - onClick onChange onSubmit

**Definisi Singkat:** Mendefinisikan tipe yang benar untuk event handler di React seperti `onClick`, `onChange`, dan `onSubmit`, termasuk tipe event object yang diterima callback.

**Analogi:** Seperti resepsionis yang hanya menerima tamu dengan jenis undangan tertentu - setiap event handler hanya boleh menerima event dengan tipe yang sesuai (click event untuk button, change event untuk input, dll).

**Poin-Poin Penting:**
- `React.MouseEvent<HTMLButtonElement>` untuk click events
- `React.ChangeEvent<HTMLInputElement>` untuk input change
- `React.FormEvent<HTMLFormElement>` untuk form submit
- `event.target` dan `event.currentTarget` memiliki tipe spesifik
- Event handler bisa inline atau fungsi terpisah

**Contoh Kode:**
```typescript
// BENAR: onClick dengan MouseEvent
function Button() {
  const handleClick = (e: React.MouseEvent<HTMLButtonElement>) => {
    console.log(e.currentTarget.textContent);
    e.preventDefault();
  };

  return <button onClick={handleClick}>Click Me</button>;
}

// BENAR: onChange dengan ChangeEvent untuk input
function InputField() {
  const [value, setValue] = useState("");

  const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    setValue(e.target.value);  // e.target.value bertipe string
  };

  return <input type="text" value={value} onChange={handleChange} />;
}

// BENAR: onSubmit dengan FormEvent
function LoginForm() {
  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();  // Mencegah reload halaman
    const formData = new FormData(e.currentTarget);
    // Proses form...
  };

  return (
    <form onSubmit={handleSubmit}>
      <input name="email" type="email" />
      <button type="submit">Login</button>
    </form>
  );
}

// ERROR: Menggunakan tipe event yang salah
const handleInput = (e: React.MouseEvent) => {
  console.log(e.target.value);  // Error: MouseEvent tidak punya .value
};
<input onChange={handleInput} />
```

**Kasus Penggunaan Nyata:**
- Mengakses properti event dengan type-safe tanpa perlu `as any`
- Mengetahui method dan properti apa yang tersedia pada event object
- Mencegah bug karena salah mengakses properti event
- Dokumentasi eksplisit tentang event apa yang handler harapkan
