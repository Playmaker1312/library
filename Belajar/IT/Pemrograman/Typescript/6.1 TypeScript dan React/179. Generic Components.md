# 179. Generic Components

**Definisi Singkat:** Komponen React yang dapat bekerja dengan berbagai tipe data menggunakan generic type parameters, membuat komponen lebih fleksibel namun tetap type-safe.

**Analogi:** Seperti wadah penyimpanan serbaguna - Anda bisa mengisi dengan pakaian, buku, atau peralatan makan, tapi setelah menentukan isinya, hanya barang dengan tipe itu yang boleh masuk.

**Poin-Poin Penting:**
- `function Component<T>(props: Props<T>)` - T adalah generic parameter
- Generic bisa memiliki constraint: `T extends HasId`
- Props bisa menggunakan tipe generic `T`
- Bisa menentukan default type untuk generic
- Penggunaan: `<Component<ItemType> />`

**Contoh Kode:**
```typescript
// BENAR: Generic List component
interface ListProps<T> {
  items: T[];
  renderItem: (item: T, index: number) => React.ReactNode;
  keyExtractor: (item: T) => string | number;
}

function List<T>({ items, renderItem, keyExtractor }: ListProps<T>) {
  return (
    <ul>
      {items.map((item, index) => (
        <li key={keyExtractor(item)}>
          {renderItem(item, index)}
        </li>
      ))}
    </ul>
  );
}

// Penggunaan dengan tipe berbeda
interface User {
  id: number;
  name: string;
  email: string;
}

const users: User[] = [
  { id: 1, name: 'Alice', email: 'alice@example.com' },
  { id: 2, name: 'Bob', email: 'bob@example.com' }
];

// Tipe T terinferensi sebagai User
<List
  items={users}
  keyExtractor={user => user.id}
  renderItem={user => (
    <div>
      <strong>{user.name}</strong> - {user.email}
    </div>
  )}
/>

// BENAR: Generic dengan constraint
interface HasId {
  id: number | string;
}

interface SelectProps<T extends HasId> {
  options: T[];
  value: T['id'] | null;
  onChange: (value: T['id']) => void;
  getLabel: (item: T) => string;
}

function Select<T extends HasId>({ options, value, onChange, getLabel }: SelectProps<T>) {
  return (
    <select value={value ?? ''} onChange={(e) => onChange(e.target.value as T['id'])}>
      {options.map(option => (
        <option key={option.id} value={option.id}>
          {getLabel(option)}
        </option>
      ))}
    </select>
  );
}

// ERROR: Item tanpa id untuk Select yang membutuhkan HasId
const items = [{ name: 'Apple' }, { name: 'Banana' }];  // Tidak ada 'id'
<Select options={items} ... />  // Error: tidak sesuai constraint HasId
```

**Kasus Penggunaan Nyata:**
- Membuat komponen reusable seperti `List`, `Table`, `Select` yang bekerja dengan tipe data apapun
- Menghindari `any` dan tetap menjaga type safety
- Satu komponen dapat digunakan untuk User, Product, Post, dll tanpa duplikasi
- Type inference otomatis menentukan tipe berdasarkan props yang diberikan
