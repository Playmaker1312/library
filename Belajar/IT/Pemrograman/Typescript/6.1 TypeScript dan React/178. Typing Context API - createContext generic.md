# 178. Typing Context API - createContext generic

**Definisi Singkat:** Menggunakan generic pada `createContext` untuk mendefinisikan tipe dari value yang disediakan Context, memastikan Consumer mengakses nilai dengan tipe yang benar.

**Analogi:** Seperti kotak surat dengan label - Context adalah kotak yang hanya boleh berisi surat dengan format tertentu (tipe), dan setiap orang yang mengambilnya (Consumer) tahu apa yang akan mereka dapatkan.

**Poin-Poin Penting:**
- `createContext<ContextType>(defaultValue)` - generic menentukan tipe value
- Default value harus sesuai tipe atau gunakan type assertion
- Provider harus menyediakan value dengan tipe yang cocok
- `useContext(Context)` mengembalikan nilai dengan tipe yang benar
- Biasanya buat custom hook untuk mengakses context

**Contoh Kode:**
```typescript
// BENAR: Context dengan tipe yang jelas
interface Theme {
  mode: 'light' | 'dark';
  primaryColor: string;
}

interface ThemeContextType {
  theme: Theme;
  toggleTheme: () => void;
  setPrimaryColor: (color: string) => void;
}

// Default value (opsional tapi berguna untuk testing)
const defaultThemeContext: ThemeContextType = {
  theme: { mode: 'light', primaryColor: '#3b82f6' },
  toggleTheme: () => {},
  setPrimaryColor: () => {}
};

const ThemeContext = createContext<ThemeContextType>(defaultThemeContext);

// Custom hook untuk akses context (recommended)
function useTheme() {
  const context = useContext(ThemeContext);
  if (!context) {
    throw new Error('useTheme must be used within ThemeProvider');
  }
  return context;
}

// Provider component
function ThemeProvider({ children }: { children: React.ReactNode }) {
  const [theme, setTheme] = useState<Theme>({ 
    mode: 'light', 
    primaryColor: '#3b82f6' 
  });

  const toggleTheme = () => {
    setTheme(prev => ({
      ...prev,
      mode: prev.mode === 'light' ? 'dark' : 'light'
    }));
  };

  const setPrimaryColor = (color: string) => {
    setTheme(prev => ({ ...prev, primaryColor: color }));
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme, setPrimaryColor }}>
      {children}
    </ThemeContext.Provider>
  );
}

// Penggunaan di komponen
function ThemedButton() {
  const { theme, toggleTheme } = useTheme();
  return (
    <button 
      onClick={toggleTheme}
      style={{ background: theme.primaryColor }}
    >
      Toggle {theme.mode}
    </button>
  );
}

// ERROR: Value yang disediakan tidak sesuai tipe
<ThemeContext.Provider value={{ mode: 'light' }}>
  {/* Error: toggleTheme dan setPrimaryColor hilang */}
</ThemeContext.Provider>
```

**Kasus Penggunaan Nyata:**
- Berbagi state global (theme, auth, bahasa) antar komponen tanpa prop drilling
- Memastikan semua komponen yang mengakses context mendapatkan tipe yang sama
- Custom hook `useTheme()` memberikan error yang jelas jika digunakan di luar Provider
- Refactoring context value akan memunculkan error di semua tempat penggunaan
