# 182. Render Props Pattern dan TypeScript

**Definisi Singkat:** Render Props adalah pattern di mana komponen menerima prop yang berupa fungsi yang merender element, memungkinkan berbagi logic antar komponen dengan kontrol penuh pada rendering.

**Analogi:** Seperti rental peralatan - Anda meminjam alat (logic stateful) dan menentukan sendiri bagaimana menggunakannya (rendering) sesuai kebutuhan Anda.

**Poin-Poin Penting:**
- Prop yang nilainya adalah fungsi: `(data: T) => React.ReactNode`
- Komponen menyediakan logic/state, consumer menentukan UI
- Lebih fleksibel daripada HOC untuk beberapa use case
- `children` sebagai function adalah variasi umum ("children as function")
- Type inference bekerja baik untuk parameter fungsi render

**Contoh Kode:**
```typescript
// BENAR: Render props sederhana untuk counter logic
interface CounterRenderProps {
  count: number;
  increment: () => void;
  decrement: () => void;
  reset: () => void;
}

interface CounterProps {
  initialCount?: number;
  children: (props: CounterRenderProps) => React.ReactNode;
}

function Counter({ initialCount = 0, children }: CounterProps) {
  const [count, setCount] = useState(initialCount);
  
  const increment = () => setCount(c => c + 1);
  const decrement = () => setCount(c => c - 1);
  const reset = () => setCount(initialCount);

  return <>{children({ count, increment, decrement, reset })}</>;
}

// Penggunaan - consumer menentukan UI sepenuhnya!
<Counter initialCount={5}>
  {({ count, increment, decrement, reset }) => (
    <div className="counter">
      <span>Count: {count}</span>
      <button onClick={decrement}>-</button>
      <button onClick={increment}>+</button>
      <button onClick={reset}>Reset</button>
    </div>
  )}
</Counter>

// Penggunaan lain dengan UI berbeda
<Counter>
  {({ count, increment }) => (
    <div>
      <progress value={count} max={10} />
      <button onClick={increment}>Add Progress</button>
    </div>
  )}
</Counter>

// BENAR: Mouse position tracker dengan render props
interface MousePosition {
  x: number;
  y: number;
}

interface MouseTrackerProps {
  render: (position: MousePosition) => React.ReactNode;
}

function MouseTracker({ render }: MouseTrackerProps) {
  const [position, setPosition] = useState<MousePosition>({ x: 0, y: 0 });

  useEffect(() => {
    const handleMouseMove = (e: MouseEvent) => {
      setPosition({ x: e.clientX, y: e.clientY });
    };

    window.addEventListener('mousemove', handleMouseMove);
    return () => window.removeEventListener('mousemove', handleMouseMove);
  }, []);

  return <>{render(position)}</>;
}

// Penggunaan
<MouseTracker 
  render={({ x, y }) => (
    <div>Mouse position: {x}, {y}</div>
  )} 
/>

// ERROR: Memanggil render props dengan tipe salah
return <>{children({ count: "5", increment: 123 })}</>;
// Error: count harus number, increment harus () => void
```

**Kasus Penggunaan Nyata:**
- Berbagi logic stateful (counter, form handling, mouse tracking)
- Memberikan kontrol penuh pada consumer tentang bagaimana merender UI
- Alternatif untuk custom hooks di class components (sebelum hooks ada)
- Membuat komponen "headless" yang hanya menyediakan logic tanpa UI
