# 173. Typing State dengan useState generic

**Definisi Singkat:** Menggunakan generic type parameter pada hook `useState` untuk mendefinisikan tipe dari state yang akan dikelola, memastikan hanya nilai dengan tipe yang benar yang dapat disimpan.

**Analogi:** Seperti kotak penyimpanan dengan label - Anda menentukan tipe barang apa yang boleh masuk ke kotak tersebut, jadi tidak mungkin memasukkan pakaian ke kotak yang ditandai "peralatan makan".

**Poin-Poin Penting:**
- `useState<T>()` - T adalah generic untuk tipe state
- Type inference bekerja jika initial value diberikan
- Gunakan generic ketika initial value adalah `null` atau `undefined`
- State bisa berupa union type: `string | null`
- Untuk objek/array, definisikan interface terlebih dahulu

**Contoh Kode:**
```typescript
// BENAR: Type inference otomatis (initial value ada)
const [count, setCount] = useState(0);  // Tipe: number
setCount(5);      // OK
setCount("abc");  // Error!

// BENAR: Generic untuk state yang bisa null
interface User {
  id: number;
  name: string;
}

const [user, setUser] = useState<User | null>(null);
setUser({ id: 1, name: "Alice" });  // OK
setUser(null);                        // OK
setUser({ id: "1" });                 // Error: id harus number

// BENAR: State dengan array objek
interface Todo {
  id: number;
  text: string;
  done: boolean;
}

const [todos, setTodos] = useState<Todo[]>([]);

setTodos([
  { id: 1, text: "Belajar TS", done: false },
  { id: 2, text: "Buat project", done: true }
]);

// ERROR: Menambahkan item dengan tipe salah ke array
setTodos(prev => [...prev, { id: 3, text: "Test" }]);
// Error: Properti 'done' hilang
```

**Kasus Penggunaan Nyata:**
- Memastikan state selalu memiliki struktur data yang konsisten
- Mencegah bug karena state yang berisi tipe data tidak terduga
- Autocomplete saat mengakses properti objek dalam state
- Mudah melacak perubahan struktur data state selama refactoring
