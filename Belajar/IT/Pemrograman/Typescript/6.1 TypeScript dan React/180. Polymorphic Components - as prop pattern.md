# 180. Polymorphic Components - as prop pattern

**Definisi Singkat:** Polymorphic components adalah komponen yang dapat merender sebagai element HTML berbeda atau komponen lain melalui prop `as`, namun tetap mempertahankan type safety untuk props yang sesuai.

**Analogi:** Seperti baju serbaguna yang bisa dipakai sebagai jaket, rompi, atau kemeja - bentuknya berubah tapi tetap nyaman dan sesuai fungsinya.

**Poin-Poin Penting:**
- Prop `as` menentukan element/komponen apa yang akan dirender
- Props harus menyesuaikan dengan element yang dipilih (`as="a"` mendapat props anchor)
- Gunakan `React.ElementType` untuk tipe prop `as`
- `React.ComponentPropsWithoutRef<T>` untuk mendapatkan props dari element T
- Gunakan `Omit` untuk mengecualikan props yang didefinisikan ulang

**Contoh Kode:**
```typescript
// BENAR: Polymorphic Button sederhana
type ButtonOwnProps<E extends React.ElementType = React.ElementType> = {
  children: React.ReactNode;
  variant?: 'primary' | 'secondary';
  as?: E;
};

type ButtonProps<E extends React.ElementType> = 
  ButtonOwnProps<E> & Omit<React.ComponentPropsWithoutRef<E>, keyof ButtonOwnProps>;

function Button<E extends React.ElementType = 'button'>({
  as: Component = 'button',
  children,
  variant = 'primary',
  ...props
}: ButtonProps<E>) {
  return (
    <Component 
      className={`btn btn-${variant}`}
      {...props}
    >
      {children}
    </Component>
  );
}

// Penggunaan - semuanya type-safe!
<Button onClick={() => console.log('click')}>
  Click me (button)
</Button>

<Button as="a" href="/about" variant="secondary">
  About (anchor tag)
</Button>

<Button as={Link} to="/home">  {/* React Router Link */}
  Home (React Router Link)
</Button>

// ERROR: Props tidak sesuai dengan element yang dipilih
<Button as="a" type="submit">  {/* Error: type bukan prop untuk <a> */}
  Submit
</Button>

<Button href="/about">  {/* Error: href bukan prop default untuk button */}
  About
</Button>

// BENAR: Dengan forwardRef untuk ref support
type PolymorphicRef<C extends React.ElementType> = 
  React.ComponentPropsWithRef<C>["ref"];

type ButtonPropsWithRef<E extends React.ElementType = "button"> = 
  ButtonProps<E> & { ref?: PolymorphicRef<E> };

const ButtonWithRef = React.forwardRef(function ButtonWithRef<
  E extends React.ElementType = "button"
>({ as: Component = "button", ...props }: ButtonPropsWithRef<E>, 
  ref?: PolymorphicRef<E>) {
  return <Component ref={ref} {...props} />;
}) as <E extends React.ElementType = "button">(
  props: ButtonPropsWithRef<E>
) => React.ReactElement;
```

**Kasus Penggunaan Nyata:**
- Membuat komponen desain sistem (Button, Text, Box) yang fleksibel
- Button yang bisa berupa `<button>`, `<a>`, atau React Router `<Link>`
- Text yang bisa berupa `<p>`, `<span>`, `<h1>`-`<h6>` sesuai kebutuhan
- Menghindari duplikasi kode untuk komponen yang serupa tapi beda element
