# 172. Typing Props dan Children

**Definisi Singkat:** Cara mendefinisikan tipe untuk props yang diterima komponen dan `children` yang dapat dirender di dalamnya, memastikan penggunaan komponen yang benar.

**Analogi:** Seperti kontainer paket - props adalah label dan isi paket yang harus sesuai spesifikasi, sedangkan children adalah barang tambahan yang boleh dimasukkan ke dalam paket.

**Poin-Poin Penting:**
- Gunakan `interface` atau `type` untuk mendefinisikan shape props
- `React.ReactNode` untuk children yang bisa berupa apapun yang dirender React
- `React.ReactElement` untuk children yang harus berupa element React spesifik
- Optional props gunakan `?`
- Default values gunakan `= defaultValue` di destructuring

**Contoh Kode:**
```typescript
// BENAR: Props sederhana dengan interface
interface ButtonProps {
  label: string;
  onClick: () => void;
  disabled?: boolean;
  variant?: 'primary' | 'secondary' | 'danger';
}

function Button({ label, onClick, disabled = false, variant = 'primary' }: ButtonProps) {
  return (
    <button 
      onClick={onClick} 
      disabled={disabled}
      className={`btn btn-${variant}`}
    >
      {label}
    </button>
  );
}

// BENAR: Props dengan children
interface CardProps {
  title: string;
  children: React.ReactNode; // Bisa string, element, array, dll
}

function Card({ title, children }: CardProps) {
  return (
    <div className="card">
      <h2>{title}</h2>
      <div className="card-body">{children}</div>
    </div>
  );
}

// Penggunaan yang valid
<Card title="Profile">
  <p>Nama: John</p>
  <Button label="Edit" onClick={() => {}} />
</Card>

// ERROR: Memberikan props yang tidak sesuai
<Button 
  label="Submit" 
  onClick="not a function"  // Error: onClick harus () => void
  variant="warning"          // Error: variant tidak termasuk union type
/>
```

**Kasus Penggunaan Nyata:**
- Mencegah props yang tidak valid atau hilang saat penggunaan komponen
- Memberikan dokumentasi otomatis tentang apa yang dibutuhkan komponen
- IDE memberikan autocomplete saat mengetik nama props
- Refactoring props akan memunculkan error di semua tempat penggunaan
