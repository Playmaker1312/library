# 183. React.ComponentProps dan React.HTMLAttributes

**Definisi Singkat:** Utility types dari React untuk mendapatkan tipe props dari komponen atau element HTML, memudahkan dalam extending props dan membuat wrapper komponen.

**Analogi:** Seperti cetakan dokumen - `ComponentProps` mengambil semua kolom (props) dari formulir (komponen) yang sudah ada, sehingga Anda bisa membuat formulir baru dengan kolom yang sama plus tambahan.

**Poin-Poin Penting:**
- `React.ComponentProps<typeof Component>` - dapatkan props dari komponen
- `React.ComponentProps<'button'>` - dapatkan props dari element HTML
- `React.ComponentPropsWithoutRef<T>` - tanpa `ref` prop
- `React.ComponentPropsWithRef<T>` - dengan `ref` prop
- `React.HTMLAttributes<T>` - atribut HTML umum untuk element T

**Contoh Kode:**
```typescript
// BENAR: Menggunakan ComponentProps untuk wrapper button
import { Button as MuiButton } from '@mui/material';

// Dapatkan semua props dari MUI Button
type MuiButtonProps = React.ComponentProps<typeof MuiButton>;

// Extend dengan props tambahan
interface AppButtonProps extends MuiButtonProps {
  loading?: boolean;
  size?: 'sm' | 'md' | 'lg';  // Override tipe size
}

function AppButton({ loading, children, ...props }: AppButtonProps) {
  return (
    <MuiButton 
      disabled={loading || props.disabled}
      {...props}
    >
      {loading ? <Spinner /> : children}
    </MuiButton>
  );
}

// BENAR: ComponentProps untuk element HTML native
// Mendapatkan semua props dari <input> element
type InputProps = React.ComponentProps<'input'>;

interface MyInputProps extends Omit<InputProps, 'onChange'> {
  label: string;
  onChange?: (value: string) => void;  // Override onChange
}

function MyInput({ label, onChange, ...props }: MyInputProps) {
  const handleChange: React.ChangeEventHandler<HTMLInputElement> = (e) => {
    onChange?.(e.target.value);
  };

  return (
    <label>
      {label}
      <input onChange={handleChange} {...props} />
    </label>
  );
}

// BENAR: HTMLAttributes untuk div wrapper
interface CardProps extends React.HTMLAttributes<HTMLDivElement> {
  title: string;
}

function Card({ title, children, ...divProps }: CardProps) {
  return (
    <div className="card" {...divProps}>
      <h3>{title}</h3>
      {children}
    </div>
  );
}

// Penggunaan - bisa pakai onClick, className, style, dll
<Card title="Hello" onClick={() => {}} className="special-card">
  Content
</Card>

// ERROR: Salah menggunakan ComponentProps
type BadProps = React.ComponentProps<'div'>;  // OK
type BadProps2 = React.ComponentProps<MyInput>;  // ❌ Gunakan typeof MyInput

// BENAR: Correct usage
type CorrectProps = React.ComponentProps<typeof MyInput>;
```

**Kasus Penggunaan Nyata:**
- Membuat wrapper komponen untuk library UI (MUI, Chakra, dll)
- Extending element HTML native dengan props tambahan
- Mendapatkan tipe props dari komponen orang lain tanpa melihat source code
- Meneruskan props ke underlying element dengan spread operator yang aman
