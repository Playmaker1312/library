# 184. Typing Third-party Libraries di React

**Definisi Singkat:** Cara menggunakan TypeScript dengan library React pihak ketiga yang mungkin atau tidak menyediakan type definitions, memastikan interaksi yang type-safe.

**Analogi:** Seperti menggunakan gadget impor - jika ada buku panduan (type definitions) dalam bahasa Anda, ikuti itu. Jika tidak, buat catatan sendiri (declaration files) agar Anda tahu cara menggunakannya dengan benar.

**Poin-Poin Penting:**
- Banyak library sudah menyediakan types di `@types/[nama-library]`
- Cek `package.json` untuk field `"types"` atau `"typings"`
- Buat `*.d.ts` declaration file untuk library tanpa types
- Gunakan `declare module 'nama-library'` untuk module augmentation
- `// @ts-ignore` atau `as any` sebagai jalan terakhir

**Contoh Kode:**
```typescript
// Install types untuk library yang tidak menyertakan types
// npm install -D @types/react-router-dom @types/lodash

// BENAR: Menggunakan library dengan types yang tersedia
import { useNavigate, Location } from 'react-router-dom';
import _ from 'lodash';

function NavigationExample() {
  const navigate = useNavigate();  // Tipe: (to: string) => void
  
  const handleClick = () => {
    navigate('/dashboard');  // Type-safe
    navigate(123);  // Error: harus string
  };

  const users = [{ name: 'Alice' }, { name: 'Bob' }];
  const sorted = _.sortBy(users, 'name');  // Tipe terinferensi
}

// BENAR: Membuat declaration file untuk library tanpa types
// File: src/types/untitled-library.d.ts
declare module 'some-untitled-library' {
  export function doSomething(value: string): number;
  export interface Config {
    enabled: boolean;
    timeout?: number;
  }
  export function init(config: Config): void;
}

// Penggunaan setelah deklarasi
import { doSomething, init } from 'some-untitled-library';

const result = doSomething('hello');  // Tipe: number
init({ enabled: true });  // OK
init({ enabled: 'yes' });  // Error: enabled harus boolean

// BENAR: Module augmentation untuk menambah types
// File: src/types/react-app-env.d.ts
import 'react';

declare module 'react' {
  interface CSSProperties {
    '--my-custom-var'?: string;  // CSS custom property
  }
}

// Sekarang bisa digunakan
<div style={{ '--my-custom-var': '#fff' }} />

// JALAN TERAKHIR: Jika benar-benar tidak ada types
// @ts-ignore - mengabaikan error untuk baris ini
import something from 'library-without-types';

// Atau cast ke any
const lib = require('library-without-types') as any;
lib.doWhatever();  // Tidak ada type checking

// ERROR: Menggunakan any secara berlebihan
const anything: any = getFromLibrary();
anything.thisDoesNotExist();  // Tidak ada error, tapi akan crash di runtime
```

**Kasus Penggunaan Nyata:**
- Menggunakan UI component library (MUI, Ant Design, Chakra) dengan aman
- Memastikan props yang diberikan ke komponen library sesuai
- Mendapatkan autocomplete dan IntelliSense untuk library pihak ketiga
- Menangani library lama yang tidak memiliki dukungan TypeScript
