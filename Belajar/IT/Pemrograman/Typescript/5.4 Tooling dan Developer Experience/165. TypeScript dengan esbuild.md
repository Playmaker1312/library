# 165. TypeScript dengan esbuild

**Definisi Singkat:** esbuild memiliki kemampuan transpile TypeScript ke JavaScript dengan sangat cepat (10-100x lebih cepat dari tsc), meskipun tanpa type checking.

**Analogi:** Seperti membaca cepat — Anda bisa melewati teks (transpile) dengan sangat cepat, tapi tidak memeriksa ejaan (type checking) secara detail.

**Poin-Poin Penting:**
- esbuild hanya transpile, tidak melakukan type checking
- Kecepatan luar biasa karena ditulis dalam Go
- Cocok untuk development dan production build
- Type checking tetap perlu `tsc --noEmit` terpisah
- Mendukung JSX, TSX, dan dekorator

**Contoh Kode:**
```javascript
// build.js
import * as esbuild from 'esbuild';

await esbuild.build({
  entryPoints: ['src/index.ts'],
  bundle: true,
  outfile: 'dist/bundle.js',
  format: 'esm',
  target: 'es2020',
});

// BENAR: build cepat tanpa type checking
// ERROR: esbuild tidak menangkap error tipe
// const x: number = 'string'; // lolos!
```

```bash
# CLI
npx esbuild src/index.ts --outfile=dist/bundle.js --bundle

# Type check terpisah
npx tsc --noEmit
```

**Kasus Penggunaan Nyata:** Build tooling yang membutuhkan kecepatan ekstrem (development servers, one-off scripts) di mana type checking dilakukan terpisah di CI atau IDE.
