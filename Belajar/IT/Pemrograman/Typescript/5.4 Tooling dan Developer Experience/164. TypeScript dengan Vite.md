# 164. TypeScript dengan Vite

**Definisi Singkat:** Vite memiliki dukungan TypeScript bawaan yang mulus — cukup install TypeScript sebagai dev dependency dan Vite akan menangani transpilasi secara otomatis tanpa konfigurasi tambahan.

**Analogi:** Seperti hotel all-inclusive — Anda datang (install), dan semua fasilitas (tooling) sudah siap pakai tanpa perlu mengurus detailnya.

**Poin-Poin Penting:**
- Vite menggunakan esbuild untuk transpile TypeScript (sangat cepat)
- Tidak melakukan type checking saat build (itu tugas `tsc`)
- Hanya transpile, bukan kompilasi penuh TypeScript
- Type checking bisa ditambahkan dengan script terpisah: `tsc --noEmit`
- Dukungan HMR (Hot Module Replacement) bekerja sempurna

**Contoh Kode:**
```bash
# Init proyek Vite + TypeScript
npm create vite@latest my-app -- --template react-ts

# Type checking terpisah
npm install -D typescript
npx tsc --noEmit
```

```typescript
// vite.config.ts
import { defineConfig } from 'vite';

// BENAR: Vite mendukung TypeScript di konfigurasi
export default defineConfig({
  plugins: [],
});

// ERROR: Vite hanya transpile, error tipe tetap lolos build
// Gunakan `tsc --noEmit` terpisah untuk type checking
```

**Kasus Penggunaan Nyata:** Setup TypeScript yang paling cepat dan sederhana untuk aplikasi web modern (React, Vue, Svelte) dengan Vite.
