# 169. Performance - mempercepat kompilasi TypeScript

**Definisi Singkat:** Beberapa strategi untuk mempercepat kompilasi TypeScript: menggunakan incremental compilation, project references, skipLibCheck, dan mengganti transpiler dengan esbuild/SWC.

**Analogi:** Seperti membersihkan rumah — daripada membersihkan seluruh rumah setiap hari (full compile), lebih baik bersihkan kamar yang dipakai saja (incremental) dan sewa pembantu cepat (esbuild) untuk tugas berat.

**Poin-Poin Penting:**
- `incremental: true` + `.tsbuildinfo` untuk kompilasi bertahap
- `skipLibCheck: true` untuk melewati pemeriksaan .d.ts
- Project References untuk kompilasi paralel
- Gunakan esbuild/SWC untuk transpile, tsc hanya untuk type checking
- Batasi scope dengan `include` yang spesifik

**Contoh Kode:**
```json
{
  "compilerOptions": {
    "incremental": true,
    "skipLibCheck": true,
    "skipDefaultLibCheck": true,
    "target": "ESNext",
    "module": "ESNext",
    "moduleResolution": "bundler"
  }
}
```

```bash
# Benchmark waktu kompilasi
Measure-Command { npx tsc --noEmit }

# Dengan optimasi
npx tsc --noEmit --incremental --skipLibCheck

# BENAR: kombinasi optimal untuk kecepatan
# ERROR: skipLibCheck bisa sembunyikan error di library
```

**Kasus Penggunaan Nyata:** Proyek besar dengan ribuan file TypeScript yang membutuhkan waktu kompilasi lebih dari 1 menit — setiap optimasi sangat berarti untuk developer productivity.
