# 166. TypeScript dengan SWC

**Definisi Singkat:** SWC (Speedy Web Compiler) adalah platform kompilasi yang ditulis dalam Rust, mampu mentranspile TypeScript 20x lebih cepat dari Babel dan mendukung banyak fitur TypeScript.

**Analogi:** Seperti mobil balap dibandingkan mobil biasa — keduanya sampai tujuan, tapi SWC melakukannya dengan kecepatan luar biasa dan efisiensi bahan bakar (resource) yang lebih baik.

**Poin-Poin Penting:**
- Jauh lebih cepat dari Babel dan tsc
- Mendukung TypeScript, JSX, dan dekorator (Stage 3)
- Tidak melakukan type checking (seperti esbuild)
- Digunakan oleh Next.js, Vite (sebagai alternatif), dan Parcel
- Tersedia sebagai plugin Webpack, Rollup, dan Vite

**Contoh Kode:**
```javascript
// .swcrc
{
  "jsc": {
    "parser": {
      "syntax": "typescript",
      "tsx": true,
      "decorators": true
    },
    "target": "es2020"
  },
  "module": {
    "type": "es6"
  }
}
```

```bash
# CLI
npx swc src -d dist

# Dengan Next.js (built-in)
# next.config.js
module.exports = {
  swcMinify: true,
};
```

```typescript
// BENAR: SWC transpile cepat untuk production
// ERROR: SWC tidak validasi tipe
const x: number = 'string'; // ✅ lolos SWC, ❌ ditangkap tsc
```

**Kasus Penggunaan Nyata:** Proyek Next.js (menggunakan SWC secara default sejak v12) atau setup kustom yang membutuhkan kompilasi TypeScript dengan performa tinggi.
