# 162. ts-node dan tsx - menjalankan TypeScript langsung

**Definisi Singkat:** `ts-node` dan `tsx` adalah runtime yang memungkinkan Anda menjalankan file TypeScript langsung tanpa kompilasi terpisah, menggunakan JIT compilation.

**Analogi:** Seperti penerjemah simultan — Anda berbicara dalam bahasa asing (TypeScript) dan langsung dipahami tanpa harus menulis terjemahan (JavaScript) terlebih dahulu.

**Poin-Poin Penting:**
- `ts-node`: pioneer, menggunakan TypeScript compiler API
- `tsx` (lebih baru): menggunakan esbuild, jauh lebih cepat
- Keduanya mendukung watch mode dan REPL
- `tsx` adalah pengganti modern yang sangat direkomendasikan

**Contoh Kode:**
```bash
# Menginstal tsx (direkomendasikan)
npm install -D tsx

# Menjalankan TypeScript langsung
npx tsx src/index.ts

# Atau ts-node (legacy)
npm install -D ts-node
npx ts-node src/index.ts

# Watch mode
npx tsx watch src/index.ts
```

```typescript
// script.ts
const greet = (name: string): string => `Hello ${name}`;
console.log(greet('World'));

// BENAR: langsung jalan tanpa tsc
// $ npx tsx script.ts
// Output: Hello World

// ERROR: ts-node/tsx tidak validasi tipe secara default
```

**Kasus Penggunaan Nyata:** Menjalankan script development, migrasi database, atau task automation tanpa setup build step.
