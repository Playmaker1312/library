# 160. TypeScript dengan ESLint - typescript-eslint

**Definisi Singkat:** `typescript-eslint` adalah toolkit yang memungkinkan ESLint menganalisis dan melintasi kode TypeScript, memberikan aturan linting spesifik untuk tipe dan sintaks TypeScript.

**Analogi:** Seperti satpam yang juga ahli bahasa asing — ESLint biasa (untuk JS) dilengkapi dengan kemampuan tambahan untuk memahami dan memeriksa TypeScript.

**Poin-Poin Penting:**
- Menggantikan TSLint yang sudah deprecated
- Terdiri dari parser (`@typescript-eslint/parser`) dan plugin (`@typescript-eslint/eslint-plugin`)
- Menyediakan aturan seperti `no-unused-vars` versi TS
- Mendukung type-aware linting (rule yang butuh type information)

**Contoh Kode:**
```json
// .eslintrc.json
{
  "parser": "@typescript-eslint/parser",
  "plugins": ["@typescript-eslint"],
  "extends": [
    "eslint:recommended",
    "plugin:@typescript-eslint/recommended"
  ],
  "rules": {
    "@typescript-eslint/no-unused-vars": "error",
    "@typescript-eslint/explicit-function-return-type": "warn"
  }
}
```

```typescript
// ERROR: typescript-eslint menangkap ini
const x: number = 5;
x = 10; // ❌ eslint: no-const-assign

// ERROR: unused variable
function add(a: number, b: number) {
  const unused = 'test';
  return a + b; // ❌ @typescript-eslint/no-unused-vars
}
```

**Kasus Penggunaan Nyata:** Menjaga konsistensi kode dan menangkap kesalahan umum di proyek TypeScript dari berbagai ukuran.
