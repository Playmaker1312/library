# 163. TypeScript dengan Webpack - ts-loader dan fork-ts-checker

**Definisi Singkat:** Integrasi TypeScript dengan Webpack menggunakan `ts-loader` untuk kompilasi dan `fork-ts-checker-webpack-plugin` untuk type checking di proses terpisah agar build lebih cepat.

**Analogi:** Seperti dapur restoran — satu koki (ts-loader) memasak makanan (transpile), sementara koki lain (fork-ts-checker) memeriksa kualitas bahan (type checking) secara paralel.

**Poin-Poin Penting:**
- `ts-loader` menggunakan TypeScript compiler untuk transpile
- `fork-ts-checker-webpack-plugin` menjalankan type checking di thread terpisah
- `awesome-typescript-loader` sudah deprecated
- Alternatif modern: `babel-loader` + `@babel/preset-typescript` (lebih cepat, tanpa type check)

**Contoh Kode:**
```javascript
// webpack.config.js
module.exports = {
  module: {
    rules: [
      {
        test: /\.ts$/,
        use: 'ts-loader',
        exclude: /node_modules/,
      },
    ],
  },
  plugins: [
    new ForkTsCheckerWebpackPlugin({
      typescript: {
        diagnosticOptions: {
          semantic: true,
          syntactic: true,
        },
      },
    }),
  ],
  resolve: {
    extensions: ['.ts', '.js'],
  },
};
```

```typescript
// BENAR: webpack + ts-loader menghasilkan bundle
// ERROR: tanpa fork-ts-checker, error tipe tidak terlihat saat build
```

**Kasus Penggunaan Nyata:** Proyek web legacy yang menggunakan Webpack dan ingin mengintegrasikan TypeScript dengan tetap mempertahankan konfigurasi Webpack yang sudah ada.
