# 161. Prettier dan TypeScript

**Definisi Singkat:** Prettier adalah formatter kode yang mendukung TypeScript secara native, memformat kode secara otomatis berdasarkan aturan yang konsisten tanpa konfigurasi berlebihan.

**Analogi:** Seperti mesin pelurus rambut — membuat semua helai rambut (kode) rapi dan seragam, tidak peduli bagaimana awalnya.

**Poin-Poin Penting:**
- Prettier mendukung TypeScript, TSX, dan deklarasi tipe
- Tidak perlu plugin terpisah untuk TypeScript
- Sebaiknya nonaktifkan aturan ESLint yang conflicting dengan Prettier (`eslint-config-prettier`)
- Integrasi dengan editor via format on save

**Contoh Kode:**
```json
// .prettierrc
{
  "semi": true,
  "singleQuote": true,
  "trailingComma": "all",
  "printWidth": 100,
  "tabWidth": 2
}
```

```typescript
// Sebelum Prettier (berantakan)
const add=(a:number,b:number):number=>{ return a+b }

// Setelah Prettier (rapi)
const add = (a: number, b: number): number => {
  return a + b;
};

// ERROR: konflik antara ESLint dan Prettier
// tanpa eslint-config-prettier, aturan indentasi akan bentrok
```

**Kasus Penggunaan Nyata:** Mengotomatiskan formatting sehingga tim tidak perlu berdebat tentang gaya kode — cukup jalankan Prettier.
