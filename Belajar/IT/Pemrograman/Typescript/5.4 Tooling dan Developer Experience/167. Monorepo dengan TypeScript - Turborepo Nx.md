# 167. Monorepo dengan TypeScript - Turborepo Nx

**Definisi Singkat:** Monorepo dengan TypeScript menggunakan tools seperti Turborepo atau Nx untuk mengelola banyak package dalam satu repository, dengan caching build dan task orchestration.

**Analogi:** Seperti pusat perbelanjaan — banyak toko (package) berbeda dalam satu gedung (repo), dengan sistem keamanan dan layanan bersama (tooling) yang terkoordinasi.

**Poin-Poin Penting:**
- Turborepo: ringan, fokus pada caching build
- Nx: lebih berat, dengan banyak fitur generator dan plugin
- Keduanya mendukung TypeScript Project References
- Build caching mempercepat CI secara dramatis
- Task orchestration: jalankan task secara paralel sesuai dependency graph

**Contoh Kode:**
```json
// turbo.json
{
  "pipeline": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": ["dist/**"]
    },
    "test": {
      "dependsOn": ["build"]
    },
    "lint": {}
  }
}
```

```bash
# Turborepo
npx turbo run build

# Nx
npx nx run-many --target=build --all

# BENAR: dependencies otomatis dibangun dalam urutan benar
# ERROR: tanpa caching, setiap build full dari awal
```

**Kasus Penggunaan Nyata:** Proyek besar dengan multiple packages (shared UI components, backend services, utility libraries) yang perlu dibangun dan diuji bersama.
