# 41. Readonly Properties - properti yang tidak bisa diubah **Definisi Singkat:** Properti yang hanya dapat dibaca setelah object dibuat, tidak bisa di-reassign. **Analogi:** Seperti nomor induk KTP — bisa dilihat, tetapi tidak bisa diubah setelah dicetak. **Poin-Poin Penting:** - Ditambahkan keyword `readonly` sebelum nama properti - Hanya mencegah reassignment, bukan immutability dalam (shallow) - Berguna untuk immutable configuration atau ID **Contoh Kode:** ```typescript // BENAR (valid):
interface Config {
  readonly apiKey: string;
  readonly endpoint: string;
  timeout: number;
}

const config: Config = { apiKey: "abc123", endpoint: "/api", timeout: 5000 };
config.timeout = 3000; // valid, bisa diubah
// config.apiKey = "newkey"; // error: Cannot assign to 'apiKey' because it is a read-only property /* error */

// ReadonlyArray
const arr: ReadonlyArray<number> = [1, 2, 3];
// arr.push(4); // error: Property 'push' does not exist on type 'readonly number[]' /* error */ ``` **Kasus Penggunaan Nyata:** Konfigurasi aplikasi yang tidak boleh berubah setelah inisialisasi, atau immutable state management pattern.
