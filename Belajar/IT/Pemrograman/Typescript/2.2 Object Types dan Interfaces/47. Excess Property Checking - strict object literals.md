# 47. Excess Property Checking - strict object literals **Definisi Singkat:** TypeScript secara ketat memeriksa bahwa object literal tidak memiliki properti tambahan di luar yang dideklarasikan. **Analogi:** Seperti check-in hotel — Anda hanya boleh membawa barang yang terdaftar di formulir; koper ekstra akan ditolak. **Poin-Poin Penting:** - Hanya berlaku untuk object literal, bukan variable yang sudah diassign - Memberikan error jika ada properti tak dikenal - Bisa dilewati dengan type assertion atau index signature **Contoh Kode:** ```typescript // BENAR (valid):
interface Person {
  name: string;
  age: number;
}

const p1: Person = { name: "Mira", age: 25 };

// Variabel yang sudah diassign tidak dicek ketat
const data = { name: "Mira", age: 25, extra: true };
const p2: Person = data; // valid — tidak kena excess checking

// ERROR (type-error):
const wrong: Person = { name: "Mira", age: 25, extra: true }; // error: Object literal may only specify known properties /* error */ ``` **Kasus Penggunaan Nyata:** Mencegah typo pada properti object literal, memastikan data yang dikirim ke fungsi sesuai kontrak, dan keamanan saat mapping data API.
