# 42. Index Signatures - dynamic property keys **Definisi Singkat:** Mendefinisikan tipe properti untuk object dengan key yang dinamis/tidak diketahui sebelumnya. **Analogi:** Seperti kamus — Anda tidak tahu semua kata yang ada, tapi Anda tahu bahwa setiap kata (key) memiliki definisi (value) bertipe string. **Poin-Poin Penting:** - Syntax: `[key: TipeKey]: TipeValue` - Key type hanya bisa `string`, `number`, atau `symbol` - Semua properti harus sesuai dengan index signature **Contoh Kode:** ```typescript // BENAR (valid):
interface StringDictionary {
  [key: string]: string;
}

const translations: StringDictionary = {
  hello: "halo",
  goodbye: "selamat tinggal",
};

interface NumberMap {
  [id: number]: string;
}
const users: NumberMap = { 1: "Budi", 2: "Sari" };

// ERROR (type-error):
const wrong: StringDictionary = { hello: 42 }; // error: Type 'number' is not assignable to type 'string' /* error */ ``` **Kasus Penggunaan Nyata:** Cache objects, map/dictionary pattern, data dari API dengan key dinamis, atau object lookup table.
