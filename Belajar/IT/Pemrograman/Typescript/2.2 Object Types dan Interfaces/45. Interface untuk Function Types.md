# 45. Interface untuk Function Types **Definisi Singkat:** Interface juga bisa mendeskripsikan tipe fungsi menggunakan call signature `(parameter: Tipe): ReturnType` . **Analogi:** Seperti formulir lamaran kerja — mendeskripsikan "pekerjaan" apa yang bisa dilakukan seseorang tanpa melihat siapa orangnya. **Poin-Poin Penting:** - Call signature ditulis dengan `:` bukan `=>` - Interface function type bisa memiliki properti tambahan - Alternatif dari function type expression **Contoh Kode:** ```typescript // BENAR (valid):
interface StringProcessor {
  (input: string): string;
}

const toUpper: StringProcessor = (input) => input.toUpperCase();

interface MathOperation {
  (a: number, b: number): number;
  operationName: string;
}

const multiply: MathOperation = (a, b) => a * b;
multiply.operationName = "perkalian";

// ERROR (type-error):
const wrong: StringProcessor = (input: number) => input.toString(); // error: Parameter type mismatch /* error */ ``` **Kasus Penggunaan Nyata:** Mendefinisikan tipe untuk factory function, validator, atau transform function yang juga membutuhkan metadata tambahan.
