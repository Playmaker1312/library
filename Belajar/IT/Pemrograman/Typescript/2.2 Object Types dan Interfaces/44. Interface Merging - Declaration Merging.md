# 44. Interface Merging - Declaration Merging **Definisi Singkat:** TypeScript secara otomatis menggabungkan beberapa deklarasi interface dengan nama yang sama menjadi satu interface tunggal. **Analogi:** Seperti menambahkan sayap pada bangunan yang sudah ada — bangunan tetap sama, sekarang lebih besar dengan fitur baru. **Poin-Poin Penting:** - Hanya berlaku untuk `interface`, bukan `type` - Semua deklarasi dengan nama yang sama akan digabung - Berguna untuk augmentasi library pihak ketiga **Contoh Kode:** ```typescript // BENAR (valid):
interface Box {
  height: number;
  width: number;
}

interface Box {
  depth: number;
}

// Hasilnya: interface Box { height: number; width: number; depth: number; }
const box: Box = { height: 10, width: 20, depth: 30 }; // valid

// ERROR (type-error):
// Tidak bisa override tipe properti yang sudah ada
interface Box {
  weight: string;
}
interface Box {
  weight: number; // error: Subsequent property declarations must have the same type /* error */ ``` **Kasus Penggunaan Nyata:** Menambahkan properti ke interface global seperti `Window` atau `String`, atau augmentasi tipe dari package npm (module augmentation).
