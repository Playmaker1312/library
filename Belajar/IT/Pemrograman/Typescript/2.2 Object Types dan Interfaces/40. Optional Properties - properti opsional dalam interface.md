# 40. Optional Properties - properti opsional dalam interface **Definisi Singkat:** Properti dalam interface yang boleh ada atau tidak, ditandai dengan `?` setelah nama properti. **Analogi:** Seperti survei dengan kolom "komentar tambahan" — bersifat opsional, bisa diisi atau dikosongkan. **Poin-Poin Penting:** - Ditulis: `propertyName?: Tipe` - Secara otomatis menjadi `Tipe | undefined` - Saat mengakses, TypeScript memperingatkan kemungkinan undefined **Contoh Kode:** ```typescript // BENAR (valid):
interface UserProfile {
  username: string;
  email: string;
  phone?: string;
}

const user1: UserProfile = { username: "indra", email: "indra@mail.com" };
const user2: UserProfile = { username: "joko", email: "joko@mail.com", phone: "081234" };

function getContact(user: UserProfile): string {
  return user.phone ?? user.email; // nullish coalescing
}

// ERROR (type-error):
const wrong: UserProfile = { username: "test" }; // error: Property 'email' is missing /* error */ ``` **Kasus Penggunaan Nyata:** Representasi data dari form dengan field opsional, data API yang tidak selalu menyertakan semua field, atau konfigurasi partial.
