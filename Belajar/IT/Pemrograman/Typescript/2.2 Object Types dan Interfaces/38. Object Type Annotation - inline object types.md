# 38. Object Type Annotation - inline object types **Definisi Singkat:** Mendeskripsikan bentuk suatu object secara langsung di tempat menggunakan `{ property: Tipe }` . **Analogi:** Seperti formulir pendaftaran — kolom-kolomnya didefinisikan langsung di formulir tanpa cetak biru terpisah. **Poin-Poin Penting:** - Ditulis inline: `{ nama: string; umur: number }` - Pemisah bisa `;` atau `,` - Setiap properti bisa diberi tipe secara spesifik **Contoh Kode:** ```typescript // BENAR (valid):
function printCoord(pt: { x: number; y: number }): void {
  console.log(`(${pt.x}, ${pt.y})`);
}
printCoord({ x: 10, y: 20 });

const user: { name: string; age: number } = {
  name: "Fajar",
  age: 22,
};

// ERROR (type-error):
printCoord({ x: 10, y: "20" }); // error: Type 'string' is not assignable to type 'number' /* error */ ``` **Kasus Penggunaan Nyata:** Parameter fungsi sederhana yang hanya digunakan sekali, atau tipe data sementara dalam satu modul kecil.
