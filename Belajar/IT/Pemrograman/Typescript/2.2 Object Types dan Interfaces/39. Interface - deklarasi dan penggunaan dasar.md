# 39. Interface - deklarasi dan penggunaan dasar **Definisi Singkat:** Interface adalah cara untuk mendefinisikan kontrak bentuk suatu object dengan keyword `interface` . **Analogi:** Seperti cetakan kue — menentukan bentuk akhir kue tanpa perlu membuatnya berulang-ulang. **Poin-Poin Penting:** - Menggunakan keyword `interface` diikuti nama dan `{ }` - Dapat digunakan berulang kali di banyak tempat - Bersifat open — bisa ditambahkan properti baru (declaration merging) **Contoh Kode:** ```typescript // BENAR (valid):
interface Person {
  name: string;
  age: number;
}

function greet(person: Person): string {
  return `Halo ${person.name}, usia ${person.age}`;
}

const employee: Person = { name: "Gita", age: 25 };
greet(employee);

// ERROR (type-error):
const wrong: Person = { name: "Hadi" }; // error: Property 'age' is missing /* error */ ``` **Kasus Penggunaan Nyata:** Mendefinisikan tipe entity/model seperti `User`, `Product`, `Order` yang digunakan di seluruh aplikasi.
