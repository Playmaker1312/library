# 46. Hybrid Types - object yang juga callable **Definisi Singkat:** Tipe yang menggabungkan sifat object (properti) dan fungsi (callable) secara bersamaan dalam satu entitas. **Analogi:** Seperti resepsionis yang juga merangkap operator telepon — bisa diajak bicara (fungsi) dan juga memiliki atribut seperti nama dan shift kerja (properti). **Poin-Poin Penting:** - Gabungkan call signature dan properti dalam satu interface - Berguna untuk fungsi yang memiliki state atau konfigurasi - TypeScript memvalidasi kedua aspek secara bersamaan **Contoh Kode:** ```typescript // BENAR (valid):
interface Counter {
  (start: number): string;
  interval: number;
  reset(): void;
}

function createCounter(): Counter {
  const fn = ((start: number) => `Count ${start}`) as Counter;
  fn.interval = 1000;
  fn.reset = () => { console.log("Reset!"); };
  return fn;
}

const counter = createCounter();
counter(5);        // "Count 5"
counter.interval;  // 1000

// ERROR (type-error):
const wrong: Counter = (n: number) => n.toString(); // error: Property 'reset' is missing /* error */ ``` **Kasus Penggunaan Nyata:** Library jQuery-style ($ adalah fungsi sekaligus punya properti), atau stateful function seperti `createStore` di Redux.
