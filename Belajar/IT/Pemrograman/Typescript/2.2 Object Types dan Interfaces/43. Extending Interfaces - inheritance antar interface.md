# 43. Extending Interfaces - inheritance antar interface **Definisi Singkat:** Interface dapat mewarisi properti dari satu atau lebih interface lain menggunakan keyword `extends` . **Analogi:** Seperti spesifikasi mobil sport yang mewarisi semua fitur dari mobil biasa — tetap punya roda, stir, kursi, plus tambahan spoiler dan turbo. **Poin-Poin Penting:** - Syntax: `interface B extends A { ... }` - Bisa extends multiple interface: `interface C extends A, B` - Mencegah duplikasi properti **Contoh Kode:** ```typescript // BENAR (valid):
interface Named {
  name: string;
}
interface Aged {
  age: number;
}
interface Employee extends Named, Aged {
  employeeId: string;
}

const emp: Employee = {
  name: "Lina",
  age: 30,
  employeeId: "EMP001",
};

// ERROR (type-error):
const wrong: Employee = { name: "Lina", age: 30 }; // error: Property 'employeeId' is missing /* error */ ``` **Kasus Penggunaan Nyata:** Memodelkan hierarki entity (BaseUser -> AdminUser, Customer), atau memperluas tipe dari library eksternal.
