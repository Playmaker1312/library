# 230. Behavioral Patterns - Observer dengan TypeScript **Definisi Singkat:** Observer mendefinisikan hubungan one-to-many di mana ketika satu objek berubah state, semua dependennya diberitahu secara otomatis. **Analogi:** Observer seperti channel YouTube—Anda subscribe, dan setiap kali konten baru diupload, Anda mendapat notifikasi. **Poin-Poin Penting:** - Subject menyimpan daftar observers - TypeScript bisa digunakan untuk type-safe event payload - Lepas coupling antara subject dan observer **Contoh Kode:** ```typescript // BENAR: interface Observer<T> { update(data: T): void; } class Subject<T> { private observers: Observer<T>[] = []; subscribe(obs: Observer<T>): void { this.observers.push(obs); } unsubscribe(obs: Observer<T>): void { this.observers = this.observers.filter(o => o !== obs); } notify(data: T): void { this.observers.forEach(o => o.update(data)); } } class Logger implements Observer<string> { update(data: string) { console.log("Log:", data); } } const subject = new Subject<string>(); subject.subscribe(new Logger()); subject.notify("Hello"); // "Log: Hello" // ERROR: class BadObserver { update(data: number) {} } // Tidak compatible dengan Observer<string> ``` **Kasus Penggunaan Nyata:** Event handling sistem, state management (Redux/Zustand), real-time updates di aplikasi chat atau dashboard.
