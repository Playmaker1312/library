# 226. Structural Patterns - Adapter dengan TypeScript **Definisi Singkat:** Adapter memungkinkan objek dengan interface tidak kompatibel untuk bekerja sama dengan cara membungkusnya dalam adapter. **Analogi:** Adapter seperti adaptor colokan listrik—colokan Eropa tidak bisa langsung ke stopkontak AS, butuh adaptor sebagai perantara. **Poin-Poin Penting:** - Menggunakan interface TypeScript untuk mendefinisikan target - Class adapter membungkus adaptee - Client hanya berinteraksi dengan interface target **Contoh Kode:** ```typescript // BENAR: interface EuropeanPlug { voltage(): number; } class USPlug { providePower(): number { return 120; } } class USToEuropeanAdapter implements EuropeanPlug { private usPlug: USPlug; constructor(usPlug: USPlug) { this.usPlug = usPlug; } voltage(): number { return this.usPlug.providePower() * 2.2; // step-up transformer } } const adapter = new USToEuropeanAdapter(new USPlug()); console.log(adapter.voltage()); // ~264V // ERROR: // Tanpa adapter, EuropeanPlug tidak bisa menerima USPlug ``` **Kasus Penggunaan Nyata:** Integrasi library pihak ketiga dengan interface berbeda—membungkus API lama agar kompatibel dengan sistem baru.
