Behavioral Patterns - Strategy dengan TypeScript **Definisi Singkat:** Strategy mendefinisikan keluarga algoritma yang dapat dipertukarkan, memungkinkan algoritma bervariasi secara independen dari klien yang menggunakannya. **Analogi:** Strategy seperti aplikasi navigasi—Anda bisa memilih rute tercepat, terpendek, atau paling hemat bahan bakar tanpa mengubah aplikasi. **Poin-Poin Penting:** - Setiap strategy mengimplementasikan interface yang sama - Klien memilih strategy saat runtime - TypeScript memastikan semua strategy memiliki signature yang sama **Contoh Kode:** ```typescript // BENAR: interface PaymentStrategy { pay(amount: number): void; } class CreditCardPayment implements PaymentStrategy { pay(amount: number) { console.log(`Paid ${amount} with credit card`); } } class PayPalPayment implements PaymentStrategy { pay(amount: number) { console.log(`Paid ${amount} with PayPal`); } } class ShoppingCart { constructor(private strategy: PaymentStrategy) {} checkout(amount: number) { this.strategy.pay(amount); } } const cart = new ShoppingCart(new PayPalPayment()); cart.checkout(100); // "Paid 100 with PayPal" // ERROR: class InvalidStrategy { pay(amount: string) {} } // Tak cocok dengan interface ``` **Kasus Penggunaan Nyata:** Multiple authentication methods (OAuth, JWT, LDAP), multiple export formats (PDF, CSV, Excel), atau sorting algorithms.
