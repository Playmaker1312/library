# 225. Creational Patterns - Builder dengan TypeScript **Definisi Singkat:** Builder memisahkan konstruksi objek kompleks dari representasinya sehingga proses konstruksi yang sama dapat menghasilkan representasi berbeda. **Analogi:** Builder seperti membuat pizza—Anda memilih base, saus, topping secara bertahap, dan hasil akhirnya adalah pizza utuh. **Poin-Poin Penting:** - Menggunakan method chaining (return `this`) - Mengakumulasi parameter sebelum `build()` - TypeScript bisa memvalidasi langkah builder dengan tipe state **Contoh Kode:** ```typescript // BENAR: class PizzaBuilder { private crust: string = ""; private sauce: string = ""; private toppings: string[] = []; setCrust(crust: string): this { this.crust = crust; return this; } addSauce(sauce: string): this { this.sauce = sauce; return this; } addTopping(topping: string): this { this.toppings.push(topping); return this; } build(): string { return `Pizza with ${this.crust} crust, ${this.sauce} sauce, ${this.toppings.join(",")}`; } } const pizza = new PizzaBuilder().setCrust("thin").addSauce("tomato").addTopping("cheese").build(); // ERROR: // Builder tanpa return this memutus method chaining ``` **Kasus Penggunaan Nyata:** Membangun objek konfigurasi kompleks (HTTP request builder, query builder ORM) dengan banyak parameter opsional.
