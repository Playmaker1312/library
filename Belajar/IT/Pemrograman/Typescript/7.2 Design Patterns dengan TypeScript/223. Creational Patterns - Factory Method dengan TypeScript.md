Creational Patterns - Factory Method dengan TypeScript **Definisi Singkat:** Factory Method mendefinisikan interface untuk membuat objek, tetapi membiarkan subclass menentukan kelas konkret yang akan diinstansiasi. **Analogi:** Factory Method seperti restoran dengan menu—pelanggan memesan "makanan" (interface), dan dapur memutuskan menu spesifik apa yang dibuat. **Poin-Poin Penting:** - Pisahkan kode pembuatan objek dari kode bisnis - Memanfaatkan polymorphism TypeScript - Cocok untuk tipe objek yang bervariasi **Contoh Kode:** ```typescript // BENAR: interface Button { render(): void; } class WindowsButton implements Button { render() { console.log("Render Windows button"); } } class MacButton implements Button { render() { console.log("Render Mac button"); } } abstract class Dialog { abstract createButton(): Button; showDialog() { const btn = this.createButton(); btn.render(); } } class WindowsDialog extends Dialog { createButton(): Button { return new WindowsButton(); } } // ERROR: // Jika createButton return string, akan error karena tidak sesuai kontrak ``` **Kasus Penggunaan Nyata:** UI component library yang perlu menyesuaikan tampilan di berbagai platform (Windows, macOS, Linux).
