# 236. Dependency Injection tanpa framework **Definisi Singkat:** Dependency Injection (DI) adalah teknik di mana objek menerima dependensinya dari luar, bukan membuatnya sendiri—tanpa perlu framework berat seperti NestJS. **Analogi:** DI seperti membawa laptop ke service center—Anda tidak perlu membawa seluruh meja kerja; teknisi hanya perlu laptop (dependensi spesifik). **Poin-Poin Penting:** - Constructor injection adalah cara paling sederhana - TypeScript interfaces memudahkan mocking dan testing - Cocok untuk codebase kecil hingga menengah **Contoh Kode:** ```typescript // BENAR: interface Logger { log(message: string): void; } class ConsoleLogger implements Logger { log(message: string) { console.log(message); } } class UserService { constructor(private logger: Logger) {} // DI via constructor createUser(name: string) { this.logger.log(`User ${name} created`); } } // Wiring (manual DI container) const logger = new ConsoleLogger(); const userService = new UserService(logger); // ERROR: class BadService { private logger = new ConsoleLogger(); // ❌ Hardcoded dependency, sulit di-test } ``` **Kasus Penggunaan Nyata:** Aplikasi yang membutuhkan testability tinggi—dengan DI, Anda bisa inject mock logger/mock database saat unit testing tanpa framework mahal.
