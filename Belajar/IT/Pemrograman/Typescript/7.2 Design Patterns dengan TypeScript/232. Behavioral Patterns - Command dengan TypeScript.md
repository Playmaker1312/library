Behavioral Patterns - Command dengan TypeScript **Definisi Singkat:** Command mengubah permintaan menjadi objek mandiri yang berisi semua informasi tentang permintaan tersebut. **Analogi:** Command seperti waiter di restoran—pelanggan memberi tahu waiter (perintah ditangkap), lalu waiter menyampaikannya ke koki (eksekusi terpisah). **Poin-Poin Penting:** - Memisahkan objek yang memanggil operasi dari yang tahu cara menjalankan - Mendukung undo/redo, queue, logging - TypeScript bisa tipe-safe payload tiap command **Contoh Kode:** ```typescript // BENAR: interface Command { execute(): void; undo(): void; } class TextEditor { private text = ""; write(chars: string) { this.text += chars; } erase(n: number) { this.text = this.text.slice(0, -n); } getText() { return this.text; } } class WriteCommand implements Command { constructor(private editor: TextEditor, private chars: string) {} execute() { this.editor.write(this.chars); } undo() { this.editor.erase(this.chars.length); } } // Usage: const editor = new TextEditor(); const cmd = new WriteCommand(editor, "Hello"); cmd.execute(); cmd.undo(); // ERROR: class BadCmd { execute() {} } // ❌ Missing undo() method ``` **Kasus Penggunaan Nyata:** Undo/redo di aplikasi editor, task queue, macro recording, atau transaction logging di sistem database.
