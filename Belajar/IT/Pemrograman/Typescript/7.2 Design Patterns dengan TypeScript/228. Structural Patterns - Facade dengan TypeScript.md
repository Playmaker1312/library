Structural Patterns - Facade dengan TypeScript **Definisi Singkat:** Facade menyediakan antarmuka sederhana ke subsistem atau kumpulan class yang kompleks. **Analogi:** Facade seperti remote TV—Anda cukup tekan tombol "power" tanpa perlu tahu cara kerja rangkaian listrik di dalam TV. **Poin-Poin Penting:** - Menyembunyikan kompleksitas subsistem - Client hanya berinteraksi dengan facade - Mengurangi coupling antara client dan subsistem **Contoh Kode:** ```typescript // BENAR: class CPU { start() { /* complex */ } } class Memory { load() { /* complex */ } } class HardDrive { read() { /* complex */ } } class ComputerFacade { private cpu = new CPU(); private memory = new Memory(); private hardDrive = new HardDrive(); start(): void { this.cpu.start(); this.memory.load(); this.hardDrive.read(); console.log("Computer started"); } } const computer = new ComputerFacade(); computer.start(); // Simple API for complex subsystem // ERROR: // Client mengakses CPU, Memory, HardDrive langsung → kompleks dan rawan error ``` **Kasus Penggunaan Nyata:** Library untuk mengirim email—satu fungsi `sendEmail()` menyembunyikan kompleksitas koneksi SMTP, format MIME, dan handling attachment.
