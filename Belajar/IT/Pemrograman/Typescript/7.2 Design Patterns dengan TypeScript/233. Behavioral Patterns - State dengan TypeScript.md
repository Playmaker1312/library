Behavioral Patterns - State dengan TypeScript **Definisi Singkat:** State memungkinkan objek mengubah perilakunya ketika state internalnya berubah, seolah-olah objek berganti kelas. **Analogi:** State seperti air—pada suhu berbeda (state), perilaku air berubah: padat (es), cair (air), gas (uap). **Poin-Poin Penting:** - Setiap state adalah class yang mengimplementasikan interface sama - Context mendelegasikan behavior ke state saat ini - Transisi state terjadi di dalam state itu sendiri **Contoh Kode:** ```typescript // BENAR: interface State { play(): void; pause(): void; } class PlayingState implements State { constructor(private player: MusicPlayer) {} play() { console.log("Already playing"); } pause() { console.log("Pausing"); this.player.setState(this.player.pausedState); } } class PausedState implements State { constructor(private player: MusicPlayer) {} play() { console.log("Playing"); this.player.setState(this.player.playingState); } pause() { console.log("Already paused"); } } class MusicPlayer { playingState = new PlayingState(this); pausedState = new PausedState(this); private state: State = this.pausedState; setState(s: State) { this.state = s; } play() { this.state.play(); } pause() { this.state.pause(); } } // ERROR: // Jika state tidak mengimplement State, method play/pause tidak ada ``` **Kasus Penggunaan Nyata:** Workflow engine, game character states (idle, running, jumping), atau koneksi WebSocket (connecting, connected, disconnected).
