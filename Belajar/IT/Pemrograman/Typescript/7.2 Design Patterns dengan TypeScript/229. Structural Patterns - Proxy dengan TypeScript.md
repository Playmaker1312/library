Structural Patterns - Proxy dengan TypeScript **Definisi Singkat:** Proxy menyediakan pengganti atau placeholder untuk objek lain guna mengontrol akses ke objek tersebut. **Analogi:** Proxy seperti sekretaris eksekutif—semua panggilan ke CEO harus melalui sekretaris yang menyaring, menjadwalkan, atau menunda. **Poin-Poin Penting:** - Proxy dan real subject mengimplementasikan interface yang sama - Jenis: virtual proxy, protection proxy, logging proxy - Cocok untuk lazy loading, access control, caching **Contoh Kode:** ```typescript // BENAR: interface Image { display(): void; } class RealImage implements Image { constructor(private filename: string) { this.loadFromDisk(); } private loadFromDisk() { console.log("Loading huge image..."); } display() { console.log(`Display ${this.filename}`); } } class ProxyImage implements Image { private realImage: RealImage | null = null; constructor(private filename: string) {} display(): void { if (!this.realImage) { this.realImage = new RealImage(this.filename); } this.realImage.display(); } } const img = new ProxyImage("photo.jpg"); img.display(); // Load & display first time img.display(); // Only display (cached) // ERROR: // ProxyImage tidak mengimplement Image → tidak bisa substitusi ``` **Kasus Penggunaan Nyata:** Virtual proxy untuk gambar besar (lazy loading), protection proxy untuk otentikasi, caching proxy untuk hasil komputasi mahal.
