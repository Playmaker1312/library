Creational Patterns - Abstract Factory dengan TypeScript **Definisi Singkat:** Abstract Factory menyediakan interface untuk membuat keluarga objek yang saling terkait tanpa menentukan kelas konkretnya. **Analogi:** Abstract Factory seperti pabrik furnitur—satu pabrik memproduksi set lengkap (kursi, meja, sofa) dengan gaya yang konsisten (minimalis, klasik). **Poin-Poin Penting:** - Lebih tinggi levelnya dari Factory Method—memproduksi banyak produk - Menggunakan interface/type untuk setiap produk - TypeScript enforces contract antar produk **Contoh Kode:** ```typescript // BENAR: interface Chair { sit(): void; } interface Table { place(): void; } interface FurnitureFactory { createChair(): Chair; createTable(): Table; } class ModernChair implements Chair { sit() { console.log("Sit on modern chair"); } } class ModernTable implements Table { place() { console.log("Place on modern table"); } } class ModernFactory implements FurnitureFactory { createChair() { return new ModernChair(); } createTable() { return new ModernTable(); } } // ERROR: class IncompleteFactory implements FurnitureFactory { createChair() { return new ModernChair(); } // ❌ Missing createTable() } ``` **Kasus Penggunaan Nyata:** UI theme system (Light/Dark theme) yang konsisten untuk semua komponen (button, input, card).
