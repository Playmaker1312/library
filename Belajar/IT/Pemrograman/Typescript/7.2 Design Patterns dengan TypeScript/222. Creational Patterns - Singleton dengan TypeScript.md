Creational Patterns - Singleton dengan TypeScript **Definisi Singkat:** Singleton memastikan sebuah class hanya memiliki satu instance dan menyediakan akses global ke instance tersebut. **Analogi:** Singleton seperti presiden sebuah negara—hanya ada satu pada satu waktu, dan semua orang mengakses pemimpin yang sama. **Poin-Poin Penting:** - Gunakan `private constructor` + static method - TypeScript memudahkan dengan access modifiers - Pertimbangkan dependency injection sebagai alternatif **Contoh Kode:** ```typescript // BENAR: class Database { private static instance: Database; private constructor() { } static getInstance(): Database { if (!Database.instance) { Database.instance = new Database(); } return Database.instance; } query(sql: string) { /* ... */ } } const db = Database.getInstance(); // ERROR: const db2 = new Database(); // ❌ Constructor of 'Database' is private ``` **Kasus Penggunaan Nyata:** Koneksi database, logger, konfigurasi aplikasi global—di mana hanya satu resource yang dibutuhkan.
