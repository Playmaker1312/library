# 235. Functional Patterns - Pipe dan Compose **Definisi Singkat:** Pipe dan Compose adalah fungsi yang menggabungkan beberapa fungsi menjadi satu aliran data—pipe dari kiri ke kanan, compose dari kanan ke kiri. **Analogi:** Pipe seperti jalur perakitan pabrik—bahan mentah masuk di satu sisi, melewati serangkaian stasiun, dan keluar sebagai produk jadi. **Poin-Poin Penting:** - Pipe: `f1(f2(f3(x)))` ditulis sebagai `pipe(x, f3, f2, f1)` - Compose: `f1(f2(f3(x)))` ditulis sebagai `compose(f1, f2, f3)(x)` - TypeScript type inference bekerja dengan variadic tuple types **Contoh Kode:** ```typescript // BENAR: type Pipe = <A, B, C>(a: A, ab: (a: A) => B, bc: (b: B) => C) => C; const pipe: Pipe = (a, ab, bc) => bc(ab(a)); const add1 = (x: number) => x + 1; const toString = (x: number) => String(x); const result = pipe(5, add1, toString); // "6" (string) // Compose const compose = <A, B, C>(bc: (b: B) => C, ab: (a: A) => B) => (a: A): C => bc(ab(a)); const add1ThenString = compose(toString, add1); console.log(add1ThenString(5)); // "6" // ERROR: pipe(5, toString, add1); // ❌ add1 expects number, gets string ``` **Kasus Penggunaan Nyata:** Data transformation pipeline—misalnya, mengambil data dari API → validasi → transform → format response, semua dalam rantai type-safe.
