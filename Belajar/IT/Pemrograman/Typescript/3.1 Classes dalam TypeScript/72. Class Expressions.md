# 72. Class Expressions

**Definisi Singkat:** Class expressions adalah cara mendefinisikan class tanpa nama (anonymous) atau dengan nama opsional sebagai ekspresi yang bisa di-assign ke variabel, dikirim sebagai argumen, atau dibuat secara dinamis.

**Analogi:** Seperti makanan kaki lima yang dimasak di gerobak tanpa nama restoran — tetap bisa dimakan (digunakan), meskipun tidak ada papan nama.

**Poin-Poin Penting:**
- Syntax: `const Nama = class { ... }` — anonymous class expression
- Bisa dikasih nama internal: `const Nama = class InternalName { ... }` (hanya terlihat di dalam class)
- Bisa di-return dari fungsi, di-pass sebagai argumen, atau dibuat dinamis
- Mendukung inheritance dan implements seperti class declaration biasa

**Contoh Kode:**
```typescript
// BENAR: class expression dalam berbagai bentuk
// 1. Anonymous class expression
const Logger = class {
  constructor(private prefix: string) {}

  log(message: string): void {
    console.log(`[${this.prefix}] ${message}`);
  }
};

const logger = new Logger("App");
logger.log("Aplikasi dimulai"); // "[App] Aplikasi dimulai"

// 2. Class expression dengan nama internal
const Parser = class ParserInternal {
  private name: string;

  constructor(name: string) {
    this.name = name;
    // Nama internal hanya bisa diakses di dalam class
    // console.log(ParserInternal.name); // "ParserInternal"
  }

  parse(input: string): any {
    return JSON.parse(input);
  }
};
// console.log(ParserInternal); // Error: tidak dikenal di luar

// 3. Factory function yang mengembalikan class expression
function createRepository<T>(tableName: string) {
  return class {
    constructor(public table: string = tableName) {}

    async findById(id: number): Promise<T | null> {
      console.log(`Mencari di ${this.table} dengan id ${id}`);
      return null;
    }

    async save(data: T): Promise<void> {
      console.log(`Menyimpan ke ${this.table}:`, data);
    }
  };
}

class User {
  constructor(public id: number, public name: string) {}
}

const UserRepo = createRepository<User>("users");
const repo = new UserRepo();
repo.findById(1); // "Mencari di users dengan id 1"
```

**Kasus Penggunaan Nyata:** Mixins (fungsi yang menghasilkan class), factory pattern untuk repository/service, dependency injection container, dynamic class creation berdasarkan konfigurasi, composable class utilities.
