# 65. Getter dan Setter dengan tipe

**Definisi Singkat:** Getter (`get`) dan setter (`set`) adalah accessor properties yang memungkinkan eksekusi logika saat membaca atau menulis properti, dengan anotasi tipe yang ketat.

**Analogi:** Seperti security door — pintu (setter) memverifikasi sidik jari dulu sebelum membuka, dan sensor (getter) melaporkan status pintu dengan format tertentu.

**Poin-Poin Penting:**
- `get` tidak boleh memiliki parameter, `set` harus memiliki tepat satu parameter
- Tipe return getter harus sama dengan tipe parameter setter
- Bisa digunakan untuk validasi, transformasi, atau computed properties
- Getter/setter muncul sebagai properti biasa, bukan method

**Contoh Kode:**
```typescript
// BENAR: getter dan setter dengan validasi tipe
class Temperature {
  private _celsius: number = 0;

  get celsius(): number {
    return this._celsius;
  }

  set celsius(value: number) {
    if (value < -273.15) {
      throw new Error("Suhu tidak boleh di bawah absolute zero!");
    }
    this._celsius = value;
  }

  // Computed property (getter saja, tanpa setter)
  get fahrenheit(): number {
    return this._celsius * 9 / 5 + 32;
  }

  set fahrenheit(value: number) {
    this._celsius = (value - 32) * 5 / 9;
  }

  get formatted(): string {
    return `${this._celsius}°C / ${this.fahrenheit}°F`;
  }
}

const temp = new Temperature();
temp.celsius = 100;           // menggunakan setter
console.log(temp.fahrenheit); // 212 — menggunakan getter
console.log(temp.formatted);  // "100°C / 212°F"

// temp.celsius = -300;       // ERROR: throw exception

// ERROR: tipe setter harus cocok dengan getter
// set celsius(value: string) { } // Error
```

**Kasus Penggunaan Nyata:** Validasi input (umur tidak negatif, email format benar), transformasi data (format mata uang, normalisasi string), computed properties (fullName dari firstName + lastName), logging perubahan properti.
