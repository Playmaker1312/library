# 61. Class declaration dengan type annotations

**Definisi Singkat:** TypeScript memperbolehkan deklarasi class dengan anotasi tipe eksplisit pada properties, constructor, dan method untuk memastikan type safety.

**Analogi:** Seperti cetak biru bangunan yang sudah menentukan spesifikasi material, dimensi, dan letak setiap bagian — semua harus sesuai cetak biru.

**Poin-Poin Penting:**
- `class Nama { properti: tipe = nilai; }` — deklarasi properti dengan tipe
- TypeScript tidak mengizinkan akses properti yang tidak dideklarasikan di class

**Contoh Kode:**
```typescript
// BENAR: deklarasi class dengan anotasi tipe lengkap
class Product {
  id: number;
  name: string;
  price: number;
  inStock: boolean = true;

  constructor(id: number, name: string, price: number) {
    this.id = id;
    this.name = name;
    this.price = price;
  }

  applyDiscount(percent: number): number {
    this.price = this.price * (1 - percent / 100);
    return this.price;
  }
}

const phone = new Product(1, "Phone", 500);
phone.inStock = false;

// ERROR: properti tidak dideklarasikan
phone.category = "electronics";
// Property 'category' does not exist on type 'Product'
```

**Kasus Penggunaan Nyata:** Membuat model data (User, Order, Product) dengan struktur yang ketat agar mencegah kesalahan assignment properti di aplikasi backend NestJS atau frontend dengan framework OOP.
