# 62. Access Modifiers - public private protected

**Definisi Singkat:** Access modifiers (`public`, `private`, `protected`) mengontrol visibilitas properti dan method class — siapa yang bisa mengakses dari luar class atau dari kelas turunan.

**Analogi:** Seperti rumah: `public` adalah halaman depan (semua orang bisa akses), `private` adalah kamar tidur (hanya penghuni rumah), `protected` adalah ruang keluarga (penghuni dan tamu tertentu/keluarga).

**Poin-Poin Penting:**
- `public` (default) — bisa diakses dari mana saja
- `private` — hanya bisa diakses dari dalam class itu sendiri (tidak termasuk turunan)
- `protected` — bisa diakses dari class dan subclass (tidak dari luar instance)
- JavaScript native `#` untuk private class fields juga didukung

**Contoh Kode:**
```typescript
// BENAR: access modifiers mengontrol visibilitas
class BankAccount {
  public accountNumber: string;
  private balance: number;
  protected ownerName: string;

  constructor(accountNumber: string, ownerName: string, initialBalance: number) {
    this.accountNumber = accountNumber;
    this.ownerName = ownerName;
    this.balance = initialBalance;
  }

  public deposit(amount: number): void {
    if (amount > 0) this.balance += amount;
  }

  private calculateInterest(): number {
    return this.balance * 0.05;
  }

  protected getBalanceInfo(): string {
    return `Saldo: ${this.balance}, Bunga: ${this.calculateInterest()}`;
  }
}

class SavingsAccount extends BankAccount {
  showInfo(): string {
    // OK: protected bisa diakses dari subclass
    return `Akun milik ${this.ownerName}`;
    // ERROR: private tidak bisa diakses dari subclass
    // return this.balance; // Error
    // return this.calculateInterest(); // Error
  }
}

const acc = new BankAccount("12345", "Budi", 1000);
acc.deposit(500);
acc.accountNumber;      // OK: public
// acc.balance;         // ERROR: private
// acc.ownerName;      // ERROR: protected
// acc.calculateInterest(); // ERROR: private
```

**Kasus Penggunaan Nyata:** Enkapsulasi data sensitif seperti password hash, saldo rekening, atau token internal — hanya diekspos melalui method getter/setter yang aman.
