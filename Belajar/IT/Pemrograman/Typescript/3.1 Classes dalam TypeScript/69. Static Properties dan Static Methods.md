# 69. Static Properties dan Static Methods

**Definisi Singkat:** Anggota `static` dimiliki oleh class itu sendiri, bukan oleh instance — diakses langsung melalui `ClassName.property` tanpa perlu membuat objek.

**Analogi:** Seperti resep rahasia sebuah restoran — semua chef (instance) menggunakan resep yang sama dari buku resep pusat (static), bukan resep pribadi masing-masing.

**Poin-Poin Penting:**
- `static properti: tipe` atau `static method() { }` — milik class, bukan instance
- Diakses dengan `NamaClass.properti`, bukan `this.properti`
- Method static hanya bisa mengakses member static lain (tidak bisa akses `this` instance)
- Bisa juga `private static` untuk helper internal class

**Contoh Kode:**
```typescript
// BENAR: static member milik class
class MathUtils {
  static PI: number = 3.1415926535;

  static circleArea(radius: number): number {
    return MathUtils.PI * radius ** 2;
  }

  static isEven(num: number): boolean {
    return num % 2 === 0;
  }

  private static log(message: string): void {
    console.log(`[MathUtils] ${message}`);
  }
}

// Akses tanpa instance
console.log(MathUtils.PI);              // 3.1415926535
console.log(MathUtils.circleArea(5));   // 78.539...
console.log(MathUtils.isEven(4));       // true

const obj = new MathUtils(); // Tidak berguna, semua member static
// obj.PI;                   // ERROR: static tidak bisa diakses via instance

class Config {
  static instanceCount: number = 0;
  readonly name: string;

  constructor(name: string) {
    this.name = name;
    Config.instanceCount++; // Static counter
  }

  static getCount(): number {
    return Config.instanceCount;
    // ERROR: tidak bisa akses non-static dari static
    // return this.name; // Error
  }
}

new Config("A");
new Config("B");
console.log(Config.getCount()); // 2
```

**Kasus Penggunaan Nyata:** Utility/helper class (Math, DateFormatter), factory methods (`User.fromJSON()`), singleton pattern, counters, metadata class (registry, mapping), konfigurasi global.
