# 67. Implementing Interfaces - implements keyword

**Definisi Singkat:** `implements` memungkinkan class untuk mengontrak bahwa ia akan menyediakan implementasi konkret dari semua properti dan method yang dideklarasikan oleh interface.

**Analogi:** Seperti kontrak kerja antara perusahaan dan karyawan — interface adalah daftar tugas (job description), class adalah karyawan yang melaksanakan tugas-tugas tersebut.

**Poin-Poin Penting:**
- `class Foo implements Bar { ... }` — class wajib memiliki semua member dari interface `Bar`
- Sebuah class bisa mengimplementasi multiple interfaces: `class A implements B, C`
- Interface hanya mendefinisikan bentuk (shape), bukan implementasi
- Class yang mengimplementasi interface bisa memiliki member tambahan

**Contoh Kode:**
```typescript
// BENAR: class mengimplementasi interface
interface Printable {
  print(): void;
  getContent(): string;
}

interface Exportable {
  exportTo(format: string): string;
}

// Class implementasi satu interface
class Report implements Printable {
  constructor(private title: string, private body: string) {}

  print(): void {
    console.log(`=== ${this.title} ===\n${this.body}`);
  }

  getContent(): string {
    return `${this.title}\n${this.body}`;
  }
}

// Class implementasi multiple interfaces
class Invoice implements Printable, Exportable {
  constructor(
    private invoiceNumber: string,
    private total: number
  ) {}

  print(): void {
    console.log(`Invoice #${this.invoiceNumber}: Rp${this.total}`);
  }

  getContent(): string {
    return `INV-${this.invoiceNumber}\nTotal: ${this.total}`;
  }

  exportTo(format: string): string {
    if (format === "PDF") return `PDF: ${this.getContent()}`;
    if (format === "CSV") return `CSV: ${this.invoiceNumber},${this.total}`;
    throw new Error("Format tidak didukung");
  }
}

const report = new Report("Laporan Keuangan", "...");
report.print();

const invoice = new Invoice("INV-001", 500000);
console.log(invoice.exportTo("PDF"));

// ERROR: class tidak mengimplementasi semua member interface
// interface Flyable { fly(): void; }
// class Bird implements Flyable { } // Error: 'fly' missing
```

**Kasus Penggunaan Nyata:** Strategy Pattern (interface Strategy → class ConcreteStrategy), Repository Pattern, Service Layer, Dependency Injection — mendefinisikan kontrak yang bisa diganti implementasinya.
