# 66. Class Inheritance - extends keyword

**Definisi Singkat:** Inheritance memungkinkan sebuah class (child) mewarisi properti dan method dari class lain (parent) menggunakan keyword `extends`, serta dapat menambahkan atau meng- override behavior.

**Analogi:** Seperti mobil listrik yang mewarisi fitur dari mobil biasa (roda, setir, rem) tetapi menambahkan fitur baru (baterai, motor listrik) dan mengubah cara kerja mesin.

**Poin-Poin Penting:**
- `class Child extends Parent { ... }` — child mewarisi semua member parent (kecuali `private`)
- Constructor child harus memanggil `super()` sebelum mengakses `this`
- Method overriding: child bisa mendefinisikan ulang method parent dengan nama sama
- TypeScript memeriksa compatibility tipe saat override

**Contoh Kode:**
```typescript
// BENAR: inheritance dengan extends dan super
class Animal {
  constructor(public name: string) {}

  makeSound(): string {
    return `${this.name} membuat suara`;
  }

  move(distance: number): string {
    return `${this.name} bergerak ${distance}m`;
  }
}

class Dog extends Animal {
  constructor(name: string, public breed: string) {
    super(name); // WAJIB: panggil constructor parent
  }

  // Override method parent
  makeSound(): string {
    return `${this.name} menggonggong: Guk! Guk!`;
  }

  // Method baru khusus Dog
  wagTail(): string {
    return `${this.name} mengibas-ngibaskan ekor`;
  }
}

class Cat extends Animal {
  constructor(name: string, public isIndoor: boolean) {
    super(name);
  }

  makeSound(): string {
    return `${this.name} mengeong: Meow~`;
  }

  move(distance: number): string {
    // Panggil method parent lalu tambahkan behavior
    return `${super.move(distance)} dengan sangat lincah`;
  }
}

const dog = new Dog("Max", "Golden Retriever");
console.log(dog.makeSound()); // "Max menggonggong: Guk! Guk!"
console.log(dog.wagTail());   // "Max mengibas-ngibaskan ekor"

const cat = new Cat("Luna", true);
console.log(cat.makeSound()); // "Luna mengeong: Meow~"
console.log(cat.move(10));    // "Luna bergerak 10m dengan sangat lincah"

// ERROR: method private parent tidak bisa diakses child
// class Animal { private secret() {} }
// class Bird extends Animal { test() { this.secret(); } } // Error
```

**Kasus Penggunaan Nyata:** Hierarki entitas bisnis (Employee → Manager → Director), komponen UI (BaseButton → IconButton), model database (BaseModel → UserModel → AdminModel), plugin system (Plugin → LoggerPlugin → AuthPlugin).
