# 71. Override keyword TS 4.3+

**Definisi Singkat:** Keyword `override` (TS 4.3+) menandai secara eksplisit bahwa suatu method di subclass sengaja menimpa method dari parent class — compiler akan memeriksa bahwa method dengan nama yang sama benar-benar ada di parent.

**Analogi:** Seperti tombol "Override" di microwave — Anda sengaja mengganti waktu memasak default, dan mesin akan memastikan bahwa program default memang ada sebelum Anda menggantinya.

**Poin-Poin Penting:**
- `override` ditempatkan sebelum method signature di subclass
- Compiler error jika method yang di-"override" tidak ada di parent class
- Mencegah typo atau perubahan signature parent yang tidak disengaja
- Diaktifkan dengan `noImplicitOverride` di tsconfig.json

**Contoh Kode:**
```typescript
// BENAR: override keyword mencegah kesalahan
class BaseService {
  save(data: any): void {
    console.log("Menyimpan data:", data);
  }

  validate(data: any): boolean {
    return data != null;
  }

  protected log(message: string): void {
    console.log(`[BaseService] ${message}`);
  }
}

class UserService extends BaseService {
  // BENAR: sengaja override method parent
  override save(data: any): void {
    this.log("Memvalidasi sebelum menyimpan");
    if (this.validate(data)) {
      super.save(data);
    }
  }

  // ERROR: method 'valdate' tidak ada di parent (typo)
  // override valdate(data: any): boolean {
  //   return data.name != null;
  // }
  // This member cannot have an 'override' modifier
  // because it is not declared in the base class.

  override validate(data: any): boolean {
    return data != null && data.name != null;
  }

  override log(message: string): void {
    console.log(`[UserService] ${message}`);
  }
}

// Tanpa override — tidak ada error meskipun typo
class BrokenService extends BaseService {
  // Tidak pakai override — typo tidak ketahuan
  // vallidate(data: any): boolean { // Tidak error, method baru
  //   return true;
  // }
}
```

**Kasus Penggunaan Nyata:** Team projects di mana banyak developer meng-extend base class — `override` mencegah kesalahan saat refactoring nama method di parent; framework/library yang menggunakan inheritance chain panjang.
