# 64. Constructor dan Parameter Properties shorthand

**Definisi Singkat:** Parameter properties shorthand memungkinkan deklarasi, inisialisasi, dan assignment properti class langsung dari parameter constructor dengan menambahkan access modifier atau `readonly`.

**Analogi:** Seperti mesin ATM yang langsung menerima setoran dan mencatatnya di buku tabungan dalam satu langkah — tanpa perlu antri dua kali.

**Poin-Poin Penting:**
- Tambahkan `public`, `private`, `protected`, atau `readonly` di parameter constructor
- TypeScript otomatis membuat dan mengisi properti dengan nama yang sama
- Mengurangi boilerplate kode deklarasi + assignment manual

**Contoh Kode:**
```typescript
// BENAR: parameter properties shorthand mengurangi boilerplate
class Employee {
  // Shorthand: deklarasi + inisialisasi dalam satu langkah
  constructor(
    public readonly id: number,
    public name: string,
    private salary: number,
    protected department: string,
  ) {}
  // Tidak perlu tulis:
  //   this.id = id; this.name = name; this.salary = salary; ...

  getInfo(): string {
    return `${this.name} (${this.id}) - ${this.department}`;
  }
}

const emp = new Employee(1, "Budi", 5000000, "IT");
console.log(emp.name);       // OK: public
// console.log(emp.salary);  // ERROR: private

// Sebenarnya sama dengan:
class EmployeeLong {
  public readonly id: number;
  public name: string;
  private salary: number;
  protected department: string;

  constructor(id: number, name: string, salary: number, department: string) {
    this.id = id;
    this.name = name;
    this.salary = salary;
    this.department = department;
  }
}
```

**Kasus Penggunaan Nyata:** DTO (Data Transfer Object), service layers dengan dependency injection di NestJS/Angular, entity models dengan banyak field — menulis kode lebih ringkas dan konsisten.
