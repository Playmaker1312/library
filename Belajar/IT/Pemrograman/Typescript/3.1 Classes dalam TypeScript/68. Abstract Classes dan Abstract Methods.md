# 68. Abstract Classes dan Abstract Methods

**Definisi Singkat:** Abstract class adalah class yang tidak bisa diinstansiasi langsung — berfungsi sebagai kerangka dasar yang menyediakan implementasi sebagian dan mewajibkan subclass untuk mengimplementasikan method abstract tertentu.

**Analogi:** Seperti cetakan kue berbentuk bintang — Anda tidak bisa makan cetakannya (abstract class), tapi Anda bisa membuat kue bintang dari cetakan itu (concrete class).

**Poin-Poin Penting:**
- `abstract class Nama { ... }` — tidak bisa di-`new` langsung
- `abstract method(): tipe` — deklarasi tanpa body, wajib diimplementasi subclass
- Bisa memiliki method konkret (dengan implementasi) dan properti biasa
- Abstract method hanya boleh ada di abstract class

**Contoh Kode:**
```typescript
// BENAR: abstract class sebagai kerangka
abstract class Shape {
  constructor(protected color: string) {}

  // Method konkret — semua subclass mewarisi ini
  getColor(): string {
    return this.color;
  }

  // Abstract method — wajib diimplementasi subclass
  abstract area(): number;
  abstract perimeter(): number;

  // Method konkret yang menggunakan abstract method
  describe(): string {
    return `Bentuk ${this.color} dengan luas ${this.area().toFixed(2)}`;
  }
}

class Circle extends Shape {
  constructor(color: string, private radius: number) {
    super(color);
  }

  area(): number {
    return Math.PI * this.radius ** 2;
  }

  perimeter(): number {
    return 2 * Math.PI * this.radius;
  }
}

class Rectangle extends Shape {
  constructor(color: string, private width: number, private height: number) {
    super(color);
  }

  area(): number {
    return this.width * this.height;
  }

  perimeter(): number {
    return 2 * (this.width + this.height);
  }
}

// const shape = new Shape("merah");   // ERROR: tidak bisa instansiasi abstract class
const circle = new Circle("biru", 5);
console.log(circle.describe());         // "Bentuk biru dengan luas 78.54"
console.log(circle.perimeter());        // 31.415...

// ERROR: subclass tidak implementasi abstract method
// class Triangle extends Shape { }     // Error: 'area', 'perimeter' missing
```

**Kasus Penggunaan Nyata:** Template Method Pattern (proses yang langkahnya sudah ditentukan tapi detailnya berbeda), base class untuk komponen UI, pipeline processor, validators dengan logika umum dan aturan spesifik per jenis.
