# 73. this type dalam class methods

**Definisi Singkat:** `this` sebagai tipe return di class method memungkinkan method mengembalikan tipe konkret dari subclass yang memanggilnya — mendukung fluent interface dan chaining yang type-safe dengan inheritance.

**Analogi:** Seperti remote TV universal — saat Anda menekan tombol "volume naik" di remote Samsung, ia tahu itu remote Samsung dan mengembalikan remote Samsung, bukan remote merek lain.

**Poin-Poin Penting:**
- Method bisa dideklarasikan return type `this` — bukan nama class
- Subclass yang memanggil method akan mendapatkan tipe subclass-nya
- `this` sebagai tipe parameter: `method(this: Type)` — untuk type guard di method
- Berguna untuk builder pattern dan fluent API dengan inheritance

**Contoh Kode:**
```typescript
// BENAR: this type untuk fluent chaining type-safe
class Builder {
  protected data: Record<string, any> = {};

  set(key: string, value: any): this {
    this.data[key] = value;
    return this; // Return this, tipe = class konkret
  }

  build(): Record<string, any> {
    return { ...this.data };
  }
}

class UserBuilder extends Builder {
  setName(name: string): this {
    return this.set("name", name);
  }

  setAge(age: number): this {
    return this.set("age", age);
  }
}

// Tanpa this type — return tipe Builder, method subclass hilang
const user = new UserBuilder()
  .setName("Budi")   // return UserBuilder
  .setAge(25)        // return UserBuilder (OK)
  .set("role", "admin") // return UserBuilder (OK)
  .build();

console.log(user);

// Parameter this type untuk type guard
class Animal {
  constructor(public name: string) {}

  isDog(this: Animal): this is Dog {
    return this instanceof Dog;
  }

  isCat(this: Animal): this is Cat {
    return this instanceof Cat;
  }
}

class Dog extends Animal {
  bark(): string { return "Guk!"; }
}

class Cat extends Animal {
  meow(): string { return "Meow!"; }
}

const pets: Animal[] = [new Dog("Max"), new Cat("Luna")];
for (const pet of pets) {
  if (pet.isDog()) {
    console.log(pet.bark()); // TypeScript tahu ini Dog
  }
}
```

**Kasus Penggunaan Nyata:** Builder/fluent pattern (ORM query builder seperti Prisma, Jest assertions), chain configuration, Composite pattern, method chaining di library UI atau DOM manipulation.
