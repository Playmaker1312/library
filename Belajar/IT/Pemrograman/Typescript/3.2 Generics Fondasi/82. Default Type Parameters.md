# 82. Default Type Parameters

**Definisi Singkat:** Default type parameter memungkinkan penentuan tipe default untuk type parameter jika tidak dispesifikasikan atau tidak bisa di-infer oleh TypeScript.

**Analogi:** Seperti setting pabrik (factory default) di ponsel — Anda bisa mengubahnya sesuai keinginan, tapi jika tidak diubah, ponsel akan menggunakan pengaturan default yang sudah ditentukan.

**Poin-Poin Penting:**
- Syntax: `<T = DefaultType>` — di type alias, interface, class
- Tidak bisa digunakan di function generic (hanya di type/interface/class)
- Berguna untuk membuat API yang fleksibel dengan fallback tipe
- Default bisa berupa tipe konkret atau tipe yang dihasilkan dari parameter lain

**Contoh Kode:**
```typescript
// BENAR: default type parameter untuk API yang fleksibel

// 1. Generic interface dengan default
interface ApiResponse<T = unknown> {
  success: boolean;
  data: T;
  message?: string;
}

// Tanpa spesifikasi tipe — pakai default unknown
const response1: ApiResponse = {
  success: true,
  data: { anything: "goes" },
};

// Dengan tipe spesifik
const response2: ApiResponse<{ id: number; name: string }> = {
  success: true,
  data: { id: 1, name: "Budi" },
};

// 2. Generic type alias dengan default
type Result<T, E = Error> =
  | { success: true; data: T }
  | { success: false; error: E };

// E menggunakan default Error
const ok: Result<number> = { success: true, data: 42 };
// E bisa dispesifikasikan
const custom: Result<string, string> = {
  success: false,
  error: "Terjadi kesalahan"
};

// 3. Generic class dengan default
class Stack<T = any> {
  private items: T[] = [];
  push(item: T): void { this.items.push(item); }
  pop(): T | undefined { return this.items.pop(); }
}

// Tanpa spesifikasi tipe — Stack<any>
const anyStack = new Stack();
anyStack.push("string");
anyStack.push(42); // OK: any

// Dengan tipe spesifik
const numStack = new Stack<number>();
numStack.push(1);
// numStack.push("2"); // ERROR

// 4. Default dari parameter lain
type EventHandler<EventMap, Event extends keyof EventMap = keyof EventMap & string> =
  (payload: EventMap[Event]) => void;

// Default type parameter di interface extends
interface BaseResponse<T = any> {
  data: T;
  status: number;
}

// ERROR: default type tidak bisa di function
// function create<T = string>(x: T): T { return x; }
// TypeScript akan error — function generic tidak support default type
```

**Kasus Penggunaan Nyata:** Library/framework API yang ingin user-friendly (tidak perlu specify type untuk kasus sederhana), utility types dengan fallback, event system dengan payload unknown secara default, state manager store generic.
