# 75. Generic Functions - sintaks angle bracket T

**Definisi Singkat:** Generic function adalah fungsi yang dideklarasikan dengan satu atau lebih parameter tipe (type parameter) menggunakan angle bracket `<T>`, sehingga bisa menerima dan mengembalikan tipe yang berbeda-beda.

**Analogi:** Seperti mesin stamping custom — Anda bisa mengganti cetakan (tipe) untuk membuat stempel berbeda, tetapi mesinnya tetap sama.

**Poin-Poin Penting:**
- Syntax: `function nama<T>(param: T): T { }` — T adalah placeholder tipe
- Type inference: compiler bisa menyimpulkan T dari argumen
- Eksplisit: bisa ditentukan manual: `nama<string>("arg")`
- Bisa memiliki multiple type parameter

**Contoh Kode:**
```typescript
// BENAR: generic function dengan type inference dan eksplisit
// Generic function sederhana
function wrapInArray<T>(item: T): T[] {
  return [item];
}

// Type inference otomatis
const numArray = wrapInArray(42);     // T = number → number[]
const strArray = wrapInArray("hello"); // T = string → string[]
const boolArray = wrapInArray(true);   // T = boolean → boolean[]

// Eksplisit menentukan tipe
const explicit = wrapInArray<string>("hello"); // T = string

// Generic function dengan multiple parameter
function pair<T, U>(first: T, second: U): [T, U] {
  return [first, second];
}

const p1 = pair(1, "one");      // [number, string]
const p2 = pair(true, 42);      // [boolean, number]
const p3 = pair<string, number>("age", 25); // [string, number]

// Generic arrow function
const merge = <T, U>(obj1: T, obj2: U): T & U => {
  return { ...obj1, ...obj2 };
};

const merged = merge({ name: "Budi" }, { age: 25 });
// type: { name: string } & { age: number }

// Generic dengan constraint built-in
function getLength<T extends { length: number }>(item: T): number {
  return item.length;
}

getLength("hello");    // 5 (string punya length)
getLength([1, 2, 3]);  // 3 (array punya length)
// getLength(42);       // ERROR: number tidak punya length
```

**Kasus Penggunaan Nyata:** Fungsi utilitas (pick, omit, map, filter), transformasi data API, helper untuk state management, fungsi yang memproses Promise hasil query database.
