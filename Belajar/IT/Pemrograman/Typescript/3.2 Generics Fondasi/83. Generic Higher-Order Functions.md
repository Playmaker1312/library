# 83. Generic Higher-Order Functions

**Definisi Singkat:** Higher-order function generic adalah fungsi yang menerima atau mengembalikan fungsi lain dengan type parameter, memungkinkan komposisi fungsi yang type-safe dan reusable.

**Analogi:** Seperti jalur perakitan (assembly line) di pabrik — setiap stasiun kerja (fungsi) menerima input tertentu, memprosesnya, dan melemparkan ke stasiun berikutnya, semua dengan spesifikasi yang terdefinisi.

**Poin-Poin Penting:**
- Generic HOF bisa meng-generic-kan input, output, atau callback function
- Type inference bekerja melalui beberapa tingkat HOF
- Memungkinkan komposisi fungsi (function composition) yang type-safe
- Berguna untuk decorators, middleware, transforms

**Contoh Kode:**
```typescript
// BENAR: generic higher-order functions

// 1. Generic function wrapper/decorator
function withLogging<T extends (...args: any[]) => any>(
  fn: T
): (...args: Parameters<T>) => ReturnType<T> {
  return (...args: Parameters<T>): ReturnType<T> => {
    console.log(`Memanggil ${fn.name} dengan:`, args);
    const result = fn(...args);
    console.log(`Hasil:`, result);
    return result;
  };
}

function add(a: number, b: number): number {
  return a + b;
}

const loggedAdd = withLogging(add);
const sum = loggedAdd(3, 4); // Console: "Memanggil add dengan: [3, 4]", "Hasil: 7"

// 2. Generic function composer
function compose<T, U, V>(
  f: (x: T) => U,
  g: (x: U) => V
): (x: T) => V {
  return (x: T) => g(f(x));
}

const toUpper = (s: string) => s.toUpperCase();
const exclaim = (s: string) => `${s}!`;
const shout = compose(toUpper, exclaim);
console.log(shout("hello")); // "HELLO!"

// 3. Generic middleware pattern
type Middleware<T> = (data: T, next: (data: T) => void) => void;

function createPipeline<T>(...middlewares: Middleware<T>[]) {
  return (initialData: T): void => {
    const execute = (index: number, data: T): void => {
      if (index < middlewares.length) {
        middlewares[index](data, (nextData) => execute(index + 1, nextData));
      }
    };
    execute(0, initialData);
  };
}

const pipeline = createPipeline<{ user: string; role: string }>(
  (data, next) => { console.log("Auth:", data.user); next(data); },
  (data, next) => { console.log("Role:", data.role); next(data); },
);

pipeline({ user: "Budi", role: "admin" });
// Auth: Budi
// Role: admin

// 4. Generic memoize
function memoize<T extends (...args: any[]) => any>(fn: T): T {
  const cache = new Map<string, ReturnType<T>>();
  return ((...args: Parameters<T>): ReturnType<T> => {
    const key = JSON.stringify(args);
    if (cache.has(key)) return cache.get(key)!;
    const result = fn(...args);
    cache.set(key, result);
    return result;
  }) as T;
}
```

**Kasus Penggunaan Nyata:** Express/Koa middleware chains, NestJS guards/interceptors, Redux middleware, function composition di data pipeline, caching decorators, rate limiting wrappers, error boundary functions.
