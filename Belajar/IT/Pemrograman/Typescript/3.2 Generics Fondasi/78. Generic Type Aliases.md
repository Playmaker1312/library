# 78. Generic Type Aliases

**Definisi Singkat:** Generic type alias menggunakan `type` keyword dengan type parameter untuk membuat nama alias tipe yang reusable dengan berbagai tipe data.

**Analogi:** Seperti cetakan kue huruf — cetakan "A" bisa menghasilkan kue bentuk A dari adonan coklat, vanila, atau stroberi (tipe bahan berbeda), tapi cetakannya sama.

**Poin-Poin Penting:**
- `type Nama<T> = ...` — membuat alias tipe generik
- Bisa digunakan untuk union types, intersection, tuple, function signature
- Lebih fleksibel daripada interface untuk tipe non-object (union, intersection, conditional)
- Bisa digunakan dengan mapped types, conditional types

**Contoh Kode:**
```typescript
// BENAR: generic type alias untuk berbagai bentuk

// 1. Generic wrapper/result type
type Result<T, E = Error> =
  | { success: true; data: T }
  | { success: false; error: E };

const ok: Result<number> = { success: true, data: 42 };
const fail: Result<string> = { success: false, error: new Error("gagal") };

// 2. Generic nullable type
type Nullable<T> = T | null | undefined;
const name: Nullable<string> = null; // bisa string | null | undefined

// 3. Generic function type
type Mapper<T, U> = (item: T, index: number) => U;
const toString: Mapper<number, string> = (n) => n.toString();

// 4. Generic union type
type ApiState<T> =
  | { status: "idle" }
  | { status: "loading" }
  | { status: "success"; data: T }
  | { status: "error"; message: string };

const state: ApiState<User[]> = { status: "idle" };

// 5. Generic dengan conditional type
type IsString<T> = T extends string ? true : false;
type A = IsString<"hello">; // true
type B = IsString<number>;  // false

// 6. Generic mapped type
type Readonly<T> = {
  readonly [K in keyof T]: T[K];
};

type Partial<T> = {
  [K in keyof T]?: T[K];
};

interface User { id: number; name: string }
type ReadonlyUser = Readonly<User>; // { readonly id: number; readonly name: string }

// ERROR: type alias tidak bisa extends
// type Animal<T> { } // Syntax error — bukan interface
```

**Kasus Penggunaan Nyata:** Utility types (Partial, Required, Pick, Record — built-in), API state management (loading/success/error state), error handling patterns, response wrapper types, form state types.
