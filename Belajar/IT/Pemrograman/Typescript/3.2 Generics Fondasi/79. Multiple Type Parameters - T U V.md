# 79. Multiple Type Parameters - T U V

**Definisi Singkat:** Multiple type parameters (biasanya dinotasikan T, U, V, dll.) memungkinkan generic yang melibatkan beberapa tipe independen, seperti fungsi yang menerima dua tipe berbeda dan mengembalikan kombinasi keduanya.

**Analogi:** Seperti mesin las yang menyambung dua logam berbeda (besi T dan tembaga U) menjadi satu objek baru (T & U) — input dua jenis, output satu hasil gabungan.

**Poin-Poin Penting:**
- Syntax: `<T, U, V>` — type parameters dipisah koma
- Tradisi: T = pertama, U = kedua, V = ketiga (tidak wajib, bisa nama deskriptif)
- Type inference bisa menyimpulkan masing-masing parameter dari argumen berbeda
- Bisa dikombinasikan dengan constraint per parameter

**Contoh Kode:**
```typescript
// BENAR: multiple type parameters untuk fleksibilitas maksimal

// 1. Pair/tuple generic
function createPair<T, U>(first: T, second: U): { first: T; second: U } {
  return { first, second };
}

const pair1 = createPair(1, "satu");     // T=number, U=string
const pair2 = createPair(true, [1, 2]);  // T=boolean, U=number[]

// 2. Merge dua objek
function merge<T, U>(obj1: T, obj2: U): T & U {
  return { ...obj1, ...obj2 };
}

const merged = merge(
  { name: "Budi", age: 25 },
  { role: "admin", permissions: ["read", "write"] }
);
// type: { name: string; age: number } & { role: string; permissions: string[] }

console.log(merged.name);  // OK
console.log(merged.role);  // OK

// 3. Transform array dengan mapper
function mapArray<T, U>(items: T[], mapper: (item: T) => U): U[] {
  return items.map(mapper);
}

const lengths = mapArray(["a", "bb", "ccc"], (s) => s.length);
// T=string, U=number, result: number[]

// 4. Generic dengan nama parameter deskriptif
function createResponse<TData, TMessage = string>(
  data: TData,
  message?: TMessage
): { data: TData; message?: TMessage } {
  return { data, message };
}

const res1 = createResponse({ id: 1 });  // TData = { id: number }
const res2 = createResponse("ok", 200);  // TData = string, TMessage = number

// 5. Multiple constraints
function combine<T extends object, U extends object>(a: T, b: U): T & U {
  return { ...a, ...b };
}

// ERROR: type parameter tidak bisa punya default di function
// function foo<T = string>(x: T) { } // OK di type/interface, tapi tidak di function
```

**Kasus Penggunaan Nyata:** Object.assign-style merge, event emitter (event name + payload type), Map<K,V>, Promise<T>, React useState<S>, API handler dengan request type dan response type yang berbeda.
