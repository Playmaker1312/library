# 76. Generic Interfaces

**Definisi Singkat:** Generic interface memungkinkan pendefinisian kontrak (bentuk) yang bisa digunakan dengan berbagai tipe data, seperti interface untuk repository, response API, atau koleksi data.

**Analogi:** Seperti colokan listrik universal — bentuk colokan (interface) sama, tapi tegangan (tipe) bisa berbeda-beda (220V di Indonesia, 110V di AS).

**Poin-Poin Penting:**
- `interface Nama<T> { ... }` — deklarasi interface dengan type parameter
- Bisa digunakan untuk function signatures, properti, method return types
- Bisa memiliki constraint dengan `extends`
- Multiple type parameters: `interface Nama<T, U, V>`

**Contoh Kode:**
```typescript
// BENAR: generic interface untuk berbagai kebutuhan

// 1. Generic interface untuk API response wrapper
interface ApiResponse<T> {
  success: boolean;
  data: T;
  message?: string;
  timestamp: Date;
}

// Implementasi dengan tipe berbeda
const userResponse: ApiResponse<{ id: number; name: string }> = {
  success: true,
  data: { id: 1, name: "Budi" },
  timestamp: new Date(),
};

const listResponse: ApiResponse<string[]> = {
  success: true,
  data: ["apple", "banana"],
  timestamp: new Date(),
};

// 2. Generic interface untuk repository pattern
interface Repository<T, ID = number> {
  findById(id: ID): Promise<T | null>;
  findAll(): Promise<T[]>;
  create(data: Omit<T, "id">): Promise<T>;
  update(id: ID, data: Partial<T>): Promise<T>;
  delete(id: ID): Promise<boolean>;
}

interface User {
  id: number;
  name: string;
  email: string;
}

class UserRepository implements Repository<User, number> {
  async findById(id: number): Promise<User | null> {
    // ... implementasi
    return null;
  }
  async findAll(): Promise<User[]> { return []; }
  async create(data: Omit<User, "id">): Promise<User> {
    return { id: 1, ...data };
  }
  async update(id: number, data: Partial<User>): Promise<User> {
    return { id, name: "", email: "" };
  }
  async delete(id: number): Promise<boolean> { return true; }
}

// 3. Generic interface untuk fungsi
interface Comparator<T> {
  (a: T, b: T): number;
}

const numberCompare: Comparator<number> = (a, b) => a - b;
const stringCompare: Comparator<string> = (a, b) => a.localeCompare(b);
```

**Kasus Penggunaan Nyata:** API response wrapper (standarisasi format response), repository pattern (CRUD generic), event emitter system, state management store, pagination result yang generic, serializers/deserializers.
