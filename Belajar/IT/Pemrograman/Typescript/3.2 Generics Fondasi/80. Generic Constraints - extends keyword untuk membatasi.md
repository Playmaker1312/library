# 80. Generic Constraints - extends keyword untuk membatasi

**Definisi Singkat:** Generic constraints menggunakan keyword `extends` untuk membatasi tipe apa yang bisa digunakan sebagai type parameter, memastikan generic hanya bekerja dengan tipe yang memiliki properti atau struktur tertentu.

**Analogi:** Seperti pintu otomatis di mal yang hanya terbuka untuk pengunjung yang membawa kartu anggota (memiliki `cardId`) — pengunjung tanpa kartu tidak bisa masuk.

**Poin-Poin Penting:**
- `function foo<T extends SomeType>(x: T)` — T harus memiliki minimal struktur SomeType
- Constraint bisa berupa interface, class, union type, atau tipe bawaan
- Memberi akses ke properti yang didefinisikan di constraint
- Error jika argumen tidak memenuhi constraint

**Contoh Kode:**
```typescript
// BENAR: generic constraints memastikan tipe memiliki properti tertentu

// 1. Constraint dengan properti length
interface HasLength {
  length: number;
}

function logLength<T extends HasLength>(item: T): T {
  console.log(`Panjang: ${item.length}`);
  return item;
}

logLength("hello");      // OK: string punya length
logLength([1, 2, 3]);    // OK: array punya length
logLength({ length: 5 }); // OK: objek dengan length
// logLength(123);        // ERROR: number tidak punya length

// 2. Constraint dengan properti spesifik
interface Identifiable {
  id: number | string;
}

function findById<T extends Identifiable>(items: T[], id: T["id"]): T | undefined {
  return items.find((item) => item.id === id);
}

const users = [
  { id: 1, name: "Budi" },
  { id: 2, name: "Siti" },
];
const user = findById(users, 1); // T = { id: number; name: string }

// 3. Constraint union untuk key type
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const person = { name: "Budi", age: 25, city: "Jakarta" };
const nama = getProperty(person, "name"); // type: string
const umur = getProperty(person, "age");  // type: number
// getProperty(person, "country");        // ERROR: 'country' not in keyof

// 4. Constraint dengan constructor (newable)
function createInstance<T>(ctor: new (...args: any[]) => T, ...args: any[]): T {
  return new ctor(...args);
}

class Product {
  constructor(public name: string, public price: number) {}
}

const phone = createInstance(Product, "Phone", 500); // type: Product

// ERROR: generic constraint dilanggar
// function processNumber<T extends number>(x: T): T {
//   return x * 2; // Error: operator '*' tidak dijamin untuk T extends number
// }
```

**Kasus Penggunaan Nyata:** API endpoint handlers yang membutuhkan request body dengan field tertentu, plugin system yang memvalidasi konfigurasi, ORM query dengan field lookup, generic validators yang membutuhkan properti spesifik.
