# 74. Mengapa butuh Generics - masalah yang dipecahkan

**Definisi Singkat:** Generics memecahkan masalah duplikasi kode dan kehilangan informasi tipe saat kita ingin membuat fungsi/class/interface yang bisa bekerja dengan berbagai tipe tanpa menggunakan `any`.

**Analogi:** Seperti mesin fotokopi yang bisa memfotokopi kertas ukuran apa pun (A4, A5, Letter) — tanpa generics, Anda harus punya mesin terpisah untuk setiap ukuran kertas.

**Poin-Poin Penting:**
- Tanpa generics: harus pakai `any` (kehilangan type safety) atau overloading (duplikasi)
- Generics mempertahankan informasi tipe spesifik tanpa mengorbankan reusability
- Compiler bisa melakukan type checking lebih akurat dengan type inference

**Contoh Kode:**
```typescript
// MASALAH: tanpa generics
// Solusi 1: any — kehilangan type safety
function identityAny(value: any): any {
  return value;
}
const result1 = identityAny("hello");
// result1.toUpperCase(); // OK saat runtime, tapi tidak ada autocomplete
// result1 is 'any' — tidak ada type checking

// Solusi 2: overload — duplikasi untuk setiap tipe
function identityStr(value: string): string { return value; }
function identityNum(value: number): number { return value; }
// ... harus buat untuk boolean, array, object, dll — tidak praktis

// SOLUSI: generics — type-safe + reusable
function identity<T>(value: T): T {
  return value;
}

const str = identity("hello");   // type: "hello" (string literal)
const num = identity(42);        // type: 42 (number literal)
const bool = identity(true);     // type: true (boolean literal)

str.toUpperCase(); // OK: TypeScript tahu ini string
// num.toUpperCase(); // ERROR: number tidak punya toUpperCase

// Masalah lain yang dipecahkan:
// Array generic tanpa any
function firstElement<T>(arr: T[]): T | undefined {
  return arr[0];
}

const first = firstElement([1, 2, 3]); // type: number | undefined
// first.toFixed(2); // OK (setelah narrow check)
```

**Kasus Penggunaan Nyata:** Library utility (Lodash, Ramda), collection/data structures (Array<T>, Map<K,V>), API response wrappers, state management (Redux store generic), database queries (Prisma client generics).
