# 81. Generic dengan keyof operator

**Definisi Singkat:** `keyof T` menghasilkan union type dari semua key properti di tipe T, dan ketika dikombinasikan dengan generic, memungkinkan akses properti objek secara type-safe dengan key yang diverifikasi.

**Analogi:** Seperti resep dokter yang hanya boleh mengambil obat yang ada di daftar apotek — `keyof` adalah daftar obat yang tersedia, Anda tidak bisa minta obat yang tidak terdaftar.

**Poin-Poin Penting:**
- `keyof T` = union literal keys dari T (`"id" | "name" | ...`)
- Kombinasi `<T, K extends keyof T>` = generic key yang terverifikasi
- `T[K]` = indexed access type — tipe dari properti K di T
- Berguna untuk safe getter, setter, pluck, pick, omit

**Contoh Kode:**
```typescript
// BENAR: generic + keyof untuk akses properti type-safe

// 1. Safe getter
function getValue<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const user = {
  id: 1,
  name: "Budi",
  age: 25,
  address: { city: "Jakarta", street: "Merdeka" },
};

const id = getValue(user, "id");       // type: number
const name = getValue(user, "name");   // type: string
const addr = getValue(user, "address"); // type: { city: string; street: string }
// getValue(user, "country");           // ERROR: 'country' not in keyof

// 2. Pluck — mengambil array properti tertentu
function pluck<T, K extends keyof T>(items: T[], key: K): T[K][] {
  return items.map((item) => item[key]);
}

const users = [
  { id: 1, name: "Budi", age: 25 },
  { id: 2, name: "Siti", age: 30 },
  { id: 3, name: "Ali", age: 28 },
];

const names = pluck(users, "name"); // type: string[] → ["Budi", "Siti", "Ali"]
const ages = pluck(users, "age");   // type: number[] → [25, 30, 28]

// 3. Setter dengan validasi tipe
function setValue<T, K extends keyof T>(obj: T, key: K, value: T[K]): void {
  obj[key] = value;
}

setValue(user, "name", "Budi Baru"); // OK: value adalah string
setValue(user, "age", 26);           // OK: value adalah number
// setValue(user, "name", 123);      // ERROR: number tidak assignable ke string

// 4. Type-safe event system
interface Events {
  click: { x: number; y: number };
  focus: { target: string };
  keydown: { key: string; ctrlKey: boolean };
}

function emit<K extends keyof Events>(event: K, payload: Events[K]): void {
  console.log(`Event ${event}:`, payload);
}

emit("click", { x: 10, y: 20 });       // OK
emit("keydown", { key: "Enter", ctrlKey: false }); // OK
// emit("click", { key: "Enter" });     // ERROR: payload tidak cocok
```

**Kasus Penggunaan Nyata:** Form validation (mengubah nilai field tertentu), state management (type-safe setter), event systems, data transformation (pick/pluck dari dataset), ORM query builder (select field tertentu).
