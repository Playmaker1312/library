# 84. Contoh praktis Generic Repository Pattern

**Definisi Singkat:** Generic Repository Pattern menggunakan TypeScript generics untuk membuat base repository yang bisa digunakan untuk berbagai entitas database, mengurangi duplikasi kode CRUD untuk setiap model.

**Analogi:** Seperti toko serba ada (convenience store) — layout-nya sama untuk semua cabang, hanya isi raknya (tipe barang) yang berbeda. Manajer toko tidak perlu mendesain ulang tata letak untuk setiap jenis toko.

**Poin-Poin Penting:**
- Generic interface `Repository<T, ID>` mendefinisikan kontrak CRUD
- Base class `BaseRepository<T>` mengimplementasi logika umum
- Setiap entitas membuat repository sendiri yang extends base
- Type safety terjamin — tipe data entitas dan ID diverifikasi

**Contoh Kode:**
```typescript
// BENAR: Generic Repository Pattern implementasi nyata

// 1. Entity definitions
interface BaseEntity {
  id: number;
  createdAt: Date;
  updatedAt: Date;
}

interface User extends BaseEntity {
  name: string;
  email: string;
  age: number;
}

interface Product extends BaseEntity {
  name: string;
  price: number;
  stock: number;
}

// 2. Generic Repository Interface
interface IRepository<T, ID = number> {
  findById(id: ID): Promise<T | null>;
  findAll(filter?: Partial<T>): Promise<T[]>;
  create(data: Omit<T, keyof BaseEntity>): Promise<T>;
  update(id: ID, data: Partial<Omit<T, keyof BaseEntity>>): Promise<T>;
  delete(id: ID): Promise<boolean>;
  count(): Promise<number>;
}

// 3. Generic Base Repository (implementasi in-memory)
class BaseRepository<T extends BaseEntity> implements IRepository<T> {
  protected entities: Map<number, T> = new Map();
  private nextId: number = 1;

  async findById(id: number): Promise<T | null> {
    return this.entities.get(id) ?? null;
  }

  async findAll(filter?: Partial<T>): Promise<T[]> {
    let result = Array.from(this.entities.values());
    if (filter) {
      result = result.filter((entity) =>
        Object.entries(filter).every(
          ([key, value]) => entity[key as keyof T] === value
        )
      );
    }
    return result;
  }

  async create(data: Omit<T, keyof BaseEntity>): Promise<T> {
    const now = new Date();
    const entity = {
      ...data,
      id: this.nextId++,
      createdAt: now,
      updatedAt: now,
    } as unknown as T;
    this.entities.set(entity.id, entity);
    return entity;
  }

  async update(id: number, data: Partial<Omit<T, keyof BaseEntity>>): Promise<T> {
    const existing = this.entities.get(id);
    if (!existing) throw new Error(`Entity ${id} not found`);
    const updated = {
      ...existing,
      ...data,
      updatedAt: new Date(),
    };
    this.entities.set(id, updated);
    return updated;
  }

  async delete(id: number): Promise<boolean> {
    return this.entities.delete(id);
  }

  async count(): Promise<number> {
    return this.entities.size;
  }
}

// 4. Concrete repositories
class UserRepository extends BaseRepository<User> {
  async findByEmail(email: string): Promise<User | null> {
    const users = await this.findAll();
    return users.find((u) => u.email === email) ?? null;
  }
}

class ProductRepository extends BaseRepository<Product> {
  async findByPriceRange(min: number, max: number): Promise<Product[]> {
    const products = await this.findAll();
    return products.filter((p) => p.price >= min && p.price <= max);
  }
}

// 5. Penggunaan
async function main() {
  const userRepo = new UserRepository();
  const productRepo = new ProductRepository();

  const user = await userRepo.create({
    name: "Budi",
    email: "budi@email.com",
    age: 25,
  });
  console.log(user.id); // 1 (auto-increment)

  const products = await productRepo.create({
    name: "Laptop",
    price: 15000000,
    stock: 10,
  });

  const foundUser = await userRepo.findByEmail("budi@email.com");
  console.log(foundUser?.name); // "Budi"

  const cheap = await productRepo.findByPriceRange(10000, 500000);
}
```

**Kasus Penggunaan Nyata:** Backend NestJS/Express dengan database PostgreSQL/MongoDB, service layer dengan pattern repository, unit testing (mudah mock repository), konsistensi akses data antar modul, migrasi database dengan perubahan minimal di kode.
