# 85. User-Defined Type Guards - is keyword

**Definisi Singkat:** User-defined type guard adalah fungsi yang mengembalikan `boolean` dengan tipe return berupa type predicate (`param is Type`), memberi tahu TypeScript untuk mempersempit tipe di cabang tertentu.

**Analogi:** Seperti petugas keamanan di bandara yang memeriksa paspor — setelah diperiksa, petugas memberi stempel (type guard) yang mengonfirmasi status penumpang (WNA/WNI), dan sistem bandara memperlakukan mereka sesuai status tersebut.

**Poin-Poin Penting:**
- Return type: `parameterName is TargetType` — bukan `boolean` biasa
- TypeScript akan narrow type di blok `if` (true) dan `else` (false)
- Hanya bisa untuk satu parameter fungsi (biasanya parameter pertama)
- Berguna untuk membedakan union types di runtime

**Contoh Kode:**
```typescript
// BENAR: type guard dengan is keyword

// 1. Basic type guard untuk union type
interface Dog {
  type: "dog";
  breed: string;
  bark(): string;
}

interface Cat {
  type: "cat";
  color: string;
  meow(): string;
}

type Pet = Dog | Cat;

// Type guard function
function isDog(pet: Pet): pet is Dog {
  return pet.type === "dog";
}

function isCat(pet: Pet): pet is Cat {
  return pet.type === "cat";
}

function getPetSound(pet: Pet): string {
  if (isDog(pet)) {
    // Di sini TypeScript tahu pet adalah Dog
    return pet.bark(); // OK: method spesifik Dog
  }
  if (isCat(pet)) {
    return pet.meow(); // OK: method spesifik Cat
  }
  return "unknown";
}

// 2. Type guard untuk tipe primitif
function isString(value: unknown): value is string {
  return typeof value === "string";
}

function isNumber(value: unknown): value is number {
  return typeof value === "number" && !isNaN(value);
}

function processValue(value: unknown): string {
  if (isString(value)) {
    return `Panjang string: ${value.length}`; // value: string
  }
  if (isNumber(value)) {
    return `Angka: ${value.toFixed(2)}`; // value: number
  }
  return "Unknown";
}

// 3. Type guard dengan properti spesifik
interface HasEmail {
  email: string;
  sendEmail(body: string): void;
}

function hasEmail(obj: any): obj is HasEmail {
  return typeof obj.email === "string" && typeof obj.sendEmail === "function";
}

// ERROR: return type harus type predicate
// function isStringBad(x: unknown): boolean {
//   return typeof x === "string";
// }
// // TypeScript TIDAK narrow type meskipun return true
```

**Kasus Penggunaan Nyata:** Discriminated union processing (event types, action types di Redux, message types di WebSocket), validation function yang mengubah tipe setelah validasi, API response handler (success vs error), form field type differentiation.
