# 87. Const Assertions - as const mendalam

**Definisi Singkat:** `as const` adalah assertion yang memberi tahu TypeScript untuk memperlakukan nilai sebagai literal type yang paling spesifik dan readonly — mencegah widening dan membuat seluruh objek/array immutable di level tipe.

**Analogi:** Seperti ukiran di batu — sekali ditulis, tidak bisa diubah. Berbeda dengan tulisan pensil di kertas (let) yang bisa dihapus atau spidol di whiteboard (const biasa) yang masih bisa ditimpa.

**Poin-Poin Penting:**
- `as const` pada literal: tipe menjadi literal value (`"hello"` bukan `string`)
- `as const` pada array: menjadi `readonly tuple` bukan `array`
- `as const` pada objek: semua properti menjadi `readonly` dan literal
- Mencegah type widening — berguna untuk konstanta, enum pattern, configuration

**Contoh Kode:**
```typescript
// BENAR: as const untuk tipe literal dan readonly

// 1. Tanpa as const — widening
let normalColor = "red";
// type: string (bisa diubah jadi string lain)

// Dengan as const — literal type
const color = "red" as const;
// type: "red" (hanya bisa "red")

// 2. Array tanpa as const
const normalRoles = ["admin", "user", "guest"];
// type: string[] (bisa push string apapun)

const roles = ["admin", "user", "guest"] as const;
// type: readonly ["admin", "user", "guest"]
// roles.push("superadmin"); // ERROR: readonly

// 3. Objek dengan as const
const config = {
  apiUrl: "https://api.example.com",
  timeout: 5000,
  retries: 3,
} as const;
/* type:
{
  readonly apiUrl: "https://api.example.com";
  readonly timeout: 5000;
  readonly retries: 3;
}
*/
// config.timeout = 6000; // ERROR: readonly

// 4. Enum pattern dengan as const
const Direction = {
  UP: "UP",
  DOWN: "DOWN",
  LEFT: "LEFT",
  RIGHT: "RIGHT",
} as const;

type Direction = (typeof Direction)[keyof typeof Direction];
// type Direction = "UP" | "DOWN" | "LEFT" | "RIGHT"

function move(direction: Direction): void {
  console.log(`Bergerak ke ${direction}`);
}

move(Direction.UP); // OK
// move("DIAGONAL"); // ERROR: not in Direction

// 5. as const untuk exhaustive switch
const Status = {
  IDLE: "idle",
  LOADING: "loading",
  SUCCESS: "success",
  ERROR: "error",
} as const;

type Status = (typeof Status)[keyof typeof Status];

function handleStatus(status: Status): string {
  switch (status) {
    case Status.IDLE: return "Menunggu...";
    case Status.LOADING: return "Memuat...";
    case Status.SUCCESS: return "Berhasil!";
    case Status.ERROR: return "Gagal!";
    default:
      const exhaustive: never = status;
      return exhaustive;
  }
}
```

**Kasus Penggunaan Nyata:** Konfigurasi aplikasi yang immutable, Enum pattern tanpa `enum` keyword, action types Redux/Zustand, constant objects untuk mapping/lookup, route definitions,HTTP status code constants, i18n key types.
