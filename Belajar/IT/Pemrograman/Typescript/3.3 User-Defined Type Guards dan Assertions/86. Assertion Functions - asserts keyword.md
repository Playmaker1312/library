# 86. Assertion Functions - asserts keyword

**Definisi Singkat:** Assertion functions menggunakan keyword `asserts` untuk menegaskan bahwa suatu kondisi harus terpenuhi — jika tidak, function akan throw error; jika lolos, TypeScript mempersempit tipe setelah pemanggilan.

**Analogi:** Seperti satpam yang memeriksa KTP di pintu masuk gedung — jika KTP tidak valid (tidak sesuai asserts), satpam menolak masuk (throw error). Jika lolos, Anda dianggap terverifikasi (type narrowed).

**Poin-Poin Penting:**
- `asserts condition` — function harus memastikan kondisi truthy
- `asserts param is Type` — menegaskan bahwa param memiliki tipe tertentu
- Function harus throw jika kondisi tidak terpenuhi (tidak boleh return normal)
- Berbeda dengan type guard: tidak mengembalikan boolean, melempar error

**Contoh Kode:**
```typescript
// BENAR: assertion function dengan asserts keyword

// 1. Assertion kondisi sederhana
function assertNonNull<T>(value: T): asserts value is NonNullable<T> {
  if (value === null || value === undefined) {
    throw new Error("Nilai tidak boleh null atau undefined");
  }
}

function greet(name: string | null): string {
  assertNonNull(name); // Setelah ini, name dipersempit ke string
  return `Halo, ${name.toUpperCase()}!`; // OK: name adalah string
}

// 2. Assertion dengan type predicate
interface User {
  id: number;
  name: string;
  email: string;
}

function assertIsUser(obj: any): asserts obj is User {
  if (typeof obj !== "object" || obj === null) {
    throw new Error("Bukan objek");
  }
  if (typeof obj.id !== "number") {
    throw new Error("id harus number");
  }
  if (typeof obj.name !== "string") {
    throw new Error("name harus string");
  }
  if (typeof obj.email !== "string") {
    throw new Error("email harus string");
  }
}

function processUser(data: unknown): void {
  assertIsUser(data); // Setelah ini, data adalah User
  console.log(data.name.toUpperCase()); // OK
  console.log(data.email.toLowerCase()); // OK
}

// 3. Assertion dalam class method
class StringBuffer {
  private buffer: string | null = null;

  init(): asserts this is { buffer: string } {
    if (this.buffer === null) {
      this.buffer = "";
    }
  }

  append(text: string): void {
    this.init(); // Setelah ini, this.buffer pasti string
    this.buffer += text; // OK
  }

  getValue(): string {
    this.init();
    return this.buffer; // OK
  }
}

// 4. Assertion dengan custom error
function assertExists<T>(
  value: T | null | undefined,
  message: string = "Value required"
): asserts value is T {
  if (value == null) {
    throw new Error(message);
  }
}
```

**Kasus Penggunaan Nyata:** Validasi input API (request body validation), form validation sebelum processing, deserialization JSON yang aman, dependency injection container assertion, environment variable checking, configuration validation startup.
