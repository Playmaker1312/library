# 88. Satisfies Operator TS 4.9+ - validasi tanpa widening

**Definisi Singkat:** Operator `satisfies` (TS 4.9+) memvalidasi bahwa tipe suatu expression cocok dengan suatu tipe tanpa mengubah tipe inferred-nya — menjaga literal type sambil memastikan strukturnya sesuai.

**Analogi:** Seperti stiker "LULUS QC" (Quality Control) di produk elektronik — produk tetap memiliki spesifikasi aslinya (warna, model), tetapi sudah diverifikasi memenuhi standar kualitas tertentu.

**Poin-Poin Penting:**
- Syntax: `expression satisfies Type` — validasi tanpa widening
- Tidak seperti `: Type` yang melebarkan tipe, `satisfies` mempertahankan tipe inferred
- Error jika expression tidak memenuhi constraint Type
- Berguna untuk memvalidasi objek kompleks sambil menjaga literal types

**Contoh Kode:**
```typescript
// BENAR: satisfies memvalidasi tanpa widening

// 1. Tanpa satisfies — widening mengubah tipe
const rgb: Record<string, string> = {
  red: "#ff0000",
  green: "#00ff00",
  blue: "#0000ff",
};
// rgb.red adalah string (bukan literal "#ff0000")

// Dengan satisfies — validasi + mempertahankan literal
const palette = {
  red: "#ff0000",
  green: "#00ff00",
  blue: "#0000ff",
} satisfies Record<string, string>;
// palette.red tetap "#ff0000" (literal), bukan string

// 2. Validasi bentuk objek
type Point2D = { x: number; y: number };

const point = {
  x: 10,
  y: 20,
  // z: 30, // ERROR: 'z' not in Point2D
} satisfies Point2D;
// point.x adalah 10 (literal number), bukan number

// 3. Validasi tuple dengan satisfies
const coordinates = [10, 20] satisfies [number, number];
// coordinates[0] adalah 10 (literal), bukan number
// coordinates.push(30); // Masih array, tapi tipe diinfer sebagai tuple

// 4. Kombinasi dengan as const
const theme = {
  primary: "#1a1a2e",
  secondary: "#16213e",
  accent: "#0f3460",
  colors: ["red", "green", "blue"] as const,
} satisfies {
  primary: string;
  secondary: string;
  accent: string;
  colors: readonly string[];
};
// theme.primary tetap literal "#1a1a2e"
// theme.colors[0] tetap "red" (literal)

// 5. Memvalidasi method signatures
const mathOperations = {
  double: (x: number) => x * 2,
  square: (x: number) => x * x,
} satisfies Record<string, (x: number) => number>;

const result = mathOperations.double(5); // type: number

// ERROR: tipe tidak memenuhi constraint
// const invalid = { x: "bukan angka" } satisfies Point2D;
// Error: 'string' is not assignable to 'number'
```

**Kasus Penggunaan Nyata:** Theme/styling configuration dengan literal color values, API endpoint definitions, route parameters dengan literal types, mapping objects dengan validasi struktur tanpa kehilangan literal, event handler registrations.
