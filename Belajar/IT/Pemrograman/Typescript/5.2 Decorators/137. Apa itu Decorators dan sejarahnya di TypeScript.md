# 137. Apa itu Decorators dan sejarahnya di TypeScript

**Definisi Singkat:** Decorators adalah fungsi khusus yang memungkinkan Anda memodifikasi class, method, properti, atau parameter. Mereka adalah fitur eksperimental di TypeScript yang terinspirasi dari Python dan AtScript (Angular).

**Analogi:** Seperti stiker yang Anda tempel di laptop — stiker tersebut mengubah tampilan (perilaku) tanpa mengubah laptop itu sendiri.

**Poin-Poin Penting:**
- Decorators menggunakan sintaks `@expression` sebelum deklarasi
- Pertama kali diperkenalkan di TypeScript 1.5 (2015)
- Awalnya berbasis Stage 1 proposal TC39
- TypeScript 5.0+ mendukung Stage 3 decorators resmi

**Contoh Kode:**
```typescript
// Decorator sederhana
function sealed(target: any) {
  Object.seal(target);
}

@sealed
class MyClass {
  method() {}
}

// BENAR: decorator diterapkan
const obj = new MyClass();
console.log(Object.isSealed(obj)); // true

// ERROR: decorator harus function
@123
class BadClass {} // ❌
```

**Kasus Penggunaan Nyata:** Angular, NestJS, dan banyak framework menggunakan decorators sebagai fondasi arsitektur mereka.
