# 139. Class Decorators

**Definisi Singkat:** Class decorators diterapkan pada deklarasi class dan dapat memodifikasi atau mengganti konstruktor class. Dideklarasikan tepat sebelum deklarasi class dengan `@expression`.

**Analogi:** Seperti kerangka mobil yang dimodifikasi di pabrik — Anda bisa mengubah struktur dasarnya sebelum mobil itu digunakan.

**Poin-Poin Penting:**
- Menerima satu argumen: konstruktor target
- Bisa memodifikasi prototype atau mengganti konstruktor
- Tidak bisa digunakan dengan `declare` class
- Nilai returnnya akan menggantikan class asli

**Contoh Kode:**
```typescript
function sealed(constructor: Function) {
  Object.seal(constructor);
  Object.seal(constructor.prototype);
}

@sealed
class Animal {
  constructor(public name: string) {}
}

// BENAR: class menjadi sealed
const dog = new Animal('Dog');
console.log(Object.isSealed(Animal)); // true

// ERROR: decorator class tidak menerima argumen tambahan
@sealed('extra')
class BadAnimal {} // ❌
```

**Kasus Penggunaan Nyata:** Implementasi pola Singleton, registrasi class ke dependency injection container, atau menambahkan metadata.
