# 143. Accessor Decorators

**Definisi Singkat:** Accessor decorators diterapkan pada getter atau setter (accessor) dari properti class dan dapat memodifikasi perilaku akses properti tersebut.

**Analogi:** Seperti resepsionis yang mencatat setiap kali seseorang masuk atau keluar gedung — getter/setter tetap berfungsi, tapi dengan pengawasan tambahan.

**Poin-Poin Penting:**
- Menerima tiga argumen: target, propertyKey, descriptor
- Diterapkan pada getter atau setter, bukan keduanya (dekorasi pertama yang berlaku)
- Hanya bisa diterapkan pada accessor (get/set)
- Dapat memodifikasi getter/setter untuk validasi atau logging

**Contoh Kode:**
```typescript
function configurable(value: boolean) {
  return function(target: any, key: string, desc: PropertyDescriptor) {
    desc.configurable = value;
  };
}

class Point {
  private _x: number;

  constructor(x: number) {
    this._x = x;
  }

  @configurable(false)
  get x(): number {
    return this._x;
  }
}

// BENAR: accessor menjadi non-configurable
const p = new Point(5);
console.log(p.x); // 5

// ERROR: accessor decorator tidak bisa di properti biasa (non-accessor)
```

**Kasus Penggunaan Nyata:** Mengontrol konfigurabilitas properti, menerapkan lazy loading, atau memvalidasi nilai saat diakses.
