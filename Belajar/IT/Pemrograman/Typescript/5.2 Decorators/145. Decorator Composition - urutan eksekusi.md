# 145. Decorator Composition - urutan eksekusi

**Definisi Singkat:** Decorator composition adalah penerapan beberapa decorator pada satu target. Urutan eksekusi memiliki aturan spesifik: dekorator dieksekusi dari bawah ke atas (bottom-up) untuk fungsi, dan dari kanan ke kiri.

**Analogi:** Seperti memasang lapisan baju — jaket (decorator terluar) dikenakan terakhir tapi terlihat pertama. Saat melepas, jaket dilepas duluan.

**Poin-Poin Penting:**
- Untuk method/property: evaluasi dari bawah ke atas, eksekusi dari atas ke bawah
- Untuk class: evaluasi dari dalam ke luar
- Urutan parameter: dari kiri ke kanan
- Class decorators dijalankan setelah semua member decorators

**Contoh Kode:**
```typescript
function first() {
  console.log('first factory');
  return () => console.log('first apply');
}

function second() {
  console.log('second factory');
  return () => console.log('second apply');
}

class Example {
  @first()
  @second()
  method() {}
}

// OUTPUT:
// first factory
// second factory
// second apply
// first apply

// BENAR: urutan sesuai aturan composition

// ERROR: decorator composition tidak mempengaruhi logika
```

**Kasus Penggunaan Nyata:** Mengkombinasikan multiple concerns seperti `@Log` + `@Cache` + `@Validate` pada satu method.
