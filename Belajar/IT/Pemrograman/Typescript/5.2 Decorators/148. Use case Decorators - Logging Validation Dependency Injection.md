# 148. Use case Decorators - Logging Validation Dependency Injection

**Definisi Singkat:** Decorators memiliki tiga use case utama: logging (mencatat eksekusi), validation (memvalidasi input/output), dan dependency injection (menyediakan dependensi otomatis).

**Analogi:** Seperti tiga fitur di pabrik: CCTV (logging) merekam semua aktivitas, quality control (validation) memeriksa produk, dan jalur konveyor (DI) mengirim bahan ke tempat yang tepat.

**Poin-Poin Penting:**
- Logging: mencatat waktu, argumen, dan hasil method
- Validation: memeriksa tipe atau nilai parameter
- Dependency Injection: framework menggunakan metadata decorators
- Semua bisa dikombinasikan dengan decorator composition

**Contoh Kode:**
```typescript
// LOGGING
function logMethod(target: any, key: string, desc: PropertyDescriptor) {
  const orig = desc.value;
  desc.value = function(...args: any[]) {
    console.log(`${key} dipanggil dengan:`, args);
    return orig.apply(this, args);
  };
}

// VALIDATION
function validate(target: any, key: string, index: number) {
  const existing = Reflect.getOwnMetadata('validators', target) || [];
  existing.push({ key, index });
  Reflect.defineMetadata('validators', existing, target);
}

// PENGGUNAAN
class UserService {
  @logMethod
  createUser(name: string, @validate email: string) {
    return { name, email };
  }
}

// BENAR: decorators meningkatkan fungsionalitas
const svc = new UserService();
svc.createUser('Alice', 'alice@test.com');
// Console: createUser dipanggil dengan: ['Alice', 'alice@test.com']
```

**Kasus Penggunaan Nyata:** NestJS decorators (`@Controller`, `@Get`, `@Inject`), Angular decorators (`@Component`, `@Injectable`), TypeORM (`@Entity`, `@Column`).
