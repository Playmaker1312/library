# 144. Decorator Factories - decorator dengan argumen

**Definisi Singkat:** Decorator factories adalah fungsi yang mengembalikan fungsi decorator, memungkinkan decorator menerima argumen kustom.

**Analogi:** Seperti mesin pesanan kustom — Anda memberi spesifikasi (argumen), dan mesin menghasilkan stiker (decorator) yang sesuai dengan keinginan Anda.

**Poin-Poin Penting:**
- Fungsi di luar yang menerima argumen, return function decorator
- Memungkinkan konfigurasi decorator per penggunaan
- Pola umum: `@decorator(args)` bukan `@decorator`
- Digunakan di hampir semua framework (Angular, NestJS, TypeORM)

**Contoh Kode:**
```typescript
function log(label: string) {
  return function(target: any, key: string, desc: PropertyDescriptor) {
    const original = desc.value;
    desc.value = function(...args: any[]) {
      console.log(`[${label}] Calling ${key}`);
      return original.apply(this, args);
    };
  };
}

class Service {
  @log('SERVICE')
  doSomething() {
    return 'done';
  }
}

// BENAR: decorator factory dengan argumen
const svc = new Service();
svc.doSomething(); // [SERVICE] Calling doSomething

// ERROR: decorator factory tanpa kurung akan jadi decorator biasa
@log
class A {} // ❌ log bukan decorator, tapi factory
```

**Kasus Penggunaan Nyata:** Membuat decorator yang dapat dikonfigurasi seperti `@Route('/api')`, `@Validate({ required: true })`, atau `@Log('INFO')`.
