# 140. Method Decorators

**Definisi Singkat:** Method decorators diterapkan pada method sebuah class dan dapat memodifikasi perilaku method tersebut, seperti logging, caching, atau validasi.

**Analogi:** Seperti sekuriti yang memeriksa dan mencatat setiap orang yang melewati pintu — Anda tetap masuk, tapi ada proses tambahan.

**Poin-Poin Penting:**
- Menerima tiga argumen: target, propertyKey, descriptor
- Dapat memodifikasi PropertyDescriptor method
- Berguna untuk AOP (Aspect Oriented Programming)

**Contoh Kode:**
```typescript
function log(target: any, key: string, desc: PropertyDescriptor) {
  const original = desc.value;
  desc.value = function(...args: any[]) {
    console.log(`Calling ${key} with`, args);
    return original.apply(this, args);
  };
}

class Calculator {
  @log
  add(a: number, b: number): number {
    return a + b;
  }
}

// BENAR: method akan logging otomatis
const calc = new Calculator();
calc.add(2, 3); // Console: Calling add with [2, 3]

// ERROR: method decorator tidak bisa di async arrow function class
```

**Kasus Penggunaan Nyata:** Logging otomatis, timing eksekusi, validasi parameter, atau caching hasil method.
