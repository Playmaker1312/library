# 146. Stage 3 Decorators TC39 TS 5.0+

**Definisi Singkat:** Stage 3 Decorators adalah proposal resmi ECMAScript yang mencapai Stage 3 dan diimplementasikan di TypeScript 5.0+. Tidak memerlukan flag `experimentalDecorators`.

**Analogi:** Seperti fitur yang sudah lulus uji kelayakan dan siap dipakai di jalan raya — bukan lagi prototipe eksperimental.

**Poin-Poin Penting:**
- Menggunakan API yang berbeda dari legacy decorators
- Tidak memerlukan `experimentalDecorators: true`
- Context object menggantikan parameter individual
- Fungsi decorator mengembalikan fungsi baru, bukan memodifikasi descriptor

**Contoh Kode:**
```typescript
// Stage 3 decorator (TS 5.0+)
function logged<T extends (...args: any[]) => any>(
  target: T,
  context: ClassMethodDecoratorContext
) {
  return function(this: any, ...args: Parameters<T>) {
    console.log(`called ${String(context.name)}`);
    return target.call(this, ...args);
  };
}

class MyClass {
  @logged
  greet(name: string) {
    return `Hello ${name}`;
  }
}

// BENAR: Stage 3 decorator tanpa experimental flag
const c = new MyClass();
c.greet('World'); // called greet

// ERROR: context berbeda dengan legacy decorator
```

**Kasus Penggunaan Nyata:** Masa depan decorators di JavaScript — semua implementasi baru sebaiknya menggunakan Stage 3 API.
