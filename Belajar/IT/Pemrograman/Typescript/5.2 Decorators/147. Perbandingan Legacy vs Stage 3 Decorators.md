# 147. Perbandingan Legacy vs Stage 3 Decorators

**Definisi Singkat:** Legacy decorators (experimental) dan Stage 3 decorators memiliki perbedaan signifikan dalam hal API, cara kerja, dan dukungan tooling.

**Analogi:** Seperti mesin tik vs komputer — keduanya menulis dokumen, tapi cara kerja, kemampuan, dan ekosistemnya sangat berbeda.

**Poin-Poin Penting:**
- Legacy memodifikasi descriptor, Stage 3 menggunakan context object
- Legacy memerlukan `experimentalDecorators`, Stage 3 tidak
- Stage 3 hanya mendukung class, method, field, accessor (tidak parameter)
- Legacy bisa mengubah nilai return, Stage 3 tidak bisa untuk field
- Stage 3 lebih aman dan terintegrasi dengan JavaScript masa depan

**Contoh Kode:**
```typescript
// LEGACY (experimental)
function legacyLog(target: any, key: string, desc: PropertyDescriptor) {
  const orig = desc.value;
  desc.value = (...args: any[]) => {
    console.log(`Legacy: ${key}`);
    return orig(...args);
  };
}

// STAGE 3 (TS 5.0+)
function stage3Log<T extends (...args: any[]) => any>(
  target: T,
  context: ClassMethodDecoratorContext
) {
  return function(this: any, ...args: Parameters<T>) {
    console.log(`Stage 3: ${String(context.name)}`);
    return target.call(this, ...args);
  };
}

// ERROR: Stage 3 tidak bisa decorator parameter
function paramDec(target: any, context: ClassMethodDecoratorContext) {}
// ❌ Stage 3 tidak support parameter decorator
```

**Kasus Penggunaan Nyata:** Memilih API decorator yang tepat sangat penting untuk kompatibilitas dengan framework (Angular masih menggunakan legacy, sementara proyek baru bisa beralih ke Stage 3).
