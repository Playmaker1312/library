# 142. Parameter Decorators

**Definisi Singkat:** Parameter decorators diterapkan pada parameter function atau method dan biasanya digunakan untuk menangkap metadata parameter, seperti informasi dependency injection.

**Analogi:** Seperti catatan tempel pada masing-masing bahan masakan — memberi tahu juru masak (framework) bagaimana bahan itu harus digunakan.

**Poin-Poin Penting:**
- Menerima tiga argumen: target, propertyKey, parameterIndex
- Tidak bisa memodifikasi parameter secara langsung
- Hanya mencatat metadata untuk digunakan oleh decorator lain
- Sering digunakan bersama class/method decorators

**Contoh Kode:**
```typescript
import 'reflect-metadata';

function inject(serviceIdentifier: string) {
  return function(target: any, key: string, index: number) {
    Reflect.defineMetadata(`param:${key}:${index}`, serviceIdentifier, target);
  };
}

class Service {
  handle(@inject('Logger') logger: any) {
    logger.log('Hello');
  }
}

// BENAR: parameter decorator mencatat metadata
// (metadata bisa dibaca oleh framework DI)

// ERROR: parameter decorator tidak bisa mengubah nilai parameter
```

**Kasus Penggunaan Nyata:** Dependency injection di Angular (`@Inject()`) dan NestJS, atau validasi parameter otomatis.
