# 138. Mengaktifkan experimentalDecorators

**Definisi Singkat:** Untuk menggunakan decorators gaya lama (legacy), Anda perlu mengaktifkan opsi `experimentalDecorators: true` di tsconfig.json karena decorators masih dalam tahap eksperimental.

**Analogi:** Seperti fitur "beta" di aplikasi — Anda harus secara sukarela mengaktifkannya di pengaturan karena belum sepenuhnya stabil.

**Poin-Poin Penting:**
- Diatur di `compilerOptions.experimentalDecorators`
- Juga perlu `emitDecoratorMetadata: true` untuk metadata (Angular/NestJS)
- TypeScript 5.0+ tidak memerlukan ini untuk Stage 3 decorators
- Legacy decorators masih didukung untuk backward compatibility

**Contoh Kode:**
```json
// tsconfig.json
{
  "compilerOptions": {
    "experimentalDecorators": true,
    "emitDecoratorMetadata": true
  }
}
```

```typescript
// BENAR: decorators berfungsi dengan flag
function log(target: any, key: string) {
  console.log(`Method: ${key}`);
}

class Service {
  @log
  handle() {}
}

// ERROR: tanpa experimentalDecorators, akan error
// "Decorators are not valid here"
```

**Kasus Penggunaan Nyata:** Diperlukan untuk proyek Angular, NestJS, TypeORM, atau library lain yang menggunakan legacy decorators.
