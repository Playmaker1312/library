# 141. Property Decorators

**Definisi Singkat:** Property decorators diterapkan pada properti sebuah class dan dapat memodifikasi atau mengobservasi properti tersebut, meskipun tidak bisa langsung mengubah nilai.

**Analogi:** Seperti label harga di barang — Anda melihat informasinya, dan bisa mengubah bagaimana label itu ditampilkan, meskipun tidak langsung mengubah produknya.

**Poin-Poin Penting:**
- Menerima dua argumen: target dan propertyKey
- Tidak menerima PropertyDescriptor (tidak seperti method decorator)
- Sering digunakan bersama library validasi atau serialisasi
- Dapat mengembalikan PropertyDescriptor (khusus legacy)

**Contoh Kode:**
```typescript
function readonly(target: any, key: string) {
  Object.defineProperty(target, key, {
    writable: false
  });
}

class Person {
  @readonly
  name: string = 'Alice';
}

// BENAR: properti menjadi read-only
const p = new Person();
// p.name = 'Bob'; // Error (strict mode)

// ERROR: property decorator tidak bisa memodifikasi nilai
function setValue(target: any, key: string) {
  target[key] = 'forced'; // tidak bekerja seperti yang diharapkan
}
```

**Kasus Penggunaan Nyata:** Validasi properti (seperti `@Required`, `@MinLength`), serialisasi (JSON ignore), dan integrasi ORM.
