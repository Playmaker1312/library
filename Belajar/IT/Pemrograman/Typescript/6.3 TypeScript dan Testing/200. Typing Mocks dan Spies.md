# 200. Typing Mocks dan Spies

**Definisi Singkat:** Cara mendefinisikan tipe untuk mock functions dan spies di TypeScript, memastikan mock dipanggil dengan argumen yang benar dan mengembalikan nilai dengan tipe yang sesuai.

**Analogi:** Seperti stunt double di film - mock adalah pengganti asli yang harus bertingkah sama (memiliki interface yang sama) agar adegan berjalan lancar, tapi tanpa resiko yang sebenarnya.

**Poin-Poin Penting:**
- `jest.Mock<ReturnType, Args>` atau `vi.Mock` untuk tipe mock
- `jest.MockedFunction<T>` untuk meng-cast fungsi menjadi mock
- `jest.Mocked<Class>` untuk mock class
- Spies mempertahankan tipe fungsi asli
- `mockReturnValue`, `mockResolvedValue` memiliki tipe parameter

**Contoh Kode:**
```typescript
import { describe, it, expect, vi, jest } from 'vitest';  // atau jest

// Interface untuk dependency
interface UserRepository {
  findById(id: string): Promise<User | null>;
  findAll(): Promise<User[]>;
  create(user: Omit<User, 'id'>): Promise<User>;
  delete(id: string): Promise<boolean>;
}

interface User {
  id: string;
  name: string;
  email: string;
}

// Service yang menggunakan repository
class UserService {
  constructor(private readonly repository: UserRepository) {}

  async getUser(id: string): Promise<User> {
    const user = await this.repository.findById(id);
    if (!user) {
      throw new Error(`User with id ${id} not found`);
    }
    return user;
  }

  async createUser(name: string, email: string): Promise<User> {
    return this.repository.create({ name, email });
  }
}

// BENAR: Membuat mock dengan tipe yang benar
describe('UserService', () => {
  // Mock repository dengan tipe eksplisit
  let mockRepository: jest.Mocked<UserRepository>;
  let service: UserService;

  beforeEach(() => {
    // Buat mock untuk semua method
    mockRepository = {
      findById: vi.fn(),
      findAll: vi.fn(),
      create: vi.fn(),
      delete: vi.fn()
    };
    
    service = new UserService(mockRepository);
  });

  describe('getUser', () => {
    it('should return user when found', async () => {
      const mockUser: User = {
        id: '1',
        name: 'John Doe',
        email: 'john@example.com'
      };

      // MockReturnValue typed sesuai method
      mockRepository.findById.mockResolvedValue(mockUser);

      const result = await service.getUser('1');
      
      expect(result).toEqual(mockUser);
      expect(mockRepository.findById).toHaveBeenCalledWith('1');
    });

    it('should throw error when user not found', async () => {
      // mockResolvedValue menerima tipe yang sesuai (null)
      mockRepository.findById.mockResolvedValue(null);

      await expect(service.getUser('999')).rejects.toThrow('not found');
    });
  });

  describe('createUser', () => {
    it('should create user via repository', async () => {
      const newUser: User = {
        id: 'new-id',
        name: 'Jane Doe',
        email: 'jane@example.com'
      };

      mockRepository.create.mockResolvedValue(newUser);

      const result = await service.createUser('Jane Doe', 'jane@example.com');
      
      expect(result).toEqual(newUser);
      // Type checking pada mock calls
      expect(mockRepository.create).toHaveBeenCalledWith({
        name: 'Jane Doe',
        email: 'jane@example.com'
      });
    });
  });
});

// BENAR: Mocking modules dengan tipe
// File: api.ts
export const api = {
  async fetchUser(id: string): Promise<User> {
    const response = await fetch(`/api/users/${id}`);
    return response.json();
  },
  
  async updateUser(id: string, data: Partial<User>): Promise<User> {
    const response = await fetch(`/api/users/${id}`, {
      method: 'PATCH',
      body: JSON.stringify(data)
    });
    return response.json();
  }
};

// Mock entire module
vi.mock('./api', () => ({
  api: {
    fetchUser: vi.fn(),
    updateUser: vi.fn()
  }
}));

// Import setelah mock (atau gunakan type assertion)
import { api } from './api';

// Cast api menjadi mock yang typed
const mockedApi = vi.mocked(api);

describe('api usage', () => {
  it('should call fetchUser', async () => {
    const mockUser: User = { id: '1', name: 'John', email: 'john@example.com' };
    
    // Sekarang autocomplete dan type checking tersedia!
    mockedApi.fetchUser.mockResolvedValue(mockUser);
    
    const result = await mockedApi.fetchUser('1');
    expect(result).toEqual(mockUser);
  });
});

// BENAR: Spies dengan tipe
const originalApi = {
  fetchData: async (url: string): Promise<unknown> => {
    const response = await fetch(url);
    return response.json();
  },
  log: (message: string): void => {
    console.log(message);
  }
};

describe('spies', () => {
  it('should spy on method calls', () => {
    // Spy mempertahankan tipe fungsi asli
    const logSpy = vi.spyOn(originalApi, 'log');
    
    originalApi.log('Hello');
    originalApi.log('World');
    
    // Type-safe assertions
    expect(logSpy).toHaveBeenCalledTimes(2);
    expect(logSpy).toHaveBeenCalledWith('Hello');
    expect(logSpy).toHaveBeenLastCalledWith('World');
    
    // Spy juga bisa di-mock
    logSpy.mockImplementation(() => {
      // Do nothing instead of logging
    });
    
    originalApi.log('This wont log');
    
    // Restore original
    logSpy.mockRestore();
  });
});

// BENAR: Mock functions dengan tipe eksplisit
// Tipe: jest.Mock<ReturnType, [Arg1Type, Arg2Type, ...]>
type CalculatorFn = (a: number, b: number) => number;

describe('mock functions', () => {
  it('should have typed mock', () => {
    // Mock dengan tipe eksplisit
    const mockAdd: jest.Mock<number, [number, number]> = vi.fn();
    
    mockAdd.mockReturnValue(5);
    mockAdd.mockImplementation((a, b) => a + b);
    
    // Type checking pada argumen
    mockAdd(2, 3);  // OK
    // mockAdd('a', 'b');  // Error! Argumen harus number
    
    expect(mockAdd).toHaveBeenCalledWith(2, 3);
    expect(mockAdd(2, 3)).toBe(5);
  });
});

// ERROR: Mock tanpa tipe
describe('untyped mocks', () => {
  it('should be avoided', () => {
    const untypedMock = vi.fn();
    
    // ❌ Bisa dipanggil dengan apapun
    untypedMock('string', 123, { nested: true });
    
    // ❌ Tidak ada type checking
    untypedMock.mockReturnValue('anything');
    
    // ✅ Lebih baik: berikan tipe eksplisit
    const typedMock = vi.fn<(a: string, b: number) => boolean>();
    typedMock.mockReturnValue(true);
    typedMock('test', 42);  // OK
    // typedMock(42, 'test');  // Error! Urutan tipe salah
  });
});
```

**Kasus Penggunaan Nyata:**
- Mengisolasi unit test dari dependency eksternal (API, database)
- Memastikan mock dipanggil dengan argumen yang bertipe benar
- Memastikan mock mengembalikan nilai dengan tipe yang diharapkan
- Auto-completion saat menggunakan mock methods (mockReturnValue, dll)
- Refactoring interface akan memunculkan error di semua mock yang menggunakan
