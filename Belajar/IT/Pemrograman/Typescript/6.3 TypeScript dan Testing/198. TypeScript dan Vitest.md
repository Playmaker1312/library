# 198. TypeScript dan Vitest

**Definisi Singkat:** Vitest adalah test runner modern yang sangat cepat dan native mendukung TypeScript tanpa konfigurasi rumit, dirancang untuk kompatibilitas dengan Vite.

**Analogi:** Seperti mobil listrik vs mobil bensin - Vitest adalah mobil listriknya (cepat, modern, efisien) sedangkan Jest adalah mobil bensin (lebih lama tapi mapan). Keduanya mencapai tujuan yang sama tapi dengan cara berbeda.

**Poin-Poin Penting:**
- Native TypeScript support tanpa `ts-jest`
- Sangat cepat dengan HMR (Hot Module Replacement)
- API kompatibel dengan Jest (mudah migrasi)
- Built-in support untuk ESM
- Konfigurasi via `vite.config.ts` atau `vitest.config.ts`

**Contoh Kode:**
```typescript
// Install
// npm install -D vitest typescript
// npm install -D @vitest/ui  // Optional: UI untuk melihat test

// BENAR: Konfigurasi vitest.config.ts
import { defineConfig } from 'vitest/config';

export default defineConfig({
  test: {
    // Environment: 'node' atau 'jsdom' untuk browser
    environment: 'node',
    
    // File test yang akan dijalankan
    include: ['**/*.{test,spec}.{js,mjs,cjs,ts,mts,cts,jsx,tsx}'],
    exclude: ['node_modules', 'dist'],
    
    // Global API seperti Jest (describe, it, expect)
    globals: true,
    
    // Coverage dengan c8 atau istanbul
    coverage: {
      provider: 'c8',
      reporter: ['text', 'json', 'html'],
      include: ['src/**/*.ts'],
      exclude: ['src/**/*.d.ts', 'src/**/*.test.ts']
    },
    
    // Setup files (seperti jest.setup.js)
    setupFiles: ['./test/setup.ts'],
    
    // Watch mode default
    watch: false
  }
});

// Atau konfigurasi di vite.config.ts (jika pakai Vite)
// import { defineConfig } from 'vite';
// 
// export default defineConfig({
//   test: {
//     globals: true,
//     environment: 'jsdom'
//   }
// });

// Script di package.json
// {
//   "scripts": {
//     "test": "vitest",
//     "test:run": "vitest run",
//     "test:coverage": "vitest run --coverage",
//     "test:ui": "vitest --ui"

// BENAR: Menulis test dengan Vitest (API mirip Jest!)
// File: src/math.ts
export function add(a: number, b: number): number {
  return a + b;
}

export async function asyncAdd(a: number, b: number): Promise<number> {
  await new Promise(resolve => setTimeout(resolve, 100));
  return a + b;
}

// File: src/math.test.ts
import { describe, it, expect, vi } from 'vitest';
import { add, asyncAdd } from './math';

// describe, it, expect - sama seperti Jest!
describe('math functions', () => {
  describe('add', () => {
    it('should add two numbers', () => {
      expect(add(1, 2)).toBe(3);
      expect(add(-1, 1)).toBe(0);
    });
  });

  describe('asyncAdd', () => {
    it('should add numbers asynchronously', async () => {
      const result = await asyncAdd(5, 3);
      expect(result).toBe(8);
    });

    it('should resolve with correct value', async () => {
      await expect(asyncAdd(2, 2)).resolves.toBe(4);
    });
  });
});

// BENAR: Mocking dengan Vitest (menggunakan vi)
import { vi } from 'vitest';

// Mock function
const mockFn = vi.fn();
mockFn.mockReturnValue('default');
mockFn.mockImplementation((a: number, b: number) => a + b);

// Mock module
vi.mock('./api', () => ({
  fetchUser: vi.fn().mockResolvedValue({ id: '1', name: 'John' })
}));

// BENAR: Spy dan mock timers
const original = {
  getData: () => 'real data'
};

const spy = vi.spyOn(original, 'getData');
spy.mockReturnValue('mocked data');

console.log(original.getData());  // 'mocked data'

// Fake timers
vi.useFakeTimers();
setTimeout(() => console.log('delayed'), 1000);
vi.runAllTimers();  // Jalankan semua timeout
vi.useRealTimers();  // Kembali ke timer asli

// BENAR: Test untuk React dengan Vitest
// Install: npm install -D @testing-library/react @testing-library/jest-dom jsdom
import { render, screen, fireEvent } from '@testing-library/react';
import { Button } from './Button';
import { vi, describe, it, expect } from 'vitest';

describe('Button', () => {
  it('should render with correct text', () => {
    render(<Button label="Click me" onClick={() => {}} />);
    expect(screen.getByText('Click me')).toBeInTheDocument();
  });

  it('should call onClick when clicked', () => {
    const handleClick = vi.fn();
    render(<Button label="Click" onClick={handleClick} />);
    
    fireEvent.click(screen.getByText('Click'));
    expect(handleClick).toHaveBeenCalledTimes(1);
  });
});

// File test/setup.ts (untuk extend expect)
import '@testing-library/jest-dom';
import { expect } from 'vitest';
import matchers from '@testing-library/jest-dom/matchers';

// Extend Vitest expect dengan jest-dom matchers
expect.extend(matchers);

// BENAR: Snapshot testing dengan Vitest
import { render } from '@testing-library/react';
import { App } from './App';

it('should match snapshot', () => {
  const { container } = render(<App />);
  expect(container).toMatchSnapshot();
});

// Update snapshot: vitest --update
// atau: vitest -u

// Perbandingan Jest vs Vitest:
// Jest: jest.fn()          → Vitest: vi.fn()
// Jest: jest.mock()        → Vitest: vi.mock()
// Jest: jest.spyOn()       → Vitest: vi.spyOn()
// Jest: jest.useFakeTimers() → Vitest: vi.useFakeTimers()
// Jest: jest.clearAllMocks() → Vitest: vi.clearAllMocks()
```

**Kasus Penggunaan Nyata:**
- Test yang sangat cepat dengan HMR - tidak perlu menunggu re-compile lama
- Test untuk project Vite tanpa konfigurasi tambahan
- Migrasi dari Jest dengan perubahan minimal (API hampir sama)
- Testing TypeScript ESM modules tanpa masalah
- UI interface untuk melihat test berjalan dengan `vitest --ui`
