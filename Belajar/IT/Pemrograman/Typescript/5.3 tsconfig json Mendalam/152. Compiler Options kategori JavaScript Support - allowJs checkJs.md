# 152. Compiler Options kategori JavaScript Support - allowJs checkJs

**Definisi Singkat:** Opsi JavaScript Support memungkinkan TypeScript bekerja dengan file `.js`, baik hanya mengompilasi (`allowJs`) maupun juga memeriksa tipe (`checkJs`).

**Analogi:** Seperti restoran yang menerima tamu berbahasa asing — `allowJs` mengizinkan mereka masuk, `checkJs` mencoba berkomunikasi dalam bahasa mereka.

**Poin-Poin Penting:**
- `allowJs`: mengizinkan kompilasi file `.js` bersama `.ts`
- `checkJs`: melakukan type checking pada file `.js`
- `checkJs` juga bisa diaktifkan per file dengan `// @ts-check`
- Berguna untuk migrasi bertahap dari JavaScript ke TypeScript

**Contoh Kode:**
```json
{
  "compilerOptions": {
    "allowJs": true,
    "checkJs": true
  }
}
```

```javascript
// file.js (dengan checkJs)
// @ts-check
/** @param {number} x @param {number} y @returns {number} */
function multiply(x, y) {
  return x * y;
}

// ERROR: checkJs menangkap kesalahan
multiply("2", 3); // ❌ Argument of type 'string' not assignable to parameter of type 'number'

// BENAR: allowJs mengompilasi file JS
```

**Kasus Penggunaan Nyata:** Migrasi proyek JavaScript besar ke TypeScript secara bertahap tanpa harus menulis ulang semuanya sekaligus.
