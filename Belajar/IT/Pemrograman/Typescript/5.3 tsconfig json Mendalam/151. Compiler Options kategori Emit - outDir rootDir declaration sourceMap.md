# 151. Compiler Options kategori Emit - outDir rootDir declaration sourceMap

**Definisi Singkat:** Kategori Emit mengontrol output kompilasi TypeScript: di mana file hasil diletakkan (`outDir`), struktur direktori sumber (`rootDir`), serta file tambahan seperti deklarasi tipe (`declaration`) dan source map (`sourceMap`).

**Analogi:** Seperti mesin cetak — Anda menentukan kertas masuk (rootDir), hasil cetakan (outDir), dan apakah perlu salinan blueprint (declaration) serta panduan revisi (sourceMap).

**Poin-Poin Penting:**
- `outDir`: direktori output file .js hasil kompilasi
- `rootDir`: direktori akar struktur input TypeScript
- `declaration`: menghasilkan file `.d.ts`
- `sourceMap`: menghasilkan file `.js.map` untuk debugging
- `removeComments`: menghapus komentar di output

**Contoh Kode:**
```json
{
  "compilerOptions": {
    "outDir": "./dist",
    "rootDir": "./src",
    "declaration": true,
    "sourceMap": true,
    "declarationMap": true
  }
}
```

```
// Struktur:
// src/
//   utils.ts  →  dist/
//                   utils.js
//                   utils.d.ts
//                   utils.js.map
//                   utils.d.ts.map
```

```typescript
// BENAR: declaration file membantu konsumen library
export function add(a: number, b: number): number {
  return a + b;
}
// menghasilkan: dist/utils.d.ts dengan deklarasi tipe

// ERROR: rootDir tidak konsisten dengan letak file
```

**Kasus Penggunaan Nyata:** Mengatur struktur output untuk package npm, memungkinkan debugging dengan sourceMap, dan menyediakan tipe untuk konsumen library.
