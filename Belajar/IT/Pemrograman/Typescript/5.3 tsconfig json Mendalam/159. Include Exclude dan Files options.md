# 159. Include Exclude dan Files options

**Definisi Singkat:** `include`, `exclude`, dan `files` adalah opsi di tsconfig yang mengontrol file mana yang termasuk dalam kompilasi TypeScript.

**Analogi:** Seperti daftar tamu undangan (`include`), daftar orang yang tidak diundang (`exclude`), dan daftar VIP yang harus hadir (`files`). Semua mengontrol siapa yang masuk ke pesta kompilasi.

**Poin-Poin Penting:**
- `include`: glob pattern file yang akan dikompilasi
- `exclude`: glob pattern file yang dikecualikan
- `files`: daftar file spesifik (bukan glob)
- `exclude` hanya berlaku jika `include` ditentukan
- Default `include`: `["**/*.ts", "**/*.tsx", "**/*.d.ts"]` (dengan exclude node_modules)

**Contoh Kode:**
```json
{
  "include": ["src/**/*.ts"],
  "exclude": ["node_modules", "dist", "src/**/*.test.ts"],
  "files": ["src/index.ts", "src/types.ts"]
}
```

```
// Struktur:
// src/
//   index.ts      ✓ (include + files)
//   types.ts      ✓ (include + files)
//   utils.test.ts ✗ (exclude pattern)
// dist/           ✗ (exclude)
```

```typescript
// BENAR: hanya file yang cocok dikompilasi

// ERROR: file di files tidak ditemukan
// { "files": ["nonexistent.ts"] } // ❌ file not found
```

**Kasus Penggunaan Nyata:** Memastikan hanya file source yang dikompilasi, tidak termasuk test, node_modules, atau file output.
