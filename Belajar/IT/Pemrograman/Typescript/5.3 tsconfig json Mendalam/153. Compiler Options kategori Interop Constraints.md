# 153. Compiler Options kategori Interop Constraints

**Definisi Singkat:** Kategori Interop Constraints mengontrol bagaimana TypeScript berinteraksi dengan JavaScript dari sistem module berbeda, memastikan kompatibilitas antara ES Modules dan CommonJS.

**Analogi:** Seperti adaptor colokan listrik — memastikan perangkat dari satu negara (module system) bisa digunakan di negara lain tanpa masalah.

**Poin-Poin Penting:**
- `esModuleInterop`: memperbaiki interop antara ES modules dan CommonJS
- `allowSyntheticDefaultImports`: mengizinkan default import dari module tanpa default export
- `forceConsistentCasingInFileNames`: memastikan konsistensi huruf di path file
- `isolatedModules`: memastikan kode aman untuk transpiler single-file (Babel, esbuild, SWC)

**Contoh Kode:**
```json
{
  "compilerOptions": {
    "esModuleInterop": true,
    "forceConsistentCasingInFileNames": true,
    "isolatedModules": true,
    "skipLibCheck": true
  }
}
```

```typescript
// BENAR: esModuleInterop memungkinkan import default
import express from 'express';

// ERROR: tanpa esModuleInterop
import express from 'express'; // ❌ Module has no default export

// ERROR: isolatedModules melarang re-export type
export { SomeType } from './types'; // ❌ butuh `export type`
```

**Kasus Penggunaan Nyata:** Setiap proyek TypeScript modern sebaiknya mengaktifkan `esModuleInterop`, `forceConsistentCasingInFileNames`, dan `skipLibCheck` untuk pengalaman developer yang lebih baik.
