# 158. Extending tsconfig - extends property

**Definisi Singkat:** Properti `extends` di tsconfig memungkinkan Anda mewarisi konfigurasi dari file tsconfig lain, mengurangi duplikasi dan memudahkan pengelolaan konfigurasi bersama.

**Analogi:** Seperti template CV — Anda membuat satu master yang berisi format umum, lalu setiap orang (proyek) bisa menyesuaikan bagian tertentu tanpa mengulangi semuanya.

**Poin-Poin Penting:**
- Nilai dari file yang di-extend akan ditimpa oleh file yang me-extend
- Support rantai extends (A extends B extends C)
- Path bisa relatif atau package npm (`@tsconfig/node18`)
- Properties arrays akan digabung, bukan ditimpa

**Contoh Kode:**
```json
// base.json
{
  "compilerOptions": {
    "strict": true,
    "target": "ES2022",
    "module": "ESNext"
  }
}

// tsconfig.json (mewarisi base.json)
{
  "extends": "./base.json",
  "compilerOptions": {
    "outDir": "./dist",
    "rootDir": "./src"
  }
}
```

```typescript
// BENAR: extends mengurangi duplikasi konfigurasi
// base.json: strict + target + module
// tsconfig.json: outDir + rootDir saja

// ERROR: path extends tidak valid
{ "extends": "./nonexistent.json" } // ❌ file not found
```

**Kasus Penggunaan Nyata:** Mengelola konfigurasi bersama untuk monorepo, atau menggunakan preset seperti `@tsconfig/node18` atau `@tsconfig/vite`.
