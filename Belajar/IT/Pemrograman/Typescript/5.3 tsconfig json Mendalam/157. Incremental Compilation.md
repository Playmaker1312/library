# 157. Incremental Compilation

**Definisi Singkat:** Incremental compilation adalah fitur TypeScript yang hanya mengompilasi file yang berubah sejak kompilasi terakhir, menggunakan file `.tsbuildinfo` untuk melacak perubahan.

**Analogi:** Seperti mencuci hanya piring kotor, bukan seluruh dapur — menghemat waktu dan tenaga dengan hanya memproses yang berubah.

**Poin-Poin Penting:**
- Diaktifkan dengan `incremental: true` di tsconfig
- Menghasilkan file `.tsbuildinfo` untuk data cache
- Juga berfungsi dengan `tsc --watch` untuk kompilasi cepat
- Dapat dikombinasikan dengan Project References

**Contoh Kode:**
```json
{
  "compilerOptions": {
    "incremental": true,
    "tsBuildInfoFile": "./.tsbuildinfo"
  }
}
```

```bash
# Kompilasi pertama: normal (lambat)
tsc

# Kompilasi kedua: hanya file berubah (cepat!)
tsc

# Bersihkan cache
tsc --build --clean

# BENAR: incremental mempercepat development loop
# ERROR: menghapus .tsbuildinfo akan memicu full rebuild
```

**Kasus Penggunaan Nyata:** Meningkatkan produktivitas developer dengan mengurangi waktu kompilasi dari menit menjadi detik pada proyek besar.
