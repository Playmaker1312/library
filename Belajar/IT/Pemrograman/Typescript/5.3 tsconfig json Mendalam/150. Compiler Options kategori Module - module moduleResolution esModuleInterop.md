# 150. Compiler Options kategori Module - module moduleResolution esModuleInterop

**Definisi Singkat:** Kategori Module mengontrol bagaimana TypeScript menangani sistem module, termasuk format output (`module`), strategi resolusi (`moduleResolution`), dan interoperabilitas (`esModuleInterop`).

**Analogi:** Seperti pengaturan pos internasional — menentukan bagaimana paket (module) harus dibungkus (format) dan dikirim (resolusi) agar sampai ke tujuan dengan benar.

**Poin-Poin Penting:**
- `module` menentukan format output: `commonjs`, `esnext`, `node16`, dll
- `moduleResolution` menentukan cara mencari file module
- `esModuleInterop` memungkinkan import default dari module CJS
- `allowSyntheticDefaultImports` hanya deklarasi tipe (tanpa polyfill runtime)

**Contoh Kode:**
```json
{
  "compilerOptions": {
    "module": "esnext",
    "moduleResolution": "bundler",
    "esModuleInterop": true
  }
}
```

```typescript
// BENAR: esModuleInterop memungkinkan ini
import React from 'react';

// ERROR: tanpa esModuleInterop, harus:
import * as React from 'react';

// ERROR: module mismatch
// module: "esnext" dengan moduleResolution: "node16"
import foo from './bar'; // butuh ekstensi .js
```

**Kasus Penggunaan Nyata:** Konfigurasi yang tepat memastikan TypeScript bekerja dengan baik dengan runtime (Node.js, browser) dan bundler (Webpack, Vite).
