# 156. Project References dan Composite Projects

**Definisi Singkat:** Project References memungkinkan Anda membagi proyek TypeScript besar menjadi sub-proyek yang lebih kecil yang saling mereferensi, dengan opsi `composite: true` untuk membangun secara incremental.

**Analogi:** Seperti membangun perumahan — setiap rumah (sub-proyek) dibangun secara independen, tapi saling terhubung dengan jalan (referensi) dan bisa dibangun bersamaan.

**Poin-Poin Penting:**
- Setiap sub-proyek punya tsconfig sendiri dengan `composite: true`
- File `.tsbuildinfo` mempercepat kompilasi ulang
- Mendukung build order otomatis dengan `tsc --build`
- Ideal untuk monorepo dengan banyak package

**Contoh Kode:**
```json
// tsconfig.json (root)
{
  "references": [
    { "path": "./packages/core" },
    { "path": "./packages/utils" }
  ]
}

// packages/core/tsconfig.json
{
  "compilerOptions": {
    "composite": true,
    "outDir": "./dist",
    "rootDir": "./src"
  }
}
```

```bash
# Membangun semua sub-proyek dengan urutan benar
tsc --build

# BENAR: hanya membangun yang berubah
tsc --build --force

# ERROR: tanpa composite, project references tidak berfungsi
```

**Kasus Penggunaan Nyata:** Memecah monorep besar menjadi package-package kecil yang bisa dikompilasi secara paralel dan incremental.
