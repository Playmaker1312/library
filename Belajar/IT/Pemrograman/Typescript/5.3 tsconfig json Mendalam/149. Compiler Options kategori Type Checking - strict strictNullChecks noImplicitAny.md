# 149. Compiler Options kategori Type Checking - strict strictNullChecks noImplicitAny

**Definisi Singkat:** Kategori Type Checking pada tsconfig mengontrol seberapa ketat TypeScript memeriksa tipe, dengan opsi seperti `strict`, `strictNullChecks`, dan `noImplicitAny`.

**Analogi:** Seperti tingkat keamanan bandara — semakin ketat (strict), semakin banyak pemeriksaan yang dilakukan sebelum kode "terbang".

**Poin-Poin Penting:**
- `strict: true` mengaktifkan semua opsi type checking ketat sekaligus
- `strictNullChecks` mencegah null/undefined masuk ke tipe yang tidak seharusnya
- `noImplicitAny` menghasilkan error jika tipe tidak bisa diinferensi
- Opsi lain: `noUnusedLocals`, `noUnusedParameters`, `exactOptionalPropertyTypes`

**Contoh Kode:**
```json
{
  "compilerOptions": {
    "strict": true,
    "noImplicitAny": true,
    "strictNullChecks": true
  }
}
```

```typescript
// BENAR: strictNullChecks mencegah ini
function greet(name: string | null) {
  // ERROR: Object is possibly 'null'
  console.log(name.toUpperCase());
}

// ERROR: noImplicitAny
function add(a, b) { return a + b; }
// ❌ Parameter 'a' implicitly has an 'any' type
```

**Kasus Penggunaan Nyata:** Mengaktifkan strict mode sangat disarankan untuk semua proyek baru karena menangkap bug lebih awal.
