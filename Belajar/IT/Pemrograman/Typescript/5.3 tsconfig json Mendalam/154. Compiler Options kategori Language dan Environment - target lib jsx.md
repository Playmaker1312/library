# 154. Compiler Options kategori Language dan Environment - target lib jsx

**Definisi Singkat:** Kategori Language dan Environment menentukan versi JavaScript target (`target`), deklarasi API lingkungan (`lib`), dan dukungan JSX/React (`jsx`).

**Analogi:** Seperti memilih bahasa dan alat yang tepat — Anda menentukan untuk audiens mana (target), buku referensi apa yang tersedia (lib), dan apakah akan menulis dalam format tertentu (jsx).

**Poin-Poin Penting:**
- `target`: versi ECMAScript output (ES5, ES2020, ESNext)
- `lib`: file deklarasi yang disertakan (DOM, ES2021, dll)
- `jsx`: bagaimana JSX diproses (react, react-jsx, preserve)
- `jsxFactory` dan `jsxFragmentFactory` untuk custom JSX

**Contoh Kode:**
```json
{
  "compilerOptions": {
    "target": "ES2022",
    "lib": ["ES2022", "DOM", "DOM.Iterable"],
    "jsx": "react-jsx"
  }
}
```

```typescript
// BENAR: target modern mendukung fitur baru
const map = new Map<string, number>();
const promise = Promise.resolve(42);

// ERROR: target ES5 tidak tahu Promise (butuh polyfill)
// ❌ 'Promise' only refers to a type, but is being used as a value

// ERROR: tanpa lib: ["DOM"]
document.getElementById('app'); // ❌ 'document' not found
```

**Kasus Penggunaan Nyata:** Menyesuaikan konfigurasi berdasarkan lingkungan target — browser modern (ES2020+), Node.js, atau legacy browser (ES5).
