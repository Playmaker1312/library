# 155. Strict Mode - apa saja yang diaktifkan

**Definisi Singkat:** `strict: true` di tsconfig adalah meta-flag yang mengaktifkan serangkaian opsi type checking ketat secara bersamaan, memberikan pengamanan tipe maksimal.

**Analogi:** Seperti tombol "mode sulit" di game — semua tantangan diaktifkan sekaligus, membuat Anda bermain lebih hati-hati dan menjadi pemain yang lebih baik.

**Poin-Poin Penting:**
- `strictNullChecks`: null/undefined tidak bisa diassign ke tipe lain
- `noImplicitAny`: error jika tipe tidak bisa diinfer
- `strictFunctionTypes`: pemeriksaan fungsi kontravarian
- `strictBindCallApply`: cek tipe pada bind/call/apply
- `strictPropertyInitialization`: properti class harus diinisialisasi
- `noImplicitThis`: `this` tidak boleh implicit any
- `alwaysStrict`: gunakan strict mode JavaScript

**Contoh Kode:**
```typescript
// strict: true mengaktifkan semua ini

function greet(name?: string) {
  // ERROR: strictNullChecks
  console.log(name.toUpperCase()); // Object is possibly 'undefined'
}

// ERROR: noImplicitThis
function onClick() {
  console.log(this.value); // 'this' implicitly has type 'any'
}

// ERROR: strictPropertyInitialization
class Person {
  name: string; // ❌ Property 'name' has no initializer
  constructor() {}
}
```

**Kasus Penggunaan Nyata:** Semua proyek TypeScript baru wajib menggunakan `strict: true`. Hanya proyek legacy yang mungkin menonaktifkannya sebagian.
