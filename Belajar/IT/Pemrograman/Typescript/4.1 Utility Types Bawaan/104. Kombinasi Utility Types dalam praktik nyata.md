# 104. Kombinasi Utility Types dalam praktik nyata

**Definisi Singkat:** Utility types menjadi sangat powerful saat dikombinasikan untuk menyelesaikan masalah kompleks dengan type-safe.

**Analogi:** Seperti pisau Swiss Army — setiap alat (utility type) berguna sendiri, tapi kombinasi beberapa alat sekaligus menyelesaikan masalah yang lebih rumit.

**Poin-Poin Penting:**
- Kombinasi `Pick`, `Omit`, `Partial`, `Required` — membentuk ulang object type
- Kombinasi `ReturnType` + `Awaited` — handle async function types
- Kombinasi `Record` + `Pick` — membuat lookup table terbatas

**Contoh Kode:**
```typescript
interface User {
  id: number;
  name: string;
  email: string;
  password: string;
  role: "admin" | "user";
  createdAt: Date;
}

// Kombinasi: update user (partial + omit readonly fields)
type UserUpdate = Partial<Omit<User, "id" | "createdAt">>;
const update: UserUpdate = { name: "Budi", role: "admin" }; // ✅

// Kombinasi: async return type dengan Awaited
async function fetchUser(id: number): Promise<User> {
  return { id, name: "", email: "", password: "", role: "user", createdAt: new Date() };
}
type FetchedUser = Awaited<ReturnType<typeof fetchUser>>; // User ✅

// Kombinasi: Record + Pick
type UserPublic = Pick<User, "id" | "name" | "email">;
const userMap: Record<number, UserPublic> = {
  1: { id: 1, name: "Budi", email: "budi@mail.com" },
}; // ✅

// ERROR: kombinasi tetap menjaga batasan tipe
// const bad: UserUpdate = { id: 1 }; // ❌ id sudah di-omit
```

**Kasus Penggunaan Nyata:** Membangun tipe untuk API response, request body, dan state management dengan sedikit kode dan maksimal type safety.
