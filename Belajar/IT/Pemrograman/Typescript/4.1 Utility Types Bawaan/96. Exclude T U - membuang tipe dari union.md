# 96. Exclude\<T, U\> - membuang tipe dari union

**Definisi Singkat:** `Exclude<T, U>` membuang anggota-anggota union T yang termasuk dalam U. Bekerja pada union types, bukan object types.

**Analogi:** Seperti menyaring buah busuk dari keranjang — kamu membuang semua yang masuk kategori "busuk" dari campuran buah.

**Poin-Poin Penting:**
- Implementasi: `type Exclude<T, U> = T extends U ? never : T`
- Bekerja secara distributif pada union T
- Tidak bekerja pada object/interface, hanya union types

**Contoh Kode:**
```typescript
type Status = "active" | "inactive" | "deleted" | "pending";

// BENAR: buang "deleted" dari union
type ActiveStatus = Exclude<Status, "deleted">;
// ActiveStatus = "active" | "inactive" | "pending"

let s: ActiveStatus = "active"; // ✅
// s = "deleted"; // ❌ "deleted" sudah di-exclude

type T = Exclude<string | number | boolean, string | boolean>;
// T = number ✅
```

**Kasus Penggunaan Nyata:** Membuat subset status yang valid setelah filter, atau menghapus tipe tertentu dari generic union.
