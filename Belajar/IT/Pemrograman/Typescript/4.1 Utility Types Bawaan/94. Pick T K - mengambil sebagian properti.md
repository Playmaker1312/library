# 94. Pick\<T, K\> - mengambil sebagian properti

**Definisi Singkat:** `Pick<T, K>` membuat tipe baru dengan hanya mengambil properti-properti tertentu dari T yang disebutkan di K.

**Analogi:** Seperti memilih menu prasmanan — kamu hanya mengambil beberapa lauk dari semua yang tersedia, sisanya tidak diambil.

**Poin-Poin Penting:**
- Implementasi: `type Pick<T, K extends keyof T> = { [P in K]: T[P] }`
- K adalah union of keys yang ingin dipertahankan
- Berguna untuk membuat subset type dari type yang lebih besar

**Contoh Kode:**
```typescript
interface User {
  id: number;
  name: string;
  email: string;
  password: string;
}

// BENAR: hanya mengambil name dan email
type PublicUser = Pick<User, "name" | "email">;
const publicData: PublicUser = { name: "Budi", email: "budi@mail.com" }; // ✅

// ERROR: properti yang tidak dipilih tidak boleh ada
// const pub: PublicUser = { id: 1, name: "Budi", email: "" }; // ❌ id tidak ada di PublicUser
```

**Kasus Penggunaan Nyata:** Mengirim data publik ke frontend tanpa mengekspos field sensitif seperti password atau token.
