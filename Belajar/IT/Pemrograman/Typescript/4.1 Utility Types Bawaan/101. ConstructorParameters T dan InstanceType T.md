# 101. ConstructorParameters\<T\> dan InstanceType\<T\>

**Definisi Singkat:** `ConstructorParameters<T>` mengambil tuple parameter dari constructor class, sedangkan `InstanceType<T>` mengambil tipe instance dari constructor type.

**Analogi:** Seperti arsitek dan rumah — `ConstructorParameters` adalah cetak biru material bangunan yang dibutuhkan, `InstanceType` adalah rumah jadi yang dihasilkan.

**Poin-Poin Penting:**
- `ConstructorParameters<T>` — `T extends abstract new (...args: infer P) => any ? P : never`
- `InstanceType<T>` — `T extends abstract new (...args: any) => infer R ? R : any`
- Bekerja dengan constructor type (class types), bukan regular function

**Contoh Kode:**
```typescript
class User {
  constructor(public id: number, public name: string) {}
}

// BENAR: ambil parameter constructor dan instance type
type UserParams = ConstructorParameters<typeof User>;
// UserParams = [id: number, name: string]

type UserInstance = InstanceType<typeof User>;
// UserInstance = User

const args: UserParams = [1, "Budi"];
const user: UserInstance = new User(...args); // ✅

// ERROR: ConstructorParameters bukan function type
// type T = ConstructorParameters<() => void>; // ❌
```

**Kasus Penggunaan Nyata:** Dependency injection container yang perlu membuat instance class secara dinamis dengan parameter yang type-safe.
