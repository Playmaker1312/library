# 102. Awaited\<T\> - unwrap Promise type

**Definisi Singkat:** `Awaited<T>` membuka (unwrap) tipe yang dibungkus Promise, termasuk nested Promise, hingga mendapatkan tipe dasarnya.

**Analogi:** Seperti membuka boneka Rusia (Matryoshka) — kamu terus membuka lapisan luar (Promise) sampai mendapatkan boneka terkecil (tipe dasar).

**Poin-Poin Penting:**
- Diperkenalkan di TypeScript 4.5
- Meng-unwrap `Promise`, `PromiseLike`, termasuk nested seperti `Promise<Promise<string>>`
- Mirip dengan apa yang dilakukan `await` pada level tipe

**Contoh Kode:**
```typescript
// BENAR: unwrap Promise type
type Result1 = Awaited<Promise<string>>;        // string
type Result2 = Awaited<Promise<Promise<number>>>; // number
type Result3 = Awaited<string | Promise<number>>; // string | number

async function fetchData(): Promise<{ id: number }> {
  return { id: 1 };
}

type Data = Awaited<ReturnType<typeof fetchData>>; // { id: number } ✅

// ERROR: Awaited tetap mengembalikan tipe untuk non-Promise
type T = Awaited<string>; // string (bukan error)
```

**Kasus Penggunaan Nyata:** Mendapatkan return type dari async function tanpa menulis ulang interface, terutama saat menggunakan fungsi API yang mengembalikan Promise.
