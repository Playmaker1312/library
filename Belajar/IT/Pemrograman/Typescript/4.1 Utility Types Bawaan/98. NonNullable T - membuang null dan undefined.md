# 98. NonNullable\<T\> - membuang null dan undefined

**Definisi Singkat:** `NonNullable<T>` menghilangkan `null` dan `undefined` dari tipe T, menyisakan hanya tipe yang non-nullable.

**Analogi:** Seperti saringan tepung — kamu menyaring gumpalan (null/undefined) sehingga hanya tersisa tepung halus (tipe asli).

**Poin-Poin Penting:**
- Implementasi: `type NonNullable<T> = T extends null | undefined ? never : T`
- Berguna setelah validasi bahwa suatu value pasti ada
- Sama seperti `Exclude<T, null | undefined>`

**Contoh Kode:**
```typescript
type MaybeString = string | null | undefined;

// BENAR: null dan undefined dibuang
type DefiniteString = NonNullable<MaybeString>;
// DefiniteString = string

function process(value: MaybeString): void {
  const clean: NonNullable<MaybeString> = value!;
  // setelah validasi
}

// ERROR: NonNullable menghilangkan null, jadi null tidak bisa di-assign
// const x: NonNullable<string | null> = null; // ❌
```

**Kasus Penggunaan Nyata:** Membersihkan tipe setelah guard atau filter null, misalnya setelah `Array.filter(Boolean)`.
