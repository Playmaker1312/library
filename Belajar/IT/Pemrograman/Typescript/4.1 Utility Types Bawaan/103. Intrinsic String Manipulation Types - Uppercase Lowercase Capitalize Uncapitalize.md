# 103. Intrinsic String Manipulation Types - Uppercase Lowercase Capitalize Uncapitalize

**Definisi Singkat:** TypeScript menyediakan 4 utility type built-in untuk memanipulasi string literal pada level tipe: `Uppercase`, `Lowercase`, `Capitalize`, dan `Uncapitalize`.

**Analogi:** Seperti stempel huruf di toko percetakan — kamu punya stempel untuk huruf besar semua, kecil semua, kapital di awal, atau tanpa kapital di awal.

**Poin-Poin Penting:**
- Intrinsic = diimplementasikan langsung di kompiler, bukan dengan mapped type biasa
- Bekerja pada string literal types, bukan runtime string
- Sering dikombinasikan dengan Template Literal Types

**Contoh Kode:**
```typescript
// BENAR: manipulasi string literal type
type Greeting = "hello world";
type Shout = Uppercase<Greeting>;       // "HELLO WORLD"
type Whisper = Lowercase<Greeting>;      // "hello world"
type Title = Capitalize<Greeting>;       // "Hello world"
type Lower = Uncapitalize<Greeting>;     // "hello world"

type Route = "user-profile";
type EventName = `on${Capitalize<Route>}`; // "onUser-profile"

// ERROR: intrinsic types hanya untuk string literal, bukan runtime
// const x: Uppercase<string> = "HELLO"; // boleh, karena string juga string literal
```

**Kasus Penggunaan Nyata:** Membuat event handler name dari komponen name secara otomatis, misalnya `onClick`, `onChange` dari `click`, `change`.
