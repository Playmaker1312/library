# 100. Parameters\<T\> - mendapatkan tuple parameter types

**Definisi Singkat:** `Parameters<T>` mengembalikan tuple tipe dari parameter-parameter function type T.

**Analogi:** Seperti melihat cetakan kue — kamu bisa melihat bentuk loyang (parameter types) yang dibutuhkan tanpa harus memanggang kue (menjalankan fungsi).

**Poin-Poin Penting:**
- Implementasi: `type Parameters<T> = T extends (...args: infer P) => any ? P : never`
- Berguna untuk reuse parameter type di banyak tempat
- Mengembalikan tuple, bukan object

**Contoh Kode:**
```typescript
function setUser(id: number, name: string, role?: string): void {}

// BENAR: dapatkan tuple parameter type
type SetUserParams = Parameters<typeof setUser>;
// SetUserParams = [id: number, name: string, role?: string]

const params: SetUserParams = [1, "Budi"]; // ✅

// ERROR: jumlah parameter tidak sesuai
// const bad: SetUserParams = [1]; // ❌ kurang parameter name
```

**Kasus Penggunaan Nyata:** Typing untuk wrapper fungsi, logger, atau decorator yang perlu tahu persis parameter dari fungsi yang dibungkus.
