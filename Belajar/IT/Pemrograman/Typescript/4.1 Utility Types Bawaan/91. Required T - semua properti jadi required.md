# 91. Required\<T\> - semua properti jadi required

**Definisi Singkat:** `Required<T>` adalah kebalikan dari `Partial`, mengubah semua properti opsional menjadi wajib (required).

**Analogi:** Seperti checklist wajib di aplikasi imigrasi — tidak boleh ada kolom yang dikosongkan, semua harus diisi.

**Poin-Poin Penting:**
- Implementasi: `type Required<T> = { [P in keyof T]-?: T[P] }` (minus optional)
- Berguna ketika setelah suatu tahap, semua properti harus terisi penuh
- Membalikkan efek `?` pada properti

**Contoh Kode:**
```typescript
interface Config {
  apiKey?: string;
  timeout?: number;
  retry?: boolean;
}

// BENAR: memaksa semua properti harus diisi
function initApp(config: Required<Config>): void {
  console.log(config.apiKey, config.timeout, config.retry);
}
initApp({ apiKey: "abc", timeout: 5000, retry: true }); // ✅

// ERROR: jika masih ada yang optional
// initApp({ apiKey: "abc" }); // ❌ timeout dan retry hilang
```

**Kasus Penggunaan Nyata:** Validasi form bertahap — setelah user menyelesaikan semua langkah, form menjadi `Required` sebelum dikirim.
