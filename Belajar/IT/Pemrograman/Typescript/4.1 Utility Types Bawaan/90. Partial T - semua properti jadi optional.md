# 90. Partial\<T\> - semua properti jadi optional

**Definisi Singkat:** `Partial<T>` mengubah semua properti di T menjadi opsional (optional). Berguna saat ingin membuat objek dengan subset properti.

**Analogi:** Seperti formulir pendaftaran di mana kolom wajib diisi, tapi `Partial` mengizinkan kamu hanya mengisi beberapa kolom saja tanpa harus lengkap.

**Poin-Poin Penting:**
- Implementasi: `type Partial<T> = { [P in keyof T]?: T[P] }`
- Membantu saat update parsial data tanpa harus menyediakan seluruh properti
- Sama seperti menambahkan `?` pada setiap properti di suatu tipe

**Contoh Kode:**
```typescript
interface User {
  id: number;
  name: string;
  email: string;
}

// BENAR: hanya update field yang diperlukan
function updateUser(id: number, changes: Partial<User>): void {
  // kirim hanya field yang berubah
}
updateUser(1, { name: "Budi" }); // ✅ hanya name

// ERROR: Partial tidak mengubah tipe value
// updateUser(1, { name: 123 }); // ❌ number tidak assignable ke string
```

**Kasus Penggunaan Nyata:** API PATCH endpoint di mana client hanya mengirim field yang ingin diubah, bukan seluruh objek.
