# 97. Extract\<T, U\> - mengambil tipe dari union

**Definisi Singkat:** `Extract<T, U>` mengambil anggota-anggota union T yang termasuk dalam U. Kebalikan dari `Exclude`.

**Analogi:** Seperti menyaring kelereng merah dari kumpulan kelereng warna-warni — kamu hanya mengambil yang merah saja.

**Poin-Poin Penting:**
- Implementasi: `type Extract<T, U> = T extends U ? T : never`
- Bekerja secara distributif pada union T
- Berguna untuk memfilter union type berdasarkan kriteria

**Contoh Kode:**
```typescript
type Status = "active" | "inactive" | "deleted" | 404 | 500;

// BENAR: ambil hanya string
type StringStatus = Extract<Status, string>;
// StringStatus = "active" | "inactive" | "deleted"

// BENAR: ambil hanya number
type NumberStatus = Extract<Status, number>;
// NumberStatus = 404 | 500

type T = Extract<string | number | boolean, string | boolean>;
// T = string | boolean ✅
```

**Kasus Penggunaan Nyata:** Memfilter union type untuk mendapatkan tipe-tipe yang memenuhi kondisi tertentu dalam generic programming.
