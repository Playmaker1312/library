# 95. Omit\<T, K\> - membuang sebagian properti

**Definisi Singkat:** `Omit<T, K>` membuat tipe baru dengan membuang properti-properti tertentu dari T yang disebutkan di K.

**Analogi:** Seperti menyunting dokumen rahasia — kamu mencoret (omit) informasi sensitif sebelum menunjukkan ke orang lain.

**Poin-Poin Penting:**
- Implementasi: menggunakan `Pick` dan `Exclude` — `type Omit<T, K> = Pick<T, Exclude<keyof T, K>>`
- K adalah union of keys yang ingin dibuang
- Kebalikan dari `Pick`

**Contoh Kode:**
```typescript
interface User {
  id: number;
  name: string;
  email: string;
  password: string;
}

// BENAR: buang password dan id
type UserInput = Omit<User, "id" | "password">;
const input: UserInput = { name: "Budi", email: "budi@mail.com" }; // ✅

// ERROR: properti yang di-omit tidak boleh ada
// const inp: UserInput = { name: "Budi", password: "123" }; // ❌ password sudah di-omit
```

**Kasus Penggunaan Nyata:** Form input data di mana field auto-generated seperti `id` dan `createdAt` tidak perlu diisi user.
