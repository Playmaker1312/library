# 99. ReturnType\<T\> - mendapatkan return type fungsi

**Definisi Singkat:** `ReturnType<T>` mengambil tipe kembalian (return type) dari function type T.

**Analogi:** Seperti melihat lubang mesin penjual otomatis setelah transaksi — kamu melihat apa yang keluar (return type) tanpa peduli cara kerjanya.

**Poin-Poin Penting:**
- Implementasi menggunakan `infer`: `type ReturnType<T> = T extends (...args: any[]) => infer R ? R : any`
- Hanya bekerja pada function type, bukan instance function
- Berguna untuk reusable type dari fungsi yang sudah ada

**Contoh Kode:**
```typescript
function createUser() {
  return { id: 1, name: "Budi", createdAt: new Date() };
}

// BENAR: ekstrak return type
type NewUser = ReturnType<typeof createUser>;
// NewUser = { id: number; name: string; createdAt: Date }

const user: NewUser = { id: 2, name: "Siti", createdAt: new Date() }; // ✅

// ERROR: bukan function type
// type T = ReturnType<string>; // ❌ string tidak assignable ke (...args: any[]) => infer R
```

**Kasus Penggunaan Nyata:** Mendapatkan tipe dari fungsi factory atau library eksternal tanpa perlu mengekspor interface-nya.
