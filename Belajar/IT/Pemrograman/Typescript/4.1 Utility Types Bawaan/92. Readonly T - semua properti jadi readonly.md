# 92. Readonly\<T\> - semua properti jadi readonly

**Definisi Singkat:** `Readonly<T>` membuat semua properti di T menjadi read-only, tidak bisa diubah setelah diinisialisasi.

**Analogi:** Seperti lencana ID karyawan — setelah dicetak dan diberikan, tidak boleh diedit lagi.

**Poin-Poin Penting:**
- Implementasi: `type Readonly<T> = { readonly [P in keyof T]: T[P] }`
- Mencegah mutasi yang tidak disengaja pada objek
- Sama seperti menambahkan keyword `readonly` di setiap properti

**Contoh Kode:**
```typescript
interface User {
  id: number;
  name: string;
}

// BENAR: properti hanya bisa dibaca
const user: Readonly<User> = { id: 1, name: "Budi" };
console.log(user.name); // ✅ membaca diperbolehkan

// ERROR: reassign properti tidak diizinkan
// user.id = 2; // ❌ Cannot assign to 'id' because it is a read-only property
```

**Kasus Penggunaan Nyata:** State management seperti Redux — state hanya bisa dibaca dan diubah melalui reducer, bukan direct mutation.
