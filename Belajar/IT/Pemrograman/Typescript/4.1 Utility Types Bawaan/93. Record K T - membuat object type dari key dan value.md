# 93. Record\<K, T\> - membuat object type dari key dan value

**Definisi Singkat:** `Record<K, T>` membuat object type dengan key bertipe K dan value bertipe T. Berguna untuk mapping key-value yang seragam.

**Analogi:** Seperti laci penyimpanan bernomor — setiap nomor (key) menunjuk ke satu barang (value) dengan jenis yang sama.

**Poin-Poin Penting:**
- Implementasi: `type Record<K extends keyof any, T> = { [P in K]: T }`
- K biasanya adalah union of string literal types
- Setiap value memiliki tipe yang sama

**Contoh Kode:**
```typescript
type Role = "admin" | "user" | "guest";

// BENAR: mapping role ke permission
const permissions: Record<Role, string[]> = {
  admin: ["read", "write", "delete"],
  user: ["read"],
  guest: [],
};

const scores: Record<string, number> = { Budi: 90, Siti: 85 }; // ✅

// ERROR: key tidak ada di Role
// const perms: Record<Role, string> = { admin: "all", staff: "some" }; // ❌ staff bukan Role
```

**Kasus Penggunaan Nyata:** Lookup table, mapping enum ke konfigurasi, atau cache data dengan key dinamis.
