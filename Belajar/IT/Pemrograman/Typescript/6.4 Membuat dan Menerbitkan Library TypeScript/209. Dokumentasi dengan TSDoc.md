# 209. Dokumentasi dengan TSDoc

**Definisi Singkat:** TSDoc adalah standar komentar dokumentasi untuk TypeScript yang memungkinkan IDE dan tools menampilkan informasi yang berguna tentang fungsi, class, dan types.

**Analogi:** Seperti label pada peralatan - TSDoc adalah label yang menjelaskan apa fungsi alat itu, bagaimana menggunakannya, dan peringatan apa yang perlu diperhatikan.

**Poin-Poin Penting:**
- Gunakan `/** ... */` untuk komentar TSDoc (bukan `//`)
- Tag umum: `@param`, `@returns`, `@example`, `@deprecated`, `@see`
- `@internal` untuk menandai API internal (akan dihilangkan dengan `stripInternal`)
- `@template` untuk generic types
- TSDoc muncul di tooltip IDE dan IntelliSense

**Contoh Kode:**
```typescript
// ========== KOMENTAR DASAR TSDOC ==========

/**
 * Menambahkan dua angka dan mengembalikan hasilnya.
 * @param a - Angka pertama yang akan ditambahkan
 * @param b - Angka kedua yang akan ditambahkan
 * @returns Hasil penjumlahan a + b
 * @example
 * ```typescript
 * const result = add(2, 3);
 * console.log(result); // Output: 5
 * ```
 */
export function add(a: number, b: number): number {
  return a + b;

/**
 * Representasi pengguna dalam sistem
 * @remarks
 * Interface ini digunakan di berbagai tempat dalam aplikasi.
 * Untuk membuat user baru, gunakan {@link createUser} function.
 * 
 * @example
 * ```typescript
 * const user: User = {
 *   id: 'usr_123',
 *   name: 'John Doe',
 *   email: 'john@example.com',
 *   role: 'user'
 * };
 * ```
 * 
 * @see {@link createUser}
 * @see {@link updateUser}
 */
export interface User {
  /** ID unik pengguna (format: usr_xxx) */
  id: string;
  
  /** Nama lengkap pengguna */
  name: string;
  
  /** Alamat email pengguna (harus unik) */
  email: string;
  
  /**
   * Role pengguna dalam sistem
   * @defaultValue 'user'
   */
  role: 'admin' | 'moderator' | 'user';
  
  /**
   * Tanggal pembuatan akun
   * @readonly
   */
  readonly createdAt: Date;
}

/**
 * Membuat pengguna baru dalam sistem
 * @param data - Data pengguna tanpa ID (ID akan di-generate otomatis)
 * @returns Pengguna yang baru dibuat dengan ID dan createdAt
 * @throws {ValidationError} Jika email tidak valid atau sudah digunakan
 * @throws {DatabaseError} Jika terjadi kesalahan saat menyimpan ke database
 * 
 * @example
 * ```typescript
 * try {
 *   const newUser = await createUser({
 *     name: 'Jane Doe',
 *     email: 'jane@example.com',
 *     role: 'user'
 *   });
 *   console.log('User created:', newUser.id);
 * } catch (error) {
 *   if (error instanceof ValidationError) {
 *     console.error('Validation failed:', error.message);
 *   }
 * }
 * ```
 * 
 * @see {@link User}
 * @see {@link updateUser}
 * @see {@link deleteUser}
 * 
 * @public
 */
export async function createUser(data: Omit<User, 'id' | 'createdAt'>): Promise<User> {
  // Implementation
  return {
    id: `usr_${Date.now()}`,
    ...data,
    createdAt: new Date()
  } as User;
}

// ========== DEPRECATED DAN ALTERNATIF ==========

/**
 * Fungsi lama untuk memformat tanggal
 * @deprecated Gunakan {@link formatDateISO} atau {@link formatDateLocale} sebagai gantinya
 * @param date - Tanggal yang akan diformat
 * @returns String tanggal dalam format lama
 * @example
 * ```typescript
 * // ❌ JANGAN GUNAKAN
 * const formatted = oldFormatDate(new Date());
 * 
 * // ✅ GUNAKAN INI
 * const formatted = formatDateISO(new Date());
 * ```
 */
export function oldFormatDate(date: Date): string {
  return `${date.getDate()}/${date.getMonth() + 1}/${date.getFullYear()}`;
}

/**
 * Memformat tanggal ke format ISO (YYYY-MM-DD)
 * @param date - Tanggal yang akan diformat
 * @returns String dalam format YYYY-MM-DD
 */
export function formatDateISO(date: Date): string {
  return date.toISOString().split('T')[0];
}

// ========== TSDOC UNTUK GENERICS ==========

/**
 * Mengambil nilai pertama dari array jika ada
 * @template T - Tipe element dalam array
 * @param array - Array input
 * @returns Element pertama atau undefined jika array kosong
 * @example
 * ```typescript
 * const numbers = [1, 2, 3];
 * const firstNum = first(numbers);  // Tipe: number | undefined
 * 
 * const strings = ['a', 'b'];
 * const firstStr = first(strings);  // Tipe: string | undefined
 * ```
 */
export function first<T>(array: T[]): T | undefined {
  return array[0];
}

/**
 * Fungsi map yang type-safe
 * @template T - Tipe element input
 * @template U - Tipe element output
 * @param array - Array input
 * @param mapper - Fungsi untuk mengubah setiap element
 * @returns Array baru dengan hasil transformasi
 */
export function map<T, U>(array: T[], mapper: (item: T, index: number) => U): U[] {
  return array.map(mapper);
}

  | { success: false; error: E };

// Fungsi untuk hitung diskon
function calculateDiscount(price: number, percent: number): number {
  return price * (percent / 100);
}

// ✅ KOMENTAR BAIK (menggunakan TSDoc)
/**
 * Menghitung nilai diskon dari harga
 * @param price - Harga asli sebelum diskon
 * @param percent - Persentase diskon (0-100)
 * @returns Nilai diskon dalam mata uang
 * @example
 * ```typescript
 * const discount = calculateDiscount(100000, 10);
 * console.log(discount); // 10000
 * ```
 */
function calculateDiscount(price: number, percent: number): number {
  if (percent < 0 || percent > 100) {
    throw new RangeError('Percent must be between 0 and 100');
  }
  return price * (percent / 100);
}

**Kasus Penggunaan Nyata:**
- Dokumentasi otomatis yang muncul di tooltip IDE
- Pengguna library tahu cara menggunakan API tanpa membaca dokumentasi terpisah
- Menjelaskan parameter, return value, dan exceptions dengan jelas
- Memberikan contoh penggunaan langsung di dalam kode
- Mempermudah maintenance karena dokumentasi dekat dengan kode
- Membantu saat refactoring (IDE akan menunjukkan mana yang menggunakan API tersebut)
