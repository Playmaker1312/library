# 204. Project structure untuk library TypeScript

**Definisi Singkat:** Struktur direktori dan file yang direkomendasikan untuk membuat library TypeScript yang maintainable, termasuk pengaturan source, build output, tests, dan dokumentasi.

**Analogi:** Seperti tata letak toko yang baik - pelanggan (pengguna library) tahu di mana mencari barang (exports), dan staf (maintainer) tahu cara mengatur inventaris (source code) dengan rapi.

**Poin-Poin Penting:**
- `src/` - Source code TypeScript
- `dist/` atau `lib/` - Build output (compiled JS + .d.ts)
- `tests/` - Test files
- `examples/` - Contoh penggunaan
- `package.json` - Konfigurasi utama dengan exports field
- `tsconfig.json` - Konfigurasi TypeScript untuk build

**Contoh Kode:**

**Kasus Penggunaan Nyata:**
- Membuat library yang mudah digunakan oleh developer lain
- Struktur yang jelas memudahkan maintainer menemukan kode
- Build output yang benar untuk berbagai module system (CJS, ESM)
- Penerbitan ke npm dengan konfigurasi yang tepat
- Mudah menambahkan fitur baru tanpa merusak struktur yang ada
