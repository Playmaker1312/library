# 185. Setup Node.js dan TypeScript

**Definisi Singkat:** Langkah-langkah mengkonfigurasi project Node.js untuk menggunakan TypeScript, termasuk instalasi dependencies, konfigurasi tsconfig.json, dan setup development workflow.

**Analogi:** Seperti menyiapkan dapur sebelum memasak - Anda mengatur peralatan (dependencies), menyiapkan resep (tsconfig), dan menyiapkan cara memasak (scripts) agar hasilnya konsisten dan enak.

**Poin-Poin Penting:**
- Install `typescript`, `@types/node`, `ts-node`/`tsx` untuk development
- `tsconfig.json` adalah file konfigurasi utama TypeScript
- Gunakan `ts-node` atau `tsx` untuk menjalankan TypeScript langsung
- Untuk production: compile ke JavaScript dengan `tsc`
- Target `ES2020` atau lebih tinggi untuk Node.js modern

**Contoh Kode:**
```typescript
// BENAR: Langkah setup project

// 1. Inisialisasi project
// npm init -y

// 2. Install dependencies
// npm install -D typescript @types/node tsx
// npm install express  // contoh dependency aplikasi

// 3. Buat tsconfig.json
{
  "compilerOptions": {
    "target": "ES2022",           // Node.js 18+ mendukung ES2022
    "module": "NodeNext",         // Module system untuk Node.js
    "moduleResolution": "NodeNext",
    "outDir": "./dist",           // Output compile JS
    "rootDir": "./src",           // Source TS files
    "strict": true,                // Enable semua strict checks
    "esModuleInterop": true,       // Kompatibilitas CommonJS modules
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "declaration": true,           // Generate .d.ts files (jika library)
    "resolveJsonModule": true      // Bisa import .json files
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}

// 4. Setup scripts di package.json
{
  "scripts": {
    "dev": "tsx watch src/index.ts",    // Development dengan auto-reload
    "build": "tsc",                       // Compile ke JS
    "start": "node dist/index.js",        // Jalankan production
    "typecheck": "tsc --noEmit"          // Cek tipe tanpa generate file
  }
}

// 5. Buat file src/index.ts
interface ServerConfig {
  port: number;
  host: string;
}

const config: ServerConfig = {
  port: process.env.PORT ? parseInt(process.env.PORT) : 3000,
  host: 'localhost'
};

console.log(`Server starting at http://${config.host}:${config.port}`);

// 6. Jalankan
// npm run dev    -> Development mode
// npm run build  -> Compile untuk production
// npm start      -> Jalankan hasil compile

// ERROR: Konfigurasi yang menyebabkan masalah
{
  "compilerOptions": {
    "target": "ES3",        // Node.js tidak butuh target serendah ini
    "strict": false,         // Menghilangkan type safety
    "outDir": "./src"       // ❌ Akan menimpa source files!
  }
}
```

**Kasus Penggunaan Nyata:**
- Memulai project backend API dengan type safety
- Menangkap error sebelum runtime saat development
- Membuat kode lebih maintainable untuk tim besar
- Dokumentasi otomatis melalui type definitions
