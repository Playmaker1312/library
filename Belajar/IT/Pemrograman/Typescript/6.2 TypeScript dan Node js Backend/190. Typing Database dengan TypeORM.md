# 190. Typing Database dengan TypeORM

**Definisi Singkat:** Menggunakan TypeORM dengan TypeScript untuk ORM (Object-Relational Mapper) yang type-safe, menghubungkan object TypeScript dengan tabel database.

**Analogi:** Seperti penerjemah antara dua bahasa - TypeORM menerjemahkan object TypeScript (class, interface) ke tabel database dan sebaliknya, memastikan komunikasi yang lancar.

**Poin-Poin Penting:**
- TypeORM menggunakan decorators untuk mendefinisikan entity
- Entity adalah class TypeScript yang dipetakan ke tabel database
- `@Entity()`, `@PrimaryGeneratedColumn()`, `@Column()` adalah decorators umum
- Repository pattern untuk operasi database
- Mendukung MySQL, PostgreSQL, MariaDB, SQLite, SQL Server, Oracle

**Contoh Kode:**
```typescript
// Install
// npm install typeorm reflect-metadata pg  // pg untuk PostgreSQL
// npm install -D @types/node typescript

// tsconfig.json perlu mengaktifkan decorators
// {
//   "compilerOptions": {
//     "emitDecoratorMetadata": true,
//     "experimentalDecorators": true,
//     "strictPropertyInitialization": false  // Agar tidak error pada entity
//   }
// }

import 'reflect-metadata';
import { Entity, PrimaryGeneratedColumn, Column, CreateDateColumn, UpdateDateColumn, OneToMany, ManyToOne, JoinColumn } from 'typeorm';

// BENAR: Mendefinisikan Entity (Tabel Database)
@Entity('users')
export class User {
  @PrimaryGeneratedColumn('uuid')
  id: string;

  @Column({ unique: true })
  email: string;

  @Column()
  name: string;

  @Column({ nullable: true })
  avatar: string;

  @Column({ type: 'varchar', default: 'user' })
  role: 'admin' | 'user';

  @CreateDateColumn()
  createdAt: Date;

  @UpdateDateColumn()
  updatedAt: Date;

  // Relasi One-to-Many
  @OneToMany(() => Post, (post) => post.author)
  posts: Post[];
}

@Entity('posts')
export class Post {
  @PrimaryGeneratedColumn('uuid')
  id: string;

  @Column()
  title: string;

  @Column({ type: 'text' })
  content: string;

  @Column({ default: true })
  isPublished: boolean;

  @CreateDateColumn()
  createdAt: Date;

  // Relasi Many-to-One
  @Column()
  authorId: string;

  @ManyToOne(() => User, (user) => user.posts)
  @JoinColumn({ name: 'authorId' })
  author: User;
}

// BENAR: Konfigurasi DataSource
import { DataSource } from 'typeorm';

const AppDataSource = new DataSource({
  type: 'postgres',
  host: 'localhost',
  port: 5432,
  username: 'postgres',
  password: 'password',
  database: 'myapp',
  entities: [User, Post],  // atau path: 'src/entities/*.ts'
  synchronize: true,  // Auto-create tabel (hanya development!)
  logging: true
});

// Inisialisasi
AppDataSource.initialize()
  .then(() => console.log('Database connected'))
  .catch((error) => console.log(error));

// BENAR: Menggunakan Repository dengan Type Safety
async function userCRUD() {
  const userRepository = AppDataSource.getRepository(User);
  const postRepository = AppDataSource.getRepository(Post);

  // CREATE - Type-safe!
  const newUser = userRepository.create({
    email: 'john@example.com',
    name: 'John Doe',
    role: 'user'
  });
  await userRepository.save(newUser);

  // READ dengan find options
  const users = await userRepository.find({
    where: { role: 'admin' },  // Tipe dicek!
    relations: ['posts'],
    order: { createdAt: 'DESC' }
  });

  const user = await userRepository.findOne({
    where: { id: 'some-uuid' },
    select: ['id', 'name', 'email']  // Hanya kolom tertentu
  });

  // UPDATE
  if (user) {
    user.name = 'Updated Name';  // Type-safe
    await userRepository.save(user);
  }

  // Query Builder dengan type inference
  const posts = await postRepository
    .createQueryBuilder('post')
    .leftJoinAndSelect('post.author', 'author')
    .where('post.isPublished = :isPublished', { isPublished: true })
    .orderBy('post.createdAt', 'DESC')
    .getMany();
}

// ERROR: Properti yang tidak ada pada entity
userRepository.create({
  email: 'test@test.com',
  name: 'Test',
  unknownProperty: 'value'  // Error: Properti tidak ada di User
});
```

**Kasus Penggunaan Nyata:**
- Mapping object TypeScript ke tabel database secara otomatis
- Query database dengan type safety tanpa menulis SQL manual
- Relasi antar tabel yang type-safe (One-to-Many, Many-to-One, dll)
- Migration database yang terkelola dengan baik
