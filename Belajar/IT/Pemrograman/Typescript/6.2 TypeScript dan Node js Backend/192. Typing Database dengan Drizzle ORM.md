# 192. Typing Database dengan Drizzle ORM

**Definisi Singkat:** Drizzle ORM adalah ORM TypeScript modern yang ringan, headless, dan type-safe dengan fokus pada developer experience dan performa tinggi.

**Analogi:** Seperti kendaraan listrik modern - ringan, cepat, dan dirancang dengan teknologi terbaru (TypeScript-first). Drizzle tidak membawa beban tambahan yang tidak perlu.

**Poin-Poin Penting:**
- TypeScript-first, deklarasi schema menggunakan TypeScript (bukan DSL khusus)
- `drizzle-orm` untuk runtime, `drizzle-kit` untuk migrations
- Query builder yang sangat type-safe
- Tidak ada magic, Anda punya kontrol penuh
- Mendukung PostgreSQL, MySQL, SQLite

**Contoh Kode:**
```typescript
// Install
// npm install drizzle-orm pg
// npm install -D drizzle-kit @types/pg typescript

// BENAR: Schema Drizzle (TypeScript biasa!)
// File: src/db/schema.ts
import { pgTable, text, varchar, boolean, timestamp, uuid, foreignKey } from 'drizzle-orm/pg-core';
import { relations } from 'drizzle-orm';

export const users = pgTable('users', {
  id: uuid('id').defaultRandom().primaryKey(),
  email: varchar('email', { length: 255 }).unique().notNull(),
  name: varchar('name', { length: 255 }).notNull(),
  avatar: text('avatar'),
  role: varchar('role', { length: 20 }).default('user').notNull(),
  createdAt: timestamp('created_at').defaultNow().notNull(),
  updatedAt: timestamp('updated_at').defaultNow().notNull()
});

export const posts = pgTable('posts', {
  id: uuid('id').defaultRandom().primaryKey(),
  title: varchar('title', { length: 500 }).notNull(),
  content: text('content').notNull(),
  isPublished: boolean('is_published').default(true).notNull(),
  authorId: uuid('author_id').notNull().references(() => users.id),
  createdAt: timestamp('created_at').defaultNow().notNull()
});

// Definisikan relasi
export const usersRelations = relations(users, ({ many }) => ({
  posts: many(posts)
}));

export const postsRelations = relations(posts, ({ one }) => ({
  author: one(users, {
    fields: [posts.authorId],
    references: [users.id]
  })
}));

// Infer tipe dari schema
export type User = typeof users.$inferSelect;  // Tipe untuk SELECT
export type NewUser = typeof users.$inferInsert;  // Tipe untuk INSERT

export type Post = typeof posts.$inferSelect;
export type NewPost = typeof posts.$inferInsert;

// BENAR: Koneksi Database
import { Pool } from 'pg';
import { drizzle } from 'drizzle-orm/node-postgres';

const pool = new Pool({
  connectionString: process.env.DATABASE_URL
});

export const db = drizzle(pool, { schema: { users, posts } });

// BENAR: Operasi CRUD - Type-safe!
import { eq, like, desc, and, sql } from 'drizzle-orm';

// CREATE
async function createUser(data: NewUser): Promise<User> {
  const [newUser] = await db.insert(users).values(data).returning();
  return newUser;
}

// READ - find many
async function getAllUsers(): Promise<User[]> {
  return db.select().from(users).orderBy(desc(users.createdAt));
}

// READ - find one
async function getUserById(id: string): Promise<User | undefined> {
  const result = await db.select().from(users).where(eq(users.id, id)).limit(1);
  return result[0];
}

// READ dengan filter
async function searchUsers(query: string): Promise<User[]> {
  return db
    .select()
    .from(users)
    .where(
      and(
        eq(users.role, 'user'),
        like(users.name, `%${query}%`)
      )
    );
}

// READ dengan joins (relasi)
async function getPostsWithAuthors() {
  return db
    .select({
      postId: posts.id,
      title: posts.title,
      authorName: users.name,
      authorEmail: users.email
    })
    .from(posts)
    .leftJoin(users, eq(posts.authorId, users.id))
    .where(eq(posts.isPublished, true))
    .orderBy(desc(posts.createdAt));
}

// UPDATE
async function updateUser(id: string, data: Partial<NewUser>) {
  const [updated] = await db
    .update(users)
    .set({ ...data, updatedAt: new Date() })
    .where(eq(users.id, id))
    .returning();
  return updated;
}

// DELETE
async function deleteUser(id: string) {
  await db.delete(users).where(eq(users.id, id));
}

// BENAR: Query dengan SQL template (type-safe!)
async function getStats() {
  const result = await db.select({
    userCount: sql<number>`count(*)`.mapWith(Number),
    avgPosts: sql<number>`avg((
      select count(*) from posts where posts.author_id = users.id
    ))`.mapWith(Number)
  }).from(users);
  return result[0];
}

// ERROR: Type safety in action
db.select().from(users).where(
  eq(users.nonexistentColumn, 'value')  // Error: Column tidak ada!
);

db.insert(users).values({
  email: 123,  // Error: email harus string
  name: null   // Error: name tidak boleh null
});
```

**Kasus Penggunaan Nyata:**
- ORM yang ringan dan cepat tanpa overhead
- Full control atas query SQL yang dihasilkan
- Type safety tingkat ekstrem untuk semua operasi
- Schema didefinisikan dengan TypeScript biasa (no learning curve baru)
- Migrations yang fleksibel dengan drizzle-kit
