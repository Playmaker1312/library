# 188. TypeScript dan Fastify

**Definisi Singkat:** Menggunakan TypeScript dengan Fastify, framework web Node.js yang cepat dan secara native mendukung TypeScript dengan schema-based validation.

**Analogi:** Seperti mobil balap dengan GPS - Fastify adalah mobilnya (cepat), TypeScript adalah GPSnya (panduan arah yang akurat), dan schema validation adalah rambu lalu lintasnya (memastikan aman).

**Poin-Poin Penting:**
- Fastify memiliki dukungan TypeScript yang sangat baik secara native
- Gunakan `@fastify/type-provider-json-schema-to-ts` untuk type inference dari schema
- Route schema mendefinisikan validasi dan tipe sekaligus
- `FastifyInstance`, `FastifyRequest`, `FastifyReply` untuk tipe dasar
- Plugin system dapat di-extend dengan types

**Contoh Kode:**
```typescript
// Install
// npm install fastify @fastify/type-provider-json-schema-to-ts
// npm install -D typescript @types/node

import fastify, { FastifyInstance, FastifyRequest, FastifyReply } from 'fastify';
import { JsonSchemaToTsProvider } from '@fastify/type-provider-json-schema-to-ts';

const app: FastifyInstance = fastify({ logger: true });

// Gunakan Type Provider untuk inferensi tipe otomatis dari schema
const server = app.withTypeProvider<JsonSchemaToTsProvider>();

// BENAR: Route dengan schema dan inferred types
server.post('/api/users', {
  schema: {
    body: {
      type: 'object',
      required: ['name', 'email'],
      properties: {
        name: { type: 'string' },
        email: { type: 'string', format: 'email' },
        age: { type: 'number', minimum: 0 }
      }
    } as const,  // 'as const' penting untuk type inference
    response: {
      201: {
        type: 'object',
        properties: {
          id: { type: 'string' },
          name: { type: 'string' },
          email: { type: 'string' }
        }
      }
    } as const
  }
}, async (request, reply) => {
  // request.body memiliki tipe yang di-infer dari schema!
  const { name, email, age } = request.body;
  // name: string, email: string, age: number | undefined
  
  // Validasi OTOMATIS oleh Fastify berdasarkan schema
  // Jika body tidak sesuai, Fastify mengembalikan 400 error otomatis
  
  return reply.status(201).send({
    id: 'user_' + Date.now(),
    name,
    email
  });
});

// BENAR: Route dengan params dan query
server.get('/api/users/:id', {
  schema: {
    params: {
      type: 'object',
      required: ['id'],
      properties: {
        id: { type: 'string' }
      }
    } as const,
    querystring: {
      type: 'object',
      properties: {
        fields: { type: 'string' },
        include: { type: 'array', items: { type: 'string' } }
      }
    } as const,
    response: {
      200: {
        type: 'object',
        properties: {
          id: { type: 'string' },
          name: { type: 'string' },
          email: { type: 'string' }
        }
      }
    } as const
  }
}, async (request, reply) => {
  const { id } = request.params;           // Tipe: string
  const { fields, include } = request.query;
  // fields: string | undefined, include: string[] | undefined
  
  return { id, name: 'John', email: 'john@example.com' };
});

// BENAR: Extending Fastify dengan types untuk plugin
// File: src/types/fastify.d.ts
import 'fastify';

declare module 'fastify' {
  interface FastifyInstance {
    authenticate: (request: FastifyRequest, reply: FastifyReply) => Promise<void>;
  }
  
  interface FastifyRequest {
    userId: string;
  }
}

// Sekarang bisa digunakan
server.decorate('authenticate', async (request: FastifyRequest, reply: FastifyReply) => {
  // Logic autentikasi
  request.userId = 'user_123';
});

// ERROR: Mengirim data yang tidak sesuai schema
// Jika request POST /api/users dengan body:
// { "name": 123, "email": "not-an-email" }
// Fastify akan otomatis mengembalikan error 400!
```

**Kasus Penggunaan Nyata:**
- API dengan performa tinggi dan type safety
- Validasi request otomatis berdasarkan schema
- Inferensi tipe otomatis tanpa perlu menulis interface manual
- Dokumentasi API otomatis dari schema (dengan plugin tambahan)
