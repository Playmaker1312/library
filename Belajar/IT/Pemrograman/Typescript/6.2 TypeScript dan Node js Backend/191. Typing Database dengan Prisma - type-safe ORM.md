# 191. Typing Database dengan Prisma - type-safe ORM

**Definisi Singkat:** Prisma ORM dengan TypeScript yang menyediakan type-safety level ekstrem melalui generated client, auto-completion, dan validasi compile-time untuk semua operasi database.

**Analogi:** Seperti asisten pribadi yang tahu semua detail inventaris - Prisma tahu struktur database Anda dan hanya mengizinkan operasi yang valid, memberikan saran saat Anda mengetik.

**Poin-Poin Penting:**
- Prisma Schema adalah sumber kebenaran tunggal (`schema.prisma`)
- `prisma generate` membuat Prisma Client dengan tipe yang sesuai schema
- Semua operasi database 100% type-safe
- Auto-completion untuk semua field, relation, dan filter
- `include` dan `select` untuk memuat relasi dengan tipe yang dinamis

**Contoh Kode:**
```typescript
// Install Prisma
// npm install prisma @prisma/client
// npx prisma init

// BENAR: Schema Prisma (prisma/schema.prisma)
// generator client {
//   provider = "prisma-client-js"
// }
// 
// datasource db {
//   provider = "postgresql"
//   url      = env("DATABASE_URL")
// }
// 
// model User {
//   id        String   @id @default(uuid())
//   email     String   @unique
//   name      String
//   avatar    String?
//   role      Role     @default(USER)
//   posts     Post[]
//   createdAt DateTime @default(now())
//   updatedAt DateTime @updatedAt
// }
// 
// model Post {
//   id          String  @id @default(uuid())
//   title       String
//   content     String
//   isPublished Boolean @default(true)
//   author      User    @relation(fields: [authorId], references: [id])
//   authorId    String
//   createdAt   DateTime @default(now())
// }
// 
// enum Role {
//   USER
//   ADMIN
// }

// Setelah mengubah schema, jalankan:
// npx prisma migrate dev --name init  // Membuat tabel
// npx prisma generate  // Generate Prisma Client dengan types

// BENAR: Menggunakan Prisma Client
import { PrismaClient, User, Post, Role } from '@prisma/client';

const prisma = new PrismaClient();

// CREATE - Type-safe!
async function createUser() {
  const user = await prisma.user.create({
    data: {
      email: 'john@example.com',
      name: 'John Doe',
      role: Role.USER  // Role enum, autocomplete tersedia!
    }
  });
  // user bertipe User dengan semua field
}

// READ dengan select - tipe disesuaikan
async function getUserBasic() {
  const user = await prisma.user.findUnique({
    where: { id: 'user-uuid' },
    select: {
      id: true,
      name: true,
      email: true
    }
  });
  // user bertipe: { id: string; name: string; email: string; } | null
}

// READ dengan include - relasi termuat dengan tipe benar
async function getUserWithPosts() {
  const user = await prisma.user.findUnique({
    where: { email: 'john@example.com' },
    include: {
      posts: {
        where: { isPublished: true },
        orderBy: { createdAt: 'desc' }
      }
    }
  });
  // user.posts bertipe Post[] dengan isPublished = true
}

// UPDATE
async function updateUser(id: string) {
  const updated = await prisma.user.update({
    where: { id },
    data: {
      name: 'Updated Name',
      avatar: 'new-avatar.png'
    }
  });
}

// DELETE
async function deleteUser(id: string) {
  const deleted = await prisma.user.delete({
    where: { id }
  });
}

// BENAR: Query kompleks dengan type-safe filtering
async function getFilteredPosts() {
  const posts = await prisma.post.findMany({
    where: {
      isPublished: true,
      title: {
        contains: 'TypeScript',  // Autocomplete untuk filter ops!
        mode: 'insensitive'
      }
    },
    include: {
      author: {
        select: { name: true, email: true }
      }
    },
    orderBy: { createdAt: 'desc' },
    skip: 0,
    take: 10
  });
  // posts bertipe: (Post & { author: { name: string; email: string } })[]
}

// BENAR: Transaction
async function createUserAndPost() {
  const [user, post] = await prisma.$transaction([
    prisma.user.create({
      data: { email: 'new@example.com', name: 'New User', role: 'USER' }
    }),
    prisma.post.create({
      data: {
        title: 'Hello World',
        content: 'First post',
        author: { connect: { email: 'new@example.com' } }
      }
    })
  ]);
}

// ERROR: Operasi yang tidak valid akan ditangkap compile-time
prisma.user.create({
  data: {
    email: 'test@test.com',
    name: 'Test',
    role: 'INVALID_ROLE',  // Error: harus Role.USER atau Role.ADMIN
    nonexistentField: 'x'  // Error: field tidak ada
  }
});

prisma.user.findUnique({
  where: { nonexistentKey: 'value' }  // Error: bukan field unique
});
```

**Kasus Penggunaan Nyata:**
- Type safety 100% untuk semua operasi database
- Auto-completion yang luar biasa di IDE
- Tidak perlu menulis interface/model manual (di-generate dari schema)
- Refactoring schema aman - TypeScript akan memberitahu semua yang berubah
