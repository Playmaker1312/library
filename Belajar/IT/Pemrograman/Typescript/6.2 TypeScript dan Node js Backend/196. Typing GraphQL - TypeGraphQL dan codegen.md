# 196. Typing GraphQL - TypeGraphQL dan codegen

**Definisi Singkat:** Menggunakan TypeScript dengan GraphQL melalui TypeGraphQL (code-first) atau GraphQL Code Generator (schema-first) untuk mendapatkan type safety antara schema GraphQL dan kode TypeScript.

**Analogi:** Seperti kontrak antara dua perusahaan - schema GraphQL adalah kontraknya, dan TypeGraphQL/Codegen memastikan kedua pihak (server dan client) mematuhi kontrak tersebut dengan tipe yang benar.

**Poin-Poin Penting:**
- Code-first (TypeGraphQL): Tulis TypeScript, schema di-generate otomatis
- Schema-first: Tulis GraphQL SDL, types di-generate dengan codegen
- TypeGraphQL menggunakan decorators untuk mendefinisikan schema
- GraphQL Code Generator mendukung berbagai output (TypeScript, React Apollo, dll)
- End-to-end type safety dari database ke client

**Contoh Kode:**
```typescript
// ========== CODE-FIRST dengan TypeGraphQL ==========
// Install: npm install type-graphql graphql reflect-metadata class-validator
// npm install apollo-server

import 'reflect-metadata';
import { ObjectType, Field, ID, InputType, Query, Mutation, Resolver, Arg } from 'type-graphql';
import { ApolloServer } from 'apollo-server';

// BENAR: ObjectType - mendefinisikan GraphQL type
@ObjectType({ description: 'A user of the application' })
export class User {
  @Field(() => ID)
  id: string;

  @Field()
  name: string;

  @Field()
  email: string;

  @Field({ nullable: true })
  avatar?: string;

  @Field(() => [Post])
  posts: Post[];

  @Field()
  createdAt: Date;
}

@ObjectType()
export class Post {
  @Field(() => ID)
  id: string;

  @Field()
  title: string;

  @Field()
  content: string;

  @Field()
  isPublished: boolean;

  @Field(() => User)
  author: User;

  @Field()
  createdAt: Date;
}

// BENAR: InputType - untuk mutation inputs
@InputType()
export class CreateUserInput {
  @Field()
  name: string;

  @Field()
  email: string;

  @Field({ nullable: true })
  avatar?: string;
}

@InputType()
export class UpdateUserInput {
  @Field({ nullable: true })
  name?: string;

  @Field({ nullable: true })
  email?: string;

  @Field({ nullable: true })
  avatar?: string;
}

// BENAR: Resolver dengan type-safe
@Resolver(() => User)
export class UserResolver {
  private users: User[] = [
    { id: '1', name: 'John Doe', email: 'john@example.com', posts: [], createdAt: new Date() }
  ];

  @Query(() => [User], { description: 'Get all users' })
  async users(): Promise<User[]> {
    return this.users;
  }

  @Query(() => User, { nullable: true, description: 'Get user by ID' })
  async user(
    @Arg('id', () => ID) id: string
  ): Promise<User | undefined> {
    return this.users.find(u => u.id === id);
  }

  @Mutation(() => User, { description: 'Create a new user' })
  async createUser(
    @Arg('input') input: CreateUserInput
  ): Promise<User> {
    const newUser: User = {
      id: String(Date.now()),
      ...input,
      posts: [],
      createdAt: new Date()
    };
    this.users.push(newUser);
    return newUser;
  }

  @Mutation(() => User, { description: 'Update a user' })
  async updateUser(
    @Arg('id', () => ID) id: string,
    @Arg('input') input: UpdateUserInput
  ): Promise<User> {
    const index = this.users.findIndex(u => u.id === id);
    if (index === -1) throw new Error('User not found');
    
    this.users[index] = { ...this.users[index], ...input };
    return this.users[index];
  }

  @Mutation(() => Boolean, { description: 'Delete a user' })
  async deleteUser(
    @Arg('id', () => ID) id: string
  ): Promise<boolean> {
    const index = this.users.findIndex(u => u.id === id);
    if (index === -1) throw new Error('User not found');
    
    this.users.splice(index, 1);
    return true;
  }
}

// Build schema dan jalankan server
async function bootstrap() {
  const schema = await buildSchema({
    resolvers: [UserResolver],
    emitSchemaFile: true  // Generate schema.graphql file
  });

  const server = new ApolloServer({ schema });
  const { url } = await server.listen({ port: 4000 });
  console.log(`GraphQL server ready at ${url}`);
}
```

**Kasus Penggunaan Nyata:**
- End-to-end type safety dari database ke frontend
- Auto-completion untuk queries, mutations, dan resolvers
- Tidak ada lagi mismatch antara schema dan implementasi
- Refactoring schema akan memunculkan error di semua tempat penggunaan
- Client dapat menggunakan tipe yang sama dengan server (dengan codegen)
