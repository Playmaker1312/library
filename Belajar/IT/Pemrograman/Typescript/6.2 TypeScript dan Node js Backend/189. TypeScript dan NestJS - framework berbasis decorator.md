# 189. TypeScript dan NestJS - framework berbasis decorator

**Definisi Singkat:** Menggunakan TypeScript dengan NestJS, framework Node.js berbasis modular dan dependency injection yang dirancang khusus untuk TypeScript.

**Analogi:** Seperti konstruksi gedung bertingkat - NestJS adalah arsitek yang menentukan struktur (modular), TypeScript adalah material berkualitas, dan decorator adalah instruksi perakitan yang jelas.

**Poin-Poin Penting:**
- NestJS dibangun untuk TypeScript dari awal
- Menggunakan decorators untuk mendefinisikan controller, service, module
- Dependency injection built-in dengan type safety
- CLI untuk generate komponen dengan boilerplate TypeScript
- Mendukung Express dan Fastify sebagai underlying HTTP platform

**Contoh Kode:**
```typescript
// Install NestJS CLI
// npm i -g @nestjs/cli
// nest new project-name  // Otomatis setup TypeScript

// BENAR: Membuat Controller dengan decorators
import { Controller, Get, Post, Body, Param, Put, Delete, HttpStatus, HttpCode } from '@nestjs/common';
import { UsersService } from './users.service';
import { CreateUserDto, UpdateUserDto, UserResponseDto } from './dto/users.dto';

@Controller('api/users')
export class UsersController {
  constructor(private readonly usersService: UsersService) {}

  @Post()
  @HttpCode(HttpStatus.CREATED)
  async create(@Body() createUserDto: CreateUserDto): Promise<UserResponseDto> {
    return this.usersService.create(createUserDto);
  }

  @Get()
  async findAll(): Promise<UserResponseDto[]> {
    return this.usersService.findAll();
  }

  @Get(':id')
  async findOne(@Param('id') id: string): Promise<UserResponseDto> {
    return this.usersService.findOne(id);
  }

  @Put(':id')
  async update(
    @Param('id') id: string,
    @Body() updateUserDto: UpdateUserDto
  ): Promise<UserResponseDto> {
    return this.usersService.update(id, updateUserDto);
  }

  @Delete(':id')
  @HttpCode(HttpStatus.NO_CONTENT)
  async remove(@Param('id') id: string): Promise<void> {
    return this.usersService.remove(id);
  }
}

// BENAR: DTO (Data Transfer Object) dengan class-validator
import { IsString, IsEmail, IsOptional, IsNumber, Min } from 'class-validator';
import { PartialType } from '@nestjs/mapped-types';

export class CreateUserDto {
  @IsString()
  name: string;

  @IsEmail()
  email: string;

  @IsOptional()
  @IsNumber()
  @Min(0)
  age?: number;
}

// PartialType membuat semua field menjadi optional
export class UpdateUserDto extends PartialType(CreateUserDto) {}

// Response DTO
export class UserResponseDto {
  id: string;
  name: string;
  email: string;
  createdAt: Date;
}

// BENAR: Service dengan dependency injection
import { Injectable, NotFoundException } from '@nestjs/common';
import { CreateUserDto, UpdateUserDto, UserResponseDto } from './dto/users.dto';

@Injectable()
export class UsersService {
  private users: UserResponseDto[] = [];

  async create(createUserDto: CreateUserDto): Promise<UserResponseDto> {
    const user: UserResponseDto = {
      id: `user_${Date.now()}`,
      name: createUserDto.name,
      email: createUserDto.email,
      createdAt: new Date()
    };
    this.users.push(user);
    return user;
  }

  async findAll(): Promise<UserResponseDto[]> {
    return this.users;
  }

  async findOne(id: string): Promise<UserResponseDto> {
    const user = this.users.find(u => u.id === id);
    if (!user) {
      throw new NotFoundException(`User with id ${id} not found`);
    }
    return user;
  }

  async update(id: string, updateUserDto: UpdateUserDto): Promise<UserResponseDto> {
    const index = this.users.findIndex(u => u.id === id);
    if (index === -1) {
      throw new NotFoundException(`User with id ${id} not found`);
    }
    this.users[index] = { ...this.users[index], ...updateUserDto };
    return this.users[index];
  }

  async remove(id: string): Promise<void> {
    const index = this.users.findIndex(u => u.id === id);
    if (index === -1) {
      throw new NotFoundException(`User with id ${id} not found`);
    }
    this.users.splice(index, 1);
  }
}

// BENAR: Module untuk mengorganisir komponen
import { Module } from '@nestjs/common';
import { UsersController } from './users.controller';
import { UsersService } from './users.service';

@Module({
  controllers: [UsersController],
  providers: [UsersService],
  exports: [UsersService]  // Jika ingin digunakan di module lain
})
export class UsersModule {}
```

**Kasus Penggunaan Nyata:**
- Membangun aplikasi enterprise dengan arsitektur yang bersih dan terstruktur
- Dependency injection untuk testing yang mudah
- Validasi otomatis DTO dengan class-validator
- Skalabilitas tinggi dengan modular architecture
