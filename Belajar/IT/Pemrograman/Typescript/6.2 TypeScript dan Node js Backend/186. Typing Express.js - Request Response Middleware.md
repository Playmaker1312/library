# 186. Typing Express.js - Request Response Middleware

**Definisi Singkat:** Cara men-tipe komponen utama Express.js seperti Request, Response, dan Middleware untuk mendapatkan type safety saat membangun API.

**Analogi:** Seperti petugas bandara - Request adalah penumpang dengan dokumen (params, body, query), Response adalah petugas yang memeriksa dokumen dan memberikan output, Middleware adalah security check sebelum masuk ke pesawat.

**Poin-Poin Penting:**
- Install `@types/express` untuk type definitions
- `Express.Request` bisa di-extend untuk menambahkan properti custom
- `Request<Params, ResBody, ReqBody, Query>` - generic parameters
- Middleware: `(req, res, next) => void` dengan tipe yang sesuai
- `NextFunction` untuk parameter next middleware

**Contoh Kode:**
```typescript
// Install dependencies
// npm install express
// npm install -D @types/express @types/node

import express, { Request, Response, NextFunction, Express } from 'express';

const app: Express = express();
app.use(express.json());

// BENAR: Typing route handler sederhana
interface UserParams {
  id: string;
}

interface UserQuery {
  fields?: string;
  include?: string;
}

interface UserRequestBody {
  name: string;
  email: string;
}

interface UserResponse {
  id: string;
  name: string;
  email: string;
  createdAt: Date;
}

// Generic: Request<Params, ResBody, ReqBody, Query>
app.get('/users/:id', (
  req: Request<UserParams, UserResponse, never, UserQuery>,
  res: Response<UserResponse>
) => {
  const userId = req.params.id;        // Tipe: string
  const fields = req.query.fields;     // Tipe: string | undefined
  
  // req.body akan error karena generic ke-3 adalah 'never'
  
  res.json({
    id: userId,
    name: 'John Doe',
    email: 'john@example.com',
    createdAt: new Date()
  });
});

// BENAR: Middleware dengan tipe
interface AuthRequest extends Request {
  userId?: string;
  userRole?: 'admin' | 'user';
}

function authMiddleware(
  req: AuthRequest,
  res: Response,
  next: NextFunction
) {
  const authHeader = req.headers.authorization;
  
  if (!authHeader || !authHeader.startsWith('Bearer ')) {
    return res.status(401).json({ error: 'Unauthorized' });
  }
  
  // Verifikasi token...
  req.userId = 'user_123';      // Properti custom
  req.userRole = 'admin';        // Properti custom
  
  next();
}

// Menggunakan middleware yang memperluas Request
app.get('/protected', authMiddleware, (req: AuthRequest, res: Response) => {
  res.json({ 
    userId: req.userId,      // Tipe: string | undefined
    role: req.userRole       // Tipe: 'admin' | 'user' | undefined
  });
});

// BENAR: Extending Request secara global (module augmentation)
// File: src/types/express.d.ts
declare global {
  namespace Express {
    interface Request {
      userId: string;        // Sekarang semua Request punya userId
      userRole: 'admin' | 'user';
    }
  }
}

export {};  // Required untuk module augmentation

// Sekarang tidak butuh AuthRequest lagi
app.get('/api/users', (req, res) => {
  console.log(req.userId);    // Tersedia secara global
});

// ERROR: Mengakses properti yang tidak ada
app.get('/', (req, res) => {
  req.nonexistentProperty;    // Error: Properti tidak ada
  res.send(req.body.unknown);  // Tidak aman tanpa tipe
});
```

**Kasus Penggunaan Nyata:**
- Membuat API endpoint dengan validasi tipe untuk request body/params
- Menambahkan properti custom ke Request (user auth, dll)
- Middleware yang type-safe dan reusable
- Menghindari bug karena mengakses properti yang tidak ada pada request/response
