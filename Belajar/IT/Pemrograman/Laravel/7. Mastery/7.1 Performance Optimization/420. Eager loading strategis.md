# 420. Eager Loading Strategis

## Definisi Singkat
Teknik memuat relasi Eloquent secara proaktif dengan strategi yang tepat — tidak hanya sekadar `with()`, tapi mempertimbangkan mana yang perlu di-load dan kapan.

## Analogi
Seperti belanja bulanan — lebih efisien beli semua kebutuhan sekali jalan daripada bolak-balik ke tolo setiap kali butuh satu barang.

## Poin-Poin Penting
- `with()` untuk eager loading standar
- `load()` untuk eager loading setelah query utama
- `withCount()` / `loadCount()` untuk agregat
- `withExists()` untuk cek keberadaan relasi
- Hanya load relasi yang benar-benar digunakan
- Gunakan `constrain()` untuk filter saat load

## Contoh Kode
```php
// Eager loading dengan kondisi
$users = User::with(['posts' => function ($query) {
    $query->where('published', true)
          ->orderBy('created_at', 'desc')
          ->limit(5);
}])->get();

// WithCount dengan kondisi
$categories = Category::withCount(['products' => function ($query) {
    $query->where('stock', '>', 0);
}])->get();

// Lazy eager loading dengan kondisi
$orders = Order::all();
$orders->load(['items' => function ($query) {
    $query->where('quantity', '>', 1);
}]);

// Nested eager loading selektif
$courses = Course::with([
    'chapters' => fn($q) => $q->orderBy('order'),
    'chapters.lessons' => fn($q) => $q->where('published', true),
    'instructor' => fn($q) => $q->select('id', 'name', 'avatar'),
])->get();

// Cek keberadaan relasi
$posts = Post::withExists('comments')->get();
// $post->comments_exists (boolean)
```

## Kasus Penggunaan Nyata
Halaman course dengan 20 kelas — setiap kelas punya bab dan pelajaran. Eager loading nested dengan kondisi `published` mengurangi query dari 60+ menjadi 3 query.
