# 418. Laravel Telescope Monitoring

## Definisi Singkat
Debugging assistant untuk Laravel yang menyediakan insight real-time tentang request, exceptions, queries, jobs, mail, notifications, cache, dan scheduled tasks.

## Analogi
Seperti CCTV untuk aplikasi — merekam semua aktivitas sehingga kita bisa memutar ulang dan menganalisis masalah.

## Poin-Poin Penting
- Dashboard UI yang intuitif di `/telescope`
- Mirip Debugbar tapi lebih cocok untuk production
- Data disimpan ke database (watchlist)
- Filter berdasarkan tipe (requests, queries, exceptions)
- Bisa dikonfigurasi pruning data otomatis

## Contoh Kode
```php
// Install
composer require laravel/telescope

// Publish migration dan assets
php artisan telescope:install
php artisan migrate

// Konfigurasi config/telescope.php
return [
    'path' => 'telescope',
    'enabled' => env('TELESCOPE_ENABLED', true),
    'storage' => [
        'database' => [
            'connection' => env('DB_CONNECTION', 'mysql'),
            'chunk' => 100,
        ],
    ],
    'prune' => [
        'hours' => 48, // hapus data lebih dari 48 jam
    ],
    'only' => [
        // Hanya rekam tipe tertentu
        // Telescope::ONLY_REQUESTS,
        // Telescope::ONLY_QUERIES,
    ],
];

// Filter telescope di AppServiceProvider
Telescope::filter(function (IncomingEntry $entry) {
    return !$entry->isFailedRequest() &&
           !$entry->isFailedJob();
});
```

## Kasus Penggunaan Nyata
Production API tiba-tiba lambat — Telescope menunjukkan ada job queue gagal berulang kali yang membebani database.
