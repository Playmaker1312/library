# 422. Query Builder Query Kompleks

## Definisi Singkat
Penggunaan Laravel Query Builder untuk membuat query SQL kompleks seperti subquery, union, conditional aggregation, dan window functions tanpa raw SQL.

## Analogi
Seperti merangkai pipa-pipa modular — setiap method adalah komponen yang bisa digabung untuk membangun sistem aliran data yang rumit.

## Poin-Poin Penting
- Query Builder lebih cepat dari Eloquent untuk query kompleks
- Gunakan `DB::raw()` untuk ekspresi khusus
- `whereIn`, `whereBetween`, `whereExists` untuk filter lanjutan
- `havingRaw()`, `orderByRaw()` untuk agregasi
- Subquery di SELECT, FROM, JOIN

## Contoh Kode
```php
// Subquery di SELECT
$users = DB::table('users')
    ->select('users.*')
    ->selectSub(function ($query) {
        $query->from('orders')
              ->selectRaw('COUNT(*)')
              ->whereColumn('user_id', 'users.id')
              ->where('status', 'completed');
    }, 'completed_orders_count')
    ->get();

// Subquery di FROM
$latestPosts = DB::table('posts')
    ->select('user_id', DB::raw('MAX(created_at) as latest'))
    ->groupBy('user_id');

$users = DB::table('users')
    ->joinSub($latestPosts, 'latest_posts', function ($join) {
        $join->on('users.id', '=', 'latest_posts.user_id');
    })
    ->get();

// UNION query
$first = DB::table('users')->where('type', 'admin');
$second = DB::table('users')->where('type', 'moderator');
$users = $first->union($second)->get();

// Conditional aggregations
$stats = DB::table('orders')
    ->select(
        DB::raw('COUNT(*) as total_orders'),
        DB::raw('SUM(CASE WHEN status = "completed" THEN total ELSE 0 END) as revenue'),
        DB::raw('AVG(total) as avg_order_value')
    )
    ->whereBetween('created_at', [$start, $end])
    ->first();

// Window function (PostgreSQL/MySQL 8+)
$users = DB::table('orders')
    ->select(
        'user_id',
        'total',
        DB::raw('ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY total DESC) as rn')
    )
    ->get();
```

## Kasus Penggunaan Nyata
Laporan keuangan membutuhkan data penjualan per bulan dengan subtotal, rata-rata, dan pertumbuhan month-over-month — semua dalam satu query kompleks menggunakan Query Builder.
