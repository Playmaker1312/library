# 417. Laravel Debugbar

## Definisi Singkat
Package debugging visual untuk Laravel yang menampilkan waktu eksekusi, query database, memory usage, request data, dan informasi performa lainnya di browser.

## Analogi
Seperti dashboard mobil yang menunjukkan kecepatan, RPM, suhu mesin — memberi visibilitas penuh tentang kondisi aplikasi.

## Poin-Poin Penting
- Install via Composer: `barryvdh/laravel-debugbar`
- Otomatis aktif di environment `local`
- Nonaktifkan di production via `APP_DEBUG=false`
- Bisa dikustomisasi collector yang ditampilkan
- Mendukung Ajax requests profiling

## Contoh Kode
```php
// Install
composer require barryvdh/laravel-debugbar --dev

// Konfigurasi config/debugbar.php
return [
    'enabled' => env('DEBUGBAR_ENABLED', false),
    'except' => [
        'telescope*',
        'horizon*',
    ],
    'collectors' => [
        'phpinfo' => false,
        'messages' => true,
        'time' => true,
        'queries' => true,
        'view' => true,
        'route' => true,
        'log' => true,
    ],
];

// Menambahkan data manual
Debugbar::info($user);
Debugbar::warning('Watch out...');
Debugbar::error('Error!');
Debugbar::measure('Proses berat', function () {
    // kode yang diukur
});
```

## Kasus Penggunaan Nyata
Developer melihat ada 200 query di halaman dashboard — dengan Debugbar langsung terlihat query mana yang redundan dan bisa di-eager loading.
