# 425. Optimasi Asset Vite CDN

## Definisi Singkat
Strategi mengoptimasi file statis (CSS, JS, gambar) menggunakan Vite sebagai bundler, dikombinasikan dengan CDN untuk delivery cepat ke pengguna.

## Analogi
Seperti toko buku — Vite merapikan dan mengepak buku-buku (asset), CDN seperti kurir yang menempatkan buku di gudang-gudang di berbagai kota agar pembeli bisa ambil dekat rumah.

## Poin-Poin Penting
- Vite sebagai default bundler Laravel 9+
- Minifikasi otomatis di production
- Code splitting untuk load per halaman
- CDN untuk distribusi global
- Cache busting via version hash

## Contoh Kode
```php
// vite.config.js
import { defineConfig } from 'vite';
import laravel from 'laravel-vite-plugin';

export default defineConfig({
    plugins: [
        laravel({
            input: [
                'resources/css/app.css',
                'resources/js/app.js',
            ],
            refresh: true,
        }),
    ],
    build: {
        rollupOptions: {
            output: {
                manualChunks: {
                    vendor: ['lodash', 'axios'],
                    alpine: ['alpinejs'],
                },
            },
        },
        minify: 'terser',
        cssMinify: true,
    },
});

// Blade dengan CDN
@php
    $manifest = json_decode(file_get_contents(public_path('build/manifest.json')), true);
    $version = $manifest['resources/js/app.js']['hash'] ?? '';
@endphp

<script src="https://cdn.example.com/build/assets/app-{{ $version }}.js"></script>

// .env untuk asset URL
ASSET_URL=https://cdn.example.com

// config/filesystems.php — CDN disk
'disks' => [
    'cdn' => [
        'driver' => 's3',
        'key' => env('AWS_ACCESS_KEY_ID'),
        'secret' => env('AWS_SECRET_ACCESS_KEY'),
        'region' => env('AWS_DEFAULT_REGION'),
        'bucket' => env('AWS_BUCKET'),
        'url' => env('CDN_URL'),
    ],
],

// Deploy asset ke CDN
php artisan vendor:publish --tag=public --force
// Upload folder build ke CDN via script CI/CD

// Vite dengan CDN di production
// .env production
VITE_ASSET_URL=https://cdn.example.com
```

## Kasus Penggunaan Nyata
Situs e-commerce global — asset JS/CSS di-load dari CDN server terdekat (Singapore untuk Asia, Frankfurt untuk Eropa) mengurangi latency dari 200ms ke 30ms.
