# 429. Optimasi Autoloading Composer Production

## Definisi Singkat
Konfigurasi Composer autoloader untuk environment production agar mapping class lebih cepat dengan mengoptimalkan dump autoload.

## Analogi
Seperti daftar isi buku — versi development daftarnya ditulis manual, versi production sudah dicetak rapi dengan nomor halaman sehingga lebih cepat dicari.

## Poin-Poin Penting
- `composer install --optimize-autoloader` — dump autoload optimized
- `--no-dev` — skip package development
- `--classmap-authoritative` — pakai classmap saja, tidak perlu scan
- `--apcu-autoloader` — cache di APCu memory
- Jalankan di deployment pipeline

## Contoh Kode
```php
// Composer production install
composer install --no-dev --optimize-autoloader

// atau kombinasi lengkap
composer install --no-dev --optimize-autoloader --classmap-authoritative

// Dengan APCu autoloader
composer dump-autoload --apcu

// composer.json untuk production
{
    "config": {
        "optimize-autoloader": true,
        "classmap-authoritative": true,
        "apcu-autoloader": true,
        "prepend-autoloader": false,
        "sort-packages": true
    }
}

// Script deploy.sh
#!/bin/bash
php artisan down
git pull origin main
composer install --no-dev --optimize-autoloader --classmap-authoritative --no-interaction
php artisan migrate --force
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan up

// Cek autoloader type
echo "Classmap: " . (Composer\Factory::getConfig()->get('classmap-authoritative') ? 'yes' : 'no');
```

## Kasus Penggunaan Nyata
Aplikasi Laravel dengan 500+ package — tanpa optimasi autoload membutuhkan 50ms untuk mencari class. Setelah `classmap-authoritative` + APCu turun ke 2ms.
