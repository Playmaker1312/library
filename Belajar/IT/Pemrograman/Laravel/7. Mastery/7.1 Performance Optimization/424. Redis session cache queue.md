# 424. Redis Session Cache Queue

## Definisi Singkat
Konfigurasi dan penggunaan Redis untuk tiga fungsi utama Laravel — session storage, cache backend, dan queue driver — untuk performa maksimal.

## Analogi
Redis seperti pisau Swiss army untuk performance — satu tool bisa dipakai untuk menyimpan sesi, cache data, dan antrian pekerjaan.

## Poin-Poin Penting
- Redis in-memory database, sangat cepat
- Session di Redis lebih cepat dari file/database
- Cache dengan Redis mendukung tags dan TTL
- Queue dengan Redis lebih reliable dari database
- Gunakan predis untuk koneksi PHP

## Contoh Kode
```php
// Install predis
composer require predis/predis

// Config .env
REDIS_HOST=127.0.0.1
REDIS_PASSWORD=null
REDIS_PORT=6379

// config/session.php — session via Redis
'driver' => env('SESSION_DRIVER', 'redis'),
'connection' => 'session',

// config/cache.php — cache via Redis
'default' => env('CACHE_STORE', 'redis'),
'stores' => [
    'redis' => [
        'driver' => 'redis',
        'connection' => 'cache',
    ],
],

// config/queue.php — queue via Redis
'default' => env('QUEUE_CONNECTION', 'redis'),
'connections' => [
    'redis' => [
        'driver' => 'redis',
        'connection' => 'default',
        'queue' => env('REDIS_QUEUE', 'default'),
        'retry_after' => 90,
        'block_for' => null,
    ],
],

// config/database.php — multiple Redis connections
'redis' => [
    'client' => env('REDIS_CLIENT', 'predis'),
    'options' => [
        'prefix' => env('REDIS_PREFIX', 'laravel_'),
    ],
    'session' => [
        'host' => env('REDIS_HOST', '127.0.0.1'),
        'port' => env('REDIS_PORT', 6379),
        'database' => 0,
    ],
    'cache' => [
        'host' => env('REDIS_HOST', '127.0.0.1'),
        'port' => env('REDIS_PORT', 6379),
        'database' => 1,
    ],
    'queue' => [
        'host' => env('REDIS_HOST', '127.0.0.1'),
        'port' => env('REDIS_PORT', 6379),
        'database' => 2,
    ],
],

// Monitor Redis
// redis-cli monitor
// redis-cli --stat
```

## Kasus Penggunaan Nyata
Aplikasi SaaS dengan ribuan user aktif — migrasi session dari file ke Redis mengurangi waktu load halaman 40% karena session read/write di memori.
