# 430. php artisan optimize Production

## Definisi Singkat
Perintah Artisan untuk meng-cache konfigurasi, route, view, dan event — menggabungkan banyak file menjadi satu cache yang di-load cepat di production.

## Analogi
Seperti menyiapkan tas ransel malam sebelumnya — semua yang dibutuhkan sudah diatur rapi, tinggal ambil dan jalan tanpa perlu pikir ulang.

## Poin-Poin Penting
- `php artisan optimize` — cache config, route, view
- `php artisan config:cache` — gabung semua config jadi satu file
- `php artisan route:cache` — cache route registration
- `php artisan view:cache` — compile semua Blade jadi cached
- `php artisan event:cache` — cache event listeners
- Wajib dijalankan setiap deploy

## Contoh Kode
```php
// Perintah optimize lengkap untuk production
php artisan optimize

// Atau manual step-by-step
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan event:cache

// Reset (untuk development)
php artisan optimize:clear
// atau
php artisan config:clear
php artisan route:clear
php artisan view:clear
php artisan event:clear
php artisan cache:clear

// Cek status cache
php artisan optimize:status
// Output:
// +-------------------+-------+
// | Cache             | Status|
// +-------------------+-------+
// | Configuration     | Cached|
// | Routes            | Cached|
// | Views             | Cached|
// | Events            | Cached|
// +-------------------+-------+

// Catatan penting:
// - config:cache hanya baca dari file config, jangan pakai env() di config
// - route:cache tidak support closure routes
// - Jalankan ulang optimize setelah update kode

// Deploy script production
php artisan down --retry=10
git pull origin main
composer install --no-dev --optimize-autoloader
php artisan optimize
php artisan migrate --force
php artisan up
```

## Kasus Penggunaan Nyata
Setelah deploy tanpa `config:cache`, setiap request memanggil 50+ file config dari disk. Dengan cache, semua config digabung jadi 1 file — response time turun 30%.
