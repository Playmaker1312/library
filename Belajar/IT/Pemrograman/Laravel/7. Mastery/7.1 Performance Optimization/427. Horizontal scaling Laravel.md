# 427. Horizontal Scaling Laravel

## Definisi Singkat
Strategi menambah kapasitas aplikasi Laravel dengan menambahkan lebih banyak server (node) daripada memperbesar satu server (vertical scaling).

## Analogi
Seperti restoran yang ramai — horizontal scaling berarti membuka cabang baru di lokasi lain, bukan memperbesar dapur restoran yang sudah ada.

## Poin-Poin Penting
- Shared nothing architecture — setiap node stateless
- Session simpan di Redis (bukan file)
- Cache dan queue pakai Redis/database terpusat
- Load balancer distribusi traffic
- File storage pakai S3/sejenisnya (bukan lokal)
- Database pakai cluster read-replica

## Contoh Kode
```php
// .env untuk horizontal scaling
SESSION_DRIVER=redis
CACHE_STORE=redis
QUEUE_CONNECTION=redis
FILESYSTEM_DISK=s3

// config/session.php
'driver' => env('SESSION_DRIVER', 'redis'),
'connection' => 'session',
'cookie' => env('SESSION_COOKIE', 'laravel_session'),
'domain' => env('SESSION_DOMAIN', '.example.com'),
'same_site' => 'lax',
'secure' => env('SESSION_SECURE_COOKIE', true),

// config/filesystems.php — shared storage
'disks' => [
    's3' => [
        'driver' => 's3',
        'key' => env('AWS_ACCESS_KEY_ID'),
        'secret' => env('AWS_SECRET_ACCESS_KEY'),
        'region' => env('AWS_DEFAULT_REGION'),
        'bucket' => env('AWS_BUCKET'),
        'url' => env('AWS_URL'),
        'endpoint' => env('AWS_ENDPOINT'),
    ],
],

// config/database.php — read/write connection untuk scaling
'mysql' => [
    'read' => [
        'host' => [
            env('DB_READ_HOST_1', '127.0.0.1'),
            env('DB_READ_HOST_2', '127.0.0.1'),
        ],
    ],
    'write' => [
        'host' => [
            env('DB_WRITE_HOST', '127.0.0.1'),
        ],
    ],
    'driver' => 'mysql',
    'database' => env('DB_DATABASE', 'forge'),
    'username' => env('DB_USERNAME', 'forge'),
    'password' => env('DB_PASSWORD', ''),
],

// Load balancer health check endpoint
Route::get('/health', function () {
    try {
        DB::connection()->getPdo();
        Cache::store('redis')->get('ping');
        return response()->json(['status' => 'healthy'], 200);
    } catch (\Exception $e) {
        return response()->json(['status' => 'unhealthy'], 500);
    }
})->withoutMiddleware('throttle');
```

## Kasus Penggunaan Nyata
Platform pembelajaran online saat pandemi — traffic naik 1000%. Dengan horizontal scaling di AWS (auto-scaling group), server bertambah otomatis dari 3 ke 50 instance.
