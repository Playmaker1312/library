# 426. OPcache Optimasi PHP

## Definisi Singkat
Konfigurasi OPcache — engine caching bytecode PHP bawaan — untuk menyimpan compiled script di memori sehingga PHP tidak perlu mengompilasi ulang setiap request.

## Analogi
Seperti chef yang menyimpan resep yang sudah dihafal di kepala — tidak perlu buka buku resep setiap kali masak hidangan yang sama.

## Poin-Poin Penting
- OPcache sudah built-in di PHP 5.5+
- Simpan compiled PHP di shared memory
- Validasi timestamp bisa dimatikan di production
- `opcache.memory_consumption` tentukan ukuran memori
- `opcache.max_accelerated_files` batas maksimum file
- Reset OPcache setelah deploy

## Contoh Kode
```php
// php.ini konfigurasi OPcache untuk production
[opcache]
opcache.enable=1
opcache.memory_consumption=256
opcache.interned_strings_buffer=16
opcache.max_accelerated_files=20000
opcache.revalidate_freq=2
opcache.fast_shutdown=1
opcache.enable_cli=1
opcache.validate_timestamps=0 // nonaktifkan validasi di production

// Reset OPcache via PHP (untuk deploy)
php artisan optimize
// atau buat endpoint
Route::get('/opcache-reset', function () {
    if (app()->isLocal()) {
        opcache_reset();
        return 'OPcache reset';
    }
    abort(403);
});

// Script deploy reset OPcache di server
// deploy.sh
php artisan down
git pull origin main
composer install --no-dev --optimize-autoloader
php artisan optimize
php artisan migrate --force
php artisan up
// Reset OPcache
php -r "opcache_reset();"

// Cek status OPcache
// Buat route debug
Route::get('/opcache-status', function () {
    return opcache_get_status();
})->middleware('auth');
```

## Kasus Penggunaan Nyata
Setelah deploy Laravel ke VPS tanpa restart OPcache, pengguna melihat error karena PHP masih mengeksekusi kode lama dari cache bytecode.
