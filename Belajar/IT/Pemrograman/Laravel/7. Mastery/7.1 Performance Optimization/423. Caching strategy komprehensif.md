# 423. Caching Strategy Komprehensif

## Definisi Singkap
Strategi menyimpan data sementara di cache (memory/Redis/file) untuk mempercepat akses dan mengurangi beban database dengan berbagai pola caching.

## Analogi
Seperti kulkas — kita simpan makanan yang sering dipakai agar tidak perlu masak dari awal setiap kali mau makan.

## Poin-Poin Penting
- Cache entire query results dengan `remember()`
- Cache fragment HTML dengan `Cache::remember()`
- Cache tags untuk invalidasi grup (Redis/Memcached)
- Cache busting otomatis saat data diupdate
- Rate limiting dan cache stampede protection
- Gunakan `Cache::flexible()` untuk cache stampede (Laravel 11+)

## Contoh Kode
```php
// Cache query results
$trendingPosts = Cache::remember('trending_posts', 3600, function () {
    return Post::with('author')
        ->where('published', true)
        ->orderBy('views', 'desc')
        ->limit(10)
        ->get();
});

// Cache tags untuk invalidasi grup
Cache::tags(['posts', 'categories'])->remember('posts.all', 3600, function () {
    return Post::with('category')->get();
});

// Hapus cache berdasarkan tag
Cache::tags(['posts'])->flush();

// Cache flexible (Laravel 11+) — cegah cache stampede
$data = Cache::flexible('expensive_data', [5, 15], function () {
    return expensiveComputation();
});

// Cache dengan rememberForever
$settings = Cache::rememberForever('app_settings', function () {
    return Setting::pluck('value', 'key')->all();
});

// Cache busting otomatis dengan observer
class PostObserver
{
    public function saved(Post $post)
    {
        Cache::tags(['posts'])->flush();
    }
}

// Cache fragment Blade
@cache('profile.' . $user->id, now()->addHour())
    <div class="profile-card">
        @include('partials.profile', ['user' => $user])
    </div>
@endcache
```

## Kasus Penggunaan Nyata
Halaman beranda portal berita dengan 10 juta pengunjung/hari — cache daftar artikel trending selama 5 menit mengurangi beban database dari 10.000 query/detik menjadi 3 query/detik.
