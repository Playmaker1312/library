# 416. Identifikasi Bottleneck Laravel

## Definisi Singkat
Proses menemukan titik lemah (bottleneck) dalam aplikasi Laravel yang memperlambat performa, baik dari sisi kode, query database, maupun konfigurasi server.

## Analogi
Seperti mencari sumbatan di pipa air — kita perlu menelusuri setiap sambungan untuk menemukan di mana aliran tersendat.

## Poin-Poin Penting
- Gunakan Laravel Debugbar untuk profiling real-time
- Pantau waktu eksekusi query SQL
- Identifikasi N+1 query dengan lazy loading detection
- Ukur memory usage dan response time
- Gunakan Blackfire.io atau Tideways untuk profiling mendalam

## Contoh Kode
```php
// Menggunakan Debugbar di development
'debugbar' => [
    'enabled' => env('DEBUGBAR_ENABLED', false),
    'collectors' => [
        'time' => true,
        'queries' => true,
        'memory' => true,
    ],
],

// Benchmark manual
$start = microtime(true);
// query atau proses
$duration = microtime(true) - $start;
Log::channel('performance')->info('Process duration', [
    'duration' => $duration,
    'memory' => memory_get_peak_usage(true),
]);
```

## Kasus Penggunaan Nyata
Aplikasi e-commerce lambat saat load produk — setelah profiling ditemukan query kategori tanpa eager loading yang menyebabkan 100+ query per halaman.
