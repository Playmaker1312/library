# 474. Log Management ELK Papertrail

## Definisi Singkat
Strategi sentralisasi log aplikasi Laravel ke platform seperti ELK Stack (Elasticsearch, Logstash, Kibana) atau Papertrail/SolarWinds untuk analisis dan debugging terpusat.

## Analogi
Seperti pusat kontrol lalu lintas — semua kamera (log) dari seluruh kota (server) dikirim ke satu ruangan (ELK/Papertrail). Petugas bisa lihat kemacetan (error) di satu layar.

## Poin-Poin Penting
- Log terpusat — tidak perlu SSH ke server untuk lihat log
- ELK Stack: Elasticsearch (storage), Logstash (parser), Kibana (visualisasi)
- Papertrail: cloud log management SaaS
- Laravel log channel ke syslog, stdout, atau langsung API
- Filter dan alerting dari log patterns

## Contoh Kode
```php
<?php

// config/logging.php — berbagai channel logging
return [
    'default' => env('LOG_CHANNEL', 'stack'),

    'stack' => [
        'driver' => 'stack',
        'channels' => ['daily', 'papertrail'],
        'ignore_exceptions' => false,
    ],

    // Daily logs (lokal)
    'daily' => [
        'driver' => 'daily',
        'path' => storage_path('logs/laravel.log'),
        'level' => env('LOG_LEVEL', 'debug'),
        'days' => 14,
    ],

    // Papertrail — cloud log management
    'papertrail' => [
        'driver' => 'monolog',
        'level' => env('LOG_LEVEL', 'debug'),
        'handler' => Monolog\Handler\SyslogUdpHandler::class,
        'handler_with' => [
            'host' => env('PAPERTRAIL_URL'),
            'port' => env('PAPERTRAIL_PORT'),
        ],
    ],

    // Slack — notifikasi error urgent
    'slack' => [
        'driver' => 'slack',
        'url' => env('LOG_SLACK_WEBHOOK_URL'),
        'username' => 'Laravel Log',
        'emoji' => ':boom:',
        'level' => env('LOG_LEVEL', 'critical'),
    ],

    // ELK — Elasticsearch langsung
    'elasticsearch' => [
        'driver' => 'monolog',
        'level' => 'debug',
        'handler' => Monolog\Handler\ElasticsearchHandler::class,
        'handler_with' => [
            'client' => Elasticsearch\ClientBuilder::create()
                ->setHosts([env('ELASTICSEARCH_HOST')])
                ->build(),
            'options' => [
                'index' => 'laravel-' . strtolower(env('APP_ENV')),
            ],
        ],
    ],

    // JSON log untuk Logstash
    'json' => [
        'driver' => 'single',
        'path' => 'php://stdout',
        'level' => env('LOG_LEVEL', 'debug'),
        'tap' => [App\Logging\JsonFormatter::class],
    ],

    // Stdout — untuk Docker
    'stderr' => [
        'driver' => 'monolog',
        'level' => env('LOG_LEVEL', 'debug'),
        'handler' => Monolog\Handler\StreamHandler::class,
        'formatter' => env('LOG_STDERR_FORMATTER'),
        'with' => [
            'stream' => 'php://stderr',
        ],
    ],
];

// Custom JsonFormatter
namespace App\Logging;

use Monolog\Formatter\JsonFormatter as BaseJsonFormatter;

class JsonFormatter
{
    public function __invoke($logger): void
    {
        foreach ($logger->getHandlers() as $handler) {
            $handler->setFormatter(new BaseJsonFormatter());
        }
    }
}

// Logging dengan konteks
Log::info('Payment processed', [
    'order_id' => $order->id,
    'amount' => $order->total,
    'payment_method' => $order->payment_method,
    'user_id' => auth()->id(),
    'ip' => request()->ip(),
    'duration_ms' => $duration,
]);

// Kibana query example (ELK)
// laravel-production-* AND level: "error" AND @timestamp: >now-24h

// Papertrail search
// (level:error OR level:critical) (order OR payment)
```

## Kasus Penggunaan Nyata
Production error terjadi jam 3 pagi — Developer buka Papertrail, filter `level:error` dalam 6 jam terakhir, langsung lihat stack trace penyebab error tanpa SSH ke server.
