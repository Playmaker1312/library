# 468. docker-compose MySQL Redis Nginx

## Definisi Singkat
Konfigurasi docker-compose untuk menjalankan stack Laravel lengkap — aplikasi (PHP-FPM), web server (Nginx), database (MySQL/PostgreSQL), dan cache (Redis).

## Analogi
Seperti orkestra — docker-compose adalah konduktor yang mengatur semua alat musik (container) agar harmonis: biola (app), drum (DB), piano (Redis), konduktor (Nginx).

## Poin-Poin Penting
- Definisikan semua service di satu file
- Network internal untuk komunikasi container
- Volume untuk persistensi data
- Environment variables via .env
- Health check untuk dependency
- Development dengan hot reload

## Contoh Kode
```yaml
# docker-compose.yml
version: '3.8'

services:
  # Nginx web server
  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - .:/var/www/html
      - ./docker/nginx/default.conf:/etc/nginx/conf.d/default.conf
      - ./docker/nginx/ssl:/etc/nginx/ssl
    depends_on:
      - app
    networks:
      - laravel

  # PHP-FPM
  app:
    build:
      context: .
      dockerfile: Dockerfile
    volumes:
      - .:/var/www/html
      - ./docker/php/local.ini:/usr/local/etc/php/conf.d/local.ini
    environment:
      - APP_ENV=${APP_ENV:-local}
      - DB_HOST=mysql
      - REDIS_HOST=redis
    depends_on:
      mysql:
        condition: service_healthy
      redis:
        condition: service_started
    networks:
      - laravel

  # MySQL
  mysql:
    image: mysql:8.0
    ports:
      - "3306:3306"
    environment:
      MYSQL_ROOT_PASSWORD: ${DB_PASSWORD:-root}
      MYSQL_DATABASE: ${DB_DATABASE:-laravel}
      MYSQL_USER: ${DB_USERNAME:-laravel}
      MYSQL_PASSWORD: ${DB_PASSWORD:-secret}
    volumes:
      - mysql_data:/var/lib/mysql
      - ./docker/mysql/init.sql:/docker-entrypoint-initdb.d/init.sql
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
      timeout: 5s
      retries: 10
    networks:
      - laravel

  # Redis
  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    command: redis-server --appendonly yes --requirepass ${REDIS_PASSWORD:-}
    networks:
      - laravel

  # Queue worker
  queue:
    build:
      context: .
      dockerfile: Dockerfile
    volumes:
      - .:/var/www/html
    command: php artisan queue:work redis --sleep=3 --tries=3
    environment:
      - APP_ENV=${APP_ENV:-local}
      - DB_HOST=mysql
      - REDIS_HOST=redis
    depends_on:
      - app
      - redis
    networks:
      - laravel

  # Cron / Scheduler
  scheduler:
    build:
      context: .
      dockerfile: Dockerfile
    volumes:
      - .:/var/www/html
    command: php artisan schedule:work
    depends_on:
      - app
    networks:
      - laravel

  # Laravel Reverb (WebSocket)
  reverb:
    build:
      context: .
      dockerfile: Dockerfile
    ports:
      - "8080:8080"
    command: php artisan reverb:start
    environment:
      - APP_ENV=${APP_ENV:-local}
      - DB_HOST=mysql
      - REDIS_HOST=redis
    depends_on:
      - app
      - redis
    networks:
      - laravel


volumes:
  mysql_data:
  redis_data:

networks:
  laravel:
    driver: bridge
```

```nginx
# docker/nginx/default.conf
server {
    listen 80;
    server_name localhost;
    root /var/www/html/public;

    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass app:9000;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }
}
```

```bash
# Jalankan
docker-compose up -d

# Build ulang
docker-compose build app

# Logs
docker-compose logs -f app

# Stop
docker-compose down

# Hapus volume juga
docker-compose down -v
```

## Kasus Penggunaan Nyata
Developer baru join project — cukup `docker-compose up -d`, semua service jalan. Tidak perlu install PHP, MySQL, Redis manual. Produktivitas dari menit pertama.
