# 473. Monitoring Laravel Pulse

## Definisi Singkat
Package monitoring resmi dari Laravel untuk memantau performa aplikasi secara real-time — mencakup slow requests, jobs, queries, cache, dan exceptions.

## Analogi
Seperti dashboard rumah sakit — monitor detak jantung (request rate), tekanan darah (memory), dan alarm (error rate) untuk seluruh pasien (aplikasi).

## Poin-Poin Penting
- Dashboard real-time di `/pulse`
- Data disimpan di database (cacheable)
- Pantau: slow routes, jobs, queries, cache hits/misses
- Filter berdasarkan environment
- Auth middleware — hanya admin bisa akses
- Ringan — pakai sampling untuk performa

## Contoh Kode
```php
// Install
composer require laravel/pulse

// Publish config & migration
php artisan vendor:publish --provider="Laravel\Pulse\PulseServiceProvider"
php artisan migrate

// Config config/pulse.php
return [
    'enabled' => env('PULSE_ENABLED', true),
    'domain' => env('PULSE_DOMAIN'),
    'path' => env('PULSE_PATH', 'pulse'),
    'middleware' => ['web', 'auth'],

    'recorders' => [
        // Slow requests — lebih dari 1000ms
        \Laravel\Pulse\Recorders\SlowOutgoingRequests::class => [
            'threshold' => 1000, // ms
        ],

        // Slow queries — lebih dari 100ms
        \Laravel\Pulse\Recorders\SlowQueries::class => [
            'threshold' => 100,
        ],

        // Slow jobs
        \Laravel\Pulse\Recorders\SlowJobs::class => [
            'threshold' => 1000,
        ],

        // Exceptions
        \Laravel\Pulse\Recorders\Exceptions::class => [
            'sample_rate' => 0.1, // sampling 10%
        ],

        // Cache hits/misses
        \Laravel\Pulse\Recorders\CacheInteractions::class => [],

        // Queue size
        \Laravel\Pulse\Recorders\Queues::class => [],

        // Server metrics
        \Laravel\Pulse\Recorders\Servers::class => [
            'directories' => [
                '/',
            ],
        ],
    ],
];

// Dashboard — diakses via /pulse
// Tampilkan dengan auth guard
Route::middleware(['web', 'auth', 'can:view-pulse'])->group(function () {
    Route::get('/pulse', function () {
        return view('pulse::dashboard');
    });
});

// Atau di AppServiceProvider
Pulse::user(fn ($user) => $user->isAdmin());

// Auth gate
Gate::define('view-pulse', function ($user) {
    return $user->hasRole('admin');
});

// Custom card — tambahkan metric sendiri
Pulse::card('custom', [
    \App\Pulse\CustomRecorder::class,
]);

// Data retention
// config/pulse.php
'ingest' => [
    'trim' => [
        'lots' => 1440,   // 24 jam data detail
        'samples' => 168, // 7 hari data agregat
    ],
],

// Pulse di Blade
@livewire('pulse.dashboard', [
    'periods' => [
        ['label' => '1 hour', 'seconds' => 3600],
        ['label' => '24 hours', 'seconds' => 86400],
    ],
])
```

## Kasus Penggunaan Nyata
Tim DevOps melihat ada spike slow queries di Pulse — langsung tahu query apa yang lambat, dari controller mana, dan parameter yang dipakai. Fix dalam 5 menit.
