# 463. Nginx Web Server Laravel

## Definisi Singkat
Konfigurasi Nginx sebagai web server untuk Laravel — mencakup server block, PHP-FPM, caching static files, security headers, dan optimasi performa.

## Analogi
Seperti resepsionis gedung — Nginx menerima tamu (HTTP request), menentukan ke mana harus pergi (static file atau PHP-FPM), dan mengatur antrian.

## Poin-Poin Penting
- Nginx lebih ringan dari Apache untuk Laravel
- Konfigurasi di `/etc/nginx/sites-available/`
- `try_files` untuk pretty URL Laravel
- FastCGI cache untuk static files
- Rate limiting dan security headers
- Gzip compression untuk response

## Contoh Kode
```nginx
# /etc/nginx/nginx.conf — optimasi global
user www-data;
worker_processes auto;
worker_rlimit_nofile 65535;

events {
    worker_connections 4096;
    multi_accept on;
    use epoll;
}

http {
    sendfile on;
    tcp_nopush on;
    tcp_nodelay on;
    keepalive_timeout 65;
    types_hash_max_size 2048;
    server_tokens off;

    client_max_body_size 100M;
    client_body_buffer_size 128k;

    # Gzip configuration
    gzip on;
    gzip_vary on;
    gzip_proxied any;
    gzip_comp_level 6;
    gzip_min_length 256;
    gzip_types
        text/plain
        text/css
        text/javascript
        application/javascript
        application/json
        application/xml
        image/svg+xml;

    # Cache static files
    open_file_cache max=2000 inactive=20s;
    open_file_cache_valid 60s;
    open_file_cache_min_uses 2;
    open_file_cache_errors on;
}

# Laravel server block
server {
    listen 443 ssl http2;
    server_name example.com;
    root /var/www/app/public;

    # SSL
    ssl_certificate /etc/letsencrypt/live/example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256;

    # Security headers
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;
    add_header Permissions-Policy "camera=(), microphone=(), geolocation=()" always;

    # Pretty URL
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    # PHP-FPM
    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_buffer_size 128k;
        fastcgi_buffers 4 256k;
        fastcgi_busy_buffers_size 256k;
    }

    # Static assets — cache lama
    location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|woff2?)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
        access_log off;
        log_not_found off;
    }

    # Deny access to hidden files
    location ~ /\. {
        deny all;
        access_log off;
        log_not_found off;
    }

    # Deny access to storage (kecuali public)
    location ~ ^/storage/ {
        try_files $uri =404;
    }

    # Rate limiting
    limit_req_zone $binary_remote_addr zone=login:10m rate=5r/m;
    location /login {
        limit_req zone=login burst=2 nodelay;
        try_files $uri $uri/ /index.php?$query_string;
    }
}
```

## Kasus Penggunaan Nyata
Migrasi dari Apache ke Nginx mengurangi response time 40% untuk aplikasi Laravel dengan 500+ request/detik karena Nginx lebih efisien menangani concurrent connections.
