# 472. Cron Job Scheduler Production

## Definisi Singkat
Konfigurasi cron job untuk menjalankan Laravel Scheduler di production — cukup satu entry crontab yang menjalankan `php artisan schedule:run` setiap menit.

## Analogi
Seperti jam alarm yang terprogram — kita set jadwal (scheduler), server menjalankan tugas otomatis di waktu yang ditentukan tanpa perlu manusia ingat.

## Poin-Poin Penting
- Hanya perlu satu cron entry: `* * * * * php artisan schedule:run`
- Laravel handle logic kapan task harus jalan
- Task bisa berupa command, job, shell script
- Maintenance mode — scheduler tidak jalan saat `php artisan down`
- Output dan logging built-in
- `schedule:work` untuk development (Laravel 10+)

## Contoh Kode
```php
<?php

// app/Console/Kernel.php
namespace App\Console;

use Illuminate\Console\Scheduling\Schedule;
use Illuminate\Foundation\Console\Kernel as ConsoleKernel;

class Kernel extends ConsoleKernel
{
    protected function schedule(Schedule $schedule): void
    {
        // Setiap menit — jalankan queue worker
        $schedule->command('queue:work --stop-when-empty')
            ->everyMinute()
            ->withoutOverlapping()
            ->sendOutputTo(storage_path('logs/queue.log'));

        // Setiap jam — backup database
        $schedule->command('backup:database')
            ->hourly()
            ->environments(['production'])
            ->onFailure(function () {
                Log::error('Database backup failed!');
                Notification::route('mail', 'admin@example.com')
                    ->notify(new BackupFailed());
            });

        // Setiap hari jam 2 pagi — generate sitemap
        $schedule->command('sitemap:generate')
            ->dailyAt('02:00')
            ->timezone('Asia/Jakarta')
            ->appendOutputTo(storage_path('logs/sitemap.log'));

        // Setiap hari jam 3 pagi — arsip data lama
        $schedule->command('archive:old-orders')
            ->dailyAt('03:00')
            ->withoutOverlapping(240) // lock 4 jam
            ->onOneServer(); // hanya jalan di 1 server

        // Setiap minggu — kirim newsletter
        $schedule->job(new SendWeeklyNewsletter)
            ->weekly()
            ->mondays()
            ->at('08:00')
            ->emailOutputTo('admin@example.com');

        // Setiap 5 menit — cek antrian
        $schedule->call(function () {
            $queueSize = Queue::size();
            if ($queueSize > 1000) {
                Notification::route('slack', env('SLACK_WEBHOOK'))
                    ->notify(new QueueHighAlert($queueSize));
            }
        })->everyFiveMinutes();

        // Ping health check
        $schedule->ping('https://hc-ping.com/your-uuid')
            ->everyMinute();

        // Perbaiki data
        $schedule->exec('find /tmp -type f -mtime +7 -delete')
            ->daily();
    }

    protected function commands(): void
    {
        $this->load(__DIR__ . '/Commands');
        require base_path('routes/console.php');
    }
}
```

```bash
# 1. Tambahkan cron entry di server
crontab -e

# 2. Isi dengan:
* * * * * cd /var/www/app && php artisan schedule:run >> /dev/null 2>&1

# 3. Atau jika menggunakan Forge — sudah otomatis

# 4. Untuk development — Laravel 10+ scheduler worker
php artisan schedule:work

# 5. Cek schedule list
php artisan schedule:list

# 6. Test schedule tanpa benar-benar jalan
php artisan schedule:test

# Contoh output cron log
# Tail log scheduler
tail -f /var/log/syslog | grep CRON

# Log spesifik Laravel
tail -f storage/logs/laravel.log | grep "schedule"
```
