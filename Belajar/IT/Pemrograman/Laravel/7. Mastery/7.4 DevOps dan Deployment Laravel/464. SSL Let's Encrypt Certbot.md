# 464. SSL Let's Encrypt Certbot

## Definisi Singkat
Proses mengamankan aplikasi Laravel dengan SSL/TLS gratis dari Let's Encrypt menggunakan Certbot — memastikan koneksi HTTPS aman.

## Analogi
Seperti mengunci pintu rumah dengan gembok bersertifikat — Let's Encrypt adalah tukang kunci yang kasih gembok gratis dan terpercaya, Certbot adalah alat pasangnya.

## Poin-Poin Penting
- Let's Encrypt — sertifikat SSL gratis, valid 90 hari
- Certbot — tool otomatis untuk install & renew
- Auto-renewal via cron/systemd timer
- Verifikasi domain via HTTP-01 atau DNS-01
- HTTPS redirect dari HTTP

## Contoh Kode
```bash
# Install Certbot dengan Nginx plugin
sudo apt install -y certbot python3-certbot-nginx

# Generate SSL untuk domain
sudo certbot --nginx -d example.com -d www.example.com

# Ikuti wizard — pilih redirect HTTP to HTTPS
# Output:
# Successfully received certificate.
# Certificate is saved at:
#   /etc/letsencrypt/live/example.com/fullchain.pem
# Key is saved at:
#   /etc/letsencrypt/live/example.com/privkey.pem

# Test auto-renewal
sudo certbot renew --dry-run

# Cek status sertifikat
sudo certbot certificates

# Konfigurasi auto-renewal (Certbot otomatis bikin)
# /etc/cron.d/certbot
0 */12 * * * root certbot -q renew

# Atau systemd timer
sudo systemctl status certbot.timer

# Manual renew jika perlu
sudo certbot renew

# Nginx config dengan SSL (hasil auto dari certbot)
server {
    listen 443 ssl http2;
    server_name example.com;

    ssl_certificate /etc/letsencrypt/live/example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;
    include /etc/letsencrypt/options-ssl-nginx.conf;
    ssl_dhparam /etc/letsencrypt/ssl-dhparams.pem;
    # ... rest of config
}

# Redirect HTTP to HTTPS
server {
    listen 80;
    server_name example.com www.example.com;
    return 301 https://$server_name$request_uri;
}

# Verifikasi SSL
# https://www.ssllabs.com/ssltest/
# Atau command line:
openssl s_client -connect example.com:443 -servername example.com

# Wildcard SSL (untuk subdomain)
sudo certbot certonly --manual --preferred-challenges=dns \
    -d *.example.com -d example.com
```

## Kasus Penggunaan Nyata
Situs e-commerce — setelah install SSL dengan Let's Encrypt, browser menampilkan gembok hijau, meningkatkan kepercayaan pelanggan dan SEO ranking.
