# 466. Laravel Vapor Serverless AWS

## Definisi Singkat
Layanan serverless deployment untuk Laravel di AWS Lambda — aplikasi jalan tanpa server tradisional, auto-scaling dari 0 hingga ribuan request.

## Analogi
Seperti taksi online — kita tidak perlu punya mobil (server). Pesan (request), taksi datang (Lambda), bayar sesuai pemakaian. Jika ramai, armada otomatis bertambah.

## Poin-Poin Penting
- Auto-scaling instant — dari 0 ke ribuan request
- Bayar per request — tidak ada biaya idle
- Managed by Laravel — tinggal deploy via CLI
- Support database, queue, cron via Vapor
- Cache dan session via DynamoDB/ElastiCache
- Limitasi: cold start, execution timeout (15 menit)

## Contoh Kode
```bash
# Install Vapor CLI
composer require laravel/vapor-cli --dev

# Login
vapor login

# Init project
vapor init

# vapor.yml — konfigurasi deployment
id: 12345
name: my-app
environments:
    production:
        memory: 1024
        timeout: 30
        runtime: php-8.2:al2
        storage: my-app-production
        database: my-app-production
        redis: my-app-production-6
        queue: true
        cli: true
        scheduler: true
        domain: example.com
        build:
            - 'composer install --no-dev --optimize-autoloader'
            - 'php artisan event:cache'
            - 'npm ci && npm run build && rm -rf node_modules'
    staging:
        memory: 512
        timeout: 20
        runtime: php-8.2:al2
        storage: my-app-staging
        database: my-app-staging
        domain: staging.example.com

# Deploy
vapor deploy production

# Environment variables di Vapor UI
# APP_KEY=base64:...
# DB_HOST=...
# dll

# Queue worker di Vapor
vapor queue:size production
vapor queue:failed production

# Schedule (cron) di Vapor
# Otomatis jalan dari scheduler: true di vapor.yml

# Logs
vapor log production --tail

// Vapor-specific code
use Laravel\Vapor\Contracts\VaporResponse;

class VaporController extends Controller
{
    // Lambda response — maksimum 6MB
    public function largeData(): VaporResponse
    {
        return response()->json(
            DataExport::generate(),
            200,
            ['Content-Type' => 'application/json']
        )->withHeaders([
            'X-Vapor-Throttled' => 'false',
        ]);
    }
}

// Cold start optimization
// app/Providers/VaporServiceProvider.php
class VaporServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        // Warm up connections
        if (app()->environment('production')) {
            DB::connection()->getPdo();
            Cache::store('redis')->get('ping');
        }
    }
}
```

## Kasus Penggunaan Nyata
Aplikasi yang traffic-nya spike di jam-jam tertentu (seperti sistem voting) — dengan Vapor, 0 request di malam hari bayar $0, saat siang auto-scale ke 10.000 Lambda.
