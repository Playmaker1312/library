# 465. Laravel Forge Provisioning

## Definisi Singkap
Layanan Laravel Forge untuk provisioning dan管理 server Laravel secara otomatis — dari setup server, deploy code, queue worker, cron job, hingga SSL.

## Analogi
Seperti sopir pribadi — kita tinggal duduk (coding), Forge yang menyetir (manage server), mengurus bensin (update), servis (backup), dan parkir (deploy).

## Poin-Poin Penting
- Provisioning server (Linode, DigitalOcean, AWS, dll) dalam 2 menit
- Install Nginx, PHP, MySQL/PostgreSQL, Redis otomatis
- One-click deploy dari GitHub/GitLab/Bitbucket
- Queue worker management via Supervisor
- SSL Let's Encrypt otomatis
- Monitoring server dasar (CPU, RAM, disk)

## Contoh Kode
```
// 1. Setup server di Forge
// - Login ke forge.laravel.com
// - Klik "Create Server"
// - Pilih provider (DigitalOcean, Linode, AWS, dll)
// - Pilih region, size, PHP version
// - Klik "Create Server" — tunggu 2-3 menit

// 2. Installasi di server
// Forge akan:
// - Install Nginx + PHP 8.2 + MySQL + Redis + Supervisor
// - Setup user 'forge' dengan SSH key
// - Install Composer, Node.js, Certbot
// - Konfigurasi firewall (UFW)
// - Setup swap file

// 3. Deploy site
// - Add site (example.com)
// - Hubungkan ke Git repository
// - Set deployment script di Forge dashboard:

// Deployment script (Forge runs this)
cd /home/forge/example.com
git pull origin main
composer install --no-dev --no-interaction --optimize-autoloader
php artisan migrate --force

if [ -f artisan ]; then
    php artisan config:cache
    php artisan route:cache
    php artisan view:cache
    php artisan event:cache
fi

npm install --production
npm run build

echo "✅ Deploy complete!"

// 4. Setup Queue Worker via Forge UI
// - Buka tab "Queue Workers"
// - Klik "Create Queue Worker"
// - Connection: redis, Queue: default
// - Process: 1, Timeout: 90
// - Auto-start: yes

// 5. SSL otomatis
// - Buka tab "SSL"
// - Klik "Obtain SSL Certificate"
// - Pilih "Let's Encrypt"
// - Centang "Obtain a wildcard certificate" jika perlu

// 6. Scheduler
// - Buka tab "Scheduler"
// - Tambah command: php /home/forge/example.com/artisan schedule:run
// - Frequency: Every Minute

// 7. Forge API — deploy from CI/CD
curl -X POST https://forge.laravel.com/api/v1/servers/{server}/sites/{site}/deployment/deploy \
    -H "Authorization: Bearer YOUR_API_TOKEN" \
    -H "Content-Type: application/json" \
    -H "Accept: application/json"
```

## Kasus Penggunaan Nyata
Startup dengan 3 developer — Forge memangkas waktu setup server dari 1 hari menjadi 5 menit. Deploy cukup klik tombol atau push ke branch.
