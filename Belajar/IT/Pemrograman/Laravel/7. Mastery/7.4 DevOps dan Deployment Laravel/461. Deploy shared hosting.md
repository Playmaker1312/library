# 461. Deploy Shared Hosting

## Definisi Singkat
Proses deployment aplikasi Laravel ke shared hosting — lingkungan murah dengan keterbatasan akses server, biasanya tanpa SSH atau command line.

## Analogi
Seperti mengirim paket lewat jasa kirim — kita pack rapi-rapi (build), kirim (upload via FTP), lalu terima di tujuan. Tidak bisa masuk ke gudang kurir.

## Poin-Poin Penting
- Build project di lokal/CI, upload hasil build
- Upload folder `public/` ke `public_html/`
- Set `bootstrap/` dan `storage/` di luar public_html
- Symlink atau alias untuk keamanan
- Edit `public/index.php` untuk path yang benar
- Pastikan PHP versi sesuai (min 8.1)

## Contoh Kode
```php
// 1. Build di lokal
composer install --no-dev --optimize-autoloader
php artisan config:cache
php artisan route:cache
php artisan view:cache
npm install && npm run build

// 2. Struktur folder di shared hosting
// /
// ├── public_html/       (document root)
// │   ├── index.php      (dari public/index.php, edit pathnya)
// │   ├── .htaccess
// │   ├── assets/
// │   └── build/
// ├── laravel/            (di luar public_html)
// │   ├── app/
// │   ├── bootstrap/
// │   ├── config/
// │   ├── database/
// │   ├── resources/
// │   ├── routes/
// │   ├── storage/
// │   ├── vendor/
// │   └── artisan
// └── .env

// 3. Edit public/index.php untuk shared hosting
<?php

// Sesuaikan path ke folder laravel
require __DIR__ . '/../laravel/vendor/autoload.php';

$app = require_once __DIR__ . '/../laravel/bootstrap/app.php';

// 4. .htaccess di public_html
<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteRule ^ index.php [L]
</IfModule>

// 5. Storage symlink workaround — buat folder manual
// public_html/storage -> symlink ke ../laravel/storage/app/public
// Atau langsung buat folder public_html/storage dan isi file2nya

// 6. Crontab di cPanel
// * * * * * /usr/local/bin/php /home/user/laravel/artisan schedule:run >> /dev/null 2>&1

// 7. .env khusus shared hosting
APP_ENV=production
APP_DEBUG=false
APP_URL=https://example.com
DB_HOST=localhost
DB_DATABASE=user_database
DB_USERNAME=user_username
DB_PASSWORD=password
```

## Kasus Penggunaan Nyata
Portfolio Laravel sederhana di hosting murah (Rp 20.000/bulan) — dengan struktur di atas, aplikasi jalan lancar meski tanpa akses SSH atau Composer di server.
