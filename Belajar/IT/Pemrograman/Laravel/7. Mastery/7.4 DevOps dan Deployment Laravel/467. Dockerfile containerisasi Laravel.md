# 467. Dockerfile Containerisasi Laravel

## Definisi Singkat
Pembuatan Dockerfile untuk mengemas aplikasi Laravel beserta dependencies-nya ke dalam container Docker yang portable dan reproducible.

## Analogi
Seperti kontainer pengiriman — barang (aplikasi) dikemas rapi dengan semua yang dibutuhkan. Bisa diangkut kapal, truk, kereta — sampai tujuan tanpa perlu setup ulang.

## Poin-Poin Penting
- Multi-stage build untuk image minimal
- PHP-FPM sebagai base image
- Copy hanya file yang diperlukan
- Optimasi layer cache — dependencies duluan
- Non-root user untuk keamanan
- Health check untuk container orchestration

## Contoh Kode
```dockerfile
# Dockerfile — Multi-stage build

# === Stage 1: Build dependencies ===
FROM php:8.2-fpm-alpine AS build

# Install system dependencies
RUN apk add --no-cache \
    git \
    unzip \
    curl \
    libzip-dev \
    libpng-dev \
    oniguruma-dev \
    postgresql-dev \
    && docker-php-ext-install \
    pdo_mysql \
    pdo_pgsql \
    zip \
    gd \
    mbstring \
    bcmath

# Install Composer
COPY --from=composer:2 /usr/bin/composer /usr/bin/composer

WORKDIR /app

# Copy composer files first (caching)
COPY composer.json composer.lock ./
RUN composer install --no-dev --no-scripts --no-interaction --prefer-dist --optimize-autoloader

# Copy application code
COPY . .

# Generate optimized cache
RUN php artisan config:cache \
    && php artisan route:cache \
    && php artisan view:cache \
    && php artisan event:cache

# === Stage 2: Production image ===
FROM php:8.2-fpm-alpine

# Install runtime extensions only
RUN apk add --no-cache \
    libzip \
    libpng \
    oniguruma \
    postgresql-libs \
    && docker-php-ext-install \
    pdo_mysql \
    pdo_pgsql \
    zip \
    gd \
    mbstring \
    bcmath \
    opcache

# OPcache config
RUN docker-php-ext-enable opcache
COPY docker/opcache.ini /usr/local/etc/php/conf.d/opcache.ini

# Create non-root user
RUN addgroup -g 1000 -S app && \
    adduser -u 1000 -S app -G app

WORKDIR /app

# Copy from build stage
COPY --from=build --chown=app:app /app /app
COPY --from=build --chown=app:app /app/vendor /app/vendor
COPY --from=build --chown=app:app /app/storage /app/storage
COPY --from=build --chown=app:app /app/bootstrap/cache /app/bootstrap/cache

# Storage permission
RUN chmod -R 775 storage bootstrap/cache

USER app

EXPOSE 9000

HEALTHCHECK --interval=30s --timeout=3s \
    CMD php artisan health:check || exit 1

CMD ["php-fpm"]
```

```ini
; docker/opcache.ini
[opcache]
opcache.enable=1
opcache.memory_consumption=256
opcache.interned_strings_buffer=16
opcache.max_accelerated_files=20000
opcache.revalidate_freq=0
opcache.validate_timestamps=0
opcache.fast_shutdown=1
```

```dockerfile
# .dockerignore
.git
.gitignore
node_modules
npm-debug.log
.env
.DS_Store
docker-compose.yml
tests
phpunit.xml
.editorconfig
```

```bash
# Build & run
docker build -t laravel-app .
docker run -d -p 9000:9000 laravel-app
```
