# 475. Backup Spatie laravel-backup

## Definisi Singkat
Package backup dari Spatie untuk Laravel — membuat backup database dan file secara otomatis, mengompres, dan mengirim ke penyimpanan lokal atau cloud.

## Analogi
Seperti asuransi rumah — kita bayar premi (konfigurasi) sekali, kalau terjadi musibah (databasenya corrupt), klaim asuransi (restore backup) membuat semuanya kembali.

## Poin-Poin Penting
- Backup database (MySQL, PostgreSQL, SQLite)
- Backup file/folder tertentu
- Kompresi ZIP otomatis
- Destination: lokal, S3, Dropbox, SFTP, dll
- Auto-cleanup backup lama
- Notifikasi sukses/gagal via mail, Slack

## Contoh Kode
```php
// Install
composer require spatie/laravel-backup

// Publish config
php artisan vendor:publish --provider="Spatie\Backup\BackupServiceProvider"

// config/backup.php
return [
    'backup' => [
        'name' => env('APP_NAME', 'Laravel') . '-backup',

        'source' => [
            'databases' => [
                'mysql',
            ],
            'include' => [
                base_path('public/uploads'),
                base_path('storage/app/public'),
            ],
            'exclude' => [
                base_path('vendor'),
                base_path('node_modules'),
                base_path('storage/logs'),
                base_path('.git'),
            ],
        ],

        'destination' => [
            'filename_prefix' => '',
            'disks' => [
                'local',     // storage/app/Laravel-backup/
                's3',        // AWS S3 bucket
            ],
        ],

        'temporary_directory' => storage_path('app/backup-temp'),
    ],

    'notifications' => [
        'notifications' => [
            \Spatie\Backup\Notifications\Notifications\BackupHasFailedNotification::class => ['mail'],
            \Spatie\Backup\Notifications\Notifications\BackupWasSuccessfulNotification::class => ['mail'],
            \Spatie\Backup\Notifications\Notifications\CleanupWasSuccessfulNotification::class => [],
        ],

        'notifiable' => \Spatie\Backup\Notifications\Notifiable::class,

        'mail' => [
            'to' => 'admin@example.com',
        ],

        'slack' => [
            'webhook_url' => env('BACKUP_SLACK_WEBHOOK'),
        ],
    ],

    'monitor_backups' => [
        [
            'name' => env('APP_NAME', 'Laravel') . '-backup',
            'disks' => ['local', 's3'],
            'newest_backups_age' => 1,       // backup harus ada dalam 1 hari
            'maximum_storage_in_megabytes' => 5000,
        ],
    ],
];

// Schedule backup
// app/Console/Kernel.php
protected function schedule(Schedule $schedule): void
{
    // Backup setiap hari jam 1 pagi
    $schedule->command('backup:run')
        ->dailyAt('01:00')
        ->withoutOverlapping()
        ->onFailure(function () {
            Log::critical('Backup failed!');
        });

    // Cleanup backup lama (lebih dari 30 hari)
    $schedule->command('backup:clean')
        ->dailyAt('02:00')
        ->withoutOverlapping();
}

// Manual backup
php artisan backup:run
php artisan backup:run --only-db
php artisan backup:run --only-files
php artisan backup:run --disable-notifications

// Restore — manual via command line
// 1. Extract backup zip
// 2. Restore database:
mysql -u user -p database < backup.sql
// 3. Copy files ke tempat asal

// List backup
php artisan backup:list

// Monitor backup
php artisan backup:monitor

// Custom backup filename
// config/backup.php
'destination' => [
    'filename_prefix' => env('APP_ENV') . '-',
],

// Multiple backup strategies
$schedule->command('backup:run --only-db')
    ->name('db-backup')
    ->everySixHours()
    ->withoutOverlapping();

$schedule->command('backup:run')
    ->name('full-backup')
    ->dailyAt('01:00')
    ->withoutOverlapping();
```

## Kasus Penggunaan Nyata
Tengah malam server kena ransomware — data terenkripsi semua. Dengan Spatie Backup, restore dari backup S3 6 jam sebelumnya. Aplikasi kembali normal dalam 30 menit.
