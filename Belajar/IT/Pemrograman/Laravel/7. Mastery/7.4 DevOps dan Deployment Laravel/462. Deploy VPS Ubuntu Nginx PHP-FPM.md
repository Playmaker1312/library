# 462. Deploy VPS Ubuntu Nginx PHP-FPM

## Definisi Singkat
Langkah-langkah deployment Laravel ke VPS Ubuntu dengan stack Nginx + PHP-FPM — konfigurasi server manual untuk performa dan kontrol penuh.

## Analogi
Seperti membangun rumah sendiri — kita pilih tanah (VPS), bangun pondasi (Nginx), pasang listrik (PHP-FPM), dan atur interior (Laravel). Hasilnya sesuai keinginan.

## Poin-Poin Penting
- Update server: `apt update && apt upgrade`
- Install Nginx, PHP 8.x, MySQL/PostgreSQL
- Install Composer, Node.js
- Clone repo, install dependencies
- Konfigurasi Nginx site
- Set permission storage & bootstrap/cache
- Setup SSL dengan Let's Encrypt

## Contoh Kode
```bash
# 1. Update & install dependencies
sudo apt update && sudo apt upgrade -y
sudo apt install -y nginx mysql-server php8.2-fpm php8.2-cli php8.2-mysql \
    php8.2-xml php8.2-mbstring php8.2-curl php8.2-bcmath php8.2-zip \
    php8.2-redis composer unzip git

# 2. Clone project
cd /var/www
sudo git clone https://github.com/your-repo/app.git
cd app
sudo chown -R $USER:www-data .

# 3. Install dependencies
composer install --no-dev --optimize-autoloader
cp .env.example .env
php artisan key:generate
php artisan config:cache
php artisan route:cache
php artisan view:cache

# 4. Permission
sudo chmod -R 775 storage bootstrap/cache
sudo chown -R www-data:www-data storage bootstrap/cache

# 5. Nginx configuration
sudo nano /etc/nginx/sites-available/app
```

```nginx
# /etc/nginx/sites-available/app
server {
    listen 80;
    server_name example.com www.example.com;
    root /var/www/app/public;

    index index.php index.html;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }

    location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|woff|woff2|ttf|eot)$ {
        expires max;
        add_header Cache-Control "public, immutable";
    }

    # Security headers
    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";
    add_header X-XSS-Protection "1; mode=block";
}
```

```bash
# Enable site
sudo ln -s /etc/nginx/sites-available/app /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

# 6. Database
sudo mysql -u root -p
CREATE DATABASE app;
CREATE USER 'app_user'@'localhost' IDENTIFIED BY 'password';
GRANT ALL ON app.* TO 'app_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;

# 7. Run migration
php artisan migrate --force
```
