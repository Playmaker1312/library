# 469. CI CD GitHub Actions Laravel

## Definisi Singkat
Pipeline otomatis untuk Laravel menggunakan GitHub Actions — menjalankan test, static analysis, dan deploy otomatis ketika ada push ke branch tertentu.

## Analogi
Seperti pabrik perakitan mobil — kode masuk (push), otomatis di-test (QC), diperiksa kualitas (inspection), dan dikirim ke dealer (deploy). Semua otomatis tanpa manusia.

## Poin-Poin Penting
- Trigger: push, pull_request ke branch tertentu
- Matrix testing — multiple PHP + Laravel versions
- Cache Composer dan NPM dependencies
- Run tests, Pint, PHPStan, Larastan
- Deploy ke Forge/Vapor/server via script

## Contoh Kode
```yaml
# .github/workflows/ci.yml
name: Laravel CI/CD

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]

jobs:
  # === Quality Check ===
  quality:
    runs-on: ubuntu-latest
    services:
      mysql:
        image: mysql:8.0
        env:
          MYSQL_ROOT_PASSWORD: root
          MYSQL_DATABASE: test_db
        ports:
          - 3306:3306
        options: --health-cmd="mysqladmin ping" --health-interval=10s

    steps:
      - uses: actions/checkout@v3

      - name: Setup PHP
        uses: shivammathur/setup-php@v2
        with:
          php-version: '8.2'
          extensions: mbstring, pdo_mysql, bcmath, curl, zip
          coverage: xdebug

      - name: Cache Composer
        uses: actions/cache@v3
        with:
          path: vendor
          key: composer-${{ hashFiles('composer.lock') }}

      - name: Install Dependencies
        run: composer install --no-interaction --prefer-dist

      - name: Create .env
        run: |
          cp .env.example .env
          php artisan key:generate

      - name: Run Migration
        run: php artisan migrate --env=testing
        env:
          DB_HOST: 127.0.0.1
          DB_PORT: 3306
          DB_DATABASE: test_db
          DB_USERNAME: root
          DB_PASSWORD: root

      - name: Run Tests
        run: php artisan test
        env:
          DB_HOST: 127.0.0.1
          DB_PORT: 3306
          DB_DATABASE: test_db
          DB_USERNAME: root
          DB_PASSWORD: root

      - name: Run Laravel Pint
        run: ./vendor/bin/pint --test

      - name: Run PHPStan
        run: ./vendor/bin/phpstan analyse --memory-limit=2G

  # === Deploy to Production ===
  deploy:
    needs: quality
    if: github.ref == 'refs/heads/main'
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v3

      - name: Deploy to Laravel Forge
        run: |
          curl -X POST "${{ secrets.FORGE_DEPLOY_URL }}" \
            -H "Content-Type: application/json" \
            -H "Accept: application/json"
        # Atau deploy via SSH
      - name: Deploy via SSH
        uses: appleboy/ssh-action@v0.1.5
        with:
          host: ${{ secrets.SERVER_HOST }}
          username: ${{ secrets.SERVER_USER }}
          key: ${{ secrets.SERVER_SSH_KEY }}
          script: |
            cd /var/www/app
            git pull origin main
            composer install --no-dev --optimize-autoloader
            php artisan migrate --force
            php artisan optimize
            npm ci && npm run build

  # === Deploy to Vapor (serverless) ===
  deploy-vapor:
    needs: quality
    if: github.ref == 'refs/heads/main'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: shivammathur/setup-php@v2
        with:
          php-version: '8.2'
      - name: Deploy to Vapor
        run: |
          composer install
          vapor deploy production
        env:
          VAPOR_API_TOKEN: ${{ secrets.VAPOR_API_TOKEN }}
```

      interval: "weekly"

## Kasus Penggunaan Nyata
Tim 5 developer — setiap push ke `develop` otomatis running test. Push ke `main` deploy ke staging. Tag `v*` deploy ke production. Zero human error deployment.
