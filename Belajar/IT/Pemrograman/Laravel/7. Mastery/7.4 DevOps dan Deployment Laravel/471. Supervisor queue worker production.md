# 471. Supervisor Queue Worker Production

## Definisi Singkat
Konfigurasi Supervisor untuk mengelola queue worker Laravel di production — memastikan worker selalu berjalan, restart otomatis jika mati, dan logging.

## Analogi
Seperti petugas keamanan 24 jam — Supervisor menjaga pintu (worker) tetap terbuka. Jika petugas lelah (worker crash), Supervisor panggil pengganti (restart).

## Poin-Poin Penting
- Supervisor — process control system untuk Linux
- Queue worker butuh supervisor agar selalu jalan
- Konfigurasi di `/etc/supervisor/conf.d/`
- Multiple worker processes untuk paralel
- log output ke file untuk debugging
- Restart worker setelah deploy

## Contoh Kode
```ini
; /etc/supervisor/conf.d/laravel-worker.conf
[program:laravel-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/app/artisan queue:work redis --sleep=3 --tries=3 --max-time=3600
directory=/var/www/app
autostart=true
autorestart=true
stopwaitsecs=600
stopasgroup=true
killasgroup=true
user=forge
numprocs=4
redirect_stderr=true
stdout_logfile=/var/www/app/storage/logs/worker.log
stdout_logfile_maxbytes=50MB
stdout_logfile_backups=3

; Worker khusus untuk high-priority queue
[program:laravel-worker-high]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/app/artisan queue:work redis --queue=high --sleep=3 --tries=1
directory=/var/www/app
autostart=true
autorestart=true
user=forge
numprocs=2
redirect_stderr=true
stdout_logfile=/var/www/app/storage/logs/worker-high.log

; Worker untuk low-priority queue
[program:laravel-worker-low]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/app/artisan queue:work redis --queue=low --sleep=5 --tries=5
directory=/var/www/app
autostart=true
autorestart=true
user=forge
numprocs=2
redirect_stderr=true
stdout_logfile=/var/www/app/storage/logs/worker-low.log
```

```bash
# Install Supervisor
sudo apt install -y supervisor

# Command management
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start all
sudo supervisorctl status

# Output contoh:
# laravel-worker:laravel-worker_00     RUNNING   pid 12345, uptime 3 days
# laravel-worker:laravel-worker_01     RUNNING   pid 12346, uptime 3 days
# laravel-worker:laravel-worker_02     RUNNING   pid 12347, uptime 3 days
# laravel-worker:laravel-worker_03     RUNNING   pid 12348, uptime 3 days

# Restart worker setelah deploy
sudo supervisorctl restart all

# Atau hanya restart lewat Laravel
php artisan queue:restart
# Ini mengirim sinyal restart ke semua worker secara graceful

# Logs
sudo supervisorctl tail -f laravel-worker

// Config queue di Laravel
// config/queue.php
'connections' => [
    'redis' => [
        'driver' => 'redis',
        'connection' => 'default',
        'queue' => env('REDIS_QUEUE', 'default'),
        'retry_after' => 90,
        'block_for' => null,
        'after_commit' => true,
    ],
],

// Dispatch ke queue spesifik
ProcessPayment::dispatch($order)->onQueue('high');
SendNewsletter::dispatch($users)->onQueue('low');
```

## Kasus Penggunaan Nyata
Platform email marketing — 1 juta email dikirim via queue. Supervisor jalankan 10 worker paralel, tiap worker proses 100 email/detik. Selesai dalam 17 menit.
