# 491. Dokumentasi Resmi Laravel

## Definisi Singkat
Sumber utama dokumentasi framework Laravel di `laravel.com/docs` — referensi paling otoritatif dan selalu up-to-date untuk semua fitur Laravel.

## Analogi
Seperti buku manual mobil — semua informasi tentang mobil ada di sana: cara nyalakan, ganti ban, isi bensin. Jangan tanya bengkel sebelum baca manual.

## Poin-Poin Penting
- Dokumentasi resmi: https://laravel.com/docs
- Selalu update ke versi terbaru (saat ini 11.x / 12.x)
- Terjemahan resmi dalam berbagai bahasa
- Contoh kode lengkap untuk setiap fitur
- Release notes untuk perubahan versi
- Upgrade guide dari versi lama ke baru

## Contoh Kode
```
// Sumber daya utama:
// 1. Dokumentasi resmi
https://laravel.com/docs

// 2. API documentation
https://laravel.com/api/11.x

// 3. Laravel News
https://laravel-news.com

// 4. Laracasts
https://laracasts.com

// 5. Laravel Blog
https://blog.laravel.com

// Bagian penting di dokumentasi:
// - Installation & Configuration

// - Database & Migrations
// - Queues & Jobs
// - Broadcasting & Events
// - Authentication & Authorization
// - Testing
// - Packages (Cashier, Dusk, Horizon, dll)
// - Deployment

// Cari di dokumentasi dengan Google:
// site:laravel.com/docs "query pencarian"

// Versi dokumentasi:
// https://laravel.com/docs/11.x
// https://laravel.com/docs/10.x
// https://laravel.com/docs/9.x
// Ganti 11.x dengan versi yang diinginkan
```

## Kasus Penggunaan Nyata
Developer bingung cara pakai Laravel Broadcasting — buka dokumentasi resmi, baca panduan lengkap dengan contoh kode, selesai dalam 10 menit.
