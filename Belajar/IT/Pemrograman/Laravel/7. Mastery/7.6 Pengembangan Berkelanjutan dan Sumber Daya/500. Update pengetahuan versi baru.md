# 500. Update Pengetahuan Versi Baru

## Definisi Singkat
Strategi untuk tetap update dengan perkembangan Laravel — mengikuti rilis versi baru, mempelajari fitur, migrasi kode lama, dan mengadopsi best practices terbaru.

## Analogi
Seperti update sistem operasi smartphone — setiap versi baru datang dengan fitur baru, performa lebih baik, dan security patch. Jangan terlalu lama pakai versi lama.

## Poin-Poin Penting
- Laravel rilis major baru setiap tahun (~Q1)
- Setiap LTS didukung 2 tahun bug fix, 3 tahun security
- Upgrade guide resmi di dokumentasi
- Laravel Shift — tool upgrade otomatis berbayar
- Breaking changes diumumkan di release notes
- Package harus kompatibel dengan versi baru

## Contoh Kode
```
// Siklus rilis Laravel:
// Laravel 9  (LTS) — Feb 2022 - Feb 2024
// Laravel 10 (LTS) — Feb 2023 - Feb 2025
// Laravel 11 (LTS) — Mar 2024 - Mar 2026
// Laravel 12 (?)   — 2025

// Cara update Laravel:
// 1. Baca Upgrade Guide
https://laravel.com/docs/11.x/upgrade

// 2. Backup project
git checkout -b upgrade-to-11

// 3. Update composer.json
"require": {
    "laravel/framework": "^11.0"
}

// 4. Jalankan update
composer update

// 5. Fix breaking changes
// - Laravel Shift untuk otomatis:
https://laravelshift.com

// 6. Test semua fitur
php artisan test

// Fitur baru yang perlu dipelajari:
// Laravel 10:
// - Native type declarations
// - Process layer (Inspecting)
// - Invokable validation rules
// - Laravel Pennant (feature flags)

// Laravel 11:
// - Slimmer default app structure
// - Health routing
// - Graceful encryption key rotation
// - SQLite testing
// - Resend mail transport
// - Once() helper
// - Cache::flexible() untuk stampede

// Cara belajar fitur baru:
// 1. Baca release notes
https://laravel.com/docs/releases

// 2. Tonton Laracasts
https://laracasts.com/series/whats-new-in-laravel-11

// 3. Ikuti Laravel News
https://laravel-news.com

// 4. Coba di project sampingan
// 5. Upgrade project lama setelah stabil

// Tool untuk upgrade:
// 1. Laravel Shift — $99/project
// 2. Rector — PHP upgrade automation
// 3. Psalm/PHPStan — deteksi kode usang

// Jadwal belajar:
// - Saat beta rilis: baca changelog
// - Saat stable: upgrade project test
// - 1 bulan setelah stable: upgrade production
```

## Kasus Penggunaan Nyata
Tim engineer di perusahaan melakukan upgrade Laravel 10 ke 11 — menggunakan Laravel Shift untuk otomatisasi, selesai dalam 2 hari. Aplikasi berjalan dengan fitur baru.
