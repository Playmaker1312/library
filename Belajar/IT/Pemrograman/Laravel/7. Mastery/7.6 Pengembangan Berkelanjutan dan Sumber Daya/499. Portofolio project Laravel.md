# 499. Portofolio Project Laravel

## Definisi Singkat
Panduan membangun portofolio project Laravel untuk menunjukkan kemampuan kepada klien atau calon employer — mencakup ide project, deployment, dan presentasi.

## Analogi
Seperti buku tamu di restoran — portofolio adalah daftar "masakan" (project) yang sudah pernah kita buat, lengkap dengan foto dan testimoni. Calon pembeli bisa lihat kemampuan kita.

## Poin-Poin Penting
- Pilih project yang menunjukkan skill variatif
- Hosting di platform gratis/low-cost
- Tampilkan source code di GitHub
- Tulis README yang baik
- Dokumentasikan arsitektur dan keputusan teknis
- Sertakan live demo jika memungkinkan

## Installation
```bash
git clone https://github.com/username/project
cd project
cp .env.example .env
composer install
php artisan key:generate
php artisan migrate --seed
php artisan serve
```
