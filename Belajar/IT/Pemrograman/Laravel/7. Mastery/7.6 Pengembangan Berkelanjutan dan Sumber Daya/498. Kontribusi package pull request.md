# 498. Kontribusi Package Pull Request

## Definisi Singkat
Panduan berkontribusi ke ekosistem Laravel — membuat pull request untuk fix bug, tambah fitur, atau perbaiki dokumentasi di package Laravel resmi maupun komunitas.

## Analogi
Seperti gotong royong membersihkan lingkungan — kita bantu perbaiki jalan yang rusak (fix bug), cat ulang pagar (dokumentasi), atau tambah lampu (fitur baru). Semua untuk kebaikan bersama.

## Poin-Poin Penting
- Mulai dari kontribusi kecil: dokumentasi, typo
- Baca CONTRIBUTING.md di tiap repository
- Ikuti coding style Laravel (Pint)
- Tulis test untuk setiap perubahan
- Buat Pull Request yang fokus (satu issue per PR)
- Sabar menunggu review

## Contoh Kode
```
// 1. Mulai dari dokumentasi
// - Perbaiki typo
// - Perjelas penjelasan
// - Tambah contoh kode
// - Update versi yang kadaluarsa

// 2. Report issues
// - Cek dulu apakah sudah ada issue serupa
// - Jelaskan langkah reproduce bug
// - Sertakan environment (Laravel, PHP versi)
// - Lampirkan error message lengkap
// - Minimal code untuk reproduce

// 3. Pull Request workflow
// a. Fork repository
// b. Clone fork lokal
git clone https://github.com/USERNAME/framework.git
cd framework

// c. Buat branch
git checkout -b fix/issue-12345

// d. Buat perubahan
// e. Jalankan test
./vendor/bin/phpunit
./vendor/bin/pint --test

// f. Commit dengan format
// [X.x] Fix something (#12345)
git commit -m "[11.x] Fix N+1 query in User::all() (#12345)"

// g. Push
git push origin fix/issue-12345

// h. Buat Pull Request di GitHub
// i. Isi deskripsi: apa yang diubah dan mengapa

// 4. Tips PR diterima
// - Satu PR = satu perubahan
// - Tulis test yang jelas
// - Ikuti coding style yang ada
// - Jangan ubah hal yang tidak terkait
// - Responsif terhadap feedback

// 5. Kontribusi ke package komunitas
// - Cari issue label: "good first issue"
// - Label: "help wanted", "bug"
// - Mulai dari package yang sering dipakai

// Contoh ISSUE_TEMPLATE.md
---
name: Bug Report
about: Create a report to help us improve
title: ''
labels: bug
assignees: ''
---

**Description**
Clear description of the bug.

**Steps to reproduce**
1. Go to '...'
2. Click on '....'
3. See error

**Expected behavior**
What should happen.

**Environment:**
- Laravel Version: 11.x
- PHP Version: 8.2
- Database: MySQL 8.0
```

## Kasus Penggunaan Nyata
Developer menemukan bug di dokumentasi Laravel error link — fork repositori docs, edit file, buat PR. Dalam 2 hari PR di-merge. Nama tercatat di kontributor.
