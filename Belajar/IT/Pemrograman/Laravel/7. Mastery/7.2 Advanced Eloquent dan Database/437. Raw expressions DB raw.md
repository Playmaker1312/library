# 437. Raw Expressions DB raw

## Definisi Singkat
Penggunaan ekspresi SQL mentah di Laravel melalui `DB::raw()`, `selectRaw()`, `whereRaw()`, `orderByRaw()` — untuk query yang tidak bisa diakomodasi Query Builder standar.

## Analogi
Seperti mode manual di mobil matic — kadang perlu kendali penuh untuk situasi tertentu yang tidak bisa ditangani mode otomatis.

## Poin-Poin Penting
- Hanya untuk kasus yang tidak bisa pakai Query Builder
- Risiko SQL injection jika tidak hati-hati
- Binding parameter wajib untuk input user
- Alternatif: `whereIn`, `whereBetween` dll lebih aman
- Kombinasikan dengan Query Builder untuk fleksibilitas

## Contoh Kode
```php
<?php

use Illuminate\Support\Facades\DB;

// selectRaw — agregasi kompleks
$users = DB::table('orders')
    ->selectRaw('user_id, COUNT(*) as total_orders, SUM(total) as total_spent')
    ->selectRaw('AVG(total) as avg_order_value')
    ->selectRaw("DATE_FORMAT(created_at, '%Y-%m') as month")
    ->whereRaw('YEAR(created_at) = ?', [2024])
    ->groupBy('user_id', 'month')
    ->havingRaw('total_orders > ?', [5])
    ->orderByRaw('total_spent DESC')
    ->get();

// whereRaw dengan binding parameter
$products = DB::table('products')
    ->whereRaw('MATCH(name, description) AGAINST(? IN BOOLEAN MODE)', [$searchTerm])
    ->get();

// orderByRaw — complex sort
$posts = DB::table('posts')
    ->orderByRaw("
        CASE
            WHEN featured = 1 THEN 0
            WHEN pinned = 1 THEN 1
            ELSE 2
        END, created_at DESC
    ")
    ->get();

// DB::raw di Eloquent
$users = User::select('users.*')
    ->selectSub(function ($q) {
        $q->from('orders')
          ->selectRaw('COALESCE(SUM(total), 0)')
          ->whereColumn('user_id', 'users.id');
    }, 'lifetime_value')
    ->whereRaw('EXISTS (
        SELECT 1 FROM orders
        WHERE user_id = users.id AND status = "pending"
    )')
    ->get();

// Raw update dengan expression
DB::table('products')
    ->where('id', 1)
    ->update([
        'stock' => DB::raw('stock - 1'),
        'views' => DB::raw('views + 1'),
        'updated_at' => DB::raw('NOW()'),
    ]);

// JSON path query (MySQL)
$data = DB::table('users')
    ->whereRaw('JSON_EXTRACT(metadata, "$.phone") IS NOT NULL')
    ->get();

// Peringatan: gunakan parameter binding untuk input user
// ❌ JANGAN
DB::raw("name = '$search'");   // SQL injection!
// ✅ AMAN
DB::raw('name = ?', [$search]); // parameter binding
```

## Kasus Penggunaan Nyata
Laporan keuangan dengan perhitungan pajak, diskon bertingkat, dan grouping complex — menggunakan `selectRaw()` dan `havingRaw()` untuk formula SQL yang tidak mungkin dibuat dengan Query Builder murni.
