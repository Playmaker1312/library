# 433. Database Transactions Eloquent Query Builder

## Definisi Singkat
Mekanisme database yang memastikan sekelompok query berjalan atomic — semua berhasil atau semua gagal (rollback), mencegah data tidak konsisten.

## Analogi
Seperti transfer bank — pengiriman uang dan penerimaan harus terjadi bersama. Jika salah satu gagal, transaksi dibatalkan total.

## Poin-Poin Penting
- Atomicity — semua atau tidak sama sekali
- Otomatis rollback saat exception
- Transaction bisa di-nest (savepoints)
- Eloquent model events tetap jalan dalam transaction
- Pilih isolation level sesuai kebutuhan

## Contoh Kode
```php
<?php

use Illuminate\Support\Facades\DB;
use App\Models\Order;
use App\Models\Product;

// Transaction manual
DB::beginTransaction();

try {
    $order = Order::create([
        'user_id' => $userId,
        'total' => $total,
    ]);

    foreach ($cartItems as $item) {
        $product = Product::lockForUpdate()->find($item['product_id']);

        if ($product->stock < $item['quantity']) {
            throw new \Exception("Insufficient stock for {$product->name}");
        }

        $product->decrement('stock', $item['quantity']);

        $order->items()->create([
            'product_id' => $product->id,
            'quantity' => $item['quantity'],
            'price' => $product->price,
        ]);
    }

    DB::commit();
} catch (\Exception $e) {
    DB::rollBack();
    throw $e; // atau handle sesuai kebutuhan
}

// Transaction dengan closure (recommended)
DB::transaction(function () use ($orderData, $items) {
    $order = Order::create($orderData);

    foreach ($items as $item) {
        $product = Product::lockForUpdate()->findOrFail($item['id']);

        throw_if(
            $product->stock < $item['qty'],
            \App\Exceptions\InsufficientStockException::class
        );

        $product->decrement('stock', $item['qty']);
        $order->items()->create($item);
    }

    return $order;
}, attempts: 3); // retry 3 kali jika deadlock

// Transaction dengan Eloquent events
$order = DB::transaction(function () {
    $order = Order::create([...]);
    // saved events akan triggered setelah commit
    return $order;
});
```

## Kasus Penggunaan Nyata
Sistem pemesanan tiket konser — 500 orang memesan 3 tiket tersisa. Transaction memastikan tidak ada overselling karena stock di-decrement dalam lock.
