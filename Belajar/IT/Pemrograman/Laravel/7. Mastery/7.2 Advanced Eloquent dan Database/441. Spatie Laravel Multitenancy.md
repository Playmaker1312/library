# 441. Spatie Laravel Multitenancy

## Definisi Singkat
Package multitenancy dari Spatie untuk Laravel yang menyediakan solusi lengkap — identifikasi tenant, isolasi database, queue, dan caching per tenant.

## Analogi
Seperti sistem apartemen yang sudah dilengkapi lift, keamanan, dan utilitas — tinggal pakai, tidak perlu bangun dari nol.

## Poin-Poin Penting
- Support single DB dan multi DB
- Tenant identification via domain/subdomain/header
- Isolasi queue per tenant
- Cache prefix per tenant
- Artisan commands untuk management tenant

## Contoh Kode
```php
// Install
composer require spatie/laravel-multitenancy

// Publish config
php artisan vendor:publish --provider="Spatie\Multitenancy\MultitenancyServiceProvider"
php artisan vendor:publish --tag="multitenancy-migrations"

// Run migration
php artisan migrate

// config/multitenancy.php
return [
    'tenant_model' => App\Models\Tenant::class,
    'tenant_identification' => [
        'domain' => [
            'first_segment' => true, // tenant.example.com
        ],
    ],
    'tenant_database_connection_name' => 'tenant',
    'switchable_tenant_connections' => [
        'mysql',
    ],
    'queues_are_tenant_aware' => true,
    'cache_is_tenant_aware' => true,
];

// Model Tenant
use Spatie\Multitenancy\Models\Tenant;
use Spatie\Multitenancy\Models\Concerns\UsesLandlordConnection;

class Tenant extends Model
{
    use UsesLandlordConnection;

    protected $fillable = ['domain', 'database'];

    public static function booted(): void
    {
        static::creating(function (Tenant $tenant) {
            $tenant->database = 'tenant_' . Str::random(8);
        });
    }
}

// Event untuk setup tenant database
use Spatie\Multitenancy\Events\MadeTenantCurrentEvent;

class CreateTenantDatabase
{
    public function handle(MadeTenantCurrentEvent $event): void
    {
        $tenant = $event->tenant;

        DB::statement("CREATE DATABASE IF NOT EXISTS `{$tenant->database}`");

        config(['database.connections.tenant.database' => $tenant->database]);
        DB::purge('tenant');
        DB::reconnect('tenant');

        Artisan::call('migrate', [
            '--database' => 'tenant',
            '--path' => 'database/migrations/tenant',
            '--force' => true,
        ]);
    }
}

// Artisan commands
// Buat tenant baru
php artisan tenant:create tenant1.example.com

// Masuk ke tenant shell
php artisan tenant:artisan tenant1.example.com -- migrate

// Queue worker per tenant
php artisan queue:work --tenant=1
```

## Kasus Penggunaan Nyata
SaaS CRM untuk 500 perusahaan — dengan Spatie Multitenancy, tiap perusahaan punya database terpisah, queue sendiri, dan cache sendiri tanpa khawatir data tercampur.
