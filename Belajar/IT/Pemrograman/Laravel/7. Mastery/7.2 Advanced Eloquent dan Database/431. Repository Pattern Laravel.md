# 431. Repository Pattern Laravel

## Definisi Singkat
Pola desain yang memisahkan logika akses data (query) dari logika bisnis dengan membuat kelas repository sebagai perantara antara controller/model dan database.

## Analogi
Seperti resepsionis hotel — tamu (controller) tidak perlu tahu bagaimana sistem kamar bekerja, cukup minta ke resepsionis (repository) yang mengurus semuanya.

## Poin-Poin Penting
- Abstraksi database — ganti ORM kapan saja
- Testability — mudah di-mock
- Separation of concerns
- Jangan over-engineer untuk project kecil
- Kombinasikan dengan Service Layer

## Contoh Kode
```php
<?php

namespace App\Repositories;

use App\Models\User;
use Illuminate\Support\Collection;

class UserRepository
{
    public function __construct(
        protected User $model
    ) {}

    public function find(int $id): ?User
    {
        return $this->model->find($id);
    }

    public function findByEmail(string $email): ?User
    {
        return $this->model->where('email', $email)->first();
    }

    public function all(): Collection
    {
        return $this->model->with('profile')->get();
    }

    public function create(array $data): User
    {
        return $this->model->create($data);
    }

    public function update(int $id, array $data): bool
    {
        return $this->model->findOrFail($id)->update($data);
    }

    public function delete(int $id): bool
    {
        return $this->model->findOrFail($id)->delete();
    }

    public function paginate(int $perPage = 15)
    {
        return $this->model->latest()->paginate($perPage);
    }
}

// Interface repository (opsional)
interface UserRepositoryInterface
{
    public function find(int $id): ?User;
    public function findByEmail(string $email): ?User;
    public function create(array $data): User;
}

// Binding di AppServiceProvider
$this->app->bind(
    UserRepositoryInterface::class,
    UserRepository::class
);

// Penggunaan di controller
class UserController extends Controller
{
    public function __construct(
        protected UserRepository $users
    ) {}

    public function index()
    {
        return UserResource::collection(
            $this->users->paginate()
        );
    }
}
```

## Kasus Penggunaan Nyata
Migrasi dari MySQL ke PostgreSQL — cukup buat implementasi repository baru tanpa mengubah controller atau service layer.
