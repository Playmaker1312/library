# 436. Pessimistic Locking lockForUpdate

## Definisi Singkat
Mekanisme mengunci baris database secara eksplisit saat dibaca (`SELECT ... FOR UPDATE`) sehingga transaksi lain tidak bisa membaca atau mengubah data sampai lock dilepas.

## Analogi
Seperti toilet umum — pintu dikunci (lock) saat dipakai. Orang lain harus menunggu sampai pintu terbuka (lock release) baru bisa masuk.

## Poin-Poin Penting
- `lockForUpdate()` — mencegah write dan read dari transaksi lain
- `sharedLock()` — boleh baca, tidak boleh write
- Hanya efektif dalam transaction
- Risiko deadlock — urutan akses harus konsisten
- Cocok untuk update data keuangan, stok, booking

## Contoh Kode
```php
<?php

use Illuminate\Support\Facades\DB;
use App\Models\Account;
use App\Models\SeatReservation;

// Pessimistic locking dengan lockForUpdate
DB::transaction(function () {
    // Kunci baris rekening — transaksi lain harus tunggu
    $from = Account::lockForUpdate()->findOrFail(1);
    $to = Account::lockForUpdate()->findOrFail(2);

    $from->decrement('balance', 100000);
    $to->increment('balance', 100000);
});

// Booking kursi dengan lock
DB::transaction(function () use ($seatIds, $userId) {
    // Ambil kursi dan kunci — cegah double booking
    $seats = SeatReservation::whereIn('id', $seatIds)
        ->where('status', 'available')
        ->lockForUpdate()
        ->get();

    throw_if(
        $seats->count() !== count($seatIds),
        \App\Exceptions\SeatNotAvailableException::class
    );

    SeatReservation::whereIn('id', $seatIds)
        ->update(['status' => 'booked', 'user_id' => $userId]);
});

// Shared lock — boleh baca bersamaan, tidak bisa write
DB::transaction(function () {
    $report = DB::table('sales_summary')
        ->where('date', today())
        ->sharedLock()
        ->get();

    // Transaksi lain bisa baca, tapi tidak bisa update
});

// Lock dengan kondisi
DB::transaction(function () {
    $product = Product::where('sku', 'ABC-123')
        ->where('stock', '>', 0)
        ->lockForUpdate()
        ->first();

    if (!$product) {
        throw new \Exception('Stock habis');
    }

    $product->decrement('stock');
});

// Cegah deadlock — urutan akses konsisten
// ✅ Selalu akses ID kecil dulu
DB::transaction(function () {
    $a = Account::lockForUpdate()->find(min($aId, $bId));
    $b = Account::lockForUpdate()->find(max($aId, $bId));
    // proses...
});
```

## Kasus Penggunaan Nyata
Sistem booking tiket pesawat — 1000 orang berebut 50 tiket. `lockForUpdate()` memastikan tiket hanya dibeli satu orang, sisanya mendapat notifikasi "sudah dibooking orang lain".
