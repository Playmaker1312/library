# 439. Scout Algolia Meilisearch

## Definisi Singkat
Perbandingan dan konfigurasi driver full-text search untuk Laravel Scout — Algolia (cloud) vs Meilisearch (self-hosted/open source).

## Analogi
Algolia seperti hotel bintang 5 (full-service, bayar per kamar), Meilisearch seperti kos-kosan (sendiri urus, lebih murah, fleksibel).

## Poin-Poin Penting
- Algolia: cloud managed, bayar per search operation
- Meilisearch: self-hosted, open source, gratis
- Algolia: sangat cepat, fitur typo tolerance
- Meilisearch: lebih simple, instant search
- Keduanya support Scout engine

## Contoh Kode
```php
// Install Algolia driver
composer require algolia/algoliasearch-client-php
// .env
SCOUT_DRIVER=algolia
ALGOLIA_APP_ID=your-app-id
ALGOLIA_SECRET=your-admin-api-key

// Install Meilisearch driver
composer require meilisearch/meilisearch-php http-interop/http-factory-guzzle
// .env
SCOUT_DRIVER=meilisearch
MEILISEARCH_HOST=http://127.0.0.1:7700
MEILISEARCH_KEY=your-master-key

// config/scout.php
return [
    'driver' => env('SCOUT_DRIVER', 'meilisearch'),
    'queue' => env('SCOUT_QUEUE', true),
    'after_commit' => true,
    'chunk' => [
        'searchable' => 500,
        'unsearchable' => 500,
    ],
    'prefix' => env('SCOUT_PREFIX', ''),
    // Meilisearch specific
    'meilisearch' => [
        'host' => env('MEILISEARCH_HOST', 'http://localhost:7700'),
        'key' => env('MEILISEARCH_KEY', null),
    ],
    // Algolia specific
    'algolia' => [
        'id' => env('ALGOLIA_APP_ID', ''),
        'secret' => env('ALGOLIA_SECRET', ''),
    ],
];

// Model settings untuk Meilisearch
class Product extends Model
{
    use Searchable;

    public function toSearchableArray(): array
    {
        return [
            'id' => $this->id,
            'name' => $this->name,
            'description' => $this->description,
            'price' => $this->price,
            'categories' => $this->categories->pluck('name'),
        ];
    }

    // Meilisearch index settings
    public function searchableAs(): string
    {
        return 'products_index';
    }
}

// Setting Meilisearch via API
// products_index settings
$settings = [
    'searchableAttributes' => ['name', 'description', 'categories'],
    'filterableAttributes' => ['price'],
    'sortableAttributes' => ['price'],
    'rankingRules' => ['words', 'typo', 'proximity', 'attribute', 'sort'],
];

// Import ke Meilisearch
php artisan scout:import "App\Models\Product"

// Search
$products = Product::search('laptop gaming')
    ->where('price', '<', 20000000)
    ->orderBy('price', 'asc')
    ->get();
```

## Kasus Penggunaan Nyata
Startup e-commerce — mulai dengan Meilisearch (gratis) di VPS, setelah traffic membesar migrasi ke Algolia untuk managed search tanpa repot maintain server.
