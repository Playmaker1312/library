# 434. DB Transaction Closure

## Definisi Singkat
Penggunaan method `DB::transaction()` dengan closure — cara paling idiomatis dan aman untuk menjalankan database transactions di Laravel.

## Analogi
Seperti mesin cuci otomatis — masukkan baju (data), tekan tombol (closure), mesin cuci urus semuanya, jika listrik mati proses dibatalkan.

## Poin-Poin Penting
- Otomatis commit jika sukses, rollback jika exception
- Bisa menentukan jumlah retry (parameter kedua)
- Return value dari closure dikembalikan
- Nested transaction otomatis pakai savepoint
- Exception handling lebih bersih

## Contoh Kode
```php
<?php

use Illuminate\Support\Facades\DB;
use App\Models\Account;
use App\Exceptions\InsufficientBalanceException;

// Basic transaction closure
$transfer = DB::transaction(function () use ($fromId, $toId, $amount) {
    $from = Account::lockForUpdate()->findOrFail($fromId);
    $to = Account::lockForUpdate()->findOrFail($toId);

    throw_if(
        $from->balance < $amount,
        InsufficientBalanceException::class
    );

    $from->decrement('balance', $amount);
    $to->increment('balance', $amount);

    return Transfer::create([
        'from_account_id' => $fromId,
        'to_account_id' => $toId,
        'amount' => $amount,
    ]);
});

// Dengan retry jika deadlock
$result = DB::transaction(function () {
    $product = Product::lockForUpdate()->find(1);
    $product->decrement('stock');
    return $product;
}, attempts: 5); // retry up to 5 times

// Nested transaction
DB::transaction(function () {
    $user = User::create([...]);

    DB::transaction(function () use ($user) {
        $user->profile()->create([...]);
        // Jika gagal, savepoint rollback, transaksi luar tetap aman
    });
});

// Dengan custom exception handling
try {
    $order = DB::transaction(function () use ($data) {
        $order = Order::create($data);
        // proses lain
        return $order;
    });
} catch (QueryException $e) {
    if ($e->getCode() === '23000') {
        // Constraint violation
    }
    throw $e;
}

// Returning value dari transaction
$stats = DB::transaction(function () {
    $count = User::count();
    $sum = Order::sum('total');
    return compact('count', 'sum');
});
```

## Kasus Penggunaan Nyata
Fitur top-up dompet digital — pengurangan saldo bank dan penambahan saldo dompet dibungkus dalam `DB::transaction()` dengan retry 3x untuk antisipasi deadlock.
