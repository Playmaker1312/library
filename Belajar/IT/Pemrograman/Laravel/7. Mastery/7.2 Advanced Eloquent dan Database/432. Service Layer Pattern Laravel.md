# 432. Service Layer Pattern Laravel

## Definisi Singkat
Pola arsitektur yang memisahkan logika bisnis dari controller dan model dengan menempatkannya di kelas Service khusus.

## Analogi
Seperti dapur restoran — pelayan (controller) menerima pesanan, chef (service) memasak makanan (logika bisnis), dan gudang (repository/model) menyimpan bahan.

## Poin-Poin Penting
- Controller tetap ramping — hanya handling HTTP
- Logika bisnis reusable dari berbagai entry point
- Test lebih mudah — unit test service saja
- Hindari fat model dan fat controller
- Service bisa dipanggil dari controller, command, job

## Contoh Kode
```php
<?php

namespace App\Services;

use App\Models\Order;
use App\Repositories\OrderRepository;
use Illuminate\Support\Facades\DB;

class OrderService
{
    public function __construct(
        protected OrderRepository $orderRepo,
        protected InvoiceService $invoiceService,
        protected NotificationService $notificationService,
    ) {}

    public function checkout(array $cartData, int $userId): Order
    {
        return DB::transaction(function () use ($cartData, $userId) {
            $order = $this->orderRepo->create([
                'user_id' => $userId,
                'status' => 'pending',
                'total' => $this->calculateTotal($cartData),
            ]);

            $this->createOrderItems($order, $cartData);
            $this->invoiceService->generate($order);
            $this->notificationService->orderConfirmation($order);

            return $order;
        });
    }

    public function cancelOrder(int $orderId): void
    {
        $order = $this->orderRepo->findOrFail($orderId);
        if ($order->status !== 'pending') {
            throw new \DomainException('Cannot cancel processed order');
        }
        $this->orderRepo->update($orderId, ['status' => 'cancelled']);
        $this->notificationService->orderCancelled($order);
    }

    protected function calculateTotal(array $items): float
    {
        return collect($items)->sum(fn($item) => $item['price'] * $item['quantity']);
    }

    protected function createOrderItems(Order $order, array $items): void
    {
        foreach ($items as $item) {
            $order->items()->create([
                'product_id' => $item['product_id'],
                'quantity' => $item['quantity'],
                'price' => $item['price'],
            ]);
        }
    }
}

// Controller yang ramping
class CheckoutController extends Controller
{
    public function __construct(
        protected OrderService $orderService
    ) {}

    public function store(CheckoutRequest $request)
    {
        $order = $this->orderService->checkout(
            $request->validated()['items'],
            auth()->id()
        );

        return redirect()->route('orders.show', $order);
    }
}
```

## Kasus Penggunaan Nyata
Fitur checkout yang memproses pembayaran, mengurangi stok, mengirim invoice, dan notifikasi — semua logika di `OrderService`, controller hanya validasi dan redirect.
