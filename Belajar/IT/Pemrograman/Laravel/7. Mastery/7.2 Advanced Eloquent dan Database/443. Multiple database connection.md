# 443. Multiple Database Connection

## Definisi Singkat
Konfigurasi Laravel untuk terhubung ke beberapa database berbeda (MySQL, PostgreSQL, SQLite, dll) dalam satu aplikasi, baik untuk replikasi, migrasi, atau integrasi.

## Analogi
Seperti resepsionis yang mengelola beberapa telepon — satu untuk internal, satu untuk eksternal, satu untuk darurat. Semua terintegrasi di satu meja.

## Poin-Poin Penting
- Definisikan multiple connections di `config/database.php`
- Pilih koneksi via `DB::connection('name')`
- Model bisa punya `$connection` property
- Migration bisa diarahkan ke koneksi spesifik
- Query Builder dan Eloquent support multi-connection

## Contoh Kode
```php
<?php

// config/database.php
return [
    'default' => env('DB_CONNECTION', 'mysql'),

    'connections' => [
        'mysql' => [
            'driver' => 'mysql',
            'host' => env('DB_HOST', '127.0.0.1'),
            'port' => env('DB_PORT', '3306'),
            'database' => env('DB_DATABASE', 'forge'),
            'username' => env('DB_USERNAME', 'forge'),
            'password' => env('DB_PASSWORD', ''),
        ],

        'mysql_analytics' => [
            'driver' => 'mysql',
            'host' => env('DB_ANALYTICS_HOST', '127.0.0.1'),
            'port' => env('DB_ANALYTICS_PORT', '3306'),
            'database' => env('DB_ANALYTICS_DATABASE', 'analytics'),
            'username' => env('DB_ANALYTICS_USERNAME', 'forge'),
            'password' => env('DB_ANALYTICS_PASSWORD', ''),
        ],

        'legacy_mysql' => [
            'driver' => 'mysql',
            'host' => env('DB_LEGACY_HOST'),
            'port' => env('DB_LEGACY_PORT', '3306'),
            'database' => env('DB_LEGACY_DATABASE'),
            'username' => env('DB_LEGACY_USERNAME'),
            'password' => env('DB_LEGACY_PASSWORD'),
        ],

        'sqlite_logs' => [
            'driver' => 'sqlite',
            'url' => env('DATABASE_URL'),
            'database' => database_path('logs.sqlite'),
        ],
    ],
];

// Model dengan koneksi spesifik
class AnalyticsPageView extends Model
{
    protected $connection = 'mysql_analytics';
    protected $table = 'page_views';
    protected $fillable = ['url', 'user_agent', 'ip', 'visited_at'];
}

class LegacyProduct extends Model
{
    protected $connection = 'legacy_mysql';
    protected $table = 'products';
    public $timestamps = false; // legacy table mungkin tanpa timestamps
}

// Query Builder ke koneksi lain
$analytics = DB::connection('mysql_analytics')
    ->table('page_views')
    ->whereDate('visited_at', today())
    ->count();

// Transaction antar koneksi
DB::connection('mysql')->beginTransaction();
DB::connection('mysql_analytics')->beginTransaction();

try {
    DB::connection('mysql')->table('orders')->insert([...]);
    DB::connection('mysql_analytics')->table('sales_summary')->insert([...]);

    DB::connection('mysql')->commit();
    DB::connection('mysql_analytics')->commit();
} catch (\Throwable $e) {
    DB::connection('mysql')->rollBack();
    DB::connection('mysql_analytics')->rollBack();
    throw $e;
}

// Migration ke koneksi spesifik
// database/migrations/analytics/ create_page_views_table.php
class CreatePageViewsTable extends Migration
{
    protected $connection = 'mysql_analytics';

    public function up(): void
    {
        Schema::connection('mysql_analytics')
            ->create('page_views', function (Blueprint $table) {
                $table->id();
                $table->string('url');
                $table->timestamps();
            });
    }
}
```

## Kasus Penggunaan Nyata
Aplikasi dengan database utama MySQL untuk transaksi, database PostgreSQL untuk data geografis, dan SQLite untuk log debug lokal — semua dari satu aplikasi Laravel.
