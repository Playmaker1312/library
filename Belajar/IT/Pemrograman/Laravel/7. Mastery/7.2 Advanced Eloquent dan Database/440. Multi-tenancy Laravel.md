# 440. Multi-tenancy Laravel

## Definisi Singkat
Arsitektur aplikasi dimana satu instance Laravel melayani banyak tenant (klien/organisasi) dengan data terisolasi, baik via database terpisah (single DB) atau baris data (single DB).

## Analogi
Seperti apartemen — satu gedung (aplikasi) berisi banyak unit (tenant). Setiap unit punya kunci sendiri (isolasi data) dan tidak bisa akses unit lain.

## Poin-Poin Penting
- Single Database (Tenant per baris) — sharing DB, kolom `tenant_id`
- Multi Database (Tenant per DB) — setiap tenant punya DB sendiri
- Tenant identification via subdomain/domain
- Middleware untuk set connection otomatis
- Package populer: stancl/tenancy, hyn/multi-tenant

## Contoh Kode
```php
<?php

namespace App\Models;

use App\Observers\TenantObserver;

// Single database approach (row-level)
class Post extends Model
{
    protected $fillable = ['tenant_id', 'title', 'content'];

    // Saat create, otomatis set tenant_id
    protected static function booted(): void
    {
        static::addGlobalScope('tenant', function ($query) {
            $query->where('tenant_id', tenant()->id);
        });

        static::creating(function ($post) {
            if (!$post->tenant_id) {
                $post->tenant_id = tenant()->id;
            }
        });
    }
}

// Multi database approach
class Tenant extends Model
{
    protected $fillable = ['domain', 'database', 'name'];

    public function configure(): void
    {
        config([
            'database.connections.tenant.database' => $this->database,
        ]);

        DB::purge('tenant');
        DB::reconnect('tenant');

        // Run migrations for tenant
        Artisan::call('migrate', [
            '--database' => 'tenant',
            '--path' => 'database/migrations/tenant',
        ]);
    }
}

// Middleware untuk multi-tenancy
class TenantMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        $tenant = Tenant::where('domain', $request->getHost())->firstOrFail();

        app()->instance('tenant', $tenant);
        $tenant->configure();

        return $next($request);
    }
}

// Helper tenant()
if (!function_exists('tenant')) {
    function tenant(): ?Tenant
    {
        return app('tenant');
    }
}

// BootTraits untuk tenant isolation
trait BelongsToTenant
{
    public static function bootBelongsToTenant(): void
    {
        static::creating(function ($model) {
            if (tenant() && !$model->tenant_id) {
                $model->tenant_id = tenant()->id;
            }
        });
    }
}
```

## Kasus Penggunaan Nyata
Aplikasi POS untuk 200 toko — setiap toko adalah tenant dengan database sendiri. Toko A tidak bisa melihat data Toko B, tapi semua dikelola dari satu codebase.
