# 438. Full-text Search Laravel Scout

## Definisi Singkat
Package Laravel resmi untuk menambahkan full-text search ke model Eloquent menggunakan driver seperti Algolia, Meilisearch, atau database engine bawaan.

## Analogi
Seperti Google untuk aplikasi kita — user cukup mengetik kata kunci, Scout mencari di semua data yang relevan dengan cepat.

## Poin-Poin Penting
- Driver support: Algolia, Meilisearch, SQLite, MySQL, PostgreSQL
- Sync otomatis data ke search engine
- `search()` method langsung di model
- Filter, pagination, dan highlighting
- Queue import untuk dataset besar

## Contoh Kode
```php
<?php

namespace App\Models;

use Laravel\Scout\Searchable;

class Post extends Model
{
    use Searchable;

    // Tentukan data yang di-index
    public function toSearchableArray(): array
    {
        return [
            'id' => $this->id,
            'title' => $this->title,
            'content' => $this->content,
            'excerpt' => Str::limit($this->content, 200),
            'author' => $this->author->name,
            'tags' => $this->tags->pluck('name'),
            'published_at' => $this->published_at?->timestamp,
        ];
    }

    // Filter untuk indexing
    public function shouldBeSearchable(): bool
    {
        return $this->is_published;
    }
}

// Controller search
class PostController extends Controller
{
    public function search(Request $request)
    {
        $query = $request->validate(['q' => 'required|string|min:2'])['q'];

        $posts = Post::search($query)
            ->where('is_published', true)
            ->orderBy('published_at', 'desc')
            ->paginate(12);

        return view('posts.search', compact('posts'));
    }
}

// Import semua data ke search engine
php artisan scout:import "App\Models\Post"

// Flush semua index
php artisan scout:flush "App\Models\Post"

// Search dengan filter
$results = Post::search('laravel')
    ->where('category_id', 5)
    ->where('status', 'published')
    ->orderBy('created_at', 'desc')
    ->take(20)
    ->get();

// Highlight search matches
$posts = Post::search('eloquent')
    ->options([
        'attributesToHighlight' => ['title', 'content'],
    ])
    ->get();

foreach ($posts as $post) {
    echo $post->title; // asli
    echo $post->highlight('title'); // dengan <mark>
}
```

## Kasus Penggunaan Nyata
Portal berita dengan 50.000 artikel — fitur search menggunakan Scout + Meilisearch memberikan hasil dalam <50ms, dibanding LIKE query MySQL yang butuh 3-5 detik.
