# 456. Module System Laravel

## Definisi Singkat
Pendekatan mengorganisir kode Laravel dalam modul-modul terpisah (self-contained) — setiap modul punya controller, model, migration, config, dan routes sendiri.

## Analogi
Seperti smartphone dengan aplikasi — setiap aplikasi (modul) punya fungsi sendiri, bisa di-update sendiri, tanpa mengganggu aplikasi lain. Tapi tetap satu sistem operasi.

## Poin-Poin Penting
- Setiap modul independent dan self-contained
- Mudah dipisah menjadi package terpisah
- Cocok untuk project besar dengan banyak fitur
- Bisa menggunakan package seperti nwidart/laravel-modules
- Atau buat struktur folder manual

## Contoh Kode
```
app/
└── Modules/
    ├── Blog/
    │   ├── Controllers/
    │   │   ├── PostController.php
    │   │   └── CategoryController.php
    │   ├── Models/
    │   │   ├── Post.php
    │   │   └── Category.php
    │   ├── Requests/
    │   │   └── StorePostRequest.php
    │   ├── Resources/
    │   │   └── PostResource.php
    │   ├── Services/
    │   │   └── PostService.php
    │   ├── routes.php
    │   ├── config.php
    │   └── Providers/
    │       └── BlogServiceProvider.php
    │
    ├── Shop/
    │   ├── Controllers/
    │   ├── Models/
    │   ├── Services/
    │   ├── routes.php
    │   └── Providers/
    │       └── ShopServiceProvider.php
    │
    └── User/
        ├── Controllers/
        ├── Models/
        ├── Services/
        ├── routes.php
        └── Providers/
            └── UserServiceProvider.php

// Contoh ModuleServiceProvider
namespace App\Modules\Blog\Providers;

use Illuminate\Support\ServiceProvider;

class BlogServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        $this->loadRoutesFrom(__DIR__ . '/../routes.php');
        $this->loadMigrationsFrom(__DIR__ . '/../database/migrations');
        $this->loadViewsFrom(__DIR__ . '/../views', 'blog');
        $this->mergeConfigFrom(__DIR__ . '/../config.php', 'blog');
    }
}

// Autoload modules di composer.json
{
    "autoload": {
        "psr-4": {
            "App\\Modules\\": "app/Modules/"
        }
    }
}

// Register modules di config/app.php
'providers' => [
    App\Modules\Blog\Providers\BlogServiceProvider::class,
    App\Modules\Shop\Providers\ShopServiceProvider::class,
    App\Modules\User\Providers\UserServiceProvider::class,
],
```

## Kasus Penggunaan Nyata
Aplikasi marketplace dengan modul Product, Order, Payment, Chat, Review — setiap tim mengerjakan satu modul tanpa konflik kode dengan tim lain.
