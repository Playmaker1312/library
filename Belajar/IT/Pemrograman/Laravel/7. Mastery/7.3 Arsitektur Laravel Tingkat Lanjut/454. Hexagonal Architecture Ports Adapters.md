# 454. Hexagonal Architecture Ports Adapters

## Definisi Singkat
Pola arsitektur yang menempatkan domain/bisnis logic di tengah (hexagon) dengan port (interface) yang berkomunikasi dengan adapter (implementasi) seperti database, web, API eksternal.

## Analogi
Seperti konsol game — inti (domain) adalah mesin game. Port adalah port HDMI/USB (interface). Adapter adalah TV, controller, keyboard — bisa diganti tanpa mengubah game.

## Poin-Poin Penting
- Domain inti tidak tahu menahu tentang framework/Laravel
- Port: interface untuk masuk/keluar dari domain
- Adapter: implementasi spesifik (Eloquent, API, file)
- Inversi dependency — domain define interface, infra implement
- Testing — domain bisa di-test tanpa Laravel

## Contoh Kode
```php
<?php

// ============ DOMAIN INTI (Core/Hexagon) ============
// Tidak ADA dependensi ke Laravel!

namespace App\Core\Domain\Ports;

// Port — interface yang dibutuhkan domain
interface UserRepository
{
    public function findById(string $id): ?User;
    public function save(User $user): void;
    public function findByEmail(string $email): ?User;
}

interface NotificationService
{
    public function send(string $recipient, string $message): void;
}

// Domain Entity
class User
{
    public function __construct(
        public readonly string $id,
        public string $name,
        public string $email,
        public bool $isActive = true,
    ) {}

    public function deactivate(): void
    {
        $this->isActive = false;
        // Domain logic — validasi, ubah state
    }
}

// Domain Service — pure business logic
class RegistrationService
{
    public function __construct(
        private UserRepository $users,
        private NotificationService $notifications,
    ) {}

    public function register(string $name, string $email): User
    {
        if ($this->users->findByEmail($email)) {
            throw new \DomainException('Email already registered');
        }

        $user = new User(uniqid(), $name, $email);
        $this->users->save($user);
        $this->notifications->send($email, 'Welcome!');

        return $user;
    }
}

// ============ INFRASTRUCTURE (Adapter) ============
// Implementasi spesifik Laravel

namespace App\Infrastructure\Persistence;

use App\Core\Domain\Ports\UserRepository;
use App\Models\User as EloquentUser;

class EloquentUserRepository implements UserRepository
{
    public function findById(string $id): ?\App\Core\Domain\User
    {
        $eloquent = EloquentUser::find($id);
        return $eloquent ? $this->toDomain($eloquent) : null;
    }

    public function save(\App\Core\Domain\User $user): void
    {
        EloquentUser::updateOrCreate(
            ['id' => $user->id],
            ['name' => $user->name, 'email' => $user->email, 'is_active' => $user->isActive]
        );
    }

    public function findByEmail(string $email): ?\App\Core\Domain\User
    {
        $eloquent = EloquentUser::where('email', $email)->first();
        return $eloquent ? $this->toDomain($eloquent) : null;
    }

    private function toDomain(EloquentUser $eloquent): \App\Core\Domain\User
    {
        return new \App\Core\Domain\User(
            $eloquent->id,
            $eloquent->name,
            $eloquent->email,
            $eloquent->is_active
        );
    }
}

// Binding di ServiceProvider
class AppServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        $this->app->bind(
            \App\Core\Domain\Ports\UserRepository::class,
            \App\Infrastructure\Persistence\EloquentUserRepository::class
        );

        $this->app->bind(
            \App\Core\Domain\Ports\NotificationService::class,
            \App\Infrastructure\Notifications\EmailNotification::class
        );
    }
}

// Controller — juga adapter!
class AuthController extends Controller
{
    public function __construct(
        private \App\Core\Domain\RegistrationService $registration,
    ) {}

    public function register(RegisterRequest $request)
    {
        $user = $this->registration->register(
            $request->name,
            $request->email
        );

        return response()->json(['id' => $user->id], 201);
    }
}
```

## Kasus Penggunaan Nyata
Startup yang mulai dengan MySQL, pindah ke PostgreSQL, lalu tambah cache Redis — dengan hexagonal architecture, cukup ganti adapter. Domain logic tidak berubah.
