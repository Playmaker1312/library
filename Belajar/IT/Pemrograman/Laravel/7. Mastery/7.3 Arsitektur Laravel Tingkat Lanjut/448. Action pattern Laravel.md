# 448. Action Pattern Laravel

## Definisi Singkat
Pola desain dimana setiap "aksi" atau "use case" dalam aplikasi dienkapsulasi dalam satu kelas action tunggal yang memiliki method `__invoke()`.

## Analogi
Seperti mesin ATM — setiap aksi (tarik tunai, transfer, cek saldo) adalah tombol terpisah. Masuk, tekan tombol, dapat hasil.

## Poin-Poin Penting
- Satu kelas = satu aksi bisnis
- Controller jadi sangat ramping
- Action bisa dipanggil dari mana saja (controller, command, job)
- Mudah di-test secara independen
- Hindari godaan membuat action raksasa

## Contoh Kode
```php
<?php

namespace App\Actions\Order;

use App\Models\Order;
use App\Models\Product;
use App\Notifications\OrderConfirmation;
use Illuminate\Support\Facades\DB;

class CreateOrderAction
{
    public function __construct(
        private readonly CalculateOrderTotal $calculateTotal,
        private readonly DeductStockAction $deductStock,
    ) {}

    public function __invoke(array $data, int $userId): Order
    {
        return DB::transaction(function () use ($data, $userId) {
            $order = Order::create([
                'user_id' => $userId,
                'order_number' => 'ORD-' . strtoupper(Str::random(8)),
                'status' => 'pending',
                'total' => ($this->calculateTotal)($data['items']),
            ]);

            foreach ($data['items'] as $item) {
                $order->items()->create($item);
                ($this->deductStock)($item['product_id'], $item['quantity']);
            }

            $order->user->notify(new OrderConfirmation($order));

            return $order;
        });
    }
}

// Action sederhana dengan __invoke
namespace App\Actions\User;

class GenerateAvatarAction
{
    public function __invoke(string $name): string
    {
        $initials = collect(explode(' ', $name))
            ->map(fn($part) => strtoupper($part[0]))
           ->take(2)
            ->join('');

        return "https://ui-avatars.com/api/?name={$initials}&color=7F9CF5&background=EBF4FF";
    }
}

// Controller dengan Action
class OrderController extends Controller
{
    public function __construct(
        private readonly CreateOrderAction $createOrder,
    ) {}

    public function store(StoreOrderRequest $request)
    {
        $order = ($this->createOrder)(
            $request->validated(),
            auth()->id()
        );

        return redirect()->route('orders.show', $order);
    }
}

// Action bisa dipanggil dari queue job
class ProcessOrderJob implements ShouldQueue
{
    public function handle(CreateOrderAction $createOrder): void
    {
        ($createOrder)($this->data, $this->userId);
    }
}

// Action pipeline — multiple actions berurutan
$pipeline = app()->makeWith(Pipeline::class);
$result = $pipeline
    ->send($requestData)
    ->through([
            ValidateCartAction::class,
            CreateOrderAction::class,
            ProcessPaymentAction::class,
            SendNotificationAction::class,
    ])
    ->thenReturn();
```

## Kasus Penggunaan Nyata
Aplikasi fintech — setiap fitur seperti "Transfer Dana", "Bayar Tagihan", "Top Up" adalah action class terpisah. Mudah di-test dan dimodifikasi tanpa efek samping.
