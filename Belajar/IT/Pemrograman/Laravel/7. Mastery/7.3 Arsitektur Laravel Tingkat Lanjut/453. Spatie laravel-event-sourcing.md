# 453. Spatie laravel-event-sourcing

## Definisi Singkat
Package event sourcing dari Spatie untuk Laravel — menyediakan event store, projectors, reactors, dan snapshot secara terintegrasi.

## Analogi
Seperti DVR untuk aplikasi — merekam semua kejadian (event) sehingga kita bisa "putar ulang" kapan saja untuk rekonstruksi state.

## Poin-Poin Penting
- Install via Composer: `spatie/laravel-event-sourcing`
- StoredEvent — model untuk event store
- Projectors — build read model dari event
- Reactors — trigger aksi sampingan dari event
- Snapshots — optimasi replay event
- Artisan commands untuk management event

## Contoh Kode
```php
// Install
composer require spatie/laravel-event-sourcing

// Publish config dan migration
php artisan vendor:publish --provider="Spatie\EventSourcing\EventSourcingServiceProvider"
php artisan migrate

// Config event-sourcing.php
return [
    'stored_event_model' => Spatie\EventSourcing\StoredEvent::class,
    'queue' => env('EVENT_SOURCING_QUEUE', null),
    'projectors' => [
        App\Projectors\AccountBalanceProjector::class,
    ],
    'reactors' => [
        App\Reactors\AccountReactor::class,
    ],
    'aggregate_roots' => [
        App\Aggregates\AccountAggregate::class => 'uuid',
    ],
];

// Event class
use Spatie\EventSourcing\ShouldBeStored;

class MoneyAdded implements ShouldBeStored
{
    public function __construct(
        public string $accountUuid,
        public int $amount,
    ) {}
}

// Aggregate root
use Spatie\EventSourcing\AggregateRoots\AggregateRoot;

class AccountAggregateRoot extends AggregateRoot
{
    public function addMoney(int $amount): static
    {
        $this->recordThat(new MoneyAdded($this->uuid(), $amount));
        return $this;
    }

    public function applyMoneyAdded(MoneyAdded $event): void
    {
        // Update aggregate state
    }
}

// Penggunaan aggregate
AccountAggregateRoot::retrieve($uuid)
    ->addMoney(1000)
    ->persist();

// Projector — build read model
use Spatie\EventSourcing\Projectors\Projector;
use Spatie\EventSourcing\Projectors\ProjectsEvents;

class AccountBalanceProjector implements Projector
{
    use ProjectsEvents;

    protected array $handlesEvents = [
        MoneyAdded::class => 'onMoneyAdded',
    ];

    public function onMoneyAdded(MoneyAdded $event): void
    {
        DB::table('account_balances')
            ->upsert(
                ['uuid' => $event->accountUuid, 'balance' => $event->amount],
                'uuid',
                ['balance' => DB::raw('balance + ' . $event->amount)]
            );
    }
}

// Reactor — trigger aksi sampingan
class AccountReactor
{
    protected array $handlesEvents = [
        MoneyAdded::class => 'onMoneyAdded',
    ];

    public function onMoneyAdded(MoneyAdded $event): void
    {
        if ($event->amount > 1000000) {
            NotifyComplianceTeam::dispatch($event);
        }
    }
}

// Rebuild projection
php artisan event-sourcing:replay account_balance

// Snapshot
php artisan make:snapshot AccountAggregateRoot $uuid
```

## Kasus Penggunaan Nyata
Dompet digital — semua transaksi (topup, transfer, bayar) disimpan sebagai event. Audit trail lengkap, bisa replay untuk rebuild saldo jika ada bug.
