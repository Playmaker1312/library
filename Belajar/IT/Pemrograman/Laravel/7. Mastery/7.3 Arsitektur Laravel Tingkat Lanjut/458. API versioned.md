# 458. API Versioned

## Definisi Singkat
Strategi melakukan versioning pada API Laravel agar perubahan tidak merusak client yang sudah ada — biasanya via URL prefix (`/api/v1/`) atau header (`Accept: application/vnd.api+json; version=1`).

## Analogi
Seperti aplikasi Windows — Windows 10, 11, 12. Aplikasi lama tetap jalan di versi lama, aplikasi baru pakai versi baru. Tidak ada yang rusak.

## Poin-Poin Penting
- URL versioning: `/api/v1/`, `/api/v2/`
- Header versioning: `Accept: application/vnd.app+json; version=2`
- Buat folder controller per versi
- Gunakan route groups untuk versioning
- Maintain backward compatibility selama mungkin
- Deprecation notice via header

## Contoh Kode
```php
<?php

// routes/api.php
use Illuminate\Support\Facades\Route;

/*
|--------------------------------------------------------------------------
| API Version 1
|--------------------------------------------------------------------------
*/
Route::prefix('v1')->group(function () {
    Route::get('/users', [App\Http\Controllers\Api\V1\UserController::class, 'index']);
    Route::get('/users/{id}', [App\Http\Controllers\Api\V1\UserController::class, 'show']);
    Route::post('/users', [App\Http\Controllers\Api\V1\UserController::class, 'store']);
});

/*
|--------------------------------------------------------------------------
| API Version 2
|--------------------------------------------------------------------------
*/
Route::prefix('v2')->group(function () {
    Route::get('/users', [App\Http\Controllers\Api\V2\UserController::class, 'index']);
    Route::get('/users/{id}', [App\Http\Controllers\Api\V2\UserController::class, 'show']);
    Route::post('/users', [App\Http\Controllers\Api\V2\UserController::class, 'store']);
    Route::get('/users/{id}/posts', [App\Http\Controllers\Api\V2\UserController::class, 'posts']);
});

// Atau dengan middleware version detection
Route::middleware('api.version')->group(function () {
    Route::get('/users', 'Api\UserController@index');
});

// Middleware untuk version detection via Accept header
namespace App\Http\Middleware;

class ApiVersion
{
    public function handle(Request $request, Closure $next): Response
    {
        $accept = $request->header('Accept');

        $version = 'v1';
        if (preg_match('/version=(\d+)/', $accept, $matches)) {
            $version = 'v' . $matches[1];
        }

        app()->instance('api.version', $version);

        return $next($request);
    }
}

// Controller V1 — basic
namespace App\Http\Controllers\Api\V1;

class UserController extends Controller
{
    public function index(): AnonymousResourceCollection
    {
        return UserResource::collection(User::paginate());
    }
}

// Controller V2 — enhanced dengan relasi
namespace App\Http\Controllers\Api\V2;

class UserController extends Controller
{
    public function index(): AnonymousResourceCollection
    {
        return UserResource::collection(
            User::with('profile', 'posts')->paginate()
        );
    }

    public function posts(int $userId): AnonymousResourceCollection
    {
        return PostResource::collection(
            Post::where('user_id', $userId)->with('comments')->get()
        );
    }
}

// Deprecation header
class UserController extends Controller
{
    public function index()
    {
        return response()
            ->json(UserResource::collection(User::all()))
            ->header('X-API-Version', 'v1')
            ->header('X-API-Deprecated', 'true')
            ->header('X-API-Sunset', '2025-06-01')
            ->header('Deprecation', 'true');
    }
}
```

## Kasus Penggunaan Nyata
Mobile app versi lama di play store tetap menggunakan `/api/v1/`. Setelah user update aplikasi, panggil `/api/v2/` dengan fitur baru. Backward compatibility terjamin.
