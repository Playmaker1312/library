# 460. WebSocket Laravel Reverb

## Definisi Singkat
Server WebSocket native untuk Laravel yang memungkinkan komunikasi real-time antara server dan client — dikirim via event broadcasting Laravel.

## Analogi
Seperti radio — penyiar (server) mengirim siaran (event), semua radio yang mendengarkan (client) langsung menerima. Beda dengan HTTP yang harus tanya "ada berita baru?" terus-menerus.

## Poin-Poin Penting
- Dibangun dengan PHP murni — tidak perlu Node.js
- Terintegrasi dengan Laravel Broadcasting
- Support presence, private, dan public channels
- Auto-scaling via Redis
- Pengganti Pusher/Ably untuk self-hosted
- Sangat cepat — menggunakan ReactPHP

## Contoh Kode
```php
// Install
composer require laravel/reverb

// Publish config
php artisan reverb:install

// .env
BROADCAST_DRIVER=reverb
REVERB_APP_ID=my-app-id
REVERB_APP_KEY=my-app-key
REVERB_APP_SECRET=my-app-secret
REVERB_HOST="0.0.0.0"
REVERB_PORT=8080
REVERB_SCHEME=http

// config/broadcasting.php
'connections' => [
    'reverb' => [
        'driver' => 'reverb',
        'key' => env('REVERB_APP_KEY'),
        'secret' => env('REVERB_APP_SECRET'),
        'app_id' => env('REVERB_APP_ID'),
        'options' => [
            'host' => env('REVERB_HOST'),
            'port' => env('REVERB_PORT', 443),
            'scheme' => env('REVERB_SCHEME', 'https'),
        ],
        'client_options' => [],
    ],
],

// Event broadcasting
namespace App\Events;

use Illuminate\Broadcasting\Channel;
use Illuminate\Broadcasting\PresenceChannel;
use Illuminate\Broadcasting\PrivateChannel;
use Illuminate\Contracts\Broadcasting\ShouldBroadcast;

class OrderStatusUpdated implements ShouldBroadcast
{
    public function __construct(
        public string $orderId,
        public string $status,
        public array $data = [],
    ) {}

    public function broadcastOn(): array
    {
        return [
            new PrivateChannel("orders.{$this->orderId}"),
            new Channel('admin-notifications'),
        ];
    }

    public function broadcastAs(): string
    {
        return 'order.updated';
    }
}

// Broadcast dari controller
class OrderController extends Controller
{
    public function update(UpdateOrderRequest $request, Order $order)
    {
        $order->update($request->validated());

        broadcast(new OrderStatusUpdated(
            $order->id,
            $order->status,
            $order->toArray()
        ))->toOthers();

        return redirect()->back();
    }
}

// Client-side JavaScript (Echo + Reverb)
import Echo from 'laravel-echo';
import Pusher from 'pusher-js';

window.Echo = new Echo({
    broadcaster: 'reverb',
    key: import.meta.env.VITE_REVERB_APP_KEY,
    wsHost: import.meta.env.VITE_REVERB_HOST,
    wsPort: import.meta.env.VITE_REVERB_PORT,
    wssPort: import.meta.env.VITE_REVERB_PORT,
    forceTLS: (import.meta.env.VITE_REVERB_SCHEME ?? 'https') === 'https',
    enabledTransports: ['ws', 'wss'],
});

// Listen private channel
Echo.private(`orders.${orderId}`)
    .listen('.order.updated', (e) => {
        console.log('Order updated:', e.status);
        updateOrderUI(e);
    });

// Listen presence channel
Echo.join('chat.room.1')
    .here((users) => {
        console.log('Online users:', users);
    })
    .joining((user) => {
        console.log(`${user.name} joined`);
    })
    .leaving((user) => {
        console.log(`${user.name} left`);
    });

// Jalankan Reverb server
php artisan reverb:start

// Production — jalankan via Supervisor
// /etc/supervisor/conf.d/reverb.conf
[program:reverb]
command=php /var/www/artisan reverb:start
process_name=%(program_name)s_%(process_num)02d
numprocs=1
user=forge
autostart=true
autorestart=true
```

## Kasus Penggunaan Nyata
Dashboard monitoring real-time — saat order baru masuk, semua admin yang membuka halaman dashboard langsung melihat notifikasi tanpa refresh manual.
