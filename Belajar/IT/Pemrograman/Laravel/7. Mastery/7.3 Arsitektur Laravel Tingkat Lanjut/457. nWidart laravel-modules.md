# 457. nWidart laravel-modules

## Definisi Singkat
Package populer untuk manajemen modul di Laravel — menyediakan Artisan commands untuk generate module, migrasi, routing, dan konfigurasi per modul.

## Analogi
Seperti installer aplikasi di Play Store — tinggal klik "buat modul baru", semua folder dan file siap pakai. Tidak perlu setup manual.

## Poin-Poin Penting
- Artisan commands untuk CRUD module
- Setiap module punya migration, routes, config sendiri
- Module dependency — module A bisa depend ke module B
- Publishing assets per module
- Events untuk komunikasi antar module
- Caching module status

## Contoh Kode
```php
// Install
composer require nwidart/laravel-modules

// Publish config
php artisan vendor:publish --provider="Nwidart\Modules\LaravelModulesServiceProvider"

// Generate module
php artisan module:make Blog
php artisan module:make Shop
php artisan module:make User

// Struktur module yang di-generate
// Modules/
// ├── Blog/
// │   ├── Config/
// │   ├── Console/
// │   ├── Database/
// │   │   ├── Migrations/
// │   │   └── Seeders/
// │   ├── Entities/
// │   ├── Http/
// │   │   ├── Controllers/
// │   │   ├── Requests/
// │   │   └── routes.php
// │   ├── Providers/
// │   │   └── BlogServiceProvider.php
// │   ├── Resources/
// │   │   └── views/
// │   ├── Repositories/
// │   ├── Services/
// │   └── module.json
// ├── Shop/
// └── User/

// Module.json
{
    "name": "Blog",
    "alias": "blog",
    "description": "Blog module for managing posts",
    "version": "1.0.0",
    "active": 1,
    "order": 1,
    "providers": [
        "Modules\\Blog\\Providers\\BlogServiceProvider"
    ],
    "aliases": {},
    "files": [
        "helpers.php"
    ],
    "requires": []
}

// Generate tambahan di dalam module
php artisan module:make-controller PostController Blog
php artisan module:make-model Post Blog
php artisan module:make-migration create_posts_table Blog
php artisan module:make-seed BlogDatabaseSeeder Blog
php artisan module:make-request StorePostRequest Blog
php artisan module:make-event PostCreated Blog

// Commands management
php artisan module:list
php artisan module:enable Blog
php artisan module:disable Blog
php artisan module:migrate Blog
php artisan module:seed Blog

// Route di module
Route::group(['middleware' => 'web'], function () {
    Route::resource('posts', PostController::class);
});

// Mengakses module dari luar
$posts = Module::find('Blog')->get('posts');
$blogPosts = \Modules\Blog\Entities\Post::all();

// View namespace
view('blog::posts.index', compact('posts'));
```

## Kasus Penggunaan Nyata
SaaS LMS (Learning Management System) — modul Course, Student, Quiz, Certificate, Payment. Modul Payment depend ke modul User, bisa di-enable/disable sesuai paket.
