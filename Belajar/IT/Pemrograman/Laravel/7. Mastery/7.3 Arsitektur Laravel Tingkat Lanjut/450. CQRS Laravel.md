# 450. CQRS Laravel

## Definisi Singkat
Command Query Responsibility Segregation — pola arsitektur yang memisahkan operasi baca (Query) dan tulis (Command) ke model atau jalur yang berbeda.

## Analogi
Seperti restoran — ada kasir (Command) untuk mencatat pesanan dan mengirim ke dapur, dan ada pramusaji (Query) yang hanya menyajikan informasi menu. Pekerjaan terpisah tapi saling melengkapi.

## Poin-Poin Penting
- Command: INSERT, UPDATE, DELETE — mengubah state
- Query: SELECT — hanya baca data
- Model baca bisa berbeda struktur dari model tulis
- Read model bisa di-denormalize untuk performa
- CQRS murni vs CQRS sederhana (separate methods)

## Contoh Kode
```php
<?php

namespace App\CQRS\Commands;

use App\Models\Order;
use App\CQRS\Events\OrderCreated;
use Illuminate\Support\Facades\DB;

class CreateOrderCommand
{
    public function __construct(
        public readonly int $userId,
        public readonly array $items,
        public readonly string $shippingAddress,
    ) {}
}

class CreateOrderHandler
{
    public function handle(CreateOrderCommand $command): Order
    {
        return DB::transaction(function () use ($command) {
            $order = Order::create([
                'user_id' => $command->userId,
                'shipping_address' => $command->shippingAddress,
                'status' => 'pending',
                'total' => 0,
            ]);

            $total = 0;
            foreach ($command->items as $item) {
                $orderItem = $order->items()->create($item);
                $total += $item['price'] * $item['quantity'];
            }

            $order->update(['total' => $total]);

            // Dispatch event untuk sinkronisasi read model
            event(new OrderCreated($order));

            return $order;
        });
    }
}

// ---------- SISI QUERY ----------

namespace App\CQRS\Queries;

// Read model — denormalized untuk performa baca
class OrderReadModel
{
    public function getCustomerDashboard(int $userId): array
    {
        return DB::table('order_summaries')
            ->where('user_id', $userId)
            ->orderBy('created_at', 'desc')
            ->get()
            ->toArray();
    }

    public function getMonthlyReport(string $yearMonth): array
    {
        return DB::table('daily_sales_reports')
            ->where('month', $yearMonth)
            ->get()
            ->toArray();
    }
}

// Query bus sederhana
class QueryBus
{
    public function ask(object $query): mixed
    {
        $handlerClass = get_class($query) . 'Handler';

        if (!class_exists($handlerClass)) {
            throw new \RuntimeException("No handler for " . get_class($query));
        }

        return app($handlerClass)->handle($query);
    }
}

// Contoh query
class GetOrderQuery
{
    public function __construct(
        public readonly int $orderId,
        public readonly ?int $userId = null,
    ) {}
}

class GetOrderQueryHandler
{
    public function handle(GetOrderQuery $query): ?OrderReadModel
    {
        return DB::table('order_summaries')
            ->when($query->userId, fn($q) => $q->where('user_id', $query->userId))
            ->find($query->orderId);
    }
}

// Controller
class OrderController extends Controller
{
    public function __construct(
        private readonly QueryBus $queryBus,
    ) {}

    public function show(int $id)
    {
        $order = $this->queryBus->ask(new GetOrderQuery($id, auth()->id()));

        abort_if(!$order, 404);

        return new OrderResource($order);
    }
}
```

## Kasus Penggunaan Nyata
Sistem laporan keuangan — command untuk mencatat transaksi (write optimized), query untuk generate laporan (read optimized dengan denormalized tables). Pisah jalur baca/tulis.
