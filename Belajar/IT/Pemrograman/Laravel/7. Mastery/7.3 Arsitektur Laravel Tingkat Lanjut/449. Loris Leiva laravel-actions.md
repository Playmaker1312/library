# 449. Loris Leiva laravel-actions

## Definisi Singkat
Package dari Loris Leiva yang menyediakan trait `AsAction` — memungkinkan satu kelas menjadi Action yang sekaligus bisa sebagai controller, job, listener, atau command.

## Analogi
Seperti pisau Swiss Army — satu alat bisa berfungsi sebagai pisau, gunting, obeng, pembuka botol. Action class ini bisa dipanggil dari berbagai entry point.

## Poin-Poin Penting
- Satu class bisa di-invoke langsung, sebagai controller, job, dll
- Trait `AsAction` memberikan multiple personalities
- Method `asController()`, `asJob()`, `asListener()`
- Validasi otomatis jika sebagai controller
- Sangat mengurangi boilerplate

## Contoh Kode
```php
<?php

namespace App\Actions;

use Lorisleiva\Actions\Concerns\AsAction;

class PublishPostAction
{
    use AsAction;

    // Handle utama — dipanggil dari mana saja
    public function handle(Post $post): Post
    {
        $post->update([
            'published_at' => now(),
            'status' => 'published',
        ]);

        PostPublished::dispatch($post);

        return $post;
    }

    // Sebagai Controller
    public function asController(PublishPostRequest $request, Post $post): RedirectResponse
    {
        $this->handle($post);

        return redirect()->route('posts.show', $post)
            ->with('success', 'Post published!');
    }

    // Sebagai Job
    public function asJob(Post $post): void
    {
        $this->handle($post);
    }

    // Sebagai Listener
    public function asListener(SchedulePublishEvent $event): void
    {
        $this->handle($event->post);
    }

    // Authorization
    public function authorize(): bool
    {
        return auth()->user()->can('publish-post');
    }

    // Validasi (akan digunakan jika sebagai controller)
    public function rules(): array
    {
        return [
            'schedule_at' => 'nullable|date|after:now',
        ];
    }
}

// Cara penggunaan:

// 1. Invoke langsung
PublishPostAction::run($post);

// 2. Via route (sebagai controller)
Route::post('posts/{post}/publish', PublishPostAction::class)
    ->name('posts.publish');

// 3. Sebagai Job
PublishPostAction::dispatch($post);

// 4. Sebagai Listener
Event::listen(
    SchedulePublishEvent::class,
    PublishPostAction::class
);

// 5. Dengan middleware
PublishPostAction::withMiddleware([
    'auth',
    'throttle:10,1',
]);

// 6. Sebagai command Artisan
php artisan make:action RegisterUserAction --command=user:register

// Command akan otomatis dibuat
class RegisterUserAction
{
    use AsAction;

    public string $commandSignature = 'user:register {name} {email}';

    public function handle(string $name, string $email): User
    {
        return User::create(compact('name', 'email'));
    }

    public function asCommand(Command $command): void
    {
        $user = $this->handle(
            $command->argument('name'),
            $command->argument('email')
        );
        $command->info("User {$user->name} created!");
    }
}
```

## Kasus Penggunaan Nyata
Fitur "Send Email Verification" — satu action class digunakan untuk: trigger manual dari admin panel (controller), kirim otomatis setelah register (listener), dan batch kirim ulang (command).
