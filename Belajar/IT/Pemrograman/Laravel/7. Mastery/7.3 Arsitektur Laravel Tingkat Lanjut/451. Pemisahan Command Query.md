# 451. Pemisahan Command Query

## Definisi Singkat
Penerapan prinsip CQS (Command-Query Separation) di Laravel — method/function harus berupa command (mengubah state, return void) ATAU query (return data, tanpa efek samping), tidak keduanya.

## Analogi
Seperti mesin kopi — tombol "buat kopi" (command) mengubah state mesin dan tidak mengembalikan biji kopi. Lampu indikator (query) memberi tahu jumlah air tanpa mengubah apapun.

## Poin-Poin Penting
- Command: mutasi state, return void/null
- Query: tidak boleh mengubah state
- Pisahkan method di repository/service
- Memudahkan testing dan reasoning
- Pendekatan sederhana dari CQRS

## Contoh Kode
```php
<?php

// ❌ JANGAN — campur command dan query
class BadUserService
{
    // Melakukan update DAN return data — melanggar CQS
    public function updateAndGet(int $id, array $data): User
    {
        User::findOrFail($id)->update($data);
        return User::findOrFail($id); // efek samping + return data
    }
}

// ✅ PISAHKAN Command dan Query
class UserService
{
    // Command — hanya mengubah state, return void/null
    public function updateProfile(int $id, array $data): void
    {
        User::findOrFail($id)->update($data);
        Cache::tags(['users'])->flush();
    }

    public function deactivate(int $id): void
    {
        User::findOrFail($id)->update(['active' => false]);
        event(new UserDeactivated($id));
    }

    // Query — hanya baca data, tanpa efek samping
    public function findById(int $id): ?User
    {
        return User::with('profile', 'roles')->find($id);
    }

    public function getActiveUsersByRole(string $role): Collection
    {
        return User::whereHas('roles', fn($q) => $q->where('name', $role))
            ->where('active', true)
            ->get();
    }
}

// Controller yang mematuhi CQS
class ProfileController extends Controller
{
    public function __construct(
        private readonly UserService $userService,
    ) {}

    // Command — update
    public function update(ProfileUpdateRequest $request): RedirectResponse
    {
        $this->userService->updateProfile(auth()->id(), $request->validated());

        return redirect()->back()->with('success', 'Profile updated');
    }

    // Query — show
    public function show(): View
    {
        $user = $this->userService->findById(auth()->id());
        return view('profile.show', compact('user'));
    }
}

// Repository dengan CQS
interface ProductRepository
{
    // Commands
    public function save(Product $product): void;
    public function delete(int $id): void;
    public function updateStock(int $id, int $quantity): void;

    // Queries
    public function find(int $id): ?Product;
    public function findBySku(string $sku): ?Product;
    public function getLowStock(int $threshold): Collection;
}

// Form Request dengan CQS
class StoreOrderRequest extends FormRequest
{
    public function authorize(): bool
    {
        return auth()->check();
    }

    public function rules(): array
    {
        return [
            'items' => 'required|array|min:1',
            'items.*.product_id' => 'required|exists:products,id',
            'items.*.quantity' => 'required|integer|min:1',
        ];
    }
}

// Test lebih mudah
public function test_update_profile_does_not_return_user(): void
{
    $service = app(UserService::class);

    $service->updateProfile(1, ['name' => 'New Name']);

    $this->assertDatabaseHas('users', [
        'id' => 1,
        'name' => 'New Name',
    ]);
}
```

## Kasus Penggunaan Nyata
Sistem perbankan — method `transfer()` (command) mengubah saldo dan mengembalikan void, method `getBalance()` (query) hanya baca saldo tanpa log atau perubahan apapun.
