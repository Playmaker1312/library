# 455. Project Berskala Enterprise

## Definisi Singkat
Praktik terbaik membangun aplikasi Laravel untuk enterprise — mencakup arsitektur modular, governance, compliance, audit logging, dan integration dengan sistem legacy.

## Analogi
Seperti membangun gedung pencakar langit — bukan sekadar rumah biasa. Perlu fondasi kuat, struktur baja, sistem keamanan, lift, dan sertifikasi.

## Poin-Poin Penting
- Modular monolith — internal packages untuk setiap domain
- Audit logging — catat semua operasi penting
- Role-based access control (Spatie Permission)
- API versioning dan backward compatibility
- Comprehensive error handling & logging
- Integration event system untuk inter-module

## Contoh Kode
```php
<?php

// Audit logging trait
namespace App\Traits;

trait Auditable
{
    protected static function bootAuditable(): void
    {
        static::created(function ($model) {
            AuditLog::create([
                'user_id' => auth()->id(),
                'action' => 'created',
                'auditable_type' => get_class($model),
                'auditable_id' => $model->id,
                'old_values' => null,
                'new_values' => json_encode($model->getAttributes()),
                'ip_address' => request()->ip(),
                'user_agent' => request()->userAgent(),
            ]);
        });

        static::updated(function ($model) {
            AuditLog::create([
                'user_id' => auth()->id(),
                'action' => 'updated',
                'auditable_type' => get_class($model),
                'auditable_id' => $model->id,
                'old_values' => json_encode($model->getOriginal()),
                'new_values' => json_encode($model->getChanges()),
                'ip_address' => request()->ip(),
            ]);
        });
    }
}

// Enterprise-wide exception handler
class Handler extends ExceptionHandler
{
    public function register(): void
    {
        $this->reportable(function (DomainException $e) {
            Log::channel('domain')->error($e->getMessage(), [
                'trace' => $e->getTraceAsString(),
                'user' => auth()->id(),
            ]);
        });

        $this->reportable(function (ValidationException $e) {
            Log::channel('validation')->warning('Validation failed', [
                'errors' => $e->errors(),
                'url' => request()->fullUrl(),
            ]);
        });

        $this->renderable(function (NotFoundHttpException $e, $request) {
            if ($request->expectsJson()) {
                return response()->json([
                    'error' => 'Resource not found',
                    'request_id' => request()->header('X-Request-ID'),
                ], 404);
            }
        });
    }
}

// Modular structure
// packages/
// ├── crm/
// │   ├── src/
// │   │   ├── Models/
// │   │   ├── Services/
// │   │   └── Providers/
// │   └── composer.json
// ├── billing/
// ├── inventory/
// └── compliance/

// Inter-module communication via events
class ModuleEventBus
{
    protected array $listeners = [];

    public function listen(string $event, callable $listener): void
    {
        $this->listeners[$event][] = $listener;
    }

    public function dispatch(string $event, array $payload = []): void
    {
        foreach ($this->listeners[$event] ?? [] as $listener) {
            try {
                $listener($payload);
            } catch (\Throwable $e) {
                Log::error("Module event failed: {$event}", [
                    'error' => $e->getMessage(),
                ]);
            }
        }
    }
}

// Enterprise config dengan environment override
return [
    'enterprise' => [
        'audit_enabled' => env('AUDIT_ENABLED', true),
        'audit_retention_days' => env('AUDIT_RETENTION_DAYS', 365),
        'compliance_mode' => env('COMPLIANCE_MODE', 'standard'),
        'rate_limiting' => [
            'api' => env('API_RATE_LIMIT', 1000),
            'login' => env('LOGIN_RATE_LIMIT', 5),
        ],
        'encryption' => [
            'at_rest' => env('ENCRYPT_AT_REST', true),
            'algorithm' => 'AES-256-CBC',
        ],
    ],
];
```
