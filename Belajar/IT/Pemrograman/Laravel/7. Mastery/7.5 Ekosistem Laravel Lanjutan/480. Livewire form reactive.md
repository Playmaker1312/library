# 480. Livewire Form Reactive

## Definisi Singkat
Membangun form reaktif dengan Livewire — validasi real-time, dynamic fields, dependent dropdowns, file upload dengan progress, dan auto-save.

## Analogi
Seperti formulir pendaftaran online yang cerdas — isi provinsi, otomatis muncul daftar kota. Upload foto, langsung lihat preview. Validasi error muncul instan.

## Poin-Poin Penting
- `wire:model` — two-way data binding
- Real-time validation dengan `$this->validateOnly()`
- Dynamic form fields dengan array properties
- Dependent dropdowns dengan `updated` hooks
- File upload dengan `WithFileUploads` trait
- Auto-save dengan debounce

## Contoh Kode
```php
<?php

namespace App\Livewire;

use App\Models\City;
use App\Models\Province;
use Livewire\Component;
use Livewire\WithFileUploads;

class RegistrationForm extends Component
{
    use WithFileUploads;

    // Form data
    public string $name = '';
    public string $email = '';
    public string $password = '';
    public string $province_id = '';
    public string $city_id = '';
    public $photo;
    public ?string $photoPreview = null;

    // Dynamic fields
    public array $skills = [];
    public array $socialLinks = [];

    // Validation rules
    protected function rules(): array
    {
        return [
            'name' => 'required|min:3|max:255',
            'email' => 'required|email|unique:users,email',
            'password' => 'required|min:8',
            'province_id' => 'required|exists:provinces,id',
            'city_id' => 'required|exists:cities,id',
            'photo' => 'nullable|image|max:2048', // 2MB
            'skills.*' => 'required|string|max:50',
            'socialLinks.*.platform' => 'required|in:twitter,github,linkedin',
            'socialLinks.*.url' => 'required|url',
        ];
    }

    // Real-time validation per field
    public function updated(string $propertyName): void
    {
        $this->validateOnly($propertyName);
    }

    // Dependent dropdown — provinsi berubah, reset kota
    public function updatedProvinceId(string $value): void
    {
        $this->city_id = '';
        if ($value) {
            $this->dispatch('city-updated', cities: City::where('province_id', $value)->get()->toArray());
        }
    }

    // File upload
    public function updatedPhoto(): void
    {
        $this->validateOnly('photo');
        $this->photoPreview = $this->photo->temporaryUrl();
    }

    // Dynamic fields — tambah skill
    public function addSkill(): void
    {
        $this->skills[] = '';
    }

    public function removeSkill(int $index): void
    {
        unset($this->skills[$index]);
        $this->skills = array_values($this->skills);
    }

    // Dynamic fields — tambah social link
    public function addSocialLink(): void
    {
        $this->socialLinks[] = ['platform' => '', 'url' => ''];
    }

    public function removeSocialLink(int $index): void
    {
        unset($this->socialLinks[$index]);
        $this->socialLinks = array_values($this->socialLinks);
    }

    // Submit
    public function submit(): void
    {
        $validated = $this->validate();

        // Upload photo
        if ($this->photo) {
            $validated['photo_path'] = $this->photo->store('photos', 'public');
        }

        // Simpan ke database
        User::create([
            'name' => $this->name,
            'email' => $this->email,
            'password' => bcrypt($this->password),
            'province_id' => $this->province_id,
            'city_id' => $this->city_id,
            'photo_path' => $validated['photo_path'] ?? null,
            'skills' => $this->skills,
            'social_links' => $this->socialLinks,
        ]);

        session()->flash('success', 'Registration successful!');
        $this->reset();
    }

    public function render()
    {
        return view('livewire.registration-form', [
            'provinces' => Province::all(),
            'cities' => $this->province_id ? City::where('province_id', $this->province_id)->get() : [],
        ]);
    }
}
```

```blade
<form wire:submit="submit">
    {{-- Name --}}
    <input wire:model.blur="name" placeholder="Name">
    @error('name') <span>{{ $message }}</span> @enderror

    {{-- Email --}}
    <input wire:model.blur="email" type="email" placeholder="Email">
    @error('email') <span>{{ $message }}</span> @enderror

    {{-- Dependent dropdowns --}}
    <select wire:model.live="province_id">
        <option value="">Select Province</option>
        @foreach ($provinces as $province)
            <option value="{{ $province->id }}">{{ $province->name }}</option>
        @endforeach
    </select>

    <select wire:model.live="city_id">
        <option value="">Select City</option>
        @foreach ($cities as $city)
            <option value="{{ $city->id }}">{{ $city->name }}</option>
        @endforeach
    </select>

    {{-- File upload with preview --}}
    <input type="file" wire:model.live="photo">
    @if ($photoPreview)
        <img src="{{ $photoPreview }}" width="100">
    @endif
    <div wire:loading wire:target="photo">Uploading...</div>

    {{-- Dynamic Skills --}}
    @foreach ($skills as $index => $skill)
        <div wire:key="skill-{{ $index }}">
            <input wire:model="skills.{{ $index }}" placeholder="Skill {{ $index + 1 }}">
            <button type="button" wire:click="removeSkill({{ $index }})">X</button>
        </div>
    @endforeach
    <button type="button" wire:click="addSkill">+ Add Skill</button>

    <button type="submit">Register</button>
</form>
```

## Kasus Penggunaan Nyata
Form pendaftaran beasiswa — provinsi dan kota cascade, upload KTP langsung preview, tambah riwayat pendidikan dinamis. Semua real-time tanpa reload.
