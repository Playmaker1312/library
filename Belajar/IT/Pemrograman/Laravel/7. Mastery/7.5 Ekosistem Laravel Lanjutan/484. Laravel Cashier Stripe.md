# 484. Laravel Cashier Stripe

## Definisi Singkat
Package resmi Laravel untuk integrasi pembayaran Stripe — menangani subscription, invoice, pembayaran one-time, customer management, dan webhook Stripe.

## Analogi
Seperti kasir di supermarket — Cashier adalah mesin kasir, Stripe adalah mesin kartu kredit. Kita tinggal scan barang (produk), kasir otomatis menghitung (billing), dan kartu diproses (payment).

## Poin-Poin Penting
- Install Cashier + Stripe PHP SDK
- Billable trait di User model
- Subscription plans via Stripe Dashboard
- Handle webhooks Stripe via controller
- Invoice generation otomatis
- Trial periods, coupons, tax rates
- Refund dan cancellation handling

## Contoh Kode
```php
<?php

// Install
composer require laravel/cashier

// Migration — tambah kolom Stripe ke users
php artisan cashier:install

// User model
use Laravel\Cashier\Billable;

class User extends Authenticatable
{
    use Billable;
}

// .env
STRIPE_KEY=pk_test_...
STRIPE_SECRET=sk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...
CASHIER_CURRENCY=idr
CASHIER_CURRENCY_LOCALE=id_ID

// Subscription controller
namespace App\Http\Controllers;

use App\Models\Plan;
use Illuminate\Http\Request;

class SubscriptionController extends Controller
{
    public function checkout(Request $request)
    {
        $plan = Plan::findOrFail($request->plan_id);

        return $request->user()
            ->newSubscription('default', $plan->stripe_price_id)
            ->trialDays(7)
            ->allowPromotionCodes()
            ->checkout([
                'success_url' => route('dashboard'),
                'cancel_url' => route('pricing'),
            ]);
    }

    public function cancel(Request $request)
    {
        $request->user()->subscription('default')->cancel();

        return redirect()->back()->with('message', 'Subscription cancelled');
    }

    public function resume(Request $request)
    {
        $request->user()->subscription('default')->resume();

        return redirect()->back()->with('message', 'Subscription resumed');
    }

    public function swapPlan(Request $request, string $planId)
    {
        $request->user()->subscription('default')->swap($planId);

        return redirect()->back()->with('message', 'Plan changed');
    }

    public function invoice(Request $request)
    {
        return $request->user()->invoices();
    }

    public function downloadInvoice(Request $request, string $invoiceId)
    {
        return $request->user()->downloadInvoice($invoiceId, [
            'vendor' => config('app.name'),
            'product' => 'Subscription',
        ]);
    }
}

// Webhook controller
namespace App\Http\Controllers;

use Laravel\Cashier\Http\Controllers\WebhookController as CashierWebhook;

class StripeWebhookController extends CashierWebhook
{
    public function handleInvoicePaymentSucceeded(array $payload): ?Response
    {
        $user = $this->getUserByStripeId($payload['data']['object']['customer']);
        $user?->notify(new PaymentSucceeded($payload));
        return null;
    }

    public function handleCustomerSubscriptionDeleted(array $payload): ?Response
    {
        // Handle subscription end
        Log::info('Subscription deleted', $payload);
        return null;
    }
}

// routes/web.php
Route::post('/stripe/webhook', [StripeWebhookController::class, 'handleWebhook']);

// Blade — cek subscription
@if (auth()->user()->subscribed('default'))
    <p>You are subscribed!</p>
    <p>Next payment: {{ auth()->user()->subscription('default')->nextPaymentAttempt()?->diffForHumans() }}</p>
@else
    <a href="{{ route('pricing') }}">Subscribe now</a>
@endif

// Payment methods
$user->updateDefaultPaymentMethod('pm_xxx');
$user->paymentMethods();
$user->hasPaymentMethod();
```
