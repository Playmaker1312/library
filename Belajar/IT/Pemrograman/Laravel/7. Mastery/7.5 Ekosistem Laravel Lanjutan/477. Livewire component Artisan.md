# 477. Livewire Component Artisan

## Definisi Singkat
Perintah Artisan untuk membuat, mengelola, dan mengatur komponen Livewire — mempercepat development dengan boilerplate otomatis.

## Analogi
Seperti mesin pencetak kue — tinggal masukkan adonan (perintah artisan), keluar kue jadi (komponen) siap pakai. Tidak perlu bikin dari nol.

## Poin-Poin Penting
- `make:livewire` — generate class + view
- `livewire:list` — lihat semua komponen
- `livewire:stubs` — publish stubs untuk kustomisasi
- Opsi `--inline` — komponen tanpa view terpisah
- Opsi `--test` — generate test juga
- Opsi `--force` — overwrite file yang sudah ada

## Contoh Kode
```bash
# Buat komponen baru
php artisan make:livewire Counter

# Output:
# COMPONENT CREATED: app/Http/Livewire/Counter.php
# VIEW CREATED: resources/views/livewire/counter.blade.php
# TEST CREATED: tests/Feature/Livewire/CounterTest.php

# Buat di subfolder
php artisan make:livewire Admin/UserManager
# ~ app/Livewire/Admin/UserManager.php
# ~ views/livewire/admin/user-manager.blade.php

# Inline component — class hanya tanpa view
php artisan make:livewire ShowPosts --inline

# Dengan opsi
php artisan make:livewire PostForm \
    --force \
    --test \
    --stub=custom-stub.stub

# List semua komponen
php artisan livewire:list

# Output:
# Counter
# Admin\UserManager
# PostForm
# ShowPosts

# Publish stubs untuk kustomisasi
php artisan livewire:stubs

# Membuat folder stubs di resources/stubs/livewire/
# - component.stub
# - component.inline.stub
# - view.stub
# - test.stub

# Generate component dengan namespace
php artisan make:livewire App\\Domain\\Blog\\PostEditor
# app/Domain/Blog/Livewire/PostEditor.php

# Layout
php artisan livewire:layout
# resources/views/components/layouts/app.blade.php

# Buat komponen dari package
php artisan module:make-livewire PostList Blog
```

```php
// Contoh generate — PostForm
// app/Livewire/PostForm.php
class PostForm extends Component
{
    public $title;
    public $content;
    public $category_id;

    protected $rules = [
        'title' => 'required|min:3',
        'content' => 'required|min:10',
        'category_id' => 'required|exists:categories,id',
    ];

    public function save()
    {
        $this->validate();
        Post::create($this->only(['title', 'content', 'category_id']));
        session()->flash('success', 'Post created!');
        $this->reset();
    }

    public function render()
    {
        return view('livewire.post-form')
            ->layout('components.layouts.app');
    }
}
```

## Kasus Penggunaan Nyata
Developer perlu buat 20 komponen Livewire untuk admin panel — dengan `php artisan make:livewire User*` dalam 2 menit semua file siap, tinggal isi logic.
