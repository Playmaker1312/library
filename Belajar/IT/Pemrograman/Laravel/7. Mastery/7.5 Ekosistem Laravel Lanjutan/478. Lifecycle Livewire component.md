# 478. Lifecycle Livewire Component

## Definisi Singkat
Urutan method yang dipanggil secara otomatis dalam siklus hidup komponen Livewire — dari mount, update properties, render, hingga destroy.

## Analogi
Seperti siklus hidup kupu-kupu — telur (mount), ulat (hydrate), kepompong (updating), kupu-kupu (updated), mati (destroy). Setiap fase ada fungsi spesifik.

## Poin-Poin Penting
- `mount()` — initialize component (hanya sekali)
- `hydrate()` — dipanggil setiap request
- `boot()` — sebelum mount/hydrate
- `updating()` — sebelum property berubah
- `updated()` — setelah property berubah
- `updatingFoo()` — hook spesifik untuk property $foo
- `render()` — render view
- `destroy()` — cleanup (jarang digunakan)

## Contoh Kode
```php
<?php

namespace App\Livewire;

use App\Models\User;
use Livewire\Component;

class UserProfile extends Component
{
    public User $user;
    public string $name = '';
    public string $email = '';

    // 1. boot — pertama kali dipanggil
    public function boot(): void
    {
        // Ini dipanggil SETIAP request
        logger('UserProfile boot');
    }

    // 2. mount — sekali saat komponen dibuat
    public function mount(User $user): void
    {
        $this->user = $user;
        $this->name = $user->name;
        $this->email = $user->email;

        logger('UserProfile mounted for user: ' . $user->id);
    }

    // 3. hydrate — setiap request, setelah boot
    public function hydrate(): void
    {
        logger('UserProfile hydrate');
    }

    // 4. Sebelum property berubah
    public function updating(string $property, mixed $value): void
    {
        logger("Updating {$property} to {$value}");
    }

    // Hook spesifik untuk $name
    public function updatingName(mixed $value): void
    {
        if (strlen($value) < 3) {
            $this->addError('name', 'Name minimal 3 karakter');
        }
    }

    // 5. Setelah property berubah
    public function updated(string $property, mixed $value): void
    {
        logger("Updated {$property} to {$value}");
    }

    // Hook spesifik untuk $email
    public function updatedEmail(mixed $value): void
    {
        $this->validateOnly('email');
    }

    // Action
    public function save(): void
    {
        $this->validate([
            'name' => 'required|min:3',
            'email' => 'required|email|unique:users,email,' . $this->user->id,
        ]);

        $this->user->update([
            'name' => $this->name,
            'email' => $this->email,
        ]);

        session()->flash('success', 'Profile updated!');
    }

    // 6. render — setiap request, setelah semua update
    public function render()
    {
        return view('livewire.user-profile');
    }
}

// Alur lengkap:
// 1. First load: boot → mount → render
// 2. Update property: boot → hydrate → updating → updated → render
// 3. Call action: boot → hydrate → (validasi) → render
// 4. Redirect: boot → hydrate → (redirect) → (stop)
```

## Kasus Penggunaan Nyata
Form multi-step — gunakan `mount()` untuk load data awal, `updated()` untuk auto-save setiap step, `updating()` untuk validasi real-time.
