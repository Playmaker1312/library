# 485. Subscription Billing Cashier

## Definisi Singkat
Fitur subscription billing lanjutan dengan Laravel Cashier — multiple subscriptions, prorating, meter billing, tier pricing, dan customer portal Stripe.

## Analogi
Seperti paket langganan Netflix — ada Basic, Standard, Premium. Bisa upgrade (bayar selisih), downgrade (prorate), pause, cancel. Semua otomatis.

## Poin-Poin Penting
- Multiple subscriptions — satu user bisa punya banyak langganan
- Prorating — hitung selisih saat upgrade/downgrade
- Quantity-based subscription (meter billing)
- No-payment upfront — tagihan pertama nanti
- Stripe Customer Portal — kelola pembayaran sendiri
- Coupon dan promotion codes

## Contoh Kode
```php
<?php

// Multiple subscriptions
$user->newSubscription('main', 'price_monthly')->create($paymentMethod);
$user->newSubscription('addon', 'price_storage_100gb')->create($paymentMethod);

// Swap with prorating
$user->subscription('main')
    ->prorate() // default: true
    ->swap('price_yearly');

// Swap without prorating
$user->subscription('main')
    ->noProrate()
    ->swap('price_basic');

// Invoice options
$user->subscription('main')
    ->predefinedPrice() // tagihan flat per periode
    ->create($paymentMethod);

// Quantity-based (metered billing)
$user->subscription('main')
    ->quantity(5) // 5 seats
    ->create();

// Update quantity
$user->subscription('main')->incrementQuantity();
$user->subscription('main')->decrementQuantity();
$user->subscription('main')->updateQuantity(3);

// Pause subscription
$user->subscription('main')->pause();
$user->subscription('main')->resume();

// Trial tanpa payment method
$user->newSubscription('default', 'price_monthly')
    ->trialDays(14)
    ->create(); // tanpa $paymentMethod

// Trial dengan payment method
$user->newSubscription('default', 'price_monthly')
    ->trialDays(14)
    ->trialUntil(now()->addDays(14))
    ->allowPromotionCodes()
    ->create($paymentMethod);

// Check trial
$user->onTrial('default');
$user->onGenericTrial(); // tanpa payment method

// Stripe Customer Portal — user kelola sendiri
Route::get('/billing/portal', function () {
    return auth()->user()->redirectToBillingPortal(
        url('/dashboard')
    );
})->middleware('auth');

// Coupon
$user->newSubscription('default', 'price_monthly')
    ->withCoupon('WELCOME50')
    ->create($paymentMethod);

// Promotion code
$user->newSubscription('default', 'price_monthly')
    ->allowPromotionCodes()
    ->create($paymentMethod);

// Tax rates
$user->newSubscription('default', 'price_monthly')
    ->withTaxRate('txr_12345')
    ->create($paymentMethod);

// Anchor billing cycle
$user->newSubscription('default', 'price_monthly')
    ->anchorBillingCycleOn(now()->addDays(10))
    ->create($paymentMethod);

// Cek subscription status
auth()->user()->subscribed('main');
auth()->user()->subscribedToProduct('prod_abc');
auth()->user()->subscribedToPrice('price_monthly');
auth()->user()->subscription('main')->onGracePeriod();
auth()->user()->subscription('main')->cancelled();
auth()->user()->subscription('main')->ended();
```
