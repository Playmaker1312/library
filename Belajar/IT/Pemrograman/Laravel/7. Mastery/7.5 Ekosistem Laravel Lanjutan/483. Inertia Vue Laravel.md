# 483. Inertia Vue Laravel

## Definisi Singkat
Integrasi Inertia.js dengan Vue 3 sebagai frontend — menggunakan Single File Components Vue untuk merender halaman Laravel dengan SPA experience.

## Analogi
Sama seperti Inertia + React, tapi Vue lebih "ramah" untuk developer yang suka template-based syntax dan reaktivitas sederhana.

## Poin-Poin Penting
- Install `@inertiajs/vue3`
- Setup dengan `createInertiaApp`
- Component `<Link>` untuk navigasi
- `useForm` composable untuk form
- Layout dengan `<slot>`
- Vue DevTools support

## Contoh Kode
```vue
<!-- resources/js/app.js -->
import { createApp, h } from 'vue';
import { createInertiaApp } from '@inertiajs/vue3';
import { resolvePageComponent } from 'laravel-vite-plugin/inertia-helpers';

createInertiaApp({
    resolve: name => resolvePageComponent(
        `./Pages/${name}.vue`,
        import.meta.glob('./Pages/**/*.vue')
    ),
    setup({ el, App, props, plugin }) {
        createApp({ render: () => h(App, props) })
            .use(plugin)
            .mount(el);
    },
});

<!-- resources/js/Layouts/Authenticated.vue -->
<template>
    <div>
        <nav>
            <Link href="/dashboard">Dashboard</Link>
            <Link href="/posts">Posts</Link>
            <Link href="/logout" method="post" as="button">Logout</Link>
        </nav>
        <header v-if="$slots.header">
            <slot name="header" />
        </header>
        <main>
            <slot />
        </main>
    </div>
</template>

<script setup>
import { Link } from '@inertiajs/vue3';
</script>

<!-- resources/js/Pages/Posts/Index.vue -->
<template>
    <AuthenticatedLayout>
        <template #header>
            <h1>Posts</h1>
        </template>

        <input v-model="search" @input="handleSearch" placeholder="Search..." />

        <div v-for="post in posts.data" :key="post.id">
            <Link :href="`/posts/${post.id}`">
                <h3>{{ post.title }}</h3>
            </Link>
            <p>{{ post.excerpt }}</p>
        </div>
    </AuthenticatedLayout>
</template>

<script setup>
import { ref } from 'vue';
import { router } from '@inertiajs/vue3';
import AuthenticatedLayout from '@/Layouts/Authenticated.vue';

const props = defineProps({
    posts: Object,
    filters: Object,
});

const search = ref(props.filters.search || '');

function handleSearch() {
    router.get('/posts', { search: search.value }, {
        preserveState: true,
        replace: true,
    });
}
</script>

<!-- resources/js/Pages/Posts/Create.vue -->
<template>
    <form @submit.prevent="submit">
        <input v-model="form.title" placeholder="Title" />
        <div v-if="form.errors.title">{{ form.errors.title }}</div>

        <textarea v-model="form.content" placeholder="Content" />
        <div v-if="form.errors.content">{{ form.errors.content }}</div>

        <button type="submit" :disabled="form.processing">
            {{ form.processing ? 'Saving...' : 'Save' }}
        </button>
    </form>
</template>

<script setup>
import { useForm } from '@inertiajs/vue3';

const form = useForm({
    title: '',
    content: '',
});

function submit() {
    form.post('/posts');
}
</script>
```

```php
// PHP — tetap sama seperti Inertia React
class PostController extends Controller
{
    public function index(): Response
    {
        return Inertia::render('Posts/Index', [
            'posts' => Post::latest()->paginate(10),
            'filters' => request()->only('search'),
        ]);
    }
}
```

## Kasus Penggunaan Nyata
Tim frontend lebih familiar dengan Vue — Inertia + Vue memungkinkan mereka tetap pakai Vue SFC (template, script, style) tanpa perlu belajar React.
