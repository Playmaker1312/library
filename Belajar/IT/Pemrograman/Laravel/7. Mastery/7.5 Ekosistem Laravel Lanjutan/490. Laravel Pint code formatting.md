# 490. Laravel Pint Code Formatting

## Definisi Singkat
PHP code formatter resmi dari Laravel — berbasis PHP-CS-Fixer yang sudah di-pre-configured dengan aturan coding style Laravel untuk menjaga konsistensi kode.

## Analogi
Seperti ~setrika untuk baju~ — kode kita (baju) yang kusut (format berantakan) disetrika (Pint) jadi rapi dan bersih. Semua tim pakai standar yang sama.

## Poin-Poin Penting
- Built-in Laravel preset — langsung pakai
- Zero-config — install, jalankan, selesai
- Integrasi dengan editor (VS Code extension)
- Bisa dikustomisasi aturannya
- Fix otomatis — tidak perlu manual
- Pre-commit hook opsional

## Contoh Kode
```bash
# Install
composer require laravel/pint --dev

# Jalankan — fix semua file
./vendor/bin/pint

# Test mode — lihat perubahan tanpa fix
./vendor/bin/pint --test

# Fix folder spesifik
./vendor/bin/pint app/Models
./vendor/bin/pint app/Http/Controllers

# Diff — lihat perubahan detail
./vendor/bin/pint --diff

# Verbose
./vendor/bin/pint -v
```

```json
// pint.json — konfigurasi di root project
{
    "preset": "laravel",
    "rules": {
        "simplified_null_return": true,
        "braces": {
            "allow_single_line_anonymous_class_with_empty_body": true
        },
        "concat_space": {
            "spacing": "one"
        }
    }
}
```

```json
// Contoh pint.json kustom
{
    "preset": "psr12",
    "rules": {
        "ordered_imports": {
            "sort_algorithm": "alpha"
        },
        "no_unused_imports": true,
        "trailing_comma_in_multiline": true,
        "global_namespace_import": {
            "import_classes": true,
            "import_constants": false,
            "import_functions": true
        },
        "exclude": [
            "bootstrap/cache"
        ]
    }
}
```

```bash
# Pre-commit hook — .husky/pre-commit
#!/usr/bin/env sh
. "$(dirname -- "$0")/_/husky.sh"

./vendor/bin/pint --test

# Atau di composer scripts
```

```json
{
    "scripts": {
        "lint": "./vendor/bin/pint --test",
        "lint:fix": "./vendor/bin/pint",
        "post-update-cmd": [
            "@lint:fix"
        ]
    }
}
```

```yaml
# GitHub Actions — Pint check
name: Code Style
on: [push, pull_request]
jobs:
    pint:
        runs-on: ubuntu-latest
        steps:
            - uses: actions/checkout@v3
            - uses: shivammathur/setup-php@v2
              with:
                  php-version: '8.2'
            - run: composer install
            - run: ./vendor/bin/pint --test
```

```bash
# VS Code — otomatis fix on save
# Settings.json
{
    "[php]": {
        "editor.defaultFormatter": "open-southeners.laravel-pint",
        "editor.formatOnSave": true
    }
}
```

## Kasus Penggunaan Nyata
Tim 10 developer dengan gaya coding berbeda-beda — dengan Pint di CI/CD, semua pull request otomatis di-cek formatnya. Kode konsisten, review lebih fokus ke logic.
