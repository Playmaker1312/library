# 486. Laravel Socialite OAuth Google GitHub

## Definisi Singkat
Package resmi Laravel untuk autentikasi OAuth — memungkinkan login via Google, GitHub, Facebook, Twitter, GitLab, Bitbucket, dan provider lainnya.

## Analogi
Seperti "Login with Google" di website — kita tidak perlu daftar akun baru. Cukup klik, setuju, dan masuk. Socialite yang urus komunikasi dengan provider.

## Poin-Poin Penting
- Install Socialite + provider-specific package
- Konfigurasi credentials di `config/services.php`
- Dua route: redirect (ke provider) dan callback (dari provider)
- User data dari provider: name, email, avatar
- Social account bisa di-link ke akun existing
- Support custom providers

## Contoh Kode
```php
<?php

// Install
composer require laravel/socialite

// config/services.php
return [
    'google' => [
        'client_id' => env('GOOGLE_CLIENT_ID'),
        'client_secret' => env('GOOGLE_CLIENT_SECRET'),
        'redirect' => env('GOOGLE_REDIRECT_URI'),
    ],

    'github' => [
        'client_id' => env('GITHUB_CLIENT_ID'),
        'client_secret' => env('GITHUB_CLIENT_SECRET'),
        'redirect' => env('GITHUB_REDIRECT_URI'),
        'allow_symlinks' => false,
    ],

    'facebook' => [
        'client_id' => env('FACEBOOK_CLIENT_ID'),
        'client_secret' => env('FACEBOOK_CLIENT_SECRET'),
        'redirect' => env('FACEBOOK_REDIRECT_URI'),
    ],
];

// Controller
namespace App\Http\Controllers\Auth;

use App\Models\User;
use App\Models\SocialAccount;
use Laravel\Socialite\Facades\Socialite;

class SocialiteController extends Controller
{
    // Redirect ke provider
    public function redirect(string $provider)
    {
        return Socialite::driver($provider)
            ->scopes(['read:user', 'public_repo']) // GitHub scopes
            ->redirect();
    }

    // Callback dari provider
    public function callback(string $provider)
    {
        try {
            $socialUser = Socialite::driver($provider)->user();
        } catch (\Exception $e) {
            return redirect('/login')->with('error', 'Authentication failed');
        }

        $user = $this->findOrCreateUser($socialUser, $provider);

        auth()->login($user, true);

        return redirect()->intended('/dashboard');
    }

    protected function findOrCreateUser($socialUser, string $provider): User
    {
        // Cari social account yang sudah ada
        $socialAccount = SocialAccount::where('provider', $provider)
            ->where('provider_user_id', $socialUser->getId())
            ->first();

        if ($socialAccount) {
            return $socialAccount->user;
        }

        // Cari user by email
        $user = User::where('email', $socialUser->getEmail())->first();

        if (!$user) {
            // Register user baru
            $user = User::create([
                'name' => $socialUser->getName(),
                'email' => $socialUser->getEmail(),
                'avatar' => $socialUser->getAvatar(),
                'email_verified_at' => now(), // email dari provider sudah verified
            ]);
        }

        // Link social account ke user
        $user->socialAccounts()->create([
            'provider' => $provider,
            'provider_user_id' => $socialUser->getId(),
            'token' => $socialUser->token,
            'refresh_token' => $socialUser->refreshToken,
        ]);

        return $user;
    }

    // Link social account ke user yang sudah login
    public function linkAccount(string $provider)
    {
        return Socialite::driver($provider)->redirect();
    }

    public function handleLinkCallback(string $provider)
    {
        $socialUser = Socialite::driver($provider)->user();

        auth()->user()->socialAccounts()->create([
            'provider' => $provider,
            'provider_user_id' => $socialUser->getId(),
            'token' => $socialUser->token,
        ]);

        return redirect()->back()->with('success', 'Account linked!');
    }
}

// Model SocialAccount
class SocialAccount extends Model
{
    protected $fillable = [
        'user_id', 'provider', 'provider_user_id',
        'token', 'refresh_token',
    ];

    public function user(): BelongsTo
    {
        return $this->belongsTo(User::class);
    }
}

// Migration
Schema::create('social_accounts', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained()->cascadeOnDelete();
    $table->string('provider'); // google, github, facebook
    $table->string('provider_user_id');
    $table->text('token')->nullable();
    $table->text('refresh_token')->nullable();
    $table->timestamps();

    $table->unique(['provider', 'provider_user_id']);
    $table->index('user_id');
});

// routes/web.php
Route::get('auth/{provider}', [SocialiteController::class, 'redirect'])->name('social.redirect');
Route::get('auth/{provider}/callback', [SocialiteController::class, 'callback'])->name('social.callback');
```

## Kasus Penggunaan Nyata
Aplikasi "Dev Community" — user bisa login via GitHub (ambil repo, avatar, username). Socialite handle OAuth, tinggal 2 route dan user langsung terdaftar.
