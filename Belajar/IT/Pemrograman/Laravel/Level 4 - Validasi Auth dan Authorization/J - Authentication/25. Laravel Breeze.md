# 25. Laravel Breeze — Scaffolding Auth yang Cepat

## Penjelasan

**Laravel Breeze** adalah paket scaffolding autentikasi minimalis yang menyediakan route, controller, dan view untuk login, register, password reset, email verification, dan profil.

```bash
composer require laravel/breeze --dev
php artisan breeze:install blade  # blade | livewire | react | vue | api
npm install && npm run dev
php artisan migrate
```

Breeze membuat:
- `routes/auth.php` — semua route auth
- `app/Http/Controllers/Auth/` — controller login, register, dll
- `resources/views/auth/` — view login, register, lupa password
- Middleware `auth` dan `guest` terdaftar otomatis

## Fungsi

- Menyediakan sistem autentikasi lengkap dalam beberapa perintah
- Best practice: CSRF, session, password hashing sudah diatur
- View yang bisa dimodifikasi sesuai kebutuhan

## Cara Pengimplementasian

```bash
# 1. Install Breeze
composer require laravel/breeze --dev
php artisan breeze:install blade

# 2. Pilih stack: blade (paling sederhana)

# 3. Install frontend
npm install
npm run dev

# 4. Jalankan migration
php artisan migrate

# 5. Akses /register dan /login di browser
```

**Yang dibuat Breeze:**
```
routes/auth.php

resources/views/auth/
├── login.blade.php
```

```php
<?php
// routes/auth.php — route yang dibuat Breeze

Route::middleware('guest')->group(function () {
    Route::get('register', [RegisteredUserController::class, 'create'])->name('register');
    Route::post('register', [RegisteredUserController::class, 'store']);
    Route::get('login', [AuthenticatedSessionController::class, 'create'])->name('login');
    Route::post('login', [AuthenticatedSessionController::class, 'store']);
});

Route::middleware('auth')->group(function () {
    Route::post('logout', [AuthenticatedSessionController::class, 'destroy'])->name('logout');
});
```

## Analogi

Breeze seperti **paket standar keanggotaan perpustakaan**:

Daripada membuat formulir keanggotaan dari nol (print sendiri, tentukan format sendiri), perpustakaan sudah menyediakan **paket starter** yang tinggal dipakai:
- Formulir pendaftaran (register)
- Kartu masuk (login)
- Prosedur lupa kartu (forgot password)
- Verifikasi email (email verification)

Breeze melakukan semua ini. Kamu tinggal menyesuaikan tampilan (warna, logo) sesuai branding perpustakaan.

**Tanpa Breeze:**
```
Buat User model → migration users → buat register form → buat login form →
buat controller → validasi → session → password hashing →
forgot password → email sending → ... → 2 hari kerja
```

**Dengan Breeze:**
```
php artisan breeze:install blade → 5 menit → selesai
```

## Dipakai untuk Apa

- **Setiap aplikasi yang butuh login** — hampir semua aplikasi web
- **Memulai project baru** — Breeze sebagai fondasi auth
- **Belajar auth** — bisa baca kode Breeze untuk memahami cara kerja auth

## Kesalahan Umum

1. **Install Breeze setelah project berjalan** — bisa, tapi backup dulu jika sudah punya route/view sendiri
2. **Stack salah pilih** — pilih `blade` jika ingin Blade murni, `livewire` jika mau interaktif
3. **Lupa `npm install && npm run dev`** — CSS/JS tidak ter-load, form tidak menarik
4. **Mengubah file Breeze tanpa paham** — Breeze dibuat untuk dimodifikasi, tapi pahami dulu strukturnya
5. **Breeze vs Jetstream vs Fortify** — Breeze untuk sederhana, Jetstream untuk kompleks (team, 2FA), Fortify untuk headless (API-only auth)
6. **Tidak migrate setelah install** — tabel users belum ada, register gagal

## Koneksi dengan Materi Sebelumnya

Poin 24 membahas validasi. Breeze menggunakan Form Request dan validasi di auth controller. Setelah memahami validasi, auth menjadi lebih masuk akal — login/register adalah form yang divalidasi.
