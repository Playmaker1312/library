# 24. File konfigurasi kustom

## Definisi Singkat
Anda dapat membuat file konfigurasi sendiri di folder `config/` untuk mengatur pengaturan spesifik aplikasi (misal: `config/payment.php`, `config/shipping.php`).

## Analogi
Seperti menambah laci baru di lemari arsip yang sudah ada — Anda buat label baru (file config) sesuai kebutuhan bisnis.

## Poin-Poin Penting
- Cukup buat file PHP di `config/` yang me-return array
- Nama file akan menjadi key: `config/payment.php` → `config('payment.*')`
- Bisa menggunakan `env()` untuk nilai environment-dependent
- Setelah membuat file baru, jalankan `php artisan config:cache` untuk production
- File config otomatis terdeteksi — tidak perlu registrasi
- Best practice: gunakan lowercase, plural, deskriptif untuk nama file
- Contoh: `config/currency.php`, `config/feature-flags.php`, `config/upload.php`

## Contoh Kode
```php
<?php
// config/payment.php — file konfigurasi kustom
return [
    'gateway' => env('PAYMENT_GATEWAY', 'midtrans'),
    'currency' => 'IDR',
    'tax_rate' => 0.11,
    'methods' => [
        'bank_transfer' => [
            'banks' => ['BCA', 'BNI', 'Mandiri'],
            'fee' => 2500,
        ],
        'credit_card' => [
            'installment_months' => [3, 6, 12],
        ],
    ],
];

// Akses dari mana saja
$taxRate = config('payment.tax_rate');
$gateway = config('payment.gateway');
$banks = config('payment.methods.bank_transfer.banks');
```

## Kasus Penggunaan Nyata
Aplikasi e-commerce membuat `config/shipping.php` yang berisi ongkos kirim per wilayah, metode pengiriman (JNE, SiCepat, GoSend), dan minimal gratis ongkir.
