# 23. File di folder config: app, database, mail, cache

## Definisi Singkat
Setiap file di folder `config/` mengatur aspek spesifik aplikasi — `app.php` untuk aplikasi, `database.php` untuk koneksi DB, `mail.php` untuk email, `cache.php` untuk caching.

## Analogi
Seperti panel kontrol mobil: `app.php` = speedometer (identitas), `database.php` = mesin (data), `mail.php` = klakson (komunikasi), `cache.php` = turbo (performa).

## Poin-Poin Penting
| File             | Fungsi                                           |
|------------------|--------------------------------------------------|
| `app.php`        | Nama aplikasi, env, debug, timezone, locale, URL |
| `database.php`   | Koneksi database — mysql, pgsql, sqlite, sqlsrv  |
| `mail.php`       | Konfigurasi mailer — smtp, mailgun, postmark, ses |
| `cache.php`      | Driver cache — file, redis, memcached, dynamodb  |
| `session.php`    | Driver session — file, cookie, database, redis   |
| `queue.php`      | Queue driver — sync, database, redis, sqs        |
| `filesystems.php`| Storage disk — local, s3, public, custom         |
| `logging.php`    | Log channels — single, daily, slack, papertrail  |
| `cors.php`       | CORS settings — origins, methods, headers         |
| `services.php`   | API keys — Stripe, GitHub, Algolia, dll          |

## Contoh Kode
```php
// config/database.php — koneksi multi database
'connections' => [
    'mysql' => [
        'driver' => 'mysql',
        'host' => env('DB_HOST', '127.0.0.1'),
        'database' => env('DB_DATABASE', 'forge'),
        'username' => env('DB_USERNAME', 'forge'),
        'password' => env('DB_PASSWORD', ''),
    ],
    'redis' => [
        'client' => 'phpredis',
        'default' => [
            'host' => env('REDIS_HOST', '127.0.0.1'),
        ],
    ],
],
```

## Kasus Penggunaan Nyata
Aplikasi menggunakan MySQL untuk data utama, Redis untuk cache dan queue. Konfigurasi di `config/database.php` mengatur kedua koneksi dengan credential dari `.env`.
