# 25. Environment: development, testing, production

## Definisi Singkat
Laravel memiliki tiga environment utama — development (pengembangan), testing (pengujian), dan production (produksi) — masing-masing dengan konfigurasi dan perilaku berbeda.

## Analogi
Seperti tiga ruangan berbeda: development adalah bengkel kerja (berantakan boleh), testing adalah ruang uji coba, production adalah ruang pamer (harus rapi dan aman).

## Poin-Poin Penting
| Environment  | APP_ENV     | APP_DEBUG | Tujuan                           |
|--------------|-------------|-----------|----------------------------------|
| Development  | `local`     | `true`    | Menulis kode, debugging          |
| Testing      | `testing`   | `true`    | Menjalankan PHPUnit / Pest       |
| Staging      | `staging`   | `false`   | Mirror production untuk uji coba |
| Production   | `production`| `false`   | Live — pengguna nyata            |

- **Development**: error detail ditampilkan, log verbos, cache dimatikan
- **Testing**: database SQLite in-memory, mail fake, queue sync
- **Production**: debug mati (keamanan), cache aktif, optimasi penuh
- File `.env` berbeda per environment — jangan tertukar
- Deteksi environment: `app()->environment('production')`
- Testing environment otomatis aktif saat `phpunit` atau `pest` dijalankan
- Production harus jalankan: `php artisan optimize`

## Contoh Kode
```php
// Deteksi environment saat ini
if (app()->environment('production')) {
    // Kirim error ke Sentry, bukan tampilkan di layar
}

// Konfigurasi berbeda per environment
// config/app.php
'debug' => env('APP_DEBUG', false),

// Cek environment di controller
$env = app()->environment();
// 'local', 'production', 'testing', dll
```

## Kasus Penggunaan Nyata
Sebelum deployment ke server production, developer mengganti `APP_ENV=production` dan `APP_DEBUG=false`, lalu menjalankan `php artisan optimize` untuk performa maksimal.
