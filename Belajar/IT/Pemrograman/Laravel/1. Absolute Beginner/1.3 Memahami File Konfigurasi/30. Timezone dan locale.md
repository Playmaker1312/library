# 30. Timezone dan locale

## Definisi Singkat
Timezone mengatur zona waktu aplikasi (default UTC), sedangkan locale mengatur bahasa dan format regional (tanggal, angka, mata uang).

## Analogi
Timezone seperti jam dinding di kantor — semua orang harus melihat jam yang sama agar rapat tidak kacau. Locale seperti papan tulis — bisa bahasa Indonesia, Inggris, atau Jepang.

## Poin-Poin Penting
**Timezone:**
- Default: `UTC` (standar internasional)
- Atur di `config/app.php` → `'timezone' => 'Asia/Jakarta'`
- Atau via `.env`: tidak ada variable default — atur langsung di config
- Zona Indonesia: `Asia/Jakarta` (WIB), `Asia/Makassar` (WITA), `Asia/Jayapura` (WIT)
- Pengaruh: `now()`, `Carbon::now()`, timestamp di database

**Locale:**
- Default: `en` (English)
- Atur di `config/app.php` → `'locale' => 'id'` (Indonesia)
- Untuk localization penuh (file JSON di `resources/lang/`)
- `app()->setLocale('id')` untuk ganti runtime
- `Carbon::setLocale('id')` untuk format tanggal Indonesia

## Contoh Kode
```php
// config/app.php
'timezone' => 'Asia/Jakarta',
'locale' => 'id',

// Penggunaan di kode
echo now(); // 2026-05-28 13:45:00 (WIB)

// Format tanggal Indonesia
use Carbon\Carbon;
Carbon::setLocale('id');
echo Carbon::now()->translatedFormat('l, d F Y');
// "Kamis, 28 Mei 2026"

// Ganti locale runtime
app()->setLocale('en');
echo __('messages.welcome'); // tergantung file terjemahan
```

## Kasus Penggunaan Nyata
Aplikasi e-commerce Indonesia mengatur timezone ke `Asia/Jakarta` dan locale ke `id` agar tampilan tanggal dan nominal sesuai kebiasaan lokal.
