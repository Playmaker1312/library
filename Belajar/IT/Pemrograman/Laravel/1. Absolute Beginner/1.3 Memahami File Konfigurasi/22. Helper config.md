# 22. Helper config

## Definisi Singkat
`config()` adalah helper global Laravel untuk membaca dan menulis nilai dari file konfigurasi di folder `config/` dengan dukungan dot notation.

## Analogi
Seperti papan kontrol — Anda bisa melihat (get) dan mengubah (set) semua pengaturan dari satu tempat terpusat.

## Poin-Poin Penting
- Sintaks: `config('file.key', 'default')` — misal `config('app.name')`
- Dot notation: `config('database.connections.mysql.host')`
- Bisa juga set nilai runtime: `config(['app.debug' => true])`
- Helper ini membaca dari file di folder `config/` yang sudah di-cache
- Setelah `php artisan config:cache`, semua config disimpan di `bootstrap/cache/config.php`
- Jangan gabung `env()` dan `config()` — gunakan `config()` saja untuk konsistensi
- File config: `config/app.php`, `config/database.php`, `config/mail.php`, dll
- Supported di seluruh Laravel: Blade, Controller, Command, Job, dll

## Contoh Kode
```php
// Membaca konfigurasi
$appName = config('app.name');
$dbHost = config('database.connections.mysql.host');
$timezone = config('app.timezone', 'UTC');

// Set konfigurasi runtime (hanya untuk request ini)
config(['app.debug' => false]);

// Menulis custom config
// config/custom.php
return [
    'pagination' => 15,
    'currency' => 'IDR',
];
// Akses: config('custom.pagination')
```

## Kasus Penggunaan Nyata
Aplikasi multi-bahasa menggunakan `config('app.locale')` untuk menentukan bahasa tampilan, diubah via `config(['app.locale' => 'id'])`.
