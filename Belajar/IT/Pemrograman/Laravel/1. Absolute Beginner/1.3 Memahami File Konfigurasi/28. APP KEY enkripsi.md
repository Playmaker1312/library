# 28. APP KEY enkripsi

## Definisi Singkat
`APP_KEY` adalah kunci enkripsi 32 karakter (base64) yang digunakan Laravel untuk mengamankan session, cookie, dan data terenkripsi lainnya.

## Analogi
Seperti kunci gembok pribadi — tanpa kunci yang tepat, data yang terkunci (session, cookie) tidak bisa dibuka. Setiap instalasi Laravel harus punya kunci unik.

## Poin-Poin Penting
- Format: `base64:.............` (base64 encoded random string)
- Panjang: 32 byte (256-bit) untuk AES-256-CBC dan AES-256-GCM
- Digunakan untuk enkripsi: session data, cookie values, CSRF token
- Juga digunakan oleh fitur: encryption (`Crypt::encrypt`), signed URLs, queue payload
- Jika `APP_KEY` diganti setelah produksi: semua session user, cookie, dan data terenkripsi menjadi invalid
- Jangan pernah commit `APP_KEY` asli ke repository publik
- Gunakan environment variable berbeda untuk setiap environment

## Contoh Kode
```php
// Generate APP_KEY — otomatis saat composer create-project
// Atau manual:
// php artisan key:generate

// Hasil di .env:
// APP_KEY=base64:8h3sJf9a2kL5pQ7wE6rT4yU1iO0zXcVbNm8gH6jR3=

// Menggunakan APP_KEY untuk enkripsi data
use Illuminate\Support\Facades\Crypt;

$encrypted = Crypt::encryptString('Data sensitif');
$decrypted = Crypt::decryptString($encrypted);

// Signed URLs (menggunakan APP_KEY)
URL::signedRoute('unsubscribe', ['user' => 1]);
```

## Kasus Penggunaan Nyata
Saat memindahkan project ke server baru, file `.env` harus disalin termasuk `APP_KEY` yang sama; jika tidak, semua session user akan terlogout dan cookie tidak terbaca.
