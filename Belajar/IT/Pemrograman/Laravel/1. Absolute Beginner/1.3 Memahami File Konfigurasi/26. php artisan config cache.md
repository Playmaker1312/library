# 26. php artisan config:cache

## Definisi Singkat
Perintah untuk menggabungkan semua file konfigurasi di `config/` menjadi satu file cache untuk mempercepat loading aplikasi.

## Analogi
Seperti menyiapkan semua bahan masakan dalam satu wadah sebelum mulai memasak — tidak perlu bolak-balik ke kulkas (baca file config) setiap kali.

## Poin-Poin Penting
- Perintah: `php artisan config:cache`
- File cache tersimpan di `bootstrap/cache/config.php`
- Semua konfigurasi digabung jadi satu file — lebih cepat di-load
- **Wajib** dijalankan di environment production
- Setelah di-cache, `env()` helper tidak akan berfungsi — gunakan `config()` saja
- Jika mengubah file config atau `.env`, jalankan ulang `config:cache`
- Error jika ada sintaks tidak valid di file config — cache gagal
- Untuk menghapus cache: `php artisan config:clear`
- Best practice: jalankan `config:cache` di deployment script

## Contoh Kode
```bash
# Cache konfigurasi
php artisan config:cache

# Output: Configuration cached successfully!

# Jika ada error sintaks di file config
# Output: Parse error ... dan daftar file bermasalah

# Setelah perubahan pada .env atau config/*.php
php artisan config:cache

# Best practice: jalankan saat deployment
# deploy.sh
php artisan down --render="maintenance"
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan up
```

## Kasus Penggunaan Nyata
Saat deployment ke production, script CI/CD menjalankan `php artisan config:cache` sehingga aplikasi tidak perlu membaca file configs satu per satu setiap request.
