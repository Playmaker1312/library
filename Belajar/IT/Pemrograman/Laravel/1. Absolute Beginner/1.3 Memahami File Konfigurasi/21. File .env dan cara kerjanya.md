# 21. File .env dan cara kerjanya

## Definisi Singkat
File `.env` berisi variabel environment spesifik untuk instalasi lokal — nilainya di-load oleh framework saat bootstrap dan digunakan sebagai konfigurasi aplikasi.

## Analogi
Seperti kunci lemari yang berbeda untuk setiap rumah — isi .env unik per environment (development, staging, production) dan tidak pernah dibagikan.

## Poin-Poin Penting
- Laravel menggunakan package `vlucas/phpdotenv` untuk membaca `.env`
- Variabel dibaca dengan `env('KEY', 'default_value')`
- Urutan prioritas: `$_ENV` > `.env` file > .env.example
- Setiap baris: `KEY=VALUE` — tidak ada spasi sekitar `=`
- Nilai dengan spasi: `APP_NAME="My App"`
- Komentar: mulai dengan `#`
- File `.env` dimuat sebelum Service Provider — tersedia di seluruh siklus request
- `php artisan config:cache` menyimpan konfigurasi — env() tidak akan berfungsi jika cache aktif
- Di production, hindari `env()` langsung di kode; gunakan `config()` yang sudah di-cache

## Contoh Kode
```dotenv
# File .env
APP_NAME="Toko Online"
APP_ENV=local
APP_DEBUG=true
APP_URL=http://localhost:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=toko_online
DB_USERNAME=root
DB_PASSWORD=secret123

MAIL_MAILER=smtp
MAIL_HOST=smtp.mailtrap.io
MAIL_PORT=2525
```

## Kasus Penggunaan Nyata
Saat deployment ke production, file `.env` diisi dengan credential asli (DB production, Stripe live key) tanpa mengubah kode apa pun.
