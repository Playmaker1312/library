# 29. php artisan key:generate

## Definisi Singkat
Perintah Artisan untuk menghasilkan `APP_KEY` baru (random 32-byte string) dan menyimpannya ke file `.env`.

## Analogi
Seperti mesin pembuat kunci otomatis — Anda masukkan blank (project tanpa key) dan keluar kunci unik yang siap digunakan.

## Poin-Poin Penting
- Perintah: `php artisan key:generate`
- Mengecek apakah `APP_KEY` sudah ada di `.env` — jika ada, akan ditimpa
- Untuk safety, Laravel akan menanyakan konfirmasi jika key sudah ada (Laravel 11)
- Gunakan `--force` atau `--show` untuk bypass
- `--show` hanya menampilkan key tanpa menyimpannya
- Biasanya dijalankan satu kali setelah `composer create-project`
- Key di-generate menggunakan `Str::random(32)` yang di-base64
- Jika `.env` tidak ditemukan, command akan error
- Laravel Installer sudah otomatis generate key saat `laravel new`

## Contoh Kode
```bash
# Generate APP_KEY baru
php artisan key:generate

# Output:
# Application key set successfully.

# Generate dan tampilkan key (tanpa simpan ke .env)
php artisan key:generate --show
# Output: base64:8h3sJf9a2kL5pQ7wE6rT4yU1iO0zXcVbNm8gH6jR3=

# Paksa generate tanpa konfirmasi (jika key sudah ada)
php artisan key:generate --force

# Situasi: error "No application encryption key..."
# Solusi: php artisan key:generate
```

## Kasus Penggunaan Nyata
Developer selesai clone project dari GitHub: `composer install` lalu `php artisan key:generate` karena `.env` asli tidak ikut di-commit dan `APP_KEY` masih kosong.
