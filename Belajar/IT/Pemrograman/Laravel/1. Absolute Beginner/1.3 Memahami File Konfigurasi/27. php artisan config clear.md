# 27. php artisan config:clear

## Definisi Singkat
Perintah untuk menghapus cache konfigurasi yang tersimpan, memaksa Laravel membaca ulang file config dari folder `config/` pada request berikutnya.

## Analogi
Seperti menghapus catatan tempelan dan memaksa Anda membaca buku resep asli lagi — berguna saat resep (config) berubah.

## Poin-Poin Penting
- Perintah: `php artisan config:clear`
- Menghapus file `bootstrap/cache/config.php`
- Gunakan saat development — agar perubahan config langsung terlihat
- Jangan lupa `config:cache` ulang sebelum deploy ke production
- Alternatif: `php artisan optimize:clear` — clear semua cache (config, route, view, cache)
- Tidak merusak aplikasi — hanya memperlambat sedikit karena baca file ulang
- Wajib dilakukan jika ada masalah setelah config cache

## Contoh Kode
```bash
# Hapus cache konfigurasi
php artisan config:clear

# Output: Configuration cache cleared!

# Clear semua cache sekaligus
php artisan optimize:clear

# Setelah clear, config akan dibaca langsung dari file
config('app.name'); // membaca dari config/app.php

# Workflow development:
# 1. Ubah .env atau config/*.php
# 2. php artisan config:clear
# 3. Refresh browser
```

## Kasus Penggunaan Nyata
Developer mengubah `APP_NAME` di `.env` tetapi tidak melihat perubahan. Setelah menjalankan `php artisan config:clear`, nama aplikasi berubah — karena cache config sebelumnya masih menyimpan nilai lama.
