# 20. php artisan serve

## Definisi Singkat
Perintah Artisan untuk menjalankan development server bawaan PHP secara lokal, biasanya di `http://localhost:8000`.

## Analogi
Seperti menghidupkan generator listrik portabel — cukup nyalakan dan semua komponen aplikasi langsung bisa diakses tanpa perlu instalasi web server penuh.

## Poin-Poin Penting
- Gunakan PHP built-in development server — tidak perlu Apache/Nginx
- Default port: 8000
- Opsi `--port=8080` untuk ganti port
- Opsi `--host=0.0.0.0` untuk akses dari perangkat lain (LAN)
- Hanya untuk development — jangan pernah digunakan di production
- Reload otomatis: tidak ada hot reload — restart manual setiap perubahan
- Untuk hot reload, gunakan: Laravel Herd, Valet, atau `laravel serve` via Docker Sail
- Bisa dihentikan dengan `Ctrl+C` di terminal
- Alternatif: `php -S localhost:8000 -t public` (server PHP murni)

## Contoh Kode
```bash
# Jalankan server development di port default
php artisan serve

# Output: Laravel development server started: http://localhost:8000

# Ganti port
php artisan serve --port=8080

# Akses dari perangkat lain di jaringan
php artisan serve --host=0.0.0.0 --port=8000

# Jalankan di background (Windows — start process)
Start-Process -NoNewWindow php "artisan serve"
```

## Kasus Penggunaan Nyata
Developer ingin mengetes aplikasi Laravel setelah membuat fitur baru: buka terminal, `php artisan serve`, buka browser `localhost:8000`, lihat hasilnya.
