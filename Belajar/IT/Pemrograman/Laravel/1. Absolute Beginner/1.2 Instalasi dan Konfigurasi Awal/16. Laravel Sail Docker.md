# 16. Laravel Sail (Docker)

## Definisi Singkat
Laravel Sail adalah environment development berbasis Docker yang siap pakai — satu perintah `./vendor/bin/sail up` menyediakan seluruh stack aplikasi.

## Analogi
Seperti kontainer pengiriman standar — semua barang (server, database, cache) sudah dikemas rapi dan bisa dibuka di mana saja.

## Poin-Poin Penting
- Diperkenalkan di Laravel 8 — sekarang menjadi development environment default
- Berbasis `docker-compose.yml` — service diatur via file
- Service default: PHP, MySQL, Redis, Mailhog, Meilisearch, Selenium
- Tidak perlu instal PHP/MySQL/Composer di host — semuanya di container
- Perintah via `./vendor/bin/sail` (bisa dibuat alias: `alias sail='[ -f sail ] && sh sail || sh vendor/bin/sail'`)
- Support macOS, Windows (WSL2), Linux
- `sail share` — expose aplikasi ke internet via Ngrok
- `sail shell` — masuk ke container PHP
- Memori lebih boros dari Laragon/Herd tapi lingkungan sangat konsisten
- Cocok untuk tim dengan OS berbeda — semua container sama persis
- Laravel 11: Sail sudah tersedia di skeleton default

## Contoh Kode
```bash
# Install Sail di project Laravel
composer require laravel/sail --dev
php artisan sail:install

# Jalankan container
./vendor/bin/sail up -d

# Jalankan perintah artisan di dalam container
./vendor/bin/sail artisan migrate

# Shell ke container
./vendor/bin/sail shell

# Stop semua container
./vendor/bin/sail down
```

## Kasus Penggunaan Nyata
Tim dengan campuran macOS, Windows, dan Linux menggunakan Sail untuk memastikan environment development identik — "works on my machine" tidak lagi jadi masalah.
