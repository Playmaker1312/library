# 11. Persyaratan sistem: PHP versi dan ekstensi

## Definisi Singkat
Laravel 11 membutuhkan PHP 8.2+ dengan ekstensi spesifik seperti BCMath, Ctype, Fileinfo, JSON, Mbstring, OpenSSL, PDO, Tokenizer, dan XML.

## Analogi
Seperti membangun rumah — Anda perlu fondasi yang kuat (PHP versi tepat) dan peralatan yang sesuai (ekstensi) agar konstruksi berjalan lancar.

## Poin-Poin Penting
- **PHP minimum per versi**:
  - Laravel 9: PHP 8.0+
  - Laravel 10: PHP 8.1+
  - Laravel 11: PHP 8.2+
- **Ekstensi wajib**: BCMath, Ctype, Fileinfo, JSON, Mbstring, OpenSSL, PDO, Tokenizer, XML, GD (untuk image), PCNTL (untuk queue)
- **Database**: MySQL 5.7+/8.0, PostgreSQL 10+, SQLite 3.8+, SQL Server 2017+
- **Web server**: Apache (mod_rewrite) atau Nginx
- **Composer**: 2.x required (untuk Laravel 9+)
- **Node & npm**: Untuk frontend build (Vite, Mix) — optional jika API-only
- Cek PHP dan ekstensi dengan `php -v` dan `php -m`

## Contoh Kode
```bash
# Cek PHP versi
php -v

# Cek ekstensi yang terinstal
php -m

# Cek apakah ekstensi tertentu aktif
php -m | Select-String "mbstring"
php -m | Select-String "pdo"

# Laravel requirement checker
composer create-project laravel/laravel my-app --no-interaction
```

## Kasus Penggunaan Nyata
Saat menginstal Laravel di shared hosting, developer perlu memastikan hosting menyediakan PHP 8.2+ dan ekstensi yang dibutuhkan. Cek via `phpinfo()`.
