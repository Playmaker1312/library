# 14. Laravel Herd (macOS)

## Definisi Singkat
Laravel Herd adalah lingkungan development all-in-one untuk macOS yang menyediakan PHP, Nginx, dan database dalam satu aplikasi tanpa konfigurasi rumit.

## Analogi
Seperti membuka laptop dan langsung dapat meja kerja lengkap — tanpa perlu memasang XAMPP, MAMP, atau mengatur konfigurasi server manual.

## Poin-Poin Penting
- Dikembangkan oleh BeyondCode (tim ekosistem Laravel)
- Mendukung PHP 8.0 hingga 8.3 — bisa switch versi per project
- Otomatis mendeteksi project Laravel di folder `~/Herd`
- Termasuk: Nginx + PHP-FPM, MySQL, PostgreSQL, Redis, Mailpit, ngrok
- Integrasi dengan Laravel Valet (isolated site per project)
- Support untuk Laravel Installer, Composer, dan npm
- Fitur "Secured" — otomatis SSL via `herd secure project-name`
- Minimalis: cukup download dan drag ke Applications
- Hanya untuk macOS (Intel dan Apple Silicon)
- Gratis (ada opsi Pro berbayar dengan fitur tambahan)

## Contoh Kode
```bash
# Install Herd via herd.laravel.com
# Setelah terinstal, project Laravel di ~/Herd otomatis bisa diakses

# Contoh akses http://my-app.test
# (sesuai nama folder project)

# Secure site dengan SSL
herd secure my-app

# Ganti versi PHP per project
# Klik kanan Herd menu bar -> PHP -> Pilih versi
```

## Kasus Penggunaan Nyata
Developer macOS ingin development Laravel cepat tanpa XAMPP: download Herd, buat folder `~/Herd/my-app`, jalan `composer create-project` di sana, langsung akses `http://my-app.test`.
