# 17. Struktur direktori Laravel

## Definisi Singkat
Laravel mengikuti struktur direktori default yang terorganisir dengan folder utama: `app`, `bootstrap`, `config`, `database`, `public`, `resources`, `routes`, `storage`, `tests`.

## Analogi
Seperti rak buku dengan label khusus — setiap folder memiliki fungsi tertentu sehingga kode mudah ditemukan dan dipelihara.

## Poin-Poin Penting
```
my-app/
├── app/              # Kode inti aplikasi
│   ├── Console/      # Artisan commands
│   ├── Exceptions/   # Error handlers
│   ├── Http/         # Controllers, Middleware, Requests
│   ├── Models/       # Eloquent models
│   └── Providers/    # Service providers
├── bootstrap/        # App bootstrap & cache
├── config/           # Semua file konfigurasi
├── database/         # Migrations, seeders, factories
├── public/           # Entry point (index.php) & assets
├── resources/        # Views (Blade), CSS, JS (uncompiled)
├── routes/           # File routing (web, api, console, channels)
├── storage/          # Logs, cache, session, compiled views
├── tests/            # Unit & Feature tests
├── vendor/           # Dependency (Composer)
├── .env              # Environment configuration
├── artisan           # Artisan CLI entry
└── composer.json     # Dependency manifest
```

## Contoh Kode
```php
// Lokasi file-file penting:
// Controller: app/Http/Controllers/
// Model: app/Models/
// Migration: database/migrations/
// View: resources/views/
// Route: routes/web.php
// Test: tests/Feature/
```

## Kasus Penggunaan Nyata
Developer baru di tim Laravel langsung paham harus mencari apa di mana — controller di `app/Http/Controllers`, view di `resources/views`, tanpa perlu bertanya.
