# 12. Instal Laravel Installer via Composer

## Definisi Singkat
Laravel Installer adalah package global Composer untuk membuat project Laravel baru dengan cepat via perintah `laravel new`.

## Analogi
Seperti template dokumen siap pakai — satu klik dapat project Laravel baru tanpa perlu mengingat URL atau versi spesifik.

## Poin-Poin Penting
- Instal global: `composer global require laravel/installer`
- Pastikan `~/.composer/vendor/bin` ada di PATH sistem
- Buat project baru: `laravel new project-name`
- Installer interaktif: pilih stack (Livewire, Inertia, API), database, dll
- Berbeda dengan `composer create-project` yang langsung download tanpa tanya
- Installer mendukung: starter kit (Jetstream/Breeze), testing framework (Pest/PHPUnit), dark mode
- Untuk Windows: PATH setting via System Environment Variables
- Laravel Installer versi 5+ mendukung `laravel new` dengan prompt interaktif

## Contoh Kode
```bash
# Instal Laravel Installer
composer global require laravel/installer

# Buat project baru (interaktif)
laravel new my-app

# Buat project non-interaktif (Laravel 11 dengan Breeze)
laravel new my-app --breeze --stack=livewire --database=mysql --dark --pest

# Cek versi installer
laravel --version
```

## Kasus Penggunaan Nyata
Developer ingin memulai project e-commerce. Cukup `laravel new toko-online`, pilih stack yang diinginkan, dan project siap dalam 30 detik.
