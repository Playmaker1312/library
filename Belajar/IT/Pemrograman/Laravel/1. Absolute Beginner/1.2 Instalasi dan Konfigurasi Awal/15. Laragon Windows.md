# 15. Laragon (Windows)

## Definisi Singkat
Laragon adalah environment development terintegrasi untuk Windows yang menyediakan Apache/Nginx, PHP, MySQL/MariaDB, dan Redis dalam paket portable.

## Analogi
Laragon seperti dapur modular — Anda bisa menyalakan/mematikan kompor (Apache), keran air (MySQL), dan kulkas (Redis) secara independen.

## Poin-Poin Penting
- Ringan (~5MB installer) dan portable — bisa dijalankan dari USB
- Mendukung PHP 5.6 hingga 8.3 — switch versi dengan dropdown
- Fitur "Quick Create" — satu klik buat project Laravel baru (via Composer)
- Termasuk: Apache/Nginx, MySQL/MariaDB, PostgreSQL, Redis, Memcached, Mailpit
- Auto virtual hosts: `projectname.test` otomatis aktif
- Auto SSL via `Laragon > Auto Virtual Hosts > Enable SSL`
- Database GUI: HeidiSQL sudah terintegrasi
- Nginx juga tersedia (bisa switch dari Apache ke Nginx)
- Fitur "Add PHP" untuk menambah versi PHP secara dinamis
- Laragon > Menu > WWW folder adalah root default project
- Cocok untuk Windows 10/11 (64-bit)

## Contoh Kode
```bash
# Install Laragon dari laragon.org
# Letakkan project di C:\laragon\www\

# Buka Laragon -> Start All
# Akses http://my-app.test (otomatis)

# Atau via terminal di Laragon:
cd C:\laragon\www
composer create-project laravel/laravel my-app
```

## Kasus Penggunaan Nyata
Developer Windows menginstal Laragon, klik "Start All", buat project Laravel di folder www, dan langsung bisa ngoding tanpa setup XAMPP rumit.
