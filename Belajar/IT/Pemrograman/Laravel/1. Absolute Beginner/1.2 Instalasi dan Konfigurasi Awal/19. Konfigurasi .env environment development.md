# 19. Konfigurasi .env environment development

## Definisi Singkat
File `.env` adalah pusat konfigurasi environment Laravel yang menyimpan credential database, API key, dan pengaturan spesifik lingkungan.

## Analogi
Seperti formulir identitas — di development Anda mengisi "nama saya adalah development server", di production "nama saya adalah live server". Semua pengaturan berbeda per situasi.

## Poin-Poin Penting
- File `.env` tidak boleh masuk Git (tercantum di `.gitignore`)
- Template file: `.env.example` — duplikasi untuk memulai project baru
- Variabel environment diakses via `env()` helper atau `$_ENV`
- Mode environment diatur oleh `APP_ENV=local` (development)
- Debug mode: `APP_DEBUG=true` di development, `false` di production
- Laravel 11: `.env` untuk development; buat `.env.production` untuk production
- Jangan commit `.env` ke repository publik — resiko keamanan serius
- Gunakan `php artisan config:cache` untuk mempercepat loading konfigurasi

## Contoh Kode
```php
// File .env (development)
APP_NAME=Laravel
APP_ENV=local
APP_DEBUG=true
APP_URL=http://localhost:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=my_app
DB_USERNAME=root
DB_PASSWORD=

// Mengakses variabel environment
$database = env('DB_DATABASE', 'default_db');
$appName = config('app.name'); // direkomendasikan — pakai cache
```

## Kasus Penggunaan Nyata
Dua developer mengerjakan project sama: masing-masing punya `.env` sendiri dengan database lokal berbeda, tanpa saling mengganggu konfigurasi.
