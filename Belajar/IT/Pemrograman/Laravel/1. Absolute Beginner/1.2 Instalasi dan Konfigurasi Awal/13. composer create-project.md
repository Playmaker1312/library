# 13. composer create-project

## Definisi Singkat
Perintah Composer untuk membuat project baru dari package Laravel — alternatif dari Laravel Installer, langsung mendownload framework tanpa interaksi.

## Analogi
Seperti membeli rumah baru dari developer — Anda langsung dapat kunci (file) tanpa perlu survei lokasi (pilih stack) terlebih dahulu.

## Poin-Poin Penting
- Sintaks: `composer create-project laravel/laravel nama-project`
- Secara otomatis menjalankan `composer install` setelah download
- Membuat direktori project dan menginisialisasi `.env`
- Opsi `--prefer-dist` (default) untuk versi stabil
- Tidak interaktif — langsung jadi tanpa prompt
- Bisa tentukan versi: `composer create-project laravel/laravel:^11.0 my-app`
- Setelah selesai, jalankan `php artisan key:generate` jika belum tergenerate
- Berbeda dengan Installer: tidak ada pilihan stack, database, atau testing framework

## Contoh Kode
```bash
# Buat project Laravel 11 terbaru
composer create-project laravel/laravel my-app

# Buat project dengan versi spesifik
composer create-project laravel/laravel:^10.0 my-app

# Buat project tanpa interaksi
composer create-project laravel/laravel my-app --no-interaction

# Setelah project selesai, masuk ke direktori
cd my-app
php artisan serve
```

## Kasus Penggunaan Nyata
Tim DevOps ingin membuat project Laravel dengan versi spesifik (LTS) tanpa interaksi manual: `composer create-project laravel/laravel:^11.0 project --no-interaction`.
