# 18. Kegunaan folder: app, bootstrap, config, database, public, resources, routes, storage, tests

## Definisi Singkat
Setiap folder dalam Laravel memiliki tanggung jawab spesifik — memahami fungsi masing-masing adalah fondasi navigasi proyek.

## Analogi
Seperti peta kota: setiap distrik (folder) memiliki fungsi yang jelas — pusat bisnis (app), jalan tol (routes), gudang (storage), dan taman (resources).

## Poin-Poin Penting
| Folder      | Fungsi                                                                 |
|-------------|------------------------------------------------------------------------|
| **app**     | Kode bisnis utama: Models, Controllers, Middleware, Providers, Commands|
| **bootstrap** | File inisialisasi framework (`app.php`) dan cache routing              |
| **config**  | File konfigurasi aplikasi (`app.php`, `database.php`, `mail.php`, dll) |
| **database** | Migrations (struktur tabel), Seeders (data dummy), Factories           |
| **public**  | Entry point web (`index.php`), asset publik (CSS, JS, gambar)          |
| **resources** | Views Blade, raw CSS/JS/SCSS sebelum di-build (Vite/Mix)              |
| **routes**  | Definisi route: `web.php`, `api.php`, `console.php`, `channels.php`   |
| **storage** | File sementara: logs (`storage/logs`), session, cache, compiled views  |
| **tests**   | Unit test (`tests/Unit/`) dan feature test (`tests/Feature/`)          |
| **vendor**  | Dependency pihak ketiga (Composer) — jangan diedit manual              |

## Contoh Kode
```php
// Akses path folder dari kode
$logPath = storage_path('logs');
$viewPath = resource_path('views');
$configPath = config_path('app.php');
$publicPath = public_path('uploads');
```

## Kasus Penggunaan Nyata
Saat ingin menambahkan halaman profil: buat Route di `routes/web.php`, Controller di `app/Http/Controllers`, View di `resources/views/profile`, dan migration baru di `database/migrations`.
