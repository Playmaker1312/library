# 3. Keunggulan Laravel dibanding framework PHP lain

## Definisi Singkat
Laravel unggul dalam ekosistem lengkap, dokumentasi berkualitas, sintaks modern, dan komunitas terbesar di ekosistem PHP.

## Analogi
Framework PHP lain seperti peralatan pertukangan terpisah — Anda beli palu di satu toko, gergaji di toko lain. Laravel adalah satu kotak peralatan lengkap dengan semua yang Anda butuhkan.

## Poin-Poin Penting
- **vs CodeIgniter**: Laravel lebih modern (MVC dengan service container, dependency injection), CI lebih ringan tapi minim fitur built-in
- **vs Symfony**: Laravel dibangun di atas komponen Symfony — Laravel lebih ramah pemula, Symfony lebih fleksibel & enterprise
- **vs Yii**: Yii performa tinggi tapi kurva belajar curam; Laravel lebih produktif
- **vs CakePHP**: CakePHP pionir convention over config; Laravel mengadopsi dengan eksekusi lebih baik
- **vs Slim/Fat-Free**: Micro-framework cocok API kecil; Laravel untuk aplikasi skala besar
- Fitur unggulan Laravel: Eloquent ORM, Blade templating, Artisan CLI, ekosistem Forge/Vapor/Sail

## Contoh Kode
```php
// Fitur yang tidak dimiliki framework lain secara built-in:
// 1. Queue system dengan job classes
php artisan make:job SendWelcomeEmail

// 2. Event broadcasting realtime
use App\Events\OrderShipped;

// 3. Task scheduling (cron replacement)
// app/Console/Kernel.php
protected function schedule(Schedule $schedule) {
    $schedule->command('report:daily')->dailyAt('23:00');
}
```

## Kasus Penggunaan Nyata
Startup yang ingin cepat rilis MVP memilih Laravel karena autentikasi, notifikasi, dan queue sudah siap pakai tanpa setup tambahan.
