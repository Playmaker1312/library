# 5. Versi Laravel dan kebijakan LTS

## Definisi Singkat
Laravel dirilis dengan siklus tahunan (satu versi mayor per tahun); LTS memberikan dukungan bug fix 2 tahun dan security fix 3 tahun.

## Analogi
LTS seperti mobil yang masih dapat suku cadang resmi hingga 3 tahun — aman untuk proyek jangka panjang.

## Poin-Poin Penting
- Kebijakan rilis: 1 major version per tahun (biasanya Januari/Februari)
- Laravel 6 (2019): LTS pertama dengan semver; support bug 2th + security 3th
- Laravel 8 (2020): non-LTS meskipun signifikan
- Laravel 9 (2022): Symfony 6, PHP 8+, support hingga 2024
- Laravel 10 (2023): PHP 8.1+, native types di skeleton, support 1 tahun
- Laravel 11 (2024): LTS — support bug hingga 2026, security hingga 2027
- Versi PHP minimum: Laravel 11 membutuhkan PHP 8.2+
- Semua versi non-LTS mendapat bug fix 18 bulan, security fix 2 tahun
- Gunakan versi LTS untuk proyek enterprise/produksi jangka panjang

## Kasus Penggunaan Nyata
Perusahaan fintech memilih Laravel 11 LTS untuk aplikasi core mereka karena jaminan security fix hingga 2027.
