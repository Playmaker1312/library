# 6. Komunitas Laravel: Laracasts, Laravel News

## Definisi Singkat
Komunitas Laravel adalah salah satu yang paling aktif di dunia PHP, dengan forum diskusi, video tutorial, newsletter, dan event tahunan.

## Analogi
Seperti ekosistem taman kota — banyak jalur belajar (Laracasts), papan pengumuman (Laravel News), dan tempat berkumpul (Laracon).

## Poin-Poin Penting
- **Laracasts** (laracasts.com): Platform video tutorial oleh Jeffrey Way — 1000+ episode dari basic hingga advanced
- **Laravel News** (laravel-news.com): Portal berita harian — tutorial, package terbaru, update framework
- **Laracon**: Konferensi tahunan (US, EU, Australia) — slide, live coding, networking
- **Laravel.io**: Forum komunitas — diskusi, Q&A, showcase proyek
- **Discord Laravel**: Chat real-time — channel per topik (#general, #eloquent, #jobs)
- **GitHub**: Laravel framework memiliki 70.000+ stars, kontribusi terbuka untuk semua
- **Laravel Shift**: Layanan upgrade otomatis versi Laravel
- **Laravel Daily** (YouTube): Tutorial singkat oleh Povilas Korop

## Contoh Kode
```php
// Tidak ada kode — ini tentang sumber belajar
// Tips: berlangganan Laracasts untuk belajar sistematis
// Baca Laravel News setiap pagi
// Aktif di Discord Laravel channel #general
```

## Kasus Penggunaan Nyata
Developer junior ingin belajar Laravel dari nol: mulai dari Laracasts "Laravel From Scratch" series, kemudian bergabung Discord untuk tanya jawab saat stuck.
