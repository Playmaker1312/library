# 2. Filosofi Laravel: Elegant Syntax & Developer Happiness

## Definisi Singkat
Laravel mengutamakan sintaks yang ekspresif, bersih, dan intuitif agar developer dapat menulis kode yang indah sekaligus fungsional. Prinsip utamanya: "Developer happiness matters."

## Analogi
Seperti dapur yang tertata rapi dengan label dan peralatan yang mudah dijangkau — Laravel membuat Anda fokus memasak (coding), bukan mencari alat.

## Poin-Poin Penting
- Mengikuti prinsip konvensi di atas konfigurasi (*convention over configuration*)
- Sintaks *fluent*: method chaining yang mudah dibaca (Eloquent, Query Builder)
- Menghindari boilerplate — fitur routing, ORM, autentikasi sudah built-in
- Makin baru versi Laravel, makin sedikit kode yang perlu ditulis (Laravel 11 menghapus banyak file default)
- Integrasi dengan modern PHP: type hints, attributes, method overriding yang jelas
- Clean Code: Express yourself in code, not in comments

## Contoh Kode
```php
// Eloquent ORM — sintaks yang sangat ekspresif
$activeUsers = User::where('status', 'active')
    ->where('last_login', '>=', now()->subDays(7))
    ->orderBy('name')
    ->get();

// Route — deklaratif seperti bahasa inggris
Route::get('/users', [UserController::class, 'index']);
Route::post('/users', [UserController::class, 'store']);
```

## Kasus Penggunaan Nyata
Developer yang terbiasa menulis kode prosedural PHP beralih ke Laravel dan merasakan produktivitas naik drastis karena routing, query builder, dan templating Blade sangat intuitif.
