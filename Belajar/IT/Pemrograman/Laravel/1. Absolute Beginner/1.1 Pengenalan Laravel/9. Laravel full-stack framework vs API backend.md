# 9. Laravel: Full-Stack Framework vs API Backend

## Definisi Singkat
Laravel dapat digunakan sebagai full-stack framework (Blade/Livewire/Inertia untuk frontend) atau sebagai API backend murni (JSON/REST/GraphQL).

## Analogi
Full-stack seperti restoran lengkap dengan dapur dan ruang makan. API backend seperti dapur catering — hanya menyiapkan makanan (data) untuk dikirim ke restoran lain (frontend).

## Poin-Poin Penting
**Full-Stack:**
- Menggunakan Blade (templating server-side)
- Livewire: komponen interaktif tanpa JavaScript
- Inertia: menggunakan Vue/React tanpa perlu SPA API terpisah
- Semua dalam satu project

**API Backend:**
- Return JSON response via `return response()->json([...])`
- Autentikasi dengan Sanctum (token) atau Passport (OAuth2)
- Stateless — tidak ada session server
- Sering dipasangkan dengan Nuxt, Next.js, React Native, Flutter
- Bisa juga untuk microservices

**Laravel 11:**
- `php artisan install:api` untuk install API scaffolding
- `php artisan install:api --api` untuk API-only app

## Contoh Kode
```php
// Full-stack: route + blade
Route::get('/dashboard', function () {
    return view('dashboard');
})->middleware('auth');

// API: route + JSON response
Route::get('/api/users', function () {
    return response()->json(User::all());
})->middleware('auth:sanctum');
```

## Kasus Penggunaan Nyata
Aplikasi toko online: backend Laravel API dipasangkan dengan mobile app Flutter (API) dan dashboard admin menggunakan Blade + Livewire (full-stack).
