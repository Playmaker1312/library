# 1. Apa itu Laravel dan sejarahnya

## Definisi Singkat
Laravel adalah framework web PHP open-source berbasis MVC yang dirilis tahun 2011 oleh Taylor Otwell. Versi stabil saat ini adalah Laravel 11.x (2024) dengan dukungan LTS.

## Analogi
Laravel seperti cetakan kue profesional — Anda tinggal menuang adonan (logika bisnis) ke cetakan yang sudah tersedia, tanpa perlu membuat cetakan dari nol.

## Poin-Poin Penting
- Rilis pertama: Juni 2011 (Laravel 1)
- Laravel 3 (2012): menambahkan Artisan CLI, migrasi database, dan sistem packaging
- Laravel 4 (2013): rewrite total dengan Composer, pendekatan modular
- Laravel 5 (2015): struktur direktori baru, folder `resources`, Elixir
- Laravel 6 (2019): LTS pertama dengan semver (X.Y.Z)
- Laravel 7 (2020): Laravel Sanctum, custom eloquent casts
- Laravel 8 (2020): Laravel Jetstream, model factories class-based, migration squashing
- Laravel 9 (2022): Symfony 6, PHP 8+, Flysystem 3.x, Laravel Scout improvements
- Laravel 10 (2023): PHP 8.1 minimum, native type declarations, skeleton simplification
- Laravel 11 (2024): struktur minimalis, hapus banyak file skeleton, default SQLite
- Menggunakan Composer untuk dependency management
- Berlisensi MIT

## Contoh Kode
```php
// Cek versi Laravel via Artisan
// php artisan --version

// Atau dari kode PHP
$laravelVersion = app()->version();
echo "Laravel version: $laravelVersion";
```

## Kasus Penggunaan Nyata
Tim pengembang ingin memilih framework standar untuk perusahaan. Mereka memilih Laravel karena ekosistemnya matang, dokumentasi lengkap, dan komunitas besar.
