# 4. Ekosistem Laravel: Forge, Vapor, Nova, Cashier, Sanctum, Passport

## Definisi Singkat
Laravel memiliki ekosistem alat resmi yang mencakup deployment, hosting serverless, panel admin, pembayaran, dan autentikasi API.

## Analogi
Ekosistem Laravel seperti App Store — Anda tidak perlu menginstal dan mengkonfigurasi semuanya manual; cukup "pasang" layanan yang dibutuhkan.

## Poin-Poin Penting
- **Laravel Forge**: Manajemen server (DigitalOcean, AWS, Linode) — provisioning, deployment, SSL, cron
- **Laravel Vapor**: Deployment serverless ke AWS Lambda — bayar per eksekusi
- **Laravel Nova**: Panel admin premium ($199 per site) — CRUD generator dengan UI elegan
- **Laravel Cashier**: Manajemen subscription (Stripe / Paddle) — trial, invoice, cancellations
- **Laravel Sanctum**: Autentikasi API ringan untuk SPA dan token sederhana (gratis, built-in di Laravel)
- **Laravel Passport**: OAuth2 server untuk API — cocok untuk third-party client
- **Laravel Jetstream**: Starter kit dengan Livewire atau Inertia + team management
- **Laravel Horizon**: Dashboard untuk monitoring queue Redis
- **Laravel Telescope**: Debug assistant — request, exceptions, queries, logs

## Contoh Kode
```php
// Sanctum — autentikasi API token sederhana
use Illuminate\Http\Request;

Route::post('/login', function (Request $request) {
    $user = User::where('email', $request->email)->first();

    return $user->createToken('api-token')->plainTextToken;
});

// Cashier — subscription Stripe
$user->newSubscription('default', 'price_basic_monthly')
     ->create($paymentMethod);
```

## Kasus Penggunaan Nyata
Aplikasi SaaS e-commerce menggunakan Forge untuk deployment ke DO, Nova untuk admin panel, Cashier untuk billing Stripe, dan Sanctum untuk mobile API.
