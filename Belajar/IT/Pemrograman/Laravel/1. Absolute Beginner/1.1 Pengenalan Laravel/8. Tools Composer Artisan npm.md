# 8. Tools: Composer, Artisan, npm

## Definisi Singkat
Composer mengelola dependency PHP, Artisan adalah CLI bawaan Laravel untuk scaffolding & task, npm menangani asset frontend.

## Analogi
Seperti workstation tukang kayu: Composer adalah lemari penyimpanan bahan baku, Artisan adalah gergaji mesin, npm adalah kotak alat finishing.

## Poin-Poin Penting
- **Composer**: Dependency manager PHP — `composer install`, `composer require package/name`
- **Artisan**: CLI Laravel — `php artisan make:controller`, `php artisan migrate`, `php artisan serve`
- **npm**: Node package manager — mengelola asset frontend (Tailwind, Vue, React, Bootstrap)
- Semua Laravel project butuh Composer; npm hanya perlu jika menggunakan frontend build tools
- Laravel 11 sudah menyertakan Vite sebagai bundler default (via package.json)
- Composer 2.x lebih cepat dan aman dari 1.x
- `composer global require laravel/installer` untuk menginstal Laravel Installer

## Contoh Kode
```bash
# Composer — instal dependency
composer create-project laravel/laravel my-app
composer require laravel/sanctum

# Artisan — command harian
php artisan serve
php artisan make:model Product -m
php artisan route:list

# npm — asset frontend
npm install
npm run build
```

## Kasus Penggunaan Nyata
Developer memulai project Laravel: `composer create-project`, lalu `npm install && npm run dev` untuk Tailwind, dan `php artisan serve` untuk development.
