# 36. php artisan make:migration

## Definisi Singkat
Perintah untuk membuat file migration — class PHP yang mendefinisikan perubahan struktur database (tabel, kolom, index) secara versioned.

## Analogi
Seperti catatan perubahan (changelog) untuk database — setiap perubahan dicatat, bisa dimajukan (migrate) atau dimundurkan (rollback).

## Poin-Poin Penting
- Perintah: `php artisan make:migration create_nama_tabel_table`
- Convention nama:
  - `create_xxx_table` → otomatis method `up()` berisi `Schema::create()`
  - `add_xxx_to_yyy_table` → Schema::table()
  - `update_xxx_table` → Schema::table()
- File disimpan di `database/migrations/` dengan timestamp prefix
- Method `up()`: perubahan yang dilakukan
- Method `down()`: kebalikan (rollback)
- Gunakan `--table=xxx` jika ingin menambah kolom ke tabel yang sudah ada
- Gunakan `--path=` untuk direktori kustom

## Contoh Kode
```bash
# Migration create table
php artisan make:migration create_products_table

# Migration modify existing table
php artisan make:migration add_price_to_products_table --table=products

# Migration dengan path kustom
php artisan make:migration create_logs_table --path=database/migrations/admin
```

```php
// create_products_table.php
public function up(): void
{
    Schema::create('products', function (Blueprint $table) {
        $table->id();
        $table->string('name');
        $table->decimal('price', 12, 2);
        $table->integer('stock')->default(0);
        $table->timestamps();
    });
}

public function down(): void
{
    Schema::dropIfExists('products');
}
```

## Kasus Penggunaan Nyata
Aplikasi perlu kolom `phone` di tabel `users`. Developer jalankan `php artisan make:migration add_phone_to_users_table --table=users`, tulis schema, lalu `php artisan migrate`.
