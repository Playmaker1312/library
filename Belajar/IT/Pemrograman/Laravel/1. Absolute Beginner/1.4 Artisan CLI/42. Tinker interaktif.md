# 42. Tinker interaktif

## Definisi Singkat
Tinker adalah REPL (Read-Eval-Print Loop) interaktif untuk Laravel berbasis PsySH — memungkinkan interaksi langsung dengan aplikasi dari command line.

## Analogi
Seperti playground uji coba — Anda bisa mencoba fungsi, query database, atau testing code snippet tanpa harus menulis file atau membuka browser.

## Poin-Poin Penting
- Perintah: `php artisan tinker`
- Bisa jalankan kode PHP apa pun dalam konteks aplikasi Laravel
- Berguna untuk:
  - Testing query: `User::where('email', 'like', '%@gmail.com')->count()`
  - Debugging: `dd(config('app.name'))`
  - Manipulasi data: `User::find(1)->update(['name' => 'Baru'])`
  - Generate data: `User::factory()->create()`
  - Cek helper: `str('hello')->upper()`
- Mendukung autocomplete (tekan Tab)
- `ls` — lihat properti/variable
- `show` — lihat source code class/method
- `dump` — dump variable
- `exit` atau `Ctrl+C` untuk keluar

## Contoh Kode
```bash
php artisan tinker
```

```php
# Di dalam Tinker

# Hitung user
> User::count();
=> 15

# Cari user dan tampilkan email
> User::first()->email;
=> "admin@example.com"

# Buat data baru
> Product::create(['name' => 'Test', 'price' => 5000]);
=> App\Models\Product {#...}

# Test helper Laravel
> str('halo dunia')->title();
=> "Halo Dunia"

> now()->addDays(7)->format('d F Y');
=> "04 Juni 2026"

# Lihat source code
> show User::class
```

## Kasus Penggunaan Nyata
Developer ingin cek apakah user dengan email tertentu ada: `php artisan tinker`, ketik `User::where('email', 'test@test.com')->exists()`, langsung dapat jawaban tanpa buat route.
