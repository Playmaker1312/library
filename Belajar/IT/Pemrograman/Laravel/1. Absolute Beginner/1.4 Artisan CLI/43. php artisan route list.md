# 43. php artisan route:list

## Definisi Singkat
Perintah untuk menampilkan daftar semua route yang terdaftar, lengkap dengan method, URI, nama, controller action, dan middleware.

## Analgi
Seperti peta jalur bus — Anda bisa melihat semua rute (endpoint), halte (URI), dan aturan (middleware) yang dilalui.

## Poin-Poin Penting
- Perintah: `php artisan route:list`
- Kolom: `Domain`, `Method`, `URI`, `Name`, `Action`, `Middleware`
- Opsi filter:
  - `--path=users` — hanya route yang path-nya mengandung "users"
  - `--method=GET` — hanya route GET
  - `--name=admin.` — hanya route dengan prefix name "admin"
  - `--except-path` — exclude path tertentu
- `--json` — output JSON (berguna untuk tooling)
- `--reverse` — urutan terbalik
- `--sort=uri` — urutkan berdasarkan URI
- Route yang tidak bisa diakses (verified) juga muncul

## Contoh Kode
```bash
# Lihat semua route
php artisan route:list

# Filter route yang mengandung 'product'
php artisan route:list --path=product

# Hanya route GET
php artisan route:list --method=GET

# Route dengan prefix name 'admin.'
php artisan route:list --name=admin.

# Output JSON
php artisan route:list --json

# Output potongan:
# GET|HEAD  products              products.index     ProductController@index
# POST      products              products.store     ProductController@store
# GET|HEAD  products/{product}    products.show      ProductController@show
```

## Kasus Penggunaan Nyata
Developer menambah route baru tapi lupa nama route untuk redirect. `php artisan route:list | Select-String "product"` langsung menampilkan semua route produk dengan nama dan URI.
