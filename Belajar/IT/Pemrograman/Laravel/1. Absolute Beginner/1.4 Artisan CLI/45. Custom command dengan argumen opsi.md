# 45. Custom command dengan argumen dan opsi

## Definisi Singkat
Custom Artisan command dapat menerima argumen (input posisional) dan opsi (input flag) untuk fleksibilitas eksekusi tugas.

## Analogi
Seperti memesan kopi: argumen = jenis kopi (wajib), opsi = gula/susu (pilihan). `php artisan kopi:buat espresso --gula --susu=fullcream`

## Poin-Poin Penting
- **Argumen**: input posisional, bisa wajib atau opsional
  - `{nama}` — wajib
  - `{nama?}` — opsional
  - `{nama*}` — array (banyak nilai)
  - `{nama=default}` — dengan default value
- **Opsi**: input dengan prefix `--`, bisa tanpa nilai (boolean)
  - `{--force}` — boolean (true/false)
  - `{--queue=}` — dengan nilai
  - `{--Q|queue}` — alias pendek
- Akses di `handle()`:
  - `$this->argument('name')` — argumen
  - `$this->option('name')` — opsi
  - `$this->arguments()` — semua argumen
  - `$this->options()` — semua opsi

## Contoh Kode
```bash
php artisan make:command ImportData
```

```php
// app/Console/Commands/ImportData.php
class ImportData extends Command
{
    protected $signature = 'import:data
                          {type : Tipe data yang diimport (users/products)}
                          {files* : File yang akan diimport}
                          {--dry-run : Simulasi tanpa eksekusi}
                          {--batch=100 : Jumlah per batch}
                          {--Q|queue : Proses via queue}';

    protected $description = 'Import data dari file CSV/Excel';

    public function handle(): void
    {
        $type = $this->argument('type');
        $files = $this->argument('files');
        $batch = (int) $this->option('batch');
        $isDryRun = $this->option('dry-run');
        $useQueue = $this->option('queue');

        $this->info("Mengimport {$type} dari " . count($files) . " file");

        foreach ($files as $file) {
            $this->line("Memproses: {$file}");
        }

        if ($isDryRun) {
            $this->warn('Dry-run mode — tidak ada data tersimpan');
        }
    }
}

// Penggunaan:
// php artisan import:data users file1.csv file2.csv
// php artisan import:data products file.csv --dry-run
// php artisan import:data products file.csv --queue --batch=500
```

## Kasus Penggunaan Nyata
Staff admin mengimpor data produk dari 3 file Excel: `php artisan import:data products produk1.xlsx produk2.xlsx produk3.xlsx --batch=200`.
