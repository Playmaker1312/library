# 32. php artisan list

## Definisi Singkat
Perintah untuk menampilkan daftar semua perintah Artisan yang tersedia, termasuk dari package pihak ketiga dan kustom.

## Analogi
Seperti melihat menu restoran — Anda bisa melihat semua hidangan (command) yang bisa dipesan, lengkap dengan deskripsi singkatnya.

## Poin-Poin Penting
- Perintah: `php artisan list` — tampilkan semua command
- Ditampilkan dalam grup: `make`, `migrate`, `route`, `cache`, dll
- Gunakan `--format=json` untuk output terstruktur (berguna untuk tooling)
- Gunakan `--raw` untuk daftar tanpa tabel (lebih ringkas)
- Pipe ke `Select-String` (PowerShell) atau `grep` (Linux/Mac) untuk filter
- Command kustom muncul di grup `Custom`
- Command dari package muncul sesuai registrasi masing-masing
- Alternatif: `php artisan` (tanpa argumen) — sama dengan `list`

## Contoh Kode
```bash
# Lihat semua command
php artisan list

# Output (contoh potongan):
#   make
#     make:command      Create a new Artisan command
#     make:controller   Create a new controller class
#     make:model        Create a new Eloquent model class
#
#   migrate
#     migrate           Run the database migrations
#     migrate:fresh     Drop all tables and re-run all migrations
#     migrate:rollback  Rollback the last database migration

# Format JSON (berguna untuk script)
php artisan list --format=json

# Cari command spesifik
php artisan list | Select-String "route"
php artisan list | Select-String "make:"
```

## Kasus Penggunaan Nyata
Developer ingin tahu command apa yang tersedia untuk `make`: ketik `php artisan list | Select-String "make:"` dan langsung melihat semua opsi scaffolding.
