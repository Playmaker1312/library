# 40. php artisan make:request

## Definisi Singkat
Perintah untuk membuat Form Request — class validasi kustom yang memisahkan logika validasi dari controller, menjaga kode tetap bersih dan terorganisir.

## Analogi
Seperti formulir pendaftaran dengan petugas verifikasi — request memeriksa apakah semua data valid (format, required, unique) sebelum diproses lebih lanjut.

## Poin-Poin Penting
- Perintah: `php artisan make:request StoreProductRequest`
- File disimpan di `app/Http/Requests/`
- Method `authorize()`: cek izin user (return `true` atau gate check)
- Method `rules()`: array aturan validasi
- Method `messages()`: kustom pesan error (opsional)
- Method `failedValidation()`: kustom response validasi gagal (opsional)
- Inject ke controller method: `public function store(StoreProductRequest $request)`
- Validasi otomatis dieksekusi sebelum controller dipanggil
- Best practice: buat per request (Store, Update) agar aturan bisa berbeda

## Contoh Kode
```bash
php artisan make:request StoreProductRequest
php artisan make:request UpdateProductRequest
```

```php
// app/Http/Requests/StoreProductRequest.php
class StoreProductRequest extends FormRequest
{
    public function authorize(): bool
    {
        return $this->user()->can('create', Product::class);
    }

    public function rules(): array
    {
        return [
            'name' => 'required|string|max:255|unique:products',
            'price' => 'required|numeric|min:0',
            'stock' => 'required|integer|min:0',
            'category_id' => 'required|exists:categories,id',
        ];
    }

    public function messages(): array
    {
        return [
            'name.required' => 'Nama produk wajib diisi.',
            'price.min' => 'Harga tidak boleh negatif.',
        ];
    }
}
```

## Kasus Penggunaan Nyata
Form input produk memvalidasi nama unik, harga minimal 0, dan kategori harus ada di database. Jika validasi gagal, user langsung dikembalikan ke form dengan error.
