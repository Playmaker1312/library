# 41. php artisan make:command

## Definisi Singkat
Perintah untuk membuat Artisan command kustom — class yang menjalankan task spesifik via CLI, misalnya membersihkan log lama atau mengirim email.

## Analogi
Seperti membuat tombol pintas baru di dashboard mobil — Anda bisa menambah fungsi "kirim laporan harian" yang dijalankan dengan sekali tekan (satu perintah).

## Poin-Poin Penting
- Perintah: `php artisan make:command NamaCommand`
- File disimpan di `app/Console/Commands/`
- Property `$signature`: nama command + argumen/opsi
- Property `$description`: deskripsi untuk `php artisan list`
- Method `handle()`: logika utama command
- Argumen: `{name}` (wajib), `{name?}` (opsional)
- Opsi: `{--force}`, `{--queue=default}`
- Array: `{names*}` — bisa menerima banyak nilai
- Registrasi otomatis — tidak perlu daftar manual
- Dapat dijadwalkan di `app/Console/Kernel.php`

## Contoh Kode
```bash
php artisan make:command SendDailyReport
```

```php
// app/Console/Commands/SendDailyReport.php
class SendDailyReport extends Command
{
    protected $signature = 'report:daily
                          {--email= : Email tujuan laporan}
                          {--force : Kirim tanpa konfirmasi}';

    protected $description = 'Mengirim laporan penjualan harian';

    public function handle(): void
    {
        $email = $this->option('email') ?? config('mail.admin');
        $force = $this->option('force');

        if (! $force && ! $this->confirm('Kirim laporan ke ' . $email . '?')) {
            $this->info('Dibatalkan.');
            return;
        }

        // Logika kirim email...
        $this->info("Laporan berhasil dikirim ke {$email}");
    }
}

// Jalankan:
// php artisan report:daily --email=admin@example.com
// php artisan report:daily --force
```

## Kasus Penggunaan Nyata
Setiap jam 23:00, server menjalankan `php artisan report:daily --email=owner@toko.com` via scheduler untuk mengirim laporan penjualan hari itu.
