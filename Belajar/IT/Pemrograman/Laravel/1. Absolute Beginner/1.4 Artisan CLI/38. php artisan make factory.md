# 38. php artisan make:factory

## Definisi Singkat
Perintah untuk membuat Factory — class yang mendefinisikan template data dummy untuk Eloquent Model, biasanya digunakan dengan Seeder.

## Analogi
Seperti mesin pencetak kartu nama — Anda cukup menentukan template (nama, jabatan, perusahaan) dan mesin menghasilkan banyak kartu dengan variasi data.

## Poin-Poin Penting
- Perintah: `php artisan make:factory ProductFactory`
- File disimpan di `database/factories/`
- Sejak Laravel 8: factory berbasis class (bukan function)
- Model factory otomatis dibuat jika gunakan `php artisan make:model Product -f`
- Method `definition()` mengembalikan array data default
- Gunakan Faker (`$this->faker`) untuk data acak realistis
- Panggil di seeder: `Product::factory(20)->create()`
- State: method kustom untuk variasi data (`Product::factory()->outOfStock()->create()`)

## Contoh Kode
```bash
php artisan make:factory ProductFactory --model=Product
```

```php
// database/factories/ProductFactory.php
class ProductFactory extends Factory
{
    protected $model = Product::class;

    public function definition(): array
    {
        return [
            'name' => fake()->unique()->words(3, true),
            'price' => fake()->randomFloat(2, 1000, 100000),
            'stock' => fake()->numberBetween(0, 100),
            'is_active' => fake()->boolean(80),
        ];
    }

    // Custom state
    public function outOfStock(): static
    {
        return $this->state(fn (array $attributes) => [
            'stock' => 0,
            'is_active' => false,
        ]);
    }
}

// Penggunaan di seeder
Product::factory(10)->create();
Product::factory(3)->outOfStock()->create();
```

## Kasus Penggunaan Nyata
Developer membuat factory untuk model `Transaction` dengan data transaksi acak (nomor invoice, total, status) untuk menguji fitur laporan keuangan.
