# 39. php artisan make:middleware

## Definisi Singkat
Perintah untuk membuat Middleware — class yang memfilter HTTP request sebelum mencapai controller, misalnya untuk autentikasi atau logging.

## Analogi
Seperti satpam di pintu masuk gedung — middleware memeriksa "tiket" (request) sebelum diizinkan masuk ke ruangan (controller).

## Poin-Poin Penting
- Perintah: `php artisan make:middleware NamaMiddleware`
- File disimpan di `app/Http/Middleware/`
- Method `handle()` menerima request dan closure `$next`
- Logic: return `$next($request)` untuk lanjut, atau response lain untuk blokir
- Daftarkan di `app/Http/Kernel.php` (atau `bootstrap/app.php` di Laravel 11):
  - `$middleware` (global — semua route)
  - `$middlewareAliases` (alias — dipanggil di route)
- Bisa juga middleware dengan parameter: `$next($request, $role)`

## Contoh Kode
```bash
php artisan make:middleware CheckRole
```

```php
// app/Http/Middleware/CheckRole.php
class CheckRole
{
    public function handle(Request $request, Closure $next, string $role): Response
    {
        if (! $request->user() || ! $request->user()->hasRole($role)) {
            abort(403, 'Unauthorized');
        }

        return $next($request);
    }
}

// Registrasi di Laravel 11 (bootstrap/app.php)
->withMiddleware(function (Middleware $middleware) {
    $middleware->alias([
        'role' => CheckRole::class,
    ]);
})

// Penggunaan di route
Route::get('/admin', function () {
    return 'Admin dashboard';
})->middleware('role:admin');
```

## Kasus Penggunaan Nyata
Aplikasi memiliki role Admin dan User. Middleware `CheckRole` dipasang di route admin; jika user tanpa role admin mengakses, mendapat 403 Forbidden.
