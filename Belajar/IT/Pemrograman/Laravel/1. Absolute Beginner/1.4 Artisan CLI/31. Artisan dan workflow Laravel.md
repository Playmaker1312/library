# 31. Artisan dan workflow Laravel

## Definisi Singkat
Artisan adalah command-line interface built-in Laravel yang menyediakan ratusan perintah untuk scaffolding, migrasi, testing, dan manajemen aplikasi.

## Analogi
Seperti pisau Swiss Army — satu alat (artisan) bisa melakukan banyak hal: membuat file, menjalankan migrasi, membersihkan cache, dan banyak lagi.

## Poin-Poin Penting
- Entry point: `php artisan` dari root project (file `artisan`)
- Dibangun di atas Symfony Console component
- Perintah terbagi:
  - **Built-in**: `make:model`, `migrate`, `route:list`, dll
  - **Custom**: buat sendiri dengan `php artisan make:command`
  - **Third-party**: dari package yang diinstall (Sanctum, Horizon, dll)
- Workflow harian developer:
  1. `php artisan serve` — mulai development server
  2. `php artisan make:model Product -m` — buat model + migration
  3. `php artisan migrate` — jalankan migration
  4. `php artisan tinker` — testing interaktif
  5. `php artisan route:list` — cek route
- Scheduling: `php artisan schedule:run` — jalankan task terjadwal

## Contoh Kode
```bash
# Workflow harian developer Laravel

# 1. Mulai server
php artisan serve

# 2. Buat model dengan migration, controller, factory
php artisan make:model Product -mcf

# 3. Jalankan migration
php artisan migrate

# 4. Seed data
php artisan db:seed

# 5. Cek routes
php artisan route:list

# 6. Debug dengan Tinker
php artisan tinker
> User::count();
> Product::where('price', '>', 1000)->get();
```

## Kasus Penggunaan Nyata
Setiap pagi developer menjalankan `php artisan serve`, membuat fitur baru dengan `php artisan make:model Transaction -mc`, mengubah migration, `php artisan migrate:fresh --seed`, dan mengetes endpoint.
