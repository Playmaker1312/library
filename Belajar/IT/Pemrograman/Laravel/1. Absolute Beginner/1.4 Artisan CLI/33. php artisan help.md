# 33. php artisan help

## Definisi Singkat
Perintah untuk menampilkan dokumentasi detail dari perintah Artisan tertentu, termasuk argumen, opsi, dan contoh penggunaan.

## Analogi
Seperti melihat buku petunjuk untuk satu alat spesifik — bukan hanya tahu namanya, tapi juga cara memegang, mengarahkan, dan merawatnya.

## Poin-Poin Penting
- Sintaks: `php artisan help <command-name>`
- Menampilkan: deskripsi, usage, arguments, options
- Argumen wajib ditandai dengan kurung biasa: `{name}`
- Argumen opsional: `{name?}`
- Array argumen: `{name*}`
- Opsi: `--force`, `--seed`, `--queue`, dll
- Hampir semua command memiliki `--help` sebagai alternatif
- Berguna untuk command yang jarang digunakan atau opsi yang tidak diingat

## Contoh Kode
```bash
# Lihat help untuk make:model
php artisan help make:model

# Output:
# Description:
#   Create a new Eloquent model class
#
# Usage:
#   make:model [options] [--] <name>
#
# Arguments:
#   name               The name of the model
#
# Options:
#   -a, --all          Generate a migration, seeder, factory, policy...
#   -c, --controller   Create a new controller for the model
#   -f, --factory      Create a new factory for the model
#   -m, --migration    Create a new migration file for the model
#   -s, --seed         Create a new seeder for the model

# Alternatif
php artisan make:model --help
```

## Kasus Penggunaan Nyata
Developer lupa apakah `migrate:fresh` bisa langsung dengan seed. `php artisan help migrate:fresh` menunjukkan opsi `--seed` yang menyelesaikan masalah.
