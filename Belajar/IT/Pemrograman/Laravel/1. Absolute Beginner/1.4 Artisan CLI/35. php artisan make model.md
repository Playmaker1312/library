# 35. php artisan make:model

## Definisi Singkat
Perintah untuk membuat file Eloquent Model baru di `app/Models/` yang merepresentasikan tabel database.

## Analogi
Seperti mendaftarkan jenis barang baru ke katalog toko — model mendefinisikan bagaimana data berinteraksi dengan database.

## Poin-Poin Penting
- Perintah: `php artisan make:model NamaModel`
- Opsi flag (dapat digabung):
  - `-m` atau `--migration` — buat file migration
  - `-c` atau `--controller` — buat controller
  - `-f` atau `--factory` — buat factory
  - `-s` atau `--seed` — buat seeder
  - `-a` atau `--all` — semua di atas (migration, controller, factory, seeder, policy)
  - `-r` atau `--resource` — resource controller (gabung dengan -c)
  - `-p` atau `--pivot` — buat model pivot (many-to-many)
- Laravel 11: model lebih ramping — tidak ada `$fillable`, `$timestamps` default `true`
- Convention: nama model singular, PascalCase → tabel plural snake_case

## Contoh Kode
```bash
# Model saja
php artisan make:model Product

# Model + migration
php artisan make:model Product -m

# Model + migration + controller + factory + seeder
php artisan make:model Product -mcf

# Model + semua (all)
php artisan make:model Product -a

# Model pivot
php artisan make:model CategoryProduct --pivot
```

```php
// app/Models/Product.php
class Product extends Model
{
    protected $fillable = ['name', 'price', 'stock'];
}
```

## Kasus Penggunaan Nyata
Saat menambah modul produk: `php artisan make:model Product -mcf`. Satu perintah menghasilkan: `Product.php`, migration `create_products_table`, `ProductFactory.php`, dan `ProductController.php`.
