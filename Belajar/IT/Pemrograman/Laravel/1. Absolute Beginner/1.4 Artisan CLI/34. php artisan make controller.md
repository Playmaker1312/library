# 34. php artisan make:controller

## Definisi Singkat
Perintah untuk membuat file controller baru di `app/Http/Controllers/` dengan berbagai opsi seperti resource, API, atau invokable.

## Analogi
Seperti mencetak seragam kerja khusus — Anda dapat memesan seragam dengan berbagai model (resource, API, single action) sesuai tugas karyawan.

## Poin-Poin Penting
- Perintah: `php artisan make:controller NamaController`
- Opsi penting:
  - `--resource` — buat method `index`, `create`, `store`, `show`, `edit`, `update`, `destroy`
  - `--api` — resource tanpa `create` dan `edit` (untuk API)
  - `--invokable` — single action controller (method `__invoke`)
  - `--model=Product` — resource dengan type hinting model
  - `--requests` — buat Form Request classes terpisah
- Controller disimpan di `app/Http/Controllers/`
- Bisa gunakan subfolder: `Admin/UserController`
- Best practice: gunakan singular noun (`UserController`, bukan `UsersController`)

## Contoh Kode
```bash
# Resource controller (CRUD lengkap)
php artisan make:controller ProductController --resource

# Api resource controller
php artisan make:controller Api/V1/ProductController --api

# Single action controller
php artisan make:controller CheckoutController --invokable

# Resource dengan model binding
php artisan make:controller ProductController --resource --model=Product

# Dengan Form Request
php artisan make:controller ProductController --resource --requests
```

```php
// Hasil: ProductController dengan method:
// index(), create(), store(Request), show($id), edit($id), update(Request, $id), destroy($id)
```

## Kasus Penggunaan Nyata
Developer membuat CRUD untuk modul Artikel: `php artisan make:controller ArticleController --resource --model=Article` dan langsung mendapat 7 method siap pakai.
