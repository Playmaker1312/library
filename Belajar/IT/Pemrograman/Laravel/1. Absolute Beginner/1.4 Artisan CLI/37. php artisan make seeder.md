# 37. php artisan make:seeder

## Definisi Singkat
Perintah untuk membuat Seeder — class yang mengisi database dengan data dummy atau data awal (default) untuk development.

## Analogi
Seperti menyemai benih di kebun — Anda menanam data awal (admin user, kategori default) agar aplikasi tidak kosong saat pertama kali diakses.

## Poin-Poin Penting
- Perintah: `php artisan make:seeder NamaSeeder`
- File disimpan di `database/seeders/`
- Method `run()` berisi logika insert data
- Gunakan Eloquent, Query Builder, atau factory di dalam seeder
- Panggil factory: `User::factory(10)->create()`
- Registrasi di `database/seeders/DatabaseSeeder.php` → method `run()`
- Jalankan: `php artisan db:seed`
- `php artisan migrate:fresh --seed` — reset DB + seed
- `php artisan db:seed --class=UserSeeder` — seed spesifik

## Contoh Kode
```bash
# Buat seeder
php artisan make:seeder ProductSeeder

# Jalankan semua seeder
php artisan db:seed

# Jalankan seeder spesifik
php artisan db:seed --class=ProductSeeder

# Reset database + seed
php artisan migrate:fresh --seed
```

```php
// database/seeders/ProductSeeder.php
class ProductSeeder extends Seeder
{
    public function run(): void
    {
        Product::factory(20)->create();
    }
}

// DatabaseSeeder.php
class DatabaseSeeder extends Seeder
{
    public function run(): void
    {
        $this->call([
            UserSeeder::class,
            ProductSeeder::class,
        ]);
    }
}
```

## Kasus Penggunaan Nyata
Developer ingin database lokal berisi 50 produk dummy untuk development UI toko online: buat `ProductSeeder`, panggil factory, dan jalankan `php artisan db:seed`.
