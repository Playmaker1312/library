# 44. php artisan optimize

## Definisi Singkat
Perintah yang menggabungkan beberapa perintah caching (config, route, view) untuk mengoptimalkan performa aplikasi di production.

## Analogi
Seperti tune-up mobil sebelum perjalanan jauh — semua komponen diatur agar performa maksimal dan konsumsi bahan bakar minimal.

## Poin-Poin Penting
- Perintah: `php artisan optimize`
- Menjalankan: `config:cache`, `route:cache`, `view:cache`
- Hanya untuk production — jangan dijalankan di development
- Setelah optimize, perubahan pada file config/route/view tidak terlihat sampai cache di-clear
- Untuk clear: `php artisan optimize:clear`
- Di Laravel 11, `optimize` adalah perintah yang lebih ringan dari versi sebelumnya
- Best practice: jalankan di deployment script
- Efek: loading time aplikasi bisa turun 50-70%
- Jika ada error setelah optimize, jalankan `php artisan optimize:clear` untuk debugging

## Contoh Kode
```bash
# Optimasi production
php artisan optimize

# Output:
# Configuration cached successfully!
# Routes cached successfully!
# Views cached successfully!

# Clear semua cache (development)
php artisan optimize:clear

# Output:
# Configuration cache cleared!
# Route cache cleared!
# View cache cleared!

# Deployment script (deploy.sh)
php artisan down --render="maintenance"
git pull origin main
composer install --no-dev --optimize-autoloader
php artisan optimize
php artisan migrate --force
php artisan up
```

## Kasus Penggunaan Nyata
Sebelum traffic naik (Hari Belanja Nasional), tim DevOps menjalankan `php artisan optimize` dan `php artisan view:cache` agar response time aplikasi e-commerce tetap cepat.
