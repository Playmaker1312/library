# 49. Route put, patch, delete

## Definisi Singkat
Route PUT/PATCH digunakan untuk mengupdate data, sedangkan DELETE untuk menghapus data — HTTP method yang penting untuk operasi CRUD di Web API.

## Analogi
Seperti mengelola dokumen: POST = buat baru, PUT = ganti seluruh dokumen, PATCH = edit beberapa bagian, DELETE = hancurkan dokumen.

## Poin-Poin Penting
- **PUT**: mengganti resource secara keseluruhan (replace)
- **PATCH**: mengubah sebagian data resource (partial update)
- **DELETE**: menghapus resource
- Form HTML hanya mendukung GET dan POST — butuh `@method('PUT')` atau `@method('DELETE')` Blade directive
- API biasanya langsung PUT/PATCH/DELETE tanpa spoofing
- Resource controller otomatis mapping: `PUT/PATCH -> update`, `DELETE -> destroy`

## Contoh Kode
```php
// Route PUT — update data
Route::put('/products/{id}', [ProductController::class, 'update']);

// Route PATCH — partial update
Route::patch('/products/{id}/stock', [ProductController::class, 'updateStock']);

// Route DELETE — hapus data
Route::delete('/products/{id}', [ProductController::class, 'destroy']);

// Di Blade — method spoofing
// <form action="/products/5" method="POST">
//     @csrf
//     @method('PUT')
//     <input name="name" value="Produk Baru">
//     <button>Update</button>
// </form>

// Di API — langsung
// PUT /api/products/5
// PATCH /api/products/5/stock
// DELETE /api/products/5
```

```php
// Controller method
public function update(UpdateProductRequest $request, Product $product)
{
    $product->update($request->validated());
    return redirect('/products')->with('success', 'Produk diupdate');
}

public function destroy(Product $product)
{
    $product->delete();
    return redirect('/products')->with('success', 'Produk dihapus');
}
```

## Kasus Penggunaan Nyata
Admin mengedit harga produk: buka halaman edit, ubah field price, submit form dengan `@method('PUT')`. Laravel mengarahkan ke `ProductController@update` yang menyimpan perubahan.
