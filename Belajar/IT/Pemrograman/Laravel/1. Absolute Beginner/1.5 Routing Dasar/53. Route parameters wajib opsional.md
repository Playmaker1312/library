# 53. Route parameters: wajib & opsional

## Definisi Singkat
Route parameter menangkap segmen URL dinamis — parameter wajib harus ada di URL, parameter opsional bisa dihilangkan dengan nilai default.

## Analogi
Seperti alamat rumah: parameter wajib = nomor rumah (harus ada), parameter opsional = nama penerima (boleh kosong, pakai "Pak RT" sebagai default).

## Poin-Poin Penting
- **Parameter wajib**: `{id}` — URL harus menyertakan segmen ini
- **Parameter opsional**: `{name?}` — URL boleh tanpa segmen ini
- Parameter diteruskan ke Closure atau controller method sesuai urutan
- Parameter diakses dengan nama yang sama di method
- Bisa multiple parameter: `/products/{category}/{id}`
- Parameter opsional harus setelah parameter wajib
- Gunakan route model binding untuk inject model langsung: `{product}` otomatis `Product $product`

## Contoh Kode
```php
// Parameter wajib — ID harus ada
Route::get('/products/{id}', function (string $id) {
    return "Product ID: {$id}";
});
// /products/5 => "Product ID: 5"
// /products/ => 404

// Parameter opsional — dengan default
Route::get('/products/{category?}', function (?string $category = null) {
    return $category ? "Kategori: {$category}" : "Semua produk";
});
// /products/elektronik => "Kategori: elektronik"
// /products => "Semua produk"

// Multiple parameter
Route::get('/products/{category}/{id}', function (string $category, string $id) {
    return "Kategori: {$category}, ID: {$id}";
});

// Route model binding (parameter nama = model)
Route::get('/products/{product}', function (Product $product) {
    return $product; // otomatis query Product::findOrFail($id)
});
```
