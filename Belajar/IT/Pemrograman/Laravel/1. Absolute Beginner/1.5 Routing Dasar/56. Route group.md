# 56. Route group

## Definisi Singkat
Route group mengelompokkan beberapa route yang berbagi atribut umum seperti middleware, prefix, namespace, atau name prefix.

## Analogi
Seperti bundling paket langganan — Anda bayar sekali untuk sekelompok channel (atribut) yang berlaku untuk semua anggota grup.

## Poin-Poin Penting
- Sintaks: `Route::group(function () { ... })` atau method chaining dengan `->group()`
- Atribut yang bisa dishare:
  - `middleware` — proteksi grup route
  - `prefix` — prefix URI (`admin/...`)
  - `name` — prefix nama route (`admin.`)
  - `controller` — default controller untuk grup
  - `domain` — subdomain routing
- Bisa nested group (grup di dalam grup)
- Laravel 11: sintaks lebih ekspresif dengan method chaining

## Contoh Kode
```php
// Route group dengan middleware dan prefix
Route::middleware(['auth'])->prefix('admin')->name('admin.')->group(function () {
    Route::get('/dashboard', [DashboardController::class, 'index'])->name('dashboard');
    Route::resource('/users', UserController::class);
    Route::resource('/products', ProductController::class);
});
// Route yang dihasilkan:
// GET /admin/dashboard — name: admin.dashboard
// GET /admin/users — name: admin.users.index
// POST /admin/users — name: admin.users.store

// Nested group
Route::prefix('api')->middleware('api')->group(function () {
    Route::prefix('v1')->group(function () {
        Route::apiResource('products', ProductController::class);
    });
});
// /api/v1/products

// Group dengan controller default
Route::controller(ProductController::class)->group(function () {
    Route::get('/products', 'index');
    Route::post('/products', 'store');
});
```

## Kasus Penggunaan Nyata
Semua route admin panel (dashboard, users, settings) perlu autentikasi dan prefix `/admin`. Satu route group menangani semua tanpa perlu mengulang middleware per route.
