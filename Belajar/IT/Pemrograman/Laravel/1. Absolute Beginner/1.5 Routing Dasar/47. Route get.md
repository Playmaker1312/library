# 47. Route get

## Definisi Singkat
`Route::get()` mendefinisikan route yang hanya merespons request HTTP GET — metode yang digunakan untuk membaca/menampilkan data.

## Analogi
Seperti etalase toko — Anda hanya bisa melihat barang (GET), tidak bisa menyentuh atau membeli (POST/PUT/DELETE).

## Poin-Poin Penting
- Sintaks: `Route::get($uri, $callback)`
- GET adalah method HTTP paling umum untuk halaman web
- Digunakan untuk: menampilkan halaman, form, data publik
- Browser default melakukan GET saat mengetik URL
- GET request bisa di-bookmark, di-cache, dan di-crawl oleh search engine
- Data dikirim via query string (`?key=value`)
- Tidak boleh digunakan untuk operasi yang mengubah state (create/update/delete)

## Contoh Kode
```php
// Route GET dasar
Route::get('/', function () {
    return 'Halaman Beranda';
});

// Route GET dengan controller
Route::get('/products', [ProductController::class, 'index']);

// Route GET dengan parameter
Route::get('/products/{id}', [ProductController::class, 'show']);

// Route GET dengan query string
// URL: /search?q=laptop&sort=price
Route::get('/search', function (Request $request) {
    $query = $request->query('q');
    $sort = $request->query('sort', 'name');
    return "Mencari: {$query}, diurutkan: {$sort}";
});

// Route GET dengan named route
Route::get('/login', [AuthController::class, 'login'])->name('login');
```

## Kasus Penggunaan Nyata
User membuka URL `https://toko.test/products?category=elektronik`. Route GET `/products` di `web.php` menangkap request dan menampilkan daftar produk elektronik.
