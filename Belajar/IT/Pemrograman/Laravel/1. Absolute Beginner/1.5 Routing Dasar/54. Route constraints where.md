# 54. Route constraints (where)

## Definisi Singkat
Route constraint membatasi format parameter route menggunakan regex — memastikan parameter hanya cocok dengan pola tertentu.

## Analogi
Seperti pos security yang hanya mengizinkan masuk kendaraan dengan plat nomor tertentu — parameter hanya valid jika formatnya sesuai aturan.

## Poin-Poin Penting
- Method: `->where('param', 'pattern')` atau `->where(['p1' => 'pattern', 'p2' => 'pattern'])`
- Global constraint di `App\Providers\AppServiceProvider::boot()` via `Route::pattern('id', '[0-9]+')`
- Constraint umum: `[0-9]+` (angka), `[a-z]+` (huruf), `[a-zA-Z0-9-]+` (slug)
- Laravel memiliki helper: `->whereNumber('id')`, `->whereAlpha('name')`, `->whereUlid('uuid')`
- Jika parameter tidak cocok constraint → 404

## Contoh Kode
```php
// Constraint inline — ID hanya angka
Route::get('/products/{id}', function (string $id) {
    return "Product #{$id}";
})->where('id', '[0-9]+');
// /products/abc => 404
// /products/5 => OK

// Multiple constraints
Route::get('/posts/{category}/{slug}', function (string $category, string $slug) {
    return "Kategori: {$category}, Slug: {$slug}";
})->where([
    'category' => '[a-z]+',
    'slug' => '[a-zA-Z0-9-]+',
]);

// Helper constraint
Route::get('/users/{id}', function (string $id) {
    return User::findOrFail($id);
})->whereNumber('id');

Route::get('/coupon/{code}', function (string $code) {
    return "Kupon: {$code}";
})->whereAlphaNumeric('code');

// Global constraint di AppServiceProvider
public function boot(): void
{
    Route::pattern('id', '[0-9]+');
}
// Semua route dengan parameter {id} otomatis hanya menerima angka
```

## Kasus Penggunaan Nyata
Route `/articles/{year}/{slug}` hanya menerima tahun 4 digit: `->where('year', '[0-9]{4}')`. URL `/articles/abc/judul-artikel` akan 404.
