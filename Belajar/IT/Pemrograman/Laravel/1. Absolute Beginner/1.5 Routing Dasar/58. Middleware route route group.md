# 58. Middleware: route & route group

## Definisi Singkat
Middleware dapat dipasang langsung ke route individual atau ke route group — memeriksa/memanipulasi request sebelum mencapai controller.

## Analogi
Seperti pemeriksaan keamanan bandara: ada pos pemeriksaan untuk setiap penumpang (route individual) atau pemeriksaan untuk seluruh rombongan (route group).

## Poin-Poin Penting
- Middleware pada route: `Route::get('/path', ...)->middleware('auth')`
- Middleware pada group: `Route::middleware(['auth', 'verified'])->group(...)`
- Jenis middleware Laravel:
  - `auth` — user harus login
  - `guest` — hanya user yang belum login
  - `verified` — email sudah diverifikasi
  - `throttle:60,1` — rate limiting
  - `can:permission` — authorization
- Multiple middleware: array atau string pipe (`auth|verified`)
- Urutan middleware penting — seperti pipeline
- Custom middleware: buat dengan `php artisan make:middleware`

## Contoh Kode
```php
// Middleware pada route individual
Route::get('/dashboard', [DashboardController::class, 'index'])
    ->middleware(['auth', 'verified']);

Route::get('/profile', [ProfileController::class, 'edit'])
    ->middleware('auth');

// Middleware pada route group
Route::middleware(['auth'])->group(function () {
    Route::get('/dashboard', [DashboardController::class, 'index']);
    Route::resource('/orders', OrderController::class);
    Route::post('/logout', [AuthController::class, 'logout']);
});

// Middleware dengan parameter
Route::middleware('throttle:100,1')->group(function () {
    Route::apiResource('products', ProductController::class);
});
// Maksimal 100 request per menit

// Middleware group bersarang
Route::middleware('auth')->group(function () {
    Route::get('/home', [HomeController::class, 'index']);

    Route::middleware('verified')->group(function () {
        Route::get('/settings', [SettingsController::class, 'edit']);
    });
});
```

## Kasus Penggunaan Nyata
Halaman checkout harus: user login (`auth`), email terverifikasi (`verified`), dan maksimal 10 request per menit (`throttle:10,1`). Semua diterapkan sebagai middleware.
