# 50. Route any & multiple method

## Definisi Singkat
`Route::any()` merespons semua HTTP method (GET, POST, PUT, PATCH, DELETE), sedangkan `Route::match()` merespons method spesifik yang dipilih.

## Analogi
`Route::any()` seperti pintu putar — siapa pun bisa masuk (method apa pun). `Route::match(['GET', 'POST'])` seperti dua pintu berbeda yang menuju ruangan yang sama.

## Poin-Poin Penting
- **`Route::any($uri, $callback)`**: menerima method HTTP apa pun
- **`Route::match(['GET', 'POST'], $uri, $callback)`**: hanya method yang didaftarkan
- Gunakan `match()` jika hanya beberapa method tertentu yang valid
- `any()` jarang digunakan karena praktik REST mengharuskan method spesifik
- Berguna untuk: form yang bisa GET (tampil) dan POST (submit), atau webhook
- Akses method request: `$request->method()` untuk deteksi method saat ini

## Contoh Kode
```php
// Route any — menerima semua method
Route::any('/webhook/payment', function (Request $request) {
    Log::info('Webhook diterima', [
        'method' => $request->method(),
        'data' => $request->all(),
    ]);
    // Bisa dari payment gateway (POST) atau cek manual (GET)
    return response()->json(['status' => 'ok']);
});

// Route match — hanya GET dan POST
Route::match(['GET', 'POST'], '/checkout', [CheckoutController::class, 'index']);

// Contoh konkret: halaman form + submit
Route::match(['GET', 'POST'], '/profile/edit', function (Request $request) {
    if ($request->isMethod('post')) {
        // Simpan perubahan
        return redirect('/profile')->with('success', 'Profil diupdate');
    }

    // Tampilkan form
    return view('profile.edit');
});
```

## Kasus Penggunaan Nyata
Webhook pembayaran Midtrans bisa mengirim GET (verifikasi) dan POST (notifikasi) ke URL yang sama. `Route::any('/payment/notification', ...)` menangani keduanya.
