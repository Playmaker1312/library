# 52. Route dengan controller

## Definisi Singkat
Route dapat mengarahkan request ke method controller — pendekatan terstruktur yang memisahkan definisi route dari logika bisnis.

## Analogi
Seperti meja resepsionis: route adalah petunjuk arah, controller adalah ruangan tempat pekerjaan sesungguhnya dilakukan.

## Poin-Poin Penting
- Sintaks: `Route::get('/path', [NamaController::class, 'method'])`
- Controller method bisa menerima parameter dari route
- Method name mengikuti pola REST: `index`, `create`, `store`, `show`, `edit`, `update`, `destroy`
- Single action controller (invokable): cukup `NamaController::class` tanpa method
- Best practice: tiap controller menangani satu resource
- Controller bisa punya dependensi yang di-inject otomatis via container

## Contoh Kode
```php
// Route ke controller method spesifik
use App\Http\Controllers\ProductController;

Route::get('/products', [ProductController::class, 'index']);
Route::get('/products/create', [ProductController::class, 'create']);
Route::post('/products', [ProductController::class, 'store']);
Route::get('/products/{product}', [ProductController::class, 'show']);
Route::get('/products/{product}/edit', [ProductController::class, 'edit']);
Route::put('/products/{product}', [ProductController::class, 'update']);
Route::delete('/products/{product}', [ProductController::class, 'destroy']);

// Single action controller (invokable)
Route::get('/dashboard', DashboardController::class);

// Resource controller — satu baris untuk semua CRUD
Route::resource('products', ProductController::class);
// Sama dengan 7 route di atas secara otomatis

// API resource (tanpa create/edit)
Route::apiResource('products', ProductController::class);
```

```php
// app/Http/Controllers/ProductController.php
class ProductController extends Controller
{
    public function index()
    {
        return view('products.index', [
            'products' => Product::paginate(10)
        ]);
    }
}
```

## Kasus Penggunaan Nyata
Membuat CRUD penuh untuk kategori: `Route::resource('categories', CategoryController::class)` — satu baris menghasilkan 7 endpoint RESTful.
