# 46. Konsep routing Laravel

## Definisi Singkat
Routing adalah mekanisme yang menghubungkan URL request ke handler spesifik (Closure atau Controller method) — inti dari arsitektur web Laravel.

## Analogi
Seperti peta perjalanan: URL adalah alamat tujuan, route adalah jalur yang ditentukan, dan controller adalah rumah yang dituju.

## Poin-Poin Penting
- Semua route didefinisikan di folder `routes/`
- File default: `web.php` (dengan session, CSRF), `api.php` (stateless, prefix `/api`)
- Route bisa menuju: Closure (fungsi anonim) atau Controller method
- HTTP method: GET, POST, PUT, PATCH, DELETE, OPTIONS
- Route bisa memiliki: parameter, middleware, name, prefix, constraint
- Laravel mencocokkan URL dari atas ke bawah — urutan definisi penting
- Jika tidak ada route yang cocok → 404 Not Found
- Routing juga bisa di-cache dengan `php artisan route:cache`
- Laravel 11: route file lebih sedikit; routing berbasis `Route::` facade

## Contoh Kode
```php
// routes/web.php — route dasar

// Route ke Closure
Route::get('/', function () {
    return view('welcome');
});

// Route ke Controller
Route::get('/products', [ProductController::class, 'index']);

// Route dengan parameter
Route::get('/products/{id}', [ProductController::class, 'show']);

// Route dengan middleware
Route::get('/dashboard', [DashboardController::class, 'index'])
    ->middleware('auth');
```

## Kasus Penggunaan Nyata
User membuka `https://toko.test/products/5`. Laravel mencocokkan ke route `/products/{id}`, menjalankan `ProductController@show(5)`, dan menampilkan detail produk.
