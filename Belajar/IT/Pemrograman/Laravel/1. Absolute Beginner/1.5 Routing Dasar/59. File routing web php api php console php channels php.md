# 59. File routing: web.php, api.php, console.php, channels.php

## Definisi Singkat
Laravel membagi definisi route ke dalam file terpisah berdasarkan tanggung jawab: web (browser), api (REST), console (artisan), dan channels (broadcasting).

## Analogi
Seperti pintu masuk berbeda di gedung: pintu depan untuk tamu (web), pintu belakang untuk kurir (API), pintu servis untuk petugas (console), dan intercom untuk komunikasi (channels).

## Poin-Poin Penting
| File           | Fungsi                                                |
|----------------|-------------------------------------------------------|
| web.php        | Route untuk browser — session, CSRF, cookies          |
| api.php        | Route untuk API — stateless, prefix /api, rate limit |
| console.php    | Registrasi Artisan commands berbasis Closure          |
| channels.php   | Definisi channel broadcasting (Pusher, Reverb)        |

- web.php dimuat oleh RouteServiceProvider dengan middleware group web
- api.php dimuat dengan middleware group api — tanpa session
- console.php untuk command closure yang bisa dijalankan via Artisan
- channels.php untuk otorisasi broadcasting channel
- Laravel 11: routing lebih sederhana — banyak konfigurasi dipindah ke bootstrap/app.php
- File-file ini di-load di bootstrap/app.php via ->withRouting() method

## Contoh Kode
```php
// routes/web.php — route untuk browser
Route::get('/', function () {
    return view('welcome');
});
Route::get('/dashboard', [DashboardController::class, 'index'])->middleware('auth');

// routes/api.php — route API (prefix /api otomatis)
Route::prefix('v1')->group(function () {
    Route::apiResource('products', ProductController::class);
    Route::post('/login', [AuthController::class, 'login']);
});

// routes/console.php — Artisan command closure
Artisan::command('inspire', function () {
    $this->comment(Inspiring::quote());
})->purpose('Display an inspiring quote');

// routes/channels.php — broadcasting authorization
Broadcast::channel('order.{orderId}', function ($user, $orderId) {
    return $user->id === Order::findOrFail($orderId)->user_id;
});
```

## Kasus Penggunaan Nyata
Aplikasi toko online: web.php untuk halaman browser (home, produk, keranjang), api.php untuk endpoint mobile app, console.php untuk command hapus log lama, channels.php untuk notifikasi realtime status pesanan.
