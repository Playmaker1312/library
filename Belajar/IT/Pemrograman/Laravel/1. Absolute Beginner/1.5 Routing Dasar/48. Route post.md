# 48. Route post

## Definisi Singkat
`Route::post()` mendefinisikan route yang merespons request HTTP POST — digunakan untuk mengirim data ke server, biasanya dari form atau API.

## Analogi
Seperti mengirim surat — Anda memasukkan data (form) ke amplop (POST body) dan mengirimkannya ke alamat tujuan (route) untuk diproses.

## Poin-Poin Penting
- Sintaks: `Route::post($uri, $callback)`
- Digunakan untuk: create data, login form, upload file, submit form
- Data dikirim di body request — tidak terlihat di URL
- POST tidak bisa di-bookmark atau di-cache
- Di Laravel, form POST harus menyertakan `@csrf` (CSRF token)
- Sering digunakan bersama dengan method store di resource controller
- Tidak idempotent — setiap POST bisa membuat resource baru
- API endpoint biasanya POST untuk create resource

## Contoh Kode
```php
// Route POST dasar dengan Closure
Route::post('/contact', function (Request $request) {
    $name = $request->input('name');
    $email = $request->input('email');
    // Simpan ke database...
    return "Terima kasih {$name}, pesan Anda telah dikirim.";
});

// Route POST dengan controller
Route::post('/products', [ProductController::class, 'store']);

// Route POST untuk API
Route::post('/api/login', [AuthController::class, 'login']);

// Di Blade (form harus @csrf)
// <form method="POST" action="/contact">
//     @csrf
//     <input name="name">
//     <button type="submit">Kirim</button>
// </form>
```

## Kasus Penggunaan Nyata
User mengisi form pendaftaran di halaman register. Browser mengirim POST ke `/register` dengan data name, email, password. Route POST `/register` di `web.php` memproses dan membuat user baru.
