# 60. Helper route

## Definisi Singkat
Helper `route()` menghasilkan URL absolut dari named route — menggantikan hardcode URL dengan referensi nama yang konsisten dan mudah dipelihara.

## Analogi
Seperti buku alamat di HP — Anda cukup panggil "Rumah" (nama route) daripada harus mengingat "Jl. Merdeka No. 5" (URL). Jika pindah alamat, cukup update buku alamat.

## Poin-Poin Penting
- Sintaks: `route('nama.route', $parameters, $absolute)`
- Menghasilkan URL absolut (dengan domain) secara default
- Parameter opsional: array assosiatif atau value tunggal untuk parameter route
- Untuk URL relatif: `route('nama.route', [...], false)`
- Signed URL: `URL::signedRoute('nama', [...])` — URL dengan signature hash
- Temporary signed URL: `URL::temporarySignedRoute('nama', now()->addHours(1), [...])`
- Helper terkait:
  - `url('/path')` — URL dari path string
  - `asset('css/app.css')` — URL untuk asset
  - `secure_url('/path')` — URL dengan HTTPS
- Jika route tidak ditemukan: error

## Contoh Kode
```php
// Named route
Route::get('/products/{id}/edit', [ProductController::class, 'edit'])
    ->name('products.edit');

// Generate URL
$url = route('products.edit', ['id' => 5]);
// http://localhost:8000/products/5/edit

// Multiple parameters
Route::get('/{category}/{slug}', ...)->name('posts.show');
$url = route('posts.show', ['category' => 'tech', 'slug' => 'laravel-basics']);
// http://localhost:8000/tech/laravel-basics

// Dengan Eloquent model (otomatis ambil route key)
$url = route('products.edit', $product);
// $product->id otomatis digunakan

// Di Blade
<a href="{{ route('products.show', $product) }}">Lihat Produk</a>

// Redirect
return redirect()->route('products.index');

// Signed URL (untuk link unsubscribe, verify email)
URL::signedRoute('unsubscribe', ['user' => 1]);
// http://.../unsubscribe/1?signature=xxxx
```

## Kasus Penggunaan Nyata
Di Blade sidebar, link navigasi menggunakan `route('admin.dashboard')`, `route('admin.users.index')`, dan `route('admin.settings')`. Jika URL diubah di file route, semua link otomatis menyesuaikan.
