# 57. Prefix route group

## Definisi Singkat
Prefix route group menambahkan awalan URI ke semua route dalam grup — digunakan untuk mengelompokkan endpoint dengan segmen URL yang sama.

## Analogi
Seperti nomor induk karyawan: semua karyawan departemen IT punya prefix "IT-" — prefix route memastikan semua route dalam grup dimulai dengan segmen yang sama.

## Poin-Poin Penting
- Method: `Route::prefix('admin')->group(...)`
- Prefix bisa multi-segment: `prefix('api/v1')`
- Prefix bisa dinamis: `prefix('{locale}')` — dengan batasan
- Sering dikombinasikan dengan `name()` dan `middleware()`
- Resource controller dalam grup otomatis mendapat prefix
- Prefix berguna untuk modularisasi: admin, API versioning, area user

## Contoh Kode
```php
// Prefix dasar
Route::prefix('admin')->group(function () {
    Route::get('/dashboard', [AdminController::class, 'dashboard']);
    Route::get('/users', [AdminController::class, 'users']);
});
// URI: /admin/dashboard, /admin/users

// Multi prefix — API versioning
Route::prefix('api/v1')->group(function () {
    Route::apiResource('products', ProductController::class);
    Route::apiResource('categories', CategoryController::class);
});
// URI: /api/v1/products, /api/v1/categories

// Prefix dengan middleware dan name
Route::prefix('admin')
    ->middleware('auth')
    ->name('admin.')
    ->group(function () {
        Route::get('/dashboard', ...)->name('dashboard');
        // name: admin.dashboard
        // URI: /admin/dashboard
    });

// Dynamic prefix (locale)
Route::prefix('{locale}')
    ->whereIn('locale', ['id', 'en'])
    ->group(function () {
        Route::get('/products', [ProductController::class, 'index']);
    });
// URI: /id/products, /en/products
```

## Kasus Penggunaan Nyata
API dengan versioning: semua endpoint v2 ada di `/api/v2/...`. Cukup `Route::prefix('api/v2')->group(...)` — jika ada breaking change, buat grup v3 tanpa menggangu v2.
