# 55. Route name

## Definisi Singkat
Route name adalah alias string untuk route — memungkinkan pembuatan URL dan redirect menggunakan nama daripada hardcode URI.

## Analogi
Seperti kontak telepon — Anda cukup panggil "Ibu" daripada harus menghafal nomor telepon (URL) beliau. Jika nomor berubah, kontak tetap bisa dipanggil.

## Poin-Poin Penting
- Method: `->name('nama.route')` atau chain setelah definisi route
- Convention: gunakan dot notation (`products.index`, `products.show`)
- Generate URL: `route('products.index')` → `http://.../products`
- Redirect: `redirect()->route('login')`
- Resource controller otomatis memberi nama: `products.index`, `products.store`, dll
- Jika URI berubah, nama tetap sama — tidak perlu update di view/controller
- Route group bisa diberi prefix name dengan `->name('admin.')`

## Contoh Kode
```php
// Memberi nama route
Route::get('/products', [ProductController::class, 'index'])->name('products.index');
Route::get('/products/{id}', [ProductController::class, 'show'])->name('products.show');

// Generate URL dari nama
$url = route('products.show', ['id' => 5]);
// http://localhost:8000/products/5

// Redirect ke named route
return redirect()->route('products.index');

// Di Blade
// <a href="{{ route('products.show', $product) }}">Lihat</a>

// Route group dengan prefix name
Route::prefix('admin')->name('admin.')->group(function () {
    Route::get('/users', [UserController::class, 'index'])->name('users.index');
    // name menjadi: 'admin.users.index'
    // URI: /admin/users
});
```

## Kasus Penggunaan Nyata
Jika URI berubah dari `/produk` menjadi `/products`, semua link di view tetap berfungsi karena menggunakan `route('products.index')` — tidak perlu edit satu per satu.
