# 121. Response JSON

## Definisi Singkat
`response()->json($data, $status, $headers)` mengembalikan response dalam format JSON dengan header `Content-Type: application/json`. Metode utama untuk API endpoints.

## Analogi
Seperti **menu digital di restoran**. Daripada menulis menu di kertas (HTML), pelanggan melihat menu di tablet (JSON). Lebih cepat, terstruktur, dan bisa dibaca mesin.

## Poin-Poin Penting
- `response()->json($data)` — return JSON array/object
- Status code default: 200
- Status code khusus: `response()->json($data, 201)`
- Header tambahan: parameter ketiga
- `$data` bisa array, Collection, Model, atau paginator
- Paginator otomatis include meta pagination
- `response()->jsonp($callback, $data)` — JSONP (cross-domain)

## Contoh Kode
```php
// API Controller
namespace App\Http\Controllers\Api;

use App\Models\Product;
use Illuminate\Http\Request;

class ProductController extends Controller
{
    // GET /api/products
    public function index()
    {
        $products = Product::with('category')->paginate(10);

        return response()->json([
            'success' => true,
            'message' => 'Daftar produk',
            'data' => $products,
        ]);
    }

    // POST /api/products
    public function store(Request $request)
    {
        $product = Product::create($request->validated());

        // Status 201 = Created
        return response()->json([
            'success' => true,
            'message' => 'Produk berhasil dibuat',
            'data' => $product,
        ], 201);
    }

    // GET /api/products/{id}
    public function show(Product $product)
    {
        return response()->json([
            'success' => true,
            'data' => $product->load('category'),
        ]);
    }

    // PUT /api/products/{id}
    public function update(Request $request, Product $product)
    {
        $product->update($request->validated());

        return response()->json([
            'success' => true,
            'message' => 'Produk diperbarui',
            'data' => $product,
        ]);
    }

    // DELETE /api/products/{id}
    public function destroy(Product $product)
    {
        $product->delete();

        // 204 = No Content
        return response()->json(null, 204);
    }
}
```

## Kasus Penggunaan Nyata
Semua REST API endpoints, mobile app backend, SPA (Vue/React), integrasi third-party, webhook response.
