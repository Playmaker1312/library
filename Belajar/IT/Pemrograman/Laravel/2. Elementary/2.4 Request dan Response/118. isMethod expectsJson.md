# 118. isMethod, expectsJson

## Definisi Singkat
`$request->isMethod('post')` mengecek HTTP method request. `$request->expectsJson()` mengecek apakah client menginginkan response JSON (berdasarkan header `Accept: application/json`).

## Analogi
- `isMethod` = seperti **cek jenis surat**: apakah ini paket kilat (POST) atau pos biasa (GET)?
- `expectsJson` = seperti **cek bahasa tamu**: apakah tamu minta menu bahasa Inggris (JSON) atau bahasa Indonesia (HTML)?

## Poin-Poin Penting
- `isMethod('post')` — true jika method POST
- Method yang bisa dicek: get, post, put, patch, delete, options
- `expectsJson()` — true jika header `Accept: application/json`
- Berguna untuk controller yang handle web + API
- `wantsJson()` — mirip, cek `Accept` header lebih longgar

## Contoh Kode
```php
public function store(Request $request)
{
    // Cek method request
    if ($request->isMethod('post')) {
        // Proses POST
    }

    // Handle web dan API dalam satu controller
    if ($request->expectsJson()) {
        // Client minta JSON — return API response
        $user = User::create($request->only(['name', 'email']));

        return response()->json([
            'message' => 'User berhasil dibuat',
            'data' => $user
        ], 201);
    }

    // Client minta HTML — return view
    User::create($request->all());
    return redirect()->back()->with('success', 'User dibuat');
}

// Contoh lain: method check
public function update(Request $request, Post $post)
{
    // Bedakan PUT (full update) vs PATCH (partial)
    if ($request->isMethod('patch')) {
        // Partial update — hanya field yang dikirim
        $post->update($request->only(['title']));
    } else {
        // Full update — semua field required
        $post->update($request->all());
    }

    // Di route:
    // PUT /posts/{post} → update()
    // PATCH /posts/{post} → update() juga
}
```

## Kasus Penggunaan Nyata
Controller yang melayani web dan API, membedakan POST vs PUT/PATCH, validasi method untuk idempotency.
