# 114. Metode Post

## Definisi Singkat
`$request->post()` secara spesifik mengambil data dari **request body POST** saja (form data atau JSON), tidak dari query string. Sama dengan `input()` tetapi hanya untuk method POST/PUT/PATCH.

## Analogi
Seperti **kotak surat khusus untuk paket**. Query string = kartu pos (tempelan di luar). POST = paket dalam kotak (isi body). `post()` hanya mengambil isi paket, bukan kartu pos.

## Poin-Poin Penting
- `$request->post('key')` — ambil dari POST body
- `$request->post('key', 'default')` — dengan default
- `$request->post()` — semua data POST sebagai array
- Bedanya dengan `input()`: `input()` cek query string juga, `post()` hanya body
- Berguna saat ingin pastikan data dari form body, bukan URL

## Contoh Kode
```php
public function store(Request $request)
{
    // Hanya ambil dari POST body (bukan query string)
    $title = $request->post('title');
    $content = $request->post('content');

    // Semua data POST
    $allPost = $request->post();
    // ['title' => '...', 'content' => '...', '_token' => '...']

    // Perbedaan dengan input():
    // URL: /users?ref=facebook
    // Body POST: name=Budi

    $ref = $request->input('ref');   // 'facebook' (dari query)
    $ref = $request->post('ref');    // null (hanya body)
    $name = $request->post('name');  // 'Budi'
    $name = $request->input('name'); // 'Budi'

    // JSON request (API)
    // Body: {"name": "Budi", "email": "budi@mail.com"}
    $name = $request->post('name'); // 'Budi'

    User::create($request->post());
}
```

```php
// routes/web.php
Route::post('/users', [UserController::class, 'store']);
```

## Kasus Penggunaan Nyata
Form submission (POST), API endpoint POST, JSON body parsing, webhook receiver. `post()` digunakan saat Anda hanya ingin data body, bukan query string.
