# 122. Response Status Code

## Definisi Singkat
Status code HTTP adalah angka 3 digit yang memberi tahu client hasil dari request. Laravel memudahkan pengaturan status code pada response.

## Analogi
Seperti **lampu indikator mesin**:
- 200 = Hijau (semua baik)
- 301/302 = Belok (redirect)
- 400 = Kuning (salah input)
- 500 = Merah (mesin rusak)

## Poin-Poin Penting
| Code | Nama | Kegunaan |
|------|------|----------|
| 200 | OK | Sukses, default |
| 201 | Created | Resource berhasil dibuat |
| 204 | No Content | Sukses, tidak ada konten |
| 301 | Moved Permanently | Redirect permanen |
| 302 | Found | Redirect sementara |
| 400 | Bad Request | Input salah |
| 401 | Unauthorized | Belum login |
| 403 | Forbidden | Tidak punya akses |
| 404 | Not Found | Resource tidak ada |
| 422 | Unprocessable Entity | Validasi gagal |
| 429 | Too Many Requests | Rate limit |
| 500 | Internal Server Error | Error server |

## Contoh Kode
```php
public function responses()
{
    // 200 OK — default
    return response()->json(['data' => 'success']);

    // 201 Created
    return response()->json($user, 201);

    // 204 No Content — setelah delete
    return response()->json(null, 204);

    // 301 Redirect permanen
    return redirect('/new-url', 301);

    // 400 Bad Request
    return response()->json([
        'message' => 'Input tidak valid'
    ], 400);

    // 401 Unauthorized
    return response()->json([
        'message' => 'Silakan login'
    ], 401);

    // 403 Forbidden
    return response()->json([
        'message' => 'Anda tidak punya akses'
    ], 403);

    // 404 Not Found — otomatis dari findOrFail
    // Model::findOrFail(999) → 404

    // 422 Validation Error — otomatis dari validasi
    // $request->validate([...]) → 422

    // Helper abort
    abort(403, 'Akses ditolak');
    abort_if(!$condition, 404);
    abort_unless(Auth::check(), 401);
}
```

## Kasus Penggunaan Nyata
API response, error handling, redirect, validasi form, authorization check, resource not found.
