# 125. Response Stream File Besar

## Definisi Singkat
`response()->stream()` mengirim response secara bertahap (chunked) untuk file besar atau konten yang di-generate perlahan. Mengurangi memory usage karena tidak perlu load seluruh konten ke RAM.

## Analogi
Seperti **air keran** — Anda tidak perlu menampung satu kolam dulu baru minum. Air langsung mengalir lewat keran (stream). Begitu juga stream response: data dikirim sedikit demi sedikit langsung ke client.

## Poin-Poin Penting
- `response()->stream($callback, $status, $headers)` — kirim data bertahap
- `response()->streamDownload($callback, $name)` — stream sebagai download
- File besar tidak di-load ke memory sekaligus
- Cocok untuk: file besar, CSV generation, log export, video
- Pastikan output buffering tidak menghalangi

## Contoh Kode
```php
namespace App\Http\Controllers;

use App\Models\User;

class ExportController extends Controller
{
    // Stream CSV besar — tanpa load semua data ke memory
    public function exportUsersCsv()
    {
        $fileName = 'users-export.csv';

        return response()->streamDownload(function () {
            // Buka output stream
            $file = fopen('php://output', 'w');

            // Header CSV
            fputcsv($file, ['ID', 'Nama', 'Email', 'Dibuat']);

            // Chunk — ambil 1000 data per batch
            User::chunk(1000, function ($users) use ($file) {
                foreach ($users as $user) {
                    fputcsv($file, [
                        $user->id,
                        $user->name,
                        $user->email,
                        $user->created_at->format('Y-m-d'),
                    ]);
                }
            });

            fclose($file);
        }, $fileName, [
            'Content-Type' => 'text/csv',
        ]);
    }

    // Stream file besar dari storage
    public function streamVideo($filename)
    {
        $path = storage_path("app/videos/{$filename}");

        if (!file_exists($path)) {
            abort(404);
        }

        return response()->stream(function () use ($path) {
            $file = fopen($path, 'rb');
            // Kirim 1MB per chunk
            while (!feof($file)) {
                echo fread($file, 1024 * 1024);
                ob_flush();
                flush();
            }
            fclose($file);
        }, 200, [
            'Content-Type' => 'video/mp4',
            'Content-Length' => filesize($path),
            'Content-Disposition' => "inline; filename=\"{$filename}\"",
        ]);
    }
}
```

```php
// routes/web.php
Route::get('/export/users', [ExportController::class, 'exportUsersCsv']);
Route::get('/videos/{filename}', [ExportController::class, 'streamVideo']);
```

## Kasus Penggunaan Nyata
Export CSV/Excel dengan jutaan data, streaming video/audio, download log file besar, generate PDF besar, real-time data push.
