# 111. Objek Request Laravel

## Definisi Singkat
`Illuminate\Http\Request` adalah objek yang mewakili HTTP request yang masuk. Berisi semua data: input form, query string, file upload, header, session, method HTTP, URL, IP, dan user agent.

## Analogi
Seperti **amplop surat lengkap**. Request = amplop yang berisi: surat (input data), perangko (header), alamat pengirim (IP), jenis pengiriman (method). Anda buka amplop untuk baca isinya.

## Poin-Poin Penting
- Di-inject ke method controller: `public function index(Request $request)`
- Akses input: `$request->input('name')`, `$request->all()`
- Bisa akses langsung seperti property: `$request->name` (dynamic property)
- Berisi juga: method, path, URL, IP, user agent, file, cookie
- Laravel secara otomatis me-resolve Request dari container

## Contoh Kode
```php
namespace App\Http\Controllers;

use Illuminate\Http\Request;

class UserController extends Controller
{
    // Inject Request ke controller method
    public function store(Request $request)
    {
        // Ambil input
        $name = $request->input('name');
        $email = $request->input('email');

        // Dynamic property — akses langsung
        $name = $request->name;

        // Semua data
        $allData = $request->all();

        // Info request
        $method = $request->method();     // POST
        $path = $request->path();         // users
        $url = $request->url();           // http://localhost/users
        $ip = $request->ip();             // 192.168.1.1
        $userAgent = $request->userAgent();

        // Simpan user...
        return redirect()->back();
    }
}
```

## Kasus Penggunaan Nyata
Setiap method controller yang menerima data dari user: form registrasi, login, search, upload file, filter data, API endpoint.
