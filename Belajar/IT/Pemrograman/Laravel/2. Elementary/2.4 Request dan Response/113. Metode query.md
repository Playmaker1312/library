# 113. Metode query

## Definisi Singkat
`$request->query()` mengambil data dari **query string** URL (parameter setelah `?`). Contoh: `/search?q=laptop&page=2` → `$request->query('q')` = `laptop`.

## Analogi
Seperti **label di folder arsip**. Query string adalah label yang ditempel di URL. "q=laptop" = "Cari: laptop". "page=2" = "Halaman: 2". Metode query membaca label-label ini.

## Poin-Poin Penting
- `$request->query('key')` — ambil dari query string saja
- `$request->query('key', 'default')` — dengan default
- `$request->query()` — semua query string sebagai array
- `$request->input()` juga baca query string, tapi `query()` lebih spesifik
- Berguna untuk filter, pencarian, pagination, sorting

## Contoh Kode
```php
// URL: /products?category=electronics&sort=price&page=2&q=speaker

public function index(Request $request)
{
    // Ambil parameter query string
    $category = $request->query('category', 'all');
    $sort = $request->query('sort', 'latest');
    $page = $request->query('page', 1);
    $search = $request->query('q');

    // Semua query params
    $allParams = $request->query();
    // ['category' => 'electronics', 'sort' => 'price',
    //  'page' => '2', 'q' => 'speaker']

    // Cek apakah parameter ada
    if ($request->has('q')) {
        $products = Product::where('name', 'like', "%{$search}%");
    }

    $products = $products->orderBy($sort)->paginate(12);

    return view('products.index', compact('products', 'category', 'sort'));
}
```

```php
<!-- Di Blade — pertahankan query string di link pagination -->
<a href="{{ route('products.index', request()->query()) }}">Semua</a>
<!-- Link akan tetap membawa ?category=electronics&sort=price... -->
```

## Kasus Penggunaan Nyata
Halaman pencarian (`/search?q=...`), filter produk (`/products?category=...&sort=...`), pagination (`?page=2`), sorting (`?order=asc`).
