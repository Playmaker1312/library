# 123. Response Header Kustom

## Definisi Singkat
Header kustom memungkinkan Anda menambahkan metadata ke response HTTP — seperti CORS, cache control, content type, atau header aplikasi spesifik.

## Analogi
Seperti **stiker pada paket kiriman**. "Fragile" (cache-control), "This side up" (content-type), "Kode: TRK123" (custom header). Stiker memberitahu cara menangani paket.

## Poin-Poin Penting
- `header('Nama', 'Value')` — tambah satu header
- `withHeaders([...])` — tambah multiple header
- Header standar: Content-Type, Cache-Control, X-*
- Middleware bisa set header global
- Beberapa header yang sama bisa menggunakan `header` berulang

## Contoh Kode
```php
// Single header
return response('Content')
    ->header('Content-Type', 'text/plain');

// Multiple headers — chain
return response()->json($data)
    ->header('X-RateLimit-Limit', 100)
    ->header('X-RateLimit-Remaining', 95)
    ->header('X-App-Version', '2.0.0');

// withHeaders — array
return response()->json($data)
    ->withHeaders([
        'Content-Type' => 'application/vnd.api+json',
        'X-RateLimit-Limit' => 100,
        'X-RateLimit-Remaining' => 95,
        'Cache-Control' => 'no-cache, private',
        'X-Response-Time' => microtime(true) - LARAVEL_START,
    ]);

// CORS headers
return response('API Response', 200)
    ->header('Access-Control-Allow-Origin', '*')
    ->header('Access-Control-Allow-Methods', 'GET, POST, PUT, DELETE')
    ->header('Access-Control-Allow-Headers', 'Content-Type, Authorization');

// Cache control untuk file statis
return response($fileContent)
    ->header('Content-Type', 'application/pdf')
    ->header('Content-Disposition', 'inline; filename="laporan.pdf"')
    ->header('Cache-Control', 'public, max-age=3600');
```

```php
// Middleware untuk set header global
// app/Http/Middleware/AddHeaders.php
public function handle(Request $request, Closure $next)
{
    $response = $next($request);

    return $response->withHeaders([
        'X-Powered-By' => 'Laravel',
        'X-Request-ID' => $request->header('X-Request-ID', uniqid()),
    ]);
}
```

## Kasus Penggunaan Nyata
API rate limiting headers, CORS untuk frontend terpisah, cache control untuk aset, custom tracking header, content negotiation.
