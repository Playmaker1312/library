# 120. Objek Response Laravel

## Definisi Singkat
`Illuminate\Http\Response` adalah objek yang mewakili response dari server ke client. Bisa berisi HTML, JSON, file, redirect, atau custom response dengan status code dan header tertentu.

## Analogi
Seperti **paket yang dikirim ke pelanggan**. Response = kotak paket yang berisi: barang (konten), stiker fragile (header), dan label pengiriman (status code 200 OK).

## Poin-Poin Penting
- Dibuat dengan helper `response()`, `view()`, `redirect()`, dll
- Bisa di-chain: `response($content)->header('X-Custom', 'value')`
- Berisi: konten, status code, header, cookie
- Laravel otomatis konversi string, array, dan objek ke Response
- `response()->json()` — JSON response
- `response()->download()` — file download
- `response()->stream()` — stream file besar

## Contoh Kode
```php
namespace App\Http\Controllers;

use Illuminate\Http\Request;

class ResponseController extends Controller
{
    public function demo()
    {
        // 1. Response string — otomatis jadi Response
        return 'Hello World';

        // 2. Response view
        return view('welcome');

        // 3. Response JSON
        return response()->json(['name' => 'Budi']);

        // 4. Response dengan status code
        return response('Not Found', 404);

        // 5. Response dengan header
        return response('Content')
            ->header('Content-Type', 'text/plain')
            ->header('X-Custom', 'value');

        // 6. Response dengan cookie
        return response('Content')
            ->cookie('token', 'abc123', 60); // 60 menit

        // 7. Response redirect
        return redirect('/home');
    }

    public function custom()
    {
        // Chain multiple header
        return response('OK', 200)
            ->header('Content-Type', 'application/json')
            ->withHeaders([
                'X-RateLimit-Limit' => 100,
                'X-RateLimit-Remaining' => 99,
            ]);
    }
}
```

## Kasus Penggunaan Nyata
Mengembalikan halaman HTML, API JSON, redirect setelah form submission, error page, file download, streaming response.
