# 119. path, url, ip, userAgent

## Definisi Singkat
Request menyediakan informasi tentang request itu sendiri: `path()` (relatif), `url()` (full URL), `ip()` (alamat IP client), `userAgent()` (browser/device client).

## Analogi
Seperti **check-in counter bandara**: petugas mencatat:
- `path()` = "Tujuan: Jakarta" (rute)
- `url()` = "Penerbangan GA-123" (identitas lengkap)
- `ip()` = "No paspor: AB123456" (identitas pengunjung)
- `userAgent()` = "Maskapai: Garuda, Pesawat: Boeing 737" (jenis browser)

## Poin-Poin Penting
- `$request->path()` — path relatif, mis: `products/5/edit`
- `$request->url()` — URL tanpa query string
- `$request->fullUrl()` — URL dengan query string
- `$request->ip()` — IP address client
- `$request->userAgent()` — User-Agent header
- `$request->header('Referer')` — header spesifik

## Contoh Kode
```php
public function handle(Request $request)
{
    // Path & URL
    $path = $request->path();               // "posts/5/edit"
    $url = $request->url();                 // "http://localhost/posts/5/edit"
    $fullUrl = $request->fullUrl();         // "http://localhost/posts/5/edit?ref=admin"
    $fullUrlWithQuery = $request->fullUrlWithQuery(['sort' => 'asc']);
    // "http://localhost/posts/5/edit?ref=admin&sort=asc"

    // Client info
    $ip = $request->ip();                   // "192.168.1.10"
    $userAgent = $request->userAgent();     // "Mozilla/5.0 (Windows NT 10.0; ...)"
    $referer = $request->header('Referer'); // "http://localhost/admin"

    // Bahasa yang diterima client
    $locale = $request->getPreferredLanguage(['en', 'id']);
    // "id" jika browser set bahasa Indonesia

    // Logging
    Log::info("User accessed {$path} from IP {$ip}");

    // Analytics
    PageView::create([
        'url' => $request->fullUrl(),
        'ip' => $ip,
        'user_agent' => $userAgent,
    ]);
}

// Middleware — blokir IP tertentu
public function handle($request, Closure $next)
{
    $blockedIps = ['192.168.1.100', '10.0.0.5'];
    if (in_array($request->ip(), $blockedIps)) {
        abort(403, 'IP Anda diblokir');
    }
    return $next($request);
}
```

## Kasus Penggunaan Nyata
Logging aktivitas user, analytics/blokir IP, deteksi browser untuk responsif, redirect berdasarkan referer, geolokasi.
