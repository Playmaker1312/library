# 124. Response Download File

## Definisi Singkat
`response()->download($path, $name, $headers)` memaksa browser mendownload file dari server. File bisa dari storage lokal, public, atau path absolut.

## Analogi
Seperti **mesin dispensing tiket**. Anda minta tiket (klik download), mesin mencetak dan memberikan tiket langsung ke tangan Anda. Browser akan menyimpan file, bukan menampilkannya.

## Poin-Poin Penting
- Parameter 1: path ke file (absolut atau relative dari public)
- Parameter 2 (opsional): nama file saat didownload
- Parameter 3 (opsional): array header tambahan
- `response()->file($path)` — tampilkan file di browser (inline)
- File harus readable oleh server
- Support file besar dengan streaming otomatis

## Contoh Kode
```php
namespace App\Http\Controllers;

use Illuminate\Http\Request;

class FileController extends Controller
{
    // Download file dari public folder
    public function downloadManual()
    {
        $path = public_path('files/manual.pdf');

        return response()->download($path, 'manual-pengguna.pdf', [
            'Content-Type' => 'application/pdf',
        ]);
    }

    // Download dengan nama kustom
    public function downloadReport()
    {
        $path = storage_path('app/reports/monthly.pdf');

        $filename = 'laporan-bulanan-' . now()->format('Y-m') . '.pdf';

        return response()->download($path, $filename);
    }

    // Tampilkan file di browser (inline)
    public function viewPdf($id)
    {
        $path = storage_path("app/invoices/invoice-{$id}.pdf");

        return response()->file($path, [
            'Content-Type' => 'application/pdf',
            'Content-Disposition' => 'inline; filename="invoice.pdf"',
        ]);
    }

    // Download file dari storage
    public function downloadAvatar(User $user)
    {
        if ($user->avatar) {
            $path = storage_path("app/public/{$user->avatar}");

            return response()->download($path, 'avatar-' . $user->name . '.jpg');
        }

        return abort(404);
    }
}
```

```php
// routes/web.php
Route::get('/download/manual', [FileController::class, 'downloadManual']);
Route::get('/download/report', [FileController::class, 'downloadReport']);
Route::get('/invoice/{id}/view', [FileController::class, 'viewPdf']);
```

## Kasus Penggunaan Nyata
Download file PDF (laporan, invoice), export CSV/Excel, download gambar/file upload, download dokumentasi.
