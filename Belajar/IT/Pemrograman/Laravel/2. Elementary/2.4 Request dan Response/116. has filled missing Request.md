# 116. has, filled, missing Request

## Definisi Singkat
`$request->has('field')` cek apakah field **ada** dalam request. `$request->filled('field')` cek apakah field **ada dan tidak kosong**. `$request->missing('field')` cek apakah field **tidak ada**.

## Analogi
Seperti **cek koper**:
- `has()` = "Apakah koper ini ada sikat gigi?" (ada atau tidak?)
- `filled()` = "Apakah sikat giginya benar-benar ada dan basah?" (ada dan terisi)
- `missing()` = "Apakah sikat gigi TIDAK ada?" (kebalikan has)

## Poin-Poin Penting
- `has('field')` — true jika field ada dalam request (meski null)
- `has(['a', 'b'])` — true jika SEMUA field ada
- `hasAny(['a', 'b'])` — true jika SALAH SATU field ada
- `filled('field')` — true jika field ada dan tidak kosong
- `missing('field')` — true jika field TIDAK ada
- Kosong = null, string kosong, array kosong

## Contoh Kode
```php
public function store(Request $request)
{
    // Cek apakah field 'email' ada
    if ($request->has('email')) {
        // Field 'email' ada di request (bisa null)
    }

    // Cek apakah field 'email' ada DAN terisi
    if ($request->filled('email')) {
        // Email tidak null dan tidak string kosong
        $email = $request->email;
    }

    // Cek apakah field tidak ada
    if ($request->missing('profile_picture')) {
        // Field tidak dikirim — mungkin pakai default
        $picture = 'default-avatar.png';
    }

    // Multiple fields — semua harus ada
    if ($request->has(['name', 'email', 'password'])) {
        // Semua field ada
    }

    // Multiple — salah satu ada
    if ($request->hasAny(['phone', 'email'])) {
        // Minimal satu kontak diisi
    }

    // Contoh nyata
    $userData = [];

    if ($request->filled('name')) {
        $userData['name'] = $request->name;
    }

    if ($request->filled('bio')) {
        $userData['bio'] = $request->bio;
    }

    User::update($userData);
}
```

## Kasus Penggunaan Nyata
Validasi opsional (update partial), cek checkbox tercentang, field opsional di form, conditional logic berdasarkan input.
