# 117. File Upload Request

## Definisi Singkat
`$request->file('field')` mengambil file yang diupload dari form. Laravel menyediakan metode untuk validasi, menyimpan, dan mendapatkan info file upload.

## Analogi
Seperti **petugas bagasi bandara** — Anda serahkan koper (file), petugas (Request) cek ukuran, timbang berat, lalu simpan ke tempat yang benar dengan label unik.

## Poin-Poin Penting
- Form harus punya `enctype="multipart/form-data"`
- `$request->file('photo')` — instance UploadedFile
- `$request->hasFile('photo')` — cek apakah ada file diupload
- `$file->store('path')` — simpan ke storage disk
- `$file->storeAs('path', 'name')` — simpan dengan custom name
- `$file->getClientOriginalName()` — nama asli file
- `$file->getSize()` — ukuran dalam bytes
- `$file->getMimeType()` — tipe MIME

## Contoh Kode
```php
public function upload(Request $request)
{
    // Validasi: file wajib, max 2MB, harus gambar
    $request->validate([
        'photo' => 'required|image|mimes:jpg,png|max:2048',
        'document' => 'nullable|file|mimes:pdf|max:5120',
    ]);

    // Cek apakah ada file
    if ($request->hasFile('photo')) {
        $file = $request->file('photo');

        // Info file
        $originalName = $file->getClientOriginalName(); // "foto.jpg"
        $extension = $file->getClientOriginalExtension(); // "jpg"
        $size = $file->getSize(); // 1024000 (bytes)
        $mime = $file->getMimeType(); // "image/jpeg"

        // Simpan ke storage/app/public/photos
        // Nama unik otomatis (hash)
        $path = $file->store('photos', 'public');
        // "photos/abc123xyz.jpg"

        // Simpan dengan nama custom
        $customPath = $file->storeAs(
            'photos',
            time() . '_' . $originalName,
            'public'
        );
        // "photos/1705300000_foto.jpg"
    }

    // Upload multiple files
    if ($request->hasFile('documents')) {
        foreach ($request->file('documents') as $doc) {
            $doc->store('documents', 'public');
        }
    }

    return back()->with('success', 'File terupload');
}
```

## Kasus Penggunaan Nyata
Upload foto profil, upload gambar produk, upload dokumen (KTP, CV), upload multiple file (lampiran, galeri).
