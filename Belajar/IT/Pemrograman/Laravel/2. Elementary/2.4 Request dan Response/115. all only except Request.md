# 115. all, only, except Request

## Definisi Singkat
`$request->all()` mengembalikan **semua** data input. `$request->only(['a', 'b'])` mengambil **hanya** field tertentu. `$request->except(['_token'])` mengambil **semua kecuali** field tertentu.

## Analogi
Seperti **tas belanja**:
- `all()` = semua barang dari keranjang
- `only(['apel', 'pisang'])` = ambil apel dan pisang saja
- `except(['_token'])` = semua kecuali struk belanja

## Poin-Poin Penting
- `all()` — array semua input (termasuk _token, _method)
- `only(['field1', 'field2'])` — hanya field yang disebut
- `except(['field1'])` — semua kecuali field yang disebut
- Berguna untuk mass-assignment dengan Model::create()
- `only()` aman untuk filtering input sebelum create/update

## Contoh Kode
```php
public function store(Request $request)
{
    // Semua data — termasuk _token, _method
    $all = $request->all();
    // ['_token' => '...', 'title' => '...', 'body' => '...',
    //  'status' => 'draft']

    // Hanya field tertentu — aman untuk mass assignment
    $data = $request->only(['title', 'body', 'status']);
    // ['title' => '...', 'body' => '...', 'status' => 'draft']

    // Semua kecuali _token dan _method
    $clean = $request->except(['_token', '_method']);
    // ['title' => '...', 'body' => '...', 'status' => 'draft']

    // Gunakan for mass assignment — aman
    Post::create($request->only(['title', 'body', 'status']));

    // Atau jika ada field yang tidak boleh diisi
    Post::create($request->except(['admin_field']));
}

public function update(Request $request, Post $post)
{
    // Update hanya field yang diizinkan
    $post->update($request->only(['title', 'body']));
}
```

## Kasus Penggunaan Nyata
Filter input sebelum create/update, menghilangkan `_token` dan `_method` dari data, mengambil subset input untuk multiple model.
