# 112. Metode input Request

## Definisi Singkat
`$request->input()` mengambil nilai input dari form (POST) atau query string (GET) berdasarkan nama field. Mendukung nested array, default value, dan akses dot notation.

## Analogi
Seperti **petugas resepsionis yang menulis data tamu**. "Siapa nama Anda?" → ambil nama. "Alamat?" → ambil alamat. Jika tidak diisi, catat "Tidak disebutkan" (default value).

## Poin-Poin Penting
- `$request->input('nama')` — ambil nilai field 'nama'
- `$request->input('nama', 'default')` — dengan default jika tidak ada
- Dot notation: `$request->input('user.address.city')` — nested array
- Bisa array: `$request->input('items.*.id')` — semua id dari items
- String otomatis di-trim (Laravel middleware)
- Alternatif: `$request->nama` — dynamic property (sama)

## Contoh Kode
```php
public function store(Request $request)
{
    // Input dasar
    $title = $request->input('title');
    $body = $request->input('body');

    // Dengan default value
    $status = $request->input('status', 'draft');
    $visibilitas = $request->input('visibility', 'public');

    // Nested array — form input name="user[name]"
    $name = $request->input('user.name');  // "Budi"
    $email = $request->input('user.email'); // "budi@mail.com"

    // Array input — form name="items[]"
    $itemIds = $request->input('items.*');     // [1, 2, 3]
    $firstItem = $request->input('items.0');   // 1

    // Dynamic property — alternatif singkat
    $title = $request->title;  // sama dengan $request->input('title')

    // Boolean input (checkbox)
    $agree = $request->input('agree', false);
    $isActive = $request->boolean('is_active'); // true/false

    // Integer input — otomatis casting
    $age = $request->integer('age'); // (int) $request->input('age')

    User::create($request->only('name', 'email'));
}
```

## Kasus Penggunaan Nyata
Mengambil data dari form registrasi, form pencarian dengan default value, form input dinamis (array), checkbox boolean (setujui syarat).
