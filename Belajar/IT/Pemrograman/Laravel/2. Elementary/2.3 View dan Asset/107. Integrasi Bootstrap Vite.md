# 107. Integrasi Bootstrap Vite

## Definisi Singkat
Bootstrap diintegrasikan dengan Vite dengan menginstall package Bootstrap dan import CSS/JS di entry point. Vite akan memproses dan mengkompilasi file Bootstrap.

## Analogi
Seperti **rumah yang sudah difurnish**. Bootstrap = perabot standar (meja, kursi, lemari). Vite = tim pemasang yang merapikan semua perabot sesuai tempatnya.

## Poin-Poin Penting
- Install: `npm install bootstrap @popperjs/core`
- Import Bootstrap CSS di `resources/css/app.css`
- Import Bootstrap JS di `resources/js/app.js`
- Vite otomatis proses file node_modules
- Pastikan file scss jika pakai Bootstrap dengan Sass
- Jangan lupa `@vite` di layout

## Contoh Kode
```bash
# Install Bootstrap dan dependensinya
npm install bootstrap @popperjs/core
```

```css
/* resources/css/app.css */
/* Import Bootstrap CSS */
@import 'bootstrap/dist/css/bootstrap.min.css';

/* Custom styles di atas Bootstrap */
body {
    padding-top: 60px;
}

/* Atau pakai SCSS (install sass dulu) */
/* @import 'bootstrap/scss/bootstrap'; */
```

```javascript
// resources/js/app.js
import './bootstrap'; // Laravel default bootstrap.js

// Import Bootstrap JS
import 'bootstrap/dist/js/bootstrap.bundle.min.js';

// Atau import modular untuk ukuran lebih kecil
// import 'bootstrap/js/dist/modal';
// import 'bootstrap/js/dist/dropdown';
```

```php
<!-- resources/views/layouts/app.blade.php -->
<!DOCTYPE html>
<html>
<head>
    @vite(['resources/css/app.css'])
</head>
<body>
    <nav class="navbar navbar-expand-lg navbar-dark bg-dark">
        <div class="container">
            <a class="navbar-brand" href="/">My App</a>
        </div>
    </nav>

    <main class="container mt-4">
        @yield('content')
    </main>

    @vite(['resources/js/app.js'])
</body>
</html>
```

## Kasus Penggunaan Nyata
Aplikasi yang menggunakan Bootstrap untuk UI komponen siap pakai — navbar, card, modal, form, tabel, grid system.
