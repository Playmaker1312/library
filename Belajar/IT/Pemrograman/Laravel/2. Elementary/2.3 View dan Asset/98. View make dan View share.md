# 98. View Make dan View Share

## Definisi Singkat
`View::make()` membuat instance view secara eksplisit. `View::share()` membagikan data ke **semua view** di seluruh aplikasi — cocok untuk data global seperti setting aplikasi.

## Analogi
- View::make = **memesan menu spesifik** di restoran
- View::share = **sambal di meja** — tersedia di semua meja (view) tanpa harus minta

## Poin-Poin Penting
- `View::make('page', $data)` = sama dengan `view('page', $data)`
- `View::share('key', 'value')` — data tersedia di SEMUA view
- Panggil di `AppServiceProvider::boot()` agar global
- Cocok untuk: nama aplikasi, setting, user login (auth)
- Hindari share terlalu banyak data — bisa membingungkan

## Contoh Kode
```php
// app/Providers/AppServiceProvider.php
namespace App\Providers;

use Illuminate\Support\Facades\View;
use Illuminate\Support\ServiceProvider;
use App\Models\Setting;

class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        // Data ini tersedia di SEMUA view
        View::share('appName', 'Toko Online');
        View::share('appVersion', '2.0.0');

        // Share data dari database
        View::share('siteSettings', Setting::pluck('value', 'key'));

        // Share data kondisional
        View::composer('*', function ($view) {
            $view->with('cartCount', session('cart', 0));
        });
    }
}
```

```php
<!-- Di view manapun, langsung bisa akses tanpa passing -->
<!DOCTYPE html>
<html>
<head>
    <title>{{ $appName }} | @yield('title')</title>
</head>
<body>
    <p>Versi {{ $appVersion }}</p>
    <p>Item di keranjang: {{ $cartCount }}</p>

    @if (isset($siteSettings['site_description']))
        <meta name="description" content="{{ $siteSettings['site_description'] }}">
    @endif
</body>
</html>
```

## Kasus Penggunaan Nyata
Nama aplikasi di title/header, data setting global (logo, favicon, alamat), notifikasi global, counter keranjang, user info.
