# 103. @vite Directive

## Definisi Singkat
`@vite()` adalah direktif Blade yang secara otomatis memuat asset yang sudah dikonfigurasi di `vite.config.js`. Di development ia melayani module dengan HMR, di production ia memuat file build.

## Analogi
Seperti **pintu otomatis** — Anda tinggal mendekat, pintu terbuka sendiri. `@vite()` otomatis memilih file yang benar: file mentah (dev) atau file build (production). Tanpa Anda harus ganti manual.

## Poin-Poin Penting
- `@vite(['resources/css/app.css'])` — muat CSS entry
- `@vite(['resources/js/app.js'])` — muat JS entry
- Dev: inject module script + CSS via JS
- Production: inject `<link>` CSS + `<script>` JS dari `public/build/`
- Vite otomatis handle versioning (hash) di production
- Bisa multiple entry: `@vite(['resources/css/app.css', 'resources/js/app.js'])`

## Contoh Kode
```php
<!-- resources/views/layouts/app.blade.php -->
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>@yield('title')</title>

    <!-- @vite untuk CSS — hasil dev/prod otomatis -->
    @vite(['resources/css/app.css'])

    <!-- CSS tambahan per halaman -->
    @yield('styles')
</head>
<body>
    <div id="app">
        @yield('content')
    </div>

    <!-- @vite untuk JS — letakkan di akhir body -->
    @vite(['resources/js/app.js'])

    @yield('scripts')
</body>
</html>

<!-- Saat development (HMR aktif):
     Output: <script type="module" src="http://localhost:5173/..."></script>
     CSS di-inject via JS secara real-time -->

<!-- Saat production (build):
     Output: <link rel="stylesheet" href="/build/assets/app-abc123.css">
     <script type="module" src="/build/assets/app-xyz789.js"></script> -->
```

## Kasus Penggunaan Nyata
Memuat CSS framework (Tailwind) dan JS (Alpine.js/Vue) di layout, memuat halaman spesifik assets, integrasi dengan React/Vue SPA.
