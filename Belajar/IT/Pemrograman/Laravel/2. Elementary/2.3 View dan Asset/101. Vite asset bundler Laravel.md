# 101. Vite Asset Bundler Laravel

## Definisi Singkat
Vite adalah build tool modern untuk frontend yang menjadi default asset bundler Laravel sejak versi 9. Vite menggantikan Laravel Mix (Webpack) dengan kecepatan kompilasi yang jauh lebih cepat.

## Analogi
Seperti **mobil sport vs mobil biasa**. Mix/Webpack = mobil biasa — lambat di perjalanan pendek. Vite = mobil sport — cepat, mulus, dan hemat bahan bakar, terutama saat development.

## Poin-Poin Penting
- Vite = **V**ite **I**s a build **T**ool for fast **E**verything
- Development: HMR (Hot Module Replacement) — perubahan langsung terlihat
- Production: build minified + versioning
- Konfigurasi di `vite.config.js`
- Entry point di `resources/js/app.js` dan `resources/css/app.css`
- Gunakan `@vite()` directive di Blade untuk memuat asset

## Contoh Kode
```php
<!-- resources/views/layouts/app.blade.php -->
<!DOCTYPE html>
<html>
<head>
    ...
    @vite(['resources/css/app.css'])
    <!-- Development: inject CSS via JS
         Production: inject CSS link -->
</head>
<body>
    @yield('content')

    @vite(['resources/js/app.js'])
    <!-- Development: inject JS module with HMR
         Production: inject built JS file -->
</body>
</html>
```

```javascript
// vite.config.js
import { defineConfig } from 'vite';
import laravel from 'laravel-vite-plugin';

export default defineConfig({
    plugins: [
        laravel({
            input: ['resources/css/app.css', 'resources/js/app.js'],
            refresh: true,  // auto refresh saat Blade berubah
        }),
    ],
});
```

## Kasus Penggunaan Nyata
Semua proyek Laravel baru. Development dengan HMR untuk frontend React/Vue/Vanilla JS, production build dengan optimasi otomatis.
