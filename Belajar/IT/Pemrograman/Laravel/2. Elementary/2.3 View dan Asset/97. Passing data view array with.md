# 97. Passing Data View: Array, With

## Definisi Singkat
Data dikirim ke view melalui parameter kedua `view()` (array asosiatif) atau method `->with()`. Di Blade, data diakses sebagai variabel sesuai key array.

## Analogi
Seperti **mengirim paket lewat kurir**. Array = kotak paket berisi barang. Kurir (helper view) mengantar ke rumah (Blade). Anda buka kotak dan pakai barangnya (variabel).

## Poin-Poin Penting
- Array: `view('page', ['key' => 'value'])` → akses `$key` di Blade
- Compact: `view('page', compact('key'))` → otomatis buat variable
- With: `view('page')->with('key', 'value')` — chaining
- With multiple: `->with(['key1' => 'val1', 'key2' => 'val2'])`
- Variabel yang tidak dikirim → error undefined, gunakan `??` atau `@isset`

## Contoh Kode
```php
// Controller
class ProductController extends Controller
{
    public function index()
    {
        $products = Product::all();
        $category = 'Semua Produk';
        $total = Product::count();

        // Cara 1: Array asosiatif
        return view('products.index', [
            'products' => $products,
            'category' => $category,
            'total' => $total,
        ]);
    }

    public function show($id)
    {
        $product = Product::findOrFail($id);
        $related = Product::where('category_id', $product->category_id)
            ->where('id', '!=', $product->id)
            ->take(4)->get();

        // Cara 2: Compact (sederhana)
        return view('products.show', compact('product', 'related'));
    }

    public function search(Request $request)
    {
        $query = $request->input('q');
        $results = Product::where('name', 'like', "%{$query}%")->get();

        // Cara 3: Method chaining with()
        return view('products.search')
            ->with('query', $query)
            ->with('results', $results);
    }
}
```

```php
<!-- Di Blade — akses variabel dari data -->
<h1>{{ $category }}</h1>
<p>Total: {{ $total }} produk</p>

@foreach ($products as $product)
    <div>{{ $product->name }}</div>
@endforeach
```

## Kasus Penggunaan Nyata
Mengirim data dari controller ke view — daftar user, detail artikel, hasil pencarian, data form, setting tampilan.
