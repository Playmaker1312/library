# 106. Integrasi Tailwind CSS Vite

## Definisi Singkat
Tailwind CSS diintegrasikan dengan Vite melalui PostCSS. Cukup install Tailwind, buat file konfigurasi, dan import di CSS entry — Vite akan memprosesnya otomatis.

## Analogi
Seperti **cat tembok + semprotan otomatis**. Tailwind = cat siap pakai. Vite = semprotan otomatis yang mengecat secara merata dan cepat. Hasilnya: styling cepat, konsisten, dan ringan.

## Poin-Poin Penting
- Install: `npm install tailwindcss @tailwindcss/forms postcss autoprefixer`
- Init: `npx tailwindcss init -p` — buat `tailwind.config.js`
- Tambahkan path Blade ke `content` di konfigurasi
- Import Tailwind di `resources/css/app.css`
- Vite otomatis proses PostCSS (tailwind adalah plugin PostCSS)

## Contoh Kode
```javascript
// tailwind.config.js
/** @type {import('tailwindcss').Config} */
export default {
    content: [
        // Scan semua file Blade untuk class Tailwind
        './resources/**/*.blade.php',
        './resources/**/*.js',
        './resources/**/*.vue',
    ],
    theme: {
        extend: {
            colors: {
                primary: '#1a73e8',
                secondary: '#6c757d',
            },
        },
    },
    plugins: [
        require('@tailwindcss/forms'),
    ],
};
```

```css
/* resources/css/app.css */
@tailwind base;
@tailwind components;
@tailwind utilities;

/* Custom components */
@layer components {
    .btn-primary {
        @apply bg-blue-600 text-white px-4 py-2 rounded-lg
               hover:bg-blue-700 transition duration-200;
    }
}
```

```php
<!-- resources/views/welcome.blade.php -->
<!DOCTYPE html>
<html>
<head>
    @vite(['resources/css/app.css'])
</head>
<body class="bg-gray-100">
    <div class="container mx-auto p-8">
        <h1 class="text-4xl font-bold text-blue-600">
            Halo Tailwind!
        </h1>
        <button class="btn-primary mt-4">
            Klik Saya
        </button>
    </div>
</body>
</html>
```

## Kasus Penggunaan Nyata
Semua proyek Laravel baru yang menggunakan Tailwind untuk styling. Development cepat dengan utility-first CSS, mudah dikustomisasi.
