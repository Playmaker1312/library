# 104. npm run dev Kompilasi

## Definisi Singkat
`npm run dev` menjalankan Vite dalam mode development — mengkompilasi CSS/JS dan mengaktifkan HMR (Hot Module Replacement). Setiap perubahan langsung terlihat di browser tanpa refresh manual.

## Analogi
Seperti **koki yang memasak di dapur terbuka**. Setiap kali Anda minta tambah garam, koki langsung tambah dan Anda lihat hasilnya saat itu juga. Tidak perlu nunggu 10 menit.

## Poin-Poin Penting
- Jalankan di terminal: `npm run dev`
- Vite menjalankan server di `http://localhost:5173`
- HMR: perubahan CSS/JS langsung muncul tanpa reload halaman
- Juga pantau file Blade jika `refresh: true` di config
- Biarkan terminal tetap berjalan — jangan di-Ctrl+C
- Untuk production: `npm run build`

## Contoh Kode
```bash
# Terminal 1: Jalankan Laravel
php artisan serve

# Terminal 2: Jalankan Vite development
npm run dev

# Output:

```

## Kasus Penggunaan Nyata
Saat mengembangkan frontend — styling Tailwind, menulis JavaScript/Alpine/Vue, memperbaiki tampilan. `npm run dev` dijalankan sepanjang sesi development.
