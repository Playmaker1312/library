# 108. Helper URL, Helper Secure URL

## Definisi Singkat
`url()` menghasilkan URL lengkap ke path tertentu. `secure_url()` memaksa HTTPS. Juga ada `route()`, `action()`, dan `asset()` sebagai helper URL lainnya.

## Analogi
Seperti **GPS**. `url('/products')` = "beri saya alamat lengkap ke toko produk". GPS otomatis tahu base address rumah Anda (domain) dan menambahkan rutenya.

## Poin-Poin Penting
- `url('/path')` → `http://domain.com/path`
- `url()->current()` — URL saat ini tanpa query string
- `url()->full()` — URL saat ini dengan query string
- `url()->previous()` — URL sebelumnya (referer)
- `secure_url('/path')` → `https://domain.com/path`
- `route('nama.route')` — URL berdasarkan named route
- `action([Controller::class, 'method'])` — URL ke controller method

## Contoh Kode
```php
// Di Blade atau Controller
$currentUrl = url()->current();
$fullUrl = url()->full();
$prevUrl = url()->previous();

// URL ke path tertentu
$productsUrl = url('/products');         // http://localhost/products
$profileUrl = url('/users/5');           // http://localhost/users/5

// Named route
$postUrl = route('posts.show', 5);       // http://localhost/posts/5

// Action
$actionUrl = action([PostController::class, 'index']);

// Secure URL — paksa HTTPS
$secureAsset = secure_url('css/app.css'); // https://localhost/css/app.css

// Di Blade
<form action="{{ url('/posts') }}" method="POST">
    @csrf
    ...
</form>

<a href="{{ route('posts.show', $post) }}">Lihat Post</a>

<form action="{{ url()->current() }}" method="GET">
    <input type="search" name="q">
    <button type="submit">Cari</button>
</form>
```

## Kasus Penggunaan Nyata
Membuat link navigasi, form action, redirect setelah login, pagination, canonical URL untuk SEO.
