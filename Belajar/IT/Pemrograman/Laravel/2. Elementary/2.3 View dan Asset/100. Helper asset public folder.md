# 100. Helper Asset Public Folder

## Definisi Singkat
`asset()` menghasilkan URL lengkap ke file di folder `public/`. Digunakan untuk memuat file CSS, JavaScript, gambar, dan file statis lainnya.

## Analogi
Seperti **peta alamat**. `asset('css/app.css')` = beri saya alamat lengkap ke file ini. "Silakan ambil di: https://website.com/css/app.css"

## Poin-Poin Penting
- `asset('path/file')` → `http://domain.com/path/file`
- Otomatis menggunakan base URL aplikasi (dari config `app.url`)
- `asset()` menghasilkan URL relatif terhadap root domain
- `secure_asset()` — paksa HTTPS
- Cocok untuk file di `public/` seperti CSS, JS, gambar, upload

## Contoh Kode
```php
<!-- Di Blade — memuat asset dari folder public -->
<!DOCTYPE html>
<html>
<head>
    <!-- CSS -->
    <link rel="stylesheet" href="{{ asset('css/app.css') }}">
    <link rel="stylesheet" href="{{ asset('css/custom.css') }}">

    <!-- Favicon -->
    <link rel="icon" type="image/x-icon"
          href="{{ asset('favicon.ico') }}">
</head>
<body>
    <!-- Gambar dari folder public/images -->
    <img src="{{ asset('images/logo.png') }}" alt="Logo"
         width="200">

    <!-- File upload user -->
    <img src="{{ asset('storage/' . $user->avatar) }}"
         alt="Avatar">

    <!-- JavaScript -->
    <script src="{{ asset('js/app.js') }}"></script>

    <!-- Secure asset — paksa HTTPS -->
    <script src="{{ secure_asset('js/app.js') }}"></script>
</body>
</html>
```

## Kasus Penggunaan Nyata
Memuat CSS framework (Tailwind, Bootstrap), JavaScript (Alpine, Vue), gambar logo/icon, favicon, file upload user, font.
