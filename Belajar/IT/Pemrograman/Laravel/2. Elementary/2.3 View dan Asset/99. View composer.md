# 99. View Composer

## Definisi Singkat
View Composer adalah callback atau class yang otomatis mengikat data ke view tertentu saat view tersebut di-render. Berguna untuk data yang perlu ada di banyak view.

## Analogi
Seperti **hiasan ruangan otomatis**. Setiap kali Anda masuk ke ruang tamu (view tertentu), dekorasi (data) sudah terpasang — lampu menyala, bunga di meja. Tanpa Anda pasang manual setiap kali.

## Poin-Poin Penting
- Didaftarkan di `AppServiceProvider::boot()` atau `ViewServiceProvider`
- Bisa untuk view spesifik: `'admin.sidebar'`
- Bisa untuk semua view: `'*'`
- Bisa pakai class terpisah (recommended untuk kompleks)
- Data hanya di-load saat view benar-benar di-render
- Alternatif modern: View Composer via `View::composer`

## Contoh Kode
```php
// app/Providers/AppServiceProvider.php
namespace App\Providers;

use App\Models\Category;
use App\Models\Notification;
use Illuminate\Support\Facades\View;
use Illuminate\Support\ServiceProvider;

class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        // Composer untuk view 'layouts.sidebar'
        View::composer('layouts.sidebar', function ($view) {
            $view->with('categories', Category::all());
            $view->with('recentPosts', \App\Models\Post::latest()->take(5)->get());
        });

        // Composer untuk semua view yang mengandung 'admin'
        View::composer('admin.*', function ($view) {
            $view->with('unreadNotifications',
                Notification::where('read', false)->count());
        });

        // Bisa multiple view
        View::composer(['dashboard', 'profile'], function ($view) {
            $view->with('userStats', auth()->user()->stats());
        });
    }
}
```

```php
// Class-based view composer
// app/Http/View/Composers/CartComposer.php
namespace App\Http\View\Composers;

use Illuminate\View\View;

class CartComposer
{
    public function compose(View $view): void
    {
        $cart = session()->get('cart', []);
        $view->with('cartCount', count($cart))
             ->with('cartTotal', array_sum(array_column($cart, 'price')));
    }
}

// Daftarkan di provider:
// View::composer('*', CartComposer::class);
```

## Kasus Penggunaan Nyata
Menu navigasi dengan kategori, sidebar dengan post terbaru, notifikasi global, data keranjang belanja, user info di header.
