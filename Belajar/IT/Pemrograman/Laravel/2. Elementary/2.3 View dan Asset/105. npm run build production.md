# 105. npm run build Production

## Definisi Singkat
`npm run build` mengkompilasi CSS/JS untuk production — hasilnya diminifikasi (diperkecil), digabung, dan diberi hash untuk cache busting. Output diletakkan di `public/build/`.

## Analogi
Seperti **mengepak barang untuk pindahan**. Development = barang berantakan di meja. `npm run build` = semua barang dirapikan, dimasukkan kardus, diberi label — siap dikirim ke rumah baru (production server).

## Poin-Poin Penting
- Jalankan: `npm run build`
- Output di `public/build/assets/`
- File diberi hash unik: `app-abc123.css`
- Hash berubah jika konten berubah — cache otomatis diperbarui
- Jangan edit file di `public/build/` langsung
- Sebelum deploy ke server, selalu `npm run build`

## Contoh Output
```bash
# Terminal
npm run build

# Output:
#   vite v5.x.x building for production...
#   ✓ 2 modules transformed.
#   public/build/manifest.json         0.40 kB
#   public/build/assets/app-abc123.css  25.60 kB │ gzip: 5.12 kB
#   public/build/assets/app-xyz789.js  150.20 kB │ gzip: 42.30 kB
#   ✓ built in 1.5s
```

```json
// public/build/manifest.json — mapping file asli ke versi hash
{
    "resources/css/app.css": {
        "file": "assets/app-abc123.css",
        "isEntry": true,
        "src": "resources/css/app.css"
    },
    "resources/js/app.js": {
        "file": "assets/app-xyz789.js",
        "isEntry": true,
        "src": "resources/js/app.js"
    }
}
```

```php
// @vite secara otomatis membaca manifest.json untuk production
<!-- <link rel="stylesheet" href="/build/assets/app-abc123.css"> -->
<!-- <script type="module" src="/build/assets/app-xyz789.js"></script> -->
```

## Kasus Penggunaan Nyata
Sebelum deploy ke server production — semua file CSS/JS dioptimasi untuk kecepatan loading. File lebih kecil, cache friendly, dan siap untuk performa tinggi.
