# 102. vite.config.js Project Laravel

## Definisi Singkat
`vite.config.js` adalah file konfigurasi Vite di root proyek Laravel. File ini mengatur entry point CSS/JS, plugin, proxy, dan pengaturan build.

## Analogi
Seperti **papan control panel** di studio musik. Anda atur input (mikrofon), efek (plugin), dan output (speaker). `vite.config.js` mengatur bagaimana file mentah diproses menjadi file siap pakai.

## Poin-Poin Penting
- Terletak di root proyek Laravel
- Plugin `laravel-vite-plugin` wajib untuk integrasi Laravel
- `input` — array entry point (CSS, JS)
- `refresh` — true agar browser refresh saat file Blade berubah
- Saat development, Vite jalan di port 5173
- Saat build, output ke `public/build/`

## Contoh Konfigurasi
```javascript
// vite.config.js
import { defineConfig } from 'vite';
import laravel from 'laravel-vite-plugin';

export default defineConfig({
    plugins: [
        laravel({
            // Entry point CSS dan JS
            input: [
                'resources/css/app.css',
                'resources/js/app.js',
            ],
            // Auto refresh browser saat Blade/view berubah
            refresh: true,
        }),
    ],
    // Konfigurasi tambahan
    server: {
        // Ganti port development
        port: 3333,
        // Proxy API requests ke Laravel
        proxy: {
            '/api': 'http://localhost:8000',
        },
    },
    build: {
        // Output ke folder tertentu
        outDir: 'public/build',
        // Nonaktifkan source map di production
        sourcemap: false,
    },
});
```

## Kasus Penggunaan Nyata
Setup awal proyek Laravel — atur entry point CSS/JS, tambahkan framework (React/Vue) via plugin Vite, atur proxy untuk API development.
