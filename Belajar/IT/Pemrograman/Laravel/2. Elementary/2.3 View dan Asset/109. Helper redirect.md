# 109. Helper Redirect

## Definisi Singkat
`redirect()` mengarahkan pengguna ke URL lain. Helper ini mencakup redirect ke route, ke halaman sebelumnya, ke URL eksternal, dengan flash message.

## Analogi
Seperti **petugas bandara yang mengarahkan penumpang**. "Gate 5" = redirect('/flights'). "Maaf, Anda salah gate" = redirect()->back().

## Poin-Poin Penting
- `redirect('/path')` — redirect ke URL
- `redirect()->route('name')` — redirect ke named route
- `redirect()->action([Controller::class, 'method'])` — redirect ke action
- `redirect()->back()` — kembali ke halaman sebelumnya
- `redirect()->away('https://external.com')` — URL eksternal
- `with('key', 'value')` — flash message ke session

## Contoh Kode
```php
// app/Http/Controllers/AuthController.php
namespace App\Http\Controllers;

use Illuminate\Http\Request;

class AuthController extends Controller
{
    public function login(Request $request)
    {
        if (Auth::attempt($request->only('email', 'password'))) {
            // Redirect ke named route + flash message
            return redirect()
                ->route('dashboard')
                ->with('success', 'Login berhasil!');
        }

        // Redirect kembali ke form + error
        return redirect()
            ->back()
            ->withInput() // simpan input lama
            ->withErrors(['email' => 'Kredensial tidak valid']);
    }

    public function logout()
    {
        Auth::logout();

        // Redirect ke halaman home
        return redirect('/');
    }

    public function externalRedirect()
    {
        // Redirect ke URL eksternal
        return redirect()->away('https://payment-gateway.com/pay/123');
    }

    public function register()
    {
        return redirect()
            ->action([ProfileController::class, 'create'])
            ->with('info', 'Lengkapi profil Anda');
    }
}
```

## Kasus Penggunaan Nyata
Setelah login/logout, setelah submit form (redirect ke halaman detail), redirect jika user tidak punya akses, setelah checkout (redirect ke payment gateway).
