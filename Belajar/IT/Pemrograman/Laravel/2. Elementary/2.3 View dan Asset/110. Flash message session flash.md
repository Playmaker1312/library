# 110. Flash Message / Session Flash

## Definisi Singkat
Flash message adalah data session yang hanya tersedia untuk **satu request berikutnya**. Biasanya digunakan untuk menampilkan notifikasi sukses/error setelah redirect.

## Analogi
Seperti **post-it temporary** di pintu. Anda tempel pesan "Pesanan berhasil!" di pintu. Orang yang lewat (request berikutnya) membaca dan pesannya langsung hilang. Tidak akan ada di hari berikutnya.

## Poin-Poin Penting
- `session()->flash('key', 'value')` — set flash message
- `redirect()->with('key', 'value')` — redirect dengan flash
- Flash hanya bertahan satu request setelahnya
- `session()->keep('key')` — pertahankan flash untuk request lain
- `session()->reflash()` — pertahankan semua flash
- Di Blade: `@if(session('success'))` — tampilkan pesan

## Contoh Kode
```php
// Controller — kirim flash message
class ProductController extends Controller
{
    public function store(Request $request)
    {
        Product::create($request->validated());

        // Flash message via redirect
        return redirect()
            ->route('products.index')
            ->with('success', 'Produk berhasil ditambahkan!');
    }

    public function update(Request $request, $id)
    {
        // Flash message langsung
        session()->flash('info', 'Produk diperbarui.');

        return redirect()->route('products.index');
    }

    public function destroy($id)
    {
        Product::destroy($id);

        // Flash dengan session()->flash()
        return redirect()
            ->route('products.index')
            ->with('error', 'Produk dihapus.');
    }
}
```

```php
<!-- resources/views/layouts/app.blade.php -->
<body>
    <!-- Flash message section — muncul sekali -->
    @if (session('success'))
        <div class="alert alert-success alert-dismissible">
            {{ session('success') }}
            <button type="button" class="btn-close" data-bs-dismiss="alert"></button>
        </div>
    @endif

    @if (session('error'))
        <div class="alert alert-danger">
            {{ session('error') }}
        </div>
    @endif

    @if (session('info'))
        <div class="alert alert-info">
            {{ session('info') }}
        </div>
    @endif

    @yield('content')
</body>
```

## Kasus Penggunaan Nyata
Notifikasi "Data berhasil disimpan" setelah create, "Berhasil dihapus" setelah delete, "Login berhasil", "Email terkirim", "Password diubah".
