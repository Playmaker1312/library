# 96. Helper View

## Definisi Singkat
`view()` adalah helper function global Laravel yang membuat instance View dan melewatkan data ke template Blade. Alternatif singkat dari `Illuminate\Support\Facades\View::make()`.

## Analogi
Seperti **remote TV** — Anda tekan tombol "view('home')" dan TV langsung menampilkan channel yang diminta. Tidak perlu memutar kenop manual.

## Poin-Poin Penting
- `view('nama.view')` — memuat file Blade dari `resources/views/`
- Parameter kedua: array data `['key' => 'value']`
- Parameter ketiga: data tambahan (merge)
- Method chaining: `->with('key', 'value')`
- Juga bisa: `View::make('nama.view', $data)` — facade

## Contoh Kode
```php
// app/Http/Controllers/PageController.php
namespace App\Http\Controllers;

use App\Models\Article;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\View;

class PageController extends Controller
{
    public function home()
    {
        // Helper view — cara paling umum
        return view('pages.home', [
            'title' => 'Selamat Datang',
            'articles' => Article::latest()->take(3)->get(),
        ]);
    }

    public function about()
    {
        // Compact — shortcut laravel
        $company = 'PT Maju Jaya';
        $since = 2010;
        return view('pages.about', compact('company', 'since'));
    }

    public function contact()
    {
        // Method chaining with
        return view('pages.contact')
            ->with('email', 'info@example.com')
            ->with('phone', '021-1234567');
    }

    public function dashboard()
    {
        // Facade View::make
        return View::make('admin.dashboard', [
            'stats' => $this->getStats(),
        ]);
    }
}
```

## Kasus Penggunaan Nyata
Setiap halaman yang dikembalikan controller pasti menggunakan `view()` — halaman home, profil, daftar produk, dashboard admin.
