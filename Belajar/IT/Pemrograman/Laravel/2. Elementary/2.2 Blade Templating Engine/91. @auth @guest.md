# 91. @auth @guest

## Definisi Singkat
`@auth` menampilkan konten jika user **sedang login**. `@guest` menampilkan konten jika user **belum login** (tamu). Keduanya berbasis facade Auth Laravel.

## Analogi
Seperti **pintu klub VIP**: `@auth` = area dalam klub (hanya anggota). `@guest` = area luar klub (semua orang, termasuk yang bukan anggota).

## Poin-Poin Penting
- `@auth` — jika user terautentikasi
- `@guest` — jika user TIDAK terautentikasi
- Bisa spesifik guard: `@auth('admin')`, `@guest('admin')`
- Ditutup dengan `@endauth` dan `@endguest`
- Alternatif: `@if(Auth::check())` dan `@if(Auth::guest())`

## Contoh Kode
```php
<!-- Navigasi kondisional berdasarkan login -->
<nav>
    <a href="/">Home</a>

    @auth
        <a href="/dashboard">Dashboard</a>
        <a href="/profile">Profil Saya</a>
        <form action="/logout" method="POST">
            @csrf
            <button type="submit">Logout ({{ Auth::user()->name }})</button>
        </form>
    @endauth

    @guest
        <a href="/login">Login</a>
        <a href="/register">Daftar</a>
    @endguest
</nav>

<!-- Guard spesifik — multi-auth -->
@auth('admin')
    <a href="/admin">Panel Admin</a>
@endauth

@auth('writer')
    <a href="/writer/posts">Tulisan Saya</a>
@endauth
```

## Kasus Penggunaan Nyata
Menu navigasi yang berbeda untuk login/logout, tombol "Tambah ke keranjang" hanya untuk member, profil user, form komentar hanya untuk user terdaftar.
