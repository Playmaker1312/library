# 82. @isset @empty

## Definisi Singkat
`@isset` mengecek apakah variabel **ada dan tidak null**. `@empty` mengecek apakah variabel **kosong** (null, string kosong, array kosong, 0, false).

## Analogi
- @isset: seperti **mengecek apakah kunci ada di gantungan**. Kalau ada, ambil.
- @empty: seperti **mengecek gelas**. Apakah kosong, setengah, atau penuh?

## Poin-Poin Penting
- `@isset($var)` = `if(isset($var))` — cek ada dan tidak null
- `@empty($var)` = `if(empty($var))` — cek kosong
- Keduanya mencegah error "Undefined variable"
- Ditutup dengan `@endisset` dan `@endempty`
- `@empty` anggap 0, '0', '', [], null, false sebagai kosong

## Contoh Kode
```php
<!-- @isset — tampilkan hanya jika variabel ADA -->
@isset($profile)
    <div class="profile-card">
        <h2>{{ $profile->name }}</h2>
        <p>{{ $profile->bio }}</p>
    </div>
@endisset

<!-- @empty — tampilkan jika variabel KOSONG -->
@empty($cart->items)
    <div class="empty-cart">
        <p>Keranjang belanja Anda kosong.</p>
        <a href="/products">Belanja Sekarang</a>
    </div>
@endempty

<!-- Kombinasi: -->
@isset($users)
    @empty($users)
        <p>Tidak ada user ditemukan.</p>
    @else
        <ul>
            @foreach ($users as $user)
                <li>{{ $user->name }}</li>
            @endforeach
        </ul>
    @endempty
@endisset
```

## Kasus Penggunaan Nyata
Cek apakah data ada sebelum ditampilkan (misal foto profil), tampilkan pesan "keranjang kosong", cek apakah koleksi data kosong setelah filter.
