# 94. @method Spoofing

## Definisi Singkat
Karena HTML form hanya mendukung GET dan POST, `@method('PUT')` (atau PATCH/DELETE) memberitahu Laravel untuk memperlakukan request sebagai method HTTP yang berbeda — disebut method spoofing.

## Analogi
Seperti **surat izin yang ditulis manual**. Form HTML cuma bisa GET/POST. Tapi dengan `@method` Anda menempel stiker "sebenarnya ini PUT" di amplop POST, dan Laravel membaca stiker itu.

## Poin-Poin Penting
- HTML form hanya mendukung GET dan POST
- `@method('PUT')` — membuat hidden input `_method=PUT`
- Laravel membaca `_method` dan memperlakukan sesuai
- Method yang bisa di-spoof: PUT, PATCH, DELETE
- Harus disertai `@csrf`
- Biasa dipakai di form update dan delete

## Contoh Kode
```php
<!-- Form UPDATE -->
<form action="/posts/{{ $post->id }}" method="POST">
    @csrf
    @method('PUT')
    <!-- <input type="hidden" name="_method" value="PUT"> -->

    <input type="text" name="title" value="{{ $post->title }}">
    <textarea name="body">{{ $post->body }}</textarea>
    <button type="submit">Update Post</button>
</form>

<!-- Form DELETE -->
<form action="/posts/{{ $post->id }}" method="POST">
    @csrf
    @method('DELETE')

    <button type="submit" class="btn-danger"
            onclick="return confirm('Yakin?')">
        Hapus Post
    </button>
</form>

<!-- Form PATCH -->
<form action="/posts/{{ $post->id }}" method="POST">
    @csrf
    @method('PATCH')

    <input type="checkbox" name="published"
           {{ $post->published ? 'checked' : '' }}>
    <button type="submit">Simpan Perubahan</button>
</form>
```

```php
<!-- routes/web.php — route menangani method asli -->
Route::put('/posts/{post}', [PostController::class, 'update']);
Route::delete('/posts/{post}', [PostController::class, 'destroy']);
```

## Kasus Penggunaan Nyata
Form edit data (PUT/PATCH), tombol hapus (DELETE), update status parsial (PATCH), form setting.
