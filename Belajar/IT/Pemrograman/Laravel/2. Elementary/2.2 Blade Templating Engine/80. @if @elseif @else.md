# 80. @if @elseif @else

## Definisi Singkat
`@if`, `@elseif`, `@else`, dan `@endif` adalah direktif Blade untukpercabangan (kondisional). Mirip dengan `if-elseif-else` PHP tetapi dengan sintaks yang lebih bersih.

## Analogi
Seperti **lampu lalu lintas**: Jika (if) hijau → jalan. Jika tidak (elseif) kuning → hati-hati. Selain itu (else) → berhenti.

## Poin-Poin Penting
- `@if(condition)` — jika kondisi true
- `@elseif(condition)` — kondisi alternatif
- `@else` — fallback jika semua false
- `@endif` — penutup
- Bisa menggunakan operator logika: `&&`, `||`, `!`
- Blade tidak butuh `<?php ?>` — langsung `@if`

## Contoh Kode
```php
@if ($score >= 90)
    <span class="grade-a">Nilai A — Luar biasa!</span>
@elseif ($score >= 75)
    <span class="grade-b">Nilai B — Baik</span>
@elseif ($score >= 60)
    <span class="grade-c">Nilai C — Cukup</span>
@else
    <span class="grade-d">Nilai D — Perlu perbaikan</span>
@endif

<!-- Operator logika -->
@if ($user->isAdmin() && $user->isActive())
    <a href="/admin">Panel Admin</a>
@endif

<!-- Kondisi negatif -->
@if (!$errors->any())
    <p class="success">Tidak ada error!</p>
@endif
```

## Kasus Penggunaan Nyata
Status pesanan (pending/diproses/selesai), role user (admin/user/guest), tampilkan error/success message, menu kondisional berdasarkan login.
