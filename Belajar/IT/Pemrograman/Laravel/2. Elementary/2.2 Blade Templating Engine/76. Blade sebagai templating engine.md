# 76. Blade sebagai Templating Engine

## Definisi Singkat
Blade adalah templating engine bawaan Laravel yang memungkinkan penulisan HTML dengan sintaks PHP yang bersih, efisien, dan ekspresif. File Blade dikompilasi menjadi PHP murni dan di-cache untuk performa.

## Analogi
Seperti **stempel khusus**. Daripada menulis tangan setiap dokumen (HTML murni), Anda buat stempel (Blade) dengan format yang bisa diisi variabel, diulang, dan diatur — cepat dan konsisten.

## Poin-Poin Penting
- File berekstensi `.blade.php` di folder `resources/views/`
- Sintaks `{{ $variabel }}` untuk output otomatis di-escape
- Mendukung control structures: @if, @foreach, @while, dll
- Template inheritance: @extends, @section, @yield
- Component & slot: @component, @slot
- Tidak memperlambat app — hasil kompilasi di-cache

## Contoh Kode
```php
<!-- resources/views/welcome.blade.php -->
<!DOCTYPE html>
<html>
<head>
    <title>{{ $title }}</title>
</head>
<body>
    <h1>Halo, {{ $name }}!</h1>

    @if ($notifications > 0)
        <p>Anda punya {{ $notifications }} notifikasi</p>
    @else
        <p>Tidak ada notifikasi</p>
    @endif
</body>
</html>
```

```php
// Controller
public function welcome()
{
    return view('welcome', [
        'title' => 'Selamat Datang',
        'name' => 'Budi',
        'notifications' => 3,
    ]);
}
```

## Kasus Penggunaan Nyata
Semua halaman HTML di Laravel menggunakan Blade — layout website, email template, PDF, komponen UI yang bisa dipakai ulang.
