# 93. @csrf

## Definisi Singkat
`@csrf` menghasilkan hidden input token CSRF (Cross-Site Request Forgery) yang otomatis divalidasi Laravel untuk setiap request POST, PUT, PATCH, DELETE — melindungi aplikasi dari serangan CSRF.

## Analogi
Seperti **tanda tangan digital** di setiap cek. Bank (Laravel) hanya memproses cek yang ada tanda tangannya. Token CSRF = tanda tangan unik yang hanya dimiliki aplikasi Anda.

## Poin-Poin Penting
- Wajib disertakan di setiap form HTML yang method-nya bukan GET
- Jika lupa @csrf → error 419 Page Expired
- Token otomatis digenerate per session
- Untuk API/SPA, token dikirim via header `X-CSRF-TOKEN`
- Laravel otomatis validasi token untuk semua request POST/PUT/PATCH/DELETE

## Contoh Kode
```php
<!-- ✅ WAJIB @csrf di form POST -->
<form action="/posts" method="POST">
    @csrf
    <!-- <input type="hidden" name="_token" value="abc123..."> -->
    <input type="text" name="title" placeholder="Judul">
    <button type="submit">Simpan</button>
</form>

<!-- Method DELETE dengan @csrf -->
<form action="/posts/{{ $post->id }}" method="POST">
    @csrf
    @method('DELETE')
    <button type="submit">Hapus Post</button>
</form>

<!-- Ajax request — kirim token di header -->
<script>
    fetch('/api/posts', {
        method: 'POST',
        headers: {
            'X-CSRF-TOKEN': document.querySelector(
                'meta[name="csrf-token"]'
            ).content,
            'Content-Type': 'application/json'
        },
        body: JSON.stringify({ title: 'Post Baru' })
    });
</script>
```

```php
<!-- Tanpa @csrf → error 419 -->
<form action="/posts" method="POST">
    <!-- Lupa @csrf → 419 Page Expired -->
    <input type="text" name="title">
    <button type="submit">Simpan</button>
</form>
```

## Kasus Penggunaan Nyata
Semua form yang mengubah data: form registrasi, login, tambah/edit produk, hapus komentar, upload file, setting profil.
