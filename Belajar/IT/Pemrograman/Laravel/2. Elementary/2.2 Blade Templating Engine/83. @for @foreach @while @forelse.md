# 83. @for @foreach @while @forelse

## Definisi Singkat
Direktif perulangan Blade: `@for` (hitungan pasti), `@foreach` (array/koleksi), `@while` (selama kondisi true), `@forelse` (foreach dengan fallback jika kosong).

## Analogi
- @for = **putaran mesin** — putar 10 kali, berhenti
- @foreach = **conveyor belt** — ambil setiap item satu per satu
- @while = **memancing** — terus casting selama ikan belum dapat
- @forelse = **conveyor + safety** — kalau belt kosong, kasih pesan

## Poin-Poin Penting
- `@for($i=0; $i<10; $i++)` — perulangan dengan counter
- `@foreach($items as $item)` — iterasi tiap item
- `@while(condition)` — selama kondisi true
- `@forelse($items as $item)` — @foreach dengan @empty built-in
- Semua ditutup dengan `@endfor`, `@endforeach`, `@endwhile`, `@endforelse`

## Contoh Kode
```php
<!-- @for — perulangan jumlah pasti -->
@for ($i = 1; $i <= 5; $i++)
    <p>Baris nomor {{ $i }}</p>
@endfor

<!-- @foreach — iterasi koleksi -->
@foreach ($products as $product)
    <div class="product">
        <h3>{{ $product->name }}</h3>
        <p>Rp {{ number_format($product->price, 0, ',', '.') }}</p>
    </div>
@endforeach

<!-- @while — selama kondisi true -->
@while ($remaining > 0)
    <p>Sisa stok: {{ $remaining }}</p>
    @php $remaining--; @endphp
@endwhile

<!-- @forelse — foreach dengan fallback -->
@forelse ($notifications as $notification)
    <div class="notification">
        {{ $notification->message }}
    </div>
@empty
    <p class="text-muted">Tidak ada notifikasi.</p>
@endforelse
```

## Kasus Penggunaan Nyata
@for: pagination sederhana, kalender. @foreach: daftar produk, tabel data. @while: progress bar. @forelse: daftar komentar, notifikasi, pesan inbox.
