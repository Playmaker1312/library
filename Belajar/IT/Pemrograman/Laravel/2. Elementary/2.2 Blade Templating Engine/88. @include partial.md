# 88. @include Partial

## Definisi Singkat
`@include('nama.view')` menyisipkan file Blade lain ke dalam view saat ini. Berguna untuk memecah komponen kecil yang dipakai berulang.

## Analogi
Seperti **blok Lego**. Daripada membuat roda dari nol setiap kali, Anda tinggal ambil blok roda yang sudah jadi dan pasang ke mobil. @include = pasang blok yang sudah siap.

## Poin-Poin Penting
- `@include('nama.view')` — sisipkan view dari `resources/views/`
- Bisa kirim data tambahan: `@include('view', ['key' => 'value'])`
- View partial otomatis punya akses ke semua data view induk
- Jika file tidak ada → error. Gunakan `@includeIf` untuk cek dulu
- `@includeWhen($cond, 'view')` — include bersyarat
- `@includeFirst(['view1', 'view2'])` — coba view pertama, jika tidak ada pakai kedua

## Contoh Kode
```php
<!-- resources/views/partials/header.blade.php -->
<header>
    <h1>{{ $appName ?? 'My App' }}</h1>
    <nav>
        <a href="/">Home</a>
        <a href="/about">About</a>
        @auth
            <a href="/dashboard">Dashboard</a>
        @endauth
    </nav>
</header>
```

```php
<!-- resources/views/layouts/app.blade.php -->
<body>
    @include('partials.header', ['appName' => 'Toko Online'])

    <main>
        @yield('content')
    </main>

    @includeIf('partials.footer')
    <!-- Tidak error jika footer.blade.php tidak ada -->

    @includeWhen(Auth::check(), 'partials.admin-menu')
    <!-- Hanya include jika user login -->
</body>
```

```php
<!-- resources/views/user-card.blade.php -->
<div class="card">
    <h3>{{ $user->name }}</h3>
    <p>{{ $user->email }}</p>
</div>

<!-- Dipanggil dengan data tambahan: -->
@include('user-card', ['user' => $profileUser])
```

## Kasus Penggunaan Nyata
Header/footer global, kartu user/item, form snippet, navigasi, alert/notification komponen, meta tags.
