# 79. Escaped vs Unescaped

## Definisi Singkat
Blade memiliki dua sintaks output: `{{ $var }}` (escaped — aman) dan `{!! $var !!}` (unescaped — mentah). Escaped mengonversi karakter HTML, unescaped membiarkannya apa adanya.

## Analogi
Seperti **kemasan produk**:
- Escaped (`{{ }}`) = produk terbungkus rapat — isi aman terkendali
- Unescaped (`{!! !!}`) = produk terbuka — isi bisa apa saja, berbahaya jika salah

## Poin-Poin Penting
- `{{ }}` — panggil `htmlspecialchars()`, aman dari XSS
- `{!! !!}` — output mentah, TANPA escaping
- Hanya gunakan `{!! !!}` jika benar-benar yakin konten aman
- Sumber tepercaya untuk unescaped: konten dari admin/editor tepercaya
- JANGAN gunakan `{!! !!}` untuk konten input user (komentar, pesan, dll)

## Contoh Kode
```php
<!-- Controller mengirim: -->
<!-- $safe = "<strong>Tebal</strong>"; -->
<!-- $rich = "<script>alert('xss')</script>"; -->

<!-- Escaped — aman -->
<p>{{ $safe }}</p>
<!-- Output: &lt;strong&gt;Tebal&lt;/strong&gt; -->
<!-- Tag tidak jalan, tampil sebagai teks biasa -->

<!-- Unescaped — berbahaya jika konten tidak tepercaya -->
<p>{!! $safe !!}</p>
<!-- Output: <strong>Tebal</strong> → benar-benar tebal -->

<!-- Contoh di CMS: konten dari WYSIWYG editor -->
<article>
    <h1>{{ $article->title }}</h1>
    <div class="content">
        {!! $article->body !!}
        <!-- body dari admin tepercaya, pakai {!! !!} aman -->
    </div>
</article>
```

```php
<!-- Peringatan: JANGAN lakukan ini -->
<!-- {!! $userComment !!} — BAHAYA! User bisa inject script -->
```

## Kasus Penggunaan Nyata
- **Escaped**: semua data user, input form, komentar, pesan
- **Unescaped**: konten artikel dari CMS, HTML dari WYSIWYG editor, HTML yang dibuat sendiri
