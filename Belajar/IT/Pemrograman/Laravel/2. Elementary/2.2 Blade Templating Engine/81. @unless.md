# 81. @unless

## Definisi Singkat
`@unless` adalah kebalikan dari `@if` — menampilkan konten jika kondisi bernilai **false**. Membantu menulis logika negatif dengan lebih natural.

## Analogi
Seperti **tanda "DILARANG PARKIR"** — Anda hanya perlu tahu kondisi larangan, bukan area yang diizinkan. @unless berbunyi: "kecuali jika...".

## Poin-Poin Penting
- `@unless(kondisi)` = `@if(!kondisi)`
- Lebih intuitif untuk logika negatif
- Ditutup dengan `@endunless`
- Alternatif: `@if(!...)` atau `@if($kondisi === false)`

## Contoh Kode
```php
<!-- @unless = jalankan KECUALI kondisi true -->

@unless ($user->isBanned())
    <p>Selamat datang, {{ $user->name }}!</p>
@endunless

<!-- Sama dengan: -->
@if (!$user->isBanned())
    <p>Selamat datang, {{ $user->name }}!</p>
@endif

<!-- Contoh lain -->
@unless ($errors->any())
    <div class="alert alert-success">
        Tidak ada error validasi.
    </div>
@endunless

<!-- Bisa dengan else: -->
@unless ($user->hasVerifiedEmail())
    <p>Silakan verifikasi email Anda.</p>
@else
    <p>Email sudah terverifikasi.</p>
@endunless
```

## Kasus Penggunaan Nyata
Menampilkan konten hanya jika user tidak dibanned, menampilkan pesan sukses jika tidak ada error, menampilkan form login hanya jika user belum login.
