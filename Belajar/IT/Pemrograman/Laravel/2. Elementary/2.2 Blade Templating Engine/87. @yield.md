# 87. @yield

## Definisi Singkat
`@yield` digunakan di layout untuk mendefinisikan area yang akan diisi oleh halaman anak. Bisa juga memberikan konten default jika halaman anak tidak mengisi.

## Analogi
Seperti **stop kontak di dinding**. Layout menyediakan stop kontak (`@yield`), halaman anak tinggal colokkan perangkatnya (`@section`). Kalau tidak ada yang dicolok, stop kontak tetap ada tapi tidak beraliran listrik (atau pakai adaptor default).

## Poin-Poin Penting
- `@yield('nama')` — area yang akan diisi halaman anak
- `@yield('nama', 'default')` — dengan konten default
- Halaman anak mengisi dengan `@section('nama') ... @endsection`
- Bisa multiple yield: content, sidebar, scripts, styles
- `@yield` sekali panggil, `@section` bisa append dengan `@parent`

## Contoh Kode
```php
<!-- resources/views/layouts/main.blade.php -->
<!DOCTYPE html>
<html>
<head>
    <title>@yield('title', 'Default Title')</title>
    <!-- Yield untuk CSS tambahan -->
    @yield('head')
</head>
<body>
    <header>
        <h1>@yield('header', 'My Website')</h1>
    </header>

    <div class="container">
        <!-- Yield konten utama — WAJIB diisi -->
        @yield('content')
    </div>

    <aside>
        <!-- Yield sidebar — optional, punya default -->
        @yield('sidebar', '<p>Sidebar default</p>')
    </aside>

    <!-- Yield untuk JavaScript di akhir body -->
    @yield('scripts')
</body>
</html>
```

```php
<!-- Halaman anak bisa mengisi sebagian atau semua yield -->
@extends('layouts.main')

@section('title', 'Tentang Kami')

@section('content')
    <h2>Tentang Perusahaan</h2>
    <p>Kami bergerak di bidang teknologi.</p>
@endsection

<!-- Tidak mengisi @sidebar → pakai default -->
<!-- Tidak mengisi @scripts → tidak ada JS tambahan -->
```

## Kasus Penggunaan Nyata
Mendefinisikan placeholder untuk title, meta tags, konten, sidebar, CSS/JS tambahan di layout template.
