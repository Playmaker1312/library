# 77. File Blade PHP

## Definisi Singkat
File Blade adalah file template dengan ekstensi `.blade.php` yang ditempatkan di `resources/views/`. Blade otomatis memproses sintaks khusus sebelum dikirim sebagai HTML.

## Analogi
Seperti **resep masakan** — resep (file .blade.php) berisi instruksi bahan (variabel) dan langkah (logic). Dapur (Blade engine) memasaknya jadi hidangan siap santap (HTML).

## Poin-Poin Penting
- Ekstensi: `nama_file.blade.php`
- Lokasi: `resources/views/`
- Subfolder = dot notation: `resources/views/admin/dashboard.blade.php` → `admin.dashboard`
- Bisa pakai PHP murni di dalam file Blade jika perlu
- File di-cache di `storage/framework/views/` untuk performa
- Ubah file Blade → cache otomatis dihapus

## Contoh Kode
```php
<!-- resources/views/admin/dashboard.blade.php -->
@extends('layouts.admin')

@section('content')
    <h1>Dashboard Admin</h1>
    <p>Selamat datang, {{ Auth::user()->name }}</p>

    @php
        // PHP murni bisa digunakan jika perlu
        $stats = Cache::get('dashboard_stats', []);
    @endphp

    <div class="stats">
        @foreach ($stats as $key => $value)
            <div class="stat-card">
                <strong>{{ $key }}:</strong> {{ $value }}
            </div>
        @endforeach
    </div>
@endsection
```

```php
// Controller memanggilnya dengan dot notation
public function dashboard()
{
    return view('admin.dashboard', $data);
}
```

## Kasus Penggunaan Nyata
Setiap halaman di aplikasi Laravel — halaman user, admin panel, email template, komponen UI — semuanya adalah file `.blade.php`.
