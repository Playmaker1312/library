# 85. @switch @case

## Definisi Singkat
`@switch` adalah direktif Blade untuk percabangan multi-kondisi yang lebih rapi dibanding `@if` bertumpuk. Setiap `@case` mewakili satu kemungkinan nilai.

## Analogi
Seperti **mesin penjual minuman**: Anda pilih tombol A (cola), B(soda), C (jus). Mesin cek tombol mana yang ditekan dan keluarkan minuman sesuai — lebih terstruktur daripada if-elseif panjang.

## Poin-Poin Penting
- `@switch($var)` — variabel yang dicek
- `@case(value)` — kondisi spesifik
- `@break` — hentikan case, lanjut ke output
- `@default` — fallback jika tidak ada case cocok
- `@endswitch` — penutup

## Contoh Kode
```php
@switch($order->status)
    @case('pending')
        <span class="badge badge-warning">Menunggu Pembayaran</span>
    @break

    @case('processing')
        <span class="badge badge-info">Sedang Diproses</span>
    @break

    @case('shipped')
        <span class="badge badge-primary">Sedang Dikirim</span>
    @break

    @case('delivered')
        <span class="badge badge-success">Telah Diterima</span>
    @break

    @case('cancelled')
        <span class="badge badge-danger">Dibatalkan</span>
    @break

    @default
        <span class="badge badge-secondary">Status Tidak Diketahui</span>
@endswitch

<!-- Multiple case — Fallthrough (tanpa @break) -->
@switch($user->role)
    @case('superadmin')
    @case('admin')
        <p>Akses penuh ke panel admin</p>
    @break

    @case('editor')
        <p>Akses edit konten</p>
    @break

    @default
        <p>Akses terbatas</p>
@endswitch
```

## Kasus Penggunaan Nyata
Status order/transaksi, role user, tipe pembayaran, level log (info/warning/error), kode kategori.
