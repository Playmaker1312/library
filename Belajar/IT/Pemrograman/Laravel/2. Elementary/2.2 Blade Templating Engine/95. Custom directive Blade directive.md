# 95. Custom Directive Blade Directive

## Definisi Singkat
Blade memungkinkan Anda mendaftarkan direktif kustom sendiri melalui `Blade::directive()` di `AppServiceProvider::boot()`. Berguna untuk membuat shortcut sintaks yang sering dipakai.

## Analogi
Seperti **singkatan SMS**. Daripada menulis "Sampai Jumpa Lagi", Anda cukup tulis "SJL". Dengan custom directive, Anda buat singkatan untuk kode Blade yang panjang.

## Poin-Poin Penting
- Daftarkan di `AppServiceProvider::boot()` atau provider khusus
- `Blade::directive('nama', function($expr) { return "<?php ... ?>"; })`
- Fungsi harus mengembalikan string PHP yang valid
- Gunakan `<?php ?>` karena Blade kompilasi ke PHP murni
- Hati-hati dengan escaping expression
- Untuk direktif yang mengembalikan nilai, pertimbangkan `Blade::if()` untuk kondisional

## Contoh Kode
```php
// app/Providers/AppServiceProvider.php
namespace App\Providers;

use Illuminate\Support\Facades\Blade;
use Illuminate\Support\ServiceProvider;

class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        // Directive @money — format mata uang
        Blade::directive('money', function (string $expression) {
            // $expression adalah isi kurung: @money(150000)
            return "<?php echo 'Rp ' . number_format($expression, 0, ',', '.'); ?>";
        });

        // Directive @datetime — format tanggal Indonesia
        Blade::directive('datetime', function (string $expression) {
            return "<?php echo \Carbon\Carbon::parse($expression)
                ->locale('id')->translatedFormat('d F Y H:i'); ?>";
        });
    }
}
```

```php
<!-- Penggunaan di Blade -->
<p>Harga: @money(150000)</p>
<!-- Output: Rp 150.000 -->

<p>Dibuat: @datetime($post->created_at)</p>
<!-- Output: 15 Januari 2024 14:30 -->

<!-- Blade::if() — untuk direktif kondisional -->
// Di provider:
Blade::if('env', function (string $environment) {
    return app()->environment($environment);
});

// Di Blade:
@env('local')
    <p>Debug mode aktif</p>
@endenv
```

## Kasus Penggunaan Nyata
Format mata uang rupiah, tanggal Indonesia, status badge, cache-busting asset URL, direktif environment (local/production).
