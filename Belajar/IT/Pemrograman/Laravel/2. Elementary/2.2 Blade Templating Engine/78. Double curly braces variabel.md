# 78. Double Curly Braces Variabel

## Definisi Singkat
Sintaks `{{ $variabel }}` (double curly braces) digunakan untuk menampilkan variabel di Blade. Nilai otomatis di-escape terhadap XSS — aman dari serangan injeksi HTML/JavaScript.

## Analogi
Seperti **mesin fotokopi dengan filter keamanan**. Dokumen (variabel) difotokopi (ditampilkan), tapi semua tinta berbahaya (script, tag HTML) otomatis disaring.

## Poin-Poin Penting
- `{{ $name }}` → menampilkan nilai variabel `$name`
- Otomatis menjalankan `htmlspecialchars()` — aman dari XSS
- Bisa menampilkan hasil fungsi: `{{ time() }}`, `{{ strtoupper($name) }}`
- Bisa operator ternary: `{{ $age ?? 'Tidak diketahui' }}`
- Untuk tidak di-escape, gunakan `{!! $var !!}` (hati-hati)

## Contoh Kode
```php
<!-- resources/views/profile.blade.php -->
<div>
    <!-- Output aman: <script> menjadi &lt;script&gt; -->
    <p>Nama: {{ $name }}</p>

    <!-- Operasi dalam curly braces -->
    <p>Nama kapital: {{ strtoupper($name) }}</p>

    <!-- Nilai default dengan ?? -->
    <p>Umur: {{ $age ?? 'Tidak diisi' }}</p>

    <!-- Ternary -->
    <p>Status: {{ $isActive ? 'Aktif' : 'Nonaktif' }}</p>

    <!-- Function call -->
    <p>Waktu: {{ now()->format('d M Y') }}</p>
</div>
```

```php
// Jika $name = "<script>alert('xss')</script>"
// {{ $name }} akan menghasilkan:
// &lt;script&gt;alert('xss')&lt;/script&gt;
// Aman! Script tidak akan jalan.
```

## Kasus Penggunaan Nyata
Menampilkan data user, judul artikel, harga produk, tanggal, atau output apa pun dari controller/model — selalu gunakan `{{ }}` untuk keamanan.
