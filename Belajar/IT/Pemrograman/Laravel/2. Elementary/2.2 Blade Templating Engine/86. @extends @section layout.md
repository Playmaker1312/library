# 86. @extends @section Layout

## Definisi Singkat
`@extends` dan `@section` memungkinkan template inheritance — Anda buat layout induk, lalu halaman anak hanya mengisi bagian yang berbeda (seperti konten, sidebar, dll).

## Analogi
Seperti **cetak biru rumah**. Layout (cetak biru) punya tempat untuk dapur, kamar, ruang tamu. Setiap rumah (halaman) tinggal isi ruangannya — struktur bangunan tetap sama.

## Poin-Poin Penting
- Layout: file Blade berisi struktur HTML dengan `@yield` atau `@section` sebagai placeholder
- Halaman anak: `@extends('layout')` + `@section('nama')` untuk mengisi placeholder
- `@parent` — pertahankan konten default dari layout dan tambahkan
- Bisa nested: layout A → layout B → halaman

## Contoh Kode
```php
<!-- resources/views/layouts/app.blade.php — Layout Induk -->
<!DOCTYPE html>
<html>
<head>
    <title>@yield('title', 'My App')</title>
    <link rel="stylesheet" href="/css/app.css">
    @yield('styles')
</head>
<body>
    <nav>
        <!-- Navigasi tetap di semua halaman -->
        <a href="/">Home</a>
        <a href="/about">About</a>
    </nav>

    <main>
        @yield('content')
        <!-- Konten halaman akan muncul di sini -->
    </main>

    <footer>
        &copy; {{ date('Y') }} My App
    </footer>

    @yield('scripts')
</body>
</html>
```

```php
<!-- resources/views/home.blade.php — Halaman Anak -->
@extends('layouts.app')

@section('title', 'Halaman Home')

@section('content')
    <h1>Selamat Datang</h1>
    <p>Ini adalah halaman utama.</p>
@endsection

@section('styles')
    <style>
        .home { background: #f0f0f0; }
    </style>
@endsection
```

## Kasus Penggunaan Nyata
Semua halaman website dengan layout konsisten — admin panel, company profile, blog, e-commerce, dashboard.
