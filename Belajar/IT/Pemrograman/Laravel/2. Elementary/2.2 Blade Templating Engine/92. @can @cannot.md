# 92. @can @cannot

## Definisi Singkat
`@can` dan `@cannot` adalah direktif Blade untuk **otorisasi** — mengecek apakah user memiliki izin (permission) untuk melakukan aksi tertentu, berdasarkan Gate/Policy.

## Analogi
Seperti **KTP dan tiket konser**: Semua orang punya KTP (autentikasi = @auth), tapi hanya yang punya tiket VIP yang bisa masuk area backstage (otorisasi = @can).

## Poin-Poin Penting
- `@can('update', $post)` — cek apakah user bisa update post
- `@cannot('delete', $post)` — cek apakah user TIDAK bisa delete
- Bekerja dengan Gate dan Policy
- Parameter pertama: action name
- Parameter kedua: model instance (optional)
- `@canany(['update', 'delete'], $post)` — salah satu true
- Ditutup dengan `@endcan`, `@endcannot`

## Contoh Kode
```php
<!-- app/Policies/PostPolicy.php -->
public function update(User $user, Post $post)
{
    return $user->id === $post->user_id;
}

public function delete(User $user, Post $post)
{
    return $user->isAdmin() || $user->id === $post->user_id;
}
```

```php
<!-- Blade: Tampilkan tombol hanya jika berhak -->
<div class="post-actions">
    @can('update', $post)
        <a href="/posts/{{ $post->id }}/edit" class="btn-edit">
            Edit
        </a>
    @endcan

    @can('delete', $post)
        <form action="/posts/{{ $post->id }}" method="POST">
            @csrf
            @method('DELETE')
            <button type="submit" class="btn-delete">Hapus</button>
        </form>
    @else
        <p class="text-muted">Anda tidak bisa menghapus post ini.</p>
    @endcan

    @cannot('update', $post)
        <p>Post ini bukan milik Anda.</p>
    @endcannot
</div>

<!-- @canany — cek multiple permissions -->
@canany(['publish', 'approve'], $post)
    <button>Publikasikan</button>
@endcanany
```

## Kasus Penggunaan Nyata
Hanya penulis yang bisa edit/hapus artikelnya sendiri, admin bisa manage semua user, editor bisa approve komentar, viewer hanya bisa lihat.
