# 84. Loop Variabel: $loop, index, first, last

## Definisi Singkat
Di dalam perulangan `@foreach`, Blade menyediakan variabel `$loop` yang berisi informasi iterasi seperti index, apakah pertama, terakhir, jumlah total, dll.

## Analogi
Seperti **odometer mobil** — memberi tahu Anda putaran ke berapa, seberapa jauh, dan kapan sampai tujuan.

## Poin-Poin Penting
- `$loop->index` — index mulai dari 0
- `$loop->iteration` — iterasi ke-n mulai dari 1
- `$loop->first` — true jika iterasi pertama
- `$loop->last` — true jika iterasi terakhir
- `$loop->count` — total item
- `$loop->remaining` — sisa iterasi
- `$loop->depth` — level nested loop
- `$loop->parent` — akses $loop dari loop induk (nested)

## Contoh Kode
```php
<!-- @foreach dengan $loop -->
<ul>
@foreach ($users as $user)
    <li class="
        @if ($loop->first) first-item @endif
        @if ($loop->last) last-item @endif
        @if ($loop->even) even-row @endif
    ">
        {{ $loop->iteration }}. {{ $user->name }}
        ({{ $loop->remaining }} tersisa)
    </li>
@endforeach
</ul>

<!-- CSS khusus item pertama dan terakhir -->
@foreach ($posts as $post)
    @if ($loop->first)
        <div class="featured-post">
            <h1>{{ $post->title }}</h1>
        </div>
    @else
        <div class="regular-post">
            <h2>{{ $post->title }}</h2>
        </div>
    @endif
@endforeach

<!-- Nested loop -->
@foreach ($categories as $category)
    <h3>{{ $category->name }}</h3>
    <ul>
    @foreach ($category->items as $item)
        <li>
            Induk: {{ $loop->parent->iteration }},
            Anak: {{ $loop->iteration }}
        </li>
    @endforeach
    </ul>
@endforeach
```

## Kasus Penggunaan Nyata
Memberi class CSS berbeda untuk item pertama/terakhir, numbering otomatis, zebra striping tabel, featured vs regular post.
