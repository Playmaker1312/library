# 89. @component Komponen Terstruktur

## Definisi Singkat
`@component` adalah cara Blade untuk membuat komponen UI terstruktur dengan template sendiri dan data yang dilewatkan. Lebih rapi daripada @include untuk komponen kompleks.

## Analogi
Seperti **cetakan kue kering**. Anda punya cetakan (komponen) berbentuk bintang. Tinggal tekan adonan (data) ke cetakan, hasilnya kue bintang yang konsisten. Setiap cetakan punya desain sendiri.

## Poin-Poin Penting
- Letakkan komponen di `resources/views/components/`
- Panggil: `@component('components.alert', ['type' => 'success'])`
- Di dalam file komponen, gunakan `$slot` dan `$namaParameter`
- `$slot` menampung konten di antara `@component` dan `@endcomponent`
- Bisa ada multiple slot dengan `@slot('nama')`
- Di Laravel 7+ lebih disarankan pakai Blade Component (class)

## Contoh Kode
```php
<!-- resources/views/components/alert.blade.php -->
<div class="alert alert-{{ $type ?? 'info' }}" role="alert">
    <strong>{{ $title ?? 'Info' }}</strong>
    {{ $slot }}
    <!-- $slot berisi konten di antara @component ... @endcomponent -->
</div>
```

```php
<!-- Memanggil komponen -->
@component('components.alert', ['type' => 'success', 'title' => 'Berhasil!'])
    Data Anda telah tersimpan.
@endcomponent

<!-- Tanpa title → pakai default 'Info' -->
@component('components.alert', ['type' => 'warning'])
    Harap periksa kembali data Anda.
@endcomponent

<!-- Output HTML:
<div class="alert alert-success" role="alert">
    <strong>Berhasil!</strong>
    Data Anda telah tersimpan.
</div>
-->
```

```php
<!-- Alternatif dengan @include (kurang terstruktur) -->
@include('components.alert', [
    'type' => 'success',
    'slot' => 'Data tersimpan'
])
```

## Kasus Penggunaan Nyata
Alert box, card UI, modal dialog, button dengan style konsisten, panel info — komponen UI yang dipakai berulang dengan variasi data.
