# 90. @slot Komponen Blade

## Definisi Singkat
`@slot` adalah direktif untuk mendefinisikan beberapa area konten (named slots) dalam satu komponen. Memungkinkan komponen memiliki header, body, footer, dll — lebih dari satu `$slot`.

## Analogi
Seperti **bingkai foto dengan beberapa ruang**. Satu bingkai (komponen) punya tempat untuk foto utama ($slot), label judul (slot title), dan keterangan (slot caption). Setiap slot diisi terpisah.

## Poin-Poin Penting
- `$slot` — slot utama (default), konten di antara tag komponen
- `@slot('nama')` — named slot, untuk area spesifik
- Named slot diakses sebagai variabel terpisah di template komponen
- Bisa ada banyak slot dalam satu komponen
- Setiap slot bisa punya nilai default di template komponen

## Contoh Kode
```php
<!-- resources/views/components/card.blade.php -->
<div class="card">
    <div class="card-header">
        {{ $header ?? 'Card Header' }}
    </div>

    <div class="card-body">
        {{ $slot }}
        <!-- Slot utama — konten default -->
    </div>

    @isset($footer)
        <div class="card-footer">
            {{ $footer }}
        </div>
    @endisset
</div>
```

```php
<!-- Memanggil component dengan multiple slot -->
@component('components.card')
    @slot('header')
        <h2>Profil User</h2>
    @endslot

    <p>Nama: {{ $user->name }}</p>
    <p>Email: {{ $user->email }}</p>
    <!-- Ini masuk ke $slot utama -->

    @slot('footer')
        <small>Terakhir login: {{ $user->last_login }}</small>
    @endslot
@endcomponent

<!-- Output HTML:
<div class="card">
    <div class="card-header">
        <h2>Profil User</h2>
    </div>
    <div class="card-body">
        <p>Nama: Budi</p>
        <p>Email: budi@email.com</p>
    </div>
    <div class="card-footer">
        <small>Terakhir login: 2024-01-15</small>
    </div>
</div>
-->
```

## Kasus Penggunaan Nyata
Card component dengan header/body/footer, modal dialog, panel dengan judul, layout form, komponen tabel dengan caption.
