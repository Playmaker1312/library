# 65. Resource Controller Flag Resource

## Definisi Singkat
Flag `--resource` pada `make:controller` otomatis membuat 7 method standar: `index`, `create`, `store`, `show`, `edit`, `update`, `destroy` — sesuai pola CRUD.

## Analogi
Seperti **paket makanan kombo** di restoran. Daripada memesan satu per satu (membuat method manual), Anda pesan paket combo yang sudah berisi semua item lengkap.

## Poin-Poin Penting
- Jalankan: `php artisan make:controller PhotoController --resource`
- Menghasilkan 7 method sekaligus, lengkap dengan DocBlock
- Method sudah sesuai dengan konvensi RESTful Laravel
- Sangat menghemat waktu untuk resource CRUD standar
- Bisa dikombinasikan dengan `--model` untuk membuat Model sekaligus

## Kasus Penggunaan Nyata
Fitur CRUD standar seperti manajemen artikel, produk, kategori, pengguna — semuanya sempurna menggunakan Resource Controller.
