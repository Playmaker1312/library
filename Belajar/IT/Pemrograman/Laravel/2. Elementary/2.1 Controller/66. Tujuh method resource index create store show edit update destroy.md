# 66. Tujuh Method Resource: index, create, store, show, edit, update, destroy

## Definisi Singkat
Tujuh method standar yang mewakili operasi CRUD (Create, Read, Update, Delete) lengkap dengan halaman form.

## Analogi
Seperti **siklus hidup dokumen**: daftar semua (index), buka form baru (create), simpan (store), lihat detail (show), buka form edit (edit), perbarui (update), hapus (destroy).

## Poin-Poin Penting

| Method | HTTP | URL | Fungsi |
|--------|------|-----|--------|
| `index()` | GET | `/photos` | Daftar semua data |
| `create()` | GET | `/photos/create` | Form tambah data |
| `store()` | POST | `/photos` | Simpan data baru |
| `show($id)` | GET | `/photos/{id}` | Detail satu data |
| `edit($id)` | GET | `/photos/{id}/edit` | Form edit data |
| `update($id)` | PUT/PATCH | `/photos/{id}` | Perbarui data |
| `destroy($id)` | DELETE | `/photos/{id}` | Hapus data |

## Contoh Kode
```php
namespace App\Http\Controllers;

use App\Models\Photo;
use Illuminate\Http\Request;

class PhotoController extends Controller
{
    // GET /photos — tampilkan semua foto
    public function index()
    {
        $photos = Photo::latest()->paginate(10);
        return view('photos.index', compact('photos'));
    }

    // GET /photos/create — form upload foto
    public function create()
    {
        return view('photos.create');
    }

    // POST /photos — simpan foto baru
    public function store(Request $request)
    {
        $validated = $request->validate([
            'title' => 'required|max:255',
            'image' => 'required|image|mimes:jpg,png',
        ]);
        Photo::create($validated);
        return redirect('/photos')->with('success', 'Foto tersimpan');
    }

    // GET /photos/{id} — detail foto
    public function show($id)
    {
        $photo = Photo::findOrFail($id);
        return view('photos.show', compact('photo'));
    }

    // GET /photos/{id}/edit — form edit foto
    public function edit($id)
    {
        $photo = Photo::findOrFail($id);
        return view('photos.edit', compact('photo'));
    }

    // PUT/PATCH /photos/{id} — update foto
    public function update(Request $request, $id)
    {
        $photo = Photo::findOrFail($id);
        $photo->update($request->only('title'));
        return redirect('/photos')->with('success', 'Foto diupdate');
    }

    // DELETE /photos/{id} — hapus foto
    public function destroy($id)
    {
        Photo::destroy($id);
        return redirect('/photos')->with('success', 'Foto dihapus');
    }
}
```

## Kasus Penggunaan Nyata
Semua fitur kelola data: artikel blog, produk toko, daftar karyawan, manajemen inventaris — semuanya menggunakan 7 method ini.
