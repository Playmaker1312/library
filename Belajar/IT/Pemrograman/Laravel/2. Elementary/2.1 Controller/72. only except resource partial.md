# 72. only except Resource Partial

## Definisi Singkat
Method `only()` dan `except()` membatasi method resource yang akan dibuat route-nya. Berguna saat tidak membutuhkan semua 7 method.

## Analogi
Seperti **prasmanan** — Anda tidak wajib mengambil semua menu. `only()` seperti "saya ambil nasi, ayam, dan sayur saja". `except()` seperti "saya ambil semua kecuali sambal".

## Poin-Poin Penting
- `Route::resource()->only(['index', 'show'])` — hanya 2 method
- `Route::resource()->except(['create', 'edit'])` — semua kecuali create/edit
- `Route::apiResource()` otomatis exclude create/edit
- Gunakan saat resource read-only atau tidak butuh form
- Membuat route list lebih bersih dan aman

## Contoh Kode
```php
// routes/web.php
use App\Http\Controllers\PostController;
use App\Http\Controllers\CommentController;

// Hanya index dan show — read-only, tidak bisa create/edit
Route::resource('posts', PostController::class)
    ->only(['index', 'show']);

// Semua kecuali create dan edit — cocok untuk API
Route::resource('comments', CommentController::class)
    ->except(['create', 'edit']);

// Bisa juga untuk route group
Route::resource('photos', PhotoController::class)
    ->only(['index', 'store', 'destroy']);
```

```php
// Cek route yang aktif:
// php artisan route:list
// Hanya route yang diizinkan yang muncul
```

## Kasus Penggunaan Nyata
Resource read-only (portofolio, katalog publik), API backend tanpa form, resource yang hanya bisa dihapus admin, atau fitur yang belum perlu create/edit.
