# 71. Dependency Injection Method Controller

## Definisi Singkat
Selain constructor, dependency juga bisa di-inject langsung ke method controller — biasanya untuk Request atau service yang hanya dipakai satu method.

## Analogi
Seperti **alat sekali pakai di hotel** — sikat gigi, sisir, pasta gigi. Barang yang dipakai tamu satu kali, disediakan langsung saat dibutuhkan, bukan disimpan di kamar sepanjang tahun.

## Poin-Poin Penting
- Tipe-hint di parameter method, bukan constructor
- Laravel resolve otomatis tiap kali method dipanggil
- Method injection bisa digabung dengan parameter route
- Urutan: dependency di kiri, parameter route di kanan
- Paling umum: `Request $request` di method

## Contoh Kode
```php
namespace App\Http\Controllers;

use App\Services\PaymentService;
use App\Models\Order;
use Illuminate\Http\Request;

class PaymentController extends Controller
{
    // Inject Request + parameter route biasa
    public function process(Request $request, $orderId)
    {
        // $request langsung tersedia, tidak perlu buat manual
        $amount = $request->input('amount');
        // logic...
    }

    // Inject service langsung di method
    public function refund(Order $order, PaymentService $paymentService)
    {
        // Route model binding + method injection
        $result = $paymentService->refund($order);
        return response()->json($result);
    }
}
```

```php
// routes/web.php
Route::post('/payments/process/{orderId}', [PaymentController::class, 'process']);
Route::post('/payments/refund/{order}', [PaymentController::class, 'refund']);
```

## Kasus Penggunaan Nyata
`Request $request` di method store/update, service yang hanya dipakai method tertentu, atau utility class yang tidak perlu di-inject global.
