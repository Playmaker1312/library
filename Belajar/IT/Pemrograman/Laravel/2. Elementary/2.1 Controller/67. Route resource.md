# 67. Route Resource

## Definisi Singkat
`Route::resource()` membuat 7 route sekaligus yang terhubung ke 7 method resource controller secara otomatis.

## Analogi
Seperti **kabel jumper listrik** — sekali colok, semua koneksi terpasang. Anda tidak perlu memasang kabel satu per satu.

## Poin-Poin Penting
- Cukup satu baris: `Route::resource('photos', PhotoController::class)`
- Menghasilkan 7 route lengkap dengan nama route (route name)
- Nama route otomatis: `photos.index`, `photos.create`, `photos.store`, dll
- Bisa dibatasi dengan `only()` atau `except()`
- Lihat daftar route: `php artisan route:list`

## Contoh Kode
```php
// routes/web.php
use App\Http\Controllers\PhotoController;

// Satu baris ini setara dengan 7 route manual
Route::resource('photos', PhotoController::class);

// Setara dengan:
// GET       /photos              -> index   (photos.index)
// GET       /photos/create       -> create  (photos.create)
// POST      /photos              -> store   (photos.store)
// GET       /photos/{photo}      -> show    (photos.show)
// GET       /photos/{photo}/edit -> edit    (photos.edit)
// PUT/PATCH /photos/{photo}      -> update  (photos.update)
// DELETE    /photos/{photo}      -> destroy (photos.destroy)
```

```php
// Cek route di terminal:
// php artisan route:list

// Contoh output:
// GET|HEAD  photos               photos.index   PhotoController@index
// POST      photos               photos.store   PhotoController@store
// GET|HEAD  photos/create        photos.create  PhotoController@create
// GET|HEAD  photos/{photo}       photos.show    PhotoController@show
// ...
```

## Kasus Penggunaan Nyata
Setiap resource CRUD di aplikasi — postingan, produk, komentar, kategori — cukup daftarkan dengan `Route::resource()` dan semuanya terhubung otomatis.
