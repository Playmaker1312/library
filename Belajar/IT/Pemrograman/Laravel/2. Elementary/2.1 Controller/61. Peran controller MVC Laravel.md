# 61. Peran Controller MVC Laravel

## Definisi Singkat
Controller adalah penghubung antara **Model** (data/bisnis logic) dan **View** (tampilan). Controller menerima request dari Route, memprosesnya (biasanya dengan bantuan Model), lalu mengembalikan Response.

## Analogi
Seperti **pelayan restoran**. Pelayan menerima pesanan (Request) dari pelanggan, menyampaikan ke dapur (Model), lalu mengantar masakan (View) kembali ke pelanggan.

## Poin-Poin Penting
- Controller menjaga Route tetap ramping — tidak perlu logic di file route
- Memisahkan logic aplikasi dari presentasi
- Mengikuti prinsip **Separation of Concerns**
- Best practice: **Thin Controller, Fat Model** — simpan logic bisnis di Model
- Satu method dalam controller biasanya mewakili satu aksi

## Contoh Kode
```php
// app/Http/Controllers/UserController.php
namespace App\Http\Controllers;

use App\Models\User;
use Illuminate\Http\Request;

class UserController extends Controller
{
    // Satu method = satu aksi
    public function index()
    {
        $users = User::all();
        return view('users.index', compact('users'));
    }

    public function show($id)
    {
        $user = User::findOrFail($id);
        return view('users.show', compact('user'));
    }
}
```

## Kasus Penggunaan Nyata
Setiap fitur dalam aplikasi Laravel — manajemen user, blog, toko online, API — semuanya menggunakan Controller untuk mengorganisir logic berdasarkan sumber daya (resource).
