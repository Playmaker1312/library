# 64. Route ke Controller Method

## Definisi Singkat
Route di `routes/web.php` atau `routes/api.php` dipetakan ke method controller menggunakan sintaks array `[Controller::class, 'method']`.

## Analogi
Seperti **papan petunjuk arah**. Route adalah papan yang bertuliskan "Jalan A → Rumah B". Ketika pengunjung datang ke Jalan A (URL), mereka diarahkan ke Rumah B (controller method).

## Poin-Poin Penting
- Sintaks: `Route::get('/url', [NamaController::class, 'method'])`
- Gunakan `::class` untuk mendapatkan full namespace otomatis
- Bisa menggunakan string: `Route::get('/url', 'NamaController@method')` — tapi tidak direkomendasikan
- Parameter route otomatis diteruskan ke method controller
- Cocok untuk GET, POST, PUT, PATCH, DELETE

## Contoh Kode
```php
// routes/web.php
use App\Http\Controllers\ProductController;
use App\Http\Controllers\OrderController;

// Route ke method index
Route::get('/products', [ProductController::class, 'index']);

// Route dengan parameter {id}
Route::get('/products/{id}', [ProductController::class, 'show']);

// Route POST ke method store
Route::post('/products', [ProductController::class, 'store']);

// Route dengan parameter dikirim ke method
Route::get('/orders/{orderId}/items/{itemId}', [OrderController::class, 'showItem']);
```

```php
// app/Http/Controllers/OrderController.php
public function showItem($orderId, $itemId)
{
    return "Order: $orderId, Item: $itemId";
}
```

## Kasus Penggunaan Nyata
Semua URL di aplikasi Laravel dipetakan melalui route. Misalnya `/products` menampilkan daftar produk, `/products/5` menampilkan detail produk dengan ID 5.
