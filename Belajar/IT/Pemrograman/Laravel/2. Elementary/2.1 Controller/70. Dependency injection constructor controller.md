# 70. Dependency Injection Constructor Controller

## Definisi Singkat
Laravel otomatis menyuntikkan (inject) dependency ke constructor controller melalui **Service Container**. Dependency dijamin tersedia tanpa perlu membuat manual.

## Analogi
Seperti **restoran yang sudah menyediakan alat masak di dapur**. Koki (controller) tinggal pakai. Tidak perlu beli wajan sendiri.

## Poin-Poin Penting
- Tipe-hint dependency di parameter constructor
- Laravel akan resolve otomatis dari Service Container
- Cocok untuk service class yang dipakai banyak method
- Dependency hanya di-resolve sekali saat controller dibuat
- Bisa inject Model, Repository, Service, atau class lain

## Contoh Kode
```php
namespace App\Http\Controllers;

use App\Services\OrderService;
use App\Repositories\OrderRepository;
use Illuminate\Http\Request;

class OrderController extends Controller
{
    // Dependency di-inject via constructor
    protected $orderService;
    protected $orderRepo;

    public function __construct(
        OrderService $orderService,
        OrderRepository $orderRepo
    ) {
        // Laravel otomatis inject instance dari container
        $this->orderService = $orderService;
        $this->orderRepo = $orderRepo;
    }

    // Semua method bisa pakai dependency tanpa membuat ulang
    public function index()
    {
        $orders = $this->orderRepo->getAll();
        return view('orders.index', compact('orders'));
    }

    public function ship($id)
    {
        $this->orderService->shipOrder($id);
        return redirect('/orders')->with('success', 'Dikirim');
    }
}
```

## Kasus Penggunaan Nyata
Service class untuk logic bisnis kompleks, Repository untuk query database, Helper class untuk perhitungan/fungsi khusus, atau klien API eksternal.
