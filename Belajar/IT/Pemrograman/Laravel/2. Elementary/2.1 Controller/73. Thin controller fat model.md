# 73. Thin Controller Fat Model

## Definisi Singkat
Prinsip desain di mana controller hanya bertugas sebagai koordinator (tipis/ramping), sementara logic bisnis disimpan di Model (gemuk/berisi). Controller memanggil, Model mengerjakan.

## Analogi
Seperti **manajer dan karyawan**. Manajer (controller) hanya memberi perintah — "urus order ini". Karyawan (model) yang mengerjakan semua detailnya: validasi, hitung diskon, kirim email, update stok.

## Poin-Poin Penting
- Controller: hanya validasi input, panggil model, kembalikan response
- Model/Service: logic bisnis, perhitungan, query kompleks
- Keuntungan: DRY, mudah di-test, mudah diubah
- Tanda controller terlalu gemuk: banyak query, logic bersarang
- Gunakan Eloquent Scope, Accessor, Mutator, atau Service Class

## Contoh Kode
```php
// ❌ FAT CONTROLLER — jangan
class OrderController extends Controller
{
    public function store(Request $request)
    {
        $order = Order::create($request->validated());
        foreach ($request->items as $item) {
            $product = Product::find($item['product_id']);
            if ($product->stock < $item['qty']) {
                return back()->with('error', 'Stok tidak cukup');
            }
            $product->decrement('stock', $item['qty']);
            OrderItem::create([
                'order_id' => $order->id,
                'product_id' => $item['product_id'],
                'qty' => $item['qty'],
            ]);
        }
        $order->calculateTotal();
        return redirect()->route('orders.show', $order);
    }
}
```

```php
// ✅ THIN CONTROLLER — ideal
class OrderController extends Controller
{
    public function __construct(
        protected OrderService $orderService
    ) {}

    public function store(Request $request)
    {
        $order = $this->orderService->placeOrder(
            $request->validated()
        );
        return redirect()->route('orders.show', $order);
    }
}

// app/Services/OrderService.php
class OrderService
{
    public function placeOrder(array $data): Order
    {
        // Semua logic bisnis pindah ke sini
    }
}
```

## Kasus Penggunaan Nyata
Aplikasi dengan bisnis logic kompleks: e-commerce (hitung diskon, pajak, ongkir), sistem booking, manajemen inventory.
