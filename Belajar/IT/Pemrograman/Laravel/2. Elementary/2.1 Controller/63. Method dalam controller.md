# 63. Method dalam Controller

## Definisi Singkat
Method dalam controller adalah fungsi publik yang menangani request HTTP tertentu. Setiap method biasanya dipetakan ke satu route dan menjalankan satu tugas spesifik.

## Analogi
Seperti **tombol pada remote TV**. Setiap tombol (method) memiliki fungsi berbeda — volume naik, ganti channel, matikan — dan Anda tekan tombol (route) untuk menjalankannya.

## Poin-Poin Penting
- Method harus `public` agar bisa diakses Route
- Setiap method menerima Request (opsional) dan mengembalikan Response
- Nama method bebas, tapi ikuti konvensi resource bila memungkinkan
- Satu method = satu tanggung jawab (Single Responsibility)
- Method bisa mengembalikan view, redirect, JSON, atau response lainnya

## Contoh Kode
```php
namespace App\Http\Controllers;

use Illuminate\Http\Request;

class PageController extends Controller
{
    // Method menangani halaman home
    public function home()
    {
        return view('pages.home');
    }

    // Method dengan parameter dari route
    public function profile($username)
    {
        return view('pages.profile', compact('username'));
    }

    // Method dengan Request
    public function store(Request $request)
    {
        $title = $request->input('title');
        // simpan ke database...
        return redirect()->back()->with('success', 'Data tersimpan');
    }
}
```

## Kasus Penggunaan Nyata
Halaman statis (about, contact), form submission, dashboard admin — semua adalah method dalam controller yang dipanggil oleh route masing-masing.
