# 62. Membuat Basic Controller Artisan

## Definisi Singkat
Artisan CLI menyediakan perintah `make:controller` untuk membuat file controller secara otomatis, lengkap dengan namespace dan imports dasar.

## Analogi
Seperti **cetakan kue** — Anda tinggal tuang adonan, dan cetakan menghasilkan bentuk yang sudah jadi. Anda tidak perlu membuat bentuk dari nol.

## Poin-Poin Penting
- Gunakan `php artisan make:controller NamaController`
- Convention: PascalCase, akhiri dengan `Controller` (contoh: `ProductController`)
- File akan dibuat di `app/Http/Controllers/`
- Bisa buat subfolder: `make:controller Admin/DashboardController`
- Flag `--resource` untuk method resource (index, create, store, dll)
- Flag `--api` untuk API resource (tanpa create/edit)

## Contoh Kode
```php
// Terminal:
// php artisan make:controller ProductController
// php artisan make:controller Admin/DashboardController
// php artisan make:controller PhotoController --resource
// php artisan make:controller PhotoController --api

// Hasil: app/Http/Controllers/ProductController.php
namespace App\Http\Controllers;

use Illuminate\Http\Request;

class ProductController extends Controller
{
    // Masih kosong, tinggal diisi method
    public function index()
    {
        return view('products.index');
    }
}
```

## Kasus Penggunaan Nyata
Setiap kali Anda membuat fitur baru — misalnya fitur produk, kategori, atau order — Anda membuat controller baru dengan Artisan agar konsisten dan menghemat waktu.
