# 74. Route Model Binding Controller

## Definisi Singkat
Route Model Binding otomatis mengambil Model dari database berdasarkan ID (atau kolom lain) di URL, lalu menginjeksikan langsung ke method controller — tanpa perlu query manual.

## Analogi
Seperti **pramusaji yang sudah hafal meja pelanggan**. Ketika Anda bilang "meja 5", pramusaji langsung tahu persis siapa itu — tidak perlu cek satu per satu.

## Poin-Poin Penting
- Tipe-hint Model di parameter method dengan nama sama dengan segment route
- Laravel otomatis panggil `Model::findOrFail($id)`
- Jika tidak ditemukan, otomatis return 404
- Bisa bind ke kolom lain (bukan ID): `Route::get('/posts/{post:slug}')`
- Tersedia di controller, closure, dan route

## Contoh Kode
```php
// routes/web.php
use App\Models\Post;
use App\Models\User;

// Tanpa route model binding — manual
Route::get('/posts/{id}', function ($id) {
    $post = Post::findOrFail($id); // query manual
    return view('posts.show', compact('post'));
});

// Dengan route model binding — otomatis
Route::get('/posts/{post}', function (Post $post) {
    // $post sudah berisi Post::findOrFail($id)
    return view('posts.show', compact('post'));
});

// Controller dengan route model binding
Route::get('/users/{user}/posts/{post}', [PostController::class, 'showUserPost']);
```

```php
// app/Http/Controllers/PostController.php
class PostController extends Controller
{
    // $user dan $post sudah terisi dari database
    public function showUserPost(User $user, Post $post)
    {
        // Tidak perlu User::findOrFail() atau Post::findOrFail()
        return view('posts.show', compact('user', 'post'));
    }

    // Bind ke kolom 'slug' bukan 'id'
    public function showBySlug(Post $post)
    {
        // Route: /posts/{post:slug}
        // Laravel cari Post where('slug', $slug)
        return view('posts.show', compact('post'));
    }
}
```

## Kasus Penggunaan Nyata
Semua resource dengan parameter ID — detail artikel (`/posts/5`), profil user (`/users/john` menggunakan slug), product page (`/products/abc123`).
