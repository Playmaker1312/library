# 69. Single Action Controller Invoke

## Definisi Singkat
Single Action Controller adalah controller dengan hanya satu method `__invoke()` — menangani satu aksi spesifik. Cocok untuk halaman atau tugas sederhana.

## Analogi
Seperti **pisau lipat Swiss Army — mode pisau saja**. Tidak perlu membuka gunting, gergaji, dll. Satu alat untuk satu fungsi spesifik.

## Poin-Poin Penting
- Buat dengan: `php artisan make:controller NamaController --invokable`
- Hanya punya method `__invoke(Request $request)`
- Daftarkan route langsung ke controller (tanpa method)
- Ideal untuk halaman dashboard, form kontak, pencarian
- Menjaga controller tetap fokus dan ramping

## Contoh Kode
```php
// Terminal:
// php artisan make:controller DashboardController --invokable

namespace App\Http\Controllers;

use App\Models\Order;
use App\Models\User;
use Illuminate\Http\Request;

class DashboardController extends Controller
{
    // Method __invoke — satu-satunya method
    public function __invoke(Request $request)
    {
        $totalUsers = User::count();
        $totalOrders = Order::count();
        $recentOrders = Order::latest()->take(5)->get();

        return view('dashboard', compact(
            'totalUsers', 'totalOrders', 'recentOrders'
        ));
    }
}
```

```php
// routes/web.php
use App\Http\Controllers\DashboardController;

// Langsung ke controller — tidak perlu sebut method
Route::get('/dashboard', DashboardController::class);
// atau
Route::get('/dashboard', [DashboardController::class, '__invoke']);
```

## Kasus Penggunaan Nyata
Halaman dashboard, halaman statis (about, contact), form kontak sederhana, halaman pencarian global — tugas yang hanya butuh satu aksi.
