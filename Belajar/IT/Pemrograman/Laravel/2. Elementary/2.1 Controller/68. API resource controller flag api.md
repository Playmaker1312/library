# 68. API Resource Controller Flag API

## Definisi Singkat
Flag `--api` membuat resource controller tanpa method `create` dan `edit`, karena API tidak memerlukan form view — hanya logic data.

## Analogi
Seperti **mesin kopi otomatis vs barista**. Barista (web) menerima pesanan dan membuatkan kopi (form → simpan). Mesin otomatis (API) langsung menerima koin dan mengeluarkan kopi — tanpa tanya mau gula atau tidak (tanpa form).

## Poin-Poin Penting
- Jalankan: `php artisan make:controller PostController --api`
- Hanya menghasilkan 5 method: index, store, show, update, destroy
- Tidak ada method create/edit karena API tidak pakai view
- Cocok untuk backend API murni (SPA, mobile, third-party)
- Route API: `Route::apiResource('posts', PostController::class)`

## Contoh Kode
```php
// Terminal:
// php artisan make:controller PostController --api

namespace App\Http\Controllers;

use App\Models\Post;
use Illuminate\Http\Request;

class PostController extends Controller
{
    // GET /api/posts — semua post (JSON)
    public function index()
    {
        return response()->json(Post::all());
    }

    // POST /api/posts — buat post baru
    public function store(Request $request)
    {
        $post = Post::create($request->validated());
        return response()->json($post, 201);
    }

    // GET /api/posts/{id} — detail post
    public function show($id)
    {
        return response()->json(Post::findOrFail($id));
    }

    // PUT/PATCH /api/posts/{id} — update post
    public function update(Request $request, $id)
    {
        $post = Post::findOrFail($id);
        $post->update($request->validated());
        return response()->json($post);
    }

    // DELETE /api/posts/{id} — hapus post
    public function destroy($id)
    {
        Post::destroy($id);
        return response()->json(null, 204);
    }
}
```

```php
// routes/api.php
use App\Http\Controllers\PostController;
Route::apiResource('posts', PostController::class);
```

## Kasus Penggunaan Nyata
Backend untuk mobile app, SPA Vue/React, atau layanan third-party yang hanya perlu data JSON tanpa halaman HTML.
