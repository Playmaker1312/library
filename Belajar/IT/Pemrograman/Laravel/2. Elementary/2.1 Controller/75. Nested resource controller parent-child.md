# 75. Nested Resource Controller Parent-Child

## Definisi Singkat
Nested resource menangani resource yang bergantung pada resource lain (parent-child), seperti komentar dalam postingan. Route menampilkan ID parent sebelum ID child.

## Analogi
Seperti **alamat rumah**: "Jl. Merdeka No. 5 (parent), RT 02 (child)". Anda harus tahu jalannya dulu baru bisa cari RT-nya.

## Poin-Poin Penting
- `Route::resource('posts.comments', CommentController::class)`
- URL: `/posts/{post}/comments/{comment}`
- Method controller menerima parent dulu, baru child
- Bisa akses parent dari child untuk konteks
- Nama route: `posts.comments.index`, `posts.comments.show`, dll

## Contoh Kode
```php
// routes/web.php
use App\Http\Controllers\CommentController;

// Nested resource: posts -> comments
Route::resource('posts.comments', CommentController::class);

// URL yang dihasilkan:
// GET    /posts/{post}/comments           -> index
// GET    /posts/{post}/comments/create    -> create
// POST   /posts/{post}/comments           -> store
// GET    /posts/{post}/comments/{comment} -> show
// GET    /posts/{post}/comments/{comment}/edit -> edit
// PUT    /posts/{post}/comments/{comment} -> update
// DELETE /posts/{post}/comments/{comment} -> destroy
```

```php
// app/Http/Controllers/CommentController.php
namespace App\Http\Controllers;

use App\Models\Post;
use App\Models\Comment;
use Illuminate\Http\Request;

class CommentController extends Controller
{
    // Parent ($post) selalu di kiri, child ($comment) di kanan
    public function index(Post $post)
    {
        $comments = $post->comments; // hanya komentar post ini
        return view('comments.index', compact('post', 'comments'));
    }

    public function show(Post $post, Comment $comment)
    {
        // Pastikan comment milik post ini
        abort_if($comment->post_id !== $post->id, 404);
        return view('comments.show', compact('post', 'comment'));
    }

    public function update(Request $request, Post $post, Comment $comment)
    {
        if ($comment->post_id !== $post->id) abort(404);
        $comment->update($request->validated());
        return redirect()->route('posts.comments.index', $post);
    }
}
```

## Kasus Penggunaan Nyata
Komentar dalam artikel, item dalam order, file dalam folder, produk dalam kategori — semua relasi one-to-many yang butuh konteks induk.
