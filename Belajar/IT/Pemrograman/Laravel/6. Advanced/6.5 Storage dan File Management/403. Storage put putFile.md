# 403. Storage put putFile

## Definisi Singkat
`Storage::put()` dan `Storage::putFile()` menyimpan file ke disk. `put()` untuk konten string/file, `putFile()` khusus untuk UploadedFile.

## Analogi
Seperti memasukkan barang ke gudang — Anda bisa bawa barang sendiri (put dengan konten) atau minta kurir antar (putFile dengan file upload).

## Poin-Poin Penting
- `put(path, content)` — simpan string atau UploadedFile
- `putFile(path, file)` — simpan UploadedFile dengan hash name
- `putFileAs(path, file, name)` — simpan dengan nama kustom
- File otomatis di-generate nama unik (hash) untuk `putFile`
- Bisa tentukan disk: `Storage::disk('s3')->put(...)`

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Storage;

class UploadController extends Controller
{
    // Upload dengan put (string konten)
    public function saveText()
    {
        // Simpan string langsung
        Storage::put('logs/error.log', 'Error message at ' . now());

        // Simpan JSON
        Storage::put('config/app.json', json_encode([
            'name' => 'My App',
            'version' => '1.0'
        ]));

        return response()->json(['status' => 'saved']);
    }

    // Upload file dengan put (UploadedFile)
    public function uploadPhoto(Request $request)
    {
        // put — simpan dengan hash name
        $path = Storage::put('photos', $request->file('photo'));
        // Hasil: photos/abc123xyz.jpg

        return response()->json(['path' => $path]);
    }

    // putFile — sama seperti put, spesifik untuk file
    public function uploadDocument(Request $request)
    {
        // putFile — simpan dengan hash name
        $path = Storage::putFile('documents', $request->file('document'));
        // Hasil: documents/def456uvw.pdf

        return response()->json(['path' => $path]);
    }

    // putFileAs — dengan nama kustom
    public function uploadAvatar(Request $request)
    {
        // putFileAs — simpan dengan nama yang ditentukan
        $path = Storage::putFileAs(
            'avatars',                    // Direktori
            $request->file('avatar'),      // File
            'user-' . auth()->id() . '.jpg' // Nama file
        );
        // Hasil: avatars/user-1.jpg

        // Bisa dengan disk spesifik
        $path = Storage::disk('s3')->putFileAs(
            'avatars',
            $request->file('avatar'),
            'user-' . auth()->id() . '.jpg'
        );

        return response()->json(['path' => $path]);
    }
}
```

```php
<?php
// Opsi tambahan untuk put/putFile

// Visibility
Storage::put('file.txt', 'content', 'public');      // public
Storage::put('file.txt', 'content', 'private');     // private

// Dengan disk
Storage::disk('s3')->put('path', $content);
Storage::disk('public')->putFile('photos', $file);

// putFile dengan visibility
Storage::disk('s3')->putFileAs(
    'photos',
    $request->file('photo'),
    'profile.jpg',
    'public'  // ACL
);
```

```php
<?php
// Perbedaan nama file

// put() / putFile() — nama HASH (acak, unik)
// putFileAs() — nama KUSTOM (Anda tentukan)

Storage::put('dir', $file);
// -> dir/6b3f8a2c1d9e.jpg (hash)

Storage::putFileAs('dir', $file, 'myfile.jpg');
// -> dir/myfile.jpg (kustom)
```

## Kasus Penggunaan Nyata
Upload foto profil user, upload dokumen, generate file laporan (PDF/Excel), simpan log, dan backup file konfigurasi.
