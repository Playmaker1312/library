# 404. Storage get

## Definisi Singkat
`Storage::get()` membaca konten file dari disk penyimpanan sebagai string.

## Analogi
Seperti membuka file di komputer — Anda klik file (get), dan isinya muncul di layar.

## Poin-Poin Penting
- `Storage::get('path')` — return string konten file
- `Storage::disk('s3')->get('path')` — dari disk tertentu
- Return `null` atau error jika file tidak ada
- Bisa baca gambar, teks, JSON, binary
- Alternatif: `Storage::download()` untuk response download

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Storage;

class FileReadController extends Controller
{
    // Membaca file teks
    public function readLog()
    {
        // Baca file log
        $content = Storage::get('logs/app.log');

        // Jika file tidak ada
        if (!$content) {
            return response()->json(['error' => 'File tidak ditemukan'], 404);
        }

        return response($content)->header('Content-Type', 'text/plain');
    }

    // Membaca file JSON
    public function readConfig()
    {
        $json = Storage::get('config/settings.json');

        $settings = json_decode($json, true);

        return response()->json($settings);
    }

    // Membaca file dari S3
    public function readFromCloud(string $filename)
    {
        $content = Storage::disk('s3')->get("reports/{$filename}");

        return response($content)->header('Content-Type', 'application/pdf');
    }

    // Streaming file besar
    public function stream(string $path)
    {
        // Untuk file besar, pakai readStream
        $stream = Storage::readStream("videos/{$path}");

        return response()->stream(function () use ($stream) {
            fpassthru($stream);
        });
    }
}
```

```php
<?php
// Method lain untuk membaca file

// get — baca seluruh konten sebagai string
$content = Storage::get('file.txt');

// readStream — baca sebagai stream (file besar)
$stream = Storage::readStream('large-file.zip');

// download — download file ke browser
return Storage::download('file.pdf');
return Storage::download('file.pdf', 'custom-name.pdf'); // rename
return Storage::download('file.pdf', 'name.pdf', [
    'Content-Type' => 'application/pdf',
]);

// url — dapatkan URL publik
$url = Storage::disk('public')->url('avatars/photo.jpg');

// temporaryUrl — URL sementara (untuk private file)
$url = Storage::disk('s3')->temporaryUrl(
    'private/file.pdf', now()->addMinutes(5)
);
```

```php
<?php
// Cek file sebelum baca
if (Storage::exists('data/users.json')) {
    $users = json_decode(Storage::get('data/users.json'), true);
}

// Atau langsung dengan missing
if (Storage::missing('data/users.json')) {
    abort(404, 'File data tidak ditemukan');
}
```

## Kasus Penggunaan Nyata
Membaca file log, membaca template email dari storage, menyajikan gambar/dokumen ke user, membaca file konfigurasi dinamis.
