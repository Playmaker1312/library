# 402. Disk storage local public s3

## Definisi Singkat
Disk storage menentukan ke mana file disimpan — lokal (server sendiri), public (bisa diakses web), atau cloud (S3, R2, dll).

## Analogi
Seperti memilih gudang penyimpanan — gudang belakang (local), etalase toko (public), atau gudang sewa di luar kota (S3/cloud).

## Poin-Poin Penting
- `local`: simpan di `storage/app/` — tidak bisa diakses web langsung
- `public`: simpan di `storage/app/public/` — link ke `public/storage/`
- `s3`: simpan di Amazon S3 — cloud, scalable
- Bisa tambah disk kustom: R2, DigitalOcean Spaces, dll
- Pilih disk via `Storage::disk('nama')`

## Contoh Kode
```php
<?php
// config/filesystems.php

return [
    'default' => env('FILESYSTEM_DISK', 'local'),

    'disks' => [
        // LOCAL — file di server, tidak bisa diakses public
        'local' => [
            'driver' => 'local',
            'root' => storage_path('app'),
            'throw' => false,
        ],

        // PUBLIC — bisa diakses via web (setelah symlink)
        'public' => [
            'driver' => 'local',
            'root' => storage_path('app/public'),
            'url' => env('APP_URL') . '/storage',
            'visibility' => 'public',
        ],

        // S3 — Amazon Simple Storage Service
        's3' => [
            'driver' => 's3',
            'key' => env('AWS_ACCESS_KEY_ID'),
            'secret' => env('AWS_SECRET_ACCESS_KEY'),
            'region' => env('AWS_DEFAULT_REGION'),
            'bucket' => env('AWS_BUCKET'),
            'url' => env('AWS_URL'),
            'endpoint' => env('AWS_ENDPOINT'),
            'use_path_style_endpoint' => env('AWS_USE_PATH_STYLE_ENDPOINT', false),
            'throw' => false,
        ],
    ],
];
```

```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Storage;

class FileController extends Controller
{
    public function store(Request $request)
    {
        // Simpan ke disk DEFAULT (local)
        $path1 = Storage::put('files', $request->file('file'));

        // Simpan ke disk PUBLIC
        $path2 = Storage::disk('public')->put('photos', $request->file('photo'));

        // Simpan ke disk S3
        $path3 = Storage::disk('s3')->put('backups', $request->file('backup'));

        // Dapatkan URL
        $urlPublic = Storage::disk('public')->url($path2);
        $urlS3 = Storage::disk('s3')->url($path3);

        return response()->json([
            'local' => $path1,
            'public_url' => $urlPublic,
            's3_url' => $urlS3,
        ]);
    }

    public function show()
    {
        // Baca dari disk berbeda
        $local = Storage::disk('local')->get('files/readme.txt');
        $cloud = Storage::disk('s3')->get('backups/data.json');

        return response()->json([
            'local_content' => $local,
            's3_content' => $cloud,
        ]);
    }
}
```

```php
<?php
// .env untuk berbagai disk

# Local — default
FILESYSTEM_DISK=local

# Public
FILESYSTEM_DISK=public

# S3 (Amazon)
AWS_ACCESS_KEY_ID=your-key
AWS_SECRET_ACCESS_KEY=your-secret
AWS_DEFAULT_REGION=ap-southeast-1
AWS_BUCKET=my-app-bucket
```

## Kasus Penggunaan Nyata
`local` untuk file sementara/log, `public` untuk upload user (avatar, foto produk), `s3` untuk backup, file besar, dan aplikasi multi-server.
