# 401. Storage facade sistem storage

## Definisi Singkat
`Storage` facade menyediakan antarmuka seragam untuk mengelola file di berbagai sistem penyimpanan (lokal, cloud, S3, dll).

## Analogi
Seperti petugas resepsionis yang bisa mengirim surat ke mana saja — Anda berikan surat (file), dia yang urus pengirimannya (storage) ke berbagai tujuan.

## Poin-Poin Penting
- `Storage::put()` — simpan file
- `Storage::get()` — ambil file
- `Storage::delete()` — hapus file
- `Storage::exists()` — cek file
- Abstraksi: kode yang sama bekerja di lokal, S3, atau cloud
- Konfigurasi di `config/filesystems.php`

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Storage;

class FileController extends Controller
{
    public function upload(Request $request)
    {
        // Simpan file ke disk default (local)
        $path = Storage::put('photos', $request->file('photo'));

        // Simpan ke disk tertentu (public)
        $path = Storage::disk('public')->put('avatars', $request->file('avatar'));

        // Simpan dengan nama kustom
        $path = Storage::putFileAs('docs', $request->file('document'), 'contract.pdf');

        return response()->json(['path' => $path]);
    }

    public function download(string $path)
    {
        // Cek file ada
        if (!Storage::exists($path)) {
            abort(404);
        }

        // Download file
        return Storage::download($path);
    }

    public function delete(string $path)
    {
        Storage::delete($path);

        return response()->json(['status' => 'deleted']);
    }
}
```

```php
<?php
// Semua method Storage facade

Storage::put('path', $content);           // Simpan string
Storage::put('path', $file);              // Simpan UploadedFile
Storage::putFile('dir', $file);           // Simpan file dengan hash name
Storage::putFileAs('dir', $file, 'name'); // Simpan dengan nama kustom

Storage::get('path');                     // Baca file (string)
Storage::download('path');                // Download file
Storage::url('path');                     // URL publik
Storage::temporaryUrl('path', $exp);      // URL sementara

Storage::exists('path');                  // Cek ada
Storage::missing('path');                 // Cek tidak ada
Storage::delete('path');                  // Hapus file
Storage::delete(['path1', 'path2']);      // Hapus multiple

Storage::size('path');                    // Ukuran file (bytes)
Storage::lastModified('path');            // Timestamp

Storage::files('dir');                    // List file
Storage::allFiles('dir');                 // List semua file (rekursif)
Storage::directories('dir');              // List folder
Storage::allDirectories('dir');           // List semua folder

Storage::copy('from', 'to');              // Copy file
Storage::move('from', 'to');              // Pindah/rename file
Storage::makeDirectory('dir');            // Buat folder
Storage::deleteDirectory('dir');          // Hapus folder
```

## Kasus Penggunaan Nyata
Upload file, manajemen aset (gambar, dokumen), backup file, export/import data, dan semua operasi file yang membutuhkan fleksibilitas storage.
