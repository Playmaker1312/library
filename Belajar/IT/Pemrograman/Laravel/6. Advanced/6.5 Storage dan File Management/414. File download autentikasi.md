# 414. File download autentikasi

## Definisi Singkat
File download dengan autentikasi memastikan hanya user tertentu yang bisa mengunduh file private.

## Analogi
Seperti perpustakaan digital — hanya anggota yang terdaftar (autentikasi) yang bisa meminjam buku (download file).

## Poin-Poin Penting
- Middleware `auth` melindungi route download
- File disimpan di disk private (bukan public)
- Gunakan `Storage::download()` untuk response download
- Atau `Storage::temporaryUrl()` untuk file di cloud
- Bisa tambah authorisasi (siapa yang boleh download)

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Storage;
use App\Models\Document;

class DocumentController extends Controller
{
    public function __construct()
    {
        // Semua method butuh login
        $this->middleware('auth');
    }

    // Download dengan validasi kepemilikan
    public function download(Document $document)
    {
        // Authorize — hanya pemilik yang bisa download
        $this->authorize('view', $document);

        // Cek file ada
        $path = $document->file_path;

        if (Storage::disk('private')->missing($path)) {
            abort(404, 'File tidak ditemukan');
        }

        // Download dengan nama kustom
        return Storage::disk('private')->download(
            $path,
            $document->original_filename,
            [
                'Content-Type' => $document->mime_type,
            ]
        );
    }

    // Download dengan verifikasi password
    public function downloadWithPassword(Document $document, Request $request)
    {
        $request->validate(['password' => 'required']);

        if ($request->password !== $document->download_password) {
            return back()->withErrors(['password' => 'Password salah']);
        }

        return Storage::disk('private')->download($document->file_path);
    }
}
```

```php
<?php
// routes/web.php — route download terproteksi

use App\Http\Controllers\DocumentController;

Route::middleware(['auth'])->group(function () {
    Route::get('/documents/{document}/download', [DocumentController::class, 'download'])
        ->name('documents.download');

    Route::get('/invoices/{invoice}/pdf', [InvoiceController::class, 'downloadPdf'])
        ->middleware('verified'); // Email harus terverifikasi
});
```

```php
<?php
// Download dengan signed URL (temporary, tanpa login)
use Illuminate\Support\Facades\URL;

class InvoiceController extends Controller
{
    // Generate signed URL untuk download
    public function sendInvoiceLink(Invoice $invoice)
    {
        $url = URL::temporarySignedRoute(
            'invoices.download',
            now()->addDays(7),
            ['invoice' => $invoice->id]
        );

        // Kirim link via email
        Mail::to($invoice->user->email)->send(new InvoiceMail($url));

        return response()->json(['message' => 'Link download dikirim ke email']);
    }

    // Download via signed URL
    public function downloadSigned(Invoice $invoice)
    {
        // Validasi signed URL otomatis oleh Laravel
        $pdf = \Barryvdh\DomPDF\Facade\Pdf::loadView('invoices.pdf', compact('invoice'));

        return $pdf->download("invoice-{$invoice->number}.pdf");
    }
}
```

```php
<?php
// Download dengan logging (audit trail)
class SecureDownloadController extends Controller
{
    public function download(Document $document)
    {
        $this->authorize('download', $document);

        // Log download
        \App\Models\DownloadLog::create([
            'user_id' => auth()->id(),
            'document_id' => $document->id,
            'ip_address' => request()->ip(),
            'downloaded_at' => now(),
        ]);

        return Storage::disk('private')->download($document->file_path);
    }
}
```

```php
<?php
// Storage disk private — di config/filesystems.php
'private' => [
    'driver' => 'local',
    'root' => storage_path('app/private'),
    'visibility' => 'private',
],
```

## Kasus Penggunaan Nyata
Download dokumen rahasia (KTP, kontrak), invoice PDF pelanggan, file laporan internal, dan file yang hanya boleh diakses user tertentu.
