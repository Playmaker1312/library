# 405. Storage exists

## Definisi Singkat
`Storage::exists()` mengecek apakah sebuah file atau direktori ada di disk penyimpanan.

## Analogi
Seperti mengetuk pintu — sebelum masuk, Anda ketuk dulu (exists) untuk tahu apakah ada orang di dalam.

## Poin-Poin Penting
- `Storage::exists('path')` — return boolean
- `Storage::missing('path')` — kebalikan (negasi)
- Cek untuk file dan direktori
- Bisa digunakan dengan disk tertentu
- Berguna sebelum operasi baca/hapus

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Storage;

class FileCheckController extends Controller
{
    public function check(string $path)
    {
        // Cek file ada
        if (Storage::exists($path)) {
            $size = Storage::size($path);
            $lastModified = Storage::lastModified($path);

            return response()->json([
                'exists' => true,
                'size' => $size,
                'last_modified' => date('Y-m-d H:i:s', $lastModified),
            ]);
        }

        return response()->json(['exists' => false], 404);
    }

    public function showIfExists(string $filename)
    {
        $path = "photos/{$filename}";

        // Cek dulu sebelum download
        if (Storage::disk('public')->missing($path)) {
            abort(404, 'File tidak ditemukan');
        }

        return Storage::disk('public')->download($path);
    }

    public function deleteIfExists(string $path)
    {
        // Hanya hapus jika file ada
        if (Storage::exists($path)) {
            Storage::delete($path);

            return response()->json(['status' => 'deleted']);
        }

        return response()->json(['status' => 'not_found'], 404);
    }

    public function checkMultiple()
    {
        $files = [
            'config.json',
            'data/users.csv',
            'logs/error.log',
        ];

        $results = [];

        foreach ($files as $file) {
            $results[$file] = Storage::exists($file);
        }

        return response()->json($results);
    }
}
```

```php
<?php
// Cek direktori
if (Storage::exists('photos')) {

    // Subdirektori photos/2024 ada

// exists vs missing
Storage::exists('file.txt');   // true jika ada
Storage::missing('file.txt');  // true jika TIDAK ada (kebalikan)
```

```php
<?php
// Penggunaan di Service
use Illuminate\Support\Facades\Storage;

class AvatarService
{
    public function getUserAvatar(int $userId): string
    {
        $paths = [
            "avatars/{$userId}.jpg",
            "avatars/{$userId}.png",
            "avatars/{$userId}.webp",
        ];

        foreach ($paths as $path) {
            if (Storage::disk('public')->exists($path)) {
                return Storage::disk('public')->url($path);
            }
        }

        // Default avatar jika tidak ada
        return Storage::disk('public')->url('avatars/default.png');
    }
}
```

## Kasus Penggunaan Nyata
Validasi sebelum download, cek file upload sudah tersimpan, fallback ke default jika file tidak ada, dan pengecekan integritas file.
