# 406. Storage delete

## Definisi Singkat
`Storage::delete()` menghapus satu atau beberapa file dari disk penyimpanan.

## Analogi
Seperti menghapus file di komputer — Anda pilih file, kirim ke tong sampah (delete), dan file hilang.

## Poin-Poin Penting
- `Storage::delete('path')` — hapus satu file
- `Storage::delete(['path1', 'path2'])` — hapus multiple file
- `Storage::deleteDirectory('dir')` — hapus seluruh direktori
- Return boolean untuk single, array boolean untuk multiple
- Hati-hati: operasi permanen (tidak ada recycle bin)

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Storage;

class FileDeleteController extends Controller
{
    // Hapus satu file
    public function delete(string $path)
    {
        if (Storage::missing($path)) {
            return response()->json(['error' => 'File tidak ditemukan'], 404);
        }

        Storage::delete($path);

        return response()->json(['status' => 'deleted']);
    }

    // Hapus multiple file
    public function deleteMultiple()
    {
        $files = request('files', []); // ['photo1.jpg', 'photo2.jpg']

        $results = Storage::delete($files);

        return response()->json([
            'deleted_count' => count(array_filter($results)),
        ]);
    }

    // Hapus setelah user menghapus akun
    public function deleteUserFiles(int $userId)
    {
        // Hapus avatar
        Storage::disk('public')->delete("avatars/{$userId}.jpg");
        Storage::disk('public')->delete("avatars/{$userId}.png");

        // Hapus folder dokumen user
        Storage::disk('local')->deleteDirectory("users/{$userId}");

        // Hapus file di S3
        Storage::disk('s3')->delete("backups/user-{$userId}.zip");

        return response()->json(['status' => 'user files cleaned']);
    }

    // Hapus file lama (cleanup)
    public function cleanupOldFiles()
    {
        $files = Storage::disk('public')->files('temp');

        $deleted = 0;

        foreach ($files as $file) {
            $lastModified = Storage::lastModified($file);

            // Hapus file > 24 jam
            if (now()->timestamp - $lastModified > 86400) {
                Storage::disk('public')->delete($file);
                $deleted++;
            }
        }

        return response()->json(['cleaned' => $deleted]);
    }
}
```

```php
<?php
// Method hapus lainnya

// Hapus direktori dan semua isinya
Storage::deleteDirectory('old-photos');
Storage::disk('s3')->deleteDirectory('temp-uploads');

// Hapus file yang matching pattern (manual)
$files = Storage::files('logs');
foreach ($files as $file) {
    if (str_ends_with($file, '.tmp')) {
        Storage::delete($file);
    }
}
```

```php
<?php
// Model event — auto delete file
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Support\Facades\Storage;

class Photo extends Model
{
    protected static function booted(): void
    {
        // Hapus file fisik saat record dihapus
        static::deleted(function (Photo $photo) {
            Storage::disk('public')->delete($photo->path);
        });
    }
}

// Di controller:
$photo = Photo::find(1);
$photo->delete();
// File otomatis terhapus dari storage
```

## Kasus Penggunaan Nyata
Hapus avatar saat user ganti foto, cleanup file temporary, hapus dokumen expired, dan integrasi dengan soft-delete model.
