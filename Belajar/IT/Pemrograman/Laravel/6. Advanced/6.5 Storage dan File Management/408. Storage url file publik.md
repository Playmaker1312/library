# 408. Storage url file publik

## Definisi Singkat
`Storage::url()` menghasilkan URL publik untuk file yang bisa diakses langsung oleh browser.

## Analogi
Seperti alamat rumah — Anda beri alamat (URL) ke teman, mereka bisa langsung datang ke rumah (file) tanpa perlu kunci.

## Poin-Poin Penting
- `Storage::url('path')` — URL untuk disk default
- `Storage::disk('public')->url('path')` — URL dari disk public
- Untuk S3, otomatis menghasilkan URL S3 bucket
- Membutuhkan symlink `storage:link` untuk disk lokal
- File harus di disk public atau cloud dengan akses publik

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Storage;

class ProductImageController extends Controller
{
    public function show(Product $product)
    {
        // Dapatkan URL gambar produk
        $imageUrl = Storage::disk('public')->url($product->image_path);

        // Koleksi multiple gambar
        $images = $product->images->map(function ($image) {
            return [
                'id' => $image->id,
                'url' => Storage::disk('public')->url($image->path),
                'thumbnail' => Storage::disk('public')->url($image->thumbnail_path),
            ];
        });

        return view('products.show', compact('product', 'imageUrl', 'images'));
    }
}
```

```php
<?php

namespace App\Services;

use Illuminate\Support\Facades\Storage;

class MediaService
{
    public function getPublicUrl(string $path, ?string $disk = 'public'): string
    {
        if (empty($path)) {
            return asset('images/placeholder.png');
        }

        return Storage::disk($disk)->url($path);
    }

    public function getMultipleUrls(array $paths, string $disk = 'public'): array
    {
        return array_map(fn($path) => $this->getPublicUrl($path, $disk), $paths);
    }
}
```

```php
<?php
// Blade template
<img src="{{ Storage::disk('public')->url($product->image) }}"
     alt="{{ $product->name }}"
     class="w-full h-64 object-cover">

<!-- Atau dengan helper asset -->
<img src="{{ asset('storage/' . $product->image) }}"
     alt="{{ $product->name }}">
```

```php
<?php
// URL untuk berbagai disk

// Local public — butuh symlink
Storage::disk('public')->url('avatars/photo.jpg');
// http://localhost:8000/storage/avatars/photo.jpg

// S3 — langsung URL S3
Storage::disk('s3')->url('avatars/photo.jpg');
// https://my-bucket.s3.ap-southeast-1.amazonaws.com/avatars/photo.jpg

// Custom disk — tergantung konfigurasi url
Storage::disk('r2')->url('avatars/photo.jpg');
// https://my-account.r2.cloudflarestorage.com/avatars/photo.jpg
```

```php
<?php
// Konfigurasi URL di filesystems.php
'public' => [
    'driver' => 'local',
    'root' => storage_path('app/public'),
    'url' => env('APP_URL') . '/storage',  // Base URL untuk file
    'visibility' => 'public',
],

's3' => [
    'driver' => 's3',
    // ...
    'url' => env('AWS_URL'),  // Bisa custom URL (CDN)
],
```

## Kasus Penggunaan Nyata
Menampilkan gambar produk, foto profil user, thumbnail artikel, file download publik, dan aset media di halaman web.
