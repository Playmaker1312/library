# 407. php artisan storage link

## Definisi Singkat
`php artisan storage:link` membuat symlink dari `public/storage` ke `storage/app/public` agar file public bisa diakses via web.

## Analogi
Seperti jendela etalase toko — Anda bisa melihat barang (file) di etalase (public/storage) meskipun barang asli ada di gudang (storage/app/public).

## Poin-Poin Penting
- Perintah: `php artisan storage:link`
- Membuat folder `public/storage` → `storage/app/public`
- File di `storage/app/public/` bisa diakses via `http://app.com/storage/...`
- Hanya perlu dijalankan sekali (saat setup)
- Multiple links: `php artisan storage:link --relative`

## Contoh Kode
```bash
# Membuat symlink
php artisan storage:link

# Output:
# The [public/storage] directory has been linked.

# Untuk multiple links (jika punya beberapa disk)
php artisan storage:link --relative
```

```php
<?php
// Setelah storage:link, file bisa diakses via URL

// File di: storage/app/public/avatars/photo.jpg
// Bisa diakses: http://localhost:8000/storage/avatars/photo.jpg

// Di Blade:
<img src="{{ asset('storage/avatars/photo.jpg') }}" alt="Avatar">

// Atau pakai Storage facade:
$url = Storage::disk('public')->url('avatars/photo.jpg');
// http://localhost:8000/storage/avatars/photo.jpg
```

```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Storage;

class AvatarController extends Controller
{
    public function upload(Request $request)
    {
        $request->validate([
            'avatar' => 'required|image|mimes:jpg,png|max:2048',
        ]);

        // Simpan ke disk public
        $path = Storage::disk('public')->put('avatars', $request->file('avatar'));

        // Dapatkan URL publik
        $url = Storage::disk('public')->url($path);

        // Simpan path ke database
        auth()->user()->update(['avatar_path' => $path]);

        return response()->json([
            'url' => $url,
            'message' => 'Avatar berhasil diupload'
        ]);
    }

    public function show()
    {
        $user = auth()->user();

        // Jika user punya avatar, tampilkan URL-nya
        if ($user->avatar_path && Storage::disk('public')->exists($user->avatar_path)) {
            $avatarUrl = Storage::disk('public')->url($user->avatar_path);
        } else {
            $avatarUrl = asset('images/default-avatar.png');
        }

        return view('profile', compact('avatarUrl'));
    }
}
```

```php
<?php
// Jika tidak bisa pakai symlink (Windows tanpa admin, hosting)
// Alternatif: copy manual atau edit filesystems.php

// Di config/filesystems.php, ubah 'public' disk:
'public' => [
    'driver' => 'local',
    'root' => public_path('storage'),  // Langsung di public/
    'url' => env('APP_URL') . '/storage',
    'visibility' => 'public',
],
```

```php
// Di Blade untuk menampilkan gambar dari storage:
<img src="{{ Storage::disk('public')->url($post->thumbnail) }}" alt="{{ $post->title }}">

<!-- Atau -->
<img src="{{ asset('storage/' . $post->thumbnail) }}" alt="{{ $post->title }}">
```

## Kasus Penggunaan Nyata
Setiap kali setup project Laravel baru, deploy ke server baru, atau pindah environment — wajib menjalankan `storage:link` agar upload user bisa diakses publik.
