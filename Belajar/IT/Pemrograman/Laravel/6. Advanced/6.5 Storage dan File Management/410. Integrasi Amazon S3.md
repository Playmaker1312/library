# 410. Integrasi Amazon S3

## Definisi Singkat
Amazon S3 (Simple Storage Service) adalah layanan cloud storage dari AWS yang bisa diintegrasikan dengan Laravel untuk menyimpan file.

## Analogi
Seperti gudang raksasa di internet — Anda bisa menyimpan, mengambil, dan mengelola file dari mana saja tanpa khawatir kapasitas.

## Poin-Poin Penting
- Butuh akun AWS, IAM user dengan akses S3
- Package `league/flysystem-aws-s3-v3` (bawaan Laravel)
- Konfigurasi di `.env` dan `config/filesystems.php`
- Mendukung buckets, folders, ACL, dan versi
- Skalabel hingga petabyte tanpa perubahan kode

## Contoh Kode
```bash
# Install package (sudah include di Laravel)
composer require league/flysystem-aws-s3-v3
```

```php
<?php
```

```php
namespace App\Http\Controllers;

use Illuminate\Support\Facades\Storage;

class S3Controller extends Controller
{
    public function uploadToS3(Request $request)
    {
        // Simpan langsung ke S3
        $path = Storage::disk('s3')->put('products', $request->file('image'));

        // Dapatkan URL S3
        $url = Storage::disk('s3')->url($path);

        // Simpan path ke database
        $product = \App\Models\Product::create([
            'name' => $request->name,
            'image_path' => $path,
        ]);

        return response()->json([
            'product' => $product,
            'image_url' => $url,
        ]);
    }

    public function listFromS3()
    {
        // List file di bucket
        $files = Storage::disk('s3')->allFiles('products');

        // Dapatkan metadata
        $metadata = array_map(function ($file) {
            return [
                'path' => $file,
                'url' => Storage::disk('s3')->url($file),
                'size' => Storage::disk('s3')->size($file),
                'last_modified' => Storage::disk('s3')->lastModified($file),
            ];
        }, $files);

        return response()->json($metadata);
    }

    public function deleteFromS3(string $path)
    {
        Storage::disk('s3')->delete($path);

        return response()->json(['status' => 'deleted']);
    }
}
```

```php
// S3 dengan visibility dan ACL

// Upload dengan ACL public
Storage::disk('s3')->putFileAs(
    'avatars',
    $request->file('avatar'),
    'user-1.jpg',
    ['visibility' => 'public']  // atau ['ACL' => 'public-read']
);

// Private file
Storage::disk('s3')->put('private/docs/report.pdf', $content, 'private');

// S3 options untuk download
$url = Storage::disk('s3')->temporaryUrl(
    'private/file.pdf',
    now()->addMinutes(5),
    [
        'ResponseContentDisposition' => 'inline',
        'ResponseContentType' => 'application/pdf',
    ]
);
```

```php
// Semua Storage::url() akan menggunakan CDN URL
```

## Kasus Penggunaan Nyata
Upload gambar produk di e-commerce, backup database, hosting file statis, CDN untuk media, dan aplikasi dengan traffic tinggi yang butuh skalabilitas.
