# 412. File upload aman validasi

## Definisi Singkat
Upload file yang aman memerlukan validasi ketat — tipe file, ukuran, dan keamanan untuk mencegah serangan.

## Analogi
Seperti satpam di bandara — setiap barang (file) diperiksa (validasi) sebelum diizinkan masuk ke pesawat (server).

## Poin-Poin Penting
- Validasi: `mimes`, `max`, `dimensions` (gambar)
- Cegah eksekusi file berbahaya (PHP, script)
- Gunakan `Storage::putFileAs()` dengan hash name
- Jangan percaya nama file dari user
- Simpan path ke database, bukan file di public langsung

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Storage;
use Illuminate\Support\Str;

class FileUploadController extends Controller
{
    // Upload gambar dengan validasi lengkap
    public function uploadImage(Request $request)
    {
        $validated = $request->validate([
            'image' => [
                'required',
                'file',
                'image',                          // Must be gambar
                'mimes:jpeg,png,jpg,webp',         // Format diizinkan
                'max:5120',                        // Max 5MB (dalam KB)
                'dimensions:min_width=100,min_height=100,max_width=5000,max_height=5000',
            ],
        ]);

        /** @var \Illuminate\Http\UploadedFile $file */
        $file = $request->file('image');

        // Generate nama aman — hash + ekstensi asli
        $extension = $file->getClientOriginalExtension();
        $filename = Str::random(40) . '.' . $extension;

        // Simpan dengan nama hash
        $path = Storage::disk('public')->putFileAs(
            'uploads/images',
            $file,
            $filename
        );

        return response()->json([
            'path' => $path,
            'url' => Storage::disk('public')->url($path),
            'original_name' => $file->getClientOriginalName(), // Simpan di DB
        ]);
    }

    // Upload dokumen
    public function uploadDocument(Request $request)
    {
        $validated = $request->validate([
            'document' => [
                'required',
                'file',
                'mimes:pdf,doc,docx,xls,xlsx',
                'max:20480', // 20MB
            ],
        ]);

        $file = $request->file('document');

        // Validasi konten (cek magic bytes)
        $mimeType = $file->getMimeType();
        $allowedMimes = ['application/pdf', 'application/msword',
                         'application/vnd.openxmlformats-officedocument.wordprocessingml.document'];

        if (!in_array($mimeType, $allowedMimes)) {
            return response()->json(['error' => 'Tipe file tidak valid'], 422);
        }

        $path = Storage::disk('private')->putFileAs(
            'documents',
            $file,
            time() . '_' . Str::slug(pathinfo($file->getClientOriginalName(), PATHINFO_FILENAME)) . '.' . $file->extension()
        );

        return response()->json(['path' => $path]);
    }
}
```
