# 415. Storage disk kustom

## Definisi Singkat
Storage disk kustom memungkinkan Anda mendefinisikan sistem penyimpanan sendiri — bisa driver lokal, FTP, SFTP, atau driver kustom.

## Analogi
Seperti membangun gudang sendiri — Anda tentukan lokasi (root), aturan (visibility), dan akses (config) sesuai kebutuhan.

## Poin-Poin Penting
- Daftarkan di `config/filesystems.php` array `disks`
- Bisa gunakan driver: local, s3, ftp, sftp, atau kustom
- Setiap disk punya konfigurasi root, url, visibility
- Pilih disk via `Storage::disk('nama_disk')`
- Bisa buat driver kustom dengan `Storage::extend()`

## Contoh Kode
```php
<?php
// config/filesystems.php — disk kustom

return [
    'disks' => [
        // Disk untuk backup database
        'backups' => [
            'driver' => 'local',
            'root' => storage_path('backups'),
            'visibility' => 'private',
        ],

        // Disk untuk export file (sementara)
        'exports' => [
            'driver' => 'local',
            'root' => storage_path('app/exports'),
            'visibility' => 'private',
        ],

        // Disk untuk upload user (dengan ukuran limit)
        'uploads' => [
            'driver' => 'local',
            'root' => storage_path('app/uploads'),
            'visibility' => 'private',
            'throw' => true, // Throw exception jika gagal
        ],

        // SFTP — server jarak jauh via SSH
        'sftp' => [
            'driver' => 'sftp',
            'host' => env('SFTP_HOST'),
            'username' => env('SFTP_USERNAME'),
            'password' => env('SFTP_PASSWORD'),
            'port' => 22,
            'root' => '/var/www/storage',
        ],

        // FTP
        'ftp' => [
            'driver' => 'ftp',
            'host' => env('FTP_HOST'),
            'username' => env('FTP_USERNAME'),
            'password' => env('FTP_PASSWORD'),
            'port' => 21,
            'root' => '/public_html/storage',
        ],
    ],
];
```

```php
<?php
// Penggunaan disk kustom

use Illuminate\Support\Facades\Storage;

class BackupController extends Controller
{
    public function runBackup()
    {
        // Simpan ke disk 'backups'
        $filename = 'db-backup-' . now()->format('Y-m-d-H-i-s') . '.sql';

        // Proses backup...
        $content = \Illuminate\Support\Facades\DB::select('SHOW TABLES');

        Storage::disk('backups')->put($filename, json_encode($content));

        // Dapatkan file info
        $size = Storage::disk('backups')->size($filename);
        $path = Storage::disk('backups')->path($filename); // Full path

        return response()->json([
            'file' => $filename,
            'size' => $size,
            'path' => $path,
        ]);
    }

    public function listBackups()
    {
        $files = Storage::disk('backups')->files();

        $backups = collect($files)->map(function ($file) {
            return [
                'name' => basename($file),
                'size' => Storage::disk('backups')->size($file),
                'last_modified' => date('Y-m-d H:i:s', Storage::disk('backups')->lastModified($file)),
            ];
        });

        return response()->json($backups);
    }

    public function deleteOldBackups()
    {
        $files = Storage::disk('backups')->files();

        foreach ($files as $file) {
            $age = now()->timestamp - Storage::disk('backups')->lastModified($file);

            // Hapus backup > 30 hari
            if ($age > 30 * 86400) {
                Storage::disk('backups')->delete($file);
            }
        }

        return response()->json(['message' => 'Backup lama dibersihkan']);
    }
}
```

```php
<?php
// Driver kustom dengan Storage::extend()
// Di AppServiceProvider::boot()

use Illuminate\Support\Facades\Storage;
use League\Flysystem\Filesystem;
use App\Services\CustomAdapter;

public function boot(): void
{
    Storage::extend('custom', function ($app, $config) {
        $adapter = new CustomAdapter($config);

        return new Filesystem($adapter);
    });
}
```

```php
<?php
// Helper — Storage::path() untuk local disk
$fullPath = Storage::disk('backups')->path('file.sql');
// /var/www/storage/backups/file.sql

// Berguna untuk operasi yang butuh path fisik
exec("gzip " . escapeshellarg($fullPath));
```

## Kasus Penggunaan Nyata
Disk khusus untuk backup, export file sementara, integrasi dengan legacy system via FTP/SFTP, dan koneksi ke penyedia storage kustom.
