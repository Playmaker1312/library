# 409. Storage temporaryUrl file private

## Definisi Singkat
`Storage::temporaryUrl()` menghasilkan URL sementara yang kadaluarsa untuk mengakses file private (tidak publik).

## Analogi
Seperti tiket masuk museum — Anda bisa masuk (akses file) dalam waktu terbatas, setelah itu tiket tidak berlaku.

## Poin-Poin Penting
- `Storage::temporaryUrl('path', $expiration)` — URL sementara
- Hanya untuk disk dengan driver S3, R2, atau cloud lainnya
- Tidak didukung disk `local` (tanpa package tambahan)
- Parameter `$expiration`: `now()->addMinutes(5)`
- Berguna untuk file private yang perlu di-share sementara

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Storage;

class FileShareController extends Controller
{
    // Generate link download sementara
    public function generateDownloadLink(string $fileId)
    {
        $file = \App\Models\File::findOrFail($fileId);

        // Authorize — hanya pemilik yang bisa generate
        $this->authorize('view', $file);

        // Generate URL sementara (berlaku 1 jam)
        $url = Storage::disk('s3')->temporaryUrl(
            $file->path,
            now()->addHour()
        );

        return response()->json([
            'url' => $url,
            'expires_at' => now()->addHour(),
        ]);
    }

    // Download file dengan validasi
    public function download(string $fileId)
    {
        $file = \App\Models\File::findOrFail($fileId);

        $this->authorize('download', $file);

        // Gunakan temporary URL untuk redirect ke S3
        $url = Storage::disk('s3')->temporaryUrl(
            $file->path,
            now()->addMinutes(30)
        );

        return redirect()->away($url);
    }

    // Share link ke user lain
    public function share(string $fileId, Request $request)
    {
        $file = \App\Models\File::findOrFail($fileId);

        // Generate 24-hour link
        $url = Storage::disk('s3')->temporaryUrl(
            $file->path,
            now()->addHours(24)
        );

        // Kirim link via email
        \Illuminate\Support\Facades\Mail::send(
            'emails.file-shared',
            ['url' => $url, 'file' => $file],
            fn($msg) => $msg->to($request->email)->subject('File Dibagikan')
        );

        return response()->json(['message' => 'Link telah dikirim']);
    }
}
```

```php
<?php
// temporaryUrl untuk local disk — perlu package tambahan
// Install: composer propagate/dynamic-storage-url

// Atau buat sendiri dengan route
Route::get('/private/{path}', function (string $path) {
    $file = Storage::disk('local')->get($path);

    return response($file)->header('Content-Type', 'application/octet-stream');
})->middleware('auth')->where('path', '.*');
```

```php
<?php
// Opsi temporaryUrl

// Expiration: Carbon instance
Storage::disk('s3')->temporaryUrl('file.pdf', now()->addMinutes(5));
Storage::disk('s3')->temporaryUrl('file.pdf', now()->addHours(2));
Storage::disk('s3')->temporaryUrl('file.pdf', now()->addDays(1));

// S3 options (seperti response headers)
Storage::disk('s3')->temporaryUrl(
    'file.pdf',
    now()->addMinutes(10),
    [
        'ResponseContentDisposition' => 'attachment; filename="laporan.pdf"',
        'ResponseContentType' => 'application/pdf',
    ]
);
```

```php
<?php
// Contoh di blade
<a href="{{ Storage::disk('s3')->temporaryUrl($file->path, now()->addHour()) }}"
   class="btn btn-primary">
    Download File (berlaku 1 jam)
</a>
```

## Kasus Penggunaan Nyata
Download file private (dokumen rahasia, PDF, laporan), share link dengan expiry, protected video/image streaming, dan temporary access untuk client.
