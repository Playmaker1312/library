# 411. Cloudflare R2 DigitalOcean Spaces

## Definisi Singkat
Alternatif selain Amazon S3: Cloudflare R2 (tanpa biaya egress) dan DigitalOcean Spaces (harga tetap terjangkau) untuk cloud storage.

## Analogi
Seperti memilih jasa pengiriman — S3 seperti DHL (lengkap tapi mahal), R2 seperti JNE (murah, bebas biaya keluar), Spaces seperti Pos Indonesia (sederhana, harga tetap).

## Poin-Poin Penting
- Cloudflare R2: S3-compatible, tanpa biaya transfer keluar (egress)
- DigitalOcean Spaces: S3-compatible, harga flat $5/bulan untuk 250GB
- Keduanya menggunakan driver `s3` dengan endpoint berbeda
- Konfigurasi endpoint dan credentials sesuai provider
- Migrasi mudah karena API kompatibel dengan S3

## Contoh Kode
```php
<?php
// config/filesystems.php — Cloudflare R2

'r2' => [
    'driver' => 's3',
    'key' => env('CLOUDFLARE_R2_ACCESS_KEY_ID'),
    'secret' => env('CLOUDFLARE_R2_SECRET_ACCESS_KEY'),
    'region' => 'auto',
    'bucket' => env('CLOUDFLARE_R2_BUCKET'),
    'url' => env('CLOUDFLARE_R2_URL'), // https://pub-xxx.r2.dev
    'endpoint' => env('CLOUDFLARE_R2_ENDPOINT', 'https://xxx.r2.cloudflarestorage.com'),
    'use_path_style_endpoint' => true,
    'visibility' => 'public',
],
```

```php
<?php
// .env — Cloudflare R2

CLOUDFLARE_R2_ACCESS_KEY_ID=your-access-key
CLOUDFLARE_R2_SECRET_ACCESS_KEY=your-secret-key
CLOUDFLARE_R2_BUCKET=my-app-media
CLOUDFLARE_R2_URL=https://pub-abc123.r2.dev
CLOUDFLARE_R2_ENDPOINT=https://abc123.r2.cloudflarestorage.com
FILESYSTEM_DISK=r2
```

```php
<?php
// config/filesystems.php — DigitalOcean Spaces

'spaces' => [
    'driver' => 's3',
    'key' => env('DO_SPACES_KEY'),
    'secret' => env('DO_SPACES_SECRET'),
    'region' => env('DO_SPACES_REGION', 'sgp1'),
    'bucket' => env('DO_SPACES_BUCKET'),
    'url' => env('DO_SPACES_URL'), // https://sgp1.digitaloceanspaces.com
    'endpoint' => env('DO_SPACES_ENDPOINT', 'https://sgp1.digitaloceanspaces.com'),
    'use_path_style_endpoint' => false,
    'visibility' => 'public',
],
```

```php
<?php
// .env — DigitalOcean Spaces

DO_SPACES_KEY=your-access-key
DO_SPACES_SECRET=your-secret-key
DO_SPACES_REGION=sgp1
DO_SPACES_BUCKET=my-app
DO_SPACES_URL=https://my-app.sgp1.digitaloceanspaces.com
DO_SPACES_ENDPOINT=https://sgp1.digitaloceanspaces.com
FILESYSTEM_DISK=spaces
```

```php
<?php
// Penggunaan — sama persis dengan S3
// Tidak ada perubahan kode!

use Illuminate\Support\Facades\Storage;

// R2
$url = Storage::disk('r2')->url('images/photo.jpg');
$url = Storage::disk('r2')->temporaryUrl('private/doc.pdf', now()->addHour());

// DigitalOcean Spaces
$path = Storage::disk('spaces')->put('uploads', $request->file('file'));
$url = Storage::disk('spaces')->url($path);
```

## Kasus Penggunaan Nyata
R2 cocok untuk aplikasi dengan transfer data besar (video, gambar) karena tanpa biaya egress. Spaces cocok untuk UKM dengan budget tetap dan kebutuhan storage sederhana.
