# 413. Image resizing Intervention Image

## Definisi Singkat
Intervention Image adalah package untuk manipulasi gambar di Laravel — resize, crop, filter, dan optimasi.

## Analogi
Seperti Adobe Photoshop versi kode — Anda bisa mengubah ukuran, memotong, dan memanipulasi gambar tanpa membuka software.

## Poin-Poin Penting
- Package: `intervention/image-laravel` (v3)
- Install: `composer require intervention/image-laravel`
- Gunakan facade `Image::read($file)->resize()`
- Support: resize, crop, fit, text, filter, orientate
- Simpan hasil ke storage atau response

## Contoh Kode
```bash
# Install Intervention Image v3
composer require intervention/image-laravel

# Publish config (opsional)
php artisan vendor:publish --provider="Intervention\Image\ImageServiceProviderLaravelRecent"
```

```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Storage;
use Intervention\Image\Laravel\Facades\Image;

class ImageController extends Controller
{
    public function uploadAndResize(Request $request)
    {
        $request->validate([
            'photo' => 'required|image|mimes:jpeg,png,webp|max:10240',
        ]);

        $file = $request->file('photo');

        // Baca file
        $image = Image::read($file);

        // Resize dengan aspect ratio
        $image->resize(1200, null, function ($constraint) {
            $constraint->aspectRatio();
            $constraint->upsize();
        });

        // Simpan versi besar
        $image->save(storage_path("app/public/photos/large/{$file->hashName()}"));

        // Buat thumbnail (fit — crop kalau perlu)
        $thumbnail = Image::read($file)
            ->cover(300, 300);

        $thumbnail->save(storage_path("app/public/photos/thumb/{$file->hashName()}"));

        return response()->json([
            'large' => Storage::url("photos/large/{$file->hashName()}"),
            'thumb' => Storage::url("photos/thumb/{$file->hashName()}"),
        ]);
    }

    public function processProductImage(Request $request)
    {
        $file = $request->file('image');

        $image = Image::read($file);

        // Multiple operations
        $image->resize(800, 800, function ($c) {
            $c->aspectRatio();
        });

        // Tambahkan watermark
        $watermark = Image::read(public_path('images/watermark.png'));
        $watermark->resize(200, null, fn($c) => $c->aspectRatio());

        $image->place($watermark, 'bottom-right', 20, 20);

        // Optimasi kualitas
        $image->save(
            storage_path("app/public/products/{$file->hashName()}"),
            quality: 85 // 0-100
        );

        return response()->json([
            'url' => Storage::url("products/{$file->hashName()}"),
        ]);
    }
}
```

```php
<?php
// Contoh berbagai manipulasi

use Intervention\Image\Laravel\Facades\Image;

$image = Image::read($file);

// Resize
$image->resize(800, 600);                    // Ukuran pasti
$image->resize(800, null, fn($c) => $c->aspectRatio()); // Aspect ratio

// Crop
$image->crop(400, 400, 0, 0);                // Potong 400x400 dari (0,0)
$image->cover(300, 300);                     // Fit + crop center

// Effects
$image->brightness(10);                      // Kecerahan (-100 to 100)
$image->contrast(10);                        // Kontras (-100 to 100)
$image->greyscale();                         // Hitam putih
$image->blur(5);                             // Blur
$image->rotate(90);                          // Rotasi

// Text
$image->text('Copyright', 10, 50, function($font) {
    $font->file(public_path('fonts/arial.ttf'));
    $font->size(24);
    $font->color('#ffffff');
    $font->align('left');
});

// Output
$image->save('path/to/file.jpg', quality: 90);
$image->encode('webp');                      // Convert ke WebP
```

```php
<?php
// Responsive images — buat multiple sizes
class ImageService
{
    public function createResponsiveImages($file): array
    {
        $sizes = [
            'sm' => 320,
            'md' => 640,
            'lg' => 1024,
            'xl' => 1920,
        ];

        $paths = [];
        $baseName = pathinfo($file->hashName(), PATHINFO_FILENAME);

        foreach ($sizes as $label => $width) {
            $img = Image::read($file);
            $img->resize($width, null, fn($c) => $c->aspectRatio());

            $filename = "{$baseName}_{$label}.webp";
            $img->save(storage_path("app/public/responsive/{$filename}"));

            $paths[$label] = Storage::url("responsive/{$filename}");
        }

        return $paths;
    }
}
```
