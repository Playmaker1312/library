# 376. Jadwalkan queued job job

## Definisi Singkat
Menjadwalkan job queue untuk dijalankan pada waktu tertentu menggunakan method `$schedule->job()`.

## Analogi
Seperti menitipkan paket ke kurir — Anda titip (schedule job), kurir antar nanti pada waktunya (queue worker proses).

## Poin-Poin Penting
- `$schedule->job(JobClass::class)` — dispatch job ke queue
- Job akan masuk ke antrian queue yang sudah dikonfigurasi
- Bisa menentukan queue name: `$schedule->job($job, 'high')`
- Cocok untuk task berat yang tidak perlu langsung selesai
- Worker tetap perlu berjalan (`php artisan queue:work`)

## Contoh Kode
```php
<?php

namespace App\Jobs;

use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Queue\InteractsWithQueue;

class GenerateMonthlyInvoice implements ShouldQueue
{
    public function __construct(
        public int $userId,
        public string $period
    ) {}

    public function handle(): void
    {
        // Logika generate invoice...
        \Illuminate\Support\Facades\Log::info(
            "Invoice for user {$this->userId} period {$this->period}"
        );
    }
}
```

```php
<?php

// app/Console/Kernel.php
namespace App\Console;

use Illuminate\Console\Scheduling\Schedule;
use Illuminate\Foundation\Console\Kernel as ConsoleKernel;
use App\Jobs\GenerateMonthlyInvoice;
use App\Jobs\ProcessPendingOrders;
use App\Jobs\SendNewsletter;
use App\Jobs\CleanupExpiredSessions;

class Kernel extends ConsoleKernel
{
    protected function schedule(Schedule $schedule): void
    {
        // Schedule job — dispatch ke queue default
        $schedule->job(new ProcessPendingOrders)
            ->everyFiveMinutes();

        // Schedule job dengan queue spesifik
        $schedule->job(new GenerateMonthlyInvoice(1, '2024-01'), 'high')
            ->monthlyOn(1, '03:00');

        // Schedule job class (tanpa constructor params)
        $schedule->job(new CleanupExpiredSessions)
            ->daily();

        // Batch job
        $schedule->job(new SendNewsletter)
            ->weekly()
            ->mondays()
            ->at('08:00');
    }
}
```

```php
<?php
// Perbandingan command vs job

// COMMAND — synchronous, blocking
$schedule->command('report:generate')
    ->daily();

// JOB — asynchronous, via queue
$schedule->job(new GenerateReport)
    ->daily();

// COMMAND lebih cocok untuk:
// - Task ringan yang cepat selesai
// - Yang butuh output ke console
// - Yang butuh berinteraksi dengan user

// JOB lebih cocok untuk:
// - Task berat (lama, butuh resource besar)
// - Task yang bisa di-delay
// - Task yang perlu retry mechanism
```

## Kasus Penggunaan Nyata
Generate invoice bulanan, mengirim newsletter massal, proses data dalam jumlah besar, sinkronisasi dengan API eksternal, dan task berat lainnya.
