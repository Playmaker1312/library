# 377. Jadwalkan shell command exec

## Definisi Singkat
Method `$schedule->exec()` menjadwalkan perintah shell/system langsung dari scheduler Laravel.

## Analogi
Seperti asisten pribadi yang menjalankan perintah di terminal untuk Anda — Anda cukup bilang "jalankan ini" pada waktunya.

## Poin-Poin Penting
- `$schedule->exec('command')` — jalankan perintah shell
- Bisa script bash, node, python, atau binary apa pun
- Output bisa diarahkan ke file
- Path harus absolute atau dari system PATH
- Hati-hati dengan keamanan — pastikan command aman

## Contoh Kode
```php
<?php

namespace App\Console;

use Illuminate\Console\Scheduling\Schedule;
use Illuminate\Foundation\Console\Kernel as ConsoleKernel;

class Kernel extends ConsoleKernel
{
    protected function schedule(Schedule $schedule): void
    {
        // Shell command — backup database dengan mysqldump
        $schedule->exec(
            'mysqldump -u root --all-databases > ' . storage_path('backups/db.sql')
        )->dailyAt('02:00');

        // Python script
        $schedule->exec('python3 ' . base_path('scripts/analytics.py'))
            ->hourly()
            ->appendOutputTo(storage_path('logs/analytics.log'));

        // Node.js script
        $schedule->exec('node ' . base_path('scripts/generate-sitemap.js'))
            ->dailyAt('04:00');

        // Git pull untuk auto-deploy
        $schedule->exec('cd /var/www/app && git pull origin main')
            ->weekly()
            ->environments('production');

        // System maintenance
        $schedule->exec('docker system prune -f')
            ->weeklyOn(0, '03:00');

        // Multiple commands dengan &&
        $schedule->exec('cd ' . base_path() . ' && npm run build')
            ->dailyAt('05:00');
    }
}
```

```php
<?php
// Perbandingan exec vs command

// exec — shell command langsung
$schedule->exec('php artisan backup:run')->daily();

// command — via Artisan (lebih terintegrasi)
$schedule->command('backup:run')->daily();

// exec lebih cocok untuk:
// - Perintah sistem (mysqldump, docker, git)
// - Script non-PHP (python, node)
// - Perintah yang tidak ada di Artisan
```

```php
<?php
// Keamanan — validasi command
$schedule->exec(function () {
    $command = 'mysqldump -u ' . escapeshellarg(config('database.username'))
        . ' ' . escapeshellarg(config('database.database'))
        . ' > ' . storage_path('backups/daily.sql');

    return $command;
})->daily();
```

## Kasus Penggunaan Nyata
Backup database dengan mysqldump, build frontend assets, menjalankan script machine learning, git pull auto-deploy, dan maintenance sistem.
