# 385. Laravel Schedule Monitor

## Definisi Singkat
Laravel Schedule Monitor adalah package (biasanya Spatie) yang memantau task terjadwal dan memberikan notifikasi jika ada yang gagal atau terlewat.

## Analogi
Seperti satpam yang mengawasi CCTV jadwal — dia akan lapor jika ada jadwal yang terlewat atau error.

## Poin-Poin Penting
- Package: `spatie/laravel-schedule-monitor`
- Memonitor apakah task berjalan sesuai jadwal
- Mengirim notifikasi jika task gagal atau terlewat
- Menyimpan history eksekusi di database
- Integrasi dengan Slack, Mail, Discord, dll

## Contoh Kode
```bash
# Install package
composer require spatie/laravel-schedule-monitor

# Publish konfigurasi dan migrasi
php artisan vendor:publish --provider="Spatie\ScheduleMonitor\ScheduleMonitorServiceProvider"

# Jalankan migrasi
php artisan migrate
```

```php
<?php
// config/schedule-monitor.php

return [
    /*
     * Semua jadwal yang ingin dimonitor
     */
    'monitored_schedule' => [
        \App\Console\Commands\SendDailyReport::class,
        \App\Console\Commands\BackupDatabase::class,
    ],

    /*
     * Notifikasi channel
     */
    'notifications' => [
        'mail' => [
            'to' => ['admin@example.com'],
        ],
        'slack' => [
            'webhook_url' => env('SCHEDULE_MONITOR_SLACK_WEBHOOK'),
        ],
    ],

    /*
     * Grace time — toleransi keterlambatan (menit)
     */
    'grace_time' => 5,
];
```

```php
<?php
// app/Console/Kernel.php — dengan monitoring

use Spatie\ScheduleMonitor\Models\MonitoredScheduledTask;

class Kernel extends ConsoleKernel
{
    protected function schedule(Schedule $schedule): void
    {
        // Task yang dimonitor — otomatis tercatat
        $schedule->command('report:daily')
            ->daily()
            ->monitorName('Daily Report');  // Nama untuk monitoring

        $schedule->command('backup:database')
            ->dailyAt('02:00')
            ->monitorName('Database Backup');

        // Task tanpa monitorName — pakai default
        $schedule->command('cleanup:logs')
            ->weekly();
    }
}
```

## Kasus Penggunaan Nyata
Monitoring produksi untuk memastikan cron job berjalan, alerting jika backup gagal, tracking durasi eksekusi task, dan audit trail task terjadwal.
