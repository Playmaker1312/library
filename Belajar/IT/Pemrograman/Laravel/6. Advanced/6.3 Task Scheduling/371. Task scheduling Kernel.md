# 371. Task scheduling Kernel

## Definisi Singkat
Task Scheduling di Laravel memungkinkan penjadwalan tugas berulang (cron job) langsung dari kode PHP tanpa perlu menulis cron entry manual.

## Analogi
Seperti alarm pengingat — Anda set jadwal (task schedule), dan alarm akan berdering otomatis sesuai jadwal tanpa Anda ingat-ingat.

## Poin-Poin Penting
- Semua jadwal ditulis di `app/Console/Kernel.php`
- Method `schedule()` mendefinisikan semua task
- Hanya butuh SATU cron entry di server: `* * * * * php /path/to/artisan schedule:run`
- Laravel mengevaluasi jadwal setiap menit
- Mendukung berbagai frekuensi dan constraint

## Contoh Kode
```php
<?php

namespace App\Console;

use Illuminate\Console\Scheduling\Schedule;
use Illuminate\Foundation\Console\Kernel as ConsoleKernel;

class Kernel extends ConsoleKernel
{
    // Semua jadwal didefinisikan di sini
    protected function schedule(Schedule $schedule): void
    {
        // Task email — setiap jam
        $schedule->command('newsletter:send')
            ->hourly()
            ->withoutOverlapping()
            ->appendOutputTo(storage_path('logs/newsletter.log'));

        // Task cleanup — setiap hari jam 2 pagi
        $schedule->command('cleanup:logs')
            ->dailyAt('02:00')
            ->environments('production');

        // Query update — setiap 5 menit
        $schedule->job(new \App\Jobs\UpdateAnalytics)
            ->everyFiveMinutes();
    }

    protected function commands(): void
    {
        $this->load(__DIR__ . '/Commands');

        require base_path('routes/console.php');
    }
}
```

```php
<?php
// Satu baris cron entry di server
# Edit crontab: crontab -e
# Tambahkan:
# * * * * * cd /path/to/project && php artisan schedule:run >> /dev/null 2>&1
```

```php
<?php
// Cek jadwal yang terdaftar
// php artisan schedule:list
// php artisan schedule:test --name=newsletter:send
```

## Kasus Penggunaan Nyata
Menggantikan puluhan cron entry manual, mengirim email terjadwal, membersihkan log, backup database, update statistik, dan maintenance rutin.
