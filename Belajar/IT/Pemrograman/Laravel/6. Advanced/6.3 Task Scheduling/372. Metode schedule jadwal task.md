# 372. Metode schedule jadwal task

## Definisi Singkat
Method `schedule()` di Kernel adalah tempat di mana semua task dijadwalkan menggunakan sintaks yang ekspresif dan mudah dibaca.

## Analogi
Seperti papan jadwal di stasiun — Anda tinggal menuliskan jadwal keberangkatan (task) dan aturannya (frekuensi).

## Poin-Poin Penting
- Semua jadwal ditulis dalam method `schedule()`
- Parameter `$schedule` menyediakan fluent API
- Task bisa command, job, shell exec, atau closure
- Rantai method untuk aturan tambahan (constraint, timing)
- Jadwal dievaluasi setiap menit oleh `schedule:run`

## Contoh Kode
```php
<?php

namespace App\Console;

use Illuminate\Console\Scheduling\Schedule;
use Illuminate\Foundation\Console\Kernel as ConsoleKernel;

class Kernel extends ConsoleKernel
{
    protected function schedule(Schedule $schedule): void
    {
        // Format dasar: $schedule->TYPE()->FREQUENCY()->CONSTRAINTS()

        // 1. Artisan command
        $schedule->command('report:daily')
            ->dailyAt('23:00')
            ->timezone('Asia/Jakarta')
            ->environments('production');

        // 2. Queued job
        $schedule->job(new \App\Jobs\ProcessPendingOrders)
            ->everyThirtyMinutes();

        // 3. Shell command
        $schedule->exec('node generate-sitemap.js')
            ->weekly()
            ->appendOutputTo(storage_path('logs/sitemap.log'));

        // 4. Callback / Closure
        $schedule->call(function () {
            \Illuminate\Support\Facades\Log::info('Health check');
        })->everyMinute();

        // 5. Command dengan parameter
        $schedule->command('email:send --type=promo --force')
            ->mondays()
            ->at('09:00');

        // 6. Multiple constraint
        $schedule->command('backup:run')
            ->daily()
            ->at('01:00')
            ->withoutOverlapping(60)
            ->sendOutputTo(storage_path('logs/backup.log'))
            ->emailOutputTo('admin@example.com');
    }
}
```

```php
<?php
// Daftar method yang bisa digunakan di schedule()

$schedule->command('command:name');  // Artisan command
$schedule->job(JobClass::class);     // Queued job
$schedule->exec('shell command');    // Shell command
$schedule->call(function() { ... }); // Closure/callback

// Semua berantai dengan frequency methods
```

## Kasus Penggunaan Nyata
Dengan method `schedule()`, Anda bisa mengatur seluruh jadwal aplikasi di satu tempat — dari email campaign, backup, cleanup, hingga integrasi dengan sistem eksternal.
