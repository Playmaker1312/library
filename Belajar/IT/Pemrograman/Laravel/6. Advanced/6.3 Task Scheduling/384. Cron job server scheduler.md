# 384. Cron job server scheduler

## Definisi Singkat
Cron job server adalah entry `* * * * *` di server yang memicu Laravel Scheduler setiap menit agar jadwal di Kernel dievaluasi.

## Analogi
Seperti detak jantung — cron entry adalah detak yang membuat scheduler hidup dan bekerja setiap menit.

## Poin-Poin Penting
- Hanya SATU cron entry yang dibutuhkan: `* * * * *`
- Entry memanggil `php artisan schedule:run`
- Scheduler mengevaluasi semua jadwal dan menjalankan yang jatuh tempo
- Cron entry didaftarkan di crontab user server
- Untuk Windows, gunakan Task Scheduler atau WSL

## Contoh Kode
```bash
# Buka crontab
crontab -e

# Tambahkan SATU baris ini:
* * * * * cd /var/www/project && php artisan schedule:run >> /dev/null 2>&1
```

```php
<?php
// Cek apakah cron entry sudah benar
// Jalankan di terminal:
// php artisan schedule:run

// Untuk test tanpa benar-benar menjalankan:
// php artisan schedule:list           — lihat semua jadwal
// php artisan schedule:test           — test jadwal interaktif
```

```bash
# Format cron entry
# * * * * * command
# | | | | |
# | | | | +---- Hari dalam minggu (0-7, 0=Minggu)
# | | | +------ Bulan (1-12)
# | | +-------- Hari dalam bulan (1-31)
# | +---------- Jam (0-23)
# +------------ Menit (0-59)

# * * * * * = SETIAP MENIT
# Ini memastikan Laravel mengecek jadwal setiap menit
```

```bash
# Contoh untuk berbagai situasi

# Production — arahkan output ke null (tidak disimpan)
* * * * * cd /var/www/app && php artisan schedule:run >> /dev/null 2>&1

# Development — simpan output untuk debugging
* * * * * cd /var/www/app && php artisan schedule:run >> storage/logs/cron.log 2>&1

# Dengan user spesifik (jika perlu)
* * * * * www-data cd /var/www/app && php artisan schedule:run

# Multiple project di satu server
* * * * * cd /var/www/project1 && php artisan schedule:run
* * * * * cd /var/www/project2 && php artisan schedule:run
```

```php
<?php
// Untuk Windows, gunakan Task Scheduler:
// 1. Buka Task Scheduler
// 2. Create Basic Task
// 3. Trigger: Every 1 minute
// 4. Action: Start a program
// 5. Program: php.exe
// 6. Arguments: artisan schedule:run
// 7. Start in: C:\path\to\project

// Atau WSL (Windows Subsystem for Linux) dengan cron Linux biasa
```

## Kasus Penggunaan Nyata
Wajib di setup di server produksi agar scheduler Laravel berfungsi. Tanpa cron entry, tidak ada jadwal yang akan berjalan.
