# 374. Cron expression kustom

## Definisi Singkat
Selain frequency method bawaan, Laravel juga mendukung cron expression kustom untuk jadwal yang lebih fleksibel.

## Analogi
Seperti remote universal — jika tombol bawaan tidak cukup, Anda bisa program sendiri sesuai keinginan.

## Poin-Poin Penting
- Method `->cron('* * * * *')` untuk ekspresi cron manual
- Format: `menit jam hari-tanggal bulan hari-minggu`
- Berguna untuk jadwal yang tidak tercakup method bawaan
- Bisa menggunakan `->expression()` sebagai alias
- Validasi ekspresi cron otomatis

## Contoh Kode
```php
<?php

namespace App\Console;

use Illuminate\Console\Scheduling\Schedule;
use Illuminate\Foundation\Console\Kernel as ConsoleKernel;

class Kernel extends ConsoleKernel
{
    protected function schedule(Schedule $schedule): void
    {
        // Cron expression kustom

        // Setiap 15 menit (sudah ada method, tapi contoh)
        $schedule->command('sync:data')
            ->cron('*/15 * * * *');

        // Setiap jam 8 pagi dan 5 sore (Senin-Jumat)
        $schedule->command('report:send')
            ->cron('0 8,17 * * 1-5');

        // Setiap hari pertama setiap bulan jam 3 pagi
        $schedule->command('billing:invoice')
            ->cron('0 3 1 * *');

        // Setiap 30 detik (kombinasi dua cron)
        $schedule->command('health:check')
            ->cron('* * * * *')
            ->withoutOverlapping(30);

        // Setiap 2 jam antara jam 8 pagi - 6 sore
        $schedule->command('cache:warm')
            ->cron('0 8-18/2 * * *');

        // Akhir pekan jam 12 siang
        $schedule->command('backup:test')
            ->cron('0 12 * * 0,6');

        // Setiap 5 menit, tapi hanya Senin
        $schedule->command('special:task')
            ->cron('*/5 * * * 1');
    }
}
```

```php
<?php
// Contoh ekspresi cron umum

// */5 * * * *     = Setiap 5 menit
// 0 * * * *       = Setiap jam (menit 0)
// 0 0 * * *       = Setiap hari jam 00:00
// 0 0 * * 0       = Setiap Minggu jam 00:00
// 0 0 1 * *       = Tanggal 1 setiap bulan
// 0 0 * * 1-5     = Senin-Jumat jam 00:00
// 0 9,18 * * *    = Jam 9 pagi dan 6 sore
// */30 9-17 * * * = Setiap 30 menit antara jam 9-17
// 0 0 1 1 *       = 1 Januari setiap tahun
```

```php
<?php
// Helper untuk cron expression
// Gunakan https://crontab.guru untuk validasi

// Laravel juga support ->expression() alias
$schedule->command('task:run')
    ->expression('0 0 * * *');
```

## Kasus Penggunaan Nyata
Jadwal kompleks yang tidak bisa diakomodasi method bawaan, misalnya setiap 90 menit, jam kerja tertentu, atau akhir pekan saja.
