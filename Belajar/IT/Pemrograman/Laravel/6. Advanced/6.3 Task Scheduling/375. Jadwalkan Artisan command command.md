# 375. Jadwalkan Artisan command command

## Definisi Singkat
Menjadwalkan Artisan command untuk berjalan otomatis pada waktu tertentu menggunakan method `$schedule->command()`.

## Analogi
Seperti menyetel rekaman TV — Anda set agar acara direkam (command dijalankan) pada jam tayang (jadwal), tanpa Anda harus bangun.

## Poin-Poin Penting
- `$schedule->command('command:name {param}')` — jalankan command
- Bisa menggunakan class command (FQCN): `$schedule->command(SendEmail::class)`
- Parameter dan opsi bisa ditambahkan seperti di CLI
- Output bisa diarahkan ke file atau email

## Contoh Kode
```php
<?php

// app/Console/Commands/SendDailyReport.php
namespace App\Console\Commands;

use Illuminate\Console\Command;

class SendDailyReport extends Command
{
    protected $signature = 'report:daily
                            {--type=summary : Tipe laporan}
                            {--force : Paksa kirim}';

    protected $description = 'Kirim laporan harian';

    public function handle()
    {
        $type = $this->option('type');
        $this->info("Mengirim laporan {$type}...");

        // Logika kirim laporan...

        $this->info('Laporan terkirim!');
    }
}
```

```php
<?php

// app/Console/Kernel.php
namespace App\Console;

use Illuminate\Console\Scheduling\Schedule;
use Illuminate\Foundation\Console\Kernel as ConsoleKernel;
use App\Console\Commands\SendDailyReport;

class Kernel extends ConsoleKernel
{
    protected function schedule(Schedule $schedule): void
    {
        // Cara 1: String signature
        $schedule->command('report:daily --type=summary')
            ->dailyAt('07:00');

        // Cara 2: Fully Qualified Class Name
        $schedule->command(SendDailyReport::class, ['--type' => 'detailed'])
            ->dailyAt('17:00');

        // Dengan parameter
        $schedule->command('email:send --type=promo --force')
            ->mondays()
            ->at('09:00');

        // Multiple command
        $schedule->command('cache:clear')
            ->hourly();

        $schedule->command('queue:restart')
            ->everyFourHours();
    }
}
```

```php
<?php
// Daftar command yang bisa dijadwalkan

// Command bawaan Laravel
$schedule->command('cache:clear')->daily();
$schedule->command('queue:flush')->weekly();
$schedule->command('sanctum:prune-expired')->daily();
$schedule->command('telescope:prune')->daily();

// Command kustom Anda
$schedule->command('report:daily')->dailyAt('06:00');
$schedule->command('backup:run')->weeklyOn(0, '01:00');
$schedule->command('sync:inventory')->everyThirtyMinutes();
```

## Kasus Penggunaan Nyata
Mengirim email report otomatis, backup database, generate sitemap, sinkronisasi data, membersihkan data expired, dan maintenance rutin.
