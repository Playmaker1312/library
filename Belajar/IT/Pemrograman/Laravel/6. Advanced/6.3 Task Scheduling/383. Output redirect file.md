# 383. Output redirect file

## Definisi Singkat
Output dari task terjadwal bisa diarahkan ke file untuk logging, debugging, atau email notifikasi.

## Analogi
Seperti CCTV yang merekam aktivitas — Anda bisa lihat rekaman (log file) untuk tahu apa yang terjadi.

## Poin-Poin Penting
- `->sendOutputTo($path)` — simpan output ke file
- `->appendOutputTo($path)` — tambahkan ke file (tidak overwrite)
- `->emailOutputTo($email)` — kirim output via email
- `->emailWrittenOutputTo($email)` — kirim hanya jika ada output
- File path relatif terhadap storage_path

## Contoh Kode
```php
<?php

namespace App\Console;

use Illuminate\Console\Scheduling\Schedule;
use Illuminate\Foundation\Console\Kernel as ConsoleKernel;

class Kernel extends ConsoleKernel
{
    protected function schedule(Schedule $schedule): void
    {
        // Simpan output ke file (overwrite)
        $schedule->command('report:daily')
            ->daily()
            ->sendOutputTo(storage_path('logs/report.log'));

        // Append output (tambahkan, tidak overwrite)
        $schedule->command('sync:data')
            ->everyFiveMinutes()
            ->appendOutputTo(storage_path('logs/sync.log'));

        // Kirim output via email
        $schedule->command('backup:database')
            ->daily()
            ->sendOutputTo(storage_path('logs/backup.log'))
            ->emailOutputTo('admin@example.com');

        // Email hanya jika ada output (tidak kosong)
        $schedule->command('cleanup:temp')
            ->hourly()
            ->emailWrittenOutputTo('devops@example.com');

        // Kombinasi lengkap
        $schedule->command('health:check')
            ->everyMinute()
            ->appendOutputTo(storage_path('logs/health.log'))
            ->emailOutputOnFailure('alert@example.com');
    }
}
```

```php
<?php
// Log rotation — penting untuk file besar
// Tambahkan di schedule atau cron terpisah:
$schedule->command('logs:rotate')
    ->weekly()
    ->sendOutputTo(storage_path('logs/rotation.log'));
```

```php
<?php
// Melihat output yang tersimpan
// storage/logs/report.log — isi output command
// storage/logs/sync.log — history sinkronisasi

// Format output termasuk timestamp dan status
// [2024-01-15 08:00:01] Report selesai: 1500 data diproses
// [2024-01-15 08:05:01] Report selesai: 1523 data diproses
```

## Kasus Penggunaan Nyata
Audit trail task terjadwal, debugging cron job, notifikasi error ke email, monitoring health check, dan dokumentasi output task untuk compliance.
