# 379. Constraint weekdays weekends environments when

## Definisi Singkat
Constraint membatasi kapan task berjalan berdasarkan hari, environment, atau kondisi tertentu.

## Analogi
Seperti aturan "happy hour" di restoran — diskon hanya berlaku hari kerja jam tertentu (weekdays), bukan akhir pekan.

## Poin-Poin Penting
- `->weekdays()` — hanya Senin-Jumat
- `->weekends()` — hanya Sabtu-Minggu
- `->environments('production')` — hanya di environment tertentu
- `->when(Closure)` — kondisi kustom (return true/false)
- `->skip(Closure)` — kebalikan dari when

## Contoh Kode
```php
<?php

namespace App\Console;

use Illuminate\Console\Scheduling\Schedule;
use Illuminate\Foundation\Console\Kernel as ConsoleKernel;

class Kernel extends ConsoleKernel
{
    protected function schedule(Schedule $schedule): void
    {
        // Weekdays — hanya hari kerja
        $schedule->command('report:daily')
            ->dailyAt('08:00')
            ->weekdays();

        // Weekends — hanya akhir pekan
        $schedule->command('backup:full')
            ->dailyAt('02:00')
            ->weekends();

        // Environments — hanya di production
        $schedule->command('emails:send-bulk')
            ->hourly()
            ->environments('production');

        // when — kondisi kustom
        $schedule->command('promo:activate')
            ->daily()
            ->when(function () {
                // Jalankan hanya jika hari ini ada promo
                return \App\Models\Promo::whereDate('start_date', today())->exists();
            });

        // skip — kebalikan when
        $schedule->command('cleanup:temp')
            ->hourly()
            ->skip(function () {
                // Skip jika aplikasi dalam maintenance
                return app()->isDownForMaintenance();
            });

        // Kombinasi
        $schedule->command('sync:inventory')
            ->everyThirtyMinutes()
            ->weekdays()
            ->between('8:00', '17:00')
            ->environments('production', 'staging');
    }
}
```

```php
<?php
// Hari spesifik
$schedule->command('task:run')
    ->mondays();        // Senin

$schedule->command('task:run')
    ->tuesdays();       // Selasa

$schedule->command('task:run')
    ->wednesdays();     // Rabu

$schedule->command('task:run')
    ->thursdays();      // Kamis

$schedule->command('task:run')
    ->fridays();        // Jumat

$schedule->command('task:run')
    ->saturdays();      // Sabtu

$schedule->command('task:run')
    ->sundays();        // Minggu
```

## Kasus Penggunaan Nyata
Report hanya hari kerja, backup besar hanya akhir pekan, task development hanya di local, dan task bersyarat berdasarkan data di database.
