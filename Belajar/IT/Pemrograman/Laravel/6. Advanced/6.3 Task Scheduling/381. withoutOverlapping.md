# 381. withoutOverlapping

## Definisi Singkat
Constraint `->withoutOverlapping()` mencegah task yang sama berjalan secara bersamaan (overlap) jika task sebelumnya belum selesai.

## Analogi
Seperti pintu geser di kereta — hanya satu pintu yang bisa dibuka dalam satu waktu. Pintu berikutnya menunggu sampai pintu pertama tertutup.

## Poin-Poin Penting
- `->withoutOverlapping()` — cegah overlap
- `->withoutOverlapping(60)` — lock otomatis lepas setelah 60 menit
- Menggunakan cache lock di belakang layar
- Penting untuk task yang berjalan lebih lama dari interval
- Mencegah double processing data

## Contoh Kode
```php
<?php

namespace App\Console;

use Illuminate\Console\Scheduling\Schedule;
use Illuminate\Foundation\Console\Kernel as ConsoleKernel;

class Kernel extends ConsoleKernel
{
    protected function schedule(Schedule $schedule): void
    {
        // Without overlapping — jika task masih berjalan, skip
        $schedule->command('report:generate')
            ->everyFiveMinutes()
            ->withoutOverlapping();

        // Dengan timeout — lepaskan lock setelah 30 menit
        $schedule->command('sync:customers')
            ->everyMinute()
            ->withoutOverlapping(30);  // Lock timeout 30 menit

        // Kombinasi dengan constraint lain
        $schedule->command('backup:database')
            ->hourly()
            ->withoutOverlapping(120)
            ->sendOutputTo(storage_path('logs/backup.log'));

        // Job juga bisa withoutOverlapping
        $schedule->job(new \App\Jobs\ProcessQueue)
            ->everyMinute()
            ->withoutOverlapping(10);
    }
}
```

```php
<?php

namespace App\Console\Commands;

use Illuminate\Console\Command;

class GenerateReport extends Command
{
    protected $signature = 'report:generate';
    protected $description = 'Generate laporan (butuh 10 menit)';

    public function handle()
    {
        $this->info('Memulai generate report...');

        // Simulasi proses lama
        sleep(600); // 10 menit

        $this->info('Report selesai!');
    }
}
```

```php
<?php
// Tanpa withoutOverlapping:
// 08:00 — Task mulai (jalan 10 menit)
// 08:05 — Task mulai LAGI (overlap — 2 proses jalan)
// 08:10 — Task pertama selesai
// 08:15 — Task kedua selesai (duplikasi, error)

// Dengan withoutOverlapping:
// 08:00 — Task mulai (lock didapat)
// 08:05 — Task mencoba mulai (lock masih ada) → SKIP
// 08:10 — Task selesai (lock dilepas)
// 08:15 — Task mulai normal
```

## Kasus Penggunaan Nyata
Cron job yang mungkin berjalan lebih lama dari interval, sinkronisasi data massal, backup database, proses import/export, dan task dengan akses resource eksklusif.
