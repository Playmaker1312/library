# 380. between unlessBetween

## Definisi Singkat
Constraint `->between()` dan `->unlessBetween()` membatasi task berjalan dalam rentang waktu tertentu.

## Analogi
Seperti jam operasional toko — buka jam 8 pagi sampai 5 sore (between), di luar itu tutup (unlessBetween).

## Poin-Poin Penting
- `->between('08:00', '17:00')` — hanya jalan dalam rentang
- `->unlessBetween('22:00', '06:00')` — jalan di luar rentang
- Menggunakan waktu server (timezone dari config)
- Bisa dikombinasikan dengan constraint lain
- Berguna untuk task yang hanya relevan di jam kerja

## Contoh Kode
```php
<?php

namespace App\Console;

use Illuminate\Console\Scheduling\Schedule;
use Illuminate\Foundation\Console\Kernel as ConsoleKernel;

class Kernel extends ConsoleKernel
{
    protected function schedule(Schedule $schedule): void
    {
        // between — hanya jalan antara jam 8 pagi - 5 sore
        $schedule->command('sync:inventory')
            ->everyThirtyMinutes()
            ->between('8:00', '17:00')
            ->weekdays();

        // unlessBetween — jalan di luar jam sibuk
        $schedule->command('backup:incremental')
            ->everyFifteenMinutes()
            ->unlessBetween('08:00', '20:00');

        // between untuk notifikasi jam kerja
        $schedule->command('notification:send')
            ->hourly()
            ->between('09:00', '18:00')
            ->environments('production');

        // Maintenance task di malam hari
        $schedule->command('cleanup:logs')
            ->hourly()
            ->between('00:00', '06:00');
    }
}
```

```php
<?php
// between vs unlessBetween

// Hanya jalan antara jam 8 pagi - 5 sore
$schedule->command('task:day')
    ->everyHour()
    ->between('08:00', '17:00');

// Jalan di luar jam 10 malam - 6 pagi (yaitu 06:00 - 22:00)
$schedule->command('task:day')
    ->everyHour()
    ->unlessBetween('22:00', '06:00');
```

```php
<?php
// Kombinasi dengan timezone
$schedule->command('task:run')
    ->dailyAt('08:00')
    ->between('08:00', '17:00')
    ->timezone('Asia/Jakarta');
```

## Kasus Penggunaan Nyata
Sinkronisasi data hanya jam kerja, notifikasi hanya jam kantor, backup di luar jam sibuk, dan maintenance di malam hari.
