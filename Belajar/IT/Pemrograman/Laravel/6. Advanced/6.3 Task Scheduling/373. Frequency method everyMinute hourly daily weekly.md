# 373. Frequency method everyMinute hourly daily weekly

## Definisi Singkat
Frequency methods menentukan seberapa sering task dijalankan — dari setiap menit hingga tahunan.

## Analogi
Seperti pengatur waktu di microwave — Anda bisa set 1 menit (everyMinute), 1 jam (hourly), atau terjadwal setiap hari (daily).

## Poin-Poin Penting
- `->everyMinute()` — setiap menit
- `->hourly()` — setiap jam
- `->daily()` — setiap tengah malam
- `->weekly()` — setiap hari Minggu
- `->monthly()` — setiap tanggal 1
- Bisa dikombinasikan dengan `->at('HH:MM')` untuk waktu spesifik

## Contoh Kode
```php
<?php

namespace App\Console;

use Illuminate\Console\Scheduling\Schedule;
use Illuminate\Foundation\Console\Kernel as ConsoleKernel;

class Kernel extends ConsoleKernel
{
    protected function schedule(Schedule $schedule): void
    {
        // Every Minute
        $schedule->command('cache:check')
            ->everyMinute();

        // Every X minutes
        $schedule->command('analytics:update')
            ->everyFiveMinutes();

        $schedule->command('sync:data')
            ->everyTenMinutes();

        $schedule->command('notification:process')
            ->everyFifteenMinutes();

        $schedule->command('queue:monitor')
            ->everyThirtyMinutes();

        // Hourly
        $schedule->command('report:hourly')
            ->hourly();  // Menit ke-0 setiap jam

        $schedule->command('cleanup:temp')
            ->hourlyAt(15);  // Menit ke-15 setiap jam

        // Daily
        $schedule->command('email:daily')
            ->daily();  // Tengah malam

        $schedule->command('report:daily')
            ->dailyAt('06:00');  // Jam 6 pagi

        // Weekly
        $schedule->command('backup:full')
            ->weekly();  // Minggu tengah malam

        $schedule->command('maintenance:weekly')
            ->weeklyOn(3, '02:00');  // Rabu jam 2 pagi

        // Monthly
        $schedule->command('billing:monthly')
            ->monthly();  // Tanggal 1 tengah malam

        $schedule->command('report:monthly')
            ->monthlyOn(5, '08:00');  // Tanggal 5 jam 8 pagi

        // Yearly
        $schedule->command('cleanup:archives')
            ->yearly();

        // Weekdays / Weekends
        $schedule->command('report:weekday')
            ->weekdays()
            ->dailyAt('09:00');

        $schedule->command('backup:weekend')
            ->weekends()
            ->dailyAt('23:00');
    }
}
```

```php
<?php
// Tabel frekuensi
| Method | Deskripsi |
|--------|-----------|
| ->everyMinute() | Setiap menit |
| ->everyTwoMinutes() | Setiap 2 menit |
| ->everyFiveMinutes() | Setiap 5 menit |
| ->everyTenMinutes() | Setiap 10 menit |
| ->everyFifteenMinutes() | Setiap 15 menit |
| ->everyThirtyMinutes() | Setiap 30 menit |
| ->hourly() | Setiap jam |
| ->hourlyAt(15) | Setiap jam menit ke-15 |
| ->daily() | Setiap hari jam 00:00 |
| ->dailyAt('06:00') | Setiap hari jam 06:00 |
| ->twiceDaily(1, 13) | Dua kali sehari |
| ->weekly() | Setiap minggu |
| ->weeklyOn(1, '08:00') | Senin jam 08:00 |
| ->monthly() | Setiap bulan |
| ->monthlyOn(15, '10:00') | Tanggal 15 jam 10:00 |
| ->yearly() | Setiap tahun |
```

## Kasus Penggunaan Nyata
Menyesuaikan frekuensi task dengan kebutuhan — analytics ringan setiap 5 menit, email campaign setiap jam, backup full setiap minggu, laporan keuangan setiap bulan.
