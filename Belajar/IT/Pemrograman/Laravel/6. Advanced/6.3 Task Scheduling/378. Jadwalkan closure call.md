# 378. Jadwalkan closure call

## Definisi Singkat
Method `$schedule->call()` menjadwalkan closure/callback untuk dijalankan langsung tanpa perlu membuat command atau job.

## Analogi
Seperti sticky note pengingat — Anda tulis apa yang harus dilakukan (closure) dan tempel di jadwal (scheduler).

## Poin-Poin Penting
- `$schedule->call(function() { ... })` — closure langsung
- Cocok untuk task sederhana dan ringan
- Tidak perlu membuat class Command atau Job terpisah
- Closure dieksekusi langsung oleh scheduler (synchronous)
- Untuk task berat, lebih baik pakai job

## Contoh Kode
```php
<?php

namespace App\Console;

use Illuminate\Console\Scheduling\Schedule;
use Illuminate\Foundation\Console\Kernel as ConsoleKernel;
use Illuminate\Support\Facades\Log;
use Illuminate\Support\Facades\DB;
use App\Models\User;

class Kernel extends ConsoleKernel
{
    protected function schedule(Schedule $schedule): void
    {
        // Simple logging
        $schedule->call(function () {
            Log::info('Health check: scheduler berjalan.');
        })->everyMinute();

        // Cleanup temporary data
        $schedule->call(function () {
            DB::table('sessions')
                ->where('last_activity', '<', now()->subDays(30)->timestamp)
                ->delete();

            Log::info('Sessions lama dibersihkan.');
        })->daily();

        // Update status
        $schedule->call(function () {
            User::where('email_verified_at', null)
                ->where('created_at', '<', now()->subDays(7))
                ->update(['status' => 'expired']);
        })->dailyAt('03:00');

        // Cache maintenance
        $schedule->call(function () {
            $stats = [
                'users' => User::count(),
                'memory' => memory_get_usage(true),
            ];

            \Illuminate\Support\Facades\Cache::put('app.health', $stats, 3600);
        })->everyFiveMinutes();
    }
}
```

```php
<?php
// Closure dengan dependency injection
use App\Services\ReportService;

$schedule->call(function (ReportService $report) {
    $report->generateSummary();
})->dailyAt('23:00');
```

```php
<?php
// Kapan pakai call vs command vs job

// call — untuk task SIMPLE dan RINGAN
$schedule->call(fn() => Log::info('tick'))->everyMinute();

// command — untuk task TERSTRUKTUR yang reusable
$schedule->command('report:daily')->daily();

// job — untuk task BERAT asynchronous
$schedule->job(new HeavyProcess)->hourly();
```

## Kasus Penggunaan Nyata
Logging health check, cleanup data ringan, update status massal, cache warming sederhana, dan task satu-baris yang tidak perlu class terpisah.
