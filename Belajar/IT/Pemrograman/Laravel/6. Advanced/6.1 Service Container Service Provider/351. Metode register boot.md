# 351. Metode register boot

## Definisi Singkat
Dua method utama di Service Provider: `register()` untuk binding ke container, `boot()` untuk menjalankan logika setelah semua provider terdaftar.

## Analogi
Seperti pembangunan rumah — register adalah memasang fondasi (binding), boot adalah memasang perabotan setelah struktur rumah selesai.

## Poin-Poin Penting
- `register()`: Hanya untuk binding, jangan gunakan service lain
- `boot()`: Semua provider sudah terdaftar, aman menggunakan service lain
- Urutan: semua `register()` dipanggil dulu, baru semua `boot()`
- Di `boot()` bisa inject dependency otomatis
- Jangan pakai event, database, atau routing di `register()`

## Contoh Kode
```php
<?php

namespace App\Providers;

use Illuminate\Support\ServiceProvider;
use Illuminate\Support\Facades\View;
use App\Services\SettingsService;

class AppServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        // HANYA binding — tidak boleh pakai service lain
        $this->app->singleton(SettingsService::class, function ($app) {
            return new SettingsService();
        });

        // Binding interface
        $this->app->bind(
            \App\Contracts\CacheService::class,
            \App\Services\RedisCacheService::class
        );
    }

    public function boot(): void
    {
        // Di sini aman — semua provider sudah terdaftar

        // Inject dependency otomatis — container sudah siap
        view()->composer('layouts.sidebar', function ($view) {
            $settings = app(SettingsService::class);
            $view->with('settings', $settings->all());
        });

        // Mendaftarkan route model binding
        \Illuminate\Support\Facades\Route::model('user', \App\Models\User::class);
    }
}
```

```php
<?php

namespace App\Providers;

use Illuminate\Support\ServiceProvider;
use Illuminate\Support\Facades\Blade;

class ViewServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        // Binding directive parser
    }

    public function boot(): void
    {
        // Aman menggunakan Blade karena sudah terdaftar
        Blade::directive('currency', function ($expression) {
            return "<?php echo 'Rp' . number_format($expression, 0, ',', '.'); ?>";
        });
    }
}
```

## Kasus Penggunaan Nyata
Di `register()`: binding service, repository, interface. Di `boot()`: view composer, blade directive, route model binding, event listener.
