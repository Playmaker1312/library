# 355. Helper app Service Container

## Definisi Singkat
Helper function `app()` adalah cara cepat untuk mengakses Service Container dan me-resolve dependency.

## Analogi
Seperti tombol "panggil" di lift — satu tekan (satu fungsi) langsung menghubungkan Anda ke tempat tujuan.

## Poin-Poin Penting
- `app()` mengembalikan instance container jika tanpa parameter
- `app(ClassName::class)` me-resolve class dari container
- `app()->bind()`, `app()->singleton()` untuk binding
- `app()->make()` sama dengan `app(Class::class)`
- Alternatif: helper `resolve()` dan `container()`

## Contoh Kode
```php
<?php

use App\Services\CurrencyConverter;
use Illuminate\Support\Facades\Route;

// Helper app() — berbagai cara penggunaan

// 1. Mengembalikan instance container
$container = app();
$container->singleton('currency', CurrencyConverter::class);

// 2. Me-resolve class dari container (sama dengan make)
$converter = app(CurrencyConverter::class);

// 3. Dengan parameter tambahan
$converter = app()->makeWith(CurrencyConverter::class, [
    'apiKey' => config('services.currency.api_key')
]);

// 4. Binding di runtime
app()->bind('currency.formatter', function ($app) {
    return new CurrencyConverter('USD', 'IDR');
});

// 5. Cek binding
if (app()->has('currency.formatter')) {
    $formatter = app('currency.formatter');
}
```

```php
<?php

namespace App\Http\Controllers;

use App\Services\InvoiceService;

class InvoiceController extends Controller
{
    public function download(string $id)
    {
        // Helper resolve() — alternatif app()
        $invoice = resolve(InvoiceService::class)->generatePdf($id);

        return response()->download($invoice);
    }
}
```

```php
<?php
// Di routes/web.php — helper app di closure

use App\Services\ExchangeRate;

Route::get('/rate/{currency}', function (string $currency) {
    // Menggunakan helper app() di closure
    $rate = app(ExchangeRate::class)->getRate($currency);

    return response()->json(['currency' => $currency, 'rate' => $rate]);
});
```

```php
// Tabel helper
| Fungsi | Penggunaan |
|--------|------------|
| `app()` | Instance container |
| `app(Class::class)` | Resolve class |
| `resolve(Class::class)` | Sama dengan app() |
| `app()->make(Class::class)` | Resolve class |
| `app()->makeWith(Class::class, [...])` | Resolve dengan parameter |
| `app()->bind(...)` | Binding baru |
| `app()->singleton(...)` | Singleton binding |
```

## Kasus Penggunaan Nyata
Akses container di helper custom, route closure, middleware anonim, testing, atau Artisan command tanpa dependency injection.
