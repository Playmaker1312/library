# 354. Cara Kerja Facade

## Definisi Singkat
Facade di Laravel bekerja dengan meneruskan panggilan static ke objek nyata di Service Container melalui method `__callStatic`.

## Analogi
Seperti resepsionis kantor — Anda minta "tolong panggilkan Pak Budi" (static call), resepsionis (facade) menghubungi Pak Budi (service) dan menyampaikan pesan Anda.

## Poin-Poin Penting
- Setiap facade mewarisi class `Facade`
- Method `getFacadeAccessor()` menentukan binding key di container
- Panggilan static ditangkap oleh `__callStatic()` PHP
- Container meresolve objek, lalu method dipanggil pada objek tersebut
- Facade adalah syntactic sugar untuk `$app->make()`

## Contoh Kode
```php
<?php

// Lihat bagaimana Facade bekerja secara internal
namespace Illuminate\Support\Facades;

abstract class Facade
{
    // Method ini dipanggil saat method static tidak ditemukan
    public static function __callStatic($method, $args)
    {
        // Dapatkan instance dari container
        $instance = static::getFacadeRoot();

        if (!$instance) {
            throw new \RuntimeException('Facade root belum terdaftar.');
        }

        // Panggil method pada instance nyata
        return $instance->$method(...$args);
    }

    // Ambil objek dari container berdasarkan accessor
    public static function getFacadeRoot()
    {
        return static::resolveFacadeInstance(static::getFacadeAccessor());
    }

    protected static function resolveFacadeInstance($name)
    {
        return app($name);
    }

    // Wajib diimplementasikan di facade turunan
    protected static function getFacadeAccessor()
    {
        throw new \RuntimeException('Facade tidak mengimplementasikan getFacadeAccessor.');
    }
}
```

```php
<?php

namespace App\Facades;

use Illuminate\Support\Facades\Facade;

class Analytics extends Facade
{
    protected static function getFacadeAccessor(): string
    {
        return 'analytics.service';  // Key binding di container
    }
}
```

```php
// Apa yang terjadi ketika Anda panggil:
Analytics::trackEvent('page_view', ['url' => '/home']);

// 1. PHP找不到 trackEvent static method
// 2. __callStatic('trackEvent', ['page_view', [...]]) dipanggil
// 3. getFacadeAccessor() -> 'analytics.service'
// 4. resolveFacadeInstance('analytics.service') -> app('analytics.service')
// 5. $instance->trackEvent('page_view', ['url' => '/home']) dijalankan
```

```php
// Tanpa facade, kita harus melakukan:
$analytics = app('analytics.service');
$analytics->trackEvent('page_view', ['url' => '/home']);

// Dengan facade:
Analytics::trackEvent('page_view', ['url' => '/home']);
```

## Kasus Penggunaan Nyata
Facade digunakan di seluruh Laravel — `Cache::get()`, `DB::table()`, `Storage::put()`, `Mail::send()` — semuanya bekerja dengan cara yang sama.
