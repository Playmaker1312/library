# 346. Contextual Binding

## Definisi Singkat
Contextual binding memungkinkan binding berbeda untuk kelas yang sama tergantung pada kelas penggunanya (konteks).

## Analogi
Seperti kunci universal — pintu rumah Anda (konteks A) butuh kunci satu, pintu kantor (konteks B) butuh kunci berbeda, meskipun keduanya adalah "pintu".

## Poin-Poin Penting
- Binding berbeda untuk interface/class yang sama di konteks berbeda
- Didaftarkan menggunakan `when()->needs()->give()`
- Berguna untuk mengganti dependency spesifik di kelas tertentu
- Menghindari binding global yang terlalu umum

## Contoh Kode
```php
<?php

namespace App\Providers;

use Illuminate\Support\ServiceProvider;
use App\Contracts\FileStorage;
use App\Services\LocalFileStorage;
use App\Services\CloudFileStorage;
use App\Http\Controllers\ReportController;
use App\Jobs\GenerateBackupJob;

class AppServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        // Secara default, FileStorage指向 LocalFileStorage
        $this->app->bind(FileStorage::class, LocalFileStorage::class);

        // TAPI ketika ReportController butuh FileStorage, pakai CloudFileStorage
        $this->app->when(ReportController::class)
            ->needs(FileStorage::class)
            ->give(function () {
                return new CloudFileStorage(
                    config('filesystems.disks.s3')
                );
            });

        // Ketika GenerateBackupJob butuh FileStorage, pakai LocalFileStorage
        $this->app->when(GenerateBackupJob::class)
            ->needs(FileStorage::class)
            ->give(LocalFileStorage::class);
    }
}
```

```php
<?php

namespace App\Http\Controllers;

use App\Contracts\FileStorage;

class ReportController extends Controller
{
    // Di sini akan menerima CloudFileStorage, bukan LocalFileStorage
    public function __construct(
        protected FileStorage $storage
    ) {}

    public function export()
    {
        // Menyimpan laporan ke cloud
        $this->storage->put('reports/laporan.pdf', $content);
    }
}
```

## Kasus Penggunaan Nyata
Memberikan implementasi cache berbeda untuk berbagai service, storage driver berbeda per kelas, atau konfigurasi API client yang berbeda per konteks.
