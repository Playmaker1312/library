# 344. Singleton Binding singleton

## Definisi Singkat
Metode `singleton()` mendaftarkan binding ke Service Container di mana hanya satu instance yang dibuat dan digunakan kembali.

## Analogi
Seperti presiden negara — hanya ada satu orang yang menjabat, semua orang merujuk pada orang yang sama.

## Poin-Poin Penting
- Instance yang sama dikembalikan setiap kali di-resolve
- Cocok untuk service tanpa state atau shared resource
- Lebih hemat memori dibanding bind biasa
- Sering digunakan untuk service class, konfigurasi, atau koneksi

## Contoh Kode
```php
<?php

namespace App\Providers;

use Illuminate\Support\ServiceProvider;
use App\Services\ConfigurationManager;

class AppServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        // Singleton — hanya satu instance untuk seluruh aplikasi
        $this->app->singleton(ConfigurationManager::class, function ($app) {
            return new ConfigurationManager(
                config('app.env')
            );
        });
    }
}
```

```php
// Penggunaan — instance yang sama setiap kali
$config1 = app(ConfigurationManager::class);
$config2 = app(ConfigurationManager::class);

// $config1 === $config2 (instance SAMA)
```

```php
<?php

namespace App\Services;

class ConfigurationManager
{
    private array $settings = [];

    public function __construct(
        private string $environment
    ) {}

    public function set(string $key, mixed $value): void
    {
        $this->settings[$key] = $value;
    }

    public function get(string $key): mixed
    {
        return $this->settings[$key] ?? null;
    }
}
```

## Kasus Penggunaan Nyata
Logging service, mailer, event dispatcher, dan service apa pun yang state-nya perlu dibagi di seluruh aplikasi.
