# 352. Deferred Provider performa

## Definisi Singkat
Deferred Provider adalah Service Provider yang tidak langsung diload saat request, melainkan hanya ketika binding-nya benar-benar dibutuhkan.

## Analogi
Seperti AC di kamar hotel — tidak perlu dinyalakan di semua kamar, hanya di kamar yang ada tamunya. Ini menghemat listrik (performa).

## Poin-Poin Penting
- Mengurangi waktu loading aplikasi
- Provider hanya diload ketika binding-nya pertama kali diakses
- Implementasi properti `$defer = true` dan method `provides()`
- Cocok untuk provider yang jarang digunakan
- Tidak bisa menggunakan `boot()` untuk event/view composer

## Contoh Kode
```php
<?php

namespace App\Providers;

use Illuminate\Support\ServiceProvider;
use App\Services\ReportGenerator;
use App\Contracts\ReportContract;

class ReportServiceProvider extends ServiceProvider
{
    // Tandai sebagai deferred
    protected $defer = true;

    public function register(): void
    {
        $this->app->singleton(ReportGenerator::class, function ($app) {
            return new ReportGenerator(
                config('report.chunk_size'),
                config('report.temp_path')
            );
        });

        $this->app->bind(ReportContract::class, ReportGenerator::class);
    }

    // Wajib: daftarkan binding yang disediakan provider ini
    public function provides(): array
    {
        return [
            ReportGenerator::class,
            ReportContract::class,
        ];
    }
}
```

```php
<?php

namespace App\Providers;

use Illuminate\Support\ServiceProvider;
use App\Services\MailchimpService;

class MailchimpServiceProvider extends ServiceProvider
{
    protected $defer = true;

    public function register(): void
    {
        $this->app->singleton(MailchimpService::class, function ($app) {
            return new MailchimpService(
                config('services.mailchimp.api_key'),
                config('services.mailchimp.list_id')
            );
        });
    }

    public function provides(): array
    {
        return [MailchimpService::class];
    }
}
```

```php
// Di config/app.php tetap didaftarkan seperti biasa
'providers' => [
    // ...
    App\Providers\ReportServiceProvider::class,
    App\Providers\MailchimpServiceProvider::class,
],
```

## Kasus Penggunaan Nyata
Provider untuk integrasi third-party yang jarang dipakai (Mailchimp, Slack API, payment gateway tertentu), atau service berat yang hanya diperlukan di halaman tertentu.
