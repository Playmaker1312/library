# 343. Binding bind

## Definisi Singkat
Metode `bind()` digunakan untuk mendaftarkan binding ke Service Container, di mana setiap kali di-resolve akan dibuat instance baru.

## Analogi
Seperti mesin fotokopi — setiap kali Anda minta, Anda mendapat salinan baru, bukan lembar yang sama.

## Poin-Poin Penting
- `bind()` menghasilkan instance baru setiap kali di-resolve
- Cocok untuk kelas yang perlu state baru setiap penggunaan
- Bisa binding interface ke implementasi konkret
- Bisa binding string abstrak ke closure
- Didaftarkan di Service Provider

## Contoh Kode
```php
<?php

namespace App\Providers;

use Illuminate\Support\ServiceProvider;
use App\Contracts\PaymentProcessor;
use App\Services\MidtransPayment;

class AppServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        // Binding interface ke implementasi — setiap resolve dapat instance baru
        $this->app->bind(PaymentProcessor::class, function ($app) {
            return new MidtransPayment(
                config('services.midtrans.server_key')
            );
        });

        // Binding sederhana class ke class
        $this->app->bind(
            \App\Contracts\CacheService::class,
            \App\Services\RedisCacheService::class
        );
    }
}
```

```php
// Penggunaan — setiap kali dipanggil, instance baru dibuat
$processor1 = app(PaymentProcessor::class);
$processor2 = app(PaymentProcessor::class);

// $processor1 !== $processor2 (beda instance)
```

## Kasus Penggunaan Nyata
Digunakan ketika setiap resolusi membutuhkan instance baru, seperti koneksi database, HTTP client, atau service dengan state spesifik.
