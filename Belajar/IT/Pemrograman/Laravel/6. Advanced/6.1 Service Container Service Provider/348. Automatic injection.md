# 348. Automatic Injection

## Definisi Singkat
Automatic Injection adalah kemampuan Laravel untuk secara otomatis menyuntikkan dependency ke dalam method tertentu tanpa perlu binding eksplisit.

## Analogi
Seperti restoran fine dining — Anda (method) duduk, dan pelayan (container) langsung menyajikan hidangan (dependency) tanpa Anda pesan.

## Poin-Poin Penting
- Terjadi otomatis di Controller method, middleware, job, event listener
- Cukup type-hint parameter di method
- Container akan meresolve dan menyuntikkan dependency
- Juga bekerja di method `handle()`, `process()`, `execute()`
- Tidak memerlukan binding jika kelas bisa di-resolve otomatis

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use App\Services\InvoiceService;
use App\Repositories\UserRepository;

class InvoiceController extends Controller
{
    // Automatic injection di constructor
    public function __construct(
        protected InvoiceService $invoiceService
    ) {}

    // Automatic injection DI METHOD — type-hint langsung di parameter
    public function show(UserRepository $users, string $id)
    {
        $user = $users->find($id);

        return response()->json(
            $this->invoiceService->getUserInvoices($user)
        );
    }
}
```

```php
<?php

namespace App\Jobs;

use Illuminate\Contracts\Queue\ShouldQueue;
use App\Services\MailService;

class SendWelcomeEmail implements ShouldQueue
{
    // Automatic injection di job handle
    public function handle(MailService $mail): void
    {
        $mail->sendWelcome($this->user);
    }
}
```

```php
<?php

namespace App\Http\Middleware;

use App\Services\AuditLogger;

class LogRequests
{
    // Automatic injection di middleware
    public function handle(Request $request, \Closure $next, AuditLogger $logger)
    {
        $logger->log($request->path());

        return $next($request);
    }
}
```

## Kasus Penggunaan Nyata
Route model binding otomatis, dependency injection di method controller, middleware handle, job handle, dan event listener.
