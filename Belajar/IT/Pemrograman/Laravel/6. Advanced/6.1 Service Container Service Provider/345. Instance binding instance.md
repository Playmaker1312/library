# 345. Instance Binding instance

## Definisi Singkat
Metode `instance()` mendaftarkan objek yang sudah ada ke Service Container, sehingga objek tersebut digunakan kembali.

## Analogi
Seperti memberikan buku catatan pribadi Anda ke perpustakaan — pengunjung membaca buku yang sama, bukan salinan baru.

## Poin-Poin Penting
- Menerima objek yang sudah diinstansiasi
- Mirip singleton, tapi Anda membuat objeknya sendiri
- Berguna untuk binding objek yang sudah dikonfigurasi
- Objek yang sama akan dikembalikan setiap kali di-resolve

## Contoh Kode
```php
<?php

namespace App\Providers;

use Illuminate\Support\ServiceProvider;
use App\Services\ApiClient;

class AppServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        // Membuat instance dengan konfigurasi khusus
        $apiClient = new ApiClient(
            baseUrl: 'https://api.example.com',
            timeout: 30,
            retries: 3
        );

        // Mendaftarkan instance yang sudah jadi
        $this->app->instance(ApiClient::class, $apiClient);
    }
}
```

```php
// Penggunaan — objek yang persis sama
$client1 = app(ApiClient::class);
$client2 = app(ApiClient::class);

// $client1 === $client2 (objek yang sama)
```

```php
<?php

namespace App\Services;

class ApiClient
{
    private array $headers = [];

    public function __construct(
        private string $baseUrl,
        private int $timeout,
        private int $retries
    ) {}

    public function addHeader(string $key, string $value): void
    {
        $this->headers[$key] = $value;
    }

    public function getBaseUrl(): string
    {
        return $this->baseUrl;
    }
}
```

## Kasus Penggunaan Nyata
Mendaftarkan objek yang sudah dikonfigurasi seperti HTTP client dengan header default, koneksi third-party, atau objek dengan state awal tertentu.
