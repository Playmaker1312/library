# 353. Facade Kustom

## Definisi Singkat
Facade kustom adalah class Facade buatan sendiri yang menyediakan akses static ke service di Service Container.

## Analogi
Seperti remote TV — Anda cukup tekan tombol (method static) tanpa perlu tahu cara remote berkomunikasi dengan TV (proses container).

## Poin-Poin Penting
- Extend class `Illuminate\Support\Facades\Facade`
- Implementasi method `getFacadeAccessor()` mengembalikan binding key
- Daftarkan facade di `config/app.php` aliases
- Method static diteruskan ke objek dari container
- Tidak perlu `new` atau dependency injection manual

## Contoh Kode
```php
<?php

namespace App\Facades;

use Illuminate\Support\Facades\Facade;

class Payment extends Facade
{
    // Kunci binding di container — bisa class name atau string
    protected static function getFacadeAccessor(): string
    {
        return 'payment.processor';
    }
}
```

```php
<?php

namespace App\Services;

class PaymentProcessor
{
    public function __construct(
        private string $apiKey
    ) {}

    public function charge(int $amount): array
    {
        // logika pembayaran...

        return [
            'status' => 'success',
            'amount' => $amount,
            'transaction_id' => 'TRX-' . uniqid()
        ];
    }

    public function refund(string $transactionId): bool
    {
        return true;
    }
}
```

```php
<?php

namespace App\Providers;

use Illuminate\Support\ServiceProvider;
use App\Services\PaymentProcessor;

class PaymentServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        // Key harus sama dengan getFacadeAccessor()
        $this->app->singleton('payment.processor', function ($app) {
            return new PaymentProcessor(
                config('services.payment.api_key')
            );
        });
    }
}
```

```php
// config/app.php — daftarkan di aliases
'aliases' => [
    // ...
    'Payment' => App\Facades\Payment::class,
],
```

```php
// Penggunaan di controller — seperti static method
<?php

namespace App\Http\Controllers;

use App\Facades\Payment;

class CheckoutController extends Controller
{
    public function store()
    {
        $result = Payment::charge(50000);

        if ($result['status'] === 'success') {
            return redirect()->route('orders.show', $result['transaction_id']);
        }

        return back()->with('error', 'Pembayaran gagal');
    }
}
```

## Kasus Penggunaan Nyata
Membuat facade untuk service internal (payment, report, analytics) atau membungkus package third-party agar mudah digunakan.
