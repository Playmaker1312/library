# 347. Metode make resolve dependency

## Definisi Singkat
Metode `make()` pada Service Container digunakan untuk me-resolve (mengambil) dependency secara manual dari container.

## Analogi
Seperti memanggil bell boy di hotel — Anda minta (make) dan mereka mengantarkan apa yang Anda butuhkan.

## Poin-Poin Penting
- `app()->make(ClassName::class)` atau `resolve(ClassName::class)`
- Container otomatis menyelesaikan semua dependency
- Bisa menerima parameter tambahan melalui array
- Alternatif: helper `app(ClassName::class)`
- Tidak perlu manual `new ClassName(...)` dengan semua dependency-nya

## Contoh Kode
```php
<?php

namespace App\Console\Commands;

use Illuminate\Console\Command;
use App\Services\ReportGenerator;
use App\Services\PdfExporter;

class GenerateReportCommand extends Command
{
    protected $signature = 'report:generate {type}';
    protected $description = 'Generate laporan';

    public function handle()
    {
        // Cara 1: Helper app()
        $generator = app(ReportGenerator::class);

        // Cara 2: Method make()
        $exporter = $this->app->make(PdfExporter::class);

        // Dengan parameter tambahan
        $report = $this->app->makeWith(ReportGenerator::class, [
            'type' => $this->argument('type')
        ]);

        $this->info('Laporan berhasil dibuat!');
    }
}
```

```php
<?php

namespace App\Http\Controllers;

use App\Services\PaymentProcessor;

class PaymentController extends Controller
{
    public function process()
    {
        // Resolve manual dari container
        $processor = resolve(PaymentProcessor::class);

        return $processor->charge(request('amount'));
    }
}
```

```php
// Di tinker atau testing
// >>> $service = app(\App\Services\PaymentGateway::class);
// >>> $service->process(10000);
```

## Kasus Penggunaan Nyata
Digunakan di Artisan command, Job, Event Listener, atau situasi di mana DI otomatis tidak tersedia (misalnya di middleware atau helper).
