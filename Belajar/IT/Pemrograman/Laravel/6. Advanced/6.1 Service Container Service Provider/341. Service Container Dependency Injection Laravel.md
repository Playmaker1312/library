# 341. Service Container Dependency Injection Laravel

## Definisi Singkat
Service Container adalah wadah yang mengelola dependency dan melakukan Dependency Injection (DI) secara otomatis di Laravel.

## Analogi
Seperti hotel yang menyediakan layanan kamar — Anda tinggal minta, mereka antar tanpa perlu repot menyiapkan sendiri.

## Poin-Poin Penting
- Service container adalah alat utama untuk resolusi dependency
- Dependency Injection adalah teknik memberikan dependency dari luar, bukan membuat sendiri
- Laravel menggunakan container untuk mengelola kelas-kelas inti
- Bisa binding class, interface, atau closure
- Mendukung autowiring (resolusi otomatis)

## Contoh Kode
```php
<?php

namespace App\Services;

class PaymentGateway
{
    public function process(int $amount): string
    {
        return "Memproses pembayaran sebesar Rp" . number_format($amount);
    }
}
```

```php
<?php

namespace App\Http\Controllers;

use App\Services\PaymentGateway;

class OrderController extends Controller
{
    // Dependency Injection via constructor — container menyelesaikan otomatis
    public function __construct(
        protected PaymentGateway $payment
    ) {}

    public function store()
    {
        return $this->payment->process(50000);
    }
}
```

## Kasus Penggunaan Nyata
Digunakan di seluruh Laravel: Controller, Middleware, Job, Event Listener, dan Command otomatis di-resolve oleh container.
