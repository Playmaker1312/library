# 349. Service Provider make provider Artisan

## Definisi Singkat
Artisan command `make:provider` digunakan untuk membuat Service Provider baru di Laravel.

## Analogi
Seperti membuat colokan listrik baru — Anda membuat provider (steker) agar perangkat (service) bisa terhubung ke sumber daya (container).

## Poin-Poin Penting
- Perintah: `php artisan make:provider NamaProvider`
- File dibuat di `app/Providers/`
- Provider harus didaftarkan di `config/app.php`
- Setiap provider memiliki method `register()` dan `boot()`
- Nama provider biasanya diakhiri dengan `ServiceProvider`

## Contoh Kode
```bash
# Membuat Service Provider baru
php artisan make:provider PaymentServiceProvider

# Membuat dengan path yang sudah ditentukan
php artisan make:provider Services/AnalyticsServiceProvider
```

```php
<?php

namespace App\Providers;

use Illuminate\Support\ServiceProvider;
use App\Contracts\PaymentProcessor;
use App\Services\MidtransPayment;
use App\Services\XenditPayment;

class PaymentServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        // Binding berdasarkan konfigurasi
        $this->app->singleton(PaymentProcessor::class, function ($app) {
            $driver = config('payment.driver');

            return match ($driver) {
                'midtrans' => new MidtransPayment(
                    config('payment.midtrans.server_key')
                ),
                'xendit' => new XenditPayment(
                    config('payment.xendit.api_key')
                ),
                default => throw new \RuntimeException("Driver tidak dikenal")
            };
        });
    }

    public function boot(): void
    {
        // Logika setelah semua provider terdaftar
    }
}
```

```php
// Daftarkan di config/app.php
'providers' => [
    // ...
    App\Providers\PaymentServiceProvider::class,
],
```

## Kasus Penggunaan Nyata
Mengelompokkan binding service yang terkait, integrasi third-party, atau package kustom yang membutuhkan registrasi ke container.
