# 350. Daftar provider config app php bootstrap app php

## Definisi Singkat
Service Provider didaftarkan di `config/app.php` dan proses bootstrapping dimulai dari `bootstrap/app.php`.

## Analogi
Seperti daftar tamu undangan pernikahan — config/app.php adalah daftar hadir, bootstrap/app.php adalah pintu masuk tempat semua tamu dipersilakan masuk.

## Poin-Poin Penting
- `config/app.php` array `providers` berisi semua provider
- `bootstrap/app.php` membuat instance aplikasi dan mendaftarkan provider inti
- Urutan provider di config penting — provider bisa bergantung satu sama lain
- Provider inti Laravel didaftarkan lebih dulu
- Provider kustom ditambahkan di bagian bawah array

## Contoh Kode
```php
<?php
// config/app.php — daftar Service Provider

return [
    // ...

    'providers' => [
        // Provider inti Laravel (framework)
        Illuminate\Auth\AuthServiceProvider::class,
        Illuminate\Broadcasting\BroadcastServiceProvider::class,
        Illuminate\Bus\BusServiceProvider::class,
        Illuminate\Cache\CacheServiceProvider::class,
        Illuminate\Foundation\Providers\ConsoleSupportServiceProvider::class,
        Illuminate\Cookie\CookieServiceProvider::class,
        Illuminate\Database\DatabaseServiceProvider::class,
        Illuminate\Encryption\EncryptionServiceProvider::class,
        Illuminate\Filesystem\FilesystemServiceProvider::class,
        Illuminate\Foundation\Providers\FoundationServiceProvider::class,
        Illuminate\Hashing\HashServiceProvider::class,
        Illuminate\Mail\MailServiceProvider::class,
        Illuminate\Notifications\NotificationServiceProvider::class,
        Illuminate\Pagination\PaginationServiceProvider::class,
        Illuminate\Pipeline\PipelineServiceProvider::class,
        Illuminate\Queue\QueueServiceProvider::class,
        Illuminate\Redis\RedisServiceProvider::class,
        Illuminate\Auth\Passwords\PasswordResetServiceProvider::class,
        Illuminate\Session\SessionServiceProvider::class,
        Illuminate\Translation\TranslationServiceProvider::class,
        Illuminate\Validation\ValidationServiceProvider::class,
        Illuminate\View\ViewServiceProvider::class,

        // Provider Package / Third-party
        Barryvdh\Debugbar\ServiceProvider::class,

        // Provider Aplikasi (milik Anda)
        App\Providers\AppServiceProvider::class,
        App\Providers\AuthServiceProvider::class,
        App\Providers\EventServiceProvider::class,
        App\Providers\RouteServiceProvider::class,
        App\Providers\PaymentServiceProvider::class,
    ],
];
```

```php
<?php
// bootstrap/app.php — entry point aplikasi

$app = new Illuminate\Foundation\Application(
    $_ENV['APP_BASE_PATH'] ?? dirname(__DIR__)
);

$app->singleton(
    Illuminate\Contracts\Http\Kernel::class,
    App\Http\Kernel::class
);

$app->singleton(
    Illuminate\Contracts\Console\Kernel::class,
    App\Console\Kernel::class
);

$app->singleton(
    Illuminate\Contracts\Debug\ExceptionHandler::class,
    App\Exceptions\Handler::class
);

return $app;
```

## Kasus Penggunaan Nyata
Menambahkan provider package (Spatie, Barryvdh, dll), mengatur urutan loading provider, dan bootstrap aplikasi Laravel.
