# 359. Cache get ambil

## Definisi Singkat
Method `Cache::get()` digunakan untuk mengambil data dari cache berdasarkan key.

## Analogi
Seperti membuka laci arsip — Anda cari map dengan label tertentu (key), jika ada Anda dapat isinya, jika kosong Anda dapat null.

## Poin-Poin Penting
- `Cache::get(key)` — return null jika key tidak ada
- `Cache::get(key, default)` — return default jika key tidak ada
- Default bisa nilai biasa atau closure
- `Cache::has(key)` — cek apakah key ada
- `Cache::pull(key)` — ambil lalu hapus

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Cache;

class ProductController extends Controller
{
    public function show(string $id)
    {
        // Ambil dari cache — null jika tidak ada
        $product = Cache::get("product.{$id}");

        if (!$product) {
            $product = \App\Models\Product::findOrFail($id);

            Cache::put("product.{$id}", $product, 3600);
        }

        return view('products.show', compact('product'));
    }

    public function stats()
    {
        // Dengan default value
        $visitors = Cache::get('visitor_count', 0);

        // Default via closure — hanya dijalankan jika key tidak ada
        $config = Cache::get('dynamic_config', function () {
            return \App\Models\Setting::pluck('value', 'key');
        });

        // Cek apakah key ada
        if (Cache::has('maintenance_mode')) {
            abort(503);
        }

        return response()->json([
            'visitors' => $visitors,
            'config' => $config
        ]);
    }

    public function pop()
    {
        // Ambil lalu hapus dari cache
        $notification = Cache::pull('user.notification');

        return $notification ?? 'Tidak ada notifikasi';
    }
}
```

```php
<?php
// Cache::get berbagai bentuk

$value = Cache::get('key');                      // null jika tidak ada
$value = Cache::get('key', 'default');           // string default
$value = Cache::get('key', fn() => 'default');   // closure default
$value = Cache::get('key', 0);                   // numeric default
$value = Cache::get('key', []);                  // array default

if (Cache::has('key')) {
    // Key pasti ada
}
```

## Kasus Penggunaan Nyata
Mengambil data yang sudah di-cache di controller, mengecek status cache, mengambil token sementara, dan mendapatkan konfigurasi dinamis.
