# 361. Cache rememberForever

## Definisi Singkat
Method `Cache::rememberForever()` menyimpan data ke cache tanpa batas waktu (permanen) sampai dihapus manual.

## Analogi
Seperti monumen — dibangun sekali dan akan ada selamanya, kecuali dihancurkan sengaja.

## Poin-Poin Penting
- Data tidak memiliki TTL — tidak akan kedaluwarsa otomatis
- Hanya bisa dihapus dengan `Cache::forget()` atau `Cache::flush()`
- Cocok untuk data statis yang jarang berubah
- Hati-hati dengan memori — pastikan data tidak membengkak
- Alternatif: `Cache::remember(key, 999999999, closure)` untuk TTL sangat panjang

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use App\Models\Category;
use Illuminate\Support\Facades\Cache;

class CategoryController extends Controller
{
    public function index()
    {
        // Data kategori jarang berubah — cache permanen
        $categories = Cache::rememberForever('categories.all', function () {
            return Category::withCount('products')->get();
        });

        return view('categories.index', compact('categories'));
    }

    // Hapus cache saat kategori berubah
    public function store(Request $request)
    {
        Category::create($request->all());

        Cache::forget('categories.all');

        return redirect()->route('categories.index');
    }
}
```

```php
<?php

namespace App\Providers;

use Illuminate\Support\Facades\Cache;
use App\Models\Setting;

class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        // Cache konfigurasi global — permanen, refresh manual
        Cache::rememberForever('app_settings', function () {
            return Setting::pluck('value', 'key');
        });
    }
}
```

```php
<?php

namespace App\Services;

use Illuminate\Support\Facades\Cache;

class SettingsService
{
    public function get(string $key, mixed $default = null): mixed
    {
        $settings = Cache::rememberForever('app_settings', function () {
            return \App\Models\Setting::pluck('value', 'key');
        });

        return $settings[$key] ?? $default;
    }

    public function set(string $key, mixed $value): void
    {
        \App\Models\Setting::updateOrCreate(
            ['key' => $key],
            ['value' => $value]
        );

        // Refresh cache setelah update
        Cache::forget('app_settings');
    }
}
```

## Kasus Penggunaan Nyata
Data referensi statis (provinsi, kategori, konfigurasi), mapping data yang jarang berubah, dan lookup table yang di-cache permanen.
