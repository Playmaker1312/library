# 358. Cache put simpan

## Definisi Singkat
Method `Cache::put()` digunakan untuk menyimpan data ke cache dengan TTL (waktu kedaluwarsa).

## Analogi
Seperti memasukkan makanan ke kulkas dengan catatan kadaluarsa — Anda tahu kapan harus dibuang.

## Poin-Poin Penting
- `Cache::put(key, value, seconds)` — simpan dengan durasi
- `Cache::put(key, value, now()->addMinutes(10))` — pakai DateTime
- Tanpa TTL: data disimpan permanen (atau sampai dihapus)
- Key harus string unik
- Value bisa string, array, object (akan di-serialize)

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Cache;

class CacheController extends Controller
{
    public function store()
    {
        // Simpan dengan durasi detik (3600 detik = 1 jam)
        Cache::put('settings', ['theme' => 'dark', 'lang' => 'id'], 3600);

        // Simpan dengan DateTime
        Cache::put('promo_banner', $banner, now()->addDays(7));

        // Simpan tanpa TTL (permanen)
        Cache::put('app_version', '2.1.0');

        // Simpan jika key belum ada
        $saved = Cache::add('first_visit', true, 3600);
        // false jika key sudah ada

        // Simpan banyak data
        Cache::put('user_123.profile', [
            'name' => 'Budi',
            'email' => 'budi@example.com',
            'last_login' => now()
        ], 1800);

        return response()->json(['status' => 'cache tersimpan']);
    }

    // Simpan dari repository/service
    public function cacheProducts()
    {
        $products = \App\Models\Product::all();

        Cache::put('catalog.products', $products, 86400); // 24 jam

        return Cache::get('catalog.products');
    }
}
```

```php
<?php
// TTL helper

// Cache::put(key, value, seconds)
Cache::put('key', 'value', 60);         // 1 menit
Cache::put('key', 'value', 3600);       // 1 jam
Cache::put('key', 'value', 86400);      // 1 hari
Cache::put('key', 'value', 604800);     // 1 minggu

// Atau pakai Carbon
Cache::put('key', 'value', now()->addHours(2));
Cache::put('key', 'value', now()->endOfDay());
```

## Kasus Penggunaan Nyata
Menyimpan hasil query, konfigurasi dinamis, session sementara, API response, dan data yang perlu di-refresh berkala.
