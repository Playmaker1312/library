# 365. Response caching

## Definisi Singkat
Response caching menyimpan seluruh response HTTP (HTML/JSON) sehingga request berikutnya tidak perlu memproses ulang.

## Analogi
Seperti foto makanan di menu restoran — begitu difoto (di-cache), pelanggan berikutnya tinggal lihat foto, tidak perlu masak ulang.

## Poin-Poin Penting
- Cache entire response — controller, query, view semua di-skip
- Cocok untuk halaman publik yang jarang berubah
- Middleware `CacheResponse` bisa digunakan
- Perhatikan cache untuk halaman yang membutuhkan autentikasi
- Set `Cache-Control` header untuk HTTP caching

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use App\Models\Article;
use Illuminate\Support\Facades\Cache;

class PageController extends Controller
{
    // Cache entire response HTML
    public function home()
    {
        $html = Cache::remember('page.home', 3600, function () {
            $articles = Article::with('author')
                ->where('status', 'published')
                ->take(10)
                ->get();

            return view('pages.home', compact('articles'))->render();
        });

        return response($html);
    }
}
```

```php
<?php
// Dengan middleware kustom
namespace App\Http\Middleware;

use Closure;
use Illuminate\Support\Facades\Cache;

class CachePublicResponse
{
    public function handle($request, Closure $next, int $ttl = 3600)
    {
        $url = $request->fullUrl();
        $key = 'response.' . md5($url);

        if (Cache::has($key)) {
            return response(Cache::get($key));
        }

        $response = $next($request);

        if ($response->isSuccessful()) {
            Cache::put($key, $response->getContent(), $ttl);
        }

        return $response;
    }
}
```

```php
<?php
// routes/web.php
use App\Http\Middleware\CachePublicResponse;

Route::middleware([CachePublicResponse::class . ':300'])->group(function () {
    Route::get('/', [App\Http\Controllers\PageController::class, 'home']);
    Route::get('/about', [App\Http\Controllers\PageController::class, 'about']);
    Route::get('/contact', [App\Http\Controllers\PageController::class, 'contact']);
});
```

```php
<?php
// Cache API JSON response
class ApiController extends Controller
{
    public function publicData()
    {
        return Cache::remember('api.public.data', 600, function () {
            return response()->json([
                'status' => 'success',
                'data' => [
                    'products' => Product::count(),
                    'categories' => Category::count(),
                ]
            ]);
        });
    }
}
```

```php
<?php
// Cache-Control header di response
$response = response($content)
    ->header('Cache-Control', 'public, max-age=3600')
    ->header('ETag', md5($content));
```

## Kasus Penggunaan Nyata
Halaman beranda, halaman statis (about, contact, FAQ), API publik, sitemap, RSS feed, dan halaman landing marketing.
