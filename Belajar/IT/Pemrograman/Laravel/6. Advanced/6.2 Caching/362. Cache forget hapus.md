# 362. Cache forget hapus

## Definisi Singkat
Method `Cache::forget()` digunakan untuk menghapus satu item dari cache berdasarkan key.

## Analogi
Seperti menghapus file dari folder — Anda tahu nama filenya (key), Anda hapus, file itu hilang.

## Poin-Poin Penting
- `Cache::forget(key)` — return boolean (true jika berhasil)
- `Cache::pull(key)` — ambil lalu hapus (return value yang dihapus)
- Hanya menghapus satu key, bukan semua cache
- Berguna untuk invalidasi cache selektif
- Sering dipanggil setelah data diupdate

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use App\Models\Article;
use Illuminate\Support\Facades\Cache;

class ArticleController extends Controller
{
    public function update(Request $request, string $id)
    {
        $article = Article::findOrFail($id);
        $article->update($request->all());

        // Hapus cache artikel ini
        Cache::forget("article.{$article->slug}");

        // Hapus cache daftar artikel
        Cache::forget('articles.published');

        // Hapus cache dengan pull (ambil dulu baru hapus)
        $oldData = Cache::pull("article.{$id}.backup");

        return redirect()->route('articles.show', $article->slug);
    }

    public function destroy(string $id)
    {
        $article = Article::findOrFail($id);
        $article->delete();

        // Hapus semua cache terkait artikel
        Cache::forget("article.{$article->slug}");
        Cache::forget('articles.published');
        Cache::forget('articles.popular');
        Cache::forget('articles.categories');

        return redirect()->route('articles.index');
    }
}
```

```php
<?php

namespace App\Services;

use Illuminate\Support\Facades\Cache;

class ProductCacheService
{
    private const TAGS = ['products', 'catalog'];

    public function clearProduct(int $productId): void
    {
        Cache::forget("product.{$productId}");
        Cache::forget("product.reviews.{$productId}");
    }

    public function clearCatalog(): void
    {
        Cache::forget('products.all');
        Cache::forget('products.featured');
        Cache::forget('products.discounted');
    }

    public function clearAll(): void
    {
        foreach (self::TAGS as $tag) {
            Cache::forget("catalog.{$tag}");
        }
    }
}
```

```php
<?php
// Observer — auto-clear cache saat model berubah

namespace App\Observers;

use App\Models\Article;
use Illuminate\Support\Facades\Cache;

class ArticleObserver
{
    public function saved(Article $article): void
    {
        Cache::forget("article.{$article->slug}");
        Cache::forget('articles.published');
    }

    public function deleted(Article $article): void
    {
        Cache::forget("article.{$article->slug}");
        Cache::forget('articles.published');
    }
}
```

## Kasus Penggunaan Nyata
Invalidasi cache ketika data di-create/update/delete, menghapus cache user setelah logout, dan membersihkan cache specifik tanpa mempengaruhi data lain.
