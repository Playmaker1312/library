# 367. Query caching Eloquent

## Definisi Singkat
Query caching menyimpan hasil query Eloquent/DB ke cache sehingga query yang sama tidak perlu dijalankan ulang.

## Analogi
Seperti profesor yang punya jawaban ujian tahun lalu — jika ada soal yang sama, tinggal lihat arsip, tidak perlu menghitung ulang.

## Poin-Poin Penting
- Cache hasil query — bukan query builder-nya
- Bisa menggunakan `Cache::remember()` dengan query di dalamnya
- Atau menggunakan `remember()` method pada query builder (Laravel 11+)
- Cache invalidate manual saat data berubah
- Cache key harus unik per query

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use App\Models\User;
use App\Models\Order;
use Illuminate\Support\Facades\Cache;

class StatsController extends Controller
{
    // Query caching manual dengan Cache::remember
    public function dashboard()
    {
        $totalUsers = Cache::remember('stats.users', 3600, function () {
            return User::count();
        });

        $totalRevenue = Cache::remember('stats.revenue', 3600, function () {
            return Order::where('status', 'completed')->sum('total');
        });

        // Cache query dengan relasi
        $recentOrders = Cache::remember('stats.recent_orders', 300, function () {
            return Order::with('user')
                ->where('status', 'completed')
                ->latest()
                ->take(10)
                ->get();
        });

        return view('dashboard', compact('totalUsers', 'totalRevenue', 'recentOrders'));
    }
}
```

```php
<?php
// Query Builder remember (Laravel 11+)
use Illuminate\Support\Facades\DB;

$users = DB::table('users')
    ->where('active', true)
    ->remember(3600)  // Cache hasil query selama 1 jam
    ->get();

// Dengan cache key kustom
$users = DB::table('users')
    ->remember(3600, 'active_users_cache')
    ->get();
```

```php
<?php

namespace App\Repositories;

use App\Models\Product;
use Illuminate\Support\Facades\Cache;

class ProductRepository
{
    public function getFeatured(): mixed
    {
        return Cache::remember('products.featured', 86400, function () {
            return Product::with(['category', 'images'])
                ->where('is_featured', true)
                ->where('is_active', true)
                ->orderBy('position')
                ->get();
        });
    }

    public function getByCategory(string $slug): mixed
    {
        return Cache::remember("products.category.{$slug}", 3600, function () use ($slug) {
            return Product::whereHas('category', fn($q) => $q->where('slug', $slug))
                ->where('is_active', true)
                ->latest()
                ->paginate(12);
        });
    }

    public function search(string $query): mixed
    {
        // Cache hasil search — key unik per query
        $key = 'products.search.' . md5($query);

        return Cache::remember($key, 600, function () use ($query) {
            return Product::where('name', 'like', "%{$query}%")
                ->where('is_active', true)
                ->get();
        });
    }
}
```

```php
<?php
// Observer — auto flush cache query
namespace App\Observers;

use App\Models\Product;
use Illuminate\Support\Facades\Cache;

class ProductObserver
{
    public function saved(Product $product): void
    {
        Cache::forget('products.featured');
        Cache::forget("products.category.{$product->category->slug}");
    }

    public function deleted(Product $product): void
    {
        Cache::forget('products.featured');
        Cache::forget("products.category.{$product->category->slug}");
    }
}
```
