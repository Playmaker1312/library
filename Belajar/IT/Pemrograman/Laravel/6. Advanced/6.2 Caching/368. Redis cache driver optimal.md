# 368. Redis cache driver optimal

## Definisi Singkat
Redis adalah cache driver in-memory yang sangat cepat, mendukung struktur data kompleks, dan optimal untuk aplikasi skala besar.

## Analogi
Seperti lemari penyimpanan di sebelah meja kerja — lebih cepat daripada jalan ke gudang (database) karena semua ada di memori (RAM).

## Poin-Poin Penting
- Redis menyimpan data di RAM — akses microsecond
- Mendukung tipe data: string, hash, list, set, sorted set
- Mendukung cache tags
- Bisa digunakan untuk session, cache, queue, broadcast
- Konfigurasi koneksi di `config/database.php`

## Contoh Kode
```php
<?php
// config/database.php — konfigurasi Redis

'redis' => [
    'client' => env('REDIS_CLIENT', 'phpredis'),

    'options' => [
        'cluster' => env('REDIS_CLUSTER', 'redis'),
        'prefix' => env('REDIS_PREFIX', 'laravel_'),
    ],

    'default' => [
        'url' => env('REDIS_URL'),
        'host' => env('REDIS_HOST', '127.0.0.1'),
        'username' => env('REDIS_USERNAME'),
        'password' => env('REDIS_PASSWORD'),
        'port' => env('REDIS_PORT', '6379'),
        'database' => env('REDIS_DB', '0'),
    ],

    'cache' => [
        'url' => env('REDIS_URL'),
        'host' => env('REDIS_HOST', '127.0.0.1'),
        'username' => env('REDIS_USERNAME'),
        'password' => env('REDIS_PASSWORD'),
        'port' => env('REDIS_PORT', '6379'),
        'database' => env('REDIS_CACHE_DB', '1'),
    ],
],
```

```php
<?php

namespace App\Services;

use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Redis;

class RedisAdvancedService
{
    // Gunakan Redis langsung untuk operasi lanjutan
    public function leaderboard()
    {
        // Sorted set — cocok untuk leaderboard
        Redis::zadd('leaderboard', 100, 'user_1');
        Redis::zadd('leaderboard', 200, 'user_2');
        Redis::zadd('leaderboard', 150, 'user_3');

        // Top 10
        return Redis::zrevrange('leaderboard', 0, 9, 'WITHSCORES');
    }

    // Counter dengan Redis
    public function pageViews(string $slug): int
    {
        return Redis::incr("views:{$slug}");
    }

    // Hash — menyimpan object
    public function cacheUser(int $id, array $data): void
    {
        Redis::hmset("user:{$id}", $data);
        Redis::expire("user:{$id}", 3600);
    }

    public function getUser(int $id): array
    {
        return Redis::hgetall("user:{$id}");
    }
}
```

Session management, real-time leaderboard, rate limiting, message queue, cache untuk aplikasi high-traffic, dan analytics counter.
