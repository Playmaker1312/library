# 369. Cache warming strategy

## Definisi Singkat
Cache warming adalah strategi mengisi cache sebelum data benar-benar dibutuhkan oleh user, sehingga user tidak mengalami cold start.

## Analogi
Seperti memanaskan mesin mobil sebelum jalan — daripada user menunggu mesin panas, Anda panas-kan dulu dari pagi.

## Poin-Poin Penting
- Cold start: cache kosong, request pertama lambat
- Cache warming: isi cache secara proaktif
- Bisa via Artisan command, job queue, atau event
- Dilakukan setelah deploy atau jadwal tertentu
- Strategi: warming on deploy, warming on schedule, warming on write

## Contoh Kode
```php
<?php

namespace App\Console\Commands;

use Illuminate\Console\Command;
use Illuminate\Support\Facades\Cache;
use App\Models\Product;
use App\Models\Category;

class WarmCacheCommand extends Command
{
    protected $signature = 'cache:warm';
    protected $description = 'Warm cache untuk data populer';

    public function handle()
    {
        $this->info('Memulai cache warming...');

        // 1. Featured products
        $this->warm('products.featured', function () {
            return Product::with('category')
                ->where('is_featured', true)
                ->get();
        }, 86400);

        // 2. All categories
        $this->warm('categories.all', function () {
            return Category::withCount('products')->get();
        }, 86400);

        // 3. Navigation menu
        $this->warm('navigation.menu', function () {
            return Cache::rememberForever('navigation.menu', function () {
                return Category::tree()->get();
            });
        });

        // 4. Popular searches
        foreach (['laptop', 'handphone', 'aksesoris'] as $term) {
            $this->warm("search.{$term}", function () use ($term) {
                return Product::where('name', 'like', "%{$term}%")->take(20)->get();
            }, 3600);
        }

        $this->info('Cache warming selesai!');
    }

    private function warm(string $key, \Closure $callback, int $ttl = null): void
    {
        if (!Cache::has($key)) {
            $data = $callback();

            if ($ttl) {
                Cache::put($key, $data, $ttl);
            } else {
                Cache::forever($key, $data);
            }

            $this->line("Cache '{$key}' berhasil di-warm");
        }
    }
}
```

```php
<?php
// Cache warming via Job
namespace App\Jobs;

use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Support\Facades\Cache;

class WarmProductCache implements ShouldQueue
{
    public function handle(): void
    {
        $products = \App\Models\Product::with('category')
            ->where('is_active', true)
            ->get();

        Cache::put('products.all', $products, 86400);

        // Cache per kategori
        foreach ($products->groupBy('category_id') as $categoryId => $items) {
            Cache::put("products.category.{$categoryId}", $items, 86400);
        }
    }
}
```

```php
<?php
// Schedule warming di Kernel
// app/Console/Kernel.php

protected function schedule(Schedule $schedule): void
{
    // Warm cache setiap jam 3 pagi
    $schedule->command('cache:warm')
        ->dailyAt('03:00')
        ->withoutOverlapping()
        ->sendOutputTo(storage_path('logs/cache-warm.log'));
}
```

## Kasus Penggunaan Nyata
Setelah deployment, sebelum flash sale, pagi hari sebelum traffic naik, atau setelah maintenance untuk memastikan performa optimal sejak awal.
