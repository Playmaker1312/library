# 364. Cache tags kelompok

## Definisi Singkat
Cache tags memungkinkan pengelompokan item cache sehingga bisa dioperasikan (dihapus) secara kelompok.

## Analogi
Seperti rak buku dengan label genre — Anda bisa mengambil semua buku genre "Fiksi" (tag) sekaligus tanpa menyentuh buku lain.

## Poin-Poin Penting
- `Cache::tags(['tag1', 'tag2'])->remember(key, ttl, closure)`
- Hanya didukung oleh: Redis, Memcached (tidak untuk file/database)
- Bisa hapus semua cache dengan tag tertentu via `flush()`
- Tags bersifat hierarkis — bisa multiple tags
- Throw exception jika driver tidak mendukung tags

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use App\Models\Product;
use Illuminate\Support\Facades\Cache;

class ProductController extends Controller
{
    public function index()
    {
        // Kelompokkan cache produk dengan tag 'products'
        $products = Cache::tags(['products', 'catalog'])
            ->remember('products.all', 3600, function () {
                return Product::with('category')->get();
            });

        return view('products.index', compact('products'));
    }

    public function show(string $slug)
    {
        $product = Cache::tags(['products'])
            ->remember("product.{$slug}", 3600, function () use ($slug) {
                return Product::where('slug', $slug)->firstOrFail();
            });

        return view('products.show', compact('product'));
    }

    public function category(string $categorySlug)
    {
        $products = Cache::tags(['products', "category.{$categorySlug}"])
            ->remember("category.{$categorySlug}.products", 3600, function () use ($categorySlug) {
                return Product::whereHas('category', fn($q) => $q->where('slug', $categorySlug))->get();
            });

        return view('products.category', compact('products'));
    }
}
```

```php
<?php

namespace App\Services;

use Illuminate\Support\Facades\Cache;

class CacheManager
{
    // Hapus semua cache produk — tanpa menyentuh cache lain
    public function flushProducts(): void
    {
        Cache::tags(['products'])->flush();
    }

    // Hapus cache per kategori
    public function flushCategory(string $slug): void
    {
        Cache::tags(["category.{$slug}"])->flush();

        // Juga hapus products tag agar daftar produk juga di-refresh
        Cache::tags(['products'])->flush();
    }

    // Multiple tags
    public function flushCatalog(): void
    {
        Cache::tags(['products', 'catalog', 'categories'])->flush();
    }
}
```

```php
<?php
// Observer dengan tags
namespace App\Observers;

use App\Models\Product;
use Illuminate\Support\Facades\Cache;

class ProductObserver
{
    public function saved(Product $product): void
    {
        Cache::tags(['products'])->flush();
        // Semua cache dengan tag 'products' sekali hapus
    }
}
```

## Kasus Penggunaan Nyata
Grouping cache per modul (products, users, orders), invalidasi massal saat data berubah, dan manajemen cache terstruktur di aplikasi besar.
