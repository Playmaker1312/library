# 366. Atomic lock Cache lock

## Definisi Singkat
Atomic Lock menggunakan cache driver untuk mengimplementasikan locking (penguncian) antar proses/request untuk mencegah race condition.

## Analogi
Seperti toilet umum dengan kunci — orang pertama masuk dan mengunci, orang lain harus menunggu sampai pintu terbuka.

## Poin-Poin Penting
- `Cache::lock('key', seconds)` — buat lock dengan durasi
- `$lock->get()` — coba dapatkan lock (return boolean)
- `$lock->block(5)` — tunggu sampai lock tersedia (maks 5 detik)
- Cocok untuk cron job, queue, atau proses concurrent
- Lock otomatis terlepas setelah durasi habis

## Contoh Kode
```php
<?php

namespace App\Console\Commands;

use Illuminate\Console\Command;
use Illuminate\Support\Facades\Cache;

class GenerateReportCommand extends Command
{
    protected $signature = 'report:generate';
    protected $description = 'Generate laporan (dicegah double-run)';

    public function handle()
    {
        // Coba dapatkan lock — jika gagal, proses sudah berjalan
        $lock = Cache::lock('report.generation', 120);

        if (!$lock->get()) {
            $this->warn('Report sedang di-generate oleh proses lain');
            return Command::FAILURE;
        }

        // Proses generate report...
        $this->info('Mengenerate report...');
        sleep(60);

        // Lepas lock setelah selesai
        $lock->release();

        $this->info('Report selesai!');
    }
}
```

```php
<?php

namespace App\Jobs;

use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Support\Facades\Cache;

class ProcessPayment implements ShouldQueue
{
    public function handle(): void
    {
        $lock = Cache::lock('payment.processing', 30);

        // Block — tunggu sampai lock tersedia, maks 10 detik
        $lock->block(10, function () {
            // Proses pembayaran — dijamin tidak concurrent
            $this->processSafe();
        });
    }

    private function processSafe(): void
    {
        // Logika pembayaran yang aman
    }
}
```

```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Cache;

class VoteController extends Controller
{
    public function vote(string $candidateId)
    {
        $lock = Cache::lock('vote.process', 10);

        try {
            $lock->block(5);

            // Proses voting — aman dari double submit
            $count = Cache::get("votes.{$candidateId}", 0);
            Cache::put("votes.{$candidateId}", $count + 1, 86400);

        } finally {
            // Pastikan lock dilepas walau error
            $lock->release();
        }

        return back()->with('success', 'Vote berhasil!');
    }
}
```

```php
<?php
// Fitur lock lainnya

// Lock dengan owner (untuk release spesifik)
$lock = Cache::lock('key', 60);
$lock->get(function () {
    // Otomatis release setelah closure selesai
});

// Cek apakah lock masih ada
if (Cache::lock('key', 60)->get()) {
    // Dapat lock
}

// Force release — hapus lock paksa
Cache::lock('key')->forceRelease();
```

## Kasus Penggunaan Nyata
Mencegah job queue ganda, cron job overlap, double submit form, proses import/export data, dan pembayaran concurrent.
