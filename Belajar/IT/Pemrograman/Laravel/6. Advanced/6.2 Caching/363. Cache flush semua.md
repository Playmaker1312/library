# 363. Cache flush semua

## Definisi Singkat
Method `Cache::flush()` digunakan untuk menghapus seluruh data di cache store.

## Analogi
Seperti memformat ulang hard drive — semua data hilang, mulai dari awal lagi.

## Poin-Poin Penting
- `Cache::flush()` — hapus semua cache di store default
- `Cache::driver('redis')->flush()` — hapus dari driver tertentu
- Tidak bisa di-recover — gunakan hati-hati di produksi
- Operasi mahal jika cache sangat besar
- Alternatif: flush per tag (jika driver mendukung)

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Artisan;

class CacheController extends Controller
{
    // Hapus semua cache via web (hanya admin)
    public function flush()
    {
        $this->authorize('admin');

        Cache::flush();

        return redirect()->back()->with('success', 'Semua cache berhasil dihapus');
    }
}
```

```php
<?php

namespace App\Console\Commands;

use Illuminate\Console\Command;
use Illuminate\Support\Facades\Cache;

class FlushAllCache extends Command
{
    protected $signature = 'cache:flush-all {--driver= : Cache driver}';
    protected $description = 'Hapus semua data cache';

    public function handle()
    {
        $driver = $this->option('driver');

        if ($driver) {
            Cache::driver($driver)->flush();
            $this->info("Cache driver '{$driver}' berhasil di-flush");
        } else {
            Cache::flush();
            $this->info('Semua cache berhasil di-flush');
        }
    }
}
```

```php
<?php
// Perbandingan metode hapus cache

// Hapus satu key
Cache::forget('key');

// Hapus beberapa key tertentu
foreach (['key1', 'key2', 'key3'] as $key) {
    Cache::forget($key);
}

// Hapus SEMUA cache — sekali jalan
Cache::flush();

// Hapus per driver
Cache::driver('file')->flush();
Cache::driver('redis')->flush();

// Artisan command bawaan
// php artisan cache:clear  — hapus cache (hanya file driver)
// php artisan optimize:clear — hapus semua cache (termasuk blade, route, config)
```

```php
// config/cache.php — flush bisa berat untuk database driver
// Untuk database driver, flush = truncate table
// Untuk file driver, flush = hapus semua file di folder cache
// Untuk redis, flush = FLUSHDB command
```

## Kasus Penggunaan Nyata
Setelah deploy dengan perubahan besar, setelah migrasi data, tombol "Clear Cache" di dashboard admin, dan maintenance mode.
