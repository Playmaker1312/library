# 360. Cache remember simpan ambil

## Definisi Singkat
Method `Cache::remember()` menggabungkan get dan put — ambil dari cache jika ada, atau simpan hasil closure jika belum ada.

## Analogi
Seperti "beli sambil masak" — cek kulkas (cache) dulu, kalau ada tinggal ambil, kalau tidak ada masak (proses) lalu simpan.

## Poin-Poin Penting
- Parameter: `key`, `ttl` (detik), `closure` (callback)
- Jika key ada: return value dari cache
- Jika key tidak ada: jalankan closure, simpan hasilnya, return
- `Cache::remember(key, ttl, closure)`
- Sangat umum digunakan untuk query caching

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use App\Models\Article;
use Illuminate\Support\Facades\Cache;

class ArticleController extends Controller
{
    public function index()
    {
        // remember — ambil atau simpan
        $articles = Cache::remember('articles.published', 3600, function () {
            return Article::with('author')
                ->where('status', 'published')
                ->orderBy('published_at', 'desc')
                ->get();
        });

        return view('articles.index', compact('articles'));
    }

    public function show(string $slug)
    {
        // Cache per item
        $article = Cache::remember("article.{$slug}", 1800, function () use ($slug) {
            return Article::where('slug', $slug)
                ->with(['author', 'tags', 'comments'])
                ->firstOrFail();
        });

        return view('articles.show', compact('article'));
    }

    public function popular()
    {
        // Cache dengan komputasi berat
        $popular = Cache::remember('articles.popular', 300, function () {
            return Article::withCount('views')
                ->orderBy('views_count', 'desc')
                ->take(10)
                ->get();
        });

        return response()->json($popular);
    }
}
```

```php
<?php
// Cache::remember vs manual get+put

// Manual — panjang
$data = Cache::get('key');
if (!$data) {
    $data = expensiveOperation();
    Cache::put('key', $data, 3600);
}

// Dengan remember — ringkas
$data = Cache::remember('key', 3600, function () {
    return expensiveOperation();
});
```

```php
<?php
// Nested caching
$user = Cache::remember("user.{$id}", 3600, function () use ($id) {
    return Cache::remember("user.base.{$id}", 86400, function () use ($id) {
        return \App\Models\User::find($id);
    });
});
```

## Kasus Penggunaan Nyata
Caching data publik (artikel, produk, halaman landing), hasil query berat, response API, dan data yang jarang berubah.
