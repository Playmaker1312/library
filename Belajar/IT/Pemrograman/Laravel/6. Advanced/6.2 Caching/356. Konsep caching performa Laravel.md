# 356. Konsep Caching Performa Laravel

## Definisi Singkat
Caching adalah teknik menyimpan data sementara di media cepat (memory/file) untuk mengurangi beban database dan mempercepat response.

## Analogi
Seperti lemari es — Anda masak (proses) makanan sekali, lalu simpan di lemari es (cache). Besok tinggal panaskan, tidak perlu masak ulang.

## Poin-Poin Penting
- Cache menyimpan hasil operasi berat (query DB, API call, komputasi)
- Laravel mendukung banyak driver cache: file, database, redis, memcached
- Cache punya TTL (Time To Live) — data kadaluarsa otomatis
- Strategi: cache entire response, query result, atau partial view
- Cache bisa meningkatkan performa hingga 10-100x

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use App\Models\Product;
use Illuminate\Support\Facades\Cache;

class ProductController extends Controller
{
    public function index()
    {
        // Tanpa cache — query DB setiap request
        // $products = Product::all();

        // Dengan cache — query sekali, simpan 1 jam
        $products = Cache::remember('products.all', 3600, function () {
            return Product::with('category')->get();
        });

        return view('products.index', compact('products'));
    }

    public function show(string $slug)
    {
        $product = Cache::remember("product.{$slug}", 3600, function () use ($slug) {
            return Product::where('slug', $slug)->firstOrFail();
        });

        return view('products.show', compact('product'));
    }
}
```

```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Cache;

class DashboardController extends Controller
{
    public function index()
    {
        // Cache hasil komputasi berat
        $stats = Cache::remember('dashboard.stats', 300, function () {
            return [
                'total_users' => \App\Models\User::count(),
                'total_orders' => \App\Models\Order::count(),
                'revenue' => \App\Models\Order::sum('total'),
                'growth' => $this->calculateGrowth(),
            ];
        });

        return view('dashboard.index', compact('stats'));
    }

    private function calculateGrowth(): float
    {
        // Komputasi berat...
        sleep(2);
        return 15.5;
    }
}
```
