# 357. Cache Driver file database redis memcached

## Definisi Singkat
Laravel mendukung berbagai cache driver yang bisa dipilih sesuai kebutuhan melalui konfigurasi di `config/cache.php`.

## Analogi
Seperti memilih tempat penyimpanan — kardus (file), lemari arsip (database), atau brankas cepat (Redis/Memcached).

## Poin-Poin Penting
- `file`: Simpan di `storage/framework/cache/data/` — default, tanpa dependency
- `database`: Simpan di tabel database — untuk aplikasi multi-server tanpa Redis
- `redis`: In-memory, sangat cepat — untuk produksi skala besar
- `memcached`: In-memory, cepat — alternatif Redis
- `array`: Cache hilang setelah request — untuk testing
- `dynamodb`: Managed cache AWS

## Contoh Kode
```php
<?php
// config/cache.php

return [
    'default' => env('CACHE_DRIVER', 'file'),

    'stores' => [
        'file' => [
            'driver' => 'file',
            'path' => storage_path('framework/cache/data'),
        ],

        'database' => [
            'driver' => 'database',
            'table' => 'cache',
            'connection' => null,
        ],

        'redis' => [
            'driver' => 'redis',
            'connection' => 'cache',
            'lock_connection' => 'default',
        ],

        'memcached' => [
            'driver' => 'memcached',
            'servers' => [
                [
                    'host' => env('MEMCACHED_HOST', '127.0.0.1'),
                    'port' => env('MEMCACHED_PORT', 11211),
                    'weight' => 100,
                ],
            ],
        ],

        'array' => [
            'driver' => 'array',
            'serialize' => false,
        ],

        'dynamodb' => [
            'driver' => 'dynamodb',
            'key' => env('AWS_ACCESS_KEY_ID'),
            'secret' => env('AWS_SECRET_ACCESS_KEY'),
            'region' => env('AWS_DEFAULT_REGION', 'us-east-1'),
            'table' => env('DYNAMODB_CACHE_TABLE', 'cache'),
            'endpoint' => env('DYNAMODB_ENDPOINT'),
        ],
    ],

    'prefix' => env('CACHE_PREFIX', 'laravel_cache'),
];
```

```php
<?php
// .env — pilih driver
CACHE_DRIVER=redis
```

```php
<?php
// Menggunakan driver tertentu
use Illuminate\Support\Facades\Cache;

// Pakai driver file untuk data tertentu
$value = Cache::driver('file')->get('key');

// Pakai driver redis untuk data cepat
$value = Cache::driver('redis')->remember('fast.data', 3600, function () {
    return expensiveOperation();
});

// Multiple driver
Cache::driver('file')->put('backup', $data);
Cache::driver('redis')->put('hot', $data);
```

## Kasus Penggunaan Nyata
`file` untuk development, `redis` untuk produksi performa tinggi, `database` untuk shared cache tanpa infrastruktur tambahan, `array` untuk unit testing.
