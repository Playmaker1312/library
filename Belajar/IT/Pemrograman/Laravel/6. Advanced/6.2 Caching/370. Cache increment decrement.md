# 370. Cache increment decrement

## Definisi Singkat
Method `Cache::increment()` dan `Cache::decrement()` digunakan untuk menambah/mengurangi nilai numerik di cache secara atomik.

## Analogi
Seperti counter di pintu masuk mal — setiap orang lewat, counter bertambah 1. Tidak perlu baca-tulis manual.

## Poin-Poin Penting
- `Cache::increment(key)` — tambah 1 (default)
- `Cache::increment(key, amount)` — tambah amount
- `Cache::decrement(key)` — kurangi 1
- `Cache::decrement(key, amount)` — kurangi amount
- Operasi atomik — aman dari race condition
- Key harus sudah ada berupa integer atau belum ada (dianggap 0)

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Support\Facades\Cache;

class VisitorController extends Controller
{
    public function track()
    {
        // Increment visitor counter — atomik, aman concurrent
        $visitorCount = Cache::increment('visitors.total');

        // Increment per halaman
        $page = request()->path();
        Cache::increment("visitors.page." . str_replace('/', '.', $page));

        // Increment dengan jumlah tertentu
        Cache::increment('visitors.batch', 5);

        return response()->json([
            'total_visitors' => $visitorCount
        ]);
    }
}
```

```php
<?php

namespace App\Services;

use Illuminate\Support\Facades\Cache;

class VoteService
{
    public function vote(string $candidateId): int
    {
        // Increment vote count — atomik
        $newCount = Cache::increment("votes.{$candidateId}");

        // Juga increment total votes
        Cache::increment('votes.total');

        return $newCount;
    }

    public function getVotes(string $candidateId): int
    {
        return Cache::get("votes.{$candidateId}", 0);
    }

    public function resetVotes(): void
    {
        Cache::forget('votes.total');
        // Hapus semua vote candidate...
    }
}
```

```php
<?php

namespace App\Services;

use Illuminate\Support\Facades\Cache;

class StockService
{
    public function reserveStock(int $productId, int $qty = 1): bool
    {
        $key = "stock.reserved.{$productId}";

        // Cek apakah masih cukup
        $reserved = Cache::get($key, 0);
        $total = $this->getTotalStock($productId);

        if (($reserved + $qty) > $total) {
            return false; // Stock tidak cukup
        }

        // Reserve stock
        Cache::increment($key, $qty);

        return true;
    }

    public function releaseStock(int $productId, int $qty = 1): void
    {
        Cache::decrement("stock.reserved.{$productId}", $qty);
    }

    private function getTotalStock(int $productId): int
    {
        return \App\Models\Product::find($productId)->stock;
    }
}
```

## Kasus Penggunaan Nyata
Visitor counter, vote system, stock management, API rate limiting, download counter, dan analytics real-time yang membutuhkan operasi atomik.
