# 396. Mail fake Event fake Queue fake Notification fake

## Definisi Singkat
Laravel menyediakan fake (palsu) untuk Mail, Event, Queue, dan Notification agar testing lebih mudah tanpa benar-benar mengirim.

## Analogi
Seperti panggilan pura-pura di drama — aktor pura-pura menelepon, tapi tidak ada sinyal yang benar-benar dikirim.

## Poin-Poin Penting
- `Mail::fake()` — cegah email benar-benar terkirim
- `Event::fake()` — cegah event benar-benar di-dispatch
- `Queue::fake()` — cegah job benar-benar di-queue
- `Notification::fake()` — cegah notifikasi benar-benar terkirim
- Setelah fake, gunakan assert untuk verifikasi

## Contoh Kode
```php
<?php

namespace Tests\Feature;

use Tests\TestCase;
use App\Mail\WelcomeMail;
use App\Events\UserRegistered;
use App\Jobs\SendWelcomeEmail;
use App\Notifications\WelcomeNotification;
use App\Models\User;
use Illuminate\Support\Facades\Mail;
use Illuminate\Support\Facades\Event;
use Illuminate\Support\Facades\Queue;
use Illuminate\Support\Facades\Notification;
use Illuminate\Foundation\Testing\RefreshDatabase;

class UserRegistrationTest extends TestCase
{
    use RefreshDatabase;

    // MAIL FAKE
    public function test_welcome_email_is_sent(): void
    {
        Mail::fake();

        $response = $this->post('/register', [
            'name' => 'Budi',
            'email' => 'budi@example.com',
            'password' => 'password',
        ]);

        // Assert email terkirim ke user
        Mail::assertSent(WelcomeMail::class, function ($mail) {
            return $mail->hasTo('budi@example.com');
        });

        // Assert tidak ada email lain
        Mail::assertNothingOutgoing();
    }

    // EVENT FAKE
    public function test_event_is_dispatched(): void
    {
        Event::fake();

        $response = $this->post('/register', [
            'name' => 'Ani',
            'email' => 'ani@example.com',
            'password' => 'password',
        ]);

        Event::assertDispatched(UserRegistered::class);
        Event::assertDispatched(UserRegistered::class, function ($event) {
            return $event->user->email === 'ani@example.com';
        });
    }

    // QUEUE FAKE
    public function test_job_is_dispatched(): void
    {
        Queue::fake();

        $response = $this->post('/register', [
            'name' => 'Cici',
            'email' => 'cici@example.com',
            'password' => 'password',
        ]);

        Queue::assertPushed(SendWelcomeEmail::class);
        Queue::assertPushed(SendWelcomeEmail::class, function ($job) {
            return $job->user->email === 'cici@example.com';
        });

        // Assert job tidak dipush ke queue tertentu
        Queue::assertNotPushed(SendWelcomeEmail::class, 'high');
    }

    // NOTIFICATION FAKE
    public function test_notification_is_sent(): void
    {
        Notification::fake();

        $user = User::factory()->create();

        $response = $this->actingAs($user)
            ->post('/complete-profile');

        Notification::assertSentTo(
            $user,
            WelcomeNotification::class
        );

        Notification::assertSentTo(
            [$user],
            WelcomeNotification::class,
            function ($notification) {
                return $notification->title === 'Selamat Datang!';
            }
        );

        Notification::assertNothingSent();
    }
}
```

```php
<?php
// Assertions tambahan

// Mail
Mail::assertQueued(WelcomeMail::class);  // Assert di-queue
Mail::assertNotSent(WelcomeMail::class);
Mail::assertNothingOutgoing();

// Event
Event::assertNotDispatched(SomeEvent::class);
Event::assertDispatchedTimes(UserRegistered::class, 1);

// Queue
Queue::assertPushedOn('high', SendWelcomeEmail::class);
Queue::assertPushedTimes(SendWelcomeEmail::class, 1);
Queue::assertNothingPushed();

// Notification
Notification::assertSentOnDemand(WelcomeNotification::class);
Notification::assertTimesSent(1, WelcomeNotification::class);
```

## Kasus Penggunaan Nyata
Memastikan email terkirim saat registrasi, event di-dispatch saat aksi tertentu, job masuk antrian, dan notifikasi sampai ke user — tanpa benar-benar mengirimnya.
