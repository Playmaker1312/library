# 388. Make test Artisan

## Definisi Singkat
Artisan command `make:test` digunakan untuk membuat file test baru secara otomatis.

## Analogi
Seperti mencetak formulir isian — Anda tinggal isi nama test, format sudah disediakan.

## Poin-Poin Penting
- `php artisan make:test NamaTest` — buat Feature test
- `php artisan make:test NamaTest --unit` — buat Unit test
- File dibuat di `tests/Feature/` atau `tests/Unit/`
- Bisa tentukan subfolder dengan dot notation
- Test yang sudah dibuat bisa langsung dijalankan

## Contoh Kode
```bash
# Membuat test
php artisan make:test UserTest
# Created: tests/Feature/UserTest.php

php artisan make:test ProductTest --unit
# Created: tests/Unit/ProductTest.php

# Dengan subfolder
php artisan make:test Services/PaymentServiceTest --unit
# Created: tests/Unit/Services/PaymentServiceTest.php

php artisan make:test Http/Controllers/OrderControllerTest
# Created: tests/Feature/Http/Controllers/OrderControllerTest.php
```

```php
<?php
// Hasil: tests/Feature/UserTest.php
namespace Tests\Feature;

use Illuminate\Foundation\Testing\RefreshDatabase;
use Tests\TestCase;

class UserTest extends TestCase
{
    // Gunakan trait jika perlu database
    // use RefreshDatabase;

    public function test_example(): void
    {
        $response = $this->get('/');

        $response->assertStatus(200);
    }
}
```

```php
<?php
// Hasil: tests/Unit/ProductTest.php
namespace Tests\Unit;

use PHPUnit\Framework\TestCase;

class ProductTest extends TestCase
{
    public function test_example(): void
    {
        $this->assertTrue(true);
    }
}
```

```php
<?php
// Best practice — test yang baik

// 1. Nama jelas: test_user_can_register()
// 2. Satu test satu tanggung jawab
// 3. Gunakan factory, bukan data manual
// 4. Ikuti pola: Arrange → Act → Assert

public function test_admin_can_delete_product(): void
{
    // Arrange
    $admin = User::factory()->admin()->create();
    $product = Product::factory()->create();

    // Act
    $response = $this->actingAs($admin)
        ->delete("/products/{$product->id}");

    // Assert
    $response->assertStatus(302);
    $this->assertDatabaseMissing('products', ['id' => $product->id]);
}
```

## Kasus Penggunaan Nyata
Membuat test untuk setiap fitur baru, memastikan coverage testing, dan mengikuti TDD (Test Driven Development).
