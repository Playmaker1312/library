# 393. RefreshDatabase trait

## Definisi Singkat
Trait `RefreshDatabase` secara otomatis me-reset database sebelum setiap test, memastikan isolasi dan kebersihan data.

## Analogi
Seperti membersihkan meja kerja sebelum memulai tugas baru — tidak ada sisa pekerjaan sebelumnya yang mengganggu.

## Poin-Poin Penting
- `use RefreshDatabase;` di class test
- Menjalankan migrasi sebelum test pertama
- Membungkus setiap test dalam transaksi (lebih cepat)
- Alternatif: `DatabaseTransactions` trait
- Penting untuk test yang berinteraksi dengan database

## Contoh Kode
```php
<?php

namespace Tests\Feature;

use Tests\TestCase;
use App\Models\User;
use App\Models\Product;
use Illuminate\Foundation\Testing\RefreshDatabase;

class ProductCrudTest extends TestCase
{
    // Database akan di-reset untuk setiap test
    use RefreshDatabase;

    public function test_can_create_product(): void
    {
        // Database kosong — tidak ada data sebelumnya
        $this->assertDatabaseCount('products', 0);

        $response = $this->post('/products', [
            'name' => 'Produk A',
            'price' => 10000,
        ]);

        $this->assertDatabaseCount('products', 1);
        $this->assertDatabaseHas('products', ['name' => 'Produk A']);
    }

    public function test_can_list_products(): void
    {
        // Database kosong LAGI — test sebelumnya tidak berpengaruh
        Product::factory()->count(3)->create();

        $response = $this->get('/products');

        $response->assertStatus(200);
        $this->assertDatabaseCount('products', 3);
    }

    public function test_can_delete_product(): void
    {
        // Database kosong lagi
        $product = Product::factory()->create();

        $this->delete("/products/{$product->id}");

        $this->assertDatabaseCount('products', 0);
    }
}
```

```php
<?php
// RefreshDatabase vs DatabaseTransactions

// RefreshDatabase — jalankan migrasi + transaksi per test
// Cocok untuk:
// - Test yang mengubah schema
// - Project dengan banyak test
// - Lebih lambat di awal (migrasi) tapi cepat setelahnya

// DatabaseTransactions — hanya bungkus dalam transaksi
// Cocok untuk:
// - Test tanpa migrasi
// - Database sudah siap
// - Lebih cepat untuk test individual

use Illuminate\Foundation\Testing\DatabaseTransactions;

class UserTest extends TestCase
{
    use DatabaseTransactions;
    // Hanya di-rollback, tidak migrasi ulang
}
```

```php
<?php
// Konfigurasi database testing di .env
// .env.testing atau phpunit.xml

// phpunit.xml
<php>
    <env name="DB_CONNECTION" value="sqlite"/>
    <env name="DB_DATABASE" value=":memory:"/>

// Atau .env.testing
DB_CONNECTION=sqlite
DB_DATABASE=:memory:
```

## Kasus Penggunaan Nyata
Semua feature test yang menggunakan database, CRUD test, test validasi, dan test yang membutuhkan isolasi data lengkap.
