# 391. Assertions assertStatus assertJson assertRedirect

## Definisi Singkat
Assertions adalah method untuk memverifikasi bahwa response HTTP sesuai dengan harapan — status code, JSON, redirect, dll.

## Analogi
Seperti checklist koki — setelah masak (request), dicek apakah rasanya sudah pas (assert), warnanya benar, porsinya sesuai.

## Poin-Poin Penting
- `assertStatus(200)` — cek HTTP status code
- `assertOk()` — shortcut untuk status 200
- `assertJson([...])` — cek struktur JSON
- `assertRedirect($uri)` — cek redirect ke URL tertentu
- `assertViewHas('key')` — cek data yang dikirim ke view
- Banyak assertion lain: `assertSee()`, `assertSessionHas()`, dll

## Contoh Kode
```php
<?php

namespace Tests\Feature;

use Tests\TestCase;
use App\Models\User;
use Illuminate\Foundation\Testing\RefreshDatabase;

class ResponseAssertionTest extends TestCase
{
    use RefreshDatabase;

    // Status code
    public function test_status_codes(): void
    {
        // 200 OK
        $this->get('/')->assertStatus(200);
        $this->get('/')->assertOk();

        // 201 Created
        $this->postJson('/api/users', [
            'name' => 'Budi'
        ])->assertStatus(201)
          ->assertCreated();

        // 302 Redirect
        $this->get('/dashboard')
            ->assertStatus(302)
            ->assertRedirect('/login');

        // 404 Not Found
        $this->get('/nonexistent')
            ->assertStatus(404)
            ->assertNotFound();

        // 403 Forbidden
        $this->get('/admin')
            ->assertStatus(403)
            ->assertForbidden();

        // 401 Unauthenticated
        $this->getJson('/api/orders')
            ->assertStatus(401)
            ->assertUnauthorized();

        // 422 Validation Error
        $this->post('/register', [])
            ->assertStatus(422)
            ->assertSessionHasErrors(['name', 'email', 'password']);
    }

    // JSON assertions
    public function test_json_responses(): void
    {
        $response = $this->getJson('/api/users/1');

        $response->assertJson([
            'id' => 1,
            'name' => 'Budi',
        ]);

        // Cek hanya struktur (ignore field lain)
        $response->assertJsonStructure([
            'id',
            'name',
            'email',
            'created_at',
        ]);

        // Cek exact match
        $response->assertExactJson([
            'id' => 1,
            'name' => 'Budi',
        ]);

        // Cek fragment
        $response->assertJsonFragment(['name' => 'Budi']);
        $response->assertJsonMissing(['name' => 'Ani']);

        // Cek dengan path
        $response->assertJsonPath('data.user.name', 'Budi');
    }

    // Redirect assertions
    public function test_redirects(): void
    {
        // Redirect ke URL spesifik
        $this->post('/login', [
            'email' => 'user@test.com',
            'password' => 'password',
        ])->assertRedirect('/dashboard');

        // Redirect ke route
        $this->get('/login')
            ->assertRedirectToRoute('login');

        // Redirect dengan session flash
        $this->post('/products', [])
            ->assertRedirect()
            ->assertSessionHas('error');
    }

    // View assertions
    public function test_view(): void
    {
        $response = $this->get('/products');

        $response->assertViewIs('products.index');
        $response->assertViewHas('products');
        $response->assertViewHas('products', \App\Models\Product::all());
        $response->assertViewHasAll([
            'products',
            'categories',
        ]);
        $response->assertSee('Daftar Produk');
        $response->assertDontSee('Error');
    }

    // Database assertions
    public function test_database(): void
    {
        $this->assertDatabaseHas('users', [
            'email' => 'user@test.com',
        ]);

        $this->assertDatabaseMissing('users', [
            'email' => 'nonexistent@test.com',
        ]);

        $this->assertDatabaseCount('users', 5);

        $user = User::first();
        $this->assertModelExists($user);
        $this->assertSoftDeleted($user); // Jika soft delete
    }
}
```

## Kasus Penggunaan Nyata
Memvalidasi response API, memastikan redirect setelah form submission, mengecek error handling, dan verifikasi data di database.
