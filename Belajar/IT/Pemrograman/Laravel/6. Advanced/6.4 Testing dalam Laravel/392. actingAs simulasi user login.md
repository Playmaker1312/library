# 392. actingAs simulasi user login

## Definisi Singkat
Method `actingAs()` digunakan untuk mensimulasikan user yang sudah login (autentikasi) dalam feature test.

## Analogi
Seperti kartu akses karyawan — dengan `actingAs`, test Anda memiliki akses seperti user tertentu tanpa perlu login sungguhan.

## Poin-Poin Penting
- `$this->actingAs($user)` — login sebagai user
- `$this->actingAs($user, 'api')` — login dengan guard spesifik
- User bisa dibuat dengan factory
- Semua request setelahnya dianggap sebagai user tersebut
- Berguna untuk test endpoint yang butuh autentikasi

## Contoh Kode
```php
<?php

namespace Tests\Feature;

use Tests\TestCase;
use App\Models\User;
use App\Models\Order;
use Illuminate\Foundation\Testing\RefreshDatabase;

class OrderControllerTest extends TestCase
{
    use RefreshDatabase;

    public function test_guest_cannot_view_orders(): void
    {
        // Guest (tidak login) — seharusnya di-redirect
        $response = $this->get('/orders');

        $response->assertRedirect('/login');
    }

    public function test_authenticated_user_can_view_orders(): void
    {
        // Buat user
        $user = User::factory()->create();

        // Login sebagai user tersebut
        $response = $this->actingAs($user)
            ->get('/orders');

        $response->assertStatus(200);
    }

    public function test_admin_can_view_all_orders(): void
    {
        // Admin user
        $admin = User::factory()->create(['role' => 'admin']);

        // Login sebagai admin
        $response = $this->actingAs($admin)
            ->get('/admin/orders');

        $response->assertStatus(200);
        $response->assertViewHas('orders');
    }

    public function test_user_can_only_see_own_orders(): void
    {
        $user = User::factory()->create();
        $otherUser = User::factory()->create();

        // Order milik user lain
        Order::factory()->create(['user_id' => $otherUser->id]);
        // Order milik user
        $myOrder = Order::factory()->create(['user_id' => $user->id]);

        $response = $this->actingAs($user)
            ->get('/orders');

        $response->assertDontSee($otherUser->name);
        $response->assertSee($myOrder->id);
    }

    public function test_with_api_guard(): void
    {
        $user = User::factory()->create();

        $response = $this->actingAs($user, 'api')
            ->getJson('/api/orders');

        $response->assertOk();
    }
}
```

```php
<?php
// Helper untuk berbagai role

// Di TestCase.php
protected function loginAsAdmin(): User
{
    $admin = User::factory()->create(['role' => 'admin']);
    $this->actingAs($admin);

    return $admin;
}

protected function loginAsUser(): User
{
    $user = User::factory()->create(['role' => 'user']);
    $this->actingAs($user);

    return $user;
}

// Di test
public function test_admin_can_delete_user(): void
{
    $this->loginAsAdmin();

    $user = User::factory()->create();

    $response = $this->delete("/users/{$user->id}");

    $response->assertStatus(302);
}
```

## Kasus Penggunaan Nyata
Test endpoint yang membutuhkan autentikasi, test otorisasi (role-based), test profile page, dan test API dengan token/sanctum.
