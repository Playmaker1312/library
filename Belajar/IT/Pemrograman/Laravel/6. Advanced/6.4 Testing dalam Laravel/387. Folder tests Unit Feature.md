# 387. Folder tests Unit Feature

## Definisi Singkat
Folder `tests/` dibagi menjadi `Unit` dan `Feature` — Unit untuk test fungsi kecil, Feature untuk test keseluruhan fitur.

## Analogi
Unit test seperti mengecek kualitas setiap biji kopi (komponen individu), Feature test seperti mencicipi secangkir kopi jadi (keseluruhan).

## Poin-Poin Penting
- `tests/Unit/` — test method kecil, tanpa database, fast
- `tests/Feature/` — test endpoint, interaksi database, slow
- Unit test selesai dalam milidetik
- Feature test bisa melibatkan database, session, autentikasi
- Keduanya penting untuk coverage menyeluruh

## Contoh Kode
```php
<?php
// tests/Unit/Services/CurrencyConverterTest.php
// Unit test — cepat, tanpa database

namespace Tests\Unit\Services;

use PHPUnit\Framework\TestCase;
use App\Services\CurrencyConverter;

class CurrencyConverterTest extends TestCase
{
    private CurrencyConverter $converter;

    protected function setUp(): void
    {
        parent::setUp();
        $this->converter = new CurrencyConverter();
    }

    public function test_convert_rp_to_usd(): void
    {
        $result = $this->converter->convert(15000, 'IDR', 'USD');

        $this->assertIsFloat($result);
        $this->assertEquals(1, round($result));
    }

    public function test_throw_exception_for_invalid_currency(): void
    {
        $this->expectException(\InvalidArgumentException::class);

        $this->converter->convert(100, 'IDR', 'XYZ');
    }
}
```

```php
<?php
// tests/Feature/Http/Controllers/AuthControllerTest.php
// Feature test — melibatkan routing, database, session

namespace Tests\Feature\Http\Controllers;

use Tests\TestCase;
use App\Models\User;
use Illuminate\Foundation\Testing\RefreshDatabase;

class AuthControllerTest extends TestCase
{
    use RefreshDatabase;

    public function test_user_can_login(): void
    {
        $user = User::factory()->create([
            'email' => 'user@example.com',
            'password' => bcrypt('password'),
        ]);

        $response = $this->post('/login', [
            'email' => 'user@example.com',
            'password' => 'password',
        ]);

        $response->assertRedirect('/dashboard');
        $this->assertAuthenticatedAs($user);
    }

    public function test_login_fails_with_wrong_password(): void
    {
        $user = User::factory()->create([
            'email' => 'user@example.com',
        ]);

        $response = $this->post('/login', [
            'email' => 'user@example.com',
            'password' => 'wrong_password',
        ]);

        $response->assertSessionHasErrors('email');
        $this->assertGuest();
    }
}
```

## Kasus Penggunaan Nyata
Unit test untuk service, helper, model method. Feature test untuk autentikasi, CRUD, API endpoint, dan interaksi browser.
