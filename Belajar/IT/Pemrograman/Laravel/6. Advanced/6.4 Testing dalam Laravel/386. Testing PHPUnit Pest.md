# 386. Testing PHPUnit Pest

## Definisi Singkat
Laravel mendukung dua framework testing: PHPUnit (default) dan Pest (alternatif dengan sintaks lebih ekspresif).

## Analogi
PHPUnit seperti bahasa formal (baku), Pest seperti bahasa sehari-hari (lebih santai dan mudah dibaca).

## Poin-Poin Penting
- PHPUnit: `->assertTrue()`, `->assertEquals()` — sintaks OOP
- Pest: `expect()->toBeTrue()`, `->assertTrue()` — sintaks fungsional
- Pest dibangun di atas PHPUnit (masih menggunakan PHPUnit engine)
- Bisa campur PHPUnit dan Pest dalam satu project
- Keduanya menggunakan `php artisan test` untuk menjalankan

## Contoh Kode
```php
<?php
// PHPUnit style — file: tests/Feature/UserTest.php

namespace Tests\Feature;

use Tests\TestCase;
use App\Models\User;

class UserTest extends TestCase
{
    public function test_user_can_register(): void
    {
        $response = $this->post('/register', [
            'name' => 'Budi',
            'email' => 'budi@example.com',
            'password' => 'password123',
            'password_confirmation' => 'password123',
        ]);

        $response->assertStatus(302);
        $this->assertDatabaseHas('users', ['email' => 'budi@example.com']);
    }
}
```

```php
<?php
// Pest style — file: tests/Feature/UserTest.php

use App\Models\User;

// Pest menggunakan fungsi, bukan class
test('user dapat register', function () {
    $response = $this->post('/register', [
        'name' => 'Budi',
        'email' => 'budi@example.com',
        'password' => 'password123',
        'password_confirmation' => 'password123',
    ]);

    $response->assertStatus(302);
    $this->assertDatabaseHas('users', ['email' => 'budi@example.com']);
});

// Atau dengan expect (Pest style)
test('user dapat register dengan expect', function () {
    $response = $this->post('/register', [
        'name' => 'Ani',
        'email' => 'ani@example.com',
        'password' => 'password123',
        'password_confirmation' => 'password123',
    ]);

    expect($response->status())->toBe(302);
    expect(User::whereEmail('ani@example.com'))->exists()->toBeTrue();
});
```

```php
<?php
// Setup Pest di project baru

// 1. Install Pest
// composer require pestphp/pest --dev

// 2. Inisialisasi
// ./vendor/bin/pest --init

// 3. Install plugin Laravel
// composer require pestphp/pest-plugin-laravel --dev
```

```bash
# Menjalankan test
php artisan test              # Semua test
php artisan test --testsuite=Feature   # Feature test saja
php artisan test --testsuite=Unit      # Unit test saja
./vendor/bin/pest             # Via Pest langsung
./vendor/bin/phpunit          # Via PHPUnit langsung
```

## Kasus Penggunaan Nyata
Pilih PHPUnit untuk project tim yang sudah terbiasa OOP, Pest untuk project baru dengan sintaks modern, atau campur keduanya sesuai preferensi.
