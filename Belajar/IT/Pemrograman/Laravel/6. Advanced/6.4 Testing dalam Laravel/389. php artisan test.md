# 389. php artisan test

## Definisi Singkat
`php artisan test` adalah command utama untuk menjalankan semua test di Laravel dengan output yang lebih ramah dibanding PHPUnit langsung.

## Analogi
Seperti remote TV all-in-one — satu tombol untuk menjalankan semua saluran (test) sekaligus dengan tampilan yang nyaman.

## Poin-Poin Penting
- `php artisan test` — jalankan semua test
- `php artisan test --filter=Nama` — filter test tertentu
- `php artisan test --testsuite=Unit` — hanya unit test
- `php artisan test --parallel` — paralel (butuh package)
- Output lebih readable dengan warna dan ikon

## Contoh Kode
```bash
# Menjalankan test
php artisan test

# Output:
#   PASS  Tests\Unit\UserTest
#   ✓ user can create
#   ✓ user can update
#
#   PASS  Tests\Feature\AuthTest
#   ✓ user can login
#   ✓ user can register
#   ✓ user can logout
#
#   Tests:  5 passed
#   Time:   2.34s

# Filter berdasarkan nama
php artisan test --filter=login
# Hanya menjalankan test dengan "login" di namanya

# Filter per file
php artisan test tests/Feature/AuthTest.php

# Hanya unit test
php artisan test --testsuite=Unit

# Hanya feature test
php artisan test --testsuite=Feature
```

```bash
# Opsi penting

# Stop di test pertama yang gagal
php artisan test --stop-on-failure

# Dengan coverage
php artisan test --coverage
php artisan test --coverage --min=80

# Profiling test lambat
php artisan test --profile

# Parallel testing (butuh package)
# composer require brianium/paratest --dev
php artisan test --parallel
```

```php
<?php
// Di dalam kode test, gunakan $this->artisan() untuk test command

namespace Tests\Feature\Console;

use Tests\TestCase;

class BackupCommandTest extends TestCase
{
    public function test_backup_command_runs_successfully(): void
    {
        $this->artisan('backup:run')
            ->assertSuccessful()
            ->expectsOutput('Backup berhasil!')
            ->doesntExpectOutput('Error')
            ->run();
    }
}
```

## Kasus Penggunaan Nyata
Menjalankan test di lokal sebelum commit, di CI/CD pipeline, debugging test failure, dan memastikan coverage minimal sebelum deploy.
