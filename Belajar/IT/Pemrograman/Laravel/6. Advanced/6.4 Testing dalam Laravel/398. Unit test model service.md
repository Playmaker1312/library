# 398. Unit test model service

## Definisi Singkat
Unit test untuk model dan service menguji logika bisnis secara terisolasi tanpa melibatkan database atau dependency eksternal.

## Analogi
Seperti menguji mesin mobil di laboratorium — Anda test komponen mesin (service/model) tanpa perlu mobil lengkap.

## Poin-Poin Penting
- Unit test: cepat, tanpa database, tanpa HTTP
- Model test: accessor, mutator, scope, relasi
- Service test: logika bisnis, validasi, perhitungan
- Gunakan mock untuk dependency eksternal
- Jangan test Laravel framework — test kode ANDA

## Contoh Kode
```php
<?php

namespace Tests\Unit\Models;

use PHPUnit\Framework\TestCase;
use App\Models\Product;

class ProductModelTest extends TestCase
{
    public function test_format_price_accessor(): void
    {
        $product = new Product(['price' => 15000]);

        // Test accessor — asumsikan ada accessor getFormattedPriceAttribute
        $formatted = $product->formatted_price;

        $this->assertEquals('Rp15.000', $formatted);
    }

    public function test_is_discounted(): void
    {
        $product = new Product([
            'price' => 100000,
            'discount_percent' => 20,
        ]);

        $this->assertTrue($product->isDiscounted());

        // Product tanpa diskon
        $product2 = new Product([
            'price' => 50000,
            'discount_percent' => 0,
        ]);

        $this->assertFalse($product2->isDiscounted());
    }

    public function test_calculate_discount_price(): void
    {
        $product = new Product([
            'price' => 100000,
            'discount_percent' => 25,
        ]);

        $discountPrice = $product->discountPrice();

        $this->assertEquals(75000, $discountPrice);
    }
}
```

```php
<?php

namespace Tests\Unit\Services;

use PHPUnit\Framework\TestCase;
use App\Services\TaxCalculator;

class TaxCalculatorTest extends TestCase
{
    private TaxCalculator $calculator;

    protected function setUp(): void
    {
        parent::setUp();
        $this->calculator = new TaxCalculator();
    }

    public function test_calculate_ppn(): void
    {
        $tax = $this->calculator->calculatePPN(100000);

        // PPN 11% dari harga
        $this->assertEquals(11000, $tax);
    }

    public function test_calculate_total_with_tax(): void
    {
        $total = $this->calculator->calculateTotal(100000, 11000);

        $this->assertEquals(111000, $total);
    }

    public function test_calculate_discount(): void
    {
        $result = $this->calculator->calculateDiscountedPrice(100000, 20);

        $this->assertEquals([
            'original_price' => 100000,
            'discount_percent' => 20,
            'discount_amount' => 20000,
            'final_price' => 80000,
        ], $result);
    }

    /**
     * @dataProvider taxProvider
     */
    public function test_tax_for_various_amounts(int $amount, int $expected): void
    {
        $this->assertEquals($expected, $this->calculator->calculatePPN($amount));
    }

    public static function taxProvider(): array
    {
        return [
            [0, 0],
            [10000, 1100],
            [100000, 11000],
            [1000000, 110000],
        ];
    }
}
```

```php
<?php

namespace Tests\Unit\Services;

use PHPUnit\Framework\TestCase;
use App\Services\OrderService;
use App\Models\Order;
use Mockery;

class OrderServiceTest extends TestCase
{
    // Test dengan mock model
    public function test_calculate_order_total(): void
    {
        $order = Mockery::mock(Order::class);
        $order->shouldReceive('items->sum->price')
            ->andReturn(100000);

        $orderService = new OrderService();
        $total = $orderService->calculateTotal($order);

        $this->assertEquals(100000, $total);
    }

    protected function tearDown(): void
    {
        Mockery::close();
        parent::tearDown();
    }
}
```

## Kasus Penggunaan Nyata
Menguji logika harga, kalkulasi pajak, validasi data, format output, dan aturan bisnis lainnya tanpa ketergantungan database.
