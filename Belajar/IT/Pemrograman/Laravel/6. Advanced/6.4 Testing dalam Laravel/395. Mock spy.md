# 395. Mock spy

## Definisi Singkat
Mock dan Spy adalah teknik pengujian untuk menggantikan objek nyata dengan objek tiruan yang perilakunya bisa dikontrol dan diperiksa.

## Analogi
Mock seperti aktor pengganti (stuntman) — dia menggantikan aktor asli untuk adegan tertentu. Spy seperti detektif yang merekam siapa yang dihubungi dan kapan.

## Poin-Poin Penting
- `$this->mock(Class::class)` — buat mock, expectations before
- `$this->spy(Class::class)` — buat spy, assertions after
- Mock: set ekspektasi sebelum aksi
- Spy: verifikasi setelah aksi (apa yang dipanggil)
- `Mockery` library digunakan di belakang layar
- Penting untuk unit test dengan dependency eksternal

## Contoh Kode
```php
<?php

namespace Tests\Feature;

use Tests\TestCase;
use App\Services\PaymentGateway;
use App\Http\Controllers\CheckoutController;

class CheckoutTest extends TestCase
{
    // MOCK — kita set ekspektasi sebelum aksi
    public function test_checkout_with_mock(): void
    {
        $this->mock(PaymentGateway::class, function ($mock) {
            $mock->shouldReceive('charge')
                ->once()
                ->with(50000)
                ->andReturn(['status' => 'success', 'id' => 'TRX-001']);
        });

        $response = $this->post('/checkout', [
            'amount' => 50000,
        ]);

        $response->assertStatus(200);
    }

    // SPY — kita verifikasi setelah aksi
    public function test_checkout_with_spy(): void
    {
        $spy = $this->spy(PaymentGateway::class);

        $response = $this->post('/checkout', [
            'amount' => 75000,
        ]);

        // Verifikasi bahwa charge() dipanggil dengan benar
        $spy->shouldHaveReceived('charge')
            ->once()
            ->with(75000);

        $spy->shouldNotHaveReceived('refund');
    }
}
```

```php
<?php

namespace Tests\Unit;

use Tests\TestCase;
use App\Services\MailService;
use App\Services\NotificationService;

class NotificationServiceTest extends TestCase
{
    public function test_send_welcome_email(): void
    {
        // Mock MailService
        $mailMock = $this->mock(MailService::class, function ($mock) {
            $mock->shouldReceive('sendWelcome')
                ->once()
                ->with('budi@example.com')
                ->andReturn(true);
        });

        $service = new NotificationService($mailMock);
        $result = $service->sendWelcome('budi@example.com');

        $this->assertTrue($result);
    }

    public function test_send_bulk_email_with_retry(): void
    {
        $mailMock = $this->mock(MailService::class, function ($mock) {
            // First call fails
            $mock->shouldReceive('send')
                ->once()
                ->andThrow(new \Exception('Timeout'));

            // Retry succeeds
            $mock->shouldReceive('send')
                ->once()
                ->andReturn(true);
        });

        $service = new NotificationService($mailMock);
        $result = $service->sendWithRetry('test@example.com', 'Retry test');

        $this->assertTrue($result);
    }
}
```

```php
<?php
// Mock vs Spy — kapan pakai yang mana?

// MOCK — gunakan ketika:
// - Perlu mengontrol return value
// - Perlu mensimulasi error/exception
// - Dependency tidak tersedia di lingkungan test
// - Contoh: mock payment gateway, API eksternal

// SPY — gunakan ketika:
// - Hanya perlu verifikasi method dipanggil
// - Tidak perlu mengontrol return value
// - Ingin memastikan interaksi yang benar
// - Contoh: spy logger, spy mailer, spy event dispatcher
```

```php
<?php
// Mocking facade
use Illuminate\Support\Facades\Cache;

public function test_cache_interaction(): void
{
    Cache::shouldReceive('remember')
        ->once()
        ->with('products.all', \Mockery::any(), \Mockery::any())
        ->andReturn(collect(['Product A']));

    $response = $this->get('/products');

    $response->assertSee('Product A');
}
```

## Kasus Penggunaan Nyata
Testing tanpa koneksi API eksternal, simulasi payment gateway, testing error handling, verifikasi email terkirim, dan isolasi unit test dari service nyata.
