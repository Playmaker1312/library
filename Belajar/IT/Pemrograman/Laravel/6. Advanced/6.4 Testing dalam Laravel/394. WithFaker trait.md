# 394. WithFaker trait

## Definisi Singkat
Trait `WithFaker` menyediakan akses ke Faker (generator data palsu) untuk membuat data test yang realistis.

## Analogi
Seperti aktor figuran di film — mereka bukan orang sungguhan, tapi membuat scene terlihat nyata.

## Poin-Poin Penting
- `use WithFaker;` — import trait
- `$this->faker->name()` — generate nama acak
- Faker bisa generate: nama, email, alamat, teks, nomor telepon, dll
- Lokalisasi: Indonesia (`id_ID`) untuk data lokal
- Bisa digunakan di factory dan test langsung
- Data konsisten untuk seed yang sama

## Contoh Kode
```php
<?php

namespace Tests\Unit;

use Tests\TestCase;
use Illuminate\Foundation\Testing\WithFaker;

class UserRegistrationTest extends TestCase
{
    use WithFaker;

    public function test_generate_realistic_user_data(): void
    {
        // Faker menghasilkan data realistis
        $userData = [
            'name' => $this->faker->name(),
            'email' => $this->faker->unique()->safeEmail(),
            'phone' => $this->faker->phoneNumber(),
            'address' => $this->faker->address(),
            'birth_date' => $this->faker->date('Y-m-d', '2000-01-01'),
        ];

        $response = $this->post('/register', $userData);

        $response->assertStatus(302);
        $this->assertDatabaseHas('users', [
            'email' => $userData['email'],
        ]);
    }

    public function test_generate_indonesian_data(): void
    {
        // Faker with Indonesian locale
        $faker = \Faker\Factory::create('id_ID');

        $name = $faker->name();          // "Budi Santoso"
        $city = $faker->city();          // "Bandung"
        $phone = $faker->phoneNumber();  // "0812-3456-7890"

        $this->assertNotEmpty($name);
    }
}
```

```php
<?php
// Faker di Factory
// database/factories/UserFactory.php

namespace Database\Factories;

use Illuminate\Database\Eloquent\Factories\Factory;

class UserFactory extends Factory
{
    public function definition(): array
    {
        return [
            'name' => $this->faker->name(),
            'email' => $this->faker->unique()->safeEmail(),
            'phone' => $this->faker->phoneNumber(),
            'address' => $this->faker->streetAddress(),
            'city' => $this->faker->city(),
            'password' => bcrypt('password'),
        ];
    }

    // State untuk admin
    public function admin(): static
    {
        return $this->state(fn(array $attributes) => [
            'role' => 'admin',
        ]);
    }
}
```

```php
<?php
// Daftar method Faker yang sering dipakai

// Personal
$this->faker->name();              // "Budi Santoso"
$this->faker->firstName();         // "Budi"
$this->faker->lastName();          // "Santoso"
$this->faker->title();             // "Mr."

// Contact
$this->faker->email();             // "budi@gmail.com"
$this->faker->phoneNumber();       // "0812-3456-7890"
$this->faker->address();           // "Jl. Merdeka No. 123"

// Text
$this->faker->sentence();          // "Lorem ipsum dolor sit amet"
$this->faker->paragraph();         // Paragraf acak
$this->faker->text(200);           // Teks 200 karakter

// Numbers
$this->faker->randomNumber();      // Angka acak
$this->faker->randomFloat(2, 0, 1000); // 0.00 - 1000.00
$this->faker->numberBetween(1, 100);   // 1 - 100

// DateTime
$this->faker->date();              // "2024-01-15"
$this->faker->time();              // "14:30:00"
$this->faker->dateTimeThisYear();  // DateTime tahun ini

// Lainnya
$this->faker->uuid();              // UUID unik
$this->faker->url();               // "http://example.com"
$this->faker->company();           // "PT. Maju Jaya"
```

## Kasus Penggunaan Nyata
Membuat data realistis untuk testing, factory definition, seeding database development, dan stress testing dengan variasi data.
