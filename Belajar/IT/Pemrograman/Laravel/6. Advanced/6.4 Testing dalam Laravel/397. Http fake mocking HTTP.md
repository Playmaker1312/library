# 397. Http fake mocking HTTP

## Definisi Singkat
`Http::fake()` memungkinkan mocking HTTP request sehingga test tidak perlu benar-benar terhubung ke server eksternal.

## Analogi
Seperti restoran palsu di film — terlihat seperti restoran sungguhan, tapi makanan (response) sudah disiapkan, tidak benar-benar dimasak.

## Poin-Poin Penting
- `Http::fake()` — cegah semua HTTP request
- `Http::fake(['url*' => response(...)])` — fake URL spesifik
- Bisa return status, headers, body tertentu
- Sequence response untuk multiple request
- `Http::assertSent()` — verifikasi request yang dikirim

## Contoh Kode
```php
<?php

namespace Tests\Feature;

use Tests\TestCase;
use Illuminate\Support\Facades\Http;
use App\Services\WeatherService;

class WeatherServiceTest extends TestCase
{
    // Fake semua request
    public function test_get_weather(): void
    {
        Http::fake([
            // Mock response untuk URL tertentu
            'api.openweathermap.org/*' => Http::response([
                'main' => ['temp' => 28.5],
                'weather' => [['description' => 'Cerah']],
                'name' => 'Jakarta',
            ], 200),
        ]);

        $service = app(WeatherService::class);
        $weather = $service->getWeather('Jakarta');

        $this->assertEquals(28.5, $weather['temp']);
        $this->assertEquals('Cerah', $weather['description']);
    }

    // Fake dengan status error
    public function test_handles_api_error(): void
    {
        Http::fake([
            'api.example.com/*' => Http::response(null, 500),
        ]);

        $service = app(WeatherService::class);

        $this->expectException(\RuntimeException::class);
        $service->getWeather('Unknown City');
    }

    // Sequence response
    public function test_multiple_requests(): void
    {
        Http::fake([
            'api.example.com/*' => Http::sequence()
                ->push(['status' => 'processing'], 202)
                ->push(['status' => 'completed'], 200)
                ->whenEmpty(Http::response(['status' => 'done'], 200)),
        ]);

        $service = app(WeatherService::class);

        $first = $service->checkStatus();
        $second = $service->checkStatus();
        $third = $service->checkStatus();

        $this->assertEquals('processing', $first['status']);
        $this->assertEquals('completed', $second['status']);
        $this->assertEquals('done', $third['status']);
    }
}
```

```php
<?php

namespace Tests\Feature;

use Tests\TestCase;
use Illuminate\Support\Facades\Http;

class PaymentGatewayTest extends TestCase
{
    public function test_payment_success(): void
    {
        Http::fake([
            'api.midtrans.com/*' => Http::response([
                'transaction_id' => 'TRX-123',
                'status' => 'success',
                'gross_amount' => 50000,
            ], 200, ['X-Request-Id' => 'req-001']),
        ]);

        $response = Http::post('https://api.midtrans.com/v2/charge', [
            'amount' => 50000,
        ]);

        $this->assertTrue($response->successful());
        $this->assertEquals('TRX-123', $response['transaction_id']);
    }

    public function test_assert_http_sent(): void
    {
        Http::fake();

        Http::post('https://api.example.com/data', ['key' => 'value']);

        Http::assertSent(function ($request) {
            return $request->url() === 'https://api.example.com/data'
                && $request['key'] === 'value';
        });

        Http::assertSentCount(1);
        Http::assertNothingSent(); // Jika tidak ada yang dikirim
    }
}
```

```php
<?php
// Http fake options

// Response dengan delay (simulasi timeout)
Http::fake([
    'api.example.com' => Http::response(['data' => 'ok'], 200, [],
        ['delay' => 3000]  // ms
    ),
]);

// Response dari file
Http::fake([
    'api.example.com/users' => Http::response(
        file_get_contents(base_path('tests/fixtures/users.json')),
        200
    ),
]);

// Fake dengan callback
Http::fake(function ($request) {
    return Http::response(['url' => $request->url()], 200);
});
```

## Kasus Penggunaan Nyata
Testing integrasi API eksternal (Midtrans, RajaOngkir, Google Maps), simulasi error koneksi, testing retry logic, dan penghematan biaya API call di testing.
