# 399. Code coverage flag coverage

## Definisi Singkat
Code coverage mengukur persentase kode yang di-cover oleh test, membantu mengidentifikasi bagian kode yang belum diuji.

## Analogi
Seperti peta panas — area hijau (ter-cover) berarti sudah diuji, area merah (belum ter-cover) berarti berisiko.

## Poin-Poin Penting
- `php artisan test --coverage` — tampilkan coverage
- `php artisan test --coverage --min=80` — gagal jika coverage < 80%
- Membutuhkan Xdebug atau PCOV
- Coverage dihitung per baris kode yang dieksekusi
- Metrics: Lines, Functions, Classes, Methods

## Contoh Kode
```bash
# Install Xdebug (PHP extension)
# Di php.ini tambahkan:
# zend_extension=xdebug
# xdebug.mode=coverage

# Atau install PCOV (lebih cepat)
# pecl install pcov

# Jalankan dengan coverage
php artisan test --coverage

# Output:
#   App\Services\TaxCalculator        100.0%
#   App\Services\PaymentGateway        85.7%
#   App\Http\Controllers\ProductCtrl   72.3%
#   App\Models\Product                 90.0%
#   ----------------------------------------
#   Total Coverage:                   87.5%
```

```bash
# Dengan minimal threshold
php artisan test --coverage --min=90

# Jika coverage < 90%, test akan FAIL
# Tests:  45 passed
# Coverage: 87.5%
# FAIL: Coverage below expected 90.0%
```

```php
<?php
// phpunit.xml — konfigurasi coverage

<phpunit>
    <source>
        <include>
            <!-- Direktori yang diukur coverage-nya -->
            <directory suffix=".php">app/Services</directory>
            <directory suffix=".php">app/Http/Controllers</directory>
            <directory suffix=".php">app/Models</directory>
        </include>

        <exclude>
            <!-- Direktori yang tidak diukur -->
            <directory suffix=".php">app/Console</directory>
            <file>app/Helpers/functions.php</file>
        </exclude>
    </source>
</phpunit>
```

```bash
# Generate report dalam format HTML
php -dxdebug.mode=coverage ./vendor/bin/phpunit --coverage-html coverage-report

# Buka coverage-report/index.html di browser
# Lihat visual hijau-merah per file

# Format lain:
# --coverage-clover=xml  → untuk CI
# --coverage-html=dir    → visual HTML
# --coverage-text=file   → text output
```

```yaml
# .github/workflows/tests.yml — coverage di CI
- name: Run tests with coverage
  run: php artisan test --coverage --min=80

- name: Upload coverage to Codecov
  uses: codecov/codecov-action@v3
  with:
    files: ./coverage.xml
```

## Kasus Penggunaan Nyata
Memastikan kualitas kode di CI/CD, mengidentifikasi kode yang belum di-test, target coverage untuk tim (min 80%), dan audit keamanan kode.
