# 415. Memastikan Reverb Bisa Berjalan dengan Baik di Production Menggunakan Supervisor

## Definisi & Target
Mengkonfigurasi dan memastikan Laravel Reverb berjalan stabil di lingkungan production. Meliputi Supervisor process management, SSL/TLS, scaling, monitoring, dan logging. Targetnya adalah WebSocket server yang reliable 24/7.

## Komponen yang Terlibat
- Supervisor process manager
- SSL/TLS certificate
- Load balancing
- Redis for scaling
- Reverb logging
- Health check endpoint
- Monitoring (Pulse/Horizon)
- Auto-restart on failure

## Perintah Artisan CLI
```bash
# Test Reverb production
php artisan reverb:start --host=0.0.0.0 --port=8080

# Check Reverb status
php artisan reverb:status

# Generate production keys
php artisan reverb:generate-keys

# Test with production config
php artisan config:cache
php artisan route:cache
php artisan reverb:start
```

## Kode Implementasi (Per File)

### Supervisor Configuration
```ini
; /etc/supervisor/conf.d/reverb.conf
[program:laravel-reverb]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/html/artisan reverb:start --host=0.0.0.0 --port=8080
user=forge
numprocs=1
autostart=true
autorestart=true
startsecs=3
startretries=3
stopwaitsecs=600
stopasgroup=true
killasgroup=true
stdout_logfile=/var/www/html/storage/logs/reverb.log
stdout_logfile_maxbytes=50MB
stdout_logfile_backups=10
stderr_logfile=/var/www/html/storage/logs/reverb-error.log
stderr_logfile_maxbytes=50MB
stderr_logfile_backups=10
environment=
    APP_ENV=production,
    APP_DEBUG=false,
    BROADCAST_CONNECTION=reverb,
    REVERB_APP_ID="%(ENV_REVERB_APP_ID)s",
    REVERB_APP_KEY="%(ENV_REVERB_APP_KEY)s",
    REVERB_APP_SECRET="%(ENV_REVERB_APP_SECRET)s",
    REVERB_HOST=0.0.0.0,
    REVERB_PORT=8080,
    REVERB_SCHEME=https,
```

### Supervisor Command Management
```bash
# Reload supervisor config
sudo supervisorctl reread
sudo supervisorctl update

# Start Reverb
sudo supervisorctl start laravel-reverb

# Stop Reverb
sudo supervisorctl stop laravel-reverb

# Restart Reverb
sudo supervisorctl restart laravel-reverb

# Check status
sudo supervisorctl status laravel-reverb

# Check logs
sudo supervisorctl tail -f laravel-reverb
```

### Nginx Reverse Proxy Configuration
```nginx
# /etc/nginx/sites-available/example.com
server {
    listen 443 ssl;
    server_name example.com;

    ssl_certificate /etc/ssl/certs/example.com.pem;
    ssl_certificate_key /etc/ssl/private/example.com.key;

    # Reverb WebSocket proxy
    location /app {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 86400;
    }

    # Main application
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

# HTTP redirect to HTTPS
server {
    listen 80;
    server_name example.com;
    return 301 https://$server_name$request_uri;
}
```

### Health Check Endpoint
```php
<?php
// routes/api.php
use Illuminate\Support\Facades\Broadcast;
use Illuminate\Support\Facades\Route;

Route::get('/health/reverb', function () {
    try {
        $connection = Broadcast::connection('reverb');

        $ping = $connection->getPusherClient()->ping();

        return response()->json([
            'status' => 'healthy',
            'service' => 'reverb',
            'timestamp' => now()->toISO8601String(),
            'connections' => cache()->get('reverb_connections', 0),
        ]);
    } catch (\Exception $e) {
        return response()->json([
            'status' => 'unhealthy',
            'service' => 'reverb',
            'error' => $e->getMessage(),
            'timestamp' => now()->toISO8601String(),
        ], 503);
    }
});
```

### Deployment Script
```bash
#!/bin/bash
# deploy-reverb.sh

echo "Deploying Reverb configuration..."

# 1. Cache config
php artisan config:cache
php artisan route:cache

# 2. Update Supervisor config
sudo cp deployment/supervisor/reverb.conf /etc/supervisor/conf.d/
sudo supervisorctl reread
sudo supervisorctl update

# 3. Restart Reverb gracefully
sudo supervisorctl restart laravel-reverb

# 4. Verify
sleep 2
sudo supervisorctl status laravel-reverb

# 5. Test health check
curl -s https://example.com/api/health/reverb | jq .

echo "Deployment complete."
```

### Monitoring with Laravel Pulse
```php
<?php
// config/pulse.php - Pulse integration for Reverb
return [
    'recorders' => [
        \Laravel\Pulse\Recorders\Concerns\Sampling::class => [
            'sample_rate' => env('PULSE_SAMPLE_RATE', 1),
        ],
    ],
];

// Register in AppServiceProvider
public function boot(): void
{
    \Laravel\Pulse\Facades\Pulse::user(fn ($user) => [
        'name' => $user->name,
        'extra' => $user->is_admin ? 'Admin' : 'User',
    ]);
}
```

### Logging Configuration
```php
<?php
// config/logging.php
'channels' => [
    'reverb' => [
        'driver' => 'daily',
        'path' => storage_path('logs/reverb.log'),
        'level' => env('REVERB_LOG_LEVEL', 'warning'),
        'days' => 14,
    ],
],

// In ReverbServiceProvider or AppServiceProvider
public function boot(): void
{
    if (config('app.env') === 'production') {
        config()->set('reverb.logging.channel', 'reverb');
    }
}
```
