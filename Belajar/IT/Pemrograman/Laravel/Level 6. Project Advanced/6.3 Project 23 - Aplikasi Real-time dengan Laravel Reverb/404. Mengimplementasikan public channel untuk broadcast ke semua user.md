# 404. Mengimplementasikan Public Channel untuk Broadcast ke Semua User

## Definisi & Target
Mengimplementasikan public channel untuk broadcast event ke semua user yang terhubung. Public channel tidak memerlukan authentication, sehingga siapapun yang subscribe ke channel akan menerima event. Targetnya adalah broadcast notifikasi global seperti pengumuman atau update sistem.

## Komponen yang Terlibat
- ShouldBroadcast interface
- Public channel definition
- Event class
- Echo .channel() method
- Broadcasting routes
- Queue for async broadcast

## Perintah Artisan CLI
```bash
# Membuat event
php artisan make:event AnnouncementEvent
php artisan make:event SystemNotification
php artisan make:event GlobalUpdate
```

## Kode Implementasi (Per File)

### Event - AnnouncementEvent
```php
<?php
namespace App\Events;

use Illuminate\Broadcasting\Channel;
use Illuminate\Broadcasting\InteractsWithSockets;
use Illuminate\Contracts\Broadcasting\ShouldBroadcast;
use Illuminate\Foundation\Events\Dispatchable;
use Illuminate\Queue\SerializesModels;

class AnnouncementEvent implements ShouldBroadcast
{
    use Dispatchable, InteractsWithSockets, SerializesModels;

    public function __construct(
        public string $message,
        public string $type = 'info',
        public ?string $actionUrl = null,
        public ?string $actionText = null
    ) {}

    public function broadcastOn(): Channel
    {
        return new Channel('announcements');
    }

    public function broadcastAs(): string
    {
        return 'announcement.created';
    }

    public function broadcastWith(): array
    {
        return [
            'message' => $this->message,
            'type' => $this->type,
            'action_url' => $this->actionUrl,
            'action_text' => $this->actionText,
            'timestamp' => now()->toISO8601String(),
        ];
    }
}
```

### Event - SystemNotification
```php
<?php
namespace App\Events;

use Illuminate\Broadcasting\Channel;
use Illuminate\Broadcasting\InteractsWithSockets;
use Illuminate\Contracts\Broadcasting\ShouldBroadcast;
use Illuminate\Foundation\Events\Dispatchable;
use Illuminate\Queue\SerializesModels;

class SystemNotification implements ShouldBroadcast
{
    use Dispatchable, InteractsWithSockets, SerializesModels;

    public function __construct(
        public string $title,
        public string $body,
        public string $icon = 'info',
        public string $severity = 'low'
    ) {}

    public function broadcastOn(): array
    {
        return [
            new Channel('system'),
            new Channel('notifications'),
        ];
    }

    public function broadcastAs(): string
    {
        return 'system.notification';
    }

    public function broadcastWith(): array
    {
        return [
            'title' => $this->title,
            'body' => $this->body,
            'icon' => $this->icon,
            'severity' => $this->severity,
            'timestamp' => now()->toISO8601String(),
        ];
    }
}
```

### Event - GlobalUpdate
```php
<?php
namespace App\Events;

use Illuminate\Broadcasting\Channel;
use Illuminate\Broadcasting\InteractsWithSockets;
use Illuminate\Contracts\Broadcasting\ShouldBroadcast;
use Illuminate\Foundation\Events\Dispatchable;
use Illuminate\Queue\SerializesModels;

class GlobalUpdate implements ShouldBroadcast
{
    use Dispatchable, InteractsWithSockets, SerializesModels;

    public function __construct(
        public string $type,
        public array $data = []
    ) {}

    public function broadcastOn(): Channel
    {
        return new Channel('global');
    }

    public function broadcastAs(): string
    {
        return 'global.update';
    }

    public function broadcastWith(): array
    {
        return array_merge($this->data, [
            'update_type' => $this->type,
            'timestamp' => now()->toISO8601String(),
        ]);
    }
}
```

### Controller - BroadcastController
```php
<?php
namespace App\Http\Controllers;

use App\Events\AnnouncementEvent;
use App\Events\SystemNotification;
use Illuminate\Http\Request;

class BroadcastController extends Controller
{
    public function sendAnnouncement(Request $request)
    {
        $validated = $request->validate([
            'message' => 'required|string|max:500',
            'type' => 'required|in:info,warning,success,danger',
            'action_url' => 'nullable|url',
            'action_text' => 'nullable|string|max:50',
        ]);

        AnnouncementEvent::dispatch(
            $validated['message'],
            $validated['type'],
            $validated['action_url'] ?? null,
            $validated['action_text'] ?? null
        );

        return response()->json(['message' => 'Announcement broadcasted.']);
    }

    public function sendNotification(Request $request)
    {
        $validated = $request->validate([
            'title' => 'required|string|max:100',
            'body' => 'required|string|max:500',
            'icon' => 'nullable|string',
            'severity' => 'nullable|in:low,medium,high,critical',
        ]);

        SystemNotification::dispatch(
            $validated['title'],
            $validated['body'],
            $validated['icon'] ?? 'info',
            $validated['severity'] ?? 'low'
        );

        return response()->json(['message' => 'Notification broadcasted.']);
    }
}
```

### Frontend - Listening to Public Channels
```javascript
// resources/js/services/public-channels.js
import echo from '../echo';
import { echoService } from './echo-service';

export function listenAnnouncements(callback) {
    return echoService.subscribePublic('announcements', '.announcement.created', callback);
}

export function listenSystemNotifications(callback) {
    return echoService.subscribePublic('system', '.system.notification', callback);
}

export function listenGlobalUpdates(callback) {
    return echoService.subscribePublic('global', '.global.update', callback);
}
```

### Vue Component - Announcement Banner
```vue
<template>
    <div v-if="announcement" :class="bannerClass" class="px-4 py-3 text-white text-center relative">
        <span>{{ announcement.message }}</span>
        <a v-if="announcement.action_url" :href="announcement.action_url"
           class="underline ml-2 font-semibold">
            {{ announcement.action_text || 'Lihat' }}
        </a>
        <button @click="dismiss" class="absolute right-4 top-3">&times;</button>
    </div>
</template>

<script setup>
import { ref, onMounted, onUnmounted, computed } from 'vue';
import { listenAnnouncements } from '../services/public-channels';

const announcement = ref(null);
const dismissed = ref(new Set());

const bannerClass = computed(() => ({
    'bg-blue-600': announcement.value?.type === 'info',
    'bg-yellow-600': announcement.value?.type === 'warning',
    'bg-green-600': announcement.value?.type === 'success',
    'bg-red-600': announcement.value?.type === 'danger',
}));

let unsubscribe = null;

onMounted(() => {
    unsubscribe = listenAnnouncements((data) => {
        if (!dismissed.value.has(data.message)) {
            announcement.value = data;
            setTimeout(() => { announcement.value = null; }, 10000);
        }
    });
});

onUnmounted(() => {
    if (unsubscribe) unsubscribe();
});

function dismiss() {
    if (announcement.value) {
        dismissed.value.add(announcement.value.message);
        announcement.value = null;
    }
}
</script>
```

### Blade Component - System Notification
```html
<!-- resources/views/components/system-notification.blade.php -->
<div id="system-notification" class="fixed top-4 right-4 z-50 space-y-2"></div>

@push('scripts')
<script>
document.addEventListener('DOMContentLoaded', function () {
    const container = document.getElementById('system-notification');

    window.Echo.channel('system')
        .listen('.system.notification', function (data) {
            const colors = {
                low: 'bg-blue-500',
                medium: 'bg-yellow-500',
                high: 'bg-orange-500',
                critical: 'bg-red-500',
            };

            const notification = document.createElement('div');
            notification.className = `${colors[data.severity] || 'bg-blue-500'} text-white px-4 py-3 rounded-lg shadow-lg flex items-center gap-3 transition-all duration-300`;
            notification.innerHTML = `
                <span class="text-lg">${data.icon === 'info' ? 'ℹ️' : data.icon}</span>
                <div>
                    <strong>${data.title}</strong>
                    <p class="text-sm opacity-90">${data.body}</p>
                </div>
            `;

            container.appendChild(notification);

            setTimeout(() => {
                notification.style.opacity = '0';
                setTimeout(() => notification.remove(), 300);
            }, 5000);
        });
});
</script>
@endpush
```

## Cara Integrasi & Pengujian
1. Buat event class dengan ShouldBroadcast
2. Definisikan public channel di broadcastOn()
3. Jalankan Reverb: php artisan reverb:start
4. Subscribe di frontend dengan Echo.channel('announcements')
5. Broadcast event dari tinker: event(new AnnouncementEvent('Test'))
6. Verifikasi semua user terhubung menerima event
7. Test multiple subscribers di tab browser berbeda
8. Test queue worker untuk async broadcast
9. Test dengan user tidak login (public channel)
10. Monitor Reverb log untuk memastikan tidak ada error
