# 402. Menginstal dan Mengkonfigurasi Laravel Reverb sebagai WebSocket Server Native

## Definisi & Target
Menginstal dan mengkonfigurasi Laravel Reverb sebagai WebSocket server native untuk Laravel. Reverb adalah first-party WebSocket server yang terintegrasi langsung dengan Laravel Broadcasting system. Targetnya adalah WebSocket server yang siap production.

## Komponen yang Terlibat
- Laravel Reverb package
- Reverb server configuration
- Environment variables
- Queue worker untuk broadcasting
- SSL/TLS configuration
- Scaling configuration
- Supervisor process manager

## Perintah Artisan CLI
```bash
# Install Reverb
composer require laravel/reverb

# Publish config
php artisan vendor:publish --tag=reverb-config

# Generate app key
php artisan reverb:generate-keys

# Install frontend dependencies
npm install --save-dev laravel-echo pusher-js

# Start Reverb server (development)
php artisan reverb:start

# Start Reverb with debug
php artisan reverb:start --debug

# Check Reverb status
php artisan reverb:status
```

## Kode Implementasi (Per File)

### Config - reverb.php
```php
<?php
return [
    'apps' => [
        [
            'app_id' => env('REVERB_APP_ID'),
            'key' => env('REVERB_APP_KEY'),
            'secret' => env('REVERB_APP_SECRET'),
            'allowed_origins' => explode(',', env('REVERB_ALLOWED_ORIGINS', '*')),
            'ping_interval' => env('REVERB_PING_INTERVAL', 30),
            'max_message_size' => env('REVERB_MAX_MESSAGE_SIZE', 10240),
        ],
    ],
    'scaling' => [
        'enabled' => env('REVERB_SCALING_ENABLED', false),
        'channel' => env('REVERB_SCALING_CHANNEL', 'reverb_scaling'),
        'server' => [
            'url' => env('REDIS_URL'),
            'host' => env('REDIS_HOST', '127.0.0.1'),
            'port' => env('REDIS_PORT', 6379),
            'password' => env('REDIS_PASSWORD'),
            'database' => env('REDIS_DB', 0),
        ],
    ],
    'pulse_ingest_interval' => env('REVERB_PULSE_INGEST_INTERVAL', 15),
    'templates' => [
        'enabled' => env('REVERB_TEMPLATES_ENABLED', true),
        'directory' => resource_path('reverb'),
    ],
];
```

### Environment Configuration
```env
# .env untuk Reverb
BROADCAST_CONNECTION=reverb

REVERB_APP_ID=app-12345
REVERB_APP_KEY=your-app-key-here
REVERB_APP_SECRET=your-app-secret-here
REVERB_HOST=0.0.0.0

REVERB_SCHEME=http
REVERB_ALLOWED_ORIGINS=*

# REVERB_SCHEME=https
# REVERB_PORT=443

VITE_REVERB_APP_KEY="${REVERB_APP_KEY}"
VITE_REVERB_HOST="${REVERB_HOST}"
VITE_REVERB_PORT="${REVERB_PORT}"
VITE_REVERB_SCHEME="${REVERB_SCHEME}"
```

    'reverb' => [
        'driver' => 'reverb',
        'key' => env('REVERB_APP_KEY'),

### Test Script - Connection Test
```php
<?php
namespace App\Console\Commands;

use Illuminate\Console\Command;
use Illuminate\Support\Facades\Broadcast;

class TestReverbConnection extends Command
{
    protected $signature = 'reverb:test';
    protected $description = 'Test Reverb connection';

    public function handle(): int
    {
        $this->info('Testing Reverb connection...');

        try {
            $connection = Broadcast::connection('reverb');
            $this->info('Connection: OK');
            $this->line('App ID: ' . config('reverb.apps.0.app_id'));
            $this->line('Key: ' . config('reverb.apps.0.key'));
            $this->line('Host: ' . config('reverb.apps.0.options.host'));
            $this->line('Port: ' . config('reverb.apps.0.options.port'));
        } catch (\Exception $e) {
            $this->error('Connection failed: ' . $e->getMessage());
            return Command::FAILURE;
        }

        return Command::SUCCESS;
    }
}
```

### Frontend Bootstrap - resources/js/bootstrap.js
```javascript
import Echo from 'laravel-echo';
import Pusher from 'pusher-js';

window.Pusher = Pusher;

window.Echo = new Echo({
    broadcaster: 'reverb',
    key: import.meta.env.VITE_REVERB_APP_KEY,
    wsHost: import.meta.env.VITE_REVERB_HOST,
    wsPort: import.meta.env.VITE_REVERB_PORT ?? 8080,
    wssPort: import.meta.env.VITE_REVERB_PORT ?? 443,
    forceTLS: (import.meta.env.VITE_REVERB_SCHEME ?? 'https') === 'https',
    enabledTransports: ['ws', 'wss'],
    disableStats: true,
});

window.Echo.connector.pusher.connection.bind('connected', () => {
    console.log('Terhubung ke Reverb WebSocket');
});

window.Echo.connector.pusher.connection.bind('disconnected', () => {
    console.log('Terputus dari Reverb WebSocket');
});

window.Echo.connector.pusher.connection.bind('error', (error) => {
    console.error('Reverb Error:', error);
});
```

## Cara Integrasi & Pengujian
1. Install Reverb: composer require laravel/reverb
2. Generate keys: php artisan reverb:generate-keys
3. Update .env dengan konfigurasi Reverb
4. Install frontend: npm install --save-dev laravel-echo pusher-js
5. Setup Echo di resources/js/bootstrap.js
6. Jalankan Reverb: php artisan reverb:start --debug
7. Buka browser console dan verifikasi koneksi WebSocket
8. Test broadcast event dari tinker:
   ```
   php artisan tinker
   > event(new App\Events\TestEvent('hello'));
   ```
9. Atur Supervisor untuk production
10. Verifikasi log Reverb tidak ada error
