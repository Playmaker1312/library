# 384. Mengimplementasikan Tenant-Specific Configuration yang Bisa Dikustomisasi

## Definisi & Target
Tenant-specific configuration memungkinkan setiap tenant memiliki pengaturan sendiri yang dapat diubah tanpa mempengaruhi tenant lain. Contoh: logo perusahaan, warna tema, pengaturan email, payment gateway, dan fitur toggle. Targetnya adalah konfigurasi tersimpan di database dan di-cache untuk performa.

## Komponen yang Terlibat
- TenantSetting model
- TenantConfig service class
- Caching per tenant
- Settings management page
- Global scope untuk settings
- Helper function untuk akses settings di view

## Perintah Artisan CLI
`ash
# Membuat model dan migration
php artisan make:model TenantSetting -m

# Membuat service
php artisan make:class Services/TenantConfigService

# Membuat controller
php artisan make:controller TenantSettingController

# Membuat middleware untuk load settings
php artisan make:middleware LoadTenantSettings
`

## Cara Integrasi & Pengujian
1. Jalankan php artisan db:seed --class=TenantSettingDefaultSeeder
2. Daftarkan tenant baru dan login
3. Akses /settings untuk melihat form konfigurasi
4. Ubah company_name dan simpan
5. Refresh dan pastikan data tersimpan
6. Cek cache: redis/memcache key tenant_settings_{tenant_id}
7. Upload logo dan pastikan tersimpan di storage/logos/
8. Ganti tenant dan pastikan pengaturan berbeda
9. Gunakan helper tenant_config() di view atau controller
10. Test reset to default untuk satu setting
11. Pastikan cache terhapus saat setting diupdate
