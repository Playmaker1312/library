# 373. Menginstal dan mengkonfigurasi package Spatie Laravel Multitenancy

## Definisi & Target
Menginstal package Spatie Laravel Multitenancy yang menyediakan fitur multi-tenancy siap pakai, termasuk tenant identification, queue tenant-aware, cache tenant-aware, dan file system tenant-aware. Package ini menghemat waktu pengembangan dibandingkan implementasi manual.

Target: package terinstal, konfigurasi selesai, dan tenant identification berfungsi.

## Komponen yang Terlibat
- Composer package `spatie/laravel-multitenancy`
- Konfigurasi `config/multitenancy.php`
- Tenant model
- Landlord (super admin) vs Tenant model

## Perintah Artisan CLI
```bash
# Install package
composer require spatie/laravel-multitenancy

# Publish konfigurasi
php artisan vendor:publish --provider="Spatie\Multitenancy\MultitenancyServiceProvider" --tag="multitenancy-config"

# Buat migration untuk tenants table
php artisan make:migration create_tenants_table
```

## Kode Implementasi (Per File)

### Konfigurasi - config/multitenancy.php
```php
return [
    'tenant_model' => App\Models\Tenant::class,

    'tenant_finder' => Spatie\Multitenancy\TenantFinder\SubdomainTenantFinder::class,

    'switch_tenant_to_after_queue_job' => true,

    'queues_are_tenant_aware_by_default' => true,

    'tenant_aware_commands' => [
        //
    ],
];
```

### Migration - Tenants Table
```php
Schema::create('tenants', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->string('domain')->unique();
    $table->string('database')->nullable();
    $table->json('config')->nullable();
    $table->timestamps();
});
```

### Model - Tenant
```php
use Spatie\Multitenancy\Models\Tenant as BaseTenant;

class Tenant extends BaseTenant
{
    protected $fillable = [
        'name', 'domain', 'database', 'config',
    ];

    protected $casts = [
        'config' => 'array',
    ];
}
```

## Cara Integrasi & Pengujian
- Jalankan migration: `php artisan migrate`
- Buat tenant manual: `Tenant::create(['name' => 'Client A', 'domain' => 'clienta.example.com'])`
- Akses via subdomain `clienta.example.com` dan pastikan tenant terdeteksi
- Log untuk debugging: `\Spatie\Multitenancy\Models\Tenant::current()`
