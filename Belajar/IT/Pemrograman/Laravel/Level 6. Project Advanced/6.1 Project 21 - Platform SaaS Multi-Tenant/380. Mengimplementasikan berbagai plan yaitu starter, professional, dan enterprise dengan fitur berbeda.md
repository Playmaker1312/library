# 380. Mengimplementasikan Berbagai Plan Yaitu Starter, Professional, dan Enterprise dengan Fitur Berbeda

## Definisi & Target
Membuat tiered pricing dengan tiga plan: Starter (basic), Professional (menengah), dan Enterprise (lengkap). Setiap plan memiliki fitur, limitasi, dan harga berbeda. Targetnya adalah sistem dapat membedakan akses fitur berdasarkan plan tenant dengan mulus.

## Komponen yang Terlibat
- Plan model dengan seeder
- PlanFeature model untuk fitur per plan
- Middleware untuk check plan
- Policy untuk authorization berdasarkan plan
- Plan comparison table di view
- Feature flag system

## Perintah Artisan CLI
`ash
# Membuat model Plan dan PlanFeature
php artisan make:model Plan -m
php artisan make:model PlanFeature -m

# Membuat middleware
php artisan make:middleware CheckPlan
php artisan make:middleware CheckFeatureAccess

# Membuat seeder
php artisan make:seeder PlanSeeder

# Membuat controller
php artisan make:controller PlanController
`

### Middleware - CheckPlan
`php
<?php
namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class CheckPlan
{
    public function handle(Request , Closure , string ...): Response
    {
         = tenant();

        if (! || !in_array(->plan, )) {
            abort_if(->expectsJson(), 403, [
                'message' => 'Fitur ini memerlukan paket ' . implode(', ', ) . '.'
            ]);

            return redirect()->route('subscription.index')
                ->with('error', 'Upgrade paket Anda untuk mengakses fitur ini.');
        }

        return ();
    }
}
