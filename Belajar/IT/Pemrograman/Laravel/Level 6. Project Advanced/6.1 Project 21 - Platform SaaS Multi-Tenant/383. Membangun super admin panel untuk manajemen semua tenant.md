# 383. Membangun Super Admin Panel untuk Manajemen Semua Tenant

## Definisi & Target
Super admin panel adalah dashboard terpusat untuk mengelola semua tenant dari satu tempat. Fitur meliputi: daftar semua tenant dengan status, create/delete tenant, impersonate tenant, manage billing global, view logs semua tenant, dan system health monitoring. Targetnya adalah kontrol penuh atas semua tenant.

## Komponen yang Terlibat
- SuperAdmin middleware untuk proteksi akses
- Tenant management controller
- Impersonation feature
- Global billing dashboard
- Activity log viewer
- System health checks
- Tenant isolation override

### Middleware - SuperAdmin
`php
<?php
namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class SuperAdmin
{
    public function handle(Request , Closure ): Response
    {
        if (!->user() || !->user()->is_super_admin) {
            if (->expectsJson()) {
                return response()->json(['message' => 'Unauthorized. Super admin only.'], 403);
            }

            abort(403, 'Akses khusus super admin.');
        }

        return ();
    }
}

    {
        if (!tenant()) {
            Session::put('impersonate_back_to', url()->previous());
        }

        ->makeCurrent();

         = ->run(function () {
            return \App\Models\User::where('email', ->email)->first()
                ?? \App\Models\User::first();
        });

        if () {
            auth()->login();
        }

        return redirect()->route('dashboard')
            ->with('success', "Impersonating tenant: {->name}");
    }

    public function leave()
    {
        if (Session::has('impersonate_back_to')) {
             = Session::pull('impersonate_back_to');

            tenant()->forgetCurrent();

            auth()->logout();

            return redirect();
        }

        return redirect()->route('admin.dashboard');

    {

            return \App\Models\User::all();

### Route - admin.php
`php
<?php
// routes/admin.php
use Illuminate\Support\Facades\Route;
use App\Http\Controllers\Admin\DashboardController;
use App\Http\Controllers\Admin\TenantController;
use App\Http\Controllers\Admin\ImpersonationController;
use App\Http\Controllers\Admin\SystemHealthController;

Route::prefix('admin')->name('admin.')->middleware(['web', 'auth', 'super_admin'])->group(function () {

    Route::get('/', [DashboardController::class, 'index'])->name('dashboard');
    Route::get('/health', [SystemHealthController::class, 'index'])->name('health');
    Route::get('/health/check', [SystemHealthController::class, 'check'])->name('health.check');

    Route::resource('tenants', TenantController::class)->except(['edit', 'create']);
    Route::post('/tenants/{tenant}/toggle-status', [TenantController::class, 'toggleStatus'])->name('tenants.toggle-status');

    Route::prefix('impersonate')->name('impersonate.')->group(function () {
        Route::get('/enter/{tenant}', [ImpersonationController::class, 'enter'])->name('enter');
        Route::get('/leave', [ImpersonationController::class, 'leave'])->name('leave');
        Route::get('/users/{tenant}', [ImpersonationController::class, 'users'])->name('users');
    });
});

2. Akses /admin sebagai super admin → lihat dashboard
3. Akses /admin sebagai user biasa → harus 403
4. Buat tenant baru dari panel admin
5. Edit plan dan status tenant
6. Test impersonate: masuk ke tenant → lihat dashboard tenant
7. Keluar dari impersonation dan kembali ke admin panel
8. Cek halaman health check dan system metrics
9. Hapus tenant dan verifikasi data ikut terhapus
10. Test search, filter plan, dan filter status di daftar tenant
