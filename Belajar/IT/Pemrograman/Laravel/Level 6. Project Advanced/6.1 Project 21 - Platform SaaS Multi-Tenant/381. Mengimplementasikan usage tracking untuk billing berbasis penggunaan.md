# 381. Mengimplementasikan Usage Tracking untuk Billing Berbasis Penggunaan

## Definisi & Target
Usage tracking mencatat penggunaan resource per tenant (jumlah API calls, storage, user aktif, dll) untuk mendukung billing berbasis pemakaian (usage-based billing). Targetnya adalah pencatatan akurat dan real-time untuk setiap metrik penggunaan.

## Komponen yang Terlibat
- UsageRecord model untuk menyimpan catatan pemakaian
- UsageTracker service class
- Metered billing dengan Stripe
- Middleware untuk tracking request
- Scheduled job untuk reset periodik
- Dashboard usage display

<?php
namespace App\Models;

    ];

    protected  = [
        'value' => 'decimal:2',
        'limit' => 'decimal:2',
        'recorded_at' => 'datetime',
        'period_start' => 'date',
        'period_end' => 'date',
    ];

    public function tenant(): BelongsTo
    {
        return ->belongsTo(Tenant::class);
    }

    public function getUsagePercentage(): float
    {
        if (!->limit || ->limit == 0) {
            return 0;
        }
        return round((->value / ->limit) * 100, 2);
    }
}

## Cara Integrasi & Pengujian
1. Daftarkan tenant dan login
2. Akses halaman usage untuk melihat metrik
3. Buat beberapa API request dan lihat api_calls bertambah
4. Set limit di PlanFeature untuk api_calls
5. Akses endpoint yang di-protect middleware TrackApiUsage
6. Verifikasi usage tercatat di tabel usage_records
7. Test threshold alert: buat UsageAlert dan capai threshold
8. Jalankan php artisan usage:reset untuk reset periodik
9. Jadwalkan reset via cron: ->command('usage:reset')->monthly()
10. Verifikasi data billing di Stripe dashboard untuk metered usage
