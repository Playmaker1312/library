# 377. Mengimplementasikan Tenant Provisioning yaitu Setup Otomatis Saat Tenant Baru Terdaftar

## Definisi & Target
Tenant provisioning adalah proses otomatis yang menjalankan setup lengkap ketika tenant baru mendaftar. Setelah user mendaftar, sistem secara otomatis membuat database tenant, menjalankan migrasi, membuat domain/subdomain, dan mengirim kredensial. Targetnya adalah provisioning selesai dalam hitungan detik tanpa intervensi manual.

## Komponen yang Terlibat
- Event/Listener: TenantRegistered → RunProvisioning
- Artisan command untuk setup database tenant
- Spatie Multitenancy untuk database switching
- Queue job untuk provisioning async
- Domain/Subdomain registrar (DNS automation)
- Mail notification untuk kredensial

## Perintah Artisan CLI
`ash
# Membuat migration untuk table domains
php artisan make:migration create_domains_table

# Membuat job untuk provisioning
php artisan make:job ProvisionTenantJob

# Membuat listener
php artisan make:listener RunTenantProvisioning --event=TenantRegistered

# Command untuk setup manual tenant
php artisan tenant:provision --tenant={id}
`

## Cara Integrasi & Pengujian
1. Daftarkan tenant baru melalui form registrasi
2. Sistem akan membuat event dan menjalankan ProvisionTenantJob secara async
3. Cek di database apakah database tenant_baru telah dibuat
4. Cek apakah tabel di database tenant sudah termigrasi
5. Cek email untuk notifikasi welcome
6. Akses subdomain.anda.test untuk verifikasi tenant aktif
7. Gunakan php artisan queue:work untuk menjalankan job provisioning
8. Untuk testing, gunakan Storage::fake() dan Mail::fake() di PHPUnit
