# 382. Mengimplementasikan Fitur Flag Berbasis Plan Menggunakan Custom Middleware

## Definisi & Target
Membuat sistem feature flag yang mengontrol akses fitur berdasarkan plan tenant. Middleware akan memeriksa apakah tenant memiliki akses ke fitur tertentu sebelum request diproses. Targetnya adalah kontrol akses granular berbasis plan tanpa mengubah kode controller.

## Komponen yang Terlibat
- FeatureFlagService untuk evaluasi fitur
- CheckFeature middleware
- Plan-feature relationship
- Caching hasil pengecekan
- Blade directive untuk conditional rendering
- HTTP Exception handling

## Perintah Artisan CLI
`ash
# Membuat service
php artisan make:class Services/FeatureFlagService

# Membuat middleware
php artisan make:middleware CheckFeatureFlag

# Membuat facade (optional)
php artisan make:class Facades/FeatureFlag

# Membuat controller untuk testing
php artisan make:controller FeatureDemoController
`

### Route Registration - RouteServiceProvider atau web.php
`php
<?php
// Di routes/web.php

use App\Http\Controllers\ReportController;

Route::middleware(['auth', 'tenant'])->group(function () {

    // Laporan dasar - semua plan bisa akses
    Route::get('/reports/basic', [ReportController::class, 'basic'])->name('reports.basic');

    // Laporan advanced - hanya plan dengan fitur advanced_reports
    Route::middleware(['feature:advanced_reports,plans.index'])->group(function () {
        Route::get('/reports/advanced', [ReportController::class, 'advanced'])->name('reports.advanced');
        Route::get('/reports/export', [ReportController::class, 'export'])->name('reports.export');
    });

    // API Keys - hanya plan dengan fitur api_access
    Route::middleware(['feature:api_access'])->group(function () {
        Route::get('/api-keys', [ApiKeyController::class, 'index'])->name('api-keys.index');
        Route::post('/api-keys', [ApiKeyController::class, 'store'])->name('api-keys.store');
    });

    // Export data - dengan limit check
    Route::middleware(['feature.limit:export_data,exports_count'])->group(function () {
        Route::post('/data/export', [ExportController::class, 'export'])->name('data.export');
    });
});

## Cara Integrasi & Pengujian
1. Seed plan dan features (Starter = no advanced_reports, Professional/Enterprise = yes)
2. Buat testing route dengan middleware feature:advanced_reports
3. Login sebagai tenant Starter dan akses /reports/advanced → harus 403/redirect
4. Login sebagai tenant Professional dan akses /reports/advanced → harus sukses
5. Test Blade directive @feature di view
6. Test limit check dengan middleware feature.limit
7. Buka cached key di cache store untuk verifikasi caching
8. Panggil clearCache() setelah update plan untuk refresh
9. Test JSON response untuk API requests
10. Buat unit test untuk FeatureFlagService dengan berbagai scenario plan
