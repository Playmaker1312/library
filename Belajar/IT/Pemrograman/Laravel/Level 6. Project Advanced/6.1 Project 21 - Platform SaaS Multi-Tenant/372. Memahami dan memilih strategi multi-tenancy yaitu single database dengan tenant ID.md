# 372. Memahami dan memilih strategi multi-tenancy yaitu single database dengan tenant ID

## Definisi & Target
Memilih dan menerapkan strategi multi-tenancy menggunakan single database dengan kolom `tenant_id` di setiap tabel. Semua data tenant disimpan dalam satu database, diisolasi secara logis melalui foreign key `tenant_id` pada setiap query. Pendekatan ini paling sederhana secara operasional dan cocok untuk jumlah tenant kecil hingga menengah.

Target: semua migration dan model memiliki kolom `tenant_id`, query scoping berjalan otomatis, dan data antar tenant tidak bocor.

## Komponen yang Terlibat
- Database migration dengan kolom `tenant_id`
- Eloquent Model dengan Global Scope `TenantScope`
- Middleware untuk set tenant context
- Tenant identification dari subdomain/domain

## Perintah Artisan CLI
```bash
# Buat migration untuk menambah tenant_id ke tabel
php artisan make:migration add_tenant_id_to_users_table
```

## Kode Implementasi (Per File)

### Migration
```php
Schema::table('users', function (Blueprint $table) {
    $table->foreignId('tenant_id')->constrained()->cascadeOnDelete();
    $table->index('tenant_id');
});
```

### Model - TenantScope
```php
class TenantScope implements Scope
{
    public function apply(Builder $builder, Model $model)
    {
        $tenantId = app('currentTenant')->id ?? null;
        if ($tenantId) {
            $builder->where('tenant_id', $tenantId);
        }
    }
}
```

### Model - BaseModel
```php
abstract class BaseModel extends Model
{
    protected static function booted()
    {
        static::addGlobalScope(new TenantScope);
    }
}
```

### Model - User
```php
class User extends Authenticatable
{
    use BelongsToTenant;
}
```

### Trait BelongsToTenant
```php
trait BelongsToTenant
{
    public static function bootBelongsToTenant()
    {
        static::creating(function ($model) {
            if (!$model->tenant_id) {
                $model->tenant_id = app('currentTenant')->id;
            }
        });
    }

    public function tenant()
    {
        return $this->belongsTo(Tenant::class);
    }
}
```

## Cara Integrasi & Pengujian
- Setiap migration baru harus menyertakan `tenant_id`
- Unit test memastikan scope berjalan: `assertDatabaseHas` dengan `tenant_id`
- Test bahwa user dari tenant A tidak bisa mengakses data tenant B
