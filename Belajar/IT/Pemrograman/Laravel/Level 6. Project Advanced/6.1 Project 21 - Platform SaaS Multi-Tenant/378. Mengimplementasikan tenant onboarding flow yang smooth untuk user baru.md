# 378. Mengimplementasikan Tenant Onboarding Flow yang Smooth untuk User Baru

## Definisi & Target
Onboarding flow memandu tenant baru melalui serangkaian langkah setup setelah registrasi: verifikasi domain, konfigurasi profil perusahaan, undang admin/user tambahan, setup payment, dan melihat dashboard pertama. Targetnya adalah user bisa beroperasi penuh dalam < 5 menit.

## Komponen yang Terlibat
- Multi-step wizard form (Livewire atau JavaScript)
- Onboarding session tracker
- Tenant settings model
- Queue untuk background task provisioning
- Progress bar indicator
- Skip/tutorial mode

## Perintah Artisan CLI
`ash

### Livewire Component - OnboardingWizard
`php
<?php
namespace App\Http\Livewire;

use App\Models\OnboardingProgress;
use App\Models\TenantSetting;
use Livewire\Component;

class OnboardingWizard extends Component
{
    public int  = 0;
    public array  = [];
    public OnboardingProgress ;

    public const STEPS = [
        'welcome', 'company_profile', 'team_invitation',
        'payment_setup', 'first_look'
    ];

    protected  = ['stepCompleted'];

    public function mount(): void
    {
         = tenant();
        ->progress = OnboardingProgress::firstOrCreate(
            ['tenant_id' => ->id],
            ['started_at' => now()]
        );

        ->currentStep = ->progress->step_number;
    }

    public function nextStep(): void
    {
        if (->currentStep < count(self::STEPS) - 1) {
            ->progress->completeStep(self::STEPS[->currentStep]);
            ->currentStep++;
        }
    }

    public function previousStep(): void
    {
        if (->currentStep > 0) {
            ->currentStep--;
        }
    }

    public function skipStep(): void
    {
         = ->progress->skipped_steps ?? [];
        [] = self::STEPS[->currentStep];
        ->progress->update(['skipped_steps' => ]);
        ->nextStep();
    }

    public function completeOnboarding(): void
    {
        ->progress->completeStep(self::STEPS[->currentStep]);
        ->progress->update([
            'completed' => true,
            'completed_at' => now(),
        ]);

        notify_admins(new OnboardingComplete(tenant()));

        return redirect()->route('dashboard');
    }

    public function render()
    {
        return view('livewire.onboarding-wizard', [
            'steps' => self::STEPS,
            'progressPercent' => (->currentStep / count(self::STEPS)) * 100,
        ]);
    }
}
`

## Cara Integrasi & Pengujian
1. Daftarkan tenant baru dan login
2. Sistem akan redirect ke halaman onboarding wizard
3. Lengkapi setiap step dan verifikasi progress tersimpan
4. Refresh halaman dan pastikan progress tidak hilang
5. Klik "Lewati" pada beberapa step dan pastikan tidak wajib
6. Setelah selesai, redirect ke dashboard
7. Verifikasi OnboardingProgress. completed bernilai true
8. Test middleware: akses dashboard langsung tanpa completing akan redirect
