# 374. Mengimplementasikan tenant identification menggunakan subdomain

## Definisi & Target
Menerapkan mekanisme identifikasi tenant berdasarkan subdomain dari URL request. Contoh: `client-a.example.com` akan mengidentifikasi tenant dengan domain `client-a`. Spatie Multitenancy menyediakan `SubdomainTenantFinder` yang secara otomatis mencocokkan subdomain dengan data tenant di database.

Target: setiap request yang masuk melalui subdomain unik akan otomatis mengaktifkan konteks tenant yang sesuai.

## Komponen yang Terlibat
- Tenant model
- SubdomainTenantFinder (Spatie)
- Middleware multitenancy
- DNS wildcard record (infrastruktur)

## Perintah Artisan CLI
```bash
# Tidak ada perintah spesifik
# Pastikan tenant finder sudah dikonfigurasi
php artisan config:clear
```

## Kode Implementasi (Per File)

### Konfigurasi - config/multitenancy.php
```php
'tenant_finder' => Spatie\Multitenancy\TenantFinder\SubdomainTenantFinder::class,

'tenant_finder_config' => [
    'subdomain_column' => 'domain',
],
```

### Tenant Model (Existing)
```php
class Tenant extends BaseTenant
{
    // Kolom 'domain' menyimpan nilai subdomain
    // Misal: 'client-a' untuk client-a.example.com
}
```

### Custom Tenant Finder (Opsional)
```php
use Spatie\Multitenancy\Models\Tenant;
use Spatie\Multitenancy\TenantFinder\TenantFinder;
use Illuminate\Http\Request;

class CustomSubdomainTenantFinder extends TenantFinder
{
    public function findForRequest(Request $request): ?Tenant
    {
        $host = $request->getHost();
        $subdomain = explode('.', $host)[0] ?? null;

        if (!$subdomain || in_array($subdomain, ['www', 'app'])) {
            return null;
        }

        return Tenant::where('domain', $subdomain)->first();
    }
}
```

### Route Service Provider
```php
class RouteServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        $this->routes(function () {
            Route::middleware('web')
                ->domain('{subdomain}.' . config('app.domain'))
                ->group(base_path('routes/tenant.php'));
        });
    }
}
```

### Register Middleware di Kernel
```php
protected $middlewareGroups = [
    'web' => [
        \Spatie\Multitenancy\Middleware\EnsureValidTenantSession::class,
        // ...
    ],
];
```

## Cara Integrasi & Pengujian
- Setup wildcard DNS: `*.example.com` mengarah ke server
- Test dengan Postman: `GET http://client-a.example.com/login`
- Pastikan `Tenant::current()` mengembalikan tenant yang benar
- Test akses tanpa subdomain mengarah ke halaman utama (landlord)
