# 379. Membangun Subscription Management Menggunakan Laravel Cashier dengan Stripe

## Definisi & Target
Subscription management mengelola siklus berlangganan tenant: pembuatan paket, pembayaran berulang, trial period, upgrade/downgrade paket, pembatalan, dan penanganan failed payment. Targetnya adalah billing berjalan otomatis dan akurat.

## Komponen yang Terlibat
- Laravel Cashier (Stripe)
- Subscription model (Billable trait)
- Plan/Price configuration
- Stripe webhook handler
- Invoice generation
- Trial period management
- Payment method management

## Perintah Artisan CLI
`ash
# Install Cashier
composer require laravel/cashier

# Publish Cashier migration dan config
php artisan vendor:publish --tag="cashier-migrations"
php artisan vendor:publish --tag="cashier-config"

# Membuat subscription controller
php artisan make:controller SubscriptionController

# Membuat webhook controller
php artisan make:controller StripeWebhookController

# Migrate
php artisan migrate
`

### Model - Tenant with Billable
`php
<?php
namespace App\Models;

use Laravel\Cashier\Billable;
use Spatie\Multitenancy\Models\Tenant as BaseTenant;

class Tenant extends BaseTenant
{
    use Billable;

    protected  = [
        'name', 'email', 'database', 'subdomain',
        'plan', 'status', 'stripe_id', 'pm_type',
        'pm_last_four', 'trial_ends_at'
    ];

    public function plan()
    {
        return ->belongsTo(Plan::class);
    }

    public function onTrialOrSubscribed(): bool
    {
        return ->onTrial() || ->subscribed('default');
    }

    public function hasExpiredTrial(): bool
    {
        return ->trial_ends_at && now()->gt(->trial_ends_at) && !->subscribed('default');
    }
}
`

### Controller - SubscriptionController
`php
<?php
namespace App\Http\Controllers;

use App\Models\Plan;
use App\Models\Tenant;
use Illuminate\Http\Request;

class SubscriptionController extends Controller
{
    public function index()
    {
         = Plan::where('active', true)->get();
         = tenant();
         = ->subscription('default');
         = ->invoices();

        return view('subscription.index', compact('plans', 'tenant', 'subscription', 'invoices'));
    }

    public function checkout(Request )
    {
         = Plan::findOrFail(->plan_id);
         = tenant();

         = ->stripe_price_id;

        return 
            ->newSubscription('default', )
            ->trialDays(14)
            ->checkout([
                'success_url' => route('subscription.success'),
                'cancel_url' => route('subscription.cancel'),
            ]);
    }

    public function success(Request )
    {
         = tenant();
        ->update(['status' => 'active']);

        return redirect()->route('dashboard')->with('success', 'Langganan berhasil diaktifkan!');
    }

    public function swapPlan(Request )
    {
        ->validate(['plan_id' => 'required|exists:plans,id']);

         = Plan::findOrFail(->plan_id);
         = tenant();

         = ->subscription('default');

        if () {
            ->swap(->stripe_price_id);
            ->update(['plan_id' => ->id]);
        }

        return back()->with('success', 'Paket berhasil diubah.');
    }

    public function cancel(Request )
    {
         = tenant();
        ->subscription('default')->cancel();

        return back()->with('success', 'Langganan akan berakhir pada akhir periode.');
    }

    public function resume(Request )
    {
         = tenant();
        ->subscription('default')->resume();

        return back()->with('success', 'Langganan diaktifkan kembali.');
    }

    public function paymentMethod(Request )
    {
        ->validate(['payment_method' => 'required|string']);

         = tenant();
        ->updateDefaultPaymentMethod(->payment_method);

        return back()->with('success', 'Metode pembayaran berhasil diperbarui.');
    }

    public function invoice(Request , )
    {
        return tenant()->downloadInvoice(, [
            'vendor' => config('app.name'),
            'product' => 'Langganan Bulanan',
        ]);
    }
}
`

### Controller - StripeWebhookController
`php
<?php
namespace App\Http\Controllers;

use Laravel\Cashier\Http\Controllers\WebhookController as CashierWebhookController;
use Illuminate\Http\Request;

class StripeWebhookController extends CashierWebhookController
{
    public function handleInvoicePaymentSucceeded()
    {
         = ->getTenantByStripeId(['data']['object']['customer']);

        if () {
            activity('billing')
                ->performedOn()
                ->log('Pembayaran tagihan berhasil');
        }

        return ->successMethod();
    }

    public function handleInvoicePaymentFailed()
    {
         = ->getTenantByStripeId(['data']['object']['customer']);

        if () {
            ->update(['status' => 'past_due']);

            ->notify(new PaymentFailed());
        }

        return ->successMethod();
    }

    public function handleCustomerSubscriptionDeleted()
    {
         = ->getTenantByStripeId(['data']['object']['customer']);

        if () {
            ->update(['status' => 'canceled']);
        }

        return ->successMethod();
    }

    private function getTenantByStripeId(string ): ?Tenant
    {
        return Tenant::where('stripe_id', )->first();
    }
}
`

## Cara Integrasi & Pengujian
1. Setup Stripe API keys di .env (STRIPE_KEY, STRIPE_SECRET, STRIPE_WEBHOOK_SECRET)
2. Buat produk dan price di dashboard Stripe
3. Seeder Plan dengan stripe_price_id yang sesuai
4. Jalankan php artisan cashier:webhook untuk setup Stripe webhook
5. Test checkout flow: pilih plan, isi kartu kredit, sukses
6. Test di Stripe dashboard: subscription baru muncul
7. Test upgrade/downgrade plan
8. Test pembatalan dan resume subscription
9. Test invoice download
10. Test failed payment notification
11. Gunakan Stripe testing card numbers untuk berbagai scenario
