# 376. Mengimplementasikan database connection switching per tenant menggunakan Spatie

## Definisi & Target
Mengimplementasikan strategi database per tenant (multi-database) menggunakan Spatie Multitenancy. Setiap tenant memiliki database MySQL/MariaDB sendiri, dan koneksi database berganti secara otomatis berdasarkan tenant yang aktif. Cocok untuk isolasi data tingkat tinggi.

Target: setiap tenant memiliki database sendiri, koneksi database berubah otomatis per request, dan migrasi dijalankan per tenant.

## Komponen yang Terlibat
- Tenant model dengan konfigurasi database
- DatabaseManager Laravel
- Spatie Multitenancy event listener
- Tenant migration commands

## Perintah Artisan CLI
```bash
# Buat migration untuk menambah kolom database ke tenants
php artisan make:migration add_database_columns_to_tenants_table
```

## Kode Implementasi (Per File)

### Migration - Add Database Columns
```php
Schema::table('tenants', function (Blueprint $table) {
    $table->string('database_name')->nullable()->after('domain');
    $table->string('database_host')->default('127.0.0.1');
    $table->string('database_username')->nullable();
    $table->string('database_password')->nullable();
});
```

### Model - Tenant dengan Switch Database
```php
class Tenant extends BaseTenant
{
    public function configureDatabase(): void
    {
        config([
            'database.connections.tenant' => [
                'driver' => 'mysql',
                'host' => $this->database_host,
                'database' => $this->database_name,
                'username' => $this->database_username,
                'password' => decrypt($this->database_password),
                'charset' => 'utf8mb4',
                'collation' => 'utf8mb4_unicode_ci',
                'prefix' => '',
            ],
        ]);

        DB::purge('tenant');
        DB::reconnect('tenant');

        DB::setDefaultConnection('tenant');
    }

    protected static function booted()
    {
        static::retrieved(function (Tenant $tenant) {
            if ($tenant->database_name) {
                $tenant->configureDatabase();
            }
        });
    }
}
```

### Event Listener - Switch Database
```php
namespace App\Listeners;

use Spatie\Multitenancy\Events\MakingTenantCurrentEvent;

class SwitchDatabaseForTenant
{
    public function handle(MakingTenantCurrentEvent $event): void
    {
        $tenant = $event->tenant;

        if ($tenant->database_name) {
            $tenant->configureDatabase();
        }
    }
}
```

### Register Listener di EventServiceProvider
```php
protected $listen = [
    MakingTenantCurrentEvent::class => [
        SwitchDatabaseForTenant::class,
    ],
];
```

### Tenant Migration Command
```php
Artisan::call('migrate', [
    '--database' => 'tenant',
    '--path' => 'database/migrations/tenant',
]);
```
