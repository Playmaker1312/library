# 375. Membuat TenantAwareMiddleware untuk mengidentifikasi tenant dari setiap request

## Definisi & Target
Membuat middleware yang secara otomatis mengidentifikasi tenant dari setiap request, memuat konteks tenant ke dalam aplikasi, dan memastikan semua operasi database discope berdasarkan tenant tersebut. Middleware ini menjadi pintu gerbang utama multi-tenancy.

Target: setiap request yang masuk melewati TenantAwareMiddleware, tenant teridentifikasi dan tersedia secara global, request tanpa tenant valid ditolak.

## Komponen yang Terlibat
- Tenant model
- TenantAwareMiddleware
- Service container (app('currentTenant'))
- TenantFinder

## Perintah Artisan CLI
```bash
# Buat middleware
php artisan make:middleware TenantAwareMiddleware
```

## Kode Implementasi (Per File)

### Middleware - TenantAwareMiddleware
```php
namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use App\Models\Tenant;
use Symfony\Component\HttpFoundation\Response;

class TenantAwareMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        $tenantFinder = app(\Spatie\Multitenancy\TenantFinder\TenantFinder::class);
        $tenant = $tenantFinder->findForRequest($request);

        if (!$tenant) {
            if ($request->expectsJson()) {
                return response()->json(['message' => 'Tenant not found.'], 404);
            }
            abort(404, 'Tenant not found.');
        }

        $tenant->makeCurrent();

        app()->instance('currentTenant', $tenant);
        config(['app.tenant_id' => $tenant->id]);

        return $next($request);
    }
}
```

### Register Middleware di Kernel
```php
protected $middlewareGroups = [
    'web' => [
        \App\Http\Middleware\TenantAwareMiddleware::class,
        // middleware lain...
    ],
    'api' => [
        \App\Http\Middleware\TenantAwareMiddleware::class,
        // middleware lain...
    ],
];
```

### Helper Function
```php
function currentTenant(): ?Tenant
{
    return app('currentTenant');
}
```

### Service Provider untuk Binding
```php
class AppServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        $this->app->singleton('currentTenant', function () {
            return null;
        });
    }
}
```

## Cara Integrasi & Pengujian
- Test request dengan subdomain valid -> 200, tenant context aktif
- Test request tanpa subdomain -> redirect/404
- Test request dengan subdomain tidak dikenal -> 404
- Unit test: `$this->withoutTenantScope()` untuk bypass scope di test
