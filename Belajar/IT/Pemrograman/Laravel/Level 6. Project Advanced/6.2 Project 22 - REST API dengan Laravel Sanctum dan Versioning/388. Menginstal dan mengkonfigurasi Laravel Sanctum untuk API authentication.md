# 388. Menginstal dan Mengkonfigurasi Laravel Sanctum untuk API Authentication

## Definisi & Target
Menginstal dan mengkonfigurasi Laravel Sanctum sebagai solusi authentication API yang ringan. Sanctum mendukung token-based authentication (personal access tokens) dan SPA authentication (cookie-based session). Targetnya adalah sistem auth yang aman dan siap production.

## Komponen yang Terlibat
- Laravel Sanctum package
- HasApiTokens trait
- Sanctum config dan migration
- SPA authentication configuration
- CORS dan session configuration
- Middleware group

## Perintah Artisan CLI
```bash
# Install Sanctum
composer require laravel/sanctum

# Publish config dan migration
php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider"

# Jalankan migration
php artisan migrate

# Optional: install API scaffolding
php artisan install:api
```

### Model - User with HasApiTokens
```php
<?php
namespace App\Models;

use Illuminate\Foundation\Auth\User as Authenticatable;
use Illuminate\Notifications\Notifiable;
use Laravel\Sanctum\HasApiTokens;

class User extends Authenticatable
{
    use HasApiTokens, Notifiable;

    protected $fillable = [
        'name',
        'email',
        'password',
    ];

    protected $hidden = [
        'password',
        'remember_token',
    ];

    protected $casts = [
        'email_verified_at' => 'datetime',
        'password' => 'hashed',
    ];
}
```

### Controller - AuthController (Sanctum Setup)
```php
<?php
namespace App\Http\Controllers\Api\V1;

use App\Http\Controllers\Controller;
use App\Models\User;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Hash;
use Illuminate\Validation\ValidationException;

class AuthController extends Controller
{
    public function register(Request $request)
    {
        $validated = $request->validate([
            'name' => 'required|string|max:255',
            'email' => 'required|string|email|max:255|unique:users',
            'password' => 'required|string|min:8|confirmed',
        ]);

        $user = User::create([
            'name' => $validated['name'],
            'email' => $validated['email'],
            'password' => Hash::make($validated['password']),
        ]);

        $token = $user->createToken('auth-token')->plainTextToken;

        return response()->json([
            'user' => $user,
            'token' => $token,
            'token_type' => 'Bearer',
        ], 201);
    }

    public function login(Request $request)
    {
        $request->validate([
            'email' => 'required|email',
            'password' => 'required',
        ]);

        $user = User::where('email', $request->email)->first();

        if (!$user || !Hash::check($request->password, $user->password)) {
            throw ValidationException::withMessages([
                'email' => ['Kredensial yang diberikan tidak valid.'],
            ]);
        }

        $token = $user->createToken('auth-token', ['basic'])->plainTextToken;

        return response()->json([
            'user' => $user,
            'token' => $token,
            'token_type' => 'Bearer',
        ]);
    }

    public function logout(Request $request)
    {
        $request->user()->currentAccessToken()->delete();

        return response()->json(['message' => 'Berhasil logout.']);
    }

    public function logoutAll(Request $request)
    {
        $request->user()->tokens()->delete();

        return response()->json(['message' => 'Semua session berakhir.']);
    }
}
```

### Route - api/v1/auth
```php
<?php
use App\Http\Controllers\Api\V1\AuthController;

Route::post('/auth/register', [AuthController::class, 'register']);
Route::post('/auth/login', [AuthController::class, 'login']);

Route::middleware('auth:sanctum')->group(function () {
    Route::post('/auth/logout', [AuthController::class, 'logout']);
    Route::post('/auth/logout-all', [AuthController::class, 'logoutAll']);
});
```

## Cara Integrasi & Pengujian
1. Install Sanctum dan jalankan migration
2. Tambahkan HasApiTokens ke User model
3. Konfigurasi middleware di bootstrap/app.php
4. Set SANCTUM_STATEFUL_DOMAINS di .env
5. Test register: POST /api/v1/auth/register
6. Test login: POST /api/v1/auth/login
7. Gunakan token dari response untuk akses endpoint terproteksi
8. Test logout: POST /api/v1/auth/logout (dengan Bearer token)
9. Test expired token setelah expiration time
10. Verifikasi personal_access_tokens table di database
