# 398. Mendokumentasikan API Menggunakan Scribe Laravel untuk Dokumentasi Otomatis

## Definisi & Target
Menginstal dan mengkonfigurasi Scribe Laravel untuk menghasilkan dokumentasi API yang interaktif dan informatif secara otomatis dari kode. Dokumentasi mencakup semua endpoint, parameter, request/response examples, dan authentication. Targetnya adalah dokumentasi yang selalu up-to-date dengan kode.

## Komponen yang Terlibat
- Scribe package (knuckleswtf/scribe)
- PHPDoc annotations di controller
- @group, @subgroup, @queryParam
- API Resource responses
- Postman collection export
- OpenAPI/Swagger spec
- Custom strategies

## Perintah Artisan CLI
```bash
# Install Scribe
composer require knuckleswtf/scribe --dev

# Publish config
php artisan vendor:publish --tag=scribe-config

# Generate documentation
php artisan scribe:generate

# Generate dengan endpoint dari berbagai versi
php artisan scribe:generate --no-interaction
```

### Controller - Annotated Auth Controller
```php
<?php
namespace App\Http\Controllers\Api\V1;

use App\Http\Controllers\Controller;
use App\Models\User;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Hash;
use Illuminate\Validation\ValidationException;

/**
 * @group Authentication
 *
 * API endpoints untuk mengelola autentikasi pengguna.
 * Mencakup registrasi, login, logout, dan manajemen token.
 */
class AuthController extends Controller
{
    /**
     * Register User Baru
     *
     * Mendaftarkan user baru ke dalam sistem dan mengembalikan token akses.
     *
     * @bodyParam name string required Nama lengkap pengguna. Example: John Doe
     * @bodyParam email string required Alamat email pengguna. Example: john@example.com
     * @bodyParam password string required Password minimal 8 karakter. Example: secret123
     * @bodyParam password_confirmation string required Konfirmasi password. Example: secret123
     *
     * @response 201 {
     *   "user": {
     *     "id": 1,
     *     "name": "John Doe",
     *     "email": "john@example.com"
     *   },
     *   "token": "1|abc123def456",
     *   "token_type": "Bearer"
     * }
     * @response 422 {
     *   "message": "Validasi gagal.",
     *   "errors": {
     *     "email": ["Email sudah terdaftar."]
     *   }
     * }
     */
    public function register(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'name' => 'required|string|max:255',
            'email' => 'required|string|email|max:255|unique:users',
            'password' => 'required|string|min:8|confirmed',
        ]);

        $user = User::create([
            'name' => $validated['name'],
            'email' => $validated['email'],
            'password' => Hash::make($validated['password']),
        ]);

        $token = $user->createToken('auth-token')->plainTextToken;

        return response()->json([
            'user' => $user,
            'token' => $token,
            'token_type' => 'Bearer',
        ], 201);
    }

    /**
     * Login User
     *
     * Melakukan autentikasi user dan mengembalikan token akses.
     *
     * @bodyParam email string required Alamat email terdaftar. Example: john@example.com
     * @bodyParam password string required Password user. Example: secret123
     *
     * @response {
     *   "user": {
     *     "id": 1,
     *     "name": "John Doe",
     *     "email": "john@example.com"
     *   },
     *   "token": "1|abc123def456",
     *   "token_type": "Bearer"
     * }
     * @response 422 {
     *   "message": "Kredensial yang diberikan tidak valid.",
     *   "errors": {
     *     "email": ["Kredensial yang diberikan tidak valid."]
     *   }
     * }
     */
    public function login(Request $request): JsonResponse
    {
        $request->validate([
            'email' => 'required|email',
            'password' => 'required',
        ]);

        $user = User::where('email', $request->email)->first();

        if (!$user || !Hash::check($request->password, $user->password)) {
            throw ValidationException::withMessages([
                'email' => ['Kredensial yang diberikan tidak valid.'],
            ]);
        }

        $token = $user->createToken('auth-token', ['basic'])->plainTextToken;

        return response()->json([
            'user' => $user,
            'token' => $token,
            'token_type' => 'Bearer',
        ]);
    }

    /**
     * Logout User
     *
     * Menghapus token akses saat ini.
     *
     * @authenticated
     *
     * @response {
     *   "message": "Berhasil logout."
     * }
     * @response 401 {
     *   "message": "Unauthenticated."
     * }
     */
    public function logout(Request $request): JsonResponse
    {
        $request->user()->currentAccessToken()->delete();

        return response()->json(['message' => 'Berhasil logout.']);
    }
}
```

### Controller - Annotated Product Controller
```php
<?php
namespace App\Http\Controllers\Api\V2;

use App\Http\Controllers\Controller;
use App\Http\Resources\V2\ProductResource;
use App\Models\Product;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Spatie\QueryBuilder\AllowedFilter;
use Spatie\QueryBuilder\QueryBuilder;

/**
 * @group Products
 *
 * Manajemen produk dalam katalog.
 * Endpoint ini tersedia di API v2 dengan fitur lebih lengkap.
 *
 * @subgroup CRUD Produk
 */
class ProductController extends Controller
{
    /**
     * Daftar Produk
     *
     * Mengambil daftar produk dengan dukungan filtering, sorting, dan pagination.
     *
     * @queryParam filter[name] Filter berdasarkan nama produk. Example: sepatu
     * @queryParam filter[category_id] Filter berdasarkan kategori. Example: 5
     * @queryParam filter[price_between] Filter range harga (min,max). Example: 10000,50000
     * @queryParam filter[in_stock] Filter produk yang tersedia. Example: true
     * @queryParam sort Kolom sorting (name, price, created_at). Default: created_at. Example: price
     * @queryParam order Arah sorting (asc, desc). Default: desc. Example: asc
     * @queryParam per_page Jumlah item per halaman. Max: 100. Example: 15
     * @queryParam include Relasi yang di-load (category,variants). Example: category
     * @queryParam fields Field yang dikembalikan (id,name,price). Example: id,name,price
     *
     * @authenticated
     *
     * @response {
     *   "data": [
     *     {
     *       "id": 1,
     *       "name": "Sepatu Sport",
     *       "price": { "value": 150000, "currency": "IDR", "formatted": "Rp 150.000" },
     *       "category": { "id": 5, "name": "Sepatu" },
     *       "in_stock": true,
     *       "created_at": "2025-01-01T00:00:00.000000Z"
     *     }
     *   ],
     *   "meta": { "current_page": 1, "per_page": 15, "total": 50 },
     *   "links": { "first": "...", "last": "...", "prev": null, "next": "..." }
     * }
     */
    public function index(Request $request): JsonResponse
    {
        $products = QueryBuilder::for(Product::class)
            ->with(['category', 'variants'])
            ->allowedFilters([
                AllowedFilter::partial('name'),
                AllowedFilter::exact('category_id'),
                AllowedFilter::scope('price_between'),
                AllowedFilter::scope('in_stock'),
            ])
            ->allowedSorts(['name', 'price', 'created_at'])
            ->cursorPaginate($request->input('per_page', 15));

        return response()->json([
            'data' => ProductResource::collection($products),
            'meta' => [
                'per_page' => $products->perPage(),
                'has_more' => $products->hasMorePages(),
            ],
            'links' => [
                'next' => $products->nextCursor()?->encode(),
                'prev' => $products->previousCursor()?->encode(),
            ],
        ]);
    }

    /**
     * Detail Produk
     *
     * Mengambil detail produk lengkap dengan relasi.
     *
     * @urlParam product integer required ID produk. Example: 1
     *
     * @authenticated
     *
     * @response {
     *   "data": {
     *     "id": 1,
     *     "name": "Sepatu Sport",
     *     "slug": "sepatu-sport",
     *     "description": "Sepatu olahraga berkualitas tinggi.",
     *     "price": {
     *       "regular": 150000,
     *       "currency": "IDR",
     *       "formatted": "Rp 150.000"
     *     },
     *     "category": { "id": 5, "name": "Sepatu" },
     *     "variants": [
     *       { "id": 1, "name": "Ukuran 42", "price": 150000 }
     *     ],
     *     "in_stock": true,
     *     "rating": { "average": 4.5, "count": 12 },
     *     "created_at": "2025-01-01T00:00:00.000000Z"
     *   }
     * }
     * @response 404 {
     *   "message": "Resource tidak ditemukan."
     * }
     */
    public function show(Product $product): JsonResponse
    {
        $product->load(['category', 'variants', 'reviews']);

        return response()->json([
            'data' => new ProductResource($product),
        ]);
    }

    /**
     * Buat Produk Baru
     *
     * Menambahkan produk baru ke dalam katalog.
     *
     * @bodyParam name string required Nama produk. Example: Sepatu Sport
     * @bodyParam price numeric required Harga produk. Example: 150000
     * @bodyParam description string Deskripsi produk. Example: Sepatu olahraga berkualitas.
     * @bodyParam category_id int ID kategori. Example: 5
     * @bodyParam sku string SKU unik produk. Example: SP-001
     * @bodyParam variants array Variasi produk (ukuran, warna).
     * @bodyParam variants.*.name string required Nama variasi. Example: Ukuran 42
     * @bodyParam variants.*.price numeric required Harga variasi. Example: 150000
     *
     * @authenticated
     *
     * @response 201 {
     *   "data": {
     *     "id": 2,
     *     "name": "Sepatu Sport",
     *     "price": { "value": 150000, "currency": "IDR" }
     *   }
     * }
     */
    public function store(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'name' => 'required|string|max:255',
            'price' => 'required|numeric|min:0',
            'description' => 'nullable|string',
            'category_id' => 'nullable|exists:categories,id',
            'sku' => 'nullable|string|unique:products,sku',
            'variants' => 'nullable|array',
            'variants.*.name' => 'required|string',
            'variants.*.price' => 'required|numeric',
        ]);

        $product = Product::create($validated);

        if ($request->variants) {
            $product->variants()->createMany($request->variants);
        }

        return response()->json([
            'data' => new ProductResource($product->load('variants')),
        ], 201);
    }
}
```

### Strategy - Custom Response Strategy
```php
<?php
namespace App\Documentation\Strategies;

use Knuckles\Scribe\Extracting\ParamHelpers;
use Knuckles\Scribe\Extracting\Strategies\Strategy;
use ReflectionFunctionAbstract;

class AddCustomHeaders extends Strategy
{
    use ParamHelpers;

    public function __invoke(
        \Knuckles\Scribe\Tools\DocumentationConfig $config,
        \Knuckles\Scribe\Extracting\RouteDocBlocker $routeDocBlocker,
        \ReflectionClass $controller,
        ReflectionFunctionAbstract $method,
        array $routeRules,
        array $alreadyGeneratedData = []
    ): ?array
    {
        return [
            'X-API-Version' => [
                'description' => 'Versi API yang digunakan.',
                'required' => false,
                'example' => 'v2',
            ],
            'X-Request-ID' => [
                'description' => 'ID unik untuk tracing request.',
                'required' => false,
                'example' => 'req_abc123',
            ],
        ];
    }
}
```

## Cara Integrasi & Pengujian
1. Install Scribe via composer
2. Publish config dan sesuaikan dengan project
3. Tambahkan PHPDoc annotations ke semua controller
4. Jalankan php artisan scribe:generate
5. Buka public/docs/index.html di browser
6. Verifikasi semua endpoint terdaftar dengan benar
7. Test Try It Out! functionality
8. Cek request/response examples
9. Verifikasi authentication section
10. Export Postman collection
11. Tambahkan Scribe generation ke CI/CD pipeline
12. Update dokumentasi setiap kali ada perubahan API
