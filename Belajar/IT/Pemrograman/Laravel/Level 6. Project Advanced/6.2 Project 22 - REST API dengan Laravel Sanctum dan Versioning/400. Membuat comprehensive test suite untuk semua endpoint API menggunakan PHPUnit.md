# 400. Membuat Comprehensive Test Suite untuk Semua Endpoint API Menggunakan PHPUnit

## Definisi & Target
Membuat test suite yang komprehensif untuk semua endpoint API mencakup: authentication, CRUD operations, validation, filtering, sorting, pagination, rate limiting, dan authorization. Targetnya adalah coverage > 90% untuk semua endpoint API.

## Komponen yang Terlibat
- PHPUnit test cases
- Feature tests vs Unit tests
- Test factories
- Database refresh / transactions
- HTTP test helpers (getJson, postJson, etc.)
- Assertions untuk JSON structure
- Test data providers

## Kode Implementasi (Per File)

### Base Test Case - ApiTestCase
```php
<?php
namespace Tests;

use App\Models\User;
use Illuminate\Foundation\Testing\RefreshDatabase;
use Illuminate\Foundation\Testing\TestCase as BaseTestCase;
use Illuminate\Foundation\Testing\WithFaker;
use Laravel\Sanctum\Sanctum;

abstract class ApiTestCase extends BaseTestCase
{
    use CreatesApplication, RefreshDatabase, WithFaker;

    protected User $user;
    protected string $token;
    protected array $authHeaders;

    protected function setUp(): void
    {
        parent::setUp();

        $this->seed();

        $this->user = User::factory()->create([
            'email' => 'test@example.com',
            'password' => bcrypt('password'),
        ]);

        $this->token = $this->user->createToken('test-token', ['*'])->plainTextToken;

        $this->authHeaders = [
            'Authorization' => "Bearer {$this->token}",
            'Accept' => 'application/json',
        ];
    }

    protected function jsonGet(string $uri, array $headers = []): \Illuminate\Testing\TestResponse
    {
        return $this->getJson($uri, array_merge($this->authHeaders, $headers));
    }

    protected function jsonPost(string $uri, array $data = [], array $headers = []): \Illuminate\Testing\TestResponse
    {
        return $this->postJson($uri, $data, array_merge($this->authHeaders, $headers));
    }

    protected function jsonPut(string $uri, array $data = [], array $headers = []): \Illuminate\Testing\TestResponse
    {
        return $this->putJson($uri, $data, array_merge($this->authHeaders, $headers));
    }

    protected function jsonDelete(string $uri, array $headers = []): \Illuminate\Testing\TestResponse
    {
        return $this->deleteJson($uri, array_merge($this->authHeaders, $headers));
    }

    protected function assertJsonStructure(array $structure): array
    {
        return $structure;
    }
}
```

### Test - Authentication Tests
```php
<?php
namespace Tests\Feature\Api\V1;

use App\Models\User;
use Tests\ApiTestCase;

class AuthTest extends ApiTestCase
{
    public function test_user_can_register()
    {
        $response = $this->postJson('/api/v1/auth/register', [
            'name' => 'New User',
            'email' => 'new@example.com',
            'password' => 'password123',
            'password_confirmation' => 'password123',
        ]);

        $response->assertStatus(201)
            ->assertJsonStructure([
                'user' => ['id', 'name', 'email'],
                'token',
                'token_type',
            ]);

        $this->assertDatabaseHas('users', [
            'email' => 'new@example.com',
        ]);
    }

    public function test_user_cannot_register_with_existing_email()
    {
        $response = $this->postJson('/api/v1/auth/register', [
            'name' => 'Test',
            'email' => 'test@example.com',
            'password' => 'password123',
            'password_confirmation' => 'password123',
        ]);

        $response->assertStatus(422)
            ->assertJsonValidationErrors(['email']);
    }

    public function test_user_can_login()
    {
        $response = $this->postJson('/api/v1/auth/login', [
            'email' => 'test@example.com',
            'password' => 'password',
        ]);

        $response->assertOk()
            ->assertJsonStructure([
                'user',
                'token',
                'token_type',
            ]);
    }

    public function test_user_cannot_login_with_invalid_credentials()
    {
        $response = $this->postJson('/api/v1/auth/login', [
            'email' => 'test@example.com',
            'password' => 'wrong_password',
        ]);

        $response->assertStatus(422);
    }

    public function test_user_can_logout()
    {
        $response = $this->withHeaders([
            'Authorization' => "Bearer {$this->token}",
        ])->postJson('/api/v1/auth/logout');

        $response->assertOk()
            ->assertJson(['message' => 'Berhasil logout.']);
    }

    public function test_unauthenticated_user_cannot_access_protected_routes()
    {
        $response = $this->getJson('/api/v1/user');

        $response->assertStatus(401);
    }

    public function test_register_requires_password_confirmation()
    {
        $response = $this->postJson('/api/v1/auth/register', [
            'name' => 'Test',
            'email' => 'test2@example.com',
            'password' => 'password123',
        ]);

        $response->assertStatus(422)
            ->assertJsonValidationErrors(['password']);
    }

    /** @dataProvider invalidRegistrationData */
    public function test_register_validation($data, $errorField)
    {
        $response = $this->postJson('/api/v1/auth/register', $data);

        $response->assertStatus(422)
            ->assertJsonValidationErrors([$errorField]);
    }

    public static function invalidRegistrationData(): array
    {
        return [
            'missing name' => [
                ['email' => 'test@test.com', 'password' => 'pass12345', 'password_confirmation' => 'pass12345'],
                'name',
            ],
            'invalid email' => [
                ['name' => 'Test', 'email' => 'invalid', 'password' => 'pass12345', 'password_confirmation' => 'pass12345'],
                'email',
            ],
            'short password' => [
                ['name' => 'Test', 'email' => 'test@test.com', 'password' => '123', 'password_confirmation' => '123'],
                'password',
            ],
        ];
    }
}
```

### Test - CRUD Product Tests
```php
<?php
namespace Tests\Feature\Api\V1;

use App\Models\Category;
use App\Models\Product;
use Tests\ApiTestCase;

class ProductTest extends ApiTestCase
{
    public function test_can_list_products()
    {
        Product::factory()->count(5)->create();

        $response = $this->jsonGet('/api/v1/products');

        $response->assertOk()
            ->assertJsonStructure([
                'data' => [
                    '*' => ['id', 'name', 'price', 'created_at'],
                ],
                'meta' => ['current_page', 'per_page', 'total'],
            ]);
    }

    public function test_can_create_product()
    {
        $category = Category::factory()->create();

        $response = $this->jsonPost('/api/v1/products', [
            'name' => 'Test Product',
            'price' => 50000,
            'description' => 'Test description',
            'category_id' => $category->id,
        ]);

        $response->assertStatus(201)
            ->assertJsonStructure([
                'data' => ['id', 'name', 'price', 'category'],
            ]);

        $this->assertDatabaseHas('products', [
            'name' => 'Test Product',
            'price' => 50000,
        ]);
    }

    public function test_can_show_product()
    {
        $product = Product::factory()->create();

        $response = $this->jsonGet("/api/v1/products/{$product->id}");

        $response->assertOk()
            ->assertJsonFragment([
                'id' => $product->id,
                'name' => $product->name,
            ]);
    }

    public function test_returns_404_for_nonexistent_product()
    {
        $response = $this->jsonGet('/api/v1/products/99999');

        $response->assertNotFound();
    }

    public function test_can_update_product()
    {
        $product = Product::factory()->create();

        $response = $this->jsonPut("/api/v1/products/{$product->id}", [
            'name' => 'Updated Name',
            'price' => 75000,
        ]);

        $response->assertOk();

        $this->assertDatabaseHas('products', [
            'id' => $product->id,
            'name' => 'Updated Name',
            'price' => 75000,
        ]);
    }

    public function test_can_delete_product()
    {
        $product = Product::factory()->create();

        $response = $this->jsonDelete("/api/v1/products/{$product->id}");

        $response->assertOk()
            ->assertJson(['message' => 'Product deleted.']);

        $this->assertDatabaseMissing('products', ['id' => $product->id]);
    }

    public function test_create_product_validation()
    {
        $response = $this->jsonPost('/api/v1/products', [
            'name' => '',
            'price' => 'not_a_number',
        ]);

        $response->assertStatus(422)
            ->assertJsonValidationErrors(['name', 'price']);
    }
}
```

### Test - Filtering and Sorting Tests
```php
<?php
namespace Tests\Feature\Api\V2;

use App\Models\Category;
use App\Models\Product;
use Tests\ApiTestCase;

class ProductFilteringTest extends ApiTestCase
{
    public function test_can_filter_by_category()
    {
        $category = Category::factory()->create();
        Product::factory()->count(3)->create(['category_id' => $category->id]);
        Product::factory()->count(2)->create();

        $response = $this->jsonGet("/api/v2/products?filter[category_id]={$category->id}");

        $response->assertOk();
        $this->assertCount(3, $response->json('data'));
    }

    public function test_can_filter_by_price_range()
    {
        Product::factory()->create(['price' => 10000]);
        Product::factory()->create(['price' => 50000]);
        Product::factory()->create(['price' => 100000]);

        $response = $this->jsonGet('/api/v2/products?filter[price_between]=20000,75000');

        $response->assertOk();
        $this->assertCount(1, $response->json('data'));
    }

    public function test_can_sort_by_price_ascending()
    {
        Product::factory()->create(['price' => 50000]);
        Product::factory()->create(['price' => 10000]);
        Product::factory()->create(['price' => 25000]);

        $response = $this->jsonGet('/api/v2/products?sort=price&order=asc');

        $response->assertOk();
        $prices = collect($response->json('data'))->pluck('price.value');
        $this->assertEquals($prices->sort()->values()->toArray(), $prices->toArray());
    }

    public function test_can_select_specific_fields()
    {
        Product::factory()->create([
            'name' => 'Test Product',
            'price' => 50000,
            'description' => 'Full description',
        ]);

        $response = $this->jsonGet('/api/v2/products?fields=name,price');

        $response->assertOk();
        $product = $response->json('data')[0];
        $this->assertArrayHasKey('name', $product);
        $this->assertArrayHasKey('price', $product);
        $this->assertArrayNotHasKey('description', $product);
    }

    public function test_can_include_relations()
    {
        $category = Category::factory()->create();
        Product::factory()->create(['category_id' => $category->id]);

        $response = $this->jsonGet('/api/v2/products?include=category');

        $response->assertOk();
        $this->assertArrayHasKey('category', $response->json('data')[0]);
    }

    public function test_invalid_sort_falls_back_to_default()
    {
        Product::factory()->count(3)->create();

        $response = $this->jsonGet('/api/v2/products?sort=invalid_field');

        $response->assertOk();
    }
}
```

### Test - Rate Limiting Tests
```php
<?php
namespace Tests\Feature;

use App\Models\User;
use Tests\ApiTestCase;

class RateLimitTest extends ApiTestCase
{
    public function test_rate_limit_blocks_excessive_requests()
    {
        $headers = ['Authorization' => "Bearer {$this->token}"];

        for ($i = 0; $i < 60; $i++) {
            $this->getJson('/api/v1/user', $headers);
        }

        $response = $this->getJson('/api/v1/user', $headers);

        $response->assertStatus(429);
        $response->assertJsonStructure(['message']);
    }

    public function test_rate_limit_headers_are_present()
    {
        $response = $this->getJson('/api/v1/user', [
            'Authorization' => "Bearer {$this->token}",
        ]);

        $response->assertHeader('X-RateLimit-Limit');
        $response->assertHeader('X-RateLimit-Remaining');
    }

    public function test_different_users_have_separate_limits()
    {
        $user2 = User::factory()->create();
        $token2 = $user2->createToken('test')->plainTextToken;

        for ($i = 0; $i < 60; $i++) {
            $this->getJson('/api/v1/user', [
                'Authorization' => "Bearer {$this->token}",
            ]);
        }

        $response = $this->getJson('/api/v1/user', [
            'Authorization' => "Bearer {$token2}",
        ]);

        $response->assertOk();
    }
}
```

### Test - Pagination Test
```php
<?php
namespace Tests\Feature;

use App\Models\Product;
use Tests\ApiTestCase;

class PaginationTest extends ApiTestCase
{
    public function test_cursor_pagination_returns_meta()
    {
        Product::factory()->count(30)->create();

        $response = $this->jsonGet('/api/v2/products?per_page=10');

        $response->assertOk()
            ->assertJsonStructure([
                'data',
                'meta' => ['per_page', 'has_more'],
                'links' => ['next', 'prev'],
            ]);

        $this->assertNotNull($response->json('links.next'));
    }

    public function test_cursor_pagination_does_not_overlap()
    {
        Product::factory()->count(25)->create();

        $page1 = $this->jsonGet('/api/v2/products?per_page=10');
        $page1Ids = collect($page1->json('data'))->pluck('id');

        $nextCursor = $page1->json('links.next');
        $page2 = $this->jsonGet("/api/v2/products?per_page=10&cursor={$nextCursor}");
        $page2Ids = collect($page2->json('data'))->pluck('id');

        $this->assertEmpty($page1Ids->intersect($page2Ids));
    }

    public function test_last_page_has_no_next_cursor()
    {
        Product::factory()->count(5)->create();

        $response = $this->jsonGet('/api/v2/products?per_page=10');

        $this->assertNull($response->json('links.next'));
        $this->assertFalse($response->json('meta.has_more'));
    }
}
```

### Running Tests
```bash
# Run all tests
php artisan test

# Run specific test suite
php artisan test --testsuite="API V1"

# Run specific test file
php artisan test tests/Feature/Api/V1/AuthTest.php

# Run with coverage
php artisan test --coverage

# Run with parallel (needs ParaTest)
php artisan test --parallel

# Run failed tests first
php artisan test --recreate-databases

# CI mode
php artisan test --log-junit test-results.xml --coverage-clover coverage.xml
```

## Cara Integrasi & Pengujian
1. Buat test untuk setiap endpoint: success, validation, authorization
2. Gunakan data providers untuk multiple test scenarios
3. Test pagination consistency (no data overlap)
4. Test rate limiting dengan looping requests
5. Test V1 dan V2 responses berbeda
6. Test error responses (404, 422, 401, 403, 429)
7. Test filtering combinations
8. Gunakan --parallel untuk mempercepat eksekusi
9. Integrasikan dengan CI/CD (GitHub Actions)
10. Maintain coverage > 90% untuk kode API
