# 390. Mengimplementasikan SPA Authentication Menggunakan Sanctum Cookie-Based Session

## Definisi & Target
Implementasi SPA authentication menggunakan cookie-based session dari Sanctum. SPA (Single Page Application) seperti Vue.js atau React akan menggunakan cookie session yang aman (httpOnly, SameSite) tanpa perlu mengelola token secara manual.

## Komponen yang Terjadi
- SPA stateful domains configuration
- CSRF protection via /sanctum/csrf-cookie
- Cookie-based session authentication
- Axios interceptor setup
- Login/logout flow
- Guest middleware untuk SPA

## Perintah Artisan CLI
```bash
# Sudah include di Sanctum, tidak perlu install tambahan
# Pastikan session cookie terkonfigurasi
php artisan make:controller Api/V1/SpaController
```

### Controller - SPA Auth Controller
```php
<?php
namespace App\Http\Controllers\Api\V1;

use App\Http\Controllers\Controller;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Hash;
use Illuminate\Validation\ValidationException;
use App\Models\User;

class SpaAuthController extends Controller
{
    public function login(Request $request)
    {
        $request->validate([
            'email' => 'required|email',
            'password' => 'required',
        ]);

        $user = User::where('email', $request->email)->first();

        if (!$user || !Hash::check($request->password, $user->password)) {
            throw ValidationException::withMessages([
                'email' => ['Kredensial yang diberikan tidak valid.'],
            ]);
        }

        $request->session()->regenerate();

        return response()->json([
            'user' => $user,
            'message' => 'Login berhasil.',
        ]);
    }

    public function logout(Request $request)
    {
        $request->user()->currentAccessToken()?->delete();

        auth('web')->logout();

        $request->session()->invalidate();
        $request->session()->regenerateToken();

        return response()->json(['message' => 'Logout berhasil.']);
    }

    public function user(Request $request)
    {
        return response()->json([
            'data' => $request->user(),
        ]);
    }

    public function register(Request $request)
    {
        $validated = $request->validate([
            'name' => 'required|string|max:255',
            'email' => 'required|string|email|max:255|unique:users',
            'password' => 'required|string|min:8|confirmed',
        ]);

        $user = User::create([
            'name' => $validated['name'],
            'email' => $validated['email'],
            'password' => Hash::make($validated['password']),
        ]);

        auth('web')->login($user);

        $request->session()->regenerate();

        return response()->json([
            'user' => $user,
            'message' => 'Registrasi berhasil.',
        ], 201);
    }
}
```

### Middleware - EnsureEmailIsVerified (for SPA)
```php
<?php
namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;

class EnsureEmailIsVerified
{
    public function handle(Request $request, Closure $next)
    {
        if ($request->user() && !$request->user()->hasVerifiedEmail()) {
            return response()->json([
                'message' => 'Email belum diverifikasi.',
                'verification_url' => url('/api/v1/email/resend'),
            ], 409);
        }

        return $next($request);
    }
}
```

### Frontend Example - Axios Configuration (Vue.js / React)
```javascript
// api/axios.js
import axios from 'axios';

const api = axios.create({
    baseURL: 'http://localhost:8000/api/v1',
    withCredentials: true,
    headers: {
        'Accept': 'application/json',
        'Content-Type': 'application/json',
    },
});

api.interceptors.response.use(
    (response) => response,
    async (error) => {
        if (error.response?.status === 401) {
            window.location.href = '/login';
        }
        return Promise.reject(error);
    }
);

export default api;
```

### Frontend Example - Auth Service
```javascript
// services/authService.js
import api from '../api/axios';

export const authService = {
    async login(email, password) {
        await api.get('/sanctum/csrf-cookie');
        return api.post('/spa/login', { email, password });
    },

    async register(data) {
        await api.get('/sanctum/csrf-cookie');
        return api.post('/spa/register', data);
    },

    async logout() {
        return api.post('/spa/logout');
    },

    async getUser() {
        return api.get('/spa/user');
    },
};
```

### Frontend Example - Login Component (Vue 3)
```vue
<template>
    <form @submit.prevent="handleLogin">
        <input v-model="email" type="email" placeholder="Email" required />
        <input v-model="password" type="password" placeholder="Password" required />
        <button type="submit" :disabled="loading">Login</button>
        <p v-if="error" class="error">{{ error }}</p>
    </form>
</template>

<script setup>
import { ref } from 'vue';
import { authService } from '../services/authService';

const email = ref('');
const password = ref('');
const loading = ref(false);
const error = ref(null);

const handleLogin = async () => {
    loading.value = true;
    error.value = null;
    try {
        const response = await authService.login(email.value, password.value);
        localStorage.setItem('user', JSON.stringify(response.data.user));
        window.location.href = '/dashboard';
    } catch (err) {
        error.value = err.response?.data?.message || 'Login gagal';
    } finally {
        loading.value = false;
    }
};
</script>
```

## Cara Integrasi & Pengujian
1. Update .env dengan SESSION_DRIVER=cookie dan SANCTUM_STATEFUL_DOMAINS
2. Pastikan CORS supports_credentials = true
3. Frontend: panggil GET /sanctum/csrf-cookie sebelum login
4. Login via SPA: POST /api/v1/spa/login
5. Verifikasi cookie laravel_session dan XSRF-TOKEN ter-set
6. Akses endpoint terproteksi tanpa token Bearer (via cookie)
7. Logout dan pastikan session terhapus
8. Test CSRF: kirim request tanpa cookie CSRF -> harus error
9. Test dari origin berbeda: pastikan CORS blocking bekerja
10. Verifikasi session tidak bisa diakses dari JavaScript (httpOnly)
