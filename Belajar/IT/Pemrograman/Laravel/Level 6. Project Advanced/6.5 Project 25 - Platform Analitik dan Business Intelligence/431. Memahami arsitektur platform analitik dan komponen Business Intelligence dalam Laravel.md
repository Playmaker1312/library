# 431. Memahami Arsitektur Platform Analitik dan Komponen Business Intelligence dalam Laravel

## Definisi & Target
Memahami konsep platform analitik dan Business Intelligence (BI) yang dibangun dengan Laravel. Meliputi arsitektur data pipeline, ETL, data warehouse, OLAP, visualisasi, dan dashboard. Targetnya adalah merancang platform analitik yang scalable.

## Komponen yang Terlibat
- Data Pipeline architecture
- ETL (Extract, Transform, Load)
- Data Warehouse design
- OLAP vs OLTP
- Data mart
- Data lake
- Metrics & KPIs
- Dashboard system
- Reporting engine
- Data governance

## Perintah Artisan CLI
```bash
# Buat project utama
composer create-project laravel/laravel analytics-platform

# Install packages untuk analytics
composer require maatwebsite/laravel-excel
composer require barryvdh/laravel-dompdf
composer require myclabs/php-enum

# Buat struktur
php artisan make:model Metric
php artisan make:model Dashboard
php artisan make:model Report
```


### ETL Pipeline Architecture
```php
<?php
namespace App\Services\Analytics;

class ETLPipelineOrchestrator
{
    private array $extractors = [];
    private array $transformers = [];
    private array $loaders = [];

    public function registerExtractor(string $name, callable $extractor): void
    {
        $this->extractors[$name] = $extractor;
    }

    public function registerTransformer(string $name, callable $transformer): void
    {
        $this->transformers[$name] = $transformer;
    }

    public function registerLoader(string $name, callable $loader): void
    {
        $this->loaders[$name] = $loader;
    }

    public function run(string $pipelineName, array $config = []): array
    {
        $results = [];

        foreach ($config['extract'] ?? [] as $extractorName) {
            $results['extracted'][$extractorName] = ($this->extractors[$extractorName])($config);
        }

        foreach ($config['transform'] ?? [] as $transformerName) {
            $results['transformed'][$transformerName] = ($this->transformers[$transformerName])($results['extracted'], $config);
        }

        foreach ($config['load'] ?? [] as $loaderName) {
            $results['loaded'][$loaderName] = ($this->loaders[$loaderName])($results['transformed'] ?? $results['extracted'], $config);
        }

        return $results;
    }
}
```

### Dashboard Builder Config
```php
<?php
namespace App\Models\Analytics;

use Illuminate\Database\Eloquent\Model;

class Dashboard extends Model
{
    protected $fillable = [
        'name', 'description', 'layout', 'widgets', 'filters',
        'is_public', 'refresh_interval', 'user_id', 'team_id',
    ];

    protected $casts = [
        'layout' => 'array',
        'widgets' => 'array',
        'filters' => 'array',
        'is_public' => 'boolean',
    ];

    public function widgets(): array
    {
        return array_map(function ($widget) {
            return Widget::find($widget['widget_id'])->toArray();
        }, $this->widgets ?? []);
    }
}

class Widget extends Model
{
    protected $fillable = [
        'name', 'type', 'config', 'query', 'cache_ttl', 'user_id',
    ];

    protected $casts = [
        'config' => 'array',
        'query' => 'array',
    ];

    public function execute(): mixed
    {
        $queryBuilder = app(MetricQueryBuilder::class);
        return $queryBuilder->execute($this->query);
    }
}
```
