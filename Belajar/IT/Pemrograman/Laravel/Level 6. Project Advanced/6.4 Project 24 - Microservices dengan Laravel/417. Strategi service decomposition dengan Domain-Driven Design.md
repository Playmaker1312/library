# 417. Strategi Service Decomposition dengan Domain-Driven Design

## Definisi & Target
Menerapkan Domain-Driven Design (DDD) untuk memecah aplikasi menjadi microservices yang terisolasi berdasarkan bounded context. Targetnya adalah menghasilkan service boundaries yang tepat sehingga setiap service fokus pada satu domain capability.

## Komponen yang Terlibat
- Domain-Driven Design
- Bounded Context
- Ubiquitous Language
- Entity, Value Object, Aggregate
- Domain Events
- Repository pattern
- Service pattern per domain
- Context mapping
- Event Storming

## Perintah Artisan CLI

### Value Object Example
```php
<?php
namespace App\Domain\Models\ValueObjects;

use InvalidArgumentException;

class Money
{
    public function __construct(
        private readonly int $amount,
        private readonly string $currency = 'IDR'
    ) {
        if ($amount < 0) {
            throw new InvalidArgumentException('Amount cannot be negative');
        }
        if (strlen($currency) !== 3) {
            throw new InvalidArgumentException('Currency must be 3-letter ISO code');
        }
    }

    public function getAmount(): int
    {
        return $this->amount;
    }

    public function getCurrency(): string
    {
        return $this->currency;
    }

    public function add(Money $other): Money
    {
        if ($this->currency !== $other->currency) {
            throw new InvalidArgumentException('Cannot add different currencies');
        }
        return new self($this->amount + $other->amount, $this->currency);
    }

    public function multiply(int $multiplier): Money
    {
        return new self($this->amount * $multiplier, $this->currency);
    }

    public function toFloat(): float
    {
        return $this->amount / 100;
    }

    public static function fromFloat(float $value, string $currency = 'IDR'): Money
    {
        return new self((int) round($value * 100), $currency);
    }
}
```

### Aggregate Root Example
```php
<?php
namespace App\Domain\Models\Aggregates;

use App\Domain\Models\Entities\Order;
use App\Domain\Models\ValueObjects\Money;
use App\Domain\Models\ValueObjects\OrderStatus;
use App\Domain\Events\OrderPlaced;
use App\Domain\Events\OrderShipped;
use App\Domain\Events\OrderCancelled;
use Illuminate\Support\Collection;

class OrderAggregate
{
    private Collection $recordedEvents;

    public function __construct(
        private Order $order
    ) {
        $this->recordedEvents = new Collection();
    }

    public function place(array $items, Money $total): void
    {
        $this->order->status = OrderStatus::PENDING;
        $this->order->total = $total;
        $this->order->items = $items;

        $this->recordedEvents->push(
            new OrderPlaced($this->order)
        );
    }

    public function ship(): void
    {
        if ($this->order->status !== OrderStatus::CONFIRMED) {
            throw new \DomainException('Only confirmed orders can be shipped');
        }

        $this->order->status = OrderStatus::SHIPPED;

        $this->recordedEvents->push(
            new OrderShipped($this->order)
        );
    }

    public function cancel(string $reason): void
    {
        if ($this->order->status === OrderStatus::SHIPPED) {
            throw new \DomainException('Cannot cancel shipped order');
        }

        $this->order->status = OrderStatus::CANCELLED;
        $this->order->cancellation_reason = $reason;

        $this->recordedEvents->push(
            new OrderCancelled($this->order)
        );
    }

    public function getRecordedEvents(): Collection
    {
        $events = $this->recordedEvents;
        $this->recordedEvents = new Collection();
        return $events;
    }

    public function getOrder(): Order
    {
        return $this->order;
    }
}
```

### Domain Service Example
```php
<?php
namespace App\Domain\Services;

use App\Domain\Models\Aggregates\OrderAggregate;
use App\Domain\Models\ValueObjects\Money;
use App\Domain\Models\ValueObjects\Address;
use App\Domain\Repositories\Contracts\OrderRepositoryInterface;
use App\Domain\Repositories\Contracts\ProductRepositoryInterface;
use App\Domain\Events\OrderPlaced;
use Illuminate\Support\Facades\Event;

class OrderDomainService
{
    public function __construct(
        private OrderRepositoryInterface $orderRepo,
        private ProductRepositoryInterface $productRepo
    ) {}

    public function placeOrder(array $cartItems, Address $shippingAddress): OrderAggregate
    {
        $total = Money::fromFloat(0);

        foreach ($cartItems as $item) {
            $product = $this->productRepo->findById($item['product_id']);

            if (!$product->isInStock($item['quantity'])) {
                throw new \DomainException("Product {$product->name} out of stock");
            }

            $total = $total->add(
                $product->getPrice()->multiply($item['quantity'])
            );
        }

        $order = new OrderAggregate(
            $this->orderRepo->create()
        );

        $order->place($cartItems, $total);

        foreach ($order->getRecordedEvents() as $event) {
            Event::dispatch($event);
        }

        $this->orderRepo->save($order->getOrder());

        return $order;
    }
}
```

## Cara Integrasi & Pengujian
1. Lakukan Event Storming untuk menemukan domain events
2. Identifikasi bounded contexts dari event storming
3. Definisikan ubiquitous language untuk setiap context
4. Buat aggregate roots untuk transactional boundaries
5. Implement value objects untuk immutability
6. Gunakan repository pattern untuk data access
7. Buat domain services untuk business logic
8. Implement domain events untuk komunikasi
9. Setup context mapping untuk hubungan antar context
10. Test domain logic secara unit test tanpa infrastructure
