# 421. Database per Service Pattern dengan Isolated Database Migrations

## Definisi & Target
Mengimplementasikan pattern database per service (database-per-service) di mana setiap microservices memiliki database sendiri yang terisolasi. Meliputi strategi migrasi terpisah, data sharing, eventual consistency, dan pola query antar service.

## Komponen yang Terlibat
- Multiple database connections
- Isolated migrations per service
- Database seeding per service
- Data ownership pattern
- CQRS (Command Query Responsibility Segregation)
- Event sourcing untuk data sharing
- Saga pattern untuk distributed transactions
- Database versioning

## Perintah Artisan CLI
```bash
# Setup multiple database connections
php artisan make:migration create_orders_table --path=database/migrations/order
php artisan make:migration create_products_table --path=database/migrations/product

# Run migrations for specific service
php artisan migrate --database=order_service
php artisan migrate --database=product_service

# Make seeder per database
php artisan make:seeder OrderDatabaseSeeder
php artisan make:seeder ProductDatabaseSeeder
```

### Data Ownership Repository Pattern
```php
<?php
namespace App\Repositories;

use App\Exceptions\DataOwnershipException;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Http;

abstract class BaseRepository
{
    protected string $connection;

    public function __construct()
    {
        $this->connection = config('database.default');
    }

    protected function db(): \Illuminate\Database\Connection
    {
        return DB::connection($this->connection);
    }

    protected function beginTransaction(): void
    {
        $this->db()->beginTransaction();
    }

    protected function commit(): void
    {
        $this->db()->commit();
    }

    protected function rollback(): void
    {
        $this->db()->rollBack();
    }
}

// Order Repository (own order data)
class OrderRepository extends BaseRepository
{
    public function __construct()
    {
        $this->connection = 'order_service';
    }

    public function find(int $id): ?object
    {
        $order = $this->db()->table('orders')->find($id);

        if ($order) {
            $order->items = $this->db()->table('order_items')
                ->where('order_id', $id)
                ->get();
        }

        return $order;
    }

    public function create(array $data): object
    {
        $this->beginTransaction();
        try {
            $id = $this->db()->table('orders')->insertGetId([
                'customer_id' => $data['customer_id'],
                'customer_name' => $data['customer_name'],
                'customer_email' => $data['customer_email'],
                'status' => 'pending',
                'total_amount' => $data['total_amount'],
                'currency' => $data['currency'],
                'shipping_address' => json_encode($data['shipping_address']),
                'billing_address' => json_encode($data['billing_address'] ?? $data['shipping_address']),
                'created_at' => now(),
                'updated_at' => now(),
            ]);

            foreach ($data['items'] as $item) {
                $this->db()->table('order_items')->insert([
                    'order_id' => $id,
                    'product_id' => $item['product_id'],
                    'product_name' => $item['product_name'],
                    'quantity' => $item['quantity'],
                    'unit_price' => $item['unit_price'],
                    'subtotal' => $item['quantity'] * $item['unit_price'],
                    'created_at' => now(),
                ]);
            }

            $this->commit();

            return $this->find($id);
        } catch (\Exception $e) {
            $this->rollback();
            throw $e;
        }
    }
}

// External Data Access via API (not direct DB)
class ExternalCustomerRepository
{
    public function getCustomer(int $customerId): array
    {
        $response = Http::get(env('USER_SERVICE_URL') . "/api/users/{$customerId}");

        if (!$response->successful()) {
            throw new DataOwnershipException("User service unavailable");
        }

        return $response->json();
    }
}
```

### Event Sourcing for Cross-Service Data
```php
<?php
namespace App\Services;

use Illuminate\Support\Facades\DB;

class EventSourcingService
{
    public function storeEvent(string $aggregateType, string $aggregateId, string $eventType, array $data): void
    {
        DB::connection('event_store')->table('domain_events')->insert([
            'aggregate_type' => $aggregateType,
            'aggregate_id' => $aggregateId,
            'event_type' => $eventType,
            'event_data' => json_encode($data),
            'created_at' => now(),
        ]);
    }

    public function getEvents(string $aggregateType, string $aggregateId): array
    {
        return DB::connection('event_store')->table('domain_events')
            ->where('aggregate_type', $aggregateType)
            ->where('aggregate_id', $aggregateId)
            ->orderBy('created_at')
            ->get()
            ->toArray();
    }

    public function replayEvents(string $aggregateType, string $aggregateId): array
    {
        $events = $this->getEvents($aggregateType, $aggregateId);
        $state = [];

        foreach ($events as $event) {
            $state = $this->applyEvent($state, $event);
        }

        return $state;
    }

    private function applyEvent(array $state, object $event): array
    {
        $handler = 'apply' . str_replace('_', '', ucwords($event->event_type, '_'));

        if (method_exists($this, $handler)) {
            return $this->$handler($state, json_decode($event->event_data, true));
        }

        return $state;
    }
}
```

### Saga Pattern for Distributed Transactions
```php
<?php
namespace App\Services;

use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\Log;

class SagaOrchestrator
{
    private array $steps = [];
    private array $compensationSteps = [];
    private array $executedSteps = [];

    public function addStep(string $name, callable $action, callable $compensation): void
    {
        $this->steps[] = ['name' => $name, 'action' => $action];
        $this->compensationSteps[$name] = $compensation;
    }

    public function execute(): bool
    {
        foreach ($this->steps as $step) {
            try {
                $result = call_user_func($step['action']);
                $this->executedSteps[] = $step['name'];
                Log::info("Saga step completed", ['step' => $step['name']]);
            } catch (\Exception $e) {
                Log::error("Saga step failed", [
                    'step' => $step['name'],
                    'error' => $e->getMessage(),
                ]);
                $this->compensate();
                return false;
            }
        }
        return true;
    }

    private function compensate(): void
    {
        foreach (array_reverse($this->executedSteps) as $stepName) {
            try {
                if (isset($this->compensationSteps[$stepName])) {
                    call_user_func($this->compensationSteps[$stepName]);
                    Log::info("Saga compensation executed", ['step' => $stepName]);
                }
            } catch (\Exception $e) {
                Log::critical("Saga compensation failed", [
                    'step' => $stepName,
                    'error' => $e->getMessage(),
                ]);
            }
        }
    }
}

// Usage example: Place Order Saga
class PlaceOrderSaga
{
    private SagaOrchestrator $saga;

    public function __construct()
    {
        $this->saga = new SagaOrchestrator();
    }

    public function run(array $orderData): bool
    {
        $this->saga->addStep(
            'reserve_inventory',
            function () use ($orderData) {
                return Http::post(env('PRODUCT_SERVICE_URL') . '/api/internal/reserve', [
                    'items' => $orderData['items'],
                ])->throw()->json();
            },
            function () use ($orderData) {
                Http::post(env('PRODUCT_SERVICE_URL') . '/api/internal/release', [
                    'items' => $orderData['items'],
                ]);
            }
        );

        $this->saga->addStep(
            'process_payment',
            function () use ($orderData) {
                return Http::post(env('PAYMENT_SERVICE_URL') . '/api/internal/charge', [
                    'customer_id' => $orderData['customer_id'],
                    'amount' => $orderData['total_amount'],
                    'currency' => $orderData['currency'],
                ])->throw()->json();
            },
            function () use ($orderData) {
                Http::post(env('PAYMENT_SERVICE_URL') . '/api/internal/refund', [
                    'transaction_id' => $orderData['transaction_id'],
                ]);
            }
        );

        $this->saga->addStep(
            'create_order',
            function () use ($orderData) {
                return Http::post(env('ORDER_SERVICE_URL') . '/api/internal/orders', $orderData)
                    ->throw()->json();
            },
            function () use ($orderData) {
                Http::delete(env('ORDER_SERVICE_URL') . '/api/internal/orders/' . $orderData['order_id']);
            }
        );

        return $this->saga->execute();
    }
}
```

### Read Model for CQRS
```php
<?php
namespace App\Models\ReadModels;

use Illuminate\Database\Eloquent\Model;

class OrderReadModel extends Model
{
    protected $connection = 'order_service';
    protected $table = 'order_summaries';

    protected $fillable = [
        'order_id',
        'customer_id',
        'customer_name',
        'total_amount',
        'status',
        'item_count',
        'created_at',
    ];

    // This read model is populated by events, not direct writes
    public static function refreshFromEvent(array $eventData): void
    {
        static::updateOrCreate(
            ['order_id' => $eventData['order_id']],
            [
                'customer_id' => $eventData['customer_id'],
                'customer_name' => $eventData['customer_name'],
                'total_amount' => $eventData['total_amount'],
                'status' => $eventData['status'],
                'item_count' => count($eventData['items'] ?? []),
                'created_at' => $eventData['created_at'],
            ]
        );
    }
}
```

### Data Consistency Checker
```php
<?php
namespace App\Console\Commands;

use Illuminate\Console\Command;
use Illuminate\Support\Facades\Http;

class CheckDataConsistency extends Command
{
    protected $signature = 'data:consistency-check';
    protected $description = 'Check data consistency across services';

    public function handle(): int
    {
        $checks = [
            'orders_vs_payments' => $this->checkOrdersVsPayments(),
            'inventory_vs_orders' => $this->checkInventoryVsOrders(),
            'users_vs_orders' => $this->checkUsersVsOrders(),
        ];

        foreach ($checks as $name => $result) {
            if ($result['consistent']) {
                $this->info("✓ {$name}: Consistent");
            } else {
                $this->warn("✗ {$name}: Inconsistent - {$result['details']}");
            }
        }

        return self::SUCCESS;
    }

    private function checkOrdersVsPayments(): array
    {
        $orders = Http::get(env('ORDER_SERVICE_URL') . '/api/internal/orders/pending-payment')->json();
        $payments = Http::get(env('PAYMENT_SERVICE_URL') . '/api/internal/payments/recent')->json();

        $orderIds = collect($orders['data'] ?? [])->pluck('id');
        $paymentOrderIds = collect($payments['data'] ?? [])->pluck('order_id');

        $missing = $orderIds->diff($paymentOrderIds);

        return [
            'consistent' => $missing->isEmpty(),
            'details' => $missing->isEmpty() ? 'All orders have payments' : "Orders without payments: {$missing->implode(',')}",
        ];
    }

    private function checkInventoryVsOrders(): array
    {
        return ['consistent' => true, 'details' => 'Not implemented'];
    }

    private function checkUsersVsOrders(): array
    {
        return ['consistent' => true, 'details' => 'Not implemented'];
    }
}
```

## Cara Integrasi & Pengujian
1. Setup multiple database connections di config/database.php
2. Buat migration files per service domain
3. Setup model dengan connection spesifik
4. Implement repository pattern untuk data ownership
5. Jangan pernah akses database service lain secara langsung
6. Gunakan API calls untuk data dari service lain
7. Implementasikan Saga pattern untuk distributed transactions
8. Setup event store untuk event sourcing (opsional)
9. Implement CQRS untuk read models yang dioptimasi
10. Buat data consistency checker
11. Test isolated migrations per service
12. Test distributed transaction rollback
13. Test eventual consistency delay
14. Monitor data drift antar service
