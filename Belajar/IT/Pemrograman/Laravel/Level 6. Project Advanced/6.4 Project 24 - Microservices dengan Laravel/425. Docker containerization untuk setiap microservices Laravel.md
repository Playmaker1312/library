# 425. Docker Containerization untuk Setiap Microservices Laravel

## Definisi & Target
Mengcontainerization setiap microservices Laravel menggunakan Docker. Meliputi Dockerfile optimal untuk production, multi-stage builds, docker-compose untuk development, image optimization, dan best practices keamanan container.

## Komponen yang Terlibat
- Docker Engine
- Docker Compose
- Multi-stage builds
- Dockerfile optimization
- PHP-FPM + Nginx containers
- Container networking
- Volume management
- Health checks
- Image tagging & versioning

## Perintah Artisan CLI
```bash
# Build Docker image
docker build -t user-service:latest -f docker/Dockerfile .

# Run with docker-compose
docker-compose -f docker/docker-compose.yml up -d

# Scale a service
docker-compose -f docker/docker-compose.yml up -d --scale order-service=3

# Check container logs
docker logs -f user-service

# Execute artisan in container
docker exec user-service php artisan migrate
```

## Kode Implementasi (Per File)

### Production Dockerfile
```dockerfile
# docker/Dockerfile
# Stage 1: Build dependencies
FROM composer:2.6 AS vendor

WORKDIR /app

COPY composer.json composer.lock ./
RUN composer install \
    --no-dev \
    --no-scripts \
    --no-autoloader \
    --prefer-dist \
    --optimize-autoloader

COPY database/ database/
RUN composer run-script post-autoload-dump

# Stage 2: Node build (if using Vite/Inertia)
FROM node:20-alpine AS frontend

WORKDIR /app

COPY package.json package-lock.json vite.config.js ./
RUN npm ci --production

COPY resources/ resources/
RUN npm run build

# Stage 3: Runtime image
FROM php:8.2-fpm-alpine AS runtime

# Arguments
ARG APP_ENV=production
ARG APP_VERSION=latest
ARG BUILD_DATE

# Labels
LABEL maintainer="dev@example.com"
LABEL app.version="${APP_VERSION}"
LABEL build.date="${BUILD_DATE}"

# Install system dependencies
RUN apk add --no-cache \
    nginx \
    supervisor \
    postgresql-client \
    redis \
    libzip-dev \
    libpng-dev \
    libjpeg-turbo-dev \
    freetype-dev \
    oniguruma-dev \
    git \
    curl \
    && docker-php-ext-configure gd --with-freetype --with-jpeg \
    && docker-php-ext-install -j$(nproc) \
        pdo_pgsql \
        pdo_mysql \
        bcmath \
        gd \
        zip \
        opcache \
        exif

# Install Redis extension
RUN pecl install redis && docker-php-ext-enable redis

# Install and enable OPcache
RUN docker-php-ext-enable opcache

# Configure PHP
COPY docker/php.ini /usr/local/etc/php/conf.d/app.ini
COPY docker/php-fpm.conf /usr/local/etc/php-fpm.d/www.conf

# Configure Nginx
COPY docker/nginx.conf /etc/nginx/nginx.conf
COPY docker/nginx-site.conf /etc/nginx/conf.d/default.conf

# Configure Supervisor
COPY docker/supervisord.conf /etc/supervisor/conf.d/supervisord.conf

# Create system user
RUN addgroup -g 1000 -S app && \
    adduser -u 1000 -S app -G app

WORKDIR /var/www/html

# Copy built application
COPY --from=vendor --chown=app:app /app /var/www/html
COPY --from=frontend --chown=app:app /app/public/build /var/www/html/public/build
COPY --chown=app:app . /var/www/html

# Create storage structure
RUN mkdir -p storage/logs storage/framework/cache/data \
    storage/framework/sessions storage/framework/views \
    && chown -R app:app storage bootstrap/cache \
    && chmod -R 775 storage bootstrap/cache

# Optimize for production
RUN php artisan optimize && \
    php artisan route:cache && \
    php artisan view:cache && \
    php artisan config:cache && \
    php artisan event:cache

# Health check
HEALTHCHECK --interval=30s --timeout=3s --start-period=5s --retries=3 \
    CMD curl -f http://localhost/api/health || exit 1

EXPOSE 80 443

USER app

CMD ["/usr/bin/supervisord", "-c", "/etc/supervisor/conf.d/supervisord.conf"]
```

### Nginx Configuration for Laravel
```nginx
# docker/nginx-site.conf
server {
    listen 80;
    server_name _;

    root /var/www/html/public;
    index index.php;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";
    add_header X-XSS-Protection "1; mode=block";

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    location ~ \.php$ {
        fastcgi_pass 127.0.0.1:9000;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_read_timeout 60;
    }

    location ~* \.(jpg|jpeg|png|gif|ico|css|js|webp|avif)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }

    access_log /var/www/html/storage/logs/nginx-access.log;
    error_log /var/www/html/storage/logs/nginx-error.log;
}
```

### Build Script
```bash
#!/bin/bash
# docker/build-all.sh

set -e

SERVICES=("api-gateway" "user-service" "product-service" "order-service" "payment-service" "notification-service")
APP_VERSION=${APP_VERSION:-latest}
REGISTRY=${REGISTRY:-docker.io/yourorg}

echo "Building all microservices images..."

for service in "${SERVICES[@]}"; do
    echo "Building ${service}..."
    docker build \
        --build-arg APP_VERSION="${APP_VERSION}" \
        --build-arg BUILD_DATE="$(date -u +'%Y-%m-%dT%H:%M:%SZ')" \
        -t "${REGISTRY}/${service}:${APP_VERSION}" \
        -t "${REGISTRY}/${service}:latest" \
        -f "../${service}/docker/Dockerfile" \
        "../${service}"

    echo "Pushing ${service}..."
    docker push "${REGISTRY}/${service}:${APP_VERSION}"
    docker push "${REGISTRY}/${service}:latest"
done

echo "All images built and pushed successfully."
```

## Cara Integrasi & Pengujian
1. Buat Dockerfile production dengan multi-stage build
2. Setup docker-compose.yml untuk semua service
3. Konfigurasi Nginx + PHP-FPM dalam satu container
4. Setup Supervisor untuk manage multiple processes
5. Konfigurasi health check endpoint
6. Build images dan test secara lokal
7. Setup container networking antar service
8. Test scaling service (multiple instances)
9. Test volume persistence (database)
10. Test container restart behavior
11. Optimasi image size (gunakan alpine, multi-stage)
12. Setup CI/CD untuk build otomatis
13. Test production deployment dengan docker-compose
