# 430. Best Practices Keamanan dan Data Privacy di Microservices

## Definisi & Target
Mengimplementasikan security best practices untuk microservices architecture: defense in depth, zero-trust networking, encryption in transit/at-rest, secrets management, audit logging, GDPR compliance, dan secure service-to-service communication.

## Komponen yang Terlibat
- Zero-trust architecture
- mTLS (mutual TLS)
- Secrets management (Vault / AWS Secrets Manager)
- Encryption at rest & in transit
- Audit logging
- GDPR / data privacy
- Rate limiting & DDoS protection
- Security scanning (SAST/DAST)
- API key rotation

### Secure Service Client with mTLS
```php
<?php
namespace App\Services;

use Illuminate\Support\Facades\Http;

class SecureServiceClient
{
    public function call(string $service, string $method, string $path, array $data = []): mixed
    {
        $baseUrl = $this->getServiceUrl($service);

        $response = Http::withOptions([
            'cert' => [config('mtls.local_cert'), config('mtls.local_pk')],
            'verify' => config('mtls.ca_path'),
        ])->withHeaders([
            'X-Service-Name' => config('app.name'),
            'X-Request-Id' => (string) str()->uuid(),
            'X-Signed-Timestamp' => (string) now()->timestamp,
        ])->timeout(10)->$method(
            rtrim($baseUrl, '/') . '/' . ltrim($path, '/'),
            $data
        );

        if ($response->failed()) {
            throw new SecureCommunicationException(
                "Secure call to {$service} failed: {$response->status()}"
            );
        }

        return $response->json();
    }

    private function getServiceUrl(string $service): string
    {
        $urls = [
            'user' => env('USER_SERVICE_INTERNAL_URL', 'https://user-service.internal'),
            'product' => env('PRODUCT_SERVICE_INTERNAL_URL', 'https://product-service.internal'),
            'order' => env('ORDER_SERVICE_INTERNAL_URL', 'https://order-service.internal'),
            'payment' => env('PAYMENT_SERVICE_INTERNAL_URL', 'https://payment-service.internal'),
        ];

        return $urls[$service] ?? throw new \InvalidArgumentException("Unknown service");
    }
}

class SecureCommunicationException extends \RuntimeException {}
```

### Secrets Management
```php
<?php
namespace App\Services;

use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Http;

class VaultSecretsManager
{
    private string $vaultUrl;
    private string $vaultToken;
    private string $secretPath;

    public function __construct()
    {
        $this->vaultUrl = env('VAULT_URL', 'http://vault:8200');
        $this->vaultToken = env('VAULT_TOKEN');
        $this->secretPath = env('VAULT_SECRET_PATH', 'secret/microservices');
    }

    public function getSecret(string $key): string
    {
        $cacheKey = "vault_secret:{$key}";

        return Cache::remember($cacheKey, 300, function () use ($key) {
            $response = Http::withToken($this->vaultToken)
                ->get("{$this->vaultUrl}/v1/{$this->secretPath}/{$key}");

            if (!$response->successful()) {
                throw new SecretsManagementException(
                    "Failed to retrieve secret {$key}: {$response->status()}"
                );
            }

            return $response->json('data.data.value');
        });
    }

    public function setSecret(string $key, string $value): void
    {
        $response = Http::withToken($this->vaultToken)
            ->post("{$this->vaultUrl}/v1/{$this->secretPath}/{$key}", [
                'data' => ['value' => $value],
            ]);

        if (!$response->successful()) {
            throw new SecretsManagementException(
                "Failed to store secret {$key}: {$response->status()}"
            );
        }

        Cache::forget("vault_secret:{$key}");
    }

    public function rotateSecret(string $key): string
    {
        $newValue = bin2hex(random_bytes(32));
        $this->setSecret($key, $newValue);

        logger()->info("Secret {$key} rotated");

        return $newValue;
    }
}

class SecretsManagementException extends \RuntimeException {}
```

### Data Encryption at Rest
```php
<?php
namespace App\Services;

use Illuminate\Support\Facades\Crypt;

class DataEncryptionService
{
    private string $encryptionKey;

    public function __construct()
    {
        $this->encryptionKey = base64_decode(env('DATA_ENCRYPTION_KEY'));
    }

    public function encryptSensitive(string $value): string
    {
        return Crypt::encryptString($value);
    }

    public function decryptSensitive(string $encrypted): string
    {
        return Crypt::decryptString($encrypted);
    }

    // Searchable encryption for PII
    public function hashForSearch(string $value): string
    {
        return hash_hmac('sha256', strtolower(trim($value)), $this->encryptionKey);
    }

    // Partial masking for display
    public function maskEmail(string $email): string
    {
        $parts = explode('@', $email);
        $name = $parts[0];
        $domain = $parts[1] ?? '';

        $maskedName = substr($name, 0, 2) . str_repeat('*', max(0, strlen($name) - 2));
        $domainParts = explode('.', $domain);
        $maskedDomain = $domainParts[0][0] . str_repeat('*', max(0, strlen($domainParts[0]) - 1));

        return "{$maskedName}@{$maskedDomain}." . ($domainParts[1] ?? '');
    }

    public function maskPhone(string $phone): string
    {
        $cleaned = preg_replace('/[^0-9]/', '', $phone);
        $visible = substr($cleaned, -4);
        $masked = str_repeat('*', max(0, strlen($cleaned) - 4));
        return $masked . $visible;
    }
}
```

### Audit Logging Middleware
```php
<?php
namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\DB;

class AuditLog
{
    public function handle(Request $request, Closure $next): mixed
    {
        $startTime = microtime(true);

        $response = $next($request);

        $duration = (microtime(true) - $startTime) * 1000;

        // Only log non-health-check requests
        if (!str_contains($request->path(), 'health')) {
            $this->logAuditEvent($request, $response, $duration);
        }

        return $response;
    }

    private function logAuditEvent(Request $request, mixed $response, float $duration): void
    {
        $user = $request->user();
        $payload = $request->except(['password', 'password_confirmation', 'token', 'secret']);

        DB::connection(config('database.default'))->table('audit_logs')->insert([
            'service' => config('app.name'),
            'event_type' => 'http_request',
            'actor_type' => $user ? 'user' : 'service',
            'actor_id' => $user ? $user->id : $request->header('X-Service-Name'),
            'action' => "{$request->method()} {$request->path()}",
            'resource_type' => $request->segment(2) ?? 'unknown',
            'resource_id' => $request->segment(3),
            'payload' => json_encode($payload),
            'ip_address' => $request->ip(),
            'user_agent' => $request->userAgent(),
            'response_status' => $response->status(),
            'duration_ms' => round($duration, 2),
            'request_id' => $request->header('X-Request-Id'),
            'trace_id' => $request->header('X-Trace-Id'),
            'created_at' => now(),
        ]);
    }
}
```

### GDPR Compliance Handler
```php
<?php
namespace App\Services;

use App\Models\User;
use Illuminate\Support\Facades\DB;

class GDPRComplianceService
{
    public function exportUserData(int $userId): array
    {
        $user = User::findOrFail($userId);

        return [
            'profile' => $user->toArray(),
            'orders' => $this->getUserOrders($userId),
            'activities' => $this->getUserActivities($userId),
            'communications' => $this->getUserCommunications($userId),
            'consents' => $this->getUserConsents($userId),
        ];
    }

    public function anonymizeUser(int $userId): void
    {
        DB::transaction(function () use ($userId) {
            $user = User::findOrFail($userId);

            $user->update([
                'name' => 'Anonymized User',
                'email' => "deleted-{$userId}@anonymized.local",
                'phone' => null,
                'email_verified_at' => null,
                'password' => bcrypt(str()->random(40)),
                'remember_token' => null,
                'anonymized_at' => now(),
            ]);

            $this->anonymizeRelatedData($userId);
        });
    }

    public function deleteUserData(int $userId): void
    {
        DB::transaction(function () use ($userId) {
            User::findOrFail($userId)->delete();

            // Soft delete related data
            DB::table('audit_logs')->where('actor_id', $userId)->update([
                'actor_id' => null,
                'payload' => null,
            ]);
        });
    }

    public function recordConsent(int $userId, string $purpose, bool $granted): void
    {
        DB::table('user_consents')->insert([
            'user_id' => $userId,
            'purpose' => $purpose,
            'granted' => $granted,
            'ip_address' => request()->ip(),
            'user_agent' => request()->userAgent(),
            'created_at' => now(),
        ]);
    }

    public function hasConsent(int $userId, string $purpose): bool
    {
        $latest = DB::table('user_consents')
            ->where('user_id', $userId)
            ->where('purpose', $purpose)
            ->latest()
            ->first();

        return $latest ? (bool) $latest->granted : false;
    }

    private function getUserOrders(int $userId): array
    {
        $orders = DB::connection('order_service')
            ->table('orders')
            ->where('customer_id', $userId)
            ->get()
            ->toArray();

        return array_map(fn ($order) => [
            'id' => $order->id,
            'total' => $order->total_amount,
            'status' => $order->status,
            'created_at' => $order->created_at,
        ], $orders);
    }

    private function getUserActivities(int $userId): array
    {
        return DB::table('audit_logs')
            ->where('actor_id', $userId)
            ->select('action', 'created_at')
            ->limit(100)
            ->get()
            ->toArray();
    }

    private function getUserCommunications(int $userId): array
    {
        return DB::connection('notification_service')
            ->table('notifications')
            ->where('user_id', $userId)
            ->select('type', 'channel', 'created_at')
            ->limit(100)
            ->get()
            ->toArray();
    }

    private function getUserConsents(int $userId): array
    {
        return DB::table('user_consents')
            ->where('user_id', $userId)
            ->select('purpose', 'granted', 'created_at')
            ->get()
            ->toArray();
    }

    private function anonymizeRelatedData(int $userId): void
    {
        DB::table('audit_logs')
            ->where('actor_id', $userId)
            ->update(['actor_id' => null]);
    }
}
```

### API Rate Limiting per Service
```php
<?php
namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Cache;

class ServiceRateLimiter
{
    private array $limits = [
        'user-service' => ['requests' => 1000, 'window' => 60],
        'product-service' => ['requests' => 2000, 'window' => 60],
        'order-service' => ['requests' => 500, 'window' => 60],
        'payment-service' => ['requests' => 200, 'window' => 60],
    ];

    public function handle(Request $request, Closure $next): mixed
    {
        $serviceName = $request->header('X-Service-Name');

        if (!$serviceName || !isset($this->limits[$serviceName])) {
            return $next($request);
        }

        $limit = $this->limits[$serviceName];
        $key = "rate_limit:{$serviceName}:" . now()->format('Y-m-d-H-i');

        $current = Cache::increment($key, 1);

        if ($current > $limit['requests']) {
            return response()->json([
                'error' => 'Rate limit exceeded',
                'service' => $serviceName,
                'limit' => $limit['requests'],
                'window_seconds' => $limit['window'],
            ], 429)->withHeaders([
                'X-RateLimit-Limit' => $limit['requests'],
                'X-RateLimit-Remaining' => 0,
                'Retry-After' => $limit['window'],
            ]);
        }

        $response = $next($request);

        $response->headers->set('X-RateLimit-Limit', $limit['requests']);
        $response->headers->set('X-RateLimit-Remaining', max(0, $limit['requests'] - $current));

        return $response;
    }
}
```

### Security Headers Middleware
```php
<?php
namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;

class SecurityHeaders
{
    public function handle(Request $request, Closure $next): mixed
    {
        $response = $next($request);

        $response->headers->set('X-Content-Type-Options', 'nosniff');
        $response->headers->set('X-Frame-Options', 'DENY');
        $response->headers->set('X-XSS-Protection', '1; mode=block');
        $response->headers->set('Referrer-Policy', 'strict-origin-when-cross-origin');
        $response->headers->set('Permissions-Policy', 'geolocation=(), microphone=(), camera=()');

        if (app()->environment('production')) {
            $response->headers->set('Strict-Transport-Security', 'max-age=31536000; includeSubDomains');
            $response->headers->set('Content-Security-Policy', "default-src 'self'");
        }

        $response->headers->remove('X-Powered-By');
        $response->headers->remove('Server');

        return $response;
    }
}
```

### API Key Management
```php
<?php
namespace App\Services;

use App\Models\ApiKey;
use Illuminate\Support\Str;
use Illuminate\Support\Facades\Hash;

class ApiKeyManager
{
    public function generate(string $name, array $permissions = []): array
    {
        $key = 'ms-' . Str::random(48);
        $hash = hash('sha256', $key);

        $apiKey = ApiKey::create([
            'name' => $name,
            'key_prefix' => substr($key, 0, 8),
            'key_hash' => $hash,
            'permissions' => $permissions,
            'expires_at' => now()->addYear(),
        ]);

        return [
            'id' => $apiKey->id,
            'name' => $apiKey->name,
            'key' => $key,
            'key_prefix' => $apiKey->key_prefix,
            'permissions' => $apiKey->permissions,
            'expires_at' => $apiKey->expires_at,
        ];
    }

    public function validate(string $key): ?ApiKey
    {
        $hash = hash('sha256', $key);
        $prefix = substr($key, 0, 8);

        $apiKey = ApiKey::where('key_prefix', $prefix)
            ->where('key_hash', $hash)
            ->where('is_active', true)
            ->where(function ($q) {
                $q->whereNull('expires_at')
                    ->orWhere('expires_at', '>', now());
            })
            ->first();

        return $apiKey;
    }

    public function revoke(int $id): void
    {
        ApiKey::findOrFail($id)->update(['is_active' => false]);
    }

    public function rotate(int $id): array
    {
        $this->revoke($id);
        $old = ApiKey::findOrFail($id);
        return $this->generate($old->name, $old->permissions);
    }
}
```

### Security Audit Command
```php
<?php
namespace App\Console\Commands;

use Illuminate\Console\Command;
use Illuminate\Support\Facades\Http;

class SecurityAudit extends Command
{
    protected $signature = 'security:audit {--fix : Attempt to fix issues}';
    protected $description = 'Run security audit on the service';

    public function handle(): int
    {
        $issues = [];

        $issues = array_merge($issues, $this->checkEnvironment());
        $issues = array_merge($issues, $this->checkDependencies());
        $issues = array_merge($issues, $this->checkConfiguration());
        $issues = array_merge($issues, $this->checkServiceCommunication());

        if (empty($issues)) {
            $this->info('✓ No security issues found');
            return self::SUCCESS;
        }

        foreach ($issues as $issue) {
            $this->warn("  ! {$issue}");
        }

        $this->error("Found " . count($issues) . " security issue(s)");

        return self::FAILURE;
    }

    private function checkEnvironment(): array
    {
        $issues = [];

        if (app()->environment('production') && config('app.debug')) {
            $issues[] = 'APP_DEBUG is enabled in production';
        }

        if (!app()->environment('production') && !config('app.debug')) {
            $issues[] = 'APP_DEBUG should be enabled in non-production';
        }

        if (!env('APP_KEY') || str_starts_with(env('APP_KEY'), 'base64:')) {
            $issues[] = 'APP_KEY might not be properly set';
        }

        return $issues;
    }

    private function checkDependencies(): array
    {
        $issues = [];

        $devPackages = ['laravel/telescope', 'barryvdh/laravel-debugbar'];
        foreach ($devPackages as $package) {
            if (composer_is_installed($package) && app()->environment('production')) {
                $issues[] = "Development package {$package} is installed in production";
            }
        }

        return $issues;
    }

    private function checkConfiguration(): array
    {
        $issues = [];

        if (config('session.secure') !== true && app()->environment('production')) {
            $issues[] = 'SESSION_SECURE_COOKIE should be true in production';
        }

        if (config('session.http_only') !== true) {
            $issues[] = 'SESSION_HTTP_ONLY should be true';
        }

        if (config('session.same_site') !== 'strict') {
            $issues[] = 'SESSION_SAME_SITE should be strict';
        }

        return $issues;
    }

    private function checkServiceCommunication(): array
    {
        $issues = [];

        $internalEndpoints = [
            env('USER_SERVICE_INTERNAL_URL') . '/api/health',
            env('ORDER_SERVICE_INTERNAL_URL') . '/api/health',
        ];

        foreach ($internalEndpoints as $endpoint) {
            try {
                $response = Http::timeout(3)->get($endpoint);
                if (!$response->successful()) {
                    $issues[] = "Internal endpoint {$endpoint} is not responding";
                }
            } catch (\Exception $e) {
                $issues[] = "Cannot reach internal endpoint {$endpoint}: {$e->getMessage()}";
            }
        }

        return $issues;
    }
}
```

## Cara Integrasi & Pengujian
1. Enable mTLS untuk semua service-to-service communication
2. Setup Vault atau AWS Secrets Manager untuk secrets
3. Encrypt semua PII data at rest dengan column encryption
4. Implement audit logging di setiap service
5. Pasang GDPR compliance handler dengan data export/delete
6. Setup rate limiting untuk internal service calls
7. Implement security headers di semua response
8. Gunakan API keys dengan rotasi periodik
9. Setup zero-trust network policies
10. Jalankan security audit secara rutin
11. Test encryption/decryption flow
12. Test data anonymization dan GDPR compliance
13. Test API key validation dan rotasi
14. Test mTLS connection rejection (invalid cert)
15. Monitor security events dan anomaly detection
