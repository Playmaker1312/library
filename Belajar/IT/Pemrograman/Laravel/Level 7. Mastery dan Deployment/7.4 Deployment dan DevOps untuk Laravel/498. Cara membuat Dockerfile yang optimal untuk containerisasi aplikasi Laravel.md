# 498. Cara Membuat Dockerfile yang Optimal untuk Containerisasi Aplikasi Laravel

## Definisi & Target
Dockerfile mendefinisikan bagaimana image Docker dibangun. Targetnya adalah menghasilkan image Laravel yang kecil, aman, dan efisien menggunakan multi-stage build.

## Komponen yang Terlibat
- Docker Engine
- Dockerfile
- .dockerignore
- PHP CLI image
- Composer image
- Node image

## Perintah Artisan CLI
```bash
docker build -t laravel-app .
docker run -p 8000:8000 laravel-app
```

## Kode Implementasi (Per File)

**Dockerfile Multi-Stage**
```dockerfile
# Stage 1: Build dependencies
FROM composer:latest AS vendor

WORKDIR /app

COPY composer.json composer.lock ./
RUN composer install \
    --no-interaction \
    --no-dev \
    --prefer-dist \
    --optimize-autoloader

# Stage 2: Build frontend
FROM node:20-alpine AS frontend

WORKDIR /app

COPY package.json package-lock.json ./
RUN npm ci

COPY resources/ ./resources/
RUN npm run build

# Stage 3: Final image
FROM php:8.2-fpm-alpine

WORKDIR /var/www/html

RUN apk add --no-cache \
    postgresql-dev \
    libzip-dev \
    unzip \
    git \
    && docker-php-ext-install \
    pdo_mysql \
    pdo_pgsql \
    zip \
    bcmath

COPY --from=composer:latest /usr/bin/composer /usr/bin/composer

COPY --from=vendor /app/vendor ./vendor
COPY --from=frontend /app/public/build ./public/build

COPY . .

RUN php artisan config:cache \
    && php artisan route:cache \
    && php artisan view:cache \
    && php artisan event:cache

RUN chown -R www-data:www-data storage bootstrap/cache

EXPOSE 8000

CMD ["php-fpm"]
```

**Development Dockerfile (Dockerfile.dev)**
```dockerfile
FROM php:8.2-fpm-alpine

RUN apk add --no-cache \
    postgresql-dev \
    libzip-dev \
    unzip \
    git \
    && docker-php-ext-install \
    pdo_mysql \
    pdo_pgsql \
    zip \
    bcmath

COPY --from=composer:latest /usr/bin/composer /usr/bin/composer

WORKDIR /var/www/html

EXPOSE 8000

CMD ["php-fpm"]
```

**Production Optimized Dockerfile**
```dockerfile
FROM php:8.2-fpm-alpine AS base

WORKDIR /var/www/html

RUN addgroup -g 1000 -S laravel && adduser -S laravel -G laravel -u 1000

RUN apk add --no-cache \
    postgresql-dev \
    libzip-dev \
    unzip \
    git \
    && docker-php-ext-install pdo_mysql pdo_pgsql zip bcmath opcache

COPY --from=composer:latest /usr/bin/composer /usr/bin/composer

USER laravel

COPY --chown=laravel:laravel . .

RUN composer install --no-interaction --no-dev --prefer-dist --optimize-autoloader \
    && php artisan config:cache \
    && php artisan route:cache \
    && php artisan view:cache

FROM base AS production

COPY --from=base /var/www/html /var/www/html

EXPOSE 8000

HEALTHCHECK --interval=30s --timeout=3s \
    CMD php artisan health:check || exit 1

CMD ["php-fpm"]
```

**docker-entrypoint.sh**
```bash
#!/bin/sh
set -e

if [ -z "$APP_KEY" ]; then
    echo "ERROR: APP_KEY is not set"
    exit 1
fi

php artisan storage:link 2>/dev/null

exec "$@"
```

## Cara Integrasi & Pengujian
Build image dengan `docker build -t laravel-app .`. Jalankan container dengan `docker run -p 8000:8000 laravel-app`. Pastikan container bisa diakses dan tidak ada error permission.
