# 502. Cara Mengimplementasikan Zero-Downtime Deployment Menggunakan Deployer PHP

## Definisi & Target
Zero-downtime deployment memungkinkan aplikasi baru di-deploy tanpa mengganggu pengguna yang sedang aktif. Deployer PHP menggunakan strategi symlink swap — aplikasi baru di-preparasi di folder terpisah, lalu symlink di-swap secara atomik.

## Komponen yang Terlibat
- Deployer PHP (deployer.org)
- SSH access ke server
- Git repository
- Nginx/PHP-FPM

## Perintah Artisan CLI
```bash
composer require deployer/deployer --dev
vendor/bin/dep init
vendor/bin/dep deploy production
```

## Kode Implementasi (Per File)

**deploy.php**
```php
<?php

namespace Deployer;

require 'recipe/laravel.php';

set('application', 'Laravel App');
set('repository', 'git@github.com:user/app.git');
set('git_tty', false);
set('keep_releases', 5);

host('production')
    ->setHostname('example.com')
    ->setRemoteUser('deployer')
    ->setPort(22)
    ->setIdentityFile('~/.ssh/deploy_key')
    ->setDeployPath('/var/www/laravel')
    ->set('branch', 'main');

host('staging')
    ->setHostname('staging.example.com')
    ->setRemoteUser('deployer')
    ->setDeployPath('/var/www/laravel-staging')
    ->set('branch', 'develop');

set('laravel_version', 11);

add('shared_files', [
    '.env',
]);

add('shared_dirs', [
    'storage',
]);

add('writable_dirs', [
    'bootstrap/cache',
    'storage',
    'storage/app',
    'storage/framework',
    'storage/logs',
]);

task('build:frontend', function () {
    cd('{{release_path}}');
    run('npm ci --production');
    run('npm run build');
});

task('opcache:clear', function () {
    run('php -r "opcache_reset();"');
});

task('supervisor:restart', function () {
    run('sudo supervisorctl restart laravel-worker:*');
});

after('deploy:vendors', 'build:frontend');
after('deploy:symlink', 'opcache:clear');
after('deploy:symlink', 'supervisor:restart');
after('deploy:failed', 'deploy:unlock');
```

**Deployer Recipe Custom (deploy/recipe/custom.php)**
```php
<?php

namespace Deployer;

desc('Run database migrations');
task('laravel:migrate', function () {
    run('{{bin/php}} {{release_or_current_path}}/artisan migrate --force');
});

desc('Health check after deployment');
task('deploy:healthcheck', function () {
    $url = getenv('APP_URL') ?: 'https://example.com';
    $result = run("curl -s -o /dev/null -w '%{http_code}' {$url}");
    
    if ($result !== '200') {
        writeln("<error>Health check failed! HTTP status: {$result}</error>");
        throw new \RuntimeException('Health check failed');
    }
    
    writeln("<info>Health check passed. Status: {$result}</info>");
});

after('deploy:symlink', 'deploy:healthcheck');
```

**Zero-Downtime dengan Nginx (tanpa Deployer)**
```bash
#!/bin/bash
# deployment/zero-downtime.sh

APP_DIR="/var/www/laravel"
RELEASE_DIR="${APP_DIR}/releases/$(date +%Y%m%d%H%M%S)"
SHARED_DIR="${APP_DIR}/shared"
CURRENT_DIR="${APP_DIR}/current"

echo "Creating release directory..."
mkdir -p $RELEASE_DIR

echo "Cloning repository..."
git clone git@github.com:user/app.git $RELEASE_DIR

echo "Installing dependencies..."
cd $RELEASE_DIR
composer install --no-dev --optimize-autoloader

echo "Building assets..."
npm ci && npm run build

echo "Linking shared resources..."
ln -nfs $SHARED_DIR/.env $RELEASE_DIR/.env
ln -nfs $SHARED_DIR/storage $RELEASE_DIR/storage

echo "Running migrations..."
php artisan migrate --force

echo "Optimizing..."
php artisan config:cache
php artisan route:cache
php artisan view:cache

echo "Swapping symlink (zero-downtime)..."
ln -nfs $RELEASE_DIR $CURRENT_DIR-tmp
mv -Tf $CURRENT_DIR-tmp $CURRENT_DIR

echo "Restarting services..."
sudo supervisorctl restart laravel-worker:*
sudo systemctl reload php8.2-fpm

echo "Cleaning up old releases..."
cd $APP_DIR/releases && ls -t | tail -n +6 | xargs rm -rf

echo "Deployment complete!"
```

**Rollback Script (deployment/rollback.sh)**
```bash
#!/bin/bash

APP_DIR="/var/www/laravel"
CURRENT_DIR="${APP_DIR}/current"

PREVIOUS_RELEASE=$(readlink $CURRENT_DIR)
echo "Current release: $PREVIOUS_RELEASE"

# Find previous release
cd $APP_DIR/releases
PREVIOUS=$(ls -t | sed -n '2p')

if [ -z "$PREVIOUS" ]; then
    echo "No previous release found!"
    exit 1
fi

echo "Rolling back to: $PREVIOUS"
ln -nfs $APP_DIR/releases/$PREVIOUS $CURRENT_DIR
echo "Rollback complete!"
```

## Cara Integrasi & Pengujian
Inisialisasi Deployer dengan `vendor/bin/dep init`. Konfigurasi host di deploy.php. Jalankan `vendor/bin/dep deploy production`. Verifikasi bahwa symlink berubah tanpa downtime.
