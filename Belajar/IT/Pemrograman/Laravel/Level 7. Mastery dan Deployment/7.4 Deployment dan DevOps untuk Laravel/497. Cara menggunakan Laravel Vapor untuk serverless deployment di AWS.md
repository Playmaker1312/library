# 497. Cara Menggunakan Laravel Vapor untuk Serverless Deployment di AWS

## Definisi & Target
Laravel Vapor adalah platform serverless deployment berbasis AWS Lambda. Targetnya adalah menjalankan Laravel tanpa server management — auto-scaling, pay-per-execution, dan managed infrastructure.

## Komponen yang Terlibat
- Laravel Vapor account
- AWS account
- Vapor CLI
- CloudFront, Lambda, Aurora, S3, DynamoDB

## Perintah Artisan CLI
```bash
composer require laravel/vapor-cli
vapor login
vapor init
vapor deploy production
```

## Kode Implementasi (Per File)

**vapor.yml**
```yaml
id: 12345
name: my-app
environments:
  production:
    domain: example.com
    memory: 1024
    timeout: 30
    storage: my-app-production
    database: my-app-production
    cache: my-app-production
    queue: false
    cli-memory: 512
    warm: 10
    redirect-www: true
    protected: true
    builds:
      - 'npm ci && npm run build && rm -rf node_modules'
    deploy:
      - 'php artisan migrate --force'
    schedule:
      - command: 'your-command:run'
        expression: '0 */6 * * *'
  staging:
    domain: staging.example.com
    memory: 512
    warm: 0
    storage: my-app-staging
```

**Vapor Configuration (config/vapor.php)**
```php
<?php

return [
    'assets' => [
        'url' => env('ASSET_URL', null),
    ],
];
```

**Vapor Service Provider (app/Providers/VaporServiceProvider.php)**
```php
namespace App\Providers;

use Illuminate\Support\ServiceProvider;
use Laravel\Vapor\VaporServiceProvider as BaseVaporProvider;

class VaporServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        if ($this->app->environment('production')) {
            $this->app->register(BaseVaporProvider::class);
        }
    }
}
```

**Storage Disk untuk Vapor (config/filesystems.php)**
```php
'disks' => [
    'local' => [
        'driver' => 'local',
        'root' => storage_path('app'),
    ],
    'public' => [
        'driver' => 'local',
        'root' => storage_path('app/public'),
        'url' => env('APP_URL').'/storage',
        'visibility' => 'public',
    ],
    's3' => [
        'driver' => 's3',
        'key' => env('AWS_ACCESS_KEY_ID'),
        'secret' => env('AWS_SECRET_ACCESS_KEY'),
        'region' => env('AWS_DEFAULT_REGION'),
        'bucket' => env('AWS_BUCKET'),
        'url' => env('AWS_URL'),
        'endpoint' => env('AWS_ENDPOINT'),
        'use_path_style_endpoint' => env('AWS_USE_PATH_STYLE_ENDPOINT', false),
    ],
    'vapor' => [
        'driver' => 'vapor',
    ],
],
```

**Database Configuration untuk Vapor (config/database.php)**
```php
'mysql' => [
    'driver' => 'mysql',
    'url' => env('DATABASE_URL'),
    'host' => env('DB_HOST', '127.0.0.1'),
    'port' => env('DB_PORT', '3306'),
    'database' => env('DB_DATABASE', 'forge'),
    'username' => env('DB_USERNAME', 'forge'),
    'password' => env('DB_PASSWORD', ''),
    'unix_socket' => env('DB_SOCKET', ''),
    'charset' => 'utf8mb4',
    'collation' => 'utf8mb4_unicode_ci',
    'prefix' => '',
    'prefix_indexes' => true,
    'sslmode' => 'required',
],
```

**Vapor Deploy Command**
```bash
vapor deploy production
vapor deploy staging
vapor deploy production --commit="feat: add new feature"
```

**Vapor Environment Variables**
```bash
vapor env:pull production
vapor env:push production
```

## Cara Integrasi & Pengujian
Hubungkan Vapor dengan repository GitHub/GitLab. Konfigurasi vapor.yml sesuai kebutuhan. Deploy dengan `vapor deploy production`. Vapor otomatis menyediakan CloudFront, Lambda, dan database serveless Aurora.
