# 505. Cara Mengimplementasikan Backup Otomatis Database Menggunakan Spatie Laravel Backup

## Definisi & Target
Spatie Laravel Backup mengotomatisasi backup database dan file ke storage lokal atau cloud. Targetnya adalah memastikan data aplikasi selalu aman dengan backup terjadwal.

## Komponen yang Terlibat
- spatie/laravel-backup package
- Database dump (mysqldump/pg_dump)
- Storage disk (local, S3, GCS)
- Backup monitoring

## Perintah Artisan CLI
```bash
composer require spatie/laravel-backup
php artisan vendor:publish --provider="Spatie\Backup\BackupServiceProvider"
php artisan backup:run
php artisan backup:list
php artisan backup:monitor
```

**Schedule Backup (app/Console/Kernel.php)**
```php
protected function schedule(Schedule $schedule): void
{
    $schedule->command('backup:run --only-db')
        ->dailyAt('01:00')
        ->withoutOverlapping()
        ->onOneServer();

    $schedule->command('backup:run')
        ->weekly()
        ->sundays()
        ->at('02:00')
        ->withoutOverlapping()
        ->onOneServer();

    $schedule->command('backup:clean')
        ->dailyAt('03:00')
        ->withoutOverlapping();

    $schedule->command('backup:monitor')
        ->dailyAt('04:00')
        ->withoutOverlapping();
}
```

**Health Check Route (routes/web.php)**
```php
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Storage;

Route::get('/backup-status', function () {
    $backups = Cache::remember('backup-status', 300, function () {
        $files = Storage::disk('local')->files('Laravel-backup');
        return collect($files)->map(function ($file) {
            return [
                'name' => basename($file),
                'size' => Storage::disk('local')->size($file),
                'last_modified' => Storage::disk('local')->lastModified($file),
            ];
        })->sortByDesc('last_modified')->values();
    });

    return response()->json([
        'count' => $backups->count(),
        'latest' => $backups->first(),
        'healthy' => true,
    ]);
})->middleware('auth');
```

**Custom Backup Notification Channel (app/Notifications/BackupNotification.php)**
```php
namespace App\Notifications;

use Illuminate\Notifications\Notification;

class BackupNotification extends Notification
{
    public function via($notifiable): array
    {
        return ['database'];
    }

    public function toArray($notifiable): array
    {
        return [
            'type' => 'backup',
            'message' => $this->message,
            'status' => $this->status,
        ];
    }
}
```

## Cara Integrasi & Pengujian
Konfigurasi storage disk untuk backup. Jalankan `php artisan backup:run` untuk menguji. Monitor hasil backup melalui notifikasi atau dashboard. Jadwalkan backup otomatis di Kernel.
