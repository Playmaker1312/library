# 494. Cara Mengkonfigurasi PHP-FPM Pool untuk Performa Optimal

## Definisi & Target
PHP-FPM pool configuration menentukan bagaimana PHP menangani request. Targetnya adalah mengoptimasi jumlah worker, memory limit, dan timeout sesuai resource server.

## Komponen yang Terlibat
- PHP-FPM pool config
- pm (process manager) settings
- Server RAM dan CPU
- Nginx fastcgi_pass

## Perintah Artisan CLI
```bash
sudo systemctl status php8.2-fpm
sudo systemctl reload php8.2-fpm
```

## Kode Implementasi (Per File)

**PHP-FPM Pool Configuration (/etc/php/8.2/fpm/pool.d/www.conf)**
```ini
[www]

user = www-data
group = www-data

listen = /var/run/php/php8.2-fpm.sock
listen.owner = www-data
listen.group = www-data
listen.mode = 0660

; Process Manager: dynamic, static, ondemand
pm = dynamic
pm.max_children = 50
pm.start_servers = 10
pm.min_spare_servers = 5
pm.max_spare_servers = 20
pm.process_idle_timeout = 10s
pm.max_requests = 500

; Execution limits
request_terminate_timeout = 300
request_slowlog_timeout = 10
slowlog = /var/log/php8.2-fpm-slow.log

; Resource limits
rlimit_files = 131072
rlimit_core = unlimited

; Security
security.limit_extensions = .php .phar

; Environment
env[HOSTNAME] = $HOSTNAME
env[PATH] = /usr/local/bin:/usr/bin:/bin
env[TMP] = /tmp
env[TMPDIR] = /tmp
env[TEMP] = /tmp
```

**PHP-FPM Pool Calculation Script**
```bash
#!/bin/bash

RAM_MB=$(free -m | awk '/^Mem:/{print $2}')
CPU_CORES=$(nproc)

echo "Server: ${RAM_MB}MB RAM, ${CPU_CORES} CPU cores"
echo ""

AVG_PHP_PROCESS_MB=35
MAX_CHILDREN=$((RAM_MB * 80 / 100 / AVG_PHP_PROCESS_MB))

echo "Recommended settings:"
echo "  pm.max_children = $MAX_CHILDREN"
echo ""
echo "  pm = dynamic"
echo "  pm.max_children = $MAX_CHILDREN"
echo "  pm.start_servers = $((CPU_CORES * 2))"
echo "  pm.min_spare_servers = $((CPU_CORES))"
echo "  pm.max_spare_servers = $((CPU_CORES * 4))"
echo "  pm.max_requests = 500"
```

**Multiple Pool untuk Multiple Apps**
```ini
; Pool untuk aplikasi utama
[laravel_main]
listen = /var/run/php/php8.2-fpm-main.sock
pm = dynamic
pm.max_children = 30
pm.start_servers = 6
pm.min_spare_servers = 3
pm.max_spare_servers = 12
security.limit_extensions = .php

; Pool untuk API
[laravel_api]
listen = /var/run/php/php8.2-fpm-api.sock
pm = ondemand
pm.max_children = 20
pm.process_idle_timeout = 30s
security.limit_extensions = .php
```

**Monitoring PHP-FPM**
```bash
# Cek status pool
sudo -u www-data php -r "print_r(json_decode(file_get_contents('http://localhost/php-fpm-status?json'), true));"

# Monitor processes
watch -n 1 'ps aux | grep php-fpm | grep -v grep | wc -l'

# Cek slow log
tail -f /var/log/php8.2-fpm-slow.log
```

**Enable PHP-FPM Status**
```nginx
server {
    location /php-fpm-status {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        include fastcgi_params;
        allow 127.0.0.1;
        deny all;
    }
}
```

## Cara Integrasi & Pengujian
Sesuaikan `pm.max_children` dengan RAM server. Gunakan `ondemand` untuk API pool yang tidak selalu aktif. Monitor slow log untuk mendeteksi query atau kode yang lambat.
