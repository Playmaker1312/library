# 501. Cara Mengkonfigurasi Cron Job untuk Laravel Scheduler di Production

## Definisi & Target
Laravel Scheduler memungkinkan penjadwalan tugas menggunakan sintaks PHP yang ekspresif. Satu cron entry di server menjalankan scheduler setiap menit, yang kemudian mengeksekusi tugas sesuai jadwal.

## Komponen yang Terlibat
- Cron daemon
- Laravel Artisan scheduler
- Task definitions di Kernel
- Log output

## Perintah Artisan CLI
```bash
php artisan schedule:list
php artisan schedule:run
php artisan make:command ProcessReports
```

## Kode Implementasi (Per File)

**Cron Entry (/etc/cron.d/laravel)**
```cron
* * * * * www-data cd /var/www/laravel && php artisan schedule:run >> /dev/null 2>&1
```

**Atau via crontab**
```bash
sudo crontab -e -u www-data
```

```cron
* * * * * cd /var/www/laravel && php artisan schedule:run >> /dev/null 2>&1
```

**Task Scheduler (app/Console/Kernel.php)**
```php
namespace App\Console;

use Illuminate\Console\Scheduling\Schedule;
use Illuminate\Foundation\Console\Kernel as ConsoleKernel;

class Kernel extends ConsoleKernel
{
    protected function schedule(Schedule $schedule): void
    {
        $schedule->command('reports:generate')
            ->dailyAt('02:00')
            ->withoutOverlapping()
            ->runInBackground()
            ->appendOutputTo(storage_path('logs/reports.log'));

        $schedule->command('backup:run')
            ->dailyAt('03:00')
            ->withoutOverlapping()
            ->emailOutputTo('admin@example.com');

        $schedule->command('queue:prune-failed')
            ->daily()
            ->onOneServer();

        $schedule->command('activitylog:clean')
            ->weekly()
            ->sundays()
            ->at('04:00');

        $schedule->call(function () {
            Cache::forget('site_statistics');
        })->hourly();

        $schedule->exec('uptime')
            ->everyFiveMinutes()
            ->appendOutputTo(storage_path('logs/uptime.log'));

        $schedule->command('sitemap:generate')
            ->weekly()
            ->mondays()
            ->at('05:00')
            ->environments(['production']);
    }

    protected function commands(): void
    {
        $this->load(__DIR__.'/Commands');
        require base_path('routes/console.php');
    }
}
```

**Example Command (app/Console/Commands/ProcessReports.php)**
```php
namespace App\Console\Commands;

use Illuminate\Console\Command;
use App\Services\ReportService;

class ProcessReports extends Command
{
    protected $signature = 'reports:generate {--date=today}';
    protected $description = 'Generate daily reports';

    public function handle(ReportService $reportService): int
    {
        $this->info('Generating reports...');

        $reportService->generateDaily($this->option('date'));

        $this->info('Reports generated successfully.');

        return Command::SUCCESS;
    }
}
```

**routes/console.php untuk Closure Command**
```php
use Illuminate\Support\Facades\Schedule;

Schedule::call(function () {
    $expired = \App\Models\Subscription::where('ends_at', '<', now())
        ->where('status', 'active')
        ->update(['status' => 'expired']);

    Log::info("Expired {$expired} subscriptions");
})->daily();
```

**Heartbeat Monitoring**
```php
// app/Console/Kernel.php
protected function schedule(Schedule $schedule): void
{
    $schedule->call(function () {
        Http::get('https://hc-ping.com/your-heartbeat-uuid');
    })->everyMinute();
}
```

**Scheduler Logging (config/logging.php)**
```php
'scheduler' => [
    'driver' => 'daily',
    'path' => storage_path('logs/scheduler.log'),
    'level' => 'info',
    'days' => 14,
],
```

## Cara Integrasi & Pengujian
Tambahkan cron entry di server. Jalankan `php artisan schedule:list` untuk melihat jadwal. Uji dengan `php artisan schedule:run`. Verifikasi log di storage/logs.
