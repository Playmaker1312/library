# 492. Cara Men-deploy Laravel ke VPS Ubuntu Menggunakan Nginx dan PHP-FPM

## Definisi & Target
VPS Ubuntu memberikan kontrol penuh atas environment. Targetnya adalah melakukan deployment Laravel dari awal di VPS dengan Nginx sebagai web server dan PHP-FPM untuk eksekusi PHP.

## Komponen yang Terlibat
- Ubuntu server (22.04 LTS)
- Nginx web server
- PHP-FPM
- MySQL/MariaDB
- Git, Composer, Node.js

## Perintah Artisan CLI
```bash
php artisan key:generate
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

## Kode Implementasi (Per File)

**Script Setup Server (deployment/setup-vps.sh)**
```bash
#!/bin/bash

echo "Updating system..."
sudo apt update && sudo apt upgrade -y

echo "Installing Nginx..."
sudo apt install nginx -y

echo "Installing PHP 8.2 and extensions..."
sudo apt install php8.2-fpm php8.2-cli php8.2-mbstring php8.2-xml php8.2-curl \
    php8.2-mysql php8.2-bcmath php8.2-gd php8.2-zip php8.2-redis -y

echo "Installing MySQL..."
sudo apt install mysql-server -y

echo "Installing Composer..."
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

echo "Installing Node.js..."
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install nodejs -y

echo "Setup complete!"
```

**Clone dan Deploy Script (deployment/deploy-vps.sh)**
```bash
#!/bin/bash

APP_DIR="/var/www/laravel"
REPO_URL="https://github.com/user/app.git"

echo "Deploying Laravel application..."

if [ ! -d "$APP_DIR" ]; then
    git clone $REPO_URL $APP_DIR
fi

cd $APP_DIR

git pull origin main

composer install --no-interaction --prefer-dist --optimize-autoloader

npm ci && npm run build

php artisan migrate --force

php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan event:cache

php artisan storage:link

sudo chown -R www-data:www-data storage bootstrap/cache

sudo systemctl reload php8.2-fpm

echo "Deployment complete!"
```

**Nginx Configuration (/etc/nginx/sites-available/laravel)**
```nginx
server {
    listen 80;
    server_name example.com;
    root /var/www/laravel/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    index index.php;

    charset utf-8;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
```

**Enable Site**
```bash
sudo ln -s /etc/nginx/sites-available/laravel /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## Cara Integrasi & Pengujian
Jalankan script setup di VPS baru. Konfigurasi Nginx dan PHP-FPM. Clone repository dan jalankan deploy script. Akses domain untuk verifikasi aplikasi berjalan.
