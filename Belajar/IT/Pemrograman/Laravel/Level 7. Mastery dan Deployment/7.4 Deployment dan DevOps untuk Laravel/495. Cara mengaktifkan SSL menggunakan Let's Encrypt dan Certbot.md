# 495. Cara Mengaktifkan SSL Menggunakan Let's Encrypt dan Certbot

## Definisi & Target
Let's Encrypt menyediakan SSL certificate gratis yang valid selama 90 hari. Certbot mengotomatisasi proses instalasi dan renewal. Targetnya adalah mengamankan aplikasi Laravel dengan HTTPS.

## Komponen yang Terlibat
- Let's Encrypt CA
- Certbot client
- Nginx web server
- SSL certificate files
- Auto-renewal cron

## Perintah Artisan CLI
```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d example.com -d www.example.com
sudo certbot renew --dry-run
```

## Kode Implementasi (Per File)

**Install Certbot**
```bash
sudo apt update
sudo apt install certbot python3-certbot-nginx -y
```

**Obtain SSL Certificate**
```bash
sudo certbot --nginx -d example.com -d www.example.com \
    --non-interactive \
    --agree-tos \
    --email admin@example.com
```

**Nginx SSL Configuration (/etc/nginx/sites-available/laravel-ssl)**
```nginx
server {
    listen 443 ssl http2;
    server_name example.com www.example.com;

    ssl_certificate /etc/letsencrypt/live/example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;
    ssl_trusted_certificate /etc/letsencrypt/live/example.com/chain.pem;

    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256;
    ssl_prefer_server_ciphers on;
    ssl_session_cache shared:SSL:10m;
    ssl_session_timeout 10m;
    ssl_session_tickets off;

    ssl_stapling on;
    ssl_stapling_verify on;
    resolver 8.8.8.8 8.8.4.4 valid=300s;
    resolver_timeout 5s;

    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;

    root /var/www/laravel/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
    }
}

server {
    listen 80;
    server_name example.com www.example.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name example.com www.example.com;

    ssl_certificate /etc/letsencrypt/live/example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;

    location /.well-known/acme-challenge/ {
        root /var/www/html;
    }
}
```

**Auto-Renewal Cron**
```bash
# Tambahkan ke crontab
crontab -e
```

```cron
0 3 * * * /usr/bin/certbot renew --quiet --post-hook "systemctl reload nginx"
```

**Verifikasi SSL dengan Test (tests/Feature/SSLTest.php)**
```php
namespace Tests\Feature;

use Tests\TestCase;

class SSLTest extends TestCase
{
    public function test_https_redirect()
    {
        $response = $this->get('/', ['HTTP_HOST' => 'example.com']);
        $response->assertStatus(302);
    }

    public function test_security_headers()
    {
        $response = $this->get('/');

        if (config('app.env') === 'production') {
            $response->assertHeader('Strict-Transport-Security');
        }
    }
}
```

**Laravel Force HTTPS (bootstrap/app.php)**
```php
return Application::configure(basePath: dirname(__DIR__))
    ->withMiddleware(function (Middleware $middleware) {
        $middleware->trustProxies(at: '*');
    })
    ->create();
```

**.env Production**
```env
APP_URL=https://example.com
FORCE_HTTPS=true
```

## Cara Integrasi & Pengujian
Jalankan `certbot --nginx` untuk instalasi pertama. Verifikasi dengan `curl -I https://example.com`. Pastikan auto-renewal berfungsi dengan `certbot renew --dry-run`.
