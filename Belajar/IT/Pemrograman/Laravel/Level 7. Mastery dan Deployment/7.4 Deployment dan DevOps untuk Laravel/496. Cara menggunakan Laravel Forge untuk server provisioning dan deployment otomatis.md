# 496. Cara Menggunakan Laravel Forge untuk Server Provisioning dan Deployment Otomatis

## Definisi & Target
Laravel Forge adalah platform manajemen server yang mengotomatisasi provisioning, deployment, SSL, cron, dan queue management. Targetnya adalah menyederhanakan operasional server Laravel melalui dashboard web.

## Komponen yang Terlibat
- Laravel Forge account
- Server provider (DigitalOcean, AWS, Linode, dll)
- GitHub/GitLab/Bitbucket repository
- Forge CLI

## Perintah Artisan CLI
```bash
composer global require laravel/forge-cli
forge server:list
forge deploy example-app
```

## Kode Implementasi (Per File)

**Forge Deploy Script (.forge/deploy.sh)**
```bash
#!/bin/bash
# This script runs on Forge after deployment

cd /home/forge/example.com

$FORGE_COMPOSER install --no-interaction --prefer-dist --optimize-autoloader

$FORGE_PHP artisan migrate --force

$FORGE_PHP artisan config:cache
$FORGE_PHP artisan route:cache
$FORGE_PHP artisan view:cache
$FORGE_PHP artisan event:cache

$FORGE_PHP artisan storage:link

if [ -f package.json ]; then
    npm ci --production
    npm run build
fi

$FORGE_PHP artisan queue:restart

echo "Deployment complete!"
```

**.forge/config.yaml (Forge Configuration)**
```yaml
provider: digitalocean
region: sgp1
php_version: php82
database: mysql8
sites:
  - domain: example.com
    project_type: laravel
    directory: /public
    wildcard: true
    php_version: php82
    quick_deploy: true
    deployment: deploy.sh
    env:
      APP_ENV: production
      APP_DEBUG: false
      DB_CONNECTION: mysql
```

**Forge API Integration (app/Services/ForgeService.php)**
```php
namespace App\Services;

use Illuminate\Support\Facades\Http;

class ForgeService
{
    private string $apiToken;
    private string $baseUrl = 'https://forge.laravel.com/api/v1';

    public function __construct()
    {
        $this->apiToken = config('services.forge.token');
    }

    public function deploy(int $serverId, int $siteId): array
    {
        $response = Http::withToken($this->apiToken)
            ->post("{$this->baseUrl}/servers/{$serverId}/sites/{$siteId}/deployment/deploy");

        return $response->json();
    }

    public function getDeploymentLog(int $serverId, int $siteId, int $deploymentId): array
    {
        $response = Http::withToken($this->apiToken)
            ->get("{$this->baseUrl}/servers/{$serverId}/sites/{$siteId}/deployment/logs/{$deploymentId}");

        return $response->json();
    }

    public function getServers(): array
    {
        $response = Http::withToken($this->apiToken)
            ->get("{$this->baseUrl}/servers");

        return $response->json()['servers'] ?? [];
    }
}
```

**Forge Worker Configuration**
```php
// config/queue.php — Forge akan override otomatis
'connections' => [
    'forge' => [
        'driver' => 'redis',
        'connection' => 'default',
        'queue' => 'default',
        'retry_after' => 90,
        'block_for' => null,
    ],
],
```

## Cara Integrasi & Pengujian
Hubungkan Forge dengan provider cloud dan repository. Konfigurasi deployment script di dashboard Forge. Gunakan fitur Quick Deploy untuk auto-deploy setiap push ke branch tertentu.
