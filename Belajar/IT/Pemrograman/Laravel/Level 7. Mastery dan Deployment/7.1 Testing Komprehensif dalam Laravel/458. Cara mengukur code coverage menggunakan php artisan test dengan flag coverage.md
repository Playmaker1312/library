# 458. Cara Mengukur Code Coverage Menggunakan php artisan test dengan Flag Coverage

## Definisi & Target
PHPUnit dapat mengukur persentase kode yang tercakup oleh test menggunakan Xdebug atau PCOV. Targetnya adalah mengidentifikasi area kode yang belum teruji dan meningkatkan kualitas test suite secara bertahap.

## Komponen yang Terlibat
- Xdebug atau PCOV extension
- PHPUnit code coverage reporter
- Laravel test suite

## Perintah Artisan CLI
```bash
php artisan test --coverage
php artisan test --coverage --min=80
```

**Install PCOV (alternatif ringan)**
```bash
pecl install pcov
```

## Kode Implementasi (Per File)

**Konfigurasi phpunit.xml**
```xml
<phpunit xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:noNamespaceSchemaLocation="./vendor/phpunit/phpunit/phpunit.xsd"
         bootstrap="vendor/autoload.php"
         colors="true"
         cacheDirectory=".phpunit.cache">
    <source>
        <include>
            <directory>app</directory>
        </include>
        <exclude>
            <directory>app/Console</directory>
            <directory>app/Exceptions</directory>
            <directory>app/Providers</directory>
        </exclude>
    </source>
    <coverage>
        <report>
            <html outputDirectory="coverage"/>
            <clover outputDirectory="coverage/clover.xml"/>
            <text outputFile="php://stdout"/>
        </report>
    </coverage>
</phpunit>
```

**Output coverage di terminal**
```
  App\Services\UserService .............. 100%
  App\Http\Controllers\UserController ... 85.7%
  App\Models\User ........................ 90.0%
  App\Models\Post ........................ 66.7%
  Total: 88.2%
```

**GitHub Actions workflow (.github/workflows/tests.yml)**
```yaml
name: Tests with Coverage

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: shivammathur/setup-php@v2
        with:
          php-version: '8.2'
          coverage: pcov
      - run: composer install
      - run: php artisan test --coverage --min=80
```

## Cara Integrasi & Pengujian
Jalankan `php artisan test --coverage` dengan Xdebug atau PCOV aktif. Target coverage minimal 80% untuk production. Integrasikan dengan CI untuk mencegah penurunan coverage.
