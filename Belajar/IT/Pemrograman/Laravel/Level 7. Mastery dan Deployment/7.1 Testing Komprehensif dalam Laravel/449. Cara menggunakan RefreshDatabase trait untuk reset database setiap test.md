# 449. Cara Menggunakan RefreshDatabase Trait untuk Reset Database Setiap Test

## Definisi & Target
`RefreshDatabase` adalah trait Laravel yang secara otomatis memigrasi dan mereset database di setiap test. Targetnya adalah memastikan setiap test berjalan dalam keadaan database yang bersih dan konsisten.

## Komponen yang Terlibat
- `Illuminate\Foundation\Testing\RefreshDatabase`
- Database migrations
- Test database (SQLite in-memory atau MySQL terpisah)

## Perintah Artisan CLI
```bash
php artisan make:test ProductTest
```

## Kode Implementasi (Per File)

**Model (app/Models/Product.php)**
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Factories\HasFactory;

class Product extends Model
{
    use HasFactory;

    protected $fillable = ['name', 'price'];
}
```

**Factory (database/factories/ProductFactory.php)**
```php
namespace Database\Factories;

use App\Models\Product;
use Illuminate\Database\Eloquent\Factories\Factory;

class ProductFactory extends Factory
{
    protected $model = Product::class;

    public function definition(): array
    {
        return [
            'name' => $this->faker->word,
            'price' => $this->faker->numberBetween(1000, 100000),
        ];
    }
}
```

**Feature Test (tests/Feature/ProductTest.php)**
```php
namespace Tests\Feature;

use Tests\TestCase;
use App\Models\Product;
use Illuminate\Foundation\Testing\RefreshDatabase;

class ProductTest extends TestCase
{
    use RefreshDatabase;

    public function test_product_count()
    {
        Product::factory(5)->create();
        $this->assertCount(5, Product::all());
    }

    public function test_product_count_starts_empty()
    {
        $this->assertCount(0, Product::all());
    }
}
```

**Konfigurasi phpunit.xml**
```xml
<server name="DB_CONNECTION" value="sqlite"/>
<server name="DB_DATABASE" value=":memory:"/>
```

## Cara Integrasi & Pengujian
Jalankan `php artisan test`. Trait `RefreshDatabase` akan menjalankan `migrate:fresh` sebelum setiap test — pastikan tidak ada test yang bergantung pada data dari test sebelumnya.
