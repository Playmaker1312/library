# 448. Cara Membuat Feature Test untuk HTTP Endpoint Menggunakan Metode Get, Post, Put, dan Delete

## Definisi & Target
Feature test menguji HTTP endpoint secara end-to-end dengan mensimulasikan request GET, POST, PUT, dan DELETE. Targetnya adalah memvalidasi bahwa rute, middleware, controller, dan database bekerja sesuai harapan.

## Komponen yang Terlibat
- Laravel TestCase dengan HTTP testing methods
- Route definitions
- Controller methods
- Database (jika diperlukan)

## Perintah Artisan CLI
```bash
php artisan make:test UserControllerTest
php artisan make:controller UserController --resource
```

## Kode Implementasi (Per File)

**Controller (app/Http/Controllers/UserController.php)**
```php
namespace App\Http\Controllers;

use App\Models\User;
use Illuminate\Http\Request;

class UserController extends Controller
{
    public function index()
    {
        return User::all();
    }

    public function store(Request $request)
    {
        $validated = $request->validate([
            'name' => 'required|string',
            'email' => 'required|email|unique:users',
            'password' => 'required|min:8',
        ]);
        return User::create($validated);
    }

    public function update(Request $request, User $user)
    {
        $user->update($request->only('name', 'email'));
        return $user;
    }

    public function destroy(User $user)
    {
        $user->delete();
        return response()->noContent();
    }
}
```

**Feature Test (tests/Feature/UserControllerTest.php)**
```php
namespace Tests\Feature;

use Tests\TestCase;
use App\Models\User;
use Illuminate\Foundation\Testing\RefreshDatabase;

class UserControllerTest extends TestCase
{
    use RefreshDatabase;

    public function test_can_get_all_users()
    {
        User::factory(3)->create();
        $response = $this->getJson('/api/users');
        $response->assertStatus(200)->assertJsonCount(3);
    }

    public function test_can_create_user()
    {
        $data = ['name' => 'John', 'email' => 'john@test.com', 'password' => 'secret123'];
        $response = $this->postJson('/api/users', $data);
        $response->assertStatus(201)->assertJsonFragment(['email' => 'john@test.com']);
    }

    public function test_can_update_user()
    {
        $user = User::factory()->create();
        $response = $this->putJson("/api/users/{$user->id}", ['name' => 'Updated']);
        $response->assertStatus(200);
        $this->assertDatabaseHas('users', ['name' => 'Updated']);
    }

    public function test_can_delete_user()
    {
        $user = User::factory()->create();
        $response = $this->deleteJson("/api/users/{$user->id}");
        $response->assertStatus(204);
        $this->assertDatabaseMissing('users', ['id' => $user->id]);
    }
}
```

## Cara Integrasi & Pengujian
Jalankan `php artisan test --filter=UserControllerTest`. Setiap method test harus independen — gunakan `RefreshDatabase` untuk mereset state database antar test.
