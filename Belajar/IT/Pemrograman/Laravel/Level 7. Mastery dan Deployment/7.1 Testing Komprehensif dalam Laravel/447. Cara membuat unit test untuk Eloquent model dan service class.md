# 447. Cara Membuat Unit Test untuk Eloquent Model dan Service Class

## Definisi & Target
Unit test menguji logika bisnis secara terisolasi tanpa bergantung pada database atau HTTP. Untuk Eloquent model, kita menggunakan `Tests\TestCase` milik Laravel agar bisa memanfaatkan factory. Untuk service class, cukup extend `PHPUnit\Framework\TestCase`. Targetnya adalah memvalidasi kebenaran method secara independen.

## Komponen yang Terlibat
- PHPUnit TestCase
- Laravel TestCase untuk model test
- Model Factory
- Service class yang akan diuji

## Perintah Artisan CLI
```bash
php artisan make:test UserServiceTest --unit
php artisan make:test UserModelTest
```

## Kode Implementasi (Per File)

**Service Class (app/Services/UserService.php)**
```php
namespace App\Services;

use App\Models\User;
use Illuminate\Support\Facades\Hash;

class UserService
{
    public function register(array $data): User
    {
        $data['password'] = Hash::make($data['password']);
        return User::create($data);
    }

    public function formatUsername(User $user): string
    {
        return strtolower(str_replace(' ', '.', $user->name));
    }
}
```

**Unit Test Service (tests/Unit/UserServiceTest.php)**
```php
namespace Tests\Unit;

use PHPUnit\Framework\TestCase;
use App\Services\UserService;

class UserServiceTest extends TestCase
{
    private UserService $service;

    protected function setUp(): void
    {
        parent::setUp();
        $this->service = new UserService();
    }

    public function test_format_username_returns_lowercase_with_dots()
    {
        $user = new \App\Models\User(['name' => 'John Doe']);
        $result = $this->service->formatUsername($user);
        $this->assertEquals('john.doe', $result);
    }
}
```

**Model Test (tests/Feature/UserModelTest.php)**
```php
namespace Tests\Feature;

use Tests\TestCase;
use App\Models\User;
use Illuminate\Foundation\Testing\RefreshDatabase;

class UserModelTest extends TestCase
{
    use RefreshDatabase;

    public function test_user_has_default_role()
    {
        $user = User::factory()->create();
        $this->assertEquals('user', $user->role);
    }
}
```

## Cara Integrasi & Pengujian
Jalankan `php artisan test --testsuite=Unit` untuk menjalankan hanya unit test. Pastikan service class tidak memiliki side effect agar pengujian benar-benar terisolasi.
