# 460. Cara Membuat Testing Checklist yang Komprehensif Sebelum Setiap Deployment

## Definisi & Target
Testing checklist adalah daftar pengujian yang harus dilalui sebelum aplikasi di-deploy ke production. Targetnya adalah memastikan kualitas dan stabilitas aplikasi melalui proses verifikasi yang sistematis dan konsisten.

## Komponen yang Terlibat
- PHPUnit test suite
- Browser test (Dusk)
- Manual QA checklist
- CI pipeline

## Perintah Artisan CLI
```bash
php artisan test --parallel
php artisan dusk --headless
php artisan test --coverage --min=80
```

## Kode Implementasi (Per File)

**Testing Checklist Script (checklist/deploy-check.php)**
```php
<?php

$checks = [
    'Unit Test' => 'php artisan test --testsuite=Unit --no-interaction',
    'Feature Test' => 'php artisan test --testsuite=Feature --no-interaction',
    'Code Coverage' => 'php artisan test --coverage --min=80 --no-interaction',
    'Static Analysis' => './vendor/bin/phpstan analyse --level=max',
    'Code Style' => './vendor/bin/pint --test',
    'Security Audit' => 'composer audit',
    'Dusk Browser Test' => 'php artisan dusk --headless --no-interaction',
];

$passed = 0;
$failed = 0;

foreach ($checks as $name => $command) {
    echo "Running: $name...\n";
    exec($command, $output, $exitCode);
    if ($exitCode === 0) {
        echo "[PASS] $name\n";
        $passed++;
    } else {
        echo "[FAIL] $name\n";
        echo implode("\n", $output) . "\n";
        $failed++;
    }
}

echo "\n--- Deployment Check Summary ---\n";
echo "Passed: $passed\n";
echo "Failed: $failed\n";

if ($failed > 0) {
    echo "Status: BLOCKED - Fix failed checks before deployment.\n";
    exit(1);
}

echo "Status: READY FOR DEPLOYMENT.\n";
```

**GitHub Actions pre-deployment (.github/workflows/deploy-check.yml)**
```yaml
name: Deployment Checklist

on:
  push:
    branches: [production]

jobs:
  checklist:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: shivammathur/setup-php@v2
        with:
          php-version: '8.2'
          coverage: pcov

      - run: composer install
      - run: php artisan key:generate
      - run: php artisan test --coverage --min=80
      - run: ./vendor/bin/phpstan analyse --level=max
      - run: ./vendor/bin/pint --test
      - run: composer audit

      - name: Notify on failure
        if: failure()
        uses: slackapi/slack-github-action@v1
        with:
          payload: '{"text":"Deployment BLOCKED: Testing checklist failed for ${{ github.repository }}"}'
```

**Manual QA Checklist (docs/testing-checklist.md)**
```markdown
# Pre-Deployment Testing Checklist

## Automated Tests
- [ ] All unit tests pass
- [ ] All feature tests pass
- [ ] Code coverage >= 80%
- [ ] No critical static analysis errors
- [ ] PSR-12 code style validated

## Security
- [ ] No vulnerable dependencies (composer audit)
- [ ] CSRF protection enabled on all forms
- [ ] Rate limiting configured on sensitive endpoints
- [ ] File upload validation in place

## Manual QA
- [ ] User registration and login flow
- [ ] Core CRUD operations
- [ ] Error pages display correctly
- [ ] Email sending works
- [ ] File uploads and downloads
- [ ] Responsive design on mobile
- [ ] All third-party integrations respond

## Performance
- [ ] No N+1 queries (Debugbar checked)
- [ ] Cache configured for heavy queries
- [ ] Queue worker running for background jobs
- [ ] Assets are minified

## Infrastructure
- [ ] Database migrations run without error
- [ ] Environment variables configured
- [ ] Queue worker configured
- [ ] Cron jobs set up
- [ ] SSL certificate valid
```

## Cara Integrasi & Pengujian
Jalankan checklist secara otomatis via GitHub Actions sebelum deployment ke production. Dokumentasikan hasil QA manual di setiap rilis.
