# 457. Cara Menggunakan Laravel Dusk untuk Browser Testing End-to-End

## Definisi & Target
Laravel Dusk menyediakan browser automation API untuk menguji alur lengkap dari perspektif pengguna. Targetnya adalah memvalidasi interaksi UI seperti klik, input form, navigasi, dan JavaScript berjalan dengan benar.

## Komponen yang Terlibat
- Laravel Dusk package
- ChromeDriver atau Selenium
- Dusk Browser API
- DuskTestCase

## Perintah Artisan CLI
```bash
composer require laravel/dusk --dev
php artisan dusk:install
php artisan dusk:make LoginTest
php artisan dusk
```

## Kode Implementasi (Per File)

**Dusk Test (tests/Browser/LoginTest.php)**
```php
namespace Tests\Browser;

use Laravel\Dusk\Browser;
use Tests\DuskTestCase;
use App\Models\User;

class LoginTest extends DuskTestCase
{
    public function test_user_can_login()
    {
        $user = User::factory()->create([
            'email' => 'user@test.com',
            'password' => bcrypt('password'),
        ]);

        $this->browse(function (Browser $browser) use ($user) {
            $browser->visit('/login')
                    ->type('email', $user->email)
                    ->type('password', 'password')
                    ->press('Login')
                    ->assertPathIs('/dashboard')
                    ->assertSee('Dashboard');
        });
    }

    public function test_login_fails_with_wrong_password()
    {
        $user = User::factory()->create(['email' => 'user@test.com']);

        $this->browse(function (Browser $browser) {
            $browser->visit('/login')
                    ->type('email', 'user@test.com')
                    ->type('password', 'wrong-password')
                    ->press('Login')
                    ->assertPathIs('/login')
                    ->assertSee('These credentials do not match our records.');
        });
    }
}
```

**Dusk Test with JavaScript Interaction (tests/Browser/ModalTest.php)**
```php
namespace Tests\Browser;

use Laravel\Dusk\Browser;
use Tests\DuskTestCase;

class ModalTest extends DuskTestCase
{
    public function test_modal_opens_and_closes()
    {
        $this->browse(function (Browser $browser) {
            $browser->visit('/page')
                    ->click('#open-modal')
                    ->waitFor('.modal')
                    ->assertSeeIn('.modal', 'Modal Content')
                    ->click('.modal-close')
                    ->waitUntilMissing('.modal')
                    ->assertMissing('.modal');
        });
    }
}
```

**.env.dusk.local configuration**
```
APP_URL=http://localhost:8000
DB_DATABASE=testing_dusk
```

## Cara Integrasi & Pengujian
Jalankan `php artisan dusk` untuk menjalankan seluruh browser test. Pastikan ChromeDriver sudah terinstal dan versi Chrome sesuai. Untuk CI, gunakan `php artisan dusk --headless` untuk mode headless.
