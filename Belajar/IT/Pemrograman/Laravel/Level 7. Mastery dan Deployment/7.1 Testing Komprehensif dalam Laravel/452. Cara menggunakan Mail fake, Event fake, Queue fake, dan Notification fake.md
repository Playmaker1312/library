# 452. Cara Menggunakan Mail Fake, Event Fake, Queue Fake, dan Notification Fake

## Definisi & Target
Laravel `fake()` method memungkinkan kita mencegat Mail, Event, Queue, dan Notification sehingga tidak benar-benar dikirim/dijalankan. Targetnya adalah menguji bahwa class tertentu dikirim atau di-dispatch tanpa mengeksekusi side effect yang sebenarnya.

## Komponen yang Terlibat
- `Illuminate\Support\Facades\Mail` dengan `fake()`
- `Illuminate\Support\Facades\Event` dengan `fake()`
- `Illuminate\Support\Facades\Queue` dengan `fake()`
- `Illuminate\Support\Facades\Notification` dengan `fake()`

## Perintah Artisan CLI
```bash
php artisan make:test FakeTest
php artisan make:mail WelcomeMail
php artisan make:event UserRegistered
php artisan make:notification WelcomeNotification
```

## Kode Implementasi (Per File)

**Feature Test (tests/Feature/FakeTest.php)**
```php
namespace Tests\Feature;

use Tests\TestCase;
use App\Models\User;
use App\Mail\WelcomeMail;
use App\Events\UserRegistered;
use App\Notifications\WelcomeNotification;
use Illuminate\Support\Facades\Mail;
use Illuminate\Support\Facades\Event;
use Illuminate\Support\Facades\Queue;
use Illuminate\Support\Facades\Notification;
use Illuminate\Foundation\Testing\RefreshDatabase;

class FakeTest extends TestCase
{
    use RefreshDatabase;

    public function test_mail_fake()
    {
        Mail::fake();
        $user = User::factory()->create();
        Mail::to($user)->send(new WelcomeMail($user));
        Mail::assertSent(WelcomeMail::class, fn ($mail) => $mail->hasTo($user->email));
    }

    public function test_event_fake()
    {
        Event::fake();
        $user = User::factory()->create();
        Event::dispatch(new UserRegistered($user));
        Event::assertDispatched(UserRegistered::class);
    }

    public function test_queue_fake()
    {
        Queue::fake();
        $user = User::factory()->create();
        Mail::to($user)->queue(new WelcomeMail($user));
        Queue::assertPushed(WelcomeMail::class);
    }

    public function test_notification_fake()
    {
        Notification::fake();
        $user = User::factory()->create();
        $user->notify(new WelcomeNotification());
        Notification::assertSentTo($user, WelcomeNotification::class);
    }
}
```

## Cara Integrasi & Pengujian
Jalankan `php artisan test --filter=FakeTest`. Gunakan fake di awal test dan assertion di akhir untuk memvalidasi bahwa class yang diharapkan benar-benar dikirim atau di-dispatch.
