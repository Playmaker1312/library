# 451. Cara Menggunakan assertStatus, assertJson, assertRedirect, dan Assertion Lainnya

## Definisi & Target
Laravel menyediakan berbagai assertion method untuk memvalidasi response HTTP: `assertStatus`, `assertJson`, `assertRedirect`, `assertViewHas`, `assertSessionHas`, dan lainnya. Targetnya adalah memastikan response sesuai ekspektasi di setiap skenario test.

## Komponen yang Terlibat
- Laravel TestCase assertion methods
- HTTP response object
- Session, View, dan JSON utilities

## Perintah Artisan CLI
```bash
php artisan make:test AssertionExampleTest
```

## Kode Implementasi (Per File)

**Controller (app/Http/Controllers/TestController.php)**
```php
namespace App\Http\Controllers;

use Illuminate\Http\Request;

class TestController extends Controller
{
    public function json()
    {
        return response()->json(['status' => 'ok', 'data' => [1, 2, 3]]);
    }

    public function redirect()
    {
        return redirect()->to('/home')->with('success', 'Welcome!');
    }

    public function view()
    {
        return view('dashboard')->with('title', 'Dashboard');
    }
}
```

**Feature Test (tests/Feature/AssertionExampleTest.php)**
```php
namespace Tests\Feature;

use Tests\TestCase;

class AssertionExampleTest extends TestCase
{
    public function test_assertion_examples()
    {
        $response = $this->get('/test/json');
        $response->assertStatus(200);
        $response->assertJson(['status' => 'ok']);
        $response->assertJsonCount(3, 'data');
        $response->assertJsonStructure(['status', 'data']);
        $response->assertJsonPath('data.0', 1);
    }

    public function test_redirect_assertions()
    {
        $response = $this->get('/test/redirect');
        $response->assertRedirect('/home');
        $response->assertSessionHas('success', 'Welcome!');
    }

    public function test_view_assertions()
    {
        $response = $this->get('/test/view');
        $response->assertViewIs('dashboard');
        $response->assertViewHas('title', 'Dashboard');
    }

    public function test_response_helpers()
    {
        $response = $this->get('/test/json');
        $response->assertOk();
        $response->assertSuccessful();
        $response->assertHeader('Content-Type');
        $response->assertNoContent(204);
    }
}
```

**Routes (routes/web.php)**
```php
use App\Http\Controllers\TestController;

Route::get('/test/json', [TestController::class, 'json']);
Route::get('/test/redirect', [TestController::class, 'redirect']);
Route::get('/test/view', [TestController::class, 'view']);
```

## Cara Integrasi & Pengujian
Jalankan `php artisan test --filter=AssertionExampleTest`. Pelajari daftar lengkap assertion di dokumentasi Laravel untuk memilih assertion yang paling tepat.
