# 455. Cara Mengimplementasikan Database Seeding Khusus untuk Testing Environment

## Definisi & Target
Database seeder khusus untuk testing menyediakan data awal yang konsisten dan predictable. Targetnya adalah memastikan setiap test memiliki baseline data yang sama tanpa bergantung pada seeder production.

## Komponen yang Terlibat
- DatabaseSeeder dan test-specific seeders
- RefreshDatabase trait
- phpunit.xml environment configuration

## Perintah Artisan CLI
```bash
php artisan make:seeder TestUserSeeder
php artisan make:seeder TestCategorySeeder
```

## Kode Implementasi (Per File)

**Testing Seeder (database/seeders/TestDatabaseSeeder.php)**
```php
namespace Database\Seeders;

use Illuminate\Database\Seeder;
use App\Models\User;
use App\Models\Category;
use App\Models\Post;

class TestDatabaseSeeder extends Seeder
{
    public function run(): void
    {
        User::factory()->admin()->create([
            'email' => 'admin@test.com',
            'name' => 'Test Admin',
        ]);

        User::factory()->count(5)->create();

        $categories = Category::factory()->count(3)->create();

        Post::factory()->published()->count(10)->create();

        Post::factory()->published()->count(5)->create([
            'user_id' => User::where('email', 'admin@test.com')->first()->id,
        ]);
    }
}
```

**Base TestCase (tests/TestCase.php)**
```php
namespace Tests;

use Illuminate\Foundation\Testing\TestCase as BaseTestCase;
use Illuminate\Foundation\Testing\RefreshDatabase;

abstract class TestCase extends BaseTestCase
{
    use CreatesApplication;

    protected bool $seed = true;

    protected string $seeder = \Database\Seeders\TestDatabaseSeeder::class;
}
```

**Feature Test (tests/Feature/PostListTest.php)**
```php
namespace Tests\Feature;

use Tests\TestCase;
use App\Models\Post;
use Illuminate\Foundation\Testing\RefreshDatabase;

class PostListTest extends TestCase
{
    use RefreshDatabase;

    public function test_only_published_posts_are_listed()
    {
        $response = $this->getJson('/api/posts');
        $response->assertStatus(200);
        $posts = $response->json('data');
        foreach ($posts as $post) {
            $this->assertEquals('published', $post['status']);
        }
    }

    public function test_admin_seeded_correctly()
    {
        $this->assertDatabaseHas('users', ['email' => 'admin@test.com']);
    }
}
```

**phpunit.xml**
```xml
<php>
    <server name="APP_ENV" value="testing"/>
    <server name="DB_CONNECTION" value="sqlite"/>
    <server name="DB_DATABASE" value=":memory:"/>
    <server name="SEEDER" value="Database\Seeders\TestDatabaseSeeder"/>
</php>
```

## Cara Integrasi & Pengujian
Set properti `$seed = true` di TestCase agar seeder otomatis dijalankan. Gunakan seeder terpisah dari production agar data test tidak mengganggu data development.
