# 453. Cara Menggunakan Http Fake untuk Mocking HTTP Request ke API Eksternal

## Definisi & Target
`Http::fake()` mencegat semua HTTP request yang dikirim melalui Laravel HTTP Client dan mengembalikan response palsu. Targetnya adalah menguji kode yang bergantung pada API eksternal tanpa benar-benar terhubung ke internet.

## Komponen yang Terlibat
- `Illuminate\Support\Facades\Http` dengan `fake()`
- `Http` client dari Laravel
- Response sequence untuk multiple request

## Perintah Artisan CLI
```bash
php artisan make:test WeatherServiceTest
```

## Kode Implementasi (Per File)

**Service (app/Services/WeatherService.php)**
```php
namespace App\Services;

use Illuminate\Support\Facades\Http;

class WeatherService
{
    public function getWeather(string $city): array
    {
        $response = Http::get("https://api.weather.com/v1/{$city}");
        return $response->json();
    }

    public function getCitiesWeather(array $cities): array
    {
        $responses = [];
        foreach ($cities as $city) {
            $responses[$city] = Http::get("https://api.weather.com/v1/{$city}")->json();
        }
        return $responses;
    }
}
```

**Feature Test (tests/Feature/WeatherServiceTest.php)**
```php
namespace Tests\Feature;

use Tests\TestCase;
use App\Services\WeatherService;
use Illuminate\Support\Facades\Http;

class WeatherServiceTest extends TestCase
{
    public function test_get_weather_returns_data()
    {
        Http::fake([
            'api.weather.com/*' => Http::response([
                'city' => 'Jakarta',
                'temp' => 30,
                'condition' => 'sunny',
            ], 200),
        ]);

        $service = new WeatherService();
        $result = $service->getWeather('Jakarta');

        $this->assertEquals('Jakarta', $result['city']);
        $this->assertEquals(30, $result['temp']);
    }

    public function test_get_weather_handles_error()
    {
        Http::fake([
            'api.weather.com/*' => Http::response([], 500),
        ]);

        $service = new WeatherService();
        $result = $service->getWeather('Unknown');
        $this->assertNull($result['city'] ?? null);
    }

    public function test_mock_sequence()
    {
        Http::fake([
            'api.weather.com/*' => Http::sequence()
                ->push(['city' => 'Jakarta', 'temp' => 30])
                ->push(['city' => 'Bandung', 'temp' => 25])
                ->pushStatus(404),
        ]);

        $service = new WeatherService();
        $result = $service->getCitiesWeather(['Jakarta', 'Bandung', 'Unknown']);

        $this->assertEquals(30, $result['Jakarta']['temp']);
        $this->assertEquals(25, $result['Bandung']['temp']);
    }
}
```

## Cara Integrasi & Pengujian
Jalankan `php artisan test --filter=WeatherServiceTest`. Pastikan URL pattern pada `Http::fake()` sesuai dengan yang digunakan di service class.
