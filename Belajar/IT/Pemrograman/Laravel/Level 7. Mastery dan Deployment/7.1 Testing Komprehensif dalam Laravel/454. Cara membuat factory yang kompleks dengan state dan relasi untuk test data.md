# 454. Cara Membuat Factory yang Kompleks dengan State dan Relasi untuk Test Data

## Definisi & Target
Laravel Factory mendukung state (variasi kondisi), relasi (hasMany, belongsTo), dan nested factory. Targetnya adalah menghasilkan data test yang realistis dan beragam dengan kode yang ringkas.

## Komponen yang Terlibat
- Eloquent Model Factory
- State methods (`state`)
- Factory relationship methods (`for`, `has`, `hasAttached`)

## Perintah Artisan CLI
```bash
php artisan make:factory PostFactory --model=Post
php artisan make:factory CommentFactory --model=Comment
```

## Kode Implementasi (Per File)

**Model (app/Models/User.php)**
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Relations\HasMany;

class User extends Model
{
    use HasFactory;
    protected $fillable = ['name', 'email', 'role', 'is_active'];
    public function posts(): HasMany { return $this->hasMany(Post::class); }
}
```

**Model (app/Models/Post.php)**
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Database\Eloquent\Relations\HasMany;

class Post extends Model
{
    use HasFactory;
    protected $fillable = ['user_id', 'title', 'body', 'status'];
    public function user(): BelongsTo { return $this->belongsTo(User::class); }
    public function comments(): HasMany { return $this->hasMany(Comment::class); }
}
```

**Factory (database/factories/UserFactory.php)**
```php
namespace Database\Factories;

use App\Models\User;
use Illuminate\Database\Eloquent\Factories\Factory;

class UserFactory extends Factory
{
    protected $model = User::class;

    public function definition(): array
    {
        return [
            'name' => $this->faker->name(),
            'email' => $this->faker->unique()->safeEmail(),
            'role' => 'user',
            'is_active' => true,
        ];
    }

    public function admin(): static
    {
        return $this->state(fn (array $attrs) => ['role' => 'admin']);
    }

    public function inactive(): static
    {
        return $this->state(fn (array $attrs) => ['is_active' => false]);
    }
}
```

**Factory (database/factories/PostFactory.php)**
```php
namespace Database\Factories;

use App\Models\Post;
use App\Models\User;
use Illuminate\Database\Eloquent\Factories\Factory;

class PostFactory extends Factory
{
    protected $model = Post::class;

    public function definition(): array
    {
        return [
            'user_id' => User::factory(),
            'title' => $this->faker->sentence(),
            'body' => $this->faker->paragraphs(3, true),
            'status' => 'draft',
        ];
    }

    public function published(): static
    {
        return $this->state(fn (array $attrs) => ['status' => 'published']);
    }

    public function withComments(int $count = 3): static
    {
        return $this->has(Comment::factory($count));
    }
}
```

**Factory (database/factories/CommentFactory.php)**
```php
namespace Database\Factories;

use App\Models\Comment;
use App\Models\Post;
use App\Models\User;
use Illuminate\Database\Eloquent\Factories\Factory;

class CommentFactory extends Factory
{
    protected $model = Comment::class;

    public function definition(): array
    {
        return [
            'post_id' => Post::factory(),
            'user_id' => User::factory(),
            'body' => $this->faker->sentence(),
        ];
    }
}
```

**Feature Test (tests/Feature/FactoryRelationsTest.php)**
```php
namespace Tests\Feature;

use Tests\TestCase;
use App\Models\User;
use App\Models\Post;
use Illuminate\Foundation\Testing\RefreshDatabase;

class FactoryRelationsTest extends TestCase
{
    use RefreshDatabase;

    public function test_admin_user_with_posts()
    {
        $user = User::factory()->admin()->hasPosts(3)->create();
        $this->assertCount(3, $user->posts);
        $this->assertEquals('admin', $user->role);
    }

    public function test_published_post_with_comments()
    {
        $post = Post::factory()->published()->withComments(5)->create();
        $this->assertEquals('published', $post->status);
        $this->assertCount(5, $post->comments);
    }
}
```

## Cara Integrasi & Pengujian
Jalankan `php artisan test --filter=FactoryRelationsTest`. Kombinasikan state dan relasi untuk membuat skenario test data yang kompleks dengan cepat.
