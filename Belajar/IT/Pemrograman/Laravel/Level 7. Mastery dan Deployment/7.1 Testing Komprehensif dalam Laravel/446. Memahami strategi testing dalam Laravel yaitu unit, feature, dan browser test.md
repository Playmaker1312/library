# 446. Memahami Strategi Testing dalam Laravel yaitu Unit, Feature, dan Browser Test

## Definisi & Target
Laravel menyediakan tiga lapis strategi testing: unit test untuk menguji metode class secara terisolasi, feature test untuk menguji HTTP endpoint dan interaksi sistem secara menyeluruh, serta browser test (Dusk) untuk menguji alur UI dari perspektif pengguna. Targetnya adalah membangun kepercayaan terhadap kode melalui otomatisasi pengujian di setiap siklus pengembangan.

## Komponen yang Terlibat
- PHPUnit sebagai framework testing dasar
- Laravel TestCase dan DuskTestCase
- BrowserKit dan ChromeDriver untuk Dusk
- Database dan HTTP client internal

## Perintah Artisan CLI
```bash
php artisan make:test UserTest --unit
php artisan make:test UserControllerTest
php artisan dusk:make PageTest
php artisan test
```

## Kode Implementasi (Per File)

**Contoh Unit Test (tests/Unit/UserTest.php)**
```php
namespace Tests\Unit;

use PHPUnit\Framework\TestCase;

class UserTest extends TestCase
{
    public function test_example()
    {
        $this->assertTrue(true);
    }
}
```

**Contoh Feature Test (tests/Feature/UserControllerTest.php)**
```php
namespace Tests\Feature;

use Tests\TestCase;

class UserControllerTest extends TestCase
{
    public function test_can_list_users()
    {
        $response = $this->get('/api/users');
        $response->assertStatus(200);
    }
}
```

**Contoh Dusk Test (tests/Browser/LoginTest.php)**
```php
namespace Tests\Browser;

use Laravel\Dusk\Browser;
use Tests\DuskTestCase;

class LoginTest extends DuskTestCase
{
    public function test_login_page()
    {
        $this->browse(function (Browser $browser) {
            $browser->visit('/login')
                    ->assertSee('Login');
        });
    }
}
```

## Cara Integrasi & Pengujian
Jalankan `php artisan test` untuk menjalankan seluruh suite. Gunakan `php artisan test --filter=UserTest` untuk menjalankan test spesifik. Integrasikan ke dalam CI pipeline agar setiap pull request otomatis diuji.
