# 478. Cara Mengimplementasikan CSRF Protection yang Benar pada Semua Form

## Definisi & Target
CSRF (Cross-Site Request Forgery) protection memastikan bahwa request yang masuk berasal dari aplikasi kita sendiri, bukan dari situs jahat. Laravel menyediakan CSRF token secara otomatis. Targetnya adalah melindungi semua form POST, PUT, PATCH, DELETE dari serangan CSRF.

## Komponen yang Terlibat
- CSRF token middleware
- `@csrf` Blade directive
- `csrf_token()` helper
- Axios/JavaScript CSRF configuration

## Perintah Artisan CLI
```bash
php artisan make:middleware VerifyCsrfToken
```

## Kode Implementasi (Per File)

**Blade Form dengan CSRF**
```blade
{{-- Pendekatan 1: @csrf directive --}}
<form method="POST" action="/users">
    @csrf
    <input name="name" placeholder="Nama">
    <button type="submit">Simpan</button>
</form>

{{-- Pendekatan 2: Manual --}}
<form method="POST" action="/users">
    <input type="hidden" name="_token" value="{{ csrf_token() }}">
    <input name="name" placeholder="Nama">
    <button type="submit">Simpan</button>
</form>
```

**JavaScript/Axios CSRF Configuration (resources/js/bootstrap.js)**
```javascript
import axios from 'axios';

axios.defaults.headers.common['X-Requested-With'] = 'XMLHttpRequest';

const token = document.head.querySelector('meta[name="csrf-token"]');
if (token) {
    axios.defaults.headers.common['X-CSRF-TOKEN'] = token.content;
} else {
    console.error('CSRF token not found');
}
```

**Meta Tag CSRF di Layout**
```blade
<head>
    <meta name="csrf-token" content="{{ csrf_token() }}">
</head>
```

**Exclude CSRF untuk API Routes (bootstrap/app.php)**
```php
->withMiddleware(function (Middleware $middleware) {
    $middleware->validateCsrfTokens(
        except: [
            'stripe/*',
            'webhook/*',
        ],
    );
})
```

**API Routes tanpa CSRF (routes/api.php)**
```php
// API routes secara default menggunakan api middleware group tanpa CSRF
Route::post('/login', [AuthController::class, 'login']);
```

**Signed Routes untuk Link Aksi**
```blade
{{-- Signed route -- CSRF untuk link --}}
<a href="{{ URL::signedRoute('verify.email', ['user' => $user->id]) }}">
    Verifikasi Email
</a>
```

## Cara Integrasi & Pengujian
Pastikan semua form POST/PUT/PATCH/DELETE menyertakan `@csrf`. Untuk SPA, kirim CSRF token via header `X-CSRF-TOKEN`. Jangan exclude endpoint dari CSRF kecuali benar-benar diperlukan.
