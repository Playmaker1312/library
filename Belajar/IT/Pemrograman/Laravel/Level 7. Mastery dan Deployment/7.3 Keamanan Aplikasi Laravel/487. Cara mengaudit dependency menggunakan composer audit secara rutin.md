# 487. Cara Mengaudit Dependency Menggunakan Composer Audit Secara Rutin

## Definisi & Target
Composer audit memeriksa package yang terinstal terhadap database kerentanan Security Advisories. Targetnya adalah mendeteksi dan memperbaiki dependency yang memiliki celah keamanan.

## Komponen yang Terlibat
- Composer (versi 2.4+)
- Security Advisories database (FriendsOfPHP/security-advisories)
- composer.lock file

## Perintah Artisan CLI
```bash
composer audit
composer update --audit
```

## Kode Implementasi (Per File)

**Audit Script (audit/composer-audit.sh)**
```bash
#!/bin/bash

echo "Running Composer Security Audit..."
echo "================================"

cd /var/www

composer audit --format=json > audit-result.json

HAS_ISSUES=$(jq '.advisories | length' audit-result.json)

if [ "$HAS_ISSUES" -gt 0 ]; then
    echo "WARNING: $HAS_ISSUES security vulnerabilities found!"
    jq -r '.advisories[] | "Package: \(.package_name)\nSeverity: \(.severity)\nCVE: \(.cve // "N/A")\nLink: \(.link)\n"' audit-result.json

    # Kirim notifikasi ke Slack
    if [ -n "$SLACK_WEBHOOK_URL" ]; then
        MESSAGE="Security audit found $HAS_ISSUES vulnerabilities in $(date)"
        curl -X POST -H "Content-Type: application/json" \
            -d "{\"text\": \"$MESSAGE\"}" \
            "$SLACK_WEBHOOK_URL"
    fi

    exit 1
else
    echo "No security vulnerabilities found."
    exit 0
fi
```

**GitHub Actions Scheduled Audit (.github/workflows/security-audit.yml)**
```yaml
name: Security Audit

on:
  schedule:
    - cron: '0 6 * * 1'
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: shivammathur/setup-php@v2
        with:
          php-version: '8.2'

      - run: composer install --no-progress

      - name: Run composer audit
        run: composer audit
        continue-on-error: false

      - name: Notify on vulnerabilities
        if: failure()
        uses: slackapi/slack-github-action@v1
        with:
          payload: '{"text":"Security vulnerabilities found in ${{ github.repository }}"}'
```

**Update Dependency Aman**
```bash
# Update hanya patch version
composer update --with-all-dependencies --prefer-lowest

# Update package spesifik dengan aman
composer update laravel/framework --with-dependencies

# Update semua package kompatibel
composer update
```

**composer.json Script untuk Audit Otomatis**
```json
{
    "scripts": {
        "post-install-cmd": [
            "@audit"
        ],
        "post-update-cmd": [
            "@audit"
        ],
        "audit": "composer audit"
    }
}
```

**Artisan Command untuk Audit (app/Console/Commands/SecurityAuditCommand.php)**
```php
namespace App\Console\Commands;

use Illuminate\Console\Command;

class SecurityAuditCommand extends Command
{
    protected $signature = 'security:audit';
    protected $description = 'Run composer security audit';

    public function handle(): int
    {
        $this->info('Running security audit...');

        exec('composer audit --format=json 2>&1', $output, $exitCode);

        if ($exitCode === 0) {
            $this->info('No security vulnerabilities found.');
            return Command::SUCCESS;
        }

        $result = json_decode(implode('', $output), true);

        foreach ($result['advisories'] ?? [] as $advisory) {
            $this->warn("Package: {$advisory['package_name']}");
            $this->warn("Severity: {$advisory['severity']}");
            $this->warn("CVE: {$advisory['cve']}");
            $this->warn("Link: {$advisory['link']}");
            $this->newLine();
        }

        $this->error('Security vulnerabilities found. Please update affected packages.');

        return Command::FAILURE;
    }
}
```

## Cara Integrasi & Pengujian
Jalankan `composer audit` secara rutin (idealnya setiap minggu) atau integrasikan ke CI pipeline. Update package yang memiliki kerentanan dengan `composer update <package-name>`.
