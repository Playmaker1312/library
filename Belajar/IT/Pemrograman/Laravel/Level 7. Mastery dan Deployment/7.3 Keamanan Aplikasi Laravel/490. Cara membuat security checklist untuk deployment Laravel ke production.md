# 490. Cara Membuat Security Checklist untuk Deployment Laravel ke Production

## Definisi & Target
Security checklist adalah daftar verifikasi keamanan yang harus dipenuhi sebelum aplikasi live. Targetnya adalah memastikan tidak ada celah keamanan yang terlewat saat deployment.

## Komponen yang Terlibat
- Environment configuration
- Middleware dan konfigurasi keamanan
- Dependency audit
- Infrastructure security

## Perintah Artisan CLI
```bash
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan storage:link
```

## Kode Implementasi (Per File)

**Security Check Script (deployment/security-check.sh)**
```bash
#!/bin/bash

echo "Pre-Deployment Security Checklist"
echo "================================"
FAILED=0

check() {
    if [ "$2" = true ]; then
        echo "[PASS] $1"
    else
        echo "[FAIL] $1"
        FAILED=$((FAILED + 1))
    fi
}

# Environment checks
check "APP_DEBUG is false" "$(grep -c 'APP_DEBUG=false' .env) -eq 1"
check "APP_ENV is production" "$(grep -c 'APP_ENV=production' .env) -eq 1"
check "APP_URL uses HTTPS" "$(grep -c 'APP_URL=https://' .env) -eq 1"

# File permission checks
check "storage is writable" "$(test -w storage && echo true)"
check "bootstrap/cache is writable" "$(test -w bootstrap/cache && echo true)"

# Artisan checks
check "Config cached" "$(php artisan config:cache && rm bootstrap/cache/config.php && echo true)"
check "Route cached" "$(php artisan route:cache && rm bootstrap/cache/routes-v7.php && echo true)"

# Composer checks
check "No dev dependencies" "$(composer install --no-dev --dry-run 2>&1 | grep -c 'Nothing to install') -eq 1"

# Security audit
AUDIT_RESULT=$(composer audit --format=json)
check "No security vulnerabilities" "$(echo $AUDIT_RESULT | grep -c '"advisories":\[\]') -eq 1"

echo ""
echo "================================"
echo "Checks passed: $((10 - FAILED))/10"

if [ "$FAILED" -gt 0 ]; then
    echo "SECURITY CHECKS FAILED. Fix issues before deployment."
    exit 1
fi

echo "All security checks passed. Ready for deployment."
```

**GitHub Actions Pre-Deployment (.github/workflows/pre-deploy-security.yml)**
```yaml
name: Pre-Deployment Security Check

on:
  push:
    branches: [production]

jobs:
  security-check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: shivammathur/setup-php@v2
        with:
          php-version: '8.2'

      - run: composer install --no-dev

      - name: Environment check
        run: |
          if grep -q "APP_DEBUG=true" .env; then exit 1; fi
          if grep -q "APP_ENV=local" .env; then exit 1; fi

      - name: Security audit
        run: composer audit

      - name: Cache config check
        run: php artisan config:cache && rm bootstrap/cache/config.php

      - name: File permissions check
        run: |
          if [ ! -w storage ]; then exit 1; fi
          if [ ! -w bootstrap/cache ]; then exit 1; fi

      - name: Notify on failure
        if: failure()
        uses: slackapi/slack-github-action@v1
        with:
          payload: '{"text":"Pre-deployment security check FAILED for ${{ github.repository }}"}'
```

## Cara Integrasi & Pengujian
Jalankan security check script sebelum setiap deployment. Integrasikan ke CI pipeline untuk mencegah deployment yang tidak aman. Review checklist secara berkala dan update sesuai threat baru.
