# 476. Memahami OWASP Top 10 dalam Konteks Aplikasi Laravel

## Definisi & Target
OWASP Top 10 adalah daftar risiko keamanan web paling kritis. Targetnya adalah memahami bagaimana setiap risiko berlaku di Laravel dan bagaimana framework ini menyediakan proteksi built-in.

## Komponen yang Terlibat
- OWASP Top 10 (2021) daftar risiko
- Laravel security features (CSRF, XSS, SQL injection)
- Middleware dan konfigurasi keamanan

## Perintah Artisan CLI
```bash
composer audit
php artisan make:middleware SecurityHeaders
```

## Kode Implementasi (Per File)

**OWASP Top 10 vs Laravel Protection**
```
1. Broken Access Control   → Policy, Gate, Middleware auth
2. Cryptographic Failures  → Crypt facade, bcrypt password
3. Injection               → Eloquent/Query Builder parameter binding
4. Insecure Design         → Validation, Form Request
5. Security Misconfiguration → APP_DEBUG=false, environment config
6. Vulnerable Components   → composer audit, dependency updates
7. Authentication Failures → Laravel Breeze/Jetstream, rate limiting
8. Data Integrity Failures → CSRF token, signed routes
9. Logging & Monitoring    → Log facade, Telescope, Pulse
10. SSRF                   → HTTP client validation, URL allowlist
```

**Cek Keamanan Dasar (app/Console/Commands/SecurityCheckCommand.php)**
```php
namespace App\Console\Commands;

use Illuminate\Console\Command;

class SecurityCheckCommand extends Command
{
    protected $signature = 'security:check';
    protected $description = 'Check basic security configurations';

    public function handle(): int
    {
        $checks = [
            'APP_DEBUG=false' => env('APP_DEBUG') === false,
            'APP_ENV=production' => env('APP_ENV') === 'production',
            'HTTPS enabled' => env('APP_URL', ''),  // verifikasi manual
            'CSRF enabled' => true,
            'Auth configured' => file_exists(base_path('routes/auth.php')),
            'Rate limiting' => true,
            'CORS configured' => file_exists(base_path('config/cors.php')),
        ];

        $passed = 0;
        foreach ($checks as $name => $result) {
            if ($result) {
                $this->info("[PASS] $name");
                $passed++;
            } else {
                $this->warn("[FAIL] $name");
            }
        }

        $this->newLine();
        $this->info("Security checks: $passed/" . count($checks) . " passed");

        return $passed === count($checks) ? Command::SUCCESS : Command::FAILURE;
    }
}
```

## Cara Integrasi & Pengujian
Jalankan `php artisan security:check` secara berkala. Selalu update ke versi Laravel terbaru untuk mendapatkan security patch. Lakukan security audit setiap kuartal.
