# 485. Cara Mengkonfigurasi Laravel untuk Production yang Aman yaitu Debug False dan Error Logging

## Definisi & Target
Konfigurasi production yang aman mencegah kebocoran informasi sensitif melalui error message dan stack trace. Targetnya adalah memastikan debug mode mati, error logging terkonfigurasi, dan informasi internal tidak terekspos ke pengguna.

## Komponen yang Terlibat
- .env production configuration
- Laravel logging system
- Exception handler
- Error notification (email, Slack)

## Perintah Artisan CLI
```bash
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan optimize
```

## Kode Implementasi (Per File)

**.env Production**
```env
APP_ENV=production
APP_DEBUG=false
APP_URL=https://example.com

LOG_CHANNEL=stack
LOG_LEVEL=error

DB_CONNECTION=mysql
DB_HOST=localhost
DB_DATABASE=laravel
DB_USERNAME=laravel
DB_PASSWORD=secret

SESSION_DRIVER=redis
CACHE_DRIVER=redis
QUEUE_CONNECTION=redis
```

**Logging Configuration (config/logging.php)**
```php
'channels' => [
    'stack' => [
        'driver' => 'stack',
        'channels' => ['daily', 'slack'],
        'ignore_exceptions' => false,
    ],

    'daily' => [
        'driver' => 'daily',
        'path' => storage_path('logs/laravel.log'),
        'level' => env('LOG_LEVEL', 'error'),
        'days' => 14,
    ],

    'slack' => [
        'driver' => 'slack',
        'url' => env('LOG_SLACK_WEBHOOK_URL'),
        'username' => 'Laravel Error',
        'emoji' => ':boom:',
        'level' => env('LOG_LEVEL', 'critical'),
    ],
],
```

**Exception Handler (bootstrap/app.php)**
```php
return Application::configure(basePath: dirname(__DIR__))
    ->withExceptions(function (Exceptions $exceptions) {
        $exceptions->report(function (\Throwable $e) {
            if (app()->bound('sentry')) {
                app('sentry')->captureException($e);
            }
        });

        $exceptions->render(function (\Symfony\Component\HttpKernel\Exception\NotFoundHttpException $e) {
            return response()->view('errors.404', [], 404);
        });

        $exceptions->render(function (\Illuminate\Auth\AuthenticationException $e) {
            if (request()->expectsJson()) {
                return response()->json(['message' => 'Unauthenticated'], 401);
            }
            return redirect()->guest(route('login'));
        });
    })
    ->create();
```

**deploy.php — Production Configuration Script**
```php
<?php
// deployment/config.php

$productionConfig = [
    'APP_ENV=production',
    'APP_DEBUG=false',
    'APP_URL=https://example.com',
    'LOG_CHANNEL=daily',
    'LOG_LEVEL=error',
    'SESSION_DRIVER=redis',
    'CACHE_DRIVER=redis',
    'QUEUE_CONNECTION=redis',
];

$envContent = file_get_contents(base_path('.env'));

foreach ($productionConfig as $line) {
    [$key, $value] = explode('=', $line, 2);
    $envContent = preg_replace("/^{$key}=.*/m", $line, $envContent);
}

file_put_contents(base_path('.env.production'), $envContent);
```

## Cara Integrasi & Pengujian
Set `APP_DEBUG=false` dan `APP_ENV=production` di .env. Jalankan `php artisan config:cache`. Verifikasi bahwa error page kustom muncul (bukan stack trace) saat terjadi error.
