# 483. Cara Mengimplementasikan Authorization yang Granular Menggunakan Policy

## Definisi & Target
Policy adalah class yang mengatur logika otorisasi untuk model tertentu. Targetnya adalah memastikan hanya user yang berhak yang dapat melakukan aksi tertentu (view, create, update, delete) pada resource.

## Komponen yang Terlibat
- Artisan make:policy command
- Policy class methods
- Gate facade
- Blade @can directive
- Controller authorization

## Perintah Artisan CLI
```bash
php artisan make:policy PostPolicy --model=Post
php artisan make:policy UserPolicy --model=User
```

## Kode Implementasi (Per File)

**Policy (app/Policies/PostPolicy.php)**
```php
namespace App\Policies;

use App\Models\Post;
use App\Models\User;

class PostPolicy
{
    public function viewAny(User $user): bool
    {
        return true;
    }

    public function view(User $user, Post $post): bool
    {
        return $user->id === $post->user_id || $user->isAdmin();
    }

    public function create(User $user): bool
    {
        return $user->hasVerifiedEmail();
    }

    public function update(User $user, Post $post): bool
    {
        return $user->id === $post->user_id;
    }

    public function delete(User $user, Post $post): bool
    {
        return $user->id === $post->user_id || $user->isAdmin();
    }

    public function restore(User $user, Post $post): bool
    {
        return $user->isAdmin();
    }

    public function forceDelete(User $user, Post $post): bool
    {
        return $user->isAdmin();
    }

    public function publish(User $user, Post $post): bool
    {
        return $user->id === $post->user_id && $post->status === 'draft';
    }
}
```

**Register Policy (app/Providers/AuthServiceProvider.php)**
```php
namespace App\Providers;

use App\Models\Post;
use App\Models\User;
use App\Policies\PostPolicy;
use App\Policies\UserPolicy;
use Illuminate\Foundation\Support\Providers\AuthServiceProvider as ServiceProvider;

class AuthServiceProvider extends ServiceProvider
{
    protected $policies = [
        Post::class => PostPolicy::class,
        User::class => UserPolicy::class,
    ];

    public function boot(): void
    {
        $this->registerPolicies();
    }
}
```

**Controller dengan Authorization (app/Http/Controllers/PostController.php)**
```php
namespace App\Http\Controllers;

use App\Models\Post;
use App\Http\Requests\StorePostRequest;

class PostController extends Controller
{
    public function index()
    {
        $this->authorize('viewAny', Post::class);
        return Post::where('user_id', auth()->id())->get();
    }

    public function store(StorePostRequest $request)
    {
        $this->authorize('create', Post::class);
        return Post::create($request->validated() + ['user_id' => auth()->id()]);
    }

    public function update(StorePostRequest $request, Post $post)
    {
        $this->authorize('update', $post);
        $post->update($request->validated());
        return $post;
    }

    public function destroy(Post $post)
    {
        $this->authorize('delete', $post);
        $post->delete();
        return response()->noContent();
    }

    public function publish(Post $post)
    {
        $this->authorize('publish', $post);
        $post->update(['status' => 'published']);
        return $post;
    }
}
```

**Blade @can Directive**
```blade
@can('update', $post)
    <a href="{{ route('posts.edit', $post) }}">Edit</a>
@endcan

@cannot('delete', $post)
    <span class="text-gray-400">Tidak bisa menghapus</span>
@endcannot

{{-- Untuk @can di luar model --}}
@can('viewAny', App\Models\Post::class)
    <a href="{{ route('posts.index') }}">Lihat Semua Post</a>
@endcan
```

**Policy dengan Super Admin**
```php
namespace App\Policies;

use App\Models\User;

trait AdminOverride
{
    public function before(User $user): ?bool
    {
        if ($user->role === 'super_admin') {
            return true;
        }
        return null;
    }
}

class PostPolicy
{
    use AdminOverride;

    // Method policy lainnya...
}
```

## Cara Integrasi & Pengujian
Buat Policy untuk setiap model yang memiliki logika otorisasi spesifik. Gunakan `$this->authorize()` di controller dan `@can` di Blade. Untuk super admin, override metode `before` untuk memberikan akses penuh.
