# 477. Cara Memastikan Semua Input Divalidasi dan Disanitasi Sebelum Diproses

## Definisi & Target
Validasi input memastikan data yang masuk sesuai format yang diharapkan, sementara sanitasi membersihkan data berbahaya. Targetnya adalah mencegah data kosong, invalid, atau berbahaya masuk ke sistem.

## Komponen yang Terlibat
- Form Request validation
- Laravel validation rules
- Input sanitization helpers
- Middleware TrimStrings

## Perintah Artisan CLI
```bash
php artisan make:request StoreUserRequest
php artisan make:request UpdateProfileRequest
```

## Kode Implementasi (Per File)

**Form Request (app/Http/Requests/StoreUserRequest.php)**
```php
namespace App\Http\Requests;

use Illuminate\Foundation\Http\FormRequest;

class StoreUserRequest extends FormRequest
{
    public function authorize(): bool
    {
        return true;
    }

    public function rules(): array
    {
        return [
            'name' => 'required|string|max:255|regex:/^[a-zA-Z\s]+$/',
            'email' => 'required|email:filter|max:255|unique:users',
            'password' => 'required|string|min:8|max:100|confirmed',
            'phone' => 'nullable|string|regex:/^\+?[\d\s()-]{8,20}$/',
            'bio' => 'nullable|string|max:1000',
            'birth_date' => 'nullable|date|before:today|after:1900-01-01',
            'website' => 'nullable|url|max:255',
        ];
    }

    public function messages(): array
    {
        return [
            'name.regex' => 'Nama hanya boleh mengandung huruf dan spasi.',
            'password.min' => 'Password minimal 8 karakter.',
            'website.url' => 'Format URL tidak valid.',
        ];
    }

    protected function prepareForValidation(): void
    {
        $this->merge([
            'email' => strtolower(trim($this->email)),
        ]);
    }
}
```

**Controller dengan Sanitasi (app/Http/Controllers/UserController.php)**
```php
namespace App\Http\Controllers;

use App\Http\Requests\StoreUserRequest;
use App\Models\User;
use Illuminate\Support\Facades\Hash;

class UserController extends Controller
{
    public function store(StoreUserRequest $request)
    {
        $validated = $request->validated();

        $validated['password'] = Hash::make($validated['password']);
        $validated['name'] = strip_tags($validated['name']);
        $validated['bio'] = strip_tags($validated['bio'] ?? '');

        $user = User::create($validated);

        return response()->json($user, 201);
    }
}
```

**Sanitasi HTML Output di Blade**
```blade
{{-- Blade auto-escapes HTML --}}
<p>{{ $user->bio }}</p>

{{-- Untuk konten yang memang perlu HTML, gunakan strip_tags --}}
<p>{!! strip_tags($user->bio, '<b><i><u>') !!}</p>
```

**Global Middleware Trimming (bootstrap/app.php)**
```php
->withMiddleware(function (Middleware $middleware) {
    $middleware->append(\Illuminate\Foundation\Http\Middleware\TrimStrings::class);
    $middleware->append(\Illuminate\Foundation\Http\Middleware\ConvertEmptyStringsToNull::class);
})
```

## Cara Integrasi & Pengujian
Gunakan Form Request untuk setiap input yang masuk. Validasi di sisi server meskipun sudah ada validasi client-side. Sanitasi output di Blade dengan escaping default `{{ }}`.
