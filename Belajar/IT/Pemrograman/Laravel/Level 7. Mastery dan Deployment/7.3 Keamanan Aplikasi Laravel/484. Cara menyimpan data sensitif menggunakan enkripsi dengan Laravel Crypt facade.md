# 484. Cara Menyimpan Data Sensitif Menggunakan Enkripsi dengan Laravel Crypt Facade

## Definisi & Target
Laravel Crypt facade menyediakan enkripsi/dekripsi menggunakan AES-256-CBC atau AES-256-GCM dengan key dari APP_KEY. Targetnya adalah melindungi data sensitif seperti nomor KTP, nomor rekening, atau data pribadi lainnya.

## Komponen yang Terlibat
- `Illuminate\Support\Facades\Crypt`
- APP_KEY pada .env
- Eloquent custom casting
- OpenSSL PHP extension

## Perintah Artisan CLI
```bash
php artisan key:generate
```

## Kode Implementasi (Per File)

**Model dengan Encrypted Casting (app/Models/User.php)**
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Factories\HasFactory;

class User extends Model
{
    use HasFactory;

    protected $fillable = [
        'name', 'email', 'password',
        'phone', 'id_card_number', 'bank_account',
    ];

    protected $hidden = [
        'password', 'id_card_number', 'bank_account',
    ];

    protected function casts(): array
    {
        return [
            'password' => 'hashed',
            'id_card_number' => 'encrypted',
            'bank_account' => 'encrypted',
            'phone' => 'encrypted',
        ];
    }
}
```

**Custom Encrypted Cast (app/Casts/Encrypted.php)**
```php
namespace App\Casts;

use Illuminate\Contracts\Database\Eloquent\CastsAttributes;
use Illuminate\Support\Facades\Crypt;

class Encrypted implements CastsAttributes
{
    public function get($model, string $key, $value, array $attributes): ?string
    {
        if ($value === null) {
            return null;
        }
        return Crypt::decryptString($value);
    }

    public function set($model, string $key, $value, array $attributes): ?string
    {
        if ($value === null) {
            return null;
        }
        return Crypt::encryptString($value);
    }
}
```

**Manual Enkripsi/Dekripsi (app/Services/EncryptionService.php)**
```php
namespace App\Services;

use Illuminate\Support\Facades\Crypt;

class EncryptionService
{
    public function encryptSensitiveData(array $data): array
    {
        $sensitiveFields = ['id_card', 'bank_account', 'ssn'];

        foreach ($data as $key => $value) {
            if (in_array($key, $sensitiveFields) && !empty($value)) {
                $data[$key] = Crypt::encryptString($value);
            }
        }

        return $data;
    }

    public function decryptSensitiveData(array $data): array
    {
        $sensitiveFields = ['id_card', 'bank_account', 'ssn'];

        foreach ($data as $key => $value) {
            if (in_array($key, $sensitiveFields) && !empty($value)) {
                $data[$key] = Crypt::decryptString($value);
            }
        }

        return $data;
    }
}
```

**Controller (app/Http/Controllers/UserDataController.php)**
```php
namespace App\Http\Controllers;

use App\Models\User;
use Illuminate\Http\Request;

class UserDataController extends Controller
{
    public function store(Request $request)
    {
        $validated = $request->validate([
            'id_card_number' => 'required|string',
            'bank_account' => 'required|string',
        ]);

        // Encrypted casting akan otomatis mengenkripsi
        $user = $request->user();
        $user->update($validated);

        return response()->json(['message' => 'Data tersimpan aman']);
    }

    public function show(Request $request)
    {
        // Encrypted casting akan otomatis mendekripsi
        return response()->json([
            'id_card_number' => $request->user()->id_card_number,
            'bank_account' => $request->user()->bank_account,
        ]);
    }
}
```

**Migration untuk Encrypted Column**
```php
Schema::table('users', function (Blueprint $table) {
    $table->text('id_card_number')->nullable()->after('phone');
    $table->text('bank_account')->nullable()->after('id_card_number');
});
```

**Query Tidak Bisa Mencari Data Terenkripsi**
```php
// Ini TIDAK akan bekerja karena data terenkripsi
$user = User::where('id_card_number', '1234567890')->first();

// Solusi: enkripsi kata kunci pencarian
$encrypted = Crypt::encryptString('1234567890');
$user = User::where('id_card_number', $encrypted)->first();
```

## Cara Integrasi & Pengujian
Gunakan `encrypted` casting untuk model attribute yang sensitif. Pastikan APP_KEY unik per environment. Data terenkripsi tidak bisa dicari dengan query biasa — pertimbangkan indexed encrypted search untuk kebutuhan pencarian.
