# 489. Cara Melakukan Security Testing Dasar pada Aplikasi Laravel

## Definisi & Target
Security testing memvalidasi bahwa aplikasi tahan terhadap serangan umum. Targetnya adalah mengidentifikasi celah keamanan seperti CSRF, XSS, SQL injection, dan autentikasi yang lemah sebelum aplikasi digunakan.

## Komponen yang Terlibat
- PHPUnit feature test
- OWASP ZAP (opsional)
- burpsuite (opsional)
- Manual security checklist

## Perintah Artisan CLI
```bash
php artisan make:test SecurityTest
```

## Kode Implementasi (Per File)

**Security Feature Test (tests/Feature/SecurityTest.php)**
```php
namespace Tests\Feature;

use Tests\TestCase;
use App\Models\User;
use Illuminate\Foundation\Testing\RefreshDatabase;

class SecurityTest extends TestCase
{
    use RefreshDatabase;

    public function test_csrf_protection_on_forms()
    {
        $response = $this->post('/login', [
            'email' => 'test@test.com',
            'password' => 'password',
        ]);

        $response->assertStatus(419);
    }

    public function test_authentication_required()
    {
        $response = $this->getJson('/api/users');
        $response->assertStatus(401);
    }

    public function test_xss_prevention()
    {
        $admin = User::factory()->admin()->create();
        $payload = '<script>alert("XSS")</script>';

        $response = $this->actingAs($admin)
            ->post('/api/posts', [
                'title' => $payload,
                'body' => $payload,
            ]);

        $response->assertStatus(201);

        $this->assertStringNotContainsString(
            '<script>',
            $response->json('title')
        );
    }

    public function test_sql_injection_prevention()
    {
        $response = $this->getJson('/api/users?name=" OR 1=1 --');
        $response->assertStatus(401);
    }

    public function test_rate_limiting()
    {
        for ($i = 0; $i < 10; $i++) {
            $this->post('/login', [
                'email' => 'test@test.com',
                'password' => 'wrong',
            ]);
        }

        $response = $this->post('/login', [
            'email' => 'test@test.com',
            'password' => 'wrong',
        ]);

        $response->assertStatus(429);
    }

    public function test_unauthorized_access()
    {
        $user = User::factory()->create();
        $otherPost = Post::factory()->create();

        $response = $this->actingAs($user)
            ->deleteJson("/api/posts/{$otherPost->id}");

        $response->assertStatus(403);
    }

    public function test_mass_assignment_protection()
    {
        $user = User::factory()->create();

        $response = $this->actingAs($user)
            ->putJson('/api/profile', [
                'email' => 'admin@evil.com',
                'role' => 'admin',
            ]);

        $this->assertNotEquals('admin', $user->fresh()->role);
    }
}
```

**Security Helper (app/Helpers/SecurityHelper.php)**
```php
<?php

if (!function_exists('is_safe_url')) {
    function is_safe_url(string $url): bool
    {
        $parsed = parse_url($url);

        if (!isset($parsed['host'])) {
            return false;
        }

        $allowedHosts = [
            parse_url(config('app.url'), PHP_URL_HOST),
        ];

        return in_array($parsed['host'], $allowedHosts);
    }
}
```

**Open Redirect Test**
```php
public function test_no_open_redirect()
{
    $response = $this->get('/redirect?to=https://evil.com');
    $response->assertRedirect();

    $redirectUrl = $response->headers->get('Location');
    $this->assertStringStartsWith(config('app.url'), $redirectUrl);
}
```

## Cara Integrasi & Pengujian
Jalankan security test sebagai bagian dari test suite reguler. Gunakan OWASP ZAP secara periodik untuk automated scanning. Lakukan penetration testing manual setiap rilis major.
