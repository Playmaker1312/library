# 480. Cara Mencegah XSS Menggunakan Blade Escaping dan Content Security Policy

## Definisi & Target
XSS (Cross-Site Scripting) terjadi ketika skrip jahat disisipkan ke halaman web. Blade secara otomatis meng-escape output dengan `{{ }}`. Content Security Policy (CSP) memberikan lapisan proteksi tambahan. Targetnya adalah memblokir eksekusi skrip yang tidak sah di browser pengguna.

## Komponen yang Terlibat
- Blade templating engine (`{{ }}` vs `{!! !!}`)
- Content Security Policy header
- Middleware untuk CSP
- Purifier package untuk HTML yang aman

## Perintah Artisan CLI
```bash
php artisan make:middleware ContentSecurityPolicy
```

## Kode Implementasi (Per File)

**Blade Escaping — Aman vs Tidak Aman**
```blade
{{-- AMAN — Blade auto-escapes HTML --}}
<p>{{ $user->bio }}</p>

{{-- TIDAK AMAN — Raw output, rentan XSS --}}
<p>{!! $user->bio !!}</p>

{{-- Alternatif aman untuk HTML yang diizinkan --}}
<p>{!! strip_tags($user->bio, '<b><i><u>') !!}</p>
```

**CSP Middleware (app/Http/Middleware/ContentSecurityPolicy.php)**
```php
namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class ContentSecurityPolicy
{
    public function handle(Request $request, Closure $next): Response
    {
        $response = $next($request);

        $response->headers->set('Content-Security-Policy', $this->getPolicy());

        return $response;
    }

    private function getPolicy(): string
    {
        $nonce = base64_encode(random_bytes(16));

        return implode('; ', [
            "default-src 'self'",
            "script-src 'self' 'nonce-{$nonce}' https://cdn.example.com",
            "style-src 'self' 'unsafe-inline' https://fonts.googleapis.com",
            "img-src 'self' https: data: blob:",
            "font-src 'self' https://fonts.gstatic.com",
            "connect-src 'self' https://api.example.com",
            "frame-src 'none'",
            "object-src 'none'",
            "base-uri 'self'",
            "form-action 'self'",
        ]);
    }
}
```

**Nonce untuk Inline Script di Blade**
```blade
{{-- Mengirim nonce ke view --}}
@php $cspNonce = base64_encode(random_bytes(16)) @endphp

{{-- Inline script dengan nonce --}}
<script nonce="{{ $cspNonce }}">
    console.log('This script is allowed by CSP');
</script>
```

**Purifier untuk Input HTML (app/Services/HtmlPurifierService.php)**
```php
namespace App\Services;

use HTMLPurifier;
use HTMLPurifier_Config;

class HtmlPurifierService
{
    private HTMLPurifier $purifier;

    public function __construct()
    {
        $config = HTMLPurifier_Config::createDefault();
        $config->set('HTML.Allowed', 'p,b,i,u,a[href],ul,ol,li,br');
        $config->set('HTML.TargetBlank', true);
        $config->set('Attr.AllowedRel', ['nofollow', 'noopener']);

        $this->purifier = new HTMLPurifier($config);
    }

    public function purify(?string $html): string
    {
        if (empty($html)) {
            return '';
        }
        return $this->purifier->purify($html);
    }
}
```

**Register CSP Middleware (bootstrap/app.php)**
```php
return Application::configure(basePath: dirname(__DIR__))
    ->withMiddleware(function (Middleware $middleware) {
        $middleware->append(\App\Http\Middleware\ContentSecurityPolicy::class);
    })
    ->create();
```

## Cara Integrasi & Pengujian
Gunakan `{{ }}` sebagai default untuk semua output Blade. Pasang CSP header untuk blokir XSS di level browser. Tes dengan memasukkan `<script>alert('XSS')</script>` ke form — pastikan tidak tereksekusi.
