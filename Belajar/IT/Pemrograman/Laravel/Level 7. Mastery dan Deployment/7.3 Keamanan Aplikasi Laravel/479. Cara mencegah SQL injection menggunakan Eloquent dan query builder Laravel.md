# 479. Cara Mencegah SQL Injection Menggunakan Eloquent dan Query Builder Laravel

## Definisi & Target
SQL injection terjadi ketika input pengguna dimasukkan langsung ke query SQL tanpa dibersihkan. Eloquent ORM dan Query Builder Laravel menggunakan parameter binding sehingga input otomatis di-escape. Targetnya adalah memastikan tidak ada celah SQL injection di seluruh aplikasi.

## Komponen yang Terlibat
- Eloquent ORM
- Query Builder
- Parameter binding (PDO prepared statements)
- Raw expressions (hati-hati)

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

**Aman — Menggunakan Eloquent**
```php
// Aman — parameter binding otomatis
$user = User::where('email', $request->input('email'))->first();

// Aman — binding multiple conditions
$users = User::where('name', 'like', "%{$search}%")
             ->where('age', '>', $minAge)
             ->get();
```

**Aman — Menggunakan Query Builder**
```php
// Aman — parameter binding otomatis
$users = DB::table('users')
    ->where('email', $request->email)
    ->whereIn('role', ['admin', 'editor'])
    ->get();

// Aman — binding untuk order by juga
$users = DB::table('users')
    ->orderBy($request->sort ?? 'created_at', $request->direction ?? 'asc')
    ->get();
```

**Tidak Aman — Raw SQL Tanpa Binding**
```php
// TIDAK AMAN — jangan lakukan ini
$users = DB::select("SELECT * FROM users WHERE email = '{$request->email}'");

// AMAN — gunakan binding
$users = DB::select("SELECT * FROM users WHERE email = ?", [$request->email]);
```

**Raw Expressions dengan Binding (app/Reports/UserReport.php)**
```php
namespace App\Reports;

use Illuminate\Support\Facades\DB;

class UserReport
{
    public function getMonthlyGrowth(int $year)
    {
        return DB::table('users')
            ->selectRaw('MONTH(created_at) as month, COUNT(*) as total')
            ->whereRaw('YEAR(created_at) = ?', [$year])
            ->groupByRaw('MONTH(created_at)')
            ->orderByRaw('MONTH(created_at)')
            ->get();
    }
}
```

**Validasi Input Sebelum digunakan di Order By**
```php
use Illuminate\Validation\Rule;

// Validasi kolom yang diizinkan
$request->validate([
    'sort' => ['nullable', Rule::in(['name', 'email', 'created_at'])],
    'direction' => ['nullable', Rule::in(['asc', 'desc'])],
]);

$users = User::orderBy(
    $request->sort ?? 'created_at',
    $request->direction ?? 'asc'
)->get();
```

## Cara Integrasi & Pengujian
Selalu gunakan Eloquent atau Query Builder — jangan menulis raw SQL dengan string interpolation. Jika terpaksa menggunakan raw SQL, gunakan parameter binding (`?` atau `:name`). Lakukan code review untuk memastikan tidak ada celah SQL injection.
