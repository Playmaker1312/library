# 488. Cara Mengimplementasikan Logging Aktivitas Mencurigakan Menggunakan Spatie Activity Log

## Definisi & Target
Spatie Laravel Activity Log mencatat aktivitas pengguna secara detail — siapa, apa, kapan, dan data apa yang berubah. Targetnya adalah menyediakan audit trail untuk mendeteksi aktivitas mencurigakan dan compliance.

## Komponen yang Terlibat
- spatie/laravel-activitylog package
- Activity model
- Activity log middleware
- Custom loggers

## Perintah Artisan CLI
```bash
composer require spatie/laravel-activitylog
php artisan vendor:publish --provider="Spatie\Activitylog\ActivitylogServiceProvider" --tag="migrations"
php artisan vendor:publish --provider="Spatie\Activitylog\ActivitylogServiceProvider" --tag="config"
php artisan migrate
```

## Kode Implementasi (Per File)

**Model dengan Logging Otomatis (app/Models/Post.php)**
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Spatie\Activitylog\Traits\LogsActivity;
use Spatie\Activitylog\LogOptions;

class Post extends Model
{
    use LogsActivity;

    protected $fillable = ['title', 'body', 'status'];

    public function getActivitylogOptions(): LogOptions
    {
        return LogOptions::defaults()
            ->logOnly(['title', 'body', 'status'])
            ->logOnlyDirty()
            ->dontSubmitEmptyLogs()
            ->useLogName('post')
            ->setDescriptionForEvent(fn (string $eventName) => "Post {$eventName}");
    }
}
```

**Manual Logging (app/Http/Controllers/AuthController.php)**
```php
namespace App\Http\Controllers;

use Illuminate\Http\Request;
use Illuminate\Support\Facades\Hash;
use Spatie\Activitylog\Models\Activity;

class AuthController extends Controller
{
    public function login(Request $request)
    {
        $credentials = $request->validate([
            'email' => 'required|email',
            'password' => 'required',
        ]);

        if (auth()->attempt($credentials)) {
            activity()
                ->causedBy(auth()->user())
                ->withProperties(['ip' => $request->ip(), 'user_agent' => $request->userAgent()])
                ->log('login_success');

            return redirect()->intended();
        }

        activity()
            ->withProperties([
                'email' => $request->email,
                'ip' => $request->ip(),
                'user_agent' => $request->userAgent(),
            ])
            ->log('login_failed');

        return back()->withErrors(['email' => 'Invalid credentials']);
    }
}
```

**Custom Activity Logger (app/Services/ActivityLoggerService.php)**
```php
namespace App\Services;

use Illuminate\Http\Request;

class ActivityLoggerService
{
    public function logSuspiciousActivity(Request $request, string $reason): void
    {
        activity()
            ->causedBy($request->user())
            ->withProperties([
                'ip' => $request->ip(),
                'user_agent' => $request->userAgent(),
                'method' => $request->method(),
                'url' => $request->fullUrl(),
                'reason' => $reason,
                'input' => $request->except(['password', 'password_confirmation']),
            ])
            ->useLog('security')
            ->log('suspicious_activity');
    }

    public function logDataChange(string $model, int $modelId, array $changes, ?string $description = null): void
    {
        activity()
            ->causedBy(auth()->user())
            ->performedOn($model::find($modelId))
            ->withProperties($changes)
            ->useLog('data_change')
            ->log($description ?? "{$model} changed");
    }
}
```

**Middleware Deteksi Aktivitas Mencurigakan (app/Http/Middleware/DetectSuspiciousActivity.php)**
```php
namespace App\Http\Middleware;

use App\Services\ActivityLoggerService;
use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class DetectSuspiciousActivity
{
    public function __construct(
        private ActivityLoggerService $logger
    ) {}

    public function handle(Request $request, Closure $next): Response
    {
        if ($this->isSuspicious($request)) {
            $this->logger->logSuspiciousActivity($request, 'multiple_requests_in_short_time');
        }

        return $next($request);
    }

    private function isSuspicious(Request $request): bool
    {
        $key = 'request_count:' . $request->ip();
        $count = cache()->get($key, 0);
        cache()->put($key, $count + 1, 60);

        return $count > 100;
    }
}
```

**Display Activity Log (app/Http/Controllers/Admin/ActivityLogController.php)**
```php
namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use Spatie\Activitylog\Models\Activity;

class ActivityLogController extends Controller
{
    public function index()
    {
        $activities = Activity::with('causer')
            ->latest()
            ->paginate(50);

        return view('admin.activity-log', compact('activities'));
    }

    public function filterByType(string $logName)
    {
        $activities = Activity::with('causer')
            ->where('log_name', $logName)
            ->latest()
            ->paginate(50);

        return view('admin.activity-log', compact('activities'));
    }
}
```

## Cara Integrasi & Pengujian
Gunakan trait `LogsActivity` pada model kritis. Buat middleware untuk deteksi anomali. Pantau aktivitas mencurigakan melalui dashboard admin yang menampilkan log.
