# 508. Cara Menggunakan Livewire untuk Membuat Data Table dengan Sorting, Filter, dan Pagination

## Definisi & Target
Data table interaktif dengan sorting, filter, dan pagination adalah kebutuhan umum di aplikasi admin. Livewire memungkinkan semua interaksi ini tanpa reload halaman.

## Komponen yang Terlibat
- Livewire component
- WithPagination trait
- Query string tracking
- Filter state
- Event handling

## Perintah Artisan CLI
```bash
php artisan make:livewire UsersTable
```

## Kode Implementasi (Per File)

**Data Table Component (app/Livewire/UsersTable.php)**
```php
namespace App\Livewire;

use App\Models\User;
use Livewire\Component;
use Livewire\WithPagination;
use Livewire\Attributes\Url;

class UsersTable extends Component
{
    use WithPagination;

    #[Url(history: true)]
    public string $search = '';

    #[Url(history: true)]
    public string $sortField = 'created_at';

    #[Url(history: true)]
    public string $sortDirection = 'desc';

    public string $roleFilter = '';
    public string $statusFilter = '';
    public int $perPage = 10;

    protected $queryString = [
        'search' => ['except' => ''],
        'sortField' => ['except' => 'created_at'],
        'sortDirection' => ['except' => 'desc'],
    ];

    public function sortBy(string $field): void
    {
        if ($this->sortField === $field) {
            $this->sortDirection = $this->sortDirection === 'asc' ? 'desc' : 'asc';
        } else {
            $this->sortField = $field;
            $this->sortDirection = 'asc';
        }

        $this->resetPage();
    }

    public function updatingSearch(): void
    {
        $this->resetPage();
    }

    public function updatingRoleFilter(): void
    {
        $this->resetPage();
    }

    public function render()
    {
        $users = User::when($this->search, function ($query) {
            $query->where(function ($q) {
                $q->where('name', 'like', "%{$this->search}%")
                  ->orWhere('email', 'like', "%{$this->search}%");
            });
        })
        ->when($this->roleFilter, fn ($q) => $q->where('role', $this->roleFilter))
        ->when($this->statusFilter, fn ($q) => $q->where('is_active', $this->statusFilter === 'active'))
        ->orderBy($this->sortField, $this->sortDirection)
        ->paginate($this->perPage);

        return view('livewire.users-table', [
            'users' => $users,
        ]);
    }
}
```

**Livewire View (resources/views/livewire/users-table.blade.php)**
```blade
<div>
    <div class="flex gap-4 mb-4">
        <input wire:model.live.debounce.300ms="search" placeholder="Cari nama atau email..."
               class="border p-2 rounded flex-1">

        <select wire:model.live="roleFilter" class="border p-2 rounded">
            <option value="">Semua Role</option>
            <option value="admin">Admin</option>
            <option value="user">User</option>
        </select>

        <select wire:model.live="statusFilter" class="border p-2 rounded">
            <option value="">Semua Status</option>
            <option value="active">Aktif</option>
            <option value="inactive">Nonaktif</option>
        </select>

        <select wire:model.live="perPage" class="border p-2 rounded">
            <option value="10">10</option>
            <option value="25">25</option>
            <option value="50">50</option>
        </select>
    </div>

    <table class="w-full border-collapse">
        <thead>
            <tr class="bg-gray-100">
                <th wire:click="sortBy('name')" class="cursor-pointer p-2 text-left">
                    Nama @include('components.sort-icon', ['field' => 'name'])
                </th>
                <th wire:click="sortBy('email')" class="cursor-pointer p-2 text-left">
                    Email @include('components.sort-icon', ['field' => 'email'])
                </th>
                <th wire:click="sortBy('role')" class="cursor-pointer p-2 text-left">
                    Role @include('components.sort-icon', ['field' => 'role'])
                </th>
                <th wire:click="sortBy('created_at')" class="cursor-pointer p-2 text-left">
                    Bergabung @include('components.sort-icon', ['field' => 'created_at'])
                </th>
                <th class="p-2">Aksi</th>
            </tr>
        </thead>
        <tbody>
            @forelse ($users as $user)
                <tr class="border-t hover:bg-gray-50">
                    <td class="p-2">{{ $user->name }}</td>
                    <td class="p-2">{{ $user->email }}</td>
                    <td class="p-2">
                        <span class="px-2 py-1 rounded text-sm
                            {{ $user->role === 'admin' ? 'bg-purple-100 text-purple-800' : 'bg-gray-100' }}">
                            {{ $user->role }}
                        </span>
                    </td>
                    <td class="p-2">{{ $user->created_at->format('d M Y') }}</td>
                    <td class="p-2">
                        <button wire:click="$dispatch('edit-user', { id: {{ $user->id }} })"
                                class="text-blue-600">Edit</button>
                    </td>
                </tr>
            @empty
                <tr>
                    <td colspan="5" class="p-4 text-center text-gray-500">
                        Tidak ada data ditemukan.
                    </td>
                </tr>
            @endforelse
        </tbody>
    </table>

    <div class="mt-4">
        {{ $users->links() }}
    </div>
</div>
```

**Export Action (app/Livewire/UsersTable.php)**
```php
use App\Exports\UsersExport;
use Maatwebsite\Excel\Facades\Excel;

public function exportExcel()
{
    return Excel::download(new UsersExport(
        $this->search,
        $this->roleFilter,
        $this->statusFilter
    ), 'users.xlsx');
}
```

## Cara Integrasi & Pengujian
Gunakan `#[Url]` attribute untuk persist filter di URL. Method `updatingX()` untuk reset pagination saat filter berubah. Pagination tetap menggunakan `->links()` seperti Blade biasa.
