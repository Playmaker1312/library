# 518. Cara Menggunakan Spatie Laravel Activity Log untuk Audit Trail yang Lengkap

## Definisi & Target
Spatie Activity Log mencatat setiap aktivitas penting di aplikasi — perubahan data, login, aksi admin. Targetnya adalah menyediakan audit trail yang lengkap untuk compliance, debugging, dan keamanan.

## Komponen yang Terlibat
- spatie/laravel-activitylog package
- Activity model
- LogsActivity trait
- Activity logger facade

## Perintah Artisan CLI
```bash
composer require spatie/laravel-activitylog
php artisan vendor:publish --provider="Spatie\Activitylog\ActivitylogServiceProvider" --tag="migrations"
php artisan vendor:publish --provider="Spatie\Activitylog\ActivitylogServiceProvider" --tag="config"
php artisan migrate
```

## Kode Implementasi (Per File)

**Model Audit (app/Models/Order.php)**
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Spatie\Activitylog\Traits\LogsActivity;
use Spatie\Activitylog\LogOptions;

class Order extends Model
{
    use LogsActivity;

    protected $fillable = [
        'user_id', 'invoice_number', 'total',
        'status', 'payment_method', 'notes',
    ];

    protected $casts = [
        'total' => 'decimal:2',
    ];

    public function getActivitylogOptions(): LogOptions
    {
        return LogOptions::defaults()
            ->logAll()
            ->logOnlyDirty()
            ->dontSubmitEmptyLogs()
            ->logOnly(['status', 'total', 'invoice_number'])
            ->setDescriptionForEvent(fn (string $eventName) => "Order {$eventName}")
            ->useLogName('order');
    }
}
```

**Custom Activity Logger (app/Logging/ActivityLogger.php)**
```php
namespace App\Logging;

use App\Models\User;
use Illuminate\Http\Request;

class ActivityLogger
{
    public function logLogin(User $user, Request $request): void
    {
        activity()
            ->causedBy($user)
            ->withProperties([
                'ip' => $request->ip(),
                'user_agent' => $request->userAgent(),
                'browser' => $request->header('User-Agent'),
            ])
            ->event('login')
            ->log('User logged in');
    }

    public function logLogout(User $user, Request $request): void
    {
        activity()
            ->causedBy($user)
            ->withProperties(['ip' => $request->ip()])
            ->event('logout')
            ->log('User logged out');
    }

    public function logFailedLogin(string $email, Request $request): void
    {
        activity()
            ->withProperties([
                'email' => $email,
                'ip' => $request->ip(),
                'user_agent' => $request->userAgent(),
            ])
            ->event('login_failed')
            ->log('Failed login attempt');
    }

    public function logSensitiveAction(User $user, string $action, array $data = []): void
    {
        activity()
            ->causedBy($user)
            ->withProperties($data)
            ->useLog('security')
            ->event($action)
            ->log("Sensitive action: {$action}");
    }

    public function logDataExport(User $user, string $type, array $filters = []): void
    {
        activity()
            ->causedBy($user)
            ->withProperties([
                'export_type' => $type,
                'filters' => $filters,
                'timestamp' => now(),
            ])
            ->useLog('export')
            ->event('export')
            ->log("Data exported: {$type}");
    }
}
```

**Middleware Logging (app/Http/Middleware/LogActivityMiddleware.php)**
```php
namespace App\Http\Middleware;

use App\Logging\ActivityLogger;
use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class LogActivityMiddleware
{
    public function __construct(
        private ActivityLogger $logger
    ) {}

    public function handle(Request $request, Closure $next): Response
    {
        $response = $next($request);

        if ($request->user() && $request->isMethod('post')) {
            $this->logger->logSensitiveAction(
                $request->user(),
                $request->method() . ' ' . $request->path(),
                ['input' => $request->except(['password', 'password_confirmation'])]
            );
        }

        return $response;
    }
}
```

**Activity Log Dashboard (app/Http/Controllers/Admin/ActivityLogController.php)**
```php
namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use Spatie\Activitylog\Models\Activity;
use Illuminate\Http\Request;

class ActivityLogController extends Controller
{
    public function index(Request $request)
    {
        $activities = Activity::with('causer', 'subject')
            ->when($request->log_name, fn ($q) => $q->where('log_name', $request->log_name))
            ->when($request->event, fn ($q) => $q->where('event', $request->event))
            ->when($request->causer_id, fn ($q) => $q->where('causer_id', $request->causer_id))
            ->when($request->date_from, fn ($q) => $q->whereDate('created_at', '>=', $request->date_from))
            ->when($request->date_to, fn ($q) => $q->whereDate('created_at', '<=', $request->date_to))
            ->latest()
            ->paginate(50);

        $logNames = Activity::distinct()->pluck('log_name');

        return view('admin.activity-log.index', compact('activities', 'logNames'));
    }

    public function show(Activity $activity)
    {
        $activity->load('causer', 'subject');

        return view('admin.activity-log.show', compact('activity'));
    }
}
```

**Event Subscriber (app/Listeners/UserEventSubscriber.php)**
```php
namespace App\Listeners;

use App\Logging\ActivityLogger;
use Illuminate\Auth\Events\Login;
use Illuminate\Auth\Events\Logout;
use Illuminate\Auth\Events\Failed;

class UserEventSubscriber
{
    public function __construct(
        private ActivityLogger $logger
    ) {}

    public function handleUserLogin(Login $event): void
    {
        $this->logger->logLogin($event->user, request());
    }

    public function handleUserLogout(Logout $event): void
    {
        $this->logger->logLogout($event->user, request());
    }

    public function handleFailedLogin(Failed $event): void
    {
        $this->logger->logFailedLogin($event->credentials['email'] ?? 'unknown', request());
    }

    public function subscribe($events): array
    {
        return [
            Login::class => 'handleUserLogin',
            Logout::class => 'handleUserLogout',
            Failed::class => 'handleFailedLogin',
        ];
    }
}
```

## Cara Integrasi & Pengujian
Register subscriber di EventServiceProvider. Gunakan trait `LogsActivity` pada model yang perlu diaudit. Monitor aktivitas melalui dashboard Activity Log.
