# 516. Cara Menggunakan Spatie Laravel Permission untuk Role dan Permission Management

## Definisi & Target
Spatie Laravel Permission menyediakan sistem role dan permission yang fleksibel. Targetnya adalah mengelola hak akses pengguna secara granular dengan assignment role dan permission langsung ke user.

## Komponen yang Terlibat
- spatie/laravel-permission package
- Role model
- Permission model
- Middleware dan Blade directives
- Gate integration

## Perintah Artisan CLI
```bash
composer require spatie/laravel-permission
php artisan vendor:publish --provider="Spatie\Permission\PermissionServiceProvider"
php artisan migrate
php artisan make:command CreateRolesAndPermissions
```

## Kode Implementasi (Per File)

**Role & Permission Seeder (database/seeders/RolePermissionSeeder.php)**
```php
namespace Database\Seeders;

use Illuminate\Database\Seeder;
use Spatie\Permission\Models\Role;
use Spatie\Permission\Models\Permission;

class RolePermissionSeeder extends Seeder
{
    public function run(): void
    {
        $permissions = [
            'view-users', 'create-users', 'edit-users', 'delete-users',
            'view-posts', 'create-posts', 'edit-posts', 'delete-posts',
            'view-reports', 'export-reports',
            'manage-settings',
        ];

        foreach ($permissions as $permission) {
            Permission::create(['name' => $permission]);
        }

        $superAdmin = Role::create(['name' => 'super-admin']);
        $superAdmin->givePermissionTo(Permission::all());

        $admin = Role::create(['name' => 'admin']);
        $admin->givePermissionTo([
            'view-users', 'view-posts', 'create-posts', 'edit-posts',
            'view-reports', 'export-reports',
        ]);

        $editor = Role::create(['name' => 'editor']);
        $editor->givePermissionTo([
            'view-posts', 'create-posts', 'edit-posts',
        ]);

        $user = Role::create(['name' => 'user']);
        $user->givePermissionTo([
            'view-posts', 'create-posts',
        ]);
    }
}
```

**Model User dengan Permission (app/Models/User.php)**
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Spatie\Permission\Traits\HasRoles;

class User extends Model
{
    use HasRoles;

    protected $fillable = ['name', 'email', 'password'];

    protected $hidden = ['password'];
}
```

**Controller Permission (app/Http/Controllers/Admin/PermissionController.php)**
```php
namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Models\User;
use Illuminate\Http\Request;
use Spatie\Permission\Models\Role;
use Spatie\Permission\Models\Permission;

class PermissionController extends Controller
{
    public function index()
    {
        $users = User::with('roles', 'permissions')->paginate(20);
        $roles = Role::with('permissions')->get();
        $permissions = Permission::all();

        return view('admin.permissions.index', compact('users', 'roles', 'permissions'));
    }

    public function assignRole(Request $request, User $user)
    {
        $validated = $request->validate(['role' => 'required|exists:roles,name']);
        $user->assignRole($validated['role']);

        return back()->with('success', 'Role assigned.');
    }

    public function removeRole(Request $request, User $user)
    {
        $user->removeRole($request->input('role'));
        return back()->with('success', 'Role removed.');
    }

    public function givePermission(Request $request, User $user)
    {
        $validated = $request->validate(['permission' => 'required|exists:permissions,name']);
        $user->givePermissionTo($validated['permission']);

        return back()->with('success', 'Permission granted.');
    }

    public function revokePermission(Request $request, User $user)
    {
        $user->revokePermissionTo($request->input('permission'));
        return back()->with('success', 'Permission revoked.');
    }
}
```

**Middleware (bootstrap/app.php)**
```php
return Application::configure(basePath: dirname(__DIR__))
    ->withMiddleware(function (Middleware $middleware) {
        $middleware->alias([
            'role' => \Spatie\Permission\Middleware\RoleMiddleware::class,
            'permission' => \Spatie\Permission\Middleware\PermissionMiddleware::class,
            'role_or_permission' => \Spatie\Permission\Middleware\RoleOrPermissionMiddleware::class,
        ]);
    })
    ->create();
```

**Routes dengan Middleware (routes/web.php)**
```php
Route::middleware(['auth', 'role:super-admin|admin'])->group(function () {

    Route::delete('/admin/users/{user}', [Admin\UserController::class, 'destroy']);
```

**Blade Directives**
```blade
@role('admin')
    <p>Konten untuk admin saja.</p>
@endrole

@hasrole('super-admin|admin')
    <p>Konten untuk admin dan super admin.</p>
@endhasrole

@can('edit-posts')
    <a href="{{ route('posts.edit', $post) }}">Edit</a>
@endcan

@canany(['create-posts', 'edit-posts'])
    <p>User bisa membuat atau edit posting.</p>
@endcanany

@unlessrole('editor')
    <p>Konten untuk non-editor.</p>
@endunlessrole
```

**Helper di Controller**
```php
// Cek role user
$user->hasRole('admin');
$user->hasAnyRole(['admin', 'editor']);
$user->hasAllRoles(['admin', 'editor']);

// Cek permission user
$user->hasPermissionTo('edit-posts');
$user->hasAnyPermission(['edit-posts', 'delete-posts']);

// Cek via Gate
Gate::before(function ($user) {
    if ($user->hasRole('super-admin')) {
        return true;
    }
});
```

## Cara Integrasi & Pengujian
Jalankan seeder untuk membuat role dan permission. Assign role via controller. Gunakan middleware `role:` atau `permission:` di routes. Gunakan `@role` dan `@can` di Blade.
