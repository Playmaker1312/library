# 510. Cara Menggunakan Alpine.js Bersama Livewire untuk Interaksi UI yang Lebih Kaya

## Definisi & Target
Alpine.js adalah JavaScript library ringan untuk interaktivitas frontend. Ketika dipadukan dengan Livewire, Alpine.js menangani animasi, dropdown, modal, tooltip, dan transisi UI — sementara Livewire menangani logika backend.

## Komponen yang Terlibat
- Alpine.js (built-in di Livewire 3)
- x-data, x-show, x-transition
- Livewire $wire object
- CSS transitions

## Perintah Artisan CLI
```bash
php artisan livewire:install
```

## Kode Implementasi (Per File)

**Alpine.js Modal dengan Livewire (resources/views/livewire/alpine-modal.blade.php)**
```blade
<div>
    <button x-data x-on:click="$wire.openCreateModal()"
            class="bg-blue-500 text-white px-4 py-2 rounded">
        Tambah Data
    </button>

    {{-- Modal dengan Alpine.js transisi --}}
    <div x-data="{ show: $wire.entangle('showModal') }"
         x-show="show"
         x-cloak
         x-transition:enter="transition ease-out duration-300"
         x-transition:enter-start="opacity-0"
         x-transition:enter-end="opacity-100"
         x-transition:leave="transition ease-in duration-200"
         x-transition:leave-start="opacity-100"
         x-transition:leave-end="opacity-0"
         class="fixed inset-0 z-50 flex items-center justify-center">

        <div x-show="show"
             x-transition:enter="transition ease-out duration-300"
             x-transition:enter-start="opacity-0 scale-90"
             x-transition:enter-end="opacity-100 scale-100"
             x-transition:leave="transition ease-in duration-200"
             x-transition:leave-start="opacity-100 scale-100"
             x-transition:leave-end="opacity-0 scale-90"
             x-on:click.outside="$wire.closeModal()"
             class="bg-white rounded-lg shadow-xl p-6 w-full max-w-md">

            <h2 class="text-xl font-bold mb-4">Form Data</h2>

            <form x-on:submit.prevent="$wire.save()">
                <input x-model="$wire.form.name" placeholder="Nama" class="w-full border p-2 mb-2">
                <input x-model="$wire.form.email" type="email" placeholder="Email" class="w-full border p-2 mb-4">

                <div class="flex justify-end gap-2">
                    <button type="button" x-on:click="$wire.closeModal()"
                            class="px-4 py-2 bg-gray-200 rounded">Batal</button>
                    <button type="submit"
                            class="px-4 py-2 bg-blue-500 text-white rounded"
                            x-text="$wire.isEditing ? 'Update' : 'Simpan'">
                    </button>
                </div>
            </form>
        </div>
    </div>
</div>
```

**Toast Notification dengan Alpine.js**
```blade
<div x-data="notification()"
     x-init="init"
     x-show="show"
     x-transition:enter="transition ease-out duration-300"
     x-transition:enter-start="opacity-0 translate-x-full"
     x-transition:enter-end="opacity-100 translate-x-0"
     x-transition:leave="transition ease-in duration-200"
     x-transition:leave-start="opacity-100 translate-x-0"
     x-transition:leave-end="opacity-0 translate-x-full"
     class="fixed top-4 right-4 px-6 py-3 rounded-lg shadow-lg"
     x-bind:class="{
         'bg-green-500 text-white': type === 'success',
         'bg-red-500 text-white': type === 'error',
         'bg-blue-500 text-white': type === 'info',
     }">
    <span x-text="message"></span>
</div>

<script>
document.addEventListener('alpine:init', () => {
    Alpine.data('notification', () => ({
        show: false,
        message: '',
        type: 'success',
        timer: null,

        init() {
            Livewire.on('notify', (data) => {
                this.message = data.message;
                this.type = data.type || 'success';
                this.show = true;

                clearTimeout(this.timer);
                this.timer = setTimeout(() => {
                    this.show = false;
                }, 3000);
            });
        }
    }));
});
</script>
```

**Drag and Drop dengan Alpine.js**
```blade
<div x-data="sortableList()" class="space-y-2">
    <template x-for="(item, index) in items" :key="item.id">
        <div x-on:dragover.prevent
             x-on:dragstart="dragStart(index)"
             x-on:drop="drop(index)"
             draggable="true"
             class="p-4 bg-white rounded shadow cursor-move hover:shadow-md transition-shadow">
            <span x-text="item.name"></span>
        </div>
    </template>
</div>

<script>
document.addEventListener('alpine:init', () => {
    Alpine.data('sortableList', () => ({
        items: [],
        dragIndex: null,

        init() {
            this.$wire.getItems().then(items => {
                this.items = items;
            });
        },

        dragStart(index) {
            this.dragIndex = index;
        },

        drop(index) {
            const item = this.items.splice(this.dragIndex, 1)[0];
            this.items.splice(index, 0, item);
            this.$wire.updateOrder(this.items.map(i => i.id));
        },
    }));
});
</script>
```

## Cara Integrasi & Pengujian
Gunakan `x-on:click="$wire.methodName()"` untuk memanggil method Livewire dari Alpine.js. Gunakan `$wire.entangle('property')` untuk binding dua arah. Transisi UI dikelola sepenuhnya oleh Alpine.js.
