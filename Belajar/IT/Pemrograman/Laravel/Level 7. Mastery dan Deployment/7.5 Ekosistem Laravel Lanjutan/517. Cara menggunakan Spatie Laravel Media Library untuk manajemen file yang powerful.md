# 517. Cara Menggunakan Spatie Laravel Media Library untuk Manajemen File yang Powerful

## Definisi & Target
Spatie Media Library menangani upload, penyimpanan, manipulasi gambar, dan konversi file dengan API yang ekspresif. Targetnya adalah mengelola file media (gambar, dokumen, video) yang terkait dengan Eloquent model.

## Komponen yang Terlibat
- spatie/laravel-medialibrary package
- Media model
- Image manipulation (spatie/image)
- File conversions
- Responsive images

## Perintah Artisan CLI
```bash
composer require spatie/laravel-medialibrary
php artisan vendor:publish --provider="Spatie\MediaLibrary\MediaLibraryServiceProvider" --tag="migrations"
php artisan migrate
php artisan vendor:publish --provider="Spatie\MediaLibrary\MediaLibraryServiceProvider" --tag="config"
```

## Kode Implementasi (Per File)

**Model dengan Media (app/Models/Product.php)**
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Spatie\MediaLibrary\HasMedia;
use Spatie\MediaLibrary\InteractsWithMedia;
use Spatie\MediaLibrary\MediaCollections\Models\Media;

class Product extends Model implements HasMedia
{
    use InteractsWithMedia;

    protected $fillable = ['name', 'description', 'price'];

    public function registerMediaCollections(): void
    {
        $this->addMediaCollection('images')
            ->useDisk('public')
            ->acceptsMimeTypes(['image/jpeg', 'image/png', 'image/webp'])
            ->withResponsiveImages();

        $this->addMediaCollection('documents')
            ->useDisk('local')
            ->acceptsMimeTypes(['application/pdf', 'application/msword']);
    }

    public function registerMediaConversions(?Media $media = null): void
    {
        $this->addMediaConversion('thumb')
            ->width(150)
            ->height(150)
            ->sharpen(10)
            ->performOnCollections('images');

        $this->addMediaConversion('medium')
            ->width(400)
            ->height(300)
            ->performOnCollections('images');

        $this->addMediaConversion('large')
            ->width(1200)
            ->height(900)
            ->performOnCollections('images');
    }
}
```

**Controller Media (app/Http/Controllers/Admin/ProductMediaController.php)**
```php
namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Models\Product;
use Illuminate\Http\Request;

class ProductMediaController extends Controller
{
    public function uploadImages(Request $request, Product $product)
    {
        $request->validate([
            'images' => 'required|array',
            'images.*' => 'image|max:5120',
        ]);

        foreach ($request->file('images') as $image) {
            $product->addMedia($image)
                ->withCustomProperties(['alt' => $request->input('alt', '')])
                ->toMediaCollection('images');
        }

        return back()->with('success', 'Images uploaded.');
    }

    public function uploadDocument(Request $request, Product $product)
    {
        $request->validate([
            'document' => 'required|file|mimes:pdf,doc,docx|max:10240',
        ]);

        $product->addMedia($request->file('document'))
            ->toMediaCollection('documents');

        return back()->with('success', 'Document uploaded.');
    }

    public function deleteMedia(Product $product, int $mediaId)
    {
        $product->media()->where('id', $mediaId)->first()?->delete();

        return back()->with('success', 'Media deleted.');
    }

    public function updateOrder(Request $request, Product $product)
    {
        foreach ($request->input('order', []) as $index => $id) {
            Media::where('id', $id)->update(['order_column' => $index + 1]);
        }

        return response()->json(['message' => 'Order updated.']);
    }
}
```

**Blade View dengan Media**
```blade
@php
    $product = App\Models\Product::with('media')->find(1);
@endphp

<div class="product-gallery">
    {{-- Tampilkan gambar — secara otomatis memilih ukuran optimal --}}
    @foreach ($product->getMedia('images') as $image)
        <img src="{{ $image->getUrl('thumb') }}"
             data-src="{{ $image->getUrl('large') }}"
             alt="{{ $image->getCustomProperty('alt', 'Product Image') }}"
             loading="lazy"
             class="product-thumb">
    @endforeach

    {{-- Tampilkan gambar dengan responsive srcset --}}
    @if ($product->getFirstMedia('images'))
        <img src="{{ $product->getFirstMediaUrl('images', 'medium') }}"
             srcset="{{ $product->getFirstMedia('images')->getSrcset('medium') }}"
             sizes="(max-width: 768px) 100vw, 50vw"
             alt="{{ $product->name }}">
    @endif

    {{-- Download link untuk dokumen --}}
    @foreach ($product->getMedia('documents') as $document)
        <a href="{{ $document->getUrl() }}" target="_blank">
            {{ $document->name }} ({{ $document->human_readable_size }})
        </a>
    @endforeach
</div>
```

**API Resource untuk Media (app/Http/Resources/MediaResource.php)**
```php
namespace App\Http\Resources;

use Illuminate\Http\Request;
use Illuminate\Http\Resources\Json\JsonResource;

class MediaResource extends JsonResource
{
    public function toArray(Request $request): array
    {
        return [
            'id' => $this->id,
            'name' => $this->name,
            'file_name' => $this->file_name,
            'mime_type' => $this->mime_type,
            'size' => $this->size,
            'human_readable_size' => $this->human_readable_size,
            'url' => $this->getUrl(),
            'thumb_url' => $this->getUrl('thumb'),
            'medium_url' => $this->getUrl('medium'),
            'order' => $this->order_column,
            'custom_properties' => $this->custom_properties,
            'created_at' => $this->created_at,
        ];
    }
}
```

## Cara Integrasi & Pengujian
Implementasikan `HasMedia` dan `InteractsWithMedia` di model. Definisikan collection dan conversion. Upload via `addMedia()`. Tampilkan di Blade dengan `getUrl()`.
