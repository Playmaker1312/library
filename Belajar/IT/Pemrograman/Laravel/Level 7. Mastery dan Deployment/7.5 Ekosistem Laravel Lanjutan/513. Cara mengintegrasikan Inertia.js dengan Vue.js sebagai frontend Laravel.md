# 513. Cara Mengintegrasikan Inertia.js dengan Vue.js sebagai Frontend Laravel

## Definisi & Target
Inertia.js dengan Vue 3 memungkinkan penggunaan Vue SFC sebagai view layer Laravel. Targetnya adalah membangun SPA dengan Vue tanpa perlu REST API terpisah.

## Komponen yang Terlibat
- @inertiajs/vue3
- Vue 3
- Laravel Inertia backend
- Vite dengan Vue plugin

## Perintah Artisan CLI
```bash
composer require inertiajs/inertia-laravel
npm install vue @inertiajs/vue3
npm install --save-dev @vitejs/plugin-vue
```

## Kode Implementasi (Per File)

**vite.config.js**
```javascript
import { defineConfig } from 'vite';
import laravel from 'laravel-vite-plugin';
import vue from '@vitejs/plugin-vue';

export default defineConfig({
    plugins: [
        laravel({
            input: 'resources/js/app.js',
            refresh: true,
        }),
        vue({
            template: {
                transformAssetUrls: {
                    base: null,
                    includeAbsolute: false,
                },
            },
        }),
    ],
});
```

**app.js Entry Point (resources/js/app.js)**
```javascript
import { createApp, h } from 'vue';
import { createInertiaApp } from '@inertiajs/vue3';
import Layout from './Layouts/AppLayout.vue';

createInertiaApp({
    resolve: name => {
        const pages = import.meta.glob('./Pages/**/*.vue', { eager: true });
        let page = pages[`./Pages/${name}.vue`];
        page.default.layout = page.default.layout || Layout;
        return page;
    },
    setup({ el, App, props, plugin }) {
        createApp({ render: () => h(App, props) })
            .use(plugin)
            .mount(el);
    },
});
```

**Vue Form with useForm (resources/js/Pages/Users/Create.vue)**
```vue
<script setup>
import { useForm } from '@inertiajs/vue3';

const form = useForm({
    name: '',
    email: '',
    password: '',
});

function submit() {
    form.post('/users', {
        preserveScroll: true,
        onSuccess: () => form.reset(),
    });
}
</script>

<template>
    <form @submit.prevent="submit" class="max-w-md mx-auto">
        <input v-model="form.name" placeholder="Name" class="w-full border p-2 mb-1">
        <div v-if="form.errors.name" class="text-red-500 text-sm mb-2">{{ form.errors.name }}</div>

        <input v-model="form.email" type="email" placeholder="Email" class="w-full border p-2 mb-1">
        <div v-if="form.errors.email" class="text-red-500 text-sm mb-2">{{ form.errors.email }}</div>

        <input v-model="form.password" type="password" placeholder="Password" class="w-full border p-2 mb-4">

        <button type="submit" :disabled="form.processing"
                class="bg-blue-500 text-white px-4 py-2 rounded">
            Simpan
        </button>
    </form>
</template>
```

## Cara Integrasi & Pengujian
Setup Vite dengan Vue plugin. Gunakan `@inertiajs/vue3` untuk komponen. Data dari controller otomatis tersedia sebagai props. Gunakan `form.post()` untuk submit.
