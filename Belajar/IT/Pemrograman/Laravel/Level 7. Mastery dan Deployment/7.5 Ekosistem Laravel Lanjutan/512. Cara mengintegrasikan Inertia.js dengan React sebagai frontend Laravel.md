# 512. Cara Mengintegrasikan Inertia.js dengan React sebagai Frontend Laravel

## Definisi & Target
Inertia.js dengan React memungkinkan penggunaan komponen React sebagai view layer Laravel. Targetnya adalah membangun SPA dengan React tanpa perlu REST API terpisah.

## Komponen yang Terlibat
- @inertiajs/inertia-react
- React 18+
- Laravel Inertia backend
- Vite dengan React plugin

## Perintah Artisan CLI
```bash
composer require inertiajs/inertia-laravel
npm install react react-dom @inertiajs/react
npm install --save-dev @vitejs/plugin-react
```

## Kode Implementasi (Per File)

**vite.config.js**
```javascript
import { defineConfig } from 'vite';
import laravel from 'laravel-vite-plugin';
import react from '@vitejs/plugin-react';

export default defineConfig({
    plugins: [
        laravel({
            input: 'resources/js/app.jsx',
            refresh: true,
        }),
        react(),
    ],
});
```

**app.jsx Entry Point (resources/js/app.jsx)**
```jsx
import React from 'react';
import { createInertiaApp } from '@inertiajs/react';
import { createRoot } from 'react-dom/client';
import Layout from './Layouts/AppLayout';

createInertiaApp({
    resolve: name => {
        const pages = import.meta.glob('./Pages/**/*.jsx', { eager: true });
        let page = pages[`./Pages/${name}.jsx`];
        page.default.layout = page.default.layout || Layout;
        return page;
    },
    setup({ el, App, props }) {
        createRoot(el).render(<App {...props} />);
    },
});
```

**Layout Component (resources/js/Layouts/AppLayout.jsx)**
```jsx
import { Link, usePage } from '@inertiajs/react';

export default function Layout({ children }) {
    const { auth } = usePage().props;

    return (
        <div className="min-h-screen bg-gray-100">
            <nav className="bg-white shadow">
                <div className="max-w-7xl mx-auto px-4">
                    <div className="flex justify-between h-16">
                        <div className="flex items-center gap-4">
                            <Link href="/" className="font-bold text-xl">MyApp</Link>
                            <Link href="/dashboard">Dashboard</Link>
                            <Link href="/users">Users</Link>
                        </div>
                        <div className="flex items-center gap-2">
                            <span>{auth.user?.name}</span>
                            <Link href="/logout" method="post" as="button"
                                  className="text-red-600">Logout</Link>
                        </div>
                    </div>
                </div>
            </nav>

            <main className="max-w-7xl mx-auto py-6 px-4">
                {children}
            </main>
        </div>
    );
}
```

**React Form with useForm (resources/js/Pages/Users/Create.jsx)**
```jsx
import { useForm } from '@inertiajs/react';
import Layout from '@/Layouts/AppLayout';

export default function Create() {
    const { data, setData, post, processing, errors } = useForm({
        name: '',
        email: '',
        password: '',
    });

    function handleSubmit(e) {
        e.preventDefault();
        post('/users');
    }

    return (
        <Layout>
            <form onSubmit={handleSubmit} className="max-w-md mx-auto">
                <input value={data.name} onChange={e => setData('name', e.target.value)}
                       placeholder="Name" className="w-full border p-2 mb-1" />
                {errors.name && <div className="text-red-500 text-sm mb-2">{errors.name}</div>}

                <input value={data.email} onChange={e => setData('email', e.target.value)}
                       type="email" placeholder="Email" className="w-full border p-2 mb-1" />

                <input value={data.password} onChange={e => setData('password', e.target.value)}
                       type="password" placeholder="Password" className="w-full border p-2 mb-4" />

                <button type="submit" disabled={processing}
                        className="bg-blue-500 text-white px-4 py-2 rounded">
                    Simpan
                </button>
            </form>
        </Layout>
    );
}
```

## Cara Integrasi & Pengujian
Setup Vite dengan React plugin. Gunakan `@inertiajs/react` untuk komponen. Data dari controller otomatis tersedia sebagai props. Navigasi menggunakan `<Link>` dari Inertia.
