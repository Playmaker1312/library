# 514. Cara Menggunakan Laravel Cashier untuk Integrasi Pembayaran Stripe yang Mudah

## Definisi & Target
Laravel Cashier menyediakan antarmuka yang ekspresif untuk integrasi Stripe Billing. Targetnya adalah menangani subscription, invoice, payment method, dan webhook Stripe dengan kode minimal.

## Komponen yang Terlibat
- laravel/cashier package
- Stripe API keys
- Billable model (User)
- Stripe webhooks
- Subscription plans

## Perintah Artisan CLI
```bash
composer require laravel/cashier
php artisan vendor:publish --provider="Laravel\Cashier\CashierServiceProvider"
php artisan migrate
php artisan cashier:webhook
```

## Kode Implementasi (Per File)

**Model Billable (app/Models/User.php)**
```php
namespace App\Models;

use Laravel\Cashier\Billable;
use Illuminate\Database\Eloquent\Model;

class User extends Model
{
    use Billable;

    protected $fillable = ['name', 'email', 'password'];
}
```

**Konfigurasi Cashier (config/cashier.php)**
```php
<?php

return [
    'model' => App\Models\User::class,
    'key' => env('STRIPE_KEY'),
    'secret' => env('STRIPE_SECRET'),
    'webhook' => [
        'secret' => env('STRIPE_WEBHOOK_SECRET'),
        'tolerance' => env('STRIPE_WEBHOOK_TOLERANCE', 300),
    ],
    'currency' => env('CASHIER_CURRENCY', 'idr'),
    'currency_locale' => env('CASHIER_CURRENCY_LOCALE', 'id'),
    'payment_notification' => env('CASHIER_PAYMENT_NOTIFICATION', true),
];
```

**Controller Subscription (app/Http/Controllers/SubscriptionController.php)**
```php
namespace App\Http\Controllers;

use Illuminate\Http\Request;

class SubscriptionController extends Controller
{
    public function showPlans()
    {
        $plans = [
            'basic' => ['name' => 'Basic', 'price_id' => 'price_basic_monthly', 'amount' => 50000],
            'pro' => ['name' => 'Pro', 'price_id' => 'price_pro_monthly', 'amount' => 150000],
            'enterprise' => ['name' => 'Enterprise', 'price_id' => 'price_enterprise_monthly', 'amount' => 500000],
        ];

        return view('subscription.plans', compact('plans'));
    }

    public function checkout(Request $request)
    {
        $plan = $request->input('price_id');

        return $request->user()
            ->newSubscription('default', $plan)
            ->checkout([
                'success_url' => route('dashboard'),
                'cancel_url' => route('plans'),
            ]);
    }

    public function cancelSubscription(Request $request)
    {
        $request->user()->subscription('default')->cancel();

        return back()->with('success', 'Subscription cancelled.');
    }

    public function resumeSubscription(Request $request)
    {
        $request->user()->subscription('default')->resume();

        return back()->with('success', 'Subscription resumed.');
    }

    public function swapPlan(Request $request)
    {
        $request->user()->subscription('default')->swap($request->input('price_id'));

        return back()->with('success', 'Plan updated.');
    }
}
```

**Webhook Controller (app/Http/Controllers/StripeWebhookController.php)**
```php
namespace App\Http\Controllers;

use Laravel\Cashier\Http\Controllers\WebhookController as CashierWebhookController;

class StripeWebhookController extends CashierWebhookController
{
    public function handleInvoicePaymentSucceeded($payload)
    {
        $user = $this->getUserByStripeId($payload['data']['object']['customer']);

        if ($user) {
            Log::info('Payment succeeded for user: ' . $user->id);
        }

        return $this->successMethod();
    }

    public function handleCustomerSubscriptionDeleted($payload)
    {
        Log::info('Subscription deleted', ['customer' => $payload['data']['object']['customer']]);

        return $this->successMethod();
    }
}
```

**Routes (routes/web.php)**
```php
use App\Http\Controllers\SubscriptionController;

Route::middleware('auth')->group(function () {
    Route::get('/plans', [SubscriptionController::class, 'showPlans'])->name('plans');
    Route::post('/subscribe', [SubscriptionController::class, 'checkout'])->name('subscribe');
    Route::post('/subscription/cancel', [SubscriptionController::class, 'cancelSubscription']);
    Route::post('/subscription/resume', [SubscriptionController::class, 'resumeSubscription']);
    Route::post('/subscription/swap', [SubscriptionController::class, 'swapPlan']);
});
```

## Cara Integrasi & Pengujian
Set STRIPE_KEY dan STRIPE_SECRET di .env. Konfigurasi webhook di dashboard Stripe untuk URL `/stripe/webhook`. Uji dengan mode test Stripe.
