# 511. Memahami dan Menggunakan Inertia.js untuk Membangun SPA dengan Laravel Backend

## Definisi & Target
Inertia.js memungkinkan pembangunan SPA (Single Page Application) menggunakan framework frontend (Vue/React/Svelte) tanpa perlu API endpoint terpisah. Targetnya adalah menggabungkan kemudahan Laravel backend dengan modern frontend framework.

## Komponen yang Terlibat
- Laravel Inertia package
- Vue.js atau React sebagai frontend
- Inertia client-side adapter
- Vite bundler

## Perintah Artisan CLI
```bash
composer require inertiajs/inertia-laravel
npm install @inertiajs/vue3 vue
php artisan inertia:middleware
```

## Kode Implementasi (Per File)

**Konfigurasi Inertia (bootstrap/app.php)**
```php
return Application::configure(basePath: dirname(__DIR__))
    ->withMiddleware(function (Middleware $middleware) {
        $middleware->web(append: [
            \App\Http\Middleware\HandleInertiaRequests::class,
        ]);
    })
    ->create();
```

**Controller dengan Inertia (app/Http/Controllers/DashboardController.php)**
```php
namespace App\Http\Controllers;

use App\Models\User;
use App\Models\Post;
use Inertia\Inertia;
use Inertia\Response;

class DashboardController extends Controller
{
    public function index(): Response
    {
        return Inertia::render('Dashboard/Index', [
            'stats' => [
                'totalUsers' => User::count(),
                'totalPosts' => Post::count(),
            ],
        ]);
    }

    public function showUser(User $user): Response
    {
        return Inertia::render('Users/Show', [
            'user' => $user->only('id', 'name', 'email', 'created_at'),
            'posts' => $user->posts()->latest()->paginate(10),
        ]);
    }
}
```

**Routes (routes/web.php)**
```php
use App\Http\Controllers\DashboardController;
use App\Http\Controllers\UserController;

Route::middleware(['auth'])->group(function () {
    Route::get('/dashboard', [DashboardController::class, 'index']);
    Route::get('/users/{user}', [DashboardController::class, 'showUser']);
    Route::get('/users', [UserController::class, 'index']);
});
```

**Form dengan Inertia (resources/js/Pages/Users/Create.vue)**
```vue
<script setup>
import { useForm } from '@inertiajs/vue3';
import AppLayout from '@/Layouts/AppLayout.vue';

const form = useForm({
    name: '',
    email: '',
    password: '',
});

function submit() {
    form.post('/users', {
        preserveScroll: true,
    });
}
</script>

<template>
    <AppLayout>
        <form @submit.prevent="submit" class="max-w-md mx-auto">
            <input v-model="form.name" placeholder="Name" class="w-full border p-2 mb-2">
            <div v-if="form.errors.name" class="text-red-500">{{ form.errors.name }}</div>

            <input v-model="form.email" type="email" placeholder="Email" class="w-full border p-2 mb-2">
            <input v-model="form.password" type="password" placeholder="Password" class="w-full border p-2 mb-4">

            <button type="submit" :disabled="form.processing"
                    class="bg-blue-500 text-white px-4 py-2 rounded">
                Simpan
            </button>
        </form>
    </AppLayout>
</template>
```

**Shared Data (app/Http/Middleware/HandleInertiaRequests.php)**
```php
namespace App\Http\Middleware;

use Illuminate\Http\Request;
use Inertia\Middleware;

class HandleInertiaRequests extends Middleware
{
    public function share(Request $request): array
    {
        return array_merge(parent::share($request), [
            'auth' => [
                'user' => $request->user()
                    ? $request->user()->only('id', 'name', 'email', 'role')
                    : null,
            ],
            'flash' => [
                'success' => $request->session()->get('success'),
                'error' => $request->session()->get('error'),
            ],
        ]);
    }
}
```

## Cara Integrasi & Pengujian
Kembalikan `Inertia::render()` dari controller — data dikirim sebagai props ke komponen Vue/React. Navigasi antar halaman terjadi tanpa reload penuh.
