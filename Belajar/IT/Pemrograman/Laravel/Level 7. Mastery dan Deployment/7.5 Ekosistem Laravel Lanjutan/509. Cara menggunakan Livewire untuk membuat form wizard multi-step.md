# 509. Cara Menggunakan Livewire untuk Membuat Form Wizard Multi-Step

## Definisi & Target
Form wizard multi-step memecah form panjang menjadi beberapa langkah. Livewire memungkinkan navigasi antar step, validasi per step, dan penyimpanan state tanpa kehilangan data.

## Komponen yang Terlibat
- Livewire component
- Step management
- Per-step validation
- Progress indicator
- Session state

## Perintah Artisan CLI
```bash
php artisan make:livewire RegistrationWizard
```

## Kode Implementasi (Per File)

**Wizard Component (app/Livewire/RegistrationWizard.php)**
```php
namespace App\Livewire;

use App\Models\User;
use Livewire\Component;
use Illuminate\Support\Facades\Hash;
use Illuminate\Support\Facades\Session;

class RegistrationWizard extends Component
{
    public int $currentStep = 1;
    public int $totalSteps = 4;

    public array $accountData = [
        'email' => '',
        'password' => '',
        'password_confirmation' => '',
    ];

    public array $profileData = [
        'name' => '',
        'phone' => '',
        'bio' => '',
    ];

    public array $addressData = [
        'street' => '',
        'city' => '',
        'province' => '',
        'postal_code' => '',
    ];

    public array $preferencesData = [
        'newsletter' => false,
        'theme' => 'light',
        'language' => 'id',
    ];

    public function mount(): void
    {
        $this->restoreSession();
    }

    public function firstStepSubmit(): void
    {
        $this->validate([
            'accountData.email' => 'required|email|unique:users,email',
            'accountData.password' => 'required|min:8|confirmed',
        ]);

        $this->currentStep = 2;
        $this->saveSession();
    }

    public function secondStepSubmit(): void
    {
        $this->validate([
            'profileData.name' => 'required|string|max:255',
            'profileData.phone' => 'nullable|regex:/^\+?[\d\s()-]{8,20}$/',
        ]);

        $this->currentStep = 3;
        $this->saveSession();
    }

    public function thirdStepSubmit(): void
    {
        $this->validate([
            'addressData.street' => 'required|string|max:255',
            'addressData.city' => 'required|string|max:255',
            'addressData.province' => 'required|string|max:255',
            'addressData.postal_code' => 'required|digits:5',
        ]);

        $this->currentStep = 4;
        $this->saveSession();
    }

    public function submit(): void
    {
        $this->validate([
            'preferencesData.language' => 'required|in:id,en',
        ]);

        $user = User::create([
            'email' => $this->accountData['email'],
            'password' => Hash::make($this->accountData['password']),
            'name' => $this->profileData['name'],
            'phone' => $this->profileData['phone'],
            'bio' => $this->profileData['bio'],
            'address' => json_encode($this->addressData),
            'preferences' => json_encode($this->preferencesData),
        ]);

        Session::forget('wizard_data');

        $this->dispatch('registration-complete', userId: $user->id);
    }

    public function goToStep(int $step): void
    {
        if ($step >= 1 && $step <= $this->totalSteps) {
            $this->currentStep = $step;
        }
    }

    public function previousStep(): void
    {
        if ($this->currentStep > 1) {
            $this->currentStep--;
            $this->restoreSession();
        }
    }

    private function saveSession(): void
    {
        Session::put('wizard_data', [
            'account' => $this->accountData,
            'profile' => $this->profileData,
            'address' => $this->addressData,
            'preferences' => $this->preferencesData,
        ]);
    }

    private function restoreSession(): void
    {
        $data = Session::get('wizard_data');
        if ($data) {
            $this->accountData = $data['account'] ?? $this->accountData;
            $this->profileData = $data['profile'] ?? $this->profileData;
            $this->addressData = $data['address'] ?? $this->addressData;
            $this->preferencesData = $data['preferences'] ?? $this->preferencesData;
        }
    }

    public function render()
    {
        return view('livewire.registration-wizard');
    }
}
```

**Wizard View (resources/views/livewire/registration-wizard.blade.php)**
```blade
<div>
    <div class="flex items-center mb-8">
        @for ($i = 1; $i <= $totalSteps; $i++)
            <div class="flex items-center">
                <button wire:click="goToStep({{ $i }})"
                        class="w-10 h-10 rounded-full flex items-center justify-center
                               {{ $currentStep >= $i ? 'bg-blue-500 text-white' : 'bg-gray-200' }}">
                    {{ $i }}
                </button>
                @if ($i < $totalSteps)
                    <div class="w-12 h-1 {{ $currentStep > $i ? 'bg-blue-500' : 'bg-gray-200' }}"></div>
                @endif
            </div>
        @endfor
    </div>

    @if ($currentStep === 1)
        <div>
            <h3>Akun</h3>
            <input wire:model="accountData.email" type="email" placeholder="Email">
            @error('accountData.email') <span>{{ $message }}</span> @enderror
            <input wire:model="accountData.password" type="password" placeholder="Password">
            <input wire:model="accountData.password_confirmation" type="password" placeholder="Konfirmasi Password">
            <button wire:click="firstStepSubmit">Lanjut</button>
        </div>
    @elseif ($currentStep === 2)
        <div>
            <h3>Profil</h3>
            <input wire:model="profileData.name" placeholder="Nama Lengkap">
            <input wire:model="profileData.phone" placeholder="No. Telepon">
            <textarea wire:model="profileData.bio" placeholder="Bio"></textarea>
            <button wire:click="previousStep">Kembali</button>
            <button wire:click="secondStepSubmit">Lanjut</button>
        </div>
    @elseif ($currentStep === 3)
        <div>
            <h3>Alamat</h3>
            <input wire:model="addressData.street" placeholder="Jalan">
            <input wire:model="addressData.city" placeholder="Kota">
            <input wire:model="addressData.province" placeholder="Provinsi">
            <input wire:model="addressData.postal_code" placeholder="Kode Pos">
            <button wire:click="previousStep">Kembali</button>
            <button wire:click="thirdStepSubmit">Lanjut</button>
        </div>
    @elseif ($currentStep === 4)
        <div>
            <h3>Preferensi</h3>
            <label><input type="checkbox" wire:model="preferencesData.newsletter"> Newsletter</label>
            <select wire:model="preferencesData.theme">
                <option value="light">Terang</option>
                <option value="dark">Gelap</option>
            </select>
            <select wire:model="preferencesData.language">
                <option value="id">Indonesia</option>
                <option value="en">English</option>
            </select>
            <button wire:click="previousStep">Kembali</button>
            <button wire:click="submit">Daftar</button>
        </div>
    @endif
</div>
```

## Cara Integrasi & Pengujian
Validasi per step dengan method `firstStepSubmit()`, `secondStepSubmit()`, dll. Simpan state ke session agar data tidak hilang saat navigasi. Tampilkan progress indicator sesuai currentStep.
