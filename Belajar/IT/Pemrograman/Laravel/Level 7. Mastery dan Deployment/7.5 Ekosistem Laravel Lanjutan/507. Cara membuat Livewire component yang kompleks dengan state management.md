# 507. Cara Membuat Livewire Component yang Kompleks dengan State Management

## Definisi & Target
Livewire component kompleks membutuhkan state management untuk menangani form multi-field, validasi real-time, file upload, dan modals. Targetnya adalah membangun komponen yang tetap terstruktur meskipun memiliki banyak state.

## Komponen yang Terlibat
- Livewire component properties
- Validasi real-time
- File upload
- Modal dan event system
- Computed properties

## Perintah Artisan CLI
```bash
php artisan make:livewire ProductForm
php artisan make:livewire ProductManager
```

## Kode Implementasi (Per File)

**Complex Component (app/Livewire/ProductManager.php)**
```php
namespace App\Livewire;

use App\Models\Product;
use App\Models\Category;
use Livewire\Component;
use Livewire\WithFileUploads;
use Livewire\Attributes\On;
use Illuminate\Support\Facades\Storage;

class ProductManager extends Component
{
    use WithFileUploads;

    public bool $showModal = false;
    public bool $isEditing = false;
    public ?int $editingProductId = null;

    public array $form = [
        'name' => '',
        'description' => '',
        'price' => 0,
        'category_id' => null,
        'is_active' => true,
    ];

    public $photo;
    public $photoPreview;

    protected function rules(): array
    {
        return [
            'form.name' => 'required|string|max:255',
            'form.description' => 'nullable|string|max:5000',
            'form.price' => 'required|numeric|min:0',
            'form.category_id' => 'required|exists:categories,id',
            'form.is_active' => 'boolean',
            'photo' => 'nullable|image|max:2048',
        ];
    }

    protected $validationAttributes = [
        'form.name' => 'nama produk',
        'form.price' => 'harga',
    ];

    public function mount(): void
    {
        $this->form['category_id'] = Category::first()?->id;
    }

    public function updatedPhoto(): void
    {
        $this->validateOnly('photo');
        $this->photoPreview = $this->photo->temporaryUrl();
    }

    public function openCreateModal(): void
    {
        $this->resetForm();
        $this->showModal = true;
        $this->isEditing = false;
    }

    public function openEditModal(Product $product): void
    {
        $this->form = $product->only(['name', 'description', 'price', 'category_id', 'is_active']);
        $this->editingProductId = $product->id;
        $this->isEditing = true;
        $this->showModal = true;

        if ($product->photo) {
            $this->photoPreview = Storage::url($product->photo);
        }
    }

    public function save(): void
    {
        $this->validate();

        $data = $this->form;

        if ($this->photo) {
            $data['photo'] = $this->photo->store('products', 'public');
        }

        if ($this->isEditing) {
            $product = Product::findOrFail($this->editingProductId);
            $product->update($data);
            $this->dispatch('product-updated', productId: $product->id);
        } else {
            $product = Product::create($data);
            $this->dispatch('product-created', productId: $product->id);
        }

        $this->closeModal();
        $this->dispatch('notify', message: 'Produk berhasil disimpan');
    }

    #[On('delete-product')]
    public function deleteProduct(int $productId): void
    {
        Product::findOrFail($productId)->delete();
        $this->dispatch('notify', message: 'Produk berhasil dihapus');
    }

    public function closeModal(): void
    {
        $this->showModal = false;
        $this->resetForm();
    }

    private function resetForm(): void
    {
        $this->reset('form', 'photo', 'photoPreview', 'editingProductId', 'isEditing');
        $this->form['category_id'] = Category::first()?->id;
    }

    public function render()
    {
        return view('livewire.product-manager', [
            'products' => Product::with('category')->latest()->paginate(10),
            'categories' => Category::all(),
        ]);
    }
}
```

**Livewire View (resources/views/livewire/product-manager.blade.php)**
```blade
<div>
    <button wire:click="openCreateModal" class="bg-blue-500 text-white px-4 py-2 rounded">
        Tambah Produk
    </button>

    <table class="w-full mt-4">
        @foreach ($products as $product)
            <tr>
                <td>{{ $product->name }}</td>
                <td>Rp {{ number_format($product->price) }}</td>
                <td>
                    <button wire:click="openEditModal({{ $product->id }})">Edit</button>
                    <button wire:click="$dispatch('confirm-delete', { id: {{ $product->id }} })">Hapus</button>
                </td>
            </tr>
        @endforeach
    </table>

    @if ($showModal)
        <div class="fixed inset-0 bg-black/50" wire:click="closeModal"></div>
        <div class="fixed inset-0 flex items-center justify-center">
            <div class="bg-white p-6 rounded-lg w-96" wire:click.stop>
                <h2>{{ $isEditing ? 'Edit' : 'Tambah' }} Produk</h2>

                <form wire:submit="save">
                    <input wire:model="form.name" placeholder="Nama Produk">
                    @error('form.name') <span>{{ $message }}</span> @enderror

                    <textarea wire:model="form.description" placeholder="Deskripsi"></textarea>

                    <input wire:model="form.price" type="number" placeholder="Harga">

                    <select wire:model="form.category_id">
                        @foreach ($categories as $cat)
                            <option value="{{ $cat->id }}">{{ $cat->name }}</option>
                        @endforeach
                    </select>

                    <input type="checkbox" wire:model="form.is_active"> Aktif

                    <input type="file" wire:model="photo">
                    @if ($photoPreview)
                        <img src="{{ $photoPreview }}" class="w-20 h-20">
                    @endif

                    <button type="submit">Simpan</button>
                    <button type="button" wire:click="closeModal">Batal</button>
                </form>
            </div>
        </div>
    @endif

    <div wire:loading class="fixed top-4 right-4 bg-blue-500 text-white px-4 py-2 rounded">
        Menyimpan...
    </div>
</div>
```

## Cara Integrasi & Pengujian
Gunakan `WithFileUploads` untuk upload file. Validasi real-time dengan `$this->validateOnly()`. Manajemen state via properti publik dan array form.
