# 528. Cara Berkontribusi ke Ekosistem Laravel dengan Membuat Package atau Pull Request

## Definisi & Target
Kontribusi ke open source Laravel bisa berupa pull request ke framework, membuat package, atau membantu dokumentasi. Targetnya adalah memberikan kembali ke komunitas dan membangun reputasi sebagai developer.

## Komponen yang Terlibat
- GitHub (laravel/framework)
- Packagist untuk publish package
- Composer
- PHPUnit testing

## Cara Berkontribusi

**2. Membuat Package Laravel**
```php
// Struktur package
$packageStructure = [
    'src/' => 'Source code package',
    'src/ServiceProvider.php' => 'Service provider',
    'src/Facades/' => 'Facade untuk package',
    'config/' => 'Konfigurasi package',
    'database/migrations/' => 'Migration package',
    'resources/views/' => 'Blade views',
    'routes/' => 'Routes package',
    'composer.json' => 'Dependency package',
    'README.md' => 'Dokumentasi',
];
```

**Package Skeleton (composer.json)**
```json
{
    "name": "vendor/laravel-package-name",
    "description": "Package Laravel untuk...",
    "type": "library",
    "require": {
        "php": "^8.1",
        "illuminate/support": "^10.0|^11.0"
    },
    "require-dev": {
        "orchestra/testbench": "^8.0|^9.0",
        "phpunit/phpunit": "^10.0"
    },
    "autoload": {
        "psr-4": {
            "Vendor\\PackageName\\": "src/"
        }
    },
    "extra": {
        "laravel": {
            "providers": [
                "Vendor\\PackageName\\PackageNameServiceProvider"
            ],
            "aliases": {
                "PackageName": "Vendor\\PackageName\\Facades\\PackageName"
            }
        }
    }
}
```

**Service Provider Package (src/PackageNameServiceProvider.php)**
```php
namespace Vendor\PackageName;

use Illuminate\Support\ServiceProvider;

class PackageNameServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        if ($this->app->runningInConsole()) {
            $this->publishes([
                __DIR__.'/../config/package.php' => config_path('package.php'),
            ], 'package-config');
        }

        $this->loadRoutesFrom(__DIR__.'/../routes/web.php');
        $this->loadViewsFrom(__DIR__.'/../resources/views', 'package');
        $this->loadMigrationsFrom(__DIR__.'/../database/migrations');
    }

    public function register(): void
    {
        $this->mergeConfigFrom(
            __DIR__.'/../config/package.php', 'package'
        );
    }
}
```

**Publish ke Packagist**
```bash
# 1. Push repository ke GitHub
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/vendor/laravel-package-name
git push -u origin main

# 2. Buat tag versi
git tag v1.0.0
git push --tags

# 3. Submit ke Packagist
# Buka https://packagist.org/packages/submit
# Masukkan URL GitHub repository
```

**3. Kontribusi Dokumentasi**

$dokumentasi = [

## Cara Integrasi & Pengujian
Mulai dari kontribusi kecil (fix typo di dokumentasi). Lanjut ke pull request untuk bug fix. Buat package sederhana untuk kebutuhan spesifik. Publikasikan ke Packagist.
