# 530. Cara Menggunakan PHPStan atau Larastan untuk Static Analysis Kode Laravel

## Definisi & Target
PHPStan adalah static analysis tool yang mendeteksi error pada kode PHP tanpa menjalankannya. Larastan adalah extension khusus untuk Laravel. Targetnya adalah menemukan bug potensial, type mismatch, dan error sebelum runtime.

## Komponen yang Terlibat
- phpstan/phpstan
- larastan/larastan
- phpstan.neon config
- CI integration

## Perintah Artisan CLI
```bash
composer require --dev larastan/larastan
./vendor/bin/phpstan analyse
./vendor/bin/phpstan analyse --level=max
./vendor/bin/phpstan analyse app/Models
```

## Kode Implementasi (Per File)

**Konfigurasi PHPStan (phpstan.neon)**
```neon
includes:
    - vendor/larastan/larastan/extension.neon

parameters:
    level: max
    paths:
        - app
    excludePaths:
        - app/Providers
        - app/Http/Middleware
        - database/
        - tests/
    scanFiles:
        - vendor/laravel/framework/src/Illuminate/Support/helpers.php
    checkMissingIterableValueType: true
    checkGenericClassInNonGenericObjectType: false
    checkUninitializedProperties: true
    checkExplicitMixed: false
    reportPossiblyNonexistentGeneralArrayOffset: true
    treatPhpDocTypesAsCertain: false

    typeAliases:
        Collections: \Illuminate\Support\Collection
        EloquentCollection: \Illuminate\Database\Eloquent\Collection

    stubFiles:
        - stubs/Eloquent/Model.stub
```

**Larastan Advanced Configuration (phpstan.neon)**
```neon
parameters:
    level: 9
    paths:
        - app
        - config
        - routes

    databaseMigrationsPath:
        - database/migrations

    noUnnecessaryCollectionCall: true
    noUnnecessaryCollectionCallOnly: []

    excludes_analyse:
        - *.blade.php

    universalObjectCratesClasses:
        - Illuminate\Http\Request
        - Illuminate\Support\Optional
```

**CI Integration (.github/workflows/static-analysis.yml)**
```yaml
name: Static Analysis

on: [push, pull_request]

jobs:
  phpstan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: shivammathur/setup-php@v2
        with:
          php-version: '8.2'
          coverage: none

      - run: composer install --no-progress

      - name: Run PHPStan
        run: ./vendor/bin/phpstan analyse --no-progress --error-format=github
```

**Fix Error PHPStan Example**
```php
// Error: Parameter $user is never passed by reference
public function processUser(User $user): void
{
    // Fix: Tidak ada masalah — PHPStan expecting proper docblock
}

// Error: Method has no return type specified
public function getName(): string  // Tambahkan return type
{
    return $this->name;
}

// Error: Cannot call method on mixed
// Perbaikan: Tambahkan type hint
public function getProfile(User $user): Profile
{
    return $user->profile;  // PHPStan tahu profile bertipe Profile
}

// Error: Access to undefined property
// Perbaikan: Tambahkan @property di docblock model
/** @property string $custom_field */
class User extends Model {}
```

**Baseline File untuk Error Existing**
```bash
# Generate baseline untuk error yang sudah ada
./vendor/bin/phpstan analyse --generate-baseline phpstan-baseline.neon

# Include baseline di phpstan.neon
# includes:
#     - phpstan-baseline.neon
```

**composer.json Script**
```json
{
    "scripts": {
        "analyse": "./vendor/bin/phpstan analyse",
        "analyse:ci": "./vendor/bin/phpstan analyse --no-progress --error-format=github",
        "analyse:baseline": "./vendor/bin/phpstan analyse --generate-baseline"
    }
}
```

**PHPStorm Integration**
```json
// Tools > PHPStan > Configuration
// Level: max
// Configuration file: phpstan.neon
// Run automatically on save
```

## Cara Integrasi & Pengujian
Jalankan `./vendor/bin/phpstan analyse` secara berkala. Targetkan level max secara bertahap. Integrasikan ke CI pipeline. Gunakan baseline untuk error yang sudah ada.
