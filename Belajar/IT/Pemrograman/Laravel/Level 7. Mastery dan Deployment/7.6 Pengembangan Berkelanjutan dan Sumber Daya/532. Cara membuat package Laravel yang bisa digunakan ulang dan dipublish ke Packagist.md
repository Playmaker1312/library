# 532. Cara Membuat Package Laravel yang Bisa Digunakan Ulang dan Dipublish ke Packagist

## Definisi & Target
Package Laravel adalah kumpulan kode yang dibungkus sebagai library Composer. Targetnya adalah membuat package yang reusable, terstruktur, dan bisa diinstal via `composer require`.

## Komponen yang Terlibat
- Composer
- Packagist
- GitHub
- Service Provider
- Orchestra Testbench

## Perintah Artisan CLI
```bash
composer require vendor/package-name
composer init
```

**Service Provider (src/ValidationRuleServiceProvider.php)**
```php
namespace Username\IndonesianValidation;

use Illuminate\Support\ServiceProvider;
use Illuminate\Support\Facades\Validator;
use Username\IndonesianValidation\Rules\IndonesianPhoneNumber;

class ValidationRuleServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        $this->publishes([
            __DIR__.'/../config/validation-rule.php' => config_path('validation-rule.php'),
        ], 'config');

        Validator::extend('indonesian_phone', function ($attribute, $value) {
            return preg_match('/^(\+62|62|0)8[1-9][0-9]{6,11}$/', $value);
        }, 'Nomor telepon Indonesia tidak valid.');
    }

    public function register(): void
    {
        $this->mergeConfigFrom(
            __DIR__.'/../config/validation-rule.php', 'validation-rule'
        );
    }
}
```

**Rule Class (src/Rules/IndonesianPhoneNumber.php)**
```php
namespace Username\IndonesianValidation\Rules;

use Closure;
use Illuminate\Contracts\Validation\ValidationRule;

class IndonesianPhoneNumber implements ValidationRule
{
    public function validate(string $attribute, mixed $value, Closure $fail): void
    {
        if (!preg_match('/^(\+62|62|0)8[1-9][0-9]{6,11}$/', $value)) {
            $fail("$attribute bukan nomor telepon Indonesia yang valid.");
        }
    }
}
```

**Test (tests/Rules/IndonesianPhoneNumberTest.php)**
```php
namespace Username\IndonesianValidation\Tests\Rules;

use Orchestra\Testbench\TestCase;
use Username\IndonesianValidation\Rules\IndonesianPhoneNumber;

class IndonesianPhoneNumberTest extends TestCase
{
    private IndonesianPhoneNumber $rule;

    protected function setUp(): void
    {
        parent::setUp();
        $this->rule = new IndonesianPhoneNumber();
    }

    public function test_valid_phone_numbers(): void
    {
        $validNumbers = [
            '081234567890',
            '6281234567890',
            '+6281234567890',
        ];

        foreach ($validNumbers as $number) {
            $this->assertTrue(
                $this->rule->passes('phone', $number),
                "Failed asserting that {$number} is valid"
            );
        }
    }

    public function test_invalid_phone_numbers(): void
    {
        $invalidNumbers = [
            '12345',
            '08123',
            '082',
            '123456789012345',
        ];

        foreach ($invalidNumbers as $number) {
            $this->assertFalse(
                $this->rule->passes('phone', $number),
                "Failed asserting that {$number} is invalid"
            );
        }
    }
}
```

**Publish ke Packagist**
```bash
# 1. Push ke GitHub
git init
git add .
git commit -m "Initial release"
git remote add origin https://github.com/username/laravel-indonesian-validation
git push -u origin main

# 2. Buat versi tag
git tag v1.0.0
git push --tags

# 3. Submit ke Packagist
# Buka https://packagist.org/packages/submit
# Masukkan URL GitHub

# 4. Install via Composer
composer require username/laravel-indonesian-validation
```

## Cara Integrasi & Pengujian
Buat struktur package dengan Service Provider. Tulis test dengan Orchestra Testbench. Push ke GitHub dan buat tag. Submit ke Packagist. Install package via Composer.
