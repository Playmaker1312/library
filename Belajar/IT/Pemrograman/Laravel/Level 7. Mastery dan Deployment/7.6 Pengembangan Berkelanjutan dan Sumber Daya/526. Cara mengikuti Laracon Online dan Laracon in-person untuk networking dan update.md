# 526. Cara Mengikuti Laracon Online dan Laracon In-Person untuk Networking dan Update

## Definisi & Target
Laracon adalah konferensi tahunan Laravel yang diadakan secara online dan offline. Targetnya adalah mendapatkan update langsung dari tim Laravel, belajar dari pembicara ahli, dan networking dengan komunitas global.

## Komponen yang Terlibat
- Laracon Online (laracon.net)
- Laracon US (laracon.us)
- Laracon EU (laracon.eu)
- Laracon AU (laracon.au)
- Taylor Otwell dan tim Laravel

## Jenis Laracon

**1. Laracon Online**
```php
$laraconOnline = [
    'Frekuensi' => 'Setahun sekali',
    'Format' => 'Streaming online',
    'Biaya' => 'Gratis atau murah',
    'Durasi' => '1-2 hari',
    'Fitur' => 'Live chat, Q&A, networking rooms',
];
```

## Persiapan Mengikuti Laracon

**1. Sebelum Konferensi**
```php
$sebelum = [
    'Register early' => 'Early bird ticket lebih murah',
    'Check schedule' => 'Tandai talk yang wajib ditonton',
    'Prepare questions' => 'Siapkan pertanyaan untuk Q&A',
    'Network prep' => 'Siapkan LinkedIn, GitHub, Twitter',
    'Timezone check' => 'Konversi waktu ke zona lokal',
];
```

**2. Selama Konferensi**
```php
$selama = [
    'Take notes' => 'Catat insight penting setiap talk',
    'Engage' => 'Tanya jawab di chat/forum',
    'Network' => 'Kenalan dengan peserta lain',
    'Share' => 'Tweet highlights dengan hashtag #Laracon',
    'Record' => 'Rekam talk favorit (jika diizinkan)',
];
```

**3. Setelah Konferensi**
```php

    'Connect' => 'Follow pembicara di Twitter/GitHub',

];
```

## Cara Integrasi & Pengujian
Pantau jadwal Laracon di laravel-news.com. Daftar early bird. Siapkan budget untuk tiket dan akomodasi jika offline. Ikuti streaming jika online.
