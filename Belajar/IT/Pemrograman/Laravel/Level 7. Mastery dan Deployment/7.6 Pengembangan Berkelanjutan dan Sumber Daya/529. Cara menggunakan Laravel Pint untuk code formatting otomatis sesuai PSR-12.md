# 529. Cara Menggunakan Laravel Pint untuk Code Formatting Otomatis Sesuai PSR-12

## Definisi & Target
Laravel Pint adalah code formatter yang dibangun di atas PHP-CS-Fixer. Targetnya adalah menjaga konsistensi gaya penulisan kode sesuai standar PSR-12 tanpa effort manual.

## Komponen yang Terlibat
- laravel/pint package (built-in sejak Laravel 10)
- PHP-CS-Fixer rules
- Config file pint.json
- Git hooks

## Perintah Artisan CLI
```bash
./vendor/bin/pint
./vendor/bin/pint --test
./vendor/bin/pint --diff
./vendor/bin/pint --preset=psr12
```

## Kode Implementasi (Per File)

**Konfigurasi Pint (pint.json)**
```json
{
    "preset": "laravel",
    "rules": {
        "simplified_null_return": true,
        "braces": {
            "allow_single_line_anonymous_class_with_empty_body": true
        },
        "concat_space": {
            "spacing": "one"
        },
        "not_operator_with_successor_space": true,
        "single_quote": true,
        "trailing_comma_in_multiline": true,
        "array_syntax": {
            "syntax": "short"
        },
        "ordered_imports": {
            "sort_algorithm": "alpha"
        },
        "no_unused_imports": true
    }
}
```

**Custom Preset (pint.json)**
```json
{
    "preset": "psr12",
    "rules": {
        "align_multiline_comment": true,
        "array_indentation": true,
        "blank_line_after_opening_tag": true,
        "cast_spaces": true,
        "class_attributes_separation": {
            "elements": {
                "method": "one"
            }
        },
        "declare_strict_types": true,
        "explicit_indirect_variable": true,
        "function_typehint_space": true,
        "heredoc_indentation": true,
        "method_argument_space": {
            "on_multiline": "ensure_fully_multiline"
        },
        "no_empty_phpdoc": true,
        "no_extra_blank_lines": true,
        "no_superfluous_phpdoc_tags": true,
        "ordered_class_elements": true,
        "phpdoc_align": true,
        "phpdoc_separation": true,
        "single_trait_insert_per_statement": true,
        "standardize_not_equals": true,
        "ternary_to_null_coalescing": true,
        "visibility_required": true
    }
}
```

**Git Pre-commit Hook (.husky/pre-commit)**
```bash
#!/bin/sh

# Jalankan Pint hanya pada file yang diubah
STAGED_FILES=$(git diff --cached --name-only --diff-filter=ACMR | grep '\.php$')

if [ -n "$STAGED_FILES" ]; then
    echo "Running Pint on staged files..."
    ./vendor/bin/pint $STAGED_FILES
    git add $STAGED_FILES
fi
```

**CI Integration (.github/workflows/code-style.yml)**
```yaml
name: Code Style

on: [push, pull_request]

jobs:
  pint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: shivammathur/setup-php@v2
        with:
          php-version: '8.2'

      - run: composer install --no-progress

      - name: Check code style
        run: ./vendor/bin/pint --test
```

**composer.json Script**
```json
{
    "scripts": {
        "format": "./vendor/bin/pint",
        "format:test": "./vendor/bin/pint --test",
        "format:diff": "./vendor/bin/pint --diff"
    }
}
```

**Penggunaan di Editor**
```json
// .vscode/settings.json
{
    "php.format.enable": true,
    "[php]": {
        "editor.formatOnSave": true,
        "editor.defaultFormatter": "opencollective.php-pint"
    }
}
```

**Example: Before vs After Pint**
```php
// Sebelum Pint:
function test()   {
$name='John';return $name;    }

// Setelah Pint:
function test(): string
{
    $name = 'John';
    return $name;
}
```

## Cara Integrasi & Pengujian
Jalankan `./vendor/bin/pint` untuk memformat kode. Tambahkan `--test` di CI pipeline untuk validasi. Konfigurasi pint.json sesuai preferensi tim. Gunakan pre-commit hook untuk otomatisasi.
