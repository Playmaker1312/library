# 467. Cara Menggunakan Cache Remember dan RememberForever untuk Data yang Jarang Berubah

## Definisi & Target
`Cache::remember()` menyimpan data dengan TTL (time-to-live), sementara `rememberForever()` menyimpan data tanpa batas waktu hingga dihapus manual. Targetnya adalah mengoptimasi performa dengan menyimpan data statis atau semi-statis di cache.

## Komponen yang Terlibat
- Illuminate\Support\Facades\Cache
- Cache driver (Redis, Memcached, database, file)
- Cache tags dan keys

## Perintah Artisan CLI
```bash
php artisan cache:clear
php artisan cache:forget key_name
```

## Kode Implementasi (Per File)

**Service dengan Cache Remember (app/Services/CategoryService.php)**
```php
namespace App\Services;

use App\Models\Category;
use Illuminate\Support\Facades\Cache;

class CategoryService
{
    public function getAllCategories(): array
    {
        return Cache::remember('all_categories', 86400, function () {
            return Category::withCount('products')
                ->orderBy('name')
                ->get()
                ->toArray();
        });
    }

    public function getNavigationCategories(): array
    {
        return Cache::remember('nav_categories', 43200, function () {
            return Category::where('is_active', true)
                ->whereNull('parent_id')
                ->with('children')
                ->get()
                ->toArray();
        });
    }
}
```

**Service dengan Remember Forever (app/Services/ConfigService.php)**
```php
namespace App\Services;

use App\Models\Setting;
use Illuminate\Support\Facades\Cache;

class ConfigService
{
    public function getSiteSettings(): array
    {
        return Cache::rememberForever('site_settings', function () {
            return Setting::pluck('value', 'key')->toArray();
        });
    }

    public function clearSiteSettings(): void
    {
        Cache::forget('site_settings');
    }
}
```

**Controller (app/Http/Controllers/HomeController.php)**
```php
namespace App\Http\Controllers;

use App\Services\CategoryService;
use App\Services\ConfigService;
use App\Models\Product;
use Illuminate\Support\Facades\Cache;

class HomeController extends Controller
{
    public function index(CategoryService $categoryService, ConfigService $configService)
    {
        $categories = $categoryService->getAllCategories();
        $settings = $configService->getSiteSettings();

        $featuredProducts = Cache::remember('home_featured_products', 3600, function () {
            return Product::where('is_featured', true)
                ->where('is_active', true)
                ->with('images')
                ->limit(8)
                ->get();
        });

        return view('home', compact('categories', 'featuredProducts', 'settings'));
    }
}
```

**Event Listener untuk Cache Invalidation**
```php
namespace App\Listeners;

use App\Models\Setting;
use Illuminate\Support\Facades\Cache;

class SettingUpdatedListener
{
    public function handle(): void
    {
        Cache::forget('site_settings');
    }
}
```

## Cara Integrasi & Pengujian
Gunakan `remember()` dengan TTL yang sesuai (misal 3600 untuk 1 jam) untuk data yang berubah periodically. Gunakan `rememberForever()` untuk data master seperti kategori atau settings yang jarang berubah. Selalu sediakan mekanisme cache invalidation.
