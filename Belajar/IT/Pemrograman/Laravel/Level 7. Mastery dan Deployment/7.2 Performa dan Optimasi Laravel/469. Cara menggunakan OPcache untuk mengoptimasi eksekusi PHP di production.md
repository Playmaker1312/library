# 469. Cara Menggunakan OPcache untuk Mengoptimasi Eksekusi PHP di Production

## Definisi & Target
OPcache menyimpan compiled PHP script di shared memory sehingga PHP tidak perlu mengkompilasi ulang setiap request. Targetnya adalah meningkatkan throughput aplikasi dengan mengurangi CPU usage untuk kompilasi PHP.

## Komponen yang Terlibat
- PHP OPcache extension (built-in sejak PHP 5.5)
- php.ini configuration
- Laravel production environment

## Perintah Artisan CLI
```bash
php -i | grep opcache
php artisan optimize
```

## Kode Implementasi (Per File)

**Konfigurasi OPcache (php.ini)**
```ini
[opcache]
opcache.enable=1
opcache.memory_consumption=256
opcache.interned_strings_buffer=16
opcache.max_accelerated_files=20000
opcache.revalidate_freq=60
opcache.fast_shutdown=1
opcache.enable_cli=1
opcache.validate_timestamps=0
opcache.max_file_size=0
```

**Konfigurasi untuk Development (php.ini)**
```ini
[opcache]
opcache.enable=1
opcache.revalidate_freq=0
opcache.validate_timestamps=1
```

**Laravel Command untuk OPcache Clear (app/Console/Commands/OpcacheClear.php)**
```php
namespace App\Console\Commands;

use Illuminate\Console\Command;

class OpcacheClear extends Command
{
    protected $signature = 'opcache:clear';
    protected $description = 'Clear PHP OPcache';

    public function handle(): int
    {
        if (function_exists('opcache_reset')) {
            opcache_reset();
            $this->info('OPcache cleared successfully.');
            return Command::SUCCESS;
        }

        $this->warn('OPcache is not enabled.');
        return Command::FAILURE;
    }
}
```

**Deployment Script dengan OPcache Reset**
```bash
#!/bin/bash
# deployment/deploy.sh

php artisan down --retry=60

git pull origin main

composer install --no-dev --optimize-autoloader

php artisan migrate --force

php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan event:cache

php artisan opcache:clear

php artisan up
```

**Verifikasi OPcache di Production**
```php
Route::get('/opcache-status', function () {
    if (!auth()->user()?->isAdmin()) {
        abort(403);
    }
    return response()->json([
        'enabled' => opcache_get_status()['opcache_enabled'] ?? false,
        'memory_usage' => opcache_get_status()['memory_usage'] ?? null,
        'statistics' => opcache_get_status()['opcache_statistics'] ?? null,
    ]);
});
```

## Cara Integrasi & Pengujian
Aktifkan OPcache di php.ini production. Set `opcache.validate_timestamps=0` untuk performa maksimal. Reset OPcache setiap kali ada deployment menggunakan script di atas.
