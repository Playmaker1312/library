# 468. Cara Mengimplementasikan Response Caching untuk Halaman yang Banyak Diakses

## Definisi & Target
Response caching menyimpan output HTML lengkap dari suatu halaman sehingga request berikutnya tidak perlu melalui proses controller, blade rendering, atau database query. Targetnya adalah mengurangi response time hingga mendekati nol untuk halaman publik yang statis.

## Komponen yang Terlibat
- HTTP cache headers
- Laravel Cache middleware
- Varnish atau Nginx cache (opsional)
- Full page cache package (opsional)

## Perintah Artisan CLI
```bash
php artisan make:middleware CacheResponse
php artisan cache:clear
```

## Kode Implementasi (Per File)

**Cache Response Middleware (app/Http/Middleware/CacheResponse.php)**
```php
namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Cache;
use Symfony\Component\HttpFoundation\Response;

class CacheResponse
{
    public function handle(Request $request, Closure $next, int $ttl = 3600): Response
    {
        if ($request->isMethod('GET') === false) {
            return $next($request);
        }

        $key = 'response_cache:' . md5($request->fullUrl());

        if (Cache::has($key)) {
            $cached = Cache::get($key);
            return response($cached['content'], $cached['status'])
                ->withHeaders($cached['headers']);
        }

        $response = $next($request);

        if ($response->isSuccessful()) {
            Cache::put($key, [
                'content' => $response->getContent(),
                'status' => $response->getStatusCode(),
                'headers' => $response->headers->all(),
            ], $ttl);
        }

        return $response;
    }
}
```

**Register Middleware (bootstrap/app.php)**
```php
return Application::configure(basePath: dirname(__DIR__))
    ->withMiddleware(function (Middleware $middleware) {
        $middleware->alias([
            'cache.response' => \App\Http\Middleware\CacheResponse::class,
        ]);
    })
    ->create();
```

**Routes (routes/web.php)**
```php
use App\Http\Controllers\HomeController;
use App\Http\Controllers\BlogController;

Route::middleware('cache.response:3600')->group(function () {
    Route::get('/', [HomeController::class, 'index']);
    Route::get('/blog', [BlogController::class, 'index']);
});

// Cache lebih lama untuk halaman statis
Route::get('/about', [PageController::class, 'about'])
    ->middleware('cache.response:86400');

Route::get('/contact', [PageController::class, 'contact'])
    ->middleware('cache.response:86400');
```

**Cache Invalidation via Event**
```php
namespace App\Listeners;

use Illuminate\Support\Facades\Cache;

class PostPublishedListener
{
    public function handle(): void
    {
        $keys = [
            'response_cache:' . md5(route('home')),
            'response_cache:' . md5(route('blog.index')),
        ];

        foreach ($keys as $key) {
            Cache::forget($key);
        }
    }
}
```

**HTTP Cache Headers (Nginx config snippet)**
```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;

    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

## Cara Integrasi & Pengujian
Terapkan middleware pada halaman publik yang jarang berubah. Ukur response time sebelum dan sesudah caching dengan Debugbar atau Chrome DevTools. Hapus cache saat ada konten baru dipublikasikan.
