# 463. Cara Mengoptimasi Eloquent Query untuk Menghindari N Plus 1 Problem

## Definisi & Target
N+1 problem terjadi ketika Eloquent menjalankan 1 query untuk mengambil data parent dan N query tambahan untuk setiap relasi child. Targetnya adalah mengurangi jumlah query database dengan menggunakan eager loading.

## Komponen yang Terlibat
- Eloquent ORM
- Eager loading (`with()`, `load()`)
- Lazy eager loading (`load()`)
- Debugbar untuk memonitor query

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

**Model (app/Models/Post.php)**
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Database\Eloquent\Relations\HasMany;

class Post extends Model
{
    protected $fillable = ['user_id', 'title', 'body'];

    public function user(): BelongsTo
    {
        return $this->belongsTo(User::class);
    }

    public function comments(): HasMany
    {
        return $this->hasMany(Comment::class);
    }
}
```

**N+1 Problem — Contoh Buruk**
```php
$posts = Post::all();

foreach ($posts as $post) {
    // Menjalankan query terpisah untuk setiap post
    echo $post->user->name;
}
```

**Solusi Eager Loading — Contoh Baik**
```php
$posts = Post::with('user', 'comments')->get();

foreach ($posts as $post) {
    // Tidak ada query tambahan — data sudah di-load
    echo $post->user->name;
    echo $post->comments->count();
}
```

**Pencegahan N+1 dengan Model (app/Models/Post.php)**
```php
use Illuminate\Database\Eloquent\Builder;

protected static function booted(): void
{
    static::addGlobalScope('withRelations', function (Builder $builder) {
        if (!request()->is('api/*')) {
            $builder->with(['user', 'comments']);
        }
    });
}
```

**Controller (app/Http/Controllers/PostController.php)**
```php
namespace App\Http\Controllers;

use App\Models\Post;

class PostController extends Controller
{
    public function index()
    {
        $posts = Post::with(['user', 'comments.user'])->paginate(20);
        return view('posts.index', compact('posts'));
    }

    public function show(Post $post)
    {
        $post->load(['user', 'comments.user']);
        return view('posts.show', compact('post'));
    }
}
```

## Cara Integrasi & Pengujian
Gunakan Debugbar untuk memonitor jumlah query per halaman. Targetkan maksimal 10-15 query per halaman (tidak termasuk pagination). Selalu gunakan `with()` saat menampilkan relasi di loop.
