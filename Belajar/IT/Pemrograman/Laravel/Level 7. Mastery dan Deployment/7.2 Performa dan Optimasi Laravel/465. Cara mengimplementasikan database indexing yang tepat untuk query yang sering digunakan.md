# 465. Cara Mengimplementasikan Database Indexing yang Tepat untuk Query yang Sering Digunakan

## Definisi & Target
Database index mempercepat pencarian data dengan menciptakan struktur data terpisah untuk kolom yang sering digunakan di WHERE, JOIN, ORDER BY. Targetnya adalah mengurangi full table scan dan mempercepat response time query.

## Komponen yang Terlibat
- MySQL/MariaDB index types (BTREE, HASH, FULLTEXT)
- Laravel Migration schema builder
- Composite dan partial indexes

## Perintah Artisan CLI
```bash
php artisan make:migration add_indexes_to_posts_table
```

## Kode Implementasi (Per File)

**Migration dengan Index (database/migrations/xxxx_add_indexes_to_posts_table.php)**
```php
use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::table('posts', function (Blueprint $table) {
            $table->index('status');
            $table->index('published_at');
            $table->index(['user_id', 'status']);
            $table->fullText(['title', 'body']);
        });

        Schema::table('users', function (Blueprint $table) {
            $table->unique('email');
            $table->index('role');
        });
    }

    public function down(): void
    {
        Schema::table('posts', function (Blueprint $table) {
            $table->dropIndex(['status']);
            $table->dropIndex(['published_at']);
            $table->dropIndex(['user_id', 'status']);
            $table->dropFullText(['title', 'body']);
        });
    }
};
```

**Query yang Dioptimalkan dengan Index**
```php
// Composite index (user_id, status) akan digunakan
$posts = Post::where('user_id', 5)
             ->where('status', 'published')
             ->get();

// Fulltext index untuk pencarian teks
$posts = Post::whereFullText(['title', 'body'], 'laravel performance')
             ->get();

// Index pada published_at untuk range query
$recentPosts = Post::where('published_at', '>', now()->subDays(7))
                   ->orderBy('published_at', 'desc')
                   ->get();
```

**Cek Index dengan Raw Query**
```php
use Illuminate\Support\Facades\DB;

$indexes = DB::select('SHOW INDEXES FROM posts');
```

**Migration untuk Unique Index**
```php
Schema::table('users', function (Blueprint $table) {
    $table->string('slug')->unique()->after('name');
    $table->index(['country_id', 'city_id']);
});
```

## Cara Integrasi & Pengujian
Jalankan `php artisan migrate` untuk menerapkan index. Gunakan `EXPLAIN SELECT ...` di MySQL untuk memverifikasi index benar-benar digunakan. Pasang index pada kolom yang muncul di `WHERE`, `JOIN`, `ORDER BY`, dan `GROUP BY`.
