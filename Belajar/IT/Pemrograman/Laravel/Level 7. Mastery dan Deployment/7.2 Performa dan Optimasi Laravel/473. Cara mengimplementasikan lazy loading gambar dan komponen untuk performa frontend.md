# 473. Cara Mengimplementasikan Lazy Loading Gambar dan Komponen untuk Performa Frontend

## Definisi & Target
Lazy loading menunda loading gambar dan komponen hingga elemen tersebut mendekati viewport. Targetnya adalah mengurangi initial page load time dan bandwidth usage.

## Komponen yang Terlibat
- Native `loading="lazy"` attribute
- Intersection Observer API
- Alpine.js untuk lazy loading komponen
- Livewire lazy initialization

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

**Blade dengan Native Lazy Loading (resources/views/gallery.blade.php)**
```blade
<div class="gallery">
    @foreach ($images as $image)
        <img
            src="{{ $image->url }}"
            loading="lazy"
            decoding="async"
            width="400"
            height="300"
            alt="{{ $image->alt }}"
            class="w-full h-auto"
        >
    @endforeach
</div>
```

**Alpine.js Lazy Load Component (resources/views/components/lazy-section.blade.php)**
```blade
<div
    x-data="lazyLoad()"
    x-init="init"
    x-intersect="load"
    class="min-h-[200px]"
>
    <template x-if="!loaded">
        <div class="flex justify-center items-center h-48">
            <div class="spinner"></div>
        </div>
    </template>
    <template x-if="loaded">
        <div x-html="content"></div>
    </template>
</div>

<script>
document.addEventListener('alpine:init', () => {
    Alpine.data('lazyLoad', () => ({
        loaded: false,
        content: '',
        async load() {
            const response = await fetch(this.$el.dataset.url);
            this.content = await response.text();
            this.loaded = true;
        }
    }));
});
</script>
```

**Livewire Lazy Initialization (app/Livewire/CommentsSection.php)**
```php
namespace App\Livewire;

use Livewire\Component;

class CommentsSection extends Component
{
    public $postId;
    public $comments = [];

    public function mount()
    {
        // Tidak loading data di sini — gunakan lazy
    }

    public function loadComments()
    {
        $this->comments = \App\Models\Comment::where('post_id', $this->postId)
            ->with('user')
            ->latest()
            ->take(10)
            ->get()
            ->toArray();
    }

    public function render()
    {
        return view('livewire.comments-section');
    }
}
```

**Blade dengan Livewire Lazy**
```blade
<livewire:comments-section :post-id="$post->id" lazy />
```

**JavaScript Intersection Observer untuk Custom Lazy Load**
```javascript
// resources/js/lazy-load.js
document.addEventListener('DOMContentLoaded', () => {
    const observer = new IntersectionObserver((entries) => {
        entries.forEach(entry => {
            if (entry.isIntersecting) {
                const element = entry.target;
                if (element.dataset.src) {
                    element.src = element.dataset.src;
                    element.removeAttribute('data-src');
                }
                observer.unobserve(element);
            }
        });
    }, { rootMargin: '200px' });

    document.querySelectorAll('[data-src]').forEach(img => observer.observe(img));
});
```

## Cara Integrasi & Pengujian
Tambahkan `loading="lazy"` ke semua gambar di halaman. Gunakan komponen Livewire dengan `lazy` parameter untuk komponen yang tidak terlihat di awal. Verifikasi dengan Chrome DevTools Network tab bahwa gambar terunduh sesuai scroll position.
