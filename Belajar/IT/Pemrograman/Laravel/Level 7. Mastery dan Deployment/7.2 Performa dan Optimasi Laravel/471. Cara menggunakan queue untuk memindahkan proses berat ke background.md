# 471. Cara Menggunakan Queue untuk Memindahkan Proses Berat ke Background

## Definisi & Target
Laravel Queue memungkinkan kita menunda eksekusi tugas berat (email, export, image processing) ke worker yang berjalan di background. Targetnya adalah menjaga response time API tetap cepat dan meningkatkan user experience.

## Komponen yang Terlibat
- Queue driver (database, Redis, SQS)
- Job class
- Queue worker
- Failed jobs table

## Perintah Artisan CLI
```bash
php artisan make:job ProcessVideo
php artisan queue:table
php artisan queue:failed-table
php artisan migrate
php artisan queue:work
php artisan queue:retry all
```

## Kode Implementasi (Per File)

**Job Class (app/Jobs/ProcessVideo.php)**
```php
namespace App\Jobs;

use App\Models\Video;
use App\Services\VideoProcessor;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Queue\SerializesModels;

class ProcessVideo implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, SerializesModels;

    public int $timeout = 600;
    public int $tries = 3;

    public function __construct(
        public Video $video
    ) {}

    public function handle(VideoProcessor $processor): void
    {
        $processor->process($this->video);

        $this->video->update(['status' => 'completed']);
    }

    public function failed(\Throwable $e): void
    {
        $this->video->update([
            'status' => 'failed',
            'error' => $e->getMessage(),
        ]);
    }
}
```

**Controller (app/Http/Controllers/VideoController.php)**
```php
namespace App\Http\Controllers;

use App\Models\Video;
use App\Jobs\ProcessVideo;
use Illuminate\Http\Request;

class VideoController extends Controller
{
    public function upload(Request $request)
    {
        $video = Video::create([
            'path' => $request->file('video')->store('videos'),
            'status' => 'pending',
        ]);

        ProcessVideo::dispatch($video);

        return response()->json([
            'message' => 'Video uploaded. Processing started.',
            'video_id' => $video->id,
        ], 202);
    }
}
```

**Queue Configuration (config/queue.php)**
```php
'default' => env('QUEUE_CONNECTION', 'redis'),

'connections' => [
    'database' => [
        'driver' => 'database',
        'table' => 'jobs',
        'queue' => 'default',
        'retry_after' => 90,
    ],
    'redis' => [
        'driver' => 'redis',
        'connection' => 'default',
        'queue' => env('REDIS_QUEUE', 'default'),
        'retry_after' => 90,
        'block_for' => null,
        'after_commit' => true,
    ],
],
```

**Job Chaining untuk Proses Bertahap**
```php
use App\Jobs\ProcessVideo;
use App\Jobs\GenerateThumbnail;
use App\Jobs\NotifyUser;

Bus::chain([
    new ProcessVideo($video),
    new GenerateThumbnail($video),
    new NotifyUser($video->user, $video),
])->dispatch();
```

**Supervisor Configuration (supervisor/queue-worker.conf)**
```ini
[program:laravel-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/artisan queue:work redis --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
stopasgroup=true
killasgroup=true
user=www-data
numprocs=4
redirect_stderr=true
stdout_logfile=/var/log/laravel-worker.log
```

## Cara Integrasi & Pengujian
Jalankan `php artisan queue:work` untuk development. Untuk production, gunakan Supervisor untuk menjaga worker tetap hidup. Pantau failed jobs via `php artisan queue:failed`.
