# 462. Cara Menggunakan Laravel Telescope untuk Monitoring dan Debugging Aplikasi

## Definisi & Target
Laravel Telescope adalah debug assistant yang mencatat request, exceptions, queries, jobs, mail, notifications, cache, dan scheduled tasks. Targetnya adalah menyediakan insight mendalam tentang aktivitas aplikasi di environment development.

## Komponen yang Terlibat
- Laravel Telescope package
- Telescope database migration
- Telescope dashboard UI
- Watchers (RequestWatcher, QueryWatcher, dll)

## Perintah Artisan CLI
```bash
composer require laravel/telescope --dev
php artisan telescope:install
php artisan migrate
```

## Kode Implementasi (Per File)

**Konfigurasi (config/telescope.php)**
```php
<?php

use Laravel\Telescope\Watchers;

return [
    'domain' => env('TELESCOPE_DOMAIN'),
    'path' => env('TELESCOPE_PATH', 'telescope'),
    'driver' => env('TELESCOPE_DRIVER', 'database'),
    'storage' => [
        'database' => [
            'connection' => env('DB_CONNECTION', 'mysql'),
            'chunk' => 1000,
        ],
    ],
    'watchers' => [
        Watchers\RequestWatcher::class => true,
        Watchers\QueryWatcher::class => true,
        Watchers\ExceptionWatcher::class => true,
        Watchers\LogWatcher::class => true,
        Watchers\MailWatcher::class => true,
        Watchers\NotificationWatcher::class => true,
        Watchers\CacheWatcher::class => true,
        Watchers\JobWatcher::class => true,
        Watchers\GateWatcher::class => true,
    ],
];
```

**Service Provider (app/Providers/TelescopeServiceProvider.php)**
```php
namespace App\Providers;

use Laravel\Telescope\Telescope;
use Laravel\Telescope\TelescopeApplicationServiceProvider;

class TelescopeServiceProvider extends TelescopeApplicationServiceProvider
{
    protected function gate(): void
    {
        Gate::define('viewTelescope', function ($user) {
            return in_array($user->email, [
                'admin@example.com',
            ]);
        });
    }
}
```

**.env**
```env
TELESCOPE_ENABLED=true
```

## Cara Integrasi & Pengujian
Akses `/telescope` untuk melihat dashboard. Gunakan filter berdasarkan tipe (request, query, job) untuk menganalisis aktivitas aplikasi secara detail.
