# 474. Cara Menggunakan Laravel Pulse untuk Monitoring Performa Aplikasi di Production

## Definisi & Target
Laravel Pulse adalah package monitoring real-time yang menampilkan metrik performa aplikasi seperti slow queries, usage, jobs, cache, dan exceptions. Targetnya adalah mendeteksi anomali performa sebelum berdampak pada pengguna.

## Komponen yang Terlibat
- Laravel Pulse package
- Pulse dashboard UI
- Recorders (SlowQuery, Usage, Job, Cache, Exception)
- Database storage untuk Pulse data

## Perintah Artisan CLI
```bash
composer require laravel/pulse
php artisan pulse:install
php artisan migrate
php artisan pulse:check
```

## Kode Implementasi (Per File)

**Konfigurasi (config/pulse.php)**
```php
<?php

use Laravel\Pulse\Recorders;

return [
    'enabled' => env('PULSE_ENABLED', true),
    'domain' => env('PULSE_DOMAIN'),
    'path' => env('PULSE_PATH', 'pulse'),
    'middleware' => ['web', 'auth'],
    'recorders' => [
        Recorders\SlowJobs::class => [
            'enabled' => env('PULSE_SLOW_JOBS_ENABLED', true),
            'threshold' => env('PULSE_SLOW_JOBS_THRESHOLD', 1000),
        ],
        Recorders\SlowQueries::class => [
            'enabled' => true,
            'threshold' => env('PULSE_SLOW_QUERIES_THRESHOLD', 100),
        ],
        Recorders\SlowRequests::class => [
            'enabled' => true,
            'threshold' => env('PULSE_SLOW_REQUESTS_THRESHOLD', 500),
        ],
        Recorders\Exceptions::class => [
            'enabled' => true,
        ],
        Recorders\CacheInteractions::class => [
            'enabled' => true,
        ],
        Recorders\Queues::class => [
            'enabled' => true,
        ],
    ],
];
```

**Pulse Service Provider (app/Providers/PulseServiceProvider.php)**
```php
namespace App\Providers;

use App\Models\User;
use Illuminate\Support\Facades\Gate;
use Laravel\Pulse\Pulse;
use Laravel\Pulse\PulseServiceProvider as ServiceProvider;

class PulseServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        Gate::define('viewPulse', function (User $user) {
            return in_array($user->email, [
                'admin@example.com',
            ]);
        });
    }
}
```

**Dashboard Route (routes/web.php)**
```php
use Illuminate\Support\Facades\Route;

Route::middleware(['web', 'auth'])->group(function () {
    Route::get('/pulse', function () {
        return view('vendor.pulse.dashboard');
    });
});
```

**Pulse Dashboard Card Kustom (resources/views/vendor/pulse/cards/slow-outgoing-requests.blade.php)**
```blade
<x-pulse::card>
    <x-pulse::card-header name="Slow Outgoing Requests">
        <x-slot:icon>
            <x-pulse::icons.clock />
        </x-slot:icon>
    </x-pulse::card-header>

    <x-pulse::scroll :expand="$expand">
        @foreach ($slowRequests as $request)
            <div class="flex items-center justify-between p-2">
                <span class="truncate">{{ $request->uri }}</span>
                <span class="text-red-500">{{ $request->duration }}ms</span>
            </div>
        @endforeach
    </x-pulse::scroll>
</x-pulse::card>
```

**Pulse Check Command via Cron**
```cron
* * * * * cd /var/www && php artisan pulse:check >> /dev/null 2>&1
```

## Cara Integrasi & Pengujian
Akses `/pulse` setelah login sebagai admin. Pulse menampilkan data 1 jam terakhir secara real-time. Konfigurasikan threshold sesuai kebutuhan — misal slow query >100ms, slow request >500ms.
