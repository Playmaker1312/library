# 472. Cara Mengoptimasi Asset dengan Vite untuk Bundle Size yang Minimal

## Definisi & Target
Laravel Vite mengelola CSS dan JavaScript dengan fitur bundling, minifikasi, code splitting, dan tree shaking. Targetnya adalah menghasilkan file asset yang sekecil mungkin untuk mempercepat loading halaman.

## Komponen yang Terlibat
- Laravel Vite plugin
- vite.config.js
- Package manager (npm/pnpm)
- PostCSS, Tailwind, atau framework CSS lainnya

## Perintah Artisan CLI
```bash
npm install
npm run build
npm run dev
```

## Kode Implementasi (Per File)

**vite.config.js**
```javascript
import { defineConfig } from 'vite';
import laravel from 'laravel-vite-plugin';
import tailwindcss from '@tailwindcss/vite';

export default defineConfig({
    plugins: [
        laravel({
            input: [
                'resources/css/app.css',
                'resources/js/app.js',
            ],
            refresh: true,
        }),
        tailwindcss(),
    ],
    build: {
        rollupOptions: {
            output: {
                manualChunks: {
                    vendor: ['alpinejs', 'axios'],
                },
            },
        },
        minify: 'esbuild',
        cssMinify: true,
        sourcemap: false,
        chunkSizeWarningLimit: 200,
    },
});
```

**Code Splitting di resources/js/app.js**
```javascript
import './bootstrap';

// Dynamic import untuk kode yang jarang digunakan
const Chart = () => import('./components/Chart');
const Calendar = () => import('./components/Calendar');

document.addEventListener('alpine:init', () => {
    Alpine.data('chart', () => ({
        async loadChart() {
            const { default: Chart } = await Chart();
            new Chart(this.$refs.canvas);
        }
    }));
});
```

**Blade dengan Vite (resources/views/layouts/app.blade.php)**
```blade
<!DOCTYPE html>
<html>
<head>
    @vite(['resources/css/app.css', 'resources/js/app.js'])
    @production
        <link rel="preload" href="{{ Vite::asset('resources/js/app.js') }}" as="script">
    @endproduction
</head>
<body>
    @yield('content')
</body>
</html>
```

**package.json — Script Optimasi**
```json
{
    "scripts": {
        "dev": "vite",
        "build": "vite build",
        "preview": "vite preview",
        "analyze": "vite build --config vite.analyzer.config.js"
    }
}
```

**Image Optimization di Blade**
```blade
<img
    src="{{ Vite::asset('resources/images/hero.webp') }}"
    loading="lazy"
    decoding="async"
    width="800"
    height="600"
    alt="Hero Image"
>
```

## Cara Integrasi & Pengujian
Jalankan `npm run build` untuk menghasilkan asset production. Ukur bundle size via `npm run analyze` atau Chrome DevTools Network tab. Pastikan `sourcemap=false` di production.
