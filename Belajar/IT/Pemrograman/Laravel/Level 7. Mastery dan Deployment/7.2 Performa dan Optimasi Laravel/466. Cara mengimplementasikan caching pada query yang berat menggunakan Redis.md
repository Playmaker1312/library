# 466. Cara Mengimplementasikan Caching pada Query yang Berat Menggunakan Redis

## Definisi & Target
Redis adalah in-memory data store yang sangat cepat. Dengan menyimpan hasil query berat di Redis, kita mengurangi beban database dan mempercepat response time secara dramatis.

## Komponen yang Terlibat
- Redis server
- `predis/predis` atau `phpredis` extension
- Laravel Cache facade
- Eloquent query caching

## Perintah Artisan CLI
```bash
composer require predis/predis
php artisan config:cache
redis-cli monitor
```

## Kode Implementasi (Per File)

**Konfigurasi Cache (config/database.php)**
```php
'redis' => [
    'client' => env('REDIS_CLIENT', 'phpredis'),
    'default' => [
        'url' => env('REDIS_URL'),
        'host' => env('REDIS_HOST', '127.0.0.1'),
        'password' => env('REDIS_PASSWORD'),
        'port' => env('REDIS_PORT', 6379),
        'database' => env('REDIS_DB', 0),
    ],
    'cache' => [
        'url' => env('REDIS_URL'),
        'host' => env('REDIS_HOST', '127.0.0.1'),
        'password' => env('REDIS_PASSWORD'),
        'port' => env('REDIS_PORT', 6379),
        'database' => env('REDIS_CACHE_DB', 1),
    ],
],
```

**Konfigurasi Cache Driver (config/cache.php)**
```php
'default' => env('CACHE_DRIVER', 'redis'),

'prefix' => env('CACHE_PREFIX', 'laravel_cache'),
```

**Service dengan Caching (app/Services/ProductService.php)**
```php
namespace App\Services;

use App\Models\Product;
use Illuminate\Support\Facades\Cache;

class ProductService
{
    public function getTopProducts(int $limit = 10): array
    {
        $cacheKey = "top_products:{$limit}";

        return Cache::remember($cacheKey, 3600, function () use ($limit) {
            return Product::with('category')
                ->where('is_active', true)
                ->whereHas('orderItems', fn ($q) => $q->selectRaw('sum(quantity) as total'))
                ->orderByDesc(
                    OrderItem::selectRaw('sum(quantity)')
                        ->whereColumn('product_id', 'products.id')
                        ->groupBy('product_id')
                )
                ->limit($limit)
                ->get()
                ->toArray();
        });
    }

    public function clearTopProductsCache(): void
    {
        Cache::tags(['products', 'top_products'])->flush();
    }
}
```

**Cache Tags untuk Invalidation Selektif**
```php
Cache::tags(['products', 'featured'])->remember('featured_products', 3600, function () {
    return Product::where('is_featured', true)->get();
});

// Hanya menghapus cache featured tanpa menyentuh cache produk lainnya
Cache::tags(['featured'])->flush();
```

**Redis Command Monitoring**
```bash
redis-cli monitor
redis-cli --stat
redis-cli info keyspace
```

## Cara Integrasi & Pengujian
Set `CACHE_DRIVER=redis` di .env. Jalankan `redis-server` sebelum aplikasi. Gunakan `Cache::remember` untuk query berat yang jarang berubah. Monitor hit rate Redis dengan `redis-cli info stats`.
