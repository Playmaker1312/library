# 464. Cara Menggunakan Eager Loading Secara Strategis dengan with dan load

## Definisi & Target
`with()` melakukan eager loading di awal query, sementara `load()` melakukan lazy eager loading setelah data diambil. Targetnya adalah memilih strategi loading yang tepat berdasarkan kebutuhan performa dan konteks eksekusi.

## Komponen yang Terlibat
- Eloquent Builder method `with()`
- Eloquent Collection method `load()`
- Nested relations dan constraints

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

**Controller dengan Strategi Eager Loading (app/Http/Controllers/ProductController.php)**
```php
namespace App\Http\Controllers;

use App\Models\Product;

class ProductController extends Controller
{
    public function index()
    {
        // Eager loading langsung — data sudah siap dari awal
        $products = Product::with([
            'category',
            'reviews' => fn ($query) => $query->where('approved', true)->limit(5),
            'images' => fn ($query) => $query->where('is_primary', true),
        ])->paginate(20);

        return view('products.index', compact('products'));
    }

    public function show(Product $product)
    {
        // Lazy eager loading — hanya di-load saat dibutuhkan
        $product->load([
            'category',
            'variants',
            'reviews.user',
        ]);

        // Conditional loading
        if (auth()->user()?->isAdmin()) {
            $product->load('stockMovements');
        }

        return view('products.show', compact('product'));
    }
}
```

**Repository Pattern dengan Selective Loading (app/Repositories/ProductRepository.php)**
```php
namespace App\Repositories;

use App\Models\Product;

class ProductRepository
{
    public function getActiveProducts(array $relations = [])
    {
        return Product::when(!empty($relations), fn ($q) => $q->with($relations))
                      ->where('is_active', true)
                      ->paginate(20);
    }
}
```

**Blade View — Conditional Load**
```blade
@foreach ($products as $product)
    {{-- Relasi 'reviews' hanya di-load jika akan ditampilkan --}}
    @if ($showReviews)
        @php $product->loadCount('reviews') @endphp
    @endif
    <h2>{{ $product->name }}</h2>
@endforeach
```

**Nested Eager Loading dengan Constraint**
```php
// Hanya memuat komentar yang memiliki rating >= 4
$posts = Post::with(['comments' => function ($query) {
    $query->where('rating', '>=', 4)
          ->orderBy('created_at', 'desc')
          ->with('user');
}])->get();
```

## Cara Integrasi & Pengujian
Gunakan Debugbar untuk membandingkan jumlah query antara `with()` di awal vs `load()` setelah kondisional. Pilih `with()` jika relasi pasti digunakan, `load()` jika hanya digunakan dalam kondisi tertentu.
