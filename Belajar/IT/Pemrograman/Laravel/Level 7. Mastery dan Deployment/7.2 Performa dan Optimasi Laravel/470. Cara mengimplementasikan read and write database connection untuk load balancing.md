# 470. Cara Mengimplementasikan Read and Write Database Connection untuk Load Balancing

## Definisi & Target
Laravel mendukung multiple database connections dengan pemisahan read (SELECT) dan write (INSERT/UPDATE/DELETE). Targetnya adalah mendistribusikan beban database dengan mengirim query baca ke replica dan query tulis ke primary.

## Komponen yang Terlibat
- MySQL primary-replica replication
- Laravel database configuration
- Eloquent ORM automatic read/write splitting

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

**Konfigurasi Database Read/Write (config/database.php)**
```php
'mysql' => [
    'driver' => 'mysql',
    'read' => [
        'host' => [
            env('DB_READ_HOST_1', '192.168.1.10'),
            env('DB_READ_HOST_2', '192.168.1.11'),
        ],
        'port' => env('DB_PORT', 3306),
    ],
    'write' => [
        'host' => [
            env('DB_WRITE_HOST', '192.168.1.1'),
        ],
        'port' => env('DB_PORT', 3306),
    ],
    'sticky' => env('DB_STICKY', true),
    'database' => env('DB_DATABASE', 'laravel'),
    'username' => env('DB_USERNAME', 'root'),
    'password' => env('DB_PASSWORD', ''),
    'unix_socket' => env('DB_SOCKET', ''),
    'charset' => 'utf8mb4',
    'collation' => 'utf8mb4_unicode_ci',
    'prefix' => '',
    'prefix_indexes' => true,
    'strict' => true,
    'engine' => null,
    'options' => extension_loaded('pdo_mysql') ? array_filter([
        PDO::MYSQL_ATTR_SSL_CA => env('MYSQL_ATTR_SSL_CA'),
    ]) : [],
],
```

**Environment Variables (.env)**
```env
DB_CONNECTION=mysql
DB_HOST=primary.db.internal
DB_READ_HOST_1=replica1.db.internal
DB_READ_HOST_2=replica2.db.internal
DB_WRITE_HOST=primary.db.internal
DB_DATABASE=laravel
DB_USERNAME=laravel
DB_PASSWORD=secret
DB_STICKY=true
```

**Memaksa Query ke Connection Tertentu**
```php
// Query ke read connection (default untuk SELECT)
$users = DB::table('users')->where('active', true)->get();

// Memaksa ke write connection
$user = DB::connection('mysql')->table('users')->find(1);

// Update otomatis ke write connection
DB::table('users')->where('id', 1)->update(['name' => 'New Name']);

// Transaction menggunakan write connection
DB::beginTransaction();
DB::table('orders')->insert($data);
DB::table('inventory')->decrement('stock', 1);
DB::commit();
```

**Verifikasi Connection yang Digunakan**
```php
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Log;

DB::listen(function ($query) {
    Log::info('Query executed on connection: ' . $query->connectionName, [
        'sql' => $query->sql,
        'time' => $query->time,
    ]);
});
```

## Cara Integrasi & Pengujian
Konfigurasi MySQL replication terlebih dahulu. Set `sticky=true` agar saat ada write, request berikutnya tetap membaca dari primary untuk konsistensi data. Monitor pemisahan query melalui log database.
