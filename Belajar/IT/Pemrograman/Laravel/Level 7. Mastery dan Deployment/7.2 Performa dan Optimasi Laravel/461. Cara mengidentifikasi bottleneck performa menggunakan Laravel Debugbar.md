# 461. Cara Mengidentifikasi Bottleneck Performa Menggunakan Laravel Debugbar

## Definisi & Target
Laravel Debugbar menampilkan informasi lengkap tentang query database, memori, waktu eksekusi, dan jumlah render view di setiap halaman. Targetnya adalah mengidentifikasi bagian kode yang lambat atau boros resource.

## Komponen yang Terlibat
- Laravel Debugbar package (barryvdh/laravel-debugbar)
- Query log, timing, dan memory profiler
- Debugbar middleware

## Perintah Artisan CLI
```bash
composer require barryvdh/laravel-debugbar --dev
php artisan vendor:publish --provider="Barryvdh\Debugbar\ServiceProvider"
```

## Kode Implementasi (Per File)

**Konfigurasi (config/debugbar.php)**
```php
<?php

return [
    'enabled' => env('DEBUGBAR_ENABLED', false),
    'except' => [
        'telescope*',
        'horizon*',
    ],
    'collectors' => [
        'phpinfo' => false,
        'messages' => true,
        'time' => true,
        'memory' => true,
        'exceptions' => true,
        'log' => true,
        'db' => true,
        'views' => true,
        'route' => true,
        'auth' => true,
        'gate' => true,
        'session' => true,
        'symfony_request' => true,
        'mail' => true,
        'laravel' => true,
        'events' => true,
        'default_request' => false,
    ],
];
```

**Mengaktifkan hanya di environment development (config/app.php)**
```php
'debug' => (bool) env('APP_DEBUG', false),
```

**.env**
```env
APP_DEBUG=true
DEBUGBAR_ENABLED=true
```

## Cara Integrasi & Pengujian
Akses halaman aplikasi dan lihat toolbar Debugbar di bagian bawah. Perhatikan jumlah query (N+1), waktu eksekusi >500ms, dan memori >50MB sebagai indikator bottleneck.
