# 12. Layout dengan Blade — Satu Template, Banyak Halaman

## Penjelasan

**Layout Blade** memungkinkan kamu memiliki satu template induk yang dipakai oleh semua halaman. Ini menghindari duplikasi HTML (navbar, footer, CSS) yang sama di setiap halaman.

Tiga konsep kunci:
1. **`@yield`** — tempat di layout yang akan diisi oleh child view
2. **`@extends`** — child view menyatakan "saya menggunakan layout ini"
3. **`@section`** — child view mengisi bagian tertentu dari layout

## Fungsi

- Menghindari duplikasi HTML (navbar, footer, CSS, JS) di setiap halaman
- Memudahkan perubahan: edit navbar sekali, semua halaman berubah
- Memisahkan struktur halaman (layout) dari konten spesifik (child view)

## Cara Pengimplementasian

```blade
{{-- resources/views/layouts/app.blade.php -- LAYOUT UTAMA --}}
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="csrf-token" content="{{ csrf_token() }}">
    <title>@yield('title', config('app.name')) | Perpustakaan</title>
    @vite(['resources/css/app.css', 'resources/js/app.js'])
    @stack('styles')
</head>
<body>
    <nav>
        <a href="{{ route('beranda') }}">Beranda</a>
        <a href="{{ route('buku.index') }}">Katalog</a>
        @auth
            <span>{{ auth()->user()->nama }}</span>
            <form action="{{ route('logout') }}" method="POST">
                @csrf
                <button>Logout</button>
            </form>
        @else
            <a href="{{ route('login') }}">Login</a>
        @endauth
    </nav>

    {{-- Flash message --}}
    @if(session('sukses'))
        <div class="alert alert-success">{{ session('sukses') }}</div>
    @endif

    <main>
        @yield('content')
    </main>

    <footer>
        <p>&copy; {{ date('Y') }} Perpustakaan Digital</p>
    </footer>

    @stack('scripts')
</body>
</html>
```

```blade
{{-- resources/views/buku/index.blade.php -- CHILD VIEW --}}
@extends('layouts.app')  {{-- Gunakan layout app --}}

@section('title', 'Katalog Buku')  {{-- Isi @yield('title') --}}

@section('content')  {{-- Isi @yield('content') --}}
<div class="container">
    <h1>Katalog Buku</h1>
    @forelse($buku as $item)
        <div class="card">
            <h3>{{ $item->judul }}</h3>
            <a href="{{ route('buku.show', $item) }}">Detail</a>
        </div>
    @empty
        <p>Belum ada buku.</p>
    @endforelse
</div>
@endsection

@push('scripts')  {{-- Tambah ke @stack('scripts') --}}
<script>
    console.log('Halaman katalog buku');
</script>
@endpush
```

**Stack** (`@push` / `@stack`) digunakan untuk menambahkan CSS atau JS spesifik halaman tanpa mengubah layout.

## Analogi

Layout Blade seperti **template surat resmi perpustakaan**:

```
┌──────────────────────────────────────┐
│  KOP SURAT PERPUSTAKAAN DIGITAL      │  ← Layout (@yield)
│  ================================    │
│                                      │
│  [ISI SURAT]                         │  ← Child view (@section)
│  (berubah sesuai kebutuhan)          │
│                                      │
│  ================================    │
│  Jl. Merdeka No. 1, Jakarta          │  ← Layout (@yield)
└──────────────────────────────────────┘
```

- **Layout (`layouts/app.blade.php`)** = Template surat dengan kop dan footer tetap
- **`@yield('content')`** = "Letakkan isi surat di sini"
- **Child view** = Isi surat yang berubah-ubah (surat peminjaman, surat pengembalian)
- **`@section('title')`** = Judul surat yang berbeda-beda
- **`@stack('scripts')`** = Lampiran spesifik untuk surat tertentu

Semua surat menggunakan kop dan footer yang sama. Jika kop perlu diubah (misal: ganti logo), cukup edit layout — semua surat otomatis berubah.

## Dipakai untuk Apa

- **Setiap aplikasi Laravel** — hampir semua project punya layout utama
- **Halaman admin** — layout khusus admin dengan sidebar navigasi
- **Halaman publik** — layout berbeda untuk front-end dan landing page
- **Email template** — layout untuk email notifikasi

## Kesalahan Umum

1. **Lupa `@endsection` atau `@show`** — section tidak tertutup dengan benar
2. **Nama section tidak cocok** — layout punya `@yield('konten')` tapi child menggunakan `@section('content')`
3. **Child view tidak `@extends`** — layout tidak akan diterapkan
4. **Dua `@yield` dengan nama yang sama** — hanya yang pertama diproses
5. **Menaruh `@push` di luar `@section`** — tetap bisa, tapi lebih rapi jika di dalam
6. **Lupa `@stack` di layout** — `@push` tidak akan muncul karena tidak ada `@stack` yang menampungnya

## Soal Latihan

1. **Praktik**: Buat layout `layouts/app.blade.php` dengan navbar (Beranda, Katalog, Kontak) dan footer. Lalu buat child view `beranda.blade.php` yang meng-extend layout tersebut!
2. **Analisis**: Apa perbedaan `@yield` dengan `@stack`? Kapan menggunakan masing-masing?
3. **Praktik**: Di child view, tambahkan script JavaScript spesifik halaman menggunakan `@push` dan pastikan muncul di layout melalui `@stack`!

<details>
<summary>Jawaban</summary>

1. **Layout:**
   ```blade
   {{-- layouts/app.blade.php --}}
   <!DOCTYPE html>
   <html>
   <head><title>@yield('title') | Perpustakaan</title></head>
   <body>
       <nav>
           <a href="{{ route('beranda') }}">Beranda</a>
           <a href="{{ route('buku.index') }}">Katalog</a>
           <a href="{{ route('kontak') }}">Kontak</a>
       </nav>
       <main>@yield('content')</main>
       <footer>&copy; 2024 Perpustakaan</footer>
   </body>
   </html>
   ```
   **Child view:**
   ```blade
   {{-- beranda.blade.php --}}
   @extends('layouts.app')
   @section('title', 'Beranda')
   @section('content')
       <h1>Selamat Datang di Perpustakaan</h1>
   @endsection
   ```

2. **Perbedaan:**
   - **`@yield`** — satu konten, bisa punya default. Cocok untuk judul halaman, konten utama
   - **`@stack`** — bisa di-*push* berkali-kali dari berbagai tempat. Cocok untuk kumpulan script/stylesheets
   - `@yield` diganti dengan `@section`; `@stack` ditambah dengan `@push`

3. **Child view dengan push:**
   ```blade
   @push('scripts')
   <script>
       console.log('Halaman spesifik ini');
   </script>
   @endpush
   ```
   Pastikan di layout ada:
   ```blade
   @stack('scripts')
   ```
   Sebelum `</body>`.
</details>
