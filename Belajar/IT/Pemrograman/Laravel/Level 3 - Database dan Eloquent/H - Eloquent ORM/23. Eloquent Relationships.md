# 23. Eloquent Relationships — Relasi Antar Tabel

## Penjelasan

Relasi Eloquent menghubungkan model satu dengan yang lain, mencerminkan hubungan antar tabel di database. Tiga jenis relasi yang paling umum:

1. **One to Many (1:N)** — Satu buku punya banyak peminjaman
2. **Belongs to (N:1)** — Peminjaman milik satu buku
3. **Many to Many (N:N)** — Anggota bisa pinjam banyak buku, buku bisa dipinjam banyak anggota (via tabel pivot)

## Fungsi

- Mengakses data relasi seperti properti: `$peminjaman->buku->judul`
- Mengambil data terkait dengan method: `$anggota->peminjaman()->where('status', 'dipinjam')->get()`
- Mencegah N+1 problem dengan eager loading (`with()`)

## Cara Pengimplementasian

```php
<?php
// app/Models/Buku.php
class Buku extends Model
{
    // 1 buku punya banyak peminjaman
    public function peminjaman(): HasMany
    {
        return $this->hasMany(Peminjaman::class);
    }

    // Hitung jumlah peminjaman (tanpa load data)
    public function peminjamanAktif(): HasMany
    {
        return $this->hasMany(Peminjaman::class)->where('status', 'dipinjam');
    }
}

// app/Models/Anggota.php
class Anggota extends Model
{
    // 1 anggota punya banyak peminjaman
    public function peminjaman(): HasMany
    {
        return $this->hasMany(Peminjaman::class);
    }

    // Peminjaman yang sedang aktif
    public function peminjamanAktif(): HasMany
    {
        return $this->hasMany(Peminjaman::class)->where('status', 'dipinjam');
    }

    // Buku yang pernah dipinjam (via tabel peminjaman)
    public function bukuDipinjam(): BelongsToMany
    {
        return $this->belongsToMany(Buku::class, 'peminjaman')
                    ->withPivot('tanggal_pinjam', 'status')
                    ->withTimestamps();
    }

    // Batas maksimal peminjaman
    public function getBatasPinjam(): int
    {
        return 5; // maksimal 5 buku
    }

    public function memilikiDenda(): bool
    {
        return $this->peminjaman()
            ->where('status', 'dipinjam')
            ->where('batas_kembali', '<', now())
            ->exists();
    }
}

// app/Models/Peminjaman.php
class Peminjaman extends Model
{
    // Peminjaman milik satu buku
    public function buku(): BelongsTo
    {
        return $this->belongsTo(Buku::class);
    }

    // Peminjaman milik satu anggota
    public function anggota(): BelongsTo
    {
        return $this->belongsTo(Anggota::class);
    }
}
```

```php
<?php
// Cara pakai di controller

// EAGER LOADING — hindari N+1!
// ❌ N+1 problem:
$peminjaman = Peminjaman::all();
foreach ($peminjaman as $p) {
    echo $p->buku->judul;  // Query SELECT buku setiap iterasi!
}
// 100 peminjaman = 1 + 100 = 101 queries!

// ✅ Eager loading:
$peminjaman = Peminjaman::with(['buku', 'anggota'])->get();
foreach ($peminjaman as $p) {
    echo $p->buku->judul;  // Data sudah di-load — tidak ada query baru
}
// = 3 queries (peminjaman, buku, anggota)

// Eager loading dengan filter
$peminjaman = Peminjaman::with([
    'buku:id,judul,pengarang',
    'anggota' => fn($q) => $q->where('status', 'aktif'),
])->where('status', 'dipinjam')->get();

// withCount: hitung jumlah relasi
$buku = Buku::withCount('peminjaman')->get();
echo $buku->peminjaman_count;  // sudah otomatis
```

## Analogi

Relasi Eloquent seperti **hubungan di perpustakaan**:

**One to Many (HasMany / BelongsTo):**
```
Buku (1) ───→ Peminjaman (N)
Anggota (1) ───→ Peminjaman (N)
```
- Satu buku bisa dipinjam berkali-kali oleh anggota berbeda
- Satu anggota bisa meminjam banyak buku
- `$peminjaman->buku` = "Peminjaman ini untuk buku yang mana?"
- `$buku->peminjaman` = "Semua peminjaman untuk buku ini"

**Belongs to Many (Many to Many):**
```
Anggota (N) ←──→ Buku (N) via tabel peminjaman
```
- Anggota meminjam buku → tabel peminjaman mencatat siapa pinjam apa
- `$anggota->bukuDipinjam` = "Buku apa saja yang pernah dipinjam anggota ini?"

**Eager Loading:** Bayangkan pustakawan yang efisien:
- Tanpa eager loading: "Beri saya daftar peminjaman" → pustakawan ambil daftar. "Sekarang beri judul buku untuk peminjaman 1" → pustakawan cari lagi. "Sekarang untuk peminjaman 2" → cari lagi... capek.
- Dengan eager loading: "Beri saya daftar peminjaman beserta judul bukunya" → pustakawan ambil semuanya sekaligus.

## Dipakai untuk Apa

- **Detail halaman**: menampilkan buku beserta riwayat peminjamannya
- **Dashboard**: "Buku paling banyak dipinjam", "Anggota yang sering telat"
- **Filter relasi**: "Tampilkan buku yang pernah dipinjam"
- **Form select**: dropdown anggota, dropdown buku

## Kesalahan Umum

1. **N+1 problem** — query di dalam loop. Selalu cek dengan `with()`. Gunakan **Laravel Debugbar** untuk mendeteksi
2. **Lupa eager loading di API** — API response jadi lambat karena banyak query
3. **Foreign key tidak sesuai konvensi** — `peminjaman.buku_id` otomatis cocok dengan `Buku::class`. Jika nama kolom berbeda, perlu parameter tambahan
4. **Pivot table tidak di-define** — Many to Many butuh tabel pivot (peminjaman sebagai pivot)
5. **Relasi dipanggil sebagai method vs properti** — `$buku->peminjaman()` (query builder) vs `$buku->peminjaman` (collection). Method untuk tambah kondisi, properti untuk akses data
