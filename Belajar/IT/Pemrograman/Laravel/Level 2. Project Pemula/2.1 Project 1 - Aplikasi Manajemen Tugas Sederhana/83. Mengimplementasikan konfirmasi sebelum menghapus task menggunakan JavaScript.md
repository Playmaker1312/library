# 83. Mengimplementasikan konfirmasi sebelum menghapus task menggunakan JavaScript

## Definisi & Target
Menampilkan dialog konfirmasi sebelum task benar-benar dihapus. Menggunakan JavaScript `confirm()` bawaan browser untuk memastikan pengguna tidak sengaja menghapus data.

## Komponen yang Terlibat
- Blade View: `resources/views/tasks/index.blade.php` (form hapus)
- Blade View: `resources/views/tasks/show.blade.php` (form hapus)
- Tidak perlu file JavaScript terpisah

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**resources/views/tasks/index.blade.php (bagian tombol hapus)**
```php
<form action="{{ route('tasks.destroy', $task) }}" method="POST" class="inline-block" onsubmit="return confirmDelete(event, '{{ $task->title }}')">
    @csrf
    @method('DELETE')
    <button type="submit" class="text-red-500 hover:text-red-700">
        Hapus
    </button>
</form>
```

**Tambahkan di layout atau di bagian bawah view index:**
```php
@section('scripts')
<script>
    function confirmDelete(event, title) {
        if (!confirm(`Apakah Anda yakin ingin menghapus tugas "${title}"? Tindakan ini tidak dapat dibatalkan.`)) {
            event.preventDefault();
            return false;
        }
        return true;
    }
</script>
@endsection
```

## Cara Integrasi & Pengujian
Klik tombol hapus pada halaman index atau show. Dialog konfirmasi akan muncul dengan judul tugas yang akan dihapus. Klik "OK" untuk menghapus atau "Cancel" untuk membatalkan.
