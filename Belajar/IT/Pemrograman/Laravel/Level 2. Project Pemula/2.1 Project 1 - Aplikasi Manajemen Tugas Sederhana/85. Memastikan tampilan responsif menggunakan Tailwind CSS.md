# 85. Memastikan tampilan responsif menggunakan Tailwind CSS

## Definisi & Target
Memastikan semua halaman di aplikasi manajemen tugas tampil dengan baik di berbagai ukuran layar (desktop, tablet, mobile) menggunakan utility classes Tailwind CSS yang responsif.

## Komponen yang Terlibat
- Semua Blade View yang sudah dibuat
- File konfigurasi: `tailwind.config.js`
- File CSS: `resources/css/app.css`

## Perintah Artisan CLI
Tidak ada perintah Artisan. Pastikan Tailwind CSS sudah terinstal:
```
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

## Kode Implementasi (Per File)

**tailwind.config.js**
```js
export default {
    content: [
        "./resources/**/*.blade.php",
        "./resources/**/*.js",
        "./resources/**/*.vue",
    ],
    theme: {
        extend: {},
    },
    plugins: [],
};
```

**resources/css/app.css**
```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

**Contoh penerapan responsif di index.blade.php (tabel jadi card di mobile):**
```php
{{-- Tabel disembunyikan di layar kecil, diganti dengan card --}}
<div class="hidden md:block bg-white shadow-md rounded my-6 overflow-x-auto">
    <table class="min-w-full table-auto">
        {{-- ... tabel untuk desktop --}}
    </table>
</div>

{{-- Card view untuk mobile --}}
<div class="md:hidden space-y-4">
    @forelse($tasks as $task)
    <div class="bg-white shadow-md rounded p-4">
        <h3 class="font-semibold text-gray-800 {{ $task->isOverdue() ? 'text-red-500' : '' }}">
            {{ $task->title }}
        </h3>
        <span class="px-2 py-1 rounded text-xs inline-block mt-2
            @if($task->status == 'completed') bg-green-200 text-green-800
            @elseif($task->status == 'in_progress') bg-yellow-200 text-yellow-800
            @else bg-gray-200 text-gray-800 @endif">
            {{ \App\Models\Task::statuses()[$task->status] }}
        </span>
        <div class="mt-3 flex gap-2 text-sm">
            <a href="{{ route('tasks.show', $task) }}" class="text-blue-500">Lihat</a>
            <a href="{{ route('tasks.edit', $task) }}" class="text-yellow-500">Edit</a>
            <form action="{{ route('tasks.destroy', $task) }}" method="POST" class="inline" onsubmit="return confirm('Hapus tugas?')">
                @csrf @method('DELETE')
                <button type="submit" class="text-red-500">Hapus</button>
            </form>
        </div>
    </div>
    @empty
    <p class="text-gray-400 text-center">Belum ada tugas.</p>
    @endforelse
</div>
```

## Cara Integrasi & Pengujian
1. Jalankan `npm run build` untuk mengompilasi CSS
2. Buka aplikasi di browser dan gunakan DevTools (F12) untuk menguji berbagai ukuran layar
3. Pastikan navigasi, tabel, dan form tetap mudah digunakan di layar mobile
