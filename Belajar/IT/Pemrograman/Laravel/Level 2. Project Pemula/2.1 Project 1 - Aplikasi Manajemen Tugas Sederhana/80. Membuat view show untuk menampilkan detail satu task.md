# 80. Membuat view show untuk menampilkan detail satu task

## Definisi & Target
Membuat halaman detail yang menampilkan informasi lengkap dari satu tugas. Halaman ini menampilkan judul, deskripsi, status, due date, dan tombol navigasi.

## Komponen yang Terlibat
- Blade View: `resources/views/tasks/show.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**resources/views/tasks/show.blade.php**
```php
@extends('layouts.app')

@section('content')
<div class="container mx-auto px-4 py-8">
    <div class="max-w-2xl mx-auto">
        <div class="flex justify-between items-center mb-6">
            <h1 class="text-2xl font-bold text-gray-800">Detail Tugas</h1>
            <a href="{{ route('tasks.index') }}" class="text-gray-500 hover:text-gray-700">
                &larr; Kembali
            </a>
        </div>

        <div class="bg-white shadow-md rounded px-8 pt-6 pb-8 mb-4">
            <div class="mb-4">
                <h2 class="text-xl font-semibold text-gray-800 {{ $task->isOverdue() ? 'text-red-500' : '' }}">
                    {{ $task->title }}
                    @if($task->isOverdue())
                        <span class="text-sm bg-red-100 text-red-800 px-2 py-1 rounded ml-2">Terlambat</span>
                    @endif
                </h2>
            </div>

            <div class="mb-4">
                <span class="px-3 py-1 rounded text-sm font-medium
                    @if($task->status == 'completed') bg-green-200 text-green-800
                    @elseif($task->status == 'in_progress') bg-yellow-200 text-yellow-800
                    @else bg-gray-200 text-gray-800 @endif">
                    {{ \App\Models\Task::statuses()[$task->status] }}
                </span>
            </div>

            @if($task->description)
            <div class="mb-4">
                <h3 class="text-sm font-bold text-gray-600 uppercase mb-2">Deskripsi</h3>
                <p class="text-gray-700 whitespace-pre-wrap">{{ $task->description }}</p>
            </div>
            @endif

            <div class="mb-4">
                <h3 class="text-sm font-bold text-gray-600 uppercase mb-2">Tenggat Waktu</h3>
                <p class="text-gray-700">{{ $task->due_date ? $task->due_date->format('d F Y') : 'Tidak ada tenggat' }}</p>
            </div>

            <div class="mb-4">
                <h3 class="text-sm font-bold text-gray-600 uppercase mb-2">Dibuat Pada</h3>
                <p class="text-gray-700">{{ $task->created_at->format('d F Y H:i') }}</p>
            </div>

            <div class="mb-4">
                <h3 class="text-sm font-bold text-gray-600 uppercase mb-2">Terakhir Diperbarui</h3>
                <p class="text-gray-700">{{ $task->updated_at->format('d F Y H:i') }}</p>
            </div>

            <div class="flex gap-4 mt-6">
                <a href="{{ route('tasks.edit', $task) }}" class="bg-yellow-500 hover:bg-yellow-700 text-white font-bold py-2 px-4 rounded">
                    Edit
                </a>
                <form action="{{ route('tasks.destroy', $task) }}" method="POST" onsubmit="return confirm('Apakah Anda yakin ingin menghapus tugas ini?')">
                    @csrf
                    @method('DELETE')
                    <button type="submit" class="bg-red-500 hover:bg-red-700 text-white font-bold py-2 px-4 rounded">
                        Hapus
                    </button>
                </form>
            </div>
        </div>
    </div>
</div>
@endsection
```

## Cara Integrasi & Pengujian
Akses `/tasks/{id}` di browser. Pastikan semua detail tugas tampil dengan benar.
