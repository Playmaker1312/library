# 82. Mengimplementasikan flash message untuk notifikasi setelah operasi berhasil

## Definisi & Target
Menampilkan pesan notifikasi sementara (flash message) setelah pengguna berhasil melakukan operasi CRUD. Flash message akan muncul sekali lalu hilang setelah halaman di-refresh.

## Komponen yang Terlibat
- TaskController (sudah diimplementasikan dengan `with('success', ...)`)
- Layout Blade: `resources/views/layouts/app.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**resources/views/layouts/app.blade.php (bagian flash message)**
Tambahkan di dalam layout utama agar bisa digunakan di semua halaman:

```php
@if(session('success'))
    <div id="flash-message" class="bg-green-100 border border-green-400 text-green-700 px-4 py-3 rounded relative mb-4" role="alert">
        <span class="block sm:inline">{{ session('success') }}</span>
        <button type="button" class="absolute top-0 bottom-0 right-0 px-4 py-3" onclick="document.getElementById('flash-message').remove()">
            <span class="text-green-500">&times;</span>
        </button>
    </div>
@endif

@if(session('error'))
    <div id="flash-error" class="bg-red-100 border border-red-400 text-red-700 px-4 py-3 rounded relative mb-4" role="alert">
        <span class="block sm:inline">{{ session('error') }}</span>
        <button type="button" class="absolute top-0 bottom-0 right-0 px-4 py-3" onclick="document.getElementById('flash-error').remove()">
            <span class="text-red-500">&times;</span>
        </button>
    </div>
@endif
```

## Cara Integrasi & Pengujian
Flash message sudah otomatis muncul setelah redirect dari controller yang menggunakan `with('success', ...)`. Uji dengan menambah/edit/menghapus task dan pastikan notifikasi muncul di halaman.
