# 84. Membuat layout Blade utama dengan navigation dan footer

## Definisi & Target
Membuat layout utama yang akan digunakan oleh semua halaman. Layout ini berisi navigasi (navbar), area konten utama (`@yield('content')`), dan footer.

## Komponen yang Terlibat
- Blade Layout: `resources/views/layouts/app.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan. Buat direktori `resources/views/layouts/` secara manual.

## Kode Implementasi (Per File)

**resources/views/layouts/app.blade.php**
```php
<!DOCTYPE html>
<html lang="{{ str_replace('_', '-', app()->getLocale()) }}">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="csrf-token" content="{{ csrf_token() }}">
    <title>@yield('title', 'Manajemen Tugas') - Aplikasi Manajemen Tugas</title>
    @vite('resources/css/app.css')
</head>
<body class="bg-gray-100 min-h-screen flex flex-col">
    <nav class="bg-white shadow-lg">
        <div class="max-w-7xl mx-auto px-4">
            <div class="flex justify-between items-center h-16">
                <a href="{{ route('tasks.index') }}" class="text-xl font-bold text-gray-800">
                    Manajemen Tugas
                </a>
                <div class="flex gap-4">
                    <a href="{{ route('tasks.index') }}" class="text-gray-600 hover:text-gray-800">Daftar Tugas</a>
                    <a href="{{ route('tasks.create') }}" class="text-gray-600 hover:text-gray-800">Tambah Tugas</a>
                </div>
            </div>
        </div>
    </nav>

    <main class="flex-1">
        <div class="max-w-7xl mx-auto px-4 py-6">
            @if(session('success'))
                <div id="flash-message" class="bg-green-100 border border-green-400 text-green-700 px-4 py-3 rounded relative mb-4">
                    <span>{{ session('success') }}</span>
                    <button type="button" class="absolute top-0 bottom-0 right-0 px-4 py-3" onclick="document.getElementById('flash-message').remove()">&times;</button>
                </div>
            @endif
            @if(session('error'))
                <div id="flash-error" class="bg-red-100 border border-red-400 text-red-700 px-4 py-3 rounded relative mb-4">
                    <span>{{ session('error') }}</span>
                    <button type="button" class="absolute top-0 bottom-0 right-0 px-4 py-3" onclick="document.getElementById('flash-error').remove()">&times;</button>
                </div>
            @endif
            @yield('content')
        </div>
    </main>

    <footer class="bg-white shadow-inner mt-8">
        <div class="max-w-7xl mx-auto px-4 py-4 text-center text-gray-500 text-sm">
            &copy; {{ date('Y') }} Aplikasi Manajemen Tugas. Dibangun dengan Laravel.
        </div>
    </footer>

    @yield('scripts')
</body>
</html>
```

## Cara Integrasi & Pengujian
Semua view yang menggunakan `@extends('layouts.app')` akan otomatis menggunakan layout ini. Pastikan navigasi dan footer muncul di setiap halaman.
