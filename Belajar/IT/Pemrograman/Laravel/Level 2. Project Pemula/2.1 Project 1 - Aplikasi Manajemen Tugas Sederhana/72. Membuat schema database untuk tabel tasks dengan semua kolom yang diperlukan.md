# 72. Membuat schema database untuk tabel tasks dengan semua kolom yang diperlukan

## Definisi & Target
Merancang struktur tabel `tasks` di database yang akan menyimpan data tugas. Kolom yang diperlukan meliputi id, title, description, status (pending/in_progress/completed), due_date, dan timestamps.

## Komponen yang Terlibat
- Database migration file: `database/migrations/xxxx_xx_xx_create_tasks_table.php`

## Perintah Artisan CLI
```
php artisan make:migration create_tasks_table
```

## Kode Implementasi (Per File)

**database/migrations/xxxx_xx_xx_create_tasks_table.php**
```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('tasks', function (Blueprint $table) {
            $table->id();
            $table->string('title');
            $table->text('description')->nullable();
            $table->enum('status', ['pending', 'in_progress', 'completed'])->default('pending');
            $table->date('due_date')->nullable();
            $table->timestamps();
        });
    }

    public function down(): void
    {

```

## Cara Integrasi & Pengujian
Jalankan migration untuk memastikan tabel `tasks` terbentuk di database. Periksa menggunakan tools database seperti phpMyAdmin atau TablePlus untuk memastikan semua kolom sesuai rencana.
