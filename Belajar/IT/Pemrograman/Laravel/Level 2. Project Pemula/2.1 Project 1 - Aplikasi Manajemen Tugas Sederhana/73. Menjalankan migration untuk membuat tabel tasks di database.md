# 73. Menjalankan migration untuk membuat tabel tasks di database

## Definisi & Target
Mengeksekusi file migration yang telah dibuat agar tabel `tasks` benar-benar terbuat di database. Pastikan konfigurasi database di file `.env` sudah benar sebelum menjalankan migration.

## Komponen yang Terlibat
- File `.env` (konfigurasi database)
- File migration yang sudah dibuat sebelumnya

## Perintah Artisan CLI
```
php artisan migrate
```

## Kode Implementasi (Per File)
Tidak ada kode baru. Cukup jalankan perintah di atas.

## Cara Integrasi & Pengujian
1. Buka file `.env` dan pastikan pengaturan database benar:
```
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=nama_database
DB_USERNAME=root
DB_PASSWORD=
```
2. Jalankan `php artisan migrate`
3. Verifikasi dengan `php artisan migrate:status` untuk melihat status migration
4. Cek langsung di database menggunakan client database
