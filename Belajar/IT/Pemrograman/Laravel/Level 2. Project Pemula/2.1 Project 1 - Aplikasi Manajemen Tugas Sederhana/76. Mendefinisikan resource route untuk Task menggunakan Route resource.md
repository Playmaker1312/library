# 76. Mendefinisikan resource route untuk Task menggunakan Route resource

## Definisi & Target
Mendaftarkan route resource untuk TaskController agar semua endpoint CRUD otomatis terdaftar. Route resource akan menghasilkan URL yang sesuai dengan konvensi RESTful.

## Komponen yang Terlibat
- File routes: `routes/web.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**routes/web.php**
```php
<?php

use Illuminate\Support\Facades\Route;
use App\Http\Controllers\TaskController;

Route::get('/', function () {
    return redirect()->route('tasks.index');
});

Route::resource('tasks', TaskController::class);
```

## Cara Integrasi & Pengujian
Jalankan `php artisan route:list` untuk melihat daftar semua route yang terdaftar. Pastikan muncul endpoint berikut:
- GET /tasks (index)
- GET /tasks/create (create)
- POST /tasks (store)
- GET /tasks/{task} (show)
- GET /tasks/{task}/edit (edit)
- PUT/PATCH /tasks/{task} (update)
- DELETE /tasks/{task} (destroy)
