# 94. Membuat halaman admin sederhana untuk moderasi pesan

## Definisi & Target
Membuat halaman admin yang menampilkan semua pesan (pending, approved, rejected) dan menyediakan tombol aksi untuk approve, reject, dan delete.

## Komponen yang Terlibat
- Controller: `app/Http/Controllers/Admin/GuestbookController.php`
- Blade View: `resources/views/admin/guestbook/index.blade.php`
- Route: `routes/web.php`

## Perintah Artisan CLI
```
php artisan make:controller Admin/GuestbookController
```

## Kode Implementasi (Per File)

**app/Http/Controllers/Admin/GuestbookController.php**
```php
<?php

namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Models\GuestbookEntry;
use Illuminate\Http\Request;

class GuestbookController extends Controller
{
    public function index()
    {
        $entries = GuestbookEntry::latest()->paginate(15);
        return view('admin.guestbook.index', compact('entries'));
    }

    public function approve(GuestbookEntry $guestbookEntry)
    {
        $guestbookEntry->update(['status' => GuestbookEntry::STATUS_APPROVED]);

        return redirect()->route('admin.guestbook.index')
            ->with('success', 'Pesan berhasil disetujui.');
    }

    public function reject(GuestbookEntry $guestbookEntry)
    {
        $guestbookEntry->update(['status' => GuestbookEntry::STATUS_REJECTED]);

        return redirect()->route('admin.guestbook.index')
            ->with('success', 'Pesan berhasil ditolak.');
    }

    public function destroy(GuestbookEntry $guestbookEntry)
    {
        $guestbookEntry->delete();

        return redirect()->route('admin.guestbook.index')
            ->with('success', 'Pesan berhasil dihapus.');
    }
}
```

**resources/views/admin/guestbook/index.blade.php**
```php
@extends('layouts.admin')

@section('content')
<div class="container mx-auto px-4 py-8">
    <h1 class="text-2xl font-bold text-gray-800 mb-6">Moderasi Buku Tamu</h1>

    @if(session('success'))
        <div class="bg-green-100 border border-green-400 text-green-700 px-4 py-3 rounded mb-4">
            {{ session('success') }}
        </div>
    @endif

    <div class="bg-white shadow-md rounded overflow-x-auto">
        <table class="min-w-full table-auto">
            <thead>
                <tr class="bg-gray-100 text-gray-600 uppercase text-sm">
                    <th class="py-3 px-4 text-left">Nama</th>
                    <th class="py-3 px-4 text-left">Email</th>
                    <th class="py-3 px-4 text-left">Pesan</th>
                    <th class="py-3 px-4 text-left">Status</th>
                    <th class="py-3 px-4 text-left">IP</th>
                    <th class="py-3 px-4 text-center">Aksi</th>
                </tr>
            </thead>
            <tbody class="text-gray-600 text-sm">
                @foreach($entries as $entry)
                <tr class="border-b border-gray-200 hover:bg-gray-50">
                    <td class="py-3 px-4">{{ $entry->name }}</td>
                    <td class="py-3 px-4">{{ $entry->email }}</td>
                    <td class="py-3 px-4 max-w-xs truncate">{{ $entry->message }}</td>
                    <td class="py-3 px-4">
                        <span class="px-2 py-1 rounded text-xs font-medium
                            @if($entry->status == 'approved') bg-green-200 text-green-800
                            @elseif($entry->status == 'rejected') bg-red-200 text-red-800
                            @else bg-yellow-200 text-yellow-800 @endif">
                            {{ \App\Models\GuestbookEntry::statuses()[$entry->status] }}
                        </span>
                    </td>
                    <td class="py-3 px-4 text-xs">{{ $entry->ip_address ?? '-' }}</td>
                    <td class="py-3 px-4 text-center">
                        <div class="flex justify-center gap-2">
                            @if($entry->status != 'approved')
                                <form action="{{ route('admin.guestbook.approve', $entry) }}" method="POST" class="inline">
                                    @csrf @method('PATCH')
                                    <button type="submit" class="text-green-500 hover:text-green-700">Setujui</button>
                                </form>
                            @endif
                            @if($entry->status != 'rejected')
                                <form action="{{ route('admin.guestbook.reject', $entry) }}" method="POST" class="inline">
                                    @csrf @method('PATCH')
                                    <button type="submit" class="text-yellow-500 hover:text-yellow-700">Tolak</button>
                                </form>
                            @endif
                            <form action="{{ route('admin.guestbook.destroy', $entry) }}" method="POST" class="inline" onsubmit="return confirm('Hapus pesan ini?')">
                                @csrf @method('DELETE')
                                <button type="submit" class="text-red-500 hover:text-red-700">Hapus</button>
                            </form>
                        </div>
                    </td>
                </tr>
                @endforeach
            </tbody>
        </table>
    </div>

    <div class="mt-4">
        {{ $entries->links() }}
    </div>
</div>
@endsection
```

## Cara Integrasi & Pengujian
Akses halaman admin (route `/admin/guestbook`). Pastikan semua pesan tampil dengan statusnya masing-masing dan tombol aksi berfungsi.
