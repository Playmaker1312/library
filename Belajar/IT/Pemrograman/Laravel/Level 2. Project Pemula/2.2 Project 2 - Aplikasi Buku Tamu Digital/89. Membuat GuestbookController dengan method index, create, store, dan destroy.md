# 89. Membuat GuestbookController dengan method index, create, store, dan destroy

## Definisi & Target
Membuat controller untuk menangani operasi publik pada buku tamu. Method index menampilkan pesan yang disetujui, create menampilkan form, store menyimpan pesan baru dengan status pending, dan destroy menghapus pesan oleh admin.

## Komponen yang Terlibat
- Controller: `app/Http/Controllers/GuestbookController.php`

## Perintah Artisan CLI
```
php artisan make:controller GuestbookController
```

## Kode Implementasi (Per File)

**app/Http/Controllers/GuestbookController.php**
```php
<?php

namespace App\Http\Controllers;

use App\Models\GuestbookEntry;
use Illuminate\Http\Request;

class GuestbookController extends Controller
{
    public function index()
    {
        $entries = GuestbookEntry::approved()->latest()->paginate(10);
        return view('guestbook.index', compact('entries'));
    }

    public function create()
    {
        return view('guestbook.create');
    }

    public function store(Request $request)
    {
        $validated = $request->validate([
            'name' => 'required|string|max:255',
            'email' => 'required|email|max:255',
            'message' => 'required|string|min:10|max:1000',
            'website' => 'nullable|string|max:255',
        ]);

        if ($request->filled('website')) {
            return back()->with('error', 'Terdeteksi sebagai spam.');
        }

        GuestbookEntry::create([
            'name' => $validated['name'],
            'email' => $validated['email'],
            'message' => $validated['message'],
            'status' => GuestbookEntry::STATUS_PENDING,
            'ip_address' => $request->ip(),
        ]);

        return redirect()->route('guestbook.index')
            ->with('success', 'Pesan Anda telah dikirim dan menunggu moderasi.');
    }

    public function destroy(GuestbookEntry $guestbookEntry)
    {
        $guestbookEntry->delete();

        return redirect()->route('admin.guestbook.index')
            ->with('success', 'Pesan berhasil dihapus.');
    }
}
```

## Cara Integrasi & Pengujian
Daftarkan route untuk controller ini. Pastikan method store menyimpan data dengan status pending.
