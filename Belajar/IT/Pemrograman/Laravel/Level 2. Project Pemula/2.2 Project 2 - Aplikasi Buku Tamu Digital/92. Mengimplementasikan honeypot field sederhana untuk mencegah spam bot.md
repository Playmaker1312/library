# 92. Mengimplementasikan honeypot field sederhana untuk mencegah spam bot

## Definisi & Target
Menambahkan field tersembunyi di form yang hanya akan diisi oleh bot (bukan manusia). Jika field ini terisi, sistem akan menolak submission karena dianggap spam.

## Komponen yang Terlibat
- Blade View: `resources/views/guestbook/create.blade.php`
- GuestbookController (method store)

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**resources/views/guestbook/create.blade.php (honeypot field)**
```php
<form action="{{ route('guestbook.store') }}" method="POST">
    @csrf

    <div class="mb-4" style="display:none">
        <input type="text" name="website" tabindex="-1" autocomplete="off">
    </div>

    {{-- field form normal di bawah ini --}}
    <div class="mb-4">
        <label for="name" class="block text-gray-700 font-medium mb-2">Nama</label>
        <input type="text" name="name" id="name" value="{{ old('name') }}" required ...>
    </div>
    ...
</form>
```

**app/Http/Controllers/GuestbookController.php (cek honeypot)**
```php
public function store(Request $request)
{
    $validated = $request->validate([...]);

    if ($request->filled('website')) {
        return back()->with('error', 'Terdeteksi sebagai spam.');
    }

    GuestbookEntry::create([...]);

    return redirect()->route('guestbook.index')
        ->with('success', 'Pesan Anda telah dikirim dan menunggu moderasi.');
}
```

## Cara Integrasi & Pengujian
1. Buka form di browser (field honeypot tidak terlihat oleh pengguna)
2. Coba kirim form secara normal - harus berhasil
3. Coba kirim dengan mengisi field website (gunakan DevTools untuk menampilkan field tersembunyi) - harus ditolak sebagai spam
