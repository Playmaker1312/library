# 100. Membuat tampilan yang menarik dengan animasi CSS untuk buku tamu

## Definisi & Target
Menambahkan animasi CSS ringan untuk membuat tampilan buku tamu lebih hidup dan menarik. Animasi diterapkan pada card pesan, form, dan elemen navigasi.

## Komponen yang Terlibat
- Blade Layout: `resources/views/layouts/guestbook.blade.php`
- Blade View: `resources/views/guestbook/index.blade.php`
- Blade View: `resources/views/guestbook/create.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**resources/views/layouts/guestbook.blade.php**
```php
<!DOCTYPE html>
<html lang="{{ str_replace('_', '-', app()->getLocale()) }}">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Buku Tamu Digital</title>
    @vite('resources/css/app.css')
    <style>
        @keyframes fadeInUp {
            from { opacity: 0; transform: translateY(20px); }
            to { opacity: 1; transform: translateY(0); }
        }
        @keyframes slideInLeft {
            from { opacity: 0; transform: translateX(-30px); }
            to { opacity: 1; transform: translateX(0); }
        }
        @keyframes pulse {
            0%, 100% { transform: scale(1); }
            50% { transform: scale(1.05); }
        }
        .animate-fade-in-up {
            animation: fadeInUp 0.6s ease-out;
        }
        .animate-slide-in-left {
            animation: slideInLeft 0.5s ease-out;
        }
        .animate-pulse-slow {
            animation: pulse 3s ease-in-out infinite;
        }
        .card-enter {
            opacity: 0;
            transform: translateY(20px);
        }
        .card-enter-active {
            opacity: 1;
            transform: translateY(0);
            transition: opacity 0.5s ease, transform 0.5s ease;
        }
        .guestbook-card:nth-child(1) { animation-delay: 0.1s; }
        .guestbook-card:nth-child(2) { animation-delay: 0.2s; }
        .guestbook-card:nth-child(3) { animation-delay: 0.3s; }
        .guestbook-card:nth-child(4) { animation-delay: 0.4s; }
        .guestbook-card:nth-child(5) { animation-delay: 0.5s; }
    </style>
</head>
<body class="bg-gradient-to-br from-blue-50 to-indigo-100 min-h-screen">
    <nav class="bg-white/80 backdrop-blur-sm shadow-sm">
        <div class="max-w-4xl mx-auto px-4 py-4 flex justify-between items-center">
            <a href="{{ route('guestbook.index') }}" class="text-xl font-bold text-blue-600">
                Buku Tamu Digital
            </a>
            <div class="flex gap-4">
                <a href="{{ route('guestbook.index') }}" class="text-gray-600 hover:text-blue-600 transition">Lihat Pesan</a>
                <a href="{{ route('guestbook.create') }}" class="text-gray-600 hover:text-blue-600 transition">Tulis Pesan</a>
            </div>
        </div>
    </nav>

    <main class="max-w-4xl mx-auto px-4 py-8">
        @yield('content')
    </main>

    <footer class="text-center py-6 text-gray-400 text-sm">
        &copy; {{ date('Y') }} Buku Tamu Digital
    </footer>
</body>
</html>
```

**resources/views/guestbook/index.blade.php (tambahkan animasi pada card)**
```php
<div class="space-y-6">
    @forelse($entries as $entry)
        <div class="guestbook-card animate-fade-in-up bg-white rounded-lg shadow-md p-6 border-l-4 border-blue-400 hover:shadow-lg transition-shadow duration-300">
            <div class="flex justify-between items-start mb-3">
                <div>
                    <h3 class="font-semibold text-gray-800">{{ $entry->name }}</h3>
                    <p class="text-sm text-gray-500">{{ $entry->created_at->diffForHumans() }}</p>
                </div>
                <span class="text-blue-400 animate-pulse-slow">
                    <svg class="w-6 h-6" fill="currentColor" viewBox="0 0 20 20">
                        <path fill-rule="evenodd" d="M18 10c0 3.866-3.582 7-8 7a8.841 8.841 0 01-4.083-.98L2 17l1.338-3.123C2.493 12.767 2 11.434 2 10c0-3.866 3.582-7 8-7s8 3.134 8 7zM7 9H5v2h2V9zm8 0h-2v2h2V9zm-4 0H9v2h2V9z" clip-rule="evenodd"/>
                    </svg>
                </span>
            </div>
            <p class="text-gray-700 whitespace-pre-wrap">{{ $entry->message }}</p>
        </div>
    @empty
        <div class="text-center py-12 text-gray-400 animate-fade-in-up">
            <p class="text-lg">Belum ada pesan.</p>
            <p class="mt-2">Jadilah yang pertama meninggalkan pesan!</p>
        </div>
    @endforelse
</div>
```

## Cara Integrasi & Pengujian
1. Buka halaman buku tamu di browser
2. Perhatikan animasi fade-in pada setiap card pesan
3. Card akan muncul satu per satu dengan efek animasi yang halus
4. Tombol dan link memiliki efek transisi saat di-hover
