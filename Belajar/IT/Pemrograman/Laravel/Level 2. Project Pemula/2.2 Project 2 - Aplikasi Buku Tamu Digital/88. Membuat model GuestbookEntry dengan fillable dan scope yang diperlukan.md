# 88. Membuat model GuestbookEntry dengan fillable dan scope yang diperlukan

## Definisi & Target
Membuat Eloquent Model `GuestbookEntry` yang merepresentasikan tabel guestbook. Model ini memiliki properti $fillable, $casts, serta scope untuk memfilter berdasarkan status.

## Komponen yang Terlibat
- Model: `app/Models/GuestbookEntry.php`

## Perintah Artisan CLI
```
php artisan make:model GuestbookEntry
```

## Kode Implementasi (Per File)

**app/Models/GuestbookEntry.php**
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;

class GuestbookEntry extends Model
{
    use HasFactory;

    protected $fillable = [
        'name',
        'email',
        'message',
        'status',
        'ip_address',
    ];

    protected $casts = [
        'created_at' => 'datetime',
        'updated_at' => 'datetime',
    ];

    public const STATUS_PENDING = 'pending';
    public const STATUS_APPROVED = 'approved';
    public const STATUS_REJECTED = 'rejected';

    public static function statuses(): array
    {
        return [
            self::STATUS_PENDING => 'Pending',
            self::STATUS_APPROVED => 'Disetujui',
            self::STATUS_REJECTED => 'Ditolak',
        ];
    }

    public function scopePending($query)
    {
        return $query->where('status', self::STATUS_PENDING);
    }

    public function scopeApproved($query)
    {
        return $query->where('status', self::STATUS_APPROVED);
    }

    public function scopeRejected($query)
    {
        return $query->where('status', self::STATUS_REJECTED);
    }
}
```

## Cara Integrasi & Pengujian
Uji model di `php artisan tinker` dengan membuat entry baru dan mencoba scope yang sudah didefinisikan.
