# 98. Mengimplementasikan rate limiting pada form submission untuk mencegah spam

## Definisi & Target
Menerapkan rate limiting pada route store buku tamu untuk membatasi jumlah pengiriman pesan dalam periode waktu tertentu. Ini mencegah spam bot mengirim banyak pesan dalam waktu singkat.

## Komponen yang Terlibat
- Route: `routes/web.php`
- GuestbookController (method store)
- File: `app/Http/Kernel.php` (jika menggunakan Laravel 10)

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**routes/web.php (rate limiting)**
```php
use Illuminate\Cache\RateLimiting\Limit;
use Illuminate\Support\Facades\RateLimiter;

RateLimiter::for('guestbook', function (Request $request) {
    return Limit::perHour(3)->by($request->ip());
});

Route::post('/guestbook', [GuestbookController::class, 'store'])
    ->middleware(['throttle:guestbook'])
    ->name('guestbook.store');
```

**Atau gunakan throttle langsung:**
```php
Route::post('/guestbook', [GuestbookController::class, 'store'])
    ->middleware('throttle:3,60')
    ->name('guestbook.store');
```

**GuestbookController (tambah penanganan rate limit error)**
```php
use Illuminate\Http\Request;

public function store(Request $request)
{
    $key = 'guestbook:' . $request->ip();

    if (RateLimiter::tooManyAttempts($key, 3)) {
        $seconds = RateLimiter::availableIn($key);
        return back()->with('error', "Terlalu banyak percobaan. Silakan coba lagi dalam $seconds detik.");
    }

    RateLimiter::hit($key, 3600);

    $validated = $request->validate([...]);
    // ... sisa logika store
}
```

## Cara Integrasi & Pengujian
1. Kirim form buku tamu lebih dari 3 kali dalam 1 jam
2. Pada percobaan ke-4, sistem akan menolak dengan pesan error rate limit
3. Tunggu 1 jam atau reset menggunakan `php artisan cache:clear` untuk menguji lagi
