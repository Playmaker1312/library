# 91. Mengimplementasikan validasi form dengan pesan error yang user-friendly

## Definisi & Target
Menambahkan validasi pada form buku tamu dengan pesan error yang mudah dipahami pengguna. Validasi mencakup nama wajib, email valid, dan pesan minimal 10 karakter.

## Komponen yang Terlibat
- GuestbookController (method store)
- Blade View: `resources/views/guestbook/create.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**app/Http/Controllers/GuestbookController.php (method store dengan validasi)**
```php
public function store(Request $request)
{
    $validated = $request->validate([
        'name' => ['required', 'string', 'max:255'],
        'email' => ['required', 'email', 'max:255'],
        'message' => ['required', 'string', 'min:10', 'max:1000'],
    ], [
        'name.required' => 'Nama tidak boleh kosong.',
        'name.max' => 'Nama maksimal 255 karakter.',
        'email.required' => 'Email tidak boleh kosong.',
        'email.email' => 'Format email tidak valid.',
        'email.max' => 'Email maksimal 255 karakter.',
        'message.required' => 'Pesan tidak boleh kosong.',
        'message.min' => 'Pesan minimal 10 karakter.',
        'message.max' => 'Pesan maksimal 1000 karakter.',
    ]);

    if ($request->filled('website')) {
        return back()->with('error', 'Terdeteksi sebagai spam.');
    }

    GuestbookEntry::create([
        'name' => $validated['name'],
        'email' => $validated['email'],
        'message' => $validated['message'],
        'status' => GuestbookEntry::STATUS_PENDING,
        'ip_address' => $request->ip(),
    ]);

    return redirect()->route('guestbook.index')
        ->with('success', 'Pesan Anda telah dikirim dan menunggu moderasi.');
}
```

**Blade View (bagian error)**
```php
@if($errors->any())
    <div class="bg-red-100 border border-red-400 text-red-700 px-4 py-3 rounded mb-6">
        <ul class="list-disc list-inside">
            @foreach($errors->all() as $error)
                <li>{{ $error }}</li>
            @endforeach
        </ul>
    </div>
@endif
```

## Cara Integrasi & Pengujian
Submit form dengan data kosong atau tidak valid. Pastikan pesan error muncul sesuai dengan aturan validasi yang ditetapkan.
