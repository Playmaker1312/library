# 96. Mengimplementasikan pagination pada daftar pesan

## Definisi & Target
Menambahkan pagination pada daftar pesan buku tamu di halaman publik dan halaman admin. Pagination membuat tampilan lebih rapi dengan membatasi jumlah pesan per halaman.

## Komponen yang Terlibat
- GuestbookController (method index)
- Admin GuestbookController (method index)
- Blade View: `resources/views/guestbook/index.blade.php`
- Blade View: `resources/views/admin/guestbook/index.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**GuestbookController (method index)**
```php
public function index()
{
    $entries = GuestbookEntry::approved()->latest()->paginate(10);
    return view('guestbook.index', compact('entries'));
}
```

**Admin GuestbookController (method index)**
```php
public function index()
{
    $entries = GuestbookEntry::latest()->paginate(15);
    return view('admin.guestbook.index', compact('entries'));
}
```

**Blade View publik (tambahkan di bagian bawah)**
```php
<div class="mt-8">
    {{ $entries->links() }}
</div>
```

## Cara Integrasi & Pengujian
Pastikan ada lebih dari 10 (atau 15) pesan di database. Akses halaman publik dan admin. Link pagination akan muncul di bagian bawah. Klik halaman 2 untuk memastikan navigasi berfungsi.
