# 97. Mengirimkan email notifikasi ke admin saat ada pesan baru menggunakan Mail facade

## Definisi & Target
Mengirim notifikasi email ke admin setiap kali ada pesan baru yang masuk. Menggunakan Mail facade Laravel untuk mengirim email dengan template yang sudah ditentukan.

## Komponen yang Terlibat
- Mail Class: `app/Mail/NewGuestbookEntry.php`
- Mail Template: `resources/views/emails/new-guestbook-entry.blade.php`
- GuestbookController (method store)
- File konfigurasi `.env` (pengaturan mail)

## Perintah Artisan CLI
```
php artisan make:mail NewGuestbookEntry
```

## Kode Implementasi (Per File)

**app/Mail/NewGuestbookEntry.php**
```php
<?php

namespace App\Mail;

use App\Models\GuestbookEntry;
use Illuminate\Bus\Queueable;
use Illuminate\Mail\Mailable;
use Illuminate\Mail\Mailables\Content;
use Illuminate\Mail\Mailables\Envelope;
use Illuminate\Queue\SerializesModels;

class NewGuestbookEntry extends Mailable
{
    use Queueable, SerializesModels;

    public GuestbookEntry $entry;

    public function __construct(GuestbookEntry $entry)
    {
        $this->entry = $entry;
    }

    public function envelope(): Envelope
    {
        return new Envelope(
            subject: 'Pesan Baru di Buku Tamu',
        );
    }

    public function content(): Content
    {
        return new Content(
            view: 'emails.new-guestbook-entry',
        );
    }
}
```

**GuestbookController (method store - kirim email)**
```php
use App\Mail\NewGuestbookEntry;
use Illuminate\Support\Facades\Mail;

public function store(Request $request)
{
    $validated = $request->validate([...]);

    if ($request->filled('website')) {
        return back()->with('error', 'Terdeteksi sebagai spam.');
    }

    $entry = GuestbookEntry::create([
        'name' => $validated['name'],
        'email' => $validated['email'],
        'message' => $validated['message'],
        'status' => GuestbookEntry::STATUS_PENDING,
        'ip_address' => $request->ip(),
    ]);

    Mail::to(config('mail.admin_address'))->send(new NewGuestbookEntry($entry));

    return redirect()->route('guestbook.index')
        ->with('success', 'Pesan Anda telah dikirim dan menunggu moderasi.');
}
```

