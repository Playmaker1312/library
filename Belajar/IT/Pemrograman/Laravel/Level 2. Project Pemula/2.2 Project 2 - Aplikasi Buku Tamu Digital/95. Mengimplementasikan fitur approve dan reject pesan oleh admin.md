# 95. Mengimplementasikan fitur approve dan reject pesan oleh admin

## Definisi & Target
Membuat fitur di halaman admin untuk menyetujui (approve) atau menolak (reject) pesan buku tamu. Admin dapat mengubah status pesan dengan satu klik.

## Komponen yang Terlibat
- Controller: `app/Http/Controllers/Admin/GuestbookController.php` (method approve dan reject)
- Route: `routes/web.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**app/Http/Controllers/Admin/GuestbookController.php (method approve dan reject)**
```php
public function approve(GuestbookEntry $guestbookEntry)
{
    $guestbookEntry->update(['status' => GuestbookEntry::STATUS_APPROVED]);

    return redirect()->route('admin.guestbook.index')
        ->with('success', 'Pesan berhasil disetujui.');
}

public function reject(GuestbookEntry $guestbookEntry)
{
    $guestbookEntry->update(['status' => GuestbookEntry::STATUS_REJECTED]);

    return redirect()->route('admin.guestbook.index')
        ->with('success', 'Pesan berhasil ditolak.');
}
```

**routes/web.php (route admin)**
```php
use App\Http\Controllers\Admin\GuestbookController as AdminGuestbookController;

Route::prefix('admin')->name('admin.')->group(function () {
    Route::get('/guestbook', [AdminGuestbookController::class, 'index'])->name('guestbook.index');
    Route::patch('/guestbook/{guestbookEntry}/approve', [AdminGuestbookController::class, 'approve'])->name('guestbook.approve');
    Route::patch('/guestbook/{guestbookEntry}/reject', [AdminGuestbookController::class, 'reject'])->name('guestbook.reject');
    Route::delete('/guestbook/{guestbookEntry}', [AdminGuestbookController::class, 'destroy'])->name('guestbook.destroy');
});
```

## Cara Integrasi & Pengujian
1. Login sebagai admin (jika ada middleware auth)
2. Buka halaman admin `/admin/guestbook`
3. Klik tombol "Setujui" - status berubah menjadi approved dan pesan muncul di halaman publik
4. Klik tombol "Tolak" - status berubah menjadi rejected dan pesan tidak muncul di publik
