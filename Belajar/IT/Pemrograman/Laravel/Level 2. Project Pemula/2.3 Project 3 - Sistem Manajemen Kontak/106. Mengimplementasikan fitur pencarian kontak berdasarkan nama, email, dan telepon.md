# 106. Mengimplementasikan fitur pencarian kontak berdasarkan nama, email, dan telepon

## Definisi & Target
Menambahkan fitur pencarian pada halaman daftar kontak. Pengguna dapat mencari kontak berdasarkan nama, email, atau nomor telepon melalui satu input pencarian.

## Komponen yang Terlibat
- Model Contact (scope search)
- ContactController (method index)
- Blade View: `resources/views/contacts/index.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**app/Models/Contact.php (scope search)**
```php
public function scopeSearch($query, $term)
{
    return $query->where('name', 'like', "%{$term}%")
        ->orWhere('email', 'like', "%{$term}%")
        ->orWhere('phone', 'like', "%{$term}%");
}
```

**ContactController (method index - dengan filter search)**
```php
public function index(Request $request)
{
    $query = Contact::with('category');

    if ($request->filled('search')) {
        $query->search($request->search);
    }

    if ($request->filled('category')) {
        $query->where('category_id', $request->category);
    }

    $contacts = $query->latest()->paginate(12);
    $categories = Category::all();

    return view('contacts.index', compact('contacts', 'categories'));
}
```

**resources/views/contacts/index.blade.php (form pencarian)**
```php
<form action="{{ route('contacts.index') }}" method="GET" class="flex gap-2">
    <input type="text" name="search" value="{{ request('search') }}"
        placeholder="Cari nama, email, atau telepon..."
        class="w-full px-4 py-2 border rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-400">
    <button type="submit" class="bg-blue-500 hover:bg-blue-600 text-white px-4 py-2 rounded-lg">
        Cari
    </button>
    @if(request()->anyFilled(['search', 'category']))
        <a href="{{ route('contacts.index') }}" class="bg-gray-300 hover:bg-gray-400 text-gray-700 px-4 py-2 rounded-lg">
            Reset
        </a>
    @endif
</form>
```

## Cara Integrasi & Pengujian
1. Buka halaman daftar kontak
2. Ketik nama/email/telepon di kolom pencarian
3. Klik tombol "Cari" - hasil akan difilter sesuai keyword
4. Klik "Reset" untuk menghapus filter
