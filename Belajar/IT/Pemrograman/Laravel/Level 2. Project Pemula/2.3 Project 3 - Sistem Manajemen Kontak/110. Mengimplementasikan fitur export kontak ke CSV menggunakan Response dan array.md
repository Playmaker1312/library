# 110. Mengimplementasikan fitur export kontak ke CSV menggunakan Response dan array

## Definisi & Target
Membuat fitur export semua kontak ke file CSV. File CSV dapat diunduh oleh pengguna dan berisi data kontak seperti nama, email, telepon, kategori, dan alamat.

## Komponen yang Terlibat
- ContactController (method export)
- Route baru

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**ContactController (method export)**
```php
public function export()
{
    $contacts = Contact::with('category')->get();

    $headers = [
        'Content-Type' => 'text/csv',
        'Content-Disposition' => 'attachment; filename="contacts-export-' . date('Y-m-d') . '.csv"',
    ];

    $callback = function () use ($contacts) {
        $file = fopen('php://output', 'w');

        fputcsv($file, ['Nama', 'Email', 'Telepon', 'Kategori', 'Alamat', 'Favorite']);

        foreach ($contacts as $contact) {
            fputcsv($file, [
                $contact->name,
                $contact->email,
                $contact->phone,
                $contact->category->name,
                $contact->address,
                $contact->is_favorite ? 'Ya' : 'Tidak',
            ]);
        }

        fclose($file);
    };

    return response()->stream($callback, 200, $headers);
}
```

**routes/web.php**
```php
Route::get('/contacts/export', [ContactController::class, 'export'])->name('contacts.export');
Route::resource('contacts', ContactController::class);
```

**resources/views/contacts/index.blade.php (tombol export)**
```php
<a href="{{ route('contacts.export') }}" class="bg-green-500 hover:bg-green-600 text-white px-4 py-2 rounded-lg">
    Export CSV
</a>
```

## Cara Integrasi & Pengujian
1. Buka halaman daftar kontak
2. Klik tombol "Export CSV"
3. File CSV akan terunduh secara otomatis
4. Buka file CSV di Excel atau editor teks untuk memverifikasi data
