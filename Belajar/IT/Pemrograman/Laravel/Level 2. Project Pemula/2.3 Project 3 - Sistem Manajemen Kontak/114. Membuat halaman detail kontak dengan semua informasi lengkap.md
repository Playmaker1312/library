# 114. Membuat halaman detail kontak dengan semua informasi lengkap

## Definisi & Target
Membuat halaman detail yang menampilkan semua informasi lengkap dari satu kontak. Informasi meliputi foto, nama, email, telepon, kategori, alamat, status favorite, dan tanggal bergabung.

## Komponen yang Terlibat
- Blade View: `resources/views/contacts/show.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**resources/views/contacts/show.blade.php**
```php
@extends('layouts.app')

@section('content')
<div class="container mx-auto px-4 py-8">
    <div class="max-w-2xl mx-auto">
        <div class="mb-6 flex justify-between items-center">
            <h1 class="text-2xl font-bold text-gray-800">Detail Kontak</h1>
            <a href="{{ route('contacts.index') }}" class="text-gray-500 hover:text-gray-700">&larr; Kembali</a>
        </div>

        <div class="bg-white rounded-lg shadow-md overflow-hidden">
            <div class="bg-gradient-to-r from-blue-500 to-blue-600 p-6 text-center text-white">
                @if($contact->photo)
                    <img src="{{ \Illuminate\Support\Facades\Storage::url($contact->photo) }}" alt="{{ $contact->name }}"
                        class="w-24 h-24 rounded-full mx-auto object-cover border-4 border-white shadow">
                @else
                    <div class="w-24 h-24 rounded-full mx-auto bg-white/20 flex items-center justify-center border-4 border-white shadow">
                        <span class="text-3xl font-bold">{{ strtoupper(substr($contact->name, 0, 1)) }}</span>
                    </div>
                @endif
                <h2 class="mt-4 text-xl font-bold">{{ $contact->name }}</h2>
                <p class="text-blue-100">{{ $contact->email }}</p>
            </div>

            <div class="p-6 space-y-4">
                <div class="grid grid-cols-1 md:grid-cols-2 gap-4">
                    <div>
                        <h3 class="text-sm font-bold text-gray-500 uppercase">Telepon</h3>
                        <p class="text-gray-800">{{ $contact->phone ?? '-' }}</p>
                    </div>
                    <div>
                        <h3 class="text-sm font-bold text-gray-500 uppercase">Kategori</h3>
                        <span class="inline-block px-3 py-1 text-sm rounded bg-blue-100 text-blue-700">
                            {{ $contact->category->name }}
                        </span>
                    </div>
                    <div>
                        <h3 class="text-sm font-bold text-gray-500 uppercase">Status Favorite</h3>
                        <span class="{{ $contact->is_favorite ? 'text-yellow-500' : 'text-gray-400' }}">
                            {{ $contact->is_favorite ? 'Favorite' : 'Bukan Favorite' }}
                        </span>
                    </div>
                    <div>
                        <h3 class="text-sm font-bold text-gray-500 uppercase">Bergabung</h3>
                        <p class="text-gray-800">{{ $contact->created_at->format('d F Y') }}</p>
                    </div>
                </div>

                <div>
                    <h3 class="text-sm font-bold text-gray-500 uppercase">Alamat</h3>
                    <p class="text-gray-800 whitespace-pre-wrap">{{ $contact->address ?? 'Tidak ada alamat' }}</p>
                </div>

                <div class="flex gap-4 pt-4 border-t">
                    <a href="{{ route('contacts.edit', $contact) }}" class="bg-yellow-500 hover:bg-yellow-600 text-white px-4 py-2 rounded-lg">
                        Edit Kontak
                    </a>
                    <form action="{{ route('contacts.destroy', $contact) }}" method="POST" onsubmit="return confirm('Hapus kontak {{ $contact->name }}?')">
                        @csrf @method('DELETE')
                        <button type="submit" class="bg-red-500 hover:bg-red-600 text-white px-4 py-2 rounded-lg">
                            Hapus Kontak
                        </button>
                    </form>
                </div>
            </div>
        </div>
    </div>
</div>
@endsection
```

## Cara Integrasi & Pengujian
Akses route `/contacts/{id}`. Pastikan semua informasi kontak tampil dengan rapi dan lengkap.
