# 111. Mengimplementasikan fitur import kontak dari CSV menggunakan League CSV

## Definisi & Target
Membuat fitur import kontak dari file CSV. Pengguna dapat mengupload file CSV yang berisi data kontak untuk ditambahkan secara massal ke database.

## Komponen yang Terlibat
- Package: League CSV (bawaan Laravel)
- ContactController (method importForm dan import)
- Blade View: `resources/views/contacts/import.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan. League CSV sudah termasuk dalam dependensi Laravel.

## Kode Implementasi (Per File)

**ContactController**
```php
use Illuminate\Http\Request;
use League\Csv\Reader;

public function importForm()
{
    return view('contacts.import');
}

public function import(Request $request)
{
    $request->validate([
        'csv_file' => 'required|file|mimes:csv,txt|max:2048',
    ]);

    $csv = Reader::createFromPath($request->file('csv_file')->getPathname(), 'r');
    $csv->setHeaderOffset(0);

    $headers = $csv->getHeader();
    $requiredFields = ['nama', 'email'];

    $imported = 0;
    $errors = [];

    foreach ($csv->getRecords() as $rowIndex => $row) {
        try {
            $category = null;
            if (!empty($row['kategori'])) {
                $category = \App\Models\Category::firstOrCreate(
                    ['name' => $row['kategori']],
                    ['slug' => \Illuminate\Support\Str::slug($row['kategori'])]
                );
            }

            \App\Models\Contact::updateOrCreate(
                ['email' => $row['email']],
                [
                    'category_id' => $category?->id ?? 1,
                    'name' => $row['nama'],
                    'phone' => $row['telepon'] ?? null,
                    'address' => $row['alamat'] ?? null,
                ]
            );

            $imported++;
        } catch (\Exception $e) {
            $errors[] = "Baris " . ($rowIndex + 2) . ": " . $e->getMessage();
        }
    }

    return redirect()->route('contacts.index')
        ->with('success', "Berhasil mengimpor $imported kontak.")
        ->with('import_errors', $errors);
}
```
