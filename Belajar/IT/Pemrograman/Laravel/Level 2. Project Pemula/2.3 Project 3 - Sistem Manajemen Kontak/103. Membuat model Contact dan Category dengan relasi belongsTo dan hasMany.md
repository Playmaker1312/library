# 103. Membuat model Contact dan Category dengan relasi belongsTo dan hasMany

## Definisi & Target
Membuat Eloquent Model Contact dan Category dengan relasi yang tepat. Category memiliki banyak Contact (hasMany), dan Contact dimiliki oleh satu Category (belongsTo).

## Komponen yang Terlibat
- Model: `app/Models/Category.php`
- Model: `app/Models/Contact.php`

## Perintah Artisan CLI
```
php artisan make:model Category
php artisan make:model Contact
```

## Kode Implementasi (Per File)

**app/Models/Category.php**
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Support\Str;

class Category extends Model
{
    use HasFactory;

    protected $fillable = [
        'name',
        'slug',
        'description',
    ];

    protected static function boot()
    {
        parent::boot();
        static::creating(function ($category) {
            if (empty($category->slug)) {
                $category->slug = Str::slug($category->name);
            }
        });
    }

    public function contacts()
    {
        return $this->hasMany(Contact::class);
    }
}
```

**app/Models/Contact.php**
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;

class Contact extends Model
{
    use HasFactory;

    protected $fillable = [
        'category_id',
        'name',
        'email',
        'phone',
        'photo',
        'address',
        'is_favorite',
    ];

    protected $casts = [
        'is_favorite' => 'boolean',
    ];

    public function category()
    {
        return $this->belongsTo(Category::class);
    }

    public function scopeFavorite($query)
    {
        return $query->where('is_favorite', true);
    }

    public function scopeSearch($query, $term)
    {
        return $query->where('name', 'like', "%{$term}%")
            ->orWhere('email', 'like', "%{$term}%")
            ->orWhere('phone', 'like', "%{$term}%");
    }
}
```

## Cara Integrasi & Pengujian
Uji relasi di `php artisan tinker`. Buat category dan contact, lalu akses `$contact->category` dan `$category->contacts`.
