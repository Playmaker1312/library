# 109. Menyimpan foto kontak ke folder public storage dengan symlink yang benar

## Definisi & Target
Memastikan foto kontak yang diupload tersimpan di folder `storage/app/public/contacts` dan dapat diakses melalui URL publik menggunakan symlink.

## Komponen yang Terlibat
- Storage link (symlink)
- File konfigurasi: `config/filesystems.php`

## Perintah Artisan CLI
```
php artisan storage:link
```

## Kode Implementasi (Per File)

**config/filesystems.php**
```php
'disks' => [
    'local' => [
        'driver' => 'local',
        'root' => storage_path('app/private'),
        'serve' => true,
        'throw' => false,
    ],

    'public' => [
        'driver' => 'local',
        'root' => storage_path('app/public'),
        'url' => env('APP_URL').'/storage',
        'visibility' => 'public',
        'throw' => false,
    ],

    // ...
],
```

**ContactController (simpan dan hapus foto)**
```php
public function destroy(Contact $contact)
{
    if ($contact->photo) {
        Storage::disk('public')->delete($contact->photo);
    }

    $contact->delete();

    return redirect()->route('contacts.index')->with('success', 'Kontak berhasil dihapus.');
}
```

**.env (pastikan APP_URL benar)**
```
APP_URL=http://localhost:8000
```

## Cara Integrasi & Pengujian
1. Jalankan `php artisan storage:link` (hanya sekali)
2. Verifikasi folder `public/storage` mengarah ke `storage/app/public`
3. Upload kontak dengan foto
4. Akses foto melalui URL `http://localhost:8000/storage/contacts/nama-file.jpg`
