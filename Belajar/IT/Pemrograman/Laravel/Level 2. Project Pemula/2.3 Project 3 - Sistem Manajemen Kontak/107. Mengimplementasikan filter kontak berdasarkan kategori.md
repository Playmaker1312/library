# 107. Mengimplementasikan filter kontak berdasarkan kategori

## Definisi & Target
Menambahkan filter kategori pada halaman daftar kontak. Pengguna dapat memfilter kontak berdasarkan kategori yang dipilih melalui dropdown.

## Komponen yang Terlibat
- ContactController (method index)
- Blade View: `resources/views/contacts/index.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**ContactController (method index)**
```php
public function index(Request $request)
{
    $query = Contact::with('category');

    if ($request->filled('search')) {
        $query->search($request->search);
    }

    if ($request->filled('category')) {
        $query->where('category_id', $request->category);
    }

    if ($request->boolean('favorites')) {
        $query->favorite();
    }

    $contacts = $query->latest()->paginate(12)->withQueryString();
    $categories = Category::all();

    return view('contacts.index', compact('contacts', 'categories'));
}
```

**resources/views/contacts/index.blade.php (filter kategori)**
```php
<form action="{{ route('contacts.index') }}" method="GET" class="flex flex-wrap gap-2">
    <input type="text" name="search" value="{{ request('search') }}"
        placeholder="Cari kontak..."
        class="flex-1 min-w-[200px] px-4 py-2 border rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-400">

    <select name="category" class="px-4 py-2 border rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-400">
        <option value="">Semua Kategori</option>
        @foreach($categories as $category)
            <option value="{{ $category->id }}" {{ request('category') == $category->id ? 'selected' : '' }}>
                {{ $category->name }}
            </option>
        @endforeach
    </select>

    <button type="submit" class="bg-blue-500 hover:bg-blue-600 text-white px-4 py-2 rounded-lg">
        Filter
    </button>

    @if(request()->anyFilled(['search', 'category']))
        <a href="{{ route('contacts.index') }}" class="bg-gray-300 hover:bg-gray-400 text-gray-700 px-4 py-2 rounded-lg">
            Reset
        </a>
    @endif
</form>
```

## Cara Integrasi & Pengujian
1. Buka halaman daftar kontak
2. Pilih kategori dari dropdown
3. Klik "Filter" - hanya kontak dengan kategori terpilih yang tampil
4. Kombinasikan dengan pencarian untuk filter yang lebih spesifik
