# 115. Memastikan semua fitur contact manager berjalan dengan baik di mobile

## Definisi & Target
Memastikan seluruh halaman contact manager responsif dan mudah digunakan di perangkat mobile. Menggunakan utility classes Tailwind CSS yang responsif dan menyesuaikan tata letak untuk layar kecil.

## Komponen yang Terlibat
- Semua Blade View Contact Manager
- Layout `resources/views/layouts/app.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**Penyesuaian layout utama untuk mobile (layouts/app.blade.php)**
```php
<nav class="bg-white shadow-lg">
    <div class="max-w-7xl mx-auto px-4">
        <div class="flex justify-between items-center h-16">
            <a href="{{ route('contacts.index') }}" class="text-xl font-bold text-gray-800">
                Kontak Saya
            </a>
            <button id="mobile-menu-btn" class="md:hidden text-gray-600 hover:text-gray-800 focus:outline-none">
                <svg class="w-6 h-6" fill="none" stroke="currentColor" viewBox="0 0 24 24">
                    <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M4 6h16M4 12h16M4 18h16"/>
                </svg>
            </button>
            <div id="mobile-menu" class="hidden md:flex md:items-center md:gap-4 absolute md:relative top-16 left-0 right-0 bg-white md:bg-transparent shadow-md md:shadow-none p-4 md:p-0">
                <a href="{{ route('contacts.index') }}" class="block md:inline text-gray-600 hover:text-gray-800 py-2">Daftar Kontak</a>
                <a href="{{ route('contacts.create') }}" class="block md:inline text-gray-600 hover:text-gray-800 py-2">Tambah Kontak</a>
                <a href="{{ route('categories.index') }}" class="block md:inline text-gray-600 hover:text-gray-800 py-2">Kategori</a>
            </div>
        </div>
    </div>
</nav>

<script>
    document.getElementById('mobile-menu-btn')?.addEventListener('click', function() {
        document.getElementById('mobile-menu').classList.toggle('hidden');
    });
</script>
```

**Tombol aksi kompak di mobile (index.blade.php)**
```php

    <a href="{{ route('contacts.show', $contact) }}" class="text-blue-500 hover:text-blue-700 text-center">Detail</a>
    <a href="{{ route('contacts.edit', $contact) }}" class="text-yellow-500 hover:text-yellow-700 text-center">Edit</a>

    </form>

```

## Cara Integrasi & Pengujian
1. Buka aplikasi di browser dengan DevTools (F12)
2. Gunakan mode mobile (toggle device toolbar)
3. Uji semua halaman: daftar kontak, detail, create, edit, import
4. Pastikan navigasi mobile berfungsi dengan menu hamburger
5. Pastikan form dan tombol mudah digunakan di layar sentuh
