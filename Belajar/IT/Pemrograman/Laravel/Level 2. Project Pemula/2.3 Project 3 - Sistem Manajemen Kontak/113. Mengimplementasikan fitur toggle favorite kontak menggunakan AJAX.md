# 113. Mengimplementasikan fitur toggle favorite kontak menggunakan AJAX

## Definisi & Target
Menambahkan fitur toggle favorite pada kontak menggunakan AJAX. Pengguna dapat menandai/menghapus tanda favorite pada kontak tanpa reload halaman.

## Komponen yang Terlibat
- ContactController (method toggleFavorite)
- Route: `routes/web.php`
- Blade View: `resources/views/contacts/index.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**ContactController (method toggleFavorite)**
```php
public function toggleFavorite(Contact $contact)
{
    $contact->update(['is_favorite' => !$contact->is_favorite]);

    if (request()->wantsJson()) {
        return response()->json([
            'success' => true,
            'is_favorite' => $contact->is_favorite,
            'message' => $contact->is_favorite ? 'Ditambahkan ke favorite' : 'Dihapus dari favorite',
        ]);
    }

    return back()->with('success', 'Status favorite diperbarui.');
}
```

**routes/web.php**
```php
Route::patch('/contacts/{contact}/toggle-favorite', [ContactController::class, 'toggleFavorite'])
    ->name('contacts.toggle-favorite');
```

**resources/views/contacts/index.blade.php (tombol favorite AJAX)**
```php
<div class="text-center">
    <button type="button" class="favorite-btn text-2xl {{ $contact->is_favorite ? 'text-yellow-400' : 'text-gray-300' }} hover:text-yellow-400 transition-colors"
        data-id="{{ $contact->id }}"
        data-favorite="{{ $contact->is_favorite ? 'true' : 'false' }}">
        &#9733;
    </button>
</div>

@section('scripts')
<script>
    document.querySelectorAll('.favorite-btn').forEach(btn => {
        btn.addEventListener('click', function() {
            const contactId = this.dataset.id;
            const isFavorite = this.dataset.favorite === 'true';

            fetch(`/contacts/${contactId}/toggle-favorite`, {
                method: 'PATCH',
                headers: {
                    'X-CSRF-TOKEN': document.querySelector('meta[name="csrf-token"]').content,
                    'Accept': 'application/json',
                    'Content-Type': 'application/json',
                },
            })
            .then(res => res.json())
            .then(data => {
                if (data.success) {
                    this.dataset.favorite = data.is_favorite;
                    this.classList.toggle('text-yellow-400', data.is_favorite);
                    this.classList.toggle('text-gray-300', !data.is_favorite);
                }
            });
        });
    });
</script>
@endsection
```

## Cara Integrasi & Pengujian
1. Buka halaman daftar kontak
2. Klik bintang favorite pada card kontak
3. Bintang berubah warna tanpa reload halaman
4. Klik lagi untuk menghapus status favorite
