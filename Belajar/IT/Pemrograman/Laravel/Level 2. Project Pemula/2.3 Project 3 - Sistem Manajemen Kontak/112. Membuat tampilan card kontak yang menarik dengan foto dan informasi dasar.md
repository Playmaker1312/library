# 112. Membuat tampilan card kontak yang menarik dengan foto dan informasi dasar

## Definisi & Target
Membuat halaman daftar kontak dengan tampilan card grid yang menampilkan foto, nama, email, telepon, dan kategori. Desain responsif menggunakan Tailwind CSS.

## Komponen yang Terlibat
- Blade View: `resources/views/contacts/index.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**resources/views/contacts/index.blade.php**
```php
@extends('layouts.app')

@section('content')
<div class="container mx-auto px-4 py-8">
    <div class="flex justify-between items-center mb-6">
        <h1 class="text-2xl font-bold text-gray-800">Kontak Saya</h1>
        <div class="flex gap-2">
            <a href="{{ route('contacts.import.form') }}" class="bg-purple-500 hover:bg-purple-600 text-white px-4 py-2 rounded-lg text-sm">
                Import
            </a>
            <a href="{{ route('contacts.export') }}" class="bg-green-500 hover:bg-green-600 text-white px-4 py-2 rounded-lg text-sm">
                Export
            </a>
            <a href="{{ route('contacts.create') }}" class="bg-blue-500 hover:bg-blue-600 text-white px-4 py-2 rounded-lg text-sm">
                + Tambah
            </a>
        </div>
    </div>

    @if(session('success'))
        <div class="bg-green-100 border border-green-400 text-green-700 px-4 py-3 rounded mb-4">{{ session('success') }}</div>
    @endif

    <form action="{{ route('contacts.index') }}" method="GET" class="flex flex-wrap gap-2 mb-6">
        <input type="text" name="search" value="{{ request('search') }}" placeholder="Cari kontak..." class="flex-1 min-w-[200px] px-4 py-2 border rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-400">
        <select name="category" class="px-4 py-2 border rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-400">
            <option value="">Semua Kategori</option>
            @foreach($categories as $category)
                <option value="{{ $category->id }}" {{ request('category') == $category->id ? 'selected' : '' }}>{{ $category->name }}</option>
            @endforeach
        </select>
        <button type="submit" class="bg-blue-500 hover:bg-blue-600 text-white px-4 py-2 rounded-lg">Cari</button>
        @if(request()->anyFilled(['search', 'category']))
            <a href="{{ route('contacts.index') }}" class="bg-gray-300 hover:bg-gray-400 text-gray-700 px-4 py-2 rounded-lg">Reset</a>
        @endif
    </form>

    <div class="grid grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4 gap-4">
        @forelse($contacts as $contact)
            <div class="bg-white rounded-lg shadow-md overflow-hidden hover:shadow-lg transition-shadow">
                <div class="p-4 text-center">
                    @if($contact->photo)
                        <img src="{{ \Illuminate\Support\Facades\Storage::url($contact->photo) }}" alt="{{ $contact->name }}"
                            class="w-20 h-20 rounded-full mx-auto object-cover">
                    @else
                        <div class="w-20 h-20 rounded-full mx-auto bg-blue-100 flex items-center justify-center">
                            <span class="text-2xl font-bold text-blue-500">{{ strtoupper(substr($contact->name, 0, 1)) }}</span>
                        </div>
                    @endif
                    <h3 class="mt-3 font-semibold text-gray-800">{{ $contact->name }}</h3>
                    <p class="text-sm text-gray-500">{{ $contact->email }}</p>
                    @if($contact->phone)
                        <p class="text-sm text-gray-500">{{ $contact->phone }}</p>
                    @endif
                    <span class="inline-block mt-2 px-2 py-1 text-xs rounded bg-blue-100 text-blue-700">
                        {{ $contact->category->name }}
                    </span>
                    @if($contact->is_favorite)
                        <span class="inline-block mt-2 px-2 py-1 text-xs rounded bg-yellow-100 text-yellow-700 ml-1">
                            Favorite
                        </span>
                    @endif
                </div>
                <div class="border-t px-4 py-3 flex justify-around text-sm">
                    <a href="{{ route('contacts.show', $contact) }}" class="text-blue-500 hover:text-blue-700">Detail</a>
                    <a href="{{ route('contacts.edit', $contact) }}" class="text-yellow-500 hover:text-yellow-700">Edit</a>
                    <form action="{{ route('contacts.destroy', $contact) }}" method="POST" class="inline" onsubmit="return confirm('Hapus kontak {{ $contact->name }}?')">
                        @csrf @method('DELETE')
                        <button type="submit" class="text-red-500 hover:text-red-700">Hapus</button>
                    </form>
                </div>
            </div>
        @empty
            <div class="col-span-full text-center py-12 text-gray-400">
                <p class="text-lg">Belum ada kontak.</p>
                <a href="{{ route('contacts.create') }}" class="text-blue-500 hover:underline">Tambah kontak pertama</a>
            </div>
        @endforelse
    </div>

    <div class="mt-6">
        {{ $contacts->links() }}
    </div>
</div>
@endsection
```

## Cara Integrasi & Pengujian
Akses route `/contacts`. Pastikan card kontak tampil dalam grid rapi dengan foto (atau inisial), nama, email, telepon, dan kategori.
