# 104. Membuat seeder untuk mengisi data kategori awal menggunakan factory

## Definisi & Target
Membuat seeder dan factory untuk mengisi database dengan data kategori dan kontak awal. Factory digunakan untuk menghasilkan data dummy yang realistis.

## Komponen yang Terlibat
- Factory: `database/factories/CategoryFactory.php`
- Factory: `database/factories/ContactFactory.php`
- Seeder: `database/seeders/CategorySeeder.php`
- Seeder: `database/seeders/DatabaseSeeder.php`

## Perintah Artisan CLI
```
php artisan make:factory CategoryFactory --model=Category
php artisan make:factory ContactFactory --model=Contact
php artisan make:seeder CategorySeeder
```

## Kode Implementasi (Per File)

**database/factories/CategoryFactory.php**
```php
<?php

namespace Database\Factories;

use App\Models\Category;
use Illuminate\Database\Eloquent\Factories\Factory;
use Illuminate\Support\Str;

class CategoryFactory extends Factory
{
    protected $model = Category::class;

    public function definition(): array
    {
        $name = fake()->unique()->randomElement([
            'Keluarga', 'Teman', 'Kerja', 'Sekolah', 'Tetangga',
            'Klien', 'Supplier', 'Langganan', 'Darurat', 'Lainnya',
        ]);

        return [
            'name' => $name,
            'slug' => Str::slug($name),
            'description' => fake()->sentence(),
        ];
    }
}
```

**database/factories/ContactFactory.php**
```php
<?php

namespace Database\Factories;

use App\Models\Category;
use App\Models\Contact;
use Illuminate\Database\Eloquent\Factories\Factory;

class ContactFactory extends Factory
{
    protected $model = Contact::class;

    public function definition(): array
    {
        return [
            'category_id' => Category::factory(),
            'name' => fake()->name(),
            'email' => fake()->unique()->safeEmail(),
            'phone' => fake()->phoneNumber(),
            'photo' => null,
            'address' => fake()->address(),
            'is_favorite' => fake()->boolean(20),
        ];
    }
}
```

**database/seeders/CategorySeeder.php**
```php
<?php

namespace Database\Seeders;

use App\Models\Category;
use Illuminate\Database\Seeder;
use Illuminate\Support\Str;

class CategorySeeder extends Seeder
{
    public function run(): void
    {
        $categories = ['Keluarga', 'Teman', 'Kerja', 'Sekolah', 'Lainnya'];

        foreach ($categories as $name) {
            Category::create([
                'name' => $name,
                'slug' => Str::slug($name),
                'description' => "Kategori $name",
            ]);
        }
    }
}
```

**database/seeders/DatabaseSeeder.php**
```php
<?php

namespace Database\Seeders;

use Illuminate\Database\Seeder;

class DatabaseSeeder extends Seeder
{
    public function run(): void
    {
        $this->call([
            CategorySeeder::class,
        ]);

        \App\Models\Contact::factory(50)->create();
    }
}
```

## Cara Integrasi & Pengujian
Jalankan `php artisan db:seed`. Pastikan data category dan contact terisi di database. Untuk mengulang dari awal, jalankan `php artisan migrate:fresh --seed`.
