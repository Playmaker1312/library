# 143. Membuat barcode generator sederhana menggunakan package milon/barcode

## Definisi & Target
Mengintegrasikan barcode generator ke dalam sistem inventori. Setiap produk dapat menampilkan barcode berdasarkan SKU atau kode produk menggunakan package milon/barcode.

## Komponen yang Terlibat
- Package: milon/barcode
- Product model (barcode field)
- Blade View: `resources/views/products/show.blade.php`

## Perintah Artisan CLI
```
composer require milon/barcode
```

## Kode Implementasi (Per File)

**config/app.php (tambah provider dan alias jika perlu)**
```php
'providers' => [
    // ...
    Milon\Barcode\BarcodeServiceProvider::class,
],

'aliases' => [
    // ...
    'DNS1D' => Milon\Barcode\Facades\DNS1DFacade::class,
    'DNS2D' => Milon\Barcode\Facades\DNS2DFacade::class,
],
```

**app/Http/Controllers/ProductController.php (method generateBarcode)**
```php
use Milon\Barcode\Facades\DNS1DFacade;

public function generateBarcode(Product $product)
{
    $barcodeValue = $product->barcode ?? $product->sku;

    $barcode = DNS1DFacade::getBarcodeSVG($barcodeValue, 'C128', 2, 60);

    return response()->json([
        'success' => true,
        'barcode' => $barcode,
        'value' => $barcodeValue,
    ]);
}
```

**routes/web.php**
```php
Route::get('/products/{product}/barcode', [ProductController::class, 'generateBarcode'])->name('products.barcode');
```

**resources/views/products/show.blade.php (tampilan barcode)**

**Tambahkan field barcode di form create/edit produk**
```php
<div class="mb-4">
    <label class="block text-gray-700 text-sm font-bold mb-2">Barcode</label>
    <input type="text" name="barcode" value="{{ old('barcode', $product->barcode ?? '') }}"
        class="w-full px-4 py-2 border rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-400">
    <p class="text-xs text-gray-500 mt-1">Jika kosong, akan menggunakan SKU</p>

```

## Cara Integrasi & Pengujian
1. Install package milon/barcode
2. Buat produk dengan SKU atau barcode
3. Buka halaman detail produk - barcode akan tampil sebagai SVG
4. Cetak halaman atau gunakan untuk scanning barcode
