# 142. Mengimplementasikan export laporan stok ke PDF menggunakan DomPDF atau Barryvdh

## Definisi & Target
Membuat fitur export laporan stok ke PDF menggunakan package barryvdh/laravel-dompdf. Pengguna dapat mengunduh laporan dalam format PDF.

## Komponen yang Terlibat
- Package: barryvdh/laravel-dompdf
- ReportController (method exportPdf)
- Blade View: `resources/views/reports/stock-movement-pdf.blade.php`

## Perintah Artisan CLI
```
composer require barryvdh/laravel-dompdf
```

## Kode Implementasi (Per File)

**ReportController (method exportPdf)**
```php
use Barryvdh\DomPDF\Facade\Pdf;

public function exportPdf(Request $request)
{
    $query = StockTransaction::with(['product', 'supplier']);

    if ($request->filled('start_date')) {
        $query->whereDate('created_at', '>=', $request->start_date);
    }
    if ($request->filled('end_date')) {
        $query->whereDate('created_at', '<=', $request->end_date);
    }
    if ($request->filled('type')) {
        $query->where('type', $request->type);
    }

    $transactions = $query->latest()->get();

    $summary = (object) [
        'total_in' => $transactions->where('type', 'in')->sum('quantity'),
        'total_out' => $transactions->where('type', 'out')->sum('quantity'),
        'total_transactions' => $transactions->count(),
    ];

    $pdf = Pdf::loadView('reports.stock-movement-pdf', compact('transactions', 'summary'));

    return $pdf->download('laporan-stok-' . date('Y-m-d') . '.pdf');
}
```

## Cara Integrasi & Pengujian
1. Install package dengan composer
2. Buka halaman laporan dengan filter tertentu
3. Klik "Export PDF" - file PDF akan terunduh
4. Buka file PDF dan pastikan data tampil dengan format yang rapi
