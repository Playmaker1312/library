# 137. Mengimplementasikan fitur kurangi stok keluar dengan validasi stok minimum

## Definisi & Target
Membuat fitur untuk mengurangi stok produk keluar (stock out). Sistem akan memvalidasi bahwa stok cukup sebelum mengurangi dan mencatat transaksi.

## Komponen yang Terlibat
- StockTransactionController (method createOut dan storeOut)
- Blade View: `resources/views/stock-transactions/create-out.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**StockTransactionController (method createOut dan storeOut)**
```php
public function createOut()
{
    $products = Product::orderBy('name')->get();
    return view('stock-transactions.create-out', compact('products'));
}

public function storeOut(Request $request)
{
    $validated = $request->validate([
        'product_id' => 'required|exists:products,id',
        'quantity' => 'required|integer|min:1',
        'note' => 'nullable|string|max:500',
    ]);

    $product = Product::findOrFail($validated['product_id']);

    if ($product->stock < $validated['quantity']) {
        return back()
            ->withInput()
            ->withErrors(['quantity' => "Stok tidak mencukupi. Stok saat ini: {$product->stock}"]);
    }

    $oldStock = $product->stock;
    $newStock = $oldStock - $validated['quantity'];

    $product->update(['stock' => $newStock]);

    StockTransaction::create([
        'product_id' => $product->id,
        'type' => 'out',
        'quantity' => $validated['quantity'],
        'stock_before' => $oldStock,
        'stock_after' => $newStock,
        'note' => $validated['note'],
        'reference' => 'STOCK-OUT-' . time(),
    ]);

    return redirect()->route('products.show', $product)
        ->with('success', "Stok {$product->name} berhasil dikurangi {$validated['quantity']} unit.");
}
```

@section('scripts')
<script>
    const productSelect = document.getElementById('product-select');
    const currentStock = document.getElementById('current-stock');
    const quantityInput = document.getElementById('quantity');
    const stockWarning = document.getElementById('stock-warning');

    productSelect.addEventListener('change', function() {
        const option = this.options[this.selectedIndex];
        const stock = option.dataset.stock;
        currentStock.textContent = stock !== undefined ? stock + ' unit' : '-';
        validateStock();
    });

    quantityInput.addEventListener('input', validateStock);

    function validateStock() {
        const option = productSelect.options[productSelect.selectedIndex];
        const stock = parseInt(option.dataset.stock) || 0;
        const quantity = parseInt(quantityInput.value) || 0;
        if (quantity > 0 && quantity > stock) {
            stockWarning.classList.remove('hidden');
        } else {
            stockWarning.classList.add('hidden');
        }
    }
</script>
@endsection

3. Masukkan jumlah melebihi stok - validasi akan menolak
