# 140. Membuat dashboard inventori dengan statistik utama menggunakan Eloquent aggregation

## Definisi & Target
Membuat halaman dashboard yang menampilkan statistik inventori utama seperti total produk, total stok, produk dengan stok menipis, dan nilai inventori menggunakan Eloquent aggregation.

## Komponen yang Terlibat
- Controller: `app/Http/Controllers/DashboardController.php`
- Blade View: `resources/views/dashboard.blade.php`

## Perintah Artisan CLI
```
php artisan make:controller DashboardController
```

## Kode Implementasi (Per File)

**app/Http/Controllers/DashboardController.php**
```php
<?php

namespace App\Http\Controllers;

use App\Models\Category;
use App\Models\Product;
use App\Models\StockTransaction;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\DB;

class DashboardController extends Controller
{
    public function index()
    {
        $totalProducts = Product::count();
        $totalStock = Product::sum('stock');
        $lowStockCount = Product::lowStock()->where('stock', '>', 0)->count();
        $outOfStockCount = Product::outOfStock()->count();

        $totalInventoryValue = Product::select(
            DB::raw('SUM(stock * purchase_price) as total_purchase'),
            DB::raw('SUM(stock * selling_price) as total_selling')
        )->first();

        $lowStockProducts = Product::with('category')
            ->lowStock()
            ->orderBy('stock')
            ->limit(10)
            ->get();

        $recentTransactions = StockTransaction::with('product')
            ->latest()
            ->limit(10)
            ->get();

        $stockByCategory = Category::withCount(['products' => function ($query) {
                $query->select(DB::raw('SUM(stock) as total_stock'));
            }])
            ->having('products_count', '>', 0)
            ->get();

        $topProducts = Product::orderByDesc('stock')->limit(5)->get();

        return view('dashboard', compact(
            'totalProducts',
            'totalStock',
            'lowStockCount',
            'outOfStockCount',
            'totalInventoryValue',
            'lowStockProducts',
            'recentTransactions',
            'stockByCategory',
            'topProducts'
        ));
    }
}
```
