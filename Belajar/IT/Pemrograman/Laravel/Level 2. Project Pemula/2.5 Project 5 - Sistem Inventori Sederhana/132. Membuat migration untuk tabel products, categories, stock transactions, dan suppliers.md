# 132. Membuat migration untuk tabel products, categories, stock transactions, dan suppliers

## Definisi & Target
Membuat empat tabel database: categories, suppliers, products, dan stock_transactions. Tabel products menyimpan data barang, stock_transactions mencatat pergerakan stok.

## Komponen yang Terlibat
- Migration: create_categories_table
- Migration: create_suppliers_table
- Migration: create_products_table
- Migration: create_stock_transactions_table

## Perintah Artisan CLI
```
php artisan make:migration create_categories_table
php artisan make:migration create_suppliers_table
php artisan make:migration create_products_table
php artisan make:migration create_stock_transactions_table
```

**database/migrations/xxxx_xx_xx_create_products_table.php**
```php
Schema::create('products', function (Blueprint $table) {
    $table->id();
    $table->foreignId('category_id')->constrained()->cascadeOnDelete();
    $table->string('name');
    $table->string('sku')->unique();
    $table->text('description')->nullable();
    $table->integer('stock')->default(0);
    $table->integer('minimum_stock')->default(0);
    $table->decimal('purchase_price', 12, 2)->nullable();
    $table->decimal('selling_price', 12, 2)->nullable();
    $table->string('barcode')->nullable();
    $table->timestamps();
});
```

**database/migrations/xxxx_xx_xx_create_stock_transactions_table.php**
```php
Schema::create('stock_transactions', function (Blueprint $table) {
    $table->id();
    $table->foreignId('product_id')->constrained()->cascadeOnDelete();
    $table->foreignId('supplier_id')->nullable()->constrained()->nullOnDelete();
    $table->enum('type', ['in', 'out']);
    $table->integer('quantity');
    $table->integer('stock_before');
    $table->integer('stock_after');
    $table->text('note')->nullable();
    $table->string('reference')->nullable();
    $table->timestamps();
});
```

## Cara Integrasi & Pengujian
Jalankan `php artisan migrate` untuk membuat semua tabel. Periksa struktur dan relasi foreign key di database.
