# 144. Mengimplementasikan fitur import produk dari file Excel menggunakan Laravel Excel

## Definisi & Target
Membuat fitur import produk dari file Excel menggunakan package Laravel Excel. Pengguna dapat mengupload file Excel (.xlsx, .xls) yang berisi data produk untuk ditambahkan secara massal.

## Komponen yang Terlibat
- Package: maatwebsite/laravel-excel
- Import Class: `app/Imports/ProductsImport.php`
- ProductController (method importForm dan import)
- Blade View: `resources/views/products/import.blade.php`

## Perintah Artisan CLI
```
composer require maatwebsite/laravel-excel
php artisan vendor:publish --provider="Maatwebsite\Excel\ExcelServiceProvider" --tag=config
php artisan make:import ProductsImport --model=Product
```

## Kode Implementasi (Per File)

**app/Imports/ProductsImport.php**
```php
<?php

namespace App\Imports;

use App\Models\Category;
use App\Models\Product;
use Illuminate\Support\Str;
use Maatwebsite\Excel\Concerns\ToModel;
use Maatwebsite\Excel\Concerns\WithHeadingRow;
use Maatwebsite\Excel\Concerns\WithValidation;
use Maatwebsite\Excel\Concerns\SkipsOnFailure;
use Maatwebsite\Excel\Concerns\SkipsFailures;

class ProductsImport implements ToModel, WithHeadingRow, WithValidation, SkipsOnFailure
{
    use SkipsFailures;

    public function model(array $row)
    {
        $category = Category::firstOrCreate(
            ['slug' => Str::slug($row['kategori'])],
            ['name' => $row['kategori']]
        );

        return new Product([
            'category_id' => $category->id,
            'name' => $row['nama'],
            'sku' => $row['sku'],
            'description' => $row['deskripsi'] ?? null,
            'stock' => $row['stok'] ?? 0,
            'minimum_stock' => $row['stok_minimum'] ?? 0,
            'purchase_price' => $row['harga_beli'] ?? null,
            'selling_price' => $row['harga_jual'] ?? null,
            'barcode' => $row['barcode'] ?? null,
        ]);
    }

    public function rules(): array
    {
        return [
            'nama' => 'required|string|max:255',
            'sku' => 'required|string|max:50|unique:products,sku',
            'stok' => 'nullable|integer|min:0',
            'stok_minimum' => 'nullable|integer|min:0',
        ];
    }

    public function customValidationMessages(): array
    {
        return [
            'nama.required' => 'Nama produk wajib diisi.',
            'sku.required' => 'SKU wajib diisi.',
            'sku.unique' => 'SKU sudah terdaftar.',
        ];
    }
}
```

**ProductController (method importForm dan import)**
```php
use App\Imports\ProductsImport;
use Maatwebsite\Excel\Facades\Excel;

public function importForm()
{
    return view('products.import');
}

public function import(Request $request)
{
    $request->validate([
        'file' => 'required|file|mimes:xlsx,xls,csv|max:5120',
    ]);

    $import = new ProductsImport();
    Excel::import($import, $request->file('file'));

    $message = 'Import selesai.';

    if ($import->failures()->count() > 0) {
        $failures = $import->failures();
        return back()->with('success', $message)->with('import_failures', $failures);
    }

    return redirect()->route('products.index')
        ->with('success', "Import produk berhasil.");
}
```
