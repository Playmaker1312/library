# 134. Mengimplementasikan Eloquent observer untuk mencatat setiap perubahan stok otomatis

## Definisi & Target
Membuat Eloquent Observer yang secara otomatis mencatat transaksi stok setiap kali stok produk berubah. Observer akan mencatat stok sebelum dan sesudah perubahan.

## Komponen yang Terribat
- Observer: `app/Observers/ProductObserver.php`
- Service Provider (registrasi observer)

## Perintah Artisan CLI
```
php artisan make:observer ProductObserver --model=Product
```

## Kode Implementasi (Per File)

**app/Observers/ProductObserver.php**
```php
<?php

namespace App\Observers;

use App\Models\Product;
use App\Models\StockTransaction;

class ProductObserver
{
    public function created(Product $product): void
    {
        if ($product->stock > 0) {
            StockTransaction::create([
                'product_id' => $product->id,
                'type' => 'in',
                'quantity' => $product->stock,
                'stock_before' => 0,
                'stock_after' => $product->stock,
                'note' => 'Stok awal',
                'reference' => 'INIT',
            ]);
        }
    }

    public function updated(Product $product): void
    {
        if ($product->isDirty('stock')) {
            $oldStock = $product->getOriginal('stock');
            $newStock = $product->stock;
            $diff = $newStock - $oldStock;

            if ($diff !== 0) {
                StockTransaction::create([
                    'product_id' => $product->id,
                    'type' => $diff > 0 ? 'in' : 'out',
                    'quantity' => abs($diff),
                    'stock_before' => $oldStock,
                    'stock_after' => $newStock,
                    'note' => 'Penyesuaian stok',
                    'reference' => 'ADJUST',
                ]);
            }
        }
    }
}
```

**app/Providers/AppServiceProvider.php (registrasi observer)**
```php
<?php

namespace App\Providers;

use App\Models\Product;
use App\Observers\ProductObserver;
use Illuminate\Support\ServiceProvider;

class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        Product::observe(ProductObserver::class);
    }

    public function register(): void
    {
        //
    }
}
```

## Cara Integrasi & Pengujian
1. Buat produk baru dengan stok awal - cek tabel stock_transactions
2. Update stok produk - cek transaksi baru tercatat
3. Pastikan stock_before dan stock_after tercatat dengan benar
