# 138. Menampilkan alert atau warning saat stok produk di bawah minimum

## Definisi & Target
Menampilkan peringatan visual saat stok produk berada di bawah atau sama dengan minimum stok. Peringatan muncul di halaman daftar produk dan dashboard.

## Komponen yang Terlibat
- Model Product (scope lowStock)
- Blade View: `resources/views/products/index.blade.php`
- Blade View: `resources/views/dashboard.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**resources/views/products/index.blade.php (tampilan card dengan warning)**
```php
@forelse($products as $product)
    <div class="bg-white rounded-lg shadow-md p-5 {{ $product->isLowStock() ? 'border-l-4 border-red-500' : '' }}">
        <div class="flex justify-between items-start mb-2">
            <h3 class="font-semibold text-gray-800">{{ $product->name }}</h3>
            @if($product->isOutOfStock())
                <span class="bg-red-100 text-red-700 text-xs px-2 py-1 rounded font-medium">Habis</span>
            @elseif($product->isLowStock())
                <span class="bg-yellow-100 text-yellow-700 text-xs px-2 py-1 rounded font-medium">Stok Menipis</span>
            @endif
        </div>
        <p class="text-sm text-gray-500 mb-2">SKU: {{ $product->sku }}</p>
        <p class="text-sm text-gray-500 mb-3">{{ $product->category->name }}</p>

        <div class="flex justify-between items-center">
            <div>
                <span class="text-lg font-bold {{ $product->isLowStock() ? 'text-red-600' : 'text-gray-800' }}">
                    {{ $product->stock }}
                </span>
                <span class="text-sm text-gray-500">/ {{ $product->minimum_stock }} min</span>
            </div>
            <div class="flex gap-2 text-sm">
                <a href="{{ route('products.show', $product) }}" class="text-blue-500 hover:text-blue-700">Detail</a>
                <a href="{{ route('products.edit', $product) }}" class="text-yellow-500 hover:text-yellow-700">Edit</a>
            </div>
        </div>

        @if($product->isLowStock())
            <div class="mt-3 p-2 bg-red-50 text-red-700 text-xs rounded flex items-center gap-1">
                <span>Stok hampir habis! Segera lakukan pengadaan.</span>
            </div>
        @endif
    </div>
@empty
@endforelse
```

**resources/views/dashboard.blade.php (ringkasan stok)**

```php
@extends('layouts.app')

@section('content')
<div class="container mx-auto px-4 py-8">
    <h1 class="text-2xl font-bold text-gray-800 mb-6">Dashboard Inventori</h1>

    <div class="grid grid-cols-1 md:grid-cols-3 gap-4 mb-8">

            <h3 class="text-gray-500 text-sm">Stok Menipis</h3>
            <p class="text-3xl font-bold text-yellow-600">{{ $lowStockCount }}</p>
        </div>
        <div class="bg-white rounded-lg shadow-md p-6 border-l-4 border-red-500">

    @if($lowStockProducts->count() > 0)
        <div class="bg-yellow-50 border border-yellow-400 text-yellow-800 px-4 py-3 rounded mb-6">
            <strong>Peringatan!</strong> Terdapat {{ $lowStockProducts->count() }} produk dengan stok menipis.
        </div>

        <div class="bg-white rounded-lg shadow-md overflow-hidden">
            <table class="min-w-full">
                <thead>
                    <tr class="bg-gray-100 text-gray-600 uppercase text-xs">
                        <th class="py-3 px-4 text-left">Produk</th>
                        <th class="py-3 px-4 text-left">Stok</th>
                        <th class="py-3 px-4 text-left">Minimum</th>
                        <th class="py-3 px-4 text-center">Aksi</th>
                    </tr>
                </thead>
                <tbody>
                    @foreach($lowStockProducts as $product)
                        <tr class="border-b hover:bg-yellow-50">
                            <td class="py-3 px-4">{{ $product->name }}</td>
                            <td class="py-3 px-4 text-red-600 font-bold">{{ $product->stock }}</td>
                            <td class="py-3 px-4">{{ $product->minimum_stock }}</td>
                            <td class="py-3 px-4 text-center">

                            </td>
                        </tr>
                    @endforeach
                </tbody>
            </table>
        </div>
    @endif
</div>
@endsection
```

## Cara Integrasi & Pengujian
1. Buat produk dengan stok di bawah minimum
2. Di halaman daftar produk, produk akan memiliki border merah dan label "Stok Menipis"
3. Dashboard menampilkan jumlah produk dengan stok menipis dan stok habis
