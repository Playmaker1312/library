# 121. Membuat seeder yang mengisi database dengan data artikel realistis menggunakan Faker

## Definisi & Target
Membuat seeder yang mengisi database dengan data artikel, kategori, tag, dan komentar yang realistis menggunakan Faker (bawaan Laravel).

## Komponen yang Terlibat
- Seeder: `database/seeders/DatabaseSeeder.php`
- Seeder: `database/seeders/PostSeeder.php`

## Perintah Artisan CLI
```
php artisan make:seeder PostSeeder
```

## Kode Implementasi (Per File)

**database/seeders/PostSeeder.php**
```php
<?php

namespace Database\Seeders;

use App\Models\Category;
use App\Models\Comment;
use App\Models\Post;
use App\Models\Tag;
use App\Models\User;
use Illuminate\Database\Seeder;

class PostSeeder extends Seeder
{
    public function run(): void
    {
        $user = User::factory()->create([
            'name' => 'Admin Blog',
            'email' => 'admin@blog.com',
        ]);

        $categories = collect([
            'Teknologi', 'Olahraga', 'Kesehatan', 'Pendidikan', 'Wisata',
        ])->map(fn ($name) => Category::create(['name' => $name]));

        $tags = collect([
            'laravel', 'php', 'javascript', 'tips', 'tutorial',
            'berita', 'review', 'panduan', 'update', 'opini',
        ])->map(fn ($name) => Tag::create(['name' => $name]));

        Post::factory(20)
            ->create(['user_id' => $user->id])
            ->each(function ($post) use ($categories, $tags) {
                $post->update(['category_id' => $categories->random()->id]);
                $post->tags()->attach($tags->random(rand(1, 4))->pluck('id'));

                if (fake()->boolean(70)) {
                    Comment::factory(rand(1, 5))->create([
                        'post_id' => $post->id,
                    ]);
                }
            });
    }
}
```

**database/seeders/DatabaseSeeder.php**
```php
<?php

namespace Database\Seeders;

use Illuminate\Database\Seeder;

class DatabaseSeeder extends Seeder
{
    public function run(): void
    {
        $this->call([
            PostSeeder::class,
        ]);
    }
}
```

## Cara Integrasi & Pengujian
Jalankan `php artisan migrate:fresh --seed`. Pastikan data artikel, kategori, tag, dan komentar terisi dengan baik di database.
