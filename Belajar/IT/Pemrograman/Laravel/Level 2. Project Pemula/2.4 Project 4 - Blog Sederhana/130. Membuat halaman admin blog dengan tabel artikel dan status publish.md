# 130. Membuat halaman admin blog dengan tabel artikel dan status publish

## Definisi & Target
Membuat halaman admin untuk mengelola artikel dengan tampilan tabel yang menampilkan judul, penulis, kategori, status, tanggal publish, dan tombol aksi.

## Komponen yang Terlibat
- Blade View: `resources/views/admin/posts/index.blade.php`
- Blade Layout: `resources/views/layouts/admin.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**resources/views/admin/posts/index.blade.php**
```php
@extends('layouts.admin')

@section('title', 'Daftar Artikel')

@section('content')
<div class="bg-white rounded-lg shadow-md overflow-hidden">
    <div class="p-6 border-b flex justify-between items-center">
        <h1 class="text-xl font-bold text-gray-800">Daftar Artikel</h1>
        <a href="{{ route('admin.posts.create') }}" class="bg-blue-500 hover:bg-blue-600 text-white px-4 py-2 rounded-lg text-sm">
            + Tulis Artikel
        </a>
    </div>

    <div class="overflow-x-auto">
        <table class="min-w-full table-auto">
            <thead>
                <tr class="bg-gray-50 text-gray-600 uppercase text-xs">
                    <th class="py-3 px-4 text-left">Judul</th>
                    <th class="py-3 px-4 text-left">Penulis</th>
                    <th class="py-3 px-4 text-left">Kategori</th>
                    <th class="py-3 px-4 text-left">Status</th>
                    <th class="py-3 px-4 text-left">Tanggal</th>
                    <th class="py-3 px-4 text-center">Aksi</th>
                </tr>
            </thead>
            <tbody class="text-gray-600 text-sm">
                @foreach($posts as $post)
                <tr class="border-b border-gray-100 hover:bg-gray-50">
                    <td class="py-3 px-4">
                        <span class="font-medium text-gray-800">{{ Str::limit($post->title, 50) }}</span>
                    </td>
                    <td class="py-3 px-4">{{ $post->author->name }}</td>
                    <td class="py-3 px-4">{{ $post->category?->name ?? '-' }}</td>
                    <td class="py-3 px-4">
                        @if($post->status === 'published')
                            <span class="bg-green-100 text-green-700 px-2 py-1 rounded text-xs font-medium">Published</span>
                        @elseif($post->status === 'draft')
                            <span class="bg-yellow-100 text-yellow-700 px-2 py-1 rounded text-xs font-medium">Draft</span>
                        @else
                            <span class="bg-gray-100 text-gray-700 px-2 py-1 rounded text-xs font-medium">Archived</span>
                        @endif
                    </td>
                    <td class="py-3 px-4 text-xs">
                        {{ $post->published_at ? $post->published_at->format('d/m/Y') : '-' }}
                    </td>
                    <td class="py-3 px-4 text-center">
                        <div class="flex justify-center gap-2">
                            <a href="{{ route('blog.show', $post) }}" target="_blank" class="text-blue-500 hover:text-blue-700">Lihat</a>
                            <a href="{{ route('admin.posts.edit', $post) }}" class="text-yellow-500 hover:text-yellow-700">Edit</a>
                            <form action="{{ route('admin.posts.destroy', $post) }}" method="POST" class="inline" onsubmit="return confirm('Hapus artikel?')">
                                @csrf @method('DELETE')
                                <button type="submit" class="text-red-500 hover:text-red-700">Hapus</button>
                            </form>
                        </div>
                    </td>
                </tr>
                @endforeach
            </tbody>
        </table>
    </div>

    <div class="p-4 border-t">
        {{ $posts->links() }}
    </div>
</div>
@endsection
```

## Cara Integrasi & Pengujian
1. Login sebagai admin
2. Akses route `/admin/posts`
3. Pastikan tabel menampilkan semua artikel dengan informasi lengkap
4. Uji tombol aksi: Lihat (membuka tab baru), Edit (form edit), Hapus (konfirmasi)
