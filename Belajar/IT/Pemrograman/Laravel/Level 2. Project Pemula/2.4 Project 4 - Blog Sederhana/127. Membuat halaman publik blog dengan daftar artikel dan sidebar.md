# 127. Membuat halaman publik blog dengan daftar artikel dan sidebar

## Definisi & Target
Membuat halaman publik blog dengan daftar artikel dalam bentuk grid, sidebar yang berisi daftar kategori dan tag, serta navigasi pagination.

## Komponen yang Terlibat
- Blade View: `resources/views/blog/index.blade.php`
- Blade Layout: `resources/views/layouts/blog.blade.php`

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**resources/views/layouts/blog.blade.php**
```php
<!DOCTYPE html>
<html lang="{{ str_replace('_', '-', app()->getLocale()) }}">
<head>
    <meta charset="UTF-8">

    <title>@yield('title', 'Blog') - Blog Sederhana</title>
    @vite('resources/css/app.css')
</head>
<body class="bg-gray-50 min-h-screen flex flex-col">
    <nav class="bg-white shadow-sm">
        <div class="max-w-6xl mx-auto px-4 py-4 flex justify-between items-center">

```

**resources/views/blog/index.blade.php**
```php
@extends('layouts.blog')

@section('content')
<div class="flex flex-col lg:flex-row gap-8">
    <div class="flex-1">
        <h1 class="text-3xl font-bold text-gray-800 mb-8">
            @isset($selectedCategory)
                Kategori: {{ $selectedCategory->name }}
            @elseif(isset($selectedTag))
                Tag: {{ $selectedTag->name }}
            @else
                Artikel Terbaru
            @endisset
        </h1>

        <div class="grid grid-cols-1 md:grid-cols-2 gap-6">
            @forelse($posts as $post)
                <article class="bg-white rounded-lg shadow-md overflow-hidden hover:shadow-lg transition-shadow">
                    @if($post->getFirstMediaUrl('thumbnail'))
                        <img src="{{ $post->getFirstMediaUrl('thumbnail', 'card') }}" alt="{{ $post->title }}"
                            class="w-full h-48 object-cover">
                    @else
                        <div class="w-full h-48 bg-gradient-to-br from-blue-400 to-blue-600 flex items-center justify-center text-white text-lg font-bold">
                            {{ strtoupper(substr($post->title, 0, 2)) }}
                        </div>
                    @endif
                    <div class="p-5">
                        <div class="flex gap-2 mb-2">
                            @if($post->category)
                                <span class="text-xs bg-blue-100 text-blue-700 px-2 py-1 rounded">{{ $post->category->name }}</span>
                            @endif
                            <span class="text-xs text-gray-500">{{ $post->published_at->format('d M Y') }}</span>
                        </div>
                        <h2 class="text-lg font-semibold text-gray-800 mb-2">
                            <a href="{{ route('blog.show', $post) }}" class="hover:text-blue-600 transition">{{ $post->title }}</a>
                        </h2>
                        <p class="text-gray-600 text-sm mb-3">{{ $post->excerpt ?? Str::limit(strip_tags($post->body), 150) }}</p>
                        <div class="flex gap-1">
                            @foreach($post->tags as $tag)
                                <a href="{{ route('blog.tag', $tag) }}" class="text-xs text-gray-500 hover:text-blue-500">#{{ $tag->name }}</a>
                            @endforeach
                        </div>
                    </div>
                </article>
            @empty
                <div class="col-span-full text-center py-12 text-gray-400">
                    <p>Belum ada artikel.</p>
                </div>
            @endforelse
        </div>

        <div class="mt-8">
            {{ $posts->links() }}
        </div>
    </div>

    <aside class="lg:w-80">
        <div class="bg-white rounded-lg shadow-md p-6 mb-6">
            <h3 class="font-bold text-gray-800 mb-4">Kategori</h3>
            <ul class="space-y-2">
                @foreach($categories ?? \App\Models\Category::withCount('posts')->get() as $category)
                    <li>
                        <a href="{{ route('blog.category', $category) }}"
                            class="flex justify-between items-center text-gray-600 hover:text-blue-600 transition">
                            <span>{{ $category->name }}</span>
                            <span class="text-xs bg-gray-100 px-2 py-1 rounded">{{ $category->posts_count }}</span>
                        </a>
                    </li>
                @endforeach
            </ul>
        </div>

        <div class="bg-white rounded-lg shadow-md p-6">
            <h3 class="font-bold text-gray-800 mb-4">Tags</h3>
            <div class="flex flex-wrap gap-2">
                @foreach($tags ?? \App\Models\Tag::withCount('posts')->get() as $tag)
                    <a href="{{ route('blog.tag', $tag) }}"
                        class="text-sm bg-gray-100 text-gray-600 px-3 py-1 rounded hover:bg-blue-100 hover:text-blue-600 transition">
                        #{{ $tag->name }}
                    </a>
                @endforeach
            </div>
        </div>
    </aside>
</div>
@endsection
```

## Cara Integrasi & Pengujian
Akses route `/blog` di browser. Pastikan artikel muncul dalam grid, sidebar menampilkan kategori dan tag, dan pagination berfungsi.
