# 125. Mengimplementasikan editor teks kaya menggunakan TinyMCE atau Quill.js

## Definisi & Target
Mengintegrasikan editor teks kaya (WYSIWYG) pada form create/edit artikel. Menggunakan TinyMCE yang mudah diintegrasikan dengan Laravel.

## Komponen yang Terlibat
- Blade View: `resources/views/admin/posts/create.blade.php`
- Blade View: `resources/views/admin/posts/edit.blade.php`
- Layout Admin (menambahkan CDN TinyMCE)

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**resources/views/admin/posts/create.blade.php (bagian body)**
```php
@extends('layouts.admin')

@section('content')
<div class="container mx-auto px-4 py-8">
    <h1 class="text-2xl font-bold text-gray-800 mb-6">Tulis Artikel Baru</h1>

    <form action="{{ route('admin.posts.store') }}" method="POST" enctype="multipart/form-data">
        @csrf

        <div class="mb-4">
            <label class="block text-gray-700 font-bold mb-2">Judul</label>
            <input type="text" name="title" value="{{ old('title') }}" required
                class="w-full px-4 py-2 border rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-400">
        </div>

        <div class="grid grid-cols-1 md:grid-cols-2 gap-4 mb-4">
            <div>

                <select name="category_id" class="w-full px-4 py-2 border rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-400">
                    <option value="">Pilih Kategori</option>
                    @foreach($categories as $category)
                        <option value="{{ $category->id }}">{{ $category->name }}</option>
                    @endforeach
                </select>
            </div>

                    <option value="draft">Draft</option>
                    <option value="published">Publikasikan</option>
                </select>
            </div>
        </div>

        <div class="mb-4">
            <label class="block text-gray-700 font-bold mb-2">Konten</label>

        </div>

@section('scripts')
<script src="https://cdnjs.cloudflare.com/ajax/libs/tinymce/7.0.0/tinymce.min.js"></script>

    tinymce.init({
        selector: '#editor',
        plugins: 'advlist autolink lists link image charmap preview anchor searchreplace visualblocks code fullscreen insertdatetime media table code help wordcount',
        toolbar: 'undo redo | blocks | bold italic underline strikethrough | alignleft aligncenter alignright alignjustify | bullist numlist outdent indent | link image | code',
        height: 500,
        menubar: false,
        branding: false,
    });
</script>
@endsection
```

## Cara Integrasi & Pengujian
1. Buka halaman create artikel admin
2. Editor TinyMCE akan muncul di textarea body
3. Tulis konten dengan format teks kaya (bold, list, dll)
4. Simpan artikel dan pastikan konten tersimpan dengan HTML
5. Tampilkan di halaman publik menggunakan `{!! $post->body !!}`
