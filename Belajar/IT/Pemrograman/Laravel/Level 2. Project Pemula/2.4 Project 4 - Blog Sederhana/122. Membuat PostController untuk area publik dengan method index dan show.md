# 122. Membuat PostController untuk area publik dengan method index dan show

## Definisi & Target
Membuat controller untuk halaman publik blog. Method index menampilkan daftar artikel yang sudah dipublikasikan, method show menampilkan detail artikel lengkap.

## Komponen yang Terlibat
- Controller: `app/Http/Controllers/PostController.php`
- Route: `routes/web.php`

## Perintah Artisan CLI
```
php artisan make:controller PostController
```

## Kode Implementasi (Per File)

**app/Http/Controllers/PostController.php**
```php
<?php

namespace App\Http\Controllers;

use App\Models\Post;

class PostController extends Controller
{
    public function index()
    {
        $posts = Post::with(['author', 'category', 'tags'])
            ->published()
            ->latest('published_at')
            ->paginate(9);

        $categories = \App\Models\Category::withCount('posts')->get();
        $tags = \App\Models\Tag::withCount('posts')->get();

        return view('blog.index', compact('posts', 'categories', 'tags'));
    }

    public function show(Post $post)
    {
        if ($post->status !== 'published') {
            abort(404);
        }

        $post->load(['author', 'category', 'tags', 'approvedComments']);

        $relatedPosts = Post::published()
            ->where('category_id', $post->category_id)
            ->where('id', '!=', $post->id)
            ->latest('published_at')
            ->take(3)
            ->get();

        return view('blog.show', compact('post', 'relatedPosts'));
    }

    public function category(\App\Models\Category $category)
    {
        $posts = Post::published()
            ->where('category_id', $category->id)
            ->latest('published_at')
            ->paginate(9);

        return view('blog.index', compact('posts'))
            ->with('selectedCategory', $category);
    }

    public function tag(\App\Models\Tag $tag)
    {
        $posts = $tag->posts()
            ->published()
            ->latest('published_at')
            ->paginate(9);

        return view('blog.index', compact('posts'))
            ->with('selectedTag', $tag);
    }
}
```

**routes/web.php**
```php
use App\Http\Controllers\PostController;

Route::get('/blog', [PostController::class, 'index'])->name('blog.index');
Route::get('/blog/{post:slug}', [PostController::class, 'show'])->name('blog.show');
Route::get('/blog/category/{category:slug}', [PostController::class, 'category'])->name('blog.category');
Route::get('/blog/tag/{tag:slug}', [PostController::class, 'tag'])->name('blog.tag');
```

## Cara Integrasi & Pengujian
Akses route `/blog` di browser. Pastikan daftar artikel muncul dan klik salah satu artikel untuk melihat detail.
