# 119. Membuat relasi many-to-many antara Post dan Tag menggunakan belongsToMany

## Definisi & Target
Mengimplementasikan relasi many-to-many antara Post dan Tag. Satu post bisa memiliki banyak tag, dan satu tag bisa digunakan di banyak post. Menggunakan tabel pivot `post_tag`.

## Komponen yang Terlibat
- Model Post (method tags)
- Model Tag (method posts)

## Perintah Artisan CLI
Tidak ada perintah Artisan.

## Kode Implementasi (Per File)

**app/Models/Post.php**
```php
public function tags()
{
    return $this->belongsToMany(Tag::class)->withTimestamps();
}

public function syncTags(array $tagNames)
{
    $tagIds = collect($tagNames)->map(function ($tagName) {
        return Tag::firstOrCreate(
            ['slug' => Str::slug($tagName)],
            ['name' => $tagName]
        )->id;
    });

    $this->tags()->sync($tagIds);
}
```

**app/Models/Tag.php**
```php
public function posts()
{
    return $this->belongsToMany(Post::class);
}
```

**Penggunaan di Controller (saat store/update post)**
```php
public function store(Request $request)
{
    $post = Post::create([
        'user_id' => auth()->id(),
        'category_id' => $request->category_id,
        'title' => $request->title,
        'body' => $request->body,
        'excerpt' => $request->excerpt,
        'status' => $request->status ?? 'draft',
        'published_at' => $request->status === 'published' ? now() : null,
    ]);

    if ($request->filled('tags')) {
        $post->syncTags(explode(',', $request->tags));
    }

    return redirect()->route('admin.posts.index')->with('success', 'Artikel berhasil dibuat.');
}
```

## Cara Integrasi & Pengujian
1. Buat beberapa tag baru
2. Buat post baru dan attach beberapa tag
3. Verifikasi di tabel pivot `post_tag`
4. Uji akses `$post->tags` dan `$tag->posts`
