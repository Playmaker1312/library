# 129. Mengimplementasikan fitur like artikel menggunakan AJAX tanpa reload

## Definisi & Target
Menambahkan fitur like pada artikel blog. Pengguna dapat menekan tombol like dan jumlah like bertambah tanpa reload halaman menggunakan AJAX.

## Komponen yang Terlibat
- Migration: create_post_likes_table
- Model PostLike
- Model Post (relasi likes)
- Controller: PostController (method like)
- Route API

## Perintah Artisan CLI
```
php artisan make:migration create_post_likes_table
php artisan make:model PostLike
```

## Kode Implementasi (Per File)

**database/migrations/xxxx_xx_xx_create_post_likes_table.php**
```php
Schema::create('post_likes', function (Blueprint $table) {
    $table->id();
    $table->foreignId('post_id')->constrained()->cascadeOnDelete();
    $table->ipAddress('ip_address');
    $table->timestamps();
    $table->unique(['post_id', 'ip_address']);
});
```

**app/Models/PostLike.php**
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;

class PostLike extends Model
{
    use HasFactory;

    protected $fillable = ['post_id', 'ip_address'];
}
```

**app/Models/Post.php (tambah relasi)**
```php
public function likes()
{
    return $this->hasMany(PostLike::class);
}

public function isLikedByIp(string $ipAddress): bool
{
    return $this->likes()->where('ip_address', $ipAddress)->exists();
}
```

**PostController (method like)**
```php
public function like(Request $request, Post $post)
{
    $ip = $request->ip();

    $existingLike = PostLike::where('post_id', $post->id)
        ->where('ip_address', $ip)
        ->first();

    if ($existingLike) {
        $existingLike->delete();
        $liked = false;
    } else {
        PostLike::create(['post_id' => $post->id, 'ip_address' => $ip]);
        $liked = true;
    }

    $count = $post->likes()->count();

    if ($request->wantsJson()) {
        return response()->json([
            'success' => true,
            'liked' => $liked,
            'count' => $count,
        ]);
    }

    return back();
}
```

**routes/web.php**
```php
Route::post('/blog/{post:slug}/like', [PostController::class, 'like'])->name('blog.like');
```

**resources/views/blog/show.blade.php (tombol like)**
```php
<div class="mt-6">
    <button id="like-btn" data-slug="{{ $post->slug }}"
        class="inline-flex items-center gap-2 px-4 py-2 rounded-lg transition
            {{ $post->isLikedByIp(request()->ip()) ? 'bg-red-100 text-red-600' : 'bg-gray-100 text-gray-600 hover:bg-red-50 hover:text-red-500' }}">
        <span id="like-icon">{{ $post->isLikedByIp(request()->ip()) ? '❤️' : '🤍' }}</span>
        <span id="like-count">{{ $post->likes()->count() }}</span>
        <span>Suka</span>
    </button>
</div>

@section('scripts')
<script>
    document.getElementById('like-btn')?.addEventListener('click', function() {
        const slug = this.dataset.slug;

        fetch(`/blog/${slug}/like`, {
            method: 'POST',
            headers: {
                'X-CSRF-TOKEN': document.querySelector('meta[name="csrf-token"]').content,
                'Accept': 'application/json',
                'Content-Type': 'application/json',
            },
        })
        .then(res => res.json())
        .then(data => {
            if (data.success) {
                document.getElementById('like-count').textContent = data.count;
                document.getElementById('like-icon').textContent = data.liked ? '❤️' : '🤍';
                this.classList.toggle('bg-red-100', data.liked);
                this.classList.toggle('text-red-600', data.liked);
                this.classList.toggle('bg-gray-100', !data.liked);
                this.classList.toggle('text-gray-600', !data.liked);
            }
        });
    });
</script>
@endsection
```
