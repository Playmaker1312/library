# 117. Membuat migration untuk tabel posts, categories, tags, comments, dan post tag pivot

## Definisi & Target
Membuat lima tabel database: posts, categories, tags, comments, dan post_tag (pivot). Tabel posts berisi artikel, comments untuk komentar, dan post_tag untuk relasi many-to-many.

## Komponen yang Terlibat
- Migration: create_posts_table
- Migration: create_categories_table
- Migration: create_tags_table
- Migration: create_post_tag_table
- Migration: create_comments_table

## Perintah Artisan CLI
```
php artisan make:migration create_posts_table
php artisan make:migration create_categories_table
php artisan make:migration create_tags_table
php artisan make:migration create_post_tag_table
php artisan make:migration create_comments_table
```

Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained()->cascadeOnDelete();
    $table->foreignId('category_id')->nullable()->constrained()->nullOnDelete();
    $table->string('title');
    $table->string('slug')->unique();
    $table->text('excerpt')->nullable();
    $table->longText('body');
    $table->string('thumbnail')->nullable();
    $table->enum('status', ['draft', 'published', 'archived'])->default('draft');
    $table->timestamp('published_at')->nullable();
    $table->timestamps();
});
