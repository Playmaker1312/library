# 126. Mengimplementasikan upload gambar thumbnail artikel menggunakan Spatie Media Library

## Definisi & Target
Mengimplementasikan upload dan manajemen gambar thumbnail untuk artikel menggunakan package Spatie Media Library. Package ini menyediakan fitur upload, resize, dan konversi gambar yang powerful.

## Komponen yang Terlibat
- Package Spatie Media Library
- Model Post
- Admin PostController

## Perintah Artisan CLI
```
composer require spatie/laravel-medialibrary
php artisan vendor:publish --provider="Spatie\MediaLibrary\MediaLibraryServiceProvider" --tag="migrations"
php artisan migrate
php artisan vendor:publish --provider="Spatie\MediaLibrary\MediaLibraryServiceProvider" --tag="config"
```

## Kode Implementasi (Per File)

**app/Models/Post.php**
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;
use Spatie\MediaLibrary\HasMedia;
use Spatie\MediaLibrary\InteractsWithMedia;
use Spatie\MediaLibrary\MediaCollections\Models\Media;

class Post extends Model implements HasMedia
{
    use HasFactory, InteractsWithMedia;

    public function registerMediaCollections(): void
    {
        $this->addMediaCollection('thumbnail')
            ->singleFile()
            ->registerMediaConversions(function (Media $media = null) {
                $this->addMediaConversion('thumb')
                    ->width(300)
                    ->height(200);
                $this->addMediaConversion('card')
                    ->width(600)
                    ->height(400);
            });
    }

    // ... fillable, casts, relasi, dll
}
```

**Admin PostController (store)**
```php
public function store(Request $request)
{
    $validated = $request->validate([...]);

    $post = Post::create($validated);

    if ($request->hasFile('thumbnail')) {
        $post->addMediaFromRequest('thumbnail')
            ->toMediaCollection('thumbnail');
    }

    // ... sync tags

    return redirect()->route('admin.posts.index')
        ->with('success', 'Artikel berhasil dibuat.');
}
```

**Menampilkan thumbnail di view**
```php
@if($post->getFirstMediaUrl('thumbnail'))
    <img src="{{ $post->getFirstMediaUrl('thumbnail', 'card') }}" alt="{{ $post->title }}"
         class="w-full h-48 object-cover">
@else
    <div class="w-full h-48 bg-gray-200 flex items-center justify-center text-gray-400">
        Tanpa Gambar
    </div>
@endif
```

## Cara Integrasi & Pengujian
1. Install package dan jalankan migration
2. Tambahkan field thumbnail di form artikel
3. Upload gambar saat membuat artikel
4. Pastikan gambar tersimpan di media collection
5. Tampilkan thumbnail di halaman publik blog
