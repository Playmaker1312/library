# 353. Membangun Portal Orang Tua untuk Melihat Nilai dan Absensi Anak

## Definisi & Target
Portal untuk orang tua/wali melihat nilai, absensi, dan jadwal anak. Orang tua login dengan akun khusus yang terhubung ke data siswa.

## Komponen yang Terlibat
- Parent dashboard controller
- Parent auth (guard / role)
- View child grades & attendance
- Student-parent relationship
- Middleware akses orang tua

## Perintah Artisan CLI
```bash
php artisan make:controller ParentPortalController
php artisan make:middleware CheckParentAccess
```

### Middleware
```php
// app/Http/Middleware/CheckParentAccess.php
namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;

class CheckParentAccess
{
    public function handle(Request $request, Closure $next)
    {
        $student = $request->route('student');

        if ($student && auth()->user()->role === 'parent') {
            if ($student->parent_user_id !== auth()->id()) {
                abort(403, 'Anda tidak memiliki akses ke data siswa ini.');
            }
        }

        return $next($request);
    }
}
```

### Controller
```php
// app/Http/Controllers/ParentPortalController.php
namespace App\Http\Controllers;

use App\Models\AcademicYear;
use App\Models\Attendance;
use App\Models\Grade;
use App\Models\Student;
use App\Models\Subject;
use Illuminate\Http\Request;

class ParentPortalController extends Controller
{
    public function dashboard()
    {
        $students = Student::where('parent_user_id', auth()->id())
            ->with('classroom')
            ->get();

        return view('parent.dashboard', compact('students'));
    }

    public function studentGrades(Student $student)
    {
        if ($student->parent_user_id !== auth()->id()) {
            abort(403);
        }

        $academicYear = AcademicYear::getActiveYear();
        $semester = AcademicYear::getActiveSemester();

        $grades = Grade::where('student_id', $student->id)
            ->where('academic_year', $academicYear)
            ->where('semester', $semester)
            ->with('subject')
            ->get();

        $subjects = Subject::all();

        return view('parent.grades', compact('student', 'grades', 'subjects', 'academicYear', 'semester'));
    }

    public function studentAttendance(Student $student, Request $request)
    {
        if ($student->parent_user_id !== auth()->id()) {
            abort(403);
        }

        $month = $request->month ?? date('m');
        $year = $request->year ?? date('Y');

        $attendances = Attendance::where('student_id', $student->id)
            ->whereYear('date', $year)
            ->whereMonth('date', $month)
            ->orderBy('date')
            ->get();

        $stats = [
            'hadir' => $attendances->where('status', 'hadir')->count(),
            'sakit' => $attendances->where('status', 'sakit')->count(),
            'izin' => $attendances->where('status', 'izin')->count(),
            'alpha' => $attendances->where('status', 'alpha')->count(),
        ];

        return view('parent.attendance', compact('student', 'attendances', 'stats', 'month', 'year'));
    }

    public function studentSchedule(Student $student)
    {
        if ($student->parent_user_id !== auth()->id()) {
            abort(403);
        }

        $classroom = $student->classroom;
        $schedules = $classroom?->schedules()->with(['subject', 'teacher'])->get()->groupBy('day') ?? collect();

        return view('parent.schedule', compact('student', 'classroom', 'schedules'));
    }
}
```

### Routes
```php
// routes/web.php
use App\Http\Controllers\ParentPortalController;

Route::middleware(['auth', 'role:parent'])->prefix('parent')->group(function () {
    Route::get('/dashboard', [ParentPortalController::class, 'dashboard'])->name('parent.dashboard');
    Route::get('/students/{student}/grades', [ParentPortalController::class, 'studentGrades'])->name('parent.student.grades');
    Route::get('/students/{student}/attendance', [ParentPortalController::class, 'studentAttendance'])->name('parent.student.attendance');
    Route::get('/students/{student}/schedule', [ParentPortalController::class, 'studentSchedule'])->name('parent.student.schedule');
});
```

## Cara Integrasi & Pengujian
1. Buat user dengan role 'parent'
2. Set `parent_user_id` di tabel students
3. Login sebagai orang tua
4. Lihat dashboard dengan data anak
5. Klik "Nilai" untuk melihat nilai anak
6. Klik "Absensi" untuk melihat rekap absensi
7. Klik "Jadwal" untuk melihat jadwal pelajaran
8. Pastikan orang tua tidak bisa akses data siswa lain
