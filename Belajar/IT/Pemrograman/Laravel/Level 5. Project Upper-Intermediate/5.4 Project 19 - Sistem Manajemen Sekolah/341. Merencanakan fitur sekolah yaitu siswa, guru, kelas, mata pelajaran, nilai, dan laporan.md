# 341. Merencanakan Fitur Sekolah yaitu Siswa, Guru, Kelas, Mata Pelajaran, Nilai, dan Laporan

## Definisi & Target
Merencanakan arsitektur sistem manajemen sekolah yang mencakup data siswa, guru, kelas, jadwal, nilai, absensi, dan laporan. Target: dokumen perencanaan lengkap.

## Komponen yang Terlibat
- Manajemen Siswa (data lengkap, foto, wali)
- Manajemen Guru (data, mata pelajaran)
- Manajemen Kelas & pembagian siswa
- Jadwal pelajaran
- Sistem nilai & bobot
- Absensi harian
- Raport digital PDF
- Portal orang tua
- Dashboard kepala sekolah

## Perintah Artisan CLI
Tidak ada perintah khusus untuk tahap perencanaan.

## Kode Implementasi (Per File)

### Perencanaan Fitur

**Students Module**
- NIS/NISN, nama, tempat/tanggal lahir, jenis kelamin, alamat, foto
- Nama orang tua/wali, kontak, pekerjaan
- Tahun masuk, status (active/alumni/keluar)

**Teachers Module**
- NIP/NUPTK, nama, gelar, mata pelajaran yang diajarkan
- Kontak, alamat, foto, spesialisasi

**Classes Module**
- Tingkat (kelas 1-6/7-9/10-12), nama kelas (A, B, etc)
- Wali kelas, tahun ajaran

**Subjects Module**
- Nama mata pelajaran, kode, kelompok (wajib/peminatan)
- Jam per minggu, guru pengajar

**Grades Module**
- Nilai per mata pelajaran per siswa
- Komponen nilai: tugas, UTS, UAS dengan bobot
- Nilai akhir = (tugas*bobot_tugas + uts*bobot_uts + uas*bobot_uas)
- Grade (A, B, C, D, E)

**Attendance Module**
- Absensi harian per kelas per tanggal
- Status: hadir, izin, sakit, alpha
- Rekap bulanan

**Reports**
- Raport format PDF
- Laporan absensi Excel
- Statistik akademik dashboard

### Schema Concept
```
students
  - id, nis, nisn, name, gender, birth_place, birth_date
  - address, phone, photo, parent_name, parent_phone
  - class_id, entry_year, status
  - created_at, updated_at

teachers
  - id, nip, nuptk, name, front_degree, back_degree
  - gender, phone, address, photo, specialization
  - created_at, updated_at

classes
  - id, name, level, teacher_id (walikelas), academic_year
  - created_at, updated_at

subjects
  - id, name, code, group, hours_per_week
  - created_at, updated_at

class_subjects
  - id, class_id, subject_id, teacher_id
  - created_at

schedules
  - id, class_id, subject_id, teacher_id, day, start_time, end_time
  - created_at

grades
  - id, student_id, subject_id, class_id, academic_year, semester
  - assignment_score, uts_score, uas_score, final_score, grade
  - created_at, updated_at

attendances
  - id, student_id, class_id, date, status, note
  - created_at

announcements
  - id, title, content, target_role, created_by
  - created_at, updated_at
```
