# 347. Mengimplementasikan Jadwal Pelajaran Mingguan yang Fleksibel

## Definisi & Target
Sistem jadwal pelajaran mingguan per kelas. Admin/guru dapat mengatur jadwal dengan hari, jam mulai, jam selesai, dan guru pengajar.

## Komponen yang Terlibat
- Schedule model & migration
- ScheduleController
- Jadwal view per kelas
- Konflik detection

## Perintah Artisan CLI
```bash
php artisan make:controller ScheduleController
php artisan make:livewire ScheduleManager
```

## Kode Implementasi (Per File)

### Controller
```php
// app/Http/Controllers/ScheduleController.php
namespace App\Http\Controllers;

use App\Models\Classroom;
use App\Models\Schedule;
use App\Models\Subject;
use App\Models\Teacher;
use Illuminate\Http\Request;

class ScheduleController extends Controller
{
    public function index(Request $request)
    {
        $classes = Classroom::orderBy('level')->orderBy('name')->get();
        $selectedClass = null;
        $schedules = collect();

        if ($request->filled('class_id')) {
            $selectedClass = Classroom::with(['schedules' => fn($q) => $q->with('subject', 'teacher')])
                ->find($request->class_id);

            $schedules = $selectedClass?->schedules->groupBy('day') ?? collect();
        }

        return view('schedules.index', compact('classes', 'selectedClass', 'schedules'));
    }

    public function create(Request $request)
    {
        $classrooms = Classroom::all();
        $subjects = Subject::all();
        $teachers = Teacher::all();
        $selectedClass = $request->filled('class_id') ? Classroom::find($request->class_id) : null;

        return view('schedules.create', compact('classrooms', 'subjects', 'teachers', 'selectedClass'));
    }

    public function store(Request $request)
    {
        $request->validate([
            'class_id' => 'required|exists:classes,id',
            'subject_id' => 'required|exists:subjects,id',
            'teacher_id' => 'required|exists:teachers,id',
            'day' => 'required|in:senin,selasa,rabu,kamis,jumat,sabtu',
            'start_time' => 'required|date_format:H:i',
            'end_time' => 'required|date_format:H:i|after:start_time',
        ]);

        $conflict = $this->checkConflict(
            $request->class_id,
            $request->day,
            $request->start_time,
            $request->end_time,
            $request->teacher_id
        );

        if ($conflict) {
            return back()->withErrors($conflict)->withInput();
        }

        Schedule::create($request->all());

        return redirect()->route('schedules.index', ['class_id' => $request->class_id])
            ->with('success', 'Jadwal berhasil ditambahkan.');
    }

    public function edit(Schedule $schedule)
    {
        $classrooms = Classroom::all();
        $subjects = Subject::all();
        $teachers = Teacher::all();

        return view('schedules.edit', compact('schedule', 'classrooms', 'subjects', 'teachers'));
    }

    public function update(Request $request, Schedule $schedule)
    {
        $request->validate([
            'class_id' => 'required|exists:classes,id',
            'subject_id' => 'required|exists:subjects,id',
            'teacher_id' => 'required|exists:teachers,id',
            'day' => 'required|in:senin,selasa,rabu,kamis,jumat,sabtu',
            'start_time' => 'required|date_format:H:i',
            'end_time' => 'required|date_format:H:i|after:start_time',
        ]);

        $schedule->update($request->all());

        return redirect()->route('schedules.index', ['class_id' => $schedule->class_id])
            ->with('success', 'Jadwal diperbarui.');
    }

    public function destroy(Schedule $schedule)
    {
        $classId = $schedule->class_id;
        $schedule->delete();

        return redirect()->route('schedules.index', ['class_id' => $classId])
            ->with('success', 'Jadwal dihapus.');
    }

    protected function checkConflict($classId, $day, $start, $end, $teacherId)
    {
        $errors = [];

        $classConflict = Schedule::where('class_id', $classId)
            ->where('day', $day)
            ->where(function ($q) use ($start, $end) {
                $q->whereBetween('start_time', [$start, $end])
                  ->orWhereBetween('end_time', [$start, $end])
                  ->orWhere(function ($q2) use ($start, $end) {
                      $q2->where('start_time', '<=', $start)
                         ->where('end_time', '>=', $end);
                  });
            })
            ->exists();

        if ($classConflict) {
            $errors['class_id'] = 'Kelas sudah memiliki jadwal di jam tersebut.';
        }

        $teacherConflict = Schedule::where('teacher_id', $teacherId)
            ->where('day', $day)
            ->where(function ($q) use ($start, $end) {
                $q->whereBetween('start_time', [$start, $end])
                  ->orWhereBetween('end_time', [$start, $end])
                  ->orWhere(function ($q2) use ($start, $end) {
                      $q2->where('start_time', '<=', $start)
                         ->where('end_time', '>=', $end);
                  });
            })
            ->exists();

        if ($teacherConflict) {
            $errors['teacher_id'] = 'Guru sudah memiliki jadwal di jam tersebut.';
        }

        return $errors ?: null;
    }
}
```

### Route
```php
// routes/web.php
use App\Http\Controllers\ScheduleController;

Route::middleware(['auth', 'role:admin'])->group(function () {
    Route::get('/schedules', [ScheduleController::class, 'index'])->name('schedules.index');
    Route::get('/schedules/create', [ScheduleController::class, 'create'])->name('schedules.create');
    Route::post('/schedules', [ScheduleController::class, 'store'])->name('schedules.store');
    Route::get('/schedules/{schedule}/edit', [ScheduleController::class, 'edit'])->name('schedules.edit');
    Route::put('/schedules/{schedule}', [ScheduleController::class, 'update'])->name('schedules.update');
    Route::delete('/schedules/{schedule}', [ScheduleController::class, 'destroy'])->name('schedules.destroy');
});
```

## Cara Integrasi & Pengujian
1. Buat jadwal: pilih kelas, mata pelajaran, guru, hari, jam
2. Verifikasi jadwal muncul di tabel
3. Uji konflik: buat jadwal di jam yang sama (harus ditolak)
4. Uji konflik guru: guru yang sama di jam yang sama (harus ditolak)
5. Edit jadwal, ganti jam
6. Hapus jadwal
7. Ganti kelas di dropdown, jadwal berganti
