# 350. Mengimplementasikan Raport Digital dalam Format PDF

## Definisi & Target
Generate raport siswa dalam format PDF yang bisa didownload. Raport mencakup semua mata pelajaran, nilai, grade, predikat, dan catatan.

## Komponen yang Terlibat
- ReportController
- Laravel DomPDF / Barryvdh PDF
- Grade data aggregation
- Template raport PDF
- Filter per kelas/siswa/semester

## Perintah Artisan CLI
```bash
composer require barryvdh/laravel-dompdf
php artisan make:controller ReportController
php artisan vendor:publish --provider="Barryvdh\DomPDF\ServiceProvider"
```

## Kode Implementasi (Per File)

### Controller
```php
// app/Http/Controllers/ReportController.php
namespace App\Http\Controllers;

use App\Models\AcademicYear;
use App\Models\Classroom;
use App\Models\Grade;
use App\Models\Student;
use App\Models\Subject;
use Barryvdh\DomPDF\Facade\Pdf;
use Illuminate\Http\Request;

class ReportController extends Controller
{
    public function index()
    {
        $classes = Classroom::orderBy('level')->orderBy('name')->get();
        return view('reports.index', compact('classes'));
    }

    public function classReport(Request $request)
    {
        $request->validate([
            'class_id' => 'required|exists:classes,id',
            'semester' => 'required|in:ganjil,genap',
        ]);

        $classroom = Classroom::with(['teacher', 'students' => fn($q) => $q->where('status', 'active')->orderBy('name')])
            ->findOrFail($request->class_id);

        $academicYear = AcademicYear::getActiveYear();
        $semester = $request->semester;

        $subjects = Subject::all();

        $grades = Grade::whereIn('student_id', $classroom->students->pluck('id'))
            ->where('academic_year', $academicYear)
            ->where('semester', $semester)
            ->get()
            ->groupBy('student_id');

        $reportData = $classroom->students->map(function ($student) use ($subjects, $grades) {
            $studentGrades = $grades->get($student->id, collect())->keyBy('subject_id');
            return [
                'student' => $student,
                'grades' => $subjects->map(function ($subject) use ($studentGrades) {
                    return $studentGrades->get($subject->id);
                }),
                'total_score' => $studentGrades->avg('final_score') ?? 0,
            ];
        });

        $data = [
            'classroom' => $classroom,
            'academicYear' => $academicYear,
            'semester' => $semester,
            'subjects' => $subjects,
            'reportData' => $reportData,
            'generated_at' => now()->format('d F Y'),
        ];

        if ($request->has('download')) {
            $pdf = Pdf::loadView('reports.pdf-class', $data)->setPaper('A4', 'landscape');
            return $pdf->download("raport-kelas-{$classroom->level}-{$classroom->name}-{$semester}.pdf");
        }

        return view('reports.class', $data);
    }

    public function studentReport(Student $student, Request $request)
    {
        $academicYear = AcademicYear::getActiveYear();
        $semester = $request->semester ?? AcademicYear::getActiveSemester();

        $grades = Grade::where('student_id', $student->id)
            ->where('academic_year', $academicYear)
            ->where('semester', $semester)
            ->with('subject')
            ->get();

        $classroom = $student->classroom;
        $subjects = Subject::all();

        $data = [
            'student' => $student,
            'classroom' => $classroom,
            'grades' => $grades,
            'subjects' => $subjects,
            'academicYear' => $academicYear,
            'semester' => $semester,
            'generated_at' => now()->format('d F Y'),
            'total_score' => $grades->avg('final_score') ?? 0,
            'total_subjects' => $subjects->count(),
        ];

        if ($request->has('download')) {
            $pdf = Pdf::loadView('reports.pdf-student', $data)->setPaper('A4');
            return $pdf->download("raport-{$student->nis}-{$semester}.pdf");
        }

        return view('reports.student', $data);
    }

    public function generateAll(Request $request)
    {
        $request->validate([
            'class_id' => 'required|exists:classes,id',
            'semester' => 'required|in:ganjil,genap',
        ]);

        $classroom = Classroom::with(['students' => fn($q) => $q->where('status', 'active')])
            ->findOrFail($request->class_id);

        $zip = new \ZipArchive();
        $zipName = storage_path("app/public/reports/raport-{$classroom->level}-{$classroom->name}.zip");

        if (!is_dir(storage_path('app/public/reports'))) {
            mkdir(storage_path('app/public/reports'), 0755, true);
        }

        if ($zip->open($zipName, \ZipArchive::CREATE) !== true) {
            return back()->with('error', 'Gagal membuat file ZIP.');
        }

        $academicYear = AcademicYear::getActiveYear();
        $semester = $request->semester;
        $subjects = Subject::all();

        foreach ($classroom->students as $student) {
            $grades = Grade::where('student_id', $student->id)
                ->where('academic_year', $academicYear)
                ->where('semester', $semester)
                ->get()
                ->keyBy('subject_id');

            $data = [
                'student' => $student,
                'classroom' => $classroom,
                'grades' => $grades,
                'subjects' => $subjects,
                'academicYear' => $academicYear,
                'semester' => $semester,
                'generated_at' => now()->format('d F Y'),
                'total_score' => $grades->avg('final_score') ?? 0,
            ];

            $pdf = Pdf::loadView('reports.pdf-student', $data)->setPaper('A4');
            $zip->addFromString("raport-{$student->nis}-{$student->name}.pdf", $pdf->output());
        }

        $zip->close();

        return response()->download($zipName)->deleteFileAfterSend(true);
    }
}
```

### Routes
```php
// routes/web.php
use App\Http\Controllers\ReportController;

Route::middleware(['auth', 'role:admin|teacher|headmaster'])->group(function () {
    Route::get('/reports', [ReportController::class, 'index'])->name('reports.index');
    Route::get('/reports/class', [ReportController::class, 'classReport'])->name('reports.class');
    Route::get('/reports/student/{student}', [ReportController::class, 'studentReport'])->name('reports.student');
    Route::post('/reports/generate-all', [ReportController::class, 'generateAll'])->name('reports.generate-all');
});
```

## Cara Integrasi & Pengujian
1. Install DomPDF: `composer require barryvdh/laravel-dompdf`
2. Input nilai beberapa siswa
3. Akses `/reports`, pilih kelas
4. Klik "Lihat Raport" untuk preview HTML
5. Klik "Download PDF" untuk download per siswa
6. Klik "Download Semua" untuk ZIP
7. Verifikasi PDF tampil dengan benar (font, layout, data)
8. Uji filter semester ganjil/genap
