# 352. Mengimplementasikan Laporan Absensi Bulanan dalam Excel

## Definisi & Target
Export laporan absensi bulanan per kelas dalam format Excel (.xlsx) menggunakan Laravel Excel. Target: rekap kehadiran siswa per bulan.

## Komponen yang Terlibat
- AttendanceExport
- Laravel Excel (maatwebsite)
- Filter bulan & kelas
- Statistik kehadiran

## Perintah Artisan CLI
```bash
composer require maatwebsite/laravel-excel
php artisan make:export AttendanceExport --model=Attendance
php artisan vendor:publish --provider="Maatwebsite\Excel\ExcelServiceProvider"
```

## Kode Implementasi (Per File)

### Export Class
```php
// app/Exports/AttendanceExport.php
namespace App\Exports;

use App\Models\Attendance;
use App\Models\Student;
use Illuminate\Contracts\View\View;
use Maatwebsite\Excel\Concerns\FromView;
use Maatwebsite\Excel\Concerns\WithTitle;
use Maatwebsite\Excel\Concerns\WithStyles;
use PhpOffice\PhpSpreadsheet\Worksheet\Worksheet;

class AttendanceExport implements FromView, WithTitle, WithStyles
{
    protected $classId;
    protected $month;
    protected $year;

    public function __construct($classId, $month, $year)
    {
        $this->classId = $classId;
        $this->month = $month;
        $this->year = $year;
    }

    public function view(): View
    {
        $classroom = \App\Models\Classroom::findOrFail($this->classId);
        $students = Student::where('class_id', $this->classId)
            ->where('status', 'active')
            ->orderBy('name')
            ->get();

        $daysInMonth = cal_days_in_month(CAL_GREGORIAN, $this->month, $this->year);
        $dates = [];

        for ($day = 1; $day <= $daysInMonth; $day++) {
            $date = "{$this->year}-{$this->month}-" . str_pad($day, 2, '0', STR_PAD_LEFT);
            $dayName = date('N', strtotime($date));
            if ($dayName <= 6) {
                $dates[] = $day;
            }
        }

        $attendances = Attendance::where('class_id', $this->classId)
            ->whereYear('date', $this->year)
            ->whereMonth('date', $this->month)
            ->get()
            ->groupBy(['student_id', 'date']);

        $studentData = $students->map(function ($student) use ($attendances, $dates, $year, $month) {
            $studentAtt = $attendances->get($student->id, collect());

            $stats = [
                'hadir' => 0,
                'sakit' => 0,
                'izin' => 0,
                'alpha' => 0,
            ];

            $dailyStatus = [];
            foreach ($dates as $day) {
                $dateStr = "{$year}-" . str_pad($month, 2, '0', STR_PAD_LEFT) . "-" . str_pad($day, 2, '0', STR_PAD_LEFT);
                $att = $studentAtt->get($dateStr)?->first();
                $status = $att?->status ?? '-';
                $dailyStatus[$day] = $status;
                if (isset($stats[$status])) {
                    $stats[$status]++;
                }
            }

            return [
                'student' => $student,
                'dailyStatus' => $dailyStatus,
                'stats' => $stats,
            ];
        });

        return view('exports.attendance', compact('classroom', 'studentData', 'dates', 'month', 'year'));
    }

    public function title(): string
    {
        return "Absensi Bulan {$this->month}-{$this->year}";
    }

    public function styles(Worksheet $sheet)
    {
        return [
            1 => ['font' => ['bold' => true]],
        ];
    }
}
```

### Controller (tambahan method)
```php
// app/Http/Controllers/AttendanceController.php (tambahan)
use App\Exports\AttendanceExport;
use Maatwebsite\Excel\Facades\Excel;

public function exportExcel(Request $request)
{
    $request->validate([
        'class_id' => 'required|exists:classes,id',
        'month' => 'required|integer|min:1|max:12',
        'year' => 'required|integer|min:2020',
    ]);

    $classroom = Classroom::find($request->class_id);

    return Excel::download(
        new AttendanceExport($request->class_id, $request->month, $request->year),
        "absensi-{$classroom->level}-{$classroom->name}-{$request->month}-{$request->year}.xlsx"
    );
}
```

## Cara Integrasi & Pengujian
1. Install Laravel Excel: `composer require maatwebsite/laravel-excel`
2. Input absensi selama beberapa hari
3. Akses `/attendances/export-excel?class_id=1&month=05&year=2025`
4. Download file Excel
5. Buka file Excel, verifikasi:
   - Header kelas dan bulan
   - Data per siswa per tanggal
   - Total hadir, sakit, izin, alpha
6. Uji dengan bulan berbeda
7. Pastikan tanggal merah/libur tidak termasuk
