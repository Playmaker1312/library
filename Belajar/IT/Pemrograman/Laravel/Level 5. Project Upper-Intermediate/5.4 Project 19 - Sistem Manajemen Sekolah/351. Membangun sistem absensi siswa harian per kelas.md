# 351. Membangun Sistem Absensi Siswa Harian per Kelas

## Definisi & Target
Sistem absensi harian untuk mencatat kehadiran siswa. Guru/wali kelas mengisi absensi per kelas per tanggal dengan status: hadir, sakit, izin, alpha.

## Komponen yang Terlibat
- Attendance model & migration
- AttendanceController
- Livewire AttendanceInput
- Rekap harian per kelas

## Perintah Artisan CLI
```bash
php artisan make:controller AttendanceController
php artisan make:livewire AttendanceInput
```

## Kode Implementasi (Per File)

### Controller
```php
// app/Http/Controllers/AttendanceController.php
namespace App\Http\Controllers;

use App\Models\Attendance;
use App\Models\Classroom;
use App\Models\Student;
use App\Models\Teacher;
use Illuminate\Http\Request;

class AttendanceController extends Controller
{
    public function index(Request $request)
    {
        $classes = Classroom::orderBy('level')->orderBy('name')->get();
        $selectedClass = null;
        $attendances = collect();
        $date = $request->date ?: now()->toDateString();

        if ($request->filled('class_id')) {
            $selectedClass = Classroom::find($request->class_id);
            $students = Student::where('class_id', $request->class_id)
                ->where('status', 'active')
                ->orderBy('name')
                ->get();

            $existing = Attendance::where('class_id', $request->class_id)
                ->where('date', $date)
                ->get()
                ->keyBy('student_id');

            $attendances = $students->map(function ($student) use ($existing) {
                $att = $existing->get($student->id);
                return (object) [
                    'student' => $student,
                    'status' => $att?->status ?? 'hadir',
                    'note' => $att?->note,
                    'attendance_id' => $att?->id,
                ];
            });
        }

        return view('attendances.index', compact('classes', 'selectedClass', 'attendances', 'date'));
    }

    public function store(Request $request)
    {
        $request->validate([
            'class_id' => 'required|exists:classes,id',
            'date' => 'required|date',
            'attendances' => 'required|array',
            'attendances.*.student_id' => 'required|exists:students,id',
            'attendances.*.status' => 'required|in:hadir,sakit,izin,alpha',
            'attendances.*.note' => 'nullable|max:255',
        ]);

        $teacher = Teacher::where('user_id', auth()->id())->first();
        if (!$teacher) {
            return back()->with('error', 'Anda tidak terdaftar sebagai guru.');
        }

        foreach ($request->attendances as $data) {
            Attendance::updateOrCreate(
                [
                    'student_id' => $data['student_id'],
                    'date' => $request->date,
                ],
                [
                    'class_id' => $request->class_id,
                    'status' => $data['status'],
                    'note' => $data['note'] ?? null,
                    'recorded_by' => $teacher->id,
                ]
            );
        }

        return back()->with('success', 'Absensi tanggal ' . $request->date . ' berhasil disimpan.');
    }
}
```

### Routes
```php
// routes/web.php
use App\Http\Controllers\AttendanceController;

Route::middleware(['auth', 'role:admin|teacher'])->group(function () {
    Route::get('/attendances', [AttendanceController::class, 'index'])->name('attendances.index');
    Route::post('/attendances', [AttendanceController::class, 'store'])->name('attendances.store');
});
```

## Cara Integrasi & Pengujian
1. Pilih kelas dan tanggal
2. Radio button per siswa: Hadir (default), Sakit, Izin, Alpha
3. Tambahkan catatan jika perlu
4. Klik "Simpan Absensi"
5. Refresh halaman, status absensi tetap tersimpan
6. Ganti tanggal, absensi kosong (default hadir)
7. Verifikasi data di tabel attendances
