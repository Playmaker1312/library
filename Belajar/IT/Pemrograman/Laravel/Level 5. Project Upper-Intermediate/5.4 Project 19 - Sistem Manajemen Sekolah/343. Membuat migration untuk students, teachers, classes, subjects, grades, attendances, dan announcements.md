### Model AcademicYear
```php
// app/Models/AcademicYear.php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class AcademicYear extends Model
{
    protected $fillable = ['year', 'semester', 'is_active'];

    protected $casts = ['is_active' => 'boolean'];

    public static function getActive()
    {
        return static::where('is_active', true)->first();
    }

    public static function getActiveYear()
    {
        $active = static::getActive();
        return $active ? $active->year : date('Y') . '/' . (date('Y') + 1);
    }

    public static function getActiveSemester()
    {
        $active = static::getActive();
        return $active ? $active->semester : (date('n') <= 6 ? 'genap' : 'ganjil');
    }
}
```

### Grade Calculation Helper
```php
// app/Helpers/GradeHelper.php
namespace App\Helpers;

class GradeHelper
{
    public static function calculateFinal($assignment, $uts, $uas, $weightAssignment = 25, $weightUts = 35, $weightUas = 40)
    {
        return ($assignment * $weightAssignment / 100) +
               ($uts * $weightUts / 100) +
               ($uas * $weightUas / 100);
    }

    public static function getGrade($score)
    {
        return match (true) {
            $score >= 92 => 'A',
            $score >= 83 => 'B+',
            $score >= 75 => 'B',
            $score >= 67 => 'C+',
            $score >= 60 => 'C',
            $score >= 50 => 'D',
            default => 'E',
        };
    }

    public static function getPredicate($grade)
    {
        return match ($grade) {
            'A' => 'Sangat Baik',
            'B+', 'B' => 'Baik',
            'C+', 'C' => 'Cukup',
            'D' => 'Kurang',
            'E' => 'Sangat Kurang',
            default => '-',
        };
    }
}
```

## Cara Integrasi & Pengujian
1. Jalankan `php artisan migrate:fresh --seed`
2. Verifikasi semua tabel terbuat dengan `php artisan db:show`
3. Cek data seeder: subjects, teachers, classes, students
4. Jalankan `php artisan tinker` dan cek model: `Student::count()`
5. Verifikasi foreign key dan unique constraint
6. Uji grade helper: `GradeHelper::calculateFinal(80, 85, 90)`
