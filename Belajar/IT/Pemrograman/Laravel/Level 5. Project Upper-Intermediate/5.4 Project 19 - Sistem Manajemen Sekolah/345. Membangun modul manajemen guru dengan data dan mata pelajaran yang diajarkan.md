# 345. Membangun Modul Manajemen Guru dengan Data dan Mata Pelajaran yang Diajarkan

## Definisi & Target
CRUD manajemen guru dengan data lengkap (NIP, nama, gelar, spesialisasi) dan assignment mata pelajaran. Target: modul admin untuk mengelola guru.

## Komponen yang Terlibat
- TeacherController (resource)
- Teacher model
- Assignment mata pelajaran ke guru
- Hubungan dengan user account

## Perintah Artisan CLI
```bash
php artisan make:controller TeacherController --resource
```

## Kode Implementasi (Per File)

### Controller
```php
// app/Http/Controllers/TeacherController.php
namespace App\Http\Controllers;

use App\Models\Teacher;
use App\Models\Subject;
use App\Models\Classroom;
use App\Models\User;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Hash;
use Illuminate\Support\Facades\Storage;

class TeacherController extends Controller
{
    public function index(Request $request)
    {
        $query = Teacher::withCount('schedules');

        if ($request->filled('search')) {
            $query->where(function ($q) use ($request) {
                $q->where('name', 'like', "%{$request->search}%")
                  ->orWhere('nip', 'like', "%{$request->search}%");
            });
        }

        if ($request->filled('specialization')) {
            $query->where('specialization', $request->specialization);
        }

        $teachers = $query->latest()->paginate(15);

        return view('teachers.index', compact('teachers'));
    }

    public function create()
    {
        $subjects = Subject::all();
        return view('teachers.create', compact('subjects'));
    }

    public function store(Request $request)
    {
        $validated = $request->validate([
            'nip' => 'nullable|unique:teachers,nip|max:30',
            'nuptk' => 'nullable|unique:teachers,nuptk|max:30',
            'name' => 'required|max:255',
            'front_degree' => 'nullable|max:20',
            'back_degree' => 'nullable|max:50',
            'gender' => 'required|in:L,P',
            'phone' => 'nullable|max:20',
            'address' => 'nullable|max:1000',
            'specialization' => 'nullable|max:255',
            'photo' => 'nullable|image|max:2048',
            'subject_ids' => 'nullable|array',
            'subject_ids.*' => 'exists:subjects,id',
            'create_account' => 'boolean',
            'email' => 'required_if:create_account,1|email|unique:users,email',
            'password' => 'required_if:create_account,1|min:8',
        ]);

        if ($request->hasFile('photo')) {
            $validated['photo'] = $request->file('photo')->store('teachers', 'public');
        }

        if ($request->boolean('create_account')) {
            $user = User::create([
                'name' => $validated['name'],
                'email' => $request->email,
                'password' => Hash::make($request->password),
                'role' => 'teacher',
            ]);
            $validated['user_id'] = $user->id;
        }

        $teacher = Teacher::create($validated);

        if ($request->filled('subject_ids')) {
            $teacher->subjects()->sync($request->subject_ids);
        }

        return redirect()->route('teachers.index')
            ->with('success', 'Guru berhasil ditambahkan.');
    }

    public function show(Teacher $teacher)
    {
        $teacher->load(['subjects', 'homeroom', 'schedules' => fn($q) => $q->with('classroom', 'subject')]);
        return view('teachers.show', compact('teacher'));
    }

    public function edit(Teacher $teacher)
    {
        $subjects = Subject::all();
        return view('teachers.edit', compact('teacher', 'subjects'));
    }

    public function update(Request $request, Teacher $teacher)
    {
        $validated = $request->validate([
            'nip' => 'nullable|max:30|unique:teachers,nip,' . $teacher->id,
            'nuptk' => 'nullable|max:30|unique:teachers,nuptk,' . $teacher->id,
            'name' => 'required|max:255',
            'front_degree' => 'nullable|max:20',
            'back_degree' => 'nullable|max:50',
            'gender' => 'required|in:L,P',
            'phone' => 'nullable|max:20',
            'address' => 'nullable|max:1000',
            'specialization' => 'nullable|max:255',
            'photo' => 'nullable|image|max:2048',
            'subject_ids' => 'nullable|array',
            'subject_ids.*' => 'exists:subjects,id',
        ]);

        if ($request->hasFile('photo')) {
            if ($teacher->photo) Storage::disk('public')->delete($teacher->photo);
            $validated['photo'] = $request->file('photo')->store('teachers', 'public');
        }

        $teacher->update($validated);

        if ($request->has('subject_ids')) {
            $teacher->subjects()->sync($request->subject_ids);
        }

        return redirect()->route('teachers.index')
            ->with('success', 'Data guru diperbarui.');
    }

    public function destroy(Teacher $teacher)
    {
        if ($teacher->photo) Storage::disk('public')->delete($teacher->photo);
        $teacher->delete();

        return redirect()->route('teachers.index')
            ->with('success', 'Guru berhasil dihapus.');
    }
}
```

### Model (tambahan relasi)
```php
// app/Models/Teacher.php (tambahan)
public function subjects()
{
    return $this->belongsToMany(Subject::class, 'class_subjects', 'teacher_id', 'subject_id')
        ->withPivot('class_id');
}

public function classes()
{
    return $this->belongsToMany(Classroom::class, 'class_subjects', 'teacher_id', 'class_id')
        ->withPivot('subject_id');
}
```

### Routes
```php

    Route::resource('teachers', TeacherController::class);
});
```

## Cara Integrasi & Pengujian
1. Akses `/teachers`, lihat daftar guru
2. Tambah guru baru dengan data lengkap dan foto
3. Centang mata pelajaran yang diajarkan
4. Opsional: buat akun login untuk guru
5. Edit data guru, ubah spesialisasi
6. Lihat detail guru (jadwal mengajar, wali kelas)
7. Hapus guru dengan konfirmasi
