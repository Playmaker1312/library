# 355. Membangun Dashboard Kepala Sekolah dengan Statistik Akademik

## Definisi & Target
Dashboard untuk kepala sekolah melihat statistik akademik: jumlah siswa per kelas, rata-rata nilai, absensi, grafik tren, dan laporan ringkas.

## Komponen yang Terlibat
- HeadmasterDashboardController
- DashboardService (sekolah)
- Chart.js untuk visualisasi
- Statistik agregat

## Perintah Artisan CLI
```bash
php artisan make:controller HeadmasterDashboardController
```

## Kode Implementasi (Per File)

### Service
```php
// app/Services/SchoolDashboardService.php
namespace App\Services;

use App\Models\Student;
use App\Models\Classroom;
use App\Models\Grade;
use App\Models\Attendance;
use App\Models\Teacher;
use App\Models\Subject;
use App\Models\AcademicYear;
use Illuminate\Support\Facades\DB;

class SchoolDashboardService
{
    public function getOverview()
    {
        $academicYear = AcademicYear::getActiveYear();
        $semester = AcademicYear::getActiveSemester();

        return [
            'total_students' => Student::where('status', 'active')->count(),
            'total_teachers' => Teacher::count(),
            'total_classes' => Classroom::where('academic_year', $academicYear)->count(),
            'total_subjects' => Subject::count(),
            'total_alumni' => Student::where('status', 'alumni')->count(),
        ];
    }

    public function getStudentsPerClass()
    {
        return Classroom::withCount(['students' => fn($q) => $q->where('status', 'active')])
            ->orderBy('level')
            ->orderBy('name')
            ->get()
            ->map(fn($c) => ['label' => "Kelas {$c->level} {$c->name}", 'count' => $c->students_count]);
    }

    public function getAverageScores()
    {
        $academicYear = AcademicYear::getActiveYear();
        $semester = AcademicYear::getActiveSemester();

        return Subject::withAvg(['grades as avg_score' => function ($q) use ($academicYear, $semester) {
            $q->where('academic_year', $academicYear)
              ->where('semester', $semester)
              ->whereNotNull('final_score');
        }], 'final_score')
            ->get()
            ->map(fn($s) => ['subject' => $s->name, 'avg' => round($s->avg_score ?? 0, 1)]);
    }

    public function getAttendanceStats($month = null, $year = null)
    {
        $month = $month ?? date('m');
        $year = $year ?? date('Y');

        $stats = Attendance::select('status', DB::raw('COUNT(*) as total'))
            ->whereYear('date', $year)
            ->whereMonth('date', $month)
            ->groupBy('status')
            ->pluck('total', 'status');

        $total = $stats->sum();
        return [
            'hadir' => $stats->get('hadir', 0),
            'sakit' => $stats->get('sakit', 0),
            'izin' => $stats->get('izin', 0),
            'alpha' => $stats->get('alpha', 0),
            'total' => $total,
            'percentage' => $total > 0 ? round(($stats->get('hadir', 0) / $total) * 100, 1) : 0,
        ];
    }

    public function getGradeDistribution()
    {
        $academicYear = AcademicYear::getActiveYear();
        $semester = AcademicYear::getActiveSemester();

        return Grade::select('grade', DB::raw('COUNT(DISTINCT student_id) as total'))
            ->where('academic_year', $academicYear)
            ->where('semester', $semester)
            ->whereNotNull('grade')
            ->groupBy('grade')
            ->orderBy('grade')
            ->pluck('total', 'grade');
    }

    public function getMonthlyAttendanceTrend($months = 6)
    {
        $result = [];
        for ($i = $months - 1; $i >= 0; $i--) {
            $date = now()->subMonths($i);
            $stats = $this->getAttendanceStats($date->month, $date->year);
            $result[] = [
                'month' => $date->format('M Y'),
                'percentage' => $stats['percentage'],
            ];
        }
        return $result;
    }
}
```

### Controller
```php
// app/Http/Controllers/HeadmasterDashboardController.php
namespace App\Http\Controllers;

use App\Services\SchoolDashboardService;
use Illuminate\Http\Request;

class HeadmasterDashboardController extends Controller
{
    protected SchoolDashboardService $service;

    public function __construct(SchoolDashboardService $service)
    {
        $this->service = $service;
    }

    public function index()
    {
        $overview = $this->service->getOverview();
        $studentsPerClass = $this->service->getStudentsPerClass();
        $averageScores = $this->service->getAverageScores();
        $attendanceStats = $this->service->getAttendanceStats();
        $gradeDistribution = $this->service->getGradeDistribution();
        $attendanceTrend = $this->service->getMonthlyAttendanceTrend();

        return view('headmaster.dashboard', compact(
            'overview', 'studentsPerClass', 'averageScores',
            'attendanceStats', 'gradeDistribution', 'attendanceTrend'
        ));
    }
}
```

## Cara Integrasi & Pengujian
1. Buat user dengan role 'headmaster'
2. Pastikan ada data siswa, guru, kelas, nilai, absensi
3. Login sebagai kepala sekolah
4. Akses `/headmaster/dashboard`
5. Verifikasi statistik overview
6. Cek grafik siswa per kelas
7. Cek grafik rata-rata nilai per mapel
8. Cek data absensi dan tren kehadiran
9. Pastikan data kosong tidak menyebabkan error
