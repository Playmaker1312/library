# 335. Mengimplementasikan Sistem Escrow yaitu Dana Ditahan Sampai Order Selesai

## Definisi & Target
Dana dari klien ditahan dalam sistem escrow sampai order selesai. Jika order completed, dana dilepas ke freelancer. Jika dibatalkan, dana dikembalikan.

## Komponen yang Terlibat
- EscrowService (freelance version)
- Payment model
- Order status trigger
- Refund handling

## Perintah Artisan CLI
```php artisan make:service FreelanceEscrowService```

## Kode Implementasi (Per File)

### Service
```php
// app/Services/FreelanceEscrowService.php
namespace App\Services;

use App\Models\Order;
use App\Models\Payment;
use Illuminate\Support\Facades\DB;

class FreelanceEscrowService
{
    public function holdPayment(Order $order)
    {
        return DB::transaction(function () use ($order) {
            $payment = Payment::create([
                'payable_type' => Order::class,
                'payable_id' => $order->id,
                'user_id' => $order->client_id,
                'amount' => $order->amount,
                'status' => 'escrow',
                'expired_at' => now()->addDays(30),
            ]);

            return $payment;
        });
    }

    public function releaseToFreelancer(Order $order)
    {
        return DB::transaction(function () use ($order) {
            $payment = $order->payment;

            if (!$payment || $payment->status !== 'escrow') {
                throw new \Exception('Dana escrow tidak ditemukan atau sudah diproses.');
            }

            $payment->update([
                'status' => 'released',
                'paid_at' => now(),
            ]);

            return $payment;
        });
    }

    public function refundToClient(Order $order)
    {
        return DB::transaction(function () use ($order) {
            $payment = $order->payment;

            if (!$payment || $payment->status !== 'escrow') {
                throw new \Exception('Dana escrow tidak ditemukan atau sudah diproses.');
            }

            $payment->update([
                'status' => 'refunded',
            ]);

            return $payment;
        });
    }

    public function getEscrowBalance(Order $order)
    {
        $payment = $order->payment;
        return $payment && $payment->status === 'escrow' ? $payment->amount : 0;
    }
}
```

### Event/Listener untuk Escrow
```php
// app/Listeners/HandleEscrowOnOrderEvent.php
namespace App\Listeners;

use App\Services\FreelanceEscrowService;
use Illuminate\Support\Facades\Log;

class HandleEscrowOnOrderEvent
{
    protected $escrowService;

    public function __construct(FreelanceEscrowService $escrowService)
    {
        $this->escrowService = $escrowService;
    }

    public function handle($event)
    {
        $order = $event->order;

        try {
            if ($event instanceof \App\Events\OrderCompleted) {
                $this->escrowService->releaseToFreelancer($order);
            } elseif ($event instanceof \App\Events\OrderCancelled) {
                $this->escrowService->refundToClient($order);
            }
        } catch (\Exception $e) {
            Log::error("Escrow handling failed for order {$order->id}: {$e->getMessage()}");
        }
    }
}
```

```php
// app/Http/Controllers/OrderController.php (modifikasi complete & cancel)
use App\Events\OrderCancelled;
use App\Events\OrderCompleted;

public function complete(Order $order)
{
    // ... authorization ...

    $order->transitionTo(OrderStatus::Completed);
    event(new OrderCompleted($order));

    return redirect()->route('orders.show', $order)->with('success', 'Pesanan selesai!');
}

public function cancel(Order $order)
{
    // ... authorization ...

    $order->transitionTo(OrderStatus::Cancelled);
    event(new OrderCancelled($order));

    return back()->with('success', 'Pesanan dibatalkan.');
}
```

## Cara Integrasi & Pengujian
1. Klien membuat order dan membayar
2. Dana masuk escrow (status: escrow)
3. Freelancer mengerjakan dan deliver
4. Klien accept, order completed
5. Escrow otomatis release ke freelancer
6. Jika order dibatalkan (sebelum delivered), escrow refund ke klien
7. Verifikasi balance escrow di halaman detail order
8. Uji kasus: cancel setelah escrow sudah release (harus error)
