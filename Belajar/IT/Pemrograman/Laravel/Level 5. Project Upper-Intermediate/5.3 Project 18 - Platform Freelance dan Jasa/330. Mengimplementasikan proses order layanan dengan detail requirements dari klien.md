# 330. Mengimplementasikan Proses Order Layanan dengan Detail Requirements dari Klien

## Definisi & Target
Membangun proses pemesanan layanan dimana klien memilih paket, mengisi requirements, dan melakukan pembayaran escrow. Target: order flow yang mulus.

## Komponen yang Terlibat
- OrderController
- Order model & migration (sudah di poin 327)
- Order form dengan requirements
- Payment integrasi
- Notifikasi order

## Kode Implementasi (Per File)

### Controller
```php
// app/Http/Controllers/OrderController.php
namespace App\Http\Controllers;

use App\Models\Order;
use App\Models\Service;
use App\Models\ServicePackage;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\DB;

class OrderController extends Controller
{
    public function store(Request $request)
    {
        $request->validate([
            'service_id' => 'required|exists:services,id',
            'package_id' => 'required|exists:service_packages,id',
            'requirements' => 'required|max:10000',
        ]);

        $service = Service::findOrFail($request->service_id);
        $package = ServicePackage::findOrFail($request->package_id);

        if ($service->user_id === auth()->id()) {
            return back()->with('error', 'Anda tidak bisa memesan layanan sendiri.');
        }

        $order = Order::create([
            'service_id' => $service->id,
            'service_package_id' => $package->id,
            'client_id' => auth()->id(),
            'freelancer_id' => $service->user_id,
            'status' => 'pending',
            'amount' => $package->price,
            'requirements' => $request->requirements,
            'revisions_left' => $package->revisions,
        ]);

        return redirect()->route('orders.show', $order)
            ->with('success', 'Pesanan berhasil dibuat. Silakan lanjutkan pembayaran.');
    }

    public function show(Order $order)
    {
        $this->authorize('view', $order);
        $order->load(['service.packages', 'package', 'client', 'freelancer.freelancerProfile', 'files']);
        return view('orders.show', compact('order'));
    }

    public function myOrders()
    {
        $orders = Order::where('client_id', auth()->id())
            ->orWhere('freelancer_id', auth()->id())
            ->with(['service', 'package', 'client', 'freelancer'])
            ->latest()
            ->paginate(10);

        return view('orders.my-orders', compact('orders'));
    }
}
```

### Form Request
```php
// app/Http/Requests/StoreOrderRequest.php
namespace App\Http\Requests;

use App\Models\Service;
use App\Models\ServicePackage;
use Illuminate\Foundation\Http\FormRequest;

class StoreOrderRequest extends FormRequest
{
    public function authorize(): bool
    {
        return auth()->check();
    }

    public function rules(): array
    {
        return [
            'service_id' => 'required|exists:services,id',
            'package_id' => 'required|exists:service_packages,id',
            'requirements' => 'required|string|min:20|max:10000',
        ];
    }

    public function withValidator($validator)
    {
        $validator->after(function ($validator) {
            $service = Service::find($this->service_id);
            $package = ServicePackage::find($this->package_id);

            if (!$service || !$package) return;

            if ($package->service_id !== $service->id) {
                $validator->errors()->add('package_id', 'Paket tidak cocok dengan layanan.');
            }

            if ($service->user_id === $this->user()->id) {
                $validator->errors()->add('service_id', 'Tidak bisa memesan layanan sendiri.');
            }
        });
    }

    public function messages(): array
    {
        return [
            'requirements.min' => 'Minimal 20 karakter untuk deskripsi requirements.',
            'requirements.required' => 'Deskripsi requirements harus diisi.',
        ];
    }
}
```

## Cara Integrasi & Pengujian
1. Login sebagai client, buka halaman layanan freelancer
2. Klik "Pesan" pada paket tertentu
3. Isi requirements dengan detail, submit
4. Verifikasi order terbuat dengan status 'pending'
5. Cek halaman detail order menampilkan semua informasi
6. Uji validasi: requirements kosong, < 20 karakter
7. Pastikan tidak bisa memesan layanan sendiri
