# 336. Mengimplementasikan Pelepasan Dana ke Freelancer Setelah Order Diterima

## Definisi & Target
Dana escrow otomatis dilepas ke freelancer ketika klien menerima hasil pekerjaan (completed). Target: transparansi dan keamanan transaksi.

## Komponen yang Terlibat
- FreelanceEscrowService (releaseToFreelancer)
- OrderCompleted event
- Payment model status update
- Withdrawal / saldo freelancer
- Notifikasi pencairan dana

## Perintah Artisan CLI
```bash
php artisan make:model Withdrawal -m
php artisan make:notification PaymentReleasedNotification
```

### Notification
```php
// app/Notifications/PaymentReleasedNotification.php
namespace App\Notifications;

use App\Models\Payment;
use Illuminate\Bus\Queueable;
use Illuminate\Notifications\Notification;

class PaymentReleasedNotification extends Notification
{
    use Queueable;

    public $payment;
    public $order;

    public function __construct(Payment $payment)
    {
        $this->payment = $payment;
        $this->order = $payment->payable;
    }

    public function via($notifiable)
    {
        return ['database', 'mail'];
    }

    public function toArray($notifiable)
    {
        return [
            'type' => 'payment_released',
            'order_id' => $this->order->id,
            'service_title' => $this->order->service->title,
            'amount' => $this->payment->amount,
            'message' => "Dana Rp " . number_format($this->payment->amount) .
                " untuk {$this->order->service->title} telah dilepas ke saldo Anda.",
        ];
    }

    public function toMail($notifiable)
    {
        return (new \Illuminate\Notifications\Messages\MailMessage)
            ->subject('Dana Telah Dirilis')
            ->greeting("Halo {$notifiable->name}!")
            ->line("Dana sebesar Rp " . number_format($this->payment->amount) .
                " untuk {$this->order->service->title} telah dilepas ke saldo Anda.")
            ->action('Lihat Saldo', route('freelancer.withdrawals'));
    }
}
```

### Service (update)
```php
// app/Services/FreelanceEscrowService.php (tambahan)
use App\Notifications\PaymentReleasedNotification;

public function releaseToFreelancer(Order $order)
{
    return DB::transaction(function () use ($order) {
        $payment = $order->payment;

        if (!$payment || $payment->status !== 'escrow') {
            throw new \Exception('Dana escrow tidak ditemukan atau sudah diproses.');
        }

        $payment->update([
            'status' => 'released',
            'paid_at' => now(),
        ]);

        $order->freelancer->increment('balance', $payment->amount);

        $order->freelancer->notify(new PaymentReleasedNotification($payment));

        return $payment;
    });
}

public function refundToClient(Order $order)
{
    return DB::transaction(function () use ($order) {
        $payment = $order->payment;

        if (!$payment || $payment->status !== 'escrow') {
            throw new \Exception('Dana escrow tidak ditemukan atau sudah diproses.');
        }

        $payment->update(['status' => 'refunded']);

        $order->client->increment('balance', $payment->amount);

        return $payment;
    });
}
```

### Withdrawal Controller
```php
// app/Http/Controllers/WithdrawalController.php
namespace App\Http\Controllers;

use App\Models\Withdrawal;
use Illuminate\Http\Request;

class WithdrawalController extends Controller
{
    public function index()
    {
        $withdrawals = Withdrawal::where('user_id', auth()->id())
            ->latest()
            ->paginate(10);

        $balance = auth()->user()->balance;

        return view('freelancer.withdrawals', compact('withdrawals', 'balance'));
    }

    public function store(Request $request)
    {
        $request->validate([
            'amount' => 'required|numeric|min:50000|max:' . auth()->user()->balance,
            'bank_name' => 'required|max:100',
            'account_number' => 'required|max:50',
            'account_name' => 'required|max:200',
        ]);

        Withdrawal::create([
            'user_id' => auth()->id(),
            'amount' => $request->amount,
            'bank_name' => $request->bank_name,
            'account_number' => $request->account_number,
            'account_name' => $request->account_name,
        ]);

        auth()->user()->decrement('balance', $request->amount);

        return back()->with('success', 'Permintaan penarikan dana diajukan.');
    }
}
```

## Cara Integrasi & Pengujian
1. Buat order, bayar (escrow created)
2. Selesaikan order (klien accept)
3. Dana otomatis bertambah di balance freelancer
4. Freelancer cek saldo di halaman withdrawal
5. Ajukan penarikan dana
6. Cek database: withdrawal status pending, balance berkurang
7. Admin proses withdrawal (status jadi processed)
8. Pastikan notifikasi terkirim ke freelancer saat dana dilepas
