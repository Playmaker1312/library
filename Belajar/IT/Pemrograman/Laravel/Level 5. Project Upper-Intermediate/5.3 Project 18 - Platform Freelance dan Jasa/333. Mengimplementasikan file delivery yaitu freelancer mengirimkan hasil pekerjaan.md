# 333. Mengimplementasikan File Delivery yaitu Freelancer Mengirimkan Hasil Pekerjaan

## Definisi & Target
Freelancer dapat mengirimkan file hasil pekerjaan melalui form upload. File tersimpan di storage dan klien bisa mendownload.

## Komponen yang Terlibat
- OrderFile model (sudah di poin 327)
- File upload via Livewire
- File delivery controller
- Download tracking
- Validasi tipe dan ukuran file

## Perintah Artisan CLI
```php artisan make:livewire FileDeliveryManager```

## Kode Implementasi (Per File)

### Livewire Component
```php
// app/Livewire/FileDeliveryManager.php
namespace App\Livewire;

use App\Models\Order;
use Livewire\Component;
use Livewire\WithFileUploads;

class FileDeliveryManager extends Component
{
    use WithFileUploads;

    public Order $order;
    public $files = [];
    public $note = '';

    protected function rules()
    {
        return [
            'files' => 'required|array|min:1|max:10',
            'files.*' => 'file|max:25600',
            'note' => 'nullable|string|max:5000',
        ];
    }

    public function mount(Order $order)
    {
        $this->order = $order;
    }

    public function upload()
    {
        $this->validate();

        if ($this->order->freelancer_id !== auth()->id()) {
            session()->flash('error', 'Hanya freelancer yang bisa mengirim file.');
            return;
        }

        foreach ($this->files as $file) {
            $path = $file->store('orders/' . $this->order->id . '/delivery', 'public');
            $this->order->files()->create([
                'user_id' => auth()->id(),
                'file_path' => $path,
                'original_name' => $file->getClientOriginalName(),
                'type' => 'delivery',
            ]);
        }

        $this->order->update([
            'status' => 'delivered',
            'delivered_at' => now(),
        ]);

        $this->reset(['files', 'note']);
        $this->dispatch('files-delivered');
        session()->flash('success', 'File berhasil dikirim ke klien.');
    }

    public function removeFile($index)
    {
        unset($this->files[$index]);
        $this->files = array_values($this->files);
    }

    public function render()
    {
        return view('livewire.file-delivery-manager');
    }
}
```

### Controller (download)
```php
// app/Http/Controllers/FileController.php
namespace App\Http\Controllers;

use App\Models\OrderFile;
use Illuminate\Support\Facades\Storage;

class FileController extends Controller
{
    public function download(OrderFile $file)
    {
        $order = $file->order;

        if (auth()->id() !== $order->client_id && auth()->id() !== $order->freelancer_id) {
            abort(403);
        }

        if (!Storage::disk('public')->exists($file->file_path)) {
            abort(404);
        }

        return Storage::disk('public')->download($file->file_path, $file->original_name);
    }

    public function preview(OrderFile $file)
    {
        $order = $file->order;

        if (auth()->id() !== $order->client_id && auth()->id() !== $order->freelancer_id) {
            abort(403);
        }

        if (!Storage::disk('public')->exists($file->file_path)) {
            abort(404);
        }

        $extension = pathinfo($file->original_name, PATHINFO_EXTENSION);
        $imageExtensions = ['jpg', 'jpeg', 'png', 'gif', 'webp'];

        if (in_array(strtolower($extension), $imageExtensions)) {
            return response()->file(storage_path('app/public/' . $file->file_path));
        }

        return redirect()->route('files.download', $file);
    }
}
```

### Routes
```php
// routes/web.php
use App\Http\Controllers\FileController;

Route::middleware('auth')->group(function () {
    Route::get('/files/{file}/download', [FileController::class, 'download'])->name('files.download');
    Route::get('/files/{file}/preview', [FileController::class, 'preview'])->name('files.preview');
});
```

## Cara Integrasi & Pengujian
1. Login sebagai freelancer dengan order status in_progress
2. Lihat form upload file delivery
3. Upload file (drag & drop atau klik)
4. File muncul di daftar sementara, bisa dihapus
5. Klik "Kirim ke Klien", status berubah jadi delivered
6. Login sebagai klien, lihat file bisa didownload
7. Preview file gambar langsung di browser
8. Uji validasi: file terlalu besar, format tidak sesuai
