# 331. Mengimplementasikan Order Management dengan Status Flow yang Jelas

## Definisi & Target
Membangun alur status order: pending → active → in_progress → delivered → completed / cancelled. Setiap transisi status memiliki validasi dan notifikasi.

## Komponen yang Terlibat
- Order status management
- OrderController (accept, start, deliver, complete, cancel)
- Status enum / constants
- Policy untuk otorisasi
- Notifikasi per transisi status

## Perintah Artisan CLI
```bash
php artisan make:policy OrderPolicy
```

## Kode Implementasi (Per File)

### Order Status Constants
```php
// app/Enums/OrderStatus.php
namespace App\Enums;

enum OrderStatus: string
{
    case Pending = 'pending';
    case Active = 'active';
    case InProgress = 'in_progress';
    case Revision = 'revision';
    case Delivered = 'delivered';
    case Completed = 'completed';
    case Cancelled = 'cancelled';

    public function label(): string
    {
        return match ($this) {
            self::Pending => 'Menunggu Konfirmasi',
            self::Active => 'Dikonfirmasi',
            self::InProgress => 'Dalam Pengerjaan',
            self::Revision => 'Revisi',
            self::Delivered => 'Terkirim',
            self::Completed => 'Selesai',
            self::Cancelled => 'Dibatalkan',
        };
    }

    public function color(): string
    {
        return match ($this) {
            self::Pending => 'yellow',
            self::Active => 'blue',
            self::InProgress => 'indigo',
            self::Revision => 'orange',
            self::Delivered => 'purple',
            self::Completed => 'green',
            self::Cancelled => 'red',
        };
    }

    public static function canTransition(OrderStatus $from, OrderStatus $to): bool
    {
        $transitions = [
            self::Pending->value => [self::Active, self::Cancelled],
            self::Active->value => [self::InProgress, self::Cancelled],
            self::InProgress->value => [self::Delivered],
            self::Delivered->value => [self::Completed, self::Revision],
            self::Revision->value => [self::Delivered],
        ];

        return in_array($to->value, $transitions[$from->value] ?? []);
    }
}
```

### Order Model (tambahan method)
```php
// app/Models/Order.php (tambahan)
use App\Enums\OrderStatus;

public function transitionTo(OrderStatus $newStatus)
{
    $currentStatus = OrderStatus::from($this->status);

    if (!OrderStatus::canTransition($currentStatus, $newStatus)) {
        throw new \Exception("Transisi dari {$this->status} ke {$newStatus->value} tidak valid.");
    }

    $this->status = $newStatus->value;

    if ($newStatus === OrderStatus::Active) {
        $this->deadline = now()->addDays($this->package->delivery_days);
    }

    if ($newStatus === OrderStatus::Delivered) {
        $this->delivered_at = now();
    }

    if ($newStatus === OrderStatus::Completed) {
        $this->completed_at = now();
    }

    $this->save();
}
```

### Order Policy
```php
// app/Policies/OrderPolicy.php
namespace App\Policies;

use App\Models\Order;
use App\Models\User;

class OrderPolicy
{
    public function view(User $user, Order $order): bool
    {
        return $user->id === $order->client_id || $user->id === $order->freelancer_id;
    }

    public function accept(User $user, Order $order): bool
    {
        return $user->id === $order->freelancer_id && $order->status === 'pending';
    }

    public function start(User $user, Order $order): bool
    {
        return $user->id === $order->freelancer_id && $order->status === 'active';
    }

    public function deliver(User $user, Order $order): bool
    {
        return $user->id === $order->freelancer_id && in_array($order->status, ['in_progress', 'revision']);
    }

    public function complete(User $user, Order $order): bool
    {
        return $user->id === $order->client_id && $order->status === 'delivered';
    }

    public function cancel(User $user, Order $order): bool
    {
        return in_array($user->id, [$order->client_id, $order->freelancer_id])
            && in_array($order->status, ['pending', 'active']);
    }
}
```

### Controller
```php
// app/Http/Controllers/OrderController.php (tambahan)
use App\Enums\OrderStatus;

public function accept(Order $order)
{
    $this->authorize('accept', $order);
    $order->transitionTo(OrderStatus::Active);
    return back()->with('success', 'Pesanan diterima. Deadline telah ditetapkan.');
}

public function start(Order $order)
{
    $this->authorize('start', $order);
    $order->transitionTo(OrderStatus::InProgress);
    return back()->with('success', 'Pengerjaan dimulai.');
}

public function cancel(Order $order)
{
    $this->authorize('cancel', $order);
    $order->transitionTo(OrderStatus::Cancelled);
    return back()->with('success', 'Pesanan dibatalkan.');
}
```

## Cara Integrasi & Pengujian
1. Client membuat order (status: pending)
2. Freelancer klik "Terima Pesanan" (status: active, deadline terisi)
3. Freelancer klik "Mulai Kerjakan" (status: in_progress)
4. Freelancer deliver file (status: delivered)
5. Client klik "Selesai" (status: completed)
6. Uji cancel dari status pending dan active
7. Pastikan transisi invalid ditolak (ex: pending → delivered langsung)
8. Register policy di AuthServiceProvider
