# 328. Membangun Halaman Profil Freelancer yang Komprehensif dengan Portofolio

## Definisi & Target
Membangun halaman profil freelancer yang menampilkan bio, skills, portofolio, rating, layanan, dan statistik. Target: profil yang meyakinkan klien.

## Komponen yang Terlibat
- FreelancerProfileController
- Portofolio upload (gambar)
- Skill management
- Rating & review display
- Service listing di profil

## Perintah Artisan CLI
```bash
php artisan make:controller FreelancerProfileController
php artisan make:livewire PortfolioUploader
```

### Controller
```php
// app/Http/Controllers/FreelancerProfileController.php
namespace App\Http\Controllers;

use App\Models\FreelancerProfile;
use App\Models\Portfolio;
use App\Models\Service;
use App\Models\User;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Storage;

class FreelancerProfileController extends Controller
{
    public function show($username)
    {
        $user = User::where('username', $username)
            ->with(['freelancerProfile', 'services.packages', 'portfolios' => fn($q) => $q->orderBy('sort_order')])
            ->firstOrFail();

        $reviews = \DB::table('freelance_reviews')
            ->where('to_user_id', $user->id)
            ->where('type', 'client_to_freelancer')
            ->get();

        $avgRating = $reviews->avg('rating') ?? 0;
        $totalReviews = $reviews->count();

        return view('freelancer.show', compact('user', 'avgRating', 'totalReviews'));
    }

    public function edit()
    {
        $profile = auth()->user()->freelancerProfile ?? new FreelancerProfile();
        return view('freelancer.edit-profile', compact('profile'));
    }

    public function update(Request $request)
    {
        $request->validate([
            'headline' => 'required|max:200',
            'bio' => 'required|max:5000',
            'hourly_rate' => 'required|numeric|min:0',
            'skills' => 'required|array|min:1',
            'skills.*' => 'string|max:50',
            'experience_level' => 'required|in:beginner,intermediate,advanced,expert',
            'response_time' => 'required|integer|min:1|max:48',
            'avatar' => 'nullable|image|max:2048',
        ]);

        $data = $request->except('avatar');

        if ($request->hasFile('avatar')) {
            $data['avatar'] = $request->file('avatar')->store('avatars', 'public');
        }

        auth()->user()->freelancerProfile()->updateOrCreate(
            ['user_id' => auth()->id()],
            $data
        );

        return redirect()->route('freelancer.edit')
            ->with('success', 'Profil berhasil diperbarui.');
    }
}
```

### Routes
```php
// routes/web.php
use App\Http\Controllers\FreelancerProfileController;

Route::get('/freelancer/{username}', [FreelancerProfileController::class, 'show'])->name('freelancer.show');

    Route::get('/profile/edit', [FreelancerProfileController::class, 'edit'])->name('freelancer.edit');
    Route::put('/profile', [FreelancerProfileController::class, 'update'])->name('freelancer.update');
});
```

```blade
            tag.className = 'skill-tag px-3 py-1 bg-blue-100 text-blue-700 rounded-full text-sm flex items-center gap-1';
```
