# 339. Membangun Fitur Pencarian Freelancer dengan Filter Skill, Harga, dan Rating

## Definisi & Target
Halaman pencarian freelancer dengan filter berdasarkan skill, rentang harga, rating, dan kategori layanan. Target: memudahkan klien menemukan freelancer yang tepat.

## Komponen yang Terlibat
- FreelancerSearchController
- Livewire search component
- Filter: skills, price range, rating, category
- Pagination dengan filter

## Perintah Artisan CLI
```bash
php artisan make:controller FreelancerSearchController
php artisan make:livewire FreelancerSearch
```

## Kode Implementasi (Per File)

### Controller
```php
// app/Http/Controllers/FreelancerSearchController.php
namespace App\Http\Controllers;

use App\Models\FreelancerProfile;
use App\Models\Service;
use App\Models\Category;
use App\Models\User;
use Illuminate\Http\Request;

class FreelancerSearchController extends Controller
{
    public function index(Request $request)
    {
        $categories = Category::all();
        $skills = ['PHP', 'Laravel', 'JavaScript', 'Vue.js', 'React', 'Python', 'UI/UX', 'CSS', 'HTML', 'Node.js'];

        $query = FreelancerProfile::with('user')
            ->whereHas('user', fn($q) => $q->where('role', 'freelancer'));

        if ($request->filled('search')) {
            $search = $request->search;
            $query->where(function ($q) use ($search) {
                $q->where('headline', 'like', "%{$search}%")
                  ->orWhere('bio', 'like', "%{$search}%")
                  ->orWhereJsonContains('skills', $search);
            });
        }

        if ($request->filled('skill')) {
            $query->whereJsonContains('skills', $request->skill);
        }

        if ($request->filled('min_rate')) {
            $query->where('hourly_rate', '>=', $request->min_rate);
        }

        if ($request->filled('max_rate')) {
            $query->where('hourly_rate', '<=', $request->max_rate);
        }

        if ($request->filled('experience')) {
            $query->where('experience_level', $request->experience);
        }

        $profiles = $query->paginate(12)->withQueryString();

        return view('freelancer-search.index', compact('profiles', 'categories', 'skills'));
    }

    public function searchServices(Request $request)
    {
        $query = Service::active()->with(['user.freelancerProfile', 'packages']);

        if ($request->filled('q')) {
            $q = $request->q;
            $query->where(function ($query) use ($q) {
                $query->where('title', 'like', "%{$q}%")
                      ->orWhere('description', 'like', "%{$q}%");
            });
        }

        if ($request->filled('category')) {
            $query->where('category_id', $request->category);
        }

        if ($request->filled('min_price')) {
            $query->whereHas('packages', fn($q) => $q->where('price', '>=', $request->min_price));
        }

        if ($request->filled('max_price')) {
            $query->whereHas('packages', fn($q) => $q->where('price', '<=', $request->max_price));
        }

        if ($request->filled('min_rating')) {
            $query->whereHas('user', function ($q) use ($request) {
                $q->whereHas('freelanceReviewsReceived', function ($rq) use ($request) {
                    $rq->selectRaw('AVG(rating) as avg_rating')
                      ->having('avg_rating', '>=', $request->min_rating);
                });
            });
        }

        $services = $query->paginate(12)->withQueryString();
        $categories = Category::has('services')->get();

        if ($request->ajax()) {
            return view('freelancer-search.services-list', compact('services'))->render();
        }

        return view('freelancer-search.services', compact('services', 'categories'));
    }
}
```

### Livewire Component
```php
// app/Livewire/FreelancerSearch.php
namespace App\Livewire;

use App\Models\Category;
use App\Models\FreelancerProfile;
use Livewire\Component;
use Livewire\WithPagination;

class FreelancerSearch extends Component
{
    use WithPagination;

    public $search = '';
    public $skill = '';
    public $minRate = '';
    public $maxRate = '';
    public $experience = '';
    public $sortBy = 'latest';

    protected $queryString = ['search', 'skill', 'minRate', 'maxRate', 'experience', 'sortBy'];

    public function resetFilters()
    {
        $this->reset(['search', 'skill', 'minRate', 'maxRate', 'experience', 'sortBy']);
    }

    public function render()
    {
        $query = FreelancerProfile::with('user')
            ->whereHas('user', fn($q) => $q->where('role', 'freelancer'));

        if ($this->search) {
            $query->where(function ($q) {
                $q->where('headline', 'like', "%{$this->search}%")
                  ->orWhere('bio', 'like', "%{$this->search}%")
                  ->orWhereJsonContains('skills', $this->search);
            });
        }

        if ($this->skill) {
            $query->whereJsonContains('skills', $this->skill);
        }

        if ($this->minRate) {
            $query->where('hourly_rate', '>=', $this->minRate);
        }

        if ($this->maxRate) {
            $query->where('hourly_rate', '<=', $this->maxRate);
        }

        if ($this->experience) {
            $query->where('experience_level', $this->experience);
        }

        $query->orderBy($this->sortBy === 'rate_asc' ? 'hourly_rate' : 'created_at',
            $this->sortBy === 'rate_asc' ? 'asc' : 'desc');

        $profiles = $query->paginate(12);
        $skills = ['PHP', 'Laravel', 'JavaScript', 'Vue.js', 'React', 'Python', 'UI/UX', 'CSS', 'HTML', 'Node.js'];

        return view('livewire.freelancer-search', compact('profiles', 'skills'));
    }
}
```

## Cara Integrasi & Pengujian
1. Akses `/freelancers`
2. Cari berdasarkan nama/skill di search box
3. Filter berdasarkan skill tertentu
4. Atur rentang harga (min-max)
5. Filter berdasarkan experience level
6. Ubah sorting, pastikan hasil berubah
7. Klik "Reset Filter" untuk menghapus semua filter
8. Pastikan pagination bekerja dengan filter
9. Klik profil freelancer, diarahkan ke halaman profil
