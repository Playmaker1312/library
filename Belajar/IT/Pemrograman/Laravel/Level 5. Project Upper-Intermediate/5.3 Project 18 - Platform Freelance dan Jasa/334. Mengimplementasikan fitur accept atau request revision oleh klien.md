# 334. Mengimplementasikan Fitur Accept atau Request Revision oleh Klien

## Definisi & Target
Klien dapat menerima hasil pekerjaan (completed) atau meminta revisi setelah freelancer deliver. Target: menyelesaikan siklus order.

## Komponen yang Terlibat
- OrderController (complete, reject)
- Order status transition
- File revisi upload
- Notifikasi ke freelancer

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

### Controller
```php
// app/Http/Controllers/OrderController.php (tambahan)
use App\Enums\OrderStatus;

public function complete(Order $order)
{
    if ($order->client_id !== auth()->id()) {
        abort(403);
    }

    if ($order->status !== 'delivered') {
        return back()->with('error', 'Hanya bisa menyelesaikan order yang sudah dikirim.');
    }

    $order->transitionTo(OrderStatus::Completed);

    return redirect()->route('orders.show', $order)
        ->with('success', 'Pesanan selesai! Silakan beri review.');
}

public function acceptAndReview(Order $order)
{
    if ($order->client_id !== auth()->id()) {
        abort(403);
    }

    if ($order->status !== 'delivered') {
        return back()->with('error', 'Status tidak valid.');
    }

    $order->transitionTo(OrderStatus::Completed);

    return redirect()->route('reviews.create-for-freelancer', $order)
        ->with('success', 'Pesanan selesai! Beri rating untuk freelancer.');
}
```

### Livewire Component untuk Accept Action
```php
// app/Livewire/OrderActions.php
namespace App\Livewire;

use App\Models\Order;
use Livewire\Component;

class OrderActions extends Component
{
    public Order $order;

    public function complete()
    {
        if ($this->order->client_id !== auth()->id() || $this->order->status !== 'delivered') {
            return;
        }

        $this->order->update([
            'status' => 'completed',
            'completed_at' => now(),
        ]);

        $this->dispatch('order-completed');
        session()->flash('success', 'Pesanan selesai!');
    }

    public function render()
    {
        return view('livewire.order-actions');
    }
}
```

### Notification
```php
// app/Notifications/OrderCompletedNotification.php
namespace App\Notifications;

use App\Models\Order;
use Illuminate\Bus\Queueable;
use Illuminate\Notifications\Notification;

class OrderCompletedNotification extends Notification
{
    use Queueable;

    public $order;
    public $type;

    public function __construct(Order $order, string $type = 'completed')
    {
        $this->order = $order;
        $this->type = $type;
    }

    public function via($notifiable)
    {
        return ['database'];
    }

    public function toArray($notifiable)
    {
        return [
            'type' => "order_{$this->type}",
            'order_id' => $this->order->id,
            'service_title' => $this->order->service->title,
            'message' => $this->order->service->title . ' telah ' .
                ($this->type === 'completed' ? 'selesai' : 'diminta revisi'),
        ];
    }
}
```

## Cara Integrasi & Pengujian
1. Freelancer deliver file (status: delivered)
2. Klien buka halaman order, lihat 2 opsi: Terima atau Revisi
3. Klik "Minta Revisi" dengan catatan, status berubah ke revision
4. Freelancer deliver ulang
5. Klik "Terima", status berubah ke completed
6. Verifikasi tombol review muncul setelah completed
7. Uji coba accept saat status bukan delivered (harus ditolak)
