# 332. Mengimplementasikan Sistem Revisi yaitu Klien Bisa Meminta Revisi Sesuai Package

## Definisi & Target
Klien dapat meminta revisi setelah freelancer mengirimkan hasil. Jumlah revisi dibatasi sesuai package. Freelancer bisa deliver ulang setelah revisi.

## Komponen yang Terlibat
- Order model (revisions_left)
- OrderController (requestRevision)
- OrderFile untuk file revisi
- Validasi batas revisi

## Perintah Artisan CLI
```bash
php artisan make:controller OrderRevisionController
```

## Kode Implementasi (Per File)

### Controller
```php
// app/Http/Controllers/OrderRevisionController.php
namespace App\Http\Controllers;

use App\Models\Order;
use App\Enums\OrderStatus;
use Illuminate\Http\Request;

class OrderRevisionController extends Controller
{
    public function request(Order $order)
    {
        if ($order->client_id !== auth()->id()) {
            abort(403);
        }

        if ($order->status !== 'delivered') {
            return back()->with('error', 'Revisi hanya bisa diminta saat status "Terkirim".');
        }

        if ($order->revisions_left <= 0) {
            return back()->with('error', 'Batas revisi sudah habis.');
        }

        $order->update([
            'status' => OrderStatus::Revision->value,
            'revisions_left' => $order->revisions_left - 1,
        ]);

        return back()->with('success', 'Revisi diminta. Sisa revisi: ' . $order->revisions_left);
    }

    public function requestWithNote(Request $request, Order $order)
    {
        if ($order->client_id !== auth()->id()) {
            abort(403);
        }

        $request->validate([
            'note' => 'required|string|max:5000',
        ]);

        if ($order->status !== 'delivered') {
            return back()->with('error', 'Revisi hanya bisa diminta saat status "Terkirim".');
        }

        if ($order->revisions_left <= 0) {
            return back()->with('error', 'Batas revisi sudah habis.');
        }

        $order->update([
            'status' => OrderStatus::Revision->value,
            'revisions_left' => $order->revisions_left - 1,
        ]);

        if ($request->hasFile('files')) {
            foreach ($request->file('files') as $file) {
                $path = $file->store('orders/' . $order->id . '/revisions', 'public');
                $order->files()->create([
                    'user_id' => auth()->id(),
                    'file_path' => $path,
                    'original_name' => $file->getClientOriginalName(),
                    'type' => 'revision_note',
                ]);
            }
        }

        return back()->with('success', 'Permintaan revisi dengan catatan telah dikirim.');
    }
}
```

### Livewire Component
```php
// app/Livewire/RevisionRequest.php
namespace App\Livewire;

use App\Models\Order;
use Livewire\Component;
use Livewire\WithFileUploads;

class RevisionRequest extends Component
{
    use WithFileUploads;

    public Order $order;
    public $note = '';
    public $files = [];

    public function mount(Order $order)
    {
        $this->order = $order;
    }

    public function submit()
    {
        $this->validate([
            'note' => 'required|min:10|max:5000',
            'files.*' => 'nullable|file|max:10240',
        ]);

        $this->order->update([
            'status' => 'revision',
            'revisions_left' => $this->order->revisions_left - 1,
        ]);

        foreach ($this->files as $file) {
            $path = $file->store('orders/' . $this->order->id . '/revisions', 'public');
            $this->order->files()->create([
                'user_id' => auth()->id(),
                'file_path' => $path,
                'original_name' => $file->getClientOriginalName(),
                'type' => 'revision_note',
            ]);
        }

        $this->reset(['note', 'files']);
        $this->dispatch('revision-requested');
        session()->flash('success', 'Permintaan revisi dikirim. Sisa revisi: ' . $this->order->revisions_left);
    }

    public function render()
    {
        return view('livewire.revision-request');
    }
}
```

### Free Delivery Button (setelah revisi)
```php
// app/Http/Controllers/OrderController.php (tambahan)
public function deliver(Order $order)
{
    if ($order->freelancer_id !== auth()->id()) {
        abort(403);
    }

    if (!in_array($order->status, ['in_progress', 'revision'])) {
        return back()->with('error', 'Status tidak valid untuk pengiriman.');
    }

    $order->update([
        'status' => 'delivered',
        'delivered_at' => now(),
    ]);

    return back()->with('success', 'Hasil pekerjaan telah dikirim ke klien.');
}
```

```php
// routes/web.php
Route::post('/orders/{order}/deliver', [OrderController::class, 'deliver'])->name('orders.deliver');
```

## Cara Integrasi & Pengujian
1. Freelancer deliver hasil pekerjaan (status: delivered)
2. Klien melihat tombol "Minta Revisi"
3. Klik "Minta Revisi" tanpa catatan, status berubah ke revision, revisions_left berkurang
4. Klien juga bisa mengirim catatan + file revisi via Livewire
5. Freelancer deliver ulang (status: delivered lagi)
6. Ulangi sampai revisions_left habis
7. Jika revisions_left = 0, tombol revisi tidak muncul
8. Pastikan freelancer bisa deliver hanya dari status in_progress atau revision
