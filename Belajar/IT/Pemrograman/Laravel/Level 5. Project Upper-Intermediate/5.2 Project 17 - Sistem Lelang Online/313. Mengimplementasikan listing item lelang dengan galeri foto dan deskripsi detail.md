# 313. Mengimplementasikan Listing Item Lelang dengan Galeri Foto dan Deskripsi Detail

## Definisi & Target
Membangun halaman listing item lelang dengan galeri foto multi-gambar dan deskripsi detail. Target: seller dapat membuat item lelang lengkap dengan upload gambar.

## Komponen yang Terlibat
- AuctionItemController (create, store, show)
- Livewire untuk upload galeri
- File storage untuk gambar
- Blade view listing & detail

## Perintah Artisan CLI
```bash
php artisan make:controller AuctionItemController --resource
php artisan make:livewire AuctionGalleryUploader
php artisan storage:link
```

### Controller
```php
// app/Http/Controllers/AuctionItemController.php
namespace App\Http\Controllers;

use App\Models\AuctionItem;
use App\Models\AuctionItemImage;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Storage;

class AuctionItemController extends Controller
{
    public function index()
    {
        $items = AuctionItem::with(['images', 'seller', 'highestBid'])
            ->where('status', 'active')
            ->where('start_time', '<=', now())
            ->where('end_time', '>', now())
            ->latest()
            ->paginate(12);

        return view('auction-items.index', compact('items'));
    }

    public function create()
    {
        return view('auction-items.create');
    }

    public function store(Request $request)
    {
        $validated = $request->validate([
            'title' => 'required|max:255',
            'description' => 'required',
            'starting_bid' => 'required|numeric|min:0',
            'bid_increment' => 'required|numeric|min:100',
            'buy_now_price' => 'nullable|numeric|min:0',
            'start_time' => 'required|date|after_or_equal:now',
            'end_time' => 'required|date|after:start_time',
            'images' => 'required|array|min:1|max:10',
            'images.*' => 'image|max:5120',
        ]);

        $validated['user_id'] = auth()->id();
        $validated['status'] = 'draft';

        $item = AuctionItem::create($validated);

        foreach ($request->file('images', []) as $index => $image) {
            $path = $image->store('auctions/' . $item->id, 'public');
            $item->images()->create([
                'path' => $path,
                'is_primary' => $index === 0,
                'sort_order' => $index,
            ]);
        }

        return redirect()->route('auction-items.show', $item)
            ->with('success', 'Item lelang berhasil dibuat.');
    }

    public function show(AuctionItem $auctionItem)
    {
        $auctionItem->load(['images', 'seller', 'bids.user', 'highestBid']);
        return view('auction-items.show', compact('auctionItem'));
    }
}
```

### Livewire Gallery Uploader
```php
// app/Livewire/AuctionGalleryUploader.php
namespace App\Livewire;

use Livewire\Component;
use Livewire\WithFileUploads;

class AuctionGalleryUploader extends Component
{
    use WithFileUploads;

    public $images = [];
    public $previews = [];

    public function updatedImages()
    {
        $this->validate([
            'images.*' => 'image|max:5120',
        ]);

        $this->previews = [];
        foreach ($this->images as $image) {
            $this->previews[] = $image->temporaryUrl();
        }
    }

    public function removeImage($index)
    {
        array_splice($this->images, $index, 1);
        array_splice($this->previews, $index, 1);
    }

    public function render()
    {
        return view('livewire.auction-gallery-uploader');
    }
}
```

## Cara Integrasi & Pengujian
1. Jalankan `php artisan migrate` dan `php artisan storage:link`
2. Buat item lelang dengan upload beberapa gambar
3. Verifikasi galeri tampil di halaman detail
4. Klik thumbnail untuk mengganti gambar utama
5. Uji validasi: tanpa gambar, format file salah, ukuran > 5MB
