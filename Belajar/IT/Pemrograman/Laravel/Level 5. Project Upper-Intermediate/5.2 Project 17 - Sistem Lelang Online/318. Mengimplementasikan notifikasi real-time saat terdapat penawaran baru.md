# 318. Mengimplementasikan Notifikasi Real-Time saat Terdapat Penawaran Baru

## Definisi & Target
Mengirim notifikasi real-time ke semua peserta lelang ketika ada bid baru menggunakan Pusher dan Laravel Broadcasting.

## Komponen yang Terlibat
- NewBidPlaced event (broadcast)
- Notifikasi browser (toast/alert)
- Echo listener di frontend
- Update UI otomatis

## Perintah Artisan CLI
```bash
php artisan make:notification NewBidNotification
```

### Database Notification
```php
// app/Notifications/NewBidNotification.php
namespace App\Notifications;

use App\Models\Bid;
use Illuminate\Bus\Queueable;
use Illuminate\Notifications\Notification;

class NewBidNotification extends Notification
{
    use Queueable;

    public $bid;

    public function __construct(Bid $bid)
    {
        $this->bid = $bid;
    }

    public function via($notifiable)
    {
        return ['database', 'broadcast'];
    }

    public function toArray($notifiable)
    {
        return [
            'auction_item_id' => $this->bid->auction_item_id,
            'auction_title' => $this->bid->auctionItem->title,
            'bid_id' => $this->bid->id,
            'bidder_name' => $this->bid->user->name,
            'amount' => $this->bid->amount,
            'message' => "Penawaran baru Rp " . number_format($this->bid->amount) . " pada {$this->bid->auctionItem->title}",
        ];
    }
}
```

### Controller (Kirim notifikasi)
```php
// app/Http/Controllers/BidController.php (tambahan setelah store)
use App\Notifications\NewBidNotification;

public function store(Request $request, AuctionItem $auctionItem)
{
    // ... existing bid creation logic ...

    // Kirim notifikasi ke semua bidder lain
    $otherBidders = Bid::where('auction_item_id', $auctionItem->id)
        ->where('user_id', '!=', auth()->id())
        ->distinct('user_id')
        ->pluck('user_id');

    User::whereIn('id', $otherBidders)->each(function ($user) use ($bid) {
        $user->notify(new NewBidNotification($bid));
    });

    return back()->with('success', 'Bid berhasil dikirim!');
}
```

### Livewire untuk Notifikasi
```php
// app/Livewire/AuctionNotification.php
namespace App\Livewire;

use Livewire\Component;

class AuctionNotification extends Component
{
    public $notifications = [];
    public $unreadCount = 0;

    protected $listeners = ['echo:notifications,NewBidNotification' => 'addNotification'];

    public function mount()
    {
        if (auth()->check()) {
            $this->unreadCount = auth()->user()->unreadNotifications->count();
        }
    }

    public function addNotification($payload)
    {
        array_unshift($this->notifications, $payload);
        $this->unreadCount++;
        $this->dispatch('notification-received');
    }

    public function markAsRead($notificationId)
    {
        auth()->user()->notifications->find($notificationId)?->markAsRead();
        $this->unreadCount = auth()->user()->unreadNotifications()->count();
    }

    public function render()
    {
        return view('livewire.auction-notification');
    }
}
```

### Frontend Real-Time Listener
```javascript
// resources/js/echo.js (tambahan)
import Echo from 'laravel-echo';
import Pusher from 'pusher-js';

window.Pusher = Pusher;
window.Echo = new Echo({
    broadcaster: 'pusher',
    key: import.meta.env.VITE_PUSHER_APP_KEY,
    cluster: import.meta.env.VITE_PUSHER_APP_CLUSTER,
    forceTLS: true,
});

// Notifikasi real-time untuk halaman lelang
const auctionId = document.body.dataset.auctionId;
if (auctionId) {
    window.Echo.channel(`auction.${auctionId}`)
        .listen('.bid.placed', (e) => {
            showToast(`💰 ${e.user_name} menawar Rp ${new Intl.NumberFormat('id-ID').format(e.amount)}`);
            updateBidUI(e);
        });
}

// Notifikasi global untuk user yang login
if (window.Laravel?.userId) {
    window.Echo.private(`App.Models.User.${window.Laravel.userId}`)
        .notification((notification) => {
            showToast(`🔔 ${notification.message}`);
        });
}

function showToast(message) {
    const toast = document.createElement('div');
    toast.className = 'fixed bottom-4 right-4 bg-gray-800 text-white px-4 py-3 rounded-lg shadow-lg z-50 animate-fade-in';
    toast.textContent = message;
    document.body.appendChild(toast);
    setTimeout(() => toast.remove(), 5000);
}

function updateBidUI(e) {
    const currentBidEl = document.getElementById('current-bid');
    if (currentBidEl) {
        currentBidEl.innerText = `Rp ${new Intl.NumberFormat('id-ID').format(e.current_bid)}`;
    }

    const bidCountEl = document.getElementById('bid-count');
    if (bidCountEl) {
        bidCountEl.innerText = `${e.bid_count} penawaran`;
    }
}
```

## Cara Integrasi & Pengujian
1. Login dengan 2 akun berbeda di browser berbeda
2. Akun A bid pada item lelang
3. Akun B (yang juga sudah pernah bid) mendapatkan notifikasi real-time
4. Verifikasi notifikasi muncul sebagai toast di layar
5. Klik ikon lonceng, lihat daftar notifikasi
6. Pastikan notifikasi yang belum dibaca memiliki latar biru
7. Klik notifikasi, arahkan ke halaman lelang terkait
