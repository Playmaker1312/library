# 324. Membangun Dashboard Seller Lelang dengan Statistik Item dan Pendapatan

## Definisi & Target
Dashboard untuk seller melihat statistik item lelang, pendapatan, performa bidding, dan history transaksi. Target: visualisasi data menggunakan Chart.js.

## Komponen yang Terlibat
- SellerDashboardController
- Chart.js untuk grafik
- Livewire atau controller untuk data
- Statistik: total item, active, ended, revenue, rata-rata bid

## Perintah Artisan CLI
```bash
php artisan make:controller SellerDashboardController
php artisan make:service SellerAnalyticsService
```

## Kode Implementasi (Per File)

### Service
```php
// app/Services/SellerAnalyticsService.php
namespace App\Services;

use App\Models\AuctionItem;
use App\Models\Bid;
use App\Models\AuctionResult;
use Illuminate\Support\Facades\DB;

class SellerAnalyticsService
{
    protected $userId;

    public function __construct($userId)
    {
        $this->userId = $userId;
    }

    public function getOverview()
    {
        $items = AuctionItem::where('user_id', $this->userId);

        return [
            'total_items' => (clone $items)->count(),
            'active_items' => (clone $items)->where('status', 'active')->count(),
            'ended_items' => (clone $items)->where('status', 'ended')->count(),
            'total_bids' => Bid::whereHas('auctionItem', fn($q) => $q->where('user_id', $this->userId))->count(),
            'total_revenue' => AuctionResult::whereHas('auctionItem', fn($q) => $q->where('user_id', $this->userId))
                ->where('payment_status', 'paid')
                ->sum('final_amount'),
            'pending_payments' => AuctionResult::whereHas('auctionItem', fn($q) => $q->where('user_id', $this->userId))
                ->where('payment_status', 'pending')
                ->count(),
        ];
    }

    public function getRevenueByMonth($months = 6)
    {
        return AuctionResult::select(
            DB::raw("DATE_FORMAT(paid_at, '%Y-%m') as month"),
            DB::raw('SUM(final_amount) as total')
        )
            ->whereHas('auctionItem', fn($q) => $q->where('user_id', $this->userId))
            ->where('payment_status', 'paid')
            ->where('paid_at', '>=', now()->subMonths($months))
            ->groupBy('month')
            ->orderBy('month')
            ->get();
    }

    public function getItemsByStatus()
    {
        return AuctionItem::where('user_id', $this->userId)
            ->select('status', DB::raw('COUNT(*) as total'))
            ->groupBy('status')
            ->pluck('total', 'status');
    }

    public function getTopItems($limit = 5)
    {
        return AuctionItem::where('user_id', $this->userId)
            ->withCount('bids')
            ->withMax('bids', 'amount')
            ->orderByDesc('bids_count')
            ->limit($limit)
            ->get();
    }

    public function getRecentActivity($limit = 10)
    {
        return Bid::whereHas('auctionItem', fn($q) => $q->where('user_id', $this->userId))
            ->with(['auctionItem', 'user'])
            ->latest()
            ->limit($limit)
            ->get();
    }
}
```

### Controller
```php
// app/Http/Controllers/SellerDashboardController.php
namespace App\Http\Controllers;

use App\Services\SellerAnalyticsService;
use Illuminate\Http\Request;

class SellerDashboardController extends Controller
{
    public function index()
    {
        $analytics = new SellerAnalyticsService(auth()->id());
        $overview = $analytics->getOverview();
        $revenueByMonth = $analytics->getRevenueByMonth();
        $itemsByStatus = $analytics->getItemsByStatus();
        $topItems = $analytics->getTopItems();
        $recentActivity = $analytics->getRecentActivity();
        $items = AuctionItem::where('user_id', auth()->id())
            ->withCount('bids')
            ->latest()
            ->paginate(10);

        return view('seller.dashboard', compact(
            'overview', 'revenueByMonth', 'itemsByStatus',
            'topItems', 'recentActivity', 'items'
        ));
    }
}
```

## Cara Integrasi & Pengujian
1. Login sebagai seller yang memiliki beberapa item lelang
2. Akses `/seller/dashboard`
3. Pastikan statistik overview menampilkan angka yang benar
4. Verifikasi grafik pendapatan per bulan muncul
5. Verifikasi grafik donat status item
6. Cek tabel item terpopuler dan aktivitas terbaru
7. Pastikan seller tanpa item melihat data kosong (0)
