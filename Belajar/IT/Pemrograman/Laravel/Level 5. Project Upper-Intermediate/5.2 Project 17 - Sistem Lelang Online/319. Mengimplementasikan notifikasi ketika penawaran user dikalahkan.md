# 319. Mengimplementasikan Notifikasi ketika Penawaran User Dikalahkan

## Definisi & Target
Mengirim notifikasi ke user ketika bid mereka berhasil dikalahkan oleh bidder lain, memberi kesempatan untuk melakukan bid ulang.

## Komponen yang Terlibat
- BidOutbid notification
- Listener untuk deteksi outbid
- Database notification
- Real-time notification via Pusher

## Perintah Artisan CLI
```bash
php artisan make:notification BidOutbidNotification
php artisan make:listener NotifyOutbidUser
```

## Kode Implementasi (Per File)

### Notification
```php
// app/Notifications/BidOutbidNotification.php
namespace App\Notifications;

use App\Models\Bid;
use Illuminate\Bus\Queueable;
use Illuminate\Notifications\Notification;

class BidOutbidNotification extends Notification
{
    use Queueable;

    public $newBid;
    public $previousBid;

    public function __construct(Bid $newBid, $previousBid)
    {
        $this->newBid = $newBid;
        $this->previousBid = $previousBid;
    }

    public function via($notifiable)
    {
        return ['database', 'broadcast'];
    }

    public function toArray($notifiable)
    {
        return [
            'type' => 'outbid',
            'auction_item_id' => $this->newBid->auction_item_id,
            'auction_title' => $this->newBid->auctionItem->title,
            'new_bid_id' => $this->newBid->id,
            'new_amount' => (float) $this->newBid->amount,
            'new_bidder_name' => $this->newBid->user->name,
            'previous_amount' => (float) ($this->previousBid->amount ?? 0),
            'message' => "Penawaran Anda Rp " . number_format($this->previousBid->amount ?? 0) .
                " pada {$this->newBid->auctionItem->title} telah dikalahkan oleh {$this->newBid->user->name} " .
                "dengan Rp " . number_format($this->newBid->amount),
            'action_url' => route('auction-items.show', $this->newBid->auction_item_id),
        ];
    }
}
```

### Listener
```php
// app/Listeners/NotifyOutbidUser.php
namespace App\Listeners;

use App\Events\NewBidPlaced;
use App\Models\Bid;
use App\Notifications\BidOutbidNotification;

class NotifyOutbidUser
{
    public function handle(NewBidPlaced $event)
    {
        $newBid = $event->bid;

        $previousHighest = Bid::where('auction_item_id', $newBid->auction_item_id)
            ->where('id', '!=', $newBid->id)
            ->where('user_id', '!=', $newBid->user_id)
            ->orderByDesc('amount')
            ->first();

        if ($previousHighest) {
            $previousHighest->user->notify(new BidOutbidNotification($newBid, $previousHighest));
        }
    }
}
```

### Halaman Notifikasi
```php
// app/Http/Controllers/NotificationController.php
namespace App\Http\Controllers;

use Illuminate\Http\Request;

class NotificationController extends Controller
{
    public function index()
    {
        $notifications = auth()->user()->notifications()->paginate(20);
        return view('notifications.index', compact('notifications'));
    }

    public function markAsRead($id)
    {
        auth()->user()->notifications()->find($id)?->markAsRead();
        return back();
    }

    public function markAllAsRead()
    {
        auth()->user()->unreadNotifications->markAsRead();
        return back();
    }
}
```

### Tambahan JavaScript untuk Toast Outbid
```javascript
// resources/js/echo.js (tambahan outbid listener)
// Di halaman detail lelang
if (auctionId) {
    window.Echo.channel(`auction.${auctionId}`)
        .listen('.bid.placed', (e) => {
            showToast(`💰 ${e.user_name} menawar Rp ${new Intl.NumberFormat('id-ID').format(e.amount)}`);
            updateBidUI(e);
        });
}

// Private channel untuk user specific notifications
if (window.Laravel?.userId) {
    window.Echo.private(`App.Models.User.${window.Laravel.userId}`)
        .notification((notification) => {
            if (notification.type === 'outbid') {
                showToast(`⚠️ Anda dikalahkan! ${notification.message}`);
                playOutbidSound();
            } else {
                showToast(`🔔 ${notification.message}`);
            }
        });
}

function playOutbidSound() {
    const audio = new Audio('/sounds/outbid.mp3');
    audio.volume = 0.5;
    audio.play().catch(() => {});
}
```

## Cara Integrasi & Pengujian
1. Login sebagai User A, bid pada item lelang
2. Login sebagai User B di browser lain, bid lebih tinggi pada item yang sama
3. User A mendapatkan notifikasi "Penawaran Anda telah dikalahkan"
4. Notifikasi muncul sebagai toast dan di dropdown notifikasi
5. Klik notifikasi, diarahkan ke halaman lelang untuk bid lagi
6. Pastikan suara notifikasi outbid terdengar (jika diaktifkan)
