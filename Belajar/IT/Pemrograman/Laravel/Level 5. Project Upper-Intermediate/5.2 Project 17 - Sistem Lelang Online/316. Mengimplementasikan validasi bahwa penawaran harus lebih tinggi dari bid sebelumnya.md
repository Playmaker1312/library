# 316. Mengimplementasikan Validasi bahwa Penawaran Harus Lebih Tinggi dari Bid Sebelumnya

## Definisi & Target
Memastikan setiap bid baru memiliki nominal lebih tinggi dari bid tertinggi sebelumnya plus kelipatan increment. Target: validasi di server dan client.

## Komponen yang Terlibat
- BidController / BidForm validasi
- AuctionItem model minNextBid()
- JavaScript client-side validation
- Race condition handling

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

### Model (Validasi di level model)
```php
// app/Models/AuctionItem.php (tambahan method)
public function minNextBid()
{
    return ($this->current_bid ?? $this->starting_bid) + $this->bid_increment;
}

public function isValidBid($amount)
{
    return $amount >= $this->minNextBid();
}
```

### Server Side Validation (Controller)
```php
// app/Http/Controllers/BidController.php
use Illuminate\Http\Request;
use App\Models\AuctionItem;
use App\Models\Bid;
use App\Events\NewBidPlaced;

public function store(Request $request, AuctionItem $auctionItem)
{
    $minBid = $auctionItem->minNextBid();

    $request->validate([
        'amount' => [
            'required',
            'numeric',
            'min:' . $minBid,
            function ($attribute, $value, $fail) use ($auctionItem) {
                if ($auctionItem->buy_now_price && $value > $auctionItem->buy_now_price) {
                    $fail('Harga tidak boleh melebihi buy now price.');
                }
            },
        ],
    ]);

    DB::beginTransaction();
    try {
        $auctionItem->lockForUpdate();

        if (!$auctionItem->isActive()) {
            DB::rollBack();
            return back()->with('error', 'Lelang sudah berakhir.');
        }

        $currentMinBid = $auctionItem->minNextBid();
        if ($request->amount < $currentMinBid) {
            DB::rollBack();
            return back()->with('error', "Bid minimal Rp " . number_format($currentMinBid));
        }

        $bid = Bid::create([
            'auction_item_id' => $auctionItem->id,
            'user_id' => auth()->id(),
            'amount' => $request->amount,
        ]);

        $auctionItem->update(['current_bid' => $bid->amount]);
        DB::commit();
    } catch (\Exception $e) {
        DB::rollBack();
        return back()->with('error', 'Terjadi kesalahan. Silakan coba lagi.');
    }

    broadcast(new NewBidPlaced($bid))->toOthers();

    return back()->with('success', 'Bid berhasil dikirim!');
}
```

### Server Side Validation (Livewire)
```php
// app/Livewire/BidForm.php (dengan validasi tambahan)
use Illuminate\Support\Facades\DB;

public function placeBid()
{
    $minBid = $this->auctionItem->minNextBid();
    $buyNow = $this->auctionItem->buy_now_price;

    $this->validate([
        'amount' => "required|numeric|min:{$minBid}" . ($buyNow ? "|max:{$buyNow}" : ''),
    ]);

    if (!$this->auctionItem->isActive()) {
        $this->addError('amount', 'Lelang tidak aktif atau sudah berakhir.');
        return;
    }

    DB::transaction(function () {
        $item = AuctionItem::lockForUpdate()->find($this->auctionItem->id);

        if (!$item || $this->amount < $item->minNextBid()) {
            $this->addError('amount', 'Bid minimal Rp ' . number_format($item->minNextBid()));
            return;
        }

        $bid = Bid::create([
            'auction_item_id' => $item->id,
            'user_id' => auth()->id(),
            'amount' => $this->amount,
        ]);

        $item->update(['current_bid' => $this->amount]);
        $this->auctionItem = $item->fresh();
        $this->minBid = $item->minNextBid();
        $this->amount = $this->minBid;

        broadcast(new NewBidPlaced($bid))->toOthers();
        $this->dispatch('bid-placed', amount: $this->amount);
    });
}
```

### Client Side Validation (JavaScript)
```javascript
// resources/js/bid-validation.js
document.addEventListener('DOMContentLoaded', function () {
    const bidForm = document.getElementById('bid-form');
    if (!bidForm) return;

    const amountInput = bidForm.querySelector('input[name="amount"]');
    const minBid = parseInt(amountInput?.dataset?.minBid || 0);
    const submitBtn = bidForm.querySelector('button[type="submit"]');
    const errorEl = document.getElementById('bid-error');

    amountInput?.addEventListener('input', function () {
        const value = parseInt(this.value);

        if (isNaN(value) || value < minBid) {
            if (errorEl) {
                errorEl.textContent = `Bid minimal Rp ${new Intl.NumberFormat('id-ID').format(minBid)}`;
                errorEl.classList.remove('hidden');
            }
            if (submitBtn) submitBtn.disabled = true;
        } else {
            if (errorEl) {
                errorEl.textContent = '';
                errorEl.classList.add('hidden');
            }
            if (submitBtn) submitBtn.disabled = false;
        }
    });
});
```

### Form Request Validation
```php
// app/Http/Requests/PlaceBidRequest.php
namespace App\Http\Requests;

use App\Models\AuctionItem;
use Illuminate\Foundation\Http\FormRequest;

class PlaceBidRequest extends FormRequest
{
    protected $auctionItem;

    public function authorize()
    {
        $this->auctionItem = $this->route('auctionItem');
        return $this->auctionItem->isActive() && $this->auctionItem->user_id !== $this->user()->id;
    }

    public function rules()
    {
        return [
            'amount' => [
                'required',
                'numeric',
                'min:' . $this->auctionItem->minNextBid(),
                function ($attribute, $value, $fail) {
                    if ($this->auctionItem->buy_now_price && $value > $this->auctionItem->buy_now_price) {
                        $fail('Bid tidak boleh melebihi buy now price.');
                    }
                },
            ],
        ];
    }

    public function messages()
    {
        return [
            'amount.min' => 'Bid minimal :min.',
            'amount.required' => 'Masukkan nominal bid.',
            'amount.numeric' => 'Nominal harus angka.',
        ];
    }
}
```

## Cara Integrasi & Pengujian
1. Buat item lelang dengan starting_bid 100000 dan bid_increment 5000
2. Coba bid dengan nominal 95000 (harus ditolak, minimal 100000)
3. Coba bid dengan nominal 105000 (harus ditolak karena bukan kelipatan 5000 dari 100000 = 105000 sebenarnya valid, tapi minimal bid adalah 100000+5000=105000, jadi 105000 valid)
4. Uji race condition: buka 2 tab dan klik submit bersamaan
5. Pastikan hanya 1 bid yang tercatat dengan benar menggunakan lockForUpdate
