# 323. Mengimplementasikan Fitur Watchlist Lelang yang Ingin Dipantau

## Definisi & Target
Fitur watchlist memungkinkan user menyimpan lelang favorit untuk dipantau perkembangannya. Target: user dapat menambah/menghapus watchlist dan melihat status lelang dari dashboard.

## Komponen yang Terlibat
- Watchlist model & migration (polymorphic)
- Livewire toggle button
- Halaman watchlist
- Notifikasi perubahan status

## Perintah Artisan CLI
```bash
php artisan make:model Watchlist -m
php artisan make:livewire WatchlistButton
php artisan make:controller WatchlistController
```

### Livewire Component
```php
// app/Livewire/WatchlistButton.php
namespace App\Livewire;

use App\Models\AuctionItem;
use Livewire\Component;

class WatchlistButton extends Component
{
    public AuctionItem $auctionItem;
    public $isWatched = false;

    public function mount(AuctionItem $auctionItem)
    {
        $this->auctionItem = $auctionItem;
        if (auth()->check()) {
            $this->isWatched = $auctionItem->isWatchedBy(auth()->user());
        }
    }

    public function toggle()
    {
        if (!auth()->check()) {
            return redirect()->route('login');
        }

        $watchlist = auth()->user()->watchlists()
            ->where('watchable_id', $this->auctionItem->id)
            ->where('watchable_type', AuctionItem::class)
            ->first();

        if ($watchlist) {
            $watchlist->delete();
            $this->isWatched = false;
        } else {
            auth()->user()->watchlists()->create([
                'watchable_id' => $this->auctionItem->id,
                'watchable_type' => AuctionItem::class,
            ]);
            $this->isWatched = true;
        }
    }

    public function render()
    {
        return view('livewire.watchlist-button');
    }
}
```

### Controller
```php
// app/Http/Controllers/WatchlistController.php
namespace App\Http\Controllers;

use App\Models\AuctionItem;
use Illuminate\Http\Request;

class WatchlistController extends Controller
{
    public function index()
    {
        $watchlists = auth()->user()->watchlists()
            ->where('watchable_type', AuctionItem::class)
            ->with(['watchable' => function ($q) {
                $q->with(['images', 'highestBid']);
            }])
            ->latest()
            ->paginate(12);

        return view('watchlists.index', compact('watchlists'));
    }

    public function toggle(AuctionItem $auctionItem)
    {
        $watchlist = auth()->user()->watchlists()
            ->where('watchable_id', $auctionItem->id)
            ->where('watchable_type', AuctionItem::class)
            ->first();

        if ($watchlist) {
            $watchlist->delete();
            $status = 'removed';
        } else {
            auth()->user()->watchlists()->create([
                'watchable_id' => $auctionItem->id,
                'watchable_type' => AuctionItem::class,
            ]);
            $status = 'added';
        }

        if (request()->wantsJson()) {
            return response()->json(['status' => $status]);
        }

        return back();
    }
}
```

## Cara Integrasi & Pengujian
1. Buka halaman detail lelang
2. Klik tombol "Pantau", pastikan berubah menjadi "Tersimpan"
3. Buka halaman /watchlists, lihat lelang yang dipantau
4. Klik toggle lagi, lelang hilang dari watchlist
5. Pastikan user yang tidak login diarahkan ke halaman login
6. Verifikasi button watchlist ada di setiap kartu lelang
