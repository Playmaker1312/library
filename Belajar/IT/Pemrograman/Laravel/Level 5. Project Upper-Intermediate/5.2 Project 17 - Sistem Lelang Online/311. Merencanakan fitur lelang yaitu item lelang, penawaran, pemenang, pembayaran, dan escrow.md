# 311. Merencanakan Fitur Lelang yaitu Item Lelang, Penawaran, Pemenang, Pembayaran, dan Escrow

## Definisi & Target
Merencanakan arsitektur sistem lelang online yang mencakup seluruh siklus hidup lelang: publikasi item, bidding, penentuan pemenang, pembayaran, dan escrow. Target: dokumen perencanaan yang siap diimplementasikan.

## Komponen yang Terlibat
- Fitur inti: Item Lelang, Penawaran (Bid), Pemenang, Pembayaran, Escrow
- Scheduler untuk penutupan otomatis
- Notifikasi real-time
- Sistem rating & dispute

## Perintah Artisan CLI
Tidak ada perintah khusus untuk tahap perencanaan.

## Kode Implementasi (Per File)

### Perencanaan Fitur

**Auction Items**
- Judul, deskripsi, foto galeri, harga awal (starting_bid)
- Kelipatan bid (bid_increment)
- Harga langsung beli (buy_now_price) opsional
- Waktu mulai dan berakhir (start_time, end_time)
- Status: draft, active, cancelled, ended, sold

**Bidding System**
- User hanya bisa bid jika harga >= starting_bid
- Bid harus > current highest bid + increment
- Auto-bid / proxy bidding hingga batas maks user
- Riwayat bid ditampilkan real-time

**Winner Determination**
- Otomatis saat end_time tercapai
- Highest bidder wins
- Sistem mengirim notifikasi ke pemenang
- Waktu pembayaran (payment_deadline)

**Payment & Escrow**
- Pembayaran ditahan di escrow sampai kedua pihak setuju
- Seller mengirim barang / konfirmasi
- Buyer menerima barang / konfirmasi
- Dana dilepas ke seller
- Dispute resolution jika ada masalah

### Schema Concept
```
auction_items
  - id, user_id (seller), title, slug, description
  - starting_bid, bid_increment, buy_now_price
  - start_time, end_time, status
  - created_at, updated_at

bids
  - id, auction_item_id, user_id, amount, is_auto_bid, max_amount
  - created_at

auction_results
  - id, auction_item_id, winner_id, winning_bid_id, final_amount
  - payment_status, payment_deadline, paid_at
  - created_at, updated_at

escrows
  - id, auction_result_id, buyer_id, seller_id, amount
  - status (held, released, refunded, disputed)
  - held_at, released_at, disputed_at

disputes
  - id, escrow_id, raised_by, reason, status
  - resolution, created_at, updated_at
```
