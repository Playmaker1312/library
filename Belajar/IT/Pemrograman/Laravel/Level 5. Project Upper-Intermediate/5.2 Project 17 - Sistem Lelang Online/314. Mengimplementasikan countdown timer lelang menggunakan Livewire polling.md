# 314. Mengimplementasikan Countdown Timer Lelang Menggunakan Livewire Polling

## Definisi & Target
Menampilkan countdown timer real-time pada halaman detail lelang yang menunjukkan sisa waktu. Livewire polling akan memperbarui timer setiap detik/menit.

## Komponen yang Terlibat
- Livewire AuctionCountdown component
- Polling dengan wire:poll
- Blade view timer
- Action saat waktu habis

## Perintah Artisan CLI
```bash
php artisan make:livewire AuctionCountdown
```

## Kode Implementasi (Per File)

### Livewire Component
```php
// app/Livewire/AuctionCountdown.php
namespace App\Livewire;

use App\Models\AuctionItem;
use Livewire\Component;

class AuctionCountdown extends Component
{
    public AuctionItem $auctionItem;
    public $remaining;
    public $days = 0;
    public $hours = 0;
    public $minutes = 0;
    public $seconds = 0;
    public $isEnded = false;

    public function mount(AuctionItem $auctionItem)
    {
        $this->auctionItem = $auctionItem;
        $this->calculateRemaining();
    }

    public function calculateRemaining()
    {
        $now = now();
        $end = $this->auctionItem->end_time;

        if ($now >= $end) {
            $this->isEnded = true;
            $this->days = 0;
            $this->hours = 0;
            $this->minutes = 0;
            $this->seconds = 0;
            return;
        }

        $this->remaining = $now->diffInSeconds($end, false);
        $this->days = floor($this->remaining / 86400);
        $this->hours = floor(($this->remaining % 86400) / 3600);
        $this->minutes = floor(($this->remaining % 3600) / 60);
        $this->seconds = $this->remaining % 60;
    }

    public function poll()
    {
        $this->calculateRemaining();

        if ($this->isEnded) {
            $this->auctionItem->refresh();
            if ($this->auctionItem->status === 'active') {
                $this->dispatch('auction-ended');
            }
        }
    }

    public function render()
    {
        return view('livewire.auction-countdown');
    }
}
```

### Integrasi di Halaman Detail

```blade
<livewire:auction-countdown :auctionItem="$auctionItem" wire:key="countdown-{{ $auctionItem->id }}" />
```

### Listener untuk Event Auction Ended
```php
// app/Livewire/AuctionCountdown.php (tambahan)
protected $listeners = ['echo:auctions,auction.ended' => 'handleAuctionEnded'];

public function handleAuctionEnded($payload)
{
    if ($payload['auctionItemId'] === $this->auctionItem->id) {
        $this->isEnded = true;
        $this->auctionItem->refresh();
    }
}
```

## Cara Integrasi & Pengujian
1. Buka halaman detail lelang yang sedang aktif
2. Verifikasi countdown menunjukkan sisa waktu yang benar
3. Tunggu hingga timer mendekati 0 dan pastikan polling berjalan
4. Setelah waktu habis, pastikan status berubah menjadi "Lelang Telah Berakhir"
5. Uji dengan item yang sudah berakhir (pastikan end_time di masa lalu)
6. Uji dengan item yang masih lama (tampilkan format hari)
