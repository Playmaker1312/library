# 364. Mengimplementasikan Progress Bar Saat Mengisi Survey

## Definisi & Target
Progress bar visual yang menunjukkan kemajuan pengisian survey, termasuk persentase, halaman saat ini, dan estimasi waktu.

## Komponen yang Terlibat
- Alpine.js x-data untuk progress
- Livewire SurveyForm
- Pagination (jika diaktifkan)
- Animation

## Perintah Artisan CLI
Tidak ada perintah baru.

## Kode Implementasi (Per File)

### Blade Progress Bar Component
```blade
{{-- resources/views/components/survey-progress-bar.blade.php --}}
@props(['current', 'total', 'percentage' => 0, 'showLabel' => true])

<div class="w-full" x-data="progressBar(@entangle('percentage'))">
    <div class="flex justify-between text-sm text-gray-500 mb-1">
        <span>
            @if ($total > 1)
                Halaman {{ $current }} dari {{ $total }}
            @endif
        </span>
        <span x-text="percentage + '%'" x-show="{{ $showLabel ? 'true' : 'false' }}"></span>
    </div>

    <div class="w-full bg-gray-200 rounded-full h-3 overflow-hidden">
        <div class="h-full bg-gradient-to-r from-blue-400 to-blue-600 rounded-full transition-all duration-500 ease-out"
             :style="'width: ' + percentage + '%'">
        </div>
    </div>

    <div class="flex justify-between text-xs text-gray-400 mt-1">
        <span>Mulai</span>
        <span>Selesai</span>
    </div>
</div>

@push('scripts')
<script>
    function progressBar(percentageRef) {
        return {
            percentage: 0,
            init() {
                this.percentage = percentageRef;
                // Animate from 0 to actual percentage
                const target = percentageRef;
                let current = 0;
                const step = target / 20; // 20 frames
                const interval = setInterval(() => {
                    current += step;
                    if (current >= target) {
                        current = target;
                        clearInterval(interval);
                    }
                    this.percentage = Math.round(current);
                }, 30);
            }
        };
    }
</script>
@endpush
```

### Update SurveyForm dengan Progress
```php
// app/Livewire/SurveyForm.php - tambah computed property
public function getPercentageProperty()
{
    $completed = collect($this->answers)->filter(fn($v) =>
        $v !== null && $v !== '' && !(is_array($v) && empty($v))
    )->count();

    $total = $this->survey->questions->count();

    if ($total === 0) return 100;

    $answerWeight = 0.7; // 70% untuk jawaban
    $pageWeight = 0.3;   // 30% untuk halaman

    $answerProgress = ($completed / $total) * $answerWeight * 100;
    $pageProgress = ($this->currentPage / max($this->totalPages, 1)) * $pageWeight * 100;

    return min(round($answerProgress + $pageProgress), 100);
}
```

### Integrasi di Survey Form
```blade
{{-- resources/views/livewire/survey-form.blade.php -- update progress bar section --}}
@if ($response)
    @if ($survey->settings['show_progress_bar'] ?? true)
        <div class="mb-6">
            <x-survey-progress-bar
                :current="$this->currentPage"
                :total="$this->totalPages"
                :percentage="$this->percentage"
                :showLabel="true"
            />

            {{-- Estimasi waktu --}}
            @if ($this->startedAt)
                <div class="text-right text-xs text-gray-400 mt-1">
                    Waktu: <span x-data="timer('{{ $this->startedAt }}')" x-text="elapsed"></span>
                </div>
            @endif

            {{-- Ringkasan pertanyaan --}}
            <div class="text-center text-sm text-gray-500 mt-2">
                {{ collect($this->answers)->filter(fn($v) => $v !== null && $v !== '' && !(is_array($v) && empty($v)))->count() }}
                dari {{ $this->survey->questions->count() }} pertanyaan terjawab
            </div>
        </div>
    @endif
@endif

@push('scripts')
<script>
    function timer(startedAt) {
        return {
            elapsed: '0m 0d',
            init() {
                const start = new Date(startedAt).getTime();
                const update = () => {
                    const diff = Math.floor((Date.now() - start) / 1000);
                    const m = Math.floor(diff / 60);
                    const d = diff % 60;
                    this.elapsed = `${m}m ${d}d`;
                };
                update();
                setInterval(update, 1000);
            }
        };
    }
</script>
@endpush
```

## Cara Integrasi & Pengujian
1. Buat survey dengan 10+ pertanyaan dan pagination
2. Isi survey, lihat progress bar bertambah
3. Jawab pertanyaan, lihat persentase berubah
4. Navigasi halaman, lihat step indicator berfungsi
5. Matikan show_progress_bar di setting, verifikasi hilang
6. Cek estimasi waktu berjalan
