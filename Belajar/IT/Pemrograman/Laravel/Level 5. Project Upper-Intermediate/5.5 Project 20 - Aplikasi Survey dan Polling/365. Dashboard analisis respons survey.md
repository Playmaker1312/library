# 365. Dashboard Analisis Respons Survey

## Definisi & Target
Dashboard untuk melihat statistik dan analisis hasil survey: total respons, completion rate, rata-rata waktu, dan ringkasan.

## Komponen yang Terlibat
- SurveyResultController
- Livewire ResultDashboard
- Chart.js (opsional, integrasi poin 366)
- Statistik agregat

## Perintah Artisan CLI
```bash
php artisan make:controller SurveyResultController
php artisan make:livewire ResultDashboard
```

## Kode Implementasi (Per File)

### Controller
```php
// app/Http/Controllers/SurveyResultController.php
namespace App\Http\Controllers;

use App\Models\Survey;
use Illuminate\Http\Request;

class SurveyResultController extends Controller
{
    public function __construct()
    {
        $this->middleware(function ($request, $next) {
            $survey = $request->route('survey');
            if ($survey->user_id !== auth()->id() &&
                !$survey->collaborators()->where('user_id', auth()->id())->exists()) {
                abort(403);
            }
            return $next($request);
        });
    }

    public function overview(Survey $survey)
    {
        $survey->load('questions');
        return view('surveys.results.overview', compact('survey'));
    }

    public function responses(Survey $survey)
    {
        $responses = $survey->responses()
            ->whereNotNull('completed_at')
            ->withCount('answers')
            ->latest()
            ->paginate(20);

        return view('surveys.results.responses', compact('survey', 'responses'));
    }

    public function responseDetail(Survey $survey, $responseId)
    {
        $response = $survey->responses()
            ->with('answers.question')
            ->findOrFail($responseId);

        return view('surveys.results.response-detail', compact('survey', 'response'));
    }
}
```

### Routes
```php
// routes/web.php
Route::middleware('auth')->prefix('surveys/{survey}/results')->name('surveys.results.')->group(function () {
    Route::get('/', [SurveyResultController::class, 'overview'])->name('overview');
    Route::get('/responses', [SurveyResultController::class, 'responses'])->name('responses');
    Route::get('/responses/{response}', [SurveyResultController::class, 'responseDetail'])->name('response-detail');
});
```

### Livewire ResultDashboard
```php
// app/Livewire/ResultDashboard.php
namespace App\Livewire;

use App\Models\Survey;
use Livewire\Component;

class ResultDashboard extends Component
{
    public Survey $survey;
    public $stats = [];

    public function mount(Survey $survey)
    {
        $this->survey = $survey;
        $this->loadStats();
    }

    public function loadStats()
    {
        $responses = $this->survey->responses()->whereNotNull('completed_at');
        $total = $responses->count();
        $started = $this->survey->responses()->count();

        $this->stats = [
            'total_responses' => $total,
            'started' => $started,
            'completion_rate' => $started > 0 ? round(($total / $started) * 100, 1) : 0,
            'avg_time' => $this->formatTime($responses->avg('time_spent')),
            'responses_today' => $responses->whereDate('completed_at', today())->count(),
            'responses_this_week' => $responses->whereBetween('completed_at', [now()->startOfWeek(), now()->endOfWeek()])->count(),
            'drop_off_rate' => $started > 0 ? round((($started - $total) / $started) * 100, 1) : 0,
            'question_count' => $this->survey->questions->count(),
        ];
    }

    private function formatTime($seconds)
    {
        if (!$seconds) return '-';
        $minutes = floor($seconds / 60);
        $secs = round($seconds % 60);
        return "{$minutes}m {$secs}d";
    }

    public function render()
    {
        return view('livewire.result-dashboard');
    }
}
```

```blade
{{-- resources/views/surveys/results/overview.blade.php --}}
<x-app-layout>

                        @if ($response->time_spent)
                            &middot; {{ floor($response->time_spent / 60) }}m
                        @endif
                    </div>
                </div>
            @empty
                <p class="text-gray-500 text-center py-4">Belum ada respons yang terkumpul.</p>
            @endforelse
        </div>

        {{-- Distribusi Waktu --}}
        <div class="bg-white p-6 rounded shadow mt-6">
            <h2 class="font-bold text-lg mb-4">Distribusi Waktu</h2>
            @php
                $timeRanges = [
                    '< 1m' => $survey->responses()->where('time_spent', '<', 60)->count(),
                    '1-3m' => $survey->responses()->whereBetween('time_spent', [60, 180])->count(),
                    '3-5m' => $survey->responses()->whereBetween('time_spent', [180, 300])->count(),
                    '5-10m' => $survey->responses()->whereBetween('time_spent', [300, 600])->count(),
                    '> 10m' => $survey->responses()->where('time_spent', '>', 600)->count(),
                ];
                $maxTime = max($timeRanges);
            @endphp
            <div class="space-y-2">
                @foreach ($timeRanges as $label => $count)
                    <div>
                        <div class="flex justify-between text-sm mb-1">
                            <span>{{ $label }}</span>
                            <span>{{ $count }} respons</span>
                        </div>
                        <div class="w-full bg-gray-200 rounded h-2">
                            <div class="bg-blue-500 h-2 rounded" style="width: {{ $maxTime > 0 ? ($count / $maxTime) * 100 : 0 }}%"></div>
                        </div>
                    </div>
                @endforeach
            </div>
        </div>
    </div>
</x-app-layout>
```

```blade
                        @endfor
```

## Cara Integrasi & Pengujian
1. Kumpulkan beberapa respons survey
2. Buka halaman hasil survey
3. Verifikasi statistik: total, completion rate, avg time
4. Lihat ringkasan per pertanyaan (bar chart untuk pilihan ganda, teks untuk jawaban text)
5. Klik "Lihat Semua Respons" untuk daftar detail
6. Filter dan eksplorasi data
