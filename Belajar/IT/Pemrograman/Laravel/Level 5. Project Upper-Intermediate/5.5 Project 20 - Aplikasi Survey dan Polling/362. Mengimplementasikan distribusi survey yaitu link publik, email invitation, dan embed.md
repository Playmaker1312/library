# 362. Mengimplementasikan Distribusi Survey yaitu Link Publik, Email Invitation, dan Embed

## Definisi & Target
Mendistribusikan survey melalui berbagai saluran: link publik, undangan email, dan embed iframe.

## Komponen yang Terlibat
- ShareController
- SurveyDistributionService
- Mail (invitation)
- Embed Blade
- QR Code

## Perintah Artisan CLI
```bash
php artisan make:controller ShareController
php artisan make:mail SurveyInvitation
```

## Kode Implementasi (Per File)

### Controller
```php
// app/Http/Controllers/ShareController.php
namespace App\Http\Controllers;

use App\Models\Survey;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Mail;

class ShareController extends Controller
{
    public function index(Survey $survey)
    {
        return view('surveys.share', compact('survey'));
    }

    public function email(Request $request, Survey $survey)
    {
        $validated = $request->validate([
            'emails' => 'required|string',
            'message' => 'nullable|string|max:2000',
        ]);

        $emails = array_map('trim', explode(',', $validated['emails']));
        $message = $validated['message'] ?? '';

        foreach ($emails as $email) {
            if (filter_var($email, FILTER_VALIDATE_EMAIL)) {
                Mail::to($email)->queue(new \App\Mail\SurveyInvitation($survey, $message));
            }
        }

        return back()->with('success', 'Undangan terkirim ke ' . count($emails) . ' email.');
    }

    public function embed(Survey $survey)
    {
        return view('surveys.embed-code', compact('survey'));
    }
}
```

### Mail
```php
// app/Mail/SurveyInvitation.php
namespace App\Mail;

use App\Models\Survey;
use Illuminate\Bus\Queueable;
use Illuminate\Mail\Mailable;
use Illuminate\Mail\Mailables\Content;
use Illuminate\Mail\Mailables\Envelope;

class SurveyInvitation extends Mailable
{
    use Queueable;

    public function __construct(
        public Survey $survey,
        public string $message = ''
    ) {}

    public function envelope(): Envelope
    {
        return new Envelope(
            subject: "Undangan: {$this->survey->title}",
        );
    }

    public function content(): Content
    {
        return new Content(
            markdown: 'emails.survey-invitation',
            with: [
                'survey' => $this->survey,
                'url' => route('surveys.show', $this->survey),
                'message' => $this->message,
            ],
        );
    }
}
```

## Cara Integrasi & Pengujian
1. Buka halaman share survey
2. Salin link publik, buka di incognito
3. Kirim undangan email, cek mailbox
4. Copy embed code, paste di halaman HTML statis
5. Uji QR code dengan scan
6. Pastikan email terkirim via queue
