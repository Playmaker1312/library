## Kode Implementasi (Per File)

### QuestionEditor Component
```php
// app/Livewire/QuestionEditor.php
namespace App\Livewire;

use App\Models\Question;
use Livewire\Component;

class QuestionEditor extends Component
{
    public Question $question;
    public $logic = [
        'enabled' => false,
        'conditions' => [],
        'operator' => 'and',
    ];

    public $availableQuestions = [];

    public function mount(Question $question)
    {
        $this->question = $question;
        $this->logic = $question->logic ?? $this->logic;

        $this->availableQuestions = $question->survey->questions()
            ->where('id', '!=', $question->id)
            ->where('order', '<', $question->order)
            ->get()
            ->toArray();
    }

    public function addCondition()
    {
        $this->logic['conditions'][] = [
            'question_id' => '',
            'operator' => 'equals',
            'value' => '',
        ];
    }

    public function removeCondition($index)
    {
        unset($this->logic['conditions'][$index]);
        $this->logic['conditions'] = array_values($this->logic['conditions']);
    }

    public function save()
    {
        $this->question->update([
            'logic' => $this->logic['enabled'] ? $this->logic : null,
        ]);

        $this->dispatch('question-updated');
        $this->dispatch('close-modal', 'logic-editor');
    }

    public function render()
    {
        return view('livewire.question-editor');
    }
}
```

### JavaScript Evaluator di SurveyForm
```blade
{{-- In resources/views/livewire/survey-form.blade.php, tambahkan --}}
@push('scripts')
<script>
    document.addEventListener('livewire:init', () => {
        Livewire.on('logic-evaluate', () => {
            applyConditionalLogic();
        });

        function applyConditionalLogic() {
            document.querySelectorAll('[data-logic]').forEach(el => {
                const logic = JSON.parse(el.dataset.logic);
                if (!logic.enabled) { el.style.display = 'block'; return; }

                let visible = logic.operator === 'and';
                const conditions = logic.conditions || [];

                conditions.forEach(cond => {
                    const sourceInput = document.querySelector(`[name="answers.${cond.question_id}"]`)
                        || document.querySelector(`input[type="radio"][wire\\:model="answers.${cond.question_id}"]:checked`)
                        || document.querySelector(`[wire\\:model="answers.${cond.question_id}"]`);
                    const actualValue = sourceInput ? sourceInput.value || '' : '';

                    let match = false;
                    switch (cond.operator) {
                        case 'equals': match = actualValue === cond.value; break;
                        case 'not_equals': match = actualValue !== cond.value; break;
                        case 'contains': match = actualValue.includes(cond.value); break;
                        case 'greater_than': match = parseFloat(actualValue) > parseFloat(cond.value); break;
                        case 'less_than': match = parseFloat(actualValue) < parseFloat(cond.value); break;
                    }

                    visible = logic.operator === 'and' ? (visible && match) : (visible || match);
                });

                el.style.display = visible ? 'block' : 'none';
            });
        }

        document.addEventListener('change', applyConditionalLogic);
        document.addEventListener('input', debounce(applyConditionalLogic, 300));
    });

    function debounce(fn, ms) {
        let timer;
        return (...args) => { clearTimeout(timer); timer = setTimeout(() => fn(...args), ms); };
    }
</script>
@endpush
```

4. Uji operator AND dan OR
5. Uji logic berantai: A → B → C
6. Verifikasi data tetap tersimpan untuk pertanyaan yang tersembunyi (null)
