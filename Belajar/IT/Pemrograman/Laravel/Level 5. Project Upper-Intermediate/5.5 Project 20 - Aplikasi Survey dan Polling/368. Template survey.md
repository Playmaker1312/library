# 368. Template Survey

## Definisi & Target
Membuat template survey yang bisa disimpan, digunakan ulang, dan dibagikan. Target: pengguna bisa memulai survey baru dari template.

## Komponen yang Terlibat
- SurveyTemplate model
- TemplateController
- TemplateLibrary (Livewire)
- Template importer

## Perintah Artisan CLI
```bash
php artisan make:controller TemplateController
php artisan make:livewire TemplateLibrary
```

## Kode Implementasi (Per File)

### Controller
```php
// app/Http/Controllers/TemplateController.php
namespace App\Http\Controllers;

use App\Models\SurveyTemplate;
use App\Models\Survey;
use Illuminate\Http\Request;

class TemplateController extends Controller
{
    public function index()
    {
        $templates = SurveyTemplate::where(function ($q) {
            $q->where('user_id', auth()->id())
              ->orWhere('is_public', true);
        })->latest()->paginate(12);

        return view('templates.index', compact('templates'));
    }

    public function store(Request $request, Survey $survey)
    {
        $validated = $request->validate([
            'name' => 'required|max:255',
            'description' => 'nullable|max:5000',
            'category' => 'nullable|max:100',
            'is_public' => 'boolean',
        ]);

        $template = SurveyTemplate::create([
            'user_id' => auth()->id(),
            'name' => $validated['name'],
            'description' => $validated['description'] ?? null,
            'category' => $validated['category'] ?? null,
            'structure' => [
                'title' => $survey->title,
                'description' => $survey->description,
                'settings' => $survey->settings,
                'theme_color' => $survey->theme_color,
                'questions' => $survey->questions->map(fn($q) => $q->only([
                    'title', 'description', 'type', 'options',
                    'is_required', 'validation', 'order'
                ]))->toArray(),
            ],
            'is_public' => $validated['is_public'] ?? false,
        ]);

        return redirect()->route('templates.index')
            ->with('success', 'Template berhasil disimpan.');
    }

    public function useTemplate(SurveyTemplate $template)
    {
        $structure = $template->structure;

        $survey = Survey::create([
            'user_id' => auth()->id(),
            'title' => $structure['title'] ?? $template->name,
            'description' => $structure['description'] ?? '',
            'status' => 'draft',
            'settings' => $structure['settings'] ?? [
                'allow_anonymous' => true,
                'show_progress_bar' => true,
            ],
            'theme_color' => $structure['theme_color'] ?? '#3b82f6',
        ]);

        foreach (($structure['questions'] ?? []) as $questionData) {
            $survey->questions()->create($questionData);
        }

        return redirect()->route('surveys.edit', $survey)
            ->with('success', 'Survey dibuat dari template.');
    }

    public function destroy(SurveyTemplate $template)
    {
        abort_if($template->user_id !== auth()->id(), 403);
        $template->delete();
        return back()->with('success', 'Template dihapus.');
    }
}
```

### Model
```php
// app/Models/SurveyTemplate.php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class SurveyTemplate extends Model
{
    protected $fillable = [
        'user_id', 'name', 'description', 'category',
        'structure', 'is_public',
    ];

    protected $casts = [
        'structure' => 'array',
        'is_public' => 'boolean',
    ];

    public function user()
    {
        return $this->belongsTo(User::class);
    }

    public function scopePublic($query)
    {
        return $query->where('is_public', true);
    }

    public function scopeByCategory($query, $category)
    {
        return $query->where('category', $category);
    }

    public function questionCount()
    {
        return count($this->structure['questions'] ?? []);
    }
}
```

### Template Library (Livewire)
```php
// app/Livewire/TemplateLibrary.php
namespace App\Livewire;

use App\Models\SurveyTemplate;
use Livewire\Component;
use Livewire\WithPagination;

class TemplateLibrary extends Component
{
    use WithPagination;

    public $search = '';
    public $category = '';
    public $categories = [];

    protected $queryString = ['search', 'category'];

    public function mount()
    {
        $this->categories = SurveyTemplate::where('is_public', true)
            ->whereNotNull('category')
            ->distinct('category')
            ->pluck('category')
            ->toArray();
    }

    public function render()
    {
        $templates = SurveyTemplate::where(function ($q) {
            $q->where('user_id', auth()->id())
              ->orWhere('is_public', true);
        })
        ->when($this->search, fn($q) => $q->where('name', 'like', "%{$this->search}%"))
        ->when($this->category, fn($q) => $q->where('category', $this->category))
        ->latest()
        ->paginate(12);

        return view('livewire.template-library', compact('templates'));
    }
}
```

## Cara Integrasi & Pengujian
1. Buat survey dengan beberapa pertanyaan
2. Simpan sebagai template
3. Buka halaman template, cari template tersimpan
4. Klik "Gunakan Template", verifikasi survey baru dibuat
5. Buat template publik, logout, login sebagai user lain
6. Cari template publik, gunakan
7. Hapus template milik sendiri
