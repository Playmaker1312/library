# 357. Membuat Schema Database untuk Surveys, Questions, Question Options, Responses, dan Response Answers

## Definisi & Target
Membuat seluruh migration dan model untuk aplikasi survey. Target: database siap untuk builder, respons, dan analisis.

## Komponen yang Terlibat
- Migration: surveys, questions, survey_responses, response_answers, survey_templates, survey_collaborators
- Model setiap entitas
- Relationships

## Perintah Artisan CLI
```bash
php artisan make:model Survey -m
php artisan make:model Question -m
php artisan make:model SurveyResponse -m
php artisan make:model ResponseAnswer -m
php artisan make:model SurveyTemplate -m
```


### Models
```php
// app/Models/Survey.php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Support\Str;

class Survey extends Model
{
    protected $fillable = [
        'user_id', 'title', 'slug', 'description', 'status',
        'settings', 'theme_color', 'starts_at', 'ends_at'
    ];

    protected $casts = [
        'settings' => 'array',
        'starts_at' => 'datetime',
        'ends_at' => 'datetime',
    ];

    protected static function booted()
    {
        static::creating(fn($s) => $s->slug = Str::slug($s->title) . '-' . Str::random(6));
    }

    public function user()
    {
        return $this->belongsTo(User::class);
    }

    public function questions()
    {
        return $this->hasMany(Question::class)->orderBy('order');
    }

    public function responses()
    {
        return $this->hasMany(SurveyResponse::class);
    }

    public function collaborators()
    {
        return $this->hasMany(SurveyCollaborator::class);
    }

    public function scopePublished($query)
    {
        return $query->where('status', 'published');
    }

    public function totalResponses()
    {
        return $this->responses()->whereNotNull('completed_at')->count();
    }

    public function completionRate()
    {
        $started = $this->responses()->count();
        $completed = $this->totalResponses();
        return $started > 0 ? round(($completed / $started) * 100, 1) : 0;
    }
}
```
