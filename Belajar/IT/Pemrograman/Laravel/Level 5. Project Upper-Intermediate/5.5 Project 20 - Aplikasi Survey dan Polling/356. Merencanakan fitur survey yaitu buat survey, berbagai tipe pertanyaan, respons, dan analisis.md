# 356. Merencanakan Fitur Survey yaitu Buat Survey, Berbagai Tipe Pertanyaan, Respons, dan Analisis

## Definisi & Target
Merencanakan arsitektur aplikasi survey/polling yang mencakup pembuatan survey, berbagai tipe pertanyaan, pengumpulan respons, dan analisis hasil.

## Komponen yang Terlibat
- Survey builder (drag & drop)
- Multiple question types: text, radio, checkbox, dropdown, rating, matrix
- Logic kondisional
- Distribusi (link, email, embed)
- Analisis & export
- Template survey
- Collaboration

## Perintah Artisan CLI
Tidak ada perintah khusus untuk tahap perencanaan.

## Kode Implementasi (Per File)

### Perencanaan Fitur

**Survey Builder**
- Buat survey dengan judul, deskripsi
- Tambah pertanyaan dengan tipe berbeda
- Drag & drop reorder (SortableJS)
- Opsi required, validasi

**Question Types**
1. Text: jawaban singkat/paragraf
2. Radio: pilih satu opsi
3. Checkbox: pilih beberapa opsi
4. Dropdown: pilih satu dari dropdown
5. Rating: bintang 1-5 atau 1-10
6. Matrix: grid pertanyaan dengan skala

**Logic Kondisional**
- Tampilkan/sembunyikan pertanyaan berdasarkan jawaban sebelumnya
- Lompat ke halaman tertentu

**Distribusi**
- Link publik (tanpa login)
- Email invitation
- Embed iframe di website

**Analisis**
- Jumlah respons, completion rate
- Grafik per pertanyaan (Chart.js)
- Export Excel/CSV
- Filter respons

### Schema Concept
```
surveys
  - id, user_id, title, description, status (draft/published/closed)
  - slug, settings (json), theme
  - created_at, updated_at

questions
  - id, survey_id, title, description, type, options (json)
  - is_required, order, logic (json)
  - created_at, updated_at

survey_responses
  - id, survey_id, respondent_ip, respondent_email
  - started_at, completed_at, time_spent
  - created_at

response_answers
  - id, response_id, question_id, value (text/json)
  - created_at

survey_templates
  - id, user_id, name, description, structure (json)
  - created_at, updated_at

survey_collaborators
  - id, survey_id, user_id, role (viewer/editor/admin)
  - created_at
```
