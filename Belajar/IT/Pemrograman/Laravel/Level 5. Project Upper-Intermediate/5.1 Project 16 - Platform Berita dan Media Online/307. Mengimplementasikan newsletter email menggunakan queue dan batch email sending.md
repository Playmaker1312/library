# 307. Mengimplementasikan Newsletter Email Menggunakan Queue dan Batch Email Sending

## Definisi & Target
Membangun sistem newsletter yang mengirim email artikel terbaru ke subscriber secara terjadwal menggunakan queue untuk menghindari timeout.

## Komponen yang Terlibat
- Newsletter model dan subscriber list
- Queue (database/redis)
- Batch email sending dengan chunk
- Campaign tracking

## Perintah Artisan CLI
```bash
php artisan make:model Newsletter -m
php artisan make:model Subscriber -m
php artisan make:job SendNewsletterCampaign
php artisan make:command SendWeeklyNewsletter
php artisan make:mail ArticleDigest
```

## Kode Implementasi (Per File)

```php
// Schema subscribers
Schema::create('subscribers', function (Blueprint $table) {
    $table->id();
    $table->string('email')->unique();
    $table->string('token')->unique();
    $table->boolean('is_active')->default(true);
    $table->timestamp('subscribed_at');
    $table->timestamps();
});
```

```php
// App/Jobs/SendNewsletterCampaign.php
class SendNewsletterCampaign implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public $timeout = 300;
    public $tries = 3;

    public function __construct(public Newsletter $newsletter) {}

    public function handle(): void
    {
        $subscribers = Subscriber::where('is_active', true)->pluck('email');

        $subscribers->chunk(50)->each(function ($emailChunk) {
            $this->newsletter->subscribers()->createMany(
                $emailChunk->map(fn($email) => ['email' => $email, 'sent_at' => now()])
            );

            Mail::to($emailChunk->toArray())->queue(new ArticleDigest($this->newsletter));
        });

        $this->newsletter->update(['status' => 'sent', 'sent_at' => now()]);
    }
}
```

```php
// App/Mail/ArticleDigest.php
class ArticleDigest extends Mailable
{
    use Queueable, SerializesModels;

    public function __construct(public Newsletter $newsletter) {}

    public function build(): self
    {
        return $this->subject($this->newsletter->subject)
            ->markdown('emails.newsletter.digest');
    }
}
```

```php
// App/Console/Commands/SendWeeklyNewsletter.php
class SendWeeklyNewsletter extends Command
{
    protected $signature = 'newsletter:send-weekly';

    public function handle()
    {
        $articles = Article::where('status', ArticleStatus::Published)
            ->where('published_at', '>=', now()->subWeek())
            ->latest()->get();

        if ($articles->isEmpty()) {
            $this->info('No articles this week.');
            return;
        }

        $newsletter = Newsletter::create([
            'subject' => 'Ringkasan Berita Minggu Ini',
            'content' => view('emails.newsletter.weekly', compact('articles'))->render(),
            'status' => 'draft',
        ]);

        SendNewsletterCampaign::dispatch($newsletter);
        $this->info('Newsletter campaign dispatched.');
    }
}
```

```php
// App/Console/Kernel.php
protected function schedule(Schedule $schedule): void

}
```
