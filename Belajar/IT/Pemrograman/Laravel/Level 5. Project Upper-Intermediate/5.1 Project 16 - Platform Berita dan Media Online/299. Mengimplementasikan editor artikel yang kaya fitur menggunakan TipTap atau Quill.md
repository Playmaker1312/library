# 299. Mengimplementasikan Editor Artikel yang Kaya Fitur Menggunakan TipTap atau Quill

## Definisi & Target
Mengintegrasikan rich text editor ke dalam form pembuatan artikel. Mendukung heading, bold, italic, image upload, link, dan formatting lainnya.

## Komponen yang Terlibat
- TipTap (Tiptap Editor) atau Quill.js
- Laravel Filament atau Livewire + Alpine.js
- File upload untuk gambar
- Storage disk publik

## Perintah Artisan CLI
```bash
npm install @tiptap/core @tiptap/starter-kit @tiptap/extension-image @tiptap/extension-link @tiptap/extension-table @tiptap/extension-placeholder
php artisan storage:link
php artisan make:livewire ArticleEditor
```

## Kode Implementasi (Per File)
```html
<!-- resources/views/livewire/article-editor.blade.php -->
<div wire:ignore x-data="tiptapEditor()" x-init="init($refs.editor)">
    <div x-ref="editor" class="prose max-w-none border rounded-lg p-4 min-h-[400px]"></div>
    <textarea x-model="content" name="body" class="hidden"></textarea>
</div>

<script>
function tiptapEditor() {
    return {
        content: '',
        editor: null,
        init(el) {
            this.editor = new Editor({
                element: el,
                extensions: [StarterKit, Image, Link.configure({ openOnClick: false }), Placeholder.configure({ placeholder: 'Mulai menulis...' })],
                editorProps: {
                    attributes: { class: 'prose max-w-none focus:outline-none' }
                },
                onUpdate: ({ editor }) => { this.content = editor.getHTML(); }
            });
        }
    }
}
</script>
```

```php
// ArticleController store method
public function store(StoreArticleRequest $request)
{
    $article = Article::create([
        'title' => $request->title,
        'slug' => Str::slug($request->title),
        'body' => $request->body,
        'excerpt' => Str::limit(strip_tags($request->body), 200),
        'author_id' => auth()->id(),
        'status' => 'draft'
    ]);
    return redirect()->route('admin.articles.edit', $article);
}
```
