# 303. Mengimplementasikan AMP yaitu Accelerated Mobile Pages untuk Kecepatan di Mobile

## Definisi & Target
Membuat versi AMP (Accelerated Mobile Pages) dari halaman artikel untuk memaksimalkan kecepatan loading di perangkat mobile.

## Komponen yang Terlibat
- AMP HTML framework
- AMP cache (Google CDN)
- Route khusus untuk AMP
- Validasi AMP

## Perintah Artisan CLI
```bash
php artisan make:controller Front/AmpController
composer require tubalmartin/cssmin
npm install @ampproject/optimizer
```

## Kode Implementasi (Per File)
```php
// routes/web.php
Route::get('/amp/artikel/{article:slug}', [AmpController::class, 'show'])->name('amp.article');
```

```php
// App/Http/Controllers/Front/AmpController.php
class AmpController extends Controller
{
    public function show(Article $article)
    {
        abort_if($article->status !== ArticleStatus::Published, 404);
        $related = Article::where('status', ArticleStatus::Published)
            ->where('id', '!=', $article->id)
            ->latest('published_at')->take(4)->get();
        return view('amp.article', compact('article', 'related'));
    }
}
```

```html
<!-- resources/views/amp/article.blade.php -->
<!doctype html>
<html amp lang="id">
<head>
    <meta charset="utf-8">
    <script async src="https://cdn.ampproject.org/v0.js"></script>
    <title>{{ $article->title }} | Portal Berita</title>
    <link rel="canonical" href="{{ route('article.show', $article) }}">
    <meta name="viewport" content="width=device-width,minimum-scale=1,initial-scale=1">
    <style amp-boilerplate>body{-webkit-animation:-amp-start 8s steps(1,end) 0s 1 normal both;-moz-animation:-amp-start 8s steps(1,end) 0s 1 normal both;animation:-amp-start 8s steps(1,end) 0s 1 normal both}</style>
    <style amp-custom>
        body { font-family: system-ui, sans-serif; padding: 16px; line-height: 1.6; }
        h1 { font-size: 1.75rem; margin-bottom: 0.5rem; }
        .meta { color: #666; font-size: 0.875rem; }
        amp-img { margin: 1rem 0; }
    </style>
    <script type="application/ld+json">
    {
        "@context": "https://schema.org",
        "@type": "NewsArticle",
        "headline": "{{ $article->title }}",
        "datePublished": "{{ $article->published_at->toIso8601String() }}",
        "author": { "@type": "Person", "name": "{{ $article->author->name }}" }
    }
    </script>
</head>
<body>
    <amp-img src="{{ asset($article->featured_image) }}" width="720" height="405" layout="responsive" alt="{{ $article->title }}"></amp-img>
    <h1>{{ $article->title }}</h1>
    <div class="meta">Oleh {{ $article->author->name }} | {{ $article->published_at->format('d M Y') }}</div>
    <article>{!! $article->body !!}</article>
</body>
</html>
```
