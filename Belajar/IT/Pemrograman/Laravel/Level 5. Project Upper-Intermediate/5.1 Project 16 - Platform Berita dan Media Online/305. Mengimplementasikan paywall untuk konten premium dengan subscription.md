# 305. Mengimplementasikan Paywall untuk Konten Premium dengan Subscription

## Definisi & Target
Membangun sistem paywall yang membatasi akses ke artikel premium hanya untuk pengguna yang memiliki subscription aktif.

## Komponen yang Terlibat
- SubscriptionPlan, Subscription, Payment models
- Middleware Paywall
- Article is_premium flag
- Partial content preview

## Perintah Artisan CLI
```bash
php artisan make:model SubscriptionPlan -m
php artisan make:model Subscription -m
php artisan make:model Payment -m
php artisan make:middleware Paywall
php artisan make:controller Front/SubscriptionController
```

```php
// App/Http/Middleware/Paywall.php
class Paywall
{
    public function handle(Request $request, Closure $next): Response
    {
        if ($request->route('article')?->is_premium) {
            $user = $request->user();

            if (!$user || !$user->hasActiveSubscription()) {
                if ($request->expectsJson()) {
                    return response()->json(['message' => 'Konten premium. Silakan berlangganan.'], 403);
                }
                session(['paywall_article' => $request->route('article')->id]);
                return redirect()->route('subscription.plans');
            }
        }

        return $next($request);
    }
}
```

```php
// User model
public function subscriptions(): HasMany { return $this->hasMany(Subscription::class); }

public function hasActiveSubscription(): bool
{
    return $this->subscriptions()
        ->where('status', 'active')
        ->where('ends_at', '>', now())
        ->exists();
}
```
