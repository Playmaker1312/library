# 296. Merencanakan Fitur Portal Berita yaitu Artikel, Kategori, Breaking News, dan Subscription

## Definisi & Target
Merencanakan arsitektur dan daftar fitur utama portal berita digital. Targetnya adalah membangun platform berita multi-penulis dengan sistem kategori, breaking news real-time, dan subscription untuk konten premium.

## Komponen yang Terlibat
- Artikel (draft, review, scheduled, published, archived)
- Kategori (hierarki parent-child)
- Breaking News (push notification, banner)
- Subscription (plan, payment, access control)
- Multi-author system
- SEO (slug, meta description, canonical URL)

## Perintah Artisan CLI
```bash
php artisan make:model Article -m
php artisan make:model Category -m
php artisan make:model BreakingNews -m
php artisan make:model Subscription -m
php artisan make:model SubscriptionPlan -m
php artisan make:model AuthorProfile -m
php artisan make:controller Admin/ArticleController --resource
php artisan make:controller Front/ArticleController
php artisan make:controller Admin/BreakingNewsController
```

## Kode Implementasi (Per File)
- Migration / Model
- Routes
- Controller
- Blade View

## Cara Integrasi & Pengujian
Jalankan migrasi dan seeder untuk data awal. Uji setiap fitur melalui route yang telah didaftarkan. Gunakan Tinker untuk verifikasi relasi model.
