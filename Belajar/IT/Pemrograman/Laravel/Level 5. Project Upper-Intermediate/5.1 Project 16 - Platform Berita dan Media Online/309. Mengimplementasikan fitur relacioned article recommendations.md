# 309. Mengimplementasikan Fitur Related Article Recommendations

## Definisi & Target
Menampilkan rekomendasi artikel terkait berdasarkan kategori, tag, atau similaritas konten. Target: sistem merekomendasikan artikel relevan di halaman detail artikel.

## Komponen yang Terlibat
- Article model dengan scope rekomendasi
- Tag atau kategori sebagai basis similaritas
- RecommendationService
- View component rekomendasi
- Cache untuk performa

## Perintah Artisan CLI
```bash
php artisan make:service RecommendationService
php artisan make:component RelatedArticles
```

```php
// app/Models/Article.php (tambahan)
public function scopeRelated($query, Article $article, $limit = 4)
{
    $categoryIds = $article->categories->pluck('id');
    $tagIds = $article->tags->pluck('id');

    return $query->where('id', '!=', $article->id)
        ->where('status', 'published')
        ->where(function ($q) use ($categoryIds, $tagIds) {
            $q->whereHas('categories', fn($cq) => $cq->whereIn('categories.id', $categoryIds))
              ->orWhereHas('tags', fn($tq) => $tq->whereIn('tags.id', $tagIds));
        })
        ->withCount(['categories' => function ($cwq) use ($categoryIds) {
            $cwq->whereIn('categories.id', $categoryIds);
        }])
        ->orderByDesc('categories_count')
        ->orderByDesc('published_at')
        ->limit($limit);
}
```

### Service
```php
// app/Services/RecommendationService.php
namespace App\Services;

use App\Models\Article;
use Illuminate\Support\Facades\Cache;

class RecommendationService
{
    public function getRelated(Article $article, int $limit = 4)
    {
        $cacheKey = "related_articles_{$article->id}_{$limit}";

        return Cache::remember($cacheKey, 3600, function () use ($article, $limit) {
            $related = Article::related($article, $limit)->get();

            if ($related->count() < $limit) {
                $fallback = Article::where('id', '!=', $article->id)
                    ->where('status', 'published')
                    ->latest('published_at')
                    ->limit($limit - $related->count())
                    ->get();
                $related = $related->concat($fallback);
            }

            return $related;
        });
    }

    public function getPopular(int $limit = 5)
    {
        return Cache::remember('popular_articles', 1800, function () use ($limit) {
            return Article::where('status', 'published')
                ->orderByDesc('views_count')
                ->limit($limit)
                ->get();
        });
    }

    public function getTrending(int $limit = 5)
    {
        return Cache::remember('trending_articles', 900, function () use ($limit) {
            return Article::where('status', 'published')
                ->where('published_at', '>=', now()->subDays(7))
                ->orderByDesc('views_count')
                ->limit($limit)
                ->get();
        });
    }
}
```

### Controller
```php
// app/Http/Controllers/ArticleController.php (tambahan)
use App\Services\RecommendationService;

public function show(Article $article, RecommendationService $recommender)
{
    $article->load(['author', 'categories', 'tags', 'media']);
    $article->increment('views_count');

    $relatedArticles = $recommender->getRelated($article);
    $popularArticles = $recommender->getPopular();

    return view('articles.show', compact('article', 'relatedArticles', 'popularArticles'));
}
```

## Cara Integrasi & Pengujian
1. Buat migration tags: `php artisan make:model Tag -m`
2. Buat migration article_tag dan article_category pivot tables
3. Seed beberapa artikel dengan kategori/tags yang sama
4. Buka halaman detail artikel dan pastikan rekomendasi muncul
5. Uji cache dengan mengubah data dan lihat apakah rekomendasi butuh refresh
6. Uji fallback recommendation ketika tidak ada artikel related
