# 297. Membuat Schema Database untuk Articles, Categories, Authors, Comments, Subscriptions, dan Analytics

## Definisi & Target
Merancang dan mengimplementasikan schema database yang komprehensif untuk portal berita. Semua tabel saling terhubung dengan relasi yang tepat.

## Komponen yang Terlibat
- Tabel articles, categories, category_article (pivot)
- Tabel authors (user profile), comments
- Tabel subscriptions, subscription_plans, payments
- Tabel pageviews, analytics_events

## Kode Implementasi (Per File)
```php
// Schema articles
Schema::create('articles', function (Blueprint $table) {
    $table->id();
    $table->foreignId('author_id')->constrained('users');
    $table->string('title');
    $table->string('slug')->unique();
    $table->text('excerpt')->nullable();
    $table->longText('body');
    $table->string('featured_image')->nullable();
    $table->enum('status', ['draft','review','scheduled','published','archived'])->default('draft');
    $table->timestamp('published_at')->nullable();
    $table->timestamp('scheduled_at')->nullable();
    $table->boolean('is_premium')->default(false);
    $table->string('meta_title')->nullable();
    $table->text('meta_description')->nullable();
    $table->string('canonical_url')->nullable();
    $table->timestamps();
    $table->softDeletes();
});
```

```php
// Model Article
class Article extends Model
{
    use SoftDeletes;
    protected $fillable = ['title','slug','excerpt','body','featured_image','status','published_at','scheduled_at','is_premium','meta_title','meta_description','canonical_url','author_id'];
    protected $casts = ['published_at'=>'datetime','scheduled_at'=>'datetime','is_premium'=>'boolean'];

    public function author(): BelongsTo { return $this->belongsTo(User::class, 'author_id'); }
    public function categories(): BelongsToMany { return $this->belongsToMany(Category::class); }
    public function comments(): HasMany { return $this->hasMany(Comment::class); }
    public function pageviews(): HasMany { return $this->hasMany(Pageview::class); }
}
```

```php
// Schema categories
Schema::create('categories', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->string('slug')->unique();
    $table->foreignId('parent_id')->nullable()->constrained('categories');
    $table->text('description')->nullable();
    $table->timestamps();
});
```

```php
// Schema comments
Schema::create('comments', function (Blueprint $table) {
    $table->id();
    $table->foreignId('article_id')->constrained()->cascadeOnDelete();
    $table->foreignId('user_id')->constrained();
    $table->text('body');
    $table->enum('status', ['pending','approved','spam'])->default('pending');
    $table->timestamps();
});
```
