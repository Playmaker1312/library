# 304. Mengimplementasikan Sistem Komentar dengan Moderasi dan Anti-Spam

## Definisi & Target
Membangun sistem komentar untuk artikel dengan fitur moderasi (pending, approve, spam) dan perlindungan anti-spam.

## Komponen yang Terlibat
- Model Comment (relasi ke Article dan User)
- Moderasi manual (approve/reject/spam)
- Anti-spam (rate limit, keyword filter, reCAPTCHA)
- Nested replies

```php
// App/Http/Controllers/Front/CommentController.php
class CommentController extends Controller
{
    public function __construct(private SpamFilter $spamFilter) {}

    public function store(StoreCommentRequest $request, Article $article)
    {
        $spamScore = $this->spamFilter->analyze($request->body);

        $comment = $article->comments()->create([
            'user_id' => auth()->id(),
            'body' => $request->body,
            'parent_id' => $request->parent_id,
            'status' => $spamScore > 0.7 ? 'spam' : ($spamScore > 0.3 ? 'pending' : 'approved'),
        ]);

        return back()->with('success', 'Komentar berhasil ditambahkan');
    }
}
```

```php
// App/Services/SpamFilter.php
class SpamFilter
{
    protected array $blacklist = ['viagra','casino','http://bit.ly', 'free money'];
    protected int $maxLinks = 2;

    public function analyze(string $text): float
    {
        $score = 0.0;

        foreach ($this->blacklist as $word) {
            if (Str::contains(Str::lower($text), $word)) $score += 0.5;
        }

        preg_match_all('/https?:\/\//', $text, $matches);
        if (count($matches[0] ?? []) > $this->maxLinks) $score += 0.4;

        return min($score, 1.0);
    }
}
```
