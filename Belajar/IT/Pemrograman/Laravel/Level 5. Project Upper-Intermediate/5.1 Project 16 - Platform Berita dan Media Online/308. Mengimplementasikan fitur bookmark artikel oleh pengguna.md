# 308. Mengimplementasikan Fitur Bookmark Artikel oleh Pengguna

## Definisi & Target
Fitur bookmark memungkinkan pengguna menyimpan artikel favorit untuk dibaca nanti. Target: pengguna dapat menambah/menghapus bookmark dan melihat daftar artikel yang dibookmark.

## Komponen yang Terlibat
- Bookmark model & migration (polymorphic)
- User model relasi
- BookmarkController
- Livewire bookmark button component
- Halaman daftar bookmark pengguna

## Perintah Artisan CLI
```bash
php artisan make:model Bookmark -m
php artisan make:controller BookmarkController
php artisan make:livewire BookmarkButton
```

### Model
```php
// app/Models/Bookmark.php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Bookmark extends Model
{
    protected $fillable = ['user_id', 'bookmarkable_id', 'bookmarkable_type'];

    public function user()
    {
        return $this->belongsTo(User::class);
    }

    public function bookmarkable()
    {
        return $this->morphTo();
    }
}
```

```php
// app/Models/Article.php (tambahan)
public function bookmarks()
{
    return $this->morphMany(Bookmark::class, 'bookmarkable');
}

public function bookmarkedByUsers()
{
    return $this->belongsToMany(User::class, 'bookmarks', 'bookmarkable_id', 'user_id')
        ->wherePivot('bookmarkable_type', Article::class);
}

public function isBookmarkedBy(User $user)
{
    return $this->bookmarks()->where('user_id', $user->id)->exists();
}
```

```php
// app/Models/User.php (tambahan)
public function bookmarks()
{
    return $this->hasMany(Bookmark::class);
}

public function bookmarkedArticles()
{
    return $this->morphedByMany(Article::class, 'bookmarkable', 'bookmarks');
}
```

### Controller
```php
// app/Http/Controllers/BookmarkController.php
namespace App\Http\Controllers;

use App\Models\Article;
use App\Models\Bookmark;
use Illuminate\Http\Request;

class BookmarkController extends Controller
{
    public function toggle(Article $article)
    {
        $bookmark = Bookmark::where('user_id', auth()->id())
            ->where('bookmarkable_id', $article->id)
            ->where('bookmarkable_type', Article::class)
            ->first();

        if ($bookmark) {
            $bookmark->delete();
            return response()->json(['status' => 'removed']);
        }

        Bookmark::create([
            'user_id' => auth()->id(),
            'bookmarkable_id' => $article->id,
            'bookmarkable_type' => Article::class,
        ]);

        return response()->json(['status' => 'added']);
    }

    public function index()
    {
        $bookmarks = auth()->user()->bookmarks()
            ->where('bookmarkable_type', Article::class)
            ->with('bookmarkable')
            ->latest()
            ->paginate(12);

        return view('bookmarks.index', compact('bookmarks'));
    }
}
```

```php
// app/Livewire/BookmarkButton.php
namespace App\Livewire;

use App\Models\Article;
use Livewire\Component;

class BookmarkButton extends Component
{
    public Article $article;
    public bool $isBookmarked;

    public function mount(Article $article)
    {
        $this->article = $article;
        $this->isBookmarked = auth()->check() && $article->isBookmarkedBy(auth()->user());
    }

    public function toggle()
    {
        if (!auth()->check()) {
            return redirect()->route('login');
        }

        $this->isBookmarked
            ? auth()->user()->bookmarks()->where('bookmarkable_id', $this->article->id)
                ->where('bookmarkable_type', Article::class)->delete()
            : auth()->user()->bookmarks()->create([
                'bookmarkable_id' => $this->article->id,
                'bookmarkable_type' => Article::class,
            ]);

        $this->isBookmarked = !$this->isBookmarked;
    }

    public function render()
    {
        return view('livewire.bookmark-button');
    }
}
```

## Cara Integrasi & Pengujian
1. Jalankan migration `php artisan migrate`
2. Include `livewire:bookmark-button` di halaman detail artikel
3. Uji toggle bookmark dari halaman artikel
4. Akses `/bookmarks` untuk melihat daftar bookmark
5. Pastikan button berubah status saat diklik
