# 302. Mengimplementasikan Scheduled Publishing yaitu Artikel Terbit Otomatis di Waktu Tertentu

## Definisi & Target
Artikel yang dijadwalkan dapat terbit otomatis tanpa intervensi manual menggunakan Laravel scheduler dan queue.

## Komponen yang Terlibat
- Laravel Scheduler (Kernel)
- Queue job untuk publish artikel
- Artikel dengan status scheduled
- Notifikasi setelah publikasi

## Perintah Artisan CLI
```bash
php artisan make:job PublishScheduledArticle
php artisan make:command PublishScheduledArticles
```

## Kode Implementasi (Per File)
```php
// App/Console/Commands/PublishScheduledArticles.php
class PublishScheduledArticles extends Command
{
    protected $signature = 'articles:publish-scheduled';
    protected $description = 'Publish articles that are scheduled';

    public function handle()
    {
        $articles = Article::where('status', ArticleStatus::Scheduled)
            ->where('scheduled_at', '<=', now())
            ->get();

        foreach ($articles as $article) {
            PublishScheduledArticle::dispatch($article);
        }

        $this->info("Dispatched {$articles->count()} articles for publishing.");
    }
}
```

```php
// App/Jobs/PublishScheduledArticle.php
class PublishScheduledArticle implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public Article $article;

    public function __construct(Article $article)
    {
        $this->article = $article;
    }

    public function handle(): void
    {
        $this->article->update([
            'status' => ArticleStatus::Published,
            'published_at' => now()
        ]);
    }
}
```

```php
// App/Console/Kernel.php
protected function schedule(Schedule $schedule): void
{
    $schedule->command('articles:publish-scheduled')->everyMinute();
}
```

## Cara Integrasi & Pengujian
Setel artikel ke status scheduled dengan `scheduled_at` beberapa menit ke depan. Jalankan `php artisan schedule:run` dan verifikasi artikel terbit otomatis.
