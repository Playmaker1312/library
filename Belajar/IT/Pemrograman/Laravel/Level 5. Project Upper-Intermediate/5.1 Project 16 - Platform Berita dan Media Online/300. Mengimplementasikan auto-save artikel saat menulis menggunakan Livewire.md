# 300. Mengimplementasikan Auto-Save Artikel Saat Menulis Menggunakan Livewire

## Definisi & Target
Menyimpan artikel secara otomatis setiap beberapa detik selama penulisan sehingga data tidak hilang saat terjadi error atau koneksi terputus.

## Komponen yang Terlibat
- Livewire component dengan polling
- Debounced form data binding
- Draft revisions (riwayat auto-save)
- Session flash notification

## Perintah Artisan CLI
```bash
php artisan make:livewire ArticleAutoSave
php artisan make:migration create_article_revisions_table
```

## Kode Implementasi (Per File)
```php
// App/Livewire/ArticleAutoSave.php
class ArticleAutoSave extends Component
{
    public Article $article;
    public $title;
    public $body;
    public $excerpt;
    public $lastSaved;
    public $saving = false;

    protected $listeners = ['editorUpdated' => 'autoSave'];
    protected $debounce = '2000ms';

    public function mount(Article $article)
    {
        $this->article = $article;
        $this->title = $article->title;
        $this->body = $article->body;
        $this->excerpt = $article->excerpt;
    }

    public function autoSave()
    {
        $this->saving = true;
        $this->article->update([
            'title' => $this->title,
            'body' => $this->body,
            'excerpt' => Str::limit(strip_tags($this->body), 200),
        ]);
        ArticleRevision::create([
            'article_id' => $this->article->id,
            'body' => $this->body,
            'user_id' => auth()->id()
        ]);
        $this->lastSaved = now();
        $this->saving = false;
    }

    public function render()
    {
        return view('livewire.article-auto-save');
    }
}
```

```php
// Migration article_revisions
Schema::create('article_revisions', function (Blueprint $table) {
    $table->id();
    $table->foreignId('article_id')->constrained()->cascadeOnDelete();
    $table->foreignId('user_id')->constrained();
    $table->longText('body');
    $table->timestamps();
});
```

```html
<!-- resources/views/livewire/article-auto-save.blade.php -->
<div>
    <div class="flex items-center gap-2 text-sm text-gray-500">
        @if($saving)
            <span>Menyimpan...</span>
        @elseif($lastSaved)
            <span>Terakhir disimpan: {{ $lastSaved->diffForHumans() }}</span>
        @endif
    </div>
    <input wire:model.debounce.2000ms="title" type="text" class="w-full text-2xl font-bold border-0 focus:ring-0">
    <div wire:ignore id="editor" class="min-h-[400px]">{!! $body !!}</div>
    <textarea wire:model.defer="body" class="hidden"></textarea>
</div>
```
