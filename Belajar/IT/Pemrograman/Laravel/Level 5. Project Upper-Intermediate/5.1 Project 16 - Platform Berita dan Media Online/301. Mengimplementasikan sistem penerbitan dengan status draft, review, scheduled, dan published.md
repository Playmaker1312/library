# 301. Mengimplementasikan Sistem Penerbitan dengan Status Draft, Review, Scheduled, dan Published

## Definisi & Target
Membangun workflow penerbitan artikel dengan status lifecycle: draft → review → published/scheduled. Setiap status memiliki aturan akses dan aksi yang berbeda.

## Komponen yang Terlibat
- Status enum: draft, review, scheduled, published, archived
- Role-based action (author vs editor)
- Approval workflow
- Schedule queue

## Perintah Artisan CLI
```bash
php artisan make:enum ArticleStatus
php artisan make:notification ArticleSubmittedForReview
php artisan make:livewire ArticleWorkflow
```

## Kode Implementasi (Per File)
```php
// App/Enums/ArticleStatus.php
enum ArticleStatus: string
{
    case Draft = 'draft';
    case Review = 'review';
    case Scheduled = 'scheduled';
    case Published = 'published';
    case Archived = 'archived';

    public function label(): string
    {
        return match($this) {
            self::Draft => 'Draft',
            self::Review => 'Menunggu Review',
            self::Scheduled => 'Terjadwal',
            self::Published => 'Terbit',
            self::Archived => 'Arsip',
        };
    }

    public function canTransitionTo(self $target): bool
    {
        return match($this) {
            self::Draft => in_array($target, [self::Review, self::Archived]),
            self::Review => in_array($target, [self::Draft, self::Published, self::Scheduled]),
            self::Scheduled => $target === self::Published,
            self::Published => $target === self::Archived,
            default => false,
        };
    }
}
```

```php
// Article model
public function submitForReview(): void
{
    $this->status = ArticleStatus::Review;
    $this->save();
    Notification::send(Editor::all(), new ArticleSubmittedForReview($this));
}

public function publish(): void
{
    $this->status = ArticleStatus::Published;
    $this->published_at = now();
    $this->save();
}

public function schedule(Carbon $scheduledAt): void
{
    $this->status = ArticleStatus::Scheduled;
    $this->scheduled_at = $scheduledAt;
    $this->save();
}
```
