# 298. Mengimplementasikan Multi-Author System dengan Profil Penulis yang Lengkap

## Definisi & Target
Membangun sistem penulis ganda di mana setiap penulis memiliki profil lengkap termasuk bio, foto, sosial media, dan statistik artikel.

## Komponen yang Terlibat
- User model dengan role penulis
- AuthorProfile (bio, avatar, social links, expertise)
- Relasi User ke Article
- Halaman profil publik penulis

## Perintah Artisan CLI
```bash
php artisan make:model AuthorProfile -m
php artisan make:controller Front/AuthorController
php artisan make:livewire AuthorStats
```

## Kode Implementasi (Per File)
```php
// Schema author_profiles
Schema::create('author_profiles', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained()->unique();
    $table->string('display_name');
    $table->string('avatar')->nullable();
    $table->text('bio')->nullable();
    $table->string('job_title')->nullable();
    $table->string('facebook_url')->nullable();
    $table->string('twitter_url')->nullable();
    $table->string('instagram_url')->nullable();
    $table->string('linkedin_url')->nullable();
    $table->string('website_url')->nullable();
    $table->timestamps();
});
```

```php
// Model AuthorProfile
class AuthorProfile extends Model
{
    protected $fillable = ['user_id','display_name','avatar','bio','job_title','facebook_url','twitter_url','instagram_url','linkedin_url','website_url'];
    public function user(): BelongsTo { return $this->belongsTo(User::class); }
}
```

```php
// routes/web.php
Route::prefix('author')->name('author.')->group(function () {
    Route::get('/{user:username}', [AuthorController::class, 'show'])->name('show');
    Route::get('/{user:username}/articles', [AuthorController::class, 'articles'])->name('articles');
});
```

## Cara Integrasi & Pengujian
Buat seeder untuk author profiles. Kunjungi route `/author/{username}` untuk melihat profil publik penulis beserta daftar artikelnya.
