# 154. Mengimplementasikan perubahan password dengan verifikasi password lama

## Definisi & Target
Membuat halaman perubahan password yang membutuhkan password lama sebelum dapat diganti dengan password baru.

Target: User harus memasukkan password saat ini sebelum membuat password baru.

## Komponen yang Terlibat
- app/Http/Controllers/Auth/PasswordController
- resources/views/profile/partials/update-password-form.blade.php
- routes/web.php

## Perintah Artisan CLI
```bash
php artisan make:controller Auth/PasswordController
```

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/Auth/PasswordController.php
```php
<?php

namespace App\Http\Controllers\Auth;

use App\Http\Controllers\Controller;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Hash;
use Illuminate\Validation\Rules\Password;

class PasswordController extends Controller
{
    public function update(Request $request): RedirectResponse
    {
        $validated = $request->validateWithBag('updatePassword', [
            'current_password' => ['required', 'current_password'],
            'password' => ['required', Password::defaults(), 'confirmed'],
        ]);

        $request->user()->update([
            'password' => Hash::make($validated['password']),
        ]);

        return back()->with('status', 'password-updated');
    }
}
```

### Routes
File: routes/web.php
```php
Route::middleware('auth')->group(function () {
    Route::put('password', [PasswordController::class, 'update'])->name('password.update');
});
```

## Cara Integrasi & Pengujian
- Akses halaman profile, buka tab Password.
- Masukkan password lama yang salah, pastikan muncul error.
- Masukkan password lama yang benar dengan password baru yang sama.
- Masukkan password baru yang valid dan konfirmasi.
- Logout dan login dengan password baru.
