# 160. Mengimplementasikan activity log untuk mencatat setiap login dan logout

## Definisi & Target
Membuat sistem pencatatan aktivitas (activity log) yang mencatat setiap event login dan logout user beserta informasi IP, user agent, dan timestamp.

Target: Setiap login dan logout tercatat di database dan dapat dilihat oleh user.

## Komponen yang Terlibat
- Migration untuk tabel activity_logs
- App\Models\ActivityLog
- Event: UserLogin, UserLogout
- Listener: LogUserLogin, LogUserLogout
- EventServiceProvider
- app/Http/Controllers/ActivityLogController
- resources/views/profile/partials/activity-log-form.blade.php

## Perintah Artisan CLI
```bash
php artisan make:migration create_activity_logs_table
php artisan make:model ActivityLog
php artisan make:event UserLogin
php artisan make:event UserLogout
php artisan make:listener LogUserLogin --event=UserLogin
php artisan make:listener LogUserLogout --event=UserLogout
php artisan make:controller ActivityLogController
```

### Model
File: app/Models/ActivityLog.php
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;

class ActivityLog extends Model
{
    public $timestamps = false;

    protected $fillable = [
        'user_id',
        'type',
        'ip_address',
        'user_agent',
    ];

    protected $casts = [
        'created_at' => 'datetime',
    ];

    public function user(): BelongsTo
    {
        return $this->belongsTo(User::class);
    }
}
```

```php
namespace App\Providers;

use App\Events\UserLogin;
use App\Events\UserLogout;

use Illuminate\Auth\Listeners\SendEmailVerificationNotification;
use Illuminate\Foundation\Support\Providers\EventServiceProvider as ServiceProvider;

{
    protected $listen = [
        Registered::class => [
            SendEmailVerificationNotification::class,
        ],
        UserLogin::class => [
            LogUserLogin::class,
        ],
        UserLogout::class => [

    {
    }
```

### AuthenticatedSessionController (modifikasi)
File: app/Http/Controllers/Auth/AuthenticatedSessionController.php
```php
<?php

namespace App\Http\Controllers\Auth;

use App\Events\UserLogin;
use App\Events\UserLogout;
use App\Http\Controllers\Controller;
use App\Http\Requests\Auth\LoginRequest;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;
use Illuminate\View\View;

class AuthenticatedSessionController extends Controller
{
    public function create(): View
    {
        return view('auth.login');
    }

    public function store(LoginRequest $request): RedirectResponse
    {
        $request->authenticate();

        $request->session()->regenerate();

        event(new UserLogin(
            $request->user(),
            $request->ip(),
            $request->userAgent()
        ));

        return redirect()->intended(route('dashboard', absolute: false));
    }

    public function destroy(Request $request): RedirectResponse
    {
        $user = $request->user();

        Auth::guard('web')->logout();

        $request->session()->invalidate();
        $request->session()->regenerateToken();

        if ($user) {
            event(new UserLogout(
                $user,
                $request->ip(),
                $request->userAgent()
            ));
        }

        return redirect('/');
    }
}
```

## Cara Integrasi & Pengujian
- Jalankan migration untuk membuat tabel activity_logs.
- Login ke aplikasi, cek database di tabel activity_logs.
- Logout, cek kembali tabel activity_logs.
- Akses halaman `/activity-logs` untuk melihat riwayat login/logout.
- Login dari IP atau perangkat berbeda untuk melihat variasi.
