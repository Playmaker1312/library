# 146. Merencanakan sistem autentikasi dengan register, login, email verification, dan reset password

## Definisi & Target
Membuat roadmap sistem autentikasi lengkap yang mencakup registrasi user baru, login/logout, verifikasi email melalui link, dan reset password via email.

Target: User dapat mendaftar, memverifikasi email, login, dan mereset password jika lupa.

## Komponen yang Terlibat
- Laravel Breeze (scaffolding autentikasi)
- Model User dengan MustVerifyEmail
- Mailtrap untuk mail testing
- Blade + Tailwind CSS untuk UI

## Perintah Artisan CLI
```bash
composer require laravel/breeze --dev
php artisan breeze:install blade
php artisan migrate
npm install && npm run dev
```

## Kode Implementasi (Per File)

### Migration / Model
Tidak ada perubahan besar. Model User sudah ada dari default Laravel.

### Routes
File: routes/auth.php
Tidak perlu dibuat manual karena Breeze sudah menyediakan.

### Controller
Tidak perlu dibuat manual karena Breeze sudah menyediakan RegisteredUserController, AuthenticatedSessionController, dll.

### Blade View
Tidak perlu dibuat manual karena Breeze sudah menyediakan template register, login, forgot-password, reset-password, verify-email.

## Cara Integrasi & Pengujian
- Install Breeze, jalankan migration, lalu akses `/register` untuk mendaftar.
- Cek email verifikasi di Mailtrap.
- Login menggunakan kredensial yang sudah terverifikasi.
- Uji forgot password dengan mengirim email reset.
