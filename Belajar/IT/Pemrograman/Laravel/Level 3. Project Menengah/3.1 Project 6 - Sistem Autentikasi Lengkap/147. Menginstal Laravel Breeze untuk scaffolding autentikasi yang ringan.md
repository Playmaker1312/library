# 147. Menginstal Laravel Breeze untuk scaffolding autentikasi yang ringan

## Definisi & Target
Menginstall Laravel Breeze sebagai starter kit autentikasi minimal yang menyediakan register, login, forgot password, email verification, dan profile management.

Target: Mendapatkan scaffolding autentikasi yang siap pakai dengan Blade + Tailwind.

## Komponen yang Terlibat
- Composer package: laravel/breeze
- NPM packages: Tailwind CSS, Alpine.js
- File scaffolding: Controllers, Views, Routes

## Perintah Artisan CLI
```bash
composer require laravel/breeze --dev
php artisan breeze:install blade
php artisan migrate
npm install
npm run dev
```

## Kode Implementasi (Per File)

### Migration / Model
Tidak ada perubahan tambahan. Breeze tidak menambahkan migration baru.

### Routes
File: routes/auth.php
Breeze akan membuatkan route autentikasi lengkap.

### Controller
Breeze akan membuatkan controller di App\Http\Controllers\Auth\*.

### Blade View
Breeze akan membuatkan view di resources/views/auth/\* dan resources/views/profile/\*.

## Cara Integrasi & Pengujian
- Jalankan `php artisan serve`.
- Buka `/login` atau `/register` di browser.
- Pastikan form tampil dengan styling Tailwind.
- Lakukan registrasi dan login.
