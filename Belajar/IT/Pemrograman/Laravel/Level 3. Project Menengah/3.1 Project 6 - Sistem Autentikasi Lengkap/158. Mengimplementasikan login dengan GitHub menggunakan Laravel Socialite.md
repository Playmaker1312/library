# 158. Mengimplementasikan login dengan GitHub menggunakan Laravel Socialite

## Definisi & Target
Mengintegrasikan login menggunakan akun GitHub melalui OAuth 2.0 dengan Laravel Socialite.

Target: User dapat login/register menggunakan akun GitHub dengan satu klik.

## Komponen yang Terlibat
- Package: laravel/socialite (sudah terinstall)
- config/services.php
- app/Http/Controllers/Auth/SocialiteController
- resources/views/auth/login.blade.php (tambah tombol GitHub)

## Perintah Artisan CLI
Tidak ada perintah tambahan. Socialite sudah terinstall dari poin sebelumnya.

### Controller
File: app/Http/Controllers/Auth/SocialiteController.php (tambah method)
```php
public function redirectToGithub(): RedirectResponse
{
    return Socialite::driver('github')->redirect();
}

public function handleGithubCallback(): RedirectResponse
{
    try {
        $githubUser = Socialite::driver('github')->user();
    } catch (\Exception $e) {
        return redirect()->route('login')->withErrors(['email' => 'GitHub login failed.']);
    }

    $user = User::where('github_id', $githubUser->getId())
                ->orWhere('email', $githubUser->getEmail())
                ->first();

    if (!$user) {
        $user = User::create([
            'name' => $githubUser->getName() ?? $githubUser->getNickname(),
            'email' => $githubUser->getEmail(),
            'password' => Hash::make(Str::random(24)),
            'email_verified_at' => now(),
            'github_id' => $githubUser->getId(),
            'profile_photo_path' => $githubUser->getAvatar(),
        ]);
    } else {
        $user->update([
            'github_id' => $githubUser->getId(),
        ]);
    }

    Auth::login($user, true);

    return redirect()->intended(route('dashboard', absolute: false));
}
```

```php

```

## Cara Integrasi & Pengujian
- Daftarkan OAuth App di GitHub Settings > Developer settings > OAuth Apps.
- Set callback URL ke `http://localhost:8000/auth/github/callback`.
- Isi .env dengan GITHUB_CLIENT_ID dan GITHUB_CLIENT_SECRET.
- Jalankan migration untuk menambah kolom github_id.
- Buka halaman login, klik tombol "Login with GitHub".
- Authorize aplikasi di GitHub.
- User akan login/register otomatis.
