# 157. Mengimplementasikan login dengan Google menggunakan Laravel Socialite

## Definisi & Target
Mengintegrasikan login menggunakan akun Google melalui OAuth 2.0 dengan Laravel Socialite.

Target: User dapat login/register menggunakan akun Google dengan satu klik.

## Komponen yang Terlibat
- Package: laravel/socialite
- config/services.php
- app/Http/Controllers/Auth/SocialiteController
- resources/views/auth/login.blade.php (tambah tombol Google)

## Perintah Artisan CLI
```bash
composer require laravel/socialite
php artisan make:controller Auth/SocialiteController
```

## Kode Implementasi (Per File)

### Config
File: config/services.php
```php
'google' => [
    'client_id' => env('GOOGLE_CLIENT_ID'),
    'client_secret' => env('GOOGLE_CLIENT_SECRET'),
    'redirect' => env('GOOGLE_REDIRECT_URI'),
```

### Controller
File: app/Http/Controllers/Auth/SocialiteController.php
```php
<?php

namespace App\Http\Controllers\Auth;

use App\Http\Controllers\Controller;
use App\Models\User;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;
use Illuminate\Support\Facades\Hash;
use Illuminate\Support\Str;
use Laravel\Socialite\Facades\Socialite;

class SocialiteController extends Controller
{
    public function redirectToGoogle(): RedirectResponse
    {
        return Socialite::driver('google')->redirect();
    }

    public function handleGoogleCallback(): RedirectResponse
    {
        try {
            $googleUser = Socialite::driver('google')->user();
        } catch (\Exception $e) {
            return redirect()->route('login')->withErrors(['email' => 'Google login failed.']);
        }

        $user = User::where('email', $googleUser->getEmail())->first();

        if (!$user) {
            $user = User::create([
                'name' => $googleUser->getName(),
                'email' => $googleUser->getEmail(),
                'password' => Hash::make(Str::random(24)),
                'email_verified_at' => now(),
                'google_id' => $googleUser->getId(),
                'profile_photo_path' => $googleUser->getAvatar(),
            ]);
        } else {
            $user->update([
                'google_id' => $googleUser->getId(),
            ]);
        }

        Auth::login($user, true);

        return redirect()->intended(route('dashboard', absolute: false));
    }
}
```

### Routes
File: routes/web.php
```php
Route::get('auth/google', [SocialiteController::class, 'redirectToGoogle'])->name('auth.google');
Route::get('auth/google/callback', [SocialiteController::class, 'handleGoogleCallback']);
```

## Cara Integrasi & Pengujian
- Daftarkan aplikasi di Google Cloud Console, buat OAuth 2.0 credentials.
- Set redirect URI ke `http://localhost:8000/auth/google/callback`.
- Isi .env dengan GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET.
- Jalankan migration untuk menambah kolom google_id.
- Buka halaman login, klik tombol "Login with Google".
- Pilih akun Google dan authorize.
- User akan login/register otomatis.
