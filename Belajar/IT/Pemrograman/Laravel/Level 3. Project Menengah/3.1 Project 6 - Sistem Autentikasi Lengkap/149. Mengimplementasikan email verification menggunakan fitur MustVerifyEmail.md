# 149. Mengimplementasikan email verification menggunakan fitur MustVerifyEmail

## Definisi & Target
Mengaktifkan fitur verifikasi email agar user harus memverifikasi alamat emailnya sebelum dapat mengakses halaman tertentu.

Target: User yang belum verifikasi email akan diarahkan ke halaman peringatan verifikasi.

## Komponen yang Terlibat
- App\Models\User (implement MustVerifyEmail)
- app/Http/Controllers/Auth/EmailVerificationNotificationController
- app/Http/Controllers/Auth/VerifyEmailController
- resources/views/auth/verify-email.blade.php

## Perintah Artisan CLI
```bash
php artisan make:controller Auth/EmailVerificationController
```

## Kode Implementasi (Per File)

### Model
File: app/Models/User.php
```php
<?php

namespace App\Models;

use Illuminate\Contracts\Auth\MustVerifyEmail;
use Illuminate\Foundation\Auth\User as Authenticatable;
use Illuminate\Notifications\Notifiable;

class User extends Authenticatable implements MustVerifyEmail
{
    use Notifiable;

    protected $fillable = [
        'name',
        'email',
        'password',
    ];

    protected $hidden = [
        'password',
        'remember_token',
    ];

    protected $casts = [
        'email_verified_at' => 'datetime',
        'password' => 'hashed',
    ];
}
```

### Routes
File: routes/auth.php
```php
Route::middleware('auth')->group(function () {
    Route::get('verify-email', [EmailVerificationPromptController::class, '__invoke'])
        ->name('verification.notice');

    Route::get('verify-email/{id}/{hash}', [VerifyEmailController::class, '__invoke'])
        ->middleware(['signed', 'throttle:6,1'])
        ->name('verification.verify');

    Route::post('email/verification-notification', [EmailVerificationNotificationController::class, 'store'])
        ->middleware('throttle:6,1')
        ->name('verification.send');
});
```

### Controller
File: app/Http/Controllers/Auth/EmailVerificationPromptController.php
```php
<?php

namespace App\Http\Controllers\Auth;

use App\Http\Controllers\Controller;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\View\View;

class EmailVerificationPromptController extends Controller
{
    public function __invoke(Request $request): RedirectResponse|View
    {
        return $request->user()->hasVerifiedEmail()
                    ? redirect()->intended(route('dashboard', absolute: false))
                    : view('auth.verify-email');
    }
}
```

## Cara Integrasi & Pengujian
- Pastikan User model mengimplementasikan MustVerifyEmail.
- Daftarkan user baru, akan muncul halaman verifikasi email.
- Cek email di Mailtrap, klik link verifikasi.
- User akan terverifikasi dan bisa mengakses halaman yang diproteksi.
