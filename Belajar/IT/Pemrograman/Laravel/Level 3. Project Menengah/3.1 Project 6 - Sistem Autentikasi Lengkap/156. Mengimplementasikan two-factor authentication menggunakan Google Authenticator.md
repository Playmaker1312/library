# 156. Mengimplementasikan two-factor authentication menggunakan Google Authenticator

## Definisi & Target
Menambahkan lapisan keamanan kedua berupa TOTP (Time-based One-Time Password) menggunakan Google Authenticator.

Target: Setelah login dengan password, user harus memasukkan kode 6 digit dari Google Authenticator.

## Komponen yang Terlibat
- Package: pragmarx/google2fa-laravel
- Package: bacon/bacon-qr-code
- app/Http/Controllers/Auth/TwoFactorController
- resources/views/auth/two-factor-challenge.blade.php
- Migration untuk tabel user_2fa

### Controller
File: app/Http/Controllers/Auth/TwoFactorController.php
```php
<?php

namespace App\Http\Controllers\Auth;

use App\Http\Controllers\Controller;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\View\View;
use PragmaRX\Google2FALaravel\Google2FA;

class TwoFactorController extends Controller
{
    public function showEnable(): View
    {
        $google2fa = app('pragmarx.google2fa');
        $secretKey = $google2fa->generateSecretKey();

        $qrCodeUrl = $google2fa->getQRCodeInline(
            config('app.name'),
            auth()->user()->email,
            $secretKey
        );

        session(['2fa_secret' => $secretKey]);

        return view('auth.two-factor.enable', [
            'qrCodeUrl' => $qrCodeUrl,
            'secretKey' => $secretKey,
        ]);
    }

    public function enable(Request $request): RedirectResponse
    {
        $request->validate([
            'code' => 'required|string|size:6',
        ]);

        $google2fa = app('pragmarx.google2fa');
        $secret = session('2fa_secret');

        $valid = $google2fa->verifyKey($secret, $request->code);

        if (!$valid) {
            return back()->withErrors(['code' => 'Invalid code. Please try again.']);
        }

        auth()->user()->user2fa()->updateOrCreate(
            ['user_id' => auth()->id()],
            [
                'google2fa_secret' => $secret,
                'google2fa_enabled' => true,
            ]
        );

        session()->forget('2fa_secret');

        return redirect()->route('profile.edit')->with('status', '2fa-enabled');
    }

    public function showChallenge(): View
    {
        return view('auth.two-factor-challenge');
    }

    public function challenge(Request $request): RedirectResponse
    {
        $request->validate([
            'code' => 'required|string|size:6',
        ]);

        $user = $request->user();
        $google2fa = app('pragmarx.google2fa');

        $secret = $user->user2fa->google2fa_secret;
        $valid = $google2fa->verifyKey($secret, $request->code);

        if (!$valid) {
            return back()->withErrors(['code' => 'Invalid code.']);
        }

        $request->session()->put('2fa_verified', true);

        return redirect()->intended(route('dashboard'));
    }

    public function disable(Request $request): RedirectResponse
    {
        $request->validate([
            'password' => ['required', 'current_password'],
        ]);

        $request->user()->user2fa()->update([
            'google2fa_secret' => null,
            'google2fa_enabled' => false,
        ]);

        return redirect()->route('profile.edit')->with('status', '2fa-disabled');
    }
}
```

### Middleware
File: app/Http/Middleware/TwoFactorVerify.php
```php
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class TwoFactorVerify
{
    public function handle(Request $request, Closure $next): Response
    {
        if ($request->user() && $request->user()->user2fa?->google2fa_enabled) {
            if (!$request->session()->get('2fa_verified')) {
                return redirect()->route('two-factor.challenge');
            }
        }

        return $next($request);
    }
}
```

### Routes
File: routes/web.php

```php
Route::middleware('auth')->group(function () {
    Route::get('two-factor/enable', [TwoFactorController::class, 'showEnable'])->name('two-factor.enable');
    Route::post('two-factor/enable', [TwoFactorController::class, 'enable']);
    Route::get('two-factor/challenge', [TwoFactorController::class, 'showChallenge'])->name('two-factor.challenge');
    Route::post('two-factor/challenge', [TwoFactorController::class, 'challenge']);
    Route::post('two-factor/disable', [TwoFactorController::class, 'disable'])->name('two-factor.disable');
});
```

## Cara Integrasi & Pengujian
- Jalankan migration untuk tabel user_2fa.
- Buka profile, enable 2FA, scan QR code dengan Google Authenticator.
- Masukkan kode 6 digit dari aplikasi Authenticator.
- Logout dan login kembali, akan diminta kode 2FA.
- Masukkan kode dari Authenticator untuk masuk.
- Nonaktifkan 2FA melalui halaman profile.
