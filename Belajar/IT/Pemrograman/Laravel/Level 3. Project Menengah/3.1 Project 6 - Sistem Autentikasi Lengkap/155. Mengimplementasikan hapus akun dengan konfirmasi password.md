# 155. Mengimplementasikan hapus akun dengan konfirmasi password

## Definisi & Target
Membuat fitur penghapusan akun dimana user harus mengkonfirmasi password sebelum akun dihapus permanent.

Target: User dapat menghapus akun sendiri dengan verifikasi password.

## Komponen yang Terlibat
- app/Http/Controllers/Auth/DeleteUserController
- resources/views/profile/partials/delete-user-form.blade.php
- routes/web.php

## Perintah Artisan CLI
```bash
php artisan make:controller Auth/DeleteUserController
```

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/Auth/DeleteUserController.php
```php
<?php

namespace App\Http\Controllers\Auth;

use App\Http\Controllers\Controller;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;
use Illuminate\Support\Facades\Hash;
use Illuminate\Validation\ValidationException;

class DeleteUserController extends Controller
{
    public function destroy(Request $request): RedirectResponse
    {
        $request->validateWithBag('deleteUser', [
            'password' => ['required', 'current_password'],
        ]);

        $user = $request->user();

        Auth::logout();

        $user->delete();

        $request->session()->invalidate();
        $request->session()->regenerateToken();

        return redirect('/');
    }
}
```

### Routes
File: routes/web.php
```php
Route::middleware('auth')->group(function () {
    Route::delete('profile', [DeleteUserController::class, 'destroy'])->name('profile.destroy');
});
```

## Cara Integrasi & Pengujian
- Akses halaman profile, scroll ke bagian Delete Account.
- Klik "Delete Account", akan muncul modal konfirmasi.
- Masukkan password yang salah, pastikan ada error.
- Masukkan password yang benar, klik Delete Account.
- User akan logout dan diarahkan ke halaman utama.
- Coba login kembali dengan akun yang dihapus, pastikan gagal.
