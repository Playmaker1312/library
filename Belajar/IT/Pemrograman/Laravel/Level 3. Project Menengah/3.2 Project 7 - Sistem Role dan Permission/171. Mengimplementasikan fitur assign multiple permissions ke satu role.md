# 171. Mengimplementasikan fitur assign multiple permissions ke satu role

## Definisi & Target
Memungkinkan super admin untuk meng-assign multiple permissions ke satu role.

Target: Satu role dapat memiliki banyak permission yang dipilih dari daftar.

## Komponen yang Terlibat
- app/Http/Controllers/RoleController (method edit, update)
- resources/views/roles/edit.blade.php

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/RoleController.php
```php
public function edit(Role $role): View
{
    $permissions = Permission::all()->groupBy(function ($p) {
        return explode('-', $p->name)[0];
    });
    $rolePermissions = $role->permissions->pluck('id')->toArray();
    return view('roles.edit', compact('role', 'permissions', 'rolePermissions'));
}

public function update(RoleRequest $request, Role $role): RedirectResponse
{
    $role->update(['name' => $request->name]);
    $role->syncPermissions($request->permissions ?? []);
    return redirect()->route('roles.index')->with('success', 'Role updated.');
}
```

### Blade View
File: resources/views/roles/edit.blade.php
```blade
<div class="mb-4">
    <label class="block text-sm font-medium text-gray-700 mb-2">Permissions</label>
    @foreach ($permissions as $group => $groupPermissions)

            <h4 class="text-sm font-semibold text-gray-800 uppercase mb-2">{{ $group }}</h4>
            <div class="grid grid-cols-2 md:grid-cols-3 gap-2">
                @foreach ($groupPermissions as $permission)
                    <label class="inline-flex items-center">

                            {{ in_array($permission->id, $rolePermissions) ? 'checked' : '' }}

                        <span class="ml-2 text-sm text-gray-600">{{ $permission->name }}</span>
                    </label>
                @endforeach
            </div>
        </div>
    @endforeach
</div>
```
