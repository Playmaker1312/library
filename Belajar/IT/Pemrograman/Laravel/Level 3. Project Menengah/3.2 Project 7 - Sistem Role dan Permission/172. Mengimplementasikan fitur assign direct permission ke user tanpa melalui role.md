# 172. Mengimplementasikan fitur assign direct permission ke user tanpa melalui role

## Definisi & Target
Memberikan permission langsung ke user tertentu tanpa harus melalui role.

Target: User memiliki permission tambahan di luar yang diberikan oleh role-nya.

## Komponen yang Terlibat
- app/Http/Controllers/UserController (modifikasi)
- resources/views/users/edit.blade.php

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/UserController.php
```php
use Spatie\Permission\Models\Permission;

public function edit(User $user): View
{
    $roles = Role::all();
    $userRoles = $user->roles->pluck('id')->toArray();
    $permissions = Permission::all()->groupBy(function ($p) {
        return explode('-', $p->name)[0];
    });
    $directPermissions = $user->getDirectPermissions()->pluck('id')->toArray();

    return view('users.edit', compact('user', 'roles', 'userRoles', 'permissions', 'directPermissions'));
}

public function update(Request $request, User $user): RedirectResponse
{
    $request->validate([
        'name' => 'required|string|max:255',
        'email' => 'required|string|email|max:255|unique:users,email,' . $user->id,
        'roles' => 'nullable|array',
        'roles.*' => 'exists:roles,id',
        'direct_permissions' => 'nullable|array',
        'direct_permissions.*' => 'exists:permissions,id',
    ]);

    $user->update([
        'name' => $request->name,
        'email' => $request->email,
    ]);

    $user->syncRoles($request->roles ?? []);
    $user->syncPermissions($request->direct_permissions ?? []);

    return redirect()->route('users.index')->with('success', 'User updated.');
}
```
