# 164. Membuat seeder untuk roles yaitu super admin, admin, dan user beserta permissions

## Definisi & Target
Membuat database seeder yang mendefinisikan roles (super admin, admin, user) beserta permission masing-masing.

Target: Data awal roles dan permissions langsung tersedia setelah seeder dijalankan.

## Komponen yang Terlibat
- database/seeders/RoleAndPermissionSeeder.php
- database/seeders/DatabaseSeeder.php

## Perintah Artisan CLI
```bash
php artisan make:seeder RoleAndPermissionSeeder
php artisan db:seed --class=RoleAndPermissionSeeder
```

## Kode Implementasi (Per File)

### Seeder
File: database/seeders/RoleAndPermissionSeeder.php
```php
<?php

namespace Database\Seeders;

use Illuminate\Database\Seeder;
use Spatie\Permission\Models\Permission;
use Spatie\Permission\Models\Role;
use Spatie\Permission\PermissionRegistrar;

class RoleAndPermissionSeeder extends Seeder
{
    public function run(): void
    {
        app()[PermissionRegistrar::class]->forgetCachedPermissions();

        $permissionsByRole = [
            'super-admin' => [
                'user-list', 'user-create', 'user-edit', 'user-delete',
                'role-list', 'role-create', 'role-edit', 'role-delete',
                'permission-list', 'permission-create', 'permission-edit', 'permission-delete',
                'course-list', 'course-create', 'course-edit', 'course-delete',
                'lesson-list', 'lesson-create', 'lesson-edit', 'lesson-delete',
                'booking-list', 'booking-create', 'booking-edit', 'booking-delete',
                'report-list', 'report-generate',
                'settings-access',
            ],
            'admin' => [
                'user-list', 'user-create', 'user-edit',
                'role-list',
                'course-list', 'course-create', 'course-edit',
                'lesson-list', 'lesson-create', 'lesson-edit',
                'booking-list', 'booking-edit',
                'report-list', 'report-generate',
            ],
            'user' => [
                'course-list',
                'lesson-list',
                'booking-create', 'booking-list',
            ],
        ];

        $allPermissions = collect($permissionsByRole)->flatten()->unique()->toArray();

        foreach ($allPermissions as $permission) {
            Permission::create(['name' => $permission]);
        }

        foreach ($permissionsByRole as $roleName => $permissions) {
            $role = Role::create(['name' => $roleName]);
            $role->givePermissionTo($permissions);
        }
    }
}
```

## Cara Integrasi & Pengujian
- Buat seeder dengan daftar permission untuk setiap role.
- Jalankan `php artisan db:seed --class=RoleAndPermissionSeeder`.
- Cek database: tabel roles, permissions, role_has_permissions terisi.
- Gunakan tinker untuk verifikasi.
