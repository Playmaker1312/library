# 174. Mengimplementasikan cache untuk permissions menggunakan Redis agar performa optimal

## Definisi & Target
Mengaktifkan caching permission menggunakan Redis untuk mengurangi query database.

Target: Permission dicek dari cache, bukan database, performa lebih cepat.

## Komponen yang Terlibat
- config/permission.php (cache settings)
- config/cache.php (Redis configuration)
- .env

## Perintah Artisan CLI
```bash
composer require predis/predis
```

## Kode Implementasi (Per File)

### Config
File: config/permission.php
```php
'cache' => [
    'expiration_time' => \DateInterval::createFromDateString('24 hours'),
    'key' => 'spatie.permission.cache',
    'store' => 'redis',
],
```

File: .env
```env
CACHE_STORE=redis
REDIS_HOST=127.0.0.1
REDIS_PASSWORD=null
REDIS_PORT=6379
REDIS_CACHE_DB=1
```

File: config/cache.php
```php
'redis' => [
    'driver' => 'redis',
    'connection' => env('REDIS_CACHE_CONNECTION', 'cache'),
    'lock_connection' => env('REDIS_CACHE_LOCK_CONNECTION', 'default'),
],
```

### Seeder (cache reset)
File: database/seeders/RoleAndPermissionSeeder.php
```php
use Spatie\Permission\PermissionRegistrar;

public function run(): void
{
    app()[PermissionRegistrar::class]->forgetCachedPermissions();
    // ... sisanya
}
```

## Cara Integrasi & Pengujian
- Install Redis server.
- Set CACHE_STORE=redis di .env.
- Permission otomatis dicache di Redis.
- Reset cache: `php artisan permission:cache-reset`.
