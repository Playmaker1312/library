# 173. Membuat halaman admin untuk manajemen user, role, dan permission

## Definisi & Target
Membuat halaman dashboard admin terintegrasi untuk mengelola user, role, dan permission.

Target: Super admin memiliki panel kontrol terpusat untuk manajemen RBAC.

## Komponen yang Terlibat
- app/Http/Controllers/AdminController.php
- resources/views/admin/index.blade.php
- resources/views/layouts/admin.blade.php

## Perintah Artisan CLI
```bash
php artisan make:controller AdminController
```

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/AdminController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\User;
use Illuminate\View\View;
use Spatie\Permission\Models\Permission;
use Spatie\Permission\Models\Role;

class AdminController extends Controller
{
    public function index(): View
    {
        $stats = [
            'total_users' => User::count(),
            'total_roles' => Role::count(),
            'total_permissions' => Permission::count(),
        ];

        return view('admin.index', $stats);
    }
}
```

### Routes
File: routes/web.php
```php
Route::middleware(['auth', 'verified', 'role:super-admin'])->group(function () {
    Route::get('/admin', [AdminController::class, 'index'])->name('admin.index');
});
```

## Cara Integrasi & Pengujian
- Akses `/admin` sebagai super admin.
- Lihat statistik user, role, dan permission.
- Klik link untuk navigasi ke manajemen masing-masing.
