# 170. Mengimplementasikan fitur assign multiple roles ke satu user

## Definisi & Target
Memungkinkan admin untuk meng-assign lebih dari satu role ke satu user sekaligus.

Target: Satu user dapat memiliki multiple roles (contoh: admin + editor).

## Komponen yang Terlibat
- app/Http/Controllers/UserController (method edit, update)
- resources/views/users/edit.blade.php

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/UserController.php
```php
public function edit(User $user): View
{
    $roles = Role::all();
    $userRoles = $user->roles->pluck('id')->toArray();
    return view('users.edit', compact('user', 'roles', 'userRoles'));
}

public function update(Request $request, User $user): RedirectResponse
{
    $request->validate([
        'name' => 'required|string|max:255',
        'email' => 'required|string|email|max:255|unique:users,email,' . $user->id,
        'roles' => 'nullable|array',
        'roles.*' => 'exists:roles,id',
    ]);

    $user->update([
        'name' => $request->name,
        'email' => $request->email,
    ]);

    $user->syncRoles($request->roles ?? []);

    return redirect()->route('users.index')->with('success', 'User updated.');
}
```

### Blade View
File: resources/views/users/edit.blade.php
```blade
<div class="mb-4">

```
