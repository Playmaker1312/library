# 169. Mengimplementasikan tampilan kondisional di Blade menggunakan directive can dan cannot

## Definisi & Target
Menggunakan Blade directive `@can`, `@cannot`, `@role`, dan `@hasrole` untuk kontrol tampilan.

Target: Tampilan beradaptasi secara otomatis berdasarkan role/permission user yang login.

## Komponen yang Terlibat
- resources/views/layouts/navigation.blade.php
- resources/views/*.blade.php (semua view)

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

### Blade View
File: resources/views/layouts/navigation.blade.php
```blade
<nav x-data="{ open: false }" class="bg-white border-b border-gray-100">
    <div class="max-w-7xl mx-auto px-4 sm:px-6 lg:px-8">
        <div class="flex justify-between h-16">
            <div class="flex">
                <div class="shrink-0 flex items-center">
                    <a href="{{ route('dashboard') }}">
                        <x-application-logo class="block h-9 w-auto fill-current text-gray-800" />
                    </a>
                </div>
                <div class="hidden space-x-8 sm:-my-px sm:ms-10 sm:flex">
                    <x-nav-link :href="route('dashboard')" :active="request()->routeIs('dashboard')">
                        {{ __('Dashboard') }}
                    </x-nav-link>
                    @can('course-list')
                        <x-nav-link :href="route('courses.index')" :active="request()->routeIs('courses.*')">
                            {{ __('Courses') }}
                        </x-nav-link>
                    @endcan
                    @can('user-list')
                        <x-nav-link :href="route('users.index')" :active="request()->routeIs('users.*')">
                            {{ __('Users') }}
                        </x-nav-link>
                    @endcan
                    @role('super-admin')
                        <x-nav-link :href="route('roles.index')" :active="request()->routeIs('roles.*')">
                            {{ __('Roles') }}
                        </x-nav-link>
                        <x-nav-link :href="route('permissions.index')" :active="request()->routeIs('permissions.*')">
                            {{ __('Permissions') }}
                        </x-nav-link>
                    @endrole
                    @hasrole(['super-admin', 'admin'])
                        <x-nav-link :href="route('reports.index')" :active="request()->routeIs('reports.*')">
                            {{ __('Reports') }}
                        </x-nav-link>
                    @endhasrole
                </div>
            </div>
        </div>
    </div>
</nav>
```

### Contoh di View Lain
File: resources/views/courses/index.blade.php
```blade
@forelse ($courses as $course)
    <div class="mb-4 p-4 border rounded-lg">
        <h3 class="text-lg font-semibold">{{ $course->title }}</h3>
        <p class="text-sm text-gray-600">{{ $course->description }}</p>
        <div class="mt-2 flex gap-2">
            <a href="{{ route('courses.show', $course) }}" class="text-indigo-600">View</a>
            @can('course-edit')
                <a href="{{ route('courses.edit', $course) }}" class="text-yellow-600">Edit</a>
            @endcan
            @can('course-delete')
                <form action="{{ route('courses.destroy', $course) }}" method="POST" class="inline">
                    @csrf @method('DELETE')
                    <button type="submit" class="text-red-600">Delete</button>
                </form>
            @endcan
        </div>
    </div>
@empty
    <p class="text-gray-500">No courses found.</p>
@endforelse
```

## Cara Integrasi & Pengujian
- Login sebagai super admin, semua menu muncul.
- Login sebagai admin, menu Roles dan Permissions tidak muncul.
- Login sebagai user biasa, hanya menu Dashboard.
- Tombol Edit/Delete hanya muncul sesuai permission.
