# 218. Mengimplementasikan pencarian global di seluruh forum menggunakan Scout

## Definisi & Target
Mengimplementasikan pencarian full-text di forum menggunakan Laravel Scout dengan driver database.

Target: User dapat mencari thread berdasarkan judul dan konten.

## Komponen yang Terlibat
- Package: laravel/scout
- app/Models/Thread (Searchable trait)
- app/Http/Controllers/ForumSearchController.php

## Perintah Artisan CLI
```bash
composer require laravel/scout
php artisan vendor:publish --provider="Laravel\Scout\ScoutServiceProvider"
php artisan make:controller ForumSearchController
```

### Model
File: app/Models/Thread.php
```php
use Laravel\Scout\Searchable;

class Thread extends Model
{
    use Searchable, SoftDeletes;

    public function toSearchableArray(): array
    {
        return [
            'id' => $this->id,
            'title' => $this->title,
            'body' => strip_tags($this->body),
            'user_name' => $this->user->name,
            'category_name' => $this->category->name,
            'created_at' => $this->created_at->timestamp,
        ];
    }
}
```

### Controller
File: app/Http/Controllers/ForumSearchController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\Thread;
use Illuminate\Http\Request;
use Illuminate\View\View;

class ForumSearchController extends Controller
{
    public function search(Request $request): View
    {
        $request->validate([
            'q' => 'required|string|min:2|max:100',
        ]);

        $query = $request->q;

        $threads = Thread::search($query)
            ->query(fn($q) => $q->with(['user', 'category'])->withCount('posts', 'likes'))
            ->paginate(20);

        $threads->appends(['q' => $query]);

        return view('forum.search', compact('threads', 'query'));
    }
}
```
