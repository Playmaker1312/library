# 216. Mengimplementasikan fitur bookmark thread untuk disimpan user

## Definisi & Target
Membuat fitur bookmark dimana user dapat menyimpan thread favorit.

Target: User dapat menandai thread sebagai bookmark dan melihatnya di halaman khusus.

## Komponen yang Terlibat
- app/Http/Controllers/ForumBookmarkController.php
- app/Models/Bookmark
- resources/views/forum/bookmarks.blade.php

## Perintah Artisan CLI
```bash
php artisan make:controller ForumBookmarkController
```

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/ForumBookmarkController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\Bookmark;
use App\Models\Thread;
use Illuminate\Http\RedirectResponse;
use Illuminate\View\View;

class ForumBookmarkController extends Controller
{
    public function index(): View
    {
        $bookmarks = Bookmark::with('thread.user', 'thread.category')
            ->where('user_id', auth()->id())
            ->latest()
            ->get();

        return view('forum.bookmarks', compact('bookmarks'));
    }

    public function toggle(Thread $thread): RedirectResponse
    {
        $existing = Bookmark::where('user_id', auth()->id())
            ->where('thread_id', $thread->id)
            ->first();

        if ($existing) {
            $existing->delete();
            $message = 'Bookmark removed.';
        } else {
            Bookmark::create([
                'user_id' => auth()->id(),
                'thread_id' => $thread->id,
            ]);
            $message = 'Thread bookmarked.';
        }

        return back()->with('success', $message);
    }
}
```

### Routes
File: routes/web.php
```php
Route::middleware(['auth'])->prefix('forum')->name('forum.')->group(function () {
    Route::get('bookmarks', [ForumBookmarkController::class, 'index'])->name('bookmarks.index');
    Route::post('threads/{thread}/bookmark', [ForumBookmarkController::class, 'toggle'])->name('bookmarks.toggle');
});
```

## Cara Integrasi & Pengujian
- Buka thread, klik bookmark.
- Thread tersimpan, icon berubah.
- Akses `/forum/bookmarks`, lihat thread tersimpan.
- Klik remove, thread dihapus dari bookmark.
- Bookmark thread yang sama untuk toggle.
