# 209. Mengimplementasikan thread creation dengan editor teks kaya dan tag

## Definisi & Target
Membuat halaman pembuatan thread dengan editor teks kaya (Trix Editor) dan input tag.

Target: User dapat membuat thread dengan konten rich text dan tag.

## Komponen yang Terlibat
- app/Http/Controllers/ForumThreadController.php
- resources/views/forum/threads/create.blade.php
- resources/views/forum/threads/show.blade.php

## Perintah Artisan CLI
```bash
php artisan make:controller ForumThreadController --resource --model=Thread
```

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/ForumThreadController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\ForumCategory;
use App\Models\Thread;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\View\View;

class ForumThreadController extends Controller
{
    public function index(Request $request): View
    {
        $query = Thread::with(['user', 'category', 'posts'])
            ->withCount('posts', 'likes');

        if ($request->filled('category')) {
            $query->where('forum_category_id', $request->category);
        }

        $threads = $query->latest()->paginate(20);
        $categories = ForumCategory::where('is_active', true)->get();

        return view('forum.threads.index', compact('threads', 'categories'));
    }

    public function show(Thread $thread): View
    {
        $thread->load(['user', 'category', 'posts.user', 'posts.replies.user', 'posts.likes']);
        $thread->loadCount('likes');

        $posts = $thread->posts()->whereNull('parent_id')
            ->with(['user', 'replies.user', 'likes'])
            ->oldest()
            ->get();

        return view('forum.threads.show', compact('thread', 'posts'));
    }

    public function create(): View
    {
        $categories = ForumCategory::where('is_active', true)->get();

        return view('forum.threads.create', compact('categories'));
    }

    public function store(Request $request): RedirectResponse
    {
        $request->validate([
            'forum_category_id' => 'required|exists:forum_categories,id',
            'title' => 'required|string|max:255',
            'body' => 'required|string',
            'tags' => 'nullable|string',
        ]);

        $thread = Thread::create([
            'forum_category_id' => $request->forum_category_id,
            'user_id' => auth()->id(),
            'title' => $request->title,
            'body' => $request->body,
        ]);

        return redirect()->route('forum.threads.show', $thread)
            ->with('success', 'Thread created successfully.');
    }
}
```

### Routes
File: routes/web.php
```php
Route::prefix('forum')->name('forum.')->group(function () {
    Route::get('/', [ForumThreadController::class, 'index'])->name('index');
    Route::get('threads/create', [ForumThreadController::class, 'create'])->name('threads.create');
    Route::post('threads', [ForumThreadController::class, 'store'])->name('threads.store');
    Route::get('threads/{thread}', [ForumThreadController::class, 'show'])->name('threads.show');
});
```

## Cara Integrasi & Pengujian
- Akses `/forum/threads/create`, buat thread dengan Trix editor.
- Submit thread, lihat di halaman forum.
- Buka thread yang baru dibuat.
- Cek body thread ditampilkan dengan format rich text.
