# 210. Mengimplementasikan sistem reply nested untuk diskusi bertingkat

## Definisi & Target
Membuat sistem reply bertingkat (nested) untuk diskusi dalam thread.

Target: User dapat reply ke post lain, membentuk diskusi bertingkat.

## Komponen yang Terlibat
- app/Http/Controllers/ForumPostController.php
- resources/views/forum/threads/show.blade.php

## Perintah Artisan CLI
```bash
php artisan make:controller ForumPostController
```

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/ForumPostController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\Post;
use App\Models\Thread;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;

class ForumPostController extends Controller
{
    public function store(Request $request, Thread $thread): RedirectResponse
    {
        $request->validate([
            'body' => 'required|string',
            'parent_id' => 'nullable|exists:posts,id',
        ]);

        if ($thread->is_locked) {
            return back()->with('error', 'This thread is locked.');
        }

        Post::create([
            'thread_id' => $thread->id,
            'user_id' => auth()->id(),
            'parent_id' => $request->parent_id,
            'body' => $request->body,
        ]);

        return redirect()->route('forum.threads.show', $thread)
            ->with('success', 'Reply posted.');
    }

    public function destroy(Post $post): RedirectResponse
    {
        $this->authorize('delete', $post);

        $post->delete();

        return back()->with('success', 'Post deleted.');
    }
}
```

### Routes
File: routes/web.php
```php
Route::middleware(['auth'])->prefix('forum')->name('forum.')->group(function () {
    Route::post('threads/{thread}/posts', [ForumPostController::class, 'store'])->name('posts.store');
    Route::delete('posts/{post}', [ForumPostController::class, 'destroy'])->name('posts.destroy');
});
```

## Cara Integrasi & Pengujian
- Buka thread, buat reply baru.
- Reply ke reply lain (nested).
- Lihat diskusi bertingkat.
- Cek thread locked, reply tidak bisa ditambahkan.
