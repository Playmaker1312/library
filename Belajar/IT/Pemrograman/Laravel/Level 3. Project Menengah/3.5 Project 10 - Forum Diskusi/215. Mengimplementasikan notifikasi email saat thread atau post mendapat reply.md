# 215. Mengimplementasikan notifikasi email saat thread atau post mendapat reply

## Definisi & Target
Mengirim notifikasi email ke pembuat thread ketika ada reply baru.

Target: User mendapat email saat thread-nya di-reply.

## Komponen yang Terlibat
- app/Notifications/ThreadReplied.php
- app/Notifications/PostReplied.php

## Perintah Artisan CLI
```bash
php artisan make:notification ThreadReplied
php artisan make:notification PostReplied
```

## Kode Implementasi (Per File)

### Notification Thread Replied
File: app/Notifications/ThreadReplied.php
```php
<?php

namespace App\Notifications;

use App\Models\Post;
use App\Models\Thread;
use Illuminate\Bus\Queueable;
use Illuminate\Notifications\Messages\MailMessage;
use Illuminate\Notifications\Notification;

class ThreadReplied extends Notification
{
    use Queueable;

    public Thread $thread;
    public Post $post;

    public function __construct(Thread $thread, Post $post)
    {
        $this->thread = $thread;
        $this->post = $post;
    }

    public function via($notifiable): array
    {
        return ['mail', 'database'];
    }

    public function toMail($notifiable): MailMessage
    {
        return (new MailMessage)
            ->subject('New reply to your thread: ' . $this->thread->title)
            ->greeting('Hello ' . $notifiable->name . '!')
            ->line("{$this->post->user->name} replied to your thread \"{$this->thread->title}\"")
            ->line(strip_tags($this->post->body))
            ->action('View Thread', route('forum.threads.show', $this->thread))
            ->line('Thank you for using our forum!');
    }

    public function toArray($notifiable): array
    {
        return [
            'type' => 'thread_reply',
            'thread_id' => $this->thread->id,
            'thread_title' => $this->thread->title,
            'post_id' => $this->post->id,
            'user_name' => $this->post->user->name,
        ];
    }
}
```

### Notification Post Replied
File: app/Notifications/PostReplied.php
```php
<?php

namespace App\Notifications;

use App\Models\Post;
use Illuminate\Bus\Queueable;
use Illuminate\Notifications\Messages\MailMessage;
use Illuminate\Notifications\Notification;

class PostReplied extends Notification
{
    use Queueable;

    public Post $post;
    public Post $reply;

    public function __construct(Post $post, Post $reply)
    {
        $this->post = $post;
        $this->reply = $reply;
    }

    public function via($notifiable): array
    {
        return ['mail', 'database'];
    }

    public function toMail($notifiable): MailMessage
    {
        return (new MailMessage)
            ->subject('New reply to your post')
            ->line("{$this->reply->user->name} replied to your post in \"{$this->post->thread->title}\"")
            ->action('View Reply', route('forum.threads.show', $this->post->thread) . '#post-' . $this->reply->id)
            ->line('Thank you for using our forum!');
    }

    public function toArray($notifiable): array
    {
        return [
            'type' => 'post_reply',
            'thread_id' => $this->post->thread_id,
            'post_id' => $this->post->id,
            'reply_id' => $this->reply->id,
            'user_name' => $this->reply->user->name,
        ];
    }
}
```

### Controller (send notification)
File: app/Http/Controllers/ForumPostController.php
```php
use App\Notifications\ThreadReplied;
use App\Notifications\PostReplied;

public function store(Request $request, Thread $thread): RedirectResponse
{
    $request->validate([
        'body' => 'required|string',
        'parent_id' => 'nullable|exists:posts,id',
    ]);

    if ($thread->is_locked) {
        return back()->with('error', 'Thread is locked.');
    }

    $post = Post::create([
        'thread_id' => $thread->id,
        'user_id' => auth()->id(),
        'parent_id' => $request->parent_id,
        'body' => $request->body,
    ]);

    $this->processMentions($post);

    if ($post->parent_id) {
        $parentPost = Post::find($post->parent_id);
        if ($parentPost && $parentPost->user_id !== auth()->id()) {
            $parentPost->user->notify(new PostReplied($parentPost, $post));
        }
    }

    if ($thread->user_id !== auth()->id()) {
        $thread->user->notify(new ThreadReplied($thread, $post));
    }

    return redirect()->route('forum.threads.show', $thread)
        ->with('success', 'Reply posted.');
}
```

## Cara Integrasi & Pengujian
- Buat thread sebagai user A.
- Reply thread sebagai user B.
- User A mendapat notifikasi email dan database.
- Buka notifikasi dropdown, lihat notifikasi baru.
- Klik notifikasi, diarahkan ke thread.
