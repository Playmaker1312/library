# 220. Membuat halaman profil user dengan statistik aktivitas forum

## Definisi & Target
Membuat halaman profil user yang menampilkan statistik aktivitas forum dan reputasi.

Target: User dan pengunjung dapat melihat profil forum user lain.

## Komponen yang Terlibat
- app/Http/Controllers/ForumProfileController.php
- resources/views/forum/profile.blade.php

## Perintah Artisan CLI
```bash
php artisan make:controller ForumProfileController
```

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/ForumProfileController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\User;
use Illuminate\View\View;

class ForumProfileController extends Controller
{
    public function show(User $user): View
    {
        $stats = [
            'total_threads' => $user->threads()->count(),
            'total_posts' => $user->posts()->count(),
            'total_likes_given' => $user->likes()->count(),
            'total_likes_received' => $user->threads()->withCount('likes')->get()->sum('likes_count')
                + $user->posts()->withCount('likes')->get()->sum('likes_count'),
            'total_reputation' => $user->total_reputation,
            'badge' => $user->reputation_badge,
            'best_answers' => $user->posts()->where('is_best_answer', true)->count(),
            'member_since' => $user->created_at->format('M Y'),
        ];

        $recentThreads = $user->threads()
            ->with('category')
            ->withCount('posts', 'likes')
            ->latest()
            ->take(5)
            ->get();

        $recentPosts = $user->posts()
            ->with('thread')
            ->latest()
            ->take(5)
            ->get();

        $reputationHistory = $user->reputations()
            ->latest()
            ->take(20)
            ->get();

        return view('forum.profile', compact('user', 'stats', 'recentThreads', 'recentPosts', 'reputationHistory'));
    }
}
```

### User model (tambah relasi)
File: app/Models/User.php
```php
public function threads(): HasMany
{
    return $this->hasMany(Thread::class);
}

public function posts(): HasMany
{
    return $this->hasMany(Post::class);
}

public function likes(): HasMany
{
    return $this->hasMany(Like::class);
}

public function reputations(): HasMany
{
    return $this->hasMany(UserReputation::class);
}

public function getTotalReputationAttribute(): int
{
    return $this->reputations()->sum('points');
}

public function getReputationBadgeAttribute(): string
{
    $points = $this->total_reputation;
    if ($points >= 1000) return 'Platinum';
    if ($points >= 500) return 'Gold';
    if ($points >= 200) return 'Silver';
    if ($points >= 50) return 'Bronze';
    return 'New Member';
}
```

## Cara Integrasi & Pengujian
- Klik username di thread atau post.
- Lihat halaman profil dengan statistik.
- Cek reputasi dan badge.
- Lihat recent threads dan posts.
- Lihat reputation history.
- Klik thread atau post dari profil.
