# 214. Mengimplementasikan fitur mention user menggunakan at symbol dalam post

## Definisi & Target
Membuat fitur mention user dengan `@username` yang akan mengirim notifikasi ke user yang disebut.

Target: User dapat mention user lain dan mendapat notifikasi.

## Komponen yang Terlibat
- app/Notifications/UserMentioned.php
- app/Http/Controllers/ForumPostController (parse mentions)
- resources/views/forum/threads/show.blade.php

## Perintah Artisan CLI
```bash
php artisan make:notification UserMentioned
```

## Kode Implementasi (Per File)

### Notification
File: app/Notifications/UserMentioned.php
```php
<?php

namespace App\Notifications;

use App\Models\Post;
use App\Models\Thread;
use Illuminate\Bus\Queueable;
use Illuminate\Notifications\Messages\MailMessage;
use Illuminate\Notifications\Notification;

class UserMentioned extends Notification
{
    use Queueable;

    public Post $post;
    public Thread $thread;

    public function __construct(Post $post)
    {
        $this->post = $post;
        $this->thread = $post->thread;
    }

    public function via($notifiable): array
    {
        return ['mail', 'database'];
    }

    public function toMail($notifiable): MailMessage
    {
        return (new MailMessage)
            ->subject('You were mentioned in a forum post')
            ->line("{$this->post->user->name} mentioned you in a thread: {$this->thread->title}")
            ->action('View Thread', route('forum.threads.show', $this->thread))
            ->line('Thank you for being active in the forum!');
    }

    public function toArray($notifiable): array
    {
        return [
            'thread_id' => $this->thread->id,
            'thread_title' => $this->thread->title,
            'post_id' => $this->post->id,
            'mentioned_by' => $this->post->user->name,
        ];
    }
}
```

### Controller (parse mentions)
File: app/Http/Controllers/ForumPostController.php
```php
use App\Notifications\UserMentioned;
use App\Models\User;

public function store(Request $request, Thread $thread): RedirectResponse
{
    $request->validate([
        'body' => 'required|string',
        'parent_id' => 'nullable|exists:posts,id',
    ]);

    if ($thread->is_locked) {
        return back()->with('error', 'Thread is locked.');
    }

    $post = Post::create([
        'thread_id' => $thread->id,
        'user_id' => auth()->id(),
        'parent_id' => $request->parent_id,
        'body' => $request->body,
    ]);

    $this->processMentions($post);

    return redirect()->route('forum.threads.show', $thread)
        ->with('success', 'Reply posted.');
}

protected function processMentions(Post $post): void
{
    preg_match_all('/@(\w+)/', $post->body, $matches);

    if (empty($matches[1])) {
        return;
    }

    $usernames = array_unique($matches[1]);

    $users = User::whereIn('name', $usernames)
        ->where('id', '!=', $post->user_id)
        ->get();

    foreach ($users as $user) {
        $user->notify(new UserMentioned($post));
    }
}
```

### Helper untuk render mentions di view
File: app/helpers.php (atau di AppServiceProvider)
```php
if (!function_exists('renderBody')) {
    function renderBody(string $body): string
    {
        $body = htmlspecialchars($body);

        $body = preg_replace(
            '/@(\w+)/',
            '<a href="' . route('forum.index') . '/profile/$1" class="text-indigo-600 hover:underline">@$1</a>',
            $body
        );

        return nl2br($body);
    }
}
```
