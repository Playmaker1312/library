# 206. Merencanakan fitur forum yaitu kategori, thread, post, reply, like, dan reputasi

## Definisi & Target
Merancang arsitektur forum diskusi dengan kategori, thread, post, reply, like, bookmark, dan reputasi.

Target: Forum diskusi fungsional dengan fitur komunitas lengkap.

## Komponen yang Terlibat
- Migration: forum_categories, threads, posts, likes, bookmarks, user_reputation
- Model: ForumCategory, Thread, Post, Like, Bookmark, UserReputation
- Package: laravel/scout (search)
- Package: livewire (infinite scroll)

## Perintah Artisan CLI
```bash
composer require laravel/scout
composer require livewire/livewire
```

## Kode Implementasi (Per File)

### Migration / Model
Enam tabel utama dengan relasi polymorphic untuk likes.

### Routes
Route resource forum dengan nested thread dan post.

### Controller
Controller untuk kategori, thread, post.

Halaman forum, thread, profil user.
