# 212. Mengimplementasikan fitur mark as best answer pada thread pertanyaan

## Definisi & Target
Membuat fitur dimana pembuat thread dapat menandai post sebagai jawaban terbaik.

Target: Post tertentu ditandai sebagai best answer di thread pertanyaan.

## Komponen yang Terlibat
- app/Http/Controllers/ForumPostController (markAsBestAnswer)
- app/Models/Thread (has_best_answer)
- app/Models/Post (is_best_answer)

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/ForumPostController.php
```php
public function markAsBestAnswer(Post $post): RedirectResponse
{
    $thread = $post->thread;

    if ($thread->user_id !== auth()->id()) {
        return back()->with('error', 'Only the thread author can mark best answer.');
    }

    if ($post->user_id === auth()->id()) {
        return back()->with('error', 'You cannot mark your own post as best answer.');
    }

    Post::where('thread_id', $thread->id)
        ->where('is_best_answer', true)
        ->update(['is_best_answer' => false]);

    $post->update(['is_best_answer' => true]);
    $thread->update(['has_best_answer' => true]);

    return back()->with('success', 'Best answer marked.');
}

public function unmarkBestAnswer(Thread $thread): RedirectResponse
{
    if ($thread->user_id !== auth()->id()) {
        return back()->with('error', 'Unauthorized.');
    }

    Post::where('thread_id', $thread->id)
        ->where('is_best_answer', true)
        ->update(['is_best_answer' => false]);

    $thread->update(['has_best_answer' => false]);

    return back()->with('success', 'Best answer removed.');
}
```

### Routes
File: routes/web.php
```php
Route::middleware(['auth'])->prefix('forum')->name('forum.')->group(function () {
    Route::post('posts/{post}/best-answer', [ForumPostController::class, 'markAsBestAnswer'])->name('posts.best-answer');
    Route::delete('threads/{thread}/best-answer', [ForumPostController::class, 'unmarkBestAnswer'])->name('threads.unmark-best-answer');
});
```

## Cara Integrasi & Pengujian
- Buat thread sebagai user A.
- Buat reply sebagai user B.
- Login sebagai user A, klik "Mark as Best Answer" pada post user B.
- Post user B ditandai "Best Answer".
- Thread memiliki badge "has best answer".
- Hapus best answer jika perlu.
