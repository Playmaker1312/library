# 213. Mengimplementasikan sistem reputasi user berdasarkan aktivitas di forum

## Definisi & Target
Membuat sistem reputasi yang memberikan poin untuk setiap aktivitas positif di forum.

Target: User mendapat poin reputasi untuk membuat thread, reply, mendapat like, best answer.

## Komponen yang Terlibat
- app/Models/UserReputation.php
- app/Listeners/AwardReputation.php
- app/Providers/EventServiceProvider.php

## Perintah Artisan CLI
```bash
php artisan make:listener AwardReputation
```

## Kode Implementasi (Per File)

### Listener
File: app/Listeners/AwardReputation.php
```php
<?php

namespace App\Listeners;

use App\Models\UserReputation;

class AwardReputation
{
    public const POINTS = [
        'created_thread' => 10,
        'created_post' => 5,
        'received_like' => 3,
        'given_like' => 1,
        'best_answer' => 15,
    ];

    public function handle($event): void
    {
        $method = 'on' . class_basename($event);

        if (method_exists($this, $method)) {
            $this->$method($event);
        }
    }

    public function onThreadCreated($event): void
    {
        $this->award($event->thread->user_id, 'created_thread', $event->thread, self::POINTS['created_thread']);
    }

    public function onPostCreated($event): void
    {
        $this->award($event->post->user_id, 'created_post', $event->post, self::POINTS['created_post']);
    }

    public function onLikeGiven($event): void
    {
        $this->award($event->user_id, 'given_like', $event->likeable, self::POINTS['given_like']);

        if ($event->likeable->user_id !== $event->user_id) {
            $this->award($event->likeable->user_id, 'received_like', $event->likeable, self::POINTS['received_like']);
        }
    }

    public function onBestAnswerMarked($event): void
    {
        $this->award($event->post->user_id, 'best_answer', $event->post, self::POINTS['best_answer']);
    }

    protected function award(int $userId, string $action, $related, int $points): void
    {
        UserReputation::create([
            'user_id' => $userId,
            'points' => $points,
            'action' => $action,
            'related_id' => $related->id,
            'related_type' => get_class($related),
        ]);
    }
}
```

### Event Service Provider
File: app/Providers/EventServiceProvider.php
```php
<?php

namespace App\Providers;

use App\Events\BestAnswerMarked;
use App\Events\LikeGiven;
use App\Events\PostCreated;
use App\Events\ThreadCreated;
use App\Listeners\AwardReputation;
use Illuminate\Foundation\Support\Providers\EventServiceProvider as ServiceProvider;

class EventServiceProvider extends ServiceProvider
{
    protected $listen = [
        ThreadCreated::class => [AwardReputation::class],
        PostCreated::class => [AwardReputation::class],
        LikeGiven::class => [AwardReputation::class],
        BestAnswerMarked::class => [AwardReputation::class],
    ];
}
```

### Model User (tambah aksesori)
File: app/Models/User.php
```php
public function reputations(): HasMany
{
    return $this->hasMany(UserReputation::class);
}

public function getTotalReputationAttribute(): int
{
    return $this->reputations()->sum('points');
}

public function getReputationBadgeAttribute(): string
{
    $points = $this->total_reputation;

    if ($points >= 1000) return 'Platinum';
    if ($points >= 500) return 'Gold';
    if ($points >= 200) return 'Silver';
    if ($points >= 50) return 'Bronze';

    return 'New Member';
}
```

## Cara Integrasi & Pengujian
- Buat thread, cek reputasi user bertambah 10.
- Buat reply, cek reputasi bertambah 5.
- Like post orang lain, reputasi pemberi like +1, penerima +3.
- Tandai best answer, reputasi penulis post +15.
- Cek badge reputasi di profil user.
