# 217. Mengimplementasikan moderasi forum yaitu lock, pin, dan move thread

## Definisi & Target
Membuat fitur moderasi untuk admin: mengunci thread, menyematkan thread, dan memindahkan kategori.

Target: Admin dapat memoderasi thread sesuai kebutuhan.

## Komponen yang Terlibat
- app/Http/Controllers/ForumModerationController.php
- resources/views/forum/threads/show.blade.php (admin panel)

## Perintah Artisan CLI
```bash
php artisan make:controller ForumModerationController
```

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/ForumModerationController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\ForumCategory;
use App\Models\Thread;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\View\View;

class ForumModerationController extends Controller
{
    public function __construct()
    {
        $this->middleware('role:super-admin|admin');
    }

    public function togglePin(Thread $thread): RedirectResponse
    {
        $thread->update(['is_pinned' => !$thread->is_pinned]);

        $status = $thread->is_pinned ? 'pinned' : 'unpinned';

        return back()->with('success', "Thread {$status}.");
    }

    public function toggleLock(Thread $thread): RedirectResponse
    {
        $thread->update(['is_locked' => !$thread->is_locked]);

        $status = $thread->is_locked ? 'locked' : 'unlocked';

        return back()->with('success', "Thread {$status}.");
    }

    public function showMoveForm(Thread $thread): View
    {
        $categories = ForumCategory::where('is_active', true)
            ->where('id', '!=', $thread->forum_category_id)
            ->get();

        return view('forum.moderation.move', compact('thread', 'categories'));
    }

    public function move(Request $request, Thread $thread): RedirectResponse
    {
        $request->validate([
            'forum_category_id' => 'required|exists:forum_categories,id',
        ]);

        $thread->update(['forum_category_id' => $request->forum_category_id]);

        return redirect()->route('forum.threads.show', $thread)
            ->with('success', 'Thread moved to new category.');
    }

    public function deleteThread(Thread $thread): RedirectResponse
    {
        $thread->delete();

        return redirect()->route('forum.index')
            ->with('success', 'Thread deleted.');
    }
}
```

### Policy
File: app/Policies/ThreadPolicy.php
```php
<?php

namespace App\Policies;

use App\Models\Thread;
use App\Models\User;

class ThreadPolicy
{
    public function moderate(User $user): bool
    {
        return $user->hasRole(['super-admin', 'admin']);
    }

    public function delete(User $user, Thread $thread): bool
    {
        return $user->id === $thread->user_id || $user->hasRole(['super-admin', 'admin']);
    }
}
```

### Routes
File: routes/web.php
```php
Route::middleware(['auth', 'role:super-admin|admin'])->prefix('forum')->name('forum.moderation.')->group(function () {
    Route::patch('threads/{thread}/pin', [ForumModerationController::class, 'togglePin'])->name('pin');
    Route::patch('threads/{thread}/lock', [ForumModerationController::class, 'toggleLock'])->name('lock');
    Route::get('threads/{thread}/move', [ForumModerationController::class, 'showMoveForm'])->name('move');
    Route::patch('threads/{thread}/move', [ForumModerationController::class, 'move']);
    Route::delete('threads/{thread}', [ForumModerationController::class, 'deleteThread'])->name('delete');
});
```

## Cara Integrasi & Pengujian
- Login sebagai admin, buka thread.
- Klik "Pin", thread muncul di atas daftar.
- Klik "Lock", thread tidak bisa di-reply.
- Klik "Move", pilih kategori baru.
- Klik "Delete", thread terhapus.
- Login sebagai user biasa, tidak melihat panel moderasi.
