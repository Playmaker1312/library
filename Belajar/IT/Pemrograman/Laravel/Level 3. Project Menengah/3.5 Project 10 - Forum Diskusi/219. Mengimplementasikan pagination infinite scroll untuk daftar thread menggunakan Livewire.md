# 219. Mengimplementasikan pagination infinite scroll untuk daftar thread menggunakan Livewire

## Definisi & Target
Mengganti pagination biasa dengan infinite scroll menggunakan Livewire.

Target: Thread dimuat otomatis saat user scroll ke bawah.

## Komponen yang Terlibat
- Package: livewire/livewire
- app/Livewire/ThreadList.php
- resources/views/livewire/thread-list.blade.php

## Perintah Artisan CLI
```bash
composer require livewire/livewire
php artisan make:livewire ThreadList
```

## Kode Implementasi (Per File)

### Livewire Component
File: app/Livewire/ThreadList.php
```php
<?php

namespace App\Livewire;

use App\Models\ForumCategory;
use App\Models\Thread;
use Illuminate\Contracts\View\View;
use Livewire\Component;
use Livewire\WithPagination;

class ThreadList extends Component
{
    use WithPagination;

    public $categoryId = null;
    public $sortField = 'created_at';
    public $sortDirection = 'desc';

    protected $queryString = ['categoryId', 'sortField', 'sortDirection'];

    public function mount($categoryId = null): void
    {
        $this->categoryId = $categoryId;
    }

    public function sortBy($field): void
    {
        if ($this->sortField === $field) {
            $this->sortDirection = $this->sortDirection === 'asc' ? 'desc' : 'asc';
        } else {
            $this->sortField = $field;
            $this->sortDirection = 'desc';
        }

        $this->resetPage();
    }

    public function render(): View
    {
        $query = Thread::with(['user', 'category'])
            ->withCount('posts', 'likes');

        if ($this->categoryId) {
            $query->where('forum_category_id', $this->categoryId);
        }

        $query->orderBy('is_pinned', 'desc')
            ->orderBy($this->sortField, $this->sortDirection);

        $threads = $query->paginate(10);

        $categories = ForumCategory::where('is_active', true)->get();

        return view('livewire.thread-list', [
            'threads' => $threads,
            'categories' => $categories,
        ]);
    }
}
```

### Blade View (Livewire)
File: resources/views/livewire/thread-list.blade.php
```blade
<div>
    <div class="mb-6 flex flex-wrap items-center gap-4">
        <select wire:model.live="categoryId" class="rounded-md border-gray-300 text-sm">
            <option value="">All Categories</option>
            @foreach ($categories as $category)
                <option value="{{ $category->id }}">{{ $category->name }}</option>
            @endforeach
        </select>

        <div class="flex gap-2">
            <button wire:click="sortBy('created_at')"
                class="px-3 py-1 text-xs rounded-md {{ $sortField === 'created_at' ? 'bg-indigo-100 text-indigo-800' : 'bg-gray-100 text-gray-600' }}">
                Latest
            </button>
            <button wire:click="sortBy('posts_count')"
                class="px-3 py-1 text-xs rounded-md {{ $sortField === 'posts_count' ? 'bg-indigo-100 text-indigo-800' : 'bg-gray-100 text-gray-600' }}">
                Most Replies
            </button>
            <button wire:click="sortBy('likes_count')"
                class="px-3 py-1 text-xs rounded-md {{ $sortField === 'likes_count' ? 'bg-indigo-100 text-indigo-800' : 'bg-gray-100 text-gray-600' }}">
                Most Likes
            </button>
        </div>
    </div>

    <div class="space-y-3">
        @foreach ($threads as $thread)
            <div class="bg-white overflow-hidden shadow-sm sm:rounded-lg p-4 hover:shadow-md transition"
                wire:key="thread-{{ $thread->id }}">
                <div class="flex items-start gap-4">
                    <div class="flex-1">
                        <div class="flex items-center gap-2 mb-1">
                            @if ($thread->is_pinned)
                                <span class="text-xs bg-yellow-100 text-yellow-800 px-2 py-0.5 rounded">Pinned</span>
                            @endif
                            <span class="text-xs text-gray-500">{{ $thread->category->name }}</span>
                        </div>
                        <h3 class="font-medium">
                            <a href="{{ route('forum.threads.show', $thread) }}" class="text-gray-900 hover:text-indigo-600">
                                {{ $thread->title }}
                            </a>
                        </h3>
                        <div class="flex items-center gap-3 mt-2 text-xs text-gray-500">
                            <span>By {{ $thread->user->name }}</span>
                            <span>{{ $thread->created_at->diffForHumans() }}</span>
                            <span>{{ $thread->posts_count }} replies</span>
                            <span>{{ $thread->likes_count }} likes</span>
                        </div>
                    </div>
                </div>
            </div>
        @endforeach
    </div>

    @if ($threads->hasMorePages())
        <div x-data x-intersect="$wire.loadMore()" class="py-8 text-center text-gray-500">
            Loading more threads...
        </div>
    @endif

    @if ($threads->onLastPage() && $threads->total() > 0)
        <div class="py-8 text-center text-gray-400 text-sm">
            You've reached the end.
        </div>
    @endif
</div>
```

## Cara Integrasi & Pengujian
- Install Livewire, jalankan `npm run build`.
- Buka halaman forum, scroll ke bawah.
- Thread baru dimuat otomatis.
- Filter kategori, daftar thread berubah.
- Klik sort by Latest / Most Replies.
- Pastikan infinite scroll berfungsi.
