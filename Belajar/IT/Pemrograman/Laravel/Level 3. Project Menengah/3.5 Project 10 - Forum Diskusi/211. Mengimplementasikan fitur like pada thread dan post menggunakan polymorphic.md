# 211. Mengimplementasikan fitur like pada thread dan post menggunakan polymorphic

## Definisi & Target
Membuat fitur like/unlike untuk thread dan post menggunakan relasi polymorphic.

Target: User dapat memberi atau membatalkan like pada thread dan post.

## Komponen yang Terlibat
- app/Http/Controllers/ForumLikeController.php
- app/Models/Like (polymorphic)
- routes/web.php

## Perintah Artisan CLI
```php artisan make:controller ForumLikeController```

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/ForumLikeController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\Like;
use App\Models\Post;
use App\Models\Thread;
use Illuminate\Http\RedirectResponse;

class ForumLikeController extends Controller
{
    public function toggleThread(Thread $thread): RedirectResponse
    {
        $existing = Like::where('user_id', auth()->id())
            ->where('likeable_id', $thread->id)
            ->where('likeable_type', Thread::class)
            ->first();

        if ($existing) {
            $existing->delete();
        } else {
            Like::create([
                'user_id' => auth()->id(),
                'likeable_id' => $thread->id,
                'likeable_type' => Thread::class,
            ]);
        }

        return back();
    }

    public function togglePost(Post $post): RedirectResponse
    {
        $existing = Like::where('user_id', auth()->id())
            ->where('likeable_id', $post->id)
            ->where('likeable_type', Post::class)
            ->first();

        if ($existing) {
            $existing->delete();
        } else {
            Like::create([
                'user_id' => auth()->id(),
                'likeable_id' => $post->id,
                'likeable_type' => Post::class,
            ]);
        }

        return back();
    }
}
```

### Routes
File: routes/web.php
```php
Route::middleware(['auth'])->prefix('forum')->name('forum.')->group(function () {
    Route::post('threads/{thread}/like', [ForumLikeController::class, 'toggleThread'])->name('threads.like');
    Route::post('posts/{post}/like', [ForumLikeController::class, 'togglePost'])->name('posts.like');
});
```

## Cara Integrasi & Pengujian
- Buka thread, klik like.
- Hitung likes bertambah.
- Klik like lagi, likes berkurang (unlike).
- Like pada post juga berfungsi sama.
- Cek polymorphic di tabel likes.
