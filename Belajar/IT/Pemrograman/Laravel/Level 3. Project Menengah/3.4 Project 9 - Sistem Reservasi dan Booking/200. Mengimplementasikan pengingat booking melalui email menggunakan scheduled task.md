# 200. Mengimplementasikan pengingat booking melalui email menggunakan scheduled task

## Definisi & Target
Membuat scheduled task yang mengirim email pengingat ke user satu hari sebelum jadwal booking.

Target: User mendapat pengingat otomatis H-1 booking.

## Komponen yang Terlibat
- app/Console/Commands/SendBookingReminders.php
- app/Mail/BookingReminder.php
- app/Console/Kernel.php

## Perintah Artisan CLI
```bash
php artisan make:command SendBookingReminders
php artisan make:mail BookingReminder
```

## Kode Implementasi (Per File)

### Command
File: app/Console/Commands/SendBookingReminders.php
```php
<?php

namespace App\Console\Commands;

use App\Mail\BookingReminder;
use App\Models\Booking;
use Carbon\Carbon;
use Illuminate\Console\Command;
use Illuminate\Support\Facades\Mail;

class SendBookingReminders extends Command
{
    protected $signature = 'bookings:send-reminders';
    protected $description = 'Send email reminders for upcoming bookings';

    public function handle(): void
    {
        $tomorrow = Carbon::tomorrow()->toDateString();

        $bookings = Booking::with(['user', 'service', 'timeSlot'])
            ->whereHas('timeSlot', function ($query) use ($tomorrow) {
                $query->whereDate('date', $tomorrow);
            })
            ->whereIn('status', ['pending', 'confirmed'])
            ->get();

        $this->info("Found {$bookings->count()} bookings for tomorrow.");

        foreach ($bookings as $booking) {
            Mail::to($booking->user->email)->send(new BookingReminder($booking));
            $this->info("Reminder sent to {$booking->user->email} for booking {$booking->booking_code}");
        }

        $this->info('All reminders sent successfully.');
    }
}
```

### Mailable
File: app/Mail/BookingReminder.php
```php
<?php

namespace App\Mail;

use App\Models\Booking;
use Illuminate\Bus\Queueable;
use Illuminate\Mail\Mailable;
use Illuminate\Mail\Mailables\Content;
use Illuminate\Mail\Mailables\Envelope;
use Illuminate\Queue\SerializesModels;

class BookingReminder extends Mailable
{
    use Queueable, SerializesModels;

    public Booking $booking;

    public function __construct(Booking $booking)
    {
        $this->booking = $booking;
    }

    public function envelope(): Envelope
    {
        return new Envelope(
            subject: 'Reminder: Upcoming Booking Tomorrow - ' . $this->booking->booking_code,
        );
    }

    public function content(): Content
    {
        return new Content(
            view: 'emails.bookings.reminder',
        );
    }
}
```

### Kernel (schedule)
File: app/Console/Kernel.php
```php
<?php

namespace App\Console;

use Illuminate\Console\Scheduling\Schedule;
use Illuminate\Foundation\Console\Kernel as ConsoleKernel;

class Kernel extends ConsoleKernel
{
    protected function schedule(Schedule $schedule): void
    {
        $schedule->command('bookings:send-reminders')
            ->dailyAt('08:00')
            ->withoutOverlapping();
    }

    protected function commands(): void
    {
        $this->load(__DIR__ . '/Commands');
        require base_path('routes/console.php');
    }
}
```

## Cara Integrasi & Pengujian
- Buat booking untuk tanggal besok.
- Jalankan `php artisan bookings:send-reminders` secara manual.
- Cek Mailtrap untuk email reminder.
- Tambahkan ke scheduler: `php artisan schedule:run` (atau cron).
- Pastikan email terkirim H-1 jam 8 pagi.
