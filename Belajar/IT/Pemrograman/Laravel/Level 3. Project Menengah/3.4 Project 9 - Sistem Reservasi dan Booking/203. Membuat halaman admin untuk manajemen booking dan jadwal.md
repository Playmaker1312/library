# 203. Membuat halaman admin untuk manajemen booking dan jadwal

## Definisi & Target
Membuat halaman admin untuk melihat, mengkonfirmasi, dan mengelola semua booking.

Target: Admin dapat mengelola booking dan jadwal dari satu halaman.

## Komponen yang Terlibat
- app/Http/Controllers/AdminBookingController.php
- resources/views/admin/bookings/index.blade.php

## Perintah Artisan CLI
```bash
php artisan make:controller AdminBookingController
```

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/AdminBookingController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\Booking;
use App\Models\Service;
use App\Models\TimeSlot;
use Carbon\Carbon;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\View\View;

class AdminBookingController extends Controller
{
    public function index(Request $request): View
    {
        $query = Booking::with(['user', 'service', 'timeSlot']);

        if ($request->filled('status')) {
            $query->where('status', $request->status);
        }

        if ($request->filled('service_id')) {
            $query->where('service_id', $request->service_id);
        }

        if ($request->filled('date')) {
            $query->whereHas('timeSlot', function ($q) use ($request) {
                $q->whereDate('date', $request->date);
            });
        }

        $bookings = $query->orderBy('created_at', 'desc')->paginate(15);
        $services = Service::all();

        return view('admin.bookings.index', compact('bookings', 'services'));
    }

    public function show(Booking $booking): View
    {
        $booking->load(['user', 'service', 'timeSlot', 'payment']);

        return view('admin.bookings.show', compact('booking'));
    }

    public function confirm(Booking $booking): RedirectResponse
    {
        $booking->update(['status' => 'confirmed']);

        return back()->with('success', 'Booking confirmed.');
    }

    public function complete(Booking $booking): RedirectResponse
    {
        $booking->update(['status' => 'completed']);

        if ($booking->payment) {
            $booking->payment->update([
                'status' => 'paid',
                'paid_at' => now(),
            ]);
        }

        return back()->with('success', 'Booking completed.');
    }

    public function manageSlots(Request $request): View
    {
        $date = $request->date ? Carbon::parse($request->date) : Carbon::today();
        $services = Service::with(['timeSlots' => function ($q) use ($date) {
            $q->whereDate('date', $date);
        }])->get();

        return view('admin.bookings.slots', compact('services', 'date'));
    }

    public function toggleSlot(TimeSlot $timeSlot): RedirectResponse
    {
        $timeSlot->update(['is_available' => !$timeSlot->is_available]);

        return back()->with('success', 'Slot availability toggled.');
    }
}
```

### Routes
File: routes/web.php
```php
Route::middleware(['auth', 'verified', 'role:super-admin|admin'])->prefix('admin')->name('admin.')->group(function () {
    Route::get('bookings', [AdminBookingController::class, 'index'])->name('bookings.index');
    Route::get('bookings/{booking}', [AdminBookingController::class, 'show'])->name('bookings.show');
    Route::patch('bookings/{booking}/confirm', [AdminBookingController::class, 'confirm'])->name('bookings.confirm');
    Route::patch('bookings/{booking}/complete', [AdminBookingController::class, 'complete'])->name('bookings.complete');
    Route::get('slots', [AdminBookingController::class, 'manageSlots'])->name('slots.index');
    Route::patch('slots/{timeSlot}/toggle', [AdminBookingController::class, 'toggleSlot'])->name('slots.toggle');
});
```

## Cara Integrasi & Pengujian
- Akses `/admin/bookings` sebagai admin.
- Filter booking berdasarkan status, service, tanggal.
- Konfirmasi booking pending.
- Tandai booking selesai.
- Kelola slot waktu (aktif/nonaktifkan).
