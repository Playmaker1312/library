# 202. Mengimplementasikan fitur cancel booking dengan kebijakan pembatalan

## Definisi & Target
Membuat fitur pembatalan booking dengan kebijakan: pembatalan H-24 dapat refund, kurang dari 24 jam tidak dapat refund.

Target: User dapat membatalkan booking dengan konsekuensi sesuai kebijakan.

## Komponen yang Terlibat
- app/Http/Controllers/BookingController (cancel)
- routes/web.php

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/BookingController.php
```php
public function cancel(Booking $booking): RedirectResponse
{
    $this->authorize('view', $booking);

    if (!in_array($booking->status, ['pending', 'confirmed'])) {
        return back()->with('error', 'This booking cannot be cancelled.');
    }

    $hoursUntilBooking = Carbon::now()->diffInHours($booking->timeSlot->date->copy()->setTimeFromTimeString($booking->timeSlot->start_time), false);

    $booking->update([
        'status' => 'cancelled',
        'cancelled_at' => now(),
    ]);

    $booking->timeSlot->decrement('current_bookings');

    if ($hoursUntilBooking >= 24) {
        if ($booking->payment && $booking->payment->status === 'paid') {
            $booking->payment->update(['status' => 'refunded']);
        }
        $message = 'Booking cancelled. Full refund will be processed.';
    } else {
        $message = 'Booking cancelled. Cancellation within 24 hours, no refund applicable.';
    }

    return redirect()->route('bookings.my-bookings')
        ->with('success', $message);
}
```

### Model TimeSlot
File: app/Models/TimeSlot.php
```php
public function decrementCapacity(): void
{
    $this->decrement('current_bookings');

    if ($this->current_bookings < $this->max_capacity && !$this->is_available) {
        $this->update(['is_available' => true]);
    }
}
```

### Routes
File: routes/web.php
```php
Route::middleware(['auth', 'verified'])->group(function () {
    Route::patch('bookings/{booking}/cancel', [BookingController::class, 'cancel'])
        ->name('bookings.cancel');
});
```

## Cara Integrasi & Pengujian
- Buat booking untuk besok (> 24 jam).
- Cancel booking, lihat pesan refund.
- Cek status booking berubah 'cancelled'.
- Cek current_bookings berkurang.
- Buat booking untuk hari ini (< 24 jam).
- Cancel, lihat pesan no refund.
