# 198. Mengimplementasikan booking confirmation page setelah berhasil memesan

## Definisi & Target
Membuat halaman konfirmasi yang muncul setelah user berhasil booking.

Target: User melihat detail booking dan instruksi selanjutnya.

## Komponen yang Terlibat
- resources/views/bookings/show.blade.php
- app/Http/Controllers/BookingController (show)

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/BookingController.php
```php
public function show(Booking $booking): View
{
    $this->authorize('view', $booking);

    $booking->load(['service', 'timeSlot', 'payment']);

    return view('bookings.show', compact('booking'));
}
```

### Policy
File: app/Policies/BookingPolicy.php
```php
<?php

namespace App\Policies;

use App\Models\Booking;
use App\Models\User;

class BookingPolicy
{
    public function view(User $user, Booking $booking): bool
    {
        return $user->id === $booking->user_id || $user->hasRole('super-admin');
    }
}
```
