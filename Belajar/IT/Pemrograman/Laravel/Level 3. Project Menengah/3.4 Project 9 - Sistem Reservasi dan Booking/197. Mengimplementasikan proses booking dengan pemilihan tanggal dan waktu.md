# 197. Mengimplementasikan proses booking dengan pemilihan tanggal dan waktu

## Definisi & Target
Membuat flow booking lengkap dari pemilihan tanggal, slot, hingga konfirmasi.

Target: User dapat booking dalam beberapa langkah.

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/BookingController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\Booking;
use App\Models\Service;
use App\Models\TimeSlot;
use Carbon\Carbon;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Str;
use Illuminate\View\View;

class BookingController extends Controller
{
    public function create(Request $request, Service $service): View
    {
        $date = $request->date ? Carbon::parse($request->date) : Carbon::today();

        $slots = TimeSlot::where('service_id', $service->id)
            ->whereDate('date', $date)
            ->available()
            ->orderBy('start_time')
            ->get();

        return view('bookings.create', compact('service', 'slots', 'date'));
    }

    public function store(Request $request): RedirectResponse
    {
        $request->validate([
            'service_id' => 'required|exists:services,id',
            'time_slot_id' => 'required|exists:time_slots,id',
            'notes' => 'nullable|string|max:500',
        ]);

        $timeSlot = TimeSlot::findOrFail($request->time_slot_id);

        if (!$timeSlot->has_available_capacity) {
            return back()->with('error', 'Slot no longer available.');
        }

        $booking = Booking::create([
            'user_id' => auth()->id(),
            'service_id' => $request->service_id,
            'time_slot_id' => $timeSlot->id,
            'booking_code' => 'BK-' . strtoupper(Str::random(8)),
            'status' => 'pending',
            'notes' => $request->notes,
        ]);

        $timeSlot->incrementCapacity();

        return redirect()->route('bookings.show', $booking)
            ->with('success', 'Booking created!');
    }

    public function show(Booking $booking): View
    {
        $booking->load(['service', 'timeSlot', 'payment']);

        return view('bookings.show', compact('booking'));
    }

    public function myBookings(): View
    {
        $bookings = Booking::with(['service', 'timeSlot'])
            ->where('user_id', auth()->id())
            ->orderBy('created_at', 'desc')
            ->get();

        return view('bookings.my-bookings', compact('bookings'));
    }
}
```

### Routes
File: routes/web.php
```php
Route::middleware(['auth', 'verified'])->group(function () {
    Route::get('bookings/create/{service}', [BookingController::class, 'create'])->name('bookings.create');
    Route::post('bookings', [BookingController::class, 'store'])->name('bookings.store');
    Route::get('bookings/{booking}', [BookingController::class, 'show'])->name('bookings.show');
    Route::get('my-bookings', [BookingController::class, 'myBookings'])->name('bookings.my-bookings');
});
```

## Cara Integrasi & Pengujian
- Klik "Book Now" dari detail service.
- Pilih tanggal, lihat slot tersedia.
- Pilih slot, isi notes, konfirmasi.
- Redirect ke halaman detail booking.
