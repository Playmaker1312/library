# 191. Merencanakan fitur booking yaitu layanan, jadwal, reservasi, pembayaran, dan konfirmasi

## Definisi & Target
Merancang arsitektur sistem reservasi dan booking dengan layanan, slot waktu, booking, dan pembayaran.

Target: Sistem booking lengkap dengan manajemen jadwal dan konfirmasi.

## Komponen yang Terlibat
- Migration: services, time_slots, bookings, payments
- Model: Service, TimeSlot, Booking, Payment
- Controller: ServiceController, BookingController, PaymentController

## Perintah Artisan CLI
```bash
php artisan make:model Service -m
php artisan make:model TimeSlot -m
php artisan make:model Booking -m
php artisan make:model Payment -m
```

## Kode Implementasi (Per File)

### Migration / Model
Empat tabel utama dengan relasi Service -> TimeSlots, User -> Bookings -> Payments.

### Routes
Route publik untuk layanan, route booking untuk user, route admin.

### Controller
Controller untuk publik dan admin.

### Blade View
Halaman daftar layanan, detail dengan kalender, booking form, my bookings.

## Cara Integrasi & Pengujian
- Buat migration, model, controller.
- Test booking flow dari user hingga konfirmasi.
- Kirim email konfirmasi setelah booking.
