# 196. Mengimplementasikan logic pengecekan ketersediaan slot waktu

## Definisi & Target
Membuat logic untuk mengecek apakah slot waktu masih tersedia sebelum booking.

Target: Slot yang penuh tidak dapat di-booking.

## Komponen yang Terlibat
- app/Models/TimeSlot.php (method has_available_capacity)
- app/Http/Controllers/BookingController (store)

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

### Model
File: app/Models/TimeSlot.php
```php
public function getHasAvailableCapacityAttribute(): bool
{
    return $this->current_bookings < $this->max_capacity && $this->is_available;
}

public function decrementCapacity(): void
{
    $this->decrement('current_bookings');

    if ($this->current_bookings >= $this->max_capacity) {
        $this->update(['is_available' => false]);
    }
}

public function incrementCapacity(): void
{
    $this->increment('current_bookings');
}

public function scopeAvailable($query)
{
    return $query->where('is_available', true)
        ->whereColumn('current_bookings', '<', 'max_capacity');
}
```

### Controller (store)
File: app/Http/Controllers/BookingController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\Booking;
use App\Models\Service;
use App\Models\TimeSlot;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Str;
use Illuminate\View\View;

class BookingController extends Controller
{
    public function store(Request $request): RedirectResponse
    {
        $request->validate([
            'service_id' => 'required|exists:services,id',
            'time_slot_id' => 'required|exists:time_slots,id',
            'notes' => 'nullable|string|max:500',
        ]);

        $timeSlot = TimeSlot::findOrFail($request->time_slot_id);

        if (!$timeSlot->has_available_capacity) {
            return back()->with('error', 'This time slot is no longer available.');
        }

        $existingBooking = Booking::where('user_id', auth()->id())
            ->where('time_slot_id', $timeSlot->id)
            ->whereIn('status', ['pending', 'confirmed'])
            ->exists();

        if ($existingBooking) {
            return back()->with('error', 'You already have a booking for this time slot.');
        }

        $booking = Booking::create([
            'user_id' => auth()->id(),
            'service_id' => $request->service_id,
            'time_slot_id' => $timeSlot->id,
            'booking_code' => 'BK-' . strtoupper(Str::random(8)),
            'status' => 'pending',
            'notes' => $request->notes,
        ]);

        $timeSlot->incrementCapacity();

        return redirect()->route('bookings.show', $booking)
            ->with('success', 'Booking created successfully!');
    }
}
```

### Seeder (contoh time slots)
File: database/seeders/TimeSlotSeeder.php
```php
<?php

namespace Database\Seeders;

use App\Models\Service;
use App\Models\TimeSlot;
use Carbon\Carbon;
use Illuminate\Database\Seeder;

class TimeSlotSeeder extends Seeder
{
    public function run(): void
    {
        $services = Service::all();

        foreach ($services as $service) {
            for ($day = 0; $day < 14; $day++) {
                $date = Carbon::today()->addDays($day);

                if ($date->isSaturday() || $date->isSunday()) {
                    continue;
                }

                $startHour = 9;
                while ($startHour < 17) {
                    $startTime = sprintf('%02d:00', $startHour);
                    $endTime = sprintf('%02d:00', $startHour + 1);

                    TimeSlot::create([
                        'service_id' => $service->id,
                        'date' => $date,
                        'start_time' => $startTime,
                        'end_time' => $endTime,
                        'max_capacity' => 2,
                        'current_bookings' => 0,
                        'is_available' => true,
                    ]);

                    $startHour++;
                }
            }
        }
    }
}
```

## Cara Integrasi & Pengujian
- Buat time slot dengan max_capacity = 2.
- Booking 2 kali untuk slot yang sama.
- Booking ke-3 akan mendapat error "no longer available".
- Cek current_bookings bertambah setiap booking.
