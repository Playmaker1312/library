# 201. Membuat halaman my bookings untuk user melihat semua reservasinya

## Definisi & Target
Membuat halaman dimana user dapat melihat semua booking yang pernah dibuat.

Target: User melihat riwayat booking dengan status masing-masing.

## Komponen yang Terlibat
- app/Http/Controllers/BookingController (myBookings)
- resources/views/bookings/my-bookings.blade.php

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/BookingController.php
```php
public function myBookings(): View
{
    $bookings = Booking::with(['service', 'timeSlot', 'payment'])
        ->where('user_id', auth()->id())
        ->orderBy('created_at', 'desc')
        ->get();

    $upcoming = $bookings->whereIn('status', ['pending', 'confirmed']);
    $past = $bookings->whereIn('status', ['completed', 'cancelled']);

    return view('bookings.my-bookings', compact('bookings', 'upcoming', 'past'));
}
```

## Cara Integrasi & Pengujian
- Akses `/my-bookings` setelah membuat beberapa booking.
- Lihat booking yang akan datang (upcoming).
- Lihat booking yang sudah lewat (past).
- Klik "View" untuk detail booking.
- Klik "Cancel" untuk membatalkan.
