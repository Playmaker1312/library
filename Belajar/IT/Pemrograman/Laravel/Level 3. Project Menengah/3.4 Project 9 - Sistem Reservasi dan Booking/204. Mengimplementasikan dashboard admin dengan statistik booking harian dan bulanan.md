# 204. Mengimplementasikan dashboard admin dengan statistik booking harian dan bulanan

## Definisi & Target
Membuat dashboard admin dengan grafik dan statistik booking.

Target: Admin melihat ringkasan data booking harian dan bulanan.

## Komponen yang Terlibat
- app/Http/Controllers/AdminDashboardController.php
- resources/views/admin/dashboard.blade.php

## Perintah Artisan CLI
```bash
php artisan make:controller AdminDashboardController
```

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/AdminDashboardController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\Booking;
use App\Models\Service;
use App\Models\User;
use Carbon\Carbon;
use Illuminate\View\View;

class AdminDashboardController extends Controller
{
    public function index(): View
    {
        $today = Carbon::today();
        $startOfMonth = Carbon::now()->startOfMonth();

        $stats = [
            'total_bookings' => Booking::count(),
            'today_bookings' => Booking::whereHas('timeSlot', function ($q) use ($today) {
                $q->whereDate('date', $today);
            })->count(),
            'monthly_bookings' => Booking::where('created_at', '>=', $startOfMonth)->count(),
            'total_revenue' => Booking::where('status', 'completed')
                ->join('services', 'bookings.service_id', '=', 'services.id')
                ->sum('services.price'),
            'pending_bookings' => Booking::where('status', 'pending')->count(),
            'total_users' => User::count(),
            'total_services' => Service::count(),
        ];

        $dailyBookings = Booking::selectRaw('DATE(booked_at) as date, COUNT(*) as total')
            ->where('booked_at', '>=', Carbon::now()->subDays(14))
            ->groupBy('date')
            ->orderBy('date')
            ->get();

        $popularServices = Service::withCount('bookings')
            ->orderBy('bookings_count', 'desc')
            ->take(5)
            ->get();

        return view('admin.dashboard', compact('stats', 'dailyBookings', 'popularServices'));
    }
}
```

## Cara Integrasi & Pengujian
- Akses `/admin/dashboard` sebagai admin.
- Lihat statistik booking total, hari ini, bulan ini.
- Lihat revenue, pending, users.
- Lihat grafik booking 14 hari terakhir.
- Lihat daftar service populer.
