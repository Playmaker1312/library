# 199. Mengirimkan email konfirmasi booking menggunakan Mailable Laravel

## Definisi & Target
Mengirim email konfirmasi ke user setelah booking berhasil dibuat.

Target: User menerima email detail booking setelah memesan.

## Komponen yang Terlibat
- app/Mail/BookingConfirmation.php
- app/Notifications/BookingConfirmed.php
- resources/views/emails/bookings/confirmation.blade.php

## Perintah Artisan CLI
```bash
php artisan make:mail BookingConfirmation
php artisan make:notification BookingConfirmed
```

## Kode Implementasi (Per File)

### Mailable
File: app/Mail/BookingConfirmation.php
```php
<?php

namespace App\Mail;

use App\Models\Booking;
use Illuminate\Bus\Queueable;
use Illuminate\Mail\Mailable;
use Illuminate\Mail\Mailables\Content;
use Illuminate\Mail\Mailables\Envelope;
use Illuminate\Queue\SerializesModels;

class BookingConfirmation extends Mailable
{
    use Queueable, SerializesModels;

    public Booking $booking;

    public function __construct(Booking $booking)
    {
        $this->booking = $booking;
    }

    public function envelope(): Envelope
    {
        return new Envelope(
            subject: 'Booking Confirmation - ' . $this->booking->booking_code,
        );
    }

    public function content(): Content
    {
        return new Content(
            view: 'emails.bookings.confirmation',
        );
    }

    public function attachments(): array
    {
        return [];
    }
}
```

### Controller (send email)
File: app/Http/Controllers/BookingController.php (modifikasi store)
```php
use App\Mail\BookingConfirmation;
use Illuminate\Support\Facades\Mail;

public function store(Request $request): RedirectResponse
{
    $request->validate([
        'service_id' => 'required|exists:services,id',
        'time_slot_id' => 'required|exists:time_slots,id',
        'notes' => 'nullable|string|max:500',
    ]);

    $timeSlot = TimeSlot::findOrFail($request->time_slot_id);

    if (!$timeSlot->has_available_capacity) {
        return back()->with('error', 'Slot no longer available.');
    }

    $booking = Booking::create([
        'user_id' => auth()->id(),
        'service_id' => $request->service_id,
        'time_slot_id' => $timeSlot->id,
        'booking_code' => 'BK-' . strtoupper(Str::random(8)),
        'status' => 'pending',
        'notes' => $request->notes,
    ]);

    $timeSlot->incrementCapacity();

    Mail::to($booking->user->email)->send(new BookingConfirmation($booking));

    return redirect()->route('bookings.show', $booking)
        ->with('success', 'Booking created! Check your email for confirmation.');
}
```
