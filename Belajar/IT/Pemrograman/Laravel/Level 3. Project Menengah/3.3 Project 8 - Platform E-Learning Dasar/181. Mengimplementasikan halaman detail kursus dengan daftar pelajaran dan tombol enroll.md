# 181. Mengimplementasikan halaman detail kursus dengan daftar pelajaran dan tombol enroll

## Definisi & Target
Membuat halaman detail kursus yang menampilkan informasi kursus, daftar pelajaran, dan tombol enroll.

Target: User dapat melihat detail kursus dan mendaftar.

## Komponen yang Terlibat
- app/Http/Controllers/CourseController (show)
- resources/views/courses/show.blade.php

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/CourseController.php
```php
public function show(Course $course): View
{
    $course->load(['lessons', 'author']);

    $isEnrolled = auth()->check() && $course->enrollments()
        ->where('user_id', auth()->id())
        ->exists();

    $totalLessons = $course->lessons->count();

    return view('courses.show', compact('course', 'isEnrolled', 'totalLessons'));
}
```
