# 190. Membuat dashboard user dengan daftar kursus yang diikuti dan progress masing-masing

## Definisi & Target
Membuat halaman dashboard user yang menampilkan semua kursus yang diikuti beserta progress.

Target: User melihat semua kursus dan progress dalam satu halaman.

## Komponen yang Terlibat
- app/Http/Controllers/DashboardController.php
- resources/views/dashboard.blade.php

## Perintah Artisan CLI
```bash
php artisan make:controller DashboardController
```

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/DashboardController.php
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use Illuminate\View\View;

class DashboardController extends Controller
{
    public function index(Request $request): View
    {
        $enrollments = $request->user()->enrollments()
            ->with('course')
            ->latest()
            ->get();

        $stats = [
            'total_courses' => $enrollments->count(),
            'completed_courses' => $enrollments->where('is_completed', true)->count(),
            'in_progress' => $enrollments->where('is_completed', false)->count(),
        ];

        return view('dashboard', compact('enrollments', 'stats'));
    }
}
```

### Routes
File: routes/web.php
```php
Route::middleware(['auth', 'verified'])->group(function () {
    Route::get('/dashboard', [DashboardController::class, 'index'])
        ->name('dashboard');
});
```

## Cara Integrasi & Pengujian
- Login, akses `/dashboard`.
- Lihat statistik total kursus, in progress, completed.
- Lihat daftar kursus dengan progress bar.
- Klik "Continue" untuk melanjutkan kursus.
- Klik "Certificate" jika kursus sudah selesai.
