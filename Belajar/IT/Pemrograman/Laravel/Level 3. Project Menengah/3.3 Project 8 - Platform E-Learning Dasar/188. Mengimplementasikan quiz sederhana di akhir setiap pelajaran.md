# 188. Mengimplementasikan quiz sederhana di akhir setiap pelajaran

## Definisi & Target
Menambahkan quiz pilihan ganda sederhana di akhir setiap pelajaran.

Target: User harus menjawab quiz dengan benar untuk menyelesaikan pelajaran.

## Komponen yang Terlibat
- Migration: lesson_questions, lesson_answers
- Model: LessonQuestion, LessonAnswer
- app/Http/Controllers/QuizController.php
- resources/views/lessons/quiz.blade.php

### Model Question
File: app/Models/LessonQuestion.php
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Database\Eloquent\Relations\HasMany;

class LessonQuestion extends Model
{
    protected $fillable = ['lesson_id', 'question', 'order'];

    public function lesson(): BelongsTo
    {
        return $this->belongsTo(Lesson::class);
    }

    public function answers(): HasMany
    {
        return $this->hasMany(LessonAnswer::class, 'question_id');
    }
}
```

### Controller
File: app/Http/Controllers/QuizController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\Course;
use App\Models\Lesson;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\View\View;

class QuizController extends Controller
{
    public function show(Course $course, Lesson $lesson): View
    {
        $lesson->load('questions.answers');

        return view('lessons.quiz', compact('course', 'lesson'));
    }

    public function submit(Request $request, Course $course, Lesson $lesson): RedirectResponse
    {
        $request->validate([
            'answers' => 'required|array',
            'answers.*' => 'exists:lesson_answers,id',
        ]);

        $questions = $lesson->questions()->with('answers')->get();
        $correctCount = 0;
        $totalQuestions = $questions->count();

        foreach ($questions as $question) {
            $selectedAnswerId = $request->answers[$question->id] ?? null;

            if ($selectedAnswerId) {
                $selectedAnswer = $question->answers->find($selectedAnswerId);
                if ($selectedAnswer && $selectedAnswer->is_correct) {
                    $correctCount++;
                }
            }
        }

        $score = $totalQuestions > 0 ? round(($correctCount / $totalQuestions) * 100) : 0;

        if ($score >= 80) {
            $enrollment = $course->enrollments()
                ->where('user_id', auth()->id())
                ->firstOrFail();

            $enrollment->progress()->updateOrCreate(
                ['lesson_id' => $lesson->id],
                [
                    'is_completed' => true,
                    'completed_at' => now(),
                ]
            );

            return redirect()->route('lessons.show', [$course, $lesson])
                ->with('success', "Quiz passed! Score: {$score}%");
        }

        return back()->with('error', "Quiz failed. Score: {$score}%. Minimum 80% required.");
    }
}
```

## Cara Integrasi & Pengujian
- Buat beberapa questions dan answers untuk satu lesson.
- Akses halaman quiz dari tombol di akhir pelajaran.
- Jawab semua pertanyaan, kirim jawaban.
- Jika score >= 80%, pelajaran otomatis marked complete.
- Jika score < 80%, muncul error dan bisa mengulang.
