# 185. Mengimplementasikan lesson completion tracking saat user menyelesaikan pelajaran

## Definisi & Target
Membuat sistem tracking ketika user menandai pelajaran sebagai selesai.

Target: Setiap pelajaran yang diselesaikan tercatat di tabel lesson_progress.

## Komponen yang Terlibat
- app/Http/Controllers/LessonProgressController.php
- app/Models/LessonProgress.php
- routes/web.php

## Perintah Artisan CLI
```bash
php artisan make:controller LessonProgressController
```

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/LessonProgressController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\Course;
use App\Models\Lesson;
use Illuminate\Http\RedirectResponse;

class LessonProgressController extends Controller
{
    public function complete(Course $course, Lesson $lesson): RedirectResponse
    {
        $enrollment = $course->enrollments()
            ->where('user_id', auth()->id())
            ->firstOrFail();

        $enrollment->progress()->updateOrCreate(
            ['lesson_id' => $lesson->id],
            [
                'is_completed' => true,
                'completed_at' => now(),
            ]
        );

        $nextLesson = $course->lessons()
            ->where('order', '>', $lesson->order)
            ->orderBy('order')
            ->first();

        if ($nextLesson) {
            return redirect()->route('lessons.show', [$course, $nextLesson])
                ->with('success', 'Lesson completed!');
        }

        $allCompleted = $course->lessons->count() === $enrollment->progress()
            ->where('is_completed', true)
            ->count();

        if ($allCompleted) {
            $enrollment->update([
                'is_completed' => true,
                'completed_at' => now(),
            ]);
        }

        return redirect()->route('courses.learn', $course)
            ->with('success', 'Course completed! Congratulations!');
    }
}
```

### Routes
File: routes/web.php
```php
Route::middleware(['auth', 'verified'])->group(function () {
    Route::post('courses/{course}/lessons/{lesson}/complete', [LessonProgressController::class, 'complete'])
        ->name('lessons.complete');
});
```

## Cara Integrasi & Pengujian
- Buka pelajaran, klik "Mark as Complete".
- Cek tabel lesson_progress, record baru muncul.
- Selesaikan semua pelajaran, cek enrollment berubah is_completed=true.
- Tombol "Mark as Complete" berubah menjadi "Completed" setelah diklik.
