# 177. Membuat migration untuk tabel courses, lessons, enrollments, lesson progress, dan certificates

## Definisi & Target
Membuat migration database untuk kelima tabel utama platform e-learning.

Target: Semua tabel siap dengan kolom dan foreign key yang tepat.
