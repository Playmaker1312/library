# 189. Mengimplementasikan pembuatan sertifikat PDF otomatis saat kursus selesai

## Definisi & Target
Membuat sertifikat PDF yang otomatis tergenerate ketika user menyelesaikan seluruh pelajaran dalam kursus.

Target: User dapat mengunduh sertifikat PDF setelah kursus selesai.

## Komponen yang Terlibat
- Package: barryvdh/laravel-dompdf
- app/Http/Controllers/CertificateController.php
- app/Models/Certificate
- resources/views/certificates/template.blade.php

## Perintah Artisan CLI
```bash
composer require barryvdh/laravel-dompdf
php artisan make:controller CertificateController
```

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/CertificateController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\Course;
use App\Models\Enrollment;
use Barryvdh\DomPDF\Facade\Pdf;
use Illuminate\Http\Response;
use Illuminate\Support\Str;

class CertificateController extends Controller
{
    public function show(Enrollment $enrollment)
    {
        $this->authorize('view', $enrollment);

        if (!$enrollment->is_completed) {
            return back()->with('error', 'Course not completed yet.');
        }

        $certificate = $enrollment->certificate;

        if (!$certificate) {
            $certificate = $enrollment->certificate()->create([
                'user_id' => $enrollment->user_id,
                'course_id' => $enrollment->course_id,
                'certificate_number' => 'CERT-' . strtoupper(Str::random(10)),
                'issued_at' => now(),
            ]);
        }

        return view('certificates.show', compact('certificate', 'enrollment'));
    }

    public function download(Enrollment $enrollment): Response
    {
        $this->authorize('view', $enrollment);

        if (!$enrollment->is_completed) {
            return back()->with('error', 'Course not completed yet.');
        }

        $certificate = $enrollment->certificate;

        if (!$certificate) {
            $certificate = $enrollment->certificate()->create([
                'user_id' => $enrollment->user_id,
                'course_id' => $enrollment->course_id,
                'certificate_number' => 'CERT-' . strtoupper(Str::random(10)),
                'issued_at' => now(),
            ]);
        }

        $pdf = Pdf::loadView('certificates.pdf', [
            'certificate' => $certificate,
            'user' => $enrollment->user,
            'course' => $enrollment->course,
        ]);

        return $pdf->download('certificate-' . $enrollment->course->slug . '.pdf');
    }
}
```

### Routes
File: routes/web.php
```php
Route::middleware(['auth', 'verified'])->group(function () {
    Route::get('certificates/{enrollment}', [CertificateController::class, 'show'])
        ->name('certificates.show');
    Route::get('certificates/{enrollment}/download', [CertificateController::class, 'download'])
        ->name('certificates.download');
});
```

### Policy
File: app/Policies/EnrollmentPolicy.php
```php
<?php

namespace App\Policies;

use App\Models\Enrollment;
use App\Models\User;

class EnrollmentPolicy
{
    public function view(User $user, Enrollment $enrollment): bool
    {
        return $user->id === $enrollment->user_id || $user->hasRole('super-admin');
    }
}
```

## Cara Integrasi & Pengujian
- Selesaikan semua pelajaran dalam kursus.
- Setelah kursus selesai, link "View Certificate" muncul.
- Klik "View Certificate", lihat sertifikat HTML.
- Klik "Download PDF", unduh file PDF.
- Buka file PDF, pastikan tampilan sesuai template.
