# 183. Membuat halaman course player untuk menonton video pelajaran

## Definisi & Target
Membuat halaman player untuk menonton video pelajaran dan melihat konten materi.

Target: User dapat menonton video dan membaca materi pelajaran.

## Komponen yang Terlibat
- app/Http/Controllers/LessonController.php
- resources/views/lessons/show.blade.php

## Perintah Artisan CLI
```bash
php artisan make:controller LessonController
```

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/LessonController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\Course;
use App\Models\Lesson;
use Illuminate\View\View;

class LessonController extends Controller
{
    public function show(Course $course, Lesson $lesson): View
    {
        $enrollment = $course->enrollments()
            ->where('user_id', auth()->id())
            ->firstOrFail();

        $course->load('lessons');

        $progress = $enrollment->progress()
            ->where('is_completed', true)
            ->pluck('lesson_id')
            ->toArray();

        $previousLesson = $course->lessons()
            ->where('order', '<', $lesson->order)
            ->orderBy('order', 'desc')
            ->first();

        $nextLesson = $course->lessons()
            ->where('order', '>', $lesson->order)
            ->orderBy('order')
            ->first();

        $isCompleted = in_array($lesson->id, $progress);

        return view('lessons.show', compact(
            'course', 'lesson', 'enrollment', 'progress',
            'previousLesson', 'nextLesson', 'isCompleted'
        ));
    }
}
```

### Routes
File: routes/web.php
```php
Route::middleware(['auth', 'verified'])->group(function () {
    Route::get('courses/{course}/lessons/{lesson}', [LessonController::class, 'show'])
        ->name('lessons.show');
});
```

## Cara Integrasi & Pengujian
- Enroll ke kursus, klik "Start First Lesson".
- Tonton video pelajaran (YouTube atau HTML5).
- Navigasi antar pelajaran dengan tombol Previous/Next.
- Klik "Mark as Complete" untuk menandai selesai.
