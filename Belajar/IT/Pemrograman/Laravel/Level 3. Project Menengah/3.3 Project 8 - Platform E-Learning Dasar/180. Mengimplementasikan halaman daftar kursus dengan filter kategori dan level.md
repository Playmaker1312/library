# 180. Mengimplementasikan halaman daftar kursus dengan filter kategori dan level

## Definisi & Target
Membuat halaman publik daftar kursus dengan filter berdasarkan kategori dan level.

Target: User dapat mencari dan memfilter kursus yang tersedia.

## Komponen yang Terlibat
- app/Http/Controllers/CourseController (index)
- resources/views/courses/index.blade.php

## Perintah Artisan CLI
Tidak ada perintah khusus.

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/CourseController.php
```php
public function index(Request $request): View
{
    $query = Course::with('author')->where('is_published', true);

    if ($request->filled('category')) {
        $query->where('category', $request->category);
    }

    if ($request->filled('level')) {
        $query->where('level', $request->level);
    }

    if ($request->filled('search')) {
        $query->where('title', 'like', '%' . $request->search . '%');
    }

    $courses = $query->paginate(12)->withQueryString();

    $categories = Course::where('is_published', true)
        ->select('category')
        ->distinct()
        ->pluck('category')
        ->filter();

    $levels = ['beginner', 'intermediate', 'advanced'];

    return view('courses.index', compact('courses', 'categories', 'levels'));
}
```

## Cara Integrasi & Pengujian
- Buat beberapa kursus dengan berbagai kategori dan level.
- Akses `/courses`, filter berdasarkan kategori.
- Filter berdasarkan level.
- Gunakan search untuk mencari kursus.
