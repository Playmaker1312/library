# 176. Merencanakan fitur e-learning yaitu kursus, pelajaran, enrollment, progress, dan sertifikat

## Definisi & Target
Merancang arsitektur platform e-learning dengan fitur kursus, pelajaran, enrollment, tracking progress, dan sertifikat PDF.

Target: Platform e-learning fungsional dengan alur belajar yang terstruktur.

## Komponen yang Terlibat
- Migration: courses, lessons, enrollments, lesson_progress, certificates
- Model: Course, Lesson, Enrollment, LessonProgress, Certificate
- Controller: CourseController, LessonController, EnrollmentController
- Package: barryvdh/laravel-dompdf (PDF)

## Perintah Artisan CLI
```bash
composer require barryvdh/laravel-dompdf
```

## Kode Implementasi (Per File)

### Migration / Model
Lima tabel utama dengan relasi yang tepat.

### Routes
Route resource untuk courses, route enrollment, route progress.

### Controller
Controller untuk publik dan admin.

### Blade View
Halaman daftar kursus, detail kursus, course player, dashboard.

## Cara Integrasi & Pengujian
- Buat migration, model, controller secara bertahap.
- Test setiap fitur dari halaman publik hingga admin.
- Generate sertifikat PDF saat kursus selesai.
