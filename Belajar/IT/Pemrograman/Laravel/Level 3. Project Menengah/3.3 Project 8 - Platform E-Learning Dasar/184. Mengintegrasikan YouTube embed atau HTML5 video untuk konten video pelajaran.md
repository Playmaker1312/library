# 184. Mengintegrasikan YouTube embed atau HTML5 video untuk konten video pelajaran

## Definisi & Target
Mengintegrasikan dua jenis video: YouTube embed (dengan ID video) dan HTML5 video (upload lokal).

Target: Video pelajaran dapat diputar langsung di halaman course player.

## Komponen yang Terlibat
- app/Models/Lesson (video_type, video_url)
- resources/views/lessons/show.blade.php
- Storage: storage/app/public/lesson-videos

## Perintah Artisan CLI
```bash
php artisan storage:link
```

## Kode Implementasi (Per File)

### Model
File: app/Models/Lesson.php
```php
public function getVideoEmbedUrlAttribute(): ?string
{
    if ($this->video_type === 'youtube') {
        return 'https://www.youtube.com/embed/' . $this->video_url;
    }

    return null;
}

public function getVideoStorageUrlAttribute(): ?string
{
    if ($this->video_type === 'html5' && $this->video_url) {
        return asset('storage/' . $this->video_url);
    }

    return null;
}
```

### LessonController (upload video)
File: app/Http/Controllers/LessonController.php (tambah method untuk admin)
```php
use Illuminate\Http\Request;

public function updateVideo(Request $request, Course $course, Lesson $lesson): RedirectResponse
{
    $request->validate([
        'video_type' => 'required|in:youtube,html5',
        'video_url' => 'required|string',
    ]);

    if ($request->video_type === 'youtube') {
        $videoId = $this->extractYoutubeId($request->video_url);
        $lesson->update([
            'video_type' => 'youtube',
            'video_url' => $videoId ?? $request->video_url,
        ]);
    }

    return back()->with('success', 'Video updated.');
}

private function extractYoutubeId(?string $url): ?string
{
    if (!$url) return null;

    preg_match('/(?:youtube\.com\/(?:[^\/]+\/.+\/|(?:v|e(?:mbed)?)\/|.*[?&]v=)|youtu\.be\/)([^"&?\/\s]{11})/', $url, $matches);

    return $matches[1] ?? null;
}
```

## Cara Integrasi & Pengujian
- Buat pelajaran dengan video_type 'youtube' dan isi video_url dengan ID YouTube.
- Buat pelajaran dengan video_type 'html5' dan upload video ke storage.
- Akses halaman lesson, pastikan video dapat diputar.
- Untuk YouTube, gunakan fitur extract ID dari URL lengkap.
