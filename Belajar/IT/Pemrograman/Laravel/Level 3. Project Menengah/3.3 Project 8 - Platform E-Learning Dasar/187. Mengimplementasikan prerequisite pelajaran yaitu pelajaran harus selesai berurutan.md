# 187. Mengimplementasikan prerequisite pelajaran yaitu pelajaran harus selesai berurutan

## Definisi & Target
Membuat sistem prerequisite dimana pelajaran hanya bisa diakses jika pelajaran sebelumnya sudah selesai.

Target: User harus menyelesaikan pelajaran secara berurutan.

## Komponen yang Terlibat
- app/Models/Lesson.php (method isAccessible)
- app/Http/Middleware/CheckLessonPrerequisite.php
- routes/web.php

## Perintah Artisan CLI
```bash
php artisan make:middleware CheckLessonPrerequisite
```

## Kode Implementasi (Per File)

### Middleware
File: app/Http/Middleware/CheckLessonPrerequisite.php
```php
<?php

namespace App\Http\Middleware;

use App\Models\Course;
use App\Models\Lesson;
use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class CheckLessonPrerequisite
{
    public function handle(Request $request, Closure $next): Response
    {
        $course = $request->route('course');
        $lesson = $request->route('lesson');

        if (!$course || !$lesson) {
            return $next($request);
        }

        $enrollment = $course->enrollments()
            ->where('user_id', auth()->id())
            ->first();

        if (!$enrollment) {
            return redirect()->route('courses.show', $course)
                ->with('error', 'You must be enrolled to access lessons.');
        }

        $previousLesson = $course->lessons()
            ->where('order', '<', $lesson->order)
            ->orderBy('order', 'desc')
            ->first();

        if ($previousLesson) {
            $isPreviousCompleted = $enrollment->progress()
                ->where('lesson_id', $previousLesson->id)
                ->where('is_completed', true)
                ->exists();

            if (!$isPreviousCompleted) {
                return redirect()->route('lessons.show', [$course, $previousLesson])
                    ->with('error', 'Please complete the previous lesson first.');
            }
        }

        return $next($request);
    }
}
```

### Model (opsional, fallback)
File: app/Models/Lesson.php
```php
public function isAccessibleBy($user): bool
{
    $enrollment = $this->course->enrollments()
        ->where('user_id', $user->id)
        ->first();

    if (!$enrollment) {
        return false;
    }

    $previousLesson = $this->course->lessons()
        ->where('order', '<', $this->order)
        ->orderBy('order', 'desc')
        ->first();

    if (!$previousLesson) {
        return true;
    }

    return $enrollment->progress()
        ->where('lesson_id', $previousLesson->id)
        ->where('is_completed', true)
        ->exists();
}
```

## Cara Integrasi & Pengujian
- Buka pelajaran ke-2 tanpa menyelesaikan pelajaran ke-1.
- Redirect ke pelajaran ke-1 dengan pesan error.
- Selesaikan pelajaran ke-1, baru bisa akses pelajaran ke-2.
- Pastikan pelajaran pertama selalu bisa diakses.
