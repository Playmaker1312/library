# 182. Mengimplementasikan sistem enrollment yaitu user mendaftar ke kursus

## Definisi & Target
Membuat sistem enrollment dimana user dapat mendaftar ke kursus dan data tersimpan di database.

Target: User terdaftar di kursus dan dapat mengakses konten.

## Komponen yang Terlibat
- app/Http/Controllers/EnrollmentController.php
- routes/web.php

## Perintah Artisan CLI
```bash
php artisan make:controller EnrollmentController
```

## Kode Implementasi (Per File)

### Controller
File: app/Http/Controllers/EnrollmentController.php
```php
<?php

namespace App\Http\Controllers;

use App\Models\Course;
use App\Models\Enrollment;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\View\View;

class EnrollmentController extends Controller
{
    public function store(Course $course): RedirectResponse
    {
        if ($course->enrollments()->where('user_id', auth()->id())->exists()) {
            return redirect()->route('courses.show', $course)
                ->with('info', 'You are already enrolled in this course.');
        }

        Enrollment::create([
            'user_id' => auth()->id(),
            'course_id' => $course->id,
        ]);

        return redirect()->route('courses.learn', $course)
            ->with('success', 'Successfully enrolled in the course.');
    }

    public function learn(Course $course): View
    {
        $enrollment = $course->enrollments()
            ->where('user_id', auth()->id())
            ->firstOrFail();

        $course->load('lessons');

        $progress = $enrollment->progress()
            ->where('is_completed', true)
            ->pluck('lesson_id')
            ->toArray();

        $firstIncompleteLesson = $course->lessons
            ->whereNotIn('id', $progress)
            ->first();

        return view('courses.learn', compact('course', 'enrollment', 'progress', 'firstIncompleteLesson'));
    }
}
```

### Routes
File: routes/web.php
```php
Route::middleware(['auth', 'verified'])->group(function () {
    Route::post('courses/{course}/enroll', [EnrollmentController::class, 'store'])
        ->name('enrollments.store');
    Route::get('courses/{course}/learn', [EnrollmentController::class, 'learn'])
        ->name('courses.learn');
});
```
