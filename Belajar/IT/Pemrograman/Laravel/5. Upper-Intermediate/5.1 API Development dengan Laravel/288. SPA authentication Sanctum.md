# 288. SPA authentication Sanctum

## Definisi Singkat
SPA authentication Sanctum menggunakan cookie session (bukan token) untuk mengautentikasi aplikasi SPA yang berjalan di domain yang sama dengan Laravel backend — memanfaatkan Laravel session tanpa CSRF token manual.

## Analogi
Seperti kartu anggota toko: setelah daftar (login), toko menyimpan data kamu (session). Setiap kali belanja (request), cukup tunjukkan kartu (cookie) — toko sudah tahu siapa kamu tanpa perlu tanya ulang.

## Poin-Poin Penting
- Backend dan SPA harus satu domain utama (subdomain diperbolehkan)
- Set `SANCTUM_STATEFUL_DOMAINS` di `.env`
- SPA harus request `sanctum/csrf-cookie` sebelum login
- Menggunakan guard `web` — bukan token
- Tidak perlu mengirim Authorization header secara manual

## Contoh Kode
```php
// config/sanctum.php
'stateful' => explode(',', env('SANCTUM_STATEFUL_DOMAINS', 'localhost:3000')),

// .env
SANCTUM_STATEFUL_DOMAINS=localhost:3000
SESSION_DOMAIN=localhost
SESSION_DRIVER=cookie

// routes/api.php — tanpa middleware auth:sanctum
Route::middleware('auth:sanctum')->group(function () {
    Route::get('/user', function (Request $request) {
        return $request->user();
    });
});

// routes/web.php — endpoint login SPA
Route::post('/login', function (LoginRequest $request) {
    if (Auth::attempt($request->only('email', 'password'))) {
        $request->session()->regenerate();
        return response()->json(['message' => 'Authenticated']);
    }
    return response()->json(['message' => 'Invalid'], 401);
});
```

```javascript
// Frontend SPA (Vue/React) — Axios
// 1. Dapatkan CSRF cookie
await axios.get('/sanctum/csrf-cookie');

// 2. Login — session akan di-set otomatis
await axios.post('/login', {
    email: 'user@example.com',
    password: 'password'
});

// 3. Request berikutnya — auth:sanctum membaca session
const user = await axios.get('/api/user');

// Axios config penting:
// withCredentials: true
// axios.defaults.withCredentials = true;
```

## Kasus Penggunaan Nyata
Dashboard admin SPA (Vue.js di `admin.example.com`) dengan Laravel backend di `api.example.com` — Sanctum menangani autentikasi via cookie session, tanpa repot mengelola token di frontend.
