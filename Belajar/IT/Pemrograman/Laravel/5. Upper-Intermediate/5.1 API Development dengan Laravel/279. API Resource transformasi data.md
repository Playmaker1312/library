# 279. API Resource transformasi data

## Definisi Singkat
API Resource adalah layer transformasi yang mengubah model/collection Eloquent menjadi JSON response yang terstruktur, konsisten, dan dapat dikustom tanpa mengotori controller.

## Analogi
Seperti bingkai foto: foto (model Eloquent) tetap sama, tapi bingkai (Resource) menentukan bagaimana foto itu ditampilkan — dipotong, diberi filter, dan dilabel.

## Poin-Poin Penting
- Memisahkan logika presentasi dari model/controller
- Setiap Resource adalah kelas yang me-*extends* `Illuminate\Http\Resources\Json\JsonResource`
- Respons otomatis JSON saat dikembalikan dari controller
- Bisa nested/bersarang untuk relasi
- Mendukung conditional attributes, metadata, dan pagination

## Contoh Kode
```php
// app/Http/Resources/UserResource.php
class UserResource extends JsonResource
{
    public function toArray(Request $request): array
    {
        return [
            'id' => $this->id,
            'name' => $this->name,
            'email' => $this->email,
            'avatar' => $this->avatar_url,
            'joined_at' => $this->created_at->format('Y-m-d'),
            'posts_count' => $this->whenCounted('posts'),
            // Relasi di-resource juga
            'recent_posts' => PostResource::collection(
                $this->whenLoaded('recentPosts')
            ),
        ];
    }
}

// Controller — bersih tanpa transformasi
public function show($id)
{
    $user = User::with('recentPosts')->findOrFail($id);
    return new UserResource($user);
}

// Output JSON:
// {
//   "data": {
//     "id": 1,
//     "name": "Budi",
//     "email": "budi@example.com",
//     "avatar": "https://...",
//     "joined_at": "2024-01-15",
//     "posts_count": 12,
//     "recent_posts": { "data": [...] }
//   }
// }
```

## Kasus Penggunaan Nyata
Social media API: `PostResource` menyembunyikan `is_draft`, `updated_at` pada published posts, dan menampilkan `likes_count`, `comments_count` hanya jika dimuat.
