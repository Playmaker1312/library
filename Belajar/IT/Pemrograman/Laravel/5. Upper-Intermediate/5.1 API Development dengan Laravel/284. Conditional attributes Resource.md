# 284. Conditional attributes Resource

## Definisi Singkat
Conditional attributes memungkinkan Resource menyertakan atau mengecualikan field tertentu secara dinamis — berdasarkan kondisi seperti relasi yang dimuat, role user, atau nilai tertentu.

## Analogi
Seperti tas multifungsi: kamu bisa menambah atau melepas kompartemen sesuai kebutuhan. Saat perjalanan pendek, tas jadi ringan; saat perjalanan panjang, semua kompartemen terpasang.

## Poin-Poin Penting
- `when($condition, $value)` — menyertakan field jika kondisi truthy
- `whenLoaded('relation')` — hanya sertakan jika relasi sudah di-load
- `whenCounted('relation')` — hanya sertakan jika relasi sudah dihitung
- `whenNotNull($value)` — sertakan jika tidak null
- `mergeWhen($condition, $array)` — gabungkan array jika kondisi terpenuhi

## Contoh Kode
```php
class PostResource extends JsonResource
{
    public function toArray(Request $request): array
    {
        return [
            'id' => $this->id,
            'title' => $this->title,
            'body' => $this->body,

            // Hanya tampil jika relasi user di-load
            'author' => UserResource::make($this->whenLoaded('user')),

            // Hanya tampil jika ada
            'thumbnail' => $this->whenNotNull($this->thumbnail_url),

            // Hanya untuk admin
            'is_published' => $this->when(
                $request->user()?->isAdmin(),
                $this->is_published
            ),

            // Hitungan hanya jika sudah di-count
            'likes_count' => $this->whenCounted('likes'),

            // Gabung beberapa field hanya jika kondisi terpenuhi
            $this->mergeWhen($this->is_featured, [
                'featured_until' => $this->featured_until,
                'featured_badge' => '🌟 Featured',
            ]),

            'created_at' => $this->created_at,
        ];
    }
}

// Query yang efisien:
// Post::with('user')->withCount('likes')->get();
// Field 'author' dan 'likes_count' muncul otomatis
// Tanpa with('user'), field 'author' tidak ada di response
```

## Kasus Penggunaan Nyata
Social media feed API: `PostResource` menampilkan `comments` hanya jika `with('comments')`, `is_liked` hanya jika user login, dan `edit_url` hanya untuk pemilik post.
