# 277. Routing api php file

## Definisi Singkat
`routes/api.php` adalah file routing khusus untuk endpoint API yang secara otomatis mendapat prefix `/api` dan middleware `api` — tanpa session state, cocok untuk komunikasi stateless via token.

## Analogi
Seperti jalur cepat di tol: `web.php` adalah jalan umum dengan banyak gerbang (session), sedangkan `api.php` adalah jalur elektronik tanpa sentuhan petugas (stateless).

## Poin-Poin Penting
- Terdaftar di `App\Providers\RouteServiceProvider` dengan prefix `/api`
- Middleware group `api` (biasanya hanya `throttle:api` dan `bindings`)
- Tidak memiliki middleware `StartSession` atau `VerifyCsrfToken`
- Route definition sama dengan web.php: `Route::get|post|put|patch|delete`
- Bisa diganti prefix-nya di `RouteServiceProvider`

## Contoh Kode
```php
// routes/api.php
use App\Http\Controllers\Api\ProductController;
use App\Http\Controllers\Api\AuthController;

// Public endpoints
Route::post('/register', [AuthController::class, 'register']);
Route::post('/login', [AuthController::class, 'login']);

// Protected endpoints
Route::middleware('auth:sanctum')->group(function () {
    Route::get('/user', function (Request $request) {
        return $request->user();
    });
    Route::apiResource('products', ProductController::class);
});

// app/Providers/RouteServiceProvider.php
public function boot()
{
    $this->routes(function () {
        Route::middleware('api')
            ->prefix('api/v1')  // Prefix bisa diubah
            ->group(base_path('routes/api.php'));

        Route::middleware('web')
            ->group(base_path('routes/web.php'));
    });
}
```

## Kasus Penggunaan Nyata
Microservice backend: file `api.php` terpisah memudahkan tim frontend mobile dan web SPA mengonsumsi endpoint yang sama tanpa session overhead.
