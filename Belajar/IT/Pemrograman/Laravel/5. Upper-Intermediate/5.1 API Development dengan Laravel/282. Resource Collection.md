# 282. Resource Collection

## Definisi Singkat
Resource Collection adalah kelas khusus untuk mentransformasi koleksi data (Eloquent Collection, pagination, atau array biasa) menjadi struktur JSON terstruktur dengan wrapping `data` key secara otomatis.

## Analogi
Seperti nampan penyaji: Resource tunggal menyajikan satu piring, Resource Collection menyajikan banyak piring sekaligus di atas nampan dengan label yang rapi.

## Poin-Poin Penting
- Bisa menggunakan `ResourceClass::collection($models)` langsung tanpa membuat Collection class
- Collection class kustom memungkinkan tambahan metadata di tingkat koleksi
- Pagination otomatis menyertakan `links` dan `meta`
- Wrapping key default adalah `data` (bisa diubah)
- Jika pakai `ResourceCollection::class`, properti `$collects` menentukan Resource per item

## Contoh Kode
```php
// Cara 1: Langsung dari Resource class
Route::get('/posts', function () {
    return PostResource::collection(Post::paginate(20));
});

// Cara 2: Collection class kustom
// php artisan make:resource PostCollection
class PostCollection extends ResourceCollection
{
    public $collects = PostResource::class;

    public function toArray(Request $request): array
    {
        return [
            'data' => $this->collection,
            'meta' => [
                'total_posts' => $this->total(),
                'categories' => Category::select('id', 'name')->get(),
            ],
        ];
    }

    // Kustom pagination response
    public function paginationInformation(Request $request, array $paginated, array $default): array
    {
        return [
            'pagination' => [
                'current_page' => $paginated['current_page'],
                'per_page' => $paginated['per_page'],
                'total' => $paginated['total'],
                'last_page' => $paginated['last_page'],
            ],
        ];
    }
}

// Controller
public function index()
{
    return new PostCollection(Post::with('user')->paginate(15));
}
```

## Kasus Penggunaan Nyata
`ProductCollection` untuk katalog e-commerce: menambahkan `filters` (brands, price range) dan `sort_options` ke meta respons — membantu frontend membangun UI filter.
