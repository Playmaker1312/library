# 289. Laravel Passport

## Definisi Singkat
Laravel Passport adalah implementasi OAuth2 server lengkap untuk API autentikasi — mendukung berbagai grant types (authorization_code, client_credentials, password, personal_access) cocok untuk third-party API publik.

## Analogi
Seperti concierge hotel: tamu (user) memberikan wewenang ke temannya (third-party app) untuk akses kamar dengan kartu khusus (access token) yang bisa dibatasi waktu dan ruang (scopes).

## Poin-Poin Penting
- OAuth2 standard — mendukung Authorization Code, Client Credentials, Password, Personal Access
- Membutuhkan tabel oauth_* (migration publish)
- Membuat client ID & client secret untuk third-party apps
- Access token + Refresh token support
- Scopes untuk mengatur izin granular
- Lebih berat dari Sanctum — cocok untuk API publik / third-party besar

## Contoh Kode
```bash
# Instalasi Passport
composer require laravel/passport
php artisan passport:install
# Membuat encryption keys dan client personal access + password grant

# Jalankan migration (oauth_auth_codes, oauth_access_tokens, oauth_refresh_tokens, oauth_clients, oauth_personal_access_clients)
php artisan migrate
```

```php
// app/Providers/AuthServiceProvider.php
use Laravel\Passport\Passport;

public function boot()
{
    $this->registerPolicies();
    Passport::routes();  // Daftar route OAuth

    // Token lifetimes
    Passport::tokensExpireIn(now()->addDays(15));
    Passport::refreshTokensExpireIn(now()->addDays(30));
    Passport::personalAccessTokensExpireIn(now()->addMonths(6));

    // Scopes
    Passport::tokensCan([
        'read-posts' => 'Read posts',
        'write-posts' => 'Create/Edit posts',
    ]);
}

// Model User
use Laravel\Passport\HasApiTokens;
class User extends Authenticatable
{
    use HasApiTokens, HasFactory, Notifiable;
}

// config/auth.php — guard API pakai passport
'guards' => [
    'api' => [
        'driver' => 'passport',
        'provider' => 'users',
    ],
];
```

## Kasus Penggunaan Nyata
Platform SaaS yang menyediakan API publik: developer third-party mendaftarkan aplikasi mereka, mendapat client_id/client_secret, dan pengguna memberikan izin via OAuth consent screen — Passport menangani semua flow OAuth2.
