# 276. Pendekatan Laravel RESTful API

## Definisi Singkat
Laravel menyediakan toolset lengkap untuk membangun RESTful API — mulai dari routing, serialisasi data (Resource), autentikasi (Sanctum/Passport), hingga rate limiting — tanpa meninggalkan struktur MVC yang sudah dikenal.

## Analogi
Seperti restoran: routing API adalah menu digital, controller adalah koki, Eloquent adalah gudang bahan, dan Resource adalah piring penyaji yang menentukan tampilan hidangan ke pelanggan.

## Poin-Poin Penting
- RESTful API Laravel memanfaatkan `api.php` untuk routing stateless
- Resource Controller bisa dibatasi hanya untuk index/show/store/update/destroy
- Response format JSON otomatis via `->json()` atau API Resource
- Rate limiting built-in di `App\Http\Kernel.php`
- Versioning API umum via prefix `/api/v1/`

## Contoh Kode
```php
// routes/api.php
Route::apiResource('posts', PostController::class);
// Hanya menyediakan: index, show, store, update, destroy

// Controller
use App\Http\Resources\PostResource;

class PostController extends Controller
{
    public function index()
    {
        return PostResource::collection(Post::paginate());
    }

    public function store(StorePostRequest $request)
    {
        $post = Post::create($request->validated());
        return (new PostResource($post))
            ->response()
            ->setStatusCode(201);
    }
}

// app/Providers/RouteServiceProvider.php
protected function configureRateLimiting()
{
    RateLimiter::for('api', function (Request $request) {
        return Limit::perMinute(60)->by($request->user()?->id ?: $request->ip());
    });
}
```

## Kasus Penggunaan Nyata
Backend mobile app e-commerce: endpoint `/api/v1/products` dengan pagination, search, filter kategori, dan autentikasi token Sanctum.
