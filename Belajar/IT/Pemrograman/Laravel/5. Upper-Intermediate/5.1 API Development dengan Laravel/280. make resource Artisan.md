# 280. make resource Artisan

## Definisi Singkat
`php artisan make:resource` adalah perintah Artisan untuk membuat kelas API Resource baru yang secara otomatis ditempatkan di direktori `app/Http/Resources/`.

## Analogi
Seperti mesin stempel: sekali buat cetakan (Resource class), semua data yang lewat akan otomatis tercetak dalam format yang sama.

## Poin-Poin Penting
- `make:resource NamaResource` — Resource tunggal untuk satu model
- `make:resource NamaCollection` — Collection resource (tambahkan `--collection`)
- Bisa juga `make:resource NamaResource --collection` untuk hasil sama
- File ditempatkan di `app/Http/Resources/` secara otomatis
- Resource dan Collection adalah kelas yang bisa langsung diedit

## Contoh Kode
```bash
# Membuat resource untuk model Product
php artisan make:resource ProductResource

# Membuat collection resource
php artisan make:resource ProductCollection
# atau
php artisan make:resource ProductResource --collection

# Struktur file yang dihasilkan
# app/Http/Resources/ProductResource.php
```

```php
// Hasil generate: app/Http/Resources/ProductResource.php
namespace App\Http\Resources;

use Illuminate\Http\Request;
use Illuminate\Http\Resources\Json\JsonResource;

class ProductResource extends JsonResource
{
    public function toArray(Request $request): array
    {
        return parent::toArray($request);
        // Ubah sesuai kebutuhan transformasi
    }
}

// Hasil generate: app/Http/Resources/ProductCollection.php
namespace App\Http\Resources;

use Illuminate\Http\Resources\Json\ResourceCollection;

class ProductCollection extends ResourceCollection
{
    public $collects = ProductResource::class;

    public function toArray(Request $request): array
    {
        return parent::toArray($request);
    }
}
```

## Kasus Penggunaan Nyata
Generate `OrderResource` dan `OrderCollection` untuk JSON response order history di mobile app, memastikan format respons konsisten di seluruh endpoint.
