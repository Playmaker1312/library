# 290. Sanctum vs Passport

## Definisi Singkat
Sanctum dan Passport adalah dua solusi autentikasi API Laravel — Sanctum untuk kebutuhan sederhana (token API + SPA cookie), Passport untuk OAuth2 kompleks (third-party apps dengan berbagai grant types).

## Analogi
Sanctum seperti gembok pintu rumah (sederhana, cepat, cukup untuk satu keluarga). Passport seperti sistem keamanan kantor dengan kartu akses berbeda untuk karyawan, tamu, kontraktor (OAuth2 kompleks).

## Poin-Poin Penting
| Aspek | Sanctum | Passport |
|--------|---------|----------|
| Kompleksitas | Ringan, minim konfigurasi | Berat, banyak tabel setup |
| OAuth2 support | Tidak | Full OAuth2 |
| Token type | API token sederhana | Access + Refresh token |
| SPA auth | Cookie session | Bisa, tapi lebih kompleks |
| Third-party API | Token manual | Client credentials grant |
| Expiration | Opsional | Bisa diatur per token type |
| Tabel database | 1 (personal_access_tokens) | 5 (oauth_*) |

## Contoh Kode
```php
// SANCTUM — cocok untuk first-party & mobile
$user->createToken('mobile')->plainTextToken;
// atau SPA session
Auth::attempt($credentials);
$request->session()->regenerate();

// PASSPORT — cocok untuk third-party API publik
// Password grant type
Http::asForm()->post('/oauth/token', [
    'grant_type' => 'password',
    'client_id' => env('PASSPORT_CLIENT_ID'),
    'client_secret' => env('PASSPORT_CLIENT_SECRET'),
    'username' => 'user@example.com',
    'password' => 'password',
    'scope' => 'read-posts write-posts',
]);

// Client credentials grant (server-to-server)
Http::asForm()->post('/oauth/token', [
    'grant_type' => 'client_credentials',
    'client_id' => $clientId,
    'client_secret' => $clientSecret,
    'scope' => 'read-posts',
]);

// Kapan pilih mana?
// Sanctum: mobile app, SPA internal, simple API
// Passport: API publik, multi-tenant third-party, butuh OAuth2 compliance
```

## Kasus Penggunaan Nyata
- **Sanctum**: Aplikasi Gojek clone — driver (mobile token), customer (mobile token), admin panel (SPA cookie)
- **Passport**: Platform seperti Shopify API — developer external membuat app yang terintegrasi dengan ribuan toko via OAuth2
