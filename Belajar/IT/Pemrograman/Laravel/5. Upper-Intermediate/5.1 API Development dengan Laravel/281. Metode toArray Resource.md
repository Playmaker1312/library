# 281. Metode toArray Resource

## Definisi Singkat
Metode `toArray` pada API Resource menentukan struktur array/data apa saja yang akan ditampilkan dalam response JSON — ini adalah jantung transformasi data.

## Analogi
Seperti resep kue: `toArray` adalah daftar bahan dan takaran yang menentukan bagaimana kue (data) akan dipanggang dan disajikan. Bahan bisa ditambah, dikurangi, atau diubah bentuknya.

## Poin-Poin Penting
- Mengembalikan array asosiatif yang akan diubah menjadi JSON
- Parameter `$request` memberikan akses ke konteks HTTP
- `$this` mengacu pada model yang sedang di-resource
- Tidak wajib memanggil parent — bisa return array custom penuh
- Bisa memanfaatkan `when()`, `whenLoaded()`, `whenCounted()`, `mergeWhen()`

## Contoh Kode
```php
// app/Http/Resources/OrderResource.php
class OrderResource extends JsonResource
{
    public function toArray(Request $request): array
    {
        return [
            'id' => $this->id,
            'invoice' => "INV/" . $this->created_at->format('Ymd') . "/" . $this->id,
            'subtotal' => (int) $this->subtotal,
            'tax' => (int) $this->tax,
            'total' => (int) $this->total,
            'status' => $this->status,
            'status_label' => $this->status->label(),
            'items' => OrderItemResource::collection(
                $this->whenLoaded('items')
            ),
            'payment' => new PaymentResource(
                $this->whenLoaded('payment')
            ),
            'created_at' => $this->created_at->isoFormat('dddd, D MMMM Y'),
            // Conditional: hanya admin yang lihat internal notes
            'internal_notes' => $this->when(
                $request->user()?->isAdmin(),
                $this->internal_notes
            ),
        ];
    }
}
```

## Kasus Penggunaan Nyata
`OrderResource.toArray` menyembunyikan `payment_proof`, `internal_notes` dari customer, menampilkan `formatted_address`, dan mengkalkulasi `delivery_estimate` berdasarkan location.
