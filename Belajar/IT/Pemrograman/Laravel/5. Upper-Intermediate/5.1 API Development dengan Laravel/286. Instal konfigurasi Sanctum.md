# 286. Instal konfigurasi Sanctum

## Definisi Singkat
Instalasi Sanctum dilakukan via Composer, publish konfigurasi, dan migrasi database — menghasilkan tabel `personal_access_tokens` untuk menyimpan token API.

## Analogi
Seperti memasang sistem keamanan gedung: instal sensor (Composer), atur panel kontrol (config), dan pasang database penghuni (migration). Siap dipakai dalam hitungan menit.

## Poin-Poin Penting
- Laravel >= 11: Sanctum sudah termasuk bawaan
- Laravel 10/9: `composer require laravel/sanctum`
- Publish config: `php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider"`
- Jalankan migration: `php artisan migrate`
- Tambahkan `HasApiTokens` trait ke User model
- Untuk SPA: setup `SANCTUM_STATEFUL_DOMAINS` di `.env`

## Contoh Kode
```bash
# Instalasi Sanctum (Laravel 10/9)
composer require laravel/sanctum

# Publish config dan migration
php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider"

# Jalankan migration (membuat tabel personal_access_tokens)
php artisan migrate

# Lihat konfigurasi
```

```php
// config/sanctum.php setelah publish
return [
    'stateful' => explode(',', env('SANCTUM_STATEFUL_DOMAINS',
        sprintf('%s%s', 'localhost,localhost:3000,127.0.0.1,127.0.0.1:8000,::1',
            env('APP_URL') ? ',' . parse_url(env('APP_URL'), PHP_URL_HOST) : '')
    )),
    'guard' => ['web'],
    'expiration' => null,
    'token_prefix' => env('SANCTUM_TOKEN_PREFIX', ''),
    'middleware' => [
        'authenticate_session' => Laravel\Sanctum\Http\Middleware\AuthenticateSession::class,
        'encrypt_cookies' => Illuminate\Cookie\Middleware\EncryptCookies::class,
    ],
];

// .env untuk SPA
SANCTUM_STATEFUL_DOMAINS=localhost:3000,app.example.com
SESSION_DOMAIN=.example.com
```

## Kasus Penggunaan Nyata
Startup SaaS: installer menjalankan `composer require laravel/sanctum` di awal project, mengatur `SANCTUM_STATEFUL_DOMAINS` untuk domain staging dan production, langsung siap untuk API mobile dan web.
