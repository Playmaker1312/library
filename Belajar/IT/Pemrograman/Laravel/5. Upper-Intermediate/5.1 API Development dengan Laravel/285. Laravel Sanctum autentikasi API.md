# 285. Laravel Sanctum autentikasi API

## Definisi Singkat
Laravel Sanctum adalah package lightweight untuk autentikasi API — mendukung token-based authentication (SPA mobile) dan session-based authentication (SPA first-party) tanpa kompleksitas OAuth.

## Analogi
Seperti kartu akses hotel: tamu check-in (login) diberi kartu (token) yang bisa dipakai membuka pintu kamar (resource) selama masa menginap. Untuk SPA yang sama domain, cukup dengan cookie session (seperti fingerprint).

## Poin-Poin Penting
- Dua mode: Token-based (mobile/third-party) dan SPA (first-party cookie)
- Token disimpan di tabel `personal_access_tokens` — bisa dibatasi abilities
- Tanpa database overhead OAuth — tidak perlu client_id, client_secret
- Middleware `auth:sanctum` melindungi route API
- Bisa multiple token per user dengan nama berbeda

## Contoh Kode
```php
// config/sanctum.php
return [
    'stateful' => explode(',', env('SANCTUM_STATEFUL_DOMAINS', 'localhost,localhost:3000')),
    'expiration' => null,  // Token expiry dalam menit (null = tidak expire)
    'middleware' => [
        'authenticate_session' => Laravel\Sanctum\Http\Middleware\AuthenticateSession::class,
        'encrypt_cookies' => Illuminate\Cookie\Middleware\EncryptCookies::class,
    ],
];

// Model User — tambahkan trait
use Laravel\Sanctum\HasApiTokens;

class User extends Authenticatable
{
    use HasApiTokens, HasFactory, Notifiable;
}

// Membuat token
$token = $user->createToken('mobile-app', ['read', 'write'])->plainTextToken;

// Verifikasi abilities di route
Route::get('/orders', function () {
    // Pastikan user punya ability 'read'
})->middleware('auth:sanctum')->can('read', 'orders');
```

## Kasus Penggunaan Nyata
Aplikasi ojek online: driver menggunakan token Sanctum dari app Android, customer dari app iOS. Admin dari web browser (SPA) menggunakan cookie session Sanctum.
