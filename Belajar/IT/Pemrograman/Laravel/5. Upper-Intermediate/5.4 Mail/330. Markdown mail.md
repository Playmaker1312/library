# 330. Markdown mail

## Definisi Singkat
Markdown mail adalah sistem template email Laravel menggunakan sintaks Markdown yang di-render menjadi HTML responsif dengan komponen pre-built — menghasilkan email cantik tanpa CSS manual.

## Analogi
Seperti menulis di blog: kamu tulis konten dengan Markdown sederhana (`#` heading, `**bold**`), dan sistem otomatis mengubahnya menjadi halaman HTML dengan desain profesional.

## Poin-Poin Penting
- Dibuat dengan `--markdown=view.name` saat `make:mail`
- File view di `resources/views/vendor/mail/html/` (publish dulu)
- Komponen: `x-mail::message`, `x-mail::button`, `x-mail::panel`, `x-mail::table`
- Template otomatis responsif dan support dark mode
- Warna bisa dikustomisasi via publish config

## Contoh Kode
```bash
# Buat Mailable dengan Markdown
php artisan make:mail InvoiceMail --markdown=emails.invoice

# Publish template Markdown default (untuk kustomisasi)
php artisan vendor:publish --tag=laravel-mail
# Template ada di resources/views/vendor/mail/
```

```blade

<x-mail::message>

@endforeach
</x-mail::table>

**Total: Rp{{ number_format($invoice->total, 0, ',', '.') }}**

<x-mail::button :url="url('/invoices/' . $invoice->id)" color="primary">
Lihat Invoice
</x-mail::button>

<x-mail::panel>

</x-mail::panel>

```

```php
// app/Mail/InvoiceMail.php
public function content(): Content
{
    return new Content(
        markdown: 'emails.invoice',  // View markdown
        with: ['invoice' => $this->invoice],
    );
}
```

```php
// config/mail.php — kustomisasi warna Markdown
'markdown' => [
    'theme' => 'default',  // Atau 'custom'
    'paths' => [
        resource_path('views/vendor/mail'),
    ],
],
```

## Kasus Penggunaan Nyata
Startup yang sering kirim email transaksional: Markdown mail mempercepat development — cukup tulis markdown, dapat email look profesional tanpa desainer CSS. Kustomisasi warna brand via theme.
