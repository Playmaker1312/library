# 332. to cc bcc

## Definisi Singkat
Method `to()`, `cc()`, dan `bcc()` pada Mail facade menentukan penerima email — `to` (penerima utama), `cc` (tembusan), `bcc` (tembusan tersembunyi) — sesuai standar email protocol.

## Analogi
Seperti surat fisik: amplop `to` adalah alamat utama, `cc` adalah daftar orang yang menerima fotokopi (namanya tercantum), `bcc` adalah fotokopi rahasia (penerima lain tidak tahu).

## Poin-Poin Penting
- `to()` — penerima utama, semua penerima lihat alamat ini
- `cc()` — carbon copy, penerima lain lihat daftar cc
- `bcc()` — blind carbon copy, penerima lain tidak tahu
- Bisa di-chain: `to($a)->cc($b)->bcc($c)`
- Menerima: User model, Collection, array, atau string email

## Contoh Kode
```php
use Illuminate\Support\Facades\Mail;
use App\Mail\InvoiceMail;
use App\Mail\ReportMail;

// 1. Single penerima
Mail::to($customer)->send(new InvoiceMail($invoice));

// 2. To + CC
Mail::to($customer)
    ->cc($accountant)        // Akuntan dapat tembusan
    ->send(new InvoiceMail($invoice));

// 3. To + CC + BCC
Mail::to($customer)
    ->cc($manager->email)    // Manager lihat di CC
    ->bcc('owner@company.com') // Owner dapat salinan tanpa diketahui
    ->send(new InvoiceMail($invoice));

// 4. Multiple recipients di to/cc/bcc
Mail::to([
    $customer->email,
    'backup@example.com',
])->send(new InvoiceMail($invoice));

// 5. Mixed: User model + string email
$admin = User::where('role', 'admin')->first();
Mail::to($customer)
    ->cc($admin)          // User model otomatis ambil email
    ->bcc('audit@company.com', 'Nama Audit')
    ->send(new InvoiceMail($invoice));

// 6. Di Mailable envelope (Laravel 11+)
class InvoiceMail extends Mailable
{
    public function envelope(): Envelope
    {
        return new Envelope(
            to: [$this->invoice->user],                    // To default
            cc: [new Address('accounting@company.com', 'Accounting')],
            bcc: [new Address('audit@company.com', 'Audit')],
            subject: 'Invoice #' . $this->invoice->number,
        );
    }
}
```

## Kasus Penggunaan Nyata
Invoice payment: `to($customer)` invoice, `cc($salesRep)` biar sales tahu client bayar, `bcc($director)` tanpa diketahui customer — semua dari satu Mailable.
