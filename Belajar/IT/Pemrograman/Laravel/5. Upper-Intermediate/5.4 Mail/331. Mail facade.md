# 331. Mail facade

## Definisi Singkat
`Mail` facade adalah antarmuka utama untuk mengirim email di Laravel — menyediakan method `to()`, `cc()`, `bcc()`, `send()`, `queue()`, `later()` untuk mengirim Mailable class.

## Analogi
Seperti petugas pos: kamu serahkan surat (Mailable) ke petugas (Mail facade), sebutkan alamat (to/cc/bcc), dan petugas mengurus pengirimannya — baik langsung (send) atau dijadwalkan (later).

## Poin-Poin Penting
- `Mail::to($user)->send(new Mailable)` — kirim langsung
- `Mail::to($user)->queue(new Mailable)` — kirim via queue
- `Mail::to($user)->later($delay, new Mailable)` — kirim dengan delay
- `Mail::to($users)->send(...)` — kirim ke banyak user (iterable)
- `Mail::to()` menerima User, Collection, atau email string

## Contoh Kode
```php
use Illuminate\Support\Facades\Mail;
use App\Mail\OrderConfirmation;
use App\Mail\InvoiceMail;
use App\Mail\PromoNewsletter;

// Kirim ke satu user (object)
Mail::to($user)->send(new OrderConfirmation($order));

// Kirim ke email langsung (string)
Mail::to('customer@example.com')->send(new OrderConfirmation($order));

// Kirim ke banyak user
$users = User::where('subscribed', true)->get();
Mail::to($users)->send(new PromoNewsletter($promo));

// Kirim via queue (async)
Mail::to($user)->queue(new OrderConfirmation($order));

// Kirim dengan delay — 1 jam lagi
Mail::to($user)->later(now()->addHour(), new OrderConfirmation($order));

// Kirim dengan multiple recipients
Mail::to($user)
    ->cc($manager)
    ->bcc($adminEmail)
    ->send(new InvoiceMail($invoice));

// Global "always to" untuk development
// config/mail.php
'mailers' => [
    'smtp' => [
        'transport' => 'smtp',
        // ...
    ],
],
// .env untuk development:
// MAIL_ALWAYS_TO=dev@example.com

// Atau via code di AppServiceProvider
public function boot(): void
{
    if ($this->app->environment('local')) {
        Mail::alwaysTo('dev@example.com');
    }
}

// Kirim raw text tanpa Mailable
Mail::raw('Pesan sederhana', function (Message $message) {
    $message->to('user@example.com')
            ->subject('Notifikasi');
});
```

## Kasus Penggunaan Nyata
Sistem notifikasi otomatis: `Mail::to($user)->queue(new LowStockAlert($product))` — saat stok menipis, email langsung di-queue tanpa menunggu, worker mengirim di background.
