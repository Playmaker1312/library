# 329. Blade template email

## Definisi Singkat
Blade template untuk email adalah file view standar Laravel (`.blade.php`) di `resources/views/emails/` yang di-render menjadi body HTML email — mendukung semua fitur Blade termasuk looping, conditional, dan layout.

## Analogi
Seperti kertas surat bergaris: Blade template adalah format kertasnya — ada kop, margin, footer. Isi surat bisa ditulis bebas dengan data dari Mailable class.

## Poin-Poin Penting
- Template biasa di `resources/views/emails/nama.blade.php`
- Layout standar bisa pakai `layouts/email.blade.php`
- Data dari Mailable otomatis tersedia sebagai variable
- Bisa include component Blade biasa
- Untuk styling, gunakan inline CSS (banyak email client hapus `<style>`)

## Contoh Kode
```blade
{{-- resources/views/emails/order/confirmation.blade.php --}}
@extends('layouts.email')

@section('content')
    <h1 style="color: #333;">Halo, {{ $order->user->name }}!</h1>

    <p>Pesanan Anda telah kami terima.</p>

    <table style="width: 100%; border-collapse: collapse; margin: 20px 0;">
        <tr style="background: #f8f9fa;">
            <th style="padding: 10px; border: 1px solid #ddd;">Produk</th>
            <th style="padding: 10px; border: 1px solid #ddd;">Qty</th>
            <th style="padding: 10px; border: 1px solid #ddd;">Harga</th>
        </tr>
        @foreach ($order->items as $item)
        <tr>
            <td style="padding: 10px; border: 1px solid #ddd;">{{ $item->product->name }}</td>
            <td style="padding: 10px; border: 1px solid #ddd;">{{ $item->quantity }}</td>
            <td style="padding: 10px; border: 1px solid #ddd;">Rp{{ number_format($item->price, 0, ',', '.') }}</td>
        </tr>
        @endforeach
    </table>

    <p style="font-size: 18px; font-weight: bold;">
        Total: Rp{{ number_format($order->total, 0, ',', '.') }}
    </p>

    <a href="{{ url('/orders/' . $order->id) }}"
       style="display: inline-block; padding: 12px 24px; background: #2563eb; color: white; text-decoration: none; border-radius: 6px;">
        Lihat Detail Pesanan
    </a>
@endsection
```

```blade
{{-- resources/views/layouts/email.blade.php --}}
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Email</title>
</head>
<body style="font-family: Arial, sans-serif; line-height: 1.6; color: #333; max-width: 600px; margin: auto; padding: 20px;">
    <div style="background: #f8f9fa; padding: 20px; border-radius: 8px;">
        @yield('content')
    </div>
    <p style="text-align: center; color: #888; font-size: 12px; margin-top: 20px;">
        &copy; {{ date('Y') }} {{ config('app.name') }}. All rights reserved.
    </p>
</body>
</html>
```

## Kasus Penggunaan Nyata
Email invoice dengan Blade template: layout `email` untuk header/footer, section `content` untuk tabel item, data dari Mailable `$invoice` — semua diformat dengan inline CSS untuk kompatibilitas email client.
