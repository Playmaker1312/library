# 326. Mailable class

## Definisi Singkat
Mailable class adalah representasi email di Laravel — class yang mendefinisikan data, view template, subject, dan attachment untuk satu jenis email, memisahkan logika email dari controller.

## Analogi
Seperti amplop+surat siap kirim: Mailable class adalah rangkaian surat lengkap — siapa pengirim (from), apa judul (subject), isi surat (view), dan lampiran (attachment). Controller tinggal tulis alamat dan kirim.

## Poin-Poin Penting
- Dibuat via `php artisan make:mail NamaMail`
- Berada di `app/Mail/`
- Method `build()` atau `content()` — konfigurasi email
- Method `envelope()` — definisi subject, from, cc, bcc (Laravel 11+)
- Bisa di-queue dengan implement `ShouldQueue`

## Contoh Kode
```bash
# Membuat Mailable
php artisan make:mail OrderConfirmation
php artisan make:mail WelcomeMail
php artisan make:mail InvoiceMail
```

```php
// app/Mail/OrderConfirmation.php (Laravel 11 style)
namespace App\Mail;

use App\Models\Order;
use Illuminate\Bus\Queueable;
use Illuminate\Mail\Mailable;
use Illuminate\Mail\Mailables\Content;
use Illuminate\Mail\Mailables\Envelope;
use Illuminate\Queue\SerializesModels;

class OrderConfirmation extends Mailable
{
    use Queueable, SerializesModels;

    public function __construct(
        public Order $order  // Otomatis tersedia di view
    ) {}

    // Envelope — header email
    public function envelope(): Envelope
    {
        return new Envelope(
            subject: 'Konfirmasi Pesanan #' . $this->order->order_number,
            from: new Address(config('mail.from.address'), config('mail.from.name')),
            tags: ['order-confirmation'],
        );
    }

    // Content — view dan data
    public function content(): Content
    {
        return new Content(
            view: 'emails.orders.confirmation',
            with: [
                'orderTotal' => $this->order->total,
                'items' => $this->order->items,
            ],
        );
    }

    // Attachments (opsional)
    public function attachments(): array
    {
        return [];
    }
}

// Controller — kirim email
use App\Mail\OrderConfirmation;
use Illuminate\Support\Facades\Mail;

class OrderController extends Controller
{
    public function store(OrderRequest $request)
    {
        $order = Order::create($request->validated());
        Mail::to($order->user)->send(new OrderConfirmation($order));
        return redirect()->route('orders.show', $order);
    }
}
```

## Kasus Penggunaan Nyata
Aplikasi rental mobil: `make:mail BookingConfirmation` — email berisi detail booking, mobil, harga, dan link cancel — semua data disiapkan di Mailable class, controller hanya trigger kirim.
