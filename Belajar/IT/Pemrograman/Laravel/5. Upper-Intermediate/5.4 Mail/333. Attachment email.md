# 333. Attachment email

## Definisi Singkat
Lampiran (attachment) di email Laravel bisa berupa file dari storage, disk, atau data raw — ditambahkan via method `attach()` di Mailable class atau langsung saat mengirim.

## Analogi
Seperti mengirim paket: surat (email body) bisa disertai lampiran (attachment) berupa file PDF, gambar, atau dokumen — semua dimasukkan dalam satu amplop besar.

## Poin-Poin Penting
- `->attach('/path/file.pdf')` — lampirkan file dari path
- `->attachFromDisk('s3', 'path/file.pdf')` — dari storage disk
- `->attachData($pdfData, 'invoice.pdf')` — dari raw data/binary
- `->attach($path, ['as' => 'name.pdf', 'mime' => 'application/pdf'])` — dengan opsi
- Method `attachments()` di Mailable untuk return array attachment

## Contoh Kode
```php
use App\Models\Invoice;
use Barryvdh\DomPDF\Facade\Pdf;

class InvoiceMail extends Mailable
{
    use Queueable, SerializesModels;

    public function __construct(public Invoice $invoice) {}

    // Cara 1: Method attachments() — return array
    public function attachments(): array
    {
        $pdf = Pdf::loadView('pdfs.invoice', ['invoice' => $this->invoice]);

        return [
            // Attachment dari data binary (PDF)
            Attachment::fromData(
                fn () => $pdf->output(),
                "invoice-{$this->invoice->number}.pdf"
            )->withMime('application/pdf'),

            // Attachment dari file yang sudah ada
            Attachment::fromPath(storage_path("app/public/terms.pdf"))
                ->as('syarat-ketentuan.pdf')
                ->withMime('application/pdf'),
        ];
    }

    // Cara 2: Di controller saat kirim
    public function sendInvoice(Invoice $invoice)
    {
        Mail::to($invoice->user)->send(
            (new InvoiceMail($invoice))
            ->attach(storage_path("app/invoices/{$invoice->pdf_path}"), [
                'as' => "invoice-{$invoice->number}.pdf",
                'mime' => 'application/pdf',
            ])
            ->attachData(
                Pdf::loadHTML('<h1>Lampiran tambahan</h1>')->output(),
                'lampiran.pdf'
            )
        );
    }

    // Cara 3: Dari cloud storage (S3)
    Attachment::fromDisk('s3')
        ->path("invoices/{$this->invoice->pdf_path}")
        ->as("invoice-{$this->invoice->number}.pdf");
}

// Multiple attachment dengan berbagai tipe
public function attachments(): array
{
    return [
        Attachment::fromPath(storage_path("exports/report.xlsx")),
        Attachment::fromData(fn () => $chartImage, 'chart.png')
            ->withMime('image/png'),
        Attachment::fromDisk('public')
            ->path("logos/company-logo.png"),
    ];
}
```

## Kasus Penggunaan Nyata
Sistem payroll: email slip gaji ke karyawan — attachment PDF slip gaji (dari HTML ke PDF), file Excel rincian, dan lampiran kebijakan perusahaan — semua dari satu Mailable class.
