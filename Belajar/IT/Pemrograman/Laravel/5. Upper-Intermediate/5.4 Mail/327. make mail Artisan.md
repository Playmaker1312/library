# 327. make mail Artisan

## Definisi Singkat
`php artisan make:mail NamaMail` adalah perintah untuk membuat Mailable class baru — menghasilkan file di `app/Mail/` dengan struktur dasar yang bisa langsung dikustomisasi.

## Analogi
Seperti mencetak kop surat perusahaan: template sudah ada logo perusahaan, alamat, dan format — kamu tinggal isi konten suratnya. `make:mail` menyediakan struktur dasar Mailable.

## Poin-Poin Penting
- `php artisan make:mail NamaMail` — Mailable standar
- `php artisan make:mail NamaMail --markdown=emails.nama` — dengan Markdown template
- File dihasilkan di `app/Mail/NamaMail.php`
- View template di `resources/views/emails/nama.blade.php` (jika --markdown)
- Constructor menerima data yang akan dikirim ke view

## Contoh Kode
```bash
# Mailable standar (Blade biasa)
php artisan make:mail WelcomeMail

# Mailable dengan Markdown template
php artisan make:mail InvoiceMail --markdown=emails.invoice
# File: app/Mail/InvoiceMail.php
# View: resources/views/emails/invoice.blade.php
```

```php
// Hasil generate: app/Mail/WelcomeMail.php
namespace App\Mail;

use Illuminate\Bus\Queueable;
use Illuminate\Mail\Mailable;
use Illuminate\Mail\Mailables\Content;
use Illuminate\Mail\Mailables\Envelope;
use Illuminate\Queue\SerializesModels;

class WelcomeMail extends Mailable
{
    use Queueable, SerializesModels;

    // Data diterima via constructor
    public function __construct(
        public $user  // Tersedia di view sebagai $user
    ) {}

    public function envelope(): Envelope
    {
        return new Envelope(
            subject: 'Welcome Mail',  // Ubah sesuai kebutuhan
        );
    }

    public function content(): Content
    {
        return new Content(
            view: 'emails.welcome',  // View template
            // with: []  // Data tambahan jika perlu
        );
    }

    public function attachments(): array
    {
        return [];
    }
}

// Hasil generate jika --markdown:
// resources/views/emails/welcome.blade.php
<x-mail::message>
# Introduction

Hello {{ $user->name }},

Welcome to our application!

<x-mail::button :url="''">
Button Text
</x-mail::button>

Thanks,<br>
{{ config('app.name') }}
</x-mail::message>
```

## Kasus Penggunaan Nyata
Generate `make:mail PaymentReceipt --markdown=emails.receipt` — langsung dapat Mailable class + Markdown template dengan komponen prebuilt, tinggal edit data dan styling.
