# 340. attach dynamic file

## Definisi Singkat
Attach dynamic file memungkinkan lampiran email yang dibuat secara dinamis (bukan file fisik) — seperti PDF hasil generate, gambar chart, atau file Excel dari data — dikirim sebagai attachment tanpa menyimpan ke disk.

## Analogi
Seperti memanggang kue: kamu tidak perlu menyimpan kue di lemari (disk), cukup langsung masukkan ke kotak kado (attachment) dan kirim. Kue dibuat segar saat itu juga (dari data).

## Poin-Poin Penting
- `Attachment::fromData(callable, 'filename.pdf')` — dari data stream
- `attachData($data, 'filename.pdf', ['mime' => '...'])` — method alternatif
- Data bisa dari PDF generator, image GD, atau string binary apapun
- Tidak menyisakan file di storage — murni di memory
- Wajib hati-hati dengan memory usage untuk file besar

## Contoh Kode
```php
use Illuminate\Mail\Mailables\Attachment;
use Barryvdh\DomPDF\Facade\Pdf;
use Illuminate\Support\Facades\Mail;
use App\Mail\DynamicReportMail;

// 1. Attach PDF dinamis dari data
class ReportMail extends Mailable
{
    public function __construct(
        public array $reportData,
        public string $format
    ) {}

    public function content(): Content
    {
        return new Content(markdown: 'emails.report');
    }

    public function attachments(): array
    {
        // Generate PDF dari data dinamis
        $pdf = Pdf::loadView('pdfs.sales-report', [
            'data' => $this->reportData
        ]);

        return [
            Attachment::fromData(
                fn () => $pdf->output(),  // Callable — dipanggil saat kirim
                'laporan-penjualan-' . now()->format('Y-m-d') . '.pdf'
            )->withMime('application/pdf'),

            // 2. Attach Excel dinamis
            Attachment::fromData(
                fn () => $this->generateExcelFromData(),
                'data-export.xlsx'
            )->withMime('application/vnd.openxmlformats-officedocument.spreadsheetml.sheet'),

            // 3. Attach gambar chart dinamis
            Attachment::fromData(
                fn () => $this->generateChartImage(),
                'chart.png'
            )->withMime('image/png'),
        ];
    }

    private function generateExcelFromData(): string
    {
        // Gunakan PhpSpreadsheet atau Laravel Excel
        $spreadsheet = new \PhpOffice\PhpSpreadsheet\Spreadsheet();
        // ... isi data ...
        $writer = new \PhpOffice\PhpSpreadsheet\Writer\Xlsx($spreadsheet);
        ob_start();
        $writer->save('php://output');
        return ob_get_clean();
    }

    private function generateChartImage(): string
    {
        $image = imagecreatetruecolor(400, 300);
        // ... draw chart ...
        ob_start();
        imagepng($image);
        return ob_get_clean();
    }
}

// 3. Attach langsung di controller
public function sendDynamicReport(Request $request)
{
    $report = $this->generateReportData($request);

    Mail::to($request->user())->send(
        (new DynamicReportMail($report))
        ->attachData(
            $this->generateCsv($report),  // Data CSV
            'report.csv',
            ['mime' => 'text/csv']
        )
    );
}

// Catatan: untuk data besar, simpan dulu ke temporary file
// lalu attach dari path agar tidak overload memory
```

## Kasus Penggunaan Nyata
SaaS analytics: user klik "Email Laporan" → sistem generate PDF dan Excel dari data dashboard → attach langsung via `fromData()` → kirim — file tidak pernah disimpan di server.
