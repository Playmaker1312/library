# 336. Asynchronous email queue

## Definisi Singkat
Asynchronous email queue mengirim email melalui queue system — Mailable di-dispatch ke antrian, worker memproses di background, HTTP response tidak perlu menunggu proses SMTP selesai.

## Analogi
Seperti conveyor belt di pabrik: kamu menaruh paket (email) di ban berjalan (queue) — paket berjalan sendiri, kamu bisa langsung mengerjakan tugas lain (response). Di ujung conveyor, pekerja (worker) mengambil dan mengirimkannya.

## Poin-Poin Penting
- Trait `ShouldQueue` + `Queueable` di Mailable → otomatis queue
- `Mail::queue()` — kirim via queue manual
- `Mail::later()` — kirim dengan delay via queue
- Worker: `php artisan queue:work`
- Jangan lupa set `QUEUE_CONNECTION` bukan `sync` di production

## Contoh Kode
```php
// Cara 1: Mailable implements ShouldQueue (otomatis)
namespace App\Mail;

use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Bus\Queueable;

class WelcomeMail extends Mailable implements ShouldQueue
{
    use Queueable, SerializesModels;

    // Semua pengiriman mail ini otomatis lewat queue
    // Tidak perlu panggil ->queue() — cukup ->send()

    public function __construct(public User $user) {}

    public function content(): Content
    {
        return new Content(markdown: 'emails.welcome');
    }
}

// Controller — response cepat
class AuthController extends Controller
{
    public function register(Request $request)
    {
        $user = User::create($request->validated());

        // meskipun panggil send(), Mailable akan ke queue
        Mail::to($user)->send(new WelcomeMail($user));

        return response()->json(['message' => 'Registered'], 201);
        // Response LANGSUNG — email dikirim oleh worker nanti
    }
}

// Cara 2: Via Mail::queue() — untuk Mailable tanpa ShouldQueue

// Cara 3: Queue dengan delay
Mail::to($user)->later(now()->addMinutes(30), new FollowUpMail($user));

// Cara 4: Config global — semua mail di-queue
// config/mail.php
'mailers' => [
    'smtp' => [
        'transport' => 'smtp',
        // ...
        'queue' => 'default',  // Semua mail via queue
    ],
],

// Pastikan worker berjalan
// php artisan queue:work redis --queue=default
```

## Kasus Penggunaan Nyata
Platform kursus online: 5.000 user daftar saat flash sale — semua dapat 3 email (welcome, course list, discount). Dengan queue, semua di-dispatch dalam detik, worker kirim bertahap tanpa server down.
