# 339. Kustom komponen Markdown

## Definisi Singkat
Laravel memungkinkan pembuatan komponen Markdown kustom untuk email — memperluas komponen bawaan (`button`, `panel`, `table`) dengan komponen sesuai brand (header, footer, product card, promo banner).

## Analogi
Seperti stempel khusus perusahaan: selain stempel standar (button, panel), kamu bisa bikin stempel custom — logo, alamat, QR code — yang bisa dipakai di semua surat. Cukup buat sekali, pakai berulang.

## Poin-Poin Penting
- Komponen ditempatkan di `resources/views/vendor/mail/html/`
- Publish dulu: `php artisan vendor:publish --tag=laravel-mail`
- Buat file `.blade.php` baru dengan komponen HTML + inline CSS
- Gunakan `<x-mail::nama-komponen>` di Markdown view
- Style di `resources/views/vendor/mail/html/themes/`

## Contoh Kode
```bash
# Publish template mail default
php artisan vendor:publish --tag=laravel-mail

# Struktur direktori:
# resources/views/vendor/mail/
# ├── html/
# │   ├── layout/
# │   ├── button.blade.php
# │   ├── panel.blade.php
# │   ├── table.blade.php
# │   ├── promo-card.blade.php   # Kustom!
# │   └── product-card.blade.php # Kustom!
# ├── markdown/
# │   ├── message.blade.php
# ├── text/
# └── themes/
#     └── default.css
```

```blade
{{-- resources/views/vendor/mail/html/promo-card.blade.php --}}
<table style="width: 100%; margin: 20px 0;" cellpadding="0" cellspacing="0">
    <tr>
        <td style="background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
                   padding: 30px; border-radius: 12px; text-align: center;">
            <h2 style="color: white; margin: 0 0 10px 0;">{{ $title }}</h2>
            <p style="color: rgba(255,255,255,0.9); margin: 0 0 20px 0;">{{ $description }}</p>
            @if($link)
            <a href="{{ $link }}"
               style="display: inline-block; padding: 12px 30px; background: white;
                      color: #667eea; text-decoration: none; border-radius: 25px; font-weight: bold;">
                {{ $buttonText ?? 'Lihat' }}
            </a>
            @endif
        </td>
    </tr>
</table>

{{-- Gunakan di Markdown email --}}
<x-mail::message>
# Promo Spesial!

<x-mail::promo-card
    title="Diskon 50%"
    description="Untuk semua produk, hanya hari ini!"
    link="https://example.com/promo"
    buttonText="Belanja Sekarang"
/>

Jangan lewatkan kesempatan ini!
</x-mail::message>
```

```blade
{{-- resources/views/vendor/mail/html/product-card.blade.php --}}
<table style="width: 100%; margin: 15px 0; border: 1px solid #eee; border-radius: 8px;">
    <tr>
        <td style="padding: 15px;">
            <img src="{{ $image }}" alt="{{ $name }}" style="width: 100%; max-width: 200px;">
            <h3 style="margin: 10px 0;">{{ $name }}</h3>
            <p style="color: #666;">{{ $description }}</p>
            <p style="font-size: 20px; font-weight: bold; color: #2563eb;">{{ $price }}</p>
        </td>
    </tr>
</table>
```

## Kasus Penggunaan Nyata
E-commerce: komponen `product-card` dipakai di email rekomendasi produk — menampilkan thumbnail, nama, harga, dan link — konsisten di semua email marketing.
