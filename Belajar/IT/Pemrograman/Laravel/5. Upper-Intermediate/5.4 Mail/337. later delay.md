# 337. later delay

## Definisi Singkat
Method `later()` pada Mail facade memungkinkan pengiriman email ditunda hingga waktu tertentu — menggunakan queue worker untuk mengirim email di masa mendatang tanpa cron job.

## Analogi
Seperti surat berjadwal: kamu tulis surat sekarang, set pengiriman 3 hari lagi — kantor pos menyimpannya dan mengirim otomatis pada tanggal yang ditentukan.

## Poin-Poin Penting
- `Mail::to($user)->later($delay, new Mailable())` — delay pengiriman
- Parameter delay: `Carbon` instance, `DateTime`, atau integer (detik)
- Membutuhkan queue driver (bukan sync) dan worker berjalan
- Method `later()` otomatis men-queue Mailable dengan delay
- Bisa juga pakai `->delay()` di Mailable yang implements ShouldQueue

## Contoh Kode
```php
use Illuminate\Support\Facades\Mail;
use App\Mail\WelcomeMail;
use App\Mail\FollowUpMail;
use App\Mail\ReviewReminder;
use Carbon\Carbon;

// 1. Delay dengan Carbon — kirim 24 jam lagi
Mail::to($user)->later(
    now()->addDay(),
    new FollowUpMail($user)
);

// 2. Delay dengan jumlah detik
Mail::to($user)->later(3600, new WelcomeMail($user));  // 1 jam

// 3. Delay dengan tanggal spesifik
$birthday = Carbon::parse('2026-01-20 08:00:00');
Mail::to($user)->later(
    $birthday,
    new BirthdayPromoMail($user)
);

// 4. Delay di Mailable class (ShouldQueue)
class ReviewReminder extends Mailable implements ShouldQueue
{
    use Queueable, SerializesModels;

    public function __construct(public Order $order)
    {
        $this->delay(now()->addDays(7));  // 7 hari setelah dispatch
    }

    public function content(): Content
    {
        return new Content(markdown: 'emails.review-reminder');
    }
}

// 5. Chain delay dengan method lain
Mail::to($user)
    ->cc($manager)
    ->later(now()->addHours(2), new ReportMail($report));

// 6. later() vs queue() vs send()
// send()      — kirim langsung (blocking)
// queue()     — kirim via queue (secepat worker ambil)
// later(600)  — kirim via queue, tapi delay 10 menit

// Penting: pastikan worker berjalan
// php artisan queue:work
// Jika worker tidak jalan, delay tidak akan pernah terkirim!
```

## Kasus Penggunaan Nyata
E-commerce: `ReviewReminder` email dikirim 7 hari setelah pesanan selesai — `later(now()->addDays(7), new ReviewReminder($order))` tanpa cron job.
