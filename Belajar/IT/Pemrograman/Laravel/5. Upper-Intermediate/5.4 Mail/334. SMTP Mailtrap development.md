# 334. SMTP Mailtrap development

## Definisi Singkat
Mailtrap adalah layanan SMTP testing yang "menangkap" semua email terkirim dari environment development — menampilkannya di dashboard web tanpa benar-benar mengirim ke penerima, mencegah spam ke pengguna nyata.

## Analogi
Seperti kotak surat palsu: semua surat yang kamu kirim dari rumah (development) masuk ke kotak khusus, bukan ke kantor pos sungguhan. Kamu bisa buka kotak itu, baca suratnya, cek formatnya — tanpa takut salah kirim.

## Poin-Poin Penting
- Daftar di Mailtrap.io → dapat SMTP credentials
- Set `.env` development dengan Mailtrap SMTP
- Lihat email di dashboard Mailtrap — preview HTML, spam score, header
- Support testing dan debugging format email
- Gratis untuk development dengan limit harian

## Contoh Kode
```bash
# 1. Daftar di https://mailtrap.io
# 2. Buat inbox → dapat SMTP credentials:
#    Host: sandbox.smtp.mailtrap.io
#    Port: 2525
#    Username: 1a2b3c4d5e6f7g
#    Password: 8h9i0j1k2l3m4n
```

```php
// .env — development
MAIL_MAILER=smtp
MAIL_HOST=sandbox.smtp.mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=1a2b3c4d5e6f7g
MAIL_PASSWORD=8h9i0j1k2l3m4n
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS="dev@example.com"
MAIL_FROM_NAME="${APP_NAME}"

// config/mail.php
'default' => env('MAIL_MAILER', 'log'),

'mailers' => [
    'smtp' => [
        'transport' => 'smtp',
        'host' => env('MAIL_HOST', 'sandbox.smtp.mailtrap.io'),
        'port' => env('MAIL_PORT', 2525),
        'encryption' => env('MAIL_ENCRYPTION', 'tls'),
        'username' => env('MAIL_USERNAME'),
        'password' => env('MAIL_PASSWORD'),
        'timeout' => null,
    ],
    // Alternatif testing: simpan di log
    'log' => [
        'transport' => 'log',
        'channel' => env('MAIL_LOG_CHANNEL'),
    ],
    // Alternatif: file
    'file' => [
        'transport' => 'file',
    ],
],

// Kirim email di development → cek dashboard Mailtrap
Mail::to('siapa@saja.com')->send(new InvoiceMail($invoice));
// Email tidak sampai ke siapa@saja.com
// Tapi muncul di dashboard Mailtrap untuk diinspeksi
```

## Kasus Penggunaan Nyata
Developer menguji format email invoice: kirim ke Mailtrap, preview HTML di dashboard, cek spam score, verifikasi semua link bekerja — sebelum deploy ke production dengan Mailgun.
