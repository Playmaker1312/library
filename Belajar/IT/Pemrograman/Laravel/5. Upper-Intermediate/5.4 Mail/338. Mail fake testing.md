# 338. Mail fake testing

## Definisi Singkat
`Mail::fake()` adalah method untuk mencegah email benar-benar terkirim saat testing — email "ditangkap" dan bisa diinspeksi: siapa penerima, jenis Mailable, subject, jumlah pengiriman.

## Analogi
Seperti pos palsu saat latihan: semua surat yang dikirim selama latihan (testing) tidak benar-benar dikirim, tapi kamu bisa cek amplopnya — alamat, perangko, isi — tanpa khawatir surat sampai ke penerima.

## Poin-Poin Penting
- Panggil `Mail::fake()` di awal test
- `Mail::assertSent(Mailable::class)` — assert minimal satu terkirim
- `Mail::assertNotSent(Mailable::class)` — assert tidak terkirim
- `Mail::assertSentTo($user, Mailable::class)` — assert ke user tertentu
- `Mail::assertNothingSent()` — assert tidak ada email terkirim

## Contoh Kode
```php
use Illuminate\Support\Facades\Mail;
use App\Mail\WelcomeMail;
use App\Mail\PromoMail;
use App\Models\User;

// Test dasar
public function test_welcome_email_sent_on_registration()
{
    Mail::fake();

    $response = $this->post('/register', [
        'name' => 'Budi',
        'email' => 'budi@example.com',
        'password' => 'password123',
    ]);

    // Assert email WelcomeMail terkirim
    Mail::assertSent(WelcomeMail::class);

    // Assert terkirim ke user spesifik
    Mail::assertSent(WelcomeMail::class, function (WelcomeMail $mail) {
        return $mail->hasTo('budi@example.com');
    });

    // Assert jumlah pengiriman
    Mail::assertSent(WelcomeMail::class, 1);
}

// Test lebih detail
public function test_welcome_email_content()
{
    Mail::fake();

    $user = User::factory()->create();
    Mail::to($user)->send(new WelcomeMail($user));

    Mail::assertSent(WelcomeMail::class, function (WelcomeMail $mail) use ($user) {
        $mail->build();
        return $mail->subject === 'Selamat Datang!'
            && $mail->hasTo($user->email)
            && $mail->hasFrom(config('mail.from.address'));
    });
}

// Test email tidak terkirim
public function test_no_email_for_unsubscribed_user()
{
    Mail::fake();

    $user = User::factory()->unsubscribed()->create();
    $this->post('/promo', ['user_id' => $user->id]);

    Mail::assertNotSent(PromoMail::class);
}

// Test multiple sent
public function test_multiple_emails_on_order()
{
    Mail::fake();

    $this->post('/orders', [...]);
    $response->assertStatus(201);

    Mail::assertSent(OrderConfirmation::class);
    Mail::assertSent(InvoiceMail::class);
    Mail::assertSent(PaymentReceipt::class);
    Mail::assertNothingSent(WelcomeMail::class);  // Tidak terkirim
}

// Test queue
public function test_email_was_queued()
{
    Mail::fake();

    $this->post('/register', [...]);

    Mail::assertQueued(WelcomeMail::class);  // assert di-queue
    // vs Mail::assertSent — assert langsung (sync)
}
```

## Kasus Penggunaan Nyata
CI/CD pipeline: setiap pull request, test suite menjalankan `Mail::fake()` — memastikan email terkirim dengan benar tanpa benar-benar mengirim ke pengguna nyata.
