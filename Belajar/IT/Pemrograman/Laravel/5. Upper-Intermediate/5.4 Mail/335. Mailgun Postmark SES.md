# 335. Mailgun Postmark SES

## Definisi Singkat
Mailgun, Postmark, dan Amazon SES adalah tiga layanan email transaksional populer untuk production — masing-masing menawarkan deliverability tinggi, tracking, dan analytics, didukung langsung oleh Laravel via built-in driver.

## Analogi
Seperti jasa kurir profesional: Mailgun/Postmark/SES adalah FedEx/DHL untuk email — menjamin surat sampai ke tujuan (tidak masuk spam), memberi tracking, dan laporan pengiriman.

## Poin-Poin Penting
| Layanan | Kelebihan | Cocok Untuk |
|---------|-----------|-------------|
| Mailgun | API fleksibel, analytics detail | Semua skala |
| Postmark | Deliverability terbaik, fast | Email transaksional kritis |
| SES | Termurah, integrasi AWS | High volume, budget terbatas |

## Contoh Kode
```php
// .env — MAILGUN
MAIL_MAILER=mailgun
MAILGUN_DOMAIN=sandbox123.mailgun.org
MAILGUN_SECRET=key-xxxxxxxxxxxx
// config/services.php
'mailgun' => [
    'domain' => env('MAILGUN_DOMAIN'),
    'secret' => env('MAILGUN_SECRET'),
    'endpoint' => env('MAILGUN_ENDPOINT', 'api.mailgun.net'),
],

// .env — POSTMARK
MAIL_MAILER=postmark
POSTMARK_TOKEN=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
// config/services.php
'postmark' => [
    'token' => env('POSTMARK_TOKEN'),
],

// .env — SES
MAIL_MAILER=ses
AWS_ACCESS_KEY_ID=AKIAxxxxxxxx
AWS_SECRET_ACCESS_KEY=xxxxxxxxxxxx
AWS_DEFAULT_REGION=us-east-1
// config/services.php
'ses' => [
    'key' => env('AWS_ACCESS_KEY_ID'),
    'secret' => env('AWS_SECRET_ACCESS_KEY'),
    'region' => env('AWS_DEFAULT_REGION', 'us-east-1'),
],
```

```php
// config/mail.php
'default' => env('MAIL_MAILER', 'ses'),

'mailers' => [
    'mailgun' => [
        'transport' => 'mailgun',
    ],
    'postmark' => [
        'transport' => 'postmark',
    ],
    'ses' => [
        'transport' => 'ses',
    ],
],

// Semua service support queue via ShouldQueue
class WelcomeMail extends Mailable implements ShouldQueue
{
    use Queueable, SerializesModels;

    public function content(): Content
    {
        return new Content(markdown: 'emails.welcome');
    }
}

// Installasi package tambahan
// Mailgun: sudah built-in Laravel
// Postmark: sudah built-in Laravel
// SES: composer require aws/aws-sdk-php
```

## Kasus Penggunaan Nyata
E-commerce high volume: pakai SES (termurah) untuk email transaksional (order confirm, invoice) dengan queue Redis + Supervisor, deliverability terjaga, biaya minimal.
