# 328. Metode content Mailable

## Definisi Singkat
Method `content()` (Laravel 11+) atau `build()` (Laravel 10/9) pada Mailable class menentukan view template dan data yang akan dirender untuk body email.

## Analogi
Seperti resep kue: `content()` adalah daftar bahan (data) dan instruksi (view template) untuk membuat kue. Tanpa ini, surat hanya amplop kosong.

## Poin-Poin Penting
- `content()` mengembalikan instance `Illuminate\Mail\Mailables\Content`
- Parameter `view` — path Blade template
- Parameter `with` — array data tambahan (selain property public)
- Property public dari constructor otomatis tersedia di view
- Method `build()` (Laravel 10) menggunakan `$this->view()` langsung

## Contoh Kode
```php
// LARAVEL 11+ — method content()
class InvoiceMail extends Mailable
{
    use Queueable, SerializesModels;

    public function __construct(
        public Invoice $invoice,
        public User $customer
    ) {}

    public function content(): Content
    {
        return new Content(
            view: 'emails.invoice',     // resources/views/emails/invoice.blade.php

            // Data tambahan (selain $invoice dan $customer yang otomatis)
            with: [
                'totalFormatted' => 'Rp' . number_format($this->invoice->total, 0, ',', '.'),
                'dueDate' => $this->invoice->due_at->format('d M Y'),
                'items' => $this->invoice->items->map(function ($item) {
                    return [
                        'name' => $item->product->name,
                        'qty' => $item->quantity,
                        'price' => 'Rp' . number_format($item->price, 0, ',', '.'),
                    ];
                }),
            ],

            // HTML text (alternatif ke view)
            // htmlString: '<h1>Hello</h1>',
        );
    }

    // LARAVEL 10 — method build()
    // public function build()
    // {
    //     return $this->view('emails.invoice')
    //         ->with(['key' => 'value']);
    // }
}

// Di view blade, data tersedia:
// {{ $invoice->number }}
// {{ $totalFormatted }}
// {{ $dueDate }}
// @foreach ($items as $item) ... @endforeach

// Bisa juga menggunakan htmlString langsung (tanpa view)
public function content(): Content
{
    return new Content(
        htmlString: '<h1>Notifikasi Sederhana</h1><p>Ini email tanpa view file.</p>'
    );
}
```

## Kasus Penggunaan Nyata
`ReportMail.content()` mengirim laporan excel: view `emails.report` menampilkan summary, `with` berisi `$chartImage` (base64), `$summaryData` (array) — semua diformat di Mailable, view tetap bersih.
