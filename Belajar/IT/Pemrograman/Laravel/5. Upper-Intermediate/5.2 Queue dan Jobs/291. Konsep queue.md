# 291. Konsep queue

## Definisi Singkat
Queue adalah mekanisme menunda eksekusi tugas yang memakan waktu (email, notifikasi, upload file, API call) ke belakang layar — sehingga response HTTP tetap cepat tanpa membuat user menunggu.

## Analogi
Seperti antrian kasir: pelanggan (HTTP request) dilayani cepat dengan memberikan struk (job) ke kasir, sementara barang (tugas berat) diambil oleh asisten (worker) di belakang. Pelanggan tidak perlu menunggu barang diambil.

## Poin-Poin Penting
- Job ditempatkan ke queue (antrian) dan diproses worker secara asinkron
- Laravel mendukung berbagai queue driver: sync, database, Redis, SQS, beanstalkd
- Queue membuat aplikasi lebih responsif — response HTTP dalam milidetik
- Jobs bisa di-retry jika gagal, dan dicatat di failed_jobs table
- Cocok untuk: email, notifikasi, export laporan, resize image, webhook

## Contoh Kode
```php
// KONSEP: response cepat tanpa queue
// User nunggu 5 detik — buruk
public function register(Request $request)
{
    $user = User::create(...);
    Mail::send(new WelcomeEmail($user));  // 5 detik!
    return response()->json($user);       // Response setelah 5 detik
}

// KONSEP: dengan queue — response cepat
use App\Jobs\SendWelcomeEmail;

public function register(Request $request)
{
    $user = User::create(...);
    SendWelcomeEmail::dispatch($user);    // 0.1 detik!
    return response()->json($user);       // Response langsung
}

// File: app/Jobs/SendWelcomeEmail.php
class SendWelcomeEmail implements ShouldQueue
{
    public function handle(): void
    {
        Mail::send(new WelcomeEmail($this->user));
        // Email dikirim di background oleh queue worker
    }
}

// Menjalankan worker (di terminal terpisah)
// php artisan queue:work
```

## Kasus Penggunaan Nyata
E-commerce checkout: user klik "Bayar" → order dibuat di database → dispatch job `ProcessPayment`, `SendOrderEmail`, `UpdateInventory` → response langsung "Pesanan diterima" — semua proses berat jalan di background.
