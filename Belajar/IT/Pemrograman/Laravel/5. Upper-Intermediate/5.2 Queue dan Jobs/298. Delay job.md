# 298. Delay job

## Definisi Singkat
Delay memungkinkan job ditunda eksekusinya hingga waktu tertentu — menggunakan method `delay()` dengan parameter Carbon instance atau jumlah detik.

## Analogi
Seperti slow cooker: kamu bisa memasukkan semua bahan (job) sekarang, tapi set timer untuk mulai memasak nanti — misalnya jam 6 pagi, bubur siap untuk sarapan.

## Poin-Poin Penting
- `->delay(Carbon::parse('2025-01-20 08:00'))` — waktu absolut
- `->delay(now()->addMinutes(30))` — waktu relatif
- `->delay(60)` — detik dari sekarang (integer)
- Method `delay()` tersedia di job, notifikasi, mail, dan event listener
- Tidak semua driver mendukung delay dengan presisi tinggi (database cukup baik)

## Contoh Kode
```php
// Delay dengan waktu absolut
SendReminderEmail::dispatch($order)
    ->delay(now()->addDays(2));

// Delay dengan jumlah detik
ProcessRefund::dispatch($order)
    ->delay(3600);  // 1 jam dari sekarang

// Delay dengan Carbon instance
$scheduleAt = Carbon::parse('2025-02-14 10:00:00');
SendValentinePromo::dispatch($user)
    ->delay($scheduleAt);

// Delay di dalam job class
class SendFollowUpEmail implements ShouldQueue
{
    public function __construct(public User $user)
    {
        // Delay 3 hari setelah job di-dispatch
        $this->delay(now()->addDays(3));
    }
    // ...
}

// Kombinasi dengan onQueue
SendEmail::dispatch($user)
    ->onQueue('emails')
    ->delay(now()->addMinutes(15));

// Delay for job chaining (nanti di 305)
Bus::chain([
    new ProcessOrder($order),
    new SendConfirmation($order),
])->delay(now()->addMinutes(5))->dispatch();
```

## Kasus Penggunaan Nyata
Aplikasi reminder medis: pasien daftar konsultasi → dispatch `SendReminderJob` dengan delay 24 jam → besoknya pasien dapat notifikasi "Jadwal konsultasi besok jam 10.00".
