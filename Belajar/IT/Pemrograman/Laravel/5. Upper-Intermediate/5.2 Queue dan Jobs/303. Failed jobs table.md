# 303. Failed jobs table

## Definisi Singkat
Failed jobs table adalah tabel database (`failed_jobs`) yang menyimpan record job-job yang gagal setelah semua retry habis — memudahkan debugging dan re-run tanpa kehilangan data.

## Analogi
Seperti kotak "rusak" di pabrik: barang yang gagal setelah 3 kali diperbaiki (retry) dimasukkan ke kotak ini. Supervisor bisa buka kotak, lihat laporan kerusakan (exception), dan memutuskan mau dibuang atau diperbaiki manual.

## Poin-Poin Penting
- Otomatis terisi saat job gagal melebihi `$tries`
- Berisi: job class, payload (data), exception message, timestamp
- Migration: `php artisan queue:failed-table` lalu `php artisan migrate`
- Driver default di `config/queue.php` `failed.driver = database-uuids`
- Tidak membuat tabel jika tidak ada job gagal

## Contoh Kode
```php
// Step 1: Buat migration tabel failed_jobs (jika belum ada)
// php artisan queue:failed-table
// php artisan migrate

// Struktur tabel failed_jobs:
// - id (uuid)
// - uuid (unique)
// - connection
// - queue
// - payload (serialized job data)
// - exception (error message + stack trace)
// - failed_at (timestamp)

// config/queue.php
'failed' => [
    'driver' => env('QUEUE_FAILED_DRIVER', 'database-uuids'),
    'database' => env('DB_CONNECTION', 'mysql'),
    'table' => 'failed_jobs',
];

// Di job class — method failed() otomatis dipanggil
class ProcessPayment implements ShouldQueue
{
    public $tries = 3;

    public function handle(): void
    {
        // Jika gagal 3 kali, job masuk ke failed_jobs
    }

    public function failed(\Throwable $e): void
    {
        // Ini dipanggil SETELAH job masuk failed_jobs
        Log::error('Payment failed permanently', [
            'order_id' => $this->order->id,
            'error' => $e->getMessage()
        ]);

        // Notifikasi admin
        Notification::route('mail', 'admin@example.com')
            ->notify(new PaymentFailedNotification($this->order, $e));
    }
}

// Akses data failed jobs via query
$failedCount = DB::table('failed_jobs')->count();
$recentFailed = DB::table('failed_jobs')
    ->where('failed_at', '>', now()->subDay())
    ->get();
```

## Kasus Penggunaan Nyata
SaaS billing: job `ChargeSubscription` gagal 3 kali karena kartu kredit ditolak → masuk failed_jobs → method `failed()` kirim email "Pembayaran gagal, perbarui kartu kredit Anda" — admin juga dapat notifikasi Slack.
