# 297. onQueue

## Definisi Singkat
Method `onQueue()` menentukan nama queue spesifik tempat job akan dikirim — memungkinkan prioritas dan pemisahan jenis job ke antrian berbeda (high, low, email, default).

## Analogi
Seperti jalur kasir berbeda di supermarket: jalur cepat (express) untuk 5 item atau kurang, jalir reguler untuk belanja besar, jalur prioritas untuk lansia. Setiap antrian punya worker sendiri.

## Poin-Poin Penting
- Job masuk ke queue `default` jika tidak ditentukan
- Queue dijalankan dengan `php artisan queue:work --queue=high,default`
- Bisa dispatch dengan chain: `->onQueue('high')`
- Juga bisa di-set di constructor job: `$this->onQueue('high')`
- Urutan prioritas worker: queue pertama di argumen mendapat prioritas

## Contoh Kode
```php
// Dispatch ke queue spesifik
ProcessPayment::dispatch($order)->onQueue('high');
SendEmail::dispatch($order)->onQueue('emails');
GenerateReport::dispatch($order)->onQueue('low');

// Atau set default di job class
class SendWelcomeEmail implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public function __construct(
        public User $user
    ) {
        $this->onQueue('emails');  // Semua instance job ini masuk ke queue 'emails'
    }

    public function handle(): void
    {
        // ...
    }
}

// Multiple queue dengan prioritas
// Di job class, set queue dinamis berdasarkan kondisi
public function __construct(public Order $order)
{
    $this->onQueue($order->is_priority ? 'high' : 'default');
}

// Menjalankan worker dengan prioritas
// php artisan queue:work redis --queue=high,default,low
// Worker akan ambil dari 'high' dulu, lalu 'default', lalu 'low'

// Cek queue di database (database driver)
// SELECT * FROM jobs WHERE queue = 'high';
```

## Kasus Penggunaan Nyata
Aplikasi payment gateway: queue `high` untuk proses pembayaran (waktu sensitif), queue `default` untuk notifikasi email, queue `low` untuk laporan harian — worker diprioritaskan ke queue high.
