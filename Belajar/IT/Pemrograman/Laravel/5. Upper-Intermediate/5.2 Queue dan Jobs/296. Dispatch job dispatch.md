# 296. Dispatch job dispatch

## Definisi Singkat
Dispatch adalah proses mengirim job ke queue — untuk dieksekusi nanti oleh worker — menggunakan method `dispatch()` pada job class, helper `dispatch()` global, atau `Bus::dispatch()`.

## Analogi
Seperti memasukkan surat ke kotak pos: kamu tulis surat (job), masukkan ke kotak (dispatch), dan kurir (worker) akan mengambil dan mengantarkannya nanti. Kamu tidak perlu menunggu kurir kembali.

## Poin-Poin Penting
- `JobClass::dispatch($params)` — cara paling umum
- `dispatch(new JobClass($params))` — helper global
- `Bus::dispatch(new JobClass($params))` — facade
- `$this->dispatch(new JobClass($params))` — dari dalam class (trait Dispatchable)
- Job langsung masuk ke queue default, kecuali ditentukan queue lain

## Contoh Kode
```php
// Cara 1: Static dispatch (paling umum)
// Job memiliki trait Dispatchable
ProcessPayment::dispatch($order);

// Cara 2: Helper global
dispatch(new ProcessPayment($order));

// Cara 3: Bus facade
use Illuminate\Support\Facades\Bus;
Bus::dispatch(new ProcessPayment($order));

// Cara 4: Setelah response dikirim (dispatchAfterResponse)
// Job jalan setelah HTTP response sampai ke browser — tetap sync
ProcessPayment::dispatchAfterResponse($order);

// Dispatch dengan chain method
ProcessPayment::dispatch($order)
    ->onQueue('high')           // Queue spesifik
    ->delay(now()->addMinutes(5));  // Delay 5 menit

// Dispatch dalam controller
class OrderController extends Controller
{
    public function store(OrderRequest $request)
    {
        $order = Order::create($request->validated());

        // Dispatch job — response cepat tanpa nunggu
        ProcessPayment::dispatch($order);
        SendOrderEmail::dispatch($order);

        return new OrderResource($order);
    }
}

// Conditional dispatch (hanya jika kondisi terpenuhi)
if ($order->requires_invoice) {
    GenerateInvoice::dispatch($order);
}
```

## Kasus Penggunaan Nyata
Sistem ticketing: user submit tiket → `ProcessTicket::dispatch($ticket, $attachments)` → worker memproses attachment, assign technician, kirim notifikasi — semua async, user langsung lihat konfirmasi.
