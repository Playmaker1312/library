# 295. Metode handle job

## Definisi Singkat
Method `handle()` adalah inti dari setiap job — di sinilah logika tugas dieksekusi oleh queue worker. Method ini bisa menerima dependency injection dari Laravel container.

## Analogi
Seperti instruksi kerja di pabrik: `handle()` adalah SOP (Standard Operating Procedure) yang dibaca dan dijalankan oleh pekerja (worker). Semua alat (dependency) sudah disiapkan oleh supervisor (container).

## Poin-Poin Penting
- Dipanggil oleh queue worker saat job diproses
- Bisa injeksi dependency dari service container (type-hint di parameter)
- Property public dari constructor sudah tersedia via `$this->`
- Wajib return `void` — job tidak mengembalikan nilai ke dispatcher
- Jika throw exception, job akan di-retry (sesuai konfigurasi)

## Contoh Kode
```php
// app/Jobs/SendBulkNotification.php
class SendBulkNotification implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public function __construct(
        public Collection $users,
        public string $title,
        public string $body
    ) {}

    // Method handle — logika utama job
    // Dependency injection: FCM (Firebase Cloud Messaging)
    public function handle(FCMService $fcm): void
    {
        // Chunk agar tidak overload memory
        $this->users->chunk(100)->each(function ($chunk) use ($fcm) {
            foreach ($chunk as $user) {
                if ($user->fcm_token) {
                    $fcm->send(
                        token: $user->fcm_token,
                        title: $this->title,
                        body: $this->body
                    );
                }
            }
        });

        // Log sukses
        Log::info("Notification sent to {$this->users->count()} users");
    }

    // Method failed — dipanggil jika job gagal setelah retry habis
    public function failed(\Throwable $e): void
    {
        Log::error("Bulk notification failed: {$e->getMessage()}");
        // Notify admin via Slack
        Notification::route('slack', config('services.slack.webhook'))
            ->notify(new JobFailedAlert($this->title, $e->getMessage()));
    }
}
```

Job `GenerateInvoicePDF` — `handle()` menerima `PDFService` dari container, meng-generate invoice PDF berdasarkan `$order` yang dikirim via constructor, menyimpan ke S3, dan mengirim link ke email user.
