# 299. php artisan queue work

## Definisi Singkat
`php artisan queue:work` adalah perintah untuk menjalankan queue worker — proses yang terus-menerus mengambil job dari queue dan mengeksekusinya satu per satu.

## Analogi
Seperti kurir yang duduk di gudang: dia terus memantau kotak masuk (queue), mengambil surat (job), dan mengirimkannya. Begitu selesai satu, langsung ambil berikutnya.

## Poin-Poin Penting
- Worker berjalan sebagai process daemon — harus tetap aktif di terminal/background
- `--queue=nama` — spesifik queue name
- `--tries=3` — maksimal retry per job
- `--timeout=60` — maksimal waktu eksekusi per job (default 60)
- `--sleep=3` — tidur 3 detik jika queue kosong (default 3)
- `-v` — verbose output untuk debugging

## Contoh Kode
```bash
# Worker dasar — ambil job dari queue default
php artisan queue:work

# Worker dengan queue spesifik dan prioritas
php artisan queue:work redis --queue=high,default,low

# Worker dengan retry limit
php artisan queue:work database --tries=3

# Worker dengan timeout (job akan dianggap gagal setelah 120 detik)
php artisan queue:work redis --timeout=120

# Worker yang sleep 5 detik jika queue kosong
php artisan queue:work redis --sleep=5

# Worker untuk satu queue saja
php artisan queue:work redis --queue=emails

# Mode production — tanpa interaksi, stop jika memory leak
php artisan queue:work redis --daemon --quiet

# Menjalankan worker di background (Linux/Mac)
# nohup php artisan queue:work redis --daemon > /dev/null 2>&1 &

# Menghentikan worker
# CTRL+C atau kill process
```

## Kasus Penggunaan Nyata
Server production: `Supervisor` (lihat file 309) mengelola multiple `queue:work` process — 3 worker untuk queue `high`, 2 untuk `default`, 1 untuk `emails` — restart otomatis jika crash.
