# 310. Queue untuk email asynchronous

## Definisi Singkat
Mengirim email via queue memastikan pengguna tidak menunggu proses pengiriman email (yang bisa memakan detik) — cukup dispatch job, response langsung, worker mengirim email di background.

## Analogi
Seperti menitipkan surat ke petugas pos: kamu tulis (dispatch), serahkan ke petugas (queue), dan langsung pulang (response). Petugas yang mengurus pengiriman — kamu tidak perlu nunggu surat sampai tujuan.

## Poin-Poin Penting
- Set `$mailer->alwaysTo()` di development untuk cegah spam
- Gunakan trait `ShouldQueue` di Mailable (otomatis queue)
- Atau dispatch manual via `Mail::queue()` atau job khusus
- Queue email penting karena SMTP lambat dan bisa gagal
- Cocok untuk: welcome email, invoice, notifikasi bulk

## Contoh Kode
```php
// Cara 1: Mailable langsung ke queue (ShouldQueue trait)
// app/Mail/WelcomeMail.php
use Illuminate\Contracts\Queue\ShouldQueue;

class WelcomeMail extends Mailable implements ShouldQueue
{
    use Queueable, SerializesModels;

    // Semua pengiriman mail ini otomatis lewat queue
    public function build()
    {
        return $this->view('emails.welcome');
    }
}

// Controller — response cepat
public function register(Request $request)
{
    $user = User::create($request->validated());

    // Ini akan di-queue otomatis karena WelcomeMail implements ShouldQueue
    Mail::to($user)->send(new WelcomeMail($user));

    return response()->json(['message' => 'Registered'], 201);
    // Response langsung — email dikirim worker di background
}

// Cara 2: Manual queue via Mail facade
Mail::to($order->user)->queue(new OrderConfirmationMail($order));

// Cara 3: Job khusus untuk kirim email massal
class SendBulkNewsletter implements ShouldQueue
{
    public function __construct(public Collection $subscribers) {}

    public function handle(): void
    {
        $this->subscribers->each(function ($subscriber) {
            Mail::to($subscriber)->queue(new NewsletterMail($subscriber));
        });
    }
}

// Dispatch
SendBulkNewsletter::dispatch(User::where('subscribed', true)->get());

// Cara 4: Email dengan delay
Mail::to($user)->later(
    now()->addHours(24),
    new FollowUpMail($user)
);

// Cara 5: all Mailable otomatis queue via config
// config/mail.php
'mailers' => [
    'smtp' => [
        'transport' => 'smtp',
        // ...
    ],
],
```

## Kasus Penggunaan Nyata
Platform e-learning: 10.000 user mendaftar saat promo — setiap user mendapat 3 email (welcome, course list, discount voucher). Semua di-queue, worker memproses bertahap, server tetap responsif.
