# 306. Job batching

## Definisi Singkat
Job batching memungkinkan sekelompok job dijalankan secara paralel dan memantau progresnya — dengan callback ketika batch selesai (all jobs success) atau ada yang gagal.

## Analogi
Seperti proyek renovasi rumah: beberapa tukang bekerja paralel — tukang cat, tukang listrik, tukang pipa. Kamu bisa pantau progres (%) dan akan tahu ketika semua selesai (batch success) atau ada masalah (batch failed).

## Poin-Poin Penting
- Membutuhkan migration: `php artisan queue:batches-table`
- `Bus::batch([...])` untuk membuat batch
- `then()` — callback jika semua job sukses
- `catch()` — callback jika minimal satu job gagal
- `finally()` — callback selalu dijalankan (sukses/gagal)
- `.name('Nama Batch')` — untuk identifikasi di tabel `job_batches`

## Contoh Kode
```php
// Step 1: Buat migration
// php artisan queue:batches-table
// php artisan migrate

// Step 2: Batch jobs
use Illuminate\Support\Facades\Bus;
use App\Jobs\ProcessUserData;
use App\Jobs\GenerateUserReport;

$batch = Bus::batch([
    new ProcessUserData($user1),
    new ProcessUserData($user2),
    new ProcessUserData($user3),
    new GenerateUserReport($report),
])
->name('User Processing Batch')
->then(function (Batch $batch) {
    // Semua job sukses
    Log::info("Batch {$batch->id} completed successfully");
    Notification::route('mail', 'admin@example.com')
        ->notify(new BatchCompletedNotification($batch));
})
->catch(function (Batch $batch, Throwable $e) {
    // Minimal satu job gagal
    Log::error("Batch {$batch->id} failed: {$e->getMessage()}");
})
->finally(function (Batch $batch) {
    // Selalu dijalankan
    Log::info("Batch {$batch->id} finished processing");
})
->dispatch();

// Menambahkan job ke batch setelah batch dibuat
$batch->add([
    new AdditionalJob($data),
]);

// Mendapatkan batch progress
$batch = Bus::findBatch($batchId);
$progress = $batch->progress();  // Persentase (0-100)
$totalJobs = $batch->totalJobs;
$pendingJobs = $batch->pendingJobs;
$failedJobs = $batch->failedJobs;
```

## Kasus Penggunaan Nyata
Import CSV 10.000 user: batch dipecah menjadi 100 job (@masing-masing 100 user), diproses paralel, progres terlihat real-time, dan admin dapat notifikasi ketika semua selesai.
