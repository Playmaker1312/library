# 305. Job chaining withChain

## Definisi Singkat
Job chaining memungkinkan beberapa job dijalankan secara berurutan — job kedua baru dijalankan jika job pertama sukses. Jika salah satu gagal, chain berhenti dan sisanya tidak dijalankan.

## Analogi
Seperti resep masakan bertahap: potong bawang (job 1) → tumis bumbu (job 2) → masak nasi (job 3). Jika potong bawang gagal (job 1 gagal), tidak ada gunanya menumis bumbu. Semua tergantung suksesnya langkah sebelumnya.

## Poin-Poin Penting
- Gunakan `Bus::chain([...])` untuk membuat sequence job
- Job dijalankan berurutan, satu per satu
- Chain berhenti jika salah satu job gagal
- Method `catch()` untuk menangani kegagalan chain
- Semua job dalam chain harus independent (tidak shared state selain database)

## Contoh Kode
```php
use Illuminate\Support\Facades\Bus;

// Chain sederhana
Bus::chain([
    new ProcessOrder($order),
    new ChargePayment($order),
    new SendInvoice($order),
    new SendConfirmation($order),
])->dispatch();

// Chain dengan catch — jika gagal
Bus::chain([
    new ResizeImage($photo),
    new GenerateThumbnail($photo),
    new UploadToCDN($photo),
])->catch(function (Throwable $e) {
    // Hapus file yang sudah diupload jika gagal
    Storage::delete($photo->path);
    Log::error('Image processing chain failed: ' . $e->getMessage());

    // Notify admin
    Notification::route('slack', config('services.slack.webhook'))
        ->notify(new ImageProcessingFailed($e));
})->dispatch();

// Chain dengan delay — job pertama ditunda 1 jam
Bus::chain([
    new SendReminder($subscription),
    new ProcessRenewal($subscription),
])->delay(now()->addHour())->dispatch();

// Chain dengan queue berbeda
Bus::chain([
    (new ProcessPayment($order))->onQueue('high'),
    (new SendInvoice($order))->onQueue('default'),
    (new SendEmail($order))->onQueue('emails'),
])->dispatch();

// Chain dengan then — tambah job ke chain yang sudah ada
$chain = Bus::chain([
    new ValidateOrder($order),
    new ProcessPayment($order),
]);

$chain->chain([new SendConfirmation($order)])->dispatch();
```

## Kasus Penggunaan Nyata
Pendaftaran user: chain `CreateUser → AssignRole → SendWelcomeEmail → CreateDefaultProject`. Jika CreateUser sukses tapi AssignRole gagal, user tetap dibuat tapi tanpa role — perlu di-rollback manual via `catch()`.
