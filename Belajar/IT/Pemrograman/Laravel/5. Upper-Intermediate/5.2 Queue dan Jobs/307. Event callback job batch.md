# 307. Event callback job batch

## Definisi Singkat
Event callback pada job batch memungkinkan eksekusi kode otomatis di berbagai tahap: ketika batch selesai (success), gagal, atau selesai bagaimanapun — menggunakan method `then()`, `catch()`, dan `finally()`.

## Analogi
Seperti alarm di pabrik: ketika semua mesin selesai (then) — alarm hijau berbunyi. Jika ada mesin rusak (catch) — alarm merah. Apapun yang terjadi, setelah shift selesai (finally) — alarm mati dan laporan dicetak.

## Poin-Poin Penting
- `then()` — job sukses semua → kirim notifikasi, trigger workflow lanjutan
- `catch()` — minimal satu gagal → rollback, log error, alert admin
- `finally()` — apapun hasilnya → cleanup, update status
- Callback menerima instance `Illuminate\Bus\Batch`
- Batch bisa memiliki `allowFailures()` — job gagal tidak menghentikan batch

## Contoh Kode
```php
use Illuminate\Bus\Batch;
use Illuminate\Support\Facades\Bus;

// Batch dengan semua callback
$batch = Bus::batch([
    new ProcessVideoChunk($video, 1),
    new ProcessVideoChunk($video, 2),
    new ProcessVideoChunk($video, 3),
])
->name("Video Processing: {$video->name}")
->then(function (Batch $batch) use ($video) {
    // Semua chunk sukses — gabungkan dan publish
    $video->update(['status' => 'processing_complete']);
    Bus::batch([
        new MergeVideoChunks($video),
        new GenerateVideoThumbnail($video),
    ])->name("Video Finalization: {$video->name}")->dispatch();
})
->catch(function (Batch $batch, Throwable $e) use ($video) {
    // Chunk gagal — tandai video sebagai failed
    $video->update(['status' => 'failed', 'error' => $e->getMessage()]);
    Log::error("Video {$video->id} processing failed batch {$batch->id}");
})
->finally(function (Batch $batch) {
    // Bersihkan temporary files apapun hasilnya
    Storage::deleteDirectory("tmp/video_{$batch->id}");
})
->dispatch();

// Batch dengan allowFailures — job gagal tidak stop batch
Bus::batch([
    new SyncProduct($product1),
    new SyncProduct($product2),
    new SyncProduct($product3),
])
->allowFailures()  // Job gagal tetap lanjut ke job berikutnya
->then(function (Batch $batch) {
    $failed = $batch->failedJobs;
    Log::info("Sync selesai dengan {$failed} produk gagal");
})
->dispatch();

// Batch progress callback (dengan progress event)
// Tidak built-in, tapi bisa pakai database polling
```

## Kasus Penggunaan Nyata
Migrasi data dari sistem lama: batch 1000 job paralel dengan `allowFailures()` — data yang gagal dicatat, sisanya tetap diproses. Laporan akhir via `then()`: "999/1000 berhasil, 1 gagal — cek log".
