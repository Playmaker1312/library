# 294. Membuat job Artisan

## Definisi Singkat
`php artisan make:job NamaJob` adalah perintah untuk membuat kelas job baru — ditempatkan di `app/Jobs/` — yang mewakili satu tugas yang bisa diantre dan dieksekusi oleh queue worker.

## Analogi
Seperti mencetak formulir tugas: sekali cetak (make:job), formulir (class) siap diisi data dan dikirim ke antrian. Worker tinggal membaca dan mengerjakan sesuai instruksi.

## Poin-Poin Penting
- `php artisan make:job SendWelcomeEmail` — membuat file di `app/Jobs/SendWelcomeEmail.php`
- Setiap job mengimplementasikan `ShouldQueue` (bisa ditambahkan manual)
- Job class berisi constructor (menerima data) dan method `handle()` (logika)
- Parameter dikirim via constructor, disimpan di property public
- Job bisa di-dispatch secara synchronously (dispatchSync) atau async (dispatch)

## Contoh Kode
```bash
# Membuat job
php artisan make:job ProcessPayment
php artisan make:job SendOrderConfirmation
php artisan make:job ResizeProductImage
```

```php
// app/Jobs/ProcessPayment.php (hasil generate + modifikasi)
namespace App\Jobs;

use App\Models\Order;
use App\Services\PaymentGateway;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Queue\SerializesModels;

class ProcessPayment implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, SerializesModels;

    public function __construct(
        public Order $order  // SerializesModels ensures model is serialized
    ) {}

    public function handle(PaymentGateway $gateway): void
    {
        $gateway->charge($this->order->amount, $this->order->payment_token);
        $this->order->update(['status' => 'paid']);
    }
}

// app/Jobs/ResizeProductImage.php
class ResizeProductImage implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public function __construct(
        public string $imagePath,
        public int $width,
        public int $height
    ) {}

    public function handle(): void
    {
        Image::make(storage_path($this->imagePath))
            ->resize($this->width, $this->height)
            ->save();
    }
}
```

## Kasus Penggunaan Nyata
Setiap user upload foto profil → dispatch `ResizeAvatar` job → worker meresize ke 3 ukuran (small, medium, large) di background — user dapat response instant tanpa nunggu proses gambar selesai.
