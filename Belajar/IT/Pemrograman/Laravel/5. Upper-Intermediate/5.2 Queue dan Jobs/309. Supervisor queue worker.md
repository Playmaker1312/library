# 309. Supervisor queue worker

## Definisi Singkat
Supervisor adalah process control system untuk Linux yang memastikan `php artisan queue:work` tetap berjalan — otomatis restart jika crash, stop, atau restart server.

## Analogi
Seperti monitor detak jantung di rumah sakit: jika pasien (queue worker) berhenti bernafas (crash), monitor akan membangunkan perawat (Supervisor) yang segera melakukan CPR (restart). Pasien tetap hidup 24/7.

## Poin-Poin Penting
- Supervisor bukan bagian Laravel — install via apt/pecl
- Konfigurasi di `/etc/supervisor/conf.d/laravel-worker.conf`
- Bisa menjalankan multiple worker dari queue berbeda
- `autostart=true` — jalan otomatis saat server boot
- `autorestart=true` — restart otomatis jika crash
- `numprocs=N` — jumlah worker process yang dijalankan

## Contoh Kode
```bash
# Install Supervisor (Ubuntu/Debian)
sudo apt-get install supervisor

# Buat konfigurasi worker
sudo nano /etc/supervisor/conf.d/laravel-worker.conf
```

```ini
; /etc/supervisor/conf.d/laravel-worker.conf
[program:laravel-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/html/artisan queue:work redis --queue=high,default,low --sleep=3 --tries=3 --timeout=120
autostart=true
autorestart=true
stopasgroup=true
killasgroup=true
user=forge
numprocs=4
redirect_stderr=true
stdout_logfile=/var/www/html/storage/logs/worker.log
stopwaitsecs=360
```

```bash
# Multiple worker untuk queue berbeda
# /etc/supervisor/conf.d/laravel-high.conf
[program:laravel-high]
command=php /var/www/artisan queue:work redis --queue=high --sleep=3 --tries=5
numprocs=2
user=forge
autostart=true
autorestart=true

# /etc/supervisor/conf.d/laravel-emails.conf
[program:laravel-emails]
command=php /var/www/artisan queue:work redis --queue=emails --sleep=3 --tries=3
numprocs=3
user=forge
autostart=true
autorestart=true

# Perintah Supervisor
sudo supervisorctl reread      # Baca ulang konfigurasi
sudo supervisorctl update      # Terapkan perubahan
sudo supervisorctl start laravel-worker:*   # Start semua worker
sudo supervisorctl stop laravel-worker:*    # Stop semua worker
sudo supervisorctl restart laravel-worker:* # Restart semua worker
sudo supervisorctl status      # Cek status semua worker
```

## Kasus Penggunaan Nyata
Server production: Supervisor menjalankan 6 worker queue — 3 untuk queue `high` (prioritas), 2 untuk `default`, 1 untuk `emails`. Semua auto-restart jika crash, auto-start saat server reboot.
