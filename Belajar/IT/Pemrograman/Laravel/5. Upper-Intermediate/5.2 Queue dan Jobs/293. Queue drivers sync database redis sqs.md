# 293. Queue drivers sync database redis sqs

## Definisi Singkat
Laravel mendukung berbagai queue driver: sync (langsung/juga default development), database (MySQL/PostgreSQL sebagai antrian), Redis (in-memory cepat), dan SQS (Amazon managed queue) — masing-masing dengan tradeoff berbeda.

## Analogi
- **sync**: seperti masak langsung — cepat tapi bikin dapur penuh
- **database**: seperti kertas antrian — semua tercatat, aman, tapi agak lambat
- **redis**: seperti papan whiteboard — super cepat, data hilang jika listrik mati
- **SQS**: seperti jasa kurir — urusan diurus orang lain, skalabel, ada biaya

## Poin-Poin Penting
| Driver | Kecepatan | Persistence | Setup | Skalabilitas |
|--------|-----------|-------------|-------|-------------|
| sync | Instan | N/A | None | Tidak ada queue |
| database | Sedang | ✅ (disk) | Migration | Horizontal |
| redis | Sangat cepat | ❌ (RAM) | Redis server | Horizontal |
| SQS | Cepat | ✅ (AWS) | AWS akun | Auto-scaling |

## Contoh Kode
```php
// config/queue.php
'default' => env('QUEUE_CONNECTION', 'sync'),

// SYNC — untuk development/testing
// Semua job langsung dihandle di proses yang sama
// .env: QUEUE_CONNECTION=sync
// dispatch: job jalan langsung, blocking

// DATABASE — untuk production sederhana
// Step 1: Buat tabel jobs
// php artisan queue:table
// php artisan migrate
// .env: QUEUE_CONNECTION=database
// Worker: php artisan queue:work

// REDIS — untuk production tinggi
// Step 1: Install predis/predis atau phpredis
// composer require predis/predis
// .env: QUEUE_CONNECTION=redis
// Worker: php artisan queue:work redis --sleep=3

// SQS — untuk infrastruktur AWS
// .env:
// QUEUE_CONNECTION=sqs
// AWS_ACCESS_KEY_ID=xxx
// AWS_SECRET_ACCESS_KEY=xxx
// SQS_PREFIX=https://sqs.us-east-1.amazonaws.com/123456789
// SQS_QUEUE=my-queue
// Worker: php artisan queue:work sqs
```

## Kasus Penggunaan Nyata
Startup tahap awal pakai `database` (tanpa infrastruktur tambahan), lalu migrasi ke `redis` saat traffic naik, dan akhirnya ke `SQS` saat sudah multi-server di AWS dengan auto-scaling worker.
