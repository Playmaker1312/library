# 301. Job retry maksimal

## Definisi Singkat
Job retry maksimal (`$tries`) menentukan berapa kali Laravel akan mencoba ulang job yang gagal sebelum akhirnya dipindahkan ke tabel `failed_jobs`.

## Analogi
Seperti memancing: jika kail tidak dapat ikan (job gagal), kamu coba lagi (retry) sampai batas tertentu. Jika 3 kali tetap gagal, kamu ganti tempat mancing (failed_jobs) — bukan berarti berhenti total.

## Poin-Poin Penting
- `public $tries = 3;` — di class job (per-job config)
- `--tries=3` — di Artisan command (global config untuk semua job)
- Per-job config lebih diutamakan daripada CLI
- Retry count di-reset jika job sukses
- Gunakan `job->attempts()` untuk cek sudah berapa kali dicoba

## Contoh Kode
```php
// Opsi 1: Properti $tries di job class
class ProcessPayment implements ShouldQueue
{
    // Maksimal 3 kali percobaan
    public $tries = 3;

    public function handle(PaymentGateway $gateway): void
    {
        // Jika attempt ke-3, beri log khusus
        if ($this->attempts() === 3) {
            Log::warning('Payment final attempt', [
                'order' => $this->order->id
            ]);
        }

        $gateway->charge($this->order->amount, $this->order->payment_token);
        $this->order->update(['status' => 'paid']);
    }
}

// Opsi 2: Via Artisan command
// php artisan queue:work redis --tries=5

// Opsi 3: Method retryUntil — retry sampai waktu tertentu
class SendToExternalAPI implements ShouldQueue
{
    // Retry terus sampai jam 12:00 hari ini
    public function retryUntil(): DateTime
    {
        return now()->endOfDay();
    }
}

// Opsi 4: Kombinasi tries + retryUntil
class SyncData implements ShouldQueue
{
    public $tries = 10;  // max 10 attempts

    public function retryUntil(): DateTime
    {
        return now()->addHours(2);  // atau sampai 2 jam
    }

    public function handle(): void
    {
        // ...
    }
}

// Cek attempts di handle
public function handle(): void
{
    if ($this->job->attempts() > 2) {
        // Logging tambahan untuk attempt ke-3 dst
    }
    // ...
}
```

## Kasus Penggunaan Nyata
Job `CallWebhook` ke API eksternal yang tidak stabil: `$tries = 5` dengan exponential backoff — jika tetap gagal setelah 5 kali, masuk ke failed_jobs untuk diinvestigasi manual.
