# 308. Laravel Horizon Redis

## Definisi Singkat
Laravel Horizon adalah dashboard dan manajemen queue untuk Redis — menyediakan monitoring real-time, konfigurasi worker, balancing, dan metrik performa dalam satu UI yang indah.

## Analogi
Seperti ruang kontrol pabrik modern: ada layar besar yang menampilkan semua mesin (worker), antrian (queue), jumlah produksi (jobs processed), dan alarm jika ada masalah — semua real-time dari satu tempat.

## Poin-Poin Penting
- Eksklusif untuk Redis driver — tidak support database/SQS/beanstalkd
- Instal: `composer require laravel/horizon`
- Publish: `php artisan vendor:publish --provider="Laravel\Horizon\HorizonServiceProvider"`
- Dashboard di `/horizon` (dengan middleware auth)
- Konfigurasi worker balancing otomatis (auto, simple, false)
- Metrik: jobs processed, failed, throughput, queue length

## Contoh Kode
```bash
# Instalasi Horizon
composer require laravel/horizon
php artisan horizon:install

# Publish config
php artisan vendor:publish --provider="Laravel\Horizon\HorizonServiceProvider"

# Menjalankan Horizon (menggantikan queue:work)
php artisan horizon

# Graceful stop (selesai job yang sedang berjalan)
php artisan horizon:pause

# Lanjutkan
php artisan horizon:continue

# Lihat status
php artisan horizon:status

# Clear metrics
php artisan horizon:clear-metrics
```

```php
// config/horizon.php
'environments' => [
    'production' => [
        'supervisor-1' => [
            'connection' => 'redis',
            'queue' => ['high', 'default', 'emails', 'low'],
            'balance' => 'auto',
            'minProcesses' => 1,
            'maxProcesses' => 10,
            'tries' => 3,
        ],
    ],
    'local' => [
        'supervisor-1' => [
            'connection' => 'redis',
            'queue' => ['default'],
            'balance' => 'simple',
            'processes' => 3,
            'tries' => 3,
        ],
    ],
],

// Dashboard auth — proteksi route /horizon
// app/Providers/HorizonServiceProvider.php
protected function gate()
{
    Gate::define('viewHorizon', function ($user) {
        return $user->isAdmin();
    });
}
```

## Kasus Penggunaan Nyata
E-commerce besar dengan Redis: Horizon mengatur 10 worker auto-balancing — saat flash sale, worker otomatis scale ke max 20 process, setelah reda turun lagi, tanpa restart manual.
