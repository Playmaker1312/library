# 292. Konfigurasi queue config queue php

## Definisi Singkat
`config/queue.php` adalah file konfigurasi sentral yang mendefinisikan koneksi queue driver, default queue, dan pengaturan spesifik per driver (database, Redis, SQS, dll).

## Analogi
Seperti panel kontrol pabrik: di sini kamu atur jenis mesin (driver), jalur produksi (connection), dan antrian prioritas (queue name) — semua dari satu ruang kontrol.

## Poin-Poin Penting
- `default` — driver queue yang aktif (sync, database, redis)
- `connections` — definisi koneksi per driver dan konfigurasinya
- Setiap driver punya opsi spesifik (host, port, database, queue name)
- Queue name bisa dibedakan: high, low, default — untuk prioritas
- Environment variable via `.env` memudahkan switching driver

## Contoh Kode
```php
// config/queue.php
return [
    'default' => env('QUEUE_CONNECTION', 'sync'),
    // sync = langsung eksekusi (no queue, untuk development/testing)

    'connections' => [
        'sync' => [
            'driver' => 'sync',
        ],

        'database' => [
            'driver' => 'database',
            'table' => 'jobs',
            'queue' => 'default',
            'retry_after' => 90,
            'after_commit' => false,
        ],

        'redis' => [
            'driver' => 'redis',
            'connection' => 'default',
            'queue' => env('REDIS_QUEUE', 'default'),
            'retry_after' => 90,
            'block_for' => null,
            'after_commit' => false,
        ],

        'sqs' => [
            'driver' => 'sqs',
            'key' => env('AWS_ACCESS_KEY_ID'),
            'secret' => env('AWS_SECRET_ACCESS_KEY'),
            'prefix' => env('SQS_PREFIX', 'https://sqs.us-east-1.amazonaws.com/your-account'),
            'queue' => env('SQS_QUEUE', 'your-queue-name'),
            'suffix' => env('SQS_SUFFIX'),
            'region' => env('AWS_DEFAULT_REGION', 'us-east-1'),
        ],

        'beanstalkd' => [
            'driver' => 'beanstalkd',
            'host' => 'localhost',
            'queue' => 'default',
            'retry_after' => 90,
            'block_for' => 0,
        ],
    ],

    'failed' => [
        'driver' => env('QUEUE_FAILED_DRIVER', 'database-uuids'),
        'database' => env('DB_CONNECTION', 'mysql'),
        'table' => 'failed_jobs',
    ],
];

// .env
QUEUE_CONNECTION=database
// atau
QUEUE_CONNECTION=redis
```

## Kasus Penggunaan Nyata
Development pakai `QUEUE_CONNECTION=sync` (langsung jalan), staging pakai `database` (mudah debugging), production pakai `redis` (cepat, reliable, mendukung blocking pop).
