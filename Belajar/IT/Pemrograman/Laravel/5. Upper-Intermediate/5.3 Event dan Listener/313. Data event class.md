# 313. Data event class

## Definisi Singkat
Data dalam event class disimpan di property (biasanya public) yang diisi via constructor — ini adalah "pesan" yang akan diteruskan ke semua listener saat event dipicu.

## Analogi
Seperti amplop surat: event class adalah amplop, property adalah isi surat di dalamnya. Listener membuka amplop dan membaca isinya — bisa berupa model, array, atau nilai primitive.

## Poin-Poin Penting
- Property public memudahkan akses dari listener (`$event->user`)
- Constructor promotion (PHP 8+) membuat class lebih ringkas
- Trait `Dispatchable` — memungkinkan event di-dispatch via static method
- Trait `SerializesModels` — memastikan model Eloquent di-serialize dengan aman (untuk queue)
- Jangan simpan logika bisnis di event — event hanya data container

## Contoh Kode
```php
// Event dengan berbagai tipe data
class PaymentReceived
{
    use Dispatchable, SerializesModels;

    public function __construct(
        // Model Eloquent — otomatis di-serialize dengan SerializesModels
        public Order $order,

        // Tipe data sederhana
        public int $amount,
        public string $currency = 'IDR',

        // Array
        public array $metadata = [],

        // Nullable
        public ?User $payer = null,

        // Enum (PHP 8.1+)
        public PaymentMethod $method = PaymentMethod::BankTransfer,
    ) {}
}

// Listener mengakses data
class UpdateLedger
{
    public function handle(PaymentReceived $event): void
    {
        $event->order;        // Model
        $event->amount;       // int
        $event->currency;     // string
        $event->metadata;     // array
        $event->payer;        // ?User
        $event->method;       // PaymentMethod
    }
}

// Event tanpa trait SerializesModels (jika tidak di-queue)
class UiElementRendered
{
    use Dispatchable;

    public function __construct(
        public string $elementId,
        public array $metrics = [],
    ) {}
    // Tidak pakai SerializesModels karena tidak akan masuk queue
}

// Best practice: gunakan readonly property jika data tidak berubah
class OrderCancelled
{
    use Dispatchable, SerializesModels;

    public function __construct(
        public readonly Order $order,
        public readonly string $reason,
    ) {}
}
```

## Kasus Penggunaan Nyata
Event `TicketPurchased` membawa data: `$ticket` (model), `$quantity` (int), `$seatNumbers` (array), `$promoCode` (?string) — listener `SendETicket` menggunakan semua data untuk generate PDF tiket.
