# 316. EventServiceProvider

## Definisi Singkat
`EventServiceProvider` adalah tempat registrasi mapping antara event dan listener-nya — memberi tahu Laravel "event A harus memicu listener B, C, D" dalam satu file konfigurasi.

## Analogi
Seperti buku telepon darurat: di sini tercatat "Jika kebakaran (event), hubungi pemadam (listener), ambulans (listener), dan polisi (listener)". Semua mapping ada di satu tempat, mudah diubah.

## Poin-Poin Penting
- Terletak di `app/Providers/EventServiceProvider.php`
- Properti `$listen` — array asosiatif event => [listener, listener, ...]
- Method `boot()` — untuk registrasi event manual atau subscriber
- Bisa override `shouldDiscoverEvents()` untuk auto-discovery
- Jika auto-discovery aktif, registrasi manual tidak diperlukan

## Contoh Kode
```php
// app/Providers/EventServiceProvider.php
namespace App\Providers;

use App\Events\OrderPlaced;
use App\Events\UserRegistered;
use App\Listeners\SendOrderConfirmation;
use App\Listeners\UpdateInventory;
use App\Listeners\SendWelcomeEmail;
use App\Listeners\CreateDefaultWorkspace;
use App\Listeners\NotifyAdmin;
use Illuminate\Foundation\Support\Providers\EventServiceProvider as ServiceProvider;

class EventServiceProvider extends ServiceProvider
{
    // Mapping event → listener(s)
    protected $listen = [
        UserRegistered::class => [
            SendWelcomeEmail::class,
            CreateDefaultWorkspace::class,
            NotifyAdmin::class,
        ],

        OrderPlaced::class => [
            SendOrderConfirmation::class,
            UpdateInventory::class,
        ],

        // Event dengan satu listener
        PaymentFailed::class => [
            NotifyPaymentFailure::class,
        ],
    ];

    // Subscriber (akan dibahas di 321)
    protected $subscribe = [
        UserEventSubscriber::class,
    ];

    public function boot(): void
    {
        parent::boot();

        // Registrasi event manual (jika perlu)
        // Event::listen(function (OrderPlaced $event) {
        //     // Closure listener
        // });
    }

    // Override auto-discovery
    public function shouldDiscoverEvents(): bool
    {
        return true;  // Otomatis scan Events/ dan Listeners/
    }
}
```

## Kasus Penggunaan Nyata
Saat menambah fitur "User deleted" — cukup tambah entry `UserDeleted::class => [CleanupUserData::class, NotifyAdmin::class]` di `$listen`, tanpa edit controller atau model.
