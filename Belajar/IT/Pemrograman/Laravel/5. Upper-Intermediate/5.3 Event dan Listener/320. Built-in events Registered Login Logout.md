# 320. Built-in events Registered Login Logout

## Definisi Singkat
Laravel menyediakan event bawaan untuk autentikasi: `Registered` (user baru daftar), `Login` (user login), `Logout` (user logout), `Verified` (email terverifikasi), `PasswordReset` — semuanya bisa di-listener tanpa bikin event sendiri.

## Analogi
Seperti sensor otomatis di pintu hotel: sensor sudah terpasang (built-in events) — saat tamu check-in (login), saat tamu keluar (logout), saat tamu baru daftar (registered). Staff tinggal pasang reaksi (listener) tanpa perlu pasang sensor baru.

## Poin-Poin Penting
- Event berada di namespace `Illuminate\Auth\Events\*`
- Didispatch otomatis oleh Laravel auth system
- Tidak perlu dispatch manual — cukup buat listener
- Didaftarkan di `EventServiceProvider` seperti event biasa
- Berguna untuk: log aktivitas, kirim notifikasi, update statistik

## Contoh Kode
```php
// app/Providers/EventServiceProvider.php
use Illuminate\Auth\Events\Registered;
use Illuminate\Auth\Events\Login;
use Illuminate\Auth\Events\Logout;
use Illuminate\Auth\Events\Verified;
use Illuminate\Auth\Events\PasswordReset;

protected $listen = [
    Registered::class => [
        SendWelcomeEmail::class,
        CreateDefaultWorkspace::class,
        LogNewRegistration::class,
    ],

    Login::class => [
        LogUserLogin::class,
        SendLoginNotification::class,
    ],

    Logout::class => [
        LogUserLogout::class,
        ClearUserCache::class,
    ],

    Verified::class => [
        EnablePremiumFeatures::class,
    ],

    PasswordReset::class => [
        InvalidateOldTokens::class,
    ],
];

// Listener untuk Login event
use Illuminate\Auth\Events\Login;

class LogUserLogin
{
    public function handle(Login $event): void
    {
        // $event->user — instance User
        // $event->guard — guard name (web, api)
        // $event->remember — boolean

        Log::channel('auth')->info('User logged in', [
            'user_id' => $event->user->id,
            'ip' => request()->ip(),
            'guard' => $event->guard,
        ]);
    }
}

// Listener untuk Registered
use Illuminate\Auth\Events\Registered;

class SendWelcomeEmail
{
    public function handle(Registered $event): void
    {
        Mail::to($event->user)->send(new WelcomeMail($event->user));
    }
}
```

## Kasus Penggunaan Nyata
SaaS aplikasi: event `Registered` → listener `AssignFreeTrial`, `CreateDemoData`, `SendOnboardingEmails`. Event `Login` → listener `UpdateLastLogin`, `CheckSubscriptionStatus`, `LogGeoLocation`.
