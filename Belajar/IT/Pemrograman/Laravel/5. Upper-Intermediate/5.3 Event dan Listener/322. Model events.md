# 322. Model events

## Definisi Singkat
Model events (Eloquent events) adalah event bawaan yang dipicu saat terjadi operasi pada model: `retrieved`, `creating`, `created`, `updating`, `updated`, `saving`, `saved`, `deleting`, `deleted`, `restoring`, `restored`.

## Analogi
Seperti sensor di gudang: setiap kali barang masuk (creating/created), keluar (deleting/deleted), atau dipindah (updating/updated), sensor mengirim sinyal. Kamu bisa pasang reaksi otomatis — misal, update stok saat barang keluar.

## Poin-Poin Penting
- Bisa di-listener via EventServiceProvider (model events adalah event biasa)
- Atau via `$dispatchesEvents` property di model
- Atau via boot method model (trait/observer)
- `booted()` method untuk registrasi closure listener
- Observer adalah class khusus untuk model events (lebih terorganisir)

## Contoh Kode
```php
// Cara 1: Di model — $dispatchesEvents property
use App\Events\OrderCreated;
use App\Events\OrderUpdated;

class Order extends Model
{
    protected $dispatchesEvents = [
        'created' => OrderCreated::class,   // Dispatch event saat order dibuat
        'updated' => OrderUpdated::class,   // Dispatch event saat order diupdate
    ];
}

// Cara 2: Boot method model — closure listener
class Order extends Model
{
    protected static function booted(): void
    {
        // Sebelum create
        static::creating(function (Order $order) {
            $order->order_number = 'ORD-' . strtoupper(Str::random(8));
            $order->status = 'pending';
        });

        // Setelah create
        static::created(function (Order $order) {
            Log::info("Order {$order->id} created");
        });

        // Sebelum delete — cegah jika kondisi terpenuhi
        static::deleting(function (Order $order) {
            if ($order->status === 'shipped') {
                throw new \Exception('Cannot delete shipped order');
            }
        });
    }
}

// Cara 3: Observer class (dibahas di observer pattern)
// php artisan make:observer OrderObserver --model=Order
class OrderObserver
{
    public function creating(Order $order): void
    {
        $order->order_number = 'ORD-' . strtoupper(Str::random(8));
    }

    public function created(Order $order): void
    {
        // Event yang sudah di-dispatch via $dispatchesEvents
        // Akan memicu listener di EventServiceProvider
    }
}

// Model events yang tersedia:
// retrieved — saat data diambil dari DB
// creating / created — sebelum/sesudah INSERT
// updating / updated — sebelum/sesudah UPDATE
// saving / saved — sebelum/sesudah INSERT atau UPDATE
// deleting / deleted — sebelum/sesudah DELETE
// restoring / restored — sebelum/sesudah soft delete restore
```

## Kasus Penggunaan Nyata
Model `Transaction`: `creating` event meng-generate nomor invoice otomatis, `created` event dispatch `TransactionCreated` untuk listener `UpdateBalance`, dan `deleting` mencegah penghapusan transaksi yang sudah di-reconcile.
