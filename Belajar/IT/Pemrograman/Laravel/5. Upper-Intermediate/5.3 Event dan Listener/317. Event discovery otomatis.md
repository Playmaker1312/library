# 317. Event discovery otomatis

## Definisi Singkat
Event discovery otomatis memungkinkan Laravel secara otomatis menemukan dan mendaftarkan event/listener tanpa registrasi manual di `EventServiceProvider` — cukup scan direktori `app/Events/` dan `app/Listeners/`.

## Analogi
Seperti lemari arsip pintar: kamu cukup taruh dokumen (event) di laci A dan panduan tindakan (listener) di laci B — sistem otomatis menghubungkan yang cocok tanpa kamu harus menulis daftar isi manual.

## Poin-Poin Penting
- Diaktifkan dengan override `shouldDiscoverEvents()` return `true`
- Laravel scan semua file di `app/Listeners/` dan lihat method `handle()`
- Method `handle()` yang memiliki type-hint event class akan otomatis terdaftar
- Performance: cache events di production via `php artisan event:cache`
- Tidak perlu ubah `EventServiceProvider.$listen` untuk setiap event baru

## Contoh Kode
```php
// app/Providers/EventServiceProvider.php
class EventServiceProvider extends ServiceProvider
{
    // Tidak perlu $listen array — discovery akan scan

    public function shouldDiscoverEvents(): bool
    {
        return true;  // Aktifkan auto-discovery
    }

    public function boot(): void
    {
        parent::boot();
    }
}

// Cukup buat event di app/Events/
// app/Events/VideoProcessed.php
class VideoProcessed
{
    use Dispatchable;

    public function __construct(public Video $video) {}
}

// Dan listener di app/Listeners/
// app/Listeners/ConvertVideoFormat.php
class ConvertVideoFormat
{
    // Type-hint event — otomatis terdaftar!
    public function handle(VideoProcessed $event): void
    {
        // Convert video
    }
}

// app/Listeners/NotifyUserVideoReady.php
class NotifyUserVideoReady
{
    public function handle(VideoProcessed $event): void
    {
        // Kirim notifikasi
    }
}

// Cache event di production (wajib!)
// php artisan event:cache
// php artisan event:clear  // Hapus cache

// Cek daftar event yang terdaftar
// php artisan event:list
```

## Kasus Penggunaan Nyata
Tim besar dengan banyak event: cukup buat event dan listener di folder masing-masing — auto-discovery memastikan tidak ada yang lupa registrasi. `php artisan event:cache` di deployment untuk performance.
