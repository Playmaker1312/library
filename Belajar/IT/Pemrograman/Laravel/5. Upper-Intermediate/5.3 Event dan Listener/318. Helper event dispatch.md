# 318. Helper event dispatch

## Definisi Singkat
Event di-dispatch (dipicu) menggunakan helper global `event()` atau trait `Dispatchable` — keduanya mengirim event ke semua listener yang terdaftar tanpa perlu import facade tambahan.

## Analogi
Seperti membunyikan bel sekolah: helper `event()` seperti menekan tombol bel — semua guru (listener) di ruang berbeda mendengar dan bereaksi (mengakhiri pelajaran, memberitahu siswa, dll).

## Poin-Poin Penting
- `event(new NamaEvent($data))` — helper global
- `NamaEvent::dispatch($data)` — trait Dispatchable (harus use di event)
- Keduanya sama — dispatch event ke semua listener
- `dispatch()` bisa dipanggil dari mana saja (controller, job, command)
- Event bisa di-dispatch dengan delay: `NamaEvent::dispatch($data)->delay(now()->addHour())`

## Contoh Kode
```php
// Event dengan trait Dispatchable
class OrderPlaced
{
    use Dispatchable;  // Memberikan static method dispatch()

    public function __construct(public Order $order) {}
}

// Cara 1: Static dispatch via trait
class OrderController extends Controller
{
    public function store(OrderRequest $request)
    {
        $order = Order::create($request->validated());

        // Dispatch event — semua listener berjalan
        OrderPlaced::dispatch($order);

        return new OrderResource($order);
    }
}

// Cara 2: Helper global event()
use App\Events\OrderPlaced;

event(new OrderPlaced($order));

// Cara 3: Dispatch with delay (hanya jika event implements ShouldQueue)
OrderPlaced::dispatch($order)->delay(now()->addMinutes(30));

// Cara 4: Dispatch with onQueue
OrderPlaced::dispatch($order)->onQueue('events');

// Cara 5: DispatchAfterResponse — event jalan setelah response dikirim
OrderPlaced::dispatchAfterResponse($order);

// Dari Blade template (jarang)
// @php event(new App\Events\UserOnline($user)) @endphp

// Event tanpa trait Dispatchable — harus pakai event()
class LegacyEvent { ... }
event(new LegacyEvent($data));  // Tidak bisa LegacyEvent::dispatch()
```

## Kasus Penggunaan Nyata
Sistem review: user submit review → `ReviewSubmitted::dispatch($review, $rating)` → listener `UpdateProductRating`, `SendReviewNotification`, `CheckForBadWords` — semuanya dipicu dari satu baris kode.
