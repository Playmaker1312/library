# 312. Membuat event Artisan

## Definisi Singkat
`php artisan make:event NamaEvent` adalah perintah untuk membuat kelas event baru — ditempatkan di `app/Events/` — yang mendefinisikan data apa yang dibawa saat event dipicu.

## Analogi
Seperti mencetak undangan: kamu buat template undangan (make:event) yang berisi info penting (data class). Saat undangan dikirim (event fired), semua orang yang terdaftar (listener) akan menerima informasinya.

## Poin-Poin Penting
- `php artisan make:event OrderPlaced` — buat file di `app/Events/OrderPlaced.php`
- Event class biasanya berisi constructor dengan data publik
- Tidak wajib implement interface tertentu — class PHP biasa
- Bisa digunakan sendiri atau dengan listener
- Best practice: beri nama event dalam bentuk past tense (OrderShipped, UserRegistered)

## Contoh Kode
```bash
# Membuat event
php artisan make:event UserRegistered
php artisan make:event OrderPlaced
php artisan make:event PaymentConfirmed
```

```php
// app/Events/UserRegistered.php (hasil generate)
namespace App\Events;

use App\Models\User;
use Illuminate\Foundation\Events\Dispatchable;
use Illuminate\Queue\SerializesModels;

class UserRegistered
{
    use Dispatchable, SerializesModels;

    // Data yang dibawa event
    public User $user;
    public string $referralCode;

    public function __construct(User $user, string $referralCode = null)
    {
        $this->user = $user;
        $this->referralCode = $referralCode ?? 'NONE';
    }
}

// app/Events/OrderPlaced.php
class OrderPlaced
{
    use Dispatchable, SerializesModels;

    public function __construct(
        public Order $order,
        public array $cartItems,
        public string $paymentMethod
    ) {}
}

// Event tanpa data — hanya sinyal
class DailyReportGenerated
{
    use Dispatchable;

    public function __construct() {}
    // Tidak bawa data — listener cukup tahu "laporan sudah siap"
}
```

## Kasus Penggunaan Nyata
E-commerce: `make:event OrderPlaced` — event membawa `$order`, `$cartItems`, `$couponApplied`. Listener: `UpdateInventory`, `SendOrderEmail`, `ApplyReferralBonus`, `ClearCart`.
