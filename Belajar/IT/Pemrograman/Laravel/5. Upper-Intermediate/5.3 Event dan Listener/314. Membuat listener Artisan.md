# 314. Membuat listener Artisan

## Definisi Singkat
`php artisan make:listener NamaListener --event=NamaEvent` adalah perintah untuk membuat kelas listener yang merespons event tertentu — ditempatkan di `app/Listeners/`.

## Analogi
Seperti mendaftar newsletter: kamu buat kotak surat (make:listener) khusus untuk topik tertentu (event). Setiap kali ada berita (event dipicu), kotak suratmu akan terisi — dan kamu bisa bereaksi (handle method).

## Poin-Poin Penting
- `--event=NamaEvent` — otomatis generate method `handle` dengan type-hint
- Tanpa `--event` — listener kosong, harus tambah method handle manual
- Listener bisa di-queue dengan implement `ShouldQueue`
- Nama listener biasanya verb: SendEmail, UpdateStatus, LogActivity
- Method `handle()` menerima event instance sebagai parameter

## Contoh Kode
```bash
# Buat listener dengan event spesifik (otomatis generate handle method)
php artisan make:listener SendWelcomeEmail --event=UserRegistered
php artisan make:listener UpdateInventory --event=OrderPlaced
php artisan make:listener NotifyAdmin --event=OrderPlaced

# Buat listener tanpa event (manual)
php artisan make:listener LogUserActivity
```

```php
// app/Listeners/SendWelcomeEmail.php (dengan --event)
namespace App\Listeners;

use App\Events\UserRegistered;
use App\Mail\WelcomeMail;
use Illuminate\Support\Facades\Mail;

class SendWelcomeEmail
{
    // Method handle dengan type-hint event
    public function handle(UserRegistered $event): void
    {
        Mail::to($event->user->email)
            ->send(new WelcomeMail($event->user));

        Log::info("Welcome email sent to {$event->user->email}");
    }
}

// app/Listeners/LogUserActivity.php (tanpa --event)
class LogUserActivity
{
    // Tidak ada type-hint — listener manual
    public function handle($event): void
    {
        activity()
            ->performedOn($event->model ?? null)
            ->log(class_basename($event) . ' triggered');
    }
}

// Listener yang di-queue
class SendBulkNotification implements ShouldQueue
{
    use Queueable;

    public function handle(EventTriggered $event): void
    {
        // Proses berat di background
    }
}
```

## Kasus Penggunaan Nyata
Event `OrderPlaced` punya 3 listener: `SendOrderConfirmation` (email), `UpdateInventory` (kurangi stok), `NotifyAdmin` (Slack notif) — masing-masing dibuat via `make:listener --event=OrderPlaced`.
