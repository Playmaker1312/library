# 315. Metode handle listener

## Definisi Singkat
Method `handle()` pada listener adalah tempat eksekusi logika respons terhadap event — menerima instance event, mengakses datanya, dan menjalankan aksi (kirim email, log, update database, panggil API).

## Analogi
Seperti asisten pribadi: ketika kamu teriak "Ada tamu!" (event), asistenmu (listener) punya prosedur (handle method) — buka pintu, sambut tamu, tawarkan minuman. Setiap asisten punya tugas beda.

## Poin-Poin Penting
- Type-hint parameter dengan event class — Laravel otomatis inject
- Bisa return `void` atau tidak return apa pun
- Bisa dependency injection dari container selain event
- Jika listener throw exception, event tetap dilanjutkan ke listener lain (kecuali pakai queue)
- Satu listener bisa handle multiple event (via EventSubscriber)

## Contoh Kode
```php
// Listener standar — type-hint event
class SendOrderConfirmation
{
    public function handle(OrderPlaced $event): void
    {
        Mail::to($event->order->user)
            ->send(new OrderConfirmationMail($event->order));
    }
}

// Listener dengan dependency injection
class ChargePayment
{
    public function __construct(
        private PaymentGateway $gateway
    ) {}

    public function handle(OrderPlaced $event): void
    {
        // $gateway di-inject dari container
        $this->gateway->charge(
            $event->order->amount,
            $event->order->payment_token
        );
    }
}

// Listener dengan multiple langkah
class SyncToCRM
{
    public function handle(UserRegistered $event): void
    {
        $user = $event->user;

        // 1. Kirim ke CRM external
        $response = Http::post('https://crm.example.com/api/users', [
            'email' => $user->email,
            'name' => $user->name,
        ]);

        // 2. Simpan response CRM ID
        if ($response->successful()) {
            $user->update(['crm_id' => $response->json('id')]);
        }

        // 3. Log
        Log::info("User {$user->id} synced to CRM");
    }
}

// Listener yang menghentikan event propagation
class StopFurtherProcessing
{
    public function handle(SomeEvent $event): void
    {
        if ($someCondition) {
            // return false;  // Menghentikan listener berikutnya
            // Catatan: fitur ini sudah dihapus di Laravel 11
            // Gunakan event cancellation pattern
        }
    }
}
```

## Kasus Penggunaan Nyata
Listener `GenerateInvoicePDF.handle()`: menerima event `PaymentConfirmed`, inject `PDFService` dan `Storage`, generate invoice, upload ke S3, simpan path di database — semua dalam satu method.
