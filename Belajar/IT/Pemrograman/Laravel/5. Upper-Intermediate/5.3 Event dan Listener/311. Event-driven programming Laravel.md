# 311. Event-driven programming Laravel

## Definisi Singkat
Event-driven programming di Laravel memungkinkan berbagai bagian aplikasi bereaksi terhadap aksi tertentu tanpa saling terikat — event class mendefinisikan aksi, listener class merespons, semuanya loosely coupled.

## Analogi
Seperti stasiun radio: penyiar (event) menyiarkan berita ke semua frekuensi. Pendengar (listener) yang memasang frekuensi yang sama akan mendengar dan bereaksi — penyiar tidak perlu tahu siapa pendengarnya.

## Poin-Poin Penting
- Event adalah class sederhana yang menyimpan data
- Listener adalah class yang merespons event
- Satu event bisa punya banyak listener
- Dipisah dari controller — membuat kode lebih modular
- Bisa synchronous atau asynchronous (queue)
- Didaftarkan di `EventServiceProvider` atau auto-discovery

## Contoh Kode
```php
// Event — class sederhana, tidak butuh logika
class OrderShipped
{
    public function __construct(
        public Order $order
    ) {}
}

// Listener — bereaksi terhadap event
class SendShipmentNotification
{
    public function handle(OrderShipped $event): void
    {
        Mail::to($event->order->user)->send(new ShippedMail($event->order));
    }
}

class UpdateOrderStatus
{
    public function handle(OrderShipped $event): void
    {
        $event->order->update(['status' => 'shipped']);
    }
}

class LogShipment
{
    public function handle(OrderShipped $event): void
    {
        Log::info("Order {$event->order->id} shipped");
    }
}

// Tanpa event — tight coupling
class OrderController extends Controller
{
    public function ship(Order $order)
    {
        $order->update(['status' => 'shipped']);
        Mail::to($order->user)->send(...);
        Log::info("Order {$order->id} shipped");
        // Kalau tambah fitur, controller makin besar
    }
}

// Dengan event — loose coupling
class OrderController extends Controller
{
    public function ship(Order $order)
    {
        $order->update(['status' => 'shipped']);
        event(new OrderShipped($order));  // Semua listener jalan otomatis
    }
}
```

## Kasus Penggunaan Nyata
User registration: event `UserRegistered` dipicu — listener `SendWelcomeEmail`, `CreateDefaultWorkspace`, `AssignFreePlan`, `NotifyAdmin` berjalan tanpa controller tahu satu sama lain.
