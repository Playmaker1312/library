# 325. Kirim notifikasi email database SMS Slack

## Definisi Singkat
Notifikasi Laravel bisa dikirim melalui berbagai channel dalam satu class: `mail` (email), `database` (tabel notifications), `vonage` (SMS), `slack` (Slack webhook) — tanpa perlu kode terpisah untuk setiap channel.

## Analogi
Seperti menyebar pengumuman: kamu tulis satu pengumuman, lalu fotokopi untuk papan pengumuman (database), kirim email ke semua karyawan (mail), kirim SMS (vonage), dan post di Slack (slack). Satu sumber, banyak media.

## Poin-Poin Penting
- `toMail()` — return `MailMessage` untuk email
- `toDatabase()` — return array untuk tabel `notifications`
- `toVonage()` — return `VonageMessage` untuk SMS
- `toSlack()` — return `SlackMessage` untuk Slack
- `toBroadcast()` — untuk real-time broadcast (Pusher)
- Channel bisa dikombinasikan bebas di method `via()`

## Contoh Kode
```php
use Illuminate\Notifications\Messages\MailMessage;
use Illuminate\Notifications\Messages\VonageMessage;
use Illuminate\Notifications\Messages\SlackMessage;

class OrderNotification extends Notification implements ShouldQueue
{
    public function __construct(public Order $order) {}

    public function via(object $notifiable): array
    {
        return ['mail', 'database', 'vonage', 'slack'];
    }

    // Email
    public function toMail(object $notifiable): MailMessage
    {
        return (new MailMessage)
            ->subject("Pesanan #{$this->order->id}")
            ->greeting("Hi {$notifiable->name}")
            ->line("Pesanan Anda telah {$this->order->status}.")
            ->line("Total: Rp{$this->order->total}")
            ->action('Cek Pesanan', url("/orders/{$this->order->id}"))
            ->line('Terima kasih!');
    }

    // Database
    public function toDatabase(object $notifiable): array
    {
        return [
            'order_id' => $this->order->id,
            'status' => $this->order->status,
            'message' => "Pesanan #{$this->order->id} {$this->order->status}",
        ];
    }

    // SMS (Vonage — dulu Nexmo)
    public function toVonage(object $notifiable): VonageMessage
    {
        return (new VonageMessage)
            ->content("Pesanan #{$this->order->id} telah {$this->order->status}. Total: Rp{$this->order->total}")
            ->unicode();
    }

    // Slack
    public function toSlack(object $notifiable): SlackMessage
    {
        return (new SlackMessage)
            ->success()
            ->content("Pesanan baru: #{$this->order->order_number}")
            ->attachment(function ($attachment) {
                $attachment->title('Detail Pesanan', url("/orders/{$this->order->id}"))
                    ->fields([
                        'Customer' => $this->order->user->name,
                        'Total' => "Rp{$this->order->total}",
                        'Status' => $this->order->status,
                    ]);
            });
    }
}

// Kirim
$user->notify(new OrderNotification($order));

// Atau kirim via channel spesifik
$user->notify((new OrderNotification($order))->via('mail')); // hanya email
```

## Kasus Penggunaan Nyata
Marketplace: seller dapat notifikasi "Ada pesanan baru" via email + SMS (biar cepat) + database (buat history) — semua dari satu class `NewOrderNotification`.
