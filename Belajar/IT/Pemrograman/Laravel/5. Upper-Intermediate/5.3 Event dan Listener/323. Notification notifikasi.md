# 323. Notification notifikasi

## Definisi Singkat
Laravel Notification adalah sistem terpusat untuk mengirim notifikasi melalui berbagai saluran (channel) — email, database, SMS (via Vonage/Twilio), Slack, dan custom channel — dari satu class notifikasi.

## Analogi
Seperti pusat informasi mall: pengumuman bisa disampaikan lewat pengeras suara (SMS), papan informasi (database), brosur (email), atau chat WhatsApp (Slack). Cukup tulis satu pengumuman, pilih medianya.

## Poin-Poin Penting
- `php artisan make:notification NamaNotifikasi` — buat class notifikasi
- Setiap notification punya method `via($notifiable)` — menentukan channel
- Method `toMail()`, `toDatabase()`, `toSlack()`, `toVonage()` — format per channel
- Model yang notifiable harus use `Notifiable` trait
- Notifiable bisa User atau model lain (misal: Order untuk SMS ke customer)

## Contoh Kode
```php
// app/Notifications/OrderShippedNotification.php
namespace App\Notifications;

use App\Models\Order;
use Illuminate\Bus\Queueable;
use Illuminate\Notifications\Notification;
use Illuminate\Contracts\Queue\ShouldQueue;

class OrderShippedNotification extends Notification implements ShouldQueue
{
    use Queueable;

    public function __construct(
        public Order $order
    ) {}

    // Channel apa saja yang dipakai
    public function via(object $notifiable): array
    {
        return ['mail', 'database'];  // Email + simpan di database
    }

    // Format untuk email
    public function toMail(object $notifiable): MailMessage
    {
        return (new MailMessage)
            ->greeting("Halo {$notifiable->name}!")
            ->line("Pesanan #{$this->order->order_number} telah dikirim.")
            ->action('Lihat Pesanan', url("/orders/{$this->order->id}"))
            ->line('Terima kasih telah berbelanja!');
    }

    // Format untuk database
    public function toDatabase(object $notifiable): array
    {
        return [
            'order_id' => $this->order->id,
            'order_number' => $this->order->order_number,
            'message' => 'Pesanan telah dikirim',
        ];
    }
}

// Mengirim notifikasi
use App\Notifications\OrderShippedNotification;

// Ke satu user
$user->notify(new OrderShippedNotification($order));

// Ke banyak user (via Notification facade)
use Illuminate\Support\Facades\Notification;
Notification::send($users, new OrderShippedNotification($order));

// Ke notifiable non-User (misal: Order)
// Model Order harus use Notifiable
$order->notify(new OrderShippedNotification($order));
```

## Kasus Penggunaan Nyata
Aplikasi laundry: notifikasi "Pesanan siap" dikirim via WhatsApp (Twilio/Vonage) + email + database — user lihat di notifikasi in-app dan dapat pesan WhatsApp.
