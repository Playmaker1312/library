# 319. Listener queue

## Definisi Singkat
Listener bisa di-queue (asinkron) dengan mengimplementasikan interface `ShouldQueue` — sehingga eksekusinya ditunda dan tidak memperlambat response HTTP, cocok untuk listener yang berat (email, API call, export).

## Analogi
Seperti asisten yang mencatat pesan: ketika tamu datang (event), asisten utama (listener sync) menyambut langsung. Tugas lain seperti menyiapkan kamar (listener queue) dikerjakan oleh staf lain di belakang — tamu tidak perlu menunggu.

## Poin-Poin Penting
- Implement `Illuminate\Contracts\Queue\ShouldQueue`
- Gunakan trait `Illuminate\Queue\InteractsWithQueue` atau `Queueable`
- Listener queue tetap pakai `handle()` — perbedaannya hanya dieksekusi async
- Bisa set `$connection`, `$queue`, `$delay` di listener
- Jika listener sync gagal, response error; jika listener queue gagal, retry otomatis

## Contoh Kode
```php
// Listener sync — langsung jalan saat event di-dispatch
class LogUserLogin
{
    public function handle(UserLoggedIn $event): void
    {
        Log::info("User {$event->user->id} logged in");
    }
}

// Listener queue — di-queue, tidak nahan response
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Queue\InteractsWithQueue;

class SendLoginNotification implements ShouldQueue
{
    use InteractsWithQueue;

    public $tries = 5;  // Retry sampai 5 kali

    public function __construct()
    {
        $this->onQueue('notifications');  // Queue khusus
    }

    public function handle(UserLoggedIn $event): void
    {
        // Email/SMS notifikasi — berat, di-queue
        Mail::to($event->user)->send(new LoginAlertMail($event->user));
    }

    public function failed(UserLoggedIn $event, Throwable $e): void
    {
        Log::error("Login notification failed for user {$event->user->id}");
    }
}

// Listener dengan delay
class SendFollowUp implements ShouldQueue
{
    use InteractsWithQueue;

    public function handle(OrderPlaced $event): void
    {
        // Kirim follow-up email 24 jam setelah order
    }
}

// Dispatch listener queue — bisa with chain
OrderPlaced::dispatch($order);

// Jika listener juga implements ShouldQueue,
// Otomatis masuk queue saat event di-dispatch.

// config/queue.php
'listener' => [
    'timeout' => 120,
],
```

## Kasus Penggunaan Nyata
Event `VideoUploaded` punya listener `GenerateThumbnail` (heavy, queue) dan `NotifySubscribers` (heavy, queue) — keduanya `ShouldQueue` sehingga uploader dapat response "Upload sukses" tanpa menunggu proses thumbnail dan notifikasi.
