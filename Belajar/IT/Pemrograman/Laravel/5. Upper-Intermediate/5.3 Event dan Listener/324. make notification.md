# 324. make notification

## Definisi Singkat
`php artisan make:notification NamaNotifikasi` adalah perintah untuk membuat kelas notifikasi baru — ditempatkan di `app/Notifications/` — siap dikustomisasi dengan channel dan format pesan.

## Analogi
Seperti mencetak template pengumuman: `make:notification` memberikan kertas kosong dengan format standar — tinggal isi judul, isi pesan, dan pilih media penyampaian (email, SMS, Slack).

## Poin-Poin Penting
- `php artisan make:notification InvoicePaid` — buat file di `app/Notifications/InvoicePaid.php`
- Class extends `Notification` dan biasanya `implements ShouldQueue`
- Method `via()` — return array channel yang dipakai
- Method `toMail()`, `toDatabase()`, `toSlack()`, `toArray()`, dll
- Bisa terima data via constructor

## Contoh Kode
```bash
# Membuat notification
php artisan make:notification WelcomeNotification
php artisan make:notification InvoicePaidNotification
php artisan make:notification LowStockAlert
```

```php
// app/Notifications/InvoicePaidNotification.php (hasil generate + modifikasi)
namespace App\Notifications;

use App\Models\Invoice;
use Illuminate\Bus\Queueable;
use Illuminate\Notifications\Notification;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Notifications\Messages\MailMessage;

class InvoicePaidNotification extends Notification implements ShouldQueue
{
    use Queueable;

    public function __construct(
        public Invoice $invoice
    ) {}

    // Tentukan channel notifikasi
    public function via(object $notifiable): array
    {
        // Bisa conditional: email hanya jika user punya email
        $channels = ['database'];

        if ($notifiable->email) {
            $channels[] = 'mail';
        }

        return $channels;
    }

    // Format email
    public function toMail(object $notifiable): MailMessage
    {
        return (new MailMessage)
            ->subject("Invoice #{$this->invoice->number} telah dibayar")
            ->greeting("Yth. {$notifiable->name}")
            ->line("Invoice Anda sebesar Rp{$this->invoice->amount_formatted} telah dibayar.")
            ->action('Lihat Invoice', url("/invoices/{$this->invoice->id}"))
            ->line('Terima kasih!');
    }

    // Format database
    public function toDatabase(object $notifiable): array
    {
        return [
            'invoice_id' => $this->invoice->id,
            'amount' => $this->invoice->amount,
            'type' => 'payment_received',
        ];
    }

    // Format untuk API (JSON)
    public function toArray(object $notifiable): array
    {
        return [
            'title' => 'Pembayaran diterima',
            'body' => "Invoice #{$this->invoice->number} dibayar",
        ];
    }
}
```

## Kasus Penggunaan Nyata
SaaS: `make:notification TrialExpiringNotification` — notifikasi dikirim 3 hari sebelum trial habis via email (toMail) dan in-app (toDatabase) dengan link subscribe.
