# 259. Mengimplementasikan Perhitungan Komisi Marketplace dari Setiap Transaksi

## Definisi & Target
Membangun sistem komisi otomatis di mana marketplace mengambil persentase tertentu dari setiap transaksi yang berhasil. Komisi dihitung per order item dan disimpan di tabel commissions.

## Komponen yang Terlibat
- Service: `CommissionService`
- Model: Commission, OrderItem, Store
- Observers/Events

## Perintah Artisan CLI
- `php artisan make:observer CommissionObserver --model=OrderItem`

## Kode Implementasi (Per File)

**app/Services/CommissionService.php:**
```php
class CommissionService
{
    private const COMMISSION_RATE = 0.10;
    private const CATEGORY_RATES = [
        'elektronik' => 0.05,
        'fashion' => 0.08,
        'makanan' => 0.12,
    ];

    public function calculate(OrderItem $orderItem): Commission
    {
        $rate = $this->getRate($orderItem);
        $amount = $orderItem->subtotal * $rate;

        return Commission::create([
            'order_item_id' => $orderItem->id,
            'store_id' => $orderItem->store_id,
            'amount' => $amount,
            'rate' => $rate * 100,
            'status' => 'pending',
        ]);
    }

    private function getRate(OrderItem $orderItem): float
    {
        $product = $orderItem->product;
        $category = $product->category;

        if ($category && isset(self::CATEGORY_RATES[$category->slug])) {
            return self::CATEGORY_RATES[$category->slug];
        }

        return self::COMMISSION_RATE;
    }

    public function markAsAvailable(Commission $commission): void
    {
        if ($commission->status === 'pending') {
            $commission->update(['status' => 'available']);
        }
    }

    public function getStoreCommissionSummary(int $storeId): array
    {
        $commissions = Commission::where('store_id', $storeId);

        return [
            'total_pending' => (float) $commissions->clone()->where('status', 'pending')->sum('amount'),
            'total_available' => (float) $commissions->clone()->where('status', 'available')->sum('amount'),
            'total_withdrawn' => (float) $commissions->clone()->where('status', 'withdrawn')->sum('amount'),
            'balance' => (float) $commissions->clone()->whereIn('status', ['available'])->sum('amount'),
        ];
    }
}
```

**app/Observers/CommissionObserver.php:**
```php
class CommissionObserver
{
    public function __construct(protected CommissionService $commissionService) {}

    public function created(OrderItem $orderItem): void
    {
        if ($orderItem->order->payment_status === 'paid') {
            $this->commissionService->calculate($orderItem);
        }
    }

    public function updated(OrderItem $orderItem): void
    {
        $order = $orderItem->order;

        if ($order->wasChanged('payment_status') && $order->payment_status === 'paid') {
            $existing = Commission::where('order_item_id', $orderItem->id)->first();

            if (!$existing) {
                $this->commissionService->calculate($orderItem);
            }
        }

        if ($order->wasChanged('status') && $order->status === 'delivered') {
            $commission = Commission::where('order_item_id', $orderItem->id)->first();
            if ($commission) {
                $this->commissionService->markAsAvailable($commission);
            }
        }
    }
}
```

**app/Livewire/SellerCommissionSummary.php:**
```php
class SellerCommissionSummary extends Component
{
    public $store;
    public $summary = [];
    public $commissions = [];

    public function mount()
    {
        $this->store = auth()->user()->store;
        $this->loadSummary();
    }

    public function loadSummary()
    {
        $service = app(CommissionService::class);
        $this->summary = $service->getStoreCommissionSummary($this->store->id);

        $this->commissions = Commission::where('store_id', $this->store->id)
            ->with('orderItem.product', 'orderItem.order')
            ->latest()
            ->paginate(10);
    }

    public function render()
    {
        return view('livewire.seller-commission-summary');
    }
}
```

## Cara Integrasi & Pengujian
- Lakukan transaksi hingga payment_status = 'paid'
- Verifikasi commission terbuat otomatis via observer
- Komisi status 'pending' saat order belum delivered
- Saat status order berubah ke 'delivered', komisi jadi 'available'
- Cek ringkasan komisi di dashboard seller
- Hitung manual: rate 10% dari subtotal, bandingkan dengan yang tersimpan
- Uji dengan berbagai kategori produk (rate berbeda)
