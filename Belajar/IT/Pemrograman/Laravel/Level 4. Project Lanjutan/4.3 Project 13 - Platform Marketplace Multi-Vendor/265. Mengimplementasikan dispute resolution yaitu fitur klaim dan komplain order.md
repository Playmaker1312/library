# 265. Mengimplementasikan Dispute Resolution yaitu Fitur Klaim dan Komplain Order

## Definisi & Target
Membangun sistem dispute resolution (penyelesaian sengketa) untuk menangani klaim atau komplain dari pembeli terkait order. Admin bertindak sebagai mediator antara pembeli dan seller.

## Komponen yang Terlibat
- Livewire Component: `DisputeForm` dan `DisputeManagement`
- Model: Dispute

## Perintah Artisan CLI
- `php artisan make:livewire DisputeForm`
- `php artisan make:livewire DisputeManagement`

## Kode Implementasi (Per File)

**app/Livewire/DisputeForm.php:**
```php
class DisputeForm extends Component
{
    public $order;
    public $reason;
    public $description;
    public $evidence = [];

    protected $rules = [
        'reason' => 'required|in:produk_rusak,produk_salah,barang_tidak_sampai,pengembalian_dana,lainnya',
        'description' => 'required|string|min:20',
        'evidence.*' => 'nullable|file|mimes:jpg,jpeg,png,pdf|max:2048',
    ];

    public function mount($orderId)
    {
        $this->order = Order::with('items.product')->findOrFail($orderId);

        if ($this->order->user_id !== auth()->id()) {
            abort(403);
        }
    }

    public function submit()
    {
        $this->validate();

        $evidencePaths = [];
        foreach ($this->evidence as $file) {
            if ($file) {
                $evidencePaths[] = $file->store('disputes/' . $this->order->id, 'public');
            }
        }

        Dispute::create([
            'order_id' => $this->order->id,
            'user_id' => auth()->id(),
            'store_id' => $this->order->store_id,
            'reason' => $this->reason,
            'description' => $this->description,
            'evidence' => $evidencePaths,
            'status' => 'open',
        ]);

        $this->dispatch('disputeCreated');
    }

    public function render()
    {
        $existingDispute = Dispute::where('order_id', $this->order->id)->first();

        return view('livewire.dispute-form', compact('existingDispute'));
    }
}
```

**app/Livewire/DisputeManagement.php:**
```php
class DisputeManagement extends Component
{
    public $dispute;
    public $resolution;
    public $resolutionNote;
    public $refundAmount = 0;

    public function mount($disputeId = null)
    {
        if ($disputeId) {
            $this->dispute = Dispute::with('order.items', 'user', 'store')->findOrFail($disputeId);
        }
    }

    public function resolveDispute($disputeId, $action)
    {
        $dispute = Dispute::findOrFail($disputeId);

        $updateData = [
            'status' => $action === 'approve' ? 'resolved_buyer' : 'resolved_seller',
            'resolution' => $this->resolutionNote ?? 'Dispute telah diselesaikan',
            'resolved_at' => now(),
            'resolved_by' => auth()->id(),
        ];

        if ($action === 'approve') {
            $order = $dispute->order;
            $refundAmount = $this->refundAmount > 0 ? $this->refundAmount : $order->total;
            $updateData['refund_amount'] = $refundAmount;

            $order->update(['payment_status' => 'refunded']);
        }

        $dispute->update($updateData);
        $this->dispatch('disputeResolved');
    }

    public function render()
    {
        $disputes = Dispute::with('order', 'user', 'store')
            ->latest()
            ->paginate(10);

        return view('livewire.dispute-management', compact('disputes'));
    }
}
```

**app/Models/Dispute.php:**
```php
class Dispute extends Model
{
    use HasFactory;

    protected $fillable = [
        'order_id', 'user_id', 'store_id',
        'reason', 'description', 'evidence',
        'status', 'resolution', 'refund_amount',
        'resolved_at', 'resolved_by',
    ];

    protected $casts = [
        'evidence' => 'array',
        'resolved_at' => 'datetime',
    ];

    public function order(): BelongsTo
    {
        return $this->belongsTo(Order::class);
    }

    public function user(): BelongsTo
    {
        return $this->belongsTo(User::class);
    }

    public function store(): BelongsTo
    {
        return $this->belongsTo(Store::class);
    }

    public function scopeOpen(Builder $query): Builder
    {
        return $query->whereIn('status', ['open', 'in_review']);
    }
}
```

**Migration create_disputes_table:**
```php
Schema::create('disputes', function (Blueprint $table) {
    $table->id();
    $table->foreignId('order_id')->constrained()->cascadeOnDelete();
    $table->foreignId('user_id')->constrained();
    $table->foreignId('store_id')->constrained()->cascadeOnDelete();
    $table->enum('reason', ['produk_rusak', 'produk_salah', 'barang_tidak_sampai', 'pengembalian_dana', 'lainnya']);
    $table->text('description');
    $table->json('evidence')->nullable();
    $table->enum('status', ['open', 'in_review', 'resolved_buyer', 'resolved_seller'])->default('open');
    $table->text('resolution')->nullable();
    $table->decimal('refund_amount', 15, 2)->nullable();
    $table->timestamp('resolved_at')->nullable();
    $table->foreignId('resolved_by')->nullable()->constrained('users')->nullOnDelete();
    $table->timestamps();
});
```

## Cara Integrasi & Pengujian
- Pembeli membuka halaman dispute untuk order tertentu
- Pilih alasan komplain, isi deskripsi, upload bukti
- Submit -> dispute status "open"
- Admin melihat dispute di halaman manajemen
- Admin memutuskan: approve (refund) atau tolak
- Jika approve, order payment_status = 'refunded'
- Seller mendapat notifikasi dispute
- Verifikasi user tidak bisa membuat dispute ganda untuk order yang sama
- Semua dispute tercatat dengan riwayat lengkap
