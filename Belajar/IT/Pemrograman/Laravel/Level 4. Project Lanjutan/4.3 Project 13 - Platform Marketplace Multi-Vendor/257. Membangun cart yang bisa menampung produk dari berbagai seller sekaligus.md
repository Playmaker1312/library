# 257. Membangun Cart yang Bisa Menampung Produk dari Berbagai Seller Sekaligus

## Definisi & Target
Membangun sistem cart (keranjang belanja) yang dapat menampung produk dari multiple seller. Setiap item dalam cart mencatat store_id untuk keperluan split order saat checkout.

## Komponen yang Terlibat
- Livewire Component: `Cart`
- Session/cookie-based cart (untuk guest) atau database cart (untuk logged in)
- Model: Cart (opsional)

## Perintah Artisan CLI
- `php artisan make:livewire Cart`

## Kode Implementasi (Per File)

**app/Livewire/Cart.php:**
```php
class Cart extends Component
{
    public $cartItems = [];
    public $subtotal = 0;

    protected $listeners = ['addToCart' => 'addItem'];

    public function mount()
    {
        $this->loadCart();
    }

    public function addItem($productId, $quantity = 1)
    {
        $product = Product::with('store')->findOrFail($productId);

        $existingIndex = collect($this->cartItems)->search(
            fn($item) => $item['product_id'] === $productId
        );

        if ($existingIndex !== false) {
            $this->cartItems[$existingIndex]['quantity'] += $quantity;
        } else {
            $this->cartItems[] = [
                'product_id' => $product->id,
                'store_id' => $product->store_id,
                'store_name' => $product->store->name,
                'name' => $product->name,
                'price' => $product->price,
                'quantity' => $quantity,
                'image' => $product->images[0] ?? null,
                'subtotal' => $product->price * $quantity,
                'weight' => $product->weight,
            ];
        }

        $this->saveCart();
        $this->calculateSubtotal();
        $this->dispatch('cartUpdated');
    }

    public function updateQuantity($index, $quantity)
    {
        if (!isset($this->cartItems[$index])) return;
        $quantity = max(1, (int) $quantity);
        $this->cartItems[$index]['quantity'] = $quantity;
        $this->cartItems[$index]['subtotal'] = $this->cartItems[$index]['price'] * $quantity;
        $this->saveCart();
        $this->calculateSubtotal();
    }

    public function removeItem($index)
    {
        unset($this->cartItems[$index]);
        $this->cartItems = array_values($this->cartItems);
        $this->saveCart();
        $this->calculateSubtotal();
    }

    public function clearCart()
    {
        $this->cartItems = [];
        $this->saveCart();
        $this->calculateSubtotal();
    }

    public function getItemsByStore()
    {
        return collect($this->cartItems)->groupBy('store_id');
    }

    public function getStoreTotals()
    {
        return $this->getItemsByStore()->map(function ($items, $storeId) {
            return [
                'store_id' => $storeId,
                'store_name' => $items->first()['store_name'],
                'subtotal' => $items->sum('subtotal'),
                'total_weight' => $items->sum(fn($i) => $i['weight'] * $i['quantity']),
                'items_count' => $items->sum('quantity'),
            ];
        });
    }

    protected function loadCart()
    {
        if (auth()->check()) {
            $this->cartItems = session()->get('cart_' . auth()->id(), []);
        } else {
            $this->cartItems = session()->get('cart_guest', []);
        }
        $this->calculateSubtotal();
    }

    protected function saveCart()
    {
        $key = auth()->check() ? 'cart_' . auth()->id() : 'cart_guest';
        session()->put($key, $this->cartItems);
    }

    protected function calculateSubtotal()
    {
        $this->subtotal = collect($this->cartItems)->sum('subtotal');
    }

    public function render()
    {
        $itemsByStore = $this->getItemsByStore();
        $storeTotals = $this->getStoreTotals();

        return view('livewire.cart', compact('itemsByStore', 'storeTotals'));
    }
}
```

**resources/views/livewire/cart.blade.php:**
```html
<div class="max-w-4xl mx-auto p-6">
    <h1 class="text-2xl font-bold mb-6">Keranjang Belanja</h1>

    @forelse($itemsByStore as $storeId => $items)
    <div class="bg-white rounded-lg shadow mb-4">
        <div class="p-4 border-b bg-gray-50">
            <h2 class="font-semibold">Toko: {{ $items->first()['store_name'] }}</h2>
        </div>
        <div class="divide-y">
            @foreach($items as $index => $item)
            <div class="p-4 flex items-center space-x-4" wire:key="cart-item-{{ $storeId }}-{{ $index }}">
                <img src="{{ $item['image'] ?? 'https://via.placeholder.com/80' }}" class="w-16 h-16 object-cover rounded">
                <div class="flex-1">
                    <h3 class="font-semibold">{{ $item['name'] }}</h3>
                    <p class="text-blue-600 font-bold">Rp {{ number_format($item['price'], 0, ',', '.') }}</p>
                </div>
                <div class="flex items-center space-x-2">
                    <button wire:click="updateQuantity({{ $index }}, {{ $item['quantity'] - 1 }})"
                            class="w-8 h-8 bg-gray-200 rounded-full">-</button>
                    <input type="number" value="{{ $item['quantity'] }}" min="1"
                           wire:change="updateQuantity({{ $index }}, $event.target.value)"
                           class="w-12 text-center border rounded">
                    <button wire:click="updateQuantity({{ $index }}, {{ $item['quantity'] + 1 }})"
                            class="w-8 h-8 bg-gray-200 rounded-full">+</button>
                </div>
                <div class="text-right w-24">
                    <p class="font-semibold">Rp {{ number_format($item['subtotal'], 0, ',', '.') }}</p>
                    <button wire:click="removeItem({{ $index }})" class="text-red-500 text-sm">Hapus</button>
                </div>
            </div>
            @endforeach
        </div>
        <div class="p-4 text-right border-t">
            <p class="font-semibold">Subtotal Toko: Rp {{ number_format($storeTotals[$storeId]['subtotal'] ?? 0, 0, ',', '.') }}</p>
        </div>
    </div>
    @empty
    <div class="text-center py-16 bg-white rounded-lg shadow">
        <p class="text-4xl mb-4">🛒</p>
        <p class="text-gray-500">Keranjang belanja kosong</p>
        <a href="{{ route('products.index') }}" class="inline-block mt-4 bg-blue-600 text-white px-6 py-2 rounded">Belanja Sekarang</a>
    </div>
    @endforelse

    @if(count($cartItems) > 0)
    <div class="bg-white rounded-lg shadow p-4 flex justify-between items-center">
        <div>
            <p class="text-gray-500">Total Belanja</p>
            <p class="text-2xl font-bold text-blue-600">Rp {{ number_format($subtotal, 0, ',', '.') }}</p>
        </div>
        <div class="space-x-2">
            <button wire:click="clearCart" class="bg-gray-200 text-gray-700 px-4 py-2 rounded">Kosongkan</button>
            <a href="{{ route('checkout') }}" class="bg-blue-600 text-white px-6 py-2 rounded font-bold">Checkout</a>
        </div>
    </div>
    @endif
</div>
```

## Cara Integrasi & Pengujian
- Tambah produk dari toko A -> muncul di cart dengan label toko
- Tambah produk dari toko B -> muncul dalam grup terpisah
- Update quantity dan verifikasi subtotal berubah
- Hapus item dan verifikasi cart terupdate
- Cart tersimpan di session (guest) atau database (logged in)
- Klik Checkout -> lanjut ke halaman checkout
