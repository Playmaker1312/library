# 261. Mengimplementasikan Webhook Handler untuk Notifikasi Status Pembayaran

## Definisi & Target
Membangun endpoint webhook yang menerima notifikasi status pembayaran dari Midtrans/Xendit. Webhook memperbarui status order, mengaktifkan komisi, dan mengirim notifikasi ke seller.

## Komponen yang Terlibat
- Controller: `WebhookController`
- Route: webhook endpoint (tanpa CSRF)
- Model: Order, Commission

## Perintah Artisan CLI
- `php artisan make:controller WebhookController`

## Kode Implementasi (Per File)

**routes/web.php:**
```php
Route::post('/webhook/midtrans', [WebhookController::class, 'midtrans'])
    ->withoutMiddleware([\App\Http\Middleware\VerifyCsrfToken::class])
    ->name('webhook.midtrans');
```

**app/Http/Controllers/WebhookController.php:**
```php
use Midtrans\Transaction;

class WebhookController extends Controller
{
    public function midtrans(Request $request)
    {
        $payload = $request->all();

        \Log::info('Midtrans Webhook received', $payload);

        $orderId = $payload['order_id'];
        $transactionStatus = $payload['transaction_status'];
        $paymentType = $payload['payment_type'];
        $fraudStatus = $payload['fraud_status'] ?? 'accept';

        $order = Order::where('order_number', $orderId)->first();

        if (!$order) {
            \Log::warning('Order not found for webhook', ['order_id' => $orderId]);
            return response()->json(['message' => 'Order not found'], 404);
        }

        $this->processTransactionStatus($order, $transactionStatus, $fraudStatus, $paymentType);

        return response()->json(['message' => 'OK']);
    }

    private function processTransactionStatus(Order $order, string $status, string $fraudStatus, string $paymentType): void
    {
        switch ($status) {
            case 'capture':
                if ($fraudStatus === 'accept') {
                    $this->handlePaymentSuccess($order, $paymentType);
                }
                break;

            case 'settlement':
                $this->handlePaymentSuccess($order, $paymentType);
                break;

            case 'pending':
                $order->update(['status' => 'pending']);
                break;

            case 'deny':
            case 'cancel':
            case 'expire':
                $order->update([
                    'payment_status' => 'failed',
                    'status' => 'cancelled',
                    'payment_method' => $paymentType,
                ]);
                $this->restoreStock($order);
                break;

            case 'refund':
            case 'partial_refund':
                $order->update(['payment_status' => 'refunded']);
                break;
        }
    }

    private function handlePaymentSuccess(Order $order, string $paymentType): void
    {
        $order->update([
            'payment_status' => 'paid',
            'status' => 'confirmed',
            'payment_method' => $paymentType,
        ]);

        $order->user->notify(new OrderPaid($order));
    }

    private function restoreStock(Order $order): void
    {
        foreach ($order->items as $item) {
            $item->product->increment('stock', $item->quantity);
        }
    }

    public function verifySignature(array $payload): bool
    {
        $orderId = $payload['order_id'];
        $statusCode = $payload['status_code'];
        $grossAmount = $payload['gross_amount'];
        $serverKey = config('midtrans.server_key');
        $signature = hash('sha512', $orderId . $statusCode . $grossAmount . $serverKey);

        return $signature === ($payload['signature_key'] ?? '');
    }
}
```

**app/Http/Controllers/WebhookController.php (Xendit handler):**
```php
public function xendit(Request $request)
{
    $payload = $request->all();

    \Log::info('Xendit Webhook received', $payload);

    $event = $payload['event'] ?? '';
    $externalId = $payload['data']['external_id'] ?? '';
    $status = $payload['data']['status'] ?? '';

    // Xendit callback token verification
    $callbackToken = $request->header('x-callback-token');
    $expectedToken = env('XENDIT_WEBHOOK_TOKEN');

    if ($callbackToken !== $expectedToken) {
        return response()->json(['message' => 'Invalid token'], 401);
    }

    $order = Order::where('order_number', $externalId)->first();

    if (!$order) {
        return response()->json(['message' => 'Order not found'], 404);
    }

    match ($event) {
        'payment.succeeded' => $this->handlePaymentSuccess($order, 'xendit'),
        'payment.failed' => $order->update(['payment_status' => 'failed', 'status' => 'cancelled']),
        default => \Log::info('Unhandled Xendit event', ['event' => $event]),
    };

    return response()->json(['message' => 'OK']);
}
```

**app/Notifications/OrderPaid.php:**
```php
class OrderPaid extends Notification
{
    use Queueable;

    public function __construct(public Order $order) {}

    public function via($notifiable): array
    {
        return ['mail', 'database'];
    }

    public function toMail($notifiable): MailMessage
    {
        return (new MailMessage)
            ->subject('Pembayaran Berhasil - ' . $this->order->order_number)
            ->greeting('Halo ' . $notifiable->name . '!')
            ->line('Pembayaran untuk order ' . $this->order->order_number . ' telah berhasil.')
            ->line('Total: Rp ' . number_format($this->order->total, 0, ',', '.'))
            ->action('Lihat Order', url('/orders/' . $this->order->id))
            ->line('Terima kasih telah berbelanja.');
    }

    public function toArray($notifiable): array
    {
        return [
            'order_id' => $this->order->id,
            'order_number' => $this->order->order_number,
            'message' => 'Pembayaran berhasil untuk order ' . $this->order->order_number,
        ];
    }
}
```

## Cara Integrasi & Pengujian
- Set webhook URL di dashboard Midtrans/Xendit: `https://domain.com/webhook/midtrans`
- Lakukan pembayaran menggunakan payment gateway
- Verifikasi webhook diterima (cek log: `storage/logs/laravel.log`)
- Order terupdate payment_status = 'paid'
- Uji skenario: settlement, pending, deny, expired
- Verifikasi signature verification untuk keamanan
- Uji Xendit dengan callback token
- Notifikasi email terkirim ke pembeli
- Stok kembali normal saat pembayaran gagal
