# 254. Mengimplementasikan Sistem Registrasi Seller dengan Verifikasi Dokumen

## Definisi & Target
Membangun sistem registrasi seller di mana pengguna dapat mendaftar sebagai seller, mengunggah dokumen verifikasi (KTP, NPWP, dll), dan admin memverifikasi sebelum toko aktif.

## Komponen yang Terlibat
- Livewire Component: `SellerRegistration`
- Model: Store
- File Storage untuk dokumen

## Perintah Artisan CLI
- `php artisan make:livewire SellerRegistration`

## Kode Implementasi (Per File)

**app/Livewire/SellerRegistration.php:**
```php
class SellerRegistration extends Component
{
    public $storeName;
    public $storeDescription;
    public $address;
    public $phone;
    public $ktp;
    public $npwp;
    public $selfie;

    protected $rules = [
        'storeName' => 'required|string|max:255|unique:stores,name',
        'storeDescription' => 'required|string|min:20',
        'address' => 'required|string|max:500',
        'phone' => 'required|string|max:20',
        'ktp' => 'required|file|mimes:jpg,jpeg,png,pdf|max:2048',
        'npwp' => 'nullable|file|mimes:jpg,jpeg,png,pdf|max:2048',
        'selfie' => 'required|file|mimes:jpg,jpeg,png|max:2048',
    ];

    public function submit()
    {
        $this->validate();

        $documents = [];

        if ($this->ktp) {
            $documents['ktp'] = $this->ktp->store('seller-documents/' . auth()->id(), 'public');
        }
        if ($this->npwp) {
            $documents['npwp'] = $this->npwp->store('seller-documents/' . auth()->id(), 'public');
        }
        if ($this->selfie) {
            $documents['selfie'] = $this->selfie->store('seller-documents/' . auth()->id(), 'public');
        }

        Store::create([
            'user_id' => auth()->id(),
            'name' => $this->storeName,
            'slug' => Str::slug($this->storeName) . '-' . auth()->id(),
            'description' => $this->storeDescription,
            'address' => $this->address,
            'phone' => $this->phone,
            'documents' => $documents,
            'status' => 'pending',
        ]);

        $this->dispatch('registrationComplete');
    }

    public function render()
    {
        return view('livewire.seller-registration');
    }
}
```

**app/Livewire/AdminVerifySeller.php:**
```php
class AdminVerifySeller extends Component
{
    public function verify($storeId)
    {
        Store::findOrFail($storeId)->update([
            'status' => 'active',
            'verified_at' => now(),
        ]);
    }

    public function suspend($storeId)
    {
        Store::findOrFail($storeId)->update(['status' => 'suspended']);
    }

    public function render()
    {
        return view('livewire.admin-verify-seller', [
            'pendingStores' => Store::where('status', 'pending')->with('user')->get(),
        ]);
    }
}
```

## Cara Integrasi & Pengujian
- Pengguna mengakses halaman registrasi seller
- Isi form dan upload dokumen
- Submit -> toko muncul dengan status "pending"
- Admin membuka halaman verifikasi seller
- Admin klik "Verifikasi" -> status toko berubah jadi "active"
- Seller login dan lihat dashboard toko
- Uji validasi: nama toko unik, deskripsi min 20 karakter
