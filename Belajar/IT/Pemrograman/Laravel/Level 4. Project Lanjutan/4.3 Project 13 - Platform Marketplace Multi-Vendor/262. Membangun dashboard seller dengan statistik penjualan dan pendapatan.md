# 262. Membangun Dashboard Seller dengan Statistik Penjualan dan Pendapatan

## Definisi & Target
Membangun dashboard untuk seller yang menampilkan statistik penjualan, pendapatan, jumlah order, produk terlaris, dan grafik penjualan. Data diperbarui secara real-time.

## Komponen yang Terlibat
- Livewire Component: `SellerDashboard`
- Model: Order, OrderItem, Commission, Product

## Perintah Artisan CLI
- `php artisan make:livewire SellerDashboard`

## Kode Implementasi (Per File)

**app/Livewire/SellerDashboard.php:**
```php
class SellerDashboard extends Component
{
    public $store;
    public $stats = [];
    public $recentOrders = [];
    public $topProducts = [];
    public $salesChart = [];
    public $dateRange = 'week';

    public function mount()
    {
        $this->store = auth()->user()->store;
        $this->loadStats();
    }

    public function loadStats()
    {
        $storeId = $this->store->id;

        $this->stats = [
            'total_products' => Product::where('store_id', $storeId)->where('status', 'active')->count(),
            'total_orders' => OrderItem::where('store_id', $storeId)->distinct('order_id')->count('order_id'),
            'total_sales' => OrderItem::where('store_id', $storeId)
                ->whereHas('order', fn($q) => $q->where('payment_status', 'paid'))
                ->sum('subtotal'),
            'total_commission' => Commission::where('store_id', $storeId)->sum('amount'),
            'balance' => Commission::where('store_id', $storeId)->where('status', 'available')->sum('amount'),
            'pending_orders' => OrderItem::where('store_id', $storeId)
                ->whereHas('order', fn($q) => $q->where('status', 'pending'))->count(),
        ];

        $this->recentOrders = OrderItem::where('store_id', $storeId)
            ->with('order', 'product')
            ->latest()
            ->take(5)
            ->get()
            ->toArray();

        $this->topProducts = Product::where('store_id', $storeId)
            ->withCount(['orderItems as total_sold' => fn($q) => $q->whereHas('order', fn($oq) => $oq->where('payment_status', 'paid'))])
            ->orderByDesc('total_sold')
            ->take(5)
            ->get()
            ->toArray();

        $this->loadSalesChart();
    }

    public function loadSalesChart()
    {
        $storeId = $this->store->id;
        $days = match ($this->dateRange) { 'week' => 7, 'month' => 30, 'year' => 365, default => 7 };

        $this->salesChart = OrderItem::where('store_id', $storeId)
            ->whereHas('order', fn($q) => $q->where('payment_status', 'paid'))
            ->where('created_at', '>=', now()->subDays($days))
            ->selectRaw('DATE(created_at) as date, SUM(subtotal) as total, COUNT(*) as count')
            ->groupBy('date')
            ->orderBy('date')
            ->get()
            ->toArray();
    }

    public function render()
    {
        return view('livewire.seller-dashboard');
    }
}
```

## Cara Integrasi & Pengujian
- Login sebagai seller yang sudah terverifikasi
- Akses dashboard seller
- Verifikasi 5 kartu statistik di bagian atas
- Cek grafik penjualan dengan filter 7/30/365 hari
- Lihat produk terlaris dan order terbaru
- Data polling setiap 30 detik
- Bandingkan angka dengan data di database
