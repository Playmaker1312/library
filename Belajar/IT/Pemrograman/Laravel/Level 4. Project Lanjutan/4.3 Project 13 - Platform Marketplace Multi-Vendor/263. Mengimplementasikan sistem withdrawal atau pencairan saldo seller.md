# 263. Mengimplementasikan Sistem Withdrawal atau Pencairan Saldo Seller

## Definisi & Target
Membangun fitur penarikan saldo (withdrawal) bagi seller untuk mencairkan komisi yang tersedia ke rekening bank. Admin memproses dan mengkonfirmasi pencairan.

## Komponen yang Terlibat
- Livewire Component: `WithdrawalRequest`
- Model: Withdrawal, Commission
- Service: `WithdrawalService`

## Perintah Artisan CLI
- `php artisan make:livewire WithdrawalRequest`

**app/Livewire/WithdrawalRequest.php:**
```php
class WithdrawalRequest extends Component
{
    public $store;
    public $amount = 0;
    public $bankName;
    public $bankAccountNumber;
    public $bankAccountName;
    public $balance = 0;
    public $withdrawals = [];

    protected $rules = [
        'amount' => 'required|numeric|min:10000',
        'bankName' => 'required|string',
        'bankAccountNumber' => 'required|string',
        'bankAccountName' => 'required|string',
    ];

    public function mount()
    {
        $this->store = auth()->user()->store;
        $this->loadBalance();
        $this->loadWithdrawals();
    }

    public function loadBalance()
    {
        $this->balance = Commission::where('store_id', $this->store->id)
            ->where('status', 'available')
            ->sum('amount');
    }

    public function loadWithdrawals()
    {
        $this->withdrawals = Withdrawal::where('store_id', $this->store->id)
            ->latest()
            ->get()
            ->toArray();
    }

    public function submit()
    {
        $this->validate();

        if ($this->amount > $this->balance) {
            $this->addError('amount', 'Saldo tidak mencukupi. Saldo tersedia: Rp ' . number_format($this->balance));
            return;
        }

        if ($this->amount < 10000) {
            $this->addError('amount', 'Minimal penarikan Rp 10.000');
            return;
        }

        DB::transaction(function () {
            $withdrawal = Withdrawal::create([
                'store_id' => $this->store->id,
                'amount' => $this->amount,
                'bank_name' => $this->bankName,
                'bank_account_number' => $this->bankAccountNumber,
                'bank_account_name' => $this->bankAccountName,
                'status' => 'pending',
            ]);

            $commissions = Commission::where('store_id', $this->store->id)
                ->where('status', 'available')
                ->limit(100)
                ->get();

            $remaining = $this->amount;
            foreach ($commissions as $commission) {
                if ($remaining <= 0) break;

                $commission->update(['status' => 'withdrawn']);
                $remaining -= $commission->amount;
            }
        });

        $this->reset(['amount', 'bankName', 'bankAccountNumber', 'bankAccountName']);
        $this->loadBalance();
        $this->loadWithdrawals();
        $this->dispatch('withdrawalSubmitted');
    }

    public function render()
    {
        return view('livewire.withdrawal-request');
    }
}
```

**app/Livewire/AdminWithdrawalApproval.php:**

class AdminWithdrawalApproval extends Component
{
    public function approve($withdrawalId)
    {
        Withdrawal::findOrFail($withdrawalId)->update([
            'status' => 'completed',
            'processed_at' => now(),
        ]);
    }

    public function process($withdrawalId)
    {
        Withdrawal::findOrFail($withdrawalId)->update(['status' => 'processing']);
    }

    public function reject($withdrawalId, $notes = null)
    {
        $withdrawal = Withdrawal::findOrFail($withdrawalId);
        $withdrawal->update(['status' => 'rejected', 'notes' => $notes]);
    }

    public function render()
    {
        return view('livewire.admin-withdrawal-approval', [
            'pendingWithdrawals' => Withdrawal::with('store.user')
                ->whereIn('status', ['pending', 'processing'])
                ->latest()
                ->get(),
        ]);
    }
}

## Cara Integrasi & Pengujian
- Seller dengan saldo available mengajukan penarikan
- Verifikasi validasi: jumlah > saldo, minimal Rp 10.000
- Data withdrawal tersimpan dengan status "pending"
- Admin menyetujui -> status "completed"
- Cek komisi berstatus "withdrawn"
- Seller melihat riwayat penarikan
- Uji penolakan dengan catatan
