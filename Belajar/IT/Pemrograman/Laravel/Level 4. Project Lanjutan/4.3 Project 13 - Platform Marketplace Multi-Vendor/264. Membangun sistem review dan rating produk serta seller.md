# 264. Membangun Sistem Review dan Rating Produk serta Seller

## Definisi & Target
Membangun sistem review dan rating di mana pembeli dapat memberikan penilaian (1-5 bintang) dan ulasan tertulis untuk produk yang sudah dibeli. Rating juga diakumulasi ke level seller.

## Komponen yang Terlibat
- Livewire Component: `ProductReview`
- Model: Review

## Perintah Artisan CLI
- `php artisan make:livewire ProductReview`

## Kode Implementasi (Per File)

**app/Livewire/ProductReview.php:**
```php
class ProductReview extends Component
{
    public $product;
    public $rating = 5;
    public $comment;
    public $userReview;
    public $reviews;
    public $stats;

    protected $rules = [
        'rating' => 'required|integer|min:1|max:5',
        'comment' => 'required|string|min:10|max:1000',
    ];

    public function mount($productId)
    {
        $this->product = Product::with('store')->findOrFail($productId);
        $this->loadReviews();

        if (auth()->check()) {
            $this->userReview = Review::where('product_id', $productId)
                ->where('user_id', auth()->id())->first();
        }
    }

    public function submit()
    {
        $this->validate();

        $existing = Review::where('product_id', $this->product->id)
            ->where('user_id', auth()->id())->first();

        if ($existing) {
            $this->addError('comment', 'Anda sudah memberikan review untuk produk ini');
            return;
        }

        Review::create([
            'product_id' => $this->product->id,
            'store_id' => $this->product->store_id,
            'user_id' => auth()->id(),
            'rating' => $this->rating,
            'comment' => $this->comment,
        ]);

        $this->reset(['rating', 'comment']);
        $this->loadReviews();
        $this->dispatch('reviewSubmitted');
    }

    public function loadReviews()
    {
        $this->reviews = Review::where('product_id', $this->product->id)
            ->with('user')
            ->latest()
            ->get()
            ->toArray();

        $this->stats = [
            'average' => Review::where('product_id', $this->product->id)->avg('rating') ?? 0,
            'total' => Review::where('product_id', $this->product->id)->count(),
            'distribution' => collect(range(5, 1))->mapWithKeys(fn($r) => [
                $r => Review::where('product_id', $this->product->id)->where('rating', $r)->count(),
            ]),
        ];
    }

    public function render()
    {
        return view('livewire.product-review');
    }
}
```

**app/Models/Review.php:**
```php
class Review extends Model
{
    use HasFactory;

    protected $fillable = ['product_id', 'store_id', 'user_id', 'rating', 'comment'];

    public function product(): BelongsTo
    {
        return $this->belongsTo(Product::class);
    }

    public function store(): BelongsTo
    {
        return $this->belongsTo(Store::class);
    }

    public function user(): BelongsTo
    {
        return $this->belongsTo(User::class);
    }

    public function scopeForStore(Builder $query, int $storeId): Builder
    {
        return $query->where('store_id', $storeId);
    }
}
```

- Guest melihat tombol login untuk memberikan ulasan
- Rating juga terlihat di halaman toko seller
