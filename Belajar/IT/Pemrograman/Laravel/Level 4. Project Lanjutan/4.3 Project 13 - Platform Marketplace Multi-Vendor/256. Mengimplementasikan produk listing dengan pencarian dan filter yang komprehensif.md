# 256. Mengimplementasikan Produk Listing dengan Pencarian dan Filter yang Komprehensif

## Definisi & Target
Membangun halaman produk listing publik dengan fitur pencarian, filter kategori, filter harga, filter lokasi, sort by, dan pagination. Menggunakan Livewire untuk pengalaman real-time.

## Komponen yang Terlibat
- Livewire Component: `ProductListing`
- Model: Product, Category

## Perintah Artisan CLI
- `php artisan make:livewire ProductListing`

## Kode Implementasi (Per File)

**app/Livewire/ProductListing.php:**
```php
class ProductListing extends Component
{
    public $search = '';
    public $categoryId = '';
    public $minPrice = '';
    public $maxPrice = '';
    public $sortBy = 'newest';
    public $perPage = 12;

    protected $queryString = ['search', 'categoryId', 'minPrice', 'maxPrice', 'sortBy'];

    public function render()
    {
        $query = Product::where('status', 'active')
            ->with('store', 'category')
            ->when($this->search, function ($q) {
                $q->where(function ($sub) {
                    $sub->where('name', 'like', '%' . $this->search . '%')
                        ->orWhereHas('store', fn($s) => $s->where('name', 'like', '%' . $this->search . '%'));
                });
            })
            ->when($this->categoryId, fn($q) => $q->where('category_id', $this->categoryId))
            ->when($this->minPrice, fn($q) => $q->where('price', '>=', $this->minPrice))
            ->when($this->maxPrice, fn($q) => $q->where('price', '<=', $this->maxPrice));

        $query = match ($this->sortBy) {
            'price_asc' => $query->orderBy('price'),
            'price_desc' => $query->orderBy('price', 'desc'),
            'name_asc' => $query->orderBy('name'),
            'name_desc' => $query->orderBy('name', 'desc'),
            default => $query->latest(),
        };

        $products = $query->paginate($this->perPage);
        $categories = Category::withCount(['products' => fn($q) => $q->where('status', 'active')])->get();
        $priceRange = Product::where('status', 'active')->selectRaw('MIN(price) as min, MAX(price) as max')->first();

        return view('livewire.product-listing', compact('products', 'categories', 'priceRange'));
    }

    public function resetFilters()
    {
        $this->reset(['search', 'categoryId', 'minPrice', 'maxPrice', 'sortBy']);
    }
}
```

## Cara Integrasi & Pengujian
- Akses halaman produk listing
- Ketik kata kunci di pencarian -> hasil berubah real-time
- Filter berdasarkan kategori
- Filter berdasarkan rentang harga
- Sort by berbagai opsi
- Klik Reset Filter untuk kembali ke default
- Verifikasi pagination berfungsi dengan filter
- URL query string mencerminkan filter yang aktif
