# 260. Mengintegrasikan Payment Gateway Midtrans atau Xendit untuk Pembayaran

## Definisi & Target
Mengintegrasikan payment gateway (Midtrans/Xendit) untuk memproses pembayaran order. Pembeli diarahkan ke halaman pembayaran, dan status pembayaran diperbarui secara otomatis via callback/webhook.

## Komponen yang Terlibat
- Library: midtrans/midtrans-php atau xendit/xendit-php
- Controller: `PaymentController`
- Model: Order, Payment
- Config: midtrans.php

## Perintah Artisan CLI
- `composer require midtrans/midtrans-php`
- `php artisan make:controller PaymentController`

## Kode Implementasi (Per File)

**config/midtrans.php:**
```php
return [
    'server_key' => env('MIDTRANS_SERVER_KEY'),
    'client_key' => env('MIDTRANS_CLIENT_KEY'),
    'is_production' => env('MIDTRANS_IS_PRODUCTION', false),
    'is_sanitized' => true,
    'is_3ds' => true,
];
```

**app/Http/Controllers/PaymentController.php:**
```php
use Midtrans\Snap;
use Midtrans\Config;

class PaymentController extends Controller
{
    public function __construct()
    {
        Config::$serverKey = config('midtrans.server_key');
        Config::$isProduction = config('midtrans.is_production');
        Config::$isSanitized = config('midtrans.is_sanitized');
        Config::$is3ds = config('midtrans.is_3ds');
    }

    public function charge(Request $request)
    {
        $order = Order::with('items.product')->findOrFail($request->order_id);

        if ($order->payment_status === 'paid') {
            return back()->with('error', 'Order sudah dibayar');
        }

        $transactionDetails = [
            'order_id' => $order->order_number,
            'gross_amount' => (int) $order->total,
        ];

        $itemDetails = $order->items->map(fn($item) => [
            'id' => $item->product_id,
            'price' => (int) $item->price,
            'quantity' => $item->quantity,
            'name' => substr($item->product->name, 0, 50),
        ])->toArray();

        $customerDetails = [
            'first_name' => $order->user->name,
            'email' => $order->user->email,
        ];

        try {
            $snapToken = Snap::getSnapToken([
                'transaction_details' => $transactionDetails,
                'item_details' => $itemDetails,
                'customer_details' => $customerDetails,
            ]);

            return response()->json(['token' => $snapToken]);
        } catch (\Exception $e) {
            return response()->json(['error' => $e->getMessage()], 500);
        }
    }

    public function finish(Request $request)
    {
        $order = Order::where('order_number', $request->order_id)->first();

        if ($order && $request->transaction_status === 'capture' || $request->transaction_status === 'settlement') {
            $order->update([
                'payment_status' => 'paid',
                'payment_method' => $request->payment_type,
                'status' => 'confirmed',
            ]);
        }

        return redirect()->route('orders.show', $order)->with('success', 'Pembayaran berhasil');
    }

    public function unfinish(Request $request)
    {
        return redirect()->route('orders.show', $request->order_id)->with('error', 'Pembayaran belum selesai');
    }

    public function error(Request $request)
    {
        return redirect()->route('orders.show', $request->order_id)->with('error', 'Pembayaran gagal');
    }
}
```

**resources/views/checkout/payment.blade.php:**
```html
<x-app-layout>
    <div class="max-w-2xl mx-auto p-6">
        <div class="bg-white rounded-lg shadow p-6 text-center">
            <h1 class="text-2xl font-bold mb-4">Pilih Metode Pembayaran</h1>
            <p class="text-gray-500 mb-6">Order: {{ $order->order_number }}</p>
            <p class="text-3xl font-bold text-blue-600 mb-6">Rp {{ number_format($order->total, 0, ',', '.') }}</p>

            <button id="pay-button" class="bg-blue-600 text-white px-8 py-3 rounded-lg font-bold hover:bg-blue-700">
                Bayar Sekarang
            </button>
        </div>
    </div>

    <script src="https://app.sandbox.midtrans.com/snap/snap.js" data-client-key="{{ config('midtrans.client_key') }}"></script>
    <script>
        document.getElementById('pay-button').onclick = function() {
            fetch('{{ route('payment.charge') }}', {
                method: 'POST',
                headers: { 'Content-Type': 'application/json', 'X-CSRF-TOKEN': '{{ csrf_token() }}' },
                body: JSON.stringify({ order_id: {{ $order->id }} })
            })
            .then(res => res.json())
            .then(data => {
                if (data.token) {
                    snap.pay(data.token, {
                        onSuccess: function(result) { window.location.href = '{{ route('payment.finish') }}?order_id=' + result.order_id + '&transaction_status=' + result.transaction_status + '&transaction_id=' + result.transaction_id + '&payment_type=' + result.payment_type; },
                        onPending: function(result) { window.location.href = '{{ route('payment.unfinish') }}?order_id=' + result.order_id; },
                        onError: function(result) { window.location.href = '{{ route('payment.error') }}?order_id=' + result.order_id; },
                    });
                }
            });
        };
    </script>
</x-app-layout>
```

**routes/web.php:**
```php
Route::post('/payment/charge', [PaymentController::class, 'charge'])->name('payment.charge');
Route::get('/payment/finish', [PaymentController::class, 'finish'])->name('payment.finish');
Route::get('/payment/unfinish', [PaymentController::class, 'unfinish'])->name('payment.unfinish');
Route::get('/payment/error', [PaymentController::class, 'error'])->name('payment.error');
```

## Cara Integrasi & Pengujian
- Set MIDTRANS_SERVER_KEY dan MIDTRANS_CLIENT_KEY di .env
- Uji dengan mode sandbox (is_production = false)
- Klik "Bayar Sekarang" -> muncul popup Snap Midtrans
- Pilih metode pembayaran (virtual account, credit card, dll)
- Selesaikan pembayaran -> redirect ke halaman sukses
- Verifikasi payment_status berubah menjadi 'paid'
- Uji skenario pembayaran gagal dan pending
