# 258. Mengimplementasikan Split Order Berdasarkan Seller Saat Checkout

## Definisi & Target
Membangun proses checkout yang secara otomatis memisahkan order berdasarkan seller. Satu transaksi checkout akan menghasilkan banyak order (satu per seller), sehingga setiap seller menerima order masing-masing.

## Komponen yang Terlibat
- Livewire Component: `Checkout`
- Model: Order, OrderItem
- Database Transaction

## Perintah Artisan CLI
- `php artisan make:livewire Checkout`

## Kode Implementasi (Per File)

**app/Livewire/Checkout.php:**
```php
class Checkout extends Component
{
    public $cartItems = [];
    public $shippingAddress;
    public $shippingCost = 0;
    public $subtotal = 0;
    public $total = 0;
    public $courier = 'jne';

    protected $rules = [
        'shippingAddress' => 'required|string|min:10',
        'courier' => 'required|in:jne,tiki,pos',
    ];

    public function mount()
    {
        $this->loadCart();
    }

    public function loadCart()
    {
        $key = auth()->check() ? 'cart_' . auth()->id() : 'cart_guest';
        $this->cartItems = session()->get($key, []);
        $this->calculateTotals();
    }

    public function calculateTotals()
    {
        $this->subtotal = collect($this->cartItems)->sum('subtotal');
        $this->shippingCost = $this->calculateShipping();
        $this->total = $this->subtotal + $this->shippingCost;
    }

    public function calculateShipping()
    {
        $totalWeight = collect($this->cartItems)->sum(fn($item) => $item['weight'] * $item['quantity']);
        $rate = match ($this->courier) {
            'jne' => 8000,
            'tiki' => 10000,
            'pos' => 12000,
        };
        return $totalWeight * $rate;
    }

    public function placeOrder()
    {
        $this->validate();

        if (empty($this->cartItems)) {
            $this->addError('cart', 'Keranjang belanja kosong');
            return;
        }

        $itemsByStore = collect($this->cartItems)->groupBy('store_id');

        DB::transaction(function () use ($itemsByStore) {
            $masterOrder = null;

            foreach ($itemsByStore as $storeId => $items) {
                $storeSubtotal = $items->sum('subtotal');
                $storeWeight = $items->sum(fn($i) => $i['weight'] * $i['quantity']);
                $storeShipping = $storeWeight * match ($this->courier) {
                    'jne' => 8000, 'tiki' => 10000, 'pos' => 12000,
                };

                $order = Order::create([
                    'user_id' => auth()->id(),
                    'order_number' => 'ORD-' . strtoupper(Str::random(8)) . '-' . time(),
                    'store_id' => $storeId,
                    'subtotal' => $storeSubtotal,
                    'shipping_cost' => $storeShipping,
                    'discount' => 0,
                    'total' => $storeSubtotal + $storeShipping,
                    'status' => 'pending',
                    'payment_status' => 'unpaid',
                    'shipping_address' => $this->shippingAddress,
                    'courier' => $this->courier,
                ]);

                foreach ($items as $item) {
                    OrderItem::create([
                        'order_id' => $order->id,
                        'store_id' => $storeId,
                        'product_id' => $item['product_id'],
                        'quantity' => $item['quantity'],
                        'price' => $item['price'],
                        'subtotal' => $item['subtotal'],
                    ]);

                    Product::where('id', $item['product_id'])->decrement('stock', $item['quantity']);
                }

                $masterOrder = $order;
            }

            $key = auth()->check() ? 'cart_' . auth()->id() : 'cart_guest';
            session()->forget($key);

            $this->dispatch('orderCreated', orderNumber: $masterOrder->order_number);
        });
    }

    public function render()
    {
        $itemsByStore = collect($this->cartItems)->groupBy('store_id');

        return view('livewire.checkout', compact('itemsByStore'))
            ->layout('layouts.app');
    }
}
```

- Tambah produk dari toko A dan toko B ke cart
- Buka halaman checkout
- Isi alamat pengiriman
- Pilih kurir
- Klik "Buat Pesanan"
- Verifikasi order terpisah per seller dibuat di database
- Cart menjadi kosong setelah checkout
- Stok produk berkurang
- Nomor order unik tergenerate
