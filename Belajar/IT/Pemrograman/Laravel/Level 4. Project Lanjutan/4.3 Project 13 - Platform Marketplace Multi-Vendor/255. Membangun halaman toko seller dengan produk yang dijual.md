# 255. Membangun Halaman Toko Seller dengan Produk yang Dijual

## Definisi & Target
Membangun halaman toko publik untuk setiap seller yang menampilkan informasi toko, daftar produk, dan statistik. Setiap seller memiliki URL unik berdasarkan slug toko.

## Komponen yang Terlibat
- Controller: `StoreController`
- Model: Store, Product
- View: public store page

## Perintah Artisan CLI
- `php artisan make:controller StoreController`

## Kode Implementasi (Per File)

**routes/web.php:**
```php
Route::get('/store/{slug}', [StoreController::class, 'show'])->name('store.show');
```

**app/Http/Controllers/StoreController.php:**
```php
class StoreController extends Controller
{
    public function show($slug)
    {
        $store = Store::where('slug', $slug)
            ->where('status', 'active')
            ->with('user')
            ->firstOrFail();

        $products = Product::where('store_id', $store->id)
            ->where('status', 'active')
            ->when(request('search'), fn($q, $s) => $q->where('name', 'like', "%{$s}%"))
            ->when(request('category'), fn($q, $c) => $q->where('category_id', $c))
            ->when(request('sort'), function ($q, $sort) {
                match ($sort) {
                    'price_asc' => $q->orderBy('price'),
                    'price_desc' => $q->orderBy('price', 'desc'),
                    'newest' => $q->orderBy('created_at', 'desc'),
                    default => $q->latest(),
                };
            })
            ->paginate(12);

        $stats = [
            'total_products' => Product::where('store_id', $store->id)->where('status', 'active')->count(),
            'total_sold' => 0,
            'rating' => $store->averageRating(),
            'join_date' => $store->created_at->format('d F Y'),
        ];

        return view('store.show', compact('store', 'products', 'stats'));
    }
}
```

**app/Models/Store.php (tambahan):**
```php
public function products(): HasMany
{
    return $this->hasMany(Product::class);
}

public function user(): BelongsTo
{
    return $this->belongsTo(User::class);
}

public function commissions(): HasMany
{
    return $this->hasMany(Commission::class);
}

public function withdrawals(): HasMany
{
    return $this->hasMany(Withdrawal::class);
}

public function averageRating(): float
{
    return round(Review::whereHas('product', fn($q) => $q->where('store_id', $this->id))->avg('rating') ?? 0, 1);
}

public function getBalanceAttribute()
{
    $earned = Commission::where('store_id', $this->id)
        ->where('status', 'available')
        ->sum('amount');

    $withdrawn = Withdrawal::where('store_id', $this->id)
        ->whereIn('status', ['processing', 'completed'])
        ->sum('amount');

    return $earned - $withdrawn;
}
```

## Cara Integrasi & Pengujian
- Seller membuat toko dan menambahkan produk
- Akses `/store/{slug}` untuk melihat halaman toko
- Verifikasi informasi toko muncul dengan benar
- Filter dan sort produk berfungsi
- Verifikasi URL slug unik per toko
- Cek statistik toko (jumlah produk, rating)
