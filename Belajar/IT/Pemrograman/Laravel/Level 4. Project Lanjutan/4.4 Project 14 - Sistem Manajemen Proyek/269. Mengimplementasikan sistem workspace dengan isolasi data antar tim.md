# 269. Mengimplementasikan Sistem Workspace dengan Isolasi Data Antar Tim

## Definisi & Target
Membangun sistem workspace di mana setiap tim memiliki ruang kerja terisolasi. Pengguna hanya dapat mengakses data di workspace tempat mereka menjadi anggota.

## Komponen yang Terlibat
- Middleware: `EnsureWorkspaceAccess`
- Controller: `WorkspaceController`
- Model: Workspace, WorkspaceMember

## Perintah Artisan CLI
- `php artisan make:middleware EnsureWorkspaceAccess`
- `php artisan make:controller WorkspaceController --resource`

## Kode Implementasi (Per File)

**app/Http/Middleware/EnsureWorkspaceAccess.php:**
```php
class EnsureWorkspaceAccess
{
    public function handle(Request $request, Closure $next): Response
    {
        $workspaceId = $request->route('workspace')
            ?? $request->route('workspaceId')
            ?? session('current_workspace_id');

        if (!$workspaceId) {
            return redirect()->route('workspaces.index');
        }

        $isMember = WorkspaceMember::where('workspace_id', $workspaceId)
            ->where('user_id', auth()->id())
            ->exists();

        if (!$isMember) {
            abort(403, 'Anda tidak memiliki akses ke workspace ini');
        }

        session(['current_workspace_id' => $workspaceId]);
        view()->share('currentWorkspace', Workspace::find($workspaceId));

        return $next($request);
    }
}
```

**app/Providers/AppServiceProvider.php (global scope):**
```php
public function boot(): void
{
    Task::addGlobalScope('workspace', function (Builder $builder) {
        if (session('current_workspace_id')) {
            $builder->where('workspace_id', session('current_workspace_id'));
        }
    });

    Project::addGlobalScope('workspace', function (Builder $builder) {
        if (session('current_workspace_id')) {
            $builder->where('workspace_id', session('current_workspace_id'));
        }
    });
}
```

**app/Http/Controllers/WorkspaceController.php:**
```php
class WorkspaceController extends Controller
{
    public function index()
    {
        $workspaces = auth()->user()->workspaces()->with('owner')->get();
        return view('workspaces.index', compact('workspaces'));
    }

    public function store(Request $request)
    {
        $validated = $request->validate([
            'name' => 'required|string|max:255',
            'description' => 'nullable|string',
        ]);

        DB::transaction(function () use ($validated) {
            $workspace = Workspace::create([
                'name' => $validated['name'],
                'slug' => Str::slug($validated['name']) . '-' . Str::random(4),
                'description' => $validated['description'],
                'owner_id' => auth()->id(),
            ]);

            WorkspaceMember::create([
                'workspace_id' => $workspace->id,
                'user_id' => auth()->id(),
                'role' => 'owner',
            ]);
        });

        return redirect()->route('workspaces.index')->with('success', 'Workspace created');
    }

    public function switch($workspaceId)
    {
        $isMember = WorkspaceMember::where('workspace_id', $workspaceId)
            ->where('user_id', auth()->id())->exists();

        if (!$isMember) abort(403);

        session(['current_workspace_id' => $workspaceId]);

        return redirect()->route('projects.index');
    }

    public function invite(Request $request, Workspace $workspace)
    {
        $validated = $request->validate(['email' => 'required|email|exists:users,email']);

        $user = User::where('email', $validated['email'])->first();

        WorkspaceMember::firstOrCreate([
            'workspace_id' => $workspace->id,
            'user_id' => $user->id,
        ], ['role' => 'member']);

        return back()->with('success', 'Anggota berhasil ditambahkan');
    }
}
```

**routes/web.php:**
```php
Route::middleware('auth')->group(function () {
    Route::resource('workspaces', WorkspaceController::class);
    Route::post('/workspaces/{workspace}/switch', [WorkspaceController::class, 'switch'])->name('workspaces.switch');
    Route::post('/workspaces/{workspace}/invite', [WorkspaceController::class, 'invite'])->name('workspaces.invite');

    Route::middleware(EnsureWorkspaceAccess::class)->group(function () {
        Route::resource('projects', ProjectController::class);
        Route::resource('tasks', TaskController::class);
    });
});
```

## Cara Integrasi & Pengujian
- Buat workspace baru -> otomatis jadi member dengan role owner
- Buat workspace kedua
- Switch antar workspace, data yang tampil hanya milik workspace aktif
- Coba akses langsung URL task dari workspace lain -> 403
- Invite anggota via email
- Verifikasi global scope: Task::all() hanya menampilkan task workspace aktif
- Cek session current_workspace_id berubah saat switch
