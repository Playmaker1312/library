# 271. Mengimplementasikan Kanban Board Menggunakan Livewire dengan Drag and Drop

## Definisi & Target
Membangun Kanban board untuk menampilkan task dalam kolom status (To Do, In Progress, Review, Done) yang mendukung drag and drop untuk mengubah status task secara real-time.

## Komponen yang Terlibat
- Livewire Component: `KanbanBoard`
- Library: SortableJS untuk drag and drop
- Alpine.js

## Perintah Artisan CLI
- `php artisan make:livewire KanbanBoard`

## Kode Implementasi (Per File)

**app/Livewire/KanbanBoard.php:**
```php
class KanbanBoard extends Component
{
    public $project;
    public $todoTasks = [];
    public $inProgressTasks = [];
    public $reviewTasks = [];
    public $doneTasks = [];
    public $statusLabels = [];

    public function mount($projectId)
    {
        $this->project = Project::with('workspace')->findOrFail($projectId);
        $this->statusLabels = [
            'todo' => 'To Do',
            'in_progress' => 'In Progress',
            'review' => 'Review',
            'done' => 'Done',
        ];
        $this->loadTasks();
    }

    public function loadTasks()
    {
        $tasks = Task::where('project_id', $this->project->id)
            ->with('assignee', 'labels')
            ->orderBy('priority', 'desc')
            ->get();

        $this->todoTasks = $tasks->where('status', 'todo')->values()->toArray();
        $this->inProgressTasks = $tasks->where('status', 'in_progress')->values()->toArray();
        $this->reviewTasks = $tasks->where('status', 'review')->values()->toArray();
        $this->doneTasks = $tasks->where('status', 'done')->values()->toArray();
    }

    public function updateTaskStatus($taskId, $newStatus)
    {
        $task = Task::findOrFail($taskId);

        if ($task->project->workspace_id !== session('current_workspace_id')) {
            abort(403);
        }

        $task->update(['status' => $newStatus]);
        $this->loadTasks();
        $this->dispatch('taskUpdated', taskId: $taskId, status: $newStatus);
    }

    public function render()
    {
        return view('livewire.kanban-board');
    }
}
```

**resources/views/livewire/kanban-board.blade.php:**
```html
<div class="p-6">
    <h1 class="text-2xl font-bold mb-4">{{ $project->name }} - Kanban Board</h1>

    <div class="flex space-x-4 overflow-x-auto pb-4" x-data="kanbanBoard()" x-init="init()">
        @foreach(['todo' => $todoTasks, 'in_progress' => $inProgressTasks, 'review' => $reviewTasks, 'done' => $doneTasks] as $status => $tasks)
        <div class="flex-shrink-0 w-72 bg-gray-100 rounded-lg p-3">
            <div class="flex justify-between items-center mb-3">
                <h3 class="font-semibold text-sm">{{ $statusLabels[$status] }}</h3>
                <span class="bg-gray-200 text-xs px-2 py-1 rounded">{{ count($tasks) }}</span>
            </div>

            <div class="space-y-2 min-h-32"
                 x-on:dragover.prevent="handleDragOver($event)"
                 x-on:drop="handleDrop($event, '{{ $status }}')"
                 wire:key="column-{{ $status }}">

                @foreach($tasks as $task)
                <div class="bg-white p-3 rounded shadow cursor-grab active:cursor-grabbing"
                     draggable="true"
                     x-on:dragstart="handleDragStart($event, {{ $task['id'] }})"
                     x-on:dragend="handleDragEnd($event)"
                     wire:key="task-{{ $task['id'] }}">
                    <div class="flex justify-between items-start">
                        <p class="text-sm font-semibold">{{ $task['title'] }}</p>
                        <span class="text-xs px-1.5 py-0.5 rounded
                            {{ $task['priority'] === 'urgent' ? 'bg-red-100 text-red-800' : '' }}
                            {{ $task['priority'] === 'high' ? 'bg-orange-100 text-orange-800' : '' }}
                            {{ $task['priority'] === 'medium' ? 'bg-blue-100 text-blue-800' : '' }}
                            {{ $task['priority'] === 'low' ? 'bg-gray-100 text-gray-800' : '' }}">
                            {{ $task['priority'] }}
                        </span>
                    </div>
                    @if($task['labels'])
                    <div class="flex flex-wrap gap-1 mt-2">
                        @foreach($task['labels'] as $label)
                        <span class="text-xs px-1.5 py-0.5 rounded" style="background: {{ $label['color'] }}20; color: {{ $label['color'] }}">
                            {{ $label['name'] }}
                        </span>
                        @endforeach
                    </div>
                    @endif
                    @if($task['assignee'])
                    <div class="flex items-center mt-2 text-xs text-gray-500">
                        <div class="w-5 h-5 bg-blue-500 rounded-full flex items-center justify-center text-white text-xs mr-1">
                            {{ strtoupper(substr($task['assignee']['name'], 0, 1)) }}
                        </div>
                        {{ $task['assignee']['name'] }}
                    </div>
                    @endif
                    @if($task['due_date'])
                    <p class="text-xs mt-1 {{ \Carbon\Carbon::parse($task['due_date'])->isPast() ? 'text-red-500' : 'text-gray-400' }}">
                        {{ \Carbon\Carbon::parse($task['due_date'])->format('d/m') }}
                    </p>
                    @endif
                </div>
                @endforeach
            </div>
        </div>
        @endforeach
    </div>

    <script>
        function kanbanBoard() {
            return {
                draggedTaskId: null,
                init() {
                    Livewire.on('taskUpdated', data => {
                        // visual feedback handled by Livewire re-render
                    });
                },
                handleDragStart(event, taskId) {
                    this.draggedTaskId = taskId;
                    event.target.classList.add('opacity-50');
                },
                handleDragEnd(event) {
                    this.draggedTaskId = null;
                    event.target.classList.remove('opacity-50');
                },
                handleDragOver(event) {
                    event.preventDefault();
                },
                handleDrop(event, status) {
                    event.preventDefault();
                    if (this.draggedTaskId) {
                        Livewire.dispatch('updateTaskStatus', { taskId: this.draggedTaskId, newStatus: status });
                        this.draggedTaskId = null;
                    }
                },
            }
        }
    </script>
</div>
```

## Cara Integrasi & Pengujian
- Buka proyek dengan beberapa task
- Task tampil dalam 4 kolom: To Do, In Progress, Review, Done
- Drag task dari "To Do" ke "In Progress"
- Verifikasi status task berubah di database
- Task muncul di kolom baru setelah drop
- Uji drag and drop di semua kolom
- Urutan prioritas tetap terjaga
- Tampilan assignee, label, deadline di setiap card
