# 274. Mengimplementasikan Sistem Komentar pada Task dengan Mention User

## Definisi & Target
Membangun sistem komentar pada task di mana anggota tim dapat berdiskusi. Fitur mention user menggunakan @username yang mengirim notifikasi ke user yang disebut.

## Komponen yang Terlibat
- Livewire Component: `TaskComments`
- Model: TaskComment
- Notification: `UserMentioned`

## Perintah Artisan CLI
- `php artisan make:livewire TaskComments`
- `php artisan make:notification UserMentioned`

## Kode Implementasi (Per File)

**app/Livewire/TaskComments.php:**
```php
class TaskComments extends Component
{
    public $task;
    public $newComment = '';
    public $mentions = [];

    public function mount($taskId)
    {
        $this->task = Task::with('comments.user')->findOrFail($taskId);
    }

    public function addComment()
    {
        $this->validate(['newComment' => 'required|string|min:1|max:2000']);

        $comment = TaskComment::create([
            'task_id' => $this->task->id,
            'user_id' => auth()->id(),
            'content' => $this->newComment,
        ]);

        $this->processMentions($this->newComment, $comment);

        $this->newComment = '';
        $this->task->load('comments.user');
        $this->dispatch('commentAdded');
    }

    public function deleteComment($commentId)
    {
        $comment = TaskComment::findOrFail($commentId);
        if ($comment->user_id === auth()->id()) {
            $comment->delete();
            $this->task->load('comments.user');
        }
    }

    protected function processMentions(string $content, TaskComment $comment): void
    {
        preg_match_all('/@(\w+)/', $content, $matches);

        foreach ($matches[1] as $username) {
            $user = User::where('name', 'like', "%{$username}%")->first();

            if ($user && $user->id !== auth()->id()) {
                $user->notify(new UserMentioned($comment));
            }
        }
    }

    public function render()
    {
        return view('livewire.task-comments', [
            'comments' => $this->task->comments()->with('user')->latest()->get(),
        ]);
    }
}
```

**app/Notifications/UserMentioned.php:**
```php
class UserMentioned extends Notification
{
    use Queueable;

    public function __construct(public TaskComment $comment) {}

    public function via($notifiable): array
    {
        return ['database'];
    }

    public function toArray($notifiable): array
    {
        return [
            'task_id' => $this->comment->task_id,
            'comment_id' => $this->comment->id,
            'mentioned_by' => $this->comment->user->name,
            'message' => $this->comment->user->name . ' menyebut Anda di task #' . $this->comment->task_id,
        ];
    }
}
```

## Cara Integrasi & Pengujian
- Buka detail task
- Tulis komentar biasa -> muncul di daftar komentar
- Tulis komentar dengan @username -> user yang disebut mendapat notifikasi
- Verifikasi mention berubah warna biru
- Hapus komentar yang dibuat sendiri
- User lain tidak bisa hapus komentar orang lain
- Komentar muncul real-time setelah dikirim
- Cek tabel notifications untuk UserMentioned
