# 267. Membuat Schema Database untuk Workspace, Projects, Tasks, Task Comments, Members, dan Time Logs

## Definisi & Target
Merancang ERD dan schema database untuk sistem manajemen proyek dengan tabel workspace, projects, tasks, task_comments, members, time_logs, dan tabel pendukung.

## Komponen yang Terlibat
- Tabel `workspaces`: id, name, slug, description, owner_id, created_at
- Tabel `projects`: id, workspace_id, name, description, status, start_date, deadline, created_at
- Tabel `tasks`: id, project_id, parent_id, workspace_id, title, description, status, priority, assignee_id, start_date, due_date, created_at
- Tabel `task_comments`: id, task_id, user_id, content, created_at
- Tabel `task_attachments`: id, task_id, file_path, file_name, file_size, created_at
- Tabel `workspace_members`: id, workspace_id, user_id, role, created_at
- Tabel `time_logs`: id, task_id, user_id, start_time, end_time, duration, description, created_at
- Tabel `labels`: id, workspace_id, name, color, created_at
- Tabel `task_label`: task_id, label_id

## Perintah Artisan CLI
- `php artisan make:model Workspace -m`
- `php artisan make:model Project -m`
- `php artisan make:model Task -m`
- `php artisan make:model TaskComment -m`
- `php artisan make:model TimeLog -m`
