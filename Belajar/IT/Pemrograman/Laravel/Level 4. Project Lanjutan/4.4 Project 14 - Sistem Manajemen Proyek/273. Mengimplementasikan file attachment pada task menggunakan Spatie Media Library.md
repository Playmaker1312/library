# 273. Mengimplementasikan File Attachment pada Task Menggunakan Spatie Media Library

## Definisi & Target
Membangun fitur upload file attachment pada task menggunakan Spatie Media Library. Task dapat memiliki banyak file (gambar, dokumen, dll) yang terkelola dengan baik.

## Komponen yang Terlibat
- Library: spatie/laravel-medialibrary
- Model: Task (menggunakan HasMedia trait)
- Livewire Component: `TaskAttachments`

## Perintah Artisan CLI
- `composer require spatie/laravel-medialibrary`
- `php artisan vendor:publish --provider="Spatie\MediaLibrary\MediaLibraryServiceProvider" --tag="migrations"`
- `php artisan migrate`
- `php artisan make:livewire TaskAttachments`

## Kode Implementasi (Per File)

**app/Models/Task.php (media):**
```php
use Spatie\MediaLibrary\HasMedia;
use Spatie\MediaLibrary\InteractsWithMedia;

class Task extends Model implements HasMedia
{
    use HasFactory, InteractsWithMedia;

    public function registerMediaCollections(): void
    {
        $this->addMediaCollection('task_attachments');
    }

    public function registerMediaConversions(?Media $media = null): void
    {
        $this->addMediaConversion('thumb')
            ->width(200)
            ->height(200)
            ->nonQueued();
    }
}
```

**app/Livewire/TaskAttachments.php:**
```php
class TaskAttachments extends Component
{
    public $task;
    public $files = [];

    protected $rules = [
        'files.*' => 'required|file|max:10240', // max 10MB
    ];

    public function mount($taskId)
    {
        $this->task = Task::with('media')->findOrFail($taskId);
    }

    public function upload()
    {
        $this->validate();

        foreach ($this->files as $file) {
            $this->task->addMedia($file)
                ->toMediaCollection('task_attachments');
        }

        $this->files = [];
        $this->task->load('media');
        $this->dispatch('attachmentsUpdated');
    }

    public function deleteAttachment($mediaId)
    {
        $media = Media::findOrFail($mediaId);
        $media->delete();

        $this->task->load('media');
    }

    public function render()
    {
        return view('livewire.task-attachments');
    }
}
```

**resources/views/livewire/task-attachments.blade.php:**
```html
<div class="bg-white p-4 rounded-lg shadow">
    <h3 class="font-semibold mb-3">File Attachment</h3>

    <div class="mb-3">
        <input type="file" wire:model="files" multiple class="w-full text-sm border p-2 rounded">
        <div wire:loading wire:target="files" class="text-blue-600 text-sm mt-1">Uploading...</div>
        @error('files.*') <span class="text-red-500 text-sm">{{ $message }}</span> @enderror
        <button wire:click="upload" wire:loading.attr="disabled" class="mt-2 bg-blue-600 text-white px-3 py-1 rounded text-sm">
            Upload
        </button>
    </div>

    @if($task->getMedia('task_attachments')->count() > 0)
    <div class="grid grid-cols-3 gap-2">
        @foreach($task->getMedia('task_attachments') as $media)
        <div class="relative group border rounded p-2">
            @if(str_starts_with($media->mime_type, 'image/'))
            <a href="{{ $media->getUrl() }}" target="_blank">
                <img src="{{ $media->getUrl('thumb') }}" class="w-full h-20 object-cover rounded">
            </a>
            @else
            <div class="w-full h-20 bg-gray-100 rounded flex items-center justify-center text-2xl">
                {{ match ($media->mime_type) {
                    'application/pdf' => 'PDF',
                    'application/msword', 'application/vnd.openxmlformats-officedocument.wordprocessingml.document' => 'DOC',
                    'application/vnd.ms-excel', 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet' => 'XLS',
                    default => 'FILE',
                } }}
            </div>
            @endif
            <p class="text-xs truncate mt-1">{{ $media->name }}.{{ $media->extension }}</p>
            <p class="text-xs text-gray-400">{{ number_format($media->size / 1024, 1) }} KB</p>
            <button wire:click="deleteAttachment({{ $media->id }})"
                    class="absolute top-1 right-1 bg-red-500 text-white text-xs w-5 h-5 rounded-full opacity-0 group-hover:opacity-100 transition">
                x
            </button>
        </div>
        @endforeach
    </div>
    @else
    <p class="text-sm text-gray-400">Belum ada file</p>
    @endif
</div>
```

## Cara Integrasi & Pengujian
- Buka detail task
- Upload beberapa file (gambar dan dokumen)
- Verifikasi file tersimpan di collection 'task_attachments'
- Gambar menampilkan thumbnail
- File non-gambar menampilkan ikon tipe file
- Klik file -> buka di tab baru
- Hapus file dengan tombol x
- Verifikasi file terhapus dari storage dan database
- Cek batasan ukuran file 10MB
