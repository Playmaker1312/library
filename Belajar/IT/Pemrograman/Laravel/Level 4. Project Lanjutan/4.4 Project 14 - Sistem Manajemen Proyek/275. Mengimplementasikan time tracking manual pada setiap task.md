# 275. Mengimplementasikan Time Tracking Manual pada Setiap Task

## Definisi & Target
Membangun fitur time tracking pada task di mana user dapat mencatat waktu mulai dan selesai (timer) atau memasukkan durasi manual. Total waktu terekam per task dan per user.

## Komponen yang Terlibat
- Livewire Component: `TimeTracker`
- Model: TimeLog

## Perintah Artisan CLI
- `php artisan make:livewire TimeTracker`

## Kode Implementasi (Per File)

**app/Livewire/TimeTracker.php:**
```php
class TimeTracker extends Component
{
    public $task;
    public $activeLog = null;
    public $description = '';
    public $manualHours = 0;
    public $manualMinutes = 0;
    public $showManualForm = false;

    public function mount($taskId)
    {
        $this->task = Task::findOrFail($taskId);
        $this->activeLog = TimeLog::where('task_id', $taskId)
            ->where('user_id', auth()->id())
            ->whereNull('end_time')
            ->first();
    }

    public function startTimer()
    {
        if ($this->activeLog) {
            return;
        }

        $this->activeLog = TimeLog::create([
            'task_id' => $this->task->id,
            'user_id' => auth()->id(),
            'start_time' => now(),
            'description' => $this->description,
        ]);

        $this->dispatch('timerStarted');
    }

    public function stopTimer()
    {
        if (!$this->activeLog) {
            return;
        }

        $endTime = now();
        $startTime = $this->activeLog->start_time;
        $durationMinutes = $startTime->diffInMinutes($endTime);

        $this->activeLog->update([
            'end_time' => $endTime,
            'duration' => $durationMinutes,
        ]);

        $this->activeLog = null;
        $this->description = '';
        $this->dispatch('timerStopped', duration: $durationMinutes);
    }

    public function addManual()
    {
        $this->validate([
            'manualHours' => 'required|integer|min:0|max:24',
            'manualMinutes' => 'required|integer|min:0|max:59',
            'description' => 'required|string|max:500',
        ]);

        $totalMinutes = ($this->manualHours * 60) + $this->manualMinutes;

        if ($totalMinutes <= 0) {
            $this->addError('manualHours', 'Durasi harus lebih dari 0');
            return;
        }

        TimeLog::create([
            'task_id' => $this->task->id,
            'user_id' => auth()->id(),
            'start_time' => now()->subMinutes($totalMinutes),
            'end_time' => now(),
            'duration' => $totalMinutes,
            'description' => $this->description,
        ]);

        $this->reset(['manualHours', 'manualMinutes', 'description', 'showManualForm']);
        $this->dispatch('timeLogAdded');
    }

    public function render()
    {
        $timeLogs = TimeLog::where('task_id', $this->task->id)
            ->with('user')
            ->latest()
            ->take(20)
            ->get();

        $totalTime = TimeLog::where('task_id', $this->task->id)->sum('duration');

        return view('livewire.time-tracker', compact('timeLogs', 'totalTime'));
    }
}
```

**resources/views/livewire/time-tracker.blade.php:**
```html
<div class="bg-white p-4 rounded-lg shadow">
    <h3 class="font-semibold mb-3">Time Tracking</h3>

    <div class="mb-4 p-3 bg-gray-50 rounded">
        <div class="flex justify-between items-center">
            <div>
                <p class="text-sm text-gray-500">Total Waktu Tercatat</p>
                <p class="text-xl font-bold">{{ intdiv($totalTime, 60) }}j {{ $totalTime % 60 }}m</p>
            </div>
            @if($activeLog)
            <div class="text-center">
                <p class="text-sm text-green-600 font-semibold">Sedang berjalan...</p>
                <p class="text-2xl font-bold text-green-600" x-data x-init="
                    startTime = new Date('{{ $activeLog->start_time }}');
                    setInterval(() => {
                        let diff = Math.floor((new Date() - startTime) / 1000);
                        let h = Math.floor(diff / 3600);
                        let m = Math.floor((diff % 3600) / 60);
                        let s = diff % 60;
                        $el.textContent = String(h).padStart(2,'0') + ':' + String(m).padStart(2,'0') + ':' + String(s).padStart(2,'0');
                    }, 1000);
                ">00:00:00</p>
            </div>
            @endif
        </div>
    </div>

    <div class="flex space-x-2 mb-4">
        @if($activeLog)
        <button wire:click="stopTimer" class="bg-red-600 text-white px-4 py-2 rounded text-sm">Stop Timer</button>
        @else
        <button wire:click="startTimer" class="bg-green-600 text-white px-4 py-2 rounded text-sm">Start Timer</button>
        <button wire:click="$set('showManualForm', true)" class="bg-gray-600 text-white px-4 py-2 rounded text-sm">Manual</button>
        @endif
    </div>

    @if($showManualForm)
    <div class="border p-3 rounded mb-4">
        <div class="flex space-x-2 mb-2">
            <div>
                <label class="text-xs">Jam</label>
                <input type="number" wire:model="manualHours" class="w-16 border rounded p-1 text-sm" min="0">
            </div>
            <div>
                <label class="text-xs">Menit</label>
                <input type="number" wire:model="manualMinutes" class="w-16 border rounded p-1 text-sm" min="0" max="59">
            </div>
        </div>
        <input type="text" wire:model="description" placeholder="Deskripsi pekerjaan..." class="w-full border rounded p-1.5 text-sm mb-2">
        <div class="flex space-x-2">
            <button wire:click="addManual" class="bg-blue-600 text-white px-3 py-1 rounded text-sm">Simpan</button>
            <button wire:click="$set('showManualForm', false)" class="text-sm text-gray-500">Batal</button>
        </div>
    </div>
    @endif

    <div class="space-y-2 max-h-48 overflow-y-auto">
        @forelse($timeLogs as $log)
        <div class="flex justify-between text-sm border-b pb-1">
            <div>
                <p class="text-xs text-gray-500">{{ $log->user->name }} - {{ $log->created_at->format('d/m H:i') }}</p>
                <p>{{ $log->description ?: 'Tanpa deskripsi' }}</p>
            </div>
            <p class="font-semibold">{{ intdiv($log->duration, 60) }}j {{ $log->duration % 60 }}m</p>
        </div>
        @empty
        <p class="text-sm text-gray-400">Belum ada time log</p>
        @endforelse
    </div>
</div>
```

## Cara Integrasi & Pengujian
- Buka task dengan time tracker
- Klik "Start Timer" -> timer berjalan
- Klik "Stop Timer" -> waktu tersimpan
- Tambah time log manual (jam + menit + deskripsi)
- Verifikasi total waktu terakumulasi
- Cek data di tabel time_logs
- Timer tersimpan dengan start_time dan end_time
- Time log per user tercatat dengan benar
