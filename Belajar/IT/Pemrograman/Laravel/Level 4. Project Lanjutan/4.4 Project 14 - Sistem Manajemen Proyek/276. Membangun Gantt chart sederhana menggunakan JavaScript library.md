# 276. Membangun Gantt Chart Sederhana Menggunakan JavaScript Library

## Definisi & Target
Membangun Gantt chart untuk menampilkan timeline task dalam proyek. Menggunakan library JavaScript seperti Frappe Gantt atau dhtmlxGantt.

## Komponen yang Terlibat
- View: gantt chart page
- Library: frappe-gantt (CDN)
- Controller: `GanttController`

## Perintah Artisan CLI
- `php artisan make:controller GanttController`

## Kode Implementasi (Per File)

**routes/web.php:**
```php
Route::get('/projects/{project}/gantt', [GanttController::class, 'index'])->name('projects.gantt');
Route::get('/projects/{project}/gantt-data', [GanttController::class, 'data'])->name('projects.gantt-data');
```

**app/Http/Controllers/GanttController.php:**
```php
class GanttController extends Controller
{
    public function index(Project $project)
    {
        return view('projects.gantt', compact('project'));
    }

    public function data(Project $project)
    {
        $tasks = Task::where('project_id', $project->id)
            ->with('assignee')
            ->get()
            ->map(function ($task) {
                $start = $task->start_date ?? $task->created_at;
                $end = $task->due_date ?? $task->created_at->addDays(3);

                return [
                    'id' => (string) $task->id,
                    'name' => $task->title,
                    'start' => $start instanceof \Carbon\Carbon ? $start->format('Y-m-d') : $start,
                    'end' => $end instanceof \Carbon\Carbon ? $end->format('Y-m-d') : $end,
                    'progress' => $task->status === 'done' ? 100 : ($task->status === 'in_progress' ? 50 : 0),
                    'dependencies' => $task->parent_id ? [(string) $task->parent_id] : '',
                    'custom_class' => 'gantt-' . $task->priority,
                ];
            });

        return response()->json($tasks);
    }
}
```

**resources/views/projects/gantt.blade.php:**
```html
<x-app-layout>
    <div class="p-6">
        <div class="flex justify-between items-center mb-4">
            <h1 class="text-2xl font-bold">Gantt Chart - {{ $project->name }}</h1>
            <a href="{{ route('projects.show', $project) }}" class="text-blue-600 text-sm">Kembali ke Proyek</a>
        </div>

        <div class="bg-white rounded-lg shadow p-4">
            <svg id="gantt" width="100%" height="500"></svg>
        </div>
    </div>

    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frappe-gantt@0.6.1/dist/frappe-gantt.min.css">
    <script src="https://cdn.jsdelivr.net/npm/frappe-gantt@0.6.1/dist/frappe-gantt.min.js"></script>
    <script>
        fetch('{{ route('projects.gantt-data', $project) }}')
            .then(res => res.json())
            .then(tasks => {
                new Gantt('#gantt', tasks, {
                    view_mode: 'Month',
                    date_format: 'YYYY-MM-DD',
                    bar_height: 30,
                    bar_corner_radius: 3,
                    on_click: function(task) {
                        window.location.href = '/tasks/' + task.id;
                    },
                    on_date_change: function(task, start, end) {
                        fetch('/tasks/' + task.id, {
                            method: 'PUT',
                            headers: {
                                'Content-Type': 'application/json',
                                'X-CSRF-TOKEN': '{{ csrf_token() }}',
                            },
                            body: JSON.stringify({
                                start_date: start,
                                due_date: end,
                            })
                        });
                    },
                    on_progress_change: function(task, progress) {
                        let status = progress === 100 ? 'done' : (progress > 0 ? 'in_progress' : 'todo');
                        fetch('/tasks/' + task.id, {
                            method: 'PUT',
                            headers: {
                                'Content-Type': 'application/json',
                                'X-CSRF-TOKEN': '{{ csrf_token() }}',
                            },
                            body: JSON.stringify({ status: status })
                        });
                    }
                });
            });
    </script>

    <style>
        .gantt-urgent .bar { fill: #dc2626 !important; }
        .gantt-high .bar { fill: #ea580c !important; }
        .gantt-medium .bar { fill: #2563eb !important; }
        .gantt-low .bar { fill: #6b7280 !important; }
    </style>
</x-app-layout>
```

## Cara Integrasi & Pengujian
- Buat beberapa task dengan start_date dan due_date
- Akses route `/projects/{id}/gantt`
- Verifikasi task tampil dalam bentuk bar di timeline
- Task parent menampilkan subtask sebagai dependensi
- Klik task -> redirect ke detail task
- Drag bar untuk mengubah tanggal (opsional)
- Warna bar sesuai prioritas (urgent=merah, high=oranye, dll)
- Progress bar menunjukkan status task
