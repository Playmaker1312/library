# 278. Membangun Dashboard Proyek dengan Progress dan Statistik Task

## Definisi & Target
Membangun dashboard untuk setiap proyek yang menampilkan progress keseluruhan, statistik task (per status, per prioritas, per assignee), dan grafik perkembangan.

## Komponen yang Terlibat
- Livewire Component: `ProjectDashboard`
- Model: Project, Task

## Perintah Artisan CLI
- `php artisan make:livewire ProjectDashboard`

## Kode Implementasi (Per File)

**app/Livewire/ProjectDashboard.php:**
```php
class ProjectDashboard extends Component
{
    public $project;
    public $stats = [];
    public $statusDistribution = [];
    public $priorityDistribution = [];
    public $assigneeStats = [];
    public $recentTasks = [];

    public function mount($projectId)
    {
        $this->project = Project::with('workspace')->findOrFail($projectId);
        $this->loadStats();
    }

    public function loadStats()
    {
        $tasks = Task::where('project_id', $this->project->id);

        $this->stats = [
            'total' => $tasks->count(),
            'todo' => (clone $tasks)->where('status', 'todo')->count(),
            'in_progress' => (clone $tasks)->where('status', 'in_progress')->count(),
            'review' => (clone $tasks)->where('status', 'review')->count(),
            'done' => (clone $tasks)->where('status', 'done')->count(),
            'overdue' => (clone $tasks)->whereNot('status', 'done')->where('due_date', '<', now())->count(),
            'progress' => $this->project->progress,
            'total_time' => TimeLog::whereIn('task_id', $tasks->pluck('id'))->sum('duration'),
        ];

        $this->statusDistribution = collect(['todo', 'in_progress', 'review', 'done'])->map(fn($s) => [
            'status' => $s, 'count' => (clone $tasks)->where('status', $s)->count(),
        ])->toArray();

        $this->priorityDistribution = collect(['urgent', 'high', 'medium', 'low'])->map(fn($p) => [
            'priority' => $p, 'count' => (clone $tasks)->where('priority', $p)->count(),
        ])->toArray();

        $this->assigneeStats = User::whereIn('id', (clone $tasks)->pluck('assignee_id')->unique())
            ->withCount(['tasks' => fn($q) => $q->where('project_id', $this->project->id)])
            ->get()
            ->toArray();

        $this->recentTasks = (clone $tasks)->with('assignee')
            ->latest()
            ->take(5)
            ->get()
            ->toArray();
    }

    public function render()
    {
        return view('livewire.project-dashboard');
    }
}
```

## Cara Integrasi & Pengujian
- Buka dashboard proyek
- Verifikasi progress bar dan kartu statistik
- Task per status dan prioritas dalam grafik
- Distribusi task per anggota tim
- Daftar task terbaru
- Data polling setiap 30 detik
- Bandingkan angka dengan data task di database
- Cek task overdue (due_date < now dan belum done)
