# 280. Mengimplementasikan Kalender Proyek yang Menampilkan Deadline Task

## Definisi & Target
Membangun tampilan kalender proyek yang menampilkan deadline task dalam format kalender bulanan. Task dapat dilihat per tanggal deadline-nya dengan warna berbeda sesuai status.

## Komponen yang Terlibat
- View: project calendar
- Library: FullCalendar (CDN)
- Controller: `CalendarController`

## Perintah Artisan CLI
- `php artisan make:controller CalendarController`

## Kode Implementasi (Per File)

**routes/web.php:**
```php
Route::get('/projects/{project}/calendar', [CalendarController::class, 'index'])->name('projects.calendar');
Route::get('/projects/{project}/calendar-events', [CalendarController::class, 'events'])->name('projects.calendar-events');
```

**app/Http/Controllers/CalendarController.php:**
```php
class CalendarController extends Controller
{
    public function index(Project $project)
    {
        return view('projects.calendar', compact('project'));
    }

    public function events(Project $project, Request $request)
    {
        $start = $request->get('start', now()->startOfMonth());
        $end = $request->get('end', now()->endOfMonth());

        $tasks = Task::where('project_id', $project->id)
            ->whereNotNull('due_date')
            ->whereBetween('due_date', [$start, $end])
            ->with('assignee')
            ->get();

        $events = $tasks->map(function ($task) {
            $color = match ($task->status) {
                'done' => '#22c55e',
                'in_progress' => '#3b82f6',
                'review' => '#8b5cf6',
                default => '#eab308',
            };

            if ($task->due_date < now() && $task->status !== 'done') {
                $color = '#ef4444';
            }

            return [
                'id' => (string) $task->id,
                'title' => $task->title,
                'start' => $task->due_date->format('Y-m-d'),
                'end' => $task->due_date->addDay()->format('Y-m-d'),
                'backgroundColor' => $color,
                'borderColor' => $color,
                'textColor' => '#ffffff',
                'extendedProps' => [
                    'status' => $task->status,
                    'assignee' => $task->assignee->name ?? 'Unassigned',
                    'priority' => $task->priority,
                ],
                'url' => route('tasks.show', $task),
            ];
        });

        return response()->json($events);
    }
}
```

## Cara Integrasi & Pengujian
- Buat task dengan due_date
- Akses route `/projects/{id}/calendar`
- Deadline task tampil sebagai event di kalender
- Warna event: hijau (done), biru (in_progress), ungu (review), kuning (todo), merah (overdue)
- Klik event -> modal dengan detail task
- Navigasi bulan sebelumnya dan berikutnya
- Beralih ke tampilan week dan list
- Task tanpa due_date tidak muncul
- Klik "Lihat Detail Task" -> redirect ke halaman task
