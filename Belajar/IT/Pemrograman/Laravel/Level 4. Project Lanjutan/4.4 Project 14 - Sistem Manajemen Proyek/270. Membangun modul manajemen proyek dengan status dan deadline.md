# 270. Membangun Modul Manajemen Proyek dengan Status dan Deadline

## Definisi & Target
Membangun modul CRUD proyek dengan fitur status (planning, active, on_hold, completed, cancelled), deadline, progress bar, dan daftar task.

## Komponen yang Terlibat
- Controller: `ProjectController`
- Model: Project, Task

## Perintah Artisan CLI
- `php artisan make:controller ProjectController --resource`

## Kode Implementasi (Per File)

**routes/web.php:**
```php
Route::resource('projects', ProjectController::class);
```

**app/Http/Controllers/ProjectController.php:**
```php
class ProjectController extends Controller
{
    public function index()
    {
        $projects = Project::withCount(['tasks', 'tasks as completed_tasks_count' => fn($q) => $q->where('status', 'done')])
            ->orderByDesc('created_at')
            ->paginate(10);

        return view('projects.index', compact('projects'));
    }

    public function create()
    {
        return view('projects.create');
    }

    public function store(ProjectRequest $request)
    {
        $project = Project::create([
            'workspace_id' => session('current_workspace_id'),
            'name' => $request->name,
            'description' => $request->description,
            'status' => $request->status ?? 'planning',
            'start_date' => $request->start_date,
            'deadline' => $request->deadline,
        ]);

        return redirect()->route('projects.show', $project)->with('success', 'Proyek berhasil dibuat');
    }

    public function show(Project $project)
    {
        $project->load(['tasks' => fn($q) => $q->with('assignee', 'labels')->orderBy('priority', 'desc')->orderBy('created_at')]);

        return view('projects.show', compact('project'));
    }

    public function edit(Project $project)
    {
        return view('projects.edit', compact('project'));
    }

    public function update(ProjectRequest $request, Project $project)
    {
        $project->update($request->validated());

        return redirect()->route('projects.index')->with('success', 'Proyek berhasil diupdate');
    }

    public function destroy(Project $project)
    {
        $project->tasks()->delete();
        $project->delete();

        return redirect()->route('projects.index')->with('success', 'Proyek berhasil dihapus');
    }
}
```

## Cara Integrasi & Pengujian
- Buat proyek baru dengan status, start date, deadline
- Lihat daftar proyek dengan progress bar
- Klik proyek untuk melihat detail dan task di dalamnya
- Edit status proyek (active, completed, on_hold)
- Verifikasi task count dan progress bar akurat
- Filter berdasarkan status
- Hapus proyek (cascade ke tasks)
