# 277. Mengimplementasikan Notifikasi Real-Time Menggunakan Laravel Echo dan Pusher

## Definisi & Target
Membangun notifikasi real-time menggunakan Laravel Echo (client-side) dan Pusher (server-side broadcast). Ketika ada aktivitas di task (komentar baru, status berubah, mention), anggota terkait mendapat notifikasi langsung.

## Komponen yang Terlibat
- Broadcasting: Pusher
- Library: laravel-echo (npm), pusher-php-server (composer)
- Event: `TaskUpdated`, `NewComment`
- Model: Task, TaskComment

## Perintah Artisan CLI
- `composer require pusher/pusher-php-server`
- `npm install -D laravel-echo pusher-js`
- `php artisan make:event TaskUpdated`
- `php artisan make:event NewComment`

## Kode Implementasi (Per File)

**config/broadcasting.php:**
```php
'connections' => [
    'pusher' => [
        'driver' => 'pusher',
        'key' => env('PUSHER_APP_KEY'),
        'secret' => env('PUSHER_APP_SECRET'),
        'app_id' => env('PUSHER_APP_ID'),
        'options' => [
            'cluster' => env('PUSHER_APP_CLUSTER'),
            'useTLS' => true,
        ],
    ],
];
```

**app/Events/TaskUpdated.php:**
```php
use Illuminate\Broadcasting\Channel;
use Illuminate\Broadcasting\InteractsWithSockets;
use Illuminate\Broadcasting\PresenceChannel;
use Illuminate\Contracts\Broadcasting\ShouldBroadcast;

class TaskUpdated implements ShouldBroadcast
{
    use Dispatchable, InteractsWithSockets, SerializesModels;

    public function __construct(public Task $task) {}

    public function broadcastOn(): array
    {
        return [
            new Channel('task.' . $this->task->id),
            new Channel('project.' . $this->task->project_id),
        ];
    }

    public function broadcastWith(): array
    {
        return [
            'id' => $this->task->id,
            'title' => $this->task->title,
            'status' => $this->task->status,
            'updated_by' => auth()->user()->name,
        ];
    }
}
```

**app/Events/NewComment.php:**
```php
class NewComment implements ShouldBroadcast
{
    use Dispatchable, InteractsWithSockets, SerializesModels;

    public function __construct(public TaskComment $comment) {}

    public function broadcastOn(): array
    {
        return [
            new Channel('task.' . $this->comment->task_id),
        ];
    }

    public function broadcastWith(): array
    {
        return [
            'task_id' => $this->comment->task_id,
            'user_name' => $this->comment->user->name,
            'content' => $this->comment->content,
            'created_at' => $this->comment->created_at->diffForHumans(),
        ];
    }
}
```

**resources/js/echo.js:**
```javascript
import Echo from 'laravel-echo';
import Pusher from 'pusher-js';

window.Pusher = Pusher;

window.Echo = new Echo({
    broadcaster: 'pusher',
    key: import.meta.env.VITE_PUSHER_APP_KEY,
    cluster: import.meta.env.VITE_PUSHER_APP_CLUSTER,
    forceTLS: true,
});
```

**resources/js/bootstrap.js (app.js integration):**
```javascript
import './echo';

// Listen for task updates
window.Echo.channel('project.' + window.projectId)
    .listen('TaskUpdated', (e) => {
        showNotification('Task "' + e.title + '" berubah ke ' + e.status + ' oleh ' + e.updated_by);
        Livewire.dispatch('refreshTask');
    });

// Listen for new comments
window.Echo.private('task.' + window.taskId)
    .listen('NewComment', (e) => {
        showNotification('Komentar baru dari ' + e.user_name + ': ' + e.content);
        Livewire.dispatch('refreshComments');
    });

function showNotification(message) {
    if (Notification.permission === 'granted') {
        new Notification('Project Update', { body: message });
    }
}
```

**app/Http/Controllers/TaskController.php (trigger event):**
```php
use App\Events\TaskUpdated;

public function updateStatus(Request $request, Task $task)
{
    $task->update(['status' => $request->status]);
    broadcast(new TaskUpdated($task))->toOthers();

    return response()->json(['success' => true]);
}
```

**app/Livewire/TaskComments.php (trigger event):**
```php
use App\Events\NewComment;

public function addComment()
{
    $comment = TaskComment::create([...]);
    broadcast(new NewComment($comment))->toOthers();
}
```

**routes/channels.php:**
```php
use Illuminate\Support\Facades\Broadcast;

Broadcast::channel('task.{taskId}', function ($user, $taskId) {
    $task = Task::find($taskId);
    if (!$task) return false;

    return WorkspaceMember::where('workspace_id', $task->workspace_id)
        ->where('user_id', $user->id)->exists();
});

Broadcast::channel('project.{projectId}', function ($user, $projectId) {
    $project = Project::find($projectId);
    if (!$project) return false;

    return WorkspaceMember::where('workspace_id', $project->workspace_id)
        ->where('user_id', $user->id)->exists();
});
```

## Cara Integrasi & Pengujian
- Set PUSHER_APP_ID, PUSHER_APP_KEY, PUSHER_APP_SECRET, PUSHER_APP_CLUSTER di .env
- Jalankan `php artisan queue:work` untuk broadcast
- Buka 2 browser: user A dan user B di task yang sama
- User A mengubah status task -> User B mendapat notifikasi real-time
- User A menambah komentar -> User B melihat komentar muncul tanpa reload
- Verifikasi private channel hanya untuk anggota workspace
- Cek Broadcasting Events di dashboard Pusher
- Browser notification permission di request
