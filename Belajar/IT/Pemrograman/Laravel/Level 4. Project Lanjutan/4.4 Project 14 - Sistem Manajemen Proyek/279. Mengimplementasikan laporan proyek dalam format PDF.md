# 279. Mengimplementasikan Laporan Proyek dalam Format PDF

## Definisi & Target
Membangun fitur laporan proyek yang dapat diexport ke PDF. Laporan mencakup informasi proyek, daftar task, status, progress, dan time log.

## Komponen yang Terlibat
- Controller: `ReportController`
- Library: barryvdh/laravel-dompdf

## Perintah Artisan CLI
- `composer require barryvdh/laravel-dompdf`
- `php artisan make:controller ReportController`

## Kode Implementasi (Per File)

**routes/web.php:**
```php
Route::get('/projects/{project}/report/pdf', [ReportController::class, 'projectPdf'])->name('projects.report.pdf');
Route::get('/projects/{project}/report', [ReportController::class, 'projectReport'])->name('projects.report');
```

**app/Http/Controllers/ReportController.php:**
```php
class ReportController extends Controller
{
    public function projectReport(Project $project)
    {
        $project->load(['tasks' => fn($q) => $q->with('assignee', 'timeLogs')->orderBy('status')->orderBy('priority', 'desc')]);
        return view('projects.report', compact('project'));
    }

    public function projectPdf(Project $project)
    {
        $project->load(['tasks' => fn($q) => $q->with('assignee', 'timeLogs')->orderBy('status')]);

        $pdf = Pdf::loadView('projects.report-pdf', compact('project'));
        $pdf->setPaper('A4', 'portrait');

        $filename = 'laporan-proyek-' . Str::slug($project->name) . '-' . date('Y-m-d') . '.pdf';

        return $pdf->download($filename);
    }
}
```

## Cara Integrasi & Pengujian
- Buka proyek dengan beberapa task
- Akses route `/projects/{id}/report` untuk preview HTML
- Klik download PDF untuk mengunduh laporan
- Verifikasi informasi proyek, ringkasan, dan daftar task
- Cek format tabel dan styling
- Pastikan DomPDF merender dengan baik
- Uji dengan proyek yang memiliki banyak task
