# 245. Mengimplementasikan Approval Chain yaitu Manager Kemudian HR untuk Pengajuan Cuti

## Definisi & Target
Membangun alur approval bertingkat (approval chain) di mana pengajuan cuti harus disetujui oleh manager terlebih dahulu, kemudian oleh HR. Setiap level approval memiliki view terpisah.

## Komponen yang Terlibat
- Migration: add approval_level, manager_approved_by, hr_approved_by ke tabel leaves
- Livewire Component: `ApprovalQueue`
- Model: Leave

## Perintah Artisan CLI
- `php artisan make:migration add_approval_chain_to_leaves_table`

## Kode Implementasi (Per File)

**Migration add_approval_chain_to_leaves_table:**
```php
Schema::table('leaves', function (Blueprint $table) {
    $table->enum('approval_level', ['pending_manager', 'pending_hr', 'approved', 'rejected'])->default('pending_manager')->after('status');
    $table->foreignId('manager_approved_by')->nullable()->constrained('employees')->nullOnDelete()->after('approval_level');
    $table->timestamp('manager_approved_at')->nullable()->after('manager_approved_by');
    $table->foreignId('hr_approved_by')->nullable()->constrained('employees')->nullOnDelete()->after('manager_approved_at');
    $table->timestamp('hr_approved_at')->nullable()->after('hr_approved_by');
    $table->text('manager_notes')->nullable()->after('hr_approved_at');
    $table->text('hr_notes')->nullable()->after('manager_notes');
});
```

public function managedDepartments(): HasMany
{
    return $this->hasMany(Department::class, 'manager_id');
}

public function isManager(): bool
{
    return $this->position && $this->position->level >= 3;
}

public function isHr(): bool
{
    return $this->department && $this->department->code === 'HR';
}

public function subordinates(): HasMany
{
    return Employee::where('department_id', $this->department_id)
        ->where('id', '!=', $this->id);
}

**app/Livewire/ApprovalQueue.php:**
```php
class ApprovalQueue extends Component
{
    public $selectedTab = 'manager';

    public function approve($leaveId, $notes = null)
    {
        $leave = Leave::findOrFail($leaveId);
        $employee = auth()->user()->employee;

        if ($this->selectedTab === 'manager') {
            $leave->update([
                'approval_level' => 'pending_hr',
                'manager_approved_by' => $employee->id,
                'manager_approved_at' => now(),
                'manager_notes' => $notes,
            ]);
        } elseif ($this->selectedTab === 'hr') {
            $leave->update([
                'approval_level' => 'approved',
                'status' => 'approved',
                'hr_approved_by' => $employee->id,
                'hr_approved_at' => now(),
                'hr_notes' => $notes,
                'approved_by' => $employee->id,
                'approved_at' => now(),
            ]);
        }

        $this->dispatch('approvalProcessed');
    }

    public function reject($leaveId, $reason)
    {
        $leave = Leave::findOrFail($leaveId);
        $employee = auth()->user()->employee;

        $updateData = [
            'approval_level' => 'rejected',
            'status' => 'rejected',
            'rejection_reason' => $reason,
        ];

        if ($this->selectedTab === 'manager') {
            $updateData['manager_approved_by'] = $employee->id;
            $updateData['manager_approved_at'] = now();
        } else {
            $updateData['hr_approved_by'] = $employee->id;
            $updateData['hr_approved_at'] = now();
        }

        $leave->update($updateData);
        $this->dispatch('approvalProcessed');
    }

    public function render()
    {
        $employee = auth()->user()->employee;

        $managerQueue = collect();
        $hrQueue = collect();

        if ($employee->isManager()) {
            $managerQueue = Leave::whereHas('employee', function ($q) use ($employee) {
                    $q->where('department_id', $employee->department_id);
                })
                ->where('approval_level', 'pending_manager')
                ->with('employee')
                ->latest()
                ->get();
        }

        if ($employee->isHr()) {
            $hrQueue = Leave::where('approval_level', 'pending_hr')
                ->with('employee', 'managerApprover')
                ->latest()
                ->get();
        }

        return view('livewire.approval-queue', compact('managerQueue', 'hrQueue'));
    }
}
```

## Cara Integrasi & Pengujian
- Karyawan mengajukan cuti (approval_level = pending_manager)
- Manager menyetujui (approval_level berubah ke pending_hr)
- HR menyetujui (status berubah menjadi approved)
- Uji penolakan di level manager (status rejected langsung)
- Verifikasi data approval tercatat (siapa yang approve dan kapan)
- Karyawan dengan posisi level >= 3 bisa melihat antrian manager
- Karyawan di departemen HR bisa melihat antrian HR
