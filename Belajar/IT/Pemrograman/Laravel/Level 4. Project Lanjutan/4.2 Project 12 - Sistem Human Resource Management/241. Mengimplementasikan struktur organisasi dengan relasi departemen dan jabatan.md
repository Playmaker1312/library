# 241. Mengimplementasikan Struktur Organisasi dengan Relasi Departemen dan Jabatan

## Definisi & Target
Membangun fitur struktur organisasi yang menampilkan hierarki departemen dan jabatan dalam bentuk tree. Setiap departemen dapat memiliki sub-departemen dan setiap departemen memiliki daftar jabatan.

## Komponen yang Terlibat
- Model: Department (dengan parent_id self-referencing), Position
- Controller: `OrganizationController`
- View: organization chart

## Perintah Artisan CLI
- `php artisan make:controller OrganizationController`

## Kode Implementasi (Per File)

**routes/web.php:**
```php
Route::get('/organization', [OrganizationController::class, 'index'])->name('organization.index');
Route::get('/organization/tree', [OrganizationController::class, 'tree'])->name('organization.tree');
```

**app/Http/Controllers/OrganizationController.php:**
```php
class OrganizationController extends Controller
{
    public function index()
    {
        $departments = Department::with('children', 'positions', 'employees')
            ->whereNull('parent_id')
            ->get();

        return view('organization.index', compact('departments'));
    }

    public function tree()
    {
        $departments = Department::with(['children' => function ($q) {
            $q->with('positions', 'employees');
        }, 'positions', 'employees'])->whereNull('parent_id')->get();

        $tree = $departments->map(fn($d) => $this->buildTree($d));

        return response()->json($tree);
    }

    private function buildTree($department)
    {
        $node = [
            'id' => $department->id,
            'name' => $department->name,
            'code' => $department->code,
            'employee_count' => $department->employees->count(),
            'positions' => $department->positions->map(fn($p) => [
                'id' => $p->id,
                'name' => $p->name,
                'employee_count' => Employee::where('position_id', $p->id)->count()
            ]),
            'children' => [],
        ];

        foreach ($department->children as $child) {
            $node['children'][] = $this->buildTree($child);
        }

        return $node;
    }
}
```

**app/Models/Department.php (tambahan method):**
```php
public function allDescendantsIds(): array
{
    $ids = [$this->id];
    foreach ($this->children as $child) {
        $ids = array_merge($ids, $child->allDescendantsIds());
    }
    return $ids;
}

public function scopeRoot($query)
{
    return $query->whereNull('parent_id');
}
```

## Cara Integrasi & Pengujian
- Buat beberapa departemen dengan parent_id (contoh: IT -> Software, Infra)
- Buat jabatan di setiap departemen
- Akses `/organization` untuk melihat struktur tree
- Verifikasi tampilan hierarki dengan benar
- Klik node untuk melihat detail
- Verifikasi data JSON tree di endpoint `/organization/tree`
