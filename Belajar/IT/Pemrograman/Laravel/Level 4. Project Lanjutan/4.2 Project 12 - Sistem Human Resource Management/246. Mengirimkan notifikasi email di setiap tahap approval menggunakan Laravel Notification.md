# 246. Mengirimkan Notifikasi Email di Setiap Tahap Approval Menggunakan Laravel Notification

## Definisi & Target
Mengirimkan notifikasi email otomatis di setiap tahap approval cuti: saat pengajuan dibuat, disetujui manager, ditolak manager, disetujui HR, dan ditolak HR. Menggunakan Laravel Notification.

## Komponen yang Terlibat
- Notification Class: `LeaveSubmitted`, `LeaveApprovedByManager`, `LeaveApprovedByHr`, `LeaveRejected`
- Model: Leave, Employee (Notifiable)
- Mail Template

## Perintah Artisan CLI
- `php artisan make:notification LeaveSubmitted`
- `php artisan make:notification LeaveApproved`
- `php artisan make:notification LeaveRejected`

## Kode Implementasi (Per File)

**app/Notifications/LeaveSubmitted.php:**
```php
class LeaveSubmitted extends Notification
{
    use Queueable;

    public function __construct(public Leave $leave) {}

    public function via($notifiable): array
    {
        return ['mail', 'database'];
    }

    public function toMail($notifiable): MailMessage
    {
        return (new MailMessage)
            ->subject('Pengajuan Cuti Baru - ' . $this->leave->employee->name)
            ->greeting('Halo ' . $notifiable->name . ',')
            ->line('Terdapat pengajuan cuti baru yang perlu Anda review.')
            ->line('Karyawan: ' . $this->leave->employee->name)
            ->line('Jenis: ' . ucfirst($this->leave->type))
            ->line('Tanggal: ' . $this->leave->start_date->format('d/m/Y') . ' - ' . $this->leave->end_date->format('d/m/Y'))
            ->line('Durasi: ' . $this->leave->duration . ' hari')
            ->line('Alasan: ' . $this->leave->reason)
            ->action('Review Pengajuan', url('/admin/leaves'))
            ->line('Terima kasih.');
    }

    public function toArray($notifiable): array
    {
        return [
            'leave_id' => $this->leave->id,
            'type' => 'leave_submitted',
            'message' => 'Pengajuan cuti baru dari ' . $this->leave->employee->name,
        ];
    }
}
```

**app/Notifications/LeaveApproved.php:**
```php
class LeaveApproved extends Notification
{
    use Queueable;

    public function __construct(public Leave $leave, public string $level) {}

    public function via($notifiable): array
    {
        return ['mail', 'database'];
    }

    public function toMail($notifiable): MailMessage
    {
        $approverName = $this->level === 'manager'
            ? $this->leave->managerApprover->name
            : $this->leave->hrApprover->name;

        return (new MailMessage)
            ->subject('Cuti Disetujui - ' . $this->level)
            ->greeting('Halo ' . $notifiable->name . ',')
            ->line('Pengajuan cuti Anda telah disetujui oleh ' . $approverName . '.')
            ->line('Jenis: ' . ucfirst($this->leave->type))
            ->line('Tanggal: ' . $this->leave->start_date->format('d/m/Y') . ' - ' . $this->leave->end_date->format('d/m/Y'))
            ->line('Level: ' . ucfirst($this->level))
            ->action('Lihat Detail', url('/leaves'))
            ->line('Selamat menikmati cuti Anda!');
    }

    public function toArray($notifiable): array
    {
        return [
            'leave_id' => $this->leave->id,
            'type' => 'leave_approved_' . $this->level,
            'message' => 'Cuti Anda disetujui oleh ' . ($this->level === 'manager' ? 'Manager' : 'HR'),
        ];
    }
}
```

class LeaveRejected extends Notification
{
    use Queueable;

    public function __construct(public Leave $leave) {}

    {
        return ['mail', 'database'];

**app/Livewire/ApprovalQueue.php (memanggil notifikasi):**
```php
use App\Notifications\LeaveApproved;
use App\Notifications\LeaveRejected;

public function approve($leaveId, $notes = null)
{
    $leave = Leave::findOrFail($leaveId);
    $employee = auth()->user()->employee;

    if ($this->selectedTab === 'manager') {
        $leave->update([
            'approval_level' => 'pending_hr',
            'manager_approved_by' => $employee->id,
            'manager_approved_at' => now(),
            'manager_notes' => $notes,
        ]);

        $leave->employee->user->notify(new LeaveApproved($leave, 'manager'));
    } elseif ($this->selectedTab === 'hr') {
        $leave->update([
            'approval_level' => 'approved',
            'status' => 'approved',
            'hr_approved_by' => $employee->id,
            'hr_approved_at' => now(),
            'hr_notes' => $notes,
            'approved_by' => $employee->id,
            'approved_at' => now(),
        ]);

        $leave->employee->user->notify(new LeaveApproved($leave, 'hr'));
    }
}

public function reject($leaveId, $reason)
{
    $leave = Leave::findOrFail($leaveId);
    $employee = auth()->user()->employee;
    $leave->update([
        'approval_level' => 'rejected',
        'status' => 'rejected',
        'rejection_reason' => $reason,
    ]);

    $leave->employee->user->notify(new LeaveRejected($leave));
}
```

## Cara Integrasi & Pengujian
- Konfigurasi mail di .env (MAIL_MAILER=smtp, dll)
- Karyawan mengajukan cuti -> manager mendapat email notifikasi
- Manager approve -> karyawan mendapat email "Disetujui Manager"
- Manager reject -> karyawan mendapat email "Ditolak"
- HR approve -> karyawan mendapat email "Disetujui HR"
- Cek tabel notifications untuk notifikasi database
- Uji queue: pastikan queue worker berjalan
