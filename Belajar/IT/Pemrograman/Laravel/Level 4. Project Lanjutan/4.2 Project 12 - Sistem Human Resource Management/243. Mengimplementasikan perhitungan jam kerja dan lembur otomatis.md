# 243. Mengimplementasikan Perhitungan Jam Kerja dan Lembur Otomatis

## Definisi & Target
Membangun perhitungan otomatis jam kerja (work_hours) dan jam lembur (overtime_hours) berdasarkan selisih clock in dan clock out. Lembur dihitung jika jam kerja melebihi 8 jam per hari.

## Komponen yang Terlibat
- Model: Attendance
- Trait: `CalculatesWorkHours`
- Service: `AttendanceService`

## Perintah Artisan CLI
- Tidak ada perintah khusus

## Kode Implementasi (Per File)

**app/Services/AttendanceService.php:**
```php
class AttendanceService
{
    private const REGULAR_HOURS = 8;
    private const WORK_START = '08:00';
    private const LATE_THRESHOLD = '08:15';

    public function processClockOut(Attendance $attendance): Attendance
    {
        $clockIn = \Carbon\Carbon::parse($attendance->clock_in);
        $clockOut = \Carbon\Carbon::parse($attendance->clock_out);

        $totalMinutes = $clockIn->diffInMinutes($clockOut);
        $workHours = round($totalMinutes / 60, 2);
        $overtimeHours = round(max(0, $workHours - self::REGULAR_HOURS), 2);

        $attendance->work_hours = $workHours;
        $attendance->overtime_hours = $overtimeHours;

        return $attendance;
    }

    public function determineStatus(string $clockInTime): string
    {
        return $clockInTime > self::LATE_THRESHOLD ? 'late' : 'present';
    }

    public function calculateMonthlySummary(int $employeeId, string $yearMonth): array
    {
        $attendances = Attendance::where('employee_id', $employeeId)
            ->whereYear('date', substr($yearMonth, 0, 4))
            ->whereMonth('date', substr($yearMonth, 5, 2))
            ->get();

        return [
            'total_present' => $attendances->where('status', 'present')->count(),
            'total_late' => $attendances->where('status', 'late')->count(),
            'total_absent' => $attendances->where('status', 'absent')->count(),
            'total_work_hours' => $attendances->sum('work_hours'),
            'total_overtime_hours' => $attendances->sum('overtime_hours'),
            'total_days' => $attendances->count(),
        ];
    }

    public function calculateOvertimePay(float $overtimeHours, float $hourlyRate): float
    {
        $overtimeRate = 1.5;
        $firstHourRate = $hourlyRate * $overtimeRate;
        $subsequentRate = $hourlyRate * 2;
        $totalPay = 0;

        for ($i = 1; $i <= $overtimeHours; $i++) {
            if ($i === 1) {
                $totalPay += $firstHourRate;
            } else {
                $totalPay += $subsequentRate;
            }
        }

        return $totalPay;
    }
}
```

**app/Models/Attendance.php (tambahan method):**
```php
public function scopeMonthly(Builder $query, string $yearMonth): Builder
{
    $year = substr($yearMonth, 0, 4);
    $month = substr($yearMonth, 5, 2);
    return $query->whereYear('date', $year)->whereMonth('date', $month);
}

public function scopeLate(Builder $query): Builder
{
    return $query->where('status', 'late');
}

public function getWorkHoursFormattedAttribute(): string
{
    $hours = floor($this->work_hours);
    $minutes = round(($this->work_hours - $hours) * 60);
    return "{$hours} jam {$minutes} menit";
}

public function getOvertimeFormattedAttribute(): string
{
    if ($this->overtime_hours <= 0) return '0 jam';
    $hours = floor($this->overtime_hours);
    $minutes = round(($this->overtime_hours - $hours) * 60);
    return "{$hours} jam {$minutes} menit";
}
```

**app/Livewire/AttendanceSummary.php:**
```php
class AttendanceSummary extends Component
{
    public $employeeId;
    public $month;
    public $summary = [];
    public $attendances = [];

    public function mount($employeeId = null)
    {
        $this->employeeId = $employeeId ?? auth()->user()->employee->id;
        $this->month = now()->format('Y-m');
        $this->loadSummary();
    }

    public function loadSummary()
    {
        $service = app(AttendanceService::class);
        $this->summary = $service->calculateMonthlySummary($this->employeeId, $this->month);
        $this->attendances = Attendance::where('employee_id', $this->employeeId)
            ->monthly($this->month)
            ->orderBy('date')
            ->get()
            ->toArray();
    }

    public function render()
    {
        return view('livewire.attendance-summary');
    }
}
```
