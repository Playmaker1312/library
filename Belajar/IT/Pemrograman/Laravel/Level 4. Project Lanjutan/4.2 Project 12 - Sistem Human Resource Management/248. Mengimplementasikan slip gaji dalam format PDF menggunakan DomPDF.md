# 248. Mengimplementasikan Slip Gaji dalam Format PDF Menggunakan DomPDF

## Definisi & Target
Membangun fitur slip gaji dalam format PDF yang bisa diunduh oleh karyawan. Slip menampilkan rincian gaji, tunjangan, potongan, dan total akhir. Menggunakan DomPDF.

## Komponen yang Terlibat
- Controller: `PayrollController`
- Library: barryvdh/laravel-dompdf
- Blade View: print.slip-gaji

## Perintah Artisan CLI
- `composer require barryvdh/laravel-dompdf`
- `php artisan make:controller PayrollController`

## Kode Implementasi (Per File)

**routes/web.php:**
```php
Route::get('/payroll/{payroll}/slip', [PayrollController::class, 'slip'])->name('payroll.slip');
Route::get('/payroll/{payroll}/pdf', [PayrollController::class, 'pdf'])->name('payroll.pdf');
```

**app/Http/Controllers/PayrollController.php:**
```php
class PayrollController extends Controller
{
    public function slip(Payroll $payroll)
    {
        $payroll->load('employee.department', 'employee.position');
        return view('print.slip-gaji', compact('payroll'));
    }

    public function pdf(Payroll $payroll)
    {
        $payroll->load('employee.department', 'employee.position');
        $pdf = Pdf::loadView('print.slip-gaji', compact('payroll'));
        $pdf->setPaper('A4');

        $filename = 'slip-gaji-' . $payroll->employee->employee_id . '-' . $payroll->period . '.pdf';

        return $pdf->download($filename);
    }

    public function markPaid(Payroll $payroll)
    {
        $payroll->update(['status' => 'paid', 'paid_at' => now()]);

        return back()->with('success', 'Payroll berhasil dibayarkan');
    }
}
```

## Cara Integrasi & Pengujian
- Generate payroll untuk seorang karyawan
- Akses route `/payroll/{id}/slip` untuk tampilan HTML
- Klik download PDF untuk mengunduh slip
- Verifikasi semua informasi muncul: gaji pokok, tunjangan, potongan, total
- Uji dengan DomPDF: pastikan font dan layout berfungsi
- Tandai payroll sebagai "paid" dan lihat status berubah di PDF
