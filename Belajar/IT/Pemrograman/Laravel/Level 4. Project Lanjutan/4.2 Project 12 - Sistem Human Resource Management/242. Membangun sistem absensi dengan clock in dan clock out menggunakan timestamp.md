# 242. Membangun Sistem Absensi dengan Clock In dan Clock Out Menggunakan Timestamp

## Definisi & Target
Membangun sistem absensi yang mencatat waktu clock in dan clock out karyawan setiap hari. Sistem menggunakan timestamp untuk mencatat waktu presisi dan menentukan status kehadiran.

## Komponen yang Terlibat
- Livewire Component: `AttendanceScanner`
- Model: Attendance, Employee
- View: halaman absensi dan riwayat

## Perintah Artisan CLI
- `php artisan make:livewire AttendanceScanner`

## Kode Implementasi (Per File)

**app/Livewire/AttendanceScanner.php:**
```php
class AttendanceScanner extends Component
{
    public $employeeId = '';
    public $message = '';
    public $messageType = '';
    public $todayAttendance = null;
    public $recentAttendances = [];

    public function mount()
    {
        if (auth()->user()->employee) {
            $this->loadTodayAttendance();
        }
    }

    public function clockIn()
    {
        $employee = auth()->user()->employee;
        $today = now()->format('Y-m-d');

        $existing = Attendance::where('employee_id', $employee->id)
            ->where('date', $today)->first();

        if ($existing && $existing->clock_in) {
            $this->message = 'Anda sudah melakukan clock in hari ini';
            $this->messageType = 'warning';
            return;
        }

        $now = now();
        $status = $now->format('H:i') > '08:00' ? 'late' : 'present';

        Attendance::updateOrCreate(
            ['employee_id' => $employee->id, 'date' => $today],
            ['clock_in' => $now, 'status' => $status]
        );

        $this->message = 'Clock in berhasil pada ' . $now->format('H:i:s');
        $this->messageType = 'success';
        $this->loadTodayAttendance();
    }

    public function clockOut()
    {
        $employee = auth()->user()->employee;
        $today = now()->format('Y-m-d');

        $attendance = Attendance::where('employee_id', $employee->id)
            ->where('date', $today)->first();

        if (!$attendance || !$attendance->clock_in) {
            $this->message = 'Anda belum melakukan clock in';
            $this->messageType = 'error';
            return;
        }

        if ($attendance->clock_out) {
            $this->message = 'Anda sudah melakukan clock out hari ini';
            $this->messageType = 'warning';
            return;
        }

        $now = now();
        $clockIn = \Carbon\Carbon::parse($attendance->clock_in);
        $workHours = $clockIn->diffInHours($now);
        $overtimeHours = max(0, $workHours - 8);

        $attendance->update([
            'clock_out' => $now,
            'work_hours' => $workHours,
            'overtime_hours' => $overtimeHours,
        ]);

        $this->message = 'Clock out berhasil. Jam kerja: ' . number_format($workHours, 1) . ' jam';
        $this->messageType = 'success';
        $this->loadTodayAttendance();
    }

    public function loadTodayAttendance()
    {
        $employee = auth()->user()->employee;
        if (!$employee) return;

        $this->todayAttendance = Attendance::where('employee_id', $employee->id)
            ->where('date', now()->format('Y-m-d'))->first();

        $this->recentAttendances = Attendance::where('employee_id', $employee->id)
            ->latest('date')->take(10)->get()->toArray();
    }

    public function render()
    {
        return view('livewire.attendance-scanner');
    }
}
```

**resources/views/livewire/attendance-scanner.blade.php:**

<div class="max-w-2xl mx-auto p-6">
    <h1 class="text-2xl font-bold mb-6">Absensi Karyawan</h1>

        {{ $message }}
    </div>
    @endif

        <p class="text-gray-500 mb-2">{{ now()->format('l, d F Y') }}</p>

            {{ now()->format('H:i:s') }}
        </p>

        <div class="flex justify-center space-x-4">
            <button wire:click="clockIn" {{ $todayAttendance && $todayAttendance['clock_in'] ? 'disabled' : '' }}
                    class="px-8 py-3 rounded-lg font-bold {{ $todayAttendance && $todayAttendance['clock_in'] ? 'bg-gray-300 cursor-not-allowed' : 'bg-green-600 text-white hover:bg-green-700' }}">
                Clock In
            </button>
            <button wire:click="clockOut" {{ !$todayAttendance || $todayAttendance['clock_out'] ? 'disabled' : '' }}
                    class="px-8 py-3 rounded-lg font-bold {{ !$todayAttendance || $todayAttendance['clock_out'] ? 'bg-gray-300 cursor-not-allowed' : 'bg-red-600 text-white hover:bg-red-700' }}">
                Clock Out
            </button>
        </div>

        @if($todayAttendance)

            @if($todayAttendance['clock_in'])
            <p>Clock In: {{ \Carbon\Carbon::parse($todayAttendance['clock_in'])->format('H:i:s') }}</p>
            @endif
            @if($todayAttendance['clock_out'])
            <p>Clock Out: {{ \Carbon\Carbon::parse($todayAttendance['clock_out'])->format('H:i:s') }}</p>
            <p>Total: {{ $todayAttendance['work_hours'] }} jam</p>
            @endif
        </div>
        @endif
    </div>

        <h2 class="font-bold mb-3">Riwayat Absensi (10 Hari Terakhir)</h2>
        <table class="w-full">
            <thead>
                <tr class="text-left border-b">
                    <th class="p-2">Tanggal</th>
                    <th class="p-2">Clock In</th>
                    <th class="p-2">Clock Out</th>
                    <th class="p-2">Jam Kerja</th>
                    <th class="p-2">Status</th>
                </tr>
            </thead>
            <tbody>
                @foreach($recentAttendances as $a)

                    <td class="p-2">{{ $a['work_hours'] }} jam</td>

                            {{ $a['status'] }}
                        </span>
                    </td>
                </tr>
                @endforeach
            </tbody>

## Cara Integrasi & Pengujian
- Pastikan user memiliki relasi ke employee
- Akses halaman absensi, klik Clock In
- Verifikasi data tersimpan di tabel attendances
- Refresh halaman, clock in tidak bisa diklik lagi
- Klik Clock Out setelah beberapa waktu
- Verifikasi jam kerja dan lembur otomatis terhitung
- Cek riwayat 10 hari terakhir
