# 244. Membangun Modul Pengajuan Cuti dengan Approval Workflow

## Definisi & Target
Membangun modul pengajuan cuti yang memungkinkan karyawan mengajukan cuti (tahunan, sakit, pribadi) dan mengikuti alur approval bertingkat.

## Komponen yang Terlibat
- Livewire Component: `LeaveRequest`
- Model: Leave, Employee
- View: form pengajuan dan daftar cuti

## Perintah Artisan CLI
- `php artisan make:livewire LeaveRequest`

## Kode Implementasi (Per File)

**app/Livewire/LeaveRequest.php:**
```php
class LeaveRequest extends Component
{
    public $leaveId;
    public $type = 'annual';
    public $startDate;
    public $endDate;
    public $reason;
    public $showForm = false;

    protected $rules = [
        'type' => 'required|in:annual,sick,personal,maternity,other',
        'startDate' => 'required|date|after_or_equal:today',
        'endDate' => 'required|date|after_or_equal:startDate',
        'reason' => 'required|min:10',
    ];

    public function submit()
    {
        $this->validate();

        $employee = auth()->user()->employee;

        if ($this->type === 'annual') {
            $duration = \Carbon\Carbon::parse($this->startDate)->diffInDays($this->endDate) + 1;
            if ($duration > $employee->remaining_leave) {
                $this->addError('type', 'Sisa cuti Anda tidak mencukupi. Sisa: ' . $employee->remaining_leave . ' hari');
                return;
            }
        }

        Leave::create([
            'employee_id' => $employee->id,
            'type' => $this->type,
            'start_date' => $this->startDate,
            'end_date' => $this->endDate,
            'reason' => $this->reason,
            'status' => 'pending',
        ]);

        $this->reset(['type', 'startDate', 'endDate', 'reason', 'showForm']);
        $this->dispatch('leaveSubmitted');
    }

    public function cancelLeave($leaveId)
    {
        $leave = Leave::findOrFail($leaveId);
        if ($leave->employee_id !== auth()->user()->employee->id) return;
        if ($leave->status !== 'pending') return;

        $leave->update(['status' => 'cancelled']);
    }

    public function render()
    {
        $employee = auth()->user()->employee;
        $leaves = Leave::where('employee_id', $employee->id)
            ->latest()->paginate(10);

        return view('livewire.leave-request', [
            'leaves' => $leaves,
            'remainingLeave' => $employee->remaining_leave,
        ]);
    }
}
```

## Cara Integrasi & Pengujian
- Karyawan mengajukan cuti tahunan
- Verifikasi sisa cuti berkurang saat validasi
- Cuti muncul dengan status "pending"
- Karyawan dapat membatalkan cuti yang masih pending
- Uji validasi: tanggal harus setelah hari ini, reason minimal 10 karakter
- Uji berbagai jenis cuti (annual, sick, personal)
