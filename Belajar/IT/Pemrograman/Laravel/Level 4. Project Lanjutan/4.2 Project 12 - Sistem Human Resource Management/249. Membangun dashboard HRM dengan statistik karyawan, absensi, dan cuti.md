# 249. Membangun Dashboard HRM dengan Statistik Karyawan, Absensi, dan Cuti

## Definisi & Target
Membangun dashboard HRM yang menampilkan statistik ringkas tentang karyawan (total, aktif, resigned), absensi hari ini, pengajuan cuti pending, dan grafik kehadiran.

## Komponen yang Terlibat
- Livewire Component: `HrmDashboard`
- Model: Employee, Attendance, Leave, Payroll

## Perintah Artisan CLI
- `php artisan make:livewire HrmDashboard`

## Kode Implementasi (Per File)

**app/Livewire/HrmDashboard.php:**
```php
class HrmDashboard extends Component
{
    public $stats = [];
    public $todayAttendance = [];
    public $pendingLeaves = [];
    public $departmentStats = [];
    public $monthlyAttendance = [];

    public function mount()
    {
        $this->loadStats();
    }

    public function loadStats()
    {
        $today = now()->format('Y-m-d');
        $currentMonth = now()->format('Y-m');

        $this->stats = [
            'total_employees' => Employee::count(),
            'active_employees' => Employee::where('status', 'active')->count(),
            'resigned_employees' => Employee::where('status', 'resigned')->count(),
            'present_today' => Attendance::whereDate('created_at', today())->where('status', 'present')->count(),
            'late_today' => Attendance::whereDate('created_at', today())->where('status', 'late')->count(),
            'absent_today' => Attendance::whereDate('created_at', today())->where('status', 'absent')->count(),
            'pending_leaves' => Leave::where('status', 'pending')->count(),
            'approved_leaves' => Leave::where('status', 'approved')->whereMonth('start_date', now()->month)->count(),
            'total_payroll_this_month' => Payroll::where('period', $currentMonth)->sum('total'),
        ];

        $this->pendingLeaves = Leave::with('employee')
            ->where('status', 'pending')
            ->latest()
            ->take(5)
            ->get()
            ->toArray();

        $this->departmentStats = Department::withCount('employees')
            ->get()
            ->toArray();

        $this->todayAttendance = Attendance::with('employee')
            ->whereDate('created_at', today())
            ->orderBy('clock_in')
            ->take(10)
            ->get()
            ->toArray();

        $this->monthlyAttendance = Attendance::selectRaw('DATE(date) as date, COUNT(*) as total, SUM(CASE WHEN status = "present" THEN 1 ELSE 0 END) as present, SUM(CASE WHEN status = "late" THEN 1 ELSE 0 END) as late')
            ->whereMonth('date', now()->month)
            ->whereYear('date', now()->year)
            ->groupBy('date')
            ->orderBy('date')
            ->get()
            ->toArray();
    }

    public function render()
    {
        return view('livewire.hrm-dashboard')->layout('layouts.admin');
    }
}
```

## Cara Integrasi & Pengujian
- Akses route `/hrm/dashboard`
- Verifikasi 4 kartu statistik di bagian atas
- Cek daftar karyawan per departemen
- Lihat absensi hari ini (real-time)
- Lihat daftar cuti pending
- Grafik kehadiran bulanan muncul dengan benar
- Pastikan polling 30 detik berfungsi
