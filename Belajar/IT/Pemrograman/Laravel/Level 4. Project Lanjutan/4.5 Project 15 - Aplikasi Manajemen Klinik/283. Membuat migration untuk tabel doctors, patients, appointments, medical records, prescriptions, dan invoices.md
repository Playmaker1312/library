# 283. Membuat Migration untuk Tabel Doctors, Patients, Appointments, Medical Records, Prescriptions, dan Invoices

## Definisi & Target
Membuat file migration Laravel untuk seluruh tabel klinik dengan kolom, foreign key, index, dan constraint yang diperlukan.

## Komponen yang Terlibat
- Migration doctors, patients, appointments, medical_records, prescriptions, prescription_items, invoices

## Perintah Artisan CLI
- `php artisan make:migration create_doctors_table`
- `php artisan make:migration create_patients_table`
- `php artisan make:migration create_appointments_table`
- `php artisan make:migration create_medical_records_table`
- `php artisan make:migration create_prescriptions_table`
- `php artisan make:migration create_invoices_table`

## Kode Implementasi (Per File)

**Doctors:**
```php
Schema::create('doctors', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->nullable()->constrained()->nullOnDelete();
    $table->string('name');
    $table->string('specialist');
    $table->string('license_number')->unique();
    $table->string('phone')->nullable();
    $table->text('address')->nullable();
    $table->json('schedule')->nullable();
    $table->decimal('consultation_fee', 15, 2)->default(0);
    $table->boolean('is_active')->default(true);
    $table->timestamps();
});
```

**Patients:**
```php
Schema::create('patients', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->nullable()->constrained()->nullOnDelete();
    $table->string('name');
    $table->string('nik')->unique();
    $table->string('phone');
    $table->text('address')->nullable();
    $table->date('birth_date');
    $table->enum('gender', ['male', 'female']);
    $table->string('blood_type')->nullable();
    $table->timestamps();
    $table->index(['name', 'nik']);
});
```

**Appointments:**
```php
Schema::create('appointments', function (Blueprint $table) {
    $table->id();
    $table->foreignId('doctor_id')->constrained();
    $table->foreignId('patient_id')->constrained();
    $table->date('appointment_date');
    $table->time('time_slot');
    $table->enum('status', ['scheduled', 'checked_in', 'in_consultation', 'completed', 'cancelled'])->default('scheduled');
    $table->text('complaint')->nullable();
    $table->timestamps();
    $table->unique(['doctor_id', 'appointment_date', 'time_slot']);
});
```

**Medical Records:**
```php
Schema::create('medical_records', function (Blueprint $table) {
    $table->id();
    $table->foreignId('patient_id')->constrained();
    $table->foreignId('doctor_id')->constrained();
    $table->foreignId('appointment_id')->constrained();
    $table->text('anamnesis');
    $table->text('diagnosis');
    $table->text('therapy')->nullable();
    $table->text('notes')->nullable();
    $table->timestamps();
});
```

**Prescriptions:**
```php
Schema::create('prescriptions', function (Blueprint $table) {
    $table->id();
    $table->foreignId('medical_record_id')->constrained()->cascadeOnDelete();
    $table->text('notes')->nullable();
    $table->timestamps();
});

Schema::create('prescription_items', function (Blueprint $table) {
    $table->id();
    $table->foreignId('prescription_id')->constrained()->cascadeOnDelete();
    $table->string('drug_name');
    $table->string('dosage');
    $table->integer('quantity');
    $table->string('unit')->default('tablet');
    $table->text('notes')->nullable();
    $table->timestamps();
});
```

**Invoices:**
```php
Schema::create('invoices', function (Blueprint $table) {
    $table->id();
    $table->foreignId('patient_id')->constrained();
    $table->foreignId('appointment_id')->constrained();
    $table->string('invoice_number')->unique();
    $table->decimal('consultation_fee', 15, 2)->default(0);
    $table->decimal('action_fee', 15, 2)->default(0);
    $table->decimal('drug_fee', 15, 2)->default(0);
    $table->decimal('other_fees', 15, 2)->default(0);
    $table->decimal('total', 15, 2);
    $table->enum('status', ['unpaid', 'paid', 'cancelled'])->default('unpaid');
    $table->timestamp('paid_at')->nullable();
    $table->timestamps();
});
```

## Cara Integrasi & Pengujian
- Jalankan `php artisan migrate:fresh`
- Verifikasi unique constraint pada appointment (doctor + date + time)
- Cek foreign key cascade pada prescription_items
- Index untuk pencarian pasien (nama, NIK)
