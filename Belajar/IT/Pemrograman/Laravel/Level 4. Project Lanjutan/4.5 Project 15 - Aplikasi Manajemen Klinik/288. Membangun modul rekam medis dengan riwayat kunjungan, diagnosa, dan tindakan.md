# 288. Membangun Modul Rekam Medis dengan Riwayat Kunjungan, Diagnosa, dan Tindakan

## Definisi & Target
Membangun modul rekam medis elektronik yang mencatat anamnesis, diagnosa, terapi/tindakan, dan catatan dokter. Setiap pasien memiliki riwayat kunjungan lengkap.

## Komponen yang Terlibat
- Livewire Component: `MedicalRecordForm`
- Model: MedicalRecord, Appointment

## Perintah Artisan CLI
- `php artisan make:livewire MedicalRecordForm`

## Kode Implementasi (Per File)

**app/Livewire/MedicalRecordForm.php:**
```php
class MedicalRecordForm extends Component
{
    public $appointment;
    public $anamnesis;
    public $diagnosis;
    public $therapy;
    public $notes;
    public $patientHistory = [];

    public function mount($appointmentId)
    {
        $this->appointment = Appointment::with('patient', 'doctor')->findOrFail($appointmentId);

        $existing = MedicalRecord::where('appointment_id', $appointmentId)->first();
        if ($existing) {
            $this->anamnesis = $existing->anamnesis;
            $this->diagnosis = $existing->diagnosis;
            $this->therapy = $existing->therapy;
            $this->notes = $existing->notes;
        }

        $this->patientHistory = MedicalRecord::where('patient_id', $this->appointment->patient_id)
            ->with('doctor', 'appointment')
            ->latest()
            ->take(5)
            ->get()
            ->toArray();
    }

    public function save()
    {
        $this->validate([
            'anamnesis' => 'required|string',
            'diagnosis' => 'required|string',
            'therapy' => 'nullable|string',
            'notes' => 'nullable|string',
        ]);

        MedicalRecord::updateOrCreate(
            ['appointment_id' => $this->appointment->id],
            [
                'patient_id' => $this->appointment->patient_id,
                'doctor_id' => $this->appointment->doctor_id,
                'anamnesis' => $this->anamnesis,
                'diagnosis' => $this->diagnosis,
                'therapy' => $this->therapy,
                'notes' => $this->notes,
            ]
        );

        $this->appointment->update(['status' => 'completed']);

        $this->dispatch('medicalRecordSaved');
    }

    public function render()
    {
        return view('livewire.medical-record-form');
    }
}
```

## Cara Integrasi & Pengujian
- Buka appointment yang sudah check-in
- Isi anamnesis, diagnosa, terapi, dan catatan
- Simpan rekam medis
- Status appointment berubah menjadi "completed"
- Riwayat kunjungan pasien tampil di panel kanan
- Edit rekam medis yang sudah ada (updateOrCreate)
- Data tersimpan di tabel medical_records
- Verifikasi relasi dengan appointment, pasien, dokter
