# 290. Membangun Modul Billing dengan Perhitungan Biaya Konsultasi, Tindakan, dan Obat

## Definisi & Target
Membangun modul billing/penagihan yang menghitung total biaya berdasarkan biaya konsultasi dokter, biaya tindakan, biaya obat dari resep, dan biaya lainnya.

## Komponen yang Terlibat
- Livewire Component: `BillingForm`
- Model: Invoice, Prescription, Doctor

## Perintah Artisan CLI
- `php artisan make:livewire BillingForm`

## Kode Implementasi (Per File)

**app/Livewire/BillingForm.php:**
```php
class BillingForm extends Component
{
    public $appointment;
    public $consultationFee = 0;
    public $actionFee = 0;
    public $drugFee = 0;
    public $otherFees = 0;
    public $total = 0;
    public $actionDescription = '';

    public function mount($appointmentId)
    {
        $this->appointment = Appointment::with('patient', 'doctor', 'medicalRecord.prescription.items')
            ->findOrFail($appointmentId);

        $this->consultationFee = $this->appointment->doctor->consultation_fee ?? 0;

        $medicalRecord = $this->appointment->medicalRecord;
        if ($medicalRecord && $medicalRecord->prescription) {
            $this->drugFee = $medicalRecord->prescription->items->sum(function ($item) {
                return $this->estimateDrugPrice($item->drug_name) * $item->quantity;
            });
        }

        $existingInvoice = Invoice::where('appointment_id', $appointmentId)->first();
        if ($existingInvoice) {
            $this->consultationFee = $existingInvoice->consultation_fee;
            $this->actionFee = $existingInvoice->action_fee;
            $this->drugFee = $existingInvoice->drug_fee;
            $this->otherFees = $existingInvoice->other_fees;
            $this->total = $existingInvoice->total;
        }

        $this->calculateTotal();
    }

    public function calculateTotal()
    {
        $this->total = $this->consultationFee + $this->actionFee + $this->drugFee + $this->otherFees;
    }

    public function updatedConsultationFee() { $this->calculateTotal(); }
    public function updatedActionFee() { $this->calculateTotal(); }
    public function updatedDrugFee() { $this->calculateTotal(); }
    public function updatedOtherFees() { $this->calculateTotal(); }

    private function estimateDrugPrice($drugName): float
    {
        $prices = [
            'paracetamol' => 5000,
            'amoxicillin' => 15000,
            'ibuprofen' => 10000,
            'omeprazole' => 12000,
        ];

        $drugKey = strtolower(explode(' ', $drugName)[0]);
        return $prices[$drugKey] ?? 10000;
    }

    public function generateInvoice()
    {
        $invoiceNumber = 'INV-' . date('Ymd') . '-' . strtoupper(Str::random(6));

        $invoice = Invoice::updateOrCreate(
            ['appointment_id' => $this->appointment->id],
            [
                'patient_id' => $this->appointment->patient_id,
                'invoice_number' => $invoiceNumber,
                'consultation_fee' => $this->consultationFee,
                'action_fee' => $this->actionFee,
                'drug_fee' => $this->drugFee,
                'other_fees' => $this->otherFees,
                'total' => $this->total,
                'status' => 'unpaid',
            ]
        );

        $this->dispatch('invoiceGenerated', invoiceId: $invoice->id);
    }

    public function markPaid($invoiceId)
    {
        Invoice::findOrFail($invoiceId)->update([
            'status' => 'paid',
            'paid_at' => now(),
        ]);

        $this->dispatch('invoicePaid');
    }

    public function render()
    {
        return view('livewire.billing-form');
    }
}
```

## Cara Integrasi & Pengujian
- Buka appointment yang sudah completed
- Biaya konsultasi terisi otomatis dari data dokter
- Biaya obat terisi dari estimasi harga obat di resep
- Atur biaya tindakan dan lainnya
- Klik "Generate Invoice" -> invoice tersimpan
- Ringkasan menampilkan total
- Klik "Bayar" -> status berubah "paid"
- Verifikasi data di tabel invoices
- Cek invoice_number unik
