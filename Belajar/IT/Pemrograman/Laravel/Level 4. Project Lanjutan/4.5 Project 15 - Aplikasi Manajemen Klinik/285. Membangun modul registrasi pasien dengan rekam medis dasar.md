# 285. Membangun Modul Registrasi Pasien dengan Rekam Medis Dasar

## Definisi & Target
Membangun modul registrasi pasien baru dan manajemen data pasien. Setiap pasien memiliki rekam medis dasar yang mencatat informasi pribadi, kontak, dan riwayat medis awal.

## Komponen yang Terlibat
- Livewire Component: `PatientRegistration`
- Model: Patient

## Perintah Artisan CLI
- `php artisan make:livewire PatientRegistration`

## Kode Implementasi (Per File)

**app/Livewire/PatientRegistration.php:**
```php
class PatientRegistration extends Component
{
    public $name;
    public $nik;
    public $phone;
    public $address;
    public $birthDate;
    public $gender = 'male';
    public $bloodType;
    public $searchNik = '';
    public $searchResult = null;

    protected $rules = [
        'name' => 'required|string|max:255',
        'nik' => 'required|string|size:16|unique:patients,nik',
        'phone' => 'required|string|max:20',
        'address' => 'nullable|string',
        'birthDate' => 'required|date',
        'gender' => 'required|in:male,female',
        'bloodType' => 'nullable|in:A,B,AB,O',
    ];

    public function searchPatient()
    {
        if (strlen($this->searchNik) >= 10) {
            $this->searchResult = Patient::where('nik', 'like', "%{$this->searchNik}%")->first();
        }
    }

    public function register()
    {
        $this->validate();

        $patient = Patient::create([
            'name' => $this->name,
            'nik' => $this->nik,
            'phone' => $this->phone,
            'address' => $this->address,
            'birth_date' => $this->birthDate,
            'gender' => $this->gender,
            'blood_type' => $this->bloodType,
        ]);

        $this->dispatch('patientRegistered', patientId: $patient->id);
    }

    public function render()
    {
        return view('livewire.patient-registration');
    }
}
```

## Cara Integrasi & Pengujian
- Akses halaman registrasi pasien
- Isi data pasien baru (nama, NIK 16 digit, dll)
- Submit -> pasien tersimpan di database
- Cari pasien yang sudah ada berdasarkan NIK
- Verifikasi unique constraint NIK
- Data pasien muncul di daftar pasien
- Validasi field required dan format NIK
