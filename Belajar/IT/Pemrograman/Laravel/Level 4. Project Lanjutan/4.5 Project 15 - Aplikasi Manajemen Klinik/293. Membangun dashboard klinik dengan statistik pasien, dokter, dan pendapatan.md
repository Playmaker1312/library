# 293. Membangun Dashboard Klinik dengan Statistik Pasien, Dokter, dan Pendapatan

## Definisi & Target
Membangun dashboard utama klinik yang menampilkan statistik real-time: jumlah pasien hari ini, dokter aktif, appointment hari ini, pendapatan hari ini, dan antrian saat ini.

## Komponen yang Terlibat
- Livewire Component: `ClinicDashboard`

## Perintah Artisan CLI
- `php artisan make:livewire ClinicDashboard`

## Kode Implementasi (Per File)

**app/Livewire/ClinicDashboard.php:**
```php
class ClinicDashboard extends Component
{
    public $stats = [];
    public $todayAppointments = [];
    public $currentQueue = [];
    public $topDoctors = [];
    public $weeklyVisits = [];

    public function mount()
    {
        $this->loadStats();
    }

    public function loadStats()
    {
        $today = now()->format('Y-m-d');
        $thisMonth = now()->format('Y-m');

        $this->stats = [
            'total_patients' => Patient::count(),
            'total_doctors' => Doctor::where('is_active', true)->count(),
            'today_appointments' => Appointment::whereDate('appointment_date', $today)->count(),
            'today_completed' => Appointment::whereDate('appointment_date', $today)->where('status', 'completed')->count(),
            'today_revenue' => Invoice::whereDate('paid_at', $today)->where('status', 'paid')->sum('total'),
            'monthly_revenue' => Invoice::whereMonth('paid_at', now()->month)->whereYear('paid_at', now()->year)->where('status', 'paid')->sum('total'),
            'pending_queue' => Queue::whereDate('created_at', $today)->where('status', 'waiting')->count(),
            'in_consultation' => Queue::whereDate('created_at', $today)->where('status', 'called')->count(),
        ];

        $this->todayAppointments = Appointment::with('patient', 'doctor')
            ->whereDate('appointment_date', $today)
            ->orderBy('time_slot')
            ->take(8)
            ->get()
            ->toArray();

        $this->currentQueue = Queue::with('appointment.patient', 'appointment.doctor')
            ->whereDate('created_at', $today)
            ->whereIn('status', ['waiting', 'called'])
            ->orderBy('queue_number')
            ->take(5)
            ->get()
            ->toArray();

        $this->topDoctors = Doctor::withCount(['appointments' => fn($q) => $q->where('status', 'completed')])
            ->orderByDesc('appointments_count')
            ->take(5)
            ->get()
            ->toArray();

        $this->weeklyVisits = Appointment::selectRaw('DAYNAME(appointment_date) as day, COUNT(*) as total')
            ->whereBetween('appointment_date', [now()->startOfWeek(), now()->endOfWeek()])
            ->groupBy('day')
            ->orderBy('appointment_date')
            ->get()
            ->toArray();
    }

    public function render()
    {
        return view('livewire.clinic-dashboard');
    }
}
```
