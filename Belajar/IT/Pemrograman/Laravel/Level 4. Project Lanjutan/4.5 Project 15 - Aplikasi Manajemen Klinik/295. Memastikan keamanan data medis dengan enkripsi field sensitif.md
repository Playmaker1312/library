# 295. Memastikan Keamanan Data Medis dengan Enkripsi Field Sensitif

## Definisi & Target
Mengimplementasikan enkripsi data sensitif pada field tertentu di database (diagnosis, anamnesis, catatan medis) menggunakan Laravel's built-in encryption atau library seperti Laravel Ciphersweet.

## Komponen yang Terlibat
- Laravel Eloquent Encryption (cast)
- Model: MedicalRecord, Patient

## Perintah Artisan CLI
- Tidak ada perintah khusus (menggunakan fitur bawaan Laravel)

**app/Casts/EncryptedString.php:**
```php
class EncryptedString implements CastsAttributes
{
    public function get(Model $model, string $key, mixed $value, array $attributes): ?string
    {
        if ($value === null) return null;

        try {
            return decrypt($value);
        } catch (\Exception $e) {
            return $value;
        }
    }

    public function set(Model $model, string $key, mixed $value, array $attributes): ?string
    {
        if ($value === null) return null;

        return encrypt($value);
    }
}
```

```php
class EncryptedJson implements CastsAttributes
{
    public function get(Model $model, string $key, mixed $value, array $attributes): ?array
    {
        if ($value === null) return null;

        try {
            return json_decode(decrypt($value), true);
        } catch (\Exception $e) {
            return null;
        }
    }

    public function set(Model $model, string $key, mixed $value, array $attributes): ?string
    {
        if ($value === null) return null;

        return encrypt(json_encode($value));
    }
}
```

**app/Models/MedicalRecord.php (encrypted fields):**
```php
class MedicalRecord extends Model
{
    use HasFactory;

    protected $fillable = ['patient_id', 'doctor_id', 'appointment_id', 'anamnesis', 'diagnosis', 'therapy', 'notes'];

    protected $casts = [
        'anamnesis' => EncryptedString::class,
        'diagnosis' => EncryptedString::class,
        'therapy' => EncryptedString::class,
        'notes' => EncryptedString::class,
    ];

    protected $appends = ['diagnosis_preview'];

    public function getDiagnosisPreviewAttribute(): string
    {
        $diagnosis = $this->diagnosis;
        return $diagnosis ? substr($diagnosis, 0, 50) . '...' : 'Tidak ada diagnosa';
    }

    public function patient(): BelongsTo
    {
        return $this->belongsTo(Patient::class);
    }

    public function doctor(): BelongsTo
    {
        return $this->belongsTo(Doctor::class);
    }
}
```

**app/Models/Patient.php (encrypted sensitive fields):**
```php
class Patient extends Model
{
    use HasFactory;

    protected $fillable = ['user_id', 'name', 'nik', 'phone', 'address', 'birth_date', 'gender', 'blood_type'];

    protected $casts = [
        'nik' => EncryptedString::class,
        'phone' => EncryptedString::class,
        'address' => EncryptedString::class,
        'birth_date' => 'date',
    ];

    protected $appends = ['nik_masked'];

    public function getNikMaskedAttribute(): string
    {
        $nik = $this->nik;
        if ($nik && strlen($nik) >= 16) {
            return substr($nik, 0, 4) . str_repeat('*', 8) . substr($nik, -4);
        }
        return '****';
    }

    public function scopeSearchByNik(Builder $query, string $nik): Builder
    {
        return $query->whereRaw('CONVERT(AES_DECRYPT(UNHEX(nik), ?) USING utf8mb4) LIKE ?', [
            config('app.key'), "%{$nik}%"
        ]);
    }
}
```

**app/Providers/AppServiceProvider.php (query encryption helper):**

```php
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Str;

public function boot(): void
{
    DB::statement("CREATE FUNCTION IF NOT EXISTS AES_DECRYPT_MY(ciphertext TEXT, key_str TEXT) RETURNS TEXT DETERMINISTIC BEGIN RETURN CAST(AES_DECRYPT(UNHEX(ciphertext), key_str) AS CHAR); END");
}
```

**Middleware/EncryptMedicalData.php:**

```php
class EncryptMedicalData
{
    public function handle(Request $request, Closure $next): Response
    {
        $response = $next($request);

        // Ensure HTTPS in production
        if (app()->environment('production') && !$request->secure()) {
            return redirect()->secure($request->getRequestUri());
        }

        return $response;
    }
}
```

**Security checks pada MedicalRecordController:**
```php
public function show(MedicalRecord $medicalRecord)
{
    // Only the doctor who created it or admin can view
    if ($medicalRecord->doctor_id !== auth()->user()->doctor?->id && !auth()->user()->isAdmin()) {
        abort(403, 'Unauthorized access to medical record');
    }

    $this->logAccess('view', $medicalRecord);

    return view('medical-records.show', compact('medicalRecord'));
}
```

## Cara Integrasi & Pengujian
- Set APP_KEY di .env dengan key yang benar
- Simpan data rekam medis -> data terenkripsi di database
- Cek langsung di database: field diagnosis akan terlihat sebagai ciphertext
- Baca data melalui Eloquent -> otomatis di-decrypt
- Tes dengan user yang tidak berhak -> 403
- NIK pasien termasking di UI (contoh: 1234********5678)
- Verifikasi HTTPS di production
- Log akses tercatat
- Backup APP_KEY: jika hilang, data tidak bisa di-decrypt
- Uji performance: decrypt hanya terjadi saat akses, tidak mempengaruhi query
