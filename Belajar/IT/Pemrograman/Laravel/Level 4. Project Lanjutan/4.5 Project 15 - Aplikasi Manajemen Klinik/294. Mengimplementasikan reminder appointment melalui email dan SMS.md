# 294. Mengimplementasikan Reminder Appointment melalui Email dan SMS

## Definisi & Target
Membangun sistem reminder appointment yang mengirim pengingat ke pasien melalui email dan SMS (menggunakan notifikasi Laravel) sebelum jadwal appointment.

## Komponen yang Terlibat
- Notification: `AppointmentReminder`
- Command: `appointment:send-reminders`
- Task Scheduling

## Perintah Artisan CLI
- `php artisan make:notification AppointmentReminder`
- `php artisan make:command SendAppointmentReminders`

## Kode Implementasi (Per File)

**app/Notifications/AppointmentReminder.php:**
```php
class AppointmentReminder extends Notification
{
    use Queueable;

    public function __construct(public Appointment $appointment) {}

    public function via($notifiable): array
    {
        $channels = ['mail'];

        if ($notifiable->phone) {
            $channels[] = 'nexmo';
        }

        return $channels;
    }

    public function toMail($notifiable): MailMessage
    {
        $appointment = $this->appointment;

        return (new MailMessage)
            ->subject('Pengingat Appointment - Klinik Sehat')
            ->greeting('Halo ' . $notifiable->name . '!')
            ->line('Ini adalah pengingat untuk appointment Anda.')
            ->line('Dokter: dr. ' . $appointment->doctor->name)
            ->line('Tanggal: ' . $appointment->appointment_date->format('d F Y'))
            ->line('Jam: ' . \Carbon\Carbon::parse($appointment->time_slot)->format('H:i'))
            ->line('Jangan lupa datang tepat waktu dan membawa dokumen yang diperlukan.')
            ->action('Lihat Appointment', url('/appointments/' . $appointment->id))
            ->line('Terima kasih.');
    }

    public function toNexmo($notifiable): NexmoMessage
    {
        return (new NexmoMessage)
            ->content('Pengingat: Appointment Anda dengan dr. ' . $this->appointment->doctor->name . ' pada ' . $this->appointment->appointment_date->format('d/m/Y') . ' pukul ' . \Carbon\Carbon::parse($this->appointment->time_slot)->format('H:i') . '. - Klinik Sehat');
    }

    public function toArray($notifiable): array
    {
        return [
            'appointment_id' => $this->appointment->id,
            'message' => 'Pengingat appointment: ' . $this->appointment->appointment_date->format('d/m/Y'),
        ];
    }
}
```

**app/Console/Commands/SendAppointmentReminders.php:**
```php
class SendAppointmentReminders extends Command
{
    protected $signature = 'appointment:send-reminders';
    protected $description = 'Send appointment reminders for tomorrow appointments';

    public function handle()
    {
        $tomorrow = now()->addDay()->format('Y-m-d');

        $appointments = Appointment::with('patient.user')
            ->whereDate('appointment_date', $tomorrow)
            ->where('status', 'scheduled')
            ->get();

        $this->info('Found ' . $appointments->count() . ' appointments for tomorrow');

        foreach ($appointments as $appointment) {
            if ($appointment->patient && $appointment->patient->user) {
                $appointment->patient->user->notify(new AppointmentReminder($appointment));
                $this->line('Reminder sent to: ' . $appointment->patient->name);
            }
        }

        $this->info('All reminders sent successfully');
    }
}
```

**app/Console/Commands/SendHourlyReminders.php:**
```php
class SendHourlyReminders extends Command
{
    protected $signature = 'appointment:send-hourly-reminders';
    protected $description = 'Send reminders for appointments in the next 2 hours';

    public function handle()
    {
        $now = now();
        $twoHoursLater = now()->addHours(2);

        $appointments = Appointment::with('patient.user')
            ->whereDate('appointment_date', $now->format('Y-m-d'))
            ->whereBetween('time_slot', [$now->format('H:i'), $twoHoursLater->format('H:i')])
            ->where('status', 'scheduled')
            ->whereDoesntHave('notifications', function ($q) {
                $q->where('type', AppointmentReminder::class)
                  ->whereDate('created_at', today());
            })
            ->get();

        foreach ($appointments as $appointment) {
            if ($appointment->patient && $appointment->patient->user) {
                $appointment->patient->user->notify(new AppointmentReminder($appointment));
            }
        }

        $this->info('Sent ' . $appointments->count() . ' hourly reminders');
    }
}
```

**app/Console/Kernel.php (scheduling):**
```php
protected function schedule(Schedule $schedule): void
{
    $schedule->command('appointment:send-reminders')->dailyAt('20:00');
    $schedule->command('appointment:send-hourly-reminders')->hourly();
}
```

**app/Livewire/AppointmentList.php (manual reminder):**
```php
public function sendReminder($appointmentId)
{
    $appointment = Appointment::with('patient.user')->findOrFail($appointmentId);

    if ($appointment->patient && $appointment->patient->user) {
        $appointment->patient->user->notify(new AppointmentReminder($appointment));
        $this->dispatch('reminderSent');
    }
}
```

## Cara Integrasi & Pengujian
- Buat appointment untuk besok
- Jalankan `php artisan appointment:send-reminders`
- Verifikasi email reminder terkirim
- Cek notifikasi di tabel notifications
- Atur jadwal di Kernel.php untuk otomatis harian
- Uji hourly reminder untuk appointment dalam 2 jam
- Pastikan tidak ada duplikasi reminder (cek sudah terkirim)
- Konfigurasi Nexmo/Vonage untuk SMS (opsional)
- Fitur "Kirim Reminder" manual dari halaman appointment
