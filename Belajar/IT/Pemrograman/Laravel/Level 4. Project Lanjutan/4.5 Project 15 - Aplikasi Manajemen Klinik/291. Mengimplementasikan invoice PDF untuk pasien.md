# 291. Mengimplementasikan Invoice PDF untuk Pasien

## Definisi & Target
Membangun fitur cetak invoice/nota dalam format PDF yang diberikan kepada pasien setelah pembayaran. Invoice menampilkan rincian biaya, identitas klinik, dan informasi pasien.

## Komponen yang Terlibat
- Controller: `InvoiceController`
- Library: barryvdh/laravel-dompdf

## Perintah Artisan CLI
- `php artisan make:controller InvoiceController`

## Kode Implementasi (Per File)

**routes/web.php:**
```php
Route::get('/invoices/{invoice}/pdf', [InvoiceController::class, 'pdf'])->name('invoices.pdf');
Route::get('/invoices/{invoice}', [InvoiceController::class, 'show'])->name('invoices.show');
```

**app/Http/Controllers/InvoiceController.php:**
```php
class InvoiceController extends Controller
{
    public function show(Invoice $invoice)
    {
        $invoice->load('patient', 'appointment.doctor');
        return view('invoices.show', compact('invoice'));
    }

    public function pdf(Invoice $invoice)
    {
        $invoice->load('patient', 'appointment.doctor');

        $pdf = Pdf::loadView('invoices.pdf', compact('invoice'));
        $pdf->setPaper('A4');

        $filename = 'invoice-' . $invoice->invoice_number . '.pdf';

        return $pdf->download($filename);
    }
}
```

## Cara Integrasi & Pengujian

- Akses route `/invoices/{id}` untuk preview HTML

- Verifikasi semua informasi: klinik, pasien, dokter, rincian biaya
- Status paid/unpaid tercantum
- Cek format DomPDF dan layout
- Tanda tangan: pasien, dokter, admin
- Nomor invoice unik
