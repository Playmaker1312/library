# 289. Mengimplementasikan Resep Digital dengan Daftar Obat dan Dosis

## Definisi & Target
Membangun fitur resep digital yang terintegrasi dengan rekam medis. Dokter dapat menambahkan obat, dosis, jumlah, dan aturan pakai.

## Komponen yang Terlibat
- Livewire Component: `PrescriptionForm`
- Model: Prescription, PrescriptionItem

## Perintah Artisan CLI
- `php artisan make:livewire PrescriptionForm`

## Kode Implementasi (Per File)

**app/Livewire/PrescriptionForm.php:**
```php
class PrescriptionForm extends Component
{
    public $medicalRecord;
    public $items = [];
    public $notes;
    public $existingPrescription = null;

    public function mount($medicalRecordId)
    {
        $this->medicalRecord = MedicalRecord::findOrFail($medicalRecordId);

        $this->existingPrescription = Prescription::where('medical_record_id', $medicalRecordId)
            ->with('items')
            ->first();

        if ($this->existingPrescription) {
            $this->items = $this->existingPrescription->items->map(fn($item) => [
                'drug_name' => $item->drug_name,
                'dosage' => $item->dosage,
                'quantity' => $item->quantity,
                'unit' => $item->unit,
                'notes' => $item->notes,
            ])->toArray();

            $this->notes = $this->existingPrescription->notes;
        }
    }

    public function addItem()
    {
        $this->items[] = ['drug_name' => '', 'dosage' => '', 'quantity' => 1, 'unit' => 'tablet', 'notes' => ''];
    }

    public function removeItem($index)
    {
        unset($this->items[$index]);
        $this->items = array_values($this->items);
    }

    public function save()
    {
        $this->validate([
            'items' => 'required|array|min:1',
            'items.*.drug_name' => 'required|string',
            'items.*.dosage' => 'required|string',
            'items.*.quantity' => 'required|integer|min:1',
            'items.*.unit' => 'required|string',
            'notes' => 'nullable|string',
        ]);

        DB::transaction(function () {
            $prescription = Prescription::updateOrCreate(
                ['medical_record_id' => $this->medicalRecord->id],
                ['notes' => $this->notes]
            );

            $prescription->items()->delete();

            foreach ($this->items as $item) {
                PrescriptionItem::create([
                    'prescription_id' => $prescription->id,
                    'drug_name' => $item['drug_name'],
                    'dosage' => $item['dosage'],
                    'quantity' => $item['quantity'],
                    'unit' => $item['unit'],
                    'notes' => $item['notes'],
                ]);
            }
        });

        $this->dispatch('prescriptionSaved');
    }

    public function render()
    {
        return view('livewire.prescription-form');
    }
}
```

## Cara Integrasi & Pengujian
- Buka rekam medis yang sudah disimpan
- Tambah item obat dengan nama, dosis, quantity, unit
- Tambah beberapa obat
- Hapus obat dari daftar
- Simpan resep -> data tersimpan di prescriptions dan prescription_items
- Edit resep yang sudah ada (items di-delete dan di-recreate)
- Verifikasi data muncul di print resep atau invoice
- Cek relasi dengan medical record
