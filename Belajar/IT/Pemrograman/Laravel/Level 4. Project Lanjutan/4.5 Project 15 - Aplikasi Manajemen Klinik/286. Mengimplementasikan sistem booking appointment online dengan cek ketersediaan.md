# 286. Mengimplementasikan Sistem Booking Appointment Online dengan Cek Ketersediaan

## Definisi & Target
Membangun sistem booking appointment online di mana pasien dapat memilih dokter, melihat jadwal tersedia, dan memilih slot waktu. Sistem mencegah double booking.

## Komponen yang Terlibat
- Livewire Component: `AppointmentBooking`
- Model: Appointment, Doctor

## Perintah Artisan CLI
- `php artisan make:livewire AppointmentBooking`

## Kode Implementasi (Per File)

**app/Livewire/AppointmentBooking.php:**
```php
class AppointmentBooking extends Component
{
    public $selectedDoctorId = null;
    public $selectedDate = null;
    public $selectedTime = null;
    public $complaint = '';
    public $patientId;
    public $availableTimes = [];
    public $doctorSchedule = [];

    public function mount($patientId = null)
    {
        $this->patientId = $patientId ?? auth()->user()->patient->id ?? null;
        $this->selectedDate = now()->format('Y-m-d');
    }

    public function updatedSelectedDoctorId()
    {
        $this->selectedTime = null;
        $this->availableTimes = [];
        $this->loadSchedule();
    }

    public function updatedSelectedDate()
    {
        $this->selectedTime = null;
        $this->availableTimes = [];
        $this->loadSchedule();
    }

    public function loadSchedule()
    {
        if (!$this->selectedDoctorId || !$this->selectedDate) return;

        $doctor = Doctor::find($this->selectedDoctorId);
        $schedule = $doctor->schedule ?? [];
        $dayName = \Carbon\Carbon::parse($this->selectedDate)->locale('id')->dayName;

        $daySchedule = collect($schedule)->firstWhere('day', $dayName);

        if (!$daySchedule || !$daySchedule['active']) {
            $this->availableTimes = [];
            return;
        }

        $bookedTimes = Appointment::where('doctor_id', $this->selectedDoctorId)
            ->where('appointment_date', $this->selectedDate)
            ->whereNotIn('status', ['cancelled'])
            ->pluck('time_slot')
            ->map(fn($t) => \Carbon\Carbon::parse($t)->format('H:i'))
            ->toArray();

        $start = \Carbon\Carbon::parse($daySchedule['start']);
        $end = \Carbon\Carbon::parse($daySchedule['end']);
        $slots = [];

        while ($start < $end) {
            $timeStr = $start->format('H:i');
            if (!in_array($timeStr, $bookedTimes)) {
                $slots[] = $timeStr;
            }
            $start->addMinutes(30);
        }

        $this->availableTimes = $slots;
    }

    public function book()
    {
        $this->validate([
            'selectedDoctorId' => 'required|exists:doctors,id',
            'selectedDate' => 'required|date|after_or_equal:today',
            'selectedTime' => 'required',
            'complaint' => 'required|min:10',
        ]);

        if (!$this->patientId) {
            $this->addError('patient', 'Silakan registrasi sebagai pasien terlebih dahulu');
            return;
        }

        $exists = Appointment::where('doctor_id', $this->selectedDoctorId)
            ->where('appointment_date', $this->selectedDate)
            ->where('time_slot', $this->selectedTime)
            ->whereNot('status', 'cancelled')
            ->exists();

        if ($exists) {
            $this->addError('selectedTime', 'Slot waktu ini sudah dibooking');
            return;
        }

        Appointment::create([
            'doctor_id' => $this->selectedDoctorId,
            'patient_id' => $this->patientId,
            'appointment_date' => $this->selectedDate,
            'time_slot' => $this->selectedTime,
            'status' => 'scheduled',
            'complaint' => $this->complaint,
        ]);

        $this->dispatch('appointmentBooked');
    }

    public function render()
    {
        $doctors = Doctor::where('is_active', true)->get();
        return view('livewire.appointment-booking', compact('doctors'));
    }
}
```

**resources/views/livewire/appointment-booking.blade.php:**
```html
<div class="max-w-3xl mx-auto p-6">
    <h1 class="text-2xl font-bold mb-6">Booking Appointment</h1>

                <select wire:model.live="selectedDoctorId" class="w-full border rounded p-2">
                    <option value="">Pilih Dokter</option>

                    </option>

                </select>

                <label class="block text-sm font-medium mb-1">Tanggal</label>
                <input type="date" wire:model.live="selectedDate" class="w-full border rounded p-2" min="{{ now()->format('Y-m-d') }}">
            </div>
        </div>

        @if($selectedDoctorId && $selectedDate)
        <div class="mb-4">
            <label class="block text-sm font-medium mb-2">Pilih Waktu</label>
            @if(count($availableTimes) > 0)
            <div class="grid grid-cols-4 gap-2">
                @foreach($availableTimes as $time)
                <button wire:click="$set('selectedTime', '{{ $time }}')"

            @endif
        </div>

            <label class="block text-sm font-medium mb-1">Keluhan</label>
            <textarea wire:model="complaint" class="w-full border rounded p-2" rows="3"

            @error('complaint') <span class="text-red-500 text-sm">{{ $message }}</span> @enderror
        </div>

        <button wire:click="book" wire:loading.attr="disabled"
                class="bg-blue-600 text-white px-6 py-2 rounded font-bold hover:bg-blue-700 disabled:opacity-50"
                @if(!$selectedTime) disabled @endif>
            <span wire:loading.remove>Konfirmasi Booking</span>
            <span wire:loading>Memproses...</span>
        </button>
        @endif

```

## Cara Integrasi & Pengujian
- Pilih dokter -> jadwal muncul
- Pilih tanggal -> slot waktu tersedia tampil
- Slot yang sudah dibooking tidak muncul
- Pilih waktu, isi keluhan, konfirmasi
- Verifikasi appointment tersimpan di database
- Coba booking slot yang sama -> error double booking
- Dokter libur (jadwal tidak aktif) -> tidak ada slot
- Cek riwayat appointment pasien
