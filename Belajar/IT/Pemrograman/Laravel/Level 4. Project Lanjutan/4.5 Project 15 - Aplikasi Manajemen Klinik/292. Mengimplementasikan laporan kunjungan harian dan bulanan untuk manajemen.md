# 292. Mengimplementasikan Laporan Kunjungan Harian dan Bulanan untuk Manajemen

## Definisi & Target
Membangun laporan kunjungan pasien harian dan bulanan yang menampilkan jumlah pasien, dokter, pendapatan, dan grafik tren kunjungan.

## Komponen yang Terlibat
- Controller: `ClinicReportController`
- Model: Appointment, Invoice

## Perintah Artisan CLI
- `php artisan make:controller ClinicReportController`

**app/Http/Controllers/ClinicReportController.php:**
```php
class ClinicReportController extends Controller
{
    public function index()
    {
        return view('reports.clinic');
    }

    public function data(Request $request)
    {
        $period = $request->get('period', 'daily');
        $startDate = $request->get('start_date', now()->startOfMonth()->format('Y-m-d'));
        $endDate = $request->get('end_date', now()->format('Y-m-d'));

        $appointments = Appointment::whereBetween('appointment_date', [$startDate, $endDate]);

        $invoices = Invoice::whereBetween('created_at', [$startDate, $endDate . ' 23:59:59']);

        switch ($period) {
            case 'daily':
                $visits = (clone $appointments)
                    ->selectRaw('appointment_date as date, COUNT(*) as total, SUM(CASE WHEN status = "completed" THEN 1 ELSE 0 END) as completed')
                    ->groupBy('appointment_date')->orderBy('appointment_date')->get();

                $revenue = (clone $invoices)
                    ->selectRaw('DATE(created_at) as date, SUM(total) as total, COUNT(*) as count')
                    ->where('status', 'paid')
                    ->groupBy('date')->orderBy('date')->get();
                break;

            case 'monthly':
                $visits = (clone $appointments)
                    ->selectRaw('DATE_FORMAT(appointment_date, "%Y-%m") as month, COUNT(*) as total')
                    ->groupBy('month')->orderBy('month')->get();

                $revenue = (clone $invoices)
                    ->selectRaw('DATE_FORMAT(created_at, "%Y-%m") as month, SUM(total) as total, COUNT(*) as count')
                    ->where('status', 'paid')
                    ->groupBy('month')->orderBy('month')->get();
                break;
        }

        $summary = [
            'total_visits' => (clone $appointments)->count(),
            'completed_visits' => (clone $appointments)->where('status', 'completed')->count(),
            'cancelled_visits' => (clone $appointments)->where('status', 'cancelled')->count(),
            'total_revenue' => (clone $invoices)->where('status', 'paid')->sum('total'),
            'total_invoices' => (clone $invoices)->count(),
            'paid_invoices' => (clone $invoices)->where('status', 'paid')->count(),
            'avg_revenue_per_day' => 0,
        ];

        $daysDiff = max(1, \Carbon\Carbon::parse($startDate)->diffInDays($endDate) + 1);
        $summary['avg_revenue_per_day'] = $summary['total_revenue'] / $daysDiff;

        return response()->json(compact('visits', 'revenue', 'summary'));
    }
}
```

        let visitChartInstance = null, revenueChartInstance = null;

        document.addEventListener('DOMContentLoaded', function() {
            const today = new Date().toISOString().split('T')[0];

                        </tr>
                    `).join('');
                });
