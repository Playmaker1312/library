# 284. Membangun Modul Manajemen Dokter dengan Jadwal Praktik dan Spesialisasi

## Definisi & Target
Membangun modul CRUD untuk data dokter yang mencakup informasi pribadi, spesialisasi, nomor izin praktik, dan jadwal praktik (hari dan jam).

## Komponen yang Terlibat
- Controller: `DoctorController`
- Model: Doctor
- View: doctor management

## Perintah Artisan CLI
- `php artisan make:controller DoctorController --resource`

## Kode Implementasi (Per File)

**routes/web.php:**
```php
Route::resource('doctors', DoctorController::class)->middleware('auth');
Route::get('/doctors/{doctor}/schedule', [DoctorController::class, 'schedule'])->name('doctors.schedule');
Route::post('/doctors/{doctor}/schedule', [DoctorController::class, 'updateSchedule']);
```

**app/Http/Controllers/DoctorController.php:**
```php
class DoctorController extends Controller
{
    public function index()
    {
        $doctors = Doctor::withCount('appointments')
            ->when(request('search'), fn($q) => $q->where('name', 'like', '%' . request('search') . '%')
                ->orWhere('specialist', 'like', '%' . request('search') . '%'))
            ->when(request('specialist'), fn($q) => $q->where('specialist', request('specialist')))
            ->paginate(10);

        $specialists = Doctor::select('specialist')->distinct()->pluck('specialist');

        return view('doctors.index', compact('doctors', 'specialists'));
    }

    public function create()
    {
        return view('doctors.create');
    }

    public function store(DoctorRequest $request)
    {
        Doctor::create($request->validated());

        return redirect()->route('doctors.index')->with('success', 'Dokter berhasil ditambahkan');
    }

    public function show(Doctor $doctor)
    {
        $doctor->load(['appointments' => fn($q) => $q->with('patient')->latest()->take(10)]);
        return view('doctors.show', compact('doctor'));
    }

    public function edit(Doctor $doctor)
    {
        return view('doctors.edit', compact('doctor'));
    }

    public function update(DoctorRequest $request, Doctor $doctor)
    {
        $doctor->update($request->validated());

        return redirect()->route('doctors.index')->with('success', 'Dokter berhasil diupdate');
    }

    public function schedule(Doctor $doctor)
    {
        $schedule = $doctor->schedule ?? $this->defaultSchedule();
        return view('doctors.schedule', compact('doctor', 'schedule'));
    }

    public function updateSchedule(Request $request, Doctor $doctor)
    {
        $validated = $request->validate([
            'schedule' => 'required|array',
            'schedule.*.day' => 'required|string',
            'schedule.*.start' => 'required|date_format:H:i',
            'schedule.*.end' => 'required|date_format:H:i|after:schedule.*.start',
            'schedule.*.active' => 'boolean',
        ]);

        $doctor->update(['schedule' => $validated['schedule']]);

        return redirect()->route('doctors.index')->with('success', 'Jadwal dokter berhasil diupdate');
    }

    private function defaultSchedule(): array
    {
        $days = ['Senin', 'Selasa', 'Rabu', 'Kamis', 'Jumat', 'Sabtu'];
        return collect($days)->map(fn($day) => [
            'day' => $day,
            'start' => '08:00',
            'end' => '16:00',
            'active' => $day !== 'Sabtu',
        ])->toArray();
    }
}
```

## Cara Integrasi & Pengujian
- Tambah dokter dengan spesialisasi dan fee konsultasi
- Atur jadwal praktik per hari (aktif/tidak, jam mulai-selesai)
- Verifikasi jadwal tersimpan sebagai JSON di database
- Filter dokter berdasarkan spesialisasi
- Nonaktifkan dokter (is_active = false)
- Cek daftar appointment per dokter di halaman detail
