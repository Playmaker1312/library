# 287. Mengimplementasikan Sistem Antrian Digital dengan Nomor Antrian

## Definisi & Target
Membangun sistem antrian digital di mana pasien yang sudah check-in mendapat nomor antrian. Nomor di-generate otomatis berdasarkan dokter dan urutan kedatangan.

## Komponen yang Terlibat
- Livewire Component: `QueueSystem`
- Model: Queue, Appointment

## Perintah Artisan CLI
- `php artisan make:livewire QueueSystem`

## Kode Implementasi (Per File)

**app/Livewire/QueueSystem.php:**
```php
class QueueSystem extends Component
{
    public $currentQueue = [];
    public $callingNow = null;
    public $doctorFilter = 'all';

    public function mount()
    {
        $this->loadQueue();
    }

    public function checkIn($appointmentId)
    {
        $appointment = Appointment::findOrFail($appointmentId);

        $lastQueue = Queue::where('appointment_id', $appointmentId)->first();

        if ($lastQueue) {
            return;
        }

        $todayQueueNumber = Queue::whereDate('created_at', today())
            ->whereHas('appointment', fn($q) => $q->where('doctor_id', $appointment->doctor_id))
            ->max('queue_number') ?? 0;

        $queue = Queue::create([
            'appointment_id' => $appointment->id,
            'queue_number' => $todayQueueNumber + 1,
            'status' => 'waiting',
        ]);

        $appointment->update(['status' => 'checked_in']);

        $this->loadQueue();
        $this->dispatch('queueUpdated');
    }

    public function callNext($doctorId)
    {
        $nextQueue = Queue::whereHas('appointment', fn($q) => $q->where('doctor_id', $doctorId))
            ->where('status', 'waiting')
            ->orderBy('queue_number')
            ->first();

        if ($nextQueue) {
            $nextQueue->update([
                'status' => 'called',
                'called_at' => now(),
            ]);

            $nextQueue->appointment->update(['status' => 'in_consultation']);
            $this->callingNow = $nextQueue;
        }

        $this->loadQueue();
    }

    public function completeConsultation($queueId)
    {
        $queue = Queue::findOrFail($queueId);
        $queue->update(['status' => 'completed']);
        $queue->appointment->update(['status' => 'completed']);

        $this->callingNow = null;
        $this->loadQueue();
    }

    public function skipQueue($queueId)
    {
        $queue = Queue::findOrFail($queueId);
        $queue->update(['status' => 'skipped']);

        $this->loadQueue();
    }

    public function loadQueue()
    {
        $query = Queue::with('appointment.patient', 'appointment.doctor')
            ->whereDate('created_at', today())
            ->whereIn('status', ['waiting', 'called']);

        if ($this->doctorFilter !== 'all') {
            $query->whereHas('appointment', fn($q) => $q->where('doctor_id', $this->doctorFilter));
        }

        $this->currentQueue = $query->orderBy('queue_number')->get()->toArray();
    }

    public function render()
    {
        $doctors = Doctor::where('is_active', true)->get();

        $todaysAppointments = Appointment::with('patient')
            ->whereDate('appointment_date', today())
            ->whereIn('status', ['scheduled', 'checked_in'])
            ->orderBy('time_slot')
            ->get();

        return view('livewire.queue-system', compact('doctors', 'todaysAppointments'));
    }
}
```

## Cara Integrasi & Pengujian
- Appointment hari ini tampil di panel kanan
- Klik "Check In" -> nomor antrian ter-generate (A01, A02...)
- Antrian tampil di kolom "Menunggu"
- Klik "Call Next" -> pasien pindah ke "Sedang Dipanggil"
- Display antrian menampilkan nomor dan nama
- Klik "Selesai" -> antrian selesai
- Filter per dokter
- Nomor antrian reset setiap hari
