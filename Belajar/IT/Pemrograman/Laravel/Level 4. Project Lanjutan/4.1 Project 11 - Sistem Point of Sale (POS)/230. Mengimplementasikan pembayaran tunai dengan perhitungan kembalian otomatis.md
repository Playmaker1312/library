# 230. Mengimplementasikan Pembayaran Tunai dengan Perhitungan Kembalian Otomatis

## Definisi & Target
Membangun fitur pembayaran tunai yang menghitung kembalian secara otomatis berdasarkan jumlah uang yang dibayarkan. Menampilkan indikator visual jika uang kurang atau pas.

## Komponen yang Terlibat
- Livewire Component: `KasirPage`
- Property: `$cashAmount`, `$change`

## Perintah Artisan CLI
- Tidak ada perintah khusus

## Kode Implementasi (Per File)

**app/Livewire/KasirPage.php (cash handling):**
```php
class KasirPage extends Component
{
    public $cashAmount = 0;
    public $change = 0;
    public $cashStatus = 'empty';

    public function updatedCashAmount($value)
    {
        $amount = (int) $value;

        if ($amount <= 0) {
            $this->cashStatus = 'empty';
            $this->change = 0;
        } elseif ($amount < $this->total) {
            $this->cashStatus = 'kurang';
            $this->change = $amount - $this->total;
        } elseif ($amount == $this->total) {
            $this->cashStatus = 'pas';
            $this->change = 0;
        } else {
            $this->cashStatus = 'lebih';
            $this->change = $amount - $this->total;
        }
    }

    public function calculateChange()
    {
        return max(0, $this->cashAmount - $this->total);
    }

    public function quickAmount($amount)
    {
        $this->cashAmount = $amount;
        $this->updatedCashAmount($amount);
    }
}
```

**resources/views/livewire/kasir-page.blade.php (cash section):**
```html
<div x-data="{ showNumpad: false }">
    <label class="block text-sm font-medium mb-1">Jumlah Tunai</label>

    <div class="flex space-x-2 mb-2">
        <button wire:click="quickAmount(50000)" class="px-3 py-1 bg-gray-200 rounded text-sm hover:bg-gray-300">Rp50.000</button>
        <button wire:click="quickAmount(100000)" class="px-3 py-1 bg-gray-200 rounded text-sm hover:bg-gray-300">Rp100.000</button>
        <button wire:click="quickAmount(200000)" class="px-3 py-1 bg-gray-200 rounded text-sm hover:bg-gray-300">Rp200.000</button>
        <button wire:click="quickAmount(500000)" class="px-3 py-1 bg-gray-200 rounded text-sm hover:bg-gray-300">Rp500.000</button>
    </div>

    <input type="number" wire:model.live="cashAmount"
           class="w-full border rounded p-2 text-lg font-bold text-right"
           placeholder="0">

    <div class="mt-2">
        @if($cashStatus === 'kurang')
        <div class="bg-red-100 text-red-700 p-2 rounded text-sm">
            Kurang Rp {{ number_format(abs($change), 0, ',', '.') }}
        </div>
        @elseif($cashStatus === 'pas')
        <div class="bg-green-100 text-green-700 p-2 rounded text-sm">Uang pas</div>
        @elseif($cashStatus === 'lebih')
        <div class="bg-blue-100 text-blue-700 p-2 rounded text-sm">
            Kembalian: Rp {{ number_format($change, 0, ',', '.') }}
        </div>
        @endif
    </div>

    <div class="mt-2 text-center text-sm text-gray-500">
        Total: <span class="font-bold text-lg text-blue-600">Rp {{ number_format($total, 0, ',', '.') }}</span>
    </div>

    <button wire:click="checkout"
            @if($cashStatus === 'kurang' || $cashStatus === 'empty') disabled @endif
            class="w-full mt-3 py-3 rounded-lg font-bold
                   {{ $cashStatus === 'kurang' || $cashStatus === 'empty'
                       ? 'bg-gray-300 text-gray-500 cursor-not-allowed'
                       : 'bg-green-600 text-white hover:bg-green-700' }}">
        Bayar Tunai
    </button>
</div>
```

## Cara Integrasi & Pengujian
- Pilih metode pembayaran tunai
- Klik tombol quick amount untuk memasukkan nominal cepat
- Verifikasi status: kurang (merah), pas (hijau), lebih (biru)
- Verifikasi tombol bayar disabled jika uang kurang
- Pastikan kembalian dihitung dengan benar saat checkout
- Uji skenario uang pas dan uang lebih
