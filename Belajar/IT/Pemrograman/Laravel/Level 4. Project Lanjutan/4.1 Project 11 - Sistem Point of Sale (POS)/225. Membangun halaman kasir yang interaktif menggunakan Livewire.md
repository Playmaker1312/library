# 225. Membangun Halaman Kasir yang Interaktif Menggunakan Livewire

## Definisi & Target
Membangun halaman kasir utama dengan komponen Livewire yang responsif, menampilkan daftar produk, cart, dan area pembayaran dalam satu halaman tanpa reload.

## Komponen yang Terlibat
- Livewire Component: `KasirPage`
- Blade Layout: layout kasir dengan grid produk dan cart
- Alpine.js: interaktivitas client-side untuk UI

## Perintah Artisan CLI
- `php artisan make:livewire KasirPage`

## Kode Implementasi (Per File)

**app/Livewire/KasirPage.php:**
```php
class KasirPage extends Component
{
    public $search = '';
    public $cart = [];
    public $customerName = '';
    public $paymentMethod = 'cash';
    public $cashAmount = 0;
    public $subtotal = 0;
    public $discount = 0;
    public $tax = 0;
    public $total = 0;

    protected $queryString = ['search'];

    public function render()
    {
        $products = Product::active()
            ->search($this->search)
            ->paginate(12);

        return view('livewire.kasir-page', compact('products'))
            ->layout('layouts.pos');
    }
}
```

**resources/views/livewire/kasir-page.blade.php:**
```html
<div class="flex h-screen bg-gray-100">
    <div class="flex-1 p-4 overflow-y-auto">
        <input type="text" wire:model.live.debounce.300ms="search" placeholder="Cari produk..." class="w-full p-3 mb-4 border rounded-lg">
        <div class="grid grid-cols-3 gap-4">
            @foreach($products as $product)
            <div class="bg-white p-4 rounded-lg shadow cursor-pointer" wire:click="addToCart({{ $product->id }})">
                <h3 class="font-bold">{{ $product->name }}</h3>
                <p class="text-green-600">Rp {{ number_format($product->price) }}</p>
                <p class="text-sm text-gray-500">Stok: {{ $product->stock }}</p>
            </div>
            @endforeach
        </div>
        {{ $products->links() }}
    </div>
    <div class="w-96 bg-white shadow-lg p-4">
        <h2 class="text-xl font-bold mb-4">Keranjang</h2>
        <div id="cart-items" class="space-y-2">
            @foreach($cart as $index => $item)
            <div class="flex justify-between items-center p-2 bg-gray-50 rounded">
                <div>
                    <p class="font-semibold">{{ $item['name'] }}</p>
                    <div class="flex items-center space-x-2">
                        <button wire:click="updateQuantity({{ $index }}, 'decrease')">-</button>
                        <span>{{ $item['quantity'] }}</span>
                        <button wire:click="updateQuantity({{ $index }}, 'increase')">+</button>

                </div>
                <div class="text-right">
                    <p>Rp {{ number_format($item['subtotal']) }}</p>

                </div>
            </div>
            @endforeach
        </div>
        <div class="border-t mt-4 pt-4">
            <div class="flex justify-between"><span>Subtotal</span><span>Rp {{ number_format($subtotal) }}</span></div>
            <div class="flex justify-between"><span>Diskon</span><span>Rp {{ number_format($discount) }}</span></div>
            <div class="flex justify-between"><span>Pajak (11%)</span><span>Rp {{ number_format($tax) }}</span></div>
            <div class="flex justify-between text-xl font-bold"><span>Total</span><span>Rp {{ number_format($total) }}</span></div>
        </div>
        <button wire:click="checkout" class="w-full bg-blue-600 text-white py-3 rounded-lg mt-4">Bayar</button>
    </div>
</div>
```

**resources/views/layouts/pos.blade.php:**
```html

<head><title>POS - Kasir</title>@livewireStyles @vite('resources/css/app.css')</head>
<body>
    {{ $slot }}
    @livewireScripts @vite('resources/js/app.js')
</body>
</html>
```

## Cara Integrasi & Pengujian
- Akses route `/kasir` untuk melihat halaman kasir
- Uji pencarian produk dengan mengetik di kolom search
- Klik produk untuk menambah ke keranjang
- Verifikasi perubahan quantity dan perhitungan otomatis
