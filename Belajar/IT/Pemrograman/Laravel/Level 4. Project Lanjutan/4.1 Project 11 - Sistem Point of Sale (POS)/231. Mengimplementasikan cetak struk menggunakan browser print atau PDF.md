# 231. Mengimplementasikan Cetak Struk Menggunakan Browser Print atau PDF

## Definisi & Target
Membangun fitur cetak struk pembelian setelah transaksi berhasil. Struk dapat dicetak langsung ke printer thermal via browser print atau diunduh dalam format PDF.

## Komponen yang Terlibat
- Livewire Component: `KasirPage`
- Controller: `PrintController`
- Blade View: receipt template
- Library: barryvdh/laravel-dompdf

## Perintah Artisan CLI
- `composer require barryvdh/laravel-dompdf`
- `php artisan make:controller PrintController`

## Kode Implementasi (Per File)

**routes/web.php:**
```php
Route::get('/receipt/{transaction}', [PrintController::class, 'receipt'])->name('receipt.print');
Route::get('/receipt/{transaction}/pdf', [PrintController::class, 'pdf'])->name('receipt.pdf');
```

**app/Http/Controllers/PrintController.php:**
```php
class PrintController extends Controller
{
    public function receipt(Transaction $transaction)
    {
        $transaction->load('items.product', 'payment', 'user');
        return view('print.receipt', compact('transaction'));
    }

    public function pdf(Transaction $transaction)
    {
        $transaction->load('items.product', 'payment', 'user');
        $pdf = Pdf::loadView('print.receipt', compact('transaction'));
        $pdf->setPaper([0, 0, 226, 800], 'portrait');
        return $pdf->download('struk-' . $transaction->id . '.pdf');
    }
}
```

**app/Livewire/KasirPage.php (dispatch after checkout):**
```php
$this->dispatch('transactionCreated', transactionId: $transaction->id);
```

**resources/views/livewire/kasir-page.blade.php (script section):**
```html
<script>
    document.addEventListener('livewire:initialized', () => {
        Livewire.on('transactionCreated', (data) => {
            if (confirm('Cetak struk?')) {
                window.open('/receipt/' + data.transactionId, '_blank', 'width=400,height=600');
            }
        });
    });
</script>
```

## Cara Integrasi & Pengujian
- Lakukan transaksi hingga sukses
- Konfirmasi cetak struk saat muncul notifikasi
- Verifikasi tampilan struk sesuai format printer thermal 80mm
- Uji download PDF dengan mengakses route `/receipt/{id}/pdf`
- Pastikan window.print() terpanggil otomatis
