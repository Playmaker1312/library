# 226. Mengimplementasikan Pencarian Produk Real-Time di Halaman Kasir Menggunakan Livewire

## Definisi & Target
Membuat fitur pencarian produk yang merespons ketikan pengguna secara real-time menggunakan `wire:model.live` pada Livewire. Hasil pencarian diperbarui tanpa reload halaman.

## Komponen yang Terlibat
- Livewire Component: `KasirPage`
- Model: Product
- Alpine.js (opsional untuk debounce)

## Perintah Artisan CLI
- Tidak ada perintah khusus

## Kode Implementasi (Per File)

**app/Livewire/KasirPage.php (bagian search):**
```php
class KasirPage extends Component
{
    public $search = '';

    protected $queryString = ['search'];

    public function updatedSearch($value)
    {
        $this->resetPage();
    }

    public function render()
    {
        $products = Product::query()
            ->when($this->search, function ($query) {
                $query->where(function ($q) {
                    $q->where('name', 'like', '%' . $this->search . '%')
                      ->orWhere('sku', 'like', '%' . $this->search . '%')
                      ->orWhere('barcode', 'like', '%' . $this->search . '%');
                });
            })
            ->active()
            ->paginate(12);

        return view('livewire.kasir-page', compact('products'));
    }
}
```

**resources/views/livewire/kasir-page.blade.php (bagian search):**
```html
<div class="relative mb-4">
    <input
        type="text"
        wire:model.live.debounce.300ms="search"
        placeholder="Cari nama produk, SKU, atau barcode..."
        class="w-full p-3 pl-10 border border-gray-300 rounded-lg focus:ring-2 focus:ring-blue-500"
    >
    <svg class="absolute left-3 top-3.5 h-5 w-5 text-gray-400" fill="none" stroke="currentColor" viewBox="0 0 24 24">
        <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M21 21l-6-6m2-5a7 7 0 11-14 0 7 7 0 0114 0z"/>
    </svg>
</div>

<div class="grid grid-cols-3 gap-4" wire:loading.class="opacity-50">
    @forelse($products as $product)
    <div class="bg-white p-4 rounded-lg shadow hover:shadow-md transition cursor-pointer"
         wire:click="addToCart({{ $product->id }})"
         wire:key="product-{{ $product->id }}">
        <img src="{{ $product->image ? Storage::url($product->image) : 'https://via.placeholder.com/150' }}"
             class="w-full h-32 object-cover rounded mb-2">
        <h3 class="font-semibold text-sm">{{ $product->name }}</h3>
        <p class="text-green-600 font-bold">Rp {{ number_format($product->price, 0, ',', '.') }}</p>
        <p class="text-xs text-gray-500">Stok: {{ $product->stock }}</p>
    </div>
    @empty
    <div class="col-span-3 text-center py-10 text-gray-500">Produk tidak ditemukan</div>
    @endforelse
</div>

<div class="mt-4" wire:ignore>
    {{ $products->links() }}
</div>
```

## Cara Integrasi & Pengujian
- Buka halaman kasir dan ketik nama produk
- Pastikan hasil berubah secara real-time tanpa reload
- Uji pencarian dengan SKU dan barcode
- Uji kondisi ketika produk tidak ditemukan
- Verifikasi pagination berfungsi bersamaan dengan pencarian
