# 235. Membangun Dashboard POS dengan Statistik Penjualan Real-Time Menggunakan Livewire Polling

## Definisi & Target
Membangun dashboard utama POS yang menampilkan statistik penjualan secara real-time menggunakan fitur polling Livewire. Data diperbarui otomatis setiap interval tertentu tanpa reload halaman.

## Komponen yang Terlibat
- Livewire Component: `DashboardPos`
- Model: Transaction, Product, TransactionItem
- View: dashboard POS
- Chart.js untuk grafik

## Perintah Artisan CLI
- `php artisan make:livewire DashboardPos`

## Kode Implementasi (Per File)

**app/Livewire/DashboardPos.php:**
```php
class DashboardPos extends Component
{
    public $todaySales = 0;
    public $todayTransactions = 0;
    public $totalProducts = 0;
    public $lowStockProducts = 0;
    public $recentTransactions = [];
    public $hourlySales = [];
    public $topProducts = [];

    public function mount()
    {
        $this->loadData();
    }

    public function loadData()
    {
        $today = now()->format('Y-m-d');

        $this->todaySales = Transaction::whereDate('created_at', $today)
            ->where('payment_status', 'paid')
            ->sum('total');

        $this->todayTransactions = Transaction::whereDate('created_at', $today)
            ->where('payment_status', 'paid')
            ->count();

        $this->totalProducts = Product::count();
        $this->lowStockProducts = Product::where('stock', '<=', 5)->count();

        $this->recentTransactions = Transaction::with('items.product', 'user')
            ->whereDate('created_at', $today)
            ->latest()
            ->take(5)
            ->get()
            ->toArray();

        $this->hourlySales = Transaction::whereDate('created_at', $today)
            ->where('payment_status', 'paid')
            ->selectRaw('HOUR(created_at) as hour, SUM(total) as total, COUNT(*) as count')
            ->groupBy('hour')
            ->orderBy('hour')
            ->get()
            ->toArray();

        $this->topProducts = TransactionItem::selectRaw('product_id, SUM(quantity) as total_qty, SUM(subtotal) as total_sales')
            ->whereHas('transaction', function ($q) use ($today) {
                $q->whereDate('created_at', $today)->where('payment_status', 'paid');
            })
            ->with('product')
            ->groupBy('product_id')
            ->orderByDesc('total_qty')
            ->take(5)
            ->get()
            ->toArray();
    }

    public function render()
    {
        return view('livewire.dashboard-pos')
            ->layout('layouts.pos');
    }
}
```

**resources/views/livewire/dashboard-pos.blade.php:**
```html
<div class="p-6" wire:poll.5s="loadData">
    <h1 class="text-2xl font-bold mb-6">Dashboard POS</h1>

    <div class="grid grid-cols-4 gap-4 mb-6">
        <div class="bg-white p-4 rounded-lg shadow">
            <p class="text-sm text-gray-500">Penjualan Hari Ini</p>
            <p class="text-2xl font-bold text-green-600">Rp {{ number_format($todaySales, 0, ',', '.') }}</p>
            <p class="text-xs text-gray-400">Update: {{ now()->format('H:i:s') }}</p>
        </div>
        <div class="bg-white p-4 rounded-lg shadow">
            <p class="text-sm text-gray-500">Transaksi Hari Ini</p>
            <p class="text-2xl font-bold text-blue-600">{{ $todayTransactions }}</p>
        </div>
        <div class="bg-white p-4 rounded-lg shadow">
            <p class="text-sm text-gray-500">Total Produk</p>
            <p class="text-2xl font-bold">{{ $totalProducts }}</p>
        </div>
        <div class="bg-white p-4 rounded-lg shadow">
            <p class="text-sm text-gray-500">Stok Menipis</p>
            <p class="text-2xl font-bold text-red-600">{{ $lowStockProducts }}</p>
        </div>
    </div>

    <div class="grid grid-cols-2 gap-6 mb-6">
        <div class="bg-white p-4 rounded-lg shadow">
            <h2 class="font-bold mb-3">Penjualan Per Jam</h2>
            <canvas id="hourlyChart" height="100"></canvas>
        </div>
        <div class="bg-white p-4 rounded-lg shadow">
            <h2 class="font-bold mb-3">Produk Terlaris</h2>
            <table class="w-full">
                @foreach($topProducts as $product)
                <tr class="border-t">
                    <td class="p-2">{{ $product['product']['name'] ?? 'N/A' }}</td>
                    <td class="p-2 text-right">{{ $product['total_qty'] }} pcs</td>
                    <td class="p-2 text-right">Rp {{ number_format($product['total_sales'], 0, ',', '.') }}</td>
                </tr>
                @endforeach
            </table>
        </div>
    </div>

    <div class="bg-white p-4 rounded-lg shadow">
        <h2 class="font-bold mb-3">Transaksi Terbaru</h2>
        <table class="w-full">
            <thead>
                <tr class="text-left">
                    <th class="p-2">#</th>
                    <th class="p-2">Kasir</th>
                    <th class="p-2">Pelanggan</th>
                    <th class="p-2 text-right">Total</th>
                    <th class="p-2 text-right">Waktu</th>
                </tr>
            </thead>
            <tbody>
                @foreach($recentTransactions as $t)
                <tr class="border-t">
                    <td class="p-2">{{ $t['id'] }}</td>
                    <td class="p-2">{{ $t['user']['name'] }}</td>
                    <td class="p-2">{{ $t['customer_name'] }}</td>
                    <td class="p-2 text-right">Rp {{ number_format($t['total'], 0, ',', '.') }}</td>
                    <td class="p-2 text-right">{{ \Carbon\Carbon::parse($t['created_at'])->format('H:i') }}</td>
                </tr>
                @endforeach
            </tbody>
        </table>
    </div>

    @push('scripts')
    <script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
    <script>
        let hourlyChart = null;
        document.addEventListener('livewire:init', function() {
            initHourlyChart();
        });
        document.addEventListener('livewire:update', function() {
            initHourlyChart();
        });
        function initHourlyChart() {
            const ctx = document.getElementById('hourlyChart');
            if (!ctx) return;
            const hours = @json($hourlySales);
            const labels = hours.map(h => h.hour + ':00');
            const data = hours.map(h => h.total);
            if (hourlyChart) hourlyChart.destroy();
            hourlyChart = new Chart(ctx, {
                type: 'line',
                data: { labels, datasets: [{ label: 'Penjualan', data, borderColor: '#3b82f6', fill: true }] },
                options: { responsive: true }
            });
        }
    </script>
    @endpush
</div>
```

## Cara Integrasi & Pengujian
- Akses route `/dashboard-pos`
- Lakukan transaksi di kasir, lihat statistik berubah otomatis dalam 5 detik
- Verifikasi polling berjalan tanpa reload halaman penuh
- Cek grafik penjualan per jam diperbarui
- Verifikasi stok menipis menampilkan produk dengan stok <= 5
- Uji performa dengan banyak data transaksi
