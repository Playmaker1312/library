# 229. Mengimplementasikan Proses Checkout dengan Berbagai Metode Pembayaran

## Definisi & Target
Membangun proses checkout yang menyimpan transaksi ke database, mengurangi stok produk, dan mencatat pembayaran. Mendukung metode pembayaran tunai, debit, kredit, dan QRIS.

## Komponen yang Terlibat
- Livewire Component: `KasirPage`
- Model: Transaction, TransactionItem, Payment, Product
- Database Transaction

## Perintah Artisan CLI
- Tidak ada perintah khusus

## Kode Implementasi (Per File)

**app/Livewire/KasirPage.php (checkout method):**
```php
use Illuminate\Support\Facades\DB;

class KasirPage extends Component
{
    public $paymentMethod = 'cash';
    public $customerName = '';

    public function checkout()
    {
        $this->validate([
            'cart' => 'required|array|min:1',
            'paymentMethod' => 'required|in:cash,debit,credit,qris',
        ]);

        DB::transaction(function () {
            $transaction = Transaction::create([
                'user_id' => auth()->id(),
                'customer_name' => $this->customerName ?: 'Umum',
                'subtotal' => $this->subtotal,
                'discount' => $this->discount,
                'tax' => $this->tax,
                'total' => $this->total,
                'payment_method' => $this->paymentMethod,
                'payment_status' => 'paid',
                'transaction_date' => now(),
            ]);

            foreach ($this->cart as $item) {
                $product = Product::findOrFail($item['product_id']);

                if ($product->stock < $item['quantity']) {
                    throw new \Exception("Stok {$product->name} tidak mencukupi");
                }

                TransactionItem::create([
                    'transaction_id' => $transaction->id,
                    'product_id' => $item['product_id'],
                    'quantity' => $item['quantity'],
                    'price' => $item['price'],
                    'subtotal' => $item['subtotal'],
                ]);

                $product->decrement('stock', $item['quantity']);
            }

            Payment::create([
                'transaction_id' => $transaction->id,
                'amount' => $this->total,
                'payment_method' => $this->paymentMethod,
                'payment_details' => $this->getPaymentDetails(),
                'paid_at' => now(),
            ]);

            $this->dispatch('transactionCreated', transactionId: $transaction->id);
            $this->resetCart();
        });
    }

    protected function getPaymentDetails(): array
    {
        return match ($this->paymentMethod) {
            'cash' => ['cash_amount' => $this->cashAmount, 'change' => $this->cashAmount - $this->total],
            'debit' => ['card_number' => '****', 'bank' => $this->bank ?? ''],
            'credit' => ['card_number' => '****', 'installment' => $this->installment ?? 1],
            'qris' => ['qr_code' => 'QRIS-' . Str::random(10)],
        };
    }

    public function resetCart()
    {
        $this->cart = [];
        $this->customerName = '';
        $this->discountValue = 0;
        $this->calculateTotals();
    }
}
```

**resources/views/livewire/kasir-page.blade.php (bagian pembayaran):**
```html
<div class="space-y-3">
    <input type="text" wire:model="customerName" placeholder="Nama Pelanggan (opsional)"
           class="w-full border rounded p-2 text-sm">

    <div>
        <label class="block text-sm font-medium mb-1">Metode Pembayaran</label>
        <select wire:model.live="paymentMethod" class="w-full border rounded p-2">
            <option value="cash">Tunai</option>
            <option value="debit">Kartu Debit</option>
            <option value="credit">Kartu Kredit</option>
            <option value="qris">QRIS</option>
        </select>
    </div>

    @if($paymentMethod === 'cash')
    <div>
        <label class="block text-sm font-medium mb-1">Jumlah Tunai</label>
        <input type="number" wire:model.live="cashAmount" class="w-full border rounded p-2"
               placeholder="Masukkan jumlah tunai">
        @if($cashAmount >= $total)
        <p class="text-sm text-green-600 mt-1">Kembalian: Rp {{ number_format($cashAmount - $total, 0, ',', '.') }}</p>
        @endif
    </div>
    @endif

    <button wire:click="checkout" wire:loading.attr="disabled"
            class="w-full bg-blue-600 text-white py-3 rounded-lg font-bold hover:bg-blue-700 disabled:opacity-50">
        <span wire:loading.remove>Proses Pembayaran</span>
        <span wire:loading>Memproses...</span>
    </button>
</div>
```

## Cara Integrasi & Pengujian
- Tambahkan produk ke cart, pilih metode pembayaran tunai
- Masukkan jumlah uang dan klik "Proses Pembayaran"
- Verifikasi transaksi tersimpan di database
- Cek stok produk berkurang sesuai quantity
- Coba metode pembayaran debit, kredit, dan QRIS
- Verifikasi error handling jika stok tidak mencukupi
