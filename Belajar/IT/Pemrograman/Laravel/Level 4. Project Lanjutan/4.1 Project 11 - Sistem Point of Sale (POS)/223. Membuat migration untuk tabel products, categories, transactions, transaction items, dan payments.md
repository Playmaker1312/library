# 223. Membuat Migration untuk Tabel Products, Categories, Transactions, Transaction Items, dan Payments

## Definisi & Target
Membuat file migration Laravel untuk semua tabel POS menggunakan fitur Schema Builder. Setiap migration mencakup kolom, foreign key, index, dan timestamp.

## Komponen yang Terlibat
- Migration categories
- Migration products
- Migration transactions
- Migration transaction_items
- Migration payments

## Perintah Artisan CLI
- `php artisan make:migration create_categories_table`
- `php artisan make:migration create_products_table`
- `php artisan make:migration create_transactions_table`
- `php artisan make:migration create_transaction_items_table`
- `php artisan make:migration create_payments_table`

## Kode Implementasi (Per File)

**Migration Categories:**
```php
Schema::create('categories', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->string('slug')->unique();
    $table->text('description')->nullable();
    $table->timestamps();
});
```

**Migration Products:**
```php
Schema::create('products', function (Blueprint $table) {
    $table->id();
    $table->foreignId('category_id')->constrained()->onDelete('cascade');
    $table->string('name');
    $table->string('sku')->unique();
    $table->string('barcode')->nullable()->unique();
    $table->decimal('price', 15, 2);
    $table->decimal('cost', 15, 2)->nullable();
    $table->integer('stock')->default(0);
    $table->text('description')->nullable();
    $table->string('image')->nullable();
    $table->boolean('is_active')->default(true);
    $table->timestamps();
});
```

**Migration Transactions:**
```php
Schema::create('transactions', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained();
    $table->string('customer_name')->nullable();
    $table->decimal('subtotal', 15, 2);
    $table->decimal('discount', 15, 2)->default(0);
    $table->decimal('tax', 15, 2)->default(0);
    $table->decimal('total', 15, 2);
    $table->enum('payment_method', ['cash', 'debit', 'credit', 'qris']);
    $table->enum('payment_status', ['pending', 'paid', 'failed'])->default('pending');
    $table->timestamp('transaction_date');
    $table->timestamps();
});
```

**Migration Transaction Items:**
```php
Schema::create('transaction_items', function (Blueprint $table) {
    $table->id();
    $table->foreignId('transaction_id')->constrained()->onDelete('cascade');
    $table->foreignId('product_id')->constrained();
    $table->integer('quantity');
    $table->decimal('price', 15, 2);
    $table->decimal('subtotal', 15, 2);
    $table->timestamps();
});
```

**Migration Payments:**
```php
Schema::create('payments', function (Blueprint $table) {
    $table->id();
    $table->foreignId('transaction_id')->constrained()->onDelete('cascade');
    $table->decimal('amount', 15, 2);
    $table->enum('payment_method', ['cash', 'debit', 'credit', 'qris']);
    $table->json('payment_details')->nullable();
    $table->timestamp('paid_at');
    $table->timestamps();
});
```

## Cara Integrasi & Pengujian
- Jalankan `php artisan migrate:fresh` untuk memastikan semua tabel terbuat
- Gunakan `php artisan db:show` untuk verifikasi struktur
- Cek foreign key menggunakan tool database
