# 228. Mengimplementasikan Perhitungan Subtotal, Diskon, Pajak, dan Total Otomatis

## Definisi & Target
Membangun logika perhitungan otomatis untuk subtotal (jumlah semua subtotal item), diskon (persentase atau nominal), pajak (PPN 11%), dan total akhir yang diperbarui secara real-time.

## Komponen yang Terlibat
- Livewire Component: `KasirPage`
- Property: `$subtotal`, `$discount`, `$tax`, `$total`, `$discountType`, `$discountValue`

## Perintah Artisan CLI
- Tidak ada perintah khusus

## Kode Implementasi (Per File)

**app/Livewire/KasirPage.php (perhitungan):**
```php
class KasirPage extends Component
{
    public $subtotal = 0;
    public $discount = 0;
    public $discountType = 'percentage';
    public $discountValue = 0;
    public $tax = 0;
    public $total = 0;

    protected $listeners = ['cartUpdated' => 'calculateTotals'];

    public function calculateTotals()
    {
        $this->subtotal = collect($this->cart)->sum('subtotal');

        if ($this->discountType === 'percentage') {
            $this->discount = $this->subtotal * ($this->discountValue / 100);
        } else {
            $this->discount = min($this->discountValue, $this->subtotal);
        }

        $this->tax = ($this->subtotal - $this->discount) * 0.11;
        $this->total = $this->subtotal - $this->discount + $this->tax;
    }

    public function updatedDiscountValue()
    {
        $this->calculateTotals();
    }

    public function updatedDiscountType()
    {
        $this->discountValue = 0;
        $this->calculateTotals();
    }
}
```

## Cara Integrasi & Pengujian
- Tambahkan beberapa produk ke cart, lihat subtotal berubah
- Ubah discount type ke percentage, isi nilai 10 -> diskon 10%
- Ubah discount type ke nominal, isi nilai 5000 -> diskon Rp 5.000
- Verifikasi pajak 11% dihitung dari (subtotal - diskon)
- Verifikasi total akhir = subtotal - diskon + pajak
