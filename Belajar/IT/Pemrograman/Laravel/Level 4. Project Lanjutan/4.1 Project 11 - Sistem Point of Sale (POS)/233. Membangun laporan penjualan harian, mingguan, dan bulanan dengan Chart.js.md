# 233. Membangun Laporan Penjualan Harian, Mingguan, dan Bulanan dengan Chart.js

## Definisi & Target
Membangun halaman laporan penjualan dengan tiga rentang waktu (harian, mingguan, bulanan) yang menampilkan data dalam bentuk tabel dan grafik menggunakan Chart.js.

## Komponen yang Terlibat
- Controller: `ReportController`
- Model: Transaction, TransactionItem
- Blade View: reports.index
- Library: Chart.js (CDN atau NPM)

## Perintah Artisan CLI
- `php artisan make:controller ReportController`

## Kode Implementasi (Per File)

**routes/web.php:**
```php
Route::get('/reports', [ReportController::class, 'index'])->name('reports.index');
Route::get('/reports/data', [ReportController::class, 'data'])->name('reports.data');
```

**app/Http/Controllers/ReportController.php:**
```php
class ReportController extends Controller
{
    public function index()
    {
        return view('reports.index');
    }

    public function data(Request $request)
    {
        $period = $request->get('period', 'daily');
        $startDate = $request->get('start_date', now()->startOfMonth()->format('Y-m-d'));
        $endDate = $request->get('end_date', now()->format('Y-m-d'));

        $query = Transaction::where('payment_status', 'paid')
            ->whereBetween('transaction_date', [$startDate, $endDate . ' 23:59:59']);

        switch ($period) {
            case 'daily':
                $grouped = $query->selectRaw('DATE(transaction_date) as date, COUNT(*) as total_transactions, SUM(total) as total_sales, SUM(discount) as total_discount')
                    ->groupBy('date')->orderBy('date')->get();
                break;
            case 'weekly':
                $grouped = $query->selectRaw('YEARWEEK(transaction_date, 1) as week, MIN(transaction_date) as week_start, COUNT(*) as total_transactions, SUM(total) as total_sales')
                    ->groupBy('week')->orderBy('week')->get();
                break;
            case 'monthly':
                $grouped = $query->selectRaw('DATE_FORMAT(transaction_date, "%Y-%m") as month, COUNT(*) as total_transactions, SUM(total) as total_sales')
                    ->groupBy('month')->orderBy('month')->get();
                break;
        }

        $summary = [
            'total_sales' => $query->sum('total'),
            'total_transactions' => $query->count(),
            'average_transaction' => $query->avg('total'),
            'total_discount' => $query->sum('discount'),
        ];

        return response()->json(compact('grouped', 'summary'));
    }
}
```

**resources/views/reports/index.blade.php:**
```html
<x-app-layout>
    <div class="p-6">
        <h1 class="text-2xl font-bold mb-4">Laporan Penjualan</h1>

        <div class="bg-white p-4 rounded-lg shadow mb-6">
            <div class="flex space-x-4 mb-4">
                <select id="period" class="border rounded p-2" onchange="loadChart()">
                    <option value="daily">Harian</option>
                    <option value="weekly">Mingguan</option>
                    <option value="monthly">Bulanan</option>
                </select>
                <input type="date" id="startDate" class="border rounded p-2">
                <input type="date" id="endDate" class="border rounded p-2">
            </div>

            <div class="grid grid-cols-4 gap-4 mb-6">
                <div class="bg-blue-50 p-4 rounded">
                    <p class="text-sm text-gray-500">Total Penjualan</p>
                    <p class="text-2xl font-bold" id="totalSales">Rp 0</p>
                </div>
                <div class="bg-green-50 p-4 rounded">
                    <p class="text-sm text-gray-500">Total Transaksi</p>
                    <p class="text-2xl font-bold" id="totalTransactions">0</p>
                </div>
                <div class="bg-yellow-50 p-4 rounded">
                    <p class="text-sm text-gray-500">Rata-rata Transaksi</p>
                    <p class="text-2xl font-bold" id="averageTransaction">Rp 0</p>
                </div>
                <div class="bg-red-50 p-4 rounded">
                    <p class="text-sm text-gray-500">Total Diskon</p>
                    <p class="text-2xl font-bold" id="totalDiscount">Rp 0</p>
                </div>
            </div>

            <canvas id="salesChart" height="100"></canvas>
        </div>

        <div class="bg-white rounded-lg shadow">
            <table class="w-full" id="reportTable">
                <thead class="bg-gray-50">
                    <tr>
                        <th class="p-3 text-left">Periode</th>
                        <th class="p-3 text-right">Jumlah Transaksi</th>
                        <th class="p-3 text-right">Total Penjualan</th>
                    </tr>
                </thead>
                <tbody id="reportBody"></tbody>
            </table>
        </div>
    </div>

    @push('scripts')
    <script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
    <script>
        let chart = null;

        document.addEventListener('DOMContentLoaded', function() {
            const today = new Date().toISOString().split('T')[0];
            const firstDay = new Date(today.getFullYear(), today.getMonth(), 1).toISOString().split('T')[0];
            document.getElementById('startDate').value = firstDay;
            document.getElementById('endDate').value = today;
            loadChart();
        });

        function loadChart() {
            const period = document.getElementById('period').value;
            const startDate = document.getElementById('startDate').value;
            const endDate = document.getElementById('endDate').value;

            fetch(`/reports/data?period=${period}&start_date=${startDate}&end_date=${endDate}`)
                .then(res => res.json())
                .then(data => {
                    const ctx = document.getElementById('salesChart').getContext('2d');
                    const labels = data.grouped.map(g => g.date || g.week_start || g.month);
                    const values = data.grouped.map(g => g.total_sales);
                    const transactions = data.grouped.map(g => g.total_transactions);

                    if (chart) chart.destroy();
                    chart = new Chart(ctx, {
                        type: 'bar',
                        data: {
                            labels: labels,
                            datasets: [
                                { label: 'Penjualan', data: values, backgroundColor: 'rgba(59, 130, 246, 0.5)' },
                                { label: 'Transaksi', data: transactions, backgroundColor: 'rgba(16, 185, 129, 0.5)' }
                            ]
                        },
                        options: { responsive: true, plugins: { legend: { position: 'top' } } }
                    });

                    document.getElementById('totalSales').textContent = 'Rp ' + new Intl.NumberFormat('id-ID').format(data.summary.total_sales);
                    document.getElementById('totalTransactions').textContent = data.summary.total_transactions;
                    document.getElementById('averageTransaction').textContent = 'Rp ' + new Intl.NumberFormat('id-ID').format(data.summary.average_transaction || 0);
                    document.getElementById('totalDiscount').textContent = 'Rp ' + new Intl.NumberFormat('id-ID').format(data.summary.total_discount);

                    const tbody = document.getElementById('reportBody');
                    tbody.innerHTML = data.grouped.map(g => `
                        <tr class="border-t">
                            <td class="p-3">${g.date || g.week_start || g.month}</td>
                            <td class="p-3 text-right">${g.total_transactions}</td>
                            <td class="p-3 text-right">Rp ${new Intl.NumberFormat('id-ID').format(g.total_sales)}</td>
                        </tr>
                    `).join('');
                });
        }
    </script>
    @endpush
</x-app-layout>
```

## Cara Integrasi & Pengujian
- Akses route `/reports`
- Pilih periode "Harian", "Mingguan", atau "Bulanan"
- Pilih rentang tanggal
- Verifikasi grafik dan tabel berubah sesuai periode
- Bandingkan total penjualan dengan data di database
- Uji responsivitas grafik pada berbagai ukuran layar
