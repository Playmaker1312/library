# 222. Auth attempt login manual

## Definisi Singkat
`Auth::attempt()` adalah metode untuk melakukan login manual dengan mencocokkan kredensial (email dan password) terhadap database.

## Analogi
Seperti保安 di pintu masuk — Anda tunjukkan KTP dan face recognition, ia cocokkan dengan database karyawan, jika cocok dipersilakan masuk.

## Poin-Poin Penting
- Parameter: array kredensial `['email' => '...', 'password' => '...']` dan boolean `$remember`
- Method hash password otomatis menggunakan bcrypt
- Mengembalikan `true` jika cocok, `false` jika tidak
- Setelah berhasil, panggil `$request->session()->regenerate()` untuk regenerasi session
- `redirect()->intended()` mengarahkan ke halaman yang sebelumnya diakses

## Contoh Kode
```php
<?php

namespace App\Http\Controllers\Auth;

use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

class LoginController extends Controller
{
    public function store(Request $request)
    {
        $credentials = $request->validate([
            'email'    => ['required', 'email'],
            'password' => ['required'],
        ]);

        // Attempt login
        if (Auth::attempt($credentials, $request->boolean('remember'))) {
            $request->session()->regenerate();

            // Redirect ke halaman yang dimaksud, atau default ke dashboard
            return redirect()->intended('/dashboard');
        }

        // Gagal login — kirim error
        return back()->withErrors([
            'email' => 'Kredensial yang diberikan tidak cocok dengan data kami.',
        ]);
    }
}
```

```php
// Dengan guard spesifik
if (Auth::guard('admin')->attempt($credentials)) {
    // admin berhasil login
}
```

## Kasus Penggunaan Nyata
Login form kustom tanpa Breeze/Jetstream, API login dengan guard spesifik, dan sistem autentikasi multi-guard yang membutuhkan kontrol manual.
