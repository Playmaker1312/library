# 226. Remember Me Functionality

## Definisi Singkat
Fitur "remember me" pada autentikasi Laravel membuat user tetap login meskipun browser ditutup, menggunakan cookie token yang disimpan di session.

## Analogi
Seperti kartu akses hotel yang berlaku selama menginap — Anda tidak perlu daftar ulang setiap kali masuk ke kamar setelah check-in awal.

## Poin-Poin Penting
- Aktifkan dengan memberikan `true` sebagai argumen kedua `Auth::attempt($cred, true)`
- Laravel secara otomatis mengelola token remember di tabel users
- Token disimpan di kolom `remember_token` (string, nullable)
- Cookie encrypted dan aman
- User tetap login hingga logout manual atau token di-reset

## Contoh Kode
```php
<?php

namespace App\Http\Controllers\Auth;

use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

class LoginController extends Controller
{
    public function store(Request $request)
    {
        $credentials = $request->validate([
            'email'    => 'required|email',
            'password' => 'required',
        ]);

        // Argumen kedua $remember = true/false
        $remember = $request->boolean('remember');

        if (Auth::attempt($credentials, $remember)) {
            $request->session()->regenerate();
            return redirect()->intended('/dashboard');
        }

        return back()->withErrors([
            'email' => 'Kredensial tidak valid.',
        ]);
    }
}
```

```blade
{{-- resources/views/auth/login.blade.php --}}
<form method="POST" action="/login">
    @csrf
    <input type="email" name="email" placeholder="Email">
    <input type="password" name="password" placeholder="Password">

    <label>
        <input type="checkbox" name="remember" value="1">

    </label>

    <button type="submit">Login</button>
</form>
```

## Kasus Penggunaan Nyata
Checkbox "Ingat Saya" di form login, aplikasi yang memerlukan sesi tahan lama (seperti email atau dashboard), dan pengaturan keamanan yang memberikan kontrol kepada user.
