# 220. Breeze vs Jetstream

## Definisi Singkat
Perbandingan antara Breeze (minimal, ringan, sederhana) dan Jetstream (fitur lengkap, lebih berat, cocok untuk SaaS) untuk memilih starter kit autentikasi yang tepat.

## Analogi
Breeze seperti sepeda motor bebek — irit, sederhana, cepat dipakai. Jetstream seperti mobil mewah — banyak fitur, lebih berat, tapi nyaman untuk perjalanan jauh.

## Poin-Poin Penting
| Aspek | Breeze | Jetstream |
|-------|--------|-----------|
| **Ukuran** | Ringan, minimal | Lebih berat, banyak fitur |
| **Stack** | Blade, Livewire, Inertia, API | Livewire atau Inertia saja |
| **Fitur Auth** | Login, Register, Reset Password | Semua Breeze + 2FA, Teams |
| **API Token** | Tidak | Ya (Sanctum) |
| **Manajemen Tim** | Tidak | Ya |
| **Session Management** | Tidak | Ya |
| **Profile Photo** | Tidak | Ya |
| **Kustomisasi** | Sangat mudah | Butuh usaha lebih |
| **Target** | Aplikasi sederhana / MVP | SaaS / Aplikasi besar |

## Contoh Kode
```php
<?php
// Breeze — lebih sederhana
Route::middleware('auth')->group(function () {
    Route::view('/dashboard', 'dashboard')->name('dashboard');
});

// Jetstream — fitur tambahan untuk teams
use Laravel\Jetstream\Features;

if (Features::hasTeamFeatures()) {
    Route::middleware(['auth', 'verified'])->group(function () {
        Route::get('/teams/create', [TeamController::class, 'create'])->name('teams.create');
    });
}
```

## Kasus Penggunaan Nyata
**Pilih Breeze** untuk: blog, portfolio, aplikasi internal sederhana. **Pilih Jetstream** untuk: SaaS, aplikasi enterprise, platform dengan multi-tenant dan tim.
