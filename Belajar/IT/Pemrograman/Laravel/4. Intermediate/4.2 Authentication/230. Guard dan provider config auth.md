# 230. Guard dan Provider Config Auth

## Definisi Singkat
Guard dan provider adalah komponen konfigurasi autentikasi di `config/auth.php` yang mendefinisikan bagaimana user diautentikasi dan dari mana data user diambil.

## Analogi
Guard seperti pintu masuk yang berbeda (pintu karyawan, pintu tamu, pintu kontraktor). Provider seperti database karyawan yang berbeda (database HRD, database mitra).

## Poin-Poin Penting
- **Guard**: cara autentikasi (session driver, token driver)
- **Provider**: sumber data user (Eloquent model, database table)
- Multiple guard untuk area berbeda (web, admin, api)
- Provider bisa menggunakan model Eloquent atau Query Builder
- Default guard: `web`, default provider: `users`

## Contoh Kode
```php
<?php
// config/auth.php

return [
    'defaults' => [
        'guard' => 'web',
        'passwords' => 'users',
    ],

    'guards' => [
        'web' => [
            'driver' => 'session',
            'provider' => 'users',
        ],

        'admin' => [
            'driver' => 'session',
            'provider' => 'admins',
        ],

        'api' => [
            'driver' => 'sanctum',
            'provider' => 'users',
        ],
    ],

    'providers' => [
        'users' => [
            'driver' => 'eloquent',
            'model' => App\Models\User::class,
        ],

        'admins' => [
            'driver' => 'eloquent',
            'model' => App\Models\Admin::class,
        ],
    ],

    'passwords' => [
        'users' => [
            'provider' => 'users',
            'table' => 'password_reset_tokens',
            'expire' => 60,
            'throttle' => 60,
        ],

        'admins' => [
            'provider' => 'admins',
            'table' => 'password_reset_tokens',
            'expire' => 60,
            'throttle' => 60,
        ],
    ],

    'password_timeout' => 10800,
];
```

```php
<?php
// Pakai guard admin di route
Route::middleware('auth:admin')->group(function () {
    Route::get('/admin/dashboard', [AdminController::class, 'index']);
});

// Di controller
$admin = Auth::guard('admin')->user();
```

## Kasus Penggunaan Nyata
Aplikasi multi-level (user biasa + admin) dengan tabel terpisah, API dengan token-based auth, dan sistem dengan multiple user types yang berbeda.
