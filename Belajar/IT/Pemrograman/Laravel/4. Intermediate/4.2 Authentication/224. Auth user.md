# 224. Auth user

## Definisi Singkat
`Auth::user()` mengembalikan instance model User yang sedang login, memberikan akses ke seluruh data dan relasi user tersebut.

## Analogi
Seperti mengambil kartu identitas dari saku — Anda bisa lihat nama, foto, jabatan, dan semua informasi yang tercantum di kartu tersebut.

## Poin-Poin Penting
- Mengembalikan `null` jika tidak ada user yang login (guest)
- Mengembalikan instance model User (atau model sesuai guard)
- Alternatif: `auth()->user()` (helper), `$request->user()`
- Bisa akses relasi, misal: `Auth::user()->posts`
- Method `Auth::id()` mengembalikan hanya ID user

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

class ProfileController extends Controller
{
    public function show()
    {
        $user = Auth::user();

        // Data user
        $name  = $user->name;
        $email = $user->email;

        // Relasi
        $posts = $user->posts;
        $comments = $user->comments;

        return view('profile', compact('user', 'posts'));
    }

    public function apiProfile(Request $request)
    {
        // Cara lain: dari request
        return response()->json([
            'user' => $request->user(),
            'id'   => $request->user()->id,
        ]);
    }
}
```

Menampilkan profil user, mengecek role user, mengambil data relasi milik user, dan menampilkan konten yang dipersonalisasi di dashboard.
