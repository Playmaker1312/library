# 219. Instal Laravel Jetstream

## Definisi Singkat
Laravel Jetstream adalah starter kit autentikasi yang lebih canggih dari Breeze, dilengkapi manajemen tim, two-factor authentication, session management, dan API token via Laravel Sanctum.

## Analogi
Seperti membeli rumah dengan sistem keamanan premium — ada CCTV (2FA), kartu akses terpisah untuk tamu (API token), dan ruang meeting untuk tim (team management).

## Poin-Poin Penting
- Install dengan Inertia (Vue/React) atau Livewire (Alpine.js)
- Fitur tambahan: API token (Sanctum), 2FA, manajemen tim, session browser
- Profil user lebih lengkap
- Lebih berat dari Breeze — cocok untuk aplikasi yang lebih besar
- Menggunakan Jetstream untuk UI komponen

## Contoh Kode
```bash
# 1. Install Jetstream
composer require laravel/jetstream

# 2. Generate scaffolding (pilih Livewire atau Inertia)
php artisan jetstream:install livewire

# 3. Jalankan migrasi dan build aset
php artisan migrate
npm install && npm run build
```

```php
<?php

// config/jetstream.php — konfigurasi fitur Jetstream
return [
    'stack' => 'livewire',
    'features' => [
        Features::profilePhotos(),
        Features::api(),
        Features::teams(['invitations' => true]),
        Features::accountDeletion(),
        Features::twoFactorAuthentication([
            'confirm' => true,
            'confirmPassword' => true,
        ]),
    ],
];
```

## Kasus Penggunaan Nyata
Aplikasi SaaS dengan manajemen tim, aplikasi yang butuh API token untuk integrasi, dan proyek yang membutuhkan sistem keamanan autentikasi tingkat lanjut.
