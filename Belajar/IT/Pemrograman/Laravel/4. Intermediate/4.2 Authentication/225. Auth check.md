# 225. Auth check

## Definisi Singkat
`Auth::check()` adalah metode untuk mengecek apakah ada user yang sedang login (terautentikasi), mengembalikan `true` jika ya, `false` jika guest.

## Analogi
Seperti sensor di pintu otomatis — ia hanya tahu apakah ada orang di depan pintu (login) atau tidak (guest), tanpa peduli siapa orangnya.

## Poin-Poin Penting
- `Auth::check()` — true jika ada user login
- `Auth::guest()` — kebalikan dari check (true jika belum login)
- Berguna di Controller, Service, atau Blade untuk conditional logic
- Alternatif: middleware `auth` lebih tepat untuk proteksi route
- Jangan gunakan check di Blade jika sudah ada direktif `@auth` / `@guest`

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

class DashboardController extends Controller
{
    public function index()
    {
        if (Auth::check()) {
            // User login — tampilkan data personal
            $user = Auth::user();
            return view('dashboard', compact('user'));
        }

        // Guest — tampilkan halaman publik
        return view('welcome');
    }
}
```

```blade
{{-- Di Blade — lebih idiomatis --}}
@auth
    <p>Selamat datang kembali!</p>
@endauth

@guest
    <p>Silakan login terlebih dahulu.</p>
@endguest

{{-- Sama dengan: --}}
@if (Auth::check())
    <p>Selamat datang!</p>
@endif

@if (Auth::guest())
    <p>Silakan login.</p>
@endif
```

## Kasus Penggunaan Nyata
Menampilkan konten berbeda untuk user login vs guest di halaman yang sama, conditional rendering di layout, dan pengecekan status di Service class.
