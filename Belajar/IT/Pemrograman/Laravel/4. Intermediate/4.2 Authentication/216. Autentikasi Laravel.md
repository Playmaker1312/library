# 216. Autentikasi Laravel

## Definisi Singkat
Autentikasi Laravel adalah sistem untuk memverifikasi identitas user (login/logout/register) yang terintegrasi langsung dengan session, database, dan middleware.

## Analogi
Seperti kartu akses karyawan — Anda swipe kartu, sistem mengecek apakah Anda terdaftar, lalu membuka pintu yang sesuai dengan hak akses Anda.

## Poin-Poin Penting
- Laravel menyediakan sistem autentikasi lengkap di `config/auth.php`
- Default menggunakan session-based auth (web guard)
- Bisa menggunakan token untuk API (sanctum)
- Breeze, Jetstream, dan UI memberikan scaffolding siap pakai
- Facade `Auth` menyediakan method helper
- Middleware `auth` melindungi route

## Contoh Kode
```php
<?php

// config/auth.php — konfigurasi default
return [
    'defaults' => [
        'guard' => 'web',
        'passwords' => 'users',
    ],
    'guards' => [
        'web' => [
            'driver' => 'session',
            'provider' => 'users',
        ],
    ],
    'providers' => [
        'users' => [
            'driver' => 'eloquent',
            'model' => App\Models\User::class,
        ],
    ],
];
```

```php
// Melindungi route dengan middleware auth
Route::middleware('auth')->group(function () {
    Route::resource('posts', PostController::class);
});
```

## Kasus Penggunaan Nyata
Login/logout user, registrasi akun baru, lupa password, verifikasi email, dan membatasi akses halaman tertentu hanya untuk member yang login.
