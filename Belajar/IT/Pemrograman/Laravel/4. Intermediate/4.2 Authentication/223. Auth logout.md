# 223. Auth logout

## Definisi Singkat
`Auth::logout()` adalah metode untuk mengakhiri session autentikasi user, menghapus semua data session, dan mengembalikan user ke status guest.

## Analogi
Seperti mencabut kartu akses dari mesin pintu — pintu tertutup dan orang yang keluar tidak bisa masuk lagi tanpa swipe ulang.

## Poin-Poin Penting
- `Auth::logout()` menghapus session autentikasi
- Panggil `$request->session()->invalidate()` untuk menghapus semua session data
- Panggil `$request->session()->regenerateToken()` untuk regenerasi CSRF token
- Setelah logout, redirect ke halaman login atau beranda

## Contoh Kode
```php
<?php

namespace App\Http\Controllers\Auth;

use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

class AuthenticatedSessionController extends Controller
{
    public function destroy(Request $request)
    {
        // Logout user
        Auth::logout();

        // Hapus seluruh session
        $request->session()->invalidate();

        // Regenerasi CSRF token
        $request->session()->regenerateToken();

        // Redirect ke halaman login
        return redirect('/login');
    }
}
```

```php
// Di Blade — tombol logout
<form method="POST" action="{{ route('logout') }}">
    @csrf
    <button type="submit">Logout</button>
</form>
```

```php
// Logout dari guard spesifik
Auth::guard('admin')->logout();
```

## Kasus Penggunaan Nyata
Tombol logout di dashboard, session timeout otomatis, dan switch akun user (logout dulu lalu login dengan akun berbeda).
