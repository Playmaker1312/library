# 217. Instal Laravel Breeze Scaffolding

## Definisi Singkat
Laravel Breeze adalah starter kit minimal untuk autentikasi yang menyediakan scaffolding lengkap (controller, view, route) untuk login, register, reset password, dan verifikasi email.

## Analogi
Seperti membeli rumah baru yang sudah ada kunci, pintu, dan sistem keamanan dasar — tinggal pakai tanpa harus bangun dari nol.

## Poin-Poin Penting
- Install dengan Composer dan satu perintah Artisan
- Pilihan stack: Blade, Livewire, Inertia (Vue/React), atau API
- Ringan dan minimal — mudah dikustomisasi
- Menggunakan Tailwind CSS untuk styling
- Cocok untuk proyek yang ingin fondasi auth tanpa berat

## Contoh Kode
```bash
# 1. Buat project Laravel baru
composer create-project laravel/laravel my-app
cd my-app

# 2. Install Breeze
composer require laravel/breeze --dev

# 3. Generate scaffolding (pilih stack)
php artisan breeze:install blade

# 4. (Laravel 11) Install juga migrations dan lang
php artisan migrate
npm install && npm run dev
```

## Kasus Penggunaan Nyata
Proyek baru yang butuh sistem autentikasi siap pakai dengan tampilan dan logika standar, cocok untuk MVP dan aplikasi internal.
