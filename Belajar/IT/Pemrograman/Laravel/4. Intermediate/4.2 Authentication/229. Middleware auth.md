# 229. Middleware auth

## Definisi Singkat
Middleware `auth` melindungi route agar hanya bisa diakses oleh user yang sudah login. Jika belum login, user akan diarahkan ke halaman login.

## Analogi
Seperti pintu putar di gedung perkantoran yang hanya bisa dilewati dengan kartu akses — tanpa kartu, Anda tidak bisa masuk sama sekali.

## Poin-Poin Penting
- Middleware `auth` adalah alias untuk `Illuminate\Auth\Middleware\Authenticate`
- Bisa tentukan guard: `auth:admin`
- Redirect ke route `login` jika belum login (bisa diubah di `boot()`)
- Bisa digunakan di route, controller, atau route group
- Bisa dikombinasikan dengan middleware lain

## Contoh Kode
```php
<?php

// 1. Di route — per route
Route::get('/dashboard', function () {
    return view('dashboard');
})->middleware('auth');

// 2. Di route group
Route::middleware('auth')->group(function () {
    Route::resource('posts', PostController::class);
    Route::get('/profile', [ProfileController::class, 'show']);
});

// 3. Di controller constructor
class PostController extends Controller
{
    public function __construct()
    {
        $this->middleware('auth');
        $this->middleware('verified')->only('create', 'store');
    }
}

// 4. Guard spesifik
Route::middleware('auth:admin')->group(function () {
    Route::get('/admin', [AdminController::class, 'dashboard']);
});
```

```php
<?php

// App/Providers/AppServiceProvider.php — custom redirect
use Illuminate\Support\Facades\Route;

public function boot(): void
{
    Route::pattern('id', '[0-9]+');
}
```

## Kasus Penggunaan Nyata
Melindungi halaman dashboard, halaman admin, form edit data, halaman checkout, dan semua route yang membutuhkan user login terlebih dahulu.
