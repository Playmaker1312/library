# 221. Facade Auth

## Definisi Singkat
`Auth` facade adalah antarmuka statis ke komponen autentikasi Laravel, menyediakan akses mudah ke berbagai fungsi autentikasi tanpa perlu dependency injection.

## Analogi
Seperti remote TV — Anda tekan tombol tanpa perlu tahu bagaimana sinyal inframerah bekerja di dalamnya.

## Poin-Poin Penting
- Namespace: `Illuminate\Support\Facades\Auth`
- Method umum: `attempt()`, `login()`, `logout()`, `user()`, `check()`, `id()`
- Bisa gunakan guard spesifik: `Auth::guard('admin')->attempt(...)`
- Helper global `auth()` juga tersedia (lebih pendek)
- Menggunakan konfigurasi dari `config/auth.php`

## Contoh Kode
```php
<?php

use Illuminate\Support\Facades\Auth;
use Illuminate\Http\Request;

class LoginController extends Controller
{
    public function login(Request $request)
    {
        $credentials = $request->validate([
            'email'    => 'required|email',
            'password' => 'required',
        ]);

        if (Auth::attempt($credentials, $request->boolean('remember'))) {
            $request->session()->regenerate();
            return redirect()->intended('/dashboard');
        }

        return back()->withErrors([
            'email' => 'Email atau password salah.',
        ]);
    }

    public function profile()
    {
        // Cara pakai Auth facade
        $user = Auth::user();
        $id   = Auth::id();

        // Sama saja dengan helper global
        $user2 = auth()->user();
        $id2   = auth()->id();

        // Guard spesifik
        $admin = Auth::guard('admin')->user();

        return view('profile', compact('user'));
    }
}
```

## Kasus Penggunaan Nyata
Digunakan di Controller, Service class, atau middleware untuk mendapatkan data user login, mengecek status login, atau melakukan autentikasi manual.
