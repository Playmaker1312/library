# 228. Email Verification

## Definisi Singkat
Email verification memastikan user memiliki akses ke alamat email yang didaftarkan dengan mengirimkan link verifikasi setelah registrasi.

## Analogi
Seperti mengirim surat konfirmasi ke alamat rumah — jika Anda benar-benar tinggal di alamat itu, Anda bisa menerima dan membalas surat tersebut.

## Poin-Poin Penting
- Model User harus implement `MustVerifyEmail` interface
- Breeze/Jetstream menyediakan fitur ini secara opsional
- Link verifikasi dikirim via notifikasi (queue)
- Middleware `verified` membatasi akses ke route tertentu
- Bisa kirim ulang notifikasi verifikasi

## Contoh Kode
```php
<?php

namespace App\Models;

use Illuminate\Contracts\Auth\MustVerifyEmail;
use Illuminate\Foundation\Auth\User as Authenticatable;

class User extends Authenticatable implements MustVerifyEmail
{
    // ... trait, casts, dll
}
```

```php
<?php

// routes/web.php
Route::middleware(['auth', 'verified'])->group(function () {
    Route::view('/dashboard', 'dashboard')->name('dashboard');
});
```

```blade
{{-- resources/views/auth/verify-email.blade.php --}}
<div>
    <h1>Verifikasi Alamat Email</h1>

    @if (session('message'))
        <p>{{ session('message') }}</p>
    @endif

    <p>Link verifikasi telah dikirim ke email Anda.</p>

    <form method="POST" action="{{ route('verification.send') }}">
        @csrf
        <button type="submit">Kirim Ulang Email Verifikasi</button>
    </form>

    <form method="POST" action="{{ route('logout') }}">
        @csrf
        <button type="submit">Logout</button>
    </form>
</div>
```

## Kasus Penggunaan Nyata
Aplikasi yang memerlukan alamat email valid (seperti e-commerce, fintech, marketplace) dan aplikasi dengan sistem notifikasi email transaksional.
