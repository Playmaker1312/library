# 214. Kustom Pesan Error Global Lang

## Definisi Singkat
Pesan error validasi dapat dikustom secara global melalui file bahasa di direktori `lang/` sehingga semua validasi otomatis menggunakan pesan yang sudah diterjemahkan.

## Analogi
Seperti mengganti template surat pemberitahuan di kantor pusat — semua cabang otomatis menggunakan format surat yang baru tanpa perlu mengubah satu per satu.

## Poin-Poin Penting
- File: `lang/{locale}/validation.php`
- Publikasikan dengan `php artisan lang:publish` jika menggunakan Laravel 11+
- Array `custom` untuk pesan per field tertentu
- Array `attributes` untuk mengganti nama atribut
- Bisa menggunakan parameter seperti `:attribute`, `:min`, `:max`

## Contoh Kode
```php
<?php
// lang/id/validation.php

return [
    // Aturan umum
    'required' => ':attribute wajib diisi.',
    'email'    => ':attribute harus alamat email yang valid.',
    'unique'   => ':attribute sudah digunakan.',
    'min'      => [
        'string'  => ':attribute minimal :min karakter.',
        'numeric' => ':attribute minimal :min.',
        'array'   => ':attribute minimal :min item.',
    ],
    'max'      => [
        'string'  => ':attribute maksimal :max karakter.',
        'numeric' => ':attribute maksimal :max.',
        'array'   => ':attribute maksimal :max item.',
    ],
    'exists'   => ':attribute yang dipilih tidak valid.',
    'numeric'  => ':attribute harus berupa angka.',
    'string'   => ':attribute harus berupa teks.',
    'integer'  => ':attribute harus bilangan bulat.',

    // Pesan custom per field spesifik
    'custom' => [
        'email' => [
            'required' => 'Alamat surel wajib diisi.',
            'unique'   => 'Alamat surel ini sudah terdaftar.',
        ],
        'password' => [
            'min' => 'Kata sandi minimal :min karakter.',
        ],
    ],

    // Nama atribut (placeholder :attribute)
    'attributes' => [
        'name'       => 'Nama',
        'email'      => 'Alamat Surel',
        'password'   => 'Kata Sandi',
        'phone'      => 'Nomor Telepon',
        'address'    => 'Alamat',
    ],
];
```

```php
// Di config/app.php — set locale default
'locale' => 'id',
```

## Kasus Penggunaan Nyata
Aplikasi full Bahasa Indonesia tanpa perlu menulis pesan error manual di setiap Form Request, mendukung multi-bahasa (i18n) dengan tinggal ganti file lang.
