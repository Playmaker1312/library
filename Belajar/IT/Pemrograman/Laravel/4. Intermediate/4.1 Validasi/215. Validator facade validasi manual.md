# 215. Validator Facade Validasi Manual

## Definisi Singkat
`Validator` facade digunakan untuk membuat instance validator secara manual, memberikan kontrol penuh atas proses validasi tanpa mengandalkan mekanisme redirect otomatis.

## Analogi
Seperti hakim pengadilan — Anda bisa memeriksa bukti (data), memutuskan lolos atau tidak, dan menentukan sendiri apa yang terjadi selanjutnya.

## Poin-Poin Penting
- `Validator::make($data, $rules, $messages, $attributes)` membuat instance
- Method `fails()` / `passes()` mengecek hasil
- Method `errors()` mengambil pesan error
- Method `validated()` mengambil data yang lolos
- Cocok untuk validasi di luar HTTP request (Service class, API response)
- Tidak otomatis redirect — Anda kendalikan sendiri

## Contoh Kode
```php
<?php

use Illuminate\Support\Facades\Validator;

class UserImportService
{
    public function import(array $data): array
    {
        $validator = Validator::make($data, [
            'name'  => 'required|string|max:100',
            'email' => 'required|email|unique:users,email',
            'role'  => 'required|in:admin,user',
        ]);

        if ($validator->fails()) {
            return [
                'success' => false,
                'errors'  => $validator->errors()->all(),
            ];
        }

        $validated = $validator->validated();
        User::create($validated);

        return ['success' => true];
    }
}
```

```php
// Validasi manual di Controller (API tanpa redirect)
use Illuminate\Support\Facades\Validator;

class ApiController extends Controller
{
    public function store(Request $request)
    {
        $validator = Validator::make($request->all(), [
            'title' => 'required|string',
            'body'  => 'required',
        ]);

        if ($validator->fails()) {
            return response()->json([
                'errors' => $validator->errors()
            ], 422);
        }

        return response()->json(Post::create($validator->validated()), 201);
    }
}
```

## Kasus Penggunaan Nyata
API endpoint yang mengembalikan JSON error, service layer yang melakukan validasi sebelum logika bisnis, dan import data batch dengan laporan error detail.
