# 210. Custom Rule Artisan make rule

## Definisi Singkat
Custom Rule adalah aturan validasi buatan sendiri yang dibuat dengan Artisan `php artisan make:rule`, memungkinkan logika validasi kompleks yang tidak ada di aturan bawaan.

## Analogi
Seperti membuat stempel pemeriksaan khusus untuk dokumen tertentu — Anda tentukan sendiri kriteria lolos atau tidaknya.

## Poin-Poin Penting
- Buat: `php artisan make:rule NamaRule`
- Letak: `app/Rules/`
- Implementasi method `passes($attribute, $value)`
- Method `message()` mengembalikan pesan error
- Support dependency injection di constructor
- Bisa menggunakan rule obyek (implement `ValidationRule`) atau invokable rule

## Contoh Kode
```php
<?php

namespace App\Rules;

use Closure;
use Illuminate\Contracts\Validation\ValidationRule;

class Uppercase implements ValidationRule
{
    public function validate(string $attribute, mixed $value, Closure $fail): void
    {
        if (strtoupper($value) !== $value) {
            $fail("Field :attribute harus huruf kapital semua.");
        }
    }
}
```

```php
// Cara pakai di Controller atau Form Request
use App\Rules\Uppercase;

$request->validate([
    'kode_promo' => ['required', 'string', new Uppercase],
]);
```

```php
// Invokable Rule (Laravel 10+)
// php artisan make:rule Uppercase --invokable
use App\Rules\Uppercase;

$request->validate([
    'kode_promo' => ['required', new Uppercase],
]);
```

## Kasus Penggunaan Nyata
Validasi nomor telepon dengan format tertentu, pengecekan kata terlarang, validasi koordinat GPS, pengecekan umur dari tanggal lahir, dan logika bisnis spesifik lainnya.
