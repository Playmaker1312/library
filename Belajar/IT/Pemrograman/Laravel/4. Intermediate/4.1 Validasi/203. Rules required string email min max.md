# 203. Rules required string email min max

## Definisi Singkat
Aturan validasi dasar yang paling sering digunakan: `required` (wajib ada), `string` (harus teks), `email` (format surel), `min` (minimal panjang/nilai), dan `max` (maksimal panjang/nilai).

## Analogi
Seperti formulir pendaftaran yang memiliki kolom bertanda bintang — nama tidak boleh kosong (`required`), alamat email harus sesuai format (`email`), password minimal 8 karakter (`min:8`).

## Poin-Poin Penting
- `required` gagal jika field null, string kosong, array kosong, atau file tidak diupload
- `string` memastikan input bertipe string
- `email` memeriksa format alamat email (bukan apakah benar-benar ada)
- `min` dan `max` bekerja sesuai tipe data: string (panjang karakter), numeric (nilai), array (jumlah item), file (ukuran KB)
- Bisa digabung dengan pipe `|` atau array

## Contoh Kode
```php
<?php

use Illuminate\Http\Request;

Route::post('/register', function (Request $request) {
    $validated = $request->validate([
        'name'     => 'required|string|max:100',
        'email'    => 'required|email|max:255',
        'password' => 'required|string|min:8|max:50',
        'age'      => 'required|integer|min:17|max:120',
        'bio'      => 'nullable|string|max:500',
    ]);

    User::create($validated);
});
```

## Kasus Penggunaan Nyata
Registrasi user, form kontak, edit profil, input komentar, form checkout, dan API endpoint penerimaan data.
