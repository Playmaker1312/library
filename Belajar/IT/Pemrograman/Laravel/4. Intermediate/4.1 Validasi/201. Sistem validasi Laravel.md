# 201. Sistem Validasi Laravel

## Definisi Singkat
Sistem validasi Laravel adalah mekanisme untuk memvalidasi data input (biasanya dari request HTTP) menggunakan aturan bawaan yang ekspresif, terpusat, dan mudah dibaca.

## Analogi
Seperti petugas keamanan di pintu masuk gedung yang memeriksa KTP setiap pengunjung — memastikan nama terisi, umur cukup, dan foto sesuai sebelum diizinkan masuk.

## Poin-Poin Penting
- Validasi ada di lapisan Controller atau Form Request
- Laravel menyediakan puluhan aturan bawaan (required, email, min, max, unique, dll.)
- Validasi otomatis mengembalikan error ke halaman sebelumnya jika gagal
- Error disimpan dalam session (flash data) dan bisa ditampilkan di Blade
- Mendukung validasi nested array dengan dot notation

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;

class PostController extends Controller
{
    public function store(Request $request)
    {
        $validated = $request->validate([
            'title' => 'required|max:255',
            'body'  => 'required',
            'email' => 'required|email|unique:users',
        ]);

        // Jika lolos, lanjut simpan data
        Post::create($validated);

        return redirect('/posts')->with('success', 'Postingan berhasil dibuat');
    }
}
```

## Kasus Penggunaan Nyata
Digunakan di hampir setiap form aplikasi: registrasi user, login, input artikel, data barang, pengaturan profil, dan API request body validation.
