# 207. Form Request Class Validasi

## Definisi Singkat
Form Request adalah class khusus yang menangani validasi dan otorisasi request secara terpisah dari Controller, membuat kode lebih rapi dan reusable.

## Analogi
Seperti resepsionis khusus yang sudah hafal aturan penerimaan tamu — Anda tinggal mengarahkan tamu kepadanya tanpa perlu memeriksa ulang.

## Poin-Poin Penting
- Buat dengan Artisan: `php artisan make:request StorePostRequest`
- Letak: `app/Http/Requests/`
- Method `rules()` mengembalikan array aturan validasi
- Method `authorize()` mengontrol siapa yang boleh mengakses
- Di-inject ke method Controller seperti `Request` biasa
- Otomatis redirect jika validasi gagal

## Contoh Kode
```php
<?php

namespace App\Http\Requests;

use Illuminate\Foundation\Http\FormRequest;

class StorePostRequest extends FormRequest
{
    public function authorize(): bool
    {
        return true; // semua user boleh akses
    }

    public function rules(): array
    {
        return [
            'title' => 'required|string|max:255',
            'body'  => 'required|string|min:10',
            'category_id' => 'required|exists:categories,id',
        ];
    }
}
```

```php
// Controller jadi sangat bersih
use App\Http\Requests\StorePostRequest;

class PostController extends Controller
{
    public function store(StorePostRequest $request)
    {
        $post = Post::create($request->validated());
        return redirect('/posts')->with('success', 'Post berhasil dibuat');
    }
}
```

## Kasus Penggunaan Nyata
Memisahkan logika validasi yang kompleks dari Controller, membuat validasi reusable untuk berbagai method/Controller, dan menjaga Controller tetap ramping.
