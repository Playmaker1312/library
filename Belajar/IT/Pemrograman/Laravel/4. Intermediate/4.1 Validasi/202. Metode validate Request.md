# 202. Metode validate Request

## Definisi Singkat
Metode `validate()` pada objek `Illuminate\Http\Request` adalah cara paling langsung untuk memvalidasi input request dengan aturan tertentu.

## Analogi
Seperti mesin pemeriksa otomatis di bandara — Anda masukkan dokumen, mesin langsung memeriksa kelengkapan dan keabsahannya dalam satu langkah.

## Poin-Poin Penting
- Tersedia langsung di `$request->validate(...)`
- Parameter pertama: array aturan validasi
- Parameter kedua (opsional): kustom pesan error
- Parameter ketiga (opsional): kustom atribut nama field
- Mengembalikan data yang sudah divalidasi (hanya field yang disebut di aturan)
- Melempar `ValidationException` jika gagal (redirect otomatis)

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;

class ProductController extends Controller
{
    public function store(Request $request)
    {
        $validated = $request->validate([
            'name'  => 'required|string|max:100',
            'price' => 'required|numeric|min:0',
            'stock' => 'required|integer|min:0',
        ], [
            'name.required' => 'Nama produk wajib diisi.',
            'price.min'     => 'Harga tidak boleh negatif.',
        ], [
            'name'  => 'Nama Produk',
            'price' => 'Harga',
        ]);

        Product::create($validated);
    }
}
```

## Kasus Penggunaan Nyata
Form input di aplikasi e-commerce untuk menambah produk, form pendaftaran event, input data karyawan, dan form pengaturan umum.
