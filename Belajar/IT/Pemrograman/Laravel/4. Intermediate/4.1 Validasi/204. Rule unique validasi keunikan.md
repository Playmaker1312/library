# 204. Rule unique validasi keunikan

## Definisi Singkat
Rule `unique` memastikan nilai suatu field tidak boleh duplikat di tabel database tertentu.

## Analogi
Seperti NIK atau nomor KTP — tidak boleh ada dua orang dengan NIK yang sama di database kependudukan.

## Poin-Poin Penting
- Format: `unique:nama_tabel,kolom,ignore_id,id_kolom`
- Secara default memeriksa kolom yang sama dengan nama field
- Bisa abaikan record tertentu saat update (`ignore:$id`)
- Bisa tambahkan kondisi WHERE tambahan dengan `->where()`
- Paling sering dipakai di field `email` dan `username`

## Contoh Kode
```php
<?php

use Illuminate\Http\Request;
use App\Models\User;

Route::post('/register', function (Request $request) {
    $validated = $request->validate([
        'email' => 'required|email|unique:users,email',
        'username' => 'required|string|unique:users,username|min:3',
    ]);
});

// Saat update — abaikan user yang sedang diedit
Route::put('/users/{user}', function (Request $request, User $user) {
    $validated = $request->validate([
        'email' => 'required|email|unique:users,email,' . $user->id,
    ]);
});

// Menggunakan Rule class (Laravel >= 10)
use Illuminate\Validation\Rule;

$validated = $request->validate([
    'email' => [
        'required',
        'email',
        Rule::unique('users')->ignore($user->id)->where(function ($query) {
            $query->where('active', true);
        }),
    ],
]);
```

## Kasus Penggunaan Nyata
Registrasi memastikan email/username belum dipakai, form edit profil (abaikan email milik sendiri), dan validasi kode unik produk.
