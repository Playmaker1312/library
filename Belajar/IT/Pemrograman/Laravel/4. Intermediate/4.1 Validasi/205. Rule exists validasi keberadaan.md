# 205. Rule exists validasi keberadaan

## Definisi Singkat
Rule `exists` memastikan bahwa nilai input benar-benar ada sebagai record di tabel / kolom database tertentu (biasanya foreign key).

## Analogi
Seperti petugas yang mengecek apakah ID karyawan yang disebutkan benar-benar terdaftar di sistem HRD sebelum mengatur jadwal cuti.

## Poin-Poin Penting
- Format: `exists:nama_tabel,kolom`
- Sering digunakan untuk validasi foreign key
- Bisa ditambahkan kondisi WHERE tambahan
- Bisa menggunakan `Rule::exists()` untuk lebih ekspresif

## Contoh Kode
```php
<?php

use Illuminate\Http\Request;

Route::post('/posts', function (Request $request) {
    $validated = $request->validate([
        'title'      => 'required|string',
        'category_id' => 'required|integer|exists:categories,id',
        'author_id'   => 'required|exists:users,id',
    ]);

    // category_id dan author_id dipastikan ada di database
});

// Dengan kondisi tambahan (hanya kategori aktif)
use Illuminate\Validation\Rule;

$validated = $request->validate([
    'category_id' => [
        'required',
        'integer',
        Rule::exists('categories', 'id')->where('active', true),
    ],
]);
```

## Kasus Penggunaan Nyata
Input kategori postingan, pemilihan penanggung jawab, pemilihan produk di pesanan, dan referensi data master lainnya.
