# 212. Validasi Array Nested Data

## Definisi Singkat
Laravel mendukung validasi data bertingkat (nested array) menggunakan dot notation, wildcard `*`, dan aturan khusus array.

## Analogi
Seperti memeriksa isi setiap kardus dalam satu kontainer — bukan hanya kontainernya, tapi setiap item di dalam setiap kardus harus sesuai spesifikasi.

## Poin-Poin Penting
- Gunakan `*` sebagai wildcard untuk setiap elemen array
- Dot notation untuk nested key: `items.*.product_id`
- Aturan `array` memastikan input berupa array
- Aturan `required` dengan `min:1` untuk minimal item
- Bisa validasi kedalaman berapa pun

## Contoh Kode
```php
<?php

use Illuminate\Http\Request;

Route::post('/orders', function (Request $request) {
    $validated = $request->validate([
        'customer_name' => 'required|string',
        'items'         => 'required|array|min:1',
        'items.*.product_id' => 'required|exists:products,id',
        'items.*.quantity'   => 'required|integer|min:1',
        'items.*.price'      => 'required|numeric|min:0',
    ]);

    Order::create([
        'customer_name' => $validated['customer_name'],
        'items' => json_encode($validated['items']),
    ]);
});
```

```php
// Validasi nested lebih dalam
$request->validate([
    'data' => 'required|array',
    'data.*.user.name'  => 'required|string',
    'data.*.user.email' => 'required|email',
    'data.*.tags'       => 'array',
    'data.*.tags.*'     => 'string|distinct',
]);
```

## Kasus Penggunaan Nyata
Pesanan dengan banyak item (order detail), import data batch, konfigurasi multi-step form, dan API yang menerima array objek kompleks.
