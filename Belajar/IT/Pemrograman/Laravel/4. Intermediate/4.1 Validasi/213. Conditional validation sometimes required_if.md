# 213. Conditional Validation sometimes required_if

## Definisi Singkat
Aturan bersyarat (`sometimes`, `required_if`, `required_unless`, `required_with`) memungkinkan validasi dijalankan hanya dalam kondisi tertentu.

## Analogi
Seperti pertanyaan di form KTP yang hanya muncul jika Anda memilih status "menikah" — pertanyaan nama pasangan tidak relevan untuk yang lajang.

## Poin-Poin Penting
- `sometimes`: hanya validasi jika field ada di input
- `required_if:field,value`: field wajib jika field lain bernilai tertentu
- `required_unless:field,value`: wajib kecuali field lain bernilai tertentu
- `required_with:foo,bar`: wajib jika salah satu field lain ada
- `required_without:foo`: wajib jika field lain tidak ada
- Bisa dikombinasikan dengan aturan lain

## Contoh Kode
```php
<?php

use Illuminate\Http\Request;

Route::post('/register', function (Request $request) {
    $validated = $request->validate([
        'name'         => 'required|string',
        'email'        => 'required|email',
        'password'     => 'required|string|min:8',

        // Hanya validasi jika field 'age' ada di input
        'age'          => 'sometimes|integer|min:17',

        // Wajib jika role == 'seller'
        'role'         => 'required|in:buyer,seller',
        'store_name'   => 'required_if:role,seller|string',
        'store_address'=> 'required_if:role,seller|string',

        // Wajib jika payment_method == 'transfer'
        'payment_method' => 'required|in:cash,transfer',
        'bank_account'   => 'required_if:payment_method,transfer|string',
    ]);
});

// Pakai Rule::when
use Illuminate\Validation\Rule;
$validated = $request->validate([
    'coupon_code' => Rule::when($request->has_coupon, 'required|string|max:20', 'nullable'),
]);
```

## Kasus Penggunaan Nyata
Form bertingkat yang fieldnya tergantung pilihan sebelumnya, pendaftaran dengan tipe akun berbeda, dan form pembayaran dengan metode bervariasi.
