# 211. Rule Facade

## Definisi Singkat
`Rule` facade menyediakan method-method builder untuk membuat aturan validasi secara programatik dengan sintaks yang lebih ekspresif dibanding string pipe.

## Analogi
Seperti menu prasmanan — Anda bisa memilih sendiri lauk (aturan) yang diinginkan dan menambahkan bumbu (kondisi) sesuai selera.

## Poin-Poin Penting
- Ada di namespace `Illuminate\Validation\Rule`
- Method: `unique()`, `exists()`, `in()`, `notIn()`, `when()`, `forEach()`
- Lebih ekspresif dan mudah dibaca dibanding string aturan
- Memudahkan penambahan kondisi dinamis
- Bisa dikombinasikan dengan array aturan

## Contoh Kode
```php
<?php

use Illuminate\Http\Request;
use Illuminate\Validation\Rule;

Route::post('/users/{user}', function (Request $request, User $user) {
    $validated = $request->validate([
        'email' => [
            'required',
            'email',
            Rule::unique('users')->ignore($user->id)->where(function ($query) {
                $query->where('is_active', true);
            }),
        ],
        'role' => [
            'required',
            Rule::in(['admin', 'editor', 'viewer']),
        ],
        'kategori' => [
            'required',
            Rule::exists('categories', 'id')->where('active', true),
        ],
        'status' => [
            Rule::notIn(['deleted', 'archived']),
        ],
    ]);
});

// Rule::when — aturan bersyarat
$validated = $request->validate([
    'role' => Rule::when($request->is_admin, ['required', 'string'], ['nullable']),
]);
```

## Kasus Penggunaan Nyata
Validasi dinamis yang kondisinya tergantung input lain, validasi enum atau status yang terbatas, dan kondisi unique yang komplex saat update data.
