# 206. Pesan Error Blade @error

## Definisi Singkat
Direktif `@error` di Blade digunakan untuk menampilkan pesan error validasi per-field dengan aman dan mudah.

## Analogi
Seperti lampu indikator merah di dashboard mobil yang menyala tepat di samping komponen yang bermasalah.

## Poin-Poin Penting
- `@error('field')` mengecek apakah ada error untuk field tertentu
- Otomatis membaca dari session errors
- Harus ditutup dengan `@enderror`
- Bisa menampilkan pesan kustom atau default
- Mendukung nested field dengan dot notation

## Contoh Kode
```blade
{{-- resources/views/posts/create.blade.php --}}
<form method="POST" action="/posts">
    @csrf

    <div>
        <label>Judul</label>
        <input type="text" name="title" value="{{ old('title') }}"
               class="@error('title') is-invalid @enderror">
        @error('title')
            <div class="alert alert-danger">{{ $message }}</div>
        @enderror
    </div>

    <div>
        <label>Konten</label>
        <textarea name="body">{{ old('body') }}</textarea>
        @error('body')
            <div class="alert alert-danger">{{ $message }}</div>
        @enderror
    </div>

    {{-- Nested field --}}
    @error('user.email')
        <div>{{ $message }}</div>
    @enderror

    <button type="submit">Simpan</button>
</form>
```

## Kasus Penggunaan Nyata
Semua form di aplikasi Laravel yang membutuhkan feedback validasi langsung di sebelah input field yang gagal.
