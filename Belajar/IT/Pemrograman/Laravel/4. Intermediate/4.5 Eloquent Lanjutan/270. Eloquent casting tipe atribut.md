# 270. Eloquent Casting Tipe Atribut

## Definisi Singkat
Attribute casting mengubah tipe data atribut model secara otomatis saat diakses atau disimpan, memastikan data selalu dalam format yang benar tanpa konversi manual.

## Analogi
Seperti mesin ATM yang otomatis mengonversi angka menjadi format rupiah — Anda cukup memasukkan nilai 100000, dan ATM menampilkan "Rp 100.000" tanpa perlu Anda format manual.

## Poin-Poin Penting
- Didefinisikan di properti `$casts` (Laravel < 10) atau method `casts()` (Laravel 10+)
- Tipe yang didukung: `integer`, `real`, `float`, `double`, `string`, `boolean`, `object`, `array`, `collection`, `datetime`, `timestamp`, `encrypted`, `enum`
- Casting terjadi saat akses (`$model->attribute`) dan saat simpan
- `array` cast otomatis serialize/deserialize JSON
- `encrypted` cast menggunakan enkripsi Laravel

## Contoh Kode
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Product extends Model
{
    // Laravel < 10
    // protected $casts = [
    //     'price' => 'decimal:2',
    //     'is_active' => 'boolean',
    //     'metadata' => 'array',
    //     'expires_at' => 'datetime',
    // ];

    // Laravel 10+
    protected function casts(): array
    {
        return [
            'price'          => 'decimal:2',    // 100000 → 100000.00
            'discount'       => 'float',         // disimpan sebagai float
            'is_active'      => 'boolean',       // true/false
            'is_featured'    => 'boolean',
            'metadata'       => 'array',         // JSON → array PHP
            'tags'           => 'collection',    // JSON → Collection
            'expires_at'     => 'datetime',      // string → Carbon
            'published_at'   => 'datetime:Y-m-d',// format kustom
            'options'        => 'object',        // JSON → stdClass
            'secret_key'     => 'encrypted',     // otomatis encrypt/decrypt
            'status'         => ProductStatus::class, // enum casting
        ];
    }
}
```

```php
<?php
// Penggunaan
$product = Product::find(1);

// Otomatis boolean — bukan string '0' / '1'
if ($product->is_active) { ... }

// Otomatis Carbon instance — bisa panggil method Carbon
echo $product->expires_at->diffForHumans();

// Otomatis array — dari JSON kolom
foreach ($product->tags as $tag) { ... }

// Otomatis collection
$product->metadata->get('key');
```

## Kasus Penggunaan Nyata
Format harga otomatis, boolean untuk status aktif/non-aktif, JSON untuk data fleksibel (metadata, settings), datetime untuk manipulasi tanggal dengan Carbon, dan enkripsi data sensitif.
