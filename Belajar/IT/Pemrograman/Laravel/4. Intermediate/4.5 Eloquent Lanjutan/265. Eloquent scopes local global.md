# 265. Eloquent Scopes Local Global

## Definisi Singkat
Scopes adalah method reusable untuk membatasi query Eloquent. **Local scope** dipanggil manual (`published()->recent()`), **global scope** otomatis berlaku di semua query.

## Analogi
**Local scope** seperti filter di aplikasi belanja — Anda klik "murah" dan "rating tinggi" untuk memfilter produk. **Global scope** seperti aturan toko "hanya tampilkan barang yang tersedia" — berlaku untuk semua pencarian.

## Poin-Poin Penting
- **Local scope**: method `scopeNama()` di model, panggil `Model::nama()`
- **Global scope**: berlaku ke SEMUA query model itu
- Global scope bisa berupa class terpisah atau closure di `booted()`
- Local scope bisa menerima parameter
- Scope bisa dirantai (chained)

## Contoh Kode
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Post extends Model
{
    // --- LOCAL SCOPE ---

    // Scope tanpa parameter: Post::published()->get()
    public function scopePublished($query)
    {
        return $query->where('is_published', true);
    }

    // Scope dengan parameter: Post::whereCategory('laravel')->get()
    public function scopeWhereCategory($query, string $category)
    {
        return $query->where('category', $category);
    }

    // Scope dengan multiple parameter
    public function scopePopular($query, int $minViews = 100)
    {
        return $query->where('views', '>=', $minViews);
    }

    // Scope bisa dirantai
    // Post::published()->popular(50)->recent()->get()

    // --- GLOBAL SCOPE (closure) ---
    protected static function booted(): void
    {
        // Global scope — otomatis hanya tampilkan post aktif
        static::addGlobalScope('active', function ($query) {
            $query->where('is_active', true);
        });
    }
}
```

```php
<?php
// Penggunaan local scope
use App\Models\Post;

$posts = Post::published()
    ->whereCategory('tutorial')
    ->popular(200)
    ->orderBy('created_at', 'desc')
    ->get();
```

## Kasus Penggunaan Nyata
**Local scope**: filter publikasi, filter kategori, filter tanggal, filter status. **Global scope**: soft delete (hanya tampilkan yang tidak dihapus), tenant filtering, status aktif/non-aktif.
