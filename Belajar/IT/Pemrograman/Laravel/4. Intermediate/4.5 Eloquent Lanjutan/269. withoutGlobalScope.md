# 269. withoutGlobalScope

## Definisi Singkat
Method `withoutGlobalScope()` digunakan untuk mengecualikan global scope tertentu (atau semua) dari query, memberikan fleksibilitas untuk mengakses data yang biasanya disembunyikan.

## Analogi
Seperti membuka lemari arsip "rahasia" yang biasanya terkunci — dengan kunci khusus (withoutGlobalScope), Anda bisa melihat arsip yang biasanya tidak tampil.

## Poin-Poin Penting
- `withoutGlobalScope($scope)` — kecualikan satu scope
- `withoutGlobalScopes()` — kecualikan semua global scope
- Bisa terima class name (string) atau object
- Berguna untuk admin panel atau laporan yang perlu akses penuh
- Hanya berlaku untuk query tersebut, tidak permanen

## Contoh Kode
```php
<?php

namespace App\Models;

use App\Models\Scopes\ActiveScope;

class Post extends Model
{
    protected static function booted(): void
    {
        static::addGlobalScope(new ActiveScope);
    }
}
```

```php
<?php

use App\Models\Post;
use App\Models\Scopes\ActiveScope;

// Semua query normal — hanya tampilkan yang aktif
$activePosts = Post::all();

// Kecualikan ActiveScope — lihat semua termasuk non-aktif
$allPosts = Post::withoutGlobalScope(ActiveScope::class)->get();

// Kecualikan semua global scope
$rawPosts = Post::withoutGlobalScopes()->get();

// Admin dashboard — lihat semua data
class AdminController extends Controller
{
    public function posts()
    {
        $posts = Post::withoutGlobalScope(ActiveScope::class)
            ->withTrashed() // juga lihat soft deleted
            ->paginate(20);

        return view('admin.posts', compact('posts'));
    }
}

// Bisa juga untuk relasi
$user = User::find(1);
$allUserPosts = $user->posts()->withoutGlobalScope(ActiveScope::class)->get();
```

## Kasus Penggunaan Nyata
Admin panel yang perlu melihat semua data (termasuk non-aktif/terhapus), laporan audit untuk data yang di-soft-delete, dan debugging query dengan global scope.
