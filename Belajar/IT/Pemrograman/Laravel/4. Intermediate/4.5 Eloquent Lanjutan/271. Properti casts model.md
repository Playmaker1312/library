# 271. Properti casts model

## Definisi Singkat
Properti `$casts` (atau method `casts()` di Laravel 10+) pada model Eloquent mendefinisikan bagaimana atribut database dikonversi secara otomatis saat diakses atau disimpan.

## Analogi
Seperti lemari arsip dengan label jenis dokumen — label "Foto" berarti isinya foto, label "Dokumen" berarti isinya surat. Anda tidak perlu membuka dan menebak-nebak isinya.

## Poin-Poin Penting
- Laravel < 10: properti `$casts` array
- Laravel 10+: method `casts()` return array
- Setiap key adalah nama kolom, value adalah tipe cast
- Casting mempengaruhi akses dan penyimpanan
- Bisa menggunakan custom cast class

## Contoh Kode
```php
<?php

namespace App\Models;

use App\Enums\OrderStatus;
use Illuminate\Database\Eloquent\Model;

class Order extends Model
{
    // Laravel 10+ — method casts()
    protected function casts(): array
    {
        return [
            'amount'        => 'decimal:2',
            'tax'           => 'float',
            'total'         => 'decimal:2',
            'is_paid'       => 'boolean',
            'is_shipped'    => 'boolean',
            'items'         => 'array',
            'shipped_at'    => 'datetime',
            'paid_at'       => 'datetime',
            'config'        => 'collection',
            'notes'         => 'string',
            'status'        => OrderStatus::class,
        ];
    }

    // Laravel < 10 — properti $casts
    // protected $casts = [
    //     'amount' => 'decimal:2',
    //     'is_paid' => 'boolean',
    // ];
}
```

```php
<?php
// Cara pakai
$order = Order::find(1);

// Otomatis boolean
if ($order->is_paid) {
    // sudah bayar
}

// Otomatis Carbon
echo $order->shipped_at?->format('d M Y');

// Otomatis array dari JSON
foreach ($order->items as $item) {
    echo $item['name'];
}

// Decimal — 2 angka di belakang koma
echo number_format($order->total, 2);
```

## Kasus Penggunaan Nyata
Semua model Eloquent sebaiknya memiliki casts yang tepat untuk memastikan tipe data konsisten — terutama untuk boolean, datetime, JSON, dan enum.
