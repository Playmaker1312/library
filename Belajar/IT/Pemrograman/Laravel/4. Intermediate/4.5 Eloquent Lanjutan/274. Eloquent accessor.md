# 274. Eloquent Accessor

## Definisi Singkat
Accessor adalah method di model Eloquent yang memformat atribut saat diakses, memungkinkan transformasi data tanpa mengubah nilai asli di database.

## Analogi
Seperti kacamata dengan filter warna — saat Anda melihat sesuatu (mengakses atribut), kacamata mengubah tampilannya (format) tanpa mengubah benda aslinya (database).

## Poin-Poin Penting
- Laravel 9+: method `namaAtribut()` dengan return type `Attribute`
- Laravel lama: method `getNamaAttribute()`
- Gunakan `Attribute::make(get: fn() => ...)`
- Bisa juga define setter (mutator) dalam satu method
- Ditambahkan ke serialisasi (toArray, toJson) jika di `$appends`

## Contoh Kode
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Casts\Attribute;

class User extends Model
{
    // Laravel 9+ — Attribute::make
    protected function fullName(): Attribute
    {
        return Attribute::make(
            get: fn(mixed $value, array $attributes) => "{$attributes['first_name']} {$attributes['last_name']}",
        );
    }

    // Format tanggal kustom
    protected function createdAt(): Attribute
    {
        return Attribute::make(
            get: fn(mixed $value) => \Carbon\Carbon::parse($value)->format('d M Y H:i'),
        );
    }

    // Accessor dengan logika
    protected function statusLabel(): Attribute
    {
        return Attribute::make(
            get: fn(mixed $value, array $attributes) => match($attributes['status']) {
                'active'   => 'Aktif',
                'inactive' => 'Tidak Aktif',
                'banned'   => 'Diblokir',
                default    => 'Tidak Diketahui',
            },
        );
    }
}
```

```php
<?php
// Penggunaan
$user = User::find(1);
echo $user->full_name;     // "John Doe"
echo $user->created_at;    // "28 May 2026 13:45"
echo $user->status_label;  // "Aktif"
```

```php
<?php
// Laravel lama — method getNamaAttribute
public function getFullNameAttribute()
{
    return "{$this->first_name} {$this->last_name}";
}
```

## Kasus Penggunaan Nyata
Full name dari first_name + last_name, format harga dengan Rp, status label yang user-friendly, URL lengkap dari path, dan format tanggal sesuai locale.
