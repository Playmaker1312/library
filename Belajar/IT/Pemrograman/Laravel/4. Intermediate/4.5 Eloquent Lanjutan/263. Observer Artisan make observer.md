# 263. Observer Artisan make observer

## Definisi Singkat
Artisan `make:observer` membuat class observer baru dengan template method untuk setiap event Eloquent, yang bisa langsung diisi logika.

## Analogi
Seperti mencetak buku catatan khusus dengan halaman-halaman yang sudah diberi judul: "Creating", "Created", "Updating", "Updated" — tinggal Anda isi.

## Poin-Poin Penting
- Perintah: `php artisan make:observer PostObserver`
- Opsi `--model` otomatis mengisi method dengan type-hint
- File dibuat di `app/Observers/`
- Secara default berisi method: `created`, `updated`, `deleted`, `forceDeleted`
- Method lain bisa ditambahkan manual

## Contoh Kode
```bash
# Buat observer kosong
php artisan make:observer PostObserver

# Buat observer dengan model binding (method sudah terisi)
php artisan make:observer PostObserver --model=Post
```

```php
<?php

namespace App\Observers;

use App\Models\Post;

class PostObserver
{
    // Method-method ini otomatis terisi jika pakai --model=Post
    public function created(Post $post): void
    {
        // Logika setelah post dibuat
    }

    public function updated(Post $post): void
    {
        // Logika setelah post diupdate
    }

    public function deleted(Post $post): void
    {
        // Logika setelah post dihapus
    }

    public function forceDeleted(Post $post): void
    {
        // Logika setelah post di-force delete
    }

    // Method tambahan
    public function creating(Post $post): void
    {
        // Sebelum post disimpan
    }

    public function saving(Post $post): void
    {
        // Sebelum post disimpan (create atau update)
    }

    public function restoring(Post $post): void
    {
        // Saat post di-restore (soft delete)
    }
}
```

## Kasus Penggunaan Nyata
Membuat observer untuk setiap model yang membutuhkan side effects — PostObserver, UserObserver, OrderObserver, CommentObserver.
