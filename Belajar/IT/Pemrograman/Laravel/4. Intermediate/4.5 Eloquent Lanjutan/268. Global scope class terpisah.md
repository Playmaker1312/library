# 268. Global Scope Class Terpisah

## Definisi Singkat
Global scope bisa dibuat sebagai class terpisah (lebih rapi dan reusable), dengan Artisan `make:scope` atau manual, yang mengimplementasikan interface `Scope`.

## Analogi
Seperti membuat cetakan kue khusus — sekali buat, bisa dipakai berulang untuk model yang berbeda, tidak perlu membuat adonan baru setiap kali.

## Poin-Poin Penting
- Buat class implement `Illuminate\Database\Eloquent\Scope`
- Method `apply($query, $model)` — tempat logika scope
- Daftarkan di `booted()` model: `static::addGlobalScope(new NamaScope)`
- Bisa digunakan di lebih dari satu model
- Bisa dikecualikan dengan `withoutGlobalScope(NamaScope::class)`

## Contoh Kode
```bash
# Artisan membuat scope (Laravel 8+)
php artisan make:scope ActiveScope
```

```php
<?php

namespace App\Models\Scopes;

use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Scope;

class ActiveScope implements Scope
{
    public function apply(Builder $builder, Model $model): void
    {
        $builder->where('is_active', true);
    }
}
```

```php
<?php

namespace App\Models\Scopes;

use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Scope;

class TenantScope implements Scope
{
    public function __construct(protected string $column = 'tenant_id') {}

    public function apply(Builder $builder, Model $model): void
    {
        $tenantId = auth()->user()?->tenant_id;
        if ($tenantId) {
            $builder->where($this->column, $tenantId);
        }
    }
}
```

```php
<?php

namespace App\Models;

use App\Models\Scopes\ActiveScope;
use App\Models\Scopes\TenantScope;
use Illuminate\Database\Eloquent\Model;

class Post extends Model
{
    protected static function booted(): void
    {
        static::addGlobalScope(new ActiveScope);
        static::addGlobalScope(new TenantScope);
    }
}

// Semua query Post akan punya WHERE is_active = true AND tenant_id = current_tenant
```

```php
<?php
// Pengecualian
Post::withoutGlobalScope(ActiveScope::class)->get();
Post::withoutGlobalScope(TenantScope::class)->get();
Post::withoutGlobalScopes()->get();
```

## Kasus Penggunaan Nyata
Multi-tenant filtering, published/unpublished scope, soft delete scope (bawaan Laravel), dan company/user-specific filtering untuk aplikasi enterprise.
