# 266. Local Scope scope method

## Definisi Singkat
Local scope adalah method di model dengan prefiks `scope` yang mengembalikan query builder instance, memungkinkan filter reusable yang dipanggil secara eksplisit.

## Analogi
Seperti filter di aplikasi kamera — ada filter "vivid", "portrait", "mono" yang bisa Anda aplikasikan kapan pun Anda mau. Tidak otomatis, tapi siap pakai.

## Poin-Poin Penting
- Format: `public function scopeNama($query, ...$params) { ... }`
- Panggil: `Model::nama($params)` — tanpa prefix `scope`
- Method harus return `$query` atau query builder
- Bisa dirantai (chained) dengan scope lain atau where biasa
- Bisa menerima parameter untuk fleksibilitas

## Contoh Kode
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Product extends Model
{
    // Filter produk yang sedang diskon
    public function scopeDiscounted($query)
    {
        return $query->where('discount_percent', '>', 0)
                     ->where('stock', '>', 0);
    }

    // Filter berdasarkan rentang harga
    public function scopePriceRange($query, $min, $max)
    {
        return $query->whereBetween('price', [$min, $max]);
    }

    // Filter berdasarkan kategori dengan opsi include sub
    public function scopeByCategory($query, $categoryId, $includeSub = false)
    {
        if ($includeSub) {
            return $query->whereIn('category_id', Category::descendants($categoryId));
        }
        return $query->where('category_id', $categoryId);
    }

    // Filter dengan callback — untuk logika kompleks
    public function scopeWhereHasTag($query, string $tag)
    {
        return $query->whereHas('tags', fn($q) => $q->where('name', $tag));
    }

    // Sortir terbaru
    public function scopeLatest($query)
    {
        return $query->orderBy('created_at', 'desc');
    }
}
```

```php
<?php
// Penggunaan di Controller
use App\Models\Product;

class ProductController extends Controller
{
    public function index(Request $request)
    {
        $products = Product::query()
            ->when($request->discounted, fn($q) => $q->discounted())
            ->when($request->min_price, fn($q) => $q->priceRange($request->min_price, $request->max_price))
            ->when($request->category, fn($q) => $q->byCategory($request->category))
            ->latest()
            ->paginate(12);

        return view('products.index', compact('products'));
    }
}
```

## Kasus Penggunaan Nyata
Filter pencarian produk dengan banyak kriteria, scope untuk status (active, pending, archived), scope untuk relasi (hasComments, popularThisWeek), dan filter tanggal.
