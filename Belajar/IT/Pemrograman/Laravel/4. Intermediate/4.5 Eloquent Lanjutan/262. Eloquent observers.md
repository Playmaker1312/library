# 262. Eloquent Observers

## Definisi Singkat
Observer adalah class yang mengelompokkan semua event listener (creating, created, updating, updated, dll) untuk satu model, menjaga kode tetap rapi dan terorganisir.

## Analogi
Seperti dashboard monitoring bandara yang menampilkan semua status penerbangan dalam satu layar — daripada mengecek satu per satu, semua informasi tersedia di satu tempat.

## Poin-Poin Penting
- Mengganti event closure di `booted()` dengan class terpisah
- Method observer otomatis terpanggil sesuai event
- Bisa dibuat dengan Artisan: `php artisan make:observer PostObserver`
- Daftarkan di ServiceProvider
- Method yang tersedia: `retrieved`, `creating`, `created`, `updating`, `updated`, `saving`, `saved`, `deleting`, `deleted`, `restored`, `forceDeleted`

## Contoh Kode
```php
<?php

namespace App\Observers;

use App\Models\Post;
use Illuminate\Support\Facades\Log;

class PostObserver
{
    public function creating(Post $post): void
    {
        // Generate slug otomatis
        $post->slug = str()->slug($post->title);
    }

    public function created(Post $post): void
    {
        // Kirim notifikasi ke admin
        Log::info("Post baru dibuat: {$post->title}");
    }

    public function updating(Post $post): void
    {
        // Cegah perubahan jika sudah dipublikasikan
        if ($post->is_published && $post->isDirty('title')) {
            Log::warning("Percobaan ubah judul post publik: {$post->id}");
        }
    }

    public function updated(Post $post): void
    {
        // Log perubahan
        Log::info("Post {$post->id} diupdate", $post->getChanges());
    }

    public function deleting(Post $post): void
    {
        // Hapus komentar terkait
        $post->comments()->delete();
    }

    public function deleted(Post $post): void
    {
        Log::info("Post {$post->id} dihapus");
    }

    public function restored(Post $post): void
    {
        $post->comments()->restore();
    }

    public function forceDeleted(Post $post): void
    {
        $post->comments()->forceDelete();
    }
}
```

## Kasus Penggunaan Nyata
Logging aktivitas model, menjaga relasi tetap konsisten, generate slug/kode unik, sinkronisasi data cache, dan trigger notifikasi.
