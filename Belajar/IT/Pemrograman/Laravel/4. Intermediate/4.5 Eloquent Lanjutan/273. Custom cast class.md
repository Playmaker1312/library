# 273. Custom Cast Class

## Definisi Singkat
Custom cast adalah class buatan sendiri yang mengimplementasikan `CastsAttributes` untuk mengubah tipe data atribut dengan logika yang tidak bisa ditangani built-in cast.

## Analogi
Seperti membuat mesin konversi mata uang khusus — tidak hanya mengubah angka ke teks, tapi juga menghitung kurs, pajak, dan biaya administrasi sesuai aturan bisnis Anda.

## Poin-Poin Penting
- Buat: `php artisan make:cast NamaCast`
- Implement interface `CastsAttributes`
- Method `get()` — konversi dari DB ke PHP
- Method `set()` — konversi dari PHP ke DB
- Daftarkan di method `casts()` model seperti cast biasa
- Bisa menerima parameter dari definisi cast

## Contoh Kode
```bash
php artisan make:cast MoneyCast
php artisan make:cast JsonToModelCast
```

```php
<?php

namespace App\Casts;

use Illuminate\Contracts\Database\Eloquent\CastsAttributes;
use Illuminate\Database\Eloquent\Model;

class MoneyCast implements CastsAttributes
{
    // Dari database ke model — konversi sen ke rupiah
    public function get(Model $model, string $key, mixed $value, array $attributes): float
    {
        // Nilai di database disimpan dalam sen (integer)
        return $value / 100;
    }

    // Dari model ke database — konversi rupiah ke sen
    public function set(Model $model, string $key, mixed $value, array $attributes): int
    {
        return (int) round($value * 100);
    }
}
```

```php
<?php

namespace App\Casts;

use Illuminate\Contracts\Database\Eloquent\CastsAttributes;
use Illuminate\Database\Eloquent\Model;

class Lowercase implements CastsAttributes
{
    public function get(Model $model, string $key, mixed $value, array $attributes): string
    {
        return $value;
    }

    public function set(Model $model, string $key, mixed $value, array $attributes): string
    {
        return strtolower($value); // otomatis lowercase saat simpan
    }
}
```

```php
<?php

namespace App\Models;

use App\Casts\MoneyCast;
use App\Casts\Lowercase;
use Illuminate\Database\Eloquent\Model;

class Product extends Model
{
    protected function casts(): array
    {
        return [
            'price'    => MoneyCast::class,     // custom cast
            'sku'      => Lowercase::class,      // otomatis lowercase
            'status'   => ProductStatus::class,  // enum cast
        ];
    }
}
```

## Kasus Penggunaan Nyata
Penyimpanan harga dalam sen (integer) untuk menghindari error floating point, otomatis format teks tertentu, validasi nilai saat set, dan transformasi data kompleks antara DB dan aplikasi.
