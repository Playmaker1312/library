# 267. Global Scope Semua Query

## Definisi Singkat
Global scope ditambahkan di method `booted()` model dan secara otomatis diterapkan ke SEMUA query model itu tanpa perlu dipanggil manual.

## Analogi
Seperti aturan "hanya karyawan aktif yang muncul di daftar gaji" — aturan ini otomatis berlaku setiap kali Anda membuka daftar gaji, tanpa perlu filter manual setiap saat.

## Poin-Poin Penting
- Ditambahkan di `booted()` dengan `addGlobalScope()`
- Bisa berupa closure atau class terpisah
- Mempengaruhi semua query: `get()`, `find()`, `count()`, `paginate()`, dll
- Untuk mengecualikan, gunakan `withoutGlobalScope()`
- `SoftDeletes` trait menggunakan global scope

## Contoh Kode
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Post extends Model
{
    protected static function booted(): void
    {
        // Global scope dengan closure
        static::addGlobalScope('active', function ($query) {
            $query->where('is_active', true);
        });

        // Global scope — urutkan berdasarkan tanggal terbaru
        static::addGlobalScope('order', function ($query) {
            $query->orderByDesc('created_at');
        });
    }
}
```

```php
<?php
// Semua query otomatis memiliki where is_active = true
// dan order by created_at desc

// Query ini:
$posts = Post::all();
// SELECT * FROM posts WHERE is_active = true ORDER BY created_at DESC

// Query ini juga:
$post = Post::find(1);
// SELECT * FROM posts WHERE id = 1 AND is_active = true ORDER BY created_at DESC

$recent = Post::where('views', '>', 100)->get();
// SELECT * FROM posts WHERE views > 100 AND is_active = true ORDER BY created_at DESC
```

```php
<?php
// Untuk mengecualikan global scope
$allPosts = Post::withoutGlobalScope('active')->get();
$allPosts = Post::withoutGlobalScopes()->get(); // semua global scope dihapus
```

## Kasus Penggunaan Nyata
Soft delete (hanya tampilkan yang tidak dihapus), multi-tenant (filter berdasarkan tenant_id), published/unpublished content, dan archived records.
