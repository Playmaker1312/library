# 261. Eloquent Events creating created updating updated deleting deleted

## Definisi Singkat
Eloquent events adalah event yang di-trigger saat operasi CRUD pada model: `creating` (sebelum insert), `created` (setelah insert), `updating`, `updated`, `deleting`, `deleted`, `saving`, `saved`, `retrieved`.

## Analogi
Seperti sensor di setiap langkah produksi di pabrik: sensor ON (creating) saat mesin mulai, sensor OFF (created) saat produk jadi, sensor CEK (updating) saat perbaikan, dan seterusnya.

## Poin-Poin Penting
- `retrieved` — setelah data diambil dari database
- `creating` — sebelum record baru disimpan
- `created` — setelah record baru disimpan
- `updating` — sebelum record diupdate
- `updated` — setelah record diupdate
- `saving` / `saved` — untuk create dan update
- `deleting` — sebelum record dihapus
- `deleted` — setelah record dihapus
- `restoring` / `restored` — untuk soft delete
- Bisa return `false` untuk membatalkan operasi

## Contoh Kode
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Post extends Model
{
    protected static function booted(): void
    {
        // Sebelum membuat — return false untuk batalkan
        static::creating(function (Post $post) {
            if ($post->title === 'terlarang') {
                return false; // batalkan penyimpanan
            }
        });

        // Setelah dibuat — generate slug atau log
        static::created(function (Post $post) {
            $post->slug = str()->slug($post->title) . '-' . $post->id;
            $post->saveQuietly(); // save tanpa trigger event
        });

        // Sebelum update — log perubahan
        static::updating(function (Post $post) {
            if ($post->isDirty('title')) {
                Log::info("Post {$post->id} mengubah judul");
            }
        });

        // Setelah dihapus — kirim notifikasi
        static::deleted(function (Post $post) {
            Log::info("Post {$post->id} telah dihapus");
        });
    }
}
```

## Kasus Penggunaan Nyata
Generate slug otomatis, logging aktivitas, validasi tambahan, sinkronisasi data terkait, dan kirim notifikasi saat data berubah.
