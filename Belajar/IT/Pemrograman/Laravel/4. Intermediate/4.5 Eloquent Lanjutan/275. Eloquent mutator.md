# 275. Eloquent Mutator

## Definisi Singkat
Mutator adalah method di model Eloquent yang memformat atau memodifikasi nilai atribut SEBELUM disimpan ke database.

## Analogi
Seperti mesin stamping otomatis di pabrik — sebelum produk masuk ke gudang (database), mesin memberi stempel tanggal, nomor batch, dan label sesuai standar.

## Poin-Poin Penting
- Laravel 9+: method `namaAtribut()` dengan `Attribute::make(set: ...)`
- Laravel lama: method `setNamaAttribute($value)`
- Setter menerima nilai input dan harus mengembalikan nilai yang akan disimpan
- Bisa digabung dengan accessor dalam satu method Attribute
- Sering digunakan untuk hash password, slug, format nomor

## Contoh Kode
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Casts\Attribute;
use Illuminate\Support\Facades\Hash;

class User extends Model
{
    // Mutator + Accessor dalam satu method (Laravel 9+)
    protected function password(): Attribute
    {
        return Attribute::make(
            // Accessor — jangan expose password
            get: fn(mixed $value) => '***',   // tidak pernah tampilkan password

            // Mutator — hash otomatis sebelum simpan
            set: fn(mixed $value) => Hash::make($value),
        );
    }

    // Mutator untuk slug
    protected function title(): Attribute
    {
        return Attribute::make(
            set: fn(mixed $value) => [
                'title' => $value,
                'slug'  => str()->slug($value),
            ],
        );
    }

    // Mutator untuk format nomor telepon
    protected function phone(): Attribute
    {
        return Attribute::make(
            set: fn(mixed $value) => preg_replace('/[^0-9]/', '', $value),
        );
    }

    // Mutator — email selalu lowercase
    protected function email(): Attribute
    {
        return Attribute::make(
            set: fn(mixed $value) => strtolower(trim($value)),
        );
    }
}
```

```php
<?php
// Cara pakai — nilai otomatis ditransformasi sebelum simpan
$user = new User();
$user->password = 'secret123';   // otomatis di-hash
$user->email = 'JOHN@EXAMPLE.COM'; // otomatis lowercase
$user->phone = '0812-3456-7890';   // otomatis jadi 081234567890
$user->title = 'Hello World';      // title disimpan, slug = 'hello-world'
$user->save();
```

```php
<?php
// Laravel lama — method setNamaAttribute
public function setPasswordAttribute($value)
{
    $this->attributes['password'] = Hash::make($value);
}

public function setEmailAttribute($value)
{
    $this->attributes['email'] = strtolower(trim($value));
}
```

## Kasus Penggunaan Nyata
Hash password otomatis, generate slug dari title, format nomor telepon konsisten, lowercase email, enkripsi data sensitif, dan sanitasi input HTML.
