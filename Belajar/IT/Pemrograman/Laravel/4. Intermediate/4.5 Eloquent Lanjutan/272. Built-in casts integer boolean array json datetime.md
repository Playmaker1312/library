# 272. Built-in Casts integer boolean array json datetime

## Definisi Singkat
Laravel menyediakan built-in casts untuk tipe data umum: `integer`, `boolean`, `array`, `json` (sama dengan `array`), `datetime`, `float`, `string`, `object`, `collection`, `encrypted`, dan `timestamp`.

## Analogi
Seperti sakelar lampu — ada beberapa posisi: ON (boolean), angka (integer), timer (datetime), dan mode (string). Setiap posisi memberikan perilaku yang berbeda.

## Poin-Poin Penting
- **`boolean`**: simpan sebagai `0/1` di DB, akses sebagai `true/false`
- **`integer`**: konversi ke integer PHP
- **`float`**: konversi ke float PHP
- **`string`**: konversi ke string
- **`array`**: JSON di DB → array PHP
- **`json`**: sama dengan array (JSON → array)
- **`object`**: JSON di DB → stdClass
- **`collection`**: JSON di DB → Collection
- **`datetime`**: string DB → Carbon instance
- **`timestamp`**: Unix timestamp → Carbon
- **`encrypted`**: enkripsi/dekripsi otomatis

## Contoh Kode
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class User extends Model
{
    protected function casts(): array
    {
        return [
            'is_active'     => 'boolean',      // true / false
            'age'           => 'integer',       // integer
            'balance'       => 'float',         // float
            'bio'           => 'string',        // string
            'metadata'      => 'array',         // JSON → array
            'preferences'   => 'json',          // JSON → array (sama)
            'config'        => 'object',        // JSON → stdClass
            'roles'         => 'collection',    // JSON → Collection
            'email_verified_at' => 'datetime',  // → Carbon
            'last_login'    => 'datetime:Y-m-d H:i:s', // format kustom
            'created_at'    => 'datetime',
            'birthday'      => 'date:Y-m-d',    // hanya tanggal
            'ssn'           => 'encrypted',     // encrypt di DB
            'views_count'   => 'integer:default=0', // default 0
        ];
    }
}
```

```php
<?php
// Penggunaan
$user = User::find(1);

// boolean
if ($user->is_active) { /* true/false */ }

// array dari JSON — iterate langsung
foreach ($user->metadata as $key => $value) { }

// Collection — bisa panggil method Collection
$user->roles->pluck('name');

// Carbon — method tanggal
echo $user->email_verified_at->diffForHumans();

// encrypted — otomatis decrypt
echo $user->ssn; // tampil sebagai plain text
```

## Kasus Penggunaan Nyata
Semua aplikasi Laravel menggunakan casts — `boolean` untuk status, `array`/`json` untuk data dinamis, `datetime` untuk timestamp, `encrypted` untuk data sensitif seperti nomor KTP atau token.
