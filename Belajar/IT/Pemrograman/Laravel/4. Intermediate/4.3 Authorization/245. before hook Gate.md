# 245. before hook Gate

## Definisi Singkat
`Gate::before()` adalah hook yang dijalankan SEBELUM semua Gate check, memungkinkan logika global seperti super admin atau blacklist.

## Analogi
Seperti pos pemeriksaan pertama di pintu gerbang kompleks — sebelum masuk ke lingkungan, semua orang dicek dulu di sini. Jika lolos dari sini, baru masuk ke pos per pos berikutnya.

## Poin-Poin Penting
- `Gate::before(callback)` — jalankan sebelum Gate manapun
- Callback: `fn($user, $ability) => ?bool`
- Return `true` → izin diberikan (lolos)
- Return `false` → izin ditolak
- Return `null` → lanjut ke Gate spesifik (default)
- `Gate::after()` — jalankan setelah Gate check (tidak mengubah hasil)

## Contoh Kode
```php
<?php

// AppServiceProvider.php
use Illuminate\Support\Facades\Gate;
use App\Models\User;

public function boot(): void
{
    // before — super admin lolos semua
    Gate::before(function (User $user) {
        if ($user->role === 'super-admin') {
            return true;
        }
    });

    // before — banned user ditolak semua
    Gate::before(function (User $user) {
        if ($user->is_banned) {
            return false; // ditolak
        }
    });

    // after — log setiap akses (tidak mengubah hasil)
    Gate::after(function (User $user, string $ability, ?bool $result) {
        Log::info("User {$user->id} mencoba {$ability}: " . ($result ? 'diizinkan' : 'ditolak'));
    });
}

// Gate biasa — hanya untuk non-super-admin dan non-banned
Gate::define('edit-post', fn(User $user, Post $post) => $user->id === $post->user_id);
```

## Kasus Penggunaan Nyata
Super admin, banned/blocked user, logging audit semua akses, maintenance mode yang membatasi akses non-admin, dan blacklist IP atau fitur.
