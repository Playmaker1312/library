# 235. Gate Controller Blade

## Definisi Singkat
Gate dapat digunakan di Controller (melalui `Gate::authorize()`) dan di Blade (melalui direktif `@can`) untuk mengontrol akses di kedua layer.

## Analogi
Seperti rambu "Khusus Karyawan" yang terlihat jelas di pintu (Blade) dan juga ada penjaga yang memeriksa di belakang (Controller) — keamanan berlapis.

## Poin-Poin Penting
- **Controller**: `$this->authorize('aksi', $model)` atau `Gate::authorize()`
- **Blade**: `@can('aksi', $model)` dan `@cannot('aksi', $model)`
- **Blade**: `@canany(['aksi1', 'aksi2'])` untuk multiple
- Gate `authorize()` lempar `AuthorizationException` (403)
- Blade directive hanya untuk UI — tetap perlu proteksi di Controller

## Contoh Kode
```php
<?php

// Controller — proteksi dengan authorize
namespace App\Http\Controllers;

use App\Models\Post;
use Illuminate\Http\Request;

class PostController extends Controller
{
    public function edit(Post $post)
    {
        $this->authorize('update', $post);
        return view('posts.edit', compact('post'));
    }
}
```

```blade
{{-- Blade — tampilkan tombol hanya jika diizinkan --}}
@can('update', $post)
    <a href="{{ route('posts.edit', $post) }}">Edit</a>
@endcan

@can('delete', $post)
    <form method="POST" action="{{ route('posts.destroy', $post) }}">
        @csrf @method('DELETE')
        <button type="submit">Hapus</button>
    </form>
@endcan

@cannot('update', $post)
    <p>Anda tidak dapat mengedit postingan ini.</p>
@endcannot

@canany(['create', 'update'], $post)
    <p>Anda bisa membuat atau mengedit.</p>
@endcanany
```

## Kasus Penggunaan Nyata
Tombol edit/hapus hanya muncul untuk pemilik postingan, menu admin hanya untuk admin, dan perlindungan ganda (UI + Controller) untuk keamanan.
