# 231. Autentikasi vs Otorisasi

## Definisi Singkat
Autentikasi adalah proses memverifikasi "siapa Anda" (login). Otorisasi adalah proses menentukan "apa yang boleh Anda lakukan" (izin akses).

## Analogi
Autentikasi seperti menunjukkan KTP di pintu masuk gedung — petugas memastikan Anda adalah orang yang Anda klaim. Otorisasi seperti lanyard warna-warna — merah hanya boleh lantai 1, biru semua lantai.

## Poin-Poin Penting
| Aspek | Autentikasi | Otorisasi |
|-------|-------------|-----------|
| **Pertanyaan** | Siapa kamu? | Apa yang boleh kamu lakukan? |
| **Mekanisme** | Login, password, 2FA | Gate, Policy, Role |
| **Laravel** | Auth facade, middleware `auth` | `Gate`, `Policy`, `@can` |
| **Hasil Gagal** | Redirect ke login (401) | 403 Forbidden |
| **Ketergantungan** | Mandiri (tidak butuh otorisasi) | Butuh autentikasi dulu |

## Contoh Kode
```php
<?php

use Illuminate\Support\Facades\Auth;
use Illuminate\Support\Facades\Gate;

// Autentikasi — siapa Anda?
if (Auth::check()) {
    // User login
}

// Otorisasi — apa yang boleh?
if (Gate::allows('update-post', $post)) {
    // User boleh edit post ini
}

// Kombinasi
if (Auth::check() && Gate::allows('delete', $post)) {
    $post->delete();
}
```

## Kasus Penggunaan Nyata
**Autentikasi**: login/register. **Otorisasi**: admin boleh hapus postingan, editor boleh edit, viewer hanya lihat. Keduanya selalu digunakan bersamaan di aplikasi nyata.
