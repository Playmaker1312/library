# 242. RBAC Sederhana

## Definisi Singkat
RBAC (Role-Based Access Control) sederhana di Laravel bisa diimplementasikan menggunakan Gate atau Policy dengan kolom `role` di tabel users, tanpa package tambahan.

## Analogi
Seperti lanyard warna di kantor: merah = direktur, biru = manager, hijau = staff. Setiap warna punya akses ke ruangan tertentu.

## Poin-Poin Penting
- Tambahkan kolom `role` (string) di tabel users
- Definisikan Gate berdasarkan role
- Buat helper methods di model User untuk pengecekan role
- Cocok untuk sistem dengan role terbatas (2-5 role)
- Untuk role yang kompleks, gunakan Spatie Laravel Permission

## Contoh Kode
```php
<?php

namespace App\Models;

use Illuminate\Foundation\Auth\User as Authenticatable;

class User extends Authenticatable
{
    public function hasRole(string $role): bool
    {
        return $this->role === $role;
    }

    public function hasAnyRole(array $roles): bool
    {
        return in_array($this->role, $roles);
    }

    public function isAdmin(): bool
    {
        return $this->role === 'admin';
    }

    public function isEditor(): bool
    {
        return $this->role === 'editor';
    }
}
```

```php
<?php

// AppServiceProvider.php
use Illuminate\Support\Facades\Gate;
use App\Models\User;

public function boot(): void
{
    Gate::define('admin', fn(User $user) => $user->hasRole('admin'));
    Gate::define('editor', fn(User $user) => $user->hasAnyRole(['admin', 'editor']));
    Gate::define('viewer', fn(User $user) => true); // semua user login
}

// Controller
class AdminController extends Controller
{
    public function index()
    {
        Gate::authorize('admin');
        return view('admin.dashboard');
    }
}
```

```blade
@can('admin')
    <a href="/admin">Panel Admin</a>
@endcan
@can('editor')
    <a href="/editor">Panel Editor</a>
@endcan
```

## Kasus Penggunaan Nyata
Aplikasi internal dengan role Admin, Manager, Staff; portal berita dengan Admin, Editor, Writer; aplikasi sekolah dengan Admin, Guru, Siswa.
