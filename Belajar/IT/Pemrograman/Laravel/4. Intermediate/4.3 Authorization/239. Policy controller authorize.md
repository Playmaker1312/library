# 239. Policy Controller authorize

## Definisi Singkat
`$this->authorize()` di Controller memanggil method Policy yang sesuai secara otomatis berdasarkan model, atau `authorizeResource()` untuk semua method CRUD.

## Analogi
Seperti manajer yang mendelegasikan keputusan ke手下 — Anda cukup bilang "periksa apakah ini boleh" dan手下 yang hafal aturan akan menjawab.

## Poin-Poin Penting
- `$this->authorize('update', $post)` — panggil method `update` di PostPolicy
- `$this->authorizeResource(Post::class)` — otomatis untuk semua method
- `authorizeResource` memetakan method Controller ke method Policy
- Jika tidak diizinkan, lempar `AuthorizationException` (403)
- Bisa digunakan di `__construct` atau per method

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use App\Models\Post;
use App\Http\Requests\StorePostRequest;
use App\Http\Requests\UpdatePostRequest;

class PostController extends Controller
{
    public function __construct()
    {
        // Proteksi semua method resource sekaligus
        $this->authorizeResource(Post::class, 'post');
    }

    // Tidak perlu panggil authorize lagi di setiap method
    public function index()
    {
        return Post::all(); // otomatis cek viewAny
    }

    public function show(Post $post)
    {
        return $post; // otomatis cek view
    }

    public function store(StorePostRequest $request)
    {
        return Post::create($request->validated()); // otomatis cek create
    }

    public function update(UpdatePostRequest $request, Post $post)
    {
        $post->update($request->validated()); // otomatis cek update
        return $post;
    }

    public function destroy(Post $post)
    {
        $post->delete(); // otomatis cek delete
        return response()->noContent();
    }
}
```

```php
// Tanpa authorizeResource — manual per method
public function update(Request $request, Post $post)
{
    $this->authorize('update', $post);
    $post->update($request->all());
}
```

## Kasus Penggunaan Nyata
Controller resource untuk model yang memerlukan proteksi akses — ini praktik standar di aplikasi Laravel production.
