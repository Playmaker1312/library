# 234. Gate allows denies check

## Definisi Singkat
`Gate::allows()`, `Gate::denies()`, dan `Gate::check()` adalah method untuk mengecek otorisasi — apakah user diizinkan melakukan suatu aksi.

## Analogi
Seperti petugas yang mengecek lanyard pengunjung: `allows()` = "boleh?", `denies()` = "tidak boleh?", `check()` = "sah?".

## Poin-Poin Penting
- `Gate::allows('aksi', $model)` — true jika diizinkan
- `Gate::denies('aksi', $model)` — true jika ditolak
- `Gate::check('aksi', $model)` — sama dengan allows
- `Gate::any(['aksi1', 'aksi2'], $model)` — true jika salah satu diizinkan
- `Gate::none(...)` — true jika tidak ada yang diizinkan
- `Gate::authorize('aksi', $model)` — lempar exception jika ditolak

## Contoh Kode
```php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use Illuminate\Support\Facades\Gate;
use App\Models\Post;

class PostController extends Controller
{
    public function edit(Post $post)
    {
        // Cek dengan allows / denies
        if (Gate::denies('update-post', $post)) {
            abort(403, 'Anda tidak diizinkan mengedit postingan ini.');
        }

        return view('posts.edit', compact('post'));
    }

    public function update(Request $request, Post $post)
    {
        // authorize() langsung lempar 403 jika gagal
        Gate::authorize('update-post', $post);

        $post->update($request->all());
        return redirect('/posts');
    }

    public function destroy(Post $post)
    {
        // Cek multiple aksi
        if (Gate::any(['delete-post', 'admin'], $post)) {
            $post->delete();
            return redirect('/posts');
        }

        abort(403);
    }
}
```

## Kasus Penggunaan Nyata
Pengecekan izin di Controller sebelum menjalankan aksi, conditional rendering berdasarkan izin, dan proteksi endpoint API dari akses tidak sah.
