# 233. Gate Facade AuthServiceProvider

## Definisi Singkat
Gate didefinisikan menggunakan `Gate` facade di `App\Providers\AuthServiceProvider` (atau `AppServiceProvider` di Laravel 11) dengan method `define()`.

## Analogi
Seperti menulis buku peraturan yang kemudian ditempel di papan pengumuman — semua orang bisa lihat aturan yang berlaku.

## Poin-Poin Penting
- `Gate::define('nama-aksi', callback)` mendaftarkan gate
- Callback menerima `$user` (yang login) dan parameter opsional (misal `$post`)
- Di Laravel 11, tidak ada `AuthServiceProvider` secara default — bisa pakai `AppServiceProvider`
- Atau buat `AuthServiceProvider` sendiri dan daftarkan di `config/app.php`

## Contoh Kode
```php
<?php

// App\Providers\AppServiceProvider.php (Laravel 11)
namespace App\Providers;

use Illuminate\Support\ServiceProvider;
use Illuminate\Support\Facades\Gate;
use App\Models\User;
use App\Models\Post;

class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        // Gate sederhana berdasarkan role
        Gate::define('admin', function (User $user) {
            return $user->role === 'admin';
        });

        // Gate dengan parameter model
        Gate::define('update-post', function (User $user, Post $post) {
            return $user->id === $post->user_id;
        });

        // Gate tanpa user login (opsional)
        Gate::define('maintenance-mode', function (?User $user) {
            return $user?->role === 'admin';
        });
    }
}
```

```php
<?php

// Alternatif: Buat AuthServiceProvider
// php artisan make:provider AuthServiceProvider

namespace App\Providers;

use Illuminate\Foundation\Support\Providers\AuthServiceProvider as ServiceProvider;
use Illuminate\Support\Facades\Gate;

class AuthServiceProvider extends ServiceProvider
{
    protected $policies = [
        Post::class => PostPolicy::class,
    ];

    public function boot(): void
    {
        $this->registerPolicies();

        Gate::define('export-report', function ($user) {
            return $user->role === 'manager';
        });
    }
}
```

## Kasus Penggunaan Nyata
Mendefinisikan izin akses khusus yang tidak terikat model, seperti fitur export, maintenance mode, dan akses ke halaman admin.
