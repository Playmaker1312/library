# 236. Policy Artisan make policy

## Definisi Singkat
Artisan `make:policy` membuat class Policy — class otorisasi yang terorganisir untuk model tertentu, dengan method untuk setiap aksi CRUD.

## Analogi
Seperti membuat map khusus untuk setiap departemen — map HRD berisi aturan HRD, map Keuangan berisi aturan Keuangan, semuanya rapi dan terpisah.

## Poin-Poin Penting
- Perintah: `php artisan make:policy PostPolicy`
- Opsi `--model` otomatis generate method CRUD: `viewAny`, `view`, `create`, `update`, `delete`
- Letak: `app/Policies/`
- Setiap method menerima `User $user` dan model terkait
- Mengembalikan `bool`

## Contoh Kode
```bash
# Buat policy tanpa method default
php artisan make:policy PostPolicy

# Buat policy dengan method CRUD (viewAny, view, create, update, delete, restore, forceDelete)
php artisan make:policy PostPolicy --model=Post
```

```php
<?php

namespace App\Policies;

use App\Models\Post;
use App\Models\User;

class PostPolicy
{
    public function viewAny(User $user): bool
    {
        return true; // semua user bisa lihat daftar
    }

    public function view(User $user, Post $post): bool
    {
        return true; // semua bisa lihat detail
    }

    public function create(User $user): bool
    {
        return $user->role !== 'banned'; // user banned tidak boleh buat
    }

    public function update(User $user, Post $post): bool
    {
        return $user->id === $post->user_id || $user->role === 'admin';
    }

    public function delete(User $user, Post $post): bool
    {
        return $user->id === $post->user_id || $user->role === 'admin';
    }
}
```

## Kasus Penggunaan Nyata
Mengelola otorisasi untuk setiap model di aplikasi: Post, Comment, Product, Order, User — setiap model punya Policy sendiri.
