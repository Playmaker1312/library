# 238. Policy Method viewAny view create update delete

## Definisi Singkat
Policy memiliki method standar untuk operasi CRUD: `viewAny` (daftar), `view` (detail), `create` (buat), `update` (edit), dan `delete` (hapus).

## Analogi
Seperti prosedur standar di bank: lihat saldo (viewAny), lihat mutasi (view), buka rekening (create), ubah data (update), tutup rekening (delete).

## Poin-Poin Penting
- `viewAny(User $user)` — lihat daftar semua resource
- `view(User $user, Model $model)` — lihat detail satu resource
- `create(User $user)` — membuat resource baru
- `update(User $user, Model $model)` — mengedit resource
- `delete(User $user, Model $model)` — menghapus resource
- Method tambahan: `restore`, `forceDelete`
- Parameter $user otomatis di-inject (user login)

## Contoh Kode
```php
<?php

namespace App\Policies;

use App\Models\Post;
use App\Models\User;

class PostPolicy
{
    public function viewAny(User $user): bool
    {
        return $user->role !== 'banned';
    }

    public function view(User $user, Post $post): bool
    {
        return $post->is_published || $user->id === $post->user_id;
    }

    public function create(User $user): bool
    {
        // Hanya user dengan role 'author' atau 'admin' boleh buat posting
        return in_array($user->role, ['author', 'admin']);
    }

    public function update(User $user, Post $post): bool
    {
        return $user->id === $post->user_id && !$post->is_locked;
    }

    public function delete(User $user, Post $post): bool
    {
        return $user->id === $post->user_id || $user->role === 'admin';
    }
}
```

## Kasus Penggunaan Nyata
Controller resource yang menggunakan `$this->authorizeResource()` akan otomatis memanggil method policy sesuai aksi — membuat kode Controller sangat bersih.
