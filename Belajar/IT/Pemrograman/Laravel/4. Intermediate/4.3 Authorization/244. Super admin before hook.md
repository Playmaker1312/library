# 244. Super Admin before hook

## Definisi Singkat
Before hook di Gate atau Policy memberikan izin penuh (lolos semua pemeriksaan) untuk role super admin tanpa harus mengecek permission spesifik.

## Analogi
Seperti kunci master gedung — satu kunci bisa buka semua pintu, tanpa perlu punya kunci khusus untuk setiap ruangan.

## Poin-Poin Penting
- Didefinisikan dengan `Gate::before()` di ServiceProvider
- Callback menerima `$user` dan mengembalikan `true` untuk izin penuh
- Jika mengembalikan `null`, fallback ke Gate/Policy normal
- `Gate::after()` juga tersedia untuk aksi setelah pengecekan
- Bisa juga didefinisikan di Policy sebagai method `before()`

## Contoh Kode
```php
<?php

// App\Providers\AppServiceProvider.php
use Illuminate\Support\Facades\Gate;
use App\Models\User;

public function boot(): void
{
    // Super admin — semua aksi diizinkan
    Gate::before(function (User $user) {
        if ($user->role === 'super-admin') {
            return true; // lolos semua Gate
        }
        // return null — fallback ke aturan normal
    });

    // Gate biasa — hanya dicek jika bukan super admin
    Gate::define('edit-post', function (User $user, Post $post) {
        return $user->id === $post->user_id;
    });
}
```

```php
<?php

// Di Policy — method before() berlaku untuk semua method policy ini
namespace App\Policies;

use App\Models\User;
use App\Models\Post;

class PostPolicy
{
    public function before(User $user): ?bool
    {
        if ($user->role === 'super-admin') {
            return true;
        }
        return null;
    }

    public function update(User $user, Post $post): bool
    {
        return $user->id === $post->user_id;
    }
}
```

## Kasus Penggunaan Nyata
Aplikasi dengan role super admin yang memiliki akses tak terbatas, seperti owner aplikasi, developer, atau administrator sistem.
