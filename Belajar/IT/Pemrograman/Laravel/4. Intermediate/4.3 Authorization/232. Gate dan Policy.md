# 232. Gate dan Policy

## Definisi Singkat
Gate dan Policy adalah dua mekanisme otorisasi di Laravel. **Gate** bersifat Closure-based (sederhana), **Policy** adalah class khusus untuk model (lebih terstruktur).

## Analogi
**Gate** seperti保安 kampung yang hafal semua aturan di kepalanya — praktis untuk aturan sederhana. **Policy** seperti buku peraturan resmi di kantor — terdokumentasi dan terstruktur per departemen.

## Poin-Poin Penting
- **Gate**: cocok untuk aksi non-model (admin panel, feature flags)
- **Policy**: cocok untuk CRUD model (PostPolicy, CommentPolicy)
- Gate didefinisikan di `AppServiceProvider` pakai `Gate::define()`
- Policy dibuat dengan Artisan dan didaftarkan
- Keduanya bisa digunakan di Blade, Controller, dan Middleware

## Contoh Kode
```php
<?php

// Gate — definisi di AppServiceProvider
use Illuminate\Support\Facades\Gate;

public function boot(): void
{
    Gate::define('access-admin', function ($user) {
        return $user->role === 'admin';
    });

    Gate::define('edit-post', function ($user, Post $post) {
        return $user->id === $post->user_id;
    });
}
```

```php
<?php

// Policy — class khusus untuk model Post
namespace App\Policies;

use App\Models\Post;
use App\Models\User;

class PostPolicy
{
    public function update(User $user, Post $post): bool
    {
        return $user->id === $post->user_id;
    }

    public function delete(User $user, Post $post): bool
    {
        return $user->id === $post->user_id || $user->role === 'admin';
    }
}
```

## Kasus Penggunaan Nyata
**Gate**: akses ke halaman admin, fitur ekspor data. **Policy**: siapa yang boleh edit/hapus artikel tertentu, komentar tertentu.
