# 243. Spatie Laravel Permission

## Definisi Singkat
Spatie Laravel Permission adalah package pihak ketiga paling populer untuk manajemen role dan permission, menyediakan sistem RBAC lengkap dengan tabel pivot.

## Analogi
Seperti sistem keamanan gedung pencakar langit — ada ribuan kunci (permissions) yang bisa diatur per orang (user) atau per jabatan (role), dengan hierarki yang terstruktur.

## Poin-Poin Penting
- Install: `composer require spatie/laravel-permission`
- Publikasi config dan migration: `php artisan vendor:publish`
- Migrasi membuat tabel: `roles`, `permissions`, `model_has_roles`, `model_has_permissions`, `role_has_permissions`
- Trait `HasRoles` ditambahkan ke model User
- Method: `givePermissionTo()`, `assignRole()`, `hasRole()`, `hasPermissionTo()`
- Bisa atur permission per role atau langsung per user

## Contoh Kode
```php
<?php

namespace App\Models;

use Illuminate\Foundation\Auth\User as Authenticatable;
use Spatie\Permission\Traits\HasRoles;

class User extends Authenticatable
{
    use HasRoles;

    // ... property, casts, dll
}
```

```php
<?php

use Spatie\Permission\Models\Role;
use Spatie\Permission\Models\Permission;
use App\Models\User;

// Buat role dan permission (biasanya di seeder)
$admin = Role::create(['name' => 'admin']);
$editor = Role::create(['name' => 'editor']);

Permission::create(['name' => 'create posts']);
Permission::create(['name' => 'edit posts']);
Permission::create(['name' => 'delete posts']);
Permission::create(['name' => 'publish posts']);

// Assign permission ke role
$admin->givePermissionTo(Permission::all());
$editor->givePermissionTo(['create posts', 'edit posts']);

// Assign role ke user
$user = User::find(1);
$user->assignRole('admin');

// Cek permission
if ($user->hasPermissionTo('delete posts')) {
    // boleh hapus
}

if ($user->hasRole('admin')) {
    // adalah admin
}

// Gate otomatis — panggil via @can atau Gate
Gate::authorize('create posts');
```

```blade
@can('create posts')
    <a href="{{ route('posts.create') }}">Buat Post Baru</a>
@endcan
```

## Kasus Penggunaan Nyata
Aplikasi enterprise dengan puluhan role dan ratusan permission, aplikasi multi-tenant, dan sistem yang membutuhkan manajemen akses granular yang bisa dikonfigurasi dari UI.
