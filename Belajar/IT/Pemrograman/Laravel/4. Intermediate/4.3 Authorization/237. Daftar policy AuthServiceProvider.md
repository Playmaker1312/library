# 237. Daftar Policy AuthServiceProvider

## Definisi Singkat
Policy harus didaftarkan di `AuthServiceProvider` pada properti `$policies` agar Laravel bisa secara otomatis menghubungkan model dengan policy-nya.

## Analogi
Seperti mendaftarkan buku panduan di perpustakaan — petugas perlu tahu buku mana yang ada di rak mana agar bisa mencarikan untuk pengunjung.

## Poin-Poin Penting
- Properti `$policies` berisi array `Model::class => Policy::class`
- Di Laravel 11, buat `AuthServiceProvider` sendiri jika perlu
- Panggil `$this->registerPolicies()` di method `boot()`
- Alternatif: registrasi otomatis dengan `Gate::guessPolicyNamesUsing()`
- Tanpa registrasi, policy tidak akan ditemukan

## Contoh Kode
```php
<?php

namespace App\Providers;

use App\Models\Post;
use App\Models\Comment;
use App\Models\Product;
use App\Policies\PostPolicy;
use App\Policies\CommentPolicy;
use App\Policies\ProductPolicy;
use Illuminate\Foundation\Support\Providers\AuthServiceProvider as ServiceProvider;
use Illuminate\Support\Facades\Gate;

class AuthServiceProvider extends ServiceProvider
{
    protected $policies = [
        Post::class    => PostPolicy::class,
        Comment::class => CommentPolicy::class,
        Product::class => ProductPolicy::class,
    ];

    public function boot(): void
    {
        $this->registerPolicies();

        // Gate tambahan di sini
        Gate::define('export-products', function ($user) {
            return $user->role === 'admin';
        });
    }
}
```

```php
// config/app.php — daftarkan provider (jika perlu)
'providers' => [
    // ...
    App\Providers\AuthServiceProvider::class,
    // ...
],
```

```php
// Atau registrasi otomatis berdasarkan konvensi (Laravel 11+)
// Jika model dan policy mengikuti pola App\Models\X dan App\Policies\XPolicy
// Laravel akan otomatis menemukannya tanpa perlu daftar manual
```

## Kasus Penggunaan Nyata
Menghubungkan model Post dengan PostPolicy, model Comment dengan CommentPolicy, dan seterusnya — diperlukan agar `$this->authorize()` dan `@can()` bekerja otomatis.
