# 260. Kecualikan Route Middleware

## Definisi Singkat
Middleware global bisa dikecualikan untuk route tertentu, misalnya mengecualikan URL webhook dari proteksi CSRF atau mengecualikan halaman publik dari middleware auth.

## Analogi
Seperti pintu darurat yang tidak terkunci — semua pintu lain di gedung terkunci (middleware global), tapi pintu darurat tetap bisa diakses tanpa kunci untuk situasi khusus.

## Poin-Poin Penting
- CSRF exclusion: properti `$except` di `VerifyCsrfToken`
- Di Laravel 11: via `->withMiddleware()->validateCsrfTokens(except: [...])`
- Middleware lain bisa dikecualikan dengan `withoutMiddleware()` method
- `withoutMiddleware()` hanya bekerja untuk route tertentu
- Hati-hati dengan keamanan saat mengecualikan middleware

## Contoh Kode
```php
<?php
// bootstrap/app.php — kecualikan CSRF (Laravel 11)

use Illuminate\Foundation\Configuration\Middleware;

->withMiddleware(function (Middleware $middleware) {
    $middleware->validateCsrfTokens(except: [
        'webhook/stripe',
        'webhook/midtrans',
        'api/*',
        'callback/payment',
    ]);
})
```

```php
<?php
// Laravel sebelumnya — app/Http/Middleware/VerifyCsrfToken.php
namespace App\Http\Middleware;

use Illuminate\Foundation\Http\Middleware\VerifyCsrfToken as Middleware;

class VerifyCsrfToken extends Middleware
{
    protected $except = [
        'stripe/*',
        'api/*',
        'webhook/*',
    ];
}
```

```php
<?php
// routes/web.php — withoutMiddleware untuk route tertentu
use Illuminate\Support\Facades\Route;

// Route ini tidak akan melewati middleware 'auth'
Route::get('/public/info', function () {
    return response()->json(['status' => 'public']);
})->withoutMiddleware('auth');

// Multiple middleware exclusion
Route::post('/webhook/stripe', [WebhookController::class, 'handle'])
    ->withoutMiddleware(['auth', 'csrf']);

// Group tanpa middleware tertenu
Route::withoutMiddleware('auth')->group(function () {
    Route::get('/landing', [LandingController::class, 'index']);
    Route::get('/pricing', [PricingController::class, 'index']);
});
```

## Kasus Penggunaan Nyata
Webhook dari pihak ketiga (Stripe, Midtrans, GitHub) yang tidak mengirim CSRF token, API endpoint yang menggunakan autentikasi sendiri (token/Sanctum), dan halaman publik di aplikasi yang umumnya membutuhkan auth.
