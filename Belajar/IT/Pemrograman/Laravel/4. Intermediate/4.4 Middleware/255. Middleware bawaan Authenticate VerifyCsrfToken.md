# 255. Middleware Bawaan Authenticate VerifyCsrfToken

## Definisi Singkat
Laravel menyediakan middleware bawaan seperti `Authenticate` (auth), `VerifyCsrfToken` (CSRF), `EncryptCookies`, `TrimStrings`, `TrustProxies`, `SubstituteBindings`, dan `PreventRequestsDuringMaintenance`.

## Analogi
Seperti peralatan standar yang sudah ada di dapur rumah baru — kompor (Authenticate), lemari es (CSRF), oven (EncryptCookies), semuanya sudah terpasang dan siap pakai.

## Poin-Poin Penting
- `Authenticate` (`auth`) — cek user login, redirect jika guest
- `VerifyCsrfToken` — proteksi dari serangan CSRF (form wajib @csrf)
- `EncryptCookies` — enkripsi cookie sebelum dikirim
- `TrimStrings` — trim spasi input
- `TrustProxies` — trust proxy untuk load balancer
- `SubstituteBindings` — binding model otomatis di route

## Contoh Kode
```php
<?php

// Middleware Authenticate — menangani redirect jika guest
namespace App\Http\Middleware;

use Illuminate\Auth\Middleware\Authenticate as Middleware;

class Authenticate extends Middleware
{
    protected function redirectTo($request): ?string
    {
        if (!$request->expectsJson()) {
            return route('login');
        }

        return null;
    }
}
```

```php
<?php

// VerifyCsrfToken — kecualikan route dari CSRF
namespace App\Http\Middleware;

use Illuminate\Foundation\Http\Middleware\VerifyCsrfToken as Middleware;

class VerifyCsrfToken extends Middleware
{
    protected $except = [
        'webhook/*',     // route webhook
        'api/register',  // API register
        'stripe/*',      // Striwe webhook
    ];
}
```

```php
<?php
// Laravel 11 — di bootstrap/app.php
->withMiddleware(function (Middleware $middleware) {
    $middleware->validateCsrfTokens(except: [
        '/webhook/*',
    ]);
})
```

## Kasus Penggunaan Nyata
Semua aplikasi Laravel menggunakan middleware ini setiap saat — Authenticate untuk halaman login, VerifyCsrfToken untuk form, dan lainnya sebagai lapisan keamanan dasar.
