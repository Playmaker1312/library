# 258. Middleware Maintenance Mode

## Definisi Singkat
Middleware `PreventRequestsDuringMaintenance` memblokir semua request ketika aplikasi dalam mode maintenance (down for maintenance), menampilkan halaman 503.

## Analogi
Seperti toko yang tutup sementara untuk renovasi — ada papan "Tutup Sementara" di pintu dan tidak ada yang bisa masuk kecuali karyawan tertentu.

## Poin-Poin Penting
- Diaktifkan dengan: `php artisan down`
- Dinonaktifkan dengan: `php artisan up`
- Bypass dengan IP atau secret token: `php artisan down --secret=token`
- Akses via `{url}/{token}` untuk preview
- Bisa kustom halaman 503
- Di Laravel 11, konfigurasi di `bootstrap/app.php`

## Contoh Kode
```bash
# Aktifkan maintenance mode
php artisan down

# Aktifkan dengan pesan kustom
php artisan down --retry=60 --secret=rahasia123

# Akses tetap bisa jalan dengan token
# Kunjungi: https://example.com/rahasia123

# Nonaktifkan
php artisan up
```

```php
<?php
// bootstrap/app.php — kustomisasi maintenance mode
use Illuminate\Foundation\Configuration\Exceptions;

->withExceptions(function (Exceptions $exceptions) {
    $exceptions->render(function (HttpException $e, Request $request) {
        if ($e->getStatusCode() === 503) {
            return response()->view('errors.maintenance', [
                'message' => $e->getMessage() ?: 'Kami sedang dalam perbaikan. Silakan kembali lagi nanti.',
                'retryAfter' => $e->getHeaders()['Retry-After'] ?? 60,
            ], 503);
        }
    });
})
```

```php
{{-- resources/views/errors/503.blade.php --}}
<!DOCTYPE html>
<html>
<head>
    <title>Maintenance</title>
</head>
<body>
    <h1>🚧 Sedang Pemeliharaan</h1>
    <p>Kami sedang melakukan perbaikan. Silakan kembali dalam beberapa saat.</p>
    @if(isset($retryAfter))
        <p>Coba lagi dalam {{ $retryAfter }} detik.</p>
    @endif
</body>
</html>
```

## Kasus Penggunaan Nyata
Saat melakukan deployment dengan perubahan besar, migrasi database yang berat, atau perbaikan server — maintenance mode mencegah data korup dan memberikan informasi jelas ke user.
