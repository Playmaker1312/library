# 248. Metode handle Middleware

## Definisi Singkat
Method `handle()` adalah inti dari middleware — tempat logika filtering ditulis. Ia menerima request dan closure untuk melanjutkan ke middleware/controller berikutnya.

## Analogi
Seperti pos jaga — petugas menerima tamu (request), memeriksa identitas, lalu memutuskan: "silahkan masuk" (`$next($request)`) atau "maaf, tidak boleh" (return response).

## Poin-Poin Penting
- Parameter: `Request $request`, `Closure $next`
- Return `$next($request)` untuk melanjutkan ke next middleware/controller
- Return response langsung untuk menghentikan pipeline
- Bisa mengubah request sebelum dilanjutkan
- `$next($request)` mengembalikan `Response` object

## Contoh Kode
```php
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class CheckUserRole
{
    public function handle(Request $request, Closure $next, string $role): Response
    {
        $user = $request->user();

        // Jika belum login — redirect
        if (!$user) {
            return redirect('/login');
        }

        // Jika role tidak sesuai — 403
        if ($user->role !== $role) {
            return response()->view('errors.403', [
                'message' => 'Anda tidak memiliki akses ke halaman ini.',
            ], 403);
        }

        // Modifikasi request sebelum lanjut
        $request->attributes->set('role_checked', true);

        return $next($request);
    }
}
```

## Kasus Penggunaan Nyata
Pengecekan role/status user, validasi input global, logging waktu eksekusi, kompresi response, dan semua logika filter yang perlu dijalankan sebelum controller.
