# 259. Terminable Middleware

## Definisi Singkat
Terminable middleware memiliki method `terminate()` yang dijalankan SETELAH response dikirim ke browser, berguna untuk tugas background ringan seperti logging atau cleanup.

## Analogi
Seperti petugas kebersihan di gedung bioskop — setelah penonton keluar (response dikirim), petugas membersihkan ruangan. Pembersihan tidak mengganggu penonton yang menonton film.

## Poin-Poin Penting
- Method tambahan: `terminate($request, $response)`
- Dijalankan setelah response dikirim ke client
- Tidak mempengaruhi response (hanya untuk side effects)
- Harus mendaftarkan middleware di container sebagai `singleton` jika ingin persist state
- Berguna untuk logging, cleanup, atau operasi non-blok

## Contoh Kode
```php
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Log;
use Symfony\Component\HttpFoundation\Response;

class TerminableLogger
{
    public function handle(Request $request, Closure $next): Response
    {
        return $next($request);
    }

    // Method terminate — dijalankan SETELAH response dikirim
    public function terminate(Request $request, Response $response): void
    {
        // Log ke file — tidak memperlambat response ke user
        Log::channel('slow_log')->info('Request completed', [
            'url'    => $request->fullUrl(),
            'method' => $request->method(),
            'status' => $response->status(),
            'time'   => now(),
        ]);

        // Atau cleanup temporary files
        if ($request->has('session_id')) {
            // cleanup session temp files
        }
    }
}
```

```php
// Daftarkan secara normal — Laravel otomatis deteksi method terminate
// bootstrap/app.php
->withMiddleware(function (Middleware $middleware) {
    $middleware->append(TerminableLogger::class);
})
```

## Kasus Penggunaan Nyata
Logging ke file atau database tanpa memperlambat response, cleanup file temporary, mengirim notifikasi non-kritis, sinkronisasi data ke layanan eksternal di background.
