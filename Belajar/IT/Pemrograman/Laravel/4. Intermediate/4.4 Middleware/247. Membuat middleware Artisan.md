# 247. Membuat Middleware Artisan

## Definisi Singkat
Artisan `make:middleware` membuat class middleware baru di `app/Http/Middleware/` dengan template method `handle()`.

## Analogi
Seperti membuat filter air baru — Anda tinggal membeli tabung filter (Artisan), lalu mengisi isian filter sesuai kebutuhan.

## Poin-Poin Penting
- Perintah: `php artisan make:middleware NamaMiddleware`
- File dibuat di `app/Http/Middleware/`
- Method `handle($request, Closure $next)` siap diisi
- Setelah dibuat, daftarkan sebagai global, route alias, atau di grup
- Secara default return `$next($request)` — artinya request lolos

## Contoh Kode
```bash
# Buat middleware
php artisan make:middleware LogRequest
php artisan make:middleware EnsureTokenIsValid
php artisan make:middleware CheckUserStatus
```

```php
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class EnsureTokenIsValid
{
    public function handle(Request $request, Closure $next): Response
    {
        if ($request->header('X-API-Key') !== config('app.api_key')) {
            return response()->json(['message' => 'API Key tidak valid'], 401);
        }

        return $next($request);
    }
}
```

## Kasus Penggunaan Nyata
Membuat middleware kustom untuk aplikasi: validasi API key, pengecekan status user, logging request, pembatasan akses berdasarkan domain, dan banyak lagi.
