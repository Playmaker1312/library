# 249. Middleware Global Bootstrap App PHP Laravel 11

## Definisi Singkat
Di Laravel 11, middleware global dikonfigurasi di `bootstrap/app.php` menggunakan method `->withMiddleware()`, berbeda dari Laravel sebelumnya yang menggunakan `Kernel`.

## Analogi
Seperti security perimeter di luar gedung — middleware global berlaku untuk SEMUA route, tidak bisa dipilih-pilih.

## Poin-Poin Penting
- File konfigurasi: `bootstrap/app.php`
- Method `->withMiddleware()` pada Application instance
- Middleware global default: `EncryptCookies`, `AddQueuedCookiesToResponse`, `StartSession`, `ShareErrorsFromSession`, `VerifyCsrfToken`, `SubstituteBindings`
- Bisa tambah middleware global sendiri
- Bisa kecualikan route dari middleware tertentu (CSRF)

## Contoh Kode
```php
<?php
// bootstrap/app.php

use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Exceptions;
use Illuminate\Foundation\Configuration\Middleware;
use App\Http\Middleware\LogRequest;
use App\Http\Middleware\CheckUserStatus;

return Application::configure(basePath: dirname(__DIR__))
    ->withRouting(
        web: __DIR__.'/../routes/web.php',
        // api: __DIR__.'/../routes/api.php',
        commands: __DIR__.'/../routes/console.php',
        health: '/up',
    )
    ->withMiddleware(function (Middleware $middleware) {
        // Tambah middleware global
        $middleware->append(LogRequest::class);

        // Kecualikan route dari CSRF
        $middleware->validateCsrfTokens(except: [
            '/webhook/*',
            '/api/*',
        ]);

        // Alias middleware
        $middleware->alias([
            'role' => \App\Http\Middleware\CheckRole::class,
            'log'  => LogRequest::class,
        ]);

        // Grup middleware
        $middleware->group('api', [
            'throttle:api',
            'auth:sanctum',
        ]);
    })
    ->withExceptions(function (Exceptions $exceptions) {
        // ...
    })->create();
```

## Kasus Penggunaan Nyata
Menambahkan middleware logging untuk semua request, mengecualikan webhook dari CSRF, mendaftarkan alias middleware kustom, dan mengatur grup middleware.
