# 254. After Middleware

## Definisi Singkat
After middleware menjalankan logika SETELAH request diproses oleh Controller, memungkinkan modifikasi response sebelum dikirim ke browser.

## Analogi
Seperti bagian quality control di pabrik — setelah barang jadi (Controller selesai), QC memeriksa dan memberi label/stempel sebelum dikirim ke pelanggan.

## Poin-Poin Penting
- Logika ditulis SETELAH `$response = $next($request)`
- Bisa akses dan modifikasi response object
- Bisa tambah header, kompresi, cache, atau logging
- Class middleware sama — hanya letak kode yang membedakan
- Bisa juga menangani error dari Controller

## Contoh Kode
```php
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class AddCustomHeaders
{
    public function handle(Request $request, Closure $next): Response
    {
        // Request masuk — tidak ada aksi sebelum controller

        $response = $next($request); // ← Controller dieksekusi di sini

        // After middleware — modifikasi response
        $response->headers->set('X-Response-Time', microtime(true) - LARAVEL_START);
        $response->headers->set('X-App-Version', config('app.version'));
        $response->headers->set('X-Frame-Options', 'DENY');

        return $response;
    }
}
```

```php
<?php

namespace App\Http\Middleware;

use Illuminate\Support\Facades\Log;
use Symfony\Component\HttpFoundation\Response;

class LogResponseTime
{
    public function handle($request, Closure $next): Response
    {
        $start = microtime(true);

        $response = $next($request);

        $duration = microtime(true) - $start;
        Log::info("Request {$request->method()} {$request->path()} selesai dalam {$duration} detik");

        return $response;
    }
}
```

## Kasus Penggunaan Nyata
Menambahkan header keamanan, logging waktu eksekusi, kompresi response, cache response, minifikasi HTML, dan formatting response (JSON API).
