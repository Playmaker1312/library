# 256. Middleware Throttle Rate Limiting

## Definisi Singkat
Middleware `throttle` membatasi jumlah request yang bisa dilakukan user dalam periode waktu tertentu, melindungi aplikasi dari penyalahgunaan dan serangan brute force.

## Analogi
Seperti antrian di gerbang tol — maksimal 10 mobil per menit, jika lebih harus menunggu. Ini mencegah kemacetan dan penyalahgunaan jalur.

## Poin-Poin Penting
- Format: `throttle:max_attempts,decay_minutes`
- Contoh: `throttle:60,1` = 60 request per menit
- Bisa nama kustom: `throttle:api` (didefinisikan di `AppServiceProvider`)
- PHP `RateLimiter` facade untuk kustomisasi
- Response 429 (Too Many Requests) jika melebihi batas
- Hitungan per IP atau per user (auth)

## Contoh Kode
```php
<?php

// Route — throttle per route
Route::get('/api/posts', [ApiController::class, 'index'])
    ->middleware('throttle:60,1');

Route::post('/api/contact', [ApiController::class, 'contact'])
    ->middleware('throttle:10,1'); // 10 request per menit
```

```php
<?php

// AppServiceProvider.php — definisi rate limiter kustom
use Illuminate\Cache\RateLimiting\Limit;
use Illuminate\Support\Facades\RateLimiter;

public function boot(): void
{
    RateLimiter::for('api', function (Request $request) {
        return Limit::perMinute(60)->by($request->user()?->id ?: $request->ip());
    });

    RateLimiter::for('login', function (Request $request) {
        return Limit::perMinute(5)->by($request->input('email') . '|' . $request->ip());
    });

    RateLimiter::for('uploads', function (Request $request) {
        // Limit lebih ketat untuk upload
        return Limit::perMinute(5)->by($request->user()->id);
    });
}
```

```php
<?php
// routes/api.php — pakai limiter kustom
Route::middleware('throttle:login')->group(function () {
    Route::post('/login', [AuthController::class, 'login']);
});

Route::middleware('throttle:uploads')->group(function () {
    Route::post('/upload', [UploadController::class, 'store']);
});
```

## Kasus Penggunaan Nyata
API rate limiting, proteksi login brute force, pembatasan upload file, pembatasan akses endpoint publik, dan proteksi dari DDoS.
