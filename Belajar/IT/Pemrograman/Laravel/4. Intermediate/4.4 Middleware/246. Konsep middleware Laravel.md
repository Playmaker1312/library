# 246. Konsep Middleware Laravel

## Definisi Singkat
Middleware adalah lapisan yang memfilter HTTP request sebelum mencapai aplikasi (Controller), dan bisa juga memodifikasi response sebelum dikirim ke client.

## Analogi
Seperti jalur keamanan di bandara — sebelum naik pesawat (Controller), Anda melewati beberapa pos: pemeriksaan tiket (auth), pemeriksaan bagasi (CSRF), pemeriksaan paspor (verified). Setiap pos bisa menolak atau meloloskan.

## Poin-Poin Penting
- Middleware dijalankan dalam pipeline — request melewatinya berurutan
- Bisa global (semua route) atau spesifik per route/group
- Method `handle($request, Closure $next)` memproses request
- Bisa menghentikan request (return response) atau melanjutkan (`$next($request)`)
- Middleware setelah request: modifikasi response sebelum dikirim

## Contoh Kode
```php
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;

class ContohMiddleware
{
    public function handle(Request $request, Closure $next)
    {
        // Sebelum request mencapai controller
        if ($request->user()?->isBanned()) {
            return response('Akun Anda dibanned.', 403);
        }

        $response = $next($request); // lanjut ke controller

        // Setelah response dari controller
        $response->headers->set('X-Powered-By', 'Laravel');

        return $response;
    }
}
```

## Kasus Penggunaan Nyata
Autentikasi, logging request, CORS, maintenance mode, throttle rate limiting, trimming input, kompresi response, dan validasi CSRF — semua diimplementasikan sebagai middleware.
