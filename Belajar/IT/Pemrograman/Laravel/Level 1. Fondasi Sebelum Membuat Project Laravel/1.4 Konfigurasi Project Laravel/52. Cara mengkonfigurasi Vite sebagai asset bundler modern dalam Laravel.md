# 52. Cara Mengkonfigurasi Vite sebagai Asset Bundler Modern dalam Laravel

## Definisi & Target
Vite menggantikan Laravel Mix sebagai bundler aset yang cepat. Target: CSS dan JavaScript ter-build dan termuat di halaman.

## Komponen yang Terlibat
- File ite.config.js
- File esources/js/app.js
- File esources/css/app.css
- Package package.json

## Perintah Artisan CLI
`
npm install
npm run dev
npm run build
`

## Kode Implementasi (Per File)
### vite.config.js
`javascript
import { defineConfig } from 'vite';
import laravel from 'laravel-vite-plugin';

export default defineConfig({
    plugins: [
        laravel({
            input: ['resources/css/app.css', 'resources/js/app.js'],
            refresh: true,
        }),
    ],
});
`

## Cara Integrasi & Pengujian
1. Vite sudah termasuk di Laravel 10+
2. Jalankan 
pm install untuk menginstal dependency
3. Jalankan 
pm run dev untuk development (HMR aktif)
4. Buka browser â€” perubahan CSS/JS otomatis ter-refresh
5. Untuk production: 
pm run build
6. Pastikan @vite() directive ada di layout Blade
7. Jika menggunakan port selain 8000, atuh VITE_PORT di .env
