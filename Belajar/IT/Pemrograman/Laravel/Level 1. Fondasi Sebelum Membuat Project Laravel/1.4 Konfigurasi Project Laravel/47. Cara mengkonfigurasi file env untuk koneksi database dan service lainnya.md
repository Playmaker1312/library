# 47. Cara Mengkonfigurasi File .env untuk Koneksi Database dan Service Lainnya

## Definisi & Target
File .env menyimpan konfigurasi environment-specific seperti database, mail, dan API key. Target: mampu mengatur .env untuk development dan production.

## Komponen yang Terlibat
- File .env
- File config/database.php
- File config/app.php

## Perintah Artisan CLI
`
php artisan config:clear
php artisan config:cache
`

## Kode Implementasi (Per File)
### File .env â€” contoh konfigurasi lengkap
`
APP_NAME=BlogKu
APP_ENV=local
APP_DEBUG=true
APP_URL=http://localhost:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=blog
DB_USERNAME=root
DB_PASSWORD=secret

MAIL_MAILER=smtp
MAIL_HOST=sandbox.smtp.mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=null
MAIL_PASSWORD=null

FILESYSTEM_DISK=local
QUEUE_CONNECTION=database
CACHE_DRIVER=redis
SESSION_DRIVER=file
`

### Mengakses .env di kode
`php
 = env('DB_DATABASE', 'default_db');

// Di config file, gunakan env() hanya di config
// Jangan gunakan env() langsung di Controller
`

## Cara Integrasi & Pengujian
1. File .env tidak dicommit ke Git (ada di .gitignore)
2. Gunakan .env.example sebagai template
3. Setelah mengubah .env jalankan php artisan config:clear
4. Untuk production: php artisan config:cache
5. Jangan gunakan env() langsung di kode bisnis â€” gunakan config()
