# 55. Cara Mengkonfigurasi Queue Connection di File config/queue.php

## Definisi & Target
Queue memproses task berat (email, upload) secara asinkron. Target: task antri dan diproses di background.

## Komponen yang Terlibat
- File config/queue.php
- File .env
- Jobs di pp/Jobs/

## Perintah Artisan CLI
`
php artisan make:job ProcessPayment
php artisan queue:table
php artisan migrate
php artisan queue:work
`

## Kode Implementasi (Per File)
### config/queue.php â€” default connection
`php
'default' => env('QUEUE_CONNECTION', 'database'),

'connections' => [
    'sync' => [
        'driver' => 'sync',
    ],

    'database' => [
        'driver' => 'database',
        'table' => 'jobs',
        'queue' => 'default',
        'retry_after' => 90,
        'after_commit' => true,
    ],

    'redis' => [
        'driver' => 'redis',
        'connection' => 'default',
        'queue' => 'default',
        'retry_after' => 90,
        'block_for' => null,
        'after_commit' => true,
    ],
],
`

### Dispatch Job
`php

`

## Cara Integrasi & Pengujian
1. Set QUEUE_CONNECTION=database atau redis di .env
2. Buat tabel jobs: php artisan queue:table && php artisan migrate
3. Buat job dengan php artisan make:job
4. Dispatch job dari Controller
5. Jalankan worker: php artisan queue:work
6. Lihat log untuk memastikan job diproses
