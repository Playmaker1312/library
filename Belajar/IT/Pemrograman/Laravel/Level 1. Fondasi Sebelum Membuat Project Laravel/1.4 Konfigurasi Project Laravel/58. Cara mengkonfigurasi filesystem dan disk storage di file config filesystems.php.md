# 58. Cara Mengkonfigurasi Filesystem dan Disk Storage di File config/filesystems.php

## Definisi & Target
Filesystem mengelola penyimpanan file lokal dan cloud. Target: file upload tersimpan dan bisa diakses dengan benar.

## Komponen yang Terlibat
- File config/filesystems.php
- File .env
- Storage link (public)

## Perintah Artisan CLI
`
php artisan storage:link
`

## Kode Implementasi (Per File)
### config/filesystems.php
`php
'default' => env('FILESYSTEM_DISK', 'local'),

'disks' => [
    'local' => [
        'driver' => 'local',
        'root' => storage_path('app/private'),
        'serve' => true,
    ],

    'public' => [
        'driver' => 'local',
        'root' => storage_path('app/public'),
        'url' => env('APP_URL').'/storage',
        'visibility' => 'public',
        'serve' => true,
    ],

    's3' => [
        'driver' => 's3',
        'key' => env('AWS_ACCESS_KEY_ID'),
        'secret' => env('AWS_SECRET_ACCESS_KEY'),
        'region' => env('AWS_DEFAULT_REGION'),
        'bucket' => env('AWS_BUCKET'),
        'url' => env('AWS_URL'),
        'endpoint' => env('AWS_ENDPOINT'),
    ],
],
`

## Cara Integrasi & Pengujian
1. Jalankan php artisan storage:link untuk membuat symlink
2. Simpan file dengan $request->file()->store('folder', 'disk')
3. Akses dengan Storage::url()
4. Untuk S3, install: composer require league/flysystem-aws-s3-v3
5. Test upload dan pastikan file muncul di storage/app/public
