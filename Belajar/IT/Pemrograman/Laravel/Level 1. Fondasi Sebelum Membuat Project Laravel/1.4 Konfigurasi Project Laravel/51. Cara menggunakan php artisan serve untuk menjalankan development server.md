# 51. Cara Menggunakan php artisan serve untuk Menjalankan Development Server

## Definisi & Target
php artisan serve menjalankan server development PHP built-in. Target: aplikasi bisa diakses dari browser.

## Komponen yang Terlibat
- File rtisan
- PHP built-in server

## Perintah Artisan CLI
`
php artisan serve
`

### Opsi yang tersedia
`
php artisan serve --port=8080
php artisan serve --host=0.0.0.0
php artisan serve --port=8080 --host=0.0.0.0
`

## Kode Implementasi (Per File)
Tidak ada kode. Server berjalan di terminal.

### Output yang diharapkan
`
Starting Laravel development server...
INFO  Server running on [http://localhost:8000].
Press Ctrl+C to stop the server
`

## Cara Integrasi & Pengujian
1. Pastikan berada di root project Laravel
2. Jalankan php artisan serve
3. Buka browser ke http://localhost:8000
4. Halaman Laravel welcome muncul
5. Untuk port kustom: php artisan serve --port=8080
6. Untuk akses dari perangkat lain (LAN): --host=0.0.0.0
7. Tekan Ctrl+C untuk menghentikan server
8. Catatan: hanya untuk development, bukan production
