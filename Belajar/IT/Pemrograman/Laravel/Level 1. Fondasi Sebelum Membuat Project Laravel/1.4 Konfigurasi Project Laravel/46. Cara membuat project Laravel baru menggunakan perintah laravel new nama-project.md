# 46. Cara Membuat Project Laravel Baru Menggunakan Perintah Laravel New

## Definisi & Target
laravel new membuat project Laravel dengan struktur, konfigurasi, dan starter kit. Target: project baru siap dikembangkan.

## Komponen yang Terlibat
- Laravel Installer (global)
- Folder project baru

## Perintah Artisan CLI
`
laravel new blog
`

### Opsi yang tersedia
`
laravel new blog --jet
laravel new blog --stack=livewire
laravel new blog --stack=react
laravel new blog --dev
`

## Kode Implementasi (Per File)
Setelah perintah dijalankan:
`
cd blog
php artisan serve
`

Akses: http://localhost:8000

## Cara Integrasi & Pengujian
1. Pastikan Laravel Installer terinstal (laravel --version)
2. Jalankan laravel new nama-project
3. Pilih starter kit (atau none untuk vanilla)
4. Pilih database (SQLite default, atau MySQL/PostgreSQL)
5. Masuk ke folder: cd nama-project
6. Jalankan php artisan serve dan buka browser ke localhost:8000
