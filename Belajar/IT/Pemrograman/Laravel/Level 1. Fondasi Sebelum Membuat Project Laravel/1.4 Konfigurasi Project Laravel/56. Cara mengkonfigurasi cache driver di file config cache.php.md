# 56. Cara Mengkonfigurasi Cache Driver di File config/cache.php

## Definisi & Target
Cache menyimpan data sementara untuk mempercepat aplikasi. Target: data yang sering diakses tidak perlu query database berulang.

## Komponen yang Terlibat
- File config/cache.php
- File .env
- Redis atau database untuk cache store

## Perintah Artisan CLI
`
php artisan cache:clear
php artisan config:cache
`

## Kode Implementasi (Per File)
### config/cache.php â€” default
`php
'default' => env('CACHE_DRIVER', 'redis'),

'stores' => [
    'file' => [
        'driver' => 'file',
        'path' => storage_path('framework/cache/data'),
    ],

    'database' => [
        'driver' => 'database',
        'table' => 'cache',
        'connection' => null,
    ],

    'redis' => [
        'driver' => 'redis',
        'connection' => 'cache',
        'lock_connection' => 'default',
    ],
],

'prefix' => env('CACHE_PREFIX', 'blog_cache'),
`

### Penggunaan Cache di Controller
`php
public function index()
{
     = Cache::remember('posts.all', 3600, function () {
        return Post::with('user')->latest()->get();
    });

    return view('posts.index', compact('posts'));
}
`

## Cara Integrasi & Pengujian
1. Set CACHE_DRIVER=redis atau file di .env
2. Redis memberikan performa lebih baik dibanding file
3. Gunakan Cache::remember() untuk cache dengan timeout
4. Cache::forget('key') untuk menghapus cache tertentu
5. php artisan cache:clear untuk membersihkan semua cache
6. Test: akses halaman dua kali â€” load time kedua lebih cepat
