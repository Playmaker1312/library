# 54. Cara Menginstal dan Mengkonfigurasi Alpine.js untuk Interaksi JavaScript Ringan

## Definisi & Target
Alpine.js menyediakan interaktivitas JavaScript minimal tanpa build step complex. Target: dropdown, modal, tabs, dan interaksi lain berfungsi.

## Komponen yang Terlibat
- File esources/js/app.js
- File package.json
- File ite.config.js

## Perintah Artisan CLI
`
npm install alpinejs
`

## Kode Implementasi (Per File)
### resources/js/app.js
`javascript
import Alpine from 'alpinejs';

window.Alpine = Alpine;
Alpine.start();
`

### Contoh penggunaan di Blade
`lade
<div x-data="{ open: false }" class="relative">
    <button @click="open = !open" class="px-4 py-2 bg-blue-500 text-white rounded">
        Menu
    </button>

    <div x-show="open" @click.outside="open = false"
         class="absolute mt-2 w-48 bg-white rounded-md shadow-lg">
        <a href="#" class="block px-4 py-2 hover:bg-gray-100">Profil</a>
        <a href="#" class="block px-4 py-2 hover:bg-gray-100">Pengaturan</a>
        <a href="#" class="block px-4 py-2 hover:bg-gray-100">Logout</a>
    </div>
</div>

<div x-data="{ tab: 'profile' }">
    <button @click="tab = 'profile'" :class="{ 'active': tab === 'profile' }">Profil</button>
    <button @click="tab = 'settings'" :class="{ 'active': tab === 'settings' }">Pengaturan</button>

    <div x-show="tab === 'profile'">Konten Profil</div>
    <div x-show="tab === 'settings'">Konten Pengaturan</div>
</div>
`

## Cara Integrasi & Pengujian
1. Install Alpine: 
pm install alpinejs
2. Import dan start Alpine di resources/js/app.js
3. Pastikan @vite('resources/js/app.js') ada di layout
4. Gunakan x-data, x-show, x-if, @click di Blade
5. Jalankan 
pm run dev dan uji interaktivitas
6. Alpine cocok untuk interaksi ringan tanpa perlu Vue/React penuh
