# 49. Cara Mengkonfigurasi Timezone dan Locale dalam File config/app.php

## Definisi & Target
Timezone menentukan zona waktu aplikasi; locale menentukan bahasa. Target: aplikasi menggunakan waktu dan bahasa yang sesuai.

## Komponen yang Terlibat
