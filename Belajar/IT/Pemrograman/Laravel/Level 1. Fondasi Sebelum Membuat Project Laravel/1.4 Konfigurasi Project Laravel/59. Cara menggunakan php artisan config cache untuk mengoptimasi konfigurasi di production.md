# 59. Cara Menggunakan php artisan config:cache untuk Mengoptimasi Konfigurasi di Production

## Definisi & Target
config:cache menggabungkan semua file konfigurasi menjadi satu file untuk mempercepat loading. Target: aplikasi production lebih cepat karena konfigurasi sudah di-cache.

## Komponen yang Terlibat
- Semua file di folder config/
- File ootstrap/cache/config.php

## Perintah Artisan CLI
`
php artisan config:cache
php artisan config:clear
`

## Kode Implementasi (Per File)
### Cara penggunaan
`ash
# Production â€” cache semua konfigurasi
php artisan config:cache

# Saat mengubah .env, refresh cache
php artisan config:clear
php artisan config:cache

# Hanya clear cache (development)
php artisan config:clear
`

### Penting!
`php
// Setelah config:cache, function env() tidak berfungsi di luar file config
// Selalu gunakan config() helper di Controller/View

// BENAR
 = config('app.timezone');

// SALAH (setelah config:cache)
 = env('APP_TIMEZONE');
`

## Cara Integrasi & Pengujian
1. Sebelum deploy ke production, jalankan php artisan config:cache
2. Semua konfigurasi dari folder config/ digabung menjadi satu file
3. Setelah di-cache, jangan gunakan env() di luar file config
4. Jika mengubah .env di production, jalankan php artisan config:clear lalu php artisan config:cache
5. Jangan jalankan config:cache di development â€” merepotkan saat debugging
