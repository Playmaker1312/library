# 48. Cara Menggunakan php artisan key:generate untuk Membuat Application Key

## Definisi & Target
Application key digunakan untuk enkripsi session dan cookie. Target: APP_KEY terisi di .env.

## Komponen yang Terlibat
- File .env
- Perintah Artisan

## Perintah Artisan CLI
`
php artisan key:generate
`

### Jika key sudah ada dan ingin regenerate
`
php artisan key:generate --force
`

## Kode Implementasi (Per File)
### Sebelum menjalankan
File .env berisi:
`
APP_KEY=
`

### Setelah menjalankan
`
APP_KEY=base64:xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx=
`

## Cara Integrasi & Pengujian
1. Setelah membuat project baru, .env belum memiliki APP_KEY
2. Jalankan php artisan key:generate
