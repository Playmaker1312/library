# 60. Cara Menggunakan php artisan optimize untuk Mengoptimasi Seluruh Aplikasi di Production

## Definisi & Target
optimize menjalankan beberapa perintah caching sekaligus. Target: aplikasi siap production dengan performa maksimal.

## Komponen yang Terlibat
- Cache file di ootstrap/cache/
- Route, config, view, event

## Perintah Artisan CLI
`
php artisan optimize
php artisan optimize:clear
`

### Yang dijalankan oleh optimize:
`
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan event:cache
`

### Rollback:
`
php artisan optimize:clear
`

## Kode Implementasi (Per File)
### Deploy script sederhana
`ash
# Di server production
php artisan down --render="errors::maintenance"
git pull origin main
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan optimize
php artisan up
`

## Cara Integrasi & Pengujian
1. Jalankan php artisan optimize sebelum deployment
2. Untuk menghapus semua cache: php artisan optimize:clear
3. Gunakan php artisan down sebelum optimize di production untuk menghindari error
4. Setiap ada perubahan file, jalankan optimize:clear lalu optimize lagi
5. Jangan jalankan optimize di development â€” lebih baik jalankan perintah individu
6. Pantau performa dengan mengukur response time sebelum dan sesudah optimize
