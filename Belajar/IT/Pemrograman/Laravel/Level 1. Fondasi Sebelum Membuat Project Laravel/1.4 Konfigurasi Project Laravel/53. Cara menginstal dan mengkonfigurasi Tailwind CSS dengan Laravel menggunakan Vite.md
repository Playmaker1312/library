# 53. Cara Menginstal dan Mengkonfigurasi Tailwind CSS dengan Laravel Menggunakan Vite

## Definisi & Target
Tailwind CSS adalah utility-first CSS framework untuk desain cepat. Target: Tailwind berfungsi dan styling bisa menggunakan utility classes.

## Komponen yang Terlibat
- File 	ailwind.config.js
- File postcss.config.js
- File esources/css/app.css
- File ite.config.js

## Perintah Artisan CLI
`
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
`

## Kode Implementasi (Per File)
### tailwind.config.js
`javascript
/** @type {import('tailwindcss').Config} */
export default {
    content: [
        "./resources/**/*.blade.php",
        "./resources/**/*.js",
        "./resources/**/*.vue",
    ],
    theme: {
        extend: {},
    },
    plugins: [],
};
`

### resources/css/app.css
`css
@tailwind base;
@tailwind components;
@tailwind utilities;
`

## Cara Integrasi & Pengujian
1. Install Tailwind: 
pm install -D tailwindcss postcss autoprefixer
2. Inisialisasi: 
px tailwindcss init -p
3. Update tailwind.config.js dengan content paths
4. Ganti isi resources/css/app.css dengan @tailwind directives
5. Pastikan @vite('resources/css/app.css') ada di layout
6. Jalankan 
pm run dev
