# 31. Memahami Arsitektur MVC dalam Konteks Laravel yaitu Model View Controller

## Definisi & Target
MVC (Model-View-Controller) memisahkan logika data, tampilan, dan kontrol. Target: memahami alur request dari Route ke Controller, ke Model, lalu ke View.

## Komponen yang Terlibat
- Route (web.php / api.php)
- Controller
- Model
- Blade View

## Perintah Artisan CLI
`
php artisan make:controller BlogController
php artisan make:model Blog
php artisan make:model Post -m
`

## Cara Integrasi & Pengujian
1. MVC adalah fondasi Laravel â€” setiap fitur mengikuti pola ini
2. Alur: Browser -> Route -> Controller -> Model -> View -> Browser
3. Buat route, controller, model, dan view untuk fitur baru
4. Akses URL yang sesuai untuk melihat hasil
