# 44. Memahami Konsep Authentication dan Authorization dalam Laravel

## Definisi & Target
Authentication memverifikasi identitas user; authorization menentukan akses user. Target: mampu mengatur login, register, dan permissions.

## Komponen yang Terlibat
- Laravel Breeze / Jetstream / UI scaffolding
- Middleware uth dan can
- Gate / Policy

## Perintah Artisan CLI
`
composer require laravel/breeze --dev
php artisan breeze:install blade
php artisan make:policy PostPolicy --model=Post
`

## Kode Implementasi (Per File)
### Policy â€” app/Policies/PostPolicy.php
`php
<?php

namespace App\Policies;

use App\Models\Post;
use App\Models\User;

class PostPolicy
{
    public function viewAny(User ): bool
    {
        return true;
    }

    public function update(User , Post ): bool
    {
        return ->id === ->user_id;
    }

    public function delete(User , Post ): bool
    {
        return ->id === ->user_id || ->role === 'admin';
    }
}
`

### Gate di Controller
`php
public function update(UpdatePostRequest , Post )
{
    Gate::authorize('update', );

    ->update(->validated());
}

public function destroy(Post )
{
    ->authorize('delete', );

    ->delete();
}
`

### Blade â€” authorization di view
`lade
@can('update', )
    <a href="{{ route('posts.edit', ) }}">Edit</a>
@endcan

@cannot('delete', )
    <p>Tidak bisa menghapus</p>
@endcannot
`

## Cara Integrasi & Pengujian
1. Install Breeze untuk scaffolding auth: composer require laravel/breeze --dev
2. Jalankan php artisan breeze:install blade
3. Migrasi: php artisan migrate
4. Buat Policy dengan php artisan make:policy
5. Daftarkan Policy di AppServiceProvider atau otomatis
6. Gunakan @can dan @cannot di Blade untuk UI conditional
7. Test login sebagai user berbeda untuk melihat perbedaan akses
