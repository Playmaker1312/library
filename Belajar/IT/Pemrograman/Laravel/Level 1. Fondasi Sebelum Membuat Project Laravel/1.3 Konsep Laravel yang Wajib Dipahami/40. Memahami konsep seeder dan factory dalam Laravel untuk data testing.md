# 40. Memahami Konsep Seeder dan Factory dalam Laravel untuk Data Testing

## Definisi & Target
Seeder dan factory mengisi database dengan data dummy untuk development dan testing. Target: mampu membuat factory dan seeder untuk data massal.

## Komponen yang Terlibat
- Factory di database/factories/
- Seeder di database/seeders/
- DatabaseSeeder

## Perintah Artisan CLI
`
php artisan make:factory ProductFactory --model=Product
php artisan make:seeder ProductSeeder
php artisan db:seed
php artisan migrate:fresh --seed
`

## Kode Implementasi (Per File)
### Factory â€” database/factories/ProductFactory.php
`php
<?php

namespace Database\Factories;

use App\Models\Category;
use Illuminate\Database\Eloquent\Factories\Factory;

class ProductFactory extends Factory
{
    public function definition(): array
    {
        return [
            'category_id' => Category::factory(),
            'name' => fake()->unique()->words(3, true),
            'slug' => fake()->unique()->slug(3),
            'description' => fake()->paragraphs(2, true),
            'price' => fake()->randomFloat(2, 1000, 1000000),
            'stock' => fake()->numberBetween(0, 100),
            'is_active' => fake()->boolean(80),
        ];
    }

    public function inactive(): static
    {
        return ->state(fn(array ) => [
            'is_active' => false,
        ]);
    }
}
`

### Seeder â€” database/seeders/ProductSeeder.php
`php
<?php

namespace Database\Seeders;

use App\Models\Category;
use App\Models\Product;
use Illuminate\Database\Seeder;

class ProductSeeder extends Seeder
{
    public function run(): void
    {
        Category::factory(5)->hasProducts(10)->create();

        Product::factory(50)->inactive()->create();
    }
}
`

### DatabaseSeeder
`php
class DatabaseSeeder extends Seeder
{
    public function run(): void
    {
        ->call([
            CategorySeeder::class,
            ProductSeeder::class,
        ]);
    }
}
`

## Cara Integrasi & Pengujian
1. Buat factory dengan php artisan make:factory
2. Definisikan data default di method definition()
3. Buat seeder dan panggil factory di un()
4. Jalankan php artisan migrate:fresh --seed
5. Periksa data di database via TablePlus atau tinker
6. Factory state untuk variasi kondisi data
