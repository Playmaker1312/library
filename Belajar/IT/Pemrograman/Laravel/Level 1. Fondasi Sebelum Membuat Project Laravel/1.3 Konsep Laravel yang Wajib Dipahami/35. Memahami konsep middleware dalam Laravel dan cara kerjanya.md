# 35. Memahami Konsep Middleware dalam Laravel dan Cara Kerjanya

## Definisi & Target
Middleware menyaring HTTP request sebelum mencapai Controller. Target: mampu membuat dan mendaftarkan middleware untuk autentikasi, logging, atau CORS.

## Komponen yang Terlibat
- File middleware di pp/Http/Middleware/
- Kernel (ootstrap/app.php di Laravel 11)
- Route

## Perintah Artisan CLI
`
php artisan make:middleware LogRequests
`

### Mendaftarkan Middleware di Route (Laravel 11)
`php
// bootstrap/app.php
use App\Http\Middleware\LogRequests;

return Application::configure(basePath: dirname(__DIR__))
    ->withMiddleware(function (Middleware ) {
        ->api(prepend: [
            LogRequests::class,
        ]);
    })
    ->create();
`

### Menggunakan Middleware di Route
`php
Route::middleware(['auth', 'verified'])->group(function () {
    Route::resource('posts', PostController::class);
});

Route::get('admin/dashboard', function () {
    return view('admin.dashboard');
})->middleware(['auth', 'admin']);
`

## Cara Integrasi & Pengujian
1. Buat middleware dengan php artisan make:middleware
2. Daftarkan di ootstrap/app.php (Laravel 11) atau Kernel
3. Terapkan ke route secara global, grup, atau individual
4. Middleware bisa menerima parameter: middleware('role:admin')
5. Test dengan mengakses route yang dilindungi middleware
