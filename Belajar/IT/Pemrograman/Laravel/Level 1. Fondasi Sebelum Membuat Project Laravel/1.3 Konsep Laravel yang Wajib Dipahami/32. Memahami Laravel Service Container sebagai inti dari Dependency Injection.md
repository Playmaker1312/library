# 32. Memahami Laravel Service Container sebagai Inti dari Dependency Injection

## Definisi & Target
Service Container mengelola dependency class secara otomatis. Target: memahami cara container meresolve class dan bagaimana binding interface bekerja.

## Komponen yang Terlibat
- pp/Providers/AppServiceProvider.php
- Controller / class yang menerima dependency

## Perintah Artisan CLI
`
php artisan make:provider AppServiceProvider
`

## Kode Implementasi (Per File)
### Binding Interface ke Implementasi
`php
class AppServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        ->app->bind(PaymentGateway::class, MidtransGateway::class);
        ->app->singleton(LoggerService::class, function () {
            return new LoggerService(storage_path('logs/laravel.log'));
        });
    }
}
`
