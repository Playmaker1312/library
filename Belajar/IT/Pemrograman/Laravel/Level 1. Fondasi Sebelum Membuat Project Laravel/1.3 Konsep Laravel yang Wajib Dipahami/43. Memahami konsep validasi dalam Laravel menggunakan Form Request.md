# 43. Memahami Konsep Validasi dalam Laravel Menggunakan Form Request

## Definisi & Target
Form Request memisahkan logika validasi dari Controller. Target: mampu membuat Form Request dengan aturan validasi dan pesan kustom.

## Kode Implementasi (Per File)
### Form Request â€” app/Http/Requests/StorePostRequest.php
`php
<?php

namespace App\Http\Requests;

use Illuminate\Foundation\Http\FormRequest;

class StorePostRequest extends FormRequest
{
    public function authorize(): bool
    {
        return true;
    }

    public function rules(): array
    {
        return [
            'title' => ['required', 'string', 'min:5', 'max:200', 'unique:posts,title'],
            'body' => ['required', 'string', 'min:20'],
            'category_id' => ['required', 'exists:categories,id'],
            'tags' => ['nullable', 'array'],
            'tags.*' => ['exists:tags,id'],
            'is_published' => ['boolean'],
        ];
    }

    public function messages(): array
    {
        return [
            'title.required' => 'Judul wajib diisi.',
            'title.min' => 'Judul minimal 5 karakter.',
            'body.min' => 'Konten minimal 20 karakter.',
        ];
    }
}
`

ules()
