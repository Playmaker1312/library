# 36. Memahami Eloquent ORM sebagai Cara Laravel Berinteraksi dengan Database

## Definisi & Target
Eloquent ORM menyediakan Active Record pattern untuk berinteraksi dengan database. Target: mampu membuat model, relasi, dan query menggunakan Eloquent.

## Komponen yang Terlibat
- Model di pp/Models/
- Migration di database/migrations/
- Controller

## Perintah Artisan CLI
`
php artisan make:model Product -m
php artisan make:model Category -m
`

## Kode Implementasi (Per File)
### Model dengan Relasi
`php
class Category extends Model
{
    use HasFactory;

    protected  = ['name', 'slug'];

    public function products(): HasMany
    {
        return ->hasMany(Product::class);
    }
}

class Product extends Model
{
    use HasFactory;

    protected  = ['category_id', 'name', 'price', 'stock'];

    public function category(): BelongsTo
    {
        return ->belongsTo(Category::class);
    }

    public function scopeInStock()
    {
        return ->where('stock', '>', 0);
    }
}
`

### Query dengan Eloquent
`php
 = Product::with('category')
    ->inStock()
    ->where('price', '>=', 10000)
    ->latest()
    ->paginate(12);

 = Category::withCount('products')->findOrFail();
`

## Cara Integrasi & Pengujian
1. Buat model bersamaan dengan migration (-m flag)
2. Definisikan $fillable atau $guarded untuk mass assignment
3. Gunakan with() untuk eager loading relasi
4. Local scope mempermudah query yang sering digunakan
5. Akses di tinker: php artisan tinker lalu Product::all()
