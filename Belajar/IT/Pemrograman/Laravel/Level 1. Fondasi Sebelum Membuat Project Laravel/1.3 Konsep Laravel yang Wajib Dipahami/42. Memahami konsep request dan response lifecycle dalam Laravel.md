# 42. Memahami Konsep Request dan Response Lifecycle dalam Laravel

## Definisi & Target
Request lifecycle menjelaskan perjalanan HTTP request dari masuk hingga response keluar. Target: memahami urutan proses: middleware, controller, response.

## Komponen yang Terlibat
- public/index.php (entry point)
- HTTP Kernel / bootstrap/app.php
- Middleware stack
- Route / Controller
- Service Provider

## Kode Implementasi (Per File)
### Alur Request Lifecycle
`
1. public/index.php â€” entry point semua request
2. Autoload composer dan bootstrap aplikasi
3. Service Provider register() â€” daftarkan binding
4. Service Provider boot() â€” inisialisasi service
5. Middleware global â€” CORS, session, dll
6. Route matching â€” cocokkan URL dengan route
7. Middleware route â€” auth, verified, dll
8. Controller method â€” eksekusi logika bisnis
9. Response â€” dikirim kembali melalui middleware

`

## Cara Integrasi & Pengujian
1. Setiap request ke public/index.php memulai lifecycle
2. Tambahkan middleware untuk intervensi di tengah alur
3. Response bisa berupa View, JSON, Redirect, atau File
4. Service Provider boot() dijalankan sebelum middleware
5. Pahami lifecycle untuk debugging dan optimasi
