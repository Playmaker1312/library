# 33. Memahami Laravel Service Provider sebagai Tempat Mendaftarkan Binding

## Definisi & Target
Service Provider adalah tempat central untuk mendaftarkan binding, event listener, middleware, dan konfigurasi. Target: mampu membuat dan mendaftarkan Service Provider.

## Komponen yang Terlibat
- File provider di pp/Providers/
- Konfigurasi di config/app.php (providers array)

## Perintah Artisan CLI
`
php artisan make:provider PaymentServiceProvider
`

## Kode Implementasi (Per File)
### PaymentServiceProvider
`php
<?php

namespace App\Providers;

use Illuminate\Support\ServiceProvider;
use App\Contracts\PaymentGateway;
use App\Services\MidtransGateway;

class PaymentServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        ->app->bind(PaymentGateway::class, MidtransGateway::class);

        ->app->bind('payment.logger', function () {
            return new \App\Services\PaymentLogger();
        });
    }

    public function boot(): void
    {
        // Kode yang dijalankan setelah semua provider terdaftar
        ->app->make('payment.logger')->initialize();
    }
}
`

### Mendaftarkan Provider di config/app.php
`php
'providers' => [
    // ...
    App\Providers\PaymentServiceProvider::class,
],
`
