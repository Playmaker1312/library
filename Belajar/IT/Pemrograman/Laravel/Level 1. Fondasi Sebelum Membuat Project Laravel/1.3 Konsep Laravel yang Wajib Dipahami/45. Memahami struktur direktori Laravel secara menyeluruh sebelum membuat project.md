# 45. Memahami Struktur Direktori Laravel secara Menyeluruh sebelum Membuat Project

## Definisi & Target
Struktur direktori Laravel mengorganisir kode berdasarkan fungsinya. Target: memahami fungsi setiap folder utama dalam project Laravel.

## Komponen yang Terlibat
Semua folder dalam project Laravel.

## Perintah Artisan CLI
`
tree /f
`
