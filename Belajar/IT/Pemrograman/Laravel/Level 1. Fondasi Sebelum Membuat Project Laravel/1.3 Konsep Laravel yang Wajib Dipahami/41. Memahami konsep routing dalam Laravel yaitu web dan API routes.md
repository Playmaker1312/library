# 41. Memahami Konsep Routing dalam Laravel yaitu Web dan API Routes

## Definisi & Target
Route mengarahkan HTTP request ke Controller yang sesuai. Target: mampu mendefinisikan route web (dengan session) dan API (tanpa session).

## Komponen yang Terlibat
- outes/web.php â€” untuk route dengan session, CSRF, Blade
- outes/api.php â€” untuk route stateless, response JSON
- Controller

## Perintah Artisan CLI
`
php artisan route:list
php artisan make:controller Api/PostController --api
`

## Kode Implementasi (Per File)
### Web Routes â€” routes/web.php
`php
use App\Http\Controllers\PostController;
use App\Http\Controllers\ProfileController;

Route::get('/', function () {
    return view('welcome');
});

Route::middleware(['auth', 'verified'])->group(function () {
    Route::resource('posts', PostController::class);
    Route::get('/profile', [ProfileController::class, 'edit']);
    Route::patch('/profile', [ProfileController::class, 'update']);
});
`

### API Routes â€” routes/api.php
`php
use App\Http\Controllers\Api\PostController;

Route::prefix('v1')->group(function () {
    Route::apiResource('posts', PostController::class)->except(['create', 'edit']);

    Route::middleware('auth:sanctum')->group(function () {
        Route::post('posts/{post}/like', [PostController::class, 'like']);
    });
});
`

### Route dengan Parameter dan Binding
`php
Route::get('posts/{post:slug}', [PostController::class, 'show']);

Route::get('categories/{category}/posts', function (Category ) {
    return ->posts()->paginate();
});
`

## Cara Integrasi & Pengujian
1. Definisikan route di file yang sesuai (web atau api)
2. Gunakan php artisan route:list untuk melihat semua route
3. Route web menggunakan session dan CSRF; route API stateless
4. Route model binding otomatis mencari data berdasarkan ID
5. Test web route di browser; test API route via Postman/curl
