# 39. Memahami Konsep Migration Database dalam Laravel

## Definisi & Target
Migration adalah version control untuk database â€” mengelola perubahan skema secara terstruktur. Target: mampu membuat, menjalankan, dan rollback migration.

## Komponen yang Terlibat
- File migration di database/migrations/
- Model
- php artisan migrate

## Perintah Artisan CLI
`
php artisan make:migration create_products_table
php artisan make:migration add_price_to_products_table
php artisan migrate
php artisan migrate:rollback
php artisan migrate:fresh
php artisan migrate:status
`

## Kode Implementasi (Per File)
### Migration Membuat Tabel
`php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('products', function (Blueprint ) {
            ->id();
            ->foreignId('category_id')->constrained()->cascadeOnDelete();
            ->string('name', 200);
            ->string('slug')->unique();
            ->text('description')->nullable();
            ->decimal('price', 12, 2)->default(0);
            ->integer('stock')->default(0);
            ->boolean('is_active')->default(true);
            ->timestamps();
            ->softDeletes();
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('products');
    }
};
`

### Migration Modifikasi Tabel
`php
public function up(): void
{
    Schema::table('products', function (Blueprint ) {
        ->decimal('discount_price', 12, 2)->nullable()->after('price');
        ->index('slug');
    });
}

public function down(): void
{
    Schema::table('products', function (Blueprint ) {
        ->dropColumn('discount_price');
        ->dropIndex('products_slug_index');
    });
}
`

## Cara Integrasi & Pengujian
1. Buat migration dengan php artisan make:migration
2. Tulis skema di method up(), kebalikan di down()
3. Jalankan php artisan migrate untuk mengeksekusi
4. Gunakan migrate:rollback untuk membatalkan migration terakhir
5. migrate:status menampilkan migration mana yang sudah dijalankan
6. Selalu uji down() agar rollback berfungsi
