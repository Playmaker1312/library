# 37. Memahami Blade sebagai Templating Engine Bawaan Laravel

## Definisi & Target
Blade menyediakan sintaks template yang bersih dengan directives dan component. Target: mampu membuat layout, component, dan rendering data di Blade.

## Komponen yang Terlibat
- File blade di `resources/views/`
- Layout file
- Component class (opsional)

## Perintah Artisan CLI
```
php artisan make:component Alert
```

## Kode Implementasi (Per File)
### Layout — resources/views/layouts/app.blade.php
```blade
<!DOCTYPE html>
<html>
<head>
    <title>@yield('title', 'Default')</title>
    @vite('resources/css/app.css')
</head>
<body>
    <x-navbar />
    <main>
        @yield('content')
    </main>
    <x-footer />
    @vite('resources/js/app.js')
</body>
</html>
```

### Halaman — resources/views/posts/index.blade.php
```blade
@extends('layouts.app')

@section('title', 'Daftar Post')

@section('content')
    <div class="container">
        <h1>Daftar Post</h1>

        @forelse($posts as $post)
            <x-post-card :post="$post" />
        @empty
            <p>Tidak ada post.</p>
        @endforelse

        {{ $posts->links() }}
    </div>
@endsection
```

### Blade Component — app/View/Components/PostCard.php
```php
class PostCard extends Component
{
    public function __construct(
        public Post $post,
    ) {}

    public function render(): View
    {
        return view('components.post-card');
    }
}
```

### Component View — resources/views/components/post-card.blade.php
```blade
<article class="border p-4 rounded">
    <h2>{{ $post->title }}</h2>
    <p class="text-gray-600">{{ $post->excerpt }}</p>
    <a href="{{ route('posts.show', $post) }}">Baca selengkapnya</a>
</article>
```

## Cara Integrasi & Pengujian
1. Layout base menyediakan struktur HTML umum
2. Gunakan @extends dan @section untuk konten per halaman
3. Blade component untuk elemen UI reusable
4. Directive @auth, @guest, @forelse mempermudah logika template
5. Render otomatis saat controller memanggil view()
