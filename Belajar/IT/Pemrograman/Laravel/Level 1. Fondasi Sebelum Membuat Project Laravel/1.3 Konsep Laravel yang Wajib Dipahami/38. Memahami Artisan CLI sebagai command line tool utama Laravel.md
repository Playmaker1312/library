# 38. Memahami Artisan CLI sebagai Command Line Tool Utama Laravel

## Definisi & Target
Artisan adalah command-line tool Laravel untuk membuat file, menjalankan task, dan manage aplikasi. Target: menguasai perintah Artisan yang paling sering digunakan.

## Komponen yang Terlibat
- File `artisan` di root project
- Command custom di `app/Console/Commands/`

## Perintah Artisan CLI
```
php artisan list
php artisan help make:model
```

## Kode Implementasi (Per File)
### Perintah Artisan yang Sering Digunakan
```bash
# Membuat file
php artisan make:controller PostController
php artisan make:model Post -m
php artisan make:migration create_posts_table
php artisan make:seeder PostSeeder
php artisan make:factory PostFactory
php artisan make:request StorePostRequest
php artisan make:event PostCreated
php artisan make:listener SendPostNotification
php artisan make:job ProcessPost
php artisan make:mail OrderConfirmation
php artisan make:notification PostPublished
php artisan make:rule ValidSlug
php artisan make:command SendDailyReport

# Database
php artisan migrate
php artisan migrate:fresh
php artisan migrate:refresh
php artisan db:seed
php artisan db:seed --class=PostSeeder

# Cache & Optimize
php artisan cache:clear
php artisan config:clear
php artisan config:cache
php artisan route:cache
php artisan view:clear
php artisan optimize

# Development
php artisan serve
php artisan tinker
php artisan route:list
php artisan make:filament-user  # jika pakai Filament
```

### Membuat Custom Artisan Command
```php
<?php

namespace App\Console\Commands;

use Illuminate\Console\Command;

class SendDailyReport extends Command
{
    protected $signature = 'report:daily {--email= : Email tujuan}';
    protected $description = 'Mengirim laporan harian via email';

    public function handle(): int
    {
        $email = $this->option('email') ?? config('mail.admin_address');
        $this->info("Mengirim laporan ke {$email}...");
        return Command::SUCCESS;
    }
}
```

## Cara Integrasi & Pengujian
1. Ketik php artisan untuk melihat semua perintah
2. Gunakan make:* untuk generate file boilerplate
3. Custom command didaftarkan otomatis di folder Commands
4. Jalankan custom command: php artisan report:daily --email=admin@test.com
5. Schedule command di app/Console/Kernel.php untuk otomatisasi
