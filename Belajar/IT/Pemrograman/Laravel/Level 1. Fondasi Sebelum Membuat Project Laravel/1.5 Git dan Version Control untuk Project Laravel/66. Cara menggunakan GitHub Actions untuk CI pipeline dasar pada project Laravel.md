# 66. Cara Menggunakan GitHub Actions untuk CI Pipeline Dasar pada Project Laravel

## Definisi & Target
GitHub Actions menjalankan test otomatis setiap kali push atau pull request. Target: setiap perubahan kode otomatis diuji.

## Komponen yang Terlibat
- File .github/workflows/tests.yml
- PHPUnit test
- GitHub repository

## Perintah Artisan CLI
`
php artisan test
`

## Kode Implementasi (Per File)
### .github/workflows/tests.yml
`yaml
name: Tests

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest

    services:
      mysql:
        image: mysql:8.0
        env:
          MYSQL_ALLOW_EMPTY_PASSWORD: yes
          MYSQL_DATABASE: testing
        ports:
          - 3306:3306

    steps:
      - uses: actions/checkout@v4

      - name: Setup PHP
        uses: shivammathur/setup-php@v2
        with:
          php-version: '8.2'
          extensions: mbstring, pdo_mysql

      - name: Copy .env
        run: cp .env.example .env

      - name: Install Dependencies
        run: composer install --no-progress

      - name: Generate Key
        run: php artisan key:generate

      - name: Run Tests
        run: php artisan test
        env:
          DB_CONNECTION: mysql
          DB_HOST: 127.0.0.1
          DB_PORT: 3306
          DB_DATABASE: testing
          DB_USERNAME: root
          DB_PASSWORD: ""
`

## Cara Integrasi & Pengujian
1. Buat folder .github/workflows/ di root project
2. Buat file 	ests.yml dengan konfigurasi di atas
3. Push ke GitHub
