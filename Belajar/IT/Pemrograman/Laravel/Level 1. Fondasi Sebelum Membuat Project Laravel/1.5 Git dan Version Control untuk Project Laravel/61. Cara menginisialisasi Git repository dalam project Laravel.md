# 61. Cara Menginisialisasi Git Repository dalam Project Laravel

## Definisi & Target
Git repository melacak perubahan kode dan memfasilitasi kolaborasi. Target: project Laravel terikat dengan Git.

## Komponen yang Terlibat
- Folder .git/
- File .gitignore

## Perintah Artisan CLI
Tidak ada. Menggunakan Git CLI.

## Kode Implementasi (Per File)
### Inisialisasi Git
`ash
cd /path/to/laravel-project
git init
git add .
git commit -m "feat: initial project setup"
`

### Cek status
`ash
git status
git log --oneline
`

## Cara Integrasi & Pengujian
1. Laravel project baru sudah menyertakan .gitignore
2. Jalankan git init di root project
3. Jalankan git add . untuk staging semua file
4. Jalankan git commit -m "Initial commit"
5. Verifikasi dengan git log
6. Repository lokal siap dihubungkan ke GitHub/GitLab
