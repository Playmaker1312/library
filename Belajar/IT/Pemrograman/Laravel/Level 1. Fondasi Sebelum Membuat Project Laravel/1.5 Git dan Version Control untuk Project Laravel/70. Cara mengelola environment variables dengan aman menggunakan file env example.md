# 70. Cara Mengelola Environment Variables dengan Aman Menggunakan File .env.example

## Definisi & Target
.env.example menyediakan template environment variables tanpa nilai sensitif. Target: developer lain tahu variable apa yang diperlukan tanpa mengekspos rahasia.

## Komponen yang Terlibat
- File .env.example
- File .gitignore
- File .env

## Perintah Artisan CLI
`
cp .env.example .env
`

## Kode Implementasi (Per File)
### .env.example â€” template yang aman
`
APP_NAME="Nama Aplikasi"
APP_ENV=local
APP_DEBUG=true
APP_URL=http://localhost:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel

BROADCAST_DRIVER=log
CACHE_DRIVER=file
FILESYSTEM_DISK=local

MAIL_FROM_NAME=""

AWS_ACCESS_KEY_ID=
AWS_SECRET_ACCESS_KEY=
AWS_DEFAULT_REGION=us-east-1
AWS_BUCKET=

VITE_APP_NAME=""
`

### .gitignore â€” pastikan .env tidak ikut push
`
.env
.env.*.local
`

## Cara Integrasi & Pengujian
1. Setelah membuat project, segera buat .env.example
2. Hapus nilai sensitif dari .env.example (password, API key, secret)
3. Jangan commit .env ke repository â€” sudah ada di .gitignore
4. Developer lain menjalankan cp .env.example .env lalu mengisi nilainya
5. Update .env.example setiap kali ada variable environment baru
6. Jangan pernah menyimpan password atau token asli di .env.example
