# 63. Cara Membuat Repository GitHub dan Menghubungkannya dengan Project Lokal

## Definisi & Target
Repository GitHub menyimpan kode secara remote untuk backup dan kolaborasi. Target: project lokal terhubung ke GitHub.

## Komponen yang Terlibat
- Akun GitHub
- Repository GitHub (remote)
- Git CLI

## Perintah Artisan CLI
Tidak ada. Menggunakan Git CLI dan GitHub CLI.

## Kode Implementasi (Per File)
### Via GitHub CLI
`ash
gh repo create nama-repo --public --source=. --remote=origin --push
`

### Via Git manual
`ash
git remote add origin https://github.com/username/nama-repo.git
git branch -M main
git push -u origin main
`

## Cara Integrasi & Pengujian
1. Buat repository di github.com (jangan inisialisasi dengan README)
2. Di terminal project: git remote add origin <url>
3. Push: git push -u origin main

5. Untuk clone: git clone <url> di komputer lain
