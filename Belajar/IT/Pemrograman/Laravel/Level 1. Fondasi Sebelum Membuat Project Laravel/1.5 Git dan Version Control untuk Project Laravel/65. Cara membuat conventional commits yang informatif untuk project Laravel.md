# 65. Cara Membuat Conventional Commits yang Informatif untuk Project Laravel

## Definisi & Target
Conventional commits memberikan format pesan commit yang standar dan informatif. Target: riwayat commit mudah dibaca dan bisa digunakan untuk changelog otomatis.

## Komponen yang Terlibat
- Commit message

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### Format Conventional Commit
`
<type>(<scope>): <description>

<body>

<footer>
`

### Contoh untuk project Laravel
`
feat(auth): add login with Google OAuth

feat(posts): implement CRUD for blog posts

fix(api): handle null category in product response

refactor(service): extract payment logic to PaymentService

chore(deps): upgrade Laravel to 11.x

docs(readme): update installation steps

test(post): add feature test for post creation

style(blade): format blade templates with Tailwind classes
`

### Type yang umum
`
feat:     Fitur baru
fix:      Perbaikan bug
chore:    Tugas maintenance (deps, config)
docs:     Dokumentasi
refactor: Refactoring kode (tanpa perubahan perilaku)
test:     Menambahkan test
style:    Perubahan formatting (space, indent)
perf:     Optimasi performa
`
