# 69. Cara Menggunakan Git Hooks untuk Menjalankan Test Sebelum Commit

## Definisi & Target
Git hooks menjalankan script otomatis sebelum commit, mencegah kode rusak masuk repository. Target: test dijalankan setiap kali commit.

## Komponen yang Terlibat
- File .git/hooks/pre-commit
- PHPUnit test
- Laravel Pint / PHPCS (opsional)

## Perintah Artisan CLI
`
php artisan test
./vendor/bin/pint
`

## Kode Implementasi (Per File)
### .git/hooks/pre-commit
`ash
#!/bin/sh

echo "Menjalankan test..."
php artisan test --group=current

if [ True -ne 0 ]; then
    echo "Test gagal! Commit dibatalkan."
    exit 1
fi

echo "Test berhasil. Commit diizinkan."
`

File .husky/pre-commit:
`ash
#!/usr/bin/env sh
. "/_/husky.sh"

npm run pint
php artisan test --stop-on-failure
`

## Cara Integrasi & Pengujian
1. Buat file .git/hooks/pre-commit (tanpa extensi)
2. Isi dengan script test
3. Beri izin eksekusi (Linux/Mac: chmod +x)
4. Coba commit â€” test berjalan otomatis
5. Jika test gagal, commit dibatalkan
6. Untuk tim, gunakan Husky agar hooks tereplikasi
