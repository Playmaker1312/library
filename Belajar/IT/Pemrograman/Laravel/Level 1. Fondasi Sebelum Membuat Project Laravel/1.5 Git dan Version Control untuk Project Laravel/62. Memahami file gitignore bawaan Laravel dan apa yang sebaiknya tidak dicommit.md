# 62. Memahami File .gitignore Bawaan Laravel dan Apa yang Sebaiknya Tidak Dicommit

## Definisi & Target
.gitignore mencegah file sensitif dan tidak perlu masuk ke repository. Target: memahami file mana yang aman dicommit dan mana yang tidak.

## Komponen yang Terlibat
- File .gitignore

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### File yang tidak boleh dicommit
`
.env                    # Berisi kredensial dan API key
/vendor                 # Dependency â€” cukup composer.json
node_modules/           # Dependency JS â€” cukup package.json
storage/framework/cache/
storage/framework/sessions/
storage/framework/views/
storage/logs/
.DS_Store               # File sistem macOS
Thumbs.db               # File sistem Windows
*.log
.phpunit.result.cache
`

### File yang wajib dicommit
`
.env.example            # Template .env tanpa nilai sensitif
composer.json
composer.lock
package.json
resources/
app/
config/
routes/
database/migrations/
public/
`

## Cara Integrasi & Pengujian
1. .gitignore sudah disediakan Laravel saat project dibuat
2. Jangan commit .env â€” gunakan .env.example sebagai template
3. Folder vendor/ cukup di-rebuild dengan composer install
4. Jika ada file lokal yang perlu diabaikan, tambahkan ke .gitignore
5. Cek dengan git status sebelum commit
