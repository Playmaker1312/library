# 03. Cara Menginstal Laravel Installer menggunakan Perintah Composer Global Require

## Definisi & Target
Laravel Installer mempermudah pembuatan project baru. Target: perintah `laravel new` tersedia di terminal global.

## Komponen yang Terlibat
- Composer (global composer.json)
- Laravel Installer package

## Perintah Artisan CLI
Tidak langsung. Namun setelah instalasi, pembuatan project menjadi:
```
laravel new nama-project
```

## Kode Implementasi (Per File)
### Langkah Instalasi
```
composer global require laravel/installer
```

### Pastikan direktori global composer ada di PATH
Path yang perlu ditambahkan:
```
%USERPROFILE%\AppData\Roaming\Composer\vendor\bin
```

## Cara Integrasi & Pengujian
1. Jalankan `composer global require laravel/installer`
2. Tambahkan direktori vendor/bin global ke PATH jika belum ada
3. Buka terminal baru, ketik `laravel`
4. Jika muncul daftar perintah Laravel Installer, instalasi berhasil
5. Untuk membuat project: `laravel new nama-app`
