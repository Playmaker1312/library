# 01. Cara Menginstal PHP Versi 8.1 atau Lebih Tinggi sebagai Runtime Utama Laravel

## Definisi & Target
PHP 8.1+ adalah runtime minimal yang dibutuhkan Laravel 10/11. Target: PHP terinstal dan terbukti lewat perintah php -v.

## Komponen yang Terlibat
- File installer PHP (Windows: php-8.x.x-Win32-vs16-x64.zip)
- Environment variable PATH
- Command prompt / terminal

## Perintah Artisan CLI
Tidak ada. Ini adalah instalasi sistem, bukan proyek Laravel.

## Kode Implementasi (Per File)
Tidak ada kode PHP. Cukup verifikasi instalasi:

### Verifikasi Instalasi
`
php -v
`

Output yang diharapkan:
`
PHP 8.3.x (cli) (built: ...)
Copyright (c) The PHP Group
Zend Engine v4.3.x
`

## Cara Integrasi & Pengujian
1. Unduh PHP dari windows.php.net/download (versi Thread Safe ZIP)
2. Ekstrak ke C:\php
3. Tambahkan C:\php ke PATH environment variable
4. Buka terminal baru dan ketik php -v
5. Pastikan versi yang tampil adalah 8.1 atau lebih tinggi
