# 07. Cara Menjalankan PostgreSQL Menggunakan Docker untuk Development Laravel

## Definisi & Target
Menjalankan PostgreSQL dalam container Docker agar Laravel bisa menggunakannya sebagai database. Target: container PostgreSQL berjalan dan bisa dikoneksi Laravel.

## Komponen yang Terlibat
- Docker Desktop
- File docker-compose.yml (di root project Laravel)
- File .env Laravel

## Perintah Artisan CLI
`
php artisan migrate
`

## Kode Implementasi (Per File)
### docker-compose.yml
`yaml
services:
  postgres:
    image: postgres:16
    container_name: laravel_postgres
    ports:
      - "5432:5432"
    environment:
      POSTGRES_DB: laravel
      POSTGRES_USER: laravel
      POSTGRES_PASSWORD: secret
    volumes:
      - postgres_data:/var/lib/postgresql/data

volumes:
  postgres_data:
`

### File .env (Laravel)
`
DB_CONNECTION=pgsql
DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=laravel
DB_USERNAME=laravel
DB_PASSWORD=secret
`

## Cara Integrasi & Pengujian
1. Letakkan docker-compose.yml di root project Laravel
2. Jalankan docker compose up -d postgres
3. Pastikan container berjalan: docker ps
4. Update file .env dengan konfigurasi di atas
5. Jalankan php artisan migrate untuk menguji koneksi
6. Jika migrasi berjalan, PostgreSQL siap digunakan
