# 14. Cara Menginstal Ekstensi Laravel Blade Snippets di VS Code

## Definisi & Target
Laravel Blade Snippets menyediakan potongan kode cepat untuk directive Blade. Target: mengetik @if lalu Enter menghasilkan struktur if lengkap.

## Komponen yang Terlibat
- VS Code Extensions panel
- Laravel Blade Snippets (oleh Winnie Lin)

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### Instalasi via terminal
`
code --install-extension winnielin.laravel-blade-snippets
`

### Contoh snippets yang tersedia:
| Trigger | Hasil |
|---------|-------|
| @if   | @if (condition) ... @endif |
| @fore | @foreach ( as ) ... @endforeach |
| @sec  | @section('name') ... @endsection |
| @extends | @extends('layout') |
| @include | @include('view') |

## Cara Integrasi & Pengujian
1. Buka VS Code Extensions
2. Cari Laravel Blade Snippets oleh Winnie Lin
3. Install
4. Buat file baru test.blade.php
5. Ketik @if lalu tekan Tab -- snippet lengkap muncul
6. Coba @foreach, @section, dan @extends
