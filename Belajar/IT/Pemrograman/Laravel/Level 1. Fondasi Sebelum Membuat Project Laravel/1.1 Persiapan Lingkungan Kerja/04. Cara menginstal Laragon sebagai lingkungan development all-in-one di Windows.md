# 03. Cara Menginstal Laravel Installer menggunakan Perintah Composer Global Require

## Definisi & Target
Laravel Installer mempermudah pembuatan project baru. Target: perintah laravel new tersedia di terminal global.

## Komponen yang Terlibat
- Composer (global composer.json)
- Laravel Installer package

## Perintah Artisan CLI
Tidak langsung. Namun setelah instalasi, pembuatan project menjadi:
`
laravel new nama-project
`

## Kode Implementasi (Per File)
### Langkah Instalasi
`
composer global require laravel/installer
`

### Pastikan direktori global composer ada di PATH
Path yang perlu ditambahkan:
`
%USERPROFILE%\AppData\Roaming\Composer\vendor\bin
`

## Cara Integrasi & Pengujian
1. Jalankan composer global require laravel/installer
2. Tambahkan direktori vendor/bin global ke PATH jika belum ada
3. Buka terminal baru, ketik laravel
4. Jika muncul daftar perintah Laravel Installer, instalasi berhasil
5. Untuk membuat project: laravel new nama-app

# 04. Cara Menginstal Laragon sebagai Lingkungan Development All-in-One di Windows

## Definisi & Target
Laragon menyediakan Apache/Nginx, PHP, MySQL, dan tools lain dalam satu paket untuk Windows. Target: Laragon berjalan dan halaman Welcome muncul.

## Komponen yang Terlibat
- Laragon installer (laragon-wsl.exe atau laragon-full.exe)
- Services: Apache/Nginx, MySQL/MariaDB, PHP

## Perintah Artisan CLI
Setelah Laragon terinstal, Laravel bisa diakses melalui php artisan serve dari folder project.

## Kode Implementasi (Per File)
### Konfigurasi Laragon
Buka Laragon > Menu > Preferences:
- Document Root: C:\Users\...\Laragon\www
- Pastikan Apache dan MySQL berstatus running

### Membuat project Laravel di Laragon
`
cd C:\laragon\www
laravel new blog
`

Lalu akses: http://blog.test

## Cara Integrasi & Pengujian
1. Unduh Laragon Full dari laragon.org/download
2. Jalankan installer dan pilih direktori (default C:\laragon)
3. Buka Laragon, klik Start All
4. Indikator Apache dan MySQL berubah hijau
5. Buka browser ke http://localhost -- tampil halaman Laragon
6. Project Laravel bisa diletakkan di C:\laragon\www
