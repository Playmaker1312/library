# 13. Cara Menginstal Ekstensi Blade Formatter di VS Code untuk Formatting Template Blade

## Definisi & Target
Blade Formatter merapikan kode template Blade agar konsisten. Target: format otomatis saat menyimpan file .blade.php.

## Komponen yang Terlibat
- VS Code Extensions panel
- Laravel Blade Formatter (oleh shufo)

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### Instalasi via terminal
`
code --install-extension shufo.vscode-blade-formatter
`

### Setting VS Code (settings.json)
`json
{
  "[blade]": {
    "editor.formatOnSave": true,
    "editor.defaultFormatter": "shufo.vscode-blade-formatter"
  }
}
`

## Cara Integrasi & Pengujian
1. Buka VS Code Extensions
2. Cari "Blade Formatter" oleh shufo
3. Install, lalu tambahkan konfigurasi di settings.json
4. Buka file esources/views/welcome.blade.php
5. Buat indentasi berantakan, lalu simpan (Ctrl+S)
6. File otomatis diformat rapi
