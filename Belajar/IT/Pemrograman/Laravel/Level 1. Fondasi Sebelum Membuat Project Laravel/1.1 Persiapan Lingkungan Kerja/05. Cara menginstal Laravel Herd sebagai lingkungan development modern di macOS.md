# 05. Cara Menginstal Laravel Herd sebagai Lingkungan Development Modern di macOS

## Definisi & Target
Laravel Herd menyediakan Nginx, PHP, dan DNS resolver otomatis untuk macOS. Target: Herd berjalan dan project Laravel bisa diakses via .test domain.

## Komponen yang Terlibat
- Laravel Herd aplikasi macOS
- Nginx, PHP 8.x, DNS resolver bawaan

## Perintah Artisan CLI
Tidak perlu php artisan serve -- Herd menggunakan Nginx sebagai proxy.

## Kode Implementasi (Per File)
### Pembuatan Project via Herd
`
cd ~/Herd
laravel new blog
`

Akses: http://blog.test

## Cara Integrasi & Pengujian
1. Unduh Laravel Herd dari herd.laravel.com
2. Pindahkan ke folder Applications dan jalankan
3. Klik Start Herd -- ikon Herd muncul di menu bar
4. Buat folder ~/Herd/sites jika belum ada
5. Semua project di folder tersebut otomatis terdeteksi dengan domain .test
6. Buka browser ke http://blog.test
