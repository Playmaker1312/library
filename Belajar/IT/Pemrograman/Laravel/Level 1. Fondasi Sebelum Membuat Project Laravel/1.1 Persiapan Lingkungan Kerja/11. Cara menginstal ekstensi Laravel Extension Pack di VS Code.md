# 11. Cara Menginstal Ekstensi Laravel Extension Pack di VS Code

## Definisi & Target
Laravel Extension Pack menyediakan kumpulan ekstensi yang memudahkan development Laravel. Target: ekstensi terinstal di VS Code.

## Komponen yang Terlibat
- VS Code Extensions panel
- Laravel Extension Pack (oleh OneX Developer)

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### Instalasi via terminal VS Code
`
code --install-extension onexlaravel.laravel-extension-pack
`

### Ekstensi yang termasuk dalam pack:
- Laravel Snippets
- Laravel Blade Snippets
- Laravel goto view
- Laravel Extra IntelliSense
- DotENV
- Laravel Artisan

## Cara Integrasi & Pengujian
1. Buka VS Code, klik ikon Extensions (Ctrl+Shift+X)
2. Cari "Laravel Extension Pack" oleh OneX Developer
3. Klik Install
4. Setelah selesai, restart VS Code
5. Saat membuka file blade, sintaks highlight otomatis aktif
6. Fitur goto view akan muncul saat Ctrl+klik nama view
