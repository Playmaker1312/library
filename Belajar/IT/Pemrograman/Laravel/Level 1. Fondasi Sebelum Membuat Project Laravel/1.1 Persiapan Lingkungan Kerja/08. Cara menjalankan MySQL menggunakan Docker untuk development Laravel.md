# 08. Cara Menjalankan MySQL Menggunakan Docker untuk Development Laravel

## Definisi & Target
Menjalankan MySQL dalam container Docker agar Laravel dapat menyimpan data relasional. Target: container MySQL berjalan dan Laravel berhasil migrate.

## Komponen yang Terlibat
- Docker Desktop
- File docker-compose.yml
- File .env Laravel

## Perintah Artisan CLI
`
php artisan migrate
`

## Kode Implementasi (Per File)
### docker-compose.yml
`yaml
services:
  mysql:
    image: mysql:8.0
    container_name: laravel_mysql
    ports:
      - "3306:3306"
    environment:
      MYSQL_DATABASE: laravel
      MYSQL_USER: laravel
      MYSQL_PASSWORD: secret
      MYSQL_ROOT_PASSWORD: root
    volumes:
      - mysql_data:/var/lib/mysql

volumes:
  mysql_data:
`

### File .env (Laravel)
`
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel
DB_USERNAME=laravel
DB_PASSWORD=secret
`

## Cara Integrasi & Pengujian
1. Letakkan docker-compose.yml di root project Laravel
2. Jalankan docker compose up -d mysql
3. Verifikasi container berjalan: docker ps
4. Update .env dengan konfigurasi di atas
5. Jalankan php artisan migrate untuk menguji koneksi
6. Gunakan TablePlus/DBeaver untuk melihat data di database
