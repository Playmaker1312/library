# 03. Cara Menginstal Laravel Installer menggunakan Perintah Composer Global Require

## Definisi & Target
Laravel Installer mempermudah pembuatan project baru. Target: perintah laravel new tersedia di terminal global.

## Komponen yang Terlibat
- Composer (global composer.json)
- Laravel Installer package

## Perintah Artisan CLI
Tidak langsung. Namun setelah instalasi, pembuatan project menjadi:
`
laravel new nama-project
`

## Kode Implementasi (Per File)
### Langkah Instalasi
`
composer global require laravel/installer
`

### Pastikan direktori global composer ada di PATH
Path yang perlu ditambahkan:
`
%USERPROFILE%\AppData\Roaming\Composer\vendor\bin
`

## Cara Integrasi & Pengujian
1. Jalankan composer global require laravel/installer
2. Tambahkan direktori vendor/bin global ke PATH jika belum ada
3. Buka terminal baru, ketik laravel
4. Jika muncul daftar perintah Laravel Installer, instalasi berhasil
5. Untuk membuat project: laravel new nama-app

# 04. Cara Menginstal Laragon sebagai Lingkungan Development All-in-One di Windows

## Definisi & Target
Laragon menyediakan Apache/Nginx, PHP, MySQL, dan tools lain dalam satu paket untuk Windows. Target: Laragon berjalan dan halaman Welcome muncul.

## Komponen yang Terlibat
- Laragon installer (laragon-wsl.exe atau laragon-full.exe)
- Services: Apache/Nginx, MySQL/MariaDB, PHP

## Perintah Artisan CLI
Setelah Laragon terinstal, Laravel bisa diakses melalui php artisan serve dari folder project.

## Kode Implementasi (Per File)
### Konfigurasi Laragon
Buka Laragon > Menu > Preferences:
- Document Root: C:\Users\...\Laragon\www
- Pastikan Apache dan MySQL berstatus running

### Membuat project Laravel di Laragon
`
cd C:\laragon\www
laravel new blog
`

Lalu akses: http://blog.test

## Cara Integrasi & Pengujian
1. Unduh Laragon Full dari laragon.org/download
2. Jalankan installer dan pilih direktori (default C:\laragon)
3. Buka Laragon, klik "Start All"
4. Indikator Apache dan MySQL berubah hijau
5. Buka browser ke http://localhost — tampil halaman Laragon
6. Project Laravel bisa diletakkan di C:\laragon\www

# 05. Cara Menginstal Laravel Herd sebagai Lingkungan Development Modern di macOS

## Definisi & Target
Laravel Herd menyediakan Nginx, PHP, dan DNS resolver otomatis untuk macOS. Target: Herd berjalan dan project Laravel bisa diakses via .test domain.

## Komponen yang Terlibat
- Laravel Herd aplikasi macOS
- Nginx, PHP 8.x, DNS resolver bawaan

## Perintah Artisan CLI
Tidak perlu php artisan serve — Herd menggunakan Nginx sebagai proxy.

## Kode Implementasi (Per File)
### Pembuatan Project via Herd
`
cd ~/Herd
laravel new blog
`

Akses: http://blog.test

## Cara Integrasi & Pengujian
1. Unduh Laravel Herd dari herd.laravel.com
2. Pindahkan ke folder Applications dan jalankan
3. Klik "Start Herd" — ikon Herd muncul di menu bar
4. Buat folder ~/Herd/sites jika belum ada
5. Semua project di folder tersebut otomatis terdeteksi dengan domain .test
6. Buka browser ke http://blog.test

# 06. Cara Menginstal Docker Desktop untuk Kebutuhan Containerisasi Database dan Service

## Definisi & Target
Docker Desktop memungkinkan menjalankan database (PostgreSQL, MySQL, Redis) dalam container tanpa instalasi native. Target: docker --version dan docker compose version berfungsi.

## Komponen yang Terlibat
- Docker Desktop installer
- WSL 2 (untuk Windows) atau Hyper-V backend
- docker-compose.yml untuk konfigurasi service

## Perintah Artisan CLI
Tidak langsung. Namun Docker digunakan bersama Laravel Sail:
`
php artisan sail:install
`

## Kode Implementasi (Per File)
### Verifikasi Instalasi
`
docker --version
docker compose version
`

## Cara Integrasi & Pengujian
1. Unduh Docker Desktop dari docker.com/products/docker-desktop
2. Jalankan installer, pastikan WSL 2 backend dipilih
3. Restart komputer jika diminta
4. Buka Docker Desktop, tunggu engine mulai
5. Buka terminal, ketik docker run hello-world
6. Jika container hello-world berjalan, instalasi sukses
