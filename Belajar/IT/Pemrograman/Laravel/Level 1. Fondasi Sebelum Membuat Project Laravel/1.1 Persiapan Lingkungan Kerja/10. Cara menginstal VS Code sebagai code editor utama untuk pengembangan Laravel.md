# 10. Cara Menginstal VS Code sebagai Code Editor Utama untuk Pengembangan Laravel

## Definisi & Target
VS Code adalah editor kode ringan namun kaya fitur untuk menulis PHP dan Blade. Target: VS Code terinstal dan bisa membuka folder project Laravel.

## Komponen yang Terlibat
- VS Code installer
- Integrated terminal

## Perintah Artisan CLI
Dari terminal VS Code:
`
php artisan serve
`

## Kode Implementasi (Per File)
### Opening project via terminal
`
code /path/to/laravel-project
`

### Setting VS Code untuk Laravel
Buka Settings (Ctrl+,), cari:
- Files > Associations: tambahkan *.blade.php = html
- Editor: Format On Save = true

## Cara Integrasi & Pengujian
1. Unduh VS Code dari code.visualstudio.com
2. Jalankan installer, centang "Add to PATH"
3. Buka VS Code, buka folder project Laravel via File > Open Folder
4. Buka terminal bawaan (Ctrl+) dan ketik php artisan serve
5. Editor siap digunakan untuk coding Laravel
