# 12. Cara Menginstal Ekstensi PHP Intelephense di VS Code untuk Autocomplete PHP

## Definisi & Target
PHP Intelephense memberikan autocomplete, navigasi kode, dan type checking untuk PHP. Target: autocomplete bekerja saat mengetik kode Laravel.

## Komponen yang Terlibat
- VS Code Extensions panel
- PHP Intelephense (oleh Ben Mewburn)

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### Instalasi via terminal
`
code --install-extension bmewburn.vscode-intelephense-client
`

### Setting VS Code
`
"intelephense.files.associations": ["*.php", "*.blade.php"],
"php.suggest.basic": false
`

## Cara Integrasi & Pengujian
1. Buka VS Code Extensions (Ctrl+Shift+X)
2. Cari "PHP Intelephense" oleh Ben Mewburn
3. Klik Install
4. Buka file outes/web.php — coba ketik Route:: dan lihat autocomplete muncul
5. Intelephense juga mendeteksi parameter type dan return type
6. Untuk fitur premium (laravel), lisensi opsional via pembelian
