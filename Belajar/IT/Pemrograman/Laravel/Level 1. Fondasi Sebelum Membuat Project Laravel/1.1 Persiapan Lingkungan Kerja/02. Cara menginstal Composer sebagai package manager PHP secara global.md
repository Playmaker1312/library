# 02. Cara Menginstal Composer sebagai Package Manager PHP secara Global

## Definisi & Target
Composer mengelola dependency PHP. Target: perintah composer --version bisa dijalankan dari mana saja.

## Komponen yang Terlibat
- File installer Composer (Composer-Setup.exe)
- Environment variable PATH

## Perintah Artisan CLI
Tidak ada. Composer adalah tool terpisah.

## Kode Implementasi (Per File)
### Verifikasi Instalasi
`
composer --version
`

### Inisialisasi composer.json di project
`
composer init
`

## Cara Integrasi & Pengujian
1. Unduh Composer-Setup.exe dari getcomposer.org
2. Jalankan installer, biarkan mendeteksi PHP otomatis
3. Pastikan opsi "Add to PATH" dicentang
4. Buka terminal baru, ketik composer --version
5. Composer siap digunakan untuk menginstal package Laravel
