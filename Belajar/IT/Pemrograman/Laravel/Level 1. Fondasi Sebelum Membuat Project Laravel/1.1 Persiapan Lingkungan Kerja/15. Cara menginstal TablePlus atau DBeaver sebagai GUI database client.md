# 14. Cara Menginstal Ekstensi Laravel Blade Snippets di VS Code

## Definisi & Target
Laravel Blade Snippets menyediakan potongan kode cepat untuk directive Blade. Target: mengetik @if lalu Enter menghasilkan struktur if lengkap.

## Komponen yang Terlibat
- VS Code Extensions panel
- Laravel Blade Snippets (oleh Winnie Lin)

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### Instalasi via terminal
`
code --install-extension winnielin.laravel-blade-snippets
`

### Contoh snippets yang tersedia:
| Trigger | Hasil |
|---------|-------|
| @if   | @if (condition) ... @endif |
| @fore | @foreach ( as ) ... @endforeach |
| @sec  | @section('name') ... @endsection |
| @extends | @extends('layout') |
| @include | @include('view') |

## Cara Integrasi & Pengujian
1. Buka VS Code Extensions
2. Cari "Laravel Blade Snippets" oleh Winnie Lin
3. Install
4. Buat file baru 	est.blade.php
5. Ketik @if lalu tekan Tab — snippet lengkap muncul
6. Coba @foreach, @section, dan @extends

# 15. Cara Menginstal TablePlus atau DBeaver sebagai GUI Database Client

## Definisi & Target
GUI database client memudahkan melihat, mengedit, dan mengelola data tanpa SQL manual. Target: bisa terkoneksi ke database Laravel dan melihat tabel.

## Komponen yang Terlibat
- TablePlus atau DBeaver installer
- Database credentials (dari .env Laravel)

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### Konfigurasi Koneksi di TablePlus
- Connection Type: MySQL / PostgreSQL
- Host: 127.0.0.1
- Port: 3306 (MySQL) / 5432 (PostgreSQL)
- User: laravel
- Password: secret
- Database: laravel

### Konfigurasi Koneksi di DBeaver
- Klik New Database Connection
- Pilih MySQL atau PostgreSQL
- Isi Host, Port, Database, Username, Password
- Test Connection

## Cara Integrasi & Pengujian
1. Unduh TablePlus (tableplus.com) atau DBeaver (dbeaver.io)
2. Install dan buka aplikasi
3. Buat koneksi baru dengan credentials dari .env Laravel
4. Klik Test Connection — pastikan sukses
5. Setelah migrate, tabel akan muncul di panel kiri
6. Gunakan untuk melihat data, menjalankan query, atau mengedit langsung
