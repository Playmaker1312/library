# 09. Cara Menjalankan Redis Menggunakan Docker untuk Caching dan Queue Laravel

## Definisi & Target
Redis digunakan sebagai cache driver dan queue backend yang cepat untuk Laravel. Target: container Redis berjalan dan Laravel bisa terkoneksi.

## Komponen yang Terlibat
- Docker Desktop
- File docker-compose.yml
- File .env Laravel
- predis/predis package (via Composer)

## Perintah Artisan CLI
`
composer require predis/predis
php artisan config:cache
`

## Kode Implementasi (Per File)
### docker-compose.yml
`yaml
services:
  redis:
    image: redis:7-alpine
    container_name: laravel_redis
    ports:
      - "6379:6379"
    command: redis-server --appendonly yes
    volumes:
      - redis_data:/data

volumes:
  redis_data:
`

### File .env (Laravel)
`
REDIS_HOST=127.0.0.1
REDIS_PASSWORD=null
REDIS_PORT=6379

CACHE_DRIVER=redis
QUEUE_CONNECTION=redis
`

## Cara Integrasi & Pengujian
1. Tambahkan service redis ke docker-compose.yml
2. Jalankan docker compose up -d redis
3. Install predis: composer require predis/predis
4. Update .env dengan konfigurasi di atas
5. Jalankan php artisan tinker lalu Cache::put('test', 'ok', 10); Cache::get('test');
6. Jika mengembalikan 'ok', Redis berfungsi
