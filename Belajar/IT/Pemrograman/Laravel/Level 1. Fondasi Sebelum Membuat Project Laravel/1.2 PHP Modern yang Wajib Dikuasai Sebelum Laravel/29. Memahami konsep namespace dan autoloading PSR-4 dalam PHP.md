# 29. Memahami Konsep Namespace dan Autoloading PSR-4 dalam PHP

## Definisi & Target
Namespace mencegah konflik nama class, PSR-4 autoloading memuat class otomatis. Target: memahami mapping namespace ke direktori dan cara composer autoload bekerja.

## Komponen yang Terlibat
- Semua file PHP di pp/
- File composer.json
- File endor/autoload.php

## Perintah Artisan CLI
`
composer dump-autoload
`

## Kode Implementasi (Per File)
### Struktur Namespace di Laravel
Direktori pp/Services/PaymentService.php:
`php
<?php

namespace App\Services;

class PaymentService
{
    // ...
}
`

### Mapping PSR-4 di composer.json
`json
{
    "autoload": {
        "psr-4": {
            "App\\": "app/",
            "Database\\Factories\\": "database/factories/",
            "Database\\Seeders\\": "database/seeders/"
        }
    }
}
`

### Cara Menggunakan Namespace
`php
use App\Services\PaymentService;
use App\Enums\UserRole;
use App\Exceptions\InsufficientStockException;

class OrderController extends Controller
{
    public function __construct(
        private PaymentService ,
    ) {}
}
`

## Cara Integrasi & Pengujian
1. Namespace Laravel dimulai dengan App\ yang merujuk ke folder pp/
2. Setiap class membutuhkan namespace yang sesuai dengan path-nya
3. Laravel secara otomatis mendaftarkan PSR-4 melalui composer.json
4. Jika menambahkan folder baru, jalankan composer dump-autoload
5. Gunakan use statement untuk mengimpor class
