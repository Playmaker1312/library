# 24. Memahami PHP 8.2 Readonly Classes untuk Immutable Class

## Definisi & Target
Readonly class membuat semua property otomatis readonly. Target: menciptakan immutable class tanpa mendeklarasikan readonly per property.

## Komponen yang Terlibat
DTO, Value Object, atau Configuration class.

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### app/DTOs/ProductDTO.php
`php
<?php

namespace App\DTOs;

readonly class ProductDTO
{
    public function __construct(
        public string ,
        public float ,
        public int ,
        public ?string  = null,
    ) {}
}
`

### Controller menggunakan Readonly Class
`php
use App\DTOs\ProductDTO;

public function store(ProductRequest )
{
     = new ProductDTO(
        name: ->name,
        price: ->price,
        stock: ->stock,
        category: ->category,
    );

    Product::create((array) );
}
`

## Cara Integrasi & Pengujian
1. Readonly class tersedia di PHP 8.2+
2. Semua property di readonly class secara otomatis readonly
3. Tidak bisa memiliki static property
4. Tidak bisa di-extends â€” class final secara implisit
5. Gunakan untuk data yang tidak boleh berubah setelah dibuat
