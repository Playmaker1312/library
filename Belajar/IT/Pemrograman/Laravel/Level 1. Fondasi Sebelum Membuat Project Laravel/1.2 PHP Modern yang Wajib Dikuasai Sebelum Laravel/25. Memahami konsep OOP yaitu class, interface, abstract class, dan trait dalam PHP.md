## Kode Implementasi (Per File)
### Interface â€” kontrak method
`php
<?php

namespace App\Contracts;

interface PaymentGateway
{
    public function charge(int ): array;
    public function refund(string ): array;
}
`

### Abstract Class â€” kerajaan dengan implementasi dasar
`php
<?php

namespace App\Services;

abstract class PaymentProvider
{
    abstract protected function getEndpoint(): string;

    protected function logTransaction(string ): void
    {
        logger("Payment {}");
    }
}
`

### Trait â€” reusable code tanpa inheritance
`php
<?php

namespace App\Traits;

trait HasTimestamps
{
    public function scopeRecent()
    {
        return ->where('created_at', '>=', now()->subDays(7));
    }
}
`

### Class â€” implementasi konkret
`php
<?php

namespace App\Services;

use App\Contracts\PaymentGateway;

class MidtransGateway extends PaymentProvider implements PaymentGateway
{
    use HasTimestamps;

    public function charge(int ): array
    {
        ->logTransaction('charging');
        return ['status' => 'success', 'amount' => ];
    }

    public function refund(string ): array
    {
        return ['status' => 'refunded'];
    }

    protected function getEndpoint(): string
    {
        return 'https://api.midtrans.com/v2';
    }
}
`

## Cara Integrasi & Pengujian
1. Interface digunakan di Laravel untuk binding ke Service Container
2. Abstract class untuk shared logic antar service
3. Trait untuk menambahkan method ke Model atau Controller
4. Laravel secara ekstensif menggunakan OOP: Controller, Model, Service Provider
