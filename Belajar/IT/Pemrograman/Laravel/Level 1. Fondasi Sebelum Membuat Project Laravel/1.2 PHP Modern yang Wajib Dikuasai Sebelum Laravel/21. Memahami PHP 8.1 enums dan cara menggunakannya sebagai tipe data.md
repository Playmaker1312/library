# 21. Memahami PHP 8.1 Enums dan Cara Menggunakannya sebagai Tipe Data

## Definisi & Target
Enum menyediakan kumpulan konstanta bertipe yang aman. Target: mampu membuat dan menggunakan backed enum untuk status, role, atau kode tetap lainnya.

## Komponen yang Terlibat
- File enum di pp/Enums/
- Model, Controller, Migration

## Perintah Artisan CLI
`
php artisan make:enum UserRole
`
(Catatan: perintah di atas memerlukan package tambahan, atau buat manual)

## Kode Implementasi (Per File)
### app/Enums/UserRole.php
`php
<?php

namespace App\Enums;

enum UserRole: string
{
    case Admin = 'admin';
    case Editor = 'editor';
    case User = 'user';

    public function label(): string
    {
        return match () {
            self::Admin => 'Administrator',
            self::Editor => 'Editor',
            self::User => 'Pengguna',
        };
    }
}
`

### Controller
`php
use App\Enums\UserRole;

public function updateRole(Request , User )
{
     = ->validate([
        'role' => ['required', 'string', Rule::enum(UserRole::class)],
    ]);

    ->role = UserRole::from(['role']);
    ->save();
}
`

### Migration
`php
Schema::table('users', function (Blueprint ) {
    ->string('role')->default(UserRole::User->value);
});
`

## Cara Integrasi & Pengujian
1. Buat folder pp/Enums/ jika belum ada
2. Buat file enum dengan sintaks PHP 8.1
3. Gunakan di migration untuk default value
4. Gunakan di Controller untuk validasi dan logic
5. Akses nilai: UserRole::Admin->value atau UserRole::Admin->label()

# 22. Memahami PHP 8.1 Readonly Properties untuk Immutable Object

## Definisi & Target
Readonly property hanya bisa diassign sekali (di constructor) dan tidak bisa diubah setelahnya. Target: menciptakan object yang aman dan predictable.

## Komponen yang Terlibat
DTO (Data Transfer Object) atau class yang membutuhkan immutability.

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### app/DTOs/UserDTO.php
`php
<?php

namespace App\DTOs;

class UserDTO
{
    public function __construct(
        public readonly string ,
        public readonly string ,
        public readonly ?string  = null,
    ) {}
}
`

### Controller menggunakan DTO
`php
use App\DTOs\UserDTO;

public function store(Request )
{
     = new UserDTO(
        name: ->input('name'),
        email: ->input('email'),
        phone: ->input('phone'),
    );

     = User::create((array) );
}
`

## Cara Integrasi & Pengujian
1. Readonly properties tersedia di PHP 8.1+
2. Cocok untuk DTO, Value Object, dan Configuration object
3. PHP 8.2 mendukung readonly classes (semua property otomatis readonly)
4. Tidak bisa digunakan dengan unset() atau assignment ulang
