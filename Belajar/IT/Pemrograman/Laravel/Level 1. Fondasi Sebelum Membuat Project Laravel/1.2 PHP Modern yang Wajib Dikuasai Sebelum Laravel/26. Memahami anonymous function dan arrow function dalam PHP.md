# 26. Memahami Anonymous Function dan Arrow Function dalam PHP

## Definisi & Target
Anonymous function (closure) dan arrow function dipakai untuk callback, collection pipeline, dan event handler. Target: mampu menulis callback yang ringkas.

## Komponen yang Terlibat
Controller, Service class, atau file yang memproses collection Eloquent.

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### Anonymous Function
`php
 = function (string ): string {
    return "Halo, !";
};

echo ('Andi');
`

### Arrow Function (PHP 7.4+)
`php
 = fn(string ): string => "Halo, !";
`

### Contoh di Laravel â€” Collection Pipeline
`php
 = Order::query()
    ->where('status', 'completed')
    ->get()
    ->filter(fn(Order ) => ->amount > 0)
    ->map(fn(Order ) => ->amount)
    ->sum();
`

### Closure sebagai Callback
`php
Route::middleware(function (, ) {
    ->attributes->set('start_time', microtime(true));
    return ();
});
`

## Cara Integrasi & Pengujian
1. Arrow function tidak bisa memiliki multi-statement
2. Arrow function otomatis mengakses variable parent scope (tidak perlu use)
3. Anonymous function perlu use untuk mengakses variable parent
4. Banyak digunakan di Collection, Query Builder, dan Event/Listener
