# 17. Memahami PHP 8 Match Expression sebagai Pengganti Switch yang Lebih Ekspresif

## Definisi & Target
Match expression mengembalikan nilai tanpa perlu break, mendukung multiple condition per baris, dan strict comparison. Target: mampu mengganti switch-case dengan match di kode Laravel.

## Komponen yang Terlibat
Controller atau Service class yang membutuhkan logika percabangan.

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### Contoh Match Expression
`php
 = match () {
    'A' => 'Sangat Baik',
    'B' => 'Baik',
    'C', 'D' => 'Kurang',
    default => 'Tidak Lulus',
};
`

### Contoh di Laravel Controller
`php
public function getStatusMessage(string ): string
{
    return match () {
        'pending' => 'Menunggu persetujuan',
        'approved' => 'Telah disetujui',
        'rejected' => 'Ditolak',
        'revision' => 'Perlu revisi',
        default => 'Status tidak dikenal',
    };
}
`

## Cara Integrasi & Pengujian
1. Match expression tersedia di PHP 8.0+
2. Gunakan saat membutuhkan percabangan yang mengembalikan nilai
3. Berbeda dengan switch, match menggunakan === (strict comparison)
4. Jika tidak ada default dan tidak ada yang cocok, throw UnhandledMatchError
