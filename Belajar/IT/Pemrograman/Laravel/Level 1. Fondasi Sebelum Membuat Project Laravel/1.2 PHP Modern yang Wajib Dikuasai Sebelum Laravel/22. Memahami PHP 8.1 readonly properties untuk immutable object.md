# 22. Memahami PHP 8.1 Readonly Properties untuk Immutable Object

## Definisi & Target
Readonly property hanya bisa diassign sekali (di constructor) dan tidak bisa diubah setelahnya. Target: menciptakan object yang aman dan predictable.

## Komponen yang Terlibat
DTO (Data Transfer Object) atau class yang membutuhkan immutability.

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### app/DTOs/UserDTO.php
```php
<?php

namespace App\DTOs;

class UserDTO
{
    public function __construct(
        public readonly string $name,
        public readonly string $email,
        public readonly ?string $phone = null,
    ) {}
}
```

### Controller menggunakan DTO
```php
use App\DTOs\UserDTO;

public function store(Request $request)
{
    $dto = new UserDTO(
        name: $request->input('name'),
        email: $request->input('email'),
        phone: $request->input('phone'),
    );

    $user = User::create((array) $dto);
}
```

## Cara Integrasi & Pengujian
1. Readonly properties tersedia di PHP 8.1+
2. Cocok untuk DTO, Value Object, dan Configuration object
3. PHP 8.2 mendukung readonly classes (semua property otomatis readonly)
4. Tidak bisa digunakan dengan `unset()` atau assignment ulang
