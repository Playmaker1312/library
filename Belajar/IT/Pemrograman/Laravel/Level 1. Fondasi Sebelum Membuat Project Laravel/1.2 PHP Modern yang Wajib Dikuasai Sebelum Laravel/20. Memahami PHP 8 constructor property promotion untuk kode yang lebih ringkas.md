# 20. Memahami PHP 8 Constructor Property Promotion untuk Kode yang Lebih Ringkas

## Definisi & Target
Constructor property promotion menggabungkan deklarasi property dan assignment dalam satu sintaks. Target: kode class menjadi lebih ringkas tanpa boilerplate.

## Komponen yang Terlibat
Controller, Service class, atau class lain di Laravel yang memiliki dependency injection via constructor.

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### Tanpa Property Promotion â€” verbose
`php
class UserController
{
    private UserService ;
    private Logger ;

    public function __construct(UserService , Logger )
    {
        ->userService = ;
        ->logger = ;
    }
}
`

### Dengan Property Promotion â€” ringkas
`php
class UserController
{
    public function __construct(
        private UserService ,
        private Logger ,
    ) {}
}
`

### Contoh di Laravel Controller
`php
class PostController extends Controller
{
    public function __construct(
        private PostService ,
        private MediaService ,
    ) {}
}
`

## Cara Integrasi & Pengujian
1. Constructor property promotion tersedia di PHP 8.0+
2. Laravel secara otomatis meng-inject dependency melalui constructor
3. Akses property seperti biasa: $this->postService
4. Bisa dikombinasikan dengan readonly properties (PHP 8.1)
