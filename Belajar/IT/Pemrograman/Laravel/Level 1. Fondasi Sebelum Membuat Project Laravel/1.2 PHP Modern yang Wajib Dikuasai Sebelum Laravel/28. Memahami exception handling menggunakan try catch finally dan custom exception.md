# 28. Memahami Exception Handling Menggunakan Try Catch Finally dan Custom Exception

## Definisi & Target
Exception handling menangani error yang terjadi saat runtime. Target: mampu membuat custom exception dan menanganinya dengan try-catch-finally.

## Komponen yang Terlibat
- Custom Exception class di pp/Exceptions/
- Handler di pp/Exceptions/Handler.php
- Controller yang melempar exception

## Perintah Artisan CLI
`
php artisan make:exception InsufficientStockException
`

## Kode Implementasi (Per File)
### Custom Exception
`php
<?php

namespace App\Exceptions;

use Exception;

class InsufficientStockException extends Exception
{
    public function __construct(
        string  = '',
        int  = 0,
        ?Throwable  = null
    ) {
         = "Stok tidak mencukupi untuk produk: {}";
        parent::__construct(, , );
    }

    public function render(): \Illuminate\Http\JsonResponse
    {
        return response()->json([
            'message' => ->getMessage(),
        ], 422);
    }
}
`

### Controller dengan Exception Handling
`php
public function checkout(CheckoutRequest )
{
    try {
         = ->orderService->processOrder(->validated());
        return redirect()->route('orders.show', );
    } catch (InsufficientStockException ) {
        return back()->withErrors(['stock' => ->getMessage()]);
    } catch (\Exception ) {
        Log::error('Checkout failed', ['error' => ->getMessage()]);
        return back()->with('error', 'Terjadi kesalahan sistem.');
    }
}
`

### Exception Handler (app/Exceptions/Handler.php)
`php
public function register(): void
{
    ->reportable(function (InsufficientStockException ) {
        Log::warning('Stock issue', [
            'message' => ->getMessage(),
        ]);
    });
}
`

## Cara Integrasi & Pengujian
1. Buat custom exception dengan php artisan make:exception
2. Lempar exception dengan 	hrow new InsufficientStockException('Product A')
3. Tangkap di Controller dengan try-catch
4. Gunakan inally jika ada kode yang harus tetap dijalankan
5. Custom render method mengontrol response JSON/View
