# 30. Memahami Konsep Dependency Injection dalam PHP sebelum Menggunakannya di Laravel

## Definisi & Target
Dependency Injection (DI) memberikan dependency dari luar, bukan membuat di dalam class. Target: memahami prinsip DI dan bagaimana Laravel Service Container mengelola dependency.

## Komponen yang Terlibat
- Controller, Service, atau class yang menerima dependency
- Service Container (Laravel bindings)

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)

`php

    private Logger ;

    public function __construct()

        ->logger = new Logger();
    }

### Dengan DI â€” loose coupling
`php

{
    public function __construct(
        private Logger ,
        private PaymentService ,
    ) {}
}
`

### Manual DI tanpa framework
`php
 = new Logger();
 = new PaymentService();
 = new OrderController(, );

### DI di Laravel â€” otomatis oleh Service Container
`php

{
    public function __construct(
        private OrderService ,
        private PaymentService ,
    ) {}
}
`

## Cara Integrasi & Pengujian
1. Laravel Service Container secara otomatis meng-inject dependency di constructor
2. Untuk interface binding, daftarkan di Service Provider
3. Prinsip DI membuat kode lebih testable â€” mudah diganti mock
