# 19. Memahami PHP 8 Union Types untuk Type Declaration yang Lebih Fleksibel

## Definisi & Target
Union types memungkinkan parameter atau return value memiliki lebih dari satu tipe. Target: mampu mendeklarasikan tipe yang fleksibel dengan sintaks 	ipe1|tipe2.

## Komponen yang Terlibat
Controller, Model, atau Form Request yang membutuhkan type declaration multi-tipe.

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### Contoh Union Types
`php
public function findById(string|int ): User|null
{
    return User::where('id', )->orWhere('uuid', )->first();
}
`

### Contoh di Laravel Controller
`php
public function formatValue(string|int|float ): string
{
    return number_format((float) , 2, ',', '.');
}
`

### Form Request dengan Union Types
`php
public function rules(): array
{
    return [
        'user_id' => ['required', 'string|int'],
        'amount' => ['required', 'numeric'],
    ];
}
`

## Cara Integrasi & Pengujian
1. Union types tersedia di PHP 8.0+
2. Void tidak bisa digunakan dalam union type
3. Null bisa ditulis sebagai ?string atau string|null
4. Gunakan di type hint parameter, return type, dan property
