# 16. Memahami PHP 8 Named Arguments dan Cara Penggunaannya

## Definisi & Target
Named arguments memungkinkan parameter fungsi dipanggil berdasarkan nama, bukan posisi. Target: mampu menulis kode yang lebih ekspresif dan tidak bergantung urutan parameter.

## Komponen yang Terlibat
Tidak ada file spesifik. Cukup dipahami sebagai sintaks PHP 8+ yang akan digunakan di Controller, Model, atau class Laravel lainnya.

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### Contoh Named Arguments di PHP 8
`php
function buatPengguna(string , string , bool  = true, string  = 'user'): array
{
    return compact('nama', 'email', 'aktif', 'role');
}

// Tanpa named arguments
buatPengguna('Andi', 'andi@mail.com', true, 'admin');

// Dengan named arguments â€” lebih jelas
buatPengguna(
    nama: 'Andi',
    email: 'andi@mail.com',
    role: 'admin'
);
`

### Contoh di Laravel Controller
`php
public function store(Request )
{
    return redirect()->route('dashboard', ['user' => ->user()->id]);
}
`

## Cara Integrasi & Pengujian
1. Named arguments bisa langsung digunakan di file PHP 8.1+
2. Jalankan php -v untuk memastikan versi PHP 8.1+
3. Coba tulis fungsi dengan parameter banyak dan panggil menggunakan named arguments
4. Named arguments sangat berguna saat memanggil method Laravel dengan parameter opsional
