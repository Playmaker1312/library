# 23. Memahami PHP 8.1 Fibers untuk Concurrency Dasar

## Definisi & Target
Fibers memungkinkan eksekusi kode secara asynchronous dalam satu thread. Target: memahami konsep dasar fiber untuk future-proofing, meski jarang dipakai langsung di Laravel.

## Komponen yang Terlibat
Tidak ada file spesifik. Fiber digunakan oleh framework/library, bukan langsung oleh developer Laravel.

## Perintah Artisan CLI
Tidak ada.

## Kode Implementasi (Per File)
### Contoh Fiber Sederhana
`php
 = new Fiber(function (): void {
     = Fiber::suspend('mengirim data');
    echo "Lanjut dengan: ";
});

 = ->start();
echo ;

->resume('data selesai');
`

### Konteks di Laravel
Laravel menggunakan Fiber di dalam proses async seperti Laravel Octane dan beberapa library queue. Developer umumnya tidak perlu membuat Fiber secara manual.

## Cara Integrasi & Pengujian
1. Fibers tersedia di PHP 8.1+
2. Jalankan script PHP yang mengandung Fiber untuk melihat alur eksekusi
3. Fiber mirip dengan Generator tetapi bisa di-suspend dari dalam call stack
4. Penting untuk diketahui jika bekerja dengan Laravel Octane atau ReactPHP
