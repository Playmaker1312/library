# 160. limit offset pagination manual

## Definisi Singkat
`limit()` dan `skip()` (atau `offset()`) digunakan untuk membatasi jumlah record dan menentukan posisi awal pengambilan — pagination manual.

## Analogi
Seperti membaca buku — `limit` = berapa halaman yang dibaca, `skip` = dari halaman berapa mulai membaca. Misal: skip(10) artinya lewati 10 halaman, limit(5) ambil 5 halaman.

## Poin-Poin Penting
- `limit(n)` — batasi jumlah record (LIMIT n)
- `skip(n)` — lewati n record (OFFSET n)
- `offset(n)` — alias dari `skip()`
- `take(n)` — alias dari `limit()`
- `forPage(page, perPage)` — shorthand untuk pagination manual
- Biasa digunakan untuk custom pagination atau "load more"

## Contoh Kode
```php
use App\Models\Post;
use App\Models\User;

// limit — ambil 10 post terbaru
$posts = Post::latest()->limit(10)->get();
// SELECT * FROM posts ORDER BY created_at DESC LIMIT 10

// skip + limit — manual pagination
// Halaman 1: ambil 10 post pertama
$page1 = Post::skip(0)->take(10)->get();  // OFFSET 0 LIMIT 10

// Halaman 2: lewati 10, ambil 10 berikutnya
$page2 = Post::skip(10)->take(10)->get(); // OFFSET 10 LIMIT 10

// Halaman 3
$page3 = Post::skip(20)->take(10)->get();

// forPage — shorthand
$page = Post::forPage(1, 10)->get();  // skip(0)->take(10)
$page = Post::forPage(2, 10)->get();  // skip(10)->take(10)

// Implementasi pagination manual di controller
public function index(Request $request)
{
    $perPage = 10;
    $page = $request->get('page', 1);
    $offset = ($page - 1) * $perPage;

    $posts = Post::skip($offset)->take($perPage)->get();
    $total = Post::count();

    return view('posts.index', [
        'posts' => $posts,
        'currentPage' => $page,
        'lastPage' => ceil($total / $perPage),
    ]);
}
```

## Kasus Penggunaan Nyata
- Custom pagination yang tidak menggunakan `paginate()`
- Infinite scroll / load more (API ambil 10 data setiap scroll)
- "Show more" button di komentar
- Export data per batch
