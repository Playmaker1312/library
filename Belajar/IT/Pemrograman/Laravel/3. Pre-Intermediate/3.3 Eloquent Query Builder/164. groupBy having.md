# 164. groupBy having

## Definisi Singkat
`groupBy()` mengelompokkan data berdasarkan kolom tertentu. `having()` memfilter hasil pengelompokan — seperti WHERE untuk aggregate.

## Analogi
Seperti mengelompokkan transaksi berdasarkan bulan — lalu hanya menampilkan bulan dengan total penjualan di atas Rp10 juta (HAVING).

## Poin-Poin Penting
- `groupBy('kolom')` — kelompokkan data
- `having('kolom', 'operator', 'nilai')` — filter hasil group
- `having` bisa menggunakan kolom aggregate: `havingRaw('SUM(total) > ?', [1000])`
- `select` harus menyertakan kolom yang di-group
- `groupBy` sering dipakai dengan aggregate functions

## Contoh Kode
```php
use App\Models\Order;
use App\Models\Post;
use App\Models\User;

// Group by role
$usersByRole = User::selectRaw('role, COUNT(*) as total')
                    ->groupBy('role')
                    ->get();
// Output: [{role: 'admin', total: 5}, {role: 'user', total: 100}]

// Group with having
$popularCategories = Post::selectRaw('category_id, COUNT(*) as total')
                          ->groupBy('category_id')
                          ->having('total', '>=', 10)
                          ->get();

// havingRaw — filter aggregate complex
$monthlyRevenue = Order::selectRaw('
                         YEAR(created_at) as year,
                         MONTH(created_at) as month,
                         SUM(total_amount) as revenue
                     ')
                     ->groupBy('year', 'month')
                     ->havingRaw('SUM(total_amount) > ?', [1000000])
                     ->orderBy('year', 'desc')
                     ->orderBy('month', 'desc')
                     ->get();

// Group by multiple columns
$stats = Product::selectRaw('category_id, supplier_id, COUNT(*) as total')
                ->groupBy('category_id', 'supplier_id')
                ->get();

// where sebelum groupBy
$activeUsersByRole = User::where('is_active', true)
                          ->selectRaw('role, COUNT(*) as total')
                          ->groupBy('role')
                          ->get();
```

## Kasus Penggunaan Nyata
- Laporan penjualan per bulan/per tahun
- Jumlah user per role
- Kategori dengan post di atas jumlah tertentu
- Rata-rata rating per produk
- Group produk berdasarkan supplier
