# 156. Metode Select Kolom

## Definisi Singkat
`select()` digunakan untuk menentukan kolom mana saja yang akan diambil dalam query, menggantikan `SELECT *` dengan hanya kolom yang diperlukan.

## Analogi
Seperti memesan menu prasmanan — daripada mengambil semua makanan (SELECT *), Anda cukup memilih lauk yang diinginkan (SELECT kolom tertentu).

## Poin-Poin Penting
- `select('kolom1', 'kolom2')` atau `select(['kolom1', 'kolom2'])`
- `addSelect('kolom')` untuk menambah kolom ke select yang sudah ada
- `selectRaw('COUNT(*) as total')` untuk raw expression
- Mengurangi memory usage dengan hanya mengambil kolom dibutuhkan
- Penting untuk query dengan join (hindari ambiguitas kolom)

## Contoh Kode
```php
use App\Models\User;
use App\Models\Post;

// Pilih kolom tertentu
$users = User::select('id', 'name', 'email')->get();
// SELECT id, name, email FROM users

// Bentuk array
$users = User::select(['id', 'name', 'email'])->get();

// addSelect — tambah kolom ke query yang sudah ada
$query = User::select('id', 'name');
$query->addSelect('email');
$users = $query->get();

// selectRaw — ekspresi SQL mentah
$posts = Post::selectRaw('COUNT(*) as total_posts')
             ->selectRaw('YEAR(created_at) as year')
             ->groupBy('year')
             ->get();

// Hindari ambiguitas saat join
$users = User::select('users.id', 'users.name', 'roles.name as role_name')
             ->join('roles', 'users.role_id', '=', 'roles.id')
             ->get();

// Distinct — hilangkan duplikat
$cities = User::select('city')->distinct()->get();
```

## Kasus Penggunaan Nyata
- API response hanya butuh id, name, email — tidak perlu semua kolom
- Report/statistik dengan aggregate function (SUM, COUNT)
- Export data spesifik (misal: export hanya kolom untuk Excel)
- Join query untuk menghindari nama kolom bentrok
