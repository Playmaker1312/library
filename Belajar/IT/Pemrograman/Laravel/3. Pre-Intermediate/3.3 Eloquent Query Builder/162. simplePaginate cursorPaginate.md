# 162. simplePaginate cursorPaginate

## Definisi Singkat
`simplePaginate()` hanya punya "Previous" dan "Next" (tanpa total halaman). `cursorPaginate()` menggunakan cursor (token) untuk performa lebih baik di dataset besar.

## Analogi
- `paginate()`: Peta lengkap dengan semua halaman (tahu total halaman)
- `simplePaginate`: Tombol "Prev/Next" — tidak tahu total berapa halaman
- `cursorPaginate`: Seperti gulir tanpa batas (infinite scroll) — pakai token

## Poin-Poin Penting
- `simplePaginate(n)` — tanpa total count, lebih cepat
- `cursorPaginate(n)` — paling cepat untuk dataset besar
- `simplePaginate` cocok untuk UI "Previous/Next" tanpa nomor halaman
- `cursorPaginate` ideal untuk API/infinite scroll dan tabel besar
- `cursorPaginate` menggunakan `WHERE id > cursor` — lebih efisien dari OFFSET

## Contoh Kode
```php
use App\Models\Post;
use App\Models\User;

// simplePaginate — tanpa total halaman
$posts = Post::simplePaginate(10);
// Hanya punya: prev, next, items
// Tidak punya: total, lastPage, links

// Di view: $posts->links() — hanya prev/next

// cursorPaginate — menggunakan cursor
$posts = Post::orderBy('id')->cursorPaginate(10);
// URL: ?cursor=eyJpZCI6MTAsIl9wb2ludHNUb09u...

// Dapatkan cursor untuk request berikutnya
$nextCursor = $posts->nextCursor();   // cursor untuk halaman berikutnya
$prevCursor = $posts->previousCursor(); // cursor untuk halaman sebelumnya

// URL dari cursor
$posts->nextPageUrl();   // URL dengan cursor next
$posts->previousPageUrl(); // URL dengan cursor prev

// Perbandingan performa:
// 1. paginate(10) = SELECT COUNT(*) + SELECT ... LIMIT 10 OFFSET 0 (full scan)
// 2. simplePaginate(10) = SELECT ... LIMIT 11 OFFSET 0 (lebih cepat, ambil +1)
// 3. cursorPaginate(10) = SELECT ... WHERE id > 10 ORDER BY id LIMIT 10

// Kapan pakai apa?
// - Data < 1000: paginate()
// - Data > 1000 tanpa perlu total: simplePaginate()
// - Data > 10000: cursorPaginate()
```

## Kasus Penggunaan Nyata
- `simplePaginate` — blog dengan prev/next navigasi
- `cursorPaginate` — infinite scroll di feed sosial media
- `cursorPaginate` — API endpoint dengan dataset besar (jutaan record)
- `simplePaginate` — komentar yang tidak perlu menampilkan total halaman
