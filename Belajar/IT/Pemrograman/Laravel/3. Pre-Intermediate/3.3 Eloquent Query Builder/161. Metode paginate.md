# 161. Metode paginate()

## Definisi Singkat
`paginate(n)` adalah method Eloquent yang membagi hasil query menjadi halaman-halaman, dengan informasi navigasi (total, halaman saat ini, link).

## Analogi
Seperti hasil pencarian Google — setiap halaman menampilkan 10 hasil, dengan nomor halaman di bawah dan info "Halaman 2 dari 100".

## Poin-Poin Penting
- `paginate(perPage)` — kembalikan instance `LengthAwarePaginator`
- Otomatis membaca parameter `?page=` dari request
- Mengandung: data, links, total, currentPage, lastPage, dll.
- `appends(['key' => 'value'])` — tambah query string ke link
- `onEachSide(n)` — jumlah link halaman di samping halaman aktif
- `fragment('komentar')` — tambah anchor # ke link

## Contoh Kode
```php
use App\Models\Post;
use App\Models\User;

// Pagination dasar — 10 per halaman
$posts = Post::latest()->paginate(10);
// Baca parameter ?page= dari URL otomatis

// Di view (Blade)
// {{ $posts->links() }}  // render pagination links

// Di controller
public function index()
{
    $posts = Post::latest()->paginate(10);
    return view('posts.index', compact('posts'));
}

// Blade view:
// @foreach ($posts as $post)
//     <h3>{{ $post->title }}</h3>
// @endforeach
//
// {{ $posts->links() }}
// {{ $posts->links('vendor.pagination.bootstrap-5') }}

// Custom pagination
$posts = Post::where('is_published', true)
             ->paginate(
                 perPage: 15,          // 15 per halaman
                 pageName: 'halaman'   // ?halaman=2 bukan ?page=2
             );

// Append query string ke link
$posts = Post::paginate(10)->appends(['search' => 'laravel']);
// ?search=laravel&page=2

// Info dari paginator
$posts->total();          // total semua record
$posts->currentPage();    // halaman sekarang
$posts->lastPage();       // halaman terakhir
$posts->hasMorePages();   // masih ada halaman berikutnya?
$posts->firstItem();      // nomor item pertama
$posts->lastItem();       // nomor item terakhir
```

## Kasus Penggunaan Nyata
- Daftar artikel blog dengan navigasi halaman
- Tabel data di admin panel
- API dengan pagination (otomatis response terstruktur)
- Katalog produk di toko online
- Daftar transaksi/pesanan
