# 159. orderBy latest oldest

## Definisi Singkat
`orderBy()`, `latest()`, dan `oldest()` digunakan untuk mengurutkan hasil query, baik ascending (ASC) maupun descending (DESC).

## Analogi
Seperti mengatur buku di rak — dari yang terbaru ke terlama (latest), dari yang terlama ke terbaru (oldest), atau berdasarkan abjad (orderBy).

## Poin-Poin Penting
- `orderBy('kolom', 'asc/desc')` — urutkan berdasarkan kolom
- `latest('kolom')` — descending (default: created_at)
- `oldest('kolom')` — ascending (default: created_at)
- `reorder()` — reset ordering yang sudah ada
- `inRandomOrder()` — urutan acak
- Bisa multiple orderBy untuk secondary sorting

## Contoh Kode
```php
use App\Models\Post;
use App\Models\User;

// orderBy
$posts = Post::orderBy('created_at', 'desc')->get();
// SELECT * FROM posts ORDER BY created_at DESC

$users = User::orderBy('name', 'asc')->get();
// SELECT * FROM users ORDER BY name ASC

// latest() — shorthand descending (default created_at)
$posts = Post::latest()->get();                    // ORDER BY created_at DESC
$posts = Post::latest('published_at')->get();      // ORDER BY published_at DESC

// oldest() — shorthand ascending
$posts = Post::oldest()->get();                    // ORDER BY created_at ASC
$posts = Post::oldest('published_at')->get();      // ORDER BY published_at ASC

// Multiple orderBy
$posts = Post::orderBy('category_id')
             ->orderBy('created_at', 'desc')
             ->get();
// ORDER BY category_id ASC, created_at DESC

// Urutan acak
$random = Post::inRandomOrder()->first();

// Reset ordering
$query = Post::orderBy('created_at', 'desc');
$query->reorder();  // hapus semua orderBy
$query->orderBy('title');  // ganti dengan yang baru

// Di controller untuk listing
public function index()
{
    $posts = Post::latest()->paginate(10);
    return view('posts.index', compact('posts'));
}
```

## Kasus Penggunaan Nyata
- Tampilkan artikel terbaru di halaman depan (latest)
- Daftar pengguna berdasarkan abjad (orderBy name asc)
- Produk termurah ke termahal (orderBy price asc)
- Random produk untuk "Rekomendasi Hari Ini"
- Sorting tabel di admin panel dengan parameter request
