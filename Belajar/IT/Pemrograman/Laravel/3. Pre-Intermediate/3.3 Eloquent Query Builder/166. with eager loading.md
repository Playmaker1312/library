# 166. with eager loading

## Definisi Singkat
Eager loading menggunakan method `with()` untuk memuat relasi secara efisien, menghindari masalah N+1 query dengan mengambil data relasi dalam 1-2 query saja.

## Analogi
Tanpa eager loading: seperti pergi ke toko 100 kali untuk membeli 100 barang (N+1). Dengan eager loading: seperti pergi sekali dengan daftar belanja dan membawa semua barang sekaligus.

## Poin-Poin Penting
- `Model::with('relasi')->get()` — muat relasi bersamaan
- Bisa multiple: `with(['posts', 'profile'])`
- Bisa nested: `with('posts.comments')`
- Mencegah N+1 problem (query dalam loop)
- Hanya menambah 1-2 query tambahan
- Juga bisa constraints: `with(['posts' => fn($q) => $q->where(...)])`

## Contoh Kode
```php
use App\Models\User;
use App\Models\Post;

// TANPA eager loading — N+1 problem!
$users = User::all();
foreach ($users as $user) {
    echo $user->posts->count();  // 1 query per user!
}
// Total: 1 (users) + N (posts) query

// DENGAN eager loading — 2 query total
$users = User::with('posts')->get();
foreach ($users as $user) {
    echo $user->posts->count();  // sudah di-cache
}
// Total: 1 (users) + 1 (posts) = 2 query

// Multiple relasi
$users = User::with(['posts', 'profile', 'roles'])->get();

// Nested relasi
$users = User::with('posts.comments.author')->get();
// Muat: user → posts → comments → author

// Constraint eager loading
$users = User::with(['posts' => function ($query) {
    $query->where('is_published', true)
          ->orderBy('created_at', 'desc');
}])->get();

// Pilih kolom di relasi
$users = User::with(['posts' => function ($query) {
    $query->select('id', 'title', 'user_id');  // FK wajib ada
}])->get();
```

## Kasus Penggunaan Nyata
- Menampilkan daftar artikel dengan nama penulis
- Daftar produk dengan kategori dan stok
- Profil user dengan post dan komentar mereka
- API endpoint: sertakan data relasi dalam response
