# 169. Metode Chunk Data Besar

## Definisi Singkat
`chunk(n, callback)` memproses data dalam potongan-potongan kecil (chunk) untuk menghindari memory overload saat bekerja dengan dataset besar.

## Analogi
Seperti memindahkan pasir menggunakan ember, bukan sekop truk — ambil sedikit demi sedikit (chunk) agar tidak kelelahan (memory full).

## Poin-Poin Penting
- `Model::chunk(n, function($records) { ... })` — proses per batch
- n = jumlah record per chunk (contoh: 100, 500, 1000)
- Ideal untuk dataset ribuan hingga jutaan record
- Alternatif: `lazy()` (return LazyCollection) — lebih modern
- Alternatif: `cursor()` — mengembalikan generator
- chunk menggunakan `LIMIT` dan `OFFSET` — bisa lambat di offset besar

## Contoh Kode
```php
use App\Models\User;
use App\Models\Post;

// chunk — proses 100 user per batch
User::chunk(100, function ($users) {
    foreach ($users as $user) {
        // Kirim email, update data, export, dll.
        Log::info("Memproses user: $user->id");
    }
});

// chunkById — lebih stabil untuk data yang berubah saat diproses
User::chunkById(100, function ($users) {
    foreach ($users as $user) {
        $user->update(['processed' => true]);
    }
});
// chunkById menggunakan id sebagai cursor, bukan OFFSET

// lazy() — LazyCollection (PHP 8+)
$users = User::lazy(100);
foreach ($users as $user) {
    // proses satu per satu, memory tetap rendah
    echo $user->name;
}

// cursor() — yield satu per satu (generator)
foreach (User::cursor() as $user) {
    // Hanya 1 model dalam memory setiap saat
    echo $user->name;
}

// Contoh export 100.000 user ke CSV
public function exportUsers()
{
    $file = fopen('users_export.csv', 'w');
    fputcsv($file, ['ID', 'Name', 'Email']);

    User::chunk(500, function ($users) use ($file) {
        foreach ($users as $user) {
            fputcsv($file, [$user->id, $user->name, $user->email]);
        }
    });

    fclose($file);
}
```

## Kasus Penggunaan Nyata
- Export ribuan record ke Excel/CSV
- Kirim newsletter ke 50.000 user (proses per 100)
- Update massal data (migrasi data, update kolom)
- Hapus data lama secara bertahap
- Generate laporan dari database besar
