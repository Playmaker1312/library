# 157. where orWhere whereNot

## Definisi Singkat
`where()` untuk kondisi AND, `orWhere()` untuk kondisi OR, dan `whereNot()` untuk negasi — membangun klausa WHERE yang kompleks di query.

## Analogi
Seperti filter pencarian produk: "Merk A ATAU Merk B" (orWhere), DAN "Harga di bawah 100rb" (where), DAN "BUKAN kategori X" (whereNot).

## Poin-Poin Penting
- `where()` — defaultnya AND
- `orWhere()` — menambah kondisi dengan OR
- `whereNot()` — WHERE NOT (kebalikan kondisi)
- `where(function($q) { ... })` — grouping logical (AND/OR dalam kurung)
- Urutan chaining penting untuk logika query

## Contoh Kode
```php
use App\Models\User;
use App\Models\Post;

// where + orWhere
$users = User::where('role', 'admin')
             ->orWhere('role', 'superadmin')
             ->get();
// WHERE role = 'admin' OR role = 'superadmin'

// Kombinasi AND dan OR (butuh grouping)
$users = User::where('is_active', true)
             ->where(function ($query) {
                 $query->where('role', 'admin')
                       ->orWhere('role', 'superadmin');
             })
             ->get();
// WHERE is_active = 1 AND (role = 'admin' OR role = 'superadmin')

// whereNot
$users = User::where('is_active', true)
             ->whereNot('role', 'guest')
             ->get();
// WHERE is_active = 1 AND role != 'guest'

// Multiple orWhere
$posts = Post::where('is_published', true)
             ->where(function ($q) {
                 $q->where('category', 'tutorial')
                   ->orWhere('category', 'news')
                   ->orWhere('category', 'review');
             })
             ->get();

// whereNot dengan callback
$users = User::whereNot(function ($query) {
    $query->where('role', 'admin')
          ->orWhere('role', 'superadmin');
})->get();
// WHERE NOT (role = 'admin' OR role = 'superadmin')
```

## Kasus Penggunaan Nyata
- Filter produk: kategori A ATAU B, dengan harga tertentu
- Pencarian user: nama mengandung "John" ATAU email mengandung "john"
- Pengecualian: ambil semua user KECUALI yang role-nya guest
- Dashboard: tampilkan post dari kategori tertentu dan status tertentu
