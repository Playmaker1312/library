# 170. Metode when conditional query

## Definisi Singkat
`when($kondisi, $callback)` menambahkan kondisi query hanya jika nilai tertentu terpenuhi — menghindari if-else bercabang dalam query.

## Analogi
Seperti saklar otomatis — jika tombol ditekan (kondisi true), lampu menyala (query ditambahkan). Jika tidak, saklar diabaikan.

## Poin-Poin Penting
- `when(true, fn($q) => ...)` — callback dijalankan
- `when(false, fn($q) => ...)` — callback diabaikan
- Parameter ketiga: `$default` callback untuk kondisi false
- Sangat berguna untuk filter dinamis (dari request)
- Membuat kode lebih bersih daripada if-else bertumpuk

## Contoh Kode
```php
use App\Models\Post;
use App\Models\User;
use Illuminate\Http\Request;

// when — filter dinamis dari request
$posts = Post::query()
    ->when($request->search, function ($query) use ($request) {
        $query->where('title', 'like', '%' . $request->search . '%');
    })
    ->when($request->category, function ($query) use ($request) {
        $query->where('category_id', $request->category);
    })
    ->when($request->min_price, function ($query) use ($request) {
        $query->where('price', '>=', $request->min_price);
    })
    ->when($request->max_price, function ($query) use ($request) {
        $query->where('price', '<=', $request->max_price);
    })
    ->when($request->sort, function ($query) use ($request) {
        $query->orderBy($request->sort, $request->direction ?? 'asc');
    }, function ($query) {
        // default sorting — jika $request->sort falsy
        $query->latest();
    })
    ->paginate(10);

// when di model scope
public function scopeFilter(Builder $query, array $filters): Builder
{
    return $query
        ->when($filters['search'] ?? null, fn($q, $v) => $q->where('title', 'like', "%$v%"))
        ->when($filters['category'] ?? null, fn($q, $v) => $q->where('category_id', $v))
        ->when($filters['status'] ?? null, fn($q, $v) => $q->where('status', $v));
}

// Penggunaan: Post::filter($request->all())->get();

// Contoh controller dengan filter
public function index(Request $request)
{
    $posts = Post::query()
        ->when($request->filled('search'), fn($q) =>
            $q->where(function($q) use ($request) {
                $q->where('title', 'like', "%{$request->search}%")
                  ->orWhere('body', 'like', "%{$request->search}%");
            })
        )
        ->when($request->boolean('published_only'), fn($q) =>
            $q->where('is_published', true)
        )
        ->paginate(15);
}
```

## Kasus Penggunaan Nyata
- Filter pencarian di halaman index (search, category, price range)
- Dashboard dengan parameter filter dinamis
- API dengan query params opsional
- Report generator dengan banyak opsi filter
- Advanced search form
