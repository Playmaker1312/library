# 165. join leftJoin rightJoin

## Definisi Singkat
`join()` menggabungkan tabel berdasarkan relasi (INNER JOIN). `leftJoin()` mengambil semua data dari tabel kiri meski tidak ada kecocokan. `rightJoin()` sebaliknya.

## Analogi
- `join`: Seperti daftar siswa yang terdaftar di kursus — hanya tampil yang punya relasi
- `leftJoin`: Daftar semua siswa — yang tidak ikut kursus tetap muncul (null)
- `rightJoin`: Daftar semua kursus — yang tidak ada siswanya tetap muncul

## Poin-Poin Penting
- `join('tabel', 'tabel1.kolom', '=', 'tabel2.kolom')`
- INNER JOIN: hanya data yang cocok di kedua tabel
- LEFT JOIN: semua data kiri + data kanan (null jika tidak cocok)
- RIGHT JOIN: semua data kanan + data kiri (null jika tidak cocok)
- `crossJoin()` — Cartesian product
- Prefix kolom dengan nama tabel untuk hindari ambiguitas

## Contoh Kode
```php
use App\Models\User;
use App\Models\Post;

// INNER JOIN — user dengan post
$users = User::select('users.*', 'posts.title as post_title')
             ->join('posts', 'users.id', '=', 'posts.user_id')
             ->get();
// Hanya user yang punya post

// LEFT JOIN — semua user, meski tanpa post
$users = User::select('users.*', 'posts.title as post_title')
             ->leftJoin('posts', 'users.id', '=', 'posts.user_id')
             ->get();
// User tanpa post: post_title = null

// RIGHT JOIN — semua post, meski user sudah dihapus
$posts = Post::select('posts.*', 'users.name as author')
             ->rightJoin('users', 'posts.user_id', '=', 'users.id')
             ->get();

// Multi join
$orders = DB::table('orders')
            ->join('users', 'orders.user_id', '=', 'users.id')
            ->join('order_items', 'orders.id', '=', 'order_items.order_id')
            ->join('products', 'order_items.product_id', '=', 'products.id')
            ->select(
                'orders.*',
                'users.name',
                'products.name as product_name',
                'order_items.quantity',
                'order_items.price'
            )
            ->get();

// Left join dengan kondisi tambahan
$users = User::leftJoin('posts', function ($join) {
                 $join->on('users.id', '=', 'posts.user_id')
                      ->where('posts.is_published', true);
             })
             ->select('users.*', 'posts.title as post_title')
             ->get();
```

## Kasus Penggunaan Nyata
- Daftar order dengan nama pelanggan (join users)
- Daftar produk dengan nama kategori (join categories)
- Daftar semua user dengan post terakhir mereka (leftJoin)
- Laporan: semua produk meski tidak pernah terjual (leftJoin)
