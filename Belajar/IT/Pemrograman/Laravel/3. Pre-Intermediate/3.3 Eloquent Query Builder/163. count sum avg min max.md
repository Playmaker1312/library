# 163. count sum avg min max

## Definisi Singkat
Method aggregate pada Eloquent untuk menghitung statistik: `count()` (jumlah), `sum()` (total), `avg()` (rata-rata), `min()` (terkecil), `max()` (terbesar).

## Analogi
Seperti kalkulator untuk data: hitung jumlah item (count), total harga (sum), rata-rata nilai (avg), nilai terendah (min), nilai tertinggi (max).

## Poin-Poin Penting
- Semua return nilai tunggal (bukan collection)
- Bisa dikombinasikan dengan `where()` dan query lainnya
- `count()` — jumlah record
- `sum('kolom')` — total nilai kolom
- `avg('kolom')` — rata-rata nilai kolom
- `min('kolom')` — nilai terkecil
- `max('kolom')` — nilai terbesar
- `distinct()->count()` — hitung nilai unik

## Contoh Kode
```php
use App\Models\Order;
use App\Models\Product;
use App\Models\User;

// count — jumlah record
$totalUsers = User::count();
$activeUsers = User::where('is_active', true)->count();
$distinctRoles = User::distinct()->count('role');

// sum — total nilai
$totalRevenue = Order::where('status', 'completed')
                      ->sum('total_amount');

// avg — rata-rata
$averagePrice = Product::avg('price');
$averageRating = Review::where('product_id', 1)->avg('rating');

// min — nilai terkecil
$cheapestProduct = Product::min('price');
$oldestUser = User::min('created_at');

// max — nilai terbesar
$mostExpensive = Product::max('price');
$latestOrder = Order::max('created_at');

// Kombinasi dengan group
$stats = Product::selectRaw('
    COUNT(*) as total_products,
    MIN(price) as min_price,
    MAX(price) as max_price,
    AVG(price) as avg_price,
    SUM(stock) as total_stock
')->first();

echo $stats->total_products;
echo $stats->avg_price;

// Di dashboard
public function dashboard()
{
    $data = [
        'total_users' => User::count(),
        'total_revenue' => Order::where('status', 'completed')->sum('total'),
        'average_order' => Order::where('status', 'completed')->avg('total'),
        'products_count' => Product::count(),
    ];

    return view('dashboard', $data);
}
```

## Kasus Penggunaan Nyata
- Dashboard admin: total user, total pendapatan
- Halaman produk: rata-rata rating, range harga
- Laporan keuangan: total penjualan hari ini
- Statistik: jumlah post per kategori, rata-rata view per artikel
