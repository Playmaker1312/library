# 158. whereBetween whereIn whereNull

## Definisi Singkat
Method-method kondisi spesifik untuk kasus umum: `whereBetween` (rentang), `whereIn` (dalam array), `whereNull` (nilai kosong), dan variasinya.

## Analogi
- `whereBetween`: Seperti filter harga "Rp50rb - Rp100rb"
- `whereIn`: Seperti filter kategori "Pilih: Buku, Alat Tulis, Tas"
- `whereNull`: Seperti "Pengguna yang belum verifikasi email"

## Poin-Poin Penting
- `whereBetween('kolom', [min, max])` — nilai di antara (inklusif)
- `whereNotBetween('kolom', [min, max])` — nilai di luar rentang
- `whereIn('kolom', [1, 2, 3])` — nilai dalam array
- `whereNotIn('kolom', [1, 2, 3])` — nilai tidak dalam array
- `whereNull('kolom')` — kolom bernilai NULL
- `whereNotNull('kolom')` — kolom tidak NULL
- `whereDate`, `whereMonth`, `whereYear`, `whereTime` — filter tanggal

## Contoh Kode
```php
use App\Models\User;
use App\Models\Product;
use App\Models\Order;

// whereBetween — produk harga Rp10rb - Rp50rb
$products = Product::whereBetween('price', [10000, 50000])->get();
// SELECT * FROM products WHERE price BETWEEN 10000 AND 50000

// whereNotBetween
$products = Product::whereNotBetween('price', [1000, 50000])->get();

// whereIn — user dengan role tertentu
$users = User::whereIn('role', ['admin', 'editor', 'superadmin'])->get();

// whereNotIn
$users = User::whereNotIn('status', ['banned', 'suspended'])->get();

// whereNull — user yang belum verifikasi email
$unverified = User::whereNull('email_verified_at')->get();

// whereNotNull — user yang sudah punya avatar
$withAvatar = User::whereNotNull('avatar')->get();

// Filter tanggal
$todayOrders = Order::whereDate('created_at', today())->get();
$januaryUsers = User::whereMonth('created_at', 1)->get();    // Januari
$users2024 = User::whereYear('created_at', 2024)->get();
$morningLogs = Log::whereTime('created_at', '>=', '08:00:00')
                   ->whereTime('created_at', '<=', '17:00:00')
                   ->get();
```

## Kasus Penggunaan Nyata
- Filter harga minimum-maksimum di toko online
- Filter kategori yang dipilih user di form
- Cari user yang belum melengkapi profil (avatar null)
- Laporan penjualan per bulan/periode
- Cek stok produk yang hampir habis (between 1 and 10)
