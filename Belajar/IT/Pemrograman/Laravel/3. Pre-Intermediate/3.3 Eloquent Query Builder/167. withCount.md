# 167. withCount()

## Definisi Singkat
`withCount('relasi')` menambahkan kolom `{relasi}_count` ke hasil query yang berisi jumlah record dari relasi terkait, tanpa memuat data relasinya.

## Analogi
Seperti melihat jumlah like di postingan tanpa melihat siapa yang like — Anda cukup tahu jumlahnya, tidak perlu data detailnya.

## Poin-Poin Penting
- Otomatis menambah kolom `{relasi}_count` (misal: `posts_count`)
- Mencegah N+1 jika hanya butuh jumlah, bukan data relasi
- Tidak memuat data relasi — lebih efisien dari `with()`
- Bisa multiple `withCount(['posts', 'comments', 'likes'])`
- Bisa dengan kondisi: `withCount(['posts' => fn($q) => $q->where(...)])`
- `loadCount('relasi')` untuk lazy loading

## Contoh Kode
```php
use App\Models\User;
use App\Models\Category;
use App\Models\Post;

// Hitung jumlah post per user
$users = User::withCount('posts')->get();
foreach ($users as $user) {
    echo "$user->name memiliki $user->posts_count postingan";
}
// Query: SELECT *, (SELECT COUNT(*) FROM posts WHERE user_id = users.id) as posts_count FROM users

// Multiple withCount
$users = User::withCount(['posts', 'comments', 'likes'])->get();
// posts_count, comments_count, likes_count

// Dengan kondisi
$users = User::withCount(['posts' => function ($query) {
    $query->where('is_published', true);
}])->get();
// posts_count hanya menghitung post yang dipublikasi

// Pada model relasi
$categories = Category::withCount('products')->get();
// products_count

// Sorting berdasarkan count
$popularPosts = Post::withCount('comments')
                     ->orderBy('comments_count', 'desc')
                     ->get();

// loadCount — lazy load count
$user = User::find(1);
$user->loadCount('posts');
echo $user->posts_count;
```

## Kasus Penggunaan Nyata
- Menampilkan jumlah postingan setiap user di profil
- Jumlah produk per kategori di sidebar
- Postingan terpopuler berdasarkan jumlah komentar
- Jumlah like, share, comment di feed sosial media
- Sorting produk berdasarkan jumlah review
