# 136. php artisan migrate:fresh

## Definisi Singkat
`php artisan migrate:fresh` menghapus semua tabel di database lalu menjalankan semua migration dari awal.

## Analogi
Seperti merobohkan seluruh bangunan dan membangun kembali dari pondasi — semua data lama hilang, struktur dibuat baru semua.

## Poin-Poin Penting
- Menghapus semua tabel (drop semua tabel)
- Menjalankan `php artisan migrate` dari awal
- Semua data akan hilang — hanya untuk development
- Bisa dikombinasikan dengan `--seed` untuk isi data awal
- JANGAN dijalankan di production

## Contoh Kode
```bash
# Hapus semua tabel lalu migrate ulang
php artisan migrate:fresh

# Fresh + jalankan seeder
php artisan migrate:fresh --seed

# Fresh + seeder spesifik
php artisan migrate:fresh --seeder=ProductSeeder

# Fresh di production (dengan warning)
php artisan migrate:fresh --force
```

## Kasus Penggunaan Nyata
- Development: struktur database berubah drastis, lebih mudah fresh
- Testing: ingin database bersih untuk test case
- Setup ulang project development setelah banyak perubahan
