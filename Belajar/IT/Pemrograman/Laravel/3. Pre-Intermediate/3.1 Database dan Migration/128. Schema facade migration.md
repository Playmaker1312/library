# 128. Schema Facade Migration

## Definisi Singkat
`Schema` facade menyediakan method statis untuk membuat, memodifikasi, dan menghapus tabel database dalam migration.

## Analogi
Seperti tukang bangunan yang punya alat lengkap untuk membuat pondasi, tembok, dan atap — Schema facade adalah toolkit untuk membangun struktur database.

## Poin-Poin Penting
- `Schema::create()` — membuat tabel baru
- `Schema::table()` — memodifikasi tabel yang sudah ada
- `Schema::dropIfExists()` — menghapus tabel
- `Schema::rename()` — mengganti nama tabel
- `Schema::hasTable()` — mengecek apakah tabel ada
- `Schema::hasColumn()` — mengecek apakah kolom ada
- Gunakan `Blueprint` untuk mendefinisikan kolom dalam closure

## Contoh Kode
```php
use Illuminate\Support\Facades\Schema;
use Illuminate\Database\Schema\Blueprint;

// Cek apakah tabel sudah ada
if (!Schema::hasTable('products')) {
    // Buat tabel baru
    Schema::create('products', function (Blueprint $table) {
        $table->id();
        $table->string('name');
        $table->timestamps();
    });
}

// Cek apakah kolom sudah ada
if (Schema::hasColumn('products', 'description')) {
    // Hapus kolom
    Schema::table('products', function (Blueprint $table) {
        $table->dropColumn('description');
    });
}

// Rename tabel
Schema::rename('products', 'items');
```

## Kasus Penggunaan Nyata
- Membuat tabel kategori produk saat migrasi pertama
- Menambah kolom stok ke tabel produk yang sudah ada
- Mengecek keberadaan tabel sebelum membuatnya untuk menghindari error
