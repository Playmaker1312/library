# 133. Schema Table Modifikasi Tabel

## Definisi Singkat
`Schema::table()` digunakan untuk memodifikasi tabel yang sudah ada — menambah, mengubah, atau menghapus kolom tanpa membuat ulang tabel.

## Analogi
Seperti merenovasi rumah yang sudah berdiri — menambah jendela baru, memperbesar pintu, atau menutup ruangan yang tidak terpakai, tanpa harus membongkar seluruh bangunan.

## Poin-Poin Penting
- `Schema::table('nama', closure)` untuk modifikasi
- Gunakan `->after()` untuk menentukan posisi kolom baru
- `$table->dropColumn('nama')` untuk menghapus kolom
- `$table->renameColumn('lama', 'baru')` untuk rename
- `$table->dropForeign()`, `$table->dropUnique()` untuk hapus constraint
- `$table->string('kolom')->nullable()->change()` untuk ubah properti
- Beberapa database (SQLite) punya keterbatasan dalam alter kolom

## Contoh Kode
```php
// Migration: add_price_to_products_table
return new class extends Migration
{
    public function up(): void
    {
        // Menambah kolom baru ke tabel products
        Schema::table('products', function (Blueprint $table) {
            $table->decimal('price', 10, 2)->after('description');
            $table->integer('stock')->default(0)->after('price');
            $table->boolean('is_active')->default(true)->after('stock');
            $table->softDeletes();  // Kolom deleted_at
        });
    }

    public function down(): void
    {
        // Membatalkan perubahan
        Schema::table('products', function (Blueprint $table) {
            $table->dropColumn(['price', 'stock', 'is_active']);
            $table->dropSoftDeletes();
        });
    }
};

// Mengubah properti kolom (Laravel 10+)
Schema::table('users', function (Blueprint $table) {
    $table->string('name', 100)->change();  // Ubah panjang varchar
    $table->string('email')->nullable()->change();  // Jadikan nullable
});

// Menghapus foreign key
Schema::table('posts', function (Blueprint $table) {
    $table->dropForeign(['user_id']);  // Hapus FK
});
```

## Kasus Penggunaan Nyata
- Menambah kolom `phone` ke tabel users setelah fitur baru
- Mengganti nama kolom `username` menjadi `nickname`
- Menghapus kolom legacy yang tidak dipakai lagi
- Mengubah kolom menjadi nullable karena aturan bisnis berubah
