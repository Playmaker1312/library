# 140. SoftDeletes Soft Delete

## Definisi Singkat
Soft delete adalah teknik menghapus data secara "lunak" — data tidak benar-benar dihapus dari database, melainkan ditandai dengan kolom `deleted_at`.

## Analogi
Seperti memindahkan file ke folder "Recycle Bin" — file tidak hilang, tapi tidak terlihat di tempat biasa. Bisa dikembalikan kapan saja (restore) atau dihapus permanen.

## Poin-Poin Penting
- Migration: `$table->softDeletes()` menambah kolom `deleted_at` (nullable timestamp)
- Model: gunakan trait `Illuminate\Database\Eloquent\SoftDeletes`
- Query normal otomatis mengecualikan data yang di-soft-delete
- `Model::withTrashed()` — ambil semua termasuk yang terhapus
- `Model::onlyTrashed()` — ambil hanya yang terhapus
- `$model->restore()` — kembalikan data yang di-soft-delete
- `$model->forceDelete()` — hapus permanen (true delete)

## Contoh Kode
```php
// Migration — tambah kolom deleted_at
Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->string('title');
    $table->timestamps();
    $table->softDeletes();  // deleted_at (nullable timestamp)
});

// Model — gunakan trait SoftDeletes
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\SoftDeletes;

class Post extends Model
{
    use SoftDeletes;

    protected $fillable = ['title'];
}

// Penggunaan di controller
// Soft delete — data tetap di database
$post = Post::find(1);
$post->delete();  // deleted_at terisi timestamp

// Query — otomatis filter deleted_at IS NULL
$posts = Post::all();  // hanya yang belum dihapus

// Sertakan data yang dihapus
$posts = Post::withTrashed()->get();

// Hanya data yang dihapus
$trashed = Post::onlyTrashed()->get();

// Restore (kembalikan)
$post = Post::withTrashed()->find(1);
$post->restore();

// Hapus permanen
$post->forceDelete();
```

## Kasus Penggunaan Nyata
- Pengguna menghapus akun — data tetap ada untuk audit, bisa dipulihkan
- Artikel di-trashed — editor bisa mengembalikan jika salah hapus
- Pesanan dibatalkan — tetap tersimpan untuk laporan, tapi tidak muncul di daftar aktif
