# 131. Modifier Nullable Default Unique Unsigned

## Definisi Singkat
Modifier adalah method chaining pada Blueprint yang menambahkan properti tambahan ke kolom, seperti nullable, default value, unique constraint, dan unsigned.

## Analogi
Seperti memberikan label tambahan pada kotak penyimpanan — "boleh kosong" (nullable), "isi default" (default), "tidak boleh duplikat" (unique), dan "hanya positif" (unsigned).

## Poin-Poin Penting
- `->nullable()` — kolom boleh bernilai NULL
- `->default(nilai)` — nilai default jika tidak diisi
- `->unique()` — nilai tidak boleh duplikat (UNIQUE constraint)
- `->unsigned()` — hanya untuk integer, nilai tidak boleh negatif
- `->unsignedBigInteger()` — shortcut untuk bigInteger + unsigned
- `->after('kolom')` — posisi kolom setelah kolom tertentu
- `->comment('teks')` — menambah komentar pada kolom
- `->first()` — letakkan kolom di posisi pertama

## Contoh Kode
```php
Schema::create('users', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->string('email')->unique();               // Tidak boleh duplikat
    $table->timestamp('email_verified_at')->nullable(); // Boleh NULL
    $table->string('password');
    $table->string('avatar')->nullable()->default('default.jpg');
    $table->integer('age')->unsigned()->default(0);  // Tidak negatif
    $table->boolean('is_admin')->default(false);     // Default false
    $table->text('bio')->nullable();                 // Boleh NULL
    $table->rememberToken();
    $table->timestamps();
});

// Contoh dengan after
Schema::table('users', function (Blueprint $table) {
    $table->string('phone')->nullable()->after('email');
    $table->string('username')->unique()->after('name');
});
```

## Kasus Penggunaan Nyata
- `nullable()` — foto profil (tidak wajib di awal)
- `default(0)` — saldo awal pengguna
- `unique()` — email, username, nomor telepon
- `unsigned()` — foreign key, umur, quantity (tidak mungkin negatif)
