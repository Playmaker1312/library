# 135. php artisan migrate rollback

## Definisi Singkat
`php artisan migrate:rollback` membatalkan migration terakhir yang dijalankan dengan mengeksekusi method `down()` pada file migration.

## Analogi
Seperti tombol "Undo" (Ctrl+Z) untuk perubahan database — mengembalikan database ke kondisi sebelum batch migration terakhir.

## Poin-Poin Penting
- Rollback hanya membatalkan batch migration terakhir
- Laravel mencatat batch number di tabel `migrations`
- Method `down()` harus mengembalikan perubahan yang dilakukan `up()`
- Gunakan `--step=n` untuk rollback sejumlah n batch
- Hati-hati: data bisa hilang jika `down()` menghapus tabel/kolom

## Contoh Kode
```bash
# Rollback batch terakhir
php artisan migrate:rollback

# Rollback 3 batch terakhir
php artisan migrate:rollback --step=3

# Rollback di production (tanpa konfirmasi)
php artisan migrate:rollback --force

# Rollback semua migration
php artisan migrate:rollback --batch=0

# Lihat SQL tanpa eksekusi
php artisan migrate:rollback --pretend
```

## Kasus Penggunaan Nyata
- Migration baru ternyata error — rollback lalu perbaiki file
- Fitur dibatalkan — rollback migration yang sudah dijalankan
- Testing migration sebelum deploy ke production
