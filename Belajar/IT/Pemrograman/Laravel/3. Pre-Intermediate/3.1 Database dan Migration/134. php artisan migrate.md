# 134. php artisan migrate

## Definisi Singkat
`php artisan migrate` adalah perintah untuk menjalankan semua migration yang belum dijalankan, mengeksekusi method `up()` setiap file migration.

## Analogi
Seperti menekan tombol "Apply" pada pembaruan software — semua perubahan yang tertunda akan diterapkan secara berurutan sesuai urutan timestamp.

## Poin-Poin Penting
- Menjalankan semua migration yang belum dijalankan
- Urutan eksekusi berdasarkan timestamp di nama file
- Migration yang sudah dijalankan dicatat di tabel `migrations`
- Bisa dijalankan berkali-kali — hanya migration baru yang akan dieksekusi
- Gunakan `--force` di production tanpa konfirmasi

## Contoh Kode
```bash
# Menjalankan semua migration yang tertunda
php artisan migrate

# Dengan output verbose
php artisan migrate -v

# Di production (tanpa konfirmasi)
php artisan migrate --force

# Simulasi (dry run) — lihat SQL tanpa eksekusi
php artisan migrate --pretend

# Menjalankan migration dari path tertentu
php artisan migrate --path=database/migrations/2024

# Hanya migration tertentu (1 file)
php artisan migrate --path=database/migrations/2024_01_01_000001_create_users_table.php
```

## Kasus Penggunaan Nyata
- Setelah `git pull` dari tim — jalankan migrate untuk update database
- Deployment ke server — `php artisan migrate --force` di script deploy
- Persiapan environment development baru — clone repo lalu migrate
