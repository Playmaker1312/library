# 126. Database Migration Laravel

## Definisi Singkat
Migration adalah sistem version control untuk database di Laravel yang memungkinkan pengelolaan skema tabel secara terstruktur dan kolaboratif.

## Analogi
Seperti buku catatan perubahan (changelog) untuk struktur database — setiap perubahan dicatat, bisa dilihat sejarahnya, dan bisa diulang atau dibatalkan kapan saja.

## Poin-Poin Penting
- Setiap migration berisi method `up` (menjalankan perubahan) dan `down` (membatalkan perubahan)
- Disimpan di direktori `database/migrations/`
- Nama file menggunakan timestamp agar urutan eksekusi konsisten
- Bekerja dengan Schema Facade dan Fluent Query Builder
- Mendukung rollback, fresh, dan refresh

## Contoh Kode
```php
// File: database/migrations/2024_01_01_000001_create_users_table.php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    // Method up: menjalankan perubahan (membuat tabel)
    public function up(): void
    {
        Schema::create('users', function (Blueprint $table) {
            $table->id();
            $table->string('name');
            $table->string('email')->unique();
            $table->timestamps();
        });
    }

    // Method down: membatalkan perubahan (menghapus tabel)
    public function down(): void
    {
        Schema::dropIfExists('users');
    }
};
```

## Kasus Penggunaan Nyata
- Tim pengembang bekerja bersama di database — migration memastikan semua anggota punya struktur database yang sama
- Deployment otomatis ke staging/production tanpa perlu ekspor SQL manual
- Rollback perubahan jika ada error saat migrate
