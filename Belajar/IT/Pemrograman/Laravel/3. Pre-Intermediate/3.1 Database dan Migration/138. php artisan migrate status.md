# 138. php artisan migrate:status

## Definisi Singkat
`php artisan migrate:status` menampilkan daftar semua file migration beserta statusnya — sudah dijalankan (Y) atau belum (N).

## Analogi
Seperti checklist tugas — menampilkan mana yang sudah selesai (centang) dan mana yang masih pending.

## Poin-Poin Penting
- Menampilkan 3 kolom: Ran? (status), Migration (nama file), Batch (urutan)
- "Ran" = Y berarti sudah dieksekusi
- "Ran" = N berarti belum dijalankan
- Berguna untuk troubleshooting dan perencanaan

## Contoh Kode
```bash
# Melihat status semua migration
php artisan migrate:status

# Output contoh:
# +------+-------------------------------------------------+-------+
# | Ran? | Migration                                       | Batch |
# +------+-------------------------------------------------+-------+
# | Y    | 2024_01_01_000001_create_users_table             | 1     |
# | Y    | 2024_01_02_000001_create_posts_table             | 1     |
# | N    | 2024_01_03_000001_add_price_to_products_table    |       |
# +------+-------------------------------------------------+-------+
```

## Kasus Penggunaan Nyata
- Cek apakah migration terbaru sudah dijalankan setelah deploy
- Investigasi mengapa kolom tidak muncul di database
- Memastikan urutan migration sebelum rollback
