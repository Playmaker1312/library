# 129. Schema Create Tabel

## Definisi Singkat
`Schema::create()` adalah method untuk membuat tabel database baru dengan kolom-kolom yang didefinisikan menggunakan Blueprint.

## Analogi
Seperti menggambar denah rumah — Schema::create mendefinisikan ruangan apa saja yang ada, sedangkan Blueprint menentukan ukuran dan fungsi setiap ruangan.

## Poin-Poin Penting
- Parameter pertama: nama tabel (string)
- Parameter kedua: closure yang menerima objek `Blueprint`
- Blueprint digunakan untuk mendefinisikan kolom dan tipe data
- Setiap tabel biasanya punya `id()` dan `timestamps()`
- Migration `create_xxx_table` biasanya otomatis terdeteksi oleh Artisan

## Contoh Kode
```php
use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        // Parameter 1: 'products' — nama tabel
        // Parameter 2: closure dengan $table sebagai Blueprint
        Schema::create('products', function (Blueprint $table) {
            // Kolom primary key auto-increment (id)
            $table->id();

            // Kolom string
            $table->string('name', 100);  // varchar(100)
            $table->string('slug')->unique();

            // Kolom text
            $table->text('description')->nullable();

            // Kolom numerik
            $table->decimal('price', 10, 2);  // 10 digit total, 2 desimal
            $table->integer('stock')->default(0);

            // Kolom boolean
            $table->boolean('is_active')->default(true);

            // Timestamps: created_at dan updated_at
            $table->timestamps();
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('products');
    }
};
```

## Kasus Penggunaan Nyata
- Membuat tabel `orders` untuk mencatat transaksi penjualan
- Membuat tabel `categories` untuk pengelompokan produk
- Membuat tabel `reviews` untuk ulasan pelanggan
