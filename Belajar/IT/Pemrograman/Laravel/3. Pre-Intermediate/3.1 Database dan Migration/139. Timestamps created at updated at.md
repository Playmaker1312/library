# 139. Timestamps Created At Updated At

## Definisi Singkat
Method `timestamps()` pada migration otomatis membuat dua kolom: `created_at` (waktu dibuat) dan `updated_at` (waktu terakhir diubah), yang dikelola secara otomatis oleh Eloquent.

## Analogi
Seperti stempel waktu pada dokumen — mencatat kapan dokumen dibuat dan kapan terakhir direvisi, tanpa perlu manual mengisinya.

## Poin-Poin Penting
- `$table->timestamps()` membuat `created_at` dan `updated_at` (nullable timestamp)
- Eloquent otomatis mengisi `created_at` saat record dibuat
- Eloquent otomatis mengupdate `updated_at` setiap record diubah
- Bisa dinonaktifkan dengan `public $timestamps = false;` di model
- Format default: `Y-m-d H:i:s` (datetime MySQL)
- Gunakan `$table->timestamp('created_at')->useCurrent()` untuk default NOW()

## Contoh Kode
```php
// Migration
Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->string('title');
    $table->text('body');
    $table->timestamps();  // created_at + updated_at
});

// Di Model — Eloquent mengelola otomatis
class Post extends Model
{
    use HasFactory;

    // Nonaktifkan timestamps (jika tidak ingin otomatis)
    // public $timestamps = false;

    // Ganti nama kolom (jarang)
    const CREATED_AT = 'created_date';
    const UPDATED_AT = 'updated_date';
}

// Contoh nilai yang tersimpan:
// created_at: 2024-01-15 10:30:00
// updated_at: 2024-01-16 14:22:00
```

## Kasus Penggunaan Nyata
- Menampilkan "Diposting 2 jam yang lalu" — dari created_at
- Menampilkan "Terakhir diupdate kemarin" — dari updated_at
- Sorting artikel berdasarkan created_at DESC
- Filter data dalam rentang tanggal tertentu
