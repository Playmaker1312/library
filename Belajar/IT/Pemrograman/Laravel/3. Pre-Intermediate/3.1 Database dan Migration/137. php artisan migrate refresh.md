# 137. php artisan migrate:refresh

## Definisi Singkat
`php artisan migrate:refresh` melakukan rollback semua migration kemudian menjalankannya kembali dari awal.

## Analogi
Seperti merombak total interior rumah — semua perabotan dikeluarkan (rollback), lalu ditata ulang dari awal (migrate). Tidak menghancurkan bangunan, hanya mereset isinya.

## Poin-Poin Penting
- Rollback seluruh batch, lalu migrate ulang — berbeda dengan fresh yang drop semua tabel
- Data tetap hilang karena tabel di-drop di method `down()`
- Lebih lambat dari `fresh` karena menjalankan semua method `down()`
- Bisa dikombinasikan dengan `--seed`

## Contoh Kode
```bash
# Rollback semua, lalu migrate ulang
php artisan migrate:refresh

# Refresh + seeder
php artisan migrate:refresh --seed

# Refresh hanya 3 batch terakhir
php artisan migrate:refresh --step=3

# Refresh di production
php artisan migrate:refresh --force
```

## Perbedaan fresh vs refresh
| Migrate:fresh | Migrate:refresh |
|--------------|-----------------|
| Drop semua tabel langsung | Rollback satu per satu |
| Semua data hilang | Data hilang (via down()) |
| Lebih cepat | Lebih lambat |
| Tidak butuh method down() | Butuh method down() |
