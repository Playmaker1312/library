# 132. Foreign Key Constraint Migration

## Definisi Singkat
Foreign key constraint memastikan referensi antar tabel tetap valid dengan menghubungkan kolom di satu tabel ke primary key di tabel lain.

## Analogi
Seperti daftar tamu yang harus terdaftar di buku tamu utama — tidak boleh ada transaksi dari pelanggan yang tidak terdaftar. Foreign key menjaga integritas referensi.

## Poin-Poin Penting
- `$table->foreignId('kolom')` — shortcut untuk unsignedBigInteger
- `->constrained()` — otomatis merujuk ke id di tabel terkait
- `->cascadeOnDelete()` — hapus data anak jika induk dihapus
- `->cascadeOnUpdate()` — update otomatis FK jika PK berubah
- `->nullOnDelete()` — set null jika induk dihapus
- `->restrictOnDelete()` — cegah penghapusan jika masih ada referensi
- Urutan migration penting: tabel referensi harus dibuat lebih dulu

## Contoh Kode
```php
// Tabel users (harus ada lebih dulu)
Schema::create('users', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->timestamps();
});

// Tabel posts — memiliki foreign key ke users
Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->string('title');
    $table->text('body');

    // Cara 1: foreignId + constrained (paling modern)
    $table->foreignId('user_id')
          ->constrained()           // otomatis referensi users.id
          ->cascadeOnDelete();      // hapus post jika user dihapus

    // Cara 2: manual (lama)
    // $table->unsignedBigInteger('user_id');
    // $table->foreign('user_id')->references('id')->on('users');

    $table->timestamps();
});

// Contoh dengan nullOnDelete
Schema::create('logs', function (Blueprint $table) {
    $table->id();
    $table->string('action');

    $table->foreignId('user_id')
          ->nullable()
          ->constrained()
          ->nullOnDelete();  // log tetap ada, user_id jadi null

    $table->timestamps();
});
```

## Kasus Penggunaan Nyata
- Relasi post milik user — cascade on delete
- Log aktivitas — null on delete (log tetap tersimpan)
- Order milik customer — restrict on delete (cegah hapus customer yang punya order)
