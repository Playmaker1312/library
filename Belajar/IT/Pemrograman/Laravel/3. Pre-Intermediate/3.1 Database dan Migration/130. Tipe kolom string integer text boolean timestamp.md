# 130. Tipe Kolom String Integer Text Boolean Timestamp

## Definisi Singkat
Blueprint menyediakan berbagai method untuk mendefinisikan tipe kolom database, seperti string, integer, text, boolean, dan timestamp.

## Analogi
Seperti memilih wadah yang tepat untuk menyimpan barang — botol untuk cairan, kotak untuk barang padat, map untuk dokumen. Setiap tipe kolom adalah wadah untuk jenis data tertentu.

## Poin-Poin Penting
- `string('nama', panjang)` — VARCHAR dengan batas karakter
- `text('nama')` — TEXT untuk teks panjang (artikel, deskripsi)
- `integer('nama')` — INTEGER untuk angka bulat
- `bigInteger('nama')` — BIGINT untuk angka besar
- `decimal('nama', total, desimal)` — DECIMAL untuk angka presisi
- `boolean('nama')` — BOOLEAN untuk true/false
- `timestamp('nama')` — TIMESTAMP untuk tanggal dan waktu
- `date('nama')` — DATE untuk tanggal saja
- `float('nama')` — FLOAT untuk angka desimal
- `json('nama')` — JSON untuk data terstruktur

## Contoh Kode
```php
Schema::create('articles', function (Blueprint $table) {
    $table->id();
    $table->string('title', 200);           // VARCHAR(200)
    $table->string('slug', 255)->unique();  // VARCHAR unik
    $table->text('body');                   // TEXT panjang
    $table->text('excerpt')->nullable();    // TEXT boleh kosong
    $table->integer('view_count')->default(0); // INTEGER default 0
    $table->bigInteger('external_id');      // BIGINT untuk ID eksternal
    $table->decimal('rating', 3, 1);        // DECIMAL(3,1) = 4.5
    $table->boolean('is_published');        // BOOLEAN
    $table->boolean('featured')->default(false);
    $table->date('published_at');           // DATE saja
    $table->timestamp('last_read');         // TIMESTAMP
    $table->json('metadata');               // JSON
    $table->float('price');                 // FLOAT
    $table->timestamps();                   // created_at + updated_at
});
```

## Kasus Penggunaan Nyata
- `string` untuk nama pengguna, email, judul artikel
- `text` untuk konten blog, deskripsi produk
- `integer` untuk jumlah stok, umur, quantity
- `boolean` untuk status aktif, verifikasi email
- `timestamp` untuk waktu posting, login terakhir
