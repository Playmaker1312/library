# 127. Membuat Migration Artisan Nama File Migration

## Definisi Singkat
Perintah Artisan `make:migration` digunakan untuk membuat file migration baru dengan nama yang deskriptif dan timestamp otomatis.

## Analogi
Seperti menekan tombol "Simpan Sebagai" untuk draft perubahan database — nama file langsung menunjukkan isi perubahan.

## Poin-Poin Penting
- Format: `php artisan make:migration NamaFile`
- Nama file harus deskriptif (contoh: `create_users_table`, `add_email_to_users_table`)
- Laravel otomatis menambahkan timestamp di awal nama file
- Gunakan kata `create` untuk pembuatan tabel baru
- Gunakan kata `add`, `modify`, `change` untuk modifikasi tabel
- Opsi `--table` dan `--create` untuk template otomatis

## Contoh Kode
```php
// Membuat migration untuk tabel baru
// php artisan make:migration create_posts_table

// File yang dihasilkan: 2024_01_01_000002_create_posts_table.php
use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('posts', function (Blueprint $table) {
            $table->id();
            $table->timestamps();
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('posts');
    }
};

// Dengan opsi --create (langsung ada skema tabel)
// php artisan make:migration create_posts_table --create=posts

// Dengan opsi --table (untuk modifikasi tabel)
// php artisan make:migration add_title_to_posts_table --table=posts
```

## Kasus Penggunaan Nyata
- Developer menambahkan fitur baru yang butuh kolom tambahan di tabel
- Membuat tabel baru untuk modul yang belum ada
- Memperbaiki skema database dengan menambah/menghapus kolom
