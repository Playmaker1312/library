# 154. Delete dan Destroy

## Definisi Singkat
`delete()` menghapus record dari database pada instance model. `destroy()` menghapus satu atau lebih record langsung berdasarkan primary key.

## Analogi
- `delete()`: Seperti memilih satu item di keranjang lalu klik "Hapus"
- `destroy()`: Seperti mencentang beberapa item sekaligus lalu klik "Hapus Semua"

## Poin-Poin Penting
- `$model->delete()` — hapus instance model, return boolean
- `Model::destroy($id)` — hapus berdasarkan PK, return jumlah terhapus
- `Model::destroy([1, 2, 3])` — hapus banyak sekaligus
- `Model::where(...)->delete()` — hapus dengan kondisi, return jumlah
- Jika menggunakan SoftDeletes: `delete()` jadi soft delete
- `forceDelete()` untuk hard delete (abaikan soft deletes)

## Contoh Kode
```php
use App\Models\Post;
use App\Models\User;

// delete() — dari instance model
$post = Post::find(1);
$post->delete();  // return true/false (boolean)

// destroy() — langsung berdasarkan ID
Post::destroy(1);                              // hapus 1 record
Post::destroy(1, 2, 3);                       // hapus beberapa
Post::destroy([1, 2, 3, 4, 5]);               // hapus array ID

// destroy return jumlah baris yang terhapus
$deleted = Post::destroy([1, 2, 3]);
echo "$deleted post berhasil dihapus";  // 3

// Delete dengan kondisi
Post::where('is_draft', true)
    ->where('created_at', '<', now()->subDays(30))
    ->delete();  // hapus draft yang lebih dari 30 hari

// Soft delete — jika model pakai SoftDeletes trait
$post = Post::find(1);
$post->delete();         // soft delete (set deleted_at)
$post->forceDelete();    // hard delete (hapus permanen)

// Hapus relasi
$user = User::find(1);
$user->posts()->delete();  // hapus semua post milik user
```

## Kasus Penggunaan Nyata
- Hapus postingan dari halaman admin
- Hapus akun pengguna yang meminta penghapusan data
- Hapus massal data kadaluarsa (logs, session expired)
- Hapus dengan soft delete untuk keamanan data
