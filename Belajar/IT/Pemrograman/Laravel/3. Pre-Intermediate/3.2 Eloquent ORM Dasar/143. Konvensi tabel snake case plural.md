# 143. Konvensi Tabel Snake Case Plural

## Definisi Singkat
Eloquent secara otomatis menentukan nama tabel berdasarkan nama model dengan aturan: nama model (StudlyCase) diubah ke snake_case dan bentuk jamak (plural).

## Analogi
Seperti sistem alamat surat otomatis — jika Anda berkirim ke "User", Eloquent otomatis mengirimkannya ke tabel "users" tanpa perlu konfigurasi.

## Poin-Poin Penting
- Model `User` → tabel `users` (User → user + s)
- Model `Post` → tabel `posts` (Post → post + s)
- Model `Category` → tabel `categories` (Category → categor + ies)
- Model `News` → tabel `news` (irregular, tetap news)
- Model `Person` → tabel `people` (irregular, tidak otomatis)
- Konvensi bisa di-override dengan properti `$table` di model

## Contoh Kode
```php
// Konvensi otomatis Eloquent:
// Model       → Tabel yang diasumsikan
// Post        → posts
// Product     → products
// Category    → categories
// Person      → persons  (tidak otomatis jadi people)

// Aturan plural Inggris:
// - Akhiran s, x, z, ch, sh → +es (box → boxes)
// - Akhiran y → ies (category → categories)
// - Akhiran f, fe → ves (shelf → shelves)
// - Irregular: child → children, person → people

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Post extends Model
{
    // Secara otomatis menggunakan tabel 'posts'
    // Tidak perlu deklarasi apapun
}

class Category extends Model
{
    // Otomatis: tabel 'categories'
    // Tidak perlu deklarasi apapun
}
```

## Kasus Penggunaan Nyata
- Model `Article` → tabel `articles` — tanpa perlu ngasih tahu Laravel
- Model `Review` → tabel `reviews` — konvensi sudah cukup
- Tim developer konsisten dengan nama model dan tabel
