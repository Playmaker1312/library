# 146. Metode all()

## Definisi Singkat
`Model::all()` adalah method Eloquent yang mengambil semua record dari tabel terkait dan mengembalikannya sebagai Collection.

## Analogi
Seperti membuka lemari arsip dan mengambil seluruh dokumen tanpa filter — Anda mendapatkan semua isi dalam satu kali ambil.

## Poin-Poin Penting
- Mengembalikan `Illuminate\Database\Eloquent\Collection`
- Mengeksekusi `SELECT * FROM nama_tabel`
- Tidak bisa ditambahkan kondisi (where, orderBy, limit)
- Untuk query dengan kondisi, gunakan `Model::where()->get()`
- Berbahaya untuk tabel besar — bisa memuat banyak data

## Contoh Kode
```php
use App\Models\User;
use App\Models\Post;

// Ambil semua user
$users = User::all();

// $users adalah Collection
foreach ($users as $user) {
    echo $user->name;
}

// Hitung jumlah
$count = User::all()->count();

// Ambil kolom tertentu (parameter dikirim ke all)
$users = User::all(['id', 'name', 'email']);

// all() vs get() — sama jika tanpa kondisi
$users = User::all();           // SELECT * FROM users
$users = User::get();           // SELECT * FROM users

// Chaining method pada Collection
$recentUsers = User::all()->where('created_at', '>', now()->subDays(7));

// Peringatan: untuk 100.000 user, jangan pakai all()
// $users = User::all();  // Bisa memory overload!

// Alternatif: chunk atau cursor untuk data besar
User::chunk(100, function ($users) {
    foreach ($users as $user) {
        // proses satu per satu
    }
});
```

## Kasus Penggunaan Nyata
- Menampilkan daftar semua kategori (jumlah sedikit, < 100)
- Export seluruh data ke Excel (hati-hati dengan ukuran)
- Mengisi dropdown options dengan data referensi (roles, status)
- Caching seluruh data kecil ke memory
