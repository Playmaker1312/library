# 152. Metode save()

## Definisi Singkat
`$model->save()` adalah method untuk menyimpan instance model ke database — membuat baru (INSERT) jika belum ada, atau mengupdate (UPDATE) jika sudah ada.

## Analogi
Seperti tombol "Simpan" di aplikasi edit dokumen — apakah dokumen baru atau revisi dari dokumen lama, satu tombol yang sama yang menuliskan perubahan ke penyimpanan.

## Poin-Poin Penting
- Bisa untuk INSERT (model baru) maupun UPDATE (model existing)
- INSERT jika `$model->exists === false`
- UPDATE jika `$model->exists === true`
- Otomatis mengisi `created_at` dan `updated_at`
- Mengembalikan `boolean` (true/false) — sukses atau gagal
- Untuk INSERT + langsung dapat instance: `create()` lebih praktis

## Contoh Kode
```php
use App\Models\Post;
use App\Models\User;

// INSERT — model baru
$post = new Post();
$post->title = 'Belajar Laravel';
$post->body = 'Ini adalah konten artikel...';
$post->user_id = 1;
$post->save();

// Setelah save, $post->id sudah terisi
echo $post->id;  // ID dari auto-increment

// UPDATE — model yang sudah ada
$post = Post::find(1);
$post->title = 'Judul Baru';  // ubah properti
$post->body = 'Konten yang direvisi...';
$post->save();  // UPDATE posts SET ... WHERE id = 1

// Cek apakah save berhasil
if ($post->save()) {
    echo 'Data tersimpan';
} else {
    echo 'Gagal menyimpan';
}

// Cara kerja internal:
// $post->exists menentukan INSERT atau UPDATE
$post = new Post();      // $post->exists = false → INSERT
$post->title = 'Test';
$post->save();           // INSERT, lalu exists jadi true

$post->title = 'Test 2'; // $post->exists = true → UPDATE
$post->save();           // UPDATE

// Batch assignment (manual)
$post = new Post();
$post->fill(['title' => 'Judul', 'body' => 'Konten']);
$post->save();
```

## Kasus Penggunaan Nyata
- Update spesifik beberapa kolom tanpa touch kolom lain
- Menyimpan data setelah validasi bertahap
- Proses bisnis yang membutuhkan logic sebelum save
- Hook ke event model (creating, created, updating, updated)
