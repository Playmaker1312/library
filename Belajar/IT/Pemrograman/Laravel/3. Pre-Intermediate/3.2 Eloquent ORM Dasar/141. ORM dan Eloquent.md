# 141. ORM dan Eloquent

## Definisi Singkat
ORM (Object-Relational Mapping) adalah teknik memetakan tabel database menjadi objek PHP. Eloquent adalah ORM bawaan Laravel yang membuat interaksi database terasa seperti bekerja dengan objek biasa.

## Analogi
Seperti penerjemah bahasa — database berbicara SQL (bahasa asing), Eloquent menerjemahkannya ke PHP (bahasa kita). Kita cukup memanggil method, Eloquent yang urus SQL-nya.

## Poin-Poin Penting
- Setiap tabel punya 1 Model (kelas PHP)
- Setiap baris di tabel = 1 instance model
- Eloquent otomatis mapping properti ke kolom
- Query return Collection (bukan array biasa)
- Relasi antar tabel didefinisikan sebagai method di model

## Contoh Kode
```php
// Tanpa ORM (manual SQL)
$users = DB::select('SELECT * FROM users WHERE active = ?', [1]);
foreach ($users as $user) {
    echo $user->name;  // stdClass object
}

// Dengan Eloquent ORM — lebih ekspresif
$users = User::where('active', true)->get();

foreach ($users as $user) {
    echo $user->name;  // App\Models\User object
    echo $user->posts->count();  // relasi: panggil relasi sebagai properti
}

// Model Eloquent dasar
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class User extends Model
{
    // Eloquent akan mengasumsikan:
    // - Tabel: 'users' (snake_case plural dari User)
    // - Primary key: 'id'
    // - Timestamps: created_at, updated_at
}
```

## Kasus Penggunaan Nyata
- CRUD (Create, Read, Update, Delete) tanpa menulis SQL manual
- Relasi data: user punya banyak post, post milik satu user
- Query kompleks: filter, sorting, pagination dengan method chaining
- Event lifecycle: menjalankan kode otomatis saat data dibuat/diubah
