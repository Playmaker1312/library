# 150. Metode Get Collection

## Definisi Singkat
`get()` mengeksekusi query builder dan mengembalikan hasil sebagai `Collection` — sebuah objek yang membungkus array model dengan banyak method helper.

## Analogi
Seperti membawa keranjang belanja — `get()` mengumpulkan semua hasil belanjaan (record) ke dalam satu keranjang yang bisa dipilah, dihitung, dan diolah.

## Poin-Poin Penting
- `get()` adalah eksekutor query — tanpa `get()`, query tidak dieksekusi
- Mengembalikan `Illuminate\Database\Eloquent\Collection`
- Collection memiliki method: `map`, `filter`, `pluck`, `sum`, `avg`, dll.
- `get(['kolom1', 'kolom2'])` untuk memilih kolom tertentu
- `get()` berbeda dari `all()` — `all()` tidak bisa dikasih where

## Contoh Kode
```php
use App\Models\User;
use App\Models\Post;

// get() — eksekusi query
$users = User::where('is_active', true)
             ->orderBy('name')
             ->get();

// Method Collection yang berguna
$names = User::all()->pluck('name');                // ['John', 'Jane', ...]
$totalAge = User::all()->sum('age');                 // total umur
$average = User::all()->avg('age');                  // rata-rata umur
$grouped = User::all()->groupBy('role');             // group by role

// Map — transformasi data
$formatted = User::all()->map(function ($user) {
    return [
        'id' => $user->id,
        'full_name' => strtoupper($user->name),
    ];
});

// Filter collection
$adults = User::all()->filter(function ($user) {
    return $user->age >= 18;
});

// Pilih kolom spesifik
$users = User::where('role', 'admin')->get(['id', 'name', 'email']);

// isEmpty / isNotEmpty
if (User::where('role', 'admin')->get()->isEmpty()) {
    echo 'Tidak ada admin';
}

// toArray / toJson
$array = User::all()->toArray();
$json = User::all()->toJson();
```

## Kasus Penggunaan Nyata
- Get data lalu format untuk API response
- Filter collection di PHP tanpa perlu query tambahan
- Pluck untuk dropdown options di form
- Map untuk transformasi data sebelum dikirim ke view
