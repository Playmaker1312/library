# 145. Properti PrimaryKey Kustom

## Definisi Singkat
Properti `$primaryKey` digunakan untuk menentukan primary key yang berbeda jika tidak menggunakan kolom `id`.

## Analogi
Seperti menggunakan nomor induk karyawan (NIK) sebagai identitas, bukan nomor urut default — Anda bisa menentukan kolom mana yang dianggap sebagai identitas utama.

## Poin-Poin Penting
- Default Eloquent: `$primaryKey = 'id'`
- `protected $primaryKey = 'uuid';` untuk primary key kustom
- `public $incrementing = false;` jika bukan auto-increment integer
- `protected $keyType = 'string';` jika primary key bukan integer
- Auto-increment membutuhkan integer unsigned primary key

## Contoh Kode
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Product extends Model
{
    // Primary key bukan 'id' tapi 'product_id'
    protected $primaryKey = 'product_id';

    // Tetap auto-increment integer — tidak perlu ubah lain
}

class User extends Model
{
    // Primary key menggunakan UUID string
    protected $primaryKey = 'uuid';
    public $incrementing = false;     // bukan auto-increment
    protected $keyType = 'string';    // tipe data string

    protected static function boot(): void
    {
        parent::boot();

        static::creating(function ($user) {
            $user->uuid = (string) str()->uuid();
        });
    }
}

class LegacyOrder extends Model
{
    // Tabel legacy dengan composite key
    // Eloquent tidak mendukung composite key secara native
    // Harus di-handle manual
    protected $primaryKey = 'order_id';
}
```

## Kasus Penggunaan Nyata
- Tabel menggunakan UUID sebagai primary key (distributed system)
- Database legacy dengan `product_id` atau `category_id` sebagai PK
- Tabel yang menggunakan kode unik (seperti `kode_barang`) sebagai identitas
