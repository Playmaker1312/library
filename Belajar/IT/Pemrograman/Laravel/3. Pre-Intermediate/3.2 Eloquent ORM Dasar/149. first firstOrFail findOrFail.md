# 149. first firstOrFail findOrFail

## Definisi Singkat
`first()` mengambil record pertama dari hasil query (return model atau null). `firstOrFail()` sama tapi melempar exception jika tidak ditemukan. `findOrFail()` mencari berdasarkan primary key dan throw exception jika tidak ada.

## Analogi
- `first()`: Seperti mengambil buah paling atas dari tumpukan — jika tidak ada, tangan kosong
- `firstOrFail()`: Seperti memesan menu di restoran — jika tidak ada, komplain (exception)
- `findOrFail()`: Seperti mencari buku berdasarkan kategori — jika tidak ada, lapor pustakawan

## Poin-Poin Penting
- `first()` mengembalikan model instance atau `null`
- `firstOrFail()` mengembalikan model instance atau throw `ModelNotFoundException`
- `findOrFail($id)` mencari PK lalu throw exception jika tidak ketemu
- `firstOrFail()` dan `findOrFail()` otomatis return 404 di controller
- `firstWhere('kolom', 'nilai')` shorthand untuk `where()->first()`

## Contoh Kode
```php
use App\Models\User;
use App\Models\Post;

// first() — bisa null
$user = User::where('email', 'john@example.com')->first();
if ($user) {
    echo $user->name;
}

// Shorthand: firstWhere
$user = User::firstWhere('email', 'john@example.com');

// firstOrFail() — throw exception
$user = User::where('role', 'admin')->firstOrFail();
// Jika tidak ada admin → ModelNotFoundException

// findOrFail($id) — cari PK
$post = Post::findOrFail(1);
// Jika post id=1 tidak ada → 404

// Di Controller - contoh penggunaan
public function show($id)
{
    // Otomatis return 404 jika tidak ditemukan
    $post = Post::findOrFail($id);
    return view('posts.show', compact('post'));
}

// firstOr() — bisa fallback ke callback
$user = User::where('age', '>', 100)->firstOr(function () {
    return 'Tidak ada user berusia di atas 100 tahun';
});
```

## Kasus Penggunaan Nyata
- `firstOrFail` di controller untuk detail page (404 jika tidak ada)
- `firstWhere` untuk cek email unik saat registrasi
- `findOrFail` di method `show`, `edit`, `update`, `destroy` (resource controller)
