# 148. Metode where()

## Definisi Singkat
`Model::where()` menambahkan kondisi query untuk memfilter record berdasarkan kolom tertentu. Mendukung operator perbandingan dan chaining.

## Analogi
Seperti saringan dengan beberapa tingkat — Anda bisa menyaring berdasarkan ukuran, warna, dan berat sekaligus untuk mendapatkan hasil yang spesifik.

## Poin-Poin Penting
- Format: `where('kolom', 'operator', 'nilai')`
- Operator: `=`, `>`, `<`, `>=`, `<=`, `!=`, `like`
- Jika hanya 2 parameter: `where('kolom', 'nilai')` → operator `=`
- Bisa di-chain: `where()->where()->where()`
- Hasil query builder — harus diakhiri dengan `get()`, `first()`, dll.

## Contoh Kode
```php
use App\Models\User;
use App\Models\Post;

// Basic where (operator =)
$users = User::where('is_active', true)->get();
// SELECT * FROM users WHERE is_active = 1

// Dengan operator
$users = User::where('age', '>', 18)->get();
// SELECT * FROM users WHERE age > 18

$products = Product::where('price', '<=', 100000)->get();

$posts = Post::where('title', 'like', '%Laravel%')->get();

// Chaining — semua kondisi AND
$users = User::where('is_active', true)
             ->where('role', 'admin')
             ->where('age', '>=', 21)
             ->get();
// SELECT * FROM users WHERE is_active = 1 AND role = 'admin' AND age >= 21

// orWhere
$users = User::where('role', 'admin')
             ->orWhere('role', 'superadmin')
             ->get();
// SELECT * FROM users WHERE role = 'admin' OR role = 'superadmin'

// where dengan array
$users = User::where([
    ['is_active', true],
    ['role', 'admin'],
])->get();

// whereNull / whereNotNull
$users = User::whereNull('email_verified_at')->get();
$users = User::whereNotNull('password')->get();
```

## Kasus Penggunaan Nyata
- Filter produk berdasarkan kategori dan harga
- Mencari user dengan email spesifik
- Menampilkan artikel yang sudah dipublikasikan
- Filter data berdasarkan tanggal (whereDate, whereMonth, whereYear)
