# 144. Properti Table Kustom

## Definisi Singkat
Properti `$table` pada model Eloquent digunakan untuk menentukan nama tabel secara eksplisit jika berbeda dari konvensi default.

## Analogi
Seperti memberi label khusus pada map arsip — meskipun biasanya map diberi nama sesuai isi, kadang Anda perlu memakai nama yang berbeda dari kebiasaan.

## Poin-Poin Penting
- Tetapkan `protected $table = 'nama_tabel';` di model
- Berguna jika nama tabel tidak mengikuti konvensi snake_case plural
- Berguna untuk menggunakan tabel yang sudah ada sebelumnya (legacy)
- Juga untuk model yang menggunakan tabel dari database eksternal

## Contoh Kode
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Product extends Model
{
    // Nama model: Product
    // Default Eloquent: 'products'
    // Tapi kita pakai tabel lama: 'tbl_products'
    protected $table = 'tbl_products';
}

class Admin extends Model
{
    // Model: Admin → default: 'admins'
    // Tapi tabel yang ada: 'users'
    protected $table = 'users';
}

class Setting extends Model
{
    // Model: Setting → default: 'settings'
    // Tapi kita ingin eksplisit
    protected $table = 'app_settings';

    // Koneksi database yang berbeda
    protected $connection = 'mysql_secondary';
}

// Polymorphic — tabel kustom untuk pivot
class ProductUser extends Model
{
    protected $table = 'product_user';  // pivot table
}
```

## Kasus Penggunaan Nyata
- Migrasi dari sistem lama dengan nama tabel `tbl_mst_product`
- Database dengan prefix seperti `wp_posts`, `app_users`
- Tabel pivot many-to-many yang manual
- Model untuk view database (bukan tabel fisik)
