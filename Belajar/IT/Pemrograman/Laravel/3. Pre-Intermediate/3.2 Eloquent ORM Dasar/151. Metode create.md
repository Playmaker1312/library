# 151. Metode create()

## Definisi Singkat
`Model::create(array $data)` adalah method untuk menyimpan record baru ke database dalam satu baris — membuat instance model, mengisi atribut, dan menyimpannya sekaligus.

## Analogi
Seperti mengisi formulir pendaftaran online — semua data diisi sekaligus, lalu satu klik "Daftar" langsung memproses dan menyimpannya.

## Poin-Poin Penting
- Menggunakan mass assignment — membutuhkan `$fillable` atau `$guarded`
- Menerima array asosiatif: `['kolom' => 'nilai']`
- Mengembalikan instance model yang sudah tersimpan
- Melempar `MassAssignmentException` jika kolom tidak di-fillable
- Alternatif: `forceCreate()` untuk bypass mass assignment protection

## Contoh Kode
```php
use App\Models\User;
use App\Models\Post;

// Pastikan model punya fillable
class User extends Model
{
    protected $fillable = [
        'name', 'email', 'password', 'phone'
    ];
}

// Create — simpan data baru
$user = User::create([
    'name' => 'John Doe',
    'email' => 'john@example.com',
    'password' => bcrypt('secret123'),
]);

echo $user->id;  // ID yang baru dibuat
echo $user->name;  // 'John Doe'

// Create di controller
public function store(Request $request)
{
    $validated = $request->validate([
        'name' => 'required|string|max:255',
        'email' => 'required|email|unique:users',
        'password' => 'required|min:8',
    ]);

    $validated['password'] = bcrypt($validated['password']);

    $user = User::create($validated);

    return redirect()->route('users.index');
}

// create() vs manual:
// Manual:
$user = new User();
$user->name = 'John';
$user->email = 'john@example.com';
$user->save();

// Sama dengan:
$user = User::create([
    'name' => 'John',
    'email' => 'john@example.com',
]);
```

- Registrasi user baru dari form
- Membuat postingan baru dari editor
- Menambahkan produk baru ke katalog
