# 153. Metode update()

## Definisi Singkat
`Model::where(...)->update($data)` atau `$model->update($data)` memperbarui record di database dengan array data yang diberikan.

## Analogi
Seperti mengganti beberapa halaman di buku tanpa menulis ulang seluruh buku — hanya bagian yang diubah yang diperbarui.

## Poin-Poin Penting
- `update()` pada query builder: `Model::where('id', 1)->update([...])`
- `update()` pada instance: `$model->update([...])` — butuh fillable
- Tidak mengembalikan model instance, tapi jumlah baris yang terpengaruh
- `$model->update()` otomatis mengisi `updated_at`
- Wajib ada `$fillable` atau `$guarded` untuk mass assignment
- Lebih efisien daripada `save()` untuk update langsung tanpa proses

## Contoh Kode
```php
use App\Models\User;
use App\Models\Post;

// Update via query builder (tanpa load model)
User::where('id', 1)->update([
    'name' => 'John Updated',
    'phone' => '08123456789',
]);
// RETURN: jumlah baris yang diupdate (int)

// Update via instance model
$user = User::find(1);
$user->update([
    'name' => 'John Updated',
    'phone' => '08123456789',
]);
// RETURN: bool

// Bulk update — semua user aktif diganti role-nya
User::where('is_active', true)
    ->where('age', '>', 18)
    ->update(['role' => 'member']);

// Increment / Decrement (shorthand)
Post::where('id', 1)->increment('views');        // views + 1
Post::where('id', 1)->increment('views', 5);     // views + 5
Post::where('id', 1)->decrement('stock');         // stock - 1
Post::where('id', 1)->decrement('stock', 3);      // stock - 3

// Update dengan kondisi
User::where('email_verified_at', null)
    ->update(['status' => 'unverified']);
```

## Kasus Penggunaan Nyata
- Update profil user dari form edit
- Mengganti role user secara massal (misal: semua member jadi premium)
- Increment view counter setiap kali artikel dibuka
- Update status pesanan (pending → processing → completed)
