# 155. Mass Assignment Fillable Guarded

## Definisi Singkat
Mass assignment protection adalah fitur keamanan yang mencegah pengguna mengisi kolom sensitif (seperti `is_admin`) secara massal. Diatur dengan properti `$fillable` (whitelist) atau `$guarded` (blacklist).

## Analogi
Seperti formulir online dengan kolom yang bisa diisi — ada kolom yang bisa diisi user (fillable) dan ada kolom yang disembunyikan (guarded) seperti role admin.

## Poin-Poin Penting
- `$fillable` — daftar kolom yang BOLEH diisi massal (whitelist)
- `$guarded` — daftar kolom yang TIDAK BOLEH diisi massal (blacklist)
- Pilih salah satu, jangan keduanya (kecuali $guarded = [])
- `$guarded = ['*']` — semua kolom guarded (tidak ada mass assignment)
- `$guarded = []` — semua kolom boleh diisi (hati-hati!)
- `Model::create()`, `$model->update()`, `$model->fill()` terpengaruh
- `$model->save()` dengan assign manual tidak terpengaruh
- `Model::forceCreate()` bypass protection

## Contoh Kode
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class User extends Model
{
    // WHITELIST — hanya kolom ini yang boleh diisi massal
    protected $fillable = [
        'name',
        'email',
        'password',
        'phone',
        'avatar',
    ];

    // Kolom 'is_admin' TIDAK ada di fillable → tidak bisa diisi massal
}

// Pendekatan guarded (BLACKLIST)
class User extends Model
{
    // Semua kolom boleh diisi KECUALI yang di guarded
    protected $guarded = [
        'is_admin',        // Tidak bisa diisi massal
        'remember_token',  // Juga tidak bisa
    ];
}

// Pendekatan guarded = [] (semua boleh — hati-hati!)
class Product extends Model
{
    protected $guarded = [];  // Semua kolom fillable
}

// Contoh serangan mass assignment yang dicegah:
// Hacker mengirim: {"name": "John", "is_admin": 1}
// Jika is_admin TIDAK di fillable → akan diabaikan
User::create($request->all());  // Aman: is_admin tidak terisi

// Cara bypass (tidak disarankan sembarangan)
$user = User::forceCreate([
    'name' => 'Admin',
    'email' => 'admin@site.com',
    'is_admin' => true,
]);
```

## Kasus Penggunaan Nyata
- Form registrasi — hanya kolom name, email, password yang diisi
- Form edit profil — hanya name, phone, avatar yang bisa diubah
- Keamanan: mencegah user mengubah role, status, saldo
- API: mencegah field sensitif diterima dari request
