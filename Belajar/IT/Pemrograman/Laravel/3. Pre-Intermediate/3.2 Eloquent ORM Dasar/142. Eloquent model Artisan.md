# 142. Eloquent Model Artisan

## Definisi Singkat
`php artisan make:model NamaModel` adalah perintah untuk membuat file model Eloquent baru.

## Analogi
Seperti mesin pencetak stempel — cukup masukkan nama, dan Artisan menghasilkan file model dengan struktur dasar yang siap pakai.

## Poin-Poin Penting
- Model disimpan di `app/Models/` (Laravel 8+)
- Bisa langsung dibuat dengan migration: `--migration` atau `-m`
- Opsi `-c` untuk Controller, `-f` untuk Factory
- Opsi `-s` untuk Seeder, `-p` untuk Policy
- Model dasar hanya extends `Illuminate\Database\Eloquent\Model`

## Contoh Kode
```bash
# Model dasar
php artisan make:model Product

# Model + migration
php artisan make:model Product -m
# atau
php artisan make:model Product --migration

# Model + migration + controller (resource)
php artisan make:model Product -mc

# Model + migration + factory + seeder + controller
php artisan make:model Product -mfsc

# Model + semua (all)
php artisan make:model Product --all
```

Hasil file model:
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Product extends Model
{
    use HasFactory;
}
```

## Kasus Penggunaan Nyata
- Membuat model baru untuk setiap tabel database
- Generate model + migration sekaligus untuk efisiensi
- Saat memulai fitur baru (misal: modul produk, kategori, order)
