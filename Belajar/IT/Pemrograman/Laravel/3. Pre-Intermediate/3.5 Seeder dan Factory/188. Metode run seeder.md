# 188. Metode Run Seeder

## Definisi Singkat
Method `run()` adalah method utama di kelas Seeder yang berisi logika untuk memasukkan data ke database.

## Analogi
Seperti tombol "Eksekusi" pada mesin — semua instruksi di dalam method `run()` akan dijalankan berurutan saat seeder dipanggil.

## Poin-Poin Penting
- Setiap seeder WAJIB memiliki method `run()`
- Bisa menggunakan `Model::create()`, `DB::table()`, atau Factory
- Eksekusi: `php artisan db:seed`
- Bisa insert banyak data dengan loop atau Factory
- Method `call()` untuk memanggil seeder lain
- `DB::table('table')->truncate()` untuk reset data sebelum insert

## Contoh Kode
```php
namespace Database\Seeders;

use App\Models\Product;
use App\Models\Category;
use Illuminate\Database\Seeder;
use Illuminate\Support\Facades\DB;

class ProductSeeder extends Seeder
{
    public function run(): void
    {
        // Opsi 1: Insert manual satu per satu
        Product::create([
            'name' => 'Laptop Gaming',
            'price' => 15000000,
            'category_id' => 1,
            'stock' => 10,
        ]);

        // Opsi 2: Insert dengan loop
        $products = [
            ['name' => 'Mouse Wireless', 'price' => 250000, 'category_id' => 1, 'stock' => 50],
            ['name' => 'Keyboard Mechanical', 'price' => 750000, 'category_id' => 1, 'stock' => 30],
            ['name' => 'Monitor 4K', 'price' => 5000000, 'category_id' => 1, 'stock' => 15],
        ];

        foreach ($products as $product) {
            Product::create($product);
        }

        // Opsi 3: Insert massal dengan DB facade
        DB::table('brands')->insert([
            ['name' => 'Samsung', 'slug' => 'samsung'],
            ['name' => 'Apple', 'slug' => 'apple'],
            ['name' => 'Xiaomi', 'slug' => 'xiaomi'],
        ]);

        // Opsi 4: Kombinasi dengan Factory
        Product::factory(10)->create();
        Product::factory(5)->outOfStock()->create();  // state khusus

        // Opsi 5: Truncate + insert (reset data)
        DB::table('categories')->truncate();  // hapus semua
        Category::create(['name' => 'Baru']); // insert ulang
    }
}
```

## Kasus Penggunaan Nyata
- Insert data referensi (roles, status, jenis kelamin)
- Insert data demo untuk presentasi
- Reset dan isi ulang data testing
- Seed data berdasarkan data dari API eksternal atau file CSV
