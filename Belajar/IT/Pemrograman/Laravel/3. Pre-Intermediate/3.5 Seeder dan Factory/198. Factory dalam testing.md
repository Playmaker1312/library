# 198. Factory dalam Testing

## Definisi Singkat
Factory digunakan secara intensif di testing (PHPUnit/Pest) untuk membuat data test dengan cepat dan efisien.

## Analogi
Seperti aktor figuran di film — factory menyediakan "pemain" (data) untuk setiap skenario test tanpa perlu casting manual setiap kali.

## Poin-Poin Penting
- Factory membuat data test lebih cepat dan konsisten
- `Model::factory()->create()` untuk persist data
- `Model::factory()->make()` untuk instance tanpa save
- `refresh()` untuk reload model dari database
- Kombinasikan dengan state untuk berbagai skenario
- `DatabaseTransactions` trait untuk rollback otomatis

## Contoh Kode
```php
// Test dengan PHPUnit
namespace Tests\Feature;

use App\Models\User;
use App\Models\Post;
use Illuminate\Foundation\Testing\RefreshDatabase;
use Tests\TestCase;

class PostTest extends TestCase
{
    use RefreshDatabase;  // Reset database setiap test

    public function test_guest_cannot_create_post(): void
    {
        $response = $this->post('/posts', [
            'title' => 'Test Post',
            'body' => 'Content',
        ]);

        $response->assertRedirect('/login');
    }

    public function test_authenticated_user_can_create_post(): void
    {
        // Buat user dengan factory
        $user = User::factory()->create();

        $response = $this->actingAs($user)
                         ->post('/posts', [
                             'title' => 'Test Post',
                             'body' => 'Content body',
                         ]);

        $response->assertStatus(302);
        $this->assertDatabaseHas('posts', [
            'title' => 'Test Post',
            'user_id' => $user->id,
        ]);
    }

    public function test_post_list_shows_only_published(): void
    {
        // Buat beberapa post dengan state berbeda
        Post::factory()->create(['is_published' => true]);   // 1 published
        Post::factory(2)->create(['is_published' => false]); // 2 drafts

        $response = $this->get('/posts');

        $response->assertSee(...);  // hanya 1 post yang tampil
    }

    public function test_admin_can_see_all_posts(): void
    {
        $admin = User::factory()->admin()->create();

        Post::factory(5)->create();

        $response = $this->actingAs($admin)
                         ->get('/admin/posts');

        $response->assertStatus(200);
    }
}
```

## Kasus Penggunaan Nyata
- Unit test: test model scope, accessor, mutator
- Feature test: test endpoint dengan data spesifik
- Authentication test: test akses berdasarkan role
- Relationship test: test relasi bekerja dengan benar
- Validation test: test berbagai kombinasi input
