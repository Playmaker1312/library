# 187. Membuat Seeder Artisan

## Definisi Singkat
`php artisan make:seeder NamaSeeder` adalah perintah untuk membuat file seeder baru dengan struktur dasar.

## Analogi
Seperti mencetak template surat kosong — Anda tinggal mengisi isinya (data), format dan tempatnya sudah disediakan.

## Poin-Poin Penting
- File dibuat di `database/seeders/`
- Nama seeder menggunakan StudlyCase (contoh: `ProductSeeder`)
- Isi method `run()` dengan logika insert data
- Bisa menggunakan Eloquent, DB facade, atau Factory
- Seeder yang dibuat harus didaftarkan di `DatabaseSeeder.php`

## Contoh Kode
```bash
# Membuat seeder baru
php artisan make:seeder CategorySeeder

# File yang dihasilkan: database/seeders/CategorySeeder.php
```

```php
// database/seeders/CategorySeeder.php
namespace Database\Seeders;

use App\Models\Category;
use Illuminate\Database\Seeder;

class CategorySeeder extends Seeder
{
    public function run(): void
    {
        Category::create([
            'name' => 'Elektronik',
            'slug' => 'elektronik',
            'description' => 'Produk elektronik dan gadget',
        ]);

        Category::create([
            'name' => 'Pakaian',
            'slug' => 'pakaian',
            'description' => 'Pakaian pria, wanita, dan anak',
        ]);

        Category::create([
            'name' => 'Makanan & Minuman',
            'slug' => 'makanan-minuman',
        ]);
    }
}

// Daftarkan di DatabaseSeeder.php
class DatabaseSeeder extends Seeder
{
    public function run(): void
    {
        $this->call([
            CategorySeeder::class,
            // ProductSeeder::class,
        ]);
    }
}
```

## Kasus Penggunaan Nyata
- Buat seeder untuk setiap entitas baru (Category, Brand, Status)
- Seeder terpisah untuk data testing dan data production
- Seeder khusus untuk role/permissions
- Seeder untuk data geografis (provinsi, kota, kecamatan)
