# 192. Factory Data Palsu

## Definisi Singkat
Factory adalah kelas di Laravel untuk menghasilkan data palsu (dummy data) dalam jumlah besar menggunakan Faker library, ideal untuk testing dan development.

## Analogi
Seperti mesin pencetak dokumen contoh — Anda tinggal menentukan berapa banyak (quantity), mesin akan menghasilkan data dengan isian yang realistis.

## Poin-Poin Penting
- Berbasis Faker (library PHP untuk data palsu)
- Factory didefinisikan per model
- Method `definition()` mengembalikan array atribut default
- Factory states untuk variasi data
- Factory bisa untuk relasi antar model

## Contoh Kode
```php
namespace Database\Factories;

use App\Models\Product;
use Illuminate\Database\Eloquent\Factories\Factory;

class ProductFactory extends Factory
{
    protected $model = Product::class;

    public function definition(): array
    {
        return [
            'name' => fake()->unique()->words(3, true),         // Nama produk
            'slug' => fake()->unique()->slug(3),
            'description' => fake()->paragraph(),                // Deskripsi
            'price' => fake()->numberBetween(10000, 10000000),  // Harga random
            'stock' => fake()->numberBetween(0, 100),           // Stok random
            'is_active' => fake()->boolean(80),                  // 80% true
        ];
    }
}

// Penggunaan factory:
// Buat 1 produk
Product::factory()->create();

// Buat 10 produk
Product::factory(10)->create();

// Buat dengan data spesifik
Product::factory()->create([
    'name' => 'Produk Spesial',
    'price' => 500000,
]);
```

## Kasus Penggunaan Nyata
- Testing: isi database dengan 100 user untuk uji coba pagination
- Development: lihat tampilan aplikasi dengan data realistik
- Demo: siapkan data presentasi dengan cepat
- Stress test: buat ribuan record untuk uji performa
