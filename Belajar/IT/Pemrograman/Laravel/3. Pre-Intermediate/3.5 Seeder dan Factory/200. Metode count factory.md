# 200. Metode Count Factory

## Definisi Singkat
Parameter `count` pada factory menentukan berapa banyak record yang akan dibuat: `Model::factory(10)->create()` membuat 10 record.

## Analogi
Seperti memesan jumlah roti: "Saya pesan 12 donat" — factory(12) membuat 12 instance model sekaligus.

## Poin-Poin Penting
- `factory(5)->create()` — buat 5 record
- `factory(5)->make()` — buat 5 instance tanpa save
- `count()` method: `factory()->count(5)->create()`
- count bisa 0: `factory(0)->create()` — tidak buat apa-apa
- Untuk relasi dengan jumlah: `has(Post::factory(3))`

## Contoh Kode
```php
use App\Models\User;
use App\Models\Post;

// Buat 1 record
User::factory()->create();
User::factory(1)->create();

// Buat 10 record
User::factory(10)->create();

// Buat dengan count() method
User::factory()->count(10)->create();

// Buat 5 dengan state
User::factory(5)->admin()->create();

// Buat 0 record (tidak berguna, tapi valid)
User::factory(0)->create();

// Buat 25 user — masing-masing dengan 3 post
User::factory(25)
    ->has(Post::factory(3))
    ->create();
// Total: 25 user + 75 post = 100 record

// Buat 100 post dari user random
$users = User::factory(10)->create();
Post::factory(100)->create([
    'user_id' => fn() => $users->random()->id,
]);

// Count + for
$category = Category::factory()->create();
Product::factory(20)
    ->for($category)
    ->featured()
    ->create();

// Dynamic count berdasarkan kondisi
$count = app()->environment('production') ? 1 : 50;
User::factory($count)->create();

// Di seeder
class ProductSeeder extends Seeder
{
    public function run(): void
    {
        $categories = Category::factory(5)->create();

        foreach ($categories as $category) {
            // 10-20 produk per kategori
            $count = rand(10, 20);
            Product::factory($count)->create([
                'category_id' => $category->id,
            ]);
        }
    }
}
```

## Kasus Penggunaan Nyata
- Test pagination: butuh 50 record untuk 5 halaman
- Test performance: buat 1000 record untuk uji query
- Seed development: 25 user, 100 post, 500 komentar
- Test edge case: buat 0 atau 1 record untuk situasi spesifik
