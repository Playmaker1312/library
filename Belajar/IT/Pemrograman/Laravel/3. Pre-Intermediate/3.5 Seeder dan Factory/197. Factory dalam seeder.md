# 197. Factory dalam Seeder

## Definisi Singkat
Factory bisa dipanggil langsung di dalam seeder untuk menghasilkan data dalam jumlah besar dengan cepat.

## Analogi
Seperti menggunakan mesin roti otomatis di toko roti — factory adalah mesinnya, seeder adalah daftar pesanan yang menentukan berapa banyak roti yang harus dibuat.

## Poin-Poin Penting
- Panggil `Model::factory(n)->create()` di method `run()`
- Bisa kombinasikan dengan state
- Factory otomatis membuat relasi (jika didefinisikan)
- `create()` menyimpan ke database
- `make()` membuat instance tanpa menyimpan

## Contoh Kode
```php
namespace Database\Seeders;

use App\Models\User;
use App\Models\Post;
use App\Models\Category;
use App\Models\Product;
use Illuminate\Database\Seeder;

class DevelopmentSeeder extends Seeder
{
    public function run(): void
    {
        // Buat category dulu (referensi)
        $categories = Category::factory(5)->create();

        // Buat admin
        User::factory()->create([
            'name' => 'Admin Development',
            'email' => 'admin@dev.com',
            'role' => 'admin',
        ]);

        // Buat 50 user random
        User::factory(50)->create();

        // Buat produk — 10 per kategori
        foreach ($categories as $category) {
            Product::factory(10)->create([
                'category_id' => $category->id,
            ]);
        }
        // Total: 50 produk

        // Buat produk dengan variasi state
        Product::factory(5)->inactive()->create();
        Product::factory(3)->featured()->create();
        Product::factory(2)->outOfStock()->create();

        // Factory dengan relasi
        User::factory(10)
            ->has(Post::factory(5))  // setiap user punya 5 post
            ->create();

        // Alternatif: post dengan user_id random
        Post::factory(100)->create([
            'user_id' => User::inRandomOrder()->first()->id,
        ]);
    }
}

// Di DatabaseSeeder
class DatabaseSeeder extends Seeder
{
    public function run(): void
    {
        $this->call([
            DevelopmentSeeder::class,
        ]);
    }
}
```

## Kasus Penggunaan Nyata
- Seed 1000 produk untuk testing pagination dan filter
- Seed user dengan post dan komentar untuk social media app
- Data testing dengan relasi kompleks
- Development environment yang butuh data realistik
