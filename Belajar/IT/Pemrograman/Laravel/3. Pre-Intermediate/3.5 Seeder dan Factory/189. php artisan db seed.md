# 189. php artisan db:seed

## Definisi Singkap
`php artisan db:seed` menjalankan semua seeder yang terdaftar di `DatabaseSeeder.php` untuk mengisi database dengan data awal.

## Analogi
Seperti menekan tombol "Isi Otomatis" — semua data default akan dimasukkan ke database secara berurutan sesuai urutan pemanggilan.

## Poin-Poin Penting
- Menjalankan method `run()` di `DatabaseSeeder.php`
- `DatabaseSeeder.php` memanggil seeder lainnya via `$this->call()`
- Bisa dikombinasikan dengan migrate: `migrate --seed`
- Gunakan `--class` untuk menjalankan seeder spesifik
- Hati-hati: bisa duplicate data jika dijalankan ulang — gunakan `truncate()` atau `firstOrCreate()`

## Contoh Kode
```bash
# Jalankan semua seeder
php artisan db:seed

# Jalankan seeder spesifik
php artisan db:seed --class=UserSeeder

# Saat migrate + seed sekaligus
php artisan migrate --seed

# Fresh + seed
php artisan migrate:fresh --seed

# Refresh + seed
php artisan migrate:refresh --seed

# Seed dengan force (production)
php artisan db:seed --force

# Seeder di production — pastikan aman
# php artisan db:seed --class=ProductionSeeder --force
```

```php
// DatabaseSeeder.php — urutan penting!
class DatabaseSeeder extends Seeder
{
    public function run(): void
    {
        // Urutkan dari tabel yang tidak punya FK ke yang punya FK
        $this->call([
            RoleSeeder::class,        // 1. roles (tidak depend)
            UserSeeder::class,        // 2. users (butuh role_id)
            CategorySeeder::class,    // 3. categories (tidak depend)
            ProductSeeder::class,     // 4. products (butuh category_id)
        ]);
    }
}
```

## Kasus Penggunaan Nyata
- Setup development environment baru
- Run `migrate:fresh --seed` saat reset database
- CI/CD pipeline — seed data untuk testing
- Demo aplikasi dengan data contoh
