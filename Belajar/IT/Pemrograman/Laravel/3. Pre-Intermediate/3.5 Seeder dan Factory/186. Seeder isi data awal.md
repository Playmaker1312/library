# 186. Seeder Isi Data Awal

## Definisi Singkat
Seeder adalah kelas di Laravel untuk mengisi database dengan data awal (dummy/seed data) seperti user admin, kategori, atau produk contoh.

## Analogi
Seperti menyiapkan furnitur contoh di rumah baru — sebelum dihuni, rumah diisi dengan perabotan standar (data awal) agar tidak kosong total.

## Poin-Poin Penting
- Disimpan di `database/seeders/`
- Berisi method `run()` yang mengeksekusi insert data
- `DatabaseSeeder.php` adalah file utama yang memanggil seeder lain
- Dijalankan dengan `php artisan db:seed`
- Bisa dikombinasikan dengan Factory untuk data massal
- Jangan gunakan data sensitif di seeder (password default)

## Contoh Kode
```php
// File: database/seeders/DatabaseSeeder.php

namespace Database\Seeders;

use App\Models\User;
use Illuminate\Database\Seeder;

class DatabaseSeeder extends Seeder
{
    public function run(): void
    {
        // Panggil seeder lain
        $this->call([
            UserSeeder::class,
            CategorySeeder::class,
            ProductSeeder::class,
        ]);
    }
}

// File: database/seeders/UserSeeder.php
namespace Database\Seeders;

use App\Models\User;
use Illuminate\Database\Seeder;
use Illuminate\Support\Facades\Hash;

class UserSeeder extends Seeder
{
    public function run(): void
    {
        // Buat user admin default
        User::create([
            'name' => 'Admin',
            'email' => 'admin@example.com',
            'password' => Hash::make('password'),
            'role' => 'admin',
        ]);

        // Buat user biasa
        User::create([
            'name' => 'User Biasa',
            'email' => 'user@example.com',
            'password' => Hash::make('password'),
            'role' => 'user',
        ]);
    }
}
```

## Kasus Penggunaan Nyata
- User admin default untuk development (email: admin@test.com)
- Data kategori, status, tipe yang statis
- Data demo untuk testing fitur
- Setup awal project untuk tim developer baru
- Data referensi (roles, permissions, settings)
