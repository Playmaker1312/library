# 190. Seeder Spesifik Flag Class

## Definisi Singkat
Flag `--class` pada `php artisan db:seed` memungkinkan menjalankan satu seeder tertentu tanpa harus menjalankan semua seeder.

## Analogi
Seperti memanggil satu orang spesifik di antara kerumunan — Anda tidak perlu mengumpulkan semua orang, cukup panggil nama yang diinginkan.

## Poin-Poin Penting
- `php artisan db:seed --class=NamaSeeder`
- Tidak perlu menjalankan semua seeder di `DatabaseSeeder`
- Berguna untuk development dan testing
- Pastikan dependensi tabel sudah ada
- Bisa digunakan di production untuk data referensi

## Contoh Kode
```bash
# Jalankan hanya UserSeeder
php artisan db:seed --class=UserSeeder

# Jalankan hanya ProductSeeder
php artisan db:seed --class=ProductSeeder

# Jalankan dengan force (production)
php artisan db:seed --class=RoleSeeder --force
```

```php
// Contoh: Seed data role saja
// php artisan db:seed --class=RoleSeeder

namespace Database\Seeders;

use App\Models\Role;
use Illuminate\Database\Seeder;

class RoleSeeder extends Seeder
{
    public function run(): void
    {
        // Menggunakan firstOrCreate agar tidak duplikat
        $roles = ['admin', 'editor', 'user', 'guest'];

        foreach ($roles as $name) {
            Role::firstOrCreate(['name' => $name]);
        }
    }
}

// Contoh: Seed data testing
// php artisan db:seed --class=TestDataSeeder
class TestDataSeeder extends Seeder
{
    public function run(): void
    {
        // Buat 1 admin
        User::factory()->admin()->create([
            'email' => 'test@example.com',
        ]);

        // Buat 50 user random
        User::factory(50)->create();
    }
}
```

## Kasus Penggunaan Nyata
- Tambah data kategori baru tanpa reset semua data
- Testing seeder tertentu saja
- Production: seed data referensi (provinsi, bank, dll.)
- Development: seed data testing tanpa data lain
