# 199. Factory for has Relasi

## Definisi Singkat
Factory magic methods `for()` dan `has()` digunakan untuk membuat relasi antar model saat membuat data factory — membuat model induk dan anak sekaligus.

## Analogi
Seperti memesan paket lengkap: "Saya mau 1 user dengan 3 postingan dan 5 komentar" — factory akan membuat semuanya dalam satu perintah.

## Poin-Poin Penting
- `has()` — model ini memiliki relasi (hasOne, hasMany)
- `for()` — model ini milik relasi (belongsTo)
- `hasPosts(3)` — magic method untuk `has(Post::factory(3), 'posts')`
- `forUser($user)` — magic method untuk `for($user)`
- Bisa nested: `has(Post::factory(3)->has(Comment::factory(2)))`
- Bekerja untuk semua tipe relasi

## Contoh Kode
```php
use App\Models\User;
use App\Models\Post;
use App\Models\Comment;
use App\Models\Category;

// has() — user punya beberapa post
// Buat 1 user dengan 5 post
User::factory()
    ->has(Post::factory(5))
    ->create();

// User dengan 3 post, setiap post punya 2 komentar
User::factory()
    ->has(
        Post::factory(3)
            ->has(Comment::factory(2))
    )
    ->create();

// Magic method: hasPosts()
User::factory()
    ->hasPosts(3)
    ->create();

// for() — post milik user tertentu
$user = User::factory()->create();

Post::factory()
    ->for($user)
    ->create();
// atau
Post::factory()
    ->forUser($user)  // magic method
    ->create();

// for dengan belongsTo (category)
$category = Category::factory()->create();

Post::factory()
    ->for($category)
    ->for($user)
    ->create();
// atau
Post::factory()
    ->forCategory($category)
    ->forUser($user)
    ->create();

// Kombinasi
User::factory()
    ->has(
        Post::factory(3)
            ->for(Category::factory())  // buat category baru
            ->has(Comment::factory(2)->for(Comment::factory(), 'parent'))
    )
    ->create();

// Attach many-to-many
$user = User::factory()
    ->hasAttached(
        Role::factory()->count(2),
        ['assigned_by' => 'system']
    )
    ->create();
```

## Kasus Penggunaan Nyata
- Test data: user + post + komentar dalam satu baris
- Seed data: kategori dengan produk di dalamnya
- Testing relasi kompleks: order → items → product
- Factory data untuk demo aplikasi yang lengkap
