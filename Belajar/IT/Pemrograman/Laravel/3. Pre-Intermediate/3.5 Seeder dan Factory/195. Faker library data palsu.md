# 195. Faker Library Data Palsu

## Definisi Singkat
Faker adalah library PHP yang menghasilkan data palsu realistis — nama, alamat, email, teks, angka, dan berbagai tipe data lainnya.

## Analogi
Seperti generator identitas palsu untuk film — membuat karakter dengan nama, alamat, pekerjaan, dan latar belakang yang terlihat nyata.

## Poin-Poin Penting
- Dipanggil dengan `fake()` atau `$this->faker` di factory
- Metode Faker: `name()`, `email()`, `address()`, `phoneNumber()`, dll.
- Lokalisasi: `fake('id_ID')` untuk data Indonesia
- `unique()` untuk nilai unik: `fake()->unique()->email()`
- `optional()` untuk nilai nullable: `optional(fake())->text()`

## Contoh Kode
```php
namespace Database\Factories;

use App\Models\User;
use Illuminate\Database\Eloquent\Factories\Factory;

class UserFactory extends Factory
{
    public function definition(): array
    {
        return [
            'name' => fake()->name(),                          // John Doe
            'email' => fake()->unique()->safeEmail(),          // john@example.com
            'phone' => fake()->phoneNumber(),                  // (021) 1234-5678
            'address' => fake()->address(),                    // Jl. Merdeka No. 123
            'bio' => fake()->paragraph(),                      // Paragraf random
            'company' => fake()->company(),                    // PT. Contoh
            'birth_date' => fake()->date('Y-m-d', '2000-01-01'), // 1990-05-15
        ];
    }
}

// Lokalisasi Indonesia
// config/app.php: 'faker_locale' => 'id_ID',
// atau di factory:
fake('id_ID')->name();    // Slamet Wahyudi
fake('id_ID')->city();    // Jakarta Selatan
fake('id_ID')->address(); // Jl. Kenangan No. 45, RT 02/RW 03
fake('id_ID')->phoneNumber(); // 0812-3456-7890

// Berbagai method Faker
fake()->word();              // Kata acak
fake()->words(3, true);      // 3 kata
fake()->sentence(6);         // Kalimat 6 kata
fake()->paragraph(3);        // 3 paragraf
fake()->text(200);           // Teks maks 200 karakter

fake()->randomNumber(5);     // Angka 5 digit
fake()->numberBetween(1, 100); // Angka antara 1-100
fake()->randomFloat(2, 0, 1000); // Desimal: 123.45

fake()->boolean();           // true/false
fake()->randomElement(['admin', 'user', 'guest']); // Random dari array
fake()->shuffleArray([1, 2, 3]); // Acak urutan array

fake()->imageUrl(640, 480, 'cats'); // URL gambar random

// unique — nilai unik
fake()->unique()->email();   // Tidak akan duplikat dalam satu batch

// optional — kadang null
fake()->optional()->text();  // 50% kemungkinan null
fake()->optional(0.8)->text(); // 80% tidak null
```

## Kasus Penggunaan Nyata
- Data user testing dengan nama dan email realistis
- Alamat Indonesia untuk aplikasi lokal
- Konten artikel random untuk testing layout
- Data transaksi dengan nominal random untuk testing
