# 193. Membuat Factory Artisan

## Definisi Singkat
`php artisan make:factory NamaFactory` membuat file factory baru. Bisa langsung dikaitkan dengan model menggunakan opsi `--model`.

## Analogi
Seperti mencetak cetakan kue — sekali buat cetakan (factory), Anda bisa membuat banyak kue (data) dengan bentuk yang sama.

## Poin-Poin Penting
- Factory disimpan di `database/factories/`
- Nama factory: `NamaModelFactory` (contoh: `ProductFactory`)
- Opsi `--model` mengisi properti `$model` otomatis
- Factory yang sudah dibuat bisa diedit method `definition()`-nya
- Factory bisa untuk model apa pun

## Contoh Kode
```bash
# Buat factory dasar
php artisan make:factory ProductFactory

# Buat factory dengan model terkait
php artisan make:factory ProductFactory --model=Product

# Buat factory untuk model di subfolder
php artisan make:factory AdminFactory --model=Models/Admin
```

```php
// File: database/factories/ProductFactory.php
namespace Database\Factories;

use App\Models\Product;
use Illuminate\Database\Eloquent\Factories\Factory;

class ProductFactory extends Factory
{
    // Jika menggunakan --model=Product, properti ini otomatis terisi
    protected $model = Product::class;

    public function definition(): array
    {
        return [
            'name' => fake()->words(3, true),
            'price' => fake()->numberBetween(1000, 100000),
            'stock' => fake()->numberBetween(0, 50),
        ];
    }
}

// Jika factory tidak pakai --model, set manual:
class ProductFactory extends Factory
{
    protected $model = Product::class;

    public function definition(): array
    {
        return [];
    }
}
```

## Kasus Penggunaan Nyata
- Buat factory untuk setiap model baru
- Generate factory + model + migration sekaligus:
  `php artisan make:model Product -mf` (migration + factory)
- Buat factory untuk model legacy yang tidak punya factory
