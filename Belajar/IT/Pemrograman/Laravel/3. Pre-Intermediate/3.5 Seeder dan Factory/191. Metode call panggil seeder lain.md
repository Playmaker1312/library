# 191. Metode call Panggil Seeder Lain

## Definisi Singkat
`$this->call(ClassName::class)` di method `run()` digunakan untuk memanggil seeder lain dari dalam seeder, memungkinkan eksekusi berantai.

## Analogi
Seperti manajer yang mendelegasikan tugas ke tim — `DatabaseSeeder` (manajer) memanggil `UserSeeder`, `ProductSeeder`, dll. (anggota tim) untuk mengerjakan bagian masing-masing.

## Poin-Poin Penting
- `$this->call(UserSeeder::class)` — panggil satu seeder
- `$this->call([...])` — panggil array seeder
- Urutan pemanggilan penting (tabel dependen setelah tabel referensi)
- `$this->callSilent()` — panggil tanpa output log
- Bisa nested: Seeder A panggil B, B panggil C
- Seeder bisa dipanggil berkali-kali (tapi hati-hati duplikasi)

## Contoh Kode
```php
namespace Database\Seeders;

use Illuminate\Database\Seeder;

class DatabaseSeeder extends Seeder
{
    public function run(): void
    {
        // Panggil array seeder — urut sesuai array
        $this->call([
            // Tabel referensi (tidak punya foreign key)
            RoleSeeder::class,
            CategorySeeder::class,

            // Tabel dependen (punya foreign key)
            UserSeeder::class,
            ProductSeeder::class,

            // Relasi many-to-many
            PermissionSeeder::class,
        ]);
    }
}

// Nested call — seeder memanggil seeder lain
class UserSeeder extends Seeder
{
    public function run(): void
    {
        // Buat user admin
        User::factory()->create([
            'name' => 'Admin',
            'email' => 'admin@test.com',
        ]);

        // Panggil seeder untuk data terkait user
        $this->call([
            UserProfileSeeder::class,
            UserSettingSeeder::class,
        ]);
    }
}

// callSilent — tanpa output
class ProductSeeder extends Seeder
{
    public function run(): void
    {
        $this->callSilent(PriceSeeder::class);
        $this->callSilent(StockSeeder::class);
    }
}
```

## Kasus Penggunaan Nyata
- `DatabaseSeeder` sebagai entry point untuk semua seeder
- Memisahkan logika seed per entitas (modular)
- Urutan seed: Role → User → Post → Comment
- Reuse seeder di berbagai environment
