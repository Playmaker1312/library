# 194. Metode definition state default

## Definisi Singkat
`definition()` adalah method di factory yang mengembalikan array atribut default. `state()` membuat variasi dengan menimpa atau menambah atribut tertentu.

## Analogi
- `definition`: Seperti resep dasar kue — tepung, gula, telur (default)
- `state`: Seperti variasi rasa — coklat, keju, stroberi — tetap pakai resep dasar tapi dengan modifikasi

## Poin-Poin Penting
- `definition()` return array default yang digunakan setiap factory
- `state()` adalah method untuk membuat variasi data
- State didefinisikan sebagai method di factory: `public function namaState()`
- State bisa di-chain: `factory()->state1()->state2()->create()`
- `configure()` method untuk konfigurasi factory (callback)

## Contoh Kode
```php
namespace Database\Factories;

use App\Models\Product;
use Illuminate\Database\Eloquent\Factories\Factory;

class ProductFactory extends Factory
{
    protected $model = Product::class;

    // Data default — akan dipakai setiap kali factory dipanggil
    public function definition(): array
    {
        return [
            'name' => fake()->words(3, true),
            'price' => fake()->numberBetween(10000, 500000),
            'stock' => fake()->numberBetween(0, 100),
            'is_active' => true,
            'is_featured' => false,
        ];
    }

    // State: produk tidak aktif
    public function inactive(): static
    {
        return $this->state([
            'is_active' => false,
        ]);
    }

    // State: produk unggulan
    public function featured(): static
    {
        return $this->state([
            'is_featured' => true,
            'price' => fake()->numberBetween(100000, 1000000), // harga lebih mahal
        ]);
    }

    // State: produk gratis
    public function free(): static
    {
        return $this->state([
            'price' => 0,
            'name' => 'Gratis - ' . fake()->words(2, true),
        ]);
    }

    // State: stok habis
    public function outOfStock(): static
    {
        return $this->state([
            'stock' => 0,
            'is_active' => false,
        ]);
    }
}

// Penggunaan
Product::factory()->create();                           // default
Product::factory()->inactive()->create();                // produk tidak aktif
Product::factory()->featured()->create();                // produk unggulan
Product::factory(5)->outOfStock()->create();             // 5 produk stok habis
Product::factory()->free()->featured()->create();        // gratis + unggulan
```

## Kasus Penggunaan Nyata
- Produk dengan status berbeda (active/inactive/draft)
- User dengan role berbeda (admin/user/editor)
- Order dengan status berbeda (pending/completed/cancelled)
- Data testing untuk berbagai skenario
