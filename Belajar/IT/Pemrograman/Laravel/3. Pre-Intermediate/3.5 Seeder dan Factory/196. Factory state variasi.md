# 196. Factory State Variasi

## Definisi Singkat
Factory state adalah method di factory yang mendefinisikan variasi data — override atau tambahan atribut dari definition default.

## Analogi
Seperti menu restoran: `definition()` adalah resep dasar, sedangkan state adalah variasi menu — "default", "pedas", "vegetarian", "extra cheese".

## Poin-Poin Penting
- State didefinisikan sebagai method publik di factory
- State mengembalikan `$this->state([...])`
- Bisa juga menggunakan callback: `$this->state(fn() => [...])`
- State bisa menerima parameter
- States bisa di-chain
- `afterCreating()` untuk aksi setelah pembuatan (relasi)

## Contoh Kode
```php
namespace Database\Factories;

use App\Models\Order;
use App\Models\OrderItem;
use Illuminate\Database\Eloquent\Factories\Factory;

class OrderFactory extends Factory
{
    public function definition(): array
    {
        return [
            'order_number' => 'ORD-' . fake()->unique()->randomNumber(6),
            'status' => 'pending',
            'total_amount' => 0,
            'notes' => null,
        ];
    }

    // State: pesanan selesai
    public function completed(): static
    {
        return $this->state([
            'status' => 'completed',
        ]);
    }

    // State: pesanan dibatalkan
    public function cancelled(?string $reason = null): static
    {
        return $this->state(fn(array $attributes) => [
            'status' => 'cancelled',
            'notes' => $reason ?? fake()->sentence(),
        ]);
    }

    // State dengan callback — akses atribut lain
    public function withItems(int $count = 3): static
    {
        return $this->afterCreating(function (Order $order) use ($count) {
            OrderItem::factory($count)->create([
                'order_id' => $order->id,
            ]);

            // Update total berdasarkan item
            $order->update([
                'total_amount' => $order->items->sum('subtotal'),
            ]);
        });
    }

    // State: pesanan express
    public function express(): static
    {
        return $this->state([
            'shipping_method' => 'express',
            'shipping_cost' => 50000,
        ]);
    }
}

// Penggunaan
Order::factory()->create();                              // pending
Order::factory()->completed()->create();                  // selesai
Order::factory()->cancelled('Stok habis')->create();      // batal
Order::factory()->completed()->withItems(5)->create();    // selesai + 5 item
Order::factory()->express()->withItems(2)->create();      // express + 2 item

// Chain multiple states
Order::factory()
    ->completed()
    ->express()
    ->withItems(3)
    ->create();
```

## Kasus Penggunaan Nyata
- Order: pending, processing, completed, cancelled
- User: admin, editor, subscriber, premium
- Product: active, draft, archived, featured
- Payment: paid, unpaid, refunded, failed
- Testing berbagai skenario bisnis
