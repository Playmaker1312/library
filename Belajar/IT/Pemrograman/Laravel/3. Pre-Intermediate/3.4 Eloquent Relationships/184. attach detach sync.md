# 184. attach detach sync

## Definisi Singkat
Method untuk mengelola relasi many-to-many: `attach()` menambah relasi, `detach()` menghapus relasi, `sync()` menyelaraskan relasi (tambah/hapus sesuai array).

## Analogi
- `attach`: Seperti menambahkan item ke keranjang belanja
- `detach`: Seperti mengeluarkan item dari keranjang
- `sync`: Seperti mengganti isi keranjang dengan daftar baru — yang tidak ada di daftar baru akan dihapus

## Poin-Poin Penting
- Bekerja pada tabel pivot many-to-many
- `attach($id, [pivotData])` — INSERT ke pivot
- `detach($id)` — DELETE dari pivot
- `sync([1, 2, 3])` — sinkronisasi: hapus yang tidak di array
- `syncWithoutDetaching([1, 2])` — sync tapi jangan hapus yang sudah ada
- `toggle([1, 2])` — jika sudah ada, hapus; jika belum, tambah

## Contoh Kode
```php
use App\Models\User;
use App\Models\Role;
use App\Models\Post;

// ATTACH — tambah relasi
$user = User::find(1);
$user->roles()->attach(1);  // user mendapat role id=1
$user->roles()->attach([2, 3]);  // user mendapat role 2 dan 3

// Attach dengan data pivot
$user->roles()->attach(1, [
    'assigned_by' => 'admin',
    'expires_at' => now()->addYear(),
]);

// DETACH — hapus relasi
$user->roles()->detach(1);  // hapus role id=1 dari user
$user->roles()->detach();   // hapus SEMUA role dari user

// SYNC — sinkronisasi (ganti semua)
// Anggap user punya role [1, 2, 3]
$user->roles()->sync([1, 4, 5]);
// Hasil: role [1, 4, 5] — role 2 dan 3 dihapus

// Sync dengan data pivot
$user->roles()->sync([
    1 => ['assigned_by' => 'admin'],
    4 => ['assigned_by' => 'system'],
]);

// syncWithoutDetaching — hanya tambah, jangan hapus
$user->roles()->syncWithoutDetaching([5, 6]);

// TOGGLE — seperti saklar: on/off
$user->roles()->toggle(1);
// Jika role 1 sudah ada → dihapus
// Jika role 1 belum ada → ditambah

// Contoh di controller
public function assignRoles(Request $request, User $user)
{
    $validated = $request->validate([
        'roles' => 'required|array',
        'roles.*' => 'exists:roles,id',
    ]);

    $user->roles()->sync($validated['roles']);

    return back()->with('success', 'Roles updated');
}
```

## Kasus Penggunaan Nyata
- Assign/unassign role ke user
- Pilih tag untuk artikel (sync)
- Tambah/hapus produk dari wishlist (toggle)
- Update permission group (sync with pivot data)
- Follow/unfollow user (toggle)
