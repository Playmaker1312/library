# 176. belongsToMany Banyak Ke Banyak

## Definisi Singkat
`belongsToMany()` mendefinisikan relasi banyak-ke-banyak (many-to-many) — satu record bisa terkait dengan banyak record di tabel lain, dan sebaliknya.

## Analogi
Seperti hubungan mahasiswa dan mata kuliah — 1 mahasiswa bisa ambil banyak mata kuliah, 1 mata kuliah bisa diambil banyak mahasiswa. Butuh tabel pivot.

## Poin-Poin Penting
- Membutuhkan tabel pivot (tabel perantara)
- Default nama pivot: gabungan nama tabel diurutkan alphabet (contoh: `post_tag`, `role_user`)
- Default pivot FK: `model_id` (contoh: `role_id`, `user_id`)
- `belongsToMany` di BOTH model

## Contoh Kode
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsToMany;

class User extends Model
{
    // User memiliki banyak role
    public function roles(): BelongsToMany
    {
        return $this->belongsToMany(Role::class);
        // Tabel pivot: role_user
        // Pivot FK: user_id, role_id
    }
}

class Role extends Model
{
    // Role dimiliki banyak user
    public function users(): BelongsToMany
    {
        return $this->belongsToMany(User::class);
    }
}

// Migration pivot table
Schema::create('role_user', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained()->cascadeOnDelete();
    $table->foreignId('role_id')->constrained()->cascadeOnDelete();
    $table->timestamps();  // optional
});

// Penggunaan
$user = User::find(1);
$roles = $user->roles;  // Collection of Role models

// Cek apakah user punya role tertentu
if ($user->roles->contains('name', 'admin')) {
    echo 'User adalah admin';
}

// Attach role ke user
$user->roles()->attach(1);              // tambah role id=1
$user->roles()->attach([1, 2, 3]);      // tambah banyak

// Sync roles (ganti semua)
$user->roles()->sync([1, 2]);  // hanya role 1 dan 2 yang aktif

// Dengan custom pivot table name
public function tags(): BelongsToMany
{
    return $this->belongsToMany(Tag::class, 'product_tag')
                ->withTimestamps();
}
```

## Kasus Penggunaan Nyata
- User ↔ Role (RBAC — Role Based Access Control)
- Product ↔ Tag (produk punya banyak tag, tag dipakai banyak produk)
- Student ↔ Course (siswa ambil banyak kursus)
- Post ↔ Category (post bisa masuk banyak kategori)
- Doctor ↔ Patient (dokter tangani banyak pasien, pasien ke banyak dokter)
