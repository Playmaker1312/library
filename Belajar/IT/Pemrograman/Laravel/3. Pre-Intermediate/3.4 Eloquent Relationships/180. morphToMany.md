# 180. morphToMany

## Definisi Singkat
`morphToMany()` adalah relasi polymorphic many-to-many — satu model bisa memiliki banyak tag melalui pivot, dan tag bisa dimiliki banyak model yang berbeda tipe.

## Analogi
Seperti tagar (#) di media sosial — tag #laravel bisa dipasang ke postingan teks, video, ATAU gambar (berbeda tipe). 1 tag bisa dipakai banyak konten, 1 konten bisa punya banyak tag.

## Poin-Poin Penting
- Butuh tabel pivot dengan `taggable_id`, `taggable_type`
- `morphToMany()` di model sumber (Post, Video)
- `morphedByMany()` di model tag (untuk inverse)
- Convention: `taggable_id`, `taggable_type`
- `morphs()` di migration untuk create kedua kolom

## Contoh Kode
```php
// Migration pivot: taggables
Schema::create('taggables', function (Blueprint $table) {
    $table->id();
    $table->foreignId('tag_id')->constrained()->cascadeOnDelete();
    $table->morphs('taggable');  // taggable_id + taggable_type
    $table->timestamps();
});

// Model Post — punya banyak tag
class Post extends Model
{
    public function tags(): MorphToMany
    {
        return $this->morphToMany(Tag::class, 'taggable');
    }
}

// Model Video — juga punya banyak tag
class Video extends Model
{
    public function tags(): MorphToMany
    {
        return $this->morphToMany(Tag::class, 'taggable');
    }
}

// Model Tag — bisa dimiliki banyak post dan video
class Tag extends Model
{
    // posts() — tag dimiliki banyak post (inverse morph)
    public function posts(): MorphToMany
    {
        return $this->morphedByMany(Post::class, 'taggable');
    }

    // videos() — tag dimiliki banyak video
    public function videos(): MorphToMany
    {
        return $this->morphedByMany(Video::class, 'taggable');
    }
}

// Penggunaan
$post = Post::find(1);
$tags = $post->tags;  // Collection of Tag

// Attach tag ke post
$post->tags()->attach(1);

// Sama seperti belongsToMany biasa
$post->tags()->sync([1, 2, 3]);

// Dari sisi tag
$tag = Tag::find(1);
$posts = $tag->posts;   // Post yang pakai tag ini
$videos = $tag->videos; // Video yang pakai tag ini

// Eager loading polymorphic
$posts = Post::with('tags')->get();
```

## Kasus Penggunaan Nyata
- Tag untuk Post, Video, Product
- Kategori untuk berbagai tipe konten
- Label/flag untuk berbagai entitas
- Metadata terstruktur untuk model berbeda
