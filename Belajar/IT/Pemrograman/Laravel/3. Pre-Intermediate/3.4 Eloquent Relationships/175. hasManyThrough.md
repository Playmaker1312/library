# 175. hasManyThrough

## Definisi Singkat
`hasManyThrough()` mengakses relasi "jarak jauh" — mendapatkan record dari tabel lain melalui tabel perantara (intermediary table).

## Analogi
Seperti "Youtuber yang tinggal di suatu Kota" — bisa dapat semua subscriber dari kota itu. Country → (via User) → Post. Semua post dari user yang tinggal di suatu negara.

## Poin-Poin Penting
- Melewati satu tabel perantara
- Contoh: Country → User → Post (dapatkan semua post di suatu negara)
- Parameter: `hasManyThrough(ModelTujuan, ModelPerantara, FK_perantara, FK_tujuan)`
- Tidak butuh foreign key langsung antara kedua tabel

## Contoh Kode
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\HasManyThrough;

class Country extends Model
{
    // Dapatkan semua post dari user yang tinggal di negara ini
    // Melalui: countries → users → posts
    public function posts(): HasManyThrough
    {
        return $this->hasManyThrough(
            Post::class,       // Model tujuan (posts)
            User::class,       // Model perantara (users)
            'country_id',      // FK di tabel users (user punya country_id)
            'user_id',         // FK di tabel posts (post punya user_id)
            'id',              // Local key di tabel countries
            'id'               // Local key di tabel users
        );
    }
}

// Struktur tabel:
// countries: id, name
// users: id, country_id, name
// posts: id, user_id, title, body

// Penggunaan
$country = Country::find(1);

// Semua post dari user yang tinggal di Indonesia
$posts = $country->posts;

foreach ($posts as $post) {
    echo $post->title;
}

// Dengan eager loading
$countries = Country::with('posts')->get();

// Contoh lain: Project → Environment → Deployment
// Dapatkan semua deployment dari semua environment di suatu project
class Project extends Model
{
    public function deployments(): HasManyThrough
    {
        return $this->hasManyThrough(
            Deployment::class,
            Environment::class,
            'project_id',     // FK di environments
            'environment_id', // FK di deployments
            'id',             // Local key di projects
            'id'              // Local key di environments
        );
    }
}
```

## Kasus Penggunaan Nyata
- Semua post di suatu kategori melalui user (jika post tidak langsung ke kategori)
- Semua pesanan di suatu wilayah (Region → Store → Order)
- Semua deployment di suatu project (Project → Environment → Deployment)
- Semua komentar di course (Course → Lesson → Comment)
