# 183. Constrained Eager Loading

## Definisi Singkat
Constrained eager loading memungkinkan menambahkan kondisi (constraint) pada relasi saat eager loading — misalnya hanya memuat post yang dipublikasi.

## Analogi
Seperti menyaring buku di rak: "Ambil semua penulis, tapi hanya muat buku mereka yang terbit tahun ini" — bukan semua buku yang pernah mereka tulis.

## Poin-Poin Penting
- `with(['relasi' => fn($query) => $query->where(...)])`
- Bisa filter, sorting, limit relasi yang dimuat
- Hanya memengaruhi data yang di-load, bukan query utama
- Berguna untuk membatasi data berdasarkan kondisi
- Tetap mencegah N+1 karena masih 2 query

## Contoh Kode
```php
use App\Models\User;
use App\Models\Post;

// Constraint — hanya muat post yang dipublikasi
$users = User::with(['posts' => function ($query) {
    $query->where('is_published', true)
          ->orderBy('published_at', 'desc');
}])->get();

// Limit relasi — ambil 3 post terbaru per user
$users = User::with(['posts' => function ($query) {
    $query->latest()->limit(3);
}])->get();

// Filter dengan whereIn
$users = User::with(['posts' => function ($query) {
    $query->whereIn('category_id', [1, 3, 5])
          ->where('is_published', true);
}])->get();

// Dengan withCount
$users = User::withCount(['posts' => function ($query) {
    $query->where('is_published', true);
}])->get();
// posts_count hanya hitung post yang dipublikasi

// Multiple constrained
$users = User::with([
    'posts' => fn($q) => $q->where('is_published', true),
    'comments' => fn($q) => $q->where('is_approved', true),
    'profile',
])->get();

// Nested constrained
$users = User::with(['posts' => function ($query) {
    $query->with(['comments' => function ($q) {
        $q->where('is_approved', true)
          ->with('user.profile');
    }]);
}])->get();
```

## Kasus Penggunaan Nyata
- Profil user: hanya tampilkan post yang dipublikasi
- Produk: hanya muat review dengan rating > 3
- Order: hanya muat item yang masih tersedia
- Dashboard: hanya muat transaksi bulan ini
- API: filter relasi berdasarkan parameter
