# 177. Pivot Table

## Definisi Singkat
Pivot table adalah tabel perantara yang menyimpan relasi many-to-many antara dua tabel. Berisi foreign key dari kedua tabel dan bisa menyimpan data tambahan.

## Analogi
Seperti buku catatan absensi kehadiran di kelas — mencatat siapa (student_id) hadir di kelas apa (course_id), kapan, dan statusnya. Ini adalah pivot.

## Poin-Poin Penting
- Nama pivot biasanya: `singular_singular` (alphabetical order)
  - `role_user` (bukan user_role) — 'r' sebelum 'u'
  - `post_tag` (bukan tag_post) — 'p' sebelum 't'
- Tidak perlu model sendiri (kecuali ada data tambahan yang kompleks)
- Eloquent mengakses pivot via `$model->pivot`
- Bisa ditambahi timestamps: `withTimestamps()`
- Bisa ditambahi kolom sendiri: `withPivot('kolom')`

## Contoh Kode
```php
// Migration pivot table (default: role_user)
Schema::create('role_user', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained()->cascadeOnDelete();
    $table->foreignId('role_id')->constrained()->cascadeOnDelete();

    // Data tambahan di pivot
    $table->string('assigned_by')->nullable();  // siapa yang assign
    $table->timestamp('expires_at')->nullable(); // kapan expired

    $table->timestamps();  // created_at, updated_at
});

// Model — definisi relasi
class User extends Model
{
    public function roles(): BelongsToMany
    {
        return $this->belongsToMany(Role::class)
                    ->withPivot(['assigned_by', 'expires_at'])
                    ->withTimestamps();
    }
}

// Penggunaan pivot
$user = User::find(1);
$role = $user->roles->first();

// Akses data pivot
echo $role->pivot->assigned_by;   // siapa yang assign
echo $role->pivot->expires_at;    // kapan expired
echo $role->pivot->created_at;    // timestamps pivot

// Filter berdasarkan pivot

// Sync dengan data pivot

    1 => ['assigned_by' => 'admin', 'expires_at' => now()->addYear()],

]);
```

## Kasus Penggunaan Nyata
- Role assignment: siapa yang assign dan kapan expired
- Enrolment kursus: tanggal daftar, progres, nilai
- Order produk: quantity, price di waktu pembelian
- Like/favorite: kapan di-like
- Membership: tipe member, start date, end date
