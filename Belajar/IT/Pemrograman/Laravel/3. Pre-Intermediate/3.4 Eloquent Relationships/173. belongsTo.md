# 173. belongsTo

## Definisi Singkat
`belongsTo()` adalah kebalikan dari `hasOne()` atau `hasMany()` — mendefinisikan bahwa model ini "milik" model lain (memiliki foreign key).

## Analogi
Setiap buku memiliki satu pemilik — buku "milik" (belongs to) user. Profile belongs to User, Post belongs to User.

## Poin-Poin Penting
- Foreign key BERADA di tabel model ini
- Default foreign key: `relasi_id` (contoh: `user_id`)
- Default local key: `id`
- `$model->relasi` mengembalikan model induk
- Sering dipasangkan dengan `hasMany()` (inverse)

## Contoh Kode
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;

class Post extends Model
{
    // Post milik (belongs to) User
    // Tabel posts punya foreign key: user_id
    public function user(): BelongsTo
    {
        return $this->belongsTo(User::class);
        // belongsTo(User::class, 'user_id', 'id');
        // Parameter: model induk, foreign key di tabel posts, owner key di tabel users
    }
}

class Profile extends Model
{
    // Profile milik User
    public function user(): BelongsTo
    {
        return $this->belongsTo(User::class);
    }
}

// Migration untuk tabel posts
Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained()->cascadeOnDelete();
    $table->string('title');
    $table->text('body');
    $table->timestamps();
});

// Penggunaan
$post = Post::find(1);
$author = $post->user;  // User model
echo $author->name;

// Eager loading
$posts = Post::with('user')->get();
foreach ($posts as $post) {
    echo $post->title . ' by ' . $post->user->name;
}

// Custom foreign key
public function author(): BelongsTo
{
    return $this->belongsTo(User::class, 'author_id');
}
```

## Kasus Penggunaan Nyata
- Post → User (penulis artikel)
- Product → Category (produk milik kategori)
- Order → Customer (pesanan milik pelanggan)
- Comment → Post (komentar pada artikel)
- Transaction → User (transaksi milik pengguna)
