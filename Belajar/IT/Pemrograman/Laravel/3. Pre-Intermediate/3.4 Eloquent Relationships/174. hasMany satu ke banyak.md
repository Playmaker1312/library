# 174. hasMany Satu Ke Banyak

## Definisi Singkat
`hasMany()` mendefinisikan relasi satu-ke-banyak (one-to-many) — satu record di tabel ini bisa memiliki banyak record di tabel lain.

## Analogi
Seorang ibu bisa memiliki beberapa anak — 1 User bisa menulis banyak Post. Satu Kategori bisa memiliki banyak Produk.

## Poin-Poin Penting
- Foreign key berada di tabel relasi (tabel anak)
- Default foreign key: `model_id` (contoh: `user_id`)
- HasMany mengembalikan `Collection` (bisa 0, 1, atau banyak)
- Inverse: gunakan `belongsTo()` di model anak

## Contoh Kode
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\HasMany;

class User extends Model
{
    // User memiliki banyak post
    public function posts(): HasMany
    {
        return $this->hasMany(Post::class);
        // hasMany(Post::class, 'user_id', 'id');
    }

    // User memiliki banyak komentar
    public function comments(): HasMany
    {
        return $this->hasMany(Comment::class);
    }
}

// Migration untuk tabel posts
Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained()->cascadeOnDelete();
    $table->string('title');
    $table->timestamps();
});

// Penggunaan
$user = User::find(1);

// Ambil semua post user
$posts = $user->posts;  // Collection

// Hitung jumlah post
$count = $user->posts()->count();

// Buat post baru untuk user
$user->posts()->create([
    'title' => 'Post Baru',
]);

// Filter relasi
$recentPosts = $user->posts()
                     ->where('is_published', true)
                     ->latest()
                     ->get();

// Eager loading
$users = User::with('posts')->get();
foreach ($users as $user) {
    echo $user->name . ': ' . $user->posts->count() . ' posts';
}
```

## Kasus Penggunaan Nyata
- User → Posts (artikel yang ditulis user)
- Category → Products (produk dalam kategori)
- Course → Lessons (pelajaran dalam kursus)
- Order → OrderItems (item dalam pesanan)
- Playlist → Videos (video dalam playlist)
