# 181. with Eager Loading Hindari N+1

## Definisi Singkat
Eager loading (`with()`) mencegah masalah N+1 query — yaitu saat query dieksekusi dalam loop (N kali) setelah query awal (1 query), total menjadi 1+N query.

## Analogi
Seperti pergi ke supermarket: Tanpa eager loading, Anda pulang-pergi 100x untuk 100 barang (N+1). Dengan eager loading, Anda bawa daftar belanja dan ambil semua dalam 1 trip.

## Poin-Poin Penting
- N+1 terjadi saat akses relasi dalam loop tanpa eager loading
- `with('relasi')` mengambil semua data relasi dalam 2 query
- Debug N+1: install Laravel Debugbar atau `DB::enableQueryLog()`
- `with()` bisa di-chain: `with(['posts', 'posts.comments'])`
- Pakai `load()` untuk lazy eager loading (setelah query utama)

## Contoh Kode
```php
use App\Models\User;
use App\Models\Post;
use Illuminate\Support\Facades\DB;

// ❌ TANPA EAGER LOADING — N+1 Problem!
// Query: 1 (users) + N (posts per user)
$users = User::all();
foreach ($users as $user) {
    echo $user->posts->count();  // query di setiap iterasi!
}
// Jika 100 user → 1 + 100 = 101 query!

// ✅ DENGAN EAGER LOADING — Hanya 2 query!
$users = User::with('posts')->get();
foreach ($users as $user) {
    echo $user->posts->count();  // data sudah di-cache
}

// Contoh N+1 di view (Blade)
// ❌ Jangan:
// @foreach($users as $user)
//     <p>{{ $user->posts->count() }}</p>  // N+1!
// @endforeach

// ✅ Benar:
// Controller: $users = User::with('posts')->get();
// @foreach($users as $user)
//     <p>{{ $user->posts->count() }}</p>  // aman
// @endforeach

// Debug N+1 dengan query log
DB::enableQueryLog();
$users = User::get();
foreach ($users as $user) {
    echo $user->posts->count();
}
dump(DB::getQueryLog());  // lihat jumlah query!

// Nested eager loading
$users = User::with('posts.comments.author')->get();
// Query: 1 (users) + 1 (posts) + 1 (comments) + 1 (author) = 4 total

// Default eager loading di model (selalu dimuat)
class User extends Model
{
    protected $with = ['profile'];  // selalu eager load profile

    public function profile()
    {
        return $this->hasOne(Profile::class);
    }
}
```

## Kasus Penggunaan Nyata
- Daftar artikel dengan nama penulis
- Katalog produk dengan kategori
- List order dengan item dan produk
- Profil dengan post dan komentar
- SELALU gunakan eager loading saat looping relasi
