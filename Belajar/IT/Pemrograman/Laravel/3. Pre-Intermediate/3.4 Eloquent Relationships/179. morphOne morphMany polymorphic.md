# 179. morphOne morphMany Polymorphic

## Definisi Singkat
Polymorphic relasi memungkinkan satu model terkait dengan beberapa tipe model lain dalam satu relasi. `morphOne()` untuk one-to-one, `morphMany()` untuk one-to-many.

## Analogi
Seperti fitur "Like" di media sosial — Anda bisa like foto, video, ATAU komentar. Satu tabel `likes` melayani semua tipe konten dengan kolom `likeable_id` dan `likeable_type`.

## Poin-Poin Penting
- Tabel polymorphic punya 2 kolom: `xxx_id` (integer) dan `xxx_type` (string)
- `xxx_type` menyimpan class model (contoh: `App\Models\Post`)
- `morphMany()` di model sumber (Post, Video)
- `morphTo()` di model polymorphic (Comment, Like, Image)
- Convention: `commentable_id`, `commentable_type`

## Contoh Kode
```php
// Migration untuk tabel comments (polymorphic)
Schema::create('comments', function (Blueprint $table) {
    $table->id();
    $table->text('body');
    $table->morphs('commentable');  // commentable_id + commentable_type
    $table->foreignId('user_id')->constrained();
    $table->timestamps();
});

// Model Post — bisa punya komentar
class Post extends Model
{
    public function comments(): MorphMany
    {
        return $this->morphMany(Comment::class, 'commentable');
    }
}

// Model Video — juga bisa punya komentar
class Video extends Model
{
    public function comments(): MorphMany
    {
        return $this->morphMany(Comment::class, 'commentable');
    }
}

// Model Comment — polymorphic, belongs ke berbagai model
class Comment extends Model
{
    // Mengembalikan model yang memiliki komentar ini (Post/Video)
    public function commentable(): MorphTo
    {
        return $this->morphTo();
    }
}

// Penggunaan
$post = Post::find(1);
$comments = $post->comments;  // Collection of Comment

$video = Video::find(1);
$videoComments = $video->comments;

// Dari sisi comment — dapatkan parent
$comment = Comment::find(1);
$parent = $comment->commentable;  // instance Post atau Video

// morphOne — untuk relasi one-to-one polymorphic
// Contoh: gambar profil untuk user dan admin
class Image extends Model
{
    public function imageable(): MorphTo
    {
        return $this->morphTo();
    }
}

class User extends Model
{
    public function image(): MorphOne
    {
        return $this->morphOne(Image::class, 'imageable');
    }
}
```

## Kasus Penggunaan Nyata
- Komentar untuk Post, Video, Product (morphMany)
- Like/favorite untuk berbagai tipe konten (morphMany)
- Gambar untuk User, Product, Category (morphOne/morphMany)
- Tag untuk Post dan Video (morphToMany)
- Laporan/abuse report untuk berbagai tipe konten
