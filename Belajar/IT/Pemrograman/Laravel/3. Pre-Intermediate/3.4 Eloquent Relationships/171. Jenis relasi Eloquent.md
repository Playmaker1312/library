# 171. Jenis Relasi Eloquent

## Definisi Singkat
Eloquent mendukung berbagai jenis relasi database: one-to-one, one-to-many, many-to-many, dan polymorphic — semuanya didefinisikan sebagai method di model.

## Analogi
Seperti hubungan sosial:
- One-to-one: Setiap orang punya 1 KTP (User → Profile)
- One-to-many: 1 Ibu punya banyak anak (User → Posts)
- Many-to-many: Mahasiswa bisa ambil banyak mata kuliah, 1 mata kuliah diambil banyak mahasiswa
- Polymorphic: Like bisa untuk foto ATAU video ATAU komentar

## Poin-Poin Penting
| Relasi | Method | Contoh |
|--------|--------|--------|
| One-to-one | `hasOne()` | User → Profile |
| Inverse one-to-one | `belongsTo()` | Profile → User |
| One-to-many | `hasMany()` | User → Posts |
| Inverse one-to-many | `belongsTo()` | Post → User |
| Has-many-through | `hasManyThrough()` | Country → Posts via User |
| Many-to-many | `belongsToMany()` | User → Roles |
| Polymorphic one-to-one | `morphOne()` | User → Image |
| Polymorphic one-to-many | `morphMany()` | Post → Comments, Video → Comments |
| Polymorphic many-to-many | `morphToMany()` | Post → Tags, Video → Tags |

## Contoh Kode
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\HasMany;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Database\Eloquent\Relations\BelongsToMany;

class User extends Model
{
    // One-to-one
    public function profile(): HasOne
    {
        return $this->hasOne(Profile::class);
    }

    // One-to-many
    public function posts(): HasMany
    {
        return $this->hasMany(Post::class);
    }

    // Many-to-many
    public function roles(): BelongsToMany
    {
        return $this->belongsToMany(Role::class);
    }
}

class Post extends Model
{
    // Inverse one-to-many
    public function user(): BelongsTo
    {
        return $this->belongsTo(User::class);
    }

    // Polymorphic one-to-many
    public function comments(): MorphMany
    {
        return $this->morphMany(Comment::class, 'commentable');
    }
}
```

## Kasus Penggunaan Nyata
- Profil pengguna — one-to-one
- Artikel dengan komentar — one-to-many
- Tag untuk artikel dan video — polymorphic many-to-many
- Role permission — many-to-many
- Like system untuk berbagai tipe konten — polymorphic
