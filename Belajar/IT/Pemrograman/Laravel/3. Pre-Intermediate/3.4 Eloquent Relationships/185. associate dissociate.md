# 185. associate dissociate

## Definisi Singkat
`associate()` dan `dissociate()` digunakan untuk mengelola relasi `belongsTo()` — menetapkan atau menghapus induk dari model anak.

## Analogi
- `associate`: Seperti menetapkan "siapa pemilik barang ini" — mengisi kolom foreign key
- `dissociate`: Seperti menghapus kepemilikan — mengosongkan kolom foreign key

## Poin-Poin Penting
- `associate($model)` — set foreign key, TIDAK auto-save
- `dissociate()` — set foreign key ke null, TIDAK auto-save
- Harus panggil `save()` setelah associate/dissociate
- Berlaku untuk belongsTo (inverse dari hasOne/hasMany)
- Beda dengan attach/detach yang untuk many-to-many (pivot)

## Contoh Kode
```php
use App\Models\Post;
use App\Models\User;
use App\Models\Category;

// associate — tetapkan induk
$post = Post::find(1);
$user = User::find(1);

// Set post.user_id = 1
$post->user()->associate($user);
$post->save();  // WAJIB save!

// alternatif: langsung assign lalu save
$post->user_id = $user->id;
$post->save();

// dissociate — hapus induk (set user_id ke null)
$post = Post::find(1);
$post->user()->dissociate();
$post->save();  // user_id jadi null

// Contoh di controller
public function assignAuthor(Request $request, Post $post)
{
    $user = User::findOrFail($request->user_id);

    $post->user()->associate($user);
    $post->save();

    return back()->with('success', 'Penulis ditetapkan');
}

public function removeAuthor(Post $post)
{
    $post->user()->dissociate();
    $post->save();

    return back()->with('success', 'Penulis dihapus');
}

// Beda dengan attach/detach:
// - associate/dissociate: untuk belongsTo (1 FK di tabel sendiri)
// - attach/detach: untuk belongsToMany (tabel pivot)

// Contoh lain: Category → Post
$post = Post::find(1);
$category = Category::find(1);

$post->category()->associate($category);  // set category_id
$post->save();
```

## Kasus Penggunaan Nyata
- Assign penulis ke artikel (Post → User)
- Pindahkan produk ke kategori lain
- Hapus kategori dari produk (set null)
- Assign teknisi ke tiket support
- Ubah supervisor/manager dari karyawan
