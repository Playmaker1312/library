# 182. Lazy Eager Loading load()

## Definisi Singkat
`load()` adalah lazy eager loading — memuat relasi setelah model atau collection sudah diambil, berguna saat relasi dibutuhkan hanya dalam kondisi tertentu.

## Analogi
Seperti memutuskan untuk membeli sesuatu setelah sampai di toko — Anda tidak membawa daftar dari rumah (with), tapi memutuskan setelah melihat situasi (load).

## Poin-Poin Penting
- `$model->load('relasi')` — muat relasi setelah model di-query
- `$models->load('relasi')` — muat relasi untuk collection
- `loadCount('relasi')` — lazy load count
- `loadMissing('relasi')` — muat hanya jika belum dimuat
- Berguna untuk conditional loading (hanya muat jika kondisi terpenuhi)

## Contoh Kode
```php
use App\Models\User;
use App\Models\Post;

// load() — lazy eager loading pada model tunggal
$user = User::find(1);
// ... beberapa logic ...
if ($user->isAdmin()) {
    $user->load('roles.permissions');  // muat relasi hanya untuk admin
}

// load() pada collection
$users = User::all();
// ... beberapa logic ...
if (request()->has('with_posts')) {
    $users->load('posts');
}

// loadCount — lazy load jumlah
$user = User::find(1);
echo $user->posts_count;  // null (belum dimuat)
$user->loadCount('posts');
echo $user->posts_count;  // sudah terisi

// loadMissing — muat hanya jika belum
$user = User::with('profile')->find(1);  // profile sudah dimuat
$user->loadMissing('posts');  // muat posts, profile tidak dimuat ulang
$user->loadMissing('profile');  // diabaikan — sudah dimuat

// Conditional loading di controller
public function show($id)
{
    $user = User::findOrFail($id);

    if (auth()->user()->isAdmin()) {
        // Admin lihat data sensitif
        $user->load(['posts', 'loginLogs', 'paymentHistory']);
    } else {
        // User biasa lihat data dasar
        $user->load('profile');
    }

    return view('users.show', compact('user'));
}

// load dengan constraints
$user->load(['posts' => function ($query) {
    $query->where('is_published', true)
          ->orderBy('created_at', 'desc');
}]);
```

## Kasus Penggunaan Nyata
- Conditional loading berdasarkan role pengguna
- "Load more" — hanya muat relasi saat tombol diklik
- Performance optimization — jangan muat relasi yang tidak perlu
- API response: sertakan relasi hanya jika query param `?with=posts`
