# 172. hasOne Satu Ke Satu

## Definisi Singkat
`hasOne()` mendefinisikan relasi satu-ke-satu (one-to-one) — satu record di tabel ini berhubungan dengan satu record di tabel lain.

## Analogi
Setiap warga negara Indonesia memiliki satu NIK (Nomor Induk Kependudukan). 1 User → 1 Profile.

## Poin-Poin Penting
- Foreign key berada di tabel relasi (bukan tabel model)
- Default foreign key: `model_id` (contoh: `user_id`)
- Default local key: `id`
- `$model->relasi` mengembalikan model instance atau null
- Inverse: gunakan `belongsTo()`

## Contoh Kode
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\HasOne;
use Illuminate\Database\Eloquent\Relations\BelongsTo;

class User extends Model
{
    // User memiliki satu profile
    // Profile punya foreign key 'user_id'
    public function profile(): HasOne
    {
        return $this->hasOne(Profile::class);
        // hasOne(Profile::class, 'user_id', 'id');
        // Parameter: model relasi, foreign key di tabel profile, local key di tabel user
    }
}

// Migration untuk tabel profiles
Schema::create('profiles', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained()->cascadeOnDelete();
    $table->string('bio')->nullable();
    $table->string('avatar')->nullable();
    $table->timestamps();
});

// Penggunaan
$user = User::find(1);
$profile = $user->profile;  // Profile model atau null
echo $profile->bio;

// Eager loading
$users = User::with('profile')->get();
foreach ($users as $user) {
    echo $user->profile->bio;
}

// Create relasi
$user = User::find(1);
$user->profile()->create([
    'bio' => 'Web Developer',
    'avatar' => 'avatar.jpg',
]);
```

## Kasus Penggunaan Nyata
- User → Profile/bio
- User → Settings (preferensi pengguna)
- Order → Invoice (satu order satu invoice)
- Product → ProductDetail (spesifikasi tambahan)
