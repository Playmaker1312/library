# 178. withPivot

## Definisi Singkat
`withPivot('kolom1', 'kolom2')` menentukan kolom tambahan dari tabel pivot yang ingin disertakan saat mengambil data relasi many-to-many.

## Analogi
Seperti memilih informasi tambahan yang dicatat di buku absen — bukan hanya "siapa dan kelas apa", tapi juga "tanggal, jam masuk, dan status".

## Poin-Poin Penting
- Secara default, Eloquent hanya menyertakan foreign key di pivot
- `withPivot()` untuk menambah kolom lain ke objek pivot
- `withTimestamps()` shorthand untuk created_at + updated_at
- Kolom harus ada di tabel pivot
- Pivot diakses via `$model->pivot->nama_kolom`

## Contoh Kode
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsToMany;

class User extends Model
{
    public function roles(): BelongsToMany
    {
        return $this->belongsToMany(Role::class)
                    // Sertakan kolom tambahan dari pivot
                    ->withPivot([
                        'assigned_by',
                        'expires_at',
                        'is_active',
                    ])
                    // Sertakan timestamps pivot
                    ->withTimestamps();
    }
}

class Product extends Model
{
    public function orders(): BelongsToMany
    {
        return $this->belongsToMany(Order::class)
                    ->withPivot([
                        'quantity',
                        'price',         // harga saat pembelian
                        'subtotal',
                    ])
                    ->withTimestamps();
    }
}

// Penggunaan
$user = User::with('roles')->find(1);

foreach ($user->roles as $role) {
    echo 'Role: ' . $role->name;
    echo 'Assigned by: ' . $role->pivot->assigned_by;
    echo 'Expires: ' . $role->pivot->expires_at;
    echo 'Assigned at: ' . $role->pivot->created_at;
}

// Filter berdasarkan pivot column
$activeRoles = $user->roles()
                    ->wherePivot('is_active', true)
                    ->get();

// wherePivotIn
$specificRoles = $user->roles()
                      ->wherePivotIn('assigned_by', ['admin', 'superadmin'])
                      ->get();
```

## Kasus Penggunaan Nyata
- Data cart: quantity, price per produk di order
- Enrollment: enrolled_at, progress_percent, grade
- Membership: start_date, end_date, plan_type
- Survey jawaban: jawaban, score, waktu_mulai
- Inventory: quantity, location, batch_number
