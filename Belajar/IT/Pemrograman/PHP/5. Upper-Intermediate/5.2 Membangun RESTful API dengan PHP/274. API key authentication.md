# 274. API Key Authentication

## Definisi Singkat
API Key adalah token unik yang diberikan ke klien untuk mengakses API. Key dikirim via header `X-API-Key` atau query parameter. Ini adalah metode autentikasi sederhana untuk machine-to-machine communication.

## Analogi
Seperti kunci kamar hotel: Anda mendapat kunci unik saat check-in. Kunci yang sama digunakan setiap kali ingin masuk kamar. Jika kunci hilang/reset, kunci lama tidak berlaku.

## Poin-Poin Penting
- API key dikirim di header atau query string
- Validasi key di database atau file konfigurasi
- Jangan gunakan API key untuk user-based auth (gunakan JWT)
- Simpan key dengan hash di database
- Rotasi key secara berkala untuk keamanan
- Batasi scope/izin per key (read-only, full access)

## Contoh Kode (PHP)
```php
<?php
header('Content-Type: application/json; charset=utf-8');

// Database API keys (simulasi)
$validApiKeys = [
    'abc123def456' => ['client' => 'Aplikasi Mobile', 'scope' => 'read'],
    'xyz789uvw012' => ['client' => 'Web App', 'scope' => 'read_write'],
];

function authenticate(): array
{
    $headers = getallheaders();
    $apiKey = $headers['X-API-Key'] ?? $_GET['api_key'] ?? '';

    global $validApiKeys;

    if (empty($apiKey) || !isset($validApiKeys[$apiKey])) {
        http_response_code(401);
        echo json_encode(['error' => 'API Key tidak valid']);
        exit;
    }

    return $validApiKeys[$apiKey];
}

// Middleware autentikasi
$clientInfo = authenticate();

// Cek scope untuk operasi tertentu
function checkScope(string $required): void
{
    global $clientInfo;
    if ($clientInfo['scope'] !== 'read_write' && $required === 'write') {
        http_response_code(403);
        echo json_encode(['error' => 'API Key tidak memiliki izin']);
        exit;
    }
}

// Contoh endpoint
$method = $_SERVER['REQUEST_METHOD'];
if ($method === 'POST') {
    checkScope('write');
}

echo json_encode([
    'message' => 'Terautentikasi',
    'client' => $clientInfo['client']
]);
?>
```

## Kasus Penggunaan Nyata
Autentikasi untuk public API (cuaca, maps), service-to-service communication, SDK/third-party integration.
