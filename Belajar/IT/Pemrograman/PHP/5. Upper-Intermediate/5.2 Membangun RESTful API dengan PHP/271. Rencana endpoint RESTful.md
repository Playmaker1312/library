# 271. Rencana Endpoint RESTful

## Definisi Singkat
Rencana endpoint RESTful adalah blueprint yang mendefinisikan semua URL, HTTP methods, parameter, dan response dari API. Dokumentasi ini menjadi panduan sebelum coding dan referensi untuk tim.

## Analogi
Seperti arsitektur bangunan: sebelum membangun rumah, Anda perlu denah lengkap yang menunjukkan di mana setiap ruangan (endpoint), pintu (methods), dan jendela (parameters) berada.

## Poin-Poin Penting
- Tentukan resource utama (users, products, orders)
- Mapping HTTP methods ke operasi CRUD
- Tentukan parameter query untuk filter, pagination
- Tentukan format response (sukses dan error)
- Tentukan struktur request body
- Gunakan konsistensi penamaan (plural, lowercase)
- Gunakan nesting untuk relasi (`/users/1/orders`)

## Contoh Kode (PHP)
```php
<?php
// Contoh rencana endpoint dalam array PHP
$endpoints = [
    [
        'method' => 'GET',
        'path' => '/api/users',
        'description' => 'Daftar semua pengguna',
        'params' => ['page', 'limit', 'search', 'sort'],
        'response' => [
            'status' => 'success',
            'data' => [
                ['id' => 1, 'nama' => 'John', 'email' => 'john@test.com']
            ],
            'pagination' => [
                'page' => 1,
                'totalPages' => 5,
                'totalItems' => 50
            ]
        ]
    ],
    [
        'method' => 'GET',
        'path' => '/api/users/{id}',
        'description' => 'Detail pengguna',
        'response' => [
            'status' => 'success',
            'data' => [
                'id' => 1,
                'nama' => 'John',
                'email' => 'john@test.com',
                'created_at' => '2024-01-01'
            ]
        ]
    ],
    [
        'method' => 'POST',
        'path' => '/api/users',
        'description' => 'Buat pengguna baru',
        'body' => [
            'nama' => 'required|string|max:100',
            'email' => 'required|email|unique',
            'password' => 'required|min:8'
        ],
        'response' => [
            'status' => 'success',
            'message' => 'User berhasil dibuat',
            'data' => ['id' => 2]
        ]
    ],
    [
        'method' => 'PUT',
        'path' => '/api/users/{id}',
        'description' => 'Update data pengguna'
    ],
    [
        'method' => 'DELETE',
        'path' => '/api/users/{id}',
        'description' => 'Hapus pengguna'
    ],
    // Nested resource
    [
        'method' => 'GET',
        'path' => '/api/users/{id}/orders',
        'description' => 'Daftar pesanan pengguna'
    ]
];

echo json_encode($endpoints, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);
?>
```
