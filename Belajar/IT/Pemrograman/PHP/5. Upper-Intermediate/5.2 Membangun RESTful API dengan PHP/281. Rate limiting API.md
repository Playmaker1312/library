# 281. Rate Limiting API

## Definisi Singkat
Rate limiting membatasi jumlah request dari klien dalam periode waktu tertentu. Ini melindungi server dari abuse, serangan DDoS, dan memastikan penggunaan API yang adil.

## Analogi
Seperti kasir supermarket: "Maksimal 10 item per transaksi" (rate limit). Jika ada pelanggan yang mencoba membawa 50 item, kasir menolak. Pelanggan harus mengantri lagi untuk transaksi berikutnya.

## Poin-Poin Penting
- Algoritma: Token Bucket, Leaky Bucket, Fixed Window, Sliding Window
- Header response: `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`
- Gunakan Redis untuk distributed rate limiting
- Response 429 Too Many Requests jika limit tercapai
- Limit bisa per IP, per API key, atau per user
- Retry-After header memberi tahu kapan bisa request lagi

## Contoh Kode (PHP)
```php
<?php
header('Content-Type: application/json; charset=utf-8');

class RateLimiter
{
    private string $storageFile;
    private int $maxRequests = 10;
    private int $windowMinutes = 1;

    public function __construct(string $identifier)
    {
        $dir = __DIR__ . '/ratelimit';
        if (!is_dir($dir)) mkdir($dir, 0777, true);
        $this->storageFile = "$dir/$identifier.json";
    }

    public function check(): bool
    {
        $data = ['count' => 0, 'reset_time' => time() + ($this->windowMinutes * 60)];

        if (file_exists($this->storageFile)) {
            $data = json_decode(file_get_contents($this->storageFile), true);
            if (time() > $data['reset_time']) {
                $data = ['count' => 0, 'reset_time' => time() + ($this->windowMinutes * 60)];
            }
        }

        $data['count']++;
        file_put_contents($this->storageFile, json_encode($data));

        // Kirim rate limit headers
        header("X-RateLimit-Limit: {$this->maxRequests}");
        header("X-RateLimit-Remaining: " . max(0, $this->maxRequests - $data['count']));
        header("X-RateLimit-Reset: {$data['reset_time']}");

        if ($data['count'] > $this->maxRequests) {
            http_response_code(429);
            header("Retry-After: " . ($data['reset_time'] - time()));
            echo json_encode(['error' => 'Too many requests. Coba lagi nanti.']);
            return false;
        }

        return true;
    }
}

// Per IP atau per API key
$identifier = $_SERVER['REMOTE_ADDR'] ?? 'unknown';
$limiter = new RateLimiter($identifier);

if (!$limiter->check()) {
    exit;
}

echo json_encode(['message' => 'Request berhasil']);
?>
```

Public API (100 req/jam untuk free tier), login endpoint (5 percobaan per menit), proteksi endpoint mahal seperti search/report.
