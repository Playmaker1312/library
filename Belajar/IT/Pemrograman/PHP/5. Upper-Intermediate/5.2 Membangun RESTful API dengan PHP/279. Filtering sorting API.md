# 279. Filtering Sorting API

## Definisi Singkat
Filtering dan sorting memungkinkan klien mengambil subset data yang diinginkan berdasarkan kriteria tertentu. Filter menggunakan parameter query untuk seleksi, sorting untuk urutan data.

## Analogi
Seperti mencari buku di perpustakaan online: filter = "terbit 2024" + "kategori pemrograman", sorting = "urutkan berdasarkan judul A-Z". Pustakawan hanya mengembalikan buku yang sesuai kriteria.

## Poin-Poin Penting
- Filter: `?kategori=elektronik&harga_min=1000&harga_max=5000`
- Sorting: `?sort=harga&order=desc` (asc/desc)
- Multiple sort: `?sort[]=harga&sort[]=nama&order[]=desc&order[]=asc`
- Search: `?search=kata kunci`
- Field selection: `?fields=id,nama,email`
- Validasi field yang diizinkan untuk filter/sort
- Gunakan indexing database untuk performa

## Contoh Kode (PHP)
```php
<?php
header('Content-Type: application/json; charset=utf-8');

class QueryBuilder
{
    private array $allowedFilters = ['kategori', 'harga_min', 'harga_max', 'status'];
    private array $allowedSorts = ['nama', 'harga', 'tanggal', 'rating'];

    public function build(array $params): array
    {
        $conditions = [];
        $bindings = [];

        // Filtering
        if (!empty($params['kategori'])) {
            $conditions[] = "kategori = :kategori";
            $bindings[':kategori'] = $params['kategori'];
        }
        if (!empty($params['harga_min'])) {
            $conditions[] = "harga >= :harga_min";
            $bindings[':harga_min'] = (float)$params['harga_min'];
        }
        if (!empty($params['harga_max'])) {
            $conditions[] = "harga <= :harga_max";
            $bindings[':harga_max'] = (float)$params['harga_max'];
        }
        if (!empty($params['status'])) {
            $conditions[] = "status = :status";
            $bindings[':status'] = $params['status'];
        }

        // Searching
        if (!empty($params['search'])) {
            $conditions[] = "(nama LIKE :search OR deskripsi LIKE :search2)";
            $bindings[':search'] = "%{$params['search']}%";
            $bindings[':search2'] = "%{$params['search']}%";
        }

        // Sorting
        $sortField = in_array($params['sort'] ?? '', $this->allowedSorts)
            ? $params['sort'] : 'nama';
        $sortOrder = strtolower($params['order'] ?? 'asc') === 'desc' ? 'DESC' : 'ASC';

        $where = $conditions ? 'WHERE ' . implode(' AND ', $conditions) : '';

        return [
            'query' => "SELECT * FROM produk $where ORDER BY $sortField $sortOrder",
            'bindings' => $bindings
        ];
    }
}

$builder = new QueryBuilder();
$result = $builder->build($_GET);
echo json_encode($result, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);
// Output: query SQL dan binding yang siap dieksekusi
?>
```

## Kasus Penggunaan Nyata
Katalog produk dengan filter harga/kategori, pencarian user berdasarkan nama/email, laporan data dengan sorting tanggal.
