# 283. Dokumentasi API Swagger OpenAPI

## Definisi Singkat
OpenAPI (sebelumnya Swagger) adalah standar dokumentasi API yang mendefinisikan endpoint, parameter, request/response body, dan autentikasi dalam format YAML/JSON. Bisa di-render menjadi dokumentasi interaktif.

## Analogi
Seperti menu restoran lengkap dengan deskripsi, daftar bahan, harga, dan foto setiap makanan. Pengunjung (developer) bisa melihat semua informasi sebelum memesan (menggunakan API).

## Poin-Poin Penting
- OpenAPI menggunakan format YAML atau JSON
- Definisikan: info, servers, paths, components
- Setiap path punya method, parameters, requestBody, responses
- `$ref` untuk referensi komponen reusable
- Swagger UI menampilkan dokumentasi interaktif
- Generate client SDK otomatis dari spec
- Tools: swagger-php untuk generate dari annotasi

## Contoh Kode (PHP)
```php
<?php
// Contoh OpenAPI spec dalam PHP array (biasanya file YAML terpisah)
$openapi = [
    'openapi' => '3.0.0',
    'info' => [
        'title' => 'API Toko Online',
        'version' => '1.0.0',
        'description' => 'API untuk manajemen toko online'
    ],
    'servers' => [
        ['url' => 'http://localhost:8000/api', 'description' => 'Development'],
        ['url' => 'https://api.toko.com/v1', 'description' => 'Production']
    ],
    'paths' => [
        '/users' => [
            'get' => [
                'summary' => 'Daftar semua user',
                'parameters' => [
                    ['name' => 'page', 'in' => 'query', 'schema' => ['type' => 'integer']],
                    ['name' => 'limit', 'in' => 'query', 'schema' => ['type' => 'integer']]
                ],
                'responses' => [
                    '200' => ['description' => 'Daftar user berhasil']
                ]
            ],
            'post' => [
                'summary' => 'Buat user baru',
                'requestBody' => [
                    'required' => true,
                    'content' => [
                        'application/json' => [
                            'schema' => [
                                'type' => 'object',
                                'properties' => [
                                    'nama' => ['type' => 'string'],
                                    'email' => ['type' => 'string', 'format' => 'email'],
                                    'password' => ['type' => 'string', 'minLength' => 8]
                                ],
                                'required' => ['nama', 'email', 'password']
                            ]
                        ]
                    ]
                ],
                'responses' => [
                    '201' => ['description' => 'User berhasil dibuat'],
                    '422' => ['description' => 'Validasi gagal']
                ]
            ]
        ],
        '/users/{id}' => [
            'get' => [
                'summary' => 'Detail user',
                'parameters' => [
                    ['name' => 'id', 'in' => 'path', 'required' => true, 'schema' => ['type' => 'integer']]
                ],
                'responses' => [
                    '200' => ['description' => 'Data user'],
                    '404' => ['description' => 'User tidak ditemukan']
                ]
            ]
        ]
    ]
];

header('Content-Type: application/json');
echo json_encode($openapi, JSON_PRETTY_PRINT);
?>
```

## Kasus Penggunaan Nyata
Public API documentation (Stripe, GitHub, Twilio), internal API documentation, client SDK generation, API testing via Swagger UI.
