# 272. Router Sederhana PHP Murni

## Definisi Singkat
Router adalah komponen yang memetakan URL request ke handler tertentu. Router sederhana PHP murni dibuat tanpa framework, menggunakan `$_SERVER['REQUEST_URI']` dan `$_SERVER['REQUEST_METHOD']`.

## Analogi
Seperti resepsionis di kantor: tamu datang dengan tujuan tertentu (URL), resepsionis membaca tujuan (routing) dan mengarahkan ke ruangan (handler) yang tepat.

## Poin-Poin Penting
- Parsing URL dengan `parse_url()` dan `explode()`
- Cocokkan path dengan daftar route yang telah didefinisikan
- Ekstrak parameter dinamis dari URL (contoh: `/users/{id}`)
- Panggil fungsi handler yang sesuai
- Handle 404 jika route tidak ditemukan
- Handle 405 jika method tidak sesuai

## Contoh Kode (PHP)
```php
<?php
class Router
{
    private array $routes = [];

    public function addRoute(string $method, string $pattern, callable $handler): void
    {
        $pattern = preg_replace('/\{(\w+)\}/', '(?P<$1>[^/]+)', $pattern);
        $pattern = '#^' . $pattern . '$#';
        $this->routes[] = compact('method', 'pattern', 'handler');
    }

    public function dispatch(string $method, string $uri): void
    {
        $uri = parse_url($uri, PHP_URL_PATH);
        $uri = rtrim($uri, '/') ?: '/';

        foreach ($this->routes as $route) {
            if ($route['method'] === $method && preg_match($route['pattern'], $uri, $matches)) {
                $params = array_filter($matches, 'is_string', ARRAY_FILTER_USE_KEY);
                call_user_func($route['handler'], $params);
                return;
            }
        }

        http_response_code(404);
        echo json_encode(['error' => 'Route tidak ditemukan']);
    }
}

// Inisialisasi router
$router = new Router();
$router->addRoute('GET', '/api/users', function($params) {
    echo json_encode(['data' => 'Daftar users']);
});
$router->addRoute('GET', '/api/users/{id}', function($params) {
    echo json_encode(['data' => "User dengan id {$params['id']}"]);
});
$router->addRoute('POST', '/api/users', function($params) {
    echo json_encode(['message' => 'User dibuat']);
});

header('Content-Type: application/json; charset=utf-8');
$router->dispatch($_SERVER['REQUEST_METHOD'], $_SERVER['REQUEST_URI']);
?>
```

## Kasus Penggunaan Nyata
Proyek API kecil tanpa framework, microservice sederhana, pembelajaran konsep routing sebelum menggunakan framework.
