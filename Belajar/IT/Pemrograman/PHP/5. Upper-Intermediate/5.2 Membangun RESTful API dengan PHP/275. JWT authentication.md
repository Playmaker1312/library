# 275. JWT Authentication

## Definisi Singkat
JWT (JSON Web Token) adalah token berbasis JSON yang berisi data klaim (payload) yang ditandatangani secara digital. Token dikirim di header `Authorization: Bearer <token>` dan diverifikasi tanpa perlu session di server.

## Analogi
Seperti KTP elektronik: berisi data Anda (nama, foto), ada tanda tangan digital yang memastikan keaslian, dan bisa diverifikasi oleh siapapun. Tidak perlu database untuk mengecek apakah KTP valid.

## Poin-Poin Penting
- Terdiri dari 3 bagian: header, payload, signature (base64url encoded)
- Signature memastikan token tidak dimanipulasi
- Payload berisi klaim: `sub` (user id), `iat` (issued at), `exp` (expiry)
- Token stateless: server tidak perlu menyimpan session
- JWT bisa di-decode oleh siapapun (hanya signature yang diamankan)
- Jangan simpan data sensitif di payload (password, kartu kredit)
- Set expiry time yang pendek (15-60 menit) + refresh token

## Contoh Kode (PHP)
```php
<?php
// Implementasi JWT sederhana tanpa library
function generateJWT(array $payload, string $secret): string
{
    $header = base64url_encode(json_encode(['typ' => 'JWT', 'alg' => 'HS256']));
    $payload['iat'] = time();
    $payload['exp'] = time() + 3600;
    $payloadEncoded = base64url_encode(json_encode($payload));

    $signature = base64url_encode(
        hash_hmac('sha256', "$header.$payloadEncoded", $secret, true)
    );

    return "$header.$payloadEncoded.$signature";
}

function verifyJWT(string $token, string $secret): ?array
{
    $parts = explode('.', $token);
    if (count($parts) !== 3) return null;

    [$header, $payload, $signature] = $parts;

    $validSig = base64url_encode(
        hash_hmac('sha256', "$header.$payload", $secret, true)
    );

    if (!hash_equals($validSig, $signature)) return null;

    $data = json_decode(base64url_decode($payload), true);
    if ($data['exp'] < time()) return null;

    return $data;
}

function base64url_encode(string $data): string
{
    return rtrim(strtr(base64_encode($data), '+/', '-_'), '=');
}

function base64url_decode(string $data): string
{
    return base64_decode(strtr($data, '-_', '+/'));
}

// Middleware autentikasi
$secret = 's3cr3t-k3y-super-aman!';
$headers = getallheaders();
$authHeader = $headers['Authorization'] ?? '';

if (preg_match('/^Bearer\s+(.+)$/', $authHeader, $matches)) {
    $payload = verifyJWT($matches[1], $secret);
    if (!$payload) {
        http_response_code(401);
        echo json_encode(['error' => 'Token tidak valid atau expired']);
        exit;
    }
    echo json_encode(['message' => 'Authenticated', 'user_id' => $payload['sub']]);
} else {
    http_response_code(401);
    echo json_encode(['error' => 'Bearer token diperlukan']);
}
?>
```
