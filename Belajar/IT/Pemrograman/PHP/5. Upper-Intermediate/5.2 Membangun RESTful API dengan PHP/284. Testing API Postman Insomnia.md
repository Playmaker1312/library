# 284. Testing API Postman Insomnia

## Definisi Singkat
Postman dan Insomnia adalah tools GUI untuk menguji API secara manual dan otomatis. Mereka memungkinkan Anda mengirim request, memeriksa response, membuat collection, dan menjalankan test script.

## Analogi
Seperti mekanik yang menguji mobil: Postman/Insomnia adalah alat diagnostik yang bisa "mengemudikan" API, membaca "dashboard" (response), dan merekam hasil tes untuk diulang lagi nanti.

## Poin-Poin Penting
- **Collection**: kumpulan request API yang terorganisir
- **Environment**: variabel untuk base URL, token, dll
- **Pre-request Script**: script sebelum request (set token)
- **Tests**: script otomatis untuk validasi response
- **Runner**: jalankan collection secara berurutan
- **Code Generate**: hasilkan kode dari request (PHP, cURL, dll)
- Export/Import collection untuk kolaborasi tim

## Contoh Kode (PHP)
```php
<?php
// Testing API dengan PHP (alternatif command-line)

function testApi(string $method, string $url, array $headers = [], $body = null): array
{
    $ch = curl_init();
    curl_setopt_array($ch, [
        CURLOPT_URL => $url,
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_CUSTOMREQUEST => $method,
        CURLOPT_HTTPHEADER => $headers,
    ]);

    if ($body !== null) {
        curl_setopt($ch, CURLOPT_POSTFIELDS, is_string($body) ? $body : json_encode($body));
    }

    $response = curl_exec($ch);
    $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    curl_close($ch);

    return ['code' => $httpCode, 'body' => json_decode($response, true)];
}

// Test scenario
$baseUrl = 'http://localhost:8000/api';

// Test 1: GET users
$result = testApi('GET', "$baseUrl/users", ['Content-Type: application/json']);
echo "Test GET /users: " . $result['code'] . "\n";
var_dump($result['body']);

// Test 2: POST user
$newUser = ['nama' => 'Test User', 'email' => 'test@test.com', 'password' => 'rahasia123'];
$result = testApi('POST', "$baseUrl/users", ['Content-Type: application/json'], $newUser);
echo "Test POST /users: " . $result['code'] . "\n";
var_dump($result['body']);

// Test 3: validasi error
$invalidUser = ['nama' => ''];
$result = testApi('POST', "$baseUrl/users", ['Content-Type: application/json'], $invalidUser);
echo "Test validasi: " . $result['code'] . "\n";
var_dump($result['body']);
?>
```

## Kasus Penggunaan Nyata
Manual testing API endpoint, regression testing, collaboration antar developer, mocking API response.
