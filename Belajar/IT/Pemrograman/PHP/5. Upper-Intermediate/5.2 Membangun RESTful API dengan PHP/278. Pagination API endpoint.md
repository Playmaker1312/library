# 278. Pagination API Endpoint

## Definisi Singkat
Pagination membagi data besar menjadi halaman-halaman kecil. Parameter `page` dan `limit` dikirim klien, server mengembalikan data per halaman plus metadata pagination.

## Analogi
Seperti buku: Anda tidak membaca semua halaman sekaligus. Pembaca menentukan halaman berapa (`page`) dan berapa baris per halaman (`limit`). Buku juga memberi tahu total halaman (metadata).

## Poin-Poin Penting
- Parameter: `page` (default 1), `limit` (default 10-100)
- Hitung `offset = (page - 1) * limit` untuk query SQL
- Response metadata: `total`, `page`, `limit`, `totalPages`
- Batasi maksimum limit untuk mencegah abuse
- Sertakan link `prev` dan `next` untuk navigasi
- Gunakan `LIMIT` dan `OFFSET` di SQL

## Contoh Kode (PHP)
```php
<?php
header('Content-Type: application/json; charset=utf-8');

class Paginator
{
    public static function paginate(array $items, int $total, array $params): array
    {
        $page = max(1, (int)($params['page'] ?? 1));
        $limit = min(100, max(1, (int)($params['limit'] ?? 10)));
        $offset = ($page - 1) * $limit;
        $totalPages = (int)ceil($total / $limit);

        $data = array_slice($items, $offset, $limit);

        return [
            'data' => $data,
            'pagination' => [
                'page' => $page,
                'limit' => $limit,
                'total' => $total,
                'totalPages' => $totalPages,
                'hasPrev' => $page > 1,
                'hasNext' => $page < $totalPages,
                'prev' => $page > 1 ? "?page=" . ($page - 1) . "&limit=$limit" : null,
                'next' => $page < $totalPages ? "?page=" . ($page + 1) . "&limit=$limit" : null,
            ]
        ];
    }
}

// Database simulasi
$allUsers = [];
for ($i = 1; $i <= 100; $i++) {
    $allUsers[] = ['id' => $i, 'nama' => "User $i", 'email' => "user$i@test.com"];
}

$result = Paginator::paginate($allUsers, count($allUsers), $_GET);
echo json_encode($result, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);

// Query SQL yang sesuai:
// $page = 1; $limit = 10;
// $offset = ($page - 1) * $limit;
// $query = "SELECT * FROM users LIMIT $limit OFFSET $offset";
// $countQuery = "SELECT COUNT(*) as total FROM users";
?>
```
