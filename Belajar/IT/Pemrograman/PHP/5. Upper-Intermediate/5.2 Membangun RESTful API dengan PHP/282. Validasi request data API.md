# 282. Validasi Request Data API

## Definisi Singkat
Validasi request data adalah proses memeriksa apakah data yang dikirim klien memenuhi aturan yang ditentukan (required, tipe, format, panjang) sebelum diproses lebih lanjut.

## Analogi
Seperti petugas imigrasi: sebelum mengizinkan masuk, petugas memeriksa paspor (required), foto cocok (format), masa berlaku (range), dan visa (aturan khusus). Jika tidak lolos, ditolak dengan alasan jelas.

## Poin-Poin Penting
- Validasi: required, tipe data, format (email, URL, date), min/max length, enum
- Beri pesan error yang jelas per field
- Jangan percaya input dari klien apapun
- Sanitasi data setelah validasi
- Gunakan library seperti Respect/Validation jika perlu
- Kembalikan 422 Unprocessable Entity untuk validasi gagal

## Contoh Kode (PHP)
```php
<?php
header('Content-Type: application/json; charset=utf-8');

function validate(array $data, array $rules): array
{
    $errors = [];

    foreach ($rules as $field => $fieldRules) {
        $value = $data[$field] ?? null;
        $isRequired = in_array('required', $fieldRules);

        if ($isRequired && ($value === null || $value === '')) {
            $errors[$field][] = "$field harus diisi";
            continue;
        }

        if ($value === null || $value === '') {
            continue;
        }

        foreach ($fieldRules as $rule) {
            if ($rule === 'required') continue;

            if ($rule === 'email' && !filter_var($value, FILTER_VALIDATE_EMAIL)) {
                $errors[$field][] = "$field harus berupa email valid";
            }

            if ($rule === 'numeric' && !is_numeric($value)) {
                $errors[$field][] = "$field harus berupa angka";
            }

            if (str_starts_with($rule, 'min:')) {
                $min = (int)substr($rule, 4);
                if (is_string($value) && strlen($value) < $min) {
                    $errors[$field][] = "$field minimal $min karakter";
                }
                if (is_numeric($value) && $value < $min) {
                    $errors[$field][] = "$field minimal $min";
                }
            }

            if (str_starts_with($rule, 'max:')) {
                $max = (int)substr($rule, 4);
                if (is_string($value) && strlen($value) > $max) {
                    $errors[$field][] = "$field maksimal $max karakter";
                }
            }

            if (str_starts_with($rule, 'in:')) {
                $allowed = explode(',', substr($rule, 3));
                if (!in_array($value, $allowed)) {
                    $errors[$field][] = "$field harus salah satu: " . implode(', ', $allowed);
                }
            }
        }
    }

    return $errors;
}

$input = json_decode(file_get_contents('php://input'), true) ?? [];
$rules = [
    'nama' => ['required', 'min:3', 'max:100'],
    'email' => ['required', 'email'],
    'umur' => ['required', 'numeric', 'min:17', 'max:120'],
    'role' => ['required', 'in:admin,user,editor']
];

$errors = validate($input, $rules);
if (!empty($errors)) {
    http_response_code(422);
    echo json_encode([
        'status' => 'error',
        'message' => 'Validasi gagal',
        'errors' => $errors
    ], JSON_UNESCAPED_UNICODE);
    exit;
}

echo json_encode(['status' => 'success', 'data' => $input]);
?>
```

Registrasi user, form input data, submit order, konfigurasi API, input yang akan disimpan ke database.
