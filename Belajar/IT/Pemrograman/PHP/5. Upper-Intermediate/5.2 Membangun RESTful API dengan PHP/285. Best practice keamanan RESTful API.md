# 285. Best Practice Keamanan RESTful API

## Definisi Singkat
Best practice keamanan RESTful API adalah kumpulan langkah untuk melindungi API dari serangan seperti injeksi, penyalahgunaan akses, kebocoran data, dan serangan lainnya.

## Analogi
Seperti keamanan bank: pintu terkunci (HTTPS), petugas keamanan (autentikasi), izin akses ruangan (otorisasi), kamera CCTV (logging), prosedur darurat (rate limiting), dan brankas (enkripsi data).

## Poin-Poin Penting
- Selalu gunakan HTTPS/TLS
- Autentikasi kuat (JWT, OAuth2)
- Otorisasi: pastikan user hanya akses data miliknya
- Validasi dan sanitasi semua input
- Rate limiting untuk mencegah abuse
- CORS dikonfigurasi dengan ketat
- Logging semua request untuk audit
- Jangan expose error detail ke klien
- Gunakan security headers (CSP, X-Frame-Options)

## Contoh Kode (PHP)
```php
<?php
// Best practice keamanan API

// 1. HTTPS dipaksa (jika tidak, tolak)
function forceHTTPS(): void
{
    if (empty($_SERVER['HTTPS']) || $_SERVER['HTTPS'] === 'off') {
        $httpsUrl = 'https://' . $_SERVER['HTTP_HOST'] . $_SERVER['REQUEST_URI'];
        header('Location: ' . $httpsUrl);
        exit;
    }
}

// 2. Security headers
function setSecurityHeaders(): void
{
    header('X-Content-Type-Options: nosniff');
    header('X-Frame-Options: DENY');
    header('X-XSS-Protection: 1; mode=block');
    header('Strict-Transport-Security: max-age=31536000; includeSubDomains');
    header('Content-Security-Policy: default-src \'self\'');
    header('Cache-Control: no-store, must-revalidate');
}

// 3. CORS ketat
function strictCORS(): void
{
    $allowedOrigins = ['https://app.example.com'];
    $origin = $_SERVER['HTTP_ORIGIN'] ?? '';
    if (in_array($origin, $allowedOrigins)) {
        header("Access-Control-Allow-Origin: $origin");
    }
    header('Access-Control-Allow-Methods: GET, POST, PUT, DELETE');
    header('Access-Control-Allow-Headers: Content-Type, Authorization');
    header('Access-Control-Allow-Credentials: true');
}

// 4. Jangan expose error detail
function safeErrorHandler(): void
{
    set_exception_handler(function (Throwable $e) {
        http_response_code(500);
        // Log detail error ke file, jangan ke klien
        error_log($e->getMessage() . "\n" . $e->getTraceAsString());
        echo json_encode(['error' => 'Terjadi kesalahan internal']);
    });
}

// 5. Idempotency key untuk POST/PUT
function getIdempotencyKey(): ?string
{
    $headers = getallheaders();
    return $headers['Idempotency-Key'] ?? null;
}

// 6. Input validation
function sanitizeInput(array $data): array
{
    $clean = [];
    foreach ($data as $key => $value) {
        if (is_string($value)) {
            $clean[$key] = htmlspecialchars(strip_tags($value), ENT_QUOTES, 'UTF-8');
        } else {
            $clean[$key] = $value;
        }
    }
    return $clean;
}
?>
```

## Kasus Penggunaan Nyata
API production yang melayani data sensitif (finansial, kesehatan, data pribadi), public API dengan banyak konsumen.
