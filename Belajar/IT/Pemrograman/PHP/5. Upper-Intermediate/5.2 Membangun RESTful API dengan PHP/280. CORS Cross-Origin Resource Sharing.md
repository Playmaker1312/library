# 280. CORS Cross-Origin Resource Sharing

## Definisi Singkat
CORS adalah mekanisme keamanan browser yang mengizinkan atau membatasi request dari domain lain ke API Anda. Server mengirim header khusus untuk memberi tahu browser: "Domain ini diizinkan mengakses API saya."

## Analogi
Seperti pramugari yang memeriksa boarding pass: penumpang dari gerbang lain (domain berbeda) harus memiliki izin khusus (CORS header) untuk masuk ke pesawat Anda.

## Poin-Poin Penting
- `Access-Control-Allow-Origin`: domain yang diizinkan (`*` untuk semua)
- `Access-Control-Allow-Methods`: method yang diizinkan
- `Access-Control-Allow-Headers`: header yang diizinkan
- `Access-Control-Allow-Credentials`: untuk cookie/auth
- Preflight request (OPTIONS) untuk request kompleks
- Jangan gunakan `*` di production jika butuh credentials
- Handle OPTIONS request sebelum logic utama

## Contoh Kode (PHP)
```php
<?php
// CORS Middleware
function cors(): void
{
    // Izinkan semua origin (development)
    header('Access-Control-Allow-Origin: *');

    // Atau spesifik origin
    // $origin = $_SERVER['HTTP_ORIGIN'] ?? '';
    // $allowed = ['https://app.example.com', 'https://admin.example.com'];
    // if (in_array($origin, $allowed)) {
    //     header("Access-Control-Allow-Origin: $origin");
    // }

    header('Access-Control-Allow-Methods: GET, POST, PUT, PATCH, DELETE, OPTIONS');
    header('Access-Control-Allow-Headers: Content-Type, Authorization, X-API-Key');
    header('Access-Control-Max-Age: 86400'); // cache preflight 1 hari

    // Handle preflight
    if ($_SERVER['REQUEST_METHOD'] === 'OPTIONS') {
        http_response_code(204);
        exit;
    }
}

cors();
header('Content-Type: application/json; charset=utf-8');

// Contoh endpoint
echo json_encode(['message' => 'CORS enabled']);

// Jika butuh credentials (cookie, auth header)
// header('Access-Control-Allow-Credentials: true');
// header('Access-Control-Allow-Origin: https://app.example.com');
// Jangan gunakan * jika credentials true!

// Contoh di Nginx (.htaccess alternatif):
// add_header 'Access-Control-Allow-Origin' '*';
// add_header 'Access-Control-Allow-Methods' 'GET, POST, OPTIONS';
?>
```

## Kasus Penggunaan Nyata
Frontend SPA (React di localhost:3000) mengakses API backend (localhost:8000), mobile apps, public API untuk developer eksternal.
