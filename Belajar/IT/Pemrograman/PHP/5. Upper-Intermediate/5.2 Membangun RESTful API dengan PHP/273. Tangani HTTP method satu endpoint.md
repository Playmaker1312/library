# 273. Tangani HTTP Method Satu Endpoint

## Definisi Singkat
Satu endpoint API dapat menangani beberapa HTTP methods untuk operasi berbeda pada resource yang sama. Pattern ini membuat kode terorganisir sesuai prinsip REST.

## Analogi
Seperti satu loket layanan: loket yang sama bisa melayani" Ambil formulir (GET), Isi formulir baru (POST), Ubah formulir yang sudah diisi (PUT), atau Batalkan formulir (DELETE).

## Poin-Poin Penting
- Gunakan `switch` atau `match` untuk membedakan method
- Satu file/class menangani semua operasi untuk satu resource
- URL sama, method berbeda untuk operasi berbeda
- GET untuk baca, POST untuk buat, PUT/PATCH untuk ubah, DELETE untuk hapus
- Response berbeda tergantung method

## Contoh Kode (PHP)
```php
<?php
header('Content-Type: application/json; charset=utf-8');

$method = $_SERVER['REQUEST_METHOD'];
$userId = $_GET['id'] ?? null;

// Satu endpoint /api/users menangani semua method
switch ($method) {
    case 'GET':
        if ($userId) {
            // GET /api/users?id=1
            echo json_encode(['data' => [
                'id' => (int)$userId,
                'nama' => 'John Doe',
                'email' => 'john@example.com'
            ]]);
        } else {
            // GET /api/users
            echo json_encode(['data' => [
                ['id' => 1, 'nama' => 'John'],
                ['id' => 2, 'nama' => 'Jane']
            ]]);
        }
        break;

    case 'POST':
        // POST /api/users
        $input = json_decode(file_get_contents('php://input'), true);
        http_response_code(201);
        echo json_encode([
            'message' => 'User berhasil dibuat',
            'data' => ['id' => 3, 'nama' => $input['nama']]
        ]);
        break;

    case 'PUT':
        // PUT /api/users?id=1
        $input = json_decode(file_get_contents('php://input'), true);
        echo json_encode([
            'message' => "User {$userId} berhasil diupdate"
        ]);
        break;

    case 'DELETE':
        // DELETE /api/users?id=1
        if (!$userId) {
            http_response_code(400);
            echo json_encode(['error' => 'ID diperlukan']);
            break;
        }
        echo json_encode([
            'message' => "User {$userId} berhasil dihapus"
        ]);
        break;

    default:
        http_response_code(405);
        header('Allow: GET, POST, PUT, DELETE');
        echo json_encode(['error' => 'Method tidak diizinkan']);
}
?>
```

## Kasus Penggunaan Nyata
Endpoint CRUD untuk resource seperti users, products, posts dalam API RESTful.
