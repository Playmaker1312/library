# 277. Response JSON Konsisten Terstruktur

## Definisi Singkat
Response JSON yang konsisten berarti setiap response API memiliki format standar yang sama: wrapper untuk sukses (`status`, `data`, `message`) dan error (`status`, `error`, `code`). Ini memudahkan klien memproses response.

## Analogi
Seperti formulir yang selalu memiliki format sama: setiap formulir punya kop surat, tanggal, isi, dan tanda tangan di posisi yang sama. Petugas tahu persis di mana mencari informasi.

## Poin-Poin Penting
- Response sukses: `{ "status": "success", "data": {...}, "message": "..." }`
- Response error: `{ "status": "error", "error": {...}, "code": 400 }`
- Gunakan HTTP status codes yang sesuai
- Waktu response (`timestamp`) untuk debugging
- Metadata untuk pagination
- Jangan campur format response antar endpoint
- Gunakan helper function untuk konsistensi

## Contoh Kode (PHP)
```php
<?php
header('Content-Type: application/json; charset=utf-8');

class ApiResponse
{
    public static function success($data = null, string $message = 'OK', int $code = 200): void
    {
        http_response_code($code);
        echo json_encode([
            'status' => 'success',
            'message' => $message,
            'data' => $data,
            'timestamp' => date('c')
        ], JSON_UNESCAPED_UNICODE);
        exit;
    }

    public static function error(string $message, int $code = 400, $errors = null): void
    {
        http_response_code($code);
        $response = [
            'status' => 'error',
            'message' => $message,
            'code' => $code,
            'timestamp' => date('c')
        ];
        if ($errors !== null) {
            $response['errors'] = $errors;
        }
        echo json_encode($response, JSON_UNESCAPED_UNICODE);
        exit;
    }

    public static function paginated(array $data, int $page, int $limit, int $total): void
    {
        http_response_code(200);
        echo json_encode([
            'status' => 'success',
            'data' => $data,
            'pagination' => [
                'page' => $page,
                'limit' => $limit,
                'total' => $total,
                'totalPages' => ceil($total / $limit)
            ],
            'timestamp' => date('c')
        ], JSON_UNESCAPED_UNICODE);
        exit;
    }
}

// Contoh penggunaan
try {
    $users = [['id' => 1, 'nama' => 'John'], ['id' => 2, 'nama' => 'Jane']];
    // ApiResponse::success($users, 'Daftar pengguna berhasil diambil');

    // dengan pagination
    // ApiResponse::paginated($users, 1, 10, 50);

    // error
    // ApiResponse::error('User tidak ditemukan', 404);
} catch (\Exception $e) {
    ApiResponse::error('Internal server error', 500);
}
?>
```

## Kasus Penggunaan Nyata
Semua endpoint API menggunakan format response yang sama, memudahkan frontend membuat interceptor/error handler global.
