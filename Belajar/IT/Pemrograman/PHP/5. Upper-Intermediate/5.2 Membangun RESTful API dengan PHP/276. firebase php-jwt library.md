# 276. firebase/php-jwt Library

## Definisi Singkat
`firebase/php-jwt` adalah library populer untuk encode dan decode JWT di PHP. Library ini menyediakan API yang aman dan mudah digunakan dengan dukungan berbagai algoritma signing.

## Analogi
Seperti mesin pencetak dan pemverifikasi KTP profesional: Anda tinggal memasukkan data, mesin mencetak KTP (encode) atau memverifikasi keasliannya (decode) tanpa perlu membuat mesin dari nol.

## Poin-Poin Penting
- Instal via Composer: `composer require firebase/php-jwt`
- Fungsi utama: `JWT::encode()` dan `JWT::decode()`
- Dukung algoritma: HS256, HS384, HS512, RS256, dll
- Otomatis validasi signature dan expiry
- Gunakan `Key` object untuk menentukan algoritma
- Tangani exception `ExpiredException`, `SignatureInvalidException`

## Contoh Kode (PHP)
```php
<?php
require_once 'vendor/autoload.php';

use Firebase\JWT\JWT;
use Firebase\JWT\Key;
use Firebase\JWT\ExpiredException;

$secret = 'k3y-super-rahasia';
$payload = [
    'sub' => 123,
    'name' => 'John Doe',
    'email' => 'john@example.com',
    'iat' => time(),
    'exp' => time() + 3600
];

// Encode JWT
$jwt = JWT::encode($payload, $secret, 'HS256');
echo json_encode(['token' => $jwt]);

// Decode JWT
try {
    $decoded = JWT::decode($jwt, new Key($secret, 'HS256'));
    echo json_encode([
        'user_id' => $decoded->sub,
        'name' => $decoded->name
    ]);
} catch (ExpiredException $e) {
    http_response_code(401);
    echo json_encode(['error' => 'Token expired']);
} catch (\Exception $e) {
    http_response_code(401);
    echo json_encode(['error' => 'Token tidak valid: ' . $e->getMessage()]);
}

// Middleware autentikasi lengkap
function authenticate(): object
{
    $headers = getallheaders();
    $auth = $headers['Authorization'] ?? '';

    if (!preg_match('/^Bearer\s+(.+)$/', $auth, $m)) {
        http_response_code(401);
        echo json_encode(['error' => 'Bearer token diperlukan']);
        exit;
    }

    try {
        return JWT::decode($m[1], new Key($_ENV['JWT_SECRET'], 'HS256'));
    } catch (\Exception $e) {
        http_response_code(401);
        echo json_encode(['error' => 'Token tidak valid']);
        exit;
    }
}

$user = authenticate();
echo json_encode(['message' => 'Selamat datang ' . $user->name]);
?>
```

## Kasus Penggunaan Nyata
Autentikasi JWT production di aplikasi PHP, microservices, RESTful API dengan keamanan terpercaya.
