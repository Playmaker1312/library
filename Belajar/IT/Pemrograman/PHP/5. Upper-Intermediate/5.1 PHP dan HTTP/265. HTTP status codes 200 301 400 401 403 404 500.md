# 265. HTTP Status Codes 200 301 400 401 403 404 500

## Definisi Singkat
HTTP status codes adalah kode tiga digit yang dikirim server sebagai hasil dari request. Kode menunjukkan apakah request berhasil, perlu redirect, atau terjadi error.

## Analogi
Seperti nilai ujian: 200 = lulus sempurna, 301 = pindah kelas, 400 = soal tidak jelas, 401 = tidak boleh ikut ujian, 403 = ruang terlarang, 404 = soal tidak ditemukan, 500 = korektor error.

## Poin-Poin Penting
- **200 OK**: Request berhasil
- **201 Created**: Resource berhasil dibuat (POST)
- **301 Moved Permanently**: URL pindah permanen
- **302 Found**: Redirect sementara
- **400 Bad Request**: Request salah dari klien
- **401 Unauthorized**: Belum login / otentikasi diperlukan
- **403 Forbidden**: Tidak punya akses (sudah login tapi tidak diizinkan)
- **404 Not Found**: Resource tidak ditemukan
- **405 Method Not Allowed**: Method tidak diizinkan untuk endpoint
- **422 Unprocessable Entity**: Validasi gagal
- **429 Too Many Requests**: Rate limit tercapai
- **500 Internal Server Error**: Error di server
- **502 Bad Gateway**: Server upstream error

## Contoh Kode (PHP)
```php
<?php
// 200 OK (default)
echo json_encode(['status' => 'ok', 'data' => $data]);

// 201 Created
http_response_code(201);
echo json_encode(['message' => 'User berhasil dibuat']);

// 400 Bad Request
http_response_code(400);
echo json_encode(['error' => 'Parameter id harus berupa angka']);

// 401 Unauthorized
http_response_code(401);
echo json_encode(['error' => 'Silakan login terlebih dahulu']);

// 403 Forbidden
http_response_code(403);
echo json_encode(['error' => 'Anda tidak memiliki akses']);

// 404 Not Found
http_response_code(404);
echo json_encode(['error' => 'Resource tidak ditemukan']);

// 405 Method Not Allowed
http_response_code(405);
header('Allow: GET, POST');
echo json_encode(['error' => 'Method tidak diizinkan']);

// 500 Internal Server Error
http_response_code(500);
echo json_encode(['error' => 'Terjadi kesalahan pada server']);
?>
```

## Kasus Penggunaan Nyata
API RESTful menggunakan status codes untuk memberi tahu klien hasil request secara tepat dan standar.
