# 270. RESTful API Prinsip

## Definisi Singkat
REST (Representational State Transfer) adalah gaya arsitektur API yang menggunakan HTTP methods untuk operasi CRUD pada resource. Setiap resource diidentifikasi oleh URL unik dan direpresentasikan dalam format standar (JSON/XML).

## Analogi
Seperti restoran dengan menu lengkap: Menu (resource) adalah daftar makanan, GET = melihat menu, POST = memesan makanan baru, PUT = mengganti pesanan, PATCH = mengubah topping, DELETE = membatalkan pesanan. Setiap item menu punya nomor sendiri (URL).

## Poin-Poin Penting
- **Resource-based**: URL mewakili resource (`/users`, `/products/1`)
- **HTTP Methods**: GET (baca), POST (buat), PUT (ganti), PATCH (ubah), DELETE (hapus)
- **Stateless**: Setiap request independen, tidak ada session di server
- **Representasi**: JSON atau XML untuk data
- **Status Codes**: Gunakan kode HTTP yang tepat
- **HATEOAS**: Hypermedia sebagai mesin aplikasi state (opsional)
- URL plural: `/users` bukan `/user`

## Contoh Kode (PHP)
```php
<?php
header('Content-Type: application/json; charset=utf-8');

$method = $_SERVER['REQUEST_METHOD'];
$path = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);
$pathParts = explode('/', trim($path, '/'));

// Routing sederhana RESTful
// GET /users -> daftar users
// GET /users/1 -> user id 1
// POST /users -> buat user baru
// PUT /users/1 -> update user id 1
// DELETE /users/1 -> hapus user id 1

$resource = $pathParts[0] ?? '';
$id = $pathParts[1] ?? null;

switch ($resource) {
    case 'users':
        handleUsers($method, $id);
        break;
    case 'products':
        handleProducts($method, $id);
        break;
    default:
        http_response_code(404);
        echo json_encode(['error' => 'Endpoint tidak ditemukan']);
}

function handleUsers($method, $id) {
    switch ($method) {
        case 'GET':
            if ($id) {
                echo json_encode(['data' => "User $id"]);
            } else {
                echo json_encode(['data' => ['User 1', 'User 2']]);
            }
            break;
        case 'POST':
            http_response_code(201);
            echo json_encode(['message' => 'User dibuat']);
            break;
        case 'PUT':
        case 'PATCH':
            echo json_encode(['message' => 'User diupdate']);
            break;
        case 'DELETE':
            echo json_encode(['message' => 'User dihapus']);
            break;
    }
}
?>
```

## Kasus Penggunaan Nyata
Backend untuk aplikasi mobile, service-to-service communication, public API untuk developer pihak ketiga (seperti GitHub API, Twitter API).
