# 268. php://input baca request body API

## Definisi Singkat
`php://input` adalah stream read-only yang membaca raw data dari request body. Ini digunakan untuk membaca data JSON, XML, atau format lain yang tidak tersedia di `$_POST`.

## Analogi
Seperti pipa air langsung dari sumber ke gelas Anda. `$_POST` hanya menangkap form biasa (seperti air ledeng), `php://input` mengambil apapun yang dikirim (seperti mengambil langsung dari mata air).

## Poin-Poin Penting
- `php://input` membaca raw body request
- Tidak bisa digunakan dengan `multipart/form-data` (file upload)
- Berguna untuk API yang menerima JSON/XML
- Hanya bisa dibaca sekali, simpan ke variabel jika perlu
- Kombinasikan dengan `json_decode()` untuk API JSON
- Alternatif: `$HTTP_RAW_POST_DATA` sudah deprecated

## Contoh Kode (PHP)
```php
<?php
// Baca request body sebagai string
$rawBody = file_get_contents('php://input');

// Parse JSON
$data = json_decode($rawBody, true);

if (json_last_error() !== JSON_ERROR_NONE) {
    http_response_code(400);
    echo json_encode(['error' => 'JSON tidak valid']);
    exit;
}

echo json_encode([
    'method' => $_SERVER['REQUEST_METHOD'],
    'data' => $data
], JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);

// Contoh request dengan cURL:
// curl -X POST http://localhost/api.php \
//   -H "Content-Type: application/json" \
//   -d '{"nama":"John","email":"john@test.com"}'

// Baca XML
$xmlBody = file_get_contents('php://input');
$xml = simplexml_load_string($xmlBody);
echo "Nama: " . $xml->nama;
?>
```

## Kasus Penggunaan Nyata
Menerima data JSON dari frontend SPA (React/Vue), menerima webhook dari payment gateway, menerima data dari aplikasi mobile.
