# 264. Redirect Header Location

## Definisi Singkat
Redirect menggunakan header `Location` memberitahu browser untuk pindah ke URL lain. Server mengirim status code 301 (permanen) atau 302 (sementara) bersama header Location.

## Analogi
Seperti petugas yang memberi tahu: "Maaf, kantor pindah ke alamat baru ini." (301) atau "Untuk sementara, silakan ke cabang sebelah." (302).

## Poin-Poin Penting
- Gunakan `header('Location: URL')` lalu `exit` untuk menghentikan eksekusi
- Status code default adalah 302 (sementara)
- Gunakan `http_response_code(301)` untuk redirect permanen
- Selalu panggil `exit` atau `die` setelah redirect
- URL bisa absolut atau relatif
- 301 untuk perubahan URL permanen, 302 untuk sementara

## Contoh Kode (PHP)
```php
<?php
// Redirect sederhana (302 Found)
header('Location: /dashboard.php');
exit;

// Redirect permanen (301 Moved Permanently)
http_response_code(301);
header('Location: https://situsbaru.com/profile');
exit;

// Redirect dengan delay
header('Refresh: 3; url=/login.php');
echo "Anda akan dialihkan ke halaman login dalam 3 detik...";

// Conditional redirect
if (!isset($_SESSION['user'])) {
    header('Location: /login.php');
    exit;
}

// Redirect ke URL dengan query params
$id = 123;
header('Location: /post.php?id=' . urlencode($id) . '&status=success');
exit;
?>
```

## Kasus Penggunaan Nyata
Redirect setelah login sukses, redirect setelah form submission (PRG pattern), redirect dari HTTP ke HTTPS, redirect domain lama ke baru.
