# 267. Response JSON json_encode

## Definisi Singkat
`json_encode()` mengubah array atau object PHP menjadi string JSON. Ini adalah format standar untuk response API modern karena ringan dan mudah dibaca berbagai bahasa.

## Analogi
Seperti menerjemahkan bahasa Indonesia ke bahasa Inggris menggunakan kamus. `json_encode` adalah penerjemah yang mengubah struktur data PHP (array/object) ke format JSON universal.

## Poin-Poin Penting
- `json_encode($data, $options, $depth)` mengembalikan string JSON
- Gunakan `JSON_PRETTY_PRINT` untuk output rapi (development)
- Gunakan `JSON_UNESCAPED_UNICODE` untuk karakter UTF-8
- Gunakan `JSON_NUMERIC_CHECK` untuk angka numerik
- `JSON_HEX_TAG`, `JSON_HEX_AMP` untuk keamanan XSS
- Selalu set header `Content-Type: application/json` sebelum output
- Handle error dengan `json_last_error_msg()`

## Contoh Kode (PHP)
```php
<?php
header('Content-Type: application/json; charset=utf-8');

$data = [
    'status' => 'success',
    'data' => [
        'id' => 1,
        'nama' => 'John Doe',
        'email' => 'john@example.com',
        'umur' => 30,
        'hobi' => ['membaca', 'coding', 'gaming']
    ]
];

echo json_encode($data, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);

// Output:
// {
//     "status": "success",
//     "data": {
//         "id": 1,
//         "nama": "John Doe",
//         "email": "john@example.com",
//         "umur": 30,
//         "hobi": ["membaca", "coding", "gaming"]
//     }
// }

// Handle error encoding
$failed = json_encode(mb_convert_encoding('Data', 'ISO-8859-1', 'UTF-8'));
if (json_last_error() !== JSON_ERROR_NONE) {
    http_response_code(500);
    echo json_encode(['error' => json_last_error_msg()']);
}
?>
```

## Kasus Penggunaan Nyata
Semua API RESTful modern mengirim response dalam format JSON, dari data pengguna, daftar produk, hingga pesan error.
