# 269. getallheaders baca request headers

## Definisi Singkat
`getallheaders()` adalah fungsi PHP yang mengembalikan semua HTTP request headers dari request saat ini sebagai array asosiatif. Berguna untuk membaca token, User-Agent, Content-Type, dan header kustom.

## Analogi
Seperti melihat semua stiker dan label di sebuah paket sebelum membukanya. Header adalah informasi luar yang memberi tahu Anda tentang pengirim, jenis isi, dan instruksi khusus.

## Poin-Poin Penting
- Fungsi ini tersedia di SAPI Apache dan Nginx (melalui PHP-FPM)
- Untuk server lain, bisa menggunakan `$_SERVER` dengan prefiks `HTTP_`
- Case-insensitive (nama header akan dikembalikan dengan kapitalisasi asli)
- Alternatif: `apache_request_headers()` (sama)
- Header kustom seperti `X-API-Key` juga terbaca

## Contoh Kode (PHP)
```php
<?php
// Mendapatkan semua headers
$headers = getallheaders();

// Cetak semua headers
echo json_encode($headers, JSON_PRETTY_PRINT);

// Membaca header spesifik
$authToken = $headers['Authorization'] ?? '';
$userAgent = $headers['User-Agent'] ?? '';
$contentType = $headers['Content-Type'] ?? '';

echo "Token: " . $authToken . "\n";
echo "Browser: " . $userAgent . "\n";

// Fallback jika getallheaders tidak tersedia
if (!function_exists('getallheaders')) {
    function getallheaders() {
        $headers = [];
        foreach ($_SERVER as $name => $value) {
            if (strpos($name, 'HTTP_') === 0) {
                $name = str_replace('_', '-', substr($name, 5));
                $headers[$name] = $value;
            }
        }
        return $headers;
    }
}
?>
```

## Kasus Penggunaan Nyata
Membaca Bearer token untuk autentikasi API, membaca User-Agent untuk analitik, membaca header kustom untuk versioning API.
