# 263. header() kirim HTTP header

## Definisi Singkat
Fungsi `header()` di PHP digunakan untuk mengirim HTTP header mentah ke klien. Header harus dikirim sebelum output apapun, atau menggunakan output buffering.

## Analogi
Seperti amplop surat: sebelum memasukkan surat (body), Anda menulis alamat dan informasi di amplop (header). Jika surat sudah dimasukkan, Anda tidak bisa mengubah amplop lagi.

## Poin-Poin Penting
- `header()` harus dipanggil sebelum ada output (echo, HTML, whitespace)
- Gunakan `ob_start()` untuk output buffering jika terpaksa
- Header yang sama bisa dioverride dengan memanggil `header()` lagi
- Gunakan parameter `replace` (default true) atau `false` untuk header ganda
- `header_remove()` untuk menghapus header yang sudah diset

## Contoh Kode (PHP)
```php
<?php
// Redirect
header('Location: /dashboard.php');
exit;

// Set cookie
header('Set-Cookie: session_id=abc123; HttpOnly; Secure');

// Cache control
header('Cache-Control: no-cache, must-revalidate');
header('Expires: Sat, 26 Jul 1997 05:00:00 GMT');

// Download file
header('Content-Type: application/pdf');
header('Content-Disposition: attachment; filename="laporan.pdf"');
header('Content-Length: ' . filesize('file.pdf'));
readfile('file.pdf');

// Custom header
header('X-API-Version: 2.0');

// Multiple header dengan key sama (replace false)
header('Set-Cookie: flavor=chocolate', false);
header('Set-Cookie: size=large', false);
?>
```

## Kasus Penggunaan Nyata
Redirect setelah form submit, mengirim file untuk di-download, mengatur cache browser, mengirim response JSON dengan header yang tepat.
