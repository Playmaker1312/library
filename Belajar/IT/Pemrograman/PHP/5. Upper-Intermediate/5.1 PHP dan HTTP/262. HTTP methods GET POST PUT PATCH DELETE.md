# 262. HTTP Methods GET POST PUT PATCH DELETE

## Definisi Singkat
HTTP methods (atau HTTP verbs) adalah aksi yang ingin dilakukan klien terhadap resource di server. Yang paling umum: GET (membaca), POST (membuat), PUT (mengganti), PATCH (mengubah sebagian), DELETE (menghapus).

## Analogi
Seperti perpustakaan: GET = melihat buku, POST = menambah buku baru, PUT = mengganti buku dengan versi baru total, PATCH = memperbaiki satu halaman rusak, DELETE = menghapus buku dari rak.

## Poin-Poin Penting
- **GET**: idempotent, aman, tidak mengubah data, data di URL (query string)
- **POST**: tidak idempotent, membuat resource baru, data di body
- **PUT**: idempotent, mengganti seluruh resource
- **PATCH**: tidak harus idempotent, mengubah sebagian resource
- **DELETE**: idempotent, menghapus resource
- GET tidak boleh memiliki body request

## Contoh Kode (PHP)
```php
<?php
$method = $_SERVER['REQUEST_METHOD'];

switch ($method) {
    case 'GET':
        echo "Membaca data";
        break;
    case 'POST':
        $data = json_decode(file_get_contents('php://input'), true);
        echo "Membuat resource baru: " . json_encode($data);
        break;
    case 'PUT':
        $data = json_decode(file_get_contents('php://input'), true);
        echo "Mengganti seluruh resource";
        break;
    case 'PATCH':
        $data = json_decode(file_get_contents('php://input'), true);
        echo "Mengubah sebagian resource";
        break;
    case 'DELETE':
        echo "Menghapus resource";
        break;
    default:
        http_response_code(405);
        echo "Method not allowed";
}
?>
```

## Kasus Penggunaan Nyata
GET untuk mengambil daftar pengguna, POST untuk mendaftarkan pengguna baru, PUT untuk update profil lengkap, PATCH untuk ganti password saja, DELETE untuk hapus akun.
