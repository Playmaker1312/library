# 261. Protokol HTTP Request Response Header Body

## Definisi Singkat
HTTP (Hypertext Transfer Protocol) adalah protokol komunikasi antara klien (browser) dan server. Setiap interaksi terdiri dari **request** (permintaan) dan **response** (respons), masing-masing memiliki **header** (metadata) dan **body** (data).

## Analogi
Seperti memesan makanan di restoran: request = pesanan Anda, header = informasi tambahan (meja, alergi), body = isi pesanan. Response = makanan yang disajikan, header = informasi hidangan, body = makanannya.

## Poin-Poin Penting
- Request terdiri dari: method, URL, headers, body (opsional)
- Response terdiri dari: status code, headers, body
- Header berisi metadata seperti Content-Type, Authorization, User-Agent
- Body berisi data aktual (JSON, form data, file)
- HTTP/1.1 dan HTTP/2 adalah versi yang paling umum

## Contoh Kode (PHP)
```php
<?php
// Melihat request headers
echo "Method: " . $_SERVER['REQUEST_METHOD'] . "\n";
echo "URI: " . $_SERVER['REQUEST_URI'] . "\n";
echo "Content-Type: " . ($_SERVER['CONTENT_TYPE'] ?? 'tidak ada') . "\n";

// Body request POST
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $body = file_get_contents('php://input');
    echo "Body: " . $body . "\n";
}

// Mengirim response header
header('Content-Type: text/plain; charset=utf-8');
header('X-Powered-By: PHP');

// Response body
echo "Ini adalah response body\n";
?>
```

## Kasus Penggunaan Nyata
Setiap komunikasi antara browser dan web server, API RESTful, dan web service menggunakan protokol HTTP.
