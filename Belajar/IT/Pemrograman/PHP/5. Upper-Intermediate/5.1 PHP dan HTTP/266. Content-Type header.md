# 266. Content-Type Header

## Definisi Singkat
Header `Content-Type` memberi tahu klien/server jenis data yang dikirim. Format: `type/subtype; charset=utf-8`. Server menggunakannya untuk parsing body, klien untuk rendering response.

## Analogi
Seperti label pada wadah makanan: "Isi: Nasi Goreng" (Content-Type: application/json) atau "Isi: Jus" (Content-Type: text/html). Label membantu penerima tahu cara memproses isinya.

## Poin-Poin Penting
- `application/json`: data JSON
- `application/x-www-form-urlencoded`: form biasa
- `multipart/form-data`: form dengan file upload
- `text/html`: halaman HTML
- `text/plain`: teks biasa
- `application/pdf`: file PDF
- `image/jpeg`, `image/png`: gambar
- Untuk response JSON, kirim `Content-Type: application/json`
- Fungsi `json_encode()` otomatis mengatur encoding karakter

## Contoh Kode (PHP)
```php
<?php
// Response JSON
header('Content-Type: application/json; charset=utf-8');
echo json_encode(['nama' => 'John', 'umur' => 30]);

// Response HTML
header('Content-Type: text/html; charset=utf-8');
echo '<h1>Halo Dunia</h1>';

// Response plain text
header('Content-Type: text/plain; charset=utf-8');
echo 'Ini teks biasa';

// Response XML
header('Content-Type: application/xml; charset=utf-8');
echo '<?xml version="1.0"?><root><item>data</item></root>';

// File download PDF
header('Content-Type: application/pdf');
header('Content-Disposition: attachment; filename="dokumen.pdf"');
readfile('file.pdf');

// Deteksi Content-Type dari form
if ($_SERVER['CONTENT_TYPE'] === 'application/json') {
    $data = json_decode(file_get_contents('php://input'), true);
} else {
    $data = $_POST;
}
?>
```

## Kasus Penggunaan Nyata
Mengirim response JSON dari API, menampilkan halaman HTML, mengirim gambar dari script PHP, menentukan cara parsing request body.
