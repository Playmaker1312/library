# 313. require-dev Dependency Development

## Definisi Singkat
`require-dev` adalah section di `composer.json` untuk dependencies yang hanya dibutuhkan saat development (testing, debugging, coding standard), bukan di production.

## Analogi
Seperti peralatan tukang: `require` = peralatan utama (palu, obeng) yang dibawa ke lokasi kerja. `require-dev` = alat ukur presisi, level, dan meteran yang hanya dipakai di bengkel, tidak perlu dibawa ke lapangan.

## Poin-Poin Penting
- `require-dev` tidak diinstall dengan `composer install --no-dev`
- Gunakan untuk: PHPUnit, PHPStan, PHPCS, debug tools
- Hemat ruang dan keamanan di production
- Tambah dengan `composer require --dev <package>`
- Hapus dengan `composer remove --dev <package>`
- Bisa juga untuk faker, factory, migration tools

## Contoh Kode (PHP)
```php
<?php
// composer.json dengan require-dev
$composerJson = [
    'name' => 'perusahaan/aplikasi-ku',
    'require' => [
        'php' => '>=8.1',
        'monolog/monolog' => '^3.0',
        'vlucas/phpdotenv' => '^5.5',
        'guzzlehttp/guzzle' => '^7.0'
    ],
    'require-dev' => [
        'phpunit/phpunit' => '^10.0',
        'phpstan/phpstan' => '^1.10',
        'squizlabs/php_codesniffer' => '^3.7',
        'laravel/sail' => '^1.0',
        'fakerphp/faker' => '^1.20',
        'barryvdh/laravel-debugbar' => '^3.8'
    ]
];

echo "Production dependencies:\n";
foreach ($composerJson['require'] as $pkg => $ver) {
    echo "  $pkg: $ver\n";
}

echo "\nDevelopment dependencies:\n";
foreach ($composerJson['require-dev'] as $pkg => $ver) {
    echo "  $pkg: $ver\n";
}

echo "\n\nCara install:\n";
echo "composer install              # install semua (dev + prod)\n";
echo "composer install --no-dev     # hanya production\n\n";

echo "Cara menambah/menghapus:\n";
echo "composer require --dev phpunit/phpunit ^10.0\n";
echo "composer remove --dev phpstan/phpstan\n\n";

echo "Manfaat:\n";
echo "- Production lebih ringan\n";
echo "- Tidak ada tools debugging di production\n";
echo "- Keamanan lebih baik (tools testing tidak ter-expose)\n";
?>
```

## Kasus Penggunaan Nyata
Production server hanya butuh library fungsional, development membutuhkan testing tools, code quality tools, debug bar, dan code generators.
