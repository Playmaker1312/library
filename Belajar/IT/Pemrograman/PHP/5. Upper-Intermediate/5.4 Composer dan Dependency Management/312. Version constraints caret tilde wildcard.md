# 312. Version Constraints Caret Tilde Wildcard

## Definisi Singkat
Version constraints di Composer menentukan versi package mana yang boleh diinstall. Operator `^` (caret), `~` (tilde), `*` (wildcard), dan lainnya memberikan fleksibilitas dalam update.

## Analogi
Seperti aturan belanja: `^1.2.3` = "beli jaket versi 1.x.x, minimal 1.2.3, boleh upgrade minor/patch" (caret). `~1.2.3` = "beli jaket versi 1.2.x, minimal 1.2.3, hanya upgrade patch" (tilde). `1.*` = "beli jaket versi 1.x.x" (wildcard).

## Poin-Poin Penting
- **`^1.2.3`** (Caret): >=1.2.3, <2.0.0 (kompatibel major)
- **`~1.2.3`** (Tilde): >=1.2.3, <1.3.0 (hanya patch)
- **`~1.2`** (Tilde): >=1.2.0, <2.0.0
- **`1.*`** (Wildcard): >=1.0.0, <2.0.0
- **`>=1.2`**: >=1.2.0
- **`1.2.3`**: exact version
- **`>=1.2,<1.5`**: range

## Contoh Kode (PHP)
```php
<?php
$examples = [
    '^1.2.3' => [
        'description' => 'Caret: kompatibel major',
        'matching' => ['1.2.3', '1.3.0', '1.9.9'],
        'not_matching' => ['2.0.0', '0.1.0']
    ],
    '~1.2.3' => [
        'description' => 'Tilde: hanya patch update',
        'matching' => ['1.2.3', '1.2.4', '1.2.99'],
        'not_matching' => ['1.3.0', '2.0.0']
    ],
    '~1.2' => [
        'description' => 'Tilde: minor dan patch',
        'matching' => ['1.2.0', '1.9.9'],
        'not_matching' => ['2.0.0']
    ],
    '1.*' => [
        'description' => 'Wildcard: semua 1.x',
        'matching' => ['1.0.0', '1.5.6', '1.9.9'],
        'not_matching' => ['2.0.0', '0.9.9']
    ],
    '>=1.5' => [
        'description' => 'Minimal versi',
        'matching' => ['1.5.0', '2.0.0', '3.0.0'],
        'not_matching' => ['1.4.9']
    ],
    '1.2.*' => [
        'description' => 'Wildcard patch',
        'matching' => ['1.2.0', '1.2.1', '1.2.99'],
        'not_matching' => ['1.3.0']
    ],
];

echo json_encode($examples, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);

echo "\n\nRekomendasi:\n";
echo "Production: ^1.2.3 (caret) - aman untuk update minor/patch\n";
echo "Library: ^1.0 - fleksibel untuk downstream\n";
echo "Ketat: ~1.2.3 - kendali ketat hanya patch update\n";
echo "Hindari: * - terlalu longgar\n";
?>
```

## Kasus Penggunaan Nyata
Menentukan dependency di `composer.json` untuk aplikasi dan library, menjaga kompatibilitas sambil mendapatkan patch keamanan.
