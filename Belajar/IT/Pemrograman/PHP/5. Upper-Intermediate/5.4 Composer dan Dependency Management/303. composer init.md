# 303. composer init

## Definisi Singkat
`composer init` adalah perintah interaktif untuk membuat file `composer.json` baru. Perintah ini memandu Anda mengisi informasi proyek seperti nama, deskripsi, author, dan dependencies awal.

## Analogi
Seperti mengisi formulir pendaftaran proyek: Anda memberikan nama proyek, deskripsi singkat, siapa pembuatnya, dan library apa yang akan digunakan. Formulir ini menjadi identitas proyek Anda.

## Poin-Poin Penting
- Jalankan `composer init` di root direktori proyek
- Isi: nama proyek (`vendor/package`), deskripsi, author
- Tentukan stability: stable, RC, beta, alpha, dev
- Tentukan license (MIT, Apache-2.0, GPL, dll)
- Define PSR-4 autoloading
- Hasil akhir: file `composer.json` yang valid

## Contoh Kode (PHP)
```php
<?php
// Hasil dari composer init (composer.json)
$composerJson = [
    'name' => 'perusahaan/aplikasi-ku',
    'description' => 'Aplikasi web manajemen inventaris',
    'type' => 'project',
    'require' => [
        'php' => '>=8.1',
        'monolog/monolog' => '^3.0',
        'vlucas/phpdotenv' => '^5.5'
    ],
    'require-dev' => [
        'phpunit/phpunit' => '^10.0'
    ],
    'autoload' => [
        'psr-4' => [
            'App\\' => 'src/'
        ]
    ],
    'authors' => [
        [
            'name' => 'Nama Developer',
            'email' => 'developer@perusahaan.com'
        ]
    ],
    'license' => 'MIT',
    'scripts' => [
        'start' => 'php -S localhost:8000 -t public',
        'test' => 'phpunit'
    ]
];

echo json_encode($composerJson, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);

// Cara menggunakan:
// Di terminal:
// cd project-directory
// composer init
//
// Anda akan ditanya:
// Package name (<vendor>/<name>) [user/project]: perusahaan/aplikasi-ku
// Description []: Aplikasi web manajemen inventaris
// Author [nama <email>]: Nama Developer <developer@perusahaan.com>
// Minimum Stability []: stable
// License []: MIT
// Define your dependencies: monolog/monolog ^3.0
// Define dev dependencies: phpunit/phpunit ^10.0
// PSR-4 autoload: App\ src/
?>
```

## Kasus Penggunaan Nyata
Memulai proyek PHP baru, menginisialisasi package untuk dipublikasikan ke Packagist, membuat proyek dengan standar konfigurasi.
