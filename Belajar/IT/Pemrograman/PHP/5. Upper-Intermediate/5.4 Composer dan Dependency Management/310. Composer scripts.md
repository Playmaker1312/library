# 310. Composer Scripts

## Definisi Singkat
Composer scripts adalah perintah kustom yang didefinisikan di `composer.json` yang bisa dijalankan via `composer run-script`. Berguna untuk task umum seperti testing, linting, atau build.

## Analogi
Seperti tombol shortcut di remote TV: Anda bisa memrogram "tombol 1" untuk channel berita (test), "tombol 2" untuk channel olahraga (lint). Cukup tekan satu tombol untuk menjalankan aksi yang kompleks.

## Poin-Poin Penting
- Definisi di `scripts` section `composer.json`
- Jalankan dengan `composer <script-name>` atau `composer run <script-name>`
- Pre-defined events: `pre-install-cmd`, `post-install-cmd`, `pre-update-cmd`, `post-update-cmd`
- Multiple commands dalam satu script
- Parameter `@composer` untuk memanggil perintah composer lain

## Contoh Kode (PHP)
```php
<?php
// composer.json scripts section
$scripts = [
    'scripts' => [
        // Basic scripts
        'test' => 'phpunit',
        'lint' => 'phpcs --standard=PSR12 src/',
        'stan' => 'phpstan analyse src/ --level=max',
        'check' => [
            '@lint',
            '@stan',
            '@test'
        ],

        // Development server
        'dev' => 'php -S localhost:8000 -t public/',

        // Clear cache
        'clear-cache' => 'rm -rf var/cache/*',

        // Event-based scripts
        'post-install-cmd' => [
            '@clear-cache',
            'php artisan migrate'
        ],
        'post-update-cmd' => [
            '@clear-cache'
        ],

        // Custom dengan description
        'seed' => [
            'description' => 'Seed database with sample data',
            'command' => 'php database/seed.php'
        ],

        // Production build
        'production-build' => [
            '@lint',
            '@test',
            'composer install --no-dev --optimize-autoloader',
            'php artisan optimize'
        ]
    ]
];

echo json_encode($scripts, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);

echo "\n\nCara menjalankan:\n";
echo "composer test        -> menjalankan phpunit\n";
echo "composer lint        -> menjalankan phpcs\n";
echo "composer check       -> menjalankan lint + stan + test\n";
echo "composer dev         -> menjalankan dev server\n";
echo "composer production-build -> build untuk production\n";

// Contoh script handler di PHP
echo "\n\nScript kustom juga bisa ditulis di file PHP:\n";
echo '#!/usr/bin/env php
<?php
// scripts/deploy.php
echo "Deploying application...\n";
// logic deploy
';
?>
```

## Kasus Penggunaan Nyata
Menstandarisasi perintah development di tim, CI/CD pipeline, otomatisasi task (migrasi, seed, clear cache), build untuk production.
