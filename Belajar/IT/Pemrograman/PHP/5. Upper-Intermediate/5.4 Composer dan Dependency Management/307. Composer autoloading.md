# 307. Composer Autoloading

## Definisi Singkat
Composer autoloading adalah mekanisme yang secara otomatis memuat file class PHP saat diperlukan, tanpa harus `require` manual. Cukup include `vendor/autoload.php` dan semua class tersedia.

## Analogi
Seperti asisten pribadi yang tahu di mana setiap barang disimpan. Anda cukup bilang "Saya butuh Palu" (class `Hammer`), asisten langsung mengambil dari tempat yang tepat tanpa Anda harus tahu di mana lokasinya.

## Poin-Poin Penting
- `require_once 'vendor/autoload.php'` memuat semua class
- Mendukung PSR-4, PSR-0, classmap, dan file files
- PSR-4: namespace mapping ke direktori
- Classmap: daftar class explicit (lebih cepat)
- Files: muat file tertentu selalu (untuk helper functions)
- Autoloading memuat class saat pertama kali digunakan (lazy loading)

## Contoh Kode (PHP)
```php
<?php
// Ini saja yang diperlukan untuk memuat semua class!
require_once 'vendor/autoload.php';

// Tanpa autoloading, Anda perlu:
// require_once 'src/Controllers/UserController.php';
// require_once 'src/Models/User.php';
// require_once 'vendor/monolog/monolog/src/Monolog/Logger.php';

// Dengan autoloading, cukup:
use App\Controllers\UserController;
use App\Models\User;
use Monolog\Logger;

$controller = new UserController();
$user = new User();
$log = new Logger('app');

echo "Semua class termuat otomatis!\n";

// Konfigurasi autoloading di composer.json:
$composerAutoload = [
    'autoload' => [
        'psr-4' => [
            'App\\' => 'src/',
            'App\\Models\\' => 'src/Models/',
            'App\\Controllers\\' => 'src/Controllers/',
        ],
        'classmap' => [
            'src/Legacy/SomeOldClass.php',
            'lib/',
        ],
        'files' => [
            'src/helpers.php',
            'src/constants.php',
        ]
    ]
];

echo json_encode($composerAutoload, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);

// Setelah mengubah autoload di composer.json, jalankan:
// composer dump-autoload
// untuk meregenerasi autoloader
?>
```

## Kasus Penggunaan Nyata
Semua aplikasi PHP modern menggunakan Composer autoloading untuk memuat kode aplikasi dan dependencies secara otomatis.
