# 305. composer.json composer.lock

## Definisi Singkat
`composer.json` mendefinisikan dependencies dan konfigurasi proyek secara deklaratif (dengan version constraints). `composer.lock` mengunci versi exact yang terinstall untuk memastikan semua lingkungan menggunakan versi yang sama.

## Analogi
`composer.json` seperti resep masakan: "telur 2-3 butir, tepung 200-250gr" (version constraint). `composer.lock` seperti resep exact: "telur ukuran besar 2 butir, tepung segitiga biru 225gr" (fixed version). Koki lain yang menggunakan resep exact akan menghasilkan masakan yang sama persis.

## Poin-Poin Penting
- `composer.json` di-commit ke git (definisi proyek)
- `composer.lock` juga di-commit (reproducible build)
- Version constraint: `^1.0` (>=1.0 <2.0), `~1.2` (>=1.2 <1.3), `1.*`
- `require` vs `require-dev` untuk production vs development
- Jangan edit `composer.lock` manual
- `composer.lock` dibuat/diupdate oleh `composer install` / `composer update`

## Contoh Kode (PHP)
```php
<?php
// Contoh isi composer.json
$composerJson = [
    'name' => 'perusahaan/aplikasi-ku',
    'description' => 'Aplikasi inventaris',
    'require' => [
        'php' => '>=8.1',
        'monolog/monolog' => '^3.0',
        'vlucas/phpdotenv' => '^5.5',
        'guzzlehttp/guzzle' => '^7.0',
        'firebase/php-jwt' => '^6.0'
    ],
    'require-dev' => [
        'phpunit/phpunit' => '^10.0',
        'squizlabs/php_codesniffer' => '^3.7',
        'phpstan/phpstan' => '^1.10'
    ],
    'autoload' => [
        'psr-4' => [
            'App\\' => 'src/'
        ]
    ],
    'config' => [
        'optimize-autoloader' => true,
        'sort-packages' => true
    ]
];

echo "composer.json (deklaratif):\n";
echo json_encode($composerJson, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);

echo "\n\ncomposer.lock (berisi versi exact):\n";
echo json_encode([
    'packages' => [
        [
            'name' => 'monolog/monolog',
            'version' => '3.2.0',
            'source' => ['url' => 'https://github.com/Seldaek/monolog', 'type' => 'git', 'reference' => 'abc123...']
        ],
        [
            'name' => 'vlucas/phpdotenv',
            'version' => '5.5.0',
            'source' => ['url' => 'https://github.com/vlucas/phpdotenv', 'type' => 'git', 'reference' => 'def456...']
        ]
    ],
    'platform' => ['php' => '8.2.10']
], JSON_PRETTY_PRINT);

echo "\n\nKeduanya WAJIB di-commit ke Git!";
?>
```

## Kasus Penggunaan Nyata
Semua proyek PHP modern dengan Composer; `composer.lock` memastikan tim dan server production menggunakan versi package yang identik.
