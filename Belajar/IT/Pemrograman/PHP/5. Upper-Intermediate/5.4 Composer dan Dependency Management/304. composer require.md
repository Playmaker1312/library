# 304. composer require

## Definisi Singkat
`composer require` adalah perintah untuk menambahkan library baru ke proyek. Perintah ini mengupdate `composer.json`, mengunduh package, dan registrasi autoloading secara otomatis.

## Analogi
Seperti memesan buku baru untuk perpustakaan: Anda memberi tahu pustakawan (composer) judul buku (package name), pustakawan memesannya, menambahkan ke katalog (composer.json update), dan menempatkannya di rak (vendor/).

## Poin-Poin Penting
- `composer require vendor/package` menambah dependency
- `composer require vendor/package --dev` untuk development saja
- Tambahkan version constraint: `composer require vendor/package ^2.0`
- Composer otomatis mengupdate `composer.json` dan `composer.lock`
- Package diunduh ke folder `vendor/`
- Register autoloading di `vendor/autoload.php`

## Contoh Kode (PHP)
```php
<?php
// Contoh penggunaan composer require

// 1. Menambah dependency production
// composer require monolog/monolog
// composer require guzzlehttp/guzzle ^7.0
// composer require "laravel/framework:^10.0"

// 2. Menambah dependency development (testing, debugging)
// composer require --dev phpunit/phpunit ^10.0
// composer require --dev laravel/sail
// composer require --dev --sort-packages

// 3. Menghapus dependency
// composer remove monolog/monolog
// composer remove --dev phpunit/phpunit

// 4. Install dari composer.json yang sudah ada (tanpa lock)
// composer install

require_once 'vendor/autoload.php';

// Contoh menggunakan library yang baru diinstall
// dari composer require guzzlehttp/guzzle
use GuzzleHttp\Client;

$client = new Client();
echo "Library Guzzle berhasil diinstall dan digunakan\n";

// Melihat daftar package yang terinstall
// composer show
// composer show --latest
// composer show monolog/monolog

// Mencari package:
// composer search logging
// composer search --only-name phpmailer
?>
```

## Kasus Penggunaan Nyata
Menambah library email (PHPMailer), HTTP client (Guzzle), debug bar, logger, framework, atau utility library ke proyek PHP.
