# 315. Production no-dev flag

## Definisi Singkat
`--no-dev` adalah flag Composer yang menginstal hanya production dependencies (dari `require`), mengabaikan `require-dev`. Ini mengoptimalkan performa, keamanan, dan ukuran deployment.

## Analogi
Seperti menyiapkan mobil balap: Anda melepas kursi penumpang, AC, dan radio (dev tools) untuk mengurangi berat (ukuran) dan meningkatkan performa. Hanya komponen esensial (mesin, roda) yang dibutuhkan untuk balapan (production) yang tersisa.

## Poin-Poin Penting
- `composer install --no-dev` tanpa development packages
- `composer install --no-dev -o` optimize autoloader juga
- `composer install --no-dev --optimize-autoloader --classmap-authoritative`
- Juga: `composer update --no-dev` (jarang)
- Kurangi ukuran vendor/ drastis
- Mencegah tools debugging ter-expose di production

## Contoh Kode (PHP)
```php
<?php
echo "=== Production Deployment dengan Composer ===\n\n";

// Contoh perbandingan
$devPackages = ['phpunit/phpunit', 'phpstan/phpstan', 'phpcs/phpcs', 'fakerphp/faker'];
$prodPackages = ['monolog/monolog', 'guzzlehttp/guzzle', 'vlucas/phpdotenv'];

echo "Production packages (" . count($prodPackages) . "):\n";
foreach ($prodPackages as $p) echo "  - $p\n";

echo "\nDev packages (" . count($devPackages) . "):\n";
foreach ($devPackages as $p) echo "  - $p\n";

echo "\n=== Perintah Deployment ===\n\n";

echo "Development (full install):\n";
echo "  composer install\n\n";

echo "Production:\n";
echo "  composer install --no-dev --optimize-autoloader\n\n";

echo "Production (maximum optimization):\n";
echo "  composer install \\\n";
echo "    --no-dev \\\n";
echo "    --optimize-autoloader \\\n";
echo "    --classmap-authoritative \\\n";
echo "    --no-interaction \\\n";
echo "    --prefer-dist\n\n";

echo "=== CI/CD Script Example ===\n";
echo 'deploy.php:
<?php
$commands = [
    "composer install --no-dev --optimize-autoloader --no-interaction --prefer-dist",
    "php artisan optimize",
    "php artisan config:cache",
    "php artisan route:cache",
    "php artisan view:cache",
];
foreach ($commands as $cmd) {
    echo "Running: $cmd\n";
    passthru($cmd);
}
';

echo "\n=== Manfaat ===\n";
echo "- Ukuran vendor/ lebih kecil (50-70% lebih sedikit)\n";
echo "- Loading lebih cepat dengan autoloader optimized\n";
echo "- Tools testing/debugging tidak ter-expose\n";
echo "- Tidak bisa menjalankan phpunit di production\n";
echo "- Lebih sedikit potensi serangan\n";
?>
```

## Kasus Penggunaan Nyata
Deployment ke production server, CI/CD pipeline, Docker image build, deployment ke shared hosting dengan storage terbatas.
