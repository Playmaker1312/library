# 311. Private Repository Composer

## Definisi Singkat
Private repository memungkinkan Composer menginstall package dari repository privat (GitHub private, GitLab, Bitbucket, atau self-hosted) tanpa dipublikasikan ke Packagist publik.

## Analogi
Seperti perpustakaan internal perusahaan: buku-buku rahasia hanya bisa diakses karyawan dengan kunci khusus (SSH key / token). Tidak dijual di toko buku umum (Packagist) tapi tetap terkelola rapi di rak internal.

## Poin-Poin Penting
- Dukung VCS: git, svn, mercurial
- Autentikasi via SSH key atau OAuth token
- Definisikan di `repositories` key di `composer.json`
- GitHub: `"type": "vcs", "url": "https://github.com/perusahaan/private-package"`
- Install tetap dengan `composer require perusahaan/private-package`
- Alternatif: Satis (self-hosted) atau Private Packagist

## Contoh Kode (PHP)
```php
<?php
// composer.json dengan private repository
$composerJson = [
    'name' => 'perusahaan/aplikasi-utama',
    'repositories' => [
        // Private GitHub repository
        [
            'type' => 'vcs',
            'url' => 'https://github.com/perusahaan/private-package.git'
        ],
        // Private GitLab repository
        [
            'type' => 'vcs',
            'url' => 'https://gitlab.perusahaan.com/backend/core-library.git'
        ],
        // Package path (local development)
        [
            'type' => 'path',
            'url' => '../packages/*'
        ],
        // Satis repository (self-hosted)
        [
            'type' => 'composer',
            'url' => 'https://satis.perusahaan.com'
        ]
    ],
    'require' => [
        'perusahaan/private-package' => '^1.0',
        'perusahaan/core-library' => '^2.0'
    ]
];

echo json_encode($composerJson, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);

echo "\n\n=== Autentikasi ===\n";
echo "Untuk GitHub: buat Personal Access Token\n";
echo "Simpan di auth.json (jangan di-commit):\n";
echo json_encode([
    'http-basic' => [
        'github.com' => [
            'username' => 'token',
            'password' => 'ghp_xxxxxxxxxxxx'
        ]
    ]
], JSON_PRETTY_PRINT);

echo "\n\nAtau via environment variable:\n";
echo "COMPOSER_AUTH='{\"github-oauth\":{\"github.com\":\"ghp_xxx\"}}'\n";

echo "\n\n=== auth.json (jangan di-commit, tambah ke .gitignore) ===\n";
echo '{
    "github-oauth": {
        "github.com": "ghp_xxxxxxxxxxxx"
    },
    "gitlab-oauth": {
        "gitlab.perusahaan.com": "glpat_xxxx"
    }
}';
?>
```

## Kasus Penggunaan Nyata
Package internal perusahaan yang tidak boleh publik, shared library antar tim, plugin/proprietary code untuk klien.
