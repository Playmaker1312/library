# 314. composer dump-autoload

## Definisi Singkat
`composer dump-autoload` (atau `composer dumpautoload`) meregenerasi file autoloader tanpa mengunduh ulang packages. Berguna setelah menambah class baru, mengubah namespace, atau mapping autoload.

## Analogi
Seperti memperbarui daftar isi buku: Anda menambah bab baru (class baru) atau memindahkan bab (namespace baru). Pustakawan (Composer) perlu memperbarui daftar isi agar pembaca bisa menemukan bab dengan cepat, tanpa menulis ulang seluruh buku.

## Poin-Poin Penting
- Regenerasi `vendor/autoload.php` dan file pendukung
- Tidak mengunduh packages (hanya rebuild autoloader)
- Jalankan setelah menambah class tanpa namespace PSR-4 baru
- `composer dump-autoload -o` optimize: buat classmap untuk faster loading
- `composer dump-autoload --no-dev` tanpa dev autoloading
- Berguna saat classmap atau files autoload berubah

## Contoh Kode (PHP)
```php
<?php
echo "=== composer dump-autoload ===\n\n";

echo "Kapan harus menjalankan:\n";
echo "1. Menambah class baru di namespace baru\n";
echo "2. Mengubah mapping autoload di composer.json\n";
echo "3. Menambah file di 'files' autoload\n";
echo "4. Mengubah classmap\n";
echo "5. Switching antara environment (dev vs prod)\n\n";

echo "Perintah:\n";
echo "composer dump-autoload              # regenerate standar\n";
echo "composer dump-autoload -o           # optimize (classmap)\n";
echo "composer dump-autoload --no-dev     # tanpa dev autoload\n";
echo "composer dump-autoload -a           # classmap + authoritative\n\n";

// Simulasi perubahan autoload
$oldAutoload = [
    'psr-4' => ['App\\' => 'src/']
];

$newAutoload = [
    'psr-4' => [
        'App\\' => 'src/',
        'App\\Services\\' => 'src/Services/'  // namespace baru
    ],
    'files' => [
        'src/helpers.php'  // file baru
    ]
];

echo "Old autoload:\n";
echo json_encode($oldAutoload, JSON_PRETTY_PRINT);
echo "\n\nNew autoload:\n";
echo json_encode($newAutoload, JSON_PRETTY_PRINT);
echo "\n\nAction: composer dump-autoload\n";
echo "Autoloader diregenerasi dengan mapping baru.\n";

// Test autoloader
echo "\nTest autoloader:\n";
echo '$loader = require "vendor/autoload.php";' . "\n";
echo '// Class App\Services\MailService sekarang bisa digunakan' . "\n";
?>
```

## Kasus Penggunaan Nyata
Setiap kali struktur direktori/namespace berubah, deployment ke production dengan autoloader optimized, development cycle dengan penambahan class baru.
