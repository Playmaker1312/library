# 301. Composer Ekosistem PHP

## Definisi Singkat
Composer adalah dependency manager untuk PHP yang mengelola library/packages pihak ketiga. Composer membaca file `composer.json` dan mengunduh semua dependencies yang dibutuhkan proyek Anda.

## Analogi
Seperti manajer toko: Anda memberi daftar belanja (composer.json), manajer mengambil barang dari gudang (Packagist), menata di rak (vendor/), dan membuat catatan barang apa yang ada (composer.lock).

## Poin-Poin Penting
- Composer = npm untuk JavaScript, pip untuk Python
- Package dihosting di Packagist (packagist.org)
- Dependencies disimpan di folder `vendor/`
- Autoloading otomatis dengan `vendor/autoload.php`
- `composer.json` mendefinisikan dependencies
- `composer.lock` mengunci versi exact untuk reproducibility

## Contoh Kode (PHP)
```php
<?php
// Sebelum Composer: include manual
// require_once 'lib/PHPMailer/src/PHPMailer.php';
// require_once 'lib/PHPMailer/src/SMTP.php';
// require_once 'lib/PHPMailer/src/Exception.php';

// Sesudah Composer: autoload otomatis
require_once 'vendor/autoload.php';

// Composer mengelola semua dependency
use Monolog\Logger;
use Monolog\Handler\StreamHandler;
use Carbon\Carbon;

// Contoh menggunakan package dari Composer
$log = new Logger('app');
$log->pushHandler(new StreamHandler('app.log', Logger::WARNING));
$log->warning('Ini pesan warning');

echo "Sekarang: " . Carbon::now()->format('d/m/Y H:i:s') . "\n";
echo "Composer memudahkan manajemen library PHP\n";

// Struktur folder setelah Composer:
// project/
// ├── composer.json
// ├── composer.lock
// ├── vendor/
// │   ├── autoload.php
// │   ├── monolog/
// │   ├── carbon/
// │   └── ...
// └── src/
//     └── App.php
?>
```

## Kasus Penggunaan Nyata
Semua proyek PHP modern menggunakan Composer untuk mengelola dependencies seperti framework (Laravel, Symfony), logging, email, database, dan utility library.
