# 306. composer update

## Definisi Singkat
`composer update` memperbarui semua dependencies ke versi terbaru sesuai constraint di `composer.json`, lalu menulis versi exact yang terinstall ke `composer.lock`.

## Analogi
Seperti "belanja bulanan" menggunakan resep fleksibel: "beli keju merk apa saja, jenis apapun (sesuai constraint)". Composer mencari versi terbaru yang cocok, membelinya, dan mencatat merk serta jenis pastinya di struk (composer.lock).

## Poin-Poin Penting
- `composer update` update semua package
- `composer update monolog/monolog` update package spesifik
- Jangan jalankan `composer update` di production (gunakan `composer install`)
- Commit `composer.lock` setelah update
- `composer update --dry-run` lihat perubahan tanpa eksekusi
- `composer update --with-dependencies` update dependency tree

## Contoh Kode (PHP)
```php
<?php
echo "=== Perbedaan composer install vs update ===\n\n";

echo "composer install:\n";
echo "- Membaca composer.lock (jika ada)\n";
echo "- Install versi EXACT dari lock file\n";
echo - "Aman dijalankan di production\n";
echo "- Jika lock tidak ada, buat dari composer.json\n\n";

echo "composer update:\n";
echo "- MENGABAIKAN composer.lock\n";
echo "- Mencari VERSI TERBARU sesuai composer.json\n";
echo "- Menulis versi baru ke composer.lock\n";
echo "- HANYA untuk development / upgrade\n\n";

echo "=== Contoh skenario ===\n";
echo "Saat ini: monolog/monolog ^3.0 terinstall versi 3.1.0\n";
echo "Rilis 3.2.0:\n";
echo "  composer install -> tetap 3.1.0 (mengikuti lock)\n";
echo "  composer update -> upgrade ke 3.2.0\n\n";

// Simulasi perubahan composer.lock
$oldLock = ['monolog/monolog' => '3.1.0'];
$newLock = ['monolog/monolog' => '3.2.0'];

echo "Old lock: " . json_encode($oldLock) . "\n";
echo "New lock: " . json_encode($newLock) . "\n";
echo "Action: composer update monolog/monolog\n";

// Best practice:
echo "\n=== Best Practice ===\n";
echo "Development: composer update -> test -> commit composer.lock\n";
echo "CI/CD: composer install\n";
echo "Production: composer install --no-dev --optimize-autoloader\n";
?>
```

## Kasus Penggunaan Nyata
Upgrade dependencies ke versi terbaru, menarik patch keamanan, development environment untuk mendapatkan update terbaru.
