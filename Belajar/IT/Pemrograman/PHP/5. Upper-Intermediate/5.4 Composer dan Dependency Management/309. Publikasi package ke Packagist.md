# 309. Publikasi Package ke Packagist

## Definisi Singkat
Packagist adalah repository utama untuk package PHP Composer. Mempublikasikan package memungkinkan developer lain menginstall library Anda via `composer require`.

## Analogi
Seperti membuka toko di pasar: Anda menyiapkan produk (kode), memberi label dan harga (composer.json), membuka stan (publish ke Packagist), dan pembeli bisa membeli (composer require) produk Anda.

## Poin-Poin Penting
- Pastikan nama package unik (`vendor/package`)
- Package membutuhkan file `composer.json` yang valid
- Repository harus publik di GitHub/GitLab/Bitbucket
- Daftar akun di https://packagist.org
- Submit URL repository GitHub ke Packagist
- Set webhook GitHub-Packagist untuk auto-update
- Ikuti semver (Major.Minor.Patch)
- Tag rilis di Git untuk versi

## Contoh Kode (PHP)
```php
<?php
// Contoh struktur package yang siap publikasi
$packageStructure = [
    'composer.json' => json_encode([
        'name' => 'nama-vendor/package-ku',
        'description' => 'Deskripsi package',
        'type' => 'library',
        'license' => 'MIT',
        'autoload' => [
            'psr-4' => [
                'NamaVendor\\PackageKu\\' => 'src/'
            ]
        ],
        'require' => [
            'php' => '>=8.1'
        ],
        'require-dev' => [
            'phpunit/phpunit' => '^10.0'
        ],
        'authors' => [
            [
                'name' => 'Nama Author',
                'email' => 'author@email.com'
            ]
        ],
        'minimum-stability' => 'stable',
    ], JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE),
];

// Langkah-langkah publikasi:
echo "1. Buat repository GitHub dengan kode package\n";
echo "2. Buat composer.json dengan namespace PSR-4\n";
echo "3. Push kode ke GitHub\n";
echo "4. Buat tag rilis: git tag v1.0.0 && git push origin v1.0.0\n";
echo "5. Daftar di https://packagist.org/packages/submit\n";
echo "6. Submit URL GitHub\n";
echo "7. Setup webhook GitHub -> Packagist untuk auto-update\n\n";

echo "Setelah publish, developer lain bisa:\n";
echo "composer require nama-vendor/package-ku\n\n";

// Contoh implementasi minimal package
echo "=== File minimal package ===\n";
echo "src/Hello.php:\n";
echo '<?php
namespace NamaVendor\PackageKu;

class Hello
{
    public function say(string $name): string
    {
        return "Hello, $name!";
    }
}
';
?>
```

## Kasus Penggunaan Nyata
Membagikan library ke komunitas PHP, membuat package internal perusahaan, kontribusi open source di Packagist.
