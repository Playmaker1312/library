# 302. Instal Composer

## Definisi Singkat
Instalasi Composer adalah proses mengunduh dan menginstal composer.phar, lalu menyediakannya sebagai perintah `composer` di terminal/shell.

## Analogi
Seperti memasang alat baru di bengkel: Anda mengunduh mesin (composer.phar), memasangnya di tempat yang mudah dijangkau (global install), dan memberi nama panggilan `composer` agar mudah dipanggil.

## Poin-Poin Penting
- Download dari https://getcomposer.org/download/
- Jalankan installer atau download composer.phar langsung
- Install global agar bisa dipanggil dari mana saja
- Pastikan PHP terinstal dan tersedia di PATH
- Verifikasi dengan `composer --version`
- Update dengan `composer self-update`

## Contoh Kode (PHP)
```php
<?php
echo "Cara instal Composer:\n\n";

echo "=== Windows ===\n";
echo "1. Download installer dari getcomposer.org\n";
echo "2. Jalankan Composer-Setup.exe\n";
echo "3. Atau install manual:\n";
echo "   php -r \"copy('https://getcomposer.org/installer', 'composer-setup.php');\"\n";
echo "   php composer-setup.php\n";
echo "   php -r \"unlink('composer-setup.php');\"\n";
echo "   move composer.phar C:\\bin\\composer.phar\n";
echo "   Buat file composer.bat:\n";
echo "   @php C:\\bin\\composer.phar %*\n\n";

echo "=== Linux / macOS ===\n";
echo "php -r \"copy('https://getcomposer.org/installer', 'composer-setup.php');\"\n";
echo "php composer-setup.php\n";
echo "php -r \"unlink('composer-setup.php');\"\n";
echo "sudo mv composer.phar /usr/local/bin/composer\n\n";

echo "=== Verifikasi ===\n";
echo "composer --version\n";
echo "# Output: Composer version 2.7.x ...\n\n";

echo "=== Update Composer ===\n";
echo "composer self-update\n\n";

// Cek apakah Composer terinstal
$composerInstalled = false;
$output = [];
exec('composer --version 2>&1', $output, $exitCode);
if ($exitCode === 0) {
    echo "Composer terinstal: " . $output[0];
} else {
    echo "Composer BELUM terinstal. Ikuti panduan di atas.";
}
?>
```

## Kasus Penggunaan Nyata
Langkah pertama sebelum memulai proyek PHP modern, instalasi di development environment.
