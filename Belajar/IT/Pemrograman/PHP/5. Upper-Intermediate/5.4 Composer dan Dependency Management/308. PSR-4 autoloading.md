# 308. PSR-4 Autoloading

## Definisi Singkat
PSR-4 adalah standar PHP-FIG untuk autoloading yang memetakan namespace ke direktori. Nama class (termasuk namespace) langsung dipetakan ke path file, membuat autoloading cepat dan intuitif.

## Analogi
Seperti sistem alamat rumah: namespace `App\Models\User` diterjemahkan ke path `App/Models/User.php`. Sama seperti alamat "Jalan Merdeka No. 5" yang langsung mengarah ke rumah yang tepat tanpa perlu peta tambahan.

## Poin-Poin Penting
- `App\Models\User` -> `src/Models/User.php` (prefix `App\` -> `src/`)
- Namespace prefix dipetakan ke base directory
- Nama file harus sama persis dengan nama class (case-sensitive di Linux)
- Satu file hanya berisi satu class
- Regenerasi autoloader dengan `composer dump-autoload`
- PSR-4 lebih sederhana dari PSR-0

## Contoh Kode (PHP)
```php
<?php
// composer.json
$psr4Config = [
    'autoload' => [
        'psr-4' => [
            'App\\' => 'src/',
            'App\\Controllers\\' => 'src/Controllers/',
            'App\\Models\\' => 'src/Models/',
            'App\\Services\\' => 'src/Services/',
            'App\\Exceptions\\' => 'src/Exceptions/',
            'MyLibrary\\' => 'lib/MyLibrary/',
        ]
    ]
];

echo "PSR-4 Mapping:\n";
echo "App\Models\User     => src/Models/User.php\n";
echo "App\Controllers\Auth => src/Controllers/Auth.php\n";
echo "App\Services\Mail    => src/Services/Mail.php\n";
echo "MyLibrary\Helper     => lib/MyLibrary/Helper.php\n\n";

echo json_encode($psr4Config, JSON_PRETTY_PRINT);

// Contoh class dengan PSR-4
// File: src/Models/User.php
/*
<?php
namespace App\Models;

class User
{
    public function __construct()
    {
        echo "User model dimuat via PSR-4 autoloading\n";
    }
}
*/

// File: src/Controllers/AuthController.php
/*
<?php
namespace App\Controllers;

use App\Models\User;

class AuthController
{
    public function login(): void
    {
        $user = new User();
        // logic login
    }
}
*/

// Penggunaan:
// require_once 'vendor/autoload.php';
// $controller = new App\Controllers\AuthController();
?>
```

## Kasus Penggunaan Nyata
Standar autoloading di semua framework modern (Laravel, Symfony), organisasi kode yang rapi dengan namespace, pembuatan library yang siap publikasi.
