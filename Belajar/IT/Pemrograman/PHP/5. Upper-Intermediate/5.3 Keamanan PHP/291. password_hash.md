# 291. password_hash

## Definisi Singkat
`password_hash()` adalah fungsi PHP untuk membuat hash password dengan aman. Fungsi ini secara otomatis menggunakan salt acak dan algoritma hashing yang kuat (bcrypt default).

## Analogi
Seperti mesin penghancur kertas: Anda memasukkan kertas berisi password, mesin mengubahnya menjadi ribuan potongan kecil (hash) yang tidak bisa dikembalikan lagi. Potongan ini aman disimpan, dan setiap kali Anda ingin verifikasi, Anda memasukkan kertas baru dan bandingkan hasil hancurnya.

## Poin-Poin Penting
- Jangan gunakan MD5, SHA1, atau hash biasa untuk password
- `password_hash($password, PASSWORD_BCRYPT)` menggunakan bcrypt
- `password_hash($password, PASSWORD_ARGON2I)` menggunakan Argon2i
- Secara otomatis membuat salt unik per password
- Bisa atur cost factor (semakin tinggi, semakin lambat/aman)
- Output string panjang (60 karakter bcrypt) termasuk algoritma, cost, salt, dan hash

## Contoh Kode (PHP)
```php
<?php
$password = $_POST['password'];

// Hash password dengan bcrypt (default)
$hash = password_hash($password, PASSWORD_BCRYPT);
echo $hash;
// Output: $2y$10$xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

// Hash dengan cost kustom (default 10, range 4-31)
$hash = password_hash($password, PASSWORD_BCRYPT, ['cost' => 12]);

// Hash dengan Argon2i (PHP 7.2+)
$hash = password_hash($password, PASSWORD_ARGON2I, [
    'memory_cost' => 65536, // 64MB
    'time_cost' => 4,
    'threads' => 3
]);

// Verifikasi password
if (password_verify($password, $hash)) {
    echo "Password cocok!";
}

// Simpan ke database
$pdo = new PDO('mysql:host=localhost;dbname=test', 'user', 'pass');
$stmt = $pdo->prepare('INSERT INTO users (email, password_hash) VALUES (?, ?)');
$stmt->execute([$_POST['email'], $hash]);

// Cek apakah perlu rehash (jika cost/algorithm berubah)
if (password_needs_rehash($hash, PASSWORD_BCRYPT, ['cost' => 12])) {
    $newHash = password_hash($password, PASSWORD_BCRYPT, ['cost' => 12]);
    // Update hash di database
}
?>
```

## Kasus Penggunaan Nyata
Registrasi user, ganti password, login authentication, penyimpanan password yang aman di database.
