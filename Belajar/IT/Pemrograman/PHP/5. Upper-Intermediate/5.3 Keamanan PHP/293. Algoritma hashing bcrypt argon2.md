# 293. Algoritma Hashing bcrypt argon2

## Definisi Singkat
bcrypt dan Argon2 adalah algoritma hashing yang dirancang khusus untuk password. Mereka lambat secara sengaja (memory-hard dan CPU-hard) untuk mempersulit serangan brute-force dan rainbow table.

## Analogi
Seperti membuat kunci benteng: bcrypt seperti membuat kunci dengan palu (lambat, butuh tenaga), Argon2 seperti membuat kunci di ruangan khusus yang juga butuh banyak memori. Keduanya lebih aman daripada membuat kunci dengan obeng cepat (MD5/SHA1).

## Poin-Poin Penting
- **bcrypt**: cost factor (4-31), output 60 karakter, sudah ada sejak PHP 5.5+
- **Argon2i**: resistant terhadap side-channel, memory-hard, butuh PHP 7.2+
- **Argon2id**: kombinasi Argon2i + Argon2d, rekomendasi terbaru
- Algoritma modern lebih lambat: itu fitur, bukan bug
- Cost factor meningkat seiring hardware semakin cepat
- `PASSWORD_DEFAULT` menggunakan algoritma terkuat saat ini

## Contoh Kode (PHP)
```php
<?php
$password = 'P@ssw0rd123!';

// === BCRYPT ===
$start = microtime(true);
$bcryptHash = password_hash($password, PASSWORD_BCRYPT, ['cost' => 10]);
$bcryptTime = microtime(true) - $start;
echo "Bcrypt: $bcryptHash\n";
echo "Waktu: " . round($bcryptTime, 4) . " detik\n\n";

// === ARGON2i ===
$start = microtime(true);
$argon2iHash = password_hash($password, PASSWORD_ARGON2I, [
    'memory_cost' => 65536,  // 64 MB
    'time_cost' => 4,        // 4 iterasi
    'threads' => 2           // 2 thread
]);
$argon2iTime = microtime(true) - $start;
echo "Argon2i: $argon2iHash\n";
echo "Waktu: " . round($argon2iTime, 4) . " detik\n\n";

// === ARGON2id === (PHP 7.3+)
if (defined('PASSWORD_ARGON2ID')) {
    $argon2idHash = password_hash($password, PASSWORD_ARGON2ID, [
        'memory_cost' => 65536,
        'time_cost' => 4,
        'threads' => 2
    ]);
    echo "Argon2id: $argon2idHash\n";
}

// === Verifikasi ===
echo "\nVerifikasi:\n";
echo "bcrypt match: " . (password_verify($password, $bcryptHash) ? 'Ya' : 'Tidak') . "\n";
echo "Argon2i match: " . (password_verify($password, $argon2iHash) ? 'Ya' : 'Tidak') . "\n";

// === Deteksi algoritma dari hash ===
$info = password_get_info($bcryptHash);
echo "\nInfo hash:\n";
echo "Algoritma: " . $info['algoName'] . "\n";
echo "Cost: " . ($info['options']['cost'] ?? '-') . "\n";
?>
```

## Kasus Penggunaan Nyata
Penyimpanan password user, hashing token API, hashing data sensitif lainnya yang perlu diverifikasi.
