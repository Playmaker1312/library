# 295. vlucas/phpdotenv .env

## Definisi Singkat
`vlucas/phpdotenv` adalah library PHP yang membaca file `.env` dan memuatnya ke `$_ENV` dan `getenv()`. Memudahkan manajemen konfigurasi development tanpa mengubah kode.

## Analogi
Seperti asisten pribadi yang membaca catatan tempel di meja Anda (file `.env`) dan mengingatkan Anda (menyimpan ke environment) saat Anda butuh informasi seperti password WiFi atau kunci lemari.

## Poin-Poin Penting
- Instal via Composer: `composer require vlucas/phpdotenv`
- Buat file `.env` di root proyek (jangan di-commit ke git)
- Panggil `Dotenv\Dotenv::createImmutable(__DIR__)->load()` di awal
- Tambahkan `.env` ke `.gitignore`
- Buat `.env.example` sebagai template tanpa nilai asli
- Gunakan `$_ENV` atau `getenv()` untuk membaca

## Contoh Kode (PHP)
```php
<?php
require_once 'vendor/autoload.php';

use Dotenv\Dotenv;

// Muat .env dari direktori proyek
$dotenv = Dotenv::createImmutable(__DIR__);
$dotenv->load();

// Atau dengan path spesifik
// $dotenv = Dotenv::createImmutable(__DIR__, '.env.dev');
// $dotenv->load();

// Membaca variabel
$dbHost = $_ENV['DB_HOST'];
$dbName = getenv('DB_NAME');
$appEnv = $_ENV['APP_ENV'] ?? 'production';

echo "App Environment: $appEnv\n";
echo "Database: $dbHost/$dbName\n";

// Required variables - akan throw exception jika tidak ada
$dotenv->required('DB_PASSWORD');
$dotenv->required(['DB_HOST', 'DB_NAME', 'DB_USER', 'DB_PASS']);

// Dengan validasi tipe
// $dotenv->required('APP_PORT')->isInteger();
// $dotenv->required('APP_DEBUG')->isBoolean();

// Contoh .env file:
// App name="Aplikasi Saya"
// DB_HOST=localhost
// DB_PORT=3306
// DB_NAME=myapp
// DB_USER=root
// DB_PASS=rahasia123
// APP_ENV=development
// APP_DEBUG=true
// JWT_SECRET=s3cr3t-key-jwt
// API_KEY=abc123def456

// Contoh .env.example (template, di-commit ke git):
// DB_HOST=localhost
// DB_PORT=3306
// DB_NAME=
// DB_USER=
// DB_PASS=
?>
```

## Kasus Penggunaan Nyata
Konfigurasi environment-specific di development, staging, production; CI/CD pipeline; Docker container.
