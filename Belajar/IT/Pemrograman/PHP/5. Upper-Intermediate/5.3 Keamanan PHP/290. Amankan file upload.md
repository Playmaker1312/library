# 290. Amankan File Upload

## Definisi Singkat
File upload yang tidak aman bisa membuat penyerang mengupload file berbahaya (shell, malware) ke server. Keamanan file upload melibatkan validasi tipe, ukuran, dan penyimpanan yang benar.

## Analogi
Seperti bandara: setiap bagasi (file) diperiksa (validasi tipe), ditimbang (cek ukuran), hanya barang tertentu yang diizinkan (whitelist ekstensi), dan disimpan di tempat terpisah dari area penumpang (di luar webroot).

## Poin-Poin Penting
- Validasi ekstensi file (whitelist, bukan blacklist)
- Validasi MIME type dengan `finfo` (bukan hanya ekstensi)
- Batasi ukuran file upload
- Simpan file di luar webroot jika mungkin
- Generate nama file acak, jangan pakai nama asli
- Scan file dengan antivirus jika ada
- Nonaktifkan eksekusi PHP di folder upload

## Contoh Kode (PHP)
```php
<?php
class SecureUpload
{
    private array $allowedTypes = ['image/jpeg', 'image/png', 'image/gif', 'application/pdf'];
    private array $allowedExts = ['jpg', 'jpeg', 'png', 'gif', 'pdf'];
    private int $maxSize = 5 * 1024 * 1024; // 5MB
    private string $uploadDir;

    public function __construct(string $uploadDir)
    {
        $this->uploadDir = rtrim($uploadDir, '/') . '/';
        if (!is_dir($this->uploadDir)) {
            mkdir($this->uploadDir, 0755, true);
        }
    }

    public function upload(array $file): ?string
    {
        // Cek error
        if ($file['error'] !== UPLOAD_ERR_OK) {
            throw new Exception('Upload gagal: ' . $file['error']);
        }

        // Cek ukuran
        if ($file['size'] > $this->maxSize) {
            throw new Exception('File terlalu besar. Maksimal 5MB');
        }

        // Cek ekstensi
        $ext = strtolower(pathinfo($file['name'], PATHINFO_EXTENSION));
        if (!in_array($ext, $this->allowedExts)) {
            throw new Exception('Ekstensi file tidak diizinkan');
        }

        // Cek MIME type asli (bukan dari klien)
        $finfo = finfo_open(FILEINFO_MIME_TYPE);
        $mime = finfo_file($finfo, $file['tmp_name']);
        finfo_close($finfo);

        if (!in_array($mime, $this->allowedTypes)) {
            throw new Exception('Tipe file tidak diizinkan: ' . $mime);
        }

        // Generate nama acak
        $newName = bin2hex(random_bytes(16)) . '.' . $ext;
        $destPath = $this->uploadDir . $newName;

        if (!move_uploaded_file($file['tmp_name'], $destPath)) {
            throw new Exception('Gagal menyimpan file');
        }

        return $newName;
    }
}

// Contoh penggunaan
try {
    $uploader = new SecureUpload(__DIR__ . '/uploads');
    $filename = $uploader->upload($_FILES['gambar']);
    echo json_encode(['success' => true, 'file' => $filename]);
} catch (Exception $e) {
    http_response_code(400);
    echo json_encode(['error' => $e->getMessage()]);
}

// .htaccess untuk folder upload:
// <FilesMatch "\.php$">
//     Deny from all
// </FilesMatch>
?>
```

## Kasus Penggunaan Nyata
Upload foto profil, upload dokumen lamaran kerja, upload gambar produk e-commerce, upload lampiran email.
