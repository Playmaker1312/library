# 294. Environment Variables Data Sensitif

## Definisi Singkat
Environment variables (env vars) adalah pasangan key-value yang disimpan di luar kode sumber untuk menyimpan data sensitif seperti password database, API key, dan secret key.

## Analogi
Seperti lemari besi di rumah: Anda tidak menempel kombinasi brankas di dinding (kode sumber). Anda menyimpannya di kepala (environment). Saat butuh, Anda ambil dari kepala, bukan dari dinding.

## Poin-Poin Penting
- Jangan hardcode password/secret di kode
- Gunakan `getenv()` atau `$_ENV` / `$_SERVER` untuk membaca
- Set environment variable di server (Apache, Nginx, Docker)
- Gunakan file `.env` untuk development (jangan commit ke git)
- Jangan commit `.env` ke repository (tambah ke `.gitignore`)
- Prinsip: kode sumber bisa publik, secret tetap rahasia

## Contoh Kode (PHP)
```php
<?php
// Cara membaca environment variables

// Via getenv()
$dbHost = getenv('DB_HOST') ?: 'localhost';
$dbName = getenv('DB_NAME') ?: 'app_database';
$dbUser = getenv('DB_USER');
$dbPass = getenv('DB_PASS');

// Via $_SERVER atau $_ENV
$apiKey = $_SERVER['API_KEY'] ?? '';
$jwtSecret = $_ENV['JWT_SECRET'] ?? '';

// Koneksi database dengan env vars
try {
    $pdo = new PDO(
        "mysql:host=$dbHost;dbname=$dbName;charset=utf8mb4",
        $dbUser,
        $dbPass,
        [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
    );
    echo "Koneksi database berhasil\n";
} catch (PDOException $e) {
    // Jangan expose detail error di production
    error_log($e->getMessage());
    die('Koneksi database gagal');
}

// Cara set env vars di berbagai environment:

// Windows (Command Prompt):
// set DB_USER=root
// set DB_PASS=rahasia

// Windows (PowerShell):
// $env:DB_USER="root"

// Docker:
// docker run -e DB_USER=root -e DB_PASS=rahasia myapp

// Apache (.htaccess):
// SetEnv DB_USER root
// SetEnv DB_PASS rahasia

// Nginx (fastcgi):
// fastcgi_param DB_USER root;
// fastcgi_param DB_PASS rahasia;
?>
```

## Kasus Penggunaan Nyata
Konfigurasi database, API key pihak ketiga (Stripe, AWS, SendGrid), JWT secret, password email SMTP.
