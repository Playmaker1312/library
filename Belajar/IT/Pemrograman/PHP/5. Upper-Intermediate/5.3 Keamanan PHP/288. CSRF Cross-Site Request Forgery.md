# 288. CSRF Cross-Site Request Forgery

## Definisi Singkat
CSRF adalah serangan di mana user yang sudah login secara tidak sadar mengirim request berbahaya ke aplikasi web (misal: transfer uang, ganti password). Serangan memanfaatkan session/cookie yang masih aktif.

## Analogi
Seperti seseorang yang memegang tangan Anda dan menandatangani cek menggunakan tangan Anda sendiri, tanpa Anda sadari. Bank (server) menganggap itu tanda tangan Anda karena memang tangan Anda yang menandatangani.

## Poin-Poin Penting
- CSRF token adalah token unik acak yang dikirim di setiap form request
- Token diverifikasi di server untuk memastikan request berasal dari aplikasi kita
- Token disimpan di session dan dibandingkan dengan token dari form
- Gunakan perbedaan method (POST untuk mutasi, bukan GET)
- SameSite cookie attribute membantu mencegah CSRF
- Double Submit Cookie pattern alternatif

## Contoh Kode (PHP)
```php
<?php
session_start();

// Generate CSRF token
function generateCsrfToken(): string
{
    if (empty($_SESSION['csrf_token'])) {
        $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
    }
    return $_SESSION['csrf_token'];
}

// Validasi CSRF token
function validateCsrfToken(string $token): bool
{
    return hash_equals($_SESSION['csrf_token'] ?? '', $token);
}

// Form dengan CSRF token
$token = generateCsrfToken();
?>
<form method="POST" action="/ubah-password.php">
    <input type="hidden" name="csrf_token" value="<?= htmlspecialchars($token) ?>">
    <input type="password" name="password_baru">
    <button type="submit">Ubah Password</button>
</form>

<?php
// Proses form - validasi CSRF
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    if (!validateCsrfToken($_POST['csrf_token'] ?? '')) {
        http_response_code(403);
        exit('CSRF token tidak valid');
    }

    // Proses perubahan password
    echo "Password berhasil diubah";
    // Regenerasi token setelah digunakan
    unset($_SESSION['csrf_token']);
}

// Double Submit Cookie pattern (untuk API)
function generateDoubleSubmitToken(): string
{
    $token = bin2hex(random_bytes(32));
    setcookie('csrf_cookie', $token, [
        'httponly' => true,
        'samesite' => 'Strict',
        'secure' => true
    ]);
    return $token;
}
?>
```

## Kasus Penggunaan Nyata
Form login, form transfer bank, form ubah password, form hapus akun, setiap form yang melakukan aksi penting.
