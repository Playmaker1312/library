# 299. Input Sanitasi Validasi Komprehensif

## Definisi Singkat
Input sanitasi dan validasi komprehensif adalah proses membersihkan dan memeriksa semua input user sebelum digunakan. Validasi memeriksa kebenaran format, sanitasi menghapus karakter berbahaya.

## Analogi
Seperti memasak: Anda mencuci sayur (sanitasi - buang kotoran) dan memeriksa apakah sayur masih segar (validasi - cek kualitas). Keduanya dilakukan sebelum sayur dimasak (diproses).

## Poin-Poin Penting
- **Validasi**: periksa format, tipe, range, required
- **Sanitasi**: hapus/escaping karakter berbahaya
- Validasi dulu, baru sanitasi
- Konteks penting: sanitasi untuk HTML berbeda dengan untuk SQL
- Filter var: `filter_var()` untuk email, URL, IP
- Jangan percaya data dari `$_GET`, `$_POST`, `$_FILES`, `$_COOKIE`

## Contoh Kode (PHP)
```php
<?php
class InputValidator
{
    // Validasi email
    public static function email(string $email): bool
    {
        return filter_var($email, FILTER_VALIDATE_EMAIL) !== false;
    }

    // Validasi URL
    public static function url(string $url): bool
    {
        return filter_var($url, FILTER_VALIDATE_URL) !== false;
    }

    // Validasi IP
    public static function ip(string $ip): bool
    {
        return filter_var($ip, FILTER_VALIDATE_IP) !== false;
    }

    // Validasi angka dalam range
    public static function intBetween(int $value, int $min, int $max): bool
    {
        return filter_var($value, FILTER_VALIDATE_INT, [
            'options' => ['min_range' => $min, 'max_range' => $max]
        ]) !== false;
    }

    // Sanitasi string untuk output HTML
    public static function sanitizeHtml(string $input): string
    {
        return htmlspecialchars($input, ENT_QUOTES | ENT_HTML5, 'UTF-8');
    }

    // Sanitasi string untuk database (prepared statement tetap lebih aman)
    public static function sanitizeString(string $input): string
    {
        return strip_tags(trim($input));
    }

    // Filter array input
    public static function filterArray(array $data, array $rules): array
    {
        $result = [];
        foreach ($rules as $field => $rule) {
            $value = $data[$field] ?? null;

            if ($rule['required'] && empty($value)) {
                throw new InvalidArgumentException("$field harus diisi");
            }

            if (!empty($value)) {
                $value = match ($rule['type']) {
                    'email' => filter_var($value, FILTER_SANITIZE_EMAIL),
                    'int' => filter_var($value, FILTER_VALIDATE_INT),
                    'string' => self::sanitizeString($value),
                    'url' => filter_var($value, FILTER_SANITIZE_URL),
                    default => $value
                };

                if ($value === false || $value === null) {
                    throw new InvalidArgumentException("$field tidak valid");
                }
            }

            $result[$field] = $value;
        }
        return $result;
    }
}

// Contoh penggunaan
$userInput = [
    'name' => "  <script>alert('xss')</script>John  ",
    'email' => 'john@example.com',
    'age' => '25',
];

try {
    $clean = InputValidator::filterArray($userInput, [
        'name' => ['required' => true, 'type' => 'string'],
        'email' => ['required' => true, 'type' => 'email'],
        'age' => ['required' => true, 'type' => 'int'],
    ]);

    echo json_encode(['success' => true, 'data' => $clean]);
} catch (InvalidArgumentException $e) {
    http_response_code(422);
    echo json_encode(['error' => $e->getMessage()]);
}
?>
```

## Kasus Penggunaan Nyata
Form registrasi, form kontak, input search, parameter API, data yang akan disimpan ke database.
