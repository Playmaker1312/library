# 300. Security Audit Dasar PHP

## Definisi Singkat
Security audit adalah proses sistematis memeriksa kode PHP untuk menemukan kerentanan keamanan. Audit mencakup review kode, dependency scanning, dan configuration review.

## Analogi
Seperti pemeriksaan kesehatan tahunan: dokter memeriksa tekanan darah (SQL injection), cek jantung (XSS), tes darah (CSRF), dan rontgen (file upload). Hasilnya adalah resep perbaikan untuk tetap sehat.

## Poin-Poin Penting
- **Code review**: periksa manual kerentanan umum
- **Dependency scanning**: cek library untuk CVE
- **Penetration testing**: simulasi serangan
- **Configuration review**: periksa php.ini, server config
- **Access control review**: periksa hak akses file dan database
- **Log analysis**: periksa log untuk aktivitas mencurigakan
- Tools: PHP CodeSniffer, Phan, RIPS, OWASP ZAP

## Contoh Kode (PHP)
```php
<?php
// Security audit checklist dalam kode

class SecurityAudit
{
    public static function checkPhpVersion(): string
    {
        $version = PHP_VERSION;
        $isSupported = version_compare($version, '8.0', '>=');
        return "PHP $version - " . ($isSupported ? 'Supported' : 'OUTDATED!');
    }

    public static function checkDangerousFunctions(): array
    {
        $dangerous = ['exec', 'system', 'shell_exec', 'passthru', 'eval', 'assert', 'phpinfo', 'show_source', 'highlight_file', 'popen', 'proc_open'];
        $disabled = explode(',', ini_get('disable_functions'));
        $found = [];
        foreach ($dangerous as $fn) {
            if (!in_array($fn, array_map('trim', $disabled))) {
                $found[] = $fn;
            }
        }
        return $found;
    }

    public static function checkErrorReporting(): string
    {
        if (ini_get('display_errors')) {
            return 'ERROR: display_errors masih aktif!';
        }
        return 'OK: display_errors nonaktif';
    }

    public static function checkFilePermissions(string $path): array
    {
        $issues = [];
        $items = new RecursiveIteratorIterator(
            new RecursiveDirectoryIterator($path)
        );
        foreach ($items as $item) {
            if ($item->isFile()) {
                $perms = substr(sprintf('%o', fileperms($item)), -4);
                if ($perms > '0644') {
                    $issues[] = "{$item->getPathname()} ($perms)";
                }
            }
        }
        return $issues;
    }

    public static function checkComposerAudit(): string
    {
        $composerLock = __DIR__ . '/../composer.lock';
        if (!file_exists($composerLock)) {
            return 'composer.lock tidak ditemukan';
        }
        // Jalankan: composer audit
        return 'Jalankan "composer audit" untuk cek CVE';
    }

    public static function runAll(): array
    {
        return [
            'php_version' => self::checkPhpVersion(),
            'display_errors' => self::checkErrorReporting(),
            'dangerous_functions_enabled' => self::checkDangerousFunctions(),
            'https' => empty($_SERVER['HTTPS']) ? 'TIDAK HTTPS!' : 'HTTPS aktif',
            'composer_audit' => self::checkComposerAudit(),
        ];
    }
}

// Jalankan audit
$results = SecurityAudit::runAll();
echo json_encode($results, JSON_PRETTY_PRINT);

// Output yang diharapkan:
// {
//     "php_version": "PHP 8.2 - Supported",
//     "display_errors": "OK: display_errors nonaktif",
//     "dangerous_functions_enabled": [],
//     "https": "HTTPS aktif",
//     "composer_audit": "Jalankan \"composer audit\" untuk cek CVE"
// }
?>
```

## Kasus Penggunaan Nyata
Code review sebelum deployment, audit keamanan berkala, persiapan sertifikasi keamanan, onboarding developer baru.
