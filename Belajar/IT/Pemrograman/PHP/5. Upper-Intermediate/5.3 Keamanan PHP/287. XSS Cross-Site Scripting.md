# 287. XSS Cross-Site Scripting

## Definisi Singkat
XSS adalah serangan di mana penyerang menyisipkan script berbahaya (JavaScript) ke halaman web yang dilihat user lain. Script bisa mencuri cookie, token, atau mengubah tampilan halaman.

## Analogi
Seperti menempel stiker berisi kode berbahaya di buku perpustakaan. Orang lain yang membaca buku itu tanpa sadar menjalankan kode tersebut (karena stiker terlihat seperti bagian dari buku).

## Poin-Poin Penting
- **Stored XSS**: script disimpan di database, dijalankan saat halaman dimuat
- **Reflected XSS**: script di URL, dijalankan saat diklik
- **DOM-based XSS**: script dimanipulasi via JavaScript di klien
- Gunakan `htmlspecialchars()` untuk output
- Gunakan `strip_tags()` untuk menghapus tag HTML
- Content Security Policy (CSP) sebagai lapisan tambahan
- Jangan gunakan `eval()` atau `innerHTML` dengan input user

## Contoh Kode (PHP)
```php
<?php
// AMAN: melakukan escaping output
$userInput = "<script>alert('xss')</script>";

// htmlspecialchars mengubah < > & " ' menjadi entitas HTML
$safe = htmlspecialchars($userInput, ENT_QUOTES | ENT_HTML5, 'UTF-8');
echo $safe;
// Output: &lt;script&gt;alert(&#039;xss&#039;)&lt;/script&gt;

// Filter input - hanya izinkan tag tertentu
$clean = strip_tags($userInput, '<b><i><u>');
echo $clean;

// Menyimpan ke database - simpan raw, escape saat output
$pdo = new PDO('mysql:host=localhost;dbname=test', 'user', 'pass');
$stmt = $pdo->prepare('INSERT INTO komentar (isi) VALUES (?)');
$stmt->execute([$userInput]); // simpan raw

// Saat menampilkan, baru escape:
$stmt = $pdo->query('SELECT isi FROM komentar');
while ($row = $stmt->fetch()) {
    echo htmlspecialchars($row['isi'], ENT_QUOTES, 'UTF-8');
}

// JANGAN: echo $userInput; // LANGSUNG TANPA ESCAPE!
?>
```

## Kasus Penggunaan Nyata
Komentar blog, form input pengguna, search query, profile page, forum diskusi, aplikasi chat.
