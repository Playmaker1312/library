# 292. password_verify

## Definisi Singkat
`password_verify()` memverifikasi apakah password cocok dengan hash yang dihasilkan `password_hash()`. Menggunakan timing-safe comparison untuk mencegah timing attack.

## Analogi
Seperti mencocokkan sidik jari: Anda menempelkan jari di scanner (password), sistem membandingkan dengan sidik jari yang tersimpan (hash). Tidak perlu menyimpan sidik jari asli, cukup pola yang sudah di-hash.

## Poin-Poin Penting
- `password_verify($password, $hash)` mengembalikan boolean
- Timing-safe: waktu eksekusi sama untuk password benar/salah
- Hash yang dihasilkan sudah termasuk informasi algoritma, cost, dan salt
- Bisa digunakan dengan hash bcrypt, Argon2i, atau Argon2id
- Tidak perlu mengekstrak salt secara manual

## Contoh Kode (PHP)
```php
<?php
session_start();

function login(string $email, string $password): bool
{
    $pdo = new PDO('mysql:host=localhost;dbname=test', 'user', 'pass');

    // Ambil user dari database
    $stmt = $pdo->prepare('SELECT id, email, password_hash FROM users WHERE email = ?');
    $stmt->execute([$email]);
    $user = $stmt->fetch();

    if (!$user) {
        return false; // User tidak ditemukan
    }

    // Verifikasi password
    if (password_verify($password, $user['password_hash'])) {
        // Cek apakah perlu rehash
        if (password_needs_rehash($user['password_hash'], PASSWORD_BCRYPT)) {
            $newHash = password_hash($password, PASSWORD_BCRYPT);
            $stmt = $pdo->prepare('UPDATE users SET password_hash = ? WHERE id = ?');
            $stmt->execute([$newHash, $user['id']]);
        }

        // Set session
        $_SESSION['user_id'] = $user['id'];
        return true;
    }

    return false;
}

// Contoh penggunaan
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    if (login($_POST['email'], $_POST['password'])) {
        echo json_encode(['success' => true, 'message' => 'Login berhasil']);
    } else {
        // Jangan bocorkan apakah email atau password yang salah
        http_response_code(401);
        echo json_encode(['error' => 'Email atau password salah']);
    }
}
?>
```

## Kasus Penggunaan Nyata
Login user, verifikasi password sebelum aksi sensitif (hapus akun, transfer), API authentication dengan password.
