# 296. Least Privilege Database Config

## Definisi Singkat
Least privilege principle berarti memberikan hak akses minimal yang diperlukan untuk setiap pengguna database. Aplikasi hanya punya hak untuk melakukan apa yang dibutuhkan, tidak lebih.

## Analogi
Seperti karyawan di perusahaan: satpam hanya punya akses ke pintu masuk, bukan ke ruang server. Manajer punya akses ke laporan, bukan ke data gaji semua orang. Setiap orang hanya punya akses sesuai perannya.

## Poin-Poin Penting
- Buat user database terpisah untuk aplikasi
- Jangan gunakan root user untuk aplikasi
- Aplikasi read-only hanya butuh SELECT
- Aplikasi CRUD butuh SELECT, INSERT, UPDATE, DELETE
- Batasi akses ke database tertentu (GRANT ON db.* bukan *.*)
- Jangan beri CREATE/ALTER/DROP di production
- Buat user berbeda untuk migration vs runtime

## Contoh Kode (PHP)
```php
<?php
// Contoh konfigurasi database dengan least privilege

// === User untuk aplikasi runtime (CRUD biasa) ===
// SQL untuk membuat user:
// CREATE USER 'app_user'@'localhost' IDENTIFIED BY 'password_kuat';
// GRANT SELECT, INSERT, UPDATE, DELETE ON myapp.* TO 'app_user'@'localhost';
// FLUSH PRIVILEGES;

$config = [
    'app' => [
        'host' => getenv('DB_HOST'),
        'dbname' => getenv('DB_NAME'),
        'user' => getenv('DB_USER'),        // app_user
        'pass' => getenv('DB_PASS'),        // hanya SELECT, INSERT, UPDATE, DELETE
    ],
    'readonly' => [
        'host' => getenv('DB_HOST'),
        'dbname' => getenv('DB_NAME'),
        'user' => getenv('DB_USER_READONLY'), // app_readonly
        'pass' => getenv('DB_PASS_READONLY'), // hanya SELECT
    ],
    'migration' => [
        'host' => getenv('DB_HOST'),
        'dbname' => getenv('DB_NAME'),
        'user' => getenv('DB_USER_MIGRATE'), // app_migrate
        'pass' => getenv('DB_PASS_MIGRATE'), // CREATE, ALTER, DROP, SELECT, INSERT, UPDATE, DELETE
    ]
];

// Koneksi untuk aplikasi runtime (CRUD)
function getAppConnection(): PDO
{
    global $config;
    $c = $config['app'];
    return new PDO(
        "mysql:host={$c['host']};dbname={$c['dbname']};charset=utf8mb4",
        $c['user'], $c['pass'],
        [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
    );
}

// Koneksi read-only (untuk laporan)
function getReadonlyConnection(): PDO
{
    global $config;
    $c = $config['readonly'];
    return new PDO(
        "mysql:host={$c['host']};dbname={$c['dbname']};charset=utf8mb4",
        $c['user'], $c['pass']
    );
}

echo "Konfigurasi least privilege siap digunakan\n";
// Contoh: SELECT * FROM users; (boleh)
// DROP TABLE users; (TIDAK boleh - hanya migration yang punya hak)
?>
```

## Kasus Penggunaan Nyata
Aplikasi production dengan user database terbatas, pemisahan hak akses untuk keamanan, proteksi dari SQL injection yang bisa drop table.
