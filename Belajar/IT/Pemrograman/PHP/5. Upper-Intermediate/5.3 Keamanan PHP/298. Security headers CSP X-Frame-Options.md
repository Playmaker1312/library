# 298. Security Headers CSP X-Frame-Options

## Definisi Singkat
Security headers adalah HTTP header yang memberitahu browser cara mengamankan konten. CSP (Content Security Policy) mengontrol resource apa yang boleh dimuat, X-Frame-Options mencegah clickjacking.

## Analogi
Seperti aturan di sekolah: "Tidak boleh membawa mainan dari luar" (CSP mengontrol sumber konten) dan "Tidak boleh melihat halaman ujian dari jendela" (X-Frame-Options mencegah halaman ditampilkan di iframe).

## Poin-Poin Penting
- **CSP**: `Content-Security-Policy: default-src 'self'`
- **X-Frame-Options**: `DENY` atau `SAMEORIGIN`
- **X-Content-Type-Options**: `nosniff` cegah MIME sniffing
- **X-XSS-Protection**: `1; mode=block` proteksi XSS lama
- **Strict-Transport-Security**: paksa HTTPS (HSTS)
- **Referrer-Policy**: kontrol informasi referer

## Contoh Kode (PHP)
```php
<?php
// Set security headers
function setSecurityHeaders(): void
{
    // Cegah clickjacking - halaman tidak bisa di-iframe
    header('X-Frame-Options: DENY');
    // header('X-Frame-Options: SAMEORIGIN'); // izin dari domain sendiri

    // Content Security Policy - kontrol sumber konten
    header("Content-Security-Policy: " . implode('; ', [
        "default-src 'self'",
        "script-src 'self' 'unsafe-inline' https://code.jquery.com",
        "style-src 'self' 'unsafe-inline' https://fonts.googleapis.com",
        "img-src 'self' data: https://trusted-cdn.com",
        "font-src 'self' https://fonts.gstatic.com",
        "connect-src 'self' https://api.example.com",
        "frame-ancestors 'none'", // pengganti X-Frame-Options
        "form-action 'self'",
        "base-uri 'self'",
    ]));

    // Mencegah MIME type sniffing
    header('X-Content-Type-Options: nosniff');

    // Proteksi XSS (legacy, CSP lebih baik)
    header('X-XSS-Protection: 1; mode=block');

    // HSTS - paksa HTTPS
    header('Strict-Transport-Security: max-age=31536000; includeSubDomains; preload');

    // Referrer policy
    header("Referrer-Policy: strict-origin-when-cross-origin");

    // Feature policy / Permissions policy
    header("Permissions-Policy: geolocation=(), camera=(), microphone=()");

    // Hapus server signature
    header_remove('X-Powered-By');
}

setSecurityHeaders();
?>
<!-- HTML meta tag alternatif (jika tidak bisa set header) -->
<!--
<meta http-equiv="Content-Security-Policy" content="default-src 'self'">
<meta http-equiv="X-Frame-Options" content="DENY">
-->

<h1>Security Headers Aktif</h1>
<p>Halaman ini dilindungi oleh security headers</p>
```

## Kasus Penggunaan Nyata
Website yang mencegah clickjacking (halaman login, payment), mengontrol sumber script/style untuk mencegah XSS, aplikasi yang membutuhkan keamanan tinggi (banking, health).
