# 297. Konfigurasi PHP Production Aman

## Definisi Singkat
Konfigurasi PHP production aman adalah pengaturan `php.ini` yang meminimalkan risiko keamanan dengan menonaktifkan fitur yang tidak perlu dan membatasi resource.

## Analogi
Seperti mengunci rumah saat bepergian: matikan peralatan listrik (disable fungsi berbahaya), kunci jendela (batasi akses file), pasang alarm (error logging), dan beri tahu tetangga (set batas resource).

## Poin-Poin Penting
- Nonaktifkan `display_errors` di production
- Aktifkan `log_errors` dan set `error_log` path
- Nonaktifkan fungsi berbahaya: `exec`, `system`, `shell_exec`, `eval`, `assert`
- Batasi `memory_limit`, `max_execution_time`, `upload_max_filesize`
- Nonaktifkan `allow_url_fopen` dan `allow_url_include`
- Set `session.use_strict_mode`, `session.cookie_httponly`, `session.cookie_secure`

## Contoh Kode (PHP)
```php
<?php
// Konfigurasi php.ini untuk production
$productionConfig = [
    // Error handling
    'display_errors' => 'Off',
    'display_startup_errors' => 'Off',
    'log_errors' => 'On',
    'error_log' => '/var/log/php_errors.log',
    'error_reporting' => 'E_ALL & ~E_DEPRECATED & ~E_STRICT',

    // Resource limits
    'memory_limit' => '128M',
    'max_execution_time' => '30',
    'max_input_time' => '30',
    'post_max_size' => '8M',
    'upload_max_filesize' => '2M',
    'max_file_uploads' => '5',

    // Security
    'disable_functions' => 'exec,system,shell_exec,passthru,popen,proc_open,proc_close,proc_get_status,proc_nice,proc_terminate,show_source,highlight_file,eval,assert,phpinfo',
    'allow_url_fopen' => 'Off',
    'allow_url_include' => 'Off',

    // File uploads
    'file_uploads' => 'On',
    'upload_tmp_dir' => '/tmp/php_uploads',

    // Session
    'session.use_strict_mode' => '1',
    'session.use_only_cookies' => '1',
    'session.cookie_httponly' => '1',
    'session.cookie_secure' => '1', // hanya HTTPS
    'session.cookie_samesite' => 'Lax',
    'session.gc_maxlifetime' => '1440',
    'session.sid_length' => '48',
    'session.sid_bits_per_character' => '6',

    // OPcache
    'opcache.enable' => '1',
    'opcache.memory_consumption' => '128',
    'opcache.max_accelerated_files' => '10000',
    'opcache.validate_timestamps' => '0', // nonaktifkan di production
];

// Atau set via ini_set() untuk runtime (terbatas)
ini_set('display_errors', '0');
ini_set('log_errors', '1');
ini_set('error_log', __DIR__ . '/../logs/php_error.log');

echo "Konfigurasi PHP production aman\n";
?>
```

## Kasus Penggunaan Nyata
Server production untuk aplikasi web, API production, deployment ke shared hosting atau VPS.
