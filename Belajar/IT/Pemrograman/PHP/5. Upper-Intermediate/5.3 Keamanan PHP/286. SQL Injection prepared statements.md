# 286. SQL Injection Prepared Statements

## Definisi Singkat
SQL Injection adalah serangan di mana penyerang menyisipkan query SQL berbahaya melalui input user. Prepared Statements adalah teknik aman yang memisahkan query dari data, mencegah injeksi.

## Analogi
Seperti membeli tiket kereta: Anda tidak menulis langsung "Tolong 1 tiket; DAN HAPUS SEMUA DATA" di formulir. Petugas mengambil tiket yang sudah dicetak (prepared) dan hanya mengisi nama Anda (parameter).

## Poin-Poin Penting
- Jangan pernah menggabungkan input user langsung ke query SQL
- Prepared statements memisahkan SQL dari data
- PDO dan MySQLi mendukung prepared statements
- Parameter binding otomatis men-escape karakter berbahaya
- Prinsip: query dikirim dulu, data dikirim kemudian
- Prepared statements juga meningkatkan performa untuk query berulang

## Contoh Kode (PHP)
```php
<?php
// AMAN: menggunakan prepared statement
$pdo = new PDO('mysql:host=localhost;dbname=test', 'user', 'pass');
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

$nama = $_POST['nama']; // input user bisa berbahaya

// Prepared statement dengan named parameter
$stmt = $pdo->prepare('SELECT * FROM users WHERE nama = :nama');
$stmt->execute([':nama' => $nama]);
$users = $stmt->fetchAll();

// Prepared statement dengan positional parameter
$stmt = $pdo->prepare('INSERT INTO users (nama, email, umur) VALUES (?, ?, ?)');
$stmt->execute([$nama, $_POST['email'], (int)$_POST['umur']]);

// RENTAN terhadap SQL injection
// JANGAN LAKUKAN INI:
// $sql = "SELECT * FROM users WHERE nama = '$nama'";
// $result = $pdo->query($sql); // INI BERBAHAYA!

// Dengan MySQLi
$mysqli = new mysqli('localhost', 'user', 'pass', 'test');
$stmt = $mysqli->prepare('SELECT * FROM users WHERE email = ?');
$stmt->bind_param('s', $_POST['email']);
$stmt->execute();
$result = $stmt->get_result();
?>
```

## Kasus Penggunaan Nyata
Semua query yang melibatkan input user: login, search, registrasi, filter data, update profil.
