# Prepared Statements — Query yang Aman dari SQL Injection

## Penjelasan

**Prepared Statement** adalah teknik menjalankan query SQL dengan memisahkan **struktur query** dari **data input**. Data dikirim secara terpisah, sehingga tidak bisa mengubah struktur SQL — inilah pertahanan utama terhadap **SQL Injection**.

Cara kerja prepared statement:

1. **Prepare** — Kirim query dengan placeholder (`?` atau `:nama`) ke MySQL
2. **Bind/Execute** — Kirim data secara terpisah; MySQL sudah tahu bahwa data ini adalah nilai, bukan perintah SQL
3. **Fetch** — Ambil hasil

Dua jenis placeholder:

| Placeholder | Contoh | Keterangan |
|-------------|--------|------------|
| Positional (`?`) | `WHERE id = ? AND status = ?` | Berdasarkan urutan array |
| Named (`:nama`) | `WHERE id = :id AND status = :status` | Berdasarkan nama key array |

```php
<?php
// ❌ RENTAN SQL INJECTION — jangan pernah dilakukan!
$id = $_GET['id'];
$pdo->query("SELECT * FROM buku WHERE id = $id");
// Input: 1; DROP TABLE buku; --  → tabel buku hilang!

// ✅ AMAN dengan Prepared Statement
$stmt = $pdo->prepare("SELECT * FROM buku WHERE id = ?");
$stmt->execute([$_GET['id']]);
// Data dikirim sebagai nilai, bukan bagian SQL
?>
```

## Fungsi

Mencegah SQL Injection dengan memastikan input user tidak pernah diinterpretasikan sebagai perintah SQL. Meningkatkan performa untuk query berulang — prepared statement bisa di-compile sekali dan dijalankan berkali-kali dengan data berbeda (prepare sekali, execute multiple times). Memisahkan logika query dari data membuat kode lebih bersih dan lebih mudah di-maintain.

## Cara Pengimplementasian / Code

```php
<?php
require_once 'Database.php'; // class Database dari materi 26

try {
    $pdo = Database::getInstance();

    // =====================
    // 1. INSERT — Named Parameters
    // =====================
    $sql  = "INSERT INTO buku (judul, pengarang, tahun) VALUES (:judul, :pengarang, :tahun)";
    $stmt = $pdo->prepare($sql);

    // Execute dengan array asosiatif
    $stmt->execute([
        ':judul'    => 'Belajar PHP 8',
        ':pengarang' => 'Andi Programmer',
        ':tahun'    => 2026,
    ]);

    echo "Buku berhasil ditambahkan. ID: " . $pdo->lastInsertId() . "\n";

    // Execute ulang dengan data berbeda — prepare sekali, execute banyak kali
    $stmt->execute([
        ':judul'    => 'Mastering Database',
        ':pengarang' => 'Budi Data',
        ':tahun'    => 2025,
    ]);

    echo "Buku berhasil ditambahkan. ID: " . $pdo->lastInsertId() . "\n";

    // =====================
    // 2. SELECT — Positional Parameters
    // =====================
    $cari  = "%PHP%";
    $sql   = "SELECT * FROM buku WHERE judul LIKE ? AND tersedia = ?";
    $stmt  = $pdo->prepare($sql);
    $stmt->execute([$cari, true]);

    $bukuList = $stmt->fetchAll();

    echo "\n=== Hasil Pencarian: PHP ===\n";
    foreach ($bukuList as $buku) {
        echo "[{$buku['id']}] {$buku['judul']} — {$buku['pengarang']}\n";
    }

    // =====================
    // 3. UPDATE — Named Parameters
    // =====================
    $sql = "UPDATE buku SET tersedia = :tersedia WHERE id = :id";
    $pdo->prepare($sql)->execute([
        ':tersedia' => false,
        ':id'       => 1,
    ]);

    echo "\nBuku ID 1 berhasil diupdate statusnya.\n";

    // =====================
    // 4. DELETE — Positional
    // =====================
    $sql  = "DELETE FROM buku WHERE id = ? AND tersedia = ?";
    $stmt = $pdo->prepare($sql);
    $stmt->execute([3, true]);

    echo "Buku ID 3 dihapus. Baris terpengaruh: {$stmt->rowCount()}\n";

    // =====================
    // 5. SELECT dengan Bind Param (alternatif syntax)
    // =====================
    $sql  = "SELECT * FROM buku WHERE tahun BETWEEN :tahunAwal AND :tahunAkhir";
    $stmt = $pdo->prepare($sql);
    $stmt->bindValue(':tahunAwal', 2020, PDO::PARAM_INT);
    $stmt->bindValue(':tahunAkhir', 2026, PDO::PARAM_INT);
    $stmt->execute();

    $bukuTerbaru = $stmt->fetchAll();

    echo "\n=== Buku 2020-2026 ===\n";
    foreach ($bukuTerbaru as $buku) {
        echo "[{$buku['id']}] {$buku['judul']} ({$buku['tahun']})\n";
    }

} catch (PDOException $e) {
    die("Error: " . $e->getMessage());
}
?>
```

## Class Repository — CRUD Lengkap dengan Prepared Statement

```php
<?php
class BukuRepository {
    private PDO $pdo;

    public function __construct() {
        $this->pdo = Database::getInstance();
    }

    public function getAll(): array {
        $stmt = $this->pdo->query("SELECT * FROM buku ORDER BY judul");
        return $stmt->fetchAll();
    }

    public function getById(int $id): ?array {
        $stmt = $this->pdo->prepare("SELECT * FROM buku WHERE id = ?");
        $stmt->execute([$id]);
        return $stmt->fetch() ?: null;
    }

    public function search(string $keyword): array {
        $stmt = $this->pdo->prepare(
            "SELECT * FROM buku WHERE judul LIKE :keyword OR pengarang LIKE :keyword"
        );
        $stmt->execute([':keyword' => "%$keyword%"]);
        return $stmt->fetchAll();
    }

    public function create(string $judul, string $pengarang, int $tahun): int {
        $stmt = $this->pdo->prepare(
            "INSERT INTO buku (judul, pengarang, tahun) VALUES (:judul, :pengarang, :tahun)"
        );
        $stmt->execute([
            ':judul'    => $judul,
            ':pengarang' => $pengarang,
            ':tahun'    => $tahun,
        ]);
        return (int) $this->pdo->lastInsertId();
    }

    public function updateStatus(int $id, bool $tersedia): int {
        $stmt = $this->pdo->prepare("UPDATE buku SET tersedia = ? WHERE id = ?");
        $stmt->execute([$tersedia, $id]);
        return $stmt->rowCount();
    }

    public function delete(int $id): int {
        $stmt = $this->pdo->prepare("DELETE FROM buku WHERE id = ?");
        $stmt->execute([$id]);
        return $stmt->rowCount();
    }
}

// ===== Penggunaan =====
$repo = new BukuRepository();

$idBaru = $repo->create('Clean Code PHP', 'Robert', 2026);
echo "Buku baru ID: $idBaru\n";

$buku = $repo->getById($idBaru);
echo "Detail: {$buku['judul']} — {$buku['pengarang']}\n";

$hasil = $repo->search('PHP');
echo "Ditemukan " . count($hasil) . " buku mengandung 'PHP'\n";
?>
```

## Analogi

**Prepared Statement** seperti **formulir peminjaman buku yang sudah dicetak dengan format tetap**:

1. **Prepare**: Pustakawan menyiapkan blanko: "Anggota dengan nomor ____ meminjam buku dengan judul ____ pada tanggal ____". Struktur kalimat sudah tetap — tidak bisa diubah.
2. **Execute**: Pustakawan mengisi bagian yang kosong: "AGT-001", "PHP Dasar", "2026-06-30". Isian ini hanya ditempatkan di kolom yang sudah disediakan — tidak bisa mengubah kalimat di sekitarnya.
3. **SQL Injection adalah seperti** anggota yang menulis di kolom keterangan: "Hapus semua data" — dan karena sistem tidak memisahkan isian dari struktur, tulisan itu ikut dieksekusi sebagai perintah. Prepared statement mencegah hal ini dengan memastikan apapun yang ditulis di kolom akan tetap diperlakukan sebagai data, bukan perintah.

## Dipakai untuk Apa

- **Semua query yang melibatkan input user** — form pencarian, login, registrasi, komentar
- **Operasi CRUD** — Insert, Update, Delete dengan data dari user
- **Bulk operations** — Prepared statement bisa di-execute ulang dengan data berbeda dalam loop
- **API endpoints** — Endpoint REST yang menerima parameter dari URL atau body request
- **Search/filter** — Query dengan `LIKE`, `WHERE`, `BETWEEN` yang tergantung input
- **Setiap query di aplikasi web modern** — prepared statement adalah standar wajib

## Kesalahan Umum yang Sering Terjadi

- **Tidak pakai prepared statement**: Concatenate string langsung — `"WHERE id = $_GET[id]"` — SQL injection.
- **Salah urutan placeholder positional**: Array `['Budi', 1]` padahal query `WHERE id = ? AND nama = ?` — data terbalik.
- **Lupa `%` untuk LIKE**: `$stmt->execute(['keyword'])` tanpa `%` — `LIKE` mencari kata persis, bukan sebagian.
- **Tipe data tidak cocok**: Parameter `PDO::PARAM_INT` untuk kolom integer — meski PDO biasanya handle otomatis, lebih baik eksplisit dengan `bindValue` untuk kritis.
- **Menggunakan `query()` untuk input user**: `$pdo->query("SELECT * FROM buku WHERE id = $id")` — jebakan klasik.
- **Tidak mengecek hasil `execute()`**: Method `execute()` mengembalikan `true/false` — gunakan `errorInfo()` jika query gagal.
- **Named parameter dengan titik dua lupa**: `execute(['judul' => ...])` tanpa `:` di key — parameter tidak cocok.

## Soal Latihan & Jawaban

### Soal

Buat class `PeminjamanRepository` dengan method:
1. `pinjamBuku(int $idAnggota, int $idBuku): bool` — INSERT ke tabel `peminjaman` (kolom: `id_anggota`, `id_buku`, `tanggal_pinjam`, `status`) dan UPDATE `buku.tersedia = false`. Gunakan transaction.
2. `kembalikanBuku(int $idPeminjaman): bool` — UPDATE `status = 'dikembalikan'`, `tanggal_kembali = NOW()`, dan UPDATE `buku.tersedia = true`.

Buat tabel `peminjaman` di method `buatTabel()`. Gunakan prepared statement untuk semua query.

### Jawaban

```php
<?php
class PeminjamanRepository {
    private PDO $pdo;

    public function __construct() {
        $this->pdo = Database::getInstance();
        $this->buatTabel();
    }

    private function buatTabel(): void {
        $this->pdo->exec("CREATE TABLE IF NOT EXISTS peminjaman (
            id INT AUTO_INCREMENT PRIMARY KEY,
            id_anggota INT NOT NULL,
            id_buku INT NOT NULL,
            tanggal_pinjam DATE DEFAULT (CURRENT_DATE),
            tanggal_kembali DATE NULL,
            status ENUM('dipinjam', 'dikembalikan') DEFAULT 'dipinjam',
            FOREIGN KEY (id_anggota) REFERENCES anggota(id),
            FOREIGN KEY (id_buku) REFERENCES buku(id)
        ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4");
    }

    public function pinjamBuku(int $idAnggota, int $idBuku): bool {
        try {
            $this->pdo->beginTransaction();

            // Insert peminjaman
            $stmt = $this->pdo->prepare(
                "INSERT INTO peminjaman (id_anggota, id_buku) VALUES (:anggota, :buku)"
            );
            $stmt->execute([':anggota' => $idAnggota, ':buku' => $idBuku]);

            // Update status buku
            $stmt = $this->pdo->prepare("UPDATE buku SET tersedia = false WHERE id = :id");
            $stmt->execute([':id' => $idBuku]);

            $this->pdo->commit();
            return true;

        } catch (PDOException $e) {
            $this->pdo->rollBack();
            echo "Gagal meminjam: " . $e->getMessage() . "\n";
            return false;
        }
    }

    public function kembalikanBuku(int $idPeminjaman): bool {
        try {
            $this->pdo->beginTransaction();

            // Dapatkan id_buku dari peminjaman
            $stmt = $this->pdo->prepare("SELECT id_buku FROM peminjaman WHERE id = ?");
            $stmt->execute([$idPeminjaman]);
            $data = $stmt->fetch();

            if (!$data) {
                throw new Exception("Peminjaman ID $idPeminjaman tidak ditemukan.");
            }

            // Update status peminjaman
            $stmt = $this->pdo->prepare(
                "UPDATE peminjaman SET status = 'dikembalikan', tanggal_kembali = CURDATE() WHERE id = ?"
            );
            $stmt->execute([$idPeminjaman]);

            // Update status buku
            $stmt = $this->pdo->prepare("UPDATE buku SET tersedia = true WHERE id = ?");
            $stmt->execute([$data['id_buku']]);

            $this->pdo->commit();
            return true;

        } catch (Exception $e) {
            $this->pdo->rollBack();
            echo "Gagal mengembalikan: " . $e->getMessage() . "\n";
            return false;
        }
    }
}

// Test
$peminjamanRepo = new PeminjamanRepository();

if ($peminjamanRepo->pinjamBuku(1, 2)) {
    echo "Peminjaman berhasil.\n";
}
if ($peminjamanRepo->kembalikanBuku(1)) {
    echo "Pengembalian berhasil.\n";
}
?>
```
