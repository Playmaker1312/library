# PDO — Koneksi Database yang Aman

## Penjelasan

**PDO (PHP Data Objects)** adalah extension PHP yang menyediakan antarmuka seragam untuk mengakses berbagai jenis database (MySQL, PostgreSQL, SQLite, dll). PDO adalah pendekatan **modern dan aman** dibandingkan mysql_* atau mysqli_*.

Mengapa PDO lebih baik:

| Aspek | mysql_* (lama) | mysqli | **PDO** |
|-------|----------------|--------|---------|
| Status | **Deprecated** sejak PHP 5.5, dihapus di PHP 7 | Modern tapi spesifik MySQL | **Direkomendasikan** |
| Kompatibilitas | MySQL saja | MySQL saja | 12+ driver database |
| Named parameters | Tidak | Tidak | **Ya** :name |
| OOP | Tidak | Ya | **Ya** |
| Prepared statement | Rentan error | Manual binding | **Otomatis** |
| Exception handling | Tidak | Terbatas | **PDOException** |

Struktur dasar koneksi PDO:

```php
<?php
$dsn = 'mysql:host=localhost;dbname=perpustakaan;charset=utf8mb4';
$user = 'root';
$pass = '';

try {
    $pdo = new PDO($dsn, $user, $pass);
    // Set mode error ke exception
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    echo "Koneksi berhasil!";
} catch (PDOException $e) {
    die("Koneksi gagal: " . $e->getMessage());
}
?>
```

DSN (Data Source Name) adalah string yang memberitahu PDO:
- `mysql:` — jenis database
- `host=localhost` — alamat server (bisa `127.0.0.1` atau IP)
- `dbname=perpustakaan` — nama database
- `charset=utf8mb4` — encoding UTF-8 (mencegah error karakter)

## Fungsi

PDO menyediakan lapisan abstraksi database yang konsisten — kode PHP Anda tidak perlu berubah jika mengganti database dari MySQL ke PostgreSQL atau SQLite. PDO juga mengaktifkan **error handling modern** dengan exception dan mendukung **prepared statements** (materi 27) yang merupakan pertahanan utama terhadap SQL injection.

## Cara Pengimplementasian / Code

```php
<?php
// =====================
// 1. Koneksi Dasar dengan PDO
// =====================
$host    = 'localhost';
$dbname  = 'perpustakaan';
$user    = 'root';
$pass    = '';

$dsn = "mysql:host=$host;dbname=$dbname;charset=utf8mb4";

$options = [
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES   => false,
];

try {
    $pdo = new PDO($dsn, $user, $pass, $options);
} catch (PDOException $e) {
    die("Gagal koneksi ke database: " . $e->getMessage());
}

// =====================
// 2. Class Database Wrapper
// =====================
class Database {
    private static ?PDO $instance = null;
    private const HOST   = 'localhost';
    private const DBNAME = 'perpustakaan';
    private const USER   = 'root';
    private const PASS   = '';

    public static function getInstance(): PDO {
        if (self::$instance === null) {
            $dsn = "mysql:host=" . self::HOST . ";dbname=" . self::DBNAME . ";charset=utf8mb4";
            self::$instance = new PDO($dsn, self::USER, self::PASS, [
                PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                PDO::ATTR_EMULATE_PREPARES   => false,
            ]);
        }
        return self::$instance;
    }
}

// =====================
// 3. Query Sederhana dengan query()
// CATATAN: query() hanya untuk SQL tanpa input user
// =====================
try {
    $pdo = Database::getInstance();

    // Membuat tabel jika belum ada (gunakan sekali saja)
    $pdo->exec("CREATE TABLE IF NOT EXISTS buku (
        id INT AUTO_INCREMENT PRIMARY KEY,
        judul VARCHAR(255) NOT NULL,
        pengarang VARCHAR(255) NOT NULL,
        tahun INT,
        tersedia BOOLEAN DEFAULT TRUE,
        created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
    ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4");

    echo "Tabel 'buku' siap digunakan.\n";

    // Insert data dummy (contoh, jangan untuk produksi)
    $pdo->exec("INSERT INTO buku (judul, pengarang, tahun) VALUES
        ('PHP Dasar', 'Andi', 2025),
        ('Laravel Pro', 'Budi', 2026),
        ('JavaScript Modern', 'Citra', 2025)");

    echo "Data dummy berhasil dimasukkan.\n";

    // SELECT — membaca data
    $stmt = $pdo->query("SELECT * FROM buku");
    $bukuList = $stmt->fetchAll();

    echo "\n=== Daftar Buku ===\n";
    foreach ($bukuList as $buku) {
        $status = $buku['tersedia'] ? 'Tersedia' : 'Dipinjam';
        printf("[%d] %s — %s (%d) [%s]\n",
            $buku['id'],
            $buku['judul'],
            $buku['pengarang'],
            $buku['tahun'],
            $status
        );
    }

} catch (PDOException $e) {
    die("Error: " . $e->getMessage());
}
?>
```

SQL untuk membuat database (jalankan di phpMyAdmin atau MySQL CLI sebelum menjalankan kode di atas):

```sql
CREATE DATABASE IF NOT EXISTS perpustakaan
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_unicode_ci;
```

## Fungsi

```php
<?php
// Mode Fetch yang tersedia
$stmt->fetch();          // Satu baris
$stmt->fetchAll();       // Semua baris (array)
$stmt->fetchColumn();    // Satu kolom dari baris pertama
$stmt->rowCount();       // Jumlah baris yang terpengaruh

// PDO::FETCH_ASSOC — array asosiatif (kolom => nilai)
// PDO::FETCH_NUM  — array numerik
// PDO::FETCH_BOTH — gabungan assoc + num
// PDO::FETCH_OBJ  — object (->kolom)
// PDO::FETCH_CLASS— langsung ke object class tertentu
?>
```

## Analogi

PDO adalah **standar sistem peminjaman antar-perpustakaan yang seragam**. Dulu setiap perpustakaan punya cara berbeda untuk mencatat peminjaman (ada yang pakai buku kertas, ada yang pakai spreadsheet, ada yang pakai software sendiri). PDO datang sebagai **sistem terpadu** — semua perpustakaan menggunakan formulir peminjaman yang formatnya sama, cara mengisinya sama, cara menyimpannya sama. Pustakawan cukup belajar satu sistem saja, lalu bisa bertugas di perpustakaan mana pun. Kalau database diganti (dari buku catatan ke sistem digital), pustakawan tidak perlu belajar ulang — antarmuka PDO tetap sama.

## Dipakai untuk Apa

- **Koneksi ke database MySQL dari PHP** — fondasi setiap aplikasi web dinamis
- **Abstraksi database** — kode tetap sama walau ganti MySQL → PostgreSQL → SQLite
- **Error handling** — exception `PDOException` memudahkan debugging
- **Transaction** — `beginTransaction()`, `commit()`, `rollback()` untuk operasi atomik
- **Connection pooling** — singleton pattern (seperti class Database di atas) untuk satu koneksi per request
- **Membaca data dengan berbagai format** — assoc, object, class custom

## Kesalahan Umum yang Sering Terjadi

- **Kredensial salah**: `$user` atau `$pass` tidak sesuai — dapat `SQLSTATE[HY000] [1045] Access denied`.
- **Database belum dibuat**: DSN menyebut `dbname=perpustakaan` tapi database belum ada — error.
- **Charset tidak diatur**: `charset=utf8mb4` lupa diset — karakter emoji atau aksara tertentu jadi `???`.
- **Error mode tidak diset**: Default PDO error mode adalah silent — query gagal tanpa pemberitahuan.
- **Salah menulis DSN**: Koma atau titik koma salah — `$dsn` tidak valid.
- **PDO tidak terinstall**: Extension `pdo_mysql` tidak aktif di `php.ini` — class `PDO` tidak ditemukan.
- **Mengirim password di kode**: Hardcode credential di file — gunakan environment variable `.env`.
- **Query() untuk input user**: `$pdo->query("SELECT * FROM buku WHERE judul='$_GET[q]'")` — SQL injection!

## Hubungan dengan Materi Sebelumnya

Materi 15-17 (fungsi & scope) digunakan untuk membuat class Database wrapper dan method-methodnya. Materi 23 (Class & Object) adalah dasar — PDO sendiri adalah class bawaan PHP, dan kita membuat object `$pdo = new PDO(...)`. Materi 11-12 (string) berguna untuk menyusun query dan DSN. ## Soal Latihan & Jawaban

### Soal

Buat class `AnggotaDB` yang menggunakan PDO (via `Database::getInstance()`) dengan method:
1. `getAllAnggota(): array` — mengambil semua anggota dari tabel `anggota`
2. `getAnggotaById(int $id): ?array` — mengambil satu anggota berdasarkan ID

Buat juga tabel `anggota` dengan kolom `id`, `nama`, `email`, `tanggal_daftar`. Gunakan `try-catch` untuk menangani error.

### Jawaban

```php
<?php
// Asumsi class Database sudah ada (lihat kode di atas)

class AnggotaDB {
    private PDO $pdo;

    public function __construct() {
        $this->pdo = Database::getInstance();
        $this->buatTabel();
    }

    private function buatTabel(): void {
        $this->pdo->exec("CREATE TABLE IF NOT EXISTS anggota (
            id INT AUTO_INCREMENT PRIMARY KEY,
            nama VARCHAR(255) NOT NULL,
            email VARCHAR(255) NOT NULL UNIQUE,
            tanggal_daftar DATE DEFAULT (CURRENT_DATE)
        ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4");
    }

    public function getAllAnggota(): array {
        $stmt = $this->pdo->query("SELECT * FROM anggota ORDER BY nama");
        return $stmt->fetchAll();
    }

    public function getAnggotaById(int $id): ?array {
        $stmt = $this->pdo->prepare("SELECT * FROM anggota WHERE id = ?");
        $stmt->execute([$id]);
        $anggota = $stmt->fetch();
        return $anggota ?: null;
    }
}

// Test
try {
    $anggotaDB = new AnggotaDB();

    // Insert sample
    $pdo = Database::getInstance();
    $pdo->exec("INSERT IGNORE INTO anggota (nama, email) VALUES
        ('Siti Aminah', 'siti@email.com'),
        ('Rudi Hartono', 'rudi@email.com')");

    echo "=== Semua Anggota ===\n";
    foreach ($anggotaDB->getAllAnggota() as $a) {
        echo "[{$a['id']}] {$a['nama']} — {$a['email']}\n";
    }

    echo "\n=== Anggota ID 1 ===\n";
    $anggota = $anggotaDB->getAnggotaById(1);
    if ($anggota) {
        echo "{$anggota['nama']} — {$anggota['email']}\n";
    } else {
        echo "Anggota tidak ditemukan\n";
    }

} catch (PDOException $e) {
    echo "Error database: " . $e->getMessage() . "\n";
}
?>
```
