# Interface & Trait — Kontrak dan Reuse Code

## Penjelasan

**Interface** adalah **kontrak** yang mendefinisikan method apa saja yang harus dimiliki sebuah class, tanpa implementasi. Class yang `implements` interface **wajib** menyediakan implementasi untuk semua method interface. Interface memungkinkan polymorphism tanpa hierarki pewarisan.

**Trait** adalah **kumpulan method siap pakai** yang bisa digunakan kembali (reused) oleh banyak class. PHP tidak mendukung multiple inheritance, tapi trait menyediakan cara untuk berbagi implementasi antar class yang tidak memiliki hubungan parent-child.

| Aspek | Interface | Trait |
|-------|-----------|-------|
| Keyword | `interface`, `implements` | `trait`, `use` |
| Isi | Hanya deklarasi method (tanpa body) | Implementasi method lengkap |
| Bisa punya properti? | Tidak | Ya |
| Bisa punya method private? | Tidak | Ya |
| Bisa di-instantiate? | Tidak | Tidak |
| Digunakan berapa class? | Banyak class | Banyak class |
| Fungsi utama | Kontrak/standarisasi | Reuse code tanpa inheritance |

```php
<?php
// Interface — kontrak method
interface Printable {
    public function cetakInfo(): string;
}

// Trait — implementasi siap pakai
trait Loggable {
    public function log(string $pesan): void {
        echo "[LOG] $pesan\n";
    }
}

class Buku implements Printable {
    use Loggable;
    public function cetakInfo(): string {
        return "Ini buku";
    }
}
?>
```

## Fungsi

Interface memastikan class-class yang tidak terkait secara hierarki tetap memiliki method yang sama (polymorphism). Trait menghindari duplikasi kode di beberapa class yang membutuhkan fungsionalitas yang sama, tanpa memaksa mereka untuk memiliki parent yang sama.

## Cara Pengimplementasian / Code

```php
<?php
// =====================
// Interface: Pinjamable
// =====================
interface Pinjamable {
    public function pinjam(string $namaPeminjam): bool;
    public function kembalikan(): bool;
    public function isDipinjam(): bool;
}

// =====================
// Interface: Searchable
// =====================
interface Searchable {
    public function getKeyword(): string;
    public function match(string $kataKunci): bool;
}

// =====================
// Trait: Timestampable
// =====================
trait Timestampable {
    private string $dibuatPada;
    private string $diperbaruiPada;

    public function initTimestamp(): void {
        $this->dibuatPada     = date('Y-m-d H:i:s');
        $this->diperbaruiPada = $this->dibuatPada;
    }

    public function touch(): void {
        $this->diperbaruiPada = date('Y-m-d H:i:s');
    }

    public function getWaktuDibuat(): string {
        return $this->dibuatPada;
    }

    public function getWaktuDiperbarui(): string {
        return $this->diperbaruiPada;
    }
}

// =====================
// Trait: Identifiable
// =====================
trait Identifiable {
    private string $id;

    public function generateId(string $prefix): void {
        $this->id = $prefix . '-' . strtoupper(bin2hex(random_bytes(4)));
    }

    public function getId(): string {
        return $this->id;
    }
}

// =====================
// Class Buku — implements Pinjamable & Searchable
// =====================
class Buku implements Pinjamable, Searchable {
    use Timestampable, Identifiable;

    private string $judul;
    private string $pengarang;
    private bool $dipinjam = false;
    private ?string $peminjam = null;

    public function __construct(string $judul, string $pengarang) {
        $this->judul     = $judul;
        $this->pengarang = $pengarang;
        $this->generateId('BK');
        $this->initTimestamp();
    }

    public function pinjam(string $namaPeminjam): bool {
        if ($this->dipinjam) {
            return false;
        }
        $this->dipinjam  = true;
        $this->peminjam  = $namaPeminjam;
        $this->touch();
        return true;
    }

    public function kembalikan(): bool {
        if (!$this->dipinjam) {
            return false;
        }
        $this->dipinjam  = false;
        $this->peminjam  = null;
        $this->touch();
        return true;
    }

    public function isDipinjam(): bool {
        return $this->dipinjam;
    }

    public function getKeyword(): string {
        return $this->judul . ' ' . $this->pengarang;
    }

    public function match(string $kataKunci): bool {
        return stripos($this->getKeyword(), $kataKunci) !== false;
    }

    public function getInfo(): string {
        $status = $this->dipinjam ? "Dipinjam {$this->peminjam}" : "Tersedia";
        return "[{$this->getId()}] {$this->judul} — {$this->pengarang} ($status)";
    }
}

// =====================
// Class Majalah — implements Pinjamable
// =====================
class Majalah implements Pinjamable {
    use Timestampable, Identifiable;

    private string $nama;
    private int $edisi;
    private bool $dipinjam = false;

    public function __construct(string $nama, int $edisi) {
        $this->nama  = $nama;
        $this->edisi = $edisi;
        $this->generateId('MJ');
        $this->initTimestamp();
    }

    public function pinjam(string $namaPeminjam): bool {
        if ($this->dipinjam) return false;
        $this->dipinjam = true;
        $this->touch();
        return true;
    }

    public function kembalikan(): bool {
        if (!$this->dipinjam) return false;
        $this->dipinjam = false;
        $this->touch();
        return true;
    }

    public function isDipinjam(): bool {
        return $this->dipinjam;
    }

    public function getInfo(): string {
        return "[{$this->getId()}] {$this->nama} Edisi {$this->edisi}";
    }
}

// =====================
// Penggunaan
// =====================
$buku1 = new Buku('PHP Dasar', 'Andi');
$buku2 = new Buku('Laravel Pro', 'Budi');
$majalah = new Majalah('Tempo', 12);

// Pinjam buku
$buku1->pinjam('Siti Aminah');
$buku1->touch();

echo "=== Peminjaman ===\n";
echo $buku1->getInfo() . "\n"; // Dipinjam Siti Aminah
echo $buku2->getInfo() . "\n"; // Tersedia
echo $majalah->getInfo() . "\n";

echo "\n=== Timestamp ===\n";
echo "Buku1 dibuat: {$buku1->getWaktuDibuat()}\n";
echo "Buku1 diupdate: {$buku1->getWaktuDiperbarui()}\n";

echo "\n=== Pencarian ===\n";
$kataKunci = 'PHP';
foreach ([$buku1, $buku2] as $buku) {
    if ($buku->match($kataKunci)) {
        echo "Ditemukan: {$buku->getInfo()}\n";
    }
}

// Kembalikan buku
$buku1->kembalikan();
echo "\nSetelah dikembalikan:\n";
echo $buku1->getInfo() . "\n";
?>
```

## Analogi

**Interface** seperti **standar nasional pelayanan perpustakaan** — ditetapkan bahwa setiap perpustakaan WAJIB menyediakan layanan: `pinjamBuku()`, `kembalikanBuku()`, `cariBuku()`. Naskah standar ini hanya berisi daftar layanan (tanpa detail cara kerja). Perpustakaan kota dan perpustakaan universitas sama-sama mengikuti standar ini (`implements`), tapi cara detailnya bisa berbeda (yang satu pakai kertas, yang lain pakai sistem digital).

**Trait** seperti **mesin fotokopi dan printer standar** yang bisa dipasang di perpustakaan mana pun — tanpa harus membeli merek rak atau meja yang sama. Perpustakaan kota (class `PerpustakaanKota`) dan perpustakaan keliling (class `PerpustakaanKeliling`) bisa sama-sama `use` mesin fotokopi (`trait Fotokopi`) tanpa harus menjadi turunan dari class `PusatPeralatan`.

## Dipakai untuk Apa

- **Interface**: Membuat kode yang fleksibel terhadap perubahan — Anda bisa mengganti implementasi class selama mengikuti kontrak interface yang sama
- **Interface**: Dependency injection — parameter function menerima interface, bukan class konkret, sehingga class apa pun bisa dipakai
- **Interface**: Multiple contracts — satu class bisa `implements` banyak interface sekaligus
- **Trait**: Berbagi method antar class yang tidak memiliki hubungan hierarki
- **Trait**: Menambahkan fungsionalitas lintas sektor (logging, timestamp, event dispatching) tanpa mengubah struktur inheritance
- **Trait**: Mengurai class besar menjadi modul-modul kecil yang bisa digunakan ulang

## Kesalahan Umum yang Sering Terjadi

- **Interface tidak diimplementasi lengkap**: Lupa satu method saja dari interface → error fatal.
- **Mengubah signature method di class implementer**: Parameter method harus cocok dengan deklarasi di interface.
- **Salah paham kontrak**: Interface tanpa implementasi bukan berarti opsional — class wajib mengimplementasikannya.
- **Trait conflict**: Dua trait punya method dengan nama yang sama → error; gunakan `insteadof` atau `as` untuk resolusi.
- **Trait mengakses properti yang tidak ada**: Trait mengasumsikan properti tertentu ada di class — pastikan class yang menggunakan trait memiliki properti tersebut.
- **Overuse trait untuk logika bisnis utama**: Trait sebaiknya untuk perilaku lintas sektor (cross-cutting), bukan untuk hierarki bisnis.

## Soal Latihan & Jawaban

### Soal

Buat interface `Dendaable` dengan method `hitungDenda(int $hariTerlambat): float` dan `getDendaPerHari(): float`. Buat trait `Deskriptable` dengan properti `private string $deskripsi`, method `setDeskripsi(string $deskripsi): void` dan `getDeskripsi(): string`. Buat class `BukuDigital` yang `implements Dendaable` dan `use Deskriptable` — method `hitungDenda()` mengembalikan `$hariTerlambat * 500` dan `getDendaPerHari()` mengembalikan `500`. Buat object dan uji kedua fungsionalitasnya.

### Jawaban

```php
<?php
interface Dendaable {
    public function hitungDenda(int $hariTerlambat): float;
    public function getDendaPerHari(): float;
}

trait Deskriptable {
    private string $deskripsi;

    public function setDeskripsi(string $deskripsi): void {
        $this->deskripsi = $deskripsi;
    }

    public function getDeskripsi(): string {
        return $this->deskripsi;
    }
}

class BukuDigital implements Dendaable {
    use Deskriptable;

    private string $judul;

    public function __construct(string $judul) {
        $this->judul = $judul;
    }

    public function hitungDenda(int $hariTerlambat): float {
        return $hariTerlambat * $this->getDendaPerHari();
    }

    public function getDendaPerHari(): float {
        return 500;
    }
}

$bukuDigital = new BukuDigital('E-book PHP');
$bukuDigital->setDeskripsi('E-book tentang PHP untuk pemula');

echo "Buku: " . $bukuDigital->getDeskripsi() . "\n";
echo "Denda per hari: Rp" . $bukuDigital->getDendaPerHari() . "\n";
echo "Denda 5 hari terlambat: Rp" . $bukuDigital->hitungDenda(5) . "\n";
?>
```
