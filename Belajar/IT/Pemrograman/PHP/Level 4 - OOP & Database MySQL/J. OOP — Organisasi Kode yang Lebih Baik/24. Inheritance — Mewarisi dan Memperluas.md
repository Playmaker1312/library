# Inheritance — Mewarisi dan Memperluas

## Penjelasan

**Inheritance** (pewarisan) adalah mekanisme OOP di mana sebuah class (child) mewarisi properti dan method dari class lain (parent). Child class bisa:

- **Menggunakan** properti/method parent secara langsung
- **Menambahkan** properti/method baru yang tidak dimiliki parent
- **Override** (menimpa) method parent dengan implementasi sendiri

Keyword: `extends`

| Istilah | PHP | Keterangan |
|---------|-----|------------|
| Parent class | `class Pegawai {}` | Class yang diwarisi |
| Child class | `class Pustakawan extends Pegawai {}` | Class yang mewarisi |
| `parent::` | `parent::__construct(...)` | Memanggil method milik parent |
| `protected` | `protected $gaji` | Bisa diakses child, tidak dari luar |
| `final` | `final class` atau `final function` | Mencegah pewarisan/override |

PHP hanya mendukung **single inheritance** — satu child hanya bisa memiliki satu parent. Untuk multiple inheritance, gunakan Trait (materi 25).

```php
<?php
class Pegawai {
    protected string $nama;
    protected int $gajiPokok = 3000000;

    public function __construct(string $nama) {
        $this->nama = $nama;
    }

    public function getInfo(): string {
        return "Nama: {$this->nama}, Gaji: Rp{$this->gajiPokok}";
    }
}

class Pustakawan extends Pegawai {
    public int $jumlahBukuDiurus = 0;

    public function __construct(string $nama, int $jumlahBukuDiurus) {
        parent::__construct($nama); // panggil constructor parent
        $this->jumlahBukuDiurus = $jumlahBukuDiurus;
    }

    public function getInfo(): string {
        return parent::getInfo() . ", Buku diurus: {$this->jumlahBukuDiurus}";
    }
}

$pustakawan = new Pustakawan('Budi', 150);
echo $pustakawan->getInfo(); // Nama: Budi, Gaji: Rp3000000, Buku diurus: 150
?>
```

## Fungsi

Menghindari duplikasi kode dengan menempatkan logika umum di class parent. Memungkinkan hierarki class yang natural — Pustakawan `is-a` Pegawai. Memudahkan maintenance: perubahan di parent otomatis berlaku untuk semua child. Mendukung konsep polymorphism: child bisa dipakai di mana pun parent diharapkan.

## Cara Pengimplementasian / Code

```php
<?php
// =====================
// Parent Class: Koleksi
// =====================
class Koleksi {
    protected string $judul;
    protected string $tahunTerbit;
    protected bool $tersedia = true;

    public function __construct(string $judul, string $tahunTerbit) {
        $this->judul        = $judul;
        $this->tahunTerbit  = $tahunTerbit;
    }

    public function getJudul(): string {
        return $this->judul;
    }

    public function getInfo(): string {
        return "'{$this->judul}' ({$this->tahunTerbit})";
    }

    public function tandaiTersedia(bool $status): void {
        $this->tersedia = $status;
    }

    public function isTersedia(): bool {
        return $this->tersedia;
    }
}

// =====================
// Child Class: Buku (extends Koleksi)
// =====================
class Buku extends Koleksi {
    private string $pengarang;
    private int $jumlahHalaman;

    public function __construct(string $judul, string $tahunTerbit, string $pengarang, int $jumlahHalaman) {
        parent::__construct($judul, $tahunTerbit);
        $this->pengarang     = $pengarang;
        $this->jumlahHalaman = $jumlahHalaman;
    }

    public function getInfo(): string {
        return parent::getInfo() . " — {$this->pengarang}, {$this->jumlahHalaman} hlm";
    }
}

// =====================
// Child Class: Majalah (extends Koleksi)
// =====================
class Majalah extends Koleksi {
    private int $edisi;
    private string $penerbit;

    public function __construct(string $judul, string $tahunTerbit, int $edisi, string $penerbit) {
        parent::__construct($judul, $tahunTerbit);
        $this->edisi    = $edisi;
        $this->penerbit = $penerbit;
    }

    public function getInfo(): string {
        return parent::getInfo() . " — Edisi {$this->edisi}, {$this->penerbit}";
    }
}

// =====================
// Child Class: DVD (extends Koleksi)
// =====================
class DVD extends Koleksi {
    private int $durasiMenit;

    public function __construct(string $judul, string $tahunTerbit, int $durasiMenit) {
        parent::__construct($judul, $tahunTerbit);
        $this->durasiMenit = $durasiMenit;
    }

    public function getInfo(): string {
        return parent::getInfo() . " — {$this->durasiMenit} menit";
    }
}

// =====================
// Penggunaan Inheritance
// =====================
$buku   = new Buku('PHP Dasar', '2025', 'Andi Programmer', 350);
$majalah = new Majalah('Tempo', '2026', 12, 'Tempo Media');
$dvd    = new DVD('Tutorial Laravel', '2026', 180);

$koleksi = [$buku, $majalah, $dvd];

echo "=== Daftar Koleksi Perpustakaan ===\n";
foreach ($koleksi as $item) {
    $status = $item->isTersedia() ? 'Tersedia' : 'Dipinjam';
    echo "- {$item->getInfo()} [$status]\n";
}

// Test override — method getInfo berbeda untuk setiap class
echo "\n=== Detail Per Item ===\n";
echo $buku->getInfo() . "\n";    // 'PHP Dasar' (2025) — Andi Programmer, 350 hlm
echo $majalah->getInfo() . "\n";  // 'Tempo' (2026) — Edisi 12, Tempo Media
echo $dvd->getInfo() . "\n";     // 'Tutorial Laravel' (2026) — 180 menit
?>
```

## Analogi

Di perpustakaan ada **formulir dasar "Koleksi"** yang mencatat `judul`, `tahunTerbit`, dan `tersedia`. Dari situ dibuat **turunan spesifik**: Formulir "Buku" (tambah kolom `pengarang`, `halaman`), Formulir "Majalah" (tambah kolom `edisi`, `penerbit`), dan Formulir "DVD" (tambah kolom `durasi`). Ketiganya mewarisi kolom dasar tetapi punya kolom tambahan sesuai jenis koleksi. Pustakawan bisa memperlakukan semua sebagai "Koleksi" — cukup lihat judul dan status tersedia — atau melihat detail spesifik sesuai jenisnya.

## Dipakai untuk Apa

- **Hierarki entitas**: User → Admin, Customer; Koleksi → Buku, Majalah, DVD; Karyawan → Manager, Staff
- **DRY (Don't Repeat Yourself)**: Logika umum cukup ditulis sekali di parent
- **Polymorphism**: Satu fungsi bisa menerima berbagai tipe child class
- **Framework**: Eloquent ORM (Laravel) menggunakan inheritance untuk Model; Controller inheritance untuk middleware
- **Plugin/Extension system**: Class dasar bisa diperluas oleh modul tambahan

## Kesalahan Umum yang Sering Terjadi

- **Lupa `parent::__construct()`**: Constructor child tidak otomatis memanggil constructor parent — properti parent tidak terinisialisasi.
- **Override tanpa `parent::`**: Method override tidak menggunakan logika parent — kadang malah menghilangkan fungsionalitas penting.
- **Akses properti `private` dari child**: Properti `private` hanya bisa diakses dari class tempat ia didefinisikan. Gunakan `protected` jika child perlu mengaksesnya.
- **Hierarki terlalu dalam**: Inheritance 4-5 level ke bawah sulit dilacak alur kodenya — lebih baik gunakan composition.
- **Salah konsep "is-a"**: Meng-extends hanya untuk reuse method padahal tidak ada hubungan logis — lebih baik gunakan trait atau composition.
- **Menggunakan `final` secara berlebihan**: `final class` mencegah pewarisan — pakai hanya jika memang class tidak boleh di-extends.

## Soal Latihan & Jawaban

### Soal

Buat parent class `PenggunaPerpustakaan` dengan properti `protected string $nama`, `protected string $idAnggota`, dan method `getPeran(): string` yang mengembalikan "Pengguna". Buat dua child: `Anggota` (tambah properti `int $maksPinjam = 3`, override `getPeran()` mengembalikan "Anggota") dan `Petugas` (tambah properti `string $jabatan`, override `getPeran()` mengembalikan "Petugas: {jabatan}"). Buat object dari masing-masing class dan tampilkan peran mereka.

### Jawaban

```php
<?php
class PenggunaPerpustakaan {
    protected string $nama;
    protected string $idAnggota;

    public function __construct(string $nama, string $idAnggota) {
        $this->nama       = $nama;
        $this->idAnggota  = $idAnggota;
    }

    public function getPeran(): string {
        return "Pengguna";
    }

    public function getInfo(): string {
        return "{$this->nama} ({$this->idAnggota})";
    }
}

class Anggota extends PenggunaPerpustakaan {
    public int $maksPinjam = 3;

    public function getPeran(): string {
        return "Anggota";
    }
}

class Petugas extends PenggunaPerpustakaan {
    public string $jabatan;

    public function __construct(string $nama, string $idAnggota, string $jabatan) {
        parent::__construct($nama, $idAnggota);
        $this->jabatan = $jabatan;
    }

    public function getPeran(): string {
        return "Petugas: {$this->jabatan}";
    }
}

$anggota = new Anggota('Siti Aminah', 'AGT-001');
$petugas = new Petugas('Budi Hartono', 'PTG-001', 'Pustakawan Senior');

echo "{$anggota->getInfo()} — Peran: {$anggota->getPeran()}\n";
echo "{$petugas->getInfo()} — Peran: {$petugas->getPeran()}\n";
?>
```
