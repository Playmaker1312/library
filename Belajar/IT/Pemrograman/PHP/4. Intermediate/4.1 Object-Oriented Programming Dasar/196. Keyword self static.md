# 196. Keyword self static

## Definisi Singkat
`self` merujuk ke class di mana kode ditulis, `static` merujuk ke class yang dipanggil saat runtime (late static binding).

## Analogi
`self` = panggil nomor telepon rumah; `static` = panggil nomor HP yang sedang dipegang.

## Poin-Poin Penting
- `self::` mengacu ke class saat ini (compile-time)
- `static::` mengacu ke class yang dipanggil (runtime)
- Perbedaan terlihat pada inheritance

## Contoh Kode (PHP)
```php
<?php
class Induk {
    public static function siapa() {
        echo "Induk";
    }
    public static function panggilSelf() {
        self::siapa();
    }
    public static function panggilStatic() {
        static::siapa();
    }
}

class Anak extends Induk {
    public static function siapa() {
        echo "Anak";
    }
}

Anak::panggilSelf();   // Induk
Anak::panggilStatic(); // Anak
?>
```

## Kasus Penggunaan Nyata
`static::` digunakan dalam pattern seperti ActiveRecord, Factory Method, dan Singleton.
