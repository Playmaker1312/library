# 198. Constructor property promotion PHP 8

## Definisi Singkat
Constructor property promotion (PHP 8) memungkinkan deklarasi property langsung di parameter constructor, menghemat kode boilerplate.

## Analogi
Dulu: daftar belanja ditulis di dua tempat (di daftar + di dompet). Sekarang: langsung di dompet saja.

## Poin-Poin Penting
- Fitur baru PHP 8.0+
- Gabungkan deklarasi property + assignment constructor
- Bisa ditambah access modifier di parameter
- Tetap bisa menambah logic di body constructor

## Contoh Kode (PHP)
```php
<?php
// Cara lama (PHP 7)
class UserLama {
    public string $nama;
    public string $email;
    public function __construct(string $nama, string $email) {
        $this->nama = $nama;
        $this->email = $email;
    }
}

// Cara baru PHP 8
class UserBaru {
    public function __construct(
        public string $nama,
        public string $email,
        private ?string $telepon = null
    ) {}
}

$u = new UserBaru("Budi", "budi@mail.com");
echo $u->nama; // Budi
?>
```

## Kasus Penggunaan Nyata
Semua class DTO (Data Transfer Object), Entity, Model di framework modern.
