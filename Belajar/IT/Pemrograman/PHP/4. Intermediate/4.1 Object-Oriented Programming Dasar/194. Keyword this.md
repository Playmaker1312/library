# 194. Keyword this

## Definisi Singkat
`$this` adalah pseudo-variable yang merujuk ke object saat ini, digunakan untuk mengakses property/method dalam class.

## Analogi
Seperti kata "saya" — ketika seseorang bicara, "saya" merujuk pada dirinya sendiri.

## Poin-Poin Penting
- Hanya bisa digunakan di dalam method class
- Gunakan `->` untuk akses property/method
- Tidak bisa digunakan di static method

## Contoh Kode (PHP)
```php
<?php
class Orang {
    public $nama;
    public function sapa() {
        return "Halo, saya " . $this->nama;
    }
    public function setNama($nama) {
        $this->nama = $nama;
    }
}

$o = new Orang();
$o->setNama("Andi");
echo $o->sapa(); // Halo, saya Andi
?>
```

## Kasus Penggunaan Nyata
Digunakan di hampir semua method non-static untuk mengakses property dan method lain dalam class yang sama.
