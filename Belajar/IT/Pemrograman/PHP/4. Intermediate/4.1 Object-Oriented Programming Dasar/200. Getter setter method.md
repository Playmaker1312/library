# 200. Getter setter method

## Definisi Singkat
Getter dan setter adalah method untuk membaca (get) dan mengubah (set) nilai property, mendukung prinsip encapsulation.

## Analogi
Seperti resepsionis hotel — tamu tidak langsung masuk kamar, tapi minta kunci melalui resepsionis (getter/setter).

## Poin-Poin Penting
- Property dibuat `private` atau `protected`
- Getter: method untuk mengambil nilai
- Setter: method untuk mengubah nilai (bisa dengan validasi)
- Convention: `getNamaProperty()`, `setNamaProperty($value)`

## Contoh Kode (PHP)
```php
<?php
class Mahasiswa {
    private $nilai = 0;
    public function getNilai() {
        return $this->nilai;
    }
    public function setNilai($nilai) {
        if ($nilai >= 0 && $nilai <= 100) {
            $this->nilai = $nilai;
        }
    }
}

$m = new Mahasiswa();
$m->setNilai(85);
echo $m->getNilai(); // 85
$m->setNilai(150);   // ditolak
?>
```

## Kasus Penggunaan Nyata
Validasi data saat input, formatting output, menghitung derived property, implementasi lazy loading.
