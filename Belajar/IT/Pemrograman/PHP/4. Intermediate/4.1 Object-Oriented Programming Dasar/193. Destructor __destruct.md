# 193. Destructor __destruct

## Definisi Singkat
Destructor adalah method spesial yang otomatis dipanggil saat object dihapus/dihancurkan, biasanya untuk cleanup (tutup koneksi, hapus file temp).

## Analogi
Seperti petugas kebersihan yang membereskan ruangan setelah acara selesai.

## Poin-Poin Penting
- Ditulis sebagai `__destruct()`
- Tidak menerima parameter
- Dipanggil otomatis saat object tidak lagi direferensi
- Cocok untuk menutup resource

## Contoh Kode (PHP)
```php
<?php
class FileManager {
    private $handle;
    public function __construct($file) {
        $this->handle = fopen($file, "r");
    }
    public function __destruct() {
        fclose($this->handle);
        echo "File ditutup";
    }
}

$fm = new FileManager("data.txt");
// saat $fm dihapus, destructor otomatis dipanggil
?>
```

## Kasus Penggunaan Nyata
Menutup koneksi database, menulis log, membersihkan memori cache.
