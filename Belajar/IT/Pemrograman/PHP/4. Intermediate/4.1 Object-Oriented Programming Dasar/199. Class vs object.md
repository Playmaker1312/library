# 199. Class vs object

## Definisi Singkat
**Class** adalah cetak biru/template, **Object** adalah instance nyata dari class yang memiliki data dan perilaku.

## Analogi
Class = resep kue (tertulis di buku); Object = kue jadi yang bisa dimakan.

## Poin-Poin Penting
| Aspek | Class | Object |
|-------|-------|--------|
| Definisi | Template | Instance |
| Memori | Tidak alokasi | Alokasi memori |
| Jumlah | Satu | Banyak |
| Data | Belum ada nilai konkret | Punya nilai konkret |

## Contoh Kode (PHP)
```php
<?php
// Class (cetak biru)
class Mobil {
    public $merk = "";
    public $warna = "";
    public function jalan() {
        echo "Vroom!";
    }
}

// Object (instance)
$m1 = new Mobil();
$m1->merk = "Toyota";
$m1->warna = "Hitam";

$m2 = new Mobil();
$m2->merk = "Honda";
$m2->warna = "Putih";

echo $m1->merk; // Toyota
echo $m2->merk; // Honda
?>
```

## Kasus Penggunaan Nyata
Membedakan konsep (class) vs implementasi nyata (object) dalam perancangan aplikasi.
