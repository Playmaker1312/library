# 191. Access modifiers public protected private

## Definisi Singkat
Access modifiers menentukan siapa yang bisa mengakses property/method: `public` (semua), `protected` (class sendiri & turunan), `private` (hanya class sendiri).

## Analogi
- **Public**: taman umum — semua orang boleh masuk
- **Protected**: halaman belakang — keluarga dan tamu tertentu
- **Private**: kamar pribadi — hanya pemiliknya

## Poin-Poin Penting
- `public`: bisa diakses dari mana saja
- `protected`: bisa diakses dari class dan class turunan
- `private`: hanya bisa diakses dari class yang sama

## Contoh Kode (PHP)
```php
<?php
class Bank {
    public $nama = "BCA";
    protected $saldo = 1000000;
    private $pin = 1234;
}

class BankSwasta extends Bank {
    public function lihatSaldo() {
        return $this->saldo; // OK, protected
        // return $this->pin; // ERROR, private
    }
}
?>
```

## Kasus Penggunaan Nyata
Property sensitif (password, PIN) diberi `private`, method internal helper diberi `protected`, API publik diberi `public`.
