# 188. Keyword new

## Definisi Singkat
`new` adalah keyword untuk membuat object (instance) dari sebuah class.

## Analogi
Class = blueprint rumah; `new` = perintah untuk membangun rumah berdasarkan blueprint.

## Poin-Poin Penting
- `new ClassName()` mengembalikan object
- Bisa membuat banyak object dari satu class
- Setiap object independen satu sama lain

## Contoh Kode (PHP)
```php
<?php
class Mobil {
    public $warna = "merah";
}

$m1 = new Mobil();
$m2 = new Mobil();
$m2->warna = "biru";

echo $m1->warna; // merah
echo $m2->warna; // biru
?>
```

## Kasus Penggunaan Nyata
Membuat banyak instance pengguna, produk, atau entitas lain dalam aplikasi.
