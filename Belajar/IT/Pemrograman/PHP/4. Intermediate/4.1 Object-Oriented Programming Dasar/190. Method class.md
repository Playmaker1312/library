# 190. Method class

## Definisi Singkat
Method adalah function yang dideklarasikan di dalam class untuk mendefinisikan perilaku object.

## Analogi
Remote TV — tombol-tombolnya adalah method yang melakukan sesuatu saat dipencet.

## Poin-Poin Penting
- Sama seperti function biasa tapi di dalam class
- Bisa menerima parameter dan mengembalikan nilai
- Diakses dengan `$object->methodName()`

## Contoh Kode (PHP)
```php
<?php
class Kalkulator {
    public function tambah($a, $b) {
        return $a + $b;
    }
    public function kurang($a, $b) {
        return $a - $b;
    }
}

$calc = new Kalkulator();
echo $calc->tambah(5, 3); // 8
echo $calc->kurang(5, 3); // 2
?>
```

## Kasus Penggunaan Nyata
Method `simpan()` pada class `User`, method `hitungTotal()` pada class `Order`, dll.
