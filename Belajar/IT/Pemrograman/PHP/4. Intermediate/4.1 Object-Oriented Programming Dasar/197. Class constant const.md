# 197. Class constant const

## Definisi Singkat
Class constant adalah nilai tetap yang dideklarasikan dengan `const` di dalam class, tidak bisa diubah setelah didefinisikan.

## Analogi
Seperti nama hari dalam seminggu — tetap, tidak berubah.

## Poin-Poin Penting
- Gunakan `const` tanpa `$`
- Tidak bisa diubah setelah deklarasi
- Diakses dengan `ClassName::KONSTANTA` atau `self::KONSTANTA`
- Bersifat public secara default

## Contoh Kode (PHP)
```php
<?php
class Matematika {
    const PI = 3.14159;
    const PHI = 1.618;
    public static function luasLingkaran($r) {
        return self::PI * $r * $r;
    }
}

echo Matematika::PI;            // 3.14159
echo Matematika::luasLingkaran(7); // 153.93791
?>
```

## Kasus Penggunaan Nyata
Konfigurasi tetap: status kode, tipe user, URL API, nilai matematika, kode error.
