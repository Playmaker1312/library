# 187. Keyword class

## Definisi Singkat
`class` adalah keyword untuk mendeklarasikan sebuah class — cetak biru yang mendefinisikan property dan method.

## Analogi
Seperti `function` untuk fungsi, `class` adalah wadah yang mengelompokkan data dan perilaku.

## Poin-Poin Penting
- Diawali keyword `class` diikuti nama class (PascalCase)
- Isi class dibungkus kurung kurawal `{}`
- Satu file boleh berisi banyak class (tidak disarankan)

## Contoh Kode (PHP)
```php
<?php
class Kucing {
    public $nama;
    public function suara() {
        echo "Meow!";
    }
}

class Anjing {
    public $nama;
    public function suara() {
        echo "Guk guk!";
    }
}
?>
```

## Kasus Penggunaan Nyata
Setiap entitas dalam aplikasi (User, Product, Order) direpresentasikan sebagai class.
