# 186. Konsep OOP class object property method

## Definisi Singkat
OOP (Object-Oriented Programming) adalah paradigma pemrograman yang menggunakan **class** sebagai cetak biru untuk membuat **object**, memiliki **property** (data) dan **method** (perilaku).

## Analogi
Class = cetakan kue; Object = kue hasil cetakan; Property = bahan/resep; Method = cara membuat.

## Poin-Poin Penting
- **Class**: kerangka/template
- **Object**: instance nyata dari class
- **Property**: variabel di dalam class
- **Method**: function di dalam class

## Contoh Kode (PHP)
```php
<?php
class Mobil {
    public $merk = "Toyota";        // property
    public function jalan() {        // method
        echo "Mobil melaju";
    }
}

$mobil1 = new Mobil();              // object
echo $mobil1->merk;                  // Toyota
$mobil1->jalan();                    // Mobil melaju
?>
```
