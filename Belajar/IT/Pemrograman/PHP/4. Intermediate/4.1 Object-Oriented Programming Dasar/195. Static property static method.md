# 195. Static property static method

## Definisi Singkat
Static property/method adalah properti/method yang dimiliki class, bukan oleh object. Diakses tanpa membuat instance.

## Analogi
Seperti papan pengumuman sekolah — semua siswa bisa melihatnya tanpa harus punya kelas masing-masing.

## Poin-Poin Penting
- Gunakan keyword `static`
- Diakses dengan `ClassName::$property` atau `ClassName::method()`
- Tidak bisa menggunakan `$this`
- Nilai static dibagi antar semua instance

## Contoh Kode (PHP)
```php
<?php
class Counter {
    public static $jumlah = 0;
    public static function tambah() {
        self::$jumlah++;
    }
}

Counter::tambah();
Counter::tambah();
echo Counter::$jumlah; // 2
?>
```

## Kasus Penggunaan Nyata
Database connection (singleton), helper/utility class, factory pattern, registry pattern.
