# 192. Constructor __construct

## Definisi Singkat
Constructor adalah method spesial yang otomatis dipanggil saat object dibuat dengan `new`, biasanya untuk inisialisasi data awal.

## Analogi
Seperti pengaturan awal mobil sebelum jalan — isi bensin, setel kursi, pasang sabuk pengaman.

## Poin-Poin Penting
- Ditulis sebagai `__construct()`
- Bisa menerima parameter
- Tidak perlu dipanggil manual
- Tidak bisa mengembalikan nilai

## Contoh Kode (PHP)
```php
<?php
class Product {
    public $nama;
    public $harga;

    public function __construct($nama, $harga) {
        $this->nama = $nama;
        $this->harga = $harga;
    }
}

$produk = new Product("Laptop", 15000000);
echo $produk->nama;  // Laptop
echo $produk->harga; // 15000000
?>
```

## Kasus Penggunaan Nyata
Mengisi properti awal saat membuat object, seperti data user dari database atau konfigurasi.
