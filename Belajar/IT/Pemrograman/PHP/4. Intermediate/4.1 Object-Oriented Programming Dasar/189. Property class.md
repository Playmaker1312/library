# 189. Property class

## Definisi Singkat
Property adalah variabel yang dideklarasikan di dalam class untuk menyimpan data/state dari object.

## Analogi
Seperti form isian — setiap object memiliki data sendiri di property-nya.

## Poin-Poin Penting
- Harus memiliki visibilitas (public/protected/private)
- Bisa memiliki nilai default
- Diakses dengan `$object->property` (tanpa `$` di depan nama property)

## Contoh Kode (PHP)
```php
<?php
class Mahasiswa {
    public $nama;
    public $nim = "000000";  // nilai default
    public $jurusan;
}

$mhs = new Mahasiswa();
$mhs->nama = "Budi";
$mhs->jurusan = "Informatika";
echo $mhs->nama; // Budi
?>
```

## Kasus Penggunaan Nyata
Menyimpan data entitas: nama user, harga produk, status pesanan, dll.
