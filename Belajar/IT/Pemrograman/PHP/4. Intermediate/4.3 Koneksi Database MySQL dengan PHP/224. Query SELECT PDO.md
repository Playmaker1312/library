# 224. Query SELECT PDO

## Definisi Singkat
Query SELECT dengan PDO menggunakan `query()` untuk statis atau `prepare()` + `execute()` untuk query dinamis.

## Analogi
PDO seperti kurir yang bisa mengantar berbagai paket — dia tahu alamatnya (DSN) dan bisa bawa aman (prepared statement).

## Poin-Poin Penting
- `$pdo->query($sql)` untuk query tanpa parameter
- `$pdo->prepare($sql)` lalu `$stmt->execute()` untuk parameter
- `$stmt->fetch()` untuk satu baris, `fetchAll()` untuk semua
- Gunakan `fetch mode` untuk format hasil

## Contoh Kode (PHP)
```php
<?php
$pdo = new PDO("mysql:host=localhost;dbname=belajar", "root", "");
$pdo->setAttribute(PDO::ATTR_DEFAULT_FETCH_MODE, PDO::FETCH_ASSOC);

// Query sederhana
$stmt = $pdo->query("SELECT * FROM products");
$products = $stmt->fetchAll();
foreach ($products as $p) {
    echo $p['nama'] . " - " . $p['harga'] . "<br>";
}

// Prepared statement
$stmt = $pdo->prepare("SELECT * FROM products WHERE harga > ?");
$stmt->execute([10000]);
$mahal = $stmt->fetchAll();
?>
```

## Kasus Penggunaan Nyata
Semua aplikasi Laravel/Symfony menggunakan PDO untuk SELECT query.
