# 218. PDO PHP Data Objects

## Definisi Singkat
PDO (PHP Data Objects) adalah ekstensi database abstraction layer yang memungkinkan koneksi ke berbagai database (MySQL, PostgreSQL, SQLite, dll).

## Analogi
Seperti charger universal — bisa dipakai untuk berbagai merek HP, tinggal ganti kabelnya.

## Poin-Poin Penting
- Database abstraction layer
- Mendukung 12+ database driver
- OOP-only (tidak ada procedural)
- Prepared statement built-in lebih aman
- Exception-based error handling

## Contoh Kode (PHP)
```php
<?php
try {
    $dsn = "mysql:host=localhost;dbname=belajar;charset=utf8";
    $pdo = new PDO($dsn, "root", "");
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    echo "Koneksi PDO berhasil";
} catch (PDOException $e) {
    echo "Gagal: " . $e->getMessage();
}
?>
```

## Kasus Penggunaan Nyata
Aplikasi yang portabel antar database, framework modern (Laravel, Symfony) menggunakan PDO.
