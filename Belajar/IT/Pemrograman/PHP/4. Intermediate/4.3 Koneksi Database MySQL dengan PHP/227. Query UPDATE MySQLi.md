# 227. Query UPDATE MySQLi

## Definisi Singkat
Query UPDATE dengan MySQLi untuk mengubah data yang sudah ada di tabel database.

## Analogi
Seperti mengedit dokumen — cari halaman yang salah, perbaiki, simpan.

## Poin-Poin Penting
- Gunakan `WHERE` untuk menentukan baris yang diupdate
- `$conn->affected_rows` untuk jumlah baris yang terpengaruh
- Prepared statement untuk input dinamis
- Jangan lupa WHERE — bisa mengupdate semua baris!

## Contoh Kode (PHP)
```php
<?php
$conn = new mysqli("localhost", "root", "", "belajar");

// UPDATE langsung
$sql = "UPDATE users SET status = 'aktif' WHERE id = 1";
$conn->query($sql);
echo $conn->affected_rows . " baris diupdate";

// Prepared statement
$stmt = $conn->prepare("UPDATE products SET harga = ? WHERE id = ?");
$stmt->bind_param("di", $hargaBaru, $id);

$hargaBaru = 15000;
$id = 5;
$stmt->execute();
echo $stmt->affected_rows . " produk diupdate";

$stmt->close();
$conn->close();
?>
```

## Kasus Penggunaan Nyata
Update profil user, ubah harga produk, edit status pesanan, ganti password.
