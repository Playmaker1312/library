# 219. MySQLi procedural

## Definisi Singkat
MySQLi procedural adalah cara menggunakan MySQLi dengan fungsi-fungsi seperti `mysqli_connect()`, `mysqli_query()`, dll, mirip gaya mysql lama.

## Analogi
Seperti memasak dengan resep langkah demi langkah — ikuti prosedurnya.

## Poin-Poin Penting
- Fungsi diawali `mysqli_`
- Parameter pertama biasanya koneksi (`$conn`)
- Cocok untuk migrasi dari mysql lama
- Lebih mudah dipahami pemula

## Contoh Kode (PHP)
```php
<?php
$conn = mysqli_connect("localhost", "root", "", "belajar");

if (!$conn) {
    die("Koneksi gagal: " . mysqli_connect_error());
}

$sql = "SELECT * FROM users WHERE aktif = 1";
$result = mysqli_query($conn, $sql);

while ($row = mysqli_fetch_assoc($result)) {
    echo $row['nama'] . "<br>";
}

mysqli_free_result($result);
mysqli_close($conn);
?>
```
