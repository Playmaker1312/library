# 225. fetch_assoc fetch_row fetch_object

## Definisi Singkat
Method fetch mengubah hasil query menjadi format yang bisa digunakan: `fetch_assoc()` (array asosiatif), `fetch_row()` (array numerik), `fetch_object()` (object).

## Analogi
Hasil kueri seperti kotak mainan — bisa dibongkar sebagai daftar (array), buku katalog (asosiatif), atau paket lengkap (object).

## Poin-Poin Penting
- `fetch_assoc()`: array dengan nama kolom sebagai key
- `fetch_row()`: array dengan index numerik
- `fetch_object()`: object dengan property nama kolom
- Default PDO: `PDO::FETCH_ASSOC`, `PDO::FETCH_OBJ`, dll

## Contoh Kode (PHP)
```php
<?php
$conn = new mysqli("localhost", "root", "", "belajar");
$result = $conn->query("SELECT id, nama FROM users");

// fetch_assoc
while ($row = $result->fetch_assoc()) {
    echo $row['nama']; // array asosiatif
}

// fetch_row
$result->data_seek(0);
while ($row = $result->fetch_row()) {
    echo $row[1]; // array numerik (index 1 = nama)
}

// fetch_object
$result->data_seek(0);
while ($row = $result->fetch_object()) {
    echo $row->nama; // object
}

// PDO equivalent
$stmt = $pdo->query("SELECT * FROM users");
$data = $stmt->fetchAll(PDO::FETCH_OBJ);
echo $data[0]->nama;
?>
```

## Kasus Penggunaan Nyata
Memilih format data sesuai kebutuhan: API (object), template (assoc), kompatibilitas library.
