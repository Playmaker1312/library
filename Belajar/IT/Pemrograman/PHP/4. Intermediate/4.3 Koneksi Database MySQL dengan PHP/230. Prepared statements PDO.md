# 230. Prepared statements PDO

## Definisi Singkat
Prepared statement di PDO menggunakan placeholder `?` atau `:nama` untuk mengikat parameter dengan aman, mencegah SQL injection.

## Analogi
Seperti mesin ATM — kamu masukkan kartu, pilih nominal, mesin proses tanpa kamu lihat mekanisme internal.

## Poin-Poin Penting
- `prepare()` dengan placeholder `?` (positional) atau `:nama` (named)
- `execute([...])` dengan array parameter
- Named parameter lebih jelas untuk banyak parameter
- PDO prepared statement lebih portabel antar database

## Contoh Kode (PHP)
```php
<?php
$pdo = new PDO("mysql:host=localhost;dbname=belajar", "root", "");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

// Positional placeholder (?)
$stmt = $pdo->prepare("INSERT INTO users (nama, email) VALUES (?, ?)");
$stmt->execute(["Budi", "budi@mail.com"]);

// Named placeholder (:nama)
$stmt = $pdo->prepare("INSERT INTO users (nama, email, umur) VALUES (:nama, :email, :umur)");
$stmt->execute([
    ':nama' => 'Siti',
    ':email' => 'siti@mail.com',
    ':umur' => 23
]);

// SELECT dengan parameter
$stmt = $pdo->prepare("SELECT * FROM products WHERE harga > :min AND kategori = :kat");
$stmt->execute([':min' => 5000, ':kat' => 'makanan']);
$products = $stmt->fetchAll();
?>
```

## Kasus Penggunaan Nyata
Form input, filter data, API dengan parameter user, bulk insert/update.
