# 217. MySQLi extension

## Definisi Singkat
MySQLi (MySQL Improved) adalah ekstensi PHP untuk berinteraksi dengan database MySQL, tersedia dalam mode procedural dan OOP.

## Analogi
Seperti remote TV yang didesain khusus untuk TV merek tertentu — fitur lengkap, optimal.

## Poin-Poin Penting
- Singkatan dari MySQL Improved
- Mendukung MySQL 4.1.3+
- Tersedia procedural (`mysqli_*`) dan OOP
- Mendukung prepared statement, transaction, multiple statements

## Contoh Kode (PHP)
```php
<?php
// Cek apakah MySQLi tersedia
if (extension_loaded("mysqli")) {
    echo "MySQLi tersedia";
} else {
    echo "MySQLi tidak tersedia";
}

// Informasi MySQLi
echo mysqli_get_client_info();
?>
```

## Kasus Penggunaan Nyata
Aplikasi PHP yang spesifik menggunakan MySQL, tidak perlu ganti database.
