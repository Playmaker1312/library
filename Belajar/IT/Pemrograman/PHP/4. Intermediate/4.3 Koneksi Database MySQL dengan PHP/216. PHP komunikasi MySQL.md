# 216. PHP komunikasi MySQL

## Definisi Singkat
PHP berkomunikasi dengan MySQL database melalui ekstensi seperti MySQLi dan PDO untuk menjalankan query dan mengelola data.

## Analogi
PHP seperti kasir, MySQL seperti gudang penyimpanan — kasir bertanya ke gudang untuk cek stok, ambil barang, atau simpan barang.

## Poin-Poin Penting
- Dua ekstensi utama: MySQLi (spesifik MySQL) dan PDO (universal)
- Koneksi membutuhkan host, username, password, database
- Gunakan prepared statements untuk keamanan
- Selalu tutup koneksi setelah selesai

## Contoh Kode (PHP)
```php
<?php
// Flow: Connect -> Query -> Fetch -> Close
$host = "localhost";
$user = "root";
$pass = "";
$db   = "belajar";

// Koneksi MySQLi
$conn = new mysqli($host, $user, $pass, $db);
$result = $conn->query("SELECT * FROM users");
$data = $result->fetch_all(MYSQLI_ASSOC);
$conn->close();
?>
```
