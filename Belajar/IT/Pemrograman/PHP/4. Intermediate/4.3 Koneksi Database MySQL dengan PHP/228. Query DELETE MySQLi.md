# 228. Query DELETE MySQLi

## Definisi Singkat
Query DELETE dengan MySQLi untuk menghapus data dari tabel database.

## Analogi
Seperti menghapus file — data yang sudah dihapus tidak bisa dikembalikan (kecuali ada backup/soft delete).

## Poin-Poin Penting
- Gunakan `WHERE` — tanpa WHERE semua baris terhapus!
- `$conn->affected_rows` untuk jumlah baris terhapus
- Pertimbangkan soft delete (kolom `deleted_at`) dari pada hard delete
- Prepared statement untuk input dinamis

## Contoh Kode (PHP)
```php
<?php
$conn = new mysqli("localhost", "root", "", "belajar");

// DELETE langsung
$sql = "DELETE FROM users WHERE id = 10";
if ($conn->query($sql) === TRUE) {
    echo $conn->affected_rows . " user dihapus";
}

// Prepared statement
$stmt = $conn->prepare("DELETE FROM products WHERE id = ?");
$stmt->bind_param("i", $id);
$id = 5;
$stmt->execute();

// Soft delete (lebih aman)
$stmt = $conn->prepare("UPDATE users SET deleted_at = NOW() WHERE id = ?");
$stmt->bind_param("i", $id);
$stmt->execute();

$stmt->close();
$conn->close();
?>
```

## Kasus Penggunaan Nyata
Hapus akun user, hapus produk tidak aktif, bersihkan log lama, soft delete untuk recovery.
