# 229. Prepared statements MySQLi

## Definisi Singkat
Prepared statement di MySQLi memisahkan SQL dari data, mencegah SQL injection dengan mengirim template query + data secara terpisah.

## Analogi
Seperti formulir dengan kolom kosong — kamu tidak menulis ulang formulir, hanya mengisi kolomnya.

## Poin-Poin Penting
- Gunakan `prepare()`, `bind_param()`, `execute()`
- Parameter placeholder: `?` (tanda tanya)
- `bind_param("ssi", $a, $b, $c)` — tipe: s=string, i=int, d=double, b=blob
- Prepared statement bisa di-execute ulang dengan data berbeda

## Contoh Kode (PHP)
```php
<?php
$conn = new mysqli("localhost", "root", "", "belajar");

// Prepare & bind
$stmt = $conn->prepare("INSERT INTO users (nama, email, umur) VALUES (?, ?, ?)");
$stmt->bind_param("ssi", $nama, $email, $umur);

// Execute dengan data pertama
$nama = "Andi";
$email = "andi@mail.com";
$umur = 25;
$stmt->execute();

// Execute dengan data kedua
$nama = "Rina";
$email = "rina@mail.com";
$umur = 22;
$stmt->execute();

echo "Data berhasil disimpan";
$stmt->close();
$conn->close();
?>
```

## Kasus Penggunaan Nyata
Insert/update massal dengan data berbeda, form input user, API dengan parameter dinamis.
