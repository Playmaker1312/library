# 222. Error koneksi database

## Definisi Singkat
Error koneksi terjadi saat PHP gagal terhubung ke MySQL karena berbagai alasan — server down, kredensial salah, database tidak ada.

## Analogi
Pintu terkunci — kamu punya kunci (kredensial) tapi salah satu, atau alamat rumah salah (host).

## Poin-Poin Penting
- MySQLi: cek `$conn->connect_error` atau `mysqli_connect_error()`
- PDO: tangkap `PDOException` dalam try-catch
- Jangan expose detail error di production
- Gunakan error_log untuk logging

## Contoh Kode (PHP)
```php
<?php
// MySQLi OOP
$conn = new mysqli("localhost", "root", "salah_password", "belajar");
if ($conn->connect_error) {
    die("Error: " . $conn->connect_error); // Hanya untuk development
}

// PDO
try {
    $pdo = new PDO("mysql:host=localhost;dbname=tidak_ada", "root", "");
} catch (PDOException $e) {
    error_log($e->getMessage()); // log ke file
    die("Maaf, terjadi gangguan sistem"); // pesan aman untuk user
}
?>
```

## Kasus Penggunaan Nyata
Handling maintenance mode, konfigurasi environment (dev/prod), auto-reconnect logic.
