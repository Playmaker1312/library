# 223. Query SELECT MySQLi

## Definisi Singkat
Query SELECT menggunakan MySQLi untuk mengambil data dari database, bisa dengan `query()` untuk tanpa parameter atau prepared statement.

## Analogi
Seperti bertanya ke petugas perpustakaan: "Tolong carikan buku tentang PHP."

## Poin-Poin Penting
- Gunakan `$conn->query($sql)` untuk query sederhana
- Hasil berupa object `mysqli_result`
- Loop dengan `fetch_assoc()` untuk mengambil baris
- Gunakan prepared statement jika ada input user

## Contoh Kode (PHP)
```php
<?php
$conn = new mysqli("localhost", "root", "", "belajar");

// SELECT semua
$sql = "SELECT * FROM products";
$result = $conn->query($sql);

echo "Jumlah produk: " . $result->num_rows . "<br>";

while ($row = $result->fetch_assoc()) {
    echo $row['nama'] . " - Rp" . $row['harga'] . "<br>";
}

// SELECT dengan kondisi
$sql2 = "SELECT * FROM products WHERE harga > 10000";
$result2 = $conn->query($sql2);

$conn->close();
?>
```

## Kasus Penggunaan Nyata
Menampilkan daftar produk, data pengguna, laporan, pencarian.
