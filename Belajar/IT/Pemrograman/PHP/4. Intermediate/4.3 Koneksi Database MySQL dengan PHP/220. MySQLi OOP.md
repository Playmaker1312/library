# 220. MySQLi OOP

## Definisi Singkat
MySQLi OOP adalah cara menggunakan MySQLi dengan object-oriented style, menggunakan class `mysqli`, `mysqli_result`, dll.

## Analogi
Seperti menggunakan aplikasi mobile — semua fitur diakses lewat interface terstruktur.

## Poin-Poin Penting
- Menggunakan object `new mysqli()`, `$conn->query()`
- Lebih modern dan rapi
- Mudah diintegrasi dengan kode OOP lain
- Method chaining bisa digunakan

## Contoh Kode (PHP)
```php
<?php
$conn = new mysqli("localhost", "root", "", "belajar");

if ($conn->connect_error) {
    die("Koneksi gagal: " . $conn->connect_error);
}

$sql = "SELECT id, nama, email FROM users";
$result = $conn->query($sql);

if ($result->num_rows > 0) {
    while ($row = $result->fetch_assoc()) {
        echo $row['nama'] . " - " . $row['email'] . "<br>";
    }
}

$result->free();
$conn->close();
?>
```

## Kasus Penggunaan Nyata
Aplikasi modern PHP, integrasi dengan framework, kode yang sudah OOP.
