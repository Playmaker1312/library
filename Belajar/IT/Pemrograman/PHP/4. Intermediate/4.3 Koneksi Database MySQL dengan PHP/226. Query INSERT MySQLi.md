# 226. Query INSERT MySQLi

## Definisi Singkat
Query INSERT dengan MySQLi untuk menambahkan data baru ke tabel database.

## Analogi
Mengisi formulir pendaftaran — data diisi lalu disimpan ke database.

## Poin-Poin Penting
- Gunakan `$conn->query($sql)` atau prepared statement
- Dapatkan ID terakhir dengan `$conn->insert_id`
- Prepared statement untuk keamanan dari SQL injection
- Periksa `$conn->affected_rows` untuk konfirmasi

## Contoh Kode (PHP)
```php
<?php
$conn = new mysqli("localhost", "root", "", "belajar");

// INSERT langsung (tidak disarankan untuk input user)
$sql = "INSERT INTO users (nama, email) VALUES ('Budi', 'budi@mail.com')";
if ($conn->query($sql) === TRUE) {
    echo "ID baru: " . $conn->insert_id;
}

// Prepared statement (AMAN)
$stmt = $conn->prepare("INSERT INTO users (nama, email) VALUES (?, ?)");
$stmt->bind_param("ss", $nama, $email);

$nama = "Siti";
$email = "siti@mail.com";
$stmt->execute();

echo "Data tersimpan, ID: " . $conn->insert_id;
$stmt->close();
$conn->close();
?>
```

## Kasus Penggunaan Nyata
Registrasi user, tambah produk, simpan order, posting komentar.
