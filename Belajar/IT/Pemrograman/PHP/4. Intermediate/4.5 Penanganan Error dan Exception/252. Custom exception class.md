# 252. Custom exception class

## Definisi Singkat
Custom exception class adalah class turunan dari `Exception` yang dibuat sendiri untuk menangani error spesifik aplikasi.

## Analogi
Seperti alarm kebakaran spesifik untuk dapur — bukan alarm umum, tapi khusus untuk masalah tertentu.

## Poin-Poin Penting
- Extend class `Exception`
- Bisa tambah property/method sendiri
- Memudahkan multiple catch yang spesifik
- Gunakan nama yang deskriptif

## Contoh Kode (PHP)
```php
<?php
class ValidationException extends Exception {
    private array $errors;
    public function __construct(string $message, array $errors = []) {
        parent::__construct($message, 400);
        $this->errors = $errors;
    }
    public function getErrors(): array {
        return $this->errors;
    }
}

class AuthenticationException extends Exception {
    public function __construct(string $message = "Unauthorized") {
        parent::__construct($message, 401);
    }
}

class DatabaseException extends Exception {
    public function __construct(string $message, int $code = 500) {
        parent::__construct($message, $code);
    }
}

// Penggunaan
try {
    $email = "";
    if (empty($email)) {
        throw new ValidationException("Email wajib diisi", ['email' => 'Required']);
    }
} catch (ValidationException $e) {
    echo $e->getMessage();
    print_r($e->getErrors());
} catch (AuthenticationException $e) {
    echo "Akses ditolak";
}
?>
```

## Kasus Penggunaan Nyata
Handler per jenis error di API (Validation, Auth, Database, NotFound), domain-specific exceptions.
