# 250. try catch

## Definisi Singkat
`try-catch` adalah blok untuk menangkap dan menangani exception yang dilempar (`throw`), mencegah script berhenti total.

## Analogi
Seperti jaring pengaman — saat ada yang jatuh (throw), jaring menangkapnya (catch).

## Poin-Poin Penting
- `try`: blok kode yang mungkin melempar exception
- `catch`: blok yang menangani exception
- Bisa multiple catch untuk exception berbeda
- Exception object memberikan informasi: `getMessage()`, `getCode()`, `getFile()`, `getLine()`

## Contoh Kode (PHP)
```php
<?php
function bagi($a, $b) {
    if ($b == 0) throw new Exception("Tidak bisa dibagi nol");
    return $a / $b;
}

// Basic try-catch
try {
    $hasil = bagi(10, 0);
    echo $hasil;
} catch (Exception $e) {
    echo "Error: " . $e->getMessage();
}

// Multiple catch
try {
    $file = fopen("data.txt", "r");
    if (!$file) throw new Exception("File tidak ditemukan");
    $data = fread($file, 100);
    fclose($file);
} catch (Exception $e) {
    echo "Terjadi error: " . $e->getFile() . " baris " . $e->getLine();
}
?>
```

## Kasus Penggunaan Nyata
File operations, koneksi database, API calls, validasi form — semua kode yang berpotensi error.
