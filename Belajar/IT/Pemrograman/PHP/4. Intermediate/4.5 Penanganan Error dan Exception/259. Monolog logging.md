# 259. Monolog logging

## Definisi Singkat
Monolog adalah library logging untuk PHP yang mengirim log ke berbagai channel (file, database, email, Slack, dll) dengan level yang terstruktur.

## Analogi
Seperti sistem notifikasi terpusat — kamu bisa atur: info ke buku catatan, warning ke email, error ke telepon.

## Poin-Poin Penting
- Install dengan `composer require monolog/monolog`
- Level: DEBUG, INFO, NOTICE, WARNING, ERROR, CRITICAL, ALERT, EMERGENCY
- Setiap logger punya Handler (tujuan) dan Formatter (format)
- Bisa multiple handler untuk satu logger

## Contoh Kode (PHP)
```php
<?php
require 'vendor/autoload.php';

use Monolog\Logger;
use Monolog\Handler\StreamHandler;
use Monolog\Handler\RotatingFileHandler;
use Monolog\Formatter\LineFormatter;

// Buat logger
$log = new Logger('aplikasi');

// Handler ke file (rotate harian)
$log->pushHandler(new RotatingFileHandler(
    __DIR__ . '/../logs/app.log', 30, Logger::DEBUG
));

// Handler ke file error terpisah
$log->pushHandler(new StreamHandler(
    __DIR__ . '/../logs/error.log', Logger::ERROR
));

// Gunakan
$log->info("User login", ['user_id' => 123, 'ip' => '192.168.1.1']);
$log->warning("Stok produk menipis", ['produk' => 'Laptop', 'sisa' => 2]);
$log->error("Database connection failed", ['exception' => $e->getMessage()]);
?>
```

## Kasus Penggunaan Nyata
Logging aplikasi production, audit trail, monitoring error, analytics user behavior, debugging.
