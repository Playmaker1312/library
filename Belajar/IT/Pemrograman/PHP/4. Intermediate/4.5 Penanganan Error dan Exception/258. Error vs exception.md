# 258. Error vs exception

## Definisi Singkat
**Error** = masalah tingkat engine (tidak bisa di-catch dengan try-catch, kecuali ErrorException). **Exception** = masalah tingkat aplikasi (bisa di-catch).

## Analogi
- **Error**: mesin mobil mati total — tidak bisa diperbaiki jalan, harus ke bengkel
- **Exception**: ban bocor — bisa diperbaiki di pinggir jalan (handle)

## Poin-Poin Penting
| Aspek | Error | Exception |
|-------|-------|-----------|
| Penyebab | Fatal, Parse, Compile | Logic aplikasi |
| Catch | Tidak bisa (kecuali Error class PHP 7+) | Bisa dengan try-catch |
| Handling | set_error_handler + shutdown | try-catch |
| PHP 7+ | `Throwable` interface mencakup Error & Exception | |

## Contoh Kode (PHP)
```php
<?php
// Exception — bisa ditangkap
try {
    throw new Exception("Error aplikasi");
} catch (Exception $e) {
    echo "Exception tertangkap: " . $e->getMessage();
}

// Error PHP 7+ — bisa ditangkap sebagai Throwable
try {
    tidakAdaFungsi(); // Fatal error
} catch (Throwable $e) {
    echo "Error tertangkap: " . $e->getMessage();
}

// Error type hinting
function proses(int $data) {}
try {
    proses("bukan angka"); // TypeError
} catch (TypeError $e) {
    echo "Type error: " . $e->getMessage();
}
?>
```

## Kasus Penggunaan Nyata
Error → fatal yang tidak bisa dipulihkan, Exception → error yang bisa di-handle dan dipulihkan.
