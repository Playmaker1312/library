# 246. Jenis error PHP Parse Fatal Warning Notice Deprecated

## Definisi Singkat
PHP memiliki beberapa tingkat error: **Parse** (syntax salah), **Fatal** (error kritis), **Warning** (non-kritis), **Notice** (peringatan ringan), **Deprecated** (fitur usang).

## Analogi
- **Parse**: kalimat tidak jelas — "aku pergi ke" (tidak lengkap)
- **Fatal**: mobil mogok total, tidak bisa jalan
- **Warning**: lampu bensin menyala — peringatan tapi masih bisa jalan
- **Notice**: dasbor ada goresan kecil — tidak masalah
- **Deprecated**: HP model lama — masih bisa dipakai tapi tidak disarankan

## Poin-Poin Penting
- **Parse Error**: syntax salah, script berhenti total
- **Fatal Error**: fungsi/class tidak ditemukan, script berhenti
- **Warning**: include gagal, file tidak ada — script lanjut
- **Notice**: variabel undefined — script lanjut
- **Deprecated**: fungsi usang — script lanjut, akan error di versi depan

## Contoh Kode (PHP)
```php
<?php
// Parse Error
// echo "Halo   // syntax error

// Fatal Error
// $obj = new ClassTidakAda();

// Warning
// include "file_tidak_ada.php";

// Notice
// echo $variabel_belum_didefinisikan;

// Deprecated
$conn = mysql_connect("localhost", "root", ""); // deprecated di PHP 7+
?>
```

## Kasus Penggunaan Nyata
Debugging aplikasi, memahami log error, menyesuaikan error_reporting untuk development/production.
