# 253. Multiple exception catch

## Definisi Singkat
Multiple exception catch menangani berbagai jenis exception dengan blok catch terpisah, memberikan respons yang berbeda untuk setiap jenis.

## Analogi
Seperti panel kontrol — tombol merah untuk kebakaran, tombol biru untuk banjir, tombol hijau untuk listrik mati. Masing-masing ditangani berbeda.

## Poin-Poin Penting
- Catch dari yang paling spesifik ke umum
- PHP 8+: pipe syntax `catch (ErrorA | ErrorB $e)`
- Setiap catch punya logic penanganan berbeda
- Bisa punya default catch terakhir dengan `Exception $e`

## Contoh Kode (PHP)
```php
<?php
class FileException extends Exception {}
class NetworkException extends Exception {}
class PermissionException extends Exception {}

function prosesUpload($file) {
    if (!file_exists($file)) throw new FileException("File tidak ada");
    if (!is_readable($file)) throw new PermissionException("Tidak bisa baca");
    if (!$this->kirimKeServer($file)) throw new NetworkException("Gagal upload");
}

try {
    prosesUpload("foto.jpg");
} catch (FileException $e) {
    echo "File error: " . $e->getMessage();
} catch (PermissionException $e) {
    echo "Izin error: " . $e->getMessage();
} catch (NetworkException $e) {
    echo "Network error: " . $e->getMessage();
} catch (Exception $e) { // default catch
    echo "Error umum: " . $e->getMessage();
}

// PHP 8+ — multiple exception dalam satu catch
try {
    // kode
} catch (FileException | PermissionException $e) {
    echo "File/permission error";
} catch (Exception $e) {
    echo "Error lain";
}
?>
```

## Kasus Penggunaan Nyata
API handler yang membedakan 400 (Validation), 401 (Auth), 404 (Not Found), 500 (Server Error).
