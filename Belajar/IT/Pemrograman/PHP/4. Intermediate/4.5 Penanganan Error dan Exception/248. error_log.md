# 248. error_log

## Definisi Singkat
`error_log()` adalah fungsi untuk mengirim pesan error ke file log, email, atau syslog, tanpa menampilkannya ke user.

## Analogi
Seperti buku catatan rahasia — semua kejadian dicatat, tapi tidak dibacakan ke umum.

## Poin-Poin Penting
- `error_log($pesan)` — kirim ke log server default
- `error_log($pesan, 1, $email)` — kirim ke email
- `error_log($pesan, 3, $file)` — kirim ke file tertentu
- Jangan tampilkan error di layar production, log saja

## Contoh Kode (PHP)
```php
<?php
// Log ke file default (error_log di php.ini)
error_log("User gagal login: IP " . $_SERVER['REMOTE_ADDR']);

// Log ke file spesifik
$logFile = __DIR__ . "/../logs/error.log";
error_log("[ERROR] Database connection failed", 3, $logFile);

// Log dengan informasi waktu
$timestamp = date('Y-m-d H:i:s');
error_log("[$timestamp] [ERROR] Query gagal: " . $sql, 3, $logFile);

// Baca log
$log = file_get_contents($logFile);
echo nl2br($log);
?>
```

## Kasus Penggunaan Nyata
Monitoring error di production, audit trail, debugging tanpa expose ke user, analisis keamanan.
