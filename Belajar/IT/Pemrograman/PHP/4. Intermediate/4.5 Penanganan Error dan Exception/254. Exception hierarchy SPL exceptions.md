# 254. Exception hierarchy SPL exceptions

## Definisi Singkat
PHP memiliki hierarki exception SPL (Standard PHP Library): `Exception` adalah base, dengan turunan seperti `LogicException`, `RuntimeException`, dan spesifik lainnya.

## Analogi
Seperti pohon keluarga — ada kakek Exception, punya anak LogicException dan RuntimeException, masing-masing punya cucu sendiri.

## Poin-Poin Penting
- `LogicException`: error logika programming (harus diperbaiki developer)
  - `InvalidArgumentException`
  - `LengthException`
  - `OutOfRangeException`
- `RuntimeException`: error runtime (bisa di-handle)
  - `PDOException`
  - `UnexpectedValueException`
  - `OutOfBoundsException`

## Contoh Kode (PHP)
```php
<?php
// LogicException — kesalahan programming
function setUmur($umur) {
    if ($umur < 0) {
        throw new InvalidArgumentException("Umur tidak boleh negatif");
    }
    if ($umur > 150) {
        throw new OutOfRangeException("Umur tidak realistis");
    }
}

// RuntimeException — error saat eksekusi
function cariUser($id) {
    if ($id <= 0) {
        throw new InvalidArgumentException("ID harus positif");
    }
    // Simulasi user tidak ditemukan
    throw new UnexpectedValueException("User dengan ID $id tidak ditemukan");
}

// Tangkap berdasarkan hierarki
try {
    cariUser(-1);
} catch (InvalidArgumentException $e) {
    echo "Input tidak valid: " . $e->getMessage();
} catch (UnexpectedValueException $e) {
    echo "Data tidak ditemukan: " . $e->getMessage();
} catch (LogicException $e) {
    echo "Logic error: " . $e->getMessage();
} catch (RuntimeException $e) {
    echo "Runtime error: " . $e->getMessage();
} catch (Exception $e) {
    echo "Error umum: " . $e->getMessage();
}
?>
```

## Kasus Penggunaan Nyata
Mengikuti standar SPL, membuat kode lebih predictable, integrasi dengan framework yang menggunakan SPL exceptions.
