# 257. register_shutdown_function

## Definisi Singkat
`register_shutdown_function()` mendaftarkan function yang dipanggil saat script PHP selesai dieksekusi, termasuk saat fatal error terjadi.

## Analogi
Seperti petugas kebersihan yang selalu membereskan ruangan setelah acara selesai, bagaimanapun acaranya berakhir.

## Poin-Poin Penting
- Dipanggil saat script selesai (normal/error)
- Berguna untuk cleanup dan logging
- Bisa mendeteksi error terakhir dengan `error_get_last()`
- Tidak menerima parameter secara otomatis

## Contoh Kode (PHP)
```php
<?php
register_shutdown_function(function() {
    $error = error_get_last();
    if ($error !== null && in_array($error['type'], [E_ERROR, E_PARSE, E_CORE_ERROR])) {
        $log = "[" . date('Y-m-d H:i:s') . "] FATAL: "
               . $error['message'] . " di "
               . $error['file'] . ":" . $error['line'];

        error_log($log, 3, __DIR__ . "/fatal_errors.log");
        echo "Terjadi kesalahan kritis. Tim kami sudah diberitahu.";
    }
});

// Trigger fatal error
// someFunctionTidakAda(); // Fatal error — akan ditangkap shutdown handler

echo "Script selesai normal";
?>
```

## Kasus Penggunaan Nyata
Menutup koneksi database, logging fatal error, cleanup resource, memastikan response dikirim.
