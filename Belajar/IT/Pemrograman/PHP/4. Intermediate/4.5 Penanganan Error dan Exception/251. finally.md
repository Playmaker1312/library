# 251. finally

## Definisi Singkat
Blok `finally` dieksekusi selalu setelah try-catch, baik terjadi exception maupun tidak — cocok untuk cleanup.

## Analogi
Seperti restoran — baik kamu selesai makan (sukses) atau menumpahkan makanan (error), kamu tetap harus bayar (finally).

## Poin-Poin Penting
- `finally` dieksekusi setelah try dan/atau catch
- Tetap dijalankan meskipun ada `return` di try/catch
- Cocok untuk menutup resource
- Bisa digunakan dengan try tanpa catch (hanya try-finally)

## Contoh Kode (PHP)
```php
<?php
function bacaFile($path) {
    $handle = null;
    try {
        $handle = fopen($path, "r");
        if (!$handle) throw new Exception("Gagal buka file");
        return fread($handle, 1000);
    } catch (Exception $e) {
        echo "Error: " . $e->getMessage();
        return null;
    } finally {
        if ($handle) {
            fclose($handle);
            echo "File ditutup";
        }
    }
}

function prosesData($data) {
    $conn = new PDO("mysql:host=localhost;dbname=test", "root", "");
    try {
        // proses data
        $conn->query("INSERT INTO log VALUES ('sukses')");
    } finally {
        $conn = null; // tutup koneksi
    }
}
?>
```

## Kasus Penggunaan Nyata
Menutup file handle, koneksi database, koneksi API, release lock/mutex dalam multi-thread.
