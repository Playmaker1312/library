# 249. Exception throw

## Definisi Singkat
`throw` digunakan untuk melempar exception (kesalahan) secara sengaja dalam kode, berhenti eksekusi jika tidak ditangkap.

## Analogi
Seperti wasit yang meniup peluit — permainan berhenti karena ada pelanggaran.

## Poin-Poin Penting
- `throw new Exception("pesan")` — lempar exception
- Eksekusi berhenti di throw, lanjut ke catch blok
- Bisa throw object dari class Exception atau turunannya
- Exception bisa membawa pesan, kode error, dan previous exception

## Contoh Kode (PHP)
```php
<?php
function bagi($a, $b) {
    if ($b == 0) {
        throw new Exception("Pembagian dengan nol tidak diperbolehkan");
    }
    return $a / $b;
}

function cekUmur($umur) {
    if ($umur < 0) {
        throw new InvalidArgumentException("Umur tidak valid");
    }
    if ($umur < 17) {
        throw new Exception("Terlalu muda untuk mendaftar");
    }
    return "Pendaftaran berhasil";
}

// throw dengan kode error
throw new Exception("File tidak ditemukan", 404);
?>
```

## Kasus Penggunaan Nyata
Validasi input user, cek kondisi sebelum proses, API error handling, authentication gates.
