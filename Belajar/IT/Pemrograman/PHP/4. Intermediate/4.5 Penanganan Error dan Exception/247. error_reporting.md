# 247. error_reporting

## Definisi Singkat
`error_reporting()` adalah fungsi untuk menentukan level error mana yang akan dilaporkan/ditampilkan oleh PHP.

## Analogi
Seperti volume suara — kamu bisa setel seberapa keras suara peringatan yang ingin didengar.

## Poin-Poin Penting
- Gunakan `E_ALL` untuk semua error (development)
- Gunakan `E_ALL & ~E_DEPRECATED` untuk abaikan deprecated
- Production: jangan tampilkan error, log saja
- Setting di `php.ini` atau runtime dengan `error_reporting()`

## Contoh Kode (PHP)
```php
<?php
// Tampilkan semua error
error_reporting(E_ALL);

// Tampilkan semua kecuali Notice dan Deprecated
error_reporting(E_ALL & ~E_NOTICE & ~E_DEPRECATED);

// Hanya error kritis
error_reporting(E_ERROR | E_PARSE | E_CORE_ERROR);

// Nonaktifkan semua laporan error (production)
error_reporting(0);

// Tampilkan error di layar (development)
ini_set('display_errors', 1);

// Sembunyikan error dari layar (production)
ini_set('display_errors', 0);
ini_set('log_errors', 1);
?>
```

## Kasus Penggunaan Nyata
File konfigurasi per environment: development (E_ALL on screen), production (E_ALL & ~E_DEPRECATED|~E_NOTICE ke log).
