# 256. set_exception_handler

## Definisi Singkat
`set_exception_handler()` mendaftarkan function yang dipanggil saat exception tidak tertangkap (uncaught exception), sebagai handler terakhir.

## Analogi
Seperti jaring pengaman terakhir di sirkus — jika semua penjaga (try-catch) gagal, jaring ini yang menangkap.

## Poin-Poin Penting
- Handler untuk uncaught exception
- Tidak bisa digantikan dengan try-catch setelahnya
- Berguna untuk logging dan response standar
- Eksekusi berhenti setelah handler selesai

## Contoh Kode (PHP)
```php
<?php
set_exception_handler(function($exception) {
    $message = "Uncaught Exception: " . $exception->getMessage();
    $log = "[" . date('Y-m-d H:i:s') . "] $message di "
           . $exception->getFile() . ":" . $exception->getLine();

    // Log ke file
    error_log($log, 3, __DIR__ . "/errors.log");

    // Tampilkan halaman error yang ramah
    if (php_sapi_name() !== 'cli') {
        http_response_code(500);
        echo "<h1>Terjadi Kesalahan</h1>";
        echo "<p>Silakan coba lagi nanti.</p>";
    } else {
        echo "ERROR: $message\n";
    }
});

// Exception ini tidak ditangkap, akan masuk handler
throw new Exception("Koneksi database gagal");
echo "Ini tidak akan pernah dieksekusi";
?>
```

## Kasus Penggunaan Nyata
Menampilkan halaman error 500 yang rapi, logging semua uncaught exception, mengirim notifikasi ke developer.
