# 255. set_error_handler

## Definisi Singkat
`set_error_handler()` membuat function kustom yang dipanggil saat terjadi error PHP (warning, notice, dll), mengubahnya jadi exception.

## Analogi
Seperti memasang detektor asap — saat ada api kecil (warning), langsung bunyi alarm, bukan menunggu kebakaran besar.

## Poin-Poin Penting
- Mengganti handler error default PHP
- Tidak menangani: E_ERROR, E_PARSE, E_CORE_ERROR, E_COMPILE_ERROR
- Sering dikombinasikan dengan `ErrorException`
- Kembalikan handler lama dengan `restore_error_handler()`

## Contoh Kode (PHP)
```php
<?php
// Ubah semua error jadi ErrorException
set_error_handler(function($level, $message, $file, $line) {
    throw new ErrorException($message, 0, $level, $file, $line);
});

// Sekarang warning/notice jadi exception yang bisa di-catch
try {
    echo $variable_tidak_ada; // Notice jadi exception
    include "file_tidak_ada.php"; // Warning jadi exception
} catch (ErrorException $e) {
    echo "Terjadi error: " . $e->getMessage() . " di " . $e->getFile() . ":" . $e->getLine();
}

// Kembalikan handler default
restore_error_handler();
?>
```

## Kasus Penggunaan Nyata
Mengubah semua warning/notice jadi exception untuk kontrol error yang ketat, logging semua error.
