# 208. Konflik method trait

## Definisi Singkat
Konflik method trait terjadi ketika dua trait memiliki method dengan nama yang sama. PHP menyediakan `insteadof` dan `as` untuk resolusi.

## Analogi
Dua guru memberi PR berbeda dengan judul sama — kamu harus pilih PR siapa yang dikerjakan (`insteadof`) atau rename (`as`).

## Poin-Poin Penting
- Gunakan `insteadof` untuk memilih method dari trait tertentu
- Gunakan `as` untuk memberi alias
- Urutan prioritas: class > trait > parent

## Contoh Kode (PHP)
```php
<?php
trait A {
    public function halo() { echo "Halo dari A"; }
}
trait B {
    public function halo() { echo "Halo dari B"; }
}

class Saya {
    use A, B {
        A::halo insteadof B;   // pakai method A
        B::halo as haloB;      // alias method B
    }
}

$obj = new Saya();
$obj->halo();   // Halo dari A
$obj->haloB();  // Halo dari B
?>
```

## Kasus Penggunaan Nyata
Saat menggabungkan trait dari library berbeda yang kebetulan memiliki method serupa.
