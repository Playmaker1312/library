# 214. Composition vs inheritance

## Definisi Singkat
Inheritance ("is-a") membuat class turunan dari parent; Composition ("has-a") menggabungkan object dalam class.

## Analogi
Inheritance: Mobil **adalah** Kendaraan. Composition: Mobil **memiliki** Mesin.

## Poin-Poin Penting
| Aspek | Inheritance | Composition |
|-------|-------------|-------------|
| Hubungan | is-a | has-a |
| Keyword | extends | property object |
| Fleksibilitas | Kaku | Lebih fleksibel |
| Coupling | Tight | Loose |
| Reuse | Vertical | Horizontal |

## Contoh Kode (PHP)
```php
<?php
// Inheritance
class Engine {
    public function start() { echo "Engine started"; }
}
class Car extends Engine { }
// Car IS-A Engine (kurang tepat)

// Composition - lebih baik
class Engine2 {
    public function start() { echo "Engine started"; }
}
class Car2 {
    private Engine2 $engine;
    public function __construct() {
        $this->engine = new Engine2();
    }
    public function start() {
        $this->engine->start();
    }
}
// Car2 HAS-A Engine2 (lebih tepat)
?>
```

## Kasus Penggunaan Nyata
Gunakan composition untuk perilaku yang bisa berubah (strategy pattern), inheritance untuk hierarki yang stabil.
