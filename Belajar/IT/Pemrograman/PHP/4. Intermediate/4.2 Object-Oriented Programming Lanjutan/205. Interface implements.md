# 205. Interface implements

## Definisi Singkat
Interface adalah kontrak yang mendefinisikan method apa saja yang harus dimiliki class, tanpa implementasi. Class menggunakan `implements`.

## Analogi
Seperti colokan listrik — apapun brand-nya, harus punya 2 lubang agar bisa dicolok.

## Poin-Poin Penting
- Hanya berisi deklarasi method (tanpa body)
- Semua method otomatis public
- Class bisa implements banyak interface
- Interface bisa extends interface lain

## Contoh Kode (PHP)
```php
<?php
interface MesinCetak {
    public function cetak($dokumen);
    public function scan($dokumen);
}

interface MesinFotokopi {
    public function fotokopi($dokumen, $jumlah);
}

class PrinterSaya implements MesinCetak, MesinFotokopi {
    public function cetak($dokumen) {
        echo "Mencetak: $dokumen";
    }
    public function scan($dokumen) {
        echo "Scan: $dokumen";
    }
    public function fotokopi($dokumen, $jumlah) {
        echo "Fotokopi $dokumen sebanyak $jumlah";
    }
}
?>
```

## Kasus Penggunaan Nyata
`JsonSerializable`, `ArrayAccess`, contract antar komponen dalam framework, dependency injection.
