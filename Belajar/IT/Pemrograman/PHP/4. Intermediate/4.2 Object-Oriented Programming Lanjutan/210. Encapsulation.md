# 210. Encapsulation

## Definisi Singkat
Encapsulation adalah prinsip menyembunyikan detail internal object dan hanya mengekspos apa yang perlu melalui method publik.

## Analogi
ATM — kamu hanya melihat layar dan tombol, tidak tahu mekanisme di dalam mesin.

## Poin-Poin Penting
- Property dibuat private/protected
- Akses melalui getter/setter publik
- Melindungi integritas data
- Memudahkan perubahan internal tanpa efek ke luar

## Contoh Kode (PHP)
```php
<?php
class RekeningBank {
    private $saldo = 0;
    private $nomorRekening;

    public function __construct($nomor) {
        $this->nomorRekening = $nomor;
    }
    public function setor($jumlah) {
        if ($jumlah > 0) {
            $this->saldo += $jumlah;
        }
    }
    public function tarik($jumlah) {
        if ($jumlah > 0 && $jumlah <= $this->saldo) {
            $this->saldo -= $jumlah;
            return true;
        }
        return false;
    }
    public function getSaldo() {
        return $this->saldo;
    }
}

$rek = new RekeningBank("123456");
$rek->setor(1000000);
$rek->tarik(500000);
echo $rek->getSaldo(); // 500000
// $rek->saldo = 999999; // ERROR: private
?>
```

## Kasus Penggunaan Nyata
Data sensitif (password, saldo), validasi input, menjaga konsistensi internal object.
