# 213. Anonymous class

## Definisi Singkat
Anonymous class adalah class tanpa nama yang dideklarasikan dan diinstansiasi secara inline, berguna untuk object sekali pakai.

## Analogi
Seperti tenda darurat — dipasang cepat untuk kebutuhan sementara, lalu dibongkar.

## Poin-Poin Penting
- Dideklarasikan dengan `new class { ... }`
- Bisa implements interface, extends class
- Bisa menerima constructor arguments
- Berguna untuk mock/testing

## Contoh Kode (PHP)
```php
<?php
interface Logger {
    public function log($pesan);
}

function prosesData(Logger $logger) {
    $logger->log("Data diproses");
}

prosesData(new class implements Logger {
    public function log($pesan) {
        echo "[Console] $pesan";
    }
});

// Dengan constructor
$obj = new class("Budi") {
    public function __construct(public string $nama) {}
    public function sapa() {
        echo "Halo, $this->nama";
    }
};
$obj->sapa(); // Halo, Budi
?>
```

## Kasus Penggunaan Nyata
Mock object di unit test, simple callback handler, override method sekali pakai.
