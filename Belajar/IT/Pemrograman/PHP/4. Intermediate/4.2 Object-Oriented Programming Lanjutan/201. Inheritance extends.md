# 201. Inheritance extends

## Definisi Singkat
Inheritance (pewarisan) adalah mekanisme class mewarisi property dan method dari class lain menggunakan keyword `extends`.

## Analogi
Anak mewarisi sifat dari orang tua — rambut keriting, mata coklat, tapi punya sifat unik sendiri.

## Poin-Poin Penting
- Parent class = class yang diwarisi
- Child class = class yang mewarisi
- Gunakan `extends` untuk pewarisan
- PHP hanya mendukung single inheritance (satu parent)

## Contoh Kode (PHP)
```php
<?php
class Hewan {
    public $nama;
    public function __construct($nama) {
        $this->nama = $nama;
    }
    public function suara() {
        return "Suara hewan";
    }
}

class Kucing extends Hewan {
    public function suara() {
        return "Meow!";
    }
}

$kucing = new Kucing("Kitty");
echo $kucing->suara(); // Meow!
echo $kucing->nama;    // Kitty
?>
```

## Kasus Penggunaan Nyata
Hierarki entitas: `User` → `Admin`, `Karyawan` → `Manager`, `Payment` → `CreditCardPayment`.
