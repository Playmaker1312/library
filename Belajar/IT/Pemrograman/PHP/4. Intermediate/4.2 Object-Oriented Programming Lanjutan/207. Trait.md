# 207. Trait

## Definisi Singkat
Trait adalah mekanisme reuse kode di PHP yang mirip class, tapi tidak bisa diinstansiasi — digunakan untuk menyebarkan method ke banyak class.

## Analogi
Seperti modul tambahan — mobil bisa dipasangi sunroof, bukan dari pabrik, tapi bisa ditambahkan.

## Poin-Poin Penting
- Keyword `trait`, bukan `class`
- Gunakan `use TraitName;` di dalam class
- Mengatasi keterbatasan single inheritance
- Bisa punya property dan method

## Contoh Kode (PHP)
```php
<?php
trait Logger {
    public function log($pesan) {
        echo "[LOG] $pesan";
    }
}

trait Notifikasi {
    public function kirimEmail($ke, $subjek) {
        echo "Email ke $ke: $subjek";
    }
}

class User {
    use Logger, Notifikasi;
    public function daftar() {
        $this->log("User baru mendaftar");
        $this->kirimEmail("admin@site.com", "User baru");
    }
}

$u = new User();
$u->daftar();
?>
```

## Kasus Penggunaan Nyata
Menyebarkan method `toJson()`, `validate()`, `logActivity()` ke berbagai class tanpa inheritance.
