# 206. Abstract class vs interface

## Definisi Singkat
Abstract class dan interface sama-sama kontrak, tapi abstract class bisa punya implementasi konkret, interface hanya deklarasi (sebelum PHP 8).

## Analogi
Abstract class = template dokumen (ada bagian isi); Interface = formulir kosong (hanya kolom).

## Poin-Poin Penting
| Aspek | Abstract class | Interface |
|-------|----------------|-----------|
| Instansiasi | Tidak bisa | Tidak bisa |
| Method konkret | Bisa | PHP 8+ bisa (default method) |
| Property | Bisa | Tidak bisa |
| Constructor | Bisa | Tidak |
| Multiple | Single inheritance | Multiple interface |
| Keyword | `abstract class` | `interface` |

## Contoh Kode (PHP)
```php
<?php
// Abstract class: "is-a" relationship
abstract class Mobil {
    protected $merk;
    abstract public function mulai();
    public function klakson() { echo "Beep!"; }
}

// Interface: "can-do" relationship
interface GPS {
    public function navigasi($tujuan);
}
interface Radio {
    public function putarMusik($lagu);
}

// Multiple interface
class MobilMewah extends Mobil implements GPS, Radio {
    public function mulai() { echo "Start engine"; }
    public function navigasi($tujuan) { echo "Navigasi ke $tujuan"; }
    public function putarMusik($lagu) { echo "Putar $lagu"; }
}
?>
```

## Kasus Penggunaan Nyata
Gunakan abstract class untuk hierarki "is-a", gunakan interface untuk kemampuan "can-do".
