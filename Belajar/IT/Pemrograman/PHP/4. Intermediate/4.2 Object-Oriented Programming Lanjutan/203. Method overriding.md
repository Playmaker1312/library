# 203. Method overriding

## Definisi Singkat
Method overriding adalah mendefinisikan ulang method yang sudah ada di parent class dengan implementasi berbeda di child class.

## Analogi
Semua kendaraan punya method `berhenti()`, tapi mobil berhenti dengan rem, sepeda dengan kaki — implementasi berbeda.

## Poin-Poin Penting
- Nama method harus sama persis
- Signature parameter harus kompatibel (PHP 8+ strict)
- Child bisa panggil parent dengan `parent::`
- Method parent harus bisa diakses (public/protected)

## Contoh Kode (PHP)
```php
<?php
class Bentuk {
    public function luas() {
        return 0;
    }
}

class Persegi extends Bentuk {
    private $sisi;
    public function __construct($sisi) {
        $this->sisi = $sisi;
    }
    public function luas() {
        return $this->sisi * $this->sisi;
    }
}

class Lingkaran extends Bentuk {
    private $r;
    public function __construct($r) {
        $this->r = $r;
    }
    public function luas() {
        return pi() * $this->r * $this->r;
    }
}
?>
```
