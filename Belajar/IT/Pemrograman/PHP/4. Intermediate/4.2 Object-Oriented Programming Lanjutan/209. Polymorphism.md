# 209. Polymorphism

## Definisi Singkat
Polymorphism ("banyak bentuk") adalah kemampuan object dari class berbeda merespons method yang sama dengan cara berbeda.

## Analogi
Semua hewan punya method `bersuara()`, kucing "Meow", anjing "Guk", bebek "Kwek".

## Poin-Poin Penting
- Object berbeda bisa dipanggil dengan interface sama
- Wujud nyata: overriding + interface
- Method yang sama menghasilkan perilaku berbeda
- Meningkatkan fleksibilitas dan reuse kode

## Contoh Kode (PHP)
```php
<?php
interface Pembayaran {
    public function bayar($jumlah);
}

class KartuKredit implements Pembayaran {
    public function bayar($jumlah) {
        echo "Bayar Rp$jumlah dengan kartu kredit";
    }
}

class EWallet implements Pembayaran {
    public function bayar($jumlah) {
        echo "Bayar Rp$jumlah via e-wallet";
    }
}

function checkout(Pembayaran $metode, $total) {
    $metode->bayar($total);
}

$kartu = new KartuKredit();
$gopay = new EWallet();
checkout($kartu, 50000); // Bayar Rp50000 dengan kartu kredit
checkout($gopay, 25000); // Bayar Rp25000 via e-wallet
?>
```

## Kasus Penggunaan Nyata
Strategy pattern, payment gateway, notification channels (email/SMS/push), report generator.
