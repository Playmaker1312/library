# 204. Abstract class abstract method

## Definisi Singkat
Abstract class adalah class yang tidak bisa diinstansiasi langsung, bisa memiliki method abstract (tanpa body) yang harus diimplementasikan subclass.

## Analogi
Blueprint "Hewan" — tidak ada "hewan" abstrak di dunia nyata, hanya kucing, anjing, dll yang konkret.

## Poin-Poin Penting
- Dideklarasikan dengan keyword `abstract`
- Bisa punya method abstract dan konkret
- Method abstract hanya deklarasi, tanpa implementasi
- Semua method abstract harus diimplementasikan di subclass

## Contoh Kode (PHP)
```php
<?php
abstract class KarakterGame {
    protected $nama;
    protected $darah = 100;
    abstract public function serang($target);
    abstract public function kemampuanKhusus();
    public function __construct($nama) {
        $this->nama = $nama;
    }
    public function getInfo() {
        return "$this->nama: $this->darah HP";
    }
}

class Warrior extends KarakterGame {
    public function serang($target) {
        $target->darah -= 20;
    }
    public function kemampuanKhusus() {
        echo "Shield Bash!";
    }
}
?>
```

## Kasus Penggunaan Nyata
Template method pattern, class controller dasar di framework, payment gateway abstraction.
