# 212. Late static binding static

## Definisi Singkat
Late static binding (`static::`) memungkinkan method static merujuk ke class yang dipanggil saat runtime, bukan class tempat method didefinisikan.

## Analogi
Seperti "tunjukkan siapa yang memanggil" — bukan melihat siapa yang menulis aturan, tapi siapa yang menjalankannya.

## Poin-Poin Penting
- `self::` mengikat di compile-time (class tempat ditulis)
- `static::` mengikat di runtime (class yang dipanggil)
- Hanya relevan dengan inheritance dan static

## Contoh Kode (PHP)
```php
<?php
class Base {
    public static $nama = "Base";
    public static function getNamaSelf() {
        return self::$nama;
    }
    public static function getNamaStatic() {
        return static::$nama;
    }
}

class Anak extends Base {
    public static $nama = "Anak";
}

echo Anak::getNamaSelf();   // Base (self = Base)
echo Anak::getNamaStatic(); // Anak (static = Anak)
?>
```

## Kasus Penggunaan Nyata
Active Record pattern (ORM), Factory pattern, Singleton pattern di subclass.
