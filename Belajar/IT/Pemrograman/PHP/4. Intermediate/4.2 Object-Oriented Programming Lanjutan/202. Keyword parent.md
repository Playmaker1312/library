# 202. Keyword parent

## Definisi Singkat
`parent::` digunakan untuk mengakses method atau property dari parent class dalam class turunan.

## Analogi
Seperti anak yang bertanya "Ibu, bagaimana caranya?" lalu melakukan cara yang diajarkan ibu.

## Poin-Poin Penting
- Gunakan `parent::method()` untuk panggil method parent
- Biasanya digunakan saat override method
- Bisa juga akses property dan constant parent

## Contoh Kode (PHP)
```php
<?php
class Akun {
    protected $saldo = 0;
    public function __construct($saldoAwal) {
        $this->saldo = $saldoAwal;
    }
    public function info() {
        echo "Saldo: Rp" . $this->saldo;
    }
}

class AkunPremium extends Akun {
    public $bonus = 50000;
    public function __construct($saldoAwal) {
        parent::__construct($saldoAwal);
        $this->saldo += $this->bonus;
    }
    public function info() {
        parent::info();
        echo " (Bonus: Rp$this->bonus)";
    }
}
?>
```

## Kasus Penggunaan Nyata
Memperluas fungsionalitas method parent tanpa menulis ulang kode yang sudah ada.
