# 215. Countable Iterator ArrayAccess interface

## Definisi Singkat
Interface SPL (Standard PHP Library) yang membuat object bisa berperilaku seperti array: `Countable` (dihitung), `Iterator` (di-loop), `ArrayAccess` (diakses seperti array).

## Analogi
Membuat kotak penyimpanan — bisa dihitung isinya (Countable), bisa diambil satu-satu (Iterator), bisa diakses dengan `$box[0]` (ArrayAccess).

## Poin-Poin Penting
- `Countable`: method `count()` — berapa item?
- `Iterator`: method `current()`, `key()`, `next()`, `rewind()`, `valid()`
- `ArrayAccess`: method `offsetExists()`, `offsetGet()`, `offsetSet()`, `offsetUnset()`

## Contoh Kode (PHP)
```php
<?php
class Koleksi implements Countable, Iterator, ArrayAccess {
    private array $items = [];
    private int $posisi = 0;

    public function count(): int {
        return count($this->items);
    }
    public function current(): mixed {
        return $this->items[$this->posisi];
    }
    public function key(): int {
        return $this->posisi;
    }
    public function next(): void { $this->posisi++; }
    public function rewind(): void { $this->posisi = 0; }
    public function valid(): bool {
        return isset($this->items[$this->posisi]);
    }
    public function offsetExists(mixed $offset): bool {
        return isset($this->items[$offset]);
    }
    public function offsetGet(mixed $offset): mixed {
        return $this->items[$offset] ?? null;
    }
    public function offsetSet(mixed $offset, mixed $value): void {
        $this->items[$offset] = $value;
    }
    public function offsetUnset(mixed $offset): void {
        unset($this->items[$offset]);
    }
}

$k = new Koleksi();
$k[] = "Apel"; $k[] = "Mangga"; $k[] = "Jeruk";
echo count($k); // 3
foreach ($k as $buah) { echo "$buah "; } // Apel Mangga Jeruk
echo $k[1]; // Mangga
?>
```
