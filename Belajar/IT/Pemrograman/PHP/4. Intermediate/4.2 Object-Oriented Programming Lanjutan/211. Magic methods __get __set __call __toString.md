# 211. Magic methods __get __set __call __toString

## Definisi Singkat
Magic methods adalah method khusus dengan awalan `__` yang otomatis dipanggil saat event tertentu terjadi pada object.

## Analogi
Seperti asisten pribadi yang otomatis bekerja saat ada situasi tertentu — tamu datang (buka pintu), telepon bunyi (angkat).

## Poin-Poin Penting
- `__get($prop)`: dipanggil saat akses property yang tidak ada/protected
- `__set($prop, $val)`: dipanggil saat set property yang tidak ada/protected
- `__call($method, $args)`: dipanggil saat panggil method yang tidak ada
- `__toString()`: dipanggil saat object di-echo

## Contoh Kode (PHP)
```php
<?php
class User {
    private $data = [];
    public function __get($name) {
        return $this->data[$name] ?? null;
    }
    public function __set($name, $value) {
        $this->data[$name] = $value;
    }
    public function __call($name, $args) {
        echo "Method '$name' tidak ada dengan parameter: " . implode(", ", $args);
    }
    public function __toString() {
        return "User: " . ($this->data['nama'] ?? 'Tanpa Nama');
    }
}

$u = new User();
$u->nama = "Budi";            // __set
echo $u->nama;                 // __get -> Budi
echo $u->methodAjaib(1, 2);    // __call
echo $u;                       // __toString -> User: Budi
?>
```

## Kasus Penggunaan Nyata
Eloquent ORM (Laravel), Active Record pattern, proxy pattern, debug output.
