# 241. Foreign key relasi

## Definisi Singkat
Foreign key adalah constraint yang menghubungkan kolom di satu tabel ke PRIMARY KEY tabel lain, menjaga referential integrity.

## Analogi
Seperti KTP — setiap warga terdaftar di RT masing-masing. Kamu tidak bisa punya alamat RT yang tidak ada.

## Poin-Poin Penting
- Menghubungkan tabel anak ke tabel induk
- Mencegah data orphan (anak tanpa induk)
- `ON DELETE CASCADE` — hapus anak jika induk dihapus
- `ON DELETE SET NULL` — set NULL di anak jika induk dihapus
- `ON DELETE RESTRICT` — cegah hapus induk jika masih ada anak

## Contoh Kode (PHP)
```php
<?php
$pdo = new PDO("mysql:host=localhost;dbname=belajar", "root", "");

$sql = "CREATE TABLE orders (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    total DECIMAL(12,2),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
    ON DELETE CASCADE
)";

$pdo->exec($sql);

// Insert data — foreign key memastikan user_id valid
$stmt = $pdo->prepare("INSERT INTO orders (user_id, total) VALUES (?, ?)");
$stmt->execute([1, 150000]); // OK, user id 1 ada
// $stmt->execute([999, 50000]); // ERROR, user id 999 tidak ada
?>
```

## Kasus Penggunaan Nyata
Order dengan user, produk dengan kategori, komentar dengan artikel, semua relasi database.
