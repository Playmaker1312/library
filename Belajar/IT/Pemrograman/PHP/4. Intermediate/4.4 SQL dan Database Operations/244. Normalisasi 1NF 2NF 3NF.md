# 244. Normalisasi 1NF 2NF 3NF

## Definisi Singkat
Normalisasi adalah proses merancang database untuk mengurangi redundansi dan menjaga integritas data melalui 3 bentuk normal (1NF, 2NF, 3NF).

## Analogi
Seperti merapikan lemari — pisahkan baju, celana, aksesori ke laci berbeda (tidak dicampur).

## Poin-Poin Penting
| Bentuk | Aturan |
|--------|--------|
| **1NF** | Setiap kolom berisi nilai atomik (tidak ada array/duplikat) |
| **2NF** | 1NF + setiap kolom non-key tergantung penuh pada primary key |
| **3NF** | 2NF + tidak ada transitive dependency (kolom tergantung kolom non-key) |

## Contoh Kode (PHP)
```php
<?php
// UNNORMALIZED (0NF) — buruk
$sql = "CREATE TABLE orders_bad (
    id INT,
    produk VARCHAR(255), -- 'Laptop, Mouse, Keyboard' (tidak atomik!)
    total VARCHAR(100)   -- bisa dihitung, redundan
)";

// 1NF — atomik
$sql = "CREATE TABLE orders_1nf (
    id INT,
    produk VARCHAR(100), -- satu produk per baris
    jumlah INT
)";

// 2NF — dependen penuh pada PK
$sql = "CREATE TABLE orders (
    id INT PRIMARY KEY,
    tanggal DATE,
    user_id INT
)";
$sql = "CREATE TABLE order_items (
    id INT PRIMARY KEY,
    order_id INT,
    produk VARCHAR(100),
    harga DECIMAL(12,2),
    FOREIGN KEY (order_id) REFERENCES orders(id)
)";

// 3NF — tidak ada transitive dependency
$sql = "CREATE TABLE products (
    id INT PRIMARY KEY,
    nama VARCHAR(200),
    category_id INT
)";
$sql = "CREATE TABLE categories (
    id INT PRIMARY KEY,
    nama VARCHAR(100)
)";
// Nama kategori tidak disimpan di products, cukup category_id
?>
```

## Kasus Penggunaan Nyata
Desain database untuk aplikasi enterprise, sistem ERP, CMS yang kompleks.
