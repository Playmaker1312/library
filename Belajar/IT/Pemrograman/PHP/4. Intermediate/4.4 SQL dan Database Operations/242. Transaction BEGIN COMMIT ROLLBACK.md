# 242. Transaction BEGIN COMMIT ROLLBACK

## Definisi Singkat
Transaction memastikan sekelompok query dieksekusi semua atau tidak sama sekali (atomic), dengan `BEGIN`, `COMMIT`, `ROLLBACK`.

## Analogi
Seperti transfer bank — ambil dari A dan kirim ke B. Jika gagal di tengah, semua dibatalkan (ROLLBACK) agar saldo konsisten.

## Poin-Poin Penting
- `BEGIN` atau `START TRANSACTION` — mulai transaksi
- `COMMIT` — simpan semua perubahan
- `ROLLBACK` — batalkan semua perubahan
- Pastikan gunakan InnoDB (bukan MyISAM)
- Matikan autocommit untuk kontrol manual

## Contoh Kode (PHP)
```php
<?php
$pdo = new PDO("mysql:host=localhost;dbname=belajar", "root", "");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

try {
    $pdo->beginTransaction();

    // Kurangi stok
    $pdo->exec("UPDATE products SET stok = stok - 1 WHERE id = 5");

    // Buat order
    $pdo->exec("INSERT INTO orders (user_id, total) VALUES (1, 50000)");
    $orderId = $pdo->lastInsertId();

    // Jika ada error di sini, semua dibatalkan
    $pdo->exec("INSERT INTO order_items (order_id, product_id, qty, harga)
                VALUES ($orderId, 5, 1, 50000)");

    $pdo->commit();
    echo "Transaksi berhasil";
} catch (Exception $e) {
    $pdo->rollBack();
    echo "Transaksi gagal: " . $e->getMessage();
}
?>
```

## Kasus Penggunaan Nyata
Pembayaran, transfer saldo, pemesanan tiket, operasi multi-tabel yang harus konsisten.
