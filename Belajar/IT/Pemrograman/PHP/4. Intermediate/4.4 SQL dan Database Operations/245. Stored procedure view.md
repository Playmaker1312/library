# 245. Stored procedure view

## Definisi Singkat
**Stored Procedure** adalah kumpulan SQL yang disimpan di server, bisa dipanggil berulang. **View** adalah query SELECT yang disimpan sebagai tabel virtual.

## Analogi
- **Stored Procedure**: seperti resep masakan — langkah-langkah yang bisa dijalankan kapan saja
- **View**: seperti jendela — kamu melihat data dari sudut pandang tertentu tanpa menyentuh aslinya

## Poin-Poin Penting
- Procedure: `CREATE PROCEDURE`, panggil dengan `CALL`
- View: `CREATE VIEW`, query seperti tabel biasa
- Procedure bisa punya parameter IN/OUT
- View bisa digunakan seperti tabel (SELECT, JOIN)
- View tidak menyimpan data, hanya query yang disimpan

## Contoh Kode (PHP)
```php
<?php
$pdo = new PDO("mysql:host=localhost;dbname=belajar", "root", "");

// Buat VIEW — laporan order
$pdo->exec("CREATE VIEW laporan_penjualan AS
            SELECT o.id, u.nama as user, o.total, o.created_at
            FROM orders o
            JOIN users u ON o.user_id = u.id");

// Pakai VIEW seperti tabel biasa
$stmt = $pdo->query("SELECT * FROM laporan_penjualan WHERE total > 50000");
$data = $stmt->fetchAll();

// Buat STORED PROCEDURE
$pdo->exec("CREATE PROCEDURE get_user_orders(IN user_id INT)
            BEGIN
                SELECT * FROM orders WHERE user_id = user_id;
            END");

// Panggil procedure
$stmt = $pdo->query("CALL get_user_orders(1)");
$orders = $stmt->fetchAll();
?>
```

## Kasus Penggunaan Nyata
View untuk laporan standar, procedure untuk operasi kompleks (update stok + insert order), security layer.
