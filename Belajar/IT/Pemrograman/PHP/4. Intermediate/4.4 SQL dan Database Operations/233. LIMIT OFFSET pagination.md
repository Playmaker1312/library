# 233. LIMIT OFFSET pagination

## Definisi Singkap
`LIMIT` membatasi jumlah baris yang dikembalikan, `OFFSET` menentukan baris ke berapa untuk memulai, digunakan untuk pagination.

## Analogi
Seperti buku — LIMIT = jumlah baris per halaman, OFFSET = halaman ke berapa.

## Poin-Poin Penting
- `LIMIT jumlah` — ambil N baris
- `LIMIT jumlah OFFSET mulai` — ambil N baris mulai dari baris ke-M
- Sederhana: `LIMIT mulai, jumlah` (MySQL syntax)
- OFFSET = (halaman - 1) * per_halaman

## Contoh Kode (PHP)
```php
<?php
$pdo = new PDO("mysql:host=localhost;dbname=belajar", "root", "");

$perHal = 10;
$halaman = isset($_GET['page']) ? (int)$_GET['page'] : 1;
$offset = ($halaman - 1) * $perHal;

// Ambil data per halaman
$stmt = $pdo->prepare("SELECT * FROM products ORDER BY id LIMIT ? OFFSET ?");
$stmt->execute([$perHal, $offset]);
$products = $stmt->fetchAll();

// Hitung total halaman
$total = $pdo->query("SELECT COUNT(*) FROM products")->fetchColumn();
$totalHal = ceil($total / $perHal);

echo "Halaman $halaman dari $totalHal";
?>
```
