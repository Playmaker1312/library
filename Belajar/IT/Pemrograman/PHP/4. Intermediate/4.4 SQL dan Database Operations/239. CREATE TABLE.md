# 239. CREATE TABLE

## Definisi Singkat
`CREATE TABLE` adalah perintah SQL untuk membuat tabel baru dalam database, mendefinisikan kolom, tipe data, dan constraint.

## Analogi
Seperti membuat lemari baru — tentukan ukuran, jumlah laci, bahan (tipe data), dan aturan isi (constraint).

## Poin-Poin Penting
- Tentukan nama tabel dan kolom
- Setiap kolom punya tipe data
- Constraint: `PRIMARY KEY`, `NOT NULL`, `UNIQUE`, `DEFAULT`
- `AUTO_INCREMENT` untuk integer yang otomatis naik

## Contoh Kode (PHP)
```php
<?php
$pdo = new PDO("mysql:host=localhost;dbname=belajar", "root", "");

$sql = "CREATE TABLE IF NOT EXISTS categories (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nama VARCHAR(100) NOT NULL,
    slug VARCHAR(100) UNIQUE,
    deskripsi TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)";

$pdo->exec($sql);
echo "Tabel categories dibuat";

// Tabel dengan foreign key
$sql2 = "CREATE TABLE IF NOT EXISTS products (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nama VARCHAR(200) NOT NULL,
    harga DECIMAL(12,2) NOT NULL DEFAULT 0,
    stok INT DEFAULT 0,
    category_id INT,
    FOREIGN KEY (category_id) REFERENCES categories(id)
    ON DELETE SET NULL
)";

$pdo->exec($sql2);
echo "Tabel products dibuat";
?>
```

## Kasus Penggunaan Nyata
Setup database awal, migrasi tabel, instalasi aplikasi, pembuatan modul baru.
