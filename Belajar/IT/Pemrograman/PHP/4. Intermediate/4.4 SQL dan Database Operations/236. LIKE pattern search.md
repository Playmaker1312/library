# 236. LIKE pattern search

## Definisi Singkat
`LIKE` digunakan dalam WHERE untuk mencari pola teks menggunakan wildcard: `%` (sembarang karakter) dan `_` (satu karakter).

## Analogi
Seperti bermain tebak kata — "PHP %" cocok dengan "PHP Dasar", "PHP Lanjutan", dll.

## Poin-Poin Penting
- `%` — cocok dengan 0, 1, atau banyak karakter
- `_` — cocok dengan tepat 1 karakter
- `LIKE 'kata%'` — diawali "kata"
- `LIKE '%kata'` — diakhiri "kata"
- `LIKE '%kata%'` — mengandung "kata"

## Contoh Kode (PHP)
```php
<?php
$pdo = new PDO("mysql:host=localhost;dbname=belajar", "root", "");

// Cari produk mengandung kata "laptop"
$stmt = $pdo->prepare("SELECT * FROM products WHERE nama LIKE ?");
$stmt->execute(['%laptop%']);

// Cari user dengan email gmail
$stmt = $pdo->prepare("SELECT * FROM users WHERE email LIKE ?");
$stmt->execute(['%@gmail.com']);

// Cari username dengan panjang 5 karakter
$stmt = $pdo->prepare("SELECT * FROM users WHERE username LIKE ?");
$stmt->execute(['_____']); // 5 underscore

// Escape literal % atau _
$stmt = $pdo->prepare("SELECT * FROM products WHERE deskripsi LIKE ?");
$stmt->execute(['%100\% diskon%']); // \% untuk literal %
?>
```

## Kasus Penggunaan Nyata
Fitur pencarian (search), autocomplete, filter berdasarkan inisial/prefix.
