# 232. ORDER BY

## Definisi Singkat
`ORDER BY` digunakan untuk mengurutkan hasil query berdasarkan satu atau lebih kolom, ascending (`ASC`) atau descending (`DESC`).

## Analogi
Seperti mengatur buku di rak — berdasarkan abjad (ASC) atau dari yang terbaru (DESC).

## Poin-Poin Penting
- `ORDER BY kolom ASC` — ascending (kecil ke besar)
- `ORDER BY kolom DESC` — descending (besar ke kecil)
- Bisa multiple kolom: `ORDER BY kol1 ASC, kol2 DESC`
- Bisa menggunakan alias kolom

## Contoh Kode (PHP)
```php
<?php
$pdo = new PDO("mysql:host=localhost;dbname=belajar", "root", "");

// Urutkan harga termurah
$stmt = $pdo->query("SELECT * FROM products ORDER BY harga ASC");

// Urutkan produk terbaru
$stmt = $pdo->query("SELECT * FROM products ORDER BY created_at DESC");

// Multiple: kategori A-Z, lalu harga termurah
$stmt = $pdo->query("SELECT * FROM products ORDER BY kategori ASC, harga ASC");

// Dengan LIMIT: 5 termahal
$stmt = $pdo->query("SELECT * FROM products ORDER BY harga DESC LIMIT 5");
$data = $stmt->fetchAll();
?>
```

## Kasus Penggunaan Nyata
Produk termurah/termahal, artikel terbaru, user berdasarkan abjad, ranking nilai.
