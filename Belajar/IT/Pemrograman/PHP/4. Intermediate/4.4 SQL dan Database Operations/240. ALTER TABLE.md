# 240. ALTER TABLE

## Definisi Singkat
`ALTER TABLE` digunakan untuk mengubah struktur tabel yang sudah ada — menambah, mengubah, atau menghapus kolom dan constraint.

## Analogi
Seperti merenovasi rumah — tambah kamar (kolom baru), ganti jendela (ubah tipe), atau tutup pintu (hapus kolom).

## Poin-Poin Penting
- `ADD` — menambah kolom baru
- `MODIFY` — mengubah tipe data/constraint kolom
- `CHANGE` — rename kolom
- `DROP` — menghapus kolom
- `RENAME TO` — rename tabel

## Contoh Kode (PHP)
```php
<?php
$pdo = new PDO("mysql:host=localhost;dbname=belajar", "root", "");

// Tambah kolom
$pdo->exec("ALTER TABLE products ADD COLUMN berat DECIMAL(8,2) AFTER stok");

// Tambah kolom dengan default
$pdo->exec("ALTER TABLE products ADD COLUMN status VARCHAR(20) DEFAULT 'aktif'");

// Ubah tipe data kolom
$pdo->exec("ALTER TABLE products MODIFY COLUMN harga DECIMAL(15,2)");

// Rename kolom
$pdo->exec("ALTER TABLE products CHANGE COLUMN berat berat_kg DECIMAL(8,2)");

// Hapus kolom
$pdo->exec("ALTER TABLE products DROP COLUMN berat_kg");

// Tambah index
$pdo->exec("ALTER TABLE products ADD INDEX idx_kategori (category_id)");

echo "Tabel berhasil diubah";
?>
```

## Kasus Penggunaan Nyata
Update skema database saat aplikasi bertambah fitur, migrasi data, perubahan requirement.
