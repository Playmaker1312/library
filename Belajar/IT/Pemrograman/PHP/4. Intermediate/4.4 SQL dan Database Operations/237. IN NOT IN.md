# 237. IN NOT IN

## Definisi Singkat
`IN` memeriksa apakah nilai ada dalam daftar, `NOT IN` kebalikannya — nilai tidak ada dalam daftar.

## Analogi
Seperti daftar tamu undangan — "Apakah Budi ada di daftar?" (IN) atau "Apakah Budi tidak ada di daftar?" (NOT IN).

## Poin-Poin Penting
- `WHERE kolom IN (val1, val2, val3)` — lebih rapi dari banyak OR
- `WHERE kolom NOT IN (val1, val2)` — kebalikan
- Bisa menggunakan subquery: `WHERE id IN (SELECT user_id FROM orders)`
- Lebih performa dari multiple OR

## Contoh Kode (PHP)
```php
<?php
$pdo = new PDO("mysql:host=localhost;dbname=belajar", "root", "");

// IN dengan daftar statis
$stmt = $pdo->query("SELECT * FROM products WHERE kategori IN ('elektronik', 'gadget', 'komputer')");

// NOT IN
$stmt = $pdo->query("SELECT * FROM orders WHERE status NOT IN ('selesai', 'dibatalkan')");

// IN dengan subquery
$stmt = $pdo->query("SELECT * FROM users WHERE id IN (SELECT user_id FROM orders WHERE total > 100000)");

// IN dengan prepared statement (gunakan placeholders)
$ids = [1, 3, 5, 7];
$placeholders = implode(',', array_fill(0, count($ids), '?'));
$stmt = $pdo->prepare("SELECT * FROM users WHERE id IN ($placeholders)");
$stmt->execute($ids);
?>
```

## Kasus Penggunaan Nyata
Filter berdasarkan banyak pilihan (checkbox), subquery untuk relasi, exclude data.
