# 235. GROUP BY COUNT SUM AVG MAX MIN

## Definisi Singkat
`GROUP BY` mengelompokkan baris dengan nilai yang sama, digunakan dengan fungsi agregat: `COUNT`, `SUM`, `AVG`, `MAX`, `MIN`.

## Analogi
Seperti mengelompokkan belanjaan — total per kategori, jumlah item per kategori, rata-rata harga.

## Poin-Poin Penting
- `COUNT(expr)` — jumlah baris
- `SUM(expr)` — total nilai
- `AVG(expr)` — rata-rata
- `MAX(expr)` — nilai tertinggi
- `MIN(expr)` — nilai terendah
- `HAVING` untuk filter setelah GROUP BY (mirip WHERE untuk agregat)

## Contoh Kode (PHP)
```php
<?php
$pdo = new PDO("mysql:host=localhost;dbname=belajar", "root", "");

// Jumlah produk per kategori
$sql = "SELECT kategori, COUNT(*) as jumlah, SUM(harga) as total,
               AVG(harga) as rata_rata, MAX(harga) as termahal,
               MIN(harga) as termurah
        FROM products
        GROUP BY kategori";

// Dengan HAVING — kategori dengan produk > 5
$sql = "SELECT kategori, COUNT(*) as jumlah
        FROM products
        GROUP BY kategori
        HAVING jumlah > 5";

// GROUP BY dengan JOIN
$sql = "SELECT u.nama, COUNT(o.id) as total_order, SUM(o.total) as total_belanja
        FROM users u
        LEFT JOIN orders o ON u.id = o.user_id
        GROUP BY u.id";

$stmt = $pdo->query($sql);
$data = $stmt->fetchAll();
?>
```
