# 243. Index performa query

## Definisi Singkat
Index adalah struktur data yang mempercepat pencarian data di tabel, seperti indeks di buku — langsung ke halaman tanpa baca semua.

## Analogi
Buku tanpa indeks = baca halaman 1 sampai akhir untuk cari kata "PHP". Buku dengan indeks = langsung ke halaman yang tepat.

## Poin-Poin Penting
- `CREATE INDEX` untuk membuat index
- Index mempercepat SELECT, WHERE, JOIN, ORDER BY
- Index memperlambat INSERT, UPDATE, DELETE
- `PRIMARY KEY` dan `UNIQUE` otomatis jadi index
- `EXPLAIN` untuk menganalisis penggunaan index

## Contoh Kode (PHP)
```php
<?php
$pdo = new PDO("mysql:host=localhost;dbname=belajar", "root", "");

// Buat index
$pdo->exec("CREATE INDEX idx_email ON users(email)");
$pdo->exec("CREATE INDEX idx_kategori_harga ON products(kategori, harga)");

// Index unique
$pdo->exec("CREATE UNIQUE INDEX idx_slug ON categories(slug)");

// Hapus index
// $pdo->exec("DROP INDEX idx_email ON users");

// Cek performa dengan EXPLAIN
$stmt = $pdo->query("EXPLAIN SELECT * FROM users WHERE email = 'budi@mail.com'");
print_r($stmt->fetch());

// Query akan jauh lebih cepat dengan index
$stmt = $pdo->prepare("SELECT * FROM users WHERE email = ?");
$stmt->execute(['budi@mail.com']);
?>
```

## Kasus Penggunaan Nyata
Optimasi query di tabel besar (jutaan baris), pencarian teks, filtering berdasarkan status/tanggal.
