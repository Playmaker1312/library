# 231. SELECT WHERE clause

## Definisi Singkat
`WHERE` digunakan dalam query SELECT untuk memfilter baris berdasarkan kondisi tertentu.

## Analogi
Seperti menyaring beras — ambil yang bagus, buang yang jelek.

## Poin-Poin Penting
- WHERE diikuti kondisi (kolom, operator, nilai)
- Operator: `=`, `>`, `<`, `>=`, `<=`, `<>`, `LIKE`, `IN`
- Gabung dengan `AND`, `OR`, `NOT`
- WHERE dieksekusi sebelum SELECT

## Contoh Kode (PHP)
```php
<?php
$pdo = new PDO("mysql:host=localhost;dbname=belajar", "root", "");

// WHERE sederhana
$stmt = $pdo->query("SELECT * FROM products WHERE harga > 10000");

// WHERE dengan AND
$stmt = $pdo->query("SELECT * FROM users WHERE status = 'aktif' AND umur >= 18");

// WHERE dengan OR
$stmt = $pdo->query("SELECT * FROM orders WHERE status = 'pending' OR status = 'processing'");

// Prepared WHERE
$stmt = $pdo->prepare("SELECT * FROM products WHERE kategori = ? AND harga BETWEEN ? AND ?");
$stmt->execute(['elektronik', 100000, 500000]);
$data = $stmt->fetchAll();
?>
```

## Kasus Penggunaan Nyata
Filter produk berdasarkan kategori, cari user aktif, laporan penjualan per periode.
