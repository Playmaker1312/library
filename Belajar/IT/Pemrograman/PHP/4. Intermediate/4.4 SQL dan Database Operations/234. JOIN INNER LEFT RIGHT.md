# 234. JOIN INNER LEFT RIGHT

## Definisi Singkat
JOIN menggabungkan baris dari dua atau lebih tabel berdasarkan kolom yang terkait: `INNER JOIN` (irisan), `LEFT JOIN` (semua kiri), `RIGHT JOIN` (semua kanan).

## Analogi
- **INNER JOIN**: hanya siswa yang punya buku (kedua tabel cocok)
- **LEFT JOIN**: semua siswa, buku jika ada (prioritas kiri)
- **RIGHT JOIN**: semua buku, siswa jika ada (prioritas kanan)

## Poin-Poin Penting
- `INNER JOIN`: hanya baris yang cocok di kedua tabel
- `LEFT JOIN`: semua baris tabel kiri, NULL jika tidak cocok di kanan
- `RIGHT JOIN`: semua baris tabel kanan, NULL jika tidak cocok di kiri
- `ON` menentukan kondisi join

## Contoh Kode (PHP)
```php
<?php
$pdo = new PDO("mysql:host=localhost;dbname=belajar", "root", "");

// INNER JOIN — hanya user yang punya pesanan
$sql = "SELECT users.nama, orders.total, orders.tanggal
        FROM users
        INNER JOIN orders ON users.id = orders.user_id";

// LEFT JOIN — semua user, pesanan jika ada
$sql = "SELECT users.nama, COUNT(orders.id) as total_order
        FROM users
        LEFT JOIN orders ON users.id = orders.user_id
        GROUP BY users.id";

// Multiple JOIN
$sql = "SELECT o.id, u.nama, p.nama_produk, oi.quantity
        FROM orders o
        INNER JOIN users u ON o.user_id = u.id
        INNER JOIN order_items oi ON o.id = oi.order_id
        INNER JOIN products p ON oi.product_id = p.id";

$stmt = $pdo->query($sql);
$data = $stmt->fetchAll();
?>
```

## Kasus Penggunaan Nyata
Laporan order dengan detail user dan produk, data relasional dalam aplikasi.
