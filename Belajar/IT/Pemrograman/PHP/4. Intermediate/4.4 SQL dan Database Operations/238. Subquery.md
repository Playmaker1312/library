# 238. Subquery

## Definisi Singkat
Subquery adalah query di dalam query lain (SELECT, FROM, WHERE, HAVING) yang menghasilkan data untuk query utama.

## Analogi
Seperti "cari siswa yang nilainya di atas rata-rata" — kamu harus hitung rata-rata dulu (subquery), baru cari siswa (outer query).

## Poin-Poin Penting
- Subquery di dalam kurung `()`
- Bisa di SELECT, FROM, WHERE, HAVING
- Subquery di FROM harus punya alias
- Subquery bisa scalar (1 nilai), baris, atau tabel

## Contoh Kode (PHP)
```php
<?php
$pdo = new PDO("mysql:host=localhost;dbname=belajar", "root", "");

// Subquery di WHERE — produk di atas harga rata-rata
$sql = "SELECT * FROM products
        WHERE harga > (SELECT AVG(harga) FROM products)";

// Subquery di FROM — gunakan sebagai tabel sementara
$sql = "SELECT kategori, rata_rata
        FROM (SELECT kategori, AVG(harga) as rata_rata
              FROM products GROUP BY kategori) as tmp
        WHERE rata_rata > 50000";

// Subquery di SELECT — hitung total order per user
$sql = "SELECT nama,
               (SELECT COUNT(*) FROM orders WHERE user_id = users.id) as total_order
        FROM users";

// Subquery dengan EXISTS
$sql = "SELECT * FROM users u
        WHERE EXISTS (SELECT 1 FROM orders o WHERE o.user_id = u.id)";

$stmt = $pdo->query($sql);
$data = $stmt->fetchAll();
?>
```

## Kasus Penggunaan Nyata
Rangking, perbandingan dengan rata-rata, cek keberadaan relasi, nested reports.
