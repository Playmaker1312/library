# 128. use Keyword Closure

## Definisi Singkat
Keyword `use` pada closure memungkinkan anonymous function mengakses variabel dari scope luar (parent scope) di mana closure tersebut didefinisikan.

## Analogi
Seperti Anda membuat pesan untuk teman yang akan pergi ke luar negeri. Anda memberikan foto kenangan (variabel dari luar) yang dibungkus dalam amplop (closure). Teman Anda bisa melihat foto itu di mana pun ia pergi, karena fotonya sudah disertakan.

## Poin-Poin Penting
- Ditulis setelah parameter: `function($param) use ($varLuar)`
- Variabel yang di-`use` akan "terikat" ke closure
- Default: pass by value (salinan nilai saat closure dibuat)
- Gunakan `&` untuk pass by reference agar perubahan terlihat
- Bisa memasukkan banyak variabel, dipisah koma

## Contoh Kode (PHP)
```php
<?php
// Pass by value (default)
$pesan = "Halo";
$sapa = function($nama) use ($pesan) {
    return "$pesan, $nama!";
};

$pesan = "Selamat datang";
echo $sapa("Budi"); // Halo, Budi! (menggunakan nilai lama)

// Pass by reference
$hitung = 0;
$tambah = function($nilai) use (&$hitung) {
    $hitung += $nilai;
};

$tambah(5);
$tambah(10);
echo $hitung; // 15 (berubah)

// Multiple variabel
$prefix = "Mr.";
$suffix = "S.Kom";
$formatNama = function($nama) use ($prefix, $suffix) {
    return "$prefix $nama, $suffix";
};

echo $formatNama("Budi"); // Mr. Budi, S.Kom
?>
```

## Kasus Penggunaan Nyata
Membuat closure yang membutuhkan konteks dari lingkungannya, seperti query builder yang perlu mengakses koneksi database, atau formatter yang menggunakan pengaturan lokal.
