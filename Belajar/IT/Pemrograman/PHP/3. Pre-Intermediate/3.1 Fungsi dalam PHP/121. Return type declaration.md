# 121. Return Type Declaration

## Definisi Singkat
Return type declaration menentukan tipe data yang akan dikembalikan oleh suatu fungsi, ditulis dengan `: tipe` setelah kurung parameter dan sebelum kurung kurawal.

## Analogi
Seperti mesin ATM yang hanya mengeluarkan uang rupiah. Mesin sudah diprogram untuk selalu mengeluarkan output dalam bentuk tertentu (rupiah) — tidak akan pernah mengeluarkan dolar atau permen karet.

## Poin-Poin Penting
- Ditulis dengan `: tipe` setelah parameter: `function(): tipe`
- PHP akan memeriksa nilai `return` sesuai tipe yang dideklarasikan
- Mendukung `void` jika fungsi tidak mengembalikan nilai apa pun
- Mendukung `mixed` (PHP 8+) untuk tipe apa pun
- Union type juga bisa digunakan untuk return type
- `?tipe` berarti bisa `null` atau tipe tersebut (nullable)

## Contoh Kode (PHP)
```php
<?php
function tambah(int $a, int $b): int {
    return $a + $b;
}

echo tambah(3, 4); // 7

function sapa(string $nama): string {
    return "Halo, $nama!";
}

// Void return
function logPesan(string $pesan): void {
    file_put_contents("log.txt", $pesan);
    // tidak perlu return
}

// Nullable return
function cariUser(int $id): ?array {
    $users = [1 => "Budi", 2 => "Ani"];
    return $users[$id] ?? null;
}

$user = cariUser(3);
var_dump($user); // null

// Union return type (PHP 8+)
function formatAngka(int $n): int|string {
    return $n > 1000 ? number_format($n) : $n;
}
?>
```

## Kasus Penggunaan Nyata
Menjamin bahwa fungsi database selalu mengembalikan array, fungsi validasi selalu mengembalikan bool, dan fungsi pencarian selalu mengembalikan nullable object — membuat kontrak yang jelas antar bagian kode.
