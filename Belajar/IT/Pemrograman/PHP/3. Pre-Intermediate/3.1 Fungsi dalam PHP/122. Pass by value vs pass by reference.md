# 122. Pass by Value vs Pass by Reference

## Definisi Singkat
Pass by value mengirimkan salinan nilai ke fungsi (nilai asli tidak berubah), sedangkan pass by reference mengirimkan alamat memori variabel (nilai asli bisa diubah). Ditandai dengan `&` sebelum parameter.

## Analogi
**Pass by value**: Anda memfotokopi dokumen lalu memberikan fotokopiannya ke teman. Coretan teman Anda di fotokopi tidak akan merusak dokumen asli.

**Pass by reference**: Anda memberikan dokumen asli ke teman. Apa pun yang ia tulis di dokumen itu akan mengubah dokumen asli Anda.

## Poin-Poin Penting
- Default PHP adalah pass by value
- Pass by reference ditandai dengan `&` di depan parameter
- Pass by reference mengubah variabel asli
- Pass by reference lebih hemat memori untuk data besar
- Pass by reference bisa digunakan untuk mengembalikan banyak nilai

## Contoh Kode (PHP)
```php
<?php
// Pass by value
function tambahKurung($nama) {
    $nama = "<$nama>";
    return $nama;
}

$user = "Budi";
echo tambahKurung($user); // <Budi>
echo $user; // Budi (tidak berubah)

// Pass by reference
function tambahKurungRef(&$nama) {
    $nama = "<$nama>";
    return $nama;
}

$user2 = "Ani";
echo tambahKurungRef($user2); // <Ani>
echo $user2; // <Ani> (berubah!)

// Multiple return dengan reference
function hitung(&$a, &$b) {
    $a = $a * 2;
    $b = $b * 3;
}

$x = 5; $y = 10;
hitung($x, $y);
echo "$x, $y"; // 10, 30
?>
```

## Kasus Penggunaan Nyata
Digunakan ketika fungsi perlu memodifikasi array besar tanpa membuat salinan (hemat memori), atau ketika perlu mengembalikan beberapa nilai sekaligus dari satu fungsi.
