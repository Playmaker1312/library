# 117. Memanggil Fungsi scope

## Definisi Singkat
Scope fungsi adalah aturan tentang di mana suatu fungsi bisa dipanggil dalam kode — fungsi yang didefinisikan di global scope bisa dipanggil dari mana saja, termasuk dari dalam fungsi lain.

## Analogi
Seperti telepon rumah. Jika nomor telepon terdaftar di buku telepon global (global scope), siapa pun bisa meneleponnya dari mana saja. Tapi jika nomor hanya ditulis di catatan pribadi (local scope), hanya pemilik catatan itu yang bisa menggunakannya.

## Poin-Poin Penting
- Fungsi yang didefinisikan di global scope bisa dipanggil dari mana saja
- Fungsi bisa memanggil fungsi lain (nested call)
- Fungsi yang didefinisikan di dalam class (method) punya scope terbatas ke class tersebut
- Fungsi bisa dipanggil sebelum definisinya dalam file yang sama
- Fungsi tidak bisa dipanggil jika berada di dalam file yang tidak di-include

## Contoh Kode (PHP)
```php
<?php
// Global scope - bisa dipanggil dari mana saja
function salam() {
    return "Halo!";
}

function sapaUser($nama) {
    // Memanggil fungsi dari dalam fungsi lain
    $salam = salam();
    return "$salam $nama";
}

echo sapaUser("Budi"); // Halo! Budi

function luar() {
    function dalam() {
        return "Fungsi dalam";
    }
    return "Fungsi luar";
}

echo luar();  // Fungsi luar
echo dalam(); // Fungsi dalam (sudah terdefinisi setelah luar() dipanggil)
?>
```

## Kasus Penggunaan Nyata
Membuat hierarki fungsi di mana fungsi utama memanggil fungsi-fungsi pembantu (helper functions) untuk memecah logika kompleks menjadi bagian-bagian kecil yang lebih mudah diuji dan dipelihara.
