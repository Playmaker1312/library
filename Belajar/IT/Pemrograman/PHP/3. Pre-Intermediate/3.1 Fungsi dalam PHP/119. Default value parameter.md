# 119. Default Value Parameter

## Definisi Singkat
Parameter dengan nilai default adalah parameter yang memiliki nilai bawaan, sehingga jika argumen tidak diberikan saat pemanggilan fungsi, nilai default tersebut yang akan digunakan.

## Analogi
Seperti memesan kopi di kafe. Jika Anda tidak menyebutkan ukuran, barista akan membuatkan ukuran medium (default). Tapi jika Anda memesan "large", barista akan membuatkan large. Nilai medium adalah default — dipakai jika tidak ada instruksi khusus.

## Poin-Poin Penting
- Nilai default ditulis dengan `= nilai` setelah parameter
- Parameter dengan default harus ditempatkan setelah parameter tanpa default
- Nilai default bisa berupa literal, konstanta, atau array
- Nilai default tidak bisa berupa ekspresi kompleks atau variabel
- Bisa menggunakan `null` sebagai default untuk fleksibilitas

## Contoh Kode (PHP)
```php
<?php
// Nilai default string
function sapa($nama = "Tamu") {
    return "Halo, $nama!";
}

echo sapa("Budi"); // Halo, Budi!
echo sapa();       // Halo, Tamu!

// Default angka
function diskon($harga, $persen = 10) {
    return $harga - ($harga * $persen / 100);
}

echo diskon(100000);      // 90000 (diskon 10%)
echo diskon(100000, 20);  // 80000 (diskon 20%)

// Default array
function tampilkanConfig($config = ["theme" => "light"]) {
    return "Theme: " . $config["theme"];
}

// Default null
function cariUser($id = null) {
    if ($id === null) {
        return "Semua user";
    }
    return "User ID: $id";
}
?>
```

## Kasus Penggunaan Nyata
Fungsi dengan opsi konfigurasi yang jarang diubah, seperti paginasi (default 10 item per halaman), format tanggal, atau pengaturan tampilan yang sudah memiliki nilai standar.
