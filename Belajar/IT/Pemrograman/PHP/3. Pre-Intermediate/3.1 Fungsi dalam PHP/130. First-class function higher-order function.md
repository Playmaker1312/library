# 130. First-class Function Higher-order Function

## Definisi Singkat
First-class function berarti fungsi bisa diperlakukan seperti nilai lain (disimpan di variabel, dikirim ke fungsi lain). Higher-order function adalah fungsi yang menerima fungsi lain sebagai argumen atau mengembalikan fungsi.

## Analogi
**First-class**: Seperti wayang kulit — wayang (fungsi) bisa dipindahkan, disimpan di kotak (variabel), atau diberikan ke dalang lain (fungsi lain).

**Higher-order**: Seperti dalang yang memberi instruksi ke pemain gamelan. Dalang (higher-order function) tidak langsung memainkan musik, tapi menyuruh pemain (callback function) untuk melakukannya.

## Poin-Poin Penting
- Fungsi bisa disimpan dalam variabel, array, atau properti objek
- Fungsi bisa dikirim sebagai argumen ke fungsi lain (callback)
- Fungsi bisa dikembalikan dari fungsi lain
- `array_map`, `array_filter`, `array_reduce` adalah contoh higher-order function
- Memungkinkan paradigma functional programming di PHP

## Contoh Kode (PHP)
```php
<?php
// First-class function: fungsi sebagai nilai
function kaliDua($n) {
    return $n * 2;
}

$fungsi = 'kaliDua'; // string berisi nama fungsi
echo $fungsi(5); // 10

// Higher-order function: menerima callback
function prosesArray(array $data, callable $callback) {
    $hasil = [];
    foreach ($data as $item) {
        $hasil[] = $callback($item);
    }
    return $hasil;
}

$angka = [1, 2, 3, 4, 5];
$kuadrat = prosesArray($angka, fn($n) => $n * $n);
print_r($kuadrat); // [1, 4, 9, 16, 25]

// Higher-order function: mengembalikan fungsi
function buatFilter($min, $max) {
    return function($nilai) use ($min, $max) {
        return $nilai >= $min && $nilai <= $max;
    };
}

$filterUmur = buatFilter(17, 35);
$data = [15, 20, 30, 40, 17];
print_r(array_filter($data, $filterUmur)); // [20, 30, 17]

// Built-in higher-order functions
$genap = array_filter($angka, fn($n) => $n % 2 == 0);
$jumlah = array_reduce($angka, fn($carry, $n) => $carry + $n, 0);
echo $jumlah; // 15
?>
```
