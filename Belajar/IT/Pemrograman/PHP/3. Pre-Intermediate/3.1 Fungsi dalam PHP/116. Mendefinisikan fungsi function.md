# 116. Mendefinisikan Fungsi function

## Definisi Singkat
Fungsi adalah blok kode yang dapat digunakan kembali (reusable) yang diberi nama, ditulis sekali dan bisa dipanggil berkali-kali dari bagian mana pun dalam program.

## Analogi
Seperti resep masakan. Anda menulis langkah-langkahnya sekali di buku resep (definisi fungsi), lalu setiap kali ingin memasak hidangan itu, Anda tinggal mengikuti resep tersebut (memanggil fungsi) tanpa perlu menulis ulang langkah-langkahnya.

## Poin-Poin Penting
- Diawali dengan keyword `function`, diikuti nama, kurung `()`, dan blok `{}`
- Nama fungsi bersifat case-insensitive (tapi disarankan konsisten)
- Fungsi bisa dipanggil sebelum didefinisikan (tidak seperti bahasa lain)
- Fungsi bisa mengembalikan nilai dengan `return`
- Fungsi yang tidak mengembalikan nilai menghasilkan `null`

## Contoh Kode (PHP)
```php
<?php
// Mendefinisikan fungsi
function sapa() {
    echo "Halo, selamat datang!";
}

// Memanggil fungsi
sapa(); // Halo, selamat datang!

function hitungLuasLingkaran($jari) {
    return 3.14 * $jari * $jari;
}

$luas = hitungLuasLingkaran(7);
echo $luas; // 153.86
?>
```

## Kasus Penggunaan Nyata
Mengelompokkan logika bisnis yang berulang seperti validasi input, koneksi database, atau format tanggal agar kode lebih terstruktur dan mudah dipelihara.
