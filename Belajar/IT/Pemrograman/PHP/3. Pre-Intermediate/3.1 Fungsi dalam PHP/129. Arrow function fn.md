# 129. Arrow Function fn

## Definisi Singkat
Arrow function (diperkenalkan PHP 7.4) adalah sintaks ringkas untuk anonymous function menggunakan keyword `fn`, yang secara otomatis mengikat variabel dari parent scope (tidak perlu `use`).

## Analogi
Seperti pesan singkat SMS dibandingkan surat formal. Surat (anonymous function biasa) perlu amplop dan perangko (`use`). SMS (arrow function) langsung sampai — lebih pendek, lebih cepat, untuk hal-hal sederhana.

## Poin-Poin Penting
- Ditulis: `fn($param) => ekspresi`
- Hanya bisa berisi satu ekspresi (setelah `=>`)
- Tidak perlu keyword `return` — ekspresi langsung menjadi return value
- Secara otomatis mengikat variabel dari parent scope (by value)
- Tidak bisa menggunakan pass by reference atau `use` manual

## Contoh Kode (PHP)
```php
<?php
// Arrow function vs anonymous function
$angka = [1, 2, 3, 4, 5];

// Anonymous function biasa
$kaliDuaBiasa = array_map(function($n) {
    return $n * 2;
}, $angka);

// Arrow function
$kaliDua = array_map(fn($n) => $n * 2, $angka);

print_r($kaliDua); // [2, 4, 6, 8, 10]

// Otomatis mengikat variabel dari parent scope
$pajak = 0.11;
$harga = [10000, 20000, 30000];
$denganPajak = array_map(
    fn($h) => $h + ($h * $pajak),
    $harga
);

print_r($denganPajak); // [11100, 22200, 33300]

// Filter dengan arrow function
$genap = array_filter($angka, fn($n) => $n % 2 == 0);
print_r($genap); // [2, 4]

// Bisa multi-level (tapi tetap satu ekspresi)
$hasil = array_map(
    fn($n) => $n > 2 ? $n * 10 : $n,
    $angka
);
print_r($hasil); // [1, 2, 30, 40, 50]
?>
```

## Kasus Penggunaan Nyata
Transformasi data sederhana dalam array, mapping ID ke nama, filter cepat, atau operasi matematika ringkas di functional programming — di mana anonymous function biasa terasa terlalu panjang.
