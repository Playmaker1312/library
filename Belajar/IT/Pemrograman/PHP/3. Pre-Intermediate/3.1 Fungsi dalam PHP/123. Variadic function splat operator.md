# 123. Variadic Function Splat Operator

## Definisi Singkat
Variadic function adalah fungsi yang bisa menerima jumlah argumen yang tidak tetap menggunakan operator `...` (splat operator), yang mengumpulkan semua argumen menjadi array.

## Analogi
Seperti keranjang belanja. Anda bisa memasukkan 1 barang, 5 barang, atau 20 barang ke dalam keranjang yang sama. Keranjang itu (array `...$items`) akan menampung semua barang yang Anda masukkan, berapa pun jumlahnya.

## Poin-Poin Penting
- Ditulis dengan `...$namaParameter` pada parameter fungsi
- Semua argumen ekstra dikumpulkan menjadi array
- Hanya boleh satu parameter variadic dan harus di posisi terakhir
- Splat operator juga bisa digunakan saat memanggil fungsi (unpacking)
- Bekerja dengan type declaration: `int ...$angka`

## Contoh Kode (PHP)
```php
<?php
// Variadic parameter
function jumlahkan(...$angka) {
    return array_sum($angka);
}

echo jumlahkan(1, 2, 3);       // 6
echo jumlahkan(10, 20, 30, 40); // 100

// Dengan parameter biasa di depan
function sapaBanyak($salam, ...$nama) {
    foreach ($nama as $n) {
        echo "$salam, $n!\n";
    }
}

sapaBanyak("Halo", "Budi", "Ani", "Coki");
// Halo, Budi!
// Halo, Ani!
// Halo, Coki!

// Unpacking array saat memanggil fungsi
$nilai = [3, 5, 2];
echo jumlahkan(...$nilai); // 10

// Type declaration
function kalikan(int $pengali, int ...$angka): array {
    return array_map(fn($n) => $n * $pengali, $angka);
}

print_r(kalikan(2, 1, 2, 3)); // [2, 4, 6]
?>
```

## Kasus Penggunaan Nyata
Fungsi seperti `printf()`, log dengan banyak parameter, atau kalkulasi yang jumlah inputnya tidak pasti — misalnya fungsi untuk menjumlahkan nilai ujian siswa yang jumlahnya berbeda tiap kelas.
