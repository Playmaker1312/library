# 127. Anonymous Function Closure

## Definisi Singkat
Anonymous function (closure) adalah fungsi tanpa nama yang bisa disimpan ke variabel, dikirim sebagai argumen, atau dikembalikan dari fungsi lain. Ditulis tanpa nama setelah keyword `function`.

## Analogi
Seperti taksi online. Anda tidak memanggil "taksi bernama X", Anda cukup pesan "antar saya ke titik A" (fungsi tanpa nama). Taksi mana pun yang tersedia akan menjalankan tugas itu. Fungsinya yang penting, bukan namanya.

## Poin-Poin Penting
- Ditulis sebagai `function($param) { ... }` tanpa nama
- Harus diakhiri dengan `;` jika disimpan ke variabel
- Bisa mengakses variabel dari scope luar dengan `use`
- Sering digunakan sebagai callback untuk array functions
- Bisa ditulis sebagai arrow function (`fn`) untuk kasus sederhana

## Contoh Kode (PHP)
```php
<?php
// Anonymous function disimpan ke variabel
$sapa = function($nama) {
    return "Halo, $nama!";
};

echo $sapa("Budi"); // Halo, Budi!

// Sebagai callback
$angka = [1, 2, 3, 4, 5];
$kaliDua = array_map(function($n) {
    return $n * 2;
}, $angka);

print_r($kaliDua); // [2, 4, 6, 8, 10]

// Closure yang mengembalikan fungsi
function buatPengganda($pengali) {
    return function($angka) use ($pengali) {
        return $angka * $pengali;
    };
}

$kaliTiga = buatPengganda(3);
echo $kaliTiga(5); // 15

// Type declaration
$jumlah = function(int $a, int $b): int {
    return $a + $b;
};

echo $jumlah(10, 20); // 30
?>
```

## Kasus Penggunaan Nyata
Callback untuk operasi array (`array_map`, `array_filter`), handler dalam routing framework, atau fungsi yang perlu dibuat secara dinamis berdasarkan konteks.
