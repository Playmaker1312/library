# 118. Parameter Fungsi

## Definisi Singkat
Parameter adalah variabel yang didefinisikan dalam kurung `()` saat membuat fungsi, yang menerima nilai dari luar (argumen) ketika fungsi dipanggil.

## Analogi
Seperti mesin penjual minuman. Anda memasukkan koin (argumen) ke slot (parameter), lalu mesin memprosesnya dan mengeluarkan minuman. Slotnya sudah dirancang untuk menerima koin — itulah parameter.

## Poin-Poin Penting
- Parameter ditulis di dalam `()` saat definisi fungsi
- Argumen adalah nilai yang diberikan saat pemanggilan
- PHP mendukung argumen dengan jumlah fleksibel
- Parameter bisa memiliki tipe (type declaration)
- Parameter bisa memiliki nilai default

## Contoh Kode (PHP)
```php
<?php
// Satu parameter
function sapa($nama) {
    echo "Halo, $nama!";
}

sapa("Ani"); // Halo, Ani!

// Multiple parameter
function tambah($a, $b) {
    return $a + $b;
}

echo tambah(5, 3); // 8

// Parameter dengan nama variabel berbeda
function kurangi($x, $y) {
    return $x - $y;
}

echo kurangi(10, 4); // 6

// Argumen bisa berupa ekspresi
echo tambah(2 * 3, 4); // 10
?>
```

## Kasus Penggunaan Nyata
Membuat fungsi yang menerima input dari pengguna atau dari sistem (seperti ID pengguna, tanggal, atau filter pencarian) untuk memproses data secara dinamis.
