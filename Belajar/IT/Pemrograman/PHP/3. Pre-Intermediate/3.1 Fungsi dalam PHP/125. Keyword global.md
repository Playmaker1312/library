# 125. Keyword global

## Definisi Singkat
Keyword `global` digunakan di dalam fungsi untuk mengakses variabel yang didefinisikan di scope global (luar fungsi), sehingga fungsi bisa membaca dan mengubah variabel tersebut.

## Analogi
Seperti Anda berada di dalam ruang kerja pribadi (fungsi) tapi ingin mengambil dokumen dari lemari arsip ruang bersama (global). Anda harus membuka pintu (keyword global) untuk meraihnya.

## Poin-Poin Penting
- Keyword `global` diikuti nama variabel tanpa tanda `$` di depannya
- Setelah dideklarasikan global, variabel bisa dibaca dan diubah
- Alternatif lain: menggunakan array `$GLOBALS`
- Mengubah variabel global dari dalam fungsi akan mengubah nilai aslinya
- Sebaiknya batasi penggunaan variabel global untuk menghindari side effects

## Contoh Kode (PHP)
```php
<?php
$nama = "Budi";
$umur = 25;

function tampilkanData() {
    global $nama, $umur;
    echo "Nama: $nama, Umur: $umur";
}

tampilkanData(); // Nama: Budi, Umur: 25

// Mengubah variabel global dari dalam fungsi
function ubahNama($namaBaru) {
    global $nama;
    $nama = $namaBaru;
}

ubahNama("Ani");
echo $nama; // Ani

// Alternatif dengan $GLOBALS
function tampilkanLagi() {
    echo $GLOBALS['nama']; // Ani
}

tampilkanLagi(); // Ani
?>
```

## Kasus Penggunaan Nyata
Digunakan dalam skrip sederhana atau aplikasi legacy di mana konfigurasi global (seperti koneksi database atau setting aplikasi) perlu diakses dari berbagai fungsi tanpa meneruskannya sebagai parameter.
