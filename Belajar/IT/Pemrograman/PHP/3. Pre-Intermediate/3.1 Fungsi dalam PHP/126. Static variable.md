# 126. Static Variable

## Definisi Singkat
Static variable adalah variabel lokal di dalam fungsi yang mempertahankan nilainya antar pemanggilan fungsi — tidak dihapus setelah fungsi selesai dieksekusi, melainkan tetap ada di memori.

## Analogi
Seperti odometer mobil. Setiap kali Anda berkendara (memanggil fungsi), odometer tidak kembali ke nol. Ia terus mengingat dan menambahkan jarak tempuh dari perjalanan sebelumnya.

## Poin-Poin Penting
- Dideklarasikan dengan keyword `static` di dalam fungsi
- Hanya diinisialisasi sekali (pemanggilan pertama)
- Nilainya tetap tersimpan antar pemanggilan fungsi
- Bersifat local (hanya bisa diakses dari dalam fungsi tersebut)
- Berguna untuk caching nilai atau counter

## Contoh Kode (PHP)
```php
<?php
// Counter sederhana
function hitungKunjungan() {
    static $counter = 0;
    $counter++;
    return $counter;
}

echo hitungKunjungan(); // 1
echo hitungKunjungan(); // 2
echo hitungKunjungan(); // 3

// Cache hasil komputasi
function faktorial($n) {
    static $cache = [];
    
    if (isset($cache[$n])) {
        return $cache[$n]; // ambil dari cache
    }
    
    $hasil = ($n <= 1) ? 1 : $n * faktorial($n - 1);
    $cache[$n] = $hasil;
    return $hasil;
}

echo faktorial(5); // 120 (dihitung)
echo faktorial(5); // 120 (dari cache)

// Bandingkan dengan non-static
function nonStatic() {
    $count = 0;
    $count++;
    return $count;
}

echo nonStatic(); // 1
echo nonStatic(); // 1 (selalu reset ke 0 dulu)
?>
```

## Kasus Penggunaan Nyata
Membuat fungsi generator nomor urut, menyimpan cache hasil komputasi berat, atau melacak state sederhana tanpa perlu menggunakan variabel global.
