# 124. Variable Scope Local Global Static

## Definisi Singkat
Scope variabel menentukan di mana suatu variabel bisa diakses dalam program: local (hanya di dalam fungsi), global (di luar fungsi), dan static (tetap bernilai antar pemanggilan fungsi).

## Analogi
**Local**: Seperti buku catatan pribadi yang hanya ada di dalam kamar Anda.
**Global**: Seperti papan pengumuman di ruang tamu yang bisa dilihat semua orang.
**Static**: Seperti papan tulis kecil yang Anda bawa — isinya tidak hilang meskipun Anda keluar-masuk kamar.

## Poin-Poin Penting
- Variabel di dalam fungsi bersifat local — tidak bisa diakses dari luar
- Variabel di luar fungsi bersifat global
- Variabel lokal dibuat setiap fungsi dipanggil, dihapus setelah selesai
- Variabel static dipertahankan nilainya antar pemanggilan fungsi
- Keyword `global` digunakan untuk mengakses variabel global dari dalam fungsi

## Contoh Kode (PHP)
```php
<?php
// Variabel global
$namaGlobal = "Budi";

function testScope() {
    // Variabel lokal
    $namaLokal = "Ani";
    echo $namaLokal; // Ani
    // echo $namaGlobal; // ERROR: undefined
}

testScope();
// echo $namaLokal; // ERROR: undefined
echo $namaGlobal; // Budi

// Variabel static
function counter() {
    static $count = 0;
    $count++;
    return $count;
}

echo counter(); // 1
echo counter(); // 2
echo counter(); // 3
?>
```

## Kasus Penggunaan Nyata
Memisahkan variabel yang hanya digunakan di dalam fungsi (local) dari data aplikasi yang perlu diakses banyak bagian (global), serta menggunakan static variable untuk fungsi counter atau cache sederhana.
