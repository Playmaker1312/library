# 120. Type Declaration Parameter

## Definisi Singkat
Type declaration (type hinting) adalah fitur untuk menentukan tipe data yang diharapkan dari suatu parameter, sehingga PHP akan memeriksa dan memaksa argumen sesuai tipe yang ditentukan.

## Analogi
Seperti lubang kunci yang bentuknya khusus. Hanya kunci dengan bentuk tertentu yang bisa masuk. Jika Anda mencoba memasukkan kunci lain (tipe salah), tidak akan bisa — PHP akan menolaknya.

## Poin-Poin Penting
- Ditulis sebelum nama parameter: `function func(int $x)`
- Tipe yang didukung: `int`, `float`, `string`, `bool`, `array`, `object`, `callable`, `iterable`, `null`
- Juga mendukung class/interface names
- Strict type: deklarasikan `declare(strict_types=1)` di baris pertama file
- Tanpa strict type, PHP akan mencoba mengonversi tipe secara otomatis (coercion)

## Contoh Kode (PHP)
```php
<?php
// Tanpa strict type (coercion mode)
function hitungUmur(int $tahunLahir) {
    return 2025 - $tahunLahir;
}

echo hitungUmur("1990"); // 35 (string "1990" dikonversi ke int)

// Dengan strict type
declare(strict_types=1);

function kali(float $a, float $b): float {
    return $a * $b;
}

// echo kali(2.5, "3"); // Fatal Error: float expected

// Type declaration class
class User {}
function prosesUser(User $user) {
    // ...
}

// Union type (PHP 8+)
function cetak(string|int $nilai) {
    echo $nilai;
}
?>
```

## Kasus Penggunaan Nyata
Memastikan fungsi matematika hanya menerima angka, fungsi string hanya menerima teks, atau method hanya menerima objek tertentu — sehingga bug tipe data bisa tertangkap sejak dini.
