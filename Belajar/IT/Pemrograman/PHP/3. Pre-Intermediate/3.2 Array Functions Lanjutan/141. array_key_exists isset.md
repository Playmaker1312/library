# 141. array_key_exists isset

## Definisi Singkat
`array_key_exists()` memeriksa apakah suatu key ada di dalam array (meskipun nilainya `null`). `isset()` memeriksa apakah suatu key ada DAN nilainya tidak `null`.

## Analogi
**array_key_exists**: Seperti melihat apakah ada lemari dengan label "Peralatan Dapur" di rumah, meskipun lemari itu kosong.

**isset**: Seperti melihat apakah lemari "Peralatan Dapur" ada dan berisi sesuatu. Jika lemari ada tapi kosong (null), isset menganggapnya tidak ada.

## Poin-Poin Penting
- `array_key_exists(key, array)` mengembalikan `true` jika key ada, meskipun value-nya `null`
- `isset($array[key])` mengembalikan `false` jika key tidak ada ATAU key ada tapi nilainya `null`
- `isset()` lebih cepat sedikit daripada `array_key_exists()`
- Hati-hati: `isset()` mengembalikan `false` untuk nilai `null`
- PHP 8.0+ juga punya `key_exists()` (alias)

## Contoh Kode (PHP)
```php
<?php
$data = [
    "nama" => "Budi",
    "umur" => null,
    "kota" => "Jakarta"
];

// array_key_exists dengan null value
echo isset($data["umur"]) ? "ada" : "tidak ada"; // tidak ada
echo array_key_exists("umur", $data) ? "ada" : "tidak ada"; // ada

// isset untuk check biasa
echo isset($data["nama"]) ? "ada" : "tidak ada"; // ada
echo isset($data["alamat"]) ? "ada" : "tidak ada"; // tidak ada

// Kapan pakai apa
function getConfig($key) {
    $config = [
        "debug" => false,
        "db_host" => "localhost",
        "cache_ttl" => null // sengaja null
    ];
    
    // array_key_exists: ketika null adalah nilai valid
    if (array_key_exists($key, $config)) {
        return $config[$key];
    }
    return "Key tidak ditemukan";
}

echo getConfig("cache_ttl"); // null (ada, tapi null)
echo getConfig("debug");     // false (ada)
echo getConfig("fake");      // Key tidak ditemukan

// PHP 8.0+
// echo key_exists("nama", $data) ? "ada" : "tidak ada"; // ada
?>
```

## Kasus Penggunaan Nyata
Memeriksa keberadaan key di array form atau $_POST, validasi konfigurasi opsional dengan null value, atau mengecek parameter URL sebelum menggunakannya.
