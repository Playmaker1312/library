# 144. compact extract

## Definisi Singkat
`compact()` membuat array asosiatif dari variabel-variabel yang ada di scope saat ini. `extract()` melakukan kebalikannya: memasukkan elemen array asosiatif menjadi variabel-variabel di scope saat ini.

## Analogi
**compact**: Seperti petugas yang mendata barang-barang di kamar. Ia melihat ada buku ("Buku"), pensil ("Pensil"), dan penggaris ("Penggaris") — lalu mencatat semuanya dalam daftar: `["Buku" => "nilai_buku", "Pensil" => "nilai_pensil"]`.

**extract**: Sebaliknya, petugas membuka daftar barang lalu mengeluarkan setiap item dari daftar dan menaruhnya di kamar sebagai benda nyata. Tiba-tiba ada buku, pensil, dan penggaris berserakan di ruangan.

## Poin-Poin Penting
- `compact('var1', 'var2')` mencari variabel `$var1`, `$var2` di scope dan membuat array
- `extract($array)` membuat variabel dari setiap key-value
- `extract` bisa menimpa variabel yang sudah ada — hati-hati!
- `extract` memiliki flags untuk mengontrol perilaku (EXTR_SKIP, EXTR_PREFIX_SAME, dll)
- Keduanya berguna untuk template/view rendering

## Contoh Kode (PHP)
```php
<?php
$nama = "Budi";
$umur = 25;
$kota = "Jakarta";

// compact: dari variabel ke array
$data = compact("nama", "umur", "kota");
print_r($data);
// ["nama" => "Budi", "umur" => 25, "kota" => "Jakarta"]

// extract: dari array ke variabel
$config = [
    "db_host" => "localhost",
    "db_user" => "root",
    "db_pass" => "secret"
];

extract($config);
echo $db_host; // localhost
echo $db_user; // root

// Hati-hati: extract bisa menimpa
$nama = "Lama";
$arr = ["nama" => "Baru"];
extract($arr); // menimpa $nama!
echo $nama; // Baru

// Gunakan EXTR_SKIP untuk aman
extract($arr, EXTR_SKIP);
echo $nama; // tetap Baru (karena sudah ditimpa sebelumnya)

// Template rendering
function render($template, $data) {
    extract($data);
    ob_start();
    include "$template.php";
    return ob_get_clean();
}
// $nama, $umur, $kota tersedia di file template
?>
```

## Kasus Penggunaan Nyata
Menyiapkan data untuk template/view (compact dari variabel ke array), atau sebaliknya mengambil data dari array konfigurasi menjadi variabel (extract) untuk kemudahan akses.
