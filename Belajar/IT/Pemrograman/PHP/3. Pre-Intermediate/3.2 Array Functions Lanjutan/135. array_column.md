# 135. array_column

## Definisi Singkat
`array_column()` mengambil satu kolom (key) dari array multidimensi atau array of objects dan mengembalikannya sebagai array satu dimensi. Juga bisa menggunakan kolom kedua sebagai key.

## Analogi
Seperti Anda memiliki lemari file dengan banyak map (array multidimensi). Anda menarik semua lembar "Nama" dari setiap map dan membuat tumpukan terpisah berisi semua nama — rapi dan terorganisir.

## Poin-Poin Penting
- Parameter: `array_column(array, column_key, index_key)`
- `column_key` bisa berupa string (key) atau integer (index)
- `index_key` opsional, untuk menggunakan kolom tertentu sebagai key array hasil
- Bekerja dengan array of arrays maupun array of objects
- Jika `column_key` adalah `null`, seluruh array dikembalikan dengan key dari `index_key`

## Contoh Kode (PHP)
```php
<?php
$users = [
    ["id" => 1, "nama" => "Budi", "email" => "budi@mail.com"],
    ["id" => 2, "nama" => "Ani", "email" => "ani@mail.com"],
    ["id" => 3, "nama" => "Coki", "email" => "coki@mail.com"]
];

// Ambil semua nama
$nama = array_column($users, "nama");
print_r($nama); // ["Budi", "Ani", "Coki"]

// Gunakan id sebagai key
$namaByID = array_column($users, "nama", "id");
print_r($namaByID); // [1 => "Budi", 2 => "Ani", 3 => "Coki"]

// Array of objects
$objUsers = [
    (object)["id" => 1, "nama" => "Budi"],
    (object)["id" => 2, "nama" => "Ani"]
];

$namaObj = array_column($objUsers, "nama");
print_r($namaObj); // ["Budi", "Ani"]

// column_key null - seluruh array dengan index key
$byEmail = array_column($users, null, "email");
print_r($byEmail);
// ["budi@mail.com" => [...], "ani@mail.com" => [...], ...]
?>
```

## Kasus Penggunaan Nyata
Membuat dropdown select dari data database, mengambil daftar ID untuk query lanjutan, atau membuat mapping data untuk lookup cepat berdasarkan key tertentu.
