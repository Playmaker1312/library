# 133. array_reduce

## Definisi Singkat
`array_reduce()` mereduksi array menjadi satu nilai tunggal dengan menjalankan fungsi callback secara iteratif, di mana hasil dari iterasi sebelumnya menjadi input untuk iterasi berikutnya (carry).

## Analogi
Seperti kereta api yang mengambil penumpang di setiap stasiun. Di stasiun pertama, kereta kosong (initial value). Di setiap stasiun, penumpang baru naik (elemen array) dan bergabung dengan yang sudah ada (carry). Di akhir perjalanan, kereta berisi semua penumpang (satu nilai hasil akumulasi).

## Poin-Poin Penting
- Menerima callback dengan dua parameter: `$carry` (hasil sebelumnya) dan `$item` (elemen saat ini)
- Parameter ketiga adalah initial value untuk `$carry`
- Jika array kosong, initial value yang dikembalikan
- Sangat berguna untuk operasi agregasi
- Bisa digunakan untuk transformasi array ke tipe lain

## Contoh Kode (PHP)
```php
<?php
// Menjumlahkan semua elemen
$angka = [1, 2, 3, 4, 5];
$total = array_reduce($angka, fn($carry, $n) => $carry + $n, 0);
echo $total; // 15

// Mencari nilai maksimum
$nilai = [45, 78, 92, 33, 88, 76];
$maks = array_reduce($nilai, fn($carry, $n) => $n > $carry ? $n : $carry, 0);
echo $maks; // 92

// Array ke string
$buah = ["Apel", "Jeruk", "Mangga"];
$kalimat = array_reduce($buah, fn($c, $b) => $c . ($c ? ", " : "") . $b, "");
echo $kalimat; // Apel, Jeruk, Mangga

// Grouping data
$transaksi = [
    ["kategori" => "Makanan", "jumlah" => 50000],
    ["kategori" => "Transport", "jumlah" => 20000],
    ["kategori" => "Makanan", "jumlah" => 30000]
];

$group = array_reduce($transaksi, function($carry, $t) {
    $carry[$t["kategori"]] = ($carry[$t["kategori"]] ?? 0) + $t["jumlah"];
    return $carry;
}, []);

print_r($group); // ["Makanan" => 80000, "Transport" => 20000]
?>
```

## Kasus Penggunaan Nyata
Menghitung total belanja, mengakumulasi laporan keuangan, menggabungkan data dari beberapa sumber, atau membuat summary statistics dari kumpulan data.
