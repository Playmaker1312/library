# 143. usort uasort uksort

## Definisi Singkat
`usort()`, `uasort()`, dan `uksort()` adalah fungsi sorting kustom di PHP yang menggunakan callback untuk menentukan urutan elemen. `usort` mereset index, `uasort` mempertahankan key-value, `uksort` sorting berdasarkan key.

## Analogi
**usort**: Seperti guru yang menyuruh murid-murid berbaris berdasarkan tinggi badan. Guru memberikan instruksi "bandingkan tinggi A dan B" (callback), lalu murid-murid berbaris. Nomor urut presensi (key) diabaikan.

**uasort**: Seperti menata buku di rak berdasarkan genre, tapi label harga asli (key) tetap menempel di buku.

**uksort**: Seperti mengatur file berdasarkan abjad nama filenya (key), bukan isi filenya.

## Poin-Poin Penting
- Callback menerima dua parameter (`$a, $b`) dan harus mengembalikan integer:
  - Negatif: `$a` dianggap < `$b`
  - Nol: `$a` == `$b`
  - Positif: `$a` > `$b`
- `usort` dan `uasort` sorting berdasarkan value
- `uksort` sorting berdasarkan key
- `usort` mereset index numerik; `uasort` mempertahankan key

## Contoh Kode (PHP)
```php
<?php
// usort: sort array numerik dengan aturan kustom
$angka = [3, 1, 4, 1, 5, 9, 2, 6];
usort($angka, fn($a, $b) => $a <=> $b); // ASC
print_r($angka); // [1, 1, 2, 3, 4, 5, 6, 9]

usort($angka, fn($a, $b) => $b <=> $a); // DESC
print_r($angka); // [9, 6, 5, 4, 3, 2, 1, 1]

// uasort: sort array asosiatif, pertahankan key
$nilai = ["Budi" => 85, "Ani" => 92, "Coki" => 78, "Dewi" => 88];
uasort($nilai, fn($a, $b) => $b <=> $a); // DESC
print_r($nilai);
// ["Ani" => 92, "Dewi" => 88, "Budi" => 85, "Coki" => 78]

// uksort: sort berdasarkan key
$data = ["z" => 1, "m" => 2, "a" => 3];
uksort($data, fn($a, $b) => strcmp($a, $b));
print_r($data); // ["a" => 3, "m" => 2, "z" => 1]

// Sort array multidimensi
$produk = [
    ["nama" => "Buku", "harga" => 15000],
    ["nama" => "Pena", "harga" => 5000],
    ["nama" => "Penghapus", "harga" => 3000]
];

usort($produk, fn($a, $b) => $a["harga"] <=> $b["harga"]);
print_r($produk);
// Pena (3000), Penghapus (5000), Buku (15000) - sesuai harga
?>
```

## Kasus Penggunaan Nyata
Mengurutkan data berdasarkan kriteria kompleks (tanggal, status, prioritas), sorting daftar produk berdasarkan harga atau rating, atau mengurutkan file berdasarkan ekstensi.
