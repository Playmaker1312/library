# 134. array_walk

## Definisi Singkat
`array_walk()` menerapkan fungsi callback ke setiap elemen array dan memodifikasi array asli secara langsung (pass by reference), berbeda dengan `array_map` yang mengembalikan array baru.

## Analogi
Seperti petugas yang berkeliling di setiap rumah (elemen array) dan langsung mengecat pagar rumah tersebut. Rumah asli berubah warnanya. Tidak ada rumah baru yang dibuat — yang ada hanyalah perubahan pada rumah yang sudah ada.

## Poin-Poin Penting
- Memodifikasi array asli (parameter dikirim sebagai reference)
- Callback bisa menerima value, key, dan optional argumen ketiga
- Mengembalikan `true` jika berhasil
- Berbeda dengan `array_map` yang mengembalikan array baru (immutable)
- Bisa menerima parameter tambahan untuk callback

## Contoh Kode (PHP)
```php
<?php
// Memodifikasi array asli
$nama = ["Budi", "Ani", "Coki"];
array_walk($nama, function(&$value, $key) {
    $value = strtoupper($value);
});
print_r($nama); // ["BUDI", "ANI", "COKI"]

// Menggunakan key
$data = ["nama" => "Budi", "umur" => 25, "kota" => "Jakarta"];
array_walk($data, function($value, $key) {
    echo "$key: $value\n";
});
// nama: Budi
// umur: 25
// kota: Jakarta

// Parameter tambahan
$prefix = "Mr. ";
$daftar = ["Budi", "Ani"];
array_walk($daftar, function(&$nama, $key, $prefix) {
    $nama = $prefix . $nama;
}, $prefix);
print_r($daftar); // ["Mr. Budi", "Mr. Ani"]

// array_walk vs array_map
$asli = [1, 2, 3];
$mapHasil = array_map(fn($n) => $n * 2, $asli);
// $asli tetap [1,2,3], $mapHasil [2,4,6]

array_walk($asli, function(&$n) { $n *= 2; });
// $asli sekarang [2,4,6]
?>
```

## Kasus Penggunaan Nyata
Memodifikasi data dalam jumlah besar secara langsung (seperti membersihkan input, mengubah format), debugging/mencetak isi array, atau menerapkan perubahan pada collection objek.
