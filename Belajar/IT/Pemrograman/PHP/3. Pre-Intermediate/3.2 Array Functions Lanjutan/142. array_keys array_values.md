# 142. array_keys array_values

## Definisi Singkat
`array_keys()` mengembalikan semua key dari array sebagai array numerik. `array_values()` mengembalikan semua value dari array sebagai array numerik (mereset index).

## Analogi
**array_keys**: Seperti mengambil semua label dari stoples-stoples di dapur. Anda mendapatkan daftar: "Gula", "Tepung", "Kopi" — tanpa peduli apa isinya.

**array_values**: Sebaliknya, Anda membuka semua stoples dan hanya mengambil isinya, lalu meletakkannya berjajar tanpa label. Anda punya deretan: [Gula pasir, Tepung terigu, Kopi bubuk].

## Poin-Poin Penting
- `array_keys()` bisa menerima parameter kedua untuk mencari key yang memiliki value tertentu
- `array_values()` mereset index numerik dari 0
- Keduanya mengembalikan array baru (tidak memodifikasi asli)
- Berguna untuk iterasi atau transformasi

## Contoh Kode (PHP)
```php
<?php
$data = [
    "nama" => "Budi",
    "umur" => 25,
    "kota" => "Jakarta",
    "hobi" => "Membaca"
];

// Ambil semua key
$keys = array_keys($data);
print_r($keys); // ["nama", "umur", "kota", "hobi"]

// Ambil semua value (index di-reset)
$values = array_values($data);
print_r($values); // ["Budi", 25, "Jakarta", "Membaca"]

// array_keys dengan search value
$skor = ["Budi" => 85, "Ani" => 92, "Coki" => 85, "Dewi" => 78];
$nilai85 = array_keys($skor, 85);
print_r($nilai85); // ["Budi", "Coki"]

// Reset index setelah array_filter
$filtered = array_filter($skor, fn($s) => $s >= 85);
// ["Budi" => 85, "Ani" => 92, "Coki" => 85]
$reset = array_values($filtered);
print_r($reset); // [85, 92, 85]

// Casting array ke indexed list
$produk = ["p001" => "Buku", "p002" => "Pena", "p003" => "Penghapus"];
$list = array_values($produk);
print_r($list); // ["Buku", "Pena", "Penghapus"]
?>
```

## Kasus Penggunaan Nyata
Mendapatkan daftar kolom dari hasil query untuk header tabel, mereset index setelah filter, atau mengambil nilai-nilai tertentu untuk diolah lebih lanjut (misal: dijumlah, dirata-rata).
