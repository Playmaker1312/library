# 131. array_map

## Definisi Singkat
`array_map()` menerapkan fungsi callback ke setiap elemen array dan mengembalikan array baru dengan hasil yang sudah diubah, tanpa memodifikasi array asli.

## Analogi
Seperti ban berjalan di pabrik. Setiap produk yang lewat (elemen array) melewati stasiun kerja (callback) yang melakukan sesuatu padanya — mengecat, memberi label, dll. Hasilnya adalah produk yang sudah diubah, dan produk asli tetap utuh.

## Poin-Poin Penting
- Tidak memodifikasi array asli (immutable)
- Callback bisa berupa anonymous function, arrow function, atau nama fungsi
- Bisa menerima banyak array sebagai argumen
- Jika callback menerima parameter dengan nama yang sama, gunakan array yang sesuai
- Array asli tetap tidak berubah

## Contoh Kode (PHP)
```php
<?php
$angka = [1, 2, 3, 4, 5];

// Arrow function
$kuadrat = array_map(fn($n) => $n * $n, $angka);
print_r($kuadrat); // [1, 4, 9, 16, 25]

// Nama fungsi built-in
$huruf = ["a", "b", "c"];
$upper = array_map("strtoupper", $huruf);
print_r($upper); // ["A", "B", "C"]

// Multiple array
$harga = [10000, 20000, 30000];
$diskon = [10, 20, 15];
$setelahDiskon = array_map(
    fn($h, $d) => $h - ($h * $d / 100),
    $harga, $diskon
);
print_r($setelahDiskon); // [9000, 16000, 25500]

// Array asli tidak berubah
$asli = [1, 2, 3];
$hasil = array_map(fn($n) => $n * 10, $asli);
print_r($asli);  // [1, 2, 3]
print_r($hasil); // [10, 20, 30]
?>
```

## Kasus Penggunaan Nyata
Transformasi data massal: mengubah format tanggal dari database, menambahkan prefix/suffix ke semua item, mengkonversi suhu dari Celsius ke Fahrenheit, atau memformat array objek menjadi array string tertentu.
