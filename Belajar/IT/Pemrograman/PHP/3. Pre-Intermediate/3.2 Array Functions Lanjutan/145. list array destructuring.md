# 145. list array destructuring

## Definisi Singkat
`list()` atau sintaks `[]` (short syntax, PHP 7.1+) digunakan untuk mendestruktur array — mengekstrak elemen array ke variabel-variabel terpisah dalam satu baris.

## Analogi
Seperti membuka bungkusan kado yang berisi beberapa hadiah. Anda membuka satu bungkusan (array) dan mengeluarkan isinya: kemeja, dasi, dan sepatu — lalu menaruh masing-masing di tempatnya (variabel terpisah).

## Poin-Poin Penting
- `list($a, $b) = $array` — elemen array dipetakan berdasarkan posisi
- Short syntax: `[$a, $b] = $array` (PHP 7.1+)
- Bisa melewati elemen dengan tidak menulis variabel: `list(, $b) = $arr`
- Destructuring bersarang (nested) didukung
- Bisa digunakan dalam foreach: `foreach($arr as [$k, $v])`

## Contoh Kode (PHP)
```php
<?php
// list() dasar
$buah = ["Apel", "Jeruk", "Mangga"];
list($a, $b, $c) = $buah;
echo "$a, $b, $c"; // Apel, Jeruk, Mangga

// Short syntax (PHP 7.1+)
[$a, $b, $c] = $buah;
echo "$a, $b, $c"; // Apel, Jeruk, Mangga

// Melewati elemen
[, , $c] = $buah;
echo $c; // Mangga

// Swap variabel
$x = 1; $y = 2;
[$x, $y] = [$y, $x];
echo "$x, $y"; // 2, 1

// Destructuring dalam foreach
$users = [
    ["Budi", 25],
    ["Ani", 30],
    ["Coki", 22]
];

foreach ($users as [$nama, $umur]) {
    echo "$nama berumur $umur\n";
}
// Budi berumur 25
// Ani berumur 30
// Coki berumur 22

// Destructuring array asosiatif (PHP 7.1+)
$data = ["nama" => "Budi", "umur" => 25];
["nama" => $n, "umur" => $u] = $data;
echo "$n, $u"; // Budi, 25

// Nested destructuring
$matrix = [[1, 2], [3, 4]];
[[$a, $b], [$c, $d]] = $matrix;
echo "$a, $b, $c, $d"; // 1, 2, 3, 4
?>
```

## Kasus Penggunaan Nyata
Mengambil data dari hasil query database (misal: `$row = $stmt->fetch()`), swap variabel tanpa temporary variable, atau memproses data CSV/array berpasangan dengan rapi.
