# 138. array_flip

## Definisi Singkat
`array_flip()` menukar posisi key dan value dalam array — key menjadi value, dan value menjadi key. Berguna untuk membalikkan hubungan key-value.

## Analogi
Seperti buku telepon. Buku telepon normal memetakan "nama -> nomor". Jika Anda membalikkannya (flip), Anda punya pemetaan "nomor -> nama". Berguna ketika Anda perlu mencari nama berdasarkan nomor telepon dengan cepat.

## Poin-Poin Penting
- Value array asli harus bertipe string atau integer (bisa menjadi key)
- Jika ada value duplikat, key terakhir yang akan digunakan
- Value bertipe float akan dipotong menjadi integer
- Value boolean atau array tidak bisa di-flip (akan error)
- Berguna untuk membuat lookup table terbalik

## Contoh Kode (PHP)
```php
<?php
// Flip sederhana
$asli = ["a" => 1, "b" => 2, "c" => 3];
$flip = array_flip($asli);
print_r($flip); // [1 => "a", 2 => "b", 3 => "c"]

// Value duplikat
$duplikat = ["a" => 1, "b" => 2, "c" => 1];
$flipDup = array_flip($duplikat);
print_r($flipDup); // [1 => "c", 2 => "b"] (c menimpa a)

// Use case: membalik mapping
$kodeNegara = [
    "ID" => "Indonesia",
    "MY" => "Malaysia",
    "SG" => "Singapura"
];

$negaraKode = array_flip($kodeNegara);
echo $negaraKode["Indonesia"]; // ID

// Mencari key berdasarkan value dengan cepat
$nilai = ["Budi" => 85, "Ani" => 92, "Coki" => 78];
$nilaiFlip = array_flip($nilai);
echo $nilaiFlip[92]; // Ani

// Peringatan: value boolean tidak valid
// $invalid = array_flip(["a" => true]); // Warning: Can only flip string and integer values
?>
```

## Kasus Penggunaan Nyata
Membuat mapping terbalik (misal: dari ID user ke username dan sebaliknya), mencari key berdasarkan value dalam array asosiatif tanpa perlu looping manual.
