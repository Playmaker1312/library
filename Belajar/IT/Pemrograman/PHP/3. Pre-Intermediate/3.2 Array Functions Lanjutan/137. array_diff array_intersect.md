# 137. array_diff array_intersect

## Definisi Singkat
`array_diff()` mengembalikan elemen dari array pertama yang tidak ada di array lain (selisih). `array_intersect()` mengembalikan elemen yang ada di semua array (irisan).

## Analogi
**array_diff**: Dua keranjang buah. Keranjang A berisi apel, jeruk, mangga. Keranjang B berisi jeruk, pisang. Selisih A - B adalah apel dan mangga (yang tidak ada di B).

**array_intersect**: Dari dua keranjang yang sama, irisan adalah jeruk (buah yang ada di kedua keranjang).

## Poin-Poin Penting
- Membandingkan nilai (bukan key)
- `array_diff()`: elemen array pertama yang tidak ditemukan di array lain
- `array_intersect()`: elemen yang ada di SEMUA array
- Variasi: `array_diff_key()`, `array_diff_assoc()`, `array_intersect_key()`, `array_intersect_assoc()`
- String comparison bersifat case-sensitive

## Contoh Kode (PHP)
```php
<?php
// array_diff
$array1 = [1, 2, 3, 4, 5];
$array2 = [3, 4, 5, 6, 7];
$diff = array_diff($array1, $array2);
print_r($diff); // [1, 2]

// array_intersect
$intersect = array_intersect($array1, $array2);
print_r($intersect); // [3, 4, 5]

// Dengan array asosiatif
$userA = ["nama" => "Budi", "umur" => 25, "kota" => "Jakarta"];
$userB = ["nama" => "Ani", "umur" => 25, "kota" => "Bandung"];

$sama = array_intersect($userA, $userB);
print_r($sama); // ["umur" => 25]

$beda = array_diff($userA, $userB);
print_r($beda); // ["nama" => "Budi", "kota" => "Jakarta"]

// array_diff_assoc (perhatikan key juga)
$diffAssoc = array_diff_assoc($userA, $userB);
print_r($diffAssoc);
// ["nama" => "Budi", "kota" => "Jakarta"] (umur sama key+value)
?>
```

## Kasus Penggunaan Nyata
Mencari item yang belum diproses (diff), mencari data yang sama di dua dataset (intersect), sinkronisasi data, atau deteksi perubahan antara dua versi data.
