# 139. array_chunk

## Definisi Singkat
`array_chunk()` memotong array menjadi beberapa bagian (chunk) dengan ukuran tertentu, mengembalikan array multidimensi yang berisi potongan-potongan array asli.

## Analogi
Seperti memotong kue bolu besar menjadi beberapa potong dengan ukuran sama. Anda punya kue utuh (array besar), lalu memotongnya menjadi irisan-irisan (chunk) yang masing-masing berisi, misalnya, 3 lapis. Kue tetap sama, tapi sekarang tersaji dalam potongan-potongan.

## Poin-Poin Penting
- Parameter: `array_chunk(array, length, preserve_keys)`
- `length` adalah jumlah elemen per chunk (harus positif)
- `preserve_keys` default `false` (key di-reset numerik)
- Jika `true`, key asli dipertahankan
- Berguna untuk pagination atau batch processing

## Contoh Kode (PHP)
```php
<?php
$buah = ["Apel", "Jeruk", "Mangga", "Pisang", "Anggur", "Semangka", "Melon"];

// Potong per 3 elemen
$chunk = array_chunk($buah, 3);
print_r($chunk);
// [
//   ["Apel", "Jeruk", "Mangga"],
//   ["Pisang", "Anggur", "Semangka"],
//   ["Melon"]
// ]

// Dengan preserve keys
$asosiatif = ["a" => 1, "b" => 2, "c" => 3, "d" => 4, "e" => 5];
$chunkKey = array_chunk($asosiatif, 2, true);
print_r($chunkKey);
// [
//   ["a" => 1, "b" => 2],
//   ["c" => 3, "d" => 4],
//   ["e" => 5]
// ]

// Pagination sederhana
$items = range(1, 25);
$perHalaman = 10;
$halaman = array_chunk($items, $perHalaman);

// Halaman 1: 10 item pertama
$hal1 = $halaman[0];
echo count($hal1); // 10

// Batch processing
$data = range(1, 100);
$batch = array_chunk($data, 20);
foreach ($batch as $i => $b) {
    echo "Memproses batch " . ($i + 1) . ": " . count($b) . " item\n";
}
?>
```

## Kasus Penggunaan Nyata
Membagi data untuk pagination, batch processing data besar (misal: 1000 record per batch untuk insert database), atau membagi item menjadi kolom-kolom di layout grid.
