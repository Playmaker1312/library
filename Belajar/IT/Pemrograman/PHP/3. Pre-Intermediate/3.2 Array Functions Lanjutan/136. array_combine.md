# 136. array_combine

## Definisi Singkat
`array_combine()` menggabungkan dua array: satu menjadi key dan satu lagi menjadi value, menghasilkan array asosiatif baru. Kedua array harus memiliki jumlah elemen yang sama.

## Analogi
Seperti Anda memiliki dua tumpukan kartu — satu tumpukan berisi "nama hubungan" (suami, istri, anak) dan satu lagi berisi "nama orang" (Budi, Ani, Coki). Anda memasangkan kartu dari kedua tumpukan satu per satu sehingga terbentuk pasangan: suami -> Budi, istri -> Ani, anak -> Coki.

## Poin-Poin Penting
- Array pertama menjadi key, array kedua menjadi value
- Jumlah elemen kedua array harus sama persis
- Jika jumlah elemen tidak sama, menghasilkan `false` dan E_WARNING
- Key harus unique — jika ada duplikat, key terakhir yang menimpa
- Berguna untuk membuat mapping dari dua data terpisah

## Contoh Kode (PHP)
```php
<?php
$keys = ["nama", "umur", "kota"];
$values = ["Budi", 25, "Jakarta"];

$data = array_combine($keys, $values);
print_r($data);
// ["nama" => "Budi", "umur" => 25, "kota" => "Jakarta"]

// ID dan nama dari query terpisah
$ids = [101, 102, 103];
$nama = ["Budi", "Ani", "Coki"];
$mapUser = array_combine($ids, $nama);
print_r($mapUser);
// [101 => "Budi", 102 => "Ani", 103 => "Coki"]

// Jumlah tidak sama -> error
$k = ["a", "b"];
$v = [1, 2, 3];
// $gabung = array_combine($k, $v); // Warning: array_combine(): Both parameters should have an equal number of elements

// Key duplikat
$k2 = ["a", "b", "a"];
$v2 = [1, 2, 3];
$duplikat = array_combine($k2, $v2);
print_r($duplikat); // ["a" => 3, "b" => 2] (a terakhir menimpa)
?>
```

## Kasus Penggunaan Nyata
Membuat mapping kode pos ke nama kota, menggabungkan hasil query database (dua kolom terpisah menjadi key-value pair), atau menyusun data form menjadi array asosiatif.
