# 140. array_fill array_fill_keys

## Definisi Singkat
`array_fill()` mengisi array dengan nilai yang sama sejumlah tertentu. `array_fill_keys()` mengisi array dengan nilai yang sama tetapi menggunakan array tertentu sebagai key-nya.

## Analogi
**array_fill**: Seperti membeli 10 botol air mineral yang sama persis. Anda memesan "10 botol air" dan mendapatkan 10 botol identik dengan isi sama.

**array_fill_keys**: Seperti memberi label pada 5 botol kosong dengan label "A", "B", "C", "D", "E" lalu mengisi semuanya dengan air yang sama. Labelnya berbeda, isinya sama.

## Poin-Poin Penting
- `array_fill(start_index, num, value)`: mengisi `num` elemen mulai dari `start_index`
- `array_fill_keys(keys, value)`: menggunakan array keys sebagai key, value sebagai value
- Berguna untuk inisialisasi array dengan default value
- `start_index` bisa negatif (PHP 8+)

## Contoh Kode (PHP)
```php
<?php
// array_fill: isi dengan 5 elemen "default"
$default = array_fill(0, 5, "default");
print_r($default); // ["default", "default", "default", "default", "default"]

// Mulai dari index tertentu
$mulaiDari = array_fill(3, 4, "item");
print_r($mulaiDari); // [3 => "item", 4 => "item", 5 => "item", 6 => "item"]

// array_fill_keys
$keys = ["nama", "umur", "kota"];
$data = array_fill_keys($keys, "");
print_r($data); // ["nama" => "", "umur" => "", "kota" => ""]

// Inisialisasi skor awal
$pemain = ["Budi", "Ani", "Coki"];
$skor = array_fill_keys($pemain, 0);
print_r($skor); // ["Budi" => 0, "Ani" => 0, "Coki" => 0]

// Default value array
$menu = ["beranda", "profil", "kontak"];
$defaultPage = array_fill_keys($menu, ["aktif" => false, "icon" => "default"]);
print_r($defaultPage);
// ["beranda" => ["aktif" => false, "icon" => "default"], ...]

// array_fill dengan objek (hati-hati: semua referensi ke objek yang sama!)
$obj = (object)["count" => 0];
$filled = array_fill(0, 3, $obj);
$filled[0]->count = 5;
echo $filled[1]->count; // 5 (sama objek!)
?>
```

## Kasus Penggunaan Nyata
Inisialisasi default value untuk form input, menyiapkan array dengan nilai awal sebelum diproses, atau membuat template data untuk batch insert ke database.
