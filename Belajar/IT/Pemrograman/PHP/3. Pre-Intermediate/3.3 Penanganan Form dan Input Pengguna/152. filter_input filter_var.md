# 152. filter_input filter_var

## Definisi Singkat
`filter_input()` dan `filter_var()` adalah fungsi PHP untuk memvalidasi dan membersihkan (sanitasi) data. `filter_input()` mengambil data dari superglobal (GET, POST, COOKIE, SERVER), sedangkan `filter_var()` bekerja pada nilai variabel biasa.

## Analogi
Seperti petugas bea cukai di bandara. Setiap barang (data) yang masuk diperiksa — apakah ini makanan (validasi tipe), apakah perlu dibersihkan (sanitasi). `filter_input` adalah pos pemeriksaan di pintu masuk, `filter_var` adalah pemeriksaan barang yang sudah ada di dalam.

## Poin-Poin Penting
- Filter validasi: memeriksa apakah data memenuhi kriteria (return `true`/`false`)
- Filter sanitasi: membersihkan data (menghapus karakter berbahaya)
- `filter_input(type, name, filter, options)` — ambil dari superglobal
- `filter_var(variable, filter, options)` — filter variabel biasa
- Gunakan filter bawaan, bukan regex manual bila memungkinkan

## Contoh Kode (PHP)
```php
<?php
// filter_input — ambil dan filter data eksternal
$email = filter_input(INPUT_POST, 'email', FILTER_VALIDATE_EMAIL);
if ($email === false) {
    echo "Email tidak valid";
} else {
    echo "Email valid: $email";
}

$umur = filter_input(INPUT_GET, 'umur', FILTER_VALIDATE_INT, [
    'options' => ['min_range' => 1, 'max_range' => 150]
]);

// filter_var — filter variabel biasa
$email2 = "user@example.com";
if (filter_var($email2, FILTER_VALIDATE_EMAIL)) {
    echo "Email valid";
}

// Sanitasi
$nama = filter_input(INPUT_POST, 'nama', FILTER_SANITIZE_STRING);
// PHP 8.1+: FILTER_SANITIZE_STRING deprecated, pakai htmlspecialchars

$angkaKotor = "abc123def456";
$angkasaja = filter_var($angkaKotor, FILTER_SANITIZE_NUMBER_INT);
echo $angkasaja; // 123456

$url = "javascript:alert(1)";
$urlBersih = filter_var($url, FILTER_SANITIZE_URL);

// Filter multiple
$input = [
    'email' => FILTER_VALIDATE_EMAIL,
    'nama'  => FILTER_SANITIZE_SPECIAL_CHARS,
    'umur'  => ['filter' => FILTER_VALIDATE_INT, 'options' => ['min_range' => 1]]
];
$data = filter_input_array(INPUT_POST, $input);
?>
```

## Kasus Penggunaan Nyata
Validasi input dari form secara terstandarisasi, membersihkan input sebelum disimpan ke database, atau memvalidasi parameter URL untuk memastikan tipe data yang benar.
