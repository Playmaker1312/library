# 149. Validasi input dasar

## Definisi Singkat
Validasi input adalah proses memeriksa apakah data yang dimasukkan pengguna memenuhi kriteria tertentu sebelum diproses — seperti memastikan field tidak kosong, format email benar, atau angka dalam rentang tertentu.

## Analogi
Seperti satpam di pintu masuk mall. Satpam memeriksa setiap pengunjung: apakah membawa tas? Apakah berpakaian rapi? Apakah usia cukup? Hanya pengunjung yang lolos pemeriksaan yang diizinkan masuk. Ini mencegah masalah di dalam mall.

## Poin-Poin Penting
- Validasi sisi server adalah WAJIB (client-side bisa dilewati)
- Periksa: required, format, panjang, rentang, uniqueness
- Gunakan `empty()`, `isset()`, `strlen()`, `filter_var()` untuk validasi
- Kumpulkan error messages dalam array
- Jangan percaya input pengguna — selalu validasi!

## Contoh Kode (PHP)
```php
<?php
$errors = [];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nama   = trim($_POST['nama'] ?? '');
    $email  = trim($_POST['email'] ?? '');
    $umur   = $_POST['umur'] ?? '';
    $sandi  = $_POST['sandi'] ?? '';
    
    // Validasi required
    if (empty($nama)) {
        $errors['nama'] = 'Nama harus diisi';
    }
    
    // Validasi format email
    if (empty($email)) {
        $errors['email'] = 'Email harus diisi';
    } elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $errors['email'] = 'Format email tidak valid';
    }
    
    // Validasi numerik dan rentang
    if (empty($umur)) {
        $errors['umur'] = 'Umur harus diisi';
    } elseif (!is_numeric($umur) || $umur < 0 || $umur > 150) {
        $errors['umur'] = 'Umur harus antara 0-150';
    }
    
    // Validasi panjang string
    if (strlen($sandi) < 6) {
        $errors['sandi'] = 'Password minimal 6 karakter';
    }
    
    // Jika tidak ada error, proses data
    if (empty($errors)) {
        // Simpan ke database, kirim email, dll
        $success = "Pendaftaran berhasil!";
    }
}
?>
<!-- Tampilkan error di form -->
<?php if (!empty($errors)): ?>
    <ul>
    <?php foreach ($errors as $error): ?>
        <li><?= htmlspecialchars($error) ?></li>
    <?php endforeach; ?>
    </ul>
<?php endif; ?>
```

## Kasus Penggunaan Nyata
Form registrasi, form kontak, checkout toko online, form upload — semua input pengguna harus divalidasi sebelum diproses untuk mencegah data rusak atau serangan keamanan.
