# 148. GET vs POST Method

## Definisi Singkat
GET dan POST adalah dua metode HTTP utama untuk mengirim data dari form ke server. GET menambahkan data ke URL, POST mengirim dalam body request. Masing-masing punya kegunaan dan batasan berbeda.

## Analogi
**GET**: Seperti menulis pesan di kartu pos — semua orang bisa membaca isinya selama pengiriman. Cocok untuk pesan tidak rahasia yang ingin Anda bagikan.

**POST**: Seperti mengirim surat dalam amplop tertutup — isinya tidak terlihat selama pengiriman. Cocok untuk informasi pribadi atau sensitif.

## Poin-Poin Penting
| Aspek | GET | POST |
|-------|-----|------|
| Visibilitas | Data di URL | Data di body |
| Keamanan | Tidak aman | Lebih aman |
| Batasan panjang | ~2000 karakter | Tidak ada batasan |
| Cache | Bisa di-cache | Tidak di-cache |
| Bookmark | Bisa | Tidak bisa |
| Penggunaan | Pencarian, filter | Login, upload, create |
| Tipe data | Hanya teks | Teks + file (binary) |

## Contoh Kode (PHP)
```php
<?php
// GET: form pencarian
// <form method="get" action="cari.php">
//   <input type="text" name="keyword">
//   <input type="submit" value="Cari">
// </form>
// Hasil: cari.php?keyword=php
$keyword = $_GET['keyword'] ?? '';

// POST: form login
// <form method="post" action="login.php">
//   <input type="text" name="username">
//   <input type="password" name="password">
//   <input type="submit" value="Login">
// </form>
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $username = $_POST['username'] ?? '';
    $password = $_POST['password'] ?? '';
    // Proses login
}

// Deteksi method yang digunakan
$method = $_SERVER['REQUEST_METHOD']; // "GET" atau "POST"

// Satu halaman menerima GET dan POST
if ($method === 'GET') {
    // Tampilkan form
} elseif ($method === 'POST') {
    // Proses form
}
?>
```

## Kasus Penggunaan Nyata
GET untuk halaman publik yang bisa di-bookmark (pencarian, filter, pagination). POST untuk form yang mengubah data (register, login, create, update, delete, upload file).
