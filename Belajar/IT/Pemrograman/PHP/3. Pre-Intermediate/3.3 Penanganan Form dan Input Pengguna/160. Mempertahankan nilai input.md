# 160. Mempertahankan Nilai Input

## Definisi Singkat
Mempertahankan nilai input (sticky form) adalah teknik mengisi ulang nilai form dengan data yang sebelumnya dikirim pengguna, terutama ketika terjadi error validasi — sehingga pengguna tidak perlu mengetik ulang.

## Analogi
Seperti mengisi formulir pendaftaran di bank. Jika Anda lupa mengisi nomor telepon, petugas tidak akan menyuruh Anda mengisi ulang dari awal — mereka mengembalikan formulir yang sudah diisi, hanya menyorot bagian yang kurang. Anda tinggal melengkapi yang kosong.

## Poin-Poin Penting
- Simpan input pengguna ke variabel (biasanya `$old` atau `$input`)
- Setel `value` field dengan data sebelumnya
- Gunakan `htmlspecialchars()` untuk mencegah XSS
- Untuk checkbox/radio, gunakan `in_array()` atau perbandingan untuk set `checked`
- Untuk select/option, set `selected` berdasarkan nilai yang dipilih

## Contoh Kode (PHP)
```php
<?php
$errors = [];
// Simpan input ke variabel old
$old = $_POST;

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nama = trim($_POST['nama'] ?? '');
    $gender = $_POST['gender'] ?? '';
    $hobi = $_POST['hobi'] ?? [];

    if (empty($nama)) {
        $errors['nama'] = 'Nama wajib diisi';
    }
    // ... validasi lainnya
}
?>
<form method="post">
    <!-- Text input -->
    <input type="text" name="nama" 
           value="<?= htmlspecialchars($old['nama'] ?? '') ?>">
    <?php if (isset($errors['nama'])): ?>
        <span><?= $errors['nama'] ?></span>
    <?php endif; ?>

    <!-- Radio button -->
    <input type="radio" name="gender" value="L" 
           <?= ($old['gender'] ?? '') === 'L' ? 'checked' : '' ?>> Laki-laki
    <input type="radio" name="gender" value="P"
           <?= ($old['gender'] ?? '') === 'P' ? 'checked' : '' ?>> Perempuan

    <!-- Checkbox -->
    <input type="checkbox" name="hobi[]" value="membaca"
           <?= in_array('membaca', $old['hobi'] ?? []) ? 'checked' : '' ?>> Membaca
    <input type="checkbox" name="hobi[]" value="olahraga"
           <?= in_array('olahraga', $old['hobi'] ?? []) ? 'checked' : '' ?>> Olahraga

    <!-- Select option -->
    <select name="kota">
        <option value="">Pilih Kota</option>
        <option value="JKT" <?= ($old['kota'] ?? '') === 'JKT' ? 'selected' : '' ?>>Jakarta</option>
        <option value="BDG" <?= ($old['kota'] ?? '') === 'BDG' ? 'selected' : '' ?>>Bandung</option>
        <option value="SBY" <?= ($old['kota'] ?? '') === 'SBY' ? 'selected' : '' ?>>Surabaya</option>
    </select>

    <!-- Textarea -->
    <textarea name="alamat"><?= htmlspecialchars($old['alamat'] ?? '') ?></textarea>

    <button type="submit">Kirim</button>
</form>
```

## Kasus Penggunaan Nyata
Semua jenis form yang memerlukan validasi: form registrasi panjang, form checkout dengan banyak field, form filter/pencarian — agar pengguna tidak frustrasi mengisi ulang data yang sudah benar.
