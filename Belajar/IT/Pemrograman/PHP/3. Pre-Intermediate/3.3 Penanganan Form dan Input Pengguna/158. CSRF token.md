# 158. CSRF token

## Definisi Singkat
CSRF (Cross-Site Request Forgery) token adalah nilai unik dan rahasia yang disisipkan di form dan diverifikasi di server untuk memastikan bahwa request benar-benar berasal dari form aplikasi kita, bukan dari situs jahat lain.

## Analogi
Seperti tanda tangan digital di cek. Bank hanya akan memproses cek jika tanda tangannya cocok dengan sampel yang tersimpan. CSRF token adalah "tanda tangan" yang unik untuk setiap sesi/form — hanya aplikasi kita yang tahu nilainya.

## Poin-Poin Penting
- Token dibuat di server, disimpan di session, dan disisipkan di form
- Setiap request POST harus menyertakan token yang valid
- Token sebaiknya unik per sesi atau per form
- Gunakan `bin2hex(random_bytes(32))` untuk generate token
- Token bisa diregenerasi setiap submit untuk keamanan ekstra

## Contoh Kode (PHP)
```php
<?php
session_start();

// Generate token jika belum ada
if (empty($_SESSION['csrf_token'])) {
    $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
}

// Fungsi untuk menampilkan token di form
function csrfField() {
    $token = $_SESSION['csrf_token'];
    return '<input type="hidden" name="csrf_token" value="' . $token . '">';
}

// Verifikasi token saat form disubmit
function verifyCsrf($token) {
    if (!isset($_SESSION['csrf_token'])) {
        return false;
    }
    return hash_equals($_SESSION['csrf_token'], $token);
}

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $token = $_POST['csrf_token'] ?? '';
    
    if (!verifyCsrf($token)) {
        die("CSRF token tidak valid!");
    }
    
    // Proses form...
    // Regenerasi token setelah submit
    $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
}
?>
<!-- Form dengan CSRF token -->
<form method="post" action="">
    <?= csrfField() ?>
    <input type="text" name="nama">
    <button type="submit">Kirim</button>
</form>
```

## Kasus Penggunaan Nyata
Form login, form transfer bank, form pengaturan akun, form delete data, atau form apa pun yang melakukan tindakan penting — untuk mencegah serangan CSRF dari situs jahat.
