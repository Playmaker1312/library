# 150. htmlspecialchars cegah XSS

## Definisi Singkat
`htmlspecialchars()` mengubah karakter khusus HTML menjadi entitas HTML sehingga tidak dieksekusi sebagai kode oleh browser. Ini adalah pertahanan utama terhadap serangan XSS (Cross-Site Scripting).

## Analogi
Seperti membungkus pisau dengan kardus sebelum dikirim. Pisaunya tetap tajam (data asli), tapi tidak bisa melukai siapa pun saat dalam pengiriman. Karakter `<` dan `>` yang berbahaya "dibungkus" menjadi `&lt;` dan `&gt;` sehingga browser tidak menjalankannya sebagai kode.

## Poin-Poin Penting
- Konversi: `&`, `<`, `>`, `"`, `'` menjadi entitas HTML
- Parameter: `htmlspecialchars(string, flags, encoding, double_encode)`
- Gunakan `ENT_QUOTES` untuk mengkonversi kutip tunggal juga
- Gunakan setiap kali menampilkan data yang berasal dari input pengguna
- Bukan solusi untuk menyimpan data — gunakan untuk output saja

## Contoh Kode (PHP)
```php
<?php
// Input berbahaya dari pengguna
$komentar = "<script>alert('XSS!');</script>";

// Tanpa htmlspecialchars — BERBAHAYA!
// echo $komentar; // Script akan jalan!

// Dengan htmlspecialchars — AMAN
echo htmlspecialchars($komentar, ENT_QUOTES, 'UTF-8');
// Output: &lt;script&gt;alert('XSS!');&lt;/script&gt;

// Penggunaan di form
$nama = $_POST['nama'] ?? '';
// Saat menampilkan kembali nilai di input
?>
<input type="text" name="nama" 
       value="<?= htmlspecialchars($nama, ENT_QUOTES, 'UTF-8') ?>">

<?php
// Data dari database
$artikel = "<p>Halo <b>dunia</b></p>"; // HTML yang sah
// Gunakan htmlspecialchars jika ingin teks polos
echo htmlspecialchars($artikel);
// &lt;p&gt;Halo &lt;b&gt;dunia&lt;/b&gt;&lt;/p&gt;

// Fungsi shortcut
function h($str) {
    return htmlspecialchars($str, ENT_QUOTES, 'UTF-8');
}

echo h($komentar); // Lebih pendek dipanggil
?>
```

## Kasus Penggunaan Nyata
Menampilkan komentar pengguna, menampilkan nilai input form yang dikembalikan, menampilkan data dari database yang berasal dari input pengguna — pada dasarnya setiap output yang mengandung data dari pengguna.
