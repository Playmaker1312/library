# 159. Pesan error form user-friendly

## Definisi Singkat
Pesan error user-friendly adalah notifikasi kesalahan yang jelas, spesifik, dan membantu pengguna memperbaiki input mereka — bukan pesan teknis yang membingungkan.

## Analogi
Seperti petunjuk arah yang baik. "Salah!" (pesan error buruk) vs "Belok kiri di lampu merah, bukan kanan. Setelah lampu merah, Anda akan melihat masjid di sebelah kiri" (pesan error yang membantu). Pengguna langsung tahu apa yang salah dan bagaimana memperbaikinya.

## Poin-Poin Penting
- Spesifik: sebutkan field mana yang salah
- Konstruktif: beri tahu cara memperbaiki
- Bersebelahan: letakkan error di dekat field terkait
- Gunakan bahasa yang ramah, bukan menghakimi
- Jangan ungkapkan informasi sensitif (seperti "password salah" vs "username atau password salah")

## Contoh Kode (PHP)
```php
<?php
$errors = [];
$old = $_POST;

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nama  = trim($_POST['nama'] ?? '');
    $email = trim($_POST['email'] ?? '');
    $umur  = $_POST['umur'] ?? '';

    // Error spesifik dan konstruktif
    if (empty($nama)) {
        $errors['nama'] = 'Nama lengkap wajib diisi';
    } elseif (strlen($nama) < 3) {
        $errors['nama'] = 'Nama minimal 3 karakter';
    }

    if (empty($email)) {
        $errors['email'] = 'Alamat email wajib diisi';
    } elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $errors['email'] = 'Format email tidak valid. Contoh: nama@domain.com';
    }

    if (empty($umur)) {
        $errors['umur'] = 'Umur wajib diisi';
    } elseif (!is_numeric($umur) || $umur < 1 || $umur > 120) {
        $errors['umur'] = 'Umur harus angka antara 1 - 120 tahun';
    }
}
?>
<form method="post">
    <div>
        <label>Nama:</label>
        <input type="text" name="nama" 
               value="<?= htmlspecialchars($old['nama'] ?? '') ?>">
        <?php if (isset($errors['nama'])): ?>
            <span class="error"><?= htmlspecialchars($errors['nama']) ?></span>
        <?php endif; ?>
    </div>

    <div>
        <label>Email:</label>
        <input type="email" name="email"
               value="<?= htmlspecialchars($old['email'] ?? '') ?>">
        <?php if (isset($errors['email'])): ?>
            <span class="error"><?= htmlspecialchars($errors['email']) ?></span>
        <?php endif; ?>
    </div>

    <div>
        <label>Umur:</label>
        <input type="number" name="umur"
               value="<?= htmlspecialchars($old['umur'] ?? '') ?>">
        <?php if (isset($errors['umur'])): ?>
            <span class="error"><?= htmlspecialchars($errors['umur']) ?></span>
        <?php endif; ?>
    </div>

    <button type="submit">Kirim</button>
</form>
```

## Kasus Penggunaan Nyata
Form registrasi dengan arahan password (minimal 8 karakter, harus ada angka), form checkout dengan validasi alamat, atau form login dengan pesan error yang tidak mengungkap apakah username atau password yang salah.
