# 154. Form multiple input checkbox

## Definisi Singkat
Checkbox dengan nama yang sama bisa dikirim sebagai array ke PHP dengan menambahkan tanda kurung `[]` pada atribut `name`, sehingga PHP menerimanya sebagai array.

## Analogi
Seperti daftar pesanan di restoran. Anda bisa mencentang beberapa menu sekaligus: [x] Nasi Goreng, [x] Mie Ayam, [ ] Sate. Semua yang dicentang akan masuk ke nota. Kelompok menu yang dicentang adalah array.

## Poin-Poin Penting
- Gunakan `name="nama[]"` agar PHP menerima sebagai array
- Tanpa `[]`, hanya nilai terakhir yang terkirim
- Di sisi PHP, `$_POST['nama']` adalah array
- Gunakan `isset()` untuk cek checkbox individual jika perlu
- Selalu validasi dan sanitasi nilai yang diterima

## Contoh Kode (PHP)
```php
<?php
// form.html
?>
<form method="post" action="proses.php">
    <input type="checkbox" name="hobi[]" value="membaca"> Membaca
    <input type="checkbox" name="hobi[]" value="menulis"> Menulis
    <input type="checkbox" name="hobi[]" value="olahraga"> Olahraga
    <input type="checkbox" name="hobi[]" value="memasak"> Memasak
    <br>
    <button type="submit">Kirim</button>
</form>

<?php
// proses.php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $hobi = $_POST['hobi'] ?? [];
    
    if (empty($hobi)) {
        echo "Pilih minimal satu hobi";
    } else {
        echo "Hobi yang dipilih: ";
        foreach ($hobi as $h) {
            echo htmlspecialchars($h) . ", ";
        }
        // Simpan: implode(", ", $hobi)
        $hobiString = implode(", ", $hobi);
    }
}

// Cek checkbox tertentu
$hobiDipilih = $_POST['hobi'] ?? [];
$isMembacaChecked = in_array('membaca', $hobiDipilih) ? 'checked' : '';
?>
<!-- Mempertahankan state checkbox -->
<input type="checkbox" name="hobi[]" value="membaca" <?= $isMembacaChecked ?>> Membaca

<?php
// Checkbox boolean (on/off, kirim value saat dicentang)
?>
<input type="checkbox" name="setuju" value="1">
<?php
if (isset($_POST['setuju'])) {
    // Checkbox dicentang
}
?>
```

## Kasus Penggunaan Nyata
Form dengan kategori minat user, filter produk dengan banyak pilihan, pengaturan preferensi (notifikasi email/SMS/push), atau survei dengan pilihan ganda.
