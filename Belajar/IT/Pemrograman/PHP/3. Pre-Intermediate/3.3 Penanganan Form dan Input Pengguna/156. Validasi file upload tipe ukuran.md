# 156. Validasi file upload tipe ukuran

## Definisi Singkat
Validasi file upload memeriksa tipe MIME, ekstensi, dan ukuran file untuk memastikan hanya file yang diizinkan yang bisa diupload, mencegah file berbahaya atau terlalu besar.

## Analogi
Seperti satpam di pintu masuk gedung yang memeriksa KTP setiap pengunjung. Ia memeriksa: apakah ini KTP asli (tipe file valid)? Apakah ukurannya standar? KTP yang rusak atau palsu tidak diizinkan masuk. File berbahaya (ekstensi .exe, .php) ditolak.

## Poin-Poin Penting
- Jangan percaya `$_FILES['type']` (bisa dipalsukan) — gunakan `mime_content_type()` atau `finfo`
- Batasi ukuran dengan `$_FILES['size']` dan konfigurasi `upload_max_filesize` di php.ini
- Cek ekstensi file dengan `pathinfo()`
- Cek kode error: `UPLOAD_ERR_OK`, `UPLOAD_ERR_INI_SIZE`, `UPLOAD_ERR_FORM_SIZE`
- Gunakan whitelist (daftar yang diizinkan), bukan blacklist

## Contoh Kode (PHP)
```php
<?php
$maxSize = 2 * 1024 * 1024; // 2 MB
$allowedTypes = ['image/jpeg', 'image/png', 'image/gif'];
$allowedExt = ['jpg', 'jpeg', 'png', 'gif'];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $file = $_FILES['gambar'] ?? null;
    $errors = [];

    if ($file && $file['error'] === UPLOAD_ERR_OK) {
        // Cek ukuran
        if ($file['size'] > $maxSize) {
            $errors[] = "File terlalu besar. Maksimal 2MB";
        }

        // Cek tipe MIME real (bukan dari header)
        $finfo = finfo_open(FILEINFO_MIME_TYPE);
        $mime = finfo_file($finfo, $file['tmp_name']);
        finfo_close($finfo);

        if (!in_array($mime, $allowedTypes)) {
            $errors[] = "Tipe file $mime tidak diizinkan";
        }

        // Cek ekstensi
        $ext = strtolower(pathinfo($file['name'], PATHINFO_EXTENSION));
        if (!in_array($ext, $allowedExt)) {
            $errors[] = "Ekstensi .$ext tidak diizinkan";
        }

        if (empty($errors)) {
            $namaUnik = uniqid() . "." . $ext;
            // move_uploaded_file($file['tmp_name'], "uploads/" . $namaUnik);
            echo "Upload berhasil!";
        }
    } elseif ($file['error'] === UPLOAD_ERR_INI_SIZE) {
        $errors[] = "File melebihi batas konfigurasi server";
    } elseif ($file['error'] === UPLOAD_ERR_NO_FILE) {
        $errors[] = "Tidak ada file yang diupload";
    }
}

// Cek apakah file benar-benar gambar
function isGambarValid($path) {
    $info = getimagesize($path);
    return $info !== false;
}
?>
```

## Kasus Penggunaan Nyata
Upload profil hanya menerima JPG/PNG maksimal 1MB, upload dokumen hanya PDF maksimal 5MB, upload video dengan batasan format MP4 dan ukuran 50MB.
