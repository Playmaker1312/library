# 147. $_GET menangkap form GET

## Definisi Singkap
`$_GET` adalah superglobal array asosiatif yang menangkap data yang dikirim melalui metode HTTP GET, di mana data ditambahkan ke URL sebagai query string setelah tanda `?`.

## Analogi
Seperti menulis alamat tujuan di amplop transparan. Semua orang bisa membaca apa yang Anda kirim — "Kepada: Budi, Barang: Buku". Data GET terlihat jelas di URL (alamat), jadi tidak cocok untuk informasi rahasia.

## Poin-Poin Penting
- Data GET terlihat di URL: `?nama=Budi&umur=25`
- Terbatas dalam ukuran (sekitar 2000 karakter tergantung browser/server)
- Cocok untuk data tidak sensitif dan parameter pencarian
- Dapat di-bookmark (karena parameter ada di URL)
- Jangan gunakan untuk password atau data sensitif

## Contoh Kode (PHP)
```php
<?php
// URL: http://example.com/profil.php?id=123
$id = $_GET['id'] ?? 0;
echo "Menampilkan profil user ID: " . (int)$id;

// Form dengan method GET
// <form method="get" action="cari.php">
//   <input type="text" name="q">
//   <button type="submit">Cari</button>
// </form>

// cari.php
// URL: cari.php?q=php+tutorial
$query = $_GET['q'] ?? '';
echo "Hasil pencarian untuk: " . htmlspecialchars($query);

// Multiple parameter
// URL: produk.php?kategori=buku&harga_min=10000&harga_max=50000
$kategori = $_GET['kategori'] ?? 'semua';
$min = (int)($_GET['harga_min'] ?? 0);
$max = (int)($_GET['harga_max'] ?? 1000000);

// Pagination
$halaman = (int)($_GET['page'] ?? 1);
$limit = 10;
$offset = ($halaman - 1) * $limit;
?>
```

## Kasus Penggunaan Nyata
Halaman pencarian dengan kata kunci di URL, filter produk (kategori, harga), pagination, atau menampilkan halaman profil berdasarkan ID yang bisa di-bookmark.
