# 153. FILTER_VALIDATE_EMAIL FILTER_VALIDATE_INT

## Definisi Singkat
`FILTER_VALIDATE_EMAIL` memeriksa apakah string memiliki format email yang valid. `FILTER_VALIDATE_INT` memeriksa apakah nilai adalah integer dan bisa dengan opsi rentang tertentu.

## Analogi
**FILTER_VALIDATE_EMAIL**: Seperti petugas pos yang memeriksa amplop — apakah ada "@", apakah ada domain, apakah formatnya sesuai alamat surat. Jika tidak, surat ditolak.

**FILTER_VALIDATE_INT**: Seperti kunci brankas yang hanya menerima angka bulat. Anda tidak bisa memasukkan "tiga" atau 3.14 — hanya angka bulat seperti 3, 42, atau 100 yang lolos.

## Poin-Poin Penting
- Keduanya mengembalikan nilai yang difilter jika valid, `false` jika tidak
- `FILTER_VALIDATE_INT` bisa dikonfigurasi dengan `min_range` dan `max_range`
- `FILTER_VALIDATE_EMAIL` mendukung opsi `FILTER_FLAG_EMAIL_UNICODE`
- Jangan anggap validasi ini 100% sempurna — hanya format, bukan keberadaan
- Gunakan dengan `filter_var()` atau `filter_input()`

## Contoh Kode (PHP)
```php
<?php
// VALIDATE_EMAIL
$email1 = "user@example.com";
$email2 = "bukan-email";
$email3 = "user@";

var_dump(filter_var($email1, FILTER_VALIDATE_EMAIL)); // "user@example.com"
var_dump(filter_var($email2, FILTER_VALIDATE_EMAIL)); // false
var_dump(filter_var($email3, FILTER_VALIDATE_EMAIL)); // false

// Validasi email dari form
$emailInput = $_POST['email'] ?? '';
if (!filter_var($emailInput, FILTER_VALIDATE_EMAIL)) {
    echo "Email tidak valid";
}

// VALIDATE_INT
$int1 = 42;
$int2 = "42";
$int3 = 3.14;
$int4 = "bukan angka";

var_dump(filter_var($int1, FILTER_VALIDATE_INT)); // 42
var_dump(filter_var($int2, FILTER_VALIDATE_INT)); // 42 (string numeric)
var_dump(filter_var($int3, FILTER_VALIDATE_INT)); // false (float)
var_dump(filter_var($int4, FILTER_VALIDATE_INT)); // false

// Dengan opsi min/max
$options = [
    'options' => [
        'min_range' => 0,
        'max_range' => 120
    ]
];

$umur = filter_input(INPUT_POST, 'umur', FILTER_VALIDATE_INT, $options);
if ($umur === false) {
    echo "Umur harus angka antara 0-120";
}

// Bool: filter_var(true, FILTER_VALIDATE_INT) // false
// Hex: filter_var("0x1A", FILTER_VALIDATE_INT) // false (string)
?>
```

## Kasus Penggunaan Nyata
Memvalidasi alamat email di form registrasi, memastikan input umur/kuantitas adalah integer dalam rentang wajar, atau memfilter parameter ID dari URL agar hanya menerima angka.
