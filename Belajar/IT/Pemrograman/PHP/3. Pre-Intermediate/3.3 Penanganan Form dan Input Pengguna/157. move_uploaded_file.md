# 157. move_uploaded_file

## Definisi Singkat
`move_uploaded_file()` memindahkan file yang diupload dari lokasi temporary (biasanya di `/tmp/`) ke lokasi permanen yang Anda tentukan. Fungsi ini juga melakukan pemeriksaan keamanan untuk memastikan file benar-benar hasil upload.

## Analogi
Seperti Anda mengambil paket dari loker sementara di apartemen (tmp_name) dan membawanya ke dalam unit apartemen Anda (tujuan permanen). Petugas akan memverifikasi bahwa paket itu benar-benar milik Anda (hasil upload) sebelum mengizinkan Anda membawanya.

## Poin-Poin Penting
- Parameter: `move_uploaded_file(from, to)`
- Hanya bisa memindahkan file yang benar-benar diupload (aman)
- Mengembalikan `true` jika berhasil, `false` jika gagal
- Direktori tujuan harus sudah ada dan writable
- Nama file tujuan sebaiknya di-unique-kan untuk menghindari tabrakan

## Contoh Kode (PHP)
```php
<?php
$uploadDir = __DIR__ . "/uploads/";

// Pastikan direktori tujuan ada
if (!is_dir($uploadDir)) {
    mkdir($uploadDir, 0755, true);
}

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $file = $_FILES['foto'] ?? null;

    if ($file && $file['error'] === UPLOAD_ERR_OK) {
        $ext = strtolower(pathinfo($file['name'], PATHINFO_EXTENSION));
        
        // Nama file unik untuk menghindari tabrakan
        $namaUnik = date('Ymd_His') . '_' . uniqid() . '.' . $ext;
        $tujuan = $uploadDir . $namaUnik;

        if (move_uploaded_file($file['tmp_name'], $tujuan)) {
            echo "File berhasil diupload ke: " . $tujuan;
            // Simpan path ke database: "uploads/" . $namaUnik
        } else {
            echo "Gagal memindahkan file";
        }
    }
}

// Contoh dengan path relatif (berbahaya!)
function uploadAman($file, $tujuanFolder) {
    // Pastikan path aman — hindari path traversal
    $namaAsli = basename($file['name']); // hapus path traversal
    $tujuan = rtrim($tujuanFolder, '/') . '/' . uniqid() . '_' . $namaAsli;
    
    if (move_uploaded_file($file['tmp_name'], $tujuan)) {
        return $tujuan;
    }
    return false;
}
?>
```

## Kasus Penggunaan Nyata
Memindahkan foto profil, dokumen, gambar produk, atau file lampiran apa pun dari folder temporary server ke folder penyimpanan permanen setelah validasi berhasil.
