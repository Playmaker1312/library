# 146. $_POST menangkap form POST

## Definisi Singkat
`$_POST` adalah superglobal array asosiatif di PHP yang menangkap data yang dikirim melalui metode HTTP POST, biasanya dari form HTML dengan atribut `method="post"`.

## Analogi
Seperti kotak surat pribadi yang hanya bisa dibuka oleh pemilik rumah. Orang lain bisa memasukkan surat (data form POST) ke dalamnya, dan hanya penerima yang bisa mengambil dan membaca isinya. Data tidak terlihat di URL.

## Poin-Poin Penting
- Data POST dikirim dalam body HTTP, tidak terlihat di URL
- Aman untuk data sensitif (password, data pribadi)
- Tidak ada batasan panjang data (tidak seperti GET)
- Mengakses data: `$_POST['nama_field']`
- Selalu lakukan validasi dan sanitasi sebelum menggunakan data POST

## Contoh Kode (PHP)
```php
<?php
// form.html (file terpisah)
?>
<!--
<form method="post" action="proses.php">
    <input type="text" name="nama" required>
    <input type="email" name="email" required>
    <button type="submit">Kirim</button>
</form>
-->

<?php
// proses.php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nama  = $_POST['nama'] ?? '';
    $email = $_POST['email'] ?? '';
    
    echo "Nama: " . htmlspecialchars($nama) . "<br>";
    echo "Email: " . htmlspecialchars($email) . "<br>";
}

// Cek apakah field tertentu ada
if (isset($_POST['submit'])) {
    // Form sudah disubmit
    $pesan = $_POST['pesan'] ?? '';
}

// Multiple field dengan nama yang sama (array)
// <input type="checkbox" name="hobi[]" value="membaca">
$hobi = $_POST['hobi'] ?? []; // array
?>
```

## Kasus Penggunaan Nyata
Menangkap data login, pendaftaran user, form kontak, input data ke database, atau form apa pun yang mengirim data sensitif atau berukuran besar.
