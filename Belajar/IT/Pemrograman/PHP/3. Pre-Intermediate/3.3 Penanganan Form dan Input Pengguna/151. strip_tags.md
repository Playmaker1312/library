# 151. strip_tags

## Definisi Singkat
`strip_tags()` menghapus semua tag HTML (dan PHP) dari string, hanya menyisakan teks polos. Dapat dikonfigurasi untuk mengizinkan tag tertentu tetap ada.

## Analogi
Seperti menyaring sayuran. Anda mengambil sayuran dari kebun (string dengan HTML), lalu mencucinya dan memotong bagian yang tidak diinginkan (tag). Yang tersisa hanyalah bagian yang bisa dimakan (teks polos). Tapi Anda bisa memilih untuk mempertahankan beberapa daun yang bagus (tag yang diizinkan).

## Poin-Poin Penting
- Menghapus tag HTML dan PHP dari string
- Parameter kedua: tag yang diizinkan tetap ada
- Tidak mencegah XSS sepenuhnya (atribut berbahaya tetap ada di tag yang diizinkan)
- Berguna untuk membersihkan input sebelum disimpan
- Lebih agresif daripada `htmlspecialchars`

## Contoh Kode (PHP)
```php
<?php
$teksKotor = "<p>Halo <b>Budi</b>, selamat <script>alert('jahat')</script> datang!</p>";

// Hapus semua tag
$bersih = strip_tags($teksKotor);
echo $bersih; // "Halo Budi, selamat  datang!"

// Izinkan tag tertentu
$denganBold = strip_tags($teksKotor, "<b><i>");
echo $denganBold; // "Halo <b>Budi</b>, selamat  datang!"

// Membersihkan input dari form komentar
$komentar = $_POST['komentar'] ?? '';
$komentarBersih = strip_tags($komentar, "<a><b><i>");

// strip_tags vs htmlspecialchars
$input = "<b>teks</b> & <script>x()</script>";

echo strip_tags($input);
// "teks & x()"

echo htmlspecialchars($input, ENT_QUOTES, 'UTF-8');
// "&lt;b&gt;teks&lt;/b&gt; &amp; &lt;script&gt;x()&lt;/script&gt;"

// Peringatan: tag yang diizinkan tetap bisa berbahaya
$jahat = "<a href='javascript:alert(1)'>Klik</a>";
echo strip_tags($jahat, "<a>"); // Masih berbahaya! Gunakan htmlspecialchars juga
?>
```

## Kasus Penggunaan Nyata
Membersihkan input dari editor WYSIWYG yang hanya mengizinkan formatting dasar, menyimpan teks murni ke database untuk pencarian, atau menampilkan cuplikan/preview artikel tanpa HTML.
