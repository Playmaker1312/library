# 155. File upload $_FILES

## Definisi Singkat
`$_FILES` adalah superglobal array asosiatif yang berisi informasi file yang diunggah melalui form dengan `enctype="multipart/form-data"`.

## Analogi
Seperti meja check-in bagasi di bandara. Penumpang meletakkan koper (file) di meja (form) yang sudah disediakan. Petugas menimbang, memeriksa, dan mencatat detail koper (nama file, ukuran, tipe) di sistem — itulah `$_FILES`.

## Poin-Poin Penting
- Form harus memiliki `enctype="multipart/form-data"` dan `method="post"`
- `$_FILES['file']['name']` — nama asli file
- `$_FILES['file']['type']` — tipe MIME file
- `$_FILES['file']['size']` — ukuran dalam bytes
- `$_FILES['file']['tmp_name']` — lokasi temporary file
- `$_FILES['file']['error']` — kode error upload

## Contoh Kode (PHP)
```php
<?php
// form.html
?>
<form method="post" action="upload.php" enctype="multipart/form-data">
    <input type="file" name="dokumen">
    <button type="submit">Upload</button>
</form>

<?php
// upload.php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $file = $_FILES['dokumen'] ?? null;
    
    if ($file && $file['error'] === UPLOAD_ERR_OK) {
        echo "Nama file: " . $file['name'] . "<br>";
        echo "Tipe: " . $file['type'] . "<br>";
        echo "Ukuran: " . $file['size'] . " bytes<br>";
        echo "Lokasi temp: " . $file['tmp_name'] . "<br>";
        
        // Pindahkan file dari temporary ke folder permanen
        $tujuan = "uploads/" . basename($file['name']);
        // move_uploaded_file($file['tmp_name'], $tujuan);
    } else {
        // Tangani error upload
        $kodeError = $file['error'] ?? UPLOAD_ERR_NO_FILE;
        echo "Error upload: $kodeError";
    }
}

// Multiple file upload
// <input type="file" name="galeri[]" multiple>
$files = $_FILES['galeri'];
// $files['name'][0], $files['tmp_name'][0], dll
?>
```
