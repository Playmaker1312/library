# 176. Konfigurasi session lifetime

## Definisi Singkat
Session lifetime adalah periode waktu suatu session dianggap valid sebelum kedaluwarsa. Bisa dikonfigurasi melalui php.ini, file `.htaccess`, atau fungsi `ini_set()` dan `session_set_cookie_params()`.

## Analogi
Seperti tiket masuk taman bermain. Tiket (session) memiliki masa berlaku — bisa 1 jam, 1 hari, atau 1 bulan. Setelah masa berlaku habis, tiket tidak bisa digunakan lagi dan Anda harus membeli tiket baru (session baru).

## Poin-Poin Penting
- `session.gc_maxlifetime` — umur data session di server (dalam detik)
- `session.cookie_lifetime` — umur cookie session di browser (0 = sampai browser ditutup)
- `session.gc_probability` dan `session.gc_divisor` — frekuensi garbage collection
- Atur dengan `ini_set()` sebelum `session_start()`
- `session_set_cookie_params()` untuk mengatur cookie session

## Contoh Kode (PHP)
```php
<?php
// Konfigurasi session lifetime sebelum session_start()

// Session di server: 1 jam
ini_set('session.gc_maxlifetime', 3600);

// Cookie session di browser: 7 hari (dalam detik)
ini_set('session.cookie_lifetime', 7 * 24 * 3600);

// Atau dengan session_set_cookie_params
session_set_cookie_params([
    'lifetime' => 7 * 24 * 3600, // 7 hari
    'path' => '/',
    'domain' => '',
    'secure' => isset($_SERVER['HTTPS']),
    'httponly' => true,
    'samesite' => 'Strict'
]);

session_start();

// Cek session timeout (last activity)
$timeout = 1800; // 30 menit
if (isset($_SESSION['last_activity']) && 
    (time() - $_SESSION['last_activity']) > $timeout) {
    // Session expired karena tidak ada aktivitas
    $_SESSION = [];
    session_destroy();
    session_start();
    $_SESSION['flash'] = ['type' => 'warning', 'message' => 'Session habis, silakan login ulang'];
}

$_SESSION['last_activity'] = time();

// Untuk aplikasi kritis (banking, admin), set timeout lebih pendek
function setSessionTimeout($menit = 15) {
    ini_set('session.gc_maxlifetime', $menit * 60);
    session_set_cookie_params(['lifetime' => $menit * 60]);
    session_start();
    
    if (isset($_SESSION['last_activity']) && 
        (time() - $_SESSION['last_activity']) > ($menit * 60)) {
        session_destroy();
        header('Location: login.php?expired=1');
        exit;
    }
    $_SESSION['last_activity'] = time();
}
?>
```

## Kasus Penggunaan Nyata
Aplikasi perbankan dengan session timeout 5 menit, toko online dengan session 1 jam, atau aplikasi "ingat saya" yang memperpanjang session hingga 30 hari.
