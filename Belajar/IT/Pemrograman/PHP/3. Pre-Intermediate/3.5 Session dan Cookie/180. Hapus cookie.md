# 180. Hapus cookie

## Definisi Singkat
Cookie dihapus dengan mengatur nilai waktu kedaluwarsa (expire) ke masa lalu menggunakan `setcookie()` dengan nama yang sama. Ini memberi tahu browser untuk menghapus cookie tersebut.

## Analogi
Seperti memberikan kartu anggota yang sudah kedaluwarsa ke mesin penghancur. Kartu itu tidak bisa digunakan lagi — sudah tidak valid. Untuk menghapus cookie, Anda "menghancurkannya" dengan mengatur tanggal berlakunya ke masa lalu.

## Poin-Poin Penting
- Set `expire` ke waktu di masa lalu: `time() - 3600`
- Gunakan parameter path, domain, secure, httponly yang SAMA seperti saat membuat
- Cookie tidak langsung hilang dari `$_COOKIE` — akan hilang di request berikutnya
- Untuk memastikan terhapus, set nilai ke string kosong
- Jika cookie dibuat dengan parameter spesifik, hapus dengan parameter yang sama

## Contoh Kode (PHP)
```php
<?php
// Hapus cookie sederhana
setcookie('theme', '', time() - 3600);

// Hapus cookie dengan parameter lengkap
setcookie('preferensi_bahasa', '', [
    'expires' => time() - 3600,
    'path' => '/',
    'domain' => '',
    'secure' => false,
    'httponly' => false
]);

// Fungsi hapus cookie reusable
function hapusCookie($name, $path = '/', $domain = '') {
    if (isset($_COOKIE[$name])) {
        setcookie($name, '', [
            'expires' => time() - 3600,
            'path' => $path,
            'domain' => $domain,
            'secure' => isset($_SERVER['HTTPS']),
            'httponly' => true
        ]);
        unset($_COOKIE[$name]); // Hapus dari array saat ini juga
    }
}

// Hapus semua cookie
function hapusSemuaCookie() {
    foreach ($_COOKIE as $name => $value) {
        hapusCookie($name);
    }
}

// Hapus cookie tertentu
if (isset($_GET['hapus_cookie'])) {
    hapusCookie($_GET['hapus_cookie']);
    header('Location: ' . $_SERVER['PHP_SELF']);
    exit;
}

// Logout: hapus cookie remember me
function logoutHapusCookie() {
    hapusCookie('remember_token');
    hapusCookie('user_id');
    hapusCookie(session_name()); // Hapus cookie session
    session_destroy();
}

// Contoh penggunaan
hapusCookie('theme');
echo isset($_COOKIE['theme']) ? 'Masih ada' : 'Terhapus';
// Masih akan 'Masih ada' di halaman ini, hilang di request berikutnya
?>
```

## Kasus Penggunaan Nyata
Fitur logout yang menghapus cookie remember me, menghapus preferensi yang sudah tidak diperlukan, atau membersihkan semua cookie saat pengguna menonaktifkan akun.
