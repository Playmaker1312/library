# 175. session_destroy

## Definisi Singkat
`session_destroy()` menghapus seluruh data session dari server dan mengakhiri sesi. Setelah dipanggil, session ID dan data session tidak lagi valid. Biasanya digunakan saat logout.

## Analogi
Seperti menutup rekening bank. Petugas bank menghapus semua data rekening Anda — saldo, riwayat transaksi, semuanya hilang. Kartu ATM (session ID) juga tidak akan berfungsi lagi. Jika ingin bertransaksi lagi, Anda harus buka rekening baru (session baru).

## Poin-Poin Penting
- Menghapus semua data session dari penyimpanan server
- Session ID cookie tetap ada di browser (tapi tidak valid lagi)
- Biasanya dipanggil setelah `$_SESSION = []` dan `session_regenerate_id(true)`
- Jangan lupa panggil `session_start()` dulu sebelum `session_destroy()`
- Setelah destroy, data tidak bisa dipulihkan

## Contoh Kode (PHP)
```php
<?php
// Logout: menghapus session sepenuhnya
function logout() {
    // Mulai session (jika belum)
    if (session_status() === PHP_SESSION_NONE) {
        session_start();
    }
    
    // 1. Kosongkan data session
    $_SESSION = [];
    
    // 2. Hapus cookie session di browser
    if (ini_get("session.use_cookies")) {
        $params = session_get_cookie_params();
        setcookie(session_name(), '', time() - 42000,
            $params["path"], $params["domain"],
            $params["secure"], $params["httponly"]
        );
    }
    
    // 3. Hancurkan session di server
    session_destroy();
}

// Halaman logout
if (isset($_GET['logout'])) {
    logout();
    header('Location: login.php?msg=logged_out');
    exit;
}

// Contoh dengan session_regenerate_id
function logoutAman() {
    session_start();
    $_SESSION = [];
    
    // Regenerasi ID sebelum destroy (best practice)
    session_regenerate_id(true);
    session_destroy();
}

// Cek session setelah destroy
session_start(); // Mulai baru
session_destroy();
echo $_SESSION['key'] ?? 'Session sudah dihapus'; // Session sudah dihapus

// session_destroy tidak menghapus $_SESSION array saat ini
// $_SESSION masih bisa diakses sampai script selesai
?>
```

## Kasus Penggunaan Nyata
Fitur logout pengguna yang membersihkan semua data sesi, reset aplikasi, atau ketika pengguna menonaktifkan akun mereka.
