# 173. Membaca data session

## Definisi Singkat
Membaca data dari session dilakukan dengan mengakses `$_SESSION['key']` setelah `session_start()` dipanggil. Jika key tidak ada, akan menghasilkan notice — gunakan `isset()` atau `??` untuk aman.

## Analogi
Seperti membuka loker dan memeriksa isinya. Anda mengambil barang-barang dari loker untuk digunakan. Sebelum mengambil, Anda perlu mengecek apakah barangnya ada — bisa dengan melihat (isset) atau menyiapkan alternatif jika kosong.

## Poin-Poin Penting
- Selalu panggil `session_start()` sebelum membaca
- Gunakan `isset($_SESSION['key'])` untuk cek keberadaan
- Gunakan null coalescing: `$_SESSION['key'] ?? default`
- Data session bisa dibaca di halaman mana pun setelah `session_start()`
- Session bersifat private per pengguna (tidak bisa baca session orang lain)

## Contoh Kode (PHP)
```php
<?php
session_start();

// Membaca dengan null coalescing (aman)
$username = $_SESSION['username'] ?? 'Tamu';
$role = $_SESSION['role'] ?? 'guest';

echo "Selamat datang, $username!";
echo "Role Anda: $role";

// Cek dengan isset
if (isset($_SESSION['user_id'])) {
    $userId = $_SESSION['user_id'];
    // Lanjutkan dengan data user
} else {
    header('Location: login.php');
    exit;
}

// Membaca array dari session
$cart = $_SESSION['cart'] ?? [];
foreach ($cart as $item) {
    echo $item['nama'] . ' x ' . $item['qty'] . '<br>';
}

// Flash message (baca lalu hapus)
if (isset($_SESSION['flash'])) {
    $flash = $_SESSION['flash'];
    unset($_SESSION['flash']); // Hapus setelah dibaca
    echo "<div class='{$flash['type']}'>{$flash['message']}</div>";
}

// Cek login status
function isLoggedIn(): bool {
    return isset($_SESSION['user_id']);
}

function isAdmin(): bool {
    return ($_SESSION['role'] ?? '') === 'admin';
}

function requireLogin() {
    if (!isLoggedIn()) {
        $_SESSION['flash'] = [
            'type' => 'error',
            'message' => 'Silakan login terlebih dahulu'
        ];
        header('Location: login.php');
        exit;
    }
}
?>
```

## Kasus Penggunaan Nyata
Setiap halaman yang membutuhkan data sesi — menampilkan username di navbar, memeriksa role untuk akses halaman admin, membaca keranjang belanja, atau menampilkan flash messages.
