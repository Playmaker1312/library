# 178. session_regenerate_id

## Definisi Singkat
`session_regenerate_id()` mengganti session ID saat ini dengan yang baru tanpa mengubah data session. Parameter `true` akan menghapus session ID lama. Ini adalah pertahanan utama terhadap session fixation.

## Analogi
Seperti mengganti kunci loker setelah Anda memasukkan barang berharga. Anda mendapatkan kunci baru, tapi barang di loker tetap sama. Kunci lama yang mungkin sudah disalin orang lain tidak berguna lagi.

## Poin-Poin Penting
- Panggil setelah login sukses (wajib!)
- Parameter `delete_old_session` (default `false`) — set `true` untuk hapus session lama
- Data session tetap utuh, hanya ID yang berubah
- Regenerasi periodik juga disarankan (setiap 30-60 menit)
- Mencegah session fixation dan mengurangi risiko session hijacking

## Contoh Kode (PHP)
```php
<?php
session_start();

// 1. Regenerasi setelah login
if ($loginBerhasil) {
    session_regenerate_id(true); // Hapus session lama
    $_SESSION['user_id'] = $userId;
    $_SESSION['username'] = $username;
}

// 2. Regenerasi periodik (setiap 30 menit)
$interval = 1800; // 30 menit dalam detik
if (!isset($_SESSION['last_regenerate'])) {
    $_SESSION['last_regenerate'] = time();
} elseif (time() - $_SESSION['last_regenerate'] > $interval) {
    session_regenerate_id(true);
    $_SESSION['last_regenerate'] = time();
}

// 3. Regenerasi pada logout
function logout() {
    $_SESSION = [];
    session_regenerate_id(true);
    session_destroy();
    
    // Hapus cookie
    setcookie(session_name(), '', time() - 3600, '/');
}

// 4. Regenerasi untuk perubahan privilege
function upgradeRole($newRole) {
    session_regenerate_id(true);
    $_SESSION['role'] = $newRole;
}

// 5. Regenerasi untuk form penting
function sebelumProsesPembayaran() {
    session_regenerate_id(true);
    // Lanjutkan proses pembayaran
}

// Monitoring regenerasi
if (!isset($_SESSION['sid_history'])) {
    $_SESSION['sid_history'] = [];
}
$_SESSION['sid_history'][] = [
    'old_id' => session_id(), // ID sebelum regenerasi
    'time' => date('Y-m-d H:i:s')
];
session_regenerate_id(true);
echo "Session ID baru: " . session_id();
?>
```

## Kasus Penggunaan Nyata
Setelah login pengguna, setelah perubahan password, setelah perubahan role/privilege, setelah melakukan pembayaran, atau secara periodik untuk aplikasi yang membutuhkan keamanan tinggi.
