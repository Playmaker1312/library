# 171. session_start

## Definisi Singkat
`session_start()` memulai sesi baru atau melanjutkan sesi yang sudah ada berdasarkan session ID yang dikirim browser melalui cookie atau URL. Harus dipanggil sebelum output apapun.

## Analogi
Seperti membuka loker di stasiun. Pertama kali, petugas memberi Anda kunci dengan nomor unik (session ID) dan membukakan loker kosong (session baru). Kunjungan berikutnya, Anda datang membawa kunci yang sama — petugas membukakan loker yang sama (session dilanjutkan).

## Poin-Poin Penting
- Harus dipanggil di awal script (sebelum output HTML atau echo)
- PHP akan mengirim cookie session ID ke browser
- Jika session ID tidak ada, PHP membuat session baru
- Gunakan `session_status()` untuk cek apakah session sudah aktif
- Konfigurasi session diatur di `php.ini` atau dengan `session_set_cookie_params()`

## Contoh Kode (PHP)
```php
<?php
// session_start() HARUS sebelum output
session_start();

// Cek status session
if (session_status() === PHP_SESSION_ACTIVE) {
    echo "Session aktif<br>";
}

// Session ID unik untuk pengguna ini
echo "Session ID: " . session_id();

// Data session
$_SESSION['nama'] = 'Budi';
$_SESSION['waktu'] = time();

// Di halaman lain, panggil session_start() lagi
// session_start();
// echo $_SESSION['nama']; // Budi

// Konfigurasi cookie session sebelum session_start()
// session_set_cookie_params([
//     'lifetime' => 3600,
//     'path' => '/',
//     'domain' => 'example.com',
//     'secure' => true,
//     'httponly' => true,
//     'samesite' => 'Strict'
// ]);
// session_start();

// Cek apakah ini session baru
if (!isset($_SESSION['initiated'])) {
    $_SESSION['initiated'] = true;
    echo "Session baru dibuat";
} else {
    echo "Session dilanjutkan";
}
?>
```

## Kasus Penggunaan Nyata
Setiap halaman yang membutuhkan autentikasi, keranjang belanja, atau data sesi harus memanggil `session_start()` sebelum memproses data — biasanya di file konfigurasi utama atau bootstrap.
