# 179. setcookie

## Definisi Singkat
`setcookie()` mengirimkan cookie ke browser. Cookie adalah data kecil yang disimpan di browser dan dikirim kembali ke server pada setiap request. Fungsi ini harus dipanggil SEBELUM output HTML.

## Analogi
Seperti memberikan stiker loyalitas ke pelanggan. Pelanggan menempel stiker itu di dompet mereka (browser). Setiap kali mereka datang, mereka menunjukkan stikernya (cookie dikirim ke server) dan Anda bisa memberikan diskon berdasarkan informasi di stiker.

## Poin-Poin Penting
- Parameter: `setcookie(name, value, expire, path, domain, secure, httponly)`
- `expire`: waktu kedaluwarsa dalam Unix timestamp (`time() + detik`)
- Cookie hanya bisa berisi string — encode array dengan `serialize()` atau `json_encode()`
- Cookie harus diset sebelum output (sama seperti session)
- Nilai cookie bisa dibaca dengan `$_COOKIE['name']`

## Contoh Kode (PHP)
```php
<?php
// Cookie sederhana (bertahan sampai browser ditutup)
setcookie('theme', 'dark');

// Cookie dengan masa berlaku (30 hari)
setcookie('preferensi_bahasa', 'id', time() + 3600 * 24 * 30);

// Cookie dengan path tertentu (hanya untuk /blog/)
setcookie('blog_view', 'list', time() + 3600, '/blog/');

// Cookie aman (HTTPS only + httponly)
setcookie('token', 'abc123', [
    'expires' => time() + 3600 * 24,
    'path' => '/',
    'domain' => 'example.com',
    'secure' => true,
    'httponly' => true,
    'samesite' => 'Strict'
]);

// Cookie array (gunakan json)
$userPrefs = ['font_size' => 14, 'color' => 'blue'];
setcookie('prefs', json_encode($userPrefs), time() + 3600 * 24 * 30);

// Membaca cookie
$theme = $_COOKIE['theme'] ?? 'light';
echo "Theme: " . $theme;

// Decode cookie array
$prefs = json_decode($_COOKIE['prefs'] ?? '{}', true);
echo "Font: " . ($prefs['font_size'] ?? 16);

// Hapus cookie (set masa lalu)
setcookie('temp_data', '', time() - 3600);

// Cek apakah cookie berhasil diset
// Tidak ada return value langsung — tapi cookie akan tersedia di request berikutnya
?>
```

## Kasus Penggunaan Nyata
Menyimpan preferensi tema (gelap/terang), remember me token (login otomatis), menyimpan bahasa pilihan, tracking kunjungan, atau menyimpan item keranjang untuk pengguna yang belum login.
