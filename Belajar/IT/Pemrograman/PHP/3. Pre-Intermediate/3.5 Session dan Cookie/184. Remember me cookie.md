# 184. Remember me cookie

## Definisi Singkat
"Remember me" adalah fitur yang menggunakan cookie untuk menyimpan token autentikasi jangka panjang, sehingga pengguna tidak perlu login setiap kali mengunjungi situs — bahkan setelah browser ditutup.

## Analogi
Seperti kartu anggota VIP di hotel. Begitu Anda check-in (login), Anda diberi kartu yang bisa digunakan selama 1 tahun. Setiap kali Anda datang ke hotel (mengunjungi situs), Anda tinggal menunjukkan kartu itu — tidak perlu isi formulir lagi. Tapi jika kartu hilang, Anda harus daftar ulang.

## Poin-Poin Penting
- JANGAN simpan password di cookie! Simpan token acak (hash)
- Token disimpan di cookie dan di database (dihash)
- Gunakan `random_bytes()` atau `bin2hex(openssl_random_pseudo_bytes())`
- Set cookie dengan `httponly`, `secure`, dan `samesite`
- Token sebaiknya memiliki masa berlaku (expire)
- Sediakan opsi "remember me" checkbox di form login

## Contoh Kode (PHP)
```php
<?php
session_start();

// Simulasi database token
$tokenStorage = []; // Dalam realita: tabel remember_tokens

if ($_SERVER['REQUEST_METHOD'] === 'POST' && isset($_POST['login'])) {
    $username = $_POST['username'] ?? '';
    $password = $_POST['password'] ?? '';
    $remember = isset($_POST['remember']);
    
    // Validasi login...
    if ($username === 'budi' && $password === 'rahasia') {
        session_regenerate_id(true);
        $_SESSION['user_id'] = $username;
        
        if ($remember) {
            // Buat token acak
            $token = bin2hex(random_bytes(32));
            $selector = bin2hex(random_bytes(8));
            
            // Simpan hash token di database (simulasi)
            $tokenStorage[$selector] = [
                'token_hash' => hash('sha256', $token),
                'username' => $username,
                'expires' => time() + 30 * 24 * 3600 // 30 hari
            ];
            
            // Set cookie di browser (2 cookie: selector + token)
            setcookie('remember_selector', $selector, [
                'expires' => time() + 30 * 86400,
                'path' => '/',
                'secure' => isset($_SERVER['HTTPS']),
                'httponly' => true,
                'samesite' => 'Strict'
            ]);
            
            setcookie('remember_token', $token, [
                'expires' => time() + 30 * 86400,
                'path' => '/',
                'secure' => isset($_SERVER['HTTPS']),
                'httponly' => true,
                'samesite' => 'Strict'
            ]);
        }
        
        header('Location: dashboard.php');
        exit;
    }
}

// Auto-login via remember me cookie
if (!isset($_SESSION['user_id']) && isset($_COOKIE['remember_selector'])) {
    $selector = $_COOKIE['remember_selector'];
    $token = $_COOKIE['remember_token'];
    
    if (isset($tokenStorage[$selector])) {
        $data = $tokenStorage[$selector];
        if (hash('sha256', $token) === $data['token_hash'] && $data['expires'] > time()) {
            session_regenerate_id(true);
            $_SESSION['user_id'] = $data['username'];
        }
    }
}

// Hapus remember me cookie saat logout
function logout() {
    $_SESSION = [];
    session_destroy();
    setcookie('remember_selector', '', time() - 3600, '/');
    setcookie('remember_token', '', time() - 3600, '/');
}
?>
<form method="post">
    <input type="text" name="username" required>
    <input type="password" name="password" required>
    <label><input type="checkbox" name="remember"> Ingat saya</label>
    <button type="submit" name="login">Login</button>
</form>
```

## Kasus Penggunaan Nyata
Situs web yang ingin memberikan kenyamanan login otomatis — e-commerce, media sosial, forum, email, atau aplikasi SaaS — di mana pengguna tidak ingin login setiap hari.
