# 181. Atribut cookie expires path domain secure httponly

## Definisi Singkat
Atribut cookie mengontrol masa berlaku, jangkauan akses, dan keamanan cookie: `expires` (waktu kedaluwarsa), `path` (URL path), `domain` (domain), `secure` (HTTPS only), `httponly` (tidak bisa diakses JavaScript), `samesite` (cegah CSRF).

## Analogi
Seperti kartu akses gedung. Kartu ini punya aturan: berlaku sampai 31 Desember (expires), hanya untuk pintu utama (path), hanya untuk kantor pusat di Jakarta (domain), hanya bisa digunakan jam kantor (secure), dan tidak bisa difoto (httponly).

## Poin-Poin Penting
- `expires`: Unix timestamp saat cookie kedaluwarsa. 0 = sampai browser ditutup
- `path`: Path URL di mana cookie tersedia. `'/'` = seluruh domain
- `domain`: Domain tempat cookie bisa diakses. Kosong = domain saat ini
- `secure`: Cookie hanya dikirim melalui HTTPS
- `httponly`: Cookie tidak bisa diakses JavaScript (cegah XSS)
- `samesite`: Strict/Lax/None — cegah pengiriman cookie dari situs lain

## Contoh Kode (PHP)
```php
<?php
// Cara lama (parameter terpisah)
setcookie('nama', 'Budi', time() + 3600, '/', '', true, true);

// Cara baru (PHP 7.3+) — array lebih jelas
setcookie('preferensi', 'dark', [
    'expires'  => time() + 30 * 24 * 3600, // 30 hari
    'path'     => '/',
    'domain'   => 'example.com',    // hanya untuk example.com (bukan subdomain)
    'secure'   => true,             // hanya HTTPS
    'httponly' => true,             // tidak bisa diakses JS
    'samesite' => 'Strict'          // Strict atau Lax
]);

// Atribut untuk session cookie
session_set_cookie_params([
    'lifetime' => 0,        // sampai browser ditutup
    'path'     => '/',
    'domain'   => '',
    'secure'   => true,     // hanya HTTPS di production
    'httponly' => true,
    'samesite' => 'Lax'
]);
session_start();

// Penjelasan samesite
// 'Strict': cookie tidak dikirim sama sekali dari situs lain (paling aman)
// 'Lax': cookie dikirim untuk navigasi GET level atas (default browser modern)
// 'None': cookie selalu dikirim (perlu secure=true)

// Fungsi helper untuk set cookie aman
function setCookieAman($name, $value, $days = 30) {
    setcookie($name, $value, [
        'expires'  => time() + $days * 86400,
        'path'     => '/',
        'secure'   => isset($_SERVER['HTTPS']),
        'httponly' => true,
        'samesite' => 'Strict'
    ]);
}

setCookieAman('remember_token', 'xyz789');
?>
```

## Kasus Penggunaan Nyata
Cookie login dengan `httponly` dan `secure` untuk mencegah pencurian via XSS, cookie preferensi dengan `path` terbatas ke area tertentu, atau cookie tracking dengan `samesite=Lax` agar tetap bisa dilacak dari link eksternal.
