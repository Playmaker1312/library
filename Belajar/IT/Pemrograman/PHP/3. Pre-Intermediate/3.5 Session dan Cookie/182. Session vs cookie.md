# 182. Session vs Cookie

## Definisi Singkat
Session dan cookie sama-sama menyimpan data pengguna, tapi session menyimpan data di server (hanya ID di browser), sedangkan cookie menyimpan data langsung di browser. Masing-masing punya kelebihan dan kekurangan.

## Analogi
**Session**: Seperti loker di gym. Anda menyimpan barang berharga di loker (server), dan Anda hanya memegang kunci kecil (session ID). Aman — orang lain hanya melihat kunci, bukan isi loker.

**Cookie**: Seperti stiker nama di botol minum. Namanya tertulis langsung di botol (browser). Semua orang bisa membaca nama Anda. Praktis untuk informasi sederhana, tapi tidak aman untuk data rahasia.

## Poin-Poin Penting
| Aspek | Session | Cookie |
|-------|---------|--------|
| Lokasi penyimpanan | Server | Browser |
| Keamanan | Lebih aman | Kurang aman |
| Kapasitas | Tidak terbatas | ~4KB per cookie |
| Tipe data | Semua tipe | Hanya string |
| Masa berlaku | Sampai browser ditutup / timeout | Bisa diatur (hari/tahun) |
| Kecepatan | Lebih lambat (I/O server) | Lebih cepat (client-side) |
| Biaya | Pakai memori server | Gratis (client-side) |

## Contoh Kode (PHP)
```php
<?php
session_start();

// SESSION: data di server
$_SESSION['user_id'] = 42;
$_SESSION['cart'] = [/* array besar */];
// Aman untuk data sensitif
// Bisa menyimpan array/objek

// COOKIE: data di browser
setcookie('theme', 'dark', time() + 86400 * 30);
setcookie('lang', 'id', time() + 86400 * 30);
// Tidak aman untuk data sensitif
// Hanya string, maks 4KB

// Kapan pakai session:
// - Login user, keranjang belanja, data sensitif
// - Data besar atau kompleks (array, objek)

// Kapan pakai cookie:
// - Preferensi tema/bahasa (tidak sensitif)
// - Remember me token (hash, bukan password asli)
// - Tracking (analytics)

// Kombinasi: session + cookie
// Cookie menyimpan token "remember me"
// Session menyimpan data login aktif
if (isset($_COOKIE['remember_token']) && !isset($_SESSION['user_id'])) {
    // Auto-login berdasarkan cookie
    $token = $_COOKIE['remember_token'];
    // Validasi token, lalu set session
    $_SESSION['user_id'] = $userId;
}

// Hapus session vs hapus cookie
// Session: session_destroy()
// Cookie: setcookie('name', '', time()-3600)
?>
```

## Kasus Penggunaan Nyata
Session untuk data login, role, keranjang belanja. Cookie untuk preferensi tampilan, remember me, tracking analytics, atau A/B testing.
