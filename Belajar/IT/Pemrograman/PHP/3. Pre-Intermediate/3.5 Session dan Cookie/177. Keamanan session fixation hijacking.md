# 177. Keamanan session fixation hijacking

## Definisi Singkat
Session fixation adalah serangan di mana penyerang memaksa korban menggunakan session ID yang sudah diketahui penyerang. Session hijacking adalah pencurian session ID untuk menyamar sebagai korban.

## Analogi
**Session Fixation**: Penyerang memberikan kunci loker palsu ke korban. "Gunakan kunci ini untuk menyimpan barang Anda." Setelah korban menyimpan barang, penyerang yang punya duplikat kunci bisa membuka loker yang sama.

**Session Hijacking**: Penyerang mencuri kunci loker korban (lewat WiFi publik, misalnya) lalu membuka loker korban dan mengambil barang-barangnya.

## Poin-Poin Penting
- Regenerasi session ID setelah login: `session_regenerate_id(true)`
- Gunakan HTTPS untuk mencegah session ID dicuri (sniffing)
- Set cookie session dengan `httponly` dan `secure`
- Validasi User-Agent atau IP (tapi hati-hati dengan pengguna mobile)
- Batasi session lifetime

## Contoh Kode (PHP)
```php
<?php
session_start();

// Cegah session fixation: regenerasi ID setelah login
function login($username, $password) {
    // Verifikasi kredensial...
    if ($authBerhasil) {
        // REGENERASI session ID — kunci utama anti fixation
        session_regenerate_id(true);
        
        $_SESSION['user_id'] = 42;
        $_SESSION['username'] = $username;
        $_SESSION['login_time'] = time();
        $_SESSION['user_agent'] = $_SERVER['HTTP_USER_AGENT'];
        $_SESSION['ip_address'] = $_SERVER['REMOTE_ADDR'];
        
        return true;
    }
    return false;
}

// Verifikasi tambahan: cek User-Agent (optional)
function cekSessionConsistency() {
    if ($_SESSION['user_agent'] !== $_SERVER['HTTP_USER_AGENT']) {
        // Kemungkinan session dicuri
        session_destroy();
        header('Location: login.php?alert=session_hijack');
        exit;
    }
}

// Cookie aman
session_set_cookie_params([
    'lifetime' => 0,
    'path' => '/',
    'domain' => '',
    'secure' => true,     // Hanya HTTPS
    'httponly' => true,   // Tidak bisa diakses JavaScript
    'samesite' => 'Strict' // Cegah CSRF
]);

// Logout harus regenerasi
function logout() {
    $_SESSION = [];
    session_regenerate_id(true);
    session_destroy();
}

// Best practice lengkap
function initSecureSession() {
    // Set cookie params sebelum start
    session_set_cookie_params([
        'lifetime' => 3600,
        'secure' => isset($_SERVER['HTTPS']),
        'httponly' => true,
        'samesite' => 'Strict'
    ]);
    session_start();
    
    // Regenerasi periodik (setiap 30 menit)
    $regenerateTime = 1800;
    if (!isset($_SESSION['regenerated']) || 
        (time() - $_SESSION['regenerated']) > $regenerateTime) {
        session_regenerate_id(true);
        $_SESSION['regenerated'] = time();
    }
}
?>
```

## Kasus Penggunaan Nyata
Setiap aplikasi web dengan autentikasi — terutama aplikasi keuangan, admin panel, e-commerce, atau sistem yang menangani data sensitif pengguna.
