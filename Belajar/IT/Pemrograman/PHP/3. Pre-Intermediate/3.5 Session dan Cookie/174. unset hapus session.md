# 174. unset hapus session

## Definisi Singkat
`unset($_SESSION['key'])` menghapus item tertentu dari array session. Berbeda dengan `session_destroy()` yang menghapus seluruh session. `unset` hanya membersihkan data spesifik.

## Analogi
Seperti mengeluarkan satu barang dari loker. Anda tidak perlu mengosongkan seluruh loker — cukup ambil jaket yang ingin Anda bawa pulang (unset). Barang lain di loker tetap aman di sana.

## Poin-Poin Penting
- `unset($_SESSION['key'])` — hapus satu item session
- `$_SESSION = []` — kosongkan semua data session (tapi session ID tetap ada)
- `session_unset()` — hapus semua variabel session (tapi session ID tetap)
- Data yang dihapus tidak bisa dikembalikan
- Hanya menghapus dari array $_SESSION, tidak dari penyimpanan sampai script selesai

## Contoh Kode (PHP)
```php
<?php
session_start();

// Inisialisasi data
$_SESSION['username'] = 'budi';
$_SESSION['role'] = 'admin';
$_SESSION['cart'] = ['Buku', 'Pena'];
$_SESSION['preferensi'] = ['theme' => 'dark', 'lang' => 'id'];

// Hapus satu item
unset($_SESSION['cart']);
// $_SESSION sekarang: ['username', 'role', 'preferensi']

// Cek apakah sudah dihapus
if (!isset($_SESSION['cart'])) {
    echo "Keranjang sudah dikosongkan";
}

// Hapus flash message setelah dibaca
if (isset($_SESSION['flash'])) {
    echo $_SESSION['flash']['message'];
    unset($_SESSION['flash']); // Hapus setelah ditampilkan
}

// Hapus beberapa item
$itemsToRemove = ['temp_data', 'upload_progress'];
foreach ($itemsToRemove as $item) {
    unset($_SESSION[$item]);
}

// Kosongkan semua data session (tapi session tetap ada)
$_SESSION = [];

// Atau alternatif
// session_unset(); // Hapus semua variabel session

// Logout: hapus data login spesifik
function logout() {
    unset($_SESSION['user_id']);
    unset($_SESSION['username']);
    unset($_SESSION['role']);
    // Data lain (seperti preferensi) tetap ada
}

// Hapus data dengan prefix tertentu
foreach ($_SESSION as $key => $value) {
    if (strpos($key, 'temp_') === 0) {
        unset($_SESSION[$key]);
    }
}
?>
```

## Kasus Penggunaan Nyata
Menghapus item dari keranjang belanja, membersihkan flash message setelah ditampilkan, menghapus data temporary, atau logout parsial (menghapus data login tapi menyimpan preferensi).
