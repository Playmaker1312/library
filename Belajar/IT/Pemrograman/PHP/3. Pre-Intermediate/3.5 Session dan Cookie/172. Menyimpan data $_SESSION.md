# 172. Menyimpan data $_SESSION

## Definisi Singkat
Data sesi disimpan dengan menetapkan nilai ke elemen array `$_SESSION`, seperti `$_SESSION['key'] = value`. Data akan tersedia di seluruh halaman selama sesi masih aktif.

## Analogi
Seperti menaruh barang di loker stasiun. Anda membuka loker (session_start), lalu memasukkan tas (data) ke dalamnya. Tas itu akan tetap ada di loker sampai Anda mengambilnya kembali atau loker ditutup. Setiap kali Anda datang dengan kunci yang sama, tas masih ada di sana.

## Poin-Poin Penting
- Simpan data: `$_SESSION['key'] = $value`
- Key bisa string, value bisa berbagai tipe (string, int, array, object)
- Data disimpan di server, aman dari manipulasi client
- Data bertahan sampai session dihapus atau browser ditutup
- Bisa menyimpan array multidimensi

## Contoh Kode (PHP)
```php
<?php
session_start();

// Menyimpan data sederhana
$_SESSION['user_id'] = 42;
$_SESSION['username'] = 'budi123';
$_SESSION['role'] = 'admin';

// Menyimpan array
$_SESSION['cart'] = [
    ['id' => 1, 'nama' => 'Buku', 'qty' => 2, 'harga' => 25000],
    ['id' => 2, 'nama' => 'Pena', 'qty' => 3, 'harga' => 5000],
];

// Menyimpan objek (harus serializable, tidak disarankan)
$_SESSION['last_activity'] = time();

// Menyimpan flash message (pesan sekali lihat)
$_SESSION['flash'] = [
    'type' => 'success',
    'message' => 'Data berhasil disimpan!'
];

// Data session bisa diakses di halaman lain
function getCartTotal() {
    $total = 0;
    foreach ($_SESSION['cart'] ?? [] as $item) {
        $total += $item['harga'] * $item['qty'];
    }
    return $total;
}

// Counter kunjungan
if (!isset($_SESSION['visit_count'])) {
    $_SESSION['visit_count'] = 1;
    $_SESSION['first_visit'] = time();
} else {
    $_SESSION['visit_count']++;
}

echo "Kunjungan ke-" . $_SESSION['visit_count'];
?>
```

## Kasus Penggunaan Nyata
Menyimpan data pengguna setelah login (ID, username, role), menyimpan item keranjang belanja, flash messages (notifikasi setelah redirect), atau tracking aktivitas selama sesi.
