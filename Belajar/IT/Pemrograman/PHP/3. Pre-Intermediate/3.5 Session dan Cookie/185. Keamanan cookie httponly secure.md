# 185. Keamanan cookie httponly secure

## Definisi Singkat
Atribut `httponly` mencegah JavaScript mengakses cookie (melindungi dari XSS). Atribut `secure` memastikan cookie hanya dikirim melalui koneksi HTTPS (melindungi dari sniffing). Keduanya adalah standar keamanan minimal untuk cookie.

## Analogi
**httponly**: Seperti dokumen rahasia yang diletakkan di brankas yang hanya bisa dibuka dengan kunci fisik. Orang yang bisa melihat melalui jendela (JavaScript) tidak bisa membaca dokumennya — hanya server yang punya kuncinya.

**secure**: Seperti mengirim dokumen lewat kurir berseragam resmi (HTTPS), bukan lewat pos biasa yang bisa dibaca orang di jalan.

## Poin-Poin Penting
- `httponly=true`: cookie tidak bisa diakses oleh JavaScript (`document.cookie`)
- `secure=true`: cookie hanya dikirim melalui HTTPS
- Keduanya harus diset untuk cookie yang mengandung data sensitif
- `samesite=Strict` atau `Lax` untuk proteksi CSRF tambahan
- Cookie session HARUS memiliki kedua atribut ini di production

## Contoh Kode (PHP)
```php
<?php
// Set cookie aman dengan semua proteksi
function setSecureCookie($name, $value, $expireDays = 30) {
    setcookie($name, $value, [
        'expires'  => time() + $expireDays * 86400,
        'path'     => '/',
        'domain'   => '',
        'secure'   => true,     // Hanya HTTPS
        'httponly' => true,     // Tidak bisa JS akses
        'samesite' => 'Strict'  // Cegah CSRF
    ]);
}

// Cookie session harus aman
session_set_cookie_params([
    'lifetime' => 0,
    'path' => '/',
    'domain' => '',
    'secure' => true,     // Hanya HTTPS (production)
    'httponly' => true,   // JavaScript tidak bisa baca session ID
    'samesite' => 'Strict'
]);
session_start();

// Contoh: tanpa httponly — rentan XSS
setcookie('rentan', 'mudah_dicuri');
// <script>alert(document.cookie)</script> bisa membaca ini!

// Contoh: dengan httponly — aman dari XSS
setcookie('aman', 'tidak_terbaca_js', [
    'httponly' => true,
    'secure' => true,
    'samesite' => 'Strict'
]);

// Deteksi apakah koneksi aman
if (empty($_SERVER['HTTPS']) || $_SERVER['HTTPS'] === 'off') {
    // Peringatan: tidak boleh set secure cookie di HTTP
    // Cookie tidak akan tersimpan di browser!
    // setcookie('test', 'value', ['secure' => true]); // Gagal di HTTP
}

// Best practice: sesuaikan secure dengan environment
$isSecure = !empty($_SERVER['HTTPS']) && $_SERVER['HTTPS'] !== 'off';

session_set_cookie_params([
    'secure' => $isSecure,
    'httponly' => true,
    'samesite' => 'Strict'
]);
session_start();

// Remember me dengan cookie aman
setcookie('remember', $token, [
    'expires' => time() + 86400 * 30,
    'secure' => $isSecure,
    'httponly' => true,
    'samesite' => 'Strict'
]);
?>
```

## Kasus Penggunaan Nyata
Semua cookie yang mengandung data session, token autentikasi, atau informasi pengguna yang sensitif — diterapkan di aplikasi perbankan, e-commerce, admin panel, dan aplikasi web apa pun yang memprioritaskan keamanan.
