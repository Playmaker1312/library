# 183. Login sederhana session

## Definisi Singkat
Login sederhana menggunakan session untuk mempertahankan status autentikasi pengguna di seluruh halaman. Setelah login berhasil, data pengguna disimpan di session dan diperiksa di setiap halaman yang dilindungi.

## Analogi
Seperti masuk ke klub malam. Di pintu masuk, Anda menunjukkan KTP dan membayar (login). Petugas memberi Anda stempel di tangan (session). Selama stempel masih ada, Anda bisa keluar-masuk area klub tanpa perlu menunjukkan KTP lagi. Stempel adalah bukti Anda sudah diverifikasi.

## Poin-Poin Penting
- Gunakan `password_hash()` dan `password_verify()` untuk password
- Regenerasi session ID setelah login sukses
- Setiap halaman protected harus cek `$_SESSION['user_id']`
- Gunakan `requireLogin()` function untuk redirect
- Logout: hapus session dan cookie

## Contoh Kode (PHP)
```php
<?php
session_start();

// Database user (simulasi)
$users = [
    'budi' => password_hash('rahasia123', PASSWORD_DEFAULT),
    'ani'  => password_hash('kopi456', PASSWORD_DEFAULT)
];

// Proses login
if ($_SERVER['REQUEST_METHOD'] === 'POST' && isset($_POST['login'])) {
    $username = $_POST['username'] ?? '';
    $password = $_POST['password'] ?? '';
    
    if (isset($users[$username]) && password_verify($password, $users[$username])) {
        session_regenerate_id(true);
        $_SESSION['user_id'] = $username;
        $_SESSION['login_time'] = time();
        header('Location: dashboard.php');
        exit;
    } else {
        $error = "Username atau password salah";
    }
}

// Logout
if (isset($_GET['logout'])) {
    $_SESSION = [];
    session_destroy();
    header('Location: login.php');
    exit;
}
?>
<!-- Form Login -->
<form method="post">
    <input type="text" name="username" placeholder="Username" required>
    <input type="password" name="password" placeholder="Password" required>
    <button type="submit" name="login">Login</button>
    <?php if (isset($error)): ?>
        <p class="error"><?= htmlspecialchars($error) ?></p>
    <?php endif; ?>
</form>

<?php
// dashboard.php — halaman yang dilindungi
// require 'cek_login.php';

// cek_login.php
function requireLogin() {
    if (session_status() === PHP_SESSION_NONE) {
        session_start();
    }
    if (!isset($_SESSION['user_id'])) {
        header('Location: login.php');
        exit;
    }
}
requireLogin();
echo "Selamat datang, " . $_SESSION['user_id'];
?>
```

## Kasus Penggunaan Nyata
Sistem login dasar untuk aplikasi web — panel admin, area anggota, dashboard pengguna, atau sistem manajemen konten sederhana.
