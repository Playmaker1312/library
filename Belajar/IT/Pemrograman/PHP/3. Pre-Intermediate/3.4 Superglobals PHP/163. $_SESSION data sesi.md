# 163. $_SESSION data sesi

## Definisi Singkat
`$_SESSION` adalah superglobal array yang menyimpan data sesi pengguna di sisi server. Data ini bertahan selama sesi browser terbuka dan bisa diakses di halaman-halaman berbeda.

## Analogi
Seperti loker di pusat perbelanjaan. Anda mendapatkan kartu kunci (session ID) saat masuk. Barang-barang yang Anda simpan di loker (data session) aman tersimpan dan bisa Anda ambil kapan saja selama Anda masih memiliki kartu kuncinya. Loker yang lain (pengguna lain) tidak bisa membuka loker Anda.

## Poin-Poin Penting
- Harus memanggil `session_start()` sebelum menggunakan `$_SESSION`
- Data disimpan di server, hanya session ID yang disimpan di browser
- Data bertahan hingga session dihapus atau browser ditutup
- Bisa menyimpan berbagai tipe data: string, integer, array, object
- Setiap pengguna mendapat session ID unik

## Contoh Kode (PHP)
```php
<?php
session_start();

// Menyimpan data ke session
$_SESSION['user_id'] = 123;
$_SESSION['username'] = 'budi123';
$_SESSION['role'] = 'admin';
$_SESSION['cart'] = [
    ['produk' => 'Buku', 'qty' => 2],
    ['produk' => 'Pena', 'qty' => 5]
];

// Membaca data session
if (isset($_SESSION['username'])) {
    echo "Selamat datang, " . $_SESSION['username'];
}

// Di halaman lain (harus session_start() juga)
session_start();
$role = $_SESSION['role'] ?? 'guest';

if ($role !== 'admin') {
    header('Location: login.php');
    exit;
}

// Cek apakah user sudah login
if (empty($_SESSION['user_id'])) {
    // Redirect ke login
    header('Location: login.php');
    exit;
}
?>
```

## Kasus Penggunaan Nyata
Login system (menyimpan user ID, role), keranjang belanja, preferensi pengguna selama sesi, flash messages setelah redirect, atau tracking aktivitas pengguna dalam satu kunjungan.
