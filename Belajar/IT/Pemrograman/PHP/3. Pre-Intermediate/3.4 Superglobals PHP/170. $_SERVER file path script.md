# 170. $_SERVER file path script

## Definisi Singkat
`$_SERVER` berisi beberapa key yang memberikan informasi tentang path file script yang sedang dieksekusi, seperti `SCRIPT_NAME`, `SCRIPT_FILENAME`, `PHP_SELF`, dan `DOCUMENT_ROOT`. Berguna untuk membuat URL dan path absolut.

## Analogi
Seperti peta yang menunjukkan posisi Anda saat ini di mall. Ada berbagai cara untuk mendeskripsikan posisi: nama toko (SCRIPT_NAME), koordinat GPS (SCRIPT_FILENAME), atau denah dari pintu masuk (DOCUMENT_ROOT). Semuanya menunjuk tempat yang sama dengan cara berbeda.

## Poin-Poin Penting
- `$_SERVER['SCRIPT_NAME']` — path virtual dari document root (untuk URL)
- `$_SERVER['SCRIPT_FILENAME']` — path absolut di file system
- `$_SERVER['PHP_SELF']` — nama file script saat ini (rentan XSS jika tidak di-encode)
- `$_SERVER['DOCUMENT_ROOT']` — root direktori dokumen web server
- `$_SERVER['REQUEST_URI']` — URI lengkap termasuk query string

## Contoh Kode (PHP)
```php
<?php
// Path untuk URL
echo "Script Name: " . $_SERVER['SCRIPT_NAME'];
echo "PHP Self: " . $_SERVER['PHP_SELF'];
echo "Request URI: " . $_SERVER['REQUEST_URI'];

// Path file system
echo "Script Filename: " . $_SERVER['SCRIPT_FILENAME'];
echo "Document Root: " . $_SERVER['DOCUMENT_ROOT'];

// Membuat URL absolut
$baseUrl = (isset($_SERVER['HTTPS']) ? 'https' : 'http')
         . '://' . $_SERVER['HTTP_HOST']
         . rtrim(dirname($_SERVER['SCRIPT_NAME']), '/') . '/';

echo "Base URL: $baseUrl";

// Path ke file saat ini
$currentFile = __FILE__; // Path absolut file ini
$currentDir = __DIR__;   // Direktori file ini

// Include file berdasarkan path absolut
$configPath = __DIR__ . '/../config/database.php';
// require_once $configPath;

// PHP_SELF rentan XSS jika tidak di-encode
// <a href="<?= htmlspecialchars($_SERVER['PHP_SELF']) ?>">Link</a>

// Deteksi halaman saat ini
$page = basename($_SERVER['SCRIPT_NAME'], '.php');
echo "Halaman: $page";

// Navigasi aktif
$currentUri = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);
function isActive($path) {
    global $currentUri;
    return $currentUri === $path ? 'active' : '';
}
?>
```

## Kasus Penggunaan Nyata
Membuat navigasi yang menyorot halaman aktif, membangun URL absolut untuk link dan redirect, menentukan path untuk include file, atau routing sederhana berdasarkan URL.
