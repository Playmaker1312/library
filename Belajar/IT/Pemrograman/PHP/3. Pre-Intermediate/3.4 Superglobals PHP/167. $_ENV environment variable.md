# 167. $_ENV environment variable

## Definisi Singkat
`$_ENV` adalah superglobal array yang berisi variabel lingkungan (environment variables) dari sistem operasi atau server web. Bisa diisi melalui file `.env`, konfigurasi server, atau sistem operasi.

## Analogi
Seperti papan pengaturan di kokpit pesawat. Pilot bisa melihat berbagai setelan: ketinggian, tekanan udara, bahan bakar — semuanya adalah "lingkungan" pesawat saat ini. Nilai-nilai ini bisa diubah sesuai kondisi dan memengaruhi cara pesawat beroperasi.

## Poin-Poin Penting
- Bergantung pada konfigurasi `variables_order` di php.ini (harus termasuk "E")
- Bisa diisi melalui `putenv()`, file `.env`, atau konfigurasi Apache/Nginx
- Sering digunakan untuk menyimpan konfigurasi sensitif (password database, API key)
- Alternatif: `getenv()` function lebih reliable
- Jangan pernah menampilkan `$_ENV` langsung ke pengguna

## Contoh Kode (PHP)
```php
<?php
// $_ENV dari php.ini atau sistem
$dbHost = $_ENV['DB_HOST'] ?? 'localhost';
$dbName = $_ENV['DB_NAME'] ?? 'myapp';
$dbUser = $_ENV['DB_USER'] ?? 'root';
$dbPass = $_ENV['DB_PASS'] ?? '';

// getenv() alternatif
$appEnv = getenv('APP_ENV') ?: 'production';
$debug  = getenv('APP_DEBUG') === 'true';

// putenv() untuk set environment variable
putenv("MY_CUSTOM_VAR=HelloWorld");
echo getenv('MY_CUSTOM_VAR'); // HelloWorld

// File .env (dengan library vlucas/phpdotenv)
// require 'vendor/autoload.php';
// $dotenv = Dotenv\Dotenv::createImmutable(__DIR__);
// $dotenv->load();
// 
// $_ENV['DB_HOST'] // dari file .env

// Contoh konfigurasi aplikasi
$config = [
    'db' => [
        'host' => $_ENV['DB_HOST'] ?? 'localhost',
        'name' => $_ENV['DB_NAME'] ?? 'app',
        'user' => $_ENV['DB_USER'] ?? 'root',
        'pass' => $_ENV['DB_PASS'] ?? '',
    ],
    'app' => [
        'env'   => getenv('APP_ENV') ?: 'production',
        'debug' => filter_var(getenv('APP_DEBUG'), FILTER_VALIDATE_BOOLEAN),
        'url'   => getenv('APP_URL') ?: 'http://localhost',
    ]
];

// Jangan expose $_ENV
// var_dump($_ENV); // BERBAHAYA! Bisa bocorkan password
?>
```

## Kasus Penggunaan Nyata
Menyimpan konfigurasi database, API key untuk layanan eksternal (Stripe, AWS, Mailgun), mode aplikasi (development/production), atau pengaturan yang berbeda antar environment.
