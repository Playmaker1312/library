# 161. Superglobal Variable

## Definisi Singkat
Superglobal adalah variabel bawaan PHP yang tersedia di semua scope — bisa diakses dari mana saja (fungsi, class, file) tanpa perlu keyword `global`. Ada 9 superglobal di PHP.

## Analogi
Seperti papan pengumuman di alun-alun kota. Informasi di papan itu (data superglobal) bisa dibaca oleh siapa saja, dari mana saja — dari rumah, kantor, atau toko. Tidak perlu izin khusus untuk melihatnya.

## Poin-Poin Penting
- Tersedia secara otomatis di seluruh scope (function, class, file)
- Tidak perlu deklarasi `global` untuk mengaksesnya
- Semua superglobal adalah array asosiatif
- Sembilan superglobal: `$GLOBALS`, `$_SERVER`, `$_GET`, `$_POST`, `$_FILES`, `$_COOKIE`, `$_SESSION`, `$_REQUEST`, `$_ENV`
- Berisi data dari request, server, session, dan environment

## Contoh Kode (PHP)
```php
<?php
// Superglobal bisa diakses dari mana saja
function testSuperglobal() {
    // Tidak perlu global $_SERVER
    echo $_SERVER['REQUEST_METHOD']; // POST atau GET
    
    // Tidak perlu global $_POST
    $nama = $_POST['nama'] ?? 'Tidak ada';
    
    // $GLOBALS adalah superglobal yang berisi semua variabel global
    $globalNama = $GLOBALS['namaGlobal'] ?? '';
}

$namaGlobal = "Budi";
testSuperglobal();

// Daftar superglobal
echo '<pre>';
echo '$_SERVER : ' . print_r($_SERVER, true) . "\n";
echo '$_GET    : ' . print_r($_GET, true) . "\n";
echo '$_POST   : ' . print_r($_POST, true) . "\n";
echo '$_FILES  : ' . print_r($_FILES, true) . "\n";
echo '$_COOKIE : ' . print_r($_COOKIE, true) . "\n";
echo '$_SESSION: ' . (isset($_SESSION) ? print_r($_SESSION, true) : 'tidak aktif') . "\n";
echo '$_REQUEST: ' . print_r($_REQUEST, true) . "\n";
echo '$_ENV    : ' . print_r($_ENV, true) . "\n";
echo '$GLOBALS : ' . count($GLOBALS) . ' variabel' . "\n";
echo '</pre>';
?>
```

## Kasus Penggunaan Nyata
Mengakses data HTTP request (GET, POST), informasi server, session user, cookie, dan environment variable — semuanya tanpa perlu menulis kode inisialisasi atau passing parameter.
