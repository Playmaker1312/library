# 162. $_SERVER info server request

## Definisi Singkat
`$_SERVER` adalah superglobal array yang berisi informasi tentang server, lingkungan eksekusi, dan permintaan HTTP — seperti method request, URL, header, alamat IP, dan path file.

## Analogi
Seperti papan informasi di bandara yang menampilkan berbagai data: jam keberangkatan (request method), nomor gate (port server), tujuan penerbangan (URL yang diminta), dan status terkini. Semua informasi tentang penerbangan (request) dan bandara (server) ada di satu papan.

## Poin-Poin Penting
- `$_SERVER['REQUEST_METHOD']` — GET, POST, PUT, DELETE
- `$_SERVER['SCRIPT_NAME']` — path file saat ini
- `$_SERVER['SERVER_NAME']` — nama host server
- `$_SERVER['HTTP_HOST']` — header Host dari request
- `$_SERVER['REMOTE_ADDR']` — IP address pengunjung
- Jumlah dan nama key tergantung pada server dan request

## Contoh Kode (PHP)
```php
<?php
// Informasi request
echo "Method: " . $_SERVER['REQUEST_METHOD'];      // GET / POST
echo "URI: " . $_SERVER['REQUEST_URI'];             // /halaman.php?id=5
echo "Script: " . $_SERVER['SCRIPT_NAME'];          // /halaman.php
echo "Query String: " . ($_SERVER['QUERY_STRING'] ?? ''); // id=5

// Informasi server
echo "Server Name: " . $_SERVER['SERVER_NAME'];     // example.com
echo "Server Port: " . $_SERVER['SERVER_PORT'];     // 80 / 443
echo "Server Software: " . $_SERVER['SERVER_SOFTWARE']; // Apache/2.4
echo "Document Root: " . $_SERVER['DOCUMENT_ROOT']; // C:/xampp/htdocs

// Informasi klien
echo "IP Anda: " . $_SERVER['REMOTE_ADDR'];         // 192.168.1.1
echo "User Agent: " . $_SERVER['HTTP_USER_AGENT'];  // Mozilla/5.0...
echo "Referer: " . ($_SERVER['HTTP_REFERER'] ?? 'langsung');

// Deteksi HTTPS
$isHttps = (!empty($_SERVER['HTTPS']) && $_SERVER['HTTPS'] !== 'off')
           || $_SERVER['SERVER_PORT'] == 443;

// Path saat ini
$currentPath = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);
?>
```

## Kasus Penggunaan Nyata
Routing berdasarkan method/URL, logging akses pengguna, deteksi environment (localhost/production), redirect berdasarkan referer, atau validasi request method untuk keamanan.
