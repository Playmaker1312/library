# 169. $_SERVER IP address user agent

## Definisi Singkat
`$_SERVER['REMOTE_ADDR']` memberikan alamat IP pengunjung. `$_SERVER['HTTP_USER_AGENT']` memberikan informasi tentang browser dan sistem operasi pengunjung. Keduanya berguna untuk logging dan analitik.

## Analogi
**REMOTE_ADDR**: Seperti alamat rumah pengirim surat di amplop. Anda tahu dari mana surat itu berasal.

**HTTP_USER_AGENT**: Seperti deskripsi "surat ini ditulis dengan pulpen biru di kertas A4" — memberi tahu Anda alat apa yang digunakan pengirim.

## Poin-Poin Penting
- `REMOTE_ADDR` adalah IP asli koneksi (bisa proxy)
- Untuk IP di belakang proxy, gunakan `HTTP_X_FORWARDED_FOR` (tidak selalu ada)
- `HTTP_USER_AGENT` bisa dipalsukan — jangan untuk keamanan
- `HTTP_USER_AGENT` berisi browser, versi, dan OS
- Keduanya berguna untuk logging, analitik, dan deteksi anomali

## Contoh Kode (PHP)
```php
<?php
// IP Address
$ipAddress = $_SERVER['REMOTE_ADDR'] ?? '0.0.0.0';
echo "IP Anda: " . $ipAddress;

// IP di belakang proxy (load balancer, CDN)
$ipAsli = $_SERVER['HTTP_X_FORWARDED_FOR'] ?? $_SERVER['REMOTE_ADDR'] ?? '0.0.0.0';
// Hati-hati: HTTP_X_FORWARDED_FOR bisa dipalsukan

// User Agent
$userAgent = $_SERVER['HTTP_USER_AGENT'] ?? 'Unknown';
echo "Browser/OS: " . $userAgent;
// Contoh: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36

// Deteksi browser sederhana
function deteksiBrowser($ua) {
    if (strpos($ua, 'Chrome') !== false) return 'Chrome';
    if (strpos($ua, 'Firefox') !== false) return 'Firefox';
    if (strpos($ua, 'Safari') !== false) return 'Safari';
    if (strpos($ua, 'Edge') !== false) return 'Edge';
    return 'Unknown';
}

// Deteksi OS
function deteksiOS($ua) {
    if (strpos($ua, 'Windows') !== false) return 'Windows';
    if (strpos($ua, 'Mac') !== false) return 'macOS';
    if (strpos($ua, 'Linux') !== false) return 'Linux';
    if (strpos($ua, 'Android') !== false) return 'Android';
    if (strpos($ua, 'iOS') !== false) return 'iOS';
    return 'Unknown';
}

// Logging akses
$log = date('Y-m-d H:i:s') . " | IP: $ipAddress | Browser: " . deteksiBrowser($userAgent);
file_put_contents('access.log', $log . PHP_EOL, FILE_APPEND);

// Cek apakah request dari mobile
$isMobile = preg_match('/Mobile|Android|iPhone|iPad/i', $userAgent);
?>
```

## Kasus Penggunaan Nyata
Logging aktivitas pengguna, analitik (browser/OS populer), pembatasan akses berdasarkan IP, deteksi perangkat mobile untuk responsive layout, atau deteksi anomali keamanan.
