# 165. $_REQUEST GET POST COOKIE

## Definisi Singkat
`$_REQUEST` adalah superglobal array yang menggabungkan data dari `$_GET`, `$_POST`, dan `$_COOKIE`. Berguna ketika Anda tidak peduli dari mana data berasal, tapi harus digunakan dengan hati-hati.

## Analogi
Seperti kotak surat masuk yang mencampur semua jenis surat: surat kilat (POST), kartu pos (GET), dan paket (COOKIE). Anda bisa mengambil semuanya dari satu kotak, tapi Anda tidak tahu jenis surat mana yang mana tanpa memeriksanya lebih detail.

## Poin-Poin Penting
- Berisi gabungan `$_GET` + `$_POST` + `$_COOKIE`
- Urutan prioritas ditentukan oleh `request_order` di php.ini (biasanya GP => GET dulu baru POST)
- Jika ada key yang sama, nilai dari sumber dengan prioritas lebih tinggi yang digunakan
- Kurang aman karena tidak jelas sumber data
- Disarankan menggunakan `$_GET` atau `$_POST` secara spesifik

## Contoh Kode (PHP)
```php
<?php
// $_REQUEST menggabungkan GET, POST, dan COOKIE
$nama = $_REQUEST['nama'] ?? 'Tamu';
$action = $_REQUEST['action'] ?? 'index';

// Bisa dari GET /halaman.php?nama=Budi
// Bisa dari POST (form)
// Bisa dari COOKIE

// Bahaya: key yang sama dari sumber berbeda
// URL: ?id=123 (GET)
// Form: <input name="id" value="456"> (POST)
// $_REQUEST['id'] = 456 (POST menimpa GET jika prioritas POST lebih tinggi)

// Lebih aman: gunakan spesifik
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $id = $_POST['id'];
} else {
    $id = $_GET['id'] ?? 0;
}

// Contoh penggunaan (hati-hati)
function getParam($key, $default = null) {
    return $_REQUEST[$key] ?? $default;
}

// Filter/Search form yang bisa menerima GET dan POST
$search = trim($_REQUEST['q'] ?? '');
$page = (int)($_REQUEST['page'] ?? 1);

// Tidak disarankan untuk data sensitif
// $password = $_REQUEST['password']; // JANGAN! Bisa tampil di log/URL
?>
```

## Kasus Penggunaan Nyata
Form pencarian sederhana yang menerima parameter dari GET (bookmark) dan POST (form), atau parameter yang bisa dari berbagai sumber. Namun secara umum, lebih baik gunakan `$_GET` atau `$_POST` secara eksplisit.
