# 168. $GLOBALS semua global

## Definisi Singkat
`$GLOBALS` adalah superglobal array yang berisi SEMUA variabel global yang sedang aktif dalam script. Key dari array adalah nama variabel, value-nya adalah isi variabel tersebut.

## Analogi
Seperti papan besar di ruang kontrol yang menampilkan semua status sistem: suhu, tekanan, kecepatan, baterai — semuanya terlihat sekilas. Jika Anda mengubah salah satu nilai di papan, sistem yang sebenarnya juga berubah. Begitu juga sebaliknya.

## Poin-Poin Penting
- Berisi semua variabel global (termasuk superglobal lain)
- Bisa mengakses dan mengubah variabel global dari dalam fungsi tanpa `global`
- `$GLOBALS['var']` mereferensi ke variabel `$var` yang sama
- Mengubah `$GLOBALS['var']` sama dengan mengubah `$var`
- Hati-hati: membuat kode sulit dilacak jika terlalu sering digunakan

## Contoh Kode (PHP)
```php
<?php
$nama = "Budi";
$umur = 25;
$kota = "Jakarta";

function tampilkanData() {
    // Akses variabel global melalui $GLOBALS
    echo "Nama: " . $GLOBALS['nama'] . "\n";
    echo "Umur: " . $GLOBALS['umur'] . "\n";
    echo "Kota: " . $GLOBALS['kota'] . "\n";
    
    // $GLOBALS vs global
    // Sama dengan: global $nama; echo $nama;
}

tampilkanData();
// Nama: Budi
// Umur: 25
// Kota: Jakarta

// Mengubah variabel global dari dalam fungsi
function ubahNama($namaBaru) {
    $GLOBALS['nama'] = $namaBaru;
}

ubahNama("Ani");
echo $nama; // Ani

// $GLOBALS juga berisi superglobal lain
function cekRequest() {
    // Bisa akses $_POST melalui $GLOBALS
    $data = $GLOBALS['_POST'] ?? [];
    return $data;
}

// Melihat semua variabel global
echo count($GLOBALS); // Jumlah variabel global aktif

// Hati-hati: $GLOBALS termasuk dirinya sendiri
// (circular reference)
?>
```

## Kasus Penggunaan Nyata
Digunakan dalam skrip sederhana atau debugging untuk melihat semua variabel global. Dalam aplikasi modern, lebih baik gunakan dependency injection daripada mengandalkan `$GLOBALS`.
