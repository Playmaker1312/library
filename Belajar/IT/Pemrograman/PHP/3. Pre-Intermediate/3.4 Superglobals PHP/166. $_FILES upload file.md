# 166. $_FILES upload file

## Definisi Singkat
`$_FILES` adalah superglobal array yang berisi informasi file yang diunggah melalui HTTP POST. Setiap file upload memiliki elemen: name, type, size, tmp_name, dan error.

## Analogi
Seperti meja resepsionis di klinik. Pasien (file) datang dengan membawa: nama (name), jenis kelamin (type), berat badan (size), kartu antrian sementara (tmp_name), dan status kedatangan (error). Resepsionis mencatat semua ini sebelum pasien diperiksa lebih lanjut.

## Poin-Poin Penting
- Aktif hanya dengan `enctype="multipart/form-data"` dan `method="post"`
- Struktur: `$_FILES['fieldname']['attribute']`
- Atribut: `name`, `type`, `size`, `tmp_name`, `error`
- File disimpan sementara di `tmp_name` sebelum dipindahkan
- Kode error: `UPLOAD_ERR_OK` (0), `UPLOAD_ERR_INI_SIZE` (1), `UPLOAD_ERR_FORM_SIZE` (2)

## Contoh Kode (PHP)
```php
<?php
// Form dengan enctype yang benar
?>
<form method="post" enctype="multipart/form-data">
    <input type="file" name="gambar">
    <button type="submit">Upload</button>
</form>

<?php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $file = $_FILES['gambar'];
    
    echo "Nama: " . $file['name'] . "<br>";       // foto.jpg
    echo "Tipe: " . $file['type'] . "<br>";       // image/jpeg
    echo "Ukuran: " . $file['size'] . " bytes<br>"; // 123456
    echo "Tmp: " . $file['tmp_name'] . "<br>";     // C:\xampp\tmp\phpABC.tmp
    echo "Error: " . $file['error'] . "<br>";      // 0 = OK
    
    // Menangani berbagai kode error
    switch ($file['error']) {
        case UPLOAD_ERR_OK:
            // Berhasil
            break;
        case UPLOAD_ERR_INI_SIZE:
        case UPLOAD_ERR_FORM_SIZE:
            echo "File terlalu besar";
            break;
        case UPLOAD_ERR_PARTIAL:
            echo "File hanya terupload sebagian";
            break;
        case UPLOAD_ERR_NO_FILE:
            echo "Tidak ada file yang diupload";
            break;
        default:
            echo "Error tidak dikenal";
    }
}

// Multiple file
// <input type="file" name="files[]" multiple>
$files = $_FILES['files'];
// $files['name'][0], $files['tmp_name'][0], dll
?>
```

## Kasus Penggunaan Nyata
Upload foto profil, upload gambar produk, upload dokumen (CV, surat lamaran), upload lampiran email, atau sistem galeri foto dengan multiple upload.
