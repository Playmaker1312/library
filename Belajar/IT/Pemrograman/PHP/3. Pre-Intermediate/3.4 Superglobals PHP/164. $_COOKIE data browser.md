# 164. $_COOKIE data browser

## Definisi Singkat
`$_COOKIE` adalah superglobal array yang berisi data cookie yang dikirim oleh browser. Cookie adalah data kecil yang disimpan di browser pengguna dan dikirim ke server setiap kali request.

## Analogi
Seperti stiker nama di tas ransel anak saat piknik. Di stiker itu tertulis "Budi, Telp: 0812xxxx". Setiap kali anak itu datang ke pos pendaftaran (request ke server), stiker itu terlihat. Informasinya kecil, sederhana, dan selalu dibawa. Tapi stiker bisa hilang atau rusak (cookie bisa dihapus).

## Poin-Poin Penting
- Cookie disimpan di browser, bukan di server
- Dikirim otomatis ke server setiap request ke domain yang sama
- Untuk SET cookie, gunakan fungsi `setcookie()`
- Untuk READ cookie, gunakan `$_COOKIE`
- Memiliki batas ukuran (biasanya 4KB) dan jumlah per domain

## Contoh Kode (PHP)
```php
<?php
// SET cookie (harus sebelum output apapun)
setcookie('theme', 'dark', time() + 3600 * 24 * 30, '/'); // 30 hari
setcookie('preferensi_bahasa', 'id', time() + 3600 * 24 * 365, '/'); // 1 tahun

// READ cookie
$theme = $_COOKIE['theme'] ?? 'light'; // default light
if ($theme === 'dark') {
    echo '<link rel="stylesheet" href="dark.css">';
}

$bahasa = $_COOKIE['preferensi_bahasa'] ?? 'en';

// Cek apakah cookie ada
if (isset($_COOKIE['last_visit'])) {
    $lastVisit = $_COOKIE['last_visit'];
    echo "Terakhir kunjung: $lastVisit";
}

// Cookie array
setcookie('user[nam a]', 'Budi', time() + 3600);
setcookie('user[role]', 'admin', time() + 3600);

if (isset($_COOKIE['user'])) {
    echo "Halo, " . $_COOKIE['user']['nama'];
}
?>
```

## Kasus Penggunaan Nyata
Menyimpan preferensi tema (gelap/terang), menyimpan bahasa yang dipilih pengguna, melacak kunjungan untuk analytics, remember me token, atau menyimpan item terakhir yang dilihat.
