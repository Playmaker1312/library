# Sanitasi & Validasi — Keamanan Input Dasar

## Penjelasan
**Validasi** = memeriksa apakah input sesuai aturan (apakah email valid? apakah umur berupa angka?). **Sanitasi** = membersihkan/menormalisasi input agar aman diproses (menghapus tag HTML, memotong spasi, meng-escape karakter berbahaya).

PHP menyediakan fungsi bawaan:

| Fungsi | Tujuan |
|--------|--------|
| `filter_var($input, FILTER_VALIDATE_EMAIL)` | Validasi email |
| `filter_var($input, FILTER_SANITIZE_EMAIL)` | Sanitasi email |
| `filter_var($input, FILTER_VALIDATE_INT)` | Validasi integer |
| `filter_var($input, FILTER_SANITIZE_STRING)` | Hapus tag & karakter khusus |
| `htmlspecialchars($input)` | Ubah `<>&\"` jadi entity HTML |
| `strip_tags($input)` | Hapus semua tag HTML/PHP |
| `trim($input)` | Hapus spasi di awal & akhir |
| `preg_match($pattern, $input)` | Validasi dengan regex |

Aturan emas: **Jangan pernah percaya input pengguna.** Validasi di server (validasi client-side bisa dilewati).

## Fungsi
Melindungi aplikasi dari serangan XSS (Cross-Site Scripting), SQL Injection, dan data rusak. Memastikan data yang masuk ke database dan ditampilkan ke halaman web aman dan sesuai format yang diharapkan.

## Cara Pengimplementasian / Code
```php
<?php
function validasiDanSanitasiDataBuku(array $data): array {
    $errors   = [];
    $clean    = [];

    // === Judul Buku ===
    $judul = trim($data['judul'] ?? '');
    if ($judul === '') {
        $errors[] = 'Judul buku wajib diisi.';
    } elseif (strlen($judul) > 100) {
        $errors[] = 'Judul maksimal 100 karakter.';
    } else {
        $clean['judul'] = htmlspecialchars($judul);
    }

    // === Email Peminjam ===
    $email = trim($data['email'] ?? '');
    if ($email === '') {
        $errors[] = 'Email wajib diisi.';
    } elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $errors[] = 'Format email tidak valid.';
    } else {
        $clean['email'] = filter_var($email, FILTER_SANITIZE_EMAIL);
    }

    // === Jumlah Buku ===
    $jumlah = $data['jumlah'] ?? '';
    if ($jumlah === '') {
        $errors[] = 'Jumlah buku wajib diisi.';
    } elseif (!filter_var($jumlah, FILTER_VALIDATE_INT, ['options' => ['min_range' => 1, 'max_range' => 10]])) {
        $errors[] = 'Jumlah buku harus angka antara 1-10.';
    } else {
        $clean['jumlah'] = (int) $jumlah;
    }

    // === URL Sampul (opsional) ===
    $url = trim($data['url_sampul'] ?? '');
    if ($url !== '' && !filter_var($url, FILTER_VALIDATE_URL)) {
        $errors[] = 'URL sampul tidak valid.';
    } else {
        $clean['url_sampul'] = $url !== '' ? htmlspecialchars($url) : null;
    }

    return ['clean' => $clean, 'errors' => $errors];
}

// Simulasi input dari form
$input = [
    'judul'      => '  <script>alert("xss")</script>PHP Dasar  ',
    'email'      => ' ANDI@Perpus.COM ',
    'jumlah'     => '3',
    'url_sampul' => 'https://example.com/sampul.jpg',
];

$result = validasiDanSanitasiDataBuku($input);

if (!empty($result['errors'])) {
    foreach ($result['errors'] as $err) {
        echo "⚠️ $err\n";
    }
} else {
    $d = $result['clean'];
    echo "Judul  : {$d['judul']}\n";       // Tag <script> sudah di-escape
    echo "Email  : {$d['email']}\n";       // andi@perpus.com
    echo "Jumlah : {$d['jumlah']}\n";      // 3
    echo "Sampul : {$d['url_sampul']}\n";
}
?>
```

## Analogi
Validasi seperti **pustakawan yang memeriksa kartu anggota sebelum meminjamkan buku** — memastikan nama sesuai KTP, kartu masih berlaku, foto cocok dengan wajah. Sanitasi seperti **petugas yang membersihkan buku dari coretan dan stiker liar sebelum masuk ke rak** — menghilangkan `tag HTML` seperti menyingkirkan kertas tempel nakal yang menempel di sampul buku.

## Dipakai untuk Apa
- **Form registrasi**: Validasi email, password strength, no. telepon
- **Form peminjaman**: Pastikan ID anggota valid, ISBN buku ada di sistem
- **Komentar/tinjauan**: Sanitasi HTML agar tidak ada script jahat
- **Upload file**: Validasi ekstensi dan ukuran file
- **Search box**: Sanitasi input agar tidak merusak query

## Kesalahan Umum yang Sering Terjadi
- **Hanya validasi client-side**: JavaScript bisa dimatikan — validasi server wajib.
- **Sanitasi sebelum validasi**: Membersihkan data lalu memvalidasi data yang sudah bersih — validasi jadi tidak akurat.
- **Lupa htmlspecialchars() saat output**: `echo $_POST['nama']` langsung — XSS menunggu terjadi.
- **FILTER_SANITIZE_STRING sudah deprecated di PHP 8.1**: Gunakan `htmlspecialchars()`.
- **Tidak handle tipe data**: `$_POST['umur']` selalu string — perlu cast ke int sebelum dicek.
- **Over-sanitasi**: Menghapus karakter yang sah (misal tanda kutip dalam nama "O'Brien").

## Hubungan dengan Materi Sebelumnya
Materi 18 memperkenalkan `$_GET`/`$_POST` sebagai cara menerima data form. Materi ini adalah **keamanan dasarnya** — karena data dari form TIDAK boleh dipakai mentah-mentah. Materi 7 (type juggling) dan 8 (type casting) berguna saat mengonversi input string ke tipe yang tepat. Materi 12 (string functions) seperti `trim()` dan `strlen()` sering dipakai dalam validasi.

## Soal Latihan & Jawaban
### Soal
Buat fungsi `validasiAnggota(array $data)` yang menerima `nama` (string, min 3 karakter), `email` (valid email), `usia` (integer 5-100). Kembalikan array dengan key `clean` (data tersanitasi) dan `errors` (daftar error). Gunakan `trim()`, `filter_var()`, `htmlspecialchars()`, dan `FILTER_VALIDATE_INT`.

### Jawaban
```php
<?php
function validasiAnggota(array $data): array {
    $errors = [];
    $clean  = [];

    $nama = trim($data['nama'] ?? '');
    if (strlen($nama) < 3) {
        $errors[] = 'Nama minimal 3 karakter.';
    } else {
        $clean['nama'] = htmlspecialchars($nama);
    }

    $email = trim($data['email'] ?? '');
    if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $errors[] = 'Email tidak valid.';
    } else {
        $clean['email'] = filter_var($email, FILTER_SANITIZE_EMAIL);
    }

    $usia = $data['usia'] ?? '';
    if (!filter_var($usia, FILTER_VALIDATE_INT, ['options' => ['min_range' => 5, 'max_range' => 100]])) {
        $errors[] = 'Usia harus angka 5-100.';
    } else {
        $clean['usia'] = (int) $usia;
    }

    return ['clean' => $clean, 'errors' => $errors];
}

$input = ['nama' => '  Budi  ', 'email' => 'BUDI@PERPUS.COM', 'usia' => '25'];
$res   = validasiAnggota($input);

if (empty($res['errors'])) {
    print_r($res['clean']);
} else {
    print_r($res['errors']);
}
?>
```
