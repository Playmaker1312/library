# $_POST & $_GET — Superglobal untuk Form Data

## Penjelasan
`$_GET` dan `$_POST` adalah **superglobal** di PHP — array asosiatif bawaan yang menampung data dari form HTML. Keduanya menentukan **bagaimana data dikirim dari browser ke server**:

| Metode | Data dikirim lewat | Tampil di URL | Kapasitas | Penggunaan |
|--------|-------------------|---------------|-----------|------------|
| `$_GET` | Query string URL | Ya | Terbatas (~2000 char) | Pencarian, filter |
| `$_POST` | Body HTTP request | Tidak | Besar | Login, form data sensitif |

Superglobal `$_REQUEST` menggabungkan keduanya, tapi praktik terbaik adalah menggunakan `$_GET` atau `$_POST` secara eksplisit.

Atribut `method` di tag `<form>` menentukan mana yang dipakai:
- `<form method="get">` → `$_GET`
- `<form method="post">` → `$_POST`

## Fungsi
Menjembatani data dari HTML form ke kode PHP. Memungkinkan aplikasi web menerima input pengguna (pencarian, registrasi, login, komentar) dan memprosesnya di server.

## Cara Pengimplementasian / Code
```php
<?php
// =====================
// Contoh $_GET — Form Pencarian Buku
// =====================
?>
<!-- form_pencarian.php -->
<form method="get" action="">
    <input type="text" name="judul" placeholder="Cari judul buku...">
    <button type="submit">Cari</button>
</form>

<?php
if (isset($_GET['judul'])) {
    $cari = $_GET['judul'];
    echo "Menampilkan hasil pencarian untuk: " . htmlspecialchars($cari);
    // $cari bisa dipakai untuk query ke database
}
?>

<?php
// =====================
// Contoh $_POST — Form Peminjaman Buku
// =====================
?>
<!-- form_peminjaman.php -->
<form method="post" action="proses_pinjam.php">
    <input type="text" name="nama_anggota" placeholder="Nama anggota">
    <input type="text" name="judul_buku" placeholder="Judul buku">
    <input type="number" name="lama_hari" placeholder="Lama pinjam (hari)">
    <button type="submit">Pinjam Buku</button>
</form>

<?php
// proses_pinjam.php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nama  = $_POST['nama_anggota'];
    $buku  = $_POST['judul_buku'];
    $hari  = (int) $_POST['lama_hari'];

    echo "Anggota: $nama<br>";
    echo "Meminjam buku: $buku<br>";
    echo "Selama: $hari hari<br>";
}
?>

<?php
// =====================
// $_GET dari URL langsung (query string)
// =====================
// URL: detail.php?id=5&kategori=fiksi
if (isset($_GET['id'])) {
    $idBuku = (int) $_GET['id'];
    echo "Menampilkan detail buku dengan ID: $idBuku";
}
?>
```

## Analogi
`$_GET` seperti **slip permintaan buku yang ditempel di papan pengumuman** — semua orang bisa melihat isi permintaan (judul buku, nama peminjam) karena tertulis terang-terangan. `$_POST` seperti **formulir peminjaman yang diserahkan langsung ke pustakawan** — isinya tidak terlihat oleh pengunjung lain karena dikirim di balik meja. Keduanya sampai ke pustakawan (server PHP), tapi cara penyampaiannya berbeda.

## Dipakai untuk Apa
- **$_GET**: Pencarian buku, filter kategori, paginasi halaman, sorting, link shareable yang menyimpan state
- **$_POST**: Login anggota, registrasi, peminjaman buku, pengembalian, input data sensitif
- **Form kontak**: Nama, email, pesan dari pengunjung website

## Kesalahan Umum yang Sering Terjadi
- **Salah pilih method**: Form login pakai GET — password tampil di URL dan tercatat di history browser.
- **Tidak cek isset()**: Akses `$_GET['judul']` langsung padahal belum dikirim → `Notice: Undefined index`.
- **Tidak validasi input**: Langsung pakai `$_POST['email']` tanpa filter — risiko XSS dan injeksi.
- **Percaya data GET itu "ringan"**: Data GET bisa dimodifikasi sembarang orang di URL — jangan untuk operasi kritis.
- **Lupa sanitasi saat output**: `echo $_GET['judul']` tanpa `htmlspecialchars()` — celah XSS.

## Soal Latihan & Jawaban
### Soal
Buat dua file: `cari_buku.html` (form GET dengan input `judul` dan `kategori`) dan `cari_buku.php` yang menangkap data dengan `$_GET`, lalu menampilkan: "Mencari buku '[judul]' di kategori [kategori]". Gunakan `htmlspecialchars()` untuk output.

### Jawaban
```php
<!-- cari_buku.html -->
<form method="get" action="cari_buku.php">
    <input type="text" name="judul" placeholder="Judul buku">
    <select name="kategori">
        <option value="fiksi">Fiksi</option>
        <option value="nonfiksi">Non-Fiksi</option>
    </select>
    <button type="submit">Cari</button>
</form>
```

```php
<?php
// cari_buku.php
if (isset($_GET['judul']) && isset($_GET['kategori'])) {
    $judul    = htmlspecialchars($_GET['judul']);
    $kategori = htmlspecialchars($_GET['kategori']);
    echo "Mencari buku '$judul' di kategori $kategori";
} else {
    echo "Silakan isi form pencarian terlebih dahulu.";
}
?>
```
