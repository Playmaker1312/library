# Flash Messages — Pesan Satu Kali Pakai

## Penjelasan
**Flash message** adalah pesan notifikasi yang disimpan di session, ditampilkan **satu kali** di halaman berikutnya, lalu otomatis dihapus. Pola klasik: setelah melakukan aksi (submit form, login, logout), redirect ke halaman lain yang menampilkan pesan sukses/gagal, dan pesan itu hanya muncul sekali — tidak muncul lagi saat refresh.

Cara kerja:
1. **Set flash**: Simpan pesan di `$_SESSION['flash']` sebelum redirect
2. **Redirect**: `header('Location: ...')` ke halaman tujuan
3. **Display**: Di halaman tujuan, baca dan tampilkan `$_SESSION['flash']`
4. **Unset**: Hapus `$_SESSION['flash']` setelah ditampilkan

Helper function umum:
```php
function setFlash(string $key, string $message, string $type = 'success'): void {
    $_SESSION['flash'][$key] = ['message' => $message, 'type' => $type];
}

function getFlash(string $key): ?array {
    if (isset($_SESSION['flash'][$key])) {
        $flash = $_SESSION['flash'][$key];
        unset($_SESSION['flash'][$key]);
        return $flash;
    }
    return null;
}
```

## Fungsi
Memberikan umpan balik (feedback) instan ke pengguna setelah suatu aksi — tanpa risiko pesan muncul berulang kali. Meningkatkan user experience dengan notifikasi yang bersih sekali lihat.

## Cara Pengimplementasian / Code
```php
<?php
// =====================
// HELPER FUNCTIONS — file: helpers.php
// =====================
function setFlash(string $key, string $message, string $type = 'success'): void {
    $_SESSION['flash'][$key] = ['message' => $message, 'type' => $type];
}

function getFlash(string $key): ?array {
    if (isset($_SESSION['flash']) && isset($_SESSION['flash'][$key])) {
        $flash = $_SESSION['flash'][$key];
        unset($_SESSION['flash'][$key]);
        return $flash;
    }
    return null;
}

function hasFlash(string $key): bool {
    return isset($_SESSION['flash'][$key]);
}

function displayFlash(): void {
    if (!empty($_SESSION['flash'])) {
        foreach ($_SESSION['flash'] as $key => $flash) {
            $type = $flash['type'] === 'error' ? 'error' : 'success';
            echo "<div class='flash flash-$type'>{$flash['message']}</div>";
        }
        $_SESSION['flash'] = [];
    }
}
?>

<?php
// =====================
// PROSES PINJAM — file: proses_pinjam.php
// =====================
session_start();
require_once 'helpers.php';

$judulBuku = $_POST['judul_buku'] ?? '';

// Simulasi logika peminjaman
if ($judulBuku === '') {
    setFlash('pinjam_error', 'Judul buku tidak boleh kosong.', 'error');
    header('Location: form_pinjam.php');
    exit;
}

// Sukses
setFlash('pinjam_sukses', "Buku '$judulBuku' berhasil dipinjam! Selamat membaca.");
header('Location: dashboard.php');
exit;
?>

<?php
// =====================
// DASHBOARD — file: dashboard.php
// =====================
session_start();
require_once 'helpers.php';
?>
<!DOCTYPE html>
<html>
<head>
<style>
.flash { padding: 12px; margin: 10px 0; border-radius: 4px; }
.flash-success { background: #d4edda; color: #155724; border: 1px solid #c3e6cb; }
.flash-error   { background: #f8d7da; color: #721c24; border: 1px solid #f5c6cb; }
</style>
</head>
<body>
    <h1>Dashboard Perpustakaan</h1>

    <?php displayFlash(); ?>

    <p>Selamat datang di sistem perpustakaan.</p>
    <a href="form_pinjam.php">Pinjam Buku</a>
</body>
</html>
```

## Analogi
Flash message seperti **pengumuman yang ditempel di papan informasi perpustakaan, lalu disobek setelah dibaca**. Saat kamu berhasil meminjam buku, pustakawan menempel notifikasi "Peminjaman berhasil!" di papan. Kamu lihat, baca, lalu petugas segera merobeknya — saat pengunjung lain datang, pengumuman itu sudah tidak ada. Kalau kamu refresh halaman, tidak muncul lagi karena sudah disobek (di-unset dari session).

## Dipakai untuk Apa
- **Notifikasi sukses**: "Buku berhasil dipinjam!", "Data anggota tersimpan!"
- **Notifikasi error**: "Username sudah terdaftar!", "Buku tidak tersedia."
- **Pesan warning**: "Masa peminjaman Anda akan habis besok."
- **Konfirmasi aksi**: Setelah hapus data — "Buku berhasil dihapus dari katalog."
- **Multi-step form**: "Langkah 1 selesai. Silakan lanjut ke langkah 2."

## Kesalahan Umum yang Sering Terjadi
- **Flash muncul terus-menerus**: Lupa unset session setelah ditampilkan — pesan muncul setiap refresh.
- **Pesan hilang sebelum sempat dilihat**: Redirect terjadi tapi flash belum disimpan — urutan eksekusi salah.
- **Session belum dimulai**: `session_start()` harus dipanggil sebelum set/get flash.
- **Flash menumpuk**: Tidak membersihkan array flash lama — pesan lama dan baru tampil bersamaan.
- **Typo key**: `setFlash('sukses', ...)` lalu `getFlash('sukses')` — beda ejaan, flash tidak muncul.
- **Output sebelum redirect**: Ada `echo` atau spasi sebelum `header()` — redirect gagal, flash mungkin tidak sempat di-load.

## Hubungan dengan Materi Sebelumnya
Flash messages adalah **aplikasi langsung dari session** (materi 20) — memanfaatkan `$_SESSION` sebagai penyimpanan sementara. Materi 15 (fungsi) dipakai untuk membuat helper `setFlash()` dan `getFlash()`. Materi 18-19 (form handling & validasi) adalah sumber dari pesan yang akan ditampilkan sebagai flash — validasi gagal → set flash error, sukses → set flash sukses.

## Soal Latihan & Jawaban
### Soal
Buat sistem flash message sederhana di satu file `flash_test.php`. Saat halaman dibuka dengan parameter GET `?aksi=simpan`, set flash "Data berhasil disimpan!". Jika parameter GET `?aksi=hapus`, set flash "Data berhasil dihapus!". Tampilkan flash message di bagian atas halaman dan pastikan tidak muncul saat refresh.

### Jawaban
```php
<?php
session_start();

// Proses aksi
if (isset($_GET['aksi'])) {
    if ($_GET['aksi'] === 'simpan') {
        $_SESSION['flash'] = ['message' => 'Data berhasil disimpan!', 'type' => 'success'];
    } elseif ($_GET['aksi'] === 'hapus') {
        $_SESSION['flash'] = ['message' => 'Data berhasil dihapus!', 'type' => 'error'];
    }
    header('Location: flash_test.php');
    exit;
}
?>
<!DOCTYPE html>
<html>
<body>
    <?php if (isset($_SESSION['flash'])): ?>
        <div style="padding:10px;background:<?= $_SESSION['flash']['type'] === 'success' ? '#d4edda' : '#f8d7da' ?>">
            <?= $_SESSION['flash']['message'] ?>
        </div>
        <?php unset($_SESSION['flash']); ?>
    <?php endif; ?>

    <h2>Demo Flash Message</h2>
    <a href="?aksi=simpan">Simpan Data</a> |
    <a href="?aksi=hapus">Hapus Data</a>
</body>
</html>
```
