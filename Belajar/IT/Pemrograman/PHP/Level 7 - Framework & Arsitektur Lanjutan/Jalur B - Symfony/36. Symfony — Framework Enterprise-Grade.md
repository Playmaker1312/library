# Symfony — Framework Enterprise-Grade

## Penjelasan

**Symfony** adalah framework PHP berarsitektur modular yang dirilis pertama kali oleh Fabien Potencier pada tahun 2005. Symfony dikenal sebagai framework **enterprise-grade** — stabil, terstruktur ketat, dan digunakan oleh proyek-proyek besar seperti Drupal, phpBB, Composer sendiri, dan ribuan aplikasi enterprise di Eropa. Berbeda dengan Laravel yang mengutamakan kemudahan dan kecepatan development, Symfony mengutamakan **konfigurasi eksplisit, komponen yang reusable, dan standar industri**.

Symfony terdiri dari lebih dari 50 **komponen independen** (HttpKernel, Routing, Console, Form, Security, Mailer, dll) yang bisa digunakan satu per satu tanpa framework penuh. Inilah yang membuat Symfony unik — Anda bisa menggunakan komponen Symfony (misal `symfony/http-foundation` atau `symfony/routing`) di proyek Laravel, WordPress, atau framework apapun.

### Arsitektur Symfony

```
Request → public/index.php → Kernel → 
  ├── Event: kernel.request → Router → Controller Resolver
  ├── Event: kernel.controller → Controller → Response
  ├── Event: kernel.response → Response
  └── Event: kernel.terminate → Cleanup
```

Symfony menggunakan **Event Dispatcher** sebagai tulang punggung — setiap tahap siklus hidup request memicu event yang bisa didengarkan oleh listener/subscriber. Ini membuat Symfony sangat extensible.

### Bundle System

Symfony menggunakan **Bundle** sebagai unit modular — setiap fitur adalah bundle (AppBundle, FrameworkBundle, SecurityBundle, DoctrineBundle). Bundle bisa dipasang, diaktifkan, atau dinonaktifkan di `config/bundles.php`. Mirip dengan package Laravel, tapi lebih terstruktur.

### Konfigurasi YAML/XML/PHP

Symfony mendukung tiga format konfigurasi: YAML (paling umum), XML, dan PHP. Konfigurasi disimpan di direktori `config/`:

```
config/
├── packages/       # Konfigurasi per environment
│   ├── framework.yaml
│   ├── doctrine.yaml
│   └── security.yaml
├── routes/         # Definisi route
│   ├── annotations.yaml
│   └── api.yaml
└── services.yaml   # Service container configuration
```

### Doctrine ORM

Symfony menggunakan **Doctrine** sebagai ORM default (bukan Active Record seperti Eloquent). Doctrine menggunakan **Data Mapper pattern** — entity adalah class PHP biasa (POPO — Plain Old PHP Object) tanpa tahu cara penyimpanannya. Repository terpisah dari Entity. Pendekatan ini lebih "bersih" secara arsitektur tetapi membutuhkan lebih banyak boilerplate dibanding Active Record.

```
Entity (POPO)         →  Repository (query)    →  Database
   ↑                          ↑
EntityManager (unit of work)  ManagerRegistry
```

### Symfony Console

Symfony Console component adalah standar de facto untuk CLI di PHP — digunakan oleh Laravel Artisan (yang dibangun di atas Symfony Console), Composer, dan PHPUnit.

## Fungsi

Symfony menyediakan framework enterprise-grade dengan komponen yang stabil, teruji puluhan tahun, dan bisa digunakan secara independen. **HttpKernel** dan **Event Dispatcher** memberikan kontrol penuh atas siklus hidup request. **Security component** menyediakan autentikasi multi-provider (form, LDAP, OAuth, API key), firewall per route, voters untuk authorization granular. **Doctrine ORM** memberikan Data Mapper pattern yang lebih "bersih" secara arsitektur — entity tanpa dependency framework. **Form component** dengan data mappers dan validasi terintegrasi. **Serializer** untuk transform data (JSON, XML, YAML, CSV) dengan normalizer dan encoder. **Validator** dengan constraint annotations/YAML/XML. **Translation** dengan ICU message format. Symfony juga memiliki **LTS (Long Term Support)** — setiap rilis mayor didukung 3 tahun untuk bug fix dan 4 tahun untuk security.

// 1. ENTITY — Plain Old PHP Object (src/Entity/Buku.php)

namespace App\Entity;

use App\Repository\BukuRepository;
use Doctrine\Common\Collections\ArrayCollection;
use Doctrine\Common\Collections\Collection;
use Doctrine\DBAL\Types\Types;
use Doctrine\ORM\Mapping as ORM;
use Symfony\Component\Validator\Constraints as Assert;

#[ORM\Entity(repositoryClass: BukuRepository::class)]
#[ORM\Table(name: 'buku')]
class Buku
{
    #[ORM\Id]
    #[ORM\GeneratedValue]
    #[ORM\Column(type: Types::INTEGER)]
    private ?int $id = null;

    #[ORM\Column(type: Types::STRING, length: 255)]
    #[Assert\NotBlank(message: 'Judul buku tidak boleh kosong')]
    #[Assert\Length(max: 255)]
    private ?string $judul = null;

    #[ORM\Column(type: Types::STRING, length: 255)]
    #[Assert\NotBlank]
    private ?string $pengarang = null;

    #[ORM\Column(type: Types::STRING, length: 255, nullable: true)]
    private ?string $penerbit = null;

    #[ORM\Column(type: Types::INTEGER, nullable: true)]
    #[Assert\Range(min: 1900, max: 2099)]
    private ?int $tahunTerbit = null;

    #[ORM\Column(type: Types::STRING, length: 13, nullable: true, unique: true)]
    #[Assert\Isbn(type: 'isbn13')]
    private ?string $isbn = null;

    #[ORM\Column(type: Types::INTEGER, nullable: true)]
    private ?int $jumlahHalaman = null;

    #[ORM\ManyToOne(targetEntity: Kategori::class, inversedBy: 'buku')]
    #[ORM\JoinColumn(nullable: false)]
    private ?Kategori $kategori = null;

    #[ORM\Column(type: Types::STRING, length: 20, options: ['default' => 'tersedia'])]
    private string $status = 'tersedia';

    #[ORM\Column(type: Types::TEXT, nullable: true)]
    private ?string $deskripsi = null;

    #[ORM\Column(type: Types::STRING, length: 255, nullable: true)]
    private ?string $sampul = null;

    #[ORM\OneToMany(mappedBy: 'buku', targetEntity: Peminjaman::class)]
    private Collection $peminjaman;

    #[ORM\Column(type: Types::DATETIME_IMMUTABLE)]
    private ?\DateTimeImmutable $createdAt = null;

    #[ORM\Column(type: Types::DATETIME_IMMUTABLE, nullable: true)]
    private ?\DateTimeImmutable $updatedAt = null;

    public function __construct()
    {
        $this->peminjaman = new ArrayCollection();
        $this->createdAt = new \DateTimeImmutable();
    }

    // Getters dan Setters (hanya beberapa contoh)
    public function getId(): ?int { return $this->id; }

    public function getJudul(): ?string { return $this->judul; }
    public function setJudul(string $judul): self {
        $this->judul = $judul;
        return $this;
    }

    public function getPengarang(): ?string { return $this->pengarang; }
    public function setPengarang(string $pengarang): self {
        $this->pengarang = $pengarang;
        return $this;
    }

    public function getStatus(): string { return $this->status; }
    public function setStatus(string $status): self {
        if (!in_array($status, ['tersedia', 'dipinjam', 'rusak', 'hilang'])) {
            throw new \InvalidArgumentException("Status '$status' tidak valid");
        }
        $this->status = $status;
        return $this;
    }

    public function getKategori(): ?Kategori { return $this->kategori; }
    public function setKategori(?Kategori $kategori): self {
        $this->kategori = $kategori;
        return $this;
    }

    public function getPeminjaman(): Collection { return $this->peminjaman; }

    public function isTersedia(): bool {
        return $this->status === 'tersedia';
    }

    public function getCreatedAt(): ?\DateTimeImmutable { return $this->createdAt; }
}

// 2. REPOSITORY (src/Repository/BukuRepository.php)
// =====================================================

namespace App\Repository;

use App\Entity\Buku;
use Doctrine\Bundle\DoctrineBundle\Repository\ServiceEntityRepository;
use Doctrine\Persistence\ManagerRegistry;

/**
 * @extends ServiceEntityRepository<Buku>
 */
class BukuRepository extends ServiceEntityRepository
{
    public function __construct(ManagerRegistry $registry)
    {
        parent::__construct($registry, Buku::class);
    }

    /**
     * @param string $keyword
     * @return Buku[]
     */
    public function cari(string $keyword): array
    {
        return $this->createQueryBuilder('b')
            ->leftJoin('b.kategori', 'k')
            ->where('b.judul LIKE :keyword')
            ->orWhere('b.pengarang LIKE :keyword')
            ->orWhere('b.isbn LIKE :keyword')
            ->setParameter('keyword', "%{$keyword}%")
            ->orderBy('b.judul', 'ASC')
            ->getQuery()
            ->getResult();
    }

    /**
     * @return Buku[]
     */
    public function findTersedia(): array
    {
        return $this->createQueryBuilder('b')
            ->where('b.status = :status')
            ->setParameter('status', 'tersedia')
            ->orderBy('b.judul', 'ASC')
            ->getQuery()
            ->getResult();
    }

    /**
     * @param string $isbn
     * @return Buku|null
     */
    public function findOneByIsbn(string $isbn): ?Buku
    {
        return $this->findOneBy(['isbn' => $isbn]);
    }

    /**
     * @param string $orderBy
     * @param string $direction
     * @return Buku[]
     */
    public function findAllOrdered(string $orderBy = 'judul', string $direction = 'ASC'): array
    {
        $allowedFields = ['judul', 'pengarang', 'tahunTerbit', 'createdAt'];
        $field = in_array($orderBy, $allowedFields) ? 'b.' . $orderBy : 'b.judul';
        $dir = strtoupper($direction) === 'DESC' ? 'DESC' : 'ASC';

        return $this->createQueryBuilder('b')
            ->orderBy($field, $dir)
            ->getQuery()
            ->getResult();
    }

    /**
     * Buku yang paling sering dipinjam
     * @param int $limit
     * @return array
     */
    public function findTerpopuler(int $limit = 10): array
    {
        return $this->createQueryBuilder('b')
            ->select('b, COUNT(p.id) as totalPinjam')
            ->leftJoin('b.peminjaman', 'p')
            ->groupBy('b.id')
            ->orderBy('totalPinjam', 'DESC')
            ->setMaxResults($limit)
            ->getQuery()
            ->getResult();
    }
}

namespace App\Controller;

use App\Entity\Buku;
use App\Form\BukuType;
use App\Repository\BukuRepository;
use Doctrine\ORM\EntityManagerInterface;
use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\JsonResponse;
use Symfony\Component\HttpFoundation\Request;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Routing\Annotation\Route;

#[Route('/buku')]
class BukuController extends AbstractController
{
    public function __construct(
        private BukuRepository $bukuRepo,
        private EntityManagerInterface $em,
    ) {}

    // GET /buku
    #[Route('/', name: 'buku_index', methods: ['GET'])]
    public function index(Request $request): Response
    {
        $keyword = $request->query->get('cari');
        $orderBy = $request->query->get('order_by', 'judul');

        $buku = $keyword
            ? $this->bukuRepo->cari($keyword)
            : $this->bukuRepo->findAllOrdered($orderBy);

        return $this->render('buku/index.html.twig', [
            'buku'    => $buku,
            'keyword' => $keyword,
        ]);
    }

    // GET /buku/baru
    #[Route('/baru', name: 'buku_new', methods: ['GET', 'POST'])]
    public function new(Request $request): Response
    {
        $buku = new Buku();
        $form = $this->createForm(BukuType::class, $buku);
        $form->handleRequest($request);

        if ($form->isSubmitted() && $form->isValid()) {
            if ($sampul = $form->get('sampul')->getData()) {
                $filename = uniqid() . '.' . $sampul->guessExtension();
                $sampul->move($this->getParameter('sampul_directory'), $filename);
                $buku->setSampul($filename);
            }

            $this->em->persist($buku);
            $this->em->flush();

            $this->addFlash('success', "Buku \"{$buku->getJudul()}\" berhasil ditambahkan");

            return $this->redirectToRoute('buku_index');
        }

        return $this->render('buku/new.html.twig', [
            'form' => $form->createView(),
        ]);
    }

    // GET /buku/{id}
    #[Route('/{id}', name: 'buku_show', methods: ['GET'])]
    public function show(Buku $buku): Response
    {
        return $this->render('buku/show.html.twig', [
            'buku' => $buku,
        ]);
    }

    // GET/POST /buku/{id}/edit
    #[Route('/{id}/edit', name: 'buku_edit', methods: ['GET', 'POST'])]
    public function edit(Request $request, Buku $buku): Response
    {
        $form = $this->createForm(BukuType::class, $buku);
        $form->handleRequest($request);

        if ($form->isSubmitted() && $form->isValid()) {
            $buku->setUpdatedAt(new \DateTimeImmutable());

            if ($sampul = $form->get('sampul')->getData()) {
                $filename = uniqid() . '.' . $sampul->guessExtension();
                $sampul->move($this->getParameter('sampul_directory'), $filename);
                $buku->setSampul($filename);
            }

            $this->em->flush();

            $this->addFlash('success', 'Data buku berhasil diperbarui');
            return $this->redirectToRoute('buku_show', ['id' => $buku->getId()]);
        }

        return $this->render('buku/edit.html.twig', [
            'form' => $form->createView(),
            'buku' => $buku,
        ]);
    }

    // DELETE /buku/{id}
    #[Route('/{id}', name: 'buku_delete', methods: ['DELETE'])]
    public function delete(Request $request, Buku $buku): Response
    {
        if ($this->isCsrfTokenValid('delete' . $buku->getId(), $request->request->get('_token'))) {
            $this->em->remove($buku);
            $this->em->flush();
            $this->addFlash('success', 'Buku berhasil dihapus');
        }

        return $this->redirectToRoute('buku_index');
    }

    // GET /buku/isbn/{isbn}
    #[Route('/isbn/{isbn}', name: 'buku_by_isbn', methods: ['GET'])]
    public function cariByIsbn(string $isbn): JsonResponse
    {
        $buku = $this->bukuRepo->findOneByIsbn($isbn);

        if (!$buku) {
            return $this->json(['message' => 'Buku tidak ditemukan'], Response::HTTP_NOT_FOUND);
        }

        return $this->json($buku);
    }
}

namespace App\Form;

use App\Entity\Buku;
use App\Entity\Kategori;
use Symfony\Bridge\Doctrine\Form\Type\EntityType;
use Symfony\Component\Form\AbstractType;
use Symfony\Component\Form\Extension\Core\Type\ChoiceType;
use Symfony\Component\Form\Extension\Core\Type\DateType;
use Symfony\Component\Form\Extension\Core\Type\FileType;
use Symfony\Component\Form\Extension\Core\Type\IntegerType;
use Symfony\Component\Form\Extension\Core\Type\TextareaType;
use Symfony\Component\Form\Extension\Core\Type\TextType;
use Symfony\Component\Form\FormBuilderInterface;
use Symfony\Component\OptionsResolver\OptionsResolver;
use Symfony\Component\Validator\Constraints\File;

class BukuType extends AbstractType
{
    public function buildForm(FormBuilderInterface $builder, array $options): void
    {
        $builder
            ->add('judul', TextType::class, [
                'label' => 'Judul Buku',
                'attr'  => ['placeholder' => 'Masukkan judul buku'],
            ])
            ->add('pengarang', TextType::class, [
                'label' => 'Pengarang',
            ])
            ->add('penerbit', TextType::class, [
                'label'    => 'Penerbit',
                'required' => false,
            ])
            ->add('tahunTerbit', IntegerType::class, [
                'label'    => 'Tahun Terbit',
                'required' => false,
                'attr'     => ['min' => 1900, 'max' => date('Y')],
            ])
            ->add('isbn', TextType::class, [
                'label'    => 'ISBN',
                'required' => false,
            ])
            ->add('jumlahHalaman', IntegerType::class, [
                'label'    => 'Jumlah Halaman',
                'required' => false,
            ])
            ->add('kategori', EntityType::class, [
                'class'        => Kategori::class,
                'choice_label' => 'nama',
                'label'        => 'Kategori',
                'placeholder'  => 'Pilih kategori',
            ])
            ->add('status', ChoiceType::class, [
                'choices' => [
                    'Tersedia' => 'tersedia',
                    'Dipinjam' => 'dipinjam',
                    'Rusak'    => 'rusak',
                    'Hilang'   => 'hilang',
                ],
                'label' => 'Status',
            ])
            ->add('deskripsi', TextareaType::class, [
                'label'    => 'Deskripsi',
                'required' => false,
            ])
            ->add('sampul', FileType::class, [
                'label'    => 'Sampul Buku',
                'required' => false,
                'mapped'   => false,
                'constraints' => [
                    new File([
                        'maxSize'   => '2M',
                        'mimeTypes' => ['image/jpeg', 'image/png', 'image/webp'],
                    ]),
                ],
            ]);
    }

    public function configureOptions(OptionsResolver $resolver): void
    {
        $resolver->setDefaults([
            'data_class' => Buku::class,
        ]);
    }
}

// 9. SYMFONY CONSOLE COMMAND (src/Command/CekDendaCommand.php)
// =====================================================

namespace App\Command;

use App\Repository\PeminjamanRepository;
use Symfony\Component\Console\Attribute\AsCommand;
use Symfony\Component\Console\Command\Command;
use Symfony\Component\Console\Input\InputInterface;
use Symfony\Component\Console\Output\OutputInterface;
use Symfony\Component\Console\Style\SymfonyStyle;

#[AsCommand(
    name: 'app:cek-denda',
    description: 'Cek peminjaman yang terlambat dan hitung denda',
)]
class CekDendaCommand extends Command
{
    public function __construct(
        private PeminjamanRepository $peminjamanRepo,
    ) {
        parent::__construct();
    }

    protected function execute(InputInterface $input, OutputInterface $output): int
    {
        $io = new SymfonyStyle($input, $output);
        $io->title('Pengecekan Denda Perpustakaan');

        $peminjamanTerlambat = $this->peminjamanRepo->findTerlambat();

        if (empty($peminjamanTerlambat)) {
            $io->success('Tidak ada peminjaman terlambat.');
            return Command::SUCCESS;
        }

        $io->section('Peminjaman Terlambat:');
        $totalDenda = 0;

        foreach ($peminjamanTerlambat as $peminjaman) {
            $hariTelat = (new \DateTime())->diff($peminjaman->getTanggalJatuhTempo())->days;
            $denda = $hariTelat * 2000;
            $totalDenda += $denda;

            $io->writeln([
                sprintf('- %s oleh %s (telat %d hari, denda: Rp %s)',
                    $peminjaman->getBuku()->getJudul(),
                    $peminjaman->getAnggota()->getNama(),
                    $hariTelat,
                    number_format($denda, 0, ',', '.')
                ),
            ]);
        }

        $io->success(sprintf('Total denda yang harus dibayar: Rp %s', number_format($totalDenda, 0, ',', '.')));

        return Command::SUCCESS;
    }
}

## Analogi

Symfony adalah **sistem manajemen perpustakaan enterprise yang distandarisasi secara internasional** — seperti perpustakaan nasional dengan prosedur ISO.

- **Entity (Doctrine)** adalah **kartu katalog resmi** dengan format standar — setiap entitas (buku, anggota, peminjaman) memiliki format data yang ketat dan seragam, tidak boleh ada kolom yang asal-asalan. Ini adalah "Plain Old PHP Object" — murni data tanpa tahu di mana disimpan.
- **Repository** adalah **petugas khusus pencarian buku** — pustakawan tidak perlu tahu buku disimpan di rak mana, cukup bertanya ke petugas repository, "Tolong cari semua buku karya Pramoedya yang tersedia." Petugas akan mengurus query-nya.
- **Event Dispatcher** adalah **sistem notifikasi perpustakaan** — setiap kali buku dipinjam, sistem mengirim event: "buku dipinjam" → didengar oleh listener "kirim email notifikasi", listener "update statistik peminjaman", listener "catat log". Semua terjadi otomatis tanpa perlu kode yang saling terkait.
- **Form Type** adalah **formulir standar perpustakaan** — setiap formulir (pendaftaran anggota, peminjaman, pengembalian) sudah memiliki format baku dengan validasi terintegrasi. Petugas tinggal mengisi, sistem akan memvalidasi otomatis.
- **Security & Voters** adalah **sistem akses kartu anggota** — ada anggota biasa (ROLE_USER), petugas (ROLE_PETUGAS), dan kepala perpustakaan (ROLE_ADMIN). Voter adalah aturan: "Apakah anggota ini boleh meminjam buku referensi?" — aturan ditulis eksplisit, bukan hardcoded di controller.
- **Bundle** adalah **modul perpustakaan yang bisa dipasang-dilepas** — butuh modul peminjaman antar cabang? Pasang bundle. Butuh sistem denda otomatis? Pasang bundle. Setiap modul independen dan bisa di-share antar proyek.
- **Konfigurasi YAML** adalah **buku pedoman perpustakaan** — semua aturan ditulis rapi di satu tempat: siapa yang boleh akses rak mana, berapa lama batas peminjaman, berapa denda per hari. Tidak ada aturan yang tersembunyi di dalam kode.
- **LTS (Long Term Support)** adalah **standarisasi prosedur perpustakaan** — setiap 3 tahun prosedur dievaluasi dan distandarisasi ulang, memastikan semua cabang perpustakaan menggunakan sistem yang stabil dan terdukung.

## Dipakai untuk Apa

- **Aplikasi enterprise skala besar** — sistem ERP, CRM, HRIS, financial management dengan ribuan pengguna simultan
- **API platform** — REST API dengan API Platform (Symfony Project), GraphQL dengan OverblogGraphQLBundle
- **CMS dan portal berita** — Drupal (built on Symfony), portal berita pemerintah, e-government
- **Aplikasi finansial dan perbankan** — stabilitas dan security audit trail Symfony cocok untuk sistem yang membutuhkan kepatuhan regulasi
- **Microservices** — komponen Symfony bisa dipakai independen di setiap service
- **Sistem warisan (legacy) modernization** — komponen Symfony bisa diintegrasikan bertahap ke codebase lama
- **Proyek open source besar** — Composer, phpBB, Drupal, Magento (sebagian), Behat, PHPUnit (Console component) menggunakan komponen Symfony
- **Single-Page Application backend** — Symfony + API Platform untuk backend, frontend React/Vue/Angular

## Kesalahan Umum yang Sering Terjadi

- **Entity sebagai DTO**: Mengirim entity langsung ke view atau API response — entity yang sudah di-load bisa memicu lazy loading queries di Twig. Solusi: buat DTO atau custom normalizer.
- **Lupa flush setelah persist**: `$em->persist($entity)` tanpa `$em->flush()` — data tidak tersimpan. Solusi: selalu panggil `flush()` setelah persist.
- **N+1 query di Doctrine**: Relasi LAZY tidak di-eager load — loop 100 entity mengakses relasi menghasilkan 101 query. Solusi: gunakan `$query->setFetchMode()` atau `LEFT JOIN` di DQL.
- **Form tidak di-handleRequest**: Form dirender tapi `handleRequest()` tidak dipanggil — data tidak terisi. Solusi: selalu panggil `$form->handleRequest($request)`.
- **CSRF token tidak cocok**: Form Symfony memiliki CSRF protection bawaan — jika token expired atau tidak cocok, form rejected. Solusi: pastikan session valid dan token di-render.
- **Security voters tidak terdaftar**: Voter custom dibuat tapi tidak didaftarkan sebagai service — Symfony tidak tahu voter tersebut ada. Solusi: daftarkan sebagai service dengan tag `security.voter`.
- **Konfigurasi environment tidak terpisah**: Semua konfigurasi sama untuk dev dan prod — debug toolbar muncul di production. Solusi: gunakan file `config/packages/dev/` dan `config/packages/prod/`.
- **Migrations tidak di-version control**: File migrasi tidak di-commit — developer lain tidak bisa migrate. Solusi: commit semua file migrasi.
- **Cache tidak di-clear setelah perubahan**: Ubah service configuration tapi cache lama masih dipakai. Solusi: `php bin/console cache:clear` setelah perubahan konfigurasi.
- **Autowiring error karena multiple implementations**: Interface memiliki beberapa implementasi — container tidak tahu mana yang harus di-inject. Solusi: gunakan tag `#[AsTaggedItem]` atau binding manual di `services.yaml`.

Materi 23-25 (OOP) adalah fondasi mutlak Symfony — Entity, Controller, Service, Repository semuanya adalah class. Interface dan Trait (materi 25) digunakan intensif di Symfony (EventSubscriberInterface, KernelEvents, VoterInterface). Materi 26-27 (PDO & Prepared Statements) digantikan oleh Doctrine ORM — Anda tidak menulis SQL manual, tetapi DQL (Doctrine Query Language). ## Soal Latihan & Jawaban

### Soal

Buat fitur **manajemen kategori buku** dengan Symfony + Doctrine dengan ketentuan:

1. **Entity `Kategori`**: kolom `id` (auto), `nama` (string 100, unique), `slug` (string 100, unique, auto-generated dari nama), `deskripsi` (text nullable), `createdAt` (datetime_immutable), `updatedAt` (datetime_immutable nullable).
2. **Repository `KategoriRepository`**: method `findByNama(string $keyword): array` (cari LIKE), `findOneBySlug(string $slug): ?Kategori`.
3. **Controller `KategoriController`** dengan route:
   - `GET /kategori` — daftar semua kategori (hanya ROLE_PETUGAS dan ROLE_ADMIN)
   - `GET /kategori/baru` — form tambah kategori
   - `POST /kategori` — simpan kategori baru
   - `GET /kategori/{slug}` — detail kategori + daftar buku dalam kategori tersebut
   - `DELETE /kategori/{id}` — hapus kategori (hanya jika tidak ada buku terkait)
4. **Slug**: Buat method `setSlug()` di entity yang meng-generate slug dari nama (ganti spasi dengan `-`, lowercase, buang karakter spesial).
5. **Validasi**: Nama kategori harus unique dan minimal 3 karakter.

Tulis kode Entity, Repository, Controller (method baru, index, show, delete), dan validasi.

<?php

// =====================
// FILE: src/Entity/Kategori.php
// =====================

namespace App\Entity;

use App\Repository\KategoriRepository;
use Doctrine\Common\Collections\ArrayCollection;
use Doctrine\Common\Collections\Collection;
use Doctrine\DBAL\Types\Types;
use Doctrine\ORM\Mapping as ORM;
use Symfony\Component\Validator\Constraints as Assert;

#[ORM\Entity(repositoryClass: KategoriRepository::class)]
#[ORM\Table(name: 'kategori')]
class Kategori
{
    #[ORM\Id]
    #[ORM\GeneratedValue]
    #[ORM\Column(type: Types::INTEGER)]
    private ?int $id = null;

    #[ORM\Column(type: Types::STRING, length: 100, unique: true)]
    #[Assert\NotBlank(message: 'Nama kategori tidak boleh kosong')]
    #[Assert\Length(
        min: 3,
        max: 100,
        minMessage: 'Nama kategori minimal {{ limit }} karakter',
    )]
    private ?string $nama = null;

    #[ORM\Column(type: Types::STRING, length: 100, unique: true)]
    private ?string $slug = null;

    #[ORM\Column(type: Types::TEXT, nullable: true)]
    private ?string $deskripsi = null;

    #[ORM\OneToMany(mappedBy: 'kategori', targetEntity: Buku::class)]
    private Collection $buku;

    #[ORM\Column(type: Types::DATETIME_IMMUTABLE)]
    private ?\DateTimeImmutable $createdAt = null;

    #[ORM\Column(type: Types::DATETIME_IMMUTABLE, nullable: true)]
    private ?\DateTimeImmutable $updatedAt = null;

    public function __construct()
    {
        $this->buku = new ArrayCollection();
        $this->createdAt = new \DateTimeImmutable();
    }

    public function getId(): ?int { return $this->id; }

    public function getNama(): ?string { return $this->nama; }

    public function setNama(string $nama): self
    {
        $this->nama = $nama;
        // Auto-generate slug saat nama diubah
        $this->setSlug($this->generateSlug($nama));
        return $this;
    }

    public function getSlug(): ?string { return $this->slug; }

    public function setSlug(string $slug): self
    {
        $this->slug = $slug;
        return $this;
    }

    public function getDeskripsi(): ?string { return $this->deskripsi; }
    public function setDeskripsi(?string $deskripsi): self
    {
        $this->deskripsi = $deskripsi;
        return $this;
    }

    public function getBuku(): Collection { return $this->buku; }

    public function getCreatedAt(): ?\DateTimeImmutable { return $this->createdAt; }
    public function setCreatedAt(\DateTimeImmutable $createdAt): self
    {
        $this->createdAt = $createdAt;
        return $this;
    }

    public function getUpdatedAt(): ?\DateTimeImmutable { return $this->updatedAt; }
    public function setUpdatedAt(?\DateTimeImmutable $updatedAt): self
    {
        $this->updatedAt = $updatedAt;
        return $this;
    }

    /**
     * Generate URL-friendly slug dari string
     */
    private function generateSlug(string $string): string
    {
        // Ganti non-alfanumerik (kecuali spasi) dengan kosong
        $string = preg_replace('/[^\p{L}\p{N}\s]/u', '', $string);
        // Ganti spasi dengan -
        $slug = preg_replace('/\s+/', '-', trim($string));
        // Lowercase
        return mb_strtolower($slug);
    }

    public function __toString(): string
    {
        return $this->nama ?? '';
    }
}

// FILE: src/Repository/KategoriRepository.php
// =====================

namespace App\Repository;

use App\Entity\Kategori;
use Doctrine\Bundle\DoctrineBundle\Repository\ServiceEntityRepository;
use Doctrine\Persistence\ManagerRegistry;

/**
 * @extends ServiceEntityRepository<Kategori>
 */
class KategoriRepository extends ServiceEntityRepository
{
    public function __construct(ManagerRegistry $registry)
    {
        parent::__construct($registry, Kategori::class);
    }

    /**
     * @param string $keyword
     * @return Kategori[]
     */
    public function findByNama(string $keyword): array
    {
        return $this->createQueryBuilder('k')
            ->where('k.nama LIKE :keyword')
            ->setParameter('keyword', "%{$keyword}%")
            ->orderBy('k.nama', 'ASC')
            ->getQuery()
            ->getResult();
    }

    public function findOneBySlug(string $slug): ?Kategori
    {
        return $this->findOneBy(['slug' => $slug]);
    }

    /**
     * @return Kategori[]
     */
    public function findAllWithBukuCount(): array
    {
        return $this->createQueryBuilder('k')
            ->select('k, COUNT(b.id) as jumlahBuku')
            ->leftJoin('k.buku', 'b')
            ->groupBy('k.id')
            ->orderBy('k.nama', 'ASC')
            ->getQuery()
            ->getResult();
    }
}

// FILE: src/Controller/KategoriController.php
// =====================

namespace App\Controller;

use App\Entity\Kategori;
use App\Repository\KategoriRepository;
use Doctrine\ORM\EntityManagerInterface;
use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\Request;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Routing\Annotation\Route;
use Symfony\Component\Validator\Validator\ValidatorInterface;

#[Route('/kategori')]
class KategoriController extends AbstractController
{
    public function __construct(
        private KategoriRepository $kategoriRepo,
        private EntityManagerInterface $em,
        private ValidatorInterface $validator,
    ) {}

    // GET /kategori
    #[Route('/', name: 'kategori_index', methods: ['GET'])]
    public function index(): Response
    {
        $this->denyAccessUnlessGranted('ROLE_PETUGAS');

        $kategori = $this->kategoriRepo->findAllWithBukuCount();

        return $this->render('kategori/index.html.twig', [
            'kategori' => $kategori,
        ]);
    }

    // GET /kategori/baru
    #[Route('/baru', name: 'kategori_new', methods: ['GET', 'POST'])]
    public function new(Request $request): Response
    {
        $this->denyAccessUnlessGranted('ROLE_ADMIN');

        if ($request->isMethod('POST')) {
            $kategori = new Kategori();
            $kategori->setNama($request->request->get('nama'));

            if ($deskripsi = $request->request->get('deskripsi')) {
                $kategori->setDeskripsi($deskripsi);
            }

            $errors = $this->validator->validate($kategori);

            if (count($errors) > 0) {
                foreach ($errors as $error) {
                    $this->addFlash('error', $error->getMessage());
                }
                return $this->render('kategori/new.html.twig', [
                    'kategori' => $kategori,
                ]);
            }

            // Cek unique slug
            $existing = $this->kategoriRepo->findOneBySlug($kategori->getSlug());
            if ($existing) {
                $this->addFlash('error', 'Kategori dengan nama tersebut sudah ada.');
                return $this->render('kategori/new.html.twig', [
                    'kategori' => $kategori,
                ]);
            }

            $this->em->persist($kategori);
            $this->em->flush();

            $this->addFlash('success', "Kategori \"{$kategori->getNama()}\" berhasil ditambahkan");
            return $this->redirectToRoute('kategori_index');
        }

        return $this->render('kategori/new.html.twig');
    }

    // GET /kategori/{slug}
    #[Route('/{slug}', name: 'kategori_show', methods: ['GET'])]
    public function show(Kategori $kategori): Response
    {
        return $this->render('kategori/show.html.twig', [
            'kategori' => $kategori,
            'buku'     => $kategori->getBuku(),
        ]);
    }

    // DELETE /kategori/{id}
    #[Route('/{id}', name: 'kategori_delete', methods: ['DELETE'])]
    public function delete(Request $request, Kategori $kategori): Response
    {
        $this->denyAccessUnlessGranted('ROLE_ADMIN');

        if (!$this->isCsrfTokenValid('delete' . $kategori->getId(), $request->request->get('_token'))) {
            $this->addFlash('error', 'Token CSRF tidak valid');
            return $this->redirectToRoute('kategori_index');
        }

        if (!$kategori->getBuku()->isEmpty()) {
            $this->addFlash('error', 'Kategori tidak bisa dihapus karena masih memiliki buku terkait.');
            return $this->redirectToRoute('kategori_index');
        }

        $nama = $kategori->getNama();
        $this->em->remove($kategori);
        $this->em->flush();

        $this->addFlash('success', "Kategori \"{$nama}\" berhasil dihapus");
        return $this->redirectToRoute('kategori_index');
    }
}
