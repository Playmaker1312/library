# Clean Architecture — Arsitektur yang Scalable

## Penjelasan

**Clean Architecture** adalah pola arsitektur perangkat lunak yang dipopulerkan oleh Robert C. Martin (Uncle Bob) pada tahun 2012. Tujuan utamanya adalah **memisahkan kepentingan (separation of concerns)** dengan aturan dependensi yang ketat: kode sumber hanya boleh bergantung ke arah **dalam** — framework, database, dan UI adalah **detail** yang bisa diganti tanpa mempengaruhi aturan bisnis inti.

Struktur Clean Architecture terdiri dari 4 lapisan (layer) konsentris:

```
| Infrastructure / Frameworks (Layer 4) |
  | Interface Adapters (Layer 3) |
    | Application / Use Cases (Layer 2) |
      | Domain / Entity (Layer 1) |
```

### Aturan Ketergantungan (The Dependency Rule)

**Aturan emas Clean Architecture**: Dependensi source code hanya boleh mengarah dari luar ke dalam. Layer dalam **tidak tahu apa pun** tentang layer luar. Domain entity tidak boleh meng-import nama class dari framework, database, atau controller.

### 4 Layer Clean Architecture

| Layer | Nama | Isi | Contoh di Perpustakaan |
|-------|------|-----|----------------------|
| **Layer 1** | **Domain** | Entity, Value Object, Repository Interface | `Buku`, `Anggota`, `BukuRepositoryInterface` |
| **Layer 2** | **Application** | Use Case / Interactor, DTO | `PinjamBukuUseCase`, `HitungDendaUseCase` |
| **Layer 3** | **Interface Adapters** | Controller, Presenter, Serializer | `BukuController`, `BukuResource` |
| **Layer 4** | **Infrastructure** | Framework, Database, Mail, API Client | `DoctrineBukuRepository`, `LaravelBukuController` |

### Prinsip SOLID dalam Clean Architecture

1. **Single Responsibility** — setiap class punya satu alasan untuk berubah
2. **Open-Closed** — terbuka untuk ekstensi, tertutup untuk modifikasi
3. **Liskov Substitution** — subclass bisa menggantikan parent class
4. **Interface Segregation** — interface spesifik, bukan general-purpose
5. **Dependency Inversion** — bergantung pada abstraksi, bukan konkret

## Fungsi

Clean Architecture memastikan **aturan bisnis (business rules) tidak terikat framework atau database tertentu**. Anda bisa mengganti Laravel ke Symfony, MySQL ke PostgreSQL, atau monolithic ke microservices tanpa mengubah kode Use Case atau Entity. Ini memberikan **testability maksimal** — Use Case bisa di-test tanpa framework, tanpa database, tanpa HTTP. Setiap layer bisa diuji secara independen. Clean Architecture juga memudahkan **kerja tim paralel** — tim backend fokus di Domain/Use Case, tim frontend fokus di Interface Adapters, tim infra fokus di Infrastructure. Dalam jangka panjang, biaya maintenance lebih rendah karena perubahan teknologi (framework upgrade, migrasi database) tidak berdampak pada kode bisnis inti.

namespace Perpustakaan\Domain\Entity;

class Buku
{
    public function __construct(
        private ?int $id,
        private string $judul,
        private string $pengarang,
        private string $isbn,
        private int $tahunTerbit,
        private StatusBuku $status = StatusBuku::TERSEDIA,
        private ?Kategori $kategori = null,
    ) {}

    public function getId(): ?int { return $this->id; }
    public function getJudul(): string { return $this->judul; }
    public function getPengarang(): string { return $this->pengarang; }
    public function getIsbn(): string { return $this->isbn; }
    public function getTahunTerbit(): int { return $this->tahunTerbit; }
    public function getStatus(): StatusBuku { return $this->status; }
    public function getKategori(): ?Kategori { return $this->kategori; }

    public function pinjam(): void
    {
        if ($this->status !== StatusBuku::TERSEDIA) {
            throw new \DomainException(
                "Buku '{$this->judul}' tidak tersedia untuk dipinjam (status: {$this->status->value})"
            );
        }
        $this->status = StatusBuku::DIPINJAM;
    }

    public function kembalikan(): void
    {
        if ($this->status !== StatusBuku::DIPINJAM) {
            throw new \DomainException(
                "Buku '{$this->judul}' sedang tidak dalam status dipinjam"
            );
        }
        $this->status = StatusBuku::TERSEDIA;
    }

    public function tandaiRusak(): void
    {
        $this->status = StatusBuku::RUSAK;
    }
}

class ISBN
{
    public function __construct(
        private readonly string $value,
    ) {
        if (!preg_match('/^(978|979)\d{10}$/', $value)) {
            throw new \InvalidArgumentException("Format ISBN tidak valid: $value");
        }
    }

    public function getValue(): string { return $this->value; }
    public function __toString(): string { return $this->value; }
}

enum StatusBuku: string
{
    case TERSEDIA = 'tersedia';
    case DIPINJAM = 'dipinjam';
    case RUSAK    = 'rusak';
    case HILANG   = 'hilang';
}

class Anggota
{
    public const int MAX_PINJAMAN = 3;

    public function __construct(
        private ?int $id,
        private string $nama,
        private string $email,
        private ?string $telepon = null,
        private int $jumlahPinjamanAktif = 0,
    ) {}

    public function getId(): ?int { return $this->id; }
    public function getNama(): string { return $this->nama; }
    public function getEmail(): string { return $this->email; }
    public function getTelepon(): ?string { return $this->telepon; }
    public function getJumlahPinjamanAktif(): int { return $this->jumlahPinjamanAktif; }

    public function tambahPinjaman(): void
    {
        if ($this->jumlahPinjamanAktif >= self::MAX_PINJAMAN) {
            throw new \DomainException(
                "Anggota '{$this->nama}' sudah mencapai batas maksimal peminjaman (" . self::MAX_PINJAMAN . ")"
            );
        }
        $this->jumlahPinjamanAktif++;
    }

    public function kurangiPinjaman(): void
    {
        if ($this->jumlahPinjamanAktif <= 0) {
            throw new \DomainException('Tidak ada peminjaman aktif untuk dikurangi');
        }
        $this->jumlahPinjamanAktif--;
    }
}

class Peminjaman
{
    public function __construct(
        private ?int $id,
        private Buku $buku,
        private Anggota $anggota,
        private \DateTimeImmutable $tanggalPinjam,
        private \DateTimeImmutable $tanggalJatuhTempo,
        private ?\DateTimeImmutable $tanggalKembali = null,
    ) {}

    public function getId(): ?int { return $this->id; }
    public function getBuku(): Buku { return $this->buku; }
    public function getAnggota(): Anggota { return $this->anggota; }
    public function getTanggalPinjam(): \DateTimeImmutable { return $this->tanggalPinjam; }
    public function getTanggalJatuhTempo(): \DateTimeImmutable { return $this->tanggalJatuhTempo; }
    public function getTanggalKembali(): ?\DateTimeImmutable { return $this->tanggalKembali; }

    public function isTerlambat(\DateTimeImmutable $sekarang = new \DateTimeImmutable()): bool
    {
        return $this->tanggalKembali === null && $sekarang > $this->tanggalJatuhTempo;
    }

    public function hitungDenda(\DateTimeImmutable $sekarang = new \DateTimeImmutable()): int
    {
        if ($this->tanggalKembali !== null) return 0;
        if ($sekarang <= $this->tanggalJatuhTempo) return 0;
        $hariTelat = $sekarang->diff($this->tanggalJatuhTempo)->days;
        return $hariTelat * 2000;
    }

    public function kembalikan(\DateTimeImmutable $tanggalKembali = new \DateTimeImmutable()): void
    {
        if ($this->tanggalKembali !== null) {
            throw new \DomainException('Buku sudah dikembalikan sebelumnya');
        }
        $this->tanggalKembali = $tanggalKembali;
        $this->buku->kembalikan();
    }
}

namespace Perpustakaan\Domain\Service;

use Perpustakaan\Domain\Entity\Peminjaman;

class DendaService
{
    private const int TARIF_PER_HARI = 2000;

    public function hitungDenda(Peminjaman $peminjaman, \DateTimeImmutable $sekarang = new \DateTimeImmutable()): int
    {
        return $peminjaman->hitungDenda($sekarang);
    }

    public function formatRupiah(int $jumlah): string
    {
        return 'Rp ' . number_format($jumlah, 0, ',', '.');
    }

    /** @return array<int, int> */
    public function hitungSemuaDenda(array $daftarPeminjaman): array
    {
        $sekarang = new \DateTimeImmutable();
        $hasil = [];
        foreach ($daftarPeminjaman as $peminjaman) {
            $denda = $this->hitungDenda($peminjaman, $sekarang);
            if ($denda > 0) $hasil[$peminjaman->getId()] = $denda;
        }
        return $hasil;
    }
}

<?php
// ============================================================
// LAYER 2: APPLICATION — Use Cases / Interactors
// ============================================================

namespace Perpustakaan\Application\UseCase;

use Perpustakaan\Domain\Entity\Peminjaman;
use Perpustakaan\Domain\Repository\AnggotaRepositoryInterface;
use Perpustakaan\Domain\Repository\BukuRepositoryInterface;
use Perpustakaan\Domain\Repository\PeminjamanRepositoryInterface;

class PinjamBukuUseCase
{
    public function __construct(
        private BukuRepositoryInterface $bukuRepo,
        private AnggotaRepositoryInterface $anggotaRepo,
        private PeminjamanRepositoryInterface $peminjamanRepo,
    ) {}

    public function execute(int $anggotaId, int $bukuId): Peminjaman
    {
        $buku = $this->bukuRepo->findById($bukuId)
            ?? throw new \DomainException("Buku dengan ID $bukuId tidak ditemukan");

        $anggota = $this->anggotaRepo->findById($anggotaId)
            ?? throw new \DomainException("Anggota dengan ID $anggotaId tidak ditemukan");

        $buku->pinjam();
        $anggota->tambahPinjaman();

        $peminjaman = new Peminjaman(
            id: null,
            buku: $buku,
            anggota: $anggota,
            tanggalPinjam: new \DateTimeImmutable(),
            tanggalJatuhTempo: new \DateTimeImmutable('+14 days'),
        );

        $this->peminjamanRepo->save($peminjaman);
        $this->bukuRepo->save($buku);
        $this->anggotaRepo->save($anggota);

        return $peminjaman;
    }
}

class KembalikanBukuUseCase
{
    public function __construct(
        private BukuRepositoryInterface $bukuRepo,
        private PeminjamanRepositoryInterface $peminjamanRepo,
        private AnggotaRepositoryInterface $anggotaRepo,
        private DendaService $dendaService,
    ) {}

    public function execute(int $peminjamanId): array
    {
        $peminjaman = $this->peminjamanRepo->findById($peminjamanId)
            ?? throw new \DomainException("Peminjaman dengan ID $peminjamanId tidak ditemukan");

        $tanggalKembali = new \DateTimeImmutable();
        $peminjaman->kembalikan($tanggalKembali);
        $peminjaman->getAnggota()->kurangiPinjaman();

        $denda = $this->dendaService->hitungDenda($peminjaman);

        $this->peminjamanRepo->save($peminjaman);
        $this->bukuRepo->save($peminjaman->getBuku());
        $this->anggotaRepo->save($peminjaman->getAnggota());

        $pesan = $denda > 0
            ? "Buku dikembalikan terlambat. Denda: {$this->dendaService->formatRupiah($denda)}"
            : 'Buku berhasil dikembalikan. Terima kasih!';

        return ['peminjaman' => $peminjaman, 'denda' => $denda, 'pesan' => $pesan];
    }
}

class CariBukuUseCase
{
    public function __construct(private BukuRepositoryInterface $bukuRepo) {}

    /** @return Buku[] */
    public function execute(?string $keyword = null): array
    {
        return $keyword ? $this->bukuRepo->findByKeyword($keyword) : $this->bukuRepo->findAll();
    }
}

namespace Perpustakaan\Interface\Controller;

use Perpustakaan\Application\DTO\BukuDTO;
use Perpustakaan\Application\DTO\PinjamBukuRequest;
use Perpustakaan\Application\UseCase\CariBukuUseCase;
use Perpustakaan\Application\UseCase\KembalikanBukuUseCase;
use Perpustakaan\Application\UseCase\PinjamBukuUseCase;

class BukuController
{
    public function __construct(
        private CariBukuUseCase $cariBuku,
        private PinjamBukuUseCase $pinjamBuku,
        private KembalikanBukuUseCase $kembalikanBuku,
    ) {}

    public function index(?string $keyword = null): array
    {
        return array_map(
            fn($buku) => new BukuDTO(
                id: $buku->getId(), judul: $buku->getJudul(),
                pengarang: $buku->getPengarang(), isbn: $buku->getIsbn(),
                tahunTerbit: $buku->getTahunTerbit(),
                status: $buku->getStatus()->value,
                kategori: $buku->getKategori()?->getNama(),
            ),
            $this->cariBuku->execute($keyword)
        );
    }

    public function pinjamBuku(array $requestData): array
    {
        try {
            $request = PinjamBukuRequest::fromHttpRequest($requestData);
            $peminjaman = $this->pinjamBuku->execute(
                anggotaId: $request->anggotaId,
                bukuId: $request->bukuId,
            );
            return [
                'success' => true,
                'message' => 'Buku berhasil dipinjam. Jatuh tempo: 14 hari.',
                'data' => [
                    'peminjaman_id' => $peminjaman->getId(),
                    'buku' => $peminjaman->getBuku()->getJudul(),
                    'anggota' => $peminjaman->getAnggota()->getNama(),
                    'tanggal_pinjam' => $peminjaman->getTanggalPinjam()->format('Y-m-d'),
                    'tanggal_jatuh_tempo' => $peminjaman->getTanggalJatuhTempo()->format('Y-m-d'),
                ],
            ];
        } catch (\DomainException $e) {
            return ['success' => false, 'message' => $e->getMessage()];
        }
    }

    public function kembalikanBuku(int $peminjamanId): array
    {
        try {
            $result = $this->kembalikanBuku->execute($peminjamanId);
            return [
                'success' => true,
                'message' => $result['pesan'],
                'data' => ['denda' => $result['denda']],
            ];
        } catch (\DomainException $e) {
            return ['success' => false, 'message' => $e->getMessage()];
        }
    }
}

namespace Perpustakaan\Infrastructure\Persistence\Doctrine;

use Perpustakaan\Domain\Entity\Buku;
use Perpustakaan\Domain\Entity\StatusBuku;
use Perpustakaan\Domain\Repository\BukuRepositoryInterface;

class DoctrineBukuRepository implements BukuRepositoryInterface
{
    public function __construct(private \Doctrine\ORM\EntityManagerInterface $em) {}

    public function findById(int $id): ?Buku
    {
        return $this->em->find(Buku::class, $id);
    }

    public function findByIsbn(string $isbn): ?Buku
    {
        return $this->em->getRepository(Buku::class)->findOneBy(['isbn' => $isbn]);
    }

    public function findByKeyword(string $keyword): array
    {
        $qb = $this->em->createQueryBuilder();
        return $qb->select('b')->from(Buku::class, 'b')
            ->where($qb->expr()->like('b.judul', ':keyword'))
            ->orWhere($qb->expr()->like('b.pengarang', ':keyword'))
            ->setParameter('keyword', "%{$keyword}%")
            ->orderBy('b.judul', 'ASC')->getQuery()->getResult();
    }

    public function findAll(): array
    {
        return $this->em->getRepository(Buku::class)->findBy([], ['judul' => 'ASC']);
    }

    public function save(Buku $buku): void
    {
        $this->em->persist($buku);
        $this->em->flush();
    }

    public function delete(int $id): void
    {
        $buku = $this->findById($id);
        if ($buku) { $this->em->remove($buku); $this->em->flush(); }
    }
}

// Implementasi PDO alternatif — tanpa framework ORM

namespace Perpustakaan\Infrastructure\Persistence\PDO;

use Perpustakaan\Domain\Entity\Buku;
use Perpustakaan\Domain\Entity\StatusBuku;
use Perpustakaan\Domain\Repository\BukuRepositoryInterface;

class PdoBukuRepository implements BukuRepositoryInterface
{
    public function __construct(private \PDO $pdo) {}

    public function findById(int $id): ?Buku
    {
        $stmt = $this->pdo->prepare("SELECT * FROM buku WHERE id = ?");
        $stmt->execute([$id]);
        $data = $stmt->fetch(\PDO::FETCH_ASSOC);
        return $data ? $this->hydrate($data) : null;
    }

    public function findByIsbn(string $isbn): ?Buku
    {
        $stmt = $this->pdo->prepare("SELECT * FROM buku WHERE isbn = ?");
        $stmt->execute([$isbn]);
        $data = $stmt->fetch(\PDO::FETCH_ASSOC);
        return $data ? $this->hydrate($data) : null;
    }

    public function findByKeyword(string $keyword): array
    {
        $like = "%{$keyword}%";
        $stmt = $this->pdo->prepare("SELECT * FROM buku WHERE judul LIKE ? OR pengarang LIKE ? ORDER BY judul ASC");
        $stmt->execute([$like, $like]);
        return array_map(fn($row) => $this->hydrate($row), $stmt->fetchAll(\PDO::FETCH_ASSOC));
    }

    public function findAll(): array
    {
        $stmt = $this->pdo->query("SELECT * FROM buku ORDER BY judul ASC");
        return array_map(fn($row) => $this->hydrate($row), $stmt->fetchAll(\PDO::FETCH_ASSOC));
    }

    public function save(Buku $buku): void
    {
        if ($buku->getId()) {
            $stmt = $this->pdo->prepare("UPDATE buku SET judul=?, pengarang=?, isbn=?, tahun_terbit=?, status=? WHERE id=?");
            $stmt->execute([$buku->getJudul(), $buku->getPengarang(), $buku->getIsbn(), $buku->getTahunTerbit(), $buku->getStatus()->value, $buku->getId()]);
        } else {
            $stmt = $this->pdo->prepare("INSERT INTO buku (judul, pengarang, isbn, tahun_terbit, status) VALUES (?, ?, ?, ?, ?)");
            $stmt->execute([$buku->getJudul(), $buku->getPengarang(), $buku->getIsbn(), $buku->getTahunTerbit(), $buku->getStatus()->value]);
        }
    }

    public function delete(int $id): void
    {
        $stmt = $this->pdo->prepare("DELETE FROM buku WHERE id = ?");
        $stmt->execute([$id]);
    }

    private function hydrate(array $data): Buku
    {
        return new Buku(
            id: (int) $data['id'], judul: $data['judul'], pengarang: $data['pengarang'],
            isbn: $data['isbn'], tahunTerbit: (int) $data['tahun_terbit'],
            status: StatusBuku::from($data['status']),
        );
    }
}

## Analogi

Clean Architecture adalah **tata kelola perpustakaan yang dipisahkan dengan tegas** - setiap bagian memiliki batasan yang tidak boleh dilanggar.

- **Domain Entity** adalah **buku, anggota, dan peminjaman itu sendiri** - identitas dan aturan dasar yang melekat pada objek tersebut.
- **Repository Interface** adalah **standar formulir peminjaman** - kontrak yang tidak peduli implementasi penyimpanan.
- **Use Case** adalah **prosedur perpustakaan** - periksa anggota, periksa buku, catat peminjaman. Prosedur tidak berubah meski sistem berubah.
- **Controller** adalah **pustakawan di meja sirkulasi** - menerima permintaan, menyampaikan ke Use Case, memberikan hasil.
- **Infrastructure** adalah **sistem penyimpanan dan peralatan perpustakaan** - rak buku, komputer, printer. Bisa diganti tanpa mengubah prosedur.
- **Dependency Rule** adalah **aturan bahwa pustakawan tidak boleh main ke gudang** - Controller hanya tahu Use Case, tidak perlu tahu cara penyimpanan.

## Dipakai untuk Apa

- **Aplikasi enterprise kompleks** - sistem perbankan, asuransi, ERP dengan aturan bisnis rumit
- **Proyek jangka panjang (>5 tahun)** - framework dan database bisa upgrade tanpa mengubah kode bisnis
- **Microservices** - setiap service punya arsitektur sendiri, domain logic tetap terisolasi
- **Aplikasi multiple frontend** - satu Use Case dipakai REST API, GraphQL, CLI, web UI
- **Tim besar (>10 developer)** - layer terpisah memungkinkan developer fokus di area masing-masing
- **Domain-Driven Design (DDD)** - Clean Architecture turunan DDD, cocok untuk Ubiquitous Language
- **Modernisasi sistem legacy bertahap** - bungkus kode lama di Infrastructure, tulis Use Case baru di Application

## Kesalahan Umum yang Sering Terjadi

- **Over-engineering untuk proyek kecil** - CRUD sederhana tidak perlu Clean Architecture. Solusi: gunakan hanya jika aturan bisnis kompleks.
- **Domain Entity terinfeksi framework** - Entity extends Eloquent Model atau punya anotasi Doctrine. Solusi: Entity harus POPO murni.
- **Use Case terlalu tipis** - hanya memanggil repository tanpa logika. Solusi: jika tidak ada logika bisnis, Use Case tidak diperlukan.
- **DTO tidak digunakan** - Entity domain dikembalikan langsung ke controller. Solusi: konversi Entity ke DTO di perbatasan layer.
- **Repository mengembalikan array** - bukan Entity. Solusi: Repository harus mengembalikan Entity domain.
- **Setter publik di Entity** - aturan bisnis bisa dilanggar. Solusi: method domain seperti pinjam(), kembalikan().
- **Service Layer jadi tempat sampah** - semua logika di Service, Entity jadi data bag. Solusi: pindahkan logika ke Entity.
- **DI tidak konsisten** - sebagian dependensi dibuat dengan new. Solusi: semua dependensi harus di-inject via constructor.
- **Testing dengan database sungguhan** - Use Case harus pakai mock repository. Jika perlu database, itu integration test.
