# Laravel — Framework PHP Paling Populer

## Penjelasan

**Laravel** adalah framework PHP berbasis MVC (Model-View-Controller) yang dirilis pertama kali oleh Taylor Otwell pada tahun 2011. Laravel menjadi framework PHP paling populer di dunia dengan ekosistem terbesar — memiliki ribuan package, dokumentasi lengkap, dan komunitas aktif. Laravel dikenal karena **sintaks yang ekspresif, elegan, dan produktif** — memungkinkan developer membangun aplikasi web kompleks dalam waktu singkat.

Arsitektur Laravel terdiri dari beberapa komponen inti:

| Komponen | Fungsi |
|----------|--------|
| **Routing** | Mendefinisikan URL endpoint dan menghubungkannya ke controller |
| **Controller** | Logika pemrosesan request — memisahkan routing dari business logic |
| **Model (Eloquent ORM)** | Active Record ORM — setiap model mewakili tabel database |
| **View (Blade)** | Template engine dengan sintaks sederhana, mendukung inheritance, components, dan directives |
| **Middleware** | Lapisan filter sebelum request mencapai controller (auth, log, CSRF) |
| **Service Container** | Dependency Injection Container bawaan — auto-resolve semua dependensi |
| **Service Providers** | Tempat registrasi binding, event listener, filter, dan konfigurasi aplikasi |
| **Artisan CLI** | Command-line tool untuk generate code, migrasi, seed, dan task otomatis |

Eloquent ORM adalah fitur paling ikonik dari Laravel. Dengan Active Record pattern, setiap tabel database direpresentasikan sebagai class Model, dan relasi (one-to-one, one-to-many, many-to-many) didefinisikan sebagai method di dalam model. Query builder Laravel menggunakan sintaks fluent — `User::where('active', true)->orderBy('name')->get()`.

### Siklus Hidup Request Laravel

```
Request → public/index.php → Kernel → Service Providers (boot) → Router → Middleware → Controller → Response
```

### Migrasi Database

Laravel menggunakan migration system — setiap perubahan skema database ditulis dalam bentuk class PHP yang bisa di-version control. `php artisan make:migration create_buku_table` akan membuat file migrasi. `php artisan migrate` menjalankan semua migrasi yang belum dijalankan.

## Fungsi

Laravel menyediakan kerangka kerja lengkap untuk membangun aplikasi web modern — dari routing, authentication, database management, caching, queue, event broadcasting, hingga testing. Framework ini mengurangi repetitive boilerplate dengan fitur bawaan seperti Eloquent ORM (abstraksi database), Blade templating (layout inheritance, components, slots), Artisan CLI (generate kode scaffolding), dan built-in authentication system. Laravel juga menyediakan mekanisme keamanan bawaan: CSRF protection, XSS prevention, SQL injection protection via Eloquent, password hashing, dan encryption.

```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\HasMany;
use Illuminate\Database\Eloquent\Relations\BelongsToMany;

class Buku extends Model
{
    // Tabel yang digunakan (jika tidak sesuai konvensi plural)
    protected $table = 'buku';

    // Kolom yang bisa diisi (mass assignment)
    protected $fillable = [
        'judul',
        'pengarang',
        'penerbit',
        'tahun_terbit',
        'isbn',
        'jumlah_halaman',
        'kategori_id',
        'status',
        'deskripsi',
        'sampul',
    ];

    // Kolom yang disembunyikan dari JSON
    protected $hidden = ['created_at', 'updated_at'];

    // Cast tipe data
    protected $casts = [
        'tahun_terbit'  => 'integer',
        'jumlah_halaman' => 'integer',
        'created_at'    => 'datetime:d/m/Y H:i',
    ];

    // Relasi: Buku milik satu Kategori
    public function kategori(): BelongsTo
    {
        return $this->belongsTo(Kategori::class);
    }

    // Relasi: Buku memiliki banyak Peminjaman
    public function peminjaman(): HasMany
    {
        return $this->hasMany(Peminjaman::class);
    }

    // Accessor: format status
    public function getStatusLabelAttribute(): string
    {
        return match ($this->status) {
            'tersedia' => 'Tersedia',
            'dipinjam' => 'Dipinjam',
            'rusak'    => 'Rusak',
            'hilang'   => 'Hilang',
            default    => 'Unknown',
        };
    }

    // Scope: buku yang tersedia
    public function scopeTersedia($query)
    {
        return $query->where('status', 'tersedia');
    }

    // Scope: cari berdasarkan judul atau pengarang
    public function scopeCari($query, string $keyword)
    {
        return $query->where('judul', 'like', "%{$keyword}%")
                     ->orWhere('pengarang', 'like', "%{$keyword}%");
    }
}

// =====================================================

namespace App\Http\Controllers;

use App\Models\Buku;
use App\Models\Kategori;
use Illuminate\Http\Request;
use Illuminate\Validation\Rule;

class BukuController extends Controller
{
    // GET /buku — menampilkan semua buku
    public function index(Request $request)
    {
        $keyword = $request->get('cari');
        $kategoriId = $request->get('kategori');

        $buku = Buku::query()
            ->when($keyword, fn($q, $k) => $q->cari($k))
            ->when($kategoriId, fn($q, $k) => $q->where('kategori_id', $k))
            ->with('kategori')
            ->orderBy('created_at', 'desc')
            ->paginate(12);

        return view('buku.index', compact('buku'));
    }

    // GET /buku/create — form tambah buku
    public function create()
    {
        $kategori = Kategori::orderBy('nama')->get();
        return view('buku.create', compact('kategori'));
    }

    // POST /buku — simpan buku baru
    public function store(Request $request)
    {
        $validated = $request->validate([
            'judul'         => 'required|string|max:255',
            'pengarang'     => 'required|string|max:255',
            'penerbit'      => 'nullable|string|max:255',
            'tahun_terbit'  => 'required|integer|min:1900|max:' . date('Y'),
            'isbn'          => 'nullable|string|unique:buku,isbn',
            'kategori_id'   => 'required|exists:kategori,id',
            'jumlah_halaman'=> 'nullable|integer|min:1',
            'deskripsi'     => 'nullable|string',
            'sampul'        => 'nullable|image|mimes:jpeg,png,jpg|max:2048',
        ]);

        if ($request->hasFile('sampul')) {
            $validated['sampul'] = $request->file('sampul')->store('sampul-buku', 'public');
        }

        $validated['status'] = 'tersedia';
        $buku = Buku::create($validated);

        return redirect()->route('buku.index')
            ->with('success', "Buku \"{$buku->judul}\" berhasil ditambahkan");
    }

    // GET /buku/{id} — detail buku
    public function show(string $id)
    {
        $buku = Buku::with(['kategori', 'peminjaman.anggota'])
            ->findOrFail($id);

        return view('buku.show', compact('buku'));
    }

    // GET /buku/{id}/edit — form edit buku
    public function edit(string $id)
    {
        $buku = Buku::findOrFail($id);
        $kategori = Kategori::orderBy('nama')->get();
        return view('buku.edit', compact('buku', 'kategori'));
    }

    // PUT /buku/{id} — update buku
    public function update(Request $request, string $id)
    {
        $buku = Buku::findOrFail($id);

        $validated = $request->validate([
            'judul'         => 'required|string|max:255',
            'pengarang'     => 'required|string|max:255',
            'penerbit'      => 'nullable|string|max:255',
            'tahun_terbit'  => 'required|integer|min:1900|max:' . date('Y'),
            'isbn'          => ['nullable', 'string', Rule::unique('buku', 'isbn')->ignore($id)],
            'kategori_id'   => 'required|exists:kategori,id',
            'jumlah_halaman'=> 'nullable|integer|min:1',
            'status'        => 'required|in:tersedia,dipinjam,rusak,hilang',
            'deskripsi'     => 'nullable|string',
        ]);

        if ($request->hasFile('sampul')) {
            $validated['sampul'] = $request->file('sampul')->store('sampul-buku', 'public');
        }

        $buku->update($validated);

        return redirect()->route('buku.show', $id)
            ->with('success', 'Data buku berhasil diperbarui');
    }

    // DELETE /buku/{id} — hapus buku
    public function destroy(string $id)
    {
        $buku = Buku::findOrFail($id);
        $judul = $buku->judul;
        $buku->delete();

        return redirect()->route('buku.index')
            ->with('success', "Buku \"{$judul}\" berhasil dihapus");
    }

    // Method tambahan: cari berdasarkan ISBN
    public function cariByIsbn(Request $request)
    {
        $request->validate(['isbn' => 'required|string']);

        $buku = Buku::where('isbn', $request->isbn)->first();

        if (!$buku) {
            return response()->json(['message' => 'Buku tidak ditemukan'], 404);
        }

        return response()->json($buku);
    }
}

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;

class Peminjaman extends Model
{
    protected $fillable = [
        'buku_id',
        'anggota_id',
        'tanggal_pinjam',
        'tanggal_jatuh_tempo',
        'tanggal_kembali',
        'status',
        'catatan',
    ];

    protected $casts = [
        'tanggal_pinjam'      => 'date:d/m/Y',
        'tanggal_jatuh_tempo' => 'date:d/m/Y',
        'tanggal_kembali'     => 'date:d/m/Y',
    ];

    // Relasi: Peminjaman milik satu Buku
    public function buku(): BelongsTo
    {
        return $this->belongsTo(Buku::class);
    }

    // Relasi: Peminjaman milik satu Anggota
    public function anggota(): BelongsTo
    {
        return $this->belongsTo(Anggota::class);
    }

    // Accessor: hitung denda otomatis
    public function getDendaAttribute(): int
    {
        if ($this->tanggal_kembali) {
            return 0;
        }

        $jatuhTempo = $this->tanggal_jatuh_tempo;
        $hariIni = now();

        if ($hariIni <= $jatuhTempo) {
            return 0;
        }

        $hariTelat = $hariIni->diffInDays($jatuhTempo);
        return $hariTelat * 2000; // Rp 2000 per hari
    }

    // Scope: peminjaman aktif (belum dikembalikan)
    public function scopeAktif($query)
    {
        return $query->whereNull('tanggal_kembali');
    }

    // Scope: peminjaman terlambat
    public function scopeTerlambat($query)
    {
        return $query->aktif()
            ->where('tanggal_jatuh_tempo', '<', now());
    }
}

// 8. MIDDLEWARE CUSTOM (app/Http/Middleware/RoleMiddleware.php)
// =====================================================

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class RoleMiddleware
{
    public function handle(Request $request, Closure $next, string $role): Response
    {
        if (!$request->user() || $request->user()->role !== $role) {
            abort(403, 'Akses ditolak');
        }

        return $next($request);
    }
}
```

### Contoh Service Provider (app/Providers/AppServiceProvider.php)

```php
<?php

namespace App\Providers;

use App\Models\Buku;
use App\Observers\BukuObserver;
use Illuminate\Support\ServiceProvider;
use Illuminate\Support\Facades\Validator;

class AppServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        // Binding interface ke implementasi
        $this->app->bind(
            \App\Contracts\BukuRepositoryInterface::class,
            \App\Repositories\BukuRepository::class
        );
    }

    public function boot(): void
    {
        // Daftarkan observer
        Buku::observe(BukuObserver::class);

        // Custom validation rule
        Validator::extend('isbn_valid', function ($attribute, $value) {
            return preg_match('/^(978|979)\d{10}$/', $value);
        }, 'Format ISBN tidak valid (harus 13 digit).');
    }
}
```

## Analogi

Laravel adalah **sistem perpustakaan modern yang terdigitalisasi** dengan standar operasional prosedur yang lengkap.

- **Routing** adalah **papan petunjuk perpustakaan** — "Rak Fiksi: belok kiri", "Rak Referensi: lantai 2", "Kembalikan Buku: meja sirkulasi". Setiap URL (route) mengarahkan pengunjung ke bagian yang tepat.
- **Controller** adalah **pustakawan yang menangani permintaan** — pengunjung datang, pustakawan mendengarkan, memproses, dan memberikan jawaban atau tindakan.
- **Model (Eloquent)** adalah **kartu katalog digital** — setiap kartu mewakili satu buku dengan semua informasinya, plus relasi ke kartu lain (kategori buku, riwayat peminjaman). Tidak perlu lagi membuka lemari katalog fisik — cukup search di database.
- **Blade View** adalah **rak buku yang ditata rapi** — buku dipajang dengan layout yang konsisten, ada label, harga, dan stok. Layout Blade memastikan setiap rak (halaman) punya tampilan yang seragam.
- **Middleware** adalah **satpam perpustakaan** — sebelum masuk ke ruang baca khusus (controller), satpam memeriksa kartu anggota (autentikasi), memastikan tidak membawa makanan (filter request), dan mencatat kunjungan (log).
- **Service Container** adalah **supervisor perpustakaan** yang mengatur siapa melakukan apa. Supervisor tahu bahwa "PeminjamanService" butuh "BukuRepository" dan "AnggotaRepository" — supervisor menyediakannya tanpa pustakawan harus repot membuat sendiri.
- **Artisan CLI** adalah **asisten digital perpustakaan** — dengan satu perintah "buatkan formulir pendaftaran anggota baru" (php artisan make:model Anggota -m), asisten langsung menyiapkan kartu katalog baru beserta formatnya.
- **Migrasi** adalah **log perubahan tata letak perpustakaan** — setiap kali perpustakaan menambah rak baru atau mengubah kategori, semua perubahan dicatat rapi dan bisa di-rollback jika perlu.

## Dipakai untuk Apa

- **Aplikasi web full-stack** — CMS, e-commerce, portal berita, sistem informasi akademik, ERP
- **RESTful API** — backend untuk mobile app atau SPA (Vue, React, Next.js) menggunakan Laravel Sanctum atau Passport
- **Sistem enterprise** — aplikasi perpustakaan, manajemen inventaris, HRIS, CRM
- **SaaS platform** — Laravel Spark, Cashier (subscription billing), Horizon (queue monitoring)
- **Real-time aplikasi** — broadcasting dengan Laravel Echo + WebSocket / Pusher
- **Microservices** — Laravel dengan komunikasi via queue, event, atau API Gateway
- **Monolith pertama startup** — Laravel cukup cepat untuk MVP dan scalable hingga jutaan user dengan optimasi cache dan queue
- **Backend admin panel** — Laravel Nova, Filament, atau backpack untuk CRUD internal

## Kesalahan Umum yang Sering Terjadi

- **N+1 query problem**: Mengakses relasi di loop tanpa eager loading — `$buku->peminjaman` dipanggil di dalam loop Blade, menghasilkan 100 query untuk 100 buku. Solusi: gunakan `with('peminjaman')` atau `load('peminjaman')`.
- **Mass assignment vulnerability**: Lupa mendefinisikan `$fillable` atau `$guarded` di Model — user bisa mengirim kolom `is_admin` via form dan langsung terisi. Solusi: selalu define `$fillable`.
- **Controller terlalu gemuk (Fat Controller)**: Semua logika bisnis ditulis di controller — controller jadi 500 baris. Solusi: pindahkan logika ke Service class atau Action class.
- **Query di Blade template**: `Buku::where(...)->get()` ditulis langsung di view — melanggar pemisahan concern. Solusi: kirim data dari controller.
- **Tidak menggunakan eager loading**: `$buku = Buku::all();` lalu di Blade akses `$buku->kategori->nama` — setiap akses menjalankan query tambahan. Solusi: `Buku::with('kategori')->get()`.
- **Lupa menangani file upload**: Validasi dan penyimpanan file sering terlewat — file tidak di-validate, path tidak disimpan, file lama tidak dihapus saat update. Solusi: gunakan Form Request dan event/observer.
- **Environment hardcoded**: `DB_HOST`, `DB_DATABASE` ditulis langsung di kode, bukan di `.env`. Solusi: selalu gunakan `env()` atau `config()`.
- **Tidak memanfaatkan caching**: Query yang sama dijalankan berulang kali. Solusi: cache query dengan `Cache::remember()` untuk data yang jarang berubah (kategori, konfigurasi).
- **Route model binding tidak digunakan**: `public function show($id)` lalu `Buku::findOrFail($id)` padahal bisa langsung `public function show(Buku $buku)`. Solusi: gunakan implicit route model binding.
- **Lupa menjalankan migrasi di production**: Kode baru sudah di-deploy tapi database belum di-migrate — error 500. Solusi: jalankan `php artisan migrate` sebagai bagian dari deployment script.

## Hubungan dengan Materi Sebelumnya

Materi 23-25 (OOP: Class, Inheritance, Interface & Trait) adalah fondasi Laravel — setiap Model, Controller, dan Service adalah class. Trait digunakan intensif di Laravel (`Authenticatable`, `Authorizable`, `SoftDeletes`). Materi 26 (PDO) diabstraksi oleh Eloquent ORM — Anda tidak perlu menulis query SQL manual. Materi 27 (Prepared Statements) dihandle otomatis oleh Eloquent untuk mencegah SQL injection. Materi 30 (Composer & Autoloading) adalah fondasi install Laravel dan package management. Materi 31 (PSR Standards) — Laravel mengikuti PSR-4 (autoloading) dan PSR-2 (coding style). Materi 32 (PHP 8 Features) digunakan di seluruh Laravel 10/11 — constructor promotion, named arguments, match expression, readonly properties. Materi 33 (Unit Testing) — Laravel memiliki PHPUnit terintegrasi dengan helper seperti `$this->get()`, `$this->post()`, `$this->assertDatabaseHas()`. Setelah materi ini, kamu bisa melanjutkan ke Symfony (materi 36) sebagai alternatif framework enterprise, atau Clean Architecture (materi 37) untuk memahami arsitektur yang framework-agnostic.

## Soal Latihan & Jawaban

### Soal

Buat fitur **peminjaman buku** menggunakan Laravel dengan ketentuan:

1. **Model**: Buat model `Peminjaman` dengan migrasi yang memiliki kolom: `id`, `buku_id` (FK ke buku), `anggota_id` (FK ke anggota), `tanggal_pinjam`, `tanggal_jatuh_tempo`, `tanggal_kembali` (nullable), `status` (enum: aktif/dikembalikan/terlambat), `catatan` (nullable text), timestamps.
2. **Controller**: Buat `PeminjamanController` resource dengan method index (daftar peminjaman user yang login), store (pinjam buku), update (kembalikan buku).
3. **Relasi Model**: Peminjaman belongsTo Buku dan belongsTo Anggota. Buku hasMany Peminjaman.
4. **Accessor**: Buat accessor `denda` di model Peminjaman — hitung denda Rp 2000 per hari keterlambatan (jika status masih aktif dan melewati tanggal_jatuh_tempo).
5. **Scope**: Buat scope `aktif()` dan `terlambat()` di model Peminjaman.
6. **Route**: Resource route untuk peminjaman, dengan middleware auth.
7. **Validasi**: Saat pinjam buku, pastikan buku berstatus 'tersedia' dan anggota belum meminjam buku yang sama. Jika buku sudah dipinjam orang lain, tampilkan error.

Tulis kode untuk Model, Controller (method index, store, update), Migrasi, dan Route.

```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;

class Peminjaman extends Model
{
    protected $fillable = [
        'buku_id',
        'anggota_id',
        'tanggal_pinjam',
        'tanggal_jatuh_tempo',
        'tanggal_kembali',
        'status',
        'catatan',
    ];

    protected $casts = [
        'tanggal_pinjam'      => 'date',
        'tanggal_jatuh_tempo' => 'date',
        'tanggal_kembali'     => 'date',
    ];

    public function buku(): BelongsTo
    {
        return $this->belongsTo(Buku::class);
    }

    public function anggota(): BelongsTo
    {
        return $this->belongsTo(Anggota::class);
    }

    public function getDendaAttribute(): int
    {
        if ($this->tanggal_kembali) {
            return 0;
        }

        $jatuhTempo = $this->tanggal_jatuh_tempo;
        $hariIni = now();

        if ($hariIni <= $jatuhTempo) {
            return 0;
        }

        return $hariIni->diffInDays($jatuhTempo) * 2000;
    }

    public function scopeAktif($query)
    {
        return $query->whereNull('tanggal_kembali');
    }

    public function scopeTerlambat($query)
    {
        return $query->aktif()
            ->where('tanggal_jatuh_tempo', '<', now());
    }
}

// FILE: app/Http/Controllers/PeminjamanController.php
// =====================

namespace App\Http\Controllers;

use App\Models\Buku;
use App\Models\Peminjaman;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\DB;

class PeminjamanController extends Controller
{
    public function index()
    {
        $peminjaman = Peminjaman::with(['buku', 'anggota'])
            ->where('anggota_id', auth()->id())
            ->orderBy('created_at', 'desc')
            ->paginate(10);

        return view('peminjaman.index', compact('peminjaman'));
    }

    public function store(Request $request)
    {
        $validated = $request->validate([
            'buku_id' => 'required|exists:buku,id',
        ]);

        $buku = Buku::findOrFail($validated['buku_id']);

        if ($buku->status !== 'tersedia') {
            return back()->withErrors(['buku_id' => 'Buku tidak tersedia untuk dipinjam.']);
        }

        $sudahDipinjam = Peminjaman::where('buku_id', $buku->id)
            ->where('anggota_id', auth()->id())
            ->aktif()
            ->exists();

        if ($sudahDipinjam) {
            return back()->withErrors(['buku_id' => 'Anda sedang meminjam buku ini.']);
        }

        DB::transaction(function () use ($buku) {
            Peminjaman::create([
                'buku_id'            => $buku->id,
                'anggota_id'         => auth()->id(),
                'tanggal_pinjam'     => now(),
                'tanggal_jatuh_tempo'=> now()->addDays(14),
                'status'             => 'aktif',
            ]);

            $buku->update(['status' => 'dipinjam']);
        });

        return redirect()->route('peminjaman.index')
            ->with('success', 'Buku berhasil dipinjam. Jatuh tempo: 14 hari.');
    }

    public function update(Request $request, Peminjaman $peminjaman)
    {
        if ($peminjaman->anggota_id !== auth()->id()) {
            abort(403, 'Anda tidak memiliki akses ke peminjaman ini.');
        }

        if ($peminjaman->tanggal_kembali) {
            return back()->withErrors(['Buku sudah dikembalikan sebelumnya.']);
        }

        DB::transaction(function () use ($peminjaman) {
            $status = now() > $peminjaman->tanggal_jatuh_tempo
                ? 'terlambat'
                : 'dikembalikan';

            $peminjaman->update([
                'tanggal_kembali' => now(),
                'status'          => $status,
            ]);

            $peminjaman->buku()->update(['status' => 'tersedia']);
        });

        $message = now() > $peminjaman->tanggal_jatuh_tempo
            ? 'Buku dikembalikan terlambat. Denda: Rp ' . number_format($peminjaman->denda, 0, ',', '.')
            : 'Buku berhasil dikembalikan. Terima kasih!';

        return redirect()->route('peminjaman.index')
            ->with('success', $message);
    }
}
```
