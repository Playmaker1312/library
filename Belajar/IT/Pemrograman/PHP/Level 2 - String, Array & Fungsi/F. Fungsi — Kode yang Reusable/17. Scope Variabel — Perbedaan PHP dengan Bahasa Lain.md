# Scope Variabel — Perbedaan PHP dengan Bahasa Lain

## Penjelasan
**Scope** adalah area di mana suatu variabel dapat diakses. Berbeda dengan JavaScript atau Python yang punya aturan *function scope* atau *block scope* relatif longgar, PHP memiliki aturan yang lebih ketat dan unik:

**Scope di PHP:**
1. **Global scope** — variabel di luar fungsi. Tidak bisa diakses langsung dari dalam fungsi.
2. **Local scope (function scope)** — variabel di dalam fungsi. Tidak bisa diakses dari luar.
3. **Keyword `global`** — cara mengimpor variabel global ke dalam fungsi.
4. **`static`** — variabel lokal yang tetap mempertahankan nilainya antar pemanggilan fungsi.
5. **Superglobals** — variabel built-in yang bisa diakses dari mana saja (`$_GET`, `$_POST`, `$_SESSION`, `$_SERVER`, `$_COOKIE`, `$_REQUEST`, `$_FILES`, `$GLOBALS`).

**Perbedaan utama dengan bahasa lain:**
- Di **JavaScript**: function scope & hoisting — variabel `var` bisa diakses sebelum deklarasi. Di **PHP**: tidak ada hoisting — variabel harus dideklarasikan sebelum dipakai.
- Di **Python**: fungsi bisa membaca variabel global (read). Di **PHP**: fungsi **tidak bisa** membaca variabel global tanpa `global` atau `$GLOBALS`.
- Di **PHP (7+)**: mulai ada konsep block scope untuk `function() use ()` pada closure.

## Fungsi
Mengatur visibilitas dan umur (*lifetime*) variabel. Mencegah konflik nama variabel antar bagian kode yang berbeda, dan memastikan data tidak bocor ke scope yang tidak seharusnya.

## Cara Pengimplementasian / Code
```php
<?php
// --- GLOBAL vs LOCAL ---
$namaPerpustakaan = "Perpustakaan Pusat"; // GLOBAL

function tampilkanNama() {
    // ERROR: Undefined variable — $namaPerpustakaan tidak dikenal di sini
    // echo $namaPerpustakaan;

    $namaLokal = "Perpustakaan Cabang"; // LOCAL — hanya di sini
    echo $namaLokal . "\n"; // OK
}
tampilkanNama();
// echo $namaLokal; // ERROR — tidak bisa diakses di sini

// --- KEYWORD global ---
function tampilkanGlobal() {
    global $namaPerpustakaan; // import variabel global ke sini
    echo $namaPerpustakaan . "\n"; // "Perpustakaan Pusat"

    // Bisa juga pakai $GLOBALS
    echo $GLOBALS['namaPerpustakaan'] . "\n"; // "Perpustakaan Pusat"

    // Bahkan bisa mengubah nilai global
    $namaPerpustakaan = "Perpustakaan Nasional";
}
tampilkanGlobal();
echo $namaPerpustakaan . "\n"; // "Perpustakaan Nasional" (berubah!)

// --- STATIC VARIABLE ---
function counterPeminjaman() {
    static $count = 0; // hanya diinisialisasi sekali
    $count++;
    return $count;
}
echo counterPeminjaman() . "\n"; // 1
echo counterPeminjaman() . "\n"; // 2
echo counterPeminjaman() . "\n"; // 3
// $count tetap ada antar pemanggilan, tapi hanya bisa diakses di sini

// --- SUPERGLOBALS ---
// $_GET, $_POST, $_SESSION bisa diakses dari mana saja
// Contoh: mengakses query string
// URL: ?cari=PHP
echo "Mencari: " . ($_GET['cari'] ?? 'tidak ada') . "\n";

// --- CLOSURE SCOPE ---
$diskon = 1000;
$hitungHarga = function($harga) use ($diskon) {
    // closure butuh 'use' untuk mengakses variabel dari parent scope
    return $harga - $diskon;
};
echo $hitungHarga(10000) . "\n"; // 9000
?>
```

## Analogi
Perpustakaan punya beberapa **ruangan dengan akses berbeda**. Ruang depan (global scope) — siapa pun bisa masuk dan melihatnya. Ruang staf belakang (local/function scope) — hanya petugas tertentu (fungsi) yang bisa masuk. Seorang petugas di ruang staf belakang tidak bisa mengambil buku dari ruang depan tanpa izin (`global` keyword). **Static variable** seperti **lokcer pribadi petugas** — setiap kali petugas masuk ruangan, lokcernya masih berisi barang yang sama seperti saat dia pergi terakhir kali. **Superglobals** seperti **papan pengumuman pusat** — semua petugas di semua ruangan bisa melihatnya. Di JavaScript atau Python, aturannya lebih longgar — semua orang bisa berjalan ke ruang mana pun tanpa izin — di PHP, pintu-pintunya terkunci dan harus dibuka secara eksplisit.

## Dipakai untuk Apa
- **Mengelola state aplikasi**: Counter kunjungan, total peminjaman (static variable)
- **Konfigurasi global**: Database credentials, base URL (via `$GLOBALS` atau define)
- **Session management**: `$_SESSION` untuk login state (superglobal)
- **Memproses input**: `$_POST` untuk form, `$_GET` untuk query string
- **Environment detection**: `$_SERVER['SERVER_NAME']`, `$_SERVER['REQUEST_METHOD']`
- **Closure dengan data context**: Mengikat variabel luar ke callback (use binding)

## Kesalahan Umum yang Sering Terjadi
- **Mengira variabel global bisa diakses di fungsi**: Di PHP, fungsi tidak secara otomatis melihat variabel global — harus pakai `global` atau `$GLOBALS`.
- **Terlalu banyak `global`**: Membuat kode sulit dilacak (spaghetti code) — lebih baik kirim via parameter atau pakai dependency injection.
- **Static variable disangka bisa diakses dari luar**: Static hanya lokal ke fungsi, beda dengan `static` di OOP (class property).
- **Lupa scope closure**: Variabel di parent scope tidak otomatis tersedia di closure — harus pakai `use`.
- **Salah paham superglobal `$GLOBALS`**: `$GLOBALS['var']` adalah *reference* ke variabel global — mengubahnya mengubah variabel asli.

## Hubungan dengan Materi Sebelumnya
Setelah membuat fungsi (materi 15) dan closure (materi 16), kamu perlu memahami **di mana** variabel-variabel itu hidup dan mati. Scope adalah "aturan main" yang membedakan PHP dari JavaScript (yang kamu mungkin sudah kenal). Pemahaman scope sangat penting saat masuk ke OOP (Level 4) — di mana ada `public`, `protected`, `private` yang merupakan perpanjangan dari konsep scope.

## Soal Latihan & Jawaban
### Soal
Buat fungsi `catatPeminjaman(string $namaAnggota): int` yang menggunakan static counter. Setiap kali dipanggil, counter bertambah 1 dan fungsi mengembalikan nomor urut peminjaman. Panggil 3 kali dengan nama berbeda dan tampilkan hasilnya. Lalu buat fungsi kedua `getNamaPerpustakaan(): string` yang membaca variabel global `$namaPerpustakaan = "Digital Library"`.

### Jawaban
```php
<?php
$namaPerpustakaan = "Digital Library";

function catatPeminjaman(string $namaAnggota): int {
    static $counter = 0;
    $counter++;
    echo "$namaAnggota — Nomor antrian: $counter\n";
    return $counter;
}

function getNamaPerpustakaan(): string {
    global $namaPerpustakaan;
    return $namaPerpustakaan;
}

catatPeminjaman("Andi");   // Andi — Nomor antrian: 1
catatPeminjaman("Budi");   // Budi — Nomor antrian: 2
catatPeminjaman("Citra");  // Citra — Nomor antrian: 3

echo "Perpustakaan: " . getNamaPerpustakaan() . "\n"; // Perpustakaan: Digital Library
?>
```
