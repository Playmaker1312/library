# Fungsi — Definisi, Parameter & Return

## Penjelasan
Fungsi adalah blok kode yang diberi nama, dapat dipanggil berkali-kali, dan menerima input (parameter) serta menghasilkan output (return value). Struktur dasar:

```php
function namaFungsi(parameter1, parameter2, ...): tipeReturn {
    // body fungsi
    return $nilai;
}
```

Fitur parameter di PHP:
- **Parameter wajib** — harus diberikan saat pemanggilan
- **Default value** — parameter dengan nilai bawaan jika tidak dikirim
- **Type hint** — menentukan tipe data parameter (string, int, array, dll)
- **Variadic** — `...$args` untuk menerima jumlah parameter tak terbatas
- **Nullable** — `?string $nama` artinya boleh string atau null

Fitur return:
- **Type declaration** — `function(): int` menjamin return integer
- **Nullable return** — `function(): ?string` boleh return string atau null
- **Void** — `function(): void` tidak mengembalikan nilai
- **Early return** — `return` di tengah fungsi untuk menghentikan eksekusi lebih awal

## Fungsi
Membungkus logika yang reusable — tulis sekali, panggil berkali-kali. Meningkatkan modularitas, readability, dan maintainability kode. Menghindari duplikasi kode (DRY — Don't Repeat Yourself).

## Cara Pengimplementasian / Code
```php
<?php
// Fungsi sederhana
function sapa($nama) {
    return "Halo, $nama!";
}
echo sapa("Andi") . "\n"; // "Halo, Andi!"

// Default parameter
function daftarBuku($kategori = "Semua") {
    return "Menampilkan buku kategori: $kategori";
}
echo daftarBuku() . "\n";       // "Menampilkan buku kategori: Semua"
echo daftarBuku("Sains") . "\n"; // "Menampilkan buku kategori: Sains"

// Type hint
function hitungDenda(int $hari, int $dendaPerHari): int {
    return $hari * $dendaPerHari;
}
echo hitungDenda(3, 1000) . "\n"; // 3000

// Nullable parameter
function cariBuku(?string $judul): string {
    if ($judul === null) {
        return "Silakan masukkan judul buku";
    }
    return "Mencari buku: $judul";
}
echo cariBuku(null) . "\n";     // "Silakan masukkan judul buku"

// Variadic parameter
function jumlahkanSemua(...$angka): int {
    return array_sum($angka);
}
echo jumlahkanSemua(10, 20, 30, 40) . "\n"; // 100

// Early return
function cekKetersediaan($jumlah) {
    if ($jumlah <= 0) {
        return "Buku tidak tersedia";
    }
    if ($jumlah < 3) {
        return "Sisa stok sedikit";
    }
    return "Buku tersedia";
}
echo cekKetersediaan(0) . "\n"; // "Buku tidak tersedia"
echo cekKetersediaan(5) . "\n"; // "Buku tersedia"

// Fungsi tanpa return (void)
function cetakPesan(string $pesan): void {
    echo $pesan . "\n";
}
cetakPesan("Selamat datang di perpustakaan");
?>
```

## Analogi
Fungsi seperti **petugas perpustakaan dengan tugas spesifik**. Ada petugas sirkulasi (menerima `$nama` anggota, mengembalikan salam), petugas denda (menerima `$hari` dan `$dendaPerHari`, mengembalikan `$total`), petugas katalog (menerima `$judul` atau `null`, mengembalikan hasil pencarian). Setiap petugas punya **keahlian khusus** (parameter dengan type hint), **prosedur standar** (default parameter), dan **hasil kerja** (return value). Kamu tinggal panggil "Hai Petugas, tolong hitung denda untuk 3 hari" — tanpa perlu tahu detail bagaimana dia menghitungnya.

## Dipakai untuk Apa
- **Validasi input**: `validasiEmail($email): bool`
- **Logika bisnis**: `hitungTotal($items, $diskon): int`
- **Akses database**: `getBukuById($id): array`
- **Render view**: `tampilkanKoleksi($buku): void`
- **Utility**: `formatTanggal($date): string`, `slugify($judul): string`
- **API handler**: `getBuku($request): Response`

## Kesalahan Umum yang Sering Terjadi
- **Lupa return**: Fungsi tanpa `return` mengembalikan `null` — bisa menyebabkan bug yang sulit dilacak.
- **Salah urutan parameter**: `hitungDenda(1000, 3)` — argumen terbalik, hasilnya beda.
- **Tidak pakai type hint**: Nilai string masuk ke parameter yang seharusnya integer — operator seperti `*` akan memaksakan konversi diam-diam.
- **Parameter wajib tidak diisi**: PHP error `ArgumentCountError`.
- **Return type mismatch**: `function(): int` tapi me-return string — PHP akan melakukan type coercion atau error (strict mode).
- **Side effect di dalam fungsi**: Fungsi mengubah variabel global tanpa sengaja — gunakan parameter atau return value.

## Hubungan dengan Materi Sebelumnya
Setelah belajar menyimpan data (variabel, materi 6), mengelompokkannya (array, materi 13-14), dan memanipulasinya (string functions, materi 12), sekarang kamu belajar **membungkus logika** menjadi unit yang reusable. Fungsi adalah fondasi untuk materi selanjutnya: Closure (materi 16), Scope (materi 17), dan nantinya Method di OOP (Level 4).

## Soal Latihan & Jawaban
### Soal
Buat fungsi `hitungDendaPerpustakaan(int $hariTerlambat, bool $anggotaPremium = false): int` dengan aturan: denda Rp2000/hari untuk anggota biasa, Rp1000/hari untuk premium. Fungsi mengembalikan total denda. Panggil dengan (5 hari, premium) dan (3 hari, biasa).

### Jawaban
```php
<?php
function hitungDendaPerpustakaan(int $hariTerlambat, bool $anggotaPremium = false): int {
    $tarif = $anggotaPremium ? 1000 : 2000;
    return $hariTerlambat * $tarif;
}

echo hitungDendaPerpustakaan(5, true) . "\n";  // 5000
echo hitungDendaPerpustakaan(3) . "\n";        // 6000
?>
```
