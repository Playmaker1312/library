# String Functions — Yang Paling Sering Digunakan

## Penjelasan
PHP menyediakan puluhan fungsi bawaan untuk memanipulasi string. Beberapa yang paling sering dipakai dalam pengembangan web sehari-hari:

| Fungsi | Deskripsi |
|--------|-----------|
| `strlen($s)` | Menghitung panjang string (jumlah byte/karakter) |
| `str_word_count($s)` | Menghitung jumlah kata |
| `strpos($s, $cari)` | Mencari posisi pertama substring (false jika tidak ditemukan) |
| `substr($s, $start, $length)` | Mengambil sebagian string |
| `str_replace($cari, $ganti, $s)` | Mengganti substring |
| `strtolower($s)` / `strtoupper($s)` | Mengubah ke huruf kecil / besar |
| `trim($s)` | Menghapus spasi di awal dan akhir |
| `explode($delimiter, $s)` | Memecah string menjadi array |
| `implode($glue, $array)` | Menggabung array menjadi string |
| `ucfirst($s)` / `ucwords($s)` | Kapitalisasi huruf pertama / setiap kata |

## Fungsi
Mempermudah pembersihan, validasi, format, dan transformasi data teks — dari input pengguna hingga output tampilan.

## Cara Pengimplementasian / Code
```php
<?php
$teks = "  Selamat datang di Perpustakaan Digital  ";

// Panjang string
echo strlen($teks) . "\n";            // 40 (termasuk spasi)

// Bersihkan spasi
$teksBersih = trim($teks);
echo strlen($teksBersih) . "\n";      // 36

// Hitung kata
echo str_word_count($teksBersih) . "\n"; // 4

// Cari posisi
$pos = strpos($teksBersih, "Perpustakaan");
echo $pos . "\n";                    // 18

// Ambil substring
echo substr($teksBersih, 0, 8) . "\n"; // "Selamat "
echo substr($teksBersih, -8) . "\n";   // "Digital"

// Ganti kata
echo str_replace("Digital", "Online", $teksBersih) . "\n";
// Output: Selamat datang di Perpustakaan Online

// Ubah huruf
echo strtolower($teksBersih) . "\n";  // "selamat datang di perpustakaan digital"
echo strtoupper($teksBersih) . "\n";  // "SELAMAT DATANG DI PERPUSTAKAAN DIGITAL"
echo ucfirst("sejarah nusantara") . "\n";     // "Sejarah nusantara"
echo ucwords("sejarah nusantara") . "\n";     // "Sejarah Nusantara"

// String ke array (explode)
$kata = explode(" ", $teksBersih);
print_r($kata);
// Array ( [0] => Selamat [1] => datang [2] => di [3] => Perpustakaan [4] => Digital )

// Array ke string (implode)
$arrayBuku = ["PHP", "Dasar", "Pemula"];
echo implode(", ", $arrayBuku) . "\n";  // "PHP, Dasar, Pemula"
?>
```

## Analogi
String functions seperti **berbagai alat di meja sirkulasi perpustakaan**: `strlen` = penggaris untuk mengukur panjang label buku, `strpos` = petunjuk untuk mencari letak rak tertentu, `substr` = gunting untuk memotong sebagian label, `str_replace` = stiker koreksi untuk menutup tulisan lama dengan yang baru, `trim` = penghapus spasi berlebih di tepi kertas, `explode` = gunting pemotong yang memisahkan daftar buku menjadi kepingan individual, `implode` = lem untuk menyatukan kembali potongan-potongan label.

## Dipakai untuk Apa
- **Validasi form**: `trim($_POST['nama'])` — bersihkan input pengguna
- **Pencarian**: `strpos($deskripsi, $keyword)` — cek apakah kata kunci ada
- **Format tampilan**: `ucwords($nama)` — kapitalisasi nama pengguna
- **Slug URL**: `str_replace(' ', '-', strtolower($judul))` — ubah judul jadi slug
- **Parsing data**: `explode(',', $csvLine)` — baca file CSV
- **Sanitasi path**: `trim($path, '/')` — bersihkan path

## Kesalahan Umum yang Sering Terjadi
- **`strpos` return `0` vs `false`**: Posisi 0 (awal string) dianggap `false` jika pakai `==`. Gunakan `===` (strict comparison): `if (strpos($s, $cari) !== false)`.
- **`substr` dengan parameter negatif**: Bingung arah — `substr($s, -3)` ambil 3 karakter terakhir, bukan mulai dari posisi -3.
- **Lupa `trim`**: Input form sering punya spasi tak terlihat — validasi gagal karena `"andi" != "andi "`.
- **`explode` delimiter tidak ditemukan**: Menghasilkan array dengan satu elemen (string utuh), bukan error.
- **Multi-byte (UTF-8)**: `strlen` menghitung *byte*, bukan *karakter*. Untuk UTF-8 seperti "pustakawan" gunakan `mb_strlen` (multi-byte version).

## Hubungan dengan Materi Sebelumnya
Setelah memahami perbedaan single/double quote (materi 11), sekarang kamu belajar alat untuk memanipulasi string. Fungsi-fungsi ini akan sangat sering digunakan bersama array (materi 13-14) — misalnya `explode` menghasilkan array, `implode` mengubah array kembali ke string. Juga merupakan dasar sebelum belajar fungsi buatan sendiri (materi 15).

## Soal Latihan & Jawaban
### Soal
Petugas perpustakaan punya data mentah: `"  judul Buku: php Dasar;Pengarang: Andi  "`. Bersihkan data dengan `trim`, lalu pecah berdasarkan `;` menjadi array, lalu ubah judul buku menjadi huruf besar semua, dan tampilkan sebagai: "JUDUL: PHP DASAR | PENGARANG: ANDI".

### Jawaban
```php
<?php
$data = "  judul Buku: php Dasar;Pengarang: Andi  ";
$data = trim($data);
$parts = explode(";", $data);

$judul = strtoupper($parts[0]);        // "JUDUL BUKU: PHP DASAR"
$pengarang = strtoupper($parts[1]);    // "PENGARANG: ANDI"

echo "$judul | $pengarang" . "\n";
?>
```
