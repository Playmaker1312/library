# String Syntax — Single Quote vs Double Quote

## Penjelasan
Di PHP, string bisa ditulis dengan **single quote** (`'...'`) atau **double quote** (`"..."`). Perbedaan utamanya:
- **Single quote**: PHP memperlakukan isinya sebagai teks literal — variabel tidak akan diuraikan (tidak di-*parse*). Hanya dua escape sequence yang dikenali: `\'` (kutip tunggal) dan `\\` (garis miring).
- **Double quote**: PHP meng-*parse* isinya — variabel akan diterjemahkan menjadi nilainya. Juga mendukung lebih banyak escape sequence seperti `\n` (baris baru), `\t` (tab), `\"`, `\$`, dll.

Selain itu ada **Heredoc** dan **Nowdoc** untuk string multi-baris:
- **Heredoc** (`<<<IDENTIFIER`): Bertingkah seperti double quote — mendukung interpolasi variabel.
- **Nowdoc** (`<<<'IDENTIFIER'`): Bertingkah seperti single quote — tidak mendukung interpolasi.

## Fungsi
Memberikan fleksibilitas dalam menulis teks — pilih single quote untuk teks statis (lebih cepat), double quote saat perlu menyisipkan nilai variabel langsung di dalam string tanpa operator concatenation (`.`).

## Cara Pengimplementasian / Code
```php
<?php
$judul = "Sejarah Nusantara";
$tahun = 2025;

// Single quote — literal, tidak parse variabel
echo 'Judul buku: $judul' . "\n";     // Output: Judul buku: $judul
echo 'Hari ini\'s sale!' . "\n";      // Output: Hari ini's sale!
echo 'Path: C:\\xampp\\htdocs' . "\n"; // Output: Path: C:\xampp\htdocs

// Double quote — variabel diuraikan
echo "Judul buku: $judul" . "\n";     // Output: Judul buku: Sejarah Nusantara
echo "Tahun: $tahun" . "\n";           // Output: Tahun: 2025

// Kurung kurawal untuk memperjelas batas variabel
echo "Buku {$judul} terbit tahun $tahun" . "\n";

// Heredoc — seperti double quote
$teks = <<<TEKS
Buku "$judul" telah tersedia di rak.
Tahun terbit: $tahun
Silakan dipinjam.
TEKS;
echo $teks;

// Nowdoc — seperti single quote
$teks2 = <<<'TEKS'
Buku "$judul" telah tersedia di rak.
Tahun terbit: $tahun
Silakan dipinjam.
TEKS;
echo $teks2 . "\n";
?>
```

## Analogi
Single quote seperti **label buku yang ditulis apa adanya** — apa yang tercetak di label itulah yang dibaca petugas, tidak ada interpretasi lain. Double quote seperti **petugas yang membaca label lalu mengambil buku dari rak yang dirujuk** — `$judul` diartikan sebagai buku "Sejarah Nusantara", bukan teks `$judul`. Heredoc dan Nowdoc seperti **catatan panjang di lembar peminjaman** — yang pertama (Heredoc) akan dicari buku referensinya, yang kedua (Nowdoc) ditulis persis seperti adanya.

## Dipakai untuk Apa
- Menampilkan teks yang mengandung variabel tanpa concatenation (`"Selamat datang, $nama"`)
- Menulis query SQL dengan nilai variabel (`"SELECT * FROM buku WHERE judul = '$judul'"`)
- Membuat teks multi-baris (Heredoc) untuk template HTML atau email
- Escape sequence `\n` untuk output baris baru di CLI
- Konfigurasi path file yang mengandung backslash (Windows)

## Kesalahan Umum yang Sering Terjadi
- **Menyangka variabel di-parse di single quote**: `'Halo $nama'` akan mencetak `Halo $nama`, bukan nilai `$nama`.
- **Lupa kurung kurawal**: `"$judulBuku"` — PHP bingung karena `$judulBuku` vs `$judul` + `Buku`. Solusi: `"{$judul}Buku"`.
- **Escape sequence tidak berfungsi di single quote**: `'\n'` tidak membuat baris baru — itu hanya teks `\n`.
- **Heredoc/Nowdoc indentasi**: Identifier penutup harus tanpa spasi atau tab di awal baris.
- **Overhead performa**: Double quote sedikit lebih lambat karena parsing — untuk teks statis murni, gunakan single quote.

## Soal Latihan & Jawaban
### Soal
Seorang petugas perpustakaan ingin membuat papan pengumuman. Buat variabel `$namaBuku = "PHP Dasar"`, `$peminjam = "Andi"`, dan `$denda = 5000`. Gunakan double quote untuk mencetak: "Peminjam: Andi — Buku: PHP Dasar — Denda: Rp5.000" (tanpa concatenation, pakai interpolasi). Lalu cetak dengan single quote yang menampilkan literal `$namaBuku` (tidak diuraikan).

### Jawaban
```php
<?php
$namaBuku = "PHP Dasar";
$peminjam = "Andi";
$denda = 5000;

// Double quote — variabel diuraikan
echo "Peminjam: $peminjam — Buku: $namaBuku — Denda: Rp{$denda}" . "\n";

// Single quote — literal
echo 'Peminjam: $peminjam — Buku: $namaBuku — Denda: $denda' . "\n";
?>
```
