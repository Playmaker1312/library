# Array Indexed & Associative — Dua Jenis Utama

## Penjelasan
Array adalah struktur data yang menyimpan **banyak nilai** dalam satu variabel. PHP punya dua jenis utama:

**1. Indexed Array (Numerik)**
- Menggunakan index angka integer (dimulai dari 0)
- Mirip dengan daftar biasa — cocok untuk kumpulan item sejenis
- Sintaks: `$arr = [nilai1, nilai2, nilai3]`

**2. Associative Array**
- Menggunakan key string yang kita tentukan sendiri
- Mirip dengan kamus (*key-value pair*) — cocok untuk data dengan label
- Sintaks: `$arr = ['key1' => value1, 'key2' => value2]`

PHP juga mendukung **multidimensional array** — array di dalam array, baik indexed maupun associative.

## Fungsi
Menyimpan, mengorganisir, dan mengakses sekumpulan data terkait dalam satu variabel. Array adalah fondasi untuk semua struktur data kompleks di PHP — dari daftar buku hingga response API.

## Cara Pengimplementasian / Code
```php
<?php
// INDEXED ARRAY
$buku = ["PHP Dasar", "Sejarah Nusantara", "Algoritma"];
echo $buku[0] . "\n";   // "PHP Dasar"
echo $buku[2] . "\n";   // "Algoritma"

// Menambah item
$buku[] = "Jaringan Komputer";
array_push($buku, "Basis Data");

print_r($buku);
/* Array (
    [0] => PHP Dasar
    [1] => Sejarah Nusantara
    [2] => Algoritma
    [3] => Jaringan Komputer
    [4] => Basis Data
) */

// ASSOCIATIVE ARRAY
$detailBuku = [
    "judul" => "PHP Dasar",
    "pengarang" => "Andi",
    "tahun" => 2025,
    "tersedia" => true
];
echo $detailBuku["judul"] . "\n";      // "PHP Dasar"
echo $detailBuku["pengarang"] . "\n";  // "Andi"

// Menambah pasangan key-value baru
$detailBuku["halaman"] = 250;

print_r($detailBuku);
/* Array (
    [judul] => PHP Dasar
    [pengarang] => Andi
    [tahun] => 2025
    [tersedia] => 1
    [halaman] => 250
) */

// MULTIDIMENSIONAL ARRAY
$koleksi = [
    ["judul" => "PHP Dasar", "pengarang" => "Andi"],
    ["judul" => "Sejarah Nusantara", "pengarang" => "Raden"]
];
echo $koleksi[0]["judul"] . "\n";      // "PHP Dasar"
echo $koleksi[1]["pengarang"] . "\n";  // "Raden"

// Satu array campuran indexed + associative
$campuran = [
    "Novel Fiksi",
    "referensi" => ["Kamus", "Ensiklopedia"],
    "Sejarah"
];
print_r($campuran);
?>
```

## Analogi
**Indexed array** seperti **rak buku bernomor** di perpustakaan — posisi 0, 1, 2, 3 dan seterusnya. Kamu merujuk buku berdasarkan nomor raknya: "Buku di rak nomor 2". **Associative array** seperti **katalog perpustakaan** — setiap buku punya label unik (nomor ISBN atau kode klasifikasi) yang kamu gunakan untuk mencari, bukan nomor urut. Misalnya `$katalog["ISBN-001"]` langsung merujuk ke data buku tertentu. **Multidimensional array** seperti **lemari arsip** dengan beberapa laci — setiap laci berisi data yang lebih detail.

## Dipakai untuk Apa
- Menyimpan hasil query database (baris sebagai associative array)
- Konfigurasi aplikasi (`$config['db_host']`, `$config['db_user']`)
- Data form dengan banyak field (`$_POST['username']`, `$_POST['email']`)
- Koleksi data untuk di-loop (daftar produk, daftar pengguna)
- Response JSON API (struktur data JSON persis seperti associative array PHP)
- Menyimpan relasi (foreign key lookup, mapping data)

## Kesalahan Umum yang Sering Terjadi
- **Index mulai dari 0, bukan 1**: Pemula sering mengakses `$arr[1]` untuk elemen pertama — padahal itu elemen kedua.
- **Typo pada key associative**: `$buku["judul"]` vs `$buku["judul "]` (spasi) — key harus persis sama.
- **Mencampur index dan key tanpa sadar**: PHP mengizinkan, tapi hasilnya membingungkan.
- **Lupa bahwa `[]` pada indexed array itu append**: `$arr[] = nilai` *menambah* elemen baru, bukan mengganti.
- **Reference vs copy**: Array di-assign ke variabel lain akan di-*copy*, bukan di-*reference* (kecuali pakai `&`).
- **Mengakses index yang tidak ada**: Menghasilkan `Warning: Undefined array key`.

## Hubungan dengan Materi Sebelumnya
Setelah variabel (materi 6) yang menyimpan satu nilai, sekarang kamu belajar menyimpan **banyak nilai** dalam satu variabel. String (materi 11-12) bisa diubah menjadi array via `explode`, dan array bisa diubah menjadi string via `implode`. Array adalah jembatan ke materi Fungsi (materi 15-17) — fungsi sering menerima dan mengembalikan array.

## Soal Latihan & Jawaban
### Soal
Buat associative array `$buku` dengan key: `judul` => "Matematika Diskrit", `pengarang` => "Prof. Budi", `tahun` => 2023, `tersedia` => false. Lalu buat indexed array `$kategori` berisi ["Sains", "Teknologi", "Seni"]. Tampilkan judul buku dari array associative, dan elemen pertama dari array indexed.

### Jawaban
```php
<?php
$buku = [
    "judul" => "Matematika Diskrit",
    "pengarang" => "Prof. Budi",
    "tahun" => 2023,
    "tersedia" => false
];

$kategori = ["Sains", "Teknologi", "Seni"];

echo "Judul buku: " . $buku["judul"] . "\n";
echo "Kategori pertama: " . $kategori[0] . "\n";
?>
```
