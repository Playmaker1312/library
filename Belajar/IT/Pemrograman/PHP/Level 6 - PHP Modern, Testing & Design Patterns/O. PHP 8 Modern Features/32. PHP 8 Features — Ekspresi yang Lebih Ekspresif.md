# PHP 8 Features — Ekspresi yang Lebih Ekspresif

## Penjelasan

PHP 8.0 (dirilis November 2020) dan PHP 8.1 (November 2021) membawa perubahan besar dalam cara menulis kode PHP. Fitur-fitur baru ini membuat kode lebih pendek, lebih ekspresif, dan mengurangi boilerplate. PHP 8 tidak hanya menambah sintaks baru, tetapi juga mengubah paradigma — dari bahasa prosedural yang "longgar" menjadi bahasa yang mendukung type safety dan ekspresi deklaratif.

Fitur utama yang akan dibahas:

| Fitur | PHP 8.0 | PHP 8.1 |
|-------|---------|---------|
| Match Expression | ✅ | ✅ |
| Named Arguments | ✅ | ✅ |
| Nullsafe Operator | ✅ | ✅ |
| Union Types | ✅ | ✅ |
| Constructor Property Promotion | ✅ | ✅ |
| Readonly Properties | ❌ | ✅ |
| Enums | ❌ | ✅ |
| First-class Callable Syntax | ✅ | ✅ |
| Array unpacking with string keys | ✅ | ✅ |
| Fibers (Async) | ❌ | ✅ |

Match expression adalah pengganti switch yang lebih aman — tidak perlu `break`, mengembalikan nilai, dan melakukan strict comparison (`===`). Named arguments memungkinkan kita melewatkan parameter berdasarkan nama, bukan posisi — jadi tidak perlu mengingat urutan parameter. Nullsafe operator (`?->`) menghentikan rantai pemanggilan method jika salah satu nilainya null — tanpa perlu serangkaian `if` pengecekan null.

## Fungsi

Fitur-fitur ini mengurangi kode boilerplate, meningkatkan readability, dan mencegah bug umum. Match mencegah bug karena lupa `break` di switch. Named arguments membuat kode di call site lebih jelas — parameter `$limit` dan `$offset` tidak perlu diingat urutannya. Nullsafe operator menghilangkan nested if bertingkat untuk pengecekan null. Union types dan constructor promotion membuat definisi class lebih ringkas. Enums memberikan tipe data terbatas yang lebih ekspresif daripada konstanta class.

## Cara Pengimplementasian / Code

<?php

// =====================
// 1. MATCH EXPRESSION
// =====================
function statusPeminjaman(string $status): string {
    // Switch lama (rentan lupa break)
    // switch ($status) {
    //     case 'dipinjam': $hasil = 'Sedang dibaca'; break;
    //     case 'kembali':  $hasil = 'Sudah dikembalikan'; break;
    //     case 'telat':    $hasil = 'Terlambat!'; break;
    //     default:         $hasil = 'Unknown';
    // }

    return match ($status) {
        'dipinjam' => 'Sedang dibaca',
        'kembali'  => 'Sudah dikembalikan',
        'telat'    => 'Terlambat!',
        default    => 'Status tidak dikenal',
    };
}

echo statusPeminjaman('dipinjam'); // Sedang dibaca

// Match dengan kondisi (multiple condition per arm)
function dendaPerHari(int $hariTerlambat): int {
    return match (true) {
        $hariTerlambat <= 0  => 0,
        $hariTerlambat <= 3  => 1000,
        $hariTerlambat <= 7  => 2000,
        $hariTerlambat <= 14 => 5000,
        default              => 10000,
    };
}

echo dendaPerHari(5); // 2000

// =====================
// 2. NAMED ARGUMENTS
// =====================
function cariBuku(
    string $judul = '',
    string $pengarang = '',
    int $tahun = 0,
    int $limit = 10,
    int $offset = 0
): string {
    return "Mencari: judul=$judul, pengarang=$pengarang, tahun=$tahun (limit $limit, offset $offset)";
}

// Tanpa named arguments — harus hafal urutan
echo cariBuku('', 'Tere Liye', 0, 5, 0);

// Dengan named arguments — jelas dan tidak butuh parameter default
echo cariBuku(pengarang: 'Tere Liye', limit: 5);

// Bisa campur posisional dan named (posisional duluan)
echo cariBuku('Belajar PHP', tahun: 2024);

// 3. NULLSAFE OPERATOR (?->)
// =====================
class Anggota {
    public ?Alamat $alamat = null;
    public string $nama;

    public function __construct(string $nama, ?Alamat $alamat = null) {
        $this->nama = $nama;
        $this->alamat = $alamat;
    }
}

class Alamat {
    public string $kota;
    public function __construct(string $kota) {
        $this->kota = $kota;
    }
}

$andi = new Anggota('Andi');
$siti = new Anggota('Siti', new Alamat('Jakarta'));

// Tanpa nullsafe — butuh nested if
function getKotaLama(?Anggota $anggota): string {
    if ($anggota !== null) {
        if ($anggota->alamat !== null) {
            return $anggota->alamat->kota;
        }
    }
    return 'Tidak diketahui';
}

// Dengan nullsafe — satu baris
function getKota(?Anggota $anggota): string {
    return $anggota?->alamat?->kota ?? 'Tidak diketahui';
}

echo getKota($andi); // Tidak diketahui  (andi->alamat == null)
echo getKota($siti); // Jakarta
echo getKota(null);  // Tidak diketahui

// 4. UNION TYPES
// =====================
class Buku {
    public function __construct(
        public string $judul,
        public string|array $pengarang,  // bisa string atau array of string
        public int|null $tahun = null,   // int|null sama dengan ?int
    ) {}

    public function getPengarang(): string {
        return is_array($this->pengarang)
            ? implode(', ', $this->pengarang)
            : $this->pengarang;
    }
}

$buku1 = new Buku('PHP Dasar', 'Andi Prasetyo', 2023);
$buku2 = new Buku('Laravel Pro', ['Budi', 'Citra'], 2024);

echo $buku1->getPengarang(); // Andi Prasetyo

## Analogi

Fitur PHP 8 ini seperti **sistem katalog perpustakaan modern** yang menggantikan kartu katalog manual.

- **Match expression** adalah petugas yang langsung memberi jawaban pasti dari satu pertanyaan, tanpa perlu bolak-balik mengecek rak — efisien dan tidak bisa salah letak seperti switch yang lupa `break`.
- **Named arguments** adalah formulir peminjaman yang kolomnya sudah diberi label "Judul Buku", "Nama Peminjam", "Tanggal" — Anda tidak perlu mengingat urutan kolom, cukup isi sesuai labelnya.
- **Nullsafe operator** adalah jalur cepat di perpustakaan: jika buku sudah dipinjam orang lain (null), petugas langsung bilang "tidak tersedia" tanpa harus mengecek satu per satu lemari.
- **Union types** seperti rak buku yang bisa diisi buku atau majalah — fleksibel tapi tetap terdefinisi.
- **Constructor promotion** adalah formulir pendaftaran anggota baru: nama, alamat, telepon dicatat langsung di satu lembar tanpa perlu difotokopi berkali-kali.
- **Enums** adalah stiker status di punggung buku: "Tersedia", "Dipinjam", "Rusak" — nilai yang terbatas dan jelas, bukan string sembarangan yang bisa typo.
- **Readonly** adalah buku referensi yang hanya boleh dibaca di tempat, tidak boleh dibawa pulang — properti hanya bisa dibaca, tidak bisa diubah.

## Dipakai untuk Apa

- **Match expression** — menggantikan switch untuk mapping nilai, perhitungan denda, status routing, dan conditional assignment
- **Named arguments** — konstruktor dengan banyak parameter opsional, konfigurasi, query builder, dan validasi
- **Nullsafe operator** — chaining method pada object yang mungkin null, navigasi relasi database (anggota->alamat->kota)
- **Union types** — parameter yang bisa menerima multiple type (string|array untuk pengarang), nullable types, return type fleksibel
- **Constructor promotion** — DTO (Data Transfer Object), Entity class, Value Object — semua class yang hanya menyimpan data
- **Readonly properties** — immutable object, konfigurasi, value object yang tidak boleh berubah setelah dibuat
- **Enums** — status (buku, peminjaman, anggota), kategori, tipe, role user, dan semua data dengan nilai terbatas
- **First-class callable** — callback ke array_map, array_filter, pipeline pattern, event handler
- **Array unpacking** — menggabungkan konfigurasi, merge data array asosiatif, default values

## Kesalahan Umum yang Sering Terjadi

- **Match bukan switch — strict comparison**: Match menggunakan `===` bukan `==`. `match ('1')` tidak akan cocok dengan case `1`.
- **Match harus exhaustive**: Match harus mencakup semua kemungkinan — jika ada value yang tidak tercakup dan tidak ada `default`, error `UnhandledMatchError`.
- **Named arguments setelah positional**: Setelah menggunakan named argument, semua argumen berikutnya HARUS named juga — `cariBuku('PHP', tahun: 2024, 5)` error, harus `cariBuku('PHP', tahun: 2024, limit: 5)`.
- **Nullsafe operator tidak bisa di assignment**: `$obj?->property = value` error — nullsafe hanya untuk read, bukan write.
- **Union type `false` tidak untuk return type**: Untuk return type, gunakan `?type` atau `type|null`, bukan `false`. `false` hanya untuk backward compatibility dengan fungsi bawaan.
- **Constructor promotion tidak bisa digabung dengan property biasa di class yang sama**: Jika satu parameter menggunakan promotion, semua parameter lain di konstruktor yang sama juga harus — tidak bisa campur promoted dan non-promoted di satu constructor.
- **Enum bukan class biasa**: Enum tidak bisa di-instantiate dengan `new`, tidak bisa di-extend, tidak bisa memiliki property non-static selain `name` dan `value`.
- **Readonly property hanya bisa di-set sekali**: Readonly property hanya bisa di-set di constructor — tidak bisa di-setter method atau diubah setelahnya.
- **First-class callable syntax butuh PHP 8.1**: `fungsi(...)` tidak berfungsi di PHP 8.0 — gunakan `Closure::fromCallable('fungsi')`.

## Hubungan dengan Materi Sebelumnya

Materi 7 (Type Juggling) dan 8 (Type Casting) adalah dasar untuk memahami Union Types — PHP 8 memperketat type handling dengan strict comparison di match. Materi 10 (Operator) diperluas dengan nullsafe operator (`?->`) yang merupakan operator navigasi aman. Materi 15 (Fungsi) dan 16 (Closure & Arrow Function) diperkaya dengan first-class callable syntax dan named arguments. Materi 23-25 (OOP: Class, Inheritance, Interface/Trait) adalah fondasi untuk constructor promotion, readonly properties, dan enums — semua fitur OOP yang lebih modern. Materi 13-14 (Array) terkait dengan array unpacking dengan string keys. Setelah materi ini, kamu siap belajar Design Patterns (materi 34) yang sering menggunakan fitur PHP 8 untuk implementasi yang lebih bersih.

## Soal Latihan & Jawaban

### Soal

Buat class `DendaCalculator` yang menggunakan enum PHP 8.1 untuk kategori keterlambatan dan match expression untuk menghitung denda. Class ini harus memiliki:

1. Enum `KategoriTelat` dengan case: `TEPAT_WAKTU` (0 hari), `RINGAN` (1-3 hari), `SEDANG` (4-7 hari), `BERAT` (8-14 hari), `EKSTREM` (>14 hari). Masing-masing memiliki nilai int berupa tarif denda per hari.
2. Method `hitung(int $hariTelat): int` yang menggunakan match expression untuk menentukan kategori dan mengembalikan total denda: `hariTelat * tarif`.
3. Constructor promotion dan readonly properties untuk menyimpan `$namaPeminjam` dan `$judulBuku`.
4. Named arguments saat membuat instance.

Contoh: `hitung(5)` → termasuk kategori SEDANG (tarif 2000) → 5 * 2000 = 10000.

### Jawaban

```php
<?php

enum KategoriTelat: int {
    case TEPAT_WAKTU = 0;
    case RINGAN      = 1000;
    case SEDANG      = 2000;
    case BERAT       = 5000;
    case EKSTREM     = 10000;

    public function label(): string {
        return match ($this) {
            self::TEPAT_WAKTU => 'Tepat waktu',
            self::RINGAN      => 'Telat ringan (1-3 hari)',
            self::SEDANG      => 'Telat sedang (4-7 hari)',
            self::BERAT       => 'Telat berat (8-14 hari)',
            self::EKSTREM     => 'Telat ekstrem (>14 hari)',
        };
    }
}

class DendaCalculator {
    public function __construct(
        public readonly string $namaPeminjam,
        public readonly string $judulBuku,
    ) {}

    public function hitung(int $hariTelat): array {
        $kategori = match (true) {
            $hariTelat <= 0  => KategoriTelat::TEPAT_WAKTU,
            $hariTelat <= 3  => KategoriTelat::RINGAN,
            $hariTelat <= 7  => KategoriTelat::SEDANG,
            $hariTelat <= 14 => KategoriTelat::BERAT,
            default          => KategoriTelat::EKSTREM,
        };

        $totalDenda = $hariTelat * $kategori->value;

        return [
            'peminjam'     => $this->namaPeminjam,
            'buku'         => $this->judulBuku,
            'hari_telat'   => $hariTelat,
            'kategori'     => $kategori->label(),
            'tarif_per_hari' => $kategori->value,
            'total_denda'  => $totalDenda,
        ];
    }
}

// Gunakan named arguments
$kalkulator = new DendaCalculator(
    namaPeminjam: 'Siti Aminah',
    judulBuku: 'Belajar PHP 8',
);

$result = $kalkulator->hitung(hariTelat: 5);
print_r($result);

// Hasil:
// [
//   'peminjam'      => 'Siti Aminah',
//   'buku'          => 'Belajar PHP 8',
//   'hari_telat'    => 5,
//   'kategori'      => 'Telat sedang (4-7 hari)',
//   'tarif_per_hari' => 2000,
//   'total_denda'   => 10000,
// ]

// Test berbagai kasus:
echo $kalkulator->hitung(0)['total_denda'];   // 0
echo $kalkulator->hitung(2)['total_denda'];   // 2000
echo $kalkulator->hitung(10)['total_denda'];  // 50000
echo $kalkulator->hitung(20)['total_denda'];  // 200000
?>
```
