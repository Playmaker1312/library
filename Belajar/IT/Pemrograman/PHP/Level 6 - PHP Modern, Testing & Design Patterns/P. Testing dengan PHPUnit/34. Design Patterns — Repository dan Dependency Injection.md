# Design Patterns — Repository dan Dependency Injection

## Penjelasan

**Design Patterns** adalah solusi umum yang sudah teruji untuk masalah yang sering muncul dalam pengembangan perangkat lunak. Dua pattern fundamental dalam PHP modern adalah **Repository Pattern** dan **Dependency Injection**.

### Repository Pattern

Repository adalah lapisan abstraksi antara logika bisnis dan penyimpanan data. Alih-alih menulis query SQL langsung di controller atau service, Repository membungkus semua akses data dalam satu class. Jika suatu saat Anda mengganti MySQL ke PostgreSQL, atau dari database ke API eksternal, cukup ubah satu class repository — kode bisnis tidak perlu disentuh.

Struktur Repository:
```
Interface (abstraksi kontrak)
    ↑
RepositoryImpl (implementasi konkret — MySQL, file, API, mock)
    ↑
Service/Business Logic (hanya kenal interface, bukan implementasi)
```

### Dependency Injection (DI)

Dependency Injection adalah teknik di mana dependensi (object yang dibutuhkan) diberikan dari luar, bukan dibuat sendiri di dalam class. Ini membuat class tidak perlu tahu cara membuat dependensinya — cukup terima dan pakai.

```php
// ❌ Tanpa DI — class membuat dependensi sendiri
class PeminjamanService {
    private PDO $pdo;
    public function __construct() {
        $this->pdo = new PDO('mysql:host=localhost;dbname=library', 'root', '');
    }
}

// ✅ Dengan DI — dependensi diberikan dari luar
class PeminjamanService {
    public function __construct(
        private BukuRepositoryInterface $bukuRepo,
        private AnggotaRepositoryInterface $anggotaRepo,
    ) {}
}
```

Keuntungan DI:
- **Testability** — ganti repository dengan mock di unit test
- **Flexibility** — ganti implementasi tanpa ubah kode pemanggil
- **Separation of concerns** — class tidak bertanggung jawab membuat dependensinya
- **Reusability** — repository bisa dipakai ulang di banyak service

### Dependency Injection Container (DIC)

Container adalah alat yang mengelola pembuatan dan pemberian dependensi secara otomatis. Anda cukup mendaftarkan interface ke implementasi, dan container akan merangkai semua dependensi (auto-wiring). Contoh populer: PHP-DI, Laravel Service Container.

## Fungsi

Repository memisahkan **logika bisnis** dari **logika penyimpanan data**. Service class tidak perlu tahu apakah data disimpan di MySQL, file JSON, atau API eksternal — cukup panggil method repository `cariById()`, `simpan()`, `hapus()`. Dependency Injection membuat setiap class menerima dependensinya dari luar, sehingga testability maksimal (mudah di-mock) dan perubahan implementasi tidak berdampak ke mana-mana. Bersama-sama, Repository + DI membentuk fondasi arsitektur yang SOLID — terutama **D** (Dependency Inversion) dan **I** (Interface Segregation).

```php
namespace Perpustakaan\Repository;

interface BukuRepositoryInterface {
    public function cariById(int $id): ?array;
    public function cariSemua(string $orderBy = 'judul'): array;
    public function simpan(array $data): int;
    public function update(int $id, array $data): bool;
    public function hapus(int $id): bool;
    public function countPinjamanAktif(int $anggotaId): int;
    public function updateStatus(int $id, string $status): void;
}

interface AnggotaRepositoryInterface {
    public function cariById(int $id): ?array;
    public function cariSemua(): array;
    public function simpan(array $data): int;
    public function update(int $id, array $data): bool;
    public function hapus(int $id): bool;
}

// =====================
// 2. IMPLEMENTASI REPOSITORY — MySQL via PDO
// =====================

class BukuRepository implements BukuRepositoryInterface {
    public function __construct(
        private \PDO $pdo,
    ) {}

    public function cariById(int $id): ?array {
        $stmt = $this->pdo->prepare("SELECT * FROM buku WHERE id = ?");
        $stmt->execute([$id]);
        $result = $stmt->fetch(\PDO::FETCH_ASSOC);
        return $result ?: null;
    }

    public function cariSemua(string $orderBy = 'judul'): array {
        $kolomValid = ['judul', 'pengarang', 'tahun', 'id'];
        $order = in_array($orderBy, $kolomValid) ? $orderBy : 'judul';
        $stmt = $this->pdo->query("SELECT * FROM buku ORDER BY $order");
        return $stmt->fetchAll(\PDO::FETCH_ASSOC);
    }

    public function simpan(array $data): int {
        $stmt = $this->pdo->prepare(
            "INSERT INTO buku (judul, pengarang, tahun) VALUES (?, ?, ?)"
        );
        $stmt->execute([$data['judul'], $data['pengarang'], $data['tahun'] ?? date('Y')]);
        return (int) $this->pdo->lastInsertId();
    }

    public function update(int $id, array $data): bool {
        $fields = [];
        $values = [];
        foreach (['judul', 'pengarang', 'tahun'] as $field) {
            if (isset($data[$field])) {
                $fields[] = "$field = ?";
                $values[] = $data[$field];
            }
        }
        if (empty($fields)) return false;

        $values[] = $id;
        $sql = "UPDATE buku SET " . implode(', ', $fields) . " WHERE id = ?";
        $stmt = $this->pdo->prepare($sql);
        return $stmt->execute($values);
    }

    public function hapus(int $id): bool {
        $stmt = $this->pdo->prepare("DELETE FROM buku WHERE id = ?");
        return $stmt->execute([$id]);
    }

    public function countPinjamanAktif(int $anggotaId): int {
        $stmt = $this->pdo->prepare(
            "SELECT COUNT(*) FROM peminjaman WHERE anggota_id = ? AND tanggal_kembali IS NULL"
        );
        $stmt->execute([$anggotaId]);
        return (int) $stmt->fetchColumn();
    }

    public function updateStatus(int $id, string $status): void {
        $stmt = $this->pdo->prepare("UPDATE buku SET status = ? WHERE id = ?");
        $stmt->execute([$status, $id]);
    }
}

namespace Perpustakaan\Service;

use Perpustakaan\Repository\BukuRepositoryInterface;
use Perpustakaan\Repository\AnggotaRepositoryInterface;

class PeminjamanService {
    public function __construct(
        private BukuRepositoryInterface $bukuRepo,
        private AnggotaRepositoryInterface $anggotaRepo,
    ) {}

    public function pinjamBuku(int $anggotaId, int $bukuId): array {
        $anggota = $this->anggotaRepo->cariById($anggotaId)
            ?? throw new \InvalidArgumentException('Anggota tidak ditemukan');

        $buku = $this->bukuRepo->cariById($bukuId)
            ?? throw new \InvalidArgumentException('Buku tidak ditemukan');

        if ($this->bukuRepo->countPinjamanAktif($anggotaId) >= 3) {
            throw new \RuntimeException('Limit peminjaman tercapai (maks 3)');
        }

        $this->bukuRepo->updateStatus($bukuId, 'dipinjam');
        return ['message' => 'Buku berhasil dipinjam', 'id' => $bukuId];
    }

    public function kembalikanBuku(int $bukuId): array {
        $buku = $this->bukuRepo->cariById($bukuId)
            ?? throw new \InvalidArgumentException('Buku tidak ditemukan');

        if ($buku['status'] === 'tersedia') {
            throw new \RuntimeException('Buku sudah dikembalikan sebelumnya');
        }

        $this->bukuRepo->updateStatus($bukuId, 'tersedia');
        return ['message' => 'Buku berhasil dikembalikan'];
    }
}

class LaporanService {
    public function __construct(
        private BukuRepositoryInterface $bukuRepo,
    ) {}

    public function bukuTerpopuler(int $limit = 5): array {
        return $this->bukuRepo->cariSemua(orderBy: 'tahun');
        // Di implementasi riil, query JOIN dengan peminjaman
    }
}

// 4. DEPENDENCY INJECTION CONTAINER (manual)
// =====================

namespace Perpustakaan\Container;

// DI Container sederhana (tanpa library)
class SimpleContainer {
    private array $bindings = [];
    private array $instances = [];

    public function set(string $abstract, callable $factory): void {
        $this->bindings[$abstract] = $factory;
    }

    public function get(string $abstract): mixed {
        if (!isset($this->instances[$abstract])) {
            if (!isset($this->bindings[$abstract])) {
                throw new \RuntimeException("Binding tidak ditemukan: $abstract");
            }
            $this->instances[$abstract] = ($this->bindings[$abstract])($this);
        }
        return $this->instances[$abstract];
    }

    public function has(string $abstract): bool {
        return isset($this->bindings[$abstract]);
    }
}

// =====================
// 5. REGISTRASI DEPENDENSI
// =====================

use Perpustakaan\Container\SimpleContainer;
use Perpustakaan\Repository\AnggotaRepository;
use Perpustakaan\Repository\AnggotaRepositoryInterface;
use Perpustakaan\Repository\BukuRepository;
use Perpustakaan\Repository\BukuRepositoryInterface;
use Perpustakaan\Service\LaporanService;
use Perpustakaan\Service\PeminjamanService;

$container = new SimpleContainer();

// Daftarkan koneksi database
$container->set(\PDO::class, function () {
    return new \PDO(
        'mysql:host=localhost;dbname=perpustakaan;charset=utf8mb4',
        'root', '',
        [
            \PDO::ATTR_ERRMODE            => \PDO::ERRMODE_EXCEPTION,
            \PDO::ATTR_DEFAULT_FETCH_MODE => \PDO::FETCH_ASSOC,
            \PDO::ATTR_EMULATE_PREPARES   => false,
        ]
    );
});

// Daftarkan interface ke implementasi
$container->set(BukuRepositoryInterface::class, function ($c) {
    return new BukuRepository($c->get(\PDO::class));
});

$container->set(AnggotaRepositoryInterface::class, function ($c) {
    return new AnggotaRepository($c->get(\PDO::class));
});

// Daftarkan service
$container->set(PeminjamanService::class, function ($c) {
    return new PeminjamanService(
        $c->get(BukuRepositoryInterface::class),
        $c->get(AnggotaRepositoryInterface::class),
    );
});

$container->set(LaporanService::class, function ($c) {
    return new LaporanService(
        $c->get(BukuRepositoryInterface::class),
    );
});

// =====================
// 6. PENGGUNAAN
// =====================

$peminjamanService = $container->get(PeminjamanService::class);
$result = $peminjamanService->pinjamBuku(1, 1);
echo $result['message']; // Buku berhasil dipinjam

$laporanService = $container->get(LaporanService::class);
$bukuPopuler = $laporanService->bukuTerpopuler(10);
print_r($bukuPopuler);
```

### Dengan PHP-DI (library resmi)

```php
<?php
// Install: composer require php-di/php-di

use Perpustakaan\Repository\AnggotaRepository;
use Perpustakaan\Repository\AnggotaRepositoryInterface;
use Perpustakaan\Repository\BukuRepository;
use Perpustakaan\Repository\BukuRepositoryInterface;

$container = new DI\Container();

// PHP-DI bisa auto-wiring — secara otomatis membaca type hint constructor
// Tapi tetap perlu binding interface ke class konkret
$container->set(BukuRepositoryInterface::class, \DI\autowire(BukuRepository::class));
$container->set(AnggotaRepositoryInterface::class, \DI\autowire(AnggotaRepository::class));

// PDO perlu dikonfigurasi manual
$container->set(\PDO::class, \DI\factory(function () {
    return new \PDO('mysql:host=localhost;dbname=perpustakaan', 'root', '');
}));

// Service akan di-auto-wire otomatis
$service = $container->get(\Perpustakaan\Service\PeminjamanService::class);
$service->pinjamBuku(1, 1);
```

## Analogi

### Repository
Repository adalah **petugas sirkulasi perpustakaan**. Service class (pustakawan) tidak perlu tahu di mana buku disimpan — apakah di rak lantai 1, lantai 2, gudang bawah tanah, atau bahkan di perpustakaan cabang lain. Pustakawan cukup bilang "tolong cari buku ini" ke petugas sirkulasi (repository), dan petugas yang akan mengurus detailnya. Jika sistem penyimpanan berubah (misalnya, dari katalog kartu ke database digital), cukup petugas sirkulasi yang berubah — pustakawan tetap sama.

### Dependency Injection
DI adalah **sistem pemesanan antar bagian perpustakaan**. Bagian katalog tidak perlu membuat sendiri lembar peminjaman — bagian sirkulasi yang menyediakannya. Bagian pengembalian tidak perlu membuat sendiri stempel tanggal — bagian administrasi yang memberikannya. Setiap bagian menerima alat yang dibutuhkan dari luar, bukan membuat sendiri. Ini membuat setiap bagian bisa diganti tanpa mengganggu bagian lain, dan saat latihan (testing), kita bisa memberi alat palsu (mock) untuk simulasi.

### DI Container
DI Container adalah **supervisor perpustakaan** yang tahu siapa butuh apa. Supervisor melihat bahwa PeminjamanService butuh BukuRepository, lalu supervisor mengambil BukuRepository (yang butuh PDO), membuatkannya, dan memberikannya ke PeminjamanService. Supervisor ini yang mengatur seluruh rantai dependensi, jadi pustakawan tidak perlu pusing.

## Dipakai untuk Apa

- **Repository** — abstraksi database, memudahkan ganti dari MySQL ke PostgreSQL atau ke API, memudahkan unit testing dengan mock, memusatkan logika query di satu tempat, memisahkan business logic dari penyimpanan
- **Dependency Injection** — membuat kode testable (mudah di-mock), mengurangi coupling antar class, memudahkan penggantian implementasi, memungkinkan auto-wiring dengan DI container
- **DI Container** — mengelola lifecycle object, auto-resolve dependensi bertingkat, konfigurasi terpusat, menghilangkan kode "new" yang tersebar
- **Kombinasi Repository + DI** — arsitektur hexagonal / clean architecture, Laravel service container + Eloquent Repository, Symfony + Doctrine Repository

## Kesalahan Umum yang Sering Terjadi

- **Repository terlalu tebal**: Repository berisi logika bisnis (contoh: `if ($denda > 100000) { kirimEmail() }`) — Repository hanya boleh berisi logika database.
- **Tidak pakai interface**: Langsung pakai class konkret (`BukuRepository`) sebagai type hint — saat ganti implementasi, harus ubah semua kode yang mereferensi class tersebut.
- **DI Container sebagai Service Locator**: Memanggil `$container->get()` di dalam class — class jadi tergantung container, bukan dependensi yang di-inject.
- **Constructor terlalu banyak parameter**: Lebih dari 5 parameter di constructor biasanya tanda class melanggar SRP — pertimbangkan facade atau grouped parameter.
- **Repository mengembalikan Entity object**: Repository mengembalikan array sudah cukup untuk PHP tanpa framework — jika butuh object, buat layer transformer terpisah.
- **Setiap class dibuatkan interface**: Interface hanya diperlukan jika ada kemungkinan multiple implementation — untuk class yang hanya punya satu implementasi, interface adalah overhead.
- **Lupa daftarkan binding di container**: Aplikasi error "Class not found" atau "Cannot resolve dependency" — selalu cek registrasi binding.
- **Singleton berlebihan**: Repository dibuat singleton padahal stateless — tidak masalah, tapi pastikan tidak ada state internal yang disimpan antar request.

## Soal Latihan & Jawaban

### Soal

Buat implementasi **Repository Pattern** + **Dependency Injection** untuk fitur denda perpustakaan dengan ketentuan:

1. Interface `DendaRepositoryInterface` dengan method: `cariById(int $id): ?array`, `simpan(array $data): int`, `cariByAnggota(int $anggotaId): array`
2. Class `DendaRepository` (implementasi MySQL via PDO) — kolom tabel denda: `id`, `anggota_id`, `buku_id`, `hari_telat`, `total_denda`, `status` (lunas/belum)
3. Class `DendaService` yang menerima `DendaRepositoryInterface` via constructor injection
4. Method `hitungDanSimpanDenda(int $anggotaId, int $bukuId, int $hariTelat): array` — hitung denda dengan rumus: hariTelat * 2000, simpan ke database, return data denda
5. Method `lunaskanDenda(int $dendaId): array` — ubah status jadi 'lunas'
6. Gunakan constructor promotion (PHP 8) dan named arguments saat membuat instance

### Jawaban

```php
<?php
declare(strict_types=1);

namespace Perpustakaan\Repository;

interface DendaRepositoryInterface {
    public function cariById(int $id): ?array;
    public function simpan(array $data): int;
    public function updateStatus(int $id, string $status): void;
    public function cariByAnggota(int $anggotaId): array;
}

class DendaRepository implements DendaRepositoryInterface {
    public function __construct(
        private \PDO $pdo,
    ) {}

    public function cariById(int $id): ?array {
        $stmt = $this->pdo->prepare("SELECT * FROM denda WHERE id = ?");
        $stmt->execute([$id]);
        $result = $stmt->fetch(\PDO::FETCH_ASSOC);
        return $result ?: null;
    }

    public function simpan(array $data): int {
        $stmt = $this->pdo->prepare(
            "INSERT INTO denda (anggota_id, buku_id, hari_telat, total_denda, status)
             VALUES (?, ?, ?, ?, ?)"
        );
        $stmt->execute([
            $data['anggota_id'],
            $data['buku_id'],
            $data['hari_telat'],
            $data['total_denda'],
            $data['status'] ?? 'belum',
        ]);
        return (int) $this->pdo->lastInsertId();
    }

    public function updateStatus(int $id, string $status): void {
        $stmt = $this->pdo->prepare("UPDATE denda SET status = ? WHERE id = ?");
        $stmt->execute([$status, $id]);
    }

    public function cariByAnggota(int $anggotaId): array {
        $stmt = $this->pdo->prepare(
            "SELECT d.*, b.judul as judul_buku
             FROM denda d
             JOIN buku b ON b.id = d.buku_id
             WHERE d.anggota_id = ?
             ORDER BY d.id DESC"
        );
        $stmt->execute([$anggotaId]);
        return $stmt->fetchAll(\PDO::FETCH_ASSOC);
    }
}

namespace Perpustakaan\Service;

use Perpustakaan\Repository\DendaRepositoryInterface;

class DendaService {
    private const int TARIF_PER_HARI = 2000;

    public function __construct(
        private DendaRepositoryInterface $dendaRepo,
    ) {}

    public function hitungDanSimpanDenda(int $anggotaId, int $bukuId, int $hariTelat): array {
        if ($hariTelat < 0) {
            throw new \InvalidArgumentException('Hari telat tidak boleh negatif');
        }

        $total = $hariTelat * self::TARIF_PER_HARI;

        $id = $this->dendaRepo->simpan([
            'anggota_id'  => $anggotaId,
            'buku_id'     => $bukuId,
            'hari_telat'  => $hariTelat,
            'total_denda' => $total,
            'status'      => $total > 0 ? 'belum' : 'lunas',
        ]);

        return [
            'id'          => $id,
            'anggota_id'  => $anggotaId,
            'buku_id'     => $bukuId,
            'hari_telat'  => $hariTelat,
            'total_denda' => $total,
            'status'      => $total > 0 ? 'belum' : 'lunas',
        ];
    }

    public function lunaskanDenda(int $dendaId): array {
        $denda = $this->dendaRepo->cariById($dendaId)
            ?? throw new \InvalidArgumentException('Data denda tidak ditemukan');

        if ($denda['status'] === 'lunas') {
            throw new \RuntimeException('Denda sudah lunas sebelumnya');
        }

        $this->dendaRepo->updateStatus($dendaId, 'lunas');

        return [
            'message' => 'Denda berhasil dilunaskan',
            'id'      => $dendaId,
            'total'   => $denda['total_denda'],
        ];
    }
}

// =====================
// PENGGUNAAN
// =====================

$pdo = new \PDO('sqlite::memory:');
$pdo->exec("CREATE TABLE denda (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    anggota_id INTEGER NOT NULL,
    buku_id INTEGER NOT NULL,
    hari_telat INTEGER NOT NULL,
    total_denda INTEGER NOT NULL,
    status TEXT NOT NULL DEFAULT 'belum'
)");
$pdo->exec("CREATE TABLE buku (id INTEGER PRIMARY KEY, judul TEXT)");

$repo = new \Perpustakaan\Repository\DendaRepository($pdo);
$service = new \Perpustakaan\Service\DendaService($repo);

// Hitung dan simpan denda — 5 hari telat = 5 * 2000 = 10000
$result = $service->hitungDanSimpanDenda(
    anggotaId: 1,
    bukuId: 1,
    hariTelat: 5,
);
print_r($result);
// [
//   'id'          => 1,
//   'anggota_id'  => 1,
//   'buku_id'     => 1,
//   'hari_telat'  => 5,
//   'total_denda' => 10000,
//   'status'      => 'belum',
// ]

// Lunaskan denda
echo $service->lunaskanDenda(dendaId: 1)['message']; // Denda berhasil dilunaskan
```
