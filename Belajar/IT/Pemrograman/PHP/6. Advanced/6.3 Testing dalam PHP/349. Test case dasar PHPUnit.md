# 349. Test Case Dasar PHPUnit

## Definisi Singkat
Test case adalah class yang berisi method-method test untuk menguji fungsionalitas spesifik dalam aplikasi PHP.

## Analogi
Seperti checklist inspeksi — setiap item adalah satu test yang harus lulus sebelum mobil dinyatakan layak jalan.

## Poin-Poin Penting
- Class test extends `PHPUnit\Framework\TestCase`
- Method test diawali `test` atau pakai `#[Test]` attribute
- Setiap method menguji satu perilaku spesifik
- Nama test method harus deskriptif
- Test bisa dijalankan secara individu atau seluruh suite

## Contoh Kode (PHP)
```php
<?php
use PHPUnit\Framework\TestCase;

class Calculator {
    public function add(float $a, float $b): float { return $a + $b; }
    public function subtract(float $a, float $b): float { return $a - $b; }
    public function multiply(float $a, float $b): float { return $a * $b; }
}

class CalculatorTest extends TestCase {
    private Calculator $calc;
    
    protected function setUp(): void {
        $this->calc = new Calculator();
    }
    
    public function testAddition(): void {
        $result = $this->calc->add(2, 3);
        $this->assertEquals(5, $result);
        $this->assertIsFloat($result);
    }
    
    public function testSubtraction(): void {
        $this->assertEquals(3, $this->calc->subtract(7, 4));
    }
    
    public function testMultiplication(): void {
        $this->assertEquals(12, $this->calc->multiply(3, 4));
    }
    
    #[\PHPUnit\Framework\Attributes\Test]
    public function addition_with_negative_numbers(): void {
        $this->assertEquals(-1, $this->calc->add(-3, 2));
    }
}
?>
```

## Kasus Penggunaan Nyata
Testing service classes, validators, helpers, utilities — semua unit logic yang memiliki input/output yang bisa diverifikasi.
