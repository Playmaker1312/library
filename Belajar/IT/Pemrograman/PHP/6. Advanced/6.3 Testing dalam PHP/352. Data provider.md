# 352. Data Provider

## Definisi Singkat
Data provider adalah method PHPUnit yang menyediakan kumpulan data untuk menjalankan test yang sama dengan input berbeda.

## Analogi
Seperti mesin yang menguji kualitas air — Anda mengambil sampel dari berbagai sumber, tapi proses pengujiannya sama.

## Poin-Poin Penting
- Attribute `#[DataProvider('methodName')]` atau PHPDoc `@dataProvider`
- Method provider mengembalikan array of arrays (atau Iterator)
- Setiap array adalah satu set parameter untuk test method
- Named data provider: gunakan key asosiatif untuk nama test
- Mengurangi duplikasi kode test

## Contoh Kode (PHP)
```php
<?php
use PHPUnit\Framework\TestCase;

class MathTest extends TestCase {
    /**
     * @dataProvider additionProvider
     */
    public function testAddition(int $a, int $b, int $expected): void {
        $result = $a + $b;
        $this->assertEquals($expected, $result);
    }
    
    public static function additionProvider(): array {
        return [
            [1, 2, 3],
            [0, 0, 0],
            [-1, 1, 0],
            [99, 1, 100],
        ];
    }
    
    // Named data provider
    #[DataProvider('divisionProvider')]
    public function testDivision(float $a, float $b, float $expected): void {
        if ($b === 0.0) {
            $this->expectException(\InvalidArgumentException::class);
            // call division
            return;
        }
        $this->assertEquals($expected, $a / $b, '', 0.0001);
    }
    
    public static function divisionProvider(): array {
        return [
            'sepuluh dibagi dua' => [10, 2, 5],
            'nol dibagi angka' => [0, 5, 0],
            'angka negatif' => [-6, 3, -2],
        ];
    }
}
?>
```

## Kasus Penggunaan Nyata
Validasi input (email, nomor HP, tanggal), testing boundary conditions, testing berbagai status code response, URL routing.
