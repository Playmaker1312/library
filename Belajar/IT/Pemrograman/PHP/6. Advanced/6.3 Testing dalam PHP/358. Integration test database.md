# 358. Integration Test Database

## Definisi Singkat
Integration test database memverifikasi interaksi kode dengan database nyata (atau test database) secara end-to-end.

## Analogi
Seperti uji coba sistem irigasi — Anda benar-benar mengalirkan air (data) ke seluruh pipa (query) untuk memastikan tidak bocor.

## Poin-Poin Penting
- Gunakan test database terpisah (bukan produksi)
- Setiap test harus independen — bersihkan data setelah test
- `RefreshDatabase` trait di Laravel
- Gunakan transaction rollback untuk kecepatan
- Test: CRUD operations, relationships, constraints, migrations

## Contoh Kode (PHP)
```php
<?php
use PHPUnit\Framework\TestCase;

class UserIntegrationTest extends TestCase {
    private static \PDO $pdo;
    
    public static function setUpBeforeClass(): void {
        self::$pdo = new \PDO('sqlite::memory:');
        self::$pdo->exec('CREATE TABLE users (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            name TEXT NOT NULL,
            email TEXT UNIQUE NOT NULL,
            created_at DATETIME DEFAULT CURRENT_TIMESTAMP
        )');
    }
    
    protected function setUp(): void {
        self::$pdo->exec('DELETE FROM users');
    }
    
    public function testInsertAndRetrieveUser(): void {
        $stmt = self::$pdo->prepare('INSERT INTO users (name, email) VALUES (?, ?)');
        $stmt->execute(['Adi Prasetyo', 'adi@example.com']);
        $id = self::$pdo->lastInsertId();
        
        $stmt = self::$pdo->prepare('SELECT * FROM users WHERE id = ?');
        $stmt->execute([$id]);
        $user = $stmt->fetch(\PDO::FETCH_ASSOC);
        
        $this->assertEquals('Adi Prasetyo', $user['name']);
        $this->assertEquals('adi@example.com', $user['email']);
    }
    
    public function testUniqueEmailConstraint(): void {
        self::$pdo->prepare('INSERT INTO users (name, email) VALUES (?, ?)')
            ->execute(['Adi', 'email@test.com']);
        
        $this->expectException(\PDOException::class);
        self::$pdo->prepare('INSERT INTO users (name, email) VALUES (?, ?)')
            ->execute(['Budi', 'email@test.com']);
    }
}
?>
```

## Kasus Penggunaan Nyata
Testing repository pattern, Eloquent models, Doctrine entities, migration testing, query performance verification.
