# 353. Mock Object PHPUnit

## Definisi Singkat
Mock object adalah objek tiruan yang menggantikan dependensi asli untuk mengontrol dan memverifikasi interaksi dalam test.

## Analogi
Seperti simulator penerbangan — Anda "menerbangkan" pesawat tanpa benar-benar terbang, tapi bisa melihat reaksi semua instrumen.

## Poin-Poin Penting
- Membuat mock: `$this->createMock(ClassName::class)`
- Menentukan method yang akan di-mock
- `method()` dan `willReturn()` untuk mengatur behavior
- `expects()` untuk memverifikasi method dipanggil
- `$this->never()`, `$this->once()`, `$this->exactly($n)`

## Contoh Kode (PHP)
```php
<?php
use PHPUnit\Framework\TestCase;

interface PaymentGateway {
    public function charge(float $amount): string;
    public function refund(string $transactionId): bool;
}

class OrderService {
    public function __construct(private PaymentGateway $gateway) {}
    
    public function processPayment(float $amount): string {
        $result = $this->gateway->charge($amount);
        // Logika tambahan...
        return $result;
    }
}

class OrderServiceTest extends TestCase {
    public function testProcessPaymentSuccessful(): void {
        $mockGateway = $this->createMock(PaymentGateway::class);
        
        $mockGateway->expects($this->once())
            ->method('charge')
            ->with(50000.0)
            ->willReturn('SUCCESS-123');
        
        $service = new OrderService($mockGateway);
        $result = $service->processPayment(50000.0);
        
        $this->assertEquals('SUCCESS-123', $result);
    }
    
    public function testPaymentNotCalledForZero(): void {
        $mockGateway = $this->createMock(PaymentGateway::class);
        
        $mockGateway->expects($this->never())
            ->method('charge');
        
        // $service = new OrderService($mockGateway);
        // $service->processPayment(0);
    }
}
?>
```

## Kasus Penggunaan Nyata
Mock database, cache, API eksternal, mailer, queue — semua dependensi yang tidak bisa/susah dijalankan di lingkungan test.
