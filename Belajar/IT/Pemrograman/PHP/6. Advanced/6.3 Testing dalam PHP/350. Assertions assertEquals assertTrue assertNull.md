# 350. Assertions: assertEquals, assertTrue, assertNull

## Definisi Singkat
Assertions adalah method PHPUnit untuk memverifikasi bahwa nilai aktual sesuai dengan yang diharapkan.

## Analogi
Seperti alat ukur — Anda mengukur sesuatu dan membandingkan dengan standar. assertEquals seperti timbangan presisi.

## Poin-Poin Penting
- `assertEquals($expected, $actual)` — perbandingan nilai (loose)
- `assertSame($expected, $actual)` — perbandingan identik (===)
- `assertTrue($condition)` — nilai harus true
- `assertNull($value)` — nilai harus null
- `assertCount($n, $array)` — jumlah elemen array
- `assertInstanceOf($class, $object)` — cek tipe object
- `assertThrows($exception, $callable)` — cek exception (PHPUnit 10+)

## Contoh Kode (PHP)
```php
<?php
use PHPUnit\Framework\TestCase;

class UserValidator {
    public function validateEmail(string $email): bool {
        return filter_var($email, FILTER_VALIDATE_EMAIL) !== false;
    }
    
    public function getRole(int $level): ?string {
        return match($level) {
            1 => 'admin',
            2 => 'user',
            default => null
        };
    }
    
    public function formatName(string $first, string $last): string {
        return trim("$first $last");
    }
}

class UserValidatorTest extends TestCase {
    private UserValidator $validator;
    
    protected function setUp(): void {
        $this->validator = new UserValidator();
    }
    
    public function testEmailValidation(): void {
        $this->assertTrue($this->validator->validateEmail('user@example.com'));
        $this->assertFalse($this->validator->validateEmail('invalid-email'));
    }
    
    public function testRoleLookup(): void {
        $this->assertEquals('admin', $this->validator->getRole(1));
        $this->assertNull($this->validator->getRole(99));
        $this->assertSame('admin', $this->validator->getRole(1));
    }
    
    public function testFormatName(): void {
        $result = $this->validator->formatName('Adi', 'Prasetyo');
        $this->assertStringContainsString('Adi', $result);
        $this->assertEquals('Adi Prasetyo', $result);
    }
}
?>
```

## Kasus Penggunaan Nyata
Semua jenis test — assertions adalah inti dari testing, digunakan untuk memverifikasi output, side effects, dan kondisi error.
