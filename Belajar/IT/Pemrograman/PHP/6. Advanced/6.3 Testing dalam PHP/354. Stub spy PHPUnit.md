# 354. Stub dan Spy PHPUnit

## Definisi Singkat
Stub mengembalikan nilai tetap untuk method; Spy melacak bagaimana method dipanggil (berapa kali, argumen apa).

## Analogi
- Stub: seperti boneka stanby — hanya diam dan merespons dengan jawaban tetap
- Spy: seperti detektif yang mencatat setiap interaksi yang terjadi

## Poin-Poin Penting
- **Stub**: mengontrol input/output — fokus pada "apa yang dikembalikan"
- **Spy**: memverifikasi interaksi — fokus pada "bagaimana dipanggil"
- PHPUnit `createStub()` vs `createMock()` (yang juga bisa jadi spy)
- `willReturn()`, `willThrowException()`, `willReturnCallback()`
- `with()` untuk memeriksa argumen

## Contoh Kode (PHP)
```php
<?php
use PHPUnit\Framework\TestCase;

interface MailerService {
    public function send(string $to, string $subject): bool;
    public function getSentCount(): int;
}

class NotificationService {
    public function __construct(private MailerService $mailer) {}
    
    public function notifyUser(string $email, string $msg): void {
        $this->mailer->send($email, $msg);
    }
}

class MailerTest extends TestCase {
    // Stub — fokus pada return value
    public function testNotificationWithStub(): void {
        $stub = $this->createStub(MailerService::class);
        $stub->method('send')->willReturn(true);
        
        $service = new NotificationService($stub);
        $service->notifyUser('test@test.com', 'Hello');
        
        $this->assertTrue(true); // Tidak error
    }
    
    // Spy — fokus pada interaksi
    public function testNotificationWithMockAsSpy(): void {
        $spy = $this->createMock(MailerService::class);
        
        $spy->expects($this->once())
            ->method('send')
            ->with('user@site.com', 'Selamat datang');
        
        $service = new NotificationService($spy);
        $service->notifyUser('user@site.com', 'Selamat datang');
    }
    
    // Callback stub
    public function testCallbackStub(): void {
        $stub = $this->createStub(MailerService::class);
        $stub->method('send')
            ->willReturnCallback(fn($to, $sub) => str_contains($to, '@'));
        
        $this->assertTrue($stub->send('a@b.com', 'test'));
        $this->assertFalse($stub->send('invalid', 'test'));
    }
}
?>
```

## Kasus Penggunaan Nyata
Stub untuk API eksternal, database query; Spy untuk memastikan email terkirim, event terpanggil, queue terisi.
