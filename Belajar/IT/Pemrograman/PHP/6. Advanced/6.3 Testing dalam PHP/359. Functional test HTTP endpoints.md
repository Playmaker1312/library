# 359. Functional Test HTTP Endpoints

## Definisi Singkat
Functional test HTTP memverifikasi seluruh request-response cycle dari endpoint API atau web application.

## Analogi
Seperti pelanggan rahasia (mystery shopper) — Anda berpura-pura menjadi pengguna dan memeriksa respons dari seluruh sistem.

## Poin-Poin Penting
- Test HTTP method (GET, POST, PUT, DELETE)
- Verifikasi status code, headers, response body
- Bisa menggunakan Symfony HttpClient, Laravel TestCase, atau Guzzle
- Test authentication, authorization, validation
- End-to-end tanpa browser (API) atau dengan browser (UI)

## Contoh Kode (PHP)
```php
<?php
use PHPUnit\Framework\TestCase;

// Contoh menggunakan Symfony HttpClient
class ApiEndpointTest extends TestCase {
    private static string $baseUrl = 'http://localhost:8000/api';
    
    public function testGetUsersReturns200(): void {
        $ch = curl_init(self::$baseUrl . '/users');
        curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
        $response = curl_exec($ch);
        $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        curl_close($ch);
        
        $this->assertEquals(200, $httpCode);
        $data = json_decode($response, true);
        $this->assertIsArray($data);
    }
    
    public function testCreateUser(): void {
        $payload = json_encode([
            'name' => 'Adi Prasetyo',
            'email' => 'adi@test.com'
        ]);
        
        $ch = curl_init(self::$baseUrl . '/users');
        curl_setopt_array($ch, [
            CURLOPT_RETURNTRANSFER => true,
            CURLOPT_POST => true,
            CURLOPT_POSTFIELDS => $payload,
            CURLOPT_HTTPHEADER => ['Content-Type: application/json']
        ]);
        $response = curl_exec($ch);
        $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        curl_close($ch);
        
        $this->assertEquals(201, $httpCode);
        $data = json_decode($response, true);
        $this->assertArrayHasKey('id', $data);
        $this->assertEquals('Adi Prasetyo', $data['name']);
    }
    
    public function testUnauthorizedAccess(): void {
        $ch = curl_init(self::$baseUrl . '/admin');
        curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
        curl_exec($ch);
        $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        curl_close($ch);
        
        $this->assertEquals(401, $httpCode);
    }
}
?>
```

## Kasus Penggunaan Nyata
API REST/GraphQL testing, form submission flows, authentication/authorization testing, webhook endpoint validation.
