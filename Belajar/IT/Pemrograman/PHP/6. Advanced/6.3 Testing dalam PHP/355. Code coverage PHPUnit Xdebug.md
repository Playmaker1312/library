# 355. Code Coverage dengan PHPUnit dan Xdebug

## Definisi Singkat
Code coverage mengukur persentase kode yang dijalankan oleh test, menunjukkan bagian kode yang sudah/belum ter-test.

## Analogi
Seperti peta panas (heatmap) — area hijau sudah dijelajahi (ter-test), area merah belum tersentuh.

## Poin-Poin Penting
- Membutuhkan Xdebug atau PCOV extension
- Jalankan: `php -d xdebug.mode=coverage vendor/bin/phpunit --coverage-html coverage/`
- Metrik: Line, Function, Class, Method, Branch coverage
- Target coverage ideal: 80%+ untuk kode produksi
- Jangan kejar 100% — fokus pada kode kritis

## Contoh Kode (PHP)
```bash
# Install Xdebug
# pecl install xdebug

# Jalankan coverage
php -d xdebug.mode=coverage vendor/bin/phpunit --coverage-html coverage/ --coverage-clover coverage.xml
```

```xml
<!-- phpunit.xml dengan konfigurasi coverage -->
<phpunit>
    <source>
        <include>
            <directory>src</directory>
        </include>
        <exclude>
            <directory>src/Migrations</directory>
            <file>src/Kernel.php</file>
        </exclude>
    </source>
</phpunit>
```

```php
<?php
// Fungsi yang ter-coverage penuh
function hitungDiskon(float $harga): float {
    if ($harga > 100000) {
        return $harga * 0.9; // Ter-test
    }
    return $harga; // Juga ter-test
}
// Fungsi yang tidak ter-test sama sekali — 0% coverage
function kirimEmail(string $to): bool {
    // Belum ada test untuk ini
    return mail($to, 'Subject', 'Body');
}
?>
```

## Kasus Penggunaan Nyata
Monitoring kualitas test di CI, menemukan kode yang tidak pernah di-test, memastikan critical path sudah di-cover test.
