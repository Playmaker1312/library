# 348. Instal PHPUnit dengan Composer

## Definisi Singkat
PHPUnit adalah framework testing PHP paling populer, diinstal melalui Composer sebagai dev dependency.

## Analogi
Seperti memasang peralatan diagnostic mobil — Anda butuh toolkit khusus yang dipasang sebelum melakukan pemeriksaan.

## Poin-Poin Penting
- Instal lewat Composer: `composer require --dev phpunit/phpunit`
- Versi stabil terbaru: PHPUnit 11.x (untuk PHP 8.x)
- Konfigurasi via file `phpunit.xml` atau `phpunit.xml.dist`
- Jalankan: `./vendor/bin/phpunit`
- Alternatif: instal global dengan PHAR

## Contoh Kode (PHP)
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!-- phpunit.xml -->
<phpunit 
    bootstrap="vendor/autoload.php"
    colors="true"
    verbose="true">
    <testsuites>
        <testsuite name="Unit">
            <directory>tests/Unit</directory>
        </testsuite>
        <testsuite name="Feature">
            <directory>tests/Feature</directory>
        </testsuite>
    </testsuites>
</phpunit>
```

## Kasus Penggunaan Nyata
Semua proyek PHP modern menggunakan PHPUnit sebagai testing framework default, terutama Laravel, Symfony, dan library PHP lainnya.
