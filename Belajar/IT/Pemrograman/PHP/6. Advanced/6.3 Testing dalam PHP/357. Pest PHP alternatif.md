# 357. Pest PHP — Alternatif Testing

## Definisi Singkat
Pest adalah testing framework PHP yang dibangun di atas PHPUnit dengan sintaks yang lebih ekspresif dan sederhana.

## Analogi
Seperti menulis catatan dibanding esai — intinya sama (testing), tapi Pest lebih ringkas dan elegan.

## Poin-Poin Penting
- Sintaks fungsional: `test('judul', fn() => expect($value)->toBe($expected))`
- Berbasis PHPUnit — bisa pakai fitur PHPUnit di dalam Pest
- Instal: `composer require --dev pestphp/pest`
- Fitur: higher order tests, arch testing, custom expectations
- Makin populer di komunitas PHP

## Contoh Kode (PHP)
```php
<?php
// Pest PHP — sintaks lebih ringkas

// tests/Unit/CalculatorTest.php

// test() function
test('angka ditambah angka', function () {
    $result = 2 + 3;
    
    expect($result)->toBe(5);
    expect($result)->toBeInt();
});

// it() function — lebih natural
it('menghasilkan nilai negatif untuk pengurangan besar', function () {
    $result = 3 - 10;
    
    expect($result)->toBeLessThan(0);
});

// Higher order test
test('string manipulation')
    ->expect(strtoupper('halo'))->toBe('HALO')
    ->expect(trim('  hello  '))->toBe('hello');

// Test dengan data
test('validasi email %s', function ($email, $expected) {
    expect(filter_var($email, FILTER_VALIDATE_EMAIL))->toBe($expected);
})->with([
    ['user@example.com', 'user@example.com'],
    ['invalid', false],
    ['test@test.co.id', 'test@test.co.id'],
]);

// Arch testing (Pest 2.x)
// test('services cannot use repository')
//     ->expect('App\Services')
//     ->not->toUse('App\Repositories');
?>
```
