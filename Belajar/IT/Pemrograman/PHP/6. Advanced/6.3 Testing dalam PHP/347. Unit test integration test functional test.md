# 347. Unit Test, Integration Test, Functional Test

## Definisi Singkat
Tiga level testing dengan scope berbeda: unit (terkecil), integration (antar komponen), functional (end-to-end).

## Analogi
- Unit test: Memeriksa satu baut di mesin
- Integration test: Memeriksa apakah baut dan mur terpasang benar
- Functional test: Menyalakan mesin dan test drive mobil

## Poin-Poin Penting
- **Unit Test**: Test method/fungsi individu, mock semua dependensi eksternal
- **Integration Test**: Test interaksi antar kelas/komponen, database nyata
- **Functional Test**: Test dari user perspective, HTTP request ke response
- Piramida testing: banyak unit, sedikit integration, sedikit functional
- Setiap level memiliki kecepatan dan biaya maintenance berbeda

## Contoh Kode (PHP)
```php
<?php
// Unit test — test method individu
class StringUtils {
    public static function uppercase(string $str): string {
        return strtoupper($str);
    }
}
// assert(StringUtils::uppercase('halo') === 'HALO');

// Integration test — test Database + Repository
class UserRepository {
    public function __construct(private \PDO $pdo) {}
    public function findByEmail(string $email): ?array {
        $stmt = $this->pdo->prepare('SELECT * FROM users WHERE email = ?');
        $stmt->execute([$email]);
        return $stmt->fetch(\PDO::FETCH_ASSOC) ?: null;
    }
}

// Functional test — test HTTP endpoint
// $response = $client->get('/api/users/1');
// assert($response->getStatusCode() === 200);
// $data = json_decode($response->getBody(), true);
// assert(isset($data['name']));
?>
```

## Kasus Penggunaan Nyata
Unit test untuk service/business logic, integration test untuk repository/DAO, functional test untuk API endpoints dan UI flows.
