# 356. TDD (Test-Driven Development)

## Definisi Singkat
TDD adalah metodologi pengembangan di mana test ditulis **sebelum** kode produksi, dengan siklus Red-Green-Refactor.

## Analogi
Seperti membangun rumah dengan cetak biru — Anda tahu spesifikasinya (test) sebelum mulai membangun (kode).

## Poin-Poin Penting
- Siklus: **Red** (tulis test, gagal) → **Green** (tulis kode minimal, lulus) → **Refactor** (perbaiki kode)
- Test menentukan desain — kode ditulis hanya untuk membuat test lulus
- Menghasilkan kode yang ter-test dengan baik secara alami
- Mendorong desain yang sederhana dan modular
- Butuh disiplin tinggi pada awalnya

## Contoh Kode (PHP)
```php
<?php
use PHPUnit\Framework\TestCase;

// TAHAP 1 — RED: Tulis test yang gagal
/*
class FizzBuzzTest extends TestCase {
    public function test_returns_fizz_for_multiples_of_three(): void {
        $fizzbuzz = new FizzBuzz();
        $this->assertEquals('Fizz', $fizzbuzz->generate(3));
    }
}
*/

// TAHAP 2 — GREEN: Tulis kode minimal
class FizzBuzz {
    public function generate(int $n): string {
        if ($n % 3 === 0 && $n % 5 === 0) return 'FizzBuzz';
        if ($n % 3 === 0) return 'Fizz';
        if ($n % 5 === 0) return 'Buzz';
        return (string) $n;
    }
}

// TAHAP 3 — REFACTOR: Perbaiki tanpa mengubah perilaku
// (class FizzBuzz sudah clean, tidak perlu refactor besar)

// Test lengkap
class FizzBuzzTest extends TestCase {
    private FizzBuzz $fb;
    
    protected function setUp(): void { $this->fb = new FizzBuzz(); }
    
    public function test_returns_number_for_non_multiples(): void {
        $this->assertEquals('1', $this->fb->generate(1));
        $this->assertEquals('2', $this->fb->generate(2));
    }
    
    public function test_returns_fizz_for_multiples_of_three(): void {
        $this->assertEquals('Fizz', $this->fb->generate(3));
        $this->assertEquals('Fizz', $this->fb->generate(6));
    }
    
    public function test_returns_buzz_for_multiples_of_five(): void {
        $this->assertEquals('Buzz', $this->fb->generate(5));
    }
    
    public function test_returns_fizzbuzz_for_multiples_of_both(): void {
        $this->assertEquals('FizzBuzz', $this->fb->generate(15));
    }
}
?>
```

## Kasus Penggunaan Nyata
Proyek yang membutuhkan kualitas tinggi, pengembangan library/framework, refactoring dengan keamanan maksimal.
