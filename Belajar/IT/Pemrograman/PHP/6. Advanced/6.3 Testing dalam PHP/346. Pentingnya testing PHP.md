# 346. Pentingnya Testing PHP

## Definisi Singkat
Testing adalah proses memverifikasi bahwa kode PHP berfungsi sesuai yang diharapkan secara otomatis dan terstruktur.

## Analogi
Seperti pemeriksaan keamanan di bandara — sebelum pesawat terbang, setiap komponen diperiksa untuk memastikan keamanan.

## Poin-Poin Penting
- Mencegah regression (bug baru akibat perubahan)
- Dokumentasi hidup — test menunjukkan cara penggunaan kode
- Meningkatkan kepercayaan untuk refactor
- Menghemat biaya — bugs lebih murah diperbaiki awal
- Jenis test: Unit, Integration, Functional, Acceptance

## Contoh Kode (PHP)
```php
<?php
class Calculator {
    public function add(float $a, float $b): float {
        return $a + $b;
    }
    
    public function divide(float $a, float $b): float {
        if ($b === 0.0) {
            throw new \InvalidArgumentException('Division by zero');
        }
        return $a / $b;
    }
}

// Simulasi manual testing (seharusnya pakai PHPUnit)
$calc = new Calculator();
assert($calc->add(2, 3) === 5.0);
assert($calc->add(-1, 1) === 0.0);
assert($calc->divide(10, 2) === 5.0);

try {
    $calc->divide(1, 0);
    echo "Test gagal: seharusnya throw exception\n";
} catch (\InvalidArgumentException $e) {
    echo "Test passed: " . $e->getMessage() . "\n";
}
// Output: Test passed: Division by zero
?>
```

## Kasus Penggunaan Nyata
CI/CD pipeline yang menjalankan test otomatis sebelum deploy, pull request yang membutuhkan test passing, refactoring kode dengan percaya diri.
