# 351. setUp dan tearDown Method

## Definisi Singkat
`setUp()` dan `tearDown()` adalah method lifecycle PHPUnit yang dijalankan sebelum dan sesudah setiap method test.

## Analogi
Seperti menyiapkan meja bedah sebelum operasi (setUp) dan membersihkan alat setelah operasi (tearDown).

## Poin-Poin Penting
- `setUp()`: menyiapkan objek, koneksi, data sebelum setiap test
- `tearDown()`: membersihkan resource setelah setiap test
- `setUpBeforeClass()`: sekali sebelum semua test di class
- `tearDownAfterClass()`: sekali setelah semua test di class
- Menghindari duplikasi kode setup di setiap method test

## Contoh Kode (PHP)
```php
<?php
use PHPUnit\Framework\TestCase;

class DatabaseTest extends TestCase {
    private \PDO $pdo;
    private static string $tempFile;
    
    public static function setUpBeforeClass(): void {
        self::$tempFile = tempnam(sys_get_temp_dir(), 'test_');
    }
    
    protected function setUp(): void {
        $this->pdo = new \PDO('sqlite:' . self::$tempFile);
        $this->pdo->exec('CREATE TABLE IF NOT EXISTS users (
            id INTEGER PRIMARY KEY, name TEXT
        )');
        $this->pdo->exec("INSERT INTO users VALUES (1, 'Adi')");
    }
    
    protected function tearDown(): void {
        $this->pdo->exec('DROP TABLE IF EXISTS users');
        $this->pdo = null;
    }
    
    public static function tearDownAfterClass(): void {
        if (file_exists(self::$tempFile)) {
            unlink(self::$tempFile);
        }
    }
    
    public function testFindUser(): void {
        $stmt = $this->pdo->query('SELECT name FROM users WHERE id = 1');
        $this->assertEquals('Adi', $stmt->fetchColumn());
    }
    
    public function testCountUsers(): void {
        $stmt = $this->pdo->query('SELECT COUNT(*) FROM users');
        $this->assertEquals(1, (int) $stmt->fetchColumn());
    }
}
?>
```

## Kasus Penggunaan Nyata
Setup database connection sebelum test, create mock objects, prepare file system state, clean temporary files setelah test.
