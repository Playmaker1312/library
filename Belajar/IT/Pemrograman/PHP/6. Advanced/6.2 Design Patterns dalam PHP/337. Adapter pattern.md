# 337. Adapter Pattern

## Definisi Singkat
Adapter pattern mengubah interface sebuah kelas menjadi interface lain yang diharapkan oleh client, tanpa mengubah kode sumber.

## Analogi
Seperti adaptor colokan listrik — colokan Eropa tidak bisa langsung masuk ke stopkontak Indonesia, butuh adaptor.

## Poin-Poin Penting
- Menjembatani ketidakcocokan interface
- Wrapper class yang menerjemahkan panggilan
- Single Adapter (satu kelas) atau Object Adapter (komposisi)
- Tidak mengubah kode existing
- Menerapkan prinsip Open/Closed

## Contoh Kode (PHP)
```php
<?php
// Interface yang diharapkan aplikasi
interface PaymentProcessor {
    public function charge(float $amount, array $data): string;
}

// Library pihak ketiga dengan interface berbeda
class ThirdPartyGateway {
    public function sendPayment(float $total, string $currency, string $customer): bool {
        echo "ThirdParty: charging $total $currency for $customer\n";
        return true;
    }
}

// Adapter: membuat ThirdPartyGateway kompatibel dengan PaymentProcessor
class GatewayAdapter implements PaymentProcessor {
    public function __construct(
        private ThirdPartyGateway $gateway,
        private string $currency = 'IDR'
    ) {}
    
    public function charge(float $amount, array $data): string {
        $result = $this->gateway->sendPayment(
            $amount,
            $this->currency,
            $data['customer']
        );
        return $result ? 'success' : 'failed';
    }
}

$processor = new GatewayAdapter(new ThirdPartyGateway());
echo $processor->charge(50000, ['customer' => 'Adi']);
// Output: ThirdParty: charging 50000 IDR for Adi
// Output: success
?>
```

## Kasus Penggunaan Nyata
Integrasi payment gateway berbeda dengan interface berbeda, menggunakan library email berbeda dengan interface seragam, legacy code integration.
