# 339. Observer Pattern

## Definisi Singkat
Observer pattern mendefinisikan hubungan one-to-many di mana perubahan pada satu objek (subject) memberitahu semua dependen (observer) secara otomatis.

## Analogi
Seperti channel YouTube — ketika creator upload video, semua subscriber otomatis mendapat notifikasi.

## Poin-Poin Penting
- Subject: objek yang diamati
- Observer: objek yang ingin tahu perubahan
- Event-driven programming
- Subscriber/Publisher pattern juga dikenal sebagai Observer
- PHP memiliki SPL `SplSubject` dan `SplObserver`

## Contoh Kode (PHP)
```php
<?php
class Order implements \SplSubject {
    private string $status = 'baru';
    private \SplObjectStorage $observers;
    
    public function __construct(public int $id) {
        $this->observers = new \SplObjectStorage();
    }
    
    public function attach(\SplObserver $observer): void {
        $this->observers->attach($observer);
    }
    
    public function detach(\SplObserver $observer): void {
        $this->observers->detach($observer);
    }
    
    public function notify(): void {
        foreach ($this->observers as $observer) {
            $observer->update($this);
        }
    }
    
    public function setStatus(string $status): void {
        $this->status = $status;
        $this->notify();
    }
    
    public function getStatus(): string { return $this->status; }
}

class LoggerObserver implements \SplObserver {
    public function update(\SplSubject $subject): void {
        echo "[LOG] Order #{$subject->id} status: {$subject->getStatus()}\n";
    }
}

class EmailObserver implements \SplObserver {
    public function update(\SplSubject $subject): void {
        echo "[EMAIL] Pesanan #{$subject->id} sekarang {$subject->getStatus()}\n";
    }
}

$order = new Order(1001);
$order->attach(new LoggerObserver());
$order->attach(new EmailObserver());

$order->setStatus('diproses');
$order->setStatus('dikirim');
?>
```

## Kasus Penggunaan Nyata
Event system di Laravel/Symfony, notifikasi perubahan status, logging, caching invalidation, real-time updates via WebSocket.
