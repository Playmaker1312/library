# 331. Design Patterns di PHP

## Definisi Singkat
Design patterns adalah solusi umum yang sudah terbukti untuk masalah yang sering muncul dalam perancangan perangkat lunak.

## Analogi
Seperti cetakan kue — Anda tidak perlu menemukan bentuk baru setiap ingin membuat kue, cukup gunakan cetakan yang sudah ada.

## Poin-Poin Penting
- Kategorisasi: Creational (pembuatan objek), Structural (struktur kelas), Behavioral (interaksi objek)
- Bukan kode siap pakai, melainkan template solusi
- Meningkatkan komunikasi antar developer
- PHP memiliki implementasi spesifik karena sifat dynamic typed
- Pahami masalah sebelum memilih pattern

## Contoh Kode (PHP)
```php
<?php
// Contoh sederhana Strategy Pattern
interface Pembayaran {
    public function bayar(float $jumlah): string;
}

class KartuKredit implements Pembayaran {
    public function bayar(float $jumlah): string {
        return "Bayar $jumlah pakai Kartu Kredit";
    }
}

class GoPay implements Pembayaran {
    public function bayar(float $jumlah): string {
        return "Bayar $jumlah pakai GoPay";
    }
}

class Checkout {
    public function __construct(private Pembayaran $pembayaran) {}
    
    public function proses(float $jumlah): string {
        return $this->pembayaran->bayar($jumlah);
    }
}

$checkout = new Checkout(new GoPay());
echo $checkout->proses(50000);
// Output: Bayar 50000 pakai GoPay
?>
```

## Kasus Penggunaan Nyata
Framework PHP modern (Laravel, Symfony) menggunakan banyak design patterns: Factory, Repository, Observer, Strategy, DI Container.
