# 334. Abstract Factory Pattern

## Definisi Singkat
Abstract Factory menyediakan interface untuk membuat **keluarga objek** yang saling terkait tanpa menentukan kelas konkretnya.

## Analogi
Seperti pabrik furnitur — jika Anda memesan "gaya minimalis", Anda mendapatkan sofa minimalis, meja minimalis, dan kursi minimalis secara konsisten.

## Poin-Poin Penting
- Lebih tinggi levelnya dari Factory Method — membuat banyak objek terkait
- Client hanya berinteraksi dengan interface abstract factory
- Mengganti "keluarga produk" dengan mudah (misal UI tema gelap/terang)
- Produk dari satu factory harus kompatibel satu sama lain
- Menambahkan produk baru butuh mengubah interface factory

## Contoh Kode (PHP)
```php
<?php
interface Tombol {
    public function render(): string;
}
interface Checkbox {
    public function render(): string;
}

class TombolGelap implements Tombol {
    public function render(): string { return "Tombol [gelap]"; }
}
class CheckboxGelap implements Checkbox {
    public function render(): string { return "Checkbox [gelap]"; }
}
class TombolTerang implements Tombol {
    public function render(): string { return "Tombol (terang)"; }
}
class CheckboxTerang implements Checkbox {
    public function render(): string { return "Checkbox (terang)"; }
}

interface UIFactory {
    public function buatTombol(): Tombol;
    public function buatCheckbox(): Checkbox;
}

class GelapFactory implements UIFactory {
    public function buatTombol(): Tombol { return new TombolGelap(); }
    public function buatCheckbox(): Checkbox { return new CheckboxGelap(); }
}

class TerangFactory implements UIFactory {
    public function buatTombol(): Tombol { return new TombolTerang(); }
    public function buatCheckbox(): Checkbox { return new CheckboxTerang(); }
}

$factory = new GelapFactory();
echo $factory->buatTombol()->render();
echo "\n";
echo $factory->buatCheckbox()->render();
// Output: Tombol [gelap]
// Output: Checkbox [gelap]
?>
```

## Kasus Penggunaan Nyata
UI theme (Dark/Light mode), multi-platform rendering, database driver families, payment gateway families.
