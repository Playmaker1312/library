# 342. Dependency Injection Pattern

## Definisi Singkat
Dependency Injection (DI) memberikan dependensi dari luar ke objek, bukan objek menciptakannya sendiri.

## Analogi
Seperti koki yang menerima bahan masakan dari supplier — koki tidak perlu menanam sayur atau beternak ayam sendiri.

## Poin-Poin Penting
- Inversi kontrol — objek tidak membuat dependensinya
- Constructor injection: dependensi lewat constructor
- Setter injection: dependensi lewat setter method
- Meningkatkan testability (mudah di-mock)
- Mengurangi coupling antar kelas

## Contoh Kode (PHP)
```php
<?php
interface Mailer {
    public function send(string $to, string $subject, string $body): bool;
}

class SmtpMailer implements Mailer {
    public function send(string $to, string $subject, string $body): bool {
        echo "Mengirim email ke $to: $subject\n";
        return true;
    }
}

class LogMailer implements Mailer {
    public function send(string $to, string $subject, string $body): bool {
        echo "[LOG] Email akan dikirim ke $to\n";
        return true;
    }
}

// Tanpa DI — UserService membuat Mailer sendiri (tight coupling)
class UserServiceHardcoded {
    private Mailer $mailer;
    
    public function __construct() {
        $this->mailer = new SmtpMailer(); // Kaku!
    }
}

// Dengan DI — dependensi diberikan dari luar
class UserService {
    public function __construct(private Mailer $mailer) {}
    
    public function register(string $email): void {
        // ... logika register ...
        $this->mailer->send($email, 'Selamat Datang', 'Terima kasih telah mendaftar');
    }
}

// Gampang diganti implementasi
$service = new UserService(new SmtpMailer());
// atau
$service = new UserService(new LogMailer());
?>
```

## Kasus Penggunaan Nyata
Framework modern (Laravel, Symfony) berbasis DI, testing dengan mock objects, mengganti implementasi tanpa mengubah kode bisnis.
