# 343. DI Container

## Definisi Singkat
DI Container (Dependency Injection Container) adalah alat yang secara otomatis mengelola pembuatan dan penyuntikan dependensi objek.

## Analogi
Seperti asisten pribadi yang tahu semua kontak dan jadwal — Anda tinggal minta "Saya butuh rapat dengan klien", dan asisten mengatur semuanya.

## Poin-Poin Penting
- Auto-wiring: container bisa menentukan dependensi secara otomatis
- Definisi binding: memberi tahu container bagaimana membuat objek
- Service Provider/Registry: mendaftarkan service ke container
- Mengelola lifecycle object (singleton, factory, instance)
- Contoh: Laravel Service Container, PHP-DI, Symfony Service Container

## Contoh Kode (PHP)
```php
<?php
// DI Container sederhana
class Container {
    private array $bindings = [];
    private array $instances = [];
    
    public function set(string $abstract, callable $concrete): void {
        $this->bindings[$abstract] = $concrete;
    }
    
    public function singleton(string $abstract, callable $concrete): void {
        $this->bindings[$abstract] = function () use ($abstract, $concrete) {
            if (!isset($this->instances[$abstract])) {
                $this->instances[$abstract] = $concrete($this);
            }
            return $this->instances[$abstract];
        };
    }
    
    public function get(string $abstract): mixed {
        if (isset($this->bindings[$abstract])) {
            return ($this->bindings[$abstract])($this);
        }
        // Auto-wiring sederhana
        return $this->autoWire($abstract);
    }
    
    private function autoWire(string $class): object {
        $ref = new ReflectionClass($class);
        $constructor = $ref->getConstructor();
        
        if (!$constructor) {
            return $ref->newInstance();
        }
        
        $params = array_map(
            fn(\ReflectionParameter $p) => $this->get($p->getType()->getName()),
            $constructor->getParameters()
        );
        
        return $ref->newInstanceArgs($params);
    }
}

// Contoh penggunaan
$container = new Container();
$container->singleton(\PDO::class, fn() => new \PDO('mysql:host=localhost;dbname=test', 'root', ''));
$service = $container->get(UserService::class);
?>
```

## Kasus Penggunaan Nyata
Laravel Service Container, Symfony DependencyInjection, PHP-DI, aplikasi besar dengan banyak dependensi kompleks.
