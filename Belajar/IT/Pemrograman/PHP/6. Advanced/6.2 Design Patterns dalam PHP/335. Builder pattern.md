# 335. Builder Pattern

## Definisi Singkat
Builder pattern memisahkan konstruksi objek kompleks dari representasinya, memungkinkan proses pembuatan bertahap.

## Analogi
Seperti merakit PC — Anda memilih prosesor, RAM, GPU satu per satu, dan pada akhirnya mendapatkan PC jadi.

## Poin-Poin Penting
- Cocok untuk objek dengan banyak parameter opsional
- Method chaining untuk pengalaman builder yang lancar
- Immutable object setelah di-build
- Menggantikan constructor dengan banyak parameter (telescoping)
- Contoh populer: query builder, PSR-7 Response builder

## Contoh Kode (PHP)
```php
<?php
class Kue {
    public function __construct(
        public readonly string $rasa,
        public readonly int $ukuran,
        public readonly bool $glutenFree,
        public readonly ?string $topping = null
    ) {}
}

class KueBuilder {
    private string $rasa = 'vanilla';
    private int $ukuran = 20;
    private bool $glutenFree = false;
    private ?string $topping = null;
    
    public function setRasa(string $rasa): self {
        $this->rasa = $rasa;
        return $this;
    }
    
    public function setUkuran(int $ukuran): self {
        $this->ukuran = $ukuran;
        return $this;
    }
    
    public function setGlutenFree(bool $gf): self {
        $this->glutenFree = $gf;
        return $this;
    }
    
    public function setTopping(string $topping): self {
        $this->topping = $topping;
        return $this;
    }
    
    public function build(): Kue {
        return new Kue($this->rasa, $this->ukuran, $this->glutenFree, $this->topping);
    }
}

$kue = (new KueBuilder())
    ->setRasa('coklat')
    ->setUkuran(30)
    ->setTopping('keju')
    ->build();

print_r($kue);
?>
```

## Kasus Penggunaan Nyata
Query builder database (Laravel Query Builder, Eloquent), HTTP request/response builder, konstruksi object konfigurasi kompleks.
