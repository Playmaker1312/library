# 333. Factory Pattern

## Definisi Singkat
Factory pattern menyediakan interface untuk membuat objek tanpa menentukan kelas konkretnya di kode pemanggil.

## Analogi
Seperti restoran — Anda memesan "Nasi Goreng" (permintaan), dan dapur memutuskan bagaimana membuatnya tanpa Anda tahu detailnya.

## Poin-Poin Penting
- Memisahkan logika pembuatan objek dari penggunaannya
- Memudahkan ketika tipe objek ditentukan saat runtime
- Simple Factory: satu method/factory class
- Factory Method: biarkan subclass menentukan tipe objek
- Menghilangkan duplikasi kode `new` di banyak tempat

## Contoh Kode (PHP)
```php
<?php
interface Notifikasi {
    public function kirim(string $pesan): void;
}

class EmailNotif implements Notifikasi {
    public function kirim(string $pesan): void {
        echo "Email: $pesan\n";
    }
}

class SMSNotif implements Notifikasi {
    public function kirim(string $pesan): void {
        echo "SMS: $pesan\n";
    }
}

class NotifikasiFactory {
    public static function buat(string $tipe): Notifikasi {
        return match($tipe) {
            'email' => new EmailNotif(),
            'sms' => new SMSNotif(),
            default => throw new \InvalidArgumentException("Tipe $tipe tidak dikenal")
        };
    }
}

// Pemanggil tidak tahu kelas konkret
$notif = NotifikasiFactory::buat('email');
$notif->kirim('Halo dari Factory!');
// Output: Email: Halo dari Factory!
?>
```
