# 338. Decorator Pattern

## Definisi Singkat
Decorator pattern menambahkan perilaku baru ke objek secara dinamis tanpa mengubah struktur kelasnya.

## Analogi
Seperti hiasan pohon Natal — pohon dasarnya sama, tapi Anda bisa menambahkan lampu, ornamen, bintang secara fleksibel.

## Poin-Poin Penting
- Menggunakan komposisi, bukan inheritance
- Decorator membungkus objek asli dan menambahkan fungsionalitas
- Dapat ditumpuk (stacked) — beberapa decorator pada satu objek
- Mengikuti interface yang sama dengan objek asli
- Alternatif untuk subclass yang terlalu banyak

## Contoh Kode (PHP)
```php
<?php
interface Kopi {
    public function cost(): int;
    public function deskripsi(): string;
}

class KopiDasar implements Kopi {
    public function cost(): int { return 15000; }
    public function deskripsi(): string { return "Kopi hitam"; }
}

abstract class KopiDecorator implements Kopi {
    public function __construct(protected Kopi $kopi) {}
}

class Susu extends KopiDecorator {
    public function cost(): int { return $this->kopi->cost() + 5000; }
    public function deskripsi(): string { return $this->kopi->deskripsi() . ", susu"; }
}

class Gula extends KopiDecorator {
    public function cost(): int { return $this->kopi->cost() + 2000; }
    public function deskripsi(): string { return $this->kopi->deskripsi() . ", gula"; }
}

class Karamel extends KopiDecorator {
    public function cost(): int { return $this->kopi->cost() + 8000; }
    public function deskripsi(): string { return $this->kopi->deskripsi() . ", karamel"; }
}

$kopi = new KopiDasar();
$kopi = new Susu($kopi);
$kopi = new Gula($kopi);
$kopi = new Karamel($kopi);

echo $kopi->deskripsi() . " = Rp" . $kopi->cost();
// Output: Kopi hitam, susu, gula, karamel = Rp30000
?>
```

## Kasus Penggunaan Nyata
Middleware HTTP (Laravel middleware), stream processing, logging dengan level berbeda, caching layer, komponen UI bertumpuk.
