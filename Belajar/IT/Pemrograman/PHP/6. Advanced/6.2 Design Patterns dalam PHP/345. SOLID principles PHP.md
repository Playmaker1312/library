# 345. SOLID Principles PHP

## Definisi Singkat
SOLID adalah lima prinsip desain berorientasi objek yang membuat kode lebih mudah dipelihara, dipahami, dan dikembangkan.

## Analogi
Seperti fondasi rumah yang kuat — setiap prinsip adalah tiang penyangga yang membuat bangunan kokoh dan mudah direnovasi.

## Poin-Poin Penting
- **S**ingle Responsibility: Satu kelas punya satu tanggung jawab
- **O**pen/Closed: Terbuka untuk ekstensi, tertutup untuk modifikasi
- **L**iskov Substitution: Subclass harus bisa menggantikan parent class
- **I**nterface Segregation: Interface jangan terlalu besar
- **D**ependency Inversion: Abstraksi, bukan konkret

## Contoh Kode (PHP)
```php
<?php
// S — Single Responsibility
class Invoice {
    public function __construct(public float $amount) {}
}
class InvoicePrinter {
    public function print(Invoice $invoice): string {
        return "Invoice: Rp" . $invoice->amount;
    }
}
class InvoiceRepository {
    public function save(Invoice $invoice): void {
        // Simpan ke database
    }
}

// O — Open/Closed
interface Discount {
    public function apply(float $amount): float;
}
class NoDiscount implements Discount {
    public function apply(float $amount): float { return $amount; }
}
class TenPercentDiscount implements Discount {
    public function apply(float $amount): float { return $amount * 0.9; }
}

// L — Liskov Substitution
class Bird {
    public function walk(): string { return "jalan"; }
}
class Sparrow extends Bird {}
function jalankanBurung(Bird $bird): string { return $bird->walk(); }

// I — Interface Segregation
interface Workable { public function work(): string; }
interface Feedable { public function eat(): string; }
class HumanWorker implements Workable, Feedable {
    public function work(): string { return "bekerja"; }
    public function eat(): string { return "makan siang"; }
}
class RobotWorker implements Workable {
    public function work(): string { return "bekerja"; }
}

// D — Dependency Inversion
interface DatabaseDriver {
    public function connect(): void;
}
class MySQLDriver implements DatabaseDriver {
    public function connect(): void { echo "MySQL connected\n"; }
}
class App {
    public function __construct(private DatabaseDriver $db) {}
    public function boot(): void { $this->db->connect(); }
}
?>
```

## Kasus Penggunaan Nyata
Semua aplikasi PHP profesional — Laravel, Symfony, dan framework lain menerapkan SOLID principles dalam arsitekturnya.
