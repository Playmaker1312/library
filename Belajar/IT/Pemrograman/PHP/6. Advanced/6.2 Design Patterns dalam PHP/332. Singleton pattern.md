# 332. Singleton Pattern

## Definisi Singkat
Singleton memastikan sebuah kelas hanya memiliki satu instance dan menyediakan akses global ke instance tersebut.

## Analogi
Seperti presiden sebuah negara — hanya ada satu dalam satu waktu, dan semua orang mengakses presiden yang sama.

## Poin-Poin Penting
- Constructor private — tidak bisa diinstansiasi dari luar
- Static method `getInstance()` untuk mengakses instance
- Memiliki static property untuk menyimpan instance tunggal
- Sering dikritik karena menyembunyikan dependensi
- Alternatif: Dependency Injection

## Contoh Kode (PHP)
```php
<?php
class KoneksiDatabase {
    private static ?KoneksiDatabase $instance = null;
    private \PDO $pdo;
    
    private function __construct() {
        $this->pdo = new \PDO('mysql:host=localhost;dbname=test', 'root', '');
    }
    
    public static function getInstance(): self {
        if (self::$instance === null) {
            self::$instance = new self();
        }
        return self::$instance;
    }
    
    public function query(string $sql): array {
        $stmt = $this->pdo->query($sql);
        return $stmt->fetchAll(\PDO::FETCH_ASSOC);
    }
    
    // Cegah cloning dan unserialize
    private function __clone() {}
    public function __wakeup() {
        throw new \Exception("Cannot unserialize singleton");
    }
}

$db1 = KoneksiDatabase::getInstance();
$db2 = KoneksiDatabase::getInstance();
var_dump($db1 === $db2);
// Output: bool(true)
?>
```

## Kasus Penggunaan Nyata
Konfigurasi aplikasi global, koneksi database, logger, cache manager — yang hanya perlu satu instance sepanjang aplikasi.
