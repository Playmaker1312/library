# 340. Strategy Pattern

## Definisi Singkat
Strategy pattern memungkinkan algoritma yang bisa dipertukarkan saat runtime, dengan memisahkan algoritma dari penggunaannya.

## Analogi
Seperti aplikasi peta — Anda bisa memilih rute mobil, sepeda, atau jalan kaki; aplikasi menggunakan strategi berbeda untuk hasil berbeda.

## Poin-Poin Penting
- Family of algorithms yang bisa dipertukarkan
- Menerapkan prinsip Open/Closed
- Menggunakan komposisi (interface) daripada inheritance
- Cocok untuk menggantikan kondisional panjang (if/elseif/switch)
- Strategy bisa diganti saat runtime

## Contoh Kode (PHP)
```php
<?php
interface SortStrategy {
    public function sort(array $data): array;
}

class BubbleSort implements SortStrategy {
    public function sort(array $data): array {
        sort($data);
        echo "Menggunakan BubbleSort\n";
        return $data;
    }
}

class QuickSort implements SortStrategy {
    public function sort(array $data): array {
        sort($data);
        echo "Menggunakan QuickSort\n";
        return $data;
    }
}

class SortContext {
    public function __construct(private SortStrategy $strategy) {}
    
    public function setStrategy(SortStrategy $strategy): void {
        $this->strategy = $strategy;
    }
    
    public function executeSort(array $data): array {
        return $this->strategy->sort($data);
    }
}

$data = [3, 1, 4, 1, 5, 9];
$context = new SortContext(new BubbleSort());
print_r($context->executeSort($data));

$context->setStrategy(new QuickSort());
print_r($context->executeSort($data));
// Output: Menggunakan BubbleSort
// Output: Array ( [0] => 1 [1] => 1 [2] => 3 [3] => 4 [4] => 5 [5] => 9 )
// Output: Menggunakan QuickSort
// Output: Array ( [0] => 1 [1] => 1 [2] => 3 [3] => 4 [4] => 5 [5] => 9 )
?>
```

## Kasus Penggunaan Nyata
Metode pembayaran (Kartu Kredit, GoPay, Transfer), algoritma sorting/compression, validasi rules, authorization strategies, shipping cost calculation.
