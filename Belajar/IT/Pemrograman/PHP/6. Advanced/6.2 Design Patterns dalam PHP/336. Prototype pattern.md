# 336. Prototype Pattern

## Definisi Singkat
Prototype pattern membuat objek baru dengan menyalin (clone) objek yang sudah ada, daripada membuat dari awal.

## Analogi
Seperti fotokopi dokumen — daripada mengetik ulang seluruh dokumen, cukup fotokopi dan edit bagian yang perlu.

## Poin-Poin Penting
- Menggunakan cloning (`clone` keyword) di PHP
- Semua objek PHP secara default di-copy shallow
- `__clone()` method untuk deep copy
- Mengurangi overhead pembuatan objek berat
- Berguna ketika tipe objek ditentukan saat runtime

## Contoh Kode (PHP)
```php
<?php
class KonfigurasiAplikasi {
    public array $pengaturan = [];
    public string $lingkungan = 'development';
    
    public function __construct() {
        // Simulasi loading konfigurasi berat
        $this->pengaturan = [
            'db_host' => 'localhost',
            'db_name' => 'app',
            'debug' => true,
            'cache' => false,
        ];
    }
    
    public function __clone(): void {
        // Deep copy untuk properti array
        $this->pengaturan = array_merge([], $this->pengaturan);
    }
    
    public function setDebug(bool $value): void {
        $this->pengaturan['debug'] = $value;
    }
}

$konfigurasiDasar = new KonfigurasiAplikasi();

$configProd = clone $konfigurasiDasar;
$configProd->lingkungan = 'production';
$configProd->setDebug(false);

$configStaging = clone $konfigurasiDasar;
$configStaging->lingkungan = 'staging';

echo $configProd->lingkungan . " debug: " . ($configProd->pengaturan['debug'] ? 'true' : 'false');
echo "\n";
echo $configStaging->lingkungan . " debug: " . ($configStaging->pengaturan['debug'] ? 'true' : 'false');
// Output: production debug: false
// Output: staging debug: true
?>
```

## Kasus Penggunaan Nyata
Konfigurasi yang di-clone untuk berbagai environment, template object yang sering di-copy dengan modifikasi kecil, caching expensive object creation.
