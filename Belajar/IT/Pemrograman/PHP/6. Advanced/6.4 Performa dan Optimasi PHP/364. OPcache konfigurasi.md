# 364. OPcache Konfigurasi

## Definisi Singkat
OPcache menyimpan bytecode PHP yang sudah dikompilasi di memori sehingga tidak perlu dikompilasi ulang setiap request.

## Analogi
Seperti menyimpan makanan siap saji di kulkas — daripada memasak ulang setiap kali lapar, tinggal panaskan sebentar.

## Poin-Poin Penting
- Bawaan PHP — aktif default di PHP 8+
- Mengurangi waktu eksekusi 30-70%
- Tidak perlu instalasi tambahan
- Konfigurasi di `php.ini` atau `opcache.ini`
- `opcache.memory_consumption`: alokasi memori (default 128MB)
- `opcache.max_accelerated_files`: jumlah file maksimal

## Contoh Kode (PHP)
```ini
; php.ini — konfigurasi OPcache optimal
opcache.enable=1
opcache.enable_cli=0          ; CLI biasanya tidak perlu
opcache.memory_consumption=256 ; MB untuk cache
opcache.interned_strings_buffer=16 ; MB untuk string interned
opcache.max_accelerated_files=20000 ; Jumlah file
opcache.revalidate_freq=2     ; Detik sebelum cek perubahan file
opcache.fast_shutdown=1       ; Fast shutdown optimization

; Development — untuk saat coding
; opcache.revalidate_freq=0
; opcache.validate_timestamps=1

; Production
; opcache.validate_timestamps=0  ; Manual clear cache jika deploy
```

```php
<?php
// Cek status OPcache
$status = opcache_get_status();

if ($status !== false) {
    echo "OPcache enabled: " . ($status['opcache_enabled'] ? 'Yes' : 'No') . "\n";
    echo "Memory usage: " . round(
        $status['memory_usage']['used_memory'] / 1024 / 1024, 2
    ) . "MB / " . round(
        $status['memory_usage']['free_memory'] / 1024 / 1024, 2
    ) . "MB free\n";
    echo "Cached files: " . $status['opcache_statistics']['num_cached_scripts'] . "\n";
    echo "Hit rate: " . round($status['opcache_statistics']['hits'] / 
        ($status['opcache_statistics']['hits'] + $status['opcache_statistics']['misses']) * 100, 2) . "%\n";
}
?>
```

## Kasus Penggunaan Nyata
Semua aplikasi PHP production — Laravel, Symfony, WordPress, dll. OPcache adalah optimasi termudah dan paling berdampak.
