# 366. Redis Caching PHP

## Definisi Singkat
Redis adalah penyimpanan data in-memory yang bisa digunakan sebagai cache, session store, queue, dan pub/sub.

## Analogi
Seperti gudang sentral yang super cepat — semua barang (data) disimpan di rak yang mudah dijangkau dari mana saja.

## Poin-Poin Penting
- In-memory data structure store — sangat cepat (sub-millisecond)
- Mendukung: string, hash, list, set, sorted set
- PHP library: `predis/predis` (pure PHP) atau `phpredis` (extension)
- Fitur: TTL, pub/sub, transactions, persistence
- Cocok untuk cache terdistribusi (multi-server)

## Contoh Kode (PHP)
```php
<?php
require 'vendor/autoload.php';

// Menggunakan Predis (pure PHP)
use Predis\Client as RedisClient;

$redis = new RedisClient([
    'scheme' => 'tcp',
    'host'   => '127.0.0.1',
    'port'   => 6379,
]);

// String cache
$redis->set('user:1:name', 'Adi Prasetyo', 'EX', 3600);
echo $redis->get('user:1:name');

// Cache dengan TTL
$redis->setex('session:abc123', 86400, json_encode(['user_id' => 1, 'role' => 'admin']));

// Cache query results
function getPopularProducts(RedisClient $redis): array {
    $cacheKey = 'products:popular';
    $cached = $redis->get($cacheKey);
    
    if ($cached) {
        return json_decode($cached, true);
    }
    
    // Query database (simulasi)
    $products = [
        ['id' => 1, 'name' => 'Laptop', 'views' => 1000],
        ['id' => 2, 'name' => 'Mouse', 'views' => 800],
    ];
    
    $redis->setex($cacheKey, 300, json_encode($products));
    return $products;
}

$products = getPopularProducts($redis);
print_r($products);
// Output: Adi Prasetyo
?>
```

## Kasus Penggunaan Nyata
Session management, rate limiting, API response cache, job queue (Laravel queues menggunakan Redis), real-time leaderboard.
