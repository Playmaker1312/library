# 367. Memcached Caching

## Definisi Singkat
Memcached adalah sistem caching in-memory terdistribusi yang sederhana dan cepat untuk menyimpan data kecil.

## Analogi
Seperti loker penyimpanan di stasiun — cepat, sederhana, dan bisa diakses dari banyak tempat.

## Poin-Poin Penting
- Lebih sederhana dari Redis — hanya key-value string
- Sangat cepat untuk operasi get/set
- Tidak ada persistence (data hilang jika restart)
- PHP extension: `memcached` (libmemcached) atau `memcache`
- Cocok untuk cache sederhana tanpa fitur kompleks

## Contoh Kode (PHP)
```php
<?php
// Membutuhkan extension php-memcached
$memcached = new Memcached();
$memcached->addServer('127.0.0.1', 11211);

// Simpan cache
$memcached->set('kota_list', [
    'Jakarta', 'Bandung', 'Surabaya', 'Medan'
], 3600); // TTL 1 jam

// Ambil cache
$kota = $memcached->get('kota_list');
if ($memcached->getResultCode() === Memcached::RES_SUCCESS) {
    echo "Dari cache: " . implode(', ', $kota) . "\n";
} else {
    echo "Cache miss — ambil dari database\n";
}

// Cache multi-key
$memcached->setMulti([
    'config:app_name' => 'MyApp',
    'config:version' => '2.1',
    'config:debug' => false,
], 7200);

// Increment/Decrement
$memcached->set('page_visits', 0);
$memcached->increment('page_visits');
echo "Visits: " . $memcached->get('page_visits');

// Delete cache
$memcached->delete('kota_list');
$memcached->flush(); // Hapus semua cache

// Output: Dari cache: Jakarta, Bandung, Surabaya, Medan
// Output: Visits: 1
?>
```

## Kasus Penggunaan Nyata
Cache hasil query yang sering diakses, cache HTML fragment, session storage, rate limiting sederhana.
