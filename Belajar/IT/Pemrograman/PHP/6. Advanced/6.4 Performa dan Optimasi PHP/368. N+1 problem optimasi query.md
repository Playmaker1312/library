# 368. N+1 Problem Optimasi Query

## Definisi Singkat
N+1 problem adalah anti-pattern di mana aplikasi menjalankan 1 query untuk data utama, lalu N query untuk data relasi (N = jumlah baris).

## Analogi
Seperti pergi ke perpustakaan, bertanya "mana buku penulis X?" (1 query), lalu untuk setiap buku Anda bertanya lagi "apa isi buku ini?" (N query).

## Poin-Poin Penting
- 1 query awal + N query tambahan = total N+1 query
- Sangat lambat jika N besar
- Solusi: JOIN, eager loading, batch query
- ORM (Eloquent, Doctrine) bisa menyebabkan N+1 jika tidak hati-hati
- Identifikasi dengan log query atau profiling

## Contoh Kode (PHP)
```php
<?php
class BlogController {
    private \PDO $pdo;
    
    public function __construct() {
        $this->pdo = new \PDO('sqlite::memory:');
        $this->setupData();
    }
    
    private function setupData(): void {
        $this->pdo->exec('CREATE TABLE authors (id INTEGER PRIMARY KEY, name TEXT)');
        $this->pdo->exec('CREATE TABLE posts (id INTEGER PRIMARY KEY, title TEXT, author_id INTEGER)');
        $this->pdo->exec("INSERT INTO authors VALUES (1, 'Adi'), (2, 'Budi')");
        $this->pdo->exec("INSERT INTO posts VALUES (1, 'Post A', 1), (2, 'Post B', 1), (3, 'Post C', 2)");
    }
    
    // N+1 PROBLEM
    public function getPostsNPlus1(): void {
        $posts = $this->pdo->query('SELECT * FROM posts')->fetchAll();
        
        foreach ($posts as $post) {
            // Query ini dijalankan sekali per post!
            $stmt = $this->pdo->prepare('SELECT name FROM authors WHERE id = ?');
            $stmt->execute([$post['author_id']]);
            $author = $stmt->fetchColumn();
            echo "{$post['title']} oleh $author\n";
        }
    }
    
    // SOLUSI: JOIN
    public function getPostsWithJoin(): void {
        $stmt = $this->pdo->query('
            SELECT p.title, a.name as author
            FROM posts p
            JOIN authors a ON a.id = p.author_id
        ');
        
        foreach ($stmt->fetchAll() as $row) {
            echo "{$row['title']} oleh {$row['author']}\n";
        }
    }
}

$blog = new BlogController();
$blog->getPostsWithJoin();
// Output: Post A oleh Adi
// Output: Post B oleh Adi
// Output: Post C oleh Budi
?>
```

## Kasus Penggunaan Nyata
Eloquent ORM (Laravel): `with()` untuk eager loading, Doctrine: `LEFT JOIN` atau batch fetching, API response yang menyertakan relasi.
