# 362. Xdebug Profiling

## Definisi Singkat
Xdebug profiling menghasilkan data eksekusi kode (function calls, waktu, memory) untuk menganalisis performa aplikasi PHP.

## Analogi
Seperti dashcam yang merekam seluruh perjalanan — Anda bisa memutar ulang untuk melihat di mana waktu terbuang.

## Poin-Poin Penting
- Aktifkan: `xdebug.mode=profile` di php.ini
- Hasil file `.cachegrind` — bisa dibaca dengan tools
- Tools analisis: KCacheGrind, QCacheGrind, WebGrind, PhpStorm
- Lihat: jumlah panggilan, waktu sendiri (self time), waktu kumulatif
- Fokus pada function dengan self time tinggi

## Contoh Kode (PHP)
```ini
; php.ini — konfigurasi Xdebug profiling
xdebug.mode=profile
xdebug.output_dir=/tmp/profiling
xdebug.profiler_output_name=cachegrind.out.%t.%p

; Untuk CLI
; php -d xdebug.mode=profile script.php
```

```php
<?php
// Script yang akan diprofil
function prosesData(array $data): array {
    $result = [];
    foreach ($data as $item) {
        $result[] = transformItem($item);
    }
    return $result;
}

function transformItem(string $item): string {
    $item = strtolower($item);
    $item = preg_replace('/[^a-z]/', '', $item);
    return strrev($item);
}

$data = range('a', 'z');
$hasil = prosesData($data);
print_r($hasil);

// Setelah profiling, buka hasil .cachegrind dengan QCacheGrind
// Lihat function mana yang paling lambat
?>
```

## Kasus Penggunaan Nyata
Optimasi halaman web lambat, debugging memory leak, analisis performa algoritma, identifikasi fungsi yang dipanggil terlalu sering.
