# 373. Queue System — RabbitMQ & Redis

## Definisi Singkat
Queue system memungkinkan pemrosesan tugas secara asynchronous dengan menunda pekerjaan berat ke worker terpisah.

## Analogi
Seperti restoran dengan dapur — pelayan menaruh order di papan (queue), dan koki mengambil order satu per satu untuk dimasak.

## Poin-Poin Penting
- **Producer**: aplikasi yang mengirim job ke queue
- **Consumer/Worker**: proses yang mengambil dan memproses job
- **RabbitMQ**: message broker dengan fitur lengkap (AMQP)
- **Redis**: bisa jadi simple queue (list: LPUSH/BRPOP)
- Laravel Queue mendukung berbagai driver (database, Redis, SQS)

## Contoh Kode (PHP)
```php
<?php
require 'vendor/autoload.php';

use PhpAmqpLib\Connection\AMQPStreamConnection;
use PhpAmqpLib\Message\AMQPMessage;

// PRODUCER — kirim email task ke queue
class EmailProducer {
    private AMQPStreamConnection $connection;
    
    public function __construct() {
        $this->connection = new AMQPStreamConnection('localhost', 5672, 'guest', 'guest');
    }
    
    public function queue(string $to, string $subject, string $body): void {
        $channel = $this->connection->channel();
        $channel->queue_declare('email_queue', false, true, false, false);
        
        $msg = new AMQPMessage(json_encode([
            'to' => $to,
            'subject' => $subject,
            'body' => $body,
        ]), ['delivery_mode' => AMQPMessage::DELIVERY_MODE_PERSISTENT]);
        
        $channel->basic_publish($msg, '', 'email_queue');
        $channel->close();
        
        echo "Email queued to $to\n";
    }
}
```
