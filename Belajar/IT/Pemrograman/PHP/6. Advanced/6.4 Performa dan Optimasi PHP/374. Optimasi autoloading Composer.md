# 374. Optimasi Autoloading Composer

## Definisi Singkat
Autoloading memuat kelas PHP secara otomatis saat dibutuhkan; optimasi Composer mempercepat proses ini.

## Analogi
Seperti pustakawan yang tahu persis di mana setiap buku berada — Anda minta buku X, dan pustakawan langsung mengambilnya tanpa mencari-cari.

## Poin-Poin Penting
- Composer autoload: PSR-4, PSR-0, Classmap, Files
- Dev: `composer dump-autoload` — regenerasi autoload
- Production: `composer dump-autoload -o` (optimasi classmap)
- `-o` (optimize): buat classmap untuk loading cepat
- `-a` (classmap-authoritative): hanya pakai classmap, tidak cek filesystem

## Contoh Kode (PHP)
```bash
# Development — cepat untuk perubahan
composer install

# Production — optimasi autoloading
composer install --no-dev --optimize-autoloader
# atau
composer dump-autoload -o

# Classmap authoritative — paling cepat, tapi harus regenerate jika tambah class
composer dump-autoload -a

# Hasil: vendor/composer/autoload_classmap.php
# Berisi mapping class → file path
```

```json
{
    "name": "app/ku",
    "autoload": {
        "psr-4": {
            "App\\": "src/"
        },
        "files": [
            "src/helpers.php"
        ],
        "classmap": [
            "src/legacy/"
        ]
    },
    "scripts": {
        "post-autoload-dump": [
            "echo 'Optimasi autoload selesai!'"
        ]
    }
}
```

```php
<?php
// Sebelum optimasi — Composer cek filesystem untuk setiap namespace
require 'vendor/autoload.php';

// Setelah optimasi (-o) — Composer langsung lihat classmap
// Lebih cepat karena tidak perlu fallback ke filesystem

use App\Controllers\UserController;
use App\Models\User;

$controller = new UserController();
echo "Autoloading dioptimasi dengan classmap\n";

// Cek classmap
$classmap = require 'vendor/composer/autoload_classmap.php';
echo "Total class di map: " . count($classmap) . "\n";
?>
```

## Kasus Penggunaan Nyata
Semua proyek PHP production — optimasi autoloading penting untuk mengurangi waktu loading setiap request, terutama dengan OPcache.
