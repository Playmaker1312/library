# 372. Asynchronous PHP — ReactPHP & Swoole

## Definisi Singkat
Asynchronous PHP memungkinkan eksekusi non-blocking, menangani banyak tugas concurrent tanpa menunggu satu sama lain.

## Analogi
Seperti barista yang bisa membuat kopi sambil menerima pesanan baru — tidak perlu diam menunggu kopi selesai.

## Poin-Poin Penting
- **ReactPHP**: event-driven, non-blocking I/O (pure PHP)
- **Swoole**: PHP extension untuk async, coroutine, dan server
- Cocok untuk: WebSocket server, HTTP server, real-time apps
- PHP tradisional blocking — satu request satu proses
- Async PHP: satu proses bisa tangani ribuan koneksi

## Contoh Kode (PHP)
```php
<?php
// ReactPHP — event loop
require 'vendor/autoload.php';

use React\EventLoop\Loop;
use React\Http\HttpServer;
use React\Http\Message\Response;
use Psr\Http\Message\ServerRequestInterface;

// HTTP server sederhana dengan ReactPHP
$server = new HttpServer(function (ServerRequestInterface $request) {
    return new Response(
        200,
        ['Content-Type' => 'application/json'],
        json_encode(['message' => 'Hello dari ReactPHP!', 'method' => $request->getMethod()])
    );
});

$socket = new React\Socket\SocketServer('127.0.0.1:8080');
$server->listen($socket);

echo "Server running on http://127.0.0.1:8080\n";

// Swoole — coroutine-based
// $http = new Swoole\Http\Server('0.0.0.0', 9501);
// $http->on('request', function ($request, $response) {
//     $response->header('Content-Type', 'application/json');
//     $response->end(json_encode(['message' => 'Swoole!']));
// });
// $http->start();
// Jalankan dengan: php -d extension=swoole server.php
?>
```

## Kasus Penggunaan Nyata
WebSocket chat application, real-time notification, API gateway, microservices, IoT data processing, HTTP server tanpa Nginx/Apache.
