# 365. APCu Caching

## Definisi Singkat
APCu (Alternative PHP User Cache) menyimpan data di memori bersama (shared memory) untuk akses cepat antar request.

## Analogi
Seperti whiteboard di ruang rapat — semua orang bisa menulis dan membaca informasi tanpa perlu ke ruang arsip.

## Poin-Poin Penting
- Menyimpan data user (bukan bytecode seperti OPcache)
- Data disimpan di shared memory — sangat cepat
- Instal: `pecl install apcu`
- Fungsi: `apcu_store()`, `apcu_fetch()`, `apcu_delete()`
- Cocok untuk cache config, hasil query, session data

## Contoh Kode (PHP)
```php
<?php
// Cek APCu tersedia
if (!function_exists('apcu_enabled') || !apcu_enabled()) {
    echo "APCu tidak aktif\n";
    exit;
}

class CacheManager {
    public static function remember(string $key, int $ttl, callable $callback): mixed {
        $cached = apcu_fetch($key, $success);
        
        if ($success) {
            return $cached;
        }
        
        $value = $callback();
        apcu_store($key, $value, $ttl);
        return $value;
    }
    
    public static function invalidate(string $key): bool {
        return apcu_delete($key);
    }
}

// Contoh penggunaan
$konfigurasi = CacheManager::remember('app.config', 3600, function () {
    // Simulasi load konfigurasi dari database
    return [
        'app_name' => 'AplikasiKu',
        'version' => '2.0',
        'features' => ['dark_mode', 'export_pdf'],
    ];
});

echo $konfigurasi['app_name'];
apcu_store('page_views', 1000);

// Gunakan APC UI atau apcu.php untuk monitoring
// https://pecl.php.net/package/apcu
// Output: AplikasiKu
?>
```

## Kasus Penggunaan Nyata
Cache konfigurasi aplikasi, cache hasil query, cache session, cache data yang jarang berubah (negara, kota, kategori).
