# 369. Lazy Loading

## Definisi Singkat
Lazy loading menunda pembuatan atau loading objek/data sampai benar-benar dibutuhkan, bukan saat inisialisasi.

## Analogi
Seperti memesan makanan di restoran — Anda tidak menyiapkan semua bahan makanan di rumah, tapi memesan saat lapar.

## Poin-Poin Penting
- Menunda resource-heavy operations sampai diperlukan
- Mengurangi memory usage dan waktu inisialisasi
- Teknik: `if ($this->data === null) { $this->data = loadData(); } return $this->data;`
- Pattern: Lazy Loading, Proxy, Virtual Proxy
- ORM spesso menerapkan lazy loading untuk relasi

## Contoh Kode (PHP)
```php
<?php
class Gambar {
    private ?string $metadata = null;
    private bool $loaded = false;
    
    public function __construct(
        public readonly string $filename
    ) {}
    
    // Lazy loading — metadata hanya di-load saat diminta
    public function getMetadata(): array {
        if (!$this->loaded) {
            echo "Loading metadata untuk {$this->filename}...\n";
            $this->metadata = [
                'size' => filesize($this->filename),
                'dimension' => '1920x1080',
                'type' => mime_content_type($this->filename)
            ];
            $this->loaded = true;
        }
        return $this->metadata;
    }
}

// Lazy loading pada properti class
class Order {
    private ?array $items = null;
    private \PDO $pdo;
    
    public function __construct(
        public readonly int $id
    ) {
        $this->pdo = new \PDO('mysql:host=localhost;dbname=shop', 'root', '');
    }
    
    public function getItems(): array {
        if ($this->items === null) {
            $stmt = $this->pdo->prepare('SELECT * FROM order_items WHERE order_id = ?');
            $stmt->execute([$this->id]);
            $this->items = $stmt->fetchAll();
        }
        return $this->items;
    }
}

$order = new Order(1);
// Items belum di-load
echo "Order dibuat\n";
// Items baru di-load saat dipanggil
print_r($order->getItems());
// Output: Order dibuat
// Output: (query results)
?>
```

## Kasus Penggunaan Nyata
Relasi ORM (Eloquent lazy loading), singleton pattern, loading file besar, koneksi database yang berat, image processing.
