# 371. Generator untuk Data Besar

## Definisi Singkat
Generator adalah fungsi PHP yang menggunakan `yield` untuk menghasilkan nilai satu per satu tanpa menyimpan semua di memori.

## Analogi
Seperti keran air — Anda tidak perlu menyimpan seluruh sungai di rumah, cukup buka keran saat butuh air.

## Poin-Poin Penting
- `yield` mengembalikan nilai dan menjeda eksekusi
- Generator mengembalikan object `Generator`
- Sangat hemat memori untuk data besar
- Bisa digunakan dengan `foreach`
- Bisa menerima data dengan `$generator->send()`

## Contoh Kode (PHP)
```php
<?php
// Tanpa generator — boros memori
function rangeLama(int $start, int $end, int $step = 1): array {
    $result = [];
    for ($i = $start; $i <= $end; $i += $step) {
        $result[] = $i; // Semua disimpan di array
    }
    return $result;
}

// Dengan generator — hemat memori
function rangeBaru(int $start, int $end, int $step = 1): Generator {
    for ($i = $start; $i <= $end; $i += $step) {
        yield $i; // Hanya satu nilai di memori
    }
}

// Memproses file CSV besar
function bacaCSV(string $path): Generator {
    $handle = fopen($path, 'r');
    while (($baris = fgetcsv($handle)) !== false) {
        yield $baris;
    }
    fclose($handle);
}

// Contoh penggunaan
foreach (rangeBaru(1, 1000000) as $angka) {
    if ($angka > 5) break; // Hanya proses 5 angka pertama
    echo $angka . " ";
}
echo "\n";

// Cek memory
echo "Memory: " . round(memory_get_usage() / 1024, 2) . " KB\n";

// Generator dengan kunci
function hitungMundur(int $dari): Generator {
    for ($i = $dari; $i > 0; $i--) {
        yield "detik_$i" => $i;
    }
}

foreach (hitungMundur(3) as $key => $value) {
    echo "$key: $value\n";
}
// Output: 1 2 3 4 5
// Output: Memory: ~384 KB (vs jutaan KB jika array)
// Output: detik_3: 3
// Output: detik_2: 2
// Output: detik_1: 1
?>
```

## Kasus Penggunaan Nyata
Memproses file CSV besar (jutaan baris), streaming API response, membaca database dengan ribuan hasil, export data besar.
