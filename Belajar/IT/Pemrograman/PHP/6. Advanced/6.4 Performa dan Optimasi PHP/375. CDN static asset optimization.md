# 375. CDN & Static Asset Optimization

## Definisi Singkat
CDN (Content Delivery Network) mendistribusikan file statis (CSS, JS, gambar) ke server di seluruh dunia untuk loading lebih cepat.

## Analogi
Seperti franchise restoran — daripada semua orang datang ke dapur pusat, ada cabang di setiap kota yang menyajikan makanan yang sama.

## Poin-Poin Penting
- CDN menyimpan cache file statis di edge servers
- Mengurangi beban server utama
- Teknik: minifikasi, compression (Gzip/Brotli), cache headers
- Asset versioning (query string atau file hash)
- Tools: Laravel Mix, Vite, Webpack Encore

## Contoh Kode (PHP)
```php
<?php
// Helper untuk URL asset dengan versioning
class AssetManager {
    private static array $manifests = [];
    
    public static function getVersionedPath(string $asset): string {
        $manifestPath = __DIR__ . '/public/build/manifest.json';
        
        if (!isset(self::$manifests[$manifestPath])) {
            self::$manifests[$manifestPath] = json_decode(
                file_get_contents($manifestPath), true
            );
        }
        
        $manifest = self::$manifests[$manifestPath];
        $cdnBase = 'https://cdn.example.com';
        
        // Jika ada di manifest (Vite/Mix), gunakan versioned file
        if (isset($manifest[$asset])) {
            return $cdnBase . '/build/' . $manifest[$asset]['file'];
        }
        
        // Fallback dengan query string versioning
        $version = md5_file(__DIR__ . '/public/' . $asset);
        return $cdnBase . '/' . $asset . '?v=' . substr($version, 0, 8);
    }
}

// Penggunaan di view
echo '<link rel="stylesheet" href="' . AssetManager::getVersionedPath('css/app.css') . '">';
echo '<script src="' . AssetManager::getVersionedPath('js/app.js') . '"></script>';

// Konfigurasi cache headers di .htaccess atau Nginx
/*
<FilesMatch "\.(css|js|jpg|jpeg|png|gif|ico|svg|webp)$">
    Header set Cache-Control "public, max-age=31536000, immutable"
</FilesMatch>
*/

// Penggunaan CDN
// define('CDN_URL', 'https://cdn.example.com');
// <script src="<?= CDN_URL ?>/js/app.js"></script>
?>
```

## Kasus Penggunaan Nyata
Semua aplikasi web publik — WordPress, Laravel, Symfony; menggunakan CDN seperti Cloudflare, AWS CloudFront, atau Fastly.
