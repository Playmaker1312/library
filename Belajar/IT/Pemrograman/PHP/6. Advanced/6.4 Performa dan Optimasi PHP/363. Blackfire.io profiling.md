# 363. Blackfire.io Profiling

## Definisi Singkat
Blackfire adalah layanan profiling dan monitoring performa untuk aplikasi PHP dengan visualisasi yang kaya.

## Analogi
Seperti CCTV dengan analitik AI — bukan hanya merekam, tapi juga memberi rekomendasi area mana yang perlu diperbaiki.

## Poin-Poin Penting
- SaaS-based profiling — data dikirim ke dashboard Blackfire
- Integrasi dengan browser extension (Chrome, Firefox)
- Fitur: call graph, flame graphs, performance recommendations
- Bisa profiling di development dan production
- Memerlukan akun dan Blackfire Agent

## Contoh Kode (PHP)
```bash
# Install Blackfire Agent
# https://blackfire.io/docs/up-and-running/installation

# Profiling via CLI
php -d blackfire.agent_socket=tcp://127.0.0.1:8307 \
    -d blackfire.apm_enabled=1 \
    script.php

# Profiling via browser dengan extension
# Klik tombol Blackfire di browser → halaman di-profil
# Hasil di dashboard blackfire.io
```

```php
<?php
// Kode yang akan diprofil dengan Blackfire
class ProdukService {
    public function getProdukPopuler(int $limit = 10): array {
        // Query kompleks
        $produk = $this->queryDatabase("
            SELECT p.*, AVG(r.rating) as avg_rating
            FROM products p
            JOIN reviews r ON r.product_id = p.id
            GROUP BY p.id
            ORDER BY avg_rating DESC
            LIMIT $limit
        ");
        
        // Transform data
        return array_map(fn($p) => [
            'id' => $p['id'],
            'nama' => $p['name'],
            'harga' => $this->formatHarga($p['price']),
            'rating' => round($p['avg_rating'], 1),
        ], $produk);
    }
}

// Dashboard Blackfire akan merekomendasikan:
// - Query mana yang lambat
// - Function mana yang banyak alokasi memori
// - Bottleneck di bagian mana
?>
```

## Kasus Penggunaan Nyata
Performance audit aplikasi web, monitoring production, optimasi halaman lambat, analisis regression performa.
