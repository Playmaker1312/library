# 361. Identifikasi Bottleneck PHP

## Definisi Singkat
Bottleneck adalah titik dalam aplikasi yang membatasi performa keseluruhan — bagian paling lambat yang perlu dioptimasi.

## Analogi
Seperti pipa air yang menyempit di satu titik — seluruh aliran air terhambat oleh bagian tersempit itu.

## Poin-Poin Penting
- Gunakan profiling (Xdebug, Blackfire) untuk menemukan bottleneck
- Bottleneck umum: query database lambat, N+1 problem, looping besar
- Monitoring: response time, memory usage, CPU usage
- Jangan optimasi tanpa data — ukur dulu
- 80% performa dari 20% kode (Pareto principle)

## Contoh Kode (PHP)
```php
<?php
// Contoh bottleneck — query N+1
class BlogController {
    private \PDO $pdo;
    
    public function __construct() {
        $this->pdo = new \PDO('mysql:host=localhost;dbname=blog', 'root', '');
    }
    
    // BOTTLENECK: Query N+1
    public function getPostsWithComments(): array {
        $posts = $this->pdo->query('SELECT * FROM posts')->fetchAll();
        
        foreach ($posts as &$post) {
            // Query ini dijalankan untuk setiap post! (N+1)
            $stmt = $this->pdo->prepare('SELECT * FROM comments WHERE post_id = ?');
            $stmt->execute([$post['id']]);
            $post['comments'] = $stmt->fetchAll();
        }
        
        return $posts;
    }
    
    // OPTIMASI: JOIN atau single query
    public function getPostsWithCommentsOptimized(): array {
        $stmt = $this->pdo->query('
            SELECT p.*, c.id as comment_id, c.body as comment_body
            FROM posts p
            LEFT JOIN comments c ON c.post_id = p.id
        ');
        return $stmt->fetchAll();
    }
}
?>
```

## Kasus Penggunaan Nyata
Audit performa aplikasi web, optimasi halaman lambat, persiapan scaling aplikasi, identifikasi regresi performa.
