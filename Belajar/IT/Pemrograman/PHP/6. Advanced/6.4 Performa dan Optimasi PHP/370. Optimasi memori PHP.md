# 370. Optimasi Memori PHP

## Definisi Singkat
Optimasi memori mengelola penggunaan RAM oleh aplikasi PHP agar efisien, terutama untuk memproses data besar.

## Analogi
Seperti mengemas koper untuk perjalanan — Anda harus cerdas memasukkan barang (data) agar tidak kehabisan ruang (memori).

## Poin-Poin Penting
- Monitor memory: `memory_get_usage()`, `memory_get_peak_usage()`
- Batasi memory: `ini_set('memory_limit', '256M')`
- Hindari menyimpan semua data di array — gunakan generator
- `unset()` variabel besar yang tidak dipakai
- Gunakan streaming untuk file besar
- Perhatikan reference cycles (garbage collection)

## Contoh Kode (PHP)
```php
<?php
// MEMORY INEFFICIENT — load semua file ke memory
function prosesFileLama(string $path): int {
    $baris = file($path); // Semua baris di-load ke array
    $total = 0;
    foreach ($baris as $baris) {
        $total += (int) $baris;
    }
    return $total;
}

// MEMORY EFFICIENT — streaming
function prosesFileBaru(string $path): int {
    $handle = fopen($path, 'r');
    $total = 0;
    
    while (($baris = fgets($handle)) !== false) {
        $total += (int) $baris;
    }
    
    fclose($handle);
    return $total;
}

// Monitor memory
function monitorMemory(): void {
    echo "Memory usage: " . round(memory_get_usage() / 1024 / 1024, 2) . " MB\n";
    echo "Peak memory: " . round(memory_get_peak_usage() / 1024 / 1024, 2) . " MB\n";
}

// Hindari reference cycles
class Node {
    public ?Node $parent = null;
    public array $children = [];
}

function createTree(): void {
    $root = new Node();
    $child = new Node();
    $root->children[] = $child;
    $child->parent = $root; // Reference cycle
    
    // Unset untuk membantu garbage collector
    unset($root, $child);
}

monitorMemory();
// Output: Memory usage: 0.58 MB
// Output: Peak memory: 0.78 MB
?>
```

## Kasus Penggunaan Nyata
Memproses CSV/file besar, export data ribuan baris, image processing, API response dengan data besar, batch processing.
