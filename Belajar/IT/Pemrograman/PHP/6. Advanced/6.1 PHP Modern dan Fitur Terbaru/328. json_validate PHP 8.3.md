# 328. json_validate PHP 8.3

## Definisi Singkat
`json_validate()` adalah fungsi native PHP untuk memeriksa apakah string adalah JSON valid tanpa perlu mendekode penuh.

## Analogi
Seperti pemeriksa di pintu masuk yang hanya melihat tiket (valid/tidak) tanpa perlu membaca detail di dalam tiket.

## Poin-Poin Penting
- Mengembalikan `bool` — true jika JSON valid
- Lebih cepat daripada `json_decode()` + pengecekan error
- Tidak mengalokasi memori untuk data JSON
- Parameter: string (kedalaman opsional)
- Flags: `JSON_INVALID_UTF8_IGNORE` dan `JSON_INVALID_UTF8_SUBSTITUTE`

## Contoh Kode (PHP)
```php
<?php
$jsonBenar = '{"nama": "Adi", "usia": 25}';
$jsonSalah = '{"nama": "Adi", usia: 25}';  // usia tanpa petik

if (json_validate($jsonBenar)) {
    echo "JSON 1 valid\n";
} else {
    echo "JSON 1 tidak valid\n";
}

if (json_validate($jsonSalah)) {
    echo "JSON 2 valid\n";
} else {
    echo "JSON 2 tidak valid: " . json_last_error_msg() . "\n";
}

// Cara lama vs baru
// Lama: $data = json_decode($json); if (json_last_error() === JSON_ERROR_NONE) { ... }
// Baru: if (json_validate($json)) { $data = json_decode($json); ... }

// Output: JSON 1 valid
// Output: JSON 2 tidak valid: Syntax error
?>
```

## Kasus Penggunaan Nyata
Pre-validasi sebelum parsing JSON besar, memvalidasi payload API, mengecek file konfigurasi JSON, webhook validation.
