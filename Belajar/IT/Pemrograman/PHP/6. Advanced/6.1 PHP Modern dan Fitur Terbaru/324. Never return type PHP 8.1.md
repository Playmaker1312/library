# 324. Never Return Type PHP 8.1

## Definisi Singkat
`never` adalah return type yang menandakan bahwa fungsi tidak akan pernah selesai secara normal — selalu throw exception atau exit.

## Analogi
Seperti tombol darurat yang ketika ditekan akan menghentikan seluruh sistem — tidak akan kembali ke keadaan normal.

## Poin-Poin Penting
- Fungsi dengan `never`: pasti throw exception atau exit/terminate
- Berbeda dengan `void` (fungsi selesai tanpa nilai)
- `never` adalah subtype dari semua tipe
- Berguna untuk fungsi yang selalu melempar error atau halt
- Membantu static analysis

## Contoh Kode (PHP)
```php
<?php
function hentikanAplikasi(string $pesan): never {
    echo "ERROR: $pesan\n";
    exit(1);
    // Tidak ada return — fungsi berhenti total
}

function validasiUsia(int $usia): void {
    if ($usia < 0) {
        hentikanAplikasi("Usia tidak valid");
    }
    if ($usia < 17) {
        hentikanAplikasi("Usia minimal 17 tahun");
    }
    echo "Usia valid\n";
}

// validasiUsia(-1); // Akan menghentikan program
validasiUsia(20);
// Output: Usia valid
?>
```

## Kasus Penggunaan Nyata
Helper untuk error handling fatal, routing 404 handler, redirect yang selalu exit, fungsi validasi yang throw exception fatal.
