# 330. Fitur Modern PHP Kode Ekspresif

## Definisi Singkat
Rangkuman fitur modern PHP untuk menulis kode yang lebih ekspresif, aman, dan mudah dipelihara.

## Analogi
Seperti bengkel yang punya alat modern — pekerjaan jadi lebih cepat, presisi, dan hasil lebih rapi.

## Poin-Poin Penting
- PHP 8+: Named arguments, Union types, Attributes, Match expression
- PHP 8.1+: Enums, Fibers, Readonly properties, Intersection types, Never
- PHP 8.2+: Readonly classes, DNF types, Standalone types (null/false/true)
- PHP 8.3+: Typed constants, json_validate, Dynamic constant fetch
- Kombinasikan fitur untuk kode yang lebih clean dan type-safe

## Contoh Kode (PHP)
```php
<?php
// Kombinasi fitur modern PHP untuk kode ekspresif

#[Attribute]
readonly class Route {
    public function __construct(
        public string $path,
        public string $method = 'GET'
    ) {}
}

enum Role: string {
    case Admin = 'admin';
    case User = 'user';
    case Guest = 'guest';
}

readonly class Response {
    public function __construct(
        public int $code,
        public array|string $data
    ) {}
}

function handleResponse(?Response $response): never|string {
    $response ?? throw new \InvalidArgumentException('No response');
    
    return match(true) {
        $response->code >= 500 => throw new \RuntimeException('Server error'),
        $response->code >= 400 => "Error: {$response->data}",
        default => json_encode($response->data)
    };
}

// Kode ekspresif — pendek, aman, jelas
$response = new Response(200, ['user' => 'Adi', 'role' => Role::Admin->value]);
echo handleResponse($response);
// Output: {"user":"Adi","role":"admin"}
?>
```

## Kasus Penggunaan Nyata
Pengembangan aplikasi web modern, REST API, microservices, library/framework yang memanfaatkan type safety dan expressiveness PHP terkini.
