# 321. Enums PHP 8.1

## Definisi Singkat
Enums (enumeration) adalah tipe data yang mendefinisikan sekumpulan nilai tetap yang valid.

## Analogi
Seperti tombol lift — hanya bisa memilih lantai yang tersedia, tidak bisa menekan tombol yang tidak ada.

## Poin-Poin Penting
- PHP 8.1: Pure Enums, Backed Enums, dan Unit Enum
- Pure Enum: tanpa nilai terkait
- Backed Enum: terkait dengan string/int
- Enum bisa memiliki method dan implement interface
- Membantu type safety — menggantikan konstanta kelas

## Contoh Kode (PHP)
```php
<?php
// Pure Enum
enum StatusPesanan {
    case Baru;
    case Diproses;
    case Dikirim;
    case Selesai;
    case Dibatalkan;
}

// Backed Enum (terkait string)
enum MetodePembayaran: string {
    case Transfer = 'transfer';
    case KartuKredit = 'kartu_kredit';
    case COD = 'cod';
    
    public function label(): string {
        return match($this) {
            self::Transfer => 'Transfer Bank',
            self::KartuKredit => 'Kartu Kredit',
            self::COD => 'Bayar di Tempat',
        };
    }
}

$status = StatusPesanan::Baru;
$pembayaran = MetodePembayaran::Transfer;

echo $pembayaran->value;
echo "\n";
echo $pembayaran->label();
echo "\n";
echo $status->name;
// Output: transfer
// Output: Transfer Bank
// Output: Baru
?>
```

## Kasus Penggunaan Nyata
Status workflow (pesanan, pengguna), role/permissions, tipe pembayaran, kategori terbatas, konfigurasi mode aplikasi.
