# 322. Readonly Properties PHP 8.1

## Definisi Singkat
Readonly properties adalah properti kelas yang hanya bisa diinisialisasi sekali (di dalam konstruktor atau deklarasi) dan tidak bisa diubah setelahnya.

## Analogi
Seperti tanda tangan di atas kertas — sekali ditandatangani, tidak bisa dihapus atau diganti.

## Poin-Poin Penting
- Keyword `readonly` pada properti
- Hanya bisa di-set satu kali
- Immutable setelah konstruktor selesai
- Tidak bisa memiliki nilai default (kecuali PHP 8.3+)
- Bisa dikombinasikan dengan tipe data

## Contoh Kode (PHP)
```php
<?php
class User {
    public readonly int $id;
    public readonly string $nama;
    
    public function __construct(int $id, string $nama) {
        $this->id = $id;   // Inisialisasi — diperbolehkan
        $this->nama = $nama;
    }
}

$user = new User(1, 'Adi');
echo $user->nama;
// Output: Adi

// $user->nama = 'Budi'; // Error: Cannot modify readonly property
?>
```

## Kasus Penggunaan Nyata
DTO (Data Transfer Object), event objects, value objects, konfigurasi immutable, response API yang tidak boleh diubah setelah dibuat.
