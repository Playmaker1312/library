# 320. Fibers (Concurrency) PHP 8.1

## Definisi Singkat
Fibers adalah primitif concurrency yang memungkinkan eksekusi kode secara asynchronous dengan mekanisme suspend/resume.

## Analogi
Seperti koki yang bisa menunda memasak mie (menunggu air mendidih) sambil memotong sayuran, lalu kembali lagi ke mie — tanpa perlu koki tambahan.

## Poin-Poin Penting
- Fiber bisa di-suspend (`Fiber::suspend()`) dan di-resume (`$fiber->resume()`)
- Eksekusi tetap single-thread — cooperative multitasking
- Berguna untuk I/O-bound operations
- Bisa mengelola concurrency tanpa callback hell
- Foundation untuk async frameworks seperti Amp, ReactPHP v3

## Contoh Kode (PHP)
```php
<?php
$fiber = new Fiber(function(): void {
    $nilai = Fiber::suspend('mulai');
    echo "Fiber menerima: $nilai\n";
    return 'selesai';
});

// Resume fiber dengan nilai
$hasil1 = $fiber->start();
echo "Fiber mengirim: $hasil1\n";

$hasil2 = $fiber->resume('data dari main');
echo "Hasil akhir fiber: $hasil2\n";

// Output:
// Fiber mengirim: mulai
// Fiber menerima: data dari main
// Hasil akhir fiber: selesai
?>
```

## Kasus Penggunaan Nyata
Menangani banyak koneksi HTTP concurrently, streaming data, concurrent database queries, implementasi generators tingkat lanjut.
