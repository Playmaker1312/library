# 323. Intersection Types PHP 8.1

## Definisi Singkat
Intersection types mensyaratkan sebuah nilai memenuhi semua tipe yang disebutkan (bukan salah satu).

## Analogi
Seperti karyawan yang harus merangkap jabatan — harus bisa menulis (Writer) dan juga mengelola (Manager) sekaligus.

## Poin-Poin Penting
- Ditulis dengan sintaks `TypeA&TypeB`
- Hanya bisa digunakan dengan tipe interface/class (bukan scalar)
- Berlawanan dengan union types (`|`)
- Implementasi dari multiple type constraint
- Berguna untuk memastikan object memiliki beberapa kemampuan

## Contoh Kode (PHP)
```php
<?php
interface Loggable {
    public function log(string $msg): void;
}

interface Serializable {
    public function serialize(): string;
}

class Logger implements Loggable, Serializable {
    public function log(string $msg): void {
        echo "[LOG] $msg\n";
    }
    
    public function serialize(): string {
        return json_encode(['logged' => true]);
    }
}

function prosesData(Loggable&Serializable $handler): void {
    $handler->log('Memproses data');
    echo $handler->serialize();
}

$logger = new Logger();
prosesData($logger);
// Output: [LOG] Memproses data
// Output: {"logged":true}
?>
```

## Kasus Penggunaan Nyata
Memastikan object memiliki multiple capabilities, seperti `Comparable&Sortable` untuk sorting, `Renderable&Cacheable` untuk view templating.
