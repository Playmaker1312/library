# 316. Named Arguments PHP 8

## Definisi Singkat
Named arguments memungkinkan kita melewatkan argumen ke fungsi berdasarkan nama parameter, bukan posisi.

## Analogi
Seperti mengisi formulir dengan menulis label pada setiap kolom — tidak perlu khawatir urutan kolom.

## Poin-Poin Penting
- Argumen dilewatkan dengan `nama: nilai`
- Urutan argumen tidak penting
- Bisa menggabungkan positional dan named arguments
- Named arguments tidak bisa digunakan setelah positional argument di beberapa posisi
- Membuat kode lebih self-documenting

## Contoh Kode (PHP)
```php
<?php
function buatPesanan($menu, $jumlah, $meja = 1, $catatan = '') {
    echo "Pesanan: $menu x$jumlah untuk meja $meja";
    if ($catatan) echo " (Catatan: $catatan)";
    echo "\n";
}

// Cara lama — positional
buatPesanan('Nasi Goreng', 2, 5, 'Pedas');

// Named arguments — jelas dan fleksibel
buatPesanan(menu: 'Mie Ayam', jumlah: 1, catatan: 'Tidak pakai telur', meja: 3);

// Partial — hanya argumen yang perlu diisi
buatPesanan('Soto', 2, catatan: 'Ekstra kuah');
// Output: Pesanan: Nasi Goreng x2 untuk meja 5 (Catatan: Pedas)
// Output: Pesanan: Mie Ayam x1 untuk meja 3 (Catatan: Tidak pakai telur)
// Output: Pesanan: Soto x2 untuk meja 1 (Catatan: Ekstra kuah)
?>
```

## Kasus Penggunaan Nyata
Konfigurasi fungsi dengan banyak parameter opsional, seperti query builder, HTTP client options, atau dependency injection container.
