# 319. Attributes (Annotations) PHP 8

## Definisi Singkat
Attributes adalah metadata terstruktur yang bisa ditambahkan ke kelas, method, properti, atau parameter dalam kode.

## Analogi
Seperti stiker label pada kotak penyimpanan — memberikan informasi tambahan tentang isi kotak tanpa mengubah isinya.

## Poin-Poin Penting
- Sintaks `#[AttributeName]` — native, bukan PHPDoc
- Bisa menerima argumen: `#[Route('/api', methods: ['GET'])]`
- Dibaca secara refleksi dengan `ReflectionAttribute`
- Membantu framework routing, validasi, serialisasi
- Lebih efisien daripada parsing PHPDoc annotations

## Contoh Kode (PHP)
```php
<?php
// Definisi attribute
#[Attribute]
class Route {
    public function __construct(
        public string $path,
        public array $methods = ['GET']
    ) {}
}

#[Attribute]
class Role {
    public function __construct(public string $name) {}
}

// Penggunaan attribute
#[Route('/users', ['GET', 'POST'])]
#[Role('admin')]
class UserController {
    #[Route('/users/{id}', ['GET'])]
    public function show(int $id): void {
        echo "Menampilkan user $id";
    }
}

// Refleksi membaca attribute
$ref = new ReflectionClass(UserController::class);
$attrs = $ref->getAttributes();

foreach ($attrs as $attr) {
    $instance = $attr->newInstance();
    echo get_class($instance) . ": " . json_encode($instance) . "\n";
}
// Output: Route: {"path":"\/users","methods":["GET","POST"]}
// Output: Role: {"name":"admin"}
?>
```

## Kasus Penggunaan Nyata
Mapping ORM/ODM (Entity, Column), routing web framework (Symfony, Laravel), validasi properti, event listeners.
