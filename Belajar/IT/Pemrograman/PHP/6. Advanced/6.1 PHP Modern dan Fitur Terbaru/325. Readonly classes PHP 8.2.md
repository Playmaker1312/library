# 325. Readonly Classes PHP 8.2

## Definisi Singkat
Readonly class adalah kelas di mana semua propertinya otomatis menjadi `readonly` — immutable secara keseluruhan.

## Analogi
Seperti buku cetakan — setelah dicetak, tidak ada halaman yang bisa diubah lagi.

## Poin-Poin Penting
- Keyword `readonly class` — semua properti otomatis `readonly`
- Tidak bisa memiliki properti non-readonly
- Mendukung inheritance
- Cocok untuk value objects dan DTOs
- Property promotion otomatis jadi `readonly`

## Contoh Kode (PHP)
```php
<?php
readonly class Alamat {
    public string $jalan;
    public string $kota;
    public string $kodePos;
    
    public function __construct(
        string $jalan,
        string $kota,
        string $kodePos
    ) {
        $this->jalan = $jalan;
        $this->kota = $kota;
        $this->kodePos = $kodePos;
    }
}

readonly class Pengguna {
    public function __construct(
        public int $id,
        public string $nama,
        public Alamat $alamat
    ) {}
}

$pengguna = new Pengguna(1, 'Adi', new Alamat('Jl. Merdeka', 'Jakarta', '10110'));
echo $pengguna->nama;
// $pengguna->nama = 'Budi'; // Error: Cannot modify readonly property
?>
```

## Kasus Penggunaan Nyata
Data Transfer Objects (DTOs), request/response objects, configuration objects, event objects, value objects immutable.
