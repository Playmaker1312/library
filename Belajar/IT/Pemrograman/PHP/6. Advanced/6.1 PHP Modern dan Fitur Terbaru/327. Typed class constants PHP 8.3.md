# 327. Typed Class Constants PHP 8.3

## Definisi Singkat
Typed class constants memungkinkan kita mendeklarasikan tipe data untuk konstanta kelas.

## Analogi
Seperti label pada stoples penyimpanan — Anda tahu persis isinya tanpa harus membuka stoples.

## Poin-Poin Penting
- Sintaks: `const tipe NAMA = nilai;`
- Mencegah nilai yang tidak sesuai tipe
- Mendukung inheritance
- Bisa dengan tipe scalar, array, atau object
- Membantu static analysis dan IDE

## Contoh Kode (PHP)
```php
<?php
class Konfigurasi {
    public const string APP_NAME = 'AplikasiKu';
    public const int VERSI_MAJOR = 2;
    public const int VERSI_MINOR = 1;
    public const array ROLE_ADMIN = ['admin', 'superadmin'];
    
    // Error jika tipe tidak sesuai
    // public const int NAMA = 'text'; // TypeError!
}

echo Konfigurasi::APP_NAME;
echo "\n";
echo Konfigurasi::VERSI_MAJOR . '.' . Konfigurasi::VERSI_MINOR;
echo "\n";
print_r(Konfigurasi::ROLE_ADMIN);
// Output: AplikasiKu
// Output: 2.1
// Output: Array ( [0] => admin [1] => superadmin )
?>
```

## Kasus Penggunaan Nyata
Konfigurasi aplikasi dengan tipe ketat, definisi status codes, role permissions, magic numbers yang terdokumentasi.
