# 326. DNF Types PHP 8.2

## Definisi Singkat
DNF (Disjunctive Normal Form) types memungkinkan kombinasi union dan intersection types dengan syntax yang jelas menggunakan kurung.

## Analogi
Seperti aturan "lulus jika (nilai >= 70 DAN hadir >= 80%) ATAU (nilai >= 90)" — menggabungkan AND dan OR dalam satu aturan.

## Poin-Poin Penting
- Sintaks: `(TypeA&TypeB)|TypeC`
- Union di luar, intersection di dalam kurung
- Membantu type safety yang lebih ekspresif
- Berguna untuk parameter/kembalian yang kompleks
- Hanya intersection di dalam kurung, union di luar

## Contoh Kode (PHP)
```php
<?php
interface Renderable {
    public function render(): string;
}

interface Cacheable {
    public function cacheKey(): string;
}

interface Loggable {
    public function log(): void;
}

// DNF type: harus (Renderable DAN Cacheable) ATAU Loggable
function proses((Renderable&Cacheable)|Loggable $item): void {
    if ($item instanceof Renderable && $item instanceof Cacheable) {
        echo "Cache: {$item->cacheKey()} -> {$item->render()}\n";
    } else {
        $item->log();
    }
}

class View implements Renderable, Cacheable {
    public function render(): string { return 'konten'; }
    public function cacheKey(): string { return 'view_1'; }
}

class ErrorLog implements Loggable {
    public function log(): void { echo "Logging error\n"; }
}

proses(new View());
proses(new ErrorLog());
// Output: Cache: view_1 -> konten
// Output: Logging error
?>
```

## Kasus Penggunaan Nyata
Parameter yang bisa menerima beberapa tipe composite (Serializable&Arrayable) atau alternatif sederhana (string), event handler dengan multiple constraints.
