# 317. Union Types PHP 8

## Definisi Singkat
Union types memungkinkan sebuah parameter, return type, atau properti menerima lebih dari satu tipe data.

## Analogi
Seperti colokan universal yang bisa menerima beberapa bentuk steker — fleksibel tanpa kehilangan keamanan tipe.

## Poin-Poin Penting
- Ditulis dengan sintaks `int|string` (pipe `|`)
- Menggantikan PHPDoc `@param int|string`
- Semua tipe bisa dikombinasikan kecuali `void`
- `false` bisa digunakan sebagai union (misal `int|false`)
- `null` bisa dikombinasikan dengan `?` atau `|null`

## Contoh Kode (PHP)
```php
<?php
function formatInput(int|string $data): int|string {
    if (is_numeric($data)) {
        return (int) $data;
    }
    return strtolower($data);
}

function cariUser(int $id): array|false {
    $users = [1 => 'Adi', 2 => 'Budi'];
    return $users[$id] ?? false;
}

echo formatInput('Hello');
echo "\n";
echo formatInput(42);
echo "\n";
print_r(cariUser(1));
print_r(cariUser(99));
// Output: hello
// Output: 42
// Output: Array ( [0] => Adi )
// Output: 
?>
```

## Kasus Penggunaan Nyata
Fungsi yang bisa menerima ID (int) atau slug (string), koneksi database yang mengembalikan hasil atau false, parsing input dari berbagai sumber.
