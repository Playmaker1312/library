# 318. Nullsafe Operator `?->` PHP 8

## Definisi Singkat
Nullsafe operator (`?->`) menghentikan rantai pemanggilan method/properti jika salah satu bernilai null, tanpa melempar error.

## Analogi
Seperti lampu taman otomatis — jika sensor mendeteksi gelap (null), seluruh sistem berhenti tanpa korslet.

## Poin-Poin Penting
- Sintaks `?->` mirip dengan `->` tapi aman terhadap null
- Mengembalikan `null` jika salah satu rantai bernilai null
- Tidak memanggil method/properti selanjutnya jika null ditemukan
- Hanya berfungsi untuk method chaining
- Tidak bisa digunakan sebagai penugasan (`$a?->b = $c`)

## Contoh Kode (PHP)
```php
<?php
class Alamat {
    public ?string $kota = null;
}

class Pengguna {
    public ?Alamat $alamat = null;
}

$user = new Pengguna();

// Cara lama — penuh pengecekan null
$kota = null;
if ($user !== null) {
    if ($user->alamat !== null) {
        $kota = $user->alamat->kota;
    }
}

// Nullsafe operator — satu baris bersih
$kota = $user?->alamat?->kota;

var_dump($kota);
// Output: NULL

// Jika alamat diisi
$user->alamat = new Alamat();
$user->alamat->kota = 'Jakarta';
echo $user?->alamat?->kota;
// Output: Jakarta
?>
```

## Kasus Penggunaan Nyata
Navigasi object graph kompleks seperti `$order?->getUser()?->getAddress()?->getCity()`, menghindari nested null checks.
