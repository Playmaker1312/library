# 329. Dynamic Class Constant Fetch PHP 8.3

## Definisi Singkat
Dynamic class constant fetch memungkinkan mengakses konstanta kelas secara dinamis menggunakan nama konstanta dari variabel.

## Analogi
Seperti memilih isi lemari dengan menyebutkan nama rak — bukan membuka semua rak untuk mencari.

## Poin-Poin Penting
- Sintaks: `ClassName::{$namaVariabel}`
- Sebelumnya harus pakai `constant('ClassName::NAMA')`
- Mendukung akses dinamis pada runtime
- Bisa dengan variabel nama konstanta
- Type-safe dengan typed constants (PHP 8.3+)

## Contoh Kode (PHP)
```php
<?php
class Status {
    const AKTIF = 'active';
    const NONAKTIF = 'inactive';
    const DITANGGUHKAN = 'suspended';
}

$statusList = ['AKTIF', 'NONAKTIF', 'DITANGGUHKAN'];
$key = 'AKTIF';

// Cara lama — butuh constant()
echo constant("Status::$key") . "\n";

// Dynamic class constant fetch — PHP 8.3+
echo Status::{$key} . "\n";

foreach ($statusList as $nama) {
    echo "Status $nama: " . Status::{$nama} . "\n";
}

// Output: active
// Output: active
// Output: Status AKTIF: active
// Output: Status NONAKTIF: inactive
// Output: Status DITANGGUHKAN: suspended
?>
```

## Kasus Penggunaan Nyata
Mapping status/tipe dari input dinamis, serialization/deserialization, factory pattern berbasis konstanta, dynamic configuration lookup.
