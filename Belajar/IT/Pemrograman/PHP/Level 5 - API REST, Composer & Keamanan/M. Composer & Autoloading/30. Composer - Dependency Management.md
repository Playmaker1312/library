# Composer — Dependency Management

## Penjelasan

**Composer** adalah dependency manager untuk PHP. Composer mengelola **library/packages** (kode pihak ketiga) yang digunakan project PHP Anda — mengunduh, mengupdate, dan mengatur autoloading-nya secara otomatis. Composer adalah standar industri yang digunakan oleh semua framework modern (Laravel, Symfony, CodeIgniter) dan ribuan package di Packagist.org.

Sebelum Composer, developer harus:
1. Download library manual dari website
2. Copy-paste file ke folder project
3. Include file satu per satu dengan `require_once`
4. Manual update kalau ada versi baru

Dengan Composer, cukup definisikan dependensi di `composer.json`, lalu jalankan `composer install`.

File inti Composer:

| File/Folder | Fungsi |
|-------------|--------|
| `composer.json` | Manifest — daftar dependensi project |
| `composer.lock` | Mengunci versi exact dependensi (commit ke git) |
| `vendor/` | Folder tempat semua library diunduh (jangan commit) |
| `vendor/autoload.php` | Autoloader — include file ini sekali, semua class siap pakai |

Perintah dasar Composer:

| Perintah | Fungsi |
|----------|--------|
| `composer init` | Membuat `composer.json` interaktif |
| `composer require vendor/package` | Menambah dependensi & install |
| `composer install` | Install semua dependensi dari `composer.lock` |
| `composer update` | Update ke versi terbaru sesuai constraint |
| `composer dump-autoload` | Regenerasi autoloader (setelah tambah class sendiri) |

## Fungsi

Composer mengotomatiskan seluruh siklus hidup dependency: **mendefinisikan** (composer.json), **mengunduh** (install/require), **mengunci versi** (composer.lock), dan **memuat kode** (autoloader). Composer juga menangani dependency resolution — jika Library A butuh Library B versi 2, Composer akan menginstall keduanya secara otomatis.

```php
<?php
// =====================
// 7. Contoh — Menggunakan firebase/php-jwt
// =====================
require_once __DIR__ . '/vendor/autoload.php';

use Firebase\JWT\JWT;
use Firebase\JWT\Key;

$secret = $_ENV['JWT_SECRET'] ?? 'default_secret';

// Encode
$payload = [
    'sub'      => 1,
    'username' => 'admin',
    'role'     => 'admin',
    'iat'      => time(),
    'exp'      => time() + 3600,
];
$token = JWT::encode($payload, $secret, 'HS256');
echo "Token: $token\n";

// Decode
$decoded = JWT::decode($token, new Key($secret, 'HS256'));
print_r((array) $decoded);
```

## Analogi

Composer adalah **sistem pemesanan antar-perpustakaan**. Perpustakaan (project Anda) membuat daftar buku yang dibutuhkan (composer.json) dan mengirimkannya ke pusat distribusi (Packagist.org). Pusat distribusi mengirimkan semua buku beserta buku-buku terkait yang dibutuhkan (dependencies) sekaligus — misalnya buku "PHP Modern" juga membutuhkan buku "PDO Handbook" — semuanya diantar bersama. Setiap buku punya label rak standar (PSR-4 namespace) yang memudahkan petugas menempatkannya di rak yang tepat (autoloading). Daftar kiriman (composer.lock) dicatat agar lain kali bisa mengirim buku yang sama persis. Petugas cukup buka paket (vendor/autoload.php) dan semua buku siap dipakai.

## Dipakai untuk Apa

- **Install framework** — `composer require laravel/laravel` untuk membuat project Laravel
- **Manajemen package** — phpdotenv untuk .env, phpunit untuk testing, monolog untuk logging
- **Autoloading PSR-4** — class sendiri otomatis ter-load tanpa require_once manual
- **Version constraint** — tentukan versi eksak (`1.2.3`), range (`>=1.0 <2.0`), atau wildcard (`^1.0`)
- **Script automation** — jalankan task via `composer run-script`
- **Deployment** — `composer install --no-dev` untuk production tanpa package testing

## Kesalahan Umum yang Sering Terjadi

- **Commit folder vendor**: `vendor/` harus di `.gitignore` — cukup commit `composer.json` dan `composer.lock`.
- **Lupa jalankan `composer install`**: Clone project lalu langsung jalan — error class tidak ditemukan.
- **Conflict versi**: Package A butuh Package B v2, Package C butuh Package B v3 — Composer akan error.
- **Tidak update `composer.lock`**: Setelah tambah package, `composer.lock` harus diupdate dan di-commit.
- **Salah namespace**: `use App\Models\Buku` tapi folder `src/Models/Buku.php` — autoloading tidak ketemu.
- **Lupa `require vendor/autoload.php`**: File pertama harus include autoloader — tanpa itu class tidak ter-load.
- **Menggunakan package deprecated**: Package tidak diupdate 5 tahun — cek status di Packagist.org sebelum install.

## Hubungan dengan Materi Sebelumnya

Materi 23-25 (OOP — Class, Inheritance, Interface) digunakan oleh semua package Composer — setiap package adalah kumpulan class. Materi 15-17 (Fungsi) dan autoloading adalah evolusi dari `require`/`include` manual. Materi 28-29 (REST API & JWT) bisa menggunakan package Composer seperti `firebase/php-jwt` daripada membuat JWT dari nol. Materi 26-27 (PDO) sering dikombinasikan dengan package database abstraction.

## Soal Latihan & Jawaban

### Soal

1. Buat struktur folder project perpustakaan dengan Composer: `src/Models/Anggota.php` (namespace `App\Models`) dan `public/index.php`.
2. Buat class `Anggota` dengan properti `id`, `nama`, `email` dan method `getAll(): array` yang mengembalikan data dummy.
3. Di `index.php`, gunakan autoloading Composer dan tampilkan data anggota sebagai JSON.
4. Tambahkan package `vlucas/phpdotenv` untuk membaca konfigurasi dari `.env`.

### Jawaban

```json
// composer.json
{
    "name": "perpustakaan/sistem",
    "autoload": {
        "psr-4": {
            "App\\": "src/"
        }
    },
    "require": {
        "php": ">=8.1",
        "vlucas/phpdotenv": "^5.6"
    }
}
```

```php
<?php
// src/Models/Anggota.php
namespace App\Models;

class Anggota {
    public function __construct(
        public int $id,
        public string $nama,
        public string $email
    ) {}

    public static function getAll(): array {
        return [
            new self(1, 'Siti Aminah', 'siti@email.com'),
            new self(2, 'Rudi Hartono', 'rudi@email.com'),
            new self(3, 'Dewi Lestari', 'dewi@email.com'),
        ];
    }
}
```

```php
<?php
// public/index.php
require_once __DIR__ . '/../vendor/autoload.php';

use App\Models\Anggota;
use Dotenv\Dotenv;

$dotenv = Dotenv::createImmutable(__DIR__ . '/..');
$dotenv->load();

header('Content-Type: application/json');

$anggotaList = Anggota::getAll();
$data = array_map(fn($a) => [
    'id'    => $a->id,
    'nama'  => $a->nama,
    'email' => $a->email,
], $anggotaList);

echo json_encode([
    'app_name' => $_ENV['APP_NAME'] ?? 'Perpustakaan',
    'total'    => count($data),
    'data'     => $data,
], JSON_PRETTY_PRINT);
```
