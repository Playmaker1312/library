# 404. CQRS PHP

## Definisi Singkat
CQRS (Command Query Responsibility Segregation) adalah pola yang memisahkan operasi baca (Query) dan tulis (Command) ke model dan database yang berbeda.

## Analogi
Seperti perpustakaan: ada meja peminjaman (command — ubah data) dan meja baca (query — lihat data). Prosesnya berbeda, antriannya terpisah, dan stafnya pun berbeda.

## Poin-Poin Penting
- **Command** — mengubah state (INSERT, UPDATE, DELETE) — tidak mengembalikan data
- **Query** — membaca data (SELECT) — tidak mengubah state
- Model read bisa di-denormalisasi untuk performa baca cepat
- Model write menggunakan normalisasi untuk integritas data
- Eventual consistency jika pakai database terpisah
- Sering dikombinasikan dengan Event Sourcing

## Contoh Kode
```php
<?php
// Command — menangani perubahan data
class CreateOrderCommand {
    public function __construct(
        public string $userId,
        public array $items
    ) {}
}

class CreateOrderHandler {
    public function __construct(
        private OrderRepositoryInterface $writeRepo,
        private EventDispatcherInterface $eventDispatcher
    ) {}

    public function __invoke(CreateOrderCommand $command): void {
        $order = new Order(uniqid(), $command->userId, $command->items);
        $this->writeRepo->save($order);
        $this->eventDispatcher->dispatch(new OrderCreated($order->getId()));
    }
}

// Query — hanya membaca data
class GetOrderQuery {
    public function __construct(public string $orderId) {}
}

class GetOrderHandler {
    public function __construct(
        private OrderReadModel $readRepo  // Bisa tabel denormalized terpisah
    ) {}

    public function __invoke(GetOrderQuery $query): array {
        return $this->readRepo->findById($query->orderId);
    }
}
// Output: command mengubah data, query membaca data — model terpisah
?>
```

## Kasus Penggunaan Nyata
Sistem dengan beban baca dan tulis tidak seimbang — seperti e-commerce dengan banyak lihat produk (query) tapi sedikit checkout (command), atau sistem analytics dengan banyak insert.
