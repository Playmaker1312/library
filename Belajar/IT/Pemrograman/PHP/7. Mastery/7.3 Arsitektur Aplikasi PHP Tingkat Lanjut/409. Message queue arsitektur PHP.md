# 409. Message queue arsitektur PHP

## Definisi Singkat
Message Queue adalah sistem komunikasi asynchronous antar komponen aplikasi menggunakan antrian pesan, memungkinkan decoupling antara producer (pengirim) dan consumer (penerima).

## Analogi
Seperti pos office — Anda (producer) kirim paket (message) ke kantor pos (queue), dan kurir (consumer) mengambil paket untuk diantar nanti. Anda tidak perlu menunggu paket sampai tujuan.

## Poin-Poin Penting
- **Producer** — aplikasi yang mengirim pesan (event, job)
- **Consumer** — aplikasi yang menerima dan memproses pesan
- **Queue** — buffer penyimpanan pesan (RabbitMQ, Redis, Amazon SQS, Beanstalkd)
- **Exchange** — routing pesan ke queue yang tepat (di RabbitMQ)
- **Pattern**: Pub/Sub, Work Queue, RPC, Dead Letter Queue
- Keuntungan: decoupling, scalability, fault tolerance, async processing

## Contoh Kode
```php
<?php
// Producer — mengirim pesan ke RabbitMQ
use PhpAmqpLib\Connection\AMQPStreamConnection;
use PhpAmqpLib\Message\AMQPMessage;

class OrderProducer {
    public function sendOrderCreated(string $orderJson): void {
        $connection = new AMQPStreamConnection('localhost', 5672, 'guest', 'guest');
        $channel = $connection->channel();
        $channel->queue_declare('order_created', false, true, false, false);

        $msg = new AMQPMessage($orderJson, ['delivery_mode' => AMQPMessage::DELIVERY_MODE_PERSISTENT]);
        $channel->basic_publish($msg, '', 'order_created');
        $channel->close();
        $connection->close();
    }
}

// Consumer — memproses pesan
class OrderConsumer {
    public function consume(): void {
        $connection = new AMQPStreamConnection('localhost', 5672, 'guest', 'guest');
        $channel = $connection->channel();
        $channel->queue_declare('order_created', false, true, false, false);

        $callback = function (AMQPMessage $msg) {
            $order = json_decode($msg->body, true);
            echo "Memproses order: {$order['id']}" . PHP_EOL;
            // Kirim email, update stok, dll
            $msg->ack();
        };

        $channel->basic_qos(null, 1, null);
        $channel->basic_consume('order_created', '', false, false, false, false, $callback);

        while ($channel->is_consuming()) {
            $channel->wait();
        }
    }
}
// Output: pesan dikirim dan diproses secara asynchronous
?>
```

## Kasus Penggunaan Nyata
Sistem e-commerce: saat order dibuat — kirim email, update stok, generate invoice, kirim notifikasi — semua via queue. Juga untuk log processing, video transcoding, dan data pipeline.
