# 403. Hexagonal Architecture PHP

## Definisi Singkat
Hexagonal Architecture (Ports & Adapters) adalah pola arsitektur yang memisahkan logika inti aplikasi (domain) dari infrastruktur eksternal (database, API, UI) melalui port dan adapter.

## Analogi
Seperti steker dan colokan listrik — perangkat (domain) punya colokan standar (port). Anda bisa colokkan ke listrik rumah (database MySQL) atau generator (Redis) selama pakai adapter yang sesuai.

## Poin-Poin Penting
- **Port** — interface yang mendefinisikan kontrak (input/output)
- **Adapter** — implementasi konkret port (MySQL, Redis, API)
- **Domain** di tengah (tidak bergantung pada apa pun) — pure business logic
- **Infrastructure** di luar — database, framework, web, queue
- Keuntungan: testability tinggi, framework-independent, mudah ganti teknologi

## Contoh Kode
```php
<?php
// Port (interface)
interface OrderRepositoryInterface {
    public function save(Order $order): void;
    public function findById(string $id): ?Order;
}

// Domain Service — pure business logic
class OrderService {
    public function __construct(
        private OrderRepositoryInterface $orderRepo,
        private PaymentGatewayInterface $paymentGateway
    ) {}

    public function placeOrder(array $items): Order {
        $order = new Order(uniqid(), $items);
        $this->paymentGateway->charge($order->getTotal());
        $this->orderRepo->save($order);
        return $order;
    }
}

// Adapter — implementasi MySQL
class DoctrineOrderRepository implements OrderRepositoryInterface {
    public function __construct(private EntityManagerInterface $em) {}
    public function save(Order $order): void {
        $this->em->persist($order);
        $this->em->flush();
    }
    public function findById(string $id): ?Order {
        return $this->em->find(Order::class, $id);
    }
}
// Output: domain tidak bergantung pada database atau payment gateway
?>
```

## Kasus Penggunaan Nyata
Aplikasi yang mungkin berganti database atau layanan eksternal — misalnya migrasi dari MySQL ke PostgreSQL, atau dari Stripe ke Midtrans, cukup ganti adapter tanpa sentuh domain.
