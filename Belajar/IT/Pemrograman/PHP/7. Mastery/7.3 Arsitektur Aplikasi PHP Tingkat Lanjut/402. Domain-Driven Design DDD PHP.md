# 402. Domain-Driven Design DDD PHP

## Definisi Singkat
Domain-Driven Design (DDD) adalah pendekatan pengembangan perangkat lunak yang fokus pada pemodelan domain bisnis (business logic) dengan bahasa yang sama antara developer dan stakeholder (Ubiquitous Language).

## Analogi
Seperti arsitek dan pemilik rumah yang menggunakan gambar, istilah, dan denah yang sama — tidak ada istilah teknis yang membingungkan. Semua paham arti "ruang tamu", "dapur", dan "kamar tidur" dengan cara yang sama.

## Poin-Poin Penting
- **Entity** — objek dengan identitas unik (User, Order)
- **Value Object** — objek tanpa identitas, hanya nilai (Address, Money)
- **Aggregate** — grup entitas yang diperlakukan sebagai satu unit (Order + OrderItems)
- **Repository** — abstraksi penyimpanan data (interface, implementasi di infrastructure)
- **Domain Service** — logika bisnis yang tidak cocok di entity atau value object
- **Ubiquitous Language** — bahasa bersama antara tim teknis dan bisnis

## Contoh Kode
```php
<?php
// Domain/Entity/Order.php
class Order {
    private string $id;
    private array $items = [];
    private OrderStatus $status;

    public function addItem(OrderItem $item): void {
        $this->items[] = $item;
    }

    public function getTotal(): Money {
        $total = array_reduce($this->items, fn($carry, $item) =>
            $carry + $item->getSubtotal()->getAmount(), 0
        );
        return new Money($total, 'IDR');
    }

    public function place(): void {
        if ($this->status !== OrderStatus::DRAFT) {
            throw new \DomainException('Hanya pesanan draft yang bisa diproses');
        }
        $this->status = OrderStatus::PLACED;
    }
}

// Domain/ValueObject/Money.php
class Money {
    public function __construct(
        private float $amount,
        private string $currency
    ) {}
    public function getAmount(): float { return $this->amount; }
    public function getCurrency(): string { return $this->currency; }
}
// Output: domain model yang merepresentasikan bisnis order
?>
```

## Kasus Penggunaan Nyata
Aplikasi bisnis kompleks seperti sistem perbankan, ERP, manajemen rumah sakit, atau platform asuransi — di mana logika bisnis sangat kaya dan perlu di-modelkan dengan presisi.
