# 398. Symfony Form Component

## Definisi Singkat
Symfony Form Component adalah library untuk membuat, merender, dan memvalidasi form HTML dengan pendekatan object-oriented, memisahkan logika form dari tampilan.

## Analogi
Seperti mesin isi formulir otomatis — Anda tentukan field apa saja yang diperlukan (nama, email, password), dan mesin membuat form HTML, memvalidasi input, serta menyimpan data secara otomatis.

## Poin-Poin Penting
- Form class dibuat dengan `php bin/console make:form`
- Type field: TextType, EmailType, PasswordType, ChoiceType, DateType, EntityType
- Validasi via constraints di entity atau form (NotBlank, Email, Length, dll)
- Form terikat (bind) ke entity untuk update data otomatis
- Rendering di Twig: `{{ form_start(form) }}`, `{{ form_row(form.name) }}`

## Contoh Kode
```php
<?php
// src/Form/ProductType.php
class ProductType extends AbstractType {
    public function buildForm(FormBuilderInterface $builder, array $options): void {
        $builder
            ->add('name', TextType::class, ['label' => 'Nama Produk'])
            ->add('price', MoneyType::class, [
                'currency' => 'IDR',
                'label' => 'Harga'
            ])
            ->add('category', EntityType::class, [
                'class' => Category::class,
                'choice_label' => 'name',
            ])
            ->add('submit', SubmitType::class, ['label' => 'Simpan']);
    }
}

// Controller
class ProductController extends AbstractController {
    #[Route('/product/new', name: 'product_new')]
    public function new(Request $request, EntityManagerInterface $em): Response {
        $product = new Product();
        $form = $this->createForm(ProductType::class, $product);
        $form->handleRequest($request);

        if ($form->isSubmitted() && $form->isValid()) {
            $em->persist($product);
            $em->flush();
            return $this->redirectToRoute('product_index');
        }

        return $this->render('product/new.html.twig', ['form' => $form]);
    }
}
// Output: form HTML dengan validasi, tersimpan jika valid
?>
```

## Kasus Penggunaan Nyata
Form input data kompleks seperti registrasi user multi-step, form produk dengan relasi kategori, form checkout dengan alamat pengiriman, dan form admin CRUD.
