# 400. API Platform Symfony

## Definisi Singkat
API Platform adalah framework REST/GraphQL API berbasis Symfony yang secara otomatis men-generate endpoint API dari entity Doctrine, lengkap dengan dokumentasi (OpenAPI/Swagger) dan admin panel React.

## Analogi
Seperti mesin ATM — Anda masukkan entity (kartu), mesin otomatis menyediakan semua layanan (transaksi API), struk (response JSON), dan layar (Swagger UI) tanpa perlu coding manual.

## Poin-Poin Penting
- Instalasi: `composer require api`
- Cukup beri attribute `#[ApiResource]` pada entity untuk mendapatkan CRUD API
- Otomatis menghasilkan endpoint: GET, POST, PUT, DELETE, collection, item
- Dokumentasi Swagger/OpenAPI otomatis di `/api/docs`
- Dukungan filter, sorting, pagination, validation, dan serialization context

## Contoh Kode
```php
<?php
// src/Entity/Book.php
#[ApiResource(
    operations: [
        new Get(),
        new GetCollection(),
        new Post(security: "is_granted('ROLE_ADMIN')"),
        new Put(security: "is_granted('ROLE_ADMIN')"),
        new Delete(security: "is_granted('ROLE_ADMIN')"),
    ],
    normalizationContext: ['groups' => ['book:read']],
    denormalizationContext: ['groups' => ['book:write']]
)]
#[Entity(repositoryClass: BookRepository::class)]
class Book {
    #[Id, Column, GeneratedValue]
    private ?int $id = null;

    #[Column, Groups(['book:read', 'book:write'])]
    public string $title;

    #[Column, Groups(['book:read'])]
    public string $author;

    #[Column(type: 'decimal'), Groups(['book:read', 'book:write'])]
    public float $price;
}
// Output: API otomatis dengan dokumentasi di /api/docs
// GET /api/books/1 -> {"id":1,"title":"HP","author":"Rowling","price":150000}
?>
```

## Kasus Penggunaan Nyata
Membangun REST API dengan cepat — cocok untuk backend aplikasi mobile, SPA (React/Vue), API publik, dan mikroservice dengan dokumentasi terintegrasi.
