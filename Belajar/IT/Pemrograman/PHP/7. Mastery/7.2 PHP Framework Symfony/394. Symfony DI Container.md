# 394. Symfony DI Container

## Definisi Singkat
Dependency Injection Container (DIC) di Symfony adalah service container yang mengelola pembuatan dan injeksi dependency antar class secara otomatis.

## Analogi
Seperti waiter di restoran — Anda tidak perlu pergi ke dapur ambil piring, masak makanan, atau cari gelas. Cukup pesan (minta service), waiter urus semuanya (container menyediakan dependency).

## Poin-Poin Penting
- Service didefinisikan di `config/services.yaml`
- Autowiring: Symfony otomatis menyelesaikan dependency berdasarkan type-hint
- Service memiliki ID, class, dan bisa memiliki tag, alias, atau parameter
- `$container->get(ServiceInterface::class)` atau inject via constructor
- Service default: `private`, hanya bisa diakses via controller atau service lain

## Contoh Kode
```php
<?php
// config/services.yaml
services:
    App\Service\PaymentGateway:
        arguments:
            $apiKey: '%env(STRIPE_KEY)%'
            $httpClient: '@App\Service\HttpClient'

    App\Service\OrderService:
        autowire: true  // Otomatis inject dependency

// Controller — DI via constructor
class OrderController extends AbstractController {
    public function __construct(
        private OrderService $orderService,
        private PaymentGateway $paymentGateway
    ) {}

    #[Route('/order/create', name: 'order_create')]
    public function create(): Response {
        $this->paymentGateway->charge(100);
        // ...
    }
}
// Output: service siap pakai tanpa instantiasi manual
?>
```

## Kasus Penggunaan Nyata
Mengelola service-layer aplikasi seperti mailer, logger, payment gateway, dan repository — semua dependency diatur container, kode lebih bersih dan testable.
