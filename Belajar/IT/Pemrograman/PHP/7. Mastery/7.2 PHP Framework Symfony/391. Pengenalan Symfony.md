# 391. Pengenalan Symfony

## Definisi Singkat
Symfony adalah framework PHP enterprise-grade yang terkenal dengan arsitektur modular, reusable components, dan standar industri tinggi. Dikembangkan oleh SensioLabs sejak 2005.

## Analogi
Seperti kotak peralatan konstruksi profesional — bukan rumah jadi, melainkan alat-alat terbaik untuk membangun gedung pencakar langit dengan standar tertinggi.

## Poin-Poin Penting
- Framework berbasis komponen (60+ komponen reusable)
- Arsitektur Bundle — setiap fitur adalah bundle yang bisa dipasang/dilepas
- Mengikuti standar PSR dan praktik terbaik PHP modern
- Digunakan oleh proyek besar: Drupal, Magento, Sylius, API Platform
- Mendukung lingkungan enterprise: robust, testable, maintainable

## Contoh Kode
```php
<?php
// Minimal route di config/routes.yaml
index:
    path: /
    controller: App\Controller\HomeController::index
// Controller
class HomeController extends AbstractController {
    #[Route('/', name: 'home')]
    public function index(): Response {
        return $this->render('home/index.html.twig');
    }
}
// Output: menampilkan halaman home via Twig template
?>
```

## Kasus Penggunaan Nyata
Aplikasi enterprise berskala besar seperti sistem ERP, e-commerce kompleks, platform B2B, aplikasi pemerintahan, dan proyek dengan tim developer besar.
