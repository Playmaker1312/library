# 399. Symfony Security Component

## Definisi Singkat
Symfony Security Component adalah sistem keamanan yang komprehensif untuk autentikasi, otorisasi, dan proteksi akses, mendukung berbagai mekanisme login dan firewall.

## Analogi
Seperti sistem keamanan gedung bertingkat — ada pintu utama (login), kartu akses per lantai (role), kamera pengawas (logging), dan pintu darurat (logout).

## Poin-Poin Penting
- Firewall: aturan keamanan per URL pattern (misal: `/admin/*` butuh login)
- Autentikasi: form login, HTTP basic, JWT, OAuth, LDAP, API token
- Otorisasi: Voters dan Access Decision Manager
- Role hierarchy: `ROLE_ADMIN > ROLE_USER > ROLE_GUEST`
- `denyAccessUnlessGranted('ROLE_ADMIN')` di controller

## Contoh Kode
```php
<?php
// config/packages/security.yaml
security:
    firewalls:
        main:
            pattern: ^/
            form_login:
                login_path: app_login
                check_path: app_login
            logout:
                path: app_logout
            remember_me: true

    access_control:
        - { path: ^/admin, roles: ROLE_ADMIN }
        - { path: ^/profile, roles: ROLE_USER }

// Controller
class DashboardController extends AbstractController {
    #[Route('/admin', name: 'admin_dashboard')]
    public function admin(): Response {
        $this->denyAccessUnlessGranted('ROLE_ADMIN');
        return $this->render('admin/dashboard.html.twig');
    }
}

// Di Twig
{% if is_granted('ROLE_ADMIN') %}
    <a href="{{ path('admin_dashboard') }}">Admin Panel</a>
{% endif %}
// Output: akses /admin hanya untuk user dengan ROLE_ADMIN
?>
```

## Kasus Penggunaan Nyata
Aplikasi dengan multi-role (admin, editor, subscriber), API yang butuh JWT authentication, sistem SSO (Single Sign-On), dan proteksi halaman admin.
