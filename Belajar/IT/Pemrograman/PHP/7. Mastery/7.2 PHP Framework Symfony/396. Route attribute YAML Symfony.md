# 396. Route attribute YAML Symfony

## Definisi Singkat
Routing di Symfony dapat didefinisikan menggunakan PHP 8 attributes (langsung di controller) atau file YAML/XML/Annotation, memetakan URL ke controller method.

## Analogi
Seperti peta digital dengan pin lokasi — setiap alamat URL (path) ditandai dengan pin (attribute/YAML) yang menunjukkan tindakan apa yang harus dilakukan.

## Poin-Poin Penting
- Attribute: `#[Route('/path', name: 'route_name')]` langsung di method controller
- YAML: definisi route terpusat di `config/routes.yaml`
- Parameter route: `{id}`, dengan requirement `requirements: { id: '\d+' }`
- Route bisa digabung di class level dan method level
- `_controller` di YAML mengarah ke `App\Controller\NamaController::method`

## Contoh Kode
```php
<?php
// Method 1: PHP 8 Attribute (recommended)
class BlogController extends AbstractController {
    #[Route('/blog/{id}', name: 'blog_show', requirements: ['id' => '\d+'])]
    public function show(int $id): Response {
        return $this->json(['id' => $id, 'title' => 'Post ' . $id]);
    }
}

// Method 2: YAML — config/routes.yaml
blog_show:
    path: /blog/{id}
    controller: App\Controller\BlogController::show
    requirements:
        id: '\d+'
// Output: GET /blog/5 -> {"id":5,"title":"Post 5"}
?>
```

## Kasus Penggunaan Nyata
API REST dengan banyak endpoint — attributes lebih praktis karena routing dan controller dalam satu tempat, YAML cocok untuk proyek dengan routing terpusat.
