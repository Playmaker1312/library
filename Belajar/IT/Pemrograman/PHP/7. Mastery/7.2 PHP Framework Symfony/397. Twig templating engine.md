# 397. Twig templating engine

## Definisi Singkat
Twig adalah template engine modern, cepat, dan aman untuk PHP yang menjadi default di Symfony, dengan sintaks bersih, sandboxing, dan ekstensibilitas tinggi.

## Analogi
Seperti papan tulis ajaib — Anda tulis kode pendek (sintaks Twig), dan papan itu mengubahnya menjadi HTML indah secara otomatis tanpa risiko keamanan (auto-escape).

## Poin-Poin Penting
- Sintaks: `{{ variable }}` untuk output, `{% block %}`, `{% if %}`, `{% for %}` untuk logika
- Template inheritance: `{% extends 'base.html.twig' %}` dan `{% block content %}`
- Filter: `{{ name|upper }}`, `{{ price|number_format(2, ',', '.') }}`
- Fungsi: `asset()`, `path()`, `dump()`, `include()`
- Global variables: `app` (user, request, session, debug)

## Contoh Kode
```php
<?php
// templates/base.html.twig
<!DOCTYPE html>
<html>
<head><title>{% block title %}My App{% endblock %}</title></head>
<body>
    {% block content %}{% endblock %}
</body>
</html>

// templates/product/index.html.twig
{% extends 'base.html.twig' %}
{% block title %}Produk{% endblock %}
{% block content %}
    <h1>Daftar Produk</h1>
    {% for product in products %}
        <div class="card">
            <h3>{{ product.name }}</h3>
            <p>Rp {{ product.price|number_format(0, ',', '.') }}</p>
            <a href="{{ path('product_show', {id: product.id}) }}">Detail</a>
        </div>
    {% else %}
        <p>Tidak ada produk.</p>
    {% endfor %}
{% endblock %}
{# Output: halaman HTML daftar produk dengan layout base #}
?>
```

## Kasus Penggunaan Nyata
Semua tampilan di Symfony — halaman web, email template (HTML), PDF, dan bahkan JSON views — rendering aman dan konsisten dengan auto-escape bawaan.
