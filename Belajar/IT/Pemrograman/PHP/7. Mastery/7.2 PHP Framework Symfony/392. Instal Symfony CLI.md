# 392. Instal Symfony CLI

## Definisi Singkat
Symfony CLI adalah command-line tool untuk membuat, menjalankan, dan mengelola proyek Symfony dengan cepat, termasuk development web server bawaan.

## Analogi
Seperti memiliki studio mini lengkap — Anda tinggal tekan tombol, dan semua alat siap digunakan tanpa perlu konfigurasi manual.

## Poin-Poin Penting
- Download installer dari https://symfony.com/download
- Prasyarat: PHP >= 8.1, Composer, dan ekstensi PHP yang dibutuhkan
- `symfony new my-project --full` — membuat proyek baru (full stack)
- `symfony new my-project --no-interaction` — tanpa prompt interaktif
- `symfony server:start` — menjalankan development server lokal (HTTPS support)

## Contoh Kode
```php
<?php
// Terminal:
// symfony new my_app --full
// cd my_app
// symfony server:start
// Output: Symfony development server started (https://127.0.0.1:8000)

// Cek requirements
// symfony check:requirements
// Output: semua persyaratan terpenuhi
?>
```

## Kasus Penggunaan Nyata
Memulai proyek Symfony baru dalam hitungan detik — ideal untuk developer yang ingin langsung coding tanpa ribet konfigurasi server atau web server.
