# 395. Doctrine ORM Symfony

## Definisi Singkat
Doctrine ORM adalah library ORM (Object-Relational Mapping) default di Symfony yang memetakan objek PHP ke tabel database dengan pendekatan Data Mapper (bukan Active Record seperti Eloquent).

## Analogi
Seperti petugas administrasi yang memetakan data di buku catatan (PHP object) ke lemari arsip (database). Anda serahkan objek, dia urus simpan, cari, dan relasinya.

## Poin-Poin Penting
- Entity class merepresentasikan tabel database — anotasi/attribute mapping
- EntityManager: `$entityManager->persist($entity)`, `->flush()`
- Repository pattern: `$repo = $entityManager->getRepository(Product::class)`
- DQL (Doctrine Query Language) untuk query kompleks berbasis objek
- Migration Doctrine: `php bin/console make:migration` lalu `php bin/console doctrine:migrations:migrate`

## Contoh Kode
```php
<?php
// src/Entity/Product.php
#[Entity(repositoryClass: ProductRepository::class)]
#[Table(name: 'products')]
class Product {
    #[Id, Column(type: 'integer'), GeneratedValue]
    private int $id;

    #[Column(type: 'string', length: 255)]
    private string $name;

    #[Column(type: 'decimal', precision: 10, scale: 2)]
    private float $price;

    // getters and setters...
}

// Controller
class ProductController extends AbstractController {
    #[Route('/product', methods: ['POST'])]
    public function create(EntityManagerInterface $em): Response {
        $product = new Product();
        $product->setName('Laptop');
        $product->setPrice(15000000);
        $em->persist($product);
        $em->flush();
        return new Response('Produk tersimpan dengan ID: ' . $product->getId());
    }
}
// Output: "Produk tersimpan dengan ID: 1"
?>
```

## Kasus Penggunaan Nyata
Aplikasi enterprise yang membutuhkan kontrol penuh atas query dan mapping — cocok untuk sistem dengan skema database kompleks dan ribuan entitas.
