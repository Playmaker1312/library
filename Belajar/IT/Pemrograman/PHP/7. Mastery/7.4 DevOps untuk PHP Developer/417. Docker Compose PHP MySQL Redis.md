# 417. Docker Compose PHP MySQL Redis

## Definisi Singkat
Docker Compose mengatur multi-container untuk aplikasi PHP, MySQL, dan Redis dalam satu file konfigurasi, memungkinkan satu perintah untuk menjalankan seluruh stack.

## Analogi
Seperti panel kontrol untuk semua peralatan dapur — satu sentuhan (docker-compose up) menghidupkan kompor (PHP), kulkas (MySQL), dan oven (Redis) secara bersamaan dan terintegrasi.

## Poin-Poin Penting
- Service `app` — PHP-FPM dengan aplikasi
- Service `web` — Nginx sebagai reverse proxy (opsional, bisa langsung pakai PHP built-in)
- Service `db` — MySQL/MariaDB dengan volume persistent
- Service `redis` — Redis untuk cache dan session
- Network: semua service dalam satu network default
- Environment variable via `env_file` atau langsung di compose

## Contoh Kode
```php
<?php
# docker-compose.yml
version: '3.8'

services:
  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
    volumes:
      - .:/var/www/html
      - ./docker/nginx/default.conf:/etc/nginx/conf.d/default.conf
    depends_on:
      - app
    networks:
      - app-network

  app:
    build:
      context: .
      dockerfile: Dockerfile
    volumes:
      - .:/var/www/html
    environment:
      - DB_HOST=db
      - DB_DATABASE=laravel
      - DB_USERNAME=laravel
      - DB_PASSWORD=secret
      - REDIS_HOST=redis
    depends_on:
      - db
      - redis
    networks:
      - app-network

  db:
    image: mysql:8.0
    environment:
      MYSQL_DATABASE: laravel
      MYSQL_USER: laravel
      MYSQL_PASSWORD: secret
      MYSQL_ROOT_PASSWORD: rootsecret
    volumes:
      - mysql-data:/var/lib/mysql
    networks:
      - app-network

  redis:
    image: redis:alpine
    volumes:
      - redis-data:/data
    networks:
      - app-network

volumes:
  mysql-data:
  redis-data:

networks:
  app-network:
    driver: bridge
// Output: docker-compose up -d -> stack lengkap berjalan
?>
```

## Kasus Penggunaan Nyata
Environment development lokal yang identik dengan production, standarisasi tim, dan deployment ke server menggunakan stack container yang konsisten.
