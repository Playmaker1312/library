# 414. Apache konfigurasi PHP

## Definisi Singkat
Apache adalah web server populer yang memproses PHP langsung via mod_php (embedded) atau PHP-FPM, dikenal dengan file konfigurasi `.htaccess` dan kemudahan setup.

## Analogi
Seperti toko serba ada — Apache bisa melakukan semuanya sendiri (mod_php), tidak perlu kurir terpisah. Tapi kadang lebih berat karena bawa semuanya.

## Poin-Poin Penting
- `mod_php` — PHP berjalan di dalam proses Apache (lebih sederhana, lebih berat)
- PHP-FPM dengan Apache via `mod_proxy_fcgi` (lebih scalable)
- File `.htaccess` untuk konfigurasi per-direktori tanpa restart Apache
- `mod_rewrite` — penting untuk URL routing (Laravel/Symfony)
- Direktif utama: `DocumentRoot`, `DirectoryIndex`, `AllowOverride All`
- Cek module: `sudo a2enmod rewrite proxy_fcgi setenvif`

## Contoh Kode
```php
<?php
// /etc/apache2/sites-available/laravel.conf
<VirtualHost *:80>
    ServerName app.contoh.com
    DocumentRoot /var/www/laravel/public

    <Directory /var/www/laravel/public>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/laravel-error.log
    CustomLog ${APACHE_LOG_DIR}/laravel-access.log combined
</VirtualHost>

// .htaccess di public/ (otomatis dari Laravel)
<IfModule mod_rewrite.c>
    <IfModule mod_negotiation.c>
        Options -MultiViews -Indexes
    </IfModule>

    RewriteEngine On
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteRule ^ index.php [L]
</IfModule>
// Output: Apache melayani aplikasi Laravel dengan URL bersih
?>
```

## Kasus Penggunaan Nyata
Shared hosting (cPanel menggunakan Apache), aplikasi legacy yang bergantung pada `.htaccess`, dan developer yang familiar dengan ekosistem Apache.
