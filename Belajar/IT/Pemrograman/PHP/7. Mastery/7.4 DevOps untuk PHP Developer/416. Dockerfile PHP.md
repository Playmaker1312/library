# 416. Dockerfile PHP

## Definisi Singkat
Dockerfile adalah file instruksi untuk membangun Docker image aplikasi PHP yang berisi base image, instalasi ekstensi, copy file, dan konfigurasi.

## Analogi
Seperti resep masakan — Anda tentukan bahan dasar (base image: php:8.2-fpm), bumbu (ekstensi), cara memasak (perintah RUN), dan penyajian (CMD). Hasilnya selalu konsisten.

## Poin-Poin Penting
- Gunakan base image resmi: `php:8.2-fpm`, `php:8.2-apache`, atau `php:8.2-cli`
- Ekstensi: `docker-php-ext-install pdo_mysql bcmath gd intl`
- Composer: install di Dockerfile atau gunakan image `composer:latest`
- Multi-stage build: stage 1 untuk build (composer), stage 2 untuk production (lebih kecil)
- WORKDIR: set direktori kerja aplikasi
- USER: jangan jalankan container sebagai root

## Contoh Kode
```php
<?php
# Dockerfile untuk Laravel (multi-stage)
# Stage 1: Dependencies
FROM composer:latest AS composer
WORKDIR /app
COPY composer.json composer.lock ./
RUN composer install --no-dev --optimize-autoloader --no-interaction

# Stage 2: Production Image
FROM php:8.2-fpm-alpine
WORKDIR /var/www/html

# Install ekstensi PHP
RUN docker-php-ext-install pdo_mysql bcmath opcache

# Copy dari stage composer
COPY --from=composer /app/vendor ./vendor

# Copy aplikasi
COPY . .

# Set permission
RUN chown -R www-data:www-data storage bootstrap/cache && \
    chmod -R 775 storage bootstrap/cache

# PHP configuration
COPY php.ini-production /usr/local/etc/php/php.ini

EXPOSE 9000
CMD ["php-fpm"]
// Output: image siap pakai, build dengan docker build -t myapp .
?>
```

## Kasus Penggunaan Nyata
Setiap proyek PHP yang di-deploy dengan Docker — image siap di-push ke registry (Docker Hub, GitHub Container Registry) dan di-deploy ke production.
