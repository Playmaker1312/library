# 412. Deploy ke VPS Ubuntu

## Definisi Singkat
Deploy aplikasi PHP ke VPS (Virtual Private Server) Ubuntu dengan kontrol penuh atas server, instalasi stack LEMP (Linux, Nginx, MySQL, PHP) manual atau via script.

## Analogi
Seperti menyewa rumah sendiri — Anda punya kunci penuh, bisa renovasi kapan saja, atur keamanan sendiri. Lebih mahal dari kos (shared hosting) tapi fleksibel dan powerful.

## Poin-Poin Penting
- Setup awal: SSH ke server, update system, install Nginx, MySQL, PHP
- Clone repository dari Git ke `/var/www/nama-aplikasi`
- Install Composer dan dependensi: `composer install --no-dev`
- Konfigurasi Nginx (server block) untuk arahkan domain ke `public/`
- Setup database: buat database dan user MySQL, import SQL
- Set permission: `www-data` ownership pada `storage/` dan `bootstrap/cache/`
- Setup SSL via Certbot (Let's Encrypt)

## Kasus Penggunaan Nyata
Aplikasi production skala menengah-besar, aplikasi klien, SaaS, API backend — kontrol penuh server untuk optimasi dan keamanan.
