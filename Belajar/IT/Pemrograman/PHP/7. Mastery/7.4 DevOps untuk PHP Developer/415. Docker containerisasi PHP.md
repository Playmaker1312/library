# 415. Docker containerisasi PHP

## Definisi Singkat
Docker adalah platform containerization yang memungkinkan aplikasi PHP dan dependensinya (web server, database, Redis) berjalan dalam container terisolasi dan portabel.

## Analogi
Seperti kontainer kapal barang — semua barang (aplikasi, konfigurasi, dependensi) sudah dikemas rapi dalam satu kontainer (container). Bisa dipindahkan ke kapal mana pun (server mana pun) dan tetap berfungsi sama.

## Poin-Poin Penting
- **Image** — template baca-saja untuk membuat container
- **Container** — instance dari image yang berjalan
- **Dockerfile** — resep untuk build image
- **Docker Compose** — orchestrasi multi-container (PHP + MySQL + Redis)
- Volume — mekanisme persistensi data (database, file upload)
- Network — komunikasi antar container

## Contoh Kode
```php
<?php
// docker-compose.yml
version: '3.8'
services:
  app:
    build:
      context: .
      dockerfile: Dockerfile
    container_name: php-app
    ports:
      - "8080:80"
    volumes:
      - .:/var/www/html
    depends_on:
      - db
      - redis

  db:
    image: mysql:8.0
    container_name: mysql-db
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: myapp
      MYSQL_USER: user
      MYSQL_PASSWORD: password
    volumes:
      - db_data:/var/lib/mysql

  redis:
    image: redis:alpine
    container_name: redis-cache

volumes:
  db_data:
// Output: docker-compose up -d -> aplikasi berjalan di localhost:8080
?>
```

## Kasus Penggunaan Nyata
Standarisasi environment development dan production — semua developer punya environment identik, CI/CD menggunakan container yang sama, deploy ke production konsisten.
