# 413. Nginx PHP-FPM konfigurasi

## Definisi Singkat
Nginx adalah web server berperforma tinggi yang bekerja dengan PHP-FPM (FastCGI Process Manager) untuk memproses file PHP melalui protokol FastCGI.

## Analogi
Seperti satpam (Nginx) yang menerima tamu dan kurir (PHP-FPM) yang mengantar paket. Satpam sigap, kurir yang kerja berat. Satpam hanya antar ke kurir, bukan kurir sendiri.

## Poin-Poin Penting
- Nginx tidak memiliki modul PHP bawaan — harus via PHP-FPM
- PHP-FPM berjalan sebagai service terpisah di socket atau port (9000)
- `fastcgi_pass` mengarah ke socket/port PHP-FPM
- `try_files $uri $uri/ /index.php?$query_string` — entry point single
- Konfigurasi PHP-FPM: `pm.max_children`, `pm.start_servers`, `pm.max_requests`
- Gunakan `fastcgi_cache` untuk caching halaman dinamis

## Contoh Kode
```php
<?php
// /etc/nginx/sites-available/laravel
server {
    listen 80;
    server_name app.contoh.com;
    root /var/www/laravel/public;
    index index.php;

    # Gzip
    gzip on;
    gzip_types text/css application/json application/javascript text/xml;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;

        # Cache setting
        fastcgi_cache_bypass $http_pragma;
        fastcgi_cache_valid 200 60m;
    }

    # Security: block akses ke folder sensitif
    location ~ /\.(env|git) { deny all; }
    location ~ /storage/ { internal; }
}
// Output: Nginx serve static files, PHP-FPM proses file .php
?>
```

## Kasus Penggunaan Nyata
Standar industri untuk hosting aplikasi PHP/Laravel modern — hampir semua VPS dan cloud server menggunakan Nginx + PHP-FPM untuk performa maksimal.
