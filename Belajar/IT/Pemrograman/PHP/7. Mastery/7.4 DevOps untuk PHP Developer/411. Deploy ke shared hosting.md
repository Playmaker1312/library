# 411. Deploy ke shared hosting

## Definisi Singkat
Deploy aplikasi PHP ke shared hosting adalah proses memindahkan aplikasi ke server bersama (satu server dipakai banyak pengguna) dengan resource terbatas, biasanya via FTP/cPanel.

## Analogi
Seperti menyewa kamar kos — Anda dapat satu kamar (folder), berbagi fasilitas umum (CPU, RAM) dengan penghuni lain. Murah tapi ada batasan.

## Poin-Poin Penting
- Upload file via FTP/File Manager cPanel ke folder `public_html`
- Atur entry point: rename `public/index.php` jadi `index.php` di root, atau set document root
- Environment variable: set di `.env` file atau via cPanel (jika support)
- Composer dependencies: install dulu di lokal, upload folder `vendor/`
- Database: export SQL lokal, import via phpMyAdmin
- Pastikan versi PHP di hosting sesuai kebutuhan aplikasi

## Contoh Kode
```php
<?php
// Struktur di shared hosting
// public_html/
// ├── index.php          (entry point dari public/index.php)
// ├── .env
// ├── vendor/
// ├── app/
// └── ...

// .env untuk shared hosting (salin manual)
APP_ENV=production
APP_DEBUG=false
DB_HOST=localhost
DB_DATABASE=user123_db
DB_USERNAME=user123
DB_PASSWORD=rahasia

// Script deploy sederhana via FTP (contoh)
// Upload semua file kecuali folder lokal seperti node_modules, .git
// Output: aplikasi live di https://contoh.com
?>
```

## Kasus Penggunaan Nyata
Proyek kecil, landing page, portofolio, client dengan budget rendah — cocok untuk aplikasi dengan traffic rendah hingga menengah.
