# 420. Zero-downtime deployment PHP

## Definisi Singkat
Zero-downtime deployment adalah strategi deploy aplikasi tanpa mematikan server atau mengganggu pengguna yang sedang mengakses, memastikan ketersediaan 100% saat rilis.

## Analogi
Seperti mengganti ban mobil saat berjalan — tidak perlu berhenti. Ada ban cadangan (instance kedua) yang dipasang dulu, lalu beban dialihkan secara mulus.

## Poin-Poin Penting
- **Blue-Green Deployment** — dua environment identik (blue = live, green = staging). Setelah green siap, traffic dialihkan
- **Rolling Deployment** — update bertahap ke beberapa instance server
- **Load Balancer** — mengarahkan traffic ke instance yang aktif
- **Database Migration** — backward compatible, pisahkan deploy kode dan migrasi
- Queue worker restart bertahap agar tidak ada job hilang

## Contoh Kode
```php
<?php
// deployment.yaml — contoh strategi zero-downtime
// 1. Migrasi database (backward compatible)
// php artisan migrate
// — Tambah kolom nullable, hapus kolom belakangan

// 2. Build aplikasi baru
// git pull, composer install, npm build

// 3. Symlink swap (blue-green sederhana)
// Struktur folder:
// /var/www/
//   ├── release_1/    (current)
//   └── release_2/    (new)
// Setelah release_2 siap:
ln -sfn /var/www/release_2 /var/www/html
sudo service php8.2-fpm reload

// 4. Hapus kode lama
// rm -rf /var/www/release_1

// 5. Restart queue worker bertahap
php artisan queue:restart
// Worker akan restart setelah job selesai

// Pendekatan Laravel Envoyer
// Envoyer handle atomically: clone -> install -> activate (symlink swap)
// Output: deploy tanpa downtime, user tidak merasakan perubahan
?>
```

## Kasus Penggunaan Nyata
Aplikasi production dengan SLA tinggi — e-commerce saat flash sale, perbankan online, SaaS yang tidak boleh mati (24/7 service).
