# 419. Laravel Forge Ploi server management

## Definisi Singkat
Laravel Forge dan Ploi adalah layanan server management berbasis web yang mengotomatiskan provisioning server, deployment, SSL, queue worker, cron job, dan monitoring untuk aplikasi PHP/Laravel.

## Analogi
Seperti manajer properti untuk rumah Anda — mereka urus perbaikan (setup server), jadwal bersih-bersih (cron), keamanan (SSL), dan penyewaan (deploy). Anda tinggal terima laporan.

## Poin-Poin Penting
- **Laravel Forge** — dari Laravel ecosystem, integrasi erat dengan Laravel, Envoyer
- **Ploi** — alternatif lebih murah, UI sederhana, support PHP/Laravel
- Fitur: 1-click server provisioning (DigitalOcean, AWS, Linode, Vultr)
- Auto-deploy dari GitHub/GitLab/Bitbucket via webhook
- Manajemen: Nginx, PHP-FPM, MySQL, Redis, queue worker, cron, SSL (Let's Encrypt)
- Monitoring: server health, deployment history, log viewer

## Contoh Kode
```php
<?php
// Tidak ada kode PHP — dikelola via dashboard Forge/Ploi

// Contoh deployment script yang dihasilkan Forge (deploy script)
// Di edit via dashboard -> Server -> Deployment Script
cd /home/forge/example.com
git pull origin $FORGE_SITE_BRANCH

$FORGE_COMPOSER install --no-dev --no-interaction --prefer-dist

( flock -w 10 9 || exit 1
    echo 'Restarting FPM...'; sudo -S service $FORGE_PHP_FPM reload ) 9>/tmp/fpmlock

if [ -f artisan ]; then
    $FORGE_PHP artisan migrate --force
    $FORGE_PHP artisan queue:restart
fi

// Output: deploy otomatis cukup push ke GitHub
?>
```

## Kasus Penggunaan Nyata
Developer/agensi yang mengelola banyak server aplikasi Laravel — tidak perlu SSH manual, semua urusan server diurus dashboard dengan klik.
