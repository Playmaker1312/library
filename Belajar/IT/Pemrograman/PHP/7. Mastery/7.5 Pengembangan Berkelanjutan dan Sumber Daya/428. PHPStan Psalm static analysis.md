# 428. PHPStan Psalm static analysis

## Definisi Singkat
PHPStan dan Psalm adalah alat static analysis untuk PHP yang mendeteksi bug, type error, dan potensi masalah dalam kode tanpa menjalankannya (tanpa runtime).

## Analogi
Seperti detektor logam di bandara — sebelum barang masuk (kode dijalankan), diperiksa dulu apakah ada benda berbahaya (bug, type mismatch). Lebih baik ketahuan sebelum terbang (production) daripada di tengah jalan.

## Poin-Poin Penting
- **PHPStan** — fokus pada deteksi error berdasarkan type system
  - Level 0-9 (makin tinggi makin ketat)
  - `composer require --dev phpstan/phpstan`
  - `vendor/bin/phpstan analyse src/ --level 9`
- **Psalm** — static analysis dari Vimeo, fokus pada type safety dan performance
  - `composer require --dev vimeo/psalm`
  - `vendor/bin/psalm --init`, `vendor/bin/psalm`
- Keduanya bisa menemukan: null pointer, type mismatch, method tidak ada, dead code
- Integrasi dengan IDE dan CI/CD

## Contoh Kode
```php
<?php
// Contoh kode yang dideteksi PHPStan:
function getUsername(?object $user): string {
    return $user->name; // Error! $user bisa null
}

// PHPStan akan melaporkan:
// ------ -----------------------------------------------------------------
//  Line   app/Service/UserService.php
// ------ -----------------------------------------------------------------
//  10     Cannot call method getName() on object|null.
// ------ -----------------------------------------------------------------

// Perbaikan:
function getUsername(?object $user): string {
    return $user?->name ?? 'Guest';
}

// phpstan.neon config
parameters:
    level: 9
    paths:
        - src
    excludePaths:
        - vendor
// Output: deteksi bug sebelum testing, kode lebih aman
?>
```

## Kasus Penggunaan Nyata
Proyek PHP besar dengan tim banyak — mencegah bug yang tidak terdeteksi testing, menjaga kualitas kode, dan membantu developer menemukan potensi error lebih awal.
