# 426. PSR PHP Standards Recommendations

## Definisi Singkat
PSR (PHP Standards Recommendations) adalah standar pemrograman PHP yang diterbitkan oleh PHP-FIG (Framework Interoperability Group) untuk memastikan konsistensi dan interoperabilitas antar komponen/framework PHP.

## Analogi
Seperti standar colokan listrik — semua perangkat elektronik di Indonesia pakai colokan standar yang sama (PSR). Anda bisa beli kulkas dari toko mana pun, colokkan di rumah, pasti nyala.

## Poin-Poin Penting
- **PSR-1** — Basic Coding Standard (namespace, class naming, side effects)
- **PSR-4** — Autoloading Standard (namespace ke direktori mapping)
- **PSR-7** — HTTP Message Interface (Request/Response interface)
- **PSR-11** — Container Interface (Dependency injection container)
- **PSR-12** — Extended Coding Style Guide (indentasi, brace, spacing)
- PSR diadopsi oleh: Laravel, Symfony, PHPUnit, Composer, dll

## Contoh Kode
```php
<?php
// PSR-4: namespace sesuai direktori
// File: src/Service/PaymentGateway.php
namespace App\Service;

class PaymentGateway {
    // ...
}

// PSR-12: coding style
declare(strict_types=1);

namespace App\Controller;

use App\Service\PaymentGateway;
use Psr\Http\Message\ResponseInterface;

class PaymentController
{
    public function __construct(
        private PaymentGateway $gateway
    ) {}

    public function process(): ResponseInterface
    {
        // 4 spasi indentasi, brace di baris baru untuk class
        if ($this->gateway->charge()) {
            return new JsonResponse(['status' => 'success']);
        }

        return new JsonResponse(['status' => 'failed'], 400);
    }
}
// Output: kode konsisten dan interoperable dengan library lain
?>
```

## Kasus Penggunaan Nyata
Semua proyek PHP modern mengikuti standar PSR — memudahkan kolaborasi tim, integrasi library pihak ketiga, dan tool otomatis (PHP CS Fixer, PHPStan) bekerja dengan baik.
