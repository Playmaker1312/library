# 421. PHP manual php.net

## Definisi Singkat
PHP Manual adalah dokumentasi resmi PHP yang tersedia di php.net, berisi referensi lengkap tentang fungsi, fitur, dan konfigurasi PHP dengan contoh kode dan komentar dari komunitas.

## Analogi
Seperti kamus dan ensiklopedia bahasa PHP — saat Anda lupa cara pakai `array_map()` atau parameter `str_replace()`, buka manual untuk lihat definisi, parameter, return value, dan contoh.

## Poin-Poin Penting
- URL: https://www.php.net/manual/en/ (English), https://www.php.net/manual/id/ (Indonesia)
- Setiap fungsi memiliki halaman sendiri dengan signature, parameter, return value
- User Contributed Notes — komentar dari developer real, sering berisi tips dan gotchas
- Bagian utama: Language Reference, Security, Features, Function Reference, FAQ
- Tersedia offline dan via command: `php --help`, `php --rf function_name`

## Contoh Kode
```php
<?php
// Melihat dokumentasi fungsi dari command line
// php --rf str_replace
// Output:
// Function [ <internal:standard> function str_replace ] {
//   - Parameters [4] {
//     Parameter #0 [ <required> $search ]
//     Parameter #1 [ <required> $replace ]
//     Parameter #2 [ <required> $subject ]
//     Parameter #3 [ <optional> &$count ]
//   }
// }

// Contoh dari manual:
$text = "Hello World";
echo str_replace("World", "PHP", $text);
// Output: Hello PHP
?>
```

## Kasus Penggunaan Nyata
Setiap developer PHP membuka php.net setiap hari — saat lupa sintaks, mencari fungsi baru, atau debug masalah dengan membaca user contributed notes.
