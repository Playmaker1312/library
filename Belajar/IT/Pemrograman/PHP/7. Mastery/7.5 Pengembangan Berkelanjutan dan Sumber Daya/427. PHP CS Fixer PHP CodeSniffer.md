# 427. PHP CS Fixer PHP CodeSniffer

## Definisi Singkat
PHP CS Fixer dan PHP CodeSniffer adalah alat (tools) untuk memeriksa dan memperbaiki kode PHP agar sesuai dengan standar coding (PSR-12) secara otomatis.

## Analogi
Seperti proofreader dan editor otomatis untuk tulisan Anda — setelah Anda selesai coding, tools ini memeriksa: "Hei, indentasimu kacau, spasinya kelebihan, ada trailing space!" dan langsung membetulkannya.

## Poin-Poin Penting
- **PHP CS Fixer** — memperbaiki kode secara otomatis sesuai aturan
  - Instal: `composer require --dev friendsofphp/php-cs-fixer`
  - Jalankan: `php vendor/bin/php-cs-fixer fix src/`
- **PHP CodeSniffer** — memeriksa dan melaporkan pelanggaran standar
  - Instal: `composer require --dev squizlabs/php_codesniffer`
  - Periksa: `php vendor/bin/phpcs src/`; Perbaiki: `phpcbf src/`
- Konfigurasi di `.php-cs-fixer.dist.php` atau `phpcs.xml`
- Integrasi dengan IDE (VS Code, PHPStorm) untuk auto-fix on save

## Contoh Kode
```php
<?php
// .php-cs-fixer.dist.php
$finder = PhpCsFixer\Finder::create()
    ->in([__DIR__.'/src', __DIR__.'/tests'])
    ->exclude('vendor');

return (new PhpCsFixer\Config())
    ->setRules([
        '@PSR12' => true,
        'array_syntax' => ['syntax' => 'short'],
        'ordered_imports' => true,
        'no_unused_imports' => true,
        'trailing_comma_in_multiline' => true,
        'single_quote' => true,
    ])
    ->setFinder($finder);

// Sebelum CS Fixer:
$data = array("foo"=>'bar',"baz" =>2);

// Sesudah CS Fixer:
$data = ['foo' => 'bar', 'baz' => 2];
// Output: kode rapi, konsisten, sesuai standar
?>
```

## Kasus Penggunaan Nyata
Setiap proyek PHP tim — integrasi di CI/CD (GitHub Actions) untuk auto-check coding style setiap pull request, menjaga kualitas kode konsisten tanpa review manual.
