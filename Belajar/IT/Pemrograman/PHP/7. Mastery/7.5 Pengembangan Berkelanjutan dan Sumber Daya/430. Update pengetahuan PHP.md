# 430. Update pengetahuan PHP

## Definisi Singkat
Strategi dan sumber daya untuk terus memperbarui pengetahuan PHP seiring perkembangan bahasa, framework, dan praktik terbaik yang selalu berubah.

## Analogi
Seperti dokter — ilmu kedokteran terus berkembang. Dokter yang berhenti belajar akan menggunakan metode usang dan berbahaya. Developer PHP juga harus terus belajar karena PHP 5 (usang) sangat berbeda dengan PHP 8.

## Poin-Poin Penting
- **Sumber Utama**: php.net, php.watch, stitcher.io, laravel-news.com
- **YouTube**: Laravel, Symfony, PHP Channel, PHP ug, Program With Gio
- **Praktik**: baca changelog setiap rilis PHP baru, pelajari breaking changes
- **Upgrade Path**: pahami perbedaan major version (PHP 5→7→8), fitur baru, deprecation
- **Lakukan**: coba fitur baru di project kecil, refactor kode lama, ikut coding challenge
- **Buku**: "Modern PHP" (Josh Lockhart), "Laravel: Up & Running"

## Contoh Kode
```php
<?php
// Contoh: upgrade PHP 7.4 → PHP 8.0 — fitur baru
// PHP 7.4 — arrow function
$numbers = [1, 2, 3, 4, 5];
$squared = array_map(fn($n) => $n * $n, $numbers);

// PHP 8.0 — match expression (ganti switch)
$status = match ($order->status) {
    'pending' => 'Menunggu Pembayaran',
    'paid' => 'Lunas',
    'shipped' => 'Dikirim',
    'delivered' => 'Selesai',
    default => 'Tidak Diketahui'
};

// PHP 8.1 — enum
enum OrderStatus: string {
    case Pending = 'pending';
    case Paid = 'paid';
    case Shipped = 'shipped';
    case Delivered = 'delivered';
}

// PHP 8.3 — json_validate (sebelumnya harus try-catch json_decode)
if (json_validate($requestBody)) {
    $data = json_decode($requestBody, true);
}
// Output: kode lebih modern, efisien, dan aman
?>
```

## Kasus Penggunaan Nyata
Developer karir panjang yang ingin tetap relevan — upgrade skill seiring versi PHP, mengadopsi fitur baru untuk kode lebih efisien, dan mempersiapkan migrasi sebelum versi lama EOL (End of Life).
