# 422. PHP RFC Request for Comments

## Definisi Singkat
PHP RFC (Request for Comments) adalah proses formal untuk mengusulkan, mendiskusikan, dan memutuskan perubahan atau fitur baru pada bahasa PHP melalui voting oleh komunitas.

## Analogi
Seperti rapat RT (Rukun Tetangga) untuk memutuskan aturan baru — ada yang usul (RFC), dibahas bareng, lalu voting. Kalau mayoritas setuju, aturan mulai berlaku di versi PHP berikutnya.

## Poin-Poin Penting
- RFC dibuat di wiki.php.net/rfc, didiskusikan di mailing list internals@php.net
- Butuh 2/3 suara mayoritas untuk disetujui (lulus)
- Proses: Draft → Discussion → Voting → Implementation → Merge
- Fitur besar PHP yang lahir dari RFC: Named Arguments, Match Expression, JIT, Attributes
- Pelajari RFC di https://wiki.php.net/rfc dan https://php.watch

## Contoh Kode
```php
<?php
// Contoh fitur yang lahir dari RFC — PHP 8.0: Named Arguments
// RFC: https://wiki.php.net/rfc/named_params
function createUser(string $name, string $email, bool $isAdmin = false): array {
    return compact('name', 'email', 'isAdmin');
}

// Tanpa named arguments
createUser('John', 'john@example.com', true);

// Dengan named arguments (PHP 8.0+)
createUser(name: 'John', isAdmin: true, email: 'john@example.com');
// Output: ['name' => 'John', 'email' => 'john@example.com', 'isAdmin' => true]
// Urutan parameter bisa berbeda — lebih jelas dan fleksibel
?>
```

## Kasus Penggunaan Nyata
Developer mengikuti RFC untuk tahu fitur apa yang akan datang di PHP versi berikutnya, ikut voting (jika berkontribusi), dan mempersiapkan update kode.
