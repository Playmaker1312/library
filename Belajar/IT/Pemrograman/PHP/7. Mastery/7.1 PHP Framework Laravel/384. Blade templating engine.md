# 384. Blade templating engine

## Definisi Singkat
Blade adalah template engine bawaan Laravel yang memungkinkan penulisan tampilan HTML dengan sintaks PHP yang bersih, kompilasi ke kode PHP, dan mendukung komponen serta layout.

## Analogi
Seperti cetakan kue dengan pola — Anda tinggal tuang adonan (data) ke cetakan (template), dan keluar kue (halaman HTML) yang rapi dan konsisten.

## Poin-Poin Penting
- File view berekstensi `.blade.php` di folder `resources/views/`
- Sintaks: `{{ $variable }}` untuk output, `@if`, `@foreach`, `@php` untuk logika
- Layout: `@extends('layouts.app')` dan `@section('content')` / `@yield('content')`
- Komponen: `<x-alert type="error">` dengan class komponen
- Directive kustom dapat didaftarkan di `AppServiceProvider`

## Contoh Kode
```php
<?php
{{-- resources/views/produk/index.blade.php --}}
@extends('layouts.app')

@section('content')
<div class="container">
    <h1>Daftar Produk</h1>
    @forelse ($produk as $item)
        <div class="card">
            <h3>{{ $item->nama }}</h3>
            <p>Rp {{ number_format($item->harga, 0, ',', '.') }}</p>
        </div>
    @empty
        <p>Tidak ada produk.</p>
    @endforelse
</div>
@endsection
{{-- Output: halaman HTML daftar produk dengan data dinamis --}}
?>
```

## Kasus Penggunaan Nyata
Semua tampilan frontend di Laravel — halaman admin, landing page, email template, invoice PDF — semuanya menggunakan Blade untuk injeksi data dinamis.
