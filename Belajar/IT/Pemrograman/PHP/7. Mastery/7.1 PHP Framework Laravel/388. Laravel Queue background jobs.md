# 388. Laravel Queue background jobs

## Definisi Singkat
Queue (antrian) di Laravel memungkinkan tugas berat (email, upload file, proses data) dijalankan di latar belakang agar response ke user tetap cepat.

## Analogi
Seperti kasir di restoran cepat saji: Anda pesan dan bayar (response cepat), lalu pesanan masuk ke dapur (queue). Koki memasak di belakang (background job) sementara Anda duduk menunggu.

## Poin-Poin Penting
- Driver queue: database, Redis, SQS, Beanstalkd, atau sync (default)
- Job dibuat via `php artisan make:job SendWelcomeEmail`
- Dispatch: `SendWelcomeEmail::dispatch($user)` atau `dispatch(new SendWelcomeEmail($user))`
- Worker: `php artisan queue:work` untuk menjalankan job
- Job bisa memiliki: retry, delay, priority, batch, dan failed job handling

## Contoh Kode
```php
<?php
// app/Jobs/SendWelcomeEmail.php
class SendWelcomeEmail implements ShouldQueue {
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public function __construct(public User $user) {}

    public function handle(): void {
        Mail::to($this->user->email)->send(new WelcomeMail($this->user));
    }
}

// Di controller — dispatch job
public function register(Request $request) {
    $user = User::create($request->validated());
    dispatch(new SendWelcomeEmail($user)); // Background!
    return redirect('/home');
}
// Output: user langsung diarahkan, email terkirim di latar belakang
?>
```

## Kasus Penggunaan Nyata
Mengirim ribuan email notifikasi, memproses upload file besar (resize gambar, generate thumbnail), sinkronisasi data ke API eksternal, generate laporan PDF.
