# 386. Laravel Breeze Jetstream auth

## Definisi Singkat
Laravel Breeze dan Jetstream adalah starter kit yang menyediakan sistem autentikasi lengkap (login, register, forgot password, email verification) siap pakai.

## Analogi
Seperti membeli rumah yang sudah memiliki pintu, kunci, dan sistem keamanan standar — Anda tidak perlu membuatnya dari nol, tinggal ditempati.

## Poin-Poin Penting
- **Breeze** — minimalis, ringan, menggunakan Blade atau Livewire/Inertia
- **Jetstream** — lebih fitur: two-factor auth, team management, API tokens (Sanctum)
- Instalasi: `composer require laravel/breeze --dev` lalu `php artisan breeze:install`
- Menyediakan scaffolding lengkap: login, register, logout, update profile
- Keduanya bisa menggunakan Livewire (server-side) atau Inertia (SPA-like)

## Contoh Kode
```php
<?php
// Setelah instalasi Breeze, route auth otomatis tersedia
// php artisan breeze:install blade

// Cek user login di Blade
@auth
    <p>Selamat datang, {{ Auth::user()->name }}</p>
@endauth

@guest
    <p>Silakan <a href="{{ route('login') }}">login</a></p>
@endguest
// Output: menampilkan nama user jika login, atau link login jika belum
?>
```

## Kasus Penggunaan Nyata
Memulai proyek Laravel dengan sistem auth yang sudah jadi dan aman — cocok untuk MVP, aplikasi SaaS, portal member, dan dashboard admin.
