# 385. Middleware auth otorisasi

## Definisi Singkat
Middleware adalah lapisan filter yang memproses HTTP request sebelum mencapai controller, digunakan untuk autentikasi dan otorisasi akses.

## Analogi
Seperti satpam di gedung — sebelum masuk ruangan (controller), Anda harus menunjukkan kartu akses (auth). Satpam memeriksa apakah Anda punya akses ke lantai tertentu (otorisasi).

## Poin-Poin Penting
- Middleware `auth` — memastikan user sudah login
- Middleware `can:update,post` — Gate/Policy untuk otorisasi berbasis ability
- Middleware kustom dibuat dengan `php artisan make:middleware NamaMiddleware`
- Didaftarkan di `app/Http/Kernel.php` (global, route, atau group)
- Multiple middleware bisa ditumpuk pada satu route

## Contoh Kode
```php
<?php
// Di routes/web.php
Route::middleware(['auth'])->group(function () {
    Route::get('/dashboard', [DashboardController::class, 'index']);
    Route::resource('/posts', PostController::class)
        ->middleware('can:manage,post');
});

// Middleware kustom: CheckRole
class CheckRole {
    public function handle($request, Closure $next, $role) {
        if ($request->user()->role !== $role) {
            abort(403);
        }
        return $next($request);
    }
}
// Output: user tanpa role admin mendapat 403 Forbidden
?>
```

## Kasus Penggunaan Nyata
Melindungi halaman admin dari user biasa, membatasi akses fitur berdasarkan role (admin, editor, subscriber), validasi API token di REST API.
