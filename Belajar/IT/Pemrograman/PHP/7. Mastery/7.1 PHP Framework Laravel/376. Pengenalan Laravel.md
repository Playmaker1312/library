# 376. Pengenalan Laravel

## Definisi Singkat
Laravel adalah framework PHP open-source untuk pengembangan web dengan sintaks yang ekspresif, elegan, dan berbasis MVC. Dikembangkan oleh Taylor Otwell pada tahun 2011.

## Analogi
Seperti membangun rumah dengan cetakan dan alat ukur yang sudah jadi — Anda tidak perlu menuang fondasi dari nol, cukup fokus pada desain interior dan furnitur.

## Poin-Poin Penting
- Framework PHP paling populer saat ini dengan ekosistem terbesar
- Menggunakan arsitektur MVC (Model-View-Controller)
- Fitur bawaan: routing, ORM (Eloquent), Blade templating, Artisan CLI
- Memiliki sistem package manager via Composer
- Dukungan komunitas sangat besar dan dokumentasi lengkap

## Contoh Kode
```php
<?php
// Route sederhana di routes/web.php
Route::get('/', function () {
    return view('welcome');
});
// Output: menampilkan halaman welcome.blade.php
?>
```

## Kasus Penggunaan Nyata
Digunakan oleh startup hingga enterprise untuk membangun aplikasi web seperti portal berita, e-commerce, sistem ERP, SaaS platform, dan API backend.
