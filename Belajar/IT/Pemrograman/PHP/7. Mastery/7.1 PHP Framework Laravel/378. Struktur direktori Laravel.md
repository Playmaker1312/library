# 378. Struktur direktori Laravel

## Definisi Singkat
Struktur folder bawaan Laravel yang mengatur file aplikasi secara terorganisir berdasarkan fungsinya, memisahkan logika, konfigurasi, dan sumber daya.

## Analogi
Seperti lemari arsip dengan laci terpisah — laci untuk dokumen penting, laci untuk alat tulis, laci untuk cadangan. Semua punya tempat masing-masing.

## Poin-Poin Penting
- `app/` — Model, Controller, dan logika inti aplikasi
- `bootstrap/` — File bootstrap untuk framework
- `config/` — Semua file konfigurasi aplikasi
- `database/` — Migration, seeder, dan factory
- `public/` — Entry point dan aset publik (CSS, JS, gambar)
- `resources/` — View Blade, file bahasa, aset mentah (SCSS/Vite)
- `routes/` — Definisi route web, api, console, channels
- `storage/` — Log, cache, session, file upload
- `tests/` — Unit dan feature tests

## Contoh Kode
```php
<?php
// Menentukan lokasi view
// resources/views/halaman.blade.php
Route::get('/about', function () {
    return view('halaman');
});
// Output: menampilkan resources/views/halaman.blade.php
?>
```

## Kasus Penggunaan Nyata
Memudahkan developer baru memahami proyek dengan cepat karena struktur standar yang sama di semua proyek Laravel, mempercepat onboarding tim.
