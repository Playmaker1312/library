# 387. Laravel Validation

## Definisi Singkat
Sistem validasi di Laravel untuk memeriksa keabsahan data input (biasanya dari form) sebelum diproses, dengan aturan bawaan yang lengkap dan pesan error otomatis.

## Analogi
Seperti petugas imigrasi di bandara — sebelum masuk (diproses), setiap dokumen (data input) diperiksa kelengkapannya. Jika ada yang kurang, ditolak dengan alasan jelas.

## Poin-Poin Penting
- Validasi di controller via `$request->validate([...])`
- Aturan bawaan: `required`, `email`, `min:8`, `unique:users`, `confirmed`, `numeric`
- Validasi kustom bisa dibuat via `Validator::extend` atau Rule object
- Pesan error dikembalikan ke view via `$errors` (Blade)
- Form request class memisahkan logika validasi ke file terpisah

## Contoh Kode
```php
<?php
// Validasi di controller
public function store(Request $request) {
    $validated = $request->validate([
        'email' => 'required|email|unique:users,email',
        'password' => 'required|min:8|confirmed',
        'umur' => 'required|integer|min:17|max:100',
    ]);

    User::create($validated);
    return redirect()->back()->with('success', 'Registrasi berhasil');
}

// Di Blade untuk menampilkan error
@error('email')
    <p class="error">{{ $message }}</p>
@enderror
// Output: pesan error jika validasi gagal, atau data tersimpan jika lolos
?>
```

## Kasus Penggunaan Nyata
Form registrasi pengguna, input data produk, checkout pesanan, upload file — semua input dari user harus divalidasi sebelum diproses atau disimpan.
