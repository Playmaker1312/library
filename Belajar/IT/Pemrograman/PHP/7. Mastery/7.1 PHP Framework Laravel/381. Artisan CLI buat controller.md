# 381. Artisan CLI buat controller

## Definisi Singkat
Artisan adalah command-line tool bawaan Laravel yang menyediakan perintah untuk membuat file boilerplate seperti controller, model, migration, dan lainnya secara otomatis.

## Analogi
Seperti mesin cetak kue — Anda tinggal masukkan adonan (perintah), dan keluar kue jadi (file) dengan bentuk yang rapi dan siap pakai.

## Poin-Poin Penting
- `php artisan make:controller NamaController` — membuat controller baru
- `php artisan make:controller --resource` — membuat controller dengan method CRUD
- `php artisan make:model -mc` — membuat model beserta migration dan controller
- `php artisan list` — menampilkan semua perintah yang tersedia
- `php artisan make:controller --invokable` — controller dengan method tunggal

## Contoh Kode
```php
<?php
// Terminal:
// php artisan make:controller ProductController --resource
// Output: Controller created successfully.

// File yang dihasilkan: app/Http/Controllers/ProductController.php
class ProductController extends Controller {
    public function index() { /* ... */ }
    public function create() { /* ... */ }
    public function store(Request $request) { /* ... */ }
    public function show($id) { /* ... */ }
    public function edit($id) { /* ... */ }
    public function update(Request $request, $id) { /* ... */ }
    public function destroy($id) { /* ... */ }
}
?>
```

## Kasus Penggunaan Nyata
Mempercepat development dengan menghindari penulisan kode boilerplate berulang — cukup satu perintah, file controller, model, dan migration siap dalam detik.
