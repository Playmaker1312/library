# 377. Instal Laravel Composer

## Definisi Singkat
Proses instalasi Laravel menggunakan Composer, dependency manager PHP, untuk membuat proyek Laravel baru dengan semua dependensi yang dibutuhkan.

## Analogi
Seperti memesan paket makanan lengkap dari restoran — semua bahan, bumbu, dan resep sudah tersedia dalam satu paket, tinggal dimasak.

## Poin-Poin Penting
- Prasyarat: PHP >= 8.1, Composer, ekstensi PHP tertentu (BCMath, Ctype, JSON, Mbstring, OpenSSL, PDO, Tokenizer, XML)
- Gunakan perintah `composer create-project laravel/laravel nama-proyek`
- Laravel Installer juga tersedia via Composer untuk opsi lebih cepat
- Setelah instalasi, jalankan `php artisan serve` untuk development server
- Konfigurasi environment ada di file `.env`

## Contoh Kode
```php
<?php
// Perintah instalasi via terminal/CMD
// composer create-project laravel/laravel my-app
// cd my-app
// php artisan serve
// Output: Laravel development server started: http://127.0.0.1:8000
?>
```

## Kasus Penggunaan Nyata
Langkah pertama setiap proyek Laravel — baik itu aplikasi toko online, sistem manajemen konten, atau API backend untuk aplikasi mobile.
