# 382. Eloquent ORM

## Definisi Singkat
Eloquent ORM adalah Active Record implementation bawaan Laravel yang memungkinkan interaksi database dengan sintaks PHP berorientasi objek, bukan SQL mentah.

## Analogi
Seperti asisten pribadi yang mengurus semua komunikasi dengan database — Anda cukup bicara padanya (panggil method), dan dia yang urus query SQL-nya.

## Poin-Poin Penting
- Setiap Model mewakili satu tabel database
- Relasi: `hasOne`, `hasMany`, `belongsTo`, `belongsToMany`, `hasManyThrough`
- Query Builder: `User::where('active', 1)->orderBy('name')->get()`
- Eager loading: `User::with('posts.comments')->get()` untuk mencegah N+1 query
- Mutator, accessor, scope, dan event tersedia di model

## Contoh Kode
```php
<?php
// Model dengan relasi
class User extends Model {
    public function posts() {
        return $this->hasMany(Post::class);
    }
}

// Query
$activeUsers = User::where('active', true)
    ->with('posts')
    ->orderBy('name')
    ->get();

foreach ($activeUsers as $user) {
    echo $user->name . ': ' . $user->posts->count() . ' posts';
}
// Output: "John Doe: 5 posts" (tanpa menulis SQL)
?>
```

## Kasus Penggunaan Nyata
Mengambil data pengguna dengan semua relasinya (post, komentar, profile) dalam satu baris kode — digunakan di hampir setiap fitur yang melibatkan database.
