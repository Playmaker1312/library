# 390. Laravel API Resources

## Definisi Singkat
Eloquent API Resource adalah layer transformasi data yang mengubah model Eloquent menjadi response JSON yang terstruktur dan konsisten untuk API.

## Analogi
Seperti layanan kurir yang mengemas barang — Anda berikan produk (model), dan kurir mengemasnya dengan rapi dalam kotak (Resource) dengan label yang sesuai (atribut yang ditentukan).

## Poin-Poin Penting
- Resource: `php artisan make:resource UserResource`
- Collection: `php artisan make:resource UserCollection`
- Tentukan atribut yang akan ditampilkan di method `toArray()`
- Resource bisa nested: `'user' => new UserResource($this->user)`
- Conditionally: `'email' => $this->when($request->isAdmin, $this->email)`

## Contoh Kode
```php
<?php
// app/Http/Resources/UserResource.php
class UserResource extends JsonResource {
    public function toArray($request): array {
        return [
            'id' => $this->id,
            'name' => $this->name,
            'email' => $this->email,
            'avatar' => $this->avatar_url,
            'posts' => PostResource::collection($this->whenLoaded('posts')),
            'joined_at' => $this->created_at->format('Y-m-d'),
        ];
    }
}

// Di controller
public function show($id) {
    $user = User::with('posts')->findOrFail($id);
    return new UserResource($user);
}
// Output: JSON { "id": 1, "name": "John", "email": "...", "posts": [...] }
?>
```

## Kasus Penggunaan Nyata
Membangun REST API untuk aplikasi mobile atau SPA — response JSON konsisten, mudah diubah tanpa memengaruhi controller, dan bisa menyembunyikan field sensitif.
