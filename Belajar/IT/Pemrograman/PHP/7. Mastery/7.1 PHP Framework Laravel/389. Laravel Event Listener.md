# 389. Laravel Event Listener

## Definisi Singkat
Event dan Listener di Laravel adalah mekanisme untuk memisahkan logika dengan cara memicu event (kejadian) dan menanganinya di listener terpisah.

## Analogi
Seperti bel sekolah: ketika bel berbunyi (event), beberapa hal terjadi — guru berhenti mengajar, siswa keluar kelas, petugas kantin bersiap (listeners). Semua terpicu oleh satu kejadian.

## Poin-Poin Penting
- Event dibuat: `php artisan make:event UserRegistered`
- Listener dibuat: `php artisan make:listener SendVerificationEmail`
- Daftarkan event-listener di `EventServiceProvider`
- Dispatch event: `event(new UserRegistered($user))`
- Bisa subscribe ke event queue, broadcast, atau sync

## Contoh Kode
```php
<?php
// app/Events/UserRegistered.php
class UserRegistered {
    use Dispatchable, InteractsWithSockets, SerializesModels;
    public function __construct(public User $user) {}
}

// app/Listeners/SendVerificationEmail.php
class SendVerificationEmail {
    public function handle(UserRegistered $event): void {
        $event->user->sendEmailVerificationNotification();
    }
}

// EventServiceProvider
protected $listen = [
    UserRegistered::class => [
        SendVerificationEmail::class,
        LogRegistration::class,
        AwardWelcomeBonus::class,
    ],
];

// Trigger
event(new UserRegistered($user));
// Output: email verifikasi terkirim, log tercatat, bonus diberikan
?>
```

## Kasus Penggunaan Nyata
Saat user registrasi (event) — kirim email, catat log, beri bonus poin. Saat order dibuat — update stok, kirim notifikasi, generate invoice.
