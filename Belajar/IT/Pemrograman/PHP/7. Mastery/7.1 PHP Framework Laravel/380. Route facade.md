# 380. Route facade

## Definisi Singkat
Facade Route di Laravel menyediakan antarmuka statis untuk mendaftarkan route HTTP, memetakan URL ke controller atau closure.

## Analogi
Seperti papan rambu di persimpangan jalan — setiap URL (alamat) diarahkan ke tujuan tertentu (controller/view) dengan metode HTTP tertentu (GET, POST, dll).

## Poin-Poin Penting
- Mendukung metode HTTP: GET, POST, PUT, PATCH, DELETE, OPTIONS
- Route parameter: wajib `{id}`, opsional `{name?}`, regex constraint `->where('id', '[0-9]+')`
- Route name: `->name('profile')` untuk dipanggil via `route('profile')`
- Route group: `Route::prefix('admin')->group(...)` untuk grouping
- Middleware bisa ditambahkan per route atau group

## Contoh Kode
```php
<?php
// Route dengan controller
Route::get('/produk/{kategori}', [ProdukController::class, 'index'])
    ->name('produk.kategori')
    ->where('kategori', '[a-z]+');

// Route group dengan middleware
Route::middleware(['auth'])->group(function () {
    Route::resource('posts', PostController::class);
});
// Output: URL /produk/elektronik dipetakan ke ProdukController@index
?>
```

## Kasus Penggunaan Nyata
Mendefinisikan semua endpoint REST API, halaman web, dan form submission dalam aplikasi Laravel — tulang punggung navigasi aplikasi.
