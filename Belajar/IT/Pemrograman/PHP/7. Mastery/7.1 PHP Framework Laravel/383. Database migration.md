# 383. Database migration

## Definisi Singkat
Migration adalah version control untuk database — file PHP yang mendefinisikan perubahan skema database (tabel, kolom, index) dan dapat di-rollback.

## Analogi
Seperti catatan revisi dokumen — Anda bisa melihat siapa mengubah apa, kapan, dan bisa kembali ke versi sebelumnya kapan saja.

## Poin-Poin Penting
- Membuat migration: `php artisan make:migration create_users_table`
- Method `up()` untuk menjalankan perubahan, `down()` untuk rollback
- `php artisan migrate` menjalankan semua migration yang belum dijalankan
- `php artisan migrate:rollback` mengembalikan perubahan terakhir
- `php artisan migrate:fresh` menghapus semua tabel lalu migrasi ulang

## Contoh Kode
```php
<?php
// database/migrations/xxxx_create_produk_table.php
class CreateProdukTable extends Migration {
    public function up() {
        Schema::create('produk', function (Blueprint $table) {
            $table->id();
            $table->string('nama', 100);
            $table->text('deskripsi')->nullable();
            $table->decimal('harga', 10, 2);
            $table->integer('stok')->default(0);
            $table->timestamps();
        });
    }

    public function down() {
        Schema::dropIfExists('produk');
    }
}
// Output: tabel produk dibuat dengan kolom yang ditentukan
?>
```

## Kasus Penggunaan Nyata
Tim developer bisa bekerja bersama tanpa konflik skema database — cukup jalankan `php artisan migrate` setelah pull dari git, database selalu sinkron.
