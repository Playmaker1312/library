# 379. MVC di Laravel

## Definisi Singkat
MVC (Model-View-Controller) adalah pola arsitektur yang memisahkan logika aplikasi menjadi tiga komponen: Model (data), View (tampilan), dan Controller (pengatur).

## Analogi
Seperti restoran: Model adalah dapur dan resep (data), View adalah piring dan presentasi (tampilan), Controller adalah pelayan yang menerima pesanan (request) dan mengantarkannya ke dapur lalu kembali ke meja.

## Poin-Poin Penting
- **Model** — Berinteraksi dengan database via Eloquent, mendefinisikan relasi
- **View** — Template Blade yang menampilkan data ke pengguna
- **Controller** — Logika bisnis yang memproses request dan mengembalikan response
- Route menghubungkan URL ke method controller
- alur: Route → Controller → Model (ambil data) → Controller → View (tampilkan)

## Contoh Kode
```php
<?php
// Route
Route::get('/user/{id}', [UserController::class, 'show']);

// Controller
class UserController extends Controller {
    public function show($id) {
        $user = User::find($id); // Model
        return view('user.profile', compact('user')); // View
    }
}

// Model
class User extends Model {
    protected $fillable = ['name', 'email'];
}
// Output: menampilkan halaman profil user
?>
```

## Kasus Penggunaan Nyata
Setiap aplikasi Laravel menggunakan MVC — dari aplikasi blog sederhana hingga sistem ERP kompleks, menjaga kode tetap terstruktur dan mudah dipelihara.
