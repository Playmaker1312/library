# Type Casting — Konversi Tipe yang Eksplisit

## Penjelasan
Type casting adalah cara **eksplisit** (sengaja) mengubah tipe data suatu nilai di PHP. Berbeda dengan type juggling yang otomatis, type casting memberikan kontrol penuh kepada programmer. Kamu yang memutuskan nilai itu ingin dijadikan tipe apa.

Cara melakukan type casting di PHP:
- `(int)` atau `(integer)` → ke integer
- `(float)` atau `(double)` atau `(real)` → ke float
- `(string)` → ke string
- `(bool)` atau `(boolean)` → ke boolean
- `(array)` → ke array
- `(object)` → ke object
- `(unset)` → ke NULL (tidak disarankan)

Selain itu ada fungsi-fungsi konversi: `intval()`, `floatval()`, `strval()`, `boolval()`.

## Fungsi
Memberikan kepastian tipe data sebelum suatu nilai digunakan dalam operasi tertentu. Mencegah bug akibat type juggling yang tidak terduga. Berguna saat menerima input eksternal (form, API, database) yang tipenya tidak menentu.

## Cara Pengimplementasian / Code
```php
<?php
// Casting dasar
$angkaString = "120";

$angka = (int) $angkaString;      // 120 (integer)
$desimal = (float) "45.75";       // 45.75 (float)
$bool = (bool) "hello";           // true (string tidak kosong = true)
$nol = (int) "bukan angka";       // 0 (string non-numerik jadi 0)
$teks = (string) 250;             // "250" (string)

echo "Angka: $angka\n";
echo "Desimal: $desimal\n";
echo "Bool: " . ($bool ? "true" : "false") . "\n";
echo "Nol: $nol\n";
echo "Teks: $teks\n";

// Casting boolean
var_dump((bool) "0");     // false — string "0" dianggap false
var_dump((bool) "");      // false — string kosong false
var_dump((bool) 0);       // false
var_dump((bool) []);      // false — array kosong false
var_dump((bool) "false"); // true — string "false" tidak kosong!

// Dengan fungsi konversi
$nilai = "99.99";
echo intval($nilai) . "\n";   // 99
echo floatval($nilai) . "\n"; // 99.99
echo strval(500) . "\n";      // "500"

// Penting: casting tidak mengubah variabel asli
$x = "100";
$y = (int) $x;
echo "$x adalah " . gettype($x) . "\n"; // string
echo "$y adalah " . gettype($y) . "\n"; // integer
?>
```

## Analogi
Di perpustakaan, ada buku dari sumbangan yang sampulnya tertulis "Novel" tapi isinya ternyata kumpulan puisi. Petugas secara sadar menulis ulang labelnya: "Buku ini saya pindahkan ke rak Puisi (kategori: Puisi)". Itu type casting. Beda dengan type juggling (petugas yang auto-meletakkan ke rak Novel tanpa cek isi). Casting adalah keputusan sadar; juggling adalah asumsi otomatis.

## Dipakai untuk Apa
- Membersihkan input form: `(int) $_POST['jumlah']` memastikan yang diproses adalah angka
- Menyiapkan data untuk database: memastikan ID adalah integer, bukan string
- Perbandingan yang aman: cast dulu sebelum bandingkan dengan `===`
- Memformat output: ubah angka ke string untuk ditampilkan
- Validasi boolean dari berbagai sumber

## Kesalahan Umum yang Sering Terjadi
- **Menganggap `(bool) "false"` itu `false`**: String `"false"` tidak kosong, jadi hasilnya `true`. Gunakan perbandingan string jika ingin mengecek string "false".
- **Casting string non-numerik ke int hasilnya 0**: `(int) "abc"` = 0. Tanpa sadar bisa menyebabkan operasi matematika yang salah.
- **Casting float ke int menghilangkan desimal**: `(int) 99.99` = 99, bukan 100 (tidak dibulatkan, dipotong).
- **Mengubah asal variabel asli**: Casting hanya berlaku untuk ekspresi, tidak mengubah variabel asli. Gunakan variabel baru untuk menyimpan hasil cast.
- **Casting array ke string**: `(string) ['buku']` menghasilkan "Array" — error logis.

## Hubungan dengan Materi Sebelumnya
Setelah belajar type juggling (materi 7) yang otomatis, sekarang kamu belajar casting yang manual. Keduanya berjalan beriringan: juggling untuk kemudahan, casting untuk kontrol. Paham keduanya penting sebelum masuk ke operator (materi 10) dan kontrol flow, karena tipe data yang benar menentukan hasil operasi yang valid.

## Soal Latihan & Jawaban
### Soal
Di sistem perpustakaan, ada data berikut yang berasal dari form input (semua string):
- `$idBuku` = "  45  " (string dengan spasi)
- `$harga` = "Rp25000" (string dengan prefix "Rp")
- `$tersedia` = "true" (string "true")

Buat kode PHP yang:
1. Meng-cast `$idBuku` ke integer (bersihkan spasi dulu)
2. Mengambil angka dari `$harga` lalu cast ke integer (hasil: 25000)
3. Meng-cast `$tersedia` ke boolean dengan benar
4. Tampilkan semua hasil yang sudah dikonversi

### Jawaban
```php
<?php
$idBuku = "  45  ";
$harga = "Rp25000";
$tersedia = "true";

// 1. Cast id ke integer — trim dulu spasi
$id = (int) trim($idBuku);

// 2. Ambil angka dari harga — hapus "Rp", lalu cast ke int
$hargaBersih = (int) substr($harga, 2); // "25000" → 25000

// 3. Cast "true" ke boolean dengan benar
$status = $tersedia === "true" ? true : false;

// Tampilkan
echo "ID Buku: $id (tipe: " . gettype($id) . ")\n";
echo "Harga: $hargaBersih (tipe: " . gettype($hargaBersih) . ")\n";
echo "Tersedia: " . ($status ? "Ya" : "Tidak") . " (tipe: " . gettype($status) . ")\n";
?>
```
