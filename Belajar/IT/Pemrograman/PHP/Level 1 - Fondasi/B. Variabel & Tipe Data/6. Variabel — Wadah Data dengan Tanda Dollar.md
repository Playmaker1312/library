# Variabel — Wadah Data dengan Tanda Dollar

## Penjelasan
Variabel adalah "wadah" untuk menyimpan data di memori komputer. Dalam PHP, variabel:
- Diawali dengan tanda dolar (`$`)
- Diikuti nama variabel yang dimulai dengan huruf atau underscore (`_`)
- Bersifat **case-sensitive** (`$buku` berbeda dengan `$Buku`)
- Tidak perlu deklarasi tipe data (PHP adalah bahasa *dynamically typed*)
- Nilainya bisa diubah kapan saja

Aturan penamaan:
- Hanya boleh berisi huruf, angka, dan underscore
- Tidak boleh diawali angka
- Gunakan nama yang deskriptif (`$judulBuku`, bukan `$x`)
- Konvensi: camelCase (`$namaLengkap`) atau snake_case (`$nama_lengkap`)

## Fungsi
Menyimpan, membaca, dan memanipulasi data selama eksekusi program. Tanpa variabel, semua data harus ditulis secara hardcode — tidak ada fleksibilitas.

## Cara Pengimplementasian / Code
```php
<?php
// Deklarasi dan assignment
$judulBuku = "Belajar PHP untuk Pemula";
$pengarang = "Andi Programmer";
$tahunTerbit = 2025;
$tersedia = true;

// Menampilkan variabel
echo "Judul: $judulBuku" . "\n";
echo "Pengarang: $pengarang" . "\n";

// Mengubah nilai variabel
$judulBuku = "Mahir PHP dalam 30 Hari";
echo "Judul baru: $judulBuku" . "\n";

// Variabel dari variabel lain
$harga = 75000;
$diskon = 0.1;
$hargaDiskon = $harga - ($harga * $diskon);
echo "Harga setelah diskon: Rp$hargaDiskon" . "\n";

// Variable variables ($$)
$kategori = "fiksi";
$$kategori = "Novel Sejarah"; // membuat $fiksi = "Novel Sejarah"
echo $$kategori . "\n"; // "Novel Sejarah"
echo $fiksi . "\n";     // "Novel Sejarah" (sama)
?>
```

## Analogi
Variabel seperti **rak buku** di perpustakaan. Setiap rak punya label (nama variabel) dan isi (nilai). Rak `$judulBuku` bisa berisi buku "Belajar PHP", lalu isinya diganti dengan "Mahir PHP". Kamu tidak perlu memberi tahu pustakawan (PHP) jenis raknya — dia otomatis tahu cara memperlakukan isinya. Tanda `$` adalah seperti stiker "Rak: " yang menempel di setiap rak.

## Dipakai untuk Apa
- Menyimpan input pengguna (`$_POST['username']`)
- Menampung hasil kalkulasi (`$totalHarga = $qty * $harga`)
- Mengontrol alur program (`$isLogin = true`)
- Passing data antar bagian kode
- Menyimpan konfigurasi sementara (`$dbHost`, `$dbUser`)

## Kesalahan Umum yang Sering Terjadi
- **Lupa tanda `$`**: Menulis `judulBuku` tanpa `$` — PHP menganggapnya konstanta, hasilnya error atau nilai "judulBuku" (string).
- **Case-sensitive**: `$buku` dan `$Buku` adalah dua variabel berbeda.
- **Nama variabel tidak deskriptif**: `$a`, `$x`, `$data` sangat membingungkan saat kode sudah panjang.
- **Menggunakan variabel sebelum diisi**: Menyebabkan `Notice: Undefined variable`.
- **Salah sangka tentang `$$`**: Variable variables jarang dipakai dan sering bikin bingung — hindari jika tidak perlu.

## Hubungan dengan Materi Sebelumnya
Setelah tahu cara membuat file `.php` dan menggabungkannya dengan HTML (materi 3-4), sekarang kamu belajar cara menyimpan data. Variabel adalah dasar dari semua materi selanjutnya: tipe data (materi 7-8), operator (materi 10), string, array, fungsi, dan OOP semuanya membutuhkan variabel.

## Soal Latihan & Jawaban
### Soal
Seorang petugas perpustakaan ingin mencatat data buku. Buat variabel-variabel berikut lalu tampilkan dalam format kalimat:
- `$judul` = "Sejarah Nusantara"
- `$pengarang` = "Raden Pustaka"
- `$halaman` = 350
- `$tersedia` = true

Tampilkan: "Buku 'Sejarah Nusantara' karya Raden Pustaka (350 halaman) — Status: Tersedia"

### Jawaban
```php
<?php
$judul = "Sejarah Nusantara";
$pengarang = "Raden Pustaka";
$halaman = 350;
$tersedia = true;

$status = $tersedia ? "Tersedia" : "Dipinjam";
echo "Buku '$judul' karya $pengarang ($halaman halaman) — Status: $status";
?>
```
