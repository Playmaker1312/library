# File .php Pertama — Hello World yang Sesungguhnya

## Penjelasan
Setiap bahasa pemrograman memiliki tradisi "Hello World" — program pertama yang menampilkan teks ke layar. Di PHP, Hello World bisa dibuat dengan beberapa cara. Yang fundamental adalah fungsi `echo` (atau `print`) untuk mengeluarkan teks. Teks bisa berupa string literal atau hasil dari ekspresi PHP.

File `.php` bisa berisi HTML murni, kode PHP murni, atau campuran keduanya. Kode PHP harus diapit oleh tag `<?php ... ?>`. Jika file hanya berisi kode PHP (tanpa HTML), tag penutup `?>` bisa dihilangkan untuk mencegah spasi atau baris baru tidak sengaja ikut terkirim ke output.

## Fungsi
Sebagai program pertama yang memvalidasi bahwa environment PHP berfungsi dengan benar. Juga sebagai pengenalan sintaks dasar PHP: tag pembuka, statement, titik koma, dan output.

## Cara Pengimplementasian / Code
### Hello World paling sederhana:
```php
<?php
echo "Hello World!";
```

### Hello World dengan variabel:
```php
<?php
$pesan = "Hello World!";
echo $pesan;
```

### Hello World dengan campuran HTML:
```php
<?php $title = "Hello World"; ?>
<!DOCTYPE html>
<html>
<head>
    <title><?php echo $title; ?></title>
</head>
<body>
    <h1><?php echo $title; ?></h1>
    <p>Ini file .php pertamaku!</p>
</body>
</html>
```

### Multiple echo dan print:
```php
<?php
echo "Halo ";
echo "Dunia";
print " — salam kenal!";
```

## Analogi
Perpustakaan kecil pertama yang kamu dirikan. Kamu baru punya satu rak (file `index.php`), satu buku (string "Hello World"), dan satu petugas (`echo`). Petugas mengambil buku dari rak dan menunjukkannya ke pengunjung (browser). Ini sederhana, tanpanya tidak akan ada koleksi lain.

## Dipakai untuk Apa
- Memverifikasi bahwa server dan interpreter PHP jalan
- Memastikan folder project terhubung dengan benar (via `http://localhost/...`)
- Template paling dasar untuk halaman web dinamis

## Kesalahan Umum yang Sering Terjadi
- **Lupa titik koma `;`**: Setiap statement PHP harus diakhiri `;`. Jika lupa, muncul error `Parse error: syntax error`.
- **Lupa tanda `$`** pada nama variabel: PHP akan menganggapnya sebagai konstanta, bukan variabel.
- **Menulis tag `<?php` dengan huruf besar atau typo**: Harus `<?php`, bukan `<?Php` atau `<?PHP` (case-sensitive).
- **Spasi setelah `?>`** pada file PHP murni: Jika file hanya berisi PHP dan ditutup dengan `?>`, satu spasi atau baris baru setelahnya bisa menyebabkan error "headers already sent" saat menggunakan header redirect atau session.

## Hubungan dengan Materi Sebelumnya
Di materi 1 dan 2, kamu sudah tahu bahwa PHP butuh server dan kamu sudah punya server lokal. Sekarang kamu benar-benar menulis dan menjalankan file PHP untuk pertama kali. File `.php` ini akan menjadi "wadah" untuk semua eksperimen berikutnya.

## Soal Latihan & Jawaban
### Soal
Buat file `perpustakaan.php` di folder project. File tersebut harus menampilkan:
- Judul "Katalog Perpustakaan Digital"
- Nama perpustakaan "Perpustakaan Ilmu"
- Tahun berdiri "2025"

Semua data disimpan dalam variabel terpisah. Gunakan campuran HTML dan PHP.

### Jawaban
```php
<?php
$judul = "Katalog Perpustakaan Digital";
$namaPerpus = "Perpustakaan Ilmu";
$tahunBerdiri = "2025";
?>
<!DOCTYPE html>
<html>
<head>
    <title><?php echo $judul; ?></title>
</head>
<body>
    <h1><?php echo $namaPerpus; ?></h1>
    <p>Berdiri sejak <?php echo $tahunBerdiri; ?></p>
</body>
</html>
```
