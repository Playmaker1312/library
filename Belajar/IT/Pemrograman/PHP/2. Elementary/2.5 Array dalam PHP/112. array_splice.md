# 112. array_splice

## Definisi Singkat
`array_splice()` menghapus atau mengganti sebagian array dengan elemen lain, **dan memodifikasi array asli**. Mengembalikan array yang dihapus.

## Analogi
Seperti operasi transplantasi tanaman: Anda cabut beberapa tanaman (hapus), lalu tanam tanaman baru di tempat yang sama (ganti). Kebun asli berubah.

## Poin-Poin Penting
- `array_splice(array &$array, int $offset, ?int $length = null, mixed $replacement = []): array`
- Array asli dimodifikasi — elemen dihapus/diganti.
- Jika `$length` tidak diberikan, hapus dari offset sampai akhir.
- Jika `$replacement` diberikan, elemen baru disisipkan di posisi offset.
- Jumlah replacement tidak harus sama dengan jumlah yang dihapus.
- Key numerik direset, key string dipertahankan.

## Contoh Kode (PHP)
```php
<?php
$buah = ["apel", "mangga", "jeruk", "durian"];

// Hapus 2 elemen dari index 1
$removed = array_splice($buah, 1, 2);
print_r($removed); // [mangga, jeruk]
print_r($buah);    // [apel, durian]

// Ganti dengan elemen baru
$buah = ["apel", "mangga", "jeruk"];
array_splice($buah, 1, 2, ["blueberry", "ceri"]);
print_r($buah);
// [apel, blueberry, ceri]

// Sisipkan di posisi 1 tanpa hapus
$buah = ["apel", "jeruk"];
array_splice($buah, 1, 0, ["mangga"]);
print_r($buah);
// [apel, mangga, jeruk]
?>
```

## Kasus Penggunaan Nyata
Mengedit urutan item dalam daftar (drag-and-drop reorder), menghapus item tertentu dari array berdasarkan posisi, atau insert data di tengah array.
