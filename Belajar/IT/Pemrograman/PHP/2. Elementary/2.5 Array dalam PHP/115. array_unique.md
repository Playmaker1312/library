# 115. array_unique

## Definisi Singkat
`array_unique()` menghapus nilai duplikat dari array. Hanya nilai pertama yang dipertahankan, key-nya tetap sesuai elemen pertama yang ditemukan.

## Analogi
Seperti panitia yang mendata peserta — jika ada yang daftar dua kali dengan nama sama, panitia hanya mencatat satu kali dan mengabaikan sisanya.

## Poin-Poin Penting
- `array_unique(array $array, int $flags = SORT_STRING): array`
- Tidak mengubah array asli — mengembalikan array baru.
- Flags: `SORT_STRING` (default), `SORT_NUMERIC`, `SORT_REGULAR`, `SORT_LOCALE_STRING`.
- `SORT_REGULAR` membandingkan normal (casting).
- Perbandingan dengan `(string)` casting di `SORT_STRING`.
- PHP 8+ — `array_unique` dengan `SORT_REGULAR` untuk objek membandingkan identity.

## Contoh Kode (PHP)
```php
<?php
$buah = ["apel", "mangga", "apel", "jeruk", "mangga"];
$unique = array_unique($buah);
print_r($unique);
// [0 => apel, 1 => mangga, 3 => jeruk]

// Dengan tipe campuran
$mixed = [1, "1", 2, "2"];
$result = array_unique($mixed, SORT_REGULAR);
print_r($result);
// [0 => 1, 2 => 2] (1 == "1" jadi dianggap sama)

$result = array_unique($mixed, SORT_STRING);
print_r($result);
// [0 => 1, 2 => 2] (juga dianggap sama)
?>
```

## Kasus Penggunaan Nyata
Membersihkan duplikat dari daftar email, menampilkan kategori unik dari produk, atau menghilangkan tag duplikat dari input user.
