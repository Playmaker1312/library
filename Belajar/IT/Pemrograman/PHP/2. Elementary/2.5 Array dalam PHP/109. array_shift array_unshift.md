# 109. array_shift array_unshift

## Definisi Singkat
`array_shift()` menghapus dan mengembalikan elemen **pertama** dari array, menggeser semua key numerik turun. `array_unshift()` menambahkan elemen di **awal** array.

## Analogi
Seperti antrian di kasir: `array_unshift` = ada orang baru yang nyerobot ke depan antrian. `array_shift` = orang paling depan dilayani dan keluar antrian, sisanya maju satu langkah.

## Poin-Poin Penting
- `array_shift(array &$array): mixed` — hapus elemen pertama, **reset semua key numerik**.
- `array_unshift(array &$array, mixed ...$values): int` — tambah elemen di awal, return jumlah baru.
- `array_shift` untuk indexed array: key direset (0, 1, 2...).
- Untuk associative array, key string tidak terpengaruh oleh `array_shift`.
- Operasi `array_shift` pada array besar bisa lambat karena harus re-index.

## Contoh Kode (PHP)
```php
<?php
$antrian = ["Andi", "Budi", "Citra"];

$dilayani = array_shift($antrian);
echo $dilayani; // Andi
print_r($antrian);
// [0 => Budi, 1 => Citra] (key direset)

array_unshift($antrian, "Dewi", "Eka");
print_r($antrian);
// [0 => Dewi, 1 => Eka, 2 => Budi, 3 => Citra]

// Associative — key string tidak berubah
$data = ["a" => 1, "b" => 2];
$first = array_shift($data); // 1
print_r($data); // [b => 2]
?>
```

## Kasus Penggunaan Nyata
Antrian FIFO (First In First Out), memproses task queue, atau mengelola prioritas pekerjaan di awal antrian.
