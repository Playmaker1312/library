# 111. array_slice

## Definisi Singkat
`array_slice()` mengambil sebagian (slice) dari array berdasarkan offset dan panjang tertentu — tanpa mengubah array asli.

## Analogi
Seperti memotong kue — Anda potong bagian tertentu (offset) sebesar ukuran tertentu (length), dan kue asli tetap utuh. Potongan itulah yang Anda dapatkan.

## Poin-Poin Penting
- `array_slice(array $array, int $offset, ?int $length = null, bool $preserve_keys = false): array`
- Jika `$offset` positif, mulai dari posisi itu dari awal.
- Jika `$offset` negatif, mulai dari posisi dari akhir array.
- Jika `$length` tidak diberikan, ambil sampai akhir.
- `$preserve_keys = true` untuk mempertahankan key asli (default false: re-index).
- Tidak mengubah array asli.

## Contoh Kode (PHP)
```php
<?php
$buah = ["apel", "mangga", "jeruk", "durian", "salak"];

print_r(array_slice($buah, 1, 2));
// [0 => mangga, 1 => jeruk]

print_r(array_slice($buah, -2, 1));
// [0 => durian] (dari akhir, offset -2)

// Preserve keys
print_r(array_slice($buah, 1, 2, true));
// [1 => mangga, 2 => jeruk]

// Ambil 3 elemen pertama
$firstThree = array_slice($buah, 0, 3);
// [apel, mangga, jeruk]
?>
```

## Kasus Penggunaan Nyata
Pagination (mengambil halaman tertentu dari hasil), preview/membatasi jumlah item yang ditampilkan, atau mengambil data dari tengah array.
