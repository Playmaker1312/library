# 102. Akses Elemen Array Index

## Definisi Singkat
Elemen array diakses menggunakan kurung siku `[]` berisi key (index). Untuk indexed array gunakan angka, untuk associative array gunakan string.

## Analogi
Seperti loker di stasiun: setiap loker punya nomor (index) atau kode (key). Masukkan kode/nomor yang benar, loker terbuka dan Anda ambil isinya.

## Poin-Poin Penting
- Akses: `$array[key]` — key bisa int atau string.
- Jika key tidak ada, menghasilkan **E_WARNING** (PHP 8+) atau notice (PHP 7.x).
- Null-safe operator? `$array[key]` — jika $array null di PHP 8+, error TypeError.
- Gunakan `isset()` atau `array_key_exists()` untuk cek sebelum akses.
- Curly brace syntax `$array{0}` terdeprekasi sejak PHP 7.4, dihapus di PHP 8+.
- Chaining: `$array[0]['name']` untuk multidimensional.

## Contoh Kode (PHP)
```php
<?php
$buah = ["apel", "mangga", "jeruk"];
echo $buah[0]; // apel
echo $buah[2]; // jeruk

$user = ["name" => "Andi", "age" => 25];
echo $user["name"]; // Andi

// Cek sebelum akses
$key = "email";
if (isset($user[$key])) {
    echo $user[$key];
} else {
    echo "Key tidak ditemukan";
}

// PHP 8+ warning jika key tidak ada
// echo $buah[10]; // WARNING: Undefined array key
?>
```

## Kasus Penggunaan Nyata
Mengambil nilai input form (`$_POST["username"]`), membaca konfigurasi dari array, atau mengakses data dari hasil query database.
