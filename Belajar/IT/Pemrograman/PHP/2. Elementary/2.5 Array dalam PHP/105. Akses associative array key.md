# 105. Akses Associative Array Key

## Definisi Singkat
Mengambil value dari associative array menggunakan key string dalam kurung siku. Key bisa juga diakses melalui variable variable atau curly braces dalam interpolasi string.

## Analogi
Seperti kamus: cari kata "rumah" (key), dapatkan definisinya (value). Tidak perlu tahu halaman berapa — langsung cari kata kuncinya.

## Poin-Poin Penting
- Akses: `$array["key"]` — key dalam tanda petik.
- Tanpa petik, PHP cari konstanta dulu (deprecated, warning di PHP 8+).
- Akses key dengan variable: `$array[$keyName]`.
- Di interpolasi string: `"{$array["key"]}"` atau `"{$array[$key]}"`.
- Null coalescing: `$array["key"] ?? "default"`.
- `array_key_exists()` vs `isset()`: `isset` false untuk nilai null.

## Contoh Kode (PHP)
```php
<?php
$user = [
    "name" => "Andi",
    "age" => 25,
    "bio" => null,
];

echo $user["name"]; // Andi

// Variable key
$key = "age";
echo $user[$key]; // 25

// Perbedaan isset vs array_key_exists
var_dump(isset($user["bio"]));              // false (null)
var_dump(array_key_exists("bio", $user));   // true (ada walau null)

// Interpolasi
echo "Nama: {$user["name"]}, Umur: {$user["age"]}";
// Nama: Andi, Umur: 25
?>
```

## Kasus Penggunaan Nyata
Mengakses data dari $_SESSION, $_POST, $_GET, membaca kolom hasil database, atau mengambil nilai konfigurasi dari array asosiatif.
