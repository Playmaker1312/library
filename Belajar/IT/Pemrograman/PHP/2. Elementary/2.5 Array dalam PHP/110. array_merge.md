# 110. array_merge

## Definisi Singkat
`array_merge()` menggabungkan dua atau lebih array menjadi satu array. Key numerik akan di-re-index, key string yang sama akan ditimpa oleh array yang lebih akhir.

## Analogi
Seperti menggabungkan dua kotak peralatan: Anda satukan semua isinya. Jika ada dua kunci inggris yang sama (key nama sama), yang terakhir ditaruh yang dipakai. Nomor urut (key numerik) diatur ulang.

## Poin-Poin Penting
- `array_merge(array ...$arrays): array`
- Key **string** yang sama: nilai terakhir menimpa sebelumnya.
- Key **numerik** (integer): tidak menimpa — semuanya ditambahkan dengan re-index.
- Jika hanya satu array, key numerik tetap di-re-index.
- Untuk menggabungkan tanpa menimpa (numerik saja), gunakan `+` operator.
- `array_merge_recursive()` untuk merge rekursif (menggabungkan array dalam array).

## Contoh Kode (PHP)
```php
<?php
$a = ["a" => "apel", "b" => "belimbing"];
$b = ["b" => "blueberry", "c" => "ceri"];
$result = array_merge($a, $b);
print_r($result);
// [a => apel, b => blueberry, c => ceri] (b ditimpa)

$num1 = [1, 2, 3];
$num2 = [4, 5];
$result = array_merge($num1, $num2);
print_r($result);
// [0 => 1, 1 => 2, 2 => 3, 3 => 4, 4 => 5]

// Operator + (tidak re-index, tidak timpa)
$result = $num1 + $num2;
print_r($result);
// [0 => 1, 1 => 2, 2 => 3] (key 3,4 tidak ada di $num1)
?>
```

## Kasus Penggunaan Nyata
Menggabungkan konfigurasi default dengan konfigurasi user, menggabungkan hasil query, atau menggabungkan data dari berbagai sumber.
