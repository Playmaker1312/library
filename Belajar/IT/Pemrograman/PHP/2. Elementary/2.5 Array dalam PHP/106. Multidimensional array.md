# 106. Multidimensional Array

## Definisi Singkat
Multidimensional array adalah array di dalam array — bisa berupa array of arrays, array of indexed arrays, atau kombinasi indexed dan associative.

## Analogi
Seperti lemari arsip: lemari (array utama) berisi beberapa laci (array kedua), setiap laci berisi folder (array ketiga). Akses dengan menyebutkan nomor lemari → laci → folder.

## Poin-Poin Penting
- Bisa memiliki kedalaman berapa pun (2D, 3D, dst).
- Sintaks: `$matrix[0][1]` — akses baris 0, kolom 1.
- Setiap level bisa indexed atau associative.
- Inisialisasi nested array dengan `[...]` di dalam `[...]`.
- Iterasi dengan nested `foreach`.
- JSON sering dipetakan ke multidimensional array (dengan `json_decode($json, true)`).

## Contoh Kode (PHP)
```php
<?php
// Array 2D indexed
$matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
];
echo $matrix[1][2]; // 6

// Array associative multidimensi
$users = [
    ["name" => "Andi", "hobbies" => ["coding", "gaming"]],
    ["name" => "Budi", "hobbies" => ["reading", "swimming"]],
];
echo $users[0]["hobbies"][1]; // gaming

// Iterasi
foreach ($matrix as $row) {
    foreach ($row as $val) {
        echo "$val ";
    }
}
// 1 2 3 4 5 6 7 8 9
?>
```

## Kasus Penggunaan Nyata
Data tabel/spreadsheet, daftar user dengan alamat, kategori produk dengan sub-kategori, atau hasil query join database.
