# 108. array_push array_pop

## Definisi Singkat
`array_push()` menambahkan satu atau lebih elemen ke **akhir** array. `array_pop()` menghapus dan mengembalikan elemen **terakhir** dari array.

## Analogi
Seperti tumpukan piring: `array_push` = menaruh piring baru di atas tumpukan (paling atas/akhir). `array_pop` = mengambil piring paling atas untuk digunakan.

## Poin-Poin Penting
- `array_push(array &$array, mixed ...$values): int` — mengembalikan jumlah elemen baru.
- `array_push($arr, $val)` sama dengan `$arr[] = $val`, tetapi `$arr[]` lebih cepat (tanpa overhead fungsi).
- `array_pop(array &$array): mixed` — mengembalikan nilai yang dihapus, atau null jika array kosong.
- Modifikasi terjadi pada array asli (pass by reference).
- Setelah `array_pop`, key array tetap dipertahankan (kecuali indexed array yang key-nya di-reset? Tidak, key tetap).

## Contoh Kode (PHP)
```php
<?php
$stack = ["apel", "mangga"];
array_push($stack, "jeruk", "durian");
print_r($stack);
// [apel, mangga, jeruk, durian]

$last = array_pop($stack);
echo $last; // durian
print_r($stack);
// [apel, mangga, jeruk]

// $arr[] lebih cepat
$arr = [];
$arr[] = "a"; // Sama dengan array_push($arr, "a")
?>
```

## Kasus Penggunaan Nyata
Mengelola stack (undo/redo), antrian LIFO, mengumpulkan data dalam loop (push), memproses dan menghapus item dari daftar (pop).
