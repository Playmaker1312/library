# 101. Indexed Array

## Definisi Singkat
Indexed array adalah array dengan key berupa **integer** (dimulai dari 0 secara default). Elemen diakses berdasarkan posisi numeriknya.

## Analogi
Seperti rak buku bernomor: rak nomor 0, rak nomor 1, rak nomor 2, dan seterusnya. Setiap rak berisi satu buku (nilai).

## Poin-Poin Penting
- Dibuat dengan `array(1, 2, 3)` atau `[1, 2, 3]` (short syntax, PHP 5.4+).
- Key otomatis dimulai dari 0 dan increment +1.
- Bisa menentukan key manual: `[0 => "a", 1 => "b"]`.
- Jika key dilewati, PHP otomatis menggunakan key terbesar +1.
- Elemen tidak harus dengan tipe data sama (campuran diperbolehkan).
- PHP 8.1+ — array negatif index diperbolehkan dan berperilaku seperti biasa.

## Contoh Kode (PHP)
```php
<?php
$buah = ["apel", "mangga", "jeruk"];
echo $buah[0]; // apel
echo $buah[2]; // jeruk

// Key manual
$numbers = [10 => "a", "b", "c"];
// Key: 10 => "a", 11 => "b", 12 => "c"

// Campuran tipe
$mixed = [1, "halo", 3.14, true];
print_r($mixed);
// [0] => 1, [1] => halo, [2] => 3.14, [3] => 1
?>
```

## Kasus Penggunaan Nyata
Menyimpan daftar item sederhana (produk di keranjang, nama user, nomor antrian), data tanpa key asosiatif, atau list yang diproses secara berurutan.
