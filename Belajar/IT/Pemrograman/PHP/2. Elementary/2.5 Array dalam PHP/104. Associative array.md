# 104. Associative Array

## Definisi Singkat
Associative array menggunakan **string** sebagai key (index), bukan integer. Setiap key terhubung ke satu nilai (value) — seperti peta (map) key → value.

## Analogi
Seperti kartu identitas: "nama" → "Andi", "usia" → 25, "kota" → "Jakarta". Setiap label (key) berisi satu informasi (value), tidak berurutan karena diakses lewat label, bukan nomor.

## Poin-Poin Penting
- Sintaks: `["key" => "value", "name" => "Andi"]`.
- Key harus string atau int; key `true` jadi `1`, `false` jadi `0`.
- Key unik — jika sama, value terakhir yang disimpan.
- Order elemen dipertahankan sesuai urutan penambahan (sejak PHP 7+).
- Bisa campuran key string dan integer dalam satu array.
- Iterasi dengan `foreach ($array as $key => $value)`.

## Contoh Kode (PHP)
```php
<?php
$user = [
    "name"     => "Andi",
    "email"    => "andi@mail.com",
    "age"      => 25,
    "is_admin" => false,
];

echo $user["name"];  // Andi
echo $user["email"]; // andi@mail.com

// Iterasi
foreach ($user as $key => $value) {
    echo "$key: $value\n";
}
// name: Andi
// email: andi@mail.com
// age: 25
// is_admin:
?>
```

## Kasus Penggunaan Nyata
Representasi data terstruktur (profil user, pengaturan, metadata), mapping kode ke nama (contoh: daftar provinsi), atau hasil parsing JSON.
