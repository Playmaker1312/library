# 113. sort rsort asort arsort ksort krsort

## Definisi Singkat
Fungsi sorting array: `sort`/`rsort` (berdasarkan nilai, re-index), `asort`/`arsort` (berdasarkan nilai, pertahankan key), `ksort`/`krsort` (berdasarkan key).

## Analogi
Seperti pustakawan yang merapikan buku: `sort` = urut berdasarkan judul (buang nomor rak lama). `asort` = urut berdasarkan judul tapi catat posisi aslinya. `ksort` = urut berdasarkan nomor rak.

## Poin-Poin Penting
| Fungsi | Sort by | Key | Order |
|--------|---------|-----|-------|
| `sort()` | Value | Re-index | Ascending |
| `rsort()` | Value | Re-index | Descending |
| `asort()` | Value | Preserve | Ascending |
| `arsort()` | Value | Preserve | Descending |
| `ksort()` | Key | Preserve | Ascending |
| `krsort()` | Key | Preserve | Descending |
- Semua fungsi memodifikasi array asli (pass by reference).
- Semua mengembalikan `true` pada sukses.
- Gunakan `sort` untuk indexed array, `asort`/`ksort` untuk associative.
- `SORT_STRING`, `SORT_NUMERIC`, `SORT_NATURAL` flags untuk cara perbandingan.

## Contoh Kode (PHP)
```php
<?php
$buah = ["jeruk", "apel", "mangga", "belimbing"];
sort($buah);
print_r($buah);
// [apel, belimbing, jeruk, mangga]

rsort($buah);
print_r($buah);
// [mangga, jeruk, belimbing, apel]

$nilai = ["Andi" => 85, "Budi" => 92, "Citra" => 78];
asort($nilai); // ascending by value
print_r($nilai);
// [Citra => 78, Andi => 85, Budi => 92]

ksort($nilai); // ascending by key
print_r($nilai);
// [Andi => 85, Budi => 92, Citra => 78]
?>
```

## Kasus Penggunaan Nyata
Menampilkan produk termurah/termahal (`asort`/`arsort`), mengurutkan daftar nama (`sort`), menampilkan data berdasarkan tanggal (`ksort` untuk date key), atau ranking nilai.
