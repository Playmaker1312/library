# 103. Menambah Elemen Array

## Definisi Singkat
Elemen baru ditambahkan ke array dengan assignment `$array[] = $value` (otomatis key berikutnya) atau dengan key spesifik `$array[$key] = $value`.

## Analogi
Seperti menambahkan buku baru ke rak kosong paling ujung — tidak perlu tahu nomor rak terakhir, taruh saja di ujung ([]), atau taruh di rak bernomor tertentu.

## Poin-Poin Penting
- `$array[] = $value` — menambah di akhir, key = max key + 1.
- `$array[$key] = $value` — menambah/memperbarui dengan key tertentu.
- Jika key sudah ada, nilai **ditimpa** (overwrite).
- `array_push($array, $value)` — fungsi khusus (sama dengan `$array[]`).
- PHP 8.1+ — tidak bisa menambah elemen ke array non-array (string, int) — fatal error.

## Contoh Kode (PHP)
```php
<?php
$buah = ["apel", "mangga"];
$buah[] = "jeruk";         // key terbesar +1 = 2
print_r($buah);
// [apel, mangga, jeruk]

// Dengan key spesifik
$buah[10] = "durian";
$buah[] = "semangka";      // key: max(2,10)+1 = 11
print_r($buah);
// [apel, mangga, jeruk, 10 => durian, 11 => semangka]

// Associative
$user = ["name" => "Andi"];
$user["email"] = "andi@mail.com";
print_r($user);
// [name => Andi, email => andi@mail.com]
?>
```

## Kasus Penggunaan Nyata
Menambahkan item ke keranjang belanja session, mengumpulkan hasil validasi error dalam array, atau membangun array dinamis dari hasil loop.
