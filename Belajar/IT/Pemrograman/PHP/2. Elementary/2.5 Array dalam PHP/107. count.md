# 107. count

## Definisi Singkat
`count()` mengembalikan jumlah elemen dalam array atau properti `Countable` pada objek. Untuk array multidimensi, bisa hitung secara rekursif.

## Analogi
Seperti petugas yang menghitung jumlah pengunjung di ruangan — satu per satu dihitung, lalu melaporkan totalnya.

## Poin-Poin Penting
- `count(Countable|array $value, int $mode = COUNT_NORMAL): int`
- `$mode = COUNT_NORMAL` (default) — hanya hitung level pertama.
- `$mode = COUNT_RECURSIVE` — hitung semua elemen di semua level.
- Jika parameter bukan array atau Countable, PHP 8+ throws TypeError.
- `sizeof()` adalah alias dari `count()` — sama persis.
- Untuk menghitung string, gunakan `strlen()`, bukan `count()`.

## Contoh Kode (PHP)
```php
<?php
$buah = ["apel", "mangga", "jeruk"];
echo count($buah); // 3

$matrix = [
    [1, 2],
    [3, 4],
    [5, 6],
];
echo count($matrix);            // 3 (3 baris)
echo count($matrix, COUNT_RECURSIVE); // 9 (3 baris + 6 elemen)

// Cek array kosong
if (count($buah) === 0) {
    echo "Array kosong";
}
?>
```

## Kasus Penggunaan Nyata
Menampilkan jumlah item di keranjang ("3 item"), pagination (`$totalPages = ceil(count($items) / $perPage)`), validasi array tidak kosong.
