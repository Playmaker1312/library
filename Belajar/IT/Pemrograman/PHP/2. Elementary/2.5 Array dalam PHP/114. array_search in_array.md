# 114. array_search in_array

## Definisi Singkat
`in_array()` mengecek apakah suatu nilai ada di dalam array (return `bool`). `array_search()` mencari nilai dan mengembalikan **key** pertama yang cocok (atau `false` jika tidak ditemukan).

## Analogi
Seperti resepsionis yang ditanya: `in_array` = "Apakah Bapak Andi ada di gedung ini?" (ada/tidak). `array_search` = "Di ruang nomor berapa Bapak Andi?" (langsung dikasih nomor ruangannya).

## Poin-Poin Penting
- `in_array(mixed $needle, array $haystack, bool $strict = false): bool`
- `array_search(mixed $needle, array $haystack, bool $strict = false): int|string|false`
- Parameter `$strict = true` menggunakan `===` (tipe harus sama).
- Jika needle ditemukan beberapa kali, `array_search` mengembalikan key **pertama**.
- `in_array` lebih cepat daripada `array_search` jika hanya perlu ada/tidak.
- PHP 8+ — strict default tetap `false` (loose).

## Contoh Kode (PHP)
```php
<?php
$buah = ["apel", "mangga", "jeruk", "1"];

var_dump(in_array("mangga", $buah));     // true
var_dump(in_array("apel", $buah));       // true

// Strict vs loose
var_dump(in_array(1, $buah));            // true (loose: "1" == 1)
var_dump(in_array(1, $buah, true));      // false (strict: "1" !== 1)

// array_search
$key = array_search("jeruk", $buah);
echo $key; // 2

$key = array_search("durian", $buah);
var_dump($key); // false
?>
```

Cek apakah email sudah terdaftar (`in_array`), mencari ID produk dalam array (`array_search`), atau validasi role yang diizinkan.
