# 86. if Statement

## Definisi Singkat
`if` adalah struktur kontrol paling dasar yang mengeksekusi blok kode hanya jika kondisi boolean bernilai `true`.

## Analogi
Seperti "kalau hujan, bawa payung" — aksi hanya dilakukan jika kondisi terpenuhi. Jika tidak hujan, abaikan.

## Poin-Poin Penting
- Sintaks: `if (kondisi) { // kode }`
- Kondisi harus bernilai boolean (atau type juggling ke boolean).
- Nilai falsy: `0`, `""`, `null`, `false`, `[]`, `"0"`.
- PHP 8+ — `if` dengan ekspresi yang tidak menghasilkan nilai (seperti `if (empty())`) tetap valid.
- Blok kurung kurawal `{}` wajib jika lebih dari satu statement.

## Contoh Kode (PHP)
```php
<?php
$age = 18;

if ($age >= 17) {
    echo "Bisa bikin SIM";
}

// Tanpa kurung kurawal (satu baris)
if ($age >= 17) echo "Bisa bikin SIM";

// Cek array kosong
$items = [];
if (count($items) === 0) {
    echo "Keranjang kosong";
}
?>
```

## Kasus Penggunaan Nyata
Cek apakah user sudah login sebelum menampilkan konten, validasi input form, atau menentukan apakah suatu fitur diaktifkan.
