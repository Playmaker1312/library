# 96. break

## Definisi Singkat
`break` menghentikan eksekusi struktur perulangan (`for`, `foreach`, `while`, `do-while`, `switch`) saat itu juga. Dapat menerima argumen numerik untuk keluar dari beberapa level loop.

## Analogi
Seperti tombol "STOP" darurat di eskalator — begitu ditekan, eskalator berhenti saat itu juga. Jika ada banyak eskalator bertingkat, Anda tentukan berapa level yang berhenti.

## Poin-Poin Penting
- `break;` — keluar dari 1 level (default).
- `break n;` — keluar dari n level loop.
- Berlaku untuk `switch` juga — `break` di `case` wajib untuk mencegah fall-through.
- Tidak berlaku untuk `include` atau fungsi — hanya untuk looping dan switch.
- PHP 8+ — argumen n harus integer positif.
- `break 0;` tidak valid (minimal 1).

## Contoh Kode (PHP)
```php
<?php
// break 1 level
for ($i = 1; $i <= 10; $i++) {
    if ($i === 5) {
        break;
    }
    echo "$i ";
}
// Output: 1 2 3 4

// break multiple level
for ($i = 0; $i < 3; $i++) {
    for ($j = 0; $j < 3; $j++) {
        if ($i === 1 && $j === 1) {
            break 2; // keluar dari kedua loop
        }
        echo "($i,$j) ";
    }
}
// Output: (0,0) (0,1) (0,2) (1,0)
?>
```

## Kasus Penggunaan Nyata
Menghentikan loop saat data yang dicari ditemukan (optimasi), membatasi iterasi pencarian, atau keluar dari nested loop setelah kondisi terpenuhi.
