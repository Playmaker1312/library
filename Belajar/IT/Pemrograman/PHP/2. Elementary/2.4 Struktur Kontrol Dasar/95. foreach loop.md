# 95. foreach Loop

## Definisi Singkat
`foreach` mengiterasi setiap elemen dalam array atau objek yang mengimplementasi `Traversable`. Loop ini berjalan dari elemen pertama hingga terakhir tanpa perlu counter manual.

## Analogi
Seperti berjalan melewati setiap rak di toko — Anda lihat satu per satu barang tanpa perlu menghitung jumlah rak dulu. Setiap barang dikunjungi tepat satu kali.

## Poin-Poin Penting
- Sintaks value-only: `foreach ($array as $value)`
- Sintaks key-value: `foreach ($array as $key => $value)`
- Sejak PHP 7, `foreach` bekerja pada **copy** array (internal copy-on-write).
- Modifikasi `$value` tidak mengubah array asli kecuali menggunakan reference `&$value`.
- Bisa iterate `Traversable` objects (termasuk Generator, Collection).
- PHP 8.1+ — unpacking nested foreach dengan `list()` atau `[]`.

## Contoh Kode (PHP)
```php
<?php
$buah = ["apel", "mangga", "jeruk"];

foreach ($buah as $item) {
    echo "$item ";
}
// apel mangga jeruk

// Dengan key
$ages = ["Andi" => 25, "Budi" => 30];
foreach ($ages as $name => $age) {
    echo "$name berusia $age ";
}
// Andi berusia 25 Budi berusia 30

// Modifikasi via reference
foreach ($buah as &$item) {
    $item = strtoupper($item);
}
unset($item); // Hapus reference!
print_r($buah);
// [APEL, MANGGA, JERUK]
?>
```

## Kasus Penggunaan Nyata
Menampilkan daftar produk dari database, iterasi data API response, atau memproses setiap item dalam keranjang belanja.
