# 93. while Loop

## Definisi Singkat
`while` loop mengulang blok kode **selama** kondisi bernilai `true`. Kondisi dicek di awal setiap iterasi — bisa tidak pernah dijalankan jika kondisi sudah false dari awal.

## Analogi
Seperti "terus membaca buku selama masih halaman" — selama kondisinya terpenuhi, aksi terus dilakukan. Ketika habis halaman, berhenti.

## Poin-Poin Penting
- Sintaks: `while (kondisi) { // kode }`
- Kondisi dievaluasi sebelum body — loop bisa 0 kali jika kondisi awal false.
- Risiko **infinite loop** jika kondisi tidak pernah menjadi false.
- Berguna untuk iterasi dengan jumlah yang tidak pasti.
- Sering digunakan dengan `feof()`, `fgets()`, atau iterator yang tidak diketahui panjangnya.

## Contoh Kode (PHP)
```php
<?php
$count = 1;
while ($count <= 5) {
    echo "$count ";
    $count++;
}
// Output: 1 2 3 4 5

// Membaca file
$handle = fopen("file.txt", "r");
if ($handle) {
    while (($line = fgets($handle)) !== false) {
        echo $line;
    }
    fclose($handle);
}
?>
```

## Kasus Penggunaan Nyata
Membaca file baris per baris, polling status dari database hingga selesai, atau iterasi data yang jumlahnya tidak diketahui sebelumnya.
