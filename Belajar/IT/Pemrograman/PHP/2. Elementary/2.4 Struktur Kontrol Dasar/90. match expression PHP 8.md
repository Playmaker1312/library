# 90. match Expression (PHP 8)

## Definisi Singkat
`match` (PHP 8.0+) adalah ekspresi yang mencocokkan nilai dan mengembalikan hasil, mirip `switch` tetapi menggunakan **strict comparison (`===`)** dan langsung mengembalikan nilai tanpa `break`.

## Analogi
Seperti mesin kopi otomatis: tekan tombol "americano" → langsung dapat americano. Tidak perlu break, tidak perlu fall-through, hasil langsung keluar.

## Poin-Poin Penting
- `match (expr) { pattern => result, ... }` — **ekspresi**, bukan statement (memiliki nilai return).
- Menggunakan **strict comparison** (`===`), bukan `==`.
- Tanpa `break` — hanya satu cabang yang dieksekusi.
- **Harus exhaustive** — jika tidak ada case cocok, `UnhandledMatchError` dilempar.
- Bisa multiple pattern: `1, 2 => "rendah"`.
- `default` case untuk fallback.

## Contoh Kode (PHP)
```php
<?php
$statusCode = 404;

$message = match ($statusCode) {
    200 => "OK",
    301, 302 => "Redirect",
    404 => "Not Found",
    500 => "Server Error",
    default => "Unknown Status",
};
echo $message; // Not Found

// match sebagai ekspresi
$age = 20;
$category = match (true) {
    $age < 13 => "Anak",
    $age < 20 => "Remaja",
    default => "Dewasa",
};
echo $category; // Remaja
?>
```

## Kasus Penggunaan Nyata
Mapping HTTP status code ke pesan, parsing enum value, atau conditional assignment yang lebih bersih dari switch/if-else.
