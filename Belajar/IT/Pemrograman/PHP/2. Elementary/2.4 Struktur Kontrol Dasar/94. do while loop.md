# 94. do while Loop

## Definisi Singkat
`do while` mirip `while`, tetapi kondisi dicek **setelah** body — sehingga body pasti dijalankan **minimal satu kali** meskipun kondisi awal false.

## Analogi
Seperti "coba dulu kuenya, baru tanya 'enak?'" — aksi dilakukan dulu, baru evaluasi kondisi. Berbeda dengan while yang "tanya dulu baru makan".

## Poin-Poin Penting
- Sintaks: `do { // kode } while (kondisi);`
- Body pasti dijalankan minimal satu kali (berbeda dengan `while`).
- Titik koma (`;`) wajib setelah `while (kondisi)`.
- Cocok untuk skenario di mana aksi harus dilakukan setidaknya sekali.
- Relatif jarang digunakan dibanding `while` biasa.

## Contoh Kode (PHP)
```php
<?php
$i = 1;
do {
    echo "$i ";
    $i++;
} while ($i <= 5);
// Output: 1 2 3 4 5

// Tetap dijalankan minimal sekali
$j = 10;
do {
    echo "Dijalankan";
} while ($j < 5);
// Output: Dijalankan
?>
```

## Kasus Penggunaan Nyata
Menu interaktif CLI yang harus tampil minimal sekali, meminta input ulang sampai valid, atau melakukan aksi inisialisasi lalu mengulang berdasarkan kondisi.
