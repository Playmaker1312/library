# 88. if elseif else

## Definisi Singkat
`if elseif else` memungkinkan percabangan dengan banyak kondisi. Kondisi dievaluasi berurutan dari atas — blok pertama yang `true` dieksekusi, sisanya dilewati.

## Analogi
Seperti sistem grading nilai: >= 90 → A, >= 80 → B, >= 70 → C, < 70 → D. Dicek bertahap, begitu ketemu langsung berhenti.

## Poin-Poin Penting
- Bisa memiliki banyak `elseif` (atau `else if`, beda spasi tapi sama).
- Urutan kondisi penting — yang lebih spesifik harus diletakkan di atas.
- `else` bersifat opsional — hanya dieksekusi jika semua kondisi `false`.
- Di PHP, `elseif` adalah satu kata (tidak seperti C yang pakai `else if`).
- Terlalu banyak `elseif` biasanya lebih baik diganti `switch` atau `match`.

## Contoh Kode (PHP)
```php
<?php
$nilai = 85;

if ($nilai >= 90) {
    echo "A";
} elseif ($nilai >= 80) {
    echo "B";
} elseif ($nilai >= 70) {
    echo "C";
} elseif ($nilai >= 60) {
    echo "D";
} else {
    echo "E";
}
// Output: B
?>
```

## Kasus Penggunaan Nyata
Klasifikasi (umur, nilai, harga), routing sederhana berdasarkan parameter, atau menentukan level user (admin, editor, subscriber).
