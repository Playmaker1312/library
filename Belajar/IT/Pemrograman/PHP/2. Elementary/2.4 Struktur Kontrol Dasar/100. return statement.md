# 100. return Statement

## Definisi Singkat
`return` mengembalikan nilai dari fungsi atau method dan menghentikan eksekusi fungsi tersebut. Di file global, `return` menghentikan eksekusi file saat itu.

## Analogi
Seperti mesin penjual: Anda masukkan koin (parameter), mesin memproses, lalu **mengembalikan** produk (return value). Setelah produk keluar, mesin selesai bekerja.

## Poin-Poin Penting
- Di dalam fungsi: `return $value;` — fungsi berhenti dan mengembalikan $value.
- Global scope: `return;` — hentikan eksekusi file (sering untuk konfigurasi).
- Jika fungsi tanpa `return` eksplisit, return `null`.
- `return` di `include`/`require` mengembalikan nilai ke file pemanggil.
- Hanya satu nilai yang bisa diretur (tapi bisa array atau object).
- PHP 8.1+ — return type `never` untuk fungsi yang tidak pernah return (selalu exit/die).

## Contoh Kode (PHP)
```php
<?php
function tambah($a, $b): int {
    return $a + $b;
    echo "Ini tidak akan pernah dijalankan";
}

$hasil = tambah(5, 3);
echo $hasil; // 8

// Return null implisit
function tanpaReturn() {
    // tidak ada return
}
var_dump(tanpaReturn()); // NULL

// Return di global scope (config file)
// config.php
return [
    "db_host" => "localhost",
    "db_name" => "test",
];
// $config = require "config.php";
?>
```

## Kasus Penggunaan Nyata
Mengembalikan hasil kalkulasi, menghasilkan response dari controller, memberikan data dari model ke view, atau return konfigurasi dari file config.
