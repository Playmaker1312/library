# 92. for Loop

## Definisi Singkat
`for` loop mengulang eksekusi blok kode selama kondisi terpenuhi. Terdiri dari: inisialisasi, kondisi, dan increment/decrement.

## Analogi
Seperti lari di lintasan: tahu pasti start-nya, tahu finish-nya, dan setiap putaran bertambah satu langkah. Cocok untuk iterasi dengan jumlah pasti.

## Poin-Poin Penting
- Sintaks: `for (expr1; expr2; expr3) { body }`
  - `expr1`: dijalankan sekali di awal.
  - `expr2`: dicek setiap iterasi — jika true, loop lanjut.
  - `expr3`: dijalankan setiap akhir iterasi.
- Semua ekspresi opsional: `for (;;)` adalah infinite loop.
- Bisa menggunakan multiple expression dengan koma: `for ($i = 0, $j = 10; ...)`.
- Cocok untuk iterasi dengan counter numerik.

## Contoh Kode (PHP)
```php
<?php
for ($i = 1; $i <= 5; $i++) {
    echo "$i ";
}
// Output: 1 2 3 4 5

// Hitung mundur
for ($i = 5; $i >= 1; $i--) {
    echo "$i ";
}
// Output: 5 4 3 2 1

// Multiple expression
for ($i = 0, $j = 5; $i < 5; $i++, $j--) {
    echo "($i, $j) ";
}
// Output: (0, 5) (1, 4) (2, 3) (3, 2) (4, 1)
?>
```

## Kasus Penggunaan Nyata
Menampilkan nomor urut dalam tabel, generate menu dengan jumlah item pasti, iterasi dengan index counter dalam array numerik.
