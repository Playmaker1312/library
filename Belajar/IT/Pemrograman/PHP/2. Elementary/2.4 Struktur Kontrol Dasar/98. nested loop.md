# 98. Nested Loop

## Definisi Singkat
Nested loop adalah perulangan di dalam perulangan. Loop dalam akan dijalankan sepenuhnya untuk **setiap iterasi** loop luar.

## Analogi
Seperti jam: jarum menit (loop luar) bergerak satu langkah, lalu jarum detik (loop dalam) berputar penuh 60 langkah, baru jarum menit bergerak lagi. Satu iterasi luar memicu banyak iterasi dalam.

## Poin-Poin Penting
- Kompleksitas O(n × m) — bisa lambat jika kedua loop besar.
- Loop dalam bisa menggunakan variabel dari loop luar.
- Gunakan `break n` / `continue n` untuk kontrol dari dalam.
- Nested loop sering digunakan untuk array multidimensi.
- Pertimbangkan optimasi: kadang bisa di-flatten atau pakai teknik lain.

## Contoh Kode (PHP)
```php
<?php
// Tabel perkalian
for ($i = 1; $i <= 3; $i++) {
    for ($j = 1; $j <= 3; $j++) {
        echo sprintf("%2d ", $i * $j);
    }
    echo "\n";
}
//  1  2  3
//  2  4  6
//  3  6  9

// Array multidimensi
$matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
];

foreach ($matrix as $row) {
    foreach ($row as $value) {
        echo "$value ";
    }
}
// Output: 1 2 3 4 5 6 7 8 9
?>
```

## Kasus Penggunaan Nyata
Menampilkan tabel data dari database (baris dalam loop luar, kolom dalam loop dalam), memproses matrix/grid, atau menghasilkan kombinasi produk.
