# 91. switch vs match

## Definisi Singkat
`switch` adalah statement yang mengeksekusi blok kode (membutuhkan `break`), sedangkan `match` (PHP 8+) adalah ekspresi yang mengembalikan nilai dengan perbandingan strict (`===`).

## Analogi
`switch` seperti pom bensin konvensional: pilih jenis, isi, lalu tutup (break). `match` seperti mesin otomatis: masukkan pilihan, langsung dapat produk, tanpa langkah tambahan.

## Poin-Poin Penting
| Aspek | switch | match |
|-------|--------|-------|
| Comparison | Loose (`==`) | Strict (`===`) |
| Return value | Tidak (statement) | Ya (expression) |
| Break | Wajib | Tidak perlu |
| Fall-through | Ya (tanpa break) | Tidak |
| Exhaustive | Tidak wajib | Wajib (error jika tidak cocok) |
| Multiple pattern | Tidak langsung | Ya (`case a, b =>`) |
| Tipe | Tersedia sejak PHP 4 | PHP 8.0+ |

## Contoh Kode (PHP)
```php
<?php
// switch — butuh break, loose comparison
switch ("1") {
    case 1:
        echo "Angka 1"; // Terekseskusi!
        break;
}

// match — strict, tidak fall-through
echo match ("1") {
    1 => "Angka 1",   // Tidak cocok (string vs int)
    "1" => "String 1", // Cocok
};
// Output: String 1
?>
```

## Kasus Penggunaan Nyata
Gunakan `match` untuk conditional return/assignment (PHP 8+). Gunakan `switch` jika perlu menjalankan blok kode kompleks (bukan sekadar return nilai).
