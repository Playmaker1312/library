# 89. switch Statement

## Definisi Singkat
`switch` membandingkan satu ekspresi dengan banyak nilai (`case`) dan mengeksekusi blok yang cocok. Harus menggunakan `break` untuk mencegah **fall-through** ke case berikutnya.

## Analogi
Seperti mesin tiket tujuan: Anda pilih tujuan (case), mesin mengeluarkan tiket yang sesuai. Kalau lupa ambil tiket (break), Anda lanjut ke tujuan berikutnya (fall-through).

## Poin-Poin Penting
- Perbandingan menggunakan **loose comparison** (`==`), bukan `===`.
- Wajib `break` untuk stop; tanpa break, eksekusi lanjut ke case berikutnya **(fall-through)**.
- `default` untuk nilai yang tidak cocok case manapun.
- Bisa menggunakan `;` sebagai ganti `:` setelah case (jarang).
- Di PHP 8, `match` sering menjadi alternatif yang lebih baik.

## Contoh Kode (PHP)
```php
<?php
$role = "admin";

switch ($role) {
    case "admin":
        echo "Akses penuh";
        break;
    case "editor":
        echo "Akses edit";
        break;
    case "subscriber":
        echo "Akses baca";
        break;
    default:
        echo "Akses ditolak";
}
// Output: Akses penuh

// Fall-through case
switch ($day) {
    case "sabtu":
    case "minggu":
        echo "Weekend";
        break;
    default:
        echo "Weekday";
}
?>
```

## Kasus Penggunaan Nyata
Routing berdasarkan role user, menangani aksi dari form (`$_POST["action"]`), atau mapping status code ke pesan.
