# 97. continue

## Definisi Singkat
`continue` melewati sisa iterasi saat ini dan langsung melanjutkan ke iterasi berikutnya dalam perulangan. Sama seperti `break`, bisa menerima argumen numerik untuk level.

## Analogi
Seperti di pabrik: ada barang cacat di ban berjalan — alih-alih menghentikan seluruh pabrik, barang itu disingkirkan (skip) dan ban berjalan lanjut ke barang berikutnya.

## Poin-Poin Penting
- `continue;` — skip sisa body, lanjut ke iterasi berikutnya.
- `continue n;` — skip n level loop.
- Di `switch` dalam loop, `continue` akan melanjutkan loop (bukan switch).
- `continue 2;` pada switch di dalam loop untuk melanjutkan loop luar.
- PHP 8+ — continue dengan argumen n pada switch akan error.
- Hati-hati: dalam `for`, `continue` tetap mengeksekusi increment.

## Contoh Kode (PHP)
```php
<?php
for ($i = 1; $i <= 5; $i++) {
    if ($i === 3) {
        continue;
    }
    echo "$i ";
}
// Output: 1 2 4 5

// continue 2 pada nested loop
for ($i = 0; $i < 3; $i++) {
    for ($j = 0; $j < 3; $j++) {
        if ($j === 1) {
            continue 2;
        }
        echo "($i,$j) ";
    }
}
// Output: (0,0) (1,0) (2,0)
?>
```

## Kasus Penggunaan Nyata
Melewati item yang tidak valid dalam daftar (contoh: produk tanpa stok), memproses hanya data yang memenuhi kriteria tertentu, atau skip iterasi yang tidak perlu.
