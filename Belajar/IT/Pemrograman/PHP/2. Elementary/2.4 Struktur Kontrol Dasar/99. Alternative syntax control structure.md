# 99. Alternative Syntax Control Structure

## Definisi Singkat
PHP menyediakan sintaks alternatif untuk struktur kontrol (`if`, `while`, `for`, `foreach`, `switch`) dengan mengganti kurung kurawal `{}` dengan titik dua `:` dan penutup `endif;`, `endwhile;`, `endfor;`, `endforeach;`, `endswitch;`.

## Analogi
Seperti dua cara menulis surat: format blok (kurung kurawal) atau format setengah blok (endif). Keduanya sah dan menghasilkan dokumen yang sama.

## Poin-Poin Penting
- Biasanya digunakan dalam template (campuran HTML dan PHP) agar lebih rapi.
- Format: `<?php if ($cond): ?> ... <?php endif; ?>`
- Alternatif untuk: `if`, `while`, `for`, `foreach`, `switch`.
- Tidak bisa digunakan bersamaan dengan kurung kurawal.
- Di PHP 8+, masih didukung penuh.

## Contoh Kode (PHP)
```php
<?php $items = ["Apel", "Mangga", "Jeruk"]; ?>

<ul>
<?php foreach ($items as $item): ?>
    <li><?= $item ?></li>
<?php endforeach; ?>
</ul>

<?php if ($loggedIn): ?>
    <p>Selamat datang, <?= $name ?></p>
<?php else: ?>
    <a href="/login">Login</a>
<?php endif; ?>

<?php for ($i = 1; $i <= 3; $i++): ?>
    <p>Nomor <?= $i ?></p>
<?php endfor; ?>
```

## Kasus Penggunaan Nyata
Digunakan di file template (seperti di Laravel Blade, atau template PHP murni) untuk memisahkan logika PHP dari markup HTML dengan rapi.
