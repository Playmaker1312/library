# 87. if else

## Definisi Singkat
`if else` menyediakan dua cabang: satu blok jika kondisi `true`, blok lain jika kondisi `false`. Hanya satu blok yang dieksekusi.

## Analogi
Seperti lampu lalu lintas: "hijau? jalan. merah? berhenti." Dua kemungkinan, dua tindakan berbeda, tidak mungkin keduanya terjadi.

## Poin-Poin Penting
- Sintaks: `if (kondisi) { true-block } else { false-block }`
- `else` tidak boleh memiliki kondisi sendiri — terikat pada `if` sebelumnya.
- Dapat dikombinasikan dengan `elseif` untuk banyak cabang.
- Nested if-else diperbolehkan tapi kurangi keterbacaan jika terlalu dalam.
- PHP 8+ — tidak ada perubahan pada sintaks if-else.

## Contoh Kode (PHP)
```php
<?php
$isLogin = true;

if ($isLogin) {
    echo "Selamat datang kembali!";
} else {
    echo "Silakan login terlebih dahulu.";
}

// Nilai falsy check
$score = 0;
if ($score) {
    echo "Nilai: $score";
} else {
    echo "Belum ada nilai";
}
// Belum ada nilai (karena 0 falsy)
?>
```

## Kasus Penggunaan Nyata
Menampilkan tombol "Login" atau "Logout" berdasarkan status session, menampilkan pesan sukses/gagal setelah operasi, atau menentukan template mana yang dirender.
