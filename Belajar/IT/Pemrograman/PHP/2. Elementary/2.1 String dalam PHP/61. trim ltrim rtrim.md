# 61. trim ltrim rtrim

## Definisi Singkat
`trim()` menghapus spasi (whitespace) atau karakter tertentu dari awal dan akhir string. `ltrim()` hanya dari kiri (awal), `rtrim()` hanya dari kanan (akhir).

## Analogi
Seperti memotong ujung-ujung kain yang tidak rapi — trim (kedua ujung), ltrim (ujung kiri), rtrim (ujung kanan).

## Poin-Poin Penting
- `trim(string $string, string $characters = " \n\r\t\v\x00"): string`
- Default: hapus spasi, newline (`\n`), carriage return (`\r`), tab (`\t`), vertical tab (`\v`), null byte (`\x00`).
- Bisa menentukan karakter khusus yang ingin dihapus via parameter kedua.
- `ltrim()` — hapus dari kiri saja; `rtrim()` — hapus dari kanan saja.
- Tidak mengubah string asli.
- Karakter di parameter `$characters` dihapus satu per satu, bukan sebagai grup.

## Contoh Kode (PHP)
```php
<?php
$text = "  Halo Dunia  ";
echo trim($text);           // "Halo Dunia"
echo ltrim($text);          // "Halo Dunia  "
echo rtrim($text);          // "  Halo Dunia"

// Hapus karakter tertentu
$url = "www.example.com";
echo trim($url, "w.");      // "example.com"

// Hapus koma dan spasi
$csv = "apel, jeruk, ";
echo rtrim($csv, ", ");     // "apel, jeruk"
?>
```

## Kasus Penggunaan Nyata
Membersihkan input form dari spasi tak sengaja, normalize string untuk validasi, menghapus trailing slash dari URL, atau membersihkan data CSV.
