# 65. sprintf printf

## Definisi Singkat
`sprintf()` mengembalikan string yang diformat berdasarkan format specifier, sedangkan `printf()` langsung menampilkan (echo) hasilnya. Keduanya mirip dengan `sprintf` di C.

## Analogi
Seperti cetakan kue — Anda siapkan loyang (format) dengan berbagai lubang (specifier), lalu tuang adonan (nilai) — kue yang keluar sudah sesuai bentuk yang diinginkan.

## Poin-Poin Penting
- Format specifier: `%s` (string), `%d` (integer), `%f` (float), `%x` (hex), dll.
- `sprintf(format, ...values): string` — mengembalikan string.
- `printf(format, ...values): int` — langsung echo, mengembalikan panjang output.
- Bisa menentukan lebar, presisi, padding: `%04d`, `%.2f`.
- PHP 8+ — argument swapping dengan `%1$s` untuk mengubah urutan parameter.
- `vprintf()` dan `vsprintf()` untuk array parameter.

## Contoh Kode (PHP)
```php
<?php
$name = "Dewi";
$age = 25;

echo sprintf("Nama: %s, Umur: %d", $name, $age);
// Nama: Dewi, Umur: 25

// Format angka
echo sprintf("Harga: Rp%.2f", 15000.5);  // Harga: Rp15000.50
echo sprintf("%04d", 42);                // 0042

// Argument swapping
echo sprintf("Umur: %2\$d, Nama: %1\$s", $name, $age);
// Umur: 25, Nama: Dewi

printf("Halo %s", "Dunia");  // Halo Dunia (langsung output)
?>
```

## Kasus Penggunaan Nyata
Memformat harga dengan desimal tetap, membuat laporan dengan kolom rata kiri/kanan, menghasilkan query SQL yang aman (walaupun prepared statement lebih baik), atau logging dengan format konsisten.
