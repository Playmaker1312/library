# 64. str_pad str_repeat

## Definisi Singkat
`str_pad()` menambahkan karakter padding ke string hingga mencapai panjang tertentu. `str_repeat()` mengulang string sebanyak N kali.

## Analogi
`str_pad` seperti mengisi bantal dengan kapas sampai mencapai ketebalan yang diinginkan. `str_repeat` seperti mesin fotokopi yang menggandakan dokumen berkali-kali.

## Poin-Poin Penting
- `str_pad(string $string, int $length, string $pad_string = " ", int $pad_type = STR_PAD_RIGHT): string`
- `$pad_type`: `STR_PAD_RIGHT`, `STR_PAD_LEFT`, `STR_PAD_BOTH`.
- Jika panjang string sudah >= `$length`, tidak ada padding.
- `str_repeat(string $string, int $times): string`
- Jika `$times` = 0, mengembalikan string kosong.
- Di PHP 8.0+, str_repeat dengan `$times` negatif: ValueError.

## Contoh Kode (PHP)
```php
<?php
// str_pad
echo str_pad("42", 5, "0", STR_PAD_LEFT);   // 00042
echo str_pad("Halo", 10, ".-");              // Halo.-.-.-
echo str_pad("Tengah", 11, "*", STR_PAD_BOTH); // ***Tengah**

// str_repeat
echo str_repeat("Ho", 3);                    // HoHoHo
echo str_repeat("-=", 5);                    // -=-=-=-=-=-
echo str_repeat("A", 0);                     // (string kosong)
?>
```

## Kasus Penggunaan Nyata
`str_pad`: membuat nomor invoice dengan leading zero (INV-00042), merapikan kolom tabel. `str_repeat`: membuat garis pemisah, generate placeholder, atau membuat grafik ASCII sederhana.
