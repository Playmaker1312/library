# 54. Nowdoc Syntax

## Definisi Singkat
Nowdoc adalah heredoc yang berperilaku seperti **single quote** — tidak ada interpolasi variabel dan tidak ada pemrosesan escape sequence. Identifier diawali dengan tanda petik tunggal: `<<<'IDENTIFIER'`.

## Analogi
Seperti mengirimkan kode sumber melalui email tanpa compiler memprosesnya — apa yang ditulis adalah teks mentah apa adanya.

## Poin-Poin Penting
- Sama seperti heredoc tetapi identifier dikelilingi `'`, contoh `<<<'EOT'`.
- Tidak menginterpolasi variabel — variabel ditampilkan sebagai teks literal.
- Tidak memproses escape sequence (kecuali `\\` untuk backslash literal).
- Cocok untuk konten yang mengandung kode atau sintaks asing.
- Flexible nowdoc (penutup boleh menjorok) tersedia sejak PHP 7.3+.
- Sedikit lebih cepat dari heredoc karena tidak perlu parsing variabel.

## Contoh Kode (PHP)
```php
<?php
$name = "Citra";
$text = <<<'EOT'
Halo $name,
Baris ini \n tidak akan diproses.
EOT;

echo $text;
// Halo $name,
// Baris ini \n tidak akan diproses.
?>

// Flexible nowdoc (PHP 7.3+)
$code = <<<'CODE'
    if ($x === 10) {
        echo "X adalah 10";
    }
CODE;
```

## Kasus Penggunaan Nyata
Menyimpan template kode (JavaScript, CSS) di dalam variabel PHP tanpa khawatir variabel PHP keinterpolasi, atau membuat dokumentasi yang berisi contoh kode PHP.
