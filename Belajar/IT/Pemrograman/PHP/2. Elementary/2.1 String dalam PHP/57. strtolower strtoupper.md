# 57. strtolower strtoupper

## Definisi Singkat
`strtolower()` mengubah string menjadi huruf kecil seluruhnya, sedangkan `strtoupper()` mengubah menjadi huruf besar seluruhnya. Untuk multibyte, gunakan `mb_strtolower()` / `mb_strtoupper()`.

## Analogi
Seperti tombol "CAPS" dan "uncaps" di remote TV — sekali tekan, seluruh teks berubah format hurufnya.

## Poin-Poin Penting
- `strtolower(string $string): string` — lowercase seluruhnya.
- `strtoupper(string $string): string` — uppercase seluruhnya.
- Tidak andal untuk karakter non-ASCII (seperti `Ü`, `ñ`) — hasil bisa tidak sesuai.
- Gunakan fungsi `mb_*` untuk locale-aware dan multibyte: `mb_strtolower($str, 'UTF-8')`.
- Tidak mengubah karakter non-huruf (angka, simbol tetap sama).
- PHP 8+ parameter null menyebabkan TypeError.

## Contoh Kode (PHP)
```php
<?php
$text = "Halo Dunia!";
echo strtolower($text);   // halo dunia!
echo strtoupper($text);   // HALO DUNIA!

// Multibyte safe
echo mb_strtoupper("café");  // CAFÉ
echo mb_strtolower("JALAN"); // jalan
?>
```

## Kasus Penggunaan Nyata
Normalisasi input (membandingkan email/username case-insensitive), mengubah judul menjadi slug URL, atau formatting teks untuk tampilan.
