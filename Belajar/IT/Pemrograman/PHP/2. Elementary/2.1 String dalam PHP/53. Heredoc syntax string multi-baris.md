# 53. Heredoc Syntax String Multi-Baris

## Definisi Singkat
Heredoc adalah cara membuat string multi-baris di PHP tanpa perlu escape quote, dengan perilaku seperti **double quote** (mendukung interpolasi variabel dan escape sequence).

## Analogi
Seperti menulis surat panjang di atas kertas terpisah lalu menjepitnya ke dokumen utama — kontennya bersih tanpa tanda kutip, tetapi variabel tetap bisa diganti isinya.

## Poin-Poin Penting
- Dimulai dengan `<<<IDENTIFIER` dan diakhiri dengan `IDENTIFIER;` pada baris sendiri.
- Penutup **harus** berada di awal baris (tanpa spasi/tab) dan diakhiri titik koma.
- Berperilaku seperti double quote (interpolasi + escape).
- Nama identifier: huruf, underscore (contoh: `EOT`, `HTML`, `SQL`).
- Di PHP 7.3+, penutup boleh sedikit menjorok (flexible heredoc).
- Bisa digunakan sebagai argument function sejak PHP 8.1+.

## Contoh Kode (PHP)
```php
<?php
$name = "Budi";
$text = <<<EOT
Halo $name,
Selamat datang di PHP.
Baris ini juga bagian string.
EOT;

echo $text;
// Halo Budi,
// Selamat datang di PHP.
// Baris ini juga bagian string.
?>

// PHP 8.1: heredoc sebagai argument
<?php
echo <<<HTML
<div>
  <p>Halo</p>
</div>
HTML;
?>
```

## Kasus Penggunaan Nyata
Membuat template HTML atau SQL query panjang dengan banyak baris dan variabel dinamis tanpa repot dengan concatenation atau escape quote.
