# 55. Concatenation Operator Titik

## Definisi Singkat
Operator titik (`.`) digunakan untuk menggabungkan dua atau lebih string menjadi satu string baru. Ini adalah operator concatenation satu-satunya di PHP.

## Analogi
Seperti menyambungkan gerbong kereta — setiap gerbong (string) disambungkan dengan kopling (titik) menjadi satu rangkaian panjang.

## Poin-Poin Penting
- Gunakan titik (`.`) di antara string atau variabel yang ingin digabung.
- Setiap operand dikonversi ke string secara otomatis (tipe lain seperti int/float akan di-cast).
- Operator `.=` adalah shorthand untuk `$var = $var . "sesuatu"`.
- Tidak seperti JavaScript yang pakai `+`, PHP hanya menggunakan `.` untuk concatenation.
- Untuk performa tinggi dengan banyak penggabungan, pertimbangkan `implode()` atau `sprintf`.

## Contoh Kode (PHP)
```php
<?php
$first = "Halo";
$last = "Dunia";
echo $first . " " . $last;  // Halo Dunia

$num = 42;
echo "Angka: " . $num;      // Angka: 42

// Shorthand .=
$greeting = "Halo";
$greeting .= " " . "Andi";
echo $greeting;             // Halo Andi
?>
```

## Kasus Penggunaan Nyata
Membangun pesan dinamis (contoh: "Selamat datang, {nama}! Ada {jumlah} notifikasi"), menyusun query string URL, atau menggabungkan bagian-bagian alamat lengkap.
