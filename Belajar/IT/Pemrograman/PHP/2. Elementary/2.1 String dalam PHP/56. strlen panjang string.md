# 56. strlen — Panjang String

## Definisi Singkat
`strlen()` mengembalikan panjang string dalam **byte**, bukan jumlah karakter. Untuk string multibyte (UTF-8), gunakan `mb_strlen()`.

## Analogi
Seperti menghitung jumlah kerikil dalam satu baris — setiap kerikil adalah satu byte. Tapi kalau ada kerikil besar (karakter Unicode seperti emoji), ukurannya bisa 4 byte tetap dihitung satu per satu.

## Poin-Poin Penting
- `strlen(string $string): int` — mengembalikan panjang dalam byte.
- PHP 8: `null` tidak lagi diterima (akan error TypeError), harus string.
- Untuk karakter UTF-8 (seperti `é`, `字`, atau emoji), gunakan `mb_strlen($string, 'UTF-8')`.
- Di PHP 8+, `strlen()` dengan array (dulu warning) sekarang TypeError.
- String kosong mengembalikan `0`.

## Contoh Kode (PHP)
```php
<?php
echo strlen("Halo");          // 4
echo strlen("é");             // 2 (dalam byte UTF-8)
echo mb_strlen("é", "UTF-8"); // 1

echo strlen("");              // 0
echo strlen(" ");             // 1
echo strlen("😀");            // 4 (byte)
echo mb_strlen("😀", "UTF-8"); // 1
?>
```

## Kasus Penggunaan Nyata
Validasi panjang input form (misal password minimal 8 karakter — gunakan `mb_strlen` untuk mendukung Unicode), memotong teks berdasarkan panjang, atau cek string kosong.
