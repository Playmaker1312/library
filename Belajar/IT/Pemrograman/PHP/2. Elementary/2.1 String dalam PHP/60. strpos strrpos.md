# 60. strpos strrpos

## Definisi Singkat
`strpos()` mencari posisi (**index**) pertama kemunculan substring dalam string. `strrpos()` mencari posisi kemunculan **terakhir**. Keduanya case-sensitive dan mengembalikan `false` jika tidak ditemukan.

## Analogi
Seperti mencari halaman pertama dan halaman terakhir di mana suatu kata muncul di dalam buku.

## Poin-Poin Penting
- `strpos(string $haystack, string $needle, int $offset = 0): int|false`
- Mengembalikan posisi (0-indexed) atau `false` jika tidak ditemukan.
- **Gunakan `===`** untuk mengecek `false` karena posisi 0 adalah falsy.
- `strrpos()` — cari dari kanan (kemunculan terakhir).
- `stripos()` / `strripos()` untuk versi case-insensitive.
- Parameter `$offset` bisa digunakan untuk mulai mencari dari posisi tertentu.
- PHP 8: `$needle` tidak boleh string kosong — akan error.

## Contoh Kode (PHP)
```php
<?php
$str = "Halo Dunia Halo";

echo strpos($str, "Dunia");      // 5
echo strrpos($str, "Halo");      // 11
echo strpos($str, "Bumi");       // false (tidak ditemukan)

// Cek dengan ===
if (strpos($str, "Halo") !== false) {
    echo "Ditemukan";            // Ditemukan
}

// Offset
echo strpos($str, "Halo", 1);    // 11 (mulai cari dari index 1)
?>
```

## Kasus Penggunaan Nyata
Mengecek apakah email mengandung '@', menemukan posisi ekstensi file, parsing URL, atau mencari keyword dalam string.
