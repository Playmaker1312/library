# 58. str_replace

## Definisi Singkat
`str_replace()` menggantikan semua kemunculan string pencarian dengan string pengganti di dalam string tertentu. Bersifat case-sensitive.

## Analogi
Seperti fitur "Find & Replace" di Word — cari kata tertentu lalu ganti dengan kata lain di seluruh dokumen sekaligus.

## Poin-Poin Penting
- `str_replace(mixed $search, mixed $replace, mixed $subject): string|array`
- `$search` dan `$replace` bisa berupa array untuk multiple replacement.
- Case-sensitive — gunakan `str_ireplace()` untuk case-insensitive.
- Jika `$subject` adalah array, fungsi memproses setiap elemen dan mengembalikan array.
- Tidak mengubah string asli (mengembalikan string baru).
- PHP 8: jika `$search` adalah string kosong, tidak ada perubahan.

## Contoh Kode (PHP)
```php
<?php
echo str_replace("Dunia", "PHP", "Halo Dunia"); // Halo PHP

// Multiple replacement
echo str_replace(["a", "e"], ["*", "3"], "Halo"); // H*l*

// str_ireplace (case-insensitive)
echo str_ireplace("php", "PHP", "Saya suka PHP"); // Saya suka PHP

// Dengan array subject
$result = str_replace("b", "B", ["ab", "bc"]);
print_r($result); // ["aB", "Bc"]
?>
```

## Kasus Penggunaan Nyata
Mengganti placeholder dalam template (contoh: `{{nama}}` dengan data user), membersihkan input dari karakter terlarang, atau masking data sensitif.
