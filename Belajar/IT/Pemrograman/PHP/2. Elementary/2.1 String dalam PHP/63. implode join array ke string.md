# 63. implode join — Array ke String

## Definisi Singkat
`implode()` menggabungkan elemen-elemen array menjadi satu string dengan separator tertentu. `join()` adalah alias dari `implode()` — sama persis.

## Analogi
Seperti merangkai manik-manik menjadi kalung — setiap manik (elemen array) dirangkai dengan tali (separator) sehingga menjadi satu rangkaian.

## Poin-Poin Penting
- `implode(string $separator, array $array): string`
- Parameter order: `implode($separator, $array)` atau `implode($array)` (tanpa separator, akan pakai `""`) — tapi cara pertama lebih disarankan.
- `join()` adalah alias — `join(",", $array)`.
- Kebalikan dari `explode()`.
- Jika array kosong, mengembalikan string kosong.
- Sejak PHP 8, parameter separator harus string (tidak boleh dilewati untuk konsistensi).

## Contoh Kode (PHP)
```php
<?php
$buah = ["apel", "mangga", "jeruk"];
echo implode(", ", $buah);      // apel, mangga, jeruk
echo implode(" | ", $buah);     // apel | mangga | jeruk

// join() alias
echo join(" - ", $buah);        // apel - mangga - jeruk

// Tanpa separator (hanya array)
echo implode($buah);            // apelmanggajeruk
?>
```

## Kasus Penggunaan Nyata
Menggabungkan tag artikel menjadi string, membuat CSV dari data array, menampilkan daftar error dalam satu baris, atau membangun query string.
