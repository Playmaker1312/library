# 52. Single Quote vs Double Quote

## Definisi Singkat
Perbedaan utama: **single quote** tidak menginterpolasi variabel dan hanya mengenali dua escape sequence (`\\` dan `\'`), sedangkan **double quote** menginterpolasi variabel dan mendukung semua escape sequence standar.

## Analogi
Single quote seperti fotokopi dokumen — hasilnya persis sama persis. Double quote seperti template surat yang otomatis mengisi nama penerima.

## Poin-Poin Penting
| Aspek | Single Quote | Double Quote |
|-------|-------------|-------------|
| Interpolasi variabel | Tidak | Ya |
| Escape `\n`, `\t` | Tidak | Ya |
| Escape `\\`, `\$` | `\\` ya, `\$` tidak perlu | Ya |
| Kinerja | Sedikit lebih cepat | Sedikit lebih lambat |
- Di PHP 8+, perbedaan kinerja sangat kecil, hampir tidak signifikan.
- Complex variable syntax (`{$var}`) hanya di double quote dan heredoc.

## Contoh Kode (PHP)
```php
<?php
$price = 50000;
echo 'Harga: $price';   // Harga: $price
echo "Harga: $price";   // Harga: 50000

// Escape sequence
echo 'It\'s okay';      // It's okay
echo "Baris 1\nBaris 2"; // Baris 1 (newline) Baris 2

// Complex syntax
echo "Total: {$price}0"; // Total: 500000
?>
```

## Kasus Penggunaan Nyata
Gunakan single quote untuk HTML class name, SQL query literal, atau array key agar tidak perlu escape. Double quote untuk string yang mengandung variabel dinamis.
