# 62. explode — Memecah String ke Array

## Definisi Singkat
`explode()` memecah string menjadi array berdasarkan delimiter (pemisah) tertentu.

## Analogi
Seperti memotong sosis — setiap kali pisau mengenai batas (delimiter), sosis terpotong menjadi potongan-potongan terpisah dalam wadah (array).

## Poin-Poin Penting
- `explode(string $separator, string $string, int $limit = PHP_INT_MAX): array`
- Jika `$separator` string kosong, PHP 8+ memberi error (sebelumnya warning).
- Jika delimiter tidak ditemukan, mengembalikan array dengan satu elemen (string utuh).
- Parameter `$limit`: positif = maksimal elemen; negatif = potong dari akhir; 0 = treat sebagai 1.
- `explode()` kebalikan dari `implode()`/`join()`.

## Contoh Kode (PHP)
```php
<?php
$csv = "apel,mangga,jeruk";
$buah = explode(",", $csv);
print_r($buah);
// Array ( [0] => apel [1] => mangga [2] => jeruk )

// Dengan limit
$parts = explode(",", "a,b,c,d", 2);
print_r($parts);
// Array ( [0] => a [1] => b,c,d )

// Delimiter tidak ditemukan
print_r(explode(";", "halo")); // [0] => halo
?>
```

## Kasus Penggunaan Nyata
Memecah data CSV, parsing query string, memisahkan tag yang dipisah koma, atau mengekstrak bagian-bagian dari path file.
