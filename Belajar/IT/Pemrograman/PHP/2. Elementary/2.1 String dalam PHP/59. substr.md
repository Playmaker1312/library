# 59. substr

## Definisi Singkat
`substr()` mengambil sebagian string (substring) berdasarkan posisi awal dan panjang tertentu. Untuk multibyte, gunakan `mb_substr()`.

## Analogi
Seperti memotong sepotong tali — tentukan mulai potong dari sentimeter ke berapa dan berapa panjang potongannya.

## Poin-Poin Penting
- `substr(string $string, int $offset, ?int $length = null): string`
- Jika `$offset` positif, mulai dari posisi itu (0-indexed).
- Jika `$offset` negatif, mulai dari posisi dari akhir string.
- Jika `$length` tidak diberikan, ambil sampai akhir string.
- Jika `$length` negatif, potong sejumlah karakter dari akhir.
- Gunakan `mb_substr()` untuk karakter multibyte (UTF-8).
- PHP 8: parameter null lebih ketat — `$length` boleh null.

## Contoh Kode (PHP)
```php
<?php
$str = "Halo Dunia";

echo substr($str, 0, 4);         // Halo
echo substr($str, 5);            // Dunia
echo substr($str, -5);           // Dunia
echo substr($str, 0, -6);        // Halo
echo substr($str, -5, 3);        // Dun

// Multibyte
echo mb_substr("café", 0, 3);    // caf
echo mb_substr("café", 3, 1);    // é
?>
```
