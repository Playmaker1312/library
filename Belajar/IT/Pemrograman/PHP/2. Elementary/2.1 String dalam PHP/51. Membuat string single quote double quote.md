# 51. Membuat String Single Quote Double Quote

## Definisi Singkat
String di PHP dapat dibuat dengan tanda petik satu (`'`) atau petik dua (`"`). Keduanya menghasilkan tipe data string tetapi memiliki perilaku berbeda dalam memproses variabel dan escape sequence.

## Analogi
Seperti label tempelan: petik satu adalah spidol permanen — apa yang ditulis ya itu hasilnya. Petik dua seperti papan tulis yang bisa mengganti isi variabel dengan nilainya secara otomatis.

## Poin-Poin Penting
- Petik satu (`'`) bersifat literal — hanya escape `\\` dan `\'` yang dikenali.
- Petik dua (`"`) memproses escape sequence (`\n`, `\t`, `\$`, dll) dan interpolasi variabel.
- Interpolasi variabel hanya terjadi pada string petik dua dan heredoc.
- PHP 8+ tidak mengubah aturan dasar ini.
- Gunakan petik satu untuk string tanpa variabel (lebih ringan).

## Contoh Kode (PHP)
```php
<?php
$name = "Andi";

echo 'Halo $name';     // Halo $name (tidak diinterpolasi)
echo "Halo $name";     // Halo Andi

echo 'Jalan\\raya';    // Jalan\raya
echo "Baris 1\nBaris 2"; // Baris 1 (newline) Baris 2
?>
```

## Kasus Penggunaan Nyata
Menyimpan teks statis (label, pesan error) dengan petik satu agar lebih cepat, dan string berisi variabel (contoh: salam sambutan) dengan petik dua.
