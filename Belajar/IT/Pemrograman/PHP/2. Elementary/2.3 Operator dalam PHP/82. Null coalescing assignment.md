# 82. Null Coalescing Assignment

## Definisi Singkat
Null coalescing assignment (`??=`) adalah shorthand untuk mengassign nilai ke variabel **hanya jika** variabel tersebut `null`. Tersedia sejak PHP 7.4.

## Analogi
Seperti "isi galon jika kosong" — Anda cek dulu galonnya: kalau masih terisi, biarkan; kalau kosong, baru isi. Tidak perlu mengecek ulang.

## Poin-Poin Penting
- `$x ??= $value` sama dengan `$x = $x ?? $value`.
- Hanya mengassign jika $x **null** (atau tidak diset).
- Tidak mengassign jika $x falsy tapi tidak null (0, "", false tidak terpengaruh).
- Lebih ringkas daripada `isset()` pattern.
- Tersedia sejak PHP 7.4.

## Contoh Kode (PHP)
```php
<?php
$items = null;
$items ??= ["default item"];
print_r($items);
// Array ( [0] => default item )

// Tidak mengubah jika sudah ada nilai
$name = "Andi";
$name ??= "Tamu";
echo $name; // Andi

// Berguna dengan array
$config = [];
$config["host"] ??= "localhost";
$config["port"] ??= 3306;
print_r($config);
// Array ( [host] => localhost [port] => 3306 )
?>
```

## Kasus Penggunaan Nyata
Memberikan default pada konfigurasi aplikasi, menginisialisasi cache yang mungkin null, atau mengisi data yang belum diset dalam array asosiatif tanpa menimpa yang sudah ada.
