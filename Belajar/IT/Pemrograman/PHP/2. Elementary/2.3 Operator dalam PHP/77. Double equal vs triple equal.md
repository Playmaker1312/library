# 77. Double Equal vs Triple Equal

## Definisi Singkat
`==` (loose equality) membandingkan nilai setelah **type juggling** (konversi tipe otomatis), sedangkan `===` (strict equality) membandingkan nilai **dan** tipe tanpa konversi.

## Analogi
`==` seperti menanyakan "apakah 5 sama dengan 5 apel?" — "ya, sama-sama 5". `===` seperti menanyakan "apakah 5 (integer) sama dengan 5 (string)?" — "tidak, berbeda jenis".

## Poin-Poin Penting
- `==` melakukan type coercion: `"5" == 5` → true.
- `===` tidak: `"5" === 5` → false.
- Di **PHP 8**, `==` lebih ketat: perbandingan string numerik dengan non-numerik tidak lagi dicocokkan.
- Selalu prioritaskan `===` untuk menghindari bug type juggling.
- Gunakan `==` hanya jika Anda secara eksplisit menginginkan type coercion.
- `!=` dan `!==` mengikuti aturan yang sama.

## Contoh Kode (PHP)
```php
<?php
var_dump(0 == "0");       // true (string "0" jadi int 0)
var_dump(0 == "");        // true (string kosong jadi 0)
var_dump(0 == false);     // true (false jadi 0)
var_dump(0 == null);      // true (null jadi 0)

var_dump(0 === "0");      // false
var_dump(0 === false);    // false

// PHP 8 — perbandingan numerik lebih ketat
var_dump("123abc" == 123); // false (PHP 8+), true (PHP 7.x)
var_dump("123" == 123);    // true (sama-sama numerik)
?>
```

## Kasus Penggunaan Nyata
`===` untuk cek `strpos()` return false (posisi 0 === false?), validasi tipe input, atau membandingkan nilai enum. `==` jarang digunakan kecuali untuk komparasi longgar.
