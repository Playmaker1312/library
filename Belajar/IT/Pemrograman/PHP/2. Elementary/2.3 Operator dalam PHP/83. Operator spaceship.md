# 83. Operator Spaceship

## Definisi Singkat
Operator spaceship (`<=>`) membandingkan dua ekspresi dan mengembalikan **-1, 0, atau 1** jika operand kiri lebih kecil, sama, atau lebih besar dari operand kanan. Tersedia sejak PHP 7.0.

## Analogi
Seperti timbangan digital yang menunjukkan hasil: -1 (kiri lebih ringan), 0 (sama berat), 1 (kiri lebih berat). Satu operasi memberikan tiga kemungkinan hasil.

## Poin-Poin Penting
- `$a <=> $b` mengembalikan: -1 jika $a < $b, 0 jika $a == $b, 1 jika $a > $b.
- Bekerja untuk int, float, string, array, objek yang comparable.
- Berguna untuk **usort() / uasort()** — cukup return `$a <=> $b`.
- Perbandingan mengikuti aturan yang sama dengan operator `==`, `<`, `>`.
- Di PHP 8+, behavior perbandingan string-string numerik lebih konsisten.

## Contoh Kode (PHP)
```php
<?php
echo 5 <=> 10;   // -1
echo 10 <=> 10;  // 0
echo 15 <=> 10;  // 1

echo "c" <=> "a"; // 1
echo "a" <=> "a"; // 0
echo "a" <=> "c"; // -1

// Untuk sorting
$data = [3, 1, 4, 1, 5];
usort($data, fn($a, $b) => $a <=> $b);
print_r($data);
// [1, 1, 3, 4, 5]

// Descending
usort($data, fn($a, $b) => $b <=> $a);
?>
```

## Kasus Penggunaan Nyata
Custom sorting array multidimensi (`usort`), implementasi Comparable interface, atau menentukan urutan prioritas dalam ranking.
