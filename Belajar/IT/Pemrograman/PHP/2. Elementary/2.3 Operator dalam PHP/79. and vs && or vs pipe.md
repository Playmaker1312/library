# 79. and vs && / or vs ||

## Definisi Singkat
`&&` dan `||` memiliki **prioritas lebih tinggi** daripada `and` dan `or`. Perbedaan prioritas ini dapat menyebabkan hasil evaluasi yang berbeda dalam ekspresi assignment.

## Analogi
`&&` dan `||` seperti eksekutif senior yang diprioritaskan duluan, `and` dan `or` seperti staf junior yang menunggu giliran setelah keputusan lain selesai.

## Poin-Poin Penting
- Prioritas: `&&` > `=` > `and` — sehingga `$x = true && false` dievaluasi sebagai `$x = (true && false)`.
- `$x = true and false` dievaluasi sebagai `($x = true) and false`.
- `||` vs `or` — perilaku sama, prioritas berbeda.
- Rekomendasi: `&&` dan `||` lebih aman dan lebih umum digunakan.
- `and` / `or` berguna dalam konstruksi `or die()` (legacy).

## Contoh Kode (PHP)
```php
<?php
$x = true && false;    // (true && false) → false
$y = true and false;   // (true) and false → $y = true
echo $x;               // false
echo $y;               // true

$a = false || true;    // (false || true) → true
$b = false or true;    // (false) or true → $b = false
echo $a;               // true
echo $b;               // false

// Legacy pattern (hindari)
$result = mysql_query($sql) or die("Error");
?>
```

## Kasus Penggunaan Nyata
Selalu gunakan `&&` dan `||` untuk kontrol flow yang jelas. Hindari `and`/`or` dalam assignment kecuali Anda memahami eksplisit prioritasnya.
