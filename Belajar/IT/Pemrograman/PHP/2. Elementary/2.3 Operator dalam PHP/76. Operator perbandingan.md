# 76. Operator Perbandingan

## Definisi Singkat
Operator perbandingan membandingkan dua nilai dan mengembalikan `true` atau `false`. Termasuk: `==`, `===`, `!=`, `!==`, `<`, `>`, `<=`, `>=`, `<=>`.

## Analogi
Seperti timbangan digital — Anda meletakkan dua benda dan timbangan memberi hasil: sama, tidak sama, lebih besar, atau lebih kecil.

## Poin-Poin Penting
| Operator | Nama | Keterangan |
|----------|------|-----------|
| `==` | Equal | Sama nilai (type juggling) |
| `===` | Identical | Sama nilai dan tipe |
| `!=` / `<>` | Not equal | Tidak sama nilai |
| `!==` | Not identical | Tidak sama nilai atau tipe |
| `<` | Less than | Kurang dari |
| `>` | Greater than | Lebih dari |
| `<=` | Less than or equal | Kurang dari atau sama |
| `>=` | Greater than or equal | Lebih dari atau sama |
| `<=>` | Spaceship | -1, 0, 1 (PHP 7+) |

- PHP 8+ perbandingan string-number lebih ketat (`"42" == 42` true, `"42abc" == 42` false di PHP 8+).

## Contoh Kode (PHP)
```php
<?php
var_dump(5 == "5");     // true (type juggling)
var_dump(5 === "5");    // false (tipe berbeda)
var_dump(5 != "5");     // false
var_dump(5 !== "5");    // true
var_dump(5 > 3);        // true
var_dump(5 <= 5);       // true

// PHP 8+ behavior
var_dump("42abc" == 42); // false (sejak PHP 8.0)
var_dump("42" == 42);    // true
?>
```

## Kasus Penggunaan Nyata
Validasi form untuk cek kesamaan password (`===`), menentukan harga dengan diskon (`$qty > 10`), atau mengecek hak akses user.
