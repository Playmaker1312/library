# 84. Operator String Concatenation

## Definisi Singkat
PHP menyediakan operator concatenation (penggabungan string) menggunakan titik (`.`). Secara teknis ini adalah operator string yang sama dengan `55. Concatenation operator titik`, dalam konteks lebih umum.

## Analogi
Seperti lem yang merekatkan dua kertas — hasilnya satu lembar kertas panjang dari dua lembar terpisah.

## Poin-Poin Penting
- `.` = concatenation operator (gabung dua string).
- `.=` = concatenating assignment (gabung lalu assign).
- Semua tipe data dikonversi ke string secara otomatis saat digabung.
- Untuk array, `array . string` tidak valid; akan error.
- Di PHP 8+, konversi numerik string lebih ketat.
- Concatenation di dalam echo dapat menggunakan koma (`,`), yang sedikit lebih cepat.

## Contoh Kode (PHP)
```php
<?php
$greeting = "Halo" . " " . "Dunia";
echo $greeting; // Halo Dunia

// Dengan tipe lain
$total = 100;
echo "Total: " . $total; // Total: 100

// Concatenating assignment
$msg = "Error: ";
$msg .= "File not found";
echo $msg; // Error: File not found

// Koma di echo lebih efisien
echo "Halo", " ", "Dunia"; // Halo Dunia (tanpa concatenation)
?>
```

## Kasus Penggunaan Nyata
Menyusun SQL query (walaupun prepared statement lebih baik), membangun HTML dinamis, atau membuat pesan log yang terdiri dari beberapa bagian data.
