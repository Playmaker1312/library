# 80. Operator Ternary

## Definisi Singkat
Operator ternary (`?:`) adalah shorthand `if-else` yang mengembalikan satu dari dua nilai berdasarkan kondisi: `$condition ? $valueIfTrue : $valueIfFalse`.

## Analogi
Seperti mesin penjual minuman: "Uang cukup? Dapat minuman. Tidak cukup? Dapat kembalian." Dua kemungkinan, satu keputusan.

## Poin-Poin Penting
- Sintaks: `(expr) ? true_value : false_value`
- Dapat **dirantai** (ternary bersarang), tapi kurang terbaca.
- **Elvis operator** (`?:`) — `$x ?: $default` sama dengan `$x ? $x : $default`.
- Hindari ternary bersarang lebih dari satu level.
- PHP 8+ tidak ada perubahan signifikan pada ternary.
- Parenthesis sangat disarankan untuk keterbacaan.

## Contoh Kode (PHP)
```php
<?php
$age = 20;
$status = ($age >= 18) ? "Dewasa" : "Anak-anak";
echo $status; // Dewasa

// Elvis operator
$username = $_GET["user"] ?: "Tamu";
echo $username; // "Tamu" jika $_GET["user"] kosong/null

// Ternary bersarang (hindari)
$result = ($a > $b) ? "A lebih" : (($a < $b) ? "B lebih" : "Sama");
?>
```

## Kasus Penggunaan Nyata
Menentukan class CSS aktif di menu (`$currentPage === 'home' ? 'active' : ''`), memformat tampilan berdasarkan kondisi, atau memberikan default value singkat.
