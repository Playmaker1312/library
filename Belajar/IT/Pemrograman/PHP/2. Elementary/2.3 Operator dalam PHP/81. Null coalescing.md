# 81. Null Coalescing

## Definisi Singkat
Null coalescing operator (`??`) mengembalikan operand kiri jika tidak `null`, jika `null` maka kembalikan operand kanan. Tersedia sejak PHP 7.0.

## Analogi
Seperti helm cadangan di motor: "Punya helm? Pakai helm sendiri. Tidak punya? Pakai helm cadangan." Selalu ada opsi default kalau yang utama tidak ada.

## Poin-Poin Penting
- `$x ?? $default` sama dengan `isset($x) ? $x : $default`.
- Berbeda dengan Elvis (`?:`) — `??` mengecek **null**, sedangkan `?:` mengecek **falsy**.
- Bisa dirantai: `$a ?? $b ?? $c ?? 'default'`.
- Tidak menghasilkan `E_NOTICE` jika variabel tidak ada (aman).
- PHP 8+ — bisa digunakan untuk properti objek: `$user->profile->name ?? 'Tamu'`.

## Contoh Kode (PHP)
```php
<?php
$name = $_GET["name"] ?? "Tamu";
echo $name; // "Tamu" jika $_GET["name"] tidak diset atau null

// Rantai
$value = $a ?? $b ?? $c ?? "default";
echo $value;

// Perbedaan dengan elvis
$count = 0;
echo $count ?: 10;  // 10 (karena 0 falsy)
echo $count ?? 10;  // 0 (karena 0 !== null)

// Properti objek
echo $user->bio ?? "Tidak ada bio";
?>
```

## Kasus Penggunaan Nyata
Mengambil input form dengan default (`$_POST["username"] ?? ""`), membaca konfigurasi dengan fallback, atau mengakses nested array/objek tanpa error.
