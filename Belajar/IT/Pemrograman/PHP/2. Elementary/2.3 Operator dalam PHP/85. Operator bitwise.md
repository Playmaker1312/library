# 85. Operator Bitwise

## Definisi Singkat
Operator bitwise bekerja pada level **bit** (biner) dari integer: `&` (AND), `|` (OR), `^` (XOR), `~` (NOT), `<<` (shift left), `>>` (shift right).

## Analogi
Seperti saklar lampu individual di sebuah panel — setiap bit adalah satu saklar. Operator bitwise memungkinkan Anda menyalakan/mematikan saklar tertentu tanpa menyentuh yang lain.

## Poin-Poin Penting
| Operator | Nama | Contoh |
|----------|------|--------|
| `&` | AND | `5 & 3` = 1 |
| `\|` | OR (pipe) | `5 \| 3` = 7 |
| `^` | XOR | `5 ^ 3` = 6 |
| `~` | NOT | `~5` = -6 |
| `<<` | Shift left | `5 << 1` = 10 |
| `>>` | Shift right | `5 >> 1` = 2 |
- Berguna untuk **flags/permissions** — kombinasi izin dalam satu integer.
- PHP 8+ — shift dengan nilai negatif atau melebihi bit-width menghasilkan ValueError.
- Operator `&` dan `|` berbeda dengan `&&` dan `||` (logika vs bitwise).

## Contoh Kode (PHP)
```php
<?php
// Bitwise
echo 5 & 3;   // 1  (101 & 011 = 001)
echo 5 | 3;   // 7  (101 | 011 = 111)
echo 5 ^ 3;   // 6  (101 ^ 011 = 110)
echo ~5;      // -6 (bitwise not)
echo 5 << 1;  // 10 (1010)
echo 5 >> 1;  // 2  (10)

// Flags pattern
define("READ", 1);    // 001
define("WRITE", 2);   // 010
define("EXECUTE", 4); // 100

$permissions = READ | WRITE; // 011 (3)
echo $permissions & READ;    // 1 (true — bisa baca)
echo $permissions & EXECUTE; // 0 (false — tidak bisa eksekusi)
?>
```

## Kasus Penggunaan Nyata
Manajemen permission sistem (Unix-style chmod), pengaturan flag pada gambar (GD/Imagick), optimasi penyimpanan multiple boolean dalam satu field database integer, atau kriptografi.
