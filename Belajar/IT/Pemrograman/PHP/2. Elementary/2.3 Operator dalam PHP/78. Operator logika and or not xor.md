# 78. Operator Logika and or not xor

## Definisi Singkat
Operator logika: `and` (&&), `or` (||), `not` (!), `xor` (exclusive or) — digunakan untuk mengombinasikan ekspresi boolean.

## Analogi
Seperti petugas keamanan: AND ("keduanya harus lulus"), OR ("salah satu lulus"), NOT ("kebalikan"), XOR ("hanya satu yang lulus, tidak keduanya").

## Poin-Poin Penting
| Operator | Nama | Hasil true jika |
|----------|------|----------------|
| `$a and $b` / `$a && $b` | And | Keduanya true |
| `$a or $b` / `$a \|\| $b` | Or | Salah satu atau keduanya true |
| `!$a` / `not $a` | Not | $a false |
| `$a xor $b` | Xor | Salah satu true, tapi tidak keduanya |
- `||` / `&&` memiliki prioritas lebih tinggi dari `or` / `and`.
- Short-circuit: jika hasil sudah bisa ditentukan dari operand kiri, operand kanan tidak dievaluasi.

## Contoh Kode (PHP)
```php
<?php
$a = true;
$b = false;

var_dump($a && $b); // false
var_dump($a || $b); // true
var_dump(!$a);      // false
var_dump($a xor $b); // true
var_dump($b xor $b); // false

// Short-circuit
$result = false && someFunction(); // someFunction() tidak dipanggil
?>
```

## Kasus Penggunaan Nyata
Cek akses user (`$isAdmin || $isOwner`), validasi form (`$email && $password`), atau menentukan kondisi kompleks dalam if statement.
