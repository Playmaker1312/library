# 67. Increment Decrement

## Definisi Singkat
Operator `++` menambah nilai variabel dengan 1, operator `--` mengurangi dengan 1. Ada dua bentuk: prefix (`++$x`) dan postfix (`$x++`).

## Analogi
Seperti penghitung klik di gerbang masuk: prefix seperti "dihitung dulu baru masuk", postfix seperti "masuk dulu baru dihitung".

## Poin-Poin Penting
| Operator | Nama | Deskripsi |
|----------|------|-----------|
| `++$x` | Pre-increment | Naikkan $x, lalu kembalikan nilai |
| `$x++` | Post-increment | Kembalikan $x, lalu naikkan |
| `--$x` | Pre-decrement | Turunkan $x, lalu kembalikan |
| `$x--` | Post-decrement | Kembalikan $x, lalu turunkan |
- Hanya bekerja pada variabel, bukan pada literal (++5 error).
- PHP 8+ — increment/decrement pada objek tidak lagi didukung kecuali properti numerik.
- Tidak berlaku untuk string non-numerik (post-increment string didukung hingga PHP 8.x).

## Contoh Kode (PHP)
```php
<?php
$x = 5;
echo ++$x;  // 6 (pre: $x jadi 6, lalu echo 6)
echo $x;    // 6

$y = 5;
echo $y++;  // 5 (post: echo 5, lalu $y jadi 6)
echo $y;    // 6

for ($i = 0; $i < 3; $i++) {
    echo $i; // 0 1 2
}
?>
```

## Kasus Penggunaan Nyata
Counter dalam loop (`for`), pagination (halaman berikutnya), atau tracking jumlah item yang diproses dalam iterasi.
