# 70. abs — Nilai Absolut

## Definisi Singkat
`abs()` mengembalikan nilai absolut (nilai positif) dari suatu angka. Jika input negatif, hasilnya positif; jika sudah positif, tetap sama.

## Analogi
Seperti jarak — jarak dari rumah ke sekolah 5 km, baik Anda jalan maju atau mundur, jaraknya tetap 5 km (positif).

## Poin-Poin Penting
- `abs(int|float $num): int|float`
- Tipe kembalian: jika input int, hasil int; jika float, hasil float.
- Jika nilai `PHP_INT_MIN` absolutnya overflow menjadi negatif (karena int range).
- PHP 8+ — strict type hinting: parameter hanya int|float.

## Contoh Kode (PHP)
```php
<?php
echo abs(-10);       // 10
echo abs(10);        // 10
echo abs(-3.14);     // 3.14
echo abs(0);         // 0

// Overflow pada PHP_INT_MIN
echo abs(PHP_INT_MIN); // float positif (karena overflow)
?>
```

## Kasus Penggunaan Nyata
Menghitung selisih absolut dua angka (misal beda suhu, jarak koordinat), menormalisasi nilai negatif dari hasil kalkulasi, atau memvalidasi margin error.
