# 68. Operator Penugasan

## Definisi Singkat
Operator penugasan (`=`) memberikan nilai ke variabel. **Assignment by reference** (`= &`) membuat alias, sedangkan **assignment by value** (default) menyalin nilai.

## Analogi
Seperti menulis di papan tulis: `=` berarti "tuliskan nilai ini di papan". Gabungan operator (`+=`, `.=`) seperti "ambil nilai yang sudah ada, operasikan, lalu tulis ulang".

## Poin-Poin Penting
- Operator gabungan: `+=`, `-=`, `*=`, `/=`, `%=`, `**=`, `.=`, `&=`, `|=`, `^=`, `<<=`, `>>=`.
- Semua operator gabungan: `$x += 5` sama dengan `$x = $x + 5`.
- Assignment by reference (`=&`) membuat alias — kedua variabel menunjuk ke memori sama.
- PHP 8+ — assignment pada ekspresi non-variabel error (misal `(foo()) = 5`).

## Contoh Kode (PHP)
```php
<?php
$x = 10;
$x += 5;    // $x = 15
$x -= 3;    // $x = 12
$x *= 2;    // $x = 24
$x /= 4;    // $x = 6
$x **= 2;   // $x = 36

$str = "Halo";
$str .= " "; // $str = "Halo "
$str .= "Dunia"; // $str = "Halo Dunia"

// Reference assignment
$a = 10;
$b =& $a;
$b = 20;
echo $a;    // 20
?>
```

## Kasus Penggunaan Nyata
Akumulasi total belanja (`$total += $harga`), membangun string panjang (`$html .= "<div>...</div>"`), atau menggunakan reference untuk memodifikasi array besar tanpa copy.
