# 74. number_format

## Definisi Singkat
`number_format()` memformat angka dengan pengelompokan ribuan dan desimal sesuai standar lokal. Berguna untuk menampilkan harga atau statistik.

## Analogi
Seperti mesin kasir yang otomatis menambahkan titik ribuan dan koma desimal pada struk belanja.

## Poin-Poin Penting
- `number_format(float $num, int $decimals = 0, ?string $decimal_separator = ".", ?string $thousands_separator = ","): string`
- Jika hanya satu parameter: format tanpa desimal, koma ribuan.
- Jika dua parameter: `$decimals`, separator default `.` dan `,`.
- Jika empat parameter: kustom separator desimal dan ribuan.
- **Hasilnya string**, bukan float — tidak bisa digunakan untuk kalkulasi langsung.
- Pembulatan terjadi sesuai `$decimals`.
- PHP 8+ — parameter nullable diperbolehkan.

## Contoh Kode (PHP)
```php
<?php
echo number_format(1500000);            // 1,500,000
echo number_format(1500000, 2);         // 1,500,000.00
echo number_format(1500000, 2, ",", "."); // 1.500.000,00

// Dengan desimal
echo number_format(12345.678, 2);       // 12,345.68
echo number_format(99.9, 0);            // 100 (pembulatan)
?>
```

## Kasus Penggunaan Nyata
Menampilkan harga produk (Rp1.500.000,00), menampilkan total penjualan, memformat persentase, atau menampilkan statistik dengan separator ribuan.
