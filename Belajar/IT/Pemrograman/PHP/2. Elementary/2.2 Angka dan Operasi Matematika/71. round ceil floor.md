# 71. round ceil floor

## Definisi Singkat
`round()` membulatkan float ke bilangan terdekat, `ceil()` membulatkan ke atas (ke tak hingga), `floor()` membulatkan ke bawah (ke negatif tak hingga).

## Analogi
Seperti membulatkan nilai rapor: round (4.4 → 4, 4.5 → 5), ceil (4.1 → 5 — naik), floor (4.9 → 4 — turun).

## Poin-Poin Penting
- `round(float $num, int $precision = 0, int $mode = PHP_ROUND_HALF_UP): float`
- `$precision`: jumlah digit desimal (bisa negatif untuk bulatkan puluhan/ribuan).
- `$mode`: `PHP_ROUND_HALF_UP` (default), `PHP_ROUND_HALF_DOWN`, `PHP_ROUND_HALF_EVEN`, `PHP_ROUND_HALF_ODD`.
- `ceil(float $num): float` — selalu ke atas.
- `floor(float $num): float` — selalu ke bawah.
- Hati-hati: `floor(-3.4)` = -4 (karena ke bawah = -4 lebih kecil).

## Contoh Kode (PHP)
```php
<?php
echo round(3.4);       // 3
echo round(3.5);       // 4
echo round(3.678, 2);  // 3.68
echo round(1234, -2);  // 1200

echo ceil(4.1);        // 5
echo ceil(-3.9);       // -3

echo floor(4.9);       // 4
echo floor(-3.1);      // -4

// Mode ganjil/genap
echo round(2.5, 0, PHP_ROUND_HALF_EVEN); // 2
?>
```

## Kasus Penggunaan Nyata
`round`: membulatkan harga ke 2 desimal. `ceil`: menentukan jumlah halaman pagination (`ceil($total / $perPage)`). `floor`: menghitung diskon atau menentukan harga pembulatan ke bawah.
