# 75. Konstanta M_PI M_E

## Definisi Singkat
`M_PI` adalah konstanta matematika π (3.141592...), `M_E` adalah konstanta Euler e (2.718281...). Keduanya didefinisikan jika ekstensi `math` diaktifkan (atau di PHP 8+ via `php.ini`).

## Analogi
Seperti konstanta umum yang sudah ditulis di papan tulis kelas matematika — tidak perlu menghafal atau menghitung ulang, tinggal pakai.

## Poin-Poin Penting
- `M_PI` = 3.14159265358979323846 (π)
- `M_E` = 2.71828182845904523536 (e)
- Tersedia jika `php.ini` memiliki `define_syslog_variables` atau ekstensi matematika diaktifkan.
- Di PHP 8+, konstanta ini tetap tersedia tanpa perlu konfigurasi khusus.
- Konstanta lain: `M_PI_2` (π/2), `M_PI_4` (π/4), `M_1_PI` (1/π), `M_SQRT2` (√2), `M_LN2` (ln 2).
- Bisa juga gunakan fungsi: `pi()`.

## Contoh Kode (PHP)
```php
<?php
echo M_PI;          // 3.1415926535898
echo M_E;           // 2.718281828459

echo pi();          // 3.1415926535898 (sama dengan M_PI)

// Hitung luas lingkaran
$radius = 10;
$area = M_PI * $radius ** 2;
echo $area;         // 314.15926535898

echo M_SQRT2;       // 1.4142135623731 (√2)
echo M_LN2;         // 0.69314718055995 (ln 2)
?>
```

## Kasus Penggunaan Nyata
Kalkulasi geometri (luas lingkaran, volume bola), perhitungan ilmiah (statistik, fisika), atau aplikasi kriptografi yang menggunakan konstanta e.
