# 69. Operator Precedence

## Definisi Singkat
Operator precedence (prioritas operator) menentukan urutan evaluasi ekspresi ketika beberapa operator digunakan bersamaan. Operator dengan prioritas lebih tinggi dievaluasi lebih dulu.

## Analogi
Seperti aturan "kali-bagi dikerjakan dulu sebelum tambah-kurang" di matematika — sama seperti aturan di sekolah dasar.

## Poin-Poin Penting
- Urutan prioritas (tinggi ke rendah): `()` → `**` → `* / %` → `+ -` → `== !=` → `&&` → `||`.
- `**` bersifat **right-associative** (dari kanan ke kiri).
- `=` (assignment) prioritas paling rendah bersama `=>`.
- `and`, `or` lebih rendah prioritasnya dari `=`.
- **Gunakan kurung `()`** untuk memperjelas maksud daripada mengandalkan precedence.

## Contoh Kode (PHP)
```php
<?php
echo 2 + 3 * 4;      // 14 (kali dulu)
echo (2 + 3) * 4;    // 20

echo 2 ** 3 ** 2;    // 512 (right-associative: 2**(3**2))

// Perangkap and/or
$x = true && false;   // false (&& lebih tinggi dari =)
$y = true and false;  // true (and lebih rendah dari =)
echo $x;              // false
echo $y;              // true
?>
```

## Kasus Penggunaan Nyata
Menghindari bugs dengan selalu menggunakan kurung pada ekspresi kompleks, terutama saat menggabungkan operator logika dan perbandingan.
