# 73. rand mt_rand

## Definisi Singkat
`rand()` menghasilkan bilangan acak, sedangkan `mt_rand()` menggunakan algoritma Mersenne Twister yang lebih cepat dan lebih acak. Untuk keperluan kriptografis, gunakan `random_int()`.

## Analogi
Seperti dadu: `rand` dadu biasa, `mt_rand` dadu elektronik yang lebih seimbang. Tapi untuk undian berhadiah serius, gunakan `random_int` yang benar-benar tidak bisa diprediksi.

## Poin-Poin Penting
- `rand(int $min, int $max): int` — jangan gunakan untuk kriptografi.
- `mt_rand(int $min, int $max): int` — lebih cepat, periode lebih panjang.
- Sejak PHP 7.1, `rand()` dan `mt_rand()` menggunakan algoritma yang sama (Mersenne Twister).
- **Untuk kriptografi**: `random_int()` (PHP 7.0+) — aman, unpredictable.
- `mt_srand()` / `srand()` untuk seed (terutama testing).
- PHP 8.2+ — `mt_rand()` seeded secara otomatis per request.

## Contoh Kode (PHP)
```php
<?php
echo rand(1, 10);       // Acak 1-10
echo mt_rand(1, 100);   // Acak 1-100

// Untuk kriptografi
$secure = random_int(1, 100);
echo $secure;

// Generate token acak (hex)
echo bin2hex(random_bytes(16)); // 32 karakter hex
?>
```

## Kasus Penggunaan Nyata
`rand`/`mt_rand`: shuffle konten, memilih item acak (misal quote of the day), generate nomor dummy. `random_int`/`random_bytes`: generate token CSRF, password reset link, API key.
