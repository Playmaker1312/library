# 72. max min

## Definisi Singkat
`max()` mengembalikan nilai terbesar, `min()` mengembalikan nilai terkecil dari kumpulan angka atau array.

## Analogi
Seperti mencari siswa tertinggi dan terpendek di kelas — max (paling tinggi), min (paling pendek).

## Poin-Poin Penting
- `max(mixed $value, mixed ...$values): mixed`
- Menerima array sebagai argumen tunggal atau dua+ nilai terpisah.
- Jika salah satu nilai bukan numerik, dilakukan perbandingan dengan aturan PHP.
- `min()` dan `max()` bekerja dengan array dan Traversable.
- String dibandingkan secara leksikografis jika campuran tipe.
- PHP 8+: perbandingan tipe campuran lebih ketat.

## Contoh Kode (PHP)
```php
<?php
echo max(3, 7, 2, 9, 5);           // 9
echo min(3, 7, 2, 9, 5);           // 2

echo max([10, 20, 5, 8]);          // 20
echo min([10, 20, 5, 8]);          // 5

// Dengan string
echo max("apel", "mangga", "jeruk"); // apel (secara leksikografis)
echo max(10, "20");                  // 20
?>
```

## Kasus Penggunaan Nyata
Menentukan harga tertinggi/terendah dari array produk, mencari tanggal terbaru/terlama, membatasi nilai agar tidak melebihi range (`min(100, max(0, $value))`).
