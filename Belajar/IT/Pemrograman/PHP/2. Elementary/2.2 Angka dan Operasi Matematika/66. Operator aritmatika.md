# 66. Operator Aritmatika

## Definisi Singkat
Operator aritmatika digunakan untuk melakukan operasi matematika dasar pada tipe numerik (int/float) di PHP: `+`, `-`, `*`, `/`, `%`, `**`.

## Analogi
Seperti kalkulator saku — tombol tambah, kurang, kali, bagi, modulus, dan pangkat untuk menghitung angka.

## Poin-Poin Penting
| Operator | Nama | Contoh | Hasil |
|----------|------|--------|-------|
| `+` | Penjumlahan | `5 + 3` | `8` |
| `-` | Pengurangan | `5 - 3` | `2` |
| `*` | Perkalian | `5 * 3` | `15` |
| `/` | Pembagian | `5 / 2` | `2.5` (float) |
| `%` | Modulus (sisa bagi) | `5 % 2` | `1` |
| `**` | Pangkat (PHP 5.6+) | `5 ** 2` | `25` |
- Pembagian dengan nol menghasilkan `DivisionByZeroError` di PHP 8+.
- Operator `**` lebih jelas daripada `pow()`.

## Contoh Kode (PHP)
```php
<?php
echo 10 + 3;   // 13
echo 10 - 3;   // 7
echo 10 * 3;   // 30
echo 10 / 3;   // 3.3333333333
echo 10 % 3;   // 1
echo 10 ** 3;  // 1000

// Prioritas
echo 2 + 3 * 4;   // 14
echo (2 + 3) * 4; // 20
?>
```

## Kasus Penggunaan Nyata
Menghitung total harga (perkalian qty * price), menghitung diskon (pengurangan), menentukan halaman dari jumlah data (modulus untuk pagination), atau kalkulasi matematika.
