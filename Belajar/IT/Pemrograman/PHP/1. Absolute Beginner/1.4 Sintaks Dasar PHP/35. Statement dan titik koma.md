# 35. Statement dan titik koma

## Definisi Singkat
Setiap statement (pernyataan) di PHP harus diakhiri dengan titik koma (`;`). Titik koma menandakan akhir dari satu instruksi, mirip seperti tanda titik di akhir kalimat.

## Analogi
Titik koma di PHP seperti lampu lalu lintas hijau untuk setiap persimpangan: setiap kali Anda melewati persimpangan (statement selesai), lampu hijau (`;`) memberi tahu mobil berikutnya (statement selanjutnya) untuk jalan. Tanpa lampu, terjadi tabrakan (error).

## Poin-Poin Penting
- Lupa titik koma menyebabkan Parse Error: "syntax error, unexpected..."
- Statement terakhir sebelum `?>` boleh tanpa titik koma (tapi jangan biasakan)
- Beberapa statement bisa dalam satu baris, dipisah titik koma
- Satu statement bisa beberapa baris (titik koma di akhir)
- Tag penutup `?>` mengimplisitkan titik koma untuk statement terakhir
- Tidak perlu titik koma setelah kurung kurawal `}`, kecuali untuk deklarasi konstan/expression
- `;` sendiri adalah empty statement (valid, tidak melakukan apa-apa)

## Contoh Kode (PHP)
```php
<?php
// Titik koma di setiap akhir statement
$nama = "Budi";
echo "Halo ";
echo "dunia!";

// Satu baris - banyak statement (valid tapi kurang terbaca)
$x = 5; $y = 10; $z = $x + $y; echo $z;

// Statement multi-baris (titik koma di akhir)
$panjang_string = "Ini adalah string yang sangat panjang "
    . "sehingga ditulis dalam beberapa baris "
    . "untuk readability yang lebih baik.";

// Hati-hati: titik koma sebelum tutup kurung
if ($x > 0) {
    echo "Positif"; // titik koma di sini
} // TIDAK pakai titik koma setelah }
?>
```

## Kasus Penggunaan Nyata
Saat coding, biasakan menekan `;` setelah setiap statement. Code editor seperti VS Code dengan Intelephense akan memberi tahu jika lupa titik koma dengan garis merah. Gunakan auto-formatting (Shift+Alt+F) untuk memperbaiki.
