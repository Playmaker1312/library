# 38. Case sensitivity PHP

## Definisi Singkat
Di PHP, nama variabel dan properti bersifat case-sensitive (`$nama` berbeda dengan `$Nama`), tetapi keyword, function, dan class names bersifat case-insensitive (`ECHO` sama dengan `echo`).

## Analogi
Seperti sistem KTP: nama orang (variabel) harus persis sama - "Budi" berbeda dengan "budi" atau "BUDI". Tapi nama jabatan (keyword) tidak sensitif - "DIREKTUR" sama dengan "direktur". Anda bisa manggil "Pak Direktur" atau "pak direktur", tetap sama.

## Poin-Poin Penting
- **Case-sensitive**: variabel (`$user`, `$User`), array keys, constants (define), properti objek
- **Case-insensitive**: function name, class name, keyword (`if`, `else`, `echo`, `foreach`, `while`)
- Best practice: tetap gunakan casing konsisten (camelCase untuk variabel/fungsi, PascalCase untuk class)
- Konstanta `define("NAMA", "value")` case-sensitive default, bisa diubah: `define("NAMA", "value", true)` (tidak direkomendasikan)
- Konstanta `const` selalu case-sensitive
- Magical constants (`__FILE__`, `__LINE__`) selalu UPPERCASE
- `true`, `false`, `null` case-insensitive (TRUE, True, true sama)
- PHP 8+ tetap mempertahankan aturan ini

## Contoh Kode (PHP)
```php
<?php
// Variabel: case-sensitive
$nama = "Budi";
$Nama = "Ani";
$NAMA = "Cici";
echo "$nama, $Nama, $NAMA<br>"; // Budi, Ani, Cici

// Function: case-insensitive
function sapa($name) {
    return "Halo $name";
}
echo SAPA("Doni") . "<br>"; // Halo Doni (function dipanggil berbeda casing)

// Keyword: case-insensitive
ECHO "Ini menggunakan ECHO<br>"; // valid
Foreach (["a", "b"] as $item) {
    echo "$item ";
}
?>
```

## Kasus Penggunaan Nyata
Saat migrasi dari framework lama ke Laravel, perhatikan bahwa nama variabel session `$_SESSION['user']` berbeda dengan `$_SESSION['User']`. Bug sering terjadi karena typo casing pada variabel. Gunakan IDE dengan type hinting untuk menghindari ini.
