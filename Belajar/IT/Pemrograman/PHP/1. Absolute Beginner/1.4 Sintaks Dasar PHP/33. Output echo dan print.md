# 33. Output echo dan print

## Definisi Singkat
`echo` dan `print` adalah konstruksi bahasa PHP untuk menampilkan output ke browser. `echo` lebih cepat dan bisa menerima multiple parameter, `print` mengembalikan nilai 1 dan hanya bisa satu parameter.

## Analogi
Echo seperti speaker umum di stasiun: bisa menyiarkan banyak pengumuman sekaligus (multiple parameter), tidak ada konfirmasi apakah berhasil. Print seperti kasir yang memberikan struk (return value 1), hanya bisa satu transaksi per waktu.

## Poin-Poin Penting
- `echo` bukan fungsi, melainkan language construct - tidak butuh tanda kurung
- `echo "Halo";` - valid tanpa kurung
- `echo("Halo");` - valid dengan kurung
- `echo "A", "B", "C";` - valid, output "ABC"
- `print "A";` - valid, return 1
- `print("A", "B");` - INVALID, hanya satu argumen
- `$result = print("A");` - valid, $result bernilai 1
- `echo` sedikit lebih cepat dari `print`
- Keduanya bisa menggunakan single quote (`'`) atau double quote (`"`)
- Double quote menginterpretasi variabel di dalamnya

## Contoh Kode (PHP)
```php
<?php
// Echo - multiple parameter
echo "Halo ", "dari ", "PHP", "<br>";

// Echo dengan variabel (double quote)
$nama = "Ani";
echo "Nama saya $nama<br>";

// Print - return value
$hasil = print("Ini dari print<br>");
echo "Print mengembalikan: $hasil<br>"; // 1

// Perbedaan kutip
echo 'Variabel $nama tidak akan dieksekusi<br>';
echo "Variabel $nama akan dieksekusi<br>";
?>
```

## Kasus Penggunaan Nyata
Gunakan `echo` di 99% kasus karena lebih cepat dan fleksibel. Gunakan `print` jika Anda butuh return value (misal dalam ekspresi ternary): `$loggedIn ? print("Welcome") : print("Login");` - tapi lebih baik pakai `echo` dengan ternary biasa.
