# 40. Whitespace dan indentation

## Definisi Singkat
PHP mengabaikan whitespace berlebih (spasi, tab, newline) di luar string. Indentation bertujuan untuk readability kode, bukan untuk syntax. PHP tidak seperti Python yang menggunakan indentasi sebagai blok kode.

## Analogi
PHP seperti ruang kerja yang rapi atau berantakan: mesin (interpreter) tetap bisa membaca tulisan Anda meskipun kertas berantakan. Tapi untuk Anda sendiri, meja rapi (indentasi konsisten) membuat kerja lebih efisien dan nyaman.

## Poin-Poin Penting
- PHP menggunakan kurung kurawal `{}` untuk blok kode (bukan indentasi)
- Indentasi 4 spasi adalah standar PSR-12 (atau 1 tab sesuai preferensi tim)
- Konsistensi lebih penting daripada jumlah spasi
- Newline dan spasi berlebih tidak mempengaruhi eksekusi
- Whitespace di dalam string (`" "`) diperhitungkan
- Whitespace di HTML output bisa diperhatikan (tapi bukan error)
- Gunakan auto-formatting di VS Code (Shift+Alt+F) untuk merapikan
- PHP CodeSniffer atau PHP-CS-Fixer bisa otomatis memformat sesuai standar
- Hindari mencampur tab dan spasi dalam satu file

## Contoh Kode (PHP)
```php
<?php
// Kode dengan indentasi baik (PSR-12)
$items = ["Apel", "Mangga", "Jeruk"];

foreach ($items as $item) {
    if (strlen($item) > 4) {
        echo "$item memiliki nama panjang<br>";
    } else {
        echo "$item memiliki nama pendek<br>";
    }
}

// Kode tanpa indentasi (valid, tapi sulit dibaca)
$items = ["Apel", "Mangga", "Jeruk"];
foreach ($items as $item) {
if (strlen($item) > 4) {
echo "$item memiliki nama panjang<br>";
} else {
echo "$item memiliki nama pendek<br>";
}
}
?>
```

## Kasus Penggunaan Nyata
Di project tim, gunakan `.editorconfig` di root project untuk konsistensi indentasi. Gunakan juga PHP-CS-Fixer dalam pre-commit hook agar semua developer memiliki gaya penulisan yang sama.
