# 39. PHP campur HTML

## Definisi Singkat
PHP bisa ditulis langsung di dalam file HTML dengan beralih antara mode PHP (di dalam `<?php ... ?>`) dan mode HTML (di luar tag). Sangat berguna untuk template dan view.

## Analogi
Seperti membuat scrapbook: Anda menulis catatan (PHP) di sticky notes, lalu menempelkannya di halaman album (HTML). Catatan bisa dihapus/diganti kapan saja, tapi halaman album tetap utuh. Hasil akhirnya adalah halaman scrapbook yang indah (HTML murni).

## Poin-Poin Penting
- File dengan campuran PHP dan HTML biasanya berekstensi `.php`
- Alternating syntax: gunakan `<?php ... ?>` untuk logika, HTML untuk markup
- Struktur kontrol bisa dengan colon syntax: `<?php if (kondisi): ?>` HTML `<?php endif; ?>`
- Colon syntax lebih bersih untuk template yang banyak HTML
- Hindari logika kompleks di dalam template - pindahkan ke controller/logic layer
- Template engine seperti Blade (Laravel) atau Twig (Symfony) menyediakan syntax lebih bersih
- Alirkan variabel dari PHP ke HTML dengan `<?= $var ?>`
- PSR-12 merekomendasikan indentasi yang konsisten saat campur HTML

## Contoh Kode (PHP)
```php
<?php
$title = "Halaman Profil";
$user = ["nama" => "Budi", "umur" => 25, "aktif" => true];
$produk = ["Laptop", "Mouse", "Keyboard"];
?>
<!DOCTYPE html>
<html>
<head>
    <title><?= $title ?></title>
</head>
<body>
    <h1>Profil: <?= $user['nama'] ?></h1>
    <p>Umur: <?= $user['umur'] ?></p>

    <?php if ($user['aktif']): ?>
        <span style="color: green">Aktif</span>
    <?php else: ?>
        <span style="color: red">Tidak Aktif</span>
    <?php endif; ?>

    <ul>
        <?php foreach ($produk as $p): ?>
            <li><?= $p ?></li>
        <?php endforeach; ?>
    </ul>
</body>
</html>
```

## Kasus Penggunaan Nyata
Buat file `profil.php` yang menerima data user dari database, lalu tampilkan dalam HTML. Logika pengambilan data di atas file, tampilan di bawah dengan campuran PHP-HTML. Ini pola dasar MVC (Model-View-Controller) sederhana.
