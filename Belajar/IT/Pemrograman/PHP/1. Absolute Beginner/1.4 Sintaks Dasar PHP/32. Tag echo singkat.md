# 32. Tag echo singkat

## Definisi Singkat
`<?= ?>` adalah tag echo singkat di PHP yang merupakan shortcut untuk `<?php echo ... ?>`. Mulai PHP 5.4+, tag ini selalu tersedia tanpa perlu mengaktifkan `short_open_tag`.

## Analogi
Seperti tombol "print screen" di keyboard: Anda tidak perlu buka aplikasi Paint → paste → save (<?php echo ... ?>). Cukup tekan satu tombol (`<?= ... ?>`), langsung jadi. Sama cepat dan praktis.

## Poin-Poin Penting
- `<?= $variable ?>` setara dengan `<?php echo $variable; ?>`
- Bisa digunakan dengan ekspresi: `<?= 5 + 3 ?>`, `<?= date('Y') ?>`
- Bisa digunakan dengan fungsi: `<?= htmlspecialchars($text) ?>`
- Tidak bisa digunakan untuk statement kompleks: `<?= if ... ?>` tidak valid
- Sangat berguna di template/view untuk output variabel
- Jaminan tersedia di semua server dengan PHP 5.4+
- Performa sama persis dengan `<?php echo ... ?>`
- Best practice di template Blade-like: `{{ $var }}` di Laravel, `<?= $var ?>` di PHP native

## Contoh Kode (PHP)
```php
<?php
$title = "Dashboard";
$user = "Budi";
$year = 2025;
?>
<!DOCTYPE html>
<html>
<head>
    <title><?= htmlspecialchars($title) ?></title>
</head>
<body>
    <h1>Selamat datang, <?= $user ?>!</h1>
    <p>Tahun: <?= $year ?></p>
    <p>5 + 3 = <?= 5 + 3 ?></p>
</body>
</html>
```

## Kasus Penggunaan Nyata
Di file template PHP (misal: `header.php`) yang bercampur HTML, gunakan `<?= $title ?>` untuk output title halaman, `<?= $userName ?>` untuk menyapa user. Lebih bersih dari `<?php echo $title; ?>`.
