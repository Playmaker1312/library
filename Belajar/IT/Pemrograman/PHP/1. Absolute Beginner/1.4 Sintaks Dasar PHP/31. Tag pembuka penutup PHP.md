# 31. Tag pembuka penutup PHP

## Definisi Singkat
Kode PHP ditulis di dalam tag pembuka `<?php` dan tag penutup `?>`. Tag ini memberi tahu server bahwa kode di dalamnya adalah PHP yang perlu dieksekusi, bukan HTML biasa.

## Analogi
Seperti tanda kurung pidato: mikrofon dinyalakan dengan `<?php` (mulai bicara) dan dimatikan dengan `?>` (berhenti bicara). Di luar tanda itu, pendengar (browser) mendengar suara biasa (HTML). Di dalam tanda, suara diproses (dieksekusi server).

## Poin-Poin Penting
- Tag standar: `<?php ... ?>` (wajib, selalu didukung)
- Short tag: `<? ... ?>` - bergantung pada `short_open_tag` di php.ini, tidak direkomendasikan untuk portabilitas
- Short echo tag: `<?= ... ?>` - selalu tersedia di PHP 8+, shortcut untuk `<?php echo ... ?>`
- Tag penutup `?>` opsional di file PHP murni (tanpa HTML sesudahnya) - direkomendasikan untuk dihapus
- Mengapa hapus `?>`: spasi atau newline setelah `?>` bisa menyebabkan "headers already sent" error jika ada session/redirect setelahnya
- File PHP murni sebaiknya diakhiri tanpa `?>`
- Jika PHP bercampur HTML, `?>` diperlukan untuk kembali ke mode HTML

## Contoh Kode (PHP)
```php
<?php
$nama = "Budi";
echo "Halo, $nama!";
// File PHP murni, tanpa ?> di akhir - ini best practice
?>
```

## Kasus Penggunaan Nyata
File konfigurasi `config.php` sebaiknya tanpa `?>` di akhir. File template campuran HTML-PHP seperti `header.php` perlu `?>` untuk beralih ke HTML: `<?php echo $title; ?> <nav>...</nav> <?php // PHP lagi ?>`.
