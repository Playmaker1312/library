# 37. Komentar multi-baris

## Definisi Singkat
Komentar multi-baris di PHP menggunakan `/* ... */`, berguna untuk memberikan penjelasan panjang, dokumentasi fungsi (PHPDoc), atau menonaktifkan blok kode besar sementara.

## Analogi
Komentar multi-baris seperti amplop dokumen: Anda bisa memasukkan banyak halaman catatan (penjelasan panjang) ke dalam amplop `/* */`, dan semuanya diabaikan saat dokumen diproses. Lebih rapi daripada banyak sticky notes.

## Poin-Poin Penting
- Dimulai dengan `/*`, diakhiri dengan `*/`
- Bisa mencakup banyak baris
- Tidak bisa ditumpuk (nested): `/* /* */ */` akan error
- Gunakan untuk dokumentasi fungsi/class (PHPDoc): `/** ... */`
- PHPDoc memiliki format khusus dengan `@param`, `@return`, `@throws`
- Gunakan untuk lisensi file di bagian atas file
- Hati-hati: komentar blok besar di dalam string akan error
- Alternatif: nonaktifkan kode dengan `/* */` untuk debugging
- PHP 8+ mendukung `/**` untuk attribute comments

## Contoh Kode (PHP)
```php
<?php
/**
 * Menghitung total harga termasuk pajak
 *
 * @param float $harga Harga dasar produk
 * @param float $pajak Persentase pajak (0-100)
 * @return float Total harga setelah pajak
 */
function hitungTotal(float $harga, float $pajak): float {
    return $harga + ($harga * $pajak / 100);
}

/*
    Blok kode sementara dinonaktifkan:
    $query = "SELECT * FROM users";
    $result = mysqli_query($conn, $query);
    while ($row = mysqli_fetch_assoc($result)) {
        echo $row['name'];
    }
*/

echo hitungTotal(100000, 11); // 111000
?>
```

## Kasus Penggunaan Nyata
Menulis dokumentasi fungsi PHPDoc di atas setiap method di class Laravel agar IDE bisa auto-complete parameter. Atau menonaktifkan blok kode besar saat debugging tanpa menghapus baris satu per satu.
