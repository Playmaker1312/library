# 36. Komentar satu baris

## Definisi Singkat
Komentar satu baris di PHP menggunakan `//` atau `#`. Semua teks setelah tanda tersebut hingga akhir baris diabaikan oleh interpreter PHP. Gunakan untuk menjelaskan kode atau menonaktifkan kode sementara.

## Analogi
Komentar seperti sticky notes (tempelan) di dokumen: Anda menulis catatan untuk diri sendiri atau rekan kerja, tapi catatan itu tidak terbaca oleh mesin fotokopi (interpreter PHP). Berguna untuk mengingatkan atau menjelaskan bagian rumit.

## Poin-Poin Penting
- `//` adalah gaya yang paling umum dan direkomendasikan (PSR-12)
- `#` jarang digunakan, lebih umum di script config
- Komentar hanya berlaku sampai akhir baris yang sama
- Bisa diletakkan di baris sendiri atau di samping kode
- Digunakan untuk menjelaskan "mengapa" kode ditulis, bukan "apa" yang dilakukan
- Kode yang baik seharusnya sudah jelas "apa" yang dilakukan tanpa komentar
- Jangan komentari kode yang tidak jelas - perbaiki kodenya
- Komentar untuk TODO: `// TODO: implementasi fitur X`
- Komentar untuk debugging: `// $debug = true;`

## Contoh Kode (PHP)
```php
<?php
// Ini komentar satu baris
echo "Hello"; // Komentar di samping kode

# Ini juga komentar satu baris (gaya alternatif)
echo "World";

// Berguna untuk nonaktifkan kode sementara
// $password = $_POST['password']; // dinonaktifkan untuk testing
$password = "test123";

// TODO: validasi password dengan regex
echo "Password: $password";
?>
```

## Kasus Penggunaan Nyata
Saat debugging, komentari baris yang tidak ingin dieksekusi: `// $conn->query($sql);` sementara dan `// echo $sql;` untuk lihat query. Jangan lupa hapus komentar setelah selesai.
