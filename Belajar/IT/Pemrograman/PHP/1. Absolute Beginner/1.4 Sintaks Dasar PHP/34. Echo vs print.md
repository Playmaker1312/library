# 34. Echo vs print

## Definisi Singkat
Echo dan print sama-sama output, tapi echo lebih unggul dalam kecepatan dan fleksibilitas (multiple parameter). Print memiliki return value yang berguna untuk kasus tertentu.

## Analogi
Echo seperti melemparkan informasi ke papan tulis - cepat dan bisa banyak sekaligus. Print seperti memberikan kertas ke tangan seseorang - lebih lambat tapi Anda tahu bahwa orang tersebut sudah menerima (return value).

## Poin-Poin Penting
| Aspek | echo | print |
|---|---|---|
| Kecepatan | Lebih cepat | Sedikit lebih lambat |
| Return value | Tidak ada | 1 (integer) |
| Multiple parameter | Ya | Tidak |
| Parentheses | Opsional | Opsional |
| Penggunaan dalam ekspresi | Tidak bisa | Bisa (karena return value) |
| Popularitas | 95% digunakan | 5% digunakan |

- Di PHP 8+, perbedaan performa sangat kecil (micro-optimization)
- echo bisa ditulis sebagai: `echo "satu", "dua";`
- print selalu ditulis: `print "satu";`
- print bisa digunakan di dalam ekspresi ternary: `$x ? print "ya" : print "tidak"`
- echo bisa dengan concatenation: `echo "satu" . "dua";` atau multiple: `echo "satu", "dua";`
- Best practice: selalu gunakan `echo`, hanya `print` jika memang butuh return value

## Contoh Kode (PHP)
```php
<?php
// Echo - multiple parameter lebih cepat
echo "<p>Paragraf 1</p>", "<p>Paragraf 2</p>";

// Print dalam ternary (kasus dimana print berguna)
$status = "aktif";
// print mengembalikan 1, jadi bisa dalam ekspresi
$aktif = ($status === "aktif") ? print "Aktif" : print "Tidak aktif";
echo "<br>Nilai return print: $aktif<br>"; // 1

// Echo lebih bersih
echo ($status === "aktif") ? "Aktif" : "Tidak aktif";
?>
```

## Kasus Penggunaan Nyata
Dalam praktik sehari-hari, developer selalu menggunakan `echo` untuk output HTML. `print` jarang digunakan kecuali dalam situasi spesifik seperti callback atau logging: `$log = print("error");` mengembalikan 1 yang bisa disimpan ke file log.
