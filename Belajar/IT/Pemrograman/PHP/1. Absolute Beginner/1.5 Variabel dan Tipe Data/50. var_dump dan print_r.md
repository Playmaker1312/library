# 50. var_dump dan print_r

## Definisi Singkat
`var_dump()` dan `print_r()` adalah fungsi debugging di PHP untuk menampilkan informasi detail tentang variabel, termasuk tipe data, nilai, dan struktur (untuk array/object). `var_dump()` lebih detail, `print_r()` lebih rapi.

## Analogi
var_dump seperti laporan pemeriksaan kesehatan lengkap: Anda mendapat detail semua organ (tipe data, ukuran, nilai). print_r seperti foto rontgen: Anda bisa melihat struktur tulang (array/object) dengan jelas, tapi tanpa detail lab (tipe data). Keduanya untuk dokter (developer), bukan pasien (user).

## Poin-Poin Penting
- `var_dump($var)`: menampilkan tipe data, ukuran/panjang, dan nilai
- `print_r($var)`: menampilkan struktur dalam format lebih terbaca
- `var_dump` untuk debugging detail (tahu tipe data persis)
- `print_r` untuk melihat struktur array/object dengan cepat
- Parameter kedua `print_r($var, true)` mengembalikan string, tidak output langsung
- `var_export($var)`: mengembalikan representasi PHP yang valid (bisa di-copy-paste sebagai kode)
- `var_dump` bisa multiple parameter: `var_dump($a, $b, $c)`
- `print_r` hanya satu parameter
- Jangan gunakan di production - bocorkan informasi sensitif

## Contoh Kode (PHP)
```php
<?php
$data = [
    "nama" => "Budi",
    "umur" => 25,
    "hobi" => ["coding", "membaca", "game"],
    "aktif" => true,
    "saldo" => null,
];

echo "=== var_dump ===<br>";
var_dump($data);

echo "<br>=== print_r ===<br>";
print_r($data);

echo "<br>=== var_export ===<br>";
var_export($data);

echo "<br>=== print_r return string ===<br>";
$output = print_r($data, true);
echo nl2br($output); // output sebagai string, bisa di-log

// Object
$obj = (object) ["a" => 1, "b" => 2];
echo "<br>=== Object var_dump ===<br>";
var_dump($obj);
?>
```

## Kasus Penggunaan Nyata
Debugging array $_POST saat menerima form: `var_dump($_POST);` untuk melihat data apa yang dikirim. Debugging response API: `print_r($apiResponse, true);` lalu tulis ke log file: `error_log(print_r($data, true));`. Hapus setelah debugging selesai.
