# 49. Tipe data object

## Definisi Singkat
Object adalah tipe data yang merupakan instance dari class, berisi properti (data) dan method (fungsi). PHP mendukung OOP penuh dengan class, inheritance, interface, trait, dan enum.

## Analogi
Object seperti mobil hasil produksi dari cetakan (class). Cetakan (class) mendefinisikan bahwa mobil punya roda, setir, mesin. Mobil yang sudah jadi (object) punya warna, nomor plat, pemilik yang spesifik. Satu cetakan bisa menghasilkan banyak mobil berbeda.

## Poin-Poin Penting
- Object dibuat dengan `new ClassName()`
- Class mendefinisikan properti (`public $nama;`) dan method (`public function sapa()`)
- `$this` merujuk ke object saat ini di dalam class
- Constructor: `__construct()` dipanggil otomatis saat object dibuat
- Property promotion (PHP 8+): deklarasi langsung di constructor parameter
- Readonly property (PHP 8.1+): hanya bisa di-assign sekali
- Enum (PHP 8.1+): tipe data terbatas dengan kasus yang sudah ditentukan
- stdClass: object generic buatan PHP, bisa dibuat dari `(object) []` atau casting array
- Casting array ke object: properti jadi nama key
- Getter/setter dengan `__get`, `__set` magic methods

## Contoh Kode (PHP)
```php
<?php
// Class dengan constructor property promotion (PHP 8+)
class Product {
    public function __construct(
        public readonly string $name,
        public float $price,
        public ?string $category = null,
    ) {}

    public function getPriceFormatted(): string {
        return "Rp" . number_format($this->price, 0, ',', '.');
    }
}

// Membuat object
$laptop = new Product(name: "Laptop ROG", price: 25000000, category: "Elektronik");
echo $laptop->name . "<br>"; // Laptop ROG
echo $laptop->getPriceFormatted() . "<br>"; // Rp25.000.000

// $laptop->name = "Baru"; // Error! readonly

// stdClass - object generic
$obj = (object) ["nama" => "Budi", "umur" => 25];
echo $obj->nama; // Budi

// Casting array ke object
$arr = ["a" => 1, "b" => 2];
$obj2 = (object) $arr;
echo $obj2->a; // 1
?>
```

## Kasus Penggunaan Nyata
DTO (Data Transfer Object) di Laravel: buat class `UserData` dengan readonly property untuk data yang diterima dari form/API. Gunakan constructor property promotion: `public function __construct(public readonly string $name, public readonly string $email) {}`.
