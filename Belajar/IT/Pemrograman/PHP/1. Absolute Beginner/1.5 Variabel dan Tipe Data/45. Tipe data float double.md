# 45. Tipe data float double

## Definisi Singkat
Float (atau double) adalah tipe data bilangan pecahan (desimal) dengan presisi sekitar 14-15 digit desimal. Digunakan untuk nilai yang membutuhkan angka di belakang koma.

## Analogi
Float seperti timbangan digital: bisa menunjukkan berat 1.5 kg, 0.75 kg, atau 3.14159 kg. Tapi timbangan ini memiliki keterbatasan - jika terlalu presisi (misal 0.1 + 0.2), hasilnya bisa sedikit meleset karena cara komputer menghitung desimal.

## Poin-Poin Penting
- Notasi: `3.14`, `.5` (0.5), `1.5e3` (1500)
- PHP_FLOAT_MAX: ~1.8e308, PHP_FLOAT_MIN: ~2.2e-308
- Jangan gunakan float untuk uang atau perhitungan presisi tinggi
- Masalah presisi: `0.1 + 0.2` menghasilkan `0.30000000000000004`
- Solusi presisi: gunakan `bcmath` (arbitrary precision) atau integer (sen)
- NaN (Not a Number): hasil operasi matematika invalid `sqrt(-1)`
- Infinity: `log(0)` menghasilkan `-INF`
- Cek float: `is_float()`, `is_nan()`, `is_infinite()`
- Casting: `(float) $var`, `floatval($var)`

## Contoh Kode (PHP)
```php
<?php
// Float dasar
$harga = 99.99;
$berat = 0.5;
$jarak = 1.5e3; // 1500
echo "Harga: $harga, Berat: $berat, Jarak: $jarak<br>";

// Masalah presisi float
$total = 0.1 + 0.2;
echo "0.1 + 0.2 = " . $total . "<br>"; // 0.30000000000000004
var_dump($total === 0.3); // bool(false) - WARNING!

// Solusi: bandingkan dengan toleransi
$epsilon = 0.0001;
if (abs($total - 0.3) < $epsilon) {
    echo "Sama dalam toleransi<br>";
}

// NaN dan Infinity
$nan = acos(2);  // NaN
$inf = log(0);   // -INF
var_dump($nan, $inf);
?>
```

## Kasus Penggunaan Nyata
Perhitungan diskon: `$diskon = $harga * 0.1;` menghasilkan float. Untuk pembayaran, bulatkan ke 2 desimal: `round($diskon, 2)`. Untuk kalkulasi keuangan kritis, gunakan `bcmath`: `bcadd('0.1', '0.2', 2)` menghasilkan `0.30` dengan presisi tepat.
