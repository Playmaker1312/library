# 48. Tipe data array

## Definisi Singkat
Array di PHP adalah struktur data yang bisa menyimpan banyak nilai dalam satu variabel, dengan akses via key (index numerik atau string). PHP array sebenarnya adalah ordered map yang menggabungkan fitur list, hash map, dan dictionary.

## Analogi
Array seperti lemari arsip dengan laci: setiap laci (index) berisi dokumen (nilai). Bisa laci angka (0, 1, 2...) untuk daftar, atau laci label ("nama", "umur") untuk data terstruktur. Satu lemari bisa menampung banyak jenis dokumen.

## Poin-Poin Penting
- Indexed array: `$arr = [10, 20, 30];` akses dengan `$arr[0]`
- Associative array: `$user = ["nama" => "Budi", "umur" => 25];` akses dengan `$user["nama"]`
- Sintaks `[]` (sejak PHP 5.4) menggantikan `array()`
- Multidimensional array: array di dalam array
- Fungsi penting: `count()`, `array_push()`, `array_pop()`, `array_merge()`, `array_keys()`, `array_values()`
- Sorting: `sort()`, `rsort()`, `asort()`, `ksort()`
- Array unpacking (PHP 7.4+): `$arr = [...$arr1, ...$arr2];`
- Array spread (PHP 8.1+): `$arr = [1, 2, 3, ...$other];`
- Array is (PHP 8.4): memeriksa tipe array lebih mudah

## Contoh Kode (PHP)
```php
<?php
// Indexed array
$buah = ["Apel", "Mangga", "Jeruk"];
echo $buah[0] . "<br>"; // Apel
$buah[] = "Anggur"; // tambah di akhir
print_r($buah); // Array ( [0] => Apel [1] => Mangga [2] => Jeruk [3] => Anggur )

echo "<br>";

// Associative array
$user = [
    "nama" => "Budi",
    "umur" => 25,
    "hobi" => ["coding", "membaca"],
];
echo $user["nama"] . "<br>"; // Budi
echo $user["hobi"][0] . "<br>"; // coding

// Multidimensional
$produk = [
    ["nama" => "Laptop", "harga" => 10000],
    ["nama" => "Mouse", "harga" => 200],
];
foreach ($produk as $p) {
    echo "{$p['nama']}: Rp{$p['harga']}<br>";
}

// Array functions
$angka = [3, 1, 4, 1, 5];
sort($angka);
echo implode(", ", $angka); // 1, 1, 3, 4, 5
?>
```

## Kasus Penggunaan Nyata
Mengambil data dari database: `$users = $db->query("SELECT * FROM users")->fetchAll();` mengembalikan array asosiatif. Looping: `foreach ($users as $user) { echo $user['name']; }`. Array adalah struktur data paling penting di PHP.
