# 42. Aturan penamaan variabel

## Definisi Singkat
Nama variabel PHP harus diawali huruf atau underscore (`_`), hanya mengandung huruf, angka, dan underscore, serta bersifat case-sensitive. Ikuti konvensi penamaan yang konsisten untuk kode yang profesional.

## Analogi
Seperti pembuatan plat nomor kendaraan: harus dimulai huruf (tidak boleh angka), hanya berisi kombinasi huruf dan angka, dan bersifat unik. "B 1234 CD" valid, "1234 B CD" tidak valid. Case-sensitive seperti "B 1234 A" berbeda dengan "b 1234 a".

## Poin-Poin Penting
- Aturan wajib:
  - Diawali `$` lalu huruf atau underscore: `$variabel`, `$_data`
  - Tidak bisa diawali angka: `$1data` INVALID
  - Hanya mengandung: `a-z`, `A-Z`, `0-9`, `_`
  - Tidak boleh spasi: `$nama user` INVALID
  - Tidak boleh karakter spesial: `$nama-user`, `$nama.user` INVALID
- Case-sensitive: `$User` berbeda dengan `$user`
- Konvensi umum:
  - camelCase: `$namaDepan`, `$totalBelanja` (variabel/fungsi)
  - snake_case: `$nama_depan`, `$total_belanja` (alternatif umum)
  - PascalCase: `$NamaDepan` (class names, bukan variabel biasa)
- Nama bermakna: `$hargaProduk` lebih baik dari `$hp`
- Jangan pakai reserved keywords sebagai nama variabel: `$echo`, `$if`, `$class` (beberapa bisa, tapi tidak direkomendasikan)

## Contoh Kode (PHP)
```php
<?php
// Penamaan yang benar
$nama = "Budi";
$nama_depan = "Budi";       // snake_case
$namaBelakang = "Santoso";  // camelCase
$_private = "internal";     // underscore prefix (biasanya private)
$angka1 = 10;               // valid, angka di tengah/akhir

// Penamaan yang salah (UNCOMMENT TO TEST):
// $1nama = "test";  // Parse error: unexpected number
// $nama-ku = "test"; // Parse error
// $nama ku = "test"; // Parse error

// Case sensitivity
$warna = "merah";
$Warna = "biru";
echo "$warna $Warna<br>"; // merah biru

// Nama bermakna
$hargaSetelahDiskon = 85000; // jelas
$hsd = 85000; // tidak jelas
?>
```

## Kasus Penggunaan Nyata
Di project Laravel, ikuti konvensi: `$user` (model), `$users` (collection), `$request` (form request), `$userName` (camelCase). Konsistensi memudahkan kolaborasi tim. Gunakan PHP_CodeSniffer untuk enforce aturan penamaan.
