# 43. Tipe data string

## Definisi Singkat
String adalah tipe data untuk teks yang diapit kutip satu (`'...'`) atau kutip dua (`"..."`). PHP 8+ juga mendukung heredoc dan nowdoc untuk string multi-baris.

## Analogi
String seperti kotak penyimpanan teks: Anda bisa memasukkan huruf, angka, simbol, bahkan emoji ke dalamnya. Kutip satu adalah kotak kaku (isi mentah-mentah), kutip dua adalah kotak pintar (bisa memproses variabel di dalamnya).

## Poin-Poin Penting
- Kutip satu (`'`): tidak menginterpretasi variabel, hanya escape `\\` dan `\'`
- Kutip dua (`"`): menginterpretasi variabel, escape sequences (`\n`, `\t`, `\$`, `\\`, `\"`)
- Interpolasi: `"Halo $nama"` atau `"Halo {$nama}erman"` (kurung kurawal untuk batasi variabel)
- Heredoc: `<<<EOT ... EOT;` - string multi-baris seperti kutip dua
- Nowdoc: `<<<'EOT' ... EOT;` - string multi-baris seperti kutip satu
- String bisa diakses seperti array: `$str[0]` untuk karakter pertama
- Multibyte string (UTF-8): gunakan `mb_*` functions, jangan `strlen` untuk karakter non-ASCII
- PHP 8.4: string dengan UTF-8 lebih terintegrasi

## Contoh Kode (PHP)
```php
<?php
$nama = "Budi";
$umur = 25;

// Kutip satu - tidak interpretasi variabel
echo 'Halo $nama, umur $umur<br>'; // Halo $nama, umur $umur

// Kutip dua - interpretasi variabel
echo "Halo $nama, umur $umur<br>"; // Halo Budi, umur 25

// Kurung kurawal untuk variabel kompleks
echo "Halo {$nama}erman<br>"; // Halo Budierman

// Heredoc (seperti kutip dua)
$teks = <<<HTML
<div>
    <h2>Profil $nama</h2>
    <p>Umur: $umur</p>
</div>
HTML;
echo $teks;

// Nowdoc (seperti kutip satu)
$teks2 = <<<'TEXT'
Teks ini tidak akan menampilkan $nama
TEXT;
echo $teks2;
?>
```

## Kasus Penggunaan Nyata
Query database: `$sql = "SELECT * FROM users WHERE email = '$email'"` - gunakan prepared statement (`$stmt = $pdo->prepare("SELECT * FROM users WHERE email = ?")`) untuk keamanan, bukan interpolasi string langsung.
