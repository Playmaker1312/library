# 46. Tipe data boolean

## Definisi Singkat
Boolean adalah tipe data yang hanya memiliki dua nilai: `true` atau `false`. Digunakan untuk logika kondisional dan kontrol alur program.

## Analogi
Boolean seperti saklar lampu: hanya ada dua posisi - ON (true) atau OFF (false). Tidak ada posisi setengah. Semua kondisi di PHP pada akhirnya menghasilkan salah satu dari dua nilai ini.

## Poin-Poin Penting
- Nilai: `true` dan `false` (case-insensitive: TRUE, True, true sama)
- Falsy values (dianggap false dalam konteks boolean):
  - `false`
  - `0` (integer)
  - `0.0` (float)
  - `""` (string kosong)
  - `"0"` (string "0")
  - `[]` (array kosong)
  - `null`
  - SimpleXML object kosong
- Truthy values: semua nilai lainnya (termasuk string `"false"`)
- Casting: `(bool) $var`, `boolval($var)`
- Operator yang menghasilkan boolean: `==`, `===`, `>`, `<`, `>=`, `<=`, `!=`, `!==`, `&&`, `||`, `!`
- Fungsi berguna: `is_bool()`

## Contoh Kode (PHP)
```php
<?php
// Boolean dasar
$aktif = true;
$menikah = false;

if ($aktif) {
    echo "User aktif<br>";
}

// Falsy values
$falsy = [false, 0, 0.0, "", "0", [], null];
foreach ($falsy as $val) {
    if (!$val) {
        echo "Falsy: " . var_export($val, true) . "<br>";
    }
}

// Truthy
$truthy = [1, -1, "false", " ", [1], "0.0"];
foreach ($truthy as $val) {
    if ($val) {
        echo "Truthy: " . var_export($val, true) . "<br>";
    }
}

// Casting
var_dump((bool) "PHP"); // true
var_dump((bool) "");    // false
var_dump((bool) "0");   // false
?>
```

## Kasus Penggunaan Nyata
Cek login: `$isLoggedIn = (bool) ($_SESSION['user_id'] ?? false);`. Guard clause: `if (!$isLoggedIn) { header('Location: login.php'); exit; }`. Boolean memudahkan penulisan logika yang bersih dan mudah dibaca.
