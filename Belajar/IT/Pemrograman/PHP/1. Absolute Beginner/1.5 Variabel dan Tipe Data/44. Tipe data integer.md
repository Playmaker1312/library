# 44. Tipe data integer

## Definisi Singkat
Integer adalah tipe data bilangan bulat (tanpa desimal) positif atau negatif. Ukuran integer tergantung platform (32-bit: -2^31 s/d 2^31-1, 64-bit: -2^63 s/d 2^63-1).

## Analogi
Integer seperti biji kacang: Anda hitung dalam jumlah bulat (1, 2, 3...). Tidak bisa setengah biji. Jika biji melebihi wadah (overflow), secara otomatis berubah menjadi float.

## Poin-Poin Penting
- Rentang: `PHP_INT_MIN` sampai `PHP_INT_MAX`
- PHP_INT_MAX di 64-bit: 9223372036854775807
- Overflow: jika integer melebihi PHP_INT_MAX, berubah menjadi float
- Notasi: desimal (42), heksadesimal (0x2A), oktal (052), biner (0b101010)
- PHP 8.1+ mendukung explicit octal notation: `0o52`
- Underscore sebagai pemisah (PHP 7.4+): `1_000_000` = 1000000
- Casting: `(int) $var`, `intval($var)`
- Fungsi berguna: `is_int()`, `abs()`, `round()`, `ceil()`, `floor()`

## Contoh Kode (PHP)
```php
<?php
// Integer dasar
$a = 42;
$b = -7;
$c = 1_000_000; // PHP 7.4+ underscore separator
echo "a=$a, b=$b, c=$c<br>";

// Berbagai notasi
$desimal = 42;
$heksa = 0x2A;  // 42
$oktal = 052;   // 42
$biner = 0b101010; // 42

echo "Desimal: $desimal, Heksa: $heksa, Oktal: $oktal, Biner: $biner<br>";

// Cek tipe
$x = 10;
$y = 10.0;
var_dump(is_int($x)); // bool(true)
var_dump(is_int($y)); // bool(false)

// Overflow
$large = PHP_INT_MAX;
echo "Max int: $large<br>";
$overflow = $large + 1;
var_dump($overflow); // float (berubah karena overflow)

// Casting
echo (int) "123abc"; // 123
echo "<br>" . intval(99.99); // 99
?>
```

## Kasus Penggunaan Nyata
Sistem e-commerce: `$totalHarga = 150000;` (integer untuk rupiah dalam satuan terkecil). Hindari float untuk uang karena masalah presisi. Gunakan integer (sen/rupiah) atau library seperti Brick\Money.
