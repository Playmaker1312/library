# 47. Tipe data NULL

## Definisi Singkat
NULL adalah tipe data khusus yang merepresentasikan variabel tanpa nilai. Variabel menjadi null jika: belum diisi, di-set ke `null`, di-unset, atau merupakan undefined variable.

## Analogi
NULL seperti kotak kosong yang belum diisi: bukan kotak berisi angka 0 (itu integer), bukan kotak berisi spasi (itu string), tapi benar-benar kotak kosong yang belum pernah diisi apa pun. Bahkan "tidak ada" adalah sebuah state.

## Poin-Poin Penting
- `null` adalah satu-satunya nilai untuk tipe `null`
- Case-insensitive: `null`, `NULL`, `Null` sama
- Cara membuat null:
  - `$var = null;`
  - `$var = undefined_function();` (fungsi tanpa return)
  - `unset($var);` lalu akses `$var`
  - Parameter function dengan default null: `function foo($x = null)`
- `is_null($var)` untuk cek null
- `$var === null` lebih cepat dari `is_null()`
- Null coalescing operator (PHP 7+): `$x = $var ?? 'default';`
- Nullsafe operator (PHP 8+): `$user?->address?->city`
- `isset($var)` mengembalikan false jika null atau undefined
- `empty($var)` mengembalikan true untuk null, 0, "", false, []

## Contoh Kode (PHP)
```php
<?php
// Null explicit
$data = null;
var_dump($data); // NULL

// Fungsi tanpa return menghasilkan null
function test() {
    // tidak ada return
}
$hasil = test();
var_dump($hasil); // NULL

// Cek null
$nama = null;
if (is_null($nama)) {
    echo "\$nama adalah null<br>";
}
if ($nama === null) {
    echo "Sama dengan null<br>";
}

// Null coalescing operator
$username = $_GET['user'] ?? 'Pengunjung';
echo "Halo, $username<br>";

// Nullsafe operator (PHP 8+)
class User {
    public ?Address $address = null;
}
class Address {
    public string $city = "Jakarta";
}
$user = new User();
echo $user?->address?->city ?? "Kota tidak diketahui<br>";

// Perbedaan isset vs empty
$value = 0;
var_dump(isset($value));  // true (karena variabel ada)
var_dump(empty($value));  // true (karena 0 dianggap empty)
?>
```

## Kasus Penggunaan Nyata
Nullable return type: `function findUser(int $id): ?User { ... }` mengembalikan User atau null jika tidak ditemukan. Panggil dengan nullsafe: `$user?->getName() ?? 'Tidak ditemukan'`.
