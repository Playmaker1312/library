# 41. Deklarasi variabel dollar

## Definisi Singkat
Di PHP, semua variabel diawali dengan simbol dollar (`$`), tidak perlu deklarasi tipe data, dan nilainya bisa diubah kapan saja. PHP akan menentukan tipe data secara otomatis berdasarkan nilai yang diberikan.

## Analogi
Seperti papan nama di kantor: tanda `$` menunjukkan "ini adalah papan nama" (variabel), dan Anda bisa mengganti nama orang di papan itu kapan saja. Tidak perlu mendaftarkan jabatan orang tersebut (tipe data) - cukup tulis nama, sistem akan tahu.

## Poin-Poin Penting
- Format: `$namaVariabel = nilai;`
- `$` harus diikuti huruf atau underscore (`_`) - tidak bisa angka
- Inisialisasi tidak wajib (tapi akses variabel undefined menghasilkan Notice)
- Nilai bisa diubah: `$x = 5; $x = "teks";` - valid
- Referensi: `$a =& $b;` membuat kedua variabel menunjuk ke memori yang sama
- Variable variables: `$$nama` - nama variabel dari nilai variabel lain (jarang digunakan)
- Hapus variabel: `unset($var);`
- Cek apakah variabel terdefinisi: `isset($var)`
- PHP 8.4: properti hooks memungkinkan logika getter/setter pada property class

## Contoh Kode (PHP)
```php
<?php
// Deklarasi variabel
$nama = "Budi";
$umur = 25;
$tinggi = 170.5;
$menikah = false;

echo "$nama, $umur tahun, tinggi $tinggi cm<br>";

// Ubah tipe data
$data = "100";
echo gettype($data); // string
$data = (int) $data; // casting
echo ", " . gettype($data); // integer

// Variable variables
$hewan = "kucing";
$$hewan = "makan ikan"; // $kucing = "makan ikan"
echo "$kucing<br>"; // makan ikan

// Cek eksistensi
echo isset($nama) ? "Ada" : "Tidak ada"; // Ada
unset($nama);
echo isset($nama) ? "Ada" : "Tidak ada"; // Tidak ada
?>
```

## Kasus Penggunaan Nyata
Saat menerima input form: `$username = $_POST['username'] ?? '';` - deklarasi dengan null coalescing operator agar tidak undefined. Kemudian `$username = trim($username);` untuk membersihkan spasi.
