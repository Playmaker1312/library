# 4. Cara PHP bekerja di web server

## Definisi Singkat
PHP bekerja melalui modul yang terintegrasi dengan web server (Apache via mod_php, Nginx via PHP-FPM). Server menerima request `.php`, meneruskannya ke interpreter PHP, lalu mengembalikan hasil HTML ke klien.

## Analogi
Seperti mesin fotokopi: Anda meletakkan dokumen kosong (request HTTP), mesin memproses di dalam (interpreter PHP menjalankan skrip), lalu mengeluarkan hasil fotokopian (response HTML). Operator mesin (web server) mengatur antrian dan tujuan.

## Poin-Poin Penting
- Apache: mod_php memuat PHP langsung di dalam proses Apache - cepat tapi boros memori
- Nginx: PHP-FPM sebagai proses terpisah - lebih efisien untuk traffic tinggi
- Saat file `.php` di-request:
  1. Web server menerima HTTP request
  2. Server melihat ekstensi `.php` dan tahu harus menggunakan PHP interpreter
  3. PHP interpreter mengeksekusi skrip
  4. Output (HTML) dikembalikan ke server
  5. Server mengirim response ke browser
- PHP dapat berjalan sebagai CGI, FastCGI, atau CLI (command line)
- PHP CLI digunakan untuk skrip background, cron job, atau task scheduler

## Contoh Kode (PHP)
```php
<?php
// Simulasi proses server
$ip_pengunjung = $_SERVER['REMOTE_ADDR'];
$browser = $_SERVER['HTTP_USER_AGENT'];
echo "<p>IP Anda: $ip_pengunjung</p>";
echo "<p>Browser: $browser</p>";
// Output dinamis berdasarkan request pengunjung
?>
```

## Kasus Penggunaan Nyata
Saat user mengakses `https://toko-online.com/produk.php?id=5`, Apache/Nginx meneruskan ke PHP, PHP mengambil data produk ID=5 dari database, merender HTML produk, mengirim ke browser user.
