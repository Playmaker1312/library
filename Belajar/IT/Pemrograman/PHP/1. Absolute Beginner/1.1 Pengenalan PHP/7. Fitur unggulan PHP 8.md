# 7. Fitur unggulan PHP 8

## Definisi Singkat
PHP 8 adalah major release yang menghadirkan JIT (Just-In-Time) compiler untuk peningkatan performa drastis, ditambah fitur bahasa modern seperti named arguments, attributes, union types, match expression, dan constructor property promotion.

## Analogi
PHP 7 adalah mobil biasa, PHP 8 adalah mobil dengan turbocharger (JIT) dan fitur self-driving (type safety, named arguments). Performa lebih kencang, pengendalian lebih mudah, kode lebih bersih.

## Poin-Poin Penting
- **JIT Compiler**: Meningkat performa hingga 3x untuk CPU-intensive tasks, kode dikompilasi ke machine code saat runtime
- **Named Arguments**: `calculate(total: 100, tax: 0.1)` - argumen bisa disebut namanya, urutan tidak penting
- **Attributes**: `#[Route('/api/users')]` metadata native, pengganti PHPDoc annotations
- **Union Types**: `function(int|string $id): void` - parameter bisa multiple types
- **Match Expression**: Switch yang lebih aman, tanpa fallthrough, mengembalikan nilai
- **Constructor Property Promotion**: Deklarasi property langsung di parameter constructor
- **Nullsafe Operator**: `$user?->address?->city` - chain method aman dari null
- **Stringable Interface**: Class yang punya `__toString()` otomatis implement Stringable
- **Enums (8.1)**: First-class enum support
- **Readonly Properties (8.1)**: Property hanya bisa di-set sekali
- **Property Hooks (8.4)**: Getter/setter native di property

## Contoh Kode (PHP)
```php
<?php
// Constructor Property Promotion + Named Arguments
class Product {
    public function __construct(
        public string $name,
        public readonly float $price,
        public ?string $category = null,
    ) {}
}

// Named arguments
$product = new Product(name: "Laptop", price: 15000, category: "Elektronik");

// Match expression
$status = match($product->price) {
    > 10000 => "Mahal",
    > 5000 => "Sedang",
    default => "Murah",
};

echo $status; // Mahal
?>
```

## Kasus Penggunaan Nyata
Migrasi dari PHP 7.4 ke PHP 8.4: ganti switch-case besar dengan match expression untuk status order, gunakan named arguments untuk function dengan banyak parameter opsional, manfaatkan readonly property untuk immutable DTO.
