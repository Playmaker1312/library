# 3. Client-side vs server-side

## Definisi Singkat
Client-side (browser) menangani tampilan dan interaksi langsung dengan pengguna menggunakan HTML, CSS, JavaScript. Server-side (PHP) menangani logika bisnis, database, autentikasi, dan keamanan di server sebelum mengirim hasil ke client.

## Analogi
Restoran: server-side adalah dapur (chef memasak, cek stok bahan, atur resep). Client-side adalah waiter dan dekorasi meja (sajian cantik, interaksi langsung dengan pelanggan). Pelanggan hanya melihat hasil akhir.

## Poin-Poin Penting
| Aspek | Client-side | Server-side (PHP) |
|---|---|---|
| Eksekusi | Browser user | Server web |
| Bahasa | HTML, CSS, JS | PHP, Python, Ruby |
| Kecepatan real-time | Sangat cepat | Tergantung jaringan |
| Keamanan | Source code terlihat | Source code tersembunyi |
| Database | Tidak bisa langsung | Bisa akses langsung |
| SEO | Kurang optimal | Bisa generate HTML untuk SEO |

- PHP bisa menghasilkan JavaScript, CSS, HTML secara dinamis
- JavaScript modern (Node.js) juga bisa server-side, tapi bukan di browser
- PHP murni server-side, tidak bisa jalan di browser tanpa server

## Contoh Kode (PHP)
```php
<?php
// SERVER-SIDE: PHP memproses data
$produk = ["Laptop", "Mouse", "Keyboard"];
$daftar = "<ul>";
foreach ($produk as $item) {
    $daftar .= "<li>$item</li>";
}
$daftar .= "</ul>";
echo $daftar;
// Output HTML: <ul><li>Laptop</li><li>Mouse</li><li>Keyboard</li></ul>
?>
```

## Kasus Penggunaan Nyata
Form registrasi: HTML (client) untuk tampilan form, JavaScript (client) untuk validasi real-time (email sudah format benar?), PHP (server-side) untuk validasi final, hash password, simpan ke database.
