# 9. PHP vs Python Node.js Ruby

## Definisi Singkat
PHP, Python, Node.js (JavaScript), dan Ruby adalah bahasa server-side populer. PHP unggul di web hosting murah dan ekosistem CMS, Python di data science, Node.js di real-time, Ruby di rapid prototyping.

## Analogi
Pilih alat sesuai proyek: PHP seperti palu dan paku (web tradisional), Python seperti pisau Swiss Army (serba bisa), Node.js seperti obat nyamuk (event-driven, cepat untuk real-time), Ruby seperti kuas lukis (elegant, artistik).

## Poin-Poin Penting
| Aspek | PHP | Python | Node.js | Ruby |
|---|---|---|---|---|
| Eksekusi | Sync, blocking | Sync, blocking | Async non-blocking | Sync, blocking |
| Performa | Baik (PHP 8 JIT) | Sedang | Tinggi (V8) | Sedang |
| Hosting cost | Murah, banyak | Limited | Limited | Limited |
| CMS/Platform | WordPress, Drupal | Django CMS | Ghost | Shopify |
| Framework web | Laravel, Symfony | Django, Flask | Express, Nest | Rails |
| Learning curve | Mudah | Mudah | Sedang | Sedang |
| Type system | Weakly typed | Strongly typed | Weakly typed | Strongly typed |

- PHP: ~77% web (dominasi WordPress)
- Python: Populer di AI, data science, backend
- Node.js: Unggul di real-time app (chat, streaming)
- Ruby: Rails populer untuk startup, prototyping cepat
- PHP 8+ dengan JIT bersaing dengan Node.js dalam performa

## Contoh Kode (PHP)
```php
<?php
// PHP - web tradisional yang straightforward
$conn = new PDO("mysql:host=localhost;dbname=shop", "root", "");
$stmt = $conn->query("SELECT * FROM products");
foreach ($stmt as $row) {
    echo "<h2>{$row['name']}</h2>";
}
?>
```

## Kasus Penggunaan Nyata
Pilih PHP untuk: website perusahaan, blog WordPress, toko online WooCommerce, portal berita, sistem akademik. Pilih Node.js untuk: chat real-time, kolaborasi dokumen. Pilih Python untuk: API machine learning, data processing.
