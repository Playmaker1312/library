# 5. Siklus request response PHP

## Definisi Singkat
Siklus request-response PHP mengikuti pola: Browser mengirim HTTP request → Server PHP menerima → PHP mengeksekusi skrip → Mengembalikan response HTML. Satu request = satu eksekusi PHP lengkap, lalu PHP mati.

## Analogi
Seperti layanan drive-thru: Anda memesan (request) → petugas menerima pesanan → koki memasak (eksekusi PHP) → petugas memberikan makanan (response) → selesai. Pesanan berikutnya mulai dari awal lagi.

## Poin-Poin Penting
- Setiap request HTTP ke file PHP memulai siklus baru, tidak ada state bawaan
- Variabel tidak dipertahankan antar request (kecuali session/cookie)
- Siklus lengkap:
  1. User mengakses URL (GET/POST request)
  2. Web server intercept request ke file `.php`
  3. PHP engine menginisialisasi, parsing, eksekusi
  4. PHP menghasilkan output buffer
  5. Web server mengirim HTTP response
  6. PHP engine shutdown, semua resource dibebaskan
- Session menggunakan file/database untuk mempertahankan state antar request
- PHP 8+ memiliki opcache yang mempercepat eksekusi dengan caching bytecode

## Contoh Kode (PHP)
```php
<?php
// Setiap refresh halaman adalah siklus baru
$hit = $_SESSION['hit'] ?? 0;
$hit++;
$_SESSION['hit'] = $hit;
echo "Anda merefresh halaman ini $hit kali";
// Tanpa session, counter akan selalu 1
?>
```

## Kasus Penggunaan Nyata
Saat implementasi form login: user submit username+password (POST request) → PHP validasi → jika cocok, buat session → response redirect ke dashboard. Siklus berikutnya (dashboard) cek session, jika valid tampilkan data.
