# 8. PHP dinamis weakly typed

## Definisi Singkat
PHP adalah bahasa dengan dynamic (weakly) typing, artinya variabel bisa berubah tipe data secara otomatis saat runtime tanpa deklarasi tipe eksplisit. Namun PHP 7+ mendukung type declarations untuk mengubahnya menjadi strict.

## Analogi
Seperti koper ajaib: Anda bisa memasukkan baju (string), buku (integer), atau panci (array) tanpa memberi label. Kopernya akan menyesuaikan bentuk sendiri. Tapi PHP 7+ memberi Anda stiker label jika ingin.

## Poin-Poin Penting
- Variabel tidak perlu dideklarasikan tipenya: `$x = "hello"; $x = 5;` valid
- Type coercion otomatis: `"5" + 3` menghasilkan integer 8
- PHP 7+ strict types: `declare(strict_types=1)` di awal file mengubah perilaku
- Dengan strict types, type coercion tidak akan terjadi
- Union types (PHP 8+): `function foo(int|string $val) {}`
- Mixed type: `function bar(mixed $val) {}` - menerima semua tipe
- Kelemahan weakly typed: bug subtle seperti `"123abc" + 1` menghasilkan 124
- PHP mengkonversi string ke int secara otomatis untuk operasi aritmatika

## Contoh Kode (PHP)
```php
<?php
// Dynamic typing - tipe berubah
$x = "100";
echo gettype($x); // string

$x = $x + 50; // coercion otomatis
echo gettype($x); // integer
echo $x; // 150

// Strict mode (letakkan di awal file)
declare(strict_types=1);
function tambah(int $a, int $b): int {
    return $a + $b;
}
// tambah("5", 3); // TypeError: Argument must be int
?>
```

## Kasus Penggunaan Nyata
Saat menerima input dari form HTML semua nilai adalah string. PHP otomatis mengkonversi sesuai konteks: `$_POST['age'] + 1` bekerja tanpa casting manual. Tapi untuk kode production, gunakan type declarations untuk mencegah bug.
