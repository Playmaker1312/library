# 1. Apa itu PHP dan sejarahnya

## Definisi Singkat
PHP (Hypertext Preprocessor) adalah bahasa pemrograman server-side open-source yang dirancang khusus untuk pengembangan web. Awalnya dibuat oleh Rasmus Lerdorf pada 1994 sebagai "Personal Home Page Tools".

## Analogi
Bayangkan PHP sebagai koki di restoran: pelanggan (browser) memesan makanan (request), koki memasak di dapur (server) dan baru menyajikan hasil jadi (HTML). Koki tidak pernah menunjukkan proses memasak, hanya hasil akhirnya.

## Poin-Poin Penting
- PHP 8.0 (November 2020) membawa JIT compiler, named arguments, attributes
- PHP 8.1 (November 2021): enums, readonly properties, fibers
- PHP 8.2 (Desember 2022): readonly classes, standalone types
- PHP 8.3 (November 2023): json_validate, override attribute
- PHP 8.4 (November 2024): property hooks, asymmetric visibility
- Versi 7.x (2015-2019): Return type declarations, scalar type declarations, null coalescing operator
- Versi 5.x (2004-2018): OOP modern dengan visibility, interfaces, exceptions
- Versi 4 (2000): Dukungan session, output buffering
- Sekarang PHP digunakan oleh ~77% website di dunia (W3Techs 2024)

## Contoh Kode (PHP)
```php
<?php
echo "Hello, dunia PHP! Versi saat ini: " . phpversion();
// Output: Hello, dunia PHP! Versi saat ini: 8.4.x
?>
```

## Kasus Penggunaan Nyata
Saat memulai proyek web baru, pilih PHP 8+ untuk memanfaatkan performa JIT dan fitur modern. Framework seperti Laravel, Symfony, dan Wordpress semuanya dibangun di atas PHP.
