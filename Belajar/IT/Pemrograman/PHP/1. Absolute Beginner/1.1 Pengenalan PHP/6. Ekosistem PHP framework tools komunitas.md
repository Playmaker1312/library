# 6. Ekosistem PHP framework tools komunitas

## Definisi Singkat
Ekosistem PHP terdiri dari framework (Laravel, Symfony, CodeIgniter), CMS (WordPress, Joomla, Drupal), package manager (Composer), tool development (PHPUnit, Xdebug), dan komunitas global yang sangat aktif.

## Analogi
Ekosistem PHP seperti pasar raksasa: ada toko bahan bangunan (framework), toko furnitur jadi (CMS), toko alat khusus (library), dan koperasi (Packagist). Anda bisa bangun dari nol atau beli yang sudah jadi.

## Poin-Poin Penting
- **Framework populer**: Laravel (MVC, eloquent ORM), Symfony (modular, reusable), CodeIgniter (ringan), CakePHP, Yii
- **CMS raksasa**: WordPress (~43% web), Joomla, Drupal, Magento (e-commerce)
- **Package manager**: Composer dengan registry Packagist.org (300k+ packages)
- **Tool testing**: PHPUnit (unit test), Pest (syntax elegant), PHPStan (static analysis)
- **Tool debugging**: Xdebug (step debug), Ray, Laravel Telescope, Symfony Profiler
- **Database ORM**: Eloquent (Laravel), Doctrine (Symfony)
- **Template engine**: Blade (Laravel), Twig (Symfony), Smarty
- **Linting/Code quality**: PHP CodeSniffer, PHP-CS-Fixer, Rector (upgrade otomatis)
- **Komunitas**: Laravel Indonesia, PHP Indonesia di Facebook/Telegram, Stack Overflow

## Contoh Kode (PHP)
```php
<?php
// Menginstal package via Composer (terminal):
// composer require guzzlehttp/guzzle

// Menggunakan package
require 'vendor/autoload.php';
use GuzzleHttp\Client;

$client = new Client();
$res = $client->get('https://api.github.com');
echo $res->getStatusCode(); // 200
?>
```

## Kasus Penggunaan Nyata
Membangun toko online: gunakan Laravel untuk backend + CRUD produk, Spatie Media Library untuk upload gambar, Laravel Cashier untuk pembayaran, Laravel Horizon untuk queue. Semua via Composer.
