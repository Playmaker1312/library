# 2. PHP sebagai bahasa server-side

## Definisi Singkat
PHP adalah bahasa server-side, artinya semua kode PHP dieksekusi di server web sebelum hasilnya dikirim sebagai HTML murni ke browser klien. Klien tidak pernah melihat kode PHP asli.

## Analogi
Seperti mesin ATM: Anda (browser) memasukkan kartu dan PIN (request), mesin memproses di dalam sistem internalnya (server), lalu mengeluarkan uang (response HTML). Anda tidak pernah melihat logika internal mesinnya.

## Poin-Poin Penting
- Kode PHP dieksekusi di server oleh interpreter PHP (Zend Engine)
- Hasil eksekusi berupa HTML, CSS, atau JavaScript yang dikirim ke browser
- Browser hanya menerima output, bukan source code PHP
- Aman karena logika bisnis dan koneksi database tersembunyi dari klien
- PHP terintegrasi langsung dengan web server (Apache, Nginx, IIS) via modul (mod_php, php-fpm)
- Di PHP 8+, PHP-FPM adalah mode eksekusi paling umum dengan Nginx
- Tidak seperti JavaScript yang berjalan di client (browser)

## Contoh Kode (PHP)
```php
<?php
$waktu = date("H:i:s");
echo "<h1>Sekarang jam $waktu</h1>";
// Browser hanya melihat: <h1>Sekarang jam 14:30:25</h1>
// Kode PHP tidak terlihat di view source browser
?>
```

## Kasus Penggunaan Nyata
Saat membangun sistem login, validasi password dan logika autentikasi harus di server-side (PHP), bukan JavaScript. JavaScript hanya untuk UX (animasi error), PHP untuk keamanan sesungguhnya.
