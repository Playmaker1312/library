# 13. Instal LAMPP Linux Ubuntu

## Definisi Singkat
LAMPP adalah versi XAMPP untuk Linux dengan Apache, MySQL, PHP, dan phpMyAdmin. Di Ubuntu, instalasi bisa melalui package manager (`apt`) atau download binary dari situs XAMPP.

## Analogi
LAMPP seperti workshop DIY: Anda bisa beli paket alat lengkap (XAMPP binary) atau merakit sendiri satu per satu (apt install). Keduanya berfungsi sama, bedanya kemudahan vs fleksibilitas.

## Poin-Poin Penting
- **Opsi 1 (XAMPP)**: download dari apachefriends.org, `chmod +x xampp-*.run`, `sudo ./xampp-*.run`
- **Opsi 2 (manual via apt)**: `sudo apt install apache2 php mysql-server php-mysql phpmyadmin`
- Lokasi XAMPP: `/opt/lampp/`
- Start/stop: `sudo /opt/lampp/lampp start|stop`
- File PHP: `/opt/lampp/htdocs/`
- Web root default: `/var/www/html/` (jika via apt)
- PHP CLI: `/opt/lampp/bin/php` atau `which php` (jika via apt)
- Test: buka `http://localhost`
- Log error: `/opt/lampp/logs/`

## Contoh Kode (PHP)
```php
<?php
// File: /opt/lampp/htdocs/info.php
echo php_uname() . "<br>";
echo "PHP berjalan di Linux!";
// Output: Linux hostname 5.x.x ...<br>PHP berjalan di Linux!
?>
```

## Kasus Penggunaan Nyata
Developer Ubuntu yang ingin full control: install Apache + PHP + MySQL via apt untuk production-like environment di lokal, atau pakai XAMPP untuk setup cepat belajar.
