# 20. VS Code untuk PHP

## Definisi Singkap
Visual Studio Code adalah code editor ringan dan gratis dari Microsoft yang sangat populer untuk PHP development dengan ekstensi seperti PHP Intelephense, PHP Debug, dan berbagai snippet.

## Analogi
VS Code seperti meja kerja tukang kayu profesional: awalnya kosong, tapi Anda bisa memasang berbagai alat (extension) sesuai kebutuhan - gergaji (debugger), meteran (Intelephense), obeng (snippet). Mejanya tetap ringan dan rapi.

## Poin-Poin Penting
- Download dari https://code.visualstudio.com/
- **Ekstensi wajib PHP**:
  - PHP Intelephense (auto-complete, type hinting, navigation)
  - PHP Debug (debug dengan Xdebug)
  - PHP Snippet (code templates)
  - Composer (integrasi Composer di VS Code)
- **Ekstensi pendukung**: GitLens, Prettier, MySQL (database client), Thunder Client (API testing)
- Setting penting: `php.validate.executablePath` arahkan ke `C:\xampp\php\php.exe`
- Buka folder project: File → Open Folder → pilih `C:\xampp\htdocs\project-anda`
- Integrated terminal: Ctrl+` untuk menjalankan perintah PHP/Composer
- Emmet: HTML/CSS autocomplete bekerja di file .php
- Live Server (ekstensi) tidak berguna untuk PHP (butuh server)

## Contoh Kode (PHP)
```php
<?php
// Di VS Code: ketika mengetik "php-" akan muncul snippet
// echo, phpinfo, foreach, dll auto-complete oleh Intelephense

$nama = "Budi";
echo "Halo, $nama!"; // Intelephense akan bantu auto-complete variabel
// Output: Halo, Budi!
?>
```

## Kasus Penggunaan Nyata
Developer PHP membuka VS Code, install Intelephense (auto-complete PHP), PHP Debug (step debug dengan Xdebug), dan MySQL extension (lihat database tanpa phpMyAdmin). Semua kebutuhan development dalam satu editor.
