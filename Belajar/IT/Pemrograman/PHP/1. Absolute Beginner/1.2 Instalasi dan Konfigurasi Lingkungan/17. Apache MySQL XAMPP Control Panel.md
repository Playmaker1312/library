# 17. Apache MySQL XAMPP Control Panel

## Definisi Singkat
XAMPP Control Panel adalah GUI untuk mengelola service Apache (web server) dan MySQL (database server), termasuk start/stop, konfigurasi port, dan melihat log.

## Analogi
Panel kontrol XAMPP seperti dashboard operator pembangkit listrik: ada tombol ON/OFF (start/stop), indikator menyala (service running), dan monitor troubleshooting (log). Tanpa ini, Anda harus menyalakan generator manual via terminal.

## Poin-Poin Penting
- Jalankan sebagai Administrator (Windows) untuk akses penuh
- Modul utama: Apache (port 80/443), MySQL (port 3306)
- Tombol Start/Stop untuk masing-masing service
- Tombol Admin: buka phpMyAdmin (untuk MySQL) atau dashboard Apache
- Tombol Config: akses file konfigurasi (httpd.conf, php.ini, my.ini)
- Tombol Logs: lihat error log untuk debugging
- Tombol Explorer: buka folder XAMPP root
- Port bentrok (port 80 dipakai): klik Config → Apache (httpd.conf) → ubah `Listen 80` ke port lain (8080)
- MySQL port bentrok: ubah di my.ini → `port=3307`
- Tombol Shell: buka terminal dengan XAMPP environment path

## Contoh Kode (PHP)
```php
<?php
// Cek apakah service berjalan
$mysql_connected = @mysqli_connect("localhost", "root", "");
if ($mysql_connected) {
    echo "MySQL berjalan! Server: " . mysqli_get_server_info($mysql_connected);
    mysqli_close($mysql_connected);
} else {
    echo "MySQL tidak terhubung. Cek XAMPP Control Panel.";
}
?>
```

## Kasus Penggunaan Nyata
Setelah install XAMPP, buka Control Panel → Start Apache (hijau) → Start MySQL (hijau). Jika Apache gagal start karena port 80 dipakai Skype, klik Config → Apache → ganti Listen 80 ke 8080 → Save → Start ulang.
