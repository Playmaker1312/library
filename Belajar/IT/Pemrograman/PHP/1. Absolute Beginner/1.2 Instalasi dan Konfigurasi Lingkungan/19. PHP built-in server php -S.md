# 19. PHP built-in server php -S

## Definisi Singkat
PHP memiliki built-in web server yang bisa dijalankan via CLI dengan perintah `php -S localhost:8000`, berguna untuk development/testing tanpa perlu Apache atau Nginx.

## Analogi
PHP built-in server seperti kompor portable camping: kecil, ringan, bisa dipakai di mana saja tanpa instalasi dapur lengkap. Cocok untuk masak (develop) sendiri, tidak untuk restoran ramai (production).

## Poin-Poin Penting
- Jalankan: `php -S localhost:8000` dari folder project
- Akses via: `http://localhost:8000`
- PHP built-in server adalah single-threaded, hanya untuk development
- Bisa tentukan router script: `php -S localhost:8000 router.php`
- Untuk akses dari device lain: `php -S 0.0.0.0:8000` (LAN)
- Matikan server: Ctrl + C di terminal
- Tidak perlu install Apache/Nginx untuk testing sederhana
- File index.php/index.html dibuka otomatis jika akses folder
- Log request tampil di terminal real-time

## Contoh Kode (PHP)
```php
<?php
// Di terminal:
// cd C:\xampp\htdocs\project-saya
// php -S localhost:8000

// File: index.php (akan tampil saat akses localhost:8000)
echo "<h1>Server built-in PHP berjalan!</h1>";
echo "<p>Request: " . $_SERVER['REQUEST_URI'] . "</p>";
// Output: Server built-in PHP berjalan!
// Output: Request: /
?>
```

## Kasus Penggunaan Nyata
Testing API kecil: tanpa XAMPP, cukup `php -S localhost:8080` di folder project. Bisa test endpoint REST API dengan Postman. Cocok saat belajar atau mengerjakan microservice kecil.
