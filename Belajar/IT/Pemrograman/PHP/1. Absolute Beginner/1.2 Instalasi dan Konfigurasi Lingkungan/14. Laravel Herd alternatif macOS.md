# 14. Laravel Herd alternatif macOS

## Definisi Singkat
Laravel Herd adalah development environment native macOS khusus Laravel yang menyediakan PHP, Nginx, dan database (MySQL/PostgreSQL) tanpa perlu XAMPP atau MAMP. Dikembangkan oleh BeyondCode.

## Analogi
Herd seperti concierge hotel mewah: semua kebutuhan Anda diurus oleh satu orang (NGINX, PHP, DB sudah terkonfigurasi). Anda tinggal bilang "saya mau proyek Laravel baru", dan semuanya langsung siap.

## Poin-Poin Penting
- Download gratis dari https://herd.laravel.com/
- Mendukung multiple PHP version (8.0, 8.1, 8.2, 8.3, 8.4)
- Menggunakan Nginx, bukan Apache - lebih ringan
- Auto SSL untuk development (localhost via HTTPS)
- Integrasi mulus dengan Laravel Valet
- DNS wildcard: `http://project-name.test` otomatis terdeteksi
- GUI untuk switch PHP version, manage services
- Cocok untuk developer Laravel profesional di macOS
- Alternatif: Laravel Valet (CLI-only, tanpa GUI)

## Contoh Kode (PHP)
```php
<?php
// Herd tidak perlu konfigurasi manual
// Cukup buat folder di ~/Herd/
// Akses: http://nama-folder.test/
echo "Laravel Herd siap digunakan!";
// Output di browser: Laravel Herd siap digunakan!
?>
```

## Kasus Penggunaan Nyata
Developer Laravel macOS beralih dari XAMPP ke Herd karena: lebih cepat, native macOS, multi-version PHP mudah, auto SSL, cocok untuk development harian Laravel.
