# 16. Struktur folder htdocs XAMPP

## Definisi Singkat
`htdocs` adalah folder root web XAMPP (atau `www` di Laragon) tempat semua file PHP dan website disimpan. File di dalamnya bisa diakses via browser melalui `http://localhost/nama-folder/nama-file.php`.

## Analogi
htdocs seperti rak display di toko: semua barang di rak ini bisa dilihat pelanggan (browser). Barang di gudang belakang (luar htdocs) tidak bisa dilihat langsung. Anda hanya meletakkan barang jadi di rak.

## Poin-Poin Penting
- Lokasi default XAMPP: `C:\xampp\htdocs\`
- Lokasi default Laragon: `C:\laragon\www\`
- Setiap subfolder di htdocs bisa diakses sebagai path URL
- Contoh: `C:\xampp\htdocs\toko\index.php` → `http://localhost/toko/index.php`
- File index.php/index.html otomatis dibuka jika akses folder tanpa nama file
- Jangan simpan file konfigurasi database (.env, config.php) di luar htdocs
- File sensitif (.sql, .env, .json) bisa diakses publik jika di dalam htdocs
- Gunakan `.htaccess` atau folder di luar htdocs (via php `require`) untuk keamanan
- Virtual host memungkinkan folder di luar htdocs sebagai document root

## Contoh Kode (PHP)
```php
<?php
// Cek path absolut file saat ini
echo "Path file ini: " . __FILE__ . "<br>";
echo "Document root: " . $_SERVER['DOCUMENT_ROOT'];
// Output: Path file ini: C:\xampp\htdocs\test.php
// Output: Document root: C:/xampp/htdocs
?>
```

## Kasus Penggunaan Nyata
Saat membangun website company profile, buat folder `C:\xampp\htdocs\company\`. Letakkan `index.php`, `about.php`, `contact.php` di sana. Akses via `http://localhost/company/`.
