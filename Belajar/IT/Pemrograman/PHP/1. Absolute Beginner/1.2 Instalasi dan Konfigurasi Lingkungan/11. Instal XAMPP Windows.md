# 11. Instal XAMPP Windows

## Definisi Singkat
XAMPP adalah paket aplikasi web server siap pakai untuk Windows yang berisi Apache, PHP, MySQL/MariaDB, dan phpMyAdmin dalam satu installer. Solusi termudah untuk memulai PHP development di Windows.

## Analogi
XAMPP seperti paket makanan instan lengkap: tinggal tambah air panas (install), semua bumbu sudah termasuk (Apache, PHP, MySQL). Tidak perlu masak satu per satu.

## Poin-Poin Penting
- Download dari https://www.apachefriends.org/ (versi PHP 8.x terbaru)
- Install di `C:\xampp` (default), hindari folder dengan spasi
- Pilih komponen: Apache, MySQL, PHP, phpMyAdmin (cukup)
- Setelah install, jalankan XAMPP Control Panel sebagai Administrator
- Start Apache dan MySQL dari panel
- Test: buka browser, akses `http://localhost` - muncul halaman XAMPP
- File PHP ditaruh di `C:\xampp\htdocs\`
- Security: file/folder di htdocs bisa diakses via browser - jangan simpan data sensitif di sini
- Port 80 dan 3306 harus bebas (tidak dipakai aplikasi lain)
- Nonaktifkan IIS atau aplikasi yang menggunakan port 80 jika bentrok

## Contoh Kode (PHP)
```php
<?php
// File: C:\xampp\htdocs\info.php
// Akses: http://localhost/info.php
phpinfo();
// Menampilkan seluruh konfigurasi PHP, Apache, MySQL
?>
```

## Kasus Penggunaan Nyata
Developer Windows menginstal XAMPP dalam 10 menit, langsung bisa coding PHP + MySQL. Cukup buka VS Code, buat file di `htdocs`, akses via `http://localhost/nama-file.php`.
