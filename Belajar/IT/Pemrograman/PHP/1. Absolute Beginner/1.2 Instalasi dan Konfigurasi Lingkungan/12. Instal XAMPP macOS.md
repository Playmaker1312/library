# 12. Instal XAMPP macOS

## Definisi Singkat
XAMPP untuk macOS menyediakan lingkungan PHP development lengkap dengan Apache, MySQL, dan phpMyAdmin, terinstal di `/Applications/XAMPP/`. Alternatif yang user-friendly untuk developer macOS pemula.

## Analogi
XAMPP macOS seperti food truck yang siap jualan: semua peralatan masak sudah terpasang di dalam kendaraan (satu paket aplikasi), tinggal parkir (install) dan buka dagangan (start server).

## Poin-Poin Penting
- Download DMG dari https://www.apachefriends.org/
- Drag ke Applications, ikuti wizard installer
- Lokasi instalasi: `/Applications/XAMPP/`
- Control panel: gunakan `manager-osx` dari Applications
- File PHP ditaruh di `/Applications/XAMPP/htdocs/`
- Start/stop Apache dan MySQL via GUI manager
- Test: buka `http://localhost` di browser
- Terminal: `/Applications/XAMPP/bin/php` untuk PHP CLI
- Uninstall: hapus folder `/Applications/XAMPP/`
- sudo mungkin diperlukan untuk permission

## Contoh Kode (PHP)
```php
<?php
// File: /Applications/XAMPP/htdocs/test.php
echo "XAMPP macOS berjalan! Versi PHP: " . phpversion();
// Output: XAMPP macOS berjalan! Versi PHP: 8.x.x
?>
```

## Kasus Penggunaan Nyata
Mahasiswa macOS yang baru belajar PHP bisa install XAMPP, langsung coba kode PHP tanpa setup rumit. Cocok untuk belajar, tidak ideal untuk production.
