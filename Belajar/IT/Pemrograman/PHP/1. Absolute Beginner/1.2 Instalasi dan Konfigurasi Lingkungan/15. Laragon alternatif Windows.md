# 15. Laragon alternatif Windows

## Definisi Singkat
Laragon adalah development environment modern untuk Windows yang ringan, portable, dan mendukung PHP, Apache/Nginx, MySQL/MariaDB, Redis, serta Node.js dalam satu paket terintegrasi.

## Analogi
Laragon seperti pisau Swiss Army digital: bukan hanya PHP, tapi juga Node.js, Python, Redis, Git, semuanya dalam satu aplikasi portable. Bisa dibawa di flashdisk.

## Poin-Poin Penting
- Download dari https://laragon.org/
- Portable: bisa diinstal di USB, tidak perlu admin rights
- Sangat ringan (~5MB) dibanding XAMPP (~150MB)
- Mendukung multiple PHP versions (switch instant)
- Addon system: install WordPress, Laravel, Joomla otomatis
- Auto virtual host: `project-name.test` langsung jalan
- Termasuk: Apache/Nginx, MySQL/MariaDB/PostgreSQL, Redis, Memcached
- Quick create: Laravel, Symfony, WordPress dengan 1 klik
- Notifikasi tray icon untuk start/stop services
- Fitur Pretty URLs tanpa konfigurasi Apache rewrite

## Contoh Kode (PHP)
```php
<?php
// Laragon: buka terminal Laragon, ketik:
// Quick create -> Laravel -> nama-proyek
// Langsung bisa diakses http://nama-proyek.test
echo json_encode([
    'app' => 'Laragon',
    'php' => PHP_VERSION,
    'server' => $_SERVER['SERVER_SOFTWARE'],
]);
?>
```

## Kasus Penggunaan Nyata
Web developer Windows yang jengah dengan XAMPP yang berat dan kaku beralih ke Laragon. Dengan 1 klik bisa buat proyek Laravel baru lengkap dengan database dan virtual host.
