# 18. phpMyAdmin manajemen database

## Definisi Singkat
phpMyAdmin adalah web-based tool untuk mengelola database MySQL/MariaDB melalui GUI, termasuk membuat database, tabel, menjalankan query SQL, import/export data, dan manajemen user.

## Analogi
phpMyAdmin seperti meja kerja admin perpustakaan dengan komputer: Anda bisa menambah rak buku baru (create database), mengatur kategori (create table), mencari buku (query), menambah koleksi (insert data), semuanya tanpa harus ingat nomor katalog (SQL).

## Poin-Poin Penting
- Akses via: `http://localhost/phpmyadmin` (setelah Apache + MySQL aktif)
- Login default: user `root`, password kosong (XAMPP)
- **Jangan biarkan root tanpa password di production!** Ganti password segera
- Fitur utama: Create database, Create table, Insert/Update/Delete data, Run SQL queries
- Import/Export SQL untuk backup dan migrasi database
- Cari database tabel di panel kiri, klik untuk melihat struktur
- Tab SQL untuk query manual, tab Insert untuk input data via form
- Tab Export untuk backup database (.sql), Import untuk restore
- Fitur Search untuk mencari data di seluruh tabel
- phpMyAdmin dikonfigurasi di `C:\xampp\phpMyAdmin\config.inc.php`

## Contoh Kode (PHP)
```php
<?php
// Membuat koneksi ke database yang sudah dibuat via phpMyAdmin
$conn = new mysqli("localhost", "root", "", "nama_database");
if ($conn->connect_error) {
    die("Koneksi gagal: " . $conn->connect_error);
}
echo "Terhubung ke database!";
$conn->close();
?>
```

## Kasus Penggunaan Nyata
Developer ingin membuat tabel `users` untuk fitur registrasi. Buka phpMyAdmin → New Database (nama: "web_app") → Create Table (nama: "users", kolom: id, username, email, password) → Save. Siap digunakan dari PHP.
