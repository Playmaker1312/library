# 24. Upload file size upload_max_filesize

## Definisi Singkat
`upload_max_filesize` di php.ini membatasi ukuran maksimal file yang bisa diunggah melalui PHP. Pengaturan terkait: `post_max_size` (total POST data) dan `memory_limit` (memori untuk memproses).

## Analogi
Seperti lift barang di gedung: `upload_max_filesize` adalah kapasitas maksimal per barang (100kg per file). `post_max_size` adalah total kapasitas lift sekali jalan (200kg total). `memory_limit` adalah kekuatan motor lift (seberapa kuat menarik beban).

## Poin-Poin Penting
- `upload_max_filesize` default: 2M (terlalu kecil untuk kebanyakan aplikasi modern)
- `post_max_size` harus lebih besar dari `upload_max_filesize` (minimal 20% lebih besar)
- `memory_limit` harus cukup untuk memproses file yang diupload
- `max_file_uploads` membatasi jumlah file per request (default 20)
- `file_uploads = On` harus aktif
- Untuk upload file besar (>100MB), pertimbangkan chunked upload atau cloud storage
- Di PHP 8+, limit upload file lebih strict untuk keamanan
- Rekomendasi untuk app gambar: `upload_max_filesize = 10M`, `post_max_size = 12M`
- Untuk app video: `upload_max_filesize = 100M`, `post_max_size = 110M`

## Contoh Kode (PHP)
```php
<?php
// Cek limit upload saat ini
echo "Max upload: " . ini_get('upload_max_filesize') . "<br>";
echo "Max POST: " . ini_get('post_max_size') . "<br>";
echo "Max file count: " . ini_get('max_file_uploads') . "<br>";

// Form upload (HTML):
?>
<form method="POST" enctype="multipart/form-data">
    <input type="file" name="file">
    <input type="hidden" name="MAX_FILE_SIZE" value="5000000">
    <button type="submit">Upload</button>
</form>
<?php
if ($_SERVER['REQUEST_METHOD'] === 'POST' && isset($_FILES['file'])) {
    echo "File: " . $_FILES['file']['name'] . " (" . $_FILES['file']['size'] . " bytes)";
}
?>
```

## Kasus Penggunaan Nyata
Website foto wedding perlu upload gambar resolusi tinggi (5-8MB per file). Ubah php.ini: `upload_max_filesize = 20M`, `post_max_size = 25M`, `memory_limit = 128M`. Restart Apache. User bisa upload foto tanpa error "File too large".
