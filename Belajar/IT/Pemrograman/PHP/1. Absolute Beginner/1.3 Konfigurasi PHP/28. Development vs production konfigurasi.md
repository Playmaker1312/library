# 28. Development vs production konfigurasi

## Definisi Singkat
Konfigurasi PHP untuk development (error ditampilkan, caching dimatikan) sangat berbeda dengan production (error disembunyikan, caching diaktifkan, limit diperketat). Menggunakan konfigurasi yang salah berbahaya.

## Analogi
Development seperti bengkel mobil dengan pintu terbuka: semua orang bisa lihat proses perbaikan, alat berserakan, dan mekanik bekerja bebas. Production seperti showroom: bersih, rapi, pelanggan hanya lihat hasil akhir, area service tertutup.

## Poin-Poin Penting
| Pengaturan | Development | Production |
|---|---|---|
| display_errors | On | Off |
| error_reporting | E_ALL | E_ALL & ~E_DEPRECATED |
| log_errors | On | On |
| opcache | Off | On |
| opcache.validate_timestamps | 1 | 0 |
| expose_php | On | Off |
| max_execution_time | 120 | 30 |
| memory_limit | 256M | 128M |
| allow_url_fopen | On | On (dengan hati-hati) |

- Di production, selalu set `display_errors = Off` agar user tidak lihat stack trace
- Gunakan `error_log` untuk mencatat error di file terpisah
- Opcache di production meningkatkan performa 2-5x
- `expose_php = Off` menyembunyikan versi PHP dari header HTTP (keamanan)
- Laravel: `.env` dengan `APP_DEBUG=true` (dev) / `false` (prod)

## Contoh Kode (PHP)
```php
<?php
// Deteksi environment otomatis
$is_development = in_array($_SERVER['SERVER_NAME'] ?? '', ['localhost', '127.0.0.1']);

if ($is_development) {
    error_reporting(E_ALL);
    ini_set('display_errors', '1');
    $env = "DEVELOPMENT";
} else {
    error_reporting(E_ALL & ~E_DEPRECATED & ~E_NOTICE);
    ini_set('display_errors', '0');
    ini_set('log_errors', '1');
    $env = "PRODUCTION";
}

echo "Mode: $env<br>";
echo "PHP: " . PHP_VERSION;
?>
```

## Kasus Penggunaan Nyata
Setelah deploy aplikasi ke server hosting, user melihat "Warning: Undefined variable" di halaman. Segera edit php.ini: `display_errors = Off`. Error tetap tercatat di log untuk debugging, user melihat halaman bersih tanpa error.
