# 30. PHP version manager phpenv phpbrew

## Definisi Singkat
PHP version manager (phpenv, phpbrew) memungkinkan instalasi dan switch antara multiple PHP versions (7.4, 8.0, 8.1, 8.2, 8.3, 8.4) di satu sistem, berguna untuk testing kompatibilitas aplikasi di berbagai versi PHP.

## Analogi
Seperti memiliki beberapa pasang sepatu untuk aktivitas berbeda: sepatu lari (PHP 8.4 untuk proyek baru), sepatu formal (PHP 8.0 untuk aplikasi legacy), sepatu santai (PHP 7.4 untuk maintenance). Anda tinggal ganti sesuai kebutuhan tanpa beli baru.

## Poin-Poin Penting
- **phpenv** (Linux/macOS): fork dari rbenv, ringan, bash-based
- **phpbrew** (Linux/macOS): build PHP dari source, bisa install extension custom
- **Laragon** (Windows): sudah memiliki fitur switch PHP version dengan GUI
- **Herd** (macOS): built-in multi-version PHP, switch via GUI
- **Docker**: alternatif modern - setiap proyek punya container dengan versi PHP sendiri
- Cara phpenv: `phpenv install 8.4.0`, `phpenv global 8.4.0`, `phpenv local 8.0.0`
- Cara phpbrew: `phpbrew install 8.4.0 +default`, `phpbrew switch 8.4.0`
- Di Windows, alternatif native terbatas; Laragon adalah solusi terbaik
- PHP 8.4 compile membutuhkan memori >2GB jika build dari source

## Contoh Kode (PHP)
```php
<?php
// Kode ini mendeteksi versi PHP yang sedang aktif
echo "PHP Version: " . PHP_VERSION . "<br>";
echo "PHP Major: " . PHP_MAJOR_VERSION . "<br>";
echo "PHP Minor: " . PHP_MINOR_NERSION . "<br>";

// Cek fitur yang tersedia berdasarkan versi
if (PHP_VERSION_ID >= 80100) {
    echo "Fitur Enum tersedia<br>";
}
if (PHP_VERSION_ID >= 80000) {
    echo "Fitur PHP 8 tersedia (JIT, Attributes, dll)<br>";
}
?>
```

## Kasus Penggunaan Nyata
Developer ingin migrasi aplikasi Laravel dari PHP 7.4 ke 8.4. Dengan phpbrew, install PHP 7.4 dan 8.4. Tes aplikasi di 8.4 tanpa menghapus 7.4. Jika ada error, switch kembali ke 7.4 untuk produksi sambil memperbaiki kompatibilitas.
