# 22. Lokasi php.ini aktif

## Definisi Singkat
Mengetahui lokasi file `php.ini` aktif penting karena PHP bisa memiliki beberapa file konfigurasi. Fungsi `phpinfo()` atau perintah `php --ini` membantu menemukan file mana yang sedang digunakan.

## Analogi
Seperti mencari remote control yang benar: Anda mungkin punya beberapa remote, tapi hanya satu yang terhubung ke TV. `phpinfo()` menunjukkan remote mana yang aktif, bukan remote yang tergeletak di meja.

## Poin-Poin Penting
- Cek via browser: buat file `info.php` dengan `<?php phpinfo(); ?>`, cari baris "Loaded Configuration File"
- Cek via CLI: `php --ini` di terminal
- Lokasi umum:
  - XAMPP Windows: `C:\xampp\php\php.ini`
  - XAMPP macOS: `/Applications/XAMPP/etc/php.ini`
  - LAMPP Linux: `/opt/lampp/etc/php.ini`
  - Ubuntu apt: `/etc/php/8.x/apache2/php.ini` (Apache) atau `/etc/php/8.x/cli/php.ini` (CLI)
  - Laragon: `C:\laragon\bin\php\php-8.x\php.ini`
- PHP CLI dan Apache bisa menggunakan php.ini berbeda
- Cek `phpinfo()` juga baris "Scan this dir for additional .ini files" untuk file terpisah
- Setelah mengubah php.ini, restart web server (Apache/Nginx) agar berlaku

## Contoh Kode (PHP)
```php
<?php
// Cara termudah: buat file info.php
phpinfo();
// Cari "Loaded Configuration File" di halaman yang muncul
// Alternatif programatik:
echo "php.ini path: " . php_ini_loaded_file() . "<br>";
echo "Scan dir: " . (php_ini_scanned_files() ?: 'tidak ada');
?>
```

## Kasus Penggunaan Nyata
Setelah mengubah `upload_max_filesize` di `C:\xampp\php\php.ini` tapi tidak berpengaruh, cek `phpinfo()` ternyata XAMPP menggunakan file di `C:\xampp\apache\bin\php.ini` juga. Ubah keduanya lalu restart Apache.
