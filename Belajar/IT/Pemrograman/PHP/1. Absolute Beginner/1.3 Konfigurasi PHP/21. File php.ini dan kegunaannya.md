# 21. File php.ini dan kegunaannya

## Definisi Singkat
`php.ini` adalah file konfigurasi utama PHP yang mengatur semua aspek perilaku PHP, termasuk error reporting, memory limit, upload size, ekstensi, dan timezone. Tanpa file ini, PHP menggunakan nilai default.

## Analogi
php.ini seperti buku panduan operasional mesin pabrik: Anda bisa mengatur suhu (memory_limit), kecepatan konveyor (max_execution_time), ukuran bahan baku (upload_max_filesize), dan jenis sensor (error_reporting). Setiap pengaturan mempengaruhi bagaimana mesin (PHP) bekerja.

## Poin-Poin Penting
- Format: `direktif = nilai` (case-sensitive untuk direktif)
- Komentar dengan titik koma `;`
- Nilai boolean: `On`/`Off`, `true`/`false`, `1`/`0`
- Nilai ukuran: menggunakan shorthand (K=KB, M=MB, G=GB) contoh: `128M`
- Dibaca saat PHP startup, perubahan butuh restart web server
- PHP 8+ memiliki default yang lebih aman (misal: `display_errors=Off` di production)
- Pengaturan bisa dioverride di runtime dengan `ini_set()` untuk beberapa direktif
- Beberapa direktif hanya bisa di php.ini (PHP_INI_SYSTEM), tidak bisa di runtime

## Contoh Kode (PHP)
```php
<?php
// Melihat nilai php.ini saat runtime
echo "Memory limit: " . ini_get('memory_limit') . "<br>";
echo "Max upload: " . ini_get('upload_max_filesize') . "<br>";
echo "Timezone: " . ini_get('date.timezone') . "<br>";

// Mengubah sementara (hanya script ini)
ini_set('max_execution_time', 300);
echo "Max execution: " . ini_get('max_execution_time') . " detik";
?>
```

## Kasus Penggunaan Nyata
Aplikasi e-commerce perlu upload gambar produk besar (max 10MB). Edit `php.ini`: `upload_max_filesize = 10M`, `post_max_size = 12M`, lalu restart Apache. Atau jika tidak punya akses php.ini, buat `.user.ini` di folder project.
