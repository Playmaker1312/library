# 29. Instal PHP terpisah tanpa XAMPP

## Definisi Singkat
PHP bisa diinstal secara standalone (tanpa Apache/MySQL) langsung dari situs resmi windows.php.net. Berguna untuk developer yang ingin menggunakan PHP dengan web server atau environment berbeda.

## Analogi
Instal PHP terpisah seperti membeli mesin mobil terpisah: Anda bisa memasangnya di berbagai jenis kendaraan (Apache, Nginx, IIS) atau bahkan menggunakannya sendiri untuk balapan (CLI scripting). Lebih fleksibel daripada paket all-in-one.

## Poin-Poin Penting
- **Windows**: Download ZIP dari https://windows.php.net/download/ → extract ke `C:\php` → tambahkan ke PATH
- **macOS**: `brew install php` (Homebrew) - cara termudah
- **Linux Ubuntu**: `sudo apt install php8.4 php8.4-cli php8.4-common php8.4-mysql php8.4-curl`
- Setelah instal, cek: `php -v` di terminal
- Untuk development, perlu setup sendiri: konfigurasi dengan web server, atur php.ini
- PATH environment variable penting agar `php` bisa dipanggil dari mana saja
- Windows: Install Visual C++ Redistributable jika diperlukan
- Linux: bisa install extension via `sudo apt install php8.4-{extension_name}`
- Kelebihan: kontrol penuh, tanpa bloatware, versi lebih update

## Contoh Kode (PHP)
```php
<?php
// Cek apakah PHP diinstal terpisah atau via paket
echo "PHP Installed at: " . PHP_BINARY . "<br>";
echo "Config: " . php_ini_loaded_file() . "<br>";
echo "Extension dir: " . PHP_EXTENSION_DIR . "<br>";

// Test apakah PHP standalone bisa jalan
echo "PHP berfungsi dengan baik!<br>";
echo "Server API: " . PHP_SAPI; // CLI jika dari terminal
?>
```

## Kasus Penggunaan Nyata
Developer ingin menggunakan Nginx (bukan Apache) di Windows. Instal PHP standalone dari windows.php.net, instal Nginx terpisah, konfigurasi Nginx untuk mengarah ke PHP melalui FastCGI (php-cgi.exe atau php-fpm).
