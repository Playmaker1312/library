# 26. Extension PHP di php.ini

## Definisi Singkat
Extension PHP adalah library tambahan yang menyediakan fungsionalitas spesifik (misal: mysqli, gd, curl, mbstring). Extension dimuat di `php.ini` dengan direktif `extension=nama_extensi`.

## Analogi
Extension seperti aplikasi di smartphone: OS (PHP) hanya punya fungsi dasar. Mau foto? Install kamera (gd extension). Mau browsing? Install Chrome (curl extension). Mau kirim WA? Install WhatsApp (mbstring/mysqli). Semua dikelola di settings (php.ini).

## Poin-Poin Penting
- Format: `extension=curl` atau `extension=php_curl.dll` (Windows)
- Di XAMPP, banyak extension sudah tersedia tinggal uncomment (hapus `;`)
- Extension umum: curl (HTTP), gd (image processing), mysqli (MySQL), mbstring (multibyte), openssl (enkripsi), pdo_mysql (PDO MySQL), xml, zip, intl (internasionalisasi)
- PHP 8+ mengaktifkan extension secara otomatis untuk extension inti
- Extension pihak ketiga: xdebug (debugging), xhprof (profiling), igbinary (serializer)
- Cek extension aktif: `phpinfo()` atau `get_loaded_extensions()`
- Extension disabled untuk keamanan di environment shared hosting
- Module baru di PHP 8.4: `php -m` untuk lihat semua module

## Contoh Kode (PHP)
```php
<?php
// Cek extension yang aktif
$extensions = get_loaded_extensions();
sort($extensions);
echo "Extension aktif: " . count($extensions) . "<br>";
echo implode(", ", array_slice($extensions, 0, 10)) . "...<br>";

// Cek extension spesifik
echo "Curl: " . (extension_loaded('curl') ? 'Ada' : 'Tidak ada') . "<br>";
echo "GD: " . (extension_loaded('gd') ? 'Ada' : 'Tidak ada') . "<br>";
echo "MBString: " . (extension_loaded('mbstring') ? 'Ada' : 'Tidak ada') . "<br>";
?>
```

## Kasus Penggunaan Nyata
Aplikasi butuh resize gambar profil (butuh GD) dan kirim request ke API pembayaran (butuh cURL). Di php.ini, pastikan `extension=gd` dan `extension=curl` tidak dikomentari. Restart Apache. Jika GD tidak ada, install dengan `sudo apt install php-gd`.
