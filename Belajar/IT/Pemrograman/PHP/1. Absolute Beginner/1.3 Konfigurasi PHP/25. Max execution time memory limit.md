# 25. Max execution time memory limit

## Definisi Singkat
`max_execution_time` membatasi waktu maksimal eksekusi skrip PHP (default 30 detik), sedangkan `memory_limit` membatasi memori maksimal yang bisa digunakan skrip (default 128M). Keduanya mencegah skrip nakal menghabiskan sumber daya server.

## Analogi
Seperti antrean di restoran: `max_execution_time` adalah batas waktu setiap pelanggan makan (30 menit). Jika terlalu lama, pelanggan diminta pergi. `memory_limit` adalah batas piring yang bisa diambil (jika ambil 20 piring, dilarang). Ini memastikan semua pelanggan kebagian meja.

## Poin-Poin Penting
- `max_execution_time` dalam detik, `0` berarti tanpa batas (hanya untuk CLI)
- Waktu tidak termasuk operasi database atau file eksternal (system calls)
- `memory_limit` di PHP 8+ default 128M, bisa dinaikkan ke 256M/512M
- `memory_limit = -1` berarti tanpa batas (berbahaya, jangan di production)
- Untuk skrip panjang (cron job, import data): set di runtime dengan `set_time_limit(0)`
- `max_input_time` batas waktu parsing input data (upload file besar)
- PHP 8.4: memory_limit bisa diubah via `ini_set()` untuk semua fase termasuk startup

## Contoh Kode (PHP)
```php
<?php
// Cek limit saat ini
echo "Max execution: " . ini_get('max_execution_time') . " detik<br>";
echo "Memory limit: " . ini_get('memory_limit') . "<br>";

// Ubah untuk skrip yang butuh waktu lama
set_time_limit(120); // 2 menit
ini_set('memory_limit', '256M');

echo "Skrip akan jalan dengan limit baru<br>";

// Simulasi proses panjang
$start = microtime(true);
$data = range(1, 100000);
echo "Array dengan " . count($data) . " elemen dibuat dalam ";
echo round(microtime(true) - $start, 2) . " detik";
?>
```

## Kasus Penggunaan Nyata
Fitur export laporan Excel dengan 100.000 baris: PHP butuh waktu >30 detik dan memori >128M. Set `set_time_limit(300)` dan `ini_set('memory_limit', '512M')` di awal skrip agar tidak timeout.
