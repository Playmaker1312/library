# 27. phpinfo melihat konfigurasi

## Definisi Singkat
`phpinfo()` adalah fungsi PHP yang menampilkan informasi lengkap tentang konfigurasi PHP, termasuk versi, php.ini path, extension aktif, environment variables, dan server information.

## Analogi
phpinfo() seperti kartu identitas dan CV seseorang: menampilkan nama (versi), alamat (php.ini path), keahlian (extension), riwayat (konfigurasi), dan data diri (server info). Sangat berguna saat perkenalan pertama dengan server.

## Poin-Poin Penting
- Cukup buat file `<?php phpinfo(); ?>` dan akses via browser
- Output berisi ribuan baris informasi terstruktur dalam tabel
- Bagian penting: PHP Version, Loaded Configuration File, Server API, error_reporting, extension info
- Gunakan `phpinfo(INFO_MODULES)` untuk informasi extension tertentu saja
- `phpinfo(8)` atau `phpinfo(INFO_CONFIGURATION)` hanya konfigurasi
- **Jangan biarkan file phpinfo() di production!** Sangat berbahaya (informasi server bocor)
- CLI: `php -i` untuk versi terminal dari phpinfo()
- `php --ini` untuk informasi php.ini saja
- `php -m` lihat module/extension yang terload

## Contoh Kode (PHP)
```php
<?php
// phpinfo() lengkap
phpinfo();

// Atau tampilkan ringkasan sendiri
echo "PHP Version: " . PHP_VERSION . "<br>";
echo "OS: " . PHP_OS . "<br>";
echo "Server API: " . PHP_SAPI . "<br>";
echo "Int size: " . PHP_INT_SIZE . " bytes<br>";
echo "Max int: " . PHP_INT_MAX . "<br>";
echo "Extension dir: " . PHP_EXTENSION_DIR . "<br>";
?>
```

## Kasus Penggunaan Nyata
Developer pindah ke server baru dan ingin tahu konfigurasi PHP. Buat `info.php` dengan `phpinfo()`, upload ke server, akses via browser. Cek "Loaded Configuration File" untuk path php.ini, pastikan extension yang dibutuhkan aktif.
