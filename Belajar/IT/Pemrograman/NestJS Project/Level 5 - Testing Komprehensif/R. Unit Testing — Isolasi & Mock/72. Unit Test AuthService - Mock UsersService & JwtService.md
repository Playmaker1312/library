# 72. Unit Test AuthService — Mock UsersService & JwtService

## Penjelasan

AuthService adalah salah satu service paling kritis dalam aplikasi NestJS karena menangani autentikasi dan otorisasi pengguna. Service ini biasanya bergantung pada `UsersService` (untuk mencari dan menyimpan data user), `JwtService` (untuk membuat dan memverifikasi token JWT), dan `ConfigService` (untuk membaca konfigurasi seperti JWT_SECRET dan JWT_EXPIRATION). Menguji AuthService tanpa mock berarti kita harus menyediakan database nyata dengan data user, yang memperlambat test dan membuatnya tidak deterministik.

Mocking pada AuthService membutuhkan perhatian khusus karena kita perlu mensimulasikan berbagai skenario keamanan: registrasi dengan email yang sudah terdaftar, login dengan password salah, refresh token dengan token expired, dan logout dengan token yang tidak valid. Setiap skenario harus mengembalikan HTTP status code dan pesan error yang sesuai. Jest memungkinkan kita mengatur return value mock secara dinamis per test case, sehingga kita bisa dengan mudah berganti antara "user ditemukan" dan "user tidak ditemukan".

Salah satu tantangan terbesar dalam testing AuthService adalah handling hash password. Kita tidak ingin benar-benar melakukan bcrypt hash di unit test karena itu lambat. Solusinya adalah memisahkan tanggung jawab: buat adapter atau utility terpisah untuk hashing, lalu mock utility tersebut. Atau kita bisa menggunakan `jest.spyOn` pada method `bcrypt.compare` dan `bcrypt.hash` secara langsung. Pendekatan yang lebih baik adalah membuat `PasswordHasher` interface yang di-inject, sehingga bisa di-mock dengan mudah.

## Fungsi

- Memvalidasi logika registrasi: validasi email unik, hash password, return token
- Memvalidasi logika login: verifikasi password, generate access & refresh token
- Memvalidasi refresh token: verifikasi token lama, generate token baru
- Memvalidasi logout: hapus refresh token dari database/redis
- Menguji error handling: email sudah terdaftar, password salah, token expired
- Memastikan flow autentikasi berjalan dari awal hingga akhir secara aman

```typescript
// src/auth/auth.service.spec.ts
import { Test, TestingModule } from '@nestjs/testing';
import {
  ConflictException,
  UnauthorizedException,
} from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';
import { ConfigService } from '@nestjs/config';
import * as bcrypt from 'bcrypt';
import { AuthService } from './auth.service';
import { RegisterDto } from './dto/register.dto';
import { LoginDto } from './dto/login.dto';
import { UsersService } from '../users/users.service';
import { Role } from './enums/role.enum';
import { mockUser, mockUsersService, mockJwtService, mockConfigService } from '../../test/mocks/auth.mock';

describe('AuthService', () => {
  let service: AuthService;
  let usersService: jest.Mocked<UsersService>;
  let jwtService: jest.Mocked<JwtService>;
  let configService: jest.Mocked<ConfigService>;

  beforeEach(async () => {
    const module: TestingModule = await Test.createTestingModule({
      providers: [
        AuthService,
        { provide: UsersService, useValue: mockUsersService },
        { provide: JwtService, useValue: mockJwtService },
        { provide: ConfigService, useValue: mockConfigService },
      ],
    }).compile();

    service = module.get<AuthService>(AuthService);
    usersService = module.get(UsersService) as jest.Mocked<UsersService>;
    jwtService = module.get(JwtService) as jest.Mocked<JwtService>;
    configService = module.get(ConfigService) as jest.Mocked<ConfigService>;

    jest.clearAllMocks();

    // Default config mock
    configService.get.mockImplementation((key: string) => {
      const configs: Record<string, string> = {
        JWT_ACCESS_SECRET: 'access-secret',
        JWT_ACCESS_EXPIRATION: '15m',
        JWT_REFRESH_SECRET: 'refresh-secret',
        JWT_REFRESH_EXPIRATION: '7d',
      };
      return configs[key] ?? null;
    });
  });

  // ============== REGISTER ==============

  describe('register', () => {
    const registerDto: RegisterDto = {
      email: 'john@example.com',
      password: 'password123',
      name: 'John Doe',
    };

    it('should register a new user successfully', async () => {
      usersService.findByEmail.mockResolvedValue(null);
      usersService.create.mockResolvedValue(mockUser);

      jest.spyOn(bcrypt, 'hash').mockResolvedValue('$2b$10$hashedPassword' as never);

      jwtService.sign
        .mockReturnValueOnce('access-token')  // access token
        .mockReturnValueOnce('refresh-token'); // refresh token

      usersService.updateRefreshToken.mockResolvedValue(undefined);

      const result = await service.register(registerDto);

      expect(result).toEqual({
        accessToken: 'access-token',
        refreshToken: 'refresh-token',
        user: expect.objectContaining({ email: 'john@example.com' }),
      });

      expect(usersService.findByEmail).toHaveBeenCalledWith('john@example.com');
      expect(bcrypt.hash).toHaveBeenCalledWith('password123', expect.any(Number));
      expect(usersService.create).toHaveBeenCalled();
      expect(jwtService.sign).toHaveBeenCalledTimes(2);
      expect(usersService.updateRefreshToken).toHaveBeenCalled();
    });

    it('should throw ConflictException if email already exists', async () => {
      usersService.findByEmail.mockResolvedValue(mockUser);

      await expect(service.register(registerDto)).rejects.toThrow(
        ConflictException,
      );
      expect(usersService.create).not.toHaveBeenCalled();
    });

    it('should propagate error if password hashing fails', async () => {
      usersService.findByEmail.mockResolvedValue(null);
      jest.spyOn(bcrypt, 'hash').mockRejectedValue(new Error('Hashing failed') as never);

      await expect(service.register(registerDto)).rejects.toThrow('Hashing failed');
    });
  });

  // ============== LOGIN ==============

  describe('login', () => {
    const loginDto: LoginDto = {
      email: 'john@example.com',
      password: 'password123',
    };

    it('should login successfully with valid credentials', async () => {
      usersService.findByEmail.mockResolvedValue(mockUser);
      jest.spyOn(bcrypt, 'compare').mockResolvedValue(true as never);

      jwtService.sign
        .mockReturnValueOnce('access-token')
        .mockReturnValueOnce('refresh-token');

      usersService.updateRefreshToken.mockResolvedValue(undefined);

      const result = await service.login(loginDto);

      expect(result).toEqual({
        accessToken: 'access-token',
        refreshToken: 'refresh-token',
        user: expect.objectContaining({ email: 'john@example.com' }),
      });

      expect(usersService.findByEmail).toHaveBeenCalledWith('john@example.com');
      expect(bcrypt.compare).toHaveBeenCalledWith('password123', mockUser.password);
    });

    it('should throw UnauthorizedException if email not found', async () => {
      usersService.findByEmail.mockResolvedValue(null);

      await expect(service.login(loginDto)).rejects.toThrow(UnauthorizedException);
    });

    it('should throw UnauthorizedException if password is incorrect', async () => {
      usersService.findByEmail.mockResolvedValue(mockUser);
      jest.spyOn(bcrypt, 'compare').mockResolvedValue(false as never);

      await expect(service.login(loginDto)).rejects.toThrow(UnauthorizedException);
    });

    it('should throw UnauthorizedException if user account is deactivated', async () => {
      const deactivatedUser = { ...mockUser, isActive: false };
      usersService.findByEmail.mockResolvedValue(deactivatedUser);

      await expect(service.login(loginDto)).rejects.toThrow(UnauthorizedException);
    });
  });

  // ============== REFRESH TOKEN ==============

  describe('refreshTokens', () => {
    const refreshToken = 'valid-refresh-token';
    const payload = { sub: 'user-1', email: 'john@example.com' };

    it('should refresh tokens successfully', async () => {
      jwtService.verify.mockReturnValue(payload);
      usersService.findById.mockResolvedValue({ ...mockUser, refreshToken: 'hashed-refresh-token' });
      jest.spyOn(bcrypt, 'compare').mockResolvedValue(true as never);

      jwtService.sign
        .mockReturnValueOnce('new-access-token')
        .mockReturnValueOnce('new-refresh-token');

      usersService.updateRefreshToken.mockResolvedValue(undefined);

      const result = await service.refreshTokens(refreshToken);

      expect(result.accessToken).toBe('new-access-token');
      expect(result.refreshToken).toBe('new-refresh-token');
      expect(jwtService.verify).toHaveBeenCalledWith(refreshToken, expect.any(Object));
    });

    it('should throw UnauthorizedException if refresh token is expired', async () => {
      jwtService.verify.mockImplementation(() => {
        throw new Error('jwt expired');
      });

      await expect(service.refreshTokens(refreshToken)).rejects.toThrow(
        UnauthorizedException,
      );
    });

    it('should throw UnauthorizedException if user not found', async () => {
      jwtService.verify.mockReturnValue(payload);
      usersService.findById.mockResolvedValue(null);

      await expect(service.refreshTokens(refreshToken)).rejects.toThrow(
        UnauthorizedException,
      );
    });
  });

  // ============== LOGOUT ==============

  describe('logout', () => {
    it('should logout successfully by clearing refresh token', async () => {
      usersService.updateRefreshToken.mockResolvedValue(undefined);

      const result = await service.logout('user-1');

      expect(result).toEqual({ message: 'Logout successful' });
      expect(usersService.updateRefreshToken).toHaveBeenCalledWith('user-1', null);
    });

    it('should handle logout for non-existent user gracefully', async () => {
      usersService.updateRefreshToken.mockRejectedValue(
        new Error('User not found'),
      );

      await expect(service.logout('non-existent')).rejects.toThrow();
    });
  });
});
```

## Analogi

Bayangkan perpustakaan memiliki **sistem keanggotaan**. Petugas pendaftaran (AuthService) perlu memverifikasi data calon anggota baru. Untuk menguji petugas ini, kita menggunakan **kartu anggota palsu** (mock UsersService) yang sudah berisi data contoh, **mesin cetak kartu palsu** (mock JwtService) yang selalu mencetak token yang bisa diprediksi, dan **papan aturan palsu** (mock ConfigService) yang berisi durasi keanggotaan. Dengan alat-alat palsu ini, kita bisa menguji: apakah petugas menolak pendaftaran dengan email yang sudah terdaftar? Apakah dia menolak login dengan password salah? Apakah dia berhasil memperpanjang kartu anggota yang masih berlaku? Semua ini diuji tanpa harus merekrut anggota sungguhan atau mencetak kartu asli.

## Penggunaan

- Memvalidasi seluruh flow autentikasi: register → login → refresh → logout
- Menguji keamanan: password salah, token expired, user tidak aktif
- Digunakan sebagai regression test saat mengubah mekanisme autentikasi
- Memastikan error handling berjalan dengan benar untuk semua skenario gagal
- Dokumentasi interaksi antara AuthService dengan dependency-nya

## Kesalahan Umum yang Sering Terjadi

1. **Tidak memock bcrypt dengan benar**: Bcrypt menggunakan native binding yang tidak bisa di-mock langsung. Solusi: gunakan `jest.spyOn(bcrypt, 'hash')` dan pastikan return type cocok dengan `as never`.

2. **ConfigService.get tidak di-mock untuk semua key**: AuthService membaca banyak konfigurasi (JWT_ACCESS_SECRET, JWT_REFRESH_SECRET, dll). Jika ada key yang tidak di-mock, test akan gagal. Solusi: gunakan `mockImplementation` dengan object lengkap.

3. **JwtService.sign dipanggil dengan urutan berbeda**: Test assertion gagal karena urutan pemanggilan `mockReturnValueOnce` tidak sesuai. Solusi: debug dengan `console.log` atau gunakan `mockReturnValue` (sama untuk semua panggilan).

4. **Lupa memverifikasi `updateRefreshToken`**: Token baru disimpan, tapi test hanya memeriksa return value. Padahal menyimpan refresh token di database adalah bagian kritis flow. Solusi: tambahkan assertion `toHaveBeenCalledWith`.

5. **Test refresh token tanpa memverifikasi token lama**: Refresh token yang sudah digunakan seharusnya di-invalidate (rotation). Solusi: tambahkan test case yang memverifikasi token lama tidak bisa dipakai dua kali.
