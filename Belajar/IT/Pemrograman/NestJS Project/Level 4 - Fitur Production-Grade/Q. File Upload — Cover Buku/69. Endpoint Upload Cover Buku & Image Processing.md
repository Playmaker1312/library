# 69. Endpoint Upload Cover Buku & Image Processing

## Penjelasan

Setelah Multer dikonfigurasi untuk menerima file, langkah selanjutnya adalah membuat endpoint yang memproses file tersebut lebih lanjut. Upload file mentah tidaklah cukup — kita perlu melakukan **image processing**: meresize gambar ke ukuran standar (400x600 piksel), mengkonversi ke format WebP (yang lebih ringan dari JPEG/PNG), dan menyimpan path-nya ke database. Untuk tugas ini, kita menggunakan library **Sharp** — library manipulasi gambar Node.js yang cepat dan efisien.

Endpoint `POST /books/:id/cover` akan: (1) menerima file upload melalui Multer, (2) memproses gambar dengan Sharp (resize + konversi WebP), (3) menghapus file mentah yang diupload Multer, (4) menyimpan path file hasil proses ke database (field `coverUrl`), dan (5) mengembalikan response berisi URL cover yang baru.

## Fungsi

Endpoint dan service upload berfungsi untuk menyediakan cover buku dengan kualitas dan ukuran yang konsisten. Image processing memastikan semua cover buku memiliki dimensi yang seragam (400x600), format yang efisien (WebP), dan ukuran file yang kecil untuk performa loading yang lebih baik.

### 2. Image Processing Service

```typescript
// src/books/services/image-processor.service.ts
import { Injectable, Logger } from '@nestjs/common';
import * as sharp from 'sharp';
import * as path from 'path';
import * as fs from 'fs';

@Injectable()
export class ImageProcessorService {
  private readonly logger = new Logger(ImageProcessorService.name);

  readonly COVER_WIDTH = 400;
  readonly COVER_HEIGHT = 600;
  readonly QUALITY = 80;

  async processCover(inputPath: string, bookId: string): Promise<string> {
    const outputDir = path.join(process.cwd(), 'uploads', 'covers', 'processed');

    if (!fs.existsSync(outputDir)) {
      fs.mkdirSync(outputDir, { recursive: true });
    }

    const outputFilename = `cover-${bookId}-${Date.now()}.webp`;
    const outputPath = path.join(outputDir, outputFilename);

    try {
      await sharp(inputPath)
        .resize(this.COVER_WIDTH, this.COVER_HEIGHT, {
          fit: 'cover',      // crop untuk memenuhi dimensi
          position: 'center', // fokus ke tengah
        })
        .webp({ quality: this.QUALITY })
        .toFile(outputPath);

      // Hapus file mentah dari Multer
      fs.unlinkSync(inputPath);

      // Path relatif untuk disimpan di DB
      return `/uploads/covers/processed/${outputFilename}`;

    } catch (error) {
      this.logger.error(`Image processing failed: ${error.message}`);
      // Jika proses gagal, hapus file mentah
      if (fs.existsSync(inputPath)) {
        fs.unlinkSync(inputPath);
      }
      throw error;
    }
  }

  async generateThumbnail(inputPath: string, bookId: string): Promise<string> {
    const outputDir = path.join(process.cwd(), 'uploads', 'covers', 'thumbnails');

    if (!fs.existsSync(outputDir)) {
      fs.mkdirSync(outputDir, { recursive: true });
    }

    const thumbnailPath = path.join(outputDir, `thumb-${bookId}.webp`);

    await sharp(inputPath)
      .resize(150, 225, { fit: 'cover', position: 'center' })
      .webp({ quality: 60 })
      .toFile(thumbnailPath);

    return `/uploads/covers/thumbnails/thumb-${bookId}.webp`;
  }

  async deleteCover(coverUrl: string): Promise<void> {
    if (!coverUrl) return;

    const fullPath = path.join(process.cwd(), coverUrl);
    const thumbnailPath = path.join(
      process.cwd(),
      'uploads',
      'covers',
      'thumbnails',
      `thumb-${path.basename(coverUrl).replace('cover-', '')}`,
    );

    // Hapus file cover
    if (fs.existsSync(fullPath)) {
      fs.unlinkSync(fullPath);
    }

    // Hapus thumbnail jika ada
    if (fs.existsSync(thumbnailPath)) {
      fs.unlinkSync(thumbnailPath);
    }
  }
}
```

### 3. Update BooksService

```typescript
// src/books/services/books.service.ts (tambahan)
import { ImageProcessorService } from './image-processor.service';

@Injectable()
export class BooksService {
  constructor(
    private readonly prisma: PrismaService,
    @Inject(CACHE_MANAGER) private cacheManager: Cache,
    private readonly imageProcessor: ImageProcessorService,
  ) {}

  async updateCover(id: string, file: Express.Multer.File) {
    const book = await this.prisma.book.findUnique({ where: { id } });
    if (!book) {
      throw new NotFoundException('Buku tidak ditemukan');
    }

    // Proses gambar (resize + convert to WebP)
    const coverUrl = await this.imageProcessor.processCover(file.path, id);

    // Hapus cover lama jika ada
    if (book.coverUrl) {
      await this.imageProcessor.deleteCover(book.coverUrl);
    }

    // Update database
    const updated = await this.prisma.book.update({
      where: { id },
      data: { coverUrl },
      include: { category: true },
    });

    // Invalidate cache
    await this.clearBooksCache(id);

    return updated;
  }

  async deleteCover(id: string) {
    const book = await this.prisma.book.findUnique({ where: { id } });
    if (!book || !book.coverUrl) {
      throw new NotFoundException('Cover tidak ditemukan');
    }

    await this.imageProcessor.deleteCover(book.coverUrl);

    const updated = await this.prisma.book.update({
      where: { id },
      data: { coverUrl: null },
    });

    await this.clearBooksCache(id);

    return updated;
  }
}
```

### 4. Controller Upload

```typescript
// src/books/controllers/books.controller.ts
import {
  Controller, Post, Delete, Param, UseGuards, UseInterceptors,
  UploadedFile, ParseFilePipe, MaxFileSizeValidator, FileTypeValidator,
  HttpCode, HttpStatus,
} from '@nestjs/common';
import { FileInterceptor } from '@nestjs/platform-express';
import { JwtAuthGuard } from '../../auth/guards/jwt-auth.guard';
import { RolesGuard } from '../../auth/guards/roles.guard';
import { Roles } from '../../auth/decorators/roles.decorator';
import { BooksService } from '../services/books.service';
import { imageFileFilter, MAX_FILE_SIZE } from '../../common/config/multer.config';
import { ApiTags, ApiOperation, ApiConsumes, ApiBody } from '@nestjs/swagger';

@ApiTags('Books')
@Controller('books')
export class BooksController {
  constructor(private readonly booksService: BooksService) {}

  @Post(':id/cover')
  @UseGuards(JwtAuthGuard, RolesGuard)
  @Roles('ADMIN')
  @UseInterceptors(
    FileInterceptor('cover', {
      fileFilter: imageFileFilter,
      limits: { fileSize: MAX_FILE_SIZE },
    }),
  )
  @ApiOperation({ summary: 'Upload cover buku' })
  @ApiConsumes('multipart/form-data')
  @ApiBody({
    schema: {
      type: 'object',
      properties: {
        cover: {
          type: 'string',
          format: 'binary',
        },
      },
    },
  })
  async uploadCover(
    @Param('id') id: string,
    @UploadedFile(
      new ParseFilePipe({
        validators: [
          new MaxFileSizeValidator({ maxSize: MAX_FILE_SIZE }),
          new FileTypeValidator({ fileType: /(jpg|jpeg|png|webp)$/ }),
        ],
        errorHttpStatusCode: HttpStatus.UNPROCESSABLE_ENTITY,
      }),
    )
    file: Express.Multer.File,
  ) {
    return this.booksService.updateCover(id, file);
  }

  @Delete(':id/cover')
  @UseGuards(JwtAuthGuard, RolesGuard)
  @Roles('ADMIN')
  @HttpCode(HttpStatus.NO_CONTENT)
  @ApiOperation({ summary: 'Hapus cover buku' })
  async deleteCover(@Param('id') id: string) {
    await this.booksService.deleteCover(id);
  }
}
```

## Analogi

Bayangkan perpustakaan memiliki **mesin laminasi** khusus untuk sampul buku. Anggota atau petugas bisa menyerahkan sampul kertas (file mentah) ke mesin ini. Mesin akan: memotong sampul sesuai ukuran standar buku (resize 400x600), melapisinya dengan plastik pelindung (konversi WebP), dan memberi label kode unik (nama file). Hasilnya adalah sampul yang rapi, seragam, dan tahan lama — siap ditempelkan ke buku. Sampul kertas asli yang sudah diproses akan dibuang (hapus file mentah). Mesin laminasi ini adalah **Sharp + ImageProcessor**.

## Penggunaan

Endpoint upload cover digunakan oleh:
- **Admin panel**: form upload cover saat menambah atau mengedit buku
- **Batch import**: script migrasi data dari sistem lama
- **API integration**: sistem lain yang ingin menyediakan cover buku
- **User request**: anggota bisa mengusulkan cover untuk buku yang belum punya (setelah review admin)

## Kesalahan Umum yang Sering Terjadi

1. **Sharp error karena file corrupt** — Sharp akan throw error jika file input rusak. Tangkap error dan beri response yang jelas.
2. **Ukuran file membengkak setelah processing** — jika kualitas WebP terlalu tinggi (>90%), file bisa lebih besar dari JPEG asli. Gunakan kualitas 70-80 sebagai default.
3. **Lupa handle update cover** — jika buku sudah punya cover dan diupload ulang, cover lama harus dihapus dari disk untuk mencegah file sampah menumpuk.
4. **Path tidak konsisten** — path yang disimpan di DB harus cocok dengan prefix `useStaticAssets`. Jika server dijalankan dari direktori berbeda, path absolut bisa bermasalah.
5. **Race condition rename** — jika dua request upload cover untuk buku yang sama terjadi bersamaan, file bisa tertimpa. Gunakan timestamp yang presisi.

## Soal Latihan

**Soal:**
Buat method `processCoverWithWatermark()` di ImageProcessorService yang menambahkan watermark teks "PERPUSTAKAAN DIGITAL" di pojok kanan bawah cover. Gunakan `sharp.composite()`.

**Jawaban:**

```typescript
import * as sharp from 'sharp';

async processCoverWithWatermark(inputPath: string, bookId: string): Promise<string> {
  const outputPath = path.join(process.cwd(), 'uploads', 'covers', 'watermarked', `cover-${bookId}.webp`);

  // Buat SVG watermark
  const watermarkSvg = Buffer.from(`
    <svg width="400" height="600" xmlns="http://www.w3.org/2000/svg">
      <text x="380" y="580" font-family="Arial" font-size="14"
            fill="white" opacity="0.6" text-anchor="end">
        PERPUSTAKAAN DIGITAL
      </text>
    </svg>
  `);

  await sharp(inputPath)
    .resize(400, 600, { fit: 'cover', position: 'center' })
    .webp({ quality: 80 })
    .composite([
      {
        input: watermarkSvg,
        top: 0,
        left: 0,
      },
    ])
    .toFile(outputPath);

  if (fs.existsSync(inputPath)) {
    fs.unlinkSync(inputPath);
  }

  return `/uploads/covers/watermarked/cover-${bookId}.webp`;
}
```
