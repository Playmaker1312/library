# 61. Scheduled Job — Cron untuk Update Status Overdue

## Penjelasan

Di aplikasi perpustakaan, status peminjaman buku perlu diperbarui secara otomatis ketika melewati batas waktu pengembalian. Karena tidak mungkin mengharapkan user untuk manual meng-update status, kita membutuhkan **scheduled job** (cron job) yang berjalan secara periodik — misalnya setiap jam pada menit ke-0 — untuk mengecek semua loan dengan status `ACTIVE` yang `dueDate`-nya sudah lewat, lalu mengubah statusnya menjadi `OVERDUE`.

NestJS menyediakan package `@nestjs/schedule` yang mendukung dekorator `@Cron()` untuk menjadwalkan eksekusi method pada waktu tertentu. Kita bisa menggunakan `CronExpression` enum untuk pattern yang umum (setiap jam, setiap hari tengah malam, dll), atau menulis ekspresi cron kustom. `OverdueCheckerTask` adalah service khusus yang berisi logika pengecekan dan update status overdue.

## Fungsi

Scheduled job berfungsi untuk mengeksekusi tugas tertentu secara otomatis pada jadwal yang telah ditentukan, tanpa campur tangan pengguna. Dalam konteks ini, `OverdueCheckerTask` secara periodik mendeteksi peminjaman yang terlambat dan memperbarui statusnya.

## Cara Implementasi / Code

### 1. Install @nestjs/schedule

```bash
npm install @nestjs/schedule
```

### 2. Import ScheduleModule

```typescript
// src/schedule/schedule.module.ts
import { Module } from '@nestjs/common';
import { ScheduleModule } from '@nestjs/schedule';
import { OverdueCheckerTask } from './tasks/overdue-checker.task';
import { LoansModule } from '../loans/loans.module';

@Module({
  imports: [
    ScheduleModule.forRoot(),
    LoansModule,
  ],
  providers: [OverdueCheckerTask],
})
export class TaskScheduleModule {}
```

### 3. Buat OverdueCheckerTask

```typescript
// src/schedule/tasks/overdue-checker.task.ts
import { Injectable, Logger } from '@nestjs/common';
import { Cron, CronExpression } from '@nestjs/schedule';
import { PrismaService } from '../../prisma/prisma.service';

@Injectable()
export class OverdueCheckerTask {
  private readonly logger = new Logger(OverdueCheckerTask.name);

  constructor(private readonly prisma: PrismaService) {}

  /**
   * Berjalan setiap jam pada menit ke-0
   * Contoh: 00:00, 01:00, 02:00, ...
   */
  @Cron(CronExpression.EVERY_HOUR)
  async checkOverdueLoans() {
    this.logger.log('Memeriksa peminjaman yang terlambat...');

    const now = new Date();

    const result = await this.prisma.loan.updateMany({
      where: {
        status: 'ACTIVE',
        dueDate: { lt: now }, // dueDate < sekarang
      },
      data: {
        status: 'OVERDUE',
      },
    });

    if (result.count > 0) {
      this.logger.log(`${result.count} peminjaman diubah statusnya menjadi OVERDUE`);
    } else {
      this.logger.log('Tidak ada peminjaman yang terlambat');
    }

    return result;
  }

  /**
   * Berjalan setiap hari jam 08:00 — dispatch notifikasi overdue
   */
  @Cron('0 8 * * *')
  async dispatchOverdueNotifications() {
    this.logger.log('Mendispatch notifikasi overdue harian...');

    const overdueLoans = await this.prisma.loan.findMany({
      where: { status: 'OVERDUE' },
      include: { user: true, book: true },
    });

    for (const loan of overdueLoans) {
      const daysOverdue = Math.floor(
        (Date.now() - loan.dueDate.getTime()) / (1000 * 60 * 60 * 24),
      );

      // Dispatch job email untuk setiap overdue
      await this.emailQueue.add('send-overdue-notice', {
        email: loan.user.email,
        userName: loan.user.name,
        bookTitle: loan.book.title,
        daysOverdue,
      });
    }

    this.logger.log(`Notifikasi dikirim ke ${overdueLoans.length} anggota`);
  }
}
```

### 5. Dynamic Cron — Ubah Jadwal Runtime

```typescript
import { SchedulerRegistry } from '@nestjs/schedule';

@Injectable()
export class DynamicCronService {
  constructor(private schedulerRegistry: SchedulerRegistry) {}

  addCronJob(name: string, expression: string, callback: () => void) {
    const job = new CronJob(expression, callback);
    this.schedulerRegistry.addCronJob(name, job);
    job.start();
  }

  stopCronJob(name: string) {
    const job = this.schedulerRegistry.getCronJob(name);
    job.stop();
  }
}
```

## Analogi

Di perpustakaan, setiap hari pada jam 12 malam, **petugas piket malam** berkeliling memeriksa semua kartu peminjaman di rak. Kartu yang tanggal pengembaliannya sudah lewat akan diberi stempel merah "TERLAMBAT" dan dipindahkan ke tumpukan khusus. Keesokan paginya, petugas lain akan mengirim surat pemberitahuan ke anggota yang bersangkutan. Cron job `OverdueCheckerTask` adalah petugas piket malam, dan jadwal jam 12 malam adalah ekspresi cron `0 0 * * *`.

## Penggunaan

Scheduled job digunakan untuk berbagai tugas periodik:
- **Overdue checker**: update status peminjaman
- **Backup database**: backup otomatis setiap hari
- **Cleanup**: hapus token expired, session basi, log lama
- **Report**: generate laporan harian/mingguan
- **Sync**: sinkronisasi data dengan sistem eksternal
- **Reminder**: kirim pengingat pengembalian H-1

## Kesalahan Umum yang Sering Terjadi

1. **Cron expression salah** — tool seperti crontab.guru sangat membantu. Expression `0 0 * * *` (setiap jam) berbeda dengan `0 0 0 * * *` (setiap hari tengah malam).
2. **Multiple instance menjalankan cron yang sama** — di deployment dengan banyak replica, cron akan berjalan di semua instance. Gunakan distributed lock (Redis) atau aktifkan cron hanya di satu instance via environment variable.
3. **Cron berjalan terlalu lama** — jika task butuh waktu lama, bisa tumpang tindih dengan eksekusi berikutnya. Gunakan `@Cron` dengan opsi `waitForCompletion` atau pattern yang cukup renggang.
4. **Error tidak di-handle** — jika cron throw error tanpa try-catch, eksekusi berikutnya tetap jalan. Tapi logging error penting untuk debugging.
5. **Lupa import ScheduleModule** — `@Cron` tidak akan bekerja jika `ScheduleModule.forRoot()` tidak di-import.

## Hubungan dengan Materi Sebelumnya

Di **#60**, kita mendispatch job secara reaktif — sebagai respons terhadap aksi user (pinjam buku). Sekarang dengan scheduled job, kita mendispatch secara **proaktif** — berdasarkan waktu. Kedua pola ini melengkapi satu sama lain: reactive dispatch untuk immediate notification, cron untuk periodic maintenance. Setelah ini, di **#62** kita akan membuat dashboard untuk memonitoring semua queue dan job.

## Soal Latihan

**Soal:**
Buat cron job `DailyReportTask` yang berjalan setiap hari jam 23:55 dan mengirim laporan harian ke admin via email. Laporan berisi: jumlah peminjaman hari ini, jumlah pengembalian, dan jumlah buku yang menjadi overdue.

**Jawaban:**

```typescript
@Injectable()
export class DailyReportTask {
  constructor(
    private prisma: PrismaService,
    @InjectQueue('email') private emailQueue: Queue,
  ) {}

  @Cron('55 23 * * *') // 23:55 setiap hari
  async sendDailyReport() {
    const today = new Date();
    today.setHours(0, 0, 0, 0);

    const [borrowed, returned, overdue] = await Promise.all([
      this.prisma.loan.count({
        where: { borrowedAt: { gte: today } },
      }),
      this.prisma.loan.count({
        where: { returnedAt: { gte: today } },
      }),
      this.prisma.loan.count({
        where: { status: 'OVERDUE' },
      }),
    ]);

    await this.emailQueue.add('send-daily-report', {
      email: 'admin@library.com',
      reportDate: today.toLocaleDateString('id-ID'),
      borrowed,
      returned,
      overdue,
    });
  }
}
```
