# 49. Mendokumentasikan Controller dengan @ApiTags, @ApiOperation & @ApiResponse

## Penjelasan

Selain mendokumentasikan DTO, kita juga perlu mendokumentasikan controller dan endpoint-endpointnya. NestJS Swagger menyediakan beberapa dekorator untuk ini: `@ApiTags()` untuk mengelompokkan endpoint berdasarkan controller, `@ApiOperation()` untuk memberikan ringkasan dan deskripsi setiap endpoint, dan `@ApiResponse()` untuk mendokumentasikan kemungkinan response (status code, tipe data, deskripsi).

Dekorator `@ApiBearerAuth()` juga penting untuk menandai endpoint mana yang membutuhkan autentikasi JWT. Swagger UI akan secara otomatis menampilkan ikon gembok di endpoint yang membutuhkan token, dan akan mengirimkan token yang sudah diisi di tombol "Authorize" ke endpoint tersebut.

## Fungsi

Dekorator controller berfungsi untuk: (1) mengelompokkan endpoint ke dalam kategori (tag) yang rapi di Swagger UI, (2) memberikan deskripsi yang jelas tentang fungsi setiap endpoint, (3) mendokumentasikan response sukses dan error, (4) menandai endpoint yang membutuhkan autentikasi, (5) memberikan contoh request dan response.

## Cara Implementasi / Code

**1. AuthController dengan dokumentasi Swagger lengkap:**

```typescript
import {
  Controller,
  Post,
  Get,
  Body,
  UseGuards,
  HttpCode,
  HttpStatus,
} from '@nestjs/common';
import { AuthGuard } from '@nestjs/passport';
import {
  ApiTags,
  ApiOperation,
  ApiResponse,
  ApiBearerAuth,
  ApiBody,
  ApiUnauthorizedResponse,
  ApiConflictResponse,
  ApiForbiddenResponse,
} from '@nestjs/swagger';
import { AuthService } from './auth.service';
import { RegisterDto } from './dto/register.dto';
import { LoginDto } from './dto/login.dto';
import { RefreshTokenDto } from './dto/refresh-token.dto';
import { AuthResponseDto } from './dto/auth-response.dto';
import { Public } from './decorators/public.decorator';
import { CurrentUser } from './decorators/current-user.decorator';

@ApiTags('Authentication')
@Controller('auth')
export class AuthController {
  constructor(private readonly authService: AuthService) {}

  @Public()
  @Post('register')
  @HttpCode(HttpStatus.CREATED)
  @ApiOperation({
    summary: 'Mendaftarkan pengguna baru',
    description:
      'Endpoint untuk membuat akun baru. Email harus unik. ' +
      'Password akan di-hash sebelum disimpan.',
  })
  @ApiBody({ type: RegisterDto })
  @ApiResponse({
    status: 201,
    description: 'Pengguna berhasil didaftarkan',
    type: AuthResponseDto,
  })
  @ApiConflictResponse({
    description: 'Email sudah terdaftar',
  })
  async register(@Body() dto: RegisterDto) {
    return this.authService.register(dto);
  }

  @Public()
  @Post('login')
  @HttpCode(HttpStatus.OK)
  @ApiOperation({
    summary: 'Login pengguna',
    description:
      'Autentikasi dengan email dan password. ' +
      'Mengembalikan access token (15 menit) dan refresh token (7 hari).',
  })
  @ApiBody({ type: LoginDto })
  @ApiResponse({
    status: 200,
    description: 'Login berhasil',
    type: AuthResponseDto,
  })
  @ApiUnauthorizedResponse({
    description: 'Email atau password salah',
  })
  async login(@Body() dto: LoginDto) {
    return this.authService.login(dto);
  }

  @UseGuards(AuthGuard('jwt-refresh'))
  @Post('refresh')
  @HttpCode(HttpStatus.OK)
  @ApiBearerAuth('JWT-auth')
  @ApiOperation({
    summary: 'Refresh token',
    description:
      'Memperbarui access token menggunakan refresh token. ' +
      'Menerapkan refresh token rotation untuk keamanan.',
  })
  @ApiBody({ type: RefreshTokenDto })
  @ApiResponse({
    status: 200,
    description: 'Token berhasil diperbarui',
    schema: {
      properties: {
        accessToken: { type: 'string', example: 'eyJhbGciOiJIUzI1NiIs...' },
        refreshToken: { type: 'string', example: 'eyJhbGciOiJIUzI1NiIs...' },
      },
    },
  })
  @ApiForbiddenResponse({
    description: 'Refresh token tidak valid atau sudah digunakan',
  })
  async refresh(
    @Body() dto: RefreshTokenDto,
    @CurrentUser() user: any,
  ) {
    return this.authService.refreshTokens(user.sub, dto.refreshToken);
  }

  @Post('logout')
  @HttpCode(HttpStatus.OK)
  @ApiBearerAuth('JWT-auth')
  @ApiOperation({
    summary: 'Logout pengguna',
    description:
      'Menghapus refresh token dari database. ' +
      'Access token masih berlaku sampai kedaluwarsa.',
  })
  @ApiResponse({
    status: 200,
    description: 'Logout berhasil',
    schema: {
      properties: {
        message: { type: 'string', example: 'Logged out successfully' },
      },
    },
  })
  @ApiUnauthorizedResponse({
    description: 'Token tidak valid atau tidak dikirim',
  })
  async logout(@CurrentUser('id') userId: number) {
    return this.authService.logout(userId);
  }

  @Get('me')
  @HttpCode(HttpStatus.OK)
  @ApiBearerAuth('JWT-auth')
  @ApiOperation({
    summary: 'Profil pengguna saat ini',
    description: 'Mengembalikan data pengguna yang sedang login.',
  })
  @ApiResponse({
    status: 200,
    description: 'Data profil berhasil diambil',
    schema: {
      properties: {
        user: {
          type: 'object',
          properties: {
            id: { type: 'number', example: 1 },
            email: { type: 'string', example: 'john@example.com' },
            name: { type: 'string', example: 'John Doe' },
            role: { type: 'string', example: 'USER' },
          },
        },
      },
    },
  })
  getProfile(@CurrentUser() user: any) {
    return { user };
  }
}
```

**2. BooksController dengan dokumentasi Swagger:**

```typescript
import {
  Controller,
  Get,
  Post,
  Patch,
  Delete,
  Body,
  Param,
  ParseIntPipe,
} from '@nestjs/common';
import { Role } from '@prisma/client';
import {
  ApiTags,
  ApiOperation,
  ApiResponse,
  ApiBearerAuth,
  ApiBody,
  ApiParam,
  ApiForbiddenResponse,
  ApiNotFoundResponse,
} from '@nestjs/swagger';
import { BooksService } from './books.service';
import { CreateBookDto } from './dto/create-book.dto';
import { UpdateBookDto } from './dto/update-book.dto';
import { Public } from '../auth/decorators/public.decorator';
import { Roles } from '../auth/decorators/roles.decorator';
import { CurrentUser } from '../auth/decorators/current-user.decorator';

@ApiTags('Books')
@Controller('books')
export class BooksController {
  constructor(private readonly booksService: BooksService) {}

  @Public()
  @Get()
  @ApiOperation({
    summary: 'Mendapatkan semua buku',
    description: 'Mengembalikan daftar semua buku yang tersedia. Tidak memerlukan autentikasi.',
  })
  @ApiResponse({
    status: 200,
    description: 'Daftar buku berhasil diambil',
    isArray: true,
  })
  async findAll() {
    return this.booksService.findAll();
  }

  @Public()
  @Get(':id')
  @ApiOperation({
    summary: 'Mendapatkan detail buku',
    description: 'Mengembalikan detail buku berdasarkan ID.',
  })
  @ApiParam({ name: 'id', type: 'number', description: 'ID buku' })
  @ApiResponse({ status: 200, description: 'Detail buku ditemukan' })
  @ApiNotFoundResponse({ description: 'Buku tidak ditemukan' })
  async findOne(@Param('id', ParseIntPipe) id: number) {
    return this.booksService.findOne(id);
  }

  @Roles(Role.LIBRARIAN, Role.ADMIN)
  @Post()
  @ApiBearerAuth('JWT-auth')
  @ApiOperation({
    summary: 'Menambahkan buku baru',
    description: 'Hanya dapat diakses oleh LIBRARIAN dan ADMIN.',
  })
  @ApiBody({ type: CreateBookDto })
  @ApiResponse({ status: 201, description: 'Buku berhasil ditambahkan' })
  @ApiForbiddenResponse({
    description: 'Tidak memiliki akses (bukan LIBRARIAN atau ADMIN)',
  })
  async create(
    @Body() dto: CreateBookDto,
    @CurrentUser('id') userId: number,
  ) {
    return this.booksService.create(dto, userId);
  }

  @Roles(Role.LIBRARIAN, Role.ADMIN)
  @Patch(':id')
  @ApiBearerAuth('JWT-auth')
  @ApiOperation({
    summary: 'Memperbarui data buku',
    description: 'Hanya dapat diakses oleh LIBRARIAN dan ADMIN.',
  })
  @ApiParam({ name: 'id', type: 'number', description: 'ID buku' })
  @ApiBody({ type: UpdateBookDto })
  @ApiResponse({ status: 200, description: 'Buku berhasil diperbarui' })
  @ApiNotFoundResponse({ description: 'Buku tidak ditemukan' })
  async update(
    @Param('id', ParseIntPipe) id: number,
    @Body() dto: UpdateBookDto,
  ) {
    return this.booksService.update(id, dto);
  }

  @Roles(Role.ADMIN)
  @Delete(':id')
  @ApiBearerAuth('JWT-auth')
  @ApiOperation({
    summary: 'Menghapus buku',
    description: 'Hanya dapat diakses oleh ADMIN.',
  })
  @ApiParam({ name: 'id', type: 'number', description: 'ID buku' })
  @ApiResponse({ status: 200, description: 'Buku berhasil dihapus' })
  @ApiNotFoundResponse({ description: 'Buku tidak ditemukan' })
  async remove(@Param('id', ParseIntPipe) id: number) {
    return this.booksService.remove(id);
  }
}
```

## Analogi

Dekorator Swagger di controller seperti **papan informasi wisata** di perpustakaan:
- `@ApiTags('Books')` seperti **seksi "Koleksi Buku"** di peta — mengelompokkan semua rute yang berkaitan dengan buku
- `@ApiOperation({ summary })` seperti **judul petunjuk arah**: "Cara Menambahkan Buku Baru"
- `@ApiResponse()` seperti **rambu peringatan**: "Jika buku tidak ditemukan, Anda akan melihat pesan 404"
- `@ApiBearerAuth()` seperti **ikon gembok** 🔒 yang menandakan "Area Khusus Staf — Kartu Akses Diperlukan"
- `@ApiParam()` seperti **label nomor rak**: "Rak #: ID Buku"

## Penggunaan

Dekorator dokumentasi Swagger digunakan di semua controller untuk memberikan informasi yang jelas dan terstruktur tentang API. Developer frontend akan sangat terbantu dengan dokumentasi yang baik karena mereka bisa memahami API tanpa harus membaca kode backend.

## Kesalahan Umum yang Sering Terjadi

1. **Lupa @ApiBearerAuth()**: Endpoint yang membutuhkan token tapi tidak diberi @ApiBearerAuth() akan tetap bisa di-test di Swagger, tapi user harus mengisi token secara manual di header.
2. **Deskripsi tidak informatif**: "Create book" terlalu singkat. Lebih baik "Menambahkan buku baru ke dalam katalog perpustakaan".
3. **Tidak mendokumentasikan error response**: Developer perlu tahu apa yang terjadi jika request gagal. Dokumentasikan 400, 401, 403, 404.
4. **Over-dokumentasi**: Untuk endpoint sederhana, cukup `@ApiOperation({ summary })` saja tanpa perlu `@ApiResponse()` yang terlalu detail.

## Soal Latihan

**Soal 1:** Apa fungsi `@ApiBearerAuth('JWT-auth')` dan bagaimana kaitannya dengan setup di main.ts?

**Jawaban:** `@ApiBearerAuth('JWT-auth')` menghubungkan endpoint dengan security scheme yang didefinisikan di main.ts melalui `.addBearerAuth()`. Nama 'JWT-auth' harus cocok dengan nama yang diberikan di `.addBearerAuth()`. Di Swagger UI, endpoint dengan dekorator ini akan menampilkan ikon gembok dan secara otomatis mengirim token yang diisi user di tombol "Authorize".

**Soal 2:** Bagaimana cara mendokumentasikan response yang bisa mengembalikan dua tipe data berbeda (misalnya sukses 200 atau error 404)?

**Jawaban:** Gunakan multiple @ApiResponse decorator untuk status yang berbeda:

```typescript
@Get(':id')
@ApiResponse({ status: 200, description: 'Buku ditemukan', type: BookDto })
@ApiResponse({ status: 404, description: 'Buku tidak ditemukan' })
async findOne(@Param('id') id: string) {
  // ...
}
```

**Soal 3:** Buat custom decorator `@ApiAuthEndpoint()` yang menggabungkan `@ApiBearerAuth()`, `@ApiForbiddenResponse()`, dan `@ApiUnauthorizedResponse()` untuk mengurangi duplikasi.

**Jawaban:**

```typescript
import { applyDecorators } from '@nestjs/common';
import { ApiBearerAuth, ApiForbiddenResponse, ApiUnauthorizedResponse } from '@nestjs/swagger';

export function ApiAuthEndpoint() {
  return applyDecorators(
    ApiBearerAuth('JWT-auth'),
    ApiUnauthorizedResponse({ description: 'Token tidak valid atau tidak dikirim' }),
    ApiForbiddenResponse({ description: 'Tidak memiliki akses yang cukup' }),
  );
}
```

Penggunaan: cukup `@ApiAuthEndpoint()` di atas endpoint yang butuh autentikasi.
