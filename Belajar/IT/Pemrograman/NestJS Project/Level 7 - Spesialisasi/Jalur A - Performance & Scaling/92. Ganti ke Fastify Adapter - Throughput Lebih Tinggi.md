# 92. Ganti ke Fastify Adapter - Throughput Lebih Tinggi

## Penjelasan
Secara default, NestJS menggunakan Express sebagai HTTP framework. Express sudah sangat populer dan stabil, tetapi untuk aplikasi dengan traffic tinggi, Express bisa menjadi bottleneck karena sifatnya yang synchronous-heavy dan single-threaded. **Fastify** hadir sebagai alternatif yang diklaim 2–3x lebih cepat dalam hal request per detik (throughput) berkat arsitektur yang lebih efisien, plugin-based, dan serialisasi JSON yang optimal.

`@nestjs/platform-fastify` adalah adapter resmi dari NestJS untuk mengganti Express dengan Fastify. Dengan FastifyAdapter di `main.ts`, seluruh aplikasi NestJS berjalan di atas Fastify tanpa mengubah kode controller atau service sama sekali. Namun ada beberapa perbedaan kecil: Fastify menggunakan `light-my-request` untuk testing (bukan supertest), dan middleware Express tidak bisa langsung digunakan (perlu plugin Fastify). NestJS sudah meng-handle kompatibilitas ini melalui adapter layer-nya.

## Fungsi
- Meningkatkan throughput (request/detik) aplikasi NestJS secara signifikan
- Mengurangi latensi rata-rata request, terutama untuk endpoint dengan payload JSON besar
- Menyediakan schema-based serialization untuk response yang lebih cepat
- Mendukung plugin ecosystem Fastify untuk fitur tambahan seperti kompresi, rate limiting, dll.

## Cara Implementasi / Code

**1. Install package Fastify adapter:**
```bash
npm install @nestjs/platform-fastify
```

**2. Update main.ts — Ganti Express dengan Fastify:**
```typescript
import { NestFactory } from '@nestjs/core';
import {
  FastifyAdapter,
  NestFastifyApplication,
} from '@nestjs/platform-fastify';
import { AppModule } from './app.module';
import { ValidationPipe } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create<NestFastifyApplication>(
    AppModule,
    new FastifyAdapter({
      logger: true,
      bodyLimit: 10 * 1024 * 1024, // 10MB max body
    }),
  );

  app.setGlobalPrefix('api');
  app.useGlobalPipes(new ValidationPipe({ whitelist: true }));

  // CORS untuk Fastify
  app.enableCors({
    origin: ['http://localhost:3000'],
    methods: ['GET', 'POST', 'PUT', 'DELETE', 'PATCH'],
  });

  await app.listen(3000, '0.0.0.0');
  console.log(`Server running on http://localhost:3000/api`);
}
bootstrap();
```

**3. Update test — Fastify menggunakan light-my-request:**
```typescript
import { Test, TestingModule } from '@nestjs/testing';
import {
  FastifyAdapter,
  NestFastifyApplication,
} from '@nestjs/platform-fastify';
import { AppModule } from '../src/app.module';

describe('BooksController (Fastify)', () => {
  let app: NestFastifyApplication;

  beforeAll(async () => {
    const moduleFixture: TestingModule = await Test.createTestingModule({
      imports: [AppModule],
    }).compile();

    app = moduleFixture.createNestApplication<NestFastifyApplication>(
      new FastifyAdapter(),
    );
    await app.init();
    await app.getHttpAdapter().getInstance().ready();
  });

  it('GET /api/books', async () => {
    const result = await app.inject({
      method: 'GET',
      url: '/api/books?page=1&limit=10',
    });
    expect(result.statusCode).toBe(200);
    expect(JSON.parse(result.payload)).toHaveProperty('data');
  });

  afterAll(async () => {
    await app.close();
  });
});
```

**4. Middleware Express → Plugin Fastify (jika ada):**
```typescript
// Express: app.use(cookieParser())
// Fastify: install @fastify/cookie dan gunakan plugin
import fastifyCookie from '@fastify/cookie';

const app = await NestFactory.create<NestFastifyApplication>(
  AppModule,
  new FastifyAdapter(),
);

const fastifyInstance = app.getHttpAdapter().getInstance();
await fastifyInstance.register(fastifyCookie);
```

## Analogi
Bayangkan perpustakaan memiliki **pintu masuk** dengan sistem lama (Express): setiap pengunjung harus mengisi formulir kertas, petugas mengetik manual ke komputer, lalu buku dicari. Sekarang diganti **pintu masuk otomatis** (Fastify): pengunjung cukup scan kartu anggota, sistem langsung mendeteksi buku favorit, dan pintu terbuka dalam 1 detik. Keduanya tetap melayani fungsi yang sama — memasukkan pengunjung — tetapi yang baru jauh lebih cepat dan bisa melayani lebih banyak orang tanpa menambah petugas.

## Penggunaan
- API publik dengan traffic tinggi (>500 request/detik)
- Aplikasi real-time yang membutuhkan latensi rendah
- Microservices dengan komunikasi inter-service yang intensif (setiap milidetik berarti)
- REST API dengan response JSON besar (data buku dengan relasi penulis, kategori, reviews)

## Kesalahan Umum yang Sering Terjadi
1. **Lupa install @nestjs/platform-fastify** — Error "FastifyAdapter is not a constructor" atau "Cannot find module".
2. **Middleware Express tidak jalan** — Middleware seperti `cookie-parser`, `morgan`, atau `cors` versi Express perlu diganti dengan plugin Fastify-nya.
3. **Testing error** — Test menggunakan `supertest` tidak kompatibel dengan Fastify; gunakan `app.inject()` bawaan Fastify.
4. **File upload** — `@nestjs/platform-express` punya integrasi Multer; di Fastify perlu `@fastify/multipart` plugin.
5. **Swagger UI** — Jika menggunakan Swagger, pastikan konfigurasi `SwaggerModule.setup()` kompatibel dengan Fastify (biasanya fine, tapi perlu di-test).

## Hubungan dengan Materi Sebelumnya
Di Level 5 kita melakukan unit testing, di Level 6 deployment. Load testing di materi 91 akan menunjukkan apakah performa kurang. Fastify adapter adalah salah satu optimasi pertama yang direkomendasikan — tanpa mengubah kode bisnis sama sekali, throughput bisa naik 2x. Langkah berikutnya adalah optimasi database (materi 93) dan caching (dari Level 4).

## Soal Latihan

**Soal:** Sebuah aplikasi NestJS saat ini menggunakan Express dan memiliki bottleneck pada response time. Ubah `main.ts` berikut agar menggunakan FastifyAdapter dengan konfigurasi: log diaktifkan, body limit 5MB, prefix global `/v1`, dan CORS hanya untuk `https://app.example.com`.

Kode awal:
```typescript
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.setGlobalPrefix('api');
  await app.listen(3000);
}
bootstrap();
```

**Jawaban:**
```typescript
import { NestFactory } from '@nestjs/core';
import {
  FastifyAdapter,
  NestFastifyApplication,
} from '@nestjs/platform-fastify';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create<NestFastifyApplication>(
    AppModule,
    new FastifyAdapter({
      logger: true,
      bodyLimit: 5 * 1024 * 1024,
    }),
  );

  app.setGlobalPrefix('v1');
  app.enableCors({
    origin: ['https://app.example.com'],
  });

  await app.listen(3000, '0.0.0.0');
}
bootstrap();
```
