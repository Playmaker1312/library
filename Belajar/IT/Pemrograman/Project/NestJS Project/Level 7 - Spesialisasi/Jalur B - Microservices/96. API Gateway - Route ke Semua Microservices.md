# 96. API Gateway - Route ke Semua Microservices

## Penjelasan
API Gateway adalah service yang bertindak sebagai **single entry point** untuk semua client (web, mobile, third-party). Client hanya perlu tahu satu URL (misal `https://api.perpustakaan.com`), dan gateway akan me-routing request ke service internal yang sesuai. Di NestJS, API Gateway dibuat sebagai project NestJS biasa (bukan microservice) dengan HTTP listener, yang menggunakan `ClientsModule` untuk membuat koneksi TCP ke microservices.

`ClientsModule` adalah module NestJS yang menyediakan `ClientProxy` — object proxy yang bisa mengirim pesan ke microservice dan menerima response. Setiap service (Books, Users, Loans) akan memiliki `ClientProxy` masing-masing yang dikonfigurasi dengan `Transport.TCP` dan port yang sesuai. Di controller gateway, kita gunakan `@Inject()` untuk mendapatkan `ClientProxy`, lalu panggil `this.booksClient.send({ cmd: 'get_books' }, payload)` — method `send()` mengembalikan Observable yang bisa kita konversi ke Promise dengan `lastValueFrom()`. Gateway juga bisa menangani cross-cutting concerns seperti autentikasi (JWT verification), rate limiting, request logging, dan response transformation.

## Fungsi
- Menyediakan satu endpoint publik untuk semua client, menyembunyikan kompleksitas internal
- Me-routing request ke microservice yang tepat berdasarkan path/pattern
- Menangani autentikasi dan otorisasi terpusat (tidak perlu di setiap service)
- Mengubah protokol (HTTP → TCP) sehingga service internal tidak perlu tahu soal HTTP

## Cara Implementasi / Code

**1. Generate project gateway:**
```bash
nest new api-gateway --package-manager npm
cd api-gateway
npm install @nestjs/microservices
```

**2. app.module.ts — Daftarkan ClientsModule untuk setiap service:**
```typescript
import { Module } from '@nestjs/common';
import { ClientsModule, Transport } from '@nestjs/microservices';
import { GatewayController } from './gateway.controller';
import { GatewayService } from './gateway.service';

@Module({
  imports: [
    ClientsModule.register([
      {
        name: 'BOOKS_SERVICE',
        transport: Transport.TCP,
        options: { host: 'localhost', port: 3001 },
      },
      {
        name: 'USERS_SERVICE',
        transport: Transport.TCP,
        options: { host: 'localhost', port: 3002 },
      },
      {
        name: 'LOANS_SERVICE',
        transport: Transport.TCP,
        options: { host: 'localhost', port: 3003 },
      },
    ]),
  ],
  controllers: [GatewayController],
  providers: [GatewayService],
})
export class AppModule {}
```

**3. gateway.service.ts — ClientProxy wrapper:**
```typescript
import { Injectable, Inject } from '@nestjs/common';
import { ClientProxy } from '@nestjs/microservices';
import { lastValueFrom } from 'rxjs';

@Injectable()
export class GatewayService {
  constructor(
    @Inject('BOOKS_SERVICE') private readonly booksClient: ClientProxy,
    @Inject('USERS_SERVICE') private readonly usersClient: ClientProxy,
    @Inject('LOANS_SERVICE') private readonly loansClient: ClientProxy,
  ) {}

  // ========== BOOKS ==========
  async getBooks(page: number, limit: number) {
    return lastValueFrom(
      this.booksClient.send({ cmd: 'get_books' }, { page, limit }),
    );
  }

  async getBookById(id: string) {
    return lastValueFrom(
      this.booksClient.send({ cmd: 'get_book_by_id' }, { id }),
    );
  }

  async createBook(data: { title: string; author: string; isbn: string; categoryId: string }) {
    return lastValueFrom(
      this.booksClient.send({ cmd: 'create_book' }, data),
    );
  }

  async searchBooks(query: string) {
    return lastValueFrom(
      this.booksClient.send({ cmd: 'search_books' }, { query }),
    );
  }

  // ========== USERS ==========
  async getUsers(page: number, limit: number) {
    return lastValueFrom(
      this.usersClient.send({ cmd: 'get_users' }, { page, limit }),
    );
  }

  async registerUser(data: { name: string; email: string; password: string }) {
    return lastValueFrom(
      this.usersClient.send({ cmd: 'register_user' }, data),
    );
  }

  // ========== LOANS ==========
  async createLoan(data: { bookId: string; memberId: string }) {
    return lastValueFrom(
      this.loansClient.send({ cmd: 'create_loan' }, data),
    );
  }

  async returnBook(loanId: string) {
    return lastValueFrom(
      this.loansClient.send({ cmd: 'return_book' }, { loanId }),
    );
  }

  async getMemberLoans(memberId: string) {
    return lastValueFrom(
      this.loansClient.send({ cmd: 'get_member_loans' }, { memberId }),
    );
  }
}
```

**4. gateway.controller.ts — HTTP endpoints:**
```typescript
import {
  Controller,
  Get,
  Post,
  Param,
  Body,
  Query,
  UseGuards,
} from '@nestjs/common';
import { GatewayService } from './gateway.service';

@Controller('api')
export class GatewayController {
  constructor(private readonly gatewayService: GatewayService) {}

  // ========== BOOKS ENDPOINTS ==========
  @Get('books')
  async getBooks(@Query('page') page = 1, @Query('limit') limit = 20) {
    return this.gatewayService.getBooks(+page, +limit);
  }

  @Get('books/search')
  async searchBooks(@Query('q') query: string) {
    return this.gatewayService.searchBooks(query);
  }

  @Get('books/:id')
  async getBook(@Param('id') id: string) {
    return this.gatewayService.getBookById(id);
  }

  @Post('books')
  async createBook(@Body() dto: { title: string; author: string; isbn: string; categoryId: string }) {
    return this.gatewayService.createBook(dto);
  }

  // ========== LOANS ENDPOINTS ==========
  @Post('loans')
  async createLoan(@Body() dto: { bookId: string; memberId: string }) {
    return this.gatewayService.createLoan(dto);
  }

  @Post('loans/:id/return')
  async returnBook(@Param('id') id: string) {
    return this.gatewayService.returnBook(id);
  }

  @Get('members/:memberId/loans')
  async getMemberLoans(@Param('memberId') memberId: string) {
    return this.gatewayService.getMemberLoans(memberId);
  }
}
```

**5. main.ts — Gateway (HTTP server biasa):**
```typescript
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { ValidationPipe } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.setGlobalPrefix('api');
  app.useGlobalPipes(new ValidationPipe({ whitelist: true }));
  app.enableCors();

  await app.listen(3000);
  console.log('API Gateway running on http://localhost:3000');
}
bootstrap();
```

**7. Error handling di gateway — Timeout dan fallback:**
```typescript
import { Injectable, RequestTimeoutException } from '@nestjs/common';
import { ClientProxy } from '@nestjs/microservices';
import { lastValueFrom, timeout, catchError } from 'rxjs';

@Injectable()
export class GatewayService {
  // ...

  async getBookById(id: string) {
    return lastValueFrom(
      this.booksClient
        .send({ cmd: 'get_book_by_id' }, { id })
        .pipe(
          timeout(5000), // 5 detik timeout
          catchError((err) => {
            throw new RequestTimeoutException('Books service timeout');
          }),
        ),
    );
  }
}
```

## Analogi
API Gateway adalah **Meja Informasi Utama** di pintu masuk perpustakaan. Pengunjung datang dan bertanya "saya mau pinjam buku Harry Potter". Petugas meja informasi tidak langsung mengambil buku — ia tahu bahwa urusan buku ada di **Bagian Katalog** (Books Service), urusan anggota ada di **Bagian Keanggotaan** (Users Service), dan urusan peminjaman ada di **Bagian Sirkulasi** (Loans Service). Petugas meja informasi (gateway) menulis surat, memasukkannya ke tabung pneumatik yang berbeda untuk setiap bagian, menunggu jawaban, lalu menyampaikannya ke pengunjung. Pengunjung tidak perlu tahu tata letak ruangan atau nomor ekstensi telepon setiap bagian — cukup datang ke meja informasi.

## Penggunaan
- Single entry point untuk aplikasi web, mobile apps, dan third-party API
- Sentralisasi autentikasi (JWT verification di gateway, bukan di setiap service)
- Rate limiting, IP whitelisting, dan API versioning di satu tempat
- Response transformation (aggregate data dari beberapa service)

## Kesalahan Umum yang Sering Terjadi
1. **Lupa handle timeout** — Microservice bisa lambat atau mati. Tanpa timeout, request client menggantung sampai timeout HTTP default (30 detik). Selalu tambahkan `.pipe(timeout(5000))`.
2. **ClientProxy tidak di-inject dengan benar** — Nama client di `@Inject()` harus persis sama dengan `name` di `ClientsModule.register()`.
3. **Service belum jalan** — Gateway jalan tapi Books Service belum start. Request akan error koneksi tertolak. Pastikan startup order atau gunakan health check.
4. **Pattern tidak konsisten** — Gateway kirim `{ cmd: 'getBooks' }` tapi Books Service menerima `{ cmd: 'get_books' }`. Simpan pattern sebagai konstanta bersama di package shared.
5. **ClientProxy dibuat ulang** — Jangan buat `new ClientProxy()` manual. Gunakan `ClientsModule.register()` yang sudah mengelola koneksi sebagai singleton.

## Soal Latihan

**Soal:** Tambahkan endpoint baru di gateway: `GET /api/members/:memberId/loans/active` yang memanggil Loans Service untuk mendapatkan daftar peminjaman aktif member. Lengkapi: (1) method di GatewayService, (2) endpoint di GatewayController.

**Jawaban:**
```typescript
// GatewayService — tambahkan method
async getActiveMemberLoans(memberId: string) {
  return lastValueFrom(
    this.loansClient.send({ cmd: 'get_active_member_loans' }, { memberId }),
  );
}
```

```typescript
// GatewayController — tambahkan endpoint
@Get('members/:memberId/loans/active')
async getActiveMemberLoans(@Param('memberId') memberId: string) {
  return this.gatewayService.getActiveMemberLoans(memberId);
```
