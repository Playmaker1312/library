# 55. Implementasi Cache di BooksService — Cache-Aside Pattern

## Penjelasan

**Cache-Aside Pattern** (juga disebut Lazy Loading) adalah strategi caching yang paling umum digunakan. Pola kerjanya sederhana: ketika sebuah data diminta, aplikasi pertama-tama memeriksa cache. Jika data ada di cache (cache hit), langsung dikembalikan. Jika tidak ada (cache miss), aplikasi mengambil data dari database, menyimpannya ke cache, lalu mengembalikannya. Data di cache akan memiliki TTL (Time-To-Live) dan akan otomatis dihapus setelah masa berlaku habis.

Di NestJS, kita mengimplementasikan pola ini dengan meng-inject `CACHE_MANAGER` ke dalam service dan menggunakan method `cache.get()` dan `cache.set()`. Untuk `BooksService`, kita akan menerapkan caching pada method `findAll()` (daftar buku) dan `findOne()` (detail buku) — dua endpoint yang paling sering dipanggil dan datanya relatif stabil.

## Fungsi

Cache-Aside pada BooksService berfungsi untuk mengurangi jumlah query ke database untuk data buku yang sering diakses. Hasilnya, response time endpoint menjadi jauh lebih cepat dan beban database berkurang drastis, terutama ketika ada ribuan request per detik untuk melihat katalog buku.

## Cara Implementasi / Code

### 1. Inject CACHE_MANAGER ke BooksService

```typescript
// src/books/services/books.service.ts
import { Injectable, Inject } from '@nestjs/common';
import { CACHE_MANAGER } from '@nestjs/cache-manager';
import { Cache } from 'cache-manager';
import { PrismaService } from '../../prisma/prisma.service';

@Injectable()
export class BooksService {
  constructor(
    private readonly prisma: PrismaService,
    @Inject(CACHE_MANAGER) private cacheManager: Cache,
  ) {}

  async findAll(query: QueryBooksDto) {
    const cacheKey = `books:all:${JSON.stringify(query)}`;
    const cached = await this.cacheManager.get(cacheKey);

    if (cached) {
      return cached;
    }

    const books = await this.prisma.book.findMany({
      where: this.buildWhereClause(query),
      include: { category: true },
      orderBy: { createdAt: 'desc' },
      skip: (query.page - 1) * query.limit,
      take: query.limit,
    });

    const total = await this.prisma.book.count({
      where: this.buildWhereClause(query),
    });

    const result = { data: books, total, page: query.page, limit: query.limit };

    await this.cacheManager.set(cacheKey, result, 60 * 1000); // TTL 60 detik

    return result;
  }

  async findOne(id: string) {
    const cacheKey = `books:${id}`;
    const cached = await this.cacheManager.get(cacheKey);

    if (cached) {
      return cached;
    }

    const book = await this.prisma.book.findUnique({
      where: { id },
      include: { category: true },
    });

    if (!book) {
      throw new NotFoundException('Buku tidak ditemukan');
    }

    await this.cacheManager.set(cacheKey, book, 60 * 1000);

    return book;
  }

  private buildWhereClause(query: QueryBooksDto) {
    const where: any = {};
    if (query.search) {
      where.OR = [
        { title: { contains: query.search, mode: 'insensitive' } },
        { author: { contains: query.search, mode: 'insensitive' } },
      ];
    }
    if (query.categoryId) where.categoryId = query.categoryId;
    return where;
  }
}
```

### 2. QueryBooksDto

```typescript
// src/books/dto/query-books.dto.ts
import { IsOptional, IsString, IsInt, Min } from 'class-validator';
import { Type } from 'class-transformer';

export class QueryBooksDto {
  @IsOptional()
  @IsString()
  search?: string;

  @IsOptional()
  @IsString()
  categoryId?: string;

  @IsOptional()
  @Type(() => Number)
  @IsInt()
  @Min(1)
  page: number = 1;

  @IsOptional()
  @Type(() => Number)
  @IsInt()
  @Min(1)
  limit: number = 10;
}
```

## Analogi

Di perpustakaan, petugas sirkulasi memiliki **notes tempelan** di mejanya untuk pertanyaan yang sering diajukan. Ketika anggota bertanya "di mana letak buku 'Clean Code'?", petugas pertama kali melihat notes-nya (cache). Jika ada catatannya, dia langsung menjawab. Jika tidak, dia pergi ke rak (database), mencari buku, menulis lokasinya di notes, baru menjawab. Lain kali jika ada yang bertanya buku yang sama, jawabannya langsung dari notes. Notes ini akan dihapus setiap 60 menit (TTL) agar informasinya tetap akurat.

## Penggunaan

Cache-Aside pattern digunakan untuk data yang **banyak dibaca (read-heavy)** dan **jarang berubah**. Contoh nyata: katalog produk e-commerce, daftar artikel blog, data master seperti daftar kategori, daftar kota/kecamatan, dan konfigurasi publik. Di aplikasi perpustakaan, daftar buku dan detail buku adalah kandidat utama karena ribuan anggota bisa melihat katalog yang sama setiap hari.

## Kesalahan Umum yang Sering Terjadi

1. **Cache key tidak unik** — misalnya, semua query pagination menggunakan key `books:all` tanpa menyertakan parameter page/limit. Akibatnya, halaman 1 dan halaman 2 mengembalikan data yang sama.
2. **Cache serialization issue** — data dari Redis dikembalikan sebagai string/object biasa, bukan instance class. Pastikan tidak ada method yang hilang setelah deserialization.
3. **TTL tidak sinkron dengan frekuensi perubahan data** — jika data berubah setiap 5 detik tapi TTL 1 jam, user akan melihat data basi.
4. **Over-caching pada data user-specific** — menyimpan data personal di cache tanpa prefix user ID bisa menyebabkan data bocor ke user lain.
5. **Tidak handle error saat Redis down** — jika Redis mati, aplikasi harus tetap jalan dengan fallback ke database.

## Hubungan dengan Materi Sebelumnya

Di **Level 3 (Fitur REST API Lanjutan)**, kita telah membuat `BooksService` dengan query yang sudah optimal menggunakan Prisma. Sekarang kita menambahkan **lapisan cache** di atasnya tanpa mengubah kode yang sudah ada — ini adalah contoh **open-closed principle**: service terbuka untuk ekstensi (tambah caching) tapi tertutup untuk modifikasi. Setelah ini, di materi selanjutnya kita akan belajar **cache invalidation** saat data berubah.

## Soal Latihan

**Soal:**
Implementasikan Cache-Aside pattern untuk method `getPopularBooks()` yang mengambil 10 buku paling banyak dipinjam (hitungan dari tabel Loan). Beri TTL 5 menit. Tambahkan juga pengecekan agar cache tidak menyimpan data kosong.

**Jawaban:**

```typescript
async getPopularBooks() {
  const cacheKey = 'books:popular';
  const cached = await this.cacheManager.get(cacheKey);

  if (cached) {
    return cached;
  }

  const popularBooks = await this.prisma.book.findMany({
    include: { category: true },
    orderBy: { loans: { _count: 'desc' } },
    take: 10,
  });

  if (popularBooks.length > 0) {
    await this.cacheManager.set(cacheKey, popularBooks, 5 * 60 * 1000);
  }

  return popularBooks;
}
```
