# 79. E2E Test Books — CRUD dengan Auth & Roles

## Penjelasan

E2E test untuk Books CRUD adalah puncak dari pengujian fitur utama aplikasi perpustakaan. Di sini kita menguji seluruh alur dari request HTTP hingga response, melibatkan autentikasi (JWT), otorisasi (roles), validasi (ValidationPipe), logika bisnis (BooksService), penyimpanan database (PrismaBooksRepository), dan formatting response (ResponseWrapperInterceptor). Test ini memvalidasi bahwa seorang user dengan role tertentu benar-benar bisa melakukan operasi yang diizinkan dan ditolak untuk operasi yang tidak diizinkan.

Skenario yang diuji mencakup tiga layer akses: (1) tanpa token — semua operasi harus ditolak dengan 401 Unauthorized; (2) dengan token user biasa — bisa membaca buku tapi mungkin tidak bisa membuat/menghapus; (3) dengan token admin — bisa melakukan semua operasi CRUD. Pengujian berbasis peran ini penting karena banyak bug keamanan muncul dari otorisasi yang tidak konsisten. Misalnya, endpoint GET /api/books mungkin tidak terlindungi (public), sementara POST /api/books hanya untuk admin. E2E test memverifikasi semua kombinasi ini.

Selain otorisasi, test CRUD juga memvalidasi response structure: data buku dikembalikan dalam format yang konsisten (termasuk field seperti id, title, author, isbn, publishedYear, genre, stock, createdAt, updatedAt). Kita juga menguji edge cases seperti mencari buku yang tidak ada (404), membuat buku dengan data tidak lengkap (400), dan menghapus buku yang sudah dihapus (404). Semua response error harus mengikuti format konsisten dari GlobalExceptionFilter.

## Fungsi

- Memvalidasi CRUD books lengkap: Create, Read, Update, Delete
- Menguji otorisasi: akses tanpa token (401), role salah (403), role benar (200/201)
- Memverifikasi format response sukses dan error konsisten
- Menguji validasi input: field required, format ISBN, stock negatif
- Mendeteksi regression saat perubahan schema database atau logika bisnis
- Acceptance criteria untuk fitur manajemen buku

### 1. `test/books.e2e-spec.ts` — Books CRUD E2E Test

```typescript
// test/books.e2e-spec.ts
import { INestApplication, ValidationPipe } from '@nestjs/common';
import { Test, TestingModule } from '@nestjs/testing';
import * as request from 'supertest';
import { AppModule } from '../src/app.module';
import { PrismaService } from '../src/prisma/prisma.service';
import { GlobalExceptionFilter } from '../src/common/filters/global-exception.filter';
import { Role } from '../src/auth/enums/role.enum';

describe('Books CRUD (E2E)', () => {
  let app: INestApplication;
  let prisma: PrismaService;
  let httpServer: any;

  // Data test
  const adminUser = {
    email: 'admin-e2e@example.com',
    password: 'AdminPass123!',
    name: 'Admin E2E',
  };

  const regularUser = {
    email: 'user-e2e@example.com',
    password: 'UserPass123!',
    name: 'User E2E',
  };

  const testBook = {
    title: 'E2E Test Book',
    author: 'Test Author',
    isbn: '978-E2E-TEST-0001',
    publishedYear: 2024,
    genre: 'Testing',
    stock: 10,
  };

  let adminToken: string;
  let userToken: string;
  let createdBookId: string;

  beforeAll(async () => {
    const moduleFixture: TestingModule = await Test.createTestingModule({
      imports: [AppModule],
    }).compile();

    app = moduleFixture.createNestApplication();
    app.useGlobalPipes(
      new ValidationPipe({
        whitelist: true,
        forbidNonWhitelisted: true,
        transform: true,
      }),
    );
    app.useGlobalFilters(new GlobalExceptionFilter());
    app.setGlobalPrefix('api');

    await app.init();
    httpServer = app.getHttpServer();
    prisma = app.get<PrismaService>(PrismaService);
  });

  afterAll(async () => {
    // Bersihkan semua data test
    await prisma.book.deleteMany({
      where: { isbn: { contains: 'E2E-TEST' } },
    });
    await prisma.user.deleteMany({
      where: { email: { contains: 'e2e' } },
    });
    await app.close();
  });

  // Setup: buat user dan dapatkan token
  beforeAll(async () => {
    // Hapus data test sebelumnya jika ada
    await prisma.user.deleteMany({
      where: { email: { contains: 'e2e' } },
    });
    await prisma.book.deleteMany({
      where: { isbn: { contains: 'E2E-TEST' } },
    });

    // Register admin user
    const adminReg = await request(httpServer)
      .post('/api/auth/register')
      .send(adminUser);

    // Update role admin di database langsung
    await prisma.user.update({
      where: { email: adminUser.email },
      data: { role: Role.ADMIN },
    });

    // Login admin
    const adminLogin = await request(httpServer)
      .post('/api/auth/login')
      .send({
        email: adminUser.email,
        password: adminUser.password,
      });
    adminToken = adminLogin.body.accessToken;

    // Register regular user
    const userReg = await request(httpServer)
      .post('/api/auth/register')
      .send(regularUser);

    // Login regular user
    const userLogin = await request(httpServer)
      .post('/api/auth/login')
      .send({
        email: regularUser.email,
        password: regularUser.password,
      });
    userToken = userLogin.body.accessToken;
  });

  // ============== CREATE BOOK ==============

  describe('POST /api/books', () => {
    it('should create a book as admin (201)', async () => {
      const response = await request(httpServer)
        .post('/api/books')
        .set('Authorization', `Bearer ${adminToken}`)
        .send(testBook)
        .expect(201);

      expect(response.body.data).toBeDefined();
      expect(response.body.data.title).toBe(testBook.title);
      expect(response.body.data.author).toBe(testBook.author);
      expect(response.body.data.isbn).toBe(testBook.isbn);
      expect(response.body.data.id).toBeDefined();

      createdBookId = response.body.data.id;
    });

    it('should reject create book without token (401)', async () => {
      await request(httpServer)
        .post('/api/books')
        .send(testBook)
        .expect(401);
    });

    it('should reject create book with regular user role (403)', async () => {
      await request(httpServer)
        .post('/api/books')
        .set('Authorization', `Bearer ${userToken}`)
        .send(testBook)
        .expect(403);
    });

    it('should reject create book with invalid data (400)', async () => {
      await request(httpServer)
        .post('/api/books')
        .set('Authorization', `Bearer ${adminToken}`)
        .send({
          title: '', // Empty title
          author: 'Test',
          isbn: 'invalid-isbn',
          publishedYear: 1800, // Terlalu lama
          genre: '',
          stock: -1, // Negatif
        })
        .expect(400);
    });

    it('should reject duplicate ISBN (409)', async () => {
      await request(httpServer)
        .post('/api/books')
        .set('Authorization', `Bearer ${adminToken}`)
        .send(testBook)
        .expect(409);
    });

    it('should handle missing required fields (400)', async () => {
      const response = await request(httpServer)
        .post('/api/books')
        .set('Authorization', `Bearer ${adminToken}`)
        .send({})
        .expect(400);

      expect(Array.isArray(response.body.message)).toBe(true);
    });
  });

  // ============== GET ALL BOOKS ==============

  describe('GET /api/books', () => {
    it('should return all books as authenticated user (200)', async () => {
      const response = await request(httpServer)
        .get('/api/books')
        .set('Authorization', `Bearer ${userToken}`)
        .expect(200);

      expect(Array.isArray(response.body.data)).toBe(true);
      expect(response.body.data.length).toBeGreaterThanOrEqual(1);
    });

    it('should return wrapped response with success flag', async () => {
      const response = await request(httpServer)
        .get('/api/books')
        .set('Authorization', `Bearer ${adminToken}`);

      expect(response.body).toHaveProperty('success', true);
      expect(response.body).toHaveProperty('data');
      expect(response.body).toHaveProperty('timestamp');
    });

    it('should reject without token (401)', async () => {
      await request(httpServer).get('/api/books').expect(401);
    });
  });

  // ============== GET BOOK BY ID ==============

  describe('GET /api/books/:id', () => {
    it('should return a book by ID (200)', async () => {
      const response = await request(httpServer)
        .get(`/api/books/${createdBookId}`)
        .set('Authorization', `Bearer ${userToken}`)
        .expect(200);

      expect(response.body.data.id).toBe(createdBookId);
      expect(response.body.data.title).toBe(testBook.title);
    });

    it('should return 404 for non-existent book', async () => {
      await request(httpServer)
        .get('/api/books/non-existent-id')
        .set('Authorization', `Bearer ${userToken}`)
        .expect(404);
    });

    it('should return 401 without token', async () => {
      await request(httpServer)
        .get(`/api/books/${createdBookId}`)
        .expect(401);
    });

    it('should return complete book fields', async () => {
      const response = await request(httpServer)
        .get(`/api/books/${createdBookId}`)
        .set('Authorization', `Bearer ${adminToken}`);

      expect(response.body.data).toMatchObject({
        id: expect.any(String),
        title: expect.any(String),
        author: expect.any(String),
        isbn: expect.any(String),
        publishedYear: expect.any(Number),
        genre: expect.any(String),
        stock: expect.any(Number),
        createdAt: expect.any(String),
        updatedAt: expect.any(String),
      });
    });
  });

  // ============== UPDATE BOOK ==============

  describe('PATCH /api/books/:id', () => {
    const updateData = {
      title: 'Updated E2E Book Title',
      stock: 25,
    };

    it('should update a book as admin (200)', async () => {
      const response = await request(httpServer)
        .patch(`/api/books/${createdBookId}`)
        .set('Authorization', `Bearer ${adminToken}`)
        .send(updateData)
        .expect(200);

      expect(response.body.data.title).toBe(updateData.title);
      expect(response.body.data.stock).toBe(updateData.stock);
    });

    it('should reject update without token (401)', async () => {
      await request(httpServer)
        .patch(`/api/books/${createdBookId}`)
        .send(updateData)
        .expect(401);
    });

    it('should reject update with regular user (403)', async () => {
      await request(httpServer)
        .patch(`/api/books/${createdBookId}`)
        .set('Authorization', `Bearer ${userToken}`)
        .send(updateData)
        .expect(403);
    });

    it('should return 404 when updating non-existent book', async () => {
      await request(httpServer)
        .patch('/api/books/non-existent-id')
        .set('Authorization', `Bearer ${adminToken}`)
        .send({ title: 'New Title' })
        .expect(404);
    });

    it('should update only provided fields (partial update)', async () => {
      const response = await request(httpServer)
        .patch(`/api/books/${createdBookId}`)
        .set('Authorization', `Bearer ${adminToken}`)
        .send({ genre: 'Updated Genre' })
        .expect(200);

      expect(response.body.data.genre).toBe('Updated Genre');
      expect(response.body.data.title).toBe(updateData.title); // Tidak berubah
    });
  });

  // ============== DELETE BOOK ==============

  describe('DELETE /api/books/:id', () => {
    let bookToDeleteId: string;

    beforeEach(async () => {
      // Buat buku baru untuk dihapus
      const response = await request(httpServer)
        .post('/api/books')
        .set('Authorization', `Bearer ${adminToken}`)
        .send({
          ...testBook,
          isbn: `978-E2E-TEST-${Date.now()}`,
          title: 'Book to Delete',
        });

      bookToDeleteId = response.body.data.id;
    });

    it('should delete a book as admin (200)', async () => {
      await request(httpServer)
        .delete(`/api/books/${bookToDeleteId}`)
        .set('Authorization', `Bearer ${adminToken}`)
        .expect(200);

      // Verifikasi buku benar-benar hilang
      await request(httpServer)
        .get(`/api/books/${bookToDeleteId}`)
        .set('Authorization', `Bearer ${adminToken}`)
        .expect(404);
    });

    it('should reject delete without token (401)', async () => {
      await request(httpServer)
        .delete(`/api/books/${bookToDeleteId}`)
        .expect(401);
    });

    it('should reject delete with regular user (403)', async () => {
      await request(httpServer)
        .delete(`/api/books/${bookToDeleteId}`)
        .set('Authorization', `Bearer ${userToken}`)
        .expect(403);
    });

    it('should return 404 when deleting non-existent book', async () => {
      await request(httpServer)
        .delete('/api/books/non-existent-id')
        .set('Authorization', `Bearer ${adminToken}`)
        .expect(404);
    });

    it('should return 404 when deleting already deleted book', async () => {
      await request(httpServer)
        .delete(`/api/books/${bookToDeleteId}`)
        .set('Authorization', `Bearer ${adminToken}`)
        .expect(200);

      await request(httpServer)
        .delete(`/api/books/${bookToDeleteId}`)
        .set('Authorization', `Bearer ${adminToken}`)
        .expect(404);
    });
  });

  // ============== FILTERING & PAGINATION ==============

  describe('GET /api/books with filters', () => {
    beforeAll(async () => {
      // Buat beberapa buku dengan variasi genre
      const genres = ['Fiction', 'Non-Fiction', 'Science', 'History'];
      for (let i = 0; i < 4; i++) {
        await request(httpServer)
          .post('/api/books')
          .set('Authorization', `Bearer ${adminToken}`)
          .send({
            ...testBook,
            isbn: `978-E2E-FILTER-${i}`,
            title: `Filter Test Book ${i}`,
            genre: genres[i],
          });
      }
    });

    it('should filter books by genre', async () => {
      const response = await request(httpServer)
        .get('/api/books?genre=Fiction')
        .set('Authorization', `Bearer ${adminToken}`)
        .expect(200);

      expect(Array.isArray(response.body.data)).toBe(true);
      response.body.data.forEach((book: any) => {
        expect(book.genre).toBe('Fiction');
      });
    });

    it('should paginate results with limit and offset', async () => {
      const response = await request(httpServer)
        .get('/api/books?limit=2&offset=0')
        .set('Authorization', `Bearer ${adminToken}`)
        .expect(200);

      expect(response.body.data.length).toBeLessThanOrEqual(2);
    });
  });
});
```

## Analogi

Bayangkan perpustakaan memiliki **sistem manajemen koleksi buku**. Ada tiga jenis pengunjung: **tamu tanpa kartu** (tanpa token), **anggota biasa** (role USER), dan **staf perpustakaan** (role ADMIN). Penguji mensimulasikan skenario berikut: (1) Tamu tanpa kartu mencoba menambah buku baru — ditolak karena tidak punya akses. (2) Anggota biasa mencoba menambah buku — ditolak karena hanya staf yang boleh menambah koleksi. (3) Staf perpustakaan menambah buku baru — berhasil, buku muncul di rak. (4) Staf mencari buku berdasarkan judul — buku ditemukan. (5) Staf memperbarui informasi buku — data berubah. (6) Staf menghapus buku — buku hilang dari rak. (7) Semua pengunjung — bahkan staf — tidak bisa mencari buku yang tidak ada di database. Setiap tindakan dicatat dan responsnya diverifikasi, memastikan sistem manajemen koleksi berfungsi dengan aman dan benar.

## Kesalahan Umum yang Sering Terjadi

1. **Setup user tidak konsisten**: Admin dan regular user dibuat tapi role admin tidak diupdate di database, menyebabkan test admin gagal. Solusi: update role langsung di database via Prisma setelah register.

2. **Data test tidak unik**: ISBN yang sama digunakan di multiple test, menyebabkan duplicate key error. Solusi: gunakan timestamp atau counter untuk membuat ISBN unik per test.

3. **Tidak membersihkan data setelah test**: Data dari test sebelumnya mempengaruhi test berikutnya. Solusi: gunakan `afterAll` untuk menghapus data dengan pattern `isbn: { contains: 'E2E-TEST' }`.

4. **Assertion tidak spesifik untuk role**: Test hanya mengecek status code 403 tanpa memverifikasi bahwa error message sesuai. Solusi: tambahkan assertion pada body response.

5. **Tidak menguji partial update**: PATCH seharusnya hanya mengupdate field yang dikirim, tapi banyak test hanya menguji full update. Solusi: tambahkan test yang mengirim satu field dan verifikasi field lain tidak berubah.

6. **Lupa menguji pagination dan filtering**: Endpoint findAll biasanya mendukung query parameter, tapi jarang diuji. Solusi: tambahkan test untuk filter by genre dan pagination.
