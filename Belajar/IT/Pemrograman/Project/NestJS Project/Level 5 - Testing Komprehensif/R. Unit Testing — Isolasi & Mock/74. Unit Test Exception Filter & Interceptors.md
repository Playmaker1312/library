# 74. Unit Test Exception Filter & Interceptors

## Penjelasan

Exception filters dan interceptors adalah komponen global di NestJS yang menangani request dan response di level infrastruktur. Exception filter seperti `GlobalExceptionFilter` bertugas menangkap semua unhandled exception yang terjadi di aplikasi dan mengubahnya menjadi response JSON yang konsisten. Interceptors seperti `ResponseWrapperInterceptor` membungkus response sukses ke dalam format standar, sementara `LoggingInterceptor` mencatat setiap request yang masuk beserta durasi eksekusinya. Menguji komponen-komponen ini penting karena mereka mempengaruhi **setiap response** yang keluar dari aplikasi.

Tantangan utama dalam menguji exception filter adalah kita perlu membuat mock exception yang realistis: `HttpException` dengan status code berbeda, `BadRequestException` dengan validation errors, dan error tak terduga seperti `TypeError`. Filter harus bisa membedakan semua jenis error ini dan menghasilkan response yang sesuai. Untuk menguji interceptor, kita perlu memanipulasi `CallHandler` — khususnya method `handle()` yang mengembalikan Observable — dan memverifikasi bahwa response di-transform dengan benar.

Pendekatan testing untuk komponen global ini sedikit berbeda dari service biasa. Alih-alih menggunakan `Test.createTestingModule`, kita bisa langsung meng-instantiate filter/interceptor dan memanggil method-nya secara manual dengan mock arguments. Ini lebih sederhana dan cepat karena tidak perlu kompilasi modul. Namun, untuk interceptor yang memiliki dependency (seperti `LoggingInterceptor` yang membutuhkan `Logger`), kita tetap perlu menyediakan mock dependency atau menggunakan pendekatan modul.

## Fungsi

- Memvalidasi `GlobalExceptionFilter` menghasilkan response JSON yang konsisten untuk semua error
- Memvalidasi `ResponseWrapperInterceptor` membungkus response sukses dengan format `{ success, data, timestamp }`
- Memvalidasi `LoggingInterceptor` mencatat method, URL, status code, dan durasi request
- Menguji edge cases: error tanpa stack trace, error dengan validation messages array
- Memastikan struktur response konsisten antara endpoint sukses dan error
- Dokumentasi kontrak response API secara eksplisit

import { ArgumentsHost } from '@nestjs/common';

export function createMockArgumentsHost(options?: {
  statusCode?: number;
  jsonMock?: jest.Mock;
}): ArgumentsHost {
  const jsonMock = options?.jsonMock ?? jest.fn();
  const statusMock = jest.fn().mockReturnValue({ json: jsonMock });

  const response = {
    status: statusMock,
    json: jsonMock,
  };

  const request = {
    url: '/api/books',
    method: 'GET',
    ip: '127.0.0.1',
  };

  return {
    switchToHttp: () => ({
      getResponse: () => response,
      getRequest: () => request,
      getNext: () => jest.fn(),
    }),
    switchToRpc: () => ({} as any),
    switchToWs: () => ({} as any),
    getType: () => 'http',
  } as ArgumentsHost;
}

### 2. `global-exception.filter.spec.ts`

```typescript
// src/common/filters/global-exception.filter.spec.ts
import {
  BadRequestException,
  ForbiddenException,
  NotFoundException,
  HttpException,
} from '@nestjs/common';
import { GlobalExceptionFilter } from './global-exception.filter';
import { createMockArgumentsHost } from '../../../test/mocks/arguments-host.mock';

describe('GlobalExceptionFilter', () => {
  let filter: GlobalExceptionFilter;

  beforeEach(() => {
    filter = new GlobalExceptionFilter();
  });

  describe('catch', () => {
    it('should handle HttpException with proper status and message', () => {
      const exception = new NotFoundException('Book not found');
      const jsonMock = jest.fn();
      const host = createMockArgumentsHost({ jsonMock });

      filter.catch(exception, host);

      expect(jsonMock).toHaveBeenCalledWith(
        expect.objectContaining({
          statusCode: 404,
          message: 'Book not found',
          error: 'Not Found',
        }),
      );
    });

    it('should handle BadRequestException with validation errors', () => {
      const exception = new BadRequestException([
        'title must be a string',
        'author must be a string',
      ]);
      const jsonMock = jest.fn();
      const host = createMockArgumentsHost({ jsonMock });

      filter.catch(exception, host);

      expect(jsonMock).toHaveBeenCalledWith(
        expect.objectContaining({
          statusCode: 400,
          message: ['title must be a string', 'author must be a string'],
          error: 'Bad Request',
        }),
      );
    });

    it('should handle ForbiddenException', () => {
      const exception = new ForbiddenException('Access denied');
      const jsonMock = jest.fn();
      const host = createMockArgumentsHost({ jsonMock });

      filter.catch(exception, host);

      expect(jsonMock).toHaveBeenCalledWith(
        expect.objectContaining({
          statusCode: 403,
          message: 'Access denied',
        }),
      );
    });

    it('should handle unknown non-HTTP exceptions as 500 Internal Server Error', () => {
      const exception = new Error('Database connection failed');
      const jsonMock = jest.fn();
      const host = createMockArgumentsHost({ jsonMock });

      filter.catch(exception, host);

      expect(jsonMock).toHaveBeenCalledWith(
        expect.objectContaining({
          statusCode: 500,
          message: 'Internal server error',
        }),
      );
    });

    it('should include stack trace in development environment', () => {
      const originalEnv = process.env.NODE_ENV;
      process.env.NODE_ENV = 'development';

      const exception = new Error('Test error');
      const jsonMock = jest.fn();
      const host = createMockArgumentsHost({ jsonMock });

      filter.catch(exception, host);

      expect(jsonMock).toHaveBeenCalledWith(
        expect.objectContaining({
          stack: expect.any(String),
        }),
      );

      process.env.NODE_ENV = originalEnv;
    });

    it('should NOT include stack trace in production environment', () => {
      const originalEnv = process.env.NODE_ENV;
      process.env.NODE_ENV = 'production';

      const exception = new Error('Test error');
      const jsonMock = jest.fn();
      const host = createMockArgumentsHost({ jsonMock });

      filter.catch(exception, host);

      expect(jsonMock).toHaveBeenCalledWith(
        expect.not.objectContaining({
          stack: expect.any(String),
        }),
      );

      process.env.NODE_ENV = originalEnv;
    });

    it('should include timestamp in every response', () => {
      const exception = new HttpException('Test', 418);
      const jsonMock = jest.fn();
      const host = createMockArgumentsHost({ jsonMock });

      filter.catch(exception, host);

      expect(jsonMock).toHaveBeenCalledWith(
        expect.objectContaining({
          timestamp: expect.any(String),
        }),
      );
    });
  });
});
```

### 3. `response-wrapper.interceptor.spec.ts`

```typescript
// src/common/interceptors/response-wrapper.interceptor.spec.ts
import { of } from 'rxjs';
import { ResponseWrapperInterceptor } from './response-wrapper.interceptor';
import { createMockExecutionContext } from '../../../test/mocks/execution-context.mock';

describe('ResponseWrapperInterceptor', () => {
  let interceptor: ResponseWrapperInterceptor;

  beforeEach(() => {
    interceptor = new ResponseWrapperInterceptor();
  });

  describe('intercept', () => {
    it('should wrap response data with success flag and timestamp', (done) => {
      const data = { id: '1', title: 'NestJS Book' };
      const context = createMockExecutionContext();
      const next = { handle: () => of(data) };

      interceptor.intercept(context, next).subscribe((result) => {
        expect(result).toEqual({
          success: true,
          data: { id: '1', title: 'NestJS Book' },
          timestamp: expect.any(String),
        });
        done();
      });
    });

    it('should handle array data correctly', (done) => {
      const data = [
        { id: '1', title: 'Book 1' },
        { id: '2', title: 'Book 2' },
      ];
      const context = createMockExecutionContext();
      const next = { handle: () => of(data) };

      interceptor.intercept(context, next).subscribe((result) => {
        expect(result.success).toBe(true);
        expect(Array.isArray(result.data)).toBe(true);
        expect(result.data).toHaveLength(2);
        done();
      });
    });

    it('should handle paginated data correctly', (done) => {
      const paginatedData = {
        items: [{ id: '1', title: 'Book 1' }],
        total: 10,
        page: 1,
        limit: 10,
      };
      const context = createMockExecutionContext();
      const next = { handle: () => of(paginatedData) };

      interceptor.intercept(context, next).subscribe((result) => {
        expect(result.success).toBe(true);
        expect(result.data.items).toBeDefined();
        expect(result.data.total).toBe(10);
        done();
      });
    });

    it('should handle empty response null', (done) => {
      const context = createMockExecutionContext();
      const next = { handle: () => of(null) };

      interceptor.intercept(context, next).subscribe((result) => {
        expect(result).toEqual({
          success: true,
          data: null,
          timestamp: expect.any(String),
        });
        done();
      });
    });
  });
});
```

### 4. `logging.interceptor.spec.ts`

```typescript
// src/common/interceptors/logging.interceptor.spec.ts
import { of } from 'rxjs';
import { Logger } from '@nestjs/common';
import { LoggingInterceptor } from './logging.interceptor';
import { createMockExecutionContext } from '../../../test/mocks/execution-context.mock';

describe('LoggingInterceptor', () => {
  let interceptor: LoggingInterceptor;
  let loggerMock: jest.Mocked<Logger>;

  beforeEach(() => {
    loggerMock = {
      log: jest.fn(),
      error: jest.fn(),
      warn: jest.fn(),
    } as any;

    interceptor = new LoggingInterceptor();
    (interceptor as any).logger = loggerMock;
  });

  describe('intercept', () => {
    it('should log incoming request and its duration', (done) => {
      const context = createMockExecutionContext({
        headers: { 'user-agent': 'Jest' },
      });

      // Mock Date.now untuk mendapatkan durasi yang konsisten
      const nowMock = jest
        .spyOn(Date, 'now')
        .mockReturnValueOnce(1000) // start
        .mockReturnValueOnce(1500); // end (500ms)

      const next = { handle: () => of({ data: 'test' }) };

      interceptor.intercept(context, next).subscribe(() => {
        expect(loggerMock.log).toHaveBeenCalledWith(
          expect.stringContaining('GET /api/books'),
        );
        expect(loggerMock.log).toHaveBeenCalledWith(
          expect.stringContaining('500ms'),
        );

        nowMock.mockRestore();
        done();
      });
    });

    it('should log error if request handler throws', (done) => {
      const context = createMockExecutionContext();
      const error = new Error('Test error');
      const next = {
        handle: () => {
          throw error;
        },
      };

      try {
        interceptor.intercept(context, next);
      } catch (e) {
        expect(loggerMock.error).toHaveBeenCalledWith(
          expect.stringContaining('Error: Test error'),
        );
        done();
      }
    });

    it('should handle requests without user-agent header', (done) => {
      const context = createMockExecutionContext();
      const next = { handle: () => of({}) };

      interceptor.intercept(context, next).subscribe(() => {
        expect(loggerMock.log).toHaveBeenCalled();
        done();
      });
    });
  });
});
```

## Analogi

Bayangkan perpustakaan memiliki **papan pengumuman digital** di pintu masuk. Ketika seorang anggota meminjam buku (request), papan pengumuman menampilkan respons dalam format yang rapi. Fungsi papan ini ada dua: (1) **Filter Exception** — jika terjadi masalah (buku tidak ditemukan, kartu expired, buku rusak), papan menampilkan pesan error dengan kode yang jelas (404, 401, 500) dalam format yang konsisten. (2) **Interceptor** — jika semuanya berjalan lancar, papan membungkus informasi buku yang dipinjam ke dalam amplop rapi bertuliskan "Sukses" bersama stempel waktu. Ada juga **papan catatan** (logging interceptor) yang mencatat setiap aktivitas: "Anggota X meminjam buku Y pada pukul Z, selesai dalam 2 detik". Menguji komponen-komponen ini berarti memastikan bahwa apa pun yang terjadi (sukses, error, atau error tak terduga), papan pengumuman selalu menampilkan informasi dengan format yang konsisten dan mudah dipahami.

## Penggunaan

- Memvalidasi format response API konsisten di semua endpoint
- Memastikan error handling tidak membocorkan detail internal di production
- Menguji bahwa logging berfungsi untuk audit trail dan debugging
- Dokumentasi kontrak response API untuk tim frontend
- Regression test saat mengubah format response

## Kesalahan Umum yang Sering Terjadi

1. **Tidak menguji environment-specific behavior**: Filter menampilkan stack trace di development tapi tidak di production, tapi test hanya mencakup satu environment. Solusi: test kedua environment dengan mengubah `process.env.NODE_ENV`.

2. **Mock ArgumentsHost tidak lengkap**: Filter mengakses `response.status()` lalu `response.status().json()`. Jika mock tidak chainable, test gagal. Solusi: pastikan mock method mengembalikan `this` atau object yang sesuai.

3. **Interceptor tidak mengembalikan Observable**: Interceptor NestJS menggunakan RxJS, jadi test harus subscribe ke Observable. Tanpa subscribe, test tidak menunggu hasilnya. Solusi: gunakan `done` callback atau `lastValueFrom` untuk Promise-based testing.

4. **Date.now tidak di-mock**: Test logging interceptor menjadi non-deterministik karena durasi bergantung pada waktu eksekusi aktual. Solusi: mock `Date.now` untuk mengontrol nilai yang dikembalikan.

5. **Lupa test untuk error di interceptor**: Jika request handler throw error, interceptor juga harus menanganinya dengan benar. Solusi: tambahkan test case untuk skenario di mana `next.handle()` melempar error.
