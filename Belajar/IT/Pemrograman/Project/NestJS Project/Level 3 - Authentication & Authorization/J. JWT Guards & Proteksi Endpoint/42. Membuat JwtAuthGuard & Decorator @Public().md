# 42. Membuat JwtAuthGuard & Decorator @Public()

## Penjelasan

JwtAuthGuard adalah custom guard yang mewarisi `AuthGuard('jwt')` dari Passport. Guard ini menambahkan fungsionalitas ekstra: kemampuan untuk menandai endpoint tertentu sebagai `@Public()` (tanpa autentikasi) meskipun guard dipasang secara global. Ini sangat berguna ketika kita ingin menerapkan autentikasi di semua endpoint sebagai default, tetapi tetap membuka akses untuk endpoint seperti register, login, atau health-check.

Mekanisme ini menggunakan **Reflector** — fitur NestJS yang memungkinkan kita membaca metadata yang ditempelkan ke class/handler melalui decorator. Kita membuat decorator `@Public()` yang menambahkan metadata `isPublic: true` ke endpoint. Di dalam JwtAuthGuard, kita cek metadata tersebut sebelum menjalankan logika autentikasi. Jika endpoint bersifat public, guard akan melewati proses autentikasi.

## Fungsi

JwtAuthGuard berfungsi sebagai pengaman global yang melindungi semua endpoint di aplikasi. Dengan mendaftarkannya secara global di `AppModule`, kita tidak perlu menambahkan `@UseGuards(AuthGuard('jwt'))` di setiap controller. Decorator `@Public()` berfungsi untuk mengecualikan endpoint tertentu dari autentikasi global.

## Cara Implementasi / Code

**1. JwtAuthGuard — `src/auth/guards/jwt-auth.guard.ts`:**

```typescript
import { Injectable, ExecutionContext } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { AuthGuard } from '@nestjs/passport';

@Injectable()
export class JwtAuthGuard extends AuthGuard('jwt') {
  constructor(private readonly reflector: Reflector) {
    super();
  }

  canActivate(context: ExecutionContext) {
    // Cek apakah endpoint memiliki decorator @Public()
    const isPublic = this.reflector.getAllAndOverride<boolean>('isPublic', [
      context.getHandler(),
      context.getClass(),
    ]);

    // Jika public, lewati autentikasi
    if (isPublic) {
      return true;
    }

    // Jika tidak, jalankan autentikasi JWT normal
    return super.canActivate(context);
  }
}
```

**2. Decorator @Public() — `src/auth/decorators/public.decorator.ts`:**

```typescript
import { SetMetadata } from '@nestjs/common';

export const IS_PUBLIC_KEY = 'isPublic';

// @Public() akan menambahkan metadata isPublic: true
export const Public = () => SetMetadata(IS_PUBLIC_KEY, true);
```

**3. Export decorator dan guard dari barrel file — `src/auth/decorators/index.ts`:**

```typescript
export { Public } from './public.decorator';
export { JwtAuthGuard } from '../guards/jwt-auth.guard';
```

**4. Daftarkan JwtAuthGuard secara global di `app.module.ts`:**

```typescript
import { Module } from '@nestjs/common';
import { APP_GUARD } from '@nestjs/core';
import { ConfigModule } from '@nestjs/config';
import { PrismaModule } from './prisma/prisma.module';
import { BooksModule } from './books/books.module';
import { UsersModule } from './users/users.module';
import { AuthModule } from './auth/auth.module';
import { JwtAuthGuard } from './auth/guards/jwt-auth.guard';

@Module({
  imports: [
    ConfigModule.forRoot({ isGlobal: true }),
    PrismaModule,
    BooksModule,
    UsersModule,
    AuthModule,
  ],
  providers: [
    {
      provide: APP_GUARD,
      useClass: JwtAuthGuard,
    },
  ],
})
export class AppModule {}
```

**5. Gunakan @Public() di endpoint yang tidak membutuhkan autentikasi:**

```typescript
import { Controller, Post, Body } from '@nestjs/common';
import { AuthService } from './auth.service';
import { RegisterDto } from './dto/register.dto';
import { LoginDto } from './dto/login.dto';
import { Public } from '../decorators/public.decorator';

@Controller('auth')
export class AuthController {
  constructor(private readonly authService: AuthService) {}

  @Public()
  @Post('register')
  async register(@Body() dto: RegisterDto) {
    return this.authService.register(dto);
  }

  @Public()
  @Post('login')
  async login(@Body() dto: LoginDto) {
    return this.authService.login(dto);
  }

  @Post('refresh')
  async refresh(@Body() body: { refreshToken: string }) {
    return this.authService.refreshTokens(body.refreshToken);
  }

  @Post('logout')
  async logout(@Body() body: { userId: number }) {
    return this.authService.logout(body.userId);
  }
}
```

## Analogi

JwtAuthGuard di perpustakaan seperti **sistem keamanan terpusat** yang terpasang di semua pintu. Semua pintu otomatis terkunci. Tapi beberapa area memang harus terbuka untuk umum — seperti pintu masuk utama (register) dan ruang informasi (login). Area-area ini diberi tanda **PUBLIC** (`@Public()`) sehingga sistem keamanan melewatinya. Tanpa tanda ini, pengunjung baru tidak akan bisa masuk karena harus menunjukkan kartu anggota yang belum mereka miliki. Ini paradoks yang dipecahkan oleh decorator @Public().

## Penggunaan

Guard global dengan @Public() sangat berguna untuk:
- Endpoint autentikasi (register, login) yang harus bisa diakses tanpa token
- Endpoint publik (halaman utama, health check, dokumentasi API)
- Webhook yang dipanggil oleh service eksternal
- Endpoint yang menggunakan mekanisme autentikasi berbeda

## Kesalahan Umum yang Sering Terjadi

1. **Lupa memberi @Public() pada endpoint register/login**: Jika guard global aktif, endpoint register dan login akan membutuhkan token — padahal user belum punya token. Ini circular dependency.
2. **Salah import Reflector**: Pastikan menggunakan `@nestjs/core` Reflector, bukan dari library lain.
3. **Guard tidak terdaftar secara global**: Jika menggunakan `@UseGuards(JwtAuthGuard)` per controller, @Public() mungkin tidak berfungsi jika guard tidak mengecek metadata.
4. **Metadata key typo**: Key 'isPublic' di decorator harus sama persis dengan key yang dibaca di guard. Gunakan konstanta untuk menghindari typo.

## Hubungan dengan Materi Sebelumnya

JwtAuthGuard menggunakan JwtStrategy (materi 40) sebagai strategy autentikasi. Dengan adanya guard global, kita tidak perlu lagi menambahkan `@UseGuards(AuthGuard('jwt'))` di setiap controller. Decorator @Public() memungkinkan endpoint tertentu di AuthController (register, login) untuk tetap bisa diakses tanpa autentikasi.

## Soal Latihan

**Soal 1:** Apa yang terjadi jika kita lupa menambahkan @Public() di endpoint register?

**Jawaban:** Endpoint register akan dilindungi oleh JwtAuthGuard global. Saat client mencoba mendaftar, mereka akan mendapatkan response 401 Unauthorized karena tidak mengirim token. Ini membuat registrasi tidak mungkin dilakukan — pengguna baru tidak bisa mendaftar karena mereka belum punya akun untuk login. Ini adalah circular dependency.

**Soal 2:** Bagaimana cara menambahkan @Public() di level controller (semua endpoint dalam satu controller)?

**Jawaban:** Tempatkan decorator @Public() di atas class controller, bukan di atas method. Guard akan membaca metadata dari class level juga karena kita menggunakan `getAllAndOverride` yang membaca dari handler dan class.

```typescript
@Public()
@Controller('public')
export class PublicController {
  @Get()
  findAll() { /* public */ }

  @Get(':id')
  findOne() { /* public */ }
}
```

**Soal 3:** Buat decorator @Public() yang bisa menerima argumen opsional, misalnya @Public('optional') yang berarti autentikasi opsional (tidak wajib, tapi jika ada token, validasi tetap jalan).

**Jawaban:**

```typescript
import { SetMetadata } from '@nestjs/common';

export const IS_PUBLIC_KEY = 'isPublic';

export const Public = (mode: 'strict' | 'optional' = 'strict') =>
  SetMetadata(IS_PUBLIC_KEY, mode);
```

```typescript
// Di guard
async canActivate(context: ExecutionContext) {
  const isPublic = this.reflector.getAllAndOverride<string>(IS_PUBLIC_KEY, [
    context.getHandler(),
    context.getClass(),
  ]);

  if (isPublic === 'strict') {
    return true; // Lewati autentikasi sepenuhnya
  }

  if (isPublic === 'optional') {
    try {
      return await super.canActivate(context);
    } catch {
      return true; // Jika token tidak ada/salah, tetap lanjut
    }
  }

  return super.canActivate(context);
}
```
