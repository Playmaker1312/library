# Membangun BooksService — CRUD dengan In-Memory Array

## Penjelasan

**Service** adalah jantung dari logic bisnis aplikasi NestJS. Di sinilah semua operasi data dilakukan — menyimpan, membaca, memperbarui, dan menghapus. Untuk tahap awal pembelajaran, kita akan menggunakan **in-memory array** sebagai penyimpanan data. Artinya, data hanya tersimpan selama aplikasi berjalan dan akan hilang saat server dimatikan. Ini sengaja dilakukan agar kita fokus pada logika CRUD tanpa kompleksitas database.

Service Books akan mengelola array `Book[]` di memory. Setiap operasi CRUD akan memanipulasi array ini. Untuk operasi **create**, kita membuat objek Book baru dengan `uuid` dan timestamp, lalu menambahkannya ke array. Untuk **findAll**, kita mengembalikan seluruh array (atau yang sudah difilter). Untuk **findById**, kita mencari berdasarkan `id`. Untuk **update**, kita menemukan buku yang sesuai lalu memperbarui propertinya. Untuk **remove**, kita menyaring array untuk menghilangkan buku dengan id tertentu.

NestJS menyediakan exception class seperti `NotFoundException` untuk kasus ketika data tidak ditemukan. Jika client meminta buku dengan id yang tidak ada, service akan melempar `NotFoundException(404)` yang nantinya akan ditangani oleh global exception filter. Ini adalah praktik yang baik — service tidak perlu mengembalikan `null` atau `undefined`, cukup lempar exception dan biarkan lapisan lain yang menanganinya.

## Fungsi

BooksService berfungsi sebagai **lapisan akses data** untuk module Books. Service ini menyediakan method-method CRUD (`create`, `findAll`, `findById`, `update`, `remove`) yang bisa dipanggil oleh controller. Dengan memisahkan logic bisnis ke service, controller tetap ringan dan hanya bertugas sebagai router/handler HTTP. Service juga bisa digunakan kembali oleh controller lain atau bahkan digunakan di dalam service lain.

### 2. BooksService lengkap

Buka file `src/modules/books/books.service.ts` dan tulis kode berikut:

```typescript
import { Injectable, NotFoundException } from '@nestjs/common';
import { v4 as uuidv4 } from 'uuid';
import { Book } from './interfaces/book.interface';
import { CreateBookDto } from './dto/create-book.dto';
import { UpdateBookDto } from './dto/update-book.dto';
import { QueryBookDto } from './dto/query-book.dto';

@Injectable()
export class BooksService {
  private books: Book[] = [];

  create(createBookDto: CreateBookDto): Book {
    const book: Book = {
      id: uuidv4(),
      ...createBookDto,
      createdAt: new Date(),
      updatedAt: new Date(),
    };
    this.books.push(book);
    return book;
  }

  findAll(query?: QueryBookDto): Book[] {
    let result = [...this.books];

    if (query) {
      // Filter by search (title or author)
      if (query.search) {
        const searchLower = query.search.toLowerCase();
        result = result.filter(
          (book) =>
            book.title.toLowerCase().includes(searchLower) ||
            book.author.toLowerCase().includes(searchLower),
        );
      }

      // Filter by author
      if (query.author) {
        result = result.filter(
          (book) => book.author.toLowerCase() === query.author!.toLowerCase(),
        );
      }

      // Filter by year
      if (query.year) {
        result = result.filter((book) => book.year === query.year);
      }

      // Sorting
      if (query.sortBy) {
        const sortOrder = query.sortOrder === 'desc' ? -1 : 1;
        result.sort((a, b) => {
          const fieldA = a[query.sortBy!];
          const fieldB = b[query.sortBy!];
          if (fieldA < fieldB) return -1 * sortOrder;
          if (fieldA > fieldB) return 1 * sortOrder;
          return 0;
        });
      }

      // Pagination
      const page = query.page || 1;
      const limit = query.limit || 10;
      const start = (page - 1) * limit;
      result = result.slice(start, start + limit);
    }

    return result;
  }

  findById(id: string): Book {
    const book = this.books.find((b) => b.id === id);
    if (!book) {
      throw new NotFoundException(`Buku dengan id "${id}" tidak ditemukan`);
    }
    return book;
  }

  update(id: string, updateBookDto: UpdateBookDto): Book {
    const bookIndex = this.books.findIndex((b) => b.id === id);
    if (bookIndex === -1) {
      throw new NotFoundException(`Buku dengan id "${id}" tidak ditemukan`);
    }

    // Update hanya properti yang dikirim dalam DTO
    const updatedBook: Book = {
      ...this.books[bookIndex],
      ...updateBookDto,
      id: this.books[bookIndex].id, // Pastikan id tidak berubah
      updatedAt: new Date(),
    };

    this.books[bookIndex] = updatedBook;
    return updatedBook;
  }

  remove(id: string): { deleted: boolean; message: string } {
    const bookIndex = this.books.findIndex((b) => b.id === id);
    if (bookIndex === -1) {
      throw new NotFoundException(`Buku dengan id "${id}" tidak ditemukan`);
    }

    this.books.splice(bookIndex, 1);
    return {
      deleted: true,
      message: `Buku dengan id "${id}" berhasil dihapus`,
    };
  }
}
```

### 3. Penjelasan Method Service

| Method | Parameter | Return | Deskripsi |
|--------|-----------|--------|-----------|
| `create` | `CreateBookDto` | `Book` | Membuat buku baru, generate id + timestamp |
| `findAll` | `QueryBookDto?` | `Book[]` | Mendapatkan semua buku dengan filter & pagination |
| `findById` | `string (id)` | `Book` | Mendapatkan satu buku berdasarkan id |
| `update` | `string (id), UpdateBookDto` | `Book` | Update sebagian atau seluruh data buku |
| `remove` | `string (id)` | `object` | Menghapus buku dari array |

### 4. Pattern Penting: Guard Clause dengan Exception

```typescript
findById(id: string): Book {
  const book = this.books.find((b) => b.id === id);
  if (!book) {
    throw new NotFoundException(`Buku dengan id "${id}" tidak ditemukan`);
  }
  return book;
}
```

Pattern **guard clause** ini sangat umum di NestJS: validasi (cek apakah data ada) dilakukan di awal method. Jika tidak valid, lempar exception. Jika valid, lanjutkan eksekusi normal. Ini membuat kode lebih bersih karena tidak perlu nested if-else.

## Analogi

Bayangkan **BooksService** adalah **petugas perpustakaan** yang bekerja di belakang meja. Petugas ini memiliki **buku catatan** (array in-memory) untuk mencatat semua buku yang ada:

- **create** — Petugas menerima formulir buku baru (CreateBookDto), memberikan nomor ID unik pada buku tersebut, mencatat tanggal masuk, dan menyimpan buku di lemari (array).

- **findAll** — Saat pengunjung bertanya "buku apa saja yang ada?", petugas membuka lemari dan menunjukkan semua buku. Jika pengunjung minta filter (misalnya "cari buku karangan Author X"), petugas akan memilahnya.

- **findById** — Pengunjung memberikan nomor ID buku. Petugas mencari di lemari berdasarkan ID tersebut. Jika tidak ditemukan, petugas berkata "Maaf, buku dengan ID tersebut tidak ada" (NotFoundException).

- **update** — Pengunjung ingin memperbaiki data buku. Petugas menemukan buku yang dimaksud, memperbarui informasinya, dan mencatat tanggal perubahan.

- **remove** — Buku akan dihapus dari koleksi. Petugas mencoret buku dari catatan dan mengonfirmasi penghapusan.

Yang penting: petugas ini **tidak pernah berinteraksi langsung dengan pengunjung**. Semua komunikasi melalui **resepsionis (controller)**. Petugas hanya fokus pada pengelolaan data buku.

## Penggunaan

Service CRUD in-memory ini digunakan untuk **prototyping dan pembelajaran**. Dalam aplikasi nyata, service akan diganti dengan database (PostgreSQL, MySQL, MongoDB). Namun, logika dasarnya tetap sama — hanya penyimpanannya yang berubah dari array ke query database. Pattern method yang kita buat sekarang (create, findAll, findById, update, remove) akan tetap sama saat migrasi ke database nanti.

## Kesalahan Umum yang Sering Terjadi

1. **Lupa mendaftarkan service di module** — Jika `BooksService` tidak ada di `providers` array `BooksModule`, NestJS akan error saat mencoba meng-inject ke controller.

2. **Mengubah parameter DTO di dalam service** — DTO adalah objek yang bisa diubah (mutable). Hindari mengubah properti DTO langsung; buat objek baru.

3. **Tidak menggunakan spread operator untuk update** — Langsung assignment seperti `this.books[bookIndex] = updateBookDto` akan menghapus properti lain. Gunakan spread: `{ ...existing, ...updateBookDto }`.

4. **Tidak menangani kasus data tidak ditemukan** — Method `findById` harus melempar exception jika id tidak ditemukan. Jangan mengembalikan `null` atau `undefined`.

5. **Menyimpan password atau data sensitif di response** — Pastikan service tidak mengembalikan data yang tidak seharusnya (seperti password hash) ke client.

## Hubungan dengan Materi Sebelumnya

Service adalah **implementasi nyata** dari interface Book (materi 8) dan DTO (materi 9). Interface Book digunakan sebagai tipe data array dan return value. DTO digunakan sebagai parameter method. Setelah service selesai, kita akan menghubungkannya ke controller (materi 11) agar bisa diakses melalui HTTP.

## Soal Latihan

**Soal:** Buatlah `MembersService` dengan CRUD in-memory array. Service harus memiliki method:
1. `create(createMemberDto)` — membuat anggota baru
2. `findAll(query?)` — mencari anggota dengan filter (search berdasarkan fullName atau memberCode, filter isActive)
3. `findById(id)` — mencari anggota berdasarkan id, lempar NotFoundException jika tidak ada
4. `update(id, updateMemberDto)` — update data anggota
5. `remove(id)` — hapus anggota

**Jawaban:**

`src/modules/members/members.service.ts`:
```typescript
import { Injectable, NotFoundException } from '@nestjs/common';
import { v4 as uuidv4 } from 'uuid';
import { Member } from './interfaces/member.interface';
import { CreateMemberDto } from './dto/create-member.dto';
import { UpdateMemberDto } from './dto/update-member.dto';
import { QueryMemberDto } from './dto/query-member.dto';

@Injectable()
export class MembersService {
  private members: Member[] = [];

  create(createMemberDto: CreateMemberDto): Member {
    const member: Member = {
      id: uuidv4(),
      ...createMemberDto,
      isActive: true,
      createdAt: new Date(),
      updatedAt: new Date(),
    };
    this.members.push(member);
    return member;
  }

  findAll(query?: QueryMemberDto): Member[] {
    let result = [...this.members];

    if (query) {
      if (query.search) {
        const searchLower = query.search.toLowerCase();
        result = result.filter(
          (m) =>
            m.fullName.toLowerCase().includes(searchLower) ||
            m.memberCode.toLowerCase().includes(searchLower),
        );
      }

      if (query.isActive !== undefined) {
        result = result.filter((m) => m.isActive === query.isActive);
      }

      const page = query.page || 1;
      const limit = query.limit || 10;
      const start = (page - 1) * limit;
      result = result.slice(start, start + limit);
    }

    return result;
  }

  findById(id: string): Member {
    const member = this.members.find((m) => m.id === id);
    if (!member) {
      throw new NotFoundException(`Anggota dengan id "${id}" tidak ditemukan`);
    }
    return member;
  }

  update(id: string, updateMemberDto: UpdateMemberDto): Member {
    const index = this.members.findIndex((m) => m.id === id);
    if (index === -1) {
      throw new NotFoundException(`Anggota dengan id "${id}" tidak ditemukan`);
    }

    const updated: Member = {
      ...this.members[index],
      ...updateMemberDto,
      id: this.members[index].id,
      updatedAt: new Date(),
    };

    this.members[index] = updated;
    return updated;
  }

  remove(id: string): { deleted: boolean; message: string } {
    const index = this.members.findIndex((m) => m.id === id);
    if (index === -1) {
      throw new NotFoundException(`Anggota dengan id "${id}" tidak ditemukan`);
    }

    this.members.splice(index, 1);
    return { deleted: true, message: `Anggota ${id} berhasil dihapus` };
  }
}
```
