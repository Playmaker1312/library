# 86. Correlation ID - Trace Request dari Awal hingga Akhir

## Penjelasan
Dalam arsitektur production, satu request HTTP bisa melalui banyak lapisan: Nginx → NestJS → Database → Redis → Microservice → External API. Jika terjadi error, bagaimana cara mencari semua log yang berkaitan dengan satu request tertentu? Jawabannya adalah **Correlation ID** (atau Trace ID / Request ID) — sebuah identifier unik yang dibuat di awal request dan diwariskan ke semua log, database query, dan panggilan eksternal yang terjadi selama request tersebut.

Di NestJS, kita menggunakan library `nestjs-cls` (CLS = Continuation Local Storage) yang menyediakan **async context** — sebuah "ruang penyimpanan" yang aman untuk async operations. CLS bekerja mirip dengan `AsyncLocalStorage` bawaan Node.js, tetapi terintegrasi langsung dengan NestJS melalui `ClsModule`. Dengan CLS, kita bisa menyimpan Correlation ID di awal request (middleware) dan mengambilnya di mana saja dalam siklus request — controller, service, repository, interceptor, guard, filter — tanpa perlu meneruskannya sebagai parameter fungsi. Ini sangat elegant.

## Fungsi
- Membuat identifier unik untuk setiap request yang bisa dilacak di semua log dan trace
- Memudahkan debugging dengan menghubungkan log yang tersebar di berbagai service
- Memungkinkan tracing end-to-end melalui microservice (dengan mewariskan Correlation ID di header)

## Cara Implementasi / Code

**Install package:**
```bash
npm install nestjs-cls
```

**Setup ClsModule di AppModule:**

```typescript
import { Module } from '@nestjs/common';
import { ClsModule } from 'nestjs-cls';
import { v4 as uuidv4 } from 'uuid';

@Module({
  imports: [
    ClsModule.forRoot({
      global: true,
      middleware: {
        mount: true,
        generateId: true,
        idGenerator: () => uuidv4(),
      },
    }),
    // ... modul lain
  ],
})
export class AppModule {}
```

**CorrelationIdMiddleware (manual, jika ingin lebih banyak kontrol):**

```typescript
import { Injectable, NestMiddleware } from '@nestjs/common';
import { ClsService } from 'nestjs-cls';
import { Request, Response, NextFunction } from 'express';
import { v4 as uuidv4 } from 'uuid';

@Injectable()
export class CorrelationIdMiddleware implements NestMiddleware {
  constructor(private readonly cls: ClsService) {}

  use(req: Request, res: Response, next: NextFunction) {
    // Ambil Correlation ID dari header request (jika diwariskan dari service lain)
    // atau buat yang baru
    const correlationId = req.headers['x-correlation-id'] as string || uuidv4();

    // Simpan di CLS agar bisa diakses di seluruh siklus request
    this.cls.set('correlationId', correlationId);

    // Set header response agar client bisa melacak
    res.setHeader('X-Correlation-Id', correlationId);

    // Jika ada logger, attach correlation ID ke default meta
    const logger = req.res?.locals?.logger;
    if (logger) {
      logger.defaultMeta = { ...logger.defaultMeta, correlationId };
    }

    next();
  }
}
```

**Aplikasikan middleware di AppModule:**

```typescript
import { Module, NestModule, MiddlewareConsumer } from '@nestjs/common';
import { CorrelationIdMiddleware } from './common/middleware/correlation-id.middleware';

export class AppModule implements NestModule {
  configure(consumer: MiddlewareConsumer) {
    consumer.apply(CorrelationIdMiddleware).forRoutes('*');
  }
}
```

**Menggunakan Correlation ID di service:**

```typescript
import { Injectable, Logger } from '@nestjs/common';
import { ClsService } from 'nestjs-cls';

@Injectable()
export class BookService {
  private readonly logger = new Logger(BookService.name);

  constructor(private readonly cls: ClsService) {}

  async getBookById(id: string) {
    const correlationId = this.cls.get('correlationId');
    this.logger.log({
      message: `Mengambil buku dengan ID: ${id}`,
      correlationId,
    });

    const book = await this.prisma.book.findUnique({ where: { id } });

    // Correlation ID juga bisa disimpan di database untuk audit trail
    await this.auditLog.create({
      data: {
        action: 'GET_BOOK',
        bookId: id,
        correlationId,
        userId: this.cls.get('userId'),
      },
    });

    return book;
  }
}
```

**Custom Logger dengan Correlation ID otomatis:**

```typescript
import { Injectable, LoggerService } from '@nestjs/common';
import { ClsService } from 'nestjs-cls';
import * as winston from 'winston';

@Injectable()
export class CorrelationLogger implements LoggerService {
  constructor(
    private readonly cls: ClsService,
    private readonly logger: winston.Logger,
  ) {}

  log(message: any, context?: string) {
    this.logger.info(message, {
      context,
      correlationId: this.cls?.get('correlationId'),
    });
  }

  error(message: any, trace?: string, context?: string) {
    this.logger.error(message, {
      trace,
      context,
      correlationId: this.cls?.get('correlationId'),
    });
  }

  warn(message: any, context?: string) {
    this.logger.warn(message, {
      context,
      correlationId: this.cls?.get('correlationId'),
    });
  }

  debug(message: any, context?: string) {
    this.logger.debug(message, {
      context,
      correlationId: this.cls?.get('correlationId'),
    });
  }

  verbose(message: any, context?: string) {
    this.logger.verbose(message, {
      context,
      correlationId: this.cls?.get('correlationId'),
    });
  }
}
```

## Analogi
Bayangkan setiap pengunjung yang masuk ke perpustakaan diberi **nomor tiket unik** (Correlation ID). Nomor ini dicatat di setiap meja yang dikunjungi: meja peminjaman, meja pengembalian, meja informasi. Jika ada keluhan, petugas cukup mencari nomor tiket tersebut untuk melihat semua aktivitas pengunjung dari awal hingga akhir — kapan masuk, buku apa yang dipinjam, berapa lama, dan masalah apa yang terjadi. Tanpa nomor tiket, petugas harus mencari manual di tumpukan catatan.

## Penggunaan
- **Debugging production** — Cari semua log error dengan Correlation ID tertentu untuk melihat rangkaian kejadian sebelum error
- **Microservice tracing** — Wariskan Correlation ID via header HTTP ke service lain sehingga trace bisa melintasi batas service
- **Audit trail** — Simpan Correlation ID di database untuk melacak perubahan data (siapa, kapan, dari request mana)
- **Customer support** — Minta user menyertakan Correlation ID saat melaporkan bug

## Kesalahan Umum yang Sering Terjadi
1. **Correlation ID tidak diwariskan ke microservice** — Saat NestJS memanggil microservice lain, header `x-correlation-id` tidak dikirim, sehingga trace terputus. Selalu gunakan interceptor untuk otomatis menambahkan header.
2. **Menggunakan Math.random() sebagai ID generator** — Bisa bentrok (collision). Gunakan UUID v4 atau library seperti `nanoid`.
3. **Tidak menyimpan Correlation ID di response header** — Client tidak bisa melaporkan ID saat error. Selalu set header response.
4. **CLS tidak ter-setup dengan benar** — `cls.get('correlationId')` return undefined di beberapa context karena middleware tidak berjalan. Pastikan `ClsModule` di-import dengan `{ global: true }`.
5. **Lupa menambahkan Correlation ID ke log** — Logger tetap tidak menyertakan correlationId meskipun CLS sudah berfungsi.

## Hubungan dengan Materi Sebelumnya
Ini adalah kelanjutan dari file 85 (Winston). Jika Winston adalah buku catatan, maka Correlation ID adalah nomor indeks yang menghubungkan semua catatan yang berkaitan dengan satu kejadian. Di file 87 (Sentry), Correlation ID juga akan disertakan ke error report agar developer bisa mencari log yang berkaitan dengan error tertentu.

## Soal Latihan

**Soal:** Kamu ingin Correlation ID otomatis diwariskan ke semua outgoing HTTP request (misal saat NestJS memanggil external API dengan Axios). Gunakan interceptor atau HTTP interceptor Axios untuk menambahkan header `x-correlation-id` ke setiap request. Tulis kode untuk Axios interceptor yang mengambil Correlation ID dari CLS.

**Jawaban:**

```typescript
import { Injectable } from '@nestjs/common';
import { ClsService } from 'nestjs-cls';
import axios from 'axios';

@Injectable()
export class AxiosCorrelationInterceptor {
  constructor(private readonly cls: ClsService) {
    axios.interceptors.request.use((config) => {
      const correlationId = this.cls.get('correlationId');
      if (correlationId) {
        config.headers['X-Correlation-Id'] = correlationId;
      }
      return config;
    });
  }
}
```
