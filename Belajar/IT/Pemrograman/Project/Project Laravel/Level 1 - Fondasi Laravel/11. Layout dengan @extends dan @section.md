# 11. Layout dengan @extends dan @section

Layout memungkinkan kamu mendefinisikan kerangka halaman sekali saja (navbar, header, footer) lalu memakai ulang di semua halaman lewat `@extends` dan `@section`. Ini menghindari duplikasi HTML yang sulit dirawat, sesuai prinsip DRY (Don't Repeat Yourself).

## 1. Penjelasan Singkat & Konsep Dasar

Di materi Blade Dasar, kamu sudah tahu cara menampilkan data dengan `{{ }}` dan mengontrol logika dengan `@if`/`@foreach`. Masalahnya: jika ada 20 halaman dan semuanya butuh navbar + footer yang sama, kamu harus menyalin HTML itu ke 20 file. Jika navbar berubah, kamu harus edit 20 tempat.

Layout menyelesaikan ini dengan pola **induk-anak (parent-child)**:

```
layouts/app.blade.php  (kerangka: <html>, navbar, @yield('content'), footer)
        ^
        | @extends('layouts.app')
        |
buku/index.blade.php   (child: hanya konten spesifik halaman)
```

Ini menjadi jembatan ke materi berikutnya: Komponen Blade, yang menyederhanakan UI reusable dengan cara yang lebih modern.

## 2. Fungsi & Kegunaan Utama dalam Laravel

- **Satu sumber kebenaran untuk kerangka halaman**: navbar, header, footer, dan aset (CSS/JS) cukup didefinisikan sekali di layout.
- **Konsistensi tampilan**: semua halaman otomatis memakai struktur yang sama tanpa bisa "melenceng".
- **Menghemat waktu & mencegah error**: mengubah logo di navbar = edit 1 file, bukan 20.
- **Fleksibilitas per halaman**: `@yield` menyediakan "lubang" yang bisa diisi berbeda tiap halaman, `@stack` + `@push` memungkinkan halaman menambahkan CSS/JS tambahan di tempat yang tepat.

## 3. Contoh Kode & Implementasi (Real-world Example)

### 3.1 Layout induk

Lokasi standar: `resources/views/layouts/app.blade.php`

```blade
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>@yield('title', 'Perpustakaan Digital')</title>

    {{-- Stack styles: halaman bisa menambahkan CSS via @push --}}
    @stack('styles')
</head>
<body>
    <nav class="navbar">
        <a href="{{ route('beranda') }}">Perpustakaan Digital</a>

        <div>
            {{-- Menu tampil untuk semua pengunjung --}}
            <a href="{{ route('buku.index') }}">Katalog Buku</a>

            {{-- Menu berbeda untuk yang sudah login vs tamu --}}
            @auth
                <a href="{{ route('peminjaman.index') }}">Peminjaman Saya</a>
                <form method="POST" action="{{ route('logout') }}">
                    @csrf
                    <button type="submit">Keluar ({{ auth()->user()->name }})</button>
                </form>
            @endauth

            @guest
                <a href="{{ route('login') }}">Masuk</a>
                <a href="{{ route('register') }}">Daftar</a>
            @endguest
        </div>
    </nav>

    <main class="container">
        {{-- Flash message: session 'sukses' atau 'error' dari controller --}}
        @if (session('sukses'))
            <div class="alert alert-sukses">{{ session('sukses') }}</div>
        @endif

        @if (session('error'))
            <div class="alert alert-error">{{ session('error') }}</div>
        @endif

        {{-- Lubang utama: diisi oleh @section('content') pada child view --}}
        @yield('content')
    </main>

    <footer class="footer">
        <p>&copy; {{ date('Y') }} Perpustakaan Digital</p>
    </footer>

    {{-- Stack scripts: halaman bisa menambahkan JS via @push --}}
    @stack('scripts')
</body>
</html>
```

Flash message dipicu dari controller, misalnya:

Lokasi standar: `app/Http/Controllers/BukuController.php`

```php
public function store(Request $request)
{
    // ... validasi & simpan buku ...

    return redirect()->route('buku.index')
        ->with('sukses', 'Buku berhasil ditambahkan.');
}
```

### 3.2 Child view dengan @extends dan @section

Lokasi standar: `resources/views/buku/index.blade.php`

```blade
{{-- Extend layout induk --}}
@extends('layouts.app')

{{-- Isi judul; pakai sintaks inline (shortcut @section) --}}
@section('title', 'Katalog Buku - Perpustakaan Digital')

{{-- Tambahkan CSS khusus halaman ini ke stack 'styles' --}}
@push('styles')
    <style>.kartu { border: 1px solid #ddd; padding: 1rem; }</style>
@endpush

{{-- Isi konten utama --}}
@section('content')
    <h1>Katalog Buku</h1>

    @forelse ($buku as $item)
        <div class="grid">
            @foreach ($item as $b)
                <div class="kartu">
                    <h2>{{ $b->judul }}</h2>
                    <p>{{ $b->pengarang }}</p>

                    @if ($b->stok > 0)
                        <span class="badge badge-hijau">Stok: {{ $b->stok }}</span>
                    @else
                        <span class="badge badge-merah">Stok habis</span>
                    @endif

                    <a href="{{ route('buku.show', $b) }}">Lihat Detail</a>
                </div>
            @endforeach
        </div>
    @empty
        <p>Belum ada buku di katalog.</p>
    @endforelse
@endsection

{{-- Tambahkan JS khusus halaman ini ke stack 'scripts' --}}
@push('scripts')
    <script>console.log('Halaman katalog dimuat');</script>
@endpush
```

Catatan: `@section('title', '...')` dengan sintaks satu baris adalah shortcut untuk `@section('title')...@endsection`. Untuk konten panjang selalu gunakan bentuk blok.

## 4. Analogi Sederhana

**Blade/View = Penyajian makanan di piring.**

Layout induk itu seperti **tata meja restoran** yang tetap: taplak meja, serbet, gelas, dan tata lampu selalu dipasang sama untuk setiap pelanggan, diatur sekali oleh restoran. Route = pelayan, controller = koki, data = bahan dari gudang/model.

`@yield('content')` adalah **area tengah piring** yang diisi menu berbeda tiap pesanan — steak untuk satu pelanggan, nasi goreng untuk pelanggan lain — tapi di atas tata meja yang sama. `@yield('title')` dengan default adalah label meja: "Nomor 1" jika pelanggan tidak menyebut nama.

`@stack` + `@push` ibarat **permintaan tambahan pelanggan** ("tolong saus sambal", "minta sumpit") yang dikumpulkan dan diantarkan ke dapur di waktu yang tepat, tanpa mengubah tata meja standar. `@auth`/`@guest` di navbar seperti **kartu VIP**: pelanggan yang sudah terdaftar mendapat menu tambahan, yang belum hanya melihat menu umum.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

- **Selalu gunakan layout untuk halaman aplikasi** yang berbagi navbar + footer, misalnya semua halaman di Perpustakaan Digital: beranda, katalog, detail buku, riwayat peminjaman.
- **Gunakan beberapa layout bila ada zona berbeda**: misalnya `layouts/app.blade.php` untuk user biasa dan `layouts/admin.blade.php` untuk dashboard admin dengan sidebar tambahan.
- **Gunakan `@yield('title', default)`** untuk memberi judul halaman yang seragam; halaman bisa menimpanya.
- **Gunakan `@push('scripts')`** bila hanya satu halaman yang butuh JavaScript tertentu (misal script pemindai ISBN di halaman tambah buku), supaya tidak membebani halaman lain.
- **Flash message di layout** agar semua halaman otomatis menampilkan notifikasi sukses/gagal dari controller tanpa menulisnya berulang kali.

## 6. Poin-poin Penting & Best Practices

- **Konvensi penamaan**: layout induk disimpan di `resources/views/layouts/app.blade.php` dan dipanggil dengan `@extends('layouts.app')` — pakai dot (`.`) sebagai pemisah path, bukan garis miring.
- **Satu `@yield` per lubang**: beri nama jelas (`content`, `title`, `sidebar`) agar mudah dimengerti.
- **`@section('title', '...')` inline** untuk teks pendek; **bentuk blok `@section(...) ... @endsection`** untuk konten yang panjang/multi-baris.
- **`@yield` hanya di layout**, `@section` hanya di child. Jangan tertukar (lihat bagian 7).
- **Default di `@yield`**: `@yield('title', 'Perpustakaan Digital')` berarti jika child tidak mengisi, gunakan nilai default. Ini membuat child view lebih pendek.
- **`@stack` untuk konten yang bisa muncul lebih dari sekali** (banyak `@push` dari banyak child/partial). `@yield` hanya menampilkan satu nilai.
- **Pastikan child mengakhiri `@section`**: `@endsection` atau `@stop`; jangan sampai terbawa ke section berikutnya.
- **Letakkan `@stack('scripts')` di akhir `<body>`** untuk performa, dan `@stack('styles')` di `<head>`.
- **Gunakan `session('sukses')` + `@if`** untuk flash message di layout; controller men-`with()` data saat redirect (lihat contoh `store` di atas).
- **Jangan taruh logika berat di layout**; layout hanya untuk kerangka, data tetap datang dari controller masing-masing child.

## 7. Kesalahan Umum (Common Pitfalls & Anti-patterns)

- **`@yield` dipakai di child view** → child tidak akan mengisi apa pun karena `@yield` adalah "lubang" yang harus ada di layout. Solusi: child memakai `@section`.
- **Lupa `@endsection`** → konten section berikutnya ikut masuk ke section sebelumnya, halaman tampil aneh. Solusi: selalu tutup blok `@section` dengan `@endsection`.
- **Nama section tidak sama** → layout punya `@yield('content')` tapi child menulis `@section('konten')`, maka halaman kosong. Solusi: samakan nama persis.
- **Path layout salah** → error `View [layouts.app] not found`. Solusi: cek file benar di `resources/views/layouts/app.blade.php` dan penulisan dot.
- **Menulis seluruh HTML `<html>` di child** → hasilnya dobel `<html>`/`<body>` karena child tetap memakai layout. Solusi: child cukup `@section('content')` saja.
- **Lupa `@csrf` pada form logout/login** → error `419 Page Expired` ketika klik tombol logout. Solusi: tambahkan `@csrf` di setiap form `POST` (contoh tombol Keluar di layout).
- **`@push` tanpa `@stack` di layout** → CSS/JS yang di-push tidak pernah muncul. Solusi: pastikan layout punya `@stack('styles')`/`@stack('scripts')`.
- **`@section` di layout** → layout tidak punya "lubang", justru mengisi nilai yang tidak berguna. Layout hanya mendefinisikan `@yield`.
- **Cache view di production** → perubahan layout tidak muncul. Solusi: jalankan `php artisan view:clear` lalu `php artisan view:cache` setelah deploy.
- **Menggunakan `@extends` ganda** → satu child hanya boleh `@extends` satu layout; kalau butuh dua kerangka, buat dua layout terpisah atau komponen.

## 8. Soal Latihan & Kunci Jawaban

### Tantangan

1. **Buat layout halaman detail buku**: Layout `layouts/app.blade.php` (boleh sederhana: navbar dengan judul "Perpustakaan Digital" dan link katalog, `@yield('content')`, `@stack('styles')`/`@stack('scripts')`, footer). Buat child `resources/views/buku/show.blade.php` yang `@extends` layout tersebut, mengisi title "Detail Buku: {judul}" dan menampilkan judul, pengarang, ISBN, harga, stok, serta deskripsi buku. Tampilkan flash message `sukses` di layout.

2. **Halaman beranda dengan judul default**: Layout `layouts/app.blade.php` punya `@yield('title', 'Perpustakaan Digital')`. Buat child `resources/views/beranda.blade.php` yang TIDAK mengisi section title (biarkan default) dan hanya menampilkan sapaan + daftar 3 buku populer (`$bukuPopuler`). Tambahkan CSS khusus halaman beranda via `@push('styles')`.

### Jawaban & Pembahasan

**Jawaban 1** — layout `resources/views/layouts/app.blade.php`:

```blade
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>@yield('title', 'Perpustakaan Digital')</title>
    @stack('styles')
</head>
<body>
    <nav>
        <a href="{{ route('beranda') }}">Perpustakaan Digital</a>
        <a href="{{ route('buku.index') }}">Katalog Buku</a>
    </nav>

    <main>
        @if (session('sukses'))
            <div class="alert alert-sukses">{{ session('sukses') }}</div>
        @endif

        @yield('content')
    </main>

    <footer>@yield('footer', '&copy; Perpustakaan Digital')</footer>
    @stack('scripts')
</body>
</html>
```

Child `resources/views/buku/show.blade.php`:

```blade
@extends('layouts.app')

@section('title', 'Detail Buku: ' . $buku->judul)

@section('content')
    <h1>{{ $buku->judul }}</h1>
    <p><strong>Pengarang:</strong> {{ $buku->pengarang }}</p>
    <p><strong>ISBN:</strong> {{ $buku->isbn }}</p>
    <p><strong>Harga:</strong> Rp {{ number_format($buku->harga, 0, ',', '.') }}</p>
    <p><strong>Stok:</strong> {{ $buku->stok }}</p>
    <p><strong>Deskripsi:</strong> {{ $buku->deskripsi }}</p>

    <a href="{{ route('buku.index') }}">&laquo; Kembali ke Katalog</a>
@endsection
```

Alur: child memanggil `@extends('layouts.app')` sehingga seluruh kerangka dari layout dipakai. `@section('title', ...)` mengisi judul tab browser. `@section('content') ... @endsection` mengisi lubang `@yield('content')` di layout. Flash message `sukses` otomatis tampil di semua halaman karena `session('sukses')` dicek di layout, sekali untuk semua child.

**Jawaban 2** — child `resources/views/beranda.blade.php`:

```blade
@extends('layouts.app')

{{-- Tidak mengisi section title => judul memakai default 'Perpustakaan Digital' --}}

@push('styles')
    <style>.kartu-populer { background: #f7f7f7; padding: 0.75rem; }</style>
@endpush

@section('content')
    <h1>Selamat datang di Perpustakaan Digital</h1>
    <p>Temukan dan pinjam koleksi buku favoritmu.</p>

    <h2>Buku Populer</h2>
    <ul>
        @foreach ($bukuPopuler as $buku)
            <li class="kartu-populer">
                {{ $buku->judul }} - {{ $buku->pengarang }}
            </li>
        @endforeach
    </ul>
@endsection
```

Alur: karena child tidak menulis `@section('title')`, `@yield('title', 'Perpustakaan Digital')` di layout jatuh ke nilai default — ini contoh manfaat default pada `@yield`. `@push('styles')` menambah CSS khusus halaman beranda dan akan dirender di lokasi `@stack('styles')` di dalam `<head>`. `@foreach` menampilkan daftar `$bukuPopuler` yang dikirim controller (misal `Buku::orderByDesc('created_at')->take(3)->get()`), tanpa perlu mengubah layout apa pun.
