# 20. Eloquent CRUD dan Relasi

Materi ini menyatukan semuanya: kamu sudah punya Model yang rapi (18) dan kemampuan membaca data dengan query (19). Sekarang giliran menulis data (Create), mengubah (Update), menghapus (Delete), serta menghubungkan tabel lewat relasi dan eager loading. Ini inti dari sistem manajemen perpustakaan: buku bisa dipinjam anggota, dan setiap peminjaman tercatat rapi.

## 1. Penjelasan Singkat & Konsep Dasar

CRUD (Create, Read, Update, Delete) adalah operasi dasar aplikasi web. Eloquent membuatnya semudah menulis metode: `create`, `update`, `delete`, dan relasi membuat tiga tabel kita (`buku`, `anggota`, `peminjaman`) bisa "berbicara" satu sama lain lewat objek, bukan join manual.

Materi 18 menyiapkan model dengan `$fillable`, casts, dan scope. Materi 19 mengajarkan cara membaca. Materi 20 menambahkan dua hal besar: **operasi tulis yang aman** dan **relasi antar model yang efisien (eager loading)**. Konsep ini langsung dimanfaatkan di Level 5 oleh API Resource lewat `whenLoaded`, jadi pastikan paham dulu dari sini.

## 2. Fungsi & Kegunaan Utama dalam Laravel

- **Operasi tulis yang aman**: `create($request->validated())` hanya mengisi kolom di `$fillable`, jadi request dari user tidak bisa menyuntikkan kolom sensitif (mass assignment protection).
- **Soft delete**: `delete()` tidak menghapus baris, cukup mengisi `deleted_at`. Data bisa dipulihkan (`restore()`) atau dihapus permanen (`forceDelete()`).
- **Relasi ekspresif**: `$peminjaman->buku->judul` membaca judul buku dari sebuah peminjaman tanpa menulis join manual.
- **Eager loading**: `with(['buku', 'anggota'])` menarik relasi sekaligus dalam satu query, menghindari masalah N+1 yang bikin aplikasi lambat.
- **withCount**: `withCount('peminjaman')` memberi atribut `peminjaman_count` untuk menampilkan jumlah pinjaman per buku tanpa query tambahan.

Fungsinya satu: menyimpan dan mengambil data yang berhubungan dengan cara yang bersih, cepat, dan sulit disalahgunakan.

## 3. Contoh Kode & Implementasi (Real-world Example)

Studi kasus: controller CRUD buku plus relasi pada model `Anggota` dan `Peminjaman`, ditutup dengan eager loading.

**Lokasi file:** `app/Models/Anggota.php` (relasi)

```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;

class Anggota extends Model
{
    use HasFactory;

    protected $fillable = [
        'nama_depan',
        'nama_belakang',
        'email',
        'telepon',
        'alamat',
    ];

    /**
     * hasMany: satu anggota bisa meminjam banyak buku.
     * Laravel otomatis mencari foreign key 'anggota_id' di tabel peminjaman.
     */
    public function peminjaman()
    {
        return $this->hasMany(Peminjaman::class);
    }
}
```

**Lokasi file:** `app/Models/Peminjaman.php` (relasi balik)

```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;

class Peminjaman extends Model
{
    use HasFactory;

    protected $fillable = [
        'buku_id', 'anggota_id', 'tanggal_pinjam',
        'batas_kembali', 'tanggal_kembali', 'denda', 'status',
    ];

    /**
     * belongsTo: sebuah peminjaman milik satu buku.
     * Foreign key 'buku_id' otomatis dicari di tabel peminjaman.
     */
    public function buku()
    {
        return $this->belongsTo(Buku::class);
    }

    /**
     * belongsTo: sebuah peminjaman milik satu anggota.
     */
    public function anggota()
    {
        return $this->belongsTo(Anggota::class);
    }
}
```

**Lokasi file:** `app/Http/Controllers/BukuController.php` (CRUD + eager loading)

```php
<?php

namespace App\Http\Controllers;

use App\Models\Buku;
use App\Models\Peminjaman;
use Illuminate\Http\Request;

class BukuController extends Controller
{
    /**
     * CREATE — data sudah divalidasi (materi Level 4).
     * Hanya kolom di $fillable yang tersimpan; kolom lain ditolak otomatis.
     */
    public function store(Request $request)
    {
        $validated = $request->validate([
            'judul' => 'required|string|max:255',
            'isbn'  => 'required|string|unique:buku,isbn',
            'harga' => 'required|numeric|min:0',
            'stok'  => 'required|integer|min:0',
            // kolom lain disesuaikan kebutuhan
        ]);

        $buku = Buku::create($validated);

        return redirect()->route('buku.show', $buku)
            ->with('success', 'Buku berhasil ditambahkan.');
    }

    /**
     * UPDATE — ambil record, ubah properti, simpan.
     * Bisa juga Buku::where('id', $id)->update([...]) untuk bulk.
     */
    public function update(Request $request, int $id)
    {
        $buku = Buku::findOrFail($id);

        $validated = $request->validate([
            'judul' => 'required|string|max:255',
            'harga' => 'required|numeric|min:0',
            'stok'  => 'required|integer|min:0',
        ]);

        $buku->update($validated);

        return redirect()->route('buku.show', $buku)
            ->with('success', 'Buku berhasil diperbarui.');
    }

    /**
     * DELETE (soft delete) — baris tetap ada, hanya deleted_at terisi.
     * restore() / forceDelete() untuk mengelola data yang diarsipkan.
     */
    public function destroy(int $id)
    {
        $buku = Buku::findOrFail($id);
        $buku->delete();               // soft delete
        // $buku->forceDelete();       // hapus permanen
        // $buku->restore();           // kembalikan data yang di-soft delete

        return redirect()->route('buku.index')
            ->with('success', 'Buku diarsipkan.');
    }

    /**
     * Contoh pemakaian: denganTrashed, restore, forceDelete.
     */
    public function archive()
    {
        // Sertakan buku yang sudah di-soft delete
        $buku = Buku::withTrashed()->paginate(12);

        return view('buku.archive', compact('buku'));
    }

    /**
     * EAGER LOADING — tarik relasi sekaligus, hindari N+1.
     * with('buku:id,judul,pengarang') hanya memuat kolom yang dibutuhkan.
     * withCount menambah atribut $peminjaman->count / $buku->peminjaman_count.
     */
    public function laporanPeminjaman()
    {
        $peminjaman = Peminjaman::with(['buku:id,judul,pengarang', 'anggota:id,nama_depan,nama_belakang'])
            ->latest()
            ->paginate(20);

        $bukuPopuler = Buku::withCount('peminjaman')
            ->orderByDesc('peminjaman_count')
            ->limit(5)
            ->get();

        return view('peminjaman.laporan', compact('peminjaman', 'bukuPopuler'));
    }
}
```

## 4. Analogi Sederhana

Kembali ke restoran:

- **Controller (koki)** memesan ke gudang. `create()` = "terima stok bahan baru", `update()` = "ubah jumlah terigu", `delete()` = "tandai terigu kadaluarsa, jangan tampilkan di daftar bahan" (soft delete — barangnya masih ada di rak, hanya diberi label).
- **Model (staf gudang)** memastikan pesanan hanya mengubah kolom yang memang boleh diubah (`$fillable`), seperti staf yang menolak permintaan "ubah harga beli" dari nota yang salah.
- **Relasi** = staf yang tahu bahwa "resep ini butuh terigu, dan terigu ini dipakai di banyak resep". `$peminjaman->buku` ibarat bertanya "resep ini pakai bahan apa?" dan langsung dijawab tanpa harus bolak-balik ke gudang setiap bahan.

**Sebelum Eloquent**: koki mencatat hubungan bahan-resep manual di buku tulis (join manual, rawan salah dan lambat). **Setelah Eloquent**: staf gudang (Eloquent) yang mengurus hubungan itu; koki cukup meminta "tampilkan semua peminjaman beserta nama bukunya" (`with('buku')`), dan semuanya diambil dalam satu perjalanan efisien ke gudang.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

- **Tambah buku baru** -> `Buku::create($request->validated())`.
- **Ubah stok / harga** -> `$buku->update([...])`.
- **Arsipkan buku yang tidak layak** -> `$buku->delete()` (soft delete), tampilkan lewat `withTrashed()`, pulihkan dengan `restore()`.
- **Catat peminjaman** -> `Peminjaman::create(['buku_id' => ..., 'anggota_id' => ..., ...])`.
- **Daftar peminjaman dengan nama buku & anggota** -> `Peminjaman::with(['buku', 'anggota'])->get()` (eager loading).
- **Buku paling sering dipinjam** -> `Buku::withCount('peminjaman')->orderByDesc('peminjaman_count')->get()`.
- **Riwayat pinjam per anggota** -> `$anggota->peminjaman()->with('buku')->get()`.

## 6. Poin-poin Penting & Best Practices

- **`$fillable` membatasi mass assignment**: `create()`/`update()` dengan array hanya mengisi kolom terdaftar. Tetap wajibkan validasi di controller.
- **Eager loading dengan `with()`** untuk daftar yang menampilkan relasi. Pilih kolom secukupnya: `with('buku:id,judul,pengarang')`.
- **`withCount('peminjaman')`** untuk jumlah relasi tanpa memuat data relasinya.
- **Hati-hati lazy loading**: akses `$buku->peminjaman` di dalam loop akan menjalankan query per iterasi (N+1). Selalu `with()` di query utama.
- **Naming convention**: relasi `hasMany(Peminjaman::class)` mencari `peminjaman.buku_id`; `belongsTo(Buku::class)` mencari `peminjaman.buku_id`. Ikuti aturan `nama_model_id` untuk zero-config.
- **`update()` vs mass assignment**: `$model->update($data)` mengembalikan boolean; `$model->fill($data)->save()` juga umum. Untuk update kolom, gunakan array sesuai `$fillable`.
- **Hapus pakai soft delete bila data punya riwayat** (peminjaman). Gunakan `forceDelete()` hanya untuk data yang memang harus hilang permanen.
- **`$request->validated()`** memastikan data sudah lolos validasi sebelum masuk model (detail di Level 4).

## 7. Kesalahan Umum (Common Pitfalls & Anti-patterns)

- **Mass Assignment Exception**: `Buku::create($request->all())` tanpa `$fillable` -> Laravel menolak. Perbaiki dengan mengisi `$fillable` dan validasi.
- **N+1 query problem**: mengakses `$peminjaman->buku` di dalam `foreach` menjalankan 1 query untuk setiap peminjaman. Contoh: 100 peminjaman = 1 + 100 query. Solusi: `Peminjaman::with('buku')->get()`.
- **Lupa `->get()` / `->first()`**: code berikutnya menerima Builder, bukan collection -> error atau hasil kosong.
- **Kolom tidak ada**: relasi atau query menyebut kolom yang tidak terdaftar di migration (typo seperti `tgl_pinjam` vs `tanggal_pinjam`). Cek migration.
- **Relasi salah nama**: `hasMany(Peminjaman::class)` mencari `peminjaman.buku_id`; kalau foreign key asli beda, relasi gagal. Tambahkan parameter kedua: `hasMany(Peminjaman::class, 'kode_buku')`.
- **Calling `all()` di production**: untuk relasi besar, gunakan `with()` + `paginate()`/`limit()`.
- **Null pointer saat akses relasi yang belum di-load**: `$peminjaman->anggota->nama` error bila relasi kosong. Gunakan `optional($peminjaman->anggota)->nama` atau pastikan `with()` dimuat.
- **Soft delete tapi data hilang dari laporan**: laporan yang memakai query normal tidak menampilkan data soft deleted; gunakan `withTrashed()` bila perlu.

### Troubleshooting cepat

- Relasi null -> cek foreign key dan pastikan data relasi benar-benar ada.
- Lambat saat menampilkan daftar -> cek N+1, tambahkan `with()`.
- Data tidak tersimpan padahal valid -> cek `$fillable` dan validasi.
- `withCount` tidak muncul -> atributnya `peminjaman_count`, bukan `peminjaman`.

### Jawaban & Pembahasan

**Jawaban 1**

```php
public function store(Request $request)
{
    $validated = $request->validate([
        'buku_id'   => 'required|exists:buku,id',
        'anggota_id' => 'required|exists:anggota,id',
    ]);

    $buku = Buku::findOrFail($validated['buku_id']);

    if (! $buku->tersedia()) {
        return back()->withErrors(['buku_id' => 'Stok buku habis.']);
    }

    $peminjaman = Peminjaman::create([
        'buku_id'       => $buku->id,
        'anggota_id'    => $validated['anggota_id'],
        'tanggal_pinjam' => now(),
        'batas_kembali' => now()->addDays(14),
        'status'        => 'dipinjam',
    ]);

    // kurangi stok setelah peminjaman tercatat
    $buku->decrement('stok');

    return redirect()->route('peminjaman.index')
        ->with('success', 'Peminjaman berhasil dicatat.');
}
```

Alur: validasi memastikan id valid (`exists`), `tersedia()` dari materi 18 mengecek stok, lalu `Peminjaman::create` menyimpan data dengan `$fillable`. Setelah berhasil, stok dikurangi memakai `decrement()`. Semua operasi tulis dibatasi `$fillable`, sehingga tidak ada kolom tak terduga yang ikut tersimpan.

**Jawaban 2**

```php
$anggota = Anggota::withCount('peminjaman')
    ->orderByDesc('peminjaman_count')
    ->limit(10)
    ->get();
```

Alur: `withCount('peminjaman')` menambahkan kolom agregat `peminjaman_count` (hasil `COUNT` dari tabel `peminjaman` per anggota) dalam satu query. `orderByDesc('peminjaman_count')` mengurutkan dari yang terbanyak, `limit(10)` membatasi hasil, dan `get()` mengeksekusi query. Di view tinggal menampilkan `$anggota->peminjaman_count` untuk tiap anggota.
