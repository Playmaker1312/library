# 12. Warna dan Background

Materi ini membahas cara memberi warna dan latar belakang pada elemen — dari warna solid, gradient, sampai gambar latar lengkap dengan overlay. Di sinilah halaman perpustakaanmu mulai "hidup" dari dokumen hitam putih menjadi halaman dengan identitas visual.

## 1. Penjelasan Singkat & Konsep Dasar

Di materi 10-11 kamu sudah belajar memilih elemen (selector) dan bagaimana aturan CSS diputuskan (cascade, specificity). Warna dan background adalah "isi" dari aturan itu — properti yang mengubah wajah elemen yang sudah kamu pilih. Mari kita ingat: CSS pertama-tama butuh selector untuk menahan target, barulah kita tulis declaration berupa `property: value`. Materi ini membekali properti `color`, `background-color`, `background-image`, dan turunannya.

Konsep inti pertama adalah **CSS Custom Properties (variabel CSS)**, ditulis dengan dua tanda strip di dalam `:root`. Contoh: `--warna-utama: #2563eb;` lalu dipakai dengan `var(--warna-utama)`. Variabel ini bukan sekadar pemanis — ia adalah **satu sumber kebenaran** untuk nilai yang dipakai berulang. Ubah satu baris di `:root`, seluruh situs berubah. Ini adalah kebiasaan profesional yang sebaiknya dipakai sejak file CSS pertama.

Konsep kedua adalah **format warna**. Ada beberapa cara menulis warna di CSS: *named color* (`red`, `cornflowerblue`), *hex* (`#2563eb`, atau `#369` yang sama dengan `#336699`), *rgb/rgba* (`rgb(37, 99, 235)` dan `rgba(37, 99, 235, 0.5)`), serta *hsl/hsla* (`hsl(220, 91%, 54%)`). Perbedaan kunci: `rgba` dan `hsla` membawa **alpha channel** — angka transparansi antara 0 (tidak terlihat) dan 1 (solid penuh). Inilah alasan kenapa format tersebut ada: saat kamu butuh *opacity* pada sebuah warna tanpa memengaruhi elemen lain.

Konsep ketiga adalah **background**. Browser memiliki beberapa properti: `background-color` untuk warna solid, `background-image` untuk gradient (`linear-gradient` dan `radial-gradient`) atau gambar (`url(...)`), plus turunan posisi seperti `background-size`, `background-position`, `background-repeat`, dan `background-attachment`. Semua bisa digabung — bahkan beberapa lapis background dalam satu deklarasi, yang menjadi teknik dasar membuat overlay.

**Benang merah**: materi ini menyambungkan selector (materi 10) dan cascade (materi 11) ke tampilan nyata, sekaligus menjadi prasyarat Level 3 (layout). Saat kamu sudah menata flexbox dan grid nanti, warna dan background inilah yang membuat layout itu terlihat bermakna — bukan kumpulan kotak kosong.

## 2. Fungsi & Kegunaan Utama dalam Web

Dua masalah besar yang diselesaikan bagian ini: **brand konsisten** dan **teks terbaca di atas gambar**.

**Brand konsisten.** Perpustakaan Digital Kota punya identitas: biru untuk aksi utama, hijau untuk status sukses, merah untuk peringatan. Tanpa variabel CSS, kamu akan menyalin hex yang sama ke puluhan tempat, lalu panik saat pimpinan minta warna sedikit lebih biru. Dengan `--warna-utama: #2563eb` di satu tempat, perubahan dilakukan sekali dan seluruh halaman (hero, tombol, kartu buku, katalog, form) ikut menyesuaikan. Inilah definisi konsistensi brand yang terkelola.

**Teks di atas gambar.** Hero section berdiri di atas foto gedung perpustakaan. Gambar sebagus apa pun sering membuat judul sulit dibaca — kontras antara teks dan gambar tidak terkontrol. Solusi standar di industri: lapisi gambar dengan gradient overlay gelap (`linear-gradient(rgba(0,0,0,0.5), rgba(0,0,0,0.5))`). Di sinilah `rgba` berperan penting: kamu butuh warna gelap *dengan transparansi*, bukan warna gelap solid yang menghapus detail gambar sepenuhnya.

**Parallax.** Properti `background-attachment: fixed` membuat gambar latar "menempel" saat halaman di-scroll, memberi kesan kedalaman yang sering dipakai di hero dan seksi pembuka. Efeknya murah secara kode tapi terasa premium.

## 3. Contoh Kode & Implementasi Real-World

```css
/* css/style.css */

/* ── 1. CSS Custom Properties: satu sumber kebenaran warna ──────────── */
:root {
    /* Warna brand */
    --warna-utama:    #2563eb;   /* biru — aksi utama, link */
    --warna-sekunder: #059669;   /* hijau — status sukses */
    --warna-aksen:    #dc2626;   /* merah — peringatan, denda */

    /* Warna teks */
    --teks-utama:     #1e293b;   /* hampir hitam — nyaman dibaca */
    --teks-sekunder:  #64748b;   /* abu-abu — teks pendukung */
    --teks-terbalik:  #ffffff;   /* teks di atas background gelap */

    /* Warna background */
    --bg-utama:       #ffffff;
    --bg-sekunder:    #f8fafc;   /* abu sangat muda untuk kartu/panel */
    --bg-gelap:       #1e293b;   /* footer, hero gelap */
}

/* ── 2. Pemakaian variabel ──────────────────────────────────────────── */
.btn-utama {
    background-color: var(--warna-utama);
    color: var(--teks-terbalik);
}

/* ── 3. Format warna: kapan pakai yang mana ─────────────────────────── */
/* Warna normal: hex adalah default yang paling umum dan ringkas */
.snapshot { color: #16a34a; }

/* rgba/hsla: hanya saat BUTUH transparansi — overlay, bayangan, hover */
.link-hover { background-color: rgba(37, 99, 235, 0.1); }
.shadow     { box-shadow: 0 10px 25px rgba(0, 0, 0, 0.15); }

/* hsl kadang lebih mudah "dibaca" secara nalar: 220 derajat = biru */
.warna-hsl  { color: hsl(220, 91%, 54%); }

/* ── 4. Gradient ────────────────────────────────────────────────────── */
.hero-section {
    /* Ganti hsl/hex jadi variabel bila dimuat ke :root */
    background-image: linear-gradient(
        135deg,                    /* arah: dari kiri-atas ke kanan-bawah */
        #2563eb 0%,
        #059669 100%
    );
}

.badge {
    /* radial: memudar dari tengah ke pinggir, cocok untuk aksen */
    background-image: radial-gradient(circle at center, #2563eb 0%, #1e293b 100%);
}

/* ── 5. Gambar background: cover + position + repeat ────────────────── */
.seksi-visual {
    background-image: url('../images/ruang-baca.jpg');
    background-size: cover;       /* gambar mengisi seluruh area tanpa distorsi */
    background-position: center;  /* kalau gambar lebih besar, titik tengahnya yang dijadikan patokan */
    background-repeat: no-repeat; /* jangan di-tile berulang */
}

/* ── 6. Parallax: gambar tetap diam saat halaman di-scroll ───────────── */
.seksi-parallax {
    background-image: url('../images/gedung-perpustakaan.jpg');
    background-size: cover;
    background-position: center;
    background-attachment: fixed; /* efek parallax — gambar "menempel" di viewport */
}

/* ── 7. Overlay gelap: teks jadi terbaca di atas gambar ──────────────── */
/* Tekniknya: tumpuk DUA background dalam satu deklarasi —
   yang pertama (gelap) di atas gambar, yang kedua gambar di bawahnya. */
.hero-dengan-gambar {
    background-image:
        linear-gradient(rgba(0, 0, 0, 0.5), rgba(0, 0, 0, 0.5)),
        url('../images/gedung-perpustakaan.jpg');
    background-size: cover;
    background-position: center;
    color: var(--teks-terbalik);
}
```

## 4. Analogi Sederhana — Membangun Rumah

Dalam analogi rumah kita: **HTML adalah kerangka dan ruang-ruang**, **CSS adalah cat, interior, dan dekorasi**, **JS adalah listrik**. Materi ini adalah kegiatan **memilih cat dinding, wallpaper, dan lantai**.

- **Warna solid di dinding utama** (`background-color`) adalah cat tembok standar — satu warna penuh untuk satu ruangan. Variabel warna di `:root` adalah **stok cat yang dibeli dalam drum besar**: semua ruangan memakai warna yang sama dari drum yang sama. Kalau kamu butuh nuansa baru, kamu "membeli satu drum warna baru" dan semua ruangan diganti sekaligus — tanpa harus mengecat ulang satu per satu.
- **Gradient** adalah **cat yang memudar dari satu warna ke warna lain** — dinding ombre. Berbeda dari cat polos, gradient mengubah suasana ruangan secara halus, karenanya dipakai di tempat yang ingin terasa istimewa (dinding hero, bukan seluruh rumah).
- **Overlay gelap** adalah **kaca film gelap di jendela**: kamu tetap bisa melihat pemandangan di baliknya, tapi sedikit redup agar lampu baca (teks) tampak terang dan jelas.
- **Gambar background dengan cover** adalah **memasang wallpaper**: dipotong agar pas menutupi seluruh dinding. `background-repeat` mirip aturan "jangan pasang wallpaper miring berulang-ulang sampai lisannya berantakan".
- **Parallax** adalah **jendela dengan pemandangan tetap**: kamu menggerakkan tubuh (scroll), tapi pemandangan di luar jendela seakan diam — memberi ilusi kedalaman di ruangan sempit.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

- **Hero section perpustakaan**: gradient biru→hijau dengan overlay gelap di atas foto gedung, plus judul besar teks putih. Membuat kesan pertama yang kuat dan teks tetap terbaca.
- **Kartu buku dan kartu statistik**: `--bg-utama` putih dengan bayangan halus di atas `--bg-sekunder`, sehingga kartu "mengambang" dari latar. Warna kategori buku memakai `--warna-aksen` yang tipis (opacity rendah via rgba).
- **Status pinjaman di katalog**: hijau untuk "tersedia", merah untuk "dipinjam", abu-abu untuk "diproses" — konsisten berkat variabel warna.
- **Footer dan seksi gelap**: `--bg-gelap` sebagai dasar, teks terang, untuk mengakhiri halaman dengan kesan tenang.
- **Tombol aksi (form peminjaman, daftar anggota)**: `--warna-utama` sebagai background tombol, dengan hover yang menggelapkan warnanya sedikit — sinyal visual bahwa elemen itu interaktif.

## 6. Poin-poin Penting & Best Practices

- **Definisikan CSS Custom Properties sejak awal** dan pakai `var()` di mana-mana. Jangan pernah menaruh angka hex langsung di tengah selector kalau bisa lewat variabel.
- **Hanya pakai `rgba`/`hsla` saat butuh transparansi.** Untuk warna solid, `#2563eb` lebih ringkas dan jelas dari `rgba(37,99,235,1)`.
- **Satu sumber kebenaran warna**: beri nama variabel berdasarkan peran (misal `--warna-utama`, `--teks-sekunder`) bukan nama warna (`--biru`). Kalau brand berganti ke warna ungu, variabel `--warna-utama` tetap valid.
- **Gradient: batasi jumlah warna dan jaga kontras.** Dua-tiga stop warna yang senada terasa profesional; tujuh warna pelangi membuat halaman terlihat mainan.
- **Cover untuk gambar background** agar tidak miring/menjadi tile; selalu atur `background-position: center` bila tidak yakin.
- **Selalu pasang overlay gelap** saat menaruh teks di atas gambar yang menarik — jangan mengandalkan keberuntungan kontras.
- Hati-hati: **parallax (`background-attachment: fixed`) bermasalah di iOS/seluler**; pertimbangkan menonaktifkannya dengan `@media` untuk perangkat kecil.

## 7. Kesalahan Umum (Common Pitfalls & Bugs)

- **Warna di-hardcode di banyak tempat.** Ganti satu tombol dengan `#2b6eb5` dan situs jadi tidak konsisten. Perbaikan: semua warna lewat variabel di `:root`, ganti nilai di satu tempat.
- **Lupa `background-repeat: no-repeat`, gambar men-tile** memenuhi hero. Perbaikan: set `background-size: cover; background-repeat: no-repeat;`.
- **Teks tidak terbaca di atas gambar cerah** karena tidak ada overlay. Perbaikan: lapisi dengan `linear-gradient(rgba(0,0,0,0.5), rgba(0,0,0,0.5))` di depan `url(...)`, atau percaya `rgba` sepenuhnya untuk transparansi.
- **Gradient dianggap satu properti warna**: ingat properti gradient bernama `background-image`, bukan `background-color`. Menaruh `linear-gradient(...)` di `background-color` membuat browser mengabaikan deklarasi itu.
