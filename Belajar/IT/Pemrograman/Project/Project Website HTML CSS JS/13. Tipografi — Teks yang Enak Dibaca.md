# 13. Tipografi — Teks yang Enak Dibaca

Sebagian besar halaman web adalah teks — judul buku, deskripsi, kategori, jam operasional. Materi ini membahas font family, skala ukuran, jarak antar baris, dan lebar paragraf yang membuat teks nyaman dibaca dalam waktu lama. Ini membedakan website yang "jadi" dari yang "berantakan".

## 1. Penjelasan Singkat & Konsep Dasar

Dari materi 12 kamu sudah mempelajari cara membungkus tampilan lewat variabel warna. Tipografi menambahkan lapisan kedua: jenis huruf (`font-family`), ukuran (`font-size`), ketebalan (`font-weight`), jarak antar baris (`line-height`), dan jarak antar huruf (`letter-spacing`). Seperti warna, semuanya sebaiknya didefinisikan sebagai CSS Custom Properties agar satu perubahan mengubah seluruh situs.

Konsep inti pertama adalah **kategori font family**. Ada tiga golongan besar: **sans-serif** (tanpa kaki, modern, bersih — untuk teks utama web), **serif** (berkaki, klasik, terasa "buku" — cocok untuk judul nuansa editorial), dan **monospace** (huruf selebar sama, untuk kode). Browser menjamin ketiganya tersedia, tapi kamu bisa **mengimpor Google Fonts** agar punya pilihan lebih baik tanpa menyimpan file font sendiri.

Konsep kedua adalah **skala ukuran berbasis `rem` dengan base 16px**. Satu `rem` = ukuran font elemen `html`, yang default browser-nya **16px**. Jadi `1rem = 16px`, `0.875rem = 14px`, `2rem = 32px`. Kenapa pakai `rem` dan bukan `px`? Karena `px` itu **ukuran tetap** — apa pun yang terjadi, 16px ya 16px. Sedangkan `rem` itu **relatif terhadap setting user**: pengguna yang mengatur ukuran font di OS/browser-nya lebih besar akan mendapatkan teks yang ikut membesar. Ini dasar aksesibilitas. (Note: `em` juga relatif, tapi relatif terhadap *parent* — mudah menumpuk dan sulit diprediksi; `rem` selalu konsisten.)

Konsep ketiga adalah **keterbacaan**: `line-height` (jarak antar baris — 1.5 untuk body, 1.25 untuk judul), `max-width: 65ch` untuk paragraf (kira-kira 60-75 karakter per baris menurut standar terbitan), dan **kontras warna** antara teks dan background (dibahas WCAG di bagian 6). Teks boleh terlihat keren, yang tidak boleh adalah teks yang sulit dibaca.

Terakhir, **interaksi link**. Link bukan sekadar dekorasi: pengguna harus tahu itu dapat diklik. `hover` membalasi aksi ketika kursor di atasnya, dan `:focus-visible` memberi outline ketika navigasi keyboard melewatinya — ini wajib untuk aksesibilitas dan sering dilupakan pemula.

**Benang merah**: materi 12 memberi warna, materi ini melengkapi karakter bacaan. Keduanya dipakai bersamaan di Level 2, dan menjadi fondasi untuk materi 14 (box model) di mana ukuran-ukuran teks akan memengaruhi ruang yang dibutuhkan elemen. Di Level 3, skala rem yang konsisten membuat media query dan layout responsif jauh lebih mudah dikelola.

## 2. Fungsi & Kegunaan Utama dalam Web

Tipografi menyelesaikan masalah **keterbacaan** dan **hierarki informasi** — dua hal yang menentukan apakah pengunjung betah membaca katalog perpustakaan digital.

**Hierarki.** Pengunjung memindai halaman dengan cepat. Judul buku harus jelas lebih besar dari nama penulis; nama penulis lebih jelas dari kategori. Tanpa hierarki yang tegas, semua teks tampak sama penting dan otak pengunjung lelah. Skala `rem` yang konsisten (misal `h1`=2.25rem, `h2`=1.875rem, body=1rem) membuat perbedaan itu terbaca secara naluriah.

**Keterbacaan.** Paragraf lebih dari 65 karakter mulai membuat mata melompat ke baris berikutnya di tempat yang salah. `line-height` 1.5 memberi ruang napas antar baris agar mata mudah mengikuti. Ini krusial untuk deskripsi buku yang panjang dan berita perpustakaan.

**Kontras.** Teks abu tipis di atas putih terlihat modern tapi sulit dibaca — apalagi bagi pengguna lanjut usia yang mayoritas pengunjung perpustakaan. Mengikuti WCAG (rasio kontras minimal 4.5:1 untuk teks normal) membuat situs nyaman *dan* tidak eksklusif.

**Konsistensi brand.** Via variabel `--font-sans`, `--teks-base`, dsb di `:root`, seluruh halaman (hero, kartu buku, form, footer) memakai bahasa tipografi yang sama. Tidak ada judul yang tiba-tiba gegar sendiri font-nya.

## 3. Contoh Kode & Implementasi Real-World

```css
/* css/style.css */

/* Import Google Fonts — taruh paling atas, sebelum penggunaan font */
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=Merriweather:ital,wght@0,400;0,700;1,400&display=swap');

:root {
    /* Font family: nama font + cadangan + kategori dasar */
    --font-sans:  'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
    --font-serif: 'Merriweather', Georgia, serif;
    --font-mono:  'Courier New', Courier, monospace;

    /* Skala ukuran berbasis rem — 1rem = 16px (default browser) */
    --teks-xs:   0.75rem;   /* 12px — caption, label kecil */
    --teks-sm:   0.875rem;  /* 14px — meta info, kategori */
    --teks-base: 1rem;      /* 16px — teks utama */
    --teks-lg:   1.125rem;  /* 18px —  sedikit lebih menonjol */
    --teks-xl:   1.25rem;   /* 20px — nama penulis yang perlu menonjol */
    --teks-2xl:  1.5rem;    /* 24px — judul kartu buku */
    --teks-3xl:  1.875rem;  /* 30px — judul section */
    --teks-4xl:  2.25rem;   /* 36px — judul hero */

    /* Line height */
    --leading-tight:  1.25;  /* judul — rapat boleh, masih terbaca */
    --leading-normal: 1.5;   /* body — ruang napas standar */
    --leading-loose:  1.75;  /* teks panjang / kutipan */
}

html {
    font-size: 16px;             /* base — 1rem = 16px */
    scroll-behavior: smooth;     /* scroll halus saat klik anchor */
}

body {
    font-family: var(--font-sans);
    font-size: var(--teks-base);
    line-height: var(--leading-normal);
    color: var(--teks-utama);
    background-color: var(--bg-utama);
}

/* Heading: judul pakai sans (bersih) + line-height rapat */
h1, h2, h3, h4, h5, h6 {
    font-family: var(--font-sans);
    font-weight: 700;
    line-height: var(--leading-tight);
    color: var(--teks-utama);
    margin-bottom: 0.75rem;
}

h1 { font-size: var(--teks-4xl); }
h2 { font-size: var(--teks-3xl); }
h3 { font-size: var(--teks-2xl); }
h4 { font-size: var(--teks-xl); }
h5 { font-size: var(--teks-lg); }
h6 { font-size: var(--teks-base); }

/* Paragraf: lebar ideal 60-65 karakter per baris */
p {
    margin-bottom: 1rem;
    max-width: 65ch;
}

/* Link: jelas dapat diklik, jelas indikator fokus keyboard */
a {
    color: var(--warna-utama);
    text-decoration: none;
    transition: color 0.2s ease;
}
a:hover {
    color: #1d4ed8;
    text-decoration: underline;
}
a:focus-visible {
    outline: 2px solid var(--warna-utama);
    outline-offset: 2px;
    border-radius: 2px;
}

/* Utilitas teks: dipakai di halaman tanpa menulis ulang sifat */
.teks-sm     { font-size: var(--teks-sm); }
.teks-lg     { font-size: var(--teks-lg); }
.teks-bold   { font-weight: 700; }
.teks-muted  { color: var(--teks-sekunder); }
.teks-center { text-align: center; }
.teks-upper  { text-transform: uppercase; letter-spacing: 0.05em; }
```

```html
<!-- index.html — potongan HTML agar hasilnya terlihat nyata -->
<section class="hero">
```

## 4. Analogi Sederhana — Membangun Rumah

Setelah dinding dicat (materi 12), sekarang waktunya **memilih font dan interior yang ramah baca**: meletakkan lampu, mengatur jarak antar furnitur, dan memilih papan nama.

- **Font family** adalah **pemilihan gaya tulisan**: serif seperti tulisan buku tua di rak perpustakaan, sans-serif seperti papan informasi modern yang bersih di lobi. Keduanya boleh ada — serif untuk judul buku, sans untuk teks antarmuka — asal konsisten.
- **Skala rem** adalah **ukuran standar furnitur**: lemari, meja, dan kursi dibuat dalam skala yang serasi dari satu sumber (16px), bukan asal-asalan per ruangan. Kalau penghuni rumah ingin ukurannya lebih besar (pengaturan font di OS), semua furnitur ikut membesar secara proporsional.
- **Line-height** adalah **jarak rak buku di rak**: kalau terlalu rapat (1.1) buku susah diambil, kalau terlalu longgar (2.5) rak hambar. 1.5 adalah "jarak nyaman".
- **max-width: 65ch** adalah **jarak antar kalimat di buku** — mata tidak boleh bolak-balik terlalu jauh; sebuah blok teks yang terlalu lebar membuat pembaca kehilangan baris.
- **Kontras teks** adalah **pencahayaan ruang baca**: ruangan gelap dengan buku gelap mustahil dibaca. Lampu (warna background) dan tinta (warna teks) harus berbeda cukup agar huruf tampil.
- **Mobile viewport** adalah **ruang sempit**: skala rem dan lebar 65ch yang cermat adalah alasan ruang sempit tetap bisa dibaca — kamu tidak perlu meletakkan sofa raksasa di kamar mandi.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

- **Hero section**: judul besar (`--teks-4xl`) dengan serif opsional untuk sentuhan editorial, brown text di bawahnya (`--teks-lg`), margin sempit. Satu `h1` per halaman, fokus.
- **Kartu buku di katalog**: judul `h3` = `--teks-2xl`, nama penulis `--teks-sm` `teks-muted`, deskripsi `--teks-base` dengan `max-width: 65ch` bila panjang.
- **Form pendaftaran anggota**: label `--teks-sm` teks-sekunder, input `--teks-base`; `:focus-visible` di input dan tombol memberi panduan jelas saat navigasi keyboard.
- **Kutipan dan berita** (blockquote, pengumuman): `--leading-loose` dan font serif untuk nuansa bacaan santai.
- **Statistik di beranda**: angka besar memakai `--teks-2xl` `teks-bold`, keterangan kecil `--teks-sm` muted — hierarki instan tanpa gambar.

## 6. Poin-poin Penting & Best Practices

- **Utamakan `rem` untuk `font-size`, bukan `px` dan bukan `em`.** `px` tetap dan melawan pengaturan pengguna; `em` relatif ke parent dan cepat tidak terkendali; `rem` konsisten dari satu titik (`html`).
- **Set base font-size di `html` (16px)** dan bangun seluruh skala dari sana sebagai variabel (`--teks-base`, `--teks-2xl`, dst).
- **`line-height` relatif** (tanpa satuan: `1.5`, bukan `1.5rem`) — agar selalu proporsional dengan ukuran font.
- **Paragraf ideal 60-75 karakter**: pakai `max-width: 65ch` pada teks panjang.
- **Kontras aksesibel (WCAG AA)**: rasio minimum 4.5:1 untuk teks normal, 3:1 untuk teks besar (18px+ atau 14px+bold). Jangan pakai abu tipis untuk teks penting.
- **Selalu sediakan indikator `:focus-visible`** — jangan `outline: none` tanpa pengganti.
- **Jangan kurangi jumlah font berlebihan**: maksimal 2-3 font family dalam satu situs (misal sans untuk UI, serif untuk judul), dan jaga jumlah *weight* yang dimuat agar halaman tetap cepat.

## 7. Kesalahan Umum (Common Pitfalls & Bugs)

- **Teks kecil dan kontras rendah** — `12px` abu-abu muda di atas putih. Perbaikan: baseline `--teks-base` 16px dan cek kontras; teks penting jangan di bawah 14px.
- **Terlalu banyak font family campur aduk** — tiap heading font beda, situs tampak tidak tenang. Perbaikan: patuhi `--font-sans` dan `--font-serif`, gunakan `--teks-bold` untuk variasi ketebalan bukan ganti font.
- **`max-width` tidak ditetapkan, paragraf selebar layar monitor 27 inci** — mata "kabur" mencari baris berikutnya. Perbaikan: `max-width: 65ch` pada `p`.
- **`line-height` memakai satuan fixed** (`line-height: 20px`) — pecah saat font diperbesar. Perbaikan: angka tanpa satuan (`1.5`).
- **Menghapus outline fokus** (`outline: none`) tanpa pengganti — pengguna keyboard tersesat. Perbaikan: `:focus-visible` dengan outline jelas atau ring visible (misal `box-shadow`).

## 8. Mini Project / Soal Latihan & Kunci Jawaban

### Tantangan

1. **Sistem tipografi pakai CSS variables**: definisikan di `:root` font sans + serif, skala `--teks-base` sampai `--teks-4xl`, dan `--leading-tight/normal/loose`. Terapkan pada `h1`, `h2`, `p`, dan `a` di halaman perpustakaan, lengkap dengan `hover` dan `:focus-visible`.
2. **Kartu buku rapi**: buat kartu yang berisi judul buku (Inter, bold, `--teks-2xl`), nama penulis (muted `--teks-sm`), dan paragraf deskripsi (base, `max-width: 65ch`), dengan heading "Buku Terbaru" di atasnya. Ukur perbedaan hierarkinya di layar.

### Solusi & Pembahasan

```css
/* css/style.css */

@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&family=Merriweather:wght@400;700&display=swap');

:root {
    --font-sans:  'Inter', -apple-system, 'Segoe UI', sans-serif;
    --font-serif: 'Merriweather', Georgia, serif;

    --teks-sm:   0.875rem;
    --teks-base: 1rem;
    --teks-lg:   1.125rem;
    --teks-xl:   1.25rem;
    --teks-2xl:  1.5rem;
    --teks-3xl:  1.875rem;
    --teks-4xl:  2.25rem;

    --leading-tight:  1.25;
    --leading-normal: 1.5;
    --leading-loose:  1.75;

    --teks-utama:    #1e293b;
    --teks-sekunder: #64748b;
    --warna-utama:   #2563eb;
}

html { font-size: 16px; }

body {
    font-family: var(--font-sans);
    font-size: var(--teks-base);
    line-height: var(--leading-normal);
    color: var(--teks-utama);
}

h1, h2, h3 {
    font-weight: 700;
    line-height: var(--leading-tight);
    margin-bottom: 0.75rem;
}

h1 { font-size: var(--teks-4xl); }
h2 { font-size: var(--teks-3xl); }
h3 { font-size: var(--teks-2xl); }

p { max-width: 65ch; margin-bottom: 1rem; }

a {
    color: var(--warna-utama);
    text-decoration: none;
}
a:hover { text-decoration: underline; }
a:focus-visible {
    outline: 2px solid var(--warna-utama);
    outline-offset: 2px;
}

/* Kartu buku dalam HTML:
   <h2>Buku Terbaru</h2>
   <article>
       <h3>Clean Code</h3>
       <p class="meta">Robert C. Martin · Teknologi</p>
       <p>Prinsip menulis kode bersih dan mudah dirawat ...</p>
       <a href="buku/clean-code.html">Lihat Detail</a>
   </article> */

.meta {
    font-size: var(--teks-sm);
    color: var(--teks-sekunder);
}
```

**Pembahasan**: latihan 1 menanamkan kebiasaan gaya *design token* — seluruh keputusan tipografi tinggal di `:root`, halaman tinggal memakai. Latihan 2 menguji hierarki dengan mata: judul `2xl`, meta `sm` muted, dan paragraf base 65ch harus terlihat jelas tingkatan informasi yang sama seperti di situs perpustakaan sungguhan. Coba ganti nilai `--teks-4xl` menjadi `2rem` satu kali — semua `h1` di situs ikut berubah, itulah kekuatan satu sumber kebenaran yang sama dengan materi 12.
