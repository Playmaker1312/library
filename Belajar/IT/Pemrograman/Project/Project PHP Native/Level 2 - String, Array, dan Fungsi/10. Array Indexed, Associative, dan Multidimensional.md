# 10. Array Indexed, Associative, dan Multidimensional

> **Level 2 · String, Array, dan Fungsi** — Dari satu nilai (string/variabel) ke kumpulan nilai (array).

---

## 1. Penjelasan Singkat & Konsep Dasar

**Array** adalah struktur data untuk menyimpan **banyak nilai dalam satu variabel**. Di PHP, array itu serbaguna dan bisa menyimpan tipe campuran.

Tiga bentuk utama:

```php
// 1) Indexed array — index angka otomatis (0, 1, 2, ...)
$kategori = ['Fiksi', 'Non-Fiksi', 'Sains'];

// 2) Associative array — index berupa string (key => value)
$buku = ['judul' => 'Clean Code', 'harga' => 150000, 'stok' => 5];

// 3) Multidimensional — array di dalam array (katalog)
$katalog = [
    ['id' => 1, 'judul' => 'Clean Code'],
    ['id' => 2, 'judul' => 'Cosmos'],
];
```

**Mengapa ini materi kunci?** Hampir semua data aplikasi web adalah kumpulan:

- Daftar buku → array of arrays
- Satu baris hasil query DB → array asosiatif (`SELECT ... FETCH_ASSOC`)
- Input form → `$_POST` (array asosiatif)
- Data JSON → array (via `json_decode`)

**Benang Merah:** string function (materi 9) mengolah *satu* teks; array menampung *banyak* data sekaligus. Dengan array, katalog buku yang tadinya hardcode di beberapa variabel menjadi satu struktur yang bisa di-loop (foreach, materi 8) — dan nanti dikirim ke/dari database (materi 20-21).

---

## 2. Fungsi & Kegunaan Utama

- **Mengelompokkan data menjadi satu unit** — seluruh "buku" dalam satu variabel `$buku` dengan key deskriptif (`judul`, `harga`, `stok`). Lebih rapih daripada `$judul`, `$harga`, `$stok` terpisah.
- **Merepresentasikan "record"** — associative array adalah bentuk paling dekat dengan baris database. Kolom DB = key array. Ini menjadikannya bahasa pemersatu antara PHP dan database.
- **Memungkinkan iterasi & pengolahan massal** — `foreach` + array function (materi 11) = tampilkan semua buku, filter, urutkan.
- **Serializable** — array mudah diubah ke JSON (`json_encode`) untuk API/storage, dan sebaliknya (`json_decode`) — dasar materi 17 (JSON storage) dan 27 (REST API).

## 3. Contoh Kode & Implementasi Real-World

**Membangun katalog buku** (data hardcode — akan jadi dari database di Level 4):

```php
<?php
// File: data/katalog.php
// Struktur ini meniru baris tabel 'buku' di database (materi 20)

$katalog = [
    [
        'id'        => 1,
        'judul'     => 'Clean Code',
        'pengarang' => 'Robert Martin',
        'harga'     => 150000,
        'stok'      => 5,
        'kategori'  => 'Teknologi',
    ],
    [
        'id'        => 2,
        'judul'     => 'Laskar Pelangi',
        'pengarang' => 'Andrea Hirata',
        'harga'     => 95000,
        'stok'      => 3,
        'kategori'  => 'Fiksi',
    ],
];

// Akses
echo $katalog[0]['judul'];    // Clean Code
echo $katalog[1]['harga'];    // 95000

// Operasi pada associative array
$buku = $katalog[0];
echo $buku['judul'];          // Clean Code
$buku['status'] = 'tersedia'; // tambah key baru
$buku['stok']   = 4;          // ubah nilai
unset($buku['status']);       // hapus key

// Cek keberadaan key — bedakan dua cara
$adaIsbn = isset($buku['isbn']);              // false — key TIDAK ada (atau null)
$adaKey  = array_key_exists('isbn', $buku);    // false — apa pun nilainya
?>

<!-- Tampilkan dengan foreach (alternatif syntax) -->
<ul>
    <?php foreach ($katalog as $buku): ?>
        <li>
            <?= htmlspecialchars($buku['judul']) ?> —
            <?= htmlspecialchars($buku['pengarang']) ?> —
            Rp <?= number_format($buku['harga'], 0, ',', '.') ?>
        </li>
    <?php endforeach; ?>
</ul>
```

**Manipulasi array:**

```php
// Menambah & menghapus anggota
$kategori = ['Fiksi', 'Sains'];
$kategori[] = 'Teknologi';     // tambah di akhir
array_push($kategori, 'Sejarah');
array_pop($kategori);          // hapus elemen terakhir
array_shift($kategori);        // hapus elemen pertama

unset($kategori[1]);           // hapus index 1
$kategori = array_values($kategori); // reset index → 0,1,2...
```

> **Poin kritis bereksperimen:** setelah `unset`, index **tidak di-reset otomatis**. Selalu `array_values()` bila kamu butuh urutan index rapi — ini sumber bug yang sering muncul di materi 11.

**PHP 8.2+ contoh tambahan:** named arguments pada fungsi array/method (semua sudah PHP 8): `array_keys($katalog, 'Teknologi', true)` dst.

## 4. Analogi Sederhana

Dalam **Sistem Administrasi Kantor**:

- **Indexed array** = **lemari arsip baku** dengan rak bernomor 0, 1, 2... Kamu mengambil berkas dari rak `[0]`, `[1]`.
- **Associative array** = **berkas berlabel** — bukan rak bernomor, tapi map berjudul `judul`, `harga`, `stok`. Untuk mengambil data, kamu sebutkan *labelnya* (`$buku['harga']`), jauh lebih jelas daripada nomor rak.
- **Multidimensional array** = **lemari berisi map-map** — satu `katalog` yang berisi banyak map buku. Setiap map buku punya label internalnya sendiri.
- **`array_values`** = staf *menulis ulang nomor rak* setelah beberapa berkas dibuang — agar tidak ada nomor kosong yang membingungkan.

---

## 5. Kapan Harus Digunakan & Kasus Penggunaan

- **Data "banyak"** — daftar buku, anggota, peminjaman → selalu array.
- **Data per-record** — hasil query DB, payload JSON → associative array.
- **Konfigurasi** — daftar kategori dalam konstanta (materi 7) bisa array.
- **Kapan memilih tiap bentuk:**
  - *Indexed*: daftar sederhana tanpa label (tag, halaman, pilihan).
  - *Associative*: data yang punya kolom/label (record).
  - *Multidimensional*: koleksi record (katalog, tabel).
- **Kasus nyata:** halaman `katalog.php` menampilkan array `$katalog`; materi 11 akan menambahkan pencarian/filter/sort di atas array ini.

## 6. Aspek Keamanan & Best Practices (Critical)

- **`isset()` vs `array_key_exists()` paham perbedaannya** — `isset($arr['key'])` bernilai `false` jika key bernilai `null`; `array_key_exists` bernilai `true` selama key ada. Untuk "apakah key ada?", lebih tepat `array_key_exists`. Untuk "apakah ada nilai yang berguna?", `isset($arr['key'] ?? null)` atau gabungan keduanya.
- **Selalu gunakan `??` saat mengakses kemungkinan-tidak-ada** — mencegah *Undefined array key* (Notice) dan mencegah kebocoran alur logika.
- **Jangan percaya struktur array dari user** — `$_GET`, `$_POST` bisa di manipulasi (key, nilai, tipe). Validasi key yang diharapkan, bukan asumsi.
- **Best practices:**
  - Struktur data konsisten: setiap buku punya key yang sama (`id`, `judul`, ...). Inconsistency = bug halus.
  - Pilih associative daripada pembuatan key numerik manual — lebih terbaca.
  - Jangan campur representasi: di dalam aplikasi pilih *satu konvensi* (misal selalu array asosiatif untuk record).
  - Escape saat output di dalam loop (`htmlspecialchars`).

## 7. Kesalahan Umum & Debugging

- **`Undefined array key "judul"`** — key tidak ada (salah eja, atau struktur tidak konsisten). Debug dengan `var_dump($array)` atau `print_r($array)` untuk melihat struktur nyata; gunakan `??` sementara.
- **`Variable $buku on line x` di luar loop** — variabel yang di-`foreach` masih ada setelah loop selesai (PHP tidak "mengosongkan" variabel loop). Hati-hati memakai `$buku` di tempat yang tidak dimaksudkan.
- **Index tidak berurutan setelah `unset`** → `foreach` tetap bekerja, tapi akses `$arr[2]` bisa `undefined`. Patuhi pola: `array_values()` setelah banyak `unset`.
- **`isset` mematikan key bernilai `null`** — bug klasik "key-nya ada kok tapi isset false". Gunakan `array_key_exists`.
- **Array casting aneh** — `$arr[] = ...` di dalam loop bisa menimpa dengan `$key =` jika kamu lupa index; pastikan assignment memakai `[]` atau key eksplisit.
- **`foreach` referensi** — `foreach ($arr as &$v)` meninggalkan referensi `$v` setelah loop selesai, menyebabkan bug pada loop berikutnya jika dipakai lagi. **Selalu `unset($v)`** setelah loop bervariabel referensi (dibahas di materi 17).

## 8. Soal Latihan & Kunci Jawaban

### Tantangan 1
Bangun `$katalog` berisi **3 buku** dengan key: `id`, `judul`, `pengarang`, `harga`, `stok`. Tuliskan: (a) akses judul buku kedua; (b) tambahkan buku keempat; (c) hapus buku dengan `id === 3`; (d) reset index setelah penghapusan; (e) tampilkan semua buku ke HTML dengan `foreach` + escape.

### Tantangan 2
Apa output & jelaskan:

```php
$a = [10, 20, 30];
unset($a[1]);
$a[] = 40;
print_r($a);
echo json_encode(array_values($a));
```

### Jawaban & Pembahasan

**Tantangan 1**

```php
<?php
$katalog = [
    ['id' => 1, 'judul' => 'Clean Code', 'pengarang' => 'Robert Martin', 'harga' => 150000, 'stok' => 5],
    ['id' => 2, 'judul' => 'Laskar Pelangi', 'pengarang' => 'Andrea Hirata', 'harga' => 95000, 'stok' => 3],
    ['id' => 3, 'judul' => 'Cosmos', 'pengarang' => 'Carl Sagan', 'harga' => 200000, 'stok' => 0],
];

// (a) judul buku kedua
echo $katalog[1]['judul'];                    // Laskar Pelangi

// (b) tambah buku keempat (index otomatis)
$katalog[] = ['id' => 4, 'judul' => 'Sapiens', 'pengarang' => 'Yuval Noah Harari', 'harga' => 180000, 'stok' => 2];

// (c) hapus id === 3
$katalog = array_values(array_filter($katalog, fn($b) => $b['id'] !== 3));

// (d) hasil sudah ter-reset index karena array_values

// (e) tampilkan
?>
<ul>
<?php foreach ($katalog as $buku): ?>
    <li><?= htmlspecialchars($buku['judul']) ?> — <?= htmlspecialchars($buku['pengarang']) ?></li>
<?php endforeach; ?>
</ul>
```

> **Pembahasan:** `$katalog[]` mendapat index otomatis terbesar+1. Penghapusan dengan `array_filter` + `array_values` (gabungan yang akan dipakai terus di materi 11) memfilter berdasar `id` — dan `array_values` menghindari index loncat-loncat. `foreach` lalu membaca struktur yang sudah bersih, dan setiap nilai di-escape saat ditampilkan.

**Tantangan 2** — Output:

```
Array ( [0] => 10 [2] => 30 [3] => 40 )
[10,30,40]
```

> **Pembahasan:** `unset($a[1])` melepas index 1 tapi index 0, 2 tetap. `$a[] = 40` menambah di **index terbesar + 1 = 3** (bukan 1!). Hasilnya `{0:10, 2:30, 3:40}` — index tidak berurutan. `array_values` mengurutkan ulang menjadi `[0=>10, 1=>30, 2=>40]`, yang mana `json_encode` menjadi `[10,30,40]`. Ini ilustrasi nyata bahaya "index yang tidak di-reset setelah unset" — dan kenapa `array_values` adalah penyelamatmu hampir setiap kali kamu melakukan filtering/penghapusan.
