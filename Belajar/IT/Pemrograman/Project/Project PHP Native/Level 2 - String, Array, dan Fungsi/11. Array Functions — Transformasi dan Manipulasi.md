# 11. Array Functions — Transformasi dan Manipulasi

> **Level 2 · String, Array, dan Fungsi** — Membaca array itu satu hal; *mengolah* array adalah skill berikutnya.

---

## 1. Penjelasan Singkat & Konsep Dasar

PHP menyediakan **puluhan fungsi array** dari bawaan: mencari, memfilter, memetakan, mengurutkan, dan mengagregasi — semuanya bekerja pada array tanpa kamu menulis loop manual. Yang wajib dikuasai (kategori inti):

| Kategori | Fungsi | Hasil |
|---|---|---|
| Cari | `in_array`, `array_search` | cek/posisi nilai |
| Filter | `array_filter` | subset yang memenuhi kondisi |
| Transform | `array_map` | array baru dengan setiap elemen diubah |
| Sorting | `sort`, `rsort`, `asort`, `usort` | urutan elemen |
| Agregasi | `array_reduce`, `array_sum`, `array_column` | hitung/ekstrak kolom |

**Benang Merah:** materi 10 memberi struktur data (array multidimensi). Sekarang array itu *diproses*: pencarian buku (filter), daftar judul (map), urutan harga (sort), total stok (reduce). Inilah "logic layer" yang nanti akan menjadi fungsi & method repository di Level 4.

---

## 2. Fungsi & Kegunaan Utama

- **Menghindari loop manual yang rawan error** — `array_filter` yang ditulis sendiri dengan `foreach` + `if` terlalu sering salah. Fungsi bawaan sudah teroptimasi & teruji.
- **Immutability yang disengaja** — banyak fungsi array PHP **mengembalikan array baru** (tidak mengubah aslinya): `array_map`, `array_filter`; sedangkan sebagian **mengubah array asli**: `sort`, `array_push`, `array_pop`. Memahami mana yang dimutasi vs tidak = kunci menghindari bug.
- **Ekspresif** — `array_map(fn($b) => $b['judul'], $katalog)` *menggambarkan maksud* ("ambil semua judul") lebih jelas daripada loop 5 baris.

> ⚠️ **Satu gotcha yang wajib kamu hafal:** `array_filter` **mempertahankan key asli**. Setelah filter, index bisa melompat (0, 2, 5...). Solusi standar: bungkus dengan `array_values()`.

```php
$bukuTersedia = array_values(array_filter($katalog, fn($b) => $b['stok'] > 0));
```

## 3. Contoh Kode & Implementasi Real-World

`functions/katalog.php` — library fungsi untuk mengolah katalog (akan dipakai di semua halaman):

```php
<?php
// File: functions/katalog.php
require_once __DIR__ . '/helpers.php';

/**
 * Cari buku berdasarkan kata kunci pada judul/pengarang (case-insensitive).
 */
function cariBuku(array $katalog, string $keyword): array {
    $keyword = strtolower(trim($keyword));
    if ($keyword === '') return $katalog;

    return array_values(array_filter($katalog, function ($buku) use ($keyword) {
        return str_contains(strtolower($buku['judul']), $keyword)
            || str_contains(strtolower($buku['pengarang']), $keyword);
    }));
}

/**
 * Filter berdasarkan kategori (default 'semua').
 */
function filterKategori(array $katalog, string $kategori): array {
    if ($kategori === 'semua') return $katalog;
    return array_values(array_filter(
        $katalog,
        fn($b) => $b['kategori'] === $kategori
    ));
}

/**
 * Urutkan berdasar kolom dengan arah tertentu (whitelist + spaceship).
 */
function urutkanBuku(array $katalog, string $field = 'judul', string $arah = 'asc'): array {
    $fieldValid = ['judul', 'pengarang', 'harga', 'tahun'];
    if (!in_array($field, $fieldValid, true)) $field = 'judul';

    usort($katalog, function ($a, $b) use ($field, $arah) {
        $hasil = is_string($a[$field ])
            ? strcmp($a[$field], $b[$field])
            : $a[$field] <=> $b[$field];
        return $arah === 'desc' ? -$hasil : $hasil;
    });

    return $katalog;
}
```

`katalog.php` — menggabungkan semuanya dengan query string dari URL:

```php
<?php
// File: katalog.php
require_once 'data/katalog.php';
require_once 'functions/katalog.php';

$q        = $_GET['q'] ?? '';
$kategori = $_GET['kategori'] ?? 'semua';
$sort     = $_GET['sort'] ?? 'judul';
$arah     = $_GET['arah'] ?? 'asc';

$hasil = cariBuku($katalog, $q);
$hasil = filterKategori($hasil, $kategori);
$hasil = urutkanBuku($hasil, $sort, $arah);

$total = array_reduce($hasil, fn($carry, $b) => $carry + $b['stok'], 0);
$semuaJudul = array_column($hasil, 'judul');
?>
<p>Ditemukan <?= count($hasil) ?> buku (total stok: <?= $total ?>).</p>
<ul>
<?php foreach ($hasil as $buku): ?>
    <li><?= htmlspecialchars($buku['judul']) ?> — <?= formatHarga($buku['harga']) ?></li>
<?php endforeach; ?>
</ul>
```

**Fungsi berharga lain (snippet cepat):**

```php
// array_column dengan key — akses cepat by ID
$katalogById = array_column($katalog, null, 'id');
echo $katalogById[1]['judul'];   // Clean Code

// array_map — transform ke format tampilan
$formatted = array_map(function ($buku) {
    return [...$buku, 'harga_format' => formatHarga($buku['harga'])];
}, $katalog);
```

## 4. Analogi Sederhana

Dalam **Sistem Administrasi Kantor**, lemari arsip (`$katalog`) berisi banyak map buku. Fungsi array = **staf pengolah arsip**:

- **`array_filter`** = staf memilah: "ambil semua map dengan stok > 0." Hasilnya berupa *tumpukan baru*, lalu staf **menulis ulang nomor urut** (`array_values`) agar rapi.
- **`array_map`** = staf *menyalin* lalu menambahkan label baru di tiap map (misal `harga_format`) tanpa menyentuh map asli.
- **`usort`** = staf *mengurutkan ulang tumpukan* sesuai aturan yang kamu berikan (harga naik, judul alfabetis).
- **`array_reduce`** = staf menjumlahkan isi stok semua map menjadi satu angka.
- **`array_column`** = staf membuat daftar "semua judul" dari tumpukan map sekaligus.

---

## 5. Kapan Harus Digunakan & Kasus Penggunaan

- **`array_filter`** — pencarian & filter (keyword, kategori, stok > 0). Akan dipakai terus di Level 3 (filtering form) dan Level 4 (`WHERE` adalah versi DB-nya).
- **`array_map`** — menyiapkan data *tampilan*: format harga, tambahkan label, pilih kolom.
- **`usort`** — sorting kolom apa pun dengan aturan kustom (`<=>`), biasanya dipicu query string `?sort=&arah=`.
- **`array_column`** — ekstraksi kolom atau membuat lookup-by-id (`array_column($katalog, null, 'id')`).
- **`array_reduce`** — agregasi: total harga, total stok, distribusi kategori.
- **`in_array`** — whitelist validasi: "apakah input kategori ada di daftar yang diizinkan?" (dipakai di materi 14).

---

## 6. Aspek Keamanan & Best Practices (Critical)

- **Validasi kolom/pilih: whitelist** — jangan izinkan `?sort=apa_saja` dilempar langsung ke logika. `in_array($field, $fieldValid, true)` dengan whitelist mencegah kode tak terduga (dan jika field ini nantinya jadi nama kolom SQL → mencegah injeksi tak sengaja).
- **Jangan hitung-hitung sensitif di client** — agregasi (`array_reduce`) di server; jangan kirim semua data mentah ke browser.
- **Best practices:**
  - Selalu `array_values()` setelah `array_filter` jika urutan index penting.
  - Prefer **arrow function** (`fn(...) => ...`) untuk callback singkat; ganti `function(...) use ($var)` jika perlu `use`.
  - Jangan memakai `sort()` di dalam array asosiatif tanpa sadar — `sort` menghapus key string! Gunakan `asort`/`ksort` bila key perlu dipertahankan.
  - Pisahkan logika pengolahan ke fungsi helper (DRY), bukan menulis inline di tiap halaman.

## 7. Kesalahan Umum & Debugging

- **`array_filter` membuat key melompat** → `foreach` tetap jalan, tapi akses `$arr[0]` bisa salah / JSON kehilangan urutan. Solusi: `array_values()` — ini **pola #11 di benang merah roadmap**.
- **`usort` memodifikasi array asli** — jika kamu butuh array asli untuk hal lain, duplikat dulu (`$copy = $katalog; usort($copy, ...)`).
- **Callback yang salah** — lupa `use ($var)` pada closure, atau arrow function salah menangkap variabel. Arrow function menangkap otomatis (materi 12).
- **`sort` pada associative array menghapus key** → data kehilangan identitasnya. Gunakan `asort`/`arsort` untuk pertahankan key.
- **`in_array` tanpa strict `true`** → `in_array('fiksi', ['Fiksi'])` bernilai false (string berbeda), tapi `in_array(0, [true])` bernilai true karena juggling (materi 6). Selalu lewatkan `true` sebagai argumen ketiga.
- **`array_column` key yang tidak ada** → ambil `null` → *Undefined index* di penggunaan selanjutnya. Sering muncul saat data belum lengkap; validasi atau `??`.
- **Periksa hasil fungsi dengan `var_dump`/`print_r`** di tengah alur — fungsi array mudah "berhasil tanpa error tapi hasilnya salah".

## 8. Soal Latihan & Kunci Jawaban

### Tantangan 1
Dengan `$katalog` (array multidimensi berisi minimal 4 buku dengan key `id`, `judul`, `harga`, `stok`, `kategori`):

(a) Cari buku ber-`kategori === 'Teknologi'` yang `stok > 0`.
(b) Sortir berdasarkan `harga` ascending tanpa mengubah array asli.
(c) Total nilai stok (stok × harga) semua buku.
(d) Daftar judul buku yang stok-nya 0.

### Tantangan 2
Jelaskan mengapa kode ini salah dan perbaiki:

```php
$bukuStokNol = array_filter($katalog, fn($b) => $b['stok'] === 0);
echo $bukuStokNol[0]['judul'];
```

### Jawaban & Pembahasan

**Tantangan 1**

```php
<?php
// (a) filter gabungan
$teknologiStok = array_values(array_filter(
    $katalog,
    fn($b) => $b['kategori'] === 'Teknologi' && $b['stok'] > 0
));

// (b) duplikat dulu, baru usort agar asli tidak berubah
$urutHarga = $katalog;
usort($urutHarga, fn($a, $b) => $a['harga'] <=> $b['harga']);

// (c) agregasi
$totalNilai = array_reduce($katalog, fn($carry, $b) => $carry + ($b['stok'] * $b['harga']), 0);

// (d) daftar judul yang habis
$judulHabis = array_map(
    fn($b) => $b['judul'],
    array_filter($katalog, fn($b) => $b['stok'] === 0)
);
```

> **Pembahasan alur:** Kondisi gabungan digabung dalam satu callback (lazily dibaca). Untuk (b), array asli di-*duplikat* sebelum `usort` karena `usort` memodifikasi in-place. (c) memakai `array_reduce` untuk menjumlahkan produk stok×harga per buku. (d) menggabungkan `array_filter` → `array_map`: filter dulu yang habis, lalu ambil kolom judul.

**Tantangan 2** — Masalah: `array_filter` **mempertahankan key asli**; elemen yang sesuai bisa berada di index yang tidak 0 (misal buku id 3 → key '2'), sehingga `$bukuStokNol[0]` memicu `Undefined array key` atau mengambil elemen yang salah.

```php
$bukuStokNol = array_values(array_filter($katalog, fn($b) => $b['stok'] === 0));
echo $bukuStokNol[0]['judul'];   // aman: index sudah urut 0,1,2,...
```

> **Pembahasan:** Membungkus hasil `array_filter` dengan `array_values` menjamin index urut dari 0 — inilah pola "filter → values" yang diangkat sebagai benang merah #11 di roadmap, dan akan dipakai terus sampai materi repository/PDO (Level 4).
