# 8. Kondisional dan Loop

> **Level 1 · Fondasi PHP** — Penutup Level 1: memberi PHP kemampuan "berpikir" (kondisi) dan "mengulang" (loop).

---

## 1. Penjelasan Singkat & Konsep Dasar

Program yang berguna harus bisa **mengambil keputusan** dan **mengulang pekerjaan**:

- **Kondisional** (`if/elseif/else`, `match`) — jalankan blok kode hanya jika kondisi bernilai `true`.
- **Loop** (`for`, `while`, `foreach`) — ulangi blok kode sebanyak yang dibutuhkan.

```php
// Kondisi
$stok = 3;
if ($stok > 0) {
    echo "Tersedia: $stok";
} else {
    echo "Stok habis";
}

// Loop — tampilkan 5 halaman
for ($i = 1; $i <= 5; $i++) {
    echo "Halaman $i<br>";
}
```

**Kapan memakai yang mana:**

| Struktur | Pergunakan ketika |
|---|---|
| `if / elseif / else` | Beberapa kondisi berurutan, fleksibel |
| `match` (PHP 8) | Satu nilai dibandingkan ke banyak kemungkinan, *strict*, mengembalikan nilai |
| `for` | Sudah tahu jumlah pengulangan (pagination) |
| `while` | Tidak tahu jumlah pengulangan, berhenti saat kondisi berubah |
| `foreach` | Iterasi array — **paling sering dipakai** |

**Benang Merah:** materi 5-7 menyiapkan data & operator. Logika keputusan menghidupkannya: sekarang PHP bisa *memilih* (stok habis vs tersedia) dan *memproduksi* halaman berulang. Ini fondasi untuk Level 2 (mengolah array) dan 3 (validasi input).

---

## 2. Fungsi & Kegunaan Utama

- **Membuat halaman dinamis** — tampilan berubah berdasarkan data: badge "Stok Banyak"/"Terbatas"/"Habis", pesan error form, filter kategori.
- **Menghasilkan output berulang** — pagination, tabel daftar buku, dropdown kategori, daftar berita.
- **`match`** menyelesaikan kelemahan `switch` klasik: perbandingan strict (`===`), tanpa `break`, langsung mengembalikan nilai (bisa dipakai dalam ekspresi).
- **Alternatif syntax (`if: ... endif;`)** — untuk mencampur PHP & HTML lebih terbaca — sangat disarankan di dalam template.

---

## 3. Contoh Kode & Implementasi Real-World

`katalog.php` — perpaduan kondisi + loop untuk daftar buku (data masih hardcode; di Level 2-4 akan jadi array & database):

```php
<?php
// Data sementara (Level 2 akan memperluas jadi array multidimensi)
$katalog = [
    ['id' => 1, 'judul' => 'Clean Code',      'harga' => 150000, 'stok' => 5],
    ['id' => 2, 'judul' => 'Laskar Pelangi',  'harga' => 95000,  'stok' => 3],
    ['id' => 3, 'judul' => 'The Great Gatsby','harga' => 120000, 'stok' => 0],
];
$stokFilter = $_GET['tersedia'] ?? 'semua';
?>
<ul class="daftar-buku">
    <?php foreach ($katalog as $buku): ?>
        <?php if ($stokFilter === 'hanya_tersedia' && $buku['stok'] === 0) continue; ?>
        <li>
            <strong><?= htmlspecialchars($buku['judul']) ?></strong> —
            Rp <?= number_format($buku['harga'], 0, ',', '.') ?>
            <?php if ($buku['stok'] > 0): ?>
                <span class="badge badge--ok">Stok <?= $buku['stok'] ?></span>
            <?php else: ?>
                <span class="badge badge--habis">Habis</span>
            <?php endif; ?>
        </li>
    <?php endforeach; ?>
</ul>
```

**Alternatif syntax di dalam HTML** — lebih mudah dibaca daripada `{ }` di tengah markup:

```php
<?php if ($buku['stok'] > 10): ?>
    <span class="badge badge--success">Stok banyak</span>
<?php elseif ($buku['stok'] > 0): ?>
    <span class="badge badge--warning">Terbatas</span>
<?php else: ?>
    <span class="badge badge--danger">Habis</span>
<?php endif; ?>
```

**Pagination dengan `for`:**

```php
<?php
$totalHalaman = 10;
$halamanAktif = 3;

for ($i = 1; $i <= $totalHalaman; $i++) {
    $aktif = $i === $halamanAktif ? 'aktif' : '';
    echo "<a href='?halaman=$i' class='page-link $aktif'>$i</a>";
}
```

**`match` — pengganti `switch` yang lebih aman (PHP 8):**

```php
$kategori = 'Teknologi';
$warnaBadge = match($kategori) {
    'Teknologi'  => 'blue',
    'Fiksi'      => 'purple',
    'Sains'      => 'green',
    default      => 'gray',
};
echo "Warna: $warnaBadge";
```

**`while` — jumlah repetisi tidak diketahui:**

```php
$stok = 5;
while ($stok > 0) {
    echo "Buku terjual, sisa $stok<br>";
    $stok--;
}
```

## 4. Analogi Sederhana

Dalam **Sistem Administrasi Kantor**:

- **`if/else`** = aturan pengambil keputusan staf di meja bantuan: "Kalau stok habis → tempel tanda HABIS; kalau masih ada → tempel jumlahnya."
- **`match`** = daftar aturan singkat di papan: "Kategori Teknologi → stempel biru, Fiksi → ungu, lainnya → abu-abu." Dibaca sekali, langsung memberi jawaban.
- **`for`** = instruksi tegas: "Cetak halaman 1 sampai 5." Jumlahnya pasti.
- **`while`** = instruksi fleksibel: "Selama masih ada berkas di antrean, terus proses." Berhenti saat antrean kosong.
- **`foreach`** = "Untuk setiap berkas dalam lemari ini, proses dan tulis hasilnya." — paling sering dipakai untuk mengolah kumpulan data.

---

## 5. Kapan Harus Digunakan & Kasus Penggunaan

- **`if/else`** — validasi input, otorisasi role, tampilan kondisional, error handling.
- **`match`** — memetakan satu nilai (kategori, status, role) ke nilai lain (warna, label) — ideal untuk kode rapi tanpa `switch`-fall-through.
- **`foreach`** — menampilkan daftar dari array (katalog) — akan jadi 90% dari seluruh iterasi di aplikasi web.
- **`for`** — pagination yang jumlah halamannya diketahui.
- **`while`** — membaca baris demi baris file/result, atau proses yang berhenti berdasarkan kondisi runtime.
- **Alternatif syntax (`:` ... `endif;`/`endforeach;`)** — WAJIB untuk template HTML campuran — menyembunyikan `{ }` yang berisik dan terlihat seperti "tag" di markup.

---

## 6. Aspek Keamanan & Best Practices (Critical)

- **Jangan tentukan keamanan di *tampilan* saja** — kondisi `if` di template hanya untuk *menampilkan*; otorisasi sebenarnya harus di logika (Level 5/6, middleware). User bisa request URL lain, jadi jangan andalkan penyembunyian UI sebagai proteksi.
- **Selalu escape output di dalam loop** — `<?= htmlspecialchars($buku['judul']) ?>`; data dari array yang berisi input user bisa jadi pintu XSS.
- **Best practices:**
  - Gunakan `match` (PHP 8) daripada `switch` untuk pemetaan nilai sederhana.
  - Prioritaskan `===` di semua kondisi (materi 6).
  - Gunakan alternatif syntax di template untuk keterbacaan; gunakan `{ }` untuk logika murni di script.
  - Hindari *deep nesting*: pecah kondisi menjadi helper/fungsi (awal refactoring, materi 12).
  - Perhatikan infinite loop — selalu ada progress menuju kondisi berhenti.
  - Hindari memakai `while(true)` tanpa `break` yang pasti.

---

## 7. Kesalahan Umum & Debugging

- **Infinite loop / server hang** — kondisi pada `while`/`for` tidak pernah false (`while ($stok > 0)` tanpa `$stok--`). Debug: pastikan ada perubahan nilai di dalam loop, gunakan timeout di browser, dan periksa log jika server membeku (Foundation: paksa stop process).
- **`Undefined array key` di dalam loop** — array tanpa sebuah key (misal `'stok'` tidak ada untuk satu item). Solusi: `$buku['stok'] ?? 0` di dalam loop, atau pastikan struktur data konsisten.
- **`break`/`continue` yang salah tempat** — hanya bekerja di dalam loop (`for`,`while`,`foreach`,`switch`). `continue` di dalam `if` di tengah foreach = "skip iterasi ini" (sering jadi Boolean bug yang halus).
- **Switch fall-through** — lupa `break` membuat banyak case dieksekusi. Di PHP 8, prefer `match` yang menghindari masalah ini (tanpa `break`).
- **`==` vs `===` di kondisi** — `$stok == 0` vs `$stok === 0`; dengan input string `"0"`, `==` menganggap true untuk `$stok = "0"` juga — salah makna. Pakai `===`.
- **Out-of-bounds** — `for ($i = 1; $i <= 5; $i++)` memproduksi 1..5. Memulai dari 0 atau menyalah gunakan `$i` di dalam body sering menghasilkan halaman kosong/berlebih.

## 8. Soal Latihan & Kunci Jawaban

### Tantangan 1
Buat `katalog.php` yang menampilkan daftar buku (5 item hardcode) dengan: badge status stok (banyak/terbatas/habis), filter via query string `?tersedia=habis` (tampilkan hanya yang habis), dan pagination sederhana (10 halaman virtual) memakai `for` + estilo active page.

### Tantangan 2
Apa output dari kode ini? Jelaskan alurnya baris per baris.

```php
$nilai = 85;
$predikat = match (true) {
    $nilai >= 90 => 'A',
    $nilai >= 80 => 'B',
    $nilai >= 70 => 'C',
    default      => 'D',
};
echo "Predikat: $predikat, " . ($nilai >= 80 ? 'Lulus' : 'Remedial');
```

### Jawaban & Pembahasan

**Tantangan 1**

```php
<?php
$katalog = [
    ['id' => 1, 'judul' => 'Clean Code',       'stok' => 12],
    ['id' => 2, 'judul' => 'Laskar Pelangi',   'stok' => 3],
    ['id' => 3, 'judul' => 'Cosmos',           'stok' => 0],
    ['id' => 4, 'judul' => 'The Pragmatic Prog', 'stok' => 7],
    ['id' => 5, 'judul' => 'Sapiens',          'stok' => 0],
];
$filter = $_GET['tersedia'] ?? 'semua';
?>
<ul>
    <?php foreach ($katalog as $buku): ?>
        <?php if ($filter === 'habis' && $buku['stok'] > 0) continue; ?>
        <?php if ($filter === 'tersedia' && $buku['stok'] === 0) continue; ?>
        <li>
            <?= htmlspecialchars($buku['judul']) ?>
            <?php if ($buku['stok'] >= 10): ?>
                <span class="badge badge--many">Stok banyak</span>
            <?php elseif ($buku['stok'] > 0): ?>
                <span class="badge badge--low">Terbatas</span>
            <?php else: ?>
                <span class="badge badge--out">Habis</span>
            <?php endif; ?>
        </li>
    <?php endforeach; ?>
</ul>
```

> **Pembahasan alur:** `foreach` berjalan satu per satu; di awal iterasi `if` memfilter item yang tidak sesuai query string (men-skip dengan `continue`). Setelah lolos filter, badge ditentukan dengan `if/elseif/else` bersarang pada alternatif syntax. Ini pola "loop + kondisi + escape" yang akan kamu pakai setiap hari di PHP native.

**Tantangan 2** — Output: `Predikat: B, Lulus`.

> **Pembahasan:** `match(true)` membuka *logika boolean*: PHP mengevaluasi setiap lengan mulai dari atas. `$nilai >= 90` (85≥90) → false; `$nilai >= 80` (85≥80) → true → ambil `'B'` dan **berhenti** (match tidak mengecek lengan berikutnya). Lalu ekspresi ternary `$nilai >= 80 ? 'Lulus' : 'Remedial'` → true → `'Lulus'`. Perhatikan bahwa `match` *strict* dan justru aman untuk kondisi seperti ini, menghindari bug fall-through dari `switch`.
