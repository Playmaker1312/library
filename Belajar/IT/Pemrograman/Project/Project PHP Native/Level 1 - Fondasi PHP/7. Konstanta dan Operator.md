# 7. Konstanta dan Operator

> **Level 1 · Fondasi PHP** — Data yang tak berubah (konstanta) dan cara mengolah data (operator).

---

## 1. Penjelasan Singkat & Konsep Dasar

Dua konsep pelengkap:

1. **Konstanta** = nilai yang **tidak bisa berubah** setelah didefinisikan. Berbeda dengan variabel (`$`), konstanta **tanpa `$`**, dan jika didefinisikan dua kali → error. Cocok untuk nilai konfigurasi: nama perpustakaan, denda per hari, batas pinjam.
2. **Operator** = simbol yang melakukan operasi terhadap nilai: aritmatika (`+ - * / % **`), penugasan (`=`, `+=`, `-=`), string (`.`), perbandingan (`== === != !== < > <=>`), dan logika (`&& || !`).

```php
const DENDA_PER_HARI = 1000;     // konstanta, tanpa $
$totalDenda = 7 * DENDA_PER_HARI; // operator *
```

**Benang Merah:** materi 5 memberi variabel, materi 6 mengingatkan tentang tipe. Konstanta adalah *variabel yang "dikunci"*, dan operator adalah cara kamu mulai *mengolah* data yang tersimpan itu — jembatan menuju logika keputusan (materi 8).

---

## 2. Fungsi & Kegunaan Utama

- **Konstanta** menyelesaikan masalah "nilai ajaib yang terulang" (magic number/string): jika denda naik, ubah **satu** tempat. Ini DRY dalam bentuk paling sederhana.
- **Konstanta PHP built-in** menyediakan informasi sistem yang sering dibutuhkan: `PHP_VERSION`, `PHP_EOL`, `PHP_INT_MAX`, `__DIR__`, `__FILE__`.
- **Operator** memungkinkan: perhitungan denda, kalkulasi harga diskon, penggabungan string, perbandingan nilai, dan logika keputusan — dasar dari semua aplikasi.

**Dua cara mendefinisikan konstanta:**

```php
define('NAMA_PERPUSTAKAAN', 'Perpustakaan Digital Kota'); // cara lama, masih valid
const MAKS_PINJAM = 5;                                     // cara modern, disarankan
const KATEGORI = ['Fiksi', 'Sains'];                       // PHP 7+ bisa array
```

> `const` hanya bisa di *compile-time* (nilai literal), sedangkan `define()` bisa nilai dinamis. Untuk konfigurasi statis, `const` lebih disukai.

**Konstanta ajaib (magic constants) — paling sering dipakai:**

```php
echo __DIR__;   // path direktori file ini
echo __FILE__;  // path lengkap file ini
echo __LINE__;  // nomor baris saat ini
echo PHP_EOL;   // newline sesuai OS
```

## 3. Contoh Kode & Implementasi Real-World

`config/perpustakaan.php` — pusat konfigurasi (akan di-refactor ke `.env` di Level 6):

```php
<?php
// File: config/perpustakaan.php
// Semua "nilai ajaib" dipusatkan di sini.

const NAMA_PERPUSTAKAAN  = 'Perpustakaan Digital Kota';
const MAKS_PINJAM        = 5;
const DENDA_PER_HARI     = 1000;   // Rupiah
const MASA_PINJAM_HARI   = 14;
const JAM_BUKA           = '08:00';
const JAM_TUTUP          = '17:00';
const KATEGORI_TERSEDIA  = ['Fiksi', 'Non-Fiksi', 'Sains', 'Teknologi', 'Sejarah'];
```

`hitung.php` — pemanfaatan operator untuk kalkulator denda:

```php
<?php
require_once 'config/perpustakaan.php';

function hitungDenda(int $hariTerlambat): int {
    return max(0, $hariTerlambat) * DENDA_PER_HARI;
}

$hariTerlambat = 7;
$denda = hitungDenda($hariTerlambat);
echo "Denda untuk $hariTerlambat hari: Rp " . number_format($denda, 0, ',', '.');
```

**Kumpulan operator dengan contoh konkret:**

```php
// Aritmatika
$harga = 150000;
$hargaDiskon = $harga * (1 - 0.10);   // 135000
$sisa   = 10 % 3;                      // 1 — modulo (sering untuk genap/ganjil)
$pangkat = 2 ** 8;                     // 256

// Penugasan gabungan
$stok = 10;
$stok += 5;   // 15
$stok -= 3;   // 12
$stok *= 2;   // 24

// String
$info = "Buku: " . "Clean Code";
$info .= " - Rp 150.000";

// Null coalescing — RATU dari input handling
$halaman  = $_GET['halaman'] ?? 1;      // default 1 jika tidak ada
$q        = $_GET['q'] ?? '';
$data['hit'] ??= 0;                     // null coalescing assignment (7.4+)
$data['hit']++;

// Spaceship — untuk sorting (dipakai di usort, materi 11)
echo 1 <=> 2;   // -1  (kiri < kanan)
echo 2 <=> 2;   //  0
echo 3 <=> 2;   //  1
```

## 4. Analogi Sederhana

Dalam **Sistem Administrasi Kantor**:

- **Konstanta** = **kebijakan tetap kantor** yang dicetak di papan pengumuman dan tidak bisa diubah seenaknya (misal "Denda keterlambatan Rp1.000/hari"). Semua staf membacanya dari satu sumber — tidak ada yang menulis ulang angka di suratnya masing-masing.
- **`const`** = kebijakan yang sudah ditetapkan sejak kantor berdiri (nilai tetap). **`define()`** = kebijakan yang bisa ditetapkan di tengah jalan.
- **Operator** = mesin hitung staf: menambah/mengurangi berkas stok (`+=`), menggabungkan dua catatan (`.`), membandingkan dua berkas (`==`, `<=>`), memilih sesuai kondisi (logika).
- **`??`** = "kalau berkas ini tidak ada di meja, ambil cadangan ini" — mencegah staf panik saat data kosong.

---

## 5. Kapan Harus Digunakan & Kasus Penggunaan

- **Konstanta untuk**: nilai konfigurasi yang dipakai lintas file — denda, batas pinjam, kategori, jam buka. Satu tempat ubah, semua ter-update.
- **`??` setiap kali mengambil input** (query string, POST, sesi) — aturan wajib di semua materi berikutnya.
- **Modulo `%`** untuk: logika genap/ganjil, pagination sederhana, rotating banner.
- **Spaceship `<=>`** untuk: custom sort (usort) — materi 11.
- **Operator penugasan gabungan** untuk kode ringkas dan terbaca: `$total += $harga` di dalam loop.

---

## 6. Aspek Keamanan & Best Practices (Critical)

- **`??` adalah lapisan keamanan input pertama** — mengambil input tanpa `??` memunculkan *Undefined array key / Undefined variable* (Notice), dan mengekspos kontrol alur yang salah. Selalu default-kan.
- **Konstanta tidak membuat data "aman"** — konstanta itu *read-only*, tapi tetap terlihat di kode (dan di bundle jika menyangkut JS — tapi PHP tidak terkirim ke browser, aman). Jangan menaruh *secret* (password) dalam konstanta yang ter-commit ke repo.
- **Best practices:**
  - `const` untuk konfigurasi statis; `define()` hanya untuk nilai dinamis.
  - Beri nama konstanta `HURUF_BESAR_SNAKE_CASE`.
  - Hindari *magic numbers* langsung di kode; pindahkan ke konstanta.
  - Selalu `??` saat mengambil input (materi 13-14 akan memperkuat).
  - Perhatikan urutan prioritas operator; gunakan tanda kurung `( ... )` untuk kejelasan.

---

## 7. Kesalahan Umum & Debugging

- **`Cannot redefine constant`** — konstanta didefinisikan dua kali (misal file config di-`require` dua kali). Solusi: `require_once`, atau periksa `defined()`.

```php
if (!defined('NAMA_PERPUSTAKAAN')) {
    define('NAMA_PERPUSTAKAAN', 'Perpustakaan Kota');
}
```

- **`Undefined constant "X"`** — salah ketik atau lupa `require`. Di PHP 8 ini jadi **Fatal Error** (di PHP <8 jadi Warning dengan asumsi string `'X'`!). Solusi: periksa file yang didefinisikan.
- **Prioritas operator mengecoh** — `1 + 2 * 3` = 7, bukan 9. Selalu pakai kurung bila ragu.
- **`$` yang terlewat** — menulis `echo NAMA_PERPUSTAKAAN;` benar; menulis `echo $NAMA_PERPUSTAKAAN;` akan jadi `Undefined variable` (variabel tak pernah didefinisikan).
- **Konstanta vs variabel yang tidak sinkron** — saat pindah dari `define()` ke `const` atau sebaliknya, pastikan semua pemakaian konsisten (tidak ada yang tetap memakai `$`).

## 8. Soal Latihan & Kunci Jawaban

### Tantangan 1
Buat file `config/perpustakaan.php` berisi: `NAMA_PERPUSTAKAAN`, `MAKS_PINJAM = 5`, `DENDA_PER_HARI = 1000`, `KATEGORI` (array). Lalu buat `perhitungan.php` yang menghitung denda 3 buku yang masing-masing terlambat 2, 5, dan 9 hari (pakai `hitungDenda`), tampilkan total denda dengan `number_format`. Pastikan nilai ajaib tidak muncul langsung di perhitungan.

### Tantangan 2
Apa output script ini, dan kenapa?

```php
$a = "5";
$b = $a + 1;
$c = (int) $a;
$hasil = $b . $c;
echo $hasil;          // ?
var_dump($hasil);     // ?
```

### Jawaban & Pembahasan

**Tantangan 1**

```php
<?php
// config/perpustakaan.php
const NAMA_PERPUSTAKAAN = 'Perpustakaan Digital Kota';
const MAKS_PINJAM       = 5;
const DENDA_PER_HARI    = 1000;
const KATEGORI          = ['Fiksi', 'Non-Fiksi', 'Sains', 'Teknologi', 'Sejarah'];
```

```php
<?php
// perhitungan.php
require_once 'config/perpustakaan.php';

function hitungDenda(int $hariTerlambat): int {
    return max(0, $hariTerlambat) * DENDA_PER_HARI;
}

$keterlambatan = [2, 5, 9];
$totalDenda = 0;
foreach ($keterlambatan as $hari) {
    $totalDenda += hitungDenda($hari);
}

echo NAMA_PERPUSTAKAAN . ' — Total denda: Rp ' .
     number_format($totalDenda, 0, ',', '.');
// Output: Perpustakaan Digital Kota — Total denda: Rp 16.000
```

> **Pembahasan alur:** Konstanta di-load sekali via `require_once`. `hitungDenda` memakai `DENDA_PER_HARI` (bukan angka 1000 di tengah kode) — jika denda berubah, cukup ubah satu baris di config. Operator `+=` mengakumulasi total; `number_format` menyajikan angka ke format Indonesia. Ini adalah pola kecil dari apa yang nanti menjadi layanan bisnis di Level 4 (class + konstanta konfigurasi).

**Tantangan 2** — Output: `66`, `string(2) "66"`.

> **Pembahasan:** `$a + 1` memicu juggling → `5+1 = 6` (int). `(int) $a` → `5` (int). Lalu `$b . $c` adalah **konkatenasi string** (`.`) → `"6" . "5"` = `"66"` — sebuah **string**, bukan 6+5. `var_dump` mengonfirmasi `string(2) "66"`. Ini menunjukkan perbedaan krusial: operator `+` (aritmatika) vs `.` (string) — dan kenapa menebak tipe hasil tanpa `var_dump` sering menyesatkan.
