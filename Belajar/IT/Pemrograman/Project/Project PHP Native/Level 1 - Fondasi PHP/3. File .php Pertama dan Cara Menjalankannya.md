# 3. File .php Pertama dan Cara Menjalankannya

> **Level 1 · Fondasi PHP** — Environment sudah hidup (materi 2), sekarang menulis dan menjalankan file `.php` pertama.

---

## 1. Penjelasan Singkat & Konsep Dasar

Sebuah file `.php` adalah **campuran teks biasa (biasanya HTML) dan kode PHP**. PHP Engine membaca file dari atas ke bawah:

- Teks di **luar** tag `<?php ... ?>` dianggap HTML murni → langsung diteruskan ke output.
- Teks di **dalam** tag `<?php ... ?>` dianggap kode → dieksekusi, hasilnya dimasukkan ke output.

Contoh minimal:

```php
<p>Ini HTML murni, langsung diteruskan.</p>
<?php echo "<p>Ini hasil PHP, dihasilkan di server.</p>"; ?>
```

Ketika PHP mengeksekusi, dia "menempelkan" hasilnya pada posisi tag itu berada. Hasil akhir yang dikirim ke browser adalah **satu aliran teks/HTML** yang sudah menyatu.

**Aturan paling penting:**

- File PHP **harus** diawali tag pembuka `<?php`. Tag penutup `?>` **bersifat opsional**.
- Kalau file berisi murni kode PHP, **jangan** ditutup dengan `?>`.

**Benang Merah:** di materi 1 kamu tahu PHP diproses server; di materi 2 kamu menyiapkan tempatnya. Sekarang kamu menulis "instruksi kerja" pertama (echo, variabel) dan melihat hasilnya benar-benar lewat browser — inilah dasar dari semua materi selanjutnya.

---

## 2. Fungsi & Kegunaan Utama

- **`echo`** — instruksi paling dasar: "kirim teks ini ke output". `print` hampir sama, tapi `echo` lebih umum dan bisa menerima banyak argumen.
- **Tag pembuka `<?php`** — memberitahu PHP Engine "mulai mode eksekusi di sini".
- **Short echo `<?=`** — singkatan `<?php echo`. Sangat nyaman dipakai di dalam HTML (misal `<?= $judul ?>`). Diaktifkan secara default sejak PHP 5.4.
- **Tag penutup dihilangkan** — jika file murni PHP, meninggalkan `?>` di akhir berisiko menambahkan whitespace/karakter tak terduga ke output sebelum header dikirim → memicu error *"headers already sent"* (dibahas di materi 7/16).

Struktur file yang disarankan (pola yang akan kamu pakai terus):

```
perpustakaan/
├── index.php      ← entry: profil singkat
├── profil.php     ← halaman detail
├── katalog.php    ← akan dibuat di Level 2
└── css/style.css
```

---

## 3. Contoh Kode & Implementasi Real-World

`index.php` — **logika PHP di atas, HTML di bawah**. Inilah pola anti-spaghetti yang dibawa sepanjang roadmap:

```php
<?php
// ─── Logika PHP: semua kalkulasi & data di sini, SEBELUM HTML ───
$namaPerpustakaan = "Perpustakaan Digital Kota";
$jumlahKoleksi    = 12500;
$tahunBerdiri     = 1995;

$kalimatSelamat = "Selamat datang di {$namaPerpustakaan}!";
?>
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title><?= htmlspecialchars($namaPerpustakaan) ?></title>
</head>
<body>
    <h1><?= htmlspecialchars($kalimatSelamat) ?></h1>
    <p>Kami memiliki lebih dari
       <strong><?= number_format($jumlahKoleksi, 0, ',', '.') ?></strong>
       koleksi buku sejak <?= $tahunBerdiri ?>.</p>
</body>
</html>
```

`profil.php` — dengan `<?= ?>` (short echo) di dalam HTML:

```php
<?php
$jamBuka = "Senin-Sabtu: 08.00-17.00";
$alamat  = "Jl. Merdeka No. 1, Bandung";
?>
<!DOCTYPE html>
<html lang="id">
<body>
    <dl>
        <dt>Jam Operasional</dt>
        <dd><?= htmlspecialchars($jamBuka) ?></dd>
        <dt>Alamat</dt>
        <dd><?= htmlspecialchars($alamat) ?></dd>
    </dl>
</body>
</html>
```

**Cara menjalankan:**

```bash
# 1. Pastikan folder project ada di web root (materi 2)
# 2. Buka browser ke:
#    http://localhost/perpustakaan/          → index.php
#    http://localhost/perpustakaan/profil.php → profil.php
# 3. Pastikan URL diawali http:// bukan file://
```

> **Debug cepat:** kalau halaman tampil tapi isinya bukan yang diharapkan, lihat *View Page Source* — bandingkan dengan output yang kamu bayangkan. Kalau muncul teks `<?php` di halaman, server tidak menjalankan PHP (lihat materi 2 bagian troubleshooting).

## 4. Analogi Sederhana

Kembali ke **Sistem Administrasi Kantor**:

- **File `.php`** = satu lembar instruksi kerja yang dibagikan ke staf. Bagian yang ditulis HTML adalah "teks siap cetak". Bagian `<?php ... ?>` adalah "langkah kerja: isi blanko ini dengan data X, hitung Y, lalu cetak".
- **`echo`** = perintah "cetak & serahkan ke depan".
- **`<?= ?>`** = seperti staf menyisipkan nilai langsung ke dalam formulir yang sedang diketik — praktis untuk mengisi bagian-bagian kecil.
- **Web root** = meja masuk tempat berkas-berkas instruksi kerja ini menunggu diproses.
- Menghilangkan `?>` di akhir file = memastikan tidak ada "catatan tambahan di pinggir halaman" yang mengganggu surat keluar.

---

## 5. Kapan Harus Digunakan & Kasus Penggunaan

- **Setiap file halaman baru** yang kamu buat di Level 1-3 — selalu mengikuti pola *logika di atas, tampilan di bawah*.
- **Saat output berupa HTML campur** — file halaman (bukan script murni). Gunakan short echo `<?= ?>` untuk menyisipkan nilai.
- **Saat file murni PHP** (class, fungsi, config) — tidak ada HTML sama sekali, jangan pakai `?>` penutup.
- **Kasus nyata:** `index.php` menampilkan ringkasan, `profil.php` menampilkan detail — keduanya mengambil data dari variabel yang didefinisikan di atas, tanpa menulis HTML statis berulang.

---

## 6. Aspek Keamanan & Best Practices (Critical)

- **Selalu escape output**: semua nilai yang kamu tampilkan ke HTML (apalagi yang berasal dari user nanti) lewat `htmlspecialchars()`. Mulai sekarang, biasakan `<?= htmlspecialchars($var) ?>`.
- **Jangan `echo` langsung kode PHP ke halaman** dengan cara menggabungkan string dari input user — itu jalan menuju XSS (Level 3 & 5).
- **Best practices:**
  - Satu file = satu tujuan (`index.php`, `profil.php`, dst). Jangan menumpuk seluruh logika di `index.php` saja (awal DRY & separation of concerns).
  - Simpan logika (variabel, perhitungan) di atas, bukan di tengah HTML.
  - Gunakan `<?= ?>` bukan `<?php echo ?>` untuk output pendek di template.
  - Konsisten dengan penamaan: `$namaPerpustakaan`, bukan `$a`.

---

## 7. Kesalahan Umum & Debugging

- **Parse error: syntax error, unexpected token** — lupa `;`, kutip tidak seimbang, atau tag `<?php` tidak ditutup. PHP menolak menjalankan file sepenuhnya. Periksa baris yang disebutkan di pesan error.
- **"Headers already sent"** — biasanya karena ada karakter/spasi **sebelum** `<?php` atau **setelah** `?>` di file yang melakukan `header()`. Solusi: hapus `?>` penutup di akhir file, pastikan `<?php` di baris paling atas tanpa spasi.
- **Halaman blank putih** — bisa jadi `display_errors` dimatikan sehingga error PHP tidak terlihat. Sementara, aktifkan error reporting (materi 4).
- **File tidak muncul di browser** — pastikan nama file persis (case-sensitive) dan lokasinya di web root.
- **Membedakan output salah vs server mati** — halaman "Connection refused" berarti server mati; halaman muncul tapi kosong/aneh berarti masalah kode.

## 8. Soal Latihan & Kunci Jawaban

### Tantangan 1
Buat `index.php` menampilkan: judul "Perpustakaan Kota", kalimat "Koleksi kami: 1.250.000 buku" (pakai `number_format`), dan tanggal hari ini dengan format `Senin, 15 Agustus 2026` (pakai `date` + array nama hari). Semua output harus via `<?= htmlspecialchars(...) ?>`.

### Tantangan 2
Jelaskan apa yang terjadi (dan apa output browser) untuk file berikut:

```php
<?php $nama = "Budi"; ?>
<?= $nama ?> adalah anggota.
```

Lalu perbaiki jika ada masalah keamanan/kepekaan terhadap XSS.

### Jawaban & Pembahasan

**Tantangan 1**

```php
<?php
$namaPerpustakaan = "Perpustakaan Kota";
$jumlahKoleksi    = 1250000;
$hari             = ['Minggu','Senin','Selasa','Rabu','Kamis','Jumat','Sabtu'];
$tanggal          = $hari[(int) date('w')] . ', ' . date('d F Y');
?>
<!DOCTYPE html>
<html lang="id">
<body>
    <h1><?= htmlspecialchars($namaPerpustakaan) ?></h1>
    <p>Koleksi kami: <strong><?= number_format($jumlahKoleksi, 0, ',', '.') ?></strong> buku.</p>
    <p>Diakses pada <?= htmlspecialchars($tanggal) ?>.</p>
</body>
</html>
```

> **Pembahasan alur:** Variabel dihitung di bagian atas. `date('w')` mengembalikan angka hari (0-6), dipakai sebagai index array nama hari; lalu digabung dengan `date('d F Y')`. Semua nilai disisipkan lewat `<?= ?>` di dalam HTML.

**Tantangan 2** — Browser menampilkan: `Budi adalah anggota.` PHP Engine memproses dua tag secara berurutan: tag pertama mendefinisikan `$nama`, tag kedua mengeksekusi `echo` yang menyisipkan nilai `Budi`. **Masalah keamanan:** `$nama` dipakai langsung tanpa `htmlspecialchars()` — jika suatu hari nilainya berasal dari user, ini celah XSS. Perbaikan:

```php
<?php $nama = "Budi"; ?>
<?= htmlspecialchars($nama) ?> adalah anggota.
```

> **Pembahasan:** Meski sekarang inputnya statis, aturan zero-XSS menuntut escape pada *setiap* output. Dengan `htmlspecialchars()`, karakter seperti `<`, `>`, `"` pada nilai `$nama` tidak akan dieksekusi sebagai HTML/JS.
