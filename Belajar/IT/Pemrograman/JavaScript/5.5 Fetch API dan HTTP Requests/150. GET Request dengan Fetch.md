### Definisi Singkat
GET request adalah method HTTP default dari `fetch()` — digunakan untuk **mengambil data** dari server. Tidak perlu menentukan method secara eksplisit, cukup URL. Data dikirim melalui query string, bukan body.

---

### Analogi
Kamu melihat menu digital di restoran. Kamu cukup **melihat (GET)** daftar menu — tidak perlu isi formulir atau kirim data. Server hanya mengirimkan data yang kamu minta tanpa mengubah apa pun.

---

### Poin-Poin Penting
- `fetch(url)` tanpa opsi kedua otomatis GET.
- Data dikirim via **query parameters** pada URL (`?key=value&key2=value2`).
- GET request seharusnya **idempotent** — tidak mengubah data di server.
- Response bisa berupa JSON, text, atau format lain.

---

### Contoh Implementasi

```javascript
// GET request — dasar
fetch('https://jsonplaceholder.typicode.com/posts')
  .then(res => {
    if (!res.ok) throw new Error('Status: ' + res.status);
    return res.json();
  })
  .then(posts => console.log(posts))
  .catch(err => console.error(err));
```

GET dengan query parameters:

```javascript
// Manual query string
const userId = 1;
fetch(`https://jsonplaceholder.typicode.com/posts?userId=${userId}`)
  .then(res => res.json())
  .then(posts => console.log('Posts user:', posts));

// Menggunakan URLSearchParams
const params = new URLSearchParams({
  userId: 1,
  _limit: 5,
  _sort: 'id',
  _order: 'desc'
});

fetch(`https://jsonplaceholder.typicode.com/posts?${params}`)
  .then(res => res.json())
  .then(posts => console.log(posts));
```

GET dengan async/await:

```javascript
async function getPost(id) {
  try {
    const res = await fetch(`https://jsonplaceholder.typicode.com/posts/${id}`);
    if (!res.ok) throw new Error('Post tidak ditemukan');
    const post = await res.json();
    return post;
  } catch (err) {
    console.error(err);
    return null;
  }
}

const post = await getPost(1);
console.log(post);
```

GET dengan headers (misal Authorization):

```javascript
fetch('https://api.github.com/user', {
  headers: {
    'Authorization': 'Bearer token_anda',
    'Accept': 'application/json'
  }
})
  .then(res => res.json())
  .then(data => console.log(data));
```

---

### Koneksi
GET adalah method HTTP paling dasar dan paling sering digunakan. Setelah menguasai GET, lanjut ke method lain seperti **POST, PUT, DELETE** untuk mengirim dan memodifikasi data di server.
