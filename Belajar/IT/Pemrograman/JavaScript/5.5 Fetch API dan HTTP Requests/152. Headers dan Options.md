### Definisi Singkat
Headers dan Options adalah parameter kedua dari `fetch()` yang memungkinkan konfigurasi request secara detail — seperti method HTTP, headers kustom, mode CORS, credentials, cache, dan lainnya.

---

### Analogi
Kamu kirim paket lewat ekspedisi. Selain isi paket, kamu bisa atur:
- **Headers**: Stiker "Fragile" atau "This Side Up" — informasi tambahan tentang paket.
- **Options**: Pilih ekspedisi (regular/express/COD) — cara paket dikirim.

---

### Poin-Poin Penting
- Object options berisi properti seperti `method`, `headers`, `body`, `mode`, `credentials`, `cache`, `signal`, dll.
- Headers bisa dikirim sebagai objek literal atau menggunakan `new Headers()`.
- **Mode**: `cors` (default), `no-cors`, `same-origin`, `navigate`.
- **Credentials**: `same-origin` (default), `include`, `omit`.
- **Cache**: `default`, `no-cache`, `reload`, `force-cache`, `only-if-cached`.
- Beberapa header tertentu (seperti `Cookie`) tidak bisa di-set manual untuk keamanan.

---

### Contoh Implementasi

**Mengirim headers (object literal):**

```javascript
fetch('https://api.example.com/data', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer eyJhbGciOiJIUzI1NiIs...',
    'Accept': 'application/json',
    'X-Custom-Header': 'custom-value'
  }
});
```

**Menggunakan Headers API:**

```javascript
const headers = new Headers();
headers.append('Content-Type', 'application/json');
headers.append('Authorization', 'Bearer token123');
headers.set('X-Request-ID', 'abc-123');

fetch('https://api.example.com/data', {
  method: 'POST',
  headers: headers,
  body: JSON.stringify({ name: 'Andi' })
});
```

**Opsi lengkap fetch:**

```javascript
fetch('https://api.example.com/data', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ key: 'value' }),
  mode: 'cors',           // cors, no-cors, same-origin
  credentials: 'include', // include, same-origin, omit
  cache: 'no-cache',      // default, no-cache, reload, force-cache
  redirect: 'follow',     // follow, error, manual
  referrerPolicy: 'strict-origin-when-cross-origin'
});
```

**Membaca response headers:**

```javascript
fetch('https://api.github.com/users/octocat')
  .then(res => {
    console.log('Content-Type:', res.headers.get('content-type'));
    console.log('Rate Limit:', res.headers.get('x-ratelimit-remaining'));

    // Iterasi semua headers
    res.headers.forEach((value, key) => {
      console.log(`${key}: ${value}`);
    });
    return res.json();
  });
```

---

### Koneksi
Headers digunakan untuk **autentikasi**, **content negotiation**, dan metadata request. Options mengontrol **keamanan** (CORS, credentials) dan **perilaku caching**. Pelajari **Error Handling** dan **AbortController** untuk request yang lebih robust.
