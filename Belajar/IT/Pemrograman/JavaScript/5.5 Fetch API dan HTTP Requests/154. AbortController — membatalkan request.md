### Definisi Singkat
`AbortController` adalah API untuk **membatalkan** fetch request yang sedang berlangsung. Dengan `AbortController.signal` yang dikirim ke opsi fetch, request bisa dibatalkan kapan saja via `controller.abort()`, menyebabkan fetch Promise menjadi rejected dengan `AbortError`.

---

### Analogi
Kamu pesan ojek online. Saat menunggu driver datang, tiba-tiba kamu dapat tumpangan dari teman. Kamu **batalkan (abort)** pesanan ojek — driver dibatalkan, request dihentikan. Kamu tidak perlu menunggu driver sampai tujuan untuk memberi tahu.

---

### Poin-Poin Penting
- Buat `new AbortController()` — dapatkan `controller.signal`.
- Kirim `signal` ke opsi fetch: `fetch(url, { signal: controller.signal })`.
- Panggil `controller.abort()` untuk membatalkan.
- Abort menyebabkan Promise fetch rejected dengan `DOMException` nama `AbortError`.
- Satu controller bisa digunakan untuk **membatalkan banyak request** sekaligus.

---

### Contoh Implementasi

**Membatalkan satu request:**

```javascript
const controller = new AbortController();
const signal = controller.signal;

// Mulai fetch
fetch('https://jsonplaceholder.typicode.com/posts', { signal })
  .then(res => res.json())
  .then(data => console.log('Data:', data))
  .catch(err => {
    if (err.name === 'AbortError') {
      console.log('Request dibatalkan oleh user');
    } else {
      console.error('Error lain:', err);
    }
  });

// Batalkan setelah 100ms (simulasi user cancel)
setTimeout(() => {
  controller.abort();
  console.log('Abort dipanggil');
}, 100);
```

**Timeout dengan AbortController:**

```javascript
async function fetchWithTimeout(url, timeoutMs = 5000) {
  const controller = new AbortController();
  const timeoutId = setTimeout(() => controller.abort(), timeoutMs);

  try {
    const response = await fetch(url, { signal: controller.signal });
    clearTimeout(timeoutId);
    return await response.json();
  } catch (err) {
    clearTimeout(timeoutId);
    if (err.name === 'AbortError') {
      throw new Error('Request timeout setelah ' + timeoutMs + 'ms');
    }
    throw err;
  }
}

// Usage
try {
  const data = await fetchWithTimeout('https://api.example.com/data', 3000);
  console.log(data);
} catch (err) {
  console.error(err.message);
}
```

**Membatalkan banyak request sekaligus:**

```javascript
const controller = new AbortController();
const signal = controller.signal;

// Mulai beberapa request paralel
const requests = [
  fetch('/api/users', { signal }),
  fetch('/api/posts', { signal }),
  fetch('/api/comments', { signal })
];

// Jika user meninggalkan halaman, batalkan semua
document.getElementById('cancelBtn').addEventListener('click', () => {
  controller.abort();
});

Promise.allSettled(requests)
  .then(results => {
    results.forEach((r, i) => {
      if (r.status === 'fulfilled') console.log(`Request ${i} sukses`);
      else if (r.reason?.name === 'AbortError') console.log(`Request ${i} dibatalkan`);
    });
  });
```

**Deteksi apakah sudah di-abort:**

```javascript
const controller = new AbortController();
console.log(controller.signal.aborted); // false
controller.abort();
console.log(controller.signal.aborted); // true
```

---

### Koneksi
AbortController penting untuk **user experience** — membatalkan request saat user navigasi, mengulang pencarian, atau timeout. Ini mencegah resource terbuang dan race condition. Lanjut ke **FormData dan File Upload** untuk pengiriman data formulir dan file.
