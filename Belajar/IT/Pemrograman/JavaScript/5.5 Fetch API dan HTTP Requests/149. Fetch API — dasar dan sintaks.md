### Definisi Singkat
Fetch API adalah antarmuka bawaan JavaScript modern untuk membuat HTTP request secara asynchronous. `fetch()` mengembalikan **Promise** yang resolve ke objek `Response` — memberikan akses ke status, header, dan body response.

---

### Analogi
Kamu kirim utusan ke perpustakaan dengan surat permintaan (request). Utusan pergi, dan kamu melanjutkan aktivitas lain. Saat utusan kembali, dia membawa amplop (Response) yang berisi informasi status ("buku tersedia/tidak"), header metadata, dan isi buku (body).

---

### Poin-Poin Penting
- `fetch(url, options)` — argumen pertama URL, kedua opsional (method, headers, body, dll).
- Mengembalikan Promise yang resolve ke objek **Response**.
- Response memiliki properti: `status`, `ok`, `headers`, `body`.
- Untuk membaca body: `response.json()`, `response.text()`, `response.blob()`, dll.
- Fetch **hanya reject** jika terjadi network error — HTTP 404/500 tetap dianggap success (`response.ok` = false).

---

### Contoh Implementasi

```javascript
// Fetch dasar — GET request
fetch('https://api.example.com/users')
  .then(response => {
    if (!response.ok) {
      throw new Error('HTTP error: ' + response.status);
    }
    return response.json();
  })
  .then(data => console.log(data))
  .catch(err => console.error('Network error:', err));
```

Dengan async/await:

```javascript
async function getUsers() {
  try {
    const response = await fetch('https://api.example.com/users');
    if (!response.ok) throw new Error('HTTP ' + response.status);
    const data = await response.json();
    return data;
  } catch (err) {
    console.error('Request gagal:', err);
  }
}
```

Method response lainnya:

```javascript
const response = await fetch('/api/data');

const text = await response.text();     // string
const json = await response.json();     // object
const blob = await response.blob();     // binary data
const formData = await response.formData(); // FormData
const buffer = await response.arrayBuffer(); // ArrayBuffer
```

---

### Koneksi
Fetch API adalah fondasi komunikasi HTTP modern di JavaScript — pengganti `XMLHttpRequest`. Setelah menguasai dasar fetch, pelajari berbagai method HTTP (GET, POST, PUT, DELETE), headers, error handling, dan cancellation.
