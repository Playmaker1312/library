### Definisi Singkat

**WebRTC (Web Real-Time Communication)** adalah protokol dan API yang memungkinkan komunikasi **peer-to-peer** real-time antara browser — tanpa server perantara untuk data media. Digunakan untuk video call, audio call, dan berbagi file P2P. WebRTC menggunakan **STUN/TURN** server untuk konektivitas.

---

### Analogi

Seperti **dua orang yang berbicara langsung** tanpa telepon — mereka bisa saling melihat dan mendengar secara langsung (P2P). Tetapi mereka perlu **saling mengetahui alamat** rumah masing-masing (signaling via server), dan jika tembok menghalangi (NAT/firewall), mereka butuh **pos polisi** (TURN server) untuk meneruskan suara.

---

### Poin-Poin Penting

- **`MediaStream` (getUserMedia)**: Akses kamera dan mikrofon.
- **`RTCPeerConnection`**: Koneksi P2P — mengelola encoding, decoding, dan adaptasi bitrate.
- **`RTCDataChannel`**: Data channel P2P untuk file/text (bukan media).
- **Signaling**: Proses pertukaran SDP (Session Description) via server (WebSocket/polling) — WebRTC tidak mendefinisikan protokol signaling.
- **STUN**: Server untuk menemukan IP publik dan port (NAT traversal).
- **TURN**: Relay server jika koneksi P2P gagal (karena firewall simetris).
- **ICE (Interactive Connectivity Establishment)**: Menemukan jalur komunikasi terbaik.
- **Secure**: WebRTC mewajibkan enkripsi (DTLS/SRTP).

### Contoh Implementasi

```javascript
// 1. Akses kamera/mikrofon
async function startCamera() {
  try {
    const stream = await navigator.mediaDevices.getUserMedia({
      video: true,
      audio: true,
    });
    const video = document.getElementById('localVideo');
    video.srcObject = stream;
    return stream;
  } catch (err) {
    console.error('Gagal akses media:', err);
  }
}

// 2. Membuat koneksi P2P (sederhana)
const configuration = {
  iceServers: [
    { urls: 'stun:stun.l.google.com:19302' },
    { urls: 'turn:turn.example.com', username: 'user', credential: 'pass' },
  ],
};

const peerConnection = new RTCPeerConnection(configuration);

// 3. Menambahkan stream ke koneksi
localStream.getTracks().forEach((track) => {
  peerConnection.addTrack(track, localStream);
});

// 4. Membuat offer (oleh inisiator)
async function createOffer() {
  const offer = await peerConnection.createOffer();
  await peerConnection.setLocalDescription(offer);
  // Kirim offer ke peer lain via signaling server (WebSocket)
  signalingServer.send(JSON.stringify({ type: 'offer', sdp: offer }));
}

// 5. Menerima offer dan membuat answer (oleh penerima)
peerConnection.onicecandidate = (event) => {
  if (event.candidate) {
    signalingServer.send(JSON.stringify({ type: 'candidate', candidate: event.candidate }));
  }
};

peerConnection.ontrack = (event) => {
  const video = document.getElementById('remoteVideo');
  video.srcObject = event.streams[0];
};
```

### Koneksi

Berkaitan dengan **WebSocket** (signaling untuk WebRTC), **Service Workers** (integrasi PWA + WebRTC), **Media APIs** (getUserMedia), **Web Workers** (pengolahan stream), dan **Peer-to-Peer** (konsep jaringan).
