### Definisi Singkat
Node types adalah klasifikasi setiap simpul dalam DOM tree. Ada 12 tipe node, tetapi yang paling umum adalah **element node** (1), **text node** (3), dan **comment node** (8). Setiap node memiliki properti `nodeType` dan `nodeName`.

---

### Analogi
Bayangkan DOM seperti **surat kabar**. Element node adalah **judul artikel** (punya struktur), text node adalah **isi tulisannya** (konten), dan comment node adalah **catatan editor** (tidak tampil di publik).

---

### Poin-Poin Penting
- `Node.ELEMENT_NODE` (1) — elemen HTML seperti `<div>`, `<p>`, `<span>`
- `Node.TEXT_NODE` (3) — teks di dalam elemen (termasuk spasi dan newline)
- `Node.COMMENT_NODE` (8) — komentar HTML `<!-- ... -->`
- Gunakan `nodeType` untuk mengecek tipe node
- Whitespace di HTML juga dianggap text node

---

### Contoh Implementasi

```javascript
const body = document.body;

body.childNodes.forEach(node => {
  switch (node.nodeType) {
    case Node.ELEMENT_NODE:
      console.log('Element:', node.nodeName);
      break;
    case Node.TEXT_NODE:
      console.log('Text:', node.textContent.trim());
      break;
    case Node.COMMENT_NODE:
      console.log('Comment:', node.textContent);
      break;
    default:
      console.log('Tipe lain:', node.nodeType);
  }
});
```

### Koneksi
- **156 →** DOM tree terdiri dari berbagai node types
- **162 →** Navigasi DOM memanfaatkan properti seperti `childNodes`
- **164 →** `textContent` membaca text node di dalam elemen
