### Definisi Singkat
`getElementById()` adalah method pada `document` yang mengembalikan satu elemen berdasarkan nilai atribut `id`. Karena ID harus unik dalam satu halaman, method ini selalu mengembalikan satu elemen (atau `null` jika tidak ditemukan).

---

### Analogi
`getElementById` seperti **NIK (Nomor Induk Kependudukan)**. Setiap warga punya NIK unik. Kamu bisa langsung menemukan satu orang tertentu tanpa perlu mencari di antara banyak orang.

---

### Poin-Poin Penting
- Hanya tersedia di `document`, bukan di element biasa
- Mengembalikan `null` jika ID tidak ditemukan
- Case-sensitive — `"Main"` berbeda dengan `"main"`
- ID harus unik dalam satu halaman HTML
- Performa sangat cepat karena browser mengoptimasi pencarian ID

---

### Contoh Implementasi

```javascript
// HTML: <div id="header">...</div>
const header = document.getElementById('header');

if (header) {
  console.log('Elemen ditemukan:', header);
  header.style.backgroundColor = 'lightblue';
} else {
  console.log('Elemen tidak ditemukan');
}

// Mengubah konten
const judul = document.getElementById('judul');
if (judul) judul.textContent = 'Judul Baru';
```
