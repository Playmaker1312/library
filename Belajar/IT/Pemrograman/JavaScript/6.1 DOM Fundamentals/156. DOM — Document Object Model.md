### Definisi Singkat
DOM (Document Object Model) adalah representasi terstruktur dari dokumen HTML/XML dalam bentuk tree (pohon) yang memungkinkan JavaScript berinteraksi dan memanipulasi konten, struktur, dan style halaman web.

--- 

### Analogi
DOM seperti **pohon keluarga**. Setiap elemen HTML adalah anggota keluarga — ada induk (parent), anak (child), dan saudara (sibling). Jika kamu ingin mengubah nama salah satu anggota, kamu harus tahu di mana posisinya di pohon keluarga tersebut.

---

### Poin-Poin Penting
- DOM bukan bagian dari JavaScript, melainkan Web API yang disediakan browser
- Setiap node dalam DOM tree merepresentasikan elemen, teks, atau komentar
- DOM bersifat live — perubahan akan langsung terlihat di halaman
- DOM tree dimulai dari `document` (root) lalu bercabang ke `<html>`, `<head>`, `<body>`, dst.

---

### Contoh Implementasi

```javascript
// Melihat struktur DOM dari elemen body
console.log(document.body);

// Mengecek jumlah child nodes dari body
console.log(document.body.childNodes.length);

// Mengubah konten elemen pertama di halaman
document.body.children[0].textContent = 'Halo dari DOM!';
```
