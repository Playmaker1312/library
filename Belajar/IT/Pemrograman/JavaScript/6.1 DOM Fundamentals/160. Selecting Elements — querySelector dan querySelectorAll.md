### Definisi Singkat
`querySelector()` dan `querySelectorAll()` adalah method untuk memilih elemen DOM menggunakan **CSS selector**. `querySelector()` mengembalikan elemen pertama yang cocok, sedangkan `querySelectorAll()` mengembalikan **NodeList** statis berisi semua elemen yang cocok.

---

### Analogi
Seperti **mesin pencari Google**. Kamu bisa mencari dengan kata kunci spesifik — `querySelector` seperti "I'm Feeling Lucky" (ambil hasil pertama), `querySelectorAll` seperti hasil pencarian biasa (ambil semua).

---

### Poin-Poin Penting
- Menerima CSS selector sebagai string (`.class`, `#id`, `div > p`, dll)
- `querySelector()` mengembalikan `null` jika tidak ada yang cocok
- `querySelectorAll()` mengembalikan NodeList (kosong jika tak ada cocok)
- Bisa dipanggil dari element (tidak hanya document) — pencarian terbatas dalam subtree
- NodeList dari `querySelectorAll` bersifat **static** (tidak live)

---

### Contoh Implementasi

```javascript
// Single element
const nav = document.querySelector('nav#navbar');
const firstBtn = document.querySelector('.btn-primary');

// Multiple elements
const allButtons = document.querySelectorAll('button');
const items = document.querySelectorAll('ul.list > li');

// Dari parent element tertentu
const container = document.getElementById('konten');
const paragraphs = container.querySelectorAll('p');

// Iterasi NodeList
allButtons.forEach(btn => {
  btn.addEventListener('click', () => alert('Diklik!'));
});

// Konversi ke array
const btnArray = [...allButtons];
```
