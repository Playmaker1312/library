### Definisi Singkat
`document` adalah objek global bawaan browser yang menjadi entry point utama untuk mengakses dan memanipulasi DOM. Melalui `document`, kita bisa mencari elemen, membuat elemen baru, mengubah struktur halaman, dan banyak lagi.

---

### Analogi
`document` seperti **pintu utama** sebuah rumah. Semua aktivitas di dalam rumah (mengubah dekorasi, menata perabot) harus dimulai dari pintu ini. Tanpa `document`, kamu tidak bisa masuk ke DOM.

---

### Poin-Poin Penting
- `document` adalah instance dari `Document` class
- Merupakan root dari DOM tree
- Bukan bagian dari JavaScript — disediakan oleh browser (Web API)
- Properti penting: `document.head`, `document.body`, `document.title`, `document.URL`, `document.cookie`
- Method penting: `getElementById()`, `querySelector()`, `createElement()`, `write()`

---

### Contoh Implementasi

```javascript
// Informasi dokumen
console.log(document.title);       // Judul halaman
console.log(document.URL);         // URL saat ini
console.log(document.lastModified); // Terakhir diubah

// Mengubah judul halaman
document.title = 'Halaman Baru';

// Mengecek jumlah elemen
console.log(document.all.length);   // Total elemen (usang, hindari)
console.log(document.forms.length); // Jumlah form
console.log(document.links.length); // Jumlah link
```
