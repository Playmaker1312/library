### Definisi Singkat

Parameter adalah variabel yang didefinisikan dalam deklarasi fungsi sebagai tempat penampung input. Arguments adalah nilai nyata yang diberikan (diteruskan) ke dalam fungsi saat fungsi dipanggil.

---

### Analogi

Bayangkan sebuah **mesin pembuat kopi**:

- **Parameter** adalah **tempat bubuk kopi** pada mesin — slot yang dirancang untuk menerima kopi.
- **Arguments** adalah **bubuk kopi** yang dimasukkan ke dalam slot tersebut saat mesin digunakan.

Mesin menentukan bentuk slotnya (parameter), dan pengguna memberikan isinya (argument).

---

### Poin-Poin Penting

- **Parameter** ditulis saat mendefinisikan fungsi: `function tambah(a, b)` — `a` dan `b` adalah parameter.
- **Arguments** ditulis saat memanggil fungsi: `tambah(3, 5)` — `3` dan `5` adalah arguments.
- Parameter bersifat opsional — jika argument tidak diberikan, nilainya `undefined`.
- Jumlah argument bisa berbeda dari jumlah parameter — kelebihan argument diabaikan, kekurangan argument menjadi `undefined`.
- Parameter memiliki sifat _pass-by-value_ untuk primitif dan _pass-by-reference_ (sebenarnya nilai referensi) untuk objek.

---

### Contoh Implementasi

```javascript
// Definisi: a dan b adalah parameter
function jumlahkan(a, b) {
    console.log("Parameter a:", a);
    console.log("Parameter b:", b);
    return a + b;
}

// Pemanggilan: 10 dan 20 adalah arguments
console.log(jumlahkan(10, 20)); // 30

// Argument kurang — parameter b menjadi undefined
console.log(jumlahkan(5)); // NaN (5 + undefined)

// Argument lebih — kelebihan diabaikan
console.log(jumlahkan(1, 2, 3, 4)); // 3 (hanya dua argument pertama yang dipakai)
```

---

### Koneksi

Konsep parameter dan argument menjadi dasar untuk topik **default parameters**, **rest parameters** (`...args`), dan **arguments object**. Pemahaman ini krusial dalam penulisan fungsi yang fleksibel dan reusable di JavaScript.
