### Definisi Singkat

Arrow function dan regular function (function declaration/expression) memiliki perbedaan fundamental dalam hal binding `this`, ketersediaan `arguments` object, kemampuan sebagai constructor, dan cara mereka menangani konteks eksekusi.

---

### Analogi

- **Regular function:** Seperti **aktor panggung** yang karakternya berubah tergantung panggung tempat ia tampil (`this` tergantung bagaimana fungsi dipanggil).
- **Arrow function:** Seperti **bayangan aktor** yang selalu melekat pada aktor aslinya — tidak bisa lepas dari induknya (`this` selalu dari lingkup induk/lexical scope).

---

### Poin-Poin Penting

| Aspek | Regular Function | Arrow Function |
|-------|-----------------|----------------|
| `this` binding | Dinamis (tergantung cara panggil) | Lexical (mengikuti scope induk) |
| `arguments` object | Tersedia | Tidak tersedia |
| Constructor (`new`) | Bisa | Tidak bisa (error) |
| `prototype` property | Ada | Tidak ada |
| Method syntax | `obj.method()` | Tidak disarankan untuk method objek |
| `call`, `apply`, `bind` | Bisa mengubah `this` | `this` tetap (tidak terpengaruh) |
| Hoisting | Declaration di-hoist | Tidak di-hoist |

---

### Contoh Implementasi

```javascript
// Perbedaan this binding
const obj = {
    nama: "Budi",
    regular: function() {
        console.log(this.nama); // "Budi" — this mengacu ke obj
    },
    arrow: () => {
        console.log(this.nama); // undefined — this dari global scope
    }
};
obj.regular(); // "Budi"
obj.arrow();   // undefined

// Arrow function tidak bisa constructor
function Regular(nama) {
    this.nama = nama;
}
const Arrow = (nama) => {
    this.nama = nama;
};
const r = new Regular("Budi"); // OK
// const a = new Arrow("Budi"); // TypeError: Arrow is not a constructor

// arguments object
function regularFunc() {
    console.log(arguments[0]); // "a"
}
regularFunc("a");
const arrowFunc = () => {
    // console.log(arguments); // ReferenceError
};

// call/apply/bind pada arrow function
function regularF() { console.log(this.nama); }
const arrowF = () => { console.log(this.nama); };
regularF.call({ nama: "Budi" }); // "Budi"
arrowF.call({ nama: "Budi" });   // undefined (this tetap global)
```

---

### Koneksi

Pemahaman perbedaan ini krusial saat bekerja dengan **OOP JavaScript**, **event handlers**, **method object**, **callback asynchronous**, dan **functional programming**. Salah memilih jenis fungsi bisa menyebabkan bug `this` yang sulit dilacak.
