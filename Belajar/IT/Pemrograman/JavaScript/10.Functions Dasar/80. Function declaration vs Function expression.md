### Definisi Singkat

Function declaration dan function expression adalah dua cara utama untuk mendefinisikan fungsi di JavaScript. Perbedaan utamanya terletak pada hoisting — function declaration di-hoisting ke atas scope sehingga bisa dipanggil sebelum definisinya, sedangkan function expression tidak.

---

### Analogi

- **Function declaration:** Seperti buku yang sudah diletakkan di rak perpustakaan sebelum perpustakaan dibuka — siap digunakan kapan saja.
- **Function expression:** Seperti buku yang baru akan diletakkan di rak setelah perintah meletakkan diberikan — tidak bisa diakses sebelum proses itu selesai.

---

### Poin-Poin Penting

- **Function declaration** menggunakan kata kunci `function` diikuti nama fungsi, bisa dipanggil sebelum baris definisinya karena hoisting.
- **Function expression** menyimpan fungsi ke dalam variabel — bisa menggunakan `var`, `let`, atau `const`. Jika `var`, variabel di-hoisting tapi nilainya `undefined`; jika `let`/`const`, masuk Temporal Dead Zone.
- Function expression bisa bersifat anonym (tanpa nama) atau named (dengan nama).
- Arrow function hanyalah salah satu bentuk function expression, bukan function declaration.

---

### Contoh Implementasi

```javascript
// Function declaration
console.log(kali(3, 4)); // 12 — bisa dipanggil sebelum deklarasi

function kali(a, b) {
    return a * b;
}

// Function expression (anonymous)
const bagi = function (a, b) {
    return a / b;
};

console.log(bagi(10, 2)); // 5 — hanya bisa dipanggil setelah assignment

// Function expression (named)
const pangkat = function kuadrat(n) {
    return n * n;
};

console.log(pangkat(5)); // 25
```

---

### Koneksi

Topik ini terkait erat dengan **hoisting**, **scope**, dan **arrow function**. Memahami perbedaan declaration vs expression membantu developer memilih pendekatan yang tepat untuk organisasi kode, menghindari bug akibat hoisting, dan memahami bagaimana JavaScript engine memproses fungsi.
