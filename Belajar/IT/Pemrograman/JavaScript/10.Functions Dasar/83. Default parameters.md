### Definisi Singkat

Default parameters adalah fitur ES6 yang memungkinkan parameter fungsi memiliki nilai bawaan jika argument tidak diberikan atau bernilai `undefined` saat fungsi dipanggil.

---

### Analogi

Bayangkan **pemesanan pizza online**:

- **Parameter tanpa default:** Anda harus mengisi semua field — jika tidak diisi, muncul error.
- **Default parameter:** Ukuran pizza sudah diisi "Medium" secara otomatis. Anda hanya perlu mengubah jika ingin ukuran lain. Topping ekstra bersifat opsional dengan nilai default "Tidak ada".

---

### Poin-Poin Penting

- Default parameter hanya berlaku jika argument adalah `undefined` — tidak berlaku untuk `null` atau falsy lainnya.
- Default parameter bisa berupa nilai literal, ekspresi, atau bahkan hasil pemanggilan fungsi lain.
- Default parameter dievaluasi saat fungsi dipanggil (lazy evaluation), bukan saat didefinisikan.
- Parameter dengan default sebaiknya ditempatkan di akhir daftar parameter untuk menghindari kebingungan.
- Sebelum ES6, default parameter disimulasikan dengan operator logika `||` atau ternary.

---

### Contoh Implementasi

```javascript
// Default parameter sederhana
function sapa(nama = "Tamu") {
    return "Halo, " + nama;
}
console.log(sapa("Budi")); // "Halo, Budi"
console.log(sapa());       // "Halo, Tamu"
console.log(sapa(undefined)); // "Halo, Tamu"

// Default parameter dengan ekspresi
function hitungHarga(harga, pajak = harga * 0.1) {
    return harga + pajak;
}
console.log(hitungHarga(100));     // 110
console.log(hitungHarga(100, 20)); // 120

// Default parameter menggunakan fungsi lain
function createUser(nama, timestamp = Date.now()) {
    return { nama, timestamp };
}
console.log(createUser("Budi"));

// Default di parameter tengah (kurang ideal)
function daftar(nama, role = "user", usia) {
    return `${nama} - ${role} - ${usia}`;
}
// Harus kirim undefined untuk role agar pakai default
console.log(daftar("Budi", undefined, 20));
```

---

### Koneksi

Default parameters berkaitan erat dengan **rest parameters**, **destructuring assignment**, dan **function overloading** (meskipun JS tidak memiliki overloading sejati). Fitur ini membantu menulis fungsi yang lebih robust dan mengurangi kode validasi manual.
