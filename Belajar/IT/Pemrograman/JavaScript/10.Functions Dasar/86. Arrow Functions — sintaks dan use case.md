### Definisi Singkat

Arrow function adalah sintaks fungsi yang lebih ringkas diperkenalkan di ES6, ditulis dengan `=>` (panah). Arrow function menawarkan penulisan yang lebih pendek, implicit return untuk satu ekspresi, dan tidak memiliki binding `this` sendiri.

---

### Analogi

Bayangkan **menulis surat**:

- **Function expression (regular):** Menulis surat formal dengan kop surat, tanggal, salam pembuka, isi, dan salam penutup — panjang dan terstruktur.
- **Arrow function:** Menulis **pesan singkat (chat)** — langsung ke inti, tanpa formalitas, cepat dan padat.

---

### Poin-Poin Penting

- Sintaks: `(param) => ekspresi` atau `(param) => { statement }`
- Jika hanya satu parameter, tanda kurung bisa dihilangkan: `x => x * 2`
- Jika body hanya satu ekspresi, `return` implicit: `(a, b) => a + b`
- Jika body berupa objek literal, bungkus dengan kurung: `() => ({ nama: "Budi" })`
- Tidak memiliki `this` binding sendiri — `this` mengikuti lexical scope (dari lingkup induknya).
- Tidak memiliki `arguments` object, tidak bisa digunakan sebagai constructor (tidak punya `prototype`).

---

### Contoh Implementasi

```javascript
// Arrow function basic
const sapa = (nama) => {
    return "Halo, " + nama;
};
console.log(sapa("Budi")); // "Halo, Budi"

// Satu parameter — tanpa kurung
const kuadrat = x => x * x;
console.log(kuadrat(5)); // 25

// Implicit return — satu ekspresi
const tambah = (a, b) => a + b;
console.log(tambah(3, 4)); // 7

// Return objek literal
const buatUser = (nama, usia) => ({ nama, usia });
console.log(buatUser("Budi", 20));

// Use case: callback array
const angka = [1, 2, 3, 4, 5];
const genap = angka.filter(n => n % 2 === 0);
console.log(genap); // [2, 4]

// Use case: event listener (tanpa binding this)
const tombol = {
    label: "Kirim",
    klik: function() {
        // Arrow function mewarisi this dari fungsi klik
        setTimeout(() => {
            console.log("Tombol " + this.label + " diklik");
        }, 100);
    }
};
tombol.klik(); // "Tombol Kirim diklik"
```

---

### Koneksi

Arrow function terkait erat dengan **callback dan higher-order functions** (seperti `map`, `filter`, `reduce`), **lexical this binding**, **functional programming**, dan perbedaannya dengan **regular function** menjadi topik tersendiri yang sangat penting.
