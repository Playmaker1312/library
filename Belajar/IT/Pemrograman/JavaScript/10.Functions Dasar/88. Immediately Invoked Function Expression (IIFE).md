### Definisi Singkat

IIFE (Immediately Invoked Function Expression) adalah fungsi yang langsung dieksekusi setelah didefinisikan. Pola ini digunakan untuk menciptakan scope terisolasi, menghindari polusi global, dan menjalankan kode secara langsung tanpa perlu dipanggil terpisah.

---

### Analogi

Bayangkan **kapsul kopi sekali pakai**:

- Anda memasukkan kapsul ke mesin, dan **langsung** menyeduh kopi — tidak ada proses penyimpanan, tidak ada persiapan ulang.
- Begitu kopi jadi, kapsulnya dibuang — tidak bisa digunakan lagi.
- **IIFE** seperti kapsul itu: didefinisikan dan langsung dieksekusi, lalu selesai.

---

### Poin-Poin Penting

- Sintaks: `(function(){ ... })()` atau `(function(){ ... }())` — fungsi dibungkus kurung lalu dipanggil.
- Bisa menggunakan arrow function: `(() => { ... })()`.
- Variabel yang dideklarasikan di dalam IIFE tidak bisa diakses dari luar (scope terisolasi).
- Berguna untuk menghindari bentukan nama variabel global (global namespace pollution).
- Sebelum ES6 module, IIFE adalah pola utama untuk modularitas di JavaScript.
- Sering digunakan bersama **module pattern** untuk data privacy.
- Bisa menerima arguments seperti fungsi biasa.

---

### Contoh Implementasi

```javascript
// IIFE basic
(function() {
    const pesan = "Halo dari dalam IIFE!";
    console.log(pesan);
})(); // "Halo dari dalam IIFE!"
// console.log(pesan); // ReferenceError — tidak bisa diakses

// IIFE dengan parameter
(function(nama) {
    console.log("Halo, " + nama);
})("Budi"); // "Halo, Budi"

// IIFE dengan arrow function
(() => {
    console.log("Arrow IIFE dieksekusi!");
})();

// IIFE untuk isolasi scope
const counter = (function() {
    let count = 0;
    return {
        increment: () => ++count,
        getValue: () => count
    };
})();
console.log(counter.increment()); // 1
console.log(counter.increment()); // 2
console.log(counter.getValue());  // 2
// console.log(count); // ReferenceError

// IIFE untuk menghindari polusi global
(function() {
    const user = { nama: "Budi", role: "admin" };
    // Kode yang menggunakan user
})();
```

---

### Koneksi

IIFE terkait erat dengan **module pattern**, **closure**, **scope dan execution context**, serta **ES6 modules**. Meskipun ES6 modules kini menjadi standar, IIFE masih digunakan dalam bundler (seperti Webpack), kode legacy, dan situasi di mana scope isolasi cepat diperlukan tanpa setup module.
