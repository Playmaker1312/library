### Definisi Singkat
Class inheritance memungkinkan sebuah class (child) mewarisi properti dan method dari class lain (parent) menggunakan keyword `extends`. Keyword `super` digunakan untuk mengakses parent class.

---
### Analogi
Seperti seragam sekolah: seragam dasar (parent class) punya atasan dan bawahan. Seragam khusus jurusan IPA (child class) mewarisi seragam dasar, lalu menambahkan atribut seperti jas lab.

---
### Poin-Poin Penting
- `class Anak extends Induk { ... }` untuk inheritance
- `super()` memanggil constructor parent (harus dipanggil sebelum `this`)
- `super.methodName()` memanggil method parent
- Method di child meng-override method parent dengan nama sama
- Rantai inheritance bisa bertingkat

---
### Contoh Implementasi
```javascript
class Animal {
  constructor(name) {
    this.name = name;
  }

  breathe() {
    console.log(`${this.name} bernafas`);
  }

  sound() {
    console.log(`${this.name} membuat suara`);
  }
}

class Mamalia extends Animal {
  constructor(name, hasFur) {
    super(name); // wajib panggil parent constructor
    this.hasFur = hasFur;
  }

  // Override method
  sound() {
    console.log(`${this.name} bersuara mamalia`);
  }

  // Method baru
  feedMilk() {
    console.log(`${this.name} menyusui`);
  }
}

class Kucing extends Mamalia {
  constructor(name, breed) {
    super(name, true); // mamalia berbulu
    this.breed = breed;
  }

  // Override dengan super
  sound() {
    super.sound(); // panggil parent sound
    console.log('Meow!');
  }

  purr() {
    console.log(`${this.name} mendengkur...`);
  }
}

const kitty = new Kucing('Kitty', 'Persia');
kitty.breathe(); // "Kitty bernafas" — dari Animal
kitty.feedMilk(); // "Kitty menyusui" — dari Mamalia
kitty.purr();     // "Kitty mendengkur..." — milik sendiri
kitty.sound();
// "Kitty bersuara mamalia"
// "Meow!"
```
