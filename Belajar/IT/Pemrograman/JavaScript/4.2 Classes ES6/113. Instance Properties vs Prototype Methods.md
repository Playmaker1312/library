### Definisi Singkat
Instance properties adalah properti yang dimiliki langsung oleh setiap instance (unik per instance), sedangkan prototype methods adalah method yang didefinisikan di prototype class dan diwarisi oleh semua instance (shared).

---
### Analogi
Instance properties seperti nama dan umur setiap siswa — unik per orang. Prototype methods seperti rumus matematika yang diajarkan guru — semua siswa mengakses rumus yang sama.

---
### Poin-Poin Penting
- Instance properties: didefinisikan di `constructor` atau langsung di body class (public field)
- Prototype methods: didefinisikan di luar constructor, otomatis di prototype
- Instance properties bisa berbeda antar instance; prototype methods sama
- Method di `constructor` akan digandakan setiap instance (boros memori)
- Instance properties bisa memiliki nilai default

---
### Contoh Implementasi
```javascript
class Student {
  // Instance properties (public field)
  school = 'SMA Negeri 1'; // sama untuk semua, tapi milik instance
  grade = 10;

  constructor(name, age) {
    // Instance properties (lebih umum)
    this.name = name;
    this.age = age;
    this.createdAt = new Date();
  }

  // Method di constructor — TIDAK disarankan
  // constructor() {
  //   this.greet = function() { ... } // dibuat ulang tiap instance
  // }

  // Prototype method — shared, hemat memori
  greet() {
    console.log(`Halo, ${this.name}!`);
  }

  study() {
    console.log(`${this.name} sedang belajar`);
  }
}

const andi = new Student('Andi', 16);
const budi = new Student('Budi', 17);

// Instance properties — unik
console.log(andi.name); // "Andi"
console.log(budi.name); // "Budi"

// Public field — milik instance (di-copy, bukan di prototype)
console.log(andi.school); // "SMA Negeri 1"

// Prototype method — shared
console.log(andi.greet === budi.greet); // true

// Method milik instance sendiri vs prototype
console.log(andi.hasOwnProperty('name'));   // true
console.log(andi.hasOwnProperty('school')); // true
console.log(andi.hasOwnProperty('greet'));  // false — di prototype
```
