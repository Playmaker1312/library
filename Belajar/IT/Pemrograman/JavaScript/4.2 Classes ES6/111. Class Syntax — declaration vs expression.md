### Definisi Singkat
Class dapat didefinisikan dengan dua cara: **class declaration** (menggunakan keyword `class` diikuti nama) dan **class expression** (class disimpan dalam variabel). Keduanya menghasilkan fungsi constructor di belakang layar.

---
### Analogi
Class declaration seperti memberi nama resmi pada resep kue; class expression seperti menulis resep langsung di buku catatan tanpa judul khusus.

---
### Poin-Poin Penting
- Class declaration: `class Nama { ... }` — harus dideklarasikan sebelum digunakan (tidak di-hoist)
- Class expression: `const Nama = class { ... }` — bisa dengan nama (named) atau tanpa (anonymous)
- Class expression bisa diberi nama internal untuk referensi di dalam class
- Keduanya adalah syntactic sugar atas prototype-based inheritance

---
### Contoh Implementasi
```javascript
// Class Declaration
class Person {
  constructor(name) {
    this.name = name;
  }
  greet() {
    console.log(`Halo, ${this.name}`);
  }
}

// Class Expression — anonymous
const Animal = class {
  constructor(type) {
    this.type = type;
  }
  speak() {
    console.log(`${this.type} bersuara`);
  }
};

// Class Expression — named (nama internal)
const Mobil = class Kendaraan {
  constructor(merk) {
    this.merk = merk;
  }
  info() {
    console.log(`Mobil ${this.merk}`);
    console.log(typeof Kendaraan); // function (hanya visible di dalam class)
  }
};

const honda = new Mobil('Honda');
honda.info(); // "Mobil Honda"

// Perbedaan: class declaration tidak di-hoist
try {
  const x = new Salah(); // ReferenceError
  class Salah {}
} catch (e) {
  console.log('Class tidak di-hoist!');
}
```
