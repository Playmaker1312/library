### Definisi Singkat
`instanceof` adalah operator binary yang mengecek apakah suatu objek merupakan instance dari class/constructor function tertentu dengan memeriksa prototype chain.

---
### Analogi
Seperti mengecek KTP seseorang: Anda bisa tahu apakah seseorang warga negara Indonesia (instanceof Indonesia) dengan menelusuri silsilah keluarganya (prototype chain).

---
### Poin-Poin Penting
- Sintaks: `object instanceof Constructor`
- Mengecek prototype chain, bukan class itu sendiri
- Mengembalikan `true` jika Constructor.prototype ada di prototype chain object
- Berguna untuk type checking dan validasi
- Bisa mengecoh jika prototype chain dimanipulasi

---
### Contoh Implementasi
```javascript
class Animal {}
class Mamalia extends Animal {}
class Kucing extends Mamalia {}

const kitty = new Kucing();
const dog = new Mamalia();

console.log(kitty instanceof Kucing);   // true
console.log(kitty instanceof Mamalia);  // true (dari parent)
console.log(kitty instanceof Animal);   // true (dari grandparent)
console.log(kitty instanceof Object);   // true (semua objek)
console.log(kitty instanceof Array);    // false

console.log(dog instanceof Kucing);     // false

// Dengan constructor function
function Person(name) {
  this.name = name;
}
const andi = new Person('Andi');
console.log(andi instanceof Person); // true
console.log(andi instanceof Object); // true

// instanceof dengan prototype dimanipulasi
const obj = {};
console.log(obj instanceof Array); // false
Object.setPrototypeOf(obj, Array.prototype);
console.log(obj instanceof Array); // true — chain dimanipulasi

// instanceof untuk type checking array
const arr = [1, 2, 3];
console.log(arr instanceof Array);  // true
console.log(Array.isArray(arr));    // true (lebih aman)
```
