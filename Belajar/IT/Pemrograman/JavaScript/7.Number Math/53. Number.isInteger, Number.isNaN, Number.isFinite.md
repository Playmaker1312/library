### Definisi Singkat

**Number.isInteger**, **Number.isNaN**, dan **Number.isFinite** adalah method statis dari object Number di JavaScript yang digunakan untuk memeriksa tipe dan validitas angka. Ini adalah versi **lebih ketat** dibanding operator atau fungsi global sebelumnya.

---

### Analogi

Bayangkan Anda adalah penjaga pintu klub bilangan:

- **Number.isInteger:** Hanya mengizinkan masuk bilangan bulat (1, 2, 3...). Yang berkoma seperti 3.14 ditolak.
- **Number.isNaN:** Mengecek apakah yang datang adalah "bukan angka" (NaN). Hanya NaN yang diakui.
- **Number.isFinite:** Mengecek apakah yang datang adalah angka terbatas (bukan Infinity, bukan NaN).

---

### Poin-Poin Penting

- **Number.isInteger(value):** Mengembalikan 	rue jika alue adalah integer.
- **Number.isNaN(value):** Mengembalikan 	rue hanya jika alue benar-benar NaN. Lebih akurat daripada isNaN() global yang melakukan konversi paksa.
- **Number.isFinite(value):** Mengembalikan 	rue jika alue adalah angka terbatas. Berbeda dengan isFinite() global.
- Semua method ini **tidak melakukan type coercion** — jika nilai bukan number, hasilnya alse.

---

### Contoh Implementasi

`javascript
// Number.isInteger
console.log(Number.isInteger(42));      // true
console.log(Number.isInteger(3.14));    // false
console.log(Number.isInteger("42"));    // false (string)
console.log(Number.isInteger(0));       // true

// Number.isNaN vs isNaN global
console.log(Number.isNaN(NaN));         // true
console.log(Number.isNaN("Halo"));      // false (tidak coercion)
console.log(isNaN("Halo"));             // true (coercion dulu)

// Number.isFinite
console.log(Number.isFinite(100));      // true
console.log(Number.isFinite(Infinity)); // false
console.log(Number.isFinite(-Infinity));// false
console.log(Number.isFinite(NaN));      // false
console.log(Number.isFinite("100"));    // false (string)
`

---

### Koneksi

Method ini sering digunakan untuk **validasi input** setelah parsing menggunakan parseInt/parseFloat (materi 52). Juga berkaitan dengan **NaN dan Infinity** (materi 54) sebagai nilai spesial yang perlu diidentifikasi.
