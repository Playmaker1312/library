### Definisi Singkat

**Math methods** lainnya di JavaScript mencakup fungsi matematika tambahan seperti Math.max, Math.min, Math.pow, Math.sqrt, dan Math.abs — digunakan untuk mencari nilai maksimum/minimum, perpangkatan, akar kuadrat, dan nilai mutlak.

---

### Analogi

- **Math.max:** Mencari siswa dengan nilai tertinggi di kelas.
- **Math.min:** Mencari siswa dengan nilai terendah di kelas.
- **Math.pow:** Seperti mesin pengganda — 2 pangkat 3 = 2 × 2 × 2.
- **Math.sqrt:** Sebaliknya — akar 25 = 5, karena 5 × 5 = 25.
- **Math.abs:** Seperti mengukur jarak — tidak peduli arah, yang diukur hanya besarnya.

---

### Poin-Poin Penting

- **Math.max(a, b, ...):** Mengembalikan nilai terbesar dari argumen.
- **Math.min(a, b, ...):** Mengembalikan nilai terkecil dari argumen.
- **Math.pow(base, exponent):** Mengembalikan ase pangkat exponent. Alternatif: operator **.
- **Math.sqrt(x):** Mengembalikan akar kuadrat dari x. Untuk bilangan negatif hasilnya NaN.
- **Math.abs(x):** Mengembalikan nilai absolut (positif) dari x.
- Untuk array, gunakan spread operator: Math.max(...arr).

---

### Contoh Implementasi

`javascript
// Math.max dan Math.min
console.log(Math.max(5, 10, 3));   // 10
console.log(Math.min(5, 10, 3));   // 3

// Dengan array
const angka = [4, 7, 1, 9, 2];
console.log(Math.max(...angka));   // 9
console.log(Math.min(...angka));   // 1

// Math.pow
console.log(Math.pow(2, 3));       // 8
console.log(Math.pow(5, 2));       // 25
console.log(Math.pow(10, -1));     // 0.1

// Alternatif operator **
console.log(2 ** 3);               // 8

// Math.sqrt
console.log(Math.sqrt(25));        // 5
console.log(Math.sqrt(2));         // 1.414...
console.log(Math.sqrt(-1));        // NaN

// Math.abs
console.log(Math.abs(-5));         // 5
console.log(Math.abs(5));          // 5
console.log(Math.abs(-3.14));      // 3.14
`

---

### Koneksi

Method ini sering digunakan bersama **Math.random** (materi 55) untuk menghasilkan angka acak dalam rentang tertentu. Math.abs berguna untuk menghitung **jarak** atau **selisih absolut** antara dua nilai.
