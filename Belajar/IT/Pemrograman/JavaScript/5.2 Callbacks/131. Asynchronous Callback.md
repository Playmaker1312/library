### Definisi Singkat
Asynchronous callback adalah callback yang tidak langsung dieksekusi, melainkan dijadwalkan untuk dijalankan nanti setelah operasi tertentu selesai. Callback ini memanfaatkan event loop dan tidak memblokir eksekusi kode di bawahnya.

---

### Analogi
Kamu mendaftar paket notifikasi di aplikasi ojek online. Kamu tidak perlu terus-menerus ngecek aplikasi — saat driver sampai, aplikasi akan **memanggil (callback)** kamu dengan notifikasi. Kamu bisa lanjut browsing atau main game sambil menunggu.

---

### Poin-Poin Penting
- Asynchronous callback tidak langsung masuk ke call stack, melainkan masuk ke **task queue** (macro/micro task).
- Dieksekusi setelah call stack kosong, melalui event loop.
- Contoh: `setTimeout`, `setInterval`, `addEventListener`, `fs.readFile` (Node.js), `fetch.then()`.
- Tidak memblokir kode lain — kode setelahnya tetap jalan.

---

### Contoh Implementasi

```javascript
console.log('Mulai');

setTimeout(function () {
  console.log('Ini callback async — jalan setelah 2 detik');
}, 2000);

console.log('Selesai');

// Output:
// Mulai
// Selesai
// Ini callback async — jalan setelah 2 detik
```

Event handler — callback dipanggil saat event terjadi:

```javascript
const button = document.querySelector('button');

button.addEventListener('click', function () {
  console.log('Tombol diklik! — ini async callback');
});

console.log('Event listener sudah terdaftar');
```

Callback dalam Node.js (membaca file):

```javascript
const fs = require('fs');

console.log('Membaca file...');

fs.readFile('data.txt', 'utf8', function (err, data) {
  if (err) console.error('Gagal baca:', err);
  else console.log('Isi file:', data);
});

console.log('Perintah lain tetap jalan');
```

---

### Koneksi
Asynchronous callback adalah pintu masuk ke **event loop** dan **programming asynchronous** di JavaScript. Dari sini muncul kebutuhan akan **Promise** untuk mengatasi masalah kompleksitas callback (callback hell).
