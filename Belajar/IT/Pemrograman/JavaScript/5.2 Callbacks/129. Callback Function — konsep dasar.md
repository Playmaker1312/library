### Definisi Singkat
Callback adalah fungsi yang dikirim sebagai argumen ke fungsi lain dan akan dipanggil (dieksekusi) di dalam fungsi tersebut. Callback memungkinkan kita mengontrol urutan eksekusi — kapan sebuah kode harus dijalankan.

---

### Analogi
Kamu pesan pizza, lalu kasih nomor telepon ke kasir. Saat pizza sudah siap, kasir **menelepon kembali (callback)** nomor itu. Kamu tidak perlu berdiri diam menunggu — kamu bisa melakukan hal lain sambil menunggu panggilan.

---

### Poin-Poin Penting
- Callback adalah **first-class function** — bisa disimpan dalam variabel, dikirim sebagai argumen.
- Callback bisa **synchronous** (dieksekusi langsung) atau **asynchronous** (dieksekusi nanti).
- Callback adalah fondasi dari programming asynchronous di JavaScript sebelum Promise dan async/await.
- Fungsi yang menerima callback disebut **higher-order function**.

---

### Contoh Implementasi

```javascript
function greet(name, callback) {
  console.log('Halo, ' + name);
  callback();
}

function sayGoodbye() {
  console.log('Sampai jumpa!');
}

greet('Andi', sayGoodbye);
// Output:
// Halo, Andi
// Sampai jumpa!
```

Contoh dengan anonymous callback:

```javascript
[1, 2, 3].forEach(function (num) {
  console.log(num * 2);
});
// Output: 2, 4, 6
```

---

### Koneksi
Callback adalah konsep fundamental yang melandasi **Promise** dan **async/await**. Callback juga digunakan di **event handler** (addEventListener), **setTimeout/setInterval**, dan metode array seperti `map`, `filter`, `forEach`.
