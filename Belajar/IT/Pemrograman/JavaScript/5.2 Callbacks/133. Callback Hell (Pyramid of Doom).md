### Definisi Singkat
Callback Hell (juga disebut Pyramid of Doom) adalah situasi di mana callback bersarang (nested) terlalu dalam karena operasi asynchronous yang bergantung satu sama lain. Kode menjadi sulit dibaca, sulit di-debug, dan rawan error.

---

### Analogi
Kamu harus ngurus KTP: ke RT minta surat pengantar → setelah dapat, ke Kelurahan → setelah tanda tangan, ke Kecamatan → setelah validasi, ke Disdukcapil → setelah jadi, ambil KTP. Setiap langkah harus menunggu langkah sebelumnya dan dilakukan di tempat berbeda. Bayangkan jika prosedurnya ditulis dalam satu narasi tanpa jeda paragraf — membingungkan, kan?

---

### Poin-Poin Penting
- **Nested callback** yang terlalu dalam (>3 level) membuat kode menjorok ke kanan (bentuk piramida).
- Sulit melacak alur eksekusi karena bercampurnya error handling di setiap level.
- **Error handling tidak terpusat** — setiap callback punya error handling masing-masing.
- Menyulitkan refactoring, testing, dan kolaborasi tim.
- Callback Hell menjadi salah satu alasan utama lahirnya Promise dan async/await.

---

### Contoh Implementasi

```javascript
// Callback Hell — Pyramid of Doom
getUserData(function (err, user) {
  if (err) {
    console.error(err);
  } else {
    getOrders(user.id, function (err, orders) {
      if (err) {
        console.error(err);
      } else {
        getOrderDetails(orders[0].id, function (err, details) {
          if (err) {
            console.error(err);
          } else {
            processPayment(details.total, function (err, payment) {
              if (err) {
                console.error(err);
              } else {
                sendReceipt(payment.id, function (err, receipt) {
                  if (err) {
                    console.error(err);
                  } else {
                    console.log('Selesai:', receipt);
                  }
                });
              }
            });
          }
        });
      }
    });
  }
});
```

Masalah yang muncul:
- Kode menjorok ke kanan semakin dalam.
- Error handling diulang di setiap level.
- Alur eksekusi tidak linear dan sulit diikuti.
- Jika salah satu callback lupa handle error, error bisa terlewat.

---

### Koneksi
Callback Hell mendorong lahirnya **Promise** (dengan `.then()` chaining) dan **async/await** yang membuat kode asynchronous terlihat seperti synchronous. Pelajari Promise dan async/await sebagai solusi modern untuk masalah ini.
