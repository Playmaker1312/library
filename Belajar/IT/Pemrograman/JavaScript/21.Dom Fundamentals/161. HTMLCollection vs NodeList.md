### Definisi Singkat
**HTMLCollection** dan **NodeList** adalah dua tipe collection (kumpulan node) di DOM. HTMLCollection bersifat **live** (otomatis ter-update jika DOM berubah) dan hanya berisi element nodes. NodeList bisa bersifat **live atau static** dan bisa berisi berbagai tipe node.

---

### Analogi
HTMLCollection seperti **daftar hadir langsung** — setiap kali ada siswa baru masuk, daftar otomatis berubah. NodeList (static) seperti **foto kelas** — sekali dijepret, tidak berubah meskipun ada siswa baru.

---

### Poin-Poin Penting

| Properti | HTMLCollection | NodeList |
|----------|---------------|----------|
| Live/Static | Live | Bisa live atau static |
| Isi | Hanya element node | Semua tipe node |
| Method | Item by index/namedItem | forEach, entries, keys, values |
| Akses index | `collection[0]` | `list[0]` |
| Contoh | `getElementsByClassName()` | `querySelectorAll()` |

- `childNodes` → NodeList (live)
- `children` → HTMLCollection (live)
- `querySelectorAll()` → NodeList (static)

---

### Contoh Implementasi

```javascript
// HTMLCollection — live
const divsByTag = document.getElementsByTagName('div');
console.log(divsByTag.length); // Misal 3

const newDiv = document.createElement('div');
document.body.appendChild(newDiv);
console.log(divsByTag.length); // 4 — otomatis bertambah!

// NodeList — static
const divsQuery = document.querySelectorAll('div');
console.log(divsQuery.length); // 3

document.body.appendChild(newDiv.cloneNode());
console.log(divsQuery.length); // 3 — tetap, tidak berubah!

// Konversi ke array
const arr1 = Array.from(divsByTag);
const arr2 = [...divsQuery];
```

- **160 →** `querySelectorAll` mengembalikan NodeList static
- **162 →** `children` (HTMLCollection) vs `childNodes` (NodeList)
