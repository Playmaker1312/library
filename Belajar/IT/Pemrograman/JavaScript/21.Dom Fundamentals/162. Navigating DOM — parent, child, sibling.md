### Definisi Singkat
DOM navigation properties memungkinkan kita bergerak di antara node dalam DOM tree menggunakan properti seperti `parentNode`, `childNodes`, `children`, `firstChild`, `lastChild`, `nextSibling`, `previousSibling`, `firstElementChild`, `lastElementChild`, `nextElementSibling`, dan `previousElementSibling`.

---

### Analogi
Navigasi DOM seperti **bergerak di peta metro**. Kamu bisa naik ke stasiun induk (parent), turun ke stasiun anak (child), atau pindah ke stasiun sebelah (sibling).

---

### Poin-Poin Penting
- Properti `*Element*` (seperti `nextElementSibling`) hanya mengacu ke element nodes
- Properti tanpa `Element` (seperti `nextSibling`) mencakup semua node termasuk text/comment
- `parentNode` selalu mengembalikan element node (kecuali document)
- `children` adalah HTMLCollection (hanya elements)
- `childNodes` adalah NodeList (semua node termasuk text)

---

### Contoh Implementasi

```javascript
const current = document.querySelector('.active');

// Parent
const parent = current.parentNode;
const parentEl = current.parentElement;

// Children
const children = current.children;           // HTMLCollection
const allChildNodes = current.childNodes;    // NodeList
const first = current.firstElementChild;
const last = current.lastElementChild;

// Sibling
const prev = current.previousElementSibling;
const next = current.nextElementSibling;

// Traversal chaining
const headerText = document
  .getElementById('header')
  .firstElementChild
  .textContent;

console.log({ parent, first, next, headerText });
```
