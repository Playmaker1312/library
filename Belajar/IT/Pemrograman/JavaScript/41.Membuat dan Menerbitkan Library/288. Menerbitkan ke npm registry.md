### Definisi Singkat

**npm registry** adalah database publik package JavaScript. Menerbitkan (publish) ke npm berarti membuat package Anda tersedia untuk diinstall oleh siapa pun via `npm install nama-package`. Prosesnya meliputi login, build, dan publikasi.

---

### Analogi

Seperti **membuka toko di pasar** — Anda menyewa kios (membuat akun npm), menyiapkan barang dagangan (build package), menulis label harga (package.json), menaruh barang di rak (npm publish), dan pengunjung pasar bisa membeli (npm install). Anda juga bisa membatasi toko untuk anggota tertentu (scoped packages / private).

---

### Poin-Poin Penting

- **Login**: `npm login` — autentikasi dengan akun npm.
- **Publish**: `npm publish` — publikasikan package ke registry.
- **Scoped packages**: `@username/package-name` — untuk organisasi atau mencegah konflik nama.
- **Private packages**: Berbayar — hanya bisa diakses oleh anggota tim.
- **`npm version`**: Menaikkan versi + membuat git tag secara otomatis.
- **`prepublishOnly` script**: Jalankan build dan test sebelum publish.
- **Unpublish**: Ada batasan — hanya dalam 72 jam pertama, dan hanya jika tidak ada dependen.
- **Deprecate**: Alternatif unpublish — `npm deprecate pkg@"<1.5" "Rekomendasi: gunakan v2"`.
- **Dist-tag**: `npm publish --tag beta` — publikasikan dengan tag khusus (default: `latest`).

---

### Contoh Implementasi

```bash
# 1. Login ke npm
npm login
# Masukkan username, password, dan OTP

# 2. Periksa apakah sudah login
npm whoami

# 3. Build package
npm run build

# 4. Publikasikan
npm publish

# 5. Publikasikan dengan tag pre-release
npm publish --tag beta

# 6. Scoped package — perlu flag access
npm publish --access public

# 7. Update versi + publish sekaligus
npm version patch
npm publish

# 8. Deprecate versi lama
npm deprecate my-package@"<2.0.0" "Versi 1.x tidak didukung lagi, upgrade ke 2.x"
```

```json
// package.json — untuk publikasi yang benar
{
  "name": "@username/my-library",
  "version": "1.0.0",
  "private": false,
  "publishConfig": {
    "access": "public"
  },
  "files": ["dist"],
  "scripts": {
    "prepublishOnly": "npm run build && npm test"
  }
}
```

```bash
# Melihat package yang sudah dipublikasi
npm view my-package
npm view my-package versions
```

### Koneksi

Berkaitan dengan **Package.json** (metadata publikasi), **Struktur Package** (apa yang dikirim), **SemVer** (versi untuk publikasi), **CI/CD** (publish otomatis via GitHub Actions), dan **Dokumentasi** (README di halaman npm).
