### Definisi Singkat

**Semantic Versioning (SemVer)** adalah skema penomoran versi dengan format **MAJOR.MINOR.PATCH** (contoh: `2.1.3`). Aturan inti: Anda menaikkan nomor versi berdasarkan jenis perubahan yang dibuat pada API publik library.

---

### Analogi

Seperti **nomor generasi mobil**:
- **MAJOR**: Generasi baru (Mobil 1 → Mobil 2) — perubahan besar, tidak kompatibel dengan aksesori lama.
- **MINOR**: Fitur baru di generasi yang sama (Mobil 2.1 → 2.2) — tetap kompatibel dengan aksesori yang ada.
- **PATCH**: Perbaikan kecil (Mobil 2.1.0 → 2.1.1) — perbaiki rem, ganti sekring — tidak ada fitur baru.

---

### Poin-Poin Penting

- **MAJOR**: Perubahan **breaking** yang tidak kompatibel dengan versi sebelumnya.
- **MINOR**: Penambahan fitur **backward-compatible**.
- **PATCH**: Perbaikan bug **backward-compatible**.
- **Pre-release tags**: `1.0.0-alpha.1`, `2.0.0-beta.2`, `1.5.0-rc.1`.
- **Build metadata**: `1.0.0+build.123` (diabaikan dalam precedence).
- **Range operators**: `^1.2.3` (compatible) dan `~1.2.3` (hanya patch).
- **`npm version`**: Perintah untuk menaikkan versi otomatis — `npm version major` / `minor` / `patch`.
- **Stabilitas**: Versi `0.x.x` dianggap development awal — API bisa berubah kapan saja.
- **Dependencies selalu pin ke versi tertentu atau range**.

---

### Contoh Implementasi

```json
{
  "version": "2.1.0",
  "scripts": {
    "version": "git add -A src",
    "postversion": "git push && git push --tags"
  }
}
```

```bash
# Menaikkan versi
npm version patch  # 2.1.0 → 2.1.1 (bug fix)
npm version minor  # 2.1.1 → 2.2.0 (fitur baru)
npm version major  # 2.2.0 → 3.0.0 (breaking change)

# Pre-release
npm version prepatch --preid=alpha  # 1.0.0 → 1.0.1-alpha.0
```

```
Contoh riwayat versi:
1.0.0 — Rilis publik pertama
1.0.1 — Memperbaiki bug parsing
1.1.0 — Menambahkan fungsi formatDate()
2.0.0 — Mengubah API formatDate() (parameter berbeda)
2.0.1 — Memperbaiki memory leak
2.1.0 — Menambahkan fungsi formatCurrency()
```

```javascript
// npm semver library — programatik
const semver = require('semver');
semver.valid('1.2.3'); // '1.2.3'
semver.gt('2.0.0', '1.5.0'); // true
semver.satisfies('1.3.0', '^1.2.0'); // true
semver.minVersion('>=2.0.0'); // '2.0.0'
```

---

### Koneksi

Berkaitan dengan **package.json** (field version), **npm registry** (versi di npm), **CI/CD** (publikasi otomatis berdasarkan versi), dan **Dependency Management** (^, ~, range operators di package.json).
