### Definisi Singkat

Struktur **package** (npm package) adalah susunan folder dan file dalam proyek JavaScript/Node.js yang akan diterbitkan ke npm registry. Struktur yang baik memastikan konsumen package bisa mengimpor, menggunakan, dan memahami package Anda dengan mudah.

---

### Analogi

Seperti **kemasan produk supermarket** — ada kotak (folder utama), label bahan (package.json), buku petunjuk (README), bagian yang bisa diakses konsumen (exports), dan gudang penyimpanan (src/). Kemasan yang rapi membuat pembeli mudah menemukan dan menggunakan produk.

---

### Poin-Poin Penting

- **Struktur rekomendasi**:
  ```
  my-package/
  ├── src/              # Source code (ES modules / TypeScript)
  ├── dist/             # Build output (CommonJS + ESM)
  ├── test/             # Unit tests
  ├── docs/             # Dokumentasi tambahan (opsional)
  ├── examples/         # Contoh penggunaan (opsional)
  ├── index.js          # Entry point utama
  ├── package.json      # Metadata
  ├── README.md         # Dokumentasi (wajib)
  ├── LICENSE           # Lisensi
  ├── .gitignore        # Ignore node_modules, dist, dll
  └── .npmignore        # File yang tidak masuk ke npm
  ```
- **Entry points** di `package.json`: `"main"` (CJS), `"module"` (ESM), `"exports"` (conditional exports).
- **Index file**: Biasanya `index.js` di root atau `src/index.js`.
- **Environment-agnostic**: Hindari Node.js API jika library untuk browser, dan sebaliknya.
- **Tree-shaking**: Dukung dengan ESM exports dan sideEffects flag.

---

### Contoh Implementasi

```json
// package.json — struktur entry points
{
  "name": "@user/my-library",
  "version": "1.0.0",
  "main": "./dist/index.cjs",
  "module": "./dist/index.mjs",
  "exports": {
    ".": {
      "import": "./dist/index.mjs",
      "require": "./dist/index.cjs"
    },
    "./utils": {
      "import": "./dist/utils.mjs",
      "require": "./dist/utils.cjs"
    }
  },
  "files": ["dist", "README.md", "LICENSE"],
  "sideEffects": false
}
```

```
# .gitignore
node_modules/
dist/
coverage/

# .npmignore (atau gunakan "files" di package.json)
src/
test/
examples/
```

```javascript
// src/index.js — source code
export function greet(name) {
  return `Halo, ${name}!`;
}

// dist/index.mjs — build output ESM
// dist/index.cjs — build output CommonJS
```

### Koneksi

Berkaitan dengan **package.json untuk publikasi** (metadata konfigurasi), **Semantic Versioning** (versi), **Menulis Dokumentasi** (README, JSDoc), **CI/CD** (build otomatis), dan **npm registry** (destinasi publikasi).
