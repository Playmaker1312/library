### Definisi Singkat

**package.json** adalah file metadata utama proyek Node.js yang berisi informasi seperti nama, versi, dependensi, skrip, dan konfigurasi publikasi. Untuk menerbitkan package ke npm, beberapa field wajib diisi dan dikonfigurasi dengan benar.

---

### Analogi

Seperti **paspor** — berisi identitas (nama, versi), negara asal (author, license), tujuan (main/exports), dan barang bawaan (dependencies). Petugas imigrasi (npm registry) memeriksa paspor ini sebelum mengizinkan Anda masuk (publish).

---

### Poin-Poin Penting

- **Field wajib**: `name` (unik di registry) dan `version` (SemVer).
- `"private": true` — cegah publikasi tidak sengaja.
- **`"files"`**: Array file/folder yang diikutsertakan saat publish (alternatif `.npmignore`).
- **`"main"`**: Entry point untuk CommonJS (`require('pkg')`).
- **`"module"`**: Entry point untuk ES Modules (`import 'pkg'`).
- **`"exports"`**: Conditional exports (modern — support subpath exports).
- **`"scripts"`**: Perintah lifecycle (`prepublishOnly`, `prepare`, `test`, `build`).
- **`"dependencies"`** vs **`"devDependencies"`**: Hanya dependencies yang akan diinstall konsumen.
- **`"peerDependencies"`**: Untuk plugin/library yang membutuhkan versi spesifik dari host.
- **`"keywords"`**: Array kata kunci untuk pencarian di npm.

### Contoh Implementasi

```json
{
  "name": "@budi/string-utils",
  "version": "2.1.0",
  "description": "Koleksi utilitas string untuk JavaScript",
  "main": "./dist/index.js",
  "module": "./dist/index.mjs",
  "exports": {
    ".": {
      "import": "./dist/index.mjs",
      "require": "./dist/index.js"
    }
  },
  "files": ["dist"],
  "sideEffects": false,
  "scripts": {
    "build": "tsc",
    "test": "jest",
    "prepublishOnly": "npm run build && npm test",
    "lint": "eslint src/"
  },
  "keywords": ["string", "utils", "utilities", "format"],
  "author": "Budi Santoso <budi@example.com>",
  "license": "MIT",
  "repository": {
    "type": "git",
    "url": "https://github.com/budi/string-utils.git"
  },
  "bugs": {
    "url": "https://github.com/budi/string-utils/issues"
  },
  "homepage": "https://github.com/budi/string-utils#readme",
  "engines": {
    "node": ">=16.0.0"
  },
  "dependencies": {},
  "devDependencies": {
    "typescript": "^5.0.0",
    "jest": "^29.0.0"
  }
}
```

---

### Koneksi

Berkaitan dengan **Struktur Package** (organisasi file), **SemVer** (skema versi), **npm registry** (proses publikasi), **CI/CD** (skrip otomatis), dan **Menulis Dokumentasi** (README, homepage).
