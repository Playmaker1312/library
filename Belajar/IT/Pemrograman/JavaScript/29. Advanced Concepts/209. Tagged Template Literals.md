### Definisi Singkat

Tagged Template Literals adalah fitur yang memungkinkan Anda memanggil sebuah fungsi (tag) dengan template literal sebagai argumen. Fungsi tag menerima array string literal dan nilai-nilai interpolasi, sehingga Anda bisa memproses template secara kustom.

---

### Analogi

Seperti **cetakan kue dengan resep khusus** — adonan (template literal) bisa diberi topping berbeda (nilai interpolasi), dan Anda bisa menentukan bagaimana kue jadi (output) melalui resep (tag function) yang unik.

---

### Poin-Poin Penting

- Tag function dipanggil dengan sintaks: `tagFunction\`string ${expr} string\``
- Argumen pertama: array string literal (termasuk raw strings via `raw` property)
- Argumen selanjutnya: nilai-nilai interpolasi, satu per satu
- Berguna untuk: sanitasi HTML, internasionalisasi (i18n), DSL (domain-specific language), styling CSS-in-JS
- String literal memiliki properti `raw` untuk akses string mentah (tanpa escape processing)

---

### Contoh Implementasi

```javascript
// Tag function sederhana
function highlight(strings, ...values) {
  let result = '';
  strings.forEach((str, i) => {
    result += str;
    if (i < values.length) {
      result += `**${values[i]}**`;
    }
  });
  return result;
}

const name = 'Budi';
const age = 25;
console.log(highlight`Nama: ${name}, Usia: ${age}`);
// "Nama: **Budi**, Usia: **25**"

// Sanitasi HTML
function escapeHtml(strings, ...values) {
  const escape = str =>
    str.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;')
       .replace(/"/g, '&quot;').replace(/'/g, '&#39;');

  return strings.reduce((result, str, i) =>
    result + escape(values[i - 1]) + str
  );
}

const userInput = '<script>alert("xss")</script>';
console.log(escapeHtml`<div>${userInput}</div>`);
// "<div>&lt;script&gt;alert(&quot;xss&quot;)&lt;/script&gt;</div>"

// i18n sederhana
function i18n(strings, ...values) {
  const translations = { 'Halo': 'Hello', 'nama': 'name' };
  return strings.reduce((result, str, i) =>
    result + (translations[values[i - 1]] || values[i - 1]) + str
  );
}

// Asumsikan kamus lebih lengkap
```

---

### Koneksi

Tagged template literal terkait dengan **Function** (dasar JavaScript) dan sering digunakan di library seperti **styled-components** (CSS-in-JS). Juga bisa dikombinasikan dengan **Generator** (file 202) untuk lazy evaluation template.
