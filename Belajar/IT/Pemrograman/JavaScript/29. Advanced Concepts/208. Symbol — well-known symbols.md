### Definisi Singkat

Symbol adalah tipe data primitif di JavaScript yang digunakan sebagai identifier unik dan immutable. Setiap panggilan `Symbol()` menghasilkan nilai yang berbeda. **Well-known symbols** adalah Symbol bawaan yang digunakan JavaScript engine untuk menyesuaikan perilaku objek (seperti `Symbol.iterator`, `Symbol.toStringTag`, dll).

---

### Analogi

Seperti **sidik jari** — setiap Symbol unik dan tidak bisa diduplikasi. Well-known symbols seperti **lubang kunci universal** yang sudah ditentukan sistem — jika objek Anda memiliki lubang itu, JavaScript engine bisa "membuka" perilaku tertentu padanya.

---

### Poin-Poin Penting

- `Symbol()` menghasilkan nilai unik, `Symbol('desc')` hanya deskripsi (debugging)
- `Symbol.for('key')` membuat/mendapatkan Symbol global yang bisa dibagikan
- Well-known symbols: `Symbol.iterator`, `Symbol.toStringTag`, `Symbol.hasInstance`, `Symbol.species`, `Symbol.match`, `Symbol.replace`, `Symbol.search`, `Symbol.split`, `Symbol.toPrimitive`, `Symbol.unscopables`
- Symbol sebagai properti objek bersifat **non-enumerable** (tidak muncul di `for...in` atau `Object.keys`)
- `Object.getOwnPropertySymbols()` untuk mengambil Symbol properties

---

### Contoh Implementasi

```javascript
// Symbol unik
const id1 = Symbol('id');
const id2 = Symbol('id');
console.log(id1 === id2); // false

// Symbol sebagai properti unik
const user = {
  name: 'Budi',
  [id1]: 123
};

// Well-known symbols
// Symbol.iterator — membuat objek iterable
const range = {
  from: 1, to: 3,
  [Symbol.iterator]() {
    let current = this.from;
    const last = this.to;
    return {
      next() { return current <= last ? { value: current++, done: false } : { value: undefined, done: true }; }
    };
  }
};
console.log([...range]); // [1, 2, 3]

// Symbol.toStringTag — kustomisasi Object.prototype.toString
const myObj = {
  [Symbol.toStringTag]: 'MyCustomObject'
};
console.log(Object.prototype.toString.call(myObj)); // [object MyCustomObject]

// Symbol.toPrimitive — kustomisasi konversi tipe
const money = {
  amount: 100,
  currency: 'IDR',
  [Symbol.toPrimitive](hint) {
    if (hint === 'string') return `${this.amount} ${this.currency}`;
    return this.amount;
  }
};
console.log(String(money)); // "100 IDR"
console.log(+money);        // 100
```
