### Definisi Singkat

Statement `return` digunakan untuk mengembalikan nilai dari sebuah fungsi sekaligus menghentikan eksekusi fungsi tersebut. Jika tidak ada `return`, fungsi mengembalikan `undefined`. Early return adalah teknik mengembalikan nilai lebih awal untuk menghindari eksekusi kode yang tidak perlu.

---

### Analagi

Bayangkan **mesin penjual otomatis (vending machine)**:

- Anda memasukkan koin (input), menekan tombol (eksekusi fungsi), dan mesin mengembalikan minuman (`return`).
- Jika stok habis, mesin bisa **early return** dengan menampilkan pesan "Stok habis" tanpa memproses lebih lanjut.
- Jika tidak ada mekanisme pengembalian, mesin hanya akan memproses koin tanpa memberi apa-apa (`undefined`).

---

### Poin-Poin Penting

- `return` menghentikan eksekusi fungsi — kode setelah `return` tidak akan pernah dijalankan.
- Jika fungsi tidak memiliki `return` atau memiliki `return` tanpa nilai, fungsi mengembalikan `undefined`.
- **Early return** digunakan untuk validasi atau pengecekan kondisi di awal fungsi agar kode lebih bersih.
- `return` hanya berlaku di dalam fungsi — tidak bisa digunakan di luar fungsi (akan menyebabkan error).
- Satu fungsi bisa memiliki beberapa statement `return` (conditional return).

---

### Contoh Implementasi

```javascript
// Fungsi tanpa return — mengembalikan undefined
function sapa(nama) {
    console.log("Halo, " + nama);
}
console.log(sapa("Budi")); // undefined

// Fungsi dengan return
function tambah(a, b) {
    return a + b;
    console.log("Ini tidak akan pernah dicetak"); // unreachable
}
console.log(tambah(3, 4)); // 7

// Early return
function cekUmur(umur) {
    if (umur < 0) {
        return "Umur tidak valid";
    }
    if (umur < 17) {
        return "Belum cukup umur";
    }
    return "Silakan masuk";
}

console.log(cekUmur(-5)); // "Umur tidak valid"
console.log(cekUmur(15)); // "Belum cukup umur"
console.log(cekUmur(20)); // "Silakan masuk"
```

---

### Koneksi

Return statement adalah fondasi dari **functional programming**, **pure functions**, dan **recursion**. Konsep early return juga terkait dengan **guard clause** dalam pola desain kode bersih (clean code). Memahami return value penting saat bekerja dengan **Promise** dan `async/await`.
