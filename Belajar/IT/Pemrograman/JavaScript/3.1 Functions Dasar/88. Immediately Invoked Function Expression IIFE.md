# 88. Immediately Invoked Function Expression IIFE **Definisi Singkat:** IIFE adalah fungsi yang langsung dijalankan setelah didefinisikan, ditulis dengan `(function(){})()`, menciptakan scope privat. **Analogi:** Seperti petasan yang langsung meledak saat dinyalakan — tidak disimpan, langsung berefek. **Poin-Poin Penting:** - Membuat isolated scope untuk menghindari polusi global - Bisa regular function atau arrow function - Sering dipakai sebelum era module (ES6) - Bisa menerima argument**Contoh Kode:** ```javascript (function () {
  const rahasia = 'Ini privat';
  console.log('IIFE regular:', rahasia);
})();

(() => {
  const rahasia = 'Juga privat';
  console.log('IIFE arrow:', rahasia);
})();

// Dengan parameter
const hasil = (function (a, b) {
  return a * b;
})(6, 7);
console.log(hasil); ``` **Hasil:** `IIFE regular: Ini privat` `IIFE arrow: Juga privat` `42` **Kasus Penggunaan Nyata:** Module pattern klasik, inisialisasi one-time code (seperti setup konfigurasi), dan menghindari konflik variabel global di script non-module.
