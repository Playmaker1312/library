Arrow Functions - sintaks dan use case **Definisi Singkat:** Arrow function adalah sintaks pendek untuk menulis fungsi dengan `=>`, memiliki binding `this` leksikal dan return implisit. **Analogi:** Seperti sepeda lipat — lebih ringkas, mudah dibawa (di-callback), tapi kurang cocok untuk medan berat (method objek, constructor). **Poin-Poin Penting:** - Berbagai bentuk: `() => expr`, `x => expr`, `(x,y) => {...}` - Return implisit jika tanpa kurung kurawal - Tidak punya `this`, `arguments`, `super`, atau `new.target` sendiri - Tidak bisa dipakai sebagai constructor atau method**Contoh Kode:** ```javascript // Berbagai bentuk arrow function
const kuadrat = x => x * x;
const tambah = (a, b) => a + b;
const sapa = nama => {
  const waktu = new Date().getHours();
  return `Selamat ${waktu < 12 ? 'pagi' : 'sore'}, ${nama}`;
};

console.log(kuadrat(5));
console.log(tambah(3, 7));
console.log(sapa('Dewi'));

// Arrow sebagai callback
const angka = [1, 2, 3];
const genap = angka.filter(n => n % 2 === 0);
console.log(genap); ``` **Hasil:** `25` `10` `Selamat pagi/sore, Dewi` `[2]` **Kasus Penggunaan Nyata:** Callback di array methods (`map`, `filter`, `reduce`), promise chains, event listeners, dan functional programming.
