# 85. Arguments object - vs rest parameter **Definisi Singkat:** `arguments` adalah objek array-like yang berisi semua argument fungsi (ES5), sedangkan rest parameter adalah array sesungguhnya (ES6+). **Analogi:** `arguments` seperti rak buku kayu (bisa dipakai, tapi tidak bisa di-susun ulang mudah); rest parameter seperti rak modular (fleksibel, bisa di-sortir, di-filter). **Poin-Poin Penting:** - `arguments` hanya tersedia di regular function (bukan arrow) - `arguments` adalah array-like, bukan Array — tidak punya `.map()`, `.filter()` - Rest parameter adalah Array sungguhan dengan semua method Array - Rest parameter hanya menangkap sisa argument, `arguments` menangkap semua**Contoh Kode:** ```javascript function pakeArguments() {
  console.log(typeof arguments);
  console.log(Array.isArray(arguments));
  const arr = Array.from(arguments);
  console.log(arr.map(x => x * 2));
}

function pakeRest(...args) {
  console.log(typeof args);
  console.log(Array.isArray(args));
  console.log(args.map(x => x * 2));
}

pakeArguments(1, 2, 3);
pakeRest(1, 2, 3); ``` **Hasil:** `object` `false` `[2, 4, 6]` `object` `true` `[2, 4, 6]` **Kasus Penggunaan Nyata:** Rest parameter dipakai di almost all modern code; `arguments` hanya ditemui di legacy code atau kasus spesifik yang butuh semua argument termasuk yang sudah di-named.
