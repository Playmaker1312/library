### Definisi Singkat

`arguments` adalah objek array-like yang tersedia di dalam fungsi regular (non-arrow) yang berisi semua argument yang diberikan ke fungsi tersebut. Rest parameter (`...args`) adalah fitur ES6 yang lebih modern dan lebih unggul dibanding `arguments` object.

---

### Analogi

- **`arguments` object:** Seperti **kertas catatan** di meja resepsionis — mencatat semua tamu yang datang, tapi catatannya tidak terstruktur dengan baik (array-like, bukan array sungguhan).
- **Rest parameter:** Seperti **Google Spreadsheet** modern — mencatat tamu dengan rapi dalam format tabel (array asli) yang bisa langsung difilter, diurutkan, atau dijumlahkan.

---

### Poin-Poin Penting

- `arguments` adalah array-like (memiliki `length` tapi tidak memiliki method array seperti `map`, `filter`, `reduce`).
- Rest parameter adalah array sungguhan — bisa menggunakan semua method array.
- `arguments` tidak tersedia di arrow function; rest parameter bisa digunakan di arrow function.
- `arguments` menangkap semua argument tanpa terkecuali; rest parameter hanya menangkap sisa argument setelah parameter yang disebutkan.
- `arguments` memiliki properti `callee` (referensi ke fungsi yang sedang dieksekusi) — kini deprecated.
- Rest parameter lebih direkomendasikan untuk kode modern karena lebih jelas dan fungsional.

---

### Contoh Implementasi

```javascript
// Menggunakan arguments object (hanya di regular function)
function jumlahkanArgs() {
    console.log(arguments.length);     // 3
    console.log(arguments[0]);          // 10
    console.log(arguments[1]);          // 20
    // arguments.map(x => x) // ERROR — arguments bukan array
    
    // Konversi manual ke array
    const arr = Array.from(arguments);
    return arr.reduce((a, b) => a + b, 0);
}
console.log(jumlahkanArgs(10, 20, 30)); // 60

// Menggunakan rest parameter (ES6+)
function jumlahkanRest(...angka) {
    return angka.reduce((a, b) => a + b, 0);
}
console.log(jumlahkanRest(10, 20, 30)); // 60

// arguments tidak bisa di arrow function
const arrowFunc = () => {
    // console.log(arguments); // ReferenceError
};
```
