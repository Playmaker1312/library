### Definisi Singkat

Rest parameters (`...args`) adalah fitur ES6 yang memungkinkan fungsi menerima jumlah argument yang tidak terbatas sebagai sebuah array. Parameter ini ditulis dengan tiga titik diikuti nama parameter, dan harus berada di posisi terakhir dalam daftar parameter.

---

### Analogi

Bayangkan sebuah **keranjang belanja tak terbatas**:

- Anda pergi ke pasar dan bisa memasukkan **apapun** ke dalam keranjang — 1 item, 10 item, atau 100 item.
- **Rest parameter** adalah keranjang itu — ia mengumpulkan semua barang (argument) yang tidak memiliki tempat spesifik ke dalam satu wadah (array).

---

### Poin-Poin Penting

- Rest parameters mengumpulkan sisa argument menjadi sebuah array nyata (true array), berbeda dengan `arguments` object yang hanya array-like.
- Hanya boleh ada satu rest parameter dalam sebuah fungsi dan harus menjadi parameter terakhir.
- Jika tidak ada argument yang diberikan untuk rest parameter, hasilnya adalah array kosong (`[]`), bukan `undefined`.
- Cocok digunakan untuk fungsi dengan jumlah argument variatif seperti `Math.max()`, `Math.min()`, atau fungsi utilitas.
- Rest parameters berbeda dengan spread operator (`...`) — rest mengumpulkan, spread menyebarkan.

---

### Contoh Implementasi

```javascript
// Rest parameter untuk menjumlahkan semua angka
function jumlahkan(...angka) {
    return angka.reduce((total, num) => total + num, 0);
}
console.log(jumlahkan(1, 2, 3, 4, 5)); // 15
console.log(jumlahkan(10, 20));         // 30

// Rest parameter setelah parameter biasa
function daftarBelanja(toko, ...items) {
    console.log(`Belanja di: ${toko}`);
    console.log(`Items: ${items.join(", ")}`);
}
daftarBelanja("Supermarket", "Beras", "Gula", "Kopi");

// Rest parameter kosong
function test(...args) {
    console.log(args.length); // 0
}
test();

// Rest parameter adalah array nyata
function cekArray(...args) {
    return Array.isArray(args); // true
}
console.log(cekArray(1, 2, 3));
```

---

### Koneksi

Rest parameters terkait dengan **arguments object**, **spread operator**, **destructuring**, dan **functional programming** (seperti pada method `reduce`, `map`, `filter`). Fitur ini是现代 JavaScript yang sangat berguna untuk menulis fungsi utilitas yang fleksibel.
