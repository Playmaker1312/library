### Definisi Singkat
Form submission modern menggunakan **`preventDefault()`** untuk mencegah reload halaman, lalu mengirim data secara asynchronous dengan **Fetch API**. Data bisa dikirim sebagai **FormData** (multipart) atau **JSON** (application/json).

---

### Analogi
Form submission tradisional seperti **mengirim surat lewat pos** — kamu harus menunggu balasan dan halaman akan "berganti". Submission dengan Fetch seperti **mengirim WhatsApp** — latar belakang, halaman tetap aktif, dan balasan datang tanpa mengganggu.

---

### Poin-Poin Penting
- `e.preventDefault()` di event submit — cegah reload
- **FormData** — otomatis ambil semua data form (termasuk file)
- **JSON** — konversi dengan `JSON.stringify(Object.fromEntries(formData))`
- Fetch: `fetch(url, { method, body, headers })`
- Handle response: loading state, success, error
- Jangan lupa disabled tombol submit untuk mencegah double submit

---

### Contoh Implementasi

```javascript
const form = document.querySelector('#myForm');
const submitBtn = form.querySelector('button[type="submit"]');
const statusDiv = document.querySelector('#status');

form.addEventListener('submit', async (e) => {
  e.preventDefault();

  // Prevent double submit
  submitBtn.disabled = true;
  submitBtn.textContent = 'Mengirim...';
  statusDiv.textContent = '';

  try {
    // Opsi 1: FormData (untuk file & form biasa)
    const formData = new FormData(form);
    const response = await fetch('/api/submit', {
      method: 'POST',
      body: formData
      // Jangan set Content-Type — browser otomatis dengan boundary
    });

    // Opsi 2: JSON
    const jsonData = Object.fromEntries(formData);
    const response2 = await fetch('/api/submit', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(jsonData)
    });

    // Handle response
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }

    const result = await response.json();
    statusDiv.textContent = 'Berhasil dikirim!';
    form.reset();

  } catch (error) {
    statusDiv.textContent = `Gagal: ${error.message}`;
  } finally {
    submitBtn.disabled = false;
    submitBtn.textContent = 'Kirim';
  }
});

// Show loading
async function submitForm(data) {
  // Loading state
  showLoader();

  try {
    const res = await fetch('/api/data', { method: 'POST', body: data });
    return await res.json();
  } finally {
    hideLoader();
  }
}
```
