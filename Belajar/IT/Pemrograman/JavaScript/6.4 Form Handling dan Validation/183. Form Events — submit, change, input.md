### Definisi Singkat
Tiga event utama pada form: **`submit`** (saat form dikirim), **`change`** (saat nilai berubah dan kehilangan fokus), dan **`input`** (setiap kali nilai berubah secara real-time). Masing-masing punya perilaku dan use case berbeda.

---

### Analogi
- **submit** seperti **menekan tombol "Kirim"** di mesin ATM — satu kali, final
- **change** seperti **memilih menu di restoran** — baru diproses setelah kamu yakin dan tutup menu
- **input** seperti **mengetik di ponsel** — setiap huruf langsung terdeteksi

---

### Poin-Poin Penting
- **submit** — hanya di `<form>`, dipicu saat submit (tombol submit/Enter)
- **change** — dipicu setelah nilai berubah **dan** elemen kehilangan fokus (blur)
- **input** — dipicu setiap kali nilai berubah (setiap ketikan, paste, dll)
- `input` lebih real-time dibanding `change`
- `submit` perlu `preventDefault()` jika ingin handle dengan JavaScript
- `input` event bekerja di `<input>`, `<textarea>`, `<select>`

---

### Contoh Implementasi

```javascript
const form = document.querySelector('form');
const emailInput = document.querySelector('#email');
const citySelect = document.querySelector('#city');

// Submit
form.addEventListener('submit', (e) => {
  e.preventDefault();
  console.log('Form dikirim!');

  const formData = new FormData(form);
  console.log(Object.fromEntries(formData));
});

// Input — real-time
emailInput.addEventListener('input', (e) => {
  const value = e.target.value;
  const isValid = value.includes('@');
  emailInput.style.borderColor = isValid ? 'green' : 'red';
  console.log('Email:', value);
});

// Change — setelah blur
citySelect.addEventListener('change', (e) => {
  console.log('Kota dipilih:', e.target.value);
  loadCityData(e.target.value);
});

// Input dengan debounce
let timeout;
searchInput.addEventListener('input', (e) => {
  clearTimeout(timeout);
  timeout = setTimeout(() => {
    searchAPI(e.target.value);
  }, 300);
});
```
