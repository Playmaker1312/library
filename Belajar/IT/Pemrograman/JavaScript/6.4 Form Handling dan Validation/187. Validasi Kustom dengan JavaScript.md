### Definisi Singkat
Validasi kustom JavaScript adalah implementasi logika validasi yang ditulis manual ketika validasi HTML5 bawaan tidak mencukupi. Cocok untuk aturan kompleks seperti validasi antar-field, pengecekan ke server, format dinamis, atau kondisi bisnis spesifik.

---

### Analogi
Validasi HTML5 seperti **aturan lalu lintas umum** (stop di lampu merah). Validasi kustom seperti **aturan khusus di kompleks perumahan** — hanya mobil dengan stiker tertentu yang boleh masuk, atau jam tertentu saja.

---

### Poin-Poin Penting
- Gunakan `setCustomValidity()` untuk mengintegrasikan validasi kustom dengan sistem HTML5
- Atau validasi manual dengan `if/else` dan tampilkan error sendiri
- Validasi **real-time** via event `input` / `change`
- Validasi **cross-field** — cocokkan dua field (password, date range)
- **Async validation** — cek ketersediaan username ke server
- Tampilkan pesan error di elemen HTML terpisah untuk kontrol lebih besar

---

### Contoh Implementasi

```javascript
const form = document.querySelector('form');
const password = document.querySelector('#password');
const confirm = document.querySelector('#confirm');
const username = document.querySelector('#username');
const errorDiv = document.querySelector('#errors');

// Cross-field validation
function validatePasswordMatch() {
  if (password.value !== confirm.value) {
    confirm.setCustomValidity('Password tidak cocok');
    return false;
  }
  confirm.setCustomValidity('');
  return true;
}

[password, confirm].forEach(input => {
  input.addEventListener('input', validatePasswordMatch);
});

// Async validation (cek username)
let usernameTimeout;
username.addEventListener('input', () => {
  clearTimeout(usernameTimeout);
  usernameTimeout = setTimeout(async () => {
    const taken = await cekUsernameKeServer(username.value);

    if (taken) {
      username.setCustomValidity('Username sudah digunakan');
      showError('Username tidak tersedia');
    } else {
      username.setCustomValidity('');
      clearError();
    }
  }, 500);
});

// Validasi kompleks — nomor rekening
function validateRekening(value) {
  const digits = value.replace(/\D/g, '');
  if (digits.length !== 10) return 'Harus 10 digit';
  if (!cekChecksum(digits)) return 'Nomor rekening tidak valid';
  return '';
}

// Manual validation tanpa setCustomValidity
form.addEventListener('submit', (e) => {
  e.preventDefault();
  const errors = [];

  if (!validatePasswordMatch()) errors.push('Password tidak cocok');
  if (username.value.length < 3) errors.push('Username minimal 3 karakter');
  // ... lebih banyak validasi

  if (errors.length > 0) {
    errorDiv.innerHTML = errors.map(e => `<p>${e}</p>`).join('');
  } else {
    form.submit();
  }
});
```
