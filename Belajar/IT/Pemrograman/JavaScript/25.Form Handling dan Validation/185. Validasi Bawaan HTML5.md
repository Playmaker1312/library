### Definisi Singkat
HTML5 menyediakan validasi bawaan tanpa JavaScript melalui atribut seperti **`required`**, **`pattern`**, **`minlength`** / **`maxlength`**, **`min`** / **`max`**, **`type`** (email, url, number, dll). Browser menampilkan pesan error otomatis dan mencegah submit jika validasi gagal.

---

### Analogi
Validasi HTML5 seperti **satpam di pintu masuk mall**. Satpam punya aturan: harus pakai sepatu (`required`), umur minimal 17 (`min`), undangan format tertentu (`pattern`). Jika tidak sesuai, satpam menolak masuk.

---

### Poin-Poin Penting
- **`required`** — field wajib diisi
- **`pattern`** — regex untuk validasi format (contoh: `[a-z]+`)
- **`minlength`/`maxlength`** — panjang karakter
- **`min`/`max`** — rentang numerik/tanggal
- **`type="email"`** — validasi format email otomatis
- **`type="url"`** — validasi URL
- Atribut **`novalidate`** di form untuk menonaktifkan validasi HTML5
- CSS pseudo-class: `:valid`, `:invalid`, `:required`, `:optional`

---

### Contoh Implementasi

```html
<!-- HTML -->
<form>
  <input type="text" required minlength="3" maxlength="20"
         placeholder="Nama (3-20 karakter)">
  <input type="email" required placeholder="Email">
  <input type="password" required minlength="8"
         pattern="(?=.*\d)(?=.*[a-z])(?=.*[A-Z]).{8,}"
         placeholder="Password kuat">
  <input type="number" min="17" max="99" value="17">
  <input type="url" placeholder="Website">
  <button type="submit">Kirim</button>
</form>
```

```javascript
// CSS styling valid/invalid
document.querySelectorAll('input').forEach(input => {
  input.addEventListener('input', () => {
    if (input.validity.valid) {
      input.classList.remove('invalid');
      input.classList.add('valid');
    } else {
      input.classList.remove('valid');
      input.classList.add('invalid');
    }
  });
});

// Cek validitas form
const form = document.querySelector('form');
form.addEventListener('submit', (e) => {
  if (!form.checkValidity()) {
    e.preventDefault();
    console.log('Form tidak valid');
  }
});
```
