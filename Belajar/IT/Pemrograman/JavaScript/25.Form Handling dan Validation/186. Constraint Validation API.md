### Definisi Singkat
**Constraint Validation API** memberikan akses JavaScript ke sistem validasi HTML5. Properti seperti **`validity`** (object dengan berbagai boolean), method **`checkValidity()`** dan **`setCustomValidity(message)`** memungkinkan kontrol validasi lebih detail dan pesan error kustom.

---

### Analogi
Constraint Validation API seperti **papan kontrol satpam**. Kamu bisa melihat persis aturan mana yang dilanggar (`validity.valueMissing`, `validity.tooShort`), mengecek ulang secara manual (`checkValidity`), dan mengganti suara satpam dengan suara sendiri (`setCustomValidity`).

---

### Poin-Poin Penting
- `element.validity` — object dengan properti: `valueMissing`, `typeMismatch`, `patternMismatch`, `tooLong`, `tooShort`, `rangeUnderflow`, `rangeOverflow`, `stepMismatch`, `badInput`, `customError`, `valid`
- `element.validationMessage` — pesan error bawaan browser
- `element.checkValidity()` — return boolean, trigger styling :invalid
- `element.reportValidity()` — sama + tampilkan pesan error
- `element.setCustomValidity(msg)` — set pesan error kustom (string kosong = valid)
- `form.noValidate` — nonaktifkan validasi HTML5

---

### Contoh Implementasi

```javascript
const email = document.querySelector('#email');
const password = document.querySelector('#password');
const form = document.querySelector('form');

// Validasi real-time dengan detail
email.addEventListener('input', () => {
  const v = email.validity;

  if (v.valid) {
    email.setCustomValidity('');
    email.classList.remove('error');
    return;
  }

  if (v.valueMissing) {
    email.setCustomValidity('Email wajib diisi');
  } else if (v.typeMismatch) {
    email.setCustomValidity('Format email tidak valid');
  }

  email.classList.add('error');
  email.reportValidity(); // Tampilkan pesan
});

// Custom validation
password.addEventListener('input', () => {
  const value = password.value;

  // Aturan kustom
  if (value.length < 8) {
    password.setCustomValidity('Minimal 8 karakter');
  } else if (!/[A-Z]/.test(value)) {
    password.setCustomValidity('Harus ada huruf besar');
  } else if (!/[0-9]/.test(value)) {
    password.setCustomValidity('Harus ada angka');
  } else {
    password.setCustomValidity(''); // Valid!
  }
});

// Submit
form.addEventListener('submit', (e) => {
  e.preventDefault();
  if (form.checkValidity()) {
    console.log('Form valid, siap dikirim');
  }
});
```
