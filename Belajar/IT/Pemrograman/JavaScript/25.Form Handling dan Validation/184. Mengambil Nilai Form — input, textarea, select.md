### Definisi Singkat
Mengambil nilai dari elemen form menggunakan properti **`value`** untuk `<input>` dan `<textarea>`, serta properti **`value`** dan **`selectedIndex`**/`options` untuk `<select>`. Alternatif modern: **FormData API** untuk mengambil semua data form sekaligus.

---

### Analogi
FormData seperti **baki surat**. Kamu tinggal mengumpulkan semua formulir yang sudah diisi ke dalam baki, tanpa perlu mengambil satu per satu dari setiap meja.

---

### Poin-Poin Penting
- `input.value` — string (default), `input.checked` — boolean (checkbox/radio)
- `textarea.value` — teks (bukan `textContent`)
- `select.value` — nilai option yang dipilih
- `select.selectedOptions` — koleksi option yang dipilih (multiple)
- `FormData` — iterator, `get()`, `getAll()`, `has()`, `append()`, `set()`, `delete()`
- File input: `input.files` — FileList
- `Object.fromEntries(formData)` — konversi ke object biasa

---

### Contoh Implementasi

```javascript
const form = document.querySelector('#myForm');

// Manual satu per satu
function getFormValues() {
  const nama = document.querySelector('#nama').value;
  const email = document.querySelector('#email').value;
  const pesan = document.querySelector('#pesan').value;
  const kota = document.querySelector('#kota').value;
  const setuju = document.querySelector('#setuju').checked;
  const file = document.querySelector('#file').files[0];

  return { nama, email, pesan, kota, setuju, file };
}

// FormData API
function getFormData() {
  const data = new FormData(form);

  // Per nilai
  console.log(data.get('nama'));
  console.log(data.getAll('hobi')); // Multiple values

  // Iterasi
  for (const [key, value] of data) {
    console.log(`${key}: ${value}`);
  }

  // Konversi
  const obj = Object.fromEntries(data);
  const json = JSON.stringify(obj);

  return data; // Siap untuk Fetch
}

// Select multiple
const select = document.querySelector('#hobi');
const selected = Array.from(select.selectedOptions).map(o => o.value);

// Reset form
form.addEventListener('reset', () => {
  console.log('Form direset');
});
```
