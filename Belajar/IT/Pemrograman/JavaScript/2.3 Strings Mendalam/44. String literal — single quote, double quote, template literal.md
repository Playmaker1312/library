### Definisi Singkat

String literal adalah cara menuliskan nilai string di dalam kode JavaScript. Terdapat tiga jenis: **single quote** ('...'), **double quote** ("..."), dan **template literal** (` ... `). Ketiganya digunakan untuk merepresentasikan data teks.

---

### Analogi

Bayangkan Anda ingin menulis catatan di atas kertas:

- **Single quote** seperti menulis dengan pulpen biru — sederhana dan langsung.
- **Double quote** seperti menulis dengan pulpen hitam — fungsi sama, hanya beda warna.
- **Template literal** seperti papan tulis yang bisa diisi ulang — Anda bisa menyisipkan ekspresi di dalamnya dengan ${...}.

---

### Poin-Poin Penting

- **Single Quote ('):** Paling umum digunakan. Tidak bisa menyisipkan variabel langsung.
- **Double Quote ("):** Fungsinya identik dengan single quote. Pilih salah satu dan konsisten.
- **Template Literal (`  `):** Mendukung **string interpolation** (${ekspresi}) dan **multi-line string** tanpa perlu escape \n.
- Tidak ada perbedaan performa signifikan antara ketiganya.
- Pilihlah satu gaya dan gunakan secara konsisten di seluruh proyek.

---

### Contoh Implementasi

`javascript
const nama = "Budi";

// Single quote
const sapa1 = 'Halo, ' + nama + '!';

// Double quote
const sapa2 = "Halo, " + nama + "!";

// Template literal
const sapa3 = Halo, !;

// Multi-line dengan template literal
const puisi = 
  Aku ingin
  belajar JavaScript
  setiap hari.
;

console.log(sapa1);
console.log(sapa2);
console.log(sapa3);
console.log(puisi);
`

---

### Koneksi

Template literal sangat erat kaitannya dengan **String Interpolation** (materi 45) yang memungkinkan penyisipan ekspresi JavaScript di dalam string. Pemilihan jenis string literal juga memengaruhi cara kita menggunakan **Escape Character** (materi 50).
