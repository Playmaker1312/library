# 44. String literal - single quote double quote template literal

**Definisi Singkat:** String bisa ditulis dengan `'...'`, `"..."`, atau `` `...` `` (template literal).

**Analogi:** Tiga jenis gelas: gelas biasa (quote), gelas khusus (template literal) yang bisa diisi variabel.

**Poin-Poin Penting:**
- Single dan double quote tidak ada bedanya di JS
- Template literal mendukung multi-line dan interpolasi `${}`
- Pilih salah satu dan konsisten (Airbnb: single quote)
- Escape dengan `\` jika perlu quote di dalam string

**Contoh Kode:**
```javascript
const single = 'Pakai single quote';
const double = "Pakai double quote";
const template = `Halo, ${single}!`;
console.log(template);
```
Hasil: `Halo, Pakai single quote!`

**Kasus Penggunaan Nyata:**
Template literal dipakai untuk menyusun string dinamis seperti HTML, pesan error, log.
