### Definisi Singkat

**String formatting methods** adalah method bawaan JavaScript untuk memanipulasi struktur dan format string. Mencakup split, concat, epeat, padStart, dan padEnd — digunakan untuk memecah, menggabung, mengulang, dan merapikan string.

---

### Analogi

Bayangkan Anda bekerja dengan pita kertas:

- **split:** Menggunting pita menjadi potongan-potongan kecil berdasarkan pola tertentu.
- **concat:** Menyambung beberapa pita menjadi satu pita panjang.
- **repeat:** Membuat banyak salinan identik dari pita yang sama.
- **padStart:** Menambahkan hiasan di awal pita agar panjangnya sesuai.
- **padEnd:** Menambahkan hiasan di akhir pita agar panjangnya sesuai.

---

### Poin-Poin Penting

- **.split(separator, limit):** Memecah string menjadi array berdasarkan separator. Jika separator kosong (""), pecah per karakter.
- **.concat(str1, str2, ...):** Menggabungkan dua atau lebih string. Alternatif: gunakan operator + atau template literal.
- **.repeat(count):** Mengulang string sebanyak count kali. Error jika count negatif.
- **.padStart(targetLength, padString):** Menambahkan padString di awal hingga panjang mencapai 	argetLength.
- **.padEnd(targetLength, padString):** Sama seperti padStart tapi di akhir.

---

### Contoh Implementasi

`javascript
const data = "apel,mangga,jeruk";

// split
console.log(data.split(","));       // ["apel", "mangga", "jeruk"]
console.log("hello".split(""));     // ["h", "e", "l", "l", "o"]

// concat
const a = "Hello";
const b = " ";
const c = "World";
console.log(a.concat(b, c));        // "Hello World"

// repeat
console.log("HA ".repeat(3));       // "HA HA HA "

// padStart dan padEnd
const angka = "5";
console.log(angka.padStart(3, "0")); // "005"
console.log(angka.padEnd(3, "0"));   // "500"
console.log("123".padStart(5));      // "  123" (spasi default)
`

---

### Koneksi

split dan concat sering digunakan dalam pengolahan **CSV** atau data teks terstruktur. padStart sangat berguna untuk **format tanggal dan jam** (misal: "2" menjadi "02").
