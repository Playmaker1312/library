# 48. String methods - split concat repeat padStart padEnd

**Definisi Singkat:** Methods manipulasi string: memisah, menggabung, mengulang, dan memberi padding.

**Analogi:** `split` seperti memotong sosis per ruas; `padStart` seperti nomor induk yang ditambahi nol di depan.

**Poin-Poin Penting:**
- `split(separator)` mengubah string ke array
- `concat()` jarang dipakai (lebih sering `+` atau template literal)
- `repeat(n)` mengulang string sebanyak n kali
- `padStart(n, char)` dan `padEnd(n, char)` untuk merapikan panjang string

**Contoh Kode:**
```javascript
const csv = "apel,mangga,jeruk";
console.log(csv.split(","));
console.log("Ha".repeat(3));
console.log("5".padStart(3, "0"));
console.log("OK".padEnd(5, "."));
```
Hasil:
```
[ 'apel', 'mangga', 'jeruk' ]
HaHaHa
005
OK...
```

**Kasus Penggunaan Nyata:**
Parsing CSV, membuat progress bar, format nomor invoice dengan leading zero.
