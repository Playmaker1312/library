# 47. String methods - toUpperCase toLowerCase trim replace

**Definisi Singkat:** Methods untuk mengubah kapitalisasi, menghapus spasi, dan mengganti teks.

**Analogi:** Seperti aplikasi edit teks: ubah kapital (toUpperCase), potong margin (trim), cari-ganti (replace).

**Poin-Poin Penting:**
- `toUpperCase()` / `toLowerCase()` mengubah huruf kapital
- `trim()` menghapus spasi di awal dan akhir
- `replace(search, replacement)` hanya mengganti yang pertama
- Gunakan regex dengan `g` flag untuk replace semua
- Semua method ini mengembalikan string baru (immutable)

**Contoh Kode:**
```javascript
const input = "  Halo Dunia  ";
console.log(input.trim());
console.log(input.toUpperCase());
console.log(input.toLowerCase());
console.log(input.trim().replace("Dunia", "Semua"));
```
Hasil:
```
Halo Dunia
  HALO DUNIA  
  halo dunia  
Halo Semua
```

**Kasus Penggunaan Nyata:**
Normalisasi input form (trim + lowercase), censoring kata, formatting display name.
