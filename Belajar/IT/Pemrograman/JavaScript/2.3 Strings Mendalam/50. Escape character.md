### Definisi Singkat

**Escape character** adalah karakter khusus yang diawali dengan backslash (\) di dalam string JavaScript. Digunakan untuk merepresentasikan karakter yang sulit atau tidak mungkin diketik langsung, seperti baris baru (\n), tab (\t), atau tanda kutip di dalam string.

---

### Analogi

Bayangkan Anda menulis dialog dalam novel:

- Jika karakter berkata: "Halo", Anda perlu tanda kutip di dalam tanda kutip.
- Escape character seperti kode rahasia: \" artinya "ini tanda kutip, bukan akhir string".
- Tab dan baris baru juga punya kode: \t untuk menjorok, \n untuk pindah baris baru.

---

### Poin-Poin Penting

- **Cara pakai:** Tulis backslash (\) diikuti karakter yang ingin di-escape.
- **Daftar escape umum:**
  - \' — single quote
  - \" — double quote
  - \\ — backslash itu sendiri
  - \n — baris baru (newline)
  - \t — tab
  - \r — carriage return
  - \b — backspace
  - \0 — null character
- **Template literal** lebih toleran: Anda bisa menggunakan tanda kutip di dalamnya tanpa escape.
- Untuk backslash di path Windows, gunakan \\ atau /.

---

### Contoh Implementasi

`javascript
// Escape tanda kutip
console.log("Dia berkata, \"Halo!\"");
console.log('It\'s a beautiful day');

// Baris baru dan tab
console.log("Nama:\tBudi\nUsia:\t25");

// Backslash literal
const path = "C:\\Users\\Budi\\Documents";
console.log(path);

// Di template literal, lebih mudah
const path2 = C:\Users\Budi\Documents;
console.log(Dia berkata, "Halo!"); // tidak perlu escape

// Unicode escape
console.log("\u00A9");  // ©
console.log("\u{1F600}"); // 😀
`

---

### Koneksi

Escape character berkaitan erat dengan **String Literal** (materi 44) — setiap jenis string literal memiliki aturan escape yang sedikit berbeda. Di **RegExp**, escape character juga digunakan untuk makna khusus seperti \d (digit).
