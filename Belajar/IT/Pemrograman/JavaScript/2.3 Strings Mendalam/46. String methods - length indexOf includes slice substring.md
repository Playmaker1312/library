# 46. String methods - length indexOf includes slice substring

**Definisi Singkat:** Methods dasar untuk mengetahui panjang, posisi, dan mengambil bagian string.

**Analogi:** Seperti penggaris: ukur panjang (length), cari posisi kata (indexOf), potong bagian (slice).

**Poin-Poin Penting:**
- `.length` adalah properti (bukan method)
- `.indexOf()` mengembalikan index pertama, `-1` jika tidak ditemukan
- `.includes()` mengembalikan boolean
- `.slice(start, end)` mengambil potongan string, end tidak termasuk
- `.substring()` mirip slice tapi tidak support indeks negatif

**Contoh Kode:**
```javascript
const text = "JavaScript itu menyenangkan";
console.log(text.length);
console.log(text.indexOf("itu"));
console.log(text.includes("Java"));
console.log(text.slice(0, 10));
console.log(text.substring(0, 10));
```
Hasil:
```
26
10
true
JavaScript
JavaScript
```
