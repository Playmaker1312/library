# 49. String immutability - konsep penting

**Definisi Singkat:** String di JavaScript bersifat *immutable* — tidak bisa diubah setelah dibuat.

**Analogi:** Seperti ukiran di batu — tidak bisa dihapus, harus buat batu baru untuk tulisan baru.

**Poin-Poin Penting:**
- Method seperti `toUpperCase()` mengembalikan string **baru**
- String asli tidak pernah berubah
- Operasi seperti `s[0] = "x"` tidak akan mengubah string
- Setiap manipulasi string membuat alokasi memori baru

**Contoh Kode:**
```javascript
let kata = "hello";
kata[0] = "H"; // Tidak berfungsi!
console.log(kata);

kata = kata[0].toUpperCase() + kata.slice(1);
console.log(kata);
```
Hasil:
```
hello
Hello
```

**Kasus Penggunaan Nyata:**
Memahami immutability penting untuk performance — banyak operasi string dalam loop besar bisa lambat.
