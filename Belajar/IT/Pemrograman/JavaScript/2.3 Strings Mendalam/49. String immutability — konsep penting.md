### Definisi Singkat

**String immutability** adalah konsep fundamental di JavaScript di mana nilai string **tidak dapat diubah setelah dibuat**. Operasi apa pun yang tampak mengubah string sebenarnya menghasilkan **string baru** tanpa memodifikasi string asli.

---

### Analogi

Bayangkan Anda memiliki tulisan di atas batu:

- String asli adalah batu yang sudah diukir — Anda tidak bisa mengubah ukirannya.
- Jika ingin "mengubah" tulisan, Anda harus membuat batu baru dengan ukiran baru.
- Batu yang lama tetap ada seperti semula.

Berbeda dengan menulis di pasir yang bisa dihapus dan ditulis ulang — string itu seperti batu, bukan pasir.

---

### Poin-Poin Penting

- **Immutable = tidak bisa diubah.** Setelah string dibuat, isinya tetap selamanya.
- let vs const: let memungkinkan Anda menunjuk ke string baru, tapi string lama tetap tidak berubah.
- Method seperti .toUpperCase(), .slice(), .trim() semuanya mengembalikan **string baru**.
- Mengubah string dengan indeks (str[0] = "X") **tidak akan bekerja** — tidak ada error tapi tidak ada perubahan.
- Konsep ini penting untuk optimasi memori dan keamanan data.

---

### Contoh Implementasi

`javascript
let nama = "Budi";

// Mencoba mengubah karakter pertama — tidak berhasil
nama[0] = "S";
console.log(nama); // "Budi" (tetap)

// Method string mengembalikan string baru
let namaKapital = nama.toUpperCase();
console.log(namaKapital); // "BUDI"
console.log(nama);        // "Budi" (asli tidak berubah)

// Re-assignment bukan mutation
nama = "Siti";
console.log(nama); // "Siti"
// Ini bukan mengubah string "Budi", tapi mengarahkan variabel ke string baru

// Bukti immutability
const a = "Hello";
const b = a.toUpperCase();
console.log(a === "Hello"); // true
console.log(b === "HELLO"); // true
console.log(a === b);       // false
`

---

### Koneksi

Konsep immutability tidak hanya berlaku untuk string, tapi juga untuk **number** dan **boolean** (primitive types). Ini berbeda dengan **Array** dan **Object** yang bersifat **mutable** — mereka bisa diubah langsung.
