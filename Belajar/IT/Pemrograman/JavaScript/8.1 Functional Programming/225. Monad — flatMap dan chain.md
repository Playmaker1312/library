### Definisi Singkat

Monad adalah struktur data dalam functional programming yang merepresentasikan **komputasi sebagai langkah-langkah berantai**. Monad memiliki method `flatMap` (atau `chain`/`bind`) yang memungkinkan komposisi fungsi yang mengembalikan nilai dalam konteks yang sama. Monad adalah Functor dengan kemampuan **flatten**.

---

### Analogi

Seperti **mesin ATM yang mengembalikan amplop berisi uang**, bukan uang lepas. Anda mengambil amplop (konteks), membukanya, lalu memasukkan uang ke mesin ATM lain. `flatMap` adalah proses: buka amplop → ambil uang → masukkan ke mesin berikutnya → dapat amplop baru. `map` biasa seperti menerima amplop dan menempel stiker di luarnya.

---

### Poin-Poin Penting

- Monad memiliki: `of` (membungkus nilai) dan `flatMap`/`chain` (transformasi + flatten)
- Hukum Monad: left identity, right identity, associativity
- `flatMap(f)` = `map(f)` lalu `flatten()` — menggabungkan layer container
- Contoh Monad: Promise (`.then()`), Array (`.flatMap()`), Maybe, Either, IO
- **Maybe** — monad untuk null safety (tanpa error)
- **Either** — monad untuk error handling tanpa throw (Left = error, Right = success)
- Berguna untuk menghindari callback hell dan exception hell

### Contoh Implementasi

```javascript
// Maybe Monad
class Maybe {
  constructor(value) {
    this.value = value;
  }

  static of(value) {
    return new Maybe(value);
  }

  map(fn) {
    return this.value == null ? Maybe.of(null) : Maybe.of(fn(this.value));
  }

  flatMap(fn) {
    return this.value == null ? Maybe.of(null) : fn(this.value);
  }

  getOrElse(defaultValue) {
    return this.value != null ? this.value : defaultValue;
  }
}

// Either Monad
class Either {
  constructor(left, right) {
    this.left = left;
    this.right = right;
  }

  static left(value) {
    return new Either(value, null);
  }

  static right(value) {
    return new Either(null, value);
  }

  isLeft() { return this.left != null; }
  isRight() { return this.right != null; }

  map(fn) {
    return this.isLeft() ? this : Either.right(fn(this.right));
  }

  flatMap(fn) {
    return this.isLeft() ? this : fn(this.right);
  }

  fold(leftFn, rightFn) {
    return this.isLeft() ? leftFn(this.left) : rightFn(this.right);
  }
}

// Contoh penggunaan
function divide(a, b) {
  return b === 0
    ? Either.left('Tidak bisa dibagi nol')
    : Either.right(a / b);
}

const result = Either.right(10)
  .flatMap(x => divide(x, 2))
  .flatMap(x => divide(x, 0))  // Akan menghasilkan Left
  .map(x => x * 100);

console.log(result.fold(
  err => `Error: ${err}`,
  val => `Hasil: ${val}`
)); // "Error: Tidak bisa dibagi nol"

// Promise sebagai Monad (mirip)
Promise.resolve(5)
  .then(x => x * 2)    // map
  .then(x => Promise.resolve(x + 1)) // flatMap (then otomatis flatten)
  .then(console.log);  // 11
```

### Koneksi

Monad adalah pengembangan dari **Functor** (file 224). Monad memungkinkan komposisi fungsi yang mengembalikan container — sesuatu yang tidak bisa dilakukan `map` biasa (akan nested). Konsep ini terkait dengan **Transducers** (file 226) untuk komposisi transformasi yang efisien.
