### Definisi Singkat

Function Composition adalah teknik menggabungkan dua atau lebih fungsi untuk menghasilkan fungsi baru, di mana output dari satu fungsi menjadi input untuk fungsi berikutnya. `compose` dan `pipe` adalah utilities untuk melakukan komposisi secara deklaratif — `compose` dari kanan ke kiri, `pipe` dari kiri ke kanan.

---

### Analogi

Seperti **jalur perakitan pabrik** — bahan mentah masuk di satu sisi, melewati serangkaian stasiun kerja (fungsi), masing-masing melakukan satu transformasi, hingga menjadi produk jadi. `pipe` seperti urutan stasiun dari awal ke akhir; `compose` dari akhir ke awal.

---

### Poin-Poin Penting

- Komposisi lebih diutamakan daripada inheritance (prinsip FP)
- `compose(f, g)(x)` = `f(g(x))` — dari kanan ke kiri
- `pipe(f, g)(x)` = `g(f(x))` — dari kiri ke kanan (lebih intuitif)
- Fungsi harus **unary** (satu parameter) untuk komposisi optimal
- Setiap fungsi dalam komposisi harus pure
- Komposisi menghasilkan fungsi point-free (tanpa menyebut argumen)
- Berguna untuk pipeline transformasi data

---

### Contoh Implementasi

```javascript
// Implementasi compose dan pipe manual
const compose = (...fns) => (x) => fns.reduceRight((acc, fn) => fn(acc), x);
const pipe   = (...fns) => (x) => fns.reduce((acc, fn) => fn(acc), x);

// Fungsi-fungsi kecil
const toUpperCase = (str) => str.toUpperCase();
const exclaim = (str) => `${str}!`;
const repeat = (str) => `${str} ${str}`;

// ❌ Tanpa komposisi (bersarang)
const result1 = repeat(exclaim(toUpperCase('halo')));

// ✅ Dengan compose (kanan ke kiri)
const shoutCompose = compose(repeat, exclaim, toUpperCase);
console.log(shoutCompose('halo')); // "HALO! HALO!"

// ✅ Dengan pipe (kiri ke kanan)
const shoutPipe = pipe(toUpperCase, exclaim, repeat);
console.log(shoutPipe('halo')); // "HALO! HALO!"

// Contoh pipeline data
const users = [
  { name: 'Budi', age: 17 },
  { name: 'Ani', age: 22 },
  { name: 'Cici', age: 30 }
];

const getAdultNames = pipe(
  (arr) => arr.filter(user => user.age >= 18),
  (arr) => arr.map(user => user.name),
  (arr) => arr.sort()
);

console.log(getAdultNames(users)); // ["Ani", "Cici"]
```

### Koneksi

Function composition membutuhkan **Pure Functions** (file 221) dan **Immutability** (file 222) agar komposisi bisa diprediksi. Konsep ini mengarah ke pola **Functor** (file 224) untuk komposisi dalam konteks (container), dan **Monad** (file 225) untuk komposisi dengan efek samping.
