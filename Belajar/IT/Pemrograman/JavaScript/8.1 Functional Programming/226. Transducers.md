### Definisi Singkat

Transducers adalah pola functional programming untuk **komposisi transformasi data yang efisien** — memisahkan transformasi (map, filter, reduce) dari sumber data dan execution context. Transducers memungkinkan transformasi berantai tanpa membuat array intermediate di setiap langkah.

---

### Analogi

Seperti **ban berjalan di pabrik** — Anda ingin menyortir apel (filter), mengupasnya (map), dan mengemasnya (map). Tanpa transducer, Anda harus mengumpulkan semua apel setelah disortir, lalu mengupasnya, lalu mengemasnya — butuh tiga tempat. Dengan transducer, apel melewati semua stasiun dalam satu aliran.

---

### Poin-Poin Penting

- Transducer adalah fungsi yang menerima transformator dan mengembalikan transformator
- Transducer memungkinkan komposisi map, filter, reduce tanpa array intermediate
- **Efisien**: satu pass melalui data, bukan n pass
- **Dekoupled**: transformasi tidak tergantung sumber data (array, stream, observable)
- Pola umum: `compose(filter(fn1), map(fn2), map(fn3))`
- Implementasi menggunakan reducer (accumulator-based)
- Library: Ramda (`R.transduce`), `transducers-js`

---

### Contoh Implementasi

```javascript
// Implementasi transducer sederhana
const map = (fn) => (reducer) => (acc, val) => reducer(acc, fn(val));
const filter = (predicate) => (reducer) => (acc, val) =>
  predicate(val) ? reducer(acc, val) : acc;

const compose = (...fns) => (x) => fns.reduceRight((acc, fn) => fn(acc), x);

// Transducer pipeline
const transducer = compose(
  filter(x => x % 2 === 0),  // Genap saja
  map(x => x * 2),           // Gandakan
  map(x => x + 1)            // Tambah 1
);

// Reducer dasar (push ke array)
const arrayReducer = (acc, val) => { acc.push(val); return acc; };

// Aplikasi transducer
const result = [1, 2, 3, 4, 5].reduce(transducer(arrayReducer), []);
console.log(result); // [5, 9]  → proses: 2*2+1=5, 4*2+1=9

// Tanpa transducer (3 pass, 3 array intermediate)
const without = [1, 2, 3, 4, 5]
  .filter(x => x % 2 === 0)
  .map(x => x * 2)
  .map(x => x + 1);
// Sama hasilnya: [5, 9]
```

### Koneksi

Transducers mengkomposisikan transformasi dari **Function Composition** (file 223) dengan efisiensi tinggi. Konsep ini terkait dengan **Functor** (file 224) dan **Monad** (file 225) dalam hal komposisi operasi. Transducer populer di library seperti **RxJS** (observable) dan **Redux** (middleware).
