### Definisi Singkat
Private method adalah method yang dideklarasikan dengan prefix `#` dan hanya bisa dipanggil dari dalam class itu sendiri. Method ini tidak bisa diakses dari luar atau diwarisi.

---
### Analogi
Seperti resep rahasia keluarga di buku masak: Anda bisa menggunakannya di dapur sendiri, tapi tamu tidak bisa membuka buku itu. Bahkan anak chef harus minta izin.

---
### Poin-Poin Penting
- Dideklarasikan dengan `#methodName() { ... }`
- Tidak bisa diakses dari luar class (`obj.#method()` error)
- Tidak bisa di-override di child class
- Berguna untuk internal logic/helper functions
- Mendukung getter/setter private juga

---
### Contoh Implementasi
```javascript
class UserManager {
  #users = [];

  constructor() {
    this.#init();
  }

  // Private method
  #init() {
    this.#users = [];
    this.#log('UserManager initialized');
  }

  #log(message) {
    console.log(`[LOG]: ${message}`);
  }

  #validateUser(user) {
    return user && user.name && user.email;
  }

  #generateId() {
    return Math.random().toString(36).substr(2, 9);
  }

  // Public API
  addUser(name, email) {
    const user = { id: this.#generateId(), name, email };

    if (this.#validateUser(user)) {
      this.#users.push(user);
      this.#log(`User ${name} ditambahkan`);
      return user;
    }

    throw new Error('Data user tidak valid');
  }

  getUsers() {
    return [...this.#users];
  }

  // Private getter
  get #userCount() {
    return this.#users.length;
  }

  getStats() {
    return { count: this.#userCount };
  }
}

const manager = new UserManager();
manager.addUser('Andi', 'andi@email.com');
manager.addUser('Budi', 'budi@email.com');
console.log(manager.getStats()); // { count: 2 }
// manager.#log('test'); // SyntaxError!
// manager.#validateUser({}); // SyntaxError!
```
