### Definisi Singkat
Encapsulation dengan closure memanfaatkan function scope untuk menyembunyikan data. Variabel yang dideklarasikan di dalam fungsi tidak bisa diakses dari luar, hanya melalui function yang dikembalikan (privileged methods).

---
### Analogi
Seperti loker penitipan barang: Anda memasukkan barang (data) ke loker, lalu hanya punya kunci (function) untuk mengambilnya. Orang lain tidak bisa membuka loker tanpa kunci.

---
### Poin-Poin Penting
- Variabel lokal di dalam function bersifat private
- Inner function (closure) bisa mengakses variabel tersebut
- Data benar-benar tersembunyi dari scope luar
- Setiap instance memiliki closure sendiri
- Pattern sebelum class dan private fields ada

---
### Contoh Implementasi
```javascript
function createCounter() {
  // Private variable — hanya bisa diakses lewat closure
  let count = 0;

  return {
    increment() {
      count++;
      return count;
    },
    decrement() {
      count--;
      return count;
    },
    getCount() {
      return count;
    },
    reset() {
      count = 0;
    },
  };
}

const counter = createCounter();
console.log(counter.increment()); // 1
console.log(counter.increment()); // 2
console.log(counter.getCount());  // 2
// console.log(counter.count);    // undefined — tidak bisa akses langsung

// Contoh dengan constructor function
function createBankAccount(initialBalance) {
  let balance = initialBalance;

  return {
    deposit(amount) {
      if (amount > 0) {
        balance += amount;
        return balance;
      }
      throw new Error('Invalid amount');
    },
    withdraw(amount) {
      if (amount <= balance) {
        balance -= amount;
        return balance;
      }
      throw new Error('Saldo tidak cukup');
    },
    getBalance() {
      return balance;
    },
  };
}

const rekening = createBankAccount(1000000);
console.log(rekening.deposit(500000));  // 1500000
console.log(rekening.withdraw(200000)); // 1300000
// console.log(rekening.balance);       // undefined
```
