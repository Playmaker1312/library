### Definisi Singkat
Symbol digunakan untuk membuat properti object yang "tersembunyi" karena key-nya unik dan tidak bisa ditebak. Symbol tidak benar-benar private (masih bisa diakses via `Object.getOwnPropertySymbols`), tetapi memberikan tingkat privasi lebih baik daripada string key.

---
### Analogi
Seperti lemari dengan kunci khusus (Symbol) yang hanya Anda miliki. Orang lain bisa melihat ada lemari, tapi tidak bisa membukanya tanpa kunci yang tepat. Namun detektif (Reflect.ownKeys) masih bisa membuka semua lemari.

---
### Poin-Poin Penting
- Symbol selalu unik: `Symbol('desc') !== Symbol('desc')`
- Properti dengan key Symbol tidak muncul di `for...in` atau `Object.keys()`
- Masih bisa diakses via `Object.getOwnPropertySymbols()` dan `Reflect.ownKeys()`
- Berguna untuk metadata atau internal properties
- Bisa digunakan dengan computed property syntax

---
### Contoh Implementasi
```javascript
// Membuat Symbol untuk private properties
const _balance = Symbol('balance');
const _pin = Symbol('pin');
const _log = Symbol('log');

class BankAccount {
  constructor(owner, initialBalance, pin) {
    this.owner = owner;
    this[_balance] = initialBalance; // Symbol key
    this[_pin] = pin;
  }

  // Symbol sebagai method
  [_log](message) {
    console.log(`[${this.owner}]: ${message}`);
  }

  deposit(amount) {
    if (amount > 0) {
      this[_balance] += amount;
      this[_log](`Deposit ${amount}`);
      return this[_balance];
    }
  }

  getBalance() {
    return this[_balance];
  }

  // Mendapatkan semua keys — symbol tidak tampak
  getOwnKeys() {
    return Object.keys(this); // tanpa symbol
  }
}

const account = new BankAccount('Andi', 1000000, 1234);
console.log(account.owner);        // "Andi"
console.log(account.getBalance()); // 1000000
console.log(Object.keys(account)); // ["owner"] — symbol tidak muncul
// console.log(account._balance);  // undefined — bukan symbol yang benar

// Tapi masih bisa diakses dengan cara:
const symbols = Object.getOwnPropertySymbols(account);
console.log(account[symbols[0]]); // 1000000 — private tersembunyi
```
