### Definisi Singkat

Module Pattern adalah pola desain yang menggunakan **closure** (IIFE — Immediately Invoked Function Expression) untuk membuat kapsulisasi: data dan method privat tersembunyi di dalam closure, sementara hanya API publik yang diekspos. Ini adalah cara untuk mencapai **information hiding** sebelum JavaScript memiliki class/module sintaks resmi.

---

### Analogi

Seperti **mesin kopi** — Anda hanya melihat tombol (public API): "Espresso", "Cappuccino", "Latte". Anda tidak tahu bagaimana air dipanaskan, biji digiling, atau tekanan pompa (private). Tombol adalah antarmuka publik; mekanisme internal tersembunyi.

---

### Poin-Poin Penting

- Menggunakan IIFE untuk membuat scope privat
- Variabel dan fungsi di dalam IIFE tidak bisa diakses dari luar (privat)
- Objek yang direturn menjadi API publik
- Bisa mengakses variabel privat via closure (privileged methods)
- Mencegah polusi global namespace
- Dapat diperluas (augmentation) dengan module augmentation
- Sebelum ES Modules, ini adalah standar de facto untuk modularitas

---

### Contoh Implementasi

```javascript
// Module Pattern dasar
const CounterModule = (function() {
  // Private
  let count = 0;

  function log(message) {
    console.log(`[Counter] ${message}`);
  }

  // Public API
  return {
    increment() {
      count++;
      log(`Count menjadi ${count}`);
    },
    decrement() {
      count--;
      log(`Count menjadi ${count}`);
    },
    getCount() {
      return count;
    },
    reset() {
      count = 0;
      log('Counter di-reset');
    }
  };
})();

// Penggunaan
CounterModule.increment(); // [Counter] Count menjadi 1
CounterModule.increment(); // [Counter] Count menjadi 2
console.log(CounterModule.getCount()); // 2
console.log(CounterModule.count); // undefined (privat)

// Revealing Module Pattern
const UserModule = (function() {
  const users = [];

  function add(name) { users.push({ name }); }
  function getAll() { return [...users]; }
  function count() { return users.length; }

  return {
    addUser: add,
    listUsers: getAll,
    userCount: count
  };
})();
```
