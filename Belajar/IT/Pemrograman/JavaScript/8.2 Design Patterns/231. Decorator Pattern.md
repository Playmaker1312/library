### Definisi Singkat

Decorator Pattern adalah pola desain yang memungkinkan **menambahkan perilaku** ke objek atau fungsi secara dinamis, tanpa mengubah struktur aslinya. Di JavaScript, dekorator bisa diimplementasikan sebagai fungsi wrapper (higher-order functions), atau menggunakan sintaks `@decorator` (masih proposal stage) untuk class.

---

### Analogi

Seperti **aksesoris ponsel** — Anda punya ponsel polos. Tambahkan case (tambah proteksi), tambahkan screen protector, tambahkan ring holder. Ponsel asli tidak berubah, tapi fungsinya bertambah. Anda bisa menambah atau melepas aksesoris kapan saja tanpa merusak ponsel.

---

### Poin-Poin Penting

- Function decorator: fungsi yang menerima fungsi dan mengembalikan fungsi baru dengan tambahan perilaku
- Class decorator (proposal): `@decorator` sebelum class/method/property
- Berguna untuk: logging, caching, validation, authorization, timing
- Dekorator bisa dikomposisi (multiple decorators)
- Tidak mengubah fungsi/class asli — prinsip Open/Closed
- Di JavaScript, higher-order function adalah cara paling umum untuk dekorator
- TypeScript memiliki dukungan dekorator eksperimental

### Contoh Implementasi

```javascript
// Function decorator
function withLogging(fn) {
  return function(...args) {
    console.log(`Memanggil ${fn.name} dengan:`, args);
    const result = fn.apply(this, args);
    console.log(`Hasil:`, result);
    return result;
  };
}

function withTiming(fn) {
  return function(...args) {
    const start = Date.now();
    const result = fn.apply(this, args);
    console.log(`${fn.name} selesai dalam ${Date.now() - start}ms`);
    return result;
  };
}

function withCache(fn) {
  const cache = new Map();
  return function(...args) {
    const key = JSON.stringify(args);
    if (cache.has(key)) return cache.get(key);
    const result = fn.apply(this, args);
    cache.set(key, result);
    return result;
  };
}

// Fungsi asli
function add(a, b) {
  return a + b;
}

// Dekorasi
const decoratedAdd = withLogging(withTiming(add));
console.log(decoratedAdd(3, 4));
// Memanggil add dengan: [3, 4]
// add selesai dalam 0ms
// Hasil: 7
// 7

// Dekorator validasi
function withValidation(schema) {
  return function(target) {
    return function(...args) {
      // Validasi args berdasarkan schema
      return target.apply(this, args);
    };
  };
}

// Contoh class decorator (menggunakan fungsi wrapper)
function readonly(target, key, descriptor) {
  descriptor.writable = false;
  return descriptor;
}
```
