### Definisi Singkat

Singleton Pattern memastikan sebuah class hanya memiliki **satu instance** sepanjang aplikasi berjalan, dan menyediakan titik akses global ke instance tersebut. Di JavaScript, Singleton bisa diimplementasikan dengan berbagai cara: module pattern, class dengan static method, atau global variable.

---

### Analogi

Seperti **resepsionis di hotel** — hanya ada satu orang yang melayani semua tamu. Tidak peduli berapa kali Anda menelepon front desk, Anda selalu terhubung ke orang yang sama. Jika ada dua resepsionis, akan kacau (dua instance).

---

### Poin-Poin Penting

- Memastikan hanya satu instance yang dibuat
- Menyediakan akses global ke instance tersebut
- Berguna untuk: database connection, konfigurasi, logging, caching
- Di JavaScript, Singleton bisa diimplementasikan via:
  - Object literal (singleton paling sederhana)
  - Class dengan static getter
  - Module pattern (instance disimpan di closure)
- Hati-hati dengan state global — bisa menyulitkan testing
- ES Modules sebenarnya sudah bersifat singleton (module hanya di-load sekali)

### Contoh Implementasi

```javascript
// Cara 1: Object literal
const Config = {
  apiUrl: 'https://api.example.com',
  timeout: 5000,
  getConfig() {
    return { apiUrl: this.apiUrl, timeout: this.timeout };
  }
};

// Cara 2: Class dengan static getter
class Database {
  constructor() {
    if (Database.instance) return Database.instance;
    this.connection = null;
    Database.instance = this;
  }

  connect(url) {
    this.connection = url;
    console.log(`Terhubung ke ${url}`);
  }

  query(sql) {
    console.log(`Menjalankan: ${sql}`);
  }
}

const db1 = new Database();
const db2 = new Database();
console.log(db1 === db2); // true

// Cara 3: Module closure
const Logger = (function() {
  let instance;

  function createInstance() {
    return {
      logs: [],
      log(message) {
        this.logs.push(message);
        console.log(`[LOG] ${message}`);
      },
      getLogs() { return [...this.logs]; }
    };
  }

  return {
    getInstance() {
      if (!instance) instance = createInstance();
      return instance;
    }
  };
})();

const logger1 = Logger.getInstance();
const logger2 = Logger.getInstance();
console.log(logger1 === logger2); // true
```
