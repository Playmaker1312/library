### Definisi Singkat
Property shadowing (atau property overriding) terjadi ketika sebuah properti pada objek memiliki nama yang sama dengan properti di prototype chain-nya, sehingga properti di objek sendiri "menutupi" properti di prototype.

---
### Analogi
Seperti aturan berpakaian keluarga: semua anggota keluarga punya aturan "baju biru" dari orang tua. Tapi Anda bisa memakai baju merah di rumah sendiri — aturan Anda menutupi aturan keluarga.

---
### Poin-Poin Penting
- Properti sendiri selalu diutamakan daripada properti prototype
- Shadowing tidak mengubah properti di prototype
- Assignment (`obj.prop = value`) pada properti yang ada di prototype akan **membuat properti baru** di objek (shadowing), bukan mengubah prototype
- Gunakan `delete obj.prop` untuk menghapus properti sendiri dan mengakses kembali properti prototype
- Hanya properti yang diwarisi melalui prototype yang bisa di-shadow

---
### Contoh Implementasi
```javascript
const prototypeObj = {
  nama: 'Prototype',
  greet() {
    console.log(`Halo dari ${this.nama}`);
  },
};

const obj = Object.create(prototypeObj);
obj.nama = 'Instance'; // shadowing!

console.log(obj.nama); // "Instance" — milik sendiri
console.log(prototypeObj.nama); // "Prototype" — tidak berubah

obj.greet(); // "Halo dari Instance" — this.nama merujuk ke shadowed

// Menghapus shadowing
delete obj.nama;
console.log(obj.nama); // "Prototype" — kembali ke prototype

// Contoh dengan method shadowing
const induk = {
  method() {
    console.log('Method induk');
  },
};

const anak = Object.create(induk);
anak.method = function () {
  console.log('Method anak (override)');
};

anak.method();  // "Method anak (override)"
induk.method(); // "Method induk"
```

---
### Koneksi
Berkaitan dengan **prototype chain**, **prototypal inheritance**, **property lookup**, dan **delete operator**.
