### Definisi Singkat
`constructor` adalah properti pada `prototype` suatu fungsi yang menunjuk kembali ke fungsi itu sendiri. Ini menyediakan referensi ke constructor function yang membuat instance.

---
### Analogi
Seperti stempel pada produk yang bertuliskan "Dibuat oleh: [nama pabrik]". Setiap produk jadi memiliki informasi siapa pembuatnya.

---
### Poin-Poin Penting
- Setiap fungsi secara otomatis memiliki properti `prototype.constructor`
- Instance mewarisi `constructor` melalui prototype chain
- Berguna untuk mengetahui constructor asal sebuah instance
- Saat meng-override prototype, properti `constructor` harus diperbaiki manual
- Digunakan oleh JavaScript untuk beberapa operasi internal

---
### Contoh Implementasi
```javascript
function Person(name) {
  this.name = name;
}

const andi = new Person('Andi');

// constructor menunjuk ke fungsi asli
console.log(Person.prototype.constructor === Person); // true
console.log(andi.constructor === Person);             // true
console.log(andi.constructor.name);                   // "Person"

// Membuat instance baru dari constructor property
const budi = new andi.constructor('Budi');
console.log(budi.name); // "Budi"

// PERINGATAN: saat meng-override prototype
function Animal(name) {
  this.name = name;
}

Animal.prototype = {
  speak() {
    console.log(`${this.name} bersuara`);
  },
};

const cat = new Animal('Kitty');
console.log(cat.constructor === Animal); // false! — constructor hilang
console.log(cat.constructor === Object); // true

// Perbaiki dengan explicit constructor
Animal.prototype = {
  constructor: Animal,
  speak() {
    console.log(`${this.name} bersuara`);
  },
};
```
