### Definisi Singkat

**Async Generator** adalah fungsi generator (`function*`) yang ditambah `async` — menjadi `async function*`. Ia menghasilkan **async iterator** yang mengembalikan Promise. Setiap `yield` bisa menunggu operasi async (`await`), memungkinkan pengiriman data secara bertahap dari sumber async.

---

### Analogi

Seperti **mesin dispensing air minum otomatis** — Anda memasukkan koin (panggil `.next()`), mesin memompa air dari tandon (await), lalu mengeluarkan segelas air (yield). Anda bisa minum gelas pertama sambil menunggu gelas kedua diisi. Prosesnya bertahap dan setiap langkah bisa "menunggu".

---

### Poin-Poin Penting

- Ditulis: `async function* generateData() { ... }`.
- `yield` bisa diikuti `await`: `yield await fetch(url)`.
- Hasilnya adalah **AsyncIterable** — bisa dipakai dengan `for await...of`.
- Error bisa di-throw dari dalam async generator dan ditangkap di konsumen.
- Berguna untuk pagination API, streaming data dari database, atau polling.
- `return` di async generator akan mengakhiri iterasi (mirip sync generator).

---

### Contoh Implementasi

```javascript
// Async generator untuk pagination API
async function* paginate(url, maxPages = 5) {
  let page = 1;
  let hasNext = true;

  while (hasNext && page <= maxPages) {
    const response = await fetch(`${url}?page=${page}`);
    const data = await response.json();

    yield data.items; // Yield array items

    hasNext = data.next !== null;
    page++;
  }
}

async function main() {
  const url = 'https://api.example.com/posts';
  for await (const items of paginate(url)) {
    console.log(`Menerima ${items.length} item`);
    for (const item of items) {
      // Proses item satu per satu
    }
  }
}

// Async generator dengan delay — simulasi streaming
async function* streamNumbers(max) {
  for (let i = 1; i <= max; i++) {
    await new Promise((r) => setTimeout(r, 200));
    yield i;
  }
}

// Async generator dengan error handling
async function* safeFetch(urls) {
  for (const url of urls) {
    try {
      const res = await fetch(url);
      if (!res.ok) throw new Error(`HTTP ${res.status}`);
      yield res.json();
    } catch (err) {
      yield { error: err.message, url }; // Yield error sebagai data
    }
  }
}
```

---

### Koneksi

Berkaitan dengan **Async Iterators** (`for await...of` mengonsumsi async generator), **Generators** (konsep dasar), **Streams** (alternatif untuk produksi data bertahap), **Fetch API** (sumber async), dan **RxJS** (Observable bisa dibuat dari async generator).
