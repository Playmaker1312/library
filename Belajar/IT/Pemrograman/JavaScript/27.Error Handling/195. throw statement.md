### Definisi Singkat
**`throw`** adalah statement untuk "melempar" error secara manual ketika kondisi yang tidak diinginkan terjadi. Kita bisa melempar **Error object**, **string**, **number**, **boolean**, atau **object** apa pun — tapi praktik terbaik menggunakan `new Error()`.

---

### Analogi
`throw` seperti **menekan tombol darurat** di pabrik. Ketika mesin mendeteksi suhu terlalu panas (`kondisi error`), kamu menekan tombol darurat (`throw`) yang menghentikan produksi dan memberi tahu operator (`catch`).

---

### Poin-Poin Penting
- `throw new Error('pesan')` — cara standar dan terbaik
- Bisa throw apa pun: `throw 'error'`, `throw 404`, `throw { code: 500 }`
- Setelah `throw`, eksekusi fungsi berhenti
- Error akan naik ke `catch` terdekat, atau ke `window.onerror` / `unhandledrejection`
- Gunakan **Error object** karena menyimpan stack trace
- Lebih informatif: `TypeError`, `RangeError`, `SyntaxError`, dll.

---

### Contoh Implementasi

```javascript
// Basic throw
function validateAge(age) {
  if (age < 0) {
    throw new Error('Umur tidak boleh negatif');
  }
  if (age > 150) {
    throw new RangeError('Umur tidak masuk akal');
  }
  return `Umur valid: ${age}`;
}

try {
  console.log(validateAge(-5));
} catch (err) {
  console.log(`${err.name}: ${err.message}`);
}

// Throw dengan berbagai tipe (hindari!)
function risky(data) {
  if (!data) throw 'Data kosong';
  if (data.length > 10) throw 413;
  if (typeof data !== 'object') throw { code: 400, msg: 'Invalid type' };
}

// Re-throw — tangkap, log, lalu lempar lagi
try {
  parseUserInput(input);
} catch (err) {
  console.log('Logging error:', err);
  throw err; // Biarkan handler lain menangani
}

// Throw di promise
async function fetchData(url) {
  const res = await fetch(url);
  if (!res.ok) {
    throw new Error(`HTTP ${res.status}: ${res.statusText}`);
  }
  return res.json();
}
```
