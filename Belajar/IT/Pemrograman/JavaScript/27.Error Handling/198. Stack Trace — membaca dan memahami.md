### Definisi Singkat
**Stack trace** adalah daftar urutan pemanggilan fungsi (call stack) pada saat error terjadi. Properti **`error.stack`** berisi informasi baris, file, dan urutan fungsi yang menyebabkan error — sangat penting untuk debugging.

---

### Analogi
Stack trace seperti **rekaman CCTV perjalanan error**. Kamu bisa melihat langkah demi langkah bagaimana program sampai ke titik error — mulai dari fungsi pertama (paling bawah) sampai ke fungsi terakhir (paling atas) yang langsung menyebabkan error.

---

### Poin-Poin Penting
- `error.stack` — string berisi urutan call stack
- Baris paling atas = tempat error terjadi
- Baris paling bawah = entry point program
- Format: `at functionName (file:line:column)`
- Setiap `throw` atau error baru menghasilkan stack trace baru
- Async operations memutus stack trace (tapi async/await memperbaikinya)
- Source maps membantu membaca stack trace dari kode production (minified)

---

### Contoh Implementasi

```javascript
// Membaca stack trace
function first() { second(); }
function second() { third(); }
function third() {
  throw new Error('Cek stack trace!');
}

try {
  first();
} catch (err) {
  console.log('=== PESAN ===');
  console.log(err.message);

  console.log('=== STACK TRACE ===');
  console.log(err.stack);

  // Output:
  // Error: Cek stack trace!
  //   at third (file.js:5:9)
  //   at second (file.js:4:25)
  //   at first (file.js:3:25)
  //   at file.js:9:5
}

// Stack trace dengan async/await
async function fetchUser() {
  await delay(100);
  throw new Error('Gagal fetch');
}

async function load() {
  try {
    await fetchUser();
  } catch (err) {
    console.log(err.stack);
    // Async/await mempertahankan stack trace yang jelas
  }
}

// Logging stack trace untuk debugging
function logError(err) {
  console.error(`${err.name}: ${err.message}`);
  console.error('Stack:', err.stack?.split('\n').slice(1).join('\n'));
}

// Parse stack trace (advanced)
function getStackLines(err) {
  return err.stack
    .split('\n')
    .slice(1) // Skip pesan error
    .map(line => line.trim().replace(/^at /, ''));
}
```
