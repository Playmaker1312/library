### Definisi Singkat

**Cross-Origin Resource Sharing (CORS)** adalah mekanisme keamanan browser yang mengontrol apakah resource di suatu domain boleh diakses oleh halaman web dari domain lain. Server menentukan izin via **HTTP headers**. Browser akan memblokir request jika server tidak memberikan izin eksplisit.

---

### Analogi

Seperti **pintu keamanan apartemen** — penghuni (browser) hanya bisa masuk ke apartemen sendiri (origin sendiri). Jika ingin mengunjungi tetangga (origin lain), penghuni harus meminta izin via interkom (preflight request), dan tetangga harus menjawab "boleh masuk" (CORS headers).

---

### Poin-Poin Penting

- **Origin** = protokol + domain + port (`https://api.example.com:443`).
- **Simple Request** vs **Preflight Request**: Preflight menggunakan `OPTIONS` untuk method "kompleks" (PUT, DELETE, custom headers).
- Header kunci dari server:
  - `Access-Control-Allow-Origin: *` (semua) atau `https://example.com`
  - `Access-Control-Allow-Methods: GET, POST, PUT`
  - `Access-Control-Allow-Credentials: true` (untuk cookie)
  - `Access-Control-Allow-Headers: Content-Type, Authorization`
- CORS error **hanya terjadi di browser** — di server/CLI tidak ada blokade.
- Solusi umum: proxy, backend mengatur header, atau gunakan mode `no-cors` (terbatas).

---

### Contoh Implementasi

```javascript
// Server-side: Express.js — setup CORS
const express = require('express');
const cors = require('cors');
const app = express();

// Izinkan domain tertentu
app.use(cors({
  origin: 'https://aplikasi-saya.com',
  methods: ['GET', 'POST'],
  credentials: true
}));

// Atau custom middleware
app.use((req, res, next) => {
  res.setHeader('Access-Control-Allow-Origin', 'https://aplikasi-saya.com');
  res.setHeader('Access-Control-Allow-Methods', 'GET, POST, PUT, DELETE');
  res.setHeader('Access-Control-Allow-Headers', 'Content-Type, Authorization');
  if (req.method === 'OPTIONS') return res.status(200).end();
  next();
});

// Client-side: fetch dengan CORS
fetch('https://api.external.com/data', {
  method: 'GET',
  credentials: 'include', // Kirim cookie
  mode: 'cors'
});
```

---

### Koneksi

Berkaitan dengan **CSRF** (CORS membatasi cross-origin request), **XSS** (CORS bukan pertahanan XSS), **HTTPS** (mixed content blocking terkait origin), dan **WebSocket** (tidak dibatasi CORS — harus diamankan sendiri).
