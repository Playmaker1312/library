### Definisi Singkat

**Content Security Policy (CSP)** adalah lapisan keamanan tambahan berupa HTTP header yang memberitahu browser sumber daya mana yang diizinkan untuk dimuat dan dieksekusi. CSP secara drastis mengurangi risiko XSS dan serangan injection lainnya dengan mendefinisikan **whitelist** sumber terpercaya.

---

### Analogi

Seperti **daftar tamu yang ketat di pintu masuk gedung** — hanya orang yang namanya ada di daftar yang boleh masuk. Tamu tak diundang (script jahat, inline CSS dari sumber asing) ditolak meskipun mereka mencoba menyelinap.

---

### Poin-Poin Penting

- Dikirim via header `Content-Security-Policy` atau meta tag `<meta http-equiv="...">`.
- Direktif utama: `default-src`, `script-src`, `style-src`, `img-src`, `connect-src`, `font-src`.
- `script-src 'self'` — hanya script dari domain sendiri yang boleh jalan.
- `script-src 'nonce-abc123'` — hanya script dengan atribut `nonce="abc123"` yang diizinkan.
- Hindari `'unsafe-inline'` dan `'unsafe-eval'` — keduanya menonaktifkan proteksi CSP.
- Mode **report-only** (`Content-Security-Policy-Report-Only`) — log pelanggaran tanpa memblokir.

---

### Contoh Implementasi

```javascript
// Server-side: Express.js — pasang CSP header
app.use((req, res, next) => {
  res.setHeader(
    'Content-Security-Policy',
    "default-src 'self'; " +
    "script-src 'self' https://analytics.google.com; " +
    "style-src 'self' 'nonce-xyz789'; " +
    "img-src 'self' data: https://images.example.com; " +
    "connect-src 'self' https://api.example.com; " +
    "font-src 'self' https://fonts.gstatic.com; " +
    "frame-ancestors 'none'; " +
    "base-uri 'self'"
  );
  next();
});

// Di HTML — script dengan nonce
// <script nonce="xyz789" src="app.js"></script>
// <script nonce="xyz789">
//   console.log('Inline script dengan nonce diizinkan');
// </script>

// Melaporkan pelanggaran (reporting)
// Header: Content-Security-Policy: ... report-uri /csp-report;

// Endpoint untuk menerima laporan
app.post('/csp-report', (req, res) => {
  console.log('CSP Violation:', req.body);
  res.status(204).end();
});
```

---

### Koneksi

Berkaitan dengan **XSS** (CSP adalah pertahanan lapisan kedua setelah sanitasi), **HTTPS** (CSP bisa memblokir mixed content), **Service Workers** (script worker juga terikat CSP), dan **WebSocket** (connect-src mengontrol endpoint WebSocket).
