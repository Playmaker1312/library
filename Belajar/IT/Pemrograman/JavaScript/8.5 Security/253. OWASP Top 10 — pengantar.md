### Definisi Singkat

**OWASP Top 10** adalah daftar sepuluh risiko keamanan aplikasi web paling kritis yang diterbitkan oleh Open Web Application Security Project (OWASP). Ini adalah referensi standar industri untuk pengembang, arsitek, dan organisasi dalam mengidentifikasi dan memitigasi kerentanan keamanan.

---

### Analogi

Seperti **daftar 10 penyakit paling berbahaya** yang diterbitkan oleh organisasi kesehatan dunia — dokter (pengembang) menggunakan daftar ini untuk memprioritaskan pemeriksaan dan vaksinasi (pengamanan) pada pasien (aplikasi).

---

### Poin-Poin Penting

- **OWASP Top 10 2021** (versi terbaru):
  1. **Broken Access Control** — pengguna bisa mengakses resource yang tidak seharusnya.
  2. **Cryptographic Failures** — enkripsi lemah atau tidak ada.
  3. **Injection** — SQL Injection, NoSQL Injection, Command Injection.
  4. **Insecure Design** — kelemahan arsitektur aplikasi.
  5. **Security Misconfiguration** — default credentials, debug mode aktif.
  6. **Vulnerable and Outdated Components** — library usang dengan CVE.
  7. **Identification and Authentication Failures** — login lemah, session management buruk.
  8. **Software and Data Integrity Failures** — CI/CD tanpa verifikasi.
  9. **Security Logging and Monitoring Failures** — tidak ada audit trail.
  10. **Server-Side Request Forgery (SSRF)** — server dipaksa mengirim request ke internal.
- Pelajari mitigasi spesifik untuk setiap item — jangan hafal, pahami polanya.
- Gunakan tools seperti OWASP ZAP, Dependency-Check, atau Snyk untuk otomatisasi.

### Contoh Implementasi

```javascript
// Contoh mitigasi beberapa item OWASP Top 10

// 1. Broken Access Control — middleware otorisasi
app.delete('/api/users/:id', requireAdmin, async (req, res) => {
  // Hanya admin yang bisa menghapus user
});

// 3. Injection — gunakan parameterized query
db.query('SELECT * FROM users WHERE id = ?', [userId]);

// 7. Authentication — rate limiting
const rateLimit = require('express-rate-limit');
app.use('/login', rateLimit({
  windowMs: 15 * 60 * 1000, // 15 menit
  max: 5, // Maksimal 5 percobaan
  message: 'Terlalu banyak percobaan login'
}));

// 6. Outdated components — audit dependencies
// Jalankan: npm audit
```

---

### Koneksi

Berkaitan dengan semua topik keamanan: **XSS** (bagian dari Injection dalam konteks OWASP), **CSRF** (Broken Access Control), **CORS** (Security Misconfiguration), **CSP** (mitigasi XSS), dan **HTTPS** (Cryptographic Failures).
