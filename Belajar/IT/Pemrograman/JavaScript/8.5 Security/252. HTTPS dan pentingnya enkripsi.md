### Definisi Singkat

**HTTPS (Hypertext Transfer Protocol Secure)** adalah versi aman dari HTTP yang menggunakan enkripsi **TLS/SSL** untuk melindungi data yang dikirim antara browser dan server. HTTPS mencegah eavesdropping, man-in-the-middle attacks, dan tampering data. Saat ini dianggap sebagai standar minimum untuk website modern.

---

### Analogi

Seperti **surat dalam amplop tertutup dan terkunci** (HTTPS) vs **kartu pos** (HTTP) — siapa pun yang melihat kartu pos bisa membaca isinya. HTTPS memastikan hanya pengirim dan penerima yang bisa membaca isi pesan.

---

### Poin-Poin Penting

- Enkripsi menggunakan **sertifikat digital** (TLS certificate) dari Certificate Authority (CA).
- Browser menampilkan **gembok** di address bar untuk koneksi HTTPS yang valid.
- Manfaat: **kerahasiaan** (data terenkripsi), **integritas** (data tidak diubah), **autentikasi** (server adalah yang asli).
- **Mixed content** terjadi ketika halaman HTTPS memuat resource HTTP — browser akan memblokirnya.
- **Let's Encrypt** menyediakan sertifikat gratis dan otomatis.
- HTTP/2 membutuhkan HTTPS; HTTP/3 (QUIC) juga berjalan di atas TLS.
- Google menggunakan HTTPS sebagai **ranking signal** SEO.

---

### Contoh Implementasi

```javascript
// Express.js — redirect HTTP ke HTTPS
const express = require('express');
const app = express();

app.use((req, res, next) => {
  if (req.headers['x-forwarded-proto'] === 'http') {
    return res.redirect(301, `https://${req.hostname}${req.url}`);
  }
  next();
});

// Node.js HTTPS server dengan sertifikat
const https = require('https');
const fs = require('fs');

const options = {
  key: fs.readFileSync('privkey.pem'),
  cert: fs.readFileSync('cert.pem')
};

https.createServer(options, app).listen(443);

// Deteksi koneksi dari client
if (window.location.protocol === 'https:') {
  console.log('Koneksi aman');
} else {
  console.warn('Koneksi tidak aman!');
}
```

---

### Koneksi

Berkaitan dengan **CORS** (mixed content blokade), **CSP** (CSP upgrade-insecure-requests), **Service Workers** (hanya berjalan di HTTPS), **PWA** (membutuhkan HTTPS), dan **WebSocket Secure (WSS)**.
