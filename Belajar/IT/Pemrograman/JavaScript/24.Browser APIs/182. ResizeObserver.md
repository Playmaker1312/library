### Definisi Singkat
**ResizeObserver** adalah API yang memantau perubahan ukuran (width/height) suatu elemen. Berbeda dengan event `resize` di `window` yang hanya memantau viewport, ResizeObserver bisa memantau elemen spesifik apa pun.

---

### Analogi
ResizeObserver seperti **pita ukur elastis**. Setiap kali bingkai foto (elemen) berubah ukuran, pita ukur akan memberi tahu berapa ukuran barunya. Kamu bisa pasang pita ini di banyak bingkai sekaligus.

---

### Poin-Poin Penting
- `new ResizeObserver(callback)` — buat observer
- `observer.observe(element)` — mulai amati
- `observer.unobserve(element)` — berhenti amati
- `observer.disconnect()` — berhenti semua
- Callback menerima array `entries`, masing-masing punya: `contentRect`, `borderBoxSize`, `contentBoxSize`, `target`
- Tidak memicu infinite loop (perubahan dari callback tidak memicu ulang)
- `contentRect` — ukuran konten elemen (width, height, x, y, top, left)

---

### Contoh Implementasi

```javascript
const box = document.querySelector('.resizable');

const observer = new ResizeObserver((entries) => {
  for (const entry of entries) {
    const { width, height } = entry.contentRect;
    console.log(`Ukuran berubah: ${width} x ${height}`);

    // Responsif terhadap ukuran
    if (width < 400) {
      box.classList.add('compact');
    } else {
      box.classList.remove('compact');
    }

    // Update tampilan
    document.getElementById('size-info').textContent =
      `${Math.round(width)}px x ${Math.round(height)}px`;
  }
});

observer.observe(box);

// Memantau banyak elemen
const observers = new ResizeObserver((entries) => {
  entries.forEach(entry => {
    entry.target.style.fontSize =
      `${Math.max(12, entry.contentRect.width / 20)}px`;
  });
});

document.querySelectorAll('.fluid-text')
  .forEach(el => observers.observe(el));

// Cleanup
// observers.disconnect();
```
