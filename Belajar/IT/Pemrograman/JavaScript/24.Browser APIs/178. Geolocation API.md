### Definisi Singkat
**Geolocation API** menyediakan akses ke posisi geografis perangkat pengguna melalui `navigator.geolocation`. Method utama: **`getCurrentPosition()`** untuk satu kali pembacaan, dan **`watchPosition()`** untuk pelacakan berkelanjutan.

---

### Analgi
Geolocation API seperti **petugas resepsionis yang tahu di mana kamu berada**. Kamu bertanya "Di mana saya?" (`getCurrentPosition`), dan resepsionis menjawab dengan koordinat. Atau kamu bisa minta diikuti terus (`watchPosition`) seperti GPS.

---

### Poin-Poin Penting
- Membutuhkan izin pengguna (browser akan menampilkan prompt)
- `getCurrentPosition(success, error, options)` — satu kali
- `watchPosition(success, error, options)` — real-time
- `clearWatch(id)` — hentikan watch
- Objek posisi: `coords.latitude`, `coords.longitude`, `coords.accuracy`, `coords.altitude`
- Opsi: `enableHighAccuracy`, `timeout`, `maximumAge`
- Selalu handle error (pengguna tolak, timeout, dll)

---

### Contoh Implementasi

```javascript
// Cek dukungan
if (!('geolocation' in navigator)) {
  console.log('Geolocation tidak didukung');
}

// Mendapatkan posisi sekali
navigator.geolocation.getCurrentPosition(
  (pos) => {
    const { latitude, longitude, accuracy } = pos.coords;
    console.log(`Lokasi: ${latitude}, ${longitude} (±${accuracy}m)`);
  },
  (err) => {
    switch(err.code) {
      case err.PERMISSION_DENIED:
        console.log('Izin ditolak');
        break;
      case err.POSITION_UNAVAILABLE:
        console.log('Lokasi tidak tersedia');
        break;
      case err.TIMEOUT:
        console.log('Waktu habis');
        break;
    }
  },
  { enableHighAccuracy: true, timeout: 5000, maximumAge: 0 }
);

// Watch position
const watchId = navigator.geolocation.watchPosition((pos) => {
  console.log(`Posisi diperbarui: ${pos.coords.latitude}`);
});

// Berhenti watch
setTimeout(() => navigator.geolocation.clearWatch(watchId), 30000);
```
