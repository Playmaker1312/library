### Definisi Singkat
**localStorage** dan **sessionStorage** adalah Web Storage API yang menyimpan data key-value di browser. **localStorage** bersifat persisten (tidak hilang saat browser ditutup), sedangkan **sessionStorage** hanya bertahan selama tab/session aktif.

---

### Analogi
localStorage seperti **lemari arsip** — dokumen tetap ada meskipun kantor tutup. sessionStorage seperti **buku catatan sementara** — catatan akan dibuang setelah kamu pulang dan tutup buku.

---

### Poin-Poin Penting
- Hanya menyimpan **string** — objek perlu `JSON.stringify/parse`
- Kapasitas ~5-10MB per domain
- `setItem(key, value)`, `getItem(key)`, `removeItem(key)`, `clear()`
- `key(index)` untuk akses berdasarkan index
- Data tidak dikirim ke server (berbeda dengan cookies)
- `Storage` event — terpicu di tab lain saat localStorage berubah

---

### Contoh Implementasi

```javascript
// localStorage — persisten
localStorage.setItem('theme', 'dark');
localStorage.setItem('user', JSON.stringify({ name: 'Budi', role: 'admin' }));

const theme = localStorage.getItem('theme');
const user = JSON.parse(localStorage.getItem('user'));
console.log(theme, user);

localStorage.removeItem('theme');
// localStorage.clear(); // Hapus semua

// sessionStorage — per session
sessionStorage.setItem('tempData', 'hanya di tab ini');
const temp = sessionStorage.getItem('tempData');

// Storage event (tab lain)
window.addEventListener('storage', (e) => {
  console.log(`${e.key} berubah dari "${e.oldValue}" ke "${e.newValue}"`);
});

// Utility
function save(key, data) {
  localStorage.setItem(key, JSON.stringify(data));
}
function load(key) {
  const item = localStorage.getItem(key);
  return item ? JSON.parse(item) : null;
}
```
