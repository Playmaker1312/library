### Definisi Singkat
Error handling pada Fetch API membutuhkan perhatian khusus karena `fetch()` hanya **reject** pada network error (gagal koneksi, DNS error, timeout), bukan HTTP error status. HTTP 404, 500, dan error lainnya tetap dianggap success — perlu pengecekan manual melalui `response.ok` atau `response.status`.

---

### Analogi
Kamu kirim surat via pos:
- **Network error**: Kantor pos terbakar, kurir mogok — surat tidak sampai (**fetch reject**).
- **HTTP error**: Surat sampai, tapi penerima balas "Alamat tidak ditemukan" (404) atau "Saya tidak mau terima" (500). Surat tetap sampai, tapi isinya penolakan (**response.ok = false**).

---

### Poin-Poin Penting
- `fetch()` reject hanya jika **tidak bisa terhubung** ke server.
- Cek `response.ok` (true jika status 200-299) untuk HTTP success.
- Cek `response.status` untuk kode status spesifik.
- Gunakan `try-catch` untuk async/await, `.catch()` untuk Promise chain.
- **Kombinasi**: catch network error + cek `response.ok` untuk HTTP error.

---

### Contoh Implementasi

```javascript
fetch('https://api.example.com/nonexistent')
  .then(response => {
    if (!response.ok) {
      throw new Error(`HTTP error! status: ${response.status}`);
    }
    return response.json();
  })
  .then(data => console.log(data))
  .catch(err => console.error('Fetch error:', err.message));
```

Dengan async/await dan error detail:

```javascript
async function safeFetch(url) {
  try {
    const response = await fetch(url);

    if (!response.ok) {
      // Coba baca error message dari server
      let errorMsg = `HTTP ${response.status}`;
      try {
        const errorBody = await response.text();
        if (errorBody) errorMsg += `: ${errorBody}`;
      } catch { /* abaikan */ }
      throw new Error(errorMsg);
    }

    return await response.json();
  } catch (err) {
    // Network error atau HTTP error
    console.error('Request gagal:', err.message);
    return null;
  }
}

const data = await safeFetch('https://api.example.com/users');
```

Handle berbagai kode status:

```javascript
async function handleResponse(response) {
  if (response.ok) return response.json();

  switch (response.status) {
    case 400:
      throw new Error('Bad request — periksa input');
    case 401:
      throw new Error('Unauthorized — login dulu');
    case 403:
      throw new Error('Forbidden — tidak punya akses');
    case 404:
      throw new Error('Not found — resource tidak ada');
    case 500:
      throw new Error('Server error — coba lagi nanti');
    default:
      throw new Error(`Error ${response.status}: ${response.statusText}`);
  }
}

async function fetchWithStatus(url) {
  try {
    const res = await fetch(url);
    return await handleResponse(res);
  } catch (err) {
    console.error(err.message);
  }
}
```

Network error detection:

```javascript
fetch('https://nonexistent-domain-xyz.com')
  .then(res => res.json())
  .catch(err => {
    if (err.name === 'TypeError') {
      console.log('Network error — koneksi terputus');
    } else {
      console.log('Error lain:', err.message);
    }
  });
```

### Koneksi
Error handling yang baik membuat aplikasi lebih **resilient**. Selanjutnya, pelajari **AbortController** untuk membatalkan request yang tidak perlu — misalnya saat user navigasi ke halaman lain sebelum request selesai.
