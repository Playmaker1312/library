### Definisi Singkat
Selain GET, Fetch API mendukung method HTTP lain untuk memodifikasi data: **POST** (membuat data baru), **PUT** (mengupdate seluruh data), dan **DELETE** (menghapus data). Method-method ini dikirim melalui opsi `method` pada parameter kedua fetch.

---

### Analogi
- **POST**: Kamu isi form pendaftaran anggota baru — server membuat data anggota baru.
- **PUT**: Kamu ganti alamat rumah di profil — server mengganti alamat lama dengan yang baru sepenuhnya.
- **DELETE**: Kamu hapus akun — server menghapus data kamu.

---

### Poin-Poin Penting
- Tentukan `method` di object options: `{ method: 'POST' }`.
- Untuk POST dan PUT, kirim data di `body` (biasanya JSON string).
- Jangan lupa header `Content-Type: application/json` untuk JSON body.
- DELETE biasanya tidak perlu body, hanya URL dan method.
- Selalu cek `response.ok` atau `response.status` untuk memastikan keberhasilan.

---

### Contoh Implementasi

**POST — membuat data baru:**

```javascript
const newPost = {
  title: 'Belajar Fetch API',
  body: 'Ini adalah konten post',
  userId: 1
};

fetch('https://jsonplaceholder.typicode.com/posts', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify(newPost)
})
  .then(res => {
    if (!res.ok) throw new Error('Gagal POST');
    return res.json();
  })
  .then(data => console.log('Created:', data))
  .catch(err => console.error(err));
```

**PUT — mengupdate data:**

```javascript
const updatedPost = {
  id: 1,
  title: 'Judul Diubah',
  body: 'Konten baru',
  userId: 1
};

fetch('https://jsonplaceholder.typicode.com/posts/1', {
  method: 'PUT',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify(updatedPost)
})
  .then(res => res.json())
  .then(data => console.log('Updated:', data));
```

**DELETE — menghapus data:**

```javascript
fetch('https://jsonplaceholder.typicode.com/posts/1', {
  method: 'DELETE'
})
  .then(res => {
    if (res.ok) console.log('Berhasil dihapus');
    else throw new Error('Gagal hapus');
  })
  .catch(err => console.error(err));
```

**PATCH — update sebagian (tidak penuh seperti PUT):**

```javascript
fetch('https://jsonplaceholder.typicode.com/posts/1', {
  method: 'PATCH',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ title: 'Judul saja yang diubah' })
})
  .then(res => res.json())
  .then(data => console.log('Patched:', data));
```

---

### Koneksi
POST, PUT, DELETE melengkapi operasi CRUD. Setelah menguasai ini, pelajari **Headers dan Options** untuk kontrol lebih detail, **Error Handling** untuk resilient code, dan **AbortController** untuk pembatalan request.
