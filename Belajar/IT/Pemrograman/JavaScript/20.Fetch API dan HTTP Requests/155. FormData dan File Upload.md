### Definisi Singkat
`FormData` adalah API bawaan browser untuk membangun data formulir yang bisa dikirim via fetch — mendukung field teks dan file. Fetch otomatis mengatur `Content-Type: multipart/form-data` saat body berupa FormData, termasuk boundary untuk file upload.

---

### Analogi
Kamu kirim paket yang berisi dokumen (field teks) dan barang fisik (file). Kamu tidak bisa kirim barang fisik lewat amplop biasa — kamu perlu **paket khusus (FormData)** yang bisa menampung berbagai jenis kiriman. Kurir (fetch) akan membawakan paket khusus ini ke alamat tujuan.

---

### Poin-Poin Penting
- `new FormData()` — buat object FormData kosong.
- `.append(key, value)` — tambah field teks atau file.
- `.append(key, file, filename)` — tambah file dengan nama opsional.
- **Jangan** set `Content-Type` header manual — browser akan set otomatis dengan boundary.
- Untuk upload file, gunakan `<input type="file">` dan ambil file dari `event.target.files`.

---

### Contoh Implementasi

**FormData dasar:**

```javascript
const formData = new FormData();
formData.append('username', 'andi');
formData.append('email', 'andi@example.com');

fetch('https://api.example.com/users', {
  method: 'POST',
  body: formData // Content-Type otomatis multipart/form-data
})
  .then(res => res.json())
  .then(data => console.log('User created:', data));
```

**File Upload dari input file:**

```javascript
// HTML: <input type="file" id="avatar" accept="image/*">

const fileInput = document.getElementById('avatar');

fileInput.addEventListener('change', async (event) => {
  const file = event.target.files[0];
  if (!file) return;

  const formData = new FormData();
  formData.append('avatar', file); // nama field: 'avatar'
  formData.append('userId', '123');

  try {
    const res = await fetch('/api/upload', {
      method: 'POST',
      body: formData
    });

    if (!res.ok) throw new Error('Upload gagal');
    const data = await res.json();
    console.log('Upload sukses:', data.url);
  } catch (err) {
    console.error(err);
  }
});
```

**Multiple file upload:**

```javascript
// HTML: <input type="file" id="photos" multiple accept="image/*">

async function uploadPhotos() {
  const input = document.getElementById('photos');
  const files = input.files;

  const formData = new FormData();
  for (const file of files) {
    formData.append('photos', file); // field sama → array di server
  }

  const res = await fetch('/api/upload-multiple', {
    method: 'POST',
    body: formData
  });
  return res.json();
}
```

**FormData dari HTML form:**

```javascript
// HTML: <form id="myForm"> ... </form>

const form = document.getElementById('myForm');

form.addEventListener('submit', async (event) => {
  event.preventDefault();

  const formData = new FormData(form); // Ambil langsung dari form element

  // Tambah data tambahan
  formData.append('timestamp', Date.now());

  try {
    const res = await fetch('/api/submit', {
      method: 'POST',
      body: formData
    });
    const result = await res.json();
    console.log(result);
  } catch (err) {
    console.error(err);
  }
});
```

**Upload dengan progress indicator (menggunakan XMLHttpRequest — fetch tidak support upload progress):**

```javascript
function uploadWithProgress(file, onProgress) {
  return new Promise((resolve, reject) => {
    const xhr = new XMLHttpRequest();
    const formData = new FormData();
    formData.append('file', file);

    xhr.upload.onprogress = (event) => {
      if (event.lengthComputable) {
        const percent = Math.round((event.loaded / event.total) * 100);
        onProgress(percent);
      }
    };

    xhr.onload = () => {
      if (xhr.status >= 200 && xhr.status < 300) {
        resolve(JSON.parse(xhr.responseText));
      } else {
        reject(new Error('Upload gagal: ' + xhr.status));
      }
    };

    xhr.onerror = () => reject(new Error('Network error'));
    xhr.open('POST', '/api/upload');
    xhr.send(formData);
  });
}

// Usage
uploadWithProgress(file, (percent) => {
  console.log(`${percent}%`);
}).then(result => console.log(result));
```

---

### Koneksi
FormData dan File Upload melengkapi kemampuan Fetch API untuk menangani data **multipart**. Ini penting untuk fitur seperti upload avatar, upload dokumen, dan submission form kompleks. Setelah ini, lanjut ke DOM manipulation dan event handling untuk interaksi yang lebih dinamis.
