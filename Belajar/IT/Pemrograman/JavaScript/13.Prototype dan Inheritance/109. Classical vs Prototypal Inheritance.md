### Definisi Singkat
Classical inheritance (kelas — blueprint) dan prototypal inheritance (objek mewarisi dari objek lain) adalah dua paradigma yang berbeda. JavaScript menggunakan prototypal inheritance, tetapi bisa meniru classical melalui class syntax (syntactic sugar).

---
### Analogi
Classical seperti pabrik mobil — ada cetakan (kelas) yang menentukan spesifikasi, lalu dibuat mobil (instance). Prototypal seperti robot yang bisa meniru robot lain — cukup ambil fitur robot yang sudah ada tanpa perlu cetakan.

---
### Poin-Poin Penting
| Classical | Prototypal |
|-----------|------------|
| Blueprint (class) | Object langsung |
| Instance dari class | Clone/copy dari object |
| Hierarki kaku (class tree) | Fleksibel (object composition) |
| extends untuk inheritance | Object.create / setPrototypeOf |
| Lebih rigid | Lebih dinamis |

---
### Contoh Implementasi
```javascript
// PROTOTYPAL — murni JavaScript
const hewan = {
  init(nama) {
    this.nama = nama;
  },
  suara() {
    console.log('...');
  },
};

const kucing = Object.create(hewan);
kucing.init('Kitty');
kucing.suara = function () {
  console.log('Meow!');
};

// CLASSICAL — via class syntax (syntactic sugar)
class Hewan {
  constructor(nama) {
    this.nama = nama;
  }
  suara() {
    console.log('...');
  }
}

class Kucing extends Hewan {
  suara() {
    console.log('Meow!');
  }
}

const kitty = new Kucing('Kitty');
kitty.suara(); // "Meow!"

// Keduanya sebenarnya menggunakan prototype di belakang layar
console.log(kitty.__proto__ === Kucing.prototype);    // true
console.log(Kucing.prototype.__proto__ === Hewan.prototype); // true
```
