### Definisi Singkat
`Object.create(proto, propertiesObject)` adalah method yang membuat objek baru dengan prototype yang ditentukan, memberikan kontrol eksplisit atas prototype chain.

---
### Analogi
Seperti membuat kloning genetik: Anda menentukan DNA (prototype) organisme, lalu menciptakan organisme baru yang mewarisi seluruh sifat DNA tersebut.

---
### Poin-Poin Penting
- Parameter pertama adalah prototype object
- Parameter kedua (opsional) adalah property descriptors
- Lebih eksplisit daripada constructor function
- `Object.create(null)` membuat objek tanpa prototype (true hash map)
- Mendukung prototypal inheritance murni tanpa class

---
### Contoh Implementasi
```javascript
// Prototype object
const hewan = {
  bernafas() {
    console.log('Bernafas...');
  },
  jenis: 'hewan',
};

// Membuat objek dengan prototype hewan
const kucing = Object.create(hewan);
kucing.nama = 'Kitty';
kucing.bersuara = function () {
  console.log('Meow!');
};

console.log(kucing.nama);        // "Kitty" — properti sendiri
console.log(kucing.jenis);       // "hewan" — dari prototype
kucing.bernafas();               // "Bernafas..." — dari prototype
kucing.bersuara();               // "Meow!" — method sendiri

// Object tanpa prototype (true hash map)
const hashMap = Object.create(null);
hashMap.key = 'value';
console.log(hashMap.toString); // undefined — tidak ada prototype chain

// Dengan properti descriptors
const mobil = Object.create(Object.prototype, {
  merk: { value: 'Toyota', writable: true, enumerable: true },
  tahun: { value: 2024, writable: false },
});
console.log(mobil.merk); // "Toyota"
```

---
### Koneksi
Berkaitan dengan **prototype chain**, **property descriptors**, **prototypal inheritance**, dan **Object.create(null)**.
