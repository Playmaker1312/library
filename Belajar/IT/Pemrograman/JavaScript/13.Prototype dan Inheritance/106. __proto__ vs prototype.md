### Definisi Singkat
`__proto__` adalah properti pada setiap objek yang menunjuk ke prototype objek tersebut. `prototype` adalah properti khusus pada fungsi (constructor function) yang menjadi prototype untuk instance yang dibuat.

---
### Analogi
`prototype` seperti cetakan kue — dari cetakan yang sama dihasilkan banyak kue. `__proto__` seperti label pada setiap kue yang menunjuk ke cetakan asalnya.

---
### Poin-Poin Penting
- `prototype` hanya dimiliki oleh **functions** (khususnya constructor)
- `__proto__` dimiliki oleh **semua objek** (termasuk fungsi)
- `prototype` digunakan saat `new` untuk menjadi `__proto__` instance
- `__proto__` adalah getter/setter di `Object.prototype` (deprecated, gunakan `Object.getPrototypeOf`)
- Function juga memiliki `__proto__` yang menunjuk ke `Function.prototype`

---
### Contoh Implementasi
```javascript
function Person(name) {
  this.name = name;
}

Person.prototype.sayHello = function () {
  console.log(`Halo, saya ${this.name}`);
};

const andi = new Person('Andi');

// prototype — milik function (cetakan)
console.log(Person.prototype); // { sayHello: [Function] }

// __proto__ — milik instance (label ke cetakan)
console.log(andi.__proto__ === Person.prototype); // true

// Semua objek punya __proto__
console.log(andi.__proto__);            // Person.prototype
console.log(andi.__proto__.__proto__);  // Object.prototype
console.log(andi.__proto__.__proto__.__proto__); // null

// Method yang lebih aman
console.log(Object.getPrototypeOf(andi) === Person.prototype); // true
console.log(Person.prototype.constructor === Person);          // true
```

---
### Koneksi
Berkaitan dengan **prototype chain**, **constructor function**, **Object.create**, dan **class syntax**.
