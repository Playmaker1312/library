### Definisi Singkat
Prototype chain adalah mekanisme di JavaScript di mana objek dapat mewarisi properti dan method dari objek lain melalui rantai prototype (__proto__). Jika properti tidak ditemukan di objek, pencarian berlanjut ke prototype-nya hingga mencapai null.

---
### Analogi
Seperti anak yang mencari mainan: pertama cek di kamarnya sendiri, lalu di kamar kakak, lalu di gudang, hingga tidak ada tempat lagi.

---
### Poin-Poin Penting
- Setiap objek memiliki `__proto__` yang menunjuk ke prototype-nya
- Prototype chain berakhir di `Object.prototype` yang __proto__-nya null
- Method dan properti diwariskan melalui rantai ini
- Pencarian properti mengikuti rantai ke atas (bottom-up)
- Semua objek pada akhirnya mewarisi dari Object.prototype

---
### Contoh Implementasi
```javascript
const hewan = {
  bernafas: function () {
    console.log('Bernafas...');
  },
};

const mamalia = Object.create(hewan);
mamalia.berbulu = true;

const kucing = Object.create(mamalia);
kucing.nama = 'Kitty';

console.log(kucing.nama); // "Kitty" — properti sendiri
console.log(kucing.berbulu); // true — dari mamalia
console.log(kucing.bernafas); // function — dari hewan
console.log(kucing.toString); // function — dari Object.prototype

// Prototype chain:
console.log(kucing.__proto__ === mamalia);        // true
console.log(mamalia.__proto__ === hewan);          // true
console.log(hewan.__proto__ === Object.prototype); // true
console.log(Object.prototype.__proto__);           // null
```

---
### Koneksi
Dasar dari **prototypal inheritance**, **__proto__ vs prototype**, **Object.create**, dan **property shadowing**.
