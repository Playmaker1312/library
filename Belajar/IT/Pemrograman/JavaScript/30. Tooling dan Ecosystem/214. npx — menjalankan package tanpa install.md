### Definisi Singkat

npx (Node Package Execute) adalah tool yang dibundel bersama npm (versi 5.2+) untuk menjalankan package Node.js tanpa perlu menginstalnya secara permanen. npx mengunduh package ke cache sementara, menjalankannya, lalu membuangnya setelah selesai.

---

### Analogi

Seperti **menyewa alat daripada membelinya**. Anda butuh bor untuk satu lubang di dinding? Sewa (npx) daripada beli (npm install -g). Alat datang saat dibutuhkan, digunakan, dan dikembalikan tanpa menyimpan di rumah.

---

### Poin-Poin Penting

- `npx <command>` — menjalankan command dari registry atau lokal `node_modules/.bin`
- Tidak perlu `npm install -g` untuk menjalankan CLI tools satu kali
- Menggunakan package dari cache lokal jika sudah pernah digunakan
- Bisa menjalankan package dengan versi spesifik: `npx create-react-app@5.0.0`
- Jika command sudah terinstal di `node_modules`, npx akan menggunakan yang lokal
- Aman untuk mencoba tools baru tanpa mengotori sistem
- Berguna untuk: `create-react-app`, `tailwindcss init`, `prisma`, `ts-node`, dll

---

### Contoh Implementasi

```bash
# Membuat project React tanpa install global
npx create-react-app my-app

# Menjalankan tailwindcss sekali
npx tailwindcss init

# Menjalankan versi spesifik
npx eslint@7.32.0 src/

# Menjalankan package langsung dari registry
npx cowsay "Halo dari npx!"

# npx akan mencari di node_modules/.bin dulu
# Jika tidak ada, download dari registry

# Contoh: menjalankan http-server tanpa install
npx http-server . -p 3000
```

### Koneksi

npx melengkapi **npm** (file 212) dengan cara menjalankan package yang tidak perlu diinstal permanen. Sering digunakan dengan tool seperti **Vite** (file 215) untuk scaffolding project, **Babel** (file 217), dan **ESLint** (file 218).
