### Definisi Singkat

Vite adalah build tool modern untuk project web yang dikembangkan oleh Evan You (creator Vue.js). Vite menggunakan **ES Modules** asli untuk development server yang sangat cepat (instant hot reload), dan **Rollup** untuk production build yang optimal.

---

### Analogi

Seperti **restoran cepat saji modern** — tidak perlu memasak semua bahan dari awal setiap ada pesanan. Development server Vite hanya memproses file yang diminta (seperti memasak per pesanan), bukan semua file sekaligus. Build production seperti menyiapkan paket bekal untuk seminggu.

---

### Poin-Poin Penting

- Development server: load module sesuai permintaan (on-demand), tanpa bundle
- Hot Module Replacement (HMR) sangat cepat — hanya ganti module yang berubah
- Build produksi menggunakan Rollup dengan tree-shaking otomatis
- Dukungan bawaan untuk TypeScript, JSX, CSS, CSS Modules, JSON, dan Asset imports
- Konfigurasi minimal — sensible defaults
- Plugin system yang kompatibel dengan Rollup
- Mendukung Vue, React, Svelte, Lit, dan framework lainnya
- Mode library build untuk membuat library

---

### Contoh Implementasi

```bash
# Membuat project baru
npm create vite@latest my-app
# Pilih framework (React, Vue, Svelte, Vanilla, dll)

# Atau dengan template spesifik
npm create vite@latest my-react-app -- --template react

# Install dan jalankan
cd my-app
npm install
npm run dev
```

```javascript
// vite.config.js — konfigurasi Vite
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
  plugins: [react()],
  server: {
    port: 3000,
    open: true
  },
  build: {
    outDir: 'dist',
    sourcemap: true
  }
});
```

### Koneksi

Vite adalah alternatif modern untuk **Webpack** (file 216). Vite menggunakan **Babel** (file 217) atau esbuild untuk transformasi. Dalam ekosistem tooling, Vite bisa digabungkan dengan **ESLint** (file 218) dan **Prettier** (file 219) untuk kualitas kode.
