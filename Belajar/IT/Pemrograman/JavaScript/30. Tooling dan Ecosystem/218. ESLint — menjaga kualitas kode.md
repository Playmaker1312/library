### Definisi Singkat

ESLint adalah static code analysis tool untuk mengidentifikasi dan melaporkan pola bermasalah dalam kode JavaScript/TypeScript. ESLint membantu menjaga konsistensi kode, menemukan bug potensial, dan menegakkan style guide melalui aturan (rules) yang dapat dikonfigurasi.

---

### Analogi

Seperti **editor koran** — sebelum artikel dicetak, editor memeriksa tata bahasa, ejaan, dan konsistensi gaya penulisan. ESLint melakukan hal yang sama untuk kode: memastikan tidak ada variabel yang tidak digunakan, indentasi konsisten, dan tidak ada praktik berbahaya.

---

### Poin-Poin Penting

- Aturan (rules) bisa diatur sebagai: `off`, `warn`, atau `error`
- Konfigurasi di file `.eslintrc.js`, `.eslintrc.json`, atau `eslintConfig` di `package.json`
- **Extends** — menggunakan konfigurasi preset (eslint:recommended, airbnb, standard)
- **Plugins** — menambahkan aturan spesifik (react, typescript, prettier)
- **Parser** — default Espree, bisa diganti dengan `@typescript-eslint/parser` atau `babel-eslint`
- Auto-fix dengan `--fix` untuk memperbaiki masalah otomatis
- Integrasi dengan editor (VS Code, WebStorm) untuk feedback real-time
- Bisa dijalankan di pre-commit hook via **Husky** (file 220)

### Contoh Implementasi

```bash
npm install -D eslint
npx eslint --init
```

```javascript
// .eslintrc.js
module.exports = {
  env: {
    browser: true,
    es2021: true,
    node: true
  },
  extends: [
    'eslint:recommended',
    'plugin:react/recommended'
  ],
  parserOptions: {
    ecmaVersion: 'latest',
    sourceType: 'module',
    ecmaFeatures: { jsx: true }
  },
  plugins: ['react'],
  rules: {
    'no-unused-vars': 'warn',
    'no-console': 'off',
    'indent': ['error', 2],
    'quotes': ['error', 'single'],
    'semi': ['error', 'always'],
    'react/prop-types': 'off'
  }
};
```

```javascript
// Kode yang akan dilaporkan ESLint
var x = 1;        // Warning: Unexpected var, use let or const
console.log(x);   
// "no-console": "off" → tidak masalah
```

### Koneksi

ESLint bekerja sama dengan **Prettier** (file 219) untuk formatting (via eslint-config-prettier). Integrasi dengan **Git Hooks (Husky)** (file 220) untuk memeriksa kode sebelum commit. ESLint juga bisa digunakan di **Webpack** (file 216) dan **Vite** (file 215) via loader/plugin.
