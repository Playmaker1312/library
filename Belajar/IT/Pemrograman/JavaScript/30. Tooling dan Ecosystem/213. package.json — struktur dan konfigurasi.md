### Definisi Singkat

`package.json` adalah file konfigurasi utama dalam project Node.js/npm. File ini berisi metadata tentang project (nama, versi, deskripsi), daftar dependensi, script yang bisa dijalankan, serta berbagai konfigurasi untuk tools dan workflow.

---

### Analogi

Seperti **kartu identitas dan daftar belanja dalam satu dokumen**. Kartu identitas memberi tahu siapa project Anda (nama, versi), dan daftar belanja memberi tahu barang apa saja (dependensi) yang diperlukan. Plus ada resep (scripts) untuk menjalankan tugas tertentu.

---

### Poin-Poin Penting

- `name` dan `version` adalah field wajib
- `scripts` — perintah yang bisa dijalankan dengan `npm run`
- `dependencies` — paket yang dibutuhkan saat production
- `devDependencies` — paket hanya untuk development (testing, build tools)
- `peerDependencies` — paket yang harus disediakan konsumen
- `main` — entry point file utama
- `keywords`, `author`, `license` — metadata project
- `private: true` — mencegah publish ke registry
- Semantik versioning: `^1.2.3` (minor update), `~1.2.3` (patch only), `1.2.3` (exact), `*` (any)

---

### Contoh Implementasi

```json
{
  "name": "my-app",
  "version": "1.0.0",
  "description": "Aplikasi contoh",
  "main": "src/index.js",
  "scripts": {
    "start": "node src/index.js",
    "dev": "nodemon src/index.js",
    "build": "webpack --mode production",
    "test": "jest --coverage",
    "lint": "eslint src/",
    "format": "prettier --write src/"
  },
  "dependencies": {
    "express": "^4.18.0",
    "lodash": "^4.17.21"
  },
  "devDependencies": {
    "jest": "^29.0.0",
    "eslint": "^8.0.0",
    "prettier": "^3.0.0",
    "webpack": "^5.0.0"
  },
  "keywords": ["javascript", "example"],
  "author": "Budi <budi@example.com>",
  "license": "MIT"
}
```

### Koneksi

`package.json` adalah pusat dari **npm** (file 212) dan ecosystem tooling. Tools seperti **Vite** (file 215), **Webpack** (file 216), **Babel** (file 217), **ESLint** (file 218), **Prettier** (file 219) semuanya membaca konfigurasi dari sini atau dari file konfigurasi terpisah yang direferensikan.
