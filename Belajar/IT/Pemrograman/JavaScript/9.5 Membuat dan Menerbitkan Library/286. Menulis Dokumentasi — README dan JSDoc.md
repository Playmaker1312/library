### Definisi Singkat

**Dokumentasi** adalah bagian penting dari package/library — tanpa dokumentasi yang baik, pengguna tidak akan bisa (atau malas) menggunakan library Anda. **README.md** adalah halaman depan di npm/GitHub; **JSDoc** adalah dokumentasi inline dalam kode yang bisa menghasilkan dokumentasi API otomatis.

---

### Analogi

Seperti **buku resep masakan** — README adalah sampul dan daftar isi (apa yang bisa dimasak, bagaimana memulainya), JSDoc adalah instruksi detail di setiap resep (bahan, langkah, tips). Tanpa keduanya, Anda hanya punya bahan mentah di dapur.

---

### Poin-Poin Penting

- **README.md** (wajib ada):
  - Nama dan deskripsi singkat
  - Instalasi (`npm install my-package`)
  - Contoh penggunaan cepat (minimal 1 contoh kerja)
  - API documentation (fungsi utama)
  - Badge (build status, coverage, npm version)
  - Lisensi
- **JSDoc**: Format komentar `/** ... */` yang mendokumentasikan fungsi, parameter, return value.
  - `@param {Type} name - Deskripsi`
  - `@returns {Type} - Deskripsi`
  - `@throws {Type} - Kapan error terjadi`
  - `@example` — contoh kode
- Tools: **JSDoc** (generator HTML), **TypeScript** (type + docs), **Typedoc** (alternatif modern).
- **Storybook**: Untuk dokumentasi komponen UI interaktif.

### Contoh Implementasi

```javascript
/**
 * Memformat angka menjadi mata uang Rupiah.
 *
 * @param {number} amount - Jumlah uang yang akan diformat.
 * @param {object} [options] - Opsi tambahan.
 * @param {boolean} [options.withPrefix=true] - Sertakan "Rp" di depan.
 * @returns {string} String mata uang yang diformat.
 * @throws {TypeError} Jika amount bukan angka.
 *
 * @example
 * // Mengembalikan "Rp 1.000.000"
 * formatCurrency(1000000);
 *
 * @example
 * // Mengembalikan "1.000.000"
 * formatCurrency(1000000, { withPrefix: false });
 */
function formatCurrency(amount, options = {}) {
  const { withPrefix = true } = options;
  if (typeof amount !== 'number') {
    throw new TypeError('amount harus berupa angka');
  }
  const formatted = amount.toLocaleString('id-ID');
  return withPrefix ? `Rp ${formatted}` : formatted;
}
```

# string-utils

[![npm version](https://badge.fury.io/js/string-utils.svg)](https://badge.fury.io/js/string-utils)
[![Build Status](https://github.com/user/string-utils/workflows/CI/badge.svg)](https://github.com/user/string-utils/actions)

Koleksi utilitas string untuk JavaScript.

## Instalasi

```bash
npm install @user/string-utils
```

## Penggunaan

```javascript
import { capitalize, truncate } from '@user/string-utils';

capitalize('hello'); // 'Hello'
truncate('Lorem ipsum dolor sit amet', 11); // 'Lorem ipsum…'
```

## API

### `capitalize(str)`
Mengubah huruf pertama menjadi kapital.

### `truncate(str, maxLength)`
Memotong string dan menambahkan "…" jika melebihi panjang maksimal.

MIT
