### Definisi Singkat

_Development Environment_ adalah seperangkat perangkat lunak (aplikasi dan alat bantu) yang dikonfigurasi secara khusus agar seorang _developer_ dapat menulis, menguji, dan mengelola kode pemrograman dengan nyaman dan efisien.

---

### Analogi

Bayangkan seperti **meja kerja seorang arsitek**:

- **VS Code** adalah meja gambar serbaguna yang rapi dan memiliki semua alat ukur.
    
- **Ekstensi penting** adalah peralatan tambahan seperti pensil khusus, penghapus, dan lampu meja yang membuat pekerjaan lebih cepat, tidak mudah lelah, dan meminimalisir kesalahan.
    

---

### Poin-Poin Penting

- **Visual Studio Code (VS Code):** Editor kode sumber gratis yang sangat populer, ringan, dan memiliki dukungan bahasa yang kuat untuk JavaScript.
    
- **Manfaat Ekstensi:** Membantu mempercepat penulisan kode (_autocompletion_), mendeteksi kesalahan secara otomatis, dan mempercantik tampilan kode (_formatting_).
    
- **Ekstensi Esensial untuk JavaScript:**
    
    - **Prettier - Code Formatter:** Merapikan struktur kode agar selalu konsisten dan enak dibaca.
        
    - **ESLint:** Menganalisis kode untuk menemukan potensi _bug_ atau kesalahan penulisan (_syntax error_) secara langsung saat Anda mengetik.
        
    - **Live Server:** Membuka server lokal untuk memuat ulang halaman web secara otomatis setiap kali Anda menyimpan perubahan file.
        
    - **GitLens:** Membantu melacak perubahan kode dan kolaborasi tim menggunakan Git.

### Contoh Implementasi

Berikut adalah panduan langkah demi langkah untuk mengatur lingkungan kerja Anda:

#### 1. Instalasi VS Code

1. Unduh dan pasang aplikasi dari situs resmi [code.visualstudio.com](https://code.visualstudio.com/).
    
2. Buka aplikasi VS Code, lalu masuk ke menu **Extensions** (ikon kotak di menu sebelah kiri atau tekan `Ctrl+Shift+X`).
    

#### 2. Memasang Ekstensi Penting

Cari dan pasang ekstensi berikut melalui _search bar_ di menu Extensions:

- **Prettier - Code Formatter**
    
- **ESLint**
    
- **Live Server**
    

#### 3. Mengaktifkan Format Otomatis di Prettier

Untuk memastikan kode selalu rapi saat disimpan (_Save_), tambahkan pengaturan ini di file `settings.json` pada VS Code Anda:

JSON

```
{
    "editor.formatOnSave": true,
    "editor.defaultFormatter": "esbenp.prettier-vscode"
}
```

### Koneksi

Dalam bidang **Web Development**, memiliki lingkungan pengembangan yang tepat dapat meningkatkan produktivitas Anda secara drastis:

- Menghemat waktu dengan otomatisasi seperti _Live Server_ yang memperbarui tampilan di _browser_ seketika.
    
- Mengurangi kesalahan fatal sebelum kode berjalan (_debugging_) menggunakan bantuan _ESLint_.
    
- Mempermudah kolaborasi dengan tim melalui integrasi sistem kontrol versi (_Git_).
