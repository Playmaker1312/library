### Definisi Singkat

Menjalankan JavaScript adalah proses mengeksekusi kode yang telah ditulis agar dapat diproses oleh _engine_ dan menghasilkan _output_ yang diinginkan, baik secara langsung di _browser_ maupun melalui _command line_ di komputer.

---

### Analogi

Bayangkan Anda sedang belajar memasak resep baru:

- **Browser Console** seperti mencicipi sedikit bumbu di sendok saat memasak; cepat dan instan untuk melihat rasa atau hasil uji coba.
    
- **File `.js`** seperti menulis resep tersebut ke dalam buku catatan agar bisa dimasak berulang kali atau dibagikan ke orang lain.
    
- **Node.js** seperti membawa bahan dan resep tersebut dari dapur rumah Anda ke dapur restoran komersial menggunakan peralatan yang lebih besar dan spesialisasi profesional.
    

---

### Poin-Poin Penting

- **Browser Console:**
    
    - Digunakan untuk eksperimen cepat atau proses _debugging_.
        
    - Dapat diakses melalui menu _Inspect Element_ pada _browser_ web (biasanya melalui tombol pintasan `F12` lalu membuka tab **Console**).
        
- **File `.js`:**
    
    - Cara standar untuk menyimpan kode pemrograman dalam sebuah berkas teks.
        
    - Biasanya dipanggil di dalam file HTML menggunakan tag `<script src="nama_file.js"></script>`.
        
- **Node.js CLI:**
    
    - Memungkinkan kita menjalankan _file_ JavaScript langsung di terminal komputer tanpa antarmuka grafis atau _browser_.
        

---

### Contoh Implementasi

Berikut adalah tiga cara umum untuk mengeksekusi kode JavaScript:

#### 1. Melalui Browser Console

Buka tab _Console_ pada _browser_ Anda dan ketikkan kode berikut:

JavaScript

```
console.log("Halo dari Browser Console!");
```

#### 2. Melalui File Eksternal (`script.js`)

Buat file bernama `index.html` dan `script.js` dalam satu folder yang sama.

**`index.html`:**

HTML

```
<!DOCTYPE html>
<html lang="id">
<head>
    <title>Menjalankan File JS</title>
</head>
<body>
    <h1>Belajar JavaScript</h1>
    <script src="script.js"></script>
</body>
</html>
```

**`script.js`:**

JavaScript

```
alert("File JavaScript berhasil dijalankan!");
```

#### 3. Melalui Node.js (Terminal)

Buat file bernama `app.js` dan isi dengan kode berikut:

JavaScript

```
console.log("Halo, ini dijalankan melalui terminal menggunakan Node.js!");
```

Buka terminal atau _command prompt_, lalu jalankan perintah berikut:

Bash

```
node app.js
```

### Koneksi

Dalam bidang **Web Development**, pemahaman ketiga cara ini sangat menentukan alur kerja (_workflow_) seorang _developer_:

- **Console** digunakan untuk _debugging_ dan menguji coba logika singkat saat mengembangkan antarmuka web.
    
- **File .js** adalah fondasi utama dalam menyusun kode agar terstruktur dan mudah dipelihara.
    
- **Node.js** digunakan untuk mengeksekusi _build tools_ (seperti Webpack, Vite, atau React) serta menjalankan fungsi _backend_ aplikasi.
