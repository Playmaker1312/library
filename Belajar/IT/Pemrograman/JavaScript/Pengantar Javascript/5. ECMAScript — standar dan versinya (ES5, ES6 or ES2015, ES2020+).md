### Definisi Singkat

ECMAScript adalah standar teknis yang menjadi acuan atau spesifikasi dasar bagi JavaScript. Standar ini dikelola oleh ECMA International untuk memastikan bahwa bahasa JavaScript berjalan secara konsisten di berbagai _browser_ dan lingkungan kerja.

---

### Analogi

Bayangkan ECMAScript seperti **hukum tata negara atau undang-undang**, sedangkan JavaScript adalah **penerapannya di masyarakat**:

- **ECMAScript (Undang-Undang):** Menetapkan aturan, hak, dan kewajiban baru secara berkala (misalnya: aturan baru tentang keselamatan lalu lintas setiap tahunnya).
    
- **JavaScript (Masyarakat):** Harus mematuhi dan menyesuaikan diri dengan aturan baru tersebut agar seluruh komponen berjalan dengan tertib dan seragam.
    

---

### Poin-Poin Penting

- **ECMAScript vs JavaScript:** ECMAScript adalah spesifikasi atau cetak biru, sedangkan JavaScript adalah implementasi dari spesifikasi tersebut (selain JavaScript, ada juga ActionScript dan JScript yang mengikutinya).
    
- **ES5 (2009):** Standar utama yang membawa stabilitas setelah era awal JavaScript yang kacau. Di sinilah diperkenalkan _Strict Mode_, `JSON.parse()`, dan fungsi-fungsi _array_ standar seperti `.map()` dan `.filter()`.
    
- **ES6 / ES2015:** Merupakan pembaruan paling masif dalam sejarah bahasa ini. Fitur-fitur modern seperti `let` dan `const`, _Arrow Functions_, _Classes_, dan _Promises_ diperkenalkan pada versi ini.
    
- **ES2020+ (Modern):** ECMA International mengubah siklus rilis menjadi tahunan. Setiap tahunnya, fitur-fitur baru ditambahkan secara bertahap, seperti:
    
    - _Optional Chaining_ (`?.`) pada ES2020.
        
    - _Logical Assignment Operators_ pada ES2021.
        
    - _Array.prototype.at()_ pada ES2022.
        

---

### Contoh Implementasi

Berikut adalah perbandingan penulisan fungsi sebelum dan sesudah era ES6 (ES2015) yang lebih ringkas dan modern:

#### 1. Era ES5 (Fungsi Tradisional):

JavaScript

```
// Menggunakan kata kunci var dan fungsi standar
var tambah = function(a, b) {
    return a + b;
};
console.log(tambah(2, 3)); // Output: 5
```

#### 2. Era ES6+ (Fungsi Modern dengan Arrow Function):

JavaScript

```
// Menggunakan let/const dan arrow function =>
const tambah = (a, b) => a + b;
console.log(tambah(2, 3)); // Output: 5
```

### Koneksi

Dalam bidang **Web Development**, pemahaman tentang versi ECMAScript sangat penting untuk menentukan kompatibilitas (_compatibility_) di _browser_ lama maupun baru:

- Membantu _developer_ dalam menulis kode yang lebih bersih dan mudah dibaca (dengan sintaks modern).
    
- Menggunakan _tools_ tambahan seperti **Babel** untuk menerjemahkan kode modern (ES6+) ke versi lama (ES5) agar tetap dapat berjalan lancar di _browser_ lama pengguna.
