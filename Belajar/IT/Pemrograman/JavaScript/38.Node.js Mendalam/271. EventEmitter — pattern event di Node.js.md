### Definisi Singkat

**EventEmitter** adalah class inti di Node.js yang mengimplementasikan **pattern observer/publisher-subscriber**. Objek dapat memancarkan (emit) event bernama, dan fungsi lain dapat mendengarkan (listen) event tersebut. Hampir semua modul inti Node.js (Stream, HTTP, Server) mewarisi dari EventEmitter.

---

### Analogi

Seperti **stasiun radio** — penyiar (emitter) menyiarkan sinyal pada frekuensi tertentu (event name). Pendengar (listener) yang menyetel radio ke frekuensi yang sama akan menerima siaran. Pendengar bisa berhenti mendengarkan kapan saja (off/removeListener).

---

### Poin-Poin Penting

- Membuat emitter: `const EventEmitter = require('events'); class MyEmitter extends EventEmitter {}`
- **`emitter.on(event, listener)`** — mendaftarkan listener.
- **`emitter.emit(event, ...args)`** — memancarkan event dengan argumen.
- **`emitter.once(event, listener)`** — listener hanya sekali.
- **`emitter.removeListener(event, listener)` / `emitter.off()`** — hapus listener.
- Default maksimum 10 listener per event (peringatan jika lebih). Ubah dengan `setMaxListeners(n)`.
- **Event: `'error'`** — khusus: jika error di-emit tanpa listener, Node.js akan throw.
- **`emitter.eventNames()`** — daftar event dengan listener aktif.

---

### Contoh Implementasi

```javascript
const EventEmitter = require('events');

// 1. Membuat kustom EventEmitter
class OrderSystem extends EventEmitter {
  placeOrder(order) {
    console.log(`Pesanan ${order.id} diterima`);
    this.emit('order:placed', order);
  }
  processPayment(orderId) {
    this.emit('order:payment', { id: orderId, status: 'paid' });
  }
}

const orders = new OrderSystem();

// Mendaftarkan listener
orders.on('order:placed', (order) => {
  console.log(`Notifikasi: Pesanan baru #${order.id}`);
});

orders.once('order:payment', (payment) => {
  console.log(`Pembayaran #${payment.id}: ${payment.status}`);
});

// Memicu event
orders.placeOrder({ id: 101, item: 'Laptop' });
orders.processPayment(101);

// 2. EventEmitter pattern untuk async
class DataFetcher extends EventEmitter {
  async fetch(url) {
    try {
      const response = await fetch(url);
      const data = await response.json();
      this.emit('data', data);
    } catch (err) {
      this.emit('error', err); // Wajib handle error event!
    }
  }
}

DataFetcher.prototype.setMaxListeners(20);
```

---

### Koneksi

Berkaitan dengan **Node.js Architecture** (Event Loop + EventEmitter = fondasi Node.js), **Streams** (mewarisi EventEmitter), **Observer Pattern** (fondasi arsitektur), **Async Patterns** (callback via event), dan **WebSocket** (event-driven communication).
