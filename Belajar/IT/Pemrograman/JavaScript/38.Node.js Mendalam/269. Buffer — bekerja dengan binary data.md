### Definisi Singkat

**Buffer** adalah representasi data **biner** (byte array) di memori, digunakan di Node.js untuk menangani data mentah seperti file, gambar, atau protokol jaringan. Buffer dibuat dari kelas `Buffer` global yang beroperasi di luar batasan tipe JavaScript biasa (numbers/strings).

---

### Analogi

Seperti **ember penampung air sementara** saat Anda memindahkan air dari satu tangki ke tangki lain. Air (data biner) ditampung di ember (Buffer) sebelum diproses atau dialirkan. Ember ini lebih kuat dari kantong plastik biasa (string) karena bisa menampung data mentah apa pun, termasuk yang tidak bisa dibaca manusia.

---

### Poin-Poin Penting

- Buffer merepresentasikan **raw binary data** — array of bytes (0–255).
- Dibuat via `Buffer.alloc(size)` (aman — zero-filled), `Buffer.from(data)`.
- Encoding: `'utf8'`, `'base64'`, `'hex'`, `'ascii'`, `'latin1'`.
- Buffer tidak bisa diubah ukurannya — jika perlu lebih besar, alokasi baru.
- **`toString(encoding)`** mengubah Buffer ke string; **`Buffer.from(string)`** sebaliknya.
- Stream Readable menghasilkan Buffer (kecuali encoding ditentukan).
- Concatenation: `Buffer.concat([buf1, buf2])`.

---

### Contoh Implementasi

```javascript
// Membuat Buffer
const buf1 = Buffer.alloc(10); // 10 byte, diisi 0
const buf2 = Buffer.from('Hello', 'utf8'); // <Buffer 48 65 6c 6c 6f>
const buf3 = Buffer.from([0x48, 0x65, 0x6c, 0x6c, 0x6f]); // Sama dengan 'Hello'

// Membaca/menulis byte
console.log(buf2.toString()); // 'Hello'
console.log(buf2[0]); // 72 (desimal dari 0x48)
buf2[0] = 0x68; // Ubah 'H' (0x48) jadi 'h' (0x68)
console.log(buf2.toString()); // 'hello'

// Encoding — Base64 (umum untuk gambar/API)
const base64 = buf2.toString('base64');
console.log(base64); // 'aGVsbG8='
const decoded = Buffer.from(base64, 'base64');
console.log(decoded.toString()); // 'hello'

// Concatenate
const bufA = Buffer.from('Halo, ');
const bufB = Buffer.from('Dunia!');
const combined = Buffer.concat([bufA, bufB]);
console.log(combined.toString()); // 'Halo, Dunia!'

// Buffer dan Stream
const { Readable } = require('stream');
const stream = Readable.from([Buffer.from('chunk1'), Buffer.from('chunk2')]);
```

---

### Koneksi

Berkaitan dengan **Streams** (data mentah dari stream adalah Buffer), **File System** (`fs.read` menghasilkan Buffer), **WebSocket/WebRTC** (binary frames), dan **Node.js Architecture** (I/O menggunakan Buffer).
