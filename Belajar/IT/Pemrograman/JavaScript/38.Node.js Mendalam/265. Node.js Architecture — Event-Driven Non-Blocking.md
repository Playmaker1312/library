### Definisi Singkat

**Node.js** adalah runtime JavaScript berbasis **V8 engine** yang berjalan di server. Arsitekturnya **event-driven** dan **non-blocking I/O**, memungkinkan satu thread menangani ribuan koneksi simultan. Ini dicapai melalui **Event Loop** (libuv) yang mendelegasikan operasi I/O ke sistem, lalu memproses callback saat operasi selesai.

---

### Analogi

Seperti **restoran dengan satu koki (single thread)** yang sangat efisien. Koki tidak menunggu nasi matang sambil diam — ia mulai memasak nasi (delegasi I/O), lalu sambil menunggu ia memotong sayur, melayani pelanggan lain, atau menyiapkan pesanan berikutnya (non-blocking). Hanya satu koki, tetapi restoran bisa melayani banyak pelanggan.

---

### Poin-Poin Penting

- **Single-threaded**: Satu thread JavaScript (main thread) mengeksekusi kode.
- **Non-blocking I/O**: Operasi seperti baca file, query DB, HTTP request — tidak memblokir thread.
- **Event Loop**: Fase-fase: timers → pending callbacks → idle/prepare → poll → check (setImmediate) → close callbacks.
- **libuv**: Library C yang mengelola thread pool (untuk I/O berat) dan event loop.
- **Cocok untuk**: I/O-heavy apps (API, real-time, streaming). **Tidak cocok untuk**: CPU-heavy (harus pakai Worker Threads).
- **Process global**: `process.nextTick()`, `process.env`, `process.exit()`.

### Contoh Implementasi

```javascript
const http = require('http');

const server = http.createServer((req, res) => {
  // Non-blocking I/O — tidak memblokir request lain
  fs.readFile('data.json', (err, data) => {
    if (err) {
      res.writeHead(500);
      return res.end('Error');
    }
    res.writeHead(200, { 'Content-Type': 'application/json' });
    res.end(data);
  });
});

server.listen(3000, () => {
  console.log('Server berjalan di port 3000');
});

// Demonstrasi Event Loop
console.log('1. Start');
setTimeout(() => console.log('2. Timer (macro)'), 0);
setImmediate(() => console.log('3. setImmediate'));
process.nextTick(() => console.log('4. nextTick (micro)'));
console.log('5. End');

// Output: 1, 5, 4, 2/3 (urutan 2 dan 3 tergantung)
```
