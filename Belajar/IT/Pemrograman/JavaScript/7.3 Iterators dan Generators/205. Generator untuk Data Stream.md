### Definisi Singkat

Generator sangat cocok untuk menangani data stream — data yang datang secara bertahap, tidak terbatas, atau terlalu besar untuk dimuat sekaligus. Dengan generator, data diproses secara **lazy**: hanya dihitung atau diambil saat benar-benar dibutuhkan, sehingga hemat memori.

---

### Analogi

Seperti **keran air** — Anda tidak perlu menyediakan seluruh tangki air sekaligus. Cukup buka keran (`next()`), air mengalir sesuai kebutuhan. Mau air panas atau dingin bisa dikombinasikan dari sumber berbeda (`yield*`).

---

### Poin-Poin Penting

- Lazy evaluation: data hanya diproses saat diminta
- Hemat memori untuk dataset besar atau infinite
- Bisa membaca file baris per baris tanpa memuat seluruh file
- Bisa memproses data dari API pagination secara incremental
- Generator bisa dikomposisi untuk membentuk pipeline stream
- Cocok untuk real-time data seperti sensor atau log

---

### Contoh Implementasi

```javascript
// Infinite sequence
function* idGenerator() {
  let id = 1;
  while (true) {
    yield id++;
  }
}

const ids = idGenerator();
console.log(ids.next().value); // 1
console.log(ids.next().value); // 2
console.log(ids.next().value); // 3

// Pipeline stream: transformasi data berantai
function* paginateApi(pageSize) {
  let page = 1;
  while (true) {
    yield fetchDataFromApi(page, pageSize);
    page++;
  }
}

function* filter(predicate, generator) {
  for (const item of generator) {
    if (predicate(item)) yield item;
  }
}

function* map(transform, generator) {
  for (const item of generator) {
    yield transform(item);
  }
}

// Contoh: membaca file baris per baris (Node.js)
const fs = require('fs');
const readline = require('readline');

async function* readFileLines(filePath) {
  const rl = readline.createInterface({
    input: fs.createReadStream(filePath),
    crlfDelay: Infinity
  });
  for await (const line of rl) {
    yield line;
  }
}
```
