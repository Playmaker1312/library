### Definisi Singkat

Generator Function adalah fungsi khusus yang ditandai dengan `function*` (asterisk). Fungsi ini mengembalikan objek **Generator** yang bersifat iterable dan juga iterator. Eksekusi fungsi generator bisa dijeda (`pause`) dengan `yield` dan dilanjutkan (`resume`) dengan `next()`.

---

### Analogi

Seperti **pita pengukur yang bisa ditarik bertahap**. Setiap kali Anda menarik (`next()`), pita keluar sepanjang tertentu (`yield`). Anda bisa berhenti di tengah, melihat ukurannya, lalu menarik lagi. Tidak seperti pengukur biasa yang langsung keluar semua.

---

### Poin-Poin Penting

- Dideklarasikan dengan `function* namaFungsi()`
- Mengembalikan objek Generator (mengikuti kedua protocol: iterable dan iterator)
- Eksekusi dijeda di setiap `yield` dan dilanjutkan saat `next()` dipanggil
- Bisa menerima input melalui `next(value)` — nilai dikirim kembali ke fungsi
- Bisa memiliki banyak `yield` dalam satu fungsi
- Fungsi selesai ketika `return` dipanggil atau semua kode dieksekusi
- Sangat berguna untuk lazy evaluation dan data stream

---

### Contoh Implementasi

```javascript
// Generator sederhana
function* countUpTo(max) {
  for (let i = 1; i <= max; i++) {
    yield i;
  }
}

const gen = countUpTo(3);
console.log(gen.next()); // { value: 1, done: false }
console.log(gen.next()); // { value: 2, done: false }
console.log(gen.next()); // { value: 3, done: false }
console.log(gen.next()); // { value: undefined, done: true }

// Otomatis dengan for...of
for (const num of countUpTo(5)) {
  console.log(num); // 1, 2, 3, 4, 5
}

// Generator dengan input via next()
function* talk() {
  const name = yield "Siapa nama Anda?";
  yield `Halo, ${name}!`;
  const age = yield "Berapa usia Anda?";
  yield `Anda berusia ${age} tahun.`;
}

const conversation = talk();
console.log(conversation.next().value);       // "Siapa nama Anda?"
console.log(conversation.next("Budi").value); // "Halo, Budi!"
console.log(conversation.next().value);       // "Berapa usia Anda?"
console.log(conversation.next("25").value);   // "Anda berusia 25 tahun."
```

### Koneksi

Generator function adalah cara sintaksis yang lebih mudah untuk membuat **Custom Iterator** (file 201). Ia menggunakan **yield keyword** (file 203) untuk menjeda eksekusi. Generator juga bisa mendelegasikan ke generator lain dengan **yield\*** (file 204), dan sangat berguna untuk **Data Stream** (file 205).
