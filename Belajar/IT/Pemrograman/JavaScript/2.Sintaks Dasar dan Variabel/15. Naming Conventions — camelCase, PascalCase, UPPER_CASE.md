### Definisi Singkat

_Naming conventions_ (konvensi penamaan) adalah seperangkat aturan standar atau pedoman yang digunakan untuk memberi nama variabel, fungsi, kelas, dan konstanta di dalam kode agar mudah dibaca, dipahami, dan dipelihara.

---

### Analogi

Bayangkan seperti **sistem penamaan file di dalam folder komputer Anda**:

- **`camelCase`** seperti menuliskan nama file **`laporanKeuanganBulanan.pdf`**; kata pertama diawali dengan huruf kecil, dan setiap kata selanjutnya diawali dengan huruf kapital.
    
- **`PascalCase`** seperti menuliskan nama folder/proyek **`LaporanKeuanganBulanan`**; di mana setiap awal kata menggunakan huruf kapital.
    
- **`UPPER_CASE`** seperti memberi label pada **Peringatan: `BAHAYA_KERAS`** yang menggunakan huruf kapital semua untuk menandakan bahwa nilai tersebut bersifat mutlak atau penting.
    

---

### Poin-Poin Penting

- **`camelCase`:**
    
    - Konvensi paling umum dalam JavaScript untuk penamaan variabel, fungsi, dan properti objek.
        
    - Karakter pertama menggunakan huruf kecil, lalu huruf kapital pada awal kata berikutnya (contoh: `namaPengguna`, `hitungTotal`).
        
- **`PascalCase`:**
    
    - Digunakan secara khusus untuk penamaan _Class_, _Constructor_, atau komponen (seperti pada _framework_ React).
        
    - Karakter pertama dari setiap kata menggunakan huruf kapital (contoh: `PenggunaBaru`, `KeranjangBelanja`).
        
- **`UPPER_CASE`:**
    
    - Digunakan untuk penamaan konstanta global atau nilai yang tidak akan pernah berubah (_hard-coded_).
        
    - Menggunakan huruf kapital semua dengan pemisah garis bawah `_` (contoh: `MAX_LIMIT`, `API_URL`).
        

---

### Contoh Implementasi

Berikut adalah penerapan konvensi penamaan yang sesuai dengan standar penulisan kode JavaScript:

JavaScript

```
// 1. camelCase: Digunakan untuk variabel dan fungsi biasa
let firstName = "Budi";
let hargaBarang = 50000;

function hitungDiskon(harga, persen) {
    return harga - (harga * persen / 100);
}

// 2. PascalCase: Digunakan untuk Class (Constructor)
class KeranjangBelanja {
    constructor(item) {
        this.item = item;
    }
}

// 3. UPPER_CASE: Digunakan untuk konstanta global atau konfigurasi
const TAX_RATE = 0.11;
const API_URL = "https://api.contoh.com";
```

### Koneksi

Dalam bidang **Web Development**, konsistensi dalam menggunakan konvensi penamaan sangat penting untuk:

- **Kemudahan Membaca Kode (_Readability_):** Membantu _developer_ lain membedakan mana variabel, mana kelas, dan mana konstanta sekilas.
    
- **Integrasi Framework:** _Framework_ seperti React bergantung pada _PascalCase_ untuk membedakan antara komponen UI (misalnya `<Header />`) dan elemen HTML biasa (misalnya `<div>`).
    
- **Mengurangi Bug:** Mencegah kesalahan penulisan (_typo_) pada saat memanggil fungsi atau variabel dalam proyek yang besar.
