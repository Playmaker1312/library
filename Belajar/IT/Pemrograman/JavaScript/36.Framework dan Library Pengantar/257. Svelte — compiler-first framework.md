### Definisi Singkat

**Svelte** adalah framework JavaScript inovatif yang menggeser pekerjaan dari runtime ke **compile time**. Alih-alih menggunakan virtual DOM di browser, Svelte adalah **compiler** yang mengubah kode deklaratif Anda menjadi JavaScript imperatif yang efisien saat build. Hasilnya: bundle lebih kecil dan performa lebih tinggi.

---

### Analogi

Seperti **IKEA vs tukang kayu** — React/Vue mengirimkan lemari yang sudah jadi tapi besar (runtime + virtual DOM), Svelte mengirimkan **lembaran kayu dan instruksi** yang langsung dirakit menjadi lemari pas di tempat (compiled code yang sangat efisien).

---

### Poin-Poin Penting

- **No virtual DOM**: Svelte langsung memanipulasi DOM saat state berubah — menghilangkan overhead diffing.
- **Reaktivitas built-in**: Cukup dengan `let count = 0;`, lalu `count++` otomatis mengupdate UI.
- **Reactivity declarations**: `$:` untuk mendeklarasikan pernyataan reaktif.
- **Component `.svelte` files**: Berisi `<script>`, `<style>` (scoped secara default), dan template.
- **Store**: Sistem manajemen state bawaan (`writable`, `readable`, `derived`) untuk state yang dibagikan.
- **Bundle size sangat kecil** — ideal untuk aplikasi yang perlu loading cepat.

---

### Contoh Implementasi

```svelte
<script>
  let count = 0;
  let name = 'Dunia';

  // Reaktif — otomatis dihitung ulang saat count berubah
  $: doubled = count * 2;

  // Reaktif dengan block
  $: if (count >= 10) {
    alert('Sudah 10!');
  }

  function increment() {
    count += 1;
  }
</script>

<div>
  <h1>Halo {name}!</h1>
  <p>Counter: {count}</p>
  <p>Dua kali lipat: {doubled}</p>
  <button on:click={increment}>Tambah</button>

  <input bind:value={name} placeholder="Ganti nama" />
</div>

<style>
  button { background-color: #4CAF50; color: white; padding: 8px 16px; border: none; }
</style>
```

### Koneksi

Berkaitan dengan **React & Vue** (pendekatan alternatif), **Compiler vs Runtime** (berbeda fundamental), **Vite** (SvelteKit menggunakan Vite), **SvelteKit** (full framework untuk produksi), dan **requestAnimationFrame** (animasi built-in Svelte menggunakan rAF).
