### Definisi Singkat

**React** adalah library JavaScript untuk membangun antarmuka pengguna (UI) berbasis **komponen**. Dikembangkan oleh Meta (Facebook). Konsep inti: **components** (blok UI), **JSX** (sintaks mirip HTML di JavaScript), **state & props** (data dan alurnya), dan **virtual DOM** (optimasi rendering).

---

### Analogi

Seperti **LEGO** — setiap komponen adalah batu bata yang bisa dipasang dan digunakan kembali. Anda mendeskripsikan bagaimana tampilan bata berdasarkan data (state/props), dan React mengurus bagaimana bata itu muncul di layar.

---

### Poin-Poin Penting

- **Komponen**: Fungsi atau class yang mengembalikan JSX.
- **JSX**: Ekstensi sintaks yang memungkinkan HTML-like syntax di dalam JavaScript (`<div>{nama}</div>`).
- **Props**: Data dari parent ke child (read-only).
- **State**: Data internal komponen yang jika berubah, komponen di-render ulang (`useState`, `useReducer`).
- **Virtual DOM**: Representasi UI di memori; React menghitung minimal update ke DOM asli (reconciliation).
- **Hooks**: Fungsi untuk "hook into" React features (`useEffect`, `useContext`, `useRef`).
- **One-way data flow**: Data mengalir dari atas ke bawah.

---

### Contoh Implementasi

```javascript
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Kamu mengklik {count} kali</p>
      <button onClick={() => setCount(count + 1)}>
        Tambah
      </button>
    </div>
  );
}

// Penggunaan komponen dengan props
function Greeting({ name }) {
  return <h1>Halo, {name}!</h1>;
}

function App() {
  return (
    <div>
      <Greeting name="Budi" />
      <Counter />
    </div>
  );
}
```
