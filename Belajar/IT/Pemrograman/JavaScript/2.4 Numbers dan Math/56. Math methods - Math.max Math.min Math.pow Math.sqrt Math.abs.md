# 56. Math methods - Math.max Math.min Math.pow Math.sqrt Math.abs

**Definisi Singkat:** Methods Math untuk operasi numerik umum: maksimum, minimum, pangkat, akar, dan nilai mutlak.

**Analogi:** Seperti kalkulator ilmiah — tombol max/min (cari tertinggi/terendah), x² (pangkat), √ (akar), |x| (mutlak).

**Poin-Poin Penting:**
- `Math.max(a, b, ...)` dan `Math.min(a, b, ...)` bisa banyak argumen
- `Math.pow(base, exp)` sama dengan `base ** exp` (operator ES6)
- `Math.sqrt(x)` akar kuadrat, `Math.abs(x)` nilai absolut
- Untuk array, gunakan spread: `Math.max(...arr)`

**Contoh Kode:**
```javascript
console.log(Math.max(10, 5, 20));
console.log(Math.min(10, 5, 20));
console.log(Math.pow(3, 4));
console.log(Math.sqrt(64));
console.log(Math.abs(-15));
```
Hasil:
```
20
5
81
8
15
```

**Kasus Penggunaan Nyata:**
Mencari nilai tertinggi/terendah dalam dataset, menghitung jarak, rumus fisika.
