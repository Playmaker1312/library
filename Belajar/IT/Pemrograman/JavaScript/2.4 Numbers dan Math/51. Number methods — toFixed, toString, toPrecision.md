### Definisi Singkat

**Number formatting methods** adalah method bawaan tipe data Number di JavaScript untuk mengubah angka menjadi string dengan format tertentu. Mencakup 	oFixed, 	oString, dan 	oPrecision — digunakan untuk mengatur jumlah desimal, mengubah basis bilangan, dan mengontrol presisi angka.

---

### Analogi

Bayangkan Anda ingin menuliskan angka di papan tulis:

- **toFixed:** Anda memutuskan "tulis angka ini dengan 2 angka di belakang koma" — seperti membulatkan harga.
- **toString:** Anda ingin menulis angka dalam bentuk biner atau heksadesimal — seperti mengganti bahasa.
- **toPrecision:** Anda ingin total digit yang ditampilkan adalah 5 — seperti format ilmiah.

---

### Poin-Poin Penting

- **.toFixed(digits):** Mengembalikan string dengan digits angka di belakang koma. Melakukan **pembulatan**.
- **.toString(radix):** Mengubah angka ke string dalam basis tertentu (2=biner, 8=oktal, 16=heksadesimal). Default adix = 10.
- **.toPrecision(precision):** Mengembalikan string dengan total precision digit signifikan.
- 	oFixed dan 	oPrecision dapat menghasilkan notasi ilmiah (e+) untuk angka sangat besar/kecil.
- Hati-hati dengan **floating point**: (0.1 + 0.2).toFixed(2) menghasilkan "0.30".

---

### Contoh Implementasi

`javascript
const harga = 123.4567;

// toFixed
console.log(harga.toFixed(0));  // "123"
console.log(harga.toFixed(2));  // "123.46" (dibulatkan)
console.log(harga.toFixed(5));  // "123.45670"

// toString
console.log(harga.toString());   // "123.4567"
console.log((255).toString(16)); // "ff" (heksadesimal)
console.log((10).toString(2));   // "1010" (biner)

// toPrecision
console.log(harga.toPrecision(4)); // "123.5"
console.log(harga.toPrecision(2)); // "1.2e+2"
console.log((0.00123).toPrecision(2)); // "0.0012"
`

---

### Koneksi

Method 	oFixed sangat penting dalam **format mata uang** (bersama Intl.NumberFormat). 	oString(16) sering digunakan untuk **warna heksadesimal** di CSS (seperti #FF5733).
