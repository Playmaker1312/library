# 51. Number methods - toFixed toString toPrecision

**Definisi Singkat:** Methods untuk mengkonversi dan memformat angka ke string dengan presisi tertentu.

**Analogi:** Seperti mesin kasir: toFixed untuk format harga 2 desimal, toString untuk struk angka.

**Poin-Poin Penting:**
- `.toFixed(n)` membulatkan ke n desimal, mengembalikan string
- `.toString(base)` mengkonversi ke basis bilangan (2, 8, 16, dll)
- `.toPrecision(n)` menentukan total digit signifikan
- Hati-hati dengan floating point rounding pada toFixed

**Contoh Kode:**
```javascript
const harga = 123.4567;
console.log(harga.toFixed(2));
console.log(harga.toString(16));
console.log(harga.toPrecision(4));
```
Hasil:
```
123.46
7b.74e4f53dc4
123.5
```

**Kasus Penggunaan Nyata:**
Format harga ke 2 desimal, konversi warna RGB ke hex, menampilkan angka ilmiah.
