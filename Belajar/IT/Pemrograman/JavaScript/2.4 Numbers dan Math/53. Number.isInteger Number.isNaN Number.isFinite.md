# 53. Number.isInteger Number.isNaN Number.isFinite

**Definisi Singkat:** Methods ES6 untuk mengecek tipe angka secara andal.

**Analogi:** Seperti petugas keamanan: isInteger cek KTP, isNaN cek apakah "bukan angka", isFinite cek apakah terbatas.

**Poin-Poin Penting:**
- `Number.isInteger()` — true jika bilangan bulat
- `Number.isNaN()` — lebih andal dari global `isNaN()`
- `Number.isFinite()` — cek apakah angka terbatas (bukan Infinity atau NaN)
- Method ini tidak melakukan type coercion (tidak seperti global version)

**Contoh Kode:**
```javascript
console.log(Number.isInteger(42));
console.log(Number.isInteger(3.14));
console.log(Number.isNaN(NaN));
console.log(Number.isNaN("NaN"));
console.log(Number.isFinite(1 / 0));
console.log(Number.isFinite(100));
```
Hasil:
```
true
false
true
false
false
true
```

**Kasus Penggunaan Nyata:**
Validasi input numerik, cek hasil perhitungan sebelum diproses lebih lanjut.
