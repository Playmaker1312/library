### Definisi Singkat

**parseInt** dan **parseFloat** adalah fungsi global di JavaScript yang digunakan untuk mengonversi (**parse**) string menjadi angka. parseInt untuk bilangan bulat (integer), parseFloat untuk bilangan desimal (floating point).

---

### Analogi

Bayangkan Anda membaca papan harga di toko:

- Tulisan di papan adalah **string**: "Rp 25.000"
- **parseInt** membaca "25.000" dan mengambil angka 25 (hanya bagian depan).
- **parseFloat** membaca "25.500" dan mengambil 25.5.
- Keduanya mengabaikan karakter yang bukan angka di akhir.

---

### Poin-Poin Penting

- **parseInt(string, radix):** Membaca bilangan bulat dari awal string hingga karakter non-angka. adix adalah basis (2-36). **Selalu sertakan radix 10** untuk keamanan.
- **parseFloat(string):** Membaca bilangan desimal. Hanya mengenali basis 10.
- Keduanya mengabaikan **spasi di awal**.
- Jika tidak ada angka yang bisa dibaca, mengembalikan **NaN**.
- Number() berbeda karena mengembalikan NaN untuk string seperti "100px", sedangkan parseInt("100px") mengembalikan 100.

---

### Contoh Implementasi

`javascript
// parseInt
console.log(parseInt("42"));         // 42
console.log(parseInt("100px"));      // 100
console.log(parseInt("  -99"));      // -99
console.log(parseInt("3.14"));       // 3 (hanya bilangan bulat)
console.log(parseInt("abc"));        // NaN
console.log(parseInt("1010", 2));    // 10 (biner ke desimal)
console.log(parseInt("FF", 16));     // 255 (heksadesimal)

// parseFloat
console.log(parseFloat("3.14"));     // 3.14
console.log(parseFloat(" 2.5px "));  // 2.5
console.log(parseFloat("100.99"));   // 100.99
console.log(parseFloat("abc"));      // NaN

// Perbedaan dengan Number()
console.log(Number("100px"));        // NaN
console.log(parseInt("100px"));      // 100
`

---

### Koneksi

parseInt dan parseFloat sering digunakan saat mengambil data dari **input form** (yang selalu string) atau **CSS values** seperti "100px". Berkaitan dengan **Number.isInteger** dan **Number.isNaN** (materi 53) untuk validasi hasil parsing.
