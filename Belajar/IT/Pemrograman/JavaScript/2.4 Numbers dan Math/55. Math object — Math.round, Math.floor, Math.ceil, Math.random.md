### Definisi Singkat

**Math object** adalah object bawaan JavaScript yang menyediakan properti dan method untuk operasi matematika dasar. Method yang paling umum meliputi Math.round, Math.floor, Math.ceil, dan Math.random — digunakan untuk pembulatan dan pembangkitan angka acak.

---

### Analogi

Bayangkan Anda melihat ketinggian air di gelas ukur:

- **Math.round:** Membulatkan ke bilangan bulat terdekat — seperti pembulatan nilai ujian.
- **Math.floor:** Membulatkan ke bawah (lantai) — seperti memotong angka desimal tanpa peduli.
- **Math.ceil:** Membulatkan ke atas (langit-langit) — seperti menentukan jumlah bus yang dibutuhkan.
- **Math.random:** Melempar dadu — menghasilkan angka acak antara 0 dan 1.

---

### Poin-Poin Penting

- **Math.round(x):** Membulatkan ke integer terdekat. .5 ke atas.
- **Math.floor(x):** Membulatkan ke bawah (ke integer lebih kecil).
- **Math.ceil(x):** Membulatkan ke atas (ke integer lebih besar).
- **Math.random():** Mengembalikan angka acak antara 0 (inklusif) dan 1 (eksklusif).
- Untuk angka negatif: Math.floor(-3.1) = -4 (ke bawah), Math.ceil(-3.9) = -3 (ke atas).
- Math object bukan constructor — semua method dan propertinya statis.

---

### Contoh Implementasi

`javascript
// Pembulatan
console.log(Math.round(3.14));   // 3
console.log(Math.round(3.5));    // 4
console.log(Math.round(-3.5));   // -3

// Floor (ke bawah)
console.log(Math.floor(3.9));    // 3
console.log(Math.floor(-3.1));   // -4

// Ceil (ke atas)
console.log(Math.ceil(3.1));     // 4
console.log(Math.ceil(-3.9));    // -3

// Random
console.log(Math.random());      // 0.1234... (acak)
console.log(Math.random());      // 0.5678... (acak)

// Random dalam rentang 1-10
const acak1to10 = Math.floor(Math.random() * 10) + 1;
console.log(acak1to10);

// Random dalam rentang min-max
function randomRange(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}
console.log(randomRange(5, 10)); // 5-10 acak
`

---

### Koneksi

Method pembulatan sering digunakan bersama **Number methods** seperti 	oFixed (materi 51). Math.random adalah dasar untuk **game development**, **undian**, dan **A/B testing** di web.
