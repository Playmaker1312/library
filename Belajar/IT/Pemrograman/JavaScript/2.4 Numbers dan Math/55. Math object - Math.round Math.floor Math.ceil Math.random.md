# 55. Math object - Math.round Math.floor Math.ceil Math.random

**Definisi Singkat:** Methods Math untuk pembulatan angka dan menghasilkan angka acak.

**Analogi:** Seperti mesin arcade: round (pembulatan biasa), floor (selalu ke bawah), ceil (selalu ke atas), random (kocok dadu).

**Poin-Poin Penting:**
- `Math.round(x)` — membulatkan ke integer terdekat
- `Math.floor(x)` — selalu membulatkan ke bawah
- `Math.ceil(x)` — selalu membulatkan ke atas
- `Math.random()` — menghasilkan angka 0 ≤ x < 1
- Kombinasi `Math.floor(Math.random() * n)` untuk 0 sampai n-1

**Contoh Kode:**
```javascript
console.log(Math.round(4.7));
console.log(Math.floor(4.7));
console.log(Math.ceil(4.1));
console.log(Math.random());
console.log(Math.floor(Math.random() * 6) + 1);
```
Hasil:
```
5
4
5
0.725... (acak)
4 (acak antara 1-6)
```

**Kasus Penggunaan Nyata:**
Simulasi dadu, random ID, pembulatan harga, pagination.
