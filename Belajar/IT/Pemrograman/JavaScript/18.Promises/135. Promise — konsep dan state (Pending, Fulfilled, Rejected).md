### Definisi Singkat
Promise adalah objek bawaan JavaScript yang merepresentasikan hasil dari operasi asynchronous — baik yang berhasil (fulfilled) maupun gagal (rejected). Promise memiliki tiga state (keadaan): **Pending** (menunggu), **Fulfilled** (berhasil), dan **Rejected** (gagal). Sekali berubah dari pending, state tidak bisa diubah lagi (immutable).

---

### Analogi
Kamu pergi ke restoran dan pesan nasi goreng. Karyawan restoran memberikan **tanda terima (Promise)**. Kondisinya:
- **Pending**: Koki masih memasak — kamu belum dapat nasi goreng, tapi pesanan sudah dicatat.
- **Fulfilled**: Nasi goreng sudah siap dan diantar ke meja kamu.
- **Rejected**: Maaf, nasi goreng habis — pesanan dibatalkan.

Kamu tidak bisa mengubah tanda terima menjadi menu lain setelah dapur memprosesnya.

---

### Poin-Poin Penting
- `Pending` — state awal, operasi masih berjalan, promise belum selesai.
- `Fulfilled` — operasi berhasil, `.then()` akan dipanggil.
- `Rejected` — operasi gagal, `.catch()` akan dipanggil.
- State hanya bisa berubah sekali: **Pending → Fulfilled** atau **Pending → Rejected**.
- Promise memiliki method `.then()`, `.catch()`, dan `.finally()` untuk menangani hasilnya.

---

### Contoh Implementasi

```javascript
const promise = new Promise((resolve, reject) => {
  const success = true;

  setTimeout(() => {
    if (success) {
      resolve('Data berhasil dimuat'); // → Fulfilled
    } else {
      reject(new Error('Gagal memuat data')); // → Rejected
    }
  }, 2000);
});

console.log(promise); // Promise { <pending> }

setTimeout(() => {
  console.log(promise); // Promise { 'Data berhasil dimuat' } atau <rejected>
}, 3000);
```

Memeriksa state secara eksplisit (tidak umum, hanya untuk debugging):

```javascript
const p = new Promise((resolve) => resolve('OK'));
console.log(p); // Promise { 'OK' }
// State: fulfilled
```

---

### Koneksi
Promise adalah jembatan antara **callback** dan **async/await**. Pahami tiga state ini karena async/await bekerja di atas Promise — `await` menunggu Promise berubah dari pending ke fulfilled/rejected.
