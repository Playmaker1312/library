### Definisi Singkat

Perulangan `for...of` adalah fitur modern yang diperkenalkan pada ES6 untuk melakukan iterasi terhadap nilai dari sebuah objek yang dapat diiterasi (_iterable objects_), seperti _array_, _string_, maupun _map_. Perulangan ini memberikan cara yang lebih bersih dan mudah dibaca untuk mendapatkan nilai dari setiap elemen tanpa perlu melacak indeksnya.

---

### Analogi

Bayangkan seperti **membaca daftar menu makanan yang disajikan di atas meja**:

- Anda melihat dan mengambil makanan satu per satu dari piring tersebut.
    
- Anda tidak perlu tahu nomor piring atau menghitung posisinya; Anda cukup menikmati atau memproses makanan yang ada di piring tersebut secara langsung.
    

---

### Poin-Poin Penting

- **Sintaks Dasar:**
    
    $$\text{for (variable of iterable) \{ // blok kode \}}$$
    
- **Kelebihan dibandingkan `for` klasik:**
    
    - Tidak perlu menggunakan indeks (seperti `array[i]`), sehingga kode lebih ringkas dan mudah dibaca.
        
    - Anda tidak perlu memikirkan batas akhir array (`array.length`).
        
- **Keluaran:** Memberikan akses langsung ke **nilai** (_value_) dari elemen tersebut pada setiap iterasi.
    
- **Kompatibilitas:** Dapat digunakan pada _array_, _string_, _set_, dan _map_, tetapi tidak dapat digunakan pada objek biasa yang tidak dapat diiterasi (_non-iterable_).
    

---

### Contoh Implementasi

Berikut adalah contoh penggunaan perulangan `for...of` untuk membaca data di dalam _array_:

JavaScript

```
// Iterasi pada Array biasa
const daftarBuah = ["Apel", "Mangga", "Jeruk", "Pisang"];

for (const buah of daftarBuah) {
    console.log("Saya ingin makan buah: " + buah);
}

// Output:
// Saya ingin makan buah: Apel
// Saya ingin makan buah: Mangga
// Saya ingin makan buah: Jeruk
// Saya ingin makan buah: Pisang

// Iterasi pada String
const nama = "Budi";
for (const huruf of nama) {
    console.log(huruf);
}
```

### Koneksi

Dalam bidang **Web Development**, perulangan `for...of` sangat berguna ketika Anda perlu memproses dan merender data:

- **Menampilkan Data pada Komponen Web (seperti React):** Sangat cocok digunakan untuk mengolah _array_ objek dan mengubahnya menjadi elemen-elemen HTML atau komponen UI.
    
- **Pemrosesan Data API:** Membantu Anda mengiterasi daftar data produk dari _backend_ atau _server_ tanpa harus mengelola variabel indeks.
