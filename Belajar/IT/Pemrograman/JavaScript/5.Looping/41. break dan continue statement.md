### Definisi Singkat

`break` dan `continue` adalah pernyataan kontrol alur di dalam JavaScript yang digunakan untuk mengubah cara kerja perulangan (_loop_).

- **`break`**: Berfungsi untuk menghentikan seluruh perulangan secara total dan keluar dari blok perulangan tersebut.
    
- **`continue`**: Berfungsi untuk melewati iterasi saat ini dan langsung melompat ke iterasi perulangan berikutnya.
    

---

### Analogi

- **Analogi `break` (Membeli barang di pasar):** Anda sedang mencari sebuah baju di toko. Begitu Anda menemukan baju yang pas, Anda berhenti mencari (_break_) dan langsung pulang. Anda tidak perlu melihat sisa toko yang ada di pasar.
    
- **Analogi `continue` (Menyortir buah-buahan yang busuk):** Anda sedang memeriksa sekotak buah apel. Jika Anda menemukan apel yang busuk, Anda membuangnya dan langsung melanjutkan pemeriksaan ke apel berikutnya (_continue_ tanpa memproses apel busuk tersebut).
    

---

### Poin-Poin Penting

- **Pernyataan `break`:**
    
    - Menghentikan perulangan secara paksa.
        
    - Biasanya digunakan di dalam kondisi `if` saat target atau kondisi tertentu telah tercapai.
        
    - Berfungsi pada perulangan seperti `for`, `while`, `do-while`, dan juga pada `switch-case`.
        
- **Pernyataan `continue`:**
    
    - Menghentikan iterasi saat ini, lalu melanjutkan ke iterasi berikutnya.
        
    - Blok kode setelah pernyataan `continue` di dalam iterasi tersebut akan diabaikan.
        

---

### Contoh Implementasi

Berikut adalah contoh penggunaan `break` dan `continue` di dalam perulangan `for`:

#### 1. Contoh Penggunaan `break`:

JavaScript

```
for (let i = 1; i <= 10; i++) {
    // Berhenti total jika i sama dengan 5
    if (i === 5) {
        break; 
    }
    console.log("Iterasi ke-" + i);
}
// Output:
// Iterasi ke-1
// Iterasi ke-2
// Iterasi ke-3
// Iterasi ke-4
```

#### 2. Contoh Penggunaan `continue`:

JavaScript

```
for (let i = 1; i <= 5; i++) {
    // Lewati iterasi jika i adalah angka genap
    if (i % 2 === 0) {
        continue; 
    }
    console.log("Angka ganjil: " + i);
}
// Output:
// Angka ganjil: 1
// Angka ganjil: 3
// Angka ganjil: 5
```

---

### Koneksi

Dalam bidang **Web Development**, kedua pernyataan ini sangat membantu dalam mengelola data serta interaksi pada antarmuka pengguna:

- **Pencarian Data:** Gunakan `break` untuk menghentikan pencarian data di dalam array secara efisien begitu data yang dicari ditemukan, sehingga tidak membebani memori (_performance optimization_).
    
- **Validasi Daftar Produk:** Gunakan `continue` ketika Anda ingin menyaring atau menampilkan produk tertentu di halaman web berdasarkan suatu kriteria (misalnya menyembunyikan produk yang tidak memiliki stok).
