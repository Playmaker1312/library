### Definisi Singkat

_Nested loops_ (perulangan bersarang) adalah struktur di dalam JavaScript di mana sebuah perulangan (_loop_) berada di dalam blok perulangan lainnya. Ketika perulangan luar berjalan satu kali, perulangan di dalamnya akan diselesaikan secara penuh.

---

### Analogi

Bayangkan seperti **jarum penunjuk pada sebuah jam analog**:

- **Perulangan Luar:** Jarum panjang yang menunjukkan pergerakan **jam**. Setiap 1 jam berlalu...
    
- **Perulangan Dalam:** Jarum pendek yang menunjukkan pergerakan **menit**. Jarum ini harus berputar dari menit ke-0 hingga ke-59 di setiap satu jam tersebut.
    

---

### Poin-Poin Penting

- **Sintaks Dasar:**
    
    JavaScript
    
    ```
    for (inisialisasiLuar; kondisiLuar; incrementLuar) {
        // Blok kode perulangan luar
        for (inisialisasiDalam; kondisiDalam; incrementDalam) {
            // Blok kode perulangan dalam
        }
    }
    ```
    
- **Total Iterasi:** Total eksekusi blok kode di dalam adalah hasil kali dari jumlah iterasi perulangan luar dikali jumlah iterasi perulangan dalam.
    
- **Kinerja (_Performance_):** Hati-hati dalam menggunakan perulangan bersarang dalam jumlah yang besar. Kompleksitasnya yang tinggi dapat memperlambat performa program Anda (Kompleksitas $O(n^2)$ atau lebih).
    

---

### Contoh Implementasi

Berikut adalah contoh penggunaan perulangan bersarang untuk membuat pola matriks atau tabel koordinat:

JavaScript

```
// Membuat pola koordinat (baris dan kolom)
for (let baris = 1; baris <= 3; baris++) {
    for (let kolom = 1; kolom <= 2; kolom++) {
        console.log(`Koordinat -> Baris: ${baris}, Kolom: ${kolom}`);
    }
}

// Output:
// Koordinat -> Baris: 1, Kolom: 1
// Koordinat -> Baris: 1, Kolom: 2
// Koordinat -> Baris: 2, Kolom: 1
// Koordinat -> Baris: 2, Kolom: 2
// Koordinat -> Baris: 3, Kolom: 1
// Koordinat -> Baris: 3, Kolom: 2
```

---

### Koneksi

Dalam bidang **Web Development**, perulangan bersarang sangat berguna dalam memproses struktur data yang berlapis:

- **Pemrosesan Matriks atau Tabel Dua Dimensi:** Menelusuri baris dan kolom pada elemen _grid_, seperti papan permainan (_Tic-Tac-Toe_ atau Catur).
    
- **Manipulasi Data Bersarang (_Array of Objects_):** Mengakses data di dalam _array_ yang di dalamnya terdapat _array_ lain (seperti daftar kategori produk beserta daftar item di dalam setiap kategorinya).
