### Definisi Singkat

Perulangan `while` (_while loop_) adalah struktur kontrol di dalam JavaScript yang digunakan untuk menjalankan blok kode secara berulang selama kondisi yang ditentukan bernilai benar (_true_). Berbeda dengan `for loop` yang jumlah iterasinya sering kali sudah pasti, `while loop` sangat bergantung pada kapan kondisi tersebut menjadi salah (_false_).

---

### Analogi

Bayangkan seperti **proses mengisi ember air dengan gayung**:

- **Kondisi:** Anda memeriksa: "Apakah ember sudah penuh?"
    
- Jika **belum penuh** (_kondisi true_), Anda mengambil air dan menuangkannya ke dalam ember, lalu kembali memeriksa kondisi tersebut.
    
- Proses ini akan terus diulangi sampai ember tersebut penuh (_kondisi false_), dan barulah Anda berhenti.
    

---

### Poin-Poin Penting

- **Sintaks Dasar:**
    
    $$\text{while } (\text{kondisi}) \{ \text{// blok kode yang diulang} \}$$
    
- **Alur Eksekusi:**
    
    1. JavaScript mengevaluasi `kondisi`.
        
    2. Jika bernilai `true`, blok kode di dalam kurung kurawal dieksekusi.
        
    3. Setelah blok kode selesai, JavaScript kembali mengevaluasi kondisi.
        
    4. Perulangan berhenti saat kondisi bernilai `false`.
        
- **Peringatan _Infinite Loop_:** Anda harus memastikan bahwa ada kode di dalam perulangan yang pada akhirnya akan mengubah kondisi menjadi `false`. Jika tidak, program Anda akan mengalami perulangan tanpa henti yang dapat membuat _browser_ atau sistem _crash_.
    

---

### Contoh Implementasi

Berikut adalah contoh penggunaan `while loop` di dalam JavaScript untuk menghitung mundur:

JavaScript

```
// Menghitung mundur dari angka 3 ke 1
let hitungan = 3;

while (ungan >= 1) {
    console.log("Hitungan ke: " + hitungan);
    hitungan--; // Mengurangi hitungan agar kondisi bisa menjadi false pada saatnya
}
// Output:
// Hitungan ke: 3
// Hitungan ke: 2
// Hitungan ke: 1
```

---

### Koneksi

Dalam bidang **Web Development**, perulangan `while` sering digunakan dalam situasi di mana kita tidak tahu pasti berapa kali suatu proses akan berjalan, melainkan menunggu suatu kondisi tertentu:

- **Pengambilan Data (_Polling_ atau _Retry Mechanism_):** Memeriksa status dari _server_ atau API secara berulang setiap beberapa detik hingga data berhasil dimuat atau terjadi _timeout_.
    
- **Pencarian Data (Pencarian pada Struktur Data):** Melakukan iterasi untuk mencari elemen tertentu di dalam struktur data bersarang sampai kondisi yang dicari terpenuhi.
