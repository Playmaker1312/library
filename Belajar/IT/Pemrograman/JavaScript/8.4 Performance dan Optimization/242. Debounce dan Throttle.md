### Definisi Singkat

**Debounce** mengelompokkan panggilan beruntun menjadi satu eksekusi setelah jeda waktu tertentu. **Throttle** membatasi eksekusi maksimal satu kali dalam jangka waktu tertentu. Keduanya adalah teknik optimasi untuk mengontrol seberapa sering fungsi dipanggil.

---

### Analogi

- **Debounce**: Seperti **lift** — pintu terus terbuka selama masih ada orang yang datang, baru berangkat setelah tidak ada selama 3 detik.
- **Throttle**: Seperti **kereta** — berangkat setiap 15 menit tepat, tidak peduli berapa banyak penumpang yang datang di antaranya.

---

### Poin-Poin Penting

- Debounce cocok untuk **autocomplete search** (tunggu user selesai mengetik), throttle untuk **scroll / resize** (eksekusi berkala).
- Debounce punya varian **leading** (eksekusi di awal burst) dan **trailing** (eksekusi di akhir).
- Throttle memastikan fungsi tetap berjalan meskipun event terus-menerus terjadi.
- Implementasi naif bisa kehilangan konteks `this` — gunakan arrow function atau simpan konteks.

---

### Contoh Implementasi

```javascript
// Debounce — trailing (default)
function debounce(fn, delay) {
  let timer;
  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}

// Throttle
function throttle(fn, limit) {
  let inThrottle = false;
  return function (...args) {
    if (!inThrottle) {
      fn.apply(this, args);
      inThrottle = true;
      setTimeout(() => (inThrottle = false), limit);
    }
  };
}

// Contoh penggunaan
const handleSearch = debounce((query) => {
  console.log(`Mencari: ${query}`);
}, 300);

const handleScroll = throttle(() => {
  console.log(`Scroll position: ${window.scrollY}`);
}, 200);
```

---

### Koneksi

Berkaitan dengan **Event Loop** (microtask/macrotask), **requestAnimationFrame** (alternatif throttle untuk animasi), dan **Lazy Loading** (mengontrol kapan resource dimuat).
