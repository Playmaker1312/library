### Definisi Singkat

**Lazy Loading** adalah teknik menunda pemuatan resource (gambar, komponen, modul) sampai benar-benar dibutuhkan. Dua pendekatan utama: **dynamic `import()`** untuk modul JavaScript dan **IntersectionObserver** untuk resource berdasarkan visibilitas.

---

### Analogi

Seperti **buku tebal** — Anda tidak membaca seluruh isi buku saat membeli sampulnya. Anda hanya membuka halaman yang perlu dibaca saat itu juga, sisanya menunggu giliran.

---

### Poin-Poin Penting

- `import()` mengembalikan Promise, memungkinkan code splitting (didukung bundler seperti Webpack/Vite).
- IntersectionObserver lebih efisien daripada `scroll` event untuk infinite scroll dan lazy image.
- `loading="lazy"` atribut pada `<img>` dan `<iframe>` adalah cara native termudah.
- Lazy loading mengurangi **initial bundle size** dan **First Contentful Paint (FCP)**.
- Kombinasi dengan React.lazy + Suspense memungkinkan component-level code splitting.

---

### Contoh Implementasi

```javascript
// Dynamic import
button.addEventListener('click', async () => {
  const { format } = await import('date-fns');
  console.log(format(new Date(), 'dd/MM/yyyy'));
});

// IntersectionObserver untuk lazy image
const observer = new IntersectionObserver((entries) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      const img = entry.target;
      img.src = img.dataset.src;
      observer.unobserve(img);
    }
  });
});

document.querySelectorAll('img[data-src]').forEach((img) => observer.observe(img));
```

---

### Koneksi

Berhubungan dengan **Performance Metrics** (LCP, FCP), **Webpack/Vite code splitting**, **React.lazy**, dan **Service Worker** (pre-cache resource yang akan di-lazy load).
