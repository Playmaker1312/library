### Definisi Singkat

`requestAnimationFrame` (rAF) adalah API browser yang menjadwalkan eksekusi fungsi **sebelum proses repaint/rendering berikutnya**. Ini adalah cara standar untuk membuat animasi halus karena sinkron dengan refresh rate monitor (biasanya 60fps atau 120fps).

---

### Analogi

Seperti **orchestra conductor** yang memastikan semua musisi bermain tepat pada waktunya. Tanpa conductor, musisi bisa bermain kapan saja (seperti `setTimeout`). rAF adalah conductor yang memberi isyarat "main sekarang!" tepat sebelum penonton (layar) melihat pertunjukan.

---

### Poin-Poin Penting

- Browser mengoptimalkan rAF agar berjalan **sebelum layout/paint**, sehingga animasi lebih smooth.
- Jika tab tidak aktif, rAF otomatis **berhenti** — menghemat baterai dan CPU.
- Mengembalikan **request ID** yang bisa digunakan untuk membatalkan via `cancelAnimationFrame`.
- rAF menjalankan semua callback dalam satu frame — berbeda dengan `setTimeout` yang bisa missed frame.
- Cocok untuk animasi kustom, canvas rendering, dan visualisasi data.

---

### Contoh Implementasi

```javascript
const ball = document.getElementById('ball');
let start = null;
let position = 0;

function animate(timestamp) {
  if (!start) start = timestamp;
  const progress = timestamp - start;

  position = (progress / 16) % 600; // 600px loop
  ball.style.transform = `translateX(${position}px)`;

  requestAnimationFrame(animate);
}

requestAnimationFrame(animate);

// FPS counter
let frameCount = 0;
let lastTime = performance.now();

function countFPS(now) {
  frameCount++;
  if (now - lastTime >= 1000) {
    console.log(`FPS: ${frameCount}`);
    frameCount = 0;
    lastTime = now;
  }
  requestAnimationFrame(countFPS);
}
```

---

### Koneksi

Berkaitan erat dengan **Critical Rendering Path** (posisi rAF dalam pipeline), **Debounce/Throttle** (alternatif untuk scroll handler), **Canvas/WebGL** (render loop), dan **Performance Metrics** (FPS, frame drops).
