### Definisi Singkat
Dua cara utama mengubah style elemen: **`style` property** untuk mengatur inline style secara langsung (properti CSS camelCase), dan **`classList`** untuk menambah/menghapus/toggle class CSS yang sudah didefinisikan di stylesheet.

---

### Analgi
`style` seperti **mengecat ulang satu batu bata di dinding** — langsung, cepat, tapi khusus untuk satu elemen. `classList` seperti **mengganti wallpaper seluruh ruangan** — kamu memilih kategori style yang sudah jadi.

---

### Poin-Poin Penting

**style property:**
- Tulis CSS camelCase: `backgroundColor`, `marginTop`, `fontSize`
- Mengubah inline style langsung di elemen
- Nilai selalu string (termasuk unit: `'100px'`)
- `cssText` untuk mengatur multiple styles sekaligus

**classList:**
- `add()`, `remove()`, `toggle()`, `contains()`, `replace()`
- Tidak mengubah inline style — hanya menambah/menghapus class
- Lebih maintainable untuk style kompleks

---

### Contoh Implementasi

```javascript
const box = document.querySelector('.box');

// style property — inline
box.style.backgroundColor = 'blue';
box.style.padding = '20px';
box.style.borderRadius = '8px';
box.style.cssText = 'color: red; font-size: 16px;'; // Override semua inline

// classList
box.classList.add('active');          // tambah class
box.classList.remove('inactive');     // hapus class
box.classList.toggle('visible');      // toggle on/off
box.classList.replace('old', 'new');  // ganti class

const isActive = box.classList.contains('active');
console.log(isActive); // true/false

// Multiple class
box.classList.add('card', 'shadow', 'rounded');
```
