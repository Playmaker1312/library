### Definisi Singkat
**DocumentFragment** adalah objek DOM ringan yang bertindak sebagai container sementara. Elemen-elemen ditambahkan ke fragment terlebih dahulu, lalu fragment dimasukkan ke DOM dalam satu operasi — meminimalkan **reflow** dan **repaint** untuk performa lebih baik.

---

### Analogi
DocumentFragment seperti **nampan**. Kamu menyusun piring, gelas, dan sendok di atas nampan (fragment), lalu membawanya ke meja sekaligus (satu kali append), daripada bolak-balik membawa satu per satu.

---

### Poin-Poin Penting
- Dibuat dengan `document.createDocumentFragment()`
- Fragment tidak terlihat di DOM — hanya container sementara
- Anak-anak fragment dipindahkan (bukan di-copy) ke target
- Fragment sendiri tidak ikut tertambat ke DOM
- Sangat berguna untuk loop yang menambahkan banyak elemen
- Mengurangi jumlah DOM reflow secara signifikan

---

### Contoh Implementasi

```javascript
// Tanpa fragment — tidak efisien
const list = document.getElementById('daftar');
for (let i = 0; i < 1000; i++) {
  const li = document.createElement('li');
  li.textContent = `Item ${i}`;
  list.appendChild(li); // 1000x reflow!
}

// Dengan fragment — efisien
const fragment = document.createDocumentFragment();
for (let i = 0; i < 1000; i++) {
  const li = document.createElement('li');
  li.textContent = `Item ${i}`;
  fragment.appendChild(li);
}
list.appendChild(fragment); // 1x reflow!

// Contoh lain: bangun struktur kompleks
const frag = document.createDocumentFragment();
const div = document.createElement('div');
div.className = 'card';
div.innerHTML = '<h2>Judul</h2><p>Isi</p>';
frag.appendChild(div);
document.body.appendChild(frag);
```

---

### Koneksi
- **163 →** Operasi menambah elemen dioptimalkan dengan fragment
- **165 →** Fragment bisa diisi elemen dengan style lengkap
- **166 →** Atur atribut elemen dulu sebelum append ke fragment
