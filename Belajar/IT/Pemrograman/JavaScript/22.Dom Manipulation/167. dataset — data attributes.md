### Definisi Singkat
**Data attributes** (`data-*`) adalah atribut HTML kustom untuk menyimpan data ekstra di elemen. Diakses melalui properti **`dataset`** di JavaScript yang mengembalikan object `DOMStringMap` berisi semua `data-*` attributes.

---

### Analogi
Data attributes seperti **Post-it notes yang ditempel di barang**. Kamu bisa menulis informasi tambahan di Post-it tanpa mengubah barang itu sendiri. Bisa dibaca dan diubah kapan saja.

---

### Poin-Poin Penting
- Format HTML: `data-nama-properti="value"`
- Akses JS: `element.dataset.namaProperti` (camelCase)
- Nama `data-` diubah ke camelCase: `data-user-id` → `userId`
- Nilai selalu string (otomatis)
- Bisa diubah: `element.dataset.namaProperti = 'nilai baru'`
- Atribut akan otomatis ter-update di HTML

---

### Contoh Implementasi

```javascript
// HTML: <div id="user" data-user-id="123" data-role="admin" data-last-login="2024-01-15">

const user = document.getElementById('user');

// Membaca
console.log(user.dataset.userId);    // "123"
console.log(user.dataset.role);      // "admin"
console.log(user.dataset.lastLogin); // "2024-01-15"

// Mengecek keberadaan
console.log('userId' in user.dataset); // true

// Mengubah
user.dataset.role = 'editor';
user.dataset.status = 'active'; // Menambah baru

// Hapus
delete user.dataset.lastLogin;

// Iterasi
for (const key in user.dataset) {
  console.log(`${key}: ${user.dataset[key]}`);
}

// Di CSS
// [data-role="admin"] { background: gold; }
```
