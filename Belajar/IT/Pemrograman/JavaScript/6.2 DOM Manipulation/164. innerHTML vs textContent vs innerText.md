### Definisi Singkat
Tiga properti untuk membaca/mengubah konten elemen: **`innerHTML`** mengembalikan/mengatur HTML sebagai string (termasuk tag), **`textContent`** mengembalikan semua teks tanpa tag (termasuk teks tersembunyi), dan **`innerText`** mengembalikan teks yang tampak saja (memperhitungkan CSS dan layout).

---

### Analgi
- `innerHTML` seperti **kode sumber halaman web** — termasuk markup
- `textContent` seperti **copy-paste semua teks** dari halaman (termasuk yang di display:none)
- `innerText` seperti **membaca teks yang terlihat di layar** saja

---

### Poin-Poin Penting

| Properti | Baca HTML | Parse HTML | Perhatikan CSS | Performa |
|----------|-----------|------------|----------------|----------|
| `innerHTML` | Ya | Ya | Tidak | Lambat (parse) |
| `textContent` | Tidak | Tidak | Tidak | Cepat |
| `innerText` | Tidak | Tidak | Ya (reflow) | Paling lambat |

- `innerHTML` berbahaya jika diisi dengan input pengguna (XSS risk)
- `textContent` paling aman untuk teks mentah
- `innerText` memicu reflow — lebih lambat dari `textContent`

---

### Contoh Implementasi

```javascript
const div = document.querySelector('.content');

// HTML
div.innerHTML = '<strong>Teks tebal</strong>';
console.log(div.innerHTML); // <strong>Teks tebal</strong>

// Text content (tanpa tag)
div.textContent = '<strong>Teks tebal</strong>';
console.log(div.innerHTML); // &lt;strong&gt;... (escaped)

// innerText
div.textContent = 'Hello\nWorld';
console.log(div.innerText); // "Hello World" (gabung, tergantung CSS)

// Best practice: textContent untuk teks, innerHTML untuk HTML
const name = 'Budi';
div.textContent = `Halo, ${name}!`;  // Aman
```
