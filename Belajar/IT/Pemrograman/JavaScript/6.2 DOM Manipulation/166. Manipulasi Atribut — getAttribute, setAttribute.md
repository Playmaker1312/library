### Definisi Singkat
Manipulasi atribut HTML dilakukan dengan method **`getAttribute()`**, **`setAttribute()`**, **`removeAttribute()`**, dan **`hasAttribute()`**. Atribut HTML seperti `src`, `href`, `alt`, `disabled`, `data-*` bisa dibaca dan diubah melalui method ini.

---

### Analogi
Atribut HTML seperti **stiker label pada barang**. Kamu bisa membaca label (`getAttribute`), mengganti label (`setAttribute`), atau mencopot label (`removeAttribute`).

---

### Poin-Poin Penting
- `getAttribute(name)` mengembalikan nilai atribut (atau `null`)
- `setAttribute(name, value)` mengatur/mengubah nilai atribut
- `removeAttribute(name)` menghapus atribut
- `hasAttribute(name)` mengecek keberadaan atribut (boolean)
- Atribut boolean seperti `disabled`, `checked`, `hidden` — set nilai `''` atau nama atribut
- Beberapa atribut juga bisa diakses langsung via properti: `element.id`, `element.src`, `element.href`

---

### Contoh Implementasi

```javascript
const img = document.querySelector('img');
const link = document.querySelector('a');

// Membaca atribut
console.log(img.getAttribute('src'));
console.log(img.getAttribute('alt'));

// Mengubah atribut
img.setAttribute('src', 'gambar-baru.jpg');
img.setAttribute('alt', 'Deskripsi baru');

// Atribut boolean
const btn = document.querySelector('button');
btn.setAttribute('disabled', '');
console.log(btn.hasAttribute('disabled')); // true
btn.removeAttribute('disabled');

// Cek dan ubah
if (!link.hasAttribute('target')) {
  link.setAttribute('target', '_blank');
}

// Properti langsung vs getAttribute
// Properti: img.src — otomatis URL absolut
// getAttribute: img.getAttribute('src') — nilai asli HTML
```
