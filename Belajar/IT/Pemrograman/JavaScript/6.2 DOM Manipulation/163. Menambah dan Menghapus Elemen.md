### Definisi Singkat
Manipulasi elemen DOM mencakup pembuatan elemen baru dengan `document.createElement()`, menambahkannya ke DOM dengan `appendChild()`, `append()`, `prepend()`, `before()`, `after()`, dan menghapus dengan `removeChild()` atau `remove()`.

---

### Analgi
Seperti **bermain Lego**. Kamu bisa mengambil balok baru (`createElement`), memasangnya di tempat tertentu (`appendChild`, `after`), atau mencabutnya kembali (`removeChild`).

---

### Poin-Poin Penting
- `createElement(tagName)` membuat elemen baru (belum tampil di halaman)
- `appendChild()` menambah anak di akhir
- `append()` bisa menambah node + string sekaligus
- `prepend()` menambah di awal
- `before()` / `after()` menambah sebelum/sesudah elemen (sebagai sibling)
- `removeChild()` perlu parent, `remove()` langsung dari elemen itu sendiri
- `replaceChild()` mengganti anak yang lama

---

### Contoh Implementasi

```javascript
// Membuat elemen
const newDiv = document.createElement('div');
newDiv.textContent = 'Halo!';
newDiv.className = 'card';

// Append ke body
document.body.appendChild(newDiv);

// Append dengan posisi
const list = document.querySelector('ul');
const item = document.createElement('li');
item.textContent = 'Item baru';
list.prepend(item);        // jadi item pertama
list.append(item.cloneNode(true)); // jadi item terakhir

// Menyisipkan di antara
const refChild = list.children[2];
item.cloneNode(true).after(refChild);   // setelah refChild
item.cloneNode(true).before(refChild);  // sebelum refChild

// Menghapus
const toRemove = document.querySelector('.hapus');
toRemove.remove();            // langsung (modern)
// atau
toRemove.parentNode.removeChild(toRemove); // via parent
```
