### Definisi Singkat
`.then()`, `.catch()`, dan `.finally()` adalah method untuk mengonsumsi (consuming) Promise. `.then()` menangani hasil sukses, `.catch()` menangani error, dan `.finally()` dijalankan apa pun hasilnya (sukses/gagal).

---

### Analogi
Kamu pesan barang online:
- **.then()**: Kamu check paket saat sampai — terima dan buka.
- **.catch()**: Kamu terima paket rusak — ajukan komplain.
- **.finally()**: Apa pun yang terjadi, kamu harus tanda tangan resi pengirim.

---

### Poin-Poin Penting
- `.then(onFulfilled, onRejected)` — dua argumen: callback sukses dan opsional callback gagal.
- `.catch(onRejected)` — shortcut untuk `.then(null, onRejected)`.
- `.finally(onFinally)` — callback tanpa argumen, jalan selalu. Tidak meneruskan nilai, tetapi melewatkan nilai/error ke chain berikutnya.
- Semua method mengembalikan Promise baru, sehingga bisa di-chain.

---

### Contoh Implementasi

```javascript
function fetchData(url) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (url) resolve('Data dari ' + url);
      else reject(new Error('URL tidak valid'));
    }, 1000);
  });
}

// .then() — handle sukses
fetchData('/api/user')
  .then(data => console.log(data)); // Data dari /api/user

// .catch() — handle error
fetchData('')
  .catch(err => console.log('Error:', err.message)); // Error: URL tidak valid

// .finally() — selalu jalan
fetchData('/api/user')
  .then(data => console.log(data))
  .catch(err => console.error(err))
  .finally(() => console.log('Selesai — selalu dijalankan'));
```

`.then()` dengan dua argumen (tanpa .catch):

```javascript
fetchData('')
  .then(
    data => console.log(data),
    err => console.log('Gagal:', err.message) // Error handling di sini
  );
```

---

### Koneksi
`.then()`, `.catch()`, `.finally()` adalah method dasar yang memungkinkan **Promise Chaining**. Semua method ini mengembalikan Promise, memungkinkan kita merangkai operasi asynchronous secara linear tanpa nested callback.
