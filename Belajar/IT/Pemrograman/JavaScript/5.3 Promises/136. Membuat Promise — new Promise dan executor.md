### Definisi Singkat
Promise dibuat menggunakan constructor `new Promise(executor)`. Executor adalah fungsi yang langsung dipanggil (synchronous) saat Promise dibuat, menerima dua parameter: `resolve` (untuk menandai sukses) dan `reject` (untuk menandai gagal).

---

### Analogi
Kamu pesan kue ke toko roti. Kamu kasih resep dan instruksi (executor). Tukang roti langsung mulai mengerjakan. Saat kue matang, dia bilang **"Jadi nih!" (resolve)**. Saat ada masalah, dia bilang **"Maaf, oven rusak" (reject)**.

---

### Poin-Poin Penting
- `executor` dieksekusi **saat Promise dibuat**, bukan saat `.then()` dipanggil.
- `resolve(value)` mengubah state dari **Pending → Fulfilled** dengan nilai `value`.
- `reject(reason)` mengubah state dari **Pending → Rejected** dengan alasan error.
- Jika terjadi error di dalam executor (exception), otomatis Promise akan **rejected**.
- Hanya `resolve` atau `reject` pertama yang berpengaruh — panggilan kedua diabaikan.

---

### Contoh Implementasi

```javascript
function fetchUser(id) {
  return new Promise((resolve, reject) => {
    console.log('Mengambil data user...');

    setTimeout(() => {
      const user = { id, name: 'Andi' };

      if (user) {
        resolve(user); // Promise fulfilled dengan nilai user
      } else {
        reject(new Error('User tidak ditemukan'));
      }
    }, 1000);
  });
}

const userPromise = fetchUser(1);
// Executor langsung jalan, setTimeout dijadwalkan
```

Exception otomatis menjadi reject:

```javascript
const p = new Promise((resolve, reject) => {
  throw new Error('Something went wrong');
  // Sama seperti reject(new Error('Something went wrong'))
});

p.catch(err => console.log(err.message)); // Something went wrong
```

Hanya panggilan pertama yang berlaku:

```javascript
const p = new Promise((resolve, reject) => {
  resolve('Pertama');
  resolve('Kedua'); // Diabaikan
  reject(new Error('Gagal')); // Diabaikan
});

p.then(console.log); // Pertama
```

---

### Koneksi
Setelah menguasai cara membuat Promise, langkah berikutnya adalah **mengonsumsi** Promise dengan `.then()`, `.catch()`, `.finally()`, lalu **chaining** dan **Promise static methods**.
