### Definisi Singkat
Promisification adalah proses mengubah fungsi yang menggunakan pola callback (khususnya Error-First Callback) menjadi fungsi yang mengembalikan Promise. Di Node.js, `util.promisify()` menyediakan cara bawaan untuk melakukan ini.

---

### Analogi
Kamu punya resep kue yang ditulis dalam bahasa Mandarin (callback). Kamu menerjemahkannya ke bahasa Indonesia (Promise). Isi dan langkahnya sama, tapi sekarang lebih mudah dipahami dan diikuti oleh orang Indonesia — tanpa mengubah si pembuat kue.

---

### Poin-Poin Penting
- Tujuan: mengubah kode callback yang nested menjadi Promise chain yang rapi.
- `util.promisify(fn)` — function bawaan Node.js untuk promisification otomatis.
- Fungsi callback harus mengikuti **Error-First Callback Pattern** (`(err, result) => ...`).
- Bisa juga dilakukan manual dengan membungkus dalam `new Promise`.
- Banyak API Node.js sudah punya versi Promise native (`.promises`), seperti `fs.promises`.

---

### Contoh Implementasi

**Manual Promisification — bungkus sendiri dengan `new Promise`:**

```javascript
const fs = require('fs');

function readFilePromise(path, encoding) {
  return new Promise((resolve, reject) => {
    fs.readFile(path, encoding, (err, data) => {
      if (err) reject(err);
      else resolve(data);
    });
  });
}

// Penggunaan
readFilePromise('data.txt', 'utf8')
  .then(data => console.log(data))
  .catch(err => console.error(err));
```

**Menggunakan `util.promisify()` (Node.js):**

```javascript
const fs = require('fs');
const util = require('util');

const readFile = util.promisify(fs.readFile);
const writeFile = util.promisify(fs.writeFile);

// Penggunaan dengan Promise
readFile('data.txt', 'utf8')
  .then(data => writeFile('backup.txt', data))
  .then(() => console.log('Backup berhasil'))
  .catch(err => console.error(err));
```

**Fungsi callback kustom — dibungkus Promise:**

```javascript
function getUserData(callback) {
  setTimeout(() => {
    const user = { id: 1, name: 'Andi' };
    callback(null, user);
  }, 1000);
}

const getUserDataPromise = util.promisify(getUserData);
// Atau manual:
// const getUserDataPromise = () => new Promise((resolve, reject) => {
//   getUserData((err, user) => err ? reject(err) : resolve(user));
// });

getUserDataPromise().then(user => console.log(user)); // { id: 1, name: 'Andi' }
```

**Native Promise API di Node.js (tanpa promisify):**

```javascript
const fs = require('fs').promises;
// atau: const fsPromises = require('fs/promises');

async function bacaFile() {
  try {
    const data = await fs.readFile('data.txt', 'utf8');
    console.log(data);
  } catch (err) {
    console.error(err);
  }
}
```

---

### Koneksi
Promisification menjembatani kode **callback-based** (Node.js legacy) ke dunia **Promise** dan **async/await**. Setelah semua fungsi berubah menjadi Promise, kita bisa menggunakan async/await untuk kode yang lebih bersih dan mudah dibaca.
