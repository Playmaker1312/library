### Definisi Singkat
`Promise.all()` dan `Promise.race()` adalah static method untuk menangani banyak Promise secara paralel. `Promise.all()` menunggu **semua** Promise selesai (return array hasil), sedangkan `Promise.race()` mengambil hasil Promise **paling cepat** selesai (baik resolve maupun reject).

---

### Analogi
- **Promise.all**: Kamu pesan 3 barang dari toko berbeda online. Kamu menunggu **semua paket sampai** baru bisa merakit furnitur. Jika satu barang batal, semuanya gagal.
- **Promise.race**: Kamu pesan ojek dari Gojek dan Grab bersamaan. Kamu naik dengan **yang datang duluan**, yang lain dibatalkan.

---

### Poin-Poin Penting
- `Promise.all(iterable)` — mengembalikan Promise dengan array hasil sesuai urutan input.
- Jika **satu saja** Promise rejected, `Promise.all` langsung rejected (fail-fast).
- `Promise.race(iterable)` — mengembalikan Promise pertama yang selesai (resolve/reject).
- Pastikan semua item dalam iterable adalah Promise (bisa juga nilai biasa, akan dibungkus `Promise.resolve`).

---

### Contoh Implementasi

```javascript
const p1 = Promise.resolve(10);
const p2 = new Promise(resolve => setTimeout(() => resolve(20), 1000));
const p3 = 30; // nilai biasa, otomatis dibungkus Promise.resolve

// Promise.all — tunggu semua selesai
Promise.all([p1, p2, p3])
  .then(results => {
    console.log(results); // [10, 20, 30] (setelah 1 detik)
  })
  .catch(err => console.error(err));
```

`Promise.all` — fail-fast:

```javascript
const p1 = Promise.resolve('OK');
const p2 = Promise.reject(new Error('Gagal'));
const p3 = Promise.resolve('OK');

Promise.all([p1, p2, p3])
  .then(results => console.log(results)) // Tidak akan jalan
  .catch(err => console.log(err.message)); // Gagal
```

`Promise.race` — ambil yang tercepat:

```javascript
const slow = new Promise(resolve => setTimeout(() => resolve('Lambat'), 2000));
const fast = new Promise(resolve => setTimeout(() => resolve('Cepat'), 500));

Promise.race([slow, fast])
  .then(result => console.log(result)); // "Cepat" (setelah 500ms)
```

Implementasi timeout dengan `Promise.race`:

```javascript
function fetchWithTimeout(url, ms) {
  const fetchPromise = fetch(url);
  const timeoutPromise = new Promise((_, reject) =>
    setTimeout(() => reject(new Error('Timeout')), ms)
  );
  return Promise.race([fetchPromise, timeoutPromise]);
}
```

---

### Koneksi
`Promise.all` sangat berguna saat membutuhkan data dari beberapa endpoint API sebelum merender halaman. `Promise.race` berguna untuk timeout atau mengambil resource dari sumber tercepat. Lanjut ke **Promise.allSettled** dan **Promise.any** untuk opsi yang lebih fleksibel.
