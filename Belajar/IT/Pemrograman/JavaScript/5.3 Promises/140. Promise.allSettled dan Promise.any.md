### Definisi Singkat
`Promise.allSettled()` menunggu semua Promise selesai (apapun hasilnya) dan mengembalikan array objek `{status, value/reason}`. `Promise.any()` mengembalikan Promise pertama yang **fulfilled** — hanya rejected jika semua Promise rejected.

---

### Analogi
- **Promise.allSettled**: Kamu kirim 3 lamaran kerja. Kamu catat **hasil masing-masing**: diterima/ditolak, tanpa menghentikan proses lamaran lainnya.
- **Promise.any**: Kamu naik angkot — kamu naik **yang pertama datang**, tidak peduli yang lain macet atau mogok.

---

### Poin-Poin Penting
- `Promise.allSettled` — tidak fail-fast; semua hasil dikembalikan.
- Setiap hasil berupa `{status: "fulfilled", value: ...}` atau `{status: "rejected", reason: ...}`.
- `Promise.any` — mirip `race`, tapi hanya memperhatikan **fulfilled**. Abaikan rejected selama masih ada yang fulfilled.
- `Promise.any` akan rejected dengan `AggregateError` jika **semua** Promise rejected.

---

### Contoh Implementasi

```javascript
const p1 = Promise.resolve('Sukses');
const p2 = Promise.reject(new Error('Gagal'));
const p3 = new Promise(resolve => setTimeout(() => resolve('Lambat'), 500));

// Promise.allSettled
Promise.allSettled([p1, p2, p3])
  .then(results => {
    results.forEach((result, i) => {
      if (result.status === 'fulfilled') {
        console.log(`P${i + 1} fulfilled:`, result.value);
      } else {
        console.log(`P${i + 1} rejected:`, result.reason.message);
      }
    });
    // Output:
    // P1 fulfilled: Sukses
    // P2 rejected: Gagal
    // P3 fulfilled: Lambat
  });
```

`Promise.any` — ambil Promise pertama yang fulfilled:

```javascript
const slow = new Promise(resolve => setTimeout(() => resolve('Lambat'), 2000));
const fast = Promise.resolve('Cepat');
const failed = Promise.reject(new Error('Error'));

Promise.any([failed, fast, slow])
  .then(result => console.log(result)); // "Cepat"
```

`Promise.any` — jika semua rejected:

```javascript
const p1 = Promise.reject(new Error('Err 1'));
const p2 = Promise.reject(new Error('Err 2'));

Promise.any([p1, p2])
  .catch(err => {
    console.log(err instanceof AggregateError); // true
    console.log(err.errors); // [Error: Err 1, Error: Err 2]
  });
```

---

### Koneksi
`Promise.allSettled` berguna saat kamu ingin tahu hasil **semua** operasi tanpa peduli ada yang gagal (misal logging batch). `Promise.any` berguna saat kamu butuh satu sumber sukses dari banyak opsi redundan. Keempat static methods (`all`, `race`, `allSettled`, `any`) memberikan fleksibilitas penuh dalam mengelola Promise paralel.
