### Definisi Singkat
Error handling pada Promise dilakukan dengan `.catch()` untuk menangkap rejection, serta event `unhandledrejection` (browser) atau `process.on('unhandledRejection')` (Node.js) untuk rejection yang tidak tertangani.

---

### Analogi
Kamu main game dan karakter kamu kalah. Game memberikan layar **"Game Over" (.catch())** — kamu bisa coba lagi. Tapi jika game tiba-tiba crash tanpa pesan error sama sekali (**unhandled rejection**) — itu lebih buruk karena kamu tidak tahu apa yang salah.

---

### Poin-Poin Penting
- `.catch(errorHandler)` menangkap rejection di **chain mana pun** — error akan "turun" hingga ketemu `.catch()`.
- `.then(onFulfilled, onRejected)` bisa menangkap error di **Promise sebelumnya**, tapi tidak menangkap error di `onFulfilled` sendiri.
- Error yang dilempar di dalam `.then()` atau `.catch()` otomatis menjadi Promise rejected.
- `finally()` tidak menangkap error, hanya menjalankan cleanup.
- Rejection yang tidak ditangani menyebabkan **unhandled rejection** — crash di Node.js, warning di browser.

---

### Contoh Implementasi

```javascript
function fetchData(shouldFail) {
  return new Promise((resolve, reject) => {
    if (shouldFail) {
      reject(new Error('Gagal mengambil data'));
    } else {
      resolve('Data berhasil');
    }
  });
}

// .catch() di akhir chain — tangkap error dari mana pun
fetchData(false)
  .then(data => { throw new Error('Error di .then()'); })
  .then(() => console.log('Tidak sampai sini'))
  .catch(err => console.log('Tertangkap:', err.message));
// Output: Tertangkap: Error di .then()
```

Perbandingan `.catch()` vs `.then(null, fn)`:

```javascript
// .then(null, fn) — tidak tangkap error di dalam onFulfilled
Promise.resolve('OK')
  .then(
    data => { throw new Error('Error di sini'); },
    err => console.log('Tidak akan menangkap')
  )
  .catch(err => console.log('Baru tertangkap:', err.message));

// .catch() di ujung — tangkap semua
Promise.resolve('OK')
  .then(data => { throw new Error('Error di sini'); })
  .catch(err => console.log('Tertangkap:', err.message));
```

Unhandled Rejection:

```javascript
// Di browser
window.addEventListener('unhandledrejection', event => {
  console.log('Unhandled:', event.reason);
});

// Di Node.js
process.on('unhandledRejection', (reason, promise) => {
  console.error('Unhandled Rejection at:', promise, 'reason:', reason);
});

const p = Promise.reject(new Error('Tidak ditangani')); // Memicu event di atas
```

---

### Koneksi
Error handling pada Promise adalah fondasi untuk **try-catch di async/await** — yang sebenarnya adalah syntactic sugar di atas Promise. Pahami perbedaan `.catch()` dan `try-catch` agar bisa memilih strategi error handling yang tepat.
