### Definisi Singkat
Promise Chaining adalah teknik merangkai beberapa operasi asynchronous secara berurutan dengan cara mengembalikan Promise baru dari dalam `.then()`. Setiap `.then()` menunggu Promise sebelumnya selesai sebelum dieksekusi.

---

### Analogi
Kamu mau bikin kopi: **Siapkan air → Rebus air → Masukkan bubuk kopi → Saring → Tuang ke cangkir**. Setiap langkah bergantung pada hasil langkah sebelumnya dan menghasilkan output untuk langkah berikutnya. Kamu tidak bisa melompati urutan.

---

### Poin-Poin Penting
- `.then()` mengembalikan Promise baru — jika callback mengembalikan nilai, Promise otomatis `fulfilled` dengan nilai itu.
- Jika callback mengembalikan Promise, chain akan menunggu Promise tersebut.
- Error di **satu titik** bisa ditangkap oleh satu `.catch()` di akhir chain.
- Chaining membuat kode asynchronous linear dan mudah dibaca — tidak seperti nested callback.

---

### Contoh Implementasi

```javascript
function step1() {
  return new Promise(resolve => {
    setTimeout(() => resolve(1), 1000);
  });
}

function step2(value) {
  return new Promise(resolve => {
    setTimeout(() => resolve(value + 2), 1000);
  });
}

function step3(value) {
  return new Promise(resolve => {
    setTimeout(() => resolve(value + 3), 1000);
  });
}

// Promise Chaining
step1()
  .then(result1 => {
    console.log('Step 1:', result1); // Step 1: 1
    return step2(result1);
  })
  .then(result2 => {
    console.log('Step 2:', result2); // Step 2: 3
    return step3(result2);
  })
  .then(result3 => {
    console.log('Step 3:', result3); // Step 3: 6
  })
  .catch(err => console.error(err));
```

Return nilai biasa (bukan Promise) — otomatis dibungkus Promise:

```javascript
Promise.resolve(5)
  .then(n => n * 2)
  .then(n => n + 1)
  .then(n => console.log(n)); // 11
```

Error handling terpusat:

```javascript
fetchUser()
  .then(user => fetchOrders(user.id))
  .then(orders => fetchDetails(orders[0].id))
  .then(details => processPayment(details.total))
  .catch(err => console.error('Error di mana pun:', err));
```

---

### Koneksi
Promise Chaining adalah langkah besar mengatasi **Callback Hell**. Namun untuk keterbacaan lebih baik, **async/await** menyempurnakan pola ini dengan membuat kode terlihat seperti synchronous.
