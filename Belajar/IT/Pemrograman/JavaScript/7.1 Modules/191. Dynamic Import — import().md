### Definisi Singkat
**Dynamic import** (`import()`) adalah function-like expression yang mengembalikan **Promise** untuk memuat module secara asynchronous saat runtime. Berbeda dengan static import, dynamic import memungkinkan **lazy loading**, **conditional loading**, dan **on-demand module loading**.

---

### Analogi
Static import seperti **membawa semua buku dalam ransel** sejak pagi — berat, tapi semua siap. Dynamic import seperti **meminjam buku dari perpustakaan** saat kamu membutuhkannya — lebih ringan, tapi butuh waktu ambil.

---

### Poin-Poin Penting
- `import(modulePath)` mengembalikan Promise → object module
- Akses named export: `module.namedExport`
- Akses default export: `module.default` atau destructure
- Bisa digunakan di script biasa (non-module) juga
- Path bisa **dinamis** (string hasil expression/variable)
- Error handling dengan `.catch()` atau `try/catch` (async/await)
- Cocok untuk: code splitting, rute SPA, polyfill conditional, big library

---

### Contoh Implementasi

```javascript
// Lazy loading — muat saat dibutuhkan
const btn = document.querySelector('#loadChart');
btn.addEventListener('click', async () => {
  try {
    const chartModule = await import('./Chart.js');
    const chart = new chartModule.default();
    chart.render();
  } catch (err) {
    console.log('Gagal memuat chart:', err);
  }
});

// Conditional loading
if (typeof window.IntersectionObserver === 'undefined') {
  const polyfill = await import('./intersection-observer-polyfill.js');
}

// Dynamic path
const lang = navigator.language.startsWith('id') ? 'id' : 'en';
const i18n = await import(`./locales/${lang}.js`);

// Route-based code splitting (SPA)
const routes = {
  '/home': () => import('./pages/Home.js'),
  '/about': () => import('./pages/About.js'),
  '/users': () => import('./pages/Users.js'),
};

async function navigate(path) {
  const loadModule = routes[path];
  if (loadModule) {
    const page = await loadModule();
    page.render();
  }
}

// Destructure langsung
const { default: Component, helper } = await import('./Component.js');
```
