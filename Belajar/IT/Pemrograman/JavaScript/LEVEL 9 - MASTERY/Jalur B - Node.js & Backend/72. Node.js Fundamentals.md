# Node.js Fundamentals

## Penjelasan
Node.js adalah runtime JavaScript di sisi server berbasis mesin V8 Chrome. Node.js memungkinkan JavaScript berjalan di luar browser, membaca file sistem, mengelola jaringan, dan membuat server HTTP. Node.js menggunakan event-driven, non-blocking I/O model yang membuatnya ringan dan efisien untuk aplikasi real-time.

## Fungsi
- Membuat server backend API (REST, GraphQL)
- Membaca dan menulis file sistem
- Mengelola database (MongoDB, PostgreSQL, MySQL)
- Real-time aplikasi (chat, notifikasi) dengan WebSocket
- Command Line Tools (CLI)
- Build tools dan automation (Webpack, Vite, Gulp)

## Cara Pengimplementasian

```javascript
// Node.js Fundamentals — analogi RUMAH: rumah yang bisa diatur dari "ruang server"
// Node.js adalah sistem kelistrikan & pipa yang mengalir di seluruh rumah

// 1. Modul System (fs) — seperti membaca denah rumah dari file
const fs = require('fs');
const path = require('path');

// Baca file denah rumah
// fs.readFile(path.join(__dirname, 'denah.txt'), 'utf8', (err, data) => {
//   if (err) throw err;
//   console.log('Denah rumah:', data);
// });

// Versi modern dengan fs.promises
async function bacaDenah() {
  try {
    const data = await fs.promises.readFile('denah.txt', 'utf8');
    console.log('Denah rumah:', data);
  } catch (err) {
    console.error('Gagal baca denah:', err.message);
  }
}

// 2. HTTP Server — seperti pintu utama rumah yang menerima tamu
const http = require('http');

const server = http.createServer((req, res) => {
  // req = tamu yang datang (permintaan)
  // res = apa yang kita berikan ke tamu (respons)

  if (req.url === '/') {
    res.writeHead(200, { 'Content-Type': 'text/html' });
    res.end('<h1>Selamat Datang di Rumah</h1><p>Ruang Tamu</p>');
  } else if (req.url === '/kamar') {
    res.writeHead(200, { 'Content-Type': 'application/json' });
    res.end(JSON.stringify({ kamar: 3, luas: 120, lantai: 2 }));
  } else {
    res.writeHead(404);
    res.end('Ruangan tidak ditemukan');
  }
});

server.listen(3000, () => {
  console.log('Rumah (server) siap menerima tamu di http://localhost:3000');
});

// 3. Event-driven — seperti sensor rumah yang bereaksi
const EventEmitter = require('events');

class Rumah extends EventEmitter {
  constructor() {
    super();
    this.suhu = 25;
  }

  nyalakanAC(suhuBaru) {
    this.suhu = suhuBaru;
    this.emit('ac-berubah', { suhu: suhuBaru, ruang: 'ruang tamu' });
  }
}

const rumah = new Rumah();
rumah.on('ac-berubah', (data) => {
  console.log(`AC di ${data.ruang} diubah ke ${data.suhu}°C`);
});
rumah.nyalakanAC(18); // "AC di ruang tamu diubah ke 18°C"

// 4. Non-blocking I/O — seperti pipa air yang mengalir tanpa mengganggu aktivitas lain
console.log('Mulai memasak');   // 1
setTimeout(() => {
  console.log('Air mendidih');   // 3 — setelah 1 detik
}, 1000);
console.log('Sambil memotong sayur'); // 2 — langsung jalan, tidak menunggu air mendidih
```

## Analogi
Node.js = **sistem utility rumah** (listrik, pipa, gas, internet). Rumah (aplikasi) butuh sistem yang mengalirkan resource ke seluruh ruangan. Node.js adalah pengelola utility itu: membaca meteran (file system), menerima tamu (HTTP server), mengatur suhu (event-driven). Non-blocking I/O = **pipa air yang tidak berhenti mengalir saat satu keran ditutup**. Di rumah, kamu bisa menyalakan AC, memasak, dan mencuci bersamaan — Node.js melakukan hal yang sama dengan I/O operations. Event loop Node.js = **satpam rumah yang terus memantau siapa yang datang dan pergi** tanpa pernah tidur.

## Kesalahan Umum
1. **Callback hell** — terlalu banyak nested callback. Solusi: Promise, async/await
2. **Mengabaikan error handling** — error di callback tidak tertangani bisa crash server
3. **Blocking event loop** — operasi sinkronus berat (misal: `JSON.parse` besar) memblokir semua request
4. **Tidak memanfaatkan streaming** — membaca file besar sekaligus (buffer penuh) vs streaming per-chunk
5. **Salah paham `require` vs `import`** — Node.js default CommonJS (`require`), tapi mendukung ES Modules (`import`) dengan `"type": "module"` di package.json

## Keterkaitan dengan Materi Sebelumnya
Semua Level sebelumnya adalah fondasi untuk Node.js. Level 1-2 (dasar JS, struktur data) dipakai setiap hari. Level 3 (callback, closure) — event-driven Node.js berbasis callback. Level 5 (async, Promise, event loop) — Node.js adalah implementasi nyata event loop dan non-blocking I/O. Level 7 (module) — CommonJS (`require`) adalah sistem module Node.js yang kamu pelajari. Level 8 (pattern, performa, keamanan) — semua diterapkan di backend Node.js.

## Soal Latihan

Apa output dari kode berikut?

```javascript
console.log('A');
setTimeout(() => console.log('B'), 0);
Promise.resolve().then(() => console.log('C'));
console.log('D');
```

>!`A`, `D`, `C`, `B`. Microtask (Promise.then) dijalankan sebelum macrotask (setTimeout) meskipun timeout 0ms. Ini penting dipahami di Node.js karena memengaruhi urutan eksekusi I/O dan Promise.!
