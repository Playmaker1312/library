# Proxy & Reflect

## Penjelasan
**Proxy** adalah objek yang membungkus (wrap) objek lain dan memungkinkan kita mencegat dan mendefinisikan ulang operasi dasar pada objek tersebut (seperti membaca properti, menulis, menghapus, dll) melalui perangkap (traps).

**Reflect** adalah objek bawaan yang menyediakan method untuk operasi JavaScript yang sama dengan yang dicegat oleh Proxy. Reflect memastikan kita bisa meneruskan perilaku default dengan benar.

## Fungsi
- Mencegat dan mengontrol akses properti objek (validation, logging, caching)
- Membuat properti virtual (properti yang dihitung saat diakses)
- Implementasi reactivity (seperti Vue 3 reactive system)
- Memperluas objek tanpa mengubah struktur aslinya
- Validation dan security wrapper

## Cara Pengimplementasian

```javascript
// PROXY — analogi RUMAH: satpam yang filter semua tamu sebelum masuk rumah
// Satpam bisa mencegat, mencatat, mengizinkan, atau menolak tamu

// Objek rumah kita
const rumah = {
  pemilik: "Budi",
  kamar: 3,
  alamat: "Jl. Merdeka No. 1",
  passwordRahasia: "12345"
};

// Satpam (Proxy) yang menjaga rumah
const satpamRumah = new Proxy(rumah, {
  // Trap saat seseorang ingin MEMBACA properti
  get(target, prop) {
    if (prop === 'passwordRahasia') {
      console.log('[Satpam] Akses password ditolak!');
      return '***TIDAK BOLEH AKSES***';
    }
    if (prop.startsWith('_')) {
      console.log(`[Satpam] Properti ${prop} bersifat internal`);
      return undefined;
    }
    console.log(`[Satpam] Mengakses ${prop}: ${target[prop]}`);
    return target[prop];
  },

  // Trap saat seseorang ingin MENULIS properti
  set(target, prop, value) {
    if (prop === 'kamar' && (value < 1 || value > 100)) {
      console.log(`[Satpam] Jumlah kamar ${value} tidak masuk akal!`);
      return false; // tolak
    }
    console.log(`[Satpam] ${prop} diubah menjadi ${value}`);
    target[prop] = value;
    return true; // izinkan
  },

  // Trap cek apakah properti ada (in operator)
  has(target, prop) {
    if (prop === 'passwordRahasia') {
      return false; // sembunyikan dari pemeriksaan
    }
    return prop in target;
  },

  // Trap saat menghapus properti
  deleteProperty(target, prop) {
    if (prop === 'pemilik') {
      console.log('[Satpam] Tidak bisa menghapus pemilik rumah!');
      return false;
    }
    delete target[prop];
    return true;
  }
});

console.log(satpamRumah.pemilik);       // "[Satpam] Mengakses pemilik: Budi"
console.log(satpamRumah.passwordRahasia); // "[Satpam] Akses password ditolak!"
satpamRumah.kamar = 5;                  // "[Satpam] kamar diubah menjadi 5"
satpamRumah.kamar = 200;                // "[Satpam] Jumlah kamar 200 tidak masuk akal!"
console.log('passwordRahasia' in satpamRumah); // false
delete satpamRumah.pemilik;              // "[Satpam] Tidak bisa menghapus pemilik rumah!"

// REFLECT — seperti meneruskan keputusan ke aturan standar rumah
// Reflect memastikan semua trap punya perilaku default yang benar

const satpamPakaiReflect = new Proxy(rumah, {
  get(target, prop, receiver) {
    if (prop === 'passwordRahasia') return 'DILARANG';
    return Reflect.get(target, prop, receiver); // default behavior via Reflect
  },
  set(target, prop, value, receiver) {
    if (prop === 'kamar' && value < 1) {
      console.log('Minimal 1 kamar');
      return false;
    }
    return Reflect.set(target, prop, value, receiver);
  }
});

// PROXY + REACTIVITY — seperti sensor rumah yang mendeteksi perubahan
function buatReaktif(obj, onChange) {
  return new Proxy(obj, {
    set(target, prop, value, receiver) {
      const old = target[prop];
      const result = Reflect.set(target, prop, value, receiver);
      if (old !== value) {
        onChange(prop, value, old);
      }
      return result;
    }
  });
}

const suhuRumah = buatReaktif({ ruangTamu: 25, kamarTidur: 22 }, (prop, value, old) => {
  console.log(`[Sensor] ${prop} berubah dari ${old}°C ke ${value}°C — AC menyesuaikan`);
});

suhuRumah.ruangTamu = 27; // "[Sensor] ruangTamu berubah dari 25°C ke 27°C — AC menyesuaikan"
```

## Analogi
Proxy = **satpam yang filter semua tamu sebelum masuk rumah**. Setiap tamu (operasi seperti get, set, delete) harus melewati satpam. Satpam bisa:
- Mengizinkan masuk langsung (Reflect.get — jalan seperti biasa)
- Mencatat di buku tamu (logging)
- Menolak tamu tertentu (validation)
- Menyembunyikan ruangan tertentu (properti disembunyikan)
- Memberi informasi palsu (mengubah return value)

Reflect = **buku aturan standar rumah**. Satpam tidak perlu menghafal semua aturan — cukup lihat buku (Reflect) untuk tahu bagaimana perilaku default. `Reflect.get(target, prop)` = "menurut aturan standar, bagaimana cara mengakses properti ini?". Ini memastikan proxy berperilaku konsisten dengan objek normal.

## Dipakai Untuk Apa
- **Reactivity system** — Vue 3 menggunakan Proxy untuk reactive()
- **Validation** — memvalidasi input sebelum properti diubah
- **Logging & debugging** — mencatat semua akses properti
- **Caching / memoization** — menyimpan hasil komputasi properti
- **Revocable references** — akses yang bisa dicabut (Proxy.revocable)
- **API mocking** — proxy untuk testing tanpa implementasi nyata

## Kesalahan Umum
1. **Tidak menggunakan Reflect** — beberapa trap (seperti set) butuh Reflect untuk menjaga `this` binding dan behavior bawaan
2. **Proxy tidak transparan** — objek yang di-proxy tidak sama (===) dengan objek aslinya
3. **Overhead performa** — setiap operasi lewat proxy lebih lambat, jangan proxy-kan dalam loop ketat
4. **Tidak menangani receiver** — receiver penting untuk kasus inheritance dan getter
5. **Proxy tidak bisa di-proxy ulang** — sebenarnya bisa, tapi kompleks dan jarang diperlukan

## Keterkaitan dengan Materi Sebelumnya
Di Level 4, kamu belajar tentang properti descriptor (`Object.defineProperty`) — itu cara "lama" untuk intercept akses properti (getter/setter per properti). Proxy adalah evolusinya: bisa intercept **semua** operasi sekaligus, bukan per properti. Vue 2 menggunakan `Object.defineProperty`, Vue 3 migrasi ke Proxy karena lebih fleksibel. Di Level 8, Observer Pattern juga berkaitan — Proxy bisa menjadi dasar implementasi observer untuk reactivity.

## Soal Latihan

Apa output dari kode berikut?

```javascript
const target = { a: 1 };
const proxy = new Proxy(target, {
  get(t, p) { return p in t ? t[p] : 42; }
});
proxy.b = 2;
console.log(proxy.a);
console.log(proxy.b);
console.log(proxy.c);
console.log(target.b);
```

>!1, 2, 42, 2. `proxy.a` dan `proxy.b` mengembalikan nilai asli. `proxy.c` tidak ada di target, jadi trap get mengembalikan 42. `target.b = 2` karena `proxy.b = 2` diteruskan ke objek asli melalui set default.!
