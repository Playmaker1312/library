### Definisi Singkat
Top-Level Await adalah fitur yang memungkinkan penggunaan `await` di level paling atas modul (tanpa harus di dalam `async function`). Fitur ini hanya berfungsi di **ES Modules** (menggunakan `<script type="module">` di browser atau file `.mjs` / `"type": "module"` di Node.js).

---

### Analogi
Bayangkan kantor tempat setiap pegawai harus minta izin ke supervisor (async function) sebelum pakai mesin fotokopi. **Top-Level Await** seperti memberikan izin permanen ke seluruh lantai — setiap pegawai bisa langsung pakai mesin tanpa minta izin dulu.

---

### Poin-Poin Penting
- Hanya bekerja di **ES Modules** — bukan di script biasa (non-module).
- Modul dengan top-level await akan **menunggu** selesai sebelum modul dependennya dijalankan.
- Membuat kode lebih bersih — tidak perlu wrapper `async function`.
- Berguna untuk inisialisasi modul yang asynchronous (konfigurasi, koneksi DB).
- Fitur ini bisa **memblokir** eksekusi modul lain yang bergantung padanya — gunakan dengan hati-hati.

---

### Contoh Implementasi

```javascript
// config.js
export const config = await fetch('/api/config').then(r => r.json());
// Modul ini akan menunggu fetch selesai sebelum modul lain bisa mengimpornya
```

```javascript
// main.js
import { config } from './config.js';
console.log(config.apiUrl); // config sudah tersedia
```

Inisialisasi database:

```javascript
// db.js
import sqlite from 'sqlite';

export const db = await sqlite.open('./database.sqlite');
// Koneksi DB siap sebelum kode lain jalan
```

Conditional loading:

```javascript
// feature.js
const isEnabled = await checkFeatureFlag('new-ui');
export const ui = isEnabled ? await import('./new-ui.js') : await import('./legacy-ui.js');
```

Error handling dengan try-catch (top-level):

```javascript
try {
  const data = await fetch('/api/init');
  export const initData = await data.json();
} catch (err) {
  console.error('Init failed:', err);
  export const initData = null;
}
```

Fallback value:

```javascript
export const theme = await loadTheme().catch(() => 'light');
// Jika loadTheme gagal, theme = 'light'
```

---

### Koneksi
Top-Level Await melengkapi **async/await** dengan menghilangkan boilerplate wrapper. Module yang menggunakan TLA akan menunggu inisialisasi selesai, mirip dengan konsep **module loader** di Node.js. Setelah ini, lanjut ke **Fetch API** untuk komunikasi HTTP aktual.
