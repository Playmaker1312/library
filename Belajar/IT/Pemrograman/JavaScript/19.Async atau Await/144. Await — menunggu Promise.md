### Definisi Singkat
Kata kunci `await` digunakan di dalam `async function` untuk **menunggu** Promise selesai (fulfilled/rejected). Eksekusi fungsi async akan **pause** pada baris `await` hingga Promise selesai, lalu melanjutkan ke baris berikutnya dengan nilai hasil Promise.

---

### Analogi
Kamu di ATM: kamu masukkan kartu **(mulai async function)**, lalu **tunggu (await)** sampai ATM memproses dan memberikan uang. Selama menunggu, kamu tidak bisa melakukan operasi lain di ATM itu. Tapi ATM lain (kode di luar fungsi) tetap bisa dipakai orang lain.

---

### Poin-Poin Penting
- `await` hanya bisa digunakan di dalam `async function` (kecuali **Top-Level Await** di module).
- `await promise` mengembalikan nilai resolve dari Promise.
- Jika Promise rejected, `await` akan **melempar error** — bisa ditangkap dengan `try-catch`.
- `await` membuat kode async lebih mudah dibaca, mirip synchronous.
- `await` tidak memblokir event loop — hanya menunda eksekusi di fungsi async tersebut.

---

### Contoh Implementasi

```javascript
function delay(ms) {
  return new Promise(resolve => setTimeout(resolve, ms));
}

async function run() {
  console.log('Mulai');
  await delay(2000); // tunggu 2 detik
  console.log('Selesai setelah 2 detik');
}

run();
console.log('Ini jalan duluan, tidak terblokir');
// Output:
// Mulai
// Ini jalan duluan, tidak terblokir
// Selesai setelah 2 detik
```

Mendapatkan nilai dari Promise:

```javascript
function fetchUser(id) {
  return new Promise(resolve => {
    setTimeout(() => resolve({ id, name: 'Andi' }), 1000);
  });
}

async function showUser() {
  const user = await fetchUser(1);
  console.log(user.name); // Andi
  // Kode di bawah menunggu fetchUser selesai
  console.log('Selesai');
}

showUser();
```

Menunggu beberapa Promise secara paralel:

```javascript
async function getDashboard() {
  const [user, posts, comments] = await Promise.all([
    fetch('/api/user'),
    fetch('/api/posts'),
    fetch('/api/comments'),
  ]);
  return { user, posts, comments };
}
```

---

### Koneksi
`await` adalah inti dari async/await — membuat Promise terlihat seperti synchronous. Selanjutnya pelajari **error handling** dengan `try-catch` dan perbandingan **async/await vs Promise chaining**.
