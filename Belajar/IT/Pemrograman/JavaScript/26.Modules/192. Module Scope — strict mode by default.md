### Definisi Singkat
ES Modules berjalan dalam **strict mode** secara otomatis tanpa perlu deklarasi `"use strict"`. Setiap module memiliki **scope sendiri** — variabel yang dideklarasikan di top-level module tidak menjadi properti global (`window`). Module juga di-load secara **deferred** (setelah HTML parsed).

---

### Analogi
Module scope seperti **kamar hotel**. Setiap kamar (module) punya isi sendiri-sendiri. Barang di kamar 101 (`const x = 5`) tidak bisa dilihat dari kamar 102 tanpa `export`/`import`. Dan semua tamu harus mengikuti aturan hotel (strict mode).

---

### Poin-Poin Penting
- **Strict mode otomatis** — tidak perlu `"use strict"`
- **Top-level `this`** adalah `undefined` (bukan `window`)
- Variabel top-level tidak global — tidak bisa diakses via `window.varName`
- Module di-defer secara default — eksekusi setelah HTML parsing
- Multiple `<script type="module">` dijalankan sesuai urutan, tapi masing-masing deferred
- Module hanya dijalankan **satu kali** — hasil di-cache
- `import.meta` — object berisi metadata module (contoh: `import.meta.url`)

---

### Contoh Implementasi

```javascript
// module1.js
const shared = 'rahasia'; // Hanya di scope module ini
export const publicValue = 'bisa diakses';

console.log(this); // undefined (bukan window!)
console.log(import.meta.url); // URL file module ini

// Di browser console
// window.shared // undefined — tidak global

// module2.js
import { publicValue } from './module1.js';

// Coba akses shared — ERROR! Tidak bisa

// Strict mode otomatis berarti:
// - Tidak bisa assign ke undeclared variable
// - `delete` operator untuk properti non-configurable error
// - Duplicate parameter names error
// - `arguments.callee` error
// - Octal literals error
```

```javascript
// Top-level await (module-specific)
// Hanya bekerja di module!
const data = await fetch('/api/config').then(r => r.json());
export const API_KEY = data.key;
```
