### Definisi Singkat
**ES Modules (ESM)** adalah sistem modul resmi JavaScript yang menggunakan keyword **`export`** untuk mengekspos kode dari satu file dan **`import`** untuk menggunakannya di file lain. Setiap file adalah module dengan scope sendiri.

---

### Analogi
ES Modules seperti **perpustakaan**. Setiap buku (file) punya rak sendiri (scope). Kamu bisa meminjam buku (`import`) untuk dibaca, dan rak buku akan mencatat siapa yang meminjam. Buku yang tersedia untuk dipinjam (`export`) sudah diberi label.

---

### Poin-Poin Penting
- Gunakan `<script type="module">` di HTML untuk mengaktifkan
- Setiap file module punya **scope sendiri** — tidak ada global pollution
- **Strict mode** otomatis (tidak perlu `"use strict"`)
- Module hanya dijalankan sekali, hasilnya di-cache
- Import bersifat **hoisted** (diproses sebelum kode lain)
- Path harus relatif (`./`) atau absolut, tidak bisa nama polos
- Module di-load secara **asynchronous**

---

### Contoh Implementasi

```javascript
// math.js
export const PI = 3.14159;
export function tambah(a, b) { return a + b; }
export function kali(a, b) { return a * b; }

// app.js
import { PI, tambah } from './math.js';
console.log(tambah(PI, 2)); // 5.14159

// Import semua
import * as MathUtils from './math.js';
console.log(MathUtils.kali(3, 4)); // 12

// Rename
import { tambah as add } from './math.js';
console.log(add(1, 2)); // 3

// HTML
// <script type="module" src="app.js"></script>
```

```javascript
// Contoh lebih kompleks — import untuk efek samping
import './polyfills.js'; // Jalankan kode tanpa import binding

// Re-export
export { default as Button } from './Button.js';
```
