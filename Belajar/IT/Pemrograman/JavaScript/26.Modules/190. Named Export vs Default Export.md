### Definisi Singkat
**Named export** mengekspor beberapa nilai dengan nama spesifik (wajib kurung kurawal saat import). **Default export** mengekspor satu nilai utama per module (tanpa kurung kurawal, bisa diubah nama). Keduanya bisa digunakan bersamaan dalam satu module.

---

### Analogi
Named export seperti **menu à la carte** — kamu memilih item spesifik: "saya pesan Nasi Goreng dan Es Teh" (`import { nasiGoreng, esTeh }`). Default export seperti **paket hemat** — "saya mau paket nomor 1" (`import Paket1 from`), terserah restoran mau kasih apa.

---

### Poin-Poin Penting

| Aspek | Named Export | Default Export |
|-------|-------------|----------------|
| Keyword | `export function/const` | `export default` |
| Import | `{ name }` | `name` (tanpa `{}`) |
| Jumlah per file | Banyak | Satu |
| Rename | Wajib `as` | Bebas |
| Re-export | `export { name } from` | `export { default } from` |

- Named export bisa inline (`export function`) atau di akhir (`export { a, b }`)
- Default export sering digunakan untuk class/function utama module
- Keduanya bisa digabung: `import React, { useState } from 'react'`

---

### Contoh Implementasi

```javascript
// utils.js
// Named exports
export const version = '1.0';
export function formatDate(date) { /* ... */ }
export const MAX_COUNT = 100;

// Default export
export default class Logger {
  log(msg) { console.log(msg); }
}

// Atau declare dulu, export di akhir
const helper = () => {};
const config = { debug: true };
export { helper, config };
export default config;

// app.js
// Import named
import { version, formatDate, MAX_COUNT } from './utils.js';
import { helper } from './utils.js';

// Import default (nama bebas)
import Logger from './utils.js';
import MyLogger from './utils.js'; // Bisa beda nama

// Gabungan
import Logger, { formatDate, version } from './utils.js';

// Import semua + default
import Logger, * as Utils from './utils.js';
```
