### Definisi Singkat

**Cross-Site Request Forgery (CSRF)** adalah serangan yang memaksa pengguna yang sudah terautentikasi untuk mengeksekusi aksi yang tidak diinginkan (misal: transfer dana, ubah password) di aplikasi web tempat mereka login. Serangan ini memanfaatkan fakta bahwa browser otomatis mengirimkan cookie/credentials.

---

### Analogi

Seperti **seseorang yang menyuruh Anda menjabat tangan orang lain saat tidur** — tangan Anda (browser) bergerak secara otomatis tanpa kendali sadar Anda, dan jabat tangan itu (request) dianggap sah karena Anda adalah Anda (sesi login masih aktif).

---

### Poin-Poin Penting

- CSRF memanfaatkan **same-site request** dan **cookie yang terkirim otomatis**.
- Pencegahan utama:
  - **CSRF Token**: Token unik per sesi yang harus disertakan di setiap request mutasi.
  - **SameSite Cookie**: Set `SameSite=Strict` atau `SameSite=Lax` pada cookie.
  - **Cek Origin/Referer header**: Pastikan request berasal dari domain yang sah.
- Metode GET seharusnya tidak mengubah state (idempotent) — CSRF biasanya memanfaatkan POST/PUT/DELETE.
- Framework modern (Express, Django, Rails) memiliki middleware CSRF built-in.

---

### Contoh Implementasi

```javascript
// Server-side: generate dan validasi CSRF token (Express example)
const crypto = require('crypto');
const csrfTokens = new Map();

function generateToken(sessionId) {
  const token = crypto.randomBytes(32).toString('hex');
  csrfTokens.set(sessionId, token);
  return token;
}

function validateToken(sessionId, token) {
  return csrfTokens.get(sessionId) === token;
}

// Client-side: sertakan token di setiap request
fetch('/api/transfer', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    toAccount: '12345',
    amount: 1000,
    _csrf: csrfToken // Token dari server
  }),
  credentials: 'include'
});
```

---

### Koneksi

Berkaitan dengan **CORS** (mengontrol akses cross-origin), **XSS** (XSS bisa mencuri CSRF token), **HTTPS** (mencegah token dicuri via network), dan **Cookie security** (SameSite, HttpOnly, Secure flags).
