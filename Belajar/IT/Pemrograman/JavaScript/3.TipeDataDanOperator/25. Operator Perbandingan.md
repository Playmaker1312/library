### Definisi Singkat

Operator perbandingan adalah simbol di dalam JavaScript yang digunakan untuk membandingkan dua nilai dan menghasilkan nilai _Boolean_ (`true` atau `false`) sebagai hasilnya.

---

### Analogi

Bayangkan seperti **proses pemeriksaan oleh penjaga keamanan pintu masuk bioskop**:

- Penjaga membandingkan umur Anda dengan batas umur yang diizinkan (misalnya: "Apakah umur Anda >=17?").
    
- Jika umur Anda memenuhi syarat, hasilnya true (diizinkan masuk). Jika tidak, hasilnya false (dilarang masuk).
    

---

### Poin-Poin Penting

- **Daftar Operator Perbandingan:**
    
    - **Lebih dari (`>`):** Bernilai `true` jika nilai kiri lebih besar dari nilai kanan.
        
    - **Kurang dari (`<`):** Bernilai `true` jika nilai kiri lebih kecil dari nilai kanan.
        
    - **Lebih dari atau sama dengan (`>=`):** Bernilai `true` jika nilai kiri lebih besar atau sama dengan nilai kanan.
        
    - **Kurang dari atau sama dengan (`<=`):** Bernilai `true` jika nilai kiri lebih kecil atau sama dengan nilai kanan.
        
    - **Sama dengan longgar (`==`):** Membandingkan nilai, tetapi mengabaikan tipe datanya (melakukan _type coercion_).
        
    - **Sama dengan ketat (`===`):** Membandingkan nilai sekaligus tipe datanya. Dianjurkan sebagai praktik terbaik (_best practice_).
        
    - **Tidak sama dengan longgar (`!=`):** Bernilai `true` jika kedua nilai tidak sama.
        
    - **Tidak sama dengan ketat (`!==`):** Bernilai `true` jika kedua nilai atau tipe datanya tidak sama.
        

---

### Contoh Implementasi

Berikut adalah contoh penggunaan berbagai operator perbandingan di dalam JavaScript:

JavaScript

```
let nilaiUjian = 80;
let batasKelulusan = 75;

// 1. Perbandingan lebih dari
let lulus = nilaiUjian > batasKelulusan;
console.log(lulus); // Output: true

// 2. Perbandingan sama dengan (Strict vs Loose)
console.log(5 == "5");  // Output: true (karena tipe data diabaikan)
console.log(5 === "5"); // Output: false (tipe data number dan string tidak sama)

// 3. Perbandingan tidak sama dengan ketat (!==)
let username = "admin";
console.log(username !== "user"); // Output: true
```

### Koneksi

Dalam bidang **Web Development**, operator perbandingan sangat penting untuk mengatur logika antarmuka dan keamanan aplikasi Anda:

- **Autentikasi Pengguna:** Membandingkan apakah _password_ atau _username_ yang dimasukkan pengguna cocok dengan data di _database_.
    
- **Tampilan Bersyarat (_Conditional Rendering_):** Menampilkan tombol atau pesan peringatan jika saldo pengguna tidak mencukupi (misalnya `saldo < totalHarga`).
    
- **Paginasi Halaman:** Memeriksa apakah pengguna sudah berada di halaman terakhir saat menjelajahi daftar produk.
