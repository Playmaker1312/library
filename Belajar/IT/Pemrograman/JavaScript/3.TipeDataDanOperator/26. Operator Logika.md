### Definisi Singkat

Operator logika adalah simbol di dalam JavaScript yang digunakan untuk menggabungkan atau membalikkan dua atau lebih kondisi (ekspresi Boolean) dan menghasilkan nilai kebenaran (_true_ atau _false_).

---

### Analogi

Bayangkan Anda sedang mendaftar sebagai anggota di sebuah klub eksklusif yang memiliki aturan ketat:

- **Operator AND (`&&`)**: Anggaplah seperti syarat $\rightarrow$ "Anda harus memiliki kartu anggota **DAN** Anda harus berpakaian rapi". Jika Anda memenuhi syarat pertama tetapi tidak memenuhi syarat kedua, Anda tidak akan diizinkan masuk.
    
- **Operator OR (`||`)**: Anggaplah seperti syarat $\rightarrow$ "Anda boleh masuk jika Anda memiliki kartu anggota **ATAU** jika Anda diundang oleh salah satu pendiri". Anda cukup memenuhi salah satu dari dua syarat tersebut.
    
- **Operator NOT (`!`)**: Anggaplah seperti **tombol pembalik**: jika Anda bukan anggota ($false$), ditekan tombol NOT menjadi anggota ($true$).
    

---

### Poin-Poin Penting

- **Daftar Operator Logika:**
    
    - **Logical AND (`&&`):** Menghasilkan `true` **hanya jika kedua kondisi bernilai benar**. Jika salah satu kondisi salah, hasilnya adalah `false`.
        
    - **Logical OR (`||`):** Menghasilkan `true` **jika salah satu atau kedua kondisi bernilai benar**. Hanya bernilai `false` jika kedua kondisi salah.
        
    - **Logical NOT (`!`):** Membalikkan nilai Boolean dari sebuah kondisi. Jika kondisi bernilai `true`, maka `!true` menjadi `false`, dan sebaliknya.
        
- **Evaluasi Singkat (_Short-circuit Evaluation_):**
    
    - Pada operator `&&`, jika kondisi pertama bernilai salah, JavaScript tidak akan memeriksa kondisi kedua karena hasilnya sudah pasti salah.
        
    - Pada operator `||`, jika kondisi pertama bernilai benar, JavaScript tidak akan memeriksa kondisi kedua.
        

---

### Contoh Implementasi

Berikut adalah contoh penggunaan operator logika di dalam JavaScript:

JavaScript

```
// 1. Logika AND (&&)
// Memeriksa apakah pengguna sudah login DAN memiliki hak akses admin
let sudahLogin = true;
let isAdmin = false;
let aksesDiberikan = sudahLogin && isAdmin;
console.log(aksesDiberikan); // Output: false

// 2. Logika OR (||)
// Memeriksa apakah pengguna bisa menggunakan kupon diskon ATAU saldo poin
let punyaKupon = false;
let punyaPoin = true;
let bisaDiskon = punyaKupon || punyaPoin;
console.log(bisaDiskon); // Output: true

// 3. Logika NOT (!)
let statusHujan = true;
let statusBajuKering = !statusHujan;
console.log(statusBajuKering); // Output: false
```

---

### Koneksi

Dalam bidang **Web Development**, operator logika sangat penting untuk mengatur keamanan dan alur aplikasi:

- **Autentikasi & Otorisasi:** Menggunakan operator `&&` untuk memastikan bahwa pengguna telah masuk dan memiliki peran yang tepat untuk mengakses halaman tertentu.
    
- **Nilai Default (_Fallback Values_):** Menggunakan operator `||` sebelum sintaks modern (`??`) diperkenalkan untuk memberikan nilai _fallback_ (cadangan) jika suatu data dari API kosong.
    
- **Penyembunyian Komponen UI:** Menentukan kapan sebuah pesan kesalahan atau tombol konfirmasi harus ditampilkan kepada pengguna.
