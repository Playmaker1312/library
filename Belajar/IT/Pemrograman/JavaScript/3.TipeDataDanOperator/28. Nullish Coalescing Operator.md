

### Definisi Singkat

_Nullish Coalescing Operator_ (dilambangkan dengan simbol `??`) adalah operator logika di dalam JavaScript yang mengembalikan nilai di sebelah kanannya hanya jika nilai di sebelah kirinya bernilai `null` atau `undefined`.

---

### Analogi

Bayangkan seperti **sistem pasokan air cadangan (toren air)** di rumah Anda:

- Jika pasokan air utama Anda memiliki air yang mengalir (meskipun airnya kecil atau keruh), Anda akan menggunakan air utama tersebut.
    
- Namun, jika keran utama benar-benar **kering (null atau undefined)**, sistem akan secara otomatis mengalihkan sumber air ke toren cadangan (nilai di sisi kanan).
    

---

### Poin-Poin Penting

- **Sintaks Dasar:**
    
    $$\text{nilaiAwal} \text{ ?? } \text{nilaiCadangan}$$
    
- **Perbedaan dengan Logical OR (`||`):**
    
    - `||` menganggap semua _falsy value_ (seperti `0`, `""` string kosong, atau `false`) sebagai kondisi yang gagal, sehingga akan mengembalikan nilai cadangan.
        
    - `??` **hanya bereaksi terhadap kondisi _nullish_**, yaitu `null` dan `undefined`. Nilai seperti angka `0` atau string kosong `""` akan tetap dianggap sebagai nilai yang sah dan dikembalikan.
        
- **Manfaat:** Sangat berguna untuk memberikan nilai _default_ (cadangan) yang aman pada variabel tanpa membuang angka $0$ atau string kosong yang valid.
    

---

### Contoh Implementasi

Untuk memahami perbedaannya dengan operator `||`, perhatikan contoh berikut:

JavaScript

```
// 1. Menggunakan Nullish Coalescing (??)
let jumlahPengguna = 0; // Nilai ini sah (bukan null atau undefined)
let tampilanPengguna = jumlahPengguna ?? "Data tidak tersedia";

console.log(tampilanPengguna); // Output: 0


// 2. Jika dibandingkan dengan Logical OR (||)
let statusPoin = 0; // Dianggap falsy oleh operator OR
let totalSkor = statusPoin || 100;

console.log(totalSkor); // Output: 100 (Bukan 0, karena OR menolak nilai 0)


// 3. Menggunakan Nullish Coalescing dengan nilai null atau undefined
let namaPengguna = null;
let namaTampilan = namaPengguna ?? "Tamu";

console.log(namaTampilan); // Output: Tamu
```

---

### Koneksi

Dalam bidang **Web Development**, operator _Nullish Coalescing_ sangat membantu dalam menangani data saat mengambil informasi dari API:

- **Pengaturan Nilai Default:** Memberikan nilai awal pada formulir (_input_) jika data dari _server_ belum terisi atau masih `null`.
    
- **Mencegah Bug pada Angka 0:** Memastikan bahwa nilai seperti angka $0$ atau string kosong `""` (yang mungkin merupakan data yang benar dari pengguna) tetap ditampilkan di halaman web dan tidak tertimpa oleh nilai _default_.
