### Definisi Singkat

**Garbage Collection (GC)** adalah proses otomatis mengelola alokasi dan dealokasi memori di JavaScript engine. **Mark-and-Sweep** adalah algoritma GC utama: engine menandai (mark) objek yang masih **terjangkau** (reachable) dari root, lalu menyapu (sweep) objek yang tidak terjangkau.

---

### Analogi

Seperti **petugas kebersihan di gedung** — ia berjalan dari pintu utama (root) dan menandai semua ruangan yang masih dipakai (mark). Setelah selesai, ia membuang semua barang di ruangan yang tidak ditandai (sweep). Tamu yang sudah check-out, barangnya otomatis dibersihkan.

---

### Poin-Poin Penting

- **Root references**: Global object, DOM elements, local variables di stack — semuanya dianggap "hidup".
- **Mark phase**: Traversal graf dari root → tandai semua objek yang bisa dijangkau.
- **Sweep phase**: Hapus objek tidak bertanda → kembalikan memori ke free list.
- **Generational GC**: Objek baru (young generation) dikumpulkan lebih sering daripada objek lama (old generation) — mayoritas objek mati muda.
- **Stop-the-world**: GC lama bisa menghentikan eksekusi program — V8 menggunakan **incremental & concurrent GC** untuk mengurangi pause.
- **Memory leaks** terjadi ketika objek tetap dirujuk (reachable) padahal tidak digunakan lagi.

---

### Contoh Implementasi

```javascript
// Objek menjadi eligible untuk GC ketika tidak ada referensi lagi
let user = { name: 'Budi', age: 25 };
user = null; // Objek {name: 'Budi', ...} bisa di-GC

// Circular reference — bukan masalah untuk Mark-and-Sweep
function createCircular() {
  const a = {};
  const b = { ref: a };
  a.ref = b;
  return 'done';
}
// Ketika function selesai, a dan b tidak reachable dari root → di-GC

// Memory leak — referensi yang tidak sengaja dipertahankan
const cache = [];
function addToCache(data) {
  cache.push(data); // Terus bertambah — potensi leak
}

// WeakMap — tidak mencegah GC
const wm = new WeakMap();
let obj = { id: 1 };
wm.set(obj, 'metadata');
obj = null; // Entry di WeakMap otomatis dihapus oleh GC
```
