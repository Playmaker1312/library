### Definisi Singkat

**V8 Engine** adalah JavaScript engine open-source yang dikembangkan oleh Google, ditulis dalam C++. V8 digunakan di **Google Chrome**, **Node.js**, **Deno**, dan **Electron**. Arsitektur V8 terdiri dari beberapa komponen utama: parser, interpreter (Ignition), compiler (TurboFan), dan garbage collector (Orinoco).

---

### Analogi

Seperti **pabrik pengolahan** — bahan mentah (source code JavaScript) masuk, melewati berbagai stasiun: pemotongan (parser/pemotong token), perakitan manual (interpreter/Ignition), dan terakhir mesin otomatis (compiler/TurboFan) untuk produksi massal.

---

### Poin-Poin Penting

- **Parser**: Mengubah source code menjadi **AST** (Abstract Syntax Tree).
- **Ignition (Interpreter)**: Menjalankan bytecode dengan cepat — startup cepat.
- **TurboFan (Compiler)**: Mengubah bytecode menjadi **machine code** yang sangat dioptimalkan.
- **Orinoco (Garbage Collector)**: Mengelola memori dengan algoritma **Mark-Compact + generational**.
- **Hidden Classes**: V8 mengoptimalkan akses properti objek.
- **Inline Caching**: V8 "mengingat" tipe objek untuk akses properti yang lebih cepat.
- Proses JIT: interpreter → profiling → compiler → optimized code → deoptimization jika perlu.

### Contoh Implementasi

```javascript
// V8 optimization tricks (dulu — sekarang sudah otomatis)

// 1. Hindari perubahan tipe properti — V8 membuat hidden class berbeda
function Point(x, y) {
  this.x = x; // Hidden Class: Point
  this.y = y;
}

const p1 = new Point(1, 2);
const p2 = new Point(3, 4);
// Keduanya punya hidden class SAMA → optimal

// 2. Inisialisasi properti di constructor — bukan ditambahkan kemudian
function User(name) {
  this.name = name;
  // this.age = undefined; // Lebih baik declare semua
}

// 3. Gunakan monomorphic function calls (argumen selalu tipe sama)
function add(a, b) { return a + b; }
add(1, 2); // Semua number → V8 optimal
add(3, 4);
// add("a", "b"); // Polymorphic → slow
```
