### Definisi Singkat

**Vue.js** adalah progressive framework JavaScript untuk membangun UI. Dikembangkan oleh Evan You. Konsep inti: **template syntax** (HTML-based), **reactive data** (sistem reaktivitas otomatis), **components**, dan **Composition API** (setup function).

---

### Analogi

Seperti **rumah modular** yang bisa dibangun secara bertahap — Anda mulai dengan satu ruangan (komponen kecil), lalu menambahkan ruangan lain (komponen baru). Semua pintu dan jendela (binding) otomatis terhubung ke sistem listrik (reaktivitas).

---

### Poin-Poin Penting

- **Reactive system**: Data otomatis sinkron dengan DOM — cukup ubah data, UI menyesuaikan.
- **Template**: HTML dengan direktif khusus (`v-if`, `v-for`, `v-bind`, `v-model`).
- **Options API** vs **Composition API**: Options (data, methods, computed, watch) vs Composition (setup dengan ref/reactive).
- **Single File Component (SFC)**: `.vue` file berisi `<template>`, `<script>`, `<style>`.
- **Directives**: `v-if` (kondisi), `v-for` (loop), `v-model` (two-way binding).
- **Computed properties**: Nilai turunan yang di-cache secara reaktif.

---

### Contoh Implementasi

```vue
<script setup>
import { ref, computed } from 'vue';

const nama = ref('Dunia');
const counter = ref(0);
const doubled = computed(() => counter.value * 2);

function increment() {
  counter.value++;
}
</script>

<template>
  <div>
    <h1>Halo {{ nama }}!</h1>
    <p>Counter: {{ counter }}</p>
    <p>Dua kali lipat: {{ doubled }}</p>
    <button @click="increment">Tambah</button>

    <input v-model="nama" placeholder="Ganti nama" />
  </div>
</template>
```

---

### Koneksi

Berkaitan dengan **React** (sama-sama komponen-based, beda pendekatan reaktivitas), **Svelte** (sama-sama reaktif, Svelte tanpa virtual DOM), **Angular** (template syntax mirip, Angular lebih berat), dan **Nuxt.js** (Vue framework untuk SSR/SSG).
