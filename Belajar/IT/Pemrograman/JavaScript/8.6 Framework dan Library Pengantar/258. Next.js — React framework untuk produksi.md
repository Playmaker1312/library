### Definisi Singkat

**Next.js** adalah framework React untuk produksi yang menyediakan **server-side rendering (SSR)**, **static site generation (SSG)**, **API routes**, dan **file-based routing**. Dikembangkan oleh Vercel, Next.js mengatasi keterbatasan React SPA (Single Page Application) seperti SEO buruk dan initial load lambat.

---

### Analogy

Seperti **katering profesional** — React hanya menyediakan bahan makanan (library UI), Next.js adalah **katering lengkap** yang menyiapkan, memasak, mengemas, dan mengantarkan makanan siap saji (SEO-friendly, routing, API, optimasi gambar, dll).

---

### Poin-Poin Penting

- **File-based Routing**: File di folder `pages/` atau `app/` otomatis menjadi route.
- **SSR**: Halaman di-render di server per request — cocok untuk konten dinamis dan SEO.
- **SSG**: Halaman di-render saat build — super cepat, cocok untuk blog/docs.
- **ISR (Incremental Static Regeneration)**: Gabungan SSG + update berkala tanpa rebuild.
- **API Routes**: Backend API langsung di dalam proyek Next.js (`pages/api/`).
- **Image Optimization**: Komponen `next/image` untuk optimasi gambar otomatis.
- **App Router** (Next.js 13+): Arsitektur baru berbasis React Server Components.
- **Middleware**: Jalankan kode sebelum request selesai (redirect, rewrite, auth).

### Contoh Implementasi

```javascript
// app/page.js — App Router (Next.js 13+)
async function getData() {
  const res = await fetch('https://api.example.com/posts');
  return res.json();
}

export default async function HomePage() {
  const posts = await getData();

  return (
    <div>
      <h1>Blog Saya</h1>
      {posts.map(post => (
        <article key={post.id}>
          <h2>{post.title}</h2>
          <p>{post.body}</p>
        </article>
      ))}
    </div>
  );
}

// pages/api/hello.js — API Route
export default function handler(req, res) {
  res.status(200).json({ message: 'Halo dari Next.js API!' });
}

// next.config.js — Konfigurasi
module.exports = {
  images: {
    domains: ['images.example.com'],
  },
};
```

### Koneksi

Berkaitan dengan **React** (Next.js dibangun di atas React), **SSR/SSG** (konsep rendering), **Node.js** (server-side), **Vercel** (platform deployment), dan **PWA** (bisa diintegrasikan dengan next-pwa).
