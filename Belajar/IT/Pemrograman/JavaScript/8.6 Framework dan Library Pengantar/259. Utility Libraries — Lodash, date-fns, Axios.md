### Definisi Singkat

**Utility Libraries** adalah paket kode siap pakai yang menyelesaikan masalah umum pemrograman sehingga pengembang tidak perlu menulis ulang (reinvent the wheel). Tiga yang paling populer di ekosistem JavaScript: **Lodash** (manipulasi data), **date-fns** (format tanggal), dan **Axios** (HTTP requests).

---

### Analogi

Seperti **toolkit** — Anda bisa membuat kursi dari bahan mentah (native JavaScript), tetapi memiliki gergaji (Lodash), meteran (date-fns), dan obeng (Axios) membuat pekerjaan jauh lebih cepat dan konsisten.

---

### Poin-Poin Penting

- **Lodash**: Fungsi utilitas untuk array, objek, string — `_.debounce`, `_.throttle`, `_.deepClone`, `_.merge`. Dulu penting, sekarang banyak fungsi sudah native (ES6+).
- **date-fns**: Manipulasi tanggal **modular** — `format()`, `addDays()`, `differenceInHours()`; lebih modern daripada Moment.js (legacy).
- **Axios**: HTTP client berbasis Promise — support interceptor, cancel request, timeout, transform data, dan upload progress, API lebih bersih daripada `fetch` untuk kasus tertentu.
- Pertimbangan: ukuran bundle (Lodash besar jika full import), gunakan import spesifik (`import debounce from 'lodash/debounce'`).

---

### Contoh Implementasi

```javascript
import debounce from 'lodash/debounce';
import { format, addDays, differenceInDays } from 'date-fns';
import axios from 'axios';

// Lodash — debounce
const searchApi = debounce(async (query) => {
  const results = await axios.get(`/api/search?q=${query}`);
  console.log(results.data);
}, 300);

// date-fns — format dan manipulasi
const today = new Date();
console.log(format(today, 'dd MMMM yyyy')); // "22 Mei 2026"
console.log(format(addDays(today, 7), 'EEEE')); // "Jumat"
console.log(differenceInDays(new Date('2026-06-01'), today)); // 10 hari

// Axios — HTTP dengan interceptor
const api = axios.create({
  baseURL: 'https://api.example.com',
  timeout: 5000,
  headers: { Authorization: `Bearer ${token}` }
});

// Interceptor — logging otomatis
api.interceptors.response.use(
  (response) => response,
  (error) => {
    console.error('API Error:', error.response?.status);
    return Promise.reject(error);
  }
);

async function getUser(id) {
  const { data } = await api.get(`/users/${id}`);
  return data;
}
```

---

### Koneksi

Berkaitan dengan **Node.js** (Axios di server maupun client), **React/Vue** (Axios sering dipakai untuk fetching data), **Performance** (Lodash debounce/throttle), **Package.json** (manajemen dependensi), dan **npm registry** (sumber utility libraries).
