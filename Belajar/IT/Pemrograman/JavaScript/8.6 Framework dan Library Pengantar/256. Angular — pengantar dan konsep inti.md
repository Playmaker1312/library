### Definisi Singkat

**Angular** adalah platform dan framework pengembangan aplikasi web berbasis TypeScript yang dikembangkan oleh Google. Konsep inti: **modules** (NgModules), **components**, **templates**, **dependency injection (DI)**, dan **services**. Angular adalah full-fledged framework (bukan library) yang menyediakan solusi end-to-end.

---

### Analogi

Seperti **gedung perkantoran lengkap** — bukan hanya ruangan (komponen), tetapi juga sistem kelistrikan (DI), plumbing (routing), security (guard), dan resepsionis (HTTP client). Semua sudah terintegrasi sejak awal pembangunan.

---

### Poin-Poin Penting

- **Modules** (`@NgModule`): Mengelompokkan komponen, directives, pipes, dan services.
- **Components** (`@Component`): Unit UI dasar dengan template, styles, dan logic.
- **Templates**: HTML dengan Angular syntax (`*ngIf`, `*ngFor`, `{{ }}` interpolation, `[(ngModel)]`).
- **Dependency Injection**: Services didaftarkan di provider dan di-inject ke constructor.
- **RxJS**: Angular sangat bergantung pada Observable untuk async operations.
- **TypeScript wajib** — Angular dibangun dengan dan untuk TypeScript.
- **CLI** (`ng generate`, `ng serve`, `ng build`) — tool resmi untuk scaffolding.

---

### Contoh Implementasi

```typescript
// app.module.ts
@NgModule({
  declarations: [AppComponent, GreetingComponent],
  imports: [BrowserModule, FormsModule],
  providers: [DataService],
  bootstrap: [AppComponent]
})
export class AppModule {}

// greeting.component.ts
@Component({
  selector: 'app-greeting',
  template: `
    <h1>Halo, {{ name }}!</h1>
    <input [(ngModel)]="name" placeholder="Masukkan nama">
    <button (click)="sayHello()">Sapa</button>
  `
})
export class GreetingComponent {
  name = 'Dunia';

  constructor(private dataService: DataService) {}

  sayHello() {
    this.dataService.log(`Halo ${this.name}`);
  }
}

// data.service.ts
@Injectable({ providedIn: 'root' })
export class DataService {
  log(message: string) {
    console.log(message);
  }
}
```

### Koneksi

Berkaitan dengan **React & Vue** (alternatif framework), **RxJS** (Angular menggunakan Observable secara intensif), **TypeScript** (Angular mewajibkannya), dan **Node.js** (Angular CLI dan server-side rendering via Angular Universal).
