# 1. Apa itu JavaScript & Di Mana Ia Berjalan

## Penjelasan
JavaScript adalah bahasa pemrograman tingkat tinggi yang awalnya dibuat untuk membuat halaman web menjadi interaktif. Saat ini, JavaScript tidak hanya berjalan di browser, tetapi juga di server (Node.js), desktop (Electron), bahkan di perangkat IoT. JavaScript adalah salah satu fondasi utama pengembangan web bersama HTML dan CSS. Jika HTML adalah struktur rumah dan CSS adalah cat/warna rumah, maka JavaScript adalah semua peralatan listrik dan perangkat pintar yang membuat rumah bisa merespon perintah.

## Fungsi
JavaScript berfungsi untuk memberikan "nyawa" pada halaman web — membuat elemen bisa diklik, form bisa divalidasi, konten bisa berubah tanpa reload halaman, serta berkomunikasi dengan server secara asinkron. Tanpa JavaScript, halaman web hanya akan menjadi dokumen statis yang tidak bisa berinteraksi dengan pengguna.

## Cara Pengimplementasian
JavaScript dapat ditulis langsung di dalam file HTML menggunakan tag `<script>`, atau di file terpisah berekstensi `.js`. Kode sederhana yang bisa kamu coba:

```js
alert("Selamat datang di rumah JavaScript!");
console.log("Rumah sudah siap ditempati.");
```

## Analogi
Bayangkan JavaScript sebagai **jaringan listrik dan sistem pintar di sebuah rumah**. HTML adalah struktur rumah (tembok, atap, lantai), CSS adalah dekorasi dan cat, sedangkan JavaScript adalah semua yang membuat rumah responsive: saklar lampu, sensor pintu otomatis, termostat pintar, dan bel rumah. Tanpa JavaScript, rumah memang berdiri dan terlihat bagus, tapi tidak bisa melakukan apa-apa. Dengan JavaScript, rumah bisa bereaksi terhadap apa yang dilakukan penghuninya.

## Dipakai Untuk Apa
JavaScript digunakan di hampir semua website modern — dari tombol like di media sosial, validasi form pendaftaran, animasi halaman, hingga aplikasi berat seperti Google Docs, Figma, dan VS Code (yang dibangun dengan Electron — framework berbasis JavaScript). Di sisi server, JavaScript dipakai untuk membangun API, aplikasi real-time seperti chat, dan banyak lagi.

## Kesalahan Umum
Pemula sering mengira JavaScript sama dengan Java. Padahal keduanya berbeda total — seperti rumah dan rumah sakit, namanya mirip tapi fungsi dan isinya sangat berbeda. Kesalahan lain adalah tidak memahami bahwa JavaScript berjalan di sisi klien (browser pengguna), sehingga kode JavaScript bisa dilihat oleh pengguna melalui DevTools.

## Keterkaitan dengan Materi Sebelumnya
Ini adalah materi pertama dan menjadi fondasi untuk semua materi selanjutnya. Sebelum mempelajari variabel, tipe data, operator, dan konsep lainnya, kamu harus paham dulu apa itu JavaScript dan apa yang bisa dilakukan dengannya.
