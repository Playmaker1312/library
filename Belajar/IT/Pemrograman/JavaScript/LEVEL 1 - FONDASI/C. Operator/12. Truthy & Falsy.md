# 12. Truthy & Falsy

## Penjelasan
Truthy dan falsy adalah konsep bagaimana JavaScript mengevaluasi suatu nilai sebagai boolean (`true` atau `false`) dalam konteks boolean (seperti di kondisi `if`). Nilai **falsy** hanya ada 6: `false`, `0`, `""` (string kosong), `null`, `undefined`, dan `NaN`. Semua nilai lain di JavaScript dianggap **truthy** — termasuk `"0"` (string nol), `[]` (array kosong), `{}` (object kosong), dan `"false"` (string "false").

## Fungsi
Konsep truthy/falsy memungkinkan penulisan kode yang lebih ringkas dan ekspresif. Alih-alih menulis `if (nama !== null && nama !== undefined && nama !== "")`, kamu cukup menulis `if (nama)`. Ini adalah fondasi penting untuk memahami short-circuit evaluation pada operator logika dan untuk menulis kode yang lebih bersih.

## Cara Pengimplementasian
```js
// 6 nilai falsy
console.log(Boolean(false));     // false
console.log(Boolean(0));         // false
console.log(Boolean(""));        // false
console.log(Boolean(null));      // false
console.log(Boolean(undefined)); // false
console.log(Boolean(NaN));       // false

// Contoh truthy
console.log(Boolean("Rumah"));   // true
console.log(Boolean(1));         // true
console.log(Boolean(-1));        // true
console.log(Boolean([]));        // true (array kosong)
console.log(Boolean({}));        // true (object kosong)
console.log(Boolean("false"));   // true (string, bukan boolean)
console.log(Boolean("0"));       // true (string, bukan angka 0)

// Penggunaan praktis
const namaPenghuni = "";
if (namaPenghuni) {
  console.log(`Penghuni: ${namaPenghuni}`);
} else {
  console.log("Tidak ada penghuni"); // Ini yang jalan
}

// Memberi nilai default
const input = "";
const namaRumah = input || "Rumah Baru";
console.log(namaRumah); // "Rumah Baru"
```

## Analogi
Truthy dan falsy seperti **mengecek apakah suatu ruangan di rumah dianggap "berisi" atau "kosong"**:
- Falsy = kamar yang benar-benar kosong tanpa perabot (`false`), kamar dengan luas 0 meter (`0`), papan nama tanpa tulisan (`""`), kamar yang belum dibangun (`null`), kamar yang tidak ada dalam denah (`undefined`), ukuran yang tidak terdefinisi (`NaN`)
- Truthy = kamar dengan perabot (`{}`), kamar dengan daftar barang (`[]`), papan nama bertuliskan "0" (`"0"`), kamar yang berserakan (`"false"`)
- Penting: kamar kosong (`[]`) dan kamar dengan catatan kosong (`{}`) dianggap "berisi" (truthy) meskipun tidak ada isinya

## Dipakai Untuk Apa
Digunakan untuk validasi input form (`if (username)` — cek apakah username diisi), memberikan nilai default (`const warna = userPilihan || "Putih"`), pengecekan data dari API (`if (data)` — apakah data ada), dan menulis kondisi yang lebih ringkas di seluruh aplikasi.

## Kesalahan Umum
Kesalahan paling umum adalah mengira string `"false"` bernilai falsy — padahal truthy! Juga mengira array kosong `[]` dan object kosong `{}` adalah falsy — padahal keduanya truthy. Ini sering menyebabkan bug yang sulit dilacak. Contoh: `if ([])` akan selalu true meskipun array-nya kosong. Gunakan `array.length` untuk mengecek array kosong, bukan array itu sendiri.

## Keterkaitan dengan Materi Sebelumnya
Materi ini adalah puncak dari Level 1 — semua konsep sebelumnya (variabel, tipe data, string, coercion, operator aritmatika, perbandingan, dan logika) bersatu di sini. Truthy/falsy adalah "bahasa yang digunakan" oleh operator logika (materi 11) untuk melakukan short-circuit evaluation. Ini juga menjadi fondasi untuk materi selanjutnya seperti if/else, ternary operator, dan loop.

## Soal Latihan
Manakah dari nilai berikut yang bersifat falsy di JavaScript?
A. `0`
B. `"false"`
C. `[]`
D. `null`
E. `undefined`

<details>
<summary>Jawaban</summary>
A (`0`), D (`null`), dan E (`undefined`) adalah falsy. B (`"false"`) dan C (`[]`) adalah truthy.
</details>
