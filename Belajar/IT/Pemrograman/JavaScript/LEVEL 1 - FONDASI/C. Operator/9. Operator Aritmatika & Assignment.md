# 9. Operator Aritmatika & Assignment

## Penjelasan
Operator aritmatika digunakan untuk melakukan perhitungan matematika: `+` (penjumlahan), `-` (pengurangan), `*` (perkalian), `/` (pembagian), `%` (modulus/sisa bagi), `**` (eksponen/pangkat), `++` (increment), dan `--` (decrement). Operator assignment digunakan untuk menetapkan nilai ke variabel: `=`, `+=`, `-=`, `*=`, `/=`, dan lainnya. Kombinasi keduanya memungkinkan kamu melakukan perhitungan sekaligus menyimpan hasilnya.

## Fungsi
Operator aritmatita memungkinkan program melakukan kalkulasi matematika — menghitung total harga, luas ruangan, diskon, rata-rata nilai, dll. Operator assignment memudahkan perubahan nilai variabel tanpa mengulang nama variabel — misalnya `total += 10` lebih ringkas dari `total = total + 10`.

## Cara Pengimplementasian
```js
// Operator Aritmatika
const panjang = 10;
const lebar = 5;
const luas = panjang * lebar;
console.log(`Luas rumah: ${luas} m²`); // 50

console.log(10 + 3);  // 13
console.log(10 - 3);  // 7
console.log(10 * 3);  // 30
console.log(10 / 3);  // 3.333...
console.log(10 % 3);  // 1 (sisa bagi)
console.log(10 ** 3); // 1000 (10 pangkat 3)

let counter = 0;
counter++; // 1
counter++; // 2
counter--; // 1

// Operator Assignment
let totalBelanja = 0;
totalBelanja += 500000; // totalBelanja = totalBelanja + 500000
totalBelanja -= 100000; // totalBelanja = totalBelanja - 100000
console.log(totalBelanja); // 400000
```

## Analogi
Operator aritmatika adalah **alat ukur dan kalkulasi di rumah**:
- `+` = menggabungkan panjang dua ruangan
- `-` = mengurangi luas karena ada kamar mandi
- `*` = menghitung luas total dari panjang x lebar
- `/` = membagi tanah warisan
- `%` = sisa uang belanja setelah membeli perabot
- `**` = menghitung volume kubik ruangan

Operator assignment seperti **mengisi dan mengambil barang dari gudang**: `+=` seperti menambah stok, `-=` seperti mengeluarkan stok.

## Dipakai Untuk Apa
Digunakan untuk menghitung total belanja di e-commerce, menghitung dimensi/gambar di aplikasi desain, membuat animasi (increment posisi), menghitung skor game, mengolah data keuangan, dan semua aplikasi yang butuh perhitungan matematika.

## Kesalahan Umum
Kesalahan umum adalah lupa bahwa `+` pada string akan melakukan concatenation, bukan penjumlahan. Contoh: `"10" + 5` hasilnya `"105"`. Juga sering lupa bahwa increment `counter++` dan `++counter` berbeda — post-increment mengembalikan nilai lama dulu, pre-increment mengembalikan nilai setelah ditambah. Hindari mencampur increment dalam ekspresi kompleks.

## Keterkaitan dengan Materi Sebelumnya
Setelah memahami type coercion (materi 8), kamu perlu tahu berbagai operasi yang bisa dilakukan pada data. Operator aritmatika adalah operasi paling dasar. Materi ini juga berkaitan dengan assignment yang berhubungan erat dengan variabel (materi 5).

## Soal Latihan
Apa output dari kode berikut?
```js
let x = 10;
x += 5;
x *= 2;
console.log(x);
```
