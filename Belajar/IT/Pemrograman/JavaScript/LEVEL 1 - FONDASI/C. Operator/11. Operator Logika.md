# 11. Operator Logika

## Penjelasan
Operator logika digunakan untuk mengkombinasikan atau membalikkan nilai boolean: `&&` (AND — semua kondisi harus true), `||` (OR — salah satu kondisi true), dan `!` (NOT — membalikkan nilai boolean). JavaScript juga mengenal **short-circuit evaluation**: untuk `&&`, jika kondisi pertama false, kondisi kedua tidak dievaluasi. Untuk `||`, jika kondisi pertama true, kondisi kedua tidak dievaluasi. Operator logika juga bisa mengembalikan nilai non-boolean karena JavaScript mengembalikan nilai asli dari operand terakhir yang dievaluasi.

## Fungsi
Operator logika memungkinkan program mengevaluasi beberapa kondisi sekaligus. Misalnya: "Apakah user sudah login **DAN** punya akses admin?", "Apakah barang sedang diskon **ATAU** barang sudah mau kadaluarsa?". Ini adalah fondasi dari logika pengambilan keputusan dalam pemrograman.

## Cara Pengimplementasian
```js
const sudahBayarListrik = true;
const sudahBayarAir = false;

// AND — semua harus true
console.log(sudahBayarListrik && sudahBayarAir); // false (air belum bayar)

// OR — salah satu true sudah cukup
console.log(sudahBayarListrik || sudahBayarAir); // true (listrik sudah bayar)

// NOT — membalikkan
console.log(!sudahBayarListrik); // false
console.log(!sudahBayarAir);     // true

// Short-circuit
console.log(true || apapun);     // true (apapun tidak dievaluasi)
console.log(false && apapun);    // false (apapun tidak dievaluasi)

// Mengembalikan nilai asli
console.log("Rumah" && "Kamar"); // "Kamar" (keduanya true, ambil yang terakhir)
console.log(null || "Default");  // "Default" (null falsy, ambil default)
```

## Analogi
Operator logika seperti **sistem keamanan dan aturan di rumah**:
- `&&` (AND) = pintu rumah terbuka hanya jika **kedua** kunci (kunci pintu depan DAN kunci pagar) digunakan
- `||` (OR) = lampu teras menyala jika ada tamu **ATAU** sudah malam hari
- `!` (NOT) = kebalikan — jika lampu tidak mati (`!mati`), berarti lampu menyala
- Short-circuit = pintu otomatis: jika sensor sudah mendeteksi orang (`true`), tidak perlu cek sensor lagi

## Dipakai Untuk Apa
Digunakan di semua struktur kontrol kompleks — validasi form multi-kondisi (username terisi **DAN** password minimal 8 karakter), fitur akses (user adalah admin **ATAU** moderator), memberikan nilai default (`const nama = input || "Tamu"`), dan mengontrol alur program berdasarkan kombinasi kondisi.

## Kesalahan Umum
Pemula sering bingung dengan short-circuit yang mengembalikan nilai non-boolean. Contoh: `const nama = "" || "Tamu"` mengembalikan `"Tamu"` karena string kosong falsy. Juga sering terjadi kesalahan logika dengan negasi ganda: `!!nilai` mengubah nilai menjadi boolean (true jika truthy). Prioritaskan operator: `!` dievaluasi dulu, lalu `&&`, lalu `||` — gunakan tanda kurung untuk memperjelas.

## Keterkaitan dengan Materi Sebelumnya
Setelah bisa membandingkan nilai dengan operator perbandingan (materi 10), kamu perlu menggabungkan beberapa perbandingan sekaligus. Operator logika adalah lem yang menghubungkan kondisi-kondisi tersebut. Pemahaman tentang truthy/falsy (materi 12) juga sangat erat kaitannya dengan operator logika.

## Soal Latihan
Apa output dari kode berikut?
```js
console.log(true && false);
console.log(true || false);
console.log(!false);
console.log("" || "Rumah");
```
