# 8. Type Coercion

## Penjelasan
Type coercion adalah proses otomatis atau manual mengubah satu tipe data ke tipe data lain di JavaScript. Ada dua jenis: **implicit coercion** (dilakukan otomatis oleh JavaScript) dan **explicit coercion** (dilakukan manual oleh programmer). Contoh implisit: `"5" + 3` menghasilkan `"53"` (number 3 diubah ke string). Contoh eksplisit: `Number("5")` mengubah string `"5"` menjadi number `5`.

## Fungsi
Type coercion memungkinkan JavaScript untuk tetap berjalan meskipun ada operasi antara tipe data yang berbeda. Namun, coercion implisit sering menyebabkan bug yang sulit dilacak. Memahami coercion membantu kamu menulis kode yang lebih aman dan bisa memprediksi hasil operasi dengan benar.

## Cara Pengimplementasian
```js
// Implicit coercion (otomatis)
console.log("5" + 3);     // "53" (number 3 jadi string)
console.log("5" - 3);     // 2 (string "5" jadi number)
console.log("5" * "2");   // 10 (keduanya jadi number)
console.log(true + 1);    // 2 (true jadi 1)

// Explicit coercion (manual)
console.log(Number("5"));       // 5
console.log(String(123));       // "123"
console.log(Boolean(0));        // false
console.log(Boolean(""));       // false
console.log(Boolean("Halo"));   // true

// Trik cepat (tidak direkomendasikan)
console.log(+"5");       // 5 (unary plus)
console.log(!!"teks");   // true (double NOT)
```

## Analogi
Type coercion seperti **menyesuaikan perabot agar muat di dalam rumah**:
- Coercion implisit = memaksa lemari besar masuk ke pintu kecil dengan memiringkannya (beresiko merusak)
- Coercion eksplisit = mengukur lemari terlebih dahulu, lalu membongkar dan merakitnya kembali di dalam rumah
- `Number("5")` = mengubah papan nama bertuliskan "5" menjadi angka ukuran 5 meter
- `String(123)` = menulis angka 123 di papan nama
- `Boolean()` = mengecek apakah suatu barang ada isinya atau tidak

## Dipakai Untuk Apa
Digunakan saat menerima input dari form (semua input HTML adalah string, perlu diubah ke number), parsing data dari API, validasi data, dan operasi perbandingan yang melibatkan tipe data berbeda. Dengan memahami coercion, kamu bisa menghindari bug misterius di aplikasi.

## Kesalahan Umum
Kesalahan paling terkenal: `"5" + 3` menghasilkan `"53"` bukan `8`. Pemula sering kaget karena operator `+` bisa berfungsi sebagai concatenation (penggabungan string) dan penjumlahan. Juga waspada dengan `==` (loose equality) yang melakukan coercion — selalu gunakan `===` (strict equality) untuk menghindari kejutan.

## Keterkaitan dengan Materi Sebelumnya
Setelah memahami string (materi 7) dan tipe data primitif (materi 6), sekarang kamu perlu tahu bagaimana JavaScript "memperlakukan" data ketika tipe data berbeda bertemu. Ini penting sebelum masuk ke operator (materi 9), karena operasi aritmatika dan perbandingan sangat dipengaruhi oleh coercion.

## Soal Latihan
Apa output dari kode berikut dan jelaskan mengapa?
```js
console.log("10" + 5);
console.log("10" - 5);
console.log(0 == false);
console.log(0 === false);
```

<details>
<summary>Jawaban</summary>
`"105"` (coercion implisit — `+` dengan string memicu concatenation), `5` (coercion implisit — `-` hanya untuk number, jadi string "10" diubah ke number 10), `true` (loose equality `==` melakukan coercion: `false` jadi `0`), `false` (strict equality `===` tidak melakukan coercion, number `0` berbeda tipe dengan boolean `false`).
</details>
