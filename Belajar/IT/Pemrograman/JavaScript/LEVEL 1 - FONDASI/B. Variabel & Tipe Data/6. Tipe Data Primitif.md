# 6. Tipe Data Primitif

## Penjelasan
JavaScript memiliki 7 tipe data primitif: `string` (teks), `number` (angka), `boolean` (true/false), `undefined` (belum diisi), `null` (kosong sengaja), `bigint` (angka besar), dan `symbol` (identitas unik). Tipe data primitif bersifat immutable (tidak bisa diubah) dan disimpan langsung di memori. Semua tipe data selain ini adalah object (tipe reference).

## Fungsi
Tipe data memberitahu JavaScript jenis nilai apa yang disimpan dalam variabel. Ini penting karena operasi yang bisa dilakukan pada suatu nilai tergantung dari tipe datanya. Misalnya, kamu bisa menjumlahkan dua `number`, tetapi tidak bisa "menjumlahkan" dua `boolean` secara matematis.

## Cara Pengimplementasian
```js
const namaRumah = "Rumah Biru";        // string
const luasTanah = 200;                  // number
const sudahDihuni = true;               // boolean
let penghuni;                           // undefined
const halamanKosong = null;             // null
const angkaBesar = 9007199254740991n;   // bigint
const idUnik = Symbol("id");            // symbol

console.log(typeof namaRumah);   // "string"
console.log(typeof luasTanah);   // "number"
console.log(typeof sudahDihuni); // "boolean"
console.log(typeof penghuni);    // "undefined"
console.log(typeof halamanKosong); // "object" — ini bug JS klasik!
```

## Analogi
Tipe data seperti **jenis barang yang disimpan di kotak-kotak rumah**:
- `string` = papan nama (berisi tulisan)
- `number` = ukuran rumah dalam meter (angka)
- `boolean` = saklar lampu (hanya dua kondisi: nyala/mati)
- `undefined` = kamar kosong yang belum diisi perabot
- `null` = kamar kosong yang sengaja dikosongkan
- `bigint` = luas tanah yang sangat besar
- `symbol` = kunci unik rumah yang tidak ada duplikatnya

## Dipakai Untuk Apa
Setiap aplikasi web menggunakan berbagai tipe data — string untuk teks (nama user, alamat), number untuk perhitungan (harga, umur), boolean untuk kondisi (apakah user sudah login, apakah lampu menyala), null/undefined untuk pengecekan data kosong.

## Kesalahan Umum
Kesalahan klasik: `typeof null` mengembalikan `"object"` — ini bug JavaScript yang sudah ada sejak awal dan tidak bisa diperbaiki karena akan merusak ribuan website. Pemula juga sering bingung antara `null` dan `undefined`: `undefined` berarti variabel belum diisi, `null` berarti sengaja dikosongkan oleh programmer.

## Keterkaitan dengan Materi Sebelumnya
Setelah tahu cara mendeklarasikan variabel dengan `let` dan `const` (materi 5), sekarang kamu perlu tahu "apa yang bisa disimpan" di dalam variabel tersebut. Tipe data primitif adalah bahan baku utama yang akan kamu simpan di kotak-kotak variabel.
