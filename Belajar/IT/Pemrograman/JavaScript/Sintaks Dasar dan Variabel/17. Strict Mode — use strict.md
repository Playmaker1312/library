

### Definisi Singkat

_Strict Mode_ adalah fitur di dalam JavaScript yang mengubah cara program dieksekusi. Dengan mengaktifkan mode ini, JavaScript akan menerapkan aturan yang lebih ketat terhadap kesalahan sintaks dan praktik penulisan kode yang kurang aman, sehingga mencegah _bug_ yang tidak disengaja.

---

### Analogi

Bayangkan perbedaan ini seperti **mengemudi mobil di jalanan umum biasa versus di sirkuit balap berstandar profesional**:

- **JavaScript biasa:** Seperti mengemudi dengan aturan biasa; Anda mungkin bisa sedikit melanggar batas, menggunakan jalan pintas, atau mengemudi secara ceroboh.
    
- **Strict Mode:** Seperti mobil balap di sirkuit dengan **pengawasan sistem otomatis**. Setiap kesalahan kecil, seperti melebihi kecepatan atau belok tanpa lampu sein, akan langsung memicu peringatan dan menghentikan mobil untuk memastikan keselamatan.
    

---

### Poin-Poin Penting

- **Tujuan Utama:** Menghindari kesalahan penulisan (_typo_) pada variabel yang dapat mengubahnya menjadi variabel global tanpa disadari.
    
- **Cara Mengaktifkannya:** * Ditandai dengan string literal `"use strict";` (atau `'use strict';`) di awal file atau di dalam fungsi.
    
- **Fitur Utama yang Dibatasi oleh Strict Mode:**
    
    - **Tidak boleh menggunakan variabel yang belum dideklarasikan:** Mencegah terjadinya variabel global yang tidak disengaja akibat salah ketik nama variabel.
        
    - **Menghapus fitur yang tidak aman:** Misalnya, mencegah penggunaan `delete` pada variabel atau objek tertentu yang tidak dapat dihapus.
        
    - **Mengubah perilaku `this`:** Pada fungsi biasa yang dipanggil sendiri, nilai `this` akan menjadi `undefined` (bukan objek global seperti `window` pada _browser_).
        
    - **Parameter fungsi tidak boleh memiliki nama yang sama:** Memicu _syntax error_ jika parameter duplikat digunakan.

### Contoh Implementasi

#### 1. Kesalahan dalam Mode Normal (Tanpa Strict Mode):

Pada mode biasa, jika Anda salah mengetik nama variabel dan memberikan nilai, JavaScript akan otomatis membuat variabel global baru.

JavaScript

```
// Tanpa "use strict"
kota = "Bandung"; // Secara tidak sengaja membuat variabel global
console.log(kota); // Output: Bandung
```

#### 2. Strict Mode Memicu Error:

Jika Anda menggunakan `"use strict";`, kesalahan penulisan tersebut akan langsung dihentikan dan diberitahukan kepada Anda:

JavaScript

```
"use strict";

try {
    kota = "Jakarta"; // Memicu error karena 'kota' belum dideklarasikan dengan var/let/const
} catch (error) {
    console.error(error.message); // Output: kota is not defined
}
```

### Koneksi

Dalam bidang **Web Development**, _Strict Mode_ adalah praktik standar (_best practice_) yang digunakan dalam pengembangan modern untuk:

- **Meningkatkan keamanan aplikasi web:** Mengurangi celah di mana _script_ berbahaya dapat memanipulasi objek global seperti `window` atau mengambil alih data pengguna.
    
- **Memastikan kompatibilitas:** Membantu mematuhi standar penulisan kode modern (seperti ES6+) yang diadopsi oleh _framework_ seperti React atau Vue.
