
### Definisi Singkat

_Scope_ (ruang lingkup) adalah batasan di mana suatu variabel dapat diakses di dalam kode, sedangkan _Hoisting_ adalah mekanisme di mana deklarasi variabel atau fungsi dinaikkan ke bagian atas ruang lingkupnya sebelum kode dieksekusi.

---

### Analogi

Bayangkan perbedaan ini seperti **tingkat kerahasiaan dokumen di sebuah kantor**:

- **Scope (`var`):** Dokumen yang disimpan di papan pengumuman lobi kantor. Semua orang dari berbagai divisi (bahkan dari luar) dapat melihat dan mengubah isinya.
    
- **Scope (`let` & `const`):** Dokumen di dalam brankas ruang rapat tertentu. Hanya orang yang berada di ruangan tersebut yang dapat melihatnya.
    
- **Hoisting:** Anggaplah seperti **pendaftaran nama di absensi pagi**. Baik Anda datang terlambat, nama Anda sudah ditulis di daftar absensi teratas oleh sistem sebelum rapat dimulai.
    

---

### Poin-Poin Penting

- **Perbedaan Ruang Lingkup (Scope):**
    
    - **`var`:** Bersifat _function-scoped_. Jika dideklarasikan di dalam sebuah blok seperti `if` atau `for`, variabel tersebut tetap dapat diakses dari luar blok.
        
    - **`let` dan `const`:** Bersifat _block-scoped_ (terbatas pada kurung kurawal `{ ... }` tempat mereka dideklarasikan).
        
- **Perbedaan Hoisting:**
    
    - **`var`:** Mengalami _hoisting_ dan diinisialisasi dengan nilai `undefined`. Anda bisa menggunakan variabel `var` sebelum dideklarasikan tanpa _error_ (meskipun nilainya `undefined`).
        
    - **`let` dan `const`:** Mengalami _hoisting_, tetapi berada dalam kondisi **Temporal Dead Zone (TDZ)**. Mengakses variabel ini sebelum dideklarasikan akan langsung memicu _ReferenceError_.
        

---

### Contoh Implementasi

#### 1. Perbedaan Scope

JavaScript

```
function contohScope() {
    if (true) {
        var namaVar = "Budi";
        let namaLet = "Siti";
    }
    console.log(namaVar); // Output: Budi (karena var bersifat function-scoped)
    // console.log(namaLet); // Error: namaLet is not defined (karena block-scoped)
}
contohScope();
```

#### 2. Perbedaan Hoisting dan Temporal Dead Zone (TDZ)

JavaScript

```
// Contoh dengan var (Hoisting dan diinisialisasi sebagai undefined)
console.log(angka); // Output: undefined
var angka = 100;

// Contoh dengan let (Terkena Temporal Dead Zone)
// console.log(jumlah); // Error: Cannot access 'jumlah' before initialization
let jumlah = 50;
```

### Koneksi

Dalam bidang **Web Development**, memahami _scope_ dan _hoisting_ sangat penting untuk:

- **Mencegah _bug_ yang tidak terduga** pada aplikasi skala besar di mana nama variabel yang sama mungkin digunakan di beberapa blok kode yang berbeda.
    
- **Mengelola keamanan data** pengguna saat menggunakan fungsi-fungsi dalam _framework_ seperti React atau Vue.js, di mana variabel lokal tidak boleh bocor ke tingkat global.
