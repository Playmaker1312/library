### Definisi Singkat

Di dalam JavaScript, **Expression** adalah potongan kode yang menghasilkan nilai (dapat dievaluasi), **Statement** adalah instruksi atau perintah yang melakukan suatu tindakan, dan **Semicolon** (titik koma `;`) adalah tanda baca yang digunakan untuk memisahkan atau mengakhiri statement tersebut.

---

### Analogi

Bayangkan seperti **proses pembuatan kue**:

- **Expression** adalah bahan-bahan atau nilai tunggal seperti "tepung", "gula", atau operasi matematika sederhana seperti "3 + 5" yang menghasilkan sebuah nilai (yaitu kue atau angka).
    
- **Statement** adalah **resep atau instruksi lengkap** seperti "Masukkan gula ke dalam adonan", yang merupakan sebuah perintah untuk bertindak.
    
- **Semicolon** adalah **titik di akhir kalimat** instruksi resep tersebut untuk memberi tahu pembaca bahwa satu instruksi telah selesai.
    

---

### Poin-Poin Penting

- **Expression (Ekspresi):**
    
    - Selalu menghasilkan atau mengevaluasi menjadi satu nilai tertentu.
        
    - Contoh: `5 + 3` (menghasilkan 8), variabel `nama`, atau fungsi yang mengembalikan nilai.
        
- **Statement (Pernyataan):**
    
    - Melakukan tindakan atau instruksi, tetapi tidak selalu menghasilkan nilai yang dapat dicetak atau disimpan secara langsung.
        
    - Contoh: `if (kondisi) { ... }`, `for` loop, atau deklarasi variabel.
        
- **Semicolon (Titik Koma `;`):**
    
    - Digunakan untuk mengakhiri statement.
        
    - JavaScript memiliki fitur **ASI** (_Automatic Semicolon Insertion_) yang secara otomatis menambahkan titik koma di akhir baris, tetapi praktik terbaik (_best practice_) tetap menuliskan titik koma secara manual untuk menghindari _bug_ yang tidak terduga.
        

---

### Contoh Implementasi

Mari kita lihat perbedaan antara expression dan statement melalui contoh kode berikut:

JavaScript

```
// 1. Expression (Menghasilkan nilai 15)
let hasil = 10 + 5; 

// 2. Statement (Instruksi kondisi untuk mengontrol alur program)
if (hasil > 10) {
    console.log("Hasil lebih besar dari 10");
}
```

#### Penggunaan Semicolon:

JavaScript

```
// Statement sederhana dengan semicolon di akhir
let nama = "Budi";
console.log(nama);
```

---

### Koneksi

Dalam bidang **Web Development**, memahami perbedaan antara _statement_ dan _expression_ sangat penting saat menulis logika aplikasi web:

- **Expression** banyak digunakan ketika kita ingin memanipulasi data atau menampilkan variabel secara langsung di dalam sintaks JSX (seperti di React) atau _template literals_ HTML.
    
- **Statement** digunakan untuk mengatur alur logika halaman, seperti validasi form, pengalihan halaman, atau mengambil data dari server.
