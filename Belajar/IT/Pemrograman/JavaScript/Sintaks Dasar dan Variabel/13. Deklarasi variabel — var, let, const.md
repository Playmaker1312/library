### Definisi Singkat

Variabel adalah wadah atau tempat penyimpanan untuk menyimpan data atau nilai di dalam memori komputer. Di dalam JavaScript, terdapat tiga cara untuk mendeklarasikan variabel: `var` (cara lama), serta `let` dan `const` (cara modern).

---

### Analogi

Bayangkan Anda sedang menyewa loker penyimpanan:

- **`var`** seperti **kunci loker yang bisa diduplikasi** dan diakses oleh siapa saja dari mana saja. Jika seseorang menukar isi loker tersebut, kuncinya tetap sama dan nilainya ikut berubah di seluruh area.
    
- **`let`** seperti **loker dengan kunci yang bisa diganti isinya**, tetapi hanya berlaku di dalam ruangan tertentu saja (_block scope_).
    
- **`const`** (dari kata _constant_) seperti **kotak penyimpanan permanen yang digembok mati**. Setelah Anda memasukkan barang ke dalamnya, Anda tidak bisa menggantinya dengan barang lain.
    

---

### Poin-Poin Penting

- **`var` (Function-scoped):**
    
    - Cara deklarasi dari JavaScript versi awal (ES5).
        
    - Bersifat _function-scoped_ (terbatas pada fungsi) atau _globally-scoped_ jika dideklarasikan di luar fungsi.
        
    - Memungkinkan terjadinya _hoisting_ (variabel dapat digunakan sebelum dideklarasikan).
        
- **`let` (Block-scoped):**
    
    - Diperkenalkan pada ES6.
        
    - Bersifat _block-scoped_ (hanya bisa diakses di dalam blok kurung kurawal `{ ... }` tempat ia dibuat).
        
    - Nilainya dapat diubah (_mutable_).
        
- **`const` (Block-scoped dan Konstan):**
    
    - Diperkenalkan pada ES6.
        
    - Bersifat _block-scoped_ seperti `let`.
        
    - Nilainya tidak dapat diubah atau ditetapkan ulang (_immutable_ setelah dideklarasikan).
        

---

### Contoh Implementasi

Berikut adalah perbedaan perilaku dari ketiga jenis deklarasi variabel:

#### 1. Menggunakan `var` (Dapat dideklarasikan ulang dan nilainya berubah):

JavaScript

```
var warna = "Merah";
var warna = "Biru"; // Tidak terjadi error
console.log(warna); // Output: Biru
```

#### 2. Menggunakan `let` (Dapat diubah, tetapi tidak boleh dideklarasikan ulang di lingkup yang sama):

JavaScript

```
let angka = 10;
angka = 20; // Diperbolehkan

// let angka = 30; // Akan memicu error: Identifier 'angka' has already been declared
console.log(angka); // Output: 20
```

#### 3. Menggunakan `const` (Tidak dapat diubah atau dideklarasikan ulang):

JavaScript

```
const pi = 3.14;
// pi = 3.14159; // Akan memicu error: Assignment to constant variable.
console.log(pi);
```

### Koneksi

Dalam bidang **Web Development**, pemilihan deklarasi variabel yang tepat sangat penting untuk menjaga integritas data dan menghindari _bug_ yang tidak terduga:

- Gunakan **`const`** sebagai pilihan utama untuk variabel yang nilainya tidak akan berubah (seperti elemen DOM, fungsi, atau data konfigurasi API).
    
- Gunakan **`let`** untuk variabel yang nilainya akan sering berubah (seperti penghitung atau status _loading_).
    
- Hindari penggunaan **`var`** dalam pengembangan web modern untuk mencegah masalah tumpang tindih (_variable shadowing_ atau _hoisting_).
