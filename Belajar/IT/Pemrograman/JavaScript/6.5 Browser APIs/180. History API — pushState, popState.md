### Definisi Singkat
**History API** memungkinkan manipulasi riwayat browsing browser (session history) via JavaScript. Method utama: **`pushState()`** untuk menambah entry baru, **`replaceState()`** untuk mengganti entry saat ini, dan event **`popstate`** yang terpicu saat pengguna navigasi (back/forward).

---

### Analogi
History API seperti **buku log perjalanan**. Kamu bisa mencatat posisi baru (`pushState`), memperbarui catatan yang ada (`replaceState`), dan buku akan memberi tahu saat kamu mundur/maju (`popstate`).

---

### Poin-Poin Penting
- `history.pushState(state, title, url)` — tambah entry baru, ubah URL tanpa reload
- `history.replaceState(state, title, url)` — ganti entry saat ini
- `history.back()`, `history.forward()`, `history.go(n)`
- `history.length` — jumlah entry dalam session
- `popstate` event — terpicu saat back/forward (tidak saat pushState)
- `event.state` — data state dari entry history
- Penting untuk **SPA (Single Page Application)** routing

---

### Contoh Implementasi

```javascript
// Push state — navigasi SPA
document.querySelectorAll('a').forEach(link => {
  link.addEventListener('click', (e) => {
    e.preventDefault();
    const url = link.getAttribute('href');
    
    // Update history
    history.pushState({ page: url }, '', url);
    
    // Update konten
    loadContent(url);
  });
});

// Menangani back/forward
window.addEventListener('popstate', (e) => {
  if (e.state) {
    console.log('Kembali ke:', e.state.page);
    loadContent(e.state.page);
  }
});

// Replace state (update state tanpa entry baru)
history.replaceState({ scrollY: window.scrollY }, '');

// State data bisa object apa pun
history.pushState(
  { userId: 123, filter: 'active' },
  '',
  '/users?filter=active'
);

// Utility
function navigateTo(url) {
  history.pushState({ url }, '', url);
  // render halaman
}
```
