### Definisi Singkat
**IntersectionObserver** adalah API yang memantau visibilitas suatu elemen target relatif terhadap elemen root atau viewport. Ideal untuk **lazy loading gambar**, **infinite scroll**, **animasi scroll-based**, dan **tracking iklan**.

---

### Analogi
IntersectionObserver seperti **penjaga pintu otomatis**. Penjaga akan memberi tahu saat seseorang (elemen) masuk atau keluar dari area pintu (viewport/root). Tanpa perlu terus-menerus mengecek manual.

---

### Poin-Poin Penting
- `new IntersectionObserver(callback, options)` — buat observer
- `observer.observe(element)` — mulai amati elemen
- `observer.unobserve(element)` — berhenti amati
- `observer.disconnect()` — berhenti semua observasi
- Callback menerima array `entries`, masing-masing punya: `isIntersecting`, `intersectionRatio`, `boundingClientRect`, `target`
- Options: `root`, `rootMargin`, `threshold` (0-1 array)
- Lebih performan dari scroll event listener manual

---

### Contoh Implementasi

```javascript
// Lazy loading gambar
const images = document.querySelectorAll('img[data-src]');

const imgObserver = new IntersectionObserver((entries, observer) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const img = entry.target;
      img.src = img.dataset.src;
      img.removeAttribute('data-src');
      observer.unobserve(img); // Berhenti amati setelah dimuat
    }
  });
}, { rootMargin: '200px' }); // Mulai load 200px sebelum terlihat

images.forEach(img => imgObserver.observe(img));

// Infinite scroll
const sentinel = document.getElementById('sentinel');
const scrollObserver = new IntersectionObserver(([entry]) => {
  if (entry.isIntersecting) {
    loadMoreItems();
  }
});
scrollObserver.observe(sentinel);

// Animasi masuk viewport
const animObserver = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('animate');
    }
  });
}, { threshold: 0.5 });

document.querySelectorAll('.animate-on-scroll')
  .forEach(el => animObserver.observe(el));
```
