# 39. for...of - iterasi nilai array

**Definisi Singkat:** `for...of` mengulang setiap *nilai* (value) dari array atau iterable.

**Analogi:** Seperti "ambil satu per satu buku dari rak" — ambil buku (nilai) tanpa peduli nomor raknya.

**Poin-Poin Penting:**
- Mengambil nilai langsung, bukan index
- Bekerja untuk array, string, Map, Set, dll
- Tidak bisa mengakses index secara langsung
- Lebih bersih dari `for` klasik untuk iterasi nilai

**Contoh Kode:**
```javascript
const buah = ["Apel", "Mangga", "Jeruk"];
for (const item of buah) {
  console.log(`Buah: ${item}`);
}
```
Hasil:
```
Buah: Apel
Buah: Mangga
Buah: Jeruk
```

**Kasus Penggunaan Nyata:**
Iterasi data API, render daftar item dari array.
