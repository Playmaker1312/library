# 40. for...in - iterasi key object

**Definisi Singkat:** `for...in` mengulang setiap *key* (properti) dari sebuah object.

**Analogi:** Seperti "sebutkan label di setiap stoples" — ambil nama label (key), bukan isinya.

**Poin-Poin Penting:**
- Iterasi melewati *enumerable properties*
- Juga melewati properti dari prototype chain
- Tidak disarankan untuk array (bisa termasuk properti lain)
- Dipakai untuk object, bukan iterable

**Contoh Kode:**
```javascript
const user = { nama: "Budi", usia: 25, kota: "Jakarta" };
for (const key in user) {
  console.log(`${key}: ${user[key]}`);
}
```
Hasil:
```
nama: Budi
usia: 25
kota: Jakarta
```

**Kasus Penggunaan Nyata:**
Mengubah bentuk object, logging semua properti, debugging.
