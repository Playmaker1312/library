### Definisi Singkat

Perulangan `for` (_for loop_) adalah struktur kontrol di dalam JavaScript yang digunakan untuk mengulang blok kode tertentu sebanyak jumlah hitungan yang telah ditentukan. Sintaks klasik ini terdiri dari tiga bagian utama: inisialisasi, kondisi, dan _increment/decrement_.

---

### Analogi

Bayangkan Anda sedang berlari mengelilingi lapangan sebanyak 5 putaran:

- **Inisialisasi:** Anda mulai dari hitungan putaran pertama (misal: `let putaran = 1`).
    
- **Kondisi:** Sebelum mulai berlari, Anda memeriksa: "Apakah jumlah putaran sudah mencapai 5?"
    
- **Increment/Decrement:** Setiap kali Anda melewati garis _start/finish_, Anda menambah jumlah putaran sebesar 1 (`putaran++`).
    

---

### Poin-Poin Penting

- **Sintaks Dasar:**
    
    $$\text{for } (\text{inisialisasi}; \text{ kondisi}; \text{ increment/decrement}) \{ \text{blok kode} \}$$
    
- **Tahapan Eksekusi:**
    
    1. **Inisialisasi:** Dijalankan **hanya satu kali** di awal perulangan.
        
    2. **Kondisi:** Dievaluasi sebelum perulangan berjalan. Jika bernilai `true`, blok kode dijalankan. Jika `false`, perulangan berhenti.
        
    3. **Increment/Decrement:** Dijalankan setelah setiap putaran blok kode selesai.
        
- **Penggunaan Klasik:** Sangat cocok untuk mengulang suatu tindakan dalam rentang angka yang pasti, atau untuk menelusuri indeks elemen di dalam _array_.
    

---

### Contoh Implementasi

Berikut adalah contoh penggunaan `for loop` klasik di dalam JavaScript:

JavaScript

```
// Mengulang pencetakan angka dari 1 sampai 5
for (let i = 1; i <= 5; i++) {
    console.log("Perulangan ke-" + i);
}

// Menggunakan for loop untuk membaca elemen Array
const buah = ["Apel", "Mangga", "Jeruk"];

for (let i = 0; i < buah.length; i++) {
    console.log("Buah: " + buah[i]);
}
```

### Koneksi

Dalam bidang **Web Development**, penggunaan perulangan klasik sangat penting untuk memproses sekumpulan data:

- **Menampilkan Data dinamis:** Digunakan untuk merender daftar item (seperti daftar produk di e-commerce) dari database ke antarmuka HTML.
    
- **Manipulasi Elemen DOM:** Membantu kita untuk menerapkan perubahan gaya atau properti pada banyak elemen secara bersamaan di halaman web.
