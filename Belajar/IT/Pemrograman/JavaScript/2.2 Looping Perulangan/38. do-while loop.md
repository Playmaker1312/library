### Definisi Singkat

Perulangan `do-while` (_do-while loop_) adalah variasi dari perulangan `while` yang menjalankan blok kode **minimal satu kali terlebih dahulu**, sebelum memeriksa kondisi perulangan di akhir.

---

### Analogi

Bayangkan seperti **mencicipi makanan saat memasak**:

- Anda langsung mencicipi masakan tersebut terlebih dahulu (`do`).
    
- Setelah itu, Anda memeriksa rasanya: "Apakah rasanya kurang asin?"
    
- Jika ya, Anda akan menambahkan garam dan mencicipinya lagi. Jika sudah pas, Anda berhenti. Yang penting, Anda **pasti sudah mencicipinya setidaknya sekali**.
    

---

### Poin-Poin Penting

- **Sintaks Dasar:**
    
    $$\text{do} \{ \text{// blok kode} \} \text{ while } (\text{kondisi});$$
    
- **Alur Eksekusi:**
    
    1. JavaScript mengeksekusi blok kode di dalam `do` **tanpa** memeriksa kondisi terlebih dahulu.
        
    2. Setelah blok kode selesai, JavaScript mengevaluasi `kondisi` di akhir.
        
    3. Jika kondisi bernilai `true`, perulangan kembali ke atas dan mengulangi blok `do`.
        
    4. Jika kondisi bernilai `false`, perulangan berhenti.
        
- **Perbedaan Utama:** Berbeda dengan `while` biasa yang bisa saja tidak mengeksekusi blok kode sama sekali jika kondisinya bernilai salah sejak awal, `do-while` akan **selalu mengeksekusi blok kode setidaknya satu kali**.
    

---

### Contoh Implementasi

Berikut adalah contoh penggunaan `do-while loop` di dalam JavaScript:

JavaScript

```
let hitungan = 5;

// Blok kode ini akan dijalankan setidaknya 1 kali,
// meskipun kondisinya false sejak awal.
do {
    console.log("Angka saat ini: " + hitungan);
    hitungan++;
} while (hitungan < 3);

// Output:
// Angka saat ini: 5
```

---

### Koneksi

Dalam bidang **Web Development**, perulangan `do-while` sangat membantu ketika Anda ingin memastikan pengguna berinteraksi atau memasukkan data setidaknya sekali:

- **Validasi Input Pengguna:** Meminta pengguna memasukkan PIN atau kata sandi, memastikan formulir pop-up muncul setidaknya sekali di layar sebelum divalidasi.
    
- **Menu Interaktif Console / CLI:** Menampilkan daftar menu di konsol minimal satu kali agar pengguna dapat memilih opsi, lalu mengulanginya jika opsi yang dimasukkan salah.
