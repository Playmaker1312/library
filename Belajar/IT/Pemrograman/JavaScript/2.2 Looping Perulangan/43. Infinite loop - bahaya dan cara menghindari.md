# 43. Infinite loop - bahaya dan cara menghindari

**Definisi Singkat:** Infinite loop adalah perulangan yang tidak pernah berhenti karena kondisi tidak pernah `false`.

**Analogi:** Seperti kulkas yang terus mendingin tanpa termostat — akhirnya terlalu dingin dan rusak.

**Poin-Poin Penting:**
- Penyebab umum: lupa increment, kondisi salah, logic error
- Dapat menyebabkan browser freeze atau crash
- Selalu pastikan variabel counter berubah menuju kondisi stop
- Batasi iterasi maksimum sebagai safety net

**Contoh Kode:**
```javascript
// HATI-HATI: ini infinite loop!
// for (let i = 0; i < 5;) {
//   console.log("Tak terbatas!");
// }

// Solusi: pastikan counter berubah
for (let i = 0; i < 5; i++) {
  console.log(`Iterasi ${i + 1}`);
}
```
Hasil: `Iterasi 1 Iterasi 2 Iterasi 3 Iterasi 4 Iterasi 5`

**Kasus Penggunaan Nyata:**
Debugging infinite loop sering terjadi saat lupa increment, atau kondisi rekursif tanpa base case.
