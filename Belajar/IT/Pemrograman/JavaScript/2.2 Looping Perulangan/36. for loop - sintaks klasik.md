# 36. for loop - sintaks klasik

**Definisi Singkat:** `for` adalah perulangan dengan inisialisasi, kondisi, dan increment dalam satu baris.

**Analogi:** Seperti "lari 10 putaran" — tahu pasti berapa kali, punya counter, berhenti setelah cukup.

**Poin-Poin Penting:**
- Tiga bagian: `inisialisasi; kondisi; increment`
- Inisialisasi jalan sekali di awal
- Kondisi dicek sebelum setiap iterasi
- Increment jalan setelah blok kode

**Contoh Kode:**
```javascript
for (let i = 1; i <= 3; i++) {
  console.log(`Iterasi ke-${i}`);
}
```
Hasil:
```
Iterasi ke-1
Iterasi ke-2
Iterasi ke-3
```

**Kasus Penggunaan Nyata:**
Iterasi array dengan index, render daftar item di UI.
