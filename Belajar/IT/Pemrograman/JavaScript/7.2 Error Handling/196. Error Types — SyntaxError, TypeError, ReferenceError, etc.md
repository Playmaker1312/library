### Definisi Singkat
JavaScript memiliki beberapa tipe error bawaan: **SyntaxError** (kesalahan sintaks), **TypeError** (operasi pada tipe yang salah), **ReferenceError** (variabel tidak ditemukan), **RangeError** (nilai di luar rentang), **URIError** (fungsi URI salah), **EvalError** (eval error — jarang), dan **Error** (generik).

---

### Analogi
Tipe error seperti **lampu indikator di mobil**:
- **SyntaxError** = lampu mesin — ada yang salah secara fundamental
- **TypeError** = roda kotak — kamu pakai tipe yang salah untuk operasi tertentu
- **ReferenceError** = setir hilang — sesuatu yang kamu cari tidak ada
- **RangeError** = speedometer 500 km/h — nilai di luar batas wajar

---

### Poin-Poin Penting

| Error Type | Penyebab | Contoh |
|-----------|----------|--------|
| `SyntaxError` | Sintaks tidak valid | `JSON.parse('{bad}')` |
| `TypeError` | Operasi pada tipe salah | `null.foo`, `1()` |
| `ReferenceError` | Variabel tidak terdefinisi | `console.log(x)` |
| `RangeError` | Nilai di luar rentang | `new Array(-1)` |
| `URIError` | URI tidak valid | `decodeURI('%')` |
| `Error` | Error generik | `new Error('ups')` |

- Semua tipe error adalah turunan dari `Error`
- Memiliki properti: `name`, `message`, `stack`
- `instanceof` untuk mengecek tipe error

---

### Contoh Implementasi

```javascript
// ReferenceError
try {
  console.log(tidakAda);
} catch (err) {
  console.log(err instanceof ReferenceError); // true
  console.log(err.name);    // "ReferenceError"
  console.log(err.message); // "tidakAda is not defined"
}

// TypeError
try {
  null.foo();
} catch (err) {
  console.log(err.name);  // "TypeError"
}

// SyntaxError (hanya saat eval/JSON.parse)
try {
  JSON.parse('{test}');
} catch (err) {
  console.log(err.name);  // "SyntaxError"
}

// RangeError
try {
  new Array(-5);
} catch (err) {
  console.log(err.name);  // "RangeError"
}

// Cek tipe error
function safeJSON(str) {
  try {
    return JSON.parse(str);
  } catch (err) {
    if (err instanceof SyntaxError) {
      console.log('JSON tidak valid');
      return null;
    }
    throw err; // Error lain — lempar lagi
  }
}

// Custom dengan tipe spesifik
if (typeof val !== 'function') {
  throw new TypeError('Harus function');
}
```
