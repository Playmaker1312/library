### Definisi Singkat
**`try-catch-finally`** adalah blok untuk menangani error secara graceful. Kode yang berpotensi error ditempatkan di blok `try`. Jika error terjadi, eksekusi lompat ke blok `catch`. Blok `finally` selalu dijalankan terlepas dari error atau tidak.

---

### Analogi
Seperti **bermain di taman bermain dengan pengawas**. Kamu mencoba memanjat (`try`). Jika jatuh (`error`), pengawas menangkapmu (`catch`). Apapun yang terjadi, kamu pulang ke rumah (`finally`).

---

### Poin-Poin Penting
- `try { /* kode berisiko */ }` — jika error, sisa kode di try dilewati
- `catch (err) { /* handle error */ }` — tangkap error, `err` adalah object error
- `finally { /* selalu jalan */ }` — untuk cleanup (tutup koneksi, hapus loading)
- `catch` bisa tanpa parameter: `catch { }` (ES2019)
- `finally` tetap jalan meskipun ada `return` di `try` atau `catch`
- Hanya menangkap **runtime errors** — bukan syntax errors

---

### Contoh Implementasi

```javascript
// Basic try-catch
try {
  const data = JSON.parse('{"invalid"}');
  console.log(data);
} catch (error) {
  console.log('Terjadi error:', error.message);
} finally {
  console.log('Selesai mencoba parse JSON');
}

// try-catch-finally dengan return
function divide(a, b) {
  try {
    if (b === 0) throw new Error('Pembagi tidak boleh 0');
    return a / b;
  } catch (err) {
    console.error(err.message);
    return NaN;
  } finally {
    console.log('Operasi selesai'); // Tetap jalan!
  }
}

console.log(divide(10, 2)); // 5
console.log(divide(10, 0)); // NaN

// Nested try-catch
try {
  try {
    throw new Error('Error dalam');
  } catch (innerErr) {
    console.log('Inner catch:', innerErr.message);
    throw innerErr; // Re-throw ke outer
  }
} catch (outerErr) {
  console.log('Outer catch:', outerErr.message);
}
```
