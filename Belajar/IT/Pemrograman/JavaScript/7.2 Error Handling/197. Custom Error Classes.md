### Definisi Singkat
**Custom Error Classes** adalah kelas yang mewarisi (`extends`) dari `Error` bawaan untuk membuat tipe error spesifik aplikasi. Dengan custom error, kita bisa membedakan jenis error berdasarkan konteks bisnis — misalnya `ValidationError`, `AuthError`, `NotFoundError`.

---

### Analogi
Custom Error seperti **seragam khusus untuk petugas di berbagai divisi**. Bukan hanya "petugas" (Error generik), tapi ada "petugas keamanan" (`AuthError`), "petugas administrasi" (`ValidationError`), dan "petugas gudang" (`NotFoundError`). Masing-masing punja atribut tambahan yang relevan.

---

### Poin-Poin Penting
- `class CustomError extends Error { ... }` — warisi Error
- Panggil `super(message)` di constructor — set `this.message`
- Set `this.name = 'CustomError'` — agar nama error sesuai kelas
- Set `this.code` untuk kode HTTP/kustom
- Gunakan `instanceof` untuk membedakan tipe error
- Penting: `stack` trace otomatis diwarisi dari Error

---

### Contoh Implementasi

```javascript
// Custom Error Class
class ValidationError extends Error {
  constructor(message, field) {
    super(message);
    this.name = 'ValidationError';
    this.field = field;
    this.code = 422;
  }
}

class AuthError extends Error {
  constructor(message) {
    super(message);
    this.name = 'AuthError';
    this.code = 401;
  }
}

class NotFoundError extends Error {
  constructor(resource, id) {
    super(`${resource} dengan id ${id} tidak ditemukan`);
    this.name = 'NotFoundError';
    this.code = 404;
    this.resource = resource;
    this.id = id;
  }
}

// Penggunaan
function findUser(id) {
  if (id <= 0) {
    throw new ValidationError('ID harus positif', 'id');
  }
  const user = database.find(id);
  if (!user) {
    throw new NotFoundError('User', id);
  }
  return user;
}

// Handler
try {
  findUser(-1);
} catch (err) {
  if (err instanceof ValidationError) {
    console.log(`Validasi gagal di field ${err.field}: ${err.message}`);
  } else if (err instanceof NotFoundError) {
    console.log(`Not found: ${err.message}`);
  } else if (err instanceof AuthError) {
    console.log('Auth error:', err.message);
  } else {
    console.log('Unknown error:', err);
  }
}
```

### Koneksi
- **194 →** Custom error ditangkap di blok catch
- **195 →** `throw` dengan custom error instance
- **196 →** Custom error mewarisi Error bawaan
- **198 →** Stack trace tetap tersedia di custom error
