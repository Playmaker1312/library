### Definisi Singkat

MVC (Model-View-Controller) adalah pola arsitektur yang memisahkan aplikasi menjadi tiga komponen utama: **Model** (data dan logika bisnis), **View** (tampilan UI), dan **Controller** (penghubung antara Model dan View). Pola ini memisahkan concerns sehingga lebih mudah dikelola dan diuji.

---

### Analogi

Seperti **restoran**:
- **Model** = Dapur — menyimpan resep dan bahan (data), tahu cara memasak (logika bisnis)
- **View** = Piring dan meja — tempat penyajian makanan (tampilan)
- **Controller** = Pelayan — menerima pesanan, menyampaikan ke dapur, mengantarkan ke meja

Pelayan tidak perlu tahu cara memasak; dapur tidak perlu tahu cara menyajikan.

---

### Poin-Poin Penting

- **Model** — data, validasi, logika bisnis, akses database. Tidak tahu tentang View/Controller
- **View** — menampilkan data ke user. Tidak tahu tentang Model/Controller secara langsung
- **Controller** — menerima input user, memanggil Model, memilih View. Otak koordinasi
- Aliran: User → Controller → Model → Controller → View → User
- Model memberi tahu View tentang perubahan (biasanya via Observer Pattern)
- Keuntungan: separation of concerns, testability, reusability
- Variasi: MVP, MVVM (Model-View-ViewModel) seperti di React/Vue

### Contoh Implementasi

```javascript
// Model
class TodoModel {
  constructor() {
    this.todos = [];
    this.listeners = [];
  }

  subscribe(listener) {
    this.listeners.push(listener);
  }

  notify() {
    this.listeners.forEach(l => l(this.todos));
  }

  addTodo(text) {
    this.todos.push({ id: Date.now(), text, completed: false });
    this.notify();
  }

  toggleTodo(id) {
    const todo = this.todos.find(t => t.id === id);
    if (todo) { todo.completed = !todo.completed; }
    this.notify();
  }

  deleteTodo(id) {
    this.todos = this.todos.filter(t => t.id !== id);
    this.notify();
  }
}

// View
class TodoView {
  constructor() {
    this.app = document.getElementById('app');
    this.app.innerHTML = `
      <input id="todo-input" placeholder="Tambah todo...">
      <button id="add-btn">Tambah</button>
      <ul id="todo-list"></ul>
    `;
    this.input = this.app.querySelector('#todo-input');
    this.list = this.app.querySelector('#todo-list');
    this.addBtn = this.app.querySelector('#add-btn');
  }

  render(todos) {
    this.list.innerHTML = todos.map(todo => `
      <li>
        <input type="checkbox" ${todo.completed ? 'checked' : ''} data-id="${todo.id}">
        <span style="${todo.completed ? 'text-decoration: line-through' : ''}">${todo.text}</span>
        <button data-id="${todo.id}" class="delete-btn">Hapus</button>
      </li>
    `).join('');
  }

  getInputValue() { return this.input.value; }
  clearInput() { this.input.value = ''; }
  bindAddTodo(handler) { this.addBtn.addEventListener('click', handler); }
  bindDeleteTodo(handler) {
    this.list.addEventListener('click', e => {
      if (e.target.classList.contains('delete-btn')) {
        handler(Number(e.target.dataset.id));
      }
    });
  }
  bindToggleTodo(handler) {
    this.list.addEventListener('change', e => {
      if (e.target.type === 'checkbox') {
        handler(Number(e.target.dataset.id));
      }
    });
  }
}

// Controller
class TodoController {
  constructor(model, view) {
    this.model = model;
    this.view = view;
    this.model.subscribe(todos => this.view.render(todos));
    this.view.bindAddTodo(() => this.handleAddTodo());
    this.view.bindDeleteTodo(id => this.handleDeleteTodo(id));
    this.view.bindToggleTodo(id => this.handleToggleTodo(id));
  }

  handleAddTodo() {
    const text = this.view.getInputValue().trim();
    if (text) { this.model.addTodo(text); this.view.clearInput(); }
  }

  handleDeleteTodo(id) { this.model.deleteTodo(id); }
  handleToggleTodo(id) { this.model.toggleTodo(id); }
}

// Inisialisasi
const app = new TodoController(new TodoModel(), new TodoView());
```

---

### Koneksi

MVC menggunakan **Observer Pattern** (file 230) untuk komunikasi Model → View. Pola ini adalah fondasi dari arsitektur aplikasi web modern seperti React (MVVM), Angular (MVC/MVVM), dan Vue (MVVM). Terkait juga dengan **Module Pattern** (file 227) untuk organisasi kode.
