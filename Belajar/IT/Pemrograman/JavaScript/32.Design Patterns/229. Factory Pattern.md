### Definisi Singkat

Factory Pattern adalah pola desain yang menggunakan fungsi (factory function) untuk **membuat objek** tanpa menggunakan keyword `new` atau menentukan class secara eksplisit. Factory function mengembalikan objek baru setiap kali dipanggil, memungkinkan pembuatan objek yang fleksibel dan reusable.

---

### Analogi

Seperti **mesin cetak kue** — Anda memasukkan adonan (parameter), mesin (factory) menghasilkan kue (objek) dengan bentuk tertentu. Anda bisa meminta kue bulat, kotak, atau bintang — tanpa perlu tahu bagaimana adonan dicetak. Setiap kue adalah objek baru.

---

### Poin-Poin Penting

- Fungsi factory mengembalikan objek baru tanpa `new`
- Lebih fleksibel daripada class constructor
- Bisa menyembunyikan kompleksitas pembuatan objek
- Mendukung **composition** lebih baik daripada inheritance
- Bisa mengembalikan tipe objek berbeda berdasarkan kondisi
- Tidak ada masalah dengan `this` binding (karena tidak pakai class)
- Cocok untuk dependency injection dan testing

---

### Contoh Implementasi

```javascript
// Factory function sederhana
function createUser(name, role) {
  return {
    name,
    role,
    createdAt: new Date(),
    greet() {
      return `Halo, saya ${this.name} (${this.role})`;
    },
    canAccess(resource) {
      const permissions = {
        admin: ['all'],
        editor: ['edit', 'view'],
        viewer: ['view']
      };
      return permissions[this.role]?.includes(resource) ||
             permissions[this.role]?.includes('all') || false;
    }
  };
}

const admin = createUser('Budi', 'admin');
const editor = createUser('Ani', 'editor');
console.log(admin.greet()); // "Halo, saya Budi (admin)"
console.log(admin.canAccess('edit')); // true
console.log(editor.canAccess('delete')); // false

// Factory dengan object assign
function createLogger(prefix) {
  return {
    info: (msg) => console.log(`[${prefix}][INFO] ${msg}`),
    warn: (msg) => console.warn(`[${prefix}][WARN] ${msg}`),
    error: (msg) => console.error(`[${prefix}][ERROR] ${msg}`)
  };
}

const appLogger = createLogger('App');
appLogger.info('Aplikasi berjalan');

// Factory dengan komposisi
function withLogging(obj) {
  return {
    ...obj,
    log(method, ...args) {
      console.log(`${method} dipanggil dengan:`, args);
      return obj[method](...args);
    }
  };
}
```

### Koneksi

Factory Pattern adalah alternatif dari constructor/class di JavaScript. Terkait dengan **Pure Functions** (file 221) — factory function yang pure lebih mudah di-test. Juga terkait dengan **Module Pattern** (file 227) dan **Singleton** (file 228) sebagai cara mengelola instance.
