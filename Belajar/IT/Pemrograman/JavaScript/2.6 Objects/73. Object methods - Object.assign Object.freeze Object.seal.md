# 73. Object methods - Object.assign Object.freeze Object.seal

**Definisi Singkat:** Methods untuk menggabungkan object, mencegah perubahan properti (freeze), dan mencegah penambahan (seal).

**Analogi:** `assign` seperti menggabungkan dua resep; `freeze` seperti memfoto dokumen (tidak bisa berubah); `seal` seperti papan tulis yang tidak bisa ditambah tulisan baru.

**Poin-Poin Penting:**
- `Object.assign(target, ...sources)` — copy properti, shallow merge
- `Object.freeze(obj)` — membuat object immutable total (no add/delete/change)
- `Object.seal(obj)` — mencegah add/delete, tapi bisa ubah existing
- `Object.isFrozen()` dan `Object.isSealed()` untuk cek status
- Semua bersifat *shallow* (tidak mendalam ke nested object)

**Contoh Kode:**
```javascript
const defaults = { a: 1, b: 2 };
const overrides = { b: 3, c: 4 };
const merged = Object.assign({}, defaults, overrides);
console.log(merged);

const frozen = Object.freeze({ x: 10 });
frozen.x = 20; // silent fail (strict: error)
console.log(frozen.x);
```
Hasil:
```
{ a: 1, b: 3, c: 4 }
10
```

**Kasus Penggunaan Nyata:**
Merge konfigurasi default dengan user setting, immutable state management, constant objects.
