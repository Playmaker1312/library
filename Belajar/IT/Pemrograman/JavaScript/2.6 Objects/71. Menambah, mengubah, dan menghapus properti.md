### Definisi Singkat

Object di JavaScript bersifat **mutable** — propertinya bisa ditambah, diubah, atau dihapus setelah object dibuat. Ini dilakukan dengan assignment (=) untuk menambah/mengubah, dan operator delete untuk menghapus.

---

### Analogi

Bayangkan sebuah papan whiteboard:

- **Menambah properti:** Seperti menulis catatan baru di papan: papan.catatanBaru = "isi".
- **Mengubah properti:** Seperti menghapus tulisan lama dan menulis ulang: papan.catatanLama = "isi baru".
- **Menghapus properti:** Seperti menghapus total catatan dari papan: delete papan.catatanLama.

---

### Poin-Poin Penting

- **Menambah:** Cukup assign nilai ke properti yang belum ada: obj.prop = value.
- **Mengubah:** Assign nilai ke properti yang sudah ada: obj.prop = newValue.
- **Menghapus:** Gunakan operator delete: delete obj.prop. Mengembalikan oolean.
- delete hanya menghapus properti sendiri (own property), bukan dari prototype chain.
- delete tidak bisa menghapus properti yang **non-configurable** (seperti properti dari object bawaan).
- Menghapus properti yang tidak ada tidak error — mengembalikan 	rue.

---

### Contoh Implementasi

`javascript
const user = { nama: "Budi", usia: 25 };

// Menambah properti
user.aktif = true;
user["alamat"] = "Jakarta";
console.log(user); // { nama: "Budi", usia: 25, aktif: true, alamat: "Jakarta" }

// Mengubah properti
user.usia = 26;
user.nama = "Budianto";
console.log(user.usia); // 26
console.log(user.nama); // "Budianto"

// Menghapus properti
delete user.alamat;
console.log(user.alamat); // undefined
console.log(user); // { nama: "Budianto", usia: 26, aktif: true }

// Hati-hati dengan const
// const melindungi binding, bukan properti
// user = {}; // Error!
// Tapi propertinya bisa dimodifikasi
user.propBaru = "test"; // OK
`

---

### Koneksi

Kemampuan CRUD properti ini penting untuk **Object methods** seperti Object.assign (materi 73) untuk menggabungkan object, dan Object.freeze untuk mencegah modifikasi. Juga terkait dengan **nested objects** (materi 78).
