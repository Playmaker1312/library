# 70. Mengakses properti - dot notation vs bracket notation

**Definisi Singkat:** Properti object diakses dengan `.` (dot) atau `["key"]` (bracket).

**Analogi:** Dot notation seperti memanggil nama teman langsung; bracket notation seperti memberi nama di selembar kertas.

**Poin-Poin Penting:**
- Dot notation lebih bersih, tapi properti harus identifier valid
- Bracket notation untuk properti dengan spasi, angka, atau dinamis
- Bracket notation menerima ekspresi: `obj["key" + i]`
- Akses properti yang tidak ada menghasilkan `undefined`

**Contoh Kode:**
```javascript
const user = { "nama-depan": "Rina", usia: 22 };
console.log(user.usia);
console.log(user["nama-depan"]);

const key = "usia";
console.log(user[key]);
```
Hasil:
```
22
Rina
22
```

**Kasus Penggunaan Nyata:**
Dot untuk properti statis; bracket untuk properti dinamis seperti `event.target.name`.
