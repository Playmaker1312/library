### Definisi Singkat

**Object.keys**, **Object.values**, dan **Object.entries** adalah method statis untuk mengambil daftar properti dari object. keys mengembalikan array nama properti, alues array nilai, dan entries array pasangan [key, value].

---

### Analogi

Bayangkan sebuah buku alamat:

- **Object.keys:** Membuat daftar nama semua orang yang ada di buku alamat.
- **Object.values:** Membuat daftar nomor telepon semua orang.
- **Object.entries:** Membuat daftar kartu yang masing-masing berisi [nama, nomor].

---

### Poin-Poin Penting

- **Object.keys(obj):** Mengembalikan array berisi **nama properti** (key) yang enumerable.
- **Object.values(obj):** Mengembalikan array berisi **nilai** dari properti yang enumerable.
- **Object.entries(obj):** Mengembalikan array berisi array [key, value].
- Ketiganya hanya mengembalikan **own properties** (bukan dari prototype chain).
- Urutan properti: integer keys ascending, string keys sesuai urutan pembuatan.
- Berguna untuk **iterasi** dan **transformasi** object.

---

### Contoh Implementasi

`javascript
const user = {
  nama: "Budi",
  usia: 25,
  kota: "Jakarta"
};

// Object.keys
const kunci = Object.keys(user);
console.log(kunci); // ["nama", "usia", "kota"]

// Object.values
const nilai = Object.values(user);
console.log(nilai); // ["Budi", 25, "Jakarta"]

// Object.entries
const entri = Object.entries(user);
console.log(entri);
// [["nama", "Budi"], ["usia", 25], ["kota", "Jakarta"]]

// Iterasi dengan for...of
for (const [key, value] of Object.entries(user)) {
  console.log(${key}: );
}

// Transformasi object ke array lain
const daftarNama = Object.values(user)
  .filter(v => typeof v === "string");
console.log(daftarNama); // ["Budi", "Jakarta"]
`

---

### Koneksi

Method ini adalah fondasi untuk **iterasi object** dan sering digunakan bersama **Array methods** (materi 64) untuk transformasi data. Juga terkait dengan **Object destructuring** (materi 74) untuk ekstraksi data.
