# 78. Nested objects - object di dalam object

**Definisi Singkat:** Object bisa memiliki properti yang juga berupa object — menciptakan struktur hierarkis.

**Analogi:** Seperti alamat rumah: di dalam data orang ada alamat, di dalam alamat ada jalan, kota, kode pos.

**Poin-Poin Penting:**
- Akses nested dengan chaining: `obj.a.b.c`
- Gunakan optional chaining `?.` untuk aman dari undefined
- Destructuring bisa nested: `const { a: { b } } = obj`
- Spread operator hanya shallow copy — nested object tetap reference

**Contoh Kode:**
```javascript
const user = {
  nama: "Citra",
  alamat: {
    jalan: "Jl. Merdeka No.5",
    kota: "Jakarta",
  },
  kontak: {
    email: "citra@mail.com",
  },
};
console.log(user.alamat.kota);
console.log(user.kontak?.telepon ?? "Tidak ada");
```
Hasil:
```
Jakarta
Tidak ada
```

**Kasus Penggunaan Nyata:**
Data user dengan alamat dan kontak, konfigurasi bertingkat, response API yang kompleks.
