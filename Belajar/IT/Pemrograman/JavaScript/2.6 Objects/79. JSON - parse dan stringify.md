# 79. JSON - parse dan stringify

**Definisi Singkat:** `JSON.parse()` mengubah string JSON ke object; `JSON.stringify()` mengubah object ke string JSON.

**Analogi:** `stringify` seperti mengemas barang dalam kardus (format kirim); `parse` seperti membuka kardus dan mengeluarkan isinya.

**Poin-Poin Penting:**
- JSON hanya support: string, number, boolean, null, array, object
- `JSON.stringify(obj, replacer, space)` — bisa diformat dengan spasi
- `JSON.parse(str)` — throw error jika string tidak valid
- Function, undefined, Symbol akan dihilangkan saat stringify
- `JSON.parse(JSON.stringify(obj))` untuk deep clone sederhana

**Contoh Kode:**
```javascript
const user = { nama: "Eko", usia: 30, aktif: true };
const json = JSON.stringify(user, null, 2);
console.log(json);

const parsed = JSON.parse(json);
console.log(parsed);
```
Hasil:
```
{
  "nama": "Eko",
  "usia": 30,
  "aktif": true
}
{ nama: 'Eko', usia: 30, aktif: true }
```

**Kasus Penggunaan Nyata:**
Komunikasi API (request/response), menyimpan data ke localStorage, konfigurasi file.
