# 72. Object methods - Object.keys Object.values Object.entries

**Definisi Singkat:** Methods static untuk mengambil key, value, atau pasangan [key, value] dari object.

**Analogi:** Seperti membuat laporan inventaris: keys (daftar nama barang), values (jumlah barang), entries (daftar lengkap nama + jumlah).

**Poin-Poin Penting:**
- `Object.keys(obj)` mengembalikan array berisi key (string)
- `Object.values(obj)` mengembalikan array berisi value
- `Object.entries(obj)` mengembalikan array `[key, value]`
- Hasilnya bisa diiterasi dengan `for...of` atau array methods
- Hanya properti *enumerable* milik sendiri (bukan prototype)

**Contoh Kode:**
```javascript
const user = { nama: "Sari", usia: 27, kota: "Bandung" };
console.log(Object.keys(user));
console.log(Object.values(user));
console.log(Object.entries(user));

for (const [k, v] of Object.entries(user)) {
  console.log(`${k}: ${v}`);
}
```
Hasil:
```
[ 'nama', 'usia', 'kota' ]
[ 'Sari', 27, 'Bandung' ]
[ [ 'nama', 'Sari' ], [ 'usia', 27 ], [ 'kota', 'Bandung' ] ]
nama: Sari
usia: 27
kota: Bandung
```

**Kasus Penggunaan Nyata:**
Transformasi data object ke format lain, iterasi properti, konversi ke Map.
