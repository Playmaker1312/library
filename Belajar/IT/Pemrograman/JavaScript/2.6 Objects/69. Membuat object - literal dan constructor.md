# 69. Membuat object - literal dan constructor

**Definisi Singkat:** Object bisa dibuat dengan `{}` (literal) atau `new Object()` / konstruktor custom.

**Analogi:** Seperti KTP — object literal ibarat isi formulir langsung; constructor seperti cetak KTP dengan mesin.

**Poin-Poin Penting:**
- Object literal `{}` adalah cara paling umum
- `new Object()` jarang dipakai (setara dengan `{}`)
- Constructor function / class untuk membuat banyak object serupa
- Object literal bisa langsung berisi properti dan method

**Contoh Kode:**
```javascript
const user1 = { nama: "Adi", umur: 25 };
console.log(user1);

class Person {
  constructor(nama, umur) {
    this.nama = nama;
    this.umur = umur;
  }
}
const user2 = new Person("Budi", 30);
console.log(user2);
```
Hasil:
```
{ nama: 'Adi', umur: 25 }
Person { nama: 'Budi', umur: 30 }
```

**Kasus Penggunaan Nyata:**
Data user, konfigurasi, response API — semuanya menggunakan object literal.
