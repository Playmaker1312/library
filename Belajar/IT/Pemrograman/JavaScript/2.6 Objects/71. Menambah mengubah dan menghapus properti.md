# 71. Menambah mengubah dan menghapus properti

**Definisi Singkat:** Properti object bisa ditambah, diubah, atau dihapus setelah object dibuat.

**Analogi:** Seperti papan whiteboard — bisa tulis info baru (tambah), hapus pakai penghapus (hapus), atau tulis ulang (ubah).

**Poin-Poin Penting:**
- Tambah/ubah: `obj.prop = value` atau `obj["prop"] = value`
- Hapus: `delete obj.prop` (menghapus properti sepenuhnya)
- `delete` hanya punya efek pada properti langsung (bukan prototype)
- Properti yang dihapus menghasilkan `undefined`
- `delete` mengembalikan `true` jika berhasil

**Contoh Kode:**
```javascript
const mobil = { merek: "Toyota" };
mobil.tahun = 2020;
mobil.merek = "Honda";
console.log(mobil);
delete mobil.tahun;
console.log(mobil);
```
Hasil:
```
{ merek: 'Honda', tahun: 2020 }
{ merek: 'Honda' }
```

**Kasus Penggunaan Nyata:**
Update state di aplikasi, menghapus field sensitif sebelum kirim data ke client.
