### Definisi Singkat

Properti object dapat diakses menggunakan **dot notation** (object.properti) atau **bracket notation** (object["properti"]). Dot notation lebih ringkas, sedangkan bracket notation lebih fleksibel.

---

### Analogi

Bayangkan sebuah lemari arsip:

- **Dot notation:** Seperti membuka laci dengan label — Anda harus tahu persis nama lacinya.
- **Bracket notation:** Seperti mencari laci menggunakan kertas petunjuk — nama laci bisa ditulis di kertas, bisa dari variabel.

---

### Poin-Poin Penting

- **Dot notation (obj.key):** 
  - Lebih ringkas dan mudah dibaca.
  - Key harus berupa **identifier valid** (tanpa spasi, tanpa karakter khusus).
  - Tidak bisa menggunakan variabel sebagai key.
- **Bracket notation (obj["key"]):**
  - Key bisa berupa **string apa saja** (termasuk yang ada spasinya).
  - Bisa menggunakan **variabel** atau **ekspresi** sebagai key.
  - Lebih fleksibel tapi lebih panjang penulisannya.
- Jika properti tidak ada, kedua notation mengembalikan undefined.

---

### Contoh Implementasi

`javascript
const user = {
  nama: "Budi",
  usia: 25,
  "alamat rumah": "Jakarta"
};

// Dot notation
console.log(user.nama); // "Budi"
console.log(user.usia); // 25

// Bracket notation
console.log(user["nama"]);         // "Budi"
console.log(user["alamat rumah"]); // "Jakarta"

// Bracket dengan variabel
const key = "usia";
console.log(user[key]); // 25

// Bracket dengan ekspresi
const prefix = "nama";
console.log(user[prefix]); // "Budi"

// Dot notation tidak bisa untuk key dengan spasi
// user.alamat rumah // Error!

// Menambah properti baru
user.email = "budi@email.com";
user["no telepon"] = "08123456789";
`

---

### Koneksi

Pemahaman tentang akses properti adalah dasar untuk **CRUD properti** (materi 71) dan **Object destructuring** (materi 74). Bracket notation sangat penting untuk **Computed Property Names** (materi 77).
