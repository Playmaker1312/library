### Definisi Singkat

**Computed property names** adalah fitur ES6 yang memungkinkan penggunaan **ekspresi** (seperti variabel atau operasi) sebagai nama properti di dalam object literal. Ekspresi ditulis di dalam kurung siku [].

---

### Analogi

Bayangkan Anda memiliki lemari arsip dengan label yang dibuat oleh mesin:

- Biasanya Anda menulis label manual: { "Buku A": ... }.
- Dengan computed property, label bisa dibuat otomatis: { [generateLabel()]: ... }.
- Label bisa berasal dari variabel, fungsi, atau operasi apa pun.

---

### Poin-Poin Penting

- **Sintaks:** { [expression]: value } — ekspresi di dalam [] akan dievaluasi menjadi string.
- Ekspresi bisa berupa **variabel**, **operasi matematika**, **string concatenation**, **function call**, dll.
- Computed property names hanya bekerja di **object literal** (waktu pembuatan), bukan saat mengakses properti.
- Persinggungan dengan **bracket notation** untuk akses — konsep serupa (menggunakan []), tapi untuk pembuatan.
- Bisa dikombinasikan dengan **shorthand property** dan method.

---

### Contoh Implementasi

`javascript
const key = "nama";
const prefix = "user_";

// Computed property names
const user = {
  [key]: "Budi",
  [prefix + "id"]: 123,
  ["usia_" + 2024]: 25,
  [status_]: "aktif"
};

console.log(user);
// { nama: "Budi", user_id: 123, usia_2024: 25, status_nama: "aktif" }

// Dengan method
const methodName = "sapa";
const orang = {
  nama: "Ani",
  [methodName]() {
    return Halo, ;
  }
};
console.log(orang.sapa()); // "Halo, Ani"

// Contoh di dunia nyata — mapping data
function buatObject(key, value) {
  return { [key]: value };
}
const obj = buatObject("warna", "merah");
console.log(obj); // { warna: "merah" }
`

---

### Koneksi

Computed property names terkait erat dengan **bracket notation** (materi 70). Sering digunakan dalam **Redux** untuk action types, atau saat membuat **mapping** data dinamis.
