### Definisi Singkat

**Shorthand property dan method** adalah fitur ES6 yang memungkinkan penulisan object literal lebih ringkas. Jika nama variabel sama dengan nama properti, cukup tulis sekali. Untuk method, bisa menghilangkan kata kunci unction.

---

### Analogi

Bayangkan Anda membuat formulir:

- **Tanpa shorthand:** 
ama: nama, usia: usia
- **Dengan shorthand:** cukup 
ama, usia — seperti mengatakan "ini isinya" tanpa mengulang.

Untuk method, bayangkan:
- **Tanpa shorthand:** jalan: function() {}
- **Dengan shorthand:** jalan() {} — langsung tulis nama method dan tubuhnya.

---

### Poin-Poin Penting

- **Shorthand property:** Jika variabel 
ama ingin menjadi properti 
ama, tulis { nama } bukan { nama: nama }.
- **Shorthand method:** Tulis method() {} bukan method: function() {}.
- Kode lebih bersih, ringkas, dan mudah dibaca.
- Bisa dikombinasikan dengan properti biasa.
- Shorthand method tetap memiliki akses ke 	his.

### Contoh Implementasi

`javascript
// Shorthand property
const nama = "Budi";
const usia = 25;

// Tanpa shorthand
const user1 = { nama: nama, usia: usia };

// Dengan shorthand
const user2 = { nama, usia };
console.log(user2); // { nama: "Budi", usia: 25 }

// Shorthand method
const kalkulator = {
  angka1: 10,
  angka2: 5,

  // Tanpa shorthand
  tambahLama: function() {
    return this.angka1 + this.angka2;
  },

  // Dengan shorthand method
  tambah() {
    return this.angka1 + this.angka2;
  },

  kurang() {
    return this.angka1 - this.angka2;
  }
};

console.log(kalkulator.tambah()); // 15
console.log(kalkulator.kurang()); // 5

// Kombinasi
const x = 10, y = 20;
const point = { x, y, display() { return (, ); } };
console.log(point.display()); // "(10, 20)"
`
