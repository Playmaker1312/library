# 51. Mengubah DOM

## Penjelasan
Setelah mengakses elemen DOM, kita bisa mengubah konten, atribut, atau gaya visualnya secara langsung dari JavaScript.

## Fungsi
Memperbarui tampilan halaman secara dinamis tanpa reload, seperti merenovasi ruangan di rumah.

## Cara Pengimplementasian
```html
<!DOCTYPE html>
<html>
<body>
  <h1 id="judul">Rumah Lama</h1>
  <p id="deskripsi" class="cat-lama">Dinding berwarna putih.</p>
  <input id="warna" value="biru">
  <button onclick="renovasi()">Renovasi!</button>

  <script>
    function renovasi() {
      // textContent — ganti teks (ganti papan nama rumah)
      document.getElementById('judul').textContent = 'Rumah Baru';

      // innerHTML — ganti teks dengan HTML (ganti dinding + hiasan)
      const desc = document.getElementById('deskripsi');
      desc.innerHTML = 'Dinding dicat <strong>biru laut</strong>.';

      // setAttribute — ganti atribut (ganti jenis cat)
      desc.setAttribute('class', 'cat-baru');

      // style — ubah CSS langsung (ganti warna cat)
      desc.style.backgroundColor = '#e0f0ff';
      desc.style.padding = '10px';

      // value — ubah input (ganti isi formulir)
      document.getElementById('warna').value = 'biru laut';
    }
  </script>
</body>
</html>
```

## Analogi
- `textContent` = mengganti papan nama di depan ruangan
- `innerHTML` = merenovasi total isi ruangan (termasuk dekorasi HTML)
- `setAttribute` = mengganti jenis cat dinding (class), ukuran pintu (width), dll
- `style.property` = mengecat langsung: ubah warna, padding, margin
- `value` = mengisi atau mengganti data di formulir tamu

## Dipakai Untuk Apa
- Update teks setelah aksi pengguna
- Validasi form (ubah border merah/hijau)
- Animasi CSS via class toggling
- Menampilkan data dari API

## Kesalahan Umum
1. **Menggunakan innerHTML untuk input pengguna** — rawan XSS. Gunakan `textContent` jika hanya teks.
2. **Lupa properti CSS pakai camelCase** — `backgroundColor` bukan `background-color`.
3. **Styling via JS berceceran** — lebih baik toggle class daripada set style satu-satu.
4. **Mengubah elemen yang belum ada di DOM** — pastikan elemen sudah dirender.

## Keterkaitan dengan Materi Sebelumnya
Sama seperti arsitek melihat denah dulu baru renovasi (Level 5 fetch data), setelah data diterima kita ubah DOM untuk menampilkannya.

## Soal Latihan
Buat tombol yang mengubah teks `<h1>` dari "Rumah" menjadi "Istana" saat diklik.

> !jawaban: `document.querySelector('h1').textContent = 'Istana';`!
