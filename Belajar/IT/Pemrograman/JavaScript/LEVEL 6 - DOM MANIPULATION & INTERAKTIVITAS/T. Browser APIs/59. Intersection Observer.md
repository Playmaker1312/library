# 59. Intersection Observer

## Penjelasan
Intersection Observer API memungkinkan kita mendeteksi kapan suatu elemen terlihat (atau menyentuh) viewport atau elemen induk tertentu — seperti CCTV yang otomatis mendeteksi orang masuk halaman rumah.

## Fungsi
Menjalankan kode ketika elemen masuk atau keluar dari area pandang, tanpa perlu event scroll yang berat.

## Cara Pengimplementasian
```html
<!DOCTYPE html>
<html>
<head>
  <style>
    .kamar {
      height: 300px;

      justify-content: center;

      transform: scale(0.9);
    }
    .kamar.terlihat {
      opacity: 1;
      transform: scale(1);
      border-color: #4CAF50;
      background: #e8f5e9;
    }
    .kamar:nth-child(odd) { background: #fff3e0; }
    #indikator {
      position: fixed;
      top: 10px;
      right: 10px;
      background: #333;
      color: white;
      padding: 8px 16px;
      border-radius: 4px;
      font-size: 0.9em;
    }
  </style>
</head>
<body>
  <h1>🏠 Tur Rumah — Intersection Observer</h1>
  <div id="indikator">Memantau: -</div>

  <!-- CCTV akan mendeteksi setiap kamar yang muncul di layar -->
  <div class="kamar" data-nama="Ruang Tamu">🛋️ Ruang Tamu</div>
  <div class="kamar" data-nama="Dapur">🍳 Dapur</div>
  <div class="kamar" data-nama="Kamar Tidur Utama">🛏️ Kamar Tidur Utama</div>
  <div class="kamar" data-nama="Kamar Anak">🧸 Kamar Anak</div>
  <div class="kamar" data-nama="Ruang Kerja">💼 Ruang Kerja</div>
  <div class="kamar" data-nama="Garasi">🚗 Garasi</div>
  <div class="kamar" data-nama="Taman Belakang">🌻 Taman Belakang</div>

  <script>
    const indikator = document.getElementById('indikator');

    // --- Pasang CCTV ---
    // argumen 1: callback saat intersection berubah
    // argumen 2: options (threshold, rootMargin)
    const cctv = new IntersectionObserver((entries) => {
      entries.forEach(entry => {
        const nama = entry.target.dataset.nama;

        if (entry.isIntersecting) {
          // 🟢 Ruangan terlihat di layar
          entry.target.classList.add('terlihat');
          indikator.textContent = `📍 Sedang di: ${nama}`;
          console.log(`👀 ${nama} — tamu masuk ruangan!`);
        } else {
          // 🔴 Ruangan meninggalkan layar
          entry.target.classList.remove('terlihat');
          console.log(`🚶 ${nama} — tamu keluar ruangan.`);
        }
      });
    }, {
      threshold: 0.5 // 50% dari elemen harus terlihat
    });

    // --- Pasang CCTV di setiap kamar ---
    document.querySelectorAll('.kamar').forEach(kamar => {
      cctv.observe(kamar); // mulai memantau
    });

    // --- Contoh: lazy loading gambar (analogi: CCTV untuk paket) ---
```

## Analogi
- **Intersection Observer** = **CCTV otomatis di halaman rumah**. Kamera memantau area tertentu (viewport).
- **`observe(elemen)`** = pasang CCTV di depan pintu kamar — mulai pantau kamar itu
- **`unobserve(elemen)`** = lepas CCTV dari kamar tertentu
- **`disconnect()`** = matikan semua CCTV di rumah
- **`isIntersecting`** = CCTV mendeteksi: "Ada orang masuk halaman!" (true) / "Orang keluar halaman" (false)
- **`threshold: 0.5`** = atur sensitivitas: baru terdeteksi jika 50% ruangan terlihat
- **`rootMargin`** = perluas area pantau: CCTV bisa deteksi orang 100px sebelum masuk halaman

## Dipakai Untuk Apa
- **Lazy loading gambar/iframe** — gambar hanya di-load saat mendekati viewport
- **Infinite scroll** — trigger load konten baru saat footer terlihat
- **Animasi scroll** — elemen muncul dengan animasi saat masuk viewport
- **Ads tracking** — apakah iklan benar-benar terlihat oleh pengguna
- **Read tracking** — apakah artikel/ruangan sudah dibaca/dilihat

## Kesalahan Umum
1. **Bingung dengan scroll event** — IO lebih efisien (tidak perlu hitung posisi manual).
2. **Threshold terlalu kecil (0)** — callback terpicu terus-menerus. Atur threshold sesuai kebutuhan (0.1, 0.5, dll).
3. **Lupa unobserve setelah elemen selesai diproses** — untuk lazy loading, lepas observer setelah gambar di-load.
4. **Tidak handle fallback** — browser lama tidak support IO. Sediakan fallback (selalu load).
5. **Over-observe** — jangan observe ribuan elemen sekaligus jika tidak perlu.

## Keterkaitan dengan Materi Sebelumnya
Level 5 (async) dan fetch untuk infinite scroll: Intersection Observer mendeteksi "pengguna hampir sampai bawah" → fetch data baru → DOM manipulation.

## Soal Latihan
Gunakan Intersection Observer untuk menambahkan class "muncul" ke elemen `<div id="ruang-tamu">` saat 30% elemen terlihat.
