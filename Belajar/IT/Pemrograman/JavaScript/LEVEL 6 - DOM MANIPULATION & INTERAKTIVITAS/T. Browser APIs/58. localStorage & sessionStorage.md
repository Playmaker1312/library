# 58. localStorage & sessionStorage

## Penjelasan
Web Storage API menyediakan dua cara menyimpan data key-value di browser pengguna: `localStorage` (data bertahan setelah browser ditutup) dan `sessionStorage` (data hilang saat tab ditutup).

## Fungsi
Menyimpan data di sisi klien agar tidak hilang saat navigasi atau refresh halaman.

## Cara Pengimplementasian
```html
<!DOCTYPE html>
<html>
<body>
  <h1>🏠 Lemari Arsip Rumah</h1>
  <p>Data tersimpan akan tetap ada meskipun halaman di-refresh (localStorage).</p>

  <div>
    <label>Nama Pemilik Rumah:</label>
    <input type="text" id="namaPemilik" placeholder="Masukkan nama">
  </div>
  <div style="margin: 8px 0;">
    <label>Warna Cat Favorit:</label>
    <input type="text" id="warnaCat" placeholder="cth: Biru">
  </div>

  <button onclick="simpan()">📁 Simpan ke Lemari Arsip</button>
  <button onclick="tampilkan()">📂 Tampilkan Arsip</button>
  <button onclick="hapusSemua()">🗑️ Kosongkan Lemari</button>

  <div id="arsip" style="margin-top: 12px; padding: 8px; background: #f5f5f5;"></div>

  <script>
    // localStorage == lemari arsip besar (tahan lama)
    // sessionStorage == kertas tempelan sementara

    function simpan() {
      const nama = document.getElementById('namaPemilik').value;
      const warna = document.getElementById('warnaCat').value;

      // Simpan — seperti masukkan dokumen ke lemari arsip
      localStorage.setItem('namaPemilik', nama);
      localStorage.setItem('warnaCat', warna);

      // sessionStorage — catatan sementara
      sessionStorage.setItem('terakhirSimpan', new Date().toLocaleTimeString());

      alert('Data disimpan!');
    }

    function tampilkan() {
      // Baca — seperti buka lemari dan ambil dokumen
      const nama = localStorage.getItem('namaPemilik') || '(belum diisi)';
      const warna = localStorage.getItem('warnaCat') || '(belum diisi)';
      const terakhir = sessionStorage.getItem('terakhirSimpan') || '-';

      document.getElementById('arsip').innerHTML = `
        <strong>📜 Arsip Rumah:</strong><br>
        Pemilik: ${nama}<br>
        Warna Cat: ${warna}<br>
        Terakhir simpan (sesi ini): ${terakhir}
      `;
    }

    function hapusSemua() {
      localStorage.clear();
      document.getElementById('arsip').innerHTML = 'Lemari kosong.';
    }

    // localStorage hanya simpan string — untuk object, gunakan JSON
    function simpanObject() {
      const pengaturanRumah = {
        warnaDinding: 'Putih',
        jumlahKamar: 4,
        alarmAktif: true
      };
      localStorage.setItem('pengaturanRumah', JSON.stringify(pengaturanRumah));
    }

    function bacaObject() {
      const data = JSON.parse(localStorage.getItem('pengaturanRumah'));
      console.log(data.jumlahKamar); // 4
    }
  </script>
</body>
</html>
```

## Analogi
- **localStorage** = **lemari arsip besar di ruang bawah tanah**. Semua dokumen tetap ada meskipun kamu pergi dan pulang lagi besok (browser ditutup & dibuka).
- **sessionStorage** = **kertas tempelan di pintu kamar**. Catatan sementara — hilang saat kamu keluar rumah (tab ditutup).
- **setItem(key, value)** = masukkan dokumen ke dalam lemari dengan label
- **getItem(key)** = buka lemari dan ambil dokumen sesuai label
- **removeItem(key)** = buang dokumen tertentu
- **clear()** = kosongkan seluruh lemari

## Dipakai Untuk Apa
- Theme/user preferences (dark mode)
- Cart items di e-commerce
- Data form yang diisi (anti hilang jika refresh)
- Token autentikasi (hati-hati: lebih aman pakai httpOnly cookie)
- Game progress / score

## Kesalahan Umum
1. **Hanya bisa string** — jika simpan object, harus `JSON.stringify()`; baca harus `JSON.parse()`.
2. **Kapasitas terbatas** — ~5-10MB per domain. Jangan simpan gambar besar di sini.
3. **Synchronous / blocking** — operasi besar bisa freeze halaman sebentar.
4. **Tidak aman untuk data sensitif** — semua JS di domain yang sama bisa akses. Jangan simpan password/token di localStorage.
5. **Session storage hilang jika tab ditutup** — beda tab tidak bisa akses sessionStorage yang sama.

## Keterkaitan dengan Materi Sebelumnya
Level 5 (fetch) mengambil data dari server; `localStorage` bisa digunakan untuk cache hasil fetch agar tidak request ulang (offline-first).

## Soal Latihan
Simpan angka kunjungan ke localStorage. Setiap kali halaman dibuka, baca angka, tambah 1, simpan lagi, dan tampilkan "Kamu sudah berkunjung X kali".
