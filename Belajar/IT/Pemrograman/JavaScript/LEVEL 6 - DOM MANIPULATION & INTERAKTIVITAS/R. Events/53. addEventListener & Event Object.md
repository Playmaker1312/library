# 53. addEventListener & Event Object

## Penjelasan
Event adalah sinyal bahwa sesuatu terjadi di browser — klik, ketik, scroll, submit. `addEventListener` adalah cara mendaftarkan "satpam" yang akan bereaksi saat sinyal itu tiba. Event object berisi data detail tentang kejadian tersebut.

## Fungsi
Menangkap dan merespons interaksi pengguna dengan halaman web.

## Cara Pengimplementasian
```html
<!DOCTYPE html>
<html>
<body>
  <h1>Rumah Pintar</h1>
  <button id="belPintu">🔔 Bel Pintu</button>
  <input id="inputNama" placeholder="Nama tamu">
  <div id="log" style="margin-top: 12px;"></div>

  <script>
    const log = document.getElementById('log');

    // Daftarkan satpam di bel pintu — event click
    document.getElementById('belPintu').addEventListener('click', function(event) {
      log.innerHTML += `Bel berbunyi! Tombol diklik di posisi (${event.clientX}, ${event.clientY})<br>`;
    });

    // Event keyboard — siapa yang mengetik
    document.getElementById('inputNama').addEventListener('keydown', function(event) {
      log.innerHTML += `Tombol "${event.key}" ditekan (kode: ${event.code})<br>`;

      if (event.key === 'Enter') {
        log.innerHTML += `➡ Tamu "${this.value}" sudah masuk!<br>`;
      }
    });

    // Event object properti yang sering dipakai:
    // event.type       → "click", "keydown", dll
    // event.target     → elemen yang memicu event
    // event.currentTarget → elemen tempat listener dipasang
    // event.clientX/Y  → posisi mouse
    // event.key        → tombol keyboard
    // event.keyCode    → kode numerik tombol (deprecated, pakai .key)
  </script>
</body>
</html>
```

## Analogi
- **Event** = bel pintu berbunyi, telepon berdering, alarm kebakaran
- **`addEventListener`** = memasang perangkat pendeteksi di setiap titik rumah
- **Event object** = data yang dibawa sinyal: "pintu mana yang dibuka?", "jam berapa?", "siapa yang memencet?"
- **`event.target`** = sumber kejadian (pintu mana yang diketok)
- **`event.type`** = jenis kejadian (ketok pintu / telepon / alarm)

## Dipakai Untuk Apa
- Menangani klik tombol
- Validasi input real-time
- Navigasi keyboard
- Drag and drop
- Scroll & resize

## Kesalahan Umum
1. **Menggunakan `onclick` di HTML** — bercampur dengan JS. Lebih baik `addEventListener` terpisah.
2. **Lupa hapus listener dengan `removeEventListener`** — bisa menyebabkan memory leak. Harus referensi fungsi yang sama.
3. **Arrow function dan `this`** — arrow function tidak punya `this` sendiri; `this` di arrow mengacu ke lexical scope.
4. **Memanggil fungsi langsung di addEventListener** — tulis `addEventListener('click', handler)` bukan `addEventListener('click', handler())`.

## Keterkaitan dengan Materi Sebelumnya
Level 5 async mengatur timing (kapan data datang). Event mengatur interaktivitas (kapan pengguna melakukan sesuatu). Keduanya adalah pilar web dinamis.

## Soal Latihan
Pasang event listener pada tombol dengan id="alarm" yang ketika diklik menampilkan "Alamar rumah berbunyi!" di console, serta menampilkan koordinat klik dari event object.
