# 55. preventDefault & stopPropagation

## Penjelasan
Dua metode penting pada event object untuk mengontrol perilaku default browser dan perambatan event (bubbling) ke elemen induk.

## Fungsi
- `preventDefault()`: mencegah aksi bawaan browser (misal: link pindah halaman, form reload)
- `stopPropagation()`: menghentikan event naik (bubbling) ke elemen parent
- `stopImmediatePropagation()`: stop bubbling + cegah listener lain di elemen yang sama

## Cara Pengimplementasian
```html
<!DOCTYPE html>
<html>
<body>
  <h1>Kontrol Akses Rumah</h1>

  <!-- preventDefault: cegah link navigasi -->
  <a id="linkPintu" href="https://example.com">➡ Masuk ke rumah (klik saya)</a>
  <br><br>

  <!-- stopPropagation: cegah bubbling -->
  <div id="halaman" style="border: 2px solid green; padding: 20px;">
    🏡 Halaman Rumah
    <div id="teras" style="border: 2px solid blue; padding: 15px; margin-top: 8px;">
      🪑 Teras
      <button id="belPintu">🔔 Bel Pintu</button>
    </div>
  </div>

  <div id="log"></div>

  <script>
    const log = document.getElementById('log');

    // --- preventDefault() ---
    document.getElementById('linkPintu').addEventListener('click', function(e) {
      e.preventDefault(); // jangan pindah halaman
      log.innerHTML += '🔒 Pintu dikunci — tidak jadi keluar rumah.<br>';
    });

    // --- stopPropagation() ---
    document.getElementById('belPintu').addEventListener('click', function(e) {
      e.stopPropagation(); // berhenti — jangan beri tahu halaman dan teras
      log.innerHTML += '🔔 Bel pintu ditekan (hanya diproses di sini).<br>';
    });

    document.getElementById('teras').addEventListener('click', function() {
      log.innerHTML += '🏠 Teras mendengar bunyi (ini tidak akan muncul jika stopPropagation dipanggil).<br>';
    });

    document.getElementById('halaman').addEventListener('click', function() {
      log.innerHTML += '🌳 Halaman mendengar bunyi (ini juga tidak akan muncul).<br>';
    });

    // --- stopImmediatePropagation() ---
    const btn = document.getElementById('belPintu');
    btn.addEventListener('click', function(e) {
      // Listener kedua ini tetap jalan jika hanya stopPropagation
      log.innerHTML += '🔊 Alarm tambahan...<br>';
    });
    btn.addEventListener('click', function(e) {
      e.stopImmediatePropagation(); // hentikan SEMUA — listener lain di skip
      log.innerHTML += '🚨 STOP! Listener lain tidak akan dijalankan.<br>';
    });
    btn.addEventListener('click', function() {
      log.innerHTML += '❌ Listener ini tidak akan pernah jalan.<br>';
    });
  </script>
</body>
</html>
```

## Analogi
- **Tanpa stopped** = Tamu masuk halaman → ke teras → masuk rumah (bubbling penuh)
- **`stopPropagation()`** = Satpam di teras menghentikan tamu: "Berhenti, urusannya cukup di sini, jangan masuk ke dalam rumah."
- **`preventDefault()`** = Mencegah pintu otomatis terbuka (link navigasi). Pintu tetap terkunci.
- **`stopImmediatePropagation()`** = Satpam super tegas: "Semua urusan dihentikan, termasuk satpam lain di teras ini."

## Dipakai Untuk Apa
- **preventDefault**: Form validation (cegah submit jika tidak valid), custom link, drag & drop, context menu custom
- **stopPropagation**: Modal klik di luar tutup, nested menu, komponen yang terisolasi

## Kesalahan Umum
1. **Lupa preventDefault di form** — halaman reload saat submit, padahal mau pakai JS.
2. **Overusing stopPropagation** — bisa memecah fitur lain yang bergantung pada bubbling (event delegation jadi rusak).
3. **Menganggap stopPropagation menghentikan semua event** — hanya menghentikan bubbling ke parent, bukan event lain di elemen yang sama.
4. **Memanggil preventDefault tapi tidak return false** — di jQuery beda, di JS modern pakai preventDefault() saja.

## Keterkaitan dengan Materi Sebelumnya
Di Level 5 (fetch), `preventDefault` pada form mencegah reload agar `fetch` bisa menangani submit secara asinkron.
