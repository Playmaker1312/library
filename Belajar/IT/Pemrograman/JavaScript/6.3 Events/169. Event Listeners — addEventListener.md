### Definisi Singkat
**`addEventListener()`** adalah method untuk mendaftarkan function (event handler) yang akan dipanggil ketika event tertentu terjadi pada elemen target. Method ini menerima tipe event, callback function, dan opsi opsional (capture, once, passive).

---

### Analogi
Seperti **memasang bel pintu**. Kamu memasang bel (`addEventListener`) yang akan berbunyi (`callback`) ketika ada tamu menekan tombol (`event`). Kamu bisa pasang beberapa bel di pintu yang sama.

---

### Poin-Poin Penting
- Sintaks: `element.addEventListener(type, listener, options)`
- Bisa multiple listeners untuk event yang sama pada elemen yang sama
- Tidak mengganti event handler inline seperti `onclick`
- `options`: `capture`, `once`, `passive`
- Hapus listener dengan `removeEventListener(type, listener)`
- Arrow function tidak bisa di-remove karena anonymous

---

### Contoh Implementasi

```javascript
const btn = document.querySelector('button');

// Basic
btn.addEventListener('click', function() {
  console.log('Tombol diklik!');
});

// Dengan opsi
btn.addEventListener('click', () => {
  alert('Sekali saja!');
}, { once: true }); // Hanya sekali

// Multiple listeners
btn.addEventListener('click', () => console.log('Pertama'));
btn.addEventListener('click', () => console.log('Kedua'));

// Named function — bisa di-remove
function handleClick() {
  console.log('Handler di-remove');
}
btn.addEventListener('click', handleClick);
btn.removeEventListener('click', handleClick);

// Passive — tidak preventDefault
document.addEventListener('touchstart', () => {
  // handling touch
}, { passive: true });
```
