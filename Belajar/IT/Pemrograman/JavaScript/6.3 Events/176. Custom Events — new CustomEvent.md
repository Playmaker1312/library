### Definisi Singkat
**CustomEvent** memungkinkan kita membuat dan mengirim event kustom sendiri menggunakan `new CustomEvent(type, options)`. Event ini bisa dikirim ke elemen mana pun dengan `dispatchEvent()` dan ditangkap dengan `addEventListener()` seperti event biasa.

---

### Analgi
CustomEvent seperti **sistem interkom kantor**. Kamu bisa membuat pengumuman sendiri (`buat event`) dan menyiarkannya ke semua ruangan (`dispatch`), lalu setiap ruangan yang mendengarkan channel tertentu (`addEventListener`) akan merespon.

---

### Poin-Poin Penting
- `new CustomEvent('nama-event', { detail: data })` — buat event
- `element.dispatchEvent(event)` — kirim event
- `detail` adalah properti untuk membawa data kustom
- Custom events juga bubble dan bisa di-cancel
- `bubbles: true` jika ingin event bubbling
- Event listener biasa: `element.addEventListener('nama-event', handler)`

---

### Contoh Implementasi

```javascript
// Membuat CustomEvent
const notifEvent = new CustomEvent('notifikasi', {
  detail: {
    pesan: 'Data berhasil disimpan!',
    tipe: 'success',
    timestamp: Date.now()
  },
  bubbles: true,
  cancelable: true
});

// Mendengarkan
document.addEventListener('notifikasi', (e) => {
  const { pesan, tipe } = e.detail;
  showToast(pesan, tipe);
  console.log('Notifikasi diterima:', e.detail);
});

// Mengirim
document.dispatchEvent(notifEvent);

// Contoh lebih terstruktur
class Cart {
  addItem(item) {
    // ... logika
    const event = new CustomEvent('cart:updated', {
      detail: { items: this.items, total: this.total() },
      bubbles: true
    });
    document.dispatchEvent(event);
  }
}

// Di komponen UI
document.addEventListener('cart:updated', (e) => {
  document.getElementById('cart-count').textContent = e.detail.items.length;
});
```
