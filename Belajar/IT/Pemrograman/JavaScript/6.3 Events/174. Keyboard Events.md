### Definisi Singkat
**Keyboard events** dipicu ketika pengguna menekan tombol di keyboard: **`keydown`** (saat tombol ditekan), **`keyup`** (saat tombol dilepas), dan **`keypress`** (sudah usang — hindari). Event ini biasanya dipasang di `document` atau elemen form.

---

### Analgi
Keyboard events seperti **penerjemah bahasa isyarat**. Setiap kali jari menekan tombol (`keydown`), penerjemah mencatat tombol apa (`key`) dan kodenya (`code`), lalu melaporkan saat jari diangkat (`keyup`).

---

### Poin-Poin Penting
- `keydown` dan `keyup` adalah event standar — selalu gunakan ini
- `keypress` sudah deprecated (tidak konsisten antar browser)
- **`event.key`** — karakter yang dihasilkan (`'a'`, `'Enter'`, `'ArrowUp'`)
- **`event.code`** — kode fisik tombol (`'KeyA'`, `'Enter'`, `'ArrowUp'`)
- `event.repeat` — `true` jika tombol ditahan (auto-repeat)
- Properti modifier: `ctrlKey`, `shiftKey`, `altKey`, `metaKey`
- Keyboard events hanya bubble untuk elemen focusable

---

### Contoh Implementasi

```javascript
document.addEventListener('keydown', (e) => {
  console.log(`Key: ${e.key}, Code: ${e.code}, Repeat: ${e.repeat}`);

  // Shortcut Ctrl+S
  if (e.ctrlKey && e.key === 's') {
    e.preventDefault();
    console.log('Menyimpan...');
  }

  // Navigasi arrow
  if (e.key.startsWith('Arrow')) {
    e.preventDefault();
    console.log('Navigasi:', e.key);
  }

  // Deteksi tombol spesifik
  if (e.code === 'Escape') {
    console.log('Menutup modal...');
  }

  // Kombinasi shift
  if (e.shiftKey && e.key === '?') {
    console.log('Menampilkan bantuan');
  }
});

document.addEventListener('keyup', (e) => {
  console.log(`Tombol ${e.key} dilepas`);
});

// Hanya untuk input tertentu
const input = document.querySelector('input');
input.addEventListener('keydown', (e) => {
  if (e.key === 'Enter') {
    console.log('Submit:', input.value);
  }
});
```
