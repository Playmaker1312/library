### Definisi Singkat
**`preventDefault()`** dan **`stopPropagation()`** adalah dua method penting pada event object. `preventDefault()` membatalkan aksi default browser (misal klik link, submit form). `stopPropagation()` menghentikan event agar tidak naik (bubbling) atau turun (capturing).

---

### Analgi
- **preventDefault** seperti **menarik kembali undangan** — aksi default (tamu datang) dibatalkan
- **stopPropagation** seperti **memasang dinding kedap suara** — suara dari ruang dalam tidak terdengar ke ruang luar

---

### Poin-Poin Penting
- `preventDefault()` tidak menghentikan propagation — event tetap bubble
- `stopPropagation()` tidak mencegah aksi default
- `stopImmediatePropagation()` — hentikan propagation **dan** listener lain pada elemen yang sama
- `event.cancelable` — cek apakah event bisa di-prevent
- Jangan滥用 `stopPropagation()` — bisa mengganggu event delegation

---

### Contoh Implementasi

```javascript
// preventDefault
document.querySelector('a[href]').addEventListener('click', (e) => {
  e.preventDefault();
  console.log('Link tidak diikuti — navigasi dicegah');
});

document.querySelector('form').addEventListener('submit', (e) => {
  e.preventDefault();
  console.log('Form tidak dikirim — validasi manual');
});

document.addEventListener('keydown', (e) => {
  if (e.key === 'F12') {
    e.preventDefault(); // Cegah DevTools (sederhana)
  }
});

// stopPropagation
const btn = document.querySelector('button');
const wrapper = document.querySelector('.wrapper');

wrapper.addEventListener('click', () => console.log('Wrapper diklik'));
btn.addEventListener('click', (e) => {
  e.stopPropagation(); // Wrapper tidak akan menerima event
  console.log('Button diklik — propagation berhenti');
});

// stopImmediatePropagation
btn.addEventListener('click', (e) => {
  e.stopImmediatePropagation();
  console.log('Ini jalan');
});
btn.addEventListener('click', () => console.log('Ini TIDAK jalan')); // Dilewati
```

### Koneksi
- **169 →** Method ini dipanggil di dalam event listener
- **171 →** Propagation (bubbling/capturing) yang dihentikan
- **172 →** `stopPropagation()` bisa mengganggu event delegation
