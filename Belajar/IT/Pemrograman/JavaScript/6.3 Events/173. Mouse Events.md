### Definisi Singkat
**Mouse events** adalah event yang dipicu oleh interaksi mouse dengan elemen. Events utama: **`click`**, **`dblclick`**, **`mousedown`**, **`mouseup`**, **`mousemove`**, **`mouseover`**, **`mouseout`**, **`mouseenter`**, **`mouseleave`**, dan **`contextmenu`**.

---

### Analgi
Seperti **sensor gerak**. Ada sensor yang bereaksi saat tangan menyentuh (`mousedown`), saat dilepas (`mouseup`), saat melambai di atasnya (`mousemove`), dan saat masuk/keluar area (`mouseenter`/`mouseleave`).

---

### Poin-Poin Penting
- `click` = `mousedown` + `mouseup` pada elemen yang sama
- `mouseenter`/`mouseleave` tidak bubble (lebih bersih untuk hover)
- `mouseover`/`mouseout` bubble (termasuk ke child)
- `dblclick` untuk double-click
- `contextmenu` untuk klik kanan
- `mousemove` sangat sering terpicu — hati-hati performa
- Akses posisi: `clientX/Y` (viewport), `pageX/Y` (halaman), `screenX/Y` (layar)

---

### Contoh Implementasi

```javascript
const area = document.querySelector('.area');

// Klik tunggal dan ganda
area.addEventListener('click', () => console.log('Klik'));
area.addEventListener('dblclick', () => console.log('Double klik!'));

// Mouse down/up
area.addEventListener('mousedown', (e) => console.log('Tombol ditekan:', e.button));
area.addEventListener('mouseup', () => console.log('Tombol dilepas'));

// Pergerakan
area.addEventListener('mousemove', (e) => {
  console.log(`Posisi: ${e.clientX}, ${e.clientY}`);
});

// Hover (tidak bubble)
area.addEventListener('mouseenter', () => area.style.background = 'yellow');
area.addEventListener('mouseleave', () => area.style.background = '');

// Klik kanan
area.addEventListener('contextmenu', (e) => {
  e.preventDefault();
  console.log('Menu konteks dibuka');
});

// Drag sederhana
let isDragging = false;
element.addEventListener('mousedown', () => isDragging = true);
document.addEventListener('mousemove', (e) => {
  if (isDragging) element.style.transform = `translate(${e.clientX}px, ${e.clientY}px)`;
});
document.addEventListener('mouseup', () => isDragging = false);
```
