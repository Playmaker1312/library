### Definisi Singkat

**Object destructuring** adalah fitur ES6 yang memungkinkan ekstraksi properti dari object ke variabel terpisah dengan sintaks yang ringkas. Menggunakan pola kurung kurawal {} di sisi kiri assignment.

---

### Analogi

Bayangkan sebuah map perjalanan yang berisi informasi:

- Tanpa destructuring: 
ama = map.nama, 	ujuan = map.tujuan — mengambil satu per satu.
- Dengan destructuring: { nama, tujuan } = map — langsung membuka map dan mengambil semua yang dibutuhkan sekaligus.

---

### Poin-Poin Penting

- **Sintaks dasar:** const { prop } = obj — membuat variabel prop dengan nilai obj.prop.
- **Mengganti nama:** const { prop: alias } = obj — variabel akan bernama lias.
- **Default value:** const { prop = defaultVal } = obj — jika undefined, pakai default.
- **Nested destructuring:** const { a: { b } } = obj — destructuring object di dalam object.
- **Rest pattern:** const { a, ...rest } = obj — est berisi sisa properti.
- Bisa digunakan pada **parameter fungsi**.

---

### Contoh Implementasi

`javascript
const user = {
  id: 1,
  nama: "Budi",
  usia: 25,
  alamat: { kota: "Jakarta", negara: "Indonesia" }
};

// Destructuring dasar
const { nama, usia } = user;
console.log(nama, usia); // "Budi", 25

// Ganti nama variabel
const { nama: fullName, usia: age } = user;
console.log(fullName, age); // "Budi", 25

// Default value
const { email = "tidak ada" } = user;
console.log(email); // "tidak ada"

// Nested destructuring
const { alamat: { kota } } = user;
console.log(kota); // "Jakarta"

// Rest pattern
const { id, ...sisa } = user;
console.log(sisa); // { nama: "Budi", usia: 25, alamat: {...} }

// Destructuring di parameter fungsi
function tampilkanUser({ nama, usia }) {
  console.log(${nama} berusia  tahun);
}
tampilkanUser(user); // "Budi berusia 25 tahun"
`
