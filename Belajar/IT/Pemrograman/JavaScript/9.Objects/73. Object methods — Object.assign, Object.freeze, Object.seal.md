### Definisi Singkat

**Object.assign**, **Object.freeze**, dan **Object.seal** adalah method statis untuk mengelola dan mengontrol object. ssign menggabungkan object, reeze membuat object immutable total, dan seal mencegah penambahan/hapus properti.

---

### Analogi

- **Object.assign:** Seperti fotokopi dokumen — menyalin semua data dari satu dokumen ke dokumen lain.
- **Object.freeze:** Seperti dokumen yang sudah dimaterai dan ditandatangani — tidak bisa diubah, ditambah, atau dihapus.
- **Object.seal:** Seperti kotak tertutup — Anda tidak bisa menambah atau mengeluarkan isi, tapi bisa mengubah isi yang ada.

---

### Poin-Poin Penting

- **Object.assign(target, ...sources):** Menyalin properti dari sources ke 	arget. Mengembalikan 	arget. Shallow copy.
- **Object.freeze(obj):** Membuat object **sama sekali immutable** — tidak bisa tambah, hapus, atau ubah properti. Strict mode akan throw error, slient mode akan gagal diam-diam.
- **Object.seal(obj):** Mencegah penambahan dan penghapusan properti, tapi **nilai properti masih bisa diubah**.
- reeze dan seal bersifat **shallow** — hanya level teratas.

---

### Contoh Implementasi

`javascript
// Object.assign
const target = { a: 1 };
const source1 = { b: 2 };
const source2 = { c: 3, a: 99 };
Object.assign(target, source1, source2);
console.log(target); // { a: 99, b: 2, c: 3 }

// Untuk cloning
const asli = { x: 1, y: 2 };
const salinan = Object.assign({}, asli);
console.log(salinan); // { x: 1, y: 2 }

// Object.freeze
const konstanta = Object.freeze({ PI: 3.14 });
konstanta.PI = 3; // Gagal (strict mode: error)
console.log(konstanta.PI); // 3.14 (tidak berubah)

// Object.seal
const terbatas = Object.seal({ nama: "Budi", usia: 25 });
terbatas.usia = 26;  // Bisa (ubah nilai)
delete terbatas.nama; // Gagal (hapus)
terbatas.alamat = "Jakarta"; // Gagal (tambah)
console.log(terbatas); // { nama: "Budi", usia: 26 }
`

---

### Koneksi

Object.assign berkaitan dengan **spread operator pada object** (materi 75). Object.freeze digunakan dalam **Functional Programming** dan **state management** untuk memastikan immutability. Object.seal berguna untuk object dengan skema tetap.
