### Definisi Singkat

**JSON** (JavaScript Object Notation) adalah format pertukaran data ringan yang mirip dengan sintaks object JavaScript. **JSON.parse** mengubah string JSON menjadi object JavaScript, sedangkan **JSON.stringify** mengubah object JavaScript menjadi string JSON.

---

### Analogi

Bayangkan Anda ingin mengirim paket melalui pos:

- **JSON.stringify:** Seperti memasukkan barang (object) ke dalam kotak (string JSON) agar bisa dikirim.
- **JSON.parse:** Seperti membuka kotak dari pos dan mengeluarkan barangnya — dari string kembali ke object.

---

### Poin-Poin Penting

- **JSON.parse(jsonString):** Mengubah string JSON ke object JavaScript. Error jika format JSON tidak valid.
- **JSON.stringify(value, replacer, space):** Mengubah object/array ke string JSON.
- JSON hanya mendukung tipe data: **string, number, boolean, null, object, array**.
- **Tidak didukung:** undefined, unction, Symbol, Date (jadi string), Map, Set.
- Parameter eplacer bisa berupa array (properti yang disertakan) atau fungsi.
- Parameter space untuk formatting (indentasi) string JSON.

### Contoh Implementasi

`javascript
const user = {
  nama: "Budi",
  usia: 25,
  aktif: true,
  alamat: { kota: "Jakarta" },
  hobby: ["coding", "membaca"],
  sapa: function() { return "Halo"; } // akan dihilangkan!
};

// JSON.stringify
const jsonStr = JSON.stringify(user);
console.log(jsonStr);
// '{"nama":"Budi","usia":25,"aktif":true,"alamat":{"kota":"Jakarta"},"hobby":["coding","membaca"]}'

// Dengan formatting
const pretty = JSON.stringify(user, null, 2);
console.log(pretty);
/*
{
  "nama": "Budi",
  "usia": 25,
  "aktif": true,
  ...
}
*/

// JSON.parse
const jsonData = '{"nama":"Ani","usia":20}';
const parsed = JSON.parse(jsonData);
console.log(parsed.nama); // "Ani"
console.log(parsed.usia); // 20

// Error handling
try {
  JSON.parse("{invalid}");
} catch (e) {
  console.log("JSON tidak valid!");
}

// Deep clone dengan JSON
const clone = JSON.parse(JSON.stringify(user));
`

### Koneksi

JSON adalah fondasi pertukaran data di **Web API** dan **Fetch API**. Data dari server hampir selalu dalam format JSON. Juga terkait dengan **nested objects** (materi 78) karena JSON mendukung struktur bersarang.
