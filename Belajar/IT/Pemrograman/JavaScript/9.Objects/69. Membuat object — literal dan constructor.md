### Definisi Singkat

Object di JavaScript dapat dibuat dengan dua cara: **object literal** ({}) dan **constructor** (
ew Object()). Object literal adalah cara yang paling umum dan direkomendasikan karena lebih ringkas dan ekspresif.

---

### Analogi

Bayangkan sebuah formulir pendaftaran:

- **Object literal ({}):** Seperti formulir kosong siap isi — langsung tulis properti di dalamnya.
- **Object constructor (
ew Object()):** Seperti membeli formulir kosong lalu mengisinya — sama saja, tapi lebih panjang.

---

### Poin-Poin Penting

- **Object literal:** Gunakan kurung kurawal {}. Bisa diisi langsung: { nama: "Budi", usia: 25 }.
- **Object constructor:** Gunakan 
ew Object(). Jarang digunakan.
- Object literal lebih **cepat**, **ringkas**, dan **mudah dibaca**.
- Object bisa berisi **properti** (key-value) dan **method** (fungsi sebagai nilai).
- Property key bisa berupa **string** atau **Symbol**. JavaScript otomatis mengubah key menjadi string.
- Object adalah tipe data **mutable** — bisa diubah setelah dibuat.

---

### Contoh Implementasi

`javascript
// Object literal (cara yang benar)
const user = {
  nama: "Budi",
  usia: 25,
  aktif: true
};

// Object constructor (tidak direkomendasikan)
const user2 = new Object();
user2.nama = "Ani";
user2.usia = 17;

// Object dengan method
const kalkulator = {
  angka1: 10,
  angka2: 5,
  tambah() {
    return this.angka1 + this.angka2;
  }
};
console.log(kalkulator.tambah()); // 15

// Object bisa berisi properti dengan spasi (gunakan quotes)
const mobil = {
  "merk mobil": "Toyota",
  tahun: 2020
};
console.log(mobil["merk mobil"]); // "Toyota"
`

---

### Koneksi

Setelah object dibuat, kita bisa mengakses properti menggunakan **dot notation vs bracket notation** (materi 70), serta menambah, mengubah, dan menghapus properti (materi 71).
