### Definisi Singkat

**Nested objects** adalah object yang memiliki properti berupa object lain di dalamnya. Ini memungkinkan representasi data yang lebih kompleks dan terstruktur, seperti data pengguna dengan alamat, kontak, dan preferensi.

---

### Analogi

Bayangkan sebuah map folder di komputer:

- Folder utama = object.
- Sub-folder = nested object.
- File di dalam sub-folder = properti dari nested object.
- Anda bisa masuk ke folder A, lalu ke sub-folder B, lalu ke file C: olderA.subFolderB.fileC.

---

### Poin-Poin Penting

- **Akses nested:** Gunakan dot notation atau bracket notation bertingkat: obj.prop1.prop2.
- Akses properti yang tidak ada di nested object akan menghasilkan **TypeError** (Cannot read property of undefined) — gunakan **optional chaining** (?.).
- **Nested destructuring:** const { a: { b } } = obj.
- **Shallow vs deep copy:** Spread operator dan Object.assign hanya shallow copy — nested object masih berupa referensi.
- Untuk **deep clone**, gunakan structuredClone() atau JSON.parse(JSON.stringify(obj)).

### Contoh Implementasi

`javascript
const user = {
  id: 1,
  nama: "Budi",
  alamat: {
    jalan: "Jl. Merdeka No. 1",
    kota: "Jakarta",
    kodePos: "10110",
    koordinat: {
      lat: -6.2,
      lng: 106.8
    }
  },
  kontak: {
    email: "budi@email.com",
    telepon: "08123456789"
  }
};

// Mengakses nested object
console.log(user.alamat.kota); // "Jakarta"
console.log(user.alamat.koordinat.lat); // -6.2

// Bracket notation
console.log(user["alamat"]["kodePos"]); // "10110"

// Nested destructuring
const { alamat: { kota, kodePos }, kontak: { email } } = user;
console.log(kota, kodePos, email); // "Jakarta", "10110", "budi@email.com"

// Optional chaining (ES2020)
console.log(user.alamat?.negara);    // undefined (tidak error)
console.log(user.alamat?.koordinat?.lat); // -6.2
`

### Koneksi

Nested objects sangat umum dalam **data API** (JSON). Pemahaman ini penting untuk **JSON parsing** (materi 79) dan juga terkait dengan **Object methods** seperti Object.keys yang bekerja dengan satu level.
