### Definisi Singkat

**Spread operator (...)** pada object memungkinkan penyalinan properti dari satu object ke object lain. Ini adalah cara ringkas untuk menggabungkan, menyalin, atau memperbarui object tanpa mutasi.

---

### Analogi

Bayangkan Anda memiliki beberapa set stiker:

- Spread seperti mengambil semua stiker dari satu set dan menempelkannya ke set lain.
- Jika ada stiker dengan nama yang sama, stiker yang datang belakangan akan menimpa yang lama.

---

### Poin-Poin Penting

- **Menyalin object:** const salinan = { ...asli }. Shallow copy.
- **Menggabungkan object:** const gabung = { ...a, ...b }. Properti dari  menimpa  jika ada duplikat.
- **Menimpa properti:** const baru = { ...lama, prop: value }.
- **Membuat default values:** const config = { ...defaults, ...userConfig }.
- Spread melakukan **shallow copy** — properti yang berupa object/nested akan di-copy sebagai referensi.
- Spread bisa digunakan di dalam destructuring untuk **rest pattern**: const { a, ...rest } = obj.

---

### Contoh Implementasi

`javascript
// Menyalin object
const asli = { a: 1, b: 2 };
const salinan = { ...asli };
console.log(salinan); // { a: 1, b: 2 }

// Menggabungkan object
const obj1 = { a: 1, b: 2 };
const obj2 = { c: 3, d: 4 };
const gabung = { ...obj1, ...obj2 };
console.log(gabung); // { a: 1, b: 2, c: 3, d: 4 }

// Menimpa properti
const user = { nama: "Budi", usia: 25 };
const updated = { ...user, usia: 26 };
console.log(updated); // { nama: "Budi", usia: 26 }
console.log(user);    // { nama: "Budi", usia: 25 } (tidak berubah)

// Default values
const defaults = { mode: "light", lang: "id", debug: false };
const config = { ...defaults, ...{ lang: "en", debug: true } };
console.log(config); // { mode: "light", lang: "en", debug: true }

// Shallow copy — perhatikan nested object
const obj = { a: { b: 1 } };
const copy = { ...obj };
copy.a.b = 99;
console.log(obj.a.b); // 99 (referensi sama!)
`

---

### Koneksi

Spread operator pada object terkait dengan **spread operator pada array** (materi 67) dan **Object.assign** (materi 73). Sangat berguna dalam **state management** (React/Redux) untuk immutability.
