### Definisi Singkat
Event loop adalah mekanisme yang memungkinkan JavaScript (single-threaded) melakukan operasi non-blocking dengan menangani callback dari task queue dan microtask queue secara berulang, selama call stack kosong.

---
### Analogi
Seperti resepsionis restoran: satu orang (single thread) menerima tamu, mencatat pesanan, dan memanggil tamu saat meja siap. Sambil menunggu, ia bisa melayani tamu lain. Pesanan selesai ditambahkan ke antrian.

---
### Poin-Poin Penting
- Event loop terus berjalan, memeriksa apakah call stack kosong
- Jika call stack kosong, event loop mengambil task dari queue
- Microtask queue diprioritaskan di atas macrotask queue
- Komponen: Call Stack, Microtask Queue, Macrotask Queue, Web APIs
- `setTimeout(fn, 0)` tetap masuk antrian — tidak langsung jalan

---
### Contoh Implementasi
```javascript
console.log('1. Start');

setTimeout(() => {
  console.log('2. setTimeout callback');
}, 0);

Promise.resolve().then(() => {
  console.log('3. Promise callback');
});

queueMicrotask(() => {
  console.log('4. queueMicrotask');
});

console.log('5. End');

// Output:
// "1. Start"
// "5. End"
// "3. Promise callback"   — microtask (prioritas)
// "4. queueMicrotask"     — microtask
// "2. setTimeout callback" — macrotask

// Alur event loop:
// 1. Eksekusi semua synchronous code
// 2. Kosongkan microtask queue (Promise, queueMicrotask)
// 3. Ambil satu macrotask dari task queue (setTimeout, setInterval)
// 4. Ulangi langkah 2-3 terus menerus
```
