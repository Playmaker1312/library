### Definisi Singkat
Call stack adalah struktur data LIFO (Last In, First Out) yang melacak eksekusi fungsi dalam program. Setiap kali fungsi dipanggil, sebuah frame ditambahkan ke stack; ketika fungsi selesai, frame dikeluarkan.

---
### Analogi
Seperti tumpukan piring: piring terakhir yang diletakkan di atas adalah yang pertama diambil. Fungsi terakhir yang dipanggil adalah yang pertama selesai dieksekusi.

---
### Poin-Poin Penting
- JavaScript single-threaded — hanya satu call stack
- Stack overflow terjadi jika stack terlalu penuh (rekursi tak terbatas)
- Setiap function call membuat stack frame baru
- Saat return, function di-pop dari stack
- Call stack + Event Loop + Task Queue = Concurrency Model

---
### Contoh Implementasi
```javascript
function pertama() {
  console.log('Function pertama mulai');
  kedua();
  console.log('Function pertama selesai');
}

function kedua() {
  console.log('Function kedua mulai');
  ketiga();
  console.log('Function kedua selesai');
}

function ketiga() {
  console.log('Function ketiga mulai');
  console.log('Function ketiga selesai');
}

pertama();
// Output:
// "Function pertama mulai"
// "Function kedua mulai"
// "Function ketiga mulai"
// "Function ketiga selesai"
// "Function kedua selesai"
// "Function pertama selesai"

// Ilustrasi stack:
// 1. [pertama]          → push
// 2. [pertama, kedua]   → push
// 3. [pertama, kedua, ketiga] → push
// 4. [pertama, kedua]   → pop (ketiga selesai)
// 5. [pertama]          → pop (kedua selesai)
// 6. []                 → pop (pertama selesai)

// Stack overflow
function infinite() {
  infinite();
}
// infinite(); // RangeError: Maximum call stack size exceeded
```

---
### Koneksi
Berkaitan dengan **event loop**, **execution context**, **stack overflow**, **recursion**, dan **synchronous vs asynchronous**.
