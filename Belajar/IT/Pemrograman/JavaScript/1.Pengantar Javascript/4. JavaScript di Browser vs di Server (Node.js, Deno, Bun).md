

### Definisi Singkat

JavaScript pada awalnya hanya berjalan di dalam _browser_ (sisi _client_), namun seiring berjalannya waktu, teknologi _runtime_ memungkinkan JavaScript untuk dieksekusi di sisi _server_ secara langsung pada komputer tanpa perlu bergantung pada _browser_.

---

### Analogi

Bayangkan **JavaScript** sebagai sebuah mesin mobil _sport_:

- **Di dalam Browser:** Mobil tersebut berada di dalam **sirkuit balap** yang dirancang khusus untuk interaksi visual dan respons langsung terhadap pengemudi.
    
- **Di dalam Server (Node.js/Deno/Bun):** Mesin mobil yang sama kini diletakkan di **truk kargo atau mesin industri**, digunakan untuk mengangkat beban berat, memproses data skala besar, dan berkomunikasi melalui jaringan.
    

---

### Poin-Poin Penting

- **Lingkungan Eksekusi (_Runtime Environment_):**
    
    - **Browser:** Menyediakan objek global seperti `window`, `document` (DOM), dan fitur antarmuka pengguna.
        
    - **Server (Node.js/Deno/Bun):** Menyediakan akses ke sistem file (`fs`), jaringan (HTTP), dan sistem operasi komputer, tetapi tidak memiliki antarmuka (DOM).
        
- **Fitur Utama Runtime Server:**
    
    - **Node.js:** _Runtime_ paling populer yang menggunakan V8 Engine, menjadi standar industri untuk _backend_ berbasis JavaScript.
        
    - **Deno:** Dibuat oleh kreator asli Node.js untuk memperbaiki kekurangan keamanan dengan _default sandbox_, serta memiliki dukungan bawaan untuk TypeScript dan ES Modules modern.
        
    - **Bun:** Alternatif modern yang sangat cepat (ditulis dalam bahasa Zig) yang menggabungkan fungsi _runtime_, _package manager_, dan _bundler_ dalam satu tempat.

### Contoh Implementasi

#### 1. JavaScript di Browser (Mengakses DOM):

JavaScript

```
// Mengubah warna latar belakang halaman web
document.body.style.backgroundColor = "lightblue";
```

#### 2. JavaScript di Server (Node.js - Membuat HTTP Server):

JavaScript

```
const http = require('http');

const server = http.createServer((req, res) => {
    res.writeHead(200, { 'Content-Type': 'text/plain' });
    res.end('Halo dari Server JavaScript!');
});

server.listen(3000, () => {
    console.log('Server berjalan pada port 3000');
});
```

### Koneksi

Dalam bidang **Web Development** dan _Full-Stack Development_, pemahaman ini memungkinkan Anda untuk menjadi _Full-Stack Developer_ hanya dengan menggunakan satu bahasa pemrograman (JavaScript/TypeScript) untuk membangun seluruh arsitektur:

- **Frontend:** Menggunakan JavaScript di _browser_ untuk membuat antarmuka yang dinamis.
    
- **Backend:** Menggunakan _runtime_ seperti Node.js, Deno, atau Bun untuk memproses permintaan API, mengelola database, dan menangani logika bisnis di _server_.
