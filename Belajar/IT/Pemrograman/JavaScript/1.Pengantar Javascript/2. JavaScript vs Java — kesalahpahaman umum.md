## 2. JavaScript vs Java — Kesalahpahaman Umum

### Definisi Singkat

Meskipun memiliki nama yang mirip, JavaScript dan Java adalah dua bahasa pemrograman yang sepenuhnya berbeda, baik dari segi desain, fungsi, maupun ekosistemnya.

---

### Analogi

- **Java:** Bayangkan seperti **kopi murni** yang diseduh di pabrik atau kafe besar. Java adalah bahasa yang kompleks, terstruktur, dan membutuhkan persiapan matang sebelum bisa dinikmati (seperti membangun aplikasi skala besar atau aplikasi Android).
    
- **JavaScript:** Bayangkan seperti **roti isi (sandwich)** cepat saji yang bisa langsung dibuat dan dimakan di mana saja. JavaScript adalah bahasa yang ringan dan fleksibel, berjalan langsung di dalam _browser_ web untuk langsung berinteraksi dengan pengguna.
    

---

### Poin-Poin Penting

- **Asal Usul Nama:** JavaScript awalnya dinamai _LiveScript_. Karena popularitas bahasa Java yang sangat tinggi pada tahun 1995, pembuatnya (Netscape dan Sun Microsystems) mengubah namanya menjadi _JavaScript_ sebagai strategi pemasaran.
    
- **Tipe Bahasa:** * **Java:** Merupakan bahasa yang _statically typed_ (tipe data harus dideklarasikan secara eksplisit) dan dikompilasi sebelum dijalankan.
    
    - **JavaScript:** Merupakan bahasa yang _dynamically typed_ (tipe data ditentukan otomatis saat _runtime_) dan bersifat _interpreted_ (dieksekusi baris demi baris oleh _browser_).
        
- **Lingkungan Eksekusi (_Environment_):**
    
    - **Java:** Berjalan di dalam lingkungan bernama JVM (_Java Virtual Machine_).
        
    - **JavaScript:** Berjalan di dalam _browser_ (seperti Chrome, Firefox) atau di sisi server menggunakan Node.js.
        
- **Paradigma Pemrograman:** * **Java:** Berbasis kelas dan berorientasi objek yang ketat (_Class-based Object-Oriented_).
    
    - **JavaScript:** Berbasis _prototype_ dan mendukung _multi-paradigm_ (termasuk fungsional dan berorientasi objek).
        

---

### Contoh Implementasi

Untuk melihat perbedaan sintaks secara langsung, berikut adalah perbandingan cara mencetak teks ke layar antara kedua bahasa tersebut:

#### 1. Java (Membutuhkan kelas dan fungsi utama):

Java

```
public class Main {
    public static void main(String[] args) {
        System.out.println("Halo Dunia dari Java!");
    }
}
```

#### 2. JavaScript (Dapat dieksekusi langsung tanpa kelas):

JavaScript

```
console.log("Halo Dunia dari JavaScript!");
```

---

### Koneksi

Dalam bidang **Web Development** dan pengembangan perangkat lunak secara umum, pemahaman ini sangat penting bagi pengembang untuk memilih _tools_ yang tepat:

- Gunakan **JavaScript** untuk membangun antarmuka pengguna (frontend) yang interaktif dan membangun backend yang fleksibel (seperti API menggunakan Express.js atau NestJS).
    
- Gunakan **Java** untuk membangun sistem berskala besar tingkat perusahaan (enterprise), aplikasi desktop, atau pengembangan aplikasi Android native.
