### Definisi Singkat

JavaScript adalah bahasa pemrograman tingkat tinggi yang dinamis dan interaktif, yang digunakan terutama untuk menambahkan fungsionalitas dan logika ke dalam halaman web. Bahasa ini memungkinkan elemen-elemen di situs web dapat merespons tindakan pengguna secara langsung tanpa harus memuat ulang halaman.

---

### Analogi

Bayangkan sebuah rumah:

- **HTML** adalah fondasi dan kerangka utama rumah.
    
- **CSS** adalah desain interior, cat, dan dekorasi yang membuat rumah terlihat indah.
    
- **JavaScript** adalah sistem kelistrikan, lampu otomatis, dan sistem keamanan yang membuat rumah tersebut interaktif, hidup, dan dapat merespons kehadiran penghuninya.
    

---

### Poin-Poin Penting

- **Dibuat oleh Brendan Eich:** JavaScript pertama kali diciptakan pada tahun 1995 oleh Brendan Eich saat ia bekerja di Netscape Communications.
    
- **Awal Mula Bernama Mocha:** Sebelum dikenal dengan nama JavaScript, bahasa ini sempat dinamai Mocha, lalu diubah menjadi LiveScript, hingga akhirnya dinamai JavaScript untuk alasan pemasaran.
    
- **Standardisasi ECMAScript:** Untuk memastikan bahasa ini berjalan konsisten di berbagai _browser_, standar teknisnya diatur oleh organisasi ECMA International dengan nama resmi **ECMAScript (ES)**.
    
- **Bahasa Sisi Klien (_Client-Side Scripting_):** Umumnya dieksekusi langsung oleh _browser_ web pengguna (di sisi _client_), meskipun kini juga dapat digunakan di sisi server menggunakan _runtime_ seperti Node.js.

### Contoh Implementasi

Berikut adalah contoh sederhana bagaimana JavaScript berinteraksi dengan halaman web untuk mengubah teks ketika tombol diklik:

HTML

```
<!DOCTYPE html>
<html>
<head>
    <title>Contoh JavaScript</title>
</head>
<body>

    <h1 id="pesan">Halo Dunia!</h1>
    <button onclick="ubahTeks()">Ubah Teks</button>

    <script>
        function ubahTeks() {
            // Mengubah isi elemen HTML dengan ID 'pesan'
            document.getElementById("pesan").innerText = "Teks telah berhasil diubah!";
        }
    </script>

</body>
</html>
```

### Koneksi

Dalam bidang **Web Development** (pengembangan web), JavaScript adalah salah satu dari tiga pilar utama selain HTML dan CSS. Peran JavaScript meliputi:

- **Interaktivitas:** Membuat animasi, modal (pop-up), dan navigasi menu yang dinamis.
    
- **Validasi Formulir:** Memeriksa apakah input pengguna (seperti nomor telepon atau _password_) sudah benar sebelum dikirimkan ke server.
