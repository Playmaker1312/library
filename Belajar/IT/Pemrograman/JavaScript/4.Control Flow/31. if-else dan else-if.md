### Definisi Singkat

Pernyataan `if-else` dan `else-if` adalah struktur kontrol yang memperluas fungsi pernyataan `if` dasar untuk menangani banyak kondisi sekaligus, sehingga program dapat memilih jalur tindakan yang berbeda berdasarkan situasi yang terjadi.

---

### Analogi

Bayangkan seperti **menentukan pilihan menu minuman di sebuah kafe**:

- **`if`:** Anda memeriksa: "Apakah ada kopi susu?" Jika ada, Anda memesan kopi susu.
    
- **`else if`:** Jika tidak ada kopi susu, Anda memeriksa pilihan kedua: "Apakah ada teh tarik?" Jika ada, Anda memesan teh tarik.
    
- **`else`:** Jika semua pilihan di atas tidak tersedia (_default_), Anda akan memesan air mineral biasa sebagai pilihan terakhir.
    

---

### Poin-Poin Penting

- **Struktur `if-else`:** Digunakan ketika hanya ada dua kemungkinan kondisi (jika benar, lakukan A; jika salah, lakukan B).
    
- **Struktur `else-if`:** Digunakan ketika Anda perlu mengevaluasi tiga kondisi atau lebih secara berurutan.
    
- **Alur Eksekusi (_Top-to-Bottom_):** JavaScript mengevaluasi kondisi dari atas ke bawah. Blok kode dari kondisi yang pertama kali bernilai `true` akan dieksekusi, dan sisa kondisi di bawahnya akan diabaikan.
    
- **Blok `else` Terakhir:** Bersifat opsional, tetapi sangat berguna untuk menangani semua kondisi yang tidak tercakup oleh pernyataan `if` atau `else-if` di atasnya.
    

---

### Contoh Implementasi

Berikut adalah contoh penggunaan `if-else` dan `else-if` dalam menentukan peringkat berdasarkan nilai ujian:

JavaScript

```
let nilaiUjian = 82;

if (nilaiUjian >= 85) {
    console.log("Predikat: A (Sangat Baik)");
} else if (nilaiUjian >= 70) {
    console.log("Predikat: B (Baik)");
} else if (nilaiUjian >= 55) {
    console.log("Predikat: C (Cukup)");
} else {
    console.log("Predikat: D (Kurang)");
}
// Output: Predikat: B (Baik)
```

### Koneksi

Dalam bidang **Web Development**, struktur ini sangat sering digunakan untuk mengambil keputusan logis secara _real-time_:

- **Menentukan Biaya Pengiriman:** Menghitung ongkos kirim berdasarkan berat paket atau lokasi tujuan pengguna di situs _E-commerce_.
    
- **Status Pesanan:** Menampilkan status pesanan (_Diproses_, _Dikirim_, atau _Diterima_) pada halaman pelacakan pengguna.
    
- **Personalisasi Tampilan:** Mengubah tema antarmuka (misalnya: Mode Gelap, Mode Terang, atau Mode Ramah Pengguna) berdasarkan preferensi waktu atau input pengguna.
