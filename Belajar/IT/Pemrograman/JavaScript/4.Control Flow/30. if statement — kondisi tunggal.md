### Definisi Singkat

Pernyataan `if` adalah struktur kontrol dasar di dalam JavaScript yang digunakan untuk menjalankan suatu blok kode tertentu hanya jika kondisi yang diberikan bernilai benar (_true_).

---

### Analogi

Bayangkan seperti **pemeriksaan di pintu masuk sebuah area parkir**:

- Kondisi: "Apakah tempat parkir di dalam masih kosong?"
    
- Jika kondisi tersebut bernilai benar (_true_), maka Anda akan diizinkan masuk dan memarkir mobil Anda.
    
- Namun, jika kondisi salah, Anda akan melewati blok tersebut dan mencari jalan lain.
    

---

### Poin-Poin Penting

- **Sintaks Dasar:**
    
    $$\text{if } (\text{kondisi}) \{ \text{// blok kode yang dijalankan jika kondisi true} \}$$
    
- **Tipe Data Kondisi:** Nilai di dalam tanda kurung akan secara otomatis diubah menjadi tipe Boolean (melalui _implicit type coercion_) untuk dievaluasi.
    
- **Blok Kode (`{...}`):** Kurung kurawal digunakan untuk menandai batasan perintah yang akan dieksekusi. Jika hanya ada satu baris perintah, kurung kurawal sebenarnya bersifat opsional, namun sangat dianjurkan untuk tetap menggunakannya agar kode mudah dibaca.
    
- **Falsy Values:** Jika kondisi menghasilkan nilai seperti `false`, `0`, `""` (string kosong), `null`, `undefined`, atau `NaN`, maka blok kode di dalam `if` tidak akan dieksekusi.

JavaScript

```
let totalBelanja = 150000;
let batasMinimalDiskon = 100000;

// Memeriksa apakah total belanja memenuhi syarat diskon
if (totalBelanja >= batasMinimalDiskon) {
    console.log("Selamat! Anda mendapatkan potongan harga.");
}

// Contoh dengan kondisi Boolean
let isMember = true;

if (isMember) {
    console.log("Tampilkan menu khusus member.");
}
```

### Koneksi

Dalam bidang **Web Development**, `if` statement adalah salah satu fondasi logika utama dalam membangun antarmuka web yang dinamis:

- **Validasi Form:** Memeriksa apakah kata sandi yang dimasukkan oleh pengguna telah memenuhi panjang karakter minimal sebelum tombol kirim diaktifkan.
    
- **Notifikasi Pengguna:** Menampilkan pesan peringatan jika saldo pengguna tidak mencukupi untuk melakukan transaksi di situs _E-commerce_.
