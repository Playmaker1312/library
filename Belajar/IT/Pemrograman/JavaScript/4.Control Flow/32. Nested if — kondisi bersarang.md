### Definisi Singkat

Pernyataan `if` bersarang (_nested if_) adalah kondisi di mana terdapat satu atau lebih pernyataan `if` di dalam blok pernyataan `if` lainnya. Struktur ini digunakan ketika Anda perlu melakukan pemeriksaan lanjutan setelah kondisi pertama terpenuhi.

---

### Analogi

Bayangkan seperti **sistem keamanan berlapis saat memasuki ruang VIP di bioskop**:

- **Pemeriksaan Pertama:** "Apakah Anda memiliki tiket?" (Jika ya, Anda bisa masuk ke area utama).
    
- **Pemeriksaan Kedua (Di dalam):** "Apakah Anda mengenakan pakaian yang rapi sesuai standar VIP?" (Pemeriksaan ini hanya dilakukan jika Anda sudah memiliki tiket).
    

---

### Poin-Poin Penting

- **Sintaks Dasar:**
    
    JavaScript
    
    ```
    if (kondisiLuar) {
        // Blok kode ini dijalankan jika kondisiLuar bernilai true
        if (kondisiDalam) {
            // Blok kode ini dijalankan jika kondisiDalam juga bernilai true
        }
    }
    ```
    
- **Spesifik dan Mendalam:** Struktur ini memungkinkan pengambilan keputusan yang sangat spesifik berdasarkan beberapa faktor yang saling berkaitan.
    
- **Keterbacaan Kode (_Readability_):** Terlalu banyak menggunakan _nested if_ dapat membuat kode menjadi rumit dan sulit dibaca (disebut sebagai _Arrow Anti-Pattern_ atau _Pyramid of Doom_). Untuk penyederhanaan, disarankan untuk memecahnya menjadi fungsi terpisah atau menggunakan operator logika `&&`.
    

---

### Contoh Implementasi

Berikut adalah contoh penggunaan kondisi bersarang untuk memverifikasi kelayakan promosi berdasarkan keanggotaan dan total pembelian:

JavaScript

```
let isMember = true;
let totalBelanja = 750000;

// Pemeriksaan kondisi luar
if (isMember) {
    console.log("Pengguna adalah member.");
    
    // Pemeriksaan kondisi dalam (Nested If)
    if (totalBelanja >= 500000) {
        console.log("Selamat! Anda mendapatkan Diskon Member Premium sebesar 20%.");
    } else {
        console.log("Belanja lebih dari Rp 500.000 untuk mendapatkan Diskon Premium.");
    }
    
} else {
    console.log("Silakan mendaftar menjadi member untuk menikmati promo.");
}
/* Output:
   Pengguna adalah member.
   Selamat! Anda mendapatkan Diskon Member Premium sebesar 20%.
*/
```

### Koneksi

Dalam bidang **Web Development**, _nested if_ sangat membantu dalam menangani logika yang membutuhkan validasi bertingkat sebelum melakukan suatu tindakan:

- **Sistem Pembayaran (_Checkout_):** Memeriksa apakah pengguna sudah _login_ (kondisi luar), dan jika sudah, memeriksa apakah saldo mereka mencukupi (kondisi dalam) sebelum memproses pesanan.
    
- **Akses Halaman (_Route Protection_):** Memverifikasi apakah pengguna memiliki izin (_role_) untuk melihat suatu halaman, lalu memeriksa kembali apakah sesi mereka telah kedaluwarsa.
