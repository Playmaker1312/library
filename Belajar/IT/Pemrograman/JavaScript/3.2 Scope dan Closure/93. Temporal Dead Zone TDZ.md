# 93. Temporal Dead Zone TDZ **Definisi Singkat:** TDZ adalah periode antara masuk scope (misal ke dalam blok) dan saat variabel `let`/`const` benar-benar dideklarasikan, di mana variabel tidak bisa diakses. **Analogi:** Seperti ruang tunggu bandara — kamu sudah masuk area (blok scope) tapi belum naik pesawat (deklarasi). Selama di ruang tunggu, kamu tidak bisa mengambil barang dari dalam pesawat. **Poin-Poin Penting:** - `let` dan `const` di-hoist tapi tidak diinisialisasi — masuk TDZ - Mengakses variabel di TDZ menyebabkan `ReferenceError` - Tujuan TDZ: mencegah akses sebelum inisialisasi yang rawan bug - `var` tidak memiliki TDZ (langsung `undefined`)**Contoh Kode:** ```javascript {
  // TDZ untuk name dimulai
  // console.log(name); // ReferenceError!
  const name = 'Fitri';
  console.log(name); // OK
  // TDZ berakhir
}

function test() {
  console.log(typeof x); // ReferenceError (bukan undefined!)
  let x = 10;
}
// test();

// var — tidak ada TDZ
console.log(y);
var y = 20; ``` **Hasil:** `Fitri` `undefined` **Kasus Penggunaan Nyata:** TDZ membuat kode lebih aman karena memaksa deklarasi sebelum penggunaan, mencegah bug微妙 seperti akses variabel sebelum diinisialisasi.
