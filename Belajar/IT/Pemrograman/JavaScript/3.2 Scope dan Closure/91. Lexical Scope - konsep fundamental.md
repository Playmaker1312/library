# 91. Lexical Scope - konsep fundamental **Definisi Singkat:** Lexical scope berarti fungsi dapat mengakses variabel dari scope di mana fungsi itu didefinisikan (bukan dipanggil), berdasarkan posisi kode. **Analogi:** Seperti anak yang bisa main di halaman rumahnya sendiri dan rumah tetangga (scope luar), tapi tidak bisa main di rumah orang asing. Izin ditentukan tempat tinggal (posisi kode), bukan tempat bermain (posisi panggil). **Poin-Poin Penting:** - Scope ditentukan di waktu penulisan kode (compile-time), bukan runtime - Fungsi dalam bisa akses variabel fungsi luar (scope chain) - Ini adalah dasar dari closure - Berlaku sama untuk regular dan arrow function**Contoh Kode:** ```javascript const global = 1;

function luar() {
  const x = 2;

  function dalam() {
    const y = 3;
    console.log(global);
    console.log(x);
    console.log(y);
  }

  dalam();
}

luar();

// Scope chain: dalam -> luar -> global ``` **Hasil:** `1` `2` `3` **Kasus Penggunaan Nyata:** Setiap fungsi bersarang mengandalkan lexical scope, seperti helper function di dalam komponen React yang mengakses props atau state dari komponen induk.
