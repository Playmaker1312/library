### Definisi Singkat

Global scope adalah ruang lingkup di luar semua fungsi dan blok — variabel di sini bisa diakses dari mana saja dalam program. Local scope (function scope) adalah ruang lingkup di dalam fungsi — variabel hanya bisa diakses di dalam fungsi tersebut.

---

### Analogi

Bayangkan sebuah **sekolah**:

- **Global scope** adalah **papan pengumuman di halaman sekolah** — semua siswa, guru, dan staf bisa melihat dan mengaksesnya.
- **Local scope** adalah **catatan pribadi di dalam kelas** — hanya siswa di kelas tersebut yang bisa membacanya.
- Variabel global seperti papan pengumuman — praktis tapi bisa kacau jika semua orang menulis di sana.

---

### Poin-Poin Penting

- Variabel global dideklarasikan di luar fungsi — bisa diakses dan dimodifikasi dari mana saja.
- Variabel lokal hanya ada selama fungsi dieksekusi — setelah selesai, variabel bisa dihapus dari memori.
- Terlalu banyak variabel global menyebabkan **global namespace pollution** — risiko bentrok nama.
- `var` global menjadi properti `window` di browser; `let`/`const` global tidak.
- Setiap fungsi menciptakan local scope baru.
- Scope bersarang — fungsi di dalam fungsi bisa mengakses scope induknya (lexical scope).

---

### Contoh Implementasi

```javascript
// Global scope
const globalNama = "Budi";

function cetakGlobal() {
    console.log(globalNama); // "Budi" — bisa akses global
}

cetakGlobal();

// Local scope — variabel hanya di dalam fungsi
function hitung(a, b) {
    const hasil = a + b; // local scope
    console.log(hasil);  // bisa diakses di sini
    console.log(globalNama); // bisa akses global juga
}

hitung(3, 4); // 7
// console.log(hasil); // ReferenceError — tidak bisa diakses di luar

// Global namespace pollution
var x = 10;
let y = 20;
console.log(window.x); // 10 (var menjadi properti window)
console.log(window.y); // undefined (let tidak)
```

---

### Koneksi

Global dan local scope adalah fondasi dari **lexical scope**, **closure**, **hoisting**, dan **module pattern**. Memahami perbedaannya penting untuk menulis kode yang aman, menghindari bug akibat variabel tertimpa, dan merancang arsitektur yang terisolasi.
