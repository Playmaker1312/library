### Definisi Singkat

Function scope berarti variabel hanya bisa diakses di dalam fungsi tempat ia dideklarasikan (berlaku untuk `var`). Block scope berarti variabel hanya bisa diakses di dalam blok `{ }` tempat ia dideklarasikan (berlaku untuk `let` dan `const`).

---

### Analogi

- **Function scope (`var`):** Seperti **lemari di dalam kamar** — pintu lemari hanya terbuka jika kamar (fungsi) terbuka. Begitu keluar kamar, lemari tidak bisa diakses.
- **Block scope (`let`/`const`):** Seperti **laci di dalam lemari** — laci hanya bisa dibuka jika lemari (blok) spesifik terbuka. Setiap laci terisolasi.

---

### Poin-Poin Penting

- **Function scope:** `var` mengabaikan blok seperti `if`, `for`, `while` — hanya fungsi yang membatasi scope-nya.
- **Block scope:** `let` dan `const` diikat oleh blok `{ }` — termasuk `if`, `for`, `while`, dan blok mandiri.
- `var` dalam loop `for` hanya memiliki satu binding — menyebabkan masalah klasik dengan closure.
- `let` dalam loop `for` membuat binding baru setiap iterasi.
- Block scope mencegah kebocoran variabel ke luar blok yang tidak diinginkan.

---

### Contoh Implementasi

```javascript
// Function scope — var tidak terikat blok
if (true) {
    var x = 10; // var mengabaikan blok
}
console.log(x); // 10 — bocor ke luar blok!

// Block scope — let/const terikat blok
if (true) {
    let y = 20;
    const z = 30;
}
// console.log(y); // ReferenceError
// console.log(z); // ReferenceError

// var dalam loop
for (var i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 100);
}
// Output: 3 3 3 — karena hanya satu binding var

// let dalam loop
for (let j = 0; j < 3; j++) {
    setTimeout(() => console.log(j), 100);
}
// Output: 0 1 2 — binding baru setiap iterasi

// Blok mandiri
{
    let pesan = "Hanya di sini";
    console.log(pesan); // OK
}
// console.log(pesan); // ReferenceError
```

---

### Koneksi

Topik ini terkait dengan **hoisting**, **Temporal Dead Zone (TDZ)**, **closure dalam loop**, dan praktik terbaik modern (menggunakan `let`/`const` daripada `var`). Memahami function vs block scope mencegah bug yang sulit dilacak, terutama dalam asynchronous code dan loop.
