# 94. Closure - apa itu dan cara kerjanya **Definisi Singkat:** Closure adalah kombinasi fungsi dengan lexical environment-nya, memungkinkan fungsi dalam mengakses variabel fungsi luar meskipun fungsi luar sudah selesai dieksekusi. **Analogi:** Seperti anak yang membawa bekal makanan dari rumah ke sekolah — bekal (variabel) berasal dari rumah (scope luar) meskipun anak sudah tidak di rumah. **Poin-Poin Penting:** - Terjadi saat fungsi dalam "mengingat" scope luar setelah scope luar selesai - Setiap kali fungsi dibuat, closure tercipta - Berguna untuk data privacy dan state persistence - Menggunakan garbage collection — hati-hati memory leak**Contoh Kode:** ```javascript function buatCounter() {
  let count = 0;

  return function () {
    count++;
    console.log(count);
  };
}

const counter1 = buatCounter();
const counter2 = buatCounter();

counter1();
counter1();
counter2();
counter1(); ``` **Hasil:** `1` `2` `1` `3` **Kasus Penggunaan Nyata:** Event handlers, state management (seperti Redux), fungsi pabrik (factory function), dan segala situasi di mana fungsi butuh "mengingat" data.
