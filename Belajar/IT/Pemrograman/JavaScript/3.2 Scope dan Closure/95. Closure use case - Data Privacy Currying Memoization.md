# 95. Closure use case - Data Privacy Currying Memoization **Definisi Singkat:** Closure dipakai untuk data privacy (variabel tersembunyi), currying (fungsi berantai), dan memoization (caching hasil). **Analogi:** Seperti brankas pribadi (data privacy), mesin kopi bertahap (currying — pilih biji lalu seduh), dan buku catatan nilai (memoization — catat hasil hitungan agar tidak ngitung ulang). **Poin-Poin Penting:** - Data privacy: variabel hanya bisa diubah lewat method tertentu - Currying: transformasi fungsi multi-parameter menjadi fungsi bertingkat - Memoization: simpan hasil fungsi untuk input yang sama agar tidak dihitung ulang**Contoh Kode:** ```javascript // 1. Data Privacy
function buatRekening() {
  let saldo = 0;
  return {
    deposit: (jumlah) => { saldo += jumlah; },
    cekSaldo: () => console.log(`Saldo: ${saldo}`)
  };
}
const rek = buatRekening();
rek.deposit(100);
rek.cekSaldo();
// console.log(rek.saldo); // undefined

// 2. Currying
const kali = a => b => console.log(a * b);
kali(3)(5);

// 3. Memoization
function buatCache() {
  const cache = {};
  return function (n) {
    if (n in cache) {
      console.log('dari cache');
      return cache[n];
    }
    cache[n] = n * 2;
    console.log('dihitung');
    return cache[n];
  };
}
const double = buatCache();
console.log(double(4));
console.log(double(4)); ``` **Hasil:** `Saldo: 100` `15` `dihitung` `8` `dari cache` `8` **Kasus Penggunaan Nyata:** Data privacy di modul, currying untuk function reuse (misal logger dengan level), memoization untuk React's `useMemo` dan komputasi berat Fibonacci.
