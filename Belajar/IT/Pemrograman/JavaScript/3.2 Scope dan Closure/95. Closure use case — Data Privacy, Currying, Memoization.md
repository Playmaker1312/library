### Definisi Singkat

Closure memiliki tiga use case klasik: **Data Privacy** (menyembunyikan data dari akses luar), **Currying** (mengubah fungsi multi-parameter menjadi rantai fungsi satu parameter), dan **Memoization** (menyimpan hasil komputasi untuk menghindari perhitungan ulang).

---

### Analagi

Bayangkan **restoran dengan tiga layanan**:

- **Data Privacy:** Dapur restoran — koki bisa mengakses semua bahan dan resep rahasia, tapi pelanggan tidak bisa masuk ke dapur.
- **Currying:** Kasir yang melayani satu pesanan per langkah — "pesan nasi" → "pesan ayam" → "pesan minum" — bertahap.
- **Memoization:** Pramusaji yang menghafal pesanan pelanggan tetap — tidak perlu menanyakan ulang pesanan yang sama.

---

### Poin-Poin Penting

- **Data Privacy:** Closure membuat variabel private yang tidak bisa diakses dari luar fungsi. Hanya fungsi yang me-return yang bisa mengakses dan memodifikasi data.
- **Currying:** Mengubah `f(a, b, c)` menjadi `f(a)(b)(c)` — berguna untuk membuat fungsi khusus dari fungsi umum (partial application).
- **Memoization:** Closure menyimpan cache hasil fungsi — jika input sama, kembalikan dari cache tanpa komputasi ulang.
- Ketiga use case ini memanfaatkan kemampuan closure untuk "mengingat" state.

---

### Contoh Implementasi

```javascript
// 1. Data Privacy
function buatRekening(saldoAwal) {
    let saldo = saldoAwal; // private
    
    return {
        deposit: function(jumlah) {
            saldo += jumlah;
            return "Saldo: " + saldo;
        },
        tarik: function(jumlah) {
            if (jumlah > saldo) return "Saldo tidak cukup";
            saldo -= jumlah;
            return "Saldo: " + saldo;
        },
        cekSaldo: function() {
            return saldo;
        }
    };
}
const rekening = buatRekening(1000);
console.log(rekening.cekSaldo()); // 1000
console.log(rekening.deposit(500)); // "Saldo: 1500"
// console.log(rekening.saldo); // undefined — private

// 2. Currying
function kali(a) {
    return function(b) {
        return a * b;
    };
}
const kali2 = kali(2);
const kali3 = kali(3);
console.log(kali2(5)); // 10
console.log(kali3(5)); // 15

// 3. Memoization — faktorial dengan cache
function buatFaktorial() {
    const cache = {};
    
    return function faktorial(n) {
        if (n in cache) {
            return cache[n];
        }
        if (n <= 1) return 1;
        cache[n] = n * faktorial(n - 1);
        return cache[n];
    };
}
const faktorial = buatFaktorial();
console.log(faktorial(5)); // 120 (dihitung)
console.log(faktorial(5)); // 120 (dari cache)
```

### Koneksi

Ketiga use case ini terkait dengan **functional programming**, **module pattern**, **higher-order functions**, **partial application**, dan **performance optimization**. Closure adalah alat yang sangat serbaguna — ketiga pola ini muncul terus dalam kode JavaScript modern, dari library state management hingga utility functions.
