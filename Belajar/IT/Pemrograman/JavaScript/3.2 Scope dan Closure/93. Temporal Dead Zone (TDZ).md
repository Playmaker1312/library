### Definisi Singkat

Temporal Dead Zone (TDZ) adalah periode antara saat variabel `let` atau `const` di-hoist (masuk ke dalam scope) hingga saat variabel tersebut benar-benar diinisialisasi. Selama TDZ, mengakses variabel akan menghasilkan `ReferenceError`.

---

### Analogi

Bayangkan **sewa apartemen**:

- Anda sudah mendaftar (deklarasi) dan nama Anda tercatat di sistem — apartemen sudah "dialokasikan" untuk Anda.
- Tapi Anda belum menerima kunci dan belum bisa masuk — itulah **Temporal Dead Zone**.
- Begitu Anda menerima kunci dan masuk (inisialisasi), Anda bisa menggunakan apartemen sepenuhnya.
- Mencoba masuk sebelum menerima kunci = `ReferenceError`.

---

### Poin-Poin Penting

- `let` dan `const` di-hoist tapi tidak diinisialisasi — berbeda dengan `var` yang diinisialisasi dengan `undefined`.
- TDZ dimulai dari awal scope (blok) hingga baris deklarasi dieksekusi.
- `typeof` juga throw `ReferenceError` untuk variabel dalam TDZ (kecuali untuk variabel yang belum dideklarasikan sama sekali).
- TDZ berlaku di dalam blok, fungsi, dan scope global.
- TDZ mencegah akses variabel sebelum inisialisasi — membuat kode lebih predictable dibanding `var`.
- Class declarations juga memiliki TDZ.

---

### Contoh Implementasi

```javascript
// TDZ dengan let
{
    // TDZ dimulai — variabel nama sudah di-hoist tapi tidak bisa diakses
    // console.log(nama); // ReferenceError
    let nama = "Budi"; // TDZ berakhir
    console.log(nama); // "Budi" — aman
}

// TDZ dengan const
{
    // console.log(PI); // ReferenceError
    const PI = 3.14;
    console.log(PI); // 3.14
}

// typeof dan TDZ
// console.log(typeof x); // ReferenceError (x dalam TDZ)
let x = 10;

// typeof untuk variabel tidak dideklarasikan — aman
console.log(typeof y); // "undefined" (y tidak pernah dideklarasikan)

// TDZ dalam scope bersarang
{
    // console.log(angka); // ReferenceError (TDZ)
    let angka = 5;
    {
        console.log(angka); // 5 — bisa akses dari scope luar
    }
}

// Perbandingan dengan var
{
    console.log(a); // undefined (var di-hoist dengan undefined)
    var a = 1;
    
    // console.log(b); // ReferenceError (TDZ)
    let b = 2;
}
```

---

### Koneksi

TDZ terkait erat dengan **hoisting**, **let dan const**, **block scope**, **execution context**, dan **best practices JavaScript modern**. Memahami TDZ membantu developer menghindari bug yang sulit dilacak dan menulis kode yang lebih aman dan terstruktur.
