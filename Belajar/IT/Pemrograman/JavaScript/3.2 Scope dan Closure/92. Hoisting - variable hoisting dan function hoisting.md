# 92. Hoisting - variable hoisting dan function hoisting **Definisi Singkat:** Hoisting adalah mekanisme JS yang "mengangkat" deklarasi (var dan function) ke atas scope-nya sebelum kode dieksekusi. **Analogi:** Seperti daftar tamu yang sudah dicatat sebelum pesta dimulai — semua nama sudah diketahui (deklarasi di-hoist), tapi siapa yang hadir (inisialisasi) baru diketahui saat pesta berlangsung. **Poin-Poin Penting:** - `var` di-hoist dengan nilai `undefined` - `function declaration` di-hoist penuh (bisa dipanggil sebelum ditulis) - `let`/`const` di-hoist tapi tidak diinisialisasi (TDZ) - Function expression hanya hoist variabelnya saja**Contoh Kode:** ```javascript console.log(a);
var a = 5;
// Hoisting: var a; -> console.log(a); -> a = 5;

console.log(kali(2, 3));
function kali(x, y) {
  return x * y;
}

// console.log(bagi(10, 2)); // Error
const bagi = function (x, y) {
  return x / y;
}; ``` **Hasil:** `undefined` `6` **Kasus Penggunaan Nyata:** Function hoisting memungkinkan kita menempatkan fungsi utama di bawah helper functions tanpa error, membuat kode lebih mudah dibaca seperti tulisan从上到下.
