### Definisi Singkat

**Workflow kontribusi GitHub** adalah alur standar berkontribusi ke proyek open source: **Fork** repositori utama → buat **Branch** untuk perubahan Anda → buat **Pull Request (PR)** untuk menggabungkan perubahan kembali ke repositori asli. Ini memungkinkan maintainer meninjau kode sebelum digabungkan.

---

### Analogi

Seperti **meminjam buku dari perpustakaan dan menambahkan catatan**:
- **Fork**: Fotokopi seluruh buku (repo Anda sendiri).
- **Branch**: Pembatas buku — Anda menulis di halaman tertentu tanpa mengganggu halaman lain.
- **Commit**: Catatan kecil yang Anda tulis dengan stabilo.
- **Pull Request**: Mengembalikan buku yang sudah dicatati ke pustakawan — ia akan memeriksa apakah catatan Anda layak ditambahkan ke buku asli.

---

### Poin-Poin Penting

- **Fork**: Salin repo orang lain ke akun GitHub Anda (tombol Fork di GitHub).
- **Clone**: Salin fork ke komputer lokal.
- **Branch**: `git checkout -b nama-branch` — branch terpisah untuk pekerjaan Anda.
- **Commit**: Perubahan atomik dengan pesan yang jelas (imperative, misal: `fix: perbaiki null pointer`).
- **Push**: `git push origin nama-branch` — kirim ke GitHub.
- **Pull Request**: Usulkan perubahan ke repo asli.
- **PR Best Practices**:
  - Judul jelas, deskripsi menjelaskan apa dan mengapa.
  - Referensi issue terkait (`Closes #123`).
  - Jaga PR tetap kecil — satu fitur/fix per PR.
  - Perbarui PR jika maintainer minta revisi.
- **Sync fork**: Jaga fork tetap up-to-date dengan repo asli (`git remote add upstream`, `git pull upstream main`).

---

### Contoh Implementasi

```bash
# 1. Fork repo di GitHub (klik tombol Fork)

# 2. Clone fork lokal
git clone https://github.com/username/repo.git
cd repo

# 3. Tambahkan remote upstream (repo asli)
git remote add upstream https://github.com/original-owner/repo.git

# 4. Sync fork dengan upstream
git checkout main
git pull upstream main
git push origin main

# 5. Buat branch fitur
git checkout -b feat/tambah-fitur

# 6. Lakukan perubahan, commit, push
git add .
git commit -m "feat: tambahkan fitur validasi email"
git push origin feat/tambah-fitur

# 7. Buka Pull Request di GitHub (dari branch Anda ke main repo asli)
# URL: https://github.com/original-owner/repo/compare

# 8. Setelah PR di-merge, hapus branch lokal
git checkout main
git branch -D feat/tambah-fitur
git pull upstream main
```

```markdown
<!-- Template PR -->

Menambahkan fitur validasi email.

## Perubahan

- Menambahkan unit test

## Related Issue
Closes #42
```
