### Definisi Singkat

Hoisting adalah mekanisme JavaScript di mana deklarasi variabel (`var`) dan fungsi (function declaration) secara konseptual "diangkat" ke atas scope-nya sebelum kode dieksekusi. Ini memungkinkan fungsi dipanggil sebelum deklarasi, dan `var` diakses tanpa error (meskipun bernilai `undefined`).

---

### Analogi

Bayangkan **membaca naskah drama**:

- **Function hoisting:** Sutradara sudah menghafal seluruh peran sebelum pertunjukan dimulai — aktor bisa tampil di adegan pertama meskipun namanya baru disebut di adegan terakhir naskah.
- **Variable hoisting (`var`):** Seperti **meja rias dengan label** — labelnya sudah menempel di meja sebelum perlengkapan diletakkan. Label ada (variabel tidak error), tapi isinya masih kosong (`undefined`).
- **`let`/`const`:** Seperti laci terkunci — labelnya menempel tapi kamu tidak bisa membukanya sampai waktu yang tepat.

---

### Poin-Poin Penting

- Hanya **deklarasi** yang di-hoist, bukan **inisialisasi**.
- Function declaration di-hoist secara keseluruhan (bisa dipanggil sebelum definisi).
- `var` di-hoist dan diinisialisasi dengan `undefined`.
- `let` dan `const` di-hoist tapi tidak diinisialisasi — masuk **Temporal Dead Zone (TDZ)**.
- Function expression tidak di-hoist (hanya variabelnya yang di-hoist jika pakai `var`).
- Best practice: deklarasikan variabel di atas fungsi/scope untuk kejelasan.

---

### Contoh Implementasi

```javascript
// Function hoisting — bisa dipanggil sebelum definisi
console.log(kali(3, 4)); // 12

function kali(a, b) {
    return a * b;
}

// Variable hoisting dengan var
console.log(nilai); // undefined (bukan ReferenceError!)
var nilai = 10;
// Kode di atas setara dengan:
// var nilai;
// console.log(nilai);
// nilai = 10;

// let/const — TDZ
// console.log(nama); // ReferenceError: Cannot access before initialization
let nama = "Budi";

// Function expression tidak di-hoist
// console.log(jumlah); // undefined (var di-hoist)
// jumlah(1, 2);       // TypeError: jumlah is not a function
var jumlah = function(a, b) {
    return a + b;
};

const bagi = (a, b) => a / b;
// console.log(bagi(10, 2)); // ReferenceError jika dipanggil sebelum baris ini
```

---

### Koneksi

Hoisting terkait erat dengan **Temporal Dead Zone (TDZ)**, **function declaration vs expression**, **execution context (creation phase vs execution phase)**, dan **best practices modern** (gunakan `let`/`const` untuk menghindari confusion akibat hoisting `var`).
