### Definisi Singkat

Closure adalah kombinasi antara sebuah fungsi dengan lexical scope (lingkup) tempat fungsi itu didefinisikan. Closure memungkinkan fungsi "mengingat" dan mengakses variabel dari scope induknya bahkan setelah fungsi induk selesai dieksekusi.

---

### Analogi

Bayangkan **ransel ajaib**:

- Seorang pendaki (fungsi induk) mengemas bekal (variabel) ke dalam ransel sebelum mendaki.
- Pendaki selesai mendaki dan pulang (fungsi induk selesai dieksekusi).
- Tapi ransel (closure) yang diberikan kepada temannya (fungsi inner) masih berisi bekal (variabel) — teman itu bisa mengakses bekal kapan saja.
- **Closure** adalah ransel yang terus membawa variabel dari masa lalu.

---

### Poin-Poin Penting

- Closure terjadi otomatis di JavaScript setiap kali fungsi dibuat di dalam fungsi lain.
- Fungsi inner "menutup" (close over) variabel-variabel dari scope luar yang dirujuknya.
- Closure menyimpan referensi ke variabel, bukan salinan nilai — nilai bisa berubah.
- Tanpa closure, semua variabel lokal akan dihapus setelah fungsi induk selesai.
- Setiap panggilan fungsi menciptakan closure baru dengan state-nya sendiri.
- Closure adalah fitur yang sangat powerful tapi juga boros memori jika tidak hati-hati.

---

### Contoh Implementasi

```javascript
// Contoh dasar closure
function buatCounter() {
    let count = 0; // variabel lokal
    
    return function() {
        count++; // inner function "menutup" variabel count
        return count;
    };
}

const counter = buatCounter();
console.log(counter()); // 1
console.log(counter()); // 2
console.log(counter()); // 3

// Closure dengan multiple instance
const counter1 = buatCounter();
const counter2 = buatCounter();
console.log(counter1()); // 1
console.log(counter2()); // 1 — masing-masing punya state sendiri

// Closure mengakses parameter fungsi induk
function sapa(pesan) {
    return function(nama) {
        console.log(pesan + ", " + nama);
    };
}
const sapaFormal = sapa("Selamat pagi");
sapaFormal("Budi"); // "Selamat pagi, Budi"
sapaFormal("Siti"); // "Selamat pagi, Siti"
```

---

### Koneksi

Closure adalah konsep fundamental yang mendasari banyak pola dan fitur JavaScript: **module pattern**, **data privacy**, **currying**, **memoization**, **event handlers**, **callback asynchronous**, dan **higher-order functions**. Closure juga erat kaitannya dengan **lexical scope** dan **garbage collection**.
