### Definisi Singkat

Lexical scope (static scope) adalah aturan di mana scope variabel ditentukan oleh posisi (letak) fungsi atau blok dalam kode sumber saat penulisan, bukan saat eksekusi. Fungsi di dalam fungsi bisa mengakses variabel dari fungsi induknya.

---

### Analogi

Bayangkan **rumah bertingkat**:

- Lantai 1 (scope terluar) memiliki ruang tamu dan dapur.
- Lantai 2 (scope tengah) memiliki kamar tidur dan kamar mandi.
- Lantai 3 (scope terdalam) memiliki loteng.
- Penghuni loteng bisa turun ke lantai 2 dan lantai 1 — tapi penghuni lantai 1 tidak bisa naik ke loteng tanpa izin.
- **Lexical scope** seperti aturan rumah: "Kamu bisa mengakses semua area di bawah levelmu, tapi tidak sebaliknya."

---

### Poin-Poin Penting

- Scope ditentukan saat **penulisan kode** (compile-time), bukan saat runtime.
- Fungsi inner bisa mengakses variabel fungsi outer (scope chain).
- Setiap fungsi membawa referensi ke scope luarnya — ini yang memungkinkan **closure**.
- Scope chain (rantai scope) dibentuk dari scope terdalam ke terluar hingga global.
- Lexical scope berlaku untuk semua jenis fungsi — termasuk arrow function.
- Konsep ini berbeda dengan dynamic scope (yang dilihat dari call stack, bukan dari posisi penulisan).

---

### Contoh Implementasi

```javascript
// Lexical scope — scope ditentukan oleh posisi kode
const luar = "global";

function outer() {
    const tengah = "outer function";
    
    function inner() {
        const dalam = "inner function";
        console.log(dalam);  // "inner function" — dari scope sendiri
        console.log(tengah); // "outer function" — dari scope induk
        console.log(luar);   // "global" — dari scope global
    }
    
    inner();
    // console.log(dalam); // ReferenceError — tidak bisa akses scope inner
}

outer();

// Scope chain visual
const a = 1; // global scope
function f1() {
    const b = 2; // f1 scope
    function f2() {
        const c = 3; // f2 scope
        function f3() {
            const d = 4; // f3 scope
            console.log(a, b, c, d); // 1 2 3 4 — semua bisa diakses
        }
        f3();
    }
    f2();
}
f1();
```

---

### Koneksi

Lexical scope adalah **fondasi dari closure** — tanpa lexical scope, closure tidak mungkin ada. Konsep ini juga terkait dengan **hoisting**, **TDZ**, **execution context**, dan **scope chain**. Pemahaman lexical scope esensial untuk debugging dan penulisan kode yang predictable.
