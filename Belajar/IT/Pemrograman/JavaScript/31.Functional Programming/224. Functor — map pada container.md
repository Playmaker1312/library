### Definisi Singkat

Functor adalah konsep dari functional programming yang merepresentasikan **container** (pembungkus) yang bisa di-map dengan fungsi. Sebuah objek disebut Functor jika memiliki method `map` yang menerapkan fungsi ke nilai di dalam container dan mengembalikan container baru dengan tipe yang sama.

---

### Analogi

Seperti **paket快递 (parcel) yang bisa diubah isinya tanpa membuka bungkusnya**. Anda punya kotak (Functor) berisi kaos merah. Anda ingin kaos biru? Cukup tempel stiker "ubah warna jadi biru" (`map`) ke kotak — tanpa membukanya. Hasilnya kotak baru berisi kaos biru.

---

### Poin-Poin Penting

- Functor memiliki method `map(f)` yang menerapkan fungsi `f` ke nilai di dalamnya
- Hukum Functor: `map(id) === id` (identitas) dan `map(compose(f, g)) === compose(map(f), map(g))` (komposisi)
- Array adalah Functor — `Array.prototype.map`
- Promise juga Functor — `.then()` mirip `map` (sebenarnya Monad)
- Observer/Stream juga Functor — `.pipe(map())` di RxJS
- Custom Functor memungkinkan transformasi dalam konteks tertentu (Maybe, Either, Box)
- Functor adalah prekursor untuk konsep **Monad**

---

### Contoh Implementasi

```javascript
// Custom Functor: Box/Identity
class Box {
  constructor(value) {
    this.value = value;
  }

  map(fn) {
    return new Box(fn(this.value));
  }

  fold() {
    return this.value;
  }
}

const result = new Box(5)
  .map(x => x * 2)
  .map(x => x + 3);

console.log(result.fold()); // 13

// Maybe Functor (menangani null/undefined)
class Maybe {
  constructor(value) {
    this.value = value;
  }

  map(fn) {
    return this.value == null
      ? new Maybe(null)
      : new Maybe(fn(this.value));
  }

  getOrElse(defaultValue) {
    return this.value != null ? this.value : defaultValue;
  }
}

const maybeNum = new Maybe(5)
  .map(x => x * 2)
  .map(x => x + 1);

console.log(maybeNum.getOrElse(0)); // 11

const maybeNull = new Maybe(null)
  .map(x => x * 2);  // Tidak error!

console.log(maybeNull.getOrElse(0)); // 0
```

### Koneksi

Functor adalah jembatan antara **Function Composition** (file 223) dan konsep container. Functor mengarah ke **Monad** (file 225) yang menambahkan kemampuan `flatMap`/`chain` untuk menangani komposisi fungsi yang mengembalikan container. Juga terkait dengan **Transducers** (file 226).
