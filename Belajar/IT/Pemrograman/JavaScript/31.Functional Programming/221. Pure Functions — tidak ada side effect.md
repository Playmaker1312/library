### Definisi Singkat

Pure Function adalah fungsi yang memenuhi dua syarat: (1) **deterministik** — return value hanya ditentukan oleh input yang diberikan (bukan state eksternal), dan (2) **tanpa side effect** — tidak mengubah variabel di luar scope, tidak melakukan I/O, tidak memodifikasi argumen, dan tidak mengubah DOM.

---

### Analogi

Seperti **mesin kalkulator** — Anda memasukkan `2 + 2`, selalu keluar `4`. Tidak peduli berapa kali ditekan, tidak ada lampu yang menyala, tidak ada file yang tersimpan. Hasil murni dari input. Bandingkan dengan **mesin ATM** yang punya side effect (saldo berubah, ada cetak struk).

---

### Poin-Poin Penting

- Pure function selalu mengembalikan nilai yang sama untuk argumen yang sama
- Pure function tidak memiliki observable side effects
- Mudah di-test (tidak perlu mock setup)
- Mudah di-debug dan di-reason tentang perilakunya
- Mendukung memoization (cache hasil berdasarkan input)
- Dapat dijalankan secara paralel tanpa race condition
- Contoh pure: `Math.max()`, `Array.prototype.map()`
- Contoh impure: `Math.random()`, `Date.now()`, `console.log()`, array push()

---

### Contoh Implementasi

```javascript
// ✅ Pure function
function add(a, b) {
  return a + b;
}

function toUpperCase(str) {
  return str.toUpperCase();
}

function doubleArray(arr) {
  return arr.map(item => item * 2); // Tidak mengubah arr asli
}

// ❌ Impure function
let counter = 0;
function increment() {
  counter++; // Side effect: mengubah variabel luar
  return counter;
}

function addToArray(arr, item) {
  arr.push(item); // Side effect: memodifikasi argumen
  return arr;
}

// ✅ Pure version
function addToArrayPure(arr, item) {
  return [...arr, item]; // Membuat array baru
}

// Testing pure function itu mudah
console.assert(add(2, 3) === 5);
console.assert(add(2, 3) === 5); // Selalu sama
```
