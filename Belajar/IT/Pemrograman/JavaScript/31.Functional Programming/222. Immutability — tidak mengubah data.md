### Definisi Singkat

Immutability adalah prinsip di mana data tidak boleh diubah setelah dibuat. Alih-alih memodifikasi data yang ada, kita membuat **salinan baru** dengan perubahan yang diinginkan. Ini adalah konsep inti dalam functional programming yang mencegah side effects dan membuat kode lebih prediktif.

---

### Analogi

Seperti **foto cetak** — Anda tidak bisa mengubah foto yang sudah dicetak. Jika ingin versi berbeda, Anda cetak ulang dengan filter berbeda. Bandingkan dengan **lukisan digital** yang bisa diedit kapan saja. Immutability menggunakan pendekatan cetak foto: data asli tetap utuh.

---

### Poin-Poin Penting

- Mencegah unintended side effects — data tidak berubah di luar dugaan
- Memudahkan change detection (cukup cek referensi)
- Thread-safe — cocok untuk concurrent programming
- Mendukung time-travel debugging (Redux DevTools)
- Di JavaScript, spread operator (`...`) dan `Object.assign()` untuk immutable update
- `Array` method immutable: `map()`, `filter()`, `reduce()`, `concat()`, `slice()`
- Library seperti **Immer** dan **Immutable.js** memudahkan immutability
- Primitif (string, number, boolean) sudah immutable di JS

---

### Contoh Implementasi

```javascript
// ❌ Mutasi langsung
const user = { name: 'Budi', age: 25 };
user.age = 26; // Mutasi objek asli

const numbers = [1, 2, 3];
numbers.push(4); // Mutasi array asli

// ✅ Immutable update
const user = { name: 'Budi', age: 25 };
const updatedUser = { ...user, age: 26 }; // Objek baru
console.log(user.age); // 25 (tidak berubah)
console.log(updatedUser.age); // 26

const numbers = [1, 2, 3];
const newNumbers = [...numbers, 4]; // Array baru
console.log(numbers); // [1, 2, 3]
console.log(newNumbers); // [1, 2, 3, 4]

// Immutable update nested object
const state = {
  user: { name: 'Budi', address: { city: 'Jakarta' } }
};

const newState = {
  ...state,
  user: {
    ...state.user,
    address: { ...state.user.address, city: 'Bandung' }
  }
};

// Atau update array dengan map
const items = [{ id: 1, done: false }, { id: 2, done: true }];
const updated = items.map(item =>
  item.id === 1 ? { ...item, done: true } : item
);
```
