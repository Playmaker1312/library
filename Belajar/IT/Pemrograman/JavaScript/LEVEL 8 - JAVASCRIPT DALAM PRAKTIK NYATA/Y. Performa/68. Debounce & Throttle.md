# Debounce & Throttle

## Penjelasan
Debounce dan Throttle adalah teknik untuk membatasi seberapa sering sebuah fungsi dijalankan dalam periode waktu tertentu.

- **Debounce**: fungsi hanya dijalankan setelah jeda waktu tertentu sejak panggilan TERAKHIR. Jika fungsi dipanggil lagi sebelum jeda selesai, timer di-reset.
- **Throttle**: fungsi dijalankan MAKSIMAL satu kali dalam periode waktu tertentu, tidak peduli berapa kali dipanggil.

## Fungsi
- Mencegah fungsi dijalankan terlalu sering (berlebihan)
- Menghemat resource (CPU, memory, network request)
- Meningkatkan user experience dengan mengurangi lag

## Cara Pengimplementasian

```javascript
// DEBOUNCE — analogi RUMAH: pintu yang hanya terbuka setelah 3 ketukan dalam 1 detik
// Pintu tidak akan terbuka kalau ketukan terus datang — tunggu jeda dulu

function debounce(fn, delay) {
  let timer = null;
  return function (...args) {
    clearTimeout(timer);           // reset timer setiap kali dipanggil
    timer = setTimeout(() => {
      fn.apply(this, args);        // jalankan fn setelah delay
    }, delay);
  };
}

// Contoh: pencarian rumah — tidak fetch API setiap huruf diketik
const cariRumah = debounce((keyword) => {
  console.log(`Mencari rumah dengan kata kunci: ${keyword}`);
  // fetch(`/api/rumah?q=${keyword}`);
}, 500);

cariRumah("Ruma");     // timer di-reset
cariRumah("Rumah");    // timer di-reset lagi
cariRumah("Rumah Minima"); // timer di-reset lagi
// Hanya "Mencari rumah dengan kata kunci: Rumah Minima" yang tercetak setelah 500ms

// THROTTLE — analogi RUMAH: AC yang nyala maksimal 1 kali per 5 menit
// Tidak peduli berapa kali kamu pencet remote, AC hanya ON sekali dalam 5 menit

function throttle(fn, limit) {
  let inCooldown = false;
  return function (...args) {
    if (!inCooldown) {
      fn.apply(this, args);
      inCooldown = true;
      setTimeout(() => {
        inCooldown = false;
      }, limit);
    }
  };
}

// Contoh: AC rumah — pengaturan suhu via remote
const aturAC = throttle((suhu) => {
  console.log(`AC diatur ke ${suhu}°C — kompresor menyala`);
}, 5000);

aturAC(16); // "AC diatur ke 16°C — kompresor menyala"
aturAC(18); // diabaikan (masih cooldown)
aturAC(20); // diabaikan
setTimeout(() => aturAC(22), 6000); // setelah 6 detik, "AC diatur ke 22°C — kompresor menyala"
```

## Analogi
- **Debounce = pintu rumah yang hanya terbuka setelah 3 ketukan dalam 1 detik**. Jika tamu mengetuk sekali, pintu akan buka setelah 1 detik. Tapi jika tamu terus mengetuk setiap 0,5 detik, timer di-reset terus — pintu tidak akan terbuka sampai tamu berhenti mengetuk selama 1 detik penuh. Cocok untuk input pencarian yang baru diproses setelah user berhenti mengetik.
- **Throttle = AC rumah yang nyala maksimal 1 kali per 5 menit**. Kamu boleh pencet remote AC 100 kali dalam 1 menit, tapi AC hanya akan merespon SATU KALI. Setelah itu, tombol remote "mati" sampai 5 menit berlalu. Cocok untuk event scroll/resize yang mengirim request.

## Dipakai Untuk Apa
- **Debounce**: auto-search (search bar), form validation real-time, save draft otomatis
- **Throttle**: infinite scroll, window resize handler, button submit (cegah double click), game input (membatasi fire rate)

## Kesalahan Umum
1. **Tidak bind `this`** — fungsi debounce/throttle kehilangan konteks `this` jika dipanggil sebagai method objek
2. **Debounce bukan throttle dan sebaliknya** — menggunakan yang salah menyebabkan perilaku tidak sesuai
3. **Memory leak dari timer** — selalu cleanup `setTimeout` di komponen yang unmount
4. **Leading vs trailing** — debounce default trailing (tunggu selesai), throttle default leading (langsung jalan). Kadang perlu opsi `{ leading: true, trailing: false }`

## Keterkaitan dengan Materi Sebelumnya
Di Level 5, kamu belajar tentang timing (`setTimeout`, `setInterval`) dan event loop. Debounce dan throttle adalah aplikasi langsung dari timing functions untuk optimasi. Konsep callback juga krusial — debounce/throttle menerima callback dan mengembalikan fungsi baru. Di Level 6, event listener (scroll, resize, keyup) adalah target utama optimasi debounce/throttle.

## Soal Latihan

Jika sebuah fungsi throttle dengan limit 1000ms dipanggil 5 kali dalam 500ms (setiap 100ms sekali), berapa kali fungsi asli dijalankan?

>!1 kali. Hanya panggilan pertama yang masuk karena sisanya masih dalam periode cooldown (1000ms). Setelah 1000ms berlalu, panggilan berikutnya di luar rentang 500ms baru bisa jalan.!
