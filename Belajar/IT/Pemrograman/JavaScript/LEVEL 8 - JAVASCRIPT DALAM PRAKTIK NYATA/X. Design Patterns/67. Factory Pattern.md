# Factory Pattern

## Penjelasan
Factory pattern adalah pola desain pembuatan objek di mana kita menggunakan fungsi (factory) untuk membuat objek daripada menggunakan `new` secara langsung. Factory menentukan tipe objek apa yang dibuat berdasarkan input, menyembunyikan logika kompleks di balik satu antarmuka.

## Fungsi
- Menyembunyikan kompleksitas pembuatan objek
- Memungkinkan pembuatan objek berbeda dengan antarmuka seragam
- Mengurangi duplikasi kode pembuatan objek

## Cara Pengimplementasian

```javascript
// Factory Pattern — analogi RUMAH: pabrik pembuatan furniture
// Kamu pesan "kursi", pabrik langsung kirim kursi tanpa kamu tahu cara bikinnya

function pabrikFurniture(jenisFurniture) {
  const spesifikasi = {
    kayu: "Jati",
    warna: "Coklat",
    garansi: "5 tahun"
  };

  const base = {
    infospesifikasi() {
      return `${this.jenis}: ${this.bahan} | ${this.ukuran}`;
    }
  };

  if (jenisFurniture === "kursi") {
    return {
      ...base,
      jenis: "Kursi",
      bahan: spesifikasi.kayu,
      ukuran: "40x40x90 cm",
      duduki() { return "Duduk di kursi"; }
    };
  }

  if (jenisFurniture === "meja") {
    return {
      ...base,
      jenis: "Meja",
      bahan: spesifikasi.kayu,
      ukuran: "120x60x75 cm",
      taruhBarang() { return "Barang ditaruh di meja"; }
    };
  }

  if (jenisFurniture === "lemari") {
    return {
      ...base,
      jenis: "Lemari",
      bahan: `${spesifikasi.kayu} + Multiplek`,
      ukuran: "80x40x180 cm",
      simpanBaju() { return "Baju disimpan di lemari"; }
    };
  }

  throw new Error(`Furniture "${jenisFurniture}" tidak tersedia`);
}

// Penggunaan — tanpa factory
// const kursi = { jenis: "Kursi", bahan: "Jati", ukuran: "40x40x90", ... };
// const meja = { jenis: "Meja", bahan: "Jati", ukuran: "120x60x75", ... };
// Banyak duplikasi!

// Dengan factory
const kursi = pabrikFurniture("kursi");
console.log(kursi.infospesifikasi()); // "Kursi: Jati | 40x40x90 cm"
console.log(kursi.duduki());          // "Duduk di kursi"

const meja = pabrikFurniture("meja");
console.log(meja.infospesifikasi());  // "Meja: Jati | 120x60x75 cm"
console.log(meja.taruhBarang());      // "Barang ditaruh di meja"
```

## Analogi
Factory pattern = **pabrik pembuatan furniture rumah**. Kamu tidak perlu tahu cara menebang pohon, mengolah kayu, merakit kursi, atau mengecat — kamu cukup telepon pabrik dan pesan "satu kursi jati". Pabrik (factory) yang mengurus semua kerumitan produksi dan mengirimkan kursi jadi. Kalau kamu pesan "meja", pabrik juga bisa buatkan dengan proses yang berbeda, tapi kamu tetap terima produk jadi tanpa tahu detailnya. Bedanya dengan `new`: factory bisa memutuskan untuk mengembalikan objek yang sudah ada (reuse) atau membuat yang baru — mirip pabrik yang punya stok gudang.

## Dipakai Untuk Apa
- Membuat objek dengan konfigurasi kompleks
- Pembuatan objek berdasarkan kondisi runtime
- Mengganti constructor ketika logika pembuatan berubah
- Implementasi Dependency Injection sederhana

## Kesalahan Umum
1. **Factory terlalu gemuk** — satu factory menangani terlalu banyak jenis, lebih baik dipisah
2. **Kehilangan jejak tipe** — objek dari factory tidak punya `instanceof` yang jelas (beda dengan class)
3. **Over-engineering** — untuk objek sederhana, factory tidak diperlukan
4. **Factory di dalam factory** — abstraksi berlapis yang membingungkan

## Keterkaitan dengan Materi Sebelumnya
Di Level 4, kamu belajar constructor function dan class. Factory pattern hadir sebagai alternatif yang lebih fleksibel — tidak terikat pada `new` atau prototype chain. Di Level 7, kamu lihat pattern module yang mirip: module factory (fungsi yang return object) digunakan luas di Node.js (misal: `require('express')` return factory function). Factory juga sering dipakai bersama Dependency Injection.

## Soal Latihan

Apa output dari kode berikut?

```javascript
const pabrik = (tipe) => ({
  tipe,
  bunyi() { return tipe === "bel" ? "Ding-Dong" : "Kotek-Kotek"; }
});

const belRumah = pabrik("bel");
console.log(belRumah.bunyi());
const ayam = pabrik("ayam");
console.log(ayam.bunyi());
console.log(belRumah instanceof Object);
```

>!Output: `"Ding-Dong"`, lalu `"Kotek-Kotek"`, lalu `true`. Factory mengembalikan object literal — bukan instance class, jadi instanceof Object tetap true karena semua objek adalah instance Object.!
