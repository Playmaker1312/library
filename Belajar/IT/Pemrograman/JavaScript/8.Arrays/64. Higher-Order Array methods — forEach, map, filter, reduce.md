### Definisi Singkat

**Higher-Order Array methods (forEach, map, filter, reduce)** adalah method array yang menerima **fungsi callback** sebagai argumen. Method ini memungkinkan deklarasi operasi pada array dengan cara yang lebih fungsional dan ekspresif.

---

### Analogi

Bayangkan pabrik pengolahan buah:

- **forEach:** Seperti konveyor yang melewatkan setiap buah — Anda bisa melihat dan mencatat setiap buah, tapi tidak ada hasil baru.
- **map:** Seperti mesin yang mengupas setiap buah — setiap buah masuk, buah kupas keluar. Jumlahnya sama.
- **filter:** Seperti mesin penyortir — hanya buah yang bagus yang lolos. Jumlahnya bisa lebih sedikit.
- **reduce:** Seperti mesin pembuat jus — semua buah dimasukkan, satu hasil jus keluar.

---

### Poin-Poin Penting

- **orEach(callback):** Menjalankan callback untuk setiap elemen. Tidak mengembalikan array baru. Untuk **side effects**.
- **map(callback):** Mengembalikan array baru dengan hasil callback setiap elemen. Panjangnya **sama**.
- **ilter(callback):** Mengembalikan array baru berisi elemen yang **memenuhi kondisi** callback.
- **educe(callback, initialValue):** Mengakumulasi nilai dari seluruh elemen menjadi satu nilai.
- Method ini **tidak mengubah** array asli (immutable).
- Callback menerima (currentValue, index, array).

---

### Contoh Implementasi

`javascript
const angka = [1, 2, 3, 4, 5];

// forEach
angka.forEach((n, i) => {
  console.log(Indeks : );
});

// map
const kuadrat = angka.map(n => n * n);
console.log(kuadrat); // [1, 4, 9, 16, 25]

// filter
const genap = angka.filter(n => n % 2 === 0);
console.log(genap); // [2, 4]

// reduce
const jumlah = angka.reduce((acc, n) => acc + n, 0);
console.log(jumlah); // 15

// Contoh kompleks
const users = [
  { nama: "Budi", usia: 25 },
  { nama: "Ani", usia: 17 },
  { nama: "Cici", usia: 30 }
];

const dewasa = users
  .filter(u => u.usia >= 18)
  .map(u => u.nama.toUpperCase());

console.log(dewasa); // ["BUDI", "CICI"]
`
