### Definisi Singkat

**push, pop, shift, unshift** adalah method array yang memodifikasi array asli (**mutating methods**). push dan pop bekerja di akhir array, sedangkan shift dan unshift bekerja di awal array.

---

### Analogi

Bayangkan antrian di bioskop:

- **push:** Seperti orang baru datang dan antri di **belakang**.
- **pop:** Seperti orang terakhir dalam antrian keluar (dari belakang).
- **shift:** Seperti orang **pertama** dalam antrian masuk ke bioskop (keluar dari depan).
- **unshift:** Seperti orang penting yang "menyerobot" ke **depan** antrian.

---

### Poin-Poin Penting

- **push(elemen):** Menambahkan satu atau lebih elemen ke **akhir** array. Mengembalikan panjang baru.
- **pop():** Menghapus elemen **terakhir** dan mengembalikannya. Array menjadi kosong jika hanya satu elemen.
- **shift():** Menghapus elemen **pertama** dan mengembalikannya. Semua indeks bergeser ke kiri.
- **unshift(elemen):** Menambahkan satu atau lebih elemen ke **awal** array. Semua indeks bergeser ke kanan.
- shift dan unshift lebih lambat dari push/pop karena harus menggeser indeks.

---

### Contoh Implementasi

`javascript
const antrian = ["A", "B", "C"];

// push
antrian.push("D");
console.log(antrian); // ["A", "B", "C", "D"]
console.log(antrian.push("E", "F")); // 6 (panjang baru)

// pop
const orangKeluar = antrian.pop();
console.log(orangKeluar); // "F"
console.log(antrian);     // ["A", "B", "C", "D", "E"]

// shift
const pertama = antrian.shift();
console.log(pertama); // "A"
console.log(antrian); // ["B", "C", "D", "E"]

// unshift
antrian.unshift("Z");
console.log(antrian); // ["Z", "B", "C", "D", "E"]
antrian.unshift("X", "Y");
console.log(antrian); // ["X", "Y", "Z", "B", "C", "D", "E"]
`

---

### Koneksi

Method ini adalah dasar dari **stack** (push/pop — LIFO) dan **queue** (push/shift — FIFO). Ini adalah fondasi struktur data fundamental dalam ilmu komputer.
