### Definisi Singkat

**some, every, flat, flatMap** adalah method array tambahan untuk pengujian dan transformasi. some dan every menguji kondisi pada elemen array (return boolean), sedangkan lat dan latMap digunakan untuk meratakan array bersarang.

---

### Analogi

- **some:** Seperti pemeriksa keamanan — "Apakah **ada** orang yang membawa senjata?" Jika minimal satu ya, hasilnya true.
- **every:** Seperti pemeriksa kualitas — "Apakah **semua** produk memenuhi standar?" Jika ada satu yang tidak, hasilnya false.
- **flat:** Seperti menekan tumpukan kardus menjadi satu lapisan — array bersarang menjadi rata.
- **flatMap:** Seperti map dulu, lalu flat — dua langkah dalam satu method.

---

### Poin-Poin Penting

- **some(callback):** Mengembalikan 	rue jika **minimal satu** elemen memenuhi kondisi. Berhenti jika ketemu.
- **every(callback):** Mengembalikan 	rue jika **semua** elemen memenuhi kondisi. Berhenti jika ada yang gagal.
- **lat(depth):** Meratakan array bersarang hingga kedalaman depth (default 1).
- **latMap(callback):** Sama seperti map() lalu lat(1) — lebih efisien.
- Array kosong: some = alse, every = 	rue.
- latMap hanya flat sedalam 1 level.

---

### Contoh Implementasi

`javascript
const angka = [1, 2, 3, 4, 5];

// some
console.log(angka.some(n => n > 4));  // true (5 > 4)
console.log(angka.some(n => n > 10)); // false

// every
console.log(angka.every(n => n > 0)); // true
console.log(angka.every(n => n % 2 === 0)); // false

// flat
const nested = [1, [2, 3], [4, [5, 6]]];
console.log(nested.flat());         // [1, 2, 3, 4, [5, 6]]
console.log(nested.flat(2));        // [1, 2, 3, 4, 5, 6]

// flatMap
const kalimat = ["halo dunia", "belajar js"];
const kata = kalimat.flatMap(s => s.split(" "));
console.log(kata); // ["halo", "dunia", "belajar", "js"]

// Validasi form
const input = [
  { nilai: "Budi", valid: true },
  { nilai: "Ani", valid: true }
];
console.log(input.every(i => i.valid)); // true
`
