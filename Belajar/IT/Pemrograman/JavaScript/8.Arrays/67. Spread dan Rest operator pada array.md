### Definisi Singkat

**Spread operator (...)** dan **Rest operator (...)** menggunakan sintaks yang sama (...) tetapi dengan tujuan berbeda. **Spread** "menyebarkan" elemen array (atau iterable) menjadi elemen individual. **Rest** mengumpulkan sisa elemen menjadi array.

---

### Analogi

- **Spread (...arr):** Seperti membuka sekotak pensil dan menuangkan semua pensil ke meja — dari satu wadah menjadi banyak item terpisah.
- **Rest (...rest):** Sebaliknya — seperti mengambil sisa pensil dari meja dan memasukkannya ke dalam kotak — dari item terpisah menjadi satu kumpulan.

---

### Poin-Poin Penting

- **Spread untuk array:**
  - Menyalin array: const salinan = [...asli].
  - Menggabungkan array: const gabung = [...a, ...b].
  - Memasukkan elemen: const baru = [a, ...tengah, z].
- **Spread untuk function call:** Math.max(...arr).
- **Rest dalam destructuring:** const [a, ...rest] = arr.
- **Rest dalam parameter fungsi:** unction fn(...args) {}.
- Spread tidak bekerja dengan **deep copy** — hanya shallow copy.

---

### Contoh Implementasi

`javascript
// Spread — menyalin array
const asli = [1, 2, 3];
const salinan = [...asli];
console.log(salinan); // [1, 2, 3]

// Spread — menggabungkan array
const a = [1, 2];
const b = [3, 4];
const gabung = [...a, ...b];
console.log(gabung); // [1, 2, 3, 4]

// Spread — menyisipkan di tengah
const tengah = [3, 4];
const hasil = [1, 2, ...tengah, 5, 6];
console.log(hasil); // [1, 2, 3, 4, 5, 6]

// Spread — function call
const angka = [4, 9, 2, 7];
console.log(Math.max(...angka)); // 9

// Rest — parameter fungsi
function jumlahkan(...args) {
  return args.reduce((acc, n) => acc + n, 0);
}
console.log(jumlahkan(1, 2, 3)); // 6

// Rest — destructuring
const [first, second, ...sisanya] = [10, 20, 30, 40, 50];
console.log(first, second, sisanya); // 10, 20, [30, 40, 50]
`
