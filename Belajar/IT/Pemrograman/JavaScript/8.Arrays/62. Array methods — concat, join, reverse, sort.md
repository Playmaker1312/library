### Definisi Singkat

**concat, join, reverse, sort** adalah method array untuk transformasi. concat menggabungkan array, join mengubah array menjadi string, everse membalik urutan, dan sort mengurutkan elemen.

---

### Analogi

- **concat:** Seperti menyambung dua utas tali menjadi satu utas panjang.
- **join:** Seperti merangkai manik-manik (elemen) menjadi kalung (string) dengan benang (separator).
- **reverse:** Seperti membalik urutan kartu remi.
- **sort:** Seperti mengatur buku di rak berdasarkan abjad.

---

### Poin-Poin Penting

- **concat(arr1, arr2, ...):** Menggabungkan array. Tidak mengubah array asli. Alternatif: spread operator.
- **join(separator):** Menggabungkan semua elemen array menjadi string, dipisahkan oleh separator. Default koma.
- **everse():** Membalik urutan elemen. **Mengubah array asli**.
- **sort(compareFn):** Mengurutkan elemen sebagai **string** secara default. **Mengubah array asli**.
- Sorting default sort() tidak akurat untuk angka (karena diubah ke string). Gunakan **compare function**: sort((a, b) => a - b).

---

### Contoh Implementasi

`javascript
// concat
const a = [1, 2];
const b = [3, 4];
const c = a.concat(b);
console.log(c); // [1, 2, 3, 4]
console.log(a); // [1, 2] (tidak berubah)

// Alternatif spread
const d = [...a, ...b];

// join
const buah = ["apel", "mangga", "jeruk"];
console.log(buah.join(" - ")); // "apel - mangga - jeruk"
console.log(buah.join());      // "apel,mangga,jeruk"
console.log(buah.join(""));    // "apelmanggajeruk"

// reverse (mutating)
const arr = [1, 2, 3];
arr.reverse();
console.log(arr); // [3, 2, 1]

// sort default (string)
const angka = [10, 5, 80, 2];
angka.sort();
console.log(angka); // [10, 2, 5, 80] (salah!)

// sort dengan compare function
angka.sort((a, b) => a - b);
console.log(angka); // [2, 5, 10, 80] (benar)

// sort descending
angka.sort((a, b) => b - a);
console.log(angka); // [80, 10, 5, 2]
`

---

### Koneksi

concat dan join sering digunakan bersama **spread operator** (materi 67). sort dengan compare function adalah dasar untuk **pengurutan data** di tabel dan daftar.
