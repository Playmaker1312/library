### Definisi Singkat

**String transformation methods** adalah method bawaan JavaScript yang digunakan untuk mengubah tampilan atau format string. Mencakup 	oUpperCase, 	oLowerCase, 	rim, dan eplace — berguna untuk normalisasi teks, penghapusan spasi, dan penggantian karakter.

---

### Analogi

Bayangkan Anda mengedit dokumen di Word:

- **toUpperCase:** Mengubah semua huruf menjadi KAPITAL.
- **toLowerCase:** Mengubah semua huruf menjadi kecil.
- **trim:** Memotong spasi berlebih di awal dan akhir (seperti fitur "Trim" di Excel).
- **replace:** Fitur "Find & Replace" — mencari kata lalu menggantinya dengan kata lain.

---

### Poin-Poin Penting

- **.toUpperCase():** Mengubah seluruh string menjadi huruf kapital.
- **.toLowerCase():** Mengubah seluruh string menjadi huruf kecil.
- **.trim():** Menghapus spasi putih (spasi, tab, newline) dari kedua ujung string.
- **.trimStart() / .trimEnd():** Hanya menghapus dari awal atau akhir (ES2019).
- **.replace(searchValue, newValue):** Mengganti kemunculan **pertama** dari searchValue. Untuk ganti semua, gunakan regex dengan flag g.
- **.replaceAll(searchValue, newValue):** Mengganti semua kemunculan tanpa regex (ES2021).
- Semua method ini **tidak mengubah string asli** (immutable).

---

### Contoh Implementasi

`javascript
const pesan = "   Halo Dunia!   ";

// toUpperCase dan toLowerCase
console.log(pesan.toUpperCase()); // "   HALO DUNIA!   "
console.log(pesan.toLowerCase()); // "   halo dunia!   "

// trim
console.log(pesan.trim());        // "Halo Dunia!"

// replace
console.log(pesan.trim().replace("Dunia", "JavaScript")); // "Halo JavaScript!"

// replaceAll
const kalimat = "katak dan kucing";
console.log(kalimat.replaceAll("ka", "ba")); // "batak dan bucing"
`

---

### Koneksi

Method 	rim sering digunakan bersama **split** (materi 48) untuk membersihkan data CSV atau input form. eplace dengan regex adalah fondasi untuk **pattern matching** yang lebih kompleks.
