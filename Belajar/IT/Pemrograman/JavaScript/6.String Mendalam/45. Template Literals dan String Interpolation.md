### Definisi Singkat

**Template Literals** adalah fitur ES6 yang memungkinkan penulisan string dengan kemampuan lebih dibandingkan string biasa. Ditandai dengan backtick (`  `) dan mendukung **string interpolation** yaitu penyisipan ekspresi JavaScript langsung ke dalam string menggunakan sintaks ${ekspresi}.

---

### Analogi

Bayangkan Anda membuat kartu ucapan:

- **Tanpa template literal:** Anda harus menulis "Halo, " + nama + "!" — seperti menempelkan potongan kertas satu per satu.
- **Dengan template literal:** Anda bisa menulis Halo, ! — seperti mencetak langsung seluruh kalimat dengan bagian kosong yang diisi otomatis.

---

### Poin-Poin Penting

- **String Interpolation:** Gunakan ${...} untuk menyisipkan ekspresi seperti variabel, operasi matematika, atau bahkan panggilan fungsi.
- **Multi-line String:** Baris baru dalam template literal akan otomatis menjadi baris baru dalam string, tanpa perlu \n.
- **Expression Evaluation:** Ekspresi di dalam ${} akan dievaluasi terlebih dahulu sebelum dimasukkan ke string.
- **Nested Template:** Template literal bisa bersarang di dalam template literal lain.
