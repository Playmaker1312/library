### Definisi Singkat
Getter (`get`) dan setter (`set`) adalah method spesial dalam class yang memungkinkan properti diakses seperti properti biasa tetapi dengan logika tambahan (enkapsulasi, validasi, komputasi).

---
### Analogi
Seperti petugas resepsionis: Anda minta "nama" (get), petugas mengecek database lalu memberikannya. Anda ganti "nama" (set), petugas memvalidasi dulu sebelum menyimpan.

---
### Poin-Poin Penting
- Getter: mengakses nilai seolah properti, tanpa tanda kurung
- Setter: mengubah nilai dengan validasi/logika tambahan
- Menggunakan keyword `get` dan `set` di depan method
- Membantu enkapsulasi tanpa mengubah API eksternal
- Biasa digunakan untuk computed properties

---
### Contoh Implementasi
```javascript
class Person {
  constructor(firstName, lastName, age) {
    this.firstName = firstName;
    this.lastName = lastName;
    this._age = age; // _ menandakan internal/private (konvensi)
  }

  // Getter
  get fullName() {
    return `${this.firstName} ${this.lastName}`;
  }

  // Setter
  set fullName(name) {
    const parts = name.split(' ');
    this.firstName = parts[0];
    this.lastName = parts[1] || '';
  }

  // Getter dan setter dengan validasi
  get age() {
    return this._age;
  }

  set age(value) {
    if (value < 0 || value > 150) {
      throw new Error('Umur tidak valid');
    }
    this._age = value;
  }

  // Computed property
  get initials() {
    return `${this.firstName[0]}.${this.lastName[0]}.`;
  }
}

const person = new Person('Andi', 'Pratama', 25);
console.log(person.fullName);   // "Andi Pratama" — getter
console.log(person.initials);   // "A.P." — computed

person.fullName = 'Budi Santoso'; // setter
console.log(person.firstName); // "Budi"

try {
  person.age = 200; // Error!
} catch (e) {
  console.log(e.message); // "Umur tidak valid"
}
```

---
### Koneksi
Berkaitan dengan **encapsulation**, **property accessors**, **data validation**, dan **computed properties**.
