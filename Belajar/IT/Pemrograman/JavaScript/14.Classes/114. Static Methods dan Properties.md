### Definisi Singkat
Static methods dan properties adalah anggota class yang dimiliki oleh class itu sendiri, bukan oleh instance. Diakses langsung melalui class, bukan melalui objek instance.

---
### Analogi
Seperti papan pengumuman sekolah: informasi di papan (static) bisa dilihat semua siswa tanpa perlu masuk kelas. Tapi setiap siswa punya buku catatan pribadi (instance) masing-masing.

---
### Poin-Poin Penting
- Dideklarasikan dengan keyword `static`
- Dipanggil melalui `ClassName.method()` bukan `instance.method()`
- Tidak bisa diakses dari instance (`instance.method()` error)
- `this` dalam static method merujuk ke class (bukan instance)
- Sering digunakan untuk utility/helper functions dan konfigurasi

---
### Contoh Implementasi
```javascript
class MathUtils {
  // Static property
  static PI = 3.14159;
  static VERSION = '1.0.0';

  // Static method
  static kuadrat(x) {
    return x * x;
  }

  static lingkaran(r) {
    return this.PI * r * r;
  }

  // Instance method biasa
  instanceMethod() {
    console.log('Ini method instance');
  }
}

// Static — dipanggil langsung dari class
console.log(MathUtils.PI);            // 3.14159
console.log(MathUtils.kuadrat(5));    // 25
console.log(MathUtils.lingkaran(7));  // 153.93791

// Instance — tidak bisa akses static
const m = new MathUtils();
// m.kuadrat(5); // TypeError!
m.instanceMethod(); // OK

// Static method untuk factory
class User {
  constructor(name) {
    this.name = name;
  }

  static createAnonymous() {
    return new User('Anonymous');
  }

  static fromJSON(json) {
    const data = JSON.parse(json);
    return new User(data.name);
  }
}

const anon = User.createAnonymous();
const fromApi = User.fromJSON('{"name":"Budi"}');
```
