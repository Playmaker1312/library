### Definisi Singkat
`constructor` adalah method spesial dalam class yang otomatis dipanggil saat membuat instance baru dengan keyword `new`. Fungsinya untuk menginisialisasi properti objek.

---
### Analogi
Seperti mesin perakitan mobil: saat Anda memesan mobil (`new`), mesin (constructor) langsung memasang komponen dasar seperti mesin, roda, dan setir sesuai spesifikasi yang diberikan.

---
### Poin-Poin Penting
- Hanya boleh ada SATU constructor per class
- Jika tidak didefinisikan, JavaScript menyediakan constructor default kosong
- Constructor default untuk class turunan memanggil `super(...args)`
- Keyword `new` wajib untuk memanggil constructor class
- Constructor bisa mengembalikan object secara eksplisit (override instance)

---
### Contoh Implementasi
```javascript
class Person {
  constructor(name, age) {
    console.log('Constructor dipanggil!');
    this.name = name;
    this.age = age;
  }

  greet() {
    console.log(`Halo, saya ${this.name}, ${this.age} tahun`);
  }
}

// Constructor dipanggil otomatis saat new
const andi = new Person('Andi', 25); // "Constructor dipanggil!"
andi.greet(); // "Halo, saya Andi, 25 tahun"

// Constructor default implisit
class TanpaConstructor {
  // constructor default: constructor() {}
}
const obj = new TanpaConstructor();

// Constructor di inheritance
class Employee extends Person {
  constructor(name, age, role) {
    super(name, age); // wajib panggil parent constructor
    this.role = role;
  }
}
const budi = new Employee('Budi', 30, 'Developer');
budi.greet(); // "Halo, saya Budi, 30 tahun"
```
