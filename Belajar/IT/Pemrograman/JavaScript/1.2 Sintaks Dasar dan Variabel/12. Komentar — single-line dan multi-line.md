### Definisi Singkat

Komentar di dalam JavaScript adalah baris teks yang diabaikan oleh _engine_ saat program dieksekusi. Komentar digunakan untuk memberikan penjelasan, mendokumentasikan kode, atau untuk menonaktifkan sementara suatu baris kode.

---

### Analogi

Bayangkan seperti **catatan tempel (_sticky notes_) pada dokumen atau buku**:

- **Single-line comment** seperti catatan kecil di pinggir halaman untuk mengingatkan fungsi dari satu baris tertentu.
    
- **Multi-line comment** seperti ringkasan paragraf atau catatan pendahuluan yang ditempelkan di awal bab untuk menjelaskan keseluruhan dokumen kepada pembaca lain.
    

---

### Poin-Poin Penting

- **Single-line Comments (Komentar Satu Baris):**
    
    - Ditandai dengan dua garis miring `//`.
        
    - Semua teks setelah `//` hingga akhir baris akan diabaikan oleh _engine_.
        
    - Sangat cocok untuk penjelasan singkat.
        
- **Multi-line Comments (Komentar Banyak Baris):**
    
    - Diawali dengan `/*` dan diakhiri dengan `*/`.
        
    - Semua teks di antara kedua tanda tersebut akan diabaikan, mencakup beberapa baris sekaligus.
        
    - Sering digunakan untuk dokumentasi fungsi yang lebih panjang atau lisensi kode.
        
- **Manfaat dalam Pengembangan:**
    
    - Membantu _developer_ lain (atau diri Anda sendiri di masa depan) memahami alur kode.
        
    - Mempermudah proses _troubleshooting_ (dengan _comment out_ kode yang dicurigai bermasalah).
        

---

### Contoh Implementasi

Berikut adalah penerapan komentar satu baris dan banyak baris di dalam kode JavaScript:

JavaScript

```
// Ini adalah komentar single-line. Engine akan mengabaikan baris ini.
let namaPengguna = "Andi"; // Komentar juga bisa diletakkan di akhir baris kode

/*
   Ini adalah komentar multi-line.
   Anda bisa menulis penjelasan yang panjang tanpa takut error.
   Fungsi di bawah ini digunakan untuk menjumlahkan dua angka.
*/
function tambah(a, b) {
    return a + b;
}

// console.log("Baris ini di-comment dan tidak akan dieksekusi");
```

### Koneksi

Dalam bidang **Web Development**, penggunaan komentar yang baik sangat penting untuk mendukung kolaborasi tim:

- Membantu rekan kerja memahami logika kompleks, seperti cara kerja algoritma pada sebuah fitur atau manipulasi DOM.
    
- Memudahkan proses pemeliharaan jangka panjang (_code maintenance_), sehingga _developer_ tidak perlu membaca ulang seluruh logika dari nol.
