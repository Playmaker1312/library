# 14. Perbedaan var vs let vs const – scope dan hoisting

**Definisi Singkat:** Hoisting adalah mekanisme JavaScript yang memindahkan deklarasi (tapi bukan inisialisasi) ke atas scope; var di-hoist dengan nilai undefined, sedangkan let/const masuk Temporal Dead Zone.

**Analogi:** Hoisting seperti reservasi kursi di restoran — var seperti menaruh kartu nama (tandanya ada, tapi kosong), let/const seperti memesan kursi tapi meja belum siap sampai pelayan benar-benar datang (TDZ — error kalau dipakai sebelum siap).

**Poin-Poin Penting:**
- `var` di-hoist ke atas function scope: `console.log(x)` sebelum deklarasi menghasilkan `undefined` (bukan error)
- `let` dan `const` di-hoist tapi tidak diinisialisasi — akses sebelum deklarasi menghasilkan ReferenceError (TDZ)
- Function declaration di-hoist sepenuhnya — bisa dipanggil sebelum didefinisikan
- Function expression (const fn = () => {}) mengikuti aturan const — tidak di-hoist
- Block scope: `{}` membatasi `let`/`const` tapi tidak `var`

**Contoh Kode:**
```javascript
// === HOISTING DEMONSTRASI ===
console.log("=== Hoisting: var vs let vs const ===\n");

// 1. var hoisting — undefined, bukan error
console.log("var sebelum deklarasi:", varX); // undefined (bukan error!)
var varX = 10;
console.log("var setelah deklarasi:", varX);

// 2. let hoisting — ReferenceError (TDZ)
try {
  console.log(letY); // ReferenceError
} catch (e) {
  console.log("let sebelum deklarasi: ERROR —", e.message);
}
let letY = 20;
console.log("let setelah deklarasi:", letY);

// 3. const hoisting — ReferenceError (TDZ)
try {
  console.log(constZ); // ReferenceError
} catch (e) {
  console.log("const sebelum deklarasi: ERROR —", e.message);
}
const constZ = 30;
console.log("const setelah deklarasi:", constZ);

// 4. Function declaration — fully hoisted
console.log("\nfunction declaration:", sapa("Budi"));
function sapa(nama) {
  return `Halo ${nama}`;
}

// 5. Function expression — tidak di-hoist
try {
  console.log(sapaArrow("Ani")); // ERROR
} catch (e) {
  console.log("Arrow function sebelum deklarasi: ERROR —", e.message);
}
const sapaArrow = (nama) => `Halo ${nama}`;
console.log("Arrow function setelah deklarasi:", sapaArrow("Ani"));

// 6. Visualisasi hoisting var
// Kode ini:
console.log("\nVisualisasi hoisting:");
var warna = "merah";
// Sebenarnya dieksekusi seperti:
// var warna;
// console.log(warna); // undefined
// warna = "merah";
```
Hasil:
```
=== Hoisting: var vs let vs const ===

var sebelum deklarasi: undefined
var setelah deklarasi: 10
let sebelum deklarasi: ERROR — Cannot access 'letY' before initialization
let setelah deklarasi: 20
const sebelum deklarasi: ERROR — Cannot access 'constZ' before initialization
const setelah deklarasi: 30

function declaration: Halo Budi
Arrow function sebelum deklarasi: ERROR — Cannot access 'sapaArrow' before initialization
Arrow function setelah deklarasi: Halo Ani

Visualisasi hoisting:
undefined
merah
```

**Kasus Penggunaan Nyata:** Bug hoisting sering terjadi di kode lama dengan var — developer modern menggunakan `let`/`const` dan rule `no-var` di ESLint untuk mencegah ini, serta function declaration untuk callback yang perlu tersedia sebelum eksekusi.
