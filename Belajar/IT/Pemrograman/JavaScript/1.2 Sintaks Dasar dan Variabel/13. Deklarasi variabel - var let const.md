# 13. Deklarasi variabel – var let const

**Definisi Singkat:** `var`, `let`, dan `const` adalah keyword untuk mendeklarasikan variabel di JavaScript; `let` dan `const` (ES6) lebih disarankan karena memiliki block scope dan tidak hoisting-error.

**Analogi:** `var` seperti buku catatan terbuka yang bisa diubah siapa saja kapan saja, `let` seperti binder halaman per bab (hanya terlihat di bab itu), `const` seperti buku yang dijilid permanen — isinya tetap tidak bisa diganti.

**Poin-Poin Penting:**
- `var`: function-scoped, bisa dideklarasi ulang, hoisting menghasilkan undefined — legacy, hindari
- `let`: block-scoped, tidak bisa dideklarasi ulang di scope sama, hoisting tapi tidak diinisialisasi (TDZ)
- `const`: block-scoped, tidak bisa reassign (untuk objek, propertinya tetap bisa diubah), harus langsung diinisialisasi
- Best practice modern: default `const`, pakai `let` hanya jika butuh reassign, jangan pakai `var`
- Temporal Dead Zone (TDZ): periode antara masuk scope dan deklarasi — akses variabel sebelum deklarasi error

**Contoh Kode:**
```javascript
// === PERBEDAAN VAR, LET, CONST ===
console.log("=== var vs let vs const ===\n");

// var — bisa di-redeclare dan function-scoped
var nama = "Budi";
var nama = "Ani"; // redeclare OK
console.log("var nama:", nama); // Ani

// let — bisa reassign, tidak bisa redeclare
let umur = 25;
umur = 26; // reassign OK
// let umur = 30; // ERROR: redeclare tidak boleh
console.log("let umur:", umur);

// const — tidak bisa reassign, harus langsung diisi
const PI = 3.14159;
// PI = 3.14; // ERROR: const tidak bisa reassign
console.log("const PI:", PI);

// const untuk objek — properti tetap bisa diubah
const user = { nama: "Citra" };
user.nama = "Dewi"; // OK — properti objek bisa diubah
// user = {}; // ERROR: reassign objek tidak boleh
console.log("const objek:", user.nama);

// Block scope demo
{
  var varDiBlock = "Saya var — bocor keluar!";
  let letDiBlock = "Saya let — aman di dalam";
  const constDiBlock = "Saya const — aman di dalam";
  console.log("Di dalam block:", letDiBlock, constDiBlock);
}
console.log("var keluar block:", varDiBlock); // bisa diakses
// console.log(letDiBlock); // ERROR: let tidak visible
// console.log(constDiBlock); // ERROR: const tidak visible

// Best practice
const hargaBarang = 10000; // default const
let quantity = 3;          // let karena akan diubah
quantity += 2;
console.log("Total:", hargaBarang * quantity);
```
Hasil:
```
=== var vs let vs const ===

var nama: Ani
let umur: 26
const PI: 3.14159
const objek: Dewi
Di dalam block: Saya let — aman di dalam Saya const — aman di dalam
var keluar block: Saya var — bocor keluar!
Total: 50000
```

**Kasus Penggunaan Nyata:** Di codebase React modern, `const` dipakai untuk komponen, state, dan config; `let` hanya untuk loop counter atau nilai yang memang perlu diubah seperti accumulator.
