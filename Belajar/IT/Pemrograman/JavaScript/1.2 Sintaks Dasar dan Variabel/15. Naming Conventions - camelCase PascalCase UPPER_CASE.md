# 15. Naming Conventions – camelCase PascalCase UPPER_CASE

**Definisi Singkat:** Naming conventions adalah aturan tidak tertulis (best practice) untuk menamai variabel, fungsi, kelas, dan konstanta agar kode konsisten dan mudah dibaca.

**Analogi:** Seperti seragam sekolah — setiap kelompok (variabel, fungsi, kelas) punya seragam berbeda agar langsung dikenali perannya tanpa perlu membaca detail.

**Poin-Poin Penting:**
- **camelCase**: kata pertama huruf kecil, kata berikutnya kapital — untuk variabel, fungsi, properti objek (`namaUser`, `hitungTotal()`)
- **PascalCase**: setiap kata diawali kapital — untuk class, constructor, komponen React (`class Pengguna`, `function Navbar()`)
- **UPPER_CASE** (UPPER_SNAKE_CASE): semua kapital dengan underscore — untuk konstanta global yang tetap (`MAX_SIZE`, `API_KEY`, `COLORS`)
- **kebab-case**: huruf kecil dengan strip — untuk file/folder di project (tidak valid di JS variable)
- **snake_case**: huruf kecil dengan underscore — jarang di JS, lebih umum di Python/Ruby (tapi valid)

**Contoh Kode:**
```javascript
// === NAMING CONVENTIONS ===
console.log("=== Naming Conventions ===\n");

// 1. camelCase — variabel dan fungsi
const namaLengkap = "Budi Santoso";
const hitungTotalBelanja = (harga, jumlah) => harga * jumlah;
let jumlahBarang = 5;

console.log("camelCase variabel:", namaLengkap);
console.log("camelCase fungsi:", hitungTotalBelanja(10000, jumlahBarang));

// 2. PascalCase — class dan constructor
class Pengguna {
  constructor(nama, umur) {
    this.nama = nama;
    this.umur = umur;
  }
  perkenalan() {
    return `${this.nama}, ${this.umur} tahun`;
  }
}
const user = new Pengguna("Ani", 25);
console.log("PascalCase class:", user.perkenalan());

// 3. UPPER_CASE — konstanta tetap
const PI = 3.14159;
const MAX_RETRY_COUNT = 3;
const API_BASE_URL = "https://api.example.com/v1";
const DAYS_IN_WEEK = 7;

console.log("UPPER_CASE konstanta:", PI, MAX_RETRY_COUNT);

// 4. Kapan pakai yang mana?
let totalPendapatan = 0;          // camelCase — variabel biasa
const TAX_RATE = 0.11;            // UPPER_CASE — nilai tetap global
class ItemKeranjang { }           // PascalCase — class

// 5. Hindari nama yang membingungkan
// ❌ Hindari: let x = 5; (tidak deskriptif)
// ❌ Hindari: let data = {}; (terlalu umum)
// ✅ Pakai: let jumlahProduk = 5; (deskriptif)
// ✅ Pakai: let konfigurasiUser = {}; (spesifik)

console.log("\nBest practice: nama deskriptif > nama pendek");
```
Hasil:
```
=== Naming Conventions ===

camelCase variabel: Budi Santoso
camelCase fungsi: 50000
PascalCase class: Ani, 25 tahun
UPPER_CASE konstanta: 3.14159 3

Best practice: nama deskriptif > nama pendek
```

**Kasus Penggunaan Nyata:** Di project React, komponen menggunakan PascalCase (`export default function UserProfile() {}`), file menggunakan kebab-case (`user-profile.jsx`), state/event handler camelCase (`const [isOpen, setIsOpen] = useState(false)`).
