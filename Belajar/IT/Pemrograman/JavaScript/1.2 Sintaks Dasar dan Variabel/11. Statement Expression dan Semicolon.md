# 11. Statement Expression dan Semicolon

**Definisi Singkat:** Statement adalah instruksi yang melakukan aksi (tidak menghasilkan nilai), sedangkan expression adalah kode yang menghasilkan nilai; semicolon (;) mengakhiri statement meskipun opsional di JS modern.

**Analogi:** Statement seperti perintah "Tutup pintu!" — tidak ada nilai, hanya aksi. Expression seperti "Suhu ruangan 25°C" — menghasilkan informasi. Semicolon seperti titik di akhir kalimat — menandakan selesai.

**Poin-Poin Penting:**
- Statement: `let x = 5;`, `if (x > 0) { }`, `for (;;) { }`, `return;`
- Expression: `5 + 3`, `"Halo"`, `fungsi()`, `x > 0 ? "ya" : "tidak"`
- Semicolon opsional karena ASI (Automatic Semicolon Insertion) — tapi bisa berbahaya
- Contoh error ASI: `return` di baris sendiri akan menambahkan `;` setelah `return` → return undefined
- Best practice: gunakan semicolon secara eksplisit atau gunakan Prettier/ESLint untuk konsistensi

**Contoh Kode:**
```javascript
// === STATEMENT vs EXPRESSION ===
console.log("=== Statement vs Expression ===\n");

// Expression — menghasilkan nilai
const hasilExpression = 5 + 3;        // expression 5+3 menghasilkan 8
console.log("Expression 5+3:", hasilExpression);

const stringExpr = "Halo " + "Dunia";  // expression
console.log("Expression string:", stringExpr);

// Statement — instruksi, tidak menghasilkan nilai
let x = 10;  // statement deklarasi
if (x > 5) { // statement if
  console.log("Statement: x lebih besar dari 5");
}

// Function expression vs function statement
const funcExpr = function() { return "Ini function expression"; };
console.log(funcExpr());

function funcStatement() {
  return "Ini function statement";
}
console.log(funcStatement());

// Bahaya tanpa semicolon — ASI error
function contohError() {
  return           // ASI akan tambah ; di sini!
  {
    pesan: "Ini objek";
  };
}
console.log("Tanpa semicolon:", contohError()); // undefined!

// Benar: semicolon eksplisit
function contohBenar() {
  return {
    pesan: "Ini objek"
  };
}
console.log("Dengan semicolon:", contohBenar().pesan);
```
Hasil:
```
=== Statement vs Expression ===

Expression 5+3: 8
Expression string: Halo Dunia
Statement: x lebih besar dari 5
Ini function expression
Ini function statement
Tanpa semicolon: undefined
Dengan semicolon: Ini objek
```

**Kasus Penggunaan Nyata:** Prettier dan ESLint di project React/Vue akan otomatis menambahkan semicolon di akhir setiap statement untuk mencegah bug ASI yang sulit dilacak.
