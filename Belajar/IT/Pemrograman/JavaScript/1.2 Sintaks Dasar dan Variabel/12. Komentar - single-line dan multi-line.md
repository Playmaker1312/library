# 12. Komentar – single-line dan multi-line

**Definisi Singkat:** Komentar adalah teks yang diabaikan oleh JavaScript engine — digunakan untuk menjelaskan kode, menonaktifkan sementara, atau dokumentasi inline.

**Analogi:** Seperti sticky notes di lembar Laporan KP — warnanya mencolok (//) untuk catatan singkat, atau kertas tempel besar (/* */) untuk penjelasan panjang yang direkatkan di halaman.

**Poin-Poin Penting:**
- Single-line: `//` — komentar sampai akhir baris, untuk penjelasan pendek
- Multi-line: `/* */` — komentar bisa beberapa baris, untuk dokumentasi atau blok
- JSDoc: `/** */` — format multi-line khusus untuk dokumentasi fungsi/kelas
- Komentar berguna untuk "mengapa" bukan "apa" — kode sudah menjelaskan apa yang dilakukan
- Jangan tinggalkan kode mati (commented out code) di produksi — gunakan version control

**Contoh Kode:**
```javascript
// === TIPE-TIPE KOMENTAR DI JAVASCRIPT ===
console.log("=== Komentar JavaScript ===\n");

// 1. SINGLE-LINE COMMENT
// Ini komentar satu baris
// compiler mengabaikan semua setelah //
const nama = "Budi"; // komentar bisa di samping kode

// 2. MULTI-LINE COMMENT
/*
  Ini komentar multi-line
  Bisa untuk beberapa baris sekaligus
  Berguna untuk menonaktifkan blok kode
*/
const umur = 25;

// 3. JSDOC COMMENT — dokumentasi fungsi
/**
 * Menghitung total belanja setelah diskon
 * @param {number} harga - harga awal
 * @param {number} diskon - persentase diskon
 * @returns {number} total setelah diskon
 */
function hitungTotal(harga, diskon) {
  return harga - (harga * diskon) / 100;
}
console.log("Total setelah diskon:", hitungTotal(100000, 20));

// 4. TODO comment — menandai pekerjaan yang belum selesai
// TODO: tambahkan validasi input di fungsi ini
// FIXME: perbaiki bug overflow untuk angka besar

// 5. Comment out code — untuk debugging
// const hasil = 10 + 20;
const hasil = 30 + 40; // versi baru
console.log("Hasil:", hasil);
```
Hasil:
```
=== Komentar JavaScript ===

Total setelah diskon: 80000
Hasil: 70
```

**Kasus Penggunaan Nyata:** JSDoc comment dipakai untuk dokumentasi otomatis di VS Code IntelliSense — saat developer mengetik `hitungTotal(` akan muncul deskripsi parameter; TODO comments di track oleh VS Code Explorer → TODO Tree.
