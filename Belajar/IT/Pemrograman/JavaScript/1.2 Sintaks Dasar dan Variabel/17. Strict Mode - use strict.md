# 17. Strict Mode – use strict

**Definisi Singkat:** Strict mode adalah mode ketat JavaScript yang menonaktifkan fitur-fitur bermasalah dan ketinggalan zaman, menjadikan debugging lebih mudah dengan mengubah silent errors menjadi explicit errors.

**Analogi:** Seperti meja operasi dengan protokol ketat — semua alat harus steril, gerakan harus terukur, tidak ada yang asal-asalan. Strict mode memaksa kode mengikuti standar yang rapi dan aman.

**Poin-Poin Penting:**
- Aktifkan dengan menulis `"use strict";` di baris pertama file atau function
- Mencegah penggunaan variabel tanpa deklarasi — `x = 5` error (harus `let x = 5`)
- Mengubah silent errors (misal delete variabel) menjadi throw error
- `this` di function biasa menjadi `undefined` (bukan global object) — mencegah bug
- Menonaktifkan fitur lama seperti `with`, `arguments.callee`, duplicate parameter names
- Semua modul ES6 (`import/export`) dan class otomatis dalam strict mode

**Contoh Kode:**
```javascript
// === STRICT MODE DEMO ===
"use strict";

console.log("=== Strict Mode ===\n");

// 1. Variabel harus dideklarasi — silent error jadi explicit error
try {
  // nama = "Budi"; // ReferenceError: nama is not defined
  const nama = "Budi"; // harus pakai let/const
  console.log("1. Deklarasi wajib:", nama);
} catch (e) {
  console.log("1. Error:", e.message);
}

// 2. Delete variabel tidak bisa
try {
  let x = 10;
  // delete x; // SyntaxError
  console.log("2. Delete variabel dicegah");
} catch (e) {
  console.log("2. Error:", e.message);
}

// 3. this di function biasa = undefined
function cekThis() {
  console.log("3. this di strict mode:", this); // undefined
}
cekThis();

// 4. this di method object tetap objeknya
const user = {
  nama: "Ani",
  sapa() {
    console.log("4. this di method:", this.nama);
  }
};
user.sapa();

// 5. Duplicate parameter name tidak boleh
try {
  // function jumlah(a, a) { return a + a; } // SyntaxError
  function jumlah(a, b) { return a + b; }
  console.log("5. Fungsi tanpa duplikat:", jumlah(3, 4));
} catch (e) {
  console.log("5. Error:", e.message);
}

// 6. with statement dilarang di strict mode
try {
  // with (Math) { console.log(PI); } // SyntaxError
  console.log("6. with statement dilarang");
} catch (e) {
  console.log("6. Error:", e.message);
}

// Non-strict mode untuk perbandingan
console.log("\n7. Non-strict: x = 5 bisa (tapi jangan tiru!)");
console.log("Strict mode = kode lebih aman & rapi");
```
Hasil:
```
=== Strict Mode ===

1. Deklarasi wajib: Budi
2. Delete variabel dicegah
3. this di strict mode: undefined
4. this di method: Ani
5. Fungsi tanpa duplikat: 7
6. with statement dilarang
7. Non-strict: x = 5 bisa (tapi jangan tiru!)
Strict mode = kode lebih aman & rapi
```

**Kasus Penggunaan Nyata:** Semua project modern (React, Vue, Next.js) menggunakan ES Modules yang otomatis strict mode; file tools/build scripts juga biasa menambahkan `"use strict"` di baris pertama untuk mencegah bug global variable leaking.
