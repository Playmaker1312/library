### Definisi Singkat
Error handling pada async/await menggunakan blok `try-catch` — sama seperti synchronous code. `await` yang gagal (Promise rejected) akan melempar error yang bisa ditangkap di blok `catch`. `finally` bisa digunakan untuk cleanup.

---

### Analogi
Kamu coba menarik uang di ATM:
- **try**: Masukkan kartu, masukkan PIN, tarik uang.
- **catch**: Jika saldo tidak cukup atau ATM error — kamu dapat pesan error.
- **finally**: Kartu dikeluarkan kembali apa pun hasilnya.

---

### Poin-Poin Penting
- `try { ... }` berisi kode yang mungkin gagal (termasuk `await`).
- `catch(err) { ... }` menangkap error dari Promise yang rejected atau exception yang dilempar di `try`.
- `finally { ... }` selalu dijalankan — cocok untuk cleanup (tutup koneksi, loading = false).
- `try-catch` bisa menangkap **synchronous error** dan **asynchronous rejection** sekaligus.
- Bisa memiliki multiple `try-catch` di blok berbeda untuk error handling lebih granular.

---

### Contoh Implementasi

```javascript
function fetchData(shouldFail) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (shouldFail) reject(new Error('Gagal ambil data'));
      else resolve('Data sukses');
    }, 1000);
  });
}

async function load() {
  try {
    const data = await fetchData(false);
    console.log(data); // Data sukses
  } catch (err) {
    console.error('Error:', err.message);
  }
}

load();
```

Try-catch dengan finally:

```javascript
async function loadWithLoading() {
  showLoading(true);
  try {
    const data = await fetchData();
    render(data);
  } catch (err) {
    showError(err.message);
  } finally {
    showLoading(false); // Selalu jalan — loading hilang
  }
}
```

Multiple try-catch untuk error handling granular:

```javascript
async function processOrder(orderId) {
  try {
    const user = await fetchUser(orderId);
    try {
      const payment = await processPayment(user.id);
      console.log('Payment OK:', payment);
    } catch (paymentErr) {
      console.error('Payment gagal:', paymentErr.message);
      await cancelOrder(orderId);
    }
  } catch (userErr) {
    console.error('User tidak ditemukan:', userErr.message);
  }
}
```

Menangkap error tanpa try-catch (menggunakan .catch):

```javascript
async function risky() {
  const data = await fetchData(true).catch(err => {
    console.error('Fallback:', err.message);
    return 'Data default';
  });
  console.log(data); // Data default (tidak crash)
}
```

---

### Koneksi
`try-catch` adalah analogi `.catch()` pada Promise chain. Pilih `try-catch` untuk kode async/await yang bersih, dan `.catch()` untuk one-liner atau partial error handling. Lanjut ke **perbandingan async/await vs Promise chaining**.
