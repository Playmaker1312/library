### Definisi Singkat
Async/await dan Promise chaining sama-sama menangani operasi asynchronous — perbedaannya pada gaya penulisan. Async/await membuat kode async terlihat seperti synchronous (lebih mudah dibaca), sedangkan Promise chaining menggunakan `.then()` dan `.catch()` secara berantai.

---

### Analogi
**Promise chaining** seperti daftar instruksi berpoin: "Ambil telur → Kocok → Goreng → Sajikan." Setiap langkah terpisah dan berantai.
**Async/await** seperti resep naratif: "Kocok telur, lalu goreng, lalu sajikan." Lebih mengalir dan alami untuk dibaca.

---

### Poin-Poin Penting
- **Async/await** lebih mudah dibaca dan di-debug — terutama untuk chain yang panjang.
- **Promise chaining** lebih eksplisit menggunakan `.then()` — baik untuk operasi paralel sederhana.
- Async/await memiliki **error handling terpusat** dengan `try-catch`.
- Promise chaining lebih cocok untuk **transformasi data bertahap** (map/filter tiap .then).
- Keduanya bisa dikombinasikan dalam satu proyek.

---

### Contoh Implementasi

**Promise Chaining:**

```javascript
fetch('/api/user')
  .then(res => res.json())
  .then(user => fetch(`/api/orders/${user.id}`))
  .then(res => res.json())
  .then(orders => {
    console.log('User:', orders.user);
    console.log('Orders:', orders.list);
  })
  .catch(err => console.error('Error:', err));
```

**Async/Await (setara):**

```javascript
async function loadUserOrders() {
  try {
    const userRes = await fetch('/api/user');
    const user = await userRes.json();
    const ordersRes = await fetch(`/api/orders/${user.id}`);
    const orders = await ordersRes.json();
    console.log('User:', orders.user);
    console.log('Orders:', orders.list);
  } catch (err) {
    console.error('Error:', err);
  }
}
```

**Kapan pakai Promise chaining:**

```javascript
// Paralel — lebih ringkas pakai Promise.all
Promise.all([
  fetch('/api/a'),
  fetch('/api/b')
]).then(([a, b]) => console.log(a, b));

// Transformasi data bertahap
fetch('/api/items')
  .then(res => res.json())
  .then(items => items.filter(i => i.active))
  .then(active => active.map(i => i.name))
  .then(names => console.log(names));
```

**Kombinasi keduanya:**

```javascript
async function getConfig() {
  const base = await fetch('/api/config');
  const extras = await Promise.all([
    fetch('/api/feature-a'),
    fetch('/api/feature-b')
  ]);
  return { base, extras };
}
```

---

### Koneksi
Pilih async/await untuk keterbacaan dan debugging yang lebih baik pada flow kompleks. Pilih Promise chaining untuk chain transformasi paralel atau sederhana. Keduanya bekerja pada **Promise** yang sama. Selanjutnya pelajari **async/await pada array methods**.
