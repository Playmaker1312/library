### Definisi Singkat
`async function` adalah deklarasi fungsi yang selalu mengembalikan Promise. Kata kunci `async` ditempatkan sebelum `function` — membuat fungsi otomatis membungkus nilai return-nya dalam Promise yang fulfilled, dan error yang dilempar menjadi Promise rejected.

---

### Analogi
Kamu tempel stiker **"Kirim lewat kurir"** pada kotak kue. Sebelumnya, kamu antar sendiri kue ke teman (synchronous). Sekarang, kurir yang antar — kamu tinggal kasih ke kurir, dan dia akan memberikannya ke temanmu (**return Promise**). Temanmu tidak langsung pegang kue-nya, tapi mendapat janji bahwa kue akan sampai.

---

### Poin-Poin Penting
- `async function` selalu mengembalikan Promise — jika return nilai biasa, dibungkus `Promise.resolve()`.
- Jika fungsi melempar error, Promise akan rejected dengan error tersebut.
- `async` bisa digunakan pada: function declaration, function expression, arrow function, dan method.
- Cocok dipasangkan dengan `await` di dalamnya.
- Eksekusi fungsi async tetap synchronous sampai `await` ditemui.

---

### Contoh Implementasi

```javascript
// async function declaration
async function getData() {
  return 'Hello';
}

getData().then(console.log); // Hello
// getData() mengembalikan Promise yang fulfilled dengan 'Hello'
```

Return nilai biasa vs error:

```javascript
async function success() {
  return 42;
}

async function fail() {
  throw new Error('Something went wrong');
}

success().then(console.log); // 42
fail().catch(err => console.log(err.message)); // Something went wrong
```

Berbagai bentuk deklarasi async:

```javascript
// Function expression
const fetchUser = async function (id) {
  return { id, name: 'Andi' };
};

// Arrow function
const getPosts = async () => {
  return ['Post 1', 'Post 2'];
};

// Object method
const service = {
  async load() {
    return 'Data loaded';
  }
};

// Class method
class Api {
  async fetch(endpoint) {
    const response = await fetch(endpoint);
    return response.json();
  }
}
```

---

### Koneksi
`async function` adalah pintu masuk ke dunia **async/await**. Tanpa `async`, kata kunci `await` tidak bisa digunakan. Setelah deklarasi async, pelajari **await** untuk menunggu Promise di dalam fungsi async.
