### Definisi Singkat
Array methods seperti `forEach`, `map`, `filter`, dan `reduce` perlu perhatian khusus saat dikombinasikan dengan async/await. Tidak semua array method bekerja seperti yang diharapkan dengan fungsi async — terutama `forEach` yang tidak menunggu Promise.

---

### Analogi
Kamu punya 5 kue dan 5 oven. Metode yang kamu pilih menentukan hasilnya:
- **forEach + async**: Kamu masukkan semua kue ke oven bersamaan — tidak tahu mana yang matang duluan.
- **map + Promise.all**: Kamu catat waktu masing-masing kue, lalu cek semuanya setelah semua matang.
- **for...of + await**: Kamu panggang satu per satu — kue kedua baru masuk setelah kue pertama matang.

---

### Poin-Poin Penting
- `forEach` dengan callback async **tidak menunggu** — semua Promise dijalankan paralel.
- `map` dengan async callback mengembalikan array Promise — gunakan `Promise.all()`.
- `for...of` dengan `await` menjalankan operasi **berurutan** (satu per satu).
- `filter` dengan async callback tidak langsung berfungsi — perlu custom filter.
- `reduce` dengan async bisa untuk sequential execution.

---

### Contoh Implementasi

**`forEach` + async — tidak sequential:**

```javascript
async function processItems(items) {
  items.forEach(async (item) => {
    const result = await process(item); // Tidak ditunggu!
    console.log(result);
  });
  console.log('Selesai'); // Jalan duluan!
}
```

**`map` + `Promise.all` — paralel:**

```javascript
async function fetchAll(urls) {
  const promises = urls.map(async (url) => {
    const res = await fetch(url);
    return res.json();
  });
  const results = await Promise.all(promises);
  return results;
}

fetchAll(['/api/a', '/api/b', '/api/c'])
  .then(data => console.log(data));
```

**`for...of` — sequential (satu per satu):**

```javascript
async function processSequential(items) {
  for (const item of items) {
    const result = await process(item);
    console.log(result);
  }
  console.log('Semua selesai'); // Jalan setelah loop selesai
}
```

**`filter` — custom async filter:**

```javascript
async function asyncFilter(array, asyncPredicate) {
  const results = await Promise.all(
    array.map(asyncPredicate)
  );
  return array.filter((_, index) => results[index]);
}

// Usage
const numbers = [1, 2, 3, 4, 5];
const even = await asyncFilter(numbers, async (n) => {
  return n % 2 === 0;
});
console.log(even); // [2, 4]
```

**`reduce` — sequential dengan async:**

```javascript
async function sequentialReduce(items) {
  const result = await items.reduce(async (accPromise, item) => {
    const acc = await accPromise;
    const processed = await process(item);
    return acc + processed;
  }, Promise.resolve(0));
  return result;
}
```

---

### Koneksi
Memahami perilaku array methods dengan async/await penting untuk menghindari bug halus. Untuk operasi paralel gunakan `map` + `Promise.all`, untuk sequential gunakan `for...of` + `await`. Lanjut ke **Top-Level Await**.
