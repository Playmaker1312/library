### Definisi Singkat
**Event delegation** adalah teknik memasang satu event listener di elemen parent untuk menangani event dari banyak elemen child, memanfaatkan mekanisme **bubbling**. Cocok untuk elemen dinamis yang ditambahkan setelah halaman dimuat.

---

### Analogi
Event delegation seperti **resepsionis di kantor**. Daripada setiap ruangan punya bel sendiri, cukup satu resepsionis yang menerima semua tamu dan mengarahkan ke ruangan yang tepat berdasarkan informasi tamu.

---

### Poin-Poin Penting
- Pasang listener di parent, tangani event dari child via `event.target`
- Sangat efisien — satu listener untuk banyak elemen
- Bekerja untuk elemen yang ditambahkan secara dinamis
- Gunakan `closest()` untuk memastikan target sesuai yang diinginkan
- Perhatikan `stopPropagation()` — bisa mengganggu delegation

---

### Contoh Implementasi

```javascript
// Tanpa delegation — satu per satu
document.querySelectorAll('.item').forEach(item => {
  item.addEventListener('click', () => console.log(item.textContent));
});
// Masalah: item baru tidak punya listener

// Dengan delegation
const list = document.querySelector('ul#daftar');

list.addEventListener('click', (e) => {
  // Cari element .item terdekat
  const item = e.target.closest('li');
  if (!item) return; // Bukan li yang diklik

  console.log('Item diklik:', item.textContent);
  item.classList.toggle('selected');
});

// Delegation untuk multiple tipe
document.addEventListener('click', (e) => {
  if (e.target.matches('.btn-delete')) {
    e.target.closest('tr')?.remove();
  }
  if (e.target.matches('.btn-edit')) {
    const id = e.target.dataset.id;
    console.log('Edit id:', id);
  }
});
```
