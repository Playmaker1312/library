### Definisi Singkat
**Event propagation** adalah mekanisme DOM tentang bagaimana event menyebar dari satu elemen ke elemen lainnya. Ada tiga fase: **capturing** (dari root ke target), **target** (sampai di elemen yang dituju), dan **bubbling** (dari target kembali ke root).

---

### Analogi
Seperti **melempar batu ke kolam**. Batu jatuh di satu titik (target), lalu riak menyebar ke luar (bubbling). Sebaliknya, capturing seperti riak dari tepi kolam yang mengerucut ke titik jatuh batu.

---

### Poin-Poin Penting
- **Bubbling** (default): event naik dari target ke root (`<div>` → `<body>` → `<html>` → `document`)
- **Capturing**: event turun dari root ke target (perlu `{ capture: true }`)
- `event.target` — elemen yang memicu event (paling dalam)
- `event.currentTarget` — elemen tempat listener dipasang
- `stopPropagation()` menghentikan propagation di fase apapun
- Tidak semua event bubbling — `focus`, `blur`, `scroll`, `load` tidak bubble

---

### Contoh Implementasi

```javascript
// HTML: <div id="outer"><div id="inner"><button id="btn">Klik</button></div></div>

const outer = document.getElementById('outer');
const inner = document.getElementById('inner');
const btn = document.getElementById('btn');

// Bubbling (default) — dari btn → inner → outer
outer.addEventListener('click', (e) => console.log('OUTER'));
inner.addEventListener('click', (e) => console.log('INNER'));
btn.addEventListener('click', (e) => console.log('BTN'));
// Klik button → "BTN" → "INNER" → "OUTER"

// Capturing
outer.addEventListener('click', (e) => {
  console.log('OUTER capture');
}, { capture: true });
// Klik button → "OUTER capture" dulu, baru bubbling

// Stop propagation
inner.addEventListener('click', (e) => {
  e.stopPropagation(); // Berhenti di inner
  console.log('INNER — berhenti');
});
```
