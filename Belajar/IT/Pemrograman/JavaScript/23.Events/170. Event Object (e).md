### Definisi Singkat
**Event object** (biasanya disingkat `e` atau `event`) adalah objek yang secara otomatis diberikan ke event handler ketika event terjadi. Objek ini berisi properti dan method yang menjelaskan detail event — elemen target, posisi mouse, tombol keyboard, dan lain-lain.

---

### Analgi
Event object seperti **laporan polisi** setelah kecelakaan. Laporan itu berisi detail: siapa yang terlibat (`target`), kapan terjadi (`timestamp`), di mana posisinya (`clientX`, `clientY`), dan jenis kejadiannya (`type`).

---

### Poin-Poin Penting
- Parameter pertama callback: `element.addEventListener('click', (e) => {...})`
- Properti umum: `type`, `target`, `currentTarget`, `timeStamp`, `bubbles`, `cancelable`
- Properti mouse: `clientX`, `clientY`, `pageX`, `pageY`, `screenX`, `screenY`
- Properti keyboard: `key`, `code`, `shiftKey`, `ctrlKey`, `altKey`
- Method: `preventDefault()`, `stopPropagation()`, `stopImmediatePropagation()`

---

### Contoh Implementasi

```javascript
document.addEventListener('click', (e) => {
  console.log('=== Event Object ===');
  console.log('Type:', e.type);               // "click"
  console.log('Target:', e.target);            // Elemen yang diklik
  console.log('Current target:', e.currentTarget); // document
  console.log('Timestamp:', e.timeStamp);      // Waktu event
  console.log('Posisi mouse:', e.clientX, e.clientY);
  console.log('Tombol:', e.button);            // 0 = kiri
  console.log('Bubbles:', e.bubbles);          // true
  console.log('Cancelable:', e.cancelable);    // true
});

document.addEventListener('keydown', (e) => {
  console.log(`Tombol ${e.key} ditekan (kode: ${e.code})`);
  if (e.key === 'Enter') console.log('Enter!');
  if (e.ctrlKey && e.key === 's') {
    e.preventDefault();
    console.log('Ctrl+S dicegah');
  }
});
```
