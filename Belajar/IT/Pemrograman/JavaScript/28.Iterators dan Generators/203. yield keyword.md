### Definisi Singkat

`yield` adalah keyword dalam generator function yang menghentikan (pause) eksekusi fungsi dan mengembalikan nilai ke pemanggil. Saat `next()` dipanggil lagi, eksekusi dilanjutkan dari titik setelah `yield`. Keyword ini hanya valid di dalam `function*`.

---

### Analogi

Seperti **rambu "berhenti sejenak" di tur museum**. Pemandu berhenti (`yield`), menjelaskan suatu koleksi, lalu melanjutkan tur saat semua siap. Peserta tur bisa melihat koleksi, lalu berjalan untuk mengikuti tur lagi.

---

### Poin-Poin Penting

- `yield` mengembalikan nilai ke pemanggil dan menjeda eksekusi
- Eksekusi dilanjutkan saat `next()` dipanggil berikutnya
- `yield` bisa menerima nilai dari luar via `next(value)` — nilai tersebut menjadi hasil dari ekspresi `yield`
- Fungsi bisa memiliki banyak `yield`
- `yield` hanya bisa digunakan langsung di dalam `function*`, bukan di nested function
- `yield` bersifat lazy — nilai hanya dihitung saat diminta

---

### Contoh Implementasi

```javascript
function* numberGenerator() {
  const a = yield 1;          // yield 1, lalu terima input
  console.log('a =', a);
  const b = yield 2;          // yield 2, lalu terima input
  console.log('b =', b);
  const c = yield 3;          // yield 3, lalu terima input
  console.log('c =', c);
  return 'selesai';
}

const gen = numberGenerator();
console.log(gen.next());      // { value: 1, done: false }  → yield 1
console.log(gen.next('A'));   // a = A  → { value: 2, done: false }
console.log(gen.next('B'));   // b = B  → { value: 3, done: false }
console.log(gen.next('C'));   // c = C  → { value: 'selesai', done: true }

// yield dalam loop
function* range(start, end, step = 1) {
  for (let i = start; i <= end; i += step) {
    yield i;
  }
}

for (const n of range(1, 5)) {
  console.log(n); // 1, 2, 3, 4, 5
}
```
