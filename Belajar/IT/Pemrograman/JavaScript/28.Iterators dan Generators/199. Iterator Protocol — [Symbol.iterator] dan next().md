### Definisi Singkat

Iterator Protocol adalah kontrak dalam JavaScript yang mendefinisikan cara untuk menghasilkan urutan nilai (baik terbatas maupun tidak terbatas) melalui method `next()`. Sebuah objek dianggap sebagai iterator jika ia memiliki method `next()` yang mengembalikan objek berbentuk `{ value: any, done: boolean }`.

---

### Analogi

Bayangkan sebuah **tiket nomor antrean di klinik**. Setiap kali Anda memanggil `next()`, Anda mendapat nomor urut berikutnya. Begitu semua nomor habis, petugas akan bilang "sudah selesai" (`done: true`).

---

### Poin-Poin Penting

- Iterator Protocol adalah protokol tingkat rendah untuk iterasi
- Method `next()` wajib mengembalikan objek dengan properti `value` dan `done`
- `done: true` menandakan iterasi telah selesai
- Iterator bersifat stateful — ia melacak posisi saat ini
- Protocol ini digunakan secara internal oleh `for...of`, spread operator, `destructuring`, dll.

---

### Contoh Implementasi

```javascript
function createIterator(array) {
  let index = 0;
  return {
    next() {
      if (index < array.length) {
        return { value: array[index++], done: false };
      }
      return { value: undefined, done: true };
    }
  };
}

const iterator = createIterator(['a', 'b', 'c']);
console.log(iterator.next()); // { value: 'a', done: false }
console.log(iterator.next()); // { value: 'b', done: false }
console.log(iterator.next()); // { value: 'c', done: false }
console.log(iterator.next()); // { value: undefined, done: true }
```
