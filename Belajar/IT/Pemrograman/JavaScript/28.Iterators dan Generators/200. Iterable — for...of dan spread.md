### Definisi Singkat

Iterable adalah objek yang mengimplementasikan method `[Symbol.iterator]`, sehingga dapat diiterasi menggunakan `for...of`, spread operator (`...`), `Array.from()`, dan destructuring. Array, String, Map, Set, dan NodeList adalah contoh iterable bawaan.

---

### Analogi

Sebuah **buku kupon makanan** adalah iterable. Anda bisa membuka kupon satu per satu dengan `for...of`, atau mengambil semua kupon sekaligus dengan spread (`...`). Buku itu sendiri tahu cara memberikan kupon berikutnya melalui `[Symbol.iterator]`.

---

### Poin-Poin Penting

- Objek dikatakan iterable jika memiliki method di `[Symbol.iterator]`
- Method `[Symbol.iterator]` harus mengembalikan iterator (objek dengan `next()`)
- `for...of` memanggil `[Symbol.iterator]` sekali, lalu `next()` berulang hingga `done: true`
- Spread operator `...` juga menggunakan iterable protocol
- Object literal TIDAK iterable secara default
- Array, String, Map, Set, TypedArray, arguments, NodeList adalah iterable bawaan

---

### Contoh Implementasi

```javascript
// Membuat objek iterable
const range = {
  from: 1,
  to: 5,
  [Symbol.iterator]() {
    let current = this.from;
    const last = this.to;
    return {
      next() {
        if (current <= last) {
          return { value: current++, done: false };
        }
        return { value: undefined, done: true };
      }
    };
  }
};

// for...of
for (const num of range) {
  console.log(num); // 1, 2, 3, 4, 5
}

// Spread operator
const numbers = [...range];
console.log(numbers); // [1, 2, 3, 4, 5]

// Array.from
const arr = Array.from(range);
console.log(arr); // [1, 2, 3, 4, 5]
```
