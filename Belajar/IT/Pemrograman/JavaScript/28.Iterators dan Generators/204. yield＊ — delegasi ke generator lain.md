### Definisi Singkat

`yield*` adalah sintaks dalam generator function untuk mendelegasikan eksekusi ke generator (atau iterable) lain. Alih-alih menghasilkan nilai satu per satu, `yield*` akan mengambil semua nilai dari generator target dan menghasilkan semuanya secara berurutan.

---

### Analogi

Seperti **manajer yang mendelegasikan tugas ke tim**. Manajer tidak mengerjakan semuanya sendiri, tapi menyerahkan (`yield*`) seluruh proyek ke tim ahli. Hasil dari tim langsung diteruskan ke klien tanpa campur tangan manajer.

---

### Poin-Poin Penting

- `yield*` bekerja dengan generator function atau iterable (Array, String, dll)
- Semua nilai dari generator yang didelegasikan akan dihasilkan satu per satu
- Nilai `return` dari generator yang didelegasikan bisa ditangkap
- Berguna untuk komposisi dan reusability generator
- Dapat digunakan untuk rekursi pada struktur data tree
- Delegasi bersifat transparan — pemanggil tidak tahu sedang mendelegasi

---

### Contoh Implementasi

```javascript
function* gen1() {
  yield 1;
  yield 2;
}

function* gen2() {
  yield* gen1();   // delegasi ke gen1
  yield 3;
  yield 4;
}

console.log([...gen2()]); // [1, 2, 3, 4]

// yield* dengan iterable array
function* joinGenerators() {
  yield* [10, 20, 30];
  yield* 'ABC';
}

console.log([...joinGenerators()]); // [10, 20, 30, 'A', 'B', 'C']

// yield* rekursif untuk tree traversal
function* flattenTree(tree) {
  if (Array.isArray(tree)) {
    for (const branch of tree) {
      yield* flattenTree(branch);
    }
  } else {
    yield tree;
  }
}

const tree = [1, [2, [3, 4], 5], 6];
console.log([...flattenTree(tree)]); // [1, 2, 3, 4, 5, 6]
```
