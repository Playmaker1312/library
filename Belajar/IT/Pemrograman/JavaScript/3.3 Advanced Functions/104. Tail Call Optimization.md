### Definisi Singkat
Tail Call Optimization (TCO) adalah optimasi compiler/interpreter yang memungkinkan rekursi tanpa menumpuk call stack baru, dengan syarat panggilan rekursif berada di posisi terakhir (tail position) fungsi.

---
### Analogi
Seperti robot yang diberi instruksi "kerjakan tugas A, lalu tugas B, lalu tugas C" tanpa harus kembali ke instruktur di setiap langkah — ia cukup melanjutkan tanpa mengingat langkah sebelumnya.

---
### Poin-Poin Penting
- Panggilan rekursif harus berada di **tail position** (pernyataan terakhir)
- Tidak ada operasi setelah panggilan rekursif
- Menghemat memori dengan mencegah stack overflow
- Hanya diimplementasikan di engine tertentu (JavaScript tidak mewajibkan TCO di spec)
- Strict mode diperlukan di beberapa engine

---
### Contoh Implementasi
```javascript
// Tanpa TCO — menumpuk stack
function faktorial(n) {
  if (n <= 1) return 1;
  return n * faktorial(n - 1); // BUKAN tail call (ada operasi n * )
}

// Dengan TCO — tail call
function faktorialTCO(n, akumulator = 1) {
  if (n <= 1) return akumulator;
  return faktorialTCO(n - 1, n * akumulator); // tail call!
}

console.log(faktorialTCO(5)); // 120

// Contoh lain: sum array
function sumArray(arr, index = 0, total = 0) {
  if (index >= arr.length) return total;
  return sumArray(arr, index + 1, total + arr[index]); // tail call
}
console.log(sumArray([1, 2, 3, 4, 5])); // 15

// Fibonacci dengan TCO
function fibTCO(n, a = 0, b = 1) {
  if (n === 0) return a;
  return fibTCO(n - 1, b, a + b);
}
console.log(fibTCO(10)); // 55
```
