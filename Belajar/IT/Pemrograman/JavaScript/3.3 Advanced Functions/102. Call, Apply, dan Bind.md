### Definisi Singkat
`call`, `apply`, dan `bind` adalah method pada function yang digunakan untuk mengikat nilai `this` secara eksplisit saat fungsi dipanggil.

---
### Analogi
Seperti remote TV yang bisa diprogram ulang: `call` dan `apply` langsung menggunakan remote ke TV tertentu, `bind` membuat remote baru yang sudah terkunci ke TV tertentu.

---
### Poin-Poin Penting
- `call(thisArg, arg1, arg2, ...)` — panggil langsung, argumen terpisah
- `apply(thisArg, [argsArray])` — panggil langsung, argumen array
- `bind(thisArg, ...args)` — mengembalikan fungsi baru dengan `this` tetap
- Berguna untuk method borrowing dan function borrowing

---
### Contoh Implementasi
```javascript
const person1 = { name: 'Andi' };
const person2 = { name: 'Budi' };

function introduce(hobby, age) {
  console.log(`Halo, saya ${this.name}. Hobi: ${hobby}, umur: ${age}`);
}

// call — argumen terpisah
introduce.call(person1, 'membaca', 25);
// "Halo, saya Andi. Hobi: membaca, umur: 25"

// apply — argumen dalam array
introduce.apply(person2, ['berenang', 30]);
// "Halo, saya Budi. Hobi: berenang, umur: 30"

// bind — membuat fungsi baru
const introduceAndi = introduce.bind(person1, 'coding');
introduceAndi(22); // "Halo, saya Andi. Hobi: coding, umur: 22"

// Method borrowing
const arr = [1, 2, 3];
const obj = { 0: 'a', 1: 'b', 2: 'c', length: 3 };
const sliced = Array.prototype.slice.call(obj, 1, 3);
console.log(sliced); // ['b', 'c']
```

---
### Koneksi
Berkaitan dengan **`this` keyword**, **partial application**, **function borrowing**, dan **method chaining**.
