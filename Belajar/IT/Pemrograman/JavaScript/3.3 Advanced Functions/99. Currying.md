### Definisi Singkat
Currying adalah teknik mengubah fungsi yang menerima banyak argumen menjadi rangkaian fungsi yang masing-masing menerima satu argumen.

---
### Analogi
Seperti mesin kopi yang memproses satu langkah setiap kali: pertama masukkan biji → dapatkan bubuk → tambah air → dapatkan kopi. Setiap fungsi hanya butuh satu input.

---
### Poin-Poin Penting
- Mengubah fungsi multi-argumen menjadi fungsi unary bertingkat
- Membantu function composition
- Memungkinkan partial application secara alami
- Berbeda dengan partial application (currying mengubah struktur fungsi)

---
### Contoh Implementasi
```javascript
// Fungsi biasa
function biasa(a, b, c) {
  return a + b + c;
}

// Versi currying
function curried(a) {
  return function (b) {
    return function (c) {
      return a + b + c;
    };
  };
}

console.log(curried(1)(2)(3)); // 6

// Dengan arrow function
const curriedArrow = (a) => (b) => (c) => a + b + c;
console.log(curriedArrow(1)(2)(3)); // 6

// Fungsi curry helper (manual)
function curry(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) {
      return fn(...args);
    }
    return (...next) => curried(...args, ...next);
  };
}

const tambah = (a, b, c) => a + b + c;
const curriedTambah = curry(tambah);
console.log(curriedTambah(1)(2)(3)); // 6
console.log(curriedTambah(1, 2)(3)); // 6
```

---
### Koneksi
Berkaitan erat dengan **partial application**, **function composition**, **higher-order functions**, dan **closures**.
