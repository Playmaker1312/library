### Definisi Singkat
Function composition adalah teknik menggabungkan dua atau lebih fungsi untuk menghasilkan fungsi baru, di mana output dari satu fungsi menjadi input fungsi berikutnya.

---
### Analogi
Seperti ban berjalan di pabrik: bahan mentah masuk ke mesin A, hasilnya langsung diproses mesin B, lalu mesin C. Output setiap tahap adalah input tahap berikutnya.

---
### Poin-Poin Penting
- `compose` menjalankan fungsi dari kanan ke kiri (f(g(x)))
- `pipe` menjalankan fungsi dari kiri ke kanan (g(f(x)))
- Meningkatkan readability dan reusability
- Fungsi yang dikomposisi harus unary (menerima satu argumen) idealnya

---
### Contoh Implementasi
```javascript
// Fungsi compose (kanan ke kiri)
const compose = (...fns) => (x) => fns.reduceRight((acc, fn) => fn(acc), x);

// Fungsi pipe (kiri ke kanan)
const pipe = (...fns) => (x) => fns.reduce((acc, fn) => fn(acc), x);

// Contoh fungsi-fungsi kecil
const kaliDua = (x) => x * 2;
const tambahTiga = (x) => x + 3;
const kuadrat = (x) => x * x;

// Menggunakan compose
const prosesCompose = compose(kuadrat, tambahTiga, kaliDua);
console.log(prosesCompose(5)); // (5*2=10, 10+3=13, 13^2=169) = 169

// Menggunakan pipe
const prosesPipe = pipe(kaliDua, tambahTiga, kuadrat);
console.log(prosesPipe(5)); // sama: 169

// Contoh validasi
const trim = (s) => s.trim();
const lower = (s) => s.toLowerCase();
const sanitasi = compose(trim, lower);
console.log(sanitasi('  HELLO World  ')); // "hello world"
```
