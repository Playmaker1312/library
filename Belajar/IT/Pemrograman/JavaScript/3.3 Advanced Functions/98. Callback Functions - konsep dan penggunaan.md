# 98. Callback Functions - konsep dan penggunaan **Definisi Singkat:** Callback adalah fungsi yang dikirim sebagai argument ke fungsi lain dan dieksekusi setelah tugas tertentu selesai, biasanya untuk async atau event. **Analogi:** Seperti nomor antrian di restoran — kamu diberi pager (callback) yang akan bergetar (dipanggil) saat meja siap. **Poin-Poin Penting:** - Bisa synchronous (langsung dipanggil) atau asynchronous (ditunda) - Callback hell terjadi saat callback bersarang terlalu dalam - Alternatif modern: Promise dan async/await - Callback tetap dipakai di event listener dan Node.js streams**Contoh Kode:** ```javascript // Synchronous callback
function filter(arr, callback) {
  const hasil = [];
  for (const item of arr) {
    if (callback(item)) hasil.push(item);
  }
  return hasil;
}

const ganjil = filter([1, 2, 3, 4, 5], n => n % 2 !== 0);
console.log(ganjil);

// Asynchronous callback
function ambilData(id, callback) {
  setTimeout(() => {
    const data = { id, nama: 'User ' + id };
    callback(data);
  }, 1000);
}

ambilData(1, (data) => {
  console.log('Data diterima:', data);
}); ``` **Hasil:** `[1, 3, 5]` `Data diterima: { id: 1, nama: 'User 1' }` **Kasus Penggunaan Nyata:** Event handlers (`button.addEventListener('click', callback)`), `setTimeout/setInterval`, `fs.readFile` di Node.js, dan request animation frame.
