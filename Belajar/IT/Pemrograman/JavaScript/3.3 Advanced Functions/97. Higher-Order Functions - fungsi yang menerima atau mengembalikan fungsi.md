# 97. Higher-Order Functions - fungsi yang menerima atau mengembalikan fungsi **Definisi Singkat:** Higher-order function adalah fungsi yang menerima fungsi lain sebagai argument atau mengembalikan fungsi, memungkinkan abstraksi dan komposisi. **Analogi:** Seperti chef yang punya asisten — chef (HOF) bisa delegasi tugas ke asisten (callback) atau melatih asisten baru (return function). **Poin-Poin Penting:** - Minimal memenuhi satu: terima callback atau return fungsi - Array methods (`map`, `filter`, `reduce`) adalah HOF klasik - Memungkinkan functional programming - Membuat kode lebih deklaratif dan reusable**Contoh Kode:** ```javascript // HOF yang menerima fungsi
function prosesArray(arr, fn) {
  const hasil = [];
  for (const item of arr) {
    hasil.push(fn(item));
  }
  return hasil;
}

const angka = [1, 2, 3, 4];
const kaliDua = prosesArray(angka, x => x * 2);
console.log(kaliDua);

// HOF yang mengembalikan fungsi
function buatSapa(salam) {
  return function (nama) {
    console.log(`${salam}, ${nama}!`);
  };
}

const sapaPagi = buatSapa('Selamat pagi');
sapaPagi('Rudi');
sapaPagi('Siti'); ``` **Hasil:** `[2, 4, 6, 8]` `Selamat pagi, Rudi!` `Selamat pagi, Siti!` **Kasus Penggunaan Nyata:** `array.map()`, `setTimeout(callback)`, `fetch().then()`, middleware pattern di Express/Koa, dan React HOC (Higher-Order Component).
