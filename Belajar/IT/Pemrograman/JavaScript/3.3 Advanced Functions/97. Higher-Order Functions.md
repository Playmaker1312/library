### Definisi Singkat
Higher-order function adalah fungsi yang menerima fungsi lain sebagai argumen, mengembalikan fungsi lain, atau keduanya. Ini adalah konsep fundamental dalam functional programming.

---
### Analogi
Seperti mesin pabrik yang bisa dipasangi alat berbeda (modul). Alatnya adalah fungsi kecil, dan mesin utamanya adalah higher-order function yang mengatur alur kerja.

---
### Poin-Poin Penting
- Menerima callback function sebagai parameter (contoh: `map`, `filter`, `reduce`)
- Mengembalikan fungsi baru (closures)
- Memungkinkan abstraksi dan komposisi kode
- Contoh built-in: `Array.prototype.map`, `filter`, `reduce`, `setTimeout`, `addEventListener`

---
### Contoh Implementasi
```javascript
// Fungsi yang menerima fungsi lain (callback)
function operasi(angka, callback) {
  return callback(angka);
}

const kaliDua = (x) => x * 2;
console.log(operasi(5, kaliDua)); // 10

// Array built-in higher-order functions
const angka = [1, 2, 3, 4];
const genap = angka.filter((n) => n % 2 === 0);
const kuadrat = angka.map((n) => n * n);
const total = angka.reduce((acc, n) => acc + n, 0);

console.log(genap);   // [2, 4]
console.log(kuadrat); // [1, 4, 9, 16]
console.log(total);   // 10

// Fungsi yang mengembalikan fungsi
function buatPencacah(a) {
  return function (b) {
    return a + b;
  };
}
const tambah5 = buatPencacah(5);
console.log(tambah5(3)); // 8
```

---
### Koneksi
Berkaitan erat dengan **function composition**, **currying**, **partial application**, dan **callback functions**.
