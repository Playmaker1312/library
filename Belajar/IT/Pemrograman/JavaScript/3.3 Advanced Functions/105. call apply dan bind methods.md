# 105. call apply dan bind methods **Definisi Singkat:** `call`, `apply`, dan `bind` adalah method untuk mengatur nilai `this` secara eksplisit saat memanggil atau membuat fungsi. **Analogi:** Seperti remote TV — `call` langsung ganti channel dan lihat hasilnya, `apply` juga langsung ganti channel tapi dengan daftar channel, `bind` memo remote ke channel tertentu agar selalu ke situ. **Poin-Poin Penting:** - `fn.call(this, arg1, arg2)` — panggil langsung, argumen terpisah koma - `fn.apply(this, [arg1, arg2])` — panggil langsung, argumen dalam array - `fn.bind(this)` — buat fungsi baru dengan `this` terikat, tidak langsung panggil - `bind` berguna untuk event handler dan callback async**Contoh Kode:** ```javascript const pembicara = {
  nama: 'Rina',
  perkenalan: function (kota, profesi) {
    console.log(`${this.nama} dari ${kota}, seorang ${profesi}`);
  }
};

const orang1 = { nama: 'Budi' };
const orang2 = { nama: 'Sari' };

// call — argumen terpisah
pembicara.perkenalan.call(orang1, 'Jakarta', 'Dokter');

// apply — argumen array
pembicara.perkenalan.apply(orang2, ['Bandung', 'Desainer']);

// bind — membuat fungsi baru
const kenalinBudi = pembicara.perkenalan.bind(orang1, 'Surabaya');
kenalinBudi('Insinyur');
kenalinBudi('Guru'); // this dan kota sudah terikat

// bind untuk event handler
class Tombol {
  constructor(label) {
    this.label = label;
  }
  klik() {
    console.log(`Tombol ${this.label} diklik`);
  }
}
const btn = new Tombol('OK');
const handler = btn.klik.bind(btn);
handler(); ``` **Hasil:** `Budi dari Jakarta, seorang Dokter` `Sari dari Bandung, seorang Desainer` `Budi dari Surabaya, seorang Insinyur` `Budi dari Surabaya, seorang Guru` `Tombol OK diklik` **Kasus Penggunaan Nyata:** `call`/`apply` untuk borrow method (`Array.prototype.slice.call(arguments)`), `bind` untuk fix `this` di event listener, setTimeout, atau callback React class component.
