Memoization - caching hasil fungsi **Definisi Singkat:** Memoization menyimpan hasil eksekusi fungsi berdasarkan input tertentu, sehingga jika input yang sama datang lagi, hasil diambil dari cache tanpa menghitung ulang. **Analogi:** Seperti buku alamat — daripada menghafal nomor telepon teman setiap kali mau nelpon, kamu lihat di buku (cache) saja. **Poin-Poin Penting:** - Menggunakan closure untuk menyimpan cache - Meningkatkan performa untuk fungsi berat dengan input berulang - Trade-off antara memory dan kecepatan eksekusi - Key cache biasanya argument fungsi — hati-hati dengan objek reference**Contoh Kode:** ```javascript // Generic memoization
function memoize(fn) {
  const cache = new Map();
  return function (...args) {
    const key = JSON.stringify(args);
    if (cache.has(key)) {
      console.log('Cache hit:', key);
      return cache.get(key);
    }
    console.log('Cache miss:', key);
    const hasil = fn(...args);
    cache.set(key, hasil);
    return hasil;
  };
}

// Fibonacci tanpa memo — lambat
function fibLambat(n) {
  if (n <= 1) return n;
  return fibLambat(n - 1) + fibLambat(n - 2);
}

// Fibonacci dengan memo — cepat
const fibCepat = memoize(function (n) {
  if (n <= 1) return n;
  return fibCepat(n - 1) + fibCepat(n - 2);
});

console.log('Tanpa memo:');
console.time('fibLambat');
console.log(fibLambat(35));
console.timeEnd('fibLambat');

console.log('Dengan memo:');
console.time('fibCepat');
console.log(fibCepat(35));
console.log(fibCepat(36));
console.timeEnd('fibCepat'); ``` **Hasil:** `Tanpa memo:` `9227465` `fibLambat: ~150ms` `Dengan memo:` `Cache miss: [35]` `9227465` `Cache miss: [36]` `14930352` `fibCepat: <1ms` **Kasus Penggunaan Nyata:** Komputasi berat (Fibonacci, faktorial), React's `useMemo` dan `useCallback`, caching hasil query database, dan rendering ulang komponen yang mahal.
