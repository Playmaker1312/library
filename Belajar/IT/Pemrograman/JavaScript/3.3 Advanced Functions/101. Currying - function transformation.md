# 101. Currying - function transformation **Definisi Singkat:** Currying adalah transformasi fungsi dengan banyak parameter menjadi rangkaian fungsi bertingkat, masing-masing menerima satu parameter. **Analogi:** Seperti memesan kopi — pertama pilih ukuran (cup), lalu jenis kopi (bean), lalu tambahan (topping). Setiap langkah mengembalikan pilihan berikutnya. **Poin-Poin Penting:** - `f(a,b,c)` menjadi `f(a)(b)(c)` — setiap panggilan return fungsi baru - Memungkinkan partial application (terapkan parameter sebagian) - Meningkatkan reusability dan komposisi fungsi - Bisa dibuat dengan arrow function yang ringkas**Contoh Kode:** ```javascript // Currying manual
const sapa = (salam) => (nama) => (tanda) =>
  console.log(`${salam}, ${nama}${tanda}`);

sapa('Halo')('Dewi')('!');
sapa('Selamat pagi')('Eko')('.');

const sapaInggris = sapa('Hello');
sapaInggris('John')('!');
sapaInggris('Jane')('?');

// Currying dengan helper
function curry(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) {
      return fn(...args);
    }
    return (...more) => curried(...args, ...more);
  };
}

const tambah = (a, b, c) => a + b + c;
const curriedTambah = curry(tambah);
console.log(curriedTambah(1)(2)(3));
console.log(curriedTambah(1, 2)(3)); ``` **Hasil:** `Halo, Dewi!` `Selamat pagi, Eko.` `Hello, John!` `Hello, Jane?` `6` `6` **Kasus Penggunaan Nyata:** Logging dengan level (`log('INFO')('message')`), konfigurasi bertahap, dan event handler dengan parameter tetap parsial.
