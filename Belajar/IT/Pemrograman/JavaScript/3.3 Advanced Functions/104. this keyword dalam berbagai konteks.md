# 104. this keyword dalam berbagai konteks **Definisi Singkat:** `this` adalah keyword yang merujuk ke objek pemilik fungsi yang sedang dieksekusi, nilainya berubah tergantung bagaimana fungsi dipanggil. **Analogi:** `this` seperti kata "saya" — artinya berubah tergantung siapa yang bicara. Di kelas, "saya" berarti guru; di rumah, "saya" berarti Ibu. **Poin-Poin Penting:** - Global: `this` = `window` (browser) / `global` (Node.js) - Method objek: `this` = objek pemilik - Constructor (`new`): `this` = instance baru - Arrow: `this` = lexical (dari scope luar) - Event handler: `this` = elemen yang menerima event**Contoh Kode:** ```javascript // Global
console.log(this === window); // browser, atau {} di Node

// Method objek
const user = {
  nama: 'Budi',
  sapa: function () {
    console.log(`Halo, ${this.nama}`);
  }
};
user.sapa();

// Arrow function — lexical this
const user2 = {
  nama: 'Sari',
  sapa: () => {
    console.log(`Halo, ${this.nama}`);
  }
};
user2.sapa(); // this dari luar (global)

// Constructor
function Orang(nama) {
  this.nama = nama;
}
const andi = new Orang('Andi');
console.log(andi.nama);

// Explicit binding
function kenalan() {
  console.log(`Nama saya ${this.nama}`);
}
kenalan.call({ nama: 'Dewi' }); ``` **Hasil:** `true` (Node: `false` — `{}`) `Halo, Budi` `Halo, undefined` `Andi` `Nama saya Dewi` **Kasus Penggunaan Nyata:** Method objek, constructor class, event handler DOM, dan pemanggilan fungsi dengan context tertentu pakai `call`/`apply`.
