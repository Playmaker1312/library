# 99. Pure Functions vs Impure Functions **Definisi Singkat:** Pure function selalu mengembalikan output yang sama untuk input yang sama tanpa efek samping; impure function sebaliknya. **Analogi:** Pure seperti mesin kalkulator — tekan 2+2 selalu hasil 4; impure seperti lempar dadu — hasilnya berbeda setiap kali meskipun lemparan sama. **Poin-Poin Penting:** - Pure: deterministic + no side effects — mudah di-test dan di-debug - Efek samping: mengubah global var, I/O, DOM, DB, Math.random() - Pure function tidak mengubah argument (immutability) - Impure function diperlukan untuk interaksi dengan dunia nyata**Contoh Kode:** ```javascript // Pure function
function tambah(a, b) {
  return a + b;
}

console.log(tambah(2, 3));
console.log(tambah(2, 3));

// Impure function — side effect
let counter = 0;
function increment() {
  counter++;
  return counter;
}

console.log(increment());
console.log(increment());

// Impure — mengubah input
function tambahKeArray(arr, item) {
  arr.push(item); // Mutasi!
  return arr;
}
const angka = [1, 2];
tambahKeArray(angka, 3);
console.log(angka); ``` **Hasil:** `5` `5` `1` `2` `[1, 2, 3]` **Kasus Penggunaan Nyata:** Pure function untuk utility logic, reducers di Redux, dan validasi; impure function untuk API calls, DOM manipulation, dan logging.
