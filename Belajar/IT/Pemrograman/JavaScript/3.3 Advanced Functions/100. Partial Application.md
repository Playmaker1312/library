### Definisi Singkat
Partial application adalah teknik menerapkan sebagian argumen dari suatu fungsi, menghasilkan fungsi baru yang menunggu argumen sisanya.

---
### Analogi
Seperti memesan pizza setengah jadi: tentukan jenis roti dan saus dulu, nanti tinggal pilih topping saat mau dimakan.

---
### Poin-Poin Penting
- Menggunakan `Function.prototype.bind()` untuk partial application
- Tidak mengubah struktur fungsi seperti currying
- Berguna untuk membuat fungsi spesifik dari fungsi umum
- Meningkatkan reusability kode

---
### Contoh Implementasi
```javascript
// Partial application dengan bind
function kali(a, b) {
  return a * b;
}

const kaliDua = kali.bind(null, 2);
console.log(kaliDua(5)); // 10
console.log(kaliDua(10)); // 20

// Implementasi manual partial
function partial(fn, ...fixedArgs) {
  return function (...remainingArgs) {
    return fn(...fixedArgs, ...remainingArgs);
  };
}

function greet(greeting, name) {
  return `${greeting}, ${name}!`;
}

const sayHello = partial(greet, 'Halo');
const sayGoodbye = partial(greet, 'Selamat tinggal');

console.log(sayHello('Andi'));   // "Halo, Andi!"
console.log(sayGoodbye('Budi')); // "Selamat tinggal, Budi!"

// Contoh dengan 3 parameter
function formatAngka(prefix, suffix, angka) {
  return `${prefix}${angka}${suffix}`;
}

const rupiah = partial(formatAngka, 'Rp ', ',-');
console.log(rupiah(15000)); // "Rp 15000,-"
```

---
### Koneksi
Berkaitan erat dengan **currying**, **bind method**, **higher-order functions**, dan **function composition**.
