Recursion - fungsi rekursif **Definisi Singkat:** Rekursi adalah teknik di mana fungsi memanggil dirinya sendiri untuk menyelesaikan masalah dengan memecahnya menjadi sub-masalah yang lebih kecil. **Analogi:** Seperti boneka Matryoshka — buka boneka besar, di dalamnya ada boneka lebih kecil, terus sampai boneka terkecil (base case). **Poin-Poin Penting:** - Wajib memiliki base case untuk menghentikan rekursi — jika tidak, stack overflow - Setiap panggilan rekursif mengurangi masalah menuju base case - Lebih elegan untuk masalah yang inherently recursive (tree, factorial) - Bisa digantikan loop, tapi rekursi lebih ekspresif**Contoh Kode:** ```javascript // Faktorial: n! = n * (n-1)!
function faktorial(n) {
  if (n <= 1) return 1; // base case
  return n * faktorial(n - 1);
}

console.log(faktorial(5));
console.log(faktorial(3));

// Fibonacci
function fib(n) {
  if (n <= 1) return n;
  return fib(n - 1) + fib(n - 2);
}

console.log(fib(7));

// Traverse nested object
const menu = {
  nama: 'root',
  anak: [
    { nama: 'a', anak: [] },
    { nama: 'b', anak: [{ nama: 'b1', anak: [] }] }
  ]
};
function cetakSemua(node) {
  console.log(node.nama);
  for (const child of node.anak) cetakSemua(child);
}
cetakSemua(menu); ``` **Hasil:** `120` `6` `13` `root` `a` `b` `b1` **Kasus Penggunaan Nyata:** Traversal tree DOM, file system directory reader, algoritma graph (DFS), parsing JSON/XML, dan komponen React recursive untuk nested comments.
