# 102. Function Composition **Definisi Singkat:** Function composition adalah teknik menggabungkan dua atau lebih fungsi untuk menghasilkan fungsi baru, di mana output fungsi pertama menjadi input fungsi berikutnya. **Analogi:** Seperti jalur perakitan pabrik — bahan mentah masuk ke mesin A, keluarannya masuk ke mesin B, hasil akhir keluar dari mesin C. **Poin-Poin Penting:** - Komposisi manual: `f(g(x))` — g dijalankan dulu, lalu f - Pipe: alur kiri-ke-kanan (`pipe(f, g)(x)` = `g(f(x))`) - Compose: alur kanan-ke-kiri (`compose(f, g)(x)` = `f(g(x))`) - Membuat kode lebih deklaratif dan modular**Contoh Kode:** ```javascript // Fungsi-fungsi kecil
const kaliDua = x => x * 2;
const tambahSatu = x => x + 1;
const kuadrat = x => x * x;

// Komposisi manual
const hasil1 = kuadrat(tambahSatu(kaliDua(3)));
console.log(hasil1);

// Pipe: kiri ke kanan
const pipe = (...fns) => x => fns.reduce((acc, fn) => fn(acc), x);
const proses = pipe(kaliDua, tambahSatu, kuadrat);
console.log(proses(3));

// Compose: kanan ke kiri
const compose = (...fns) => x => fns.reduceRight((acc, fn) => fn(acc), x);
const proses2 = compose(kuadrat, tambahSatu, kaliDua);
console.log(proses2(3));

// Contoh nyata: format teks
const trim = s => s.trim();
const lower = s => s.toLowerCase();
const ambilKataPertama = s => s.split(' ')[0];
const formatNama = pipe(trim, lower, ambilKataPertama);
console.log(formatNama('  JOHN DOE  ')); ``` **Hasil:** `49` `49` `49` `john` **Kasus Penggunaan Nyata:** Middleware pipeline di Express/Koa, transformasi data (fetch -> parse -> filter -> sort), dan komponen data processing di aplikasi.
