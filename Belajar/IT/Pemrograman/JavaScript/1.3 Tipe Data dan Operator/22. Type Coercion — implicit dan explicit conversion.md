### Definisi Singkat

_Type coercion_ adalah proses pengubahan tipe data dari satu jenis ke jenis lainnya, baik secara otomatis oleh sistem (_implicit_) maupun secara sengaja oleh _developer_ (_explicit_).

---

### Analogi

Bayangkan perbedaan ini seperti **proses pembayaran belanjaan di kasir toko internasional**:

- **Implicit (Otomatis):** Saat Anda menyerahkan uang tunai dalam Rupiah untuk membayar barang berlabel Euro, kasir secara otomatis mengonversi nilainya ke mata uang yang sesuai tanpa Anda perlu menghitungnya.
    
- **Explicit (Sengaja):** Sebelum pergi ke kasir, Anda pergi ke _money changer_ secara sadar dan sengaja menukar uang Rupiah Anda menjadi mata uang Euro.
    

---

### Poin-Poin Penting

- **Implicit Coercion (Tipe Data Otomatis):**
    
    - Terjadi ketika JavaScript secara otomatis mengonversi tipe data saat melakukan operasi tertentu (misalnya, menjumlahkan angka dan teks).
        
    - Sering menyebabkan hasil yang tidak terduga jika Anda tidak berhati-hati.
        
- **Explicit Coercion (Tipe Data Manual):**
    
    - Terjadi saat _developer_ secara sadar mengubah tipe data menggunakan fungsi atau objek pembungkus (seperti `Number()`, `String()`, atau Boolean `!!`).
        
    - Lebih aman dan mudah dipelihara karena memberikan hasil yang pasti.
        
- **Konversi Umum:**
    
    - **String Conversion:** Mengubah angka menjadi string menggunakan operator plus `+` dengan string kosong.
        
    - **Number Conversion:** Mengubah string menjadi angka menggunakan tanda tambah unary `+` di depan variabel string.
        

---

### Contoh Implementasi

Berikut adalah perbandingan antara implicit dan explicit coercion di dalam JavaScript:

JavaScript

```
// 1. Implicit Coercion (Otomatis)
let angka = 5;
let teks = "10";

// JavaScript mengubah angka 5 menjadi string "5", lalu menggabungkannya
let hasilOtomatis = angka + teks; 
console.log(hasilOtomatis); // Output: "510" (String)

// Pengurangan secara implisit mengubah string menjadi angka
let penguranganOtomatis = "15" - 5;
console.log(penguranganOtomatis); // Output: 10 (Number)


// 2. Explicit Coercion (Disengaja)
let nilaiAwal = "20";

// Mengubah string menjadi number secara eksplisit menggunakan Number()
let nilaiAngka = Number(nilaiAwal);
console.log(typeof nilaiAngka); // Output: number

// Mengubah number menjadi string menggunakan String()
let nilaiTeks = String(50);
console.log(typeof nilaiTeks); // Output: string

// Mengubah menjadi boolean menggunakan Boolean() atau !! (Double NOT)
let statusLogin = Boolean(1); // Output: true
```

---

### Koneksi

Dalam bidang **Web Development**, pemahaman _type coercion_ sangat penting untuk menghindari _bug_ yang tidak terduga, terutama saat:

- **Memproses Input Formulir:** Nilai yang dimasukkan pengguna pada elemen input HTML selalu berupa _string_. Anda harus melakukan _explicit coercion_ (mengubahnya menjadi _number_) sebelum melakukan operasi matematika seperti kalkulasi total harga.
    
- **Mengevaluasi Kondisi Logika:** Memahami bagaimana JavaScript mengubah nilai ke tipe _Boolean_ membantu dalam membuat kondisi untuk menyembunyikan atau menampilkan elemen antarmuka (_UI state_).
