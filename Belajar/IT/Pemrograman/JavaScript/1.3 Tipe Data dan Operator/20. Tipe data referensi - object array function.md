# 20. Tipe data referensi – object array function

**Definisi Singkat:** Tipe data referensi (object, array, function) menyimpan alamat memori (reference), bukan nilai langsung — assignment dan perbandingan bekerja pada reference, bukan nilai aktual.

**Analogi:** Primitif seperti fotokopi kertas — setiap copy berdiri sendiri. Referensi seperti alamat rumah — banyak orang bisa punya alamat yang sama (referensi), dan jika rumah direnovasi, semua pemegang alamat akan melihat perubahannya.

**Poin-Poin Penting:**
- **Object**: koleksi key-value pair — `{ nama: "Budi", umur: 25 }`, bisa nested
- **Array**: koleksi terindeks dengan method built-in — `[1, 2, 3]`, sebenarnya juga object
- **Function**: first-class citizen — bisa disimpan di variabel, jadi parameter, dikembalikan dari function lain
- Assignment referensi: `const b = a` → b dan a menunjuk object yang SAMA — mutasi satu mempengaruhi yang lain
- Perbandingan referensi: `{} === {}` → false (walaupun isi identik, alamat memori berbeda)

**Contoh Kode:**
```javascript
// === TIPE DATA REFERENSI ===
console.log("=== Tipe Data Referensi ===\n");

// 1. OBJECT
const user = {
  nama: "Budi",
  umur: 25,
  alamat: { kota: "Jakarta", provinsi: "DKI" }
};
console.log("Object:", user.nama, "dari", user.alamat.kota);
console.log("typeof object:", typeof user);

// 2. ARRAY
const buah = ["Apel", "Mangga", "Jeruk"];
console.log("\nArray:", buah);
console.log("Panjang:", buah.length);
console.log("Elemen ke-2:", buah[1]);

// 3. FUNCTION
const sapa = (nama) => `Halo ${nama}!`;
function tambah(a, b) { return a + b; }
console.log("\nFunction:", sapa("Ani"));
console.log("Hasil:", tambah(5, 3));

// 4. REFERENCE BEHAVIOR — assignment
const original = { nilai: 100 };
const copy = original; // copy mendapatkan reference yang SAMA
copy.nilai = 200;
console.log("\nReference behavior:");
console.log("original.nilai:", original.nilai); // 200 — berubah!
console.log("copy.nilai:", copy.nilai);         // 200

// 5. COMPARISON — berdasarkan reference
const obj1 = { x: 1 };
const obj2 = { x: 1 };
console.log("{} === {}:", obj1 === obj2); // false (beda reference)

// 6. Function sebagai referensi
const fn1 = () => 1;
const fn2 = fn1; // reference sama
console.log("fn1 === fn2:", fn1 === fn2); // true

// 7. Copy benar — spread operator
const benarCopy = { ...original };
benarCopy.nilai = 300;
console.log("\nSpread copy:");
console.log("original.nilai:", original.nilai); // 200 (tidak berubah)
console.log("copy baru:", benarCopy.nilai);     // 300
```
Hasil:
```
=== Tipe Data Referensi ===

Object: Budi dari Jakarta
typeof object: object

Array: [ 'Apel', 'Mangga', 'Jeruk' ]
Panjang: 3
Elemen ke-2: Mangga

Function: Halo Ani!
Hasil: 8

Reference behavior:
original.nilai: 200
copy.nilai: 200
{} === {}: false
fn1 === fn2: true

Spread copy:
original.nilai: 200
copy baru: 300
```

**Kasus Penggunaan Nyata:** Manajemen state di React menggunakan immutability — selalu buat copy baru dengan `...spread` atau `structuredClone` agar komponen bisa deteksi perubahan; ini mencegah bug mutasi tidak sengaja yang sering terjadi di aplikasi besar.
