# 19. Tipe data primitif baru – symbol dan bigint

**Definisi Singkat:** Symbol (ES6) adalah tipe data untuk identifier unik dan immutable; BigInt (ES2020) adalah tipe untuk bilangan bulat dengan presisi tak terbatas (melebihi batas Number.MAX_SAFE_INTEGER).

**Analogi:** Symbol seperti sidik jari — setiap symbol yang dibuat selalu unik, tidak ada yang sama meskipun deskripsinya identik. BigInt seperti kalkulator ilmiah yang bisa menampung angka raksasa tanpa error pembulatan.

**Poin-Poin Penting:**
- **Symbol**: `Symbol("deskripsi")` — setiap pemanggilan menghasilkan nilai unik, dipakai untuk properti objek yang tidak bentrok, dan konstanta enum
- **Symbol.for("key")** — membuat symbol global yang bisa diakses dari mana saja (beda dengan Symbol biasa)
- Well-known symbols: `Symbol.iterator`, `Symbol.toStringTag`, `Symbol.hasInstance` untuk kustomisasi behavior
- **BigInt**: ditulis dengan akhiran `n` — `123n`, `BigInt("9007199254740991")`, bisa untuk aritmatika campuran (tapi tidak dengan Number biasa)
- BigInt tidak bisa dipakai dengan Math methods, dan tidak bisa dicampur dengan Number dalam operasi

**Contoh Kode:**
```javascript
// === SYMBOL DAN BIGINT ===
console.log("=== Symbol & BigInt ===\n");

// 1. SYMBOL — identifier unik
const sym1 = Symbol("id");
const sym2 = Symbol("id");
console.log("Symbol('id') === Symbol('id'):", sym1 === sym2); // false

// Symbol untuk properti objek — tidak bentrok
const user = {
  nama: "Budi",
  [sym1]: 12345,  // properti symbol
};
console.log("user[sym1]:", user[sym1]);

// Symbol.for — global registration
const globalId = Symbol.for("app.id");
const globalId2 = Symbol.for("app.id");
console.log("Symbol.for sama:", globalId === globalId2); // true

// Well-known symbol — Symbol.iterator
const arr = [10, 20, 30];
const iterator = arr[Symbol.iterator]();
console.log("Iterator:", iterator.next().value, iterator.next().value);

// 2. BIGINT — angka besar presisi
const bigNumber = 9007199254740991n; // Number.MAX_SAFE_INTEGER
const lebihBesar = bigNumber + 10n;
console.log("\nBigInt:", bigNumber, "+ 10n =", lebihBesar);

// BigInt dari string
const dariString = BigInt("12345678901234567890");
console.log("BigInt dari string:", dariString);

// Operasi BigInt
const a = 100n;
const b = 3n;
console.log("100n + 3n =", a + b);
console.log("100n * 3n =", a * b);
console.log("100n / 3n =", a / b); // floor division (BigInt)

// BigInt tidak bisa campur Number
try {
  // console.log(a + 5); // TypeError
} catch (e) {
  console.log("Campur Number error:", e.message);
}

// Perbandingan BigInt dengan Number (bisa, strict-nya beda)
console.log("\nBigInt vs Number:");
console.log("100n == 100:", 100n == 100);   // true
console.log("100n === 100:", 100n === 100); // false
```
Hasil:
```
=== Symbol & BigInt ===

Symbol('id') === Symbol('id'): false
user[sym1]: 12345
Symbol.for sama: true
Iterator: 10 20

BigInt: 9007199254740991n + 10n = 9007199254741001n
BigInt dari string: 12345678901234567890n
100n + 3n = 103n
100n * 3n = 300n
100n / 3n = 33n

BigInt vs Number:
100n == 100: true
100n === 100: false
```

**Kasus Penggunaan Nyata:** Symbol dipakai di framework Redux/Zustand untuk action types unik yang tidak mungkin bentrok; BigInt dipakai di fintech (mikrotransaksi dengan presisi tinggi) dan aplikasi blockchain (nilai integer besar di smart contract).
