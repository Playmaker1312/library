# 18. Tipe data primitif – string number boolean null undefined

**Definisi Singkat:** JavaScript memiliki 5 tipe data primitif dasar: string (teks), number (angka), boolean (true/false), null (sengaja kosong), dan undefined (belum diisi).

**Analogi:** Lima tipe data dasar ini seperti bahan baku dapur — string adalah tepung (teks), number adalah beras (angka), boolean adalah saklar lampu (on/off), null adalah mangkuk kosong sengaja dikosongkan, undefined adalah piring yang belum diisi apa-apa.

**Poin-Poin Penting:**
- **string**: teks dalam kutip `""`, `''`, atau backtick `` — immutable, bisa pakai template literal `${}`
- **number**: integer dan desimal dalam satu tipe (IEEE 754 64-bit) — ada nilai spesial NaN, Infinity
- **boolean**: hanya `true` atau `false` — hasil dari operator perbandingan/logika
- **null**: nilai "kosong" yang sengaja diberikan programmer — typeof null mengembalikan "object" (bug legacy)
- **undefined**: nilai default variabel yang belum diinisialisasi — juga return value function tanpa return

**Contoh Kode:**
```javascript
// === 5 TIPE DATA PRIMITIF ===
console.log("=== Tipe Data Primitif ===\n");

// 1. STRING
const teks = "Halo Dunia";
const denganKutip = 'Petik tunggal';
const template = `Template: ${teks}`;
console.log("string:", teks, typeof teks);

// 2. NUMBER
const integer = 42;
const desimal = 3.14;
const negatif = -10;
const special = NaN; // Not a Number
console.log("number:", integer, desimal, negatif, typeof integer);
console.log("NaN:", isNaN(special));

// 3. BOOLEAN
const benar = true;
const salah = false;
console.log("boolean:", benar, salah, typeof benar);

// 4. NULL — sengaja dikosongkan oleh programmer
const kosong = null;
console.log("null:", kosong, typeof kosong); // typeof null = "object" (bug)

// 5. UNDEFINED — belum diisi
let belumDiisi;
const tidakAda = undefined;
console.log("undefined:", belumDiisi, typeof belumDiisi);

// Perbandingan null vs undefined
console.log("\nnull == undefined:", null == undefined);   // true (loose equality)
console.log("null === undefined:", null === undefined); // false (strict equality)

// Operasi dasar
const nama = "Budi";
const usia = 25;
const isDewasa = usia >= 18;
console.log(`\n${nama} berusia ${usia} tahun, dewasa: ${isDewasa}`);
```
Hasil:
```
=== Tipe Data Primitif ===

string: Halo Dunia string
number: 42 3.14 -10 number
NaN: true
boolean: true false boolean
null: null object
undefined: undefined undefined

null == undefined: true
null === undefined: false

Budi berusia 25 tahun, dewasa: true
```

**Kasus Penggunaan Nyata:** Validasi form sering mengecek `null` vs `undefined` — field yang belum diisi (undefined) beda dengan field yang sengaja dikosongkan (null) seperti reset password.
