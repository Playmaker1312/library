
### Definisi Singkat

Tipe data primitif adalah tipe data paling dasar dan sederhana di dalam JavaScript yang tidak memiliki properti atau metode (bersifat _immutable_ atau tidak dapat diubah nilainya). JavaScript memiliki 7 tipe data primitif, di mana 5 di antaranya adalah yang paling sering digunakan untuk mengelola informasi sehari-hari.

---

### Analogi

Bayangkan seperti **berbagai jenis label harga atau informasi pada sebuah barang di toko**:

- **String** seperti **label nama** yang bertuliskan teks ("Sepatu").
    
- **Number** seperti **angka harga** atau berat barang (50000).
    
- **Boolean** seperti **lampu indikator** yang hanya memiliki dua status: Ya atau Tidak (_true_ atau _false_).
    
- **Null** seperti **kotak kosong yang sengaja dikosongkan** (barang sudah terjual habis dan kotaknya sengaja dikosongkan).
    
- **Undefined** seperti **barang yang belum ada atau belum dibuka sama sekali** (belum ada informasi yang dimasukkan ke dalam kotak tersebut).
    

---

### Poin-Poin Penting

- **`String`:** Digunakan untuk mewakili data teks. Diapit dengan tanda kutip tunggal (`'`), ganda (`"`), atau _backticks_ (`` ` ``).
    
- **`Number`:** Digunakan untuk mewakili data angka (baik bilangan bulat maupun desimal/pecahan).
    
- **`Boolean`:** Tipe data logis yang hanya bernilai `true` atau `false`. Sangat sering digunakan untuk kondisi logika.
    
- **`Null`:** Merepresentasikan nilai kosong atau tidak ada nilai yang disengaja. Tipe data ini sering ditetapkan oleh _developer_.
    
- **`Undefined`:** Merepresentasikan variabel yang telah dideklarasikan tetapi belum diberi nilai sama sekali.
    

---

### Contoh Implementasi

Berikut adalah contoh penggunaan kelima tipe data primitif di dalam JavaScript:

JavaScript

```
// 1. String
let nama = "Budi";
let pesan = 'Halo dunia';

// 2. Number
let umur = 25;
let harga = 15.5;

// 3. Boolean
let sudahMenikah = false;
let isPro = true;

// 4. Null (Sengaja dikosongkan)
let dataKosong = null;

// 5. Undefined (Belum ada nilai)
let belumDiisi;

console.log(typeof nama);       // Output: string
console.log(typeof umur);       // Output: number
console.log(typeof isPro);      // Output: boolean
console.log(typeof dataKosong); // Output: object (ini adalah bug historis di JavaScript)
console.log(typeof belumDiisi); // Output: undefined
```

### Koneksi

Dalam bidang **Web Development**, pemahaman tentang tipe data primitif sangat penting untuk:

- **Validasi Form:** Memastikan bahwa input yang dimasukkan pengguna ke dalam formulir sesuai dengan format yang diinginkan (misalnya, nomor telepon harus bertipe _Number_, dan nama harus bertipe _String_).
    
- **Menampilkan Pesan:** Menampilkan data pengguna atau status (seperti tombol _login_ dengan status _Boolean_) di antarmuka pengguna (UI).
    
- **Manajemen State:** Menggunakan `null` atau `undefined` untuk melacak status dari sebuah API sebelum data berhasil dimuat.
