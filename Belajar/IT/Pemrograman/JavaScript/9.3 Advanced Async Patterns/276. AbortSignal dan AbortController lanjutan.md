### Definisi Singkat

**AbortController** dan **AbortSignal** adalah API Web (juga tersedia di Node.js sejak v15) untuk **membatalkan operasi async** secara eksternal. Anda membuat `AbortController`, mendapatkan `signal` darinya, dan mengoper `signal` ke fungsi yang mendukung pembatalan (seperti `fetch`). Panggil `.abort()` untuk membatalkan.

---

### Analogi

Seperti **tombol darurat** di pabrik — semua mesin (operasi async) terhubung ke satu tombol. Saat tombol ditekan (abort()), semua mesin menerima sinyal berhenti dan menghentikan pekerjaannya. Setiap mesin bisa mengecek apakah tombol sudah ditekan (signal.aborted).

---

### Poin-Poin Penting

- **`AbortController`**: Pengontrol — punya `signal` (AbortSignal) dan `abort()` method.
- **`AbortSignal`**: Objek sinyal — punya `aborted` (boolean) dan event `'abort'`.
- **`fetch()`** secara native mendukung `signal` — batalkan HTTP request.
- **Custom async functions** bisa mendukung signal dengan mengecek `signal.aborted` secara berkala atau mendengarkan event `'abort'`.
- **Timer cleanup**: Gabungkan dengan `setTimeout`/`setInterval` untuk cleanup otomatis.
- **Node.js**: Banyak API mendukung signal (`fs`, `child_process`, `stream`).
- **Waktu habis (timeout)**: Kombinasikan AbortController dengan `setTimeout` untuk implementasi timeout.

---

### Contoh Implementasi

```javascript
// 1. Membatalkan fetch request
const controller = new AbortController();
const signal = controller.signal;

fetch('https://api.example.com/data-large', { signal })
  .then((res) => res.json())
  .then((data) => console.log(data))
  .catch((err) => {
    if (err.name === 'AbortError') {
      console.log('Request dibatalkan');
    } else {
      console.error('Error lain:', err);
    }
  });

// Batalkan setelah 3 detik
setTimeout(() => controller.abort(), 3000);

// 2. Fungsi async kustom dengan dukungan abort
async function fetchWithTimeout(url, timeoutMs = 5000) {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), timeoutMs);

  try {
    const response = await fetch(url, { signal: controller.signal });
    return response.json();
  } finally {
    clearTimeout(timer);
  }
}

// 3. Multiple operasi dengan satu controller
const globalController = new AbortController();

async function loadAll() {
  const results = await Promise.all([
    fetch('/api/users', { signal: globalController.signal }),
    fetch('/api/posts', { signal: globalController.signal }),
  ]);
  return results;
}

// Batalkan semua jika user meninggalkan halaman
window.addEventListener('beforeunload', () => globalController.abort());
```

---

### Koneksi

Berkaitan dengan **Async Patterns** (Promise cancellation), **Fetch API** (dukungan native), **React hooks** (abort di useEffect cleanup), **RxJS** (Subscription mirip dengan AbortController), dan **Node.js Streams** (signal untuk destroy stream).
