### Definisi Singkat

**RxJS (Reactive Extensions for JavaScript)** adalah library untuk pemrograman **reaktif** menggunakan **Observable** — aliran data (stream) yang bisa diamati dari waktu ke waktu. Dengan operator-operatornya, Anda bisa mentransformasi, menyaring, menggabungkan, dan mengelola data async dengan cara deklaratif.

---

### Analogi

Seperti **keran air dengan sistem penyaring canggih** — air mengalir terus (Observable). Anda bisa memasang filter (operator) seperti menyaring kotoran (filter), mengubah aliran (map), menggabungkan dua selang (merge), atau menunda aliran (debounce). Anda tidak perlu mengecek keran setiap saat — cukup pasang filter dan kerjakan hal lain.

---

### Poin-Poin Penting

- **Observable**: Sumber data yang mengirimkan nilai dari waktu ke waktu — menggantikan Promise untuk multiple values.
- **Observer**: Konsumen yang bereaksi terhadap nilai (`next`, `error`, `complete`).
- **Subscription**: Koneksi antara Observable dan Observer. Wajib di-`unsubscribe` untuk mencegah leak.
- **Operators**: Fungsi murni (pure) yang memanipulasi stream — `map`, `filter`, `debounceTime`, `switchMap`, `mergeMap`, `catchError`.
- **Subject**: Multicast Observable — satu source, banyak subscriber.
- **Scheduler**: Mengontrol kapan dan bagaimana nilai dikirim (async, queue, animationFrame).
- **Pipeable operators**: `source$.pipe(map(x => x * 2), filter(x => x > 10))`.

### Contoh Implementasi

```javascript
import { Observable, fromEvent, of } from 'rxjs';
import { map, filter, debounceTime, switchMap, catchError } from 'rxjs/operators';
import { ajax } from 'rxjs/ajax';

// Membuat Observable sederhana
const observable = new Observable((subscriber) => {
  subscriber.next(1);
  subscriber.next(2);
  subscriber.next(3);
  setTimeout(() => {
    subscriber.next(4);
    subscriber.complete();
  }, 1000);
});

observable.subscribe({
  next: (x) => console.log(x),
  error: (err) => console.error(err),
  complete: () => console.log('Selesai'),
});

// Search input dengan debounce + switchMap (batalkan request lama)
const searchInput = document.getElementById('search');
const input$ = fromEvent(searchInput, 'input');

input$
  .pipe(
    map((e) => e.target.value),
    debounceTime(300),
    filter((term) => term.length >= 3),
    switchMap((term) =>
      ajax.getJSON(`/api/search?q=${term}`).pipe(
        catchError(() => of([]))
      )
    )
  )
  .subscribe((results) => {
    console.log('Hasil pencarian:', results);
  });
```

### Koneksi

Berkaitan dengan **Async Patterns** (Observable untuk async), **Angular** (RxJS terintegrasi di Angular HTTP, Forms, Router), **WebSocket** (Observable untuk real-time), **Streams** (konsep serupa dengan Node.js streams), dan **EventEmitter** (mirip Observable).
