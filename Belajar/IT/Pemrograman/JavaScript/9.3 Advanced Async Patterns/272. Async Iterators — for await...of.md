### Definisi Singkat

**Async Iterators** memungkinkan iterasi atas data yang datang secara **asynchronous** — seperti stream, halaman API pagination, atau event. Sintaks `for await...of` mengiterasi objek yang mengimplementasikan `Symbol.asyncIterator`, menghasilkan Promise yang di-resolve setiap iterasi.

---

### Analogi

Seperti **antrean taksi di bandara** — Anda tidak tahu kapan taksi berikutnya akan datang, tetapi Anda bisa duduk dan menunggu giliran (await) satu per satu. Bandingkan dengan antrean reguler (sync iterator) di mana semua orang sudah ada di barisan.

---

### Poin-Poin Penting

- Objek async iterable harus memiliki metode `[Symbol.asyncIterator]()` yang mengembalikan `{ next() → Promise }`.
- `for await (const item of asyncIterable) { ... }` — hanya bisa di dalam async function.
- Stream Node.js (Readable) secara default adalah async iterable.
- Async generator (fungsi `async *`) secara otomatis menghasilkan async iterator.
- Error handling: gunakan `try/catch` di sekitar `for await...of`.
- Tidak seperti sync `for...of`, async iterator bisa **lazy** — data diproses saat tiba.

---

### Contoh Implementasi

```javascript
// Async iterable manual
const asyncRange = {
  from: 1,
  to: 5,
  [Symbol.asyncIterator]() {
    let current = this.from;
    return {
      next: () => {
        if (current <= this.to) {
          return new Promise((resolve) => {
            setTimeout(() => resolve({ value: current++, done: false }), 500);
          });
        }
        return Promise.resolve({ done: true });
      }
    };
  }
};

async function consume() {
  for await (const num of asyncRange) {
    console.log(num); // 1, 2, 3, 4, 5 (masing-masing jeda 500ms)
  }
}

// Stream Node.js sebagai async iterable
const fs = require('fs');

async function readLines(filePath) {
  const stream = fs.createReadStream(filePath, { encoding: 'utf8' });
  let buffer = '';

  for await (const chunk of stream) {
    buffer += chunk;
    const lines = buffer.split('\n');
    buffer = lines.pop(); // Simpan sisa yang belum lengkap
    for (const line of lines) {
      console.log('Baris:', line);
    }
  }
  // Proses sisa buffer
  if (buffer) console.log('Baris:', buffer);
}
```

---

### Koneksi

Berkaitan dengan **Async Generators** (menghasilkan async iterable), **Streams** (Node.js Readable adalah async iterable), **Event Loop** (microtask/macrotask scheduling), dan **RxJS** (Observable alternatif untuk async data streams).
