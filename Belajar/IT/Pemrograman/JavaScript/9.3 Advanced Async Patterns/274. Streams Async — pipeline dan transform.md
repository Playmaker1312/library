### Definisi Singkat

**Stream pipeline** adalah pola untuk menghubungkan beberapa stream secara berurutan, di mana output satu stream menjadi input stream berikutnya. Di Node.js, `stream.pipeline()` (atau `.pipe()` tradisional) mengelola **backpressure** otomatis dan error propagation. **Transform stream** memproses data di tengah pipeline.

---

### Analogi

Seperti **pabrik botol minuman** — air mengalir dari tangki (Readable) melalui mesin filter (Transform 1), mesin pemanis (Transform 2), mesin pengisi botol (Transform 3), dan akhirnya ke gudang (Writable). Jika gudang penuh, seluruh jalur otomatis melambat (backpressure).

---

### Poin-Poin Penting

- **`pipeline(readable, ...transforms, writable, callback)`** — metode modern, error handling otomatis.
- **`.pipe()`** — metode lama, manual error handling.
- **Backpressure**: Jika writable lambat, readable otomatis melambat — dicegah dengan `highWaterMark`.
- **Transform** adalah Duplex stream (Readable + Writable) dengan fungsi `_transform` kustom.
- **`pipeline`** lebih direkomendasikan karena cleanup otomatis (destroy semua stream jika error).
- **`finished(stream, callback)`** — deteksi kapan stream selesai atau error.

---

### Contoh Implementasi

```javascript
const fs = require('fs');
const zlib = require('zlib');
const { pipeline, Transform, finished } = require('stream');

// 1. Pipeline sederhana — dekompresi file
pipeline(
  fs.createReadStream('data.txt.gz'),
  zlib.createGunzip(),
  fs.createWriteStream('data.txt'),
  (err) => {
    if (err) console.error('Pipeline gagal:', err);
    else console.log('Dekompresi selesai');
  }
);

// 2. Transform kustom — filter dan uppercase
const filterTransform = new Transform({
  objectMode: true,
  transform(chunk, encoding, callback) {
    const words = chunk.toString().split(' ');
    const filtered = words
      .filter((w) => w.length > 3)
      .join(' ')
      .toUpperCase();
    callback(null, filtered);
  }
});

pipeline(
  fs.createReadStream('input.txt', { encoding: 'utf8' }),
  filterTransform,
  fs.createWriteStream('output.txt'),
  (err) => console.log(err || 'Sukses')
);

// 3. Pipeline dengan Promise (util.promisify)
const { promisify } = require('util');
const pipelineAsync = promisify(pipeline);

async function processFile() {
  try {
    await pipelineAsync(
      fs.createReadStream('source.txt'),
      zlib.createGzip(),
      fs.createWriteStream('source.txt.gz')
    );
    console.log('Kompresi selesai');
  } catch (err) {
    console.error('Error:', err);
  }
}

// 4. finished — tunggu stream selesai
const readStream = fs.createReadStream('file.txt');
finished(readStream, (err) => {
  console.log(err || 'Stream selesai');
});
```

### Koneksi

Berkaitan dengan **Streams** (Readable, Writable, Transform), **Buffer** (data chunk), **File System** (sumber stream), **Async Iterators** (alternatif membaca stream), dan **Web Streams API** (konsep pipeline di browser).
