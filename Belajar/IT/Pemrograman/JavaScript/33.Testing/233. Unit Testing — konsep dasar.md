### Definisi Singkat

Unit Testing adalah praktik pengujian di mana **unit terkecil** dari kode (fungsi, method, atau modul) diuji secara terisolasi untuk memastikan perilakunya sesuai harapan. Tujuan utamanya adalah memvalidasi bahwa setiap unit kode bekerja dengan benar dalam isolasi, tanpa dependensi eksternal.

---

### Analogi

Seperti **memeriksa setiap komponen mesin mobil secara terpisah** sebelum merakitnya — Anda test busi, test pompa bahan bakar, test piston masing-masing. Anda tidak perlu menyalakan mobil dulu. Ini lebih mudah mendeteksi masalah daripada menunggu mobil mogok di jalan.

---

### Poin-Poin Penting

- Unit test menguji satu unit fungsi/komponen dalam **isolasi**
- Dependensi eksternal (database, API, file system) harus di-**mock** atau di-stub
- Karakteristik unit test yang baik: **F**ast, **I**solated, **R**epeatable, **S**elf-validating, **T**imely (FIRST)
- Struktur dasar: **Arrange** (setup), **Act** (eksekusi), **Assert** (verifikasi)
- Coverage: persentase kode yang diuji — bukan jaminan kualitas, tapi indikator
- Framework populer: Jest, Mocha, Jasmine, Vitest
- Unit test adalah fondasi **Test Pyramid**

### Contoh Implementasi

```javascript
// Fungsi yang akan diuji
function formatPrice(amount, currency = 'IDR') {
  if (typeof amount !== 'number' || amount < 0) {
    throw new Error('Harga harus angka positif');
  }
  return `${currency} ${amount.toLocaleString('id-ID')}`;
}

function calculateDiscount(price, discountPercent) {
  if (discountPercent < 0 || discountPercent > 100) {
    throw new Error('Diskon harus 0-100%');
  }
  return price - (price * discountPercent) / 100;
}

// Unit Test (manual assertion)
function testFormatPrice() {
  // Arrange
  const expected = 'IDR 10,000';

  // Act
  const result = formatPrice(10000);

  // Assert
  console.assert(result === expected, `Expected ${expected}, got ${result}`);
  console.log('✓ formatPrice bekerja dengan benar');
}

function testCalculateDiscount() {
  console.assert(calculateDiscount(100000, 20) === 80000, 'Diskon 20% dari 100000 harus 80000');
  console.assert(calculateDiscount(50000, 0) === 50000, 'Diskon 0%');
  console.assert(calculateDiscount(50000, 100) === 0, 'Diskon 100%');
  console.log('✓ calculateDiscount bekerja dengan benar');
}
```
