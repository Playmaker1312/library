### Definisi Singkat

Matchers adalah method yang disediakan oleh Jest (dan framework testing lain) melalui objek `expect` untuk melakukan **assertions** — membandingkan nilai aktual dengan nilai yang diharapkan. Setiap matcher mengembalikan `true` atau `false` dan memberikan pesan error yang jelas saat gagal.

---

### Analogi

Seperti **alat ukur yang berbeda untuk benda yang berbeda** — Anda pakai penggaris untuk panjang, timbangan untuk berat, termometer untuk suhu. Jest matchers seperti itu: `toBe` untuk primitif, `toEqual` untuk objek, `toThrow` untuk error — masing-masing punya kegunaan spesifik.

---

### Poin-Poin Penting

- **Primitive comparison**: `toBe(value)` — menggunakan `Object.is` (=== yang lebih ketat)
- **Object comparison**: `toEqual(value)` — recursive comparison (deep equality)
- **Strict object comparison**: `toStrictEqual(value)` — lebih ketat (cek tipe, undefined properti)
- **Truthiness**: `toBeNull()`, `toBeUndefined()`, `toBeDefined()`, `toBeTruthy()`, `toBeFalsy()`
- **Numbers**: `toBeGreaterThan()`, `toBeGreaterThanOrEqual()`, `toBeLessThan()`, `toBeCloseTo()` (float)
- **Strings**: `toMatch(/regex/)`, `toMatch('substring')`
- **Arrays/Ierables**: `toContain(item)`, `toHaveLength(number)`
- **Error**: `toThrow()`, `toThrowError(message)`
- **Negation**: `.not.matcher()` — kebalikan assertion

---

### Contoh Implementasi

```javascript
// Primitive
test('toBe untuk primitif', () => {
  expect(2 + 2).toBe(4);
  expect('hello').toBe('hello');
});

// Object equality
test('toEqual untuk objek', () => {
  const data = { one: 1, two: 2 };
  expect(data).toEqual({ one: 1, two: 2 });
});

// Truthiness
test('null dan undefined', () => {
  const n = null;
  expect(n).toBeNull();
  expect(n).toBeDefined();
  expect(n).not.toBeUndefined();
  expect(n).not.toBeTruthy();
  expect(n).toBeFalsy();
});

// Numbers
test('angka', () => {
  expect(10).toBeGreaterThan(5);
  expect(0.1 + 0.2).toBeCloseTo(0.3); // bukan toEqual
});

// Strings
test('string dengan regex', () => {
  expect('Budi').toMatch(/udi/);
  expect('Hello World').toMatch('World');
});

// Arrays
test('array', () => {
  const arr = ['apel', 'mangga', 'pisang'];
  expect(arr).toContain('mangga');
  expect(arr).toHaveLength(3);
});

// Error
function throwError() {
  throw new Error('Terjadi error!');
}
test('error handling', () => {
  expect(() => throwError()).toThrow();
  expect(() => throwError()).toThrow('Terjadi error!');
});
```
