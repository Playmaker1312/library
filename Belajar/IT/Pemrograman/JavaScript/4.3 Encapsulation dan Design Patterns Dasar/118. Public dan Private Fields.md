### Definisi Singkat
Public fields adalah properti instance yang dideklarasikan langsung di body class. Private fields menggunakan prefix `#` untuk membuat properti yang hanya bisa diakses dari dalam class.

---
### Analogi
Public fields seperti etalase toko — semua orang bisa melihat. Private fields seperti brankas di belakang toko — hanya pemilik yang punya akses.

---
### Poin-Poin Penting
- Public field: `field = value` — dideklarasikan di body class tanpa `let/const`
- Private field: `#field = value` — diakses dengan `this.#field`
- Private field benar-benar private (enforced by engine)
- Private field tidak bisa diakses dari luar class
- Private field tidak bisa diwarisi ke child class

---
### Contoh Implementasi
```javascript
class BankAccount {
  // Public field
  bankName = 'Bank Kita';
  transactionCount = 0;

  // Private fields — wajib dideklarasikan
  #balance;
  #pin;

  constructor(owner, initialBalance, pin) {
    this.owner = owner; // public
    this.#balance = initialBalance;
    this.#pin = pin;
  }

  // Public method — akses private field
  deposit(amount) {
    if (amount > 0) {
      this.#balance += amount;
      this.transactionCount++;
      return this.#balance;
    }
    throw new Error('Jumlah tidak valid');
  }

  withdraw(amount) {
    if (amount <= this.#balance) {
      this.#balance -= amount;
      this.transactionCount++;
      return this.#balance;
    }
    throw new Error('Saldo tidak cukup');
  }

  getBalance() {
    return this.#balance;
  }

  // Private method (ES2022)
  #validatePin(inputPin) {
    return this.#pin === inputPin;
  }

  authenticate(pin) {
    return this.#validatePin(pin);
  }
}

const account = new BankAccount('Andi', 1000000, 1234);
console.log(account.bankName);       // "Bank Kita" — public OK
console.log(account.owner);          // "Andi" — public OK
// console.log(account.#balance);    // SyntaxError!
// console.log(account.#pin);        // SyntaxError!
console.log(account.getBalance());   // 1000000 — via method
console.log(account.authenticate(1234)); // true
```
