### Definisi Singkat
Module pattern adalah teknik encapsulation menggunakan IIFE (Immediately Invoked Function Expression) atau ES6 modules untuk menyembunyikan state dan fungsi internal, hanya mengekspos API publik yang dipilih.

---
### Analogi
Seperti restoran: dapur (private) tempat semua proses memasak terjadi tidak terlihat oleh tamu. Tamu hanya berinteraksi dengan menu dan pelayan (public API).

---
### Poin-Poin Penting
- Menggunakan IIFE untuk menciptakan private scope
- Mengembalikan object berisi method publik (revealing module pattern)
- ES6 Modules (`export`/`import`) memberikan encapsulation natural
- Mencegah polusi global namespace
- Setiap variabel di dalam module benar-benar terisolasi

---
### Contoh Implementasi
```javascript
// MODULE PATTERN dengan IIFE
const CartModule = (function () {
  // Private state
  let items = [];
  let discount = 0;

  // Private function
  function calculateTotal() {
    const subtotal = items.reduce((sum, item) => sum + item.price * item.qty, 0);
    return subtotal - discount;
  }

  function log(action) {
    console.log(`[Cart] ${action}`);
  }

  // Public API
  return {
    addItem(name, price, qty = 1) {
      items.push({ name, price, qty });
      log(`Added ${name} x${qty}`);
    },

    removeItem(name) {
      items = items.filter((item) => item.name !== name);
      log(`Removed ${name}`);
    },

    setDiscount(amount) {
      discount = amount;
      log(`Discount: ${amount}`);
    },

    getTotal() {
      return calculateTotal();
    },

    getItems() {
      return [...items]; // return copy, bukan reference
    },
  };
})();

// Menggunakan public API
CartModule.addItem('Buku', 50000, 2);
CartModule.addItem('Pensil', 10000, 3);
CartModule.setDiscount(15000);
console.log(CartModule.getTotal()); // (100000 + 30000) - 15000 = 115000
// CartModule.items // undefined — private!
// CartModule.calculateTotal() // error — private!

// ES6 MODULE (file terpisah — ilustrasi)
```
