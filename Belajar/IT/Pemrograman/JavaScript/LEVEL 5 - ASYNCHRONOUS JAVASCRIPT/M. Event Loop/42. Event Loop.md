# 42. Event Loop

## Penjelasan
Event Loop adalah mekanisme yang memungkinkan JavaScript — yang single-threaded (hanya punya satu jalur kerja) — menjalankan kode secara asynchronous tanpa memblokir jalur utama. JavaScript memiliki tiga komponen utama: **Call Stack** (tumpukan tugas), **Web APIs** (tugas latar), dan **Callback Queue** (antrian hasil tugas). Event Loop terus-menerus memeriksa: "Apakah Call Stack kosong? Kalau iya, ambil tugas dari Callback Queue dan jalankan."

## Fungsi
Event Loop memastikan tugas berat (seperti mengambil data dari server, baca file, timer) tidak memblokir kode lain. Tanpa Event Loop, browser akan "freeze" setiap kali menunggu data dari server. Dengan Event Loop, JavaScript bisa tetap merespon klik, animasi, dan interaksi lain sambil menunggu tugas latar selesai.

## Cara Pengimplementasian
```js
console.log("1. Pintu rumah terbuka");

setTimeout(() => {
  console.log("3. Tukang bangunan datang setelah 2 detik");
}, 2000);

console.log("2. Menyiram tanaman sambil menunggu");

// Output:
// 1. Pintu rumah terbuka
// 2. Menyiram tanaman sambil menunggu
// 3. Tukang bangunan datang setelah 2 detik
```

```js
// Demonstrasi event loop dengan Promise (microtask)
console.log("A. Bangun tidur");

setTimeout(() => console.log("D. Timer 0ms (macrotask)"), 0);

Promise.resolve().then(() => console.log("C. Microtask: sarapan"));

console.log("B. Gosok gigi");

// Output:
// A, B, C, D
// Microtask (Promise) lebih prioritas daripada macrotask (setTimeout)
```

## Analogi
**Event Loop adalah satpam rumah** yang mengatur antrian tugas. Satpam ini hanya bisa melakukan satu hal dalam satu waktu (single-threaded). Jika ada tugas ringan (ganti lampu), dia kerjakan langsung. Jika ada tugas berat (perbaiki atap yang bocor), dia panggil tukang (Web API) dan mencatatnya di buku antrian (Callback Queue). Satpam terus memantau: "Kalau saya sedang tidak sibuk, ambil catatan berikutnya dari antrian." Satpam juga punya prioritas: tamu penting (microtask — Promise) dilayani dulu sebelum tukang (macrotask — setTimeout).

## Dipakai Untuk Apa
Event Loop adalah fondasi semua operasi asynchronous di JavaScript: `setTimeout`/`setInterval`, fetching data dari API, event listener (klik, scroll), animasi `requestAnimationFrame`, dan operasi I/O di Node.js. Memahami Event Loop membantu debugging masalah timing dan urutan eksekusi kode.

## Kesalahan Umum
Mengira `setTimeout(fn, 0)` langsung jalan setelah 0ms — padahal tugasnya tetap masuk antrian dan baru jalan setelah Call Stack kosong. Juga mengira semua asynchronous berjalan "di background" secara paralel — padahal JavaScript tetap single-threaded, hanya tugas latar yang ditangani oleh Web APIs. Satu lagi: lupa bahwa Promise (microtask) lebih prioritas dari setTimeout (macrotask).

## Keterkaitan dengan Materi Sebelumnya
Di Level 4 (class, OOP), kamu belajar membuat blueprint objek dengan class. Event Loop adalah "mesin runtime" yang menjalankan objek-objek tersebut. Saat instance class memanggil method asynchronous (misal `user.simpanKeDatabase()`), Event Loop-lah yang mengatur agar Method tersebut tidak memblokir method lain. OOP memberi struktur, Event Loop memberi cara mengeksekusinya secara efisien.

## Soal Latihan
Apa output dari kode berikut?
```js
console.log("Start");
setTimeout(() => console.log("Middle"), 0);
Promise.resolve().then(() => console.log("Promise"));
console.log("End");
```
