# 43. Callback & Callback Hell

## Penjelasan
Callback adalah fungsi yang dikirimkan sebagai argumen ke fungsi lain, untuk dipanggil kembali di kemudian hari — biasanya setelah tugas asynchronous selesai. Callback adalah pola asynchronous tertua di JavaScript. **Callback Hell** (atau Pyramid of Doom) adalah kondisi ketika banyak callback bersarang (nested) sehingga kode menjadi seperti piramid menjorok ke kanan, sulit dibaca dan dipelihara.

## Fungsi
Callback memungkinkan kita menentukan "apa yang harus terjadi setelah tugas selesai" tanpa memblokir eksekusi. Ini adalah mekanisme dasar untuk menangani event (klik, timer), operasi file (Node.js), dan komunikasi server sebelum Promise hadir. Callback juga digunakan di banyak API modern seperti `setTimeout`, `addEventListener`, dan metode array (`map`, `filter`, `forEach`).

## Cara Pengimplementasian
```js
// Callback sederhana — titip pesan ke satpam
function pesanMaterial( material, callback ) {
  console.log(`Memesan ${material}...`);
  setTimeout(() => {
    console.log(`${material} sudah sampai`);

    if (typeof callback === "function") callback(material);
  }, 2000);
}

function pasangMaterial(material) {
  console.log(`Memasang ${material} di rumah`);
}

pesanMaterial("Semen", pasangMaterial);
```

```js
// CALLBACK HELL — ketika callback bersarang
function bangunRumah() {
  setTimeout(() => {
    console.log("1. Pondasi selesai");

    setTimeout(() => {
      console.log("2. Tembok selesai");

      setTimeout(() => {
        console.log("3. Atap selesai");

        setTimeout(() => {
          console.log("4. Cat selesai");

          setTimeout(() => {
            console.log("5. Furniture masuk — rumah jadi!");
          }, 1000);
        }, 1000);
      }, 1000);
    }, 1000);
  }, 1000);
}

bangunRumah();
// Melihat pola piramid? Ini Callback Hell.
```

## Analogi
**Callback = titip pesan ke satpam rumah**. Kamu sibuk merapikan taman, lalu satpam lewat. Kamu bilang: "Pak Satpam, kalau nanti tukang semen datang, tolong panggil saya." Satpam menyimpan pesan itu (callback) dan menjalankannya nanti saat kondisi terpenuhi. **Callback Hell** seperti kamu nitip pesan ke satpam, lalu satpam nitip pesan ke satpam lain, lalu satpam lain nitip ke satpam berikutnya lagi — sehingga untuk menyampaikan satu informasi, harus melewati rantai satpam yang panjang dan berantakan.

## Dipakai Untuk Apa
Callback digunakan di: event DOM (`button.addEventListener("click", handler)`), timer (`setTimeout(fn, 1000)`), operasi array (`arr.map(fn)`, `arr.filter(fn)`), dan di beberapa library lama (jQuery, Express.js middleware). Saat ini, pola Promise dan async/await lebih disukai untuk menghindari Callback Hell.

## Kesalahan Umum
Callback Hell — callback bersarang terlalu dalam. Lupa passing callback (error: "undefined is not a function"). Inversion of Control — menyerahkan kendali eksekusi ke fungsi lain yang belum tentu bisa dipercaya. Juga: tidak handle error di dalam callback, sehingga error silent dan sulit dilacak. Biasakan selalu ada parameter `err` pertama di callback (error-first callback pattern).

## Keterkaitan dengan Materi Sebelumnya
Di Level 4 (class, OOP), kamu belajar bahwa method adalah fungsi yang menjadi properti objek. Callback adalah fungsi yang menjadi argumen fungsi lain — "fungsi sebagai citizen pertama." Keduanya menunjukkan fleksibilitas fungsi di JavaScript. Method di class bisa menerima callback: `button.addEventListener("click", this.handleKlik.bind(this))`. Paham OOP + callback = bisa membuat event-driven arsitektur di aplikasi.

## Soal Latihan
Perbaiki kode Callback Hell berikut menjadi lebih rapi dengan memisahkan callback ke fungsi terpisah (tanpa Promise/async):
```js
setTimeout(() => {
  console.log("Buka pintu");
  setTimeout(() => {
    console.log("Nyalakan lampu");
    setTimeout(() => {
      console.log("Masak air");
    }, 1000);
  }, 1000);
}, 1000);
```

function bukaPintu(cb) {
