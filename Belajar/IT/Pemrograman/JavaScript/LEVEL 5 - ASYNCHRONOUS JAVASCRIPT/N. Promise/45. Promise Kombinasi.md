# 45. Promise Kombinasi

## Penjelasan
Promise memiliki metode statis untuk menggabungkan beberapa Promise secara paralel: `Promise.all()`, `Promise.allSettled()`, `Promise.race()`, dan `Promise.any()`. Ini memungkinkan kita menjalankan beberapa tugas asynchronous sekaligus (tidak berurutan) dan menggabungkan hasilnya. Pemilihan metode tergantung kebutuhan: apakah semua harus sukses, cukup satu yang sukses, atau ingin lihat hasil masing-masing terlepas dari gagal/sukses.

## Fungsi
Promise kombinasi mengoptimalkan waktu eksekusi. Jika kamu perlu mengambil data dari 3 API berbeda, daripada menunggu satu per satu (total waktu = jumlah waktu masing-masing), kamu bisa jalankan paralel (total waktu = waktu terlama). Ini krusial untuk performa aplikasi. Masing-masing metode punya use case berbeda: `all()` untuk kasus "semua atau tidak sama sekali", `race()` untuk timeout, `any()` untuk redundansi server.

## Cara Pengimplementasian
```js
function renovasiKamar(namaKamar, durasi) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (namaKamar === "Kamar Mandi") {
        reject(`Renovasi ${namaKamar} gagal (kebocoran)`);
      } else {
        resolve(`${namaKamar} selesai direnovasi`);
      }
    }, durasi);
  });
}
```

```js
// Promise.all — tunggu SEMUA selesai (gagal jika satu gagal)
const allRenovasi = Promise.all([
  renovasiKamar("Kamar Tidur", 2000),
  renovasiKamar("Ruang Tamu", 1000),
  renovasiKamar("Dapur", 3000)
]);

allRenovasi
  .then((hasil) => console.log("Semua selesai:", hasil))
  .catch((err) => console.log("Ada yang gagal:", err));
```

```js
// Promise.allSettled — tunggu semua, lihat hasil masing-masing
Promise.allSettled([
  renovasiKamar("Kamar Tidur", 2000),
  renovasiKamar("Kamar Mandi", 1500),
  renovasiKamar("Dapur", 1000)
]).then((hasil) => {
  hasil.forEach((item) => {
    if (item.status === "fulfilled") {
      console.log("✅", item.value);
    } else {
      console.log("❌", item.reason);
    }
  });
});
```

```js
// Promise.race — ambil yang paling cepat selesai (apapun hasilnya)
Promise.race([
  renovasiKamar("Kamar Tidur", 3000),
  renovasiKamar("Kamar Mandi", 1000) // lebih cepat, walau reject
]).then(console.log).catch(console.error);
```

```js
// Promise.any — ambil yang PERTAMA KALI sukses (abaikan yang gagal)
Promise.any([
  renovasiKamar("Kamar Mandi", 1000), // gagal — diabaikan
  renovasiKamar("Ruang Tamu", 2000),  // sukses — ini yang dipakai
  renovasiKamar("Dapur", 3000)
]).then(console.log).catch(console.error);
```

## Analogi
**Promise kombinasi = strategi pemilik rumah merenovasi beberapa ruangan**. Kamu punya 4 tukang (4 Promise):
- **Promise.all**: "Semua kamar harus selesai sebelum saya pindah kembali. Kalau satu saja gagal, batal semua." = all-or-nothing.
- **Promise.allSettled**: "Saya ingin laporan akhir: mana kamar yang beres dan mana yang bocor." = lihat semua hasil.
- **Promise.race**: "Siapa pun yang selesai pertama — entah berhasil atau kabur — saya akan ambil keputusan dari dia." = ambil yang tercepat.
- **Promise.any**: "Saya ingin tukang yang pertama berhasil menyelesaikan kamarnya. Abaikan yang gagal." = ambil sukses pertama.

## Dipakai Untuk Apa
`Promise.all()` dipakai ketika perlu data dari beberapa sumber dan semua wajib berhasil (misal ambil data user + daftar produk + keranjang untuk render halaman). `Promise.allSettled()` untuk logging atau batch job yang perlu laporan lengkap. `Promise.race()` untuk implementasi timeout (`Promise.race([fetch(url), timeout(5000)])`). `Promise.any()` untuk fallback server — coba beberapa server, pakai yang pertama respons.

## Kesalahan Umum
Menggunakan `Promise.all()` padahal salah satu Promise bisa gagal tanpa menggagalkan yang lain — pakai `allSettled()`. Lupa bahwa `Promise.race()` tetap "menang" meskipun Promise yang pertama selesai adalah rejected. Mengira `Promise.any()` throw error otomatis jika semua gagal — sebenarnya throw `AggregateError` yang perlu di-catch. Juga: menjalankan Promise serial (satu per satu) padahal perlu paralel — buang waktu.

## Keterkaitan dengan Materi Sebelumnya
Di Level 4 (class, OOP), kamu belajar inheritance dan composition — menggabungkan objek untuk membuat fungsi kompleks. Promise kombinasi adalah "composition" untuk asynchronous: kamu menggabungkan beberapa Promise untuk mendapatkan hasil gabungan. Seperti class `Rumah` yang punya komposisi `Kamar`, Promise.all menggabungkan renovasi setiap kamar menjadi satu proyek renovasi rumah utuh.

## Soal Latihan
Kamu punya 3 fungsi yang masing-masing mengembalikan Promise:
- `ambilSemen()` — selesai 1 detik
- `ambilPasir()` — selesai 2 detik
- `ambilBata()` — selesai 3 detik

Gunakan Promise.all untuk menjalankan ketiganya paralel, lalu cetak "Semua material siap" setelah semua selesai. Tambahkan error handling.

<summary>Jawaban</summary>
```js
function ambilSemen() {
  return new Promise((resolve) => setTimeout(() => resolve("Semen"), 1000));
}
function ambilPasir() {
  return new Promise((resolve) => setTimeout(() => resolve("Pasir"), 2000));
}
function ambilBata() {
  return new Promise((resolve) => setTimeout(() => resolve("Bata"), 1500));
}

Promise.all([ambilSemen(), ambilPasir(), ambilBata()])
  .then((material) => {
    console.log("Semua material siap:", material.join(", "));
    // Output: Semua material siap: Semen, Pasir, Bata (≈2 detik)
  })
  .catch((err) => console.log("Gagal mengambil material:", err));
```
