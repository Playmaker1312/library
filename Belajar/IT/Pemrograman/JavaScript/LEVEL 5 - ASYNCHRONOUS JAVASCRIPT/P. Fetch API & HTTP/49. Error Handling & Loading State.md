# 49. Error Handling & Loading State

## Penjelasan
Error handling dan loading state adalah dua aspek krusial dari asynchronous operation yang sering diabaikan pemula. **Error handling** memastikan aplikasi tetap berfungsi dengan baik meskipun terjadi kesalahan (network error, server error, data tidak valid). **Loading state** memberi umpan balik visual ke pengguna bahwa aplikasi sedang memproses sesuatu — mencegah klik ganda, menunjukkan progress, dan mengurangi frustrasi. Keduanya wajib dalam aplikasi production-ready.

## Fungsi
Error handling mencegah aplikasi crash diam-diam (silent failure), memberi informasi yang berguna ke pengguna ("Gagal mengambil data, coba lagi"), dan memungkinkan retry logic. Loading state memberi sinyal visual (spinner, skeleton, dimmed button) sehingga pengguna tahu bahwa app sedang bekerja — bukan freeze. Tanpa keduanya, pengguna akan melihat layar kosong bingung atau tombol yang tidak responsif.

## Cara Pengimplementasian
```js
// ========== LOADING STATE ==========
let isLoading = false;
let errorMessage = null;
let dataRumah = [];

async function fetchRumah() {
  try {
    isLoading = true;
    errorMessage = null;
    console.log("🔄 Loading: Mengambil data rumah...");

    const response = await fetch("https://jsonplaceholder.typicode.com/posts?_limit=5");

    if (!response.ok) {
      throw new Error(`Server error: ${response.status} ${response.statusText}`);
    }

    dataRumah = await response.json();
    console.log("✅ Data berhasil dimuat:", dataRumah.length, "item");
  } catch (error) {
    errorMessage = error.message;
    console.log("❌ Error:", errorMessage);

    // Retry logic — coba lagi setelah 3 detik
    if (error.message.includes("network") || error.message.includes("fetch")) {
      console.log("⏳ Mencoba lagi dalam 3 detik...");
      setTimeout(() => fetchRumah(), 3000);
    }
  } finally {
    isLoading = false;
    console.log("✨ Loading selesai");
  }
}

fetchRumah();
```

```js
// ========== ERROR HANDLING LENGKAP ==========
async function getDataRumah(id) {
  try {
    // 1. Validasi input
    if (!id || id < 1) throw new Error("ID rumah tidak valid");

    // 2. Fetch data
    const res = await fetch(`https://jsonplaceholder.typicode.com/posts/${id}`);

    // 3. Cek HTTP status
    if (res.status === 404) throw new Error("Rumah tidak ditemukan (404)");
    if (res.status === 500) throw new Error("Server sedang error (500) — coba lagi nanti");
    if (!res.ok) throw new Error(`HTTP error: ${res.status}`);

    // 4. Parse JSON
    const data = await res.json();

    // 5. Validasi data
    if (!data.title) throw new Error("Data rumah tidak lengkap");

    return { sukses: true, data };

  } catch (error) {
    return {
      sukses: false,
      error: error.message,
      tipe: error.name === "TypeError" ? "NETWORK" : "APPLICATION"
    };
  }
}

// Penggunaan
async function tampilkanRumah(id) {
  console.log(`🔍 Mencari rumah ${id}...`);

  const result = await getDataRumah(id);

  if (result.sukses) {
    console.log("🏠", result.data.title);
  } else {
    console.log(`⚠️ [${result.tipe}] ${result.error}`);
  }
}

tampilkanRumah(1);    // sukses
tampilkanRumah(0);    // error validasi
tampilkanRumah(9999); // 404
```

// ========== ABORT CONTROLLER (cancel request) ==========
async function fetchWithTimeout(url, timeoutMs = 5000) {
  const controller = new AbortController();
  const timeoutId = setTimeout(() => controller.abort(), timeoutMs);

  try {
    const response = await fetch(url, { signal: controller.signal });
    clearTimeout(timeoutId);
    return response.json();
  } catch (error) {
    if (error.name === "AbortError") {
      throw new Error("Request timeout — server tidak merespon");
    }
    throw error;
  }
}

## Analogi
**Error handling = rencana cadangan jika hujan/banjir saat bangun rumah**:
- **try** = melanjutkan pembangunan rumah seperti biasa
- **catch** = "Hujan deras! Buka tenda darurat, tutup material dengan terpal" — rencana alternatif
- **finally** = "Apapun cuacanya, catat progress hari ini di laporan" — yang tetap jalan

**Loading state = papan "SEDANG DIBANGUN" di depan rumah**:
- Spinner/loading = papan yang menyala "Dalam Proses"
- Skeleton screen = cetak biru rumah yang masih berupa kerangka (belum diisi)
- Disabled button = "DILARANG MASUK — AREA KONSTRUKSI" (cegah klik ganda)
- Error message = pengumuman "Pembangunan dihentikan sementara karena hujan"

## Dipakai Untuk Apa
Error handling dipakai di: form validation (error message di bawah input), API calls (toast "Gagal memuat data"), retry mechanism ("Coba lagi" button), offline detection ("Kamu sedang offline"). Loading state dipakai di: tombol submit (disabled + spinner), daftar data (skeleton card), infinite scroll (loading indicator di bawah), initial page load (full page loader).

## Kesalahan Umum
Hanya pakai try/catch tanpa memberi feedback ke user — error silent. Tidak membedakan jenis error (network vs server vs validasi). Lupa set `isLoading = false` di `finally` — loading forever. Tidak handle kasus spesifik: 401 (unauthorized — redirect login), 403 (forbidden), 429 (rate limited). Juga: terlalu percaya pada response — selalu validasi struktur data yang diterima.

## Keterkaitan dengan Materi Sebelumnya
Di Level 4 (class, OOP), kamu bisa membuat class `UiState` yang mengelola loading/error state secara terpusat:
```js
class UiState {
  constructor() {
    this.loading = false;
    this.error = null;
    this.data = null;
  }

  setLoading() { this.loading = true; this.error = null; }
  setError(err) { this.loading = false; this.error = err; }
  setData(data) { this.loading = false; this.error = null; this.data = data; }

  get isError() { return this.error !== null; }
  get isLoading() { return this.loading; }
  get hasData() { return this.data !== null; }
}

// Penggunaan dengan class Rumah (dari Level 4)
class RumahManager {
  constructor() {
    this.state = new UiState();
  }

  async loadRumah(id) {
    this.state.setLoading();
    try {
      const data = await ambilRumahDariAPI(id);
      this.state.setData(data);
    } catch (err) {
      this.state.setError(err.message);
    }
  }
}
```

## Soal Latihan
Buat fungsi `ambilDataDenganRetry(url, maxRetry = 3)` yang mencoba fetch url. Jika gagal (catch atau !response.ok), coba lagi hingga maxRetry kali. Jika akhirnya tetap gagal, kembalikan pesan error yang jelas.

async function ambilDataDenganRetry(url, maxRetry = 3) {
  for (let percobaan = 1; percobaan <= maxRetry; percobaan++) {
    try {
      console.log(`📡 Percobaan ${percobaan}/${maxRetry}...`);
      const res = await fetch(url);

      if (!res.ok) {
        throw new Error(`HTTP ${res.status}`);
      }

      const data = await res.json();
      console.log("✅ Berhasil!");
      return data;

    } catch (error) {
      console.log(`❌ Gagal: ${error.message}`);

      if (percobaan === maxRetry) {
        throw new Error(`Gagal setelah ${maxRetry} kali percobaan: ${error.message}`);
      }

      // Tunggu sebentar sebelum retry (exponential backoff sederhana)
      await new Promise((r) => setTimeout(r, 1000 * percobaan));
    }
  }
}
