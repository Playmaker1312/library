# 46. async await

## Penjelasan
`async` dan `await` adalah syntactic sugar di atas Promise — cara menulis kode asynchronous yang terlihat seperti synchronous (berurutan dari atas ke bawah). Kata kunci `async` mengubah fungsi biasa menjadi fungsi yang otomatis mengembalikan Promise. Kata kunci `await` memberitahu JavaScript: "tunggu sampai Promise ini selesai, baru lanjut ke baris berikutnya." `await` hanya bisa digunakan di dalam fungsi `async`.

## Fungsi
async/await membuat kode asynchronous jauh lebih mudah dibaca dan di-debug dibandingkan Promise chain atau callback. Error handling bisa pakai `try/catch` biasa (tanpa `.catch()`). Alur eksekusi terlihat linear — tidak perlu membayangkan chain `.then()`. Ini adalah standar modern penulisan asynchronous JavaScript dan digunakan di hampir semua kode JavaScript kontemporer.

## Cara Pengimplementasian
```js
// Fungsi Promise biasa
function pesanMaterial(nama, durasi) {
  return new Promise((resolve) => {
    setTimeout(() => resolve(`${nama} sudah sampai`), durasi);
  });
}

// async await — "tunggu sampai material datang, baru lanjut"
async function bangunRumah() {
  console.log("Mulai bangun rumah...");

  const semen = await pesanMaterial("Semen", 1000);
  console.log(semen);

  const pasir = await pesanMaterial("Pasir", 1500);
  console.log(pasir);

  const bata = await pesanMaterial("Bata", 2000);
  console.log(bata);

  console.log("Rumah selesai dibangun!");
  return "Rumah Jadi";
}

bangunRumah().then((hasil) => console.log(hasil));
```

```js
// Error handling dengan try/catch
async function renovasiRumah() {
  try {
    const dana = await cekSaldo();
    if (dana < 5000000) throw new Error("Dana tidak cukup");

    const tukang = await cariTukang();
    const material = await beliMaterial();

    console.log(`${tukang} mulai renovasi dengan ${material}`);
    return "Renovasi sukses";
  } catch (error) {
    console.log("Renovasi gagal:", error.message);
    return "Renovasi ditunda";
  } finally {
    console.log("Proses renovasi selesai (apapun hasilnya)");
  }
}
```

```js
// async arrow function
const perbaikiAtap = async () => {
  const alat = await siapkanAlat();
  const tukang = await panggilTukang();
  return `${tukang} memperbaiki atap pakai ${alat}`;
};
```

```js
// await dengan Promise.all — paralel pakai async/await
async function renovasiParalel() {
  const hasil = await Promise.all([
    pesanMaterial("Cat", 2000),
    pesanMaterial("Keramik", 1500),
    pesanMaterial("Pipa", 1000)
  ]);
  console.log("Semua material siap:", hasil);
}
```

## Analogi
**async/await adalah instruksi ke kontraktor rumah**: "Tunggu sampai material datang, baru lanjut ke langkah berikutnya." Seperti SOP (Standard Operating Procedure) pembangunan rumah:
1. `await` galiPondasi() — tunggu galian selesai
2. `await` corBeton() — baru cor
3. `await` pasangBata() — baru pasang bata
Tanpa await, kontraktor akan mengerjakan semua langkah sekaligus meskipun material belum siap — berantakan. Ini berbeda dengan Promise biasa yang seperti memberi daftar instruksi ke mandor (`.then()`), async/await seperti duduk di meja dan mengawasi langsung satu per satu langkah.

## Dipakai Untuk Apa
async/await dipakai di semua kode JavaScript modern: fetching API (`const data = await fetch(url)`), operasi database (MongoDB, PostgreSQL), pembacaan file di Node.js (`await fs.readFile()`), validasi form asynchronous, autocomplete/search, dan semua tempat yang sebelumnya pakai Promise chain.

## Kesalahan Umum
Lupa menambahkan `async` pada fungsi yang menggunakan `await` — error "await is only valid in async function". Menggunakan `await` di dalam loop `forEach` — `forEach` tidak menunggu Promise; gunakan `for...of` sebagai gantinya. Tidak membungkus dengan `try/catch` — Promise rejection menjadi unhandled. Juga: terlalu banyak `await` serial padahal tidak perlu (bisa paralel dengan `Promise.all`), yang membuat kode lebih lambat.

## Keterkaitan dengan Materi Sebelumnya
Di Level 4 (class, OOP), kamu bisa membuat class dengan method `async` — menggabungkan struktur OOP dengan asynchronous modern:
```js
class Rumah {
  constructor(alamat) {
    this.alamat = alamat;
    this.ruangan = [];
  }

  async tambahRuangan(nama) {
    // simulasi proses asynchronous
    await new Promise((r) => setTimeout(r, 500));
    this.ruangan.push(nama);
    return `${nama} ditambahkan ke ${this.alamat}`;
  }

  async bangun() {
    await this.tambahRuangan("Kamar Tidur");
    await this.tambahRuangan("Ruang Tamu");
    await this.tambahRuangan("Dapur");
    return this.ruangan;
  }
}
```

## Soal Latihan
Ubah kode berikut (Promise chain) ke async/await:
```js
function cekSaldo() { return Promise.resolve(1000000); }
function beliBahan(harga) { return Promise.resolve(`Bahan dibeli seharga ${harga}`); }
function mulaiRenovasi() { return Promise.resolve("Renovasi dimulai"); }

cekSaldo()
  .then((saldo) => beliBahan(saldo * 0.5))
  .then((hasilBeli) => { console.log(hasilBeli); return mulaiRenovasi(); })
  .then((hasilRenovasi) => console.log(hasilRenovasi))
  .catch((err) => console.log(err));
```
