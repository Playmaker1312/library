# 6. Cara menjalankan JavaScript – Browser Console file js Node.js

**Definisi Singkat:** JavaScript bisa dijalankan langsung di browser console, dari file .html (via script tag), atau menggunakan runtime Node.js dari terminal.

**Analogi:** Seperti resep masakan — bisa dicoba langsung dari ponsel (browser console), dimasak di dapur (file HTML), atau dimasak secara profesional di restoran (Node.js). Bahannya sama, caranya berbeda.

**Poin-Poin Penting:**
- Browser Console: buka DevTools (F12) → Console → ketik JS langsung — cocok untuk testing cepat
- File HTML: tulis `<script>` di dalam HTML lalu buka di browser — untuk proyek frontend
- File .js via Node.js: `node nama_file.js` di terminal — untuk backend scripting
- Deno: `deno run nama_file.js`, Bun: `bun run nama_file.js`
- Bisa juga via online playground: CodePen, JSFiddle, StackBlitz, PlayCode

**Contoh Kode:**
```javascript
// Simulasi berbagai cara menjalankan kode
console.log("=== Cara Menjalankan JavaScript ===");
console.log("Metode 1: Browser Console");
console.log("\t> Jalankan: Buka F12 → Console → ketik kode");
console.log("\t> Contoh: console.log('Hello from Console!');");

console.log("Metode 2: File HTML");
console.log('\t> <script> console.log("Hello from HTML!"); </script>');
console.log("\t> Jalankan: buka file .html di browser");

console.log("Metode 3: Node.js");
console.log("\t> node nama_file.js");
console.log("\t> Output akan muncul di terminal");

console.log("Metode 4: Deno / Bun");
console.log("\t> deno run file.js   atau   bun run file.js");

// Kode yang sama bisa jalan di semua metode
const sapa = metode => {
  const output = `Hello dari ${metode}!`;
  console.log(output);
  return output;
};

sapa("file.js via Node.js");
```
Hasil:
```
=== Cara Menjalankan JavaScript ===
Metode 1: Browser Console
        > Jalankan: Buka F12 → Console → ketik kode
        > Contoh: console.log('Hello from Console!');
Metode 2: File HTML
        > <script> console.log("Hello from HTML!"); </script>
        > Jalankan: buka file .html di browser
Metode 3: Node.js
        > node nama_file.js
        > Output akan muncul di terminal
Metode 4: Deno / Bun
        > deno run file.js   atau   bun run file.js
Hello dari file.js via Node.js!
```

**Kasus Penggunaan Nyata:** Developer menggunakan browser console untuk debugging cepat, Node.js untuk menjalankan script build/test di CI/CD pipeline, dan Deno/Bun untuk server production yang membutuhkan performa tinggi.
