# 8. Setup Development Environment – VS Code ekstensi penting

**Definisi Singkat:** Development environment untuk JavaScript cukup mudah — instal VS Code, Node.js, dan ekstensi pendukung seperti ESLint, Prettier, dan Live Server.

**Analogi:** Seperti menyiapkan meja kerja tukang kayu — VS Code adalah meja kerjanya, ekstensi adalah alat-alat (gergaji, palu, meteran) yang diletakkan di meja, dan Node.js adalah listrik yang menyalakan alat-alat itu.

**Poin-Poin Penting:**
- Install Node.js dari nodejs.org (pilih LTS) — sudah termasuk npm (package manager)
- VS Code ekstensi wajib: ESLint (kualitas kode), Prettier (format otomatis), Live Server (auto-reload HTML)
- Ekstensi pelengkap: JavaScript (ES6) code snippets, Path Intellisense, Bracket Pair Colorizer, GitHub Copilot
- Fitur VS Code penting: Terminal terintegrasi (Ctrl+`), Debugger (F5), IntelliSense, Source Control
- Gunakan `nvm` (Node Version Manager) untuk gonta-ganti versi Node.js di project berbeda

**Contoh Kode:**
```javascript
// Cek setup environment
console.log("=== Cek Setup Development Environment ===\n");

// Cek versi Node.js
console.log("Node.js versi:", process.version);

// Cek versi npm (synchronous simulation)
const { execSync } = require("child_process");
try {
  const npmVersion = execSync("npm --version").toString().trim();
  console.log("npm versi:", npmVersion);
} catch (e) {
  console.log("npm tidak terdeteksi");
}

// Informasi platform
console.log("Platform:", process.platform);
console.log("Architecture:", process.arch);
console.log("VS Code shortcut penting:");
console.log("  - Ctrl+Shift+P: Command Palette");
console.log("  - F5: Start Debugging");
console.log("  - Ctrl+`: Buka Terminal");
console.log("  - Alt+Up/Down: Pindah baris");

// Cek apakah file ini dijalankan via Node
console.log("\nFile:", __filename);
console.log("Directory:", __dirname);
```
Hasil:
```
=== Cek Setup Development Environment ===

Node.js versi: v...
npm versi: ...
Platform: win32
Architecture: x64
VS Code shortcut penting:
  - Ctrl+Shift+P: Command Palette
  - F5: Start Debugging
  - Ctrl+`: Buka Terminal
  - Alt+Up/Down: Pindah baris

File: ...
Directory: ...
```

**Kasus Penggunaan Nyata:** Setup standar tim developer: ESLint + Prettier dikonfigurasi sebagai pre-commit hook untuk memastikan semua kode konsisten sebelum masuk repository.
