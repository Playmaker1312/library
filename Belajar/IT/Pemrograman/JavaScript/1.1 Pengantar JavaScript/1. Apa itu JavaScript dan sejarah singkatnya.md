# 1. Apa itu JavaScript dan sejarah singkatnya

**Definisi Singkat:** JavaScript adalah bahasa pemrograman tingkat tinggi, dinamis, dan multi-paradigma yang awalnya dibuat untuk membuat halaman web interaktif, kini juga merambah server dan perangkat lunak umum.

**Analogi:** JavaScript seperti "otot" halaman web — HTML adalah kerangka tulang, CSS adalah kulit dan pakaian, sedangkan JavaScript adalah otot yang membuat semuanya bergerak dan merespons.

**Poin-Poin Penting:**
- Dibuat oleh Brendan Eich pada tahun 1995 hanya dalam 10 hari saat bekerja di Netscape
- Awalnya bernama Mocha, lalu LiveScript, akhirnya JavaScript sebagai strategi marketing
- Distandarisasi sebagai ECMAScript (ECMA-262) agar konsisten di berbagai browser
- Node.js (2009) memungkinkan JavaScript berjalan di server, meledakkan popularitasnya
- Sekarang menjadi salah satu bahasa paling populer di dunia dengan ekosistem npm terbesar

**Contoh Kode:**
```javascript
// Menampilkan informasi singkat tentang JavaScript
console.log("Javascript lahir: 1995");
console.log("Pembuat: Brendan Eich");
console.log("Waktu pembuatan: ~10 hari");
console.log("Nama awal: Mocha -> LiveScript -> JavaScript");
console.log("Standarisasi: ECMAScript (ECMA-262)");
```
Hasil:
```
Javascript lahir: 1995
Pembuat: Brendan Eich
Waktu pembuatan: ~10 hari
Nama awal: Mocha -> LiveScript -> JavaScript
Standarisasi: ECMAScript (ECMA-262)
```

**Kasus Penggunaan Nyata:**
React, Angular, dan Vue digunakan untuk membangun aplikasi web modern seperti Facebook, Gmail, dan Netflix; Node.js dipakai oleh LinkedIn, PayPal, dan Uber untuk backend; Electron dipakai untuk VS Code dan Slack.
