# 3. Bagaimana JavaScript dijalankan – Engine V8 SpiderMonkey

**Definisi Singkat:** JavaScript engine adalah program yang membaca, mengompilasi (JIT), dan mengeksekusi kode JavaScript menjadi instruksi mesin sehingga komputer bisa memahaminya.

**Analogi:** Seperti penerjemah simultan — manusia berbicara bahasa Indonesia (kode JS), lalu penerjemah mengubahnya ke bahasa Jepang (machine code) saat itu juga agar pendengar Jepang mengerti.

**Poin-Poin Penting:**
- Engine menggunakan teknik JIT (Just-In-Time) Compilation — kompilasi terjadi saat eksekusi, bukan sebelumnya
- V8 (Google) adalah engine terpopuler, dipakai di Chrome, Node.js, Deno, dan Electron
- SpiderMonkey (Mozilla) adalah engine pertama yang pernah dibuat untuk JavaScript
- JavaScriptCore (Apple) dipakai di Safari, Chakra (Microsoft, sudah pensiun) dipakai di Edge lawas
- Setiap engine mengimplementasikan standar ECMAScript, jadi kode JS yang sama bisa jalan di semua engine

**Contoh Kode:**
```javascript
// Simulasi kerja engine: Parse -> Compile -> Execute
const kodeSaya = "const x = 10 + 5";

// Tahap 1: Tokenize (memecah jadi token)
console.log("=== Simulasi Engine JavaScript ===");
console.log("Kode sumber:", kodeSaya);

// Tahap 2: Parse (membangun AST — Abstract Syntax Tree)
const ast = {
  type: "VariableDeclaration",
  name: "x",
  value: { type: "BinaryExpression", operator: "+", left: 10, right: 5 }
};
console.log("AST:", JSON.stringify(ast, null, 2));

// Tahap 3: Execution
const x = 10 + 5;
console.log("Hasil eksekusi: x =", x);

// Cek engine yang dipakai (di Node.js)
console.log("Engine:", process.version ? "V8 (Node.js)" : "Unknown");
```
Hasil:
```
=== Simulasi Engine JavaScript ===
Kode sumber: const x = 10 + 5
AST: {
  "type": "VariableDeclaration",
  "name": "x",
  "value": {
    "type": "BinaryExpression",
    "operator": "+",
    "left": 10,
    "right": 5
  }
}
Hasil eksekusi: x = 15
Engine: V8 (Node.js)
```

**Kasus Penggunaan Nyata:** V8 optimization membuat Node.js mampu menangani ribuan request per detik seperti di Netflix; SpiderMonkey dipakai di aplikasi Firefox OS.
