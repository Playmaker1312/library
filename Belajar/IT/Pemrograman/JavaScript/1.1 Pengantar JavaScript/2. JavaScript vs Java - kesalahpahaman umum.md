# 2. JavaScript vs Java – kesalahpahaman umum

**Definisi Singkat:** Meskipun namanya mirip, JavaScript dan Java adalah dua bahasa yang sangat berbeda — Java adalah bahasa kompilasi berbasis class, sedangkan JavaScript adalah bahasa interpretasi berbasis prototype.

**Analogi:** Ini seperti "mobil" (Mobil Kijang) vs "Mobil Es" (es krim) — keduanya sama-sama punya kata "mobil" tapi tidak ada hubungan sama sekali.

**Poin-Poin Penting:**
- Java dikembangkan Sun Microsystems (James Gosling), JavaScript oleh Netscape (Brendan Eich) — tidak ada hubungan tim
- Nama JavaScript hanya trik marketing untuk menumpang popularitas Java di era 90-an
- Java menggunakan static typing, JavaScript dynamic typing
- Java berjalan di JVM (Java Virtual Machine), JavaScript di engine browser atau runtime Node.js
- Java untuk aplikasi enterprise Android backend, JavaScript untuk web interaktif full-stack

**Contoh Kode:**
```javascript
// Membandingkan gaya syntax dan tipe data
const javaStyle = "Java: String nama = \"Budi\";"; // static typing
const jsStyle = "JS: let nama = \"Budi\";";          // dynamic typing

console.log("=== JavaScript vs Java ===");
console.log("Tipe data:", typeof "Budi");            // string
console.log("Tipe data:", typeof 123);               // number
console.log("JS bisa ganti tipe:", typeof true);     // boolean

// Java: int angka = 10; (fixed)
// JavaScript:
let angka = 10;
console.log("Angka sekarang:", angka, typeof angka);
angka = "sepuluh"; // valid di JS!
console.log("Angka berubah:", angka, typeof angka);
```
Hasil:
```
=== JavaScript vs Java ===
Tipe data: string
Tipe data: number
Tipe data: boolean
Angka sekarang: 10 number
Angka berubah: sepuluh string
```

**Kasus Penggunaan Nyata:** Stack Java (Spring Boot + Android) untuk aplikasi perbankan, Stack JavaScript (React + Node.js) untuk aplikasi e-commerce seperti Tokopedia.
