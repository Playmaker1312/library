# 9. Debugging dasar – console.log console.table console.error

**Definisi Singkat:** Debugging adalah proses mencari dan memperbaiki bug, dan method console di JavaScript adalah alat debugging paling fundamental — `log()` untuk info, `table()` untuk data tabular, `error()` untuk error.

**Analogi:** Seperti detektif di TKP — console.log seperti senter (menerangi data), console.table seperti papan bukti (mengatur semua barang bukti rapi), console.error seperti spidol merah (menandai barang bukti berbahaya).

**Poin-Poin Penting:**
- `console.log()` untuk mencetak nilai variabel dan tracking alur eksekusi — paling sering dipakai
- `console.table()` menampilkan array/objek dalam format tabel rapi — sangat berguna untuk data kompleks
- `console.error()` mencetak error dengan format merah mencolok — jelas beda dari log biasa
- `console.warn()` untuk peringatan, `console.info()` untuk informasi, `console.group()` untuk nesting
- `console.time() / console.timeEnd()` untuk mengukur performa kode

**Contoh Kode:**
```javascript
// Demonstrasi berbagai method console debugging
console.log("=== Console Debugging Methods ===\n");

// console.log — dasar
const user = "Budi";
const umur = 25;
console.log("User:", user, "Umur:", umur);

// console.table — data terstruktur
const users = [
  { id: 1, nama: "Ani", role: "Admin" },
  { id: 2, nama: "Budi", role: "User" },
  { id: 3, nama: "Citra", role: "Editor" },
];
console.table(users);

// console.error — error simulation
console.error("ERROR: Data tidak ditemukan (404)");

// console.warn — warning
console.warn("WARNING: Deprecated API dipakai");

// console.group — nested grouping
console.group("Profil User");
console.log("Nama: Dewi");
console.log("Umur: 30");
console.group("Alamat");
console.log("Kota: Jakarta");
console.log("Provinsi: DKI Jakarta");
console.groupEnd();
console.groupEnd();

// console.time — performance measurement
console.time("Loop 1000");
let sum = 0;
for (let i = 0; i < 1000; i++) sum += i;
console.timeEnd("Loop 1000");
```
