# 4. JavaScript di Browser vs di Server Node.js Deno Bun

**Definisi Singkat:** JavaScript bisa berjalan di browser (client-side) untuk memanipulasi DOM dan interaksi pengguna, atau di server menggunakan runtime seperti Node.js, Deno, atau Bun untuk backend logic dan file system.

**Analogi:** Browser seperti warung kopi — Anda datang, pesan, minum di tempat, lalu pulang. Server seperti dapur restoran — makanan dimasak, dikemas, lalu dikirim ke pelanggan. Bahasa resepnya sama, konteksnya berbeda.

**Poin-Poin Penting:**
- Di browser: punya akses ke `window`, `document`, `fetch` API, event user — tapi tidak bisa baca file sistem
- Di Node.js: punya akses ke `fs`, `http`, `path`, `process` — tapi tidak punya DOM API
- Deno buatan Ryan Dahl (pencipta Node.js) — perbaikan: security by default, support TypeScript native
- Bun adalah runtime terbaru — extremely fast, built-in bundler, transpiler, package manager
- Runtime berbeda membuat JavaScript benar-benar full-stack language

**Contoh Kode:**
```javascript
// Deteksi lingkungan eksekusi
console.log("=== Deteksi Lingkungan JavaScript ===");
console.log("Nama runtime:", typeof process !== "undefined"
  ? (process.versions?.bun
      ? "Bun v" + process.versions.bun
      : typeof Deno !== "undefined"
        ? "Deno v" + Deno.version
        : "Node.js v" + process.versions.node)
  : "Browser");

// Perbedaan global object
console.log("Global object:", typeof globalThis !== "undefined" ? "globalThis tersedia" : "tidak ada");

// Simulasi perbedaan environment
const envs = {
  browser: ["window", "document", "localStorage", "fetch"],
  node: ["global", "process", "require", "__dirname"],
};

console.log("\nAPI Eksklusif Browser:", envs.browser.join(", "));
console.log("API Eksklusif Node.js:", envs.node.join(", "));

// Contoh kode yang bisa jalan di mana saja
const pesan = (who) => `Hello dari ${who}!`;
console.log(pesan(typeof window !== "undefined" ? "Browser" : "Server"));
```
Hasil:
```
=== Deteksi Lingkungan JavaScript ===
Nama runtime: Node.js v...
Global object: globalThis tersedia

API Eksklusif Browser: window, document, localStorage, fetch
API Eksklusif Node.js: global, process, require, __dirname
Hello dari Server!
```

**Kasus Penggunaan Nyata:** Next.js menggunakan JS di browser (client component) dan server (server component) secara mulus; Deno dipakai untuk serverless functions di Netlify Edge Functions; Bun dipakai untuk development server cepat di proyek React.
