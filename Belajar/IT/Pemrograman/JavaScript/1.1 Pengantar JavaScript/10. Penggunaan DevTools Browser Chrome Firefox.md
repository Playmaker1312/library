# 10. Penggunaan DevTools Browser Chrome Firefox

**Definisi Singkat:** DevTools adalah tool bawaan browser (F12) untuk menginspeksi, debugging, dan profiling halaman web — tab utama: Elements, Console, Sources, Network, Performance.

**Analogi:** Seperti dokter dengan alat stetoskop, CT scan, dan monitor jantung — DevTools adalah alat diagnostik untuk "menyembuhkan" (debug) halaman web yang bermasalah.

**Poin-Poin Penting:**
- **Elements (Chrome) / Inspector (Firefox):** lihat dan edit HTML/CSS secara real-time tanpa refresh
- **Console:** menjalankan kode JS langsung, lihat error, warnings, log messages
- **Sources (Chrome) / Debugger (Firefox):** set breakpoint, step through kode, lihat scope variable
- **Network:** lihat semua request HTTP/HTTPS — methods, headers, response, timing
- **Performance/Performance Monitor:** rekam aktivitas halaman, cari bottleneck rendering dan JavaScript

**Contoh Kode:**
```javascript
// Simulasi fitur debugging DevTools
console.log("=== DevTools Browser — Fitur Debugging ===\n");

// Contoh yang bisa di-debug di Sources/Debugger tab
function hitungDiskon(harga, diskonPersen) {
  const diskon = harga * (diskonPersen / 100);
  const total = harga - diskon;
  console.log(`Harga: ${harga}, Diskon: ${diskonPersen}%`);
  console.log(`Total bayar: ${total}`);
  // Set breakpoint di sini di Sources tab untuk step-through
  return total;
}

hitungDiskon(100000, 20);

// Contoh inspeksi Network di DevTools
console.log("Buka tab Network → Refresh → Lihat requests");
console.log("Filter: XHR/Fetch, JS, CSS, Img, Doc");

// Contoh edit HTML real-time di Elements tab
console.log("Buka tab Elements → Double click teks → Edit langsung!");

// Contoh Performance recording
console.log("Buka tab Performance → Klik Record → Interaksi → Stop");

// Cek user agent untuk bedain browser
console.log("Browser:", navigator.userAgent);
console.log("DevTools: F12 (Chrome) / F12 (Firefox) / Ctrl+Shift+I");
```
Hasil:
```
=== DevTools Browser — Fitur Debugging ===

Harga: 100000, Diskon: 20%
Total bayar: 80000
Buka tab Network → Refresh → Lihat requests
Filter: XHR/Fetch, JS, CSS, Img, Doc
Buka tab Elements → Double click teks → Edit langsung!
Buka tab Performance → Klik Record → Interaksi → Stop
Browser: ...
DevTools: F12 (Chrome) / F12 (Firefox) / Ctrl+Shift+I
```

**Kasus Penggunaan Nyata:** Tim frontend menggunakan tab Network untuk debugging API response 500 error, tab Performance untuk optimasi Largest Contentful Paint (LCP), tab Elements untuk quick CSS fix tanpa deploy.
