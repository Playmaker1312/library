# 5. ECMAScript – standar dan versinya ES5 ES6 ES2020+

**Definisi Singkat:** ECMAScript (ES) adalah standar resmi yang mendefinisikan spesifikasi bahasa JavaScript, dirilis setiap tahun sejak ES6 dengan fitur-fitur baru JavaScript.

**Analogi:** Seperti standar USB — USB 2.0, 3.0, USB-C semuanya tetap "colokan USB" tapi kecepatan dan kemampuannya berbeda. ECMAScript 5, 6, 2020 semuanya "JavaScript" tapi fiturnya bertambah.

**Poin-Poin Penting:**
- ES5 (2009): standar besar pertama — array methods (forEach, map, filter), JSON, strict mode
- ES6/ES2015: revolusioner — let/const, arrow function, class, template literals, destructuring, Promise, module
- Mulai ES2016: rilis tahunan — setiap tahun ada versi baru dengan fitur baru
- ES2020: BigInt, Nullish Coalescing (??), Optional Chaining (?.), globalThis, Promise.allSettled
- ES2021+: String.replaceAll, Logical Assignment, Promise.any, Array at, Top-level await

**Contoh Kode:**
```javascript
// Evolusi fitur dari berbagai versi ECMAScript
console.log("=== Evolusi ECMAScript ===\n");

// ES5 — var dan function (2009)
var namaES5 = "Budi";
function berjalanES5() { console.log("ES5: Bisa jalan"); }
berjalanES5();

// ES6 — let, const, arrow function (2015)
const namaES6 = "Ani";
const sapaES6 = (nama) => `Halo ${nama}`;
console.log("ES6:", sapaES6(namaES6));

// ES2017 — async/await
const asyncFn = async () => "ES2017: Async/Await bekerja";
asyncFn().then(console.log);

// ES2020 — optional chaining & nullish coalescing
const user = { profile: { name: "Citra" } };
console.log("ES2020 Optional Chaining:", user?.profile?.name ?? "default");
console.log("ES2020 Nullish Coalescing:", user?.alamat?.jalan ?? "Alamat tidak tersedia");

// ES2021 — String.replaceAll
const kalimat = "ES5 ES6 ES2015 ES2020";
console.log("ES2021 replaceAll:", kalimat.replaceAll("ES", "ECMAScript"));
```
Hasil:
```
=== Evolusi ECMAScript ===

ES5: Bisa jalan
ES6: Halo Ani
ES2017: Async/Await bekerja
ES2020 Optional Chaining: Citra
ES2020 Nullish Coalescing: Alamat tidak tersedia
ES2021 replaceAll: ECMAScript5 ECMAScript6 ECMAScript2015 ECMAScript2020
```

**Kasus Penggunaan Nyata:** Project modern menggunakan ES6+ dengan Babel untuk transpile balik ke ES5 jika perlu dukung browser lama; fitur ES2020+ dipakai di semua codebase React/Vue/Angular modern.
