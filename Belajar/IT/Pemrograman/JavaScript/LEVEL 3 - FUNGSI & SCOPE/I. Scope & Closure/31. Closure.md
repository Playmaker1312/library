# 31. Closure

## Penjelasan
**Closure** adalah kemampuan sebuah fungsi untuk "mengingat" dan mengakses variabel dari scope induknya, bahkan setelah fungsi induk selesai dieksekusi. Setiap kali sebuah fungsi dibuat di dalam fungsi lain, closure terbentuk secara otomatis. Fungsi dalam tersebut menyimpan referensi ke variabel-variabel di lingkup luar, bukan salinan nilainya.

## Fungsi
Closure memungkinkan **data privacy** (variabel yang tidak bisa diakses langsung dari luar), **factory function** (fungsi yang menghasilkan fungsi lain dengan konfigurasi tertentu), dan **partial application** (mengunci sebagian argumen). Ini adalah fondasi dari banyak pola di JavaScript termasuk module pattern, currying, dan state management.

## Cara Pengimplementasian
```js
// Closure sederhana — fungsi dalam "mengingat" variabel luar
function buatRumah(warna) {
  const cat = warna;
  
  return function() {
    console.log(`Rumah berwarna ${cat}`);
  };
}

const rumahMerah = buatRumah("merah");
const rumahBiru = buatRumah("biru");

rumahMerah(); // Rumah berwarna merah
rumahBiru();  // Rumah berwarna biru
// Catatan: variabel `cat` tetap "hidup" meskipun buatRumah sudah selesai

// Closure untuk data privacy (counter)
function buatCounterRumah() {
  let tamu = 0; // Private — tidak bisa diakses langsung
  
  return {
    tambah: () => ++tamu,
    kurangi: () => --tamu,
    lihat: () => tamu
  };
}

const counter = buatCounterRumah();
console.log(counter.tambah()); // 1
console.log(counter.tambah()); // 2
console.log(counter.lihat());  // 2
// console.log(counter.tamu);  // ❌ undefined — private!
```

## Analogi
**Closure = Bau dapur yang "terbawa" ke luar ruangan**:
Bayangkan kamu memasak rendang di dapur (fungsi induk). Setelah memasak selesai, dapur boleh ditutup. Tapi bau rendang yang kuat masih tetap ada di ruang tamu (closure). Bahkan jika pintu dapur sudah tertutup, bau itu tetap tercium — "mengingat" rendang yang dimasak tadi.
- Fungsi induk = **Dapur** (tempat memasak/membuat sesuatu)
- Variabel lokal = **Bumbu dan bahan masakan** (data yang dibuat di dapur)
- Fungsi dalam = **Bau yang keluar** (closure yang membawa "ingatan" akan bumbu)
- Closure = **Bau rendang yang bertahan** — meskipun dapur sudah selesai dipakai, baunya tetap ada di ruangan lain.

## Dipakai Untuk Apa
Closure digunakan untuk: **Module pattern** (membuat data private seperti counter, konfigurasi), **Event handler** yang perlu mengingat state tertentu, **setTimeout/setInterval** yang perlu akses data saat callback dijalankan, **Function factory** (membuat fungsi spesifik dari fungsi umum), dan **Currying** (mengubah fungsi multi-parameter menjadi rantai fungsi satu parameter).

## Kesalahan Umum
Paling umum: **Closure dalam loop dengan `var`**. Karena `var` memiliki function scope, bukan block scope, semua closure dalam loop akan mengingat nilai yang sama (nilai terakhir). Solusi: gunakan `let` (block scope) atau IIFE. Juga, pemula sering tidak sadar bahwa closure menyimpan **referensi** ke variabel, bukan salinan — jadi jika nilai variabel berubah, closure akan melihat nilai terbaru. Kebocoran memori juga bisa terjadi jika closure tidak sengaja menyimpan referensi ke objek besar.

## Keterkaitan dengan Materi Sebelumnya
Closure adalah puncak dari pemahaman scope (materi 29) — closure terjadi karena fungsi dalam tetap memiliki akses ke scope luar. Hoisting (materi 30) juga berperan karena mempengaruhi kapan variabel tersedia. Closure terkait erat dengan Function Expression (materi 27) karena biasanya closure dibuat dengan fungsi yang dikembalikan atau diteruskan sebagai nilai. Konsep ini akan sangat penting di materi Higher-Order Functions (32) dan Callback (33).

## Soal Latihan
Apa output dari kode berikut?
```js
for (var i = 1; i <= 3; i++) {
  setTimeout(() => console.log(i), 100);
}
```
Bagaimana cara memperbaikinya agar mencetak 1, 2, 3?

<details>
<summary>Jawaban</summary>
Output: `4 4 4` (dicetak tiga kali). Karena `var` memiliki function scope, semua closure mengacu pada `i` yang sama — dan saat setTimeout berjalan, `i` sudah menjadi 4. Perbaiki dengan mengganti `var` menjadi `let`: `for (let i = 1; i <= 3; i++)` — `let` menciptakan binding baru setiap iterasi.
</details>
