# 34. Pure Functions & Immutability

## Penjelasan
**Pure Function** adalah fungsi yang memenuhi dua syarat: (1) **Deterministik** — diberikan input yang sama, selalu mengembalikan output yang sama; (2) **Tanpa efek samping (side effects)** — tidak mengubah variabel di luar scope-nya, tidak mengubah argumen, tidak melakukan I/O (console.log, fetch, DOM manipulation). **Immutability** berarti data tidak pernah diubah setelah dibuat — jika perlu "mengubah" data, kamu membuat salinan baru dengan nilai yang dimodifikasi.

## Fungsi
Pure function membuat kode mudah diuji (cukup input-output, tanpa setup), mudah dipahami (tidak perlu melacak state global), dan aman untuk dijalankan paralel. Immutability mencegah bug akibat perubahan data tidak sengaja — terutama di aplikasi besar dengan banyak komponen yang berbagi data (seperti Redux atau React state). Keduanya adalah pilar utama paradigma Functional Programming.

## Cara Pengimplementasian
```js
// ❌ IMPURE — mengubah data luar
let totalLuasRumah = 0;
function tambahLuasImpure(luas) {
  totalLuasRumah += luas; // Side effect: mengubah variabel global
  return totalLuasRumah;
}

// ✅ PURE — deterministik, tanpa side effect
function tambahLuasPure(luasSaatIni, tambahan) {
  return luasSaatIni + tambahan; // Tidak mengubah apapun
}

// ❌ IMPURE — mengubah argumen (mutasi)
const rumah = { nama: "Rumah Biru", kamar: 3 };
function tambahKamarImpure(r) {
  r.kamar += 1; // Mutasi langsung!
  return r;
}

// ✅ PURE — immutability dengan spread operator
function tambahKamarPure(r) {
  return { ...r, kamar: r.kamar + 1 }; // Buat objek baru
}

// Immutability pada array
const kamar = ["Tidur", "Mandi", "Tamu"];

// ❌ Mutasi
function hapusKamarImpure(list, nama) {
  list.splice(list.indexOf(nama), 1); // Mengubah array asli
}

// ✅ Immutable
function hapusKamarPure(list, nama) {
  return list.filter(k => k !== nama); // Mengembalikan array baru
}
```

## Analogi
**Pure Function & Immutability = Rumah dengan aturan "tidak merusak barang orang lain"**:
- **Pure function** = **Resep masakan** — setiap kali kamu mengikuti resep yang sama dengan bahan yang sama, hasilnya selalu sama. Kamu tidak mengubah bahan asli (tidak merusak stok dapur), hanya membuat hidangan baru.
- **Immutability** = **Furnitur yang difoto, bukan dipindah** — kalau kamu ingin lihat bagaimana sofa di tempat lain, kamu foto sofa (buat salinan), bukan mengangkat sofa asli dan memindahkannya. Sofa asli tetap di tempatnya.
- **Side effect** = **Memindahkan lemari orang lain tanpa izin** — kamu mengubah sesuatu yang bukan milikmu, dan orang lain kaget karena lemari sudah pindah tempat.
- **Mutasi** = **Menyobek halaman buku resep** — setelah kamu membuat kue berdasarkan halaman 5, halaman itu disobek. Orang lain tidak bisa lagi menggunakan resep yang sama.

## Dipakai Untuk Apa
Pure function dipakai di **Redux reducer** (setiap reducer harus pure), **React functional component** (komponen harus pure terhadap props-nya), **utility functions** (perhitungan matematika, format tanggal, validasi), **testing** (pure function sangat mudah di-test tanpa mock). Immutability dipakai di **state management** (Redux, Zustand), **React** (setState, useState tidak boleh mutasi state langsung), dan **concurrent programming** (data aman dibagikan tanpa lock).

## Kesalahan Umum
Mengira fungsi itu pure padahal memanggil `Math.random()` atau `Date.now()` — tidak deterministik. Melakukan mutasi pada parameter object/array karena lupa bahwa object dan array dikirim sebagai **referensi** — mengubah properti di dalam fungsi akan mengubah data asli di luar. Juga, pemula sering membuat "pure function" tapi tetap menggunakan `.push()` atau `.splice()` yang mengubah array asli. Solusi: biasakan menggunakan spread operator, `.map()`, `.filter()`, `.reduce()` yang mengembalikan data baru.

## Keterkaitan dengan Materi Sebelumnya
Pure function memperluas konsep fungsi dari materi 27-28. HOF (materi 32) sering menggunakan pure function sebagai callback. Immutability berkaitan dengan destructuring (materi 28 — spread operator untuk menyalin object/array). Konsep ini juga terkait dengan scope (materi 29) — pure function tidak bergantung pada scope luar. Recursion (materi 35) sering menggunakan pure function karena menghindari side effect.

## Soal Latihan
Ubah fungsi berikut menjadi pure function yang immutable:
```js
const daftarBelanja = ["cat", "paku", "kayu"];
function tambahBarang(list, barang) {
  list.push(barang);
  return list;
}
```
