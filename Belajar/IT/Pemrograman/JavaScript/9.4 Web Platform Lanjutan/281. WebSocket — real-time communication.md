### Definisi Singkat

**WebSocket** adalah protokol komunikasi **full-duplex** bidirectional melalui satu koneksi TCP yang persisten. Berbeda dengan HTTP (request-response), WebSocket memungkinkan server mengirim data ke client kapan saja tanpa diminta — ideal untuk aplikasi **real-time** seperti chat, notifikasi langsung, dan game multiplayer.

---

### Analogi

Seperti **saluran telepon** — setelah tersambung (handshake), kedua pihak bisa berbicara kapan saja tanpa menekan tombol lagi. Bandingkan dengan **surat-menyurat** (HTTP) di mana Anda harus mengirim surat, menunggu balasan, baru bisa mengirim surat lagi.

---

### Poin-Poin Penting

- Memulai dengan HTTP **handshake** (`Upgrade: websocket`), kemudian beralih ke protokol WebSocket.
- URL menggunakan **`ws://`** (tidak aman) atau **`wss://`** (aman via TLS).
- **Full-duplex**: Client dan server bisa mengirim pesan kapan saja.
- **Message-based**: Data dikirim dalam frame — teks (string) atau binary (Blob/ArrayBuffer).
- **Built-in types**: `open`, `message`, `error`, `close` events.
- **Node.js**: Library `ws` adalah implementasi WebSocket paling populer.
- **No CORS restrictions** — berbeda dengan fetch/XMLHttpRequest.
- **Keep-alive**: Koneksi tetap terbuka; perlu mekanisme reconnection jika putus.

### Contoh Implementasi

```javascript
// Client-side — browser
const socket = new WebSocket('wss://ws.example.com/chat');

socket.addEventListener('open', () => {
  console.log('Terhubung ke server');
  socket.send(JSON.stringify({ type: 'join', username: 'Budi' }));
});

socket.addEventListener('message', (event) => {
  const data = JSON.parse(event.data);
  console.log('Pesan dari server:', data);
  // Tampilkan di UI
});

socket.addEventListener('close', () => {
  console.log('Koneksi ditutup');
  // Reconnect setelah 3 detik
  setTimeout(() => reconnect(), 3000);
});

socket.addEventListener('error', (err) => {
  console.error('WebSocket error:', err);
});

// Kirim pesan
function sendMessage(text) {
  socket.send(JSON.stringify({ type: 'message', text }));
}

// Server-side — Node.js dengan library 'ws'
const WebSocket = require('ws');
const wss = new WebSocket.Server({ port: 8080 });

wss.on('connection', (ws) => {
  console.log('Client baru terhubung');

  ws.on('message', (message) => {
    const data = JSON.parse(message);
    // Broadcast ke semua client lain
    wss.clients.forEach((client) => {
      if (client !== ws && client.readyState === WebSocket.OPEN) {
        client.send(JSON.stringify(data));
      }
    });
  });

  ws.send(JSON.stringify({ type: 'welcome', message: 'Selamat datang!' }));
});
```

### Koneksi

Berkaitan dengan **WebRTC** (real-time media — WebSocket sering digunakan untuk signaling), **Service Workers** (push notification via WebSocket), **EventEmitter** (pattern event mirip WebSocket events), **RxJS** (WebSocket bisa dibungkus jadi Observable), dan **HTTP/2** (alternatif untuk server push).
