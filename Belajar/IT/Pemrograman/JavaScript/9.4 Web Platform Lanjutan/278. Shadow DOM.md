### Definisi Singkat

**Shadow DOM** adalah teknologi web standar yang menyediakan **encapsulation** untuk DOM dan style. Shadow DOM memungkinkan komponen memiliki **shadow tree** terisolasi — terpisah dari main document DOM. Style dan markup di dalam shadow tree tidak bocor ke luar, dan style luar tidak memengaruhinya.

---

### Analogi

Seperti **kapsul waktu** yang dikubur di halaman rumah — isi kapsul (shadow tree) tidak terlihat dari permukaan (main DOM) dan tidak terpengaruh oleh cuaca di luar (global CSS). Saat Anda membuka kapsul, semua isinya masih utuh dan original.

---

### Poin-Poin Penting

- **`element.attachShadow({ mode: 'open' | 'closed' })`** — buat shadow root.
  - `'open'`: shadow root bisa diakses via `element.shadowRoot`.
  - `'closed'`: shadow root tidak bisa diakses dari luar.
- **Style scoping**: CSS di dalam shadow DOM tidak memengaruhi elemen lain; CSS global juga tidak masuk.
- **`:host` selector**: Mem-style elemen host dari dalam shadow DOM.
- **`<slot>`**: Tempat untuk proyeksi konten dari luar ke dalam shadow tree.
- **`<style>`** di shadow DOM tetap di-calc sekali — efisien untuk komponen yang sama banyak.
- Didukung oleh semua browser modern; digunakan di balik layar oleh framework seperti Angular (View Encapsulation).

---

### Contoh Implementasi

```javascript
class TooltipElement extends HTMLElement {
  constructor() {
    super();
    // Shadow DOM — mode open
    const shadow = this.attachShadow({ mode: 'open' });

    // Template dengan style terisolasi
    shadow.innerHTML = `
      <style>
        .tooltip-trigger {
          color: blue;
          cursor: pointer;
          border-bottom: 1px dotted blue;
        }
        .tooltip-box {
          display: none;
          position: absolute;
          background: #333;
          color: white;
          padding: 8px;
          border-radius: 4px;
          font-size: 14px;
        }
        :host { position: relative; display: inline-block; }
      </style>
      <span class="tooltip-trigger">
        <slot></slot>
      </span>
      <div class="tooltip-box">
        <slot name="tooltip-text">Info tambahan</slot>
      </div>
    `;

    this.trigger = shadow.querySelector('.tooltip-trigger');
    this.box = shadow.querySelector('.tooltip-box');

    this.trigger.addEventListener('mouseenter', () => { this.box.style.display = 'block'; });
    this.trigger.addEventListener('mouseleave', () => { this.box.style.display = 'none'; });
  }
}

customElements.define('my-tooltip', TooltipElement);
```

```html
<my-tooltip>
  Hover saya
  <span slot="tooltip-text">Ini adalah tooltip kustom!</span>
</my-tooltip>
```

---

### Koneksi

Berkaitan dengan **Web Components** (Shadow DOM + Custom Elements), **CSS Scoping** (alternatif CSS Modules atau styled-components), **Framework** (Vue scoped styles, Angular View Encapsulation), dan **Slot** (mirip dengan Vue slots atau React children).
