### Definisi Singkat

**Service Worker** adalah jenis **Web Worker** khusus yang bertindak sebagai **proxy jaringan** antara browser, jaringan, dan cache. Service Worker berjalan di background terpisah dari halaman web, memungkinkan **offline support**, **push notifications**, dan **background sync**. Ini adalah fondasi dari Progressive Web Apps (PWA).

---

### Analogi

Seperti **asisten pribadi** yang duduk di antara Anda dan kantor pos. Saat Anda minta surat (request), asisten mengecek apakah ia punya salinannya di lemari (cache). Jika ada, ia langsung memberikannya — tanpa perlu ke kantor pos (jaringan). Jika tidak ada, ia pergi ke kantor pos, mengambil surat, menyimpan salinannya, lalu memberikannya ke Anda.

---

### Poin-Poin Penting

- **Lifecycle**: Registered → Installing → Installed → Activating → Activated → Idle/Terminated.
- **HTTPS wajib** — Service Worker hanya berjalan di origin HTTPS (kecuali localhost).
- **Self-terminating**: Browser bisa menghentikan Service Worker jika tidak digunakan.
- **`install` event**: Ideal untuk **pre-cache** resource statis.
- **`activate` event**: Bersihkan cache lama.
- **`fetch` event**: Intercept request — serve dari cache atau jaringan.
- **`push` event**: Menerima push notification dari server.
- **`sync` event**: Background sync (sinkronisasi data saat koneksi kembali).
- **`caches` API**: Storage untuk cache responses.

### Contoh Implementasi

```javascript
// sw.js — Service Worker file
const CACHE_NAME = 'my-pwa-v1';
const URLS_TO_CACHE = ['/', '/index.html', '/styles.css', '/app.js'];

// Install — pre-cache resource statis
self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => {
      console.log('Cache terbuka');
      return cache.addAll(URLS_TO_CACHE);
    })
  );
});

// Activate — bersihkan cache lama
self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then((names) =>
      Promise.all(
        names
          .filter((name) => name !== CACHE_NAME)
          .map((name) => caches.delete(name))
      )
    )
  );
});

// Fetch — strategi: cache first, lalu jaringan
self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request).then((response) => {
      return response || fetch(event.request).then((res) => {
        return caches.open(CACHE_NAME).then((cache) => {
          cache.put(event.request, res.clone());
          return res;
        });
      });
    })
  );
});

// Daftarkan Service Worker di halaman utama
// if ('serviceWorker' in navigator) {
//   navigator.serviceWorker.register('/sw.js');
// }
```

### Koneksi

Berkaitan dengan **PWA** (Service Worker adalah syarat PWA), **Web Workers** (Service Worker adalah jenis worker khusus), **Caching** (Cache API), **HTTPS** (wajib), **Push API** (notifikasi), dan **Background Sync** (sinkronisasi offline).
