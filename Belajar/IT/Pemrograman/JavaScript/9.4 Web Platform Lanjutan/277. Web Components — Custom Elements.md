### Definisi Singkat

**Web Components** adalah kumpulan teknologi web standar untuk membuat komponen UI yang **reusable** dan **encapsulated**, tanpa framework. **Custom Elements** adalah bagian utamanya — memungkinkan Anda mendefinisikan elemen HTML kustom dengan API kelas JavaScript (melalui `customElements.define()`).

---

### Analogi

Seperti **stempel perangko khusus** — Anda membuat desain stempel sendiri (custom element), dan bisa mencapnya di mana saja di dokumen HTML. Setiap cap akan selalu tampak sama (reusable) dan tidak mengganggu tinta di sekitarnya (encapsulated).

---

### Poin-Poin Penting

- **`customElements.define('nama-elemen', MyClass)`** — daftarkan elemen baru. Nama harus mengandung **tanda hubung** (kebab-case).
- **Lifecycle callbacks**: `connectedCallback` (ditambahkan ke DOM), `disconnectedCallback`, `attributeChangedCallback`, `adoptedCallback`.
- **`observedAttributes`**: Daftar atribut yang dipantau perubahannya.
- Custom Element dapat memperluas elemen HTML native (`extends HTMLButtonElement`) — **customized built-in element** (dukungan terbatas).
- Kombinasikan dengan **Shadow DOM** untuk isolasi style dan markup.
- Tidak perlu framework — bekerja di semua browser modern secara native.

---

### Contoh Implementasi

```javascript
class UserCard extends HTMLElement {
  constructor() {
    super();
    this.innerHTML = `
      <div class="card">
        <h3 id="name"></h3>
        <p id="email"></p>
      </div>
    `;
  }

  // Atribut yang dipantau
  static get observedAttributes() {
    return ['name', 'email'];
  }

  // Dipanggil saat elemen ditambahkan ke DOM
  connectedCallback() {
    this.render();
  }

  // Dipanggil saat atribut berubah
  attributeChangedCallback(name, oldVal, newVal) {
    this.render();
  }

  render() {
    this.querySelector('#name').textContent = this.getAttribute('name') || 'Tanpa Nama';
    this.querySelector('#email').textContent = this.getAttribute('email') || '';
  }
}

// Daftarkan elemen
customElements.define('user-card', UserCard);
```

```html
<!-- Penggunaan di HTML -->
<user-card name="Budi Santoso" email="budi@example.com"></user-card>
```

---

### Koneksi

Berkaitan dengan **Shadow DOM** (isolasi style), **Service Workers** (komponen untuk PWA), **React/Vue/Angular** (alternatif/target compile Web Components), dan **Custom Elements** (fondasi Web Components).
