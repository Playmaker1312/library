### Definisi Singkat

**Progressive Web Apps (PWA)** adalah pendekatan pengembangan aplikasi web yang menggunakan teknologi web modern untuk memberikan **pengalaman seperti aplikasi native** — bisa diinstal di home screen, bekerja offline, mengirim notifikasi, dan mengakses hardware. PWA menggabungkan web (jangkauan luas) dengan native (kemampuan).

---

### Analogi

Seperti **sapi perah** — dari luar tampak seperti sapi biasa (website), tetapi ia bisa menghasilkan susu (fitur native) seperti dipasang di ponsel, notifikasi, dan bekerja tanpa internet. Anda tidak perlu memiliki peternakan (App Store) untuk menikmati susunya.

---

### Poin-Poin Penting

- **Tiga pilar PWA**: HTTPS, Service Worker, Web App Manifest.
- **Web App Manifest** (`manifest.json`): File JSON yang mendefinisikan nama, ikon, theme color, display mode (standalone/browser).
- **Installable**: Jika memenuhi kriteria (HTTPS, SW terdaftar, manifest valid), browser menampilkan prompt "Add to Home Screen".
- **Offline**: Service Worker menyajikan konten dari cache saat offline.
- **Push Notifications**: Kombinasi Service Worker + Push API.
- **Responsive**: PWA harus bekerja di semua ukuran layar.
- **App Shell**: Arsitektur memisahkan shell (UI) dan konten — shell di-cache, konten dimuat dinamis.
- Lab: Lighthouse Audits untuk menguji kualitas PWA.

### Contoh Implementasi

```json
// manifest.json
{
  "name": "Aplikasi Saya",
  "short_name": "AppSaya",
  "description": "Aplikasi web progresif keren",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#3f51b5",
  "icons": [
    { "src": "/icons/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/icons/icon-512.png", "sizes": "512x512", "type": "image/png" }
  ]
}
```

```html
<!-- Di index.html -->
<link rel="manifest" href="/manifest.json" />
<meta name="theme-color" content="#3f51b5" />
```

```javascript
// Daftarkan Service Worker
if ('serviceWorker' in navigator) {
  navigator.serviceWorker.register('/sw.js');
}

// Deteksi apakah sudah terinstall
window.addEventListener('beforeinstallprompt', (event) => {
  event.preventDefault();
  console.log('PWA bisa diinstall');
  // Tampilkan tombol install kustom
  installButton.style.display = 'block';
  installButton.onclick = () => event.prompt();
});
```

### Koneksi

Berkaitan dengan **Service Workers** (fondasi PWA), **HTTPS** (syarat mutlak), **Web App Manifest** (konfigurasi install), **Push Notifications**, **Cache API**, dan **Web Components** (arsitektur UI PWA).
