### Definisi Singkat

**Streams** adalah mekanisme Node.js untuk membaca/menulis data **sepotong demi sepotong** (chunk by chunk) daripada sekaligus. Ada empat tipe: **Readable** (sumber data), **Writable** (tujuan data), **Transform** (baca → proses → tulis), dan **Duplex** (baca dan tulis independen). Stream menggunakan **EventEmitter**.

---

### Analogi

Seperti **selang air** — Anda tidak perlu menyediakan kolam renang penuh untuk mulai minum. Air mengalir terus menerus melalui selang (stream), dan Anda bisa minum langsung dari ujung selang tanpa menunggu seluruh tangki terkuras.

---

### Poin-Poin Penting

- **Readable**: `data` event (flowing mode) atau `read()` (paused mode). Contoh: `fs.createReadStream`.
- **Writable**: `write(data)` dan `end()`. Contoh: `fs.createWriteStream`.
- **Transform**: Menerima input, memproses, dan menghasilkan output. Contoh: `zlib.createGzip`.
- **Duplex**: Baca dan tulis dua arah. Contoh: `net.Socket`.
- **Backpressure**: Jika Writable lebih lambat dari Readable, stream otomatis mengelola tekanan — gunakan `highWaterMark`.
- **`pipeline()`**: Cara modern untuk menghubungkan stream — error handling otomatis.
- **Keuntungan**: Memory efisien (tidak muat semua data di RAM), waktu lebih cepat (proses segera).

### Contoh Implementasi

```javascript
const fs = require('fs');
const zlib = require('zlib');
const { pipeline } = require('stream');
const { promisify } = require('util');

const pipelineAsync = promisify(pipeline);

// Membaca file besar dengan stream
const readStream = fs.createReadStream('file-besar.txt', { encoding: 'utf8' });
readStream.on('data', (chunk) => {
  console.log(`Menerima ${chunk.length} bytes`);
});
readStream.on('end', () => console.log('Selesai membaca'));

// Pipeline — baca → kompres → tulis (efisien)
async function compressFile(input, output) {
  try {
    await pipelineAsync(
      fs.createReadStream(input),
      zlib.createGzip(),
      fs.createWriteStream(output)
    );
    console.log('Kompresi selesai');
  } catch (err) {
    console.error('Pipeline gagal:', err);
  }
}

// Custom Transform stream — uppercase
const { Transform } = require('stream');
const uppercase = new Transform({
  transform(chunk, encoding, callback) {
    callback(null, chunk.toString().toUpperCase());
  }
});

fs.createReadStream('input.txt')
  .pipe(uppercase)
  .pipe(fs.createWriteStream('output.txt'));
```

### Koneksi

Berkaitan dengan **Buffer** (data mentah dari stream), **File System** (`createReadStream`), **EventEmitter** (stream extends EventEmitter), **Async Iterators** (`for await...of` dengan stream), dan **Performance** (memory efisien).
