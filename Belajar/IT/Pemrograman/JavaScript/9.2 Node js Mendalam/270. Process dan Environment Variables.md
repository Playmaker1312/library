### Definisi Singkat

**`process`** adalah global object di Node.js yang menyediakan informasi dan kontrol terhadap proses Node.js yang sedang berjalan. **Environment variables** (`process.env`) adalah pasangan key-value yang disediakan oleh sistem operasi atau file `.env` untuk konfigurasi aplikasi (port, API keys, mode development/production).

---

### Analogi

Seperti **dashboard navigasi pesawat** — pilot melihat kecepatan (process.memoryUsage), ketinggian (process.cwd), bahan bakar (process.env), dan bisa mematikan mesin (process.exit). Environment variables seperti **papan pengaturan** yang disetel oleh ground crew sebelum lepas landas.

---

### Poin-Poin Penting

- **`process.env`**: Objek berisi environment variables. `process.env.NODE_ENV` atau `process.env.PORT`.
- **`process.argv`**: Array argumen command line.
- **`process.cwd()`**: Current working directory.
- **`process.exit(code)`**: Menghentikan proses. 0 = sukses, 1 = error.
- **`process.nextTick()`**: Jadwalkan callback setelah operasi saat ini selesai (sebelum event loop).
- **`process.on('uncaughtException')`**: Tangani error yang tidak tertangkap.
- **Dotenv**: Library untuk membaca file `.env` ke dalam `process.env`.
- Jangan simpan secrets di kode — gunakan environment variables.

---

### Contoh Implementasi

```javascript
// Environment variables
const port = process.env.PORT || 3000;
const nodeEnv = process.env.NODE_ENV || 'development';

// .env file (dengan dotenv)
// require('dotenv').config();
// Isi .env: DB_HOST=localhost, DB_USER=admin

const dbConfig = {
  host: process.env.DB_HOST,
  user: process.env.DB_USER,
  password: process.env.DB_PASSWORD // Jangan hardcode!
};

// Process.argv — CLI arguments
// Jalankan: node app.js --name Budi
const args = process.argv.slice(2);
console.log(args); // ['--name', 'Budi']

// Process info
console.log({
  cwd: process.cwd(),
  pid: process.pid,
  uptime: process.uptime(),
  memory: process.memoryUsage(),
  platform: process.platform,
  version: process.version,
});

// Graceful shutdown
process.on('SIGTERM', () => {
  console.log('Menerima SIGTERM — cleanup...');
  server.close(() => process.exit(0));
});
```

---

### Koneksi

Berkaitan dengan **Node.js Architecture** (process adalah titik masuk), **HTTPS** (env untuk SSL config), **CI/CD** (env di pipeline), **npm scripts** (`process.env.npm_*`), dan **package.json** (scripts dan config field).
