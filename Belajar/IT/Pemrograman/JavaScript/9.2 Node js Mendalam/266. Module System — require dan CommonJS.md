### Definisi Singkat

**CommonJS** adalah sistem modul standar di Node.js. Setiap file dianggap sebagai **module** dengan **scope sendiri** — variabel tidak bocor ke global. Menggunakan `require()` untuk mengimpor dan `module.exports` / `exports` untuk mengekspor. Saat ini bersanding dengan **ES Modules** (`import`/`export`).

---

### Analogi

Seperti **perpustakaan dengan sistem katalog** — setiap buku (module) punya nomor rak sendiri (scope), dan Anda meminjam buku dengan menunjukkan kartu (require). Buku yang Anda pinjam adalah salinan (cached), jadi buku yang sama tidak perlu dipinjam ulang.

---

### Poin-Poin Penting

- **`require()`**: Synchronous — membaca file, mengeksekusi, mengembalikan `module.exports`.
- **Module caching**: Setelah di-require sekali, module di-cache (singleton).
- **`module.exports` vs `exports`**: `exports` adalah alias dari `module.exports`. Hati-hati: reassign `exports` memutuskannya.
- **`__dirname` dan `__filename`**: Path absolut file/module saat ini — hanya tersedia di CommonJS.
- **Package.json `"type": "module"`** mengaktifkan ES Modules. Untuk CommonJS di proyek ES Module, gunakan ekstensi `.cjs`.
- **Circular dependency**: Dapat terjadi, Node.js mengembalikan exports yang sudah dieksekusi sebagian.

---

### Contoh Implementasi

```javascript
// math.js — mengekspor
function add(a, b) { return a + b; }
function multiply(a, b) { return a * b; }

module.exports = { add, multiply };
// Atau: exports.add = add;

// app.js — mengimpor
const math = require('./math.js');
console.log(math.add(2, 3)); // 5

// const { multiply } = require('./math.js'); // Destructure

// Module caching — instance yang sama
const math2 = require('./math.js');
console.log(math === math2); // true — cached

// Circular dependency (hindari jika bisa)
// a.js: const b = require('./b');
// b.js: const a = require('./a'); // a belum selesai — hati-hati!
```

---

### Koneksi

Berkaitan dengan **Node.js Architecture** (bagaimana module diproses), **package.json** (konfigurasi module system), **ES Modules** (alternatif modern), dan **npm** (registry module).
