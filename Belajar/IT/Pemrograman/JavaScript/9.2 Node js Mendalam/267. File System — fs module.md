### Definisi Singkat

Modul **`fs`** (File System) di Node.js menyediakan API untuk berinteraksi dengan sistem file — membaca, menulis, menghapus, mengubah izin, dan memantau file. Tersedia dalam tiga varian: **synchronous** (blocking), **callback-based** (async), dan **Promise-based** (melalui `fs.promises`).

---

### Analogi

Seperti **meja kerja dengan laci arsip** — Anda bisa mengambil dokumen (read), menaruh dokumen baru (write), menggandakan (copy), membuang (unlink), atau mengawasi siapa yang membuka laci (watch). Tangan Anda hanya bisa melakukan satu hal dalam satu waktu (sync) atau bisa melakukan sambil lalu (async).

---

### Poin-Poin Penting

- **`fs.readFileSync`** — blocking, sederhana, cocok untuk startup/konfigurasi.
- **`fs.readFile`** — callback-based, non-blocking.
- **`fs.promises.readFile`** — Promise-based, paling modern dengan `async/await`.
- Path bisa absolut, relatif, atau URL (file://).
- Encoding: `'utf8'`, `'base64'`, `'hex'`, atau buffer (default).
- **Watch**: `fs.watch` / `fs.watchFile` untuk memantau perubahan file.
- **Stream**: Untuk file besar, gunakan `fs.createReadStream` / `fs.createWriteStream`.

---

### Contoh Implementasi

```javascript
const fs = require('fs');
const fsPromises = require('fs').promises;

// 1. Synchronous — blocking
try {
  const data = fs.readFileSync('config.json', 'utf8');
  console.log(JSON.parse(data));
} catch (err) {
  console.error(err);
}

// 2. Callback — non-blocking
fs.readFile('data.txt', 'utf8', (err, data) => {
  if (err) throw err;
  console.log(data);
});

// 3. Promise — async/await (rekomendasi)
async function readConfig() {
  try {
    const data = await fsPromises.readFile('config.json', 'utf8');
    return JSON.parse(data);
  } catch (err) {
    console.error('Gagal baca file:', err.message);
  }
}

// 4. Write file
await fsPromises.writeFile('output.txt', 'Hello, Node.js!', 'utf8');

// 5. Watch file
fs.watch('app.js', (eventType, filename) => {
  console.log(`File ${filename} berubah: ${eventType}`);
});
```

---

### Koneksi

Berkaitan dengan **Streams** (baca/tulis file besar), **Buffer** (data biner saat baca/tulis), **Process & Env** (`process.cwd()` untuk path), dan **Node.js Architecture** (I/O operations).
