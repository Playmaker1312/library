### Definisi Singkat

Jest adalah framework testing JavaScript yang dikembangkan oleh Facebook. Jest menyediakan **solusi all-in-one** untuk testing: test runner, assertion library, mocking, code coverage, dan snapshot testing, semuanya dalam satu paket tanpa konfigurasi rumit.

---

### Analogi

Seperti **toolkit mekanik lengkap** dalam satu kotak — Anda tidak perlu membeli kunci pas dari satu toko, obeng dari toko lain, dan alat ukur dari toko lain. Jest memberi Anda semua alat (test runner, matchers, mock, coverage) dalam satu paket terintegrasi.

---

### Poin-Poin Penting

- Zero config untuk project JavaScript — langsung jalan
- Test files: `*.test.js`, `*.spec.js`, atau folder `__tests__/`
- Perintah: `jest` atau `npm test` (jika dikonfigurasi)
- Fitur utama: assertions (expect), mocking (jest.fn), snapshot, coverage (--coverage)
- Mode watch: `jest --watch` — jalankan ulang test saat file berubah
- `jest --coverage` — menghasilkan laporan code coverage
- **Jest DOM** — matchers khusus untuk testing DOM (testing-library)
- Dukungan untuk TypeScript, React, Vue, dan framework lainnya

### Contoh Implementasi

```bash
npm install -D jest
```

```json
// package.json
{
  "scripts": {
    "test": "jest",
    "test:watch": "jest --watch",
    "test:coverage": "jest --coverage"
  }
}
```

```javascript
// math.js
function add(a, b) { return a + b; }
function multiply(a, b) { return a * b; }
function isEven(n) { return n % 2 === 0; }

module.exports = { add, multiply, isEven };

// math.test.js
const { add, multiply, isEven } = require('./math');

test('add menambahkan 1 + 2 sama dengan 3', () => {
  expect(add(1, 2)).toBe(3);
});

test('multiply mengalikan 2 * 3 sama dengan 6', () => {
  expect(multiply(2, 3)).toBe(6);
});

test('isEven mengembalikan true untuk angka genap', () => {
  expect(isEven(4)).toBe(true);
  expect(isEven(5)).toBe(false);
});

// Setup dan teardown
beforeEach(() => {
  console.log('Sebelum setiap test');
});

afterAll(() => {
  console.log('Setelah semua test selesai');
});
```
