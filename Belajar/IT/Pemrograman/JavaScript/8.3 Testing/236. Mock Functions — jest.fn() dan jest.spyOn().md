### Definisi Singkat

Mock Functions adalah fungsi tiruan yang digunakan dalam testing untuk **menggantikan dependensi nyata** — seperti fungsi API, database query, atau modul eksternal. Jest menyediakan `jest.fn()` untuk membuat mock function dan `jest.spyOn()` untuk memantau fungsi yang sudah ada.

---

### Analogi

Seperti **simulator penerbangan untuk pilot** — Anda tidak perlu menerbangkan pesawat sungguhan (API nyata) untuk berlatih. Simulator (mock) merespons seperti pesawat asli, tapi Anda bisa mengontrol situasi (turbulensi, mesin mati) dan merekam aksi pilot.

---

### Poin-Poin Penting

- `jest.fn(implementation)` — membuat mock function baru
- `jest.spyOn(obj, 'method')` — membungkus method yang sudah ada untuk dipantau
- Method mock: `mockReturnValue()`, `mockReturnValueOnce()`, `mockResolvedValue()`, `mockRejectedValue()`
- `mockImplementation(fn)` — memberikan implementasi kustom
- `toHaveBeenCalled()` — assertion apakah fungsi dipanggil
- `toHaveBeenCalledWith(arg1, arg2)` — assertion argumen
- `toHaveBeenCalledTimes(n)` — berapa kali dipanggil
- `mockClear()` — reset call history; `mockReset()` — reset + hapus implementasi
- Berguna untuk: HTTP requests, database, timer, modul eksternal

---

### Contoh Implementasi

```javascript
// Fungsi yang akan diuji
function processOrder(order, sendEmail, saveToDb) {
  const total = order.items.reduce((sum, item) => sum + item.price, 0);
  saveToDb({ ...order, total, status: 'processed' });
  sendEmail(order.email, `Pesanan diproses. Total: ${total}`);
  return total;
}

// Test dengan mock functions
test('processOrder memanggil callback yang benar', () => {
  const order = {
    email: 'budi@test.com',
    items: [{ name: 'Buku', price: 50000 }, { name: 'Pensil', price: 5000 }]
  };

  const mockSendEmail = jest.fn();
  const mockSaveToDb = jest.fn();

  const total = processOrder(order, mockSendEmail, mockSaveToDb);

  expect(total).toBe(55000);
  expect(mockSaveToDb).toHaveBeenCalledTimes(1);
  expect(mockSaveToDb).toHaveBeenCalledWith(
    expect.objectContaining({ total: 55000, status: 'processed' })
  );
  expect(mockSendEmail).toHaveBeenCalledWith(
    'budi@test.com',
    expect.stringContaining('55000')
  );
});

// jest.spyOn
const math = {
  add: (a, b) => a + b,
  multiply: (a, b) => a * b
};

test('spyOn memantau method yang sudah ada', () => {
  const addSpy = jest.spyOn(math, 'add');

  const result = math.add(2, 3);

  expect(result).toBe(5);
  expect(addSpy).toHaveBeenCalledWith(2, 3);
  expect(addSpy).toHaveBeenCalledTimes(1);

  addSpy.mockRestore(); // Kembalikan ke fungsi asli
});

// Mock return values
test('mock dengan return value', () => {
  const mockFn = jest.fn()
    .mockReturnValueOnce(10)
    .mockReturnValueOnce(20)
    .mockReturnValue(30);

  expect(mockFn()).toBe(10);
  expect(mockFn()).toBe(20);
  expect(mockFn()).toBe(30);
  expect(mockFn()).toBe(30); // Nilai default setelah once habis
});
```
