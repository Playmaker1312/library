### Definisi Singkat

TDD (Test-Driven Development) adalah metodologi pengembangan di mana **test ditulis sebelum kode implementasi**. Siklus TDD adalah **Red-Green-Refactor**: (1) tulis test yang gagal (Red), (2) buat kode minimal agar test lulus (Green), (3) perbaiki kode tanpa mengubah perilaku (Refactor).

---

### Analogi

Seperti **membangun rumah dengan cetak biru** — Anda tidak membangun dulu lalu mengukur. Anda ukur dan rencanakan (tulis test) dulu, baru bangun tembok (tulis kode) agar sesuai ukuran. Jika ada celah, Anda perbaiki tanpa mengubah ukuran pintu.

---

### Poin-Poin Penting

- **Red**: Tulis test yang menggambarkan perilaku yang diinginkan — test harus gagal karena fitur belum ada
- **Green**: Tulis kode paling sederhana untuk membuat test lulus (boleh asal comot)
- **Refactor**: Perbaiki kode — hapus duplikasi, perbaiki desain — pastikan test tetap hijau
- Keuntungan: kode lebih teruji, desain lebih baik, dokumentasi hidup, regression safety
- Aturan: jangan tulis kode produksi tanpa test yang gagal terlebih dahulu
- TDD bukan tentang testing, tapi tentang **desain** — test memandu desain API
- Coverage tinggi adalah efek samping, bukan tujuan utama

---

### Contoh Implementasi

```javascript
// === RED: Tulis test dulu ===
// Calculator.test.js
const Calculator = require('./Calculator');

describe('Calculator', () => {
  test('add(2, 3) mengembalikan 5', () => {
    const calc = new Calculator();
    expect(calc.add(2, 3)).toBe(5);
  });

  test('subtract(5, 3) mengembalikan 2', () => {
    const calc = new Calculator();
    expect(calc.subtract(5, 3)).toBe(2);
  });

  test('divide(10, 2) mengembalikan 5', () => {
    const calc = new Calculator();
    expect(calc.divide(10, 2)).toBe(5);
  });

  test('divide by zero throws error', () => {
    const calc = new Calculator();
    expect(() => calc.divide(10, 0)).toThrow('Tidak bisa dibagi nol');
  });
});

// === GREEN: Tulis kode minimal ===
// Calculator.js
class Calculator {
  add(a, b) { return a + b; }
  subtract(a, b) { return a - b; }
  divide(a, b) {
    if (b === 0) throw new Error('Tidak bisa dibagi nol');
    return a / b;
  }
}

module.exports = Calculator;

// === REFACTOR: Perbaiki tanpa mengubah test ===
// (Mungkin tambah validasi atau rapikan kode)
// Test tetap hijau setelah refactor
```
