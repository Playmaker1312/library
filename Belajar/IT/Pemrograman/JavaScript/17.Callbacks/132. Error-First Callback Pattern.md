### Definisi Singkat
Error-First Callback adalah konvensi di Node.js di mana parameter pertama dari callback selalu diperuntukkan bagi error (jika ada), dan parameter berikutnya untuk data hasil. Jika tidak ada error, nilai `null` atau `undefined` dikirim sebagai parameter pertama.

---

### Analogi
Kamu minta teman untuk mengambilkan buku di perpustakaan. Temanmu kembali dan berkata: "Maaf, bukunya dipinjam orang lain" **(error)** atau "Ini dia bukunya" **(data)**. Temanmu selalu menyampaikan status (gagal/berhasil) terlebih dahulu sebelum memberikan bukunya.

---

### Poin-Poin Penting
- Parameter pertama callback: `err` — berisi error object jika gagal, `null` jika sukses.
- Parameter kedua dst: `data` — hasil operasi jika sukses.
- Wajib **selalu cek `err`** sebelum mengakses data.
- Banyak API native Node.js menggunakan pola ini (fs, http, child_process, dll).
- Membantu memisahkan logika error dari logika sukses secara eksplisit.

---

### Contoh Implementasi

```javascript
const fs = require('fs');

// Error-First Callback pattern
fs.readFile('/path/file.txt', 'utf8', function (err, data) {
  if (err) {
    console.error('Terjadi error:', err.message);
    return;
  }
  console.log('Data file:', data);
});
```

Custom function dengan Error-First Callback:

```javascript
function bagi(a, b, callback) {
  if (b === 0) {
    callback(new Error('Pembagi tidak boleh nol'), null);
    return;
  }
  const hasil = a / b;
  callback(null, hasil);
}

bagi(10, 2, function (err, hasil) {
  if (err) {
    console.log('Error:', err.message);
    return;
  }
  console.log('Hasil:', hasil); // Hasil: 5
});

bagi(10, 0, function (err, hasil) {
  if (err) {
    console.log('Error:', err.message); // Error: Pembagi tidak boleh nol
    return;
  }
  console.log('Hasil:', hasil);
});
```

Contoh dengan Promisification (di Node.js):

```javascript
const fs = require('fs');
const fsPromises = fs.promises;

// Error-First Callback → Promise
fsPromises.readFile('/path/file.txt', 'utf8')
  .then(data => console.log(data))
  .catch(err => console.error(err.message));
```

---

### Koneksi
Error-First Callback adalah pola standar di Node.js yang menjadi motivasi utama dibuatnya **Promise** dan **util.promisify()**. Memahami pola ini penting saat bekerja dengan kode Node.js legacy atau native module yang belum menggunakan Promise.
