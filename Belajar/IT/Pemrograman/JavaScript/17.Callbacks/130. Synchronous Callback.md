### Definisi Singkat
Synchronous callback adalah callback yang dieksekusi secara langsung (seketika) di dalam higher-order function, tanpa menunggu operasi asynchronous. Callback jenis ini memblokir eksekusi hingga selesai.

---

### Analogi
Kamu memberikan instruksi detail ke asisten: "Untuk setiap buku di rak, ambil, lap debu, lalu kembalikan." Asisten mengerjakan satu per satu secara berurutan — buku pertama selesai baru buku kedua. Kamu harus menunggu sampai semua selesai.

---

### Poin-Poin Penting
- Synchronous callback berjalan di **call stack** yang sama, secara blocking.
- Contoh paling umum: metode array seperti `forEach`, `map`, `filter`, `reduce`, `sort`.
- Tidak melibatkan event loop atau task queue.
- Jika callback melempar error, fungsi induk ikut terhenti.

---

### Contoh Implementasi

```javascript
const numbers = [1, 2, 3, 4, 5];

// forEach — synchronous callback
numbers.forEach(function (num) {
  console.log(num * 2);
});
console.log('Selesai');
// Output: 2, 4, 6, 8, 10, "Selesai"

// map — synchronous callback
const doubled = numbers.map(function (num) {
  return num * 2;
});
console.log(doubled); // [2, 4, 6, 8, 10]

// filter
const evens = numbers.filter(function (num) {
  return num % 2 === 0;
});
console.log(evens); // [2, 4]

// sort dengan callback synchronous
const fruits = ['pepaya', 'apel', 'mangga'];
fruits.sort(function (a, b) {
  return a.localeCompare(b);
});
console.log(fruits); // ['apel', 'mangga', 'pepaya']
```

---

### Koneksi
Synchronous callback berbeda dari **asynchronous callback** yang memanfaatkan event loop. Pahami synchronous callback dulu sebelum belajar async callback, Promise, dan async/await.
