### Definisi Singkat
Strategi untuk mengatasi Callback Hell meliputi refactoring kode agar lebih rapi: memisahkan callback ke fungsi bernama (named functions), menggunakan modularisasi, dan yang paling penting — migrasi ke Promise atau async/await.

---

### Analogi
Darimu menulis seluruh prosedur ngurus KTP dalam satu paragraf panjang, kamu buat checklist terpisah untuk setiap langkah, tulis di kartu berbeda, lalu beri label urutan. Jauh lebih mudah dilacak dan diperbaiki jika ada yang salah.

---

### Poin-Poin Penting
- **Named functions** — ekstrak callback anonim ke fungsi bernama.
- **Modularisasi** — pisahkan logika ke file/modul terpisah.
- **Flatten structure** — kurangi nesting dengan early return.
- **Gunakan Promise** — ganti callback chaining dengan `.then()`.
- **Gunakan async/await** — solusi paling modern dan paling mudah dibaca.

---

### Contoh Implementasi

**1. Named Functions — memecah callback anonim menjadi fungsi bernama**

```javascript
function handlePayment(paymentId, callback) {
  sendReceipt(paymentId, callback);
}

function handleOrderDetails(details, callback) {
  processPayment(details.total, function (err, payment) {
    if (err) return callback(err);
    handlePayment(payment.id, callback);
  });
}

function handleOrders(orders, callback) {
  getOrderDetails(orders[0].id, function (err, details) {
    if (err) return callback(err);
    handleOrderDetails(details, callback);
  });
}

function handleUser(err, user) {
  if (err) return console.error(err);
  getOrders(user.id, handleOrders);
}

getUserData(handleUser);
```

**2. Early Return — mengurangi else bersarang**

```javascript
getUserData(function (err, user) {
  if (err) return console.error(err);
  getOrders(user.id, function (err, orders) {
    if (err) return console.error(err);
    getOrderDetails(orders[0].id, function (err, details) {
      if (err) return console.error(err);
      console.log(details);
    });
  });
});
```

**3. Modularisasi — pisahkan ke file terpisah**

```javascript
// userService.js
function getUser(callback) { /* ... */ }
function getOrders(userId, callback) { /* ... */ }
module.exports = { getUser, getOrders };
```

```javascript
// app.js
const userService = require('./userService');
userService.getUser(function (err, user) {
  if (err) return console.error(err);
  userService.getOrders(user.id, function (err, orders) {
    if (err) return console.error(err);
    console.log(orders);
  });
});
```

**4. Beralih ke Promise / async/await (solusi terbaik)**

```javascript
// Dengan Promise chaining
getUserData()
  .then(user => getOrders(user.id))
  .then(orders => getOrderDetails(orders[0].id))
  .then(details => processPayment(details.total))
  .then(payment => sendReceipt(payment.id))
  .then(receipt => console.log(receipt))
  .catch(err => console.error(err));
```

```javascript
// Dengan async/await
async function processOrder() {
  try {
    const user = await getUserData();
    const orders = await getOrders(user.id);
    const details = await getOrderDetails(orders[0].id);
    const payment = await processPayment(details.total);
    const receipt = await sendReceipt(payment.id);
    console.log(receipt);
  } catch (err) {
    console.error(err);
  }
}
```

---

### Koneksi
Strategi-strategi ini mengarah langsung ke topik **Promise** dan **async/await** sebagai solusi definitif untuk callback hell. Named functions dan modularisasi tetap berguna bahkan setelah migrasi ke Promise.
