### Definisi Singkat

**JIT (Just-In-Time) Compilation** adalah teknik di mana JavaScript engine mengkompilasi kode **saat runtime**, bukan sebelumnya (AOT) atau setelahnya (interpretasi murni). JIT menggabungkan kecepatan startup interpreter dengan performa tinggi compiled code, membuat JavaScript bisa berjalan mendekati kecepatan native.

---

### Analogi

Seperti **penerjemah simultan** yang mulai menerjemahkan secara langsung (interpreter) sambil mencatat frasa yang sering muncul. Setelah beberapa saat, ia menyiapkan **script siap pakai** (compiled code) untuk frasa-frasa tersebut sehingga terjemahan berikutnya instan.

---

### Poin-Poin Penting

- **Proses JIT di V8**: Source → Parser → AST → **Ignition (bytecode interpreter)** → Profiling → **TurboFan (optimizing compiler)** → Optimized machine code.
- **Warm vs Hot vs Hotter**: Engine melacak fungsi yang sering dipanggil (hot) untuk dikompilasi.
- **Optimistic assumptions**: Compiler membuat asumsi (misal: parameter selalu number). Jika asumsi salah → **deoptimization** (kembali ke bytecode).
- **Trade-off**: Compilation butuh waktu dan memori — engine hanya mengkompilasi fungsi "panas".
- **Hidden class & inline caching** adalah teknik JIT spesifik V8.

---

### Contoh Implementasi

```javascript
// Kode yang "panas" — sering dipanggil → akan di-JIT compile
function sum(arr) {
  let total = 0;
  for (let i = 0; i < arr.length; i++) {
    total += arr[i];
  }
  return total;
}

// Panggil berkali-kali → V8 akan mengoptimasi sum()
for (let i = 0; i < 10000; i++) {
  sum([1, 2, 3, 4, 5]);
}

// Deoptimization jika tipe berubah
function multiply(a, b) { return a * b; }

for (let i = 0; i < 1000; i++) multiply(2, 3); // Number → optimized
multiply('2', '3'); // String! → engine harus deoptimize
```

---

### Koneksi

Berkaitan dengan **V8 Engine architecture** (Ignition & TurboFan), **Hidden Classes & Inline Caching** (teknik optimasi JIT), **Performance Metrics** (JIT memengaruhi warm-up time), dan **WebAssembly** (punya pipeline kompilasi sendiri).
