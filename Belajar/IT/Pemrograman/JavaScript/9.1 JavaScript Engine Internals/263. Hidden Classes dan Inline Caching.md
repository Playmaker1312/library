### Definisi Singkat

**Hidden Classes** adalah mekanisme internal V8 untuk melacak struktur properti objek. **Inline Caching (IC)** adalah teknik JIT yang menyimpan informasi tipe objek di situs panggilan properti (property access site). Keduanya bekerja bersama untuk mempercepat akses properti objek — dari pencarian dictionary lambat menjadi akses offset langsung seperti C++ struct.

---

### Analogi

- **Hidden Class**: Seperti **kartu identitas** yang mencatat tata letak properti seseorang. Dua orang dengan tinggi dan berat badan punya kartu yang sama (shared hidden class).
- **Inline Caching**: Seperti **resepsionis yang hafal** lokasi kantor langganan. Begitu melihat wajah (tipe objek) yang dikenali, ia langsung menunjuk tanpa perlu bertanya.

---

### Poin-Poin Penting

- V8 membuat hidden class baru jika properti ditambahkan/dihapus secara dinamis.
- Hidden class di-share antar objek dengan struktur yang sama — menghemat memori.
- **Monomorphic** (1 tipe), **Polymorphic** (2-4 tipe), **Megamorphic** (5+ tipe) — semakin banyak varian, semakin lambat.
- **Inline cache** menyimpan: hidden class yang terlihat sebelumnya → offset properti.
- Cara menghindari deoptimasi: konsisten dengan tipe, inisialisasi semua properti di constructor.

---

### Contoh Implementasi

```javascript
// Optimal — hidden class sama
function Person(name, age) {
  this.name = name;
  this.age = age;
}
const p1 = new Person('Budi', 25); // Hidden Class HC1
const p2 = new Person('Siti', 30); // Hidden Class HC1 (sama)

// Suboptimal — properti ditambahkan kemudian
function Car(make) {
  this.make = make;
}
const c1 = new Car('Toyota');
c1.model = 'Avanza'; // Hidden class baru HCA yang berbeda dari HC1
const c2 = new Car('Honda');
// c2 tidak punya properti model → hidden class berbeda → polymorphic

// Inline caching example (engine internal, tidak terlihat langsung)
function getX(obj) {
  return obj.x; // Site panggilan — V8 akan cache hidden class obj
}

getX({ x: 1 }); // Monomorphic — cepat
getX({ x: 2 }); // Masih monomorphic
getX({ x: 3, y: 4 }); // Hidden class berbeda → polymorphic
```

---

### Koneksi

Berkaitan dengan **V8 Engine** (implementasi hidden class + IC), **JIT Compilation** (IC adalah bagian optimizing compiler), **Garbage Collection** (hidden class hidup bersama objek), dan **Performance** (praktik coding yang memengaruhi IC).
