### Definisi Singkat

Proxy adalah objek dalam JavaScript yang memungkinkan Anda membuat **perantara** untuk objek lain, dengan kemampuan mendefinisikan perilaku kustom untuk operasi dasar (seperti membaca properti, assignment, pemanggilan fungsi, dll) melalui **traps** (handler methods).

---

### Analogi

Seperti **resepsionis di kantor** — Anda tidak langsung menghubungi direktur. Anda bicara ke resepsionis (Proxy). Resepsionis bisa memfilter tamu, mencatat kunjungan, atau bahkan menolak akses — tanpa mengubah cara direktur bekerja.

---

### Poin-Poin Penting

- Proxy dibuat dengan `new Proxy(target, handler)`
- `handler` berisi traps seperti `get`, `set`, `has`, `deleteProperty`, `apply`, dll
- Proxy tidak mengubah objek asli (target) — ia membungkusnya
- Berguna untuk: validasi, logging, caching, lazy loading, access control
- Proxy bisa **revocable** (dicabut aksesnya) dengan `Proxy.revocable()`
- Ada 13 traps yang tersedia (get, set, has, deleteProperty, apply, construct, dll)

---

### Contoh Implementasi

```javascript
// Proxy untuk validasi properti
const user = {
  name: 'Budi',
  age: 25
};

const validatedUser = new Proxy(user, {
  set(target, property, value) {
    if (property === 'age' && typeof value !== 'number') {
      throw new TypeError('Age harus berupa angka');
    }
    if (property === 'name' && value.length < 2) {
      throw new Error('Nama minimal 2 karakter');
    }
    target[property] = value;
    return true;
  },
  get(target, property) {
    console.log(`Mengakses properti: ${property}`);
    return target[property];
  }
});

validatedUser.age = 30;          // OK
// validatedUser.age = 'tiga';   // TypeError
// validatedUser.name = 'A';     // Error
console.log(validatedUser.name); // Log: "Mengakses properti: name" → "Budi"
```

### Koneksi

Proxy sering digunakan bersama **Reflect API** (file 207) untuk meneruskan operasi default ke target. Juga berguna dalam konteks **Decorator Pattern** (file 231) dan reactive programming.
