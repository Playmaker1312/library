### Definisi Singkat

WeakMap dan WeakSet adalah varian dari Map dan Set yang menyimpan **referensi lemah (weak reference)** terhadap key-nya. Jika tidak ada referensi lain ke objek yang digunakan sebagai key, objek tersebut bisa dihapus oleh garbage collector, mencegah kebocoran memori.

---

### Analogi

Seperti **papan tempelan dengan perekat lemah** — Anda bisa menempelkan catatan (data) ke objek. Tapi jika objeknya dibuang, catatannya ikut hilang secara otomatis. Tidak seperti papan permanen (Map biasa) yang menahan objek tetap ada.

---

### Poin-Poin Penting

- **WeakMap**: key harus berupa objek (bukan primitif), value bisa apa saja
- **WeakSet**: hanya bisa menyimpan objek
- Tidak memiliki properti `size` atau method iterasi (`keys()`, `values()`, `entries()`, `forEach`)
- Tidak bisa di-loop (tidak iterable) — karena isi bisa berubah kapan saja akibat GC
- Method WeakMap: `get()`, `set()`, `has()`, `delete()`
- Method WeakSet: `add()`, `has()`, `delete()`
- Ideal untuk: metadata privat, cache, listener management, DOM node tracking

---

### Contoh Implementasi

```javascript
// WeakMap untuk data privat
const privateData = new WeakMap();

class User {
  constructor(name, age) {
    privateData.set(this, { name, age });
  }
  getName() {
    return privateData.get(this).name;
  }
  getAge() {
    return privateData.get(this).age;
  }
}

const user = new User('Budi', 25);
console.log(user.getName()); // "Budi"
// privateData.get(user) bisa diakses, tapi data tidak terlihat di enumerasi

// WeakSet untuk tracking objek
const processed = new WeakSet();

function processItem(item) {
  if (processed.has(item)) {
    console.log('Sudah diproses');
    return;
  }
  // Proses item...
  processed.add(item);
  console.log('Memproses item');
}

const obj1 = { id: 1 };
processItem(obj1); // "Memproses item"
processItem(obj1); // "Sudah diproses"

// Cache dengan WeakMap
const cache = new WeakMap();
function computeExpensive(obj) {
  if (cache.has(obj)) return cache.get(obj);
  const result = Object.keys(obj).length * 1000;
  cache.set(obj, result);
  return result;
}
```
