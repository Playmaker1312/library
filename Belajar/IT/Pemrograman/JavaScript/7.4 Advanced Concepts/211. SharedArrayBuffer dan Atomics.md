### Definisi Singkat

SharedArrayBuffer adalah buffer biner dengan ukuran tetap yang memungkinkan memori **dibagi antar thread** (Web Workers). Atomics adalah objek statis yang menyediakan operasi atomik (tidak bisa diinterupsi) untuk membaca dan menulis data di SharedArrayBuffer secara aman dalam lingkungan concurrent.

---

### Analogi

Seperti **papan tulis bersama di ruang rapat** — beberapa orang (thread) bisa membaca dan menulis di papan yang sama. Tapi tanpa aturan, bisa terjadi kekacauan. Atomics adalah **protocol "giliran"** — hanya satu orang yang boleh menulis pada satu waktu agar tidak saling timpa.

---

### Poin-Poin Penting

- SharedArrayBuffer dibuat dengan `new SharedArrayBuffer(sizeInBytes)`
- Data diakses melalui `Int32Array`, `Uint8Array`, dll (TypedArray views)
- Atomics menyediakan: `Atomics.add()`, `Atomics.sub()`, `Atomics.load()`, `Atomics.store()`, `Atomics.exchange()`, `Atomics.compareExchange()`
- `Atomics.wait()` dan `Atomics.notify()` untuk sinkronisasi antar thread (futex-like)
- Operasi atomik menjamin tidak ada race condition pada operasi baca/tulis
- Membutuhkan header `Cross-Origin-Opener-Policy` dan `Cross-Origin-Embedder-Policy` di lingkungan web tertentu
- Tidak tersedia di semua environment (misal: tidak di Node.js lama tanpa flag)

### Contoh Implementasi

```javascript
// Main thread
const buffer = new SharedArrayBuffer(16); // 16 bytes
const int32 = new Int32Array(buffer);

// Worker thread (file: worker.js)
// self.onmessage = () => {
//   Atomics.store(int32, 0, 42);
//   Atomics.notify(int32, 0, 1);
// };

// Main thread
int32[0] = 0;
const worker = new Worker('worker.js');
worker.postMessage(buffer);

// Menunggu perubahan dari worker
// const result = Atomics.wait(int32, 0, 0);
// console.log(int32[0]); // 42

// Operasi atomik dasar
const sab = new SharedArrayBuffer(4);
const view = new Int32Array(sab);

// Store dan load atomik
Atomics.store(view, 0, 100);
console.log(Atomics.load(view, 0)); // 100

// Add atomik
Atomics.add(view, 0, 5);
console.log(Atomics.load(view, 0)); // 105

// Exchange atomik
const old = Atomics.exchange(view, 0, 200);
console.log(old); // 105
console.log(Atomics.load(view, 0)); // 200
```

---

### Koneksi

Topik ini adalah kelanjutan dari **Web Workers** (folder 24/Browser APIs). SharedArrayBuffer memungkinkan performa tinggi untuk aplikasi multi-thread seperti game engine, video processing, atau WebAssembly.
