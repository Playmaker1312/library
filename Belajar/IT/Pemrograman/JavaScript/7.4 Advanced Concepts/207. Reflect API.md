### Definisi Singkat

Reflect API adalah objek bawaan JavaScript yang menyediakan method-method untuk operasi metaprogramming yang dapat diintercept. Method Reflect memiliki signature yang sama dengan Proxy traps dan digunakan sebagai **default forwarding** dalam handler Proxy.

---

### Analogi

Seperti **salinan kunci cadangan** — Anda tidak perlu merusak pintu untuk membukanya. Cukup gunakan salinan yang tepat (Reflect) yang menjalankan operasi bawaan tanpa mengubah perilaku asli objek.

---

### Poin-Poin Penting

- Reflect bukan constructor — semua method bersifat statis (`Reflect.get()`, `Reflect.set()`, dll)
- Memiliki method yang sesuai dengan setiap Proxy trap
- `Reflect.get(target, property, receiver)` — alternatif `target[property]`
- `Reflect.set(target, property, value, receiver)` — alternatif `target[property] = value`
- `Reflect.has(target, property)` — alternatif `property in target`
- `Reflect.deleteProperty(target, property)` — alternatif `delete target[property]`
- `Reflect.ownKeys(target)` — mengembalikan semua kunci milik objek
- Memberikan return value yang konsisten (Boolean untuk set, delete)

---

### Contoh Implementasi

```javascript
const obj = { a: 1, b: 2 };

// Membaca properti
console.log(Reflect.get(obj, 'a')); // 1

// Menulis properti
Reflect.set(obj, 'c', 3);
console.log(obj.c); // 3

// Cek keberadaan
console.log(Reflect.has(obj, 'b')); // true

// Hapus properti
Reflect.deleteProperty(obj, 'a');
console.log('a' in obj); // false

// Menggunakan Reflect dalam Proxy
const handler = {
  get(target, property, receiver) {
    console.log(`Get: ${property}`);
    return Reflect.get(target, property, receiver);
  },
  set(target, property, value, receiver) {
    console.log(`Set: ${property} = ${value}`);
    return Reflect.set(target, property, value, receiver);
  }
};

const proxy = new Proxy(obj, handler);
proxy.b = 20; // Log: "Set: b = 20"
```

---

### Koneksi

Reflect API adalah pasangan alami dari **Proxy** (file 206). Setiap trap di Proxy memiliki method Reflect yang sesuai. Juga digunakan dalam metaprogramming bersama **Symbol** (file 208).
