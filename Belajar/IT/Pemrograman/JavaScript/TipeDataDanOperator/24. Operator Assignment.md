### Definisi Singkat

_Assignment operators_ (operator penugasan) adalah simbol yang digunakan untuk memberikan atau menetapkan nilai ke dalam sebuah variabel di dalam JavaScript.

---

### Analogi

Bayangkan Anda sedang mengisi bahan bakar mobil di SPBU:

- Tanda sama dengan (`=`) adalah **selang pompa bahan bakar yang dimasukkan ke dalam tangki**; apa yang ada di selang (nilai di sebelah kanan) akan dimasukkan dan disimpan di dalam tangki (variabel di sebelah kiri).
    
- Operator gabungan seperti `+=` seperti **menambahkan jumlah bahan bakar** yang sudah ada di dalam tangki dengan jumlah yang baru, tanpa harus mengosongkannya terlebih dahulu.
    

---

### Poin-Poin Penting

- **Operator Penugasan Dasar:**
    
    - **`=` (Assignment):** Menetapkan nilai dari operand kanan ke operand kiri. Contoh: `let x = 10;`.
        
- **Operator Penugasan Gabungan (Compound Assignment):**
    
    - **`+=` (Addition Assignment):** Menambahkan nilai kanan ke variabel, lalu menyimpannya kembali. Ekivalen dengan: `x = x + y;`.
        
    - **`-=` (Subtraction Assignment):** Mengurangi nilai kanan dari variabel, lalu menyimpannya kembali. Ekivalen dengan: `x = x - y;`.
        
    - **`*=` (Multiplication Assignment):** Mengalikan variabel dengan nilai kanan. Ekivalen dengan: `x = x * y;`.
        
    - **`/=` (Division Assignment):** Membagi variabel dengan nilai kanan. Ekivalen dengan: `x = x / y;`.
        
    - **`%=` (Remainder/Modulo Assignment):** Menyimpan sisa bagi dari operasi variabel dengan nilai kanan. Ekivalen dengan: `x = x % y;`.
        
- **Keuntungan:** Membuat penulisan kode menjadi lebih ringkas dan bersih (_clean code_).
    

---

### Contoh Implementasi

Berikut adalah contoh penggunaan operator penugasan di dalam JavaScript:

JavaScript

```
// 1. Assignment Dasar
let totalBelanja = 50000;
console.log(totalBelanja); // Output: 50000

// 2. Addition Assignment (+=)
let skor = 10;
skor += 5; // Sama dengan: skor = skor + 5;
console.log(skor); // Output: 15

// 3. Multiplication Assignment (*=)
let hargaSatuan = 5000;
hargaSatuan *= 2; // Sama dengan: hargaSatuan = hargaSatuan * 2;
console.log(hargaSatuan); // Output: 10000

// 4. Modulo Assignment (%=)
let sisa = 20;
sisa %= 6; // Sama dengan: sisa = 20 % 6; (Sisa bagi dari 20 dibagi 6 adalah 2)
console.log(sisa); // Output: 2
```

### Koneksi

Dalam bidang **Web Development**, operator _assignment_ digunakan secara intensif setiap kali Anda memperbarui status data atau menangani antarmuka pengguna:

- **Penghitungan Otomatis:** Memperbarui nilai keranjang belanja pengguna saat mereka menambahkan jumlah kuantiti suatu barang di _E-commerce_.
    
- **Manajemen State (_State Management_):** Menggunakan operator gabungan untuk menaikkan nilai penghitung (_counter_), seperti saat pengguna memberikan _like_ pada postingan media sosial.
