### Definisi Singkat

Operator _Ternary_ adalah satu-satunya operator di dalam JavaScript yang memerlukan tiga operan: kondisi, hasil jika kondisi benar, dan hasil jika kondisi salah. Operator ini digunakan sebagai bentuk ringkas dari pernyataan `if-else`.

---

### Analogi

Bayangkan seperti **papan harga otomatis di gerbang tol otomatis**:

- **Kondisi:** "Apakah saldo e-Toll Anda mencukupi?"
    
- **Tanda tanya (`?`):** Jika **Ya**, palang pintu terbuka dan Anda diizinkan lewat (_Value 1_).
    
- **Titik dua (`:`):** Jika **Tidak**, lampu merah menyala dan Anda diminta mengisi ulang (_Value 2_).
    

---

### Poin-Poin Penting

- **Sintaks Dasar:**
    
    $$\text{kondisi } ? \text{ nilai\_jika\_benar} : \text{ nilai\_jika\_salah};$$
    
- **Alternatif Ringkas:** Mengubah baris kode `if-else` yang panjang menjadi hanya satu baris, sehingga lebih bersih (_clean code_).
    
- **Return Value:** Operator ini mengembalikan nilai, sehingga dapat langsung disimpan di dalam variabel atau dimasukkan ke dalam parameter fungsi.
    
- **Penggunaan Bersarang (_Nested Ternary_):** Anda dapat menggabungkan beberapa _ternary_ sekaligus, namun tidak disarankan terlalu sering karena membuat kode sulit dibaca.
    

---

### Contoh Implementasi

Berikut adalah perbandingan penggunaan `if-else` tradisional dengan operator _ternary_:

#### 1. Menggunakan `if-else` Tradisional:

JavaScript

```
let nilai = 75;
let statusKelulusan;

if (nilai >= 75) {
    statusKelulusan = "Lulus";
} else {
    statusKelulusan = "Tidak Lulus";
}

console.log(statusKelulusan); // Output: Lulus
```

#### 2. Menggunakan Operator Ternary:

JavaScript

```
let nilai = 75;

// Kondisi ? Benar : Salah
let statusKelulusan = nilai >= 75 ? "Lulus" : "Tidak Lulus";

console.log(statusKelulusan); // Output: Lulus
```

#### Contoh lain: Menampilkan teks sapaan berdasarkan jenis kelamin

JavaScript

```
let jenisKelamin = "L";
let sapaan = jenisKelamin === "L" ? "Halo, Tuan!" : "Halo, Nyonya!";
console.log(sapaan); // Output: Halo, Tuan!
```

### Koneksi

Dalam bidang **Web Development**, operator _ternary_ sangat sering digunakan saat merancang antarmuka pengguna:

- **Conditional Rendering (seperti pada React atau Vue.js):** Menampilkan komponen atau teks tertentu berdasarkan status seperti $loading$, $success$, atau $error$.
    
- **Pengubahan Kelas CSS Dinamis:** Menerapkan kelas CSS yang berbeda (misalnya warna hijau untuk tombol aktif dan abu-abu untuk tombol nonaktif).
