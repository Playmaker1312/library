### Definisi Singkat

_Optional Chaining Operator_ (dilambangkan dengan tanda tanya dan titik `?.`) adalah operator di dalam JavaScript yang memungkinkan Anda untuk membaca nilai dari properti yang berada jauh di dalam rantai objek, tanpa harus memvalidasi atau memastikan terlebih dahulu apakah setiap referensi di dalam rantai tersebut ada atau tidak.

---

### Analogi

Bayangkan seperti **membuka kunci pintu pada satu set pintu yang saling terhubung di dalam gedung bertingkat**:

- Tanpa _Optional Chaining_, jika Anda mencoba membuka pintu ke-3 tetapi pintu ke-2 terkunci (atau tidak ada), Anda akan menabraknya dan program Anda _error_.
    
- Dengan _Optional Chaining_, jika Anda sampai di pintu ke-2 dan pintunya terkunci atau tidak ada, sistem akan langsung berhenti dan memberi tahu Anda bahwa jalurnya tidak tersedia (mengembalikan nilai `undefined`), tanpa membuat program menjadi _crash_ (rusak).
    

---

### Poin-Poin Penting

- **Sintaks Dasar:**
    
    $$\text{objek}?.(\text{propertiYangDicari})$$
    
- **Fungsi Utama:** Mencegah terjadinya _TypeError_ yang biasa terjadi ketika kita mencoba mengakses properti dari nilai `null` atau `undefined`.
    
- **Menghentikan Eksekusi (_Short-Circuiting_):** Jika referensi di sisi kiri `?.` bernilai `null` atau `undefined`, JavaScript akan langsung menghentikan evaluasi dan mengembalikan `undefined` tanpa melanjutkan ke properti berikutnya.
    
- **Kompatibilitas Penggunaan:** Dapat digunakan bersama dengan pemanggilan fungsi (_function calls_) `fungsi?.()` atau untuk mengakses elemen _array_ `array?.[0]`.
    

---

### Contoh Implementasi

Berikut adalah contoh perbandingan tanpa dan dengan menggunakan _Optional Chaining_:

#### 1. Masalah Tanpa Optional Chaining (Menyebabkan Error):

Misalkan Anda memiliki objek dengan data pengguna, tetapi data alamat tidak selalu tersedia di setiap pengguna:

JavaScript

```
const pengguna = {
    nama: "Budi",
    usia: 25
    // Properti 'alamat' tidak ada di sini
};

// Mencoba mengakses properti yang lebih dalam:
try {
    console.log(pengguna.alamat.jalan);
} catch (error) {
    console.error(error.message); 
    // Output: Cannot read properties of undefined (reading 'jalan')
}
```

#### 2. Menggunakan Optional Chaining (Aman dari Error):

Dengan menggunakan `?.`, program tidak akan _crash_ melainkan mengembalikan nilai `undefined`.

JavaScript

```
const penggunaLain = {
    nama: "Siti",
    usia: 22
};

// Menggunakan optional chaining
console.log(penggunaLain.alamat?.jalan); // Output: undefined
```

#### 3. Optional Chaining pada Pemanggilan Function:

Anda juga dapat memastikan apakah sebuah fungsi ada sebelum mengeksekusinya:

JavaScript

```
const penggunaDenganFungsi = {
    nama: "Joko",
    sapa: function() { return "Halo!"; }
};

const penggunaTanpaFungsi = {
    nama: "Andi"
};

console.log(penggunaDenganFungsi.sapa?.()); // Output: Halo!
console.log(penggunaTanpaFungsi.sapa?.()); // Output: undefined (tidak terjadi error)
```

---

### Koneksi

Dalam bidang **Web Development**, _Optional Chaining_ sangat penting untuk menangani data yang tidak pasti atau bersarang (seperti respons JSON dari API):

- **Mengambil Data dari API yang Kompleks:** Saat mengambil data pengguna yang strukturnya bisa saja berubah-ubah atau tidak memiliki data lengkap, operator ini mencegah situs web Anda rusak (_crash_).
    
- **Mengakses Data Bersarang:** Memudahkan penulisan kode pada saat merender data dalam jumlah banyak (_mapping_) tanpa harus membuat pengecekan bersarang menggunakan `if-else` yang terlalu panjang.
