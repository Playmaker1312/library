### Definisi Singkat

`typeof` adalah operator bawaan di JavaScript yang digunakan untuk memeriksa dan mengembalikan string yang menunjukkan tipe data dari suatu nilai atau variabel.

---

### Analogi

Bayangkan seperti **alat pemindai harga atau _barcode scanner_ di kasir**:

- Barang (variabel atau nilai) dilewatkan pada pemindai.
    
- Alat tersebut akan mengeluarkan bunyi dan memberikan informasi (seperti "Ini adalah baju" atau "Ini adalah sepatu") tanpa merusak barang tersebut. Operator `typeof` melakukan hal yang sama dengan membaca variabel dan memberi tahu Anda tipe datanya.
    

---

### Poin-Poin Penting

- **Sintaks Penggunaan:** Dapat digunakan dengan tanda kurung `typeof(variabel)` atau tanpa tanda kurung `typeof variabel`.
    
- **Nilai Kembalian (Return Values):**
    
    - `"string"` untuk teks.
        
    - `"number"` untuk angka (termasuk NaN dan Infinity).
        
    - `"boolean"` untuk true/false.
        
    - `"undefined"` untuk variabel yang belum didefinisikan.
        
    - `"object"` untuk objek, array, dan `null`.
        
    - `"function"` untuk fungsi.
        
- **_Quirk_ (Keunikan) JavaScript:**
    
    - `typeof null` mengembalikan nilai `"object"`. Ini adalah kesalahan sejarah (_bug_) di JavaScript sejak awal pembuatannya yang dipertahankan demi kompatibilitas balik.
        

---

### Contoh Implementasi

Berikut adalah contoh penggunaan operator `typeof` dalam berbagai tipe data:

JavaScript

```
// 1. Mengecek tipe data dasar
let nama = "Budi";
console.log(typeof nama); // Output: string

let usia = 25;
console.log(typeof usia); // Output: number

let isAktif = true;
console.log(typeof isAktif); // Output: boolean

// 2. Mengecek tipe data referensi
let dataKosong = null;
console.log(typeof dataKosong); // Output: object (Ini adalah bug historis)

let dataTidakDidefinisikan;
console.log(typeof dataTidakDidefinisikan); // Output: undefined

// 3. Mengecek tipe data yang lebih kompleks
let daftarNilai = [85, 90, 78];
console.log(typeof daftarNilai); // Output: object (Array juga merupakan objek di JS)

let profilPengguna = { nama: "Siti", usia: 22 };
console.log(typeof profilPengguna); // Output: object

function sapa() {
    return "Halo!";
}
console.log(typeof sapa); // Output: function
```

---

### Koneksi

Dalam bidang **Web Development**, `typeof` sangat penting untuk:

- **Validasi Data:** Memastikan data yang diterima dari formulir (_input_ pengguna) atau API sudah sesuai tipe datanya sebelum diproses lebih lanjut oleh program.
    
- **Pencegahan Error:** Memeriksa apakah suatu variabel sudah memiliki nilai atau bertipe data tertentu sebelum memanggil _method_ (misalnya memastikan suatu variabel adalah _array_ sebelum melakukan perulangan).
