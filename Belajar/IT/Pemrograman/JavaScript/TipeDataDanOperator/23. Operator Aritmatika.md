
### Definisi Singkat

Operator aritmatika adalah simbol-simbol khusus di dalam JavaScript yang digunakan untuk melakukan operasi matematika dasar pada satu atau lebih nilai (angka).

---

### Analogi

Bayangkan seperti **tombol dan fungsi pada kalkulator fisik** yang ada di atas meja Anda:

- Tombol tambah (`+`), kurang (`-`), kali (`*`), dan bagi (`/`) digunakan untuk menghitung kuantitas atau nilai dari barang belanjaan.
    
- Operator sisa bagi (`%` / _modulo_) seperti menghitung sisa barang yang tidak muat di dalam satu kotak penyimpanan setelah dibagi rata.
    

---

### Poin-Poin Penting

- **Daftar Operator Aritmatika:**
    
    - **Penjumlahan (`+`):** Menambahkan dua nilai.
        
    - **Pengurangan (`-`):** Mengurangkan nilai pertama dengan nilai kedua.
        
    - **Perkalian (`*`):** Mengalikan dua nilai.
        
    - **Pembagian (`/`):** Membagi nilai pertama dengan nilai kedua.
        
    - **Sisa Bagi / Modulo (`%`):** Mengembalikan sisa dari pembagian bilangan bulat.
        
    - **Eksponensial ():** Memangkatkan suatu bilangan (diperkenalkan pada ES6).
        
    - **Increment (`++`):** Menambahkan nilai variabel sebesar 1.
        
    - **Decrement (`--`):** Mengurangi nilai variabel sebesar 1.
        
- **Urutan Operasi (Precedence):** Mengikuti aturan matematika standar (_PEMDAS/BODMAS_), di mana perkalian dan pembagian didahulukan daripada penjumlahan dan pengurangan, kecuali jika dibatasi dengan tanda kurung `()`.

### Contoh Implementasi

Berikut adalah contoh penggunaan berbagai operator aritmatika di dalam JavaScript:

JavaScript

```
// 1. Operasi Dasar
let panjang = 10;
let lebar = 5;

let luasPersegiPanjang = panjang * lebar; // Perkalian
console.log(luasPersegiPanjang); // Output: 50

let sisaBagi = 17 % 5; // Modulo (Sisa bagi dari 17 dibagi 5)
console.log(sisaBagi); // Output: 2

// 2. Eksponensial (Pemangkatan)
let pangkat = 2 ** 3; // 2 pangkat 3
console.log(pangkat); // Output: 8

// 3. Increment & Decrement
let angka = 5;
angka++; // Menambahkan 1 ke variabel angka
console.log(angka); // Output: 6

angka--; // Mengurangi 1 dari variabel angka
console.log(angka); // Output: 5
```

### Koneksi

Dalam bidang **Web Development**, operator aritmatika sangat penting untuk mengelola logika bisnis dan antarmuka pengguna:

- **Kalkulasi Harga:** Menghitung total belanjaan, pajak, dan diskon pada aplikasi _E-commerce_.
    
- **Penomoran Halaman (_Pagination_):** Menggunakan operator modulo (`%`) untuk menentukan warna baris tabel yang selang-seling (baris genap dan ganjil).
    
- **Animasi & Posisi:** Menghitung koordinat piksel dan durasi waktu pada saat membuat animasi di browser.
