### Definisi Singkat

Selain tipe data yang telah dibahas sebelumnya, JavaScript memperkenalkan dua tipe data primitif tambahan, yaitu **`Symbol`** untuk membuat pengidentifikasi yang unik dan tidak dapat diubah, serta **`BigInt`** untuk merepresentasikan angka yang jauh lebih besar daripada batas maksimum tipe data _Number_ biasa.

---

### Analogi

Bayangkan perbedaan ini seperti **nomor seri pengaman dan kapasitas hitung pada dua kalkulator berbeda**:

- **`Symbol`** seperti **cap sidik jari atau hologram keamanan** pada dokumen penting: meskipun terlihat mirip atau memiliki nama yang sama dengan yang lain, setiap cap tersebut bersifat unik dan tidak akan pernah sama.
    
- **`BigInt`** seperti **kalkulator super canggih** yang mampu menghitung triliunan angka tanpa mengalami _error_ atau kehabisan memori, dibandingkan dengan kalkulator biasa yang batas layarnya mentok (_overflow_).
    

---

### Poin-Poin Penting

- **`Symbol`:**
    
    - Diperkenalkan pada ECMAScript 2015 (ES6).
        
    - Digunakan untuk membuat nilai yang unik dan dijamin tidak akan pernah bentrok dengan properti lain di dalam objek.
        
    - Sering digunakan untuk membuat properti objek yang bersifat tersembunyi (_hidden properties_).
        
- **`BigInt`:**
    
    - Diperkenalkan pada ECMAScript 2020.
        
    - Digunakan untuk menangani angka integer di luar batas aman maksimal `Number.MAX_SAFE_INTEGER` ($2^{53} - 1$).
        
    - Ditandai dengan menambahkan huruf `n` di akhir angka (contoh: `123456789012345678901234567890n`).
        

---

### Contoh Implementasi

Berikut adalah contoh penggunaan `Symbol` dan `BigInt` di dalam kode JavaScript:

JavaScript

```
// 1. Penggunaan Symbol
const ID1 = Symbol("id");
const ID2 = Symbol("id");

console.log(ID1 === ID2); // Output: false (karena Symbol selalu unik)

// Menggunakan Symbol sebagai properti objek yang unik
const pengguna = {
    nama: "Budi",
    [ID1]: 12345
};
console.log(pengguna[ID1]); // Output: 12345


// 2. Penggunaan BigInt
const angkaBiasa = Number.MAX_SAFE_INTEGER;
console.log(angkaBiasa + 1); // Terkadang menghasilkan pembulatan yang kurang akurat

const angkaBesar = 123456789012345678901234567890n;
console.log(angkaBesar); // Output: 123456789012345678901234567890n
```

### Koneksi

Dalam bidang **Web Development**, pemahaman tentang `Symbol` dan `BigInt` berguna untuk:

- **Pengembangan Lanjut (Advanced JavaScript):** Membantu _developer_ dalam membuat pustaka (_library_) atau _plugin_ yang propertinya tidak bisa diakses atau ditimpa secara tidak sengaja oleh kode dari luar.
    
- **Aplikasi Finansial atau Sains:** Menggunakan `BigInt` saat berhadapan dengan transaksi bernominal sangat besar atau perhitungan sistem blockchain yang membutuhkan tingkat presisi angka yang sangat tinggi tanpa kehilangan data.
