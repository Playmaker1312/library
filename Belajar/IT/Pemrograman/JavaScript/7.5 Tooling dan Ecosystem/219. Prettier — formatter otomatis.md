### Definisi Singkat

Prettier adalah **opinionated code formatter** yang secara otomatis memformat kode JavaScript, TypeScript, CSS, HTML, JSON, Markdown, dan banyak bahasa lainnya. Prettier menghilangkan perdebatan tentang style kode dengan menerapkan format yang konsisten secara otomatis.

---

### Analogi

Seperti **mesin pelurus rambut** — tidak peduli bagaimana kondisi rambut Anda setelah keramas (kode setelah ditulis), Prettier akan merapikannya dengan aturan yang ketat dan konsisten. Semua orang di tim akan memiliki rambut (kode) yang sama rapi.

---

### Poin-Poin Penting

- Opinionated: hanya sedikit opsi konfigurasi — mengurangi bike-shedding
- Mendukung JS, TS, JSX, TSX, CSS, SCSS, Less, HTML, JSON, Markdown, YAML, GraphQL
- Konfigurasi di file `.prettierrc` atau di `package.json` (prettier key)
- Opsi utama: `semi`, `singleQuote`, `tabWidth`, `trailingComma`, `printWidth`, `bracketSpacing`
- Integrasi dengan editor (format on save) dan pre-commit hooks
- Bisa digabung dengan ESLint via `eslint-config-prettier` (mematikan aturan ESLint yang konflik)
- `--check` — memeriksa format tanpa mengubah file (untuk CI)
- `--write` — memformat dan menimpa file

---

### Contoh Implementasi

```bash
npm install -D prettier
```

```json
// .prettierrc
{
  "semi": true,
  "singleQuote": true,
  "tabWidth": 2,
  "trailingComma": "es5",
  "printWidth": 80,
  "bracketSpacing": true,
  "arrowParens": "always",
  "endOfLine": "lf"
}
```

```javascript
// Sebelum Prettier — format berantakan
const   foo   =    "hello";
const   bar={a:1,b:2,
c:3};
function    greet(name){return   "Halo, "+name+"!";}

// Sesudah Prettier — rapi dan konsisten
const foo = 'hello';
const bar = { a: 1, b: 2, c: 3 };
function greet(name) {
  return 'Halo, ' + name + '!';
}
```

```bash
# Format semua file di folder src
npx prettier --write src/

# Check format (untuk CI)
npx prettier --check src/
```
