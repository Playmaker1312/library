### Definisi Singkat

Babel adalah transpiler JavaScript yang mengubah kode JavaScript modern (ES6+/ES2015+) ke versi yang kompatibel dengan browser atau environment lama. Babel memungkinkan developer menggunakan fitur JavaScript terbaru tanpa menunggu semua browser mendukungnya.

---

### Analogi

Seperti **penerjemah bahasa** — Anda menulis dalam bahasa Inggris modern (ES6+), dan Babel menerjemahkannya ke bahasa Inggris kuno yang dimengerti oleh kakek-nenek (ES5). Anda bisa bicara dengan kosakata modern, dan tetap dipahami oleh semua orang.

---

### Poin-Poin Penting

- Babel bekerja dalam 3 fase: **Parsing → Transform → Generation**
- **Presets** — kumpulan plugin yang sudah dikelompokkan (preset-env, preset-react, preset-typescript)
- **Plugins** — transformasi individual (arrow functions, destructuring, optional chaining)
- `@babel/preset-env` — secara otomatis menentukan transformasi berdasarkan target browser
- `@babel/preset-react` — untuk JSX transformation
- `@babel/preset-typescript` — untuk TypeScript (tanpa type checking)
- **Polyfill** — melalui `core-js` untuk API baru (Promise, Array.includes, dll)
- Konfigurasi di file `babel.config.js` atau `.babelrc`

---

### Contoh Implementasi

```bash
npm install -D @babel/core @babel/cli @babel/preset-env
```

```javascript
// babel.config.js
module.exports = {
  presets: [
    ['@babel/preset-env', {
      targets: {
        browsers: ['> 1%', 'last 2 versions', 'not dead']
      },
      useBuiltIns: 'usage',
      corejs: 3
    }]
  ],
  plugins: [
    '@babel/plugin-transform-arrow-functions'
  ]
};
```

```javascript
// Sebelum Babel (ES6+)
const greet = (name) => `Halo, ${name}!`;
const numbers = [1, 2, 3];
const doubled = numbers.map(n => n * 2);

// Sesudah Babel (ES5)
"use strict";
var greet = function greet(name) {
  return "Halo, ".concat(name, "!");
};
var numbers = [1, 2, 3];
var doubled = numbers.map(function(n) {
  return n * 2;
});
```
