### Definisi Singkat

npm (Node Package Manager) adalah package manager default untuk Node.js yang digunakan untuk menginstal, mengelola, dan membagikan paket (library) JavaScript. npm terdiri dari CLI (command-line interface) dan registry online (https://npmjs.com) yang berisi jutaan paket.

---

### Analogi

Seperti **toko aplikasi (App Store)** untuk kode JavaScript. Butuh library untuk validasi form? Cari di npm, install dengan satu perintah, dan langsung bisa digunakan. npm juga mengelola dependensi seperti asisten pribadi yang mencatat semua barang yang Anda pinjam.

---

### Poin-Poin Penting

- `npm init` — membuat `package.json` baru
- `npm install <package>` — menginstal paket dan menambahkannya ke `dependencies`
- `npm install -D <package>` — menginstal sebagai `devDependencies`
- `npm install -g <package>` — menginstal global (tersedia di terminal)
- `npm update` — memperbarui semua paket
- `npm uninstall <package>` — menghapus paket
- `npm run <script>` — menjalankan script dari `package.json`
- `npx <package>` — menjalankan paket tanpa menginstalnya secara permanen
- `node_modules/` — folder tempat semua paket tersimpan
- `package-lock.json` — mengunci versi eksak dependensi

---

### Contoh Implementasi

```bash
# Inisialisasi project
npm init -y

# Install dependencies produksi
npm install express

# Install dev dependencies
npm install -D jest

# Install global
npm install -g nodemon

# Menjalankan script
# package.json: "scripts": { "start": "node index.js", "test": "jest" }
npm start
npm test
```

```javascript
// Contoh penggunaan paket yang diinstal
const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('Halo dari Express!');
});

app.listen(3000);
```
