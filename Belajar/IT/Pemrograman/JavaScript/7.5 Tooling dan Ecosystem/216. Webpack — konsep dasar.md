### Definisi Singkat

Webpack adalah module bundler untuk JavaScript dan aset web. Ia mengambil file dengan berbagai dependensi (JS, CSS, gambar, font) dan menggabungkannya menjadi bundle statis yang siap untuk production. Webpack menggunakan konsep **entry, output, loaders, plugins**, dan **mode**.

---

### Analogi

Seperti **pabrik perakitan mobil** — Anda memasukkan ribuan komponen (file) dari berbagai pemasok (modul), lalu pabrik (Webpack) merakitnya menjadi mobil jadi (bundle) yang siap dikirim ke dealer (browser). Loader seperti mesin khusus untuk menangani ban, kaca, atau mesin.

---

### Poin-Poin Penting

- **Entry** — titik masuk aplikasi (misal: `src/index.js`)
- **Output** — file bundle yang dihasilkan (misal: `dist/bundle.js`)
- **Loaders** — transformasi file sebelum di-bundle (CSS-loader, Babel-loader, file-loader)
- **Plugins** — ekstensi untuk tugas tambahan (HTML generation, minification, environment variables)
- **Mode** — `development` (dengan source maps), `production` (minified + tree-shaking), `none`
- **Code splitting** — memisahkan kode menjadi beberapa bundle untuk loading lebih cepat
- **Tree shaking** — menghapus kode yang tidak digunakan

---

### Contoh Implementasi

```javascript
// webpack.config.js
const path = require('path');
const HtmlWebpackPlugin = require('html-webpack-plugin');

module.exports = {
  entry: './src/index.js',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'bundle.[contenthash].js',
    clean: true
  },
  mode: 'development',
  module: {
    rules: [
      {
        test: /\.js$/,
        exclude: /node_modules/,
        use: 'babel-loader'
      },
      {
        test: /\.css$/,
        use: ['style-loader', 'css-loader']
      },
      {
        test: /\.(png|svg|jpg)$/,
        type: 'asset/resource'
      }
    ]
  },
  plugins: [
    new HtmlWebpackPlugin({
      template: './src/index.html'
    })
  ],
  devServer: {
    port: 3000,
    hot: true
  }
};
```
