### Definisi Singkat

Git Hooks adalah script yang berjalan otomatis pada event Git tertentu (seperti `pre-commit`, `pre-push`, `commit-msg`). **Husky** adalah tool yang memudahkan pengelolaan Git Hooks di project Node.js. **lint-staged** adalah tool untuk menjalankan linter hanya pada file yang di-stage (akan di-commit), sehingga proses tetap cepat.

---

### Analogi

Seperti **satpam di pintu masuk mall** — sebelum Anda masuk (commit), satpam memeriksa tas Anda (menjalankan ESLint/Prettier). Jika ada barang terlarang (error), Anda harus membereskannya dulu. Husky memasang satpam, lint-staged memastikan hanya tas yang akan dibawa masuk yang diperiksa.

---

### Poin-Poin Penting

- Husky membuat Git Hooks mudah dikonfigurasi via `package.json` atau `husky` folder
- `pre-commit` hook: biasanya untuk menjalankan lint-staged
- `commit-msg` hook: memvalidasi format pesan commit (conventional commits)
- `pre-push` hook: menjalankan test sebelum push
- lint-staged hanya memproses file yang di-stage, bukan seluruh project
- Konfigurasi lint-staged: peta pattern → perintah (test, lint, format)
- Kombinasi Husky + lint-staged sangat populer di tim development

---

### Contoh Implementasi

```bash
npm install -D husky lint-staged
npx husky init
```

```json
// package.json — tambahkan
{
  "scripts": {
    "prepare": "husky"
  },
  "lint-staged": {
    "*.{js,jsx,ts,tsx}": ["eslint --fix", "prettier --write"],
    "*.{css,scss,json,md}": ["prettier --write"]
  }
}
```

```bash
# Membuat hook pre-commit (.husky/pre-commit)
npx husky add .husky/pre-commit "npx lint-staged"
```

```bash
# Membuat hook commit-msg (.husky/commit-msg)
npx husky add .husky/commit-msg "npx --no-install commitlint --edit $1"
```

```javascript
// Contoh file .husky/pre-commit
#!/usr/bin/env sh
. "$(dirname -- "$0")/_/husky.sh"
npx lint-staged
```
