### Definisi Singkat
Memoization adalah teknik optimasi dengan menyimpan (caching) hasil eksekusi fungsi berdasarkan argumen yang diberikan, sehingga fungsi tidak perlu dihitung ulang untuk input yang sama.

---
### Analogi
Seperti buku catatan jawaban soal matematika. Jika ada soal yang sama, tinggal lihat jawaban di buku tanpa menghitung ulang dari awal.

---
### Poin-Poin Penting
- Menggunakan object/Map sebagai cache
- Sangat efektif untuk fungsi rekursif dan heavy computation
- Trade-off: memory usage vs waktu eksekusi
- Pure function adalah kandidat ideal untuk memoization

---
### Contoh Implementasi
```javascript
// Implementasi memoization sederhana
function memoize(fn) {
  const cache = new Map();
  return function (...args) {
    const key = JSON.stringify(args);
    if (cache.has(key)) {
      console.log('Mengambil dari cache');
      return cache.get(key);
    }
    console.log('Menghitung ulang');
    const result = fn(...args);
    cache.set(key, result);
    return result;
  };
}

// Contoh dengan fibonacci
function fibonacci(n) {
  if (n <= 1) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}

const fibMemo = memoize(function (n) {
  if (n <= 1) return n;
  return fibMemo(n - 1) + fibMemo(n - 2);
});

console.log(fibMemo(40)); // cepat!
console.log(fibMemo(40)); // dari cache

// Contoh faktorial
const faktorial = memoize(function (n) {
  if (n <= 1) return 1;
  return n * faktorial(n - 1);
});

console.log(faktorial(5)); // 120
console.log(faktorial(6)); // 720 (6 * cache 5!)
```
