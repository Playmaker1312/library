### Definisi Singkat
Rekursi adalah teknik pemrograman di mana sebuah fungsi memanggil dirinya sendiri untuk menyelesaikan masalah yang bisa dipecah menjadi sub-masalah yang lebih kecil.

---
### Analogi
Seperti cermin berhadap-hadapan yang memantul tanpa henti — atau seperti matryoshka (boneka Rusia) yang di dalamnya ada boneka lebih kecil hingga yang terkecil.

---
### Poin-Poin Penting
- Harus memiliki **base case** (kondisi berhenti)
- Memiliki **recursive case** (panggilan diri sendiri)
- Setiap panggilan ditambahkan ke call stack
- Risiko **stack overflow** jika rekursi terlalu dalam
- Alternatif: iterasi (loop) atau tail call optimization

---
### Contoh Implementasi
```javascript
// Faktorial dengan rekursi
function faktorial(n) {
  if (n <= 1) return 1; // base case
  return n * faktorial(n - 1); // recursive case
}
console.log(faktorial(5)); // 120

// Fibonacci
function fibonacci(n) {
  if (n <= 1) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}
console.log(fibonacci(7)); // 13

// Traversal struktur data nested
const menu = {
  nama: 'root',
  children: [
    {
      nama: 'folder1',
      children: [{ nama: 'file1', children: [] }],
    },
    {
      nama: 'folder2',
      children: [],
    },
  ],
};

function cetakMenu(node, indent = 0) {
  console.log('  '.repeat(indent) + node.nama);
  for (const child of node.children) {
    cetakMenu(child, indent + 1);
  }
}
cetakMenu(menu);
/*
root
  folder1
    file1
  folder2
*/
```

### Koneksi
Berkaitan dengan **call stack**, **tail call optimization**, **tree traversal**, **divide and conquer**, dan **dynamic programming**.
