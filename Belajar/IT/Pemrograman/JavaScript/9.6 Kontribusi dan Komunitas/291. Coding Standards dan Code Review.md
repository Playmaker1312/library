### Definisi Singkat

**Coding Standards** adalah seperangkat aturan dan konvensi yang disepakati tim untuk menulis kode — menyangkut gaya, struktur, dan pola. **Code Review** adalah proses di mana anggota tim lain memeriksa kode sebelum digabungkan ke branch utama. Keduanya menjaga **kualitas kode**, **konsistensi**, dan **mencegah bug**.

---

### Analogi

Seperti **aturan menulis surat resmi** — Anda harus menggunakan format tertentu (kop surat, salam pembuka, bahasa baku). Jika ada yang salah, editor (code reviewer) akan mengembalikan surat untuk diperbaiki. Aturan ini memastikan semua surat di perusahaan terbaca dan profesional.

---

### Poin-Poin Penting

- **Coding Standards umum**:
  - **ESLint**: Linter untuk menganalisis dan memperbaiki kode JavaScript.
  - **Prettier**: Formatter otomatis — konsistensi tanpa debat.
  - **Conventional Commits**: Format pesan commit (`feat:`, `fix:`, `chore:`, `docs:`).
  - **Airbnb Style Guide / StandardJS**: Standar gaya kode JavaScript.
- **Code Review — apa yang diperiksa**:
  - **Logika**: Apakah solusi benar dan efisien?
  - **Arsitektur**: Apakah kode mengikuti pola yang ada?
  - **Kebersihan**: Apakah ada kode mati, komentar berlebihan, atau duplikasi?
  - **Testing**: Apakah ada tes untuk perubahan?
  - **Keamanan**: Apakah ada celah keamanan?
  - **Performance**: Apakah ada bottleneck?
- **Tips review**: Fokus pada logika, bukan gaya (biarkan linter/formatter yang tangani gaya).

### Contoh Implementasi

```javascript
// ESLint + Prettier configuration
// .eslintrc.json
{
  "extends": ["eslint:recommended", "prettier"],
  "rules": {
    "no-unused-vars": "error",
    "prefer-const": "error",
    "no-console": "warn"
  }
}

// .prettierrc
{
  "semi": true,
  "singleQuote": true,
  "trailingComma": "all",
  "printWidth": 100,
  "tabWidth": 2
}
```

```bash
# Setup di proyek
npm install --save-dev eslint prettier eslint-config-prettier
# Scripts di package.json
# "lint": "eslint src/ --fix",
# "format": "prettier --write src/"
```

```
Conventional Commits format:
feat: tambahkan fitur validasi email
fix: perbaiki null pointer di login
docs: perbarui README instalasi
refactor: gunakan async/await
chore: update dependensi
```

```markdown
<!-- Checklist code review -->
## Checklist Review
- [ ] Kode berfungsi sesuai spesifikasi
- [ ] Tidak ada bug atau regression
- [ ] Unit test ditambahkan/diperbarui
- [ ] Dokumentasi diperbarui (jika perlu)
- [ ] Tidak ada kode mati atau komentar debug
- [ ] Mengikuti coding standards proyek
```

### Koneksi

Berkaitan dengan **Open Source** (standar interaksi), **CI/CD** (lint dan test otomatis di CI), **Fork, Branch, PR** (review terjadi sebelum merge), **Komunitas** (standar bersama), dan **Karier** (soft skill review).
