### Definisi Singkat

**Open Source** adalah model pengembangan perangkat lunak di mana kode sumber tersedia secara publik untuk dilihat, digunakan, dimodifikasi, dan didistribusikan. Berkontribusi ke proyek open source berarti Anda ikut serta dalam pengembangan — baik kode, dokumentasi, desain, atau laporan bug.

---

### Analogi

Seperti **kerja bakti membersihkan taman kota** — taman (proyek open source) milik semua orang. Anda bisa datang, menyapu daun (memperbaiki bug), menanam bunga (menambah fitur), atau memberi tahu petugas jika ada bangku rusak (lapor issue). Semua kontribusi, sekecil apa pun, membuat taman lebih baik untuk semua.

---

### Poin-Poin Penting

- **Mulai dari yang kecil**: Perbaiki typo di README, update dokumentasi, atau fix bug kecil.
- **Cari issue bertanda**: `good first issue`, `help wanted`, `beginner-friendly` — biasanya ramah pemula.
- **Jangan langsung buka PR**: Diskusi dulu di issue untuk menghindari kerja sia-sia.
- **Baca CONTRIBUTING.md** — pedoman kontribusi proyek.
- **Code of Conduct**: Hormati sesama kontributor.
- **Fork → Clone → Branch → Commit → Push → PR** — alur standar kontribusi.
- **Manfaat**: Portofolio, belajar dari kode berkualitas, membangun jaringan, dan memberi kembali ke komunitas.

---

### Contoh Implementasi

```markdown
<!-- CONTRIBUTING.md contoh -->
# Contributing

Terima kasih ingin berkontribusi! Berikut panduannya:

1. Fork repositori ini.
2. Clone fork Anda: `git clone https://github.com/username/proyek.git`
3. Buat branch fitur: `git checkout -b feat/fitur-baru`
4. Lakukan perubahan dan commit.
5. Push ke fork: `git push origin feat/fitur-baru`
6. Buka Pull Request ke branch `main`.

## Panduan
- Ikuti coding style yang ada
- Tulis tes untuk fitur baru
- Perbarui dokumentasi jika perlu
- Satu PR untuk satu fitur/perbaikan
```

```bash
# Langkah kontribusi via CLI
git clone https://github.com/opencode-ai/proyek.git
cd proyek
git checkout -b fix/typo-readme
# Edit file
git add .
git commit -m "docs: perbaiki typo di README"
git push origin fix/typo-readme
# Buka PR di GitHub
```

### Koneksi

Berkaitan dengan **Fork, Branch, Pull Request** (alur teknis kontribusi), **Coding Standards** (kualitas kode), **Komunitas JavaScript** (tempat mencari proyek), dan **Karier** (open source sebagai portofolio).
