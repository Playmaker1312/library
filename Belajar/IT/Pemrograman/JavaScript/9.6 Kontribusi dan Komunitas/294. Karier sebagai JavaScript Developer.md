### Definisi Singkat

**Karier sebagai JavaScript Developer** memiliki banyak jalur — frontend, backend, full-stack, mobile (React Native), game, atau bahkan embedded. JavaScript adalah salah satu bahasa dengan permintaan pasar tertinggi dan peluang karier yang luas.

---

### Analogi

Seperti **pohon besar dengan banyak cabang** — akarnya adalah JavaScript dasar (semua jalur butuh ini). Dari batang utama, Anda bisa memilih cabang: Frontend (React), Backend (Node.js), Mobile (React Native), atau Desktop (Electron). Setiap cabang bisa Anda panjat lebih tinggi dengan spesialisasi.

---

### Poin-Poin Penting

- **Jalur Karier**:
  - **Frontend Developer**: HTML, CSS, JavaScript + framework (React/Vue/Angular).
  - **Backend Developer**: Node.js, Express, database, API design.
  - **Full-Stack Developer**: Kombinasi frontend dan backend.
  - **Mobile Developer**: React Native atau Ionic.
  - **DevTools / CLI Developer**: Membangun alat untuk developer lain.
  - **Engineering Manager**: Memimpin tim teknis.
- **Skill pendukung**: Git, CI/CD, testing, soft skills (komunikasi, kolaborasi).
- **Portofolio**: Proyek pribadi, kontribusi open source, blog teknis.
- **Sertifikasi**: Tidak wajib, tetapi sertifikasi resmi (AWS, Google) bisa membantu.
- **Gaji**: Bervariasi berdasarkan lokasi, pengalaman, dan spesialisasi.
- **Continuous learning**: JavaScript ekosistem berubah cepat — belajar terus adalah keharusan.
