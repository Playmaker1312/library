### Definisi Singkat
Microtask queue adalah antrian prioritas tinggi yang berisi callback dari Promises (`.then`, `.catch`, `.finally`), `queueMicrotask()`, dan `MutationObserver`. Microtask dieksekusi setelah synchronous code selesai, sebelum macrotask.

---
### Analogi
Seperti antrian prioritas (VIP) di bandara: penumpang VIP (microtask) dilayani duluan setelah check-in reguler, sebelum penumpang biasa (macrotask) berikutnya dipanggil.

---
### Poin-Poin Penting
- Semua microtask dieksekusi sebelum satu macrotask diambil
- Microtask baru yang ditambahkan saat eksekusi juga dijalankan (microtask bisa membuat microtask baru)
- Sumber: Promise callbacks, `queueMicrotask()`, `MutationObserver`
- Prioritas lebih tinggi dari task queue
- Penting untuk menjaga UI tetap responsif

---
### Contoh Implementasi
```javascript
console.log('1. Sinkron mulai');

// Macrotask
setTimeout(() => {
  console.log('2. Macrotask: setTimeout');
}, 0);

// Promise (.then adalah microtask)
Promise.resolve('3. Microtask: Promise')
  .then((msg) => {
    console.log(msg);
    // Microtask di dalam microtask
    return Promise.resolve('4. Microtask: Promise chain');
  })
  .then((msg) => console.log(msg));

// queueMicrotask
queueMicrotask(() => {
  console.log('5. Microtask: queueMicrotask');
});

// Observer (MutationObserver juga microtask)
console.log('6. Sinkron selesai');

// Output:
// "1. Sinkron mulai"
// "6. Sinkron selesai"
// "3. Microtask: Promise"
// "5. Microtask: queueMicrotask"
// "4. Microtask: Promise chain"
// "2. Macrotask: setTimeout"

// Microtask berantai — semua selesai dulu
queueMicrotask(() => {
  console.log('7. Microtask A');
  queueMicrotask(() => {
    console.log('8. Microtask B (dari A)');
  });
});
// 7 dan 8 diproses sebelum macrotask berikutnya
```
