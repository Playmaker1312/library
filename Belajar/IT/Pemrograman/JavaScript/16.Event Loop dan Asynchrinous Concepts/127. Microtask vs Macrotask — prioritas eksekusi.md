### Definisi Singkat
Microtask dan macrotask adalah dua jenis antrian dalam event loop. Microtask memiliki prioritas lebih tinggi: setelah setiap macrotask selesai, event loop akan mengosongkan seluruh microtask queue sebelum melanjutkan ke macrotask berikutnya.

---
### Analogi
Seperti kantor dengan dua kotak surat: kotak "PENTING" (microtask) selalu diperiksa dan dikosongkan duluan setiap kali selesai menangani satu surat dari kotat "BIASA" (macrotask).

---
### Poin-Poin Penting
| Microtask | Macrotask |
|-----------|-----------|
| Promise.then/catch/finally | setTimeout/setInterval |
| queueMicrotask() | I/O events |
| MutationObserver | UI rendering |
| process.nextTick (Node.js) | Event listeners |
| Semua dieksekusi per siklus | Satu per siklus |

---
### Contoh Implementasi
```javascript
console.log('1. Start');

// Macrotask 1
setTimeout(() => console.log('2. Macrotask A'), 0);

// Microtask 1
Promise.resolve().then(() => console.log('3. Microtask 1'));

// Macrotask 2
setTimeout(() => {
  console.log('4. Macrotask B mulai');

  // Microtask di dalam macrotask
  Promise.resolve().then(() => console.log('5. Microtask dalam Macrotask B'));

  console.log('6. Macrotask B selesai');
}, 0);

// Microtask 2
Promise.resolve().then(() => console.log('7. Microtask 2'));

console.log('8. End');

// Output:
// "1. Start"
// "8. End"
// "3. Microtask 1"       ← semua microtask
// "7. Microtask 2"       ← selesai dulu
// "2. Macrotask A"       ← macrotask pertama
// "4. Macrotask B mulai" ← macrotask kedua
// "6. Macrotask B selesai"
// "5. Microtask dalam Macrotask B" ← microtask baru setelah B selesai

// Pola: Sinkron → Microtask (all) → Macrotask (1) → Microtask (all) → Macrotask (1) → ...
```
