### Definisi Singkat
Task queue (atau macrotask/callback queue) adalah antrian tugas yang menunggu untuk dieksekusi setelah call stack kosong. Tugas di sini berasal dari `setTimeout`, `setInterval`, `I/O`, event handlers, dan `setImmediate`.

---
### Analogi
Seperti antrian di kasir supermarket: pelanggan (task) mengantri. Kasir (event loop) melayani satu per satu setelah pelanggan sebelumnya selesai total.

---
### Poin-Poin Penting
- Macrotask dieksekusi SATU per siklus event loop
- Setiap macrotask baru ditambahkan ke ujung antrian
- Sumber macrotask: `setTimeout`, `setInterval`, `I/O`, UI rendering, event listeners
- Eksekusi task queue terjadi setelah microtask queue kosong
- `setTimeout(fn, 0)` menambahkan task ke queue setelah delay minimal

---
### Contoh Implementasi
```javascript
console.log('1. Sinkron');

// Macrotask 1
setTimeout(() => {
  console.log('2. setTimeout 1');
}, 0);

// Macrotask 2
setTimeout(() => {
  console.log('3. setTimeout 2');
}, 0);

// Macrotask 3 (lebih lambat)
setTimeout(() => {
  console.log('4. setTimeout 3 (500ms)');
}, 500);

// Microtask — prioritas lebih tinggi
Promise.resolve().then(() => {
  console.log('5. Promise microtask');
});

// Click event handler (simulasi)
const button = { clicks: [] };
button.addEventListener = function (event, handler) {
  this.clicks.push(handler);
};
button.addEventListener('click', () => console.log('6. Click handler'));

console.log('7. Sinkron end');

// Output:
// "1. Sinkron"
// "7. Sinkron end"
// "5. Promise microtask"    — microtask dulu
// "2. setTimeout 1"         — macrotask pertama
// "3. setTimeout 2"         — macrotask kedua
// "6. Click handler"        — jika diklik
// "4. setTimeout 3 (500ms)" — macrotask ketiga

// Siklus event loop:
// 1. Eksekusi synchronous → kosongkan microtask
// 2. Ambil SATU macrotask → eksekusi
// 3. Kosongkan microtask lagi
// 4. Ambil macrotask berikutnya → ulangi
```
