### Definisi Singkat
Concurrency model JavaScript memungkinkan bahasa single-threaded menangani banyak operasi secara bersamaan melalui kombinasi Call Stack, Web APIs, Event Loop, dan Task Queues (macro + micro).

---
### Analogi
Seperti koki di dapur: satu koki (single thread) memasak banyak pesanan. Ia tidak menunggu air mendidih (I/O) — ia menyalakan kompor, lalu mengerjakan yang lain. Timer memberi tahu saat air sudah mendidih (callback).

---
### Poin-Poin Penting
- JavaScript single-threaded: satu call stack, satu tugas per waktu
- Non-blocking I/O via Web APIs (browser) atau libuv (Node.js)
- Event loop mengatur eksekusi callback secara asynchronous
- Concurrency ≠ parallelism (JavaScript tidak melakukan banyak hal bersamaan)
- Callback, Promise, dan async/await adalah tools untuk mengelola async

---
### Contoh Implementasi
```javascript
// Model concurrency JavaScript
console.log('1. Mulai memasak');

// Non-blocking I/O — tidak menunggu
setTimeout(() => {
  console.log('2. Air sudah mendidih!');
}, 2000);

// Operasi synchronous
function potongBawang() {
  console.log('3. Memotong bawang...');
}
potongBawang();

// Promise — microtask
Promise.resolve().then(() => {
  console.log('4. Mempersiapkan bumbu');
});

console.log('5. Selesai memasak');

// Output:
// "1. Mulai memasak"
// "3. Memotong bawang..."
// "5. Selesai memasak"
// "4. Mempersiapkan bumbu"    ← microtask
// "2. Air sudah mendidih!"    ← macrotask (setelah 2 detik)

// Arsitektur:
// ┌─────────────┐
// │  Call Stack │ ← eksekusi kode
// └──────┬──────┘
//        │
// ┌──────▼──────┐
// │  Event Loop  │ ← mengatur alur
// └──────┬──────┘
//        │
// ┌──────▼──────┐   ┌──────────────┐
// │ Microtask Q  │   │  Macrotask Q │
// │ (Promise dll)│   │ (setTimeout) │
// └─────────────┘   └──────────────┘
```
