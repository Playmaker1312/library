# 63. Array methods - indexOf includes find findIndex

**Definisi Singkat:** Methods untuk mencari elemen dalam array berdasarkan nilai atau kondisi.

**Analogi:** Seperti "cari buku di perpustakaan": indexOf (cari judul persis), includes (apa judulnya ada?), find (cari buku dengan kriteria tertentu).

**Poin-Poin Penting:**
- `indexOf(value)` mengembalikan index pertama atau `-1`
- `includes(value)` mengembalikan boolean (ES6)
- `find(fn)` mengembalikan elemen pertama yang memenuhi fn
- `findIndex(fn)` mengembalikan index dari elemen tersebut
- `find`/`findIndex` menerima callback predicate

**Contoh Kode:**
```javascript
const produk = [
  { id: 1, nama: "Buku" },
  { id: 2, nama: "Pensil" },
];
console.log(produk.find(p => p.id === 2));
console.log(produk.findIndex(p => p.nama === "Buku"));
console.log([10, 20, 30].indexOf(20));
console.log([10, 20].includes(10));
```
Hasil:
```
{ id: 2, nama: 'Pensil' }
0
1
true
```

**Kasus Penggunaan Nyata:**
Cari user berdasarkan ID di database lokal, cek apakah item sudah ada di keranjang.
