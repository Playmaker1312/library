### Definisi Singkat

**Array destructuring** adalah fitur ES6 yang memungkinkan ekstraksi nilai dari array ke dalam variabel terpisah dengan sintaks yang ringkas. Menggunakan pola kurung siku [] di sisi kiri assignment.

---

### Analogi

Bayangkan Anda memiliki boks berisi 3 bola warna:

- Tanpa destructuring: Anda harus mengambil bola satu per satu: olaMerah = boks[0], olaBiru = boks[1], dll.
- Dengan destructuring: Anda bisa membuka boks dan langsung menamai bola: [merah, biru, hijau] = boks.

---

### Poin-Poin Penting

- **Sintaks dasar:** const [a, b] = array.  mendapat elemen pertama,  elemen kedua.
- **Skip elemen:** Gunakan koma kosong: const [a, , c] = array (skip indeks 1).
- **Default value:** const [a = 10] = [] — jika elemen undefined, pakai default.
- **Rest pattern:** const [a, ...rest] = array — est berisi sisa elemen sebagai array.
- **Swap variabel:** [a, b] = [b, a] — cara mudah menukar nilai.
- Bisa digunakan dengan **return value** fungsi yang mengembalikan array.

---

### Contoh Implementasi

`javascript
// Destructuring dasar
const angka = [10, 20, 30];
const [pertama, kedua, ketiga] = angka;
console.log(pertama); // 10
console.log(kedua);   // 20

// Skip elemen
const [x, , z] = angka;
console.log(x); // 10
console.log(z); // 30

// Default value
const [a = 0, b = 0, c = 0, d = 99] = [1, 2];
console.log(a, b, c, d); // 1, 2, 0, 99

// Rest pattern
const [head, ...tail] = angka;
console.log(head); // 10
console.log(tail); // [20, 30]

// Swap variabel
let kiri = 1, kanan = 2;
[kiri, kanan] = [kanan, kiri];
console.log(kiri, kanan); // 2, 1

// Dengan return function
function getNamaDanUmur() {
  return ["Budi", 25];
}
const [nama, umur] = getNamaDanUmur();
console.log(nama, umur); // "Budi", 25
`

---

### Koneksi

Array destructuring sering digunakan bersama **spread dan rest operator** (materi 67) untuk memanipulasi array. Juga terkait dengan **Object destructuring** (materi 74) yang menggunakan sintaks serupa.
