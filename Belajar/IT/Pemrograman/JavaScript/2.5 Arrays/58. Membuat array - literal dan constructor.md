# 58. Membuat array - literal dan constructor

**Definisi Singkat:** Array bisa dibuat dengan `[]` (literal) atau `new Array()` (constructor).

**Analogi:** Seperti kotak penyimpanan — literal ibarat membeli kotak jadi, constructor seperti merakit sendiri.

**Poin-Poin Penting:**
- Array literal `[]` lebih umum dan disarankan
- `new Array(length)` membuat array kosong dengan length tertentu
- `new Array(1, 2, 3)` sama dengan `[1, 2, 3]`
- Hati-hati: `new Array(3)` membuat array sparse (lubang kosong)

**Contoh Kode:**
```javascript
const arr1 = [1, 2, 3];
const arr2 = new Array(3);
const arr3 = new Array(1, 2, 3);
console.log(arr1);
console.log(arr2);
console.log(arr3);
```
Hasil:
```
[ 1, 2, 3 ]
[ <3 empty items> ]
[ 1, 2, 3 ]
```

**Kasus Penggunaan Nyata:**
Array literal untuk deklarasi data statis; constructor untuk inisialisasi array dengan panjang tetap.
