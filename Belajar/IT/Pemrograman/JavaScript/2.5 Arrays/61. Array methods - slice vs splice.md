# 61. Array methods - slice vs splice

**Definisi Singkat:** `slice()` mengambil salinan bagian array; `splice()` mengubah isi array (hapus/tambah).

**Analogi:** `slice` seperti fotokopi halaman buku (tidak mengubah asli); `splice` seperti gunting dan lem halaman.

**Poin-Poin Penting:**
- `slice(start, end)` — mengembalikan array baru, tidak mengubah asli
- `splice(start, deleteCount, ...items)` — mengubah array asli
- `slice()` bisa dipanggil tanpa argumen untuk copy array
- `splice()` bisa untuk insert, delete, atau replace

**Contoh Kode:**
```javascript
const arr = [10, 20, 30, 40, 50];
console.log(arr.slice(1, 3));
console.log(arr);

const removed = arr.splice(1, 2, 25, 35);
console.log(removed);
console.log(arr);
```
Hasil:
```
[ 20, 30 ]
[ 10, 20, 30, 40, 50 ]
[ 20, 30 ]
[ 10, 25, 35, 40, 50 ]
```

**Kasus Penggunaan Nyata:**
`splice` untuk menghapus item dari array; `slice` untuk pagination atau preview data.
