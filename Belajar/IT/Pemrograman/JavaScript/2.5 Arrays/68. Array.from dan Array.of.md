### Definisi Singkat

**Array.from** dan **Array.of** adalah method statis dari constructor Array. Array.from mengubah iterable atau array-like object menjadi array. Array.of membuat array dari argumen yang diberikan, memperbaiki keanehan constructor 
ew Array().

---

### Analogi

- **Array.from:** Seperti mesin daur ulang yang mengubah benda-benda (seperti string, NodeList, Set) menjadi array — bahan baku apapun bisa diubah.
- **Array.of:** Seperti mesin pencetak yang membuat wadah dari barang-barang yang Anda berikan — Array.of(3) membuat [3], bukan array kosong dengan panjang 3.

---

### Poin-Poin Penting

- **Array.from(arrayLike, mapFn):** Mengubah iterable/array-like ke array. Opsional mapFn untuk transformasi langsung.
- **Array.of(...elements):** Membuat array dari elemen. Tidak memiliki perilaku ambigu 
ew Array().
- Array.from berguna untuk **NodeList** (DOM), **arguments**, **Set**, **Map**, dan **string**.
- Array.from dengan mapFn lebih efisien daripada Array.from().map().
- **Array.from({ length: n }, (_, i) => i):** Membuat array berurutan dengan cepat.

---

### Contoh Implementasi

`javascript
// Array.from — dari string
const dariString = Array.from("hello");
console.log(dariString); // ["h", "e", "l", "l", "o"]

// Array.from — dengan map function
const angka = Array.from([1, 2, 3], x => x * 2);
console.log(angka); // [2, 4, 6]

// Array.from — membuat range angka
const range = Array.from({ length: 5 }, (_, i) => i + 1);
console.log(range); // [1, 2, 3, 4, 5]

// Array.from — dari Set
const set = new Set([1, 2, 3, 3, 2]);
const arrSet = Array.from(set);
console.log(arrSet); // [1, 2, 3]

// Array.of
console.log(Array.of(3));       // [3]
console.log(Array.of(1, 2, 3)); // [1, 2, 3]
console.log(Array.of("hello")); // ["hello"]

// Perbandingan dengan new Array()
console.log(new Array(3));      // [empty × 3]
console.log(Array.of(3));       // [3]
`

---

### Koneksi

Array.from sering digunakan bersama **spread operator** (materi 67) untuk konversi iterable ke array. Penting dalam **DOM Manipulation** untuk mengubah NodeList (hasil querySelectorAll) menjadi array agar bisa menggunakan array methods.
