### Definisi Singkat

**slice** dan **splice** adalah method array untuk memotong/mengubah array. **slice** mengambil salinan bagian array tanpa mengubah array asli, sedangkan **splice** mengubah array asli dengan menambah, menghapus, atau mengganti elemen.

---

### Analogi

Bayangkan Anda memiliki sebatang cokelat:

- **slice:** Memotong cokelat menjadi beberapa bagian — potongannya adalah cokelat baru, batang asli tetap utuh.
- **splice:** Mematahkan beberapa bagian cokelat dan menyolder bagian lain — batang asli berubah bentuk.

---

### Poin-Poin Penting

- **slice(start, end):** Mengembalikan array baru dari indeks start hingga end (tidak termasuk end). Tidak mengubah array asli.
- **splice(start, deleteCount, item1, item2, ...):** Mengubah array asli. Menghapus deleteCount elemen dari start, lalu menyisipkan item baru.
- slice mendukung indeks negatif. splice juga mendukung indeks negatif untuk start.
- Jika deleteCount = 0, splice hanya menyisipkan tanpa menghapus.
- splice mengembalikan array berisi elemen yang dihapus.

---

### Contoh Implementasi

`javascript
const arr = ["a", "b", "c", "d", "e"];

// slice (tidak mengubah asli)
const potongan = arr.slice(1, 4);
console.log(potongan); // ["b", "c", "d"]
console.log(arr);      // ["a", "b", "c", "d", "e"] (tidak berubah)

// slice dengan negatif
console.log(arr.slice(-3));    // ["c", "d", "e"]
console.log(arr.slice(1, -1)); // ["b", "c", "d"]

// splice (mengubah asli)
const arr2 = ["a", "b", "c", "d", "e"];

// Hapus 2 elemen dari indeks 1
const dihapus = arr2.splice(1, 2);
console.log(dihapus); // ["b", "c"]
console.log(arr2);    // ["a", "d", "e"]

// Sisipkan tanpa hapus
arr2.splice(1, 0, "x", "y");
console.log(arr2);    // ["a", "x", "y", "d", "e"]

// Ganti elemen
arr2.splice(2, 1, "z");
console.log(arr2);    // ["a", "x", "z", "d", "e"]
`

---

### Koneksi

slice sering digunakan untuk **menyalin array** (bersama spread operator) dan mengambil sub-array. splice digunakan untuk **manipulasi data** dinamis seperti daftar item di aplikasi todo list.
