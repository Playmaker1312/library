# 62. Array methods - concat join reverse sort

**Definisi Singkat:** Methods untuk menggabung, menyambung jadi string, membalik, dan mengurutkan array.

**Analogi:** Seperti merapikan berkas: concat (gabung folder), join (jadi satu dokumen), reverse (balik urutan), sort (urutkan A-Z).

**Poin-Poin Penting:**
- `concat()` menggabung array, tidak mengubah asli
- `join(separator)` mengubah array ke string
- `reverse()` membalik array *di tempat* (mutasi asli)
- `sort()` mengurutkan sebagai string secara default
- `sort((a,b) => a - b)` untuk sort numerik

**Contoh Kode:**
```javascript
const a = [3, 1, 4];
const b = [1, 5, 9];
console.log(a.concat(b));
console.log(a.join(" - "));
console.log([...a].reverse());
console.log([...a].sort());
console.log([...a].sort((x, y) => x - y));
```
Hasil:
```
[ 3, 1, 4, 1, 5, 9 ]
3 - 1 - 4
[ 4, 1, 3 ]
[ 1, 3, 4 ]
[ 1, 3, 4 ]
```

**Kasus Penggunaan Nyata:**
Sortir daftar harga, join tag jadi CSV, reverse chat history.
