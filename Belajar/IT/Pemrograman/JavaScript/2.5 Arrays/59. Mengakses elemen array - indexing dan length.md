# 59. Mengakses elemen array - indexing dan length

**Definisi Singkat:** Elemen array diakses via index (0-based) dan `length` untuk jumlah elemen.

**Analogi:** Seperti kursi bernomor di bioskop — kursi pertama nomor 0, kedua nomor 1, total kursi = length.

**Poin-Poin Penting:**
- Index dimulai dari 0
- Elemen terakhir di `array[array.length - 1]`
- `array.length` bisa diubah untuk memotong array
- Index di luar range menghasilkan `undefined`

**Contoh Kode:**
```javascript
const warna = ["Merah", "Hijau", "Biru"];
console.log(warna[0]);
console.log(warna[warna.length - 1]);
console.log(warna[5]);

warna.length = 2;
console.log(warna);
```
Hasil:
```
Merah
Biru
undefined
[ 'Merah', 'Hijau' ]
```

**Kasus Penggunaan Nyata:**
Akses item dalam list, mendapatkan item pertama/terakhir, truncate array.
