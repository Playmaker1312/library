### Definisi Singkat

Array di JavaScript dapat dibuat menggunakan dua cara: **array literal** ([]) dan **constructor** (
ew Array()). Array literal adalah cara yang paling umum dan direkomendasikan karena lebih sederhana dan tidak ambigu.

---

### Analogi

Bayangkan Anda memiliki rak buku kosong:

- **Array literal ([]):** Seperti membeli rak buku langsung jadi — Anda bisa langsung meletakkan buku di dalamnya.
- **Array constructor (
ew Array()):** Seperti membeli rak buku yang perlu dirakit — fungsinya sama, tapi lebih panjang penulisannya.

---

### Poin-Poin Penting

- **Array literal:** Gunakan tanda kurung siku []. Bisa diisi langsung: [1, 2, 3].
- **Array constructor:** Gunakan 
ew Array(). Perilaku berbeda jika diberi satu argumen angka — itu menjadi **length**, bukan elemen.
- **Best practice:** Selalu gunakan **array literal** ([]) kecuali ada alasan khusus.
- Array bisa menampung **tipe data campuran** dalam satu array.
- Array literal lebih cepat dan lebih mudah dibaca.

---

### Contoh Implementasi

`javascript
// Array literal
const buah = ["apel", "mangga", "jeruk"];
const angka = [1, 2, 3, 4, 5];
const campuran = ["teks", 42, true, null];

// Array constructor
const arr1 = new Array(3);        // [empty × 3] (panjang 3)
const arr2 = new Array(3, 4);     // [3, 4]
const arr3 = new Array("3");      // ["3"]

// Hati-hati dengan satu argumen number
console.log(arr1);   // [empty × 3]
console.log(arr1.length); // 3

// Array literal tidak punya masalah ini
const arr4 = [3];
console.log(arr4);   // [3]
console.log(arr4.length); // 1
`
