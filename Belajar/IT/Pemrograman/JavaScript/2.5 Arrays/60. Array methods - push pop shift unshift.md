# 60. Array methods - push pop shift unshift

**Definisi Singkat:** Methods untuk menambah/menghapus elemen di awal dan akhir array.

**Analogi:** Seperti antrian di kasir: push (orang datang belakang), pop (orang selesai di belakang), shift (orang pergi dari depan), unshift (orang nyerobot depan).

**Poin-Poin Penting:**
- `push()` dan `pop()` bekerja di akhir → cepat (O(1))
- `shift()` dan `unshift()` bekerja di awal → lambat (O(n))
- `push()` mengembalikan length baru
- `pop()` dan `shift()` mengembalikan elemen yang dihapus

**Contoh Kode:**
```javascript
const queue = [1, 2, 3];
queue.push(4);
console.log(queue);
queue.pop();
console.log(queue);
queue.unshift(0);
console.log(queue);
queue.shift();
console.log(queue);
```
Hasil:
```
[ 1, 2, 3, 4 ]
[ 1, 2, 3 ]
[ 0, 1, 2, 3 ]
[ 1, 2, 3 ]
```

**Kasus Penggunaan Nyata:**
Queue management (push/shift), stack (push/pop), undo-redo history.
