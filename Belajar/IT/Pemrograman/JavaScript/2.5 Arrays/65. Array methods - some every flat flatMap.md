# 65. Array methods - some every flat flatMap

**Definisi Singkat:** Methods untuk cek kondisi seluruh/sebagian elemen dan meratakan array bersarang.

**Analogi:** `some` seperti "apa ada yang sakit?" (cukup satu ya); `every` seperti "apa semua hadir?" (harus semua); `flat` seperti meratakan tumpukan kardus.

**Poin-Poin Penting:**
- `some(fn)` — true jika **minimal satu** elemen memenuhi kondisi
- `every(fn)` — true jika **semua** elemen memenuhi kondisi
- `flat(depth)` — meratakan array bersarang hingga kedalaman tertentu
- `flatMap(fn)` — `map()` lalu `flat(1)` dalam satu langkah
- `some` dan `every` berhenti lebih awal (*short-circuit*)

**Contoh Kode:**
```javascript
const nilai = [70, 85, 90, 60];
console.log(nilai.some(n => n < 65));
console.log(nilai.every(n => n >= 60));
console.log([[1, 2], [3, [4]]].flat(2));
console.log(["halo dunia", "foo bar"].flatMap(s => s.split(" ")));
```
Hasil:
```
true
false
[ 1, 2, 3, 4 ]
[ 'halo', 'dunia', 'foo', 'bar' ]
```

**Kasus Penggunaan Nyata:**
Validasi form (every), cek otorisasi (some), parsing data nested jadi flat list.
