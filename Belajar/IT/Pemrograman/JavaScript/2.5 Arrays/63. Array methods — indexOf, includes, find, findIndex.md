### Definisi Singkat

**indexOf, includes, find, findIndex** adalah method array untuk mencari elemen. indexOf dan includes menggunakan perbandingan nilai, sedangkan ind dan indIndex menggunakan fungsi callback untuk pencarian yang lebih kompleks.

---

### Analogi

Bayangkan Anda mencari buku di perpustakaan:

- **indexOf:** Mencari buku "JavaScript" dan memberi tahu di rak nomor berapa buku itu berada.
- **includes:** Mengecek apakah buku "JavaScript" ada di perpustakaan (ya/tidak).
- **find:** Mencari buku dengan kriteria "pengarangnya X" — mengembalikan buku pertama yang cocok.
- **findIndex:** Mencari buku dengan kriteria "pengarangnya X" — mengembalikan posisi rak buku tersebut.

---

### Poin-Poin Penting

- **indexOf(searchElement, fromIndex):** Mencari elemen dengan ===. Mengembalikan indeks atau -1.
- **includes(searchElement, fromIndex):** Mencari elemen dengan ===. Mengembalikan boolean.
- **ind(callback):** Mencari elemen pertama yang memenuhi kondisi callback. Mengembalikan **elemen** atau undefined.
- **indIndex(callback):** Mencari elemen pertama yang memenuhi kondisi callback. Mengembalikan **indeks** atau -1.
- ind dan indIndex bisa mencari object berdasarkan properti (tidak bisa dengan indexOf/includes).

---

### Contoh Implementasi

`javascript
const angka = [10, 20, 30, 40, 30];

// indexOf
console.log(angka.indexOf(30));    // 2
console.log(angka.indexOf(30, 3)); // 4 (cari dari indeks 3)
console.log(angka.indexOf(99));    // -1

// includes
console.log(angka.includes(20));   // true
console.log(angka.includes(99));   // false

// find dengan callback
const hasil = angka.find(n => n > 25);
console.log(hasil); // 30 (elemen pertama > 25)

// findIndex
const idx = angka.findIndex(n => n > 25);
console.log(idx);   // 2

// Pencarian dengan object
const users = [
  { id: 1, nama: "Budi" },
  { id: 2, nama: "Ani" },
  { id: 3, nama: "Cici" }
];

const user = users.find(u => u.id === 2);
console.log(user); // { id: 2, nama: "Ani" }

const userIdx = users.findIndex(u => u.nama === "Cici");
console.log(userIdx); // 2
`

---

### Koneksi

ind dan indIndex adalah bagian dari **Higher-Order Functions** (materi 64) karena menerima callback. Ini adalah dasar untuk filter data di aplikasi seperti **pencarian produk** atau **filter tabel**.
