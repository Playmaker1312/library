# 64. Higher-Order Array methods - forEach map filter reduce

**Definisi Singkat:** Methods functional yang menerima callback untuk transformasi dan agregasi data.

**Analogi:** Seperti pabrik: forEach (periksa tiap barang), map (ubah bentuk tiap barang), filter (saring yang rusak), reduce (gabung jadi satu).

**Poin-Poin Penting:**
- `forEach` — menjalankan fungsi untuk setiap elemen (side effect)
- `map` — transformasi, mengembalikan array baru dengan panjang sama
- `filter` — seleksi, mengembalikan array baru dengan elemen yang lolos
- `reduce` — akumulasi jadi nilai tunggal (angka, object, array)
- Semua method ini menghasilkan array baru kecuali `forEach`

**Contoh Kode:**
```javascript
const angka = [1, 2, 3, 4, 5];
angka.forEach(n => console.log(n));
const kali2 = angka.map(n => n * 2);
const genap = angka.filter(n => n % 2 === 0);
const jumlah = angka.reduce((acc, n) => acc + n, 0);
console.log({ kali2, genap, jumlah });
```
Hasil:
```
1 2 3 4 5
{ kali2: [ 2, 4, 6, 8, 10 ], genap: [ 2, 4 ], jumlah: 15 }
```

**Kasus Penggunaan Nyata:**
`map` untuk format data API, `filter` untuk search/filter UI, `reduce` untuk total harga keranjang.
