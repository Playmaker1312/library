# 25. Object Destructuring & Shorthand

## Penjelasan
Object destructuring adalah sintaks untuk membongkar properti object ke dalam variabel terpisah berdasarkan nama key-nya. Berbeda dengan array destructuring yang menggunakan urutan, object destructuring menggunakan nama properti yang sama. Shorthand property memungkinkan penulisan `{ nama }` sebagai ganti `{ nama: nama }` jika variabel dan key bernama sama. Shorthand method memungkinkan `{ method() {} }` sebagai ganti `{ method: function() {} }`.

## Fungsi
Fitur-fitur ini membuat kode lebih bersih dan mengurangi repetisi. Destructuring object sangat berguna saat menangani parameter fungsi yang berupa object (parameter object pattern). Shorthand membuat deklarasi object lebih ringkas ketika variabel sudah tersedia dengan nama yang sesuai.

## Cara Pengimplementasian
```js
const rumah = {
  nama: "Rumah Hijau",
  luas: 180,
  kamar: 3,
  alamat: "Jl. Damai No. 10"
};

// Destructuring — ambil properti berdasarkan nama key
const { nama, luas, kamar } = rumah;
console.log(nama);  // "Rumah Hijau"
console.log(luas);  // 180
console.log(kamar); // 3

// Destructuring dengan rename
const { nama: namaRumah, luas: ukuran } = rumah;
console.log(namaRumah); // "Rumah Hijau"
console.log(ukuran);    // 180

// Destructuring dengan default value
const { pemilik = "Tidak diketahui" } = rumah;
console.log(pemilik); // "Tidak diketahui"

// Destructuring bersarang (nested)
const detailRumah = { alamat: { kota: "Jakarta", jalan: "Merdeka" } };
const { alamat: { kota } } = detailRumah;
console.log(kota); // "Jakarta"

// Shorthand property
const merek = "Toshiba";
const tipe = "AC Split";
const ac = { merek, tipe }; // sama dengan { merek: merek, tipe: tipe }
console.log(ac); // { merek: "Toshiba", tipe: "AC Split" }

// Shorthand method
const kalkulatorRumah = {
  nama: "Kalkulator",
  tambah(a, b) { return a + b },  // shorthand method
  kurang(a, b) { return a - b }
};

// Destructuring di parameter fungsi
function cetakRumah({ nama, luas, kamar }) {
  console.log(`${nama} — ${luas}m², ${kamar} kamar`);
}
cetakRumah(rumah); // "Rumah Hijau — 180m², 3 kamar"
```

## Analogi
**Membongkar koper setelah perjalanan.**
- **Destructuring:** Kamu membuka koper dan mengeluarkan isinya langsung ke lemari yang sesuai labelnya. Label "baju" -> lemari baju, label "sepatu" -> rak sepatu. Kamu tidak perlu mengeluarkan satu per s atu lalu mengecek labelnya — kamu langsung mencocokkan label dengan tempatnya.
- **Shorthand property:** Kamu sudah punya barang-barang di tangan (variabel). Tinggal kamu masukkan ke lemari dengan label yang sama — tanpa perlu menulis ulang nama barangnya.
- **Shorthand method:** Setiap peralatan elektronik di rumah punya tombol fungsi. Kamu cukup tekan "nyalakan()" — tanpa harus bilang "fungsi: function() { nyalakan }".

## Dipakai Untuk Apa
Destructuring untuk mengambil data dari object API response, parameter fungsi pada komponen React, import modul (`import { useState } from 'react'` adalah destructuring). Shorthand property untuk membuat object konfigurasi dari variabel yang ada. Shorthand method untuk mendefinisikan method di object literal.

## Kesalahan Umum
Lupa bahwa destructuring object menggunakan nama key, bukan urutan — jadi `const { a, b } = obj` akan mengambil properti `a` dan `b` di mana pun posisinya. Mencoba destructuring `null` atau `undefined` — error. Salah rename dengan syntax `{ asli: namaBaru }` (bukan `{ asli: namaBaru }` salah? pola yang benar adalah `{ namaAsli: namaBaru }`). Lupa memberikan default value untuk properti yang mungkin tidak ada.

## Keterkaitan dengan Materi Sebelumnya
Destructuring object (materi ini) adalah pasangan dari destructuring array (materi 22). Object dasar (materi 23) adalah prasyarat. Shorthand banyak digunakan di fungsi arrow dan callback di `map/filter` (materi 20) — misalnya `users.map(({ id, name }) => ...)`.

## Soal Latihan
Dari object `{ nama: "Rumah", warna: "Putih", kamar: 3 }`, gunakan destructuring untuk mengambil `nama` dan `kamar`, lalu gunakan shorthand property untuk membuat object baru `{ nama, warna, kamar }` dari variabel-variabel tersebut.

```js
const data = { nama: "Rumah", warna: "Putih", kamar: 3 };
const { nama, kamar } = data;
const warna = "Biru"; // ganti warna

console.log(rumahBaru); // { nama: "Rumah", warna: "Biru", kamar: 3 }
```
