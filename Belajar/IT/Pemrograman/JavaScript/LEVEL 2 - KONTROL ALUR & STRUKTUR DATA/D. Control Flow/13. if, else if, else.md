# 13. if, else if, else

## Penjelasan
`if`, `else if`, dan `else` adalah struktur kontrol paling dasar di JavaScript untuk mengambil keputusan berdasarkan kondisi boolean. Program akan mengevaluasi ekspresi di dalam tanda kurung `()`, dan jika bernilai `true`, blok kode di dalam kurung kurawal `{}` akan dijalankan. Jika `false`, program akan melanjutkan ke `else if` berikutnya (jika ada) atau ke `else` (jika ada). Kondisi dievaluasi secara berurutan dari atas ke bawah — begitu satu kondisi terpenuhi, sisanya dilewati.

## Fungsi
Struktur ini memungkinkan program bereaksi secara berbeda tergantung pada input atau keadaan. Tanpa `if/else`, program hanya bisa berjalan lurus tanpa kemampuan mengambil keputusan. Ini adalah fondasi dari semua logika percabangan dalam pemrograman.

## Cara Pengimplementasian
```js
const suhuRumah = 30;

if (suhuRumah < 20) {
  console.log("Nyalakan pemanas — rumah terlalu dingin");
} else if (suhuRumah >= 20 && suhuRumah <= 28) {
  console.log("Suhu nyaman, santai saja");
} else {
  console.log("Nyalakan AC — rumah terlalu panas");
}

// if sederhana (tanpa else)
const punyaKunci = true;
if (punyaKunci) {
  console.log("Pintu terbuka, silakan masuk");
}

// Bersarang (nested if)
const sudahMakan = true;
const adaMakanan = false;
if (sudahMakan) {
  if (adaMakanan) {
    console.log("Makan lagi? Kenapa tidak!");
  } else {
    console.log("Sudah kenyang, tidur saja");
  }
} else {
  console.log("Cari makanan dulu");
}
```

## Analogi
**Memilih jalur di lorong rumah.** Kamu berdiri di pintu masuk dan harus memutuskan ke mana akan pergi. "Apakah ada tamu di ruang tamu?" Jika ya (`true`), kamu pergi ke ruang tamu. "Tidak? Apakah lampu di dapur menyala?" Jika ya, kamu ke dapur. "Tidak juga? Kalau begitu, langsung ke kamar tidur saja." Sama seperti `if` — kamu cek satu per satu kondisi, dan hanya satu jalur yang ditempuh.

## Dipakai Untuk Apa
Digunakan di hampir semua program: validasi form login (`if (password === expected)`), menentukan role pengguna (`if (role === "admin")`), navigasi halaman, pengecekan error, logika bisnis (diskon, ongkir), dan pengaturan state aplikasi.

## Kesalahan Umum
Menggunakan `=` (assignment) sebagai ganti `===` (perbandingan) di dalam kondisi — ini akan selalu bernilai truthy. Juga lupa bahwa kondisi dievaluasi berurutan: letakkan kondisi paling spesifik di atas kondisi yang lebih umum. Contoh salah: `if (nilai >= 60) console.log("Lulus"); else if (nilai >= 80) console.log("Lulus dengan pujian")` — nilai 85 akan mencetak "Lulus" saja, bukan "Lulus dengan pujian".

## Keterkaitan dengan Materi Sebelumnya
`if/else` menggunakan truthy/falsy (materi 12) untuk mengevaluasi kondisi. Operator perbandingan (`===`, `>`, `<` — materi 10) dan operator logika (`&&`, `||`, `!` — materi 11) adalah bahan bakar untuk menulis ekspresi kondisi. Variabel (materi 5) menyimpan nilai yang dibandingkan.

## Soal Latihan
Buatlah `if/else` untuk menentukan apakah seseorang bisa masuk rumah berdasarkan tiga kondisi: (1) memiliki kunci, (2) diizinkan oleh pemilik, (3) pintu tidak terkunci. Seseorang boleh masuk jika memiliki kunci ATAU (diizinkan pemilik DAN pintu tidak terkunci).

const punyaKunci = false;
