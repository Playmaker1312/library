# 22. Array Destructuring & Spread Rest

## Penjelasan
Destructuring array adalah sintaks yang memungkinkan "membongkar" nilai dari array ke dalam variabel terpisah dalam satu baris. Spread operator (`...`) menyebarkan elemen array ke tempat lain (seperti menggabungkan array). Rest parameter (`...` di parameter fungsi) mengumpulkan sisa elemen menjadi array. Keduanya adalah fitur ES6 yang membuat kode lebih ekspresif dan ringkas.

## Fungsi
Destructuring menghilangkan kebutuhan menulis `const a = arr[0]; const b = arr[1];` — cukup `const [a, b] = arr`. Spread memudahkan penggabungan dan cloning array tanpa method seperti `concat`. Rest memungkinkan fungsi menerima jumlah argumen tak terbatas dengan elegan.

## Cara Pengimplementasian
```js
// Destructuring array
const ruangan = ["Ruang Tamu", "Kamar Tidur", "Dapur", "Mandi"];
const [ruangPertama, ruangKedua, ...sisaRuangan] = ruangan;
console.log(ruangPertama); // "Ruang Tamu"
console.log(ruangKedua);   // "Kamar Tidur"
console.log(sisaRuangan);  // ["Dapur", "Mandi"]

// Skip elemen dengan koma kosong
const [, , dapur] = ruangan;
console.log(dapur); // "Dapur"

// Spread — menggabungkan dua array
const lantai1 = ["Tamu", "Dapur"];
const lantai2 = ["Tidur", "Mandi"];
const seluruhRumah = [...lantai1, ...lantai2];
console.log(seluruhRumah); // ["Tamu", "Dapur", "Tidur", "Mandi"]

// Spread — cloning array (shallow copy)
const salinan = [...ruangan];
salinan[0] = "Garasi";
console.log(ruangan[0]); // "Ruang Tamu" (tidak berubah)

// Rest parameter di fungsi
function jumlahkanLuas(...ukuran) {
  return ukuran.reduce((a, b) => a + b, 0);
}
console.log(jumlahkanLuas(20, 15, 10, 8)); // 53

// Swap variabel dengan destructuring
let kiri = "kamar", kanan = "dapur";
[kiri, kanan] = [kanan, kiri];
console.log(kiri, kanan); // "dapur", "kamar"
```

## Analogi
**Memindahkan barang dari satu rumah ke rumah lain.**
- **Destructuring:** Kamu membuka kardus pindahan yang berisi 4 barang. Kamu keluarkan barang ke-1 langsung ke rak tamu (`ruangPertama`), barang ke-2 ke rak tidur (`ruangKedua`), dan sisanya (`...sisaRuangan`) kamu taruh di gudang dulu.
- **Spread:** Kamu punya dua kardus dari rumah lama. Kamu tuangkan isi kedua kardus ke satu kardus besar — semua barang dari kardus A dan kardus B sekarang jadi satu.
- **Rest:** Kamu menyediakan lemari kosong dan berkata "masukkan semua barang yang tersisa ke sini" — apapun sisanya, sekian banyak, masuk ke lemari itu.

## Dipakai Untuk Apa
Destructuring untuk mengambil beberapa nilai dari fungsi yang mengembalikan array, swap variabel, parsing data. Spread untuk menggabungkan array, membuat salinan array (immutable pattern di React). Rest parameter untuk fungsi fleksibel seperti `Math.max(...angka)`, logging dengan banyak argumen.

## Kesalahan Umum
Mencoba destructuring `null` atau `undefined` — akan error. Lupa bahwa spread hanya melakukan shallow copy — array yang berisi object masih merujuk ke object yang sama. Menggunakan rest parameter di tengah parameter fungsi — rest harus di posisi terakhir.

## Keterkaitan dengan Materi Sebelumnya
Destructuring dan spread adalah fitur ES6 yang bekerja dengan array (materi 19). Mereka sering digunakan bersama dengan `map/filter/reduce` (materi 20). Operator comparison (materi 10) tidak langsung terkait, tapi konsep "mengumpulkan" mirip dengan bagaimana operator `||` mengumpulkan nilai truthy.

## Soal Latihan
Dari array `["Meja", "Kursi", "Lemari", "Ranjang", "Lampu"]`, gunakan destructuring untuk mengambil "Meja" dan "Kursi", lalu kumpulkan sisanya. Kemudian gunakan spread untuk menggabungkan dua array `[1, 2]` dan `[3, 4, 5]`.
