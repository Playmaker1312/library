# 21. Array Methods Pencarian & Transformasi

## Penjelasan
Selain `map/filter/reduce`, JavaScript memiliki banyak method array untuk pencarian dan transformasi. `find` mengembalikan elemen pertama yang memenuhi kondisi. `findIndex` mengembalikan indeks elemen tersebut. `some` mengecek apakah setidaknya satu elemen memenuhi kondisi (true/false). `every` mengecek apakah semua elemen memenuhi kondisi. `includes` mengecek apakah array memiliki nilai tertentu. `sort` mengurutkan array. `splice` menambah/menghapus elemen di posisi tertentu.

## Fungsi
Method-method ini menyediakan operasi pencarian dan modifikasi array yang siap pakai. Daripada menulis loop manual untuk mencari elemen, memeriksa keberadaan, atau mengurutkan data, kamu bisa memanggil satu method dengan callback atau argumen sederhana.

## Cara Pengimplementasian
```js
const propertiRumah = ["Kolam Renang", "Garasi", "Taman", "Garasi"];

// find — cari properti pertama yang berakhiran "si"
const hasilFind = propertiRumah.find(p => p.endsWith("si"));
console.log(hasilFind); // "Garasi"

// findIndex — cari indeks "Taman"
const idx = propertiRumah.findIndex(p => p === "Taman");
console.log(idx); // 2

// some — apakah ada yang namanya "Taman"?
console.log(propertiRumah.some(p => p === "Taman")); // true

// every — apakah semua properti punya huruf 'a'?
console.log(propertiRumah.every(p => p.includes("a"))); // true

// includes — apakah "Kolam Renang" ada?
console.log(propertiRumah.includes("Kolam Renang")); // true

// sort — urutkan properti secara alfabet
console.log(propertiRumah.sort()); // ["Garasi", "Garasi", "Kolam Renang", "Taman"]

// sort angka — HATI-HATI: default sort ASCII
const angka = [10, 2, 30, 4];
console.log(angka.sort()); // [10, 2, 30, 4] — bukan numerik!
console.log(angka.sort((a, b) => a - b)); // [2, 4, 10, 30] — benar

// splice — hapus "Garasi" kedua dan tambah "Gudang"
propertiRumah.splice(2, 1, "Gudang");
console.log(propertiRumah); // ["Garasi", "Kolam Renang", "Gudang", "Taman"]
// argumen: (indexMulai, jumlahDihapus, ...itemDitambah)
```

## Analogi
**Inventarisasi barang di rumah.**
- **`find`:** Kamu mencari obeng di laci — ambil obeng pertama yang kamu temukan, berhenti mencari.
- **`findIndex`:** Kamu ingin tahu di laci nomor berapa obeng berada.
- **`some`:** Kamu bertanya "apakah ada setidaknya satu paku di kotak alat?" — jawabannya ya/tidak.
- **`every`:** Kamu mengecek "apakah semua lampu di rumah berfungsi?" — semua harus nyala.
- **`includes`:** Kamu mengecek "apakah di rumah ini ada AC?" — ya/tidak.
- **`sort`:** Kamu merapikan buku di rak berdasarkan abjad.
- **`splice`:** Kamu mengeluarkan buku lama dari tengah rak lalu menyelipkan buku baru di posisi yang sama.

## Dipakai Untuk Apa
`find` untuk mencari data spesifik (pengguna dengan ID tertentu), `some` untuk validasi (apakah ada input yang kosong?), `every` untuk cek kelengkapan (apakah semua field terisi?), `sort` untuk mengurutkan daftar (harga, tanggal, nama), `splice` untuk manipulasi data di posisi tertentu (tambah/hapus item di tengah array).

## Kesalahan Umum
Lupa bahwa `sort()` default mengubah angka menjadi string dan mengurutkan secara ASCII — `"10"` lebih kecil dari `"2"` secara ASCII! Selalu berikan comparator function `(a, b) => a - b` untuk angka. Juga lupa bahwa `splice` mengubah array asli (tidak immutable). `find` mengembalikan `undefined` jika tidak ditemukan — perlu penanganan.

## Keterkaitan dengan Materi Sebelumnya
Method ini seperti `map/filter/reduce` (materi 20) menerima callback. Truthy/falsy (materi 12) digunakan dalam `some` dan `every`. Operator perbandingan (materi 10) digunakan sebagai comparator di `sort`. Array dasar (materi 19) adalah prasyarat.

## Soal Latihan
Dari array `[8, 3, 12, 5, 9]`, cari apakah semua angka lebih dari 2 (`every`), cari angka pertama yang lebih dari 10 (`find`), dan urutkan dari terbesar ke terkecil.

<details>
<summary>Jawaban</summary>

```js
const angka = [8, 3, 12, 5, 9];

console.log(angka.every(a => a > 2)); // true
console.log(angka.find(a => a > 10)); // 12
console.log(angka.sort((a, b) => b - a)); // [12, 9, 8, 5, 3]
```
