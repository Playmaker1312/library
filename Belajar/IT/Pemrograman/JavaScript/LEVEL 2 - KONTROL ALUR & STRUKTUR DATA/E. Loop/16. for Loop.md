# 16. for Loop

## Penjelasan
`for` loop adalah struktur perulangan yang paling sering digunakan di JavaScript. Ia memiliki tiga ekspresi dalam tanda kurung: inisialisasi (`let i = 0`), kondisi (`i < n`), dan increment/decrement (`i++`). Selama kondisi bernilai `true`, blok kode di dalam kurung kurawal akan terus dijalankan. Ketiga ekspresi ini memberikan kontrol penuh atas kapan loop dimulai, kapan berhenti, dan bagaimana counter berubah setiap iterasi.

## Fungsi
`for` loop digunakan ketika kamu tahu persis berapa kali sebuah blok kode harus diulang — misalnya, memproses setiap elemen array yang diketahui panjangnya, atau menghitung jumlah dari rentang angka tertentu.

## Cara Pengimplementasian
```js
// Menghitung jumlah ruangan di rumah — 1 sampai 5
for (let ruang = 1; ruang <= 5; ruang++) {
  console.log(`Membersihkan ruang ke-${ruang}`);
}

// Iterasi array
const kamar = ["Tidur", "Mandi", "Tamu", "Dapur"];
for (let i = 0; i < kamar.length; i++) {
  console.log(`Kamar ${kamar[i]} sudah dibersihkan`);
}

// Loop mundur
for (let lantai = 5; lantai >= 1; lantai--) {
  console.log(`Turun dari lantai ${lantai}`);
}

// for dengan break
for (let i = 0; i < 10; i++) {
  if (i === 3) {
    console.log("Berhenti di kamar ke-3");
    break;
  }
  console.log(`Cek kamar ke-${i}`);
}
```

## Analogi
**Berkeliling rumah untuk membersihkan setiap kamar.** Kamu mulai dari kamar pertama (inisialisasi `let kamar = 1`), lalu selama kamar yang kamu kunjungi belum melebihi total kamar (kondisi `kamar <= totalKamar`), kamu bersihkan kamar itu (blok kode). Setelah selesai, kamu pindah ke kamar berikutnya (`kamar++`). Begitu terus sampai semua kamar bersih — atau kamu memutuskan berhenti di tengah jalan.

## Dipakai Untuk Apa
Iterasi array, perhitungan matematis (faktorial, deret angka), rendering daftar item di UI, validasi berulang, pencarian data dalam koleksi, dan semua skenario yang membutuhkan perulangan dengan counter yang jelas.

## Kesalahan Umum
Lupa menaikkan counter (`i++`) sehingga terjadi infinite loop. Juga kesalahan off-by-one: menggunakan `<=` saat seharusnya `<` (atau sebaliknya). Mendeklarasi variabel dengan `var` di dalam for (yang bocor ke global scope) — sebaiknya gunakan `let`. Mengubah array yang sedang di-loop (menambah/menghapus elemen) yang menyebabkan indeks tidak sinkron.

## Keterkaitan dengan Materi Sebelumnya
