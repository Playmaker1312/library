# Prototype Chain

## Penjelasan
Prototype chain adalah mekanisme JavaScript di mana setiap objek memiliki _hidden property_ bernama `[[Prototype]]` yang merujuk ke objek lain. Ketika properti tidak ditemukan di objek saat ini, JavaScript naik ke prototype induknya, terus hingga mencapai `null`. Ini mirip dengan warisan cetak biru — seorang arsitek punya cetak biru utama, yang menurunkan detail ke cetak biru turunan, dan seterusnya.

## Fungsi
- Memungkinkan pewarisan properti dan method antar objek tanpa duplikasi kode.
- Mendukung _property lookup_ efisien melalui rantai objek.

## Cara Pengimplementasian

```javascript
// Prototype Chain — analogi RUMAH
// Blueprint utama
const blueprintDasar = {
  punyaAtap: true,
  info() {
    return `Rumah ${this.tipe} dengan ${this.kamar} kamar`;
  }
};

// Blueprint turunan — prototype chain
const blueprintRumah = Object.create(blueprintDasar);
blueprintRumah.tipe = "Minimalis";
blueprintRumah.kamar = 3;

// Rumah jadi — object dari blueprint turunan
const rumahA = Object.create(blueprintRumah);
rumahA.warna = "Putih";

console.log(rumahA.warna);      // "Putih" — dari objek sendiri
console.log(rumahA.tipe);       // "Minimalis" — naik ke blueprintRumah
console.log(rumahA.punyaAtap);  // true — naik ke blueprintDasar
console.log(rumahA.info());     // "Rumah Minimalis dengan 3 kamar" — method dari blueprintDasar
console.log(Object.getPrototypeOf(rumahA) === blueprintRumah); // true

// Cek rantai prototype
console.log(rumahA.toString);   // naik terus hingga Object.prototype
```

## Analogi
Prototype chain = **rantai cetak biru rumah**. Cetak biru utama (Object.prototype) punya aturan dasar (toString, hasOwnProperty). Turunannya (blueprintRumah) menambahkan spesifikasi. Rumah jadi (rumahA) tinggal pakai. Jika tukang tidak menemukan instruksi di lembar rumah, dia lihat cetak biru turunan, lalu cetak biru utama.

## Dipakai Untuk Apa
- Menambahkan method ke semua instance via `Constructor.prototype.method`
- Membangun hierarki pewarisan sebelum ES6 Class
- Polyfilling — menambahkan method ke prototype bawaan (hati-hati)

## Kesalahan Umum
- Mengira `__proto__` sama dengan `prototype` (berbeda)
- Memodifikasi `Object.prototype` secara global (berbahaya)
- Tidak memahami bahwa `for...in` juga melintasi prototype chain
- Mengubah prototype setelah instance dibuat bisa menyebabkan kebingungan

## Keterkaitan dengan Materi Sebelumnya
Di Level 3, closure mempertahankan aksi ke scope terdahulu — mirip dengan prototype chain yang mempertahankan akses ke objek induk. Bedanya, closure menjaga _scope variable_, sedangkan prototype chain menjaga _rantai properti objek_.

## Soal Latihan

Apa output dari kode berikut?

```javascript
const a = { x: 1 };
const b = Object.create(a);
const c = Object.create(b);
c.x = 5;
console.log(c.x);
delete c.x;
console.log(c.x);
```

>!`5` lalu `1`. Saat `c.x = 5`, properti x dibuat di c, menutupi x dari a. Setelah dihapus (`delete c.x`), lookup naik ke prototype chain dan menemukan `x: 1` di objek a.!
