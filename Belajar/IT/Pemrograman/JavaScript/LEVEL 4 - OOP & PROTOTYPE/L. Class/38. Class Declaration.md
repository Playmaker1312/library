# Class Declaration

## Penjelasan
Class declaration (ES6) adalah sintaksis gula (_syntactic sugar_) di atas prototype dan constructor function. Class mendefinisikan _blueprint_ objek dengan cara yang lebih bersih dan mirip bahasa OOP klasik. Keyword `class`, `constructor`, `method`, `static`, `getter`/`setter` menjadi fondasi penulisan kode berorientasi objek modern. Ibarat template rumah modern: bukan lagi cetak biru kertas, melainkan file digital yang bisa langsung dipakai.

## Fungsi
- Membuat blueprint objek dengan sintaksis yang rapi dan mudah dibaca.
- Mendukung getter, setter, static method, dan private field (#).
- Mempermudah pewarisan dengan `extends`.

## Cara Pengimplementasian

```javascript
// Class Declaration — analogi TEMPLATE RUMAH MODERN
class Rumah {
  // Constructor: proses pembangunan awal
  constructor(tipe, kamar, warna) {
    this.tipe = tipe;
    this.kamar = kamar;
    this.warna = warna;
    this._listrikMenyala = false;
  }

  // Method instance
  info() {
    return `${this.warna} ${this.tipe} dengan ${this.kamar} kamar`;
  }

  // Getter — properti virtual
  get statusListrik() {
    return this._listrikMenyala ? "Menyala" : "Mati";
  }

  // Setter
  set statusListrik(kondisi) {
    this._listrikMenyala = kondisi === "nyala";
  }

  // Static method — method milik class, bukan instance
  static kategori() {
    return "Tempat Tinggal";
  }
}

// Instance: rumah jadi dari template
const rumah1 = new Rumah("Minimalis", 3, "Putih");
const rumah2 = new Rumah("Joglo", 5, "Coklat");

console.log(rumah1.info());               // "Putih Minimalis dengan 3 kamar"
console.log(rumah2.info());               // "Coklat Joglo dengan 5 kamar"
console.log(Rumah.kategori());            // "Tempat Tinggal" — static
console.log(typeof Rumah);                // "function" — class tetaplah function
console.log(rumah1 instanceof Rumah);     // true

// Getter/setter
rumah1.statusListrik = "nyala";
console.log(rumah1.statusListrik);        // "Menyala"
```

## Analogi
Class = **template rumah digital di komputer arsitek**. Template (`Rumah`) berisi spesifikasi lengkap (constructor), fitur-fitur (method), dan alat ukur (getter/setter). Setiap rumah jadi (instance) adalah bangunan nyata dari template yang sama. Static method adalah alat di kantor arsitek — tidak perlu rumah jadi untuk menggunakannya.

## Dipakai Untuk Apa
- Semua proyek JavaScript modern yang butuh OOP
- Framework seperti Angular, React (class component sebelum hooks)
- Aplikasi berskala besar dengan hierarki objek yang jelas

## Kesalahan Umum
- Mengira `class` adalah tipe data baru (masih `function`)
- Lupa memanggil `super()` di class turunan
- Menempatkan koma di antara method class (tidak seperti object literal)
- Menganggap method class ada di instance — mereka tetap di prototype

## Keterkaitan dengan Materi Sebelumnya
Level 3 membahas function declaration & expression. Class declaration mengikuti hoisting berbeda — class tidak di-hoist seperti function declaration. Anda harus mendeklarasikan class sebelum menggunakannya. Ini mengingatkan pada `const` dan `let` di Level 2 yang juga tidak di-hoist.

## Soal Latihan

Apa outputnya?

```javascript
class Rumah {
  constructor(warna) {
    this.warna = warna;
  }
  info() {
    return `Rumah ${this.warna}`;
  }
}

const r = new Rumah("Biru");
console.log(r.hasOwnProperty("info"));
console.log(Rumah.prototype.hasOwnProperty("info"));
```

>!`false` lalu `true`. Method `info` ditempatkan di `Rumah.prototype`, bukan di instance. Instance `r` hanya punya properti `warna` miliknya sendiri.!
