### Definisi Singkat

`performance.now()` adalah metode pada `Performance` API yang mengembalikan timestamp presisi tinggi (dalam milidetik) sejak page start. Berbeda dengan `Date.now()`, ia memberikan resolusi sub-milidetik (fraksional) dan tidak terpengaruh oleh penyesuaian jam sistem. Cocok untuk benchmarking kode.

---

### Analogi

Bayangkan **stopwatch laboratorium** yang bisa mengukur waktu hingga seperseribu detik. `Date.now()` seperti jam dinding yang hanya menunjukkan menit; `performance.now()` seperti stopwatch digital presisi tinggi untuk mengukur durasi sprint.

---

### Poin-Poin Pentering

- Mengembalikan `DOMHighResTimeStamp` dalam milidetik (termasuk pecahan, misal `12.123456789`).
- Bersifat monotonik (tidak pernah mundur) — bebas dari skew jam sistem.
- Dapat digunakan bersama `PerformanceObserver` untuk tracing otomatis.
- Di Web Worker juga tersedia melalui `performance.now()`.
- Untuk mengukur durasi: simpan nilai awal, lalu kurangi dengan nilai akhir.

---

### Contoh Implementasi

```javascript
const start = performance.now();

// Kode yang ingin diukur performanya
for (let i = 0; i < 1000000; i++) {
  Math.sqrt(i);
}

const end = performance.now();
console.log(`Loop selesai dalam ${(end - start).toFixed(2)} ms`);

// Benchmark banyak sampel
function benchmark(fn, iterations = 1000) {
  const samples = [];
  for (let i = 0; i < iterations; i++) {
    const t0 = performance.now();
    fn();
    const t1 = performance.now();
    samples.push(t1 - t0);
  }
  const avg = samples.reduce((a, b) => a + b) / samples.length;
  console.log(`Rata-rata: ${avg.toFixed(4)} ms`);
}
```

### Koneksi

Berhubungan erat dengan **Critical Rendering Path** (monitoring render), **requestAnimationFrame** (sinkronisasi frame), dan **DevTools Performance** panel. Dipakai juga di framework testing seperti Jest (`jest.useFakeTimers` menggantikan `performance.now`).
