### Definisi Singkat

**Web Worker** adalah mekanisme untuk menjalankan kode JavaScript di thread terpisah dari main thread browser. Ini memungkinkan operasi berat (komputasi, parsing data) berjalan tanpa memblokir UI. Komunikasi antara main thread dan worker dilakukan via **message passing** (`postMessage` / `onmessage`).

---

### Analogi

Seperti **restoran dengan dapur terpisah** — pelayan (main thread) tetap melayani pelanggan (UI) tanpa terganggu oleh aktivitas memasak (komputasi berat) yang dilakukan chef di dapur (worker). Mereka berkomunikasi melalui **papan pesan** (message passing).

---

### Poin-Poin Penting

- Worker tidak punya akses ke DOM, `window`, `document`, atau `parent`.
- Komunikasi dua arah via `postMessage()` dan event `message`.
- Worker bisa dihentikan dengan `worker.terminate()`.
- Ada **Dedicated Worker** (satu pemilik), **Shared Worker** (dibagi antar tab), dan **Service Worker** (proxy jaringan).
- Data yang dikirim di-**clone** (structured clone algorithm) — bukan referensi.
- Transferable objects (ArrayBuffer) bisa dikirim tanpa salinan untuk performa lebih baik.

---

### Contoh Implementasi

```javascript
// main.js
const worker = new Worker('worker.js');

worker.postMessage({ data: new Array(1000000).fill(42) });

worker.onmessage = (event) => {
  console.log('Hasil dari worker:', event.data);
};

// worker.js
self.onmessage = (event) => {
  const { data } = event.data;
  const result = data.reduce((acc, val) => acc + val, 0);
  self.postMessage(result);
};
```

---

### Koneksi

Berkaitan dengan **Event Loop** (worker punya event loop sendiri), **Service Worker** (jenis khusus worker untuk PWA), **Performance** (offloading komputasi berat), dan **WebRTC** (processing stream data).
