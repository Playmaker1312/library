### Definisi Singkat

**Memoization** adalah teknik caching hasil fungsi berdasarkan argumennya. **WeakMap cache** adalah varian lanjutan yang menggunakan `WeakMap` sebagai penyimpanan, memungkinkan garbage collection otomatis pada key yang tidak lagi direferensi di tempat lain — ideal untuk caching objek tanpa menyebabkan memory leak.

---

### Analogi

Seperti **koki yang mencatat resep** di papan tulis. Jika pelanggan memesan menu yang sama, ia tinggal melihat catatan daripada memasak ulang. WeakMap seperti **papan tulis ajaib** — coretan akan terhapus sendiri jika pelanggan sudah pergi (objek tidak lagi dirujuk).

---

### Poin-Poin Penting

- `Map` biasa mempertahankan referensi ke key — bisa menyebabkan memory leak jika key adalah objek besar.
- `WeakMap` hanya menerima objek sebagai key dan tidak mencegah garbage collection.
- Cocok untuk caching hasil fungsi yang menerima objek sebagai argumen.
- Tidak bisa di-iterasi (tidak punya `.size`, `.entries()`, dll) — murni untuk lookup.
- Pola "memoize with WeakMap" populer untuk pure function dengan argumen objek.

---

### Contoh Implementasi

```javascript
const memoizeWeak = (fn) => {
  const cache = new WeakMap();
  return (obj) => {
    if (cache.has(obj)) {
      console.log('Cache hit');
      return cache.get(obj);
    }
    const result = fn(obj);
    cache.set(obj, result);
    return result;
  };
};

const computeExpensive = (data) => {
  // Simulasi kalkulasi berat
  return Object.values(data).reduce((acc, val) => acc + val, 0);
};

const memoizedCompute = memoizeWeak(computeExpensive);

const obj1 = { a: 1, b: 2, c: 3 };
console.log(memoizedCompute(obj1)); // Hitung
console.log(memoizedCompute(obj1)); // Cache hit — tanpa kalkulasi ulang

// Ketika obj1 tidak lagi direferensi, entry di WeakMap akan di-GC
```

---

### Koneksi

Berkaitan dengan **Garbage Collection** (WeakMap tidak menghalangi GC), **Hidden Classes** (V8 optimasi untuk property lookup), dan **React memo / useMemo** (caching komponen dan nilai).
