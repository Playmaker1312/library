### Definisi Singkat

**Critical Rendering Path (CRP)** adalah urutan langkah yang dilakukan browser untuk mengubah HTML, CSS, dan JavaScript menjadi piksel di layar. Memahami CRP adalah kunci mengoptimalkan **perceived performance** — terutama **First Contentful Paint (FCP)** dan **Time to Interactive (TTI)**.

---

### Analogi

Seperti **jalur perakitan pabrik mobil** — rangka (HTML) datang, dicat (CSS), dipasang mesin (JavaScript), lalu diperiksa (layout), dan akhirnya dikirim (paint). Jika satu stasiun lambat, seluruh produksi terhambat.

---

### Poin-Poin Penting

- Urutan CRP: **DOM → CSSOM → Render Tree → Layout → Paint → Composite**.
- CSS dianggap **render-blocking** — browser tidak akan me-render sampai CSSOM selesai dibangun.
- **Script tag** (tanpa `defer`/`async`) adalah **parser-blocking** — menghentikan pembangunan DOM.
- Gunakan `defer` (untuk script yang perlu DOM) atau `async` (untuk script independen).
- **Kritis**: resource yang dibutuhkan untuk render awal — optimalkan dengan inline CSS kritis dan lazy load sisanya.
- Metrik utama: **FCP**, **LCP** (Largest Contentful Paint), **TBT** (Total Blocking Time).

---

### Contoh Implementasi

```html
<!-- Deklarasi CSS kritis inline, sisanya async -->
<head>
  <style>
    /* CSS kritis untuk above-the-fold */
    header { display: flex; ... }
    .hero { min-height: 100vh; ... }
  </style>
  <link rel="preload" href="styles.css" as="style" onload="this.rel='stylesheet'">
</head>

<body>
  <header>Konten di atas fold</header>

  <!-- Script dimuat async agar tidak menghalangi rendering -->
  <script defer src="app.js"></script>
</body>
```

```javascript
// Mengukur CRP dengan Performance API
const paintEntries = performance.getEntriesByType('paint');
paintEntries.forEach((entry) => {
  console.log(`${entry.name}: ${entry.startTime}ms`);
});
```

### Koneksi

Berkaitan dengan **requestAnimationFrame** (berjalan setelah CRP selesai), **Lazy Loading** (mengurangi resource blocking), **Performance Metrics** (FCP, LCP, TTI), dan **Web Vitals** (Core Web Vitals Google).
