### Definisi Singkat

Di dalam JavaScript, _Truthy_ (benar) dan _Falsy_ (salah) adalah nilai yang secara otomatis dikonversi menjadi tipe Boolean ketika dievaluasi di dalam konteks logika, seperti pada pernyataan kondisi `if` atau operator ternary. Nilai _Falsy_ adalah nilai yang jika diubah ke bentuk Boolean akan bernilai `false`, sedangkan nilai _Truthy_ adalah semua nilai lainnya yang tidak termasuk dalam daftar _Falsy_.

---

### Analogi

Bayangkan perbedaan ini seperti **pemeriksaan lampu indikator baterai pada gawai Anda**:

- **Falsy** seperti **baterai kosong (0%)**: tidak ada energi atau nilai sama sekali di dalamnya.
    
- **Truthy** seperti **baterai yang memiliki daya (lebih dari 0%)**: berapapun persentase dayanya, baterai tersebut dianggap ada atau aktif.
    

---

### Poin-Poin Penting

- **Daftar Nilai Falsy:** Hanya ada **6 nilai falsy** di dalam JavaScript:
    
    - `false` (nilai boolean yang sebenarnya)
        
    - `0` (angka nol) dan `-0` (angka nol negatif)
        
    - `0n` (BigInt untuk angka nol)
        
    - `""` atau `''` atau ` `` ` (string kosong)
        
    - `null`
        
    - `undefined`
        
    - `NaN` (_Not a Number_)
        
- **Truthy Values:** Semua nilai selain keenam nilai di atas adalah _Truthy_. Contohnya:
    
    - Angka selain nol (misal: `1`, `-1`, `3.14`)
        
    - String yang berisi karakter (misal: `"0"`, `"false"`, `"hello"`)
        
    - Array baru (`[]`) maupun objek baru (`{}`)
        

---

### Contoh Implementasi

Mari kita lihat bagaimana JavaScript mengevaluasi nilai-nilai ini ketika dimasukkan ke dalam kondisi `if`:

JavaScript

```
// 1. Contoh Falsy Values
// Kondisi di bawah ini tidak akan pernah dieksekusi
if (0) {
    console.log("Ini tidak akan dicetak (0 adalah falsy).");
}

if ("") {
    console.log("Ini tidak akan dicetak (string kosong adalah falsy).");
}

// 2. Contoh Truthy Values
// Walaupun angkanya negatif atau berupa string, JavaScript menganggapnya truthy
if (-5) {
    console.log("-5 adalah Truthy!");
}

if ("false") {
    console.log("Teks 'false' adalah Truthy, karena ini bukan string kosong!");
}

// 3. Pengecekan praktis
let namaPengguna = "Budi";

if (namaPengguna) {
    console.log("Halo, " + namaPengguna); // Akan dieksekusi karena string tidak kosong
}
```

### Koneksi

Dalam bidang **Web Development**, pemahaman tentang _truthy_ dan _falsy_ sangat berguna untuk berbagai kebutuhan berikut:

- **Validasi Input:** Memastikan apakah sebuah formulir (_form_) telah diisi oleh pengguna sebelum data dikirim ke server.
    
- **Pengaturan _State_:** Menampilkan komponen seperti pesan _loading_ atau daftar kosong jika data yang diterima dari API belum tersedia (`null` atau `undefined`).
