# 32. Nested if - kondisi bersarang

**Definisi Singkat:** Kondisi `if` di dalam blok `if` lain untuk mengecek sub-kondisi.

**Analogi:** Seperti "jika punya uang, jika tokonya buka, beli es krim" — dua kondisi berjenjang.

**Poin-Poin Penting:**
- Gunakan nested `if` dengan hati-hati agar kode tetap terbaca
- Semakin dalam nesting, semakin sulit di-debug
- Alternatif: gunakan `&&` logical operator untuk menyederhanakan

**Contoh Kode:**
```javascript
const isLoggedIn = true;
const isAdmin = true;
if (isLoggedIn) {
  if (isAdmin) {
    console.log("Akses panel admin diberikan");
  } else {
    console.log("Akses terbatas");
  }
}
```
Hasil: `Akses panel admin diberikan`

**Kasus Penggunaan Nyata:**
Otorisasi multi-level di aplikasi web (user biasa vs admin).
