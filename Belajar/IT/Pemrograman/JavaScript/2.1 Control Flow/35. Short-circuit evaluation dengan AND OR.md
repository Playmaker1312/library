# 35. Short-circuit evaluation dengan AND OR

**Definisi Singkat:** JavaScript berhenti mengevaluasi operator logika (`&&`, `||`) begitu hasil sudah pasti.

**Analogi:** `||` seperti "coba pintu pertama, kalau terbuka masuk, kalau tidak coba pintu kedua".

**Poin-Poin Penting:**
- `||` mengembalikan nilai truthy pertama atau falsy terakhir
- `&&` mengembalikan nilai falsy pertama atau truthy terakhir
- Sering digunakan untuk default value dan conditional rendering
- Bisa menggantikan `if` sederhana

**Contoh Kode:**
```javascript
const userName = "";
const displayName = userName || "Tamu";
console.log(displayName);

const isAdmin = true;
isAdmin && console.log("Menu admin ditampilkan");
```
Hasil: `Tamu` lalu `Menu admin ditampilkan`

**Kasus Penggunaan Nyata:**
Memberi default value saat data undefined, render komponen hanya jika kondisi terpenuhi di React.
