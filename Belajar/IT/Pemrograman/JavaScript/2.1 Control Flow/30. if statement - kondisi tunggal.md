# 30. if statement - kondisi tunggal

**Definisi Singkat:** `if` menjalankan blok kode hanya jika kondisi bernilai `true`.

**Analogi:** Seperti "jika hujan, bawa payung" — aksi hanya dilakukan jika kondisi terpenuhi.

**Poin-Poin Penting:**
- Kondisi ditulis dalam tanda kurung `()`
- Blok kode dalam kurung kurawal `{}`
- Jika kondisi `false`, blok dilewati sepenuhnya
- Gunakan operator perbandingan (`===`, `>`, `<`, dll)

**Contoh Kode:**
```javascript
const age = 18;
if (age >= 17) {
  console.log("Kamu sudah bisa bikin SIM");
}
```
Hasil: `Kamu sudah bisa bikin SIM`

**Kasus Penggunaan Nyata:**
Cek apakah user sudah login sebelum menampilkan halaman profil.
