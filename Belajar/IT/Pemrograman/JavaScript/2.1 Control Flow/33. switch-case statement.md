### Definisi Singkat

Pernyataan `switch-case` adalah struktur kontrol di dalam JavaScript yang digunakan untuk mengevaluasi suatu nilai dan membandingkannya dengan beberapa pilihan (_case_). Struktur ini merupakan alternatif yang lebih rapi dari `else-if` ketika Anda perlu mencocokkan satu variabel dengan banyak kemungkinan nilai tertentu.

---

### Analogi

Bayangkan seperti **mesin penjual otomatis (_vending machine_)**:

- Anda memasukkan satu pilihan (misalnya, menekan tombol "B3").
    
- Mesin akan mencocokkan tombol tersebut dengan daftar pilihan yang ada di dalamnya. Jika cocok dengan pilihan B3, mesin akan mengeluarkan produk yang sesuai (misalnya, Susu Cokelat).
    
- Jika tidak ada tombol yang cocok dengan input Anda, mesin akan mengeluarkan produk _default_ (misalnya, "Pilihan tidak tersedia").
    

---

### Poin-Poin Penting

- **Sintaks Dasar:**
    
    JavaScript
    
    ```
    switch (ekspresi) {
        case nilai1:
            // Blok kode jika ekspresi === nilai1
            break;
        case nilai2:
            // Blok kode jika ekspresi === nilai2
            break;
        default:
            // Blok kode jika tidak ada case yang cocok
    }
    ```
    
- **Keyword `break`:** Berfungsi untuk menghentikan evaluasi setelah _case_ yang cocok ditemukan. Jika Anda lupa menuliskan `break`, JavaScript akan terus menjalankan _case_ di bawahnya (disebut sebagai _fall-through_).
    
- **Keyword `default`:** Berfungsi sebagai pilihan akhir yang akan dijalankan jika tidak ada satu pun _case_ yang cocok dengan nilai ekspresi.
    
- **Perbandingan Ketat:** `switch-case` menggunakan perbandingan ketat (identik dengan operator `===`), sehingga tipe data juga harus sama persis.
    

---

### Contoh Implementasi

Berikut adalah contoh penggunaan `switch-case` untuk menampilkan nama hari berdasarkan nomor hari:

JavaScript

```
let nomorHari = 3;
let namaHari;

switch (nomorHari) {
    case 1:
        namaHari = "Senin";
        break;
    case 2:
        namaHari = "Selasa";
        break;
    case 3:
        namaHari = "Rabu";
        break;
    case 4:
        namaHari = "Kamis";
        break;
    case 5:
        namaHari = "Jumat";
        break;
    case 6:
        namaHari = "Sabtu";
        break;
    case 7:
        namaHari = "Minggu";
        break;
    default:
        namaHari = "Nomor hari tidak valid";
}

console.log(namaHari); // Output: Rabu
```

### Koneksi

Dalam bidang **Web Development**, `switch-case` sangat efektif digunakan dalam beberapa skenario berikut:

- **Menangani _Action_ pada Redux (State Management):** Mengelola perubahan state (_reducer_) pada aplikasi React atau Redux berdasarkan tipe aksi tertentu.
    
- **Memproses Input dari Pengguna (Routing/Navigasi):** Menentukan halaman atau fungsi mana yang harus dipanggil berdasarkan status tertentu (misalnya, status _loading_, _success_, atau _error_).
