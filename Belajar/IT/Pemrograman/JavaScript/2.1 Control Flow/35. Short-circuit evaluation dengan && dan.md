### Definisi Singkat

_Short-circuit evaluation_ (evaluasi hubungan pendek) adalah perilaku dalam JavaScript di mana operator logika `&&` (AND) dan `||` (OR) berhenti mengevaluasi ekspresi lebih lanjut begitu hasil kebenarannya sudah dapat dipastikan dari kondisi pertama.

---

### Analogi

Bayangkan seperti **pemeriksaan antrean masuk ke konser musik dengan dua jalur pintu yang berbeda**:

- **Operator `&&` (AND):** Ada dua petugas yang memeriksa tiket. Petugas pertama memeriksa tiket utama. Jika tiket utama tidak valid, petugas tidak perlu memanggil petugas kedua karena Anda sudah pasti ditolak masuk.
    
- **Operator `||` (OR):** Anda memiliki dua cara pembayaran: tunai atau voucher. Jika kasir memeriksa pembayaran tunai dan ternyata hasilnya valid (uangnya cukup), ia tidak perlu lagi memeriksa apakah Anda memiliki voucher atau tidak.
    

---

### Poin-Poin Penting

- **Operator AND (`&&`):**
    
    - Jika operand pertama bernilai **Falsy**, JavaScript tidak akan mengevaluasi operand kedua dan langsung mengembalikan nilai operand pertama.
        
    - Jika operand pertama bernilai **Truthy**, JavaScript akan mengevaluasi dan mengembalikan nilai dari operand kedua.
        
- **Operator OR (`||`):**
    
    - Jika operand pertama bernilai **Truthy**, JavaScript tidak akan mengevaluasi operand kedua dan langsung mengembalikan nilai operand pertama.
        
    - Jika operand pertama bernilai **Falsy**, JavaScript akan mengevaluasi dan mengembalikan nilai dari operand kedua.
        
- **Keuntungan:** Membantu kita menulis instruksi bersyukur (_conditional execution_) dengan ringkas tanpa menggunakan `if-else`.
    

---

### Contoh Implementasi

Berikut adalah contoh penggunaan evaluasi _short-circuit_ menggunakan operator `&&` dan `||` di dalam JavaScript:

#### 1. Contoh Short-circuit dengan `&&` (Sering digunakan untuk _Conditional Rendering_):

Ekspresi di sebelah kanan hanya akan dijalankan atau ditampilkan jika kondisi di sebelah kiri bernilai `true`.

JavaScript

```
let isLogin = true;
let pesanSelamat = "Selamat datang kembali!";

// Jika isLogin bernilai true, maka pesanSelamat akan dievaluasi dan dicetak
isLogin && console.log(pesanSelamat); 
// Output: Selamat datang kembali!

// Jika isLogin bernilai false, konsol tidak akan mengevaluasi fungsi setelahnya
isLogin = false;
isLogin && console.log(pesanSelamat); // Tidak terjadi apa-apa
```

#### 2. Contoh Short-circuit dengan `||` (Sering digunakan untuk _Default Value_):

Digunakan untuk memberikan nilai pengganti jika data pertama bernilai _falsy_.

JavaScript

```
let dataDariServer = null; // Data kosong (falsy value)
let dataDefault = "Pengguna Tamu";

// Karena dataDariServer bernilai falsy, JavaScript mengambil dataDefault
let dataTampilan = dataDariServer || dataDefault;

console.log(dataTampilan); // Output: Pengguna Tamu
```

---

### Koneksi

Dalam bidang **Web Development**, _short-circuit evaluation_ adalah teknik yang sangat penting untuk:

- **Conditional Rendering (terutama di React dan JSX):** Menampilkan elemen antarmuka pengguna hanya jika suatu kondisi terpenuhi (misalnya, menampilkan ikon _loading_ saat data sedang diambil).
    
- **Menyediakan Nilai Cadangan / Default:** Sebelum adanya operator _Nullish Coalescing_ (`??`), _short-circuit_ dengan `||` sering digunakan untuk menetapkan nilai awal saat memproses input atau respons API.
