# 10. Anggota keluarga (Family members)

## Definisi & Target
Mengenal nama anggota keluarga inti dan keluarga besar dalam Bahasa Inggris. Target: mampu memperkenalkan anggota keluarga.

## Analogi
Seperti pohon keluarga — setiap orang punya sebutan khusus.

## Daftar Kosakata

**Keluarga Inti (Immediate Family)**
| Indonesia | English |
|-----------|---------|
| Ayah / Bapak | Father / Dad |
| Ibu | Mother / Mom |
| Kakak laki-laki | Brother |
| Kakak perempuan | Sister |
| Anak laki-laki | Son |
| Anak perempuan | Daughter |
| Suami | Husband |
| Istri | Wife |

**Keluarga Besar (Extended Family)**
| Indonesia | English |
|-----------|---------|
| Kakek | Grandfather / Grandpa |
| Nenek | Grandmother / Grandma |
| Paman | Uncle |
| Bibi | Aunt |
| Sepupu laki-laki | Cousin (male) |
| Sepupu perempuan | Cousin (female) |
| Keponakan laki-laki | Nephew |
| Keponakan perempuan | Niece |
| Cucu | Grandchild / Grandson / Granddaughter |

## Contoh
- "My **mother** is a teacher."
- "I have one **brother** and two **sisters**."
- "My **grandfather** is 70 years old."

## Latihan
1. Gambar pohon keluargamu dan beri label dalam Bahasa Inggris.
2. Perkenalkan 3 anggota keluargamu. Contoh: "This is my father. His name is ..."
3. Apa sebutan untuk anak dari paman/bibi? (cousin)
4. Bedakan *nephew* dan *niece*.
