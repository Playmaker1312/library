# 336. English for Information Technology

## Definisi & Target
Mempelajari terminology dan komunikasi teknis dalam dunia IT — programming, networking, cybersecurity, dan DevOps. Target: mampu membaca documentation, code review, dan technical discussion.

## Analogi
English for IT seperti "keyboard shortcut" di dunia coding — tanpa ini, workflow jadi lambat dan rentan error.

## Daftar Istilah & Frasa

| Istilah | Arti | Contoh Kalimat |
|---------|------|----------------|
| Deployment | Peluncuran aplikasi ke production | "The deployment is scheduled for Friday at 2 AM." |
| Refactoring | Restrukturisasi kode tanpa ubah fungsi | "The code needs refactoring to improve readability." |
| Scalability | Skalabilitas — kemampuan sistem menangani growth | "We need to ensure scalability as user base grows." |
| Latency | Waktu tunda transfer data | "High latency is causing slow response times." |
| API endpoint | URL spesifik untuk interaksi API | "The GET /users endpoint returns all registered users." |
| Version control | Manajemen versi kode | "We use Git for version control and collaboration." |
| Continuous integration | Integrasi berkelanjutan (CI) | "CI pipeline runs automated tests on every push." |
| Authentication vs Authorization | Autentikasi (siapa kamu) vs Otorisasi (apa yang boleh kamu akses) | "OAuth handles both authentication and authorization." |
| Agile methodology | Metodologi pengembangan iteratif | "We follow Agile with two-week sprints." |
| Tech debt | Biaya jangka panjang dari solusi cepat | "We accumulated tech debt by skipping unit tests." |

**Frasa Kunci:**
- "The system is down" — sistem mati
- "We're experiencing a bug where..." — kami mengalami bug di mana...
- "Can you reproduce the issue?" — bisakah mereproduksi masalah?
- "Let's debug this together" — mari debug bersama

## Contoh
**Bug Report Comment:**
"When the user submits the form with an empty email field, the app crashes with a TypeError: Cannot read property 'trim' of undefined. The validation logic in formValidator.js line 42 is not checking for null values before calling trim()."

## Latihan
1. Baca 1 README dari open-source project di GitHub, rangkum fitur-fitur yang dijelaskan.
2. Tulis 1 bug report fiktif (description, steps to reproduce, expected vs actual result).
3. Code review comment: beri feedback pada 1 kode sederhana (atau gunakan sample dari GitHub).
4. Role-play: Standup meeting — "What did you do yesterday, what will you do today, any blockers?"
5. Baca 1 technical blog post (Medium/Dev.to), catat 10 technical terms baru.
