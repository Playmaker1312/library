# 353. Aplikasi Belajar — Anki (Flashcards SRS), Grammarly, Quizlet

## Definisi & Target
Mengoptimalkan tools digital untuk mempercepat dan memperkuat learning. Target: integrasi tools ini ke daily learning routine.

## Daftar & Deskripsi

| Aplikasi | Fungsi | Keunggulan |
|----------|--------|-----------|
| **Anki** | Spaced Repetition System (SRS) flashcards | Algoritma SRS paling powerful, customizable deck, free (desktop) / $25 (iOS) |
| **Grammarly** | Writing assistant | Cek grammar, spelling, tone, clarity. Premium: plagiarism check, style suggestions |
| **Quizlet** | Flashcards + games | UI lebih modern dari Anki, fitur belajar grup, modes (learn, match, test) |
| **Notion / Obsidian** | Note-taking + knowledge management | Bisa integrasi dictionary, template learning journal |

## Tips Penggunaan

### Anki — Best Practices
- **Buat deck sendiri** — lebih efektif daripada download deck orang.
- **Card format:** Front = context (kalimat dengan blank), Back = kata + definisi + contoh.
- **Review limit:** 20 new cards + 100 review per hari (jangan overload).
- **Leecher cards:** Jika kartu terus gagal, edit atau hapus — buat ulang dengan konteks lebih baik.
- **Pre-made decks:** "Advanced English Vocabulary" (4000+ cards) atau buat dari buku bacaan.

### Grammarly — Optimalisasi
- **Install browser extension** — cek grammar di email, sosial media, Google Docs.
- **Set goals:** Formal/Academic untuk writing, Casual untuk chat.
- **Focus on "Correctness"** — jangan terlalu dependen pada "Tone" suggestions (bisa bias).

### Quizlet — Kapan Pakai
- **Vocabulary lists cepat** — input 20 kata, langsung bisa practice dalam 5 menit.
- **Collaborative** — buat kelas, ajak teman belajar bersama.
- **Export ke Anki** — Quizlet tidak pakai SRS, pindahkan ke Anki untuk long-term retention.

## Contoh
**Anki Card — Advanced Vocabulary:**
Front: "The professor's lecture was so _____ that most students fell asleep."
Back: "tedious — too long, slow, or dull. Synonym: monotonous. Example: 'The tedious paperwork took hours to complete.'"

## Latihan
1. Install Anki desktop, download deck "English Vocabulary in Use Advanced".
2. Buat 10 Anki cards dari vocabulary baru minggu ini — gunakan format cloze deletion.
3. Install Grammarly, write 1 email, review suggestions — terima/tolak 3 suggestions dan catat alasannya.
4. Buat 1 Quizlet set 20 kata, share link dengan teman.
5. Bandingkan review experience Anki vs Quizlet — mana yang lebih efektif untukmu?
