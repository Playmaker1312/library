# 129. Suffixes (-tion, -ment, -ness, -ful, -less, -able, -ous, etc)

## Definisi & Target
Memahami akhiran (suffixes) untuk mengubah kelas kata — verb jadi noun, noun jadi adjective, dll.

## Analogi
Seperti **seragam sekolah** — suffix mengubah identitas kata. "Teach" (mengajar) pakai "-er" jadi "teacher" (guru), pakai "-ing" jadi "teaching" (pengajaran).

## Daftar & Penjelasan

| Suffix | Fungsi | Contoh |
|--------|--------|--------|
| **-tion/-sion** | Verb → Noun | educate → educa**tion**, decide → deci**sion** |
| **-ment** | Verb → Noun | agree → agree**ment**, develop → develop**ment** |
| **-ness** | Adjective → Noun | happy → happy**ness**, kind → kind**ness** |
| **-ful** | Noun → Adjective (penuh) | beauty → beauty**ful**, hope → hope**ful** |
| **-less** | Noun → Adjective (tanpa) | home → home**less**, care → care**less** |
| **-able/-ible** | Verb → Adjective (bisa) | read → read**able**, access → access**ible** |
| **-ous** | Noun → Adjective (sifat) | danger → danger**ous**, fame → fam**ous** |
| **-er/-or** | Verb → Noun (pelaku) | teach → teach**er**, act → act**or** |
| **-ly** | Adjective → Adverb | quick → quick**ly**, careful → careful**ly** |

## Latihan
1. Tambahkan suffix: "She felt great ______ (happy) about the news."
2. Ubah verb ke noun: "The govern______ announced a new policy."
3. Ubah ke adjective: "Be ______ (care) when crossing the street."
4. Lawan makna dengan suffix: "a use______ tool" vs "a use______ tool"
5. Lengkapi: "This task is imposs______. I can't do it."
