# 136. Vocabulary Environment and Nature

## Definisi & Target
Memperkaya kosakata bahasa Inggris tentang lingkungan hidup dan alam.

## Daftar & Penjelasan

| Vocabulary | Arti | Contoh |
|------------|------|--------|
| **environment** | lingkungan | We must protect the **environment**. |
| **pollution** | polusi | Air **pollution** is a serious problem. |
| **climate change** | perubahan iklim | **Climate change** affects everyone. |
| **global warming** | pemanasan global | **Global warming** causes ice to melt. |
| **renewable energy** | energi terbarukan | Solar power is a **renewable energy** source. |
| **deforestation** | penggundulan hutan | **Deforestation** destroys animal habitats. |
| **biodiversity** | keanekaragaman hayati | The rainforest has high **biodiversity**. |
| **conservation** | konservasi/pelestarian | **Conservation** efforts help endangered species. |
| **endangered species** | spesies terancam punah | Tigers are an **endangered species**. |
| **recycle** | mendaur ulang | We should **recycle** plastic bottles. |
| **ecosystem** | ekosistem | Coral reefs are a fragile **ecosystem**. |
| **carbon footprint** | jejak karbon | Reduce your **carbon footprint**. |
| **natural disaster** | bencana alam | Earthquakes are a **natural disaster**. |
| **drought** | kekeringan | The **drought** lasted for months. |
| **flood** | banjir | Heavy rain caused **floods**. |

## Latihan
1. Apa kata untuk "pemanasan global"?
2. Lengkapi: "We should ______ (mendaur ulang) paper and plastic."
3. Jelaskan "deforestation" dalam bahasa Inggris sederhana.
4. Lengkapi: "Pandas are an ______ (terancam punah) species."
5. Buat kalimat tentang cara mengurangi carbon footprint.
