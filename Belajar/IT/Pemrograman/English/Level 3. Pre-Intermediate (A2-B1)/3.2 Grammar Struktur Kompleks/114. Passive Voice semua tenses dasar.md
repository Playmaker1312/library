# 114. Passive Voice semua tenses dasar

## Definisi & Target
Mengubah kalimat aktif menjadi pasif di berbagai tenses. Subjek kalimat pasif **menerima** aksi, bukan melakukan aksi.

## Analogi
- **Aktif** = "Kucing mengejar tikus" (kucing = pelaku)
- **Pasif** = "Tikus dikejar kucing" (tikus = penerima aksi, kucing disebutkan dengan "by")

## Pola & Struktur

| Tense | Active | Passive |
|-------|--------|---------|
| Present Simple | S + V1 | S + am/is/are + V3 |
| Present Continuous | S + am/is/are + V-ing | S + am/is/are + being + V3 |
| Past Simple | S + V2 | S + was/were + V3 |
| Past Continuous | S + was/were + V-ing | S + was/were + being + V3 |
| Present Perfect | S + have/has + V3 | S + have/has + been + V3 |
| Past Perfect | S + had + V3 | S + had + been + V3 |
| Future Simple | S + will + V1 | S + will + be + V3 |
| Modal | S + modal + V1 | S + modal + be + V3 |

**Rumus umum:** **be (sesuai tense) + V3 (past participle)**

## Contoh
| Active | Passive |
|--------|---------|
| The chef cooks the meal. | The meal is cooked by the chef. |
| The company is building a bridge. | A bridge is being built by the company. |
| Someone stole my wallet. | My wallet was stolen. |
| They have finished the project. | The project has been finished. |
| She will sign the contract. | The contract will be signed. |

## Latihan
1. Ubah ke pasif: "The children eat all the cookies."
2. Ubah ke pasif: "The storm damaged many houses."
3. Ubah ke pasif (present continuous): "The workers are painting the fence."
4. Ubah ke aktif: "The letter was written by my grandmother."
5. Buat kalimat pasif tanpa "by": "Someone has stolen my bicycle."
