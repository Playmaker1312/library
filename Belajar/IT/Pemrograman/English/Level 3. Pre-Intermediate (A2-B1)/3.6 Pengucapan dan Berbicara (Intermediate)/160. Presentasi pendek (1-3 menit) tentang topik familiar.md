# 160. Presentasi pendek (1-3 menit) tentang topik familiar

## Definisi & Target
Menyampaikan presentasi singkat dalam bahasa Inggris tentang topik yang dikenal (hobi, pekerjaan, pengalaman) dengan struktur yang jelas.

## Analogi
Seperti **cerita singkat** — bukan presentasi formal panjang. Bayangkan kamu lagi ngobrol dan diminta "Ceritain dong tentang hobimu."

## Poin-Poin Penting

### Struktur Presentasi
```
Opening (10-15 detik)
  ├── Greeting: "Good morning, everyone."
  ├── Topic: "Today I'd like to talk about..."
  └── Preview: "I'll cover three points..."

Body (1-2 menit)
  ├── Point 1 + detail
  ├── Point 2 + detail
  └── Point 3 + detail

Closing (15-20 detik)
  ├── Summary: "To sum up..."
  └── Thanks: "Thank you for listening. Any questions?"
```

### Tips
- **Outline** di kartu kecil — jangan baca teks penuh
- **Keyword** saja sebagai pengingat
- **Kontak mata** dengan audiens
- **Bicara perlahan** — gugup bikin kita cenderung cepat
- **Gunakan gesture** alami

## Frase Penting
| Fungsi | Frasa |
|--------|-------|
| Opening | "I'd like to start by..." |
| Sequencing | "First of all... / Secondly... / Finally..." |
| Giving examples | "For example... / For instance..." |
| Concluding | "In conclusion... / To sum up..." |
| Q&A | "Are there any questions?" |

## Langkah-Langkah
1. Pilih topik familiar (hobi, pekerjaan, film favorit)
2. Tulis outline 3 poin utama
3. Latihan di depan cermin (2-3 kali)
4. Rekam dan evaluasi (suara, eye contact, gesture)
5. Presentasi di depan teman/kamera

## Latihan
1. Pilih topik: "My hobby" atau "My dream job." Buat outline 3 poin.
2. Tulis opening (3 kalimat) untuk topik tersebut.
3. Latihan: presentasi 1 menit, rekam, dan evaluasi.
4. Tulis 3 transition phrases untuk menghubungkan poin.
5. Buat slide sederhana (3 poin + 1 judul) untuk presentasi.
