# 147. Pengenalan membaca teks akademik

## Definisi & Target
Mempersiapkan diri membaca teks akademik sederhana seperti artikel jurnal, textbook, atau esai akademik.

## Analogi
Seperti **mendaki gunung** — teks akademik lebih "terjal" dari bacaan biasa. Tapi dengan teknik yang tepat dan perlengkapan (vocabulary akademik), kita bisa sampai ke puncak.

## Poin-Poin Penting

### Ciri Teks Akademik
| Ciri | Penjelasan |
|------|-----------|
| **Formal tone** | Tidak ada slang, kontraksi (don't → do not) |
| **Passive voice** | Sering digunakan (It can be concluded...) |
| **Academic vocabulary** | analyze, concept, establish, indicate, assume |
| **Structured** | Abstract → Introduction → Method → Results → Discussion |
| **Hedging language** | might, could, suggests, appears, seems (tidak absolut) |

### Academic Word List (dasar)
| Kata | Arti |
|------|------|
| **analyze** | menganalisis |
| **concept** | konsep |
| **data** | data |
| **environment** | lingkungan |
| **establish** | menetapkan |

| **identify** | mengidentifikasi |

| **process** | proses |
| **significant** | signifikan |

## Langkah-Langkah
1. **Preview** — baca abstrak, sub-heading, kesimpulan dulu
2. **Scan** — cari kata kunci dan istilah penting
3. **Read intensively** — baca bagian penting secara detail
4. **Annotate** — catat poin utama, highlight vocabulary
5. **Summarize** — ringkas bagian yang sudah dibaca

## Latihan
1. Cari abstract dari sebuah jurnal sederhana. Identifikasi: tujuan, metode, hasil.
2. Ubah kalimat informal ke akademik: "We looked at how kids learn."
3. Identifikasi 3 academic vocabulary dari teks yang kamu baca.
4. Mengapa teks akademik sering menggunakan passive voice?
5. Tulis 1 paragraf akademik tentang topik yang kamu kuasai.
