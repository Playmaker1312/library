# 146. Membaca grafik, tabel, dan diagram dalam bahasa Inggris

## Definisi & Target
Belajar membaca dan menginterpretasi data visual (grafik, tabel, diagram) serta mendeskripsikannya dalam bahasa Inggris.

## Analogi
Seperti **membaca peta** — grafik adalah peta visual dari data. Dengan membaca grafik, kita bisa melihat tren dan pola tanpa membaca ribuan angka.

## Poin-Poin Penting

### Vocabulary untuk Grafik
| Kata | Arti |
|------|------|
| **increase / rise / go up** | meningkat |
| **decrease / decline / drop / fall** | menurun |
| **remain stable / stay the same** | tetap stabil |
| **fluctuate / fluctuation** | berfluktuasi |
| **peak / reach a peak** | mencapai puncak |
| **reach a low / bottom out** | mencapai titik terendah |
| **upward trend** | tren naik |
| **downward trend** | tren turun |
| **dramatically / significantly** | secara drastis |
| **gradually / steadily** | secara bertahap |
| **slightly** | sedikit |

### Bagian Grafik
| English | Indonesia |
|---------|-----------|
| **X-axis / horizontal axis** | sumbu X (horizontal) |
| **Y-axis / vertical axis** | sumbu Y (vertikal) |
| **bar chart** | grafik batang |
| **line graph** | grafik garis |
| **pie chart** | diagram lingkaran |
| **table** | tabel |

## Langkah-Langkah
1. Baca judul grafik — apa yang diukur?
2. Lihat sumbu X dan Y — apa unitnya? (tahun, persen, dll)
3. Identifikasi tren umum — naik, turun, atau stabil?
4. Cari data spesifik — tertinggi, terendah, perbandingan
5. Deskripsikan dalam 3-4 kalimat

## Latihan
1. Cari grafik sederhana. Deskripsikan trennya dalam bahasa Inggris.
2. Buat 2 kalimat: "The graph shows that..." dan "There was a significant increase in..."
3. Beda: "rising steadily" vs "rising dramatically"
4. Gambar grafik sederhana menunjukkan suhu selama seminggu. Tulis deskripsi.
5. Vocabulary drill: apa lawan dari "increase"?
