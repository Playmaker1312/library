# 86. Membaca Menu, Jadwal, Tanda, dan Formulir

## Definisi & Target
Membaca teks fungsional sehari-hari: menu restoran, jadwal transportasi, tanda/petunjuk, dan formulir. Target: memahami informasi praktis dalam bahasa Inggris.

## Analogi
Seperti saat di restoran — kamu perlu baca menu untuk pesan makanan. Atau di stasiun — baca jadwal untuk tahu jam keberangkatan. Ini adalah reading for survival.

## Poin-Poin Penting

### Menu Restoran
- **Appetizer:** makanan pembuka
- **Main course / Entree:** makanan utama
- **Dessert:** makanan penutup
- **Beverages:** minuman
- **Specials:** menu spesial hari ini
- Harga biasanya dengan simbol mata uang
- Deskripsi singkat bahan/masakan

### Jadwal (Schedule)
- **Departure / Arrival:** keberangkatan / kedatangan
- **Platform / Gate:** peron / gerbang
- **Frequency:** setiap berapa jam
- **AM / PM:** pagi / sore
- Waktu 24 jam (contoh: 14:30 = 2:30 PM)

### Tanda dan Petunjuk (Signs)
| Tanda | Arti |
|---|---|
| No smoking | Dilarang merokok |
| Exit | Keluar |
| Emergency exit | Pintu darurat |
| Push / Pull | Dorong / Tarik |
| Out of order | Rusak / tidak berfungsi |
| Wet floor | Lantai basah |
| Do not enter | Dilarang masuk |
| Staff only | Khusus karyawan |

### Formulir
- **First name / Last name:** Nama depan / Nama belakang
- **Date of birth:** Tanggal lahir
- **Gender:** Jenis kelamin
- **Signature:** Tanda tangan
- **Occupation:** Pekerjaan
- **Nationality:** Kewarganegaraan

## Langkah-Langkah
1. Identifikasi jenis teks (menu/jadwal/tanda/formulir)
2. Scan informasi yang kamu butuhkan
3. Perhatikan simbol, angka, dan singkatan
4. Jika ada kata tidak dikenal, tebak dari konteks
5. Verifikasi pemahamanmu

## Contoh
Menu: "Today's Special: Fried Rice with Chicken — Rp 35,000"
- Ini menu spesial hari ini: Nasi Goreng dengan Ayam, harga Rp 35.000

Jadwal: "Train to Bandung — Departure: 07:00 AM — Platform 3"
- Kereta ke Bandung berangkat jam 7 pagi dari peron 3.

## Latihan
1. Baca menu sederhana dan sebutkan 3 appetizer dan harganya.
2. Baca jadwal kereta dan cari kereta terakhir ke kota X.
3. Artikan tanda: "No food or drinks allowed."
4. Isi formulir pendaftaran dengan data dirimu (dalam Inggris).
5. Buat menu sederhana untuk restoranmu sendiri dalam bahasa Inggris.
