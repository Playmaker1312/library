# Third-Party Framework Component Wrapper (React, Vue, Angular) ke Web Component

## Analogi: Perpustakaan Digital

Perpustakaan memiliki buku dalam berbagai format: cetak, digital (PDF), dan audio. Untuk membuat semuanya bisa diakses di rak yang sama, perpustakaan menyediakan adaptor: sampul khusus untuk buku cetak, pembaca untuk PDF, dan pemutar untuk audio. Web Components seperti rak universal yang bisa menampung buku dari format apa pun. Framework wrapper adalah adaptor yang membungkus komponen React, Vue, atau Angular sehingga bisa digunakan sebagai Web Component — dan sebaliknya, menggunakan Web Component di dalam aplikasi React, Vue, atau Angular.

## Penjelasan Detail

Web Components dan framework modern bisa saling diintegrasikan. Untuk menggunakan Web Component di React: React 19+ mendukung Web Components secara native; versi sebelumnya memerlukan ref untuk mengakses atribut dan event. Vue memiliki dukungan terbaik — atribut dan event Web Component otomatis dipetakan. Angular memerlukan `CUSTOM_ELEMENTS_SCHEMA` untuk mengenali custom elements. Untuk membungkus komponen framework menjadi Web Component, gunakan alat seperti `@lit/react` (React), `vue-web-component-wrapper` (Vue), atau `@angular/elements` (Angular). Pendekatan ini memungkinkan interoperabilitas lintas framework — komponen Vue bisa digunakan di aplikasi React, dan sebaliknya.

    // Web Component dasar yang akan di-wrapper
    class BaseBukuCard extends HTMLElement {
      constructor() {
        super();
        this._shadow = this.attachShadow({ mode: 'open' });
        this._shadow.innerHTML =
          '<style>' +
            'div { border: 2px solid #4caf50; border-radius: 8px; padding: 15px; background: white; transition: all 0.3s; }' +
            'h3 { margin: 0; color: #1565c0; }' +

            'button:hover { background: #66bb6a; }' +
          '</style>' +
          '<div>' +
            '<h3 id="judul">📖 Judul Buku</h3>' +
            '<div class="penulis" id="penulis">✍️ Penulis</div>' +
            '<div class="status" id="status">Status</div>' +
            '<button id="btn-toggle">🔄 Ubah Status</button>' +
          '</div>';

        this._shadow.getElementById('btn-toggle').addEventListener('click', function () {
          var current = this.getAttribute('status');
          var baru = current === 'tersedia' ? 'dipinjam' : 'tersedia';
          this.setAttribute('status', baru);

          this.dispatchEvent(new CustomEvent('statuschange', {
            detail: { status: baru },
            bubbles: true,
            composed: true
          }));
        }.bind(this));
      }

      static get observedAttributes() {
        return ['judul', 'penulis', 'status'];
      }

      attributeChangedCallback(name, oldValue, newValue) {
        if (!this._shadow || oldValue === newValue) return;
        var el = this._shadow.getElementById(name);
        if (el) {
          if (name === 'judul') el.textContent = '📖 ' + (newValue || '');
          else if (name === 'penulis') el.textContent = '✍️ ' + (newValue || '');
          else if (name === 'status') {
            el.textContent = newValue === 'tersedia' ? '✅ Tersedia' : '❌ Dipinjam';
            el.style.background = newValue === 'tersedia' ? '#e8f5e9' : '#ffebee';
            el.style.color = newValue === 'tersedia' ? '#2e7d32' : '#c62828';
          }
        }
      }

      connectedCallback() {
        ['judul', 'penulis', 'status'].forEach(function (attr) {
          var val = this.getAttribute(attr);
          if (val) {
            this.attributeChangedCallback(attr, null, val);
          }
        }.bind(this));
      }
    }

    customElements.define('base-buku-card', BaseBukuCard);

    // Wrapper spesifik untuk setiap framework (simulasi)
    class ReactWrapper extends HTMLElement {
      constructor() {
        super();
        this._shadow = this.attachShadow({ mode: 'open' });
      }
      connectedCallback() {
        var card = document.createElement('base-buku-card');
        card.setAttribute('judul', this.getAttribute('judul') || '');
        card.setAttribute('penulis', this.getAttribute('penulis') || '');
        card.setAttribute('status', this.getAttribute('status') || 'tersedia');
        this._shadow.appendChild(card);
      }
    }
    customElements.define('react-wrapper', ReactWrapper);

    class VueWrapper extends HTMLElement {
      constructor() {
        super();
        this._shadow = this.attachShadow({ mode: 'open' });
      }
      connectedCallback() {
        var card = document.createElement('base-buku-card');
        card.setAttribute('judul', this.getAttribute('judul') || '');
        card.setAttribute('penulis', this.getAttribute('penulis') || '');
        card.setAttribute('status', this.getAttribute('status') || 'dipinjam');
        this._shadow.appendChild(card);
      }
    }
    customElements.define('vue-wrapper', VueWrapper);

    function pilihTab(nama, el) {

## Poin Penting
- Vue memiliki interoperabilitas terbaik dengan Web Components — atribut dan event otomatis terpetakan tanpa konfigurasi tambahan.
- React 19+ mendukung Web Components secara native; untuk versi sebelumnya, gunakan ref untuk mengakses event.
- Angular memerlukan `CUSTOM_ELEMENTS_SCHEMA` di module untuk mengenali custom elements; gunakan `@angular/elements` untuk membungkus komponen Angular menjadi Web Component.
