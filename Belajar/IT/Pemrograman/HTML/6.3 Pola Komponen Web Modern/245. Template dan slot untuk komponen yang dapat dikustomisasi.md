# Template dan Slot untuk Komponen yang Dapat Dikustomisasi

## Analogi: Perpustakaan Digital

Perpustakaan memiliki rak buku standar dengan kerangka yang sama, tetapi isinya bisa berbeda-beda tergantung kebutuhan. Template adalah cetak biru rak — mendefinisikan struktur dasar. Slot adalah bagian kosong di rak tempat kita bisa meletakkan konten apa pun. Satu rak mungkin diisi novel, rak lain diisi majalah, tetapi kerangka raknya tetap sama. Ini memungkinkan komponen yang reusable dengan konten yang bisa disesuaikan.

## Penjelasan Detail

HTML Template (`<template>`) adalah elemen yang menyimpan konten HTML yang tidak langsung dirender — kontennya inert sampai "diaktifkan" oleh JavaScript. Template ideal untuk mendefinisikan struktur komponen yang akan digunakan berulang kali. Slot (`<slot>`) adalah placeholder di dalam Shadow DOM yang menampilkan konten dari light DOM (konten anak elemen). Atribut `name` pada slot memungkinkan multiple slot yang berbeda. Konten yang tidak memiliki slot yang cocok akan masuk ke slot default (tanpa nama). Fitur ini memungkinkan komposer membangun komponen dengan kerangka tetap tetapi isi yang dapat disesuaikan, mirip dengan children/props di framework modern.

```html
    class KartuPerpustakaan extends HTMLElement {

        super();

        var shadowRoot = this.attachShadow({ mode: 'open' });

      }
    }

    customElements.define('kartu-perpustakaan', KartuPerpustakaan);
  </script>

</html>
```

## Poin Penting
- Gunakan `<template>` untuk mendefinisikan struktur komponen — konten template tidak dirender sampai di-clone dan ditempelkan ke DOM.
- Slot dengan atribut `name` memungkinkan multiple injection point dalam satu komponen.
- Konten default di dalam `<slot>` akan ditampilkan jika pengguna tidak menyediakan konten untuk slot tersebut.
