# Static Site Generation (SSG) untuk menghasilkan halaman HTML statis saat build

## Analogi: Perpustakaan Digital

SSG seperti perpustakaan yang mencetak semua bukunya terlebih dahulu sebelum dibuka. Semua buku disusun rapi di rak dalam bentuk jadi saat perpustakaan mulai beroperasi. Tidak ada proses pencetakan saat pengunjung datang karena semuanya sudah siap dari awal. Ketika ada buku baru, perpustakaan melakukan sesi cetak ulang (build) untuk menghasilkan edisi terbaru. Pengunjung mendapatkan buku secepat mungkin karena tinggal mengambil dari rak yang sudah tersedia.

## Penjelasan Detail

Static Site Generation (SSG) adalah teknik menghasilkan halaman HTML pada saat build time, bukan saat request. Semua halaman dibuat menjadi file HTML statis yang dapat disajikan langsung tanpa perlu server-side processing. Pendekatan ini memberikan performa terbaik karena halaman sudah jadi dan bisa di-cache di CDN. SSG sangat cocok untuk blog, dokumentasi, landing page, dan situs yang kontennya tidak berubah setiap request. Proses build biasanya melibatkan framework seperti Astro, 11ty, Hugo, atau Jekyll yang menggabungkan template dengan konten (Markdown, JSON, atau CMS). Kelebihan SSG meliputi kecepatan loading super cepat, keamanan lebih baik (tanpa server-side code), hosting murah (bisa di GitHub Pages atau Netlify), dan SEO optimal. Kerugiannya adalah waktu build bertambah seiring jumlah halaman dan konten tidak real-time.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Tentang Saya</title>
  <meta name="description" content="Halaman tentang saya - situs statis">
</head>
<body>
  <header>
    <h1>Situs Pribadi</h1>
    <nav>
      <a href="/">Beranda</a>
      <a href="/tentang.html">Tentang</a>
      <a href="/blog/">Blog</a>
      <a href="/kontak.html">Kontak</a>
    </nav>
  </header>

  <main>
    <h2>Tentang Saya</h2>
    <p>Saya adalah seorang pengembang web yang fokus pada front-end dan static site. Situs ini dibuat menggunakan Static Site Generation dengan HTML, CSS, dan Markdown.</p>
    <p>Setiap halaman di situs ini adalah file HTML statis yang di-generate saat proses build. Tidak ada database atau server-side scripting yang berjalan saat pengunjung mengakses situs.</p>
  </main>

  <footer>
    <p>&copy; 2026 Situs Pribadi &mdash; Dibuat dengan SSG</p>
  </footer>
</body>
</html>
```

```javascript
// build.js (contoh script SSG sederhana)
const fs = require('fs');
const path = require('path');

const halaman = [
  { slug: 'index', judul: 'Beranda', konten: '<p>Selamat datang di situs statis saya.</p>' },
  { slug: 'tentang', judul: 'Tentang', konten: '<p>Tentang saya dan situs ini.</p>' },
  { slug: 'blog/index', judul: 'Blog', konten: '<p>Artikel-artikel saya.</p>' },
  { slug: 'kontak', judul: 'Kontak', konten: '<p>Hubungi saya melalui email.</p>' }
];

function renderTemplate(halaman) {
  return `<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>${halaman.judul} - Situs Statis</title>
</head>
<body>
  <header>
    <h1>Situs Statis</h1>
    <nav>
      <a href="/">Beranda</a>
      <a href="/tentang.html">Tentang</a>
      <a href="/blog/">Blog</a>
      <a href="/kontak.html">Kontak</a>
    </nav>
  </header>
  <main>
    <h2>${halaman.judul}</h2>
    ${halaman.konten}
  </main>
  <footer>
    <p>&copy; 2026 Situs Statis</p>
  </footer>
</body>
</html>`;
}

// Generate semua halaman
halaman.forEach(h => {
  const html = renderTemplate(h);
  const outputPath = path.join(__dirname, 'dist', h.slug + '.html');
  fs.mkdirSync(path.dirname(outputPath), { recursive: true });
  fs.writeFileSync(outputPath, html);
  console.log('Generated:', outputPath);
});

console.log('Build selesai! Semua halaman statis telah di-generate.');
```

## Poin Penting
- SSG menghasilkan file HTML statis saat build, bukan saat request, sehingga loading sangat cepat.
- Cocok untuk blog, dokumentasi, landing page, dan situs dengan konten yang jarang berubah.
- Hosting mudah dan murah karena hanya perlu server file statis atau CDN.
