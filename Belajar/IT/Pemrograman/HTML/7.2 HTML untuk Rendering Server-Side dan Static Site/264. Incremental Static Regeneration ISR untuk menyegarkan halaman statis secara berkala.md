# Incremental Static Regeneration (ISR) untuk menyegarkan halaman statis secara berkala

## Analogi: Perpustakaan Digital

ISR seperti perpustakaan yang memiliki rak buku khusus yang diperbarui secara otomatis setiap beberapa jam. Pengunjung membaca buku dari rak yang sudah jadi (statis), sementara di belakang layar petugas perpustakaan secara berkala mengambil buku edisi terbaru untuk menggantikan yang lama. Jika ada pengunjung yang meminta buku yang sedang diperbarui, petugas memberikan buku lama dulu sambil menyiapkan yang baru. Perpustakaan tidak perlu tutup untuk memperbarui koleksinya. Pembaruan terjadi secara bertahap tanpa mengganggu pengunjung.

## Penjelasan Detail

Incremental Static Regeneration (ISR) adalah teknik yang diperkenalkan oleh Next.js yang menggabungkan kelebihan SSG (kecepatan statis) dengan pembaruan konten berkala tanpa rebuild seluruh situs. Dengan ISR, halaman statis di-generate saat build, tetapi dapat diperbarui di background setelah periode tertentu (revalidate). Ketika request masuk setelah periode revalidate, server menyajikan halaman statis lama dulu sambil memicu regenerasi halaman baru di background. Pengguna berikutnya akan mendapatkan halaman yang sudah diperbarui. ISR sangat berguna untuk situs dengan konten yang berubah secara periodik seperti blog, e-commerce (harga produk), atau portal berita. Konfigurasi ISR dilakukan dengan menambahkan properti `revalidate` (dalam detik) pada fungsi getStaticProps di Next.js. Teknik ini mengurangi beban server dibandingkan SSR penuh namun tetap memberikan konten segar.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Harga Crypto - Diperbarui Berkala</title>
  <meta name="description" content="Harga cryptocurrency terkini, diperbarui setiap 60 detik">
</head>
<body>
  <header>
    <h1>Harga Crypto Terkini</h1>
    <p>Diperbarui setiap 60 detik &mdash; <span id="timestamp">Memuat...</span></p>
  </header>

  <main>
    <table>
      <thead>
        <tr>
          <th>Mata Uang</th>
          <th>Harga (USD)</th>
          <th>Perubahan 24j</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td>Bitcoin (BTC)</td>
          <td>$68,420.50</td>
          <td class="naik">+2.3%</td>
        </tr>
        <tr>
          <td>Ethereum (ETH)</td>
          <td>$3,521.80</td>
          <td class="turun">-1.1%</td>
        </tr>
        <tr>
          <td>Solana (SOL)</td>
          <td>$172.35</td>
          <td class="naik">+5.6%</td>
        </tr>
      </tbody>
    </table>
    <p class="catatan">Harga akan diperbarui otomatis dalam <span id="countdown">60</span> detik.</p>
  </main>

  <script>
    let detik = 60;
    const countdown = document.getElementById('countdown');
    const timestamp = document.getElementById('timestamp');

    timestamp.textContent = new Date().toLocaleTimeString();

    setInterval(() => {
      detik--;
      countdown.textContent = detik;
      if (detik <= 0) {
        location.reload();
      }
    }, 1000);
  </script>
</body>
</html>
```

```javascript
// next.config.js (Konfigurasi ISR di Next.js)
module.exports = {
  // Konfigurasi Next.js untuk ISR
};

// pages/harga-crypto.js (Next.js ISR)
export async function getStaticProps() {
  const res = await fetch('https://api.coingecko.com/api/v3/simple/price?ids=bitcoin,ethereum,solana&vs_currencies=usd&include_24hr_change=true');
  const data = await res.json();

  return {
    props: {
      harga: data,
      timestamp: new Date().toISOString()
    },
    // Regenerasi halaman setiap 60 detik
    revalidate: 60
  };
}

export default function HalamanHarga({ harga, timestamp }) {
  return (
    <div>
      <h1>Harga Crypto Terkini</h1>
      <p>Diperbarui: {new Date(timestamp).toLocaleTimeString()}</p>
      <table>
        <thead>
          <tr>
            <th>Mata Uang</th>
            <th>Harga (USD)</th>
            <th>Perubahan 24j</th>
          </tr>
        </thead>
        <tbody>
          {Object.entries(harga).map(([nama, data]) => (
            <tr key={nama}>
              <td>{nama}</td>
              <td>${data.usd.toLocaleString()}</td>
              <td className={data.usd_24h_change >= 0 ? 'naik' : 'turun'}>
                {data.usd_24h_change.toFixed(1)}%
              </td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  );
}
```

## Poin Penting
- ISR memberikan konten segar secara berkala tanpa rebuild seluruh situs, menggabungkan kecepatan SSG dengan data up-to-date.
- Properti `revalidate` menentukan interval regenerasi dalam detik.
- Cocok untuk e-commerce, blog, dan portal berita yang membutuhkan keseimbangan performa dan kesegaran konten.
