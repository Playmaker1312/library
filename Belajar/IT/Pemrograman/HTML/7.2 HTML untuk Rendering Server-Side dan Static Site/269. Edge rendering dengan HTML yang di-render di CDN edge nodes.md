# Edge rendering dengan HTML yang di-render di CDN edge nodes

## Analogi: Perpustakaan Digital

Edge rendering seperti memiliki cabang-cabang perpustakaan kecil di berbagai lokasi kota, bukan hanya satu perpustakaan pusat. Ketika pengunjung mencari buku, mereka langsung mendapatkannya dari cabang terdekat tanpa harus pergi ke pusat. Setiap cabang memiliki kemampuan untuk menyusun dan menyajikan buku secara mandiri. Buku yang paling populer sudah siap di rak (cache), sementara buku khusus bisa diambil dari pusat jika diperlukan. Pengunjung di berbagai kota mendapatkan pengalaman yang sama cepatnya karena dilayani oleh cabang terdekat.

## Penjelasan Detail

Edge rendering adalah teknik di mana halaman HTML di-render di server edge CDN (Content Delivery Network) yang tersebar di berbagai lokasi geografis, bukan di server origin tunggal. Platform seperti Cloudflare Workers, Vercel Edge Functions, dan Netlify Edge Functions memungkinkan eksekusi kode di edge nodes. Ketika pengguna mengirim request, edge node terdekat yang memproses dan merender HTML, mengurangi latency perjalanan data. Edge rendering menggabungkan kecepatan CDN (konten statis di-cache) dengan fleksibilitas server-side rendering (konten dinamis). Cocok untuk aplikasi yang memerlukan personalisasi berdasarkan lokasi geografis, A/B testing, atau konten dinamis dengan latensi rendah. Keterbatasan edge rendering meliputi resource komputasi yang lebih terbatas dibanding server tradisional dan tidak semua runtime atau API tersedia di edge.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Edge - Informasi Lokal</title>
</head>
<body>
  <h1>Selamat Datang!</h1>

  <div class="info-lokal">
    <h2>Info Berdasarkan Lokasi Anda</h2>
    <p><strong>Wilayah:</strong> <span id="wilayah">Mendeteksi...</span></p>
    <p><strong>Waktu setempat:</strong> <span id="waktu">${new Date().toLocaleString()}</span></p>
    <p><strong>Server edge:</strong> <span id="edge-lokasi">${process.env.VERCEL_REGION || 'lokal'}</span></p>
  </div>

  <div class="promo">
    <h2>Promo Spesial</h2>
    <!-- Konten promo yang di-render di edge berdasarkan lokasi -->
    <div id="promo-konten">
      <p>Selamat datang! Dapatkan diskon 20% untuk buku pertama Anda.</p>
    </div>
  </div>

  <footer>
    <p>Halaman ini di-render di edge node pada ${new Date().toISOString()}</p>
  </footer>
</body>
</html>
```

```javascript
// Edge function (Cloudflare Workers)
// Di-deploy ke edge nodes global
export default {
  async fetch(request, env, ctx) {
    const url = new URL(request.url);
    const country = request.cf?.country || 'ID';
    const city = request.cf?.city || 'Unknown';
    const region = request.cf?.region || 'Unknown';

    const waktu = new Date().toLocaleString('id-ID', {
      timeZone: 'Asia/Jakarta'
    });

    // Personalisasi konten berdasarkan lokasi
    let promo = 'Dapatkan diskon 20% untuk buku pertama Anda!';
    if (country === 'MY') {
      promo = 'Dapatkan diskaun 20% untuk buku pertama anda!';
    } else if (country === 'SG') {
      promo = 'Get 20% discount on your first book!';
    }

    const html = `<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Edge - ${city}</title>
</head>
<body>
  <h1>Selamat Datang!</h1>
  <div class="info-lokal">
    <h2>Info Berdasarkan Lokasi Anda</h2>
    <p><strong>Negara:</strong> ${country}</p>
    <p><strong>Kota:</strong> ${city}</p>
    <p><strong>Region:</strong> ${region}</p>
    <p><strong>Waktu:</strong> ${waktu}</p>
  </div>
  <div class="promo">
    <h2>Promo Spesial untuk ${city}</h2>
    <p>${promo}</p>
  </div>
  <footer>
    <p>Di-render di edge: ${request.cf?.colo || 'lokal'} | ${new Date().toISOString()}</p>
  </footer>
</body>
</html>`;

    return new Response(html, {
      headers: {
        'content-type': 'text/html; charset=utf-8',
        'cache-control': 'public, s-maxage=600' // cache di CDN 10 menit
      }
    });
  }
};
```

## Poin Penting
- Edge rendering memproses HTML di server CDN terdekat dengan pengguna, mengurangi latency.
- Memungkinkan personalisasi konten berdasarkan lokasi geografis tanpa mengorbankan kecepatan.
- Platform pendukung: Cloudflare Workers, Vercel Edge Functions, Netlify Edge Functions.
