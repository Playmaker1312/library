# Hydration HTML untuk mengaktifkan interaktivitas pada halaman SSR

## Analogi: Perpustakaan Digital

Hydration seperti menghidupkan buku-buku di perpustakaan digital. Awalnya buku hanya berupa teks statis yang bisa dibaca (HTML hasil SSR). Setelah hydration, buku menjadi interaktif: halaman bisa dibalik dengan animasi, catatan bisa ditambahkan, dan bookmark bisa disimpan. Proses hydration seperti memberikan "nyawa" pada halaman dengan menambahkan event listener dan state management. Pengunjung bisa langsung membaca buku (statis) sementara proses "menghidupkan" buku terjadi di latar belakang tanpa mengganggu pengalaman membaca.

## Penjelasan Detail

Hydration adalah proses di mana aplikasi JavaScript (seperti React, Vue, atau Svelte) mengambil alih HTML statis yang telah di-render di server dan menghubungkannya dengan logika interaktif. Server mengirimkan HTML lengkap dengan konten yang sudah jadi, sehingga pengguna langsung melihat halaman. Setelah JavaScript dimuat, framework akan "menghidrasi" DOM yang ada dengan melampirkan event handler, menginisialisasi state, dan membuat komponen menjadi interaktif. Hydration memungkinkan Time to First Paint (TTFP) yang cepat karena HTML sudah tampil, namun Time to Interactive (TTI) tetap bergantung pada ukuran JavaScript. Framework modern berusaha mengoptimalkan hydration dengan teknik seperti partial hydration (hanya menghidrasi komponen interaktif) dan selective hydration (prioritas berdasarkan visibilitas). Proses hydration yang tidak efisien dapat menyebabkan "hydration mismatch" di mana DOM server dan client berbeda, menghasilkan error.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Aplikasi Counter - Hydration Demo</title>
</head>
<body>
  <div id="root">
    <!-- HTML statis hasil SSR siap untuk dihydrasi -->
    <div class="counter-app">
      <h1>Counter Interaktif</h1>
      <p>Nilai: <span id="nilai-counter">0</span></p>
      <p class="status">Status: Netral</p>
      <div class="tombol">
        <button id="kurang" class="btn">-1</button>
        <button id="tambah" class="btn">+1</button>
        <button id="reset" class="btn">Reset</button>
      </div>
    </div>

    <!-- Data state untuk hydration -->
    <script id="__NEXT_DATA__" type="application/json">
      {"props":{"nilaiAwal":0},"page":"/counter"}
    </script>
  </div>

  <script>
    // Simulasi hydration: menghubungkan event handler ke DOM yang sudah ada
    function hydrateCounter() {
      const nilaiElement = document.getElementById('nilai-counter');
      let nilai = parseInt(nilaiElement.textContent, 10);
      const statusElement = document.querySelector('.status');

      function updateUI() {
        nilaiElement.textContent = nilai;
        statusElement.textContent = `Status: ${nilai > 0 ? 'Positif' : nilai < 0 ? 'Negatif' : 'Netral'}`;
      }

      // Event delegation untuk menghindari multiple listener
      document.querySelector('.tombol').addEventListener('click', (e) => {
        if (e.target.id === 'tambah') {
          nilai++;
          updateUI();
        } else if (e.target.id === 'kurang') {
          nilai--;
          updateUI();
        } else if (e.target.id === 'reset') {
          nilai = 0;
          updateUI();
        }
      });

      console.log('Hydration selesai: komponen sekarang interaktif');
    }

    // Hydrasi setelah DOM siap
    if (document.readyState === 'loading') {
      document.addEventListener('DOMContentLoaded', hydrateCounter);
    } else {
      hydrateCounter();
    }
  </script>
</body>
</html>
```

```javascript
// Komponen Counter
function Counter({ nilaiAwal }) {
  const [nilai, setNilai] = React.useState(nilaiAwal);

  return (
    <div className="counter-app">
      <h1>Counter Interaktif</h1>
      <p>Nilai: <span>{nilai}</span></p>
      <p>Status: {nilai > 0 ? 'Positif' : nilai < 0 ? 'Negatif' : 'Netral'}</p>
      <div className="tombol">
        <button onClick={() => setNilai(nilai - 1)}>-1</button>
        <button onClick={() => setNilai(nilai + 1)}>+1</button>
        <button onClick={() => setNilai(0)}>Reset</button>
      </div>
    </div>
  );
}
```

## Poin Penting
- Hydration menghubungkan HTML statis hasil SSR dengan event handler dan state JavaScript.
- HTML sudah tampil lebih dulu (cepat), interaktivitas menyusul setelah JavaScript dimuat.
- Hydration mismatch terjadi jika DOM server dan client berbeda; hindari dengan data yang konsisten.
