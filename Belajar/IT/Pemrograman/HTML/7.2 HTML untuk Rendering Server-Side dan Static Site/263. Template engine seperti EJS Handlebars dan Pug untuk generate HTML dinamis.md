# Template engine seperti EJS, Handlebars, dan Pug untuk generate HTML dinamis

## Analogi: Perpustakaan Digital

Template engine seperti cetak biru standar untuk buku-buku di perpustakaan digital. Bayangkan perpustakaan memiliki format buku yang seragam: semua buku memiliki sampul, daftar isi, dan halaman konten dengan tata letak yang sama. Cetak biru ini menentukan bagaimana setiap buku akan terlihat. Petugas perpustakaan tinggal mengisi bagian yang berbeda seperti judul, penulis, dan isi buku. Dengan cetak biru yang sama, perpustakaan bisa menghasilkan ribuan buku yang konsisten tanpa harus mendesain ulang setiap buku.

## Penjelasan Detail

Template engine adalah tools yang memisahkan logika HTML dari data, memungkinkan generasi halaman HTML dinamis dengan menggabungkan template statis dengan data yang berubah. EJS menggunakan sintaks `<% %>` untuk menyisipkan JavaScript langsung dalam HTML sehingga mudah dipelajari. Handlebars menggunakan sintaks `{{ }}` yang lebih bersih dan mendorong logika minimal di template, cocok untuk tim dengan pemisahan front-end dan back-end. Pug (sebelumnya Jade) menggunakan indentasi untuk struktur HTML tanpa tag penutup, menghasilkan kode yang lebih ringkas. Ketiga engine mendukung partials (komponen reusable), layout, dan helper functions. Pemilihan template engine tergantung pada kebutuhan proyek: EJS untuk kemudahan, Handlebars untuk kebersihan template, dan Pug untuk kekonsistenan kode.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Daftar Buku - Perpustakaan Digital</title>
</head>
<body>
  <h1>Koleksi Buku Perpustakaan Digital</h1>

  <section class="daftar-buku">
    <!-- Contoh hasil render dari EJS -->
    <div class="buku">
      <h2>Pemrograman Web Modern</h2>
      <p class="penulis">Oleh: Ahmad Fauzi</p>
      <p class="tahun">Tahun: 2026</p>
      <span class="status tersedia">Tersedia</span>
    </div>

    <div class="buku">
      <h2>Belajar JavaScript Lanjutan</h2>
      <p class="penulis">Oleh: Siti Rahma</p>
      <p class="tahun">Tahun: 2025</p>
      <span class="status dipinjam">Dipinjam</span>
    </div>
  </section>

  <footer>
    <p>Total buku: 2</p>
  </footer>
</body>
</html>
```

```ejs
<!-- index.ejs - Template EJS -->
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Daftar Buku</title>
</head>
<body>
  <h1>Koleksi Buku Perpustakaan Digital</h1>

  <section class="daftar-buku">
    <% bukuList.forEach(function(buku) { %>
      <div class="buku">
        <h2><%= buku.judul %></h2>
        <p>Oleh: <%= buku.penulis %></p>
        <p>Tahun: <%= buku.tahun %></p>
        <span class="status <%= buku.status %>">
          <%= buku.status === 'tersedia' ? 'Tersedia' : 'Dipinjam' %>
        </span>
      </div>
    <% }); %>
  </section>

  <footer>
    <p>Total buku: <%= bukuList.length %></p>
  </footer>
</body>
</html>
```

```handlebars
<!-- index.hbs - Template Handlebars -->
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Daftar Buku</title>
</head>
<body>
  <h1>Koleksi Buku Perpustakaan Digital</h1>

  <section class="daftar-buku">
    {{#each bukuList}}
      <div class="buku">
        <h2>{{judul}}</h2>
        <p>Oleh: {{penulis}}</p>
        <p>Tahun: {{tahun}}</p>
        <span class="status {{status}}">
          {{#if (eq status "tersedia")}}Tersedia{{else}}Dipinjam{{/if}}
        </span>
      </div>
    {{/each}}
  </section>

  <footer>
    <p>Total buku: {{bukuList.length}}</p>
  </footer>
</body>
</html>
```

```pug
//- index.pug - Template Pug
doctype html
html(lang="id")
  head
    meta(charset="UTF-8")
    title Daftar Buku
  body
    h1 Koleksi Buku Perpustakaan Digital

    section.daftar-buku
      each buku in bukuList
        div.buku
          h2= buku.judul
          p Oleh: #{buku.penulis}
          p Tahun: #{buku.tahun}
          span.status(class=buku.status)= buku.status === 'tersedia' ? 'Tersedia' : 'Dipinjam'

    footer
      p Total buku: #{bukuList.length}
```

## Poin Penting
- EJS menggunakan sintaks `<% %>` dengan JavaScript langsung di HTML, paling mudah dipelajari.
- Handlebars membatasi logika di template dengan sintaks `{{ }}`, cocok untuk tim front-end.
- Pug menggunakan indentasi ketat dan sintaks minimal, menghasilkan template yang sangat ringkas.
