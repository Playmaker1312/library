# Streaming SSR untuk mengirim HTML secara bertahap ke browser

## Analogi: Perpustakaan Digital

Streaming SSR seperti petugas perpustakaan yang memberikan buku halaman per halaman kepada pengunjung. Pengunjung tidak perlu menunggu seluruh buku selesai dicetak; mereka bisa mulai membaca halaman pertama sementara halaman berikutnya masih dalam proses. Bagian terpenting seperti sampul dan daftar isi dikirim lebih dulu, diikuti oleh bab-bab selanjutnya. Pengunjung merasa buku datang lebih cepat meskipun total waktu untuk mendapatkan buku lengkap sama saja. Pengalaman membaca terasa lebih responsif karena tidak ada waktu tunggu yang kosong.

## Penjelasan Detail

Streaming SSR adalah teknik di mana server mengirimkan HTML ke browser secara bertahap (chunks) menggunakan HTTP Streaming, bukan menunggu seluruh halaman selesai di-render. Dengan teknik ini, browser dapat mulai memproses HTML yang sudah diterima (seperti header, CSS, dan struktur halaman) sementara server masih merender konten lainnya. Framework seperti React 18 dengan `renderToPipeableStream` dan Vue dengan `renderToStream` mendukung streaming SSR. Keuntungan utama streaming SSR adalah First Byte lebih cepat diterima browser, pengguna bisa melihat konten lebih awal, dan Time to First Paint (TTFP) lebih baik. Streaming sangat bermanfaat untuk halaman dengan konten berat seperti data dari multiple API atau komponen yang membutuhkan waktu render lama. Tantangan streaming SSR adalah SEO (beberapa crawler mungkin tidak mengeksekusi JavaScript streaming) dan kompleksitas implementasi yang lebih tinggi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Artikel - Streaming SSR Demo</title>
  <style>
    body { font-family: system-ui, sans-serif; max-width: 800px; margin: auto; padding: 20px; }
    .skeleton { background: #e0e0e0; height: 20px; margin: 10px 0; border-radius: 4px; }
  </style>
</head>
<body>
  <header>
    <h1>Blog Streaming</h1>
    <nav><a href="/">Beranda</a></nav>
  </header>

  <main id="konten">
    <!-- Shell statis dikirim pertama -->
    <h2>Artikel: Masa Depan Web</h2>

    <!-- Konten akan ditambahkan secara streaming -->
    <div id="stream-area">
      <div class="skeleton" style="width: 100%"></div>
      <div class="skeleton" style="width: 80%"></div>
      <div class="skeleton" style="width: 90%"></div>
    </div>
  </main>

  <footer>
    <p>&copy; 2026 Blog Streaming</p>
  </footer>

  <script>
    // Simulasi streaming dari EventSource
    if (typeof EventSource !== 'undefined') {
      const source = new EventSource('/stream-artikel');
      const streamArea = document.getElementById('stream-area');

      source.onmessage = (event) => {
        // Hapus skeleton
        streamArea.querySelectorAll('.skeleton').forEach(el => el.remove());

        // Tambahkan konten baru secara bertahap
        const div = document.createElement('div');
        div.innerHTML = event.data;
        streamArea.appendChild(div);
      };

      source.onerror = () => {
        source.close();
        streamArea.innerHTML += '<p><em>Konten selesai dimuat.</em></p>';
      };
    }
  </script>
</body>
</html>
```

```javascript
// server-stream.js (implementasi streaming SSR di Node.js)
const http = require('http');
const { Readable } = require('stream');

http.createServer((req, res) => {
  if (req.url === '/') {
    res.writeHead(200, {
      'Content-Type': 'text/html; charset=utf-8',
      'Transfer-Encoding': 'chunked'
    });

    // Kirim shell HTML
    res.write(`<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Streaming SSR</title>
</head>
<body>
  <h1>Artikel Streaming</h1>
  <div id="konten">`);

    // Streaming konten bertahap (simulasi)
    let delay = 0;
    const chunks = [
      '<p>Bagian 1: Pendahuluan tentang streaming SSR...</p>',
      '<p>Bagian 2: Bagaimana cara kerja streaming...</p>',
      '<p>Bagian 3: Kelebihan dan kekurangan...</p>',
      '<p>Bagian 4: Kesimpulan.</p>'
    ];

    chunks.forEach((chunk, i) => {
      setTimeout(() => {
        res.write(chunk);
        if (i === chunks.length - 1) {
          res.end('</div></body></html>');
        }
      }, delay);
      delay += 1000; // 1 detik antar chunk
    });
  }
}).listen(3000, () => console.log('Server streaming di port 3000'));
```

## Poin Penting
- Streaming SSR mengirim HTML bertahap sehingga browser bisa mulai rendering lebih awal.
- TTFP (Time to First Paint) lebih cepat karena HTML shell diterima segera.
- Cocok untuk halaman dengan konten berat atau yang memerlukan data dari multiple sumber.
