# Konsep Server Side Rendering (SSR) dengan HTML yang di-generate oleh server

## Analogi: Perpustakaan Digital

SSR seperti perpustakaan di mana semua buku sudah disusun rapi di rak oleh petugas sebelum pengunjung datang. Ketika pengunjung meminta sebuah buku, petugas langsung mengambil buku yang sudah jadi dan memberikannya. Pengunjung tidak perlu menunggu buku dicetak atau dijilid terlebih dahulu. Halaman perpustakaan sudah siap saji sehingga pengunjung bisa langsung membaca. Proses penyusunan dan persiapan semua dilakukan di belakang layar oleh petugas perpustakaan.

## Penjelasan Detail

Server Side Rendering (SSR) adalah teknik di mana halaman HTML lengkap di-generate di server untuk setiap request pengguna. Server menjalankan logika aplikasi, mengambil data dari database, dan menghasilkan HTML yang sudah berisi konten. Browser menerima HTML yang sudah jadi sehingga pengguna langsung melihat konten tanpa menunggu JavaScript dieksekusi. SSR memberikan keuntungan dalam hal SEO karena search engine crawler dapat langsung membaca konten HTML. Waktu interaktif (Time to Interactive) juga lebih cepat karena HTML sudah memiliki konten. Kerugian SSR adalah beban server yang lebih berat untuk setiap request dan waktu navigasi antar halaman yang mungkin terasa lebih lambat karena server perlu memproses ulang. Framework populer untuk SSR termasuk Next.js (React), Nuxt.js (Vue), dan Remix.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Blog Saya - Artikel</title>
  <meta name="description" content="Artikel terbaru dari blog saya">

<body>
  <header>
    <h1>Blog Saya</h1>

      <a href="/">Beranda</a>

      <a href="/tentang">Tentang</a>
    </nav>
  </header>

  <main>
    <article>
      <h2>Belajar SSR dengan JavaScript</h2>
      <p class="meta">Ditulis oleh Admin &mdash; 23 Mei 2026</p>
      <p>Server Side Rendering adalah teknik rendering HTML di sisi server. Dalam artikel ini kita akan membahas konsep dasar SSR dan implementasinya menggunakan Node.js.</p>
      <p>Langkah pertama adalah menyiapkan server HTTP yang dapat merender halaman HTML berdasarkan route yang diminta. Kita bisa menggunakan Express.js untuk mempermudah routing.</p>
    </article>

    <aside>
      <h3>Artikel Terkait</h3>
      <ul>
        <li><a href="#">Apa itu SSR?</a></li>
        <li><a href="#">Perbandingan CSR vs SSR</a></li>
        <li><a href="#">SSR dengan Next.js</a></li>
      </ul>
    </aside>
  </main>

  <footer>
    <p>&copy; 2026 Blog Saya</p>
  </footer>
</body>
</html>
```

```javascript
// server.js (contoh implementasi SSR dengan Node.js dan Express)
const express = require('express');
const app = express();

function renderBlogPost(postId) {
  // Simulasi ambil data dari database
  const post = {
    title: 'Belajar SSR dengan JavaScript',
    author: 'Admin',
    date: '23 Mei 2026',
    content: '<p>Server Side Rendering adalah teknik rendering HTML di sisi server...</p>'
  };

  return `
    <!DOCTYPE html>
    <html lang="id">
    <head>
      <meta charset="UTF-8">
      <meta name="viewport" content="width=device-width, initial-scale=1.0">
      <title>${post.title}</title>
    </head>
    <body>
      <article>
        <h1>${post.title}</h1>
        <p>Oleh ${post.author} &mdash; ${post.date}</p>
        ${post.content}
      </article>
    </body>
    </html>
  `;
}

app.get('/artikel/:id', (req, res) => {
  const html = renderBlogPost(req.params.id);
  res.send(html);
});

app.listen(3000, () => console.log('Server berjalan di port 3000'));
```

## Poin Penting
- SSR menghasilkan HTML lengkap di server untuk setiap request, meningkatkan SEO dan initial load.
- Beban server lebih berat karena setiap request memerlukan proses rendering ulang.
- Cocok untuk aplikasi yang memerlukan SEO baik dan konten yang sering berubah per request.
