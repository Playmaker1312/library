# Penggunaan tag template literal di JavaScript untuk client-side rendering

## Analogi: Perpustakaan Digital

Template literal seperti papan tulis kosong di perpustakaan yang bisa diisi dengan informasi dinamis. Petugas perpustakaan bisa menuliskan judul buku, nama peminjam, dan tanggal pengembalian dengan cepat menggunakan spidol. Jika ada informasi yang berubah, petugas tinggal menghapus bagian tertentu dan menulis ulang tanpa perlu mengganti seluruh papan. Papan tulis ini bisa menampung teks biasa maupun coretan khusus seperti gambar dan daftar. Dengan template literal, pembuatan konten menjadi lebih fleksibel dan efisien.

## Penjelasan Detail

Template literal adalah fitur JavaScript (ES6) yang menggunakan backtick (` `) untuk mendefinisikan string dengan interpolasi ekspresi menggunakan `${expression}`. Tagged template literal adalah bentuk lanjutan di mana sebuah fungsi (tag) memproses template literal, memungkinkan manipulasi string yang lebih kompleks seperti escaping HTML, sanitasi input, atau pembuatan komponen UI. Penggunaan template literal untuk client-side rendering memungkinkan pengembang membuat HTML dinamis tanpa library tambahan. Teknik ini sangat berguna untuk Single Page Application kecil, rendering daftar dari data API, atau membuat komponen UI sederhana. Template literal juga mendukung multi-line string tanpa karakter escape, membuat kode lebih bersih. Untuk keamanan, penting melakukan escaping terhadap input pengguna untuk mencegah XSS saat menggunakan template literal untuk rendering HTML.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Daftar Buku - Client Side Rendering</title>
</head>
<body>
  <h1>Daftar Buku Perpustakaan</h1>

  <div class="filter">
    <button onclick="filterBuku('semua')">Semua</button>
    <button onclick="filterBuku('tersedia')">Tersedia</button>
    <button onclick="filterBuku('dipinjam')">Dipinjam</button>
  </div>

  <div id="daftar-buku">
    <p>Memuat data...</p>
  </div>

  <script>
    const bukuList = [
      { id: 1, judul: 'Pemrograman Web', penulis: 'Ahmad', status: 'tersedia' },
      { id: 2, judul: 'JavaScript Dasar', penulis: 'Budi', status: 'dipinjam' },
      { id: 3, judul: 'CSS Lanjutan', penulis: 'Citra', status: 'tersedia' },
      { id: 4, judul: 'React untuk Pemula', penulis: 'Dewi', status: 'dipinjam' }
    ];

    function escapeHtml(str) {
      const div = document.createElement('div');
      div.textContent = str;
      return div.innerHTML;
    }

    function renderBuku(daftar) {
      const container = document.getElementById('daftar-buku');

      if (daftar.length === 0) {
        container.innerHTML = '<p class="kosong">Tidak ada buku ditemukan.</p>';
        return;
      }

      container.innerHTML = daftar.map(buku => `
        <div class="card ${escapeHtml(buku.status)}">
          <h3>${escapeHtml(buku.judul)}</h3>
          <p>Penulis: ${escapeHtml(buku.penulis)}</p>
          <span class="badge ${escapeHtml(buku.status)}">
            ${buku.status === 'tersedia' ? 'Tersedia' : 'Dipinjam'}
          </span>
        </div>
      `).join('');
    }

    function filterBuku(filter) {
      if (filter === 'semua') {
        renderBuku(bukuList);
      } else {
        const hasil = bukuList.filter(b => b.status === filter);
        renderBuku(hasil);
      }
    }

    // Tampilkan semua buku saat awal
    renderBuku(bukuList);

    // Template literal dengan tagged function untuk highlight
    function highlight(strings, ...values) {
      return strings.reduce((result, str, i) => {
        const val = values[i] ? `<mark>${escapeHtml(String(values[i]))}</mark>` : '';
        return result + str + val;
      }, '');
    }

    const keyword = 'JavaScript';
    const deskripsi = highlight`Buku ${keyword} sangat cocok untuk pemula yang ingin belajar ${keyword} dari dasar.`;
    console.log(deskripsi);
  </script>
</body>
</html>
```

## Poin Penting
- Template literal menggunakan backtick dan `${expression}` untuk interpolasi ekspresi JavaScript.
- Tagged template literal memungkinkan fungsi khusus memproses template untuk escaping atau transformasi.
- Selalu escape input pengguna saat rendering HTML dengan template literal untuk mencegah XSS.
