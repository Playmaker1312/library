# Perbandingan CSR vs SSR vs SSG: kapan menggunakan masing-masing pendekatan

## Analogi: Perpustakaan Digital

CSR, SSR, dan SSG seperti tiga cara berbeda perpustakaan menyajikan buku. CSR seperti etalase kosong yang diisi buku oleh asisten saat pengunjung datang dan meminta judul tertentu. SSR seperti petugas yang menyusun buku khusus setiap kali ada permintaan. SSG seperti semua buku sudah tersusun rapi dari awal sebelum perpustakaan dibuka. CSR cepat untuk interaksi pertama, SSR cocok untuk konten personal, dan SSG unggul untuk konten yang sama untuk semua pengunjung. Pemilihan metode tergantung pada jenis pengunjung, konten, dan sumber daya yang tersedia.

## Penjelasan Detail

Client Side Rendering (CSR) merender halaman di browser menggunakan JavaScript. HTML awal minimal, konten dimuat setelah JavaScript dieksekusi. Kelebihan: interaksi kaya, navigasi cepat antar halaman (SPA), beban server ringan. Kekurangan: SEO buruk, initial load lambat, butuh JavaScript. Cocok untuk: dashboard, aplikasi internal, tools interaktif. Server Side Rendering (SSR) merender HTML lengkap di server setiap request. Kelebihan: SEO baik, First Paint cepat, konten selalu segar. Kekurangan: server berat, TTI bergantung JavaScript, latency lebih tinggi. Cocok untuk: e-commerce, portal berita, halaman personalisasi. Static Site Generation (SSG) menghasilkan HTML statis saat build. Kelebihan: performa terbaik, hosting murah, aman. Kekurangan: waktu build lama untuk situs besar, konten tidak real-time. Cocok untuk: blog, dokumentasi, landing page. Banyak situs modern menggunakan kombinasi ketiganya (hybrid).

// Flowchart perbandingan (pseudocode)
function pilihPendekatan(jenisSitus, kebutuhan) {
  if (jenisSitus === 'aplikasi_internal' || jenisSitus === 'dashboard') {
    return 'CSR';
  }
  if (jenisSitus === 'blog' || jenisSitus === 'dokumentasi') {
    return 'SSG';
  }
  if (jenisSitus === 'e-commerce' || jenisSitus === 'portal_berita') {
    if (kebutuhan.personalisasi) {
      return 'SSR';
    }
    return 'SSG + ISR'; // Hybrid
  }
  if (jenisSitus === 'landing_page' || jenisSitus === 'portofolio') {
    return 'SSG';
  }
  return 'SSR'; // Default
}

## Poin Penting
- CSR untuk aplikasi interaktif, SSR untuk konten personal/dinamis, SSG untuk konten statis.
- Kombinasi hybrid (SSG + CSR islands atau SSR + ISR) sering menjadi solusi terbaik untuk proyek kompleks.
- Pertimbangan utama: kebutuhan SEO, performa, personalisasi konten, dan anggaran hosting.
