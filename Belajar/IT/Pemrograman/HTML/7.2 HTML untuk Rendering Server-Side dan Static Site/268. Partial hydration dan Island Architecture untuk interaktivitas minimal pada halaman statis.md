# Partial hydration dan Island Architecture untuk interaktivitas minimal pada halaman statis

## Analogi: Perpustakaan Digital

Island Architecture seperti perpustakaan di mana hanya beberapa area tertentu yang interaktif, sementara sisanya statis. Bayangkan ada peta interaktif di dinding yang bisa disentuh pengunjung dan rak buku digital dengan tombol peminjaman. Area statis seperti lantai, langit-langit, dan rak buku biasa tetap statis tanpa JavaScript. Hanya "pulau-pulau" interaktivitas yang dimuat dengan JavaScript, membuat perpustakaan terasa modern tanpa harus membuat seluruh bangunan menjadi kompleks. Pendekatan ini menghemat sumber daya karena hanya bagian yang benar-benar membutuhkan interaksi yang diberi "nyawa".

## Penjelasan Detail

Partial hydration dan Island Architecture adalah pendekatan rendering di mana hanya komponen interaktif tertentu yang dihydrasi dengan JavaScript, sementara sisanya tetap berupa HTML statis. Istilah "Island Architecture" dipopulerkan oleh framework Astro, di mana halaman statis memiliki "pulau-pulau" interaktivitas yang terisolasi. Setiap pulau dapat menggunakan framework JavaScript yang berbeda (React, Vue, Svelte) tanpa konflik. Pendekatan ini menghasilkan ukuran JavaScript yang sangat kecil karena hanya komponen interaktif yang dikirim ke browser. Keuntungannya meliputi performa sangat cepat, Time to Interactive yang lebih baik, dan lebih sedikit JavaScript yang perlu di-download. Teknik ini sangat cocok untuk halaman yang sebagian besar kontennya statis seperti blog, dokumentasi, dan marketing pages. Framework yang mendukung pendekatan ini antara lain Astro, Marko, dan Qwik.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Blog - Island Architecture</title>
</head>
<body>
  <!-- Konten statis - tanpa JavaScript -->
  <header>
    <h1>Blog Saya</h1>
    <p>Catatan tentang pengembangan web</p>
  </header>

  <main>
    <article>
      <h2>Belajar Island Architecture</h2>
      <p>Island Architecture memungkinkan kita membuat halaman yang sebagian besar statis dengan beberapa komponen interaktif.</p>
      <p>Ini adalah paragraf statis biasa. Tidak perlu JavaScript untuk menampilkannya.</p>
    </article>

    <!-- Pulau interaktivitas 1: Counter (React) -->
    <div class="island" data-framework="react" data-komponen="Counter" data-props='{"awal":0}'>
      <button class="btn-kurang" data-action="kurang">-</button>
      <span class="nilai-counter">0</span>
      <button class="btn-tambah" data-action="tambah">+</button>
    </div>

    <!-- Pulau interaktivitas 2: Form Subscribe (Vue) -->
    <div class="island" data-framework="vue" data-komponen="SubscribeForm">
      <form class="subscribe-form" data-island>
        <input type="email" placeholder="Email Anda" required>
        <button type="submit">Langganan</button>
        <p class="pesan" hidden>Terima kasih!</p>
      </form>
    </div>

    <!-- Pulau interaktivitas 3: Tombol Like (Svelte) -->
    <div class="island" data-framework="svelte" data-komponen="LikeButton">
      <button class="like-btn">
        <span class="ikon">&#9825;</span>
        <span class="jumlah-like">12</span>
      </button>
    </div>
  </main>

  <!-- Konten statis lainnya -->
  <footer>
    <p>&copy; 2026 Blog Saya &mdash; Dibangun dengan Island Architecture</p>
  </footer>

  <script>
    // Hydrator sederhana untuk Island Architecture
    document.querySelectorAll('.island').forEach(pulau => {
      const framework = pulau.dataset.framework;

      // Counter island (simulasi)
      if (pulau.dataset.komponen === 'Counter') {
        const kurang = pulau.querySelector('.btn-kurang');
        const tambah = pulau.querySelector('.btn-tambah');
        const nilai = pulau.querySelector('.nilai-counter');
        let count = parseInt(pulau.dataset.props ? JSON.parse(pulau.dataset.props).awal : 0);

        kurang.addEventListener('click', () => {
          count--;
          nilai.textContent = count;
        });

        tambah.addEventListener('click', () => {
          count++;
          nilai.textContent = count;
        });
      }

      // Subscribe form island (simulasi)
      if (pulau.dataset.komponen === 'SubscribeForm') {
        const form = pulau.querySelector('.subscribe-form');
        const pesan = pulau.querySelector('.pesan');

        form.addEventListener('submit', (e) => {
          e.preventDefault();
          pesan.hidden = false;
          form.querySelector('input').disabled = true;
          form.querySelector('button').disabled = true;
        });
      }

      // Like button island (simulasi)
      if (pulau.dataset.komponen === 'LikeButton') {
        const btn = pulau.querySelector('.like-btn');
        const jumlah = pulau.querySelector('.jumlah-like');

        btn.addEventListener('click', () => {
          jumlah.textContent = parseInt(jumlah.textContent) + 1;
        });
      }

      console.log(`Island "${pulau.dataset.komponen}" (${framework}) telah dihydrasi`);
    });
  </script>
</body>
</html>
```

## Poin Penting
- Island Architecture hanya mengirim JavaScript untuk komponen interaktif, sisanya HTML statis.
- Setiap pulau interaktivitas terisolasi dan bisa menggunakan framework berbeda tanpa konflik.
- Pendekatan ini menghasilkan bundle JavaScript minimal dan performa halaman yang sangat cepat.
