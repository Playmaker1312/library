# Tag dialog untuk Membuat Kotak Dialog atau Modal Bawaan HTML

## Analogi: Perpustakaan Digital

Seperti meja layanan informasi di perpustakaan yang hanya muncul saat Anda memencet bel, tag `dialog` menyediakan jendela interaktif yang bisa dimunculkan dan disembunyikan sesuai kebutuhan. Saat tidak digunakan, meja itu seolah tidak ada — sama seperti dialog yang tidak tampil di halaman sampai dipicu. Pengunjung harus menyelesaikan urusannya di meja itu sebelum melanjutkan, layaknya dialog modal yang memblokir interaksi dengan halaman utama.

## Penjelasan Detail

Elemen `<dialog>` menyediakan kotak dialog atau modal bawaan HTML tanpa perlu pustaka JavaScript eksternal. Dialog dapat dibuka dengan metode `.show()` (non-modal) atau `.showModal()` (modal yang memblokir interaksi di belakangnya) dan ditutup dengan `.close()`. Atribut boolean `open` menandakan bahwa dialog sedang terlihat. Dialog modal juga mendukung penutupan otomatis dengan tombol Escape. Elemen ini memiliki `::backdrop` pseudo-element untuk menata latar belakang saat dialog modal aktif. Form di dalam dialog dapat menggunakan atribut `method="dialog"` untuk menutup dialog otomatis saat disubmit.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Contoh Tag dialog</title>
</head>
<body>
  <button id="bukaDialog">Buka Dialog</button>

  <dialog id="infoDialog">
    <p>Ini adalah dialog bawaan HTML.</p>
    <button id="tutupDialog">Tutup</button>
  </dialog>

  <script>
    const dialog = document.getElementById('infoDialog');
    document.getElementById('bukaDialog').addEventListener('click', () => {
      dialog.showModal();
    });
    document.getElementById('tutupDialog').addEventListener('click', () => {
      dialog.close();
    });
  </script>
</body>
</html>
```

## Poin Penting
- Dialog modal memblokir interaksi dengan halaman utama hingga ditutup
- Atribut `method="dialog"` pada form di dalam dialog otomatis menutup dialog saat submit
- Pseudo-element `::backdrop` digunakan untuk menata latar belakang saat dialog modal aktif
