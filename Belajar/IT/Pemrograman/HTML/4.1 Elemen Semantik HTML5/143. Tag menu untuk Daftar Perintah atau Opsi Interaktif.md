# Tag menu untuk Daftar Perintah atau Opsi Interaktif

## Analogi: Perpustakaan Digital

Bayangkan sebuah panel kontrol di perpustakaan yang berisi tombol-tombol seperti "Pinjam Buku", "Kembalikan", atau "Cari Katalog". Panel ini hanya muncul saat pengguna mengklik kanan atau menekan tombol menu. Tag `menu` ibarat wadah untuk kumpulan perintah interaktif tersebut — bukan sekadar daftar bacaan, melainkan aksi-aksi yang bisa dilakukan pengguna.

## Penjelasan Detail

Elemen `<menu>` secara semantik merepresentasikan kumpulan perintah atau aksi yang dapat dijalankan pengguna. Secara visual dan fungsional, `<menu>` identik dengan `<ul>` dan `<li>`, tetapi maknanya berbeda: `<menu>` untuk daftar perintah interaktif, sedangkan `<ul>` untuk daftar item non-interaktif. Penggunaan `<menu>` paling umum adalah sebagai toolbar atau konteks menu. Elemen ini dapat berisi tombol, tautan, atau elemen interaktif lain di dalam item `<li>`-nya. Dukungan browser untuk `<menu>` masih terbatas, sehingga `<ul>` sering digunakan sebagai alternatif.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Contoh Tag menu</title>
</head>
<body>
  <h1>Editor Dokumen</h1>

  <menu>
    <li><button type="button">Simpan</button></li>
    <li><button type="button">Buka</button></li>
    <li><button type="button">Cetak</button></li>
    <li><button type="button">Hapus</button></li>
  </menu>

  <p>Klik tombol di atas untuk menjalankan perintah.</p>
</body>
</html>
```

## Poin Penting
- Gunakan `<menu>` untuk daftar perintah interaktif, bukan untuk navigasi atau daftar biasa
- Secara visual identik dengan `<ul>`, tetapi berbeda makna semantik
- Dukungan browser masih terbatas — `<ul>` sering digunakan sebagai fallback
