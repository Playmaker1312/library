# Tag aside untuk Konten Sampingan yang Berkaitan dengan Konten Utama

## Analogi: Perpustakaan Digital

Bayangkan **papan pengumuman** di samping ruang baca utama. Pengumuman ini terkait dengan perpustakaan, tapi bukan bagian inti dari koleksi buku.

`<aside>` adalah **konten sampingan** — informasi yang terkait tapi tidak esensial untuk memahami konten utama. Biasanya digunakan untuk sidebar, catatan kaki, atau kotak info.

## Penjelasan Detail

`<aside>` mewakili konten yang **hanya terkait secara tidak langsung** dengan konten utama.

### Kapan Pakai `<aside>`?
- **Sidebar** — widget, kategori, arsip
- **Pull quote** — kutipan yang ditonjolkan
- **Glosarium** — definisi istilah
- **Iklan** — terkait dengan konten
- **Tautan terkait** — related posts

### Posisi
- Di dalam `<article>` → konten sampingan untuk artikel itu
- Di luar `<article>` → konten sampingan untuk seluruh halaman

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Aside Tag</title>
    <style>
      .container { display: flex; gap: 20px; }
      main { flex: 3; }
      aside { flex: 1; background: #f9f9f9; padding: 15px; }
    </style>
  </head>
  <body>
    <div class="container">
      <main>
        <article>
          <h2>Sejarah Perpustakaan Digital</h2>
          <p>Perpustakaan Digital pertama kali didirikan pada tahun 2020...</p>

          <!-- Aside di dalam article -->
          <aside>
            <h3>Catatan Sejarah</h3>
            <p>Perpustakaan digital pertama di dunia adalah...</p>
          </aside>

          <p>Sejak saat itu, perpustakaan terus berkembang...</p>
        </article>
      </main>

      <!-- Aside untuk halaman (sidebar) -->
      <aside>
        <h3>Kategori</h3>
        <ul>
          <li><a href="#">Fiksi</a></li>
          <li><a href="#">Non Fiksi</a></li>
          <li><a href="#">Sains</a></li>
        </ul>

        <h3>Buku Populer</h3>
        <ul>
          <li>Laskar Pelangi</li>
          <li>Bumi Manusia</li>
        </ul>
      </aside>
    </div>
  </body>
</html>
```

## Poin Penting
- `<aside>` = konten **sampingan**
- Terkait tapi tidak esensial untuk konten utama
- Bisa di dalam `<article>` atau sebagai sidebar halaman
- Jangan gunakan `<aside>` untuk navigasi utama (pakai `<nav>`)
