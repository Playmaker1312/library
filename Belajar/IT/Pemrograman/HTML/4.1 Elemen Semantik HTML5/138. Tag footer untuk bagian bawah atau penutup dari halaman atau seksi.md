# Tag footer untuk Bagian Bawah atau Penutup dari Halaman atau Seksi

## Analogi: Perpustakaan Digital

Bayangkan **halaman hak cipta** di akhir buku — berisi informasi penerbit, tahun terbit, ISBN. Atau **papan informasi** di pintu keluar perpustakaan — jam buka, kontak, alamat.

`<footer>` adalah **bagian penutup** — biasanya berisi informasi copyright, tautan terkait, kontak, atau navigasi sekunder.

## Penjelasan Detail

`<footer>` mewakili **footer** untuk halaman atau section.

### Isi Umum `<footer>`
- Informasi hak cipta
- Tautan kebijakan privasi
- Kontak
- Navigasi sekunder
- Logo
- Sosial media

### Aturan
- Boleh lebih dari satu `<footer>` per halaman (untuk setiap section/article)
- **Tidak boleh** di dalam `<header>` atau `<address>`
- Tidak otomatis di bagian bawah halaman — posisi diatur CSS

### Footer Per Article
```html
<article>
  <h2>Judul Artikel</h2>
  <p>Isi...</p>
  <footer>
    <p>Ditulis oleh: Budi | Kategori: Tutorial</p>
  </footer>
</article>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Footer Tag</title>
  </head>
  <body>
    <header>
      <h1>Perpustakaan Digital</h1>
      <nav>...</nav>
    </header>

    <main>
      <article>
        <h2>Cara Meminjam Buku</h2>
        <p>Isi artikel...</p>
        <footer>
          <p>Ditulis oleh Admin | 15 Juni 2024</p>
        </footer>
      </article>
    </main>

    <!-- Footer utama halaman -->
    <footer>
      <div style="display: flex; justify-content: space-between;">
        <div>
          <h4>Perpustakaan Digital</h4>
          <p>Jl. Merdeka No. 123, Jakarta</p>
        </div>
        <div>
          <h4>Tautan</h4>
          <a href="#">Tentang</a> | <a href="#">Kontak</a>
        </div>
        <div>
          <h4>Ikuti Kami</h4>
          <a href="#">Facebook</a> | <a href="#">Twitter</a>
        </div>
      </div>
      <hr>
      <p>&copy; 2024 Perpustakaan Digital. Hak cipta dilindungi.</p>
    </footer>
  </body>
</html>
```

## Poin Penting
- `<footer>` = bagian **penutup** (copyright, kontak, tautan)
- Boleh lebih dari satu per halaman
- Untuk halaman utama dan per section/article
- Posisi diatur CSS — tidak otomatis di bawah
