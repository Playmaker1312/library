# Konsep Semantic HTML dan Mengapa Penting untuk SEO dan Aksesibilitas

## Analogi: Perpustakaan Digital

Bayangkan dua perpustakaan:

**Perpustakaan A (Non-semantik):** Semua buku ditaruh di kotak yang sama tanpa label. Tidak ada papan "Fiksi", "Sejarah", "Sains". Pengunjung bingung mencari buku.

**Perpustakaan B (Semantik):** Ada papan jelas: "Fiksi → Lantai 1", "Sejarah → Lantai 2", "Sains → Lantai 3". Setiap rak punya label. Pengunjung mudah navigasi.

`<div>` dan `<span>` adalah "kotak tanpa label" (non-semantik). `<header>`, `<nav>`, `<main>`, `<article>`, `<footer>` adalah "rak dengan label" (semantik).

**Semantic HTML** = menggunakan tag yang **bermakna** — bukan hanya `<div>` untuk semuanya.

## Penjelasan Detail

### Apa Itu Semantic HTML?
Semantic HTML menggunakan tag yang **mendeskripsikan isinya**.

| Non-semantik | Semantik |
|-------------|----------|
| `<div id="header">` | `<header>` |
| `<div id="nav">` | `<nav>` |
| `<div id="main">` | `<main>` |
| `<div id="footer">` | `<footer>` |

### Manfaat
1. **SEO** — Google lebih paham struktur halaman
2. **Aksesibilitas** — screen reader navigasi lebih mudah
3. **Readability** — kode lebih mudah dibaca developer
4. **Maintenance** — lebih mudah dirawat dan diubah

## Contoh Kode Implementasi

**Non-semantik (JANGAN):**
```html
<div id="header">
  <div id="nav">...</div>
</div>
<div id="main">
  <div class="article">...</div>
  <div class="sidebar">...</div>
</div>
<div id="footer">...</div>
```

**Semantik (LAKUKAN):**
```html
<header>
  <nav>...</nav>
</header>
<main>
  <article>...</article>
  <aside>...</aside>
</main>
<footer>...</footer>
```

## Poin Penting
- Semantic HTML = tag yang **bermakna**
- Meningkatkan **SEO** dan **aksesibilitas**
- Gunakan `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`
- Hindari `<div>` untuk struktur utama
