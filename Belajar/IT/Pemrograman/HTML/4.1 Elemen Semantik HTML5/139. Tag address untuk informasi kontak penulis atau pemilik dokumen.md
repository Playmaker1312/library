# Tag address untuk Informasi Kontak Penulis atau Pemilik Dokumen

## Analogi: Perpustakaan Digital

Bayangkan **kotak kontak** di pojok ruang baca — berisi alamat email pustakawan, nomor telepon, dan alamat perpustakaan. Ini adalah informasi **kontak** yang terkait dengan dokumen atau artikel.

`<address>` adalah **informasi kontak** untuk penulis atau pemilik halaman/article.

## Penjelasan Detail

`<address>` digunakan untuk menandai **informasi kontak** — biasanya email, telepon, alamat fisik.

### Aturan Penting
- Bukan untuk alamat pos biasa — itu cukup di `<p>`
- `<address>` adalah untuk **kontak yang terkait dengan dokumen**
- Biasanya diletakkan di `<footer>` atau akhir `<article>`

### Isi yang Tepat
```html
<address>
  <a href="mailto:admin@perpustakaan.com">admin@perpustakaan.com</a><br>
  <a href="tel:+628123456789">+62 812-3456-789</a><br>
  Jl. Merdeka No. 123, Jakarta
</address>
```

### Isi yang TIDAK Tepat
- Alamat perusahaan secara umum (pakai `<p>`)
- Alamat pos untuk pengiriman
- Informasi hak cipta (pakai `<small>`)
- Tanggal publikasi

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Address Tag</title>
  </head>
  <body>
    <article>
      <h2>Panduan Menggunakan Perpustakaan Digital</h2>
      <p>Isi panduan...</p>

      <footer>
        <p>Penulis: Tim Perpustakaan Digital</p>
        <address>
          Hubungi kami:
          <a href="mailto:admin@perpustakaan.com">admin@perpustakaan.com</a><br>
          Telepon: <a href="tel:+628123456789">+62 812-3456-789</a>
        </address>
      </footer>
    </article>

    <footer>
      <p>&copy; 2024 Perpustakaan Digital</p>
      <!-- Address di footer utama -->
      <address>
        Perpustakaan Digital<br>
        Jl. Merdeka No. 123<br>
        Jakarta Pusat, 10110
      </address>
    </footer>
  </body>
</html>
```

## Poin Penting
- `<address>` = **informasi kontak** penulis/pemilik
- Bisa berisi email, telepon, alamat fisik
- Letak umum: di `<footer>` atau akhir `<article>`
- Bukan untuk alamat pos biasa
- Bisa di-`<style>` untuk tampilan ikon kontak
