# Tag details dan summary untuk Membuat Konten yang Bisa Diperluas atau Dilipat

## Analogi: Perpustakaan Digital

Bayangkan **FAQ** di perpustakaan — daftar pertanyaan yang bisa diklik untuk melihat jawabannya. Awalnya hanya pertanyaan yang terlihat. Klik → jawaban muncul.

`<details>` adalah **panel lipat** (accordion) bawaan HTML. `<summary>` adalah **judul** yang selalu terlihat. Klik judul → konten di dalam `<details>` muncul atau tersembunyi.

## Penjelasan Detail

`<details>` membuat widget yang bisa **diperluas (expand)** dan **dilipat (collapse)**. `<summary>` adalah label yang terlihat.

### Struktur
```html
<details>
  <summary>Klik untuk melihat detail</summary>
  <p>Konten tersembunyi muncul saat diklik.</p>
</details>
```

### Atribut `open`
Konten terbuka secara default:
```html
<details open>
  <summary>Judul (terbuka)</summary>
  <p>Konten ini terlihat sejak awal.</p>
</details>
```

### Styling
```css
details {
  border: 1px solid #ddd;
  padding: 10px;
  border-radius: 5px;
}
summary {
  font-weight: bold;
  cursor: pointer;
}
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Details Summary</title>
    <style>
      details {
        border: 1px solid #3498db;
        border-radius: 5px;
        padding: 10px;
        margin: 10px 0;
      }
      summary {
        font-weight: bold;
        cursor: pointer;
        color: #2c3e50;
      }
    </style>
  </head>
  <body>
    <h1>FAQ Perpustakaan Digital</h1>

    <details>
      <summary>Bagaimana cara mendaftar?</summary>
      <p>Klik tombol "Daftar" di pojok kanan atas, isi formulir, dan konfirmasi email.</p>
    </details>

    <details>
      <summary>Berapa maksimal buku yang bisa dipinjam?</summary>
      <p>Maksimal 5 buku per anggota untuk durasi 14 hari.</p>
    </details>

    <details open>
      <summary>Apa saja format buku yang tersedia?</summary>
      <p>Kami menyediakan format PDF, ePub, dan audiobook MP3.</p>
    </details>

    <details>
      <summary>Bagaimana cara mengembalikan buku?</summary>
      <p>Buku digital otomatis dikembalikan setelah masa pinjam habis. Buku fisik bisa dikembalikan di perpustakaan.</p>
    </details>
  </body>
</html>
```

## Poin Penting
- `<details>` = panel **expand/collapse** bawaan HTML
- `<summary>` = judul yang selalu terlihat (klik untuk buka/tutup)
- `open` = terbuka secara default
- Tidak perlu JavaScript — murni HTML
- CSS bisa di-styling untuk tampilan lebih menarik
