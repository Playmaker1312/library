# Tag nav untuk Blok Navigasi Utama Halaman

## Analogi: Perpustakaan Digital

Bayangkan **papan petunjuk** di lobi perpustakaan: "Koleksi Buku →", "Ruang Baca →", "Katalog →", "Kontak →". Papan ini berisi tautan-tautan penting untuk navigasi.

`<nav>` adalah **papan petunjuk** untuk navigasi utama halaman. Membungkus tautan-tautan yang membantu pengguna berpindah antar halaman atau bagian.

## Penjelasan Detail

`<nav>` digunakan untuk **blok navigasi utama**. Tidak semua kumpulan link perlu `<nav>` — hanya navigasi **utama** atau **penting**.

### Kapan Pakai `<nav>`?
- Menu navigasi utama (header)
- Daftar isi
- Breadcrumb ( navigasi hierarki)
- Pagenation (navigasi halaman 1, 2, 3...)
- Menu footer (jika penting)

### Kapan JANGAN Pakai `<nav>`?
- Tautan di artikel (itu bagian dari konten)
- Tautan sosial media di footer (cukup `<footer>`)
- Setiap grup link — hanya yang signifikan

### Contoh
```html
<nav>
  <ul>
    <li><a href="index.html">Beranda</a></li>
    <li><a href="koleksi.html">Koleksi</a></li>
    <li><a href="tentang.html">Tentang</a></li>
  </ul>
</nav>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Nav Tag</title>
  </head>
  <body>
    <header>
      <h1>Perpustakaan Digital</h1>
      <!-- Navigasi utama -->
      <nav>
        <ul>
          <li><a href="index.html">Beranda</a></li>
          <li><a href="koleksi.html">Koleksi Buku</a></li>
          <li><a href="tentang.html">Tentang Kami</a></li>
          <li><a href="kontak.html">Kontak</a></li>
        </ul>
      </nav>
    </header>

    <main>
      <h2>Koleksi Unggulan</h2>
      <p>Selamat datang di Perpustakaan Digital...</p>
    </main>

    <footer>
      <p>&copy; 2024 Perpustakaan Digital</p>
      <nav aria-label="Footer navigation">
        <a href="#">Kebijakan Privasi</a> |
        <a href="#">Syarat Ketentuan</a>
      </nav>
    </footer>
  </body>
</html>
```

## Poin Penting
- `<nav>` = blok **navigasi utama**
- Hanya untuk tautan navigasi yang signifikan
- Boleh lebih dari satu per halaman (gunakan `aria-label` untuk bedakan)
- Biasanya berisi `<ul>` dengan `<a>`
