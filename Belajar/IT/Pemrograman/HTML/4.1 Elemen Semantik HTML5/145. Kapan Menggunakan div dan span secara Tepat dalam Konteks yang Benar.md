# Kapan Menggunakan div dan span secara Tepat dalam Konteks yang Benar

## Analogi: Perpustakaan Digital

Di perpustakaan, ada rak khusus untuk fiksi, rak untuk non-fiksi, dan lemari referensi — ini seperti elemen semantik. Tapi kadang Anda butuh kotak biasa untuk mengelompokkan buku promosi sementara atau label kecil untuk menandai kata asing. `div` dan `span` adalah kotak dan label serbaguna itu: digunakan saat tidak ada tempat khusus yang sesuai, bukan sebagai pengganti rak khusus yang sudah tersedia.

## Penjelasan Detail

Gunakan `<div>` ketika Anda membutuhkan wadah blok semata-mata untuk keperluan styling CSS (seperti grid, flexbox, atau margin) atau untuk manipulasi JavaScript, dan tidak ada elemen semantik seperti `<section>`, `<article>`, `<header>`, atau `<footer>` yang cocok. Gunakan `<span>` untuk membungkus teks inline dalam frasa atau kalimat tanpa mengubah alur paragraf, misalnya untuk menyorot kata tertentu dengan warna berbeda. Jangan gunakan `div` di dalam `<button>` atau `<a>` secara tidak perlu, dan jangan gunakan `div` sebagai pengganti `<p>`, `<h1>`-`<h6>`, atau `<li>`. Prinsip utamanya: jika ada elemen HTML yang mendeskripsikan konten secara semantik, gunakan itu; jika benar-benar tidak ada, barulah `div`/`span`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Kapan Menggunakan div dan span</title>
  <style>
    .grid-container { display: grid; grid-template-columns: 1fr 1fr; gap: 16px; }
    .kartu { border: 1px solid #ccc; padding: 16px; border-radius: 8px; }
    .angka { color: #e74c3c; font-weight: bold; }
  </style>
</head>
<body>
  <h1>Dashboard Statistik</h1>

  <!-- div tepat: wadah grid tidak memiliki elemen semantik yang cocok -->
  <div class="grid-container">
    <div class="kartu">
      <h2>Pengunjung Hari Ini</h2>
      <p><span class="angka">1.247</span> orang</p>
    </div>
    <div class="kartu">
      <h2>Transaksi</h2>
      <p><span class="angka">83</span> transaksi</p>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Gunakan `div` hanya untuk wadah styling/scripting ketika elemen semantik tidak tersedia
- Gunakan `span` hanya untuk membungkus teks inline tanpa mengubah alur paragraf
- Jangan gunakan `div` sebagai pengganti elemen semantik atau paragraf yang sudah memiliki tag sendiri
