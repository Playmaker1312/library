Shadow DOM — DOM Terisolasi

Penjelasan

Shadow DOM adalah fitur Web Components yang memungkinkan kita membuat pohon DOM terisolasi di dalam sebuah elemen. Style dan script di dalam Shadow DOM tidak bocor ke luar (dan sebaliknya). Ini dicapai dengan memanggil this.attachShadow({ mode: 'open' }) pada custom element, yang mengembalikan shadow root — akar dari shadow tree.

Fungsi

  • Mengisolasi style CSS agar tidak bertabrakan dengan style global
  • Mengisolasi struktur DOM internal komponen dari manipulasi luar
  • Memungkinkan komponen memiliki <style> sendiri tanpa risiko bocor
  • Mode open memungk Akses shadow root dari luar via element.shadowRoot

Cara Pengimplementasian

class KartuProyek extends HTMLElement {
    connectedCallback() {
        const shadow = this.attachShadow({ mode: 'open' });
        const judul = this.getAttribute('judul') || 'Proyek';
        const gambar = this.getAttribute('gambar') || 'default.jpg';

        shadow.innerHTML = `
            <style>
                .kartu {
                    border: 2px solid #2ecc71;
                    border-radius: 12px;
                    padding: 20px;
                    font-family: sans-serif;
                    background: #f9f9f9;
                }
                .kartu h3 {
                    color: #2ecc71;
                    margin-top: 8px;
                }
                .kartu img {
                    width: 100%;
                    max-width: 300px;
                    border-radius: 8px;
                }
            </style>
            <div class="kartu">
                <img src="${gambar}" alt="${judul}">
                <h3>${judul}</h3>
            </div>
        `;
    }
}
customElements.define('kartu-proyek', KartuProyek);
<!-- Style global TIDAK memengaruhi elemen di dalam shadow DOM -->
<style>
    .kartu { border: 5px solid red; } /* TIDAK akan menimpa style shadow */
</style>

<kartu-proyek judul="Dashboard Admin" gambar="dashboard.jpg"></kartu-proyek>

Analogi — RUMAH

Shadow DOM seperti dinding kedap suara di setiap kamar dalam sebuah rumah besar. Musik keras di kamar anak tidak terdengar di kamar tamu — style dari luar tidak bocor ke dalam, begitu juga sebaliknya. Setiap kamar (komponen) punya aturan dekorasi sendiri tanpa mengganggu kamar lain. Ini berbeda dengan rumah tanpa sekat (DOM biasa) di mana suara dari satu ruangan bisa mengganggu seluruh rumah.

Dipakai Untuk

  • Komponen UI yang membutuhkan style terisolasi (card, modal, tooltip)
  • Widget pihak ketiga yang tidak boleh terpengaruh style website induk
  • Design system dengan jaminan konsistensi visual
  • Komponen yang dipasarkan sebagai library agar style-nya tidak rusak

Kesalahan Umum

  • Memanggil attachShadow() dua kali pada elemen yang sama — akan error
  • Menggunakan this.innerHTML setelah attachShadow() — shadow root menggantikan innerHTML, jadi konten tidak muncul
  • Menyangka style global bisa menembus shadow DOM — tidak akan terjadi tanpa CSS ::part() atau inherit
  • Lupa menambahkan mode: 'open' sehingga element.shadowRoot bernilai null

Koneksi dengan Materi Sebelumnya

Setelah belajar Custom Elements di materi sebelumnya (membuat tag sendiri), Shadow DOM menambahkan lapisan isolasi. Tanpa Shadow DOM, style komponen bisa tercampur dengan style global. Dengan Shadow DOM, kita mendapat enkapsulasi penuh — komponen jadi benar-benar mandiri seperti modul. Shadow DOM dan Custom Elements bersama-sama membentuk inti Web Components, dan biasanya digabungkan dengan HTML Templates untuk hasil maksimal.

Soal Latihan

1. Buat custom element <kotak-pesan> dengan Shadow DOM yang menampilkan teks pesan dan memiliki style sendiri (border biru, background putih, font italic). Gunakan atribut teks untuk konten pesan.

Lihat Jawaban 
class KotakPesan extends HTMLElement {
    connectedCallback() {
        const shadow = this.attachShadow({ mode: 'open' });
        const teks = this.getAttribute('teks') || 'Pesan kosong';
        shadow.innerHTML = `
            <style>
                .pesan {
                    border: 2px solid #3498db;
                    background: white;
                    padding: 16px;
                    border-radius: 8px;
                    font-style: italic;
                    font-family: sans-serif;
                }
            </style>
            <div class="pesan">${teks}</div>
        `;
    }
}
customElements.define('kotak-pesan', KotakPesan);
<kotak-pesan teks="Selamat datang di website kami!"></kotak-pesan>

2. Jika kita punya style global div { color: red !important; }, apakah teks di dalam Shadow DOM ikut berwarna merah? Jelaskan.

Lihat Jawaban

Tidak. Style global tidak menembus Shadow DOM. Teks di dalam shadow root tetap menggunakan style yang didefinisikan di dalam shadow tree. Inilah inti isolasi Shadow DOM: style luar tidak memengaruhi dalam, dan style dalam tidak memengaruhi luar. Jika ingin komponen terpengaruh style global sebagian, kita bisa menggunakan properti CSS inherit atau CSS ::part().
