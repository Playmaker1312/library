Custom Elements — Membuat Tag HTML Sendiri

Penjelasan

Custom Elements adalah fitur Web Components yang memungkinkan kita membuat elemen HTML kustom dengan perilaku dan tampilan sendiri. Elemen kustom ini dibuat dengan mendefinisikan kelas JavaScript yang mewarisi HTMLElement, lalu didaftarkan ke browser menggunakan customElements.define(). Nama custom element WAJIB mengandung tanda strip (-) agar tidak bertabrakan dengan elemen bawaan HTML.

Fungsi

  • Membuat komponen UI yang dapat dipakai ulang di berbagai halaman
  • Membungkus struktur HTML, style, dan logic dalam satu kesatuan
  • Mempermudah maintain kode karena setiap komponen mandiri
  • Menyediakan lifecycle callback seperti connectedCallback()

Cara Pengimplementasian

// 1. Definisikan kelas yang mewarisi HTMLElement
class KartuProyek extends HTMLElement {
    connectedCallback() {
        const judul = this.getAttribute('judul') || 'Proyek';
        const gambar = this.getAttribute('gambar') || 'default.jpg';
        this.innerHTML = `
            <div style="border:1px solid #ccc; border-radius:8px; padding:16px;">
                <img src="${gambar}" alt="${judul}" style="width:100%;max-width:300px;">
                <h3>${judul}</h3>
            </div>
        `;
    }
}

// 2. Daftarkan ke browser
customElements.define('kartu-proyek', KartuProyek);
<!-- 3. Gunakan di HTML -->
<kartu-proyek judul="Website Portfolio" gambar="portfolio.jpg"></kartu-proyek>
<kartu-proyek judul="Aplikasi POS" gambar="pos.jpg"></kartu-proyek>

Analogi — RUMAH

Custom Elements seperti cetakan rumah di perusahaan properti. Biasanya arsitek mendesain satu cetakan rumah minimalis, lalu cetakan itu bisa dipakai berkali-kali di berbagai perumahan. Setiap rumah dari cetakan yang sama bisa punya warna cat atau type berbeda — mirip seperti <kartu-proyek> yang bisa diisi atribut judul dan gambar yang berbeda-beda. Kita tidak perlu membangun dari nol tiap kali; cukup pakai cetakannya.

Dipakai Untuk

  • Membuat komponen kardus (card) produk, profil, atau proyek
  • Membuat tombol kustom dengan style konsisten
  • Membuat input form khusus seperti date-picker atau color-picker
  • Membangun design system internal perusahaan

Kesalahan Umum

  • Nama elemen tidak mengandung strip (-), misal <kartuproyek> — akan error
  • Mendaftarkan elemen dengan nama yang sama dua kali — akan throw error
  • Lupa memanggil customElements.define() sehingga tag tidak dikenali browser
  • Menggunakan this.innerHTML di luar connectedCallback() sebelum elemen melekat ke DOM

Koneksi dengan Materi Sebelumnya

Custom Elements adalah fondasi utama Web Components setelah kita paham HTML dasar, CSS, dan JavaScript DOM. Di Level sebelumnya kita belajar membangun struktur halaman dengan tag standar seperti <div> dan <section>. Custom Elements melangkah lebih jauh: kita mendefinisikan tag baru yang punya perilaku sendiri. Ini menjadi dasar sebelum belajar Shadow DOM (mengisolasi style) dan HTML Templates (mendefinisikan struktur tanpa render langsung).

Soal Latihan

1. Buat custom element bernama <profil-tim> yang menerima atribut nama dan role, lalu menampilkan kartu profil sederhana.

Lihat Jawaban 
class ProfilTim extends HTMLElement {
    connectedCallback() {
        const nama = this.getAttribute('nama') || 'Anggota';
        const role = this.getAttribute('role') || 'Anggota Tim';
        this.innerHTML = `
            <div style="border-left:4px solid #3498db; padding:12px; margin:8px 0;">
                <strong>${nama}</strong> — ${role}
            </div>
        `;
    }
}
customElements.define('profil-tim', ProfilTim);
<profil-tim nama="Rina" role="Frontend Developer"></profil-tim>
<profil-tim nama="Budi" role="Backend Developer"></profil-tim>

Lihat Jawaban

Browser akan melempar error karena nama tombol tidak mengandung strip (-). Aturan dari spesifikasi HTML mengharuskan custom element memiliki setidaknya satu tanda hubung agar tidak bertabrakan dengan elemen HTML bawaan seperti <button>, <div>, dll.
