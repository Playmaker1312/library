<img>: Tag Gambar di HTML

Penjelasan

Tag <img> adalah tag self-closing (tidak perlu penutup) yang digunakan untuk menampilkan gambar di halaman web. Tag ini termasuk void element, artinya tidak memiliki konten di antara tag pembuka dan penutup.

Contoh penulisan: <img src="foto.jpg" alt="Deskripsi">

Fungsi

Fungsi utama <img> adalah menyisipkan gambar ke dalam halaman web. Gambar bisa berasal dari file lokal, URL eksternal, atau data base64. Tag ini juga berperan dalam layout halaman karena ukurannya memengaruhi tata letak elemen di sekitarnya.

Cara Pengimplementasian

<!-- Contoh dasar -->
<img src="pemandangan.jpg" alt="Pemandangan gunung">

<!-- Dengan ukuran tetap -->
<img src="logo.png" alt="Logo perusahaan" width="200" height="100">

<!-- Gambar dari URL -->
<img src="https://example.com/gambar.jpg" alt="Contoh">

<!-- Self-closing (tidak perlu </img>) -->
<img src="icon.svg" alt="Ikon">
Catatan: Atribut src dan alt bersifat wajib menurut standar aksesibilitas.

Analogi: Rumah dan Bangunan

Tag <img> ibarat jendela pada sebuah rumah. Jendela dipasang di dinding (halaman web) untuk melihat pemandangan luar (gambar). Sama seperti jendela yang punya bingkai dan ukuran tertentu, <img> punya atribut width dan height untuk menentukan dimensinya. Jendela yang dipasang tanpa ukuran yang pas akan membuat tampilan rumah berantakan — begitu juga gambar tanpa ukuran bisa menyebabkan layout shift.

Dipakai Untuk

  • Menampilkan foto produk di toko online
  • Ilustrasi artikel atau blog
  • Logo perusahaan
  • Ikon navigasi
  • Banner dan hero section
  • Foto profil pengguna

Kesalahan Umum

  • Lupa atribut alt: Gambar tidak terbaca oleh screen reader dan tidak ramah SEO.
  • Tidak menentukan width dan height: Menyebabkan layout shift saat gambar dimuat (Cumulative Layout Shift / CLS).
  • Menutup tag dengan </img>: <img> adalah self-closing, tidak perlu penutup.
  • src salah path: Gambar tidak muncul (broken image). Selalu periksa jalur file.
  • Gambar terlalu besar: Memperlambat waktu muat halaman. Gunakan gambar yang sudah dioptimasi.

Koneksi dengan Materi Sebelumnya

<img> sering digunakan di dalam elemen lain seperti <figure> (tag pembungkus gambar), <a> (gambar sebagai tautan), atau di dalam <picture> untuk responsif. Pemahaman tentang atribut global (id, class, style) juga berlaku di sini.

Soal Latihan

1. Tuliskan kode HTML untuk menampilkan gambar bernama kucing.jpg dengan teks alternatif "Seekor kucing lucu" dan ukuran lebar 300 piksel.

Lihat Jawaban 
<img src="kucing.jpg" alt="Seekor kucing lucu" width="300">

2. Apa yang terjadi jika atribut alt tidak disertakan pada tag <img>? Sebutkan minimal dua dampak.

Lihat Jawaban

Dua dampak jika alt tidak disertakan:

  1. Pembaca layar (screen reader) tidak bisa mendeskripsikan gambar kepada pengguna tunanetra.
  2. Mesin pencari (SEO) kehilangan konteks tentang isi gambar, sehingga peringkat pencarian bisa turun.

3. Mengapa kita perlu menentukan width dan height pada tag <img>?

Lihat Jawaban

Menentukan width dan height membantu browser mengalokasikan ruang yang tepat untuk gambar sebelum gambar selesai dimuat. Ini mencegah layout shift (pergerakan konten mendadak) yang mengganggu pengalaman pengguna dan merusak skor Core Web Vital (CLS).
