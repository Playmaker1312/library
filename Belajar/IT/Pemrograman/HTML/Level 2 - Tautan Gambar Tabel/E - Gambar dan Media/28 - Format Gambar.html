Format Gambar di Web: JPEG, PNG, SVG, WebP, GIF

Penjelasan

Setiap format gambar memiliki karakteristik, kelebihan, dan kekurangan masing-masing. Memilih format yang tepat sangat penting untuk mengoptimalkan kecepatan muat halaman, kualitas visual, dan pengalaman pengguna. Berikut adalah format-format utama yang digunakan di web.

Fungsi Masing-Masing Format

Format Fungsi / Cocok Untuk Keunggulan
JPEG (.jpg) Foto, gambar kompleks dengan banyak warna Ukuran file kecil, kualitas baik untuk foto
PNG (.png) Grafis, logo, screenshot, gambar butuh transparansi Dukungan transparansi, lossless, teks tajam
SVG (.svg) Ikon, logo, ilustrasi sederhana, grafik vektor Resolusi tak terbatas, ukuran kecil, bisa diedit dengan kode
WebP (.webp) Pengganti JPEG/PNG modern 25-35% lebih kecil dari JPEG dengan kualitas sama
GIF (.gif) Animasi sederhana, meme, stiker Mendukung animasi, kompatibilitas tinggi

Cara Pengimplementasian

<!-- JPEG untuk foto -->
<img src="liburan.jpg" alt="Foto liburan di pantai">

<!-- PNG untuk logo dengan transparansi -->
<img src="logo-perusahaan.png" alt="Logo Perusahaan">

<!-- SVG langsung di HTML (inline) -->
<img src="icon-rumah.svg" alt="Ikon rumah">

<!-- WebP dengan fallback PNG -->
<picture>
    <source srcset="foto.webp" type="image/webp">
    <img src="foto.png" alt="Foto">
</picture>

<!-- GIF animasi -->
<img src="lucu.gif" alt="Kucing lucu bergerak">

Analogi: Rumah dan Bangunan

Format gambar ibarat jenis material bangunan yang dipilih untuk bagian rumah yang berbeda:

  • JPEG seperti batu bata — murah, kuat, dan cocok untuk dinding luas (foto besar). Tapi tidak cocok untuk detail halus.
  • PNG seperti kaca bening — transparan dan tajam, cocok untuk jendela (logo, ikon). Tapi lebih mahal (ukuran file besar).
  • SVG seperti cetak biru (blueprint) — bisa diperbesar tak terbatas tanpa pecah, dan bisa diubah kapan saja. Cocok untuk gambar teknis.
  • WebP seperti bata ringan modern — lebih ringan dari batu bata biasa dengan kekuatan setara. Paling efisien.
  • GIF seperti lampu kedip-kedip hiasan — menarik perhatian dengan gerakan, tapi kualitasnya rendah dan tidak cocok untuk penerangan utama.

Dipakai Untuk

  • JPEG: Galeri foto, gambar produk, banner, background foto
  • PNG: Logo, ikon, screenshot, UI elements, gambar dengan teks
  • SVG: Ikon navbar, ilustrasi, grafik, diagram, logo responsif
  • WebP: Hampir semua kasus — terutama untuk performa dan kecepatan web
  • GIF: Animasi pendek, meme, preview video sederhana

Kesalahan Umum

  • Menyimpan foto sebagai PNG: Ukuran file bisa 3-5x lebih besar dari JPEG tanpa peningkatan kualitas berarti.
  • Menyimpan logo sebagai JPEG: JPEG tidak punya transparansi dan teks jadi buram. Logo harus PNG atau SVG.
  • Menggunakan GIF untuk video panjang: GIF hanya punya 256 warna dan ukuran file besar. Gunakan <video> untuk animasi panjang.
  • Tidak pakai WebP: WebP di-support oleh 95%+ browser modern dan mengurangi ukuran file hingga 35%. Rugi kalau tidak digunakan.
  • SVG untuk foto kompleks: SVG tidak cocok untuk gambar dengan jutaan warna (foto). Gunakan JPEG/WebP.
  • Lupa fallback WebP: Saat pakai <picture> untuk WebP, selalu sediakan fallback JPEG/PNG untuk browser lama.

Koneksi dengan Materi Sebelumnya

Pemilihan format gambar memengaruhi cara kita menulis tag <img> dan <picture>. Format juga menentukan apakah kita perlu alt yang deskriptif (misal foto produk) atau tidak (gambar dekoratif).

Soal Latihan

1. Sebuah website toko online ingin menampilkan foto produk sepatu. Format apa yang paling efisien? Jelaskan alasannya.

Lihat Jawaban

WebP adalah pilihan terbaik karena ukurannya 25-35% lebih kecil dari JPEG dengan kualitas visual yang sama. Alternatifnya, JPEG juga bisa digunakan. Jangan pakai PNG untuk foto karena ukurannya akan terlalu besar.

2. Format apa yang paling tepat untuk logo perusahaan yang perlu tampil tajam di layar Retina dan ukurannya bisa diubah-ubah (resize)?

Lihat Jawaban

SVG adalah format yang paling tepat karena berbasis vektor, sehingga bisa diperbesar atau diperkecil tanpa kehilangan kualitas. Ukuran file juga sangat kecil untuk logo sederhana.

3. Sebutkan kelebihan utama format WebP dibandingkan JPEG dan PNG!

Lihat Jawaban

Kelebihan utama WebP:

  1. Ukuran file 25-35% lebih kecil dari JPEG dengan kualitas yang sama.
  2. Mendukung transparansi (seperti PNG) dengan ukuran file yang lebih kecil.
  3. Mendukung animasi (seperti GIF) dengan ukuran yang lebih kecil.
