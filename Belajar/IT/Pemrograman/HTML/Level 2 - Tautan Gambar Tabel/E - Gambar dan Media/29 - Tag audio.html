<audio>: Menyisipkan Audio ke Halaman Web

Penjelasan

Tag <audio> digunakan untuk menyisipkan file audio (musik, podcast, rekaman suara) ke dalam halaman web. Dengan atribut controls, browser akan menampilkan pemutar audio bawaan (play, pause, volume, dll). Tag ini mendukung beberapa format file melalui elemen <source>.

Fungsi

  • Memutar file audio langsung di halaman web tanpa plugin tambahan.
  • Menyediakan kontrol pemutaran (play, pause, volume, progress bar).
  • Mendukung autoplay, loop, dan preload untuk berbagai skenario.
  • Fallback ke beberapa format audio melalui <source>.

Cara Pengimplementasian

<!-- Audio dengan kontrol standar -->
<audio controls>
    <source src="lagu.mp3" type="audio/mpeg">
    <source src="lagu.ogg" type="audio/ogg">
    Browser Anda tidak mendukung tag audio.
</audio>

<!-- Autoplay (diam) dan loop -->
<audio controls autoplay muted loop>
    <source src="backsound.mp3" type="audio/mpeg">
</audio>

<!-- Preload -->
<audio controls preload="auto">
    <source src="podcast.mp3" type="audio/mpeg">
</audio>
Catatan: autoplay biasanya hanya bekerja jika muted juga disertakan (kebijakan browser modern).

Analogi: Rumah dan Bangunan

Tag <audio> ibarat sistem interkom (pengeras suara) di dalam rumah. Anda bisa memasangnya di dinding (halaman web) dan mengatur suara yang keluar. Atribut controls seperti tombol volume dan sakelar pada interkom — memudahkan penghuni mengontrol suara. <source> ibarat kabel cadangan: jika kabel utama (MP3) putus, kabel kedua (OGG) masih bisa mengalirkan suara.

autoplay seperti interkom yang otomatis menyala saat ada tamu datang, dan loop seperti lagu yang diputar ulang terus-menerus di ruang tunggu.

Dipakai Untuk

  • Pemutar musik di website portofolio musisi
  • Podcast atau rekaman ceramah
  • Suara latar (backsound) untuk presentasi interaktif
  • Preview lagu di toko musik online
  • Audio buku (audiobook)
  • Efek suara pada game atau aplikasi web

Kesalahan Umum

  • Autoplay tanpa muted: Browser modern memblokir autoplay bersuara. Selalu sertakan muted jika ingin autoplay.
  • Hanya menyediakan satu format audio: Tidak semua browser mendukung MP3. Sediakan alternatif OGG atau AAC.
  • Lupa atribut controls: Tanpa controls, pengguna tidak bisa memutar atau menjeda audio.
  • File audio terlalu besar: Audio berdurasi panjang bisa mencapai puluhan MB. Pertimbangkan untuk mengompresi atau streaming.
  • Teks fallback tidak informatif: Teks di antara tag <audio> adalah fallback untuk browser yang tidak mendukung. Tulis pesan yang jelas.

Koneksi dengan Materi Sebelumnya

<audio> memiliki konsep yang mirip dengan <img> — sama-sama menyematkan media eksternal. Namun, <audio> menggunakan elemen <source> untuk menyediakan format alternatif, mirip seperti <picture> pada gambar. <audio> juga bisa dibungkus dalam <figure> untuk menambahkan <figcaption>.

Soal Latihan

1. Buatlah kode HTML untuk menampilkan pemutar audio dengan file podcast-ep1.mp3 yang memiliki kontrol pemutaran, format cadangan podcast-ep1.ogg, dan otomatis mulai diputar dalam keadaan diam (muted).

Lihat Jawaban 
<audio controls autoplay muted>
    <source src="podcast-ep1.mp3" type="audio/mpeg">
    <source src="podcast-ep1.ogg" type="audio/ogg">
    Browser Anda tidak mendukung tag audio.
</audio>

2. Apa fungsi atribut controls pada tag <audio>? Apa yang terjadi jika atribut ini tidak disertakan?

Lihat Jawaban

Atribut controls menampilkan kontrol pemutar audio seperti tombol play/pause, volume, dan progress bar ke pengguna. Jika tidak disertakan, audio tetap bisa dimuat tapi pengguna tidak bisa memutar, menjeda, atau mengatur volumenya — kecuali dikontrol lewat JavaScript.

3. Mengapa kita perlu menyediakan lebih dari satu format <source> untuk tag <audio>?

Lihat Jawaban

Tidak semua browser mendukung format audio yang sama. Misalnya, browser lama mungkin tidak mendukung MP3, sementara beberapa browser tidak mendukung OGG. Dengan menyediakan multiple <source>, browser akan memilih format pertama yang didukungnya, sehingga audio bisa diputar di berbagai browser.
