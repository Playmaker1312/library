Anchor Link (Tautan Dalam Satu Halaman)

Penjelasan

Anchor link adalah tautan yang mengarah ke bagian tertentu dalam halaman yang sama. Caranya dengan memberikan id unik pada elemen tujuan, lalu di href tuliskan # diikuti id tersebut. Browser akan menggulir (scroll) otomatis ke elemen yang dituju.

Fungsi

Memudahkan navigasi dalam halaman panjang tanpa harus menggulir manual. Sangat berguna untuk daftar isi, one-page website, dokumentasi, atau FAQ.

Cara Pengimplementasian

<!-- Daftar isi (tautan) -->
<nav>
    <ul>
        <li><a href="#sejarah">Sejarah</a></li>
        <li><a href="#fitur">Fitur</a></li>
        <li><a href="#kontak">Kontak</a></li>
    </ul>
</nav>

<!-- Bagian tujuan dengan id -->
<section id="sejarah">
    <h2>Sejarah</h2>
    <p>Isi sejarah...</p>
</section>

<section id="fitur">
    <h2>Fitur</h2>
    <p>Isi fitur...</p>
</section>

<section id="kontak">
    <h2>Kontak</h2>
    <p>Isi kontak...</p>
</section>

Analogi — Rumah

Anchor link bagaikan nomor kamar dalam sebuah rumah besar. Di pintu masuk ada peta kecil: "Kamar 101 — Ruang Tamu", "Kamar 102 — Dapur". Pengunjung cukup lihat peta, lalu langsung menuju kamar dengan nomor yang sesuai. id adalah nomor kamar, href="#id" adalah petunjuk arah ke kamar itu.

Dipakai Untuk

  • One-page website (portofolio, landing page)
  • Daftar isi artikel panjang
  • Navigasi FAQ — langsung ke pertanyaan tertentu
  • Tombol "Kembali ke atas"

Kesalahan Umum

  • Dua elemen memiliki id yang sama — browser hanya menuju ke elemen pertama
  • Lupa tanda # di href, misal href="sejarah" bukan href="#sejarah"
  • Menggunakan name pada <a> (cara lama, sudah tidak disarankan)

Koneksi dengan Materi Sebelumnya

Setelah belajar navigasi antarhalaman dengan <a> (materi 19 dan 21), sekarang kita belajar navigasi dalam satu halaman menggunakan id dan href="#id".

Soal Latihan

  1. Buatlah anchor link menuju bagian dengan id "tentang"!

    Lihat Jawaban 
    <a href="#tentang">Tentang Kami</a>

<!-- ... di bagian lain halaman ... -->
<section id="tentang">
    <h2>Tentang Kami</h2>
    <p>Perusahaan kami berdiri sejak...</p>
</section>

  2. Apa yang terjadi jika ada dua elemen dengan id yang sama dalam satu halaman, dan kita mengklik anchor link menuju id tersebut?

    Lihat Jawaban

    Browser akan menggulir ke elemen pertama yang memiliki id tersebut. Elemen kedua dengan id sama akan diabaikan. Karena itu setiap id harus unik dalam satu halaman.
