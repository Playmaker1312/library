Tautan Email, Telepon, dan Download

Penjelasan

Tag <a> tidak hanya untuk menautkan ke halaman web. Dengan skema URI khusus, kita bisa membuat tautan untuk mengirim email (mailto:), menelepon (tel:), dan mendownload file (atribut download).

Fungsi

Memberi akses langsung ke aplikasi default pengguna — klien email, aplikasi telepon, atau unduhan file — tanpa perlu salin-tempel alamat atau klik kanan save-as.

Cara Pengimplementasian

<!-- Email -->
<a href="mailto:info@example.com">Kirim Email ke Info</a>

<!-- Email dengan subjek -->
<a href="mailto:info@example.com?subject=Halo%20Dunia">Kirim Email dengan Subjek</a>

<!-- Telepon -->
<a href="tel:+628123456789">Hubungi +62 812-3456-789</a>

<!-- Download file -->
<a href="dokumen.pdf" download>Unduh Dokumen PDF</a>

<!-- Download dengan nama file kustom -->
<a href="laporan.pdf" download="Laporan-Tahunan-2025.pdf">Unduh Laporan Tahunan</a>

Analogi — Rumah

Tautan mailto: seperti kotak surat di depan rumah — tinggal memasukkan surat, langsung sampai ke pemilik rumah. tel: seperti interkom — tekan tombol, langsung tersambung ke dalam rumah. Atribut download seperti lemari arsip — ambil dokumen dan salinannya langsung jatuh ke tangan Anda.

Dipakai Untuk

  • mailto: — tombol kontak, form bantuan, tautan dukungan
  • tel: — halaman kontak bisnis, website mobile-friendly
  • download — unduh brosur, katalog, aplikasi, dokumen

Kesalahan Umum

  • mailto: tanpa alamat email — membuka klien email kosong
  • tel: lupa kode negara (+62 untuk Indonesia)
  • Atribut download tidak bekerja untuk file dari domain berbeda (CORS)
  • Menggunakan spasi di URL — harus di-encode sebagai %20

Koneksi dengan Materi Sebelumnya

Setelah mempelajari berbagai jenis tautan (materi 19–23), kini kita perluas lagi: tautan bisa mengakses email, telepon, dan file download — semuanya tetap menggunakan tag <a> yang sama.

Soal Latihan

  1. Buat tautan untuk mengirim email ke halo@example.com dengan subjek "Pertanyaan"!

    Lihat Jawaban 
    <a href="mailto:halo@example.com?subject=Pertanyaan">
    Kirim Pertanyaan via Email
</a>

  2. Buat tautan untuk mendownload file bernama "brosur.pdf" dengan nama kustom "Brosur-Promosi-2025.pdf"!

    Lihat Jawaban 
    <a href="brosur.pdf" download="Brosur-Promosi-2025.pdf">
    Unduh Brosur Promosi 2025
</a>
