URL Absolut vs URL Relatif

Penjelasan

URL absolut adalah alamat lengkap yang mencakup protokol (https://), domain, dan path. Digunakan untuk menuju sumber daya di domain lain. Contoh: https://id.wikipedia.org/wiki/HTML.

URL relatif adalah alamat tanpa domain yang merujuk ke file dalam struktur folder yang sama. Contoh: portofolio.html atau gambar/logo.png.

Fungsi

URL absolut digunakan untuk menautkan ke halaman luar situs, sedangkan URL relatif digunakan untuk navigasi internal agar lebih ringkas dan mudah dipindahkan.

Cara Pengimplementasian

<!-- URL Absolut (domain lain) -->
<a href="https://id.wikipedia.org/wiki/HTML">Wikipedia HTML</a>

<!-- URL Relatif (file sendiri) -->
<a href="portofolio.html">Portofolio Saya</a>

<!-- URL Relatif dengan subfolder -->
<a href="proyek/index.html">Lihat Proyek</a>

<!-- Struktur folder yang umum -->
<!--
project/
├── index.html
├── portofolio.html
├── proyek/
│   └── index.html
└── gambar/
    └── logo.png
-->

Analogi — Rumah

URL absolut seperti alamat lengkap: "Jl. Merdeka No. 10, Jakarta". URL relatif seperti petunjuk dari dalam rumah: "naik ke lantai 2, kamar paling kiri". Alamat absolut selalu sama dari mana pun Anda berasal, sedangkan relatif bergantung pada posisi Anda saat ini.

Dipakai Untuk

  • URL absolut: menautkan ke situs eksternal (Google, Wikipedia, YouTube)
  • URL relatif: navigasi antanhalaman dalam satu situs
  • URL relatif: memudahkan proyek dipindahkan ke domain lain tanpa edit semua tautan

Kesalahan Umum

  • Menggunakan URL absolut untuk tautan internal — menyulitkan saat pindah domain
  • Salah path relatif: misal ../ untuk naik folder tapi lupa struktur folder
  • Lupa protokol https:// pada URL absolut

Koneksi dengan Materi Sebelumnya

Setelah mengenal tag <a> (materi 19), sekarang kita bedakan dua jenis URL yang bisa digunakan di atribut href.

Soal Latihan

  1. Jelaskan perbedaan URL absolut dan URL relatif beserta contoh masing-masing!

    Lihat Jawaban

    URL absolut berisi protokol dan domain lengkap, contoh: https://google.com. URL relatif hanya berisi path dari posisi file saat ini, contoh: tentang.html. URL absolut untuk tautan eksternal, relatif untuk internal.

  2. Jika file Anda berada di folder artikel/index.html dan ingin menautkan ke portofolio.html di folder utama, bagaimana penulisan URL relatifnya?

    Lihat Jawaban 
    <a href="../portofolio.html">Portofolio</a>

    ../ berarti naik satu level folder dari artikel/ ke folder utama, lalu akses portofolio.html.
