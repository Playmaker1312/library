Structured Data dengan JSON-LD

Apa Itu Structured Data JSON-LD?

JSON-LD (JavaScript Object Notation for Linked Data) adalah format data terstruktur yang disisipkan di halaman HTML menggunakan tag <script type="application/ld+json">. Data ini memberi tahu Google secara eksplisit tentang konten halaman — seperti memberi mesin pencari cetak biru detail bangunan Anda, bukan hanya foto luarnya. Google menggunakan data ini untuk menampilkan rich results (hasil pencarian yang diperkaya) seperti bintang ulasan, harga, profil orang, dan lainnya.

Fungsi JSON-LD Structured Data

  • Membantu Google memahami konten secara lebih akurat.
  • Memungkinkan halaman mendapat rich results di SERP (lebih menonjol).
  • Mendukung berbagai schema dari schema.org: Person, Article, Product, FAQ, Event, dll.
  • Mudah diimplementasikan — tidak mengubah tampilan HTML, hanya ditambahkan di <head> atau <body>.

Cara Pengimplementasian

<head>
  <script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "Person",
    "name": "Budi Santoso",
    "jobTitle": "Web Developer & SEO Specialist",
    "email": "budi@contoh.com",
    "url": "https://contoh.com",
    "sameAs": [
      "https://www.linkedin.com/in/budisantoso",
      "https://github.com/budisantoso",
      "https://twitter.com/budisantoso"
    ]
  }
  </script>
</head>

Setelah dipasang, validasi hasilnya di Google Rich Results Test untuk memastikan data terbaca dengan benar.

Analogi: Cetak Biru Bangunan

HTML biasa adalah tampilan luar rumah — cat, jendela, atap — yang bisa dilihat manusia. JSON-LD adalah cetak biru (blueprint) lengkap bangunan yang diberikan langsung kepada kontraktor (Google). Cetak biru ini berisi: ini kamar tidur (Article), ini ruang tamu (Product), ini pemilik rumah (Person), ini pipa ledeng (FAQ). Dengan cetak biru, Google bisa menampilkan informasi lebih kaya di hasil pencarian — misalnya menampilkan foto pemilik rumah, jabatan, dan tautan media sosial langsung di SERP, tanpa pengguna perlu masuk ke halaman.

Dipakai Untuk

  • Halaman profil pribadi atau tim perusahaan (Person schema).
  • Artikel berita dan blog (Article schema) agar muncul di Google News.
  • Halaman produk (Product schema) dengan harga, stok, dan ulasan.
  • Halaman FAQ (FAQ schema) untuk menampilkan tanya jawab langsung di SERP.
  • Event, resep masakan, kursus, video, dan banyak lagi.

Kesalahan Umum

  • Salah properti — menggunakan properti yang tidak ada di schema yang dipilih.
  • JSON tidak valid — koma berlebih, tanda kutip ganda tidak konsisten, dll.
  • Tidak di-escape HTML entities — karakter seperti & harus ditulis sebagai &amp; di dalam nilai JSON.
  • Data tidak cocok dengan konten halaman — Google akan memberi peringatan mismatch.
  • Tidak di-test — langsung deploy tanpa validasi di Rich Results Test.

Koneksi dengan Materi Sebelumnya

Meta tags (materi 53) dan Open Graph (materi 54) memberi tahu Google dan media sosial tentang halaman Anda dalam format metadata. JSON-LD melangkah lebih jauh dengan memberi data terstruktur dalam format yang lebih kaya dan eksplisit. Jika meta tags adalah papan nama dan etalase toko, JSON-LD adalah cetak biru lengkap yang diberikan ke Google agar rumah Anda bisa tampil sebagai bangunan premium di peta kota (SERP). Ketiganya adalah pilar SEO teknis yang saling melengkapi.

Soal Latihan

  1. Apa kepanjangan dari JSON-LD dan di dalam tag HTML apa data ini ditempatkan?

    Lihat Jawaban

    JSON-LD = JavaScript Object Notation for Linked Data. Data ditempatkan di dalam tag <script type="application/ld+json">, biasanya di dalam <head> atau <body>.

  2. Sebutkan minimal 4 properti yang bisa digunakan dalam Person schema!

    Lihat Jawaban

    Properti Person schema: name, jobTitle, email, url, sameAs, image, telephone, address, birthDate, dll.

  3. Jelaskan dengan analogi cetak biru bangunan perbedaan antara meta description biasa dengan JSON-LD structured data!

    Lihat Jawaban

    Meta description ibarat brosur depan rumah yang bilang "Ini rumah Budi, ada 3 kamar, halaman luas." — informatif tapi sederhana. JSON-LD ibarat cetak biru (blueprint) lengkap yang diserahkan ke Google: denah setiap ruangan, material bangunan, posisi jendela, jenis atap, dan siapa pemiliknya. Google bisa membaca cetak biru ini dan menampilkan informasi kaya (rich results) seperti foto pemilik, rating, harga — bukan sekadar teks deskripsi biasa.
