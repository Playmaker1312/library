# Web Storage API Dengan sessionStorage Untuk Menyimpan Data Selama Sesi Browser

## Analogi: Perpustakaan Digital

Seperti kertas tempelan yang Anda letakkan di meja baca selama Anda berada di perpustakaan, sessionStorage menyimpan data hanya selama tab browser terbuka. Begitu Anda pulang (menutup tab), semua catatan tempelan itu hilang.

## Penjelasan Detail

sessionStorage adalah bagian dari Web Storage API HTML5 yang menyimpan data dalam pasangan kunci-nilai hanya selama sesi browser berlangsung. Data akan terhapus secara otomatis saat tab atau jendela browser ditutup, menjadikannya pilihan ideal untuk data sementara seperti status formulir multi-langkah atau token sesi jangka pendek. Setiap tab browser memiliki sessionStorage terpisah, sehingga data tidak dibagikan antar tab meskipun mengunjungi domain yang sama. Seperti localStorage, sessionStorage hanya menyimpan string dan memiliki kapasitas sekitar 5-10 MB per origin. API ini menyediakan metode yang identik dengan localStorage: `setItem()`, `getItem()`, `removeItem()`, dan `clear()`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>sessionStorage Demo</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 500px; margin: auto; padding: 20px; }
    .counter { font-size: 2em; text-align: center; margin: 20px 0; }
    button { padding: 10px 20px; font-size: 16px; margin: 5px; cursor: pointer; }
    .info { padding: 10px; background: #ffecd2; border-radius: 5px; text-align: center; }
  </style>
</head>
<body>
  <h1>Penghitung Sesi (sessionStorage)</h1>
  <div class="info">Data akan hilang saat tab ditutup.</div>
  <div class="counter" id="counter">0</div>
  <div style="text-align: center;">
    <button onclick="tambah()">+1</button>
    <button onclick="reset()">Reset</button>
  </div>
  <script>
    function getCount() { return parseInt(sessionStorage.getItem('count') || '0'); }
    function setCount(val) { sessionStorage.setItem('count', val.toString()); }
    function updateDisplay() { document.getElementById('counter').textContent = getCount(); }
    function tambah() { setCount(getCount() + 1); updateDisplay(); }
    function reset() { setCount(0); updateDisplay(); }
    updateDisplay();
  </script>
</body>
</html>
```

## Poin Penting
- Data sessionStorage hanya bertahan selama tab browser terbuka dan akan terhapus saat tab ditutup
- Setiap tab memiliki sessionStorage terpisah meskipun mengunjungi domain yang sama
- sessionStorage hanya menyimpan string dengan kapasitas 5-10 MB per origin
