# Tag Template Untuk Mendefinisikan Fragmen HTML Yang Tidak Dirender Sampai Dibutuhkan

## Analogi: Perpustakaan Digital

Seperti cetakan buku yang disimpan di gudang dan baru dicetak saat ada pesanan, tag template menyimpan fragmen HTML yang tidak ditampilkan sampai JavaScript menggunakannya. Ini adalah cara efisien untuk menyimpan konten siap pakai tanpa memengaruhi halaman.

## Penjelasan Detail

Tag `<template>` adalah elemen HTML5 yang menyimpan konten HTML yang tidak langsung dirender saat halaman dimuat. Konten di dalam `<template>` tetap diparsing oleh browser tetapi tidak ditampilkan, tidak dijalankan (skrip di dalamnya tidak dieksekusi), dan tidak memuat sumber daya seperti gambar. Konten template dapat diakses dan dikloning melalui JavaScript menggunakan properti `content` yang mengembalikan `DocumentFragment`. Metode `document.importNode()` atau `content.cloneNode(true)` digunakan untuk membuat salinan konten template yang siap disisipkan ke DOM. Tag template sangat berguna untuk membuat struktur berulang seperti baris tabel, item daftar, atau kartu yang dihasilkan dari data dinamis.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Tag Template Demo</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 600px; margin: auto; padding: 20px; }
    .card { border: 1px solid #ddd; border-radius: 8px; padding: 15px; margin: 10px 0; background: #f9f9f9; }
    .card h3 { margin: 0 0 5px 0; color: #2c3e50; }
    .card .role { color: #7f8c8d; font-size: 0.9em; }
    button { padding: 10px 20px; background: #3498db; color: white; border: none; border-radius: 5px; cursor: pointer; }
  </style>
</head>
<body>
  <h1>Template untuk Data Dinamis</h1>
  <button onclick="tambahKartu()">Tambah Anggota Tim</button>
  <div id="container"></div>

  <template id="card-template">
    <div class="card">
      <h3 class="nama">Nama Anggota</h3>
      <p class="role">Posisi</p>
      <p class="bio">Deskripsi singkat tentang anggota tim.</p>
    </div>
  </template>

  <script>
    const tim = [
      { nama: 'Andi Pratama', role: 'Frontend Developer', bio: 'Spesialis HTML, CSS, dan JavaScript.' },
      { nama: 'Siti Rahma', role: 'UI/UX Designer', bio: 'Mendesain antarmuka yang intuitif.' },
      { nama: 'Budi Santoso', role: 'Backend Developer', bio: 'Ahli dalam API dan database.' }
    ];
    let index = 0;
    function tambahKartu() {
      if (index >= tim.length) { alert('Semua anggota sudah ditambahkan!'); return; }
      const template = document.getElementById('card-template');
      const clone = template.content.cloneNode(true);
      clone.querySelector('.nama').textContent = tim[index].nama;
      clone.querySelector('.role').textContent = tim[index].role;
      clone.querySelector('.bio').textContent = tim[index].bio;
      document.getElementById('container').appendChild(clone);
      index++;
    }
  </script>
</body>
</html>
```

## Poin Penting
- Konten dalam `<template>` tidak dirender sampai dikloning dan disisipkan ke DOM dengan JavaScript
- Akses konten template melalui properti `content` yang mengembalikan DocumentFragment
- Template ideal untuk membuat struktur HTML berulang dari data dinamis tanpa menulis HTML di JavaScript
