# Canvas API menggunakan Tag canvas untuk Menggambar Grafis Berbasis Piksel dengan JavaScript

## Analogi: Perpustakaan Digital

Bayangkan **papan tulis kosong** di ruang gambar perpustakaan. Kamu bisa menggambar apa pun di atasnya — lingkaran, persegi, grafik, atau animasi — dengan **kapur digital** (JavaScript).

`<canvas>` adalah **papan tulis digital**. Kamu bisa menggambar grafik, game, visualisasi data, atau animasi menggunakan JavaScript.

## Penjelasan Detail

`<canvas>` menyediakan area gambar yang bisa dimanipulasi dengan **JavaScript** (bukan HTML).

### Atribut
```html
<canvas id="myCanvas" width="400" height="300"></canvas>
```

### Cara Kerja
1. Buat `<canvas>` di HTML
2. Dapatkan konteks 2D dengan JavaScript
3. Gambar menggunakan method canvas API

### Kode JavaScript Dasar
```javascript
const canvas = document.getElementById('myCanvas');
const ctx = canvas.getContext('2d');
ctx.fillStyle = 'blue';
ctx.fillRect(50, 50, 100, 100);  // gambar persegi
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Canvas API</title>
  </head>
  <body>
    <h1>Gambar dengan Canvas</h1>

    <canvas id="bukuCanvas" width="400" height="300"
            style="border: 1px solid #333;"></canvas>

    <script>
      const canvas = document.getElementById('bukuCanvas');
      const ctx = canvas.getContext('2d');

      // Gambar buku
      ctx.fillStyle = '#8B4513';
      ctx.fillRect(50, 50, 200, 150);  // badan buku

      ctx.fillStyle = '#D2691E';
      ctx.fillRect(30, 50, 20, 150);   // sampul

      ctx.fillStyle = 'white';
      ctx.font = '20px Arial';
      ctx.fillText('📖', 120, 150);     // icon buku

      // Lingkaran
      ctx.beginPath();
      ctx.arc(300, 100, 40, 0, Math.PI * 2);
      ctx.fillStyle = '#3498db';
      ctx.fill();
    </script>
  </body>
</html>
```

## Poin Penting
- `<canvas>` = **papan gambar digital** (piksel)
- Membutuhkan **JavaScript** untuk menggambar
- Konteks 2D: `getContext('2d')`
- Method: `fillRect()`, `arc()`, `fillText()`, `beginPath()`
- Untuk grafik, game, visualisasi data
