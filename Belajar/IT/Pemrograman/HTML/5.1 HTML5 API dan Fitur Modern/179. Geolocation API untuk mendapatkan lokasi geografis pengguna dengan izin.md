# Geolocation API Untuk Mendapatkan Lokasi Geografis Pengguna Dengan Izin

## Analogi: Perpustakaan Digital

Seperti petugas perpustakaan yang meminta izin sebelum melihat kartu anggota Anda, Geolocation API meminta persetujuan pengguna sebelum mengakses data lokasi. Ini adalah cara browser untuk mengetahui posisi geografis perangkat secara bertanggung jawab.

## Penjelasan Detail

Geolocation API adalah antarmuka bawaan HTML5 yang memungkinkan aplikasi web mengakses informasi lokasi geografis perangkat pengguna. API ini membutuhkan izin eksplisit dari pengguna sebelum data lokasi dapat diakses, yang ditampilkan browser sebagai dialog notifikasi. Data lokasi dapat diperoleh melalui GPS (pada perangkat seluler), alamat IP, atau sinyal Wi-Fi terdekat. Objek `navigator.geolocation` menyediakan metode `getCurrentPosition()` untuk satu kali permintaan dan `watchPosition()` untuk pemantauan berkelanjutan. Informasi yang dikembalikan mencakup latitude, longitude, akurasi, dan opsional ketinggian serta kecepatan. API ini juga menyediakan metode `clearWatch()` untuk menghentikan pemantauan posisi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Geolocation API</title>
  <style>
    .info { margin-top: 20px; padding: 15px; background: #ecf0f1; border-radius: 8px; }
    button { padding: 10px 20px; font-size: 16px; cursor: pointer; background: #3498db; color: white; border: none; border-radius: 5px; }
    .error { color: #e74c3c; }
  </style>
</head>
<body>
  <h1>Cek Lokasi Saya</h1>
  <button onclick="dapatkanLokasi()">Dapatkan Lokasi</button>
  <div id="lokasi" class="info">Klik tombol untuk melihat lokasi Anda.</div>
  <script>
    function dapatkanLokasi() {
      const info = document.getElementById('lokasi');
      if (!navigator.geolocation) {
        info.innerHTML = '<span class="error">Geolocation tidak didukung browser ini.</span>';
        return;
      }
      info.innerHTML = 'Mendapatkan lokasi...';
      navigator.geolocation.getCurrentPosition(
        function(position) {
          const lat = position.coords.latitude.toFixed(6);
          const lng = position.coords.longitude.toFixed(6);
          const akurasi = position.coords.accuracy.toFixed(0);
          info.innerHTML = `
            <strong>Latitude:</strong> ${lat}<br>
            <strong>Longitude:</strong> ${lng}<br>
            <strong>Akurasi:</strong> ${akurasi} meter
          `;
        },
        function(error) {
          const pesan = {
            1: 'Izin lokasi ditolak.',
            2: 'Tidak dapat menentukan lokasi.',
            3: 'Waktu permintaan habis.'
          };
          info.innerHTML = `<span class="error">${pesan[error.code] || 'Terjadi kesalahan.'}</span>`;
        }
      );
    }
  </script>
</body>
</html>
```

## Poin Penting
- Geolocation API selalu meminta izin pengguna sebelum mengakses data lokasi
- `getCurrentPosition()` untuk satu kali permintaan, `watchPosition()` untuk pemantauan berkelanjutan
- Data lokasi mencakup latitude, longitude, dan akurasi yang dikembalikan dalam objek Position
