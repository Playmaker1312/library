# History API Untuk Memanipulasi Riwayat Browser Tanpa Memuat Ulang Halaman

## Analogi: Perpustakaan Digital

Seperti buku catatan yang mencatat halaman-halaman yang telah Anda baca, History API memungkinkan Anda mencatat dan mengelola riwayat navigasi browser. Anda bisa menandai posisi tertentu dan kembali tanpa harus membuka ulang seluruh buku.

## Penjelasan Detail

History API HTML5 memungkinkan aplikasi web memanipulasi riwayat sesi browser secara programatik tanpa memicu muat ulang halaman penuh. API ini diakses melalui objek `window.history` dan menyediakan metode `pushState()` untuk menambahkan entrin baru ke riwayat, `replaceState()` untuk mengubah entri saat ini, serta `back()`, `forward()`, dan `go()` untuk navigasi. Setiap entri state dapat menyimpan objek data, judul, dan URL. Event `popstate` dipicu saat pengguna menekan tombol back atau forward, memungkinkan aplikasi merespons perubahan riwayat. History API adalah fondasi penting untuk aplikasi web modern dengan navigasi berbasis hash atau pushState, terutama pada Single Page Application (SPA).

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>History API Demo</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 600px; margin: auto; padding: 20px; text-align: center; }
    .page { padding: 40px; border-radius: 10px; margin: 20px 0; }
    button { padding: 10px 20px; margin: 5px; cursor: pointer; font-size: 16px; }
    .info { color: #7f8c8d; margin-top: 20px; }
  </style>
</head>
<body>
  <h1>History API - Navigasi Tanpa Muat Ulang</h1>
  <div id="content" class="page" style="background:#e8f4f8;">
    <h2 id="judul">Halaman Utama</h2>
    <p id="deskripsi">Ini adalah halaman utama aplikasi.</p>
  </div>
  <div>
    <button onclick="pindahHalaman('beranda', 'Beranda', '#e8f4f8')">Beranda</button>
    <button onclick="pindahHalaman('tentang', 'Tentang', '#fce4ec')">Tentang</button>
    <button onclick="pindahHalaman('kontak', 'Kontak', '#e8f5e9')">Kontak</button>
  </div>
  <button onclick="history.back()" style="margin-top:15px;">Kembali</button>
  <div class="info" id="status">Gunakan tombol untuk navigasi. Coba tekan tombol Back browser.</div>
  <script>
    function pindahHalaman(halaman, judul, warna) {
      const state = { halaman, judul, warna };
      history.pushState(state, judul, `?halaman=${halaman}`);
      updateTampilan(state);
    }
    function updateTampilan(state) {
      document.getElementById('judul').textContent = state.judul;
      document.getElementById('content').style.background = state.warna;
      document.getElementById('deskripsi').textContent = `Anda sedang di halaman ${state.judul}.`;
      document.getElementById('status').textContent = `Halaman saat ini: ${state.halaman} | URL: ${window.location.href}`;
    }
    window.addEventListener('popstate', function(event) {
      if (event.state) { updateTampilan(event.state); }
    });
    if (history.state) { updateTampilan(history.state); }
  </script>
</body>
</html>
```

## Poin Penting
- `pushState()` menambah entri riwayat baru, `replaceState()` mengubah entri saat ini tanpa entri baru
- Event `popstate` memungkinkan aplikasi merespons navigasi back/forward pengguna
- History API adalah dasar navigasi SPA tanpa reload halaman penuh
