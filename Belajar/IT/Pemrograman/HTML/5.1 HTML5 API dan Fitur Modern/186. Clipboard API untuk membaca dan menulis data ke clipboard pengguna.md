# Clipboard API Untuk Membaca Dan Menulis Data Ke Clipboard Pengguna

## Analogi: Perpustakaan Digital

Seperti papan klip tempat Anda menjepit catatan sementara untuk dipindahkan dari satu meja ke meja lain, Clipboard API memungkinkan aplikasi web menulis dan membaca data dari clipboard sistem pengguna. Ini adalah cara standar untuk operasi salin-tempel antar aplikasi.

## Penjelasan Detail

Clipboard API adalah antarmuka modern HTML5 yang menyediakan akses aman ke clipboard sistem melalui objek `navigator.clipboard`. API ini menawarkan metode `writeText()` untuk menyalin teks ke clipboard dan `readText()` untuk membaca teks dari clipboard, keduanya mengembalikan Promise. Untuk jenis data yang lebih kompleks seperti gambar, tersedia metode `write()` dan `read()` yang bekerja dengan objek `ClipboardItem`. Karena alasan keamanan, akses baca ke clipboard membutuhkan izin pengguna dan hanya berfungsi dalam konteks yang aman (HTTPS atau localhost). API ini menggantikan metode lama menggunakan `document.execCommand('copy')` yang sekarang sudah tidak direkomendasikan.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Clipboard API Demo</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 500px; margin: auto; padding: 20px; }
    textarea { width: 100%; height: 100px; padding: 10px; margin: 10px 0; border: 1px solid #ccc; border-radius: 5px; font-size: 14px; }
    button { padding: 10px 20px; margin: 5px; cursor: pointer; border: none; border-radius: 5px; font-size: 14px; color: white; }
    .btn-copy { background: #3498db; }
    .btn-paste { background: #27ae60; }
    .msg { margin-top: 10px; padding: 10px; border-radius: 5px; display: none; }
    .msg.success { display: block; background: #d4edda; color: #155724; }
    .msg.error { display: block; background: #f8d7da; color: #721c24; }
  </style>
</head>
<body>
  <h1>Clipboard API</h1>
  <textarea id="teksSumber" placeholder="Tulis teks di sini, lalu salin...">Halo, ini teks contoh!</textarea>
  <div>
    <button class="btn-copy" onclick="salinTeks()">Salin ke Clipboard</button>
    <button class="btn-paste" onclick="tempelTeks()">Tempel dari Clipboard</button>
  </div>
  <textarea id="teksTujuan" placeholder="Teks hasil tempel akan muncul di sini..."></textarea>
  <div id="pesan" class="msg"></div>
  <script>
    async function salinTeks() {
      const teks = document.getElementById('teksSumber').value;
      try {
        await navigator.clipboard.writeText(teks);
        tampilPesan('Teks berhasil disalin ke clipboard!', 'success');
      } catch (err) {
        tampilPesan('Gagal menyalin: ' + err.message, 'error');
      }
    }
    async function tempelTeks() {
      try {
        const teks = await navigator.clipboard.readText();
        document.getElementById('teksTujuan').value = teks;
        tampilPesan('Teks berhasil ditempel dari clipboard!', 'success');
      } catch (err) {
        tampilPesan('Gagal menempel: ' + err.message, 'error');
      }
    }
    function tampilPesan(msg, type) {
      const el = document.getElementById('pesan');
      el.textContent = msg;
      el.className = 'msg ' + type;
      setTimeout(() => el.className = 'msg', 3000);
    }
  </script>
</body>
</html>
```

## Poin Penting
- `navigator.clipboard.writeText()` menyalin teks, `readText()` membaca teks dari clipboard
- Clipboard API bekerja secara asinkron dengan Promise dan membutuhkan konteks aman (HTTPS)
- Membaca clipboard memerlukan izin pengguna dan hanya berfungsi pada aksi pengguna langsung
