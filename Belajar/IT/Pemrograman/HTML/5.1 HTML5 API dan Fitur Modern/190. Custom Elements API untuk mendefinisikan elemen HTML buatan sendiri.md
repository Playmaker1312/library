# Custom Elements API Untuk Mendefinisikan Elemen HTML Buatan Sendiri

## Analogi: Perpustakaan Digital

Seperti membuat kategori buku baru yang tidak ada dalam sistem Dewey Decimal, Custom Elements API memungkinkan Anda menciptakan elemen HTML baru sesuai kebutuhan. Elemen kustom ini memiliki perilaku dan tampilan sendiri yang dapat digunakan di mana saja di halaman.

## Penjelasan Detail

Custom Elements API adalah bagian dari spesifikasi Web Components yang memungkinkan pengembang mendefinisikan elemen HTML baru dengan perilaku kustom. Elemen kustom dibuat dengan mendefinisikan kelas JavaScript yang mewarisi dari `HTMLElement` dan mendaftarkannya menggunakan `customElements.define()`. Nama elemen kustom harus mengandung tanda hubung (seperti `<my-element>`) untuk membedakannya dari elemen HTML bawaan. API ini menyediakan lifecycle callbacks: `connectedCallback()` saat elemen ditambahkan ke DOM, `disconnectedCallback()` saat dihapus, `attributeChangedCallback()` saat atribut berubah, dan `adoptedCallback()` saat dipindahkan ke dokumen baru. Elemen kustom dapat menggunakan `observedAttributes` untuk memantau perubahan atribut tertentu.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Custom Elements API Demo</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 600px; margin: auto; padding: 20px; }
    button { padding: 10px 20px; margin: 10px 0; cursor: pointer; background: #3498db; color: white; border: none; border-radius: 5px; }
  </style>
</head>
<body>
  <h1>Custom Elements Demo</h1>

  <tombol-counter label="Klik Saya"></tombol-counter>
  <badge-status status="sukses">Terkoneksi</badge-status>
  <badge-status status="error">Gagal</badge-status>
  <badge-status status="pending">Menunggu</badge-status>

  <script>
    class TombolCounter extends HTMLElement {
      constructor() {
        super();
        this._count = 0;
        this.attachShadow({ mode: 'open' });
        this.shadowRoot.innerHTML = `
          <style>
            button { padding: 10px 20px; background: #e67e22; color: white; border: none; border-radius: 5px; cursor: pointer; font-size: 16px; }
            span { margin-left: 10px; font-weight: bold; }
          </style>
          <button id="btn">${this.getAttribute('label') || 'Klik'}</button>
          <span id="counter">0</span>
        `;
      }
      connectedCallback() {
        this.shadowRoot.getElementById('btn').addEventListener('click', () => {
          this._count++;
          this.shadowRoot.getElementById('counter').textContent = this._count;
        });
      }
    }

    class BadgeStatus extends HTMLElement {
      constructor() {
        super();
        this.attachShadow({ mode: 'open' });
      }
      connectedCallback() {
        const status = this.getAttribute('status') || 'default';
        const colors = { sukses: '#27ae60', error: '#e74c3c', pending: '#f39c12', default: '#95a5a6' };
        const color = colors[status] || colors.default;
        this.shadowRoot.innerHTML = `
          <style>
            .badge { display: inline-block; padding: 5px 12px; border-radius: 12px; color: white; font-size: 0.85em; margin: 5px; background: ${color}; }
          </style>
          <span class="badge"><slot></slot></span>
        `;
      }
    }

    customElements.define('tombol-counter', TombolCounter);
    customElements.define('badge-status', BadgeStatus);
  </script>
</body>
</html>
```

## Poin Penting
- Elemen kustom harus memiliki nama dengan tanda hubung (kebab-case) seperti `<my-element>`
- Custom Elements memiliki lifecycle callbacks: connectedCallback, disconnectedCallback, attributeChangedCallback
- Daftarkan elemen dengan `customElements.define('nama-elemen', KelasElemen)` untuk dapat digunakan di HTML
