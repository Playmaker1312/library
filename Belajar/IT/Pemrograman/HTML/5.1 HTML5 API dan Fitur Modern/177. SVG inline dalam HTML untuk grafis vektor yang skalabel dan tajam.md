# SVG Inline Dalam HTML Untuk Grafis Vektor Yang Skalabel Dan Tajam

## Analogi: Perpustakaan Digital

Bayangkan Anda memiliki stempel yang tetap tajam di semua ukuran kertas. SVG inline seperti stempel digital yang bisa diperbesar tanpa kehilangan detail. Tidak seperti gambar bitmap yang pecah saat diperbesar, SVG tetap tajam di resolusi berapa pun.

## Penjelasan Detail

SVG (Scalable Vector Graphics) adalah format gambar vektor berbasis XML yang dapat disisipkan langsung ke dalam HTML. Dengan SVG inline, kode SVG ditulis langsung di dokumen HTML sehingga elemen-elemen di dalamnya dapat diakses dan dimanipulasi dengan CSS dan JavaScript. Berbeda dengan gambar raster (PNG, JPEG), SVG menggunakan rumus matematika untuk menggambar bentuk, sehingga tetap tajam di segala ukuran layar. SVG inline juga mengurangi jumlah request HTTP karena tidak perlu memuat file gambar terpisah. Browser modern mendukung penuh SVG sebagai bagian dari standar HTML5.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Contoh SVG Inline</title>
  <style>
    .logo-svg {
      width: 200px;
      height: 200px;
    }
    .logo-svg circle {
      fill: #3498db;
      transition: fill 0.3s;
    }
    .logo-svg:hover circle {
      fill: #e74c3c;
    }
    .logo-svg text {
      font-family: Arial, sans-serif;
      font-size: 20px;
      fill: white;
      text-anchor: middle;
      dominant-baseline: middle;
    }
  </style>
</head>
<body>
  <h1>SVG Inline Interaktif</h1>
  <svg class="logo-svg" viewBox="0 0 100 100" xmlns="http://www.w3.org/2000/svg">
    <circle cx="50" cy="50" r="45" stroke="#2c3e50" stroke-width="2"/>
    <text x="50" y="50">SVG</text>
  </svg>
  <p>Arahkan kursor ke lingkaran untuk melihat perubahan warna.</p>
</body>
</html>
```

## Poin Penting
- SVG inline dapat diubah gaya dan warnanya dengan CSS dan JavaScript secara langsung
- Gambar SVG tetap tajam pada skala berapa pun karena berbasis vektor bukan piksel
- SVG inline mengurangi HTTP request dan memudahkan aksesibilitas elemen grafis
