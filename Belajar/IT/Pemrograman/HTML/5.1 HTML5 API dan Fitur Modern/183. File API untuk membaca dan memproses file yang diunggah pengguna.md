# File API Untuk Membaca Dan Memproses File Yang Diunggah Pengguna

## Analogi: Perpustakaan Digital

Seperti mesin pemindai buku yang mengubah halaman fisik menjadi teks digital, File API memungkinkan browser membaca isi file dari komputer pengguna. Anda bisa membuka, membaca, dan memproses file tanpa harus mengirimnya ke server terlebih dahulu.

## Penjelasan Detail

File API HTML5 memungkinkan aplikasi web membaca file lokal yang dipilih pengguna melalui elemen `<input type="file">` atau drag and drop. Objek `File` mewarisi dari `Blob` dan berisi properti seperti `name`, `size`, `type`, dan `lastModified`. Untuk membaca isi file, tersedia objek `FileReader` dengan metode `readAsText()` untuk file teks, `readAsDataURL()` untuk menampilkan pratinjau gambar, `readAsArrayBuffer()` untuk data biner, dan `readAsBinaryString()`. FileReader bekerja secara asinkron dan memicu event `onload`, `onerror`, dan `onprogress`. API ini juga mendukung pembacaan file dalam bentuk `Blob` sebagian (slice) untuk file berukuran besar.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>File API Demo</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 600px; margin: auto; padding: 20px; }
    .preview { margin-top: 15px; padding: 15px; background: #f9f9f9; border-radius: 8px; min-height: 100px; }
    img.preview-img { max-width: 100%; max-height: 300px; border-radius: 5px; }
    .info { color: #7f8c8d; font-size: 0.9em; }
  </style>
</head>
<body>
  <h1>Upload dan Pratinjau File</h1>
  <input type="file" id="fileInput" accept="image/*,.txt" onchange="prosesFile(event)">
  <div class="preview" id="preview">Pilih file untuk melihat pratinjau.</div>
  <script>
    function prosesFile(event) {
      const file = event.target.files[0];
      const preview = document.getElementById('preview');
      if (!file) { preview.innerHTML = 'Tidak ada file dipilih.'; return; }
      preview.innerHTML = `
        <div class="info">
          Nama: ${file.name}<br>
          Ukuran: ${(file.size / 1024).toFixed(2)} KB<br>
          Tipe: ${file.type || 'Tidak diketahui'}
        </div><hr>
      `;
      const reader = new FileReader();
      if (file.type.startsWith('image/')) {
        reader.onload = function(e) { preview.innerHTML += `<img class="preview-img" src="${e.target.result}" alt="Preview">`; };
        reader.readAsDataURL(file);
      } else if (file.type === 'text/plain' || file.name.endsWith('.txt')) {
        reader.onload = function(e) { preview.innerHTML += `<pre>${e.target.result}</pre>`; };
        reader.readAsText(file);
      } else {
        preview.innerHTML += '<p>File tidak dapat dipratinjau.</p>';
      }
    }
  </script>
</body>
</html>
```

## Poin Penting
- File API membaca file lokal melalui input file atau drag and drop tanpa perlu upload ke server
- Objek FileReader menyediakan metode readAsText, readAsDataURL, dan readAsArrayBuffer
- FileReader bekerja asinkron dengan callback onload, onerror, dan onprogress
