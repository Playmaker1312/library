# Notification API Untuk Mengirim Notifikasi Push Ke Browser Pengguna

## Analogi: Perpustakaan Digital

Seperti sistem pengeras suara yang mengumumkan buku baru telah tiba, Notification API memungkinkan aplikasi web mengirim pemberitahuan langsung ke layar pengguna. Notifikasi ini muncul bahkan saat pengguna sedang membuka tab lain.

## Penjelasan Detail

Notification API HTML5 memungkinkan aplikasi web menampilkan notifikasi sistem kepada pengguna di luar konteks halaman web. API ini diakses melalui konstruktor `new Notification()` setelah mendapatkan izin pengguna melalui metode `Notification.requestPermission()`. Izin notifikasi memiliki tiga status: `granted` (diizinkan), `denied` (ditolak), dan `default` (belum ditentukan). Notifikasi dapat dikustomisasi dengan judul, body, ikon, gambar, dan aksi. Event `onclick` pada notifikasi memungkinkan aplikasi merespons saat pengguna mengklik notifikasi, misalnya membuka halaman tertentu. Notification API biasanya dikombinasikan dengan Service Worker untuk notifikasi push yang berfungsi bahkan saat aplikasi tidak aktif.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Notification API Demo</title>
  <style>
    body { font-family: Arial, sans-serif; text-align: center; padding: 40px; }
    button { padding: 12px 25px; margin: 10px; font-size: 16px; cursor: pointer; border: none; border-radius: 5px; color: white; }
    .btn-izin { background: #3498db; }
    .btn-notif { background: #e67e22; }
    .status { padding: 15px; margin: 20px auto; max-width: 400px; border-radius: 8px; }
  </style>
</head>
<body>
  <h1>Notification API Demo</h1>
  <div id="statusIzin" class="status" style="background:#ecf0f1;">
    Status Izin: Belum ditentukan
  </div>
  <button class="btn-izin" onclick="mintaIzin()">Minta Izin Notifikasi</button>
  <button class="btn-notif" onclick="kirimNotif()">Kirim Notifikasi</button>
  <p>Notifikasi akan muncul di sistem Anda.</p>
  <script>
    function updateStatus() {
      const el = document.getElementById('statusIzin');
      el.textContent = 'Status Izin: ' + Notification.permission;
      el.style.background = Notification.permission === 'granted' ? '#d4edda' :
                            Notification.permission === 'denied' ? '#f8d7da' : '#ecf0f1';
    }
    function mintaIzin() {
      Notification.requestPermission().then(function(permission) {
        updateStatus();
      });
    }
    function kirimNotif() {
      if (Notification.permission === 'granted') {
        const notif = new Notification('Pemberitahuan Baru', {
          body: 'Ini adalah notifikasi dari demo Notification API!',
          icon: 'data:image/svg+xml,<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100"><circle cx="50" cy="50" r="45" fill="%233498db"/></svg>'
        });
        notif.onclick = function() {
          window.focus();
          this.close();
        };
      } else if (Notification.permission === 'denied') {
        alert('Izin notifikasi telah ditolak. Ubah pengaturan browser Anda.');
      } else {
        alert('Mohon izinkan notifikasi terlebih dahulu.');
      }
    }
    updateStatus();
  </script>
</body>
</html>
```

## Poin Penting
- Notification API memerlukan izin pengguna melalui `Notification.requestPermission()` sebelum digunakan
- Notifikasi dapat dikustomisasi dengan judul, body, ikon, dan event onclick untuk respons interaktif
- Cocok dikombinasikan dengan Service Worker untuk notifikasi push latar belakang
