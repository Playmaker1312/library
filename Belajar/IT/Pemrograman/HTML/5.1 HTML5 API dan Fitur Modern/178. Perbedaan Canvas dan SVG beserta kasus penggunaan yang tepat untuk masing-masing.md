# Perbedaan Canvas Dan SVG Beserta Kasus Penggunaan Yang Tepat Untuk Masing-Masing

## Analogi: Perpustakaan Digital

Bayangkan Anda memiliki papan tulis dan sekumpulan stiker magnet. Canvas seperti papan tulis tempat Anda menggambar titik-titik piksel yang tidak bisa diubah setelah dibuat. SVG seperti stiker magnet yang masing-masing bisa dipindahkan, diubah warna, atau dihapus satu per satu.

## Penjelasan Detail

Canvas adalah elemen bitmap berbasis piksel yang digambar dengan JavaScript menggunakan konteks 2D. Setelah digambar, objek di canvas tidak bisa dimanipulasi secara individual tanpa menggambar ulang seluruh kanvas. SVG adalah format vektor berbasis XML di mana setiap elemen grafis adalah node DOM yang dapat diakses dan dimanipulasi secara langsung. Canvas cocok untuk aplikasi yang membutuhkan pembaruan grafis cepat seperti game, rendering piksel per piksel, atau visualisasi data real-time. SVG unggul untuk aplikasi yang membutuhkan interaktivitas elemen individual, skalabilitas sempurna, dan aksesibilitas. Canvas memiliki performa lebih baik untuk ribuan objek yang digambar ulang terus-menerus, sedangkan SVG lebih efisien untuk jumlah elemen yang lebih sedikit dengan interaksi pengguna yang kompleks.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Canvas vs SVG</title>
  <style>
    .container { display: flex; gap: 20px; flex-wrap: wrap; }
    .box { border: 1px solid #ccc; padding: 10px; border-radius: 8px; }
    canvas { border: 1px solid #333; }
    svg { border: 1px solid #333; }
  </style>
</head>
<body>
  <h1>Perbandingan Canvas dan SVG</h1>
  <div class="container">
    <div class="box">
      <h2>Canvas (Bitmap)</h2>
      <canvas id="myCanvas" width="200" height="200"></canvas>
      <button onclick="gambarCanvas()">Gambar Ulang</button>
    </div>
    <div class="box">
      <h2>SVG (Vektor)</h2>
      <svg id="mySvg" width="200" height="200" xmlns="http://www.w3.org/2000/svg">
        <rect id="kotakSvg" x="25" y="25" width="150" height="150" fill="#27ae60" stroke="#2c3e50" stroke-width="2"/>
        <circle id="lingkaranSvg" cx="100" cy="100" r="50" fill="#e67e22" opacity="0.7"/>
      </svg>
      <button onclick="ubahWarnaSvg()">Ubah Warna</button>
    </div>
  </div>
  <script>
    function gambarCanvas() {
      const canvas = document.getElementById('myCanvas');
      const ctx = canvas.getContext('2d');
      ctx.clearRect(0, 0, 200, 200);
      ctx.fillStyle = '#2980b9';
      ctx.fillRect(10, 10, 180, 180);
      ctx.fillStyle = '#e74c3c';
      ctx.beginPath();
      ctx.arc(100, 100, 60, 0, Math.PI * 2);
      ctx.fill();
    }
    function ubahWarnaSvg() {
      const rect = document.getElementById('kotakSvg');
      const circle = document.getElementById('lingkaranSvg');
      rect.setAttribute('fill', rect.getAttribute('fill') === '#27ae60' ? '#8e44ad' : '#27ae60');
      circle.setAttribute('fill', circle.getAttribute('fill') === '#e67e22' ? '#1abc9c' : '#e67e22');
    }
    gambarCanvas();
  </script>
</body>
</html>
```

## Poin Penting
- Canvas bersifat bitmap (piksel) dan digambar per-frame, SVG bersifat vektor dan terstruktur sebagai DOM
- SVG cocok untuk elemen interaktif individual, canvas cocok untuk animasi real-time dengan banyak objek
- SVG mempertahankan ketajaman di segala ukuran, canvas menjadi pecah jika diperbesar
