# Web Storage API Dengan localStorage Untuk Menyimpan Data Tanpa Kedaluwarsa

## Analogi: Perpustakaan Digital

Seperti lemari arsip pribadi yang menyimpan catatan peminjaman tanpa batas waktu, localStorage menyimpan data di browser pengguna secara permanen. Data tidak akan hilang meskipun browser ditutup, seperti dokumen yang tetap berada di lemari sampai sengaja dibuang.

## Penjelasan Detail

localStorage adalah bagian dari Web Storage API HTML5 yang menyimpan data dalam bentuk pasangan kunci-nilai (key-value) di browser pengguna tanpa batas waktu kedaluwarsa. Data tetap tersimpan meskipun tab atau jendela browser ditutup, berbeda dengan sessionStorage yang hanya bertahan selama sesi browser. Kapasitas penyimpanan localStorage umumnya 5-10 MB per domain, jauh lebih besar dibandingkan batas cookie 4 KB. localStorage hanya menyimpan data dalam format string, sehingga objek JavaScript perlu di-serialize menggunakan `JSON.stringify()` sebelum disimpan dan di-parse dengan `JSON.parse()` saat dibaca. API ini menyediakan metode `setItem()`, `getItem()`, `removeItem()`, dan `clear()` untuk mengelola data, serta event `storage` yang dipicu saat data berubah di tab lain.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>localStorage Demo</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 500px; margin: auto; padding: 20px; }
    input { padding: 8px; width: 70%; margin-right: 10px; }
    button { padding: 8px 15px; cursor: pointer; }
    ul { list-style: none; padding: 0; }
    li { padding: 8px; margin: 5px 0; background: #ecf0f1; border-radius: 5px; display: flex; justify-content: space-between; }
    .hapus { cursor: pointer; color: #e74c3c; font-weight: bold; }
  </style>
</head>
<body>
  <h1>Daftar Catatan (localStorage)</h1>
  <div>
    <input type="text" id="catatanInput" placeholder="Tambah catatan...">
    <button onclick="tambahCatatan()">Tambah</button>
  </div>
  <ul id="daftarCatatan"></ul>
  <button onclick="hapusSemua()">Hapus Semua</button>
  <script>
    function getNotes() { return JSON.parse(localStorage.getItem('notes') || '[]'); }
    function saveNotes(notes) { localStorage.setItem('notes', JSON.stringify(notes)); }
    function render() {
      const notes = getNotes();
      const list = document.getElementById('daftarCatatan');
      list.innerHTML = notes.map((n, i) => `<li>${n} <span class="hapus" onclick="hapusCatatan(${i})">X</span></li>`).join('');
    }
    function tambahCatatan() {
      const input = document.getElementById('catatanInput');
      if (!input.value.trim()) return;
      const notes = getNotes();
      notes.push(input.value);
      saveNotes(notes);
      input.value = '';
      render();
    }
    function hapusCatatan(index) {
      const notes = getNotes();
      notes.splice(index, 1);
      saveNotes(notes);
      render();
    }
    function hapusSemua() { localStorage.removeItem('notes'); render(); }
    render();
  </script>
</body>
</html>
```

## Poin Penting
- Data localStorage tidak pernah kedaluwarsa dan bertahan setelah browser ditutup
- Hanya menyimpan string; objek harus di-serialize dengan JSON.stringify/JSON.parse
- Kapasitas 5-10 MB per domain dan data bersifat origin-specific (per protokol + domain + port)
