# Fullscreen API Untuk Menampilkan Elemen Dalam Mode Layar Penuh

## Analogi: Perpustakaan Digital

Seperti membuka buku dengan halaman penuh tanpa gangguan dari rak-rak di sekitarnya, Fullscreen API memungkinkan elemen web ditampilkan secara penuh di layar. Pengguna dapat fokus pada satu konten tanpa distraksi elemen lain di halaman.

## Penjelasan Detail

Fullscreen API HTML5 memungkinkan elemen tertentu atau seluruh halaman ditampilkan dalam mode layar penuh, menutupi seluruh area layar pengguna. API ini diakses melalui metode `element.requestFullscreen()` untuk meminta mode layar penuh pada elemen tertentu, dan `document.exitFullscreen()` untuk keluar dari mode tersebut. Properti `document.fullscreenElement` mengembalikan elemen yang sedang dalam mode layar penuh, atau null jika tidak ada. Event `fullscreenchange` dipicu saat transisi masuk atau keluar mode layar penuh, sementara event `fullscreenerror` dipicu jika permintaan gagal. Browser mengharuskan permintaan layar penuh dipicu oleh aksi pengguna (seperti klik) karena alasan keamanan dan mencegah penyalahgunaan.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Fullscreen API Demo</title>
  <style>
    body { font-family: Arial, sans-serif; text-align: center; padding: 20px; }
    #fullscreen-container {
      width: 600px; height: 350px; margin: 20px auto;
      background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
      color: white; border-radius: 10px;
      display: flex; flex-direction: column;
      align-items: center; justify-content: center;
      transition: all 0.3s;
    }
    #fullscreen-container:-webkit-full-screen { width: 100%; height: 100%; border-radius: 0; }
    #fullscreen-container:fullscreen { width: 100%; height: 100%; border-radius: 0; }
    button { padding: 12px 25px; margin: 10px; font-size: 16px; cursor: pointer; border: none; border-radius: 5px; color: white; }
    .btn-full { background: #3498db; }
    .btn-exit { background: #e74c3c; }
  </style>
</head>
<body>
  <h1>Fullscreen API Demo</h1>
  <div id="fullscreen-container">
    <h2>Konten Layar Penuh</h2>
    <p>Elemen ini dapat ditampilkan dalam mode layar penuh.</p>
    <p>Tekan ESC atau tombol keluar untuk kembali.</p>
  </div>
  <div>
    <button class="btn-full" onclick="bukaFullscreen()">Buka Fullscreen</button>
    <button class="btn-exit" onclick="tutupFullscreen()">Keluar Fullscreen</button>
  </div>
  <p id="status">Status: Normal</p>
  <script>
    const container = document.getElementById('fullscreen-container');
    const status = document.getElementById('status');
    function bukaFullscreen() {
      if (container.requestFullscreen) { container.requestFullscreen(); }
      else if (container.webkitRequestFullscreen) { container.webkitRequestFullscreen(); }
      else if (container.msRequestFullscreen) { container.msRequestFullscreen(); }
    }
    function tutupFullscreen() {
      if (document.exitFullscreen) { document.exitFullscreen(); }
      else if (document.webkitExitFullscreen) { document.webkitExitFullscreen(); }
      else if (document.msExitFullscreen) { document.msExitFullscreen(); }
    }
    document.addEventListener('fullscreenchange', function() {
      status.textContent = document.fullscreenElement ? 'Status: Mode Layar Penuh' : 'Status: Normal';
    });
    document.addEventListener('webkitfullscreenchange', function() {
      status.textContent = document.webkitFullscreenElement ? 'Status: Mode Layar Penuh' : 'Status: Normal';
    });
  </script>
</body>
</html>
```

## Poin Penting
- Gunakan `element.requestFullscreen()` untuk memulai dan `document.exitFullscreen()` untuk keluar mode layar penuh
- Permintaan layar penuh harus dipicu oleh aksi pengguna (klik, sentuhan, atau tombol)
- Event `fullscreenchange` memungkinkan deteksi perubahan status layar penuh
