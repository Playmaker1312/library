# Tag Slot Dan Web Components Sebagai Standar Komponen Web Yang Dapat Digunakan Ulang

## Analogi: Perpustakaan Digital

Seperti rak buku modular yang bisa diisi dengan buku berbeda sesuai kebutuhan, tag slot dalam Web Components memungkinkan Anda membuat komponen dengan bagian yang bisa diisi konten dari luar. Ini adalah cara membuat elemen kustom yang fleksibel dan dapat digunakan ulang.

## Penjelasan Detail

Web Components adalah sekumpulan teknologi HTML5 yang memungkinkan pembuatan elemen kustom yang dapat digunakan ulang dengan fungsionalitas terenkapsulasi. Teknologi utamanya meliputi Custom Elements untuk mendefinisikan elemen baru, Shadow DOM untuk enkapsulasi gaya dan struktur, dan HTML Templates untuk mendefinisikan markup. Tag `<slot>` berfungsi sebagai tempat penyisipan konten dari luar komponen ke dalam Shadow DOM, memungkinkan komponen memiliki konten yang dapat dikustomisasi. Slot dapat memiliki nama (`name` attribute) untuk menunjuk tempat tertentu, dan slot default menangani konten yang tidak memiliki atribut `slot`. Web Components didukung oleh semua browser modern dan dapat digunakan dengan framework JavaScript apa pun.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Web Components & Slot Demo</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 700px; margin: auto; padding: 20px; }
  </style>
</head>
<body>
  <h1>Web Components dengan Slot</h1>

  <kartu-info>
    <span slot="judul">Andi Pratama</span>
    <span slot="role">Frontend Developer</span>
    <p>Andi memiliki pengalaman 5 tahun dalam pengembangan web dan spesialis dalam framework React.</p>
  </kartu-info>

  <kartu-info>
    <span slot="judul">Siti Rahma</span>
    <span slot="role">UI/UX Designer</span>
    <p>Siti mendesain antarmuka pengguna untuk aplikasi mobile dan web dengan fokus pada aksesibilitas.</p>
  </kartu-info>

  <script>
    class KartuInfo extends HTMLElement {
      constructor() {
        super();
        this.attachShadow({ mode: 'open' });
        this.shadowRoot.innerHTML = `
          <style>
            .card { border: 1px solid #ddd; border-radius: 8px; padding: 15px; margin: 15px 0; background: #f9f9f9; }
            .header { display: flex; justify-content: space-between; align-items: center; border-bottom: 1px solid #eee; padding-bottom: 10px; margin-bottom: 10px; }
            ::slotted([slot="judul"]) { font-size: 1.2em; font-weight: bold; color: #2c3e50; }
            ::slotted([slot="role"]) { color: #3498db; font-size: 0.9em; }
          </style>
          <div class="card">
            <div class="header">
              <slot name="judul">Judul Default</slot>
              <slot name="role">Role Default</slot>
            </div>
            <slot></slot>
          </div>
        `;
      }
    }
    customElements.define('kartu-info', KartuInfo);
  </script>
</body>
</html>
```

## Poin Penting
- Slot memungkinkan komponen Web Component menerima konten dari luar dengan fleksibilitas tinggi
- Shadow DOM memberikan enkapsulasi penuh untuk gaya dan struktur komponen
- Web Components adalah standar lintas framework yang didukung semua browser modern
