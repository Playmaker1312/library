# Drag And Drop API Bawaan HTML5 Untuk Fungsi Seret Dan Lepas Elemen

## Analogi: Perpustakaan Digital

Seperti memindahkan buku dari satu rak ke rak lain dengan tangan Anda, Drag and Drop API memungkinkan pengguna memindahkan elemen antarmuka secara langsung. Ini adalah cara alami untuk mengatur ulang konten tanpa perlu menekan tombol atau menu.

## Penjelasan Detail

Drag and Drop API adalah fitur HTML5 yang memungkinkan elemen web diseret dan dilepaskan ke area tujuan menggunakan mouse atau sentuhan. API ini bekerja dengan serangkaian event: `dragstart`, `drag`, `dragenter`, `dragover`, `dragleave`, `drop`, dan `dragend`. Elemen yang ingin diseret membutuhkan atribut `draggable="true"`. Data yang dipindahkan selama operasi drag disimpan dalam objek `dataTransfer` menggunakan metode `setData()` dan diambil dengan `getData()`. Event `dragover` pada elemen tujuan harus dicegah perilaku defaultnya dengan `preventDefault()` agar elemen dapat menerima drop. API ini mendukung efek drag seperti `move`, `copy`, dan `link` melalui properti `effectAllowed` dan `dropEffect`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Drag and Drop</title>
  <style>
    .container { display: flex; gap: 20px; }
    .task-list { width: 200px; min-height: 300px; border: 2px dashed #3498db; border-radius: 8px; padding: 10px; background: #f8f9fa; }
    .task { padding: 10px; margin: 5px 0; background: #3498db; color: white; border-radius: 5px; cursor: grab; }
    .task:active { cursor: grabbing; opacity: 0.7; }
    .task-list.drag-over { background: #d4edda; border-color: #28a745; }
    h3 { text-align: center; margin-top: 0; color: #2c3e50; }
  </style>
</head>
<body>
  <h1>Drag and Drop Tugas</h1>
  <div class="container">
    <div class="task-list" id="todo" ondrop="drop(event)" ondragover="allowDrop(event)">
      <h3>Belum Selesai</h3>
      <div class="task" draggable="true" ondragstart="drag(event)">Belajar HTML</div>
      <div class="task" draggable="true" ondragstart="drag(event)">Membaca Buku</div>
    </div>
    <div class="task-list" id="done" ondrop="drop(event)" ondragover="allowDrop(event)">
      <h3>Selesai</h3>
    </div>
  </div>
  <script>
    function allowDrop(ev) { ev.preventDefault(); }
    function drag(ev) { ev.dataTransfer.setData('text', ev.target.outerHTML); ev.target.remove(); }
    function drop(ev) {
      ev.preventDefault();
      const data = ev.dataTransfer.getData('text');
      ev.target.insertAdjacentHTML('beforeend', data);
      const task = ev.target.lastElementChild;
      task.setAttribute('draggable', 'true');
      task.ondragstart = drag;
    }
  </script>
</body>
</html>
```

## Poin Penting
- Elemen harus memiliki atribut `draggable="true"` agar bisa diseret
- Data dipindahkan melalui objek `dataTransfer` dengan metode `setData()` dan `getData()`
- Event `dragover` pada target drop harus dipanggil `preventDefault()` untuk mengizinkan drop
