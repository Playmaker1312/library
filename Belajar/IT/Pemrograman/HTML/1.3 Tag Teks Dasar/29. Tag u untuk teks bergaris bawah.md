# Tag u untuk Teks Bergaris Bawah

## Analogi: Perpustakaan Digital

Bayangkan **stabilo warna warni** yang digunakan untuk menggaris bawahi teks di papan pengumuman perpustakaan. Garis bawah menarik perhatian ke teks tertentu.

`<u>` (underline) membuat teks memiliki **garis bawah**. Namun hati-hati: di web, teks bergaris bawah biasanya berarti **tautan (link)**. Penggunaan `<u>` bisa membingungkan pengunjung.

## Penjelasan Detail

`<u>` digunakan untuk membuat teks bergaris bawah. Di HTML5, `<u>` memiliki makna semantik: menandai teks yang **berbeda gaya** dari teks biasa, seperti:
- Nama yang salah eja
- Nama diri dalam bahasa China
- Teks anotasi

### Peringatan: Garis Bawah = Link
Di web, pengguna sudah terlatih: **teks biru bergaris bawah = bisa diklik**. Jika kamu pakai `<u>` untuk teks biasa, pengguna bisa salah kira itu link.

### `<u>` vs CSS `text-decoration`
```html
<!-- Kurang disarankan -->
<u>Ini teks bergaris bawah</u>

<!-- Lebih baik, karena jelas untuk gaya -->
<span style="text-decoration: underline;">Ini teks bergaris bawah</span>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Underline</title>
  </head>
  <body>
    <h1>Pengumuman Perpustakaan</h1>

    <p>Nama yang terdaftar: <u>Budi Santoso</u> (nama sudah diverifikasi)</p>

    <p>Ejaan yang benar: <u>analisis</u>, bukan analisa</p>

    <p><u>Catatan:</u> Buku harus dikembalikan tepat waktu.</p>

    <p style="text-decoration: underline;">Alternatif menggunakan CSS.</p>
  </body>
</html>
```

## Poin Penting
- `<u>` = teks **garis bawah**
- Hati-hati: garis bawah di web identik dengan **link**
- Di HTML5, `<u>` punya makna semantik (teks berbeda gaya)
- Lebih aman pakai CSS `text-decoration: underline` untuk gaya murni
