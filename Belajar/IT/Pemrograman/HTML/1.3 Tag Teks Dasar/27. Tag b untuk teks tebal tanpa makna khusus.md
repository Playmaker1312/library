# Tag b untuk Teks Tebal Tanpa Makna Khusus

## Analogi: Perpustakaan Digital

Bayangkan **spidol tebal** yang digunakan pustakawan untuk menandai sampul buku. Tandanya hanya untuk gaya — agar buku terlihat lebih menonjol di rak, tapi tidak ada makna khusus di baliknya.

`<b>` adalah **spidol tebal** itu. Teks di dalamnya tampil **tebal**, tapi **tidak ada makna semantik tambahan**. Berbeda dengan `<strong>` yang menandakan kepentingan, `<b>` hanya mengubah tampilan.

## Penjelasan Detail

`<b>` (bold) digunakan untuk membuat teks tebal **tanpa makna khusus**. Ini adalah presentasi murni.

### Kapan Pakai `<b>`?
- **Kata kunci** dalam ringkasan (tapi tanpa penekanan)
- **Nama produk** dalam artikel
- **Angka** dalam laporan (untuk menonjolkan visual)
- **Awal paragraf** dalam artikel berita (styling)

### Kapan JANGAN Pakai `<b>`?
- Jangan jika ada makna penting (pakai `<strong>`)
- Jangan untuk heading (pakai `<h1>`-`<h6>`)
- Jangan jika kamu bisa pakai CSS

### Urutan Prioritas untuk Teks Tebal
1. `<strong>` → jika ada makna penting
2. CSS `font-weight: bold` → jika hanya gaya
3. `<b>` → jika tidak bisa pakai CSS

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Bold</title>
  </head>
  <body>
    <h1>Koleksi Perpustakaan</h1>

    <p>Buku terbaru: <b>Sejarah Nusantara</b> oleh Bambang Purwanto</p>

    <p>Total koleksi: <b>12.543</b> buku</p>

    <p>Buku terpopuler: <b>Laskar Pelangi</b> (sudah dipinjam <b>2.341</b> kali)</p>
  </body>
</html>
```

## Poin Penting
- `<b>` = teks tebal **tanpa makna khusus**
- Hanya untuk tampilan visual
- Lebih baik pakai `<strong>` jika ada makna penting
- Lebih baik pakai CSS jika bisa
