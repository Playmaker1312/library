# Tag hr untuk Membuat Garis Horizontal Pemisah Konten

## Analogi: Perpustakaan Digital

Bayangkan **garis pemisah** di antara rak-rak buku besar di perpustakaan. Garis ini memberi tahu pengunjung: "Kamu sudah selesai dengan bagian Fiksi. Sekarang masuk ke bagian Non Fiksi."

`<hr>` (horizontal rule) adalah **garis pemisah horizontal** yang memisahkan satu bagian konten dari bagian lainnya. Ini seperti pembatas visual yang membantu pengunjung melihat struktur halaman.

## Penjelasan Detail

`<hr>` adalah **self-closing tag** yang menampilkan garis horizontal. Fungsinya adalah memisahkan konten secara tematik.

### Sejarah
Awalnya `<hr>` hanya garis horizontal dekoratif. Di HTML5, `<hr>` memiliki **makna semantik** — merepresentasikan perpemishan tematik antar konten.

### Kapan Pakai `<hr>`?
- Pemisah antar bab atau bagian
- Pemisah antar artikel di halaman yang sama
- Pemisah antara konten utama dan footer
- Transisi topik yang signifikan

### Styling dengan CSS
```html
<!-- Garis standar -->
<hr>

<!-- Garis dengan CSS -->
<hr style="border: 2px dashed blue; width: 50%;">
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Horizontal Rule</title>
  </head>
  <body>
    <h1>Perpustakaan Digital</h1>

    <h2>Berita Terbaru</h2>
    <p>Perpustakaan akan menambah 1000 buku baru bulan depan.</p>

    <hr>

    <h2>Koleksi Unggulan</h2>
    <p>Buku terpopuler bulan ini adalah "Sejarah Nusantara".</p>

    <hr>

    <h2>Jam Buka</h2>
    <p>Senin - Jumat: 08.00 - 20.00</p>

    <hr>

    <footer>
      <p>&copy; 2024 Perpustakaan Digital</p>
    </footer>
  </body>
</html>
```

## Poin Penting
- `<hr>` = **garis horizontal** pemisah konten
- Self-closing tag (tidak perlu penutup)
- Memisahkan konten secara **tematik**
- Bisa diubah gayanya dengan CSS (warna, tebal, style)
