# Tag sub untuk Teks Subscript seperti Rumus Kimia

## Analogi: Perpustakaan Digital

Bayangkan **buku kimia** di perpustakaan. Di dalamnya ada rumus seperti **H₂O** — angka 2 kecil yang melayang di bawah adalah contoh subscript.

`<sub>` (subscript) membuat teks tampil **setengah ke bawah** dari baris normal, dengan ukuran lebih kecil. Biasanya untuk:
- **Rumus kimia**: H₂O, CO₂
- **Rumus fisika** tertentu
- **Variabel** dalam notasi matematika

## Penjelasan Detail

`<sub>` adalah **inline element** yang menampilkan teks di posisi **subscript** (lebih ke bawah).

### Kapan Pakai `<sub>`?
- **Rumus kimia**: `H<sub>2</sub>O` (air), `CO<sub>2</sub>` (karbon dioksida)
- **Rumus biologi** tertentu
- **Indeks dalam notasi**: `x<sub>1</sub>, x<sub>2</sub>`

### `<sup>` vs `<sub>`
```
Normal text
         ↑ superscript (H₂O → angka 2 di BAWAH)
         ↓ subscript (x² → angka 2 di ATAS)
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Subscript</title>
  </head>
  <body>
    <h1>Rumus Kimia</h1>

    <p>Air: H<sub>2</sub>O</p>
    <p>Karbon dioksida: CO<sub>2</sub></p>
    <p>Glukosa: C<sub>6</sub>H<sub>12</sub>O<sub>6</sub></p>

    <h2>Notasi Matematika</h2>
    <p>Rumus deret: x<sub>1</sub> + x<sub>2</sub> + x<sub>3</sub> + ... + x<sub>n</sub></p>
    <p>Vektor: A<sub>i</sub> + B<sub>j</sub></p>
  </body>
</html>
```

## Poin Penting
- `<sub>` = teks **di bawah** baris normal
- Untuk rumus kimia, indeks, notasi
- Pasangan dari `<sup>` (superscript)
- Ukuran lebih kecil secara otomatis
