# Tag br untuk Membuat Baris Baru Tanpa Paragraf Baru

## Analogi: Perpustakaan Digital

Bayangkan kamu menulis **puisi** di papan pengumuman perpustakaan. Puisi punya baris-baris pendek, dan kamu ingin setiap baris **turun ke bawah** tanpa membuat paragraf baru.

```
Di perpustakaan ini
ada ribuan cerita
menunggu untuk dibaca
```

Tanpa `<br>`, semua kalimat itu akan menggabung jadi satu baris panjang. `<br>` seperti **menekan Enter** di mesin tik — turun satu baris, tapi tidak memulai paragraf baru.

## Penjelasan Detail

`<br>` (line break) digunakan untuk membuat **baris baru** dalam teks. Ini adalah **self-closing tag** — tidak perlu tag penutup.

### Perbedaan `<br>` vs `<p>`
| `<br>` | `<p>` |
|--------|-------|
| Turun satu baris | Turun satu baris + spasi besar |
| Self-closing | Butuh penutup `</p>` |
| Inline effect | Block-level |
| Tidak buat paragraf baru | Buat paragraf baru |

### Kapan Pakai `<br>`?
- Alamat (setiap baris alamat)
- Puisi atau lirik lagu
- Baris dalam tabel
- Format kartu nama

### Kapan JANGAN Pakai `<br>`?
- **Jangan** untuk spasi antar paragraf (pakai `<p>`)
- **Jangan** untuk jarak vertikal besar (pakai CSS margin)

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Line Break</title>
  </head>
  <body>
    <h1>Kontak Perpustakaan</h1>

    <p>
      Perpustakaan Digital<br>
      Jl. Merdeka No. 123<br>
      Jakarta Pusat, 10110<br>
      Indonesia
    </p>

    <p>
      Rindu rasanya membaca buku<br>
      Di rak tinggi penuh ilmu<br>
      <br>
      Kini semua dalam genggaman<br>
      Perpustakaan digitalku sayang
    </p>
  </body>
</html>
```

## Poin Penting
- `<br>` = **line break** → turun satu baris
- Self-closing tag → tidak perlu `</br>`
- Untuk puisi, alamat, baris pendek
- Jangan pakai `<br>` untuk spasi antar paragraf
