# Tag sup untuk Teks Superscript seperti Pangkat Matematika

## Analogi: Perpustakaan Digital

Bayangkan **buku matematika** di perpustakaan. Di dalamnya ada rumus seperti **E = mc²** — angka 2 kecil yang melayang di atas adalah contoh superscript.

`<sup>` (superscript) membuat teks tampil **setengah ke atas** dari baris normal, dengan ukuran lebih kecil. Biasanya untuk:
- **Pangkat** matematika: 10², x³
- **Nomor urut** dalam bahasa asing: 1st, 2nd, 3rd (tapi di web biasanya ditulis biasa)
- **Catatan kaki**: lihat halaman¹

## Penjelasan Detail

`<sup>` adalah **inline element** yang menampilkan teks di posisi **superscript** (lebih ke atas).

### Kapan Pakai `<sup>`?
- **Pangkat/eksponen matematika**: `10<sup>2</sup> = 100`
- **Rumus ilmiah**: `m<sup>3</sup>` (meter kubik)
- **Catatan kaki**: `Ini adalah kutipan<sup>[1]</sup>`
- **Tanggal ordinal** (jarang di web): `May 22<sup>nd</sup>`

### `<sup>` vs `<sub>`
```
Normal text
         ↑ superscript (di atas)
         ↓ subscript (di bawah)
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Superscript</title>
  </head>
  <body>
    <h1>Rumus Matematika dan Sains</h1>

    <p>Luas persegi: sisi<sup>2</sup></p>
    <p>Volume kubus: sisi<sup>3</sup></p>
    <p>Rumus爱因斯坦: E = mc<sup>2</sup></p>

    <p>Kecepatan cahaya: 3 × 10<sup>8</sup> m/s</p>

    <p>Luas Indonesia: 1.904.569 km<sup>2</sup></p>

    <p>Footnote contoh<sup>[1]</sup></p>
    <hr>
    <p><small><sup>[1]</sup> Ini adalah catatan kaki dari teks di atas.</small></p>
  </body>
</html>
```

## Poin Penting
- `<sup>` = teks **di atas** baris normal
- Untuk pangkat, eksponen, catatan kaki
- Pasangan dari `<sub>` (subscript)
- Ukuran lebih kecil secara otomatis
