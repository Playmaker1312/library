# Tag small untuk Teks Berukuran Lebih Kecil

## Analogi: Perpustakaan Digital

Bayangkan **catatan kaki** di bagian bawah halaman buku. Tulisannya lebih kecil dari teks utama, berisi informasi tambahan seperti sumber referensi, catatan hukum, atau detail teknis.

`<small>` adalah **tulisan kecil** di HTML. Digunakan untuk teks yang secara visual perlu lebih kecil dari teks di sekitarnya.

## Penjelasan Detail

`<small>` membuat teks tampil **satu ukuran lebih kecil** dari teks di sekitarnya. Di HTML5, `<small>` memiliki makna semantik: untuk **teks cetakan kecil** (fine print) seperti:
- Disclaimer
- Catatan hukum
- Hak cipta
- Syarat dan ketentuan
- Catatan kaki

### Ukuran Relatif
`<small>` bisa bersarang — semakin dalam, semakin kecil:
```html
<p>Teks normal.</p>
<p><small>Teks kecil.</small></p>
<p><small><small>Teks lebih kecil lagi.</small></small></p>
```

### `<small>` vs CSS `font-size`
```html
<!-- Untuk teks cetakan kecil (disclaimer, copyright) -->
<small>&copy; 2024 Perpustakaan Digital</small>

<!-- Untuk ukuran kecil karena gaya -->
<span style="font-size: 12px;">Teks kecil karena desain</span>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Small Text</title>
  </head>
  <body>
    <h1>Perpustakaan Digital</h1>

    <p>Selamat datang di perpustakaan digital kami.</p>

    <p><small>* Syarat dan ketentuan berlaku. Peminjaman maksimal 5 buku.</small></p>

    <hr>

    <footer>
      <p><small>&copy; 2024 Perpustakaan Digital. Hak cipta dilindungi undang-undang.</small></p>
      <p><small><small>Versi 2.1.0 — Terakhir diperbarui: 15 Januari 2024</small></small></p>
    </footer>
  </body>
</html>
```

## Poin Penting
- `<small>` = teks ukuran **lebih kecil**
- Untuk disclaimer, copyright, catatan kaki
- Bisa bersarang (semakin dalam semakin kecil)
- Punya makna semantik di HTML5
