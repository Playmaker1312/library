# Tag Heading dari h1 hingga h6 dan Hierarki Penggunaannya

## Analogi: Perpustakaan Digital

Bayangkan **papan penanda rak** di perpustakaan digital. Papan ini membantu pengunjung menemukan buku dengan cepat:

- **`<h1>`** = **Papan utama** di pintu masuk: "PERPUSTAKAAN DIGITAL" (judul besar, paling penting, hanya satu)
- **`<h2>`** = **Penanda lantai/sayap**: "Lantai 1 - Fiksi", "Lantai 2 - Non Fiksi"
- **`<h3>`** = **Penanda rak**: "Rak A - Novel Indonesia", "Rak B - Novel Asing"
- **`<h4>`** = **Label sub-rak**: "Penulis 2000-an", "Penulis 2010-an"
- **`<h5>`** = **Label grup buku**: "Seri Harry Potter", "Seri Laskar Pelangi"
- **`<h6>`** = **Label detail**: "Jilid 1", "Jilid 2" (jarang dipakai)

Semakin kecil nomor heading, semakin **penting dan besar** tulisannya.

## Penjelasan Detail

Heading adalah tag untuk **judul dan sub-judul** dalam halaman HTML. Ada 6 level: `<h1>` (terpenting) hingga `<h6>` (terkurang penting).

### Aturan Hierarki
```html
<h1>Judul Utama Halaman</h1>
  <h2>Sub-bab 1</h2>
    <h3>Topik detail 1.1</h3>
    <h3>Topik detail 1.2</h3>
  <h2>Sub-bab 2</h2>
    <h3>Topik detail 2.1</h3>
```

### Aturan Penting
1. **Satu `<h1>` per halaman** — judul utama, menggambarkan isi halaman
2. **Jangan loncat hierarki** — dari h1 langsung h3 itu tidak disarankan
3. **Urut dan logis** — seperti outline makalah
4. **Heading untuk judul, bukan untuk ukuran** — jangan pakai `<h1>` hanya karena ingin tulisan besar

### Heading vs CSS
```html
<!-- SALAH: pakai heading untuk ukuran -->
<h1>Ini cuma teks biasa yang mau gede</h1>

<!-- BENAR: pakai CSS untuk ukuran -->
<p style="font-size: 32px;">Ini teks biasa yang digedein</p>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Heading Example</title>
  </head>
  <body>
    <h1>Perpustakaan Digital</h1>

    <h2>Koleksi Buku</h2>
    <h3>Fiksi</h3>
    <h4>Novel Indonesia</h4>
    <h4>Novel Terjemahan</h4>
    <h3>Non Fiksi</h3>
    <h4>Sejarah</h4>
    <h4>Sains</h4>

    <h2>Tentang Kami</h2>
    <h3>Visi dan Misi</h3>
    <h3>Tim Kami</h3>
  </body>
</html>
```

## Poin Penting
- 6 level heading: `<h1>` (terbesar) hingga `<h6>` (terkecil)
- Hanya SATU `<h1>` per halaman
- Jangan loncat hierarki (h1 → h3)
- Heading untuk struktur, bukan untuk ukuran font
- Heading penting untuk SEO dan aksesibilitas screen reader
