# Tag i untuk Teks Miring Tanpa Makna Khusus

## Analogi: Perpustakaan Digital

Bayangkan **tulisan miring** di sampul buku atau label rak. Mungkin untuk menunjukkan judul buku atau kata asing. Tulisannya miring, tapi tidak ada penekanan makna — hanya konvensi gaya penulisan.

`<i>` adalah **tulisan miring biasa**. Berbeda dengan `<em>` yang menekankan makna, `<i>` hanya mengubah tampilan teks menjadi miring.

## Penjelasan Detail

`<i>` (italic) digunakan untuk teks miring **tanpa makna khusus**. Fungsinya murni visual/stylistic.

### Kapan Pakai `<i>`?
- **Judul buku, film, lagu** — "Buku <i>Laskar Pelangi</i> sangat populer"
- **Istilah asing** — "Dia membaca buku <i>in memoriam</i> kakeknya"
- **Nama ilmiah** — "Tanaman <i>Rafflesia arnoldii</i>"
- **Kata atau frasa dalam bahasa lain** — "Konsep <i>wabi-sabi</i> dari Jepang"
- **Suara hati/pikiran karakter** dalam tulisan

### `<i>` vs `<em>` vs `<cite>`

| Tag | Makna | Contoh |
|-----|-------|--------|
| `<i>` | Miring biasa, tanpa makna | Kata asing: <i>bon voyage</i> |
| `<em>` | Penekanan makna | Saya <em>sangat</em> suka |
| `<cite>` | Judul karya | Buku <cite>Laskar Pelangi</cite> |

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Italic</title>
  </head>
  <body>
    <h1>Resensi Buku</h1>

    <p>Buku <i>Laskar Pelangi</i> karya Andrea Hirata telah diterjemahkan ke berbagai bahasa.</p>

    <p>Konsep <i>gigih</i> dalam budaya Jepang mengajarkan kita untuk tidak menyerah.</p>

    <p>Dalam botani, bunga ini dikenal sebagai <i>Rafflesia arnoldii</i>.</p>

    <p>Dia berpikir, <i>mungkin ini saatnya membaca buku baru</i>.</p>
  </body>
</html>
```

## Poin Penting
- `<i>` = teks miring **tanpa makna khusus**
- Untuk judul, istilah asing, nama ilmiah, pikiran karakter
- Jika ada penekanan makna, pakai `<em>`
- Jika judul karya, pakai `<cite>`
