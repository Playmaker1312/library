# Atribut width dan height untuk Mengatur Ukuran Gambar

## Analogi: Perpustakaan Digital

Bayangkan kamu ingin memajang **foto di dinding** perpustakaan. Kamu harus memilih **ukuran pigura** — lebar dan tinggi. Foto yang terlalu besar akan keluar dari bingkai, terlalu kecil akan meninggalkan banyak ruang kosong.

Atribut `width` dan `height` pada `<img>` adalah **ukuran pigura** untuk gambar.

## Penjelasan Detail

`width` dan `height` mengatur **ukuran tampilan** gambar di halaman.

### Format
```html
<!-- Pixel -->
<img src="foto.jpg" width="300" height="200">

<!-- Persentase (CSS) -->
<img src="foto.jpg" style="width: 50%;">
```

### Aturan Penting
1. **Jangan ubah rasio aspek** — jika gambar asli 600x400, width 300 harus height 200 (rasio 3:2). Jika dipaksa 300x100, gambar akan **terdistorsi**

2. **Width dan height adalah atribut presentasi** — lebih baik pakai CSS untuk desain responsif

3. **Nilai hanya dalam pixel** (tanpa satuan `px`). Untuk persentase, pakai CSS

### Cara Menjaga Rasio Aspek dengan CSS
```html
<!-- Width diatur, height otomatis -->
<img src="foto.jpg" style="width: 300px; height: auto;">

<!-- Maksimal lebar, proporsional -->
<img src="foto.jpg" style="max-width: 100%; height: auto;">
```

### Perbedaan Atribut vs CSS
```html
<!-- Atribut HTML (ukuran tetap) -->
<img src="foto.jpg" width="300" height="200">

<!-- CSS (lebih fleksibel) -->
<img src="foto.jpg" style="width: 300px; height: auto;">
<img src="foto.jpg" style="max-width: 100%; height: auto;">
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Width Height</title>
    <style>
      .responsive {
        max-width: 100%;
        height: auto;
      }
    </style>
  </head>
  <body>
    <h1>Ukuran Gambar</h1>

    <h2>Atribut width dan height</h2>
    <img src="https://via.placeholder.com/600x400" alt="Gambar 600x400" width="300" height="200">

    <h2>Hanya width (height otomatis)</h2>
    <img src="https://via.placeholder.com/600x400" alt="Width 200" width="200">

    <h2>Ukuran berbeda (distorsi — JANGAN)</h2>
    <img src="https://via.placeholder.com/600x400" alt="Distorsi" width="300" height="100">

    <h2>Responsive (CSS max-width)</h2>
    <img src="https://via.placeholder.com/600x400" alt="Responsive" class="responsive">

    <h2>Gambar asli (tanpa atribut ukuran)</h2>
    <img src="https://via.placeholder.com/600x400" alt="Asli 600x400">
  </body>
</html>
```

## Poin Penting
- `width` = lebar gambar (dalam pixel)
- `height` = tinggi gambar (dalam pixel)
- Jangan ubah **rasio aspek** — gambar akan gepeng/terdistorsi
- Untuk responsif, pakai CSS `max-width: 100%; height: auto;`
- Nilai tanpa satuan (angka saja) untuk atribut HTML
