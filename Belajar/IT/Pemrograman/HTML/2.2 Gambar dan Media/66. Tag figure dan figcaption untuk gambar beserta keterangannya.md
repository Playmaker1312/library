# Tag figure dan figcaption untuk Gambar Beserta Keterangannya

## Analogi: Perpustakaan Digital

Bayangkan sebuah **foto di museum** yang punya label keterangan di bawahnya:

```
┌──────────────────────┐
│                      │
│   [Foto Gedung]      │
│                      │
└──────────────────────┘
  Gedung Perpustakaan
  Digital tahun 2020
```

`<figure>` adalah **bingkai foto** — membungkus gambar. `<figcaption>` adalah **label keterangan** — teks penjelasan yang terkait langsung dengan gambar.

## Penjelasan Detail

`<figure>` dan `<figcaption>` bekerja berpasangan untuk menampilkan **konten independen** (gambar, ilustrasi, diagram, kode) beserta **keterangannya**.

### Struktur
```html
<figure>
  <img src="gedung.jpg" alt="Gedung Perpustakaan">
  <figcaption>Gedung Perpustakaan Digital tahun 2020</figcaption>
</figure>
```

### Keuntungan
- **Semantik** — jelas bahwa teks caption terkait dengan gambar
- **Styling mudah** — bungkus figure, atur border/margin
- **Aksesibilitas** — hubungan gambar dan caption jelas

### `<figcaption>` Posisi
Bisa di **atas** atau **bawah** gambar:
```html
<figure>
  <figcaption>Judul di atas</figcaption>
  <img src="foto.jpg" alt="Foto">
</figure>

<figure>
  <img src="foto.jpg" alt="Foto">
  <figcaption>Keterangan di bawah</figcaption>
</figure>
```

### `<figure>` Tidak Hanya untuk Gambar
Bisa juga untuk kode, kutipan, video, dll:
```html
<figure>
  <pre><code>console.log("Halo")</code></pre>
  <figcaption>Contoh kode JavaScript</figcaption>
</figure>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Figure Figcaption</title>
    <style>
      figure {
        border: 1px solid #ddd;
        padding: 10px;
        margin: 20px 0;
        text-align: center;
        background: #fafafa;
      }
      figcaption {
        font-style: italic;
        color: #666;
        margin-top: 8px;
      }
    </style>
  </head>
  <body>
    <h1>Galeri Perpustakaan</h1>

    <figure>
      <img src="https://via.placeholder.com/400x250/2c3e50/ffffff?text=Gedung+Perpustakaan" alt="Gedung Perpustakaan">
      <figcaption>Gedung Perpustakaan Digital — Diresmikan tahun 2020</figcaption>
    </figure>

    <figure>
      <figcaption>Koleksi Buku Fiksi Terbaru</figcaption>
      <img src="https://via.placeholder.com/400x250/e74c3c/ffffff?text=Koleksi+Buku" alt="Koleksi buku fiksi">
    </figure>

    <!-- Figure untuk kode -->
    <figure>
      <pre><code>&lt;h1&gt;Halo Dunia&lt;/h1&gt;</code></pre>
      <figcaption>Contoh tag heading HTML</figcaption>
    </figure>
  </body>
</html>
```

## Poin Penting
- `<figure>` = **bingkai** untuk konten independen
- `<figcaption>` = **keterangan** untuk konten di figure
- Meningkatkan **semantik** dan **aksesibilitas**
- `<figcaption>` bisa di atas atau bawah
- `<figure>` tidak hanya gambar — bisa kode, kutipan, dll.
