# Atribut src width height dan frameborder pada Tag iframe

## Analogi: Perpustakaan Digital

Bayangkan **jendela ajaib** (iframe) di perpustakaan digitalmu. Jendela ini punya pengaturan:

- **`src`** → Pemandangan apa yang terlihat di jendela (URL tujuan)
- **`width`** → Seberapa lebar jendela
- **`height`** → Seberapa tinggi jendela
- **`frameborder`** → Apakah ada bingkai/pigura di sekeliling jendela

Atribut-atribut ini mengontrol **tampilan dan sumber** dari iframe.

## Penjelasan Detail

### src
Menentukan **URL** halaman yang akan ditampilkan di dalam iframe.
```html
<iframe src="https://example.com"></iframe>
```

### width dan height
Mengatur **ukuran** iframe dalam pixel (tanpa satuan) atau persentase (CSS).
```html
<iframe src="page.html" width="600" height="400"></iframe>
<!-- atau dengan CSS -->
<iframe src="page.html" style="width: 100%; height: 400px;"></iframe>
```

### frameborder (usang — pakai CSS)
Atribut HTML lama untuk mengatur border. Nilai: `0` (tanpa border) atau `1` (dengan border).
```html
<iframe src="page.html" frameborder="0"></iframe>
```
Di HTML5, lebih baik pakai CSS:
```css
iframe { border: none; }  /* atau border: 1px solid #ddd; */
```

### allowfullscreen
Mengizinkan iframe untuk ditampilkan dalam mode **layar penuh** (khusus video).
```html
<iframe src="https://youtube.com/embed/ID" allowfullscreen></iframe>
```

### loading
Optimasi performa: muat iframe hanya saat mendekati viewport.
```html
<iframe src="page.html" loading="lazy"></iframe>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Iframe Attributes</title>
    <style>
      iframe.demo { border: 2px solid #3498db; border-radius: 8px; }
    </style>
  </head>
  <body>
    <h1>Atribut Iframe</h1>

    <h2>Iframe dengan Ukuran Kustom</h2>
    <iframe src="https://id.wikipedia.org/wiki/HTML"
      width="300" height="200"
      title="Wikipedia HTML">
    </iframe>

    <h2>Iframe Tanpa Border (frameborder)</h2>
    <iframe src="https://id.wikipedia.org/wiki/HTML"
      width="400" height="200"
      frameborder="0"
      title="Tanpa border">
    </iframe>

    <h2>Iframe dengan CSS Border Modern</h2>
    <iframe src="https://id.wikipedia.org/wiki/HTML"
      width="400" height="200"
      class="demo"
      title="Dengan border CSS">
    </iframe>

    <h2>Iframe YouTube (allowfullscreen)</h2>
    <iframe width="400" height="225"
      src="https://www.youtube.com/embed/dQw4w9WgXcQ"
      title="YouTube"
      allowfullscreen>
    </iframe>
  </body>
</html>
```

## Poin Penting
- `src` = **alamat** konten (wajib)
- `width`/`height` = **ukuran** iframe
- `frameborder` = atribut lama (ganti dengan CSS)
- `allowfullscreen` = izinkan layar penuh
- `loading="lazy"` = muat saat dibutuhkan
