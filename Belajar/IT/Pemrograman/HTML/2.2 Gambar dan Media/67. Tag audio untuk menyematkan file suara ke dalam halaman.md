# Tag audio untuk Menyematkan File Suara ke dalam Halaman

## Analogi: Perpustakaan Digital

Bayangkan **ruang audio** di perpustakaan digital. Pengunjung bisa mendengarkan **buku audio** (audiobook), **musik pengiring**, atau **podcast** sambil membaca.

`<audio>` adalah **pemutar audio digital** yang bisa kamu sematkan langsung di halaman HTML. Pengunjung bisa memutar, menjeda, dan mengatur volume tanpa aplikasi tambahan.

## Penjelasan Detail

`<audio>` digunakan untuk menyematkan file suara ke halaman web.

### Format yang Didukung
| Format | Browser Support |
|--------|----------------|
| MP3 | Semua browser modern |
| WAV | Semua browser modern |
| OGG | Firefox, Chrome, Opera |
| AAC | Safari, Chrome |

**Rekomendasi**: gunakan **MP3** — didukung semua browser.

### Atribut `<audio>`
| Atribut | Fungsi |
|---------|--------|
| `controls` | Menampilkan kontrol pemutar (play, pause, volume) |
| `autoplay` | Putar otomatis saat halaman dimuat |
| `loop` | Ulangi terus-menerus |
| `muted` | Senyap (volume 0) saat mulai |
| `preload` | Cara memuat audio (`none`, `metadata`, `auto`) |
| `src` | Lokasi file audio |

### Contoh
```html
<audio controls src="audiobook.mp3"></audio>
```

### Multiple Sources (Fallback)
Gunakan tag `<source>` untuk menyediakan format alternatif:
```html
<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
  <source src="audio.ogg" type="audio/ogg">
  Browser tidak mendukung audio.
</audio>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Audio</title>
  </head>
  <body>
    <h1>Audiobook Perpustakaan</h1>

    <h2>Pemutar Audio Dasar</h2>
    <audio controls src="audiobook-sample.mp3">
      Browser tidak mendukung pemutar audio.
    </audio>

    <h2>Audio dengan Multiple Sources</h2>
    <audio controls preload="metadata">
      <source src="audiobook.mp3" type="audio/mpeg">
      <source src="audiobook.ogg" type="audio/ogg">
      Maaf, browser Anda tidak mendukung pemutar audio.
    </audio>

    <h2>Audio Autoplay (muted — diizinkan browser)</h2>
    <audio controls autoplay muted loop src="background-music.mp3">
      Musik latar perpustakaan
    </audio>
  </body>
</html>
```

## Poin Penting
- `<audio>` = **pemutar suara** di halaman web
- Atribut `controls` = tampilkan tombol play/pause/volume
- **MP3** adalah format yang paling kompatibel
- Gunakan `<source>` untuk fallback format
- `autoplay` sering diblokir browser — gunakan `muted` juga
