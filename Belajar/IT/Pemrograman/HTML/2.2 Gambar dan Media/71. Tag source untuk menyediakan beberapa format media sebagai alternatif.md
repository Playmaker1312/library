# Tag source untuk Menyediakan Beberapa Format Media sebagai Alternatif

## Analogi: Perpustakaan Digital

Bayangkan sebuah **buku** tersedia dalam beberapa format: cetak keras, PDF, ePub, dan MP3 (audiobook). Jika pengunjung tidak bisa membaca PDF, mereka bisa baca ePub. Jika tidak bisa ePub, mereka bisa dengar audiobook.

`<source>` adalah **format alternatif** untuk media HTML. Kamu sediakan file yang sama dalam berbagai format, dan browser akan memilih **format pertama yang bisa diputar**.

## Penjelasan Detail

`<source>` digunakan di dalam `<video>`, `<audio>`, atau `<picture>` untuk menyediakan **sumber media alternatif**.

### Atribut `<source>`
| Atribut | Fungsi |
|---------|--------|
| `src` | Lokasi file media |
| `type` | Tipe MIME media (membantu browser memilih tanpa unduh) |
| `media` | Media query (untuk `<picture>`) |
| `sizes` | Ukuran gambar (untuk `<picture>`) |
| `srcset` | Set gambar responsif (untuk `<picture>`) |

### Cara Kerja
Browser akan memeriksa `<source>` **satu per satu dari atas ke bawah**:
```html
<video controls>
  <source src="video.mp4" type="video/mp4">     ← Coba ini dulu
  <source src="video.webm" type="video/webm">   ← Jika tidak support, coba ini
  <source src="video.ogv" type="video/ogg">     ← Jika tidak, coba ini
  Browser tidak support video.                   ← Jika semua gagal
</video>
```

### Tipe MIME Umum
| Format | Tipe MIME |
|--------|-----------|
| MP4 video | `video/mp4` |
| WebM video | `video/webm` |
| OGG video | `video/ogg` |
| MP3 audio | `audio/mpeg` |
| WAV audio | `audio/wav` |
| OGG audio | `audio/ogg` |
| WebP gambar | `image/webp` |
| JPEG gambar | `image/jpeg` |
| PNG gambar | `image/png` |

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Source Tag</title>
  </head>
  <body>
    <h1>Media dengan Format Alternatif</h1>

    <h2>Video dengan Fallback</h2>
    <video controls width="500">
      <source src="tutorial.mp4" type="video/mp4">
      <source src="tutorial.webm" type="video/webm">
      <source src="tutorial.ogv" type="video/ogg">
      Maaf, browser Anda tidak mendukung video.
    </video>

    <h2>Audio dengan Fallback</h2>
    <audio controls>
      <source src="podcast.mp3" type="audio/mpeg">
      <source src="podcast.ogg" type="audio/ogg">
      Maaf, browser tidak mendukung audio.
    </audio>

    <h2>Gambar dengan Fallback (Picture)</h2>
    <picture>
      <source srcset="logo.webp" type="image/webp">
      <source srcset="logo.png" type="image/png">
      <img src="logo.png" alt="Logo">
    </picture>
  </body>
</html>
```

## Poin Penting
- `<source>` = **sumber alternatif** untuk media
- Browser pilih **format pertama** yang didukung
- Urutan: letakkan format **terbaik/modern** di atas
- Atribut `type` membantu browser memilih tanpa mengunduh
- Teks di luar `<source>` = fallback jika semua gagal
