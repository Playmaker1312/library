# Tag img untuk Menyisipkan Gambar ke dalam Halaman HTML

## Analogi: Perpustakaan Digital

Bayangkan **foto atau ilustrasi** yang dipajang di dinding perpustakaan. Gambar ini bisa berupa foto gedung, ilustrasi buku, atau peta lokasi.

`<img>` adalah **pigura foto digital**. Kamu tinggal tentukan sumber gambarnya (`src`), dan browser akan menampilkan gambar di halaman.

## Penjelasan Detail

`<img>` adalah **self-closing tag** untuk menampilkan gambar.

### Atribut Wajib
| Atribut | Fungsi | Contoh |
|---------|--------|--------|
| `src` | **Lokasi/sumber file gambar** | `src="logo.png"` |
| `alt` | **Teks alternatif** (aksesibilitas) | `alt="Logo Perpustakaan"` |

### Atribut Opsional
```html
<img src="foto.jpg" alt="Deskripsi" width="300" height="200" title="Keterangan" loading="lazy">
```

| Atribut | Fungsi |
|---------|--------|
| `width` | Lebar gambar (pixel atau %) |
| `height` | Tinggi gambar |
| `title` | Tooltip saat hover |
| `loading="lazy"` | Muat gambar hanya saat mendekati viewport |
| `style` | CSS inline |

### Format Gambar untuk Web
| Format | Kelebihan | Cocok Untuk |
|--------|-----------|-------------|
| JPEG/JPG | Ukuran kecil, jutaan warna | Foto, gambar kompleks |
| PNG | Transparansi, lossless | Logo, ikon, screenshot |
| GIF | Animasi | Animasi sederhana |
| WebP | Ukuran kecil + kualitas tinggi | Modern, semua jenis |
| SVG | Vektor, skalabel tak terbatas | Ikon, ilustrasi, logo |

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Images</title>
  </head>
  <body>
    <h1>Galeri Perpustakaan</h1>

    <!-- Gambar dasar -->
    <img src="logo-perpus.png" alt="Logo Perpustakaan Digital">

    <!-- Gambar dengan ukuran -->
    <img src="gedung-perpus.jpg" alt="Gedung Perpustakaan" width="600" height="400">

    <!-- Gambar dengan lebar persentase (responsive) -->
    <img src="banner.jpg" alt="Banner Promosi" style="width: 100%; max-width: 800px;">

    <!-- Gambar dengan lazy loading -->
    <img src="foto-koleksi.jpg" alt="Koleksi Buku" loading="lazy">

    <!-- Gambar dari URL eksternal -->
    <img src="https://via.placeholder.com/300x200" alt="Placeholder">
  </body>
</html>
```

## Poin Penting
- `<img>` = menampilkan gambar
- `src` = sumber gambar (wajib)
- `alt` = teks alternatif (wajib untuk aksesibilitas)
- Self-closing tag — tidak perlu `</img>`
- `width` dan `height` untuk ukuran
- `loading="lazy"` untuk optimasi performa
