# Tag track untuk Menyisipkan Subtitle atau Caption pada Video

## Analogi: Perpustakaan Digital

Bayangkan **film dokumenter** di perpustakaan. Beberapa pengunjung tunarungu perlu **teks terjemahan** (subtitle). Pengunjung lain mungkin ingin subtitle dalam bahasa Inggris, Mandarin, atau Arab.

`<track>` adalah **lembar subtitle** yang bisa dipilih penonton. Kamu sediakan beberapa file `.vtt` (WebVTT) dalam berbagai bahasa, dan pengguna bisa memilih subtitle yang diinginkan.

## Penjelasan Detail

`<track>` digunakan di dalam `<video>` atau `<audio>` untuk menambahkan **track teks** — subtitle, caption, atau deskripsi.

### Atribut `<track>`
| Atribut | Fungsi |
|---------|--------|
| `src` | Lokasi file `.vtt` (WebVTT) |
| `kind` | Jenis track (`subtitles`, `captions`, `descriptions`, `chapters`, `metadata`) |
| `srclang` | Bahasa track (kode ISO: `id`, `en`, `ja`, dll) |
| `label` | Nama yang tampil di menu subtitle |
| `default` | Jadikan track default (jika pengguna tidak memilih) |

### Format File WebVTT (.vtt)
File teks berisi subtitle dengan timestamp:
```vtt
WEBVTT

1
00:00:01.000 --> 00:00:04.000
Selamat datang di Perpustakaan Digital

2
00:00:05.000 --> 00:00:08.000
Kami memiliki ribuan koleksi buku gratis
```

### `kind` yang Tersedia
| Kind | Fungsi |
|------|--------|
| `subtitles` | Terjemahan dialog (asumsi penonton bisa dengar) |
| `captions` | Transkripsi + efek suara (untuk tunarungu) |
| `descriptions` | Deskripsi visual (untuk tunanetra) |
| `chapters` | Penanda bab untuk navigasi video |
| `metadata` | Data tambahan (jarang) |

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Track / Subtitle</title>
  </head>
  <body>
    <h1>Video dengan Subtitle</h1>

    <video controls width="600" poster="poster.jpg">
      <source src="dokumenter.mp4" type="video/mp4">

      <!-- Subtitle Indonesia (default) -->
      <track
        kind="subtitles"
        src="subtitle-id.vtt"
        srclang="id"
        label="Bahasa Indonesia"
        default>

      <!-- Subtitle Inggris -->
      <track
        kind="subtitles"
        src="subtitle-en.vtt"
        srclang="en"
        label="English">

      <!-- Caption untuk tunarungu -->
      <track
        kind="captions"
        src="caption-id.vtt"
        srclang="id"
        label="Teks Lengkap (tunarungu)">

      Maaf, browser tidak mendukung video.
    </video>

    <p>Klik ikon CC atau Settings di pemutar untuk memilih subtitle.</p>
  </body>
</html>
```

**File: subtitle-id.vtt**
```vtt
WEBVTT

1
00:00:02.000 --> 00:00:06.000
Selamat datang di Perpustakaan Digital

2
00:00:07.000 --> 00:00:12.000
Kami menyediakan ribuan buku gratis untuk Anda
```

## Poin Penting
- `<track>` = **subtitle/caption** untuk video
- Gunakan format **WebVTT** (.vtt)
- `kind="subtitles"` = terjemahan, `kind="captions"` = teks lengkap
- Tambahkan beberapa track untuk **multibahasa**
- `default` = subtitle yang aktif tanpa intervensi pengguna
