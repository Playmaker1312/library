# Pertimbangan Keamanan saat Menggunakan iframe dari Sumber Eksternal

## Analogi: Perpustakaan Digital

Bayangkan kamu membuat **jendela ajaib** (iframe) yang memperlihatkan halaman dari luar. Tapi jendela itu bisa menjadi **celah keamanan**:
- Situs luar bisa menampilkan konten phishing
- Situs luar bisa melacak pengunjungmu
- Situs luar bisa menjalankan skrip berbahaya

Untungnya, HTML punya **pengaman jendela** untuk melindungi perpustakaandigitalmu.

## Penjelasan Detail

### Risiko Keamanan iframe
1. **Clickjacking** — situs jahat menyembunyikan tombol di bawah iframe transparan, pengguna mengklik sesuatu yang tidak mereka sadari
2. **Pelacakan** — iframe bisa melacak aktivitas pengguna via cookie
3. **Malware** — iframe bisa memuat halaman yang mengandung virus
4. **Phishing** — iframe bisa menampilkan halaman login palsu

### Atribut `sandbox` — Pengaman Utama
`sandbox` membatasi apa yang bisa dilakukan konten dalam iframe.
```html
<iframe src="situs-luar.com" sandbox></iframe>
```
Dengan `sandbox` saja (tanpa nilai), **semua** fitur dibatasi:
- Tidak bisa menjalankan JavaScript
- Tidak bisa mengirim form
- Tidak bisa membuka popup
- Tidak bisa mengakses DOM induk

### Nilai `sandbox` yang Tersedia
| Nilai | Fungsi |
|-------|--------|
| (kosong) | Batasi semua |
| `allow-scripts` | Izinkan JavaScript |
| `allow-same-origin` | Izinkan akses ke asal yang sama (hati-hati!) |
| `allow-forms` | Izinkan pengiriman form |
| `allow-popups` | Izinkan popup |
| `allow-modals` | Izinkan alert/confirm |
| `allow-top-navigation` | Izinkan navigasi ke halaman induk |

### Kombinasi yang Aman
```html
<!-- Paling aman: batasi semua -->
<iframe sandbox src="situs-luar.com"></iframe>

<!-- Sedang: izinkan script dan form, tapi jangan akses induk -->
<iframe sandbox="allow-scripts allow-forms" src="situs-luar.com"></iframe>
```

### Atribut `loading` untuk Performa
```html
<iframe src="widget.html" loading="lazy"></iframe>
```

### Cek Apakah Situs Bisa di-iframe
Beberapa situs mengirim header `X-Frame-Options: DENY` atau `SAMEORIGIN` — ini berarti mereka **tidak ingin** di-iframe oleh situs lain. Browser akan menolak menampilkannya.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Iframe Security</title>
  </head>
  <body>
    <h1>Iframe dengan Keamanan</h1>

    <h2>Sandbox Paling Aman (tanpa izin)</h2>
    <iframe sandbox src="https://example.com"
      width="400" height="200"
      title="Sandbox penuh">
    </iframe>

    <h2>Sandbox dengan JavaScript dan Form</h2>
    <iframe sandbox="allow-scripts allow-forms"
      src="https://example.com/widget"
      width="400" height="200"
      title="Sandbox terbatas">
    </iframe>

    <h2>Sandbox untuk YouTube (hanya script)</h2>
    <iframe sandbox="allow-scripts allow-same-origin allow-popups"
      src="https://www.youtube.com/embed/VIDEO_ID"
      width="400" height="225"
      allowfullscreen
      title="Video YouTube aman">
    </iframe>

    <h2>Iframe dengan lazy loading</h2>
    <iframe src="https://example.com" loading="lazy"
      width="400" height="200"
      title="Lazy load">
    </iframe>
  </body>
</html>
```

## Poin Penting
- iframe dari sumber eksternal = **risiko keamanan**
- Gunakan `sandbox` untuk **membatasi** fitur konten iframe
- `sandbox` tanpa nilai = batasi SEMUA
- Tambahkan izin sesuai kebutuhan (`allow-scripts`, `allow-forms`, dll)
- Beberapa situs tidak bisa di-iframe karena `X-Frame-Options`
- `loading="lazy"` untuk optimasi
