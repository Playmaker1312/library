# Atribut src untuk Menentukan Lokasi atau Sumber File Gambar

## Analogi: Perpustakaan Digital

Bayangkan **rak buku** yang kosong. Rak itu tidak berguna sampai kamu meletakkan buku di dalamnya. Kamu harus tahu persis di mana buku itu berada — di lantai berapa, rak mana, baris ke berapa.

Atribut `src` pada `<img>` adalah **petunjuk lokasi buku**. Kamu memberi tahu browser: "Gambar ini ada di folder `img`, nama filenya `logo.png`."

## Penjelasan Detail

`src` (source) menentukan **lokasi file gambar** yang akan ditampilkan. Ini adalah atribut **WAJIB** pada `<img>`.

### Nilai `src` yang Umum

| Jenis | Contoh | Keterangan |
|-------|--------|------------|
| **Relatif** | `src="gambar/logo.png"` | File dalam project sendiri |
| **Absolut** | `src="https://situs.com/gambar.jpg"` | File dari server lain |
| **Data URI** | `src="data:image/png;base64,..."` | Gambar di-encode dalam kode HTML |

### Path Relatif

```
/project
  /index.html     ← halaman saat ini
  /logo.png       ← src="logo.png"
  /img
    /foto.jpg     ← src="img/foto.jpg"
  /assets
    /images
      /banner.png ← src="assets/images/banner.png"
```

Dari `index.html`:
- `logo.png` → sama folder
- `img/foto.jpg` → subfolder `img`
- `../images/icon.png` → naik dulu, masuk folder `images`

### Kesalahan Umum
```html
<!-- SALAH: path salah -->
<img src="gambar.jpg">  <!-- file tidak ada di folder ini -->
<img src="img/gambar.jpg">  <!-- tapi file ada di folder images/, bukan img/ -->

<!-- BENAR -->
<img src="images/gambar.jpg">
```

### Cara Memeriksa
Jika gambar tidak muncul:
1. Klik kanan gambar rusak → "Open image in new tab"
2. Lihat URL-nya — apakah path benar?
3. Periksa nama file (case-sensitive di beberapa server)
4. Periksa ekstensi file

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>SRC Attribute</title>
  </head>
  <body>
    <h1>Berbagai Cara Menentukan SRC</h1>

    <h2>1. Path Relatif (folder yang sama)</h2>
    <img src="logo.png" alt="Logo" width="100">

    <h2>2. Path Relatif (subfolder)</h2>
    <img src="img/gedung.jpg" alt="Gedung" width="300">

    <h2>3. URL Absolut (dari internet)</h2>
    <img src="https://via.placeholder.com/300x150/3498db/ffffff?text=Perpustakaan" alt="Placeholder">

    <h2>4. Gambar Rusak (path salah)</h2>
    <img src="file-tidak-ada.jpg" alt="Gambar tidak tersedia" width="200">
    <!-- Catatan: alt akan tampil karena gambar tidak ditemukan -->
  </body>
</html>
```

## Poin Penting
- `src` = **sumber** file gambar (wajib)
- **Relatif**: path dari posisi file HTML
- **Absolut**: URL lengkap dari internet
- Jika gambar tidak muncul, periksa path-nya
- Gambar dari folder yang sama tinggal tulis nama filenya
