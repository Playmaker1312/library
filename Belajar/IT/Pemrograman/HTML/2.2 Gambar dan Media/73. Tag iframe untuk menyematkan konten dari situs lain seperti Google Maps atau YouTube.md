# Tag iframe untuk Menyematkan Konten dari Situs Lain

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan digitalmu memiliki **jendela ajaib** yang memperlihatkan pemandangan dari tempat lain. Lewat jendela ini, pengunjung bisa melihat **Google Maps**, **video YouTube**, atau **halaman Wikipedia** — tanpa meninggalkan perpustakaanmu.

`<iframe>` (inline frame) adalah **jendela ajaib** itu. Kamu bisa menyematkan halaman web lain, video, peta, atau konten eksternal langsung di dalam halamanmu.

## Penjelasan Detail

`<iframe>` digunakan untuk menyematkan (**embed**) dokumen HTML lain di dalam halaman saat ini.

### Atribut Penting
| Atribut | Fungsi |
|---------|--------|
| `src` | URL halaman/konten yang disematkan |
| `width` | Lebar iframe |
| `height` | Tinggi iframe |
| `frameborder` | Border iframe (0 atau 1) — usang, pakai CSS |
| `allowfullscreen` | Izinkan mode layar penuh |
| `loading` | `lazy` = muat saat mendekati viewport |
| `sandbox` | Pembatasan keamanan (nilai: `allow-scripts`, `allow-same-origin`, dll) |
| `title` | Deskripsi (untuk aksesibilitas) |
| `name` | Nama iframe (untuk target link) |

### Contoh Umum Embed

```html
<!-- YouTube -->
<iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID"
  allowfullscreen></iframe>

<!-- Google Maps -->
<iframe width="600" height="450" src="https://www.google.com/maps/embed?pb=..."></iframe>

<!-- Wikipedia -->
<iframe src="https://id.wikipedia.org/wiki/HTML" width="600" height="400"></iframe>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Iframe</title>
    <style>
      iframe { border: 1px solid #ddd; margin: 10px 0; }
    </style>
  </head>
  <body>
    <h1>Konten Eksternal</h1>

    <h2>Video YouTube</h2>
    <iframe width="560" height="315"
      src="https://www.youtube.com/embed/dQw4w9WgXcQ"
      title="Video tutorial"
      allowfullscreen
      loading="lazy">
    </iframe>

    <h2>Google Maps</h2>
    <iframe width="600" height="450"
      src="https://www.google.com/maps/embed?pb=!1m18!1m12!1m3!..."
      title="Lokasi Perpustakaan"
      allowfullscreen
      loading="lazy">
    </iframe>

    <h2>Halaman Web Lain</h2>
    <iframe src="https://id.wikipedia.org/wiki/Perpustakaan"
      width="600" height="400"
      title="Artikel Wikipedia tentang Perpustakaan">
    </iframe>
  </body>
</html>
```

## Poin Penting
- `<iframe>` = **jendela** ke halaman/konten lain
- Untuk embed YouTube, Google Maps, halaman web, dll.
- Atribut `title` penting untuk **aksesibilitas**
- `loading="lazy"` untuk optimasi performa
- **Keamanan**: situs lain bisa membatasi iframe (X-Frame-Options)
