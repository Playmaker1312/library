# Tag video untuk Menyematkan File Video ke dalam Halaman

## Analogi: Perpustakaan Digital

Bayangkan **ruang teater mini** di perpustakaan digital. Pengunjung bisa menonton **video dokumenter, tutorial, atau film pendek** langsung di halaman web.

`<video>` adalah **layar pemutar film** yang bisa kamu sematkan langsung di HTML. Tanpa perlu plugin atau aplikasi tambahan.

## Penjelasan Detail

`<video>` digunakan untuk menyematkan file video ke halaman web.

### Format yang Didukung
| Format | Browser Support |
|--------|----------------|
| MP4 (H.264) | **Semua browser modern** — paling aman |
| WebM | Chrome, Firefox, Opera |
| OGG/Theora | Firefox, Chrome (legacy) |

**Rekomendasi**: gunakan **MP4 (H.264)** untuk kompatibilitas maksimal. Tambahkan WebM sebagai fallback.

### Atribut `<video>`
| Atribut | Fungsi |
|---------|--------|
| `controls` | Tampilkan kontrol pemutar |
| `autoplay` | Putar otomatis |
| `loop` | Ulangi terus |
| `muted` | Senyap saat mulai |
| `poster` | Gambar thumbnail sebelum video diputar |
| `preload` | Cara memuat (`none`, `metadata`, `auto`) |
| `width` | Lebar pemutar |
| `height` | Tinggi pemutar |

### Struktur dengan Multiple Sources
```html
<video controls width="640" height="360" poster="thumbnail.jpg">
  <source src="video.mp4" type="video/mp4">
  <source src="video.webm" type="video/webm">
  Browser tidak mendukung video.
</video>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Video</title>
  </head>
  <body>
    <h1>Video Perpustakaan</h1>

    <h2>Video Dasar dengan Controls</h2>
    <video controls width="640" height="360">
      <source src="tour-perpus.mp4" type="video/mp4">
      <source src="tour-perpus.webm" type="video/webm">
      Maaf, browser Anda tidak mendukung pemutar video.
    </video>

    <h2>Video dengan Poster (thumbnail)</h2>
    <video controls width="640" poster="poster-perpus.jpg">
      <source src="dokumenter.mp4" type="video/mp4">
    </video>

    <h2>Video Autoplay + Muted + Loop</h2>
    <video autoplay muted loop width="400">
      <source src="background-video.mp4" type="video/mp4">
    </video>
  </body>
</html>
```

## Poin Penting
- `<video>` = **pemutar video** di halaman web
- Format paling aman: **MP4 (H.264)**
- `controls` = WAJIB untuk UX (kecuali autoplay)
- `poster` = thumbnail sebelum video diputar
- Gunakan `<source>` untuk format alternatif
- Teks di antara `<video>` dan `</video>` = fallback jika browser tidak support
