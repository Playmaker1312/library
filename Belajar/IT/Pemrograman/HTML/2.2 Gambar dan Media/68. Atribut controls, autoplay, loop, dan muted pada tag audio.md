# Atribut controls autoplay loop dan muted pada Tag audio

## Analogi: Perpustakaan Digital

Bayangkan **pemutar kaset** di ruang audio perpustakaan. Beberapa fiturnya:

- **Controls** → Tombol play, pause, volume, maju/mundur
- **Autoplay** → Kaset langsung berputar saat dicolok
- **Loop** → Kaset diputar ulang terus-menerus
- **Muted** → Suara dimatikan, hanya visualnya yang jalan

Atribut-atribut ini mengontrol **perilaku pemutar audio** di HTML.

## Penjelasan Detail

### controls
Menampilkan **kontrol pemutar** (play/pause, volume, timeline, dll).
```html
<audio controls src="lagu.mp3"></audio>
```
**Sangat disarankan** — tanpa ini, pengguna tidak bisa mengontrol pemutaran.

### autoplay
Memulai pemutaran **otomatis** saat halaman dimuat.
```html
<audio autoplay src="musik.mp3"></audio>
```
**Catatan**: Browser modern sering **memblokir autoplay** untuk audio bersuara. Solusinya: tambahkan `muted`.
```html
<audio autoplay muted src="musik.mp3"></audio>
```

### loop
Mengulang pemutaran **terus-menerus**.
```html
<audio loop src="musik-latar.mp3"></audio>
```

### muted
Memulai audio dalam keadaan **senyap** (volume 0).
```html
<audio muted src="intro.mp3"></audio>
```
Pengguna bisa menyalakan suara nanti lewat kontrol.

### Kombinasi
```html
<audio controls autoplay loop muted src="bgm.mp3">
  <!-- Autoplay + muted = satu-satunya cara autoplay yang diizinkan browser -->
</audio>
```

### Tabel Kombinasi
| Kombinasi | Perilaku |
|-----------|----------|
| `controls` | Pemutar dengan kontrol, pengguna klik play |
| `autoplay` | Langsung putar (sering diblokir browser) |
| `autoplay muted` | Langsung putar tanpa suara (diizinkan) |
| `controls autoplay muted loop` | Pemutar penuh, putar otomatis senyap, looping |

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Audio Attributes</title>
  </head>
  <body>
    <h1>Demo Atribut Audio</h1>

    <h2>1. Controls Only (default)</h2>
    <audio controls src="sample.mp3"></audio>

    <h2>2. Autoplay + Muted (disukai browser)</h2>
    <audio autoplay muted src="bgm.mp3"></audio>

    <h2>3. Loop + Controls</h2>
    <audio controls loop src="ulangan.mp3"></audio>

    <h2>4. Semua Atribut</h2>
    <audio controls autoplay muted loop src="full.mp3">
      Browser tidak mendukung audio.
    </audio>
  </body>
</html>
```

## Poin Penting
- `controls` = tampilkan tombol kontrol (WAJIB untuk UX)
- `autoplay` = putar otomatis (sering diblokir — tambah `muted`)
- `loop` = ulangi terus
- `muted` = mulai tanpa suara
- Autoplay bersuara hanya bekerja jika pengguna sudah pernah interaksi dengan halaman
