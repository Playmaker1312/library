# Atribut controls autoplay loop muted poster dan preload pada Tag video

## Analogi: Perpustakaan Digital

Bayangkan **pemutar film canggih** di teater mini perpustakaan:

- **Controls** → Tombol play, pause, volume, fullscreen
- **Autoplay** → Film langsung diputar saat masuk ruangan
- **Loop** → Film diputar ulang terus
- **Muted** → Film tanpa suara (hanya visual)
- **Poster** → Poster film di depan pintu sebelum masuk
- **Preload** → Seberapa cepat film disiapkan sebelum ditonton

Atribut-atribut ini mengontrol **perilaku pemutar video** di HTML.

## Penjelasan Detail

### controls
Menampilkan kontrol video (play, pause, volume, fullscreen, timeline).
```html
<video controls src="film.mp4"></video>
```

### autoplay
Video langsung diputar saat halaman dimuat.
```html
<video autoplay src="film.mp4"></video>
```
**Catatan**: Di browser modern, autoplay video bersuara diblokir. Solusi:
```html
<video autoplay muted src="film.mp4"></video>
```

### loop
Mengulang video terus-menerus.
```html
<video loop src="film.mp4"></video>
```

### muted
Video dimulai dalam keadaan senyap.
```html
<video muted src="film.mp4"></video>
```

### poster
Menampilkan **gambar thumbnail** sebelum video diputar.
```html
<video controls poster="poster-film.jpg" src="film.mp4"></video>
```
Poster muncul saat video belum dimulai atau sedang dimuat.

### preload
Memberi tahu browser seberapa agresif memuat video.
| Nilai | Perilaku |
|-------|----------|
| `none` | Jangan muat video sampai diputar |
| `metadata` | Muat hanya metadata (durasi, dimensi) — **default** |
| `auto` | Muat seluruh video jika memungkinkan |
```html
<video controls preload="metadata" src="film.mp4"></video>
```

### Tabel Kombinasi Lengkap
```html
<video controls autoplay muted loop poster="poster.jpg" preload="auto">
  <source src="film.mp4" type="video/mp4">
</video>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Video Attributes</title>
  </head>
  <body>
    <h1>Demo Atribut Video</h1>

    <h2>1. Controls + Poster</h2>
    <video controls width="400" poster="https://via.placeholder.com/400x225/2c3e50/ffffff?text=Poster+Film">
      <source src="film.mp4" type="video/mp4">
    </video>

    <h2>2. Autoplay + Muted + Loop (video latar)</h2>
    <video autoplay muted loop width="400">
      <source src="background.mp4" type="video/mp4">
    </video>

    <h2>3. Preload="none" (hemat bandwidth)</h2>
    <video controls preload="none" width="400">
      <source src="film-besar.mp4" type="video/mp4">
    </video>

    <h2>4. Semua atribut</h2>
    <video controls autoplay muted loop poster="poster.jpg" preload="metadata" width="400">
      <source src="film-lengkap.mp4" type="video/mp4">
    </video>
  </body>
</html>
```

## Poin Penting
- `controls` = tampilkan tombol kontrol (penting untuk UX)
- `autoplay muted` = satu-satunya autoplay yang diizinkan browser
- `poster` = thumbnail sebelum video diputar
- `preload` = atur strategi pemuatan video
- `loop` = putar ulang terus
- `muted` = tanpa suara saat mulai
