# Format Gambar yang Umum Digunakan seperti JPEG PNG GIF WebP dan SVG

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan punya **berbagai jenis buku**: ada buku bersampul keras (tahan lama, besar), buku saku (ringkas), buku digital (fleksibel). Masing-masing punya **kelebihan dan kekurangan**.

Gambar juga punya berbagai **format file** — masing-masing cocok untuk situasi berbeda. Memilih format yang tepat seperti memilih jenis buku yang tepat untuk kebutuhan.

## Penjelasan Detail

### Perbandingan Format

| Format | Kelebihan | Kekurangan | Cocok Untuk |
|--------|-----------|------------|-------------|
| **JPEG/JPG** | Ukuran kecil, warna kaya (16.7 juta) | Tidak support transparansi, lossy | **Foto**, gambar kompleks |
| **PNG** | Lossless, transparansi, tajam | Ukuran besar | **Logo, ikon, screenshot**, grafis |
| **GIF** | Animasi, transparansi 1-bit | Hanya 256 warna, ukuran besar | **Animasi sederhana**, meme |
| **WebP** | Kualitas tinggi, ukuran kecil (26% lebih kecil dari PNG) | Dukungan browser tidak 100% | **Modern web**, foto + grafis |
| **SVG** | Vektor, skalabel tak terbatas, ukuran kecil | Tidak untuk foto kompleks | **Ikon, ilustrasi, logo, diagram** |

### Penjelasan Detail per Format

**JPEG** — Format paling populer untuk foto. Mengompres dengan membuang detail yang tidak terlihat mata manusia. Ukuran kecil, kualitas masih bagus.

**PNG** — Format lossless (tidak ada data hilang). Support **transparansi** (latar belakang transparan). Ukuran besar, tapi tajam sempurna.

**GIF** — Format lawas yang hanya support 256 warna. Keunggulannya: **animasi**. Untuk animasi modern, lebih baik pakai video MP4 atau WebP animasi.

**WebP** — Format modern buatan Google. Ukuran file 25-35% lebih kecil dari JPEG dengan kualitas yang sama. Support transparansi dan animasi.

**SVG** — Bukan gambar bitmap (pixel), tapi **vektor** (matematika). Bisa diperbesar tak terbatas tanpa pecah. Ukuran file sangat kecil untuk ikon sederhana.

### Cara Pilih Format
```text
Apakah ini foto atau gambar kompleks?
  ├── Ya → Apakah butuh transparansi?
  │       ├── Ya → PNG atau WebP
  │       └── Tidak → JPEG atau WebP
  └── Tidak → Apakah ini ikon/ilustrasi sederhana?
          ├── Ya → SVG
          └── Tidak → PNG
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Image Formats</title>
  </head>
  <body>
    <h1>Perbandingan Format Gambar</h1>

    <h2>JPEG — Foto</h2>
    <img src="foto-perpus.jpg" alt="Foto perpustakaan" width="300">

    <h2>PNG — Logo (dengan transparansi)</h2>
    <img src="logo-perpus.png" alt="Logo Perpustakaan" width="200">

    <h2>GIF — Animasi</h2>
    <img src="animasi-buku.gif" alt="Buku berputar" width="100">

    <h2>SVG — Ikon Vektor</h2>
    <img src="ikon-buku.svg" alt="Ikon buku" width="80">

    <h2>WebP — Modern</h2>
    <img src="banner.webp" alt="Banner perpustakaan" width="400">

    <!-- Fallback untuk WebP dengan picture -->
    <picture>
      <source srcset="banner.webp" type="image/webp">
      <source srcset="banner.jpg" type="image/jpeg">
      <img src="banner.jpg" alt="Banner">
    </picture>
  </body>
</html>
```

## Poin Penting
- **JPEG** → foto (ukuran kecil, tanpa transparansi)
- **PNG** → logo/grafis (tajam, transparansi)
- **GIF** → animasi sederhana (256 warna)
- **WebP** → modern (kecil, kualitas tinggi)
- **SVG** → vektor (skalabel, ikon)
- Pilih format sesuai **kebutuhan** — bukan semua pakai JPEG
