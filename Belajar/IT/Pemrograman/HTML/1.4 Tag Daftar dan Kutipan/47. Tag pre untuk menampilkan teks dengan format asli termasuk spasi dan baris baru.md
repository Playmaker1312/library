# Tag pre untuk Menampilkan Teks dengan Format Asli Termasuk Spasi dan Baris Baru

## Analogi: Perpustakaan Digital

Bayangkan **papan pengumuman** di perpustakaan yang berisi puisi atau potongan kode program. Di papan ini, setiap spasi, tab, dan baris baru harus tampil **persis seperti aslinya** — tidak boleh diubah oleh browser.

```
If you can keep your head when all about you
    Are losing theirs and blaming it on you,
If you can trust yourself when all men doubt you,
    But make allowance for their doubting too...
```

`<pre>` (preformatted) mempertahankan **format asli** teks — semua spasi, tab, dan baris baru tetap dipertahankan. Browser biasanya menampilkan `<pre>` dengan font **monospace** (seperti mesin ketik).

## Penjelasan Detail

`<pre>` digunakan untuk menampilkan teks dengan format yang sudah ditentukan (preformatted). HTML biasanya mengabaikan spasi berlebih dan baris baru — tapi `<pre>` membuat semua format asli tetap terjaga.

### Karakteristik `<pre>`
- **Font monospace** — semua huruf lebar sama
- **Spasi dan baris baru dipertahankan** — tidak ada collapsing
- **Tab juga dipertahankan**
- Bisa berisi kode HTML (tapi tag di dalamnya tetap diproses, kecuali di-escape)

### Kapan Pakai `<pre>`?
- **Kode program** — butuh indentasi asli
- **Puisi** — baris dan spasi penting
- **Output terminal** — format kolom
- **ASCII art** — gambar dari karakter
- **Teks dengan format tabular** — tapi lebih baik pakai tabel

### Perbedaan `<pre>` vs `<code>`
- `<code>` = untuk potongan kode (inline, font monospace)
- `<pre>` = untuk format asli (blok, font monospace, spasi dipertahankan)
- Sering dipakai bersama: `<pre><code>...</code></pre>`

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Preformatted Text</title>
  </head>
  <body>
    <h1>Contoh Teks Preformat</h1>

    <h2>Puisi</h2>
    <pre>
      Aku ingin mencintaimu dengan sederhana
      dengan kata yang tak sempat diucapkan
      kayu kepada api yang menjadikannya abu

      Aku ingin mencintaimu dengan sederhana
      dengan isyarat yang tak sempat disampaikan
      awan kepada hujan yang menjadikannya tiada
    </pre>

    <h2>Kode Program</h2>
    <pre><code>
function sapa(nama) {
  if (nama) {
    return "Halo, " + nama + "!";
  }
  return "Halo, dunia!";
}
    </code></pre>

    <h2>ASCII Art</h2>
    <pre>
      /\_/\
     ( o.o )
      > ^ &lt;
    </pre>
  </body>
</html>
```

## Poin Penting
- `<pre>` = teks **format asli** (spasi dan baris baru dipertahankan)
- Font **monospace** secara default
- Untuk puisi, kode, ASCII art, output terminal
- Sering dipasangkan dengan `<code>` untuk kode program
- Tag HTML di dalam `<pre>` tetap diproses (kecuali di-escape)
