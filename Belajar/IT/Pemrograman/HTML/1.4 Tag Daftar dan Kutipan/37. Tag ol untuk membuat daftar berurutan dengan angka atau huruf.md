# Tag ol untuk Membuat Daftar Berurutan dengan Angka atau Huruf

## Analogi: Perpustakaan Digital

Bayangkan **panduan langkah demi langkah** untuk meminjam buku di perpustakaan:

```
Cara Meminjam Buku:
1. Buka website perpustakaan
2. Cari buku yang diinginkan
3. Klik tombol "Pinjam"
4. Konfirmasi peminjaman
5. Baca buku secara online
```

Setiap langkah punya **nomor urut** — 1, 2, 3. Urutannya **penting**. Kamu harus mengikuti dari awal sampai akhir.

`<ol>` (ordered list) adalah **daftar bernomor** — daftar yang urutannya **bermakna**. Setiap item ditandai dengan `<li>`.

## Penjelasan Detail

`<ol>` digunakan untuk membuat daftar dengan **urutan yang bermakna** (nomor, huruf, atau angka romawi).

### Atribut `<ol>`
| Atribut | Fungsi | Contoh |
|---------|--------|--------|
| `type="1"` | Angka (default) | 1, 2, 3 |
| `type="A"` | Huruf besar | A, B, C |
| `type="a"` | Huruf kecil | a, b, c |
| `type="I"` | Romawi besar | I, II, III |
| `type="i"` | Romawi kecil | i, ii, iii |
| `start="5"` | Mulai dari angka tertentu | 5, 6, 7 |
| `reversed` | Urutan terbalik | 3, 2, 1 |

### Kapan Pakai `<ol>`?
- **Instruksi langkah demi langkah** — "Cara meminjam buku"
- **Peringkat** — "Top 10 buku terpopuler"
- **Daftar prioritas** — "Hal yang harus dilakukan hari ini"
- **Resep** — langkah memasak

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Ordered List</title>
  </head>
  <body>
    <h1>Cara Meminjam Buku</h1>

    <ol>
      <li>Kunjungi website Perpustakaan Digital</li>
      <li>Login dengan akun Anda</li>
      <li>Cari buku melalui kolom pencarian</li>
      <li>Klik "Pinjam" pada buku yang dipilih</li>
      <li>Tunggu konfirmasi email</li>
      <li>Baca buku secara online atau unduh PDF</li>
    </ol>

    <h2>Top 3 Buku Terpopuler</h2>
    <ol type="1">
      <li>Laskar Pelangi - Andrea Hirata</li>
      <li>Bumi Manusia - Pramoedya A.</li>
      <li>Pulang - Tere Liye</li>
    </ol>

    <h2>Syarat Keanggotaan (prioritas)</h2>
    <ol type="A">
      <li>Warga negara Indonesia</li>
      <li>Usia minimal 15 tahun</li>
      <li>Memiliki alamat email</li>
    </ol>
  </body>
</html>
```

## Poin Penting
- `<ol>` = daftar **berurutan** (bernomor)
- Setiap item pakai `<li>`
- Urutan **bermakna** — tidak boleh diacak
- Atribut: `type`, `start`, `reversed`
- Untuk instruksi, peringkat, prioritas
