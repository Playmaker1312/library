# Tag ul untuk Membuat Daftar Tidak Berurutan dengan Bullet Points

## Analogi: Perpustakaan Digital

Bayangkan **daftar belanja buku** yang ditulis di papan pengumuman perpustakaan:

```
📚 Buku yang harus dibeli:
  • Novel terbaru Andrea Hirata
  • Ensiklopedia sains
  • Kamus bahasa Inggris
  • Buku resep masakan
```

Setiap item punya **bullet point** (lingkaran kecil) di depannya. Urutannya tidak penting — tidak ada nomor 1, 2, 3. Kamu bisa membaca dari mana saja.

`<ul>` (unordered list) adalah **daftar berbullet** — daftar yang urutannya **tidak penting**. Setiap item ditandai dengan `<li>`.

## Penjelasan Detail

`<ul>` digunakan untuk membuat daftar dengan **bullet points**. Urutan item tidak bermakna.

### Struktur
```html
<ul>
  <li>Item pertama</li>
  <li>Item kedua</li>
  <li>Item ketiga</li>
</ul>
```

### Jenis Bullet (CSS)
```html
<ul style="list-style-type: disc;">   <!-- ● bullet default -->
<ul style="list-style-type: circle;"> <!-- ○ lingkaran -->
<ul style="list-style-type: square;"> <!-- ■ persegi -->
<ul style="list-style-type: none;">   <!-- tanpa bullet -->
```

### Kapan Pakai `<ul>`?
- Daftar fitur produk
- Daftar kategori buku
- Menu navigasi
- Daftar apa pun yang urutannya tidak penting

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Unordered List</title>
  </head>
  <body>
    <h1>Kategori Buku</h1>

    <ul>
      <li>Fiksi
        <ul>
          <li>Novel Indonesia</li>
          <li>Novel Terjemahan</li>
          <li>Cerpen</li>
        </ul>
      </li>
      <li>Non Fiksi
        <ul>
          <li>Sejarah</li>
          <li>Sains</li>
          <li>Biografi</li>
        </ul>
      </li>
      <li>Pendidikan
        <ul>
          <li>Buku Pelajaran</li>
          <li>Kamus</li>
          <li>Ensiklopedia</li>
        </ul>
      </li>
    </ul>
  </body>
</html>
```

## Poin Penting
- `<ul>` = daftar **tidak berurutan** (bullet points)
- Setiap item pakai `<li>` (list item)
- Urutan item **tidak bermakna**
- Bisa bersarang (nested list) di dalam `<li>`
- Jenis bullet bisa diubah dengan CSS
