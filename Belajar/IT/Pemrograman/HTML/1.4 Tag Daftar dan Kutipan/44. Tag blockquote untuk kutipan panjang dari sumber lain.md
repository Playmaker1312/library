# Tag blockquote untuk Kutipan Panjang dari Sumber Lain

## Analogi: Perpustakaan Digital

Bayangkan **halaman khusus** di perpustakaan yang memajang kutipan panjang dari buku-buku terkenal. Kutipan ini ditulis di papan besar, dengan indentasi dan gaya berbeda dari teks biasa, agar jelas bahwa ini adalah **kata-kata orang lain**, bukan tulisan perpustakaan.

`<blockquote>` adalah **papan kutipan panjang**. Digunakan untuk mengutip teks panjang dari sumber lain. Browser biasanya menampilkannya dengan **indentasi** (menjorok dari kiri dan kanan).

## Penjelasan Detail

`<blockquote>` digunakan untuk kutipan **blok** (panjang) yang berasal dari sumber eksternal.

### Atribut `cite`
```html
<blockquote cite="https://example.com/sumber-kutipan">
  <p>Isi kutipan panjang di sini...</p>
</blockquote>
```
Atribut `cite` menunjukkan URL sumber kutipan (tidak terlihat di browser, tapi berguna untuk screen reader dan validasi).

### Aturan
- `<blockquote>` bisa berisi paragraf, heading, daftar
- Biasanya untuk kutipan **3+ baris**
- Untuk kutipan pendek dalam kalimat, pakai `<q>`

### Styling Default
- Indentasi kiri dan kanan
- Sering ditambahi CSS: `border-left`, `italic`, `background`

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Blockquote</title>
    <style>
      blockquote {
        border-left: 4px solid #2c3e50;
        padding: 15px 20px;
        background: #f9f9f9;
        margin: 20px 0;
        font-style: italic;
      }
      blockquote footer {
        text-align: right;
        font-style: normal;
        font-size: 14px;
        margin-top: 10px;
      }
    </style>
  </head>
  <body>
    <h1>Kutipan Inspiratif tentang Membaca</h1>

    <p>Berikut adalah kutipan terkenal yang dipajang di sudut baca perpustakaan kami:</p>

    <blockquote cite="https://example.com/sumber">
      <p>Membaca adalah jendela dunia. Semakin banyak kita membaca, semakin luas wawasan kita. Buku adalah teman setia yang tidak pernah mengkhianati. Di dalam buku, kita bisa bepergian ke mana saja tanpa harus meninggalkan rumah.</p>
      <footer>— Andrea Hirata, <cite>Laskar Pelangi</cite></footer>
    </blockquote>

    <p>Itulah sebabnya perpustakaan digital kami berkomitmen untuk menyediakan akses buku seluas-luasnya.</p>

    <h2>Kutipan Tanpa CSS (Default Browser)</h2>
    <blockquote>
      <p>Ini adalah kutipan panjang dengan tampilan default browser. Perhatikan indentasinya dari tepi kiri dan kanan.</p>
    </blockquote>
  </body>
</html>
```

## Poin Penting
- `<blockquote>` = kutipan **panjang/ blok**
- Browser default: **indentasi** kiri-kanan
- Atribut `cite` untuk URL sumber
- Untuk kutipan pendek (inline), pakai `<q>`
- Bisa diubah gayanya dengan CSS
