# Daftar Bersarang atau Nested List di Dalam Daftar Lainnya

## Analogi: Perpustakaan Digital

Bayangkan **rak buku** dalam perpustakaan yang memiliki **sub-rak** di dalamnya:

```
▶ Rak Fiksi
  ▶ Novel Indonesia
    ▶ Penulis 2000-an
    ▶ Penulis 2010-an
  ▶ Novel Asing
▶ Rak Non Fiksi
  ▶ Sejarah
  ▶ Sains
```

Ini adalah daftar di dalam daftar — **nested list** (daftar bersarang). Satu `<li>` bisa berisi `<ul>` atau `<ol>` lagi di dalamnya.

## Penjelasan Detail

Nested list adalah daftar yang diletakkan **di dalam** item daftar lain.

### Aturan
- `<ul>` atau `<ol>` baru diletakkan **di dalam** `<li>` (bukan di antara `<li>`)
- Setiap level nested akan memiliki indentasi lebih dalam
- Browser secara otomatis memberi bullet/nomor yang berbeda

### Format Penulisan
```html
<ul>
  <li>Item utama 1
    <ul>             <!-- Nested list -->
      <li>Sub-item 1</li>
      <li>Sub-item 2</li>
    </ul>
  </li>
  <li>Item utama 2</li>
</ul>
```

### Level Nested
```
Level 1: ●
Level 2: ○
Level 3: ■
Level 4: ● (kembali ke awal)
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Nested List</title>
  </head>
  <body>
    <h1>Katalog Perpustakaan</h1>

    <ul>
      <li>Fiksi
        <ul>
          <li>Novel
            <ul>
              <li>Novel Indonesia</li>
              <li>Novel Terjemahan</li>
            </ul>
          </li>
          <li>Cerpen</li>
          <li>Komik</li>
        </ul>
      </li>
      <li>Non Fiksi
        <ul>
          <li>Sejarah</li>
          <li>Sains</li>
          <li>Biografi</li>
        </ul>
      </li>
      <li>Pendidikan
        <ul>
          <li>Buku Pelajaran SD</li>
          <li>Buku Pelajaran SMP</li>
          <li>Buku Pelajaran SMA</li>
        </ul>
      </li>
    </ul>
  </body>
</html>
```

## Poin Penting
- Nested list = **daftar di dalam daftar**
- `<ul>`/`<ol>` baru di dalam `<li>`
- Membantu membuat **hierarki** dan kategorisasi
- Browser otomatis membedakan bullet/nomor tiap level
- Bisa bersarang sampai beberapa level
