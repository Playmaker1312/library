# Atribut type pada ol untuk Mengubah Format Penomoran

## Analogi: Perpustakaan Digital

Bayangkan cara perpustakaan menomori daftar koleksinya:
- **Daftar buku baru**: pakai angka (1, 2, 3)
- **Daftar bab**: pakai Romawi (I, II, III)
- **Daftar sub-bab**: pakai huruf (a, b, c)
- **Daftar lampiran**: pakai huruf besar (A, B, C)

Atribut `type` pada `<ol>` mengubah **format penomoran** sesuka hati.

## Penjelasan Detail

Atribut `type` pada `<ol>` menentukan jenis penomoran yang digunakan.

### Jenis `type`

| Nilai | Format | Contoh |
|-------|--------|--------|
| `type="1"` | Angka (default) | 1, 2, 3, ..., 10 |
| `type="A"` | Huruf kapital | A, B, C, ..., Z |
| `type="a"` | Huruf kecil | a, b, c, ..., z |
| `type="I"` | Romawi kapital | I, II, III, ..., X |
| `type="i"` | Romawi kecil | i, ii, iii, ..., x |

### Atribut Tambahan
- **`start`** — mulai dari angka/huruf tertentu
  ```html
  <ol type="1" start="5">  <!-- 5, 6, 7, ... -->
  <ol type="A" start="3">  <!-- C, D, E, ... -->
  ```
- **`reversed`** — urutan terbalik
  ```html
  <ol reversed>  <!-- 3, 2, 1 -->
  ```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>OL Type</title>
  </head>
  <body>
    <h1>Penomoran Berbagai Format</h1>

    <h2>Angka (default)</h2>
    <ol type="1">
      <li>Pertama</li>
      <li>Kedua</li>
      <li>Ketiga</li>
    </ol>

    <h2>Huruf Besar</h2>
    <ol type="A">
      <li>Bagian Pendahuluan</li>
      <li>Bagian Isi</li>
      <li>Bagian Penutup</li>
    </ol>

    <h2>Romawi</h2>
    <ol type="I">
      <li>Bab 1</li>
      <li>Bab 2</li>
      <li>Bab 3</li>
    </ol>

    <h2>Mulai dari angka 5</h2>
    <ol type="1" start="5">
      <li>Item 5</li>
      <li>Item 6</li>
      <li>Item 7</li>
    </ol>

    <h2>Urutan terbalik (Top 3)</h2>
    <ol reversed>
      <li>Juara 3</li>
      <li>Juara 2</li>
      <li>Juara 1</li>
    </ol>
  </body>
</html>
```

## Poin Penting
- Atribut `type` mengubah **format nomor**: angka, huruf, romawi
- `start` untuk memulai dari angka tertentu
- `reversed` untuk urutan terbalik
- Penomoran otomatis menyesuaikan dengan atribut
