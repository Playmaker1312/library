# Tag q untuk Kutipan Singkat Inline dalam Kalimat

## Analogi: Perpustakaan Digital

Bayangkan seorang pustakawan berkata: "Seperti kata Andrea Hirata, **'Membaca adalah jendela dunia'**, kita harus rajin membaca."

Kutipan pendek ini menyatu dalam kalimat — bukan blok terpisah. Tanda kutip di sekitarnya menunjukkan bahwa ini adalah kata orang lain.

`<q>` (quote) adalah **kutipan pendek inline**. Browser otomatis menambahkan **tanda kutip** (`"..."`) di sekeliling teks.

## Penjelasan Detail

`<q>` digunakan untuk kutipan **pendek** yang menyatu dalam kalimat.

### Perbedaan `<q>` vs `<blockquote>`
| `<q>` | `<blockquote>` |
|-------|----------------|
| Kutipan **pendek** (inline) | Kutipan **panjang** (blok) |
| Menyatu dalam paragraf | Berdiri sendiri |
| Browser tambah **tanda kutip** | Browser tambah **indentasi** |
| Untuk 1-2 kalimat pendek | Untuk 3+ kalimat |

### Atribut `cite`
```html
<q cite="https://sumber.com">Kutipan di sini</q>
```

### Bahasa dan Tanda Kutip
Browser secara otomatis menyesuaikan tanda kutip berdasarkan bahasa:
- Bahasa Indonesia/Inggris: `"..."`
- Bahasa Prancis: `«...»`
- Bahasa Jepang: `「...」`
Ini tergantung atribut `lang` pada `<html>` atau elemen.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
  <head>
    <title>Inline Quote</title>
  </head>
  <body>
    <h1>Review Buku</h1>

    <p>Dalam bukunya, Andrea Hirata mengatakan <q cite="https://example.com/laskar-pelangi">Membaca adalah jendela dunia</q>. Kata-kata ini sangat menginspirasi saya.</p>

    <p>Seperti kata pepatah, <q>tak kenal maka tak sayang</q>. Makanya, kenali dulu buku-buku di perpustakaan ini.</p>

    <p>Dia bertanya, <q>Apa kamu sudah membaca Laskar Pelangi?</q> Aku menjawab, <q>Sudah, tiga kali!</q></p>
  </body>
</html>
```

## Poin Penting
- `<q>` = kutipan **pendek inline**
- Browser otomatis tambah **tanda kutip**
- Untuk kutipan dalam kalimat (bukan blok terpisah)
- Atribut `cite` untuk URL sumber
- Untuk kutipan panjang, pakai `<blockquote>`
