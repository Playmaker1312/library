# Tag dd sebagai Deskripsi atau Penjelasan dari Istilah

## Analogi: Perpustakaan Digital

Bayangkan **kartu katalog** yang berisi penjelasan lengkap tentang sebuah buku. Setelah kamu melihat **istilah** (judul buku/kategori), kamu membaca **deskripsi** — penjelasan detail tentang istilah tersebut.

`<dd>` (description definition) adalah **deskripsi/penjelasan** dari istilah (`<dt>`) dalam daftar definisi. Ini adalah "isi" dari entri definisi.

## Penjelasan Detail

`<dd>` digunakan untuk memberikan **definisi atau deskripsi** dari istilah (`<dt>`) sebelumnya. `<dd>` harus berada di dalam `<dl>`.

### Karakteristik
- Browser biasanya menampilkan `<dd>` dengan **indentasi** (mengeser ke kanan)
- Bisa berisi teks, gambar, daftar, atau elemen HTML lainnya
- Satu `<dt>` bisa punya beberapa `<dd>`

### Indentasi Default
```html
<dl>
  <dt>HTML</dt>
  <dd>    ← Ini akan menjorok ke kanan
    Bahasa markup untuk web.
  </dd>
</dl>
```

### `<dd>` Bisa Berisi Daftar
```html
<dl>
  <dt>Bahasa Pemrograman Web</dt>
  <dd>
    <ul>
      <li>HTML - Struktur</li>
      <li>CSS - Tampilan</li>
      <li>JavaScript - Interaksi</li>
    </ul>
  </dd>
</dl>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>DD Description</title>
  </head>
  <body>
    <h1>Kategori Buku</h1>

    <dl>
      <dt>Fiksi</dt>
      <dd>Buku yang berisi cerita rekaan/imajinasi, seperti novel dan cerpen.</dd>

      <dt>Non Fiksi</dt>
      <dd>Buku berdasarkan fakta dan kenyataan, seperti buku sejarah dan biografi.</dd>

      <dt>Ensiklopedia</dt>
      <dd>Buku referensi yang berisi informasi lengkap tentang berbagai topik.</dd>
      <dd>Biasanya terdiri dari beberapa jilid atau volume.</dd>
      <dd>
        Contoh:
        <ul>
          <li>Ensiklopedia Indonesia</li>
          <li>Britannica</li>
        </ul>
      </dd>
    </dl>
  </body>
</html>
```

## Poin Penting
- `<dd>` = **deskripsi/definisi** dari istilah
- Letaknya setelah `<dt>` di dalam `<dl>`
- Browser otomatis memberi **indentasi**
- Bisa berisi teks, daftar, gambar, atau elemen lain
- Satu `<dt>` bisa punya banyak `<dd>`
