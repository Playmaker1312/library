# Tag kbd untuk Menampilkan Input Keyboard oleh Pengguna

## Analogi: Perpustakaan Digital

Bayangkan **panduan pengguna** di perpustakaan yang memberitahu: "Tekan **Ctrl + P** untuk mencetak halaman." Tombol keyboard ditampilkan dengan gaya khusus agar mudah dikenali.

`<kbd>` (keyboard) adalah tag untuk menampilkan **input dari keyboard** atau perintah suara. Browser biasanya menampilkan `<kbd>` dengan font **monospace** dan gaya tombol (tergantung browser).

## Penjelasan Detail

`<kbd>` digunakan untuk menandai teks yang merepresentasikan **input pengguna** — biasanya tombol keyboard.

### Kapan Pakai `<kbd>`?
- **Pintasan keyboard**: `<kbd>Ctrl</kbd> + <kbd>C</kbd>`
- **Perintah keyboard**: Tekan `<kbd>Enter</kbd>`
- **Input suara**: Ucapkan `<kbd>Halo</kbd>` (jarang)
- **Kombinasi tombol**: `<kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Del</kbd>`

### Styling dengan CSS
```css
kbd {
  background: #eee;
  border: 1px solid #ccc;
  padding: 2px 6px;
  border-radius: 4px;
  font-family: monospace;
}
```

### Bersarang `<kbd>` untuk Menu Bertingkat
```html
<!-- Menampilkan menu item -->
<p>Pilih <kbd><kbd>File</kbd> → <kbd>Save As</kbd></kbd></p>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Keyboard Input</title>
    <style>
      kbd {
        background-color: #f0f0f0;
        border: 1px solid #ccc;
        border-radius: 4px;
        padding: 2px 6px;
        font-family: monospace;
        font-size: 0.9em;
        box-shadow: 0 1px 0 #bbb;
      }
    </style>
  </head>
  <body>
    <h1>Pintasan Keyboard Perpustakaan Digital</h1>

    <p>Tekan <kbd>Ctrl</kbd> + <kbd>F</kbd> untuk mencari buku.</p>

    <p>Tekan <kbd>Ctrl</kbd> + <kbd>P</kbd> untuk mencetak halaman.</p>

    <p>Tekan <kbd>F11</kbd> untuk layar penuh.</p>

    <p>Untuk membuka file: tekan <kbd>Ctrl</kbd> + <kbd>O</kbd></p>

    <p>Pilih menu <kbd><kbd>File</kbd> → <kbd>Print</kbd></kbd> untuk mencetak.</p>
  </body>
</html>
```

## Poin Penting
- `<kbd>` = **input keyboard** dari pengguna
- Font **monospace** secara default
- Untuk pintasan, perintah keyboard, tombol
- Bisa di-styling dengan CSS jadi mirip tombol
- Bisa bersarang untuk menu bertingkat
