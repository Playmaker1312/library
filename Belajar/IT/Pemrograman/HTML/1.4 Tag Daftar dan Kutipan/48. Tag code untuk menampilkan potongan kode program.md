# Tag code untuk Menampilkan Potongan Kode Program

## Analogi: Perpustakaan Digital

Bayangkan **buku pemrograman** di perpustakaan. Di dalamnya ada potongan kode yang harus dibedakan dari teks biasa — tampil dengan font khusus agar pembaca langsung tahu: "Ini kode, bukan penjelasan."

`<code>` adalah tag untuk **potongan kode program**. Browser menampilkannya dengan font **monospace** (lebar tetap) — seperti font yang dipakai di editor kode.

## Penjelasan Detail

`<code>` digunakan untuk menandai teks sebagai **kode program** atau **nama teknis**.

### Karakteristik
- **Font monospace** — semua karakter lebar sama
- **Inline element** — menyatu dalam kalimat
- Biasanya dipasangkan dengan `<pre>` untuk blok kode multi-baris

### `<code>` vs `<pre>`
| `<code>` | `<pre>` |
|----------|---------|
| Inline | Block-level |
| Font monospace | Font monospace + spasi dipertahankan |
| Untuk potongan kode pendek | Untuk blok kode panjang |

### Kombinasi: `<pre><code>`
Untuk blok kode multi-baris dengan indentasi:
```html
<pre><code>
function halo() {
  console.log("Halo!");
}
</code></pre>
```

### Escape Karakter Khusus
Jika kode berisi `<` atau `>`, harus di-escape:
- `<` → `&lt;`
- `>` → `&gt;`
- `&` → `&amp;`

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Code Tag</title>
  </head>
  <body>
    <h1>Belajar HTML</h1>

    <p>Tag <code>&lt;p&gt;</code> digunakan untuk membuat paragraf.</p>

    <p>Fungsi <code>console.log()</code> digunakan untuk mencetak teks ke konsol.</p>

    <p>Variable <code>nama</code> menyimpan data string.</p>

    <h2>Contoh Blok Kode</h2>
    <pre><code>&lt;!DOCTYPE html&gt;
&lt;html&gt;
&lt;head&gt;
  &lt;title&gt;Halaman&lt;/title&gt;
&lt;/head&gt;
&lt;body&gt;
  &lt;h1&gt;Halo Dunia&lt;/h1&gt;
&lt;/body&gt;
&lt;/html&gt;</code></pre>
  </body>
</html>
```

## Poin Penting
- `<code>` = **potongan kode** (inline)
- Font **monospace**
- Untuk nama tag, fungsi, variable
- Untuk blok kode, kombinasikan dengan `<pre>`
- Escape karakter `<`, `>`, `&` dengan entity HTML
