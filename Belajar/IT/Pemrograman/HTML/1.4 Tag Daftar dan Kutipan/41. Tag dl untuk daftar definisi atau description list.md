# Tag dl untuk Daftar Definisi atau Description List

## Analogi: Perpustakaan Digital

Bayangkan **glosarium** atau **kamus istilah** di sudut perpustakaan. Glosarium ini berisi daftar istilah beserta definisinya:

```
HTML      : Bahasa markup untuk membuat halaman web
CSS       : Bahasa untuk mengatur tampilan halaman web
JavaScript: Bahasa pemrograman untuk interaksi web
```

Setiap entri punya **istilah** (term) dan **definisi** (description). Tidak ada bullet atau nomor — hanya pasangan istilah-definisi.

`<dl>` (description list) adalah **daftar definisi** — daftar yang berisi pasangan **istilah** (`<dt>`) dan **deskripsi** (`<dd>`).

## Penjelasan Detail

`<dl>` digunakan untuk daftar yang berisi pasangan **nama-nilai** atau **istilah-definisi**.

### Struktur
```html
<dl>
  <dt>Istilah 1</dt>
  <dd>Definisi dari istilah 1</dd>

  <dt>Istilah 2</dt>
  <dd>Definisi dari istilah 2</dd>
</dl>
```

### Komponen
| Tag | Kepanjangan | Fungsi |
|-----|-------------|--------|
| `<dl>` | Description List | Wadah daftar definisi |
| `<dt>` | Description Term | Istilah yang akan didefinisikan |
| `<dd>` | Description Definition | Penjelasan/definisi istilah |

### Aturan
- Satu `<dt>` bisa punya banyak `<dd>`
- Satu `<dd>` bisa dipasangkan dengan satu `<dt>`
- Bisa juga beberapa `<dt>` untuk satu `<dd>` (sinonim)

### Kapan Pakai `<dl>`?
- Glosarium/kamus
- Metadata (pasangan key-value)
- Daftar istilah teknis
- FAQ (pertanyaan = `<dt>`, jawaban = `<dd>`)

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Description List</title>
  </head>
  <body>
    <h1>Glosarium Perpustakaan Digital</h1>

    <dl>
      <dt>HTML</dt>
      <dd>HyperText Markup Language - Bahasa markup untuk membuat struktur halaman web.</dd>

      <dt>CSS</dt>
      <dd>Cascading Style Sheets - Bahasa untuk mengatur tampilan dan layout halaman web.</dd>

      <dt>JavaScript</dt>
      <dd>Bahasa pemrograman yang membuat halaman web menjadi interaktif.</dd>

      <dt>ISBN</dt>
      <dd>International Standard Book Number - Nomor identitas unik untuk buku.</dd>
      <dd>Format: 978-xxx-xxx-xxx-x</dd>
    </dl>

    <h2>Informasi Buku</h2>
    <dl>
      <dt>Judul</dt>
      <dd>Laskar Pelangi</dd>
      <dt>Penulis</dt>
      <dd>Andrea Hirata</dd>
      <dt>Tahun Terbit</dt>
      <dd>2005</dd>
    </dl>
  </body>
</html>
```

## Poin Penting
- `<dl>` = daftar definisi (description list)
- `<dt>` = istilah (term)
- `<dd>` = definisi/deskripsi
- Tidak ada bullet atau nomor
- Cocok untuk glosarium, metadata, FAQ
