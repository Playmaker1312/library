# Tag samp untuk Menampilkan Contoh Output dari Program

## Analogi: Perpustakaan Digital

Bayangkan **buku panduan komputer** di perpustakaan. Di dalamnya ada contoh layar komputer yang menampilkan pesan:

```
C:\> dir
Volume in drive C has no label
Directory of C:\Users
```

Teks ini menunjukkan **output dari program** atau sistem — bukan perintah yang dimasukkan pengguna, tapi hasil yang keluar.

`<samp>` (sample) adalah tag untuk menampilkan **contoh output** dari program komputer. Browser biasanya menampilkannya dengan font **monospace**.

## Penjelasan Detail

`<samp>` digunakan untuk menandai teks yang merupakan **output sampel** dari program, sistem, atau perintah.

### Kapan Pakai `<samp>`?
- **Pesan error**: `<samp>File not found</samp>`
- **Output program**: `<samp>Halo, dunia!</samp>`
- **Hasil perintah terminal**: output dari `dir`, `ls`, dll.
- **Pesan dari sistem**: `<samp>Loading...</samp>`

### Kombinasi dengan `<kbd>` dan `<samp>`
Sering dipakai bersama:
```html
<p>Ketik <kbd>ipconfig</kbd> di terminal.</p>
<p>Output: <samp>IPv4 Address: 192.168.1.1</samp></p>
```

### `<samp>` vs `<code>` vs `<kbd>`
| Tag | Arti | Contoh |
|-----|------|--------|
| `<code>` | Kode program | `function test()` |
| `<kbd>` | Input keyboard | `Ctrl + C` |
| `<samp>` | Output program | `Error 404` |

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Sample Output</title>
  </head>
  <body>
    <h1>Panduan Terminal Perpustakaan</h1>

    <p>Ketik <kbd>dir</kbd> untuk melihat daftar file.</p>

    <p>Contoh output:</p>
    <pre><samp>Volume in drive C has no label
Directory of C:\Users\Buku

2024-01-15  10:30    &lt;DIR&gt;    Fiksi
2024-01-15  10:30    &lt;DIR&gt;    Non-Fiksi
2024-01-15  10:31         1.234 daftar-buku.txt
               3 File(s)      1.234 bytes</samp></pre>

    <p>Pesan sukses: <samp>Buku berhasil dipinjam!</samp></p>

    <p>Pesan error: <samp style="color: red;">Maaf, buku sedang dipinjam orang lain.</samp></p>
  </body>
</html>
```

## Poin Penting
- `<samp>` = **contoh output** dari program
- Font **monospace** secara default
- Untuk pesan error, output terminal, hasil program
- Beda dengan `<code>` (kode program) dan `<kbd>` (input keyboard)
- Sering dipasangkan dengan `<pre>` untuk output multi-baris
