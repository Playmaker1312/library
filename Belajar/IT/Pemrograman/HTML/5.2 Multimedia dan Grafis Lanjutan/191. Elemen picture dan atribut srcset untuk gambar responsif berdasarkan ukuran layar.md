# Elemen picture dan Atribut srcset untuk Gambar Responsif Berdasarkan Ukuran Layar

## Analogi: Perpustakaan Digital

Bayangkan **foto buku** yang ditampilkan:
- Di **komputer** → foto ukuran besar (2000px) — tajam
- Di **tablet** → foto ukuran sedang (1000px)
- Di **HP** → foto ukuran kecil (500px) — hemat data, cepat loading

`<picture>` dan `srcset` adalah **alat pemilih ukuran foto otomatis**. Browser akan memilih ukuran gambar yang paling sesuai dengan layar pengunjung.

## Penjelasan Detail

### `<picture>` — Kontainer untuk Beberapa Sumber
```html
<picture>
  <source media="(min-width: 1024px)" srcset="besar.jpg">
  <source media="(min-width: 600px)" srcset="sedang.jpg">
  <img src="kecil.jpg" alt="Deskripsi">
</picture>
```

### `srcset` — Kumpulan Ukuran Gambar
```html
<img src="default.jpg"
     srcset="kecil.jpg 500w,
             sedang.jpg 1000w,
             besar.jpg 2000w"
     sizes="(max-width: 600px) 100vw,
            (max-width: 1024px) 50vw,
            33vw"
     alt="Deskripsi">
```

### `sizes` — Memberi Tahu Browser Ukuran Tampilan
Memberi tahu browser seberapa besar gambar akan ditampilkan (dalam viewport width).

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Responsive Images</title>
  </head>
  <body>
    <h1>Galeri Buku Responsif</h1>

    <!-- Picture element -->
    <picture>
      <source media="(min-width: 1024px)" srcset="buku-besar.jpg">
      <source media="(min-width: 600px)" srcset="buku-sedang.jpg">
      <img src="buku-kecil.jpg" alt="Koleksi buku perpustakaan"
           style="width: 100%; max-width: 800px;">
    </picture>

    <!-- srcset untuk gambar yang sama dengan resolusi berbeda -->
    <img src="sampul-buku.jpg"
         srcset="sampul-500.jpg 500w,
                 sampul-1000.jpg 1000w,
                 sampul-2000.jpg 2000w"
         sizes="(max-width: 600px) 100vw, 50vw"
         alt="Sampul buku Laskar Pelangi"
         style="width: 100%; max-width: 800px;">
  </body>
</html>
```

## Poin Penting
- `<picture>` = kontainer untuk **sumber gambar alternatif**
- `srcset` = daftar **ukuran/resolusi gambar**
- `sizes` = informasi **ukuran tampilan** untuk browser
- Browser pilih ukuran **terbaik** secara otomatis
- Meningkatkan **performa** (tidak unduh gambar besar di HP)
