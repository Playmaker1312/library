# Web Video Text Tracks (WebVTT) Untuk Subtitle Dan Caption Video Yang Aksesibel

## Analogi: Perpustakaan Digital

Seperti buku dengan transkrip lengkap untuk pengunjung tunarungu, WebVTT menyediakan teks yang sinkron dengan video. Ini memastikan konten video dapat diakses oleh semua orang, termasuk mereka yang memiliki keterbatasan pendengaran atau berada di lingkungan bising.

## Penjelasan Detail

WebVTT (Web Video Text Tracks) adalah format file teks yang berisi subtitle, caption, deskripsi, atau metadata yang disinkronkan dengan waktu pemutaran video. File WebVTT memiliki ekstensi `.vtt` dan dimulai dengan header `WEBVTT`. Setiap entri cue memiliki rentang waktu (format `HH:MM:SS.mmm --> HH:MM:SS.mmm`) diikuti teks subtitle. Cue dapat memiliki gaya CSS menggunakan `::cue` pseudo-element dan mendukung penempatan dengan pengaturan positioning. File VTT dihubungkan ke elemen `<video>` melalui elemen `<track>` dengan atribut `kind` yang dapat berupa `subtitles`, `captions`, `descriptions`, `chapters`, atau `metadata`. Browser menyediakan kontrol bawaan untuk mengaktifkan subtitle.

## Poin Penting
- File WebVTT dimulai dengan header `WEBVTT` dan berisi cue dengan format `waktu --> waktu`
- Elemen `<track>` menghubungkan file VTT ke video dengan atribut kind (subtitles, captions, dll)
- WebVTT meningkatkan aksesibilitas dan memungkinkan subtitle multibahasa
