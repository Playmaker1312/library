# Teknik Optimasi Gambar Untuk Web Termasuk Kompresi Dan Pemilihan Format Yang Tepat

## Analogi: Perpustakaan Digital

Seperti memilih jenis kertas dan ukuran cetak yang tepat untuk setiap jenis buku, optimasi gambar melibatkan pemilihan format, ukuran, dan tingkat kompresi yang sesuai untuk setiap gambar. Tujuannya adalah kualitas visual terbaik dengan ukuran file terkecil.

## Penjelasan Detail

Optimasi gambar web mencakup beberapa teknik: kompresi (lossy vs lossless), pemilihan format yang tepat, pengubahan ukuran, dan penggunaan alat modern. Format JPEG cocok untuk foto dengan gradasi warna kompleks, PNG untuk gambar dengan teks dan transparansi, WebP sebagai alternatif modern untuk keduanya, dan AVIF untuk kompresi terbaik. GIF digantikan oleh video pendek atau format animasi WebP. Teknik lain termasuk menghapus metadata EXIF, menggunakan sprite untuk ikon kecil, menerapkan kompresi dengan alat seperti imagemin atau Squoosh, serta menyajikan beberapa resolusi dengan srcset. CDN gambar seperti Cloudinary atau Imgix dapat mengotomatiskan optimasi. Kombinasi teknik ini dapat mengurangi ukuran gambar hingga 80% tanpa penurunan kualitas signifikan.

## Poin Penting
- Pilih format berdasarkan jenis gambar: JPEG untuk foto, PNG untuk grafis, WebP/AVIF sebagai alternatif modern
- Kompresi lossy mengurangi kualitas sedikit untuk ukuran file jauh lebih kecil
- Gunakan srcset dan picture untuk menyajikan gambar responsif dengan resolusi tepat
