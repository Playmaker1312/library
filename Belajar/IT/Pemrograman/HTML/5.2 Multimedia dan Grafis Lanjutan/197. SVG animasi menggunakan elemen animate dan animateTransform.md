# SVG Animasi Menggunakan Elemen Animate Dan AnimateTransform

## Analogi: Perpustakaan Digital

Seperti buku pop-up yang gerakannya muncul saat halaman dibuka, SVG animasi menghidupkan elemen grafis vektor tanpa perlu JavaScript atau CSS. Elemen animate dan animateTransform memberikan kehidupan pada gambar diam.

## Penjelasan Detail

SVG memiliki elemen animasi bawaan berdasarkan spesifikasi SMIL (Synchronized Multimedia Integration Language). Elemen `<animate>` digunakan untuk menganimasikan atribut numerik SVG seperti `x`, `y`, `width`, `height`, `fill`, atau `opacity` dari nilai awal ke nilai akhir. Elemen `<animateTransform>` khusus untuk menganimasikan transformasi seperti `translate`, `scale`, `rotate`, dan `skew`. Atribut umum meliputi `attributeName` (atribut yang dianimasikan), `from` dan `to` (nilai awal dan akhir), `dur` (durasi), `repeatCount` (jumlah pengulangan, atau `"indefinite"`), dan `begin` (waktu mulai). SVG animasi dapat membuat efek yang kompleks dengan menggabungkan beberapa elemen animasi dan menggunakan timing yang berbeda. Semua animasi berjalan langsung di browser tanpa plugin tambahan.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>SVG Animasi</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 700px; margin: auto; padding: 20px; text-align: center; }
    .anim-container { display: flex; flex-wrap: wrap; gap: 20px; justify-content: center; }
    .anim-card { border: 1px solid #ddd; border-radius: 8px; padding: 15px; background: #fafafa; }
    svg { border: 1px solid #eee; border-radius: 4px; background: white; }
  </style>
</head>
<body>
  <h1>Animasi SVG</h1>
  <div class="anim-container">
    <div class="anim-card">
      <svg width="150" height="150" xmlns="http://www.w3.org/2000/svg">
        <circle cx="75" cy="75" r="30" fill="#3498db">
          <animate attributeName="r" values="30;50;30" dur="2s" repeatCount="indefinite"/>
          <animate attributeName="fill" values="#3498db;#e74c3c;#3498db" dur="2s" repeatCount="indefinite"/>
        </circle>
      </svg>
      <p><strong>animate</strong> (ukuran &amp; warna)</p>
    </div>
    <div class="anim-card">
      <svg width="150" height="150" xmlns="http://www.w3.org/2000/svg">
        <rect x="50" y="60" width="50" height="30" fill="#27ae60" rx="5">
          <animateTransform attributeName="transform" type="rotate" from="0 75 75" to="360 75 75" dur="3s" repeatCount="indefinite"/>
        </rect>
      </svg>
      <p><strong>animateTransform</strong> (rotate)</p>
    </div>
    <div class="anim-card">
      <svg width="150" height="150" xmlns="http://www.w3.org/2000/svg">
        <circle cx="30" cy="75" r="12" fill="#e67e22">
          <animate attributeName="cx" values="30;120;30" dur="2s" repeatCount="indefinite"/>
        </circle>
      </svg>
      <p><strong>animate</strong> (bergerak)</p>
    </div>
    <div class="anim-card">
      <svg width="150" height="150" xmlns="http://www.w3.org/2000/svg">
        <rect x="40" y="40" width="70" height="70" fill="#9b59b6" rx="8" opacity="1">
          <animate attributeName="opacity" values="1;0.2;1" dur="1.5s" repeatCount="indefinite"/>
          <animateTransform attributeName="transform" type="scale" values="1;1.2;1" dur="1.5s" repeatCount="indefinite"/>
        </rect>
      </svg>
      <p><strong>Kombinasi</strong> (opacity &amp; scale)</p>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- `<animate>` menganimasikan atribut seperti posisi, ukuran, warna, dan opacity
- `<animateTransform>` menganimasikan transformasi: rotate, scale, translate, skew
- Atribut kunci: attributeName, from/to/values, dur, repeatCount, dan begin
