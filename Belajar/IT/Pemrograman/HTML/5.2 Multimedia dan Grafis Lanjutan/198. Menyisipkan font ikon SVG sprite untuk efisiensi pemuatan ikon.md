# Menyisipkan Font Ikon SVG Sprite Untuk Efisiensi Pemuatan Ikon

## Analogi: Perpustakaan Digital

Seperti satu lembar stiker yang berisi banyak ikon kecil dalam satu halaman, SVG sprite menggabungkan banyak ikon ke dalam satu file SVG. Ini mengurangi jumlah request HTTP dan mempercepat pemuatan halaman secara signifikan.

## Penjelasan Detail

SVG sprite adalah teknik menggabungkan banyak ikon SVG ke dalam satu file SVG tersembunyi, lalu merujuk setiap ikon menggunakan elemen `<use>` dengan ID tertentu. Setiap ikon ditempatkan dalam elemen `<symbol>` atau `<g>` dengan atribut `id` unik. File sprite biasanya ditempatkan di awal body atau dimuat secara terpisah. Untuk menggunakan ikon, gunakan `<svg><use href="#icon-name"></use></svg>` yang mereferensikan ID ikon dalam sprite. Keuntungan utama SVG sprite adalah hanya satu request HTTP untuk semua ikon, ukuran total lebih kecil dibandingkan file terpisah, dan ikon dapat diubah warna menggunakan CSS `fill` dan `stroke`. Ini adalah metode yang lebih efisien dibandingkan font ikon tradisional seperti Font Awesome.

## Poin Penting
- SVG sprite menggabungkan banyak ikon dalam satu file menggunakan elemen `<symbol>` dengan ID unik
- Gunakan `<svg><use href="#id-ikon"></use></svg>` untuk merender ikon dari sprite
- Ikon SVG sprite dapat diubah warna dengan CSS `fill` dan `stroke`, tidak seperti font ikon
