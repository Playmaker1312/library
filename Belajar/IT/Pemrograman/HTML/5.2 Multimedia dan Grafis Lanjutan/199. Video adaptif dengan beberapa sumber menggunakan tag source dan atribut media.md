# Video Adaptif Dengan Beberapa Sumber Menggunakan Tag Source Dan Atribut Media

## Analogi: Perpustakaan Digital

Seperti perpustakaan yang menyediakan buku dalam tiga format sekaligus (cetak besar, audio, dan braille) agar dapat diakses oleh semua pengunjung, video adaptif menyediakan beberapa versi video untuk perangkat dan kondisi jaringan yang berbeda.

## Penjelasan Detail

Video adaptif menggunakan elemen `<video>` dengan beberapa elemen `<source>` untuk menyediakan format video alternatif yang dipilih browser berdasarkan dukungan codec dan kondisi media. Atribut `type` pada `<source>` menentukan format video (seperti `video/mp4`, `video/webm`) agar browser dapat memilih sumber yang didukung tanpa mengunduh. Atribut `media` memungkinkan seleksi berdasarkan query media CSS (seperti `(max-width: 600px)` untuk perangkat seluler). Browser akan memilih sumber pertama yang didukung. Format umum meliputi MP4 (H.264) untuk dukungan universal, WebM (VP9) untuk browser modern, dan terkadang Ogg untuk kompatibilitas lama. Menyediakan beberapa resolusi juga dapat dilakukan dengan atribut `width` dan `height`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Video Adaptif</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 700px; margin: auto; padding: 20px; }
    video { width: 100%; border-radius: 10px; box-shadow: 0 4px 8px rgba(0,0,0,0.1); }
    .info { background: #e8f4f8; padding: 15px; border-radius: 8px; margin: 20px 0; }
    code { background: #f4f4f4; padding: 2px 6px; border-radius: 3px; }
    .controls { margin-top: 10px; display: flex; gap: 10px; flex-wrap: wrap; }
    .controls button { padding: 8px 16px; cursor: pointer; background: #3498db; color: white; border: none; border-radius: 5px; }
  </style>
</head>
<body>
  <h1>Video Adaptif dengan Multiple Source</h1>
  <div class="info">
    <p>Browser memilih sumber video pertama yang didukung. Urutan prioritas: WebM (VP9) &gt; MP4 (H.264).</p>
    <p>Atribut <code>media</code> dapat digunakan untuk memilih sumber berdasarkan lebar layar.</p>
  </div>

  <video controls poster="https://via.placeholder.com/700x400/2c3e50/fff?text=Video+Player">
    <!-- Prioritas tinggi: WebM untuk browser modern -->
    <source src="https://www.w3schools.com/html/mov_bbb.webm" type="video/webm">
    <!-- Fallback: MP4 untuk dukungan universal -->
    <source src="https://www.w3schools.com/html/mov_bbb.mp4" type="video/mp4">
    <!-- Teks alternatif jika video tidak didukung sama sekali -->
    Browser Anda tidak mendukung tag video.
  </video>

  <div class="controls">
    <button onclick="document.querySelector('video').play()">Putar</button>
    <button onclick="document.querySelector('video').pause()">Jeda</button>
    <button onclick="document.querySelector('video').volume += 0.1">Volume +</button>
    <button onclick="document.querySelector('video').volume -= 0.1">Volume -</button>
  </div>

  <p style="color:#7f8c8d;">Video contoh dari W3Schools (Big Buck Bunny).</p>
</body>
</html>
```

## Poin Penting
- Gunakan beberapa `<source>` dalam `<video>` untuk menyediakan format codec alternatif
- Atribut `type` membantu browser memilih format yang didukung tanpa mengunduh
- Atribut `media` memungkinkan seleksi sumber berdasarkan kondisi viewport
