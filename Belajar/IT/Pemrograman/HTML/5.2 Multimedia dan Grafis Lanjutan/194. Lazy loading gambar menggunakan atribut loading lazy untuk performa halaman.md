# Lazy Loading Gambar Menggunakan Atribut Loading Lazy Untuk Performa Halaman

## Analogi: Perpustakaan Digital

Seperti petugas perpustakaan yang hanya mengambil buku dari rak saat diminta pengunjung, lazy loading menunda pemuatan gambar sampai gambar tersebut akan terlihat di layar. Ini menghemat bandwidth dan mempercepat muat halaman awal.

## Penjelasan Detail

Atribut `loading="lazy"` pada elemen `<img>` dan `<iframe>` adalah fitur HTML5 yang memungkinkan browser menunda pemuatan sumber daya hingga elemen tersebut mendekati area pandang (viewport). Browser akan memuat gambar tepat waktu sebelum pengguna menggulir ke posisinya, menciptakan pengalaman yang mulus tanpa penundaan. Nilai lain dari atribut ini adalah `"eager"` (muat segera, default) dan `"auto"` (biarkan browser memutuskan). Lazy loading meningkatkan metrik performa seperti Largest Contentful Paint (LCP) dan mengurangi data yang diunduh pada muat halaman awal. Atribut ini didukung oleh semua browser modern dan merupakan cara paling sederhana untuk menerapkan lazy loading tanpa JavaScript tambahan.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Lazy Loading Demo</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 500px; margin: auto; padding: 20px; }
    img { width: 100%; height: 300px; object-fit: cover; border-radius: 8px; margin: 20px 0; display: block; }
    .info { background: #fff3cd; padding: 15px; border-radius: 8px; }
    .placeholder { background: #ecf0f1; display: flex; align-items: center; justify-content: center; height: 300px; border-radius: 8px; color: #95a5a6; margin: 20px 0; }
  </style>
</head>
<body>
  <h1>Lazy Loading Gambar</h1>
  <div class="info">
    <p>Gambar di halaman ini menggunakan <code>loading="lazy"</code>. Buka tab Network di DevTools dan gulir ke bawah untuk melihat gambar dimuat saat mendekati viewport.</p>
  </div>

  <!-- Gambar pertama: eager (muat segera) -->
  <img src="https://via.placeholder.com/500x300/3498db/fff?text=Gambar+1+Eager" loading="eager" alt="Gambar dimuat segera">

  <p style="height: 150vh; display: flex; align-items: center; justify-content: center; background: #f8f9fa; border-radius: 8px; color: #7f8c8d;">
    Gulir ke bawah untuk melihat lazy loading...
  </p>

  <!-- Gambar lazy -->
  <img src="https://via.placeholder.com/500x300/e74c3c/fff?text=Gambar+2+Lazy" loading="lazy" alt="Gambar lazy loading 1">
  <img src="https://via.placeholder.com/500x300/27ae60/fff?text=Gambar+3+Lazy" loading="lazy" alt="Gambar lazy loading 2">
  <img src="https://via.placeholder.com/500x300/9b59b6/fff?text=Gambar+4+Lazy" loading="lazy" alt="Gambar lazy loading 3">

  <p style="text-align: center; color: #7f8c8d; margin-top: 20px;">Selesai. Gambar dimuat saat mendekati viewport.</p>
</body>
</html>
```

## Poin Penting
- Atribut `loading="lazy"` membuat gambar dimuat hanya saat mendekati area pandang
- Menghemat bandwidth dan meningkatkan kecepatan muat halaman awal
- Didukung semua browser modern tanpa perlu library JavaScript tambahan
