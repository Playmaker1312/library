# Atribut Sizes Pada Elemen Gambar Untuk Menentukan Lebar Tampilan Gambar

## Analogi: Perpustakaan Digital

Seperti memilih ukuran buku yang tepat untuk rak yang tersedia, atribut `sizes` membantu browser memilih versi gambar yang paling sesuai dengan lebar layar pengguna. Ini memastikan gambar tidak terlalu besar atau terlalu kecil untuk ruang yang tersedia.

## Penjelasan Detail

Atribut `sizes` pada elemen `<img>` bekerja bersama dengan atribut `srcset` untuk memberi tahu browser ukuran tampilan gambar yang direncanakan pada berbagai lebar viewport. Atribut ini berisi satu atau lebih string yang dipisahkan koma, masing-masing terdiri dari kondisi media (seperti `min-width: 768px`) dan ukuran slot (seperti `50vw` atau `300px`). Browser menggunakan informasi ini untuk memilih sumber gambar yang paling sesuai dari `srcset`, mengoptimalkan bandwidth dan waktu muat. Jika `sizes` tidak ditentukan, browser menganggap ukuran gambar sebagai `100vw` (lebar viewport penuh). Atribut ini sangat berguna untuk desain responsif dengan tata letak yang mengubah lebar gambar berdasarkan breakpoint.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Atribut Sizes Demo</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 900px; margin: auto; padding: 20px; }
    .gallery { display: flex; flex-wrap: wrap; gap: 10px; }
    .gallery img { height: auto; border-radius: 5px; }
    .info { background: #ecf0f1; padding: 15px; border-radius: 8px; margin: 20px 0; }
    code { background: #f4f4f4; padding: 2px 6px; border-radius: 3px; }
  </style>
</head>
<body>
  <h1>Demo Atribut sizes</h1>
  <div class="info">
    <p>Gunakan <strong>DevTools</strong> (Network tab) untuk melihat gambar mana yang dimuat berdasarkan lebar viewport.</p>
    <p>Lebar gambar CSS: <code>min(400px, 90vw)</code></p>
  </div>
  <img src="https://via.placeholder.com/400x300/3498db/fff?text=Fallback"
       srcset="https://via.placeholder.com/400x300/3498db/fff?text=400px 400w,
               https://via.placeholder.com/600x300/e74c3c/fff?text=600px 600w,
               https://via.placeholder.com/800x300/27ae60/fff?text=800px 800w"
       sizes="(max-width: 600px) 100vw, (max-width: 900px) 50vw, 400px"
       alt="Demo atribut sizes"
       style="width: min(400px, 90vw);">
  <p>Browser memilih gambar dari <code>srcset</code> berdasarkan <code>sizes</code> dan lebar viewport.</p>
</body>
</html>
```

## Poin Penting
- Atribut `sizes` memberi tahu browser lebar tampilan gambar pada berbagai kondisi viewport
- Bekerja bersama `srcset` untuk memilih sumber gambar yang paling efisien
- Format: `(condition) width, (condition) width, default-width` seperti `(max-width: 600px) 100vw, 300px`
