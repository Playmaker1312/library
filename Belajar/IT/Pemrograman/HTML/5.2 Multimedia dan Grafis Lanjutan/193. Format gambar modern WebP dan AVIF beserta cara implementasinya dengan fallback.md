# Format Gambar Modern WebP Dan AVIF Beserta Cara Implementasinya Dengan Fallback

## Analogi: Perpustakaan Digital

Seperti buku yang dicetak dalam dua format sekaligus (hardcover untuk kualitas, paperback untuk portabilitas), WebP dan AVIF adalah format gambar modern yang menawarkan kompresi lebih baik. Anda perlu menyediakan format fallback untuk browser lama yang belum mendukungnya.

## Penjelasan Detail

WebP adalah format gambar yang dikembangkan Google dengan kompresi lossy dan lossless yang 25-35% lebih kecil dari JPEG, mendukung transparansi dan animasi. AVIF adalah format yang lebih baru berbasis AV1, menawarkan kompresi 50% lebih baik dari JPEG dengan kualitas setara. Untuk mengimplementasikan kedua format dengan fallback, gunakan elemen `<picture>` dengan beberapa elemen `<source>` dan `<img>` sebagai cadangan terakhir. Browser akan memilih format pertama yang didukung secara berurutan. WebP didukung oleh Chrome, Firefox, Edge, dan Safari 14+, sementara AVIF didukung Chrome, Firefox, dan Opera. Penggunaan format modern ini secara signifikan mengurangi ukuran halaman dan meningkatkan waktu muat.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>WebP dan AVIF Demo</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 700px; margin: auto; padding: 20px; text-align: center; }
    img { max-width: 100%; border-radius: 10px; box-shadow: 0 4px 8px rgba(0,0,0,0.1); }
    .info { background: #ecf0f1; padding: 15px; border-radius: 8px; margin: 20px 0; text-align: left; }
    code { background: #f4f4f4; padding: 2px 6px; border-radius: 3px; }
  </style>
</head>
<body>
  <h1>Format Gambar Modern: WebP &amp; AVIF</h1>
  <div class="info">
    <p>Gambar di bawah menggunakan:</p>
    <ul>
      <li><strong>AVIF</strong> (prioritas utama, kualitas terbaik, ukuran terkecil)</li>
      <li><strong>WebP</strong> (fallback kedua, ukuran kecil, dukungan luas)</li>
      <li><strong>JPEG</strong> (fallback terakhir, didukung semua browser)</li>
    </ul>
    <p>Cek elemen gambar di DevTools untuk melihat format yang dipilih.</p>
  </div>

  <picture>
    <source srcset="https://via.placeholder.com/600x400/8e44ad/fff?text=AVIF&fmt=avif" type="image/avif">
    <source srcset="https://via.placeholder.com/600x400/e67e22/fff?text=WebP&fmt=webp" type="image/webp">
    <img src="https://via.placeholder.com/600x400/3498db/fff?text=JPEG+Fallback" alt="Demo format gambar modern">
  </picture>

  <p>Browser otomatis memilih format yang didukung. Urutan prioritas: AVIF &gt; WebP &gt; JPEG.</p>
</body>
</html>
```

## Poin Penting
- WebP menawarkan kompresi 25-35% lebih kecil dari JPEG, AVIF hingga 50% lebih kecil dari JPEG
- Gunakan elemen `<picture>` dengan `<source type="image/avif">` dan `<source type="image/webp">` untuk fallback
- Format modern didukung browser terbaru, siapkan fallback ke JPEG atau PNG untuk browser lama
