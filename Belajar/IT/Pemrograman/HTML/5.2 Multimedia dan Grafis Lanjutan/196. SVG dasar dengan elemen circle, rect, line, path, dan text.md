# SVG Dasar Dengan Elemen Circle, Rect, Line, Path, Dan Text

## Analogi: Perpustakaan Digital

Seperti buku gambar yang berisi bentuk-bentuk dasar seperti lingkaran, persegi, garis, dan huruf, SVG menyediakan elemen-elemen geometris untuk membangun grafis vektor. Setiap bentuk adalah blok bangunan yang dapat digabungkan menjadi ilustrasi kompleks.

## Penjelasan Detail

SVG (Scalable Vector Graphics) menyediakan elemen geometris dasar untuk membuat grafis vektor langsung di dalam HTML. Elemen `<circle>` menggambar lingkaran dengan atribut `cx`, `cy` (pusat) dan `r` (jari-jari). `<rect>` menggambar persegi panjang dengan `x`, `y`, `width`, `height`, dan opsional `rx`/`ry` untuk sudut melengkung. `<line>` menggambar garis lurus antara dua titik dengan `x1`, `y1`, `x2`, `y2`. Elemen `<path>` adalah yang paling kuat, mampu menggambar kurva, busur, dan bentuk kompleks menggunakan perintah seperti M (move), L (line), C (cubic curve), dan Z (close). `<text>` menampilkan teks dengan atribut `x`, `y`, `font-family`, `font-size`, dan `text-anchor`. Semua elemen SVG dapat diberi gaya dengan atribut `fill`, `stroke`, `stroke-width`, dan `opacity`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Dasar SVG</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 700px; margin: auto; padding: 20px; }
    .svg-container { display: flex; flex-wrap: wrap; gap: 20px; justify-content: center; }
    .svg-card { border: 1px solid #ddd; border-radius: 8px; padding: 10px; text-align: center; background: #fafafa; }
    svg { border: 1px solid #eee; border-radius: 4px; }
    code { background: #f4f4f4; padding: 2px 6px; border-radius: 3px; }
  </style>
</head>
<body>
  <h1>Elemen Dasar SVG</h1>
  <div class="svg-container">
    <div class="svg-card">
      <svg width="120" height="120" xmlns="http://www.w3.org/2000/svg">
        <circle cx="60" cy="60" r="50" fill="#3498db" stroke="#2c3e50" stroke-width="3"/>
      </svg>
      <p><code>&lt;circle&gt;</code></p>
    </div>
    <div class="svg-card">
      <svg width="120" height="120" xmlns="http://www.w3.org/2000/svg">
        <rect x="15" y="15" width="90" height="90" fill="#e74c3c" rx="10" stroke="#2c3e50" stroke-width="3"/>
      </svg>
      <p><code>&lt;rect&gt;</code></p>
    </div>
    <div class="svg-card">
      <svg width="120" height="120" xmlns="http://www.w3.org/2000/svg">
        <line x1="15" y1="100" x2="105" y2="20" stroke="#27ae60" stroke-width="4" stroke-linecap="round"/>
      </svg>
      <p><code>&lt;line&gt;</code></p>
    </div>
    <div class="svg-card">
      <svg width="120" height="120" xmlns="http://www.w3.org/2000/svg">
        <path d="M 20 100 L 40 40 L 60 80 L 100 20" fill="none" stroke="#9b59b6" stroke-width="3" stroke-linejoin="round"/>
      </svg>
      <p><code>&lt;path&gt;</code></p>
    </div>
    <div class="svg-card">
      <svg width="120" height="120" xmlns="http://www.w3.org/2000/svg">
        <text x="60" y="65" text-anchor="middle" font-family="Arial" font-size="22" fill="#e67e22" font-weight="bold">SVG</text>
      </svg>
      <p><code>&lt;text&gt;</code></p>
    </div>
    <div class="svg-card">
      <svg width="120" height="120" xmlns="http://www.w3.org/2000/svg">
        <circle cx="60" cy="60" r="45" fill="#1abc9c" opacity="0.5"/>
        <rect x="25" y="25" width="70" height="70" fill="none" stroke="#2c3e50" stroke-width="2"/>
        <path d="M 20 60 Q 60 20 100 60 Q 60 100 20 60" fill="#e74c3c" opacity="0.5"/>
        <text x="60" y="65" text-anchor="middle" font-size="12" fill="#2c3e50">Kombinasi</text>
      </svg>
      <p>Kombinasi Elemen</p>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Elemen SVG dasar: circle (lingkaran), rect (persegi), line (garis), path (kurva), text (teks)
- Atribut fill mengatur warna isi, stroke mengatur warna garis tepi, stroke-width mengatur ketebalan
- Elemen path menggunakan perintah M (move), L (line), C (curve), Q (quadratic), Z (close)
