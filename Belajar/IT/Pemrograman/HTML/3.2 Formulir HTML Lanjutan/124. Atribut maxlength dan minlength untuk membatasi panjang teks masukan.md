# Atribut maxlength dan minlength untuk Membatasi Panjang Teks Masukan

## Analogi: Perpustakaan Digital

Bayangkan **kolom ISBN** yang hanya boleh 13 digit. Atau **kolom password** yang minimal 8 karakter. Perpustakaan punya aturan: "Kode anggota maksimal 10 karakter, password minimal 8 karakter."

- **`maxlength`** = **Batas atas** — berapa karakter maksimal
- **`minlength`** = **Batas bawah** — berapa karakter minimal

## Penjelasan Detail

`maxlength` dan `minlength` membatasi jumlah karakter yang bisa diketik.

### maxlength
Mencegah pengguna mengetik **lebih dari** jumlah karakter tertentu.
```html
<input type="text" maxlength="10">
```
Pengguna tidak bisa mengetik lebih dari 10 karakter.

### minlength
Mewajibkan input memiliki **setidaknya** jumlah karakter tertentu.
```html
<input type="password" minlength="8">
```
Browser akan menolak jika karakter kurang dari 8 (harus dikombinasikan dengan `required` atau form validation).

### Perbedaan
| Atribut | Fungsi | Kapan Diterapkan |
|---------|--------|-----------------|
| `maxlength` | Cegah kelebihan karakter | **Saat mengetik** |
| `minlength` | Validasi minimal karakter | **Saat submit** (bersama required) |

### Kombinasi
```html
<input type="text" minlength="3" maxlength="50"
       placeholder="3-50 karakter">
```

### Penting!
`minlength` hanya berfungsi jika input juga punya `required` atau nilai sudah terisi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Maxlength Minlength</title>
  </head>
  <body>
    <h1>Formulir dengan Batasan Karakter</h1>

    <form action="simpan.php" method="POST">
      <p>
        <label for="kode">Kode Buku (maksimal 10 karakter):</label><br>
        <input type="text" id="kode" name="kode"
               maxlength="10" placeholder="Contoh: BK-001">
        <small><span id="counter">0</span>/10 karakter</small>
      </p>

      <p>
        <label for="nama">Nama Buku (3-100 karakter):</label><br>
        <input type="text" id="nama" name="nama"
               minlength="3" maxlength="100" required>
      </p>

      <p>
        <label for="pass">Password (minimal 8 karakter):</label><br>
        <input type="password" id="pass" name="pass"
               minlength="8" required>
      </p>

      <p>
        <label for="deskripsi">Deskripsi (maksimal 500 karakter):</label><br>
        <textarea id="deskripsi" name="deskripsi"
                  maxlength="500" rows="4" cols="40"
                  placeholder="Deskripsi buku..."></textarea>
      </p>

      <p>
        <button type="submit">Simpan</button>
      </p>
    </form>

    <!-- Counter karakter dengan JavaScript -->
    <script>
      document.getElementById('kode').oninput = function() {
        document.getElementById('counter').textContent = this.value.length;
      };
    </script>
  </body>
</html>
```

## Poin Penting
- `maxlength` = **batas maksimal** karakter (cegah saat mengetik)
- `minlength` = **batas minimal** karakter (validasi saat submit)
- `maxlength` bekerja di text, textarea, password, dan beberapa type lain
- `minlength` butuh `required` atau form validation
- Tampilkan counter karakter untuk UX yang lebih baik
