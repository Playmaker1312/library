# Atribut multiple pada select untuk Memilih Lebih dari Satu Pilihan

## Analogi: Perpustakaan Digital

Bayangkan **daftar genre buku** yang bisa dipilih lebih dari satu. Dengan dropdown biasa, kamu hanya bisa pilih satu genre. Tapi dengan atribut `multiple`, kamu bisa pilih **Fiksi + Sains + Sejarah** sekaligus.

`multiple` pada `<select>` mengubah dropdown biasa menjadi **list box** yang memungkinkan pemilihan beberapa opsi sekaligus.

## Penjelasan Detail

`multiple` adalah atribut boolean pada `<select>` yang memungkinkan **pilih banyak opsi**.

### Tanpa vs Dengan Multiple
```html
<!-- Hanya bisa pilih satu -->
<select name="genre">
  <option>Fiksi</option>
  <option>Sains</option>
</select>

<!-- Bisa pilih banyak -->
<select name="genre[]" multiple>
  <option>Fiksi</option>
  <option>Sains</option>
</select>
```

### Cara Memilih
- **Desktop**: Ctrl+klik (Windows/Linux) atau Cmd+klik (Mac)
- **Range**: Shift+klik untuk pilih range
- **Mobile**: Biasanya dengan tap (tergantung implementasi browser)

### Atribut `size`
Sebaiknya kombinasikan dengan `size` agar beberapa opsi terlihat:
```html
<select name="genre[]" multiple size="5">
```

### Name untuk Array
Di server, value akan dikirim sebagai array. Gunakan `[]` di akhir `name`:
```html
<select name="genre[]" multiple>
```
Ini memberi tahu server untuk menerima banyak nilai (PHP, Node.js, dll).

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Multiple Select</title>
  </head>
  <body>
    <h1>Pilih Genre Buku Favorit</h1>

    <form action="simpan.php" method="POST">
      <p>
        <label for="genre">Genre favorit Anda (bisa pilih banyak):</label><br>
        <select id="genre" name="genre[]" multiple size="6"
                style="width: 200px;">
          <option value="fiksi">Fiksi</option>
          <option value="nonfiksi" selected>Non Fiksi</option>
          <option value="sains">Sains</option>
          <option value="sejarah">Sejarah</option>
          <option value="teknologi" selected>Teknologi</option>
          <option value="filsafat">Filsafat</option>
        </select>
        <br>
        <small>Ctrl+klik (Windows) atau Cmd+klik (Mac) untuk pilih banyak.</small>
      </p>

      <p>
        <button type="submit">Simpan</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `multiple` = izinkan **pilih banyak opsi**
- Ubah dropdown jadi **list box** (beberapa opsi terlihat)
- Kombinasikan dengan `size` agar opsi terlihat
- Gunakan `name[]` untuk array di server
- Pintasan: Ctrl+klik (Windows), Cmd+klik (Mac)
