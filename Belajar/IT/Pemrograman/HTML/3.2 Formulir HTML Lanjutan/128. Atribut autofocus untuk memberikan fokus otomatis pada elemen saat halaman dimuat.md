# Atribut autofocus untuk Memberikan Fokus Otomatis pada Elemen saat Halaman Dimuat

## Analogi: Perpustakaan Digital

Bayangkan saat kamu memasuki ruang baca perpustakaan, **lampu langsung menyorot ke meja baca utama**. Tanpa perlu mencari, kamu langsung tahu harus mulai dari mana.

`autofocus` adalah **sorot lampu otomatis** — saat halaman dimuat, kursor langsung berada di input yang memiliki atribut ini. Pengguna bisa langsung mengetik tanpa perlu klik kolom terlebih dahulu.

## Penjelasan Detail

`autofocus` adalah atribut boolean yang memberikan **fokus otomatis** ke elemen saat halaman dimuat.

### Format
```html
<input type="text" autofocus>
<textarea autofocus></textarea>
<button autofocus></button>
```

### Cara Kerja
1. Halaman selesai dimuat
2. Browser langsung memberikan fokus ke elemen dengan `autofocus`
3. Kursor berkedip di input tersebut
4. Pengguna bisa langsung mengetik

### Aturan
- Hanya **satu** elemen per halaman yang boleh punya `autofocus`
- Jika lebih dari satu, browser akan fokus ke yang pertama ditemukan
- Tidak berfungsi di iframe (untuk keamanan)

### Kapan Pakai `autofocus`?
- **Kotak pencarian** di halaman utama
- **Field pertama** di formulir login
- **Input pertama** di formulir pendaftaran
- **Kotak komentar** di halaman diskusi

### Kapan JANGAN Pakai?
- Halaman dengan banyak konten (fokus otomatis bisa ganggu scroll)
- Formulir panjang (pengguna mungkin ingin scroll dulu)
- Di mobile (keyboard otomatis muncul — bisa ganggu)

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Autofocus</title>
  </head>
  <body>
    <h1>Pencarian Buku Perpustakaan</h1>

    <form action="cari.php" method="GET">
      <p>
        <label for="q">Cari buku:</label><br>
        <!-- Fokus otomatis ke sini saat halaman dimuat -->
        <input type="text" id="q" name="q"
               placeholder="Judul buku, penulis, ISBN..."
               autofocus
               style="width: 300px; padding: 10px;">
      </p>

      <p>
        <button type="submit">Cari</button>
      </p>
    </form>

    <hr>

    <h2>Login Cepat</h2>
    <form action="login.php" method="POST">
      <p>
        <label for="user">Username:</label><br>
        <input type="text" id="user" name="user"
               placeholder="Username" autofocus>
        <!-- Hanya satu autofocus per halaman yang efektif -->
        <!-- Browser akan fokus ke yang pertama (input q) -->
      </p>
      <p>
        <label for="pass">Password:</label><br>
        <input type="password" id="pass" name="pass"
               placeholder="Password">
      </p>
      <p>
        <button type="submit">Login</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `autofocus` = **fokus otomatis** saat halaman dimuat
- Hanya **satu** elemen per halaman
- Cocok untuk: kotak pencarian, field login pertama
- Di mobile: keyboard akan otomatis muncul
- Jangan pakai di halaman yang butuh scroll dulu sebelum isi form
