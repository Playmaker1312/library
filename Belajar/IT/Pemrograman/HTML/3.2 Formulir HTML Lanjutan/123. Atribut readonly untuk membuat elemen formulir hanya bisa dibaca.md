# Atribut readonly untuk Membuat Elemen Formulir Hanya Bisa Dibaca

## Analogi: Perpustakaan Digital

Bayangkan **kartu anggota** yang sudah tercetak namanya. Kamu bisa melihat dan membaca nama itu, tapi tidak bisa mengubahnya. Informasinya tetap bisa dibaca sistem.

`readonly` adalah atribut yang membuat input **hanya bisa dibaca** — pengguna bisa melihat teks dan memfokuskan input, tapi tidak bisa mengedit isinya. Nilainya **tetap dikirim** ke server.

## Penjelasan Detail

`readonly` membuat input **read-only** (hanya baca). Berbeda dengan `disabled`.

### Perbandingan

| Aspek | `readonly` | `disabled` |
|-------|-----------|------------|
| Bisa difokuskan? | ✅ Ya (tab) | ❌ Tidak |
| Bisa diedit? | ❌ Tidak | ❌ Tidak |
| Tampilan | Normal | Abu-abu |
| Bisa di-copy? | ✅ Ya | ✅ Ya |
| Dikirim ke server? | ✅ **Ya** | ❌ Tidak |

### Format
```html
<input type="text" value="Tidak bisa diubah" readonly>
<textarea readonly>Teks tidak bisa diedit</textarea>
```

### Kapan Pakai `readonly`?
- **Data dari sistem** — ID, kode anggota, username
- **Data yang sudah dikonfirmasi** — tapi perlu ditampilkan
- **Data kalkulasi** — hasil perhitungan otomatis
- **Preview** — lihat data sebelum dikirim

### readonly Tidak untuk Checkbox/Radio
`readonly` **tidak berfungsi** untuk checkbox dan radio. Untuk itu, gunakan `disabled` jika perlu.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Readonly</title>
  </head>
  <body>
    <h1>Data Anggota Perpustakaan</h1>

    <form action="update.php" method="POST">
      <p>
        <label for="kode">Kode Anggota:</label><br>
        <input type="text" id="kode" name="kode"
               value="AG-2024-001" readonly>
        <small>Kode anggota tidak bisa diubah.</small>
      </p>

      <p>
        <label for="nama">Nama:</label><br>
        <input type="text" id="nama" name="nama"
               value="Budi Santoso">
        <small>Bisa diubah.</small>
      </p>

      <p>
        <label for="tgl_daftar">Tanggal Daftar:</label><br>
        <input type="date" id="tgl_daftar" name="tgl_daftar"
               value="2024-06-15" readonly>
      </p>

      <p>
        <label for="catatan">Catatan Sistem:</label><br>
        <textarea id="catatan" name="catatan" rows="3" cols="40"
                  readonly>Anggota aktif sejak 2024. Riwayat peminjaman baik.</textarea>
      </p>

      <p>
        <button type="submit">Simpan Perubahan</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `readonly` = input **hanya baca** (tidak bisa diedit)
- Tetap bisa **difokuskan** dan **di-copy**
- Nilainya **tetap dikirim** ke server (beda dengan disabled)
- Tidak berfungsi untuk checkbox/radio
- Tampilan tetap normal (tidak abu-abu)
