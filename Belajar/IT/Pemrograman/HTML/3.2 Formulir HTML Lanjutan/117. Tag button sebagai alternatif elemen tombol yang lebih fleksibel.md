# Tag button sebagai Alternatif Elemen Tombol yang Lebih Fleksibel

## Analogi: Perpustakaan Digital

Bayangkan **tombol di meja pendaftaran**. Ada tombol "Daftar" dengan teks biasa. Tapi bagaimana kalau kamu ingin tombol dengan **ikon + teks + teks tebal**? Di sinilah `<button>` lebih unggul.

`<button>` adalah **tombol yang lebih fleksibel** dibandingkan `<input type="submit">`. Kamu bisa memasukkan HTML di dalamnya — teks, gambar, ikon, bahkan format teks.

## Penjelasan Detail

`<button>` membuat tombol yang bisa berisi **HTML di dalamnya** (bukan hanya teks seperti `value` pada input).

### Perbandingan
```html
<!-- Input submit — hanya teks -->
<input type="submit" value="Kirim">

<!-- Button — bisa berisi HTML -->
<button type="submit">
  <strong>Kirim</strong> Data
</button>

<!-- Button dengan ikon -->
<button type="submit">
  📨 Kirim Sekarang
</button>
```

### Atribut `type` pada Button
| Type | Fungsi |
|------|--------|
| `submit` | Kirim form (default jika di dalam form) |
| `reset` | Reset form ke default |
| `button` | Tidak ada fungsi (butuh JavaScript) |

### Penting!
Jika `<button>` tidak diberi `type` dan diletakkan di dalam `<form>`, defaultnya adalah `submit`. Selalu tentukan `type` jika tidak ingin submit.

### Kelebihan `<button>` dibanding `<input>`
1. Bisa berisi **HTML**
2. Bisa **gambar** + teks
3. Bisa **CSS styling** lebih fleksibel
4. Lebih mudah diakses
5. Teks tombol bisa multi-baris

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Button Tag</title>
    <style>
      button {
        padding: 10px 20px;
        margin: 5px;
        cursor: pointer;
        border: none;
        border-radius: 5px;
        font-size: 16px;
      }
      .btn-primary { background: #3498db; color: white; }
      .btn-danger { background: #e74c3c; color: white; }
      .btn-success { background: #2ecc71; color: white; }
    </style>
  </head>
  <body>
    <h1>Demo Tombol dengan Button Tag</h1>

    <form action="simpan.php" method="POST">
      <p>
        <label for="nama">Nama:</label><br>
        <input type="text" id="nama" name="nama">
      </p>

      <p>
        <!-- Submit button dengan ikon -->
        <button type="submit" class="btn-primary">
          ✅ Simpan Data
        </button>

        <!-- Reset button -->
        <button type="reset" class="btn-danger">
          🔄 Hapus Semua
        </button>

        <!-- Button biasa (JavaScript) -->
        <button type="button" class="btn-success"
                onclick="alert('Halo! Selamat datang di Perpustakaan Digital')">
          👋 Sapa Pustakawan
        </button>
      </p>

      <p>
        <!-- Button dengan gambar -->
        <button type="button" onclick="alert('Mencetak...')">
          <img src="printer-icon.png" alt="" width="20" style="vertical-align: middle;">
          Cetak Halaman
        </button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `<button>` = tombol **fleksibel** (bisa berisi HTML)
- Tiga type: `submit`, `reset`, `button`
- Di dalam `<form>`, tanpa `type` → default **submit**
- Bisa berisi teks, gambar, ikon, format teks
- Lebih baik dari `<input>` untuk tombol yang kompleks
