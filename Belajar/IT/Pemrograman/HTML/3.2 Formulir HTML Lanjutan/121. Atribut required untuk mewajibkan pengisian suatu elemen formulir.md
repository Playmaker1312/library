# Atribut required untuk Mewajibkan Pengisian Suatu Elemen Formulir

## Analogi: Perpustakaan Digital

Bayangkan **formulir pendaftaran** yang memiliki kolom wajib. Jika kamu mencoba menekan tombol "Daftar" tanpa mengisi nama, formulir akan menolak dan berkata: "Harap isi nama Anda."

`required` adalah atribut yang membuat input **wajib diisi** sebelum form bisa dikirim. Browser akan menampilkan pesan error otomatis jika dikosongkan.

## Penjelasan Detail

`required` adalah atribut **boolean** — kehadirannya saja sudah cukup (tidak perlu nilai).

### Format
```html
<input type="text" required>
<input type="email" required>
<textarea required></textarea>
<select required>
  <option value="">Pilih...</option>
</select>
```

### Cara Kerja
1. Pengguna klik submit
2. Browser memeriksa semua input dengan `required`
3. Jika ada yang kosong → fokus ke input tersebut + pesan error
4. Form **tidak dikirim** sampai semua required terisi

### Pesan Error Kustom
```html
<input type="text" required
       oninvalid="this.setCustomValidity('Harap isi nama Anda')"
       oninput="this.setCustomValidity('')">
```

### Elemen yang Bisa Pakai Required
- `<input>` (kecuali type hidden, button, reset)
- `<textarea>`
- `<select>`

### Required vs Pattern
```html
<!-- Wajib diisi + validasi format -->
<input type="text" required pattern="[A-Za-z ]+">
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Required</title>
  </head>
  <body>
    <h1>Pendaftaran Anggota</h1>

    <form action="daftar.php" method="POST">
      <p>
        <label for="nama">Nama Lengkap <span style="color:red;">*</span>:</label><br>
        <input type="text" id="nama" name="nama" required
               placeholder="Wajib diisi">
      </p>

      <p>
        <label for="email">Email <span style="color:red;">*</span>:</label><br>
        <input type="email" id="email" name="email" required
               placeholder="nama@email.com">
      </p>

      <p>
        <label for="telp">No Telepon (opsional):</label><br>
        <input type="tel" id="telp" name="telp"
               placeholder="Tidak wajib">
      </p>

      <p>
        <label for="kategori">Kategori Buku Favorit <span style="color:red;">*</span>:</label><br>
        <select id="kategori" name="kategori" required>
          <option value="">— Pilih —</option>
          <option value="fiksi">Fiksi</option>
          <option value="nonfiksi">Non Fiksi</option>
        </select>
      </p>

      <p>
        <input type="checkbox" id="setuju" required>
        <label for="setuju">Saya setuju syarat dan ketentuan <span style="color:red;">*</span></label>
      </p>

      <p>
        <button type="submit">Daftar</button>
      </p>
    </form>

    <p><small>Field dengan tanda * wajib diisi.</small></p>
  </body>
</html>
```

## Poin Penting
- `required` = **wajib diisi** sebelum submit
- Browser menampilkan pesan error otomatis
- Tidak perlu nilai (`required` saja, bukan `required="true"`)
- Untuk input, textarea, select
- Kombinasikan dengan `pattern` untuk validasi format
