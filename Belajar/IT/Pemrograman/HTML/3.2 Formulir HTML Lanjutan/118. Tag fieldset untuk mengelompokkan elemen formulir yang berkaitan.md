# Tag fieldset untuk Mengelompokkan Elemen Formulir yang Berkaitan

## Analogi: Perpustakaan Digital

Bayangkan **formulir pendaftaran** yang dibagi menjadi beberapa bagian dengan kotak pembatas:

```
┌─ Data Pribadi ─────────────────────┐
│  Nama: [___________]               │
│  Email: [___________]              │
└────────────────────────────────────┘
┌─ Alamat ───────────────────────────┐
│  Jalan: [___________]              │
│  Kota: [___________]              │
└────────────────────────────────────┘
```

`<fieldset>` adalah **kotak pembatas** yang mengelompokkan elemen form yang terkait. Biasanya dipasangkan dengan `<legend>` untuk judul grup.

## Penjelasan Detail

`<fieldset>` digunakan untuk **mengelompokkan** elemen-elemen form yang memiliki hubungan.

### Atribut
| Atribut | Fungsi |
|---------|--------|
| `disabled` | Nonaktifkan **semua** elemen di dalam fieldset |
| `name` | Nama grup |
| `form` | Hubungkan dengan form (id) |

### `disabled` pada Fieldset
Satu atribut `disabled` pada fieldset akan menonaktifkan **semua** input di dalamnya:
```html
<fieldset disabled>
  <legend>Fitur Premium</legend>
  <input type="text" placeholder="Input ini nonaktif">
</fieldset>
```

### Manfaat Fieldset
1. **Organisasi** — form terstruktur dan rapi
2. **Aksesibilitas** — screen reader mengumumkan grup
3. **Styling** — kotak border otomatis
4. **Disable grup** — nonaktifkan semua elemen dalam grup

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Fieldset</title>
    <style>
      fieldset {
        border: 2px solid #3498db;
        border-radius: 8px;
        padding: 20px;
        margin: 20px 0;
      }
      legend {
        background: #3498db;
        color: white;
        padding: 5px 15px;
        border-radius: 5px;
        font-weight: bold;
      }
    </style>
  </head>
  <body>
    <h1>Pendaftaran Anggota Perpustakaan</h1>

    <form action="daftar.php" method="POST">
      <!-- Grup 1: Data Pribadi -->
      <fieldset>
        <legend>Data Pribadi</legend>

        <p>
          <label for="nama">Nama Lengkap:</label><br>
          <input type="text" id="nama" name="nama" required>
        </p>
        <p>
          <label for="email">Email:</label><br>
          <input type="email" id="email" name="email" required>
        </p>
        <p>
          <label for="telp">No Telepon:</label><br>
          <input type="tel" id="telp" name="telp">
        </p>
      </fieldset>

      <!-- Grup 2: Alamat -->
      <fieldset>
        <legend>Alamat</legend>

        <p>
          <label for="jalan">Jalan:</label><br>
          <input type="text" id="jalan" name="jalan">
        </p>
        <p>
          <label for="kota">Kota:</label><br>
          <input type="text" id="kota" name="kota">
        </p>
      </fieldset>

      <!-- Grup 3: Fitur Premium (nonaktif) -->
      <fieldset disabled>
        <legend>Fitur Premium (Segera)</legend>
        <p>
          <label for="vip">Layanan VIP:</label><br>
          <select id="vip" name="vip">
            <option>Basic</option>
            <option>Premium</option>
          </select>
        </p>
      </fieldset>

      <p>
        <button type="submit">Daftar</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `<fieldset>` = **grup** elemen form
- `<legend>` = **judul** grup (di dalam fieldset)
- `disabled` pada fieldset = nonaktifkan **semua** isinya
- Meningkatkan organisasi, aksesibilitas, dan UX
- Styling bisa disesuaikan dengan CSS
