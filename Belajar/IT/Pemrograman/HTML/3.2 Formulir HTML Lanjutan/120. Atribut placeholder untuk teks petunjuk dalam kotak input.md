# Atribut placeholder untuk Teks Petunjuk dalam Kotak Input

## Analogi: Perpustakaan Digital

Bayangkan **kolom isian** yang di dalamnya sudah ada teks abu-abu: "Masukkan nama lengkap". Saat kamu klik dan mulai mengetik, teks itu **hilang** dengan sendirinya.

`placeholder` adalah **teks petunjuk** di dalam input yang muncul saat kolom kosong, dan hilang saat pengguna mulai mengetik.

## Penjelasan Detail

`placeholder` memberikan **contoh atau petunjuk** tentang apa yang harus diisi dalam input.

### Format
```html
<input type="text" placeholder="Masukkan nama lengkap">
<textarea placeholder="Tulis komentar Anda..."></textarea>
```

### Placeholder vs Label
| Placeholder | Label |
|-------------|-------|
| Di dalam input | Di luar input |
| Hilang saat mengetik | Tetap terlihat |
| Hanya petunjuk | Identitas field |
| **Jangan jadi satu-satunya petunjuk** | **WAJIB Ada** |

### Peringatan: Jangan Gantikan Label
```html
<!-- SALAH: placeholder menggantikan label -->
<input type="text" placeholder="Nama">

<!-- BENAR: label + placeholder -->
<label for="nama">Nama:</label>
<input type="text" id="nama" placeholder="Contoh: Budi Santoso">
```

### Styling Placeholder (CSS)
```css
::placeholder {
  color: #999;
  font-style: italic;
  font-size: 0.9em;
}
```

### Atribut Terkait
```html
<input type="text" placeholder="Cari buku..."
       autofocus>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Placeholder</title>
    <style>
      input, textarea {
        width: 300px;
        padding: 10px;
        border: 1px solid #ccc;
        border-radius: 5px;
        font-size: 16px;
      }
      /* Styling placeholder */
      ::placeholder {
        color: #aaa;
        font-style: italic;
      }
    </style>
  </head>
  <body>
    <h1>Formulir Pencarian Buku</h1>

    <form>
      <p>
        <label for="cari">Cari Buku:</label><br>
        <input type="text" id="cari" name="q"
               placeholder="Judul buku, penulis, atau ISBN...">
      </p>

      <p>
        <label for="email">Email:</label><br>
        <input type="email" id="email" name="email"
               placeholder="nama@email.com">
      </p>

      <p>
        <label for="pesan">Pesan:</label><br>
        <textarea id="pesan" name="pesan"
                  rows="4" cols="40"
                  placeholder="Tulis pesan Anda di sini..."></textarea>
      </p>

      <p>
        <button type="submit">Cari</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `placeholder` = **teks petunjuk** di dalam input
- Hilang saat pengguna mulai mengetik
- **Jangan gantikan label** — label harus tetap ada
- Bisa di-styling dengan CSS `::placeholder`
- Untuk textarea, select, dan input types tertentu
