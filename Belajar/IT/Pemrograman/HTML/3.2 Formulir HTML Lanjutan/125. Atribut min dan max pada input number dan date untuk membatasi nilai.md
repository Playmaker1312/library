# Atribut min dan max pada Input Number dan Date untuk Membatasi Nilai

## Analogi: Perpustakaan Digital

Bayangkan **kolom jumlah buku** — kamu tidak boleh pinjam 0 buku (min 1) dan tidak boleh pinjam lebih dari 5 (max 5). Atau **kolom tanggal** — hanya bisa memilih tanggal dalam 30 hari ke depan.

`min` dan `max` adalah **batas bawah dan atas** untuk input yang punya rentang nilai — seperti number, date, time, range.

## Penjelasan Detail

`min` dan `max` menentukan **rentang nilai** yang valid untuk input.

### Input yang Mendukung
| Type | Contoh `min`/`max` |
|------|-------------------|
| `number` | `min="0" max="100"` |
| `date` | `min="2024-01-01" max="2024-12-31"` |
| `time` | `min="08:00" max="17:00"` |
| `range` | `min="0" max="100"` |
| `datetime-local` | `min="2024-06-01T08:00"` |
| `week`, `month` | `min="2024-W01"` |

### Cara Kerja
- Browser mencegah input di bawah `min` atau di atas `max`
- Di `number`: spinner tidak bisa turun di bawah min/naik di atas max
- Di `date`: tanggal di luar rentang tidak bisa dipilih (atau abu-abu)
- Validasi juga saat submit — pesan error jika di luar rentang

### Contoh
```html
<!-- Jumlah: 1-5 -->
<input type="number" min="1" max="5" value="1">

<!-- Tanggal: 1-30 Juni 2024 -->
<input type="date" min="2024-06-01" max="2024-06-30">

<!-- Waktu: jam kerja -->
<input type="time" min="08:00" max="17:00">
```

### step
Biasanya dipakai bersama untuk menentukan kelipatan:
```html
<input type="number" min="0" max="100" step="5">
<!-- Nilai: 0, 5, 10, 15, ... 100 -->
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Min Max</title>
  </head>
  <body>
    <h1>Formulir Peminjaman Buku</h1>

    <form action="pinjam.php" method="POST">
      <p>
        <label for="jumlah">Jumlah Buku Dipinjam (1-5):</label><br>
        <input type="number" id="jumlah" name="jumlah"
               min="1" max="5" value="1">
      </p>

      <p>
        <label for="tgl_pinjam">Tanggal Pinjam (Juni 2024):</label><br>
        <input type="date" id="tgl_pinjam" name="tgl_pinjam"
               min="2024-06-01" max="2024-06-30" value="2024-06-15">
      </p>

      <p>
        <label for="tgl_kembali">Tanggal Kembali (1-14 hari setelah pinjam):</label><br>
        <input type="date" id="tgl_kembali" name="tgl_kembali"
               min="2024-06-15" max="2024-06-29">
      </p>

      <p>
        <label for="durasi">Durasi (hari, kelipatan 7):</label><br>
        <input type="number" id="durasi" name="durasi"
               min="7" max="30" step="7" value="14">
      </p>

      <p>
        <label for="rating">Rating Buku (0-10):</label><br>
        <input type="range" id="rating" name="rating"
               min="0" max="10" value="7">
        <output id="rating-value">7</output>
      </p>

      <p>
        <button type="submit">Pinjam</button>
      </p>
    </form>

    <script>
      document.getElementById('rating').oninput = function() {
        document.getElementById('rating-value').textContent = this.value;
      };
    </script>
  </body>
</html>
```

## Poin Penting
- `min` = **nilai minimum** yang valid
- `max` = **nilai maksimum** yang valid
- Untuk: number, date, time, range, datetime-local
- Browser mencegah input di luar rentang
- Kombinasikan dengan `step` untuk kelipatan nilai
