# Atribut pattern untuk Validasi Masukan Menggunakan Ekspresi Reguler

## Analogi: Perpustakaan Digital

Bayangkan **kolom kode anggota** yang harus mengikuti format "AG-XXXX" (AG + strip + 4 angka). Atau kolom nomor telepon yang harus 10-15 digit. Kamu bisa membuat **pola khusus** yang harus diikuti.

`pattern` adalah **pola (template)** yang harus cocok dengan input pengguna. Polanya ditulis dalam **Regular Expression (Regex)**.

## Penjelasan Detail

`pattern` menentukan **pola regex** yang harus dipenuhi input sebelum form bisa dikirim.

### Format
```html
<input type="text" pattern="[A-Za-z ]+" title="Hanya huruf dan spasi">
```

### Atribut `title`
Sangat penting untuk memberi **pesan error yang jelas** — karena pesan default browser hanya "Please match the requested format".

### Contoh Pattern Umum
| Kegunaan | Pattern | Contoh Valid |
|----------|---------|--------------|
| Hanya huruf | `[A-Za-z]+` | Budi |
| Hanya angka | `[0-9]+` | 12345 |
| Kode AG + 4 digit | `AG-\d{4}` | AG-2024 |
| Email sederhana | `[^@]+@[^@]+\.[^@]+` | nama@email.com |
| Username (huruf+angka, 3-15) | `[A-Za-z0-9]{3,15}` | budi123 |
| No telepon (10-15 digit) | `\d{10,15}` | 08123456789 |
| Password kuat | `(?=.*\d)(?=.*[a-z])(?=.*[A-Z]).{8,}` | Budi1234 |

### Cara Membaca Regex
```text
[0-9]{4}   → 4 digit angka
[A-Za-z]+  → 1 atau lebih huruf (kecil/besar)
\d{3}      → 3 digit angka
.          → karakter apa pun
*          → 0 atau lebih
+          → 1 atau lebih
{3,8}      → 3 sampai 8 karakter
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Pattern Validation</title>
  </head>
  <body>
    <h1>Formulir dengan Validasi Pattern</h1>

    <form action="simpan.php" method="POST">
      <p>
        <label for="kode">Kode Anggota (AG-XXXX):</label><br>
        <input type="text" id="kode" name="kode"
               pattern="AG-\d{4}"
               placeholder="AG-2024"
               title="Format: AG- diikuti 4 angka (contoh: AG-2024)" required>
      </p>

      <p>
        <label for="telp">Nomor Telepon (10-15 digit):</label><br>
        <input type="tel" id="telp" name="telp"
               pattern="\d{10,15}"
               placeholder="08123456789"
               title="Masukkan 10-15 digit angka" required>
      </p>

      <p>
        <label for="username">Username (huruf dan angka, 3-15):</label><br>
        <input type="text" id="username" name="username"
               pattern="[A-Za-z0-9]{3,15}"
               placeholder="budi123"
               title="3-15 karakter, hanya huruf dan angka" required>
      </p>

      <p>
        <button type="submit">Simpan</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `pattern` = validasi input dengan **regex**
- `title` = pesan error **jelas** (wajib!)
- Bekerja bersama `required`
- Regex dasar: `\d` (angka), `[A-Z]` (huruf besar), `+` (1 atau lebih)
- Format password kuat: minimal 8 karakter, kombinasi huruf besar+kecil+angka
