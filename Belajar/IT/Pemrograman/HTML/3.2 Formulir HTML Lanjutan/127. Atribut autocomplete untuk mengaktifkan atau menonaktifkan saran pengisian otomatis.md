# Atribut autocomplete untuk Mengaktifkan atau Menonaktifkan Saran Pengisian Otomatis

## Analogi: Perpustakaan Digital

Bayangkan browser mengingat alamat email yang sering kamu ketik di formulir. Saat kamu mulai mengetik, browser menawarkan saran: "Apakah kamu ingin mengisi 'budi@email.com'?"

`autocomplete` mengontrol apakah browser boleh **menyimpan dan menyarankan** nilai input. Bisa diaktifkan (`on`) atau dinonaktifkan (`off`).

## Penjelasan Detail

`autocomplete` memberi petunjuk pada browser tentang **perilaku autofill**.

### Nilai
| Nilai | Fungsi |
|-------|--------|
| `on` | Aktifkan autocomplete (browser boleh simpan dan saran) |
| `off` | Nonaktifkan autocomplete |
| `name` | Nama lengkap |
| `email` | Alamat email |
| `username` | Username |
| `current-password` | Password saat ini |
| `new-password` | Password baru |
| `tel` | Nomor telepon |
| `address-line1` | Baris alamat |
| `country` | Negara |
| `postal-code` | Kode pos |

### Nilai Spesifik (Token)
HTML5 mendefinisikan **token autocomplete** spesifik yang membantu browser mengisi field dengan tepat:
```html
<input type="text" name="nama" autocomplete="name">
<input type="email" name="email" autocomplete="email">
<input type="password" name="pass" autocomplete="current-password">
```

### autocomplete di Form vs Input
```html
<!-- Nonaktifkan untuk seluruh form -->
<form autocomplete="off">

<!-- Atau per input -->
<input type="text" autocomplete="off">
```

### Kapan `off`?
- Data sensitif (nomor KTP, PIN)
- Kode OTP/verifikasi
- Data yang selalu berubah
- Formulir internal/admin

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Autocomplete</title>
  </head>
  <body>
    <h1>Formulir Login dan Pendaftaran</h1>

    <h2>Login (autocomplete ON)</h2>
    <form action="login.php" method="POST">
      <p>
        <label for="user">Username:</label><br>
        <input type="text" id="user" name="user"
               autocomplete="username">
      </p>
      <p>
        <label for="pass">Password:</label><br>
        <input type="password" id="pass" name="pass"
               autocomplete="current-password">
      </p>
      <p>
        <button type="submit">Login</button>
      </p>
    </form>

    <h2>Pendaftaran Baru</h2>
    <form action="daftar.php" method="POST" autocomplete="off">
      <p>
        <label for="nama_lengkap">Nama Lengkap:</label><br>
        <input type="text" id="nama_lengkap" name="nama_lengkap">
      </p>
      <p>
        <label for="nik">NIK (KTP):</label><br>
        <input type="text" id="nik" name="nik"
               autocomplete="off">
        <small>Autocomplete nonaktif untuk data sensitif.</small>
      </p>
      <p>
        <label for="email">Email:</label><br>
        <input type="email" id="email" name="email"
               autocomplete="email">
      </p>
      <p>
        <label for="pass_baru">Password Baru:</label><br>
        <input type="password" id="pass_baru" name="pass_baru"
               autocomplete="new-password">
      </p>
      <p>
        <button type="submit">Daftar</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `autocomplete` = kontrol **saran pengisian otomatis**
- `on` = aktif, `off` = nonaktif
- Token spesifik membantu browser isi dengan benar (`email`, `tel`, `name`, dll)
- Nonaktifkan untuk **data sensitif** (KTP, PIN, OTP)
- `autocomplete="new-password"` untuk field password baru
