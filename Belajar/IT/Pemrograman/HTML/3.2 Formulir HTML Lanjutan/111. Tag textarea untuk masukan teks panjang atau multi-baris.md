# Tag textarea untuk Masukan Teks Panjang atau Multi-baris

## Analogi: Perpustakaan Digital

Bayangkan **kotak saran** di perpustakaan — tempat pengunjung menulis pesan panjang, lebih dari satu baris. Ini berbeda dengan kolom nama yang hanya satu baris.

`<textarea>` adalah **kotak teks multi-baris** — pengguna bisa mengetik paragraf, bahkan halaman penuh teks.

## Penjelasan Detail

`<textarea>` membuat area teks yang bisa menampung **beberapa baris teks**. Berbeda dengan `<input type="text">` yang hanya satu baris.

### Atribut
| Atribut | Fungsi |
|---------|--------|
| `rows` | Tinggi (jumlah baris) |
| `cols` | Lebar (jumlah karakter per baris) |
| `placeholder` | Teks petunjuk |
| `maxlength` | Maksimal karakter |
| `minlength` | Minimal karakter |
| `readonly` | Hanya baca |
| `disabled` | Nonaktif |
| `wrap` | Pembungkusan teks (`soft`/`hard`/`off`) |
| `required` | Wajib diisi |

### Perbedaan `<textarea>` vs `<input type="text">`
| `<textarea>` | `<input type="text">` |
|-------------|----------------------|
| Multi-baris | Satu baris |
| Punya `rows` dan `cols` | Punya `size` |
| Bisa di-resize (drag) | Tidak bisa di-resize |
| Tag berpasangan | Self-closing |
| Nilai default di antara tag | Nilai default di `value` |

### Nilai Default (Beda dengan Input)
```html
<!-- input -->
<input type="text" value="Nilai default">

<!-- textarea — nilai di antara tag, bukan di value -->
<textarea>Nilai default</textarea>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Textarea</title>
  </head>
  <body>
    <h1>Formulir Saran Perpustakaan</h1>

    <form action="kirim.php" method="POST">
      <p>
        <label for="saran">Saran Anda:</label><br>
        <textarea id="saran" name="saran"
                  rows="6" cols="50"
                  placeholder="Tulis saran Anda di sini..."
                  maxlength="1000" required></textarea>
        <small>Maksimal 1000 karakter.</small>
      </p>

      <p>
        <label for="bio">Biografi Singkat:</label><br>
        <textarea id="bio" name="bio"
                  rows="4" cols="40"
                  placeholder="Ceritakan tentang diri Anda...">Anggota sejak 2024.</textarea>
      </p>

      <p>
        <button type="submit">Kirim Saran</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `<textarea>` = input **multi-baris** untuk teks panjang
- `rows` = tinggi (baris), `cols` = lebar (karakter)
- Nilai default ditulis **di antara tag**, bukan di `value`
- Bisa di-resize oleh pengguna (CSS `resize: none` untuk nonaktifkan)
- Untuk teks pendek satu baris, pakai `<input type="text">`
