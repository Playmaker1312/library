# Pengenalan Validasi Formulir HTML5 Secara Bawaan Tanpa JavaScript

## Analogi: Perpustakaan Digital

Bayangkan **pustakawan otomatis** yang memeriksa formulir pendaftaran sebelum diterima. Tanpa perlu kode khusus, pustakawan ini:
- Memastikan nama tidak kosong (`required`)
- Memastikan format email benar (`type="email"`)
- Memastikan password minimal 8 karakter (`minlength`)
- Memeriksa nomor telepon sesuai pola (`pattern`)

**Validasi HTML5** adalah **pustakawan otomatis** itu — validasi bawaan browser tanpa perlu JavaScript. Cukup dengan atribut HTML, browser sudah bisa memeriksa input pengguna.

## Penjelasan Detail

HTML5 menyediakan **validasi bawaan** (built-in validation) yang bekerja otomatis saat submit.

### Atribut Validasi
| Atribut | Fungsi | Contoh |
|---------|--------|--------|
| `required` | Wajib diisi | `required` |
| `type` | Validasi jenis data | `type="email"`, `type="url"` |
| `minlength` | Panjang minimal | `minlength="8"` |
| `maxlength` | Panjang maksimal | `maxlength="100"` |
| `min` | Nilai minimal | `min="1"` |
| `max` | Nilai maksimal | `max="5"` |
| `step` | Kelipatan nilai | `step="5"` |
| `pattern` | Pola regex | `pattern="[A-Z]+"` |

### Cara Kerja
1. Pengguna klik submit
2. Browser periksa semua input dengan atribut validasi
3. Jika ada yang tidak valid → fokus ke input error + pesan
4. Form **TIDAK dikirim** sampai semua valid

### Pesan Error Default
Browser menampilkan pesan error berbeda tergantung jenis validasi:
- `required`: "Please fill out this field"
- `type="email"`: "Please enter an email address"
- `minlength`: "Please lengthen this text to 8 characters"
- `pattern`: "Please match the requested format"

### Pesan Error Kustom (setCustomValidity)
```html
<input type="text" required
       oninvalid="this.setCustomValidity('Harap isi nama Anda')"
       oninput="this.setCustomValidity('')">
```

### Nonaktifkan Validasi
```html
<form novalidate>
  <!-- Semua validasi HTML5 dinonaktifkan -->
</form>

<!-- Atau per tombol submit -->
<button type="submit" formnovalidate>Kirim (tanpa validasi)</button>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>HTML5 Validation</title>
    <style>
      input:valid { border-color: green; }
      input:invalid { border-color: red; }
    </style>
  </head>
  <body>
    <h1>Formulir dengan Validasi HTML5</h1>

    <form action="daftar.php" method="POST">
      <p>
        <label for="nama">Nama (required):</label><br>
        <input type="text" id="nama" name="nama" required>
      </p>

      <p>
        <label for="email">Email (type=email):</label><br>
        <input type="email" id="email" name="email" required>
      </p>

      <p>
        <label for="pass">Password (min 8 karakter):</label><br>
        <input type="password" id="pass" name="pass" minlength="8" required>
      </p>

      <p>
        <label for="kode">Kode (AG-XXXX):</label><br>
        <input type="text" id="kode" name="kode"
               pattern="AG-\d{4}"
               title="Format: AG- diikuti 4 angka"
               required>
      </p>

      <p>
        <label for="usia">Usia (18-100):</label><br>
        <input type="number" id="usia" name="usia"
               min="18" max="100" required>
      </p>

      <p>
        <button type="submit">Kirim (dengan validasi)</button>
        <button type="submit" formnovalidate>Kirim (tanpa validasi)</button>
      </p>
    </form>

    <hr>

    <h2>Form Tanpa Validasi</h2>
    <form action="simpan.php" novalidate>
      <p>
        <label for="bebas">Input ini tidak divalidasi:</label><br>
        <input type="email" id="bebas" name="bebas" required>
        <small>Atribut novalidate di form → validasi dimatikan.</small>
      </p>
      <button type="submit">Kirim</button>
    </form>
  </body>
</html>
```

## Poin Penting
- HTML5 validasi = **bawaan browser** (tanpa JavaScript)
- Atribut: `required`, `type`, `min`, `max`, `minlength`, `pattern`, `step`
- Browser menampilkan **pesan error otomatis**
- `setCustomValidity()` untuk pesan kustom (butuh sedikit JS)
- `novalidate` / `formnovalidate` untuk nonaktifkan validasi
