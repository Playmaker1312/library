# Tag select untuk Membuat Dropdown atau Daftar Pilihan

## Analogi: Perpustakaan Digital

Bayangkan **daftar pilihan** jenis buku yang bisa dibuka — seperti tirai yang turun menampilkan opsi. Kamu klik, pilih salah satu.

`<select>` adalah **dropdown** (menu tarik-turun) — daftar pilihan yang hanya menampilkan satu opsi saat tertutup, dan menampilkan semua opsi saat diklik.

## Penjelasan Detail

`<select>` membuat **dropdown list**. Setiap opsi di dalamnya menggunakan tag `<option>`.

### Struktur Dasar
```html
<select name="kategori">
  <option value="fiksi">Fiksi</option>
  <option value="nonfiksi">Non Fiksi</option>
  <option value="sains">Sains</option>
</select>
```

### Atribut `<select>`
| Atribut | Fungsi |
|---------|--------|
| `name` | Nama field (wajib untuk dikirim) |
| `multiple` | Bisa pilih lebih dari satu |
| `size` | Jumlah opsi yang terlihat (tanpa dropdown) |
| `required` | Wajib memilih |
| `disabled` | Nonaktifkan dropdown |

### `multiple` — Pilih Banyak
```html
<select name="kategori[]" multiple size="4">
```
Dengan `multiple`, dropdown berubah jadi **list box** (beberapa opsi terlihat, bisa Ctrl+klik untuk pilih banyak).

### `size` — Tampilkan Beberapa Opsi
```html
<select name="kategori" size="5">
```
Tanpa dropdown, menampilkan 5 opsi sekaligus.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Select Dropdown</title>
  </head>
  <body>
    <h1>Filter Pencarian Buku</h1>

    <form action="cari.php" method="GET">
      <p>
        <label for="kategori">Kategori Buku:</label><br>
        <select id="kategori" name="kategori" required>
          <option value="">— Pilih Kategori —</option>
          <option value="fiksi">Fiksi</option>
          <option value="nonfiksi">Non Fiksi</option>
          <option value="sains">Sains</option>
          <option value="sejarah">Sejarah</option>
          <option value="teknologi">Teknologi</option>
        </select>
      </p>

      <p>
        <label for="genre">Genre (bisa pilih banyak):</label><br>
        <select id="genre" name="genre[]" multiple size="4">
          <option value="novel">Novel</option>
          <option value="cerpen">Cerpen</option>
          <option value="komik">Komik</option>
          <option value="puisi">Puisi</option>
          <option value="biografi">Biografi</option>
        </select>
        <small>Ctrl+klik untuk pilih lebih dari satu.</small>
      </p>

      <p>
        <button type="submit">Cari</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `<select>` = **dropdown** daftar pilihan
- `<option>` = setiap opsi dalam dropdown
- `multiple` = bisa pilih banyak (jadi list box)
- `size` = jumlah opsi yang terlihat
- `required` = wajib pilih
- Nilai yang dikirim adalah atribut `value` dari `<option>`
