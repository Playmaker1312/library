# Tag legend untuk Memberi Judul pada Kelompok Elemen Fieldset

## Analogi: Perpustakaan Digital

Bayangkan **label bagian** di formulir: "Data Pribadi", "Alamat", "Pembayaran". Label ini diletakkan di **tepi atas** kotak pembatas — memberi tahu pengisi form: "Sekarang kamu sedang mengisi bagian ini."

`<legend>` adalah **label judul** yang muncul di tepi atas `<fieldset>`. Ini adalah satu-satunya elemen yang secara visual "menembus" border fieldset.

## Penjelasan Detail

`<legend>` digunakan sebagai **judul atau keterangan** untuk `<fieldset>`. Harus menjadi **anak pertama** dari `<fieldset>`.

### Posisi
```html
<fieldset>
  <legend>Judul Grup</legend>  <!-- ← anak pertama -->
  <!-- elemen form lainnya -->
</fieldset>
```

### Styling
Secara default, `<legend>` muncul di pojok kiri atas border fieldset. Bisa di-styling:
```css
legend {
  background: #3498db;
  color: white;
  padding: 5px 15px;
  border-radius: 5px;
  font-weight: bold;
}
```

### Aksesibilitas
Screen reader membaca `<legend>` saat memasuki `<fieldset>`, memberi konteks tentang grup data yang akan diisi.

### Aturan
- Hanya boleh ada **satu** `<legend>` per `<fieldset>`
- Harus menjadi **anak pertama** `<fieldset>`
- Tidak boleh ada di luar `<fieldset>`

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Legend Tag</title>
    <style>
      fieldset {
        border: 2px solid #2c3e50;
        border-radius: 8px;
        padding: 20px;
        margin: 20px 0;
      }
      legend {
        background: #2c3e50;
        color: white;
        padding: 8px 20px;
        border-radius: 20px;
        font-weight: bold;
        font-size: 1.1em;
      }
    </style>
  </head>
  <body>
    <h1>Survey Perpustakaan</h1>

    <form>
      <fieldset>
        <legend>Data Responden</legend>
        <p>
          <label for="nama">Nama:</label>
          <input type="text" id="nama" name="nama">
        </p>
        <p>
          <label for="usia">Usia:</label>
          <input type="number" id="usia" name="usia">
        </p>
      </fieldset>

      <fieldset>
        <legend>Kebiasaan Membaca</legend>
        <p>
          <label>Seberapa sering membaca?</label><br>
          <label><input type="radio" name="frekuensi" value="sering"> Sering</label>
          <label><input type="radio" name="frekuensi" value="kadang"> Kadang</label>
          <label><input type="radio" name="frekuensi" value="jarang"> Jarang</label>
        </p>
      </fieldset>

      <fieldset>
        <legend>Kritik dan Saran</legend>
        <p>
          <label for="saran">Saran untuk perpustakaan:</label><br>
          <textarea id="saran" name="saran" rows="4" cols="50"></textarea>
        </p>
      </fieldset>

      <p>
        <button type="submit">Kirim Survey</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `<legend>` = **judul grup** fieldset
- Harus menjadi **anak pertama** `<fieldset>`
- Tampil di tepi atas border fieldset
- Penting untuk **aksesibilitas**
- Bisa di-styling dengan CSS
