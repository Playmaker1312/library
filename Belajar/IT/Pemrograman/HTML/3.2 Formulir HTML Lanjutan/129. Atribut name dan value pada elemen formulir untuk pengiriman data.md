# Atribut name dan value pada Elemen Formulir untuk Pengiriman Data

## Analogi: Perpustakaan Digital

Bayangkan **kartu pendaftaran** yang dikirim ke pustakawan. Kartu itu punya:
- **Nama field** (`name`) = label pada amplop: "Nama", "Email", "Alamat"
- **Isi field** (`value`) = isi amplop: "Budi Santoso", "budi@email.com"

Saat form dikirim, server menerima **pasangan name=value**: `nama=Budi+Santoso&email=budi@email.com`

## Penjelasan Detail

`name` dan `value` adalah atribut fundamental yang menentukan **data apa yang dikirim** ke server.

### name — Identitas Field
```html
<input type="text" name="nama_lengkap">
```
Server menerima data dengan kunci `nama_lengkap`.

### value — Nilai yang Dikirim
```html
<input type="hidden" name="id_buku" value="42">
<input type="text" name="judul" value="Laskar Pelangi">
```

Untuk input teks, `value` adalah nilai default (bisa diubah pengguna).
Untuk hidden, checkbox, radio — `value` tetap.

### Bagaimana Data Dikirim
Dengan method GET:
```
http://server.com/proses.php?nama=Budi+Santoso&email=budi@email.com&id_buku=42
```

Dengan method POST:
```
Body: nama=Budi+Santoso&email=budi@email.com&id_buku=42
```

### Aturan `name`
- Wajib untuk hampir semua elemen form (kecuali submit button tanpa data)
- Jika tidak ada `name`, data tidak dikirim ke server
- Gunakan nama yang deskriptif dan konsisten
- Untuk array di PHP: `name="hobi[]"`

### Aturan `value`
- Untuk `text`, `textarea` — bisa diubah pengguna
- Untuk `hidden`, `checkbox`, `radio` — tetap
- Untuk `submit` — teks tombol + nilai yang dikirim
- Untuk `option` — nilai yang dikirim jika opsi dipilih

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Name dan Value</title>
  </head>
  <body>
    <h1>Formulir dengan Name dan Value</h1>

    <form action="daftar.php" method="POST">
      <!-- name="nama" → server terima: nama = "isi input" -->
      <p>
        <label for="nama">Nama Lengkap:</label><br>
        <input type="text" id="nama" name="nama"
               value="Budi Santoso">
      </p>

      <!-- name="email" → server terima: email = "..." -->
      <p>
        <label for="email">Email:</label><br>
        <input type="email" id="email" name="email"
               placeholder="nama@email.com">
      </p>

      <!-- value tetap → server terima: jenis = "premium" -->
      <p>
        <input type="radio" name="jenis" value="biasa" id="biasa">
        <label for="biasa">Biasa</label>
        <input type="radio" name="jenis" value="premium" id="premium" checked>
        <label for="premium">Premium</label>
      </p>

      <!-- name[] untuk array -->
      <p>
        <label>Genre favorit:</label><br>
        <label><input type="checkbox" name="genre[]" value="fiksi"> Fiksi</label>
        <label><input type="checkbox" name="genre[]" value="sains"> Sains</label>
      </p>

      <!-- hidden — name + value tetap -->
      <input type="hidden" name="id_pendaftaran" value="12345">

      <!-- submit — value jadi teks tombol + dikirim -->
      <p>
        <button type="submit" name="aksi" value="daftar">Daftar</button>
      </p>
    </form>

    <p><small>Data dikirim sebagai pasangan <code>name=value</code>.</small></p>
  </body>
</html>
```

## Poin Penting
- `name` = **kunci/identitas** field (wajib untuk kirim data)
- `value` = **nilai** yang dikirim ke server
- Tanpa `name` → data **tidak dikirim**
- Untuk checkbox, gunakan `name[]` agar server terima sebagai array
- `value` pada hidden/checkbox/radio bersifat tetap
