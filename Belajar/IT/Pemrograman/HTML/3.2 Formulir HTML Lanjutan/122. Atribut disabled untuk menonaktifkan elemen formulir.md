# Atribut disabled untuk Menonaktifkan Elemen Formulir

## Analogi: Perpustakaan Digital

Bayangkan **kolom "Fitur VIP"** di formulir pendaftaran yang belum bisa diakses karena kamu belum memilih paket Premium. Kolom itu tampil **abu-abu** dan tidak bisa diklik.

`disabled` adalah atribut yang **menonaktifkan** elemen form — tidak bisa diisi, tidak bisa diklik, dan nilainya **tidak dikirim** ke server.

## Penjelasan Detail

`disabled` membuat elemen form menjadi **nonaktif**. Berbeda dengan `readonly`.

### Efek `disabled`
1. Tidak bisa diisi/diklik oleh pengguna
2. Tampil **abu-abu** (default)
3. **Tidak fokus** (tab skip)
4. Nilainya **TIDAK dikirim** ke server

### disabled vs readonly
| Aspek | `disabled` | `readonly` |
|-------|-----------|------------|
| Bisa diisi? | ❌ Tidak | ✅ Bisa fokus, tidak bisa edit |
| Tampilan | Abu-abu | Normal |
| Fokus tab? | ❌ Tidak | ✅ Ya |
| Dikirim ke server? | ❌ Tidak | ✅ Ya |
| Cocok untuk | Input yang belum tersedia | Data yang tidak boleh diedit |

### Atribut `disabled` di Fieldset
```html
<fieldset disabled>
  <!-- Semua input di dalamnya nonaktif -->
  <input type="text" placeholder="Nonaktif">
</fieldset>
```

### Kapan Pakai `disabled`?
- Input yang terkondisi (belum memenuhi syarat)
- Menunggu aksi sebelumnya
- Fitur yang belum tersedia
- Data yang tidak boleh diubah sementara

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Disabled</title>
  </head>
  <body>
    <h1>Pendaftaran Anggota</h1>

    <form action="daftar.php" method="POST">
      <p>
        <label for="nama">Nama:</label><br>
        <input type="text" id="nama" name="nama" value="Budi Santoso" disabled>
        <small>Input disabled — data tidak dikirim.</small>
      </p>

      <p>
        <label for="email">Email:</label><br>
        <input type="email" id="email" name="email" value="budi@email.com" readonly>
        <small>Input readonly — data tetap dikirim.</small>
      </p>

      <p>
        <label for="level">Level Anggota:</label><br>
        <select id="level" name="level" disabled>
          <option>Basic</option>
          <option>Premium</option>
        </select>
        <small>Segera hadir — dropdown nonaktif.</small>
      </p>

      <p>
        <label>
          <input type="checkbox" disabled>
          Fitur ini belum tersedia
        </label>
      </p>

      <p>
        <button type="submit" disabled>Kirim (nonaktif)</button>
        <button type="button">Tombol Aktif</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `disabled` = **nonaktifkan** elemen (tidak bisa interaksi)
- Tampil **abu-abu**
- Nilai **TIDAK dikirim** ke server
- Berbeda dengan `readonly` (tetap bisa dikirim)
- Bisa di fieldset untuk nonaktifkan grup
