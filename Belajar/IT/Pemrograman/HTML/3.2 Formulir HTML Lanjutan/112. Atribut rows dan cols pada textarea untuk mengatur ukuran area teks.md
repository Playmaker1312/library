# Atribut rows dan cols pada textarea untuk Mengatur Ukuran Area Teks

## Analogi: Perpustakaan Digital

Bayangkan **kertas saran** yang digantung di dinding perpustakaan. Ukuran kertasnya bisa diatur:
- **`rows`** = seberapa **tinggi** kertas (berapa baris tulisan)
- **`cols`** = seberapa **lebar** kertas (berapa huruf per baris)

Atribut `rows` dan `cols` pada `<textarea>` mengatur **ukuran dasar** area teks.

## Penjelasan Detail

`rows` dan `cols` mengatur ukuran textarea dalam **karakter/baris** (bukan pixel).

### rows
Jumlah **baris teks** yang terlihat (tinggi).
```html
<textarea rows="5">5 baris tinggi</textarea>
```

### cols
Jumlah **karakter** per baris (lebar).
```html
<textarea cols="40">40 karakter lebar</textarea>
```

### Ukuran Default
- `rows` default: 2
- `cols` default: 20

### Ukuran vs CSS
```html
<!-- Ukuran dalam karakter -->
<textarea rows="6" cols="50"></textarea>

<!-- Ukuran dalam pixel (CSS) — lebih presisi -->
<textarea style="width: 500px; height: 150px;"></textarea>
```

### Resize
Secara default, textarea bisa di-resize (diubah ukurannya) oleh pengguna. Untuk nonaktifkan:
```html
<textarea style="resize: none;"></textarea>
```

Arah resize:
```css
resize: both;      /* vertikal + horizontal (default) */
resize: vertical;  /* hanya vertikal */
resize: horizontal;/* hanya horizontal */
resize: none;      /* tidak bisa diubah */
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Rows Cols Textarea</title>
  </head>
  <body>
    <h1>Ukuran Textarea</h1>

    <form>
      <p>
        <label for="kecil">Textarea kecil (3 baris x 30 karakter):</label><br>
        <textarea id="kecil" name="kecil" rows="3" cols="30"
                  placeholder="Textarea kecil..."></textarea>
      </p>

      <p>
        <label for="besar">Textarea besar (8 baris x 60 karakter):</label><br>
        <textarea id="besar" name="besar" rows="8" cols="60"
                  placeholder="Textarea besar..."></textarea>
      </p>

      <p>
        <label for="css">Pakai CSS (width: 100%, height: 150px):</label><br>
        <textarea id="css" name="css"
                  style="width: 100%; height: 150px;"
                  placeholder="Ukuran diatur CSS"></textarea>
      </p>

      <p>
        <label for="noresize">Tidak bisa di-resize:</label><br>
        <textarea id="noresize" name="noresize"
                  rows="4" cols="40"
                  style="resize: none;"
                  placeholder="Coba drag pojok kanan — tidak bisa"></textarea>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `rows` = **tinggi** (jumlah baris)
- `cols` = **lebar** (jumlah karakter per baris)
- Default: rows=2, cols=20
- Lebih presisi pakai CSS `width`/`height`
- Pengguna bisa resize textarea — nonaktifkan dengan `resize: none`
