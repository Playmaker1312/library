# Tag option untuk Setiap Pilihan dalam Dropdown select

## Analogi: Perpustakaan Digital

Bayangkan **satu buku** dalam daftar pilihan kategori. Setiap buku adalah satu opsi yang bisa dipilih pengunjung.

`<option>` adalah **satu item** dalam dropdown `<select>`. Setiap `<option>` mewakili satu pilihan yang bisa dipilih pengguna.

## Penjelasan Detail

`<option>` digunakan di dalam `<select>`, `<optgroup>`, atau `<datalist>` untuk mendefinisikan **satu opsi**.

### Atribut `<option>`
| Atribut | Fungsi |
|---------|--------|
| `value` | Nilai yang dikirim ke server (jika tidak ditulis, teks dalam tag jadi value) |
| `selected` | Opsi yang terpilih secara default |
| `disabled` | Nonaktifkan opsi (tidak bisa dipilih) |
| `label` | Label singkat (jarang dipakai) |

### Aturan
- `value` = data yang dikirim ke server saat opsi ini dipilih
- Jika `value` tidak ditulis → teks dalam `<option>` jadi value-nya
- Hanya satu opsi bisa `selected` (kecuali `multiple`)

### Contoh
```html
<select name="buku">
  <option value="1">Laskar Pelangi</option>
  <!-- value="1", teks="Laskar Pelangi" -->
  <option value="2">Bumi Manusia</option>
  <option value="3" selected>Pulang</option>
  <!-- "Pulang" terpilih secara default -->
  <option disabled>Habis — Sangkuriang</option>
  <!-- Tidak bisa dipilih -->
</select>
```

### Opsi Placeholder (Tidak Ada Pilihan)
```html
<select name="kategori" required>
  <option value="">— Pilih —</option>
  <!-- value="" → tidak mengirim data, berguna sebagai placeholder -->
  <option value="fiksi">Fiksi</option>
</select>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Option Tag</title>
  </head>
  <body>
    <h1>Pilih Buku Favorit</h1>

    <form action="simpan.php" method="POST">
      <p>
        <label for="buku">Buku Favorit Anda:</label><br>
        <select id="buku" name="buku">
          <option value="">— Pilih Buku —</option>
          <option value="laskar-pelangi" selected>Laskar Pelangi</option>
          <option value="bumi-manusia">Bumi Manusia</option>
          <option value="pulang">Pulang</option>
          <option value="sangkuriang" disabled>Habis — Sangkuriang</option>
          <!-- Tanpa value → teks jadi value -->
          <option>Ronggeng Dukuh Paruk</option>
        </select>
      </p>

      <p>
        <button type="submit">Simpan</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `<option>` = **satu pilihan** dalam dropdown
- `value` = data yang dikirim ke server (jika kosong, teks option jadi value)
- `selected` = pilihan default
- `disabled` = nonaktifkan opsi (tidak bisa dipilih)
- Opsi dengan `value=""` bisa jadi placeholder
