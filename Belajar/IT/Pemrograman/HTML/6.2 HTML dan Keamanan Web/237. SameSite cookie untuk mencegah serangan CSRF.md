# SameSite Cookie untuk Mencegah Serangan CSRF

## Analogi: Perpustakaan Digital

Perpustakaan digital memberikan kartu anggota (cookie) kepada setiap pengunjung. Kartu ini digunakan untuk meminjam buku. Tanpa SameSite, pengunjung yang sedang mengunjungi situs berbahaya secara tidak sengaja bisa menggunakan kartu anggotanya untuk melakukan transaksi di perpustakaan — karena kartu itu dibawa serta ke mana pun browser pergi. SameSite ibarat aturan baru: "Kartu anggota hanya bisa digunakan jika Anda benar-benar berada di dalam perpustakaan (SameSite=Lax) atau hanya untuk permintaan yang berasal dari halaman perpustakaan sendiri (SameSite=Strict)." Dengan aturan ini, situs jahat tidak bisa menyalahgunakan kartu anggota pengguna.

## Penjelasan Detail

SameSite adalah atribut cookie yang mengontrol kapan cookie dikirim dalam request lintas situs. Nilai `Strict` membuat cookie hanya dikirim untuk request yang berasal dari situs yang sama — paling aman tetapi bisa mengganggu pengalaman navigasi (link dari situs lain tidak akan menyertakan cookie). Nilai `Lax` (default modern) mengirim cookie untuk navigasi top-level GET (seperti mengklik link) tetapi tidak untuk request POST atau request dari iframe/gambar/script. Nilai `None` mengirim cookie di semua konteks (harus搭配 `Secure`). Sejak 2020, Chrome dan browser lain mengubah default dari `None` ke `Lax`, yang secara signifikan mengurangi permukaan serangan CSRF tanpa memerlukan perubahan kode. Untuk keamanan maksimal, tambahkan juga CSRF token pada form.

    function setCookie(tipe) {
      var output = document.getElementById('cookie-output');
      var nama = 'test_cookie_' + tipe;
      var value = 'value_' + Date.now();

      if (tipe === 'strict') {
        document.cookie = nama + '=' + value + '; path=/; SameSite=Strict';
        output.innerHTML += '✅ Set cookie ' + nama + ' dengan SameSite=Strict\n';

        document.cookie = nama + '=' + value + '; path=/; SameSite=Lax';

        document.cookie = nama + '=' + value + '; path=/; SameSite=None; Secure';
        output.innerHTML += '⚠️ Set cookie ' + nama + ' dengan SameSite=None; Secure (mungkin ditolak di localhost non-HTTPS)\n';

## Poin Penting
- SameSite=Lax adalah default di browser modern sejak 2020 — pastikan Anda tidak mengeset SameSite=None tanpa alasan jelas.
- Cookie dengan SameSite=None WAJIB memiliki atribut Secure (HTTPS-only) atau akan ditolak browser.
- SameSite mengurangi CSRF tetapi tidak menghilangkannya sepenuhnya — selalu gunakan CSRF token untuk form yang mengubah data.
