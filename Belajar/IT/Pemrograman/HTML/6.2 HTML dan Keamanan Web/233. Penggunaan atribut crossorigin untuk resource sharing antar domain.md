# Penggunaan Atribut crossorigin untuk Resource Sharing Antar Domain

## Analogi: Perpustakaan Digital

Perpustakaan digital bekerja sama dengan perpustakaan lain di kota berbeda untuk saling meminjamkan buku. Namun, ada aturan keamanan: jika Perpustakaan A ingin menggunakan buku dari Perpustakaan B, Perpustakaan B harus memberikan izin eksplisit. Atribut `crossorigin` seperti kartu identitas yang dibawa pengunjung saat meminjam antar perpustakaan. Tanpa kartu (tanpa crossorigin), petugas perpustakaan B hanya bisa memberikan informasi terbatas. Dengan kartu (crossorigin="anonymous"), perpustakaan B memberikan akses penuh, tetapi tidak mengetahui identitas pribadi pengunjung. Dengan kartu anggota lengkap (crossorigin="use-credentials"), perpustakaan B memberikan akses penuh plus data personal.

## Penjelasan Detail

Atribut `crossorigin` pada elemen HTML (`<img>`, `<link>`, `<script>`, `<video>`, `<audio>` dll.) mengontrol bagaimana browser mengirimkan request CORS (Cross-Origin Resource Sharing) ke server domain lain. Nilai `anonymous` mengirim request tanpa kredensial (cookie, sertifikat klien), sedangkan `use-credentials` mengirim dengan kredensial. Atribut ini penting ketika: (1) memuat font dari CDN — tanpanya, beberapa browser tidak akan merender font; (2) memuat script dari domain lain untuk akses error detail via `window.onerror`; (3) memuat gambar untuk digunakan di Canvas via `drawImage()` — tanpa crossorigin, canvas akan menjadi "tainted" dan tidak bisa diekspor. Server juga harus merespons dengan header `Access-Control-Allow-Origin` yang sesuai.

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Crossorigin Attribute</title>
  <!-- Memuat font dengan crossorigin (wajib untuk font) -->
  <link rel="preconnect" href="https://fonts.googleapis.com" crossorigin>
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap" rel="stylesheet" crossorigin="anonymous">

    .crossorigin-table td { padding: 10px; border-bottom: 1px solid #e0e0e0; }
    code { background: #f5f5f5; padding: 2px 6px; border-radius: 3px; font-size: 0.9em; }
    .image-container { display: flex; gap: 20px; flex-wrap: wrap; }
  </style>
</head>
<body>
  <h1>🔗 Atribut crossorigin</h1>

  <div class="card">
    <h2>Nilai Atribut crossorigin</h2>
    <table class="crossorigin-table">
      <tr><th>Nilai</th><th>Kredensial</th><th>Header Server Diperlukan</th><th>Use Case</th></tr>

        <td>Tidak dikirim</td>

      </tr>
    </table>
  </div>

    <h2>Contoh: Font dari Google Fonts</h2>

  </div>

    <div class="image-container">
      <div>

      </div>
      <div>
        <p><strong>Dengan crossorigin:</strong> Canvas bisa diekspor</p>
        <canvas id="canvas-good" width="200" height="150" style="border:1px solid #4caf50;border-radius:4px;"></canvas>
      </div>
    </div>
    <button onclick="cobaCanvas()">Coba Canvas Export</button>
    <p id="canvas-output"></p>
  </div>

  <div class="card">
    <h2>Contoh: Script dengan crossorigin untuk Error Detail</h2>

  </div>

  <script>
    function cobaCanvas() {
      var canvasBad = document.getElementById('canvas-bad');
      var canvasGood = document.getElementById('canvas-good');
      var output = document.getElementById('canvas-output');

      try {
        var dataBad = canvasBad.toDataURL();
        output.innerHTML = '❌ Canvas "tanpa crossorigin" tetap bisa diekspor (karena gambar SVG/fallback)';
      } catch (e) {
        output.innerHTML = '❌ Canvas "tanpa crossorigin": ' + e.message;
      }

      try {
        var dataGood = canvasGood.toDataURL();
        var ctx = canvasGood.getContext('2d');
        ctx.fillStyle = '#4caf50';
        ctx.fillRect(10, 10, 180, 130);
        ctx.fillStyle = 'white';
        ctx.font = '16px Arial';
        ctx.textAlign = 'center';
        ctx.fillText('✅ Canvas Aman', 100, 80);
        output.innerHTML += '<br>✅ Canvas "dengan crossorigin" berhasil diekspor!';
      } catch (e) {
        output.innerHTML += '<br>❌ Canvas gagal: ' + e.message;
      }
    }

    // Log untuk menunjukkan crossorigin pada script
    console.log('✅ Script ini dimuat dari domain sendiri. crossorigin tidak diperlukan untuk script same-origin.');
  </script>

```

## Poin Penting
- Atribut crossorigin WAJIB untuk font web dari CDN — tanpa ini, beberapa browser tidak akan merender font.
- Menggunakan crossorigin pada script dari domain lain memungkinkan `window.onerror` menangkap detail error yang bermakna.
- Server tujuan HARUS mengirimkan header `Access-Control-Allow-Origin` yang sesuai, atau crossorigin tidak akan berfungsi.
