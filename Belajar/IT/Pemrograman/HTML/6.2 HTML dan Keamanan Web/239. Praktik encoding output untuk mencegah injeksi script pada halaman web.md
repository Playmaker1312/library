# Praktik Encoding Output untuk Mencegah Injeksi Script pada Halaman Web

## Analogi: Perpustakaan Digital

Perpustakaan digital menerima buku sumbangan dari pengunjung. Tanpa pemeriksaan, seseorang bisa menyelipkan kertas berisi kode berbahaya di antara halaman buku. Encoding output seperti proses karantina: setiap buku sumbangan diperiksa, dan setiap karakter mencurigakan diubah menjadi setara yang tidak berbahaya. Jika seseorang menulis "<script>" di ulasan buku, encoding mengubahnya menjadi "&lt;script&gt;" — kode tersebut tetap terbaca sebagai teks tetapi tidak akan dijalankan oleh browser. Dengan kata lain, kita memastikan bahwa input pengguna tetap diperlakukan sebagai data, bukan sebagai kode yang dapat dieksekusi.

## Penjelasan Detail

Encoding output (juga disebut escaping) adalah praktik mengonversi karakter berbahaya menjadi entity HTML yang aman sebelum ditampilkan di halaman web. Karakter utama yang perlu di-encode adalah `<` (menjadi `&lt;`), `>` (`&gt;`), `&` (`&amp;`), `"` (`&quot;`), dan `'` (`&#x27;`). Konteks yang berbeda memerlukan encoding yang berbeda: HTML context, HTML attribute context, URL context, CSS context, dan JavaScript context. Di sisi server, template engine modern (React JSX, Vue templates, Handlebars, EJS dengan escaping) sudah melakukan encoding otomatis. Namun, ketika menggunakan `innerHTML` atau `dangerouslySetInnerHTML`, encoding harus dilakukan manual. Prinsip utamanya: jangan pernah percaya input pengguna, selalu encode sebelum ditampilkan.

function encodeHTML(text) {
  const map = {
    '&': '&amp;',
    '<': '&lt;',
    '>': '&gt;',
    '"': '&quot;',
    "'": '&#x27;'
  };
  return text.replace(/[&<>"']/g, function(ch) {
    return map[ch];

    var outputBox = document.getElementById('output-box');
    var tanpaEncodingDiv = document.getElementById('tanpa-encoding');
    var denganEncodingDiv = document.getElementById('dengan-encoding');

    function encodeHTML(text) {
      var map = {
        '&': '&amp;',
        '<': '&lt;',
        '>': '&gt;',
        '"': '&quot;',
        "'": '&#x27;'
      };
      return text.replace(/[&<>"']/g, function (ch) { return map[ch]; });
    }

      var input = document.getElementById('user-input').value;

      // ⚠️ INI TIDAK AMAN — hanya untuk demonstrasi!

      outputBox.innerHTML = '🔴 Tanpa encoding:\n' + input.replace(/</g, '&lt;').replace(/>/g, '&gt;') +

    function tampilkanDenganEncoding() {
      var input = document.getElementById('user-input').value;
      var encoded = encodeHTML(input);

      denganEncodingDiv.innerHTML = '<strong>Komentar:</strong> ' + encoded;

      outputBox.innerHTML = '🟢 Dengan encoding:\n' + encoded +

    }

    // Tampilkan contoh awal
    tampilkanDenganEncoding();
  </script>

## Poin Penting
- Selalu encode output berdasarkan konteks — encoding untuk HTML body berbeda dengan encoding untuk JavaScript string atau URL.
- Gunakan template engine yang melakukan auto-escaping (JSX, Vue, Handlebars) daripada manipulasi innerHTML langsung.
- Encoding output adalah lapisan pertahanan terakhir — tetap lakukan validasi input di sisi server.
