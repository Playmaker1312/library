# Build tools: Vite, Webpack, dan Gulp untuk memproses HTML

## Analogi: Perpustakaan Digital

Build tools seperti mesin produksi buku di perpustakaan. Gulp seperti jalur perakitan manual: petugas mengambil bahan baku (file sumber), memproses satu per satu (minify, kompilasi), dan menghasilkan buku jadi (file produksi). Webpack seperti mesin cetak canggih yang mengelola dependensi secara otomatis: jika satu buku mereferensi buku lain, mesin akan menggabungkannya dengan benar. Vite seperti mesin cetak modern yang sangat cepat: hanya memproses buku yang benar-benar dibutuhkan saat itu juga, bukan seluruh perpustakaan. Semua mesin menghasilkan buku yang siap dibaca oleh pengunjung (browser).

## Penjelasan Detail

Build tools adalah perangkat lunak yang mengotomatiskan transformasi file sumber (HTML, CSS, JavaScript) menjadi file produksi yang optimal untuk browser. Gulp adalah task runner berbasis streaming yang menggunakan kode JavaScript untuk mendefinisikan tugas seperti minifikasi, kompilasi Sass, optimasi gambar, dan live reload. Webpack adalah module bundler yang menganalisis dependensi antar file dan menggabungkannya menjadi bundle optimal, mendukung code splitting dan loader untuk berbagai jenis file. Vite adalah build tool modern yang menggunakan native ES modules saat development untuk kecepatan instan, dan menggunakan Rollup untuk production build yang optimal. Vite mendukung Hot Module Replacement (HMR) yang sangat cepat, konfigurasi minimal, dan dukungan bawaan untuk TypeScript, CSS preprocessing, dan berbagai framework. Webpack lebih cocok untuk proyek kompleks dengan konfigurasi kustom, Vite untuk proyek baru dengan pengalaman developer yang lebih baik.

```javascript
// src/utils.js - contoh modul yang diproses Vite
export function formatDate(date) {
  return new Intl.DateTimeFormat('id-ID', {
    year: 'numeric', month: 'long', day: 'numeric',
    hour: '2-digit', minute: '2-digit'
  }).format(date);
}
```

## Poin Penting
- Gulp: task runner untuk otomatisasi tugas build sederhana (minify, kompilasi, copy).
- Webpack: module bundler powerful dengan konfigurasi fleksibel, cocok untuk proyek kompleks.
- Vite: build tool modern dengan HMR instan dan konfigurasi minimal, ideal untuk proyek baru.
