# HTML dalam konteks AI dan web scraping: bagaimana AI membaca HTML

## Analogi: Perpustakaan Digital

AI membaca HTML seperti asisten peneliti yang membaca ribuan buku di perpustakaan dengan sangat cepat. Asisten ini tidak membaca buku dari depan ke belakang seperti manusia, tetapi langsung mencari informasi spesifik: judul, penulis, ringkasan, dan kata kunci. Asisten memahami struktur perpustakaan: mana judul buku, mana daftar isi, mana indeks. Semakin rapi dan terstruktur buku-buku di perpustakaan, semakin mudah dan akurat asisten menemukan informasi yang dicari. HTML yang semantik dan terstruktur memudahkan AI memahami konten halaman.

## Penjelasan Detail

AI dan web scraping membaca HTML dengan cara yang berbeda dari browser. Mereka mengurai struktur DOM untuk mengekstrak konten, mengabaikan CSS dan JavaScript yang tidak perlu. HTML semantik sangat penting untuk AI: elemen seperti `<article>`, `<header>`, `<nav>`, dan `<table>` memberikan konteks tentang peran setiap bagian konten. Search engine crawler (Googlebot) dan AI training pipeline menggunakan HTML untuk memahami dan mengindeks konten web. Structured data (Schema.org, JSON-LD, Microdata) memberikan petunjuk eksplisit tentang tipe konten: produk, artikel, resep, acara, dll. HTML yang buruk (banyak div, inline styles, konten tersembunyi) mempersulit AI mengekstrak informasi. Teknik seperti "First Contentful Paint" dan Largest Contentful Paint mempengaruhi bagaimana AI menilai kualitas halaman. Semantic HTML, clean markup, dan structured data adalah kunci agar AI dapat membaca dan memahami konten dengan baik.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>HTML untuk AI - Resep Masakan</title>
  <meta name="description" content="Resep nasi goreng spesial dengan bumbu lengkap">

  <!-- Structured Data untuk AI (Schema.org JSON-LD) -->
  <script type="application/ld+json">
    {
      "@context": "https://schema.org",
      "@type": "Recipe",
      "name": "Nasi Goreng Spesial",
      "author": { "@type": "Person", "name": "Chef Budi" },
      "datePublished": "2026-05-23",
      "description": "Resep nasi goreng spesial dengan bumbu lengkap dan topping telur.",
      "prepTime": "PT10M",
      "cookTime": "PT15M",
      "totalTime": "PT25M",
      "recipeYield": "2 porsi",
      "recipeIngredient": [
        "2 piring nasi putih",
        "3 siung bawang merah",
        "2 siung bawang putih",
        "2 butir telur",
        "Kecap manis secukupnya"
      ],
      "recipeInstructions": [
        { "@type": "HowToStep", "text": "Haluskan bawang merah dan bawang putih." },
        { "@type": "HowToStep", "text": "Tumis bumbu hingga harum." },
        { "@type": "HowToStep", "text": "Masukkan nasi dan kecap, aduk rata." }
      ],
      "nutrition": {
        "@type": "NutritionInformation",
        "calories": "350 kalori"
      }
    }
  </script>
</head>
<body>
  <header>
    <h1>Resep Nasi Goreng Spesial</h1>
    <p>Oleh <span itemprop="author">Chef Budi</span> | <time datetime="2026-05-23">23 Mei 2026</time></p>
  </header>

  <main>
    <article>
      <section aria-labelledby="info-heading">
        <h2 id="info-heading">Informasi Resep</h2>
        <ul>
          <li><strong>Porsi:</strong> 2 porsi</li>
          <li><strong>Waktu:</strong> 25 menit</li>
          <li><strong>Kalori:</strong> 350 kkal</li>
        </ul>
      </section>

      <section aria-labelledby="bahan-heading">
        <h2 id="bahan-heading">Bahan-bahan</h2>
        <ul class="bahan">
          <li>2 piring nasi putih</li>
          <li>3 siung bawang merah</li>
          <li>2 siung bawang putih</li>
          <li>2 butir telur</li>
          <li>Kecap manis secukupnya</li>
        </ul>
      </section>

      <section aria-labelledby="cara-heading">
        <h2 id="cara-heading">Cara Membuat</h2>
        <ol class="langkah">
          <li>Haluskan bawang merah dan bawang putih.</li>
          <li>Tumis bumbu hingga harum.</li>
          <li>Masukkan nasi dan kecap, aduk rata.</li>
          <li>Sajikan dengan telur ceplok.</li>
        </ol>
      </section>
    </article>
  </main>

  <footer>
    <p>Seluruh resep dapat di-crawl oleh AI berkat HTML semantik dan structured data.</p>
  </footer>

  <script>
    // Simulasi bagaimana web scraper/AI membaca HTML
    function simulasiScrape() {
      const judul = document.querySelector('h1')?.textContent || 'Tidak ditemukan';
      const bahan = Array.from(document.querySelectorAll('.bahan li')).map(li => li.textContent);
      const langkah = Array.from(document.querySelectorAll('.langkah li')).map(li => li.textContent);

      console.log('=== Hasil Scraping oleh AI ===');
      console.log('Judul:', judul);
      console.log('Bahan:', bahan);
      console.log('Langkah:', langkah);

      // Structured data sudah bisa dibaca oleh mesin
      const ldJson = document.querySelector('script[type="application/ld+json"]');
      if (ldJson) {
        console.log('Structured Data:', JSON.parse(ldJson.textContent));
      }
    }

    simulasiScrape();

    // Contoh output scraping untuk AI
    const dataUntukAI = {
      judul: 'Resep Nasi Goreng Spesial',
      tipe: 'Recipe',
      bahan: ['nasi', 'bawang merah', 'bawang putih', 'telur', 'kecap manis'],
      waktu: '25 menit',
      porsi: '2',
      author: 'Chef Budi'
    };

    console.log('Data siap untuk AI training:', dataUntukAI);
  </script>
</body>
</html>
```

## Poin Penting
- AI dan web scraper mengandalkan HTML semantik dan struktur DOM untuk memahami konten.
- Structured data (Schema.org JSON-LD) memberikan petunjuk eksplisit tentang tipe konten untuk AI.
- HTML yang bersih, terstruktur, dan semantik meningkatkan akurasi ekstraksi data oleh AI.
