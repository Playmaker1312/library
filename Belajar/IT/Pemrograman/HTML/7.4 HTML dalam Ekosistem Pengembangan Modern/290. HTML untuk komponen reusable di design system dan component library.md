# HTML untuk komponen reusable di design system dan component library

## Analogi: Perpustakaan Digital

Design system seperti katalog master perpustakaan yang mendefinisikan standar untuk semua elemen: font judul, ukuran teks, warna sampul, dan tata letak rak. Component library seperti koleksi modul rak buku standar yang bisa digunakan di berbagai bagian perpustakaan. Setiap rak buku (komponen) sudah terstandarisasi: lebar, tinggi, bahan, dan warna yang sama. Arsitek perpustakaan tinggal memilih dan menggabungkan modul-modul ini untuk membangun perpustakaan baru. Konsistensi terjaga karena semua modul mengikuti standar yang sama.

## Penjelasan Detail

Design system adalah kumpulan standar desain, prinsip, dan komponen reusable yang digunakan untuk membangun produk secara konsisten. Component library adalah implementasi teknis dari design system dalam kode. HTML untuk komponen reusable harus memenuhi beberapa kriteria: aksesibel (ARIA attributes), fleksibel (menerima berbagai konten), terisolasi (tidak bergantung pada konteks), dan terdokumentasi dengan baik. Pendekatan pembuatan komponen meliputi: Web Components (Custom Elements + Shadow DOM), framework-specific components (React, Vue), dan CSS-only components. Tools untuk membangun design system: Storybook (dokumentasi komponen), Bit (versioning komponen), dan Fraxis (koordinasi design-code). HTML komponen biasanya menggunakan BEM atau utility classes untuk styling yang konsisten dan mudah diprediksi.

```html
    // Web Component contoh untuk komponen reusable
    class BookCard extends HTMLElement {
      constructor() {
        super();
        this.attachShadow({ mode: 'open' });
      }

      connectedCallback() {
        const judul = this.getAttribute('judul') || 'Tanpa Judul';
        const penulis = this.getAttribute('penulis') || 'Tanpa Penulis';
        const status = this.getAttribute('status') || 'tersedia';

        this.shadowRoot.innerHTML = `
          <style>
            .card { border: 1px solid #ddd; border-radius: 8px; padding: 1rem; font-family: system-ui; }
            .judul { font-size: 1.1rem; margin: 0 0 0.5rem; }
            .penulis { color: #666; margin: 0 0 0.5rem; }
            .badge { display: inline-block; padding: 0.25rem 0.75rem; border-radius: 20px; font-size: 0.8rem; }

            .dipinjam { background: #f8d7da; color: #721c24; }
          </style>

            <h3 class="judul">${judul}</h3>
            <p class="penulis">${penulis}</p>
            <span class="badge ${status}">${status}</span>
          </div>
        `;
      }
    }

    customElements.define('book-card', BookCard);
  </script>

```

## Poin Penting
- Design system mendefinisikan standar desain; component library adalah implementasi teknisnya dalam kode.
- Komponen HTML reusable harus aksesibel, fleksibel, terisolasi, dan terdokumentasi.
- Web Components memungkinkan komponen reusable tanpa framework menggunakan Custom Elements dan Shadow DOM.
