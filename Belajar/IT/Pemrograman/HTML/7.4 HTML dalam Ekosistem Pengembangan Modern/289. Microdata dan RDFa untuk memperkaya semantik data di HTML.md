# Microdata dan RDFa untuk memperkaya semantik data di HTML

## Analogi: Perpustakaan Digital

Microdata dan RDFa seperti stiker label tambahan yang ditempel di sampul buku di perpustakaan. Selain judul dan penulis yang sudah terlihat, stiker ini memberikan informasi terstruktur: genre buku, tingkat kesulitan, target pembaca, dan ISBN dalam format yang bisa dibaca mesin. Petugas perpustakaan bisa dengan cepat mengelompokkan buku berdasarkan label ini. Sistem komputer perpustakaan juga bisa memproses informasi ini secara otomatis tanpa perlu membaca isi buku. Label ini tidak mengubah tampilan buku, hanya memberikan data tambahan yang terstruktur.

## Penjelasan Detail

Microdata dan RDFa adalah spesifikasi untuk menambahkan metadata terstruktur ke dalam HTML agar mesin (search engine, AI, scraper) dapat memahami makna konten dengan lebih baik. Microdata menggunakan atribut `itemscope`, `itemtype`, dan `itemprop` untuk mendefinisikan item dan propertinya. RDFa (Resource Description Framework in Attributes) menggunakan atribut `typeof`, `property`, dan `vocab` untuk tujuan serupa. Keduanya bekerja dengan Schema.org, kumpulan skema terstruktur yang mencakup berbagai tipe: Article, Product, Recipe, Event, Organization, Person, dan banyak lagi. Keuntungan: meningkatkan SEO dengan rich snippets di hasil pencarian, memudahkan AI memahami konten, dan meningkatkan interoperabilitas data. Google, Bing, Yahoo, dan Yandex mendukung format ini untuk featured snippets dan knowledge graph.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Microdata & RDFa - Perpustakaan Digital</title>
</head>
<body>
  <h1>Koleksi Buku dengan Semantic Markup</h1>

  <!-- Microdata Example -->
  <article itemscope itemtype="https://schema.org/Book">
    <h2 itemprop="name">Pemrograman Web Modern</h2>

    <div itemprop="author" itemscope itemtype="https://schema.org/Person">
      <p>Penulis: <span itemprop="name">Ahmad Fauzi</span></p>
    </div>

    <p itemprop="description">Buku komprehensif tentang pengembangan web modern menggunakan HTML5, CSS3, dan JavaScript.</p>

    <p>ISBN: <span itemprop="isbn">978-123-456-789</span></p>
    <p>Tahun: <span itemprop="datePublished">2026</span></p>
    <p>Penerbit: <span itemprop="publisher" itemscope itemtype="https://schema.org/Organization">
      <span itemprop="name">Penerbit Digital</span>
    </span></p>

    <div itemprop="offers" itemscope itemtype="https://schema.org/Offer">
      <p>Harga: <span itemprop="price" content="150000">Rp 150.000</span></p>
      <meta itemprop="priceCurrency" content="IDR">
      <link itemprop="availability" href="https://schema.org/InStock">Tersedia
    </div>

    <p>Rating:
      <span itemprop="aggregateRating" itemscope itemtype="https://schema.org/AggregateRating">
        <span itemprop="ratingValue">4.5</span>/<span itemprop="bestRating">5</span>
        (<span itemprop="ratingCount">42</span> ulasan)
      </span>
    </p>
  </article>

  <hr>

  <!-- RDFa Example -->
  <article typeof="schema:Book" vocab="https://schema.org/">
    <h2 property="schema:name">JavaScript Deep Dive</h2>

    <div rel="schema:author">
      <div typeof="schema:Person">
        <p>Penulis: <span property="schema:name">Siti Rahma</span></p>
      </div>
    </div>

    <p property="schema:description">Eksplorasi mendalam JavaScript modern, dari dasar hingga tingkat mahir.</p>

    <p>ISBN: <span property="schema:isbn">978-123-456-790</span></p>
    <p>Tahun: <span property="schema:datePublished">2025</span></p>

    <div rel="schema:offers">
      <div typeof="schema:Offer">
        <p>Harga: <span property="schema:price" content="120000">Rp 120.000</span></p>
        <meta property="schema:priceCurrency" content="IDR">
        <link property="schema:availability" href="https://schema.org/OutOfStock">Stok Habis
      </div>
    </div>
  </article>

  <hr>

  <!-- Event dengan Microdata -->
  <div itemscope itemtype="https://schema.org/Event">
    <h2 itemprop="name">Bedah Buku: Pemrograman Web</h2>
    <p>Tanggal: <time itemprop="startDate" datetime="2026-06-15T19:00">15 Juni 2026, 19:00</time></p>
    <p>Lokasi: <span itemprop="location" itemscope itemtype="https://schema.org/Place">
      <span itemprop="name">Aula Perpustakaan Digital</span>
    </span></p>
  </div>

  <script>
    // Verifikasi markup terstruktur
    function cekMicrodata() {
      const items = document.querySelectorAll('[itemscope]');
      console.log(`Ditemukan ${items.length} item dengan microdata:`);
      items.forEach(item => {
        const type = item.getAttribute('itemtype');
        const props = item.querySelectorAll('[itemprop]');
        console.log(`- ${type}: ${props.length} properti`);
      });
    }

    function cekRDFa() {
      const items = document.querySelectorAll('[typeof]');
      console.log(`Ditemukan ${items.length} item dengan RDFa:`);
      items.forEach(item => {
        const type = item.getAttribute('typeof');
        const props = item.querySelectorAll('[property]');
        console.log(`- ${type}: ${props.length} properti`);
      });
    }

    cekMicrodata();
    cekRDFa();

    // Google Structured Data Testing Tool
    console.log('Gunakan https://search.google.com/test/rich-results untuk validasi');
  </script>
</body>
</html>
```

## Poin Penting
- Microdata menggunakan `itemscope`, `itemtype`, `itemprop` untuk markup semantik terstruktur.
- RDFa menggunakan `typeof`, `property`, `vocab` untuk tujuan yang sama dengan sintaks berbeda.
- Keduanya bekerja dengan Schema.org dan meningkatkan SEO dengan rich snippets serta membantu AI.
