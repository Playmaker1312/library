# HTML di lingkungan Single Page Application (SPA) dengan React, Vue, Angular

## Analogi: Perpustakaan Digital

SPA seperti perpustakaan digital satu halaman di mana semua rak buku, meja baca, dan area referensi ada dalam satu ruangan besar. Pengunjung tidak perlu pindah ruangan untuk melihat bagian berbeda. Cukup klik tombol, dan rak buku yang ditampilkan berganti tanpa memuat ulang halaman. Framework SPA seperti arsitek yang mengatur bagaimana bagian-bagian perpustakaan ditampilkan dan disembunyikan secara dinamis. HTML di SPA diubah-ubah oleh JavaScript sesuai interaksi pengunjung, bukan dari server. Pengunjung mendapat pengalaman yang mulus tanpa jeda reload halaman.

## Penjelasan Detail

Single Page Application (SPA) adalah arsitektur di mana hampir semua UI di-render di client menggunakan JavaScript, dengan satu file HTML utama yang menjadi wadah. React menggunakan JSX, ekstensi sintaks JavaScript yang mirip HTML, untuk mendefinisikan komponen UI. Vue menggunakan template HTML yang lebih dekat ke HTML standar dengan direktif khusus seperti `v-if`, `v-for`. Angular menggunakan TypeScript dengan template HTML dan sistem binding dua arah. Dalam SPA, HTML awal biasanya minimal (hanya `<div id="root">`) dan seluruh UI dihasilkan oleh JavaScript. Setiap framework memiliki mekanisme routing di sisi client untuk navigasi tanpa reload. SPA cocok untuk aplikasi dengan interaksi kaya seperti dashboard, email client, dan tools produktivitas. Kerugian SPA termasuk SEO yang lebih sulit dan initial load yang lebih berat karena harus mengunduh JavaScript terlebih dahulu.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>SPA - Perpustakaan Digital</title>
</head>
<body>
  <!-- Root element untuk framework -->
  <div id="app">
    <!-- Akan di-render oleh framework -->
  </div>

  <!-- Simulasi React-like SPA tanpa framework -->
  <script>
    // State management sederhana
    const state = {
      halaman: 'beranda',
      bukuList: [
        { id: 1, judul: 'Pemrograman React', penulis: 'Ahmad', status: 'tersedia' },
        { id: 2, judul: 'Vue.js untuk Pemula', penulis: 'Budi', status: 'dipinjam' },
        { id: 3, judul: 'Angular Lanjutan', penulis: 'Citra', status: 'tersedia' }
      ]
    };

    // Komponen: fungsi yang mengembalikan string HTML
    function Header() {
      return `
        <header>
          <h1>Perpustakaan Digital SPA</h1>
          <nav>
            <a href="#" onclick="navigasi('beranda')">Beranda</a>
            <a href="#" onclick="navigasi('katalog')">Katalog</a>
            <a href="#" onclick="navigasi('tentang')">Tentang</a>
          </nav>
        </header>
      `;
    }

    function Beranda() {
      return `
        <main>
          <h2>Selamat Datang</h2>
          <p>Perpustakaan digital dengan ${state.bukuList.length} buku.</p>
          <p>Buku tersedia: ${state.bukuList.filter(b => b.status === 'tersedia').length}</p>
        </main>
      `;
    }

    function Katalog() {
      return `
        <main>
          <h2>Katalog Buku</h2>
          <ul>
            ${state.bukuList.map(buku => `
              <li>
                <strong>${buku.judul}</strong> - ${buku.penulis}
                <span style="color: ${buku.status === 'tersedia' ? 'green' : 'red'}">
                  (${buku.status})
                </span>
              </li>
            `).join('')}
          </ul>
        </main>
      `;
    }

    function Tentang() {
      return `
        <main>
          <h2>Tentang Aplikasi</h2>
          <p>Aplikasi SPA sederhana tanpa framework. Dibangun dengan vanilla JavaScript.</p>
          <p>Navigasi dilakukan tanpa reload halaman.</p>
        </main>
      `;
    }

    function Footer() {
      return `
        <footer>
          <p>&copy; 2026 Perpustakaan Digital SPA</p>
        </footer>
      `;
    }

    // Router sederhana
    function navigasi(halaman) {
      state.halaman = halaman;
      render();
    }

    function render() {
      const app = document.getElementById('app');
      const halamanMap = {
        beranda: Beranda,
        katalog: Katalog,
        tentang: Tentang
      };
      const Konten = halamanMap[state.halaman] || Beranda;

      app.innerHTML = `
        ${Header()}
        ${Konten()}
        ${Footer()}
      `;
    }

    // Render awal
    render();

    // Contoh kode React yang setara (hanya ilustrasi)

          {halaman === 'katalog' && <Katalog />}
          {halaman === 'tentang' && <Tentang />}
          <Footer />
        </div>
      );
    }
    */

    // Contoh kode Vue yang setara (hanya ilustrasi)
    /*

          <Katalog v-if="halaman === 'katalog'" />

          <Footer />
        </div>
      `
    });
    */
  </script>
</body>
</html>
```

## Poin Penting
- SPA menggunakan satu halaman HTML utama, konten diubah oleh JavaScript tanpa reload.
- React menggunakan JSX, Vue menggunakan template HTML, Angular menggunakan TypeScript.
- Kelebihan SPA: navigasi cepat tanpa reload, interaksi kaya, cocok untuk aplikasi kompleks.
