# HTML untuk web scraping, parsing DOM, dan ekstraksi data

## Analogi: Perpustakaan Digital

Web scraping seperti petugas perpustakaan yang menyalin informasi dari ribuan buku ke dalam database digital. Petugas ini membaca setiap buku dengan cepat, mengambil data penting seperti judul, penulis, nomor ISBN, dan tahun terbit, lalu memasukkannya ke dalam spreadsheet. Semakin konsisten format buku (semua judul di halaman yang sama, penulis di tempat yang sama), semakin cepat petugas bekerja. Petugas menggunakan alat seperti gunting (CSS selector) untuk memotong bagian yang relevan dan kaca pembesar (regex) untuk membaca detail kecil.

## Penjelasan Detail

Web scraping adalah teknik mengekstrak data dari halaman web secara otomatis. Alat scraping bekerja dengan mengambil HTML halaman, memparsing DOM tree, dan mengekstrak data menggunakan selector CSS, XPath, atau regular expression. Library populer untuk scraping: Cheerio (Node.js, parsing HTML cepat), Puppeteer/Playwright (browser automation untuk JavaScript-heavy sites), BeautifulSoup (Python), dan Scrapy (Python framework). Saat scraping, penting untuk memperhatikan robots.txt, rate limiting, dan terms of service situs target. HTML yang terstruktur dengan baik memudahkan scraping: gunakan class dan ID yang konsisten, hindari tata letak yang terlalu dinamis. Banyak situs sekarang menggunakan anti-scraping techniques seperti CAPTCHA, IP blocking, dan dynamic content rendering. Developer dapat memfasilitasi scraping dengan menyediakan API publik atau structured data.

    function scrapeKatalog() {
      const bukuList = [];

      document.querySelectorAll('.buku').forEach(el => {
        bukuList.push({
          id: el.dataset.id,
          judul: el.querySelector('.judul').textContent.trim(),
          penulis: el.querySelector('.penulis').textContent.trim(),
          isbn: el.querySelector('.isbn').textContent.trim(),

## Poin Penting
- Web scraping mengekstrak data dari HTML menggunakan CSS selector atau XPath.
- HTML terstruktur dengan class dan ID konsisten memudahkan scraping otomatis.
- Selalu patuhi robots.txt, gunakan rate limiting, dan hormati terms of service situs target.
