# Headless CMS dengan HTML sebagai output konten

## Analogi: Perpustakaan Digital

Headless CMS seperti gudang pusat perpustakaan yang menyimpan semua buku dalam format master digital. Gudang ini hanya bertugas menyimpan dan mengelola buku, tanpa memikirkan bagaimana buku akan ditampilkan. Bagian depan perpustakaan (rak buku, meja baca, lampu) bisa didesain sesuka hati tanpa mempengaruhi gudang. Petugas bisa menggunakan aplikasi khusus untuk mengelola koleksi di gudang, sementara arsitek bebas mendesain tampilan perpustakaan. Konten (buku) terpisah dari presentasi (rak).

## Penjelasan Detail

Headless CMS adalah sistem manajemen konten yang memisahkan backend pengelolaan konten dari frontend presentasi. Konten dikelola melalui dashboard dan disediakan melalui API (REST atau GraphQL) dalam format terstruktur (biasanya JSON). Frontend (bisa berupa Next.js, Astro, atau HTML statis) mengambil konten dari API dan merendernya menjadi HTML. Contoh headless CMS populer: Strapi, Contentful, Sanity, WordPress (dengan REST API). Kelebihan headless CMS: fleksibilitas frontend (bisa menggunakan teknologi apa pun), konten dapat digunakan di multiple platform (web, mobile, IoT), keamanan lebih baik (backend tidak terekspos langsung), dan performa lebih baik (frontend bisa di-host di CDN). Kekurangan: biaya pengembangan lebih tinggi, tidak ada preview visual langsung, dan memerlukan developer untuk mengelola frontend.

```javascript
// Contoh kode Next.js mengambil konten dari Headless CMS
// pages/index.js
export async function getStaticProps() {
  const res = await fetch('https://cms.perpusdigital.com/api/buku');
  const data = await res.json();

  return {
    props: {
      bukuList: data.data
    },
    revalidate: 60
  };
}

export default function Beranda({ bukuList }) {
  return (
    <div>
      <h1>Perpustakaan Digital</h1>
      <div className="grid">
        {bukuList.map(buku => (
          <div key={buku.id} className="card">
            <h2>{buku.attributes.judul}</h2>
            <p>{buku.attributes.penulis}</p>
          </div>
        ))}
      </div>
    </div>
  );
}
```

## Poin Penting
- Headless CMS memisahkan manajemen konten dari presentasi, konten diakses via API.
- Frontend bebas menggunakan teknologi apa pun untuk merender HTML dari konten CMS.
- Cocok untuk multi-platform (web, mobile, IoT) dengan satu sumber konten terpusat.
