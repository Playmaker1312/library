# HTML di lingkungan mobile hybrid: React Native, Flutter Webview, Capacitor

## Analogi: Perpustakaan Digital

Mobile hybrid seperti perpustakaan kelling yang menggunakan mobil untuk menjangkau pembaca di berbagai lokasi. HTML adalah buku-buku yang dibawa di dalam mobil. React Native seperti mobil yang mengubah buku menjadi format digital yang bisa dibaca di aplikasi khusus. Flutter seperti mobil yang mendesain ulang tampilan buku agar sesuai dengan dashboard digital mobil. Capacitor seperti mobil yang menampilkan buku langsung di jendela mobil tanpa mengubah format aslinya. Semua pendekatan memungkinkan buku perpustakaan diakses di perangkat mobile dengan cara yang berbeda.

## Penjelasan Detail

Mobile hybrid memungkinkan aplikasi web (HTML, CSS, JavaScript) berjalan di perangkat mobile dengan akses ke kemampuan native. Capacitor (dari Ionic) adalah yang paling dekat dengan web: aplikasi web dibungkus dalam WebView, dengan akses ke native APIs melalui plugin. React Native menggunakan pendekatan berbeda: komponen React diterjemahkan menjadi UI native, bukan WebView, sehingga HTML tidak digunakan langsung. Flutter juga tidak menggunakan HTML; ia menggunakan Canvas untuk merender UI. Framework lain seperti Ionic menggunakan WebView untuk menampilkan aplikasi web dengan tampilan seperti native. Kelebihan pendekatan hybrid: kode dapat digunakan kembali di web dan mobile, update lebih mudah (tanpa lewat app store untuk perubahan konten). Kekurangan: performa mungkin tidak setara native, akses ke API native terbatas pada plugin yang tersedia.

## Poin Penting
- Capacitor membungkus aplikasi web dalam WebView dengan akses API native via plugin.
- React Native dan Flutter tidak menggunakan HTML secara langsung, melainkan UI native.
- Pendekatan hybrid cocok untuk migrasi web ke mobile dengan biaya pengembangan lebih rendah.
