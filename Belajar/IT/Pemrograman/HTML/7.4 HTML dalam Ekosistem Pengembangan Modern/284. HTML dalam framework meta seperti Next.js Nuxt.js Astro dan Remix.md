# HTML dalam framework meta seperti Next.js, Nuxt.js, Astro, dan Remix

## Analogi: Perpustakaan Digital

Framework meta seperti arsitek perpustakaan yang merancang seluruh bangunan, bukan hanya menata buku di rak. Mereka memutuskan bagaimana buku disimpan (SSG, SSR), bagaimana pengunjung bergerak antar ruangan (routing), dan bagaimana buku dikirim ke pengunjung (rendering). Next.js seperti arsitek serba bisa yang bisa membangun perpustakaan statis, dinamis, atau campuran. Nuxt.js seperti arsitek yang mengkhususkan diri pada estetika Vue. Astro seperti arsitek minimalis yang hanya menggunakan JavaScript untuk bagian yang benar-benar interaktif. Remix seperti arsitek yang fokus pada pengalaman pengunjung dengan memanfaatkan standar web modern.

## Penjelasan Detail

Framework meta (metaframework) dibangun di atas framework UI seperti React, Vue, atau Svelte, menambahkan kemampuan untuk routing, rendering (SSR, SSG, ISR), data fetching, dan optimasi. Next.js (berbasis React) adalah framework meta paling populer dengan dukungan SSR, SSG, ISR, API routes, dan App Router terbaru. Nuxt.js (berbasis Vue) menawarkan fitur serupa dengan auto-imports, modules, dan konvensi file-based routing. Astro menggunakan pendekatan unik dengan Island Architecture, menghasilkan HTML statis dengan minimal JavaScript. Remix (berbasis React) fokus pada standar web, nested routing, dan progressive enhancement. Framework meta menyederhanakan pengembangan web modern dengan menyediakan solusi terintegrasi untuk routing, rendering, dan optimasi performa. Pemilihan framework tergantung pada framework UI yang digunakan (React/Vue/Svelte) dan kebutuhan proyek.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Framework Meta - Perpustakaan Digital</title>
</head>
<body>
  <h1>Framework Meta untuk HTML</h1>

  <div class="cards">
    <div class="card">
      <h2>Next.js (React)</h2>
      <p>SSR, SSG, ISR, App Router, API Routes</p>
      <pre>
// pages/buku/[id].js
export async function getStaticProps({ params }) {
  const res = await fetch(`/api/buku/${params.id}`);
  const buku = await res.json();
  return { props: { buku }, revalidate: 60 };
}
      </pre>
    </div>

    <div class="card">
      <h2>Nuxt.js (Vue)</h2>
      <p>File-based routing, auto-imports, modules</p>
      <pre>
// pages/buku/_id.vue
&lt;template&gt;
  &lt;article&gt;
    &lt;h1&gt;{{ buku.judul }}&lt;/h1&gt;
  &lt;/article&gt;
&lt;/template&gt;
      </pre>
    </div>

    <div class="card">
      <h2>Astro</h2>
      <p>Zero JS by default, Island Architecture</p>
      <pre>
---
// src/pages/index.astro
const buku = await fetch('...').then(r => r.json());
---
&lt;h1&gt;{buku.judul}&lt;/h1&gt;
&lt;Counter client:load /&gt;
      </pre>
    </div>

    <div class="card">
      <h2>Remix (React)</h2>
      <p>Nested routing, progressive enhancement</p>
      <pre>
// app/routes/buku.$id.tsx
export async function loader({ params }) {
  return fetch(`/api/buku/${params.id}`);
}
      </pre>
    </div>
  </div>

  <section>
    <h2>Contoh: Halaman Buku dengan Next.js</h2>
    <article>
      <h3>Pemrograman Web Modern</h3>
      <p>Penulis: Ahmad Fauzi</p>
      <p>Halaman ini bisa di-render sebagai statis (SSG) dengan revalidasi (ISR) setiap 60 detik.</p>
      <p>Next.js akan menghasilkan HTML saat build, tetapi menyegarkannya secara berkala di background.</p>
    </article>
  </section>

  <section>
    <h2>Contoh: Komponen Interaktif dengan Astro</h2>
    <div id="astro-counter">
      <p>Counter: <span id="count">0</span></p>
      <button onclick="tambah()">+1</button>
    </div>
    <p class="catatan">Di Astro, komponen ini akan menjadi "island" yang dihydrasi secara terpisah.</p>
  </section>

  <footer>
    <p>Framework meta dipilih berdasarkan kebutuhan: performa, developer experience, dan ekosistem.</p>
  </footer>

  <script>
    let count = 0;
    window.tambah = function() {
      count++;
      document.getElementById('count').textContent = count;
    };
  </script>

  <style>
    .cards { display: grid; grid-template-columns: repeat(auto-fill, minmax(280px, 1fr)); gap: 1rem; margin: 1rem 0; }
    .card { border: 1px solid #ddd; border-radius: 8px; padding: 1rem; background: #f9f9f9; }
    pre { background: #eee; padding: 0.5rem; border-radius: 4px; font-size: 0.85em; overflow-x: auto; }
    .catatan { font-size: 0.9em; color: #666; font-style: italic; }
  </style>
</body>
</html>
```

## Poin Penting
- Next.js dan Nuxt.js untuk SSR/SSG penuh dengan ekosistem React/Vue.
- Astro untuk situs statis dengan JavaScript minimal dan Island Architecture.
- Remix untuk aplikasi web yang memanfaatkan standar web dan progressive enhancement.
