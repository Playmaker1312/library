# Pesan Error dan Validasi yang Aksesibel bagi Pengguna Screen Reader

## Analogi: Perpustakaan Digital

Bayangkan Anda mengisi formulir pendaftaran perpustakaan online. Setelah mengirim, Anda mendapat pesan "Error #4432 — isian salah." Tanpa penjelasan lebih lanjut, Anda bingung harus memperbaiki apa. Sekarang bayangkan pesan yang berbunyi "Kolom Nama Lengkap harus diisi — silakan tulis nama Anda." Pesan error yang aksesibel seperti petugas perpustakaan yang dengan sabar menunjuk tepat ke kolom yang salah dan menjelaskan cara memperbaikinya.

## Penjelasan Detail

Pesan error dan validasi yang aksesibel adalah komponen penting dalam pengalaman pengguna, terutama bagi pengguna screen reader. Ketika validasi formulir gagal, pengguna harus segera diberi tahu dengan cara yang jelas dan dapat ditindaklanjuti. Beberapa praktik terbaik meliputi: mengaitkan pesan error dengan input yang bermasalah menggunakan `aria-describedby` atau `aria-errormessage`, menggunakan `role="alert"` atau `aria-live="polite"` agar pesan error langsung diumumkan oleh screen reader tanpa memindahkan fokus, memindahkan fokus ke error pertama atau ke ringkasan error di bagian atas formulir, dan menyediakan ringkasan error yang jelas yang mencantumkan semua masalah. Pesan error harus spesifik — bukan hanya "Input tidak valid" tetapi "Format email tidak valid. Contoh yang benar: nama@domain.com."

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Contoh Validasi Formulir Aksesibel</title>
  <style>
    body { font-family: sans-serif; padding: 20px; max-width: 600px; margin: auto; }
    .field { margin-bottom: 20px; }
    label { display: block; font-weight: bold; margin-bottom: 4px; }
    input { width: 100%; padding: 8px; font-size: 16px; border: 2px solid #ccc; border-radius: 4px; box-sizing: border-box; }
    input:focus { outline: 3px solid #007bff; }
    .error-message { color: #cc0000; font-size: 0.9em; margin-top: 4px; display: none; }
    .error-message.visible { display: block; }
    input.invalid { border-color: #cc0000; background: #fff5f5; }
    #errorSummary {
      background: #fff5f5; border: 2px solid #cc0000; padding: 16px; border-radius: 6px; margin-bottom: 20px; display: none;
    }
    #errorSummary.visible { display: block; }
    #errorSummary a { color: #cc0000; text-decoration: underline; cursor: pointer; }
    #errorSummary a:focus { outline: 2px solid #cc0000; }
    button { padding: 10px 24px; font-size: 16px; background: #007bff; color: white; border: none; border-radius: 4px; cursor: pointer; }
    button:hover { background: #0056b3; }
    .hint { font-size: 0.9em; color: #555; margin-top: 4px; }
  </style>
</head>
<body>
  <h1>Formulir dengan Validasi Error Aksesibel</h1>

  <form id="loginForm" novalidate>
    <!-- Ringkasan error (akan muncul jika ada validasi gagal) -->
    <div id="errorSummary" role="alert" aria-live="assertive" tabindex="-1">
      <h2>Harap perbaiki kesalahan berikut:</h2>
      <ul id="errorList"></ul>
    </div>

    <div class="field">
      <label for="username">Nama Pengguna</label>
      <input type="text" id="username" name="username" autocomplete="username" aria-describedby="username-error username-hint" aria-required="true">
      <div id="username-hint" class="hint">Minimal 4 karakter, hanya huruf dan angka.</div>
      <div id="username-error" class="error-message" role="alert"></div>
    </div>

    <div class="field">
      <label for="email">Alamat Email</label>
      <input type="email" id="email" name="email" autocomplete="email" aria-describedby="email-error email-hint" aria-required="true">
      <div id="email-hint" class="hint">Contoh: nama@domain.com</div>
      <div id="email-error" class="error-message" role="alert"></div>
    </div>

    <div class="field">
      <label for="password">Kata Sandi</label>
      <input type="password" id="password" name="password" autocomplete="new-password" aria-describedby="password-error password-hint" aria-required="true">
      <div id="password-hint" class="hint">Minimal 8 karakter dengan kombinasi huruf dan angka.</div>
      <div id="password-error" class="error-message" role="alert"></div>
    </div>

    <button type="submit">Daftar</button>
  </form>

  <script>
    const form = document.getElementById('loginForm');
    const errorSummary = document.getElementById('errorSummary');
    const errorList = document.getElementById('errorList');

    function validate() {
      let errors = [];
      const fields = {
        username: { el: document.getElementById('username'), errorEl: document.getElementById('username-error'), label: 'Nama Pengguna' },
        email: { el: document.getElementById('email'), errorEl: document.getElementById('email-error'), label: 'Alamat Email' },
        password: { el: document.getElementById('password'), errorEl: document.getElementById('password-error'), label: 'Kata Sandi' }
      };

      // Validasi username
      if (fields.username.el.value.trim().length < 4) {
        errors.push({ field: 'username', msg: 'Nama Pengguna minimal 4 karakter.' });
      } else if (!/^[a-zA-Z0-9]+$/.test(fields.username.el.value.trim())) {
        errors.push({ field: 'username', msg: 'Nama Pengguna hanya boleh huruf dan angka.' });
      }

      // Validasi email
      if (!fields.email.el.value.includes('@')) {
        errors.push({ field: 'email', msg: 'Alamat Email harus mengandung @. Contoh: nama@domain.com.' });
      }

      // Validasi password
      if (fields.password.el.value.length < 8) {
        errors.push({ field: 'password', msg: 'Kata Sandi minimal 8 karakter.' });
      } else if (!/(?=.*[a-zA-Z])(?=.*[0-9])/.test(fields.password.el.value)) {
        errors.push({ field: 'password', msg: 'Kata Sandi harus kombinasi huruf dan angka.' });
      }

      // Bersihkan semua error
      Object.values(fields).forEach(f => {
        f.el.classList.remove('invalid');
        f.errorEl.textContent = '';
        f.errorEl.classList.remove('visible');
      });

      if (errors.length > 0) {
        errors.forEach(err => {
          const f = fields[err.field];
          f.el.classList.add('invalid');
          f.errorEl.textContent = err.msg;
          f.errorEl.classList.add('visible');
        });

        errorList.innerHTML = errors.map((err, i) =>
          '<li><a href="#' + err.field + '">' + err.msg + '</a></li>'
        ).join('');
        errorSummary.classList.add('visible');
        errorSummary.focus();

        // Fokus ke input error pertama
        document.getElementById(errors[0].field).focus();
      } else {
        errorSummary.classList.remove('visible');
        errorList.innerHTML = '';
        alert('Pendaftaran berhasil!');
      }
    }

    form.addEventListener('submit', function(e) {
      e.preventDefault();
      validate();
    });

    // Validasi real-time dengan aria-live
    document.querySelectorAll('input').forEach(input => {
      input.addEventListener('blur', function() {
        if (this.value.trim() !== '') {
          validate();
        }
      });
    });
  </script>
</body>
</html>
```

## Poin Penting
- Gunakan `role="alert"` pada elemen pesan error agar screen reader langsung mengumumkannya saat error muncul.
- Tautkan pesan error ke input yang bermasalah menggunakan `aria-describedby` agar screen reader membacakan error saat fokus pada input.
- Sediakan ringkasan error di bagian atas formulir yang dapat difokus dan mengandung link ke setiap input error untuk navigasi cepat.
