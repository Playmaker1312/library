# Atribut role pada Elemen HTML untuk Mendefinisikan Peran Elemen bagi Screen Reader

## Analogi: Perpustakaan Digital

Di perpustakaan, setiap area memiliki fungsi yang jelas: meja sirkulasi, rak buku, area baca, dan ruang diskusi. Jika area-area itu tidak diberi tanda, pengunjung akan bingung meskipun melihat langsung. Atribut `role` dalam HTML seperti memasang papan nama di setiap area perpustakaan: "ini adalah meja sirkulasi," "ini adalah area baca," sehingga pengunjung yang menggunakan pemandu (screen reader) tahu persis fungsi setiap bagian.

## Penjelasan Detail

Atribut `role` adalah komponen inti WAI-ARIA yang memungkinkan pengembang untuk secara eksplisit mendefinisikan peran atau fungsi suatu elemen di halaman web. Elemen HTML native seperti `<button>`, `<nav>`, atau `<header>` sudah memiliki peran bawaan (implicit role), tetapi kadang pengembang menggunakan elemen non-semantik seperti `<div>` atau `<span>` untuk membuat komponen interaktif. Dalam kasus ini, atribut `role` diperlukan agar screen reader dapat menginterpretasikan elemen tersebut dengan benar. Contoh peran yang umum digunakan antara lain `role="button"`, `role="navigation"`, `role="dialog"`, `role="tab"`, `role="alert"`, dan `role="progressbar"`. Aturan penting dalam penggunaan `role` adalah jangan mengubah peran semantik elemen native yang sudah memiliki peran jelas, karena hal ini dapat membingungkan pengguna alat bantu.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Contoh Atribut Role</title>
  <style>
    body { font-family: sans-serif; padding: 20px; }
    .tab-list { display: flex; gap: 4px; }
    .tab { padding: 8px 16px; cursor: pointer; background: #e0e0e0; border: none; }
    .tab[aria-selected="true"] { background: #007bff; color: white; }
    .tab-panel { padding: 16px; border: 1px solid #ccc; margin-top: 4px; }
  </style>
</head>
<body>
  <h1>Contoh Penggunaan Role Tab</h1>

  <div role="tablist" class="tab-list" aria-label="Navigasi konten">
    <div role="tab" aria-selected="true" aria-controls="panel1" tabindex="0" id="tab1">HTML</div>
    <div role="tab" aria-selected="false" aria-controls="panel2" tabindex="-1" id="tab2">CSS</div>
    <div role="tab" aria-selected="false" aria-controls="panel3" tabindex="-1" id="tab3">JavaScript</div>
  </div>

  <div role="tabpanel" id="panel1" aria-labelledby="tab1">
    <p>HTML adalah bahasa markup untuk struktur halaman web.</p>
  </div>
  <div role="tabpanel" id="panel2" aria-labelledby="tab2" hidden>
    <p>CSS digunakan untuk styling dan layout halaman web.</p>
  </div>
  <div role="tabpanel" id="panel3" aria-labelledby="tab3" hidden>
    <p>JavaScript menambahkan interaktivitas pada halaman web.</p>
  </div>

  <script>
    const tabs = document.querySelectorAll('[role="tab"]');
    const panels = {
      panel1: document.getElementById('panel1'),
      panel2: document.getElementById('panel2'),
      panel3: document.getElementById('panel3')
    };

    tabs.forEach(tab => {
      tab.addEventListener('click', function() {
        tabs.forEach(t => { t.setAttribute('aria-selected', 'false'); t.setAttribute('tabindex', '-1'); });
        this.setAttribute('aria-selected', 'true');
        this.setAttribute('tabindex', '0');
        Object.keys(panels).forEach(id => panels[id].hidden = true);
        const panelId = this.getAttribute('aria-controls');
        document.getElementById(panelId).hidden = false;
      });
    });
  </script>
</body>
</html>
```

## Poin Penting
- Gunakan elemen HTML semantik terlebih dahulu; atribut `role` hanya diperlukan ketika elemen non-semantik digunakan untuk komponen interaktif.
- Jangan menimpa peran implisit elemen native — misalnya jangan tambahkan `role="button"` pada elemen `<button>` yang sudah memiliki peran button secara implisit.
- Pastikan `role` yang digunakan sesuai dengan praktik ARIA Authoring Practices Guide (APG) agar komponen dapat dioperasikan dengan keyboard.
