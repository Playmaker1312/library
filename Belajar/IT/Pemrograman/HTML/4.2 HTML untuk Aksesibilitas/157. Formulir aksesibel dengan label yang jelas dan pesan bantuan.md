# Formulir Aksesibel dengan Label yang Jelas dan Pesan Bantuan

## Analogi: Perpustakaan Digital

Di perpustakaan, ada formulir pendaftaran anggota baru. Setiap kolom isian memiliki papan petunjuk yang jelas: "Nama Lengkap — tulis nama sesuai KTP," "Alamat Email — masukkan alamat email aktif." Tanpa petunjuk itu, pengunjung akan bingung mengisi formulir. Formulir aksesibel di web seperti formulir perpustakaan yang ramah — setiap kolom memiliki label yang jelas, instruksi yang membantu, dan umpan balik yang informatif, sehingga semua pengunjung bisa mengisinya dengan mudah.

## Penjelasan Detail

Formulir aksesibel adalah formulir yang dapat diisi oleh semua pengguna, termasuk pengguna screen reader dan pengguna dengan disabilitas kognitif. Beberapa prinsip utama dalam membuat formulir aksesibel meliputi: menggunakan elemen `<label>` yang secara eksplisit ditautkan ke `<input>` melalui atribut `for` dan `id`, memberikan instruksi atau petunjuk pengisian yang jelas, mengelompokkan elemen terkait dengan `<fieldset>` dan `<legend>`, serta memberikan pesan bantuan kontekstual yang dapat diakses. Label harus jelas dan deskriptif — bukan hanya "Nama" tetapi "Nama Lengkap (sesuai KTP)". Pesan bantuan dan contoh format (placeholder) dapat membantu, tetapi jangan hanya mengandalkan placeholder karena akan hilang saat pengguna mulai mengetik. Formulir yang baik juga memberikan umpan balik real-time yang aksesibel menggunakan `aria-live` atau `role="alert"`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Contoh Formulir Aksesibel</title>
  <style>
    body { font-family: sans-serif; padding: 20px; max-width: 600px; margin: auto; }
    .field { margin-bottom: 20px; }
    label { display: block; font-weight: bold; margin-bottom: 4px; }
    input, select, textarea {
      width: 100%; padding: 8px; font-size: 16px; border: 2px solid #ccc; border-radius: 4px; box-sizing: border-box;
    }
    input:focus, select:focus, textarea:focus { outline: 3px solid #007bff; border-color: #007bff; }
    .hint { font-size: 0.9em; color: #555; margin-top: 4px; }
    .required::after { content: " *"; color: #cc0000; }
    .error { color: #cc0000; font-size: 0.9em; margin-top: 4px; }
    input.error-input { border-color: #cc0000; background: #fff5f5; }
    fieldset { border: 2px solid #ddd; border-radius: 6px; padding: 16px; margin-bottom: 20px; }
    legend { font-weight: bold; padding: 0 8px; }
    button { padding: 10px 24px; font-size: 16px; background: #007bff; color: white; border: none; border-radius: 4px; cursor: pointer; }
    button:hover { background: #0056b3; }
    .success { background: #d4edda; color: #155724; padding: 12px; border: 1px solid #c3e6cb; border-radius: 4px; margin-top: 16px; }
  </style>
</head>
<body>
  <h1>Formulir Pendaftaran Aksesibel</h1>

  <form id="daftarForm" novalidate>
    <!-- Field dengan label eksplisit -->
    <div class="field">
      <label for="nama" class="required">Nama Lengkap</label>
      <input type="text" id="nama" name="nama" autocomplete="name" aria-describedby="nama-hint" aria-required="true">
      <div id="nama-hint" class="hint">Masukkan nama lengkap sesuai KTP, minimal 3 karakter.</div>
    </div>

    <div class="field">
      <label for="email" class="required">Alamat Email</label>
      <input type="email" id="email" name="email" autocomplete="email" aria-describedby="email-hint" aria-required="true">
      <div id="email-hint" class="hint">Kami akan mengirim email verifikasi ke alamat ini.</div>
    </div>

    <!-- Fieldset untuk mengelompokkan opsi terkait -->
    <fieldset>
      <legend>Jenis Kelamin</legend>
      <div>
        <input type="radio" id="gender-l" name="gender" value="L">
        <label for="gender-l" style="display: inline;">Laki-laki</label>
      </div>
      <div>
        <input type="radio" id="gender-p" name="gender" value="P">
        <label for="gender-p" style="display: inline;">Perempuan</label>
      </div>
    </fieldset>

    <!-- Field dengan aria-describedby untuk bantuan -->
    <div class="field">
      <label for="bio" class="required">Biografi Singkat</label>
      <textarea id="bio" name="bio" rows="4" aria-describedby="bio-hint" aria-required="true"></textarea>
      <div id="bio-hint" class="hint">Ceritakan tentang diri Anda dalam 50-200 karakter.</div>
    </div>

    <div class="field">
      <label for="negara">Negara</label>
      <select id="negara" name="negara">
        <option value="">Pilih negara...</option>
        <option value="ID">Indonesia</option>
        <option value="MY">Malaysia</option>
        <option value="SG">Singapura</option>
      </select>
    </div>

    <!-- Area untuk pesan error -->
    <div id="errorContainer" role="alert" aria-live="polite"></div>
    <div id="successContainer"></div>

    <button type="submit">Daftar</button>
  </form>

  <script>
    const form = document.getElementById('daftarForm');
    const errorContainer = document.getElementById('errorContainer');

    form.addEventListener('submit', function(e) {
      e.preventDefault();
      errorContainer.innerHTML = '';
      let errors = [];

      const nama = document.getElementById('nama');
      if (nama.value.trim().length < 3) {
        errors.push('Nama lengkap minimal 3 karakter.');
        nama.className = 'error-input';
      } else {
        nama.className = '';
      }

      const email = document.getElementById('email');
      if (!email.value.includes('@')) {
        errors.push('Alamat email tidak valid.');
        email.className = 'error-input';
      } else {
        email.className = '';
      }

      const bio = document.getElementById('bio');
      if (bio.value.trim().length < 10) {
        errors.push('Biografi minimal 10 karakter.');
        bio.className = 'error-input';
      } else {
        bio.className = '';
      }

      if (errors.length > 0) {
        errorContainer.innerHTML = '<div class="error"><strong>Harap perbaiki kesalahan berikut:</strong><ul><li>' + errors.join('</li><li>') + '</li></ul></div>';
      } else {
        document.getElementById('successContainer').innerHTML = '<div class="success">Pendaftaran berhasil! Kami akan menghubungi Anda melalui email.</div>';
      }
    });
  </script>
</body>
</html>
```

## Poin Penting
- Setiap elemen input harus memiliki `<label>` yang ditautkan secara eksplisit dengan atribut `for` yang cocok dengan `id` input.
- Gunakan `<fieldset>` dan `<legend>` untuk mengelompokkan elemen formulir yang terkait, seperti grup radio button atau checkbox.
- Sediakan petunjuk dan pesan bantuan kontekstual menggunakan `aria-describedby`, dan pastikan placeholder tidak digunakan sebagai satu-satunya petunjuk.
