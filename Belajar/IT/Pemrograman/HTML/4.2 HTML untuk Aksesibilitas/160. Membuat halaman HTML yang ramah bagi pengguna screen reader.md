# Membuat Halaman HTML yang Ramah bagi Pengguna Screen Reader

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan digital yang sempurna: setiap rak diberi label jelas, lorong-lorong memiliki petunjuk arah, peta tersedia di pintu masuk, dan pemandu siap membantu kapan pun. Pengunjung tunanetra bisa berjalan sendiri karena semua informasi tersedia dalam format yang bisa didengar atau diraba. Halaman HTML yang ramah screen reader seperti perpustakaan ideal itu — setiap elemen memiliki makna, navigasi mudah diikuti, dan tidak ada informasi yang hanya bisa diakses secara visual.

## Penjelasan Detail

Halaman HTML yang ramah screen reader adalah halaman yang dapat dinavigasi dan dipahami sepenuhnya melalui teknologi pembaca layar tanpa kehilangan informasi atau fungsionalitas. Untuk mencapai ini, pengembang perlu menerapkan beberapa prinsip utama: menggunakan elemen HTML semantik (seperti `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`) untuk memberikan struktur yang bermakna, memastikan urutan navigasi keyboard logis dan konsisten, menyediakan teks alternatif untuk semua konten non-teks, menggunakan heading yang terstruktur secara hierarkis, memberikan label yang jelas pada semua elemen interaktif, dan mengelola fokus dengan baik pada konten dinamis. Halaman yang ramah screen reader tidak hanya membantu pengguna tunanetra tetapi juga meningkatkan SEO, performa, dan pengalaman pengguna secara keseluruhan.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Toko Buku Aksesibel — Beranda</title>
  <style>
    /* Reset dan base */
    body { font-family: sans-serif; margin: 0; padding: 0; line-height: 1.6; color: #222; background: #fff; }
    * { box-sizing: border-box; }

    /* Skip link */
    .skip-link { position: absolute; top: -100%; left: 8px; background: #000; color: #fff; padding: 8px 16px; z-index: 1000; }
    .skip-link:focus { top: 8px; }

    /* Header */
    .site-header { background: #2c3e50; color: white; padding: 16px 24px; }
    .site-header h1 { margin: 0; }

    /* Navigasi */
    .site-nav { background: #34495e; padding: 8px 24px; }
    .site-nav ul { list-style: none; padding: 0; margin: 0; display: flex; gap: 24px; flex-wrap: wrap; }
    .site-nav a { color: white; text-decoration: none; padding: 4px 0; }
    .site-nav a:hover, .site-nav a:focus { text-decoration: underline; }

    /* Layout */
    .layout { display: flex; flex-wrap: wrap; max-width: 1200px; margin: auto; padding: 24px; gap: 24px; }
    .main-content { flex: 2; min-width: 280px; }
    .sidebar { flex: 1; min-width: 220px; background: #f8f9fa; padding: 16px; border-radius: 6px; }

    /* Kartu buku */
    .book-card { border: 1px solid #ddd; padding: 16px; border-radius: 6px; margin-bottom: 16px; }
    .book-card h3 { margin-top: 0; }
    .book-card:focus-within { border-color: #2c3e50; }

    /* Form */
    .search-form { display: flex; gap: 8px; margin-bottom: 24px; flex-wrap: wrap; }
    .search-form label { font-weight: bold; }
    .search-form input { padding: 8px; font-size: 16px; border: 2px solid #ccc; border-radius: 4px; flex: 1; min-width: 200px; }
    .search-form input:focus { border-color: #2c3e50; outline: 2px solid #2c3e50; }
    .search-form button { padding: 8px 16px; background: #2c3e50; color: white; border: none; border-radius: 4px; cursor: pointer; font-size: 16px; }

    /* Footer */
    .site-footer { background: #2c3e50; color: white; text-align: center; padding: 16px; margin-top: 24px; }
    .site-footer a { color: #a0d0ff; }

    /* Responsif */
    @media (max-width: 600px) {
      .site-nav ul { flex-direction: column; gap: 8px; }
      .layout { padding: 12px; }
    }

    /* Visually hidden untuk screen reader saja */
    .sr-only { position: absolute; width: 1px; height: 1px; padding: 0; margin: -1px; overflow: hidden; clip: rect(0,0,0,0); border: 0; }
  </style>
</head>
<body>
  <!-- Skip link -->
  <a href="#main-content" class="skip-link">Lompat ke konten utama</a>

  <!-- Header -->
  <header class="site-header">
    <h1>Toko Buku Aksesibel</h1>
  </header>

  <!-- Navigasi utama -->
  <nav class="site-nav" aria-label="Navigasi utama">
    <ul>
      <li><a href="#" aria-current="page">Beranda</a></li>
      <li><a href="#">Katalog Buku</a></li>
      <li><a href="#">Tentang Kami</a></li>
      <li><a href="#">Kontak</a></li>
      <li><a href="#">Keranjang (0)</a></li>
    </ul>
  </nav>

  <!-- Konten utama -->
  <div class="layout">
    <main id="main-content" class="main-content" tabindex="-1">
      <h2>Buku Terbaru</h2>

      <!-- Form pencarian dengan label eksplisit -->
      <form class="search-form" role="search" aria-label="Cari buku">
        <label for="search-input">Cari buku:</label>
        <input type="search" id="search-input" placeholder="Judul, penulis, atau kategori" aria-describedby="search-hint">
        <button type="submit">Cari</button>
        <span id="search-hint" class="sr-only">Tekan Enter untuk mencari.</span>
      </form>

      <!-- Daftar buku dengan artikel -->
      <article class="book-card" aria-labelledby="book1-title">
        <h3 id="book1-title">HTML untuk Semua Orang</h3>
        <p><strong>Penulis:</strong> Ahmad Fauzi</p>
        <p><strong>Deskripsi:</strong> Buku panduan HTML yang ditulis khusus untuk pemula dengan pendekatan aksesibilitas.</p>
        <a href="#" aria-label="Detail buku HTML untuk Semua Orang">Lihat detail</a>
        <button aria-label="Tambah HTML untuk Semua Orang ke keranjang">Tambah ke Keranjang</button>
      </article>

      <article class="book-card" aria-labelledby="book2-title">
        <h3 id="book2-title">CSS Modern dan Responsif</h3>
        <p><strong>Penulis:</strong> Siti Nurhaliza</p>
        <p><strong>Deskripsi:</strong> Pelajari CSS modern dengan Flexbox, Grid, dan teknik responsive design.</p>
        <a href="#" aria-label="Detail buku CSS Modern dan Responsif">Lihat detail</a>
        <button aria-label="Tambah CSS Modern dan Responsif ke keranjang">Tambah ke Keranjang</button>
      </article>

      <article class="book-card" aria-labelledby="book3-title">
        <h3 id="book3-title">JavaScript Interaktif</h3>
        <p><strong>Penulis:</strong> Budi Santoso</p>
        <p><strong>Deskripsi:</strong> Kuasai JavaScript dari dasar hingga mahir dengan proyek nyata.</p>
        <a href="#" aria-label="Detail buku JavaScript Interaktif">Lihat detail</a>
        <button aria-label="Tambah JavaScript Interaktif ke keranjang">Tambah ke Keranjang</button>
      </article>

      <!-- Navigasi halaman -->
      <nav aria-label="Navigasi halaman katalog">
        <h3 class="sr-only">Halaman</h3>
        <a href="#" aria-label="Halaman 1" aria-current="page">1</a>
        <a href="#" aria-label="Halaman 2">2</a>
        <a href="#" aria-label="Halaman 3">3</a>
        <a href="#" aria-label="Halaman berikutnya">Berikutnya</a>
      </nav>
    </main>

    <!-- Sidebar -->
    <aside class="sidebar" aria-label="Informasi tambahan">
      <section>
        <h2>Kategori Populer</h2>
        <nav aria-label="Kategori buku">
          <ul>
            <li><a href="#">Pemrograman Web</a></li>
            <li><a href="#">Data Science</a></li>
            <li><a href="#">Desain Grafis</a></li>
            <li><a href="#">Jaringan Komputer</a></li>
          </ul>
        </nav>
      </section>

      <section>
        <h2>Promo Hari Ini</h2>
        <p>Diskon 20% untuk semua buku pemrograman! Gunakan kode <strong>WEB20</strong>.</p>
        <p aria-hidden="true">&#x1F389;</p>
      </section>
    </aside>
  </div>

  <!-- Footer -->
  <footer class="site-footer">
    <p>&copy; 2026 Toko Buku Aksesibel. <a href="#">Kebijakan Privasi</a> | <a href="#">Syarat &amp; Ketentuan</a></p>
  </footer>
</body>
</html>
```

## Poin Penting
- Gunakan elemen HTML semantik (`<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`) untuk struktur halaman yang bermakna.
- Pastikan semua fungsi dapat diakses melalui keyboard — tidak ada elemen interaktif yang hanya bisa dioperasikan dengan mouse.
- Sediakan teks alternatif untuk semua gambar, label untuk semua input, dan heading yang terstruktur secara hierarkis (h1 hingga h6 tanpa lompatan).
