# Atribut aria-label, aria-labelledby, dan aria-describedby untuk Memberi Label Elemen

## Analogi: Perpustakaan Digital

Di perpustakaan, setiap pintu dan tombol harus memiliki label yang jelas. Bayangkan tombol di lift perpustakaan — tanpa label "Buka Pintu" atau "Lantai 2", pengunjung tidak akan tahu fungsinya. `aria-label` seperti menempelkan label langsung pada tombol, `aria-labelledby` seperti menunjuk ke papan petunjuk yang sudah ada, dan `aria-describedby` seperti memberikan catatan penjelasan tambahan yang bisa dibaca jika diperlukan.

## Penjelasan Detail

Atribut `aria-label`, `aria-labelledby`, dan `aria-describedby` adalah tiga atribut WAI-ARIA yang digunakan untuk memberikan nama dan deskripsi pada elemen agar dapat dikenali oleh screen reader. `aria-label` digunakan untuk memberikan label langsung dalam bentuk string teks pada elemen yang tidak memiliki teks visual, seperti tombol ikon. `aria-labelledby` digunakan ketika label sudah ada sebagai teks visual di halaman — atribut ini merujuk pada `id` elemen yang berisi teks label tersebut. `aria-describedby` memberikan deskripsi tambahan yang lebih panjang, biasanya untuk instruksi atau konteks lebih lanjut. Ketiga atribut ini sangat berguna untuk elemen interaktif seperti tombol, input form, dan link, terutama ketika label visual tidak mencukupi atau tidak ada sama sekali. Urutan prioritas pemberian nama elemen oleh screen reader adalah: `aria-labelledby` > `aria-label` > atribut lain seperti `alt` atau label native.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Contoh aria-label, aria-labelledby, aria-describedby</title>
  <style>
    body { font-family: sans-serif; padding: 20px; }
    .field { margin-bottom: 15px; }
    .hint { font-size: 0.9em; color: #555; margin-top: 4px; }
    button.icon-btn { background: none; border: none; font-size: 24px; cursor: pointer; }
  </style>
</head>
<body>
  <h1>Formulir dengan Label dan Deskripsi ARIA</h1>

  <!-- aria-label: tombol ikon tanpa teks visual -->
  <button class="icon-btn" aria-label="Cari data" onclick="alert('Pencarian dibuka')">
    &#x1F50D;
  </button>

  <hr>

  <!-- aria-labelledby: merujuk ke elemen label yang sudah ada -->
  <div class="field">
    <h2 id="nama-label">Nama Lengkap</h2>
    <input type="text" id="nama" aria-labelledby="nama-label" aria-describedby="nama-hint">
    <div id="nama-hint" class="hint">Masukkan nama lengkap tanpa gelar.</div>
  </div>

  <!-- aria-describedby: tombol dengan deskripsi tambahan -->
  <div class="field">
    <button id="simpanBtn" aria-describedby="simpan-desc">Simpan</button>
    <p id="simpan-desc" class="hint">Data akan disimpan ke server dan tidak bisa dibatalkan.</p>
  </div>

  <hr>

  <!-- aria-label pada navigasi -->
  <nav aria-label="Navigasi utama halaman">
    <a href="#">Beranda</a> |
    <a href="#">Profil</a> |
    <a href="#">Kontak</a>
  </nav>
</body>
</html>
```

## Poin Penting
- `aria-label` memberikan label langsung; `aria-labelledby` merujuk ke teks visual yang sudah ada di halaman.
- `aria-describedby` menambahkan deskripsi tambahan yang dibacakan setelah label utama.
- Jika suatu elemen memiliki teks visual yang jelas, gunakan elemen HTML native seperti `<label>` — ARIA hanya untuk melengkapi ketika metode native tidak memadai.
