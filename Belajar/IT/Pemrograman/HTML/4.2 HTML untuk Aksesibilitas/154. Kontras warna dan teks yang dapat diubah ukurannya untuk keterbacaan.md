# Kontras Warna dan Teks yang Dapat Diubah Ukurannya untuk Keterbacaan

## Analogi: Perpustakaan Digital

Bayangkan sebuah buku perpustakaan dengan tinta abu-abu muda di atas kertas putih dan ukuran huruf yang sangat kecil. Pembaca dengan penglihatan normal pun akan kesulitan membaca, apalagi pembaca dengan gangguan penglihatan. Kontras warna yang baik seperti menggunakan tinta hitam pekat di atas kertas putih — jelas dan mudah dibaca. Teks yang bisa diubah ukurannya seperti buku dengan huruf yang bisa diperbesar sesuai kebutuhan — setiap pengunjung bisa menyesuaikan kenyamanan bacanya.

## Penjelasan Detail

Kontras warna dan kemampuan mengubah ukuran teks adalah dua aspek fundamental dalam aksesibilitas web yang diatur oleh WCAG 2.1. Rasio kontras minimum yang disarankan adalah 4.5:1 untuk teks normal dan 3:1 untuk teks besar (di atas 18px bold atau 24px regular). Kontras yang rendah menyulitkan pengguna dengan low vision, buta warna, atau pengguna yang membaca di layar dengan pencahayaan buruk. Selain kontras, teks harus dapat diubah ukurannya hingga 200% tanpa kehilangan konten atau fungsionalitas — ini berarti pengguna harus bisa memperbesar teks melalui browser tanpa membuat tata letak halaman rusak atau tombol tumpang tindih. Penggunaan unit relatif seperti `em` atau `rem` untuk ukuran font lebih disukai daripada `px` karena memungkinkan penskalaan yang lebih fleksibel.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Contoh Kontras Warna dan Teks Skalabel</title>
  <style>
    /* Gunakan unit relatif untuk ukuran teks */
    body { font-family: sans-serif; padding: 1.25rem; line-height: 1.6; }

    /* Kontras baik: hitam di atas putih (21:1) */
    .good-contrast {
      background: #ffffff;
      color: #000000;
      padding: 1rem;
      margin-bottom: 1rem;
      border: 1px solid #ccc;
    }

    /* Kontras buruk (contoh yang salah) */
    .bad-contrast {
      background: #f0f0f0;
      color: #999999;
      padding: 1rem;
      margin-bottom: 1rem;
      border: 1px solid #ddd;
    }

    /* Teks besar dengan kontras 3:1 minimal */
    .large-text {
      font-size: 1.5rem;
      font-weight: bold;
      color: #767676;
      background: #ffffff;
      padding: 1rem;
      margin-bottom: 1rem;
    }

    /* Contoh tombol dengan kontras baik */
    button {
      background: #007bff;
      color: white;
      border: none;
      padding: 0.5rem 1rem;
      font-size: 1rem;
      cursor: pointer;
    }
    button:hover { background: #0056b3; }

    /* Kontainer dengan ukuran relatif */
    .content { max-width: 40rem; margin: auto; }

    /* Pesan error dengan kontras baik */
    .error { color: #cc0000; background: #fff5f5; padding: 0.75rem; border: 2px solid #cc0000; }
  </style>
</head>
<body>
  <div class="content">
    <h1>Contoh Kontras Warna dan Teks Skalabel</h1>

    <section>
      <h2>Kontras yang Baik</h2>
      <div class="good-contrast">
        <p>Teks hitam di atas latar putih memiliki rasio kontras 21:1 — sangat mudah dibaca.</p>
      </div>
    </section>

    <section>
      <h2>Kontras yang Buruk (Contoh Salah)</h2>
      <div class="bad-contrast">
        <p>Teks abu-abu (#999) di atas latar abu-abu muda (#f0f0f0) memiliki kontras sekitar 2.2:1 — sulit dibaca.</p>
      </div>
    </section>

    <section>
      <h2>Teks Besar dengan Kontras Minimum</h2>
      <div class="large-text">
        <p>Teks besar ini memiliki kontras sekitar 4.1:1, memenuhi syarat untuk teks besar.</p>
      </div>
    </section>

    <section>
      <h2>Tombol dengan Kontras Baik</h2>
      <button type="button">Tombol Utama</button>
    </section>

    <section>
      <h2>Pesan Error yang Aksesibel</h2>
      <div class="error" role="alert">
        <p><strong>Error:</strong> Data tidak valid. Silakan periksa kembali input Anda.</p>
      </div>
    </section>

    <section>
      <h2>Catatan</h2>
      <p>Coba perbesar teks dengan Ctrl + (+). Halaman ini tetap terbaca dengan baik karena menggunakan unit relatif (rem).</p>
    </section>
  </div>
</body>
</html>
```

## Poin Penting
- Pastikan rasio kontras minimal 4.5:1 untuk teks normal dan 3:1 untuk teks besar sesuai standar WCAG AA.
- Gunakan unit relatif seperti `em` atau `rem` untuk ukuran font agar teks dapat diskalakan hingga 200% tanpa merusak tata letak.
- Jangan mengandalkan warna saja untuk menyampaikan informasi — kombinasikan dengan ikon, teks, atau pola agar aksesibel bagi pengguna buta warna.
