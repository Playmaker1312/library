# Teks Alternatif pada Gambar yang Bermakna dan Informatif

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada sebuah lukisan pemandangan yang dipajang di dinding. Pengunjung tunanetra tidak bisa melihat lukisan itu, tetapi pemandu bisa mendeskripsikannya: "ini lukisan gunung dengan matahari terbenam, berwarna jingga dan ungu." Teks alternatif (alt text) pada gambar di web adalah deskripsi yang disediakan oleh pengembang, seperti pemandu yang mendeskripsikan lukisan — memastikan pengguna yang tidak bisa melihat gambar tetap mendapatkan informasi yang sama.

## Penjelasan Detail

Teks alternatif atau `alt` attribute pada elemen `<img>` adalah salah satu prinsip aksesibilitas web paling dasar dan penting. Atribut `alt` menyediakan deskripsi tekstual dari gambar yang dibacakan oleh screen reader atau ditampilkan ketika gambar gagal dimuat. Teks alternatif yang baik harus informatif dan sesuai dengan konteks — misalnya, gambar logo perusahaan cukup ditulis "Logo Perusahaan XYZ", sedangkan foto produk memerlukan deskripsi yang lebih detail seperti "Sepatu lari berwarna biru dengan sol putih." Untuk gambar dekoratif murni yang tidak menambah informasi, gunakan `alt=""` (alt kosong) agar screen reader melewatkannya. Teks alternatif yang buruk — seperti "gambar1.jpg" atau "image" — sama sekali tidak berguna dan menurunkan pengalaman pengguna.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Contoh Teks Alternatif pada Gambar</title>
  <style>
    body { font-family: sans-serif; padding: 20px; max-width: 700px; margin: auto; }
    .gallery { display: flex; flex-wrap: wrap; gap: 16px; }
    .card { border: 1px solid #ddd; padding: 12px; border-radius: 6px; max-width: 300px; }
    img { max-width: 100%; height: auto; border-radius: 4px; }
    .example { margin-bottom: 24px; }
    .wrong { background: #fff0f0; border-left: 4px solid #cc0000; padding: 8px 16px; }
    .correct { background: #f0fff0; border-left: 4px solid #00aa00; padding: 8px 16px; }
  </style>
</head>
<body>
  <h1>Contoh Teks Alternatif yang Bermakna</h1>

  <!-- Gambar informatif dengan alt yang baik -->
  <section class="example">
    <h2>Gambar Informatif</h2>
    <div class="card">
      <img
        src="https://via.placeholder.com/300x200/007bff/ffffff?text=Sepatu+Olahraga"
        alt="Sepatu lari berwarna biru navy dengan sol tebal berwarna putih"
        width="300" height="200">
      <!-- alt harus mendeskripsikan konten visual gambar secara akurat -->
    </div>
    <div class="correct">
      <p>alt="Sepatu lari berwarna biru navy dengan sol tebal berwarna putih"</p>
    </div>
  </section>

  <!-- Gambar dekoratif dengan alt kosong -->
  <section class="example">
    <h2>Gambar Dekoratif (Alt Kosong)</h2>
    <div class="card">
      <p>
        <img
          src="https://via.placeholder.com/20x20/cccccc/666666?text=*"
          alt=""
          width="20" height="20"
          aria-hidden="true">
        Ikon dekoratif sebelum teks ini tidak memiliki makna, jadi alt="" digunakan.
      </p>
    </div>
    <div class="correct">
      <p>alt="" — gambar dekoratif dilewati screen reader.</p>
    </div>
  </section>

  <!-- Gambar fungsi (tombol) -->
  <section class="example">
    <h2>Gambar sebagai Tombol</h2>
    <button type="button" style="background: none; border: none; cursor: pointer; padding: 0;">
      <img
        src="https://via.placeholder.com/48x48/28a745/ffffff?text=%E2%9C%93"
        alt="Simpan perubahan"
        width="48" height="48">
    </button>
    <div class="correct">
      <p>alt="Simpan perubahan" — gambar dalam tombol harus mendeskripsikan aksi tombol.</p>
    </div>
  </section>

  <!-- Perbandingan: alt salah vs benar -->
  <section class="example">
    <h2>Perbandingan Alt Salah dan Benar</h2>
    <div class="wrong">
      <p>SALAH: alt="img_2025_08_21.jpg" atau alt="gambar"</p>
    </div>
    <div class="correct">
      <p>BENAR: alt="Diagram arsitektur aplikasi web menunjukkan alur data dari klien ke server"</p>
    </div>
  </section>

  <!-- Catatan -->
  <section>
    <h2>Praktik Terbaik</h2>
    <ul>
      <li>Gambar informatif: alt harus mendeskripsikan konten visual secara singkat dan akurat.</li>
      <li>Gambar dekoratif: gunakan alt="" agar screen reader melewatkannya.</li>
      <li>Gambar fungsional (link/tombol): alt harus mendeskripsikan tujuan/fungsi, bukan gambar itu sendiri.</li>
      <li>Gambar kompleks (grafik/diagram): berikan alt ringkas dan deskripsi panjang di teks sekitar.</li>
    </ul>
  </section>
</body>
</html>
```

## Poin Penting
- Setiap `<img>` harus memiliki atribut `alt` — gunakan `alt=""` untuk gambar dekoratif, bukan menghilangkan atribut `alt` sama sekali.
- Teks alternatif harus kontekstual dan informatif, mendeskripsikan konten atau fungsi gambar secara akurat dalam 1-2 kalimat singkat.
- Gambar fungsional (sebagai tombol atau link) harus memiliki alt yang menjelaskan tujuan/fungsinya, bukan deskripsi visualnya.
