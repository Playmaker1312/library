# Manajemen Fokus untuk Aplikasi Web yang Aksesibel

## Analogi: Perpustakaan Digital

Bayangkan Anda sedang meminjam buku di perpustakaan dengan mata tertutup, dan petugas memandu Anda dari meja pendaftaran ke rak buku lalu ke meja sirkulasi. Jika pemandu tiba-tiba diam dan tidak memberi tahu Anda sudah sampai di meja sirkulasi, Anda akan bingung. Manajemen fokus seperti memberikan arahan "sekarang kita di meja sirkulasi — silakan lanjutkan" setiap kali Anda berpindah tempat, memastikan Anda selalu tahu posisi Anda.

## Penjelasan Detail

Manajemen fokus adalah praktik mengontrol perpindahan fokus keyboard secara terprogram (programmatic focus management) dalam aplikasi web, terutama pada aplikasi halaman tunggal (SPA) atau komponen dinamis. Ketika konten berubah secara signifikan — seperti membuka dialog modal, berpindah tab, atau memuat konten baru — fokus keyboard harus dipindahkan secara eksplisit ke elemen yang relevan agar pengguna screen reader dan keyboard tetap mengetahui konteksnya. Tanpa manajemen fokus yang baik, pengguna bisa kehilangan jejak dan bingung karena fokus terlempar ke awal halaman atau bahkan menghilang sama sekali. Praktik terbaik meliputi: memindahkan fokus ke judul dialog saat modal terbuka, mengembalikan fokus ke tombol pemicu saat modal ditutup, mengelola fokus dalam siklus (focus trap) di dalam modal, dan memperbarui `aria-live` region untuk mengumumkan perubahan konteks.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Contoh Manajemen Fokus</title>
  <style>
    body { font-family: sans-serif; padding: 20px; }
    .modal-overlay {
      position: fixed; top: 0; left: 0; right: 0; bottom: 0;
      background: rgba(0,0,0,0.5); display: flex;
      justify-content: center; align-items: center;
    }
    .modal { background: white; padding: 24px; border-radius: 8px; max-width: 400px; width: 90%; }
    .modal h2 { margin-top: 0; }
    button { padding: 8px 16px; }
  </style>
</head>
<body>
  <h1>Contoh Manajemen Fokus pada Modal</h1>

  <a href="#">Link di luar modal</a>
  <br><br>
  <button id="openModalBtn">Buka Modal</button>
  <br><br>
  <a href="#">Link lain di luar modal</a>

  <div id="modalContainer"></div>

  <script>
    let lastFocused = null;

    document.getElementById('openModalBtn').addEventListener('click', function() {
      lastFocused = this;
      openModal();
    });

    function openModal() {
      const overlay = document.createElement('div');
      overlay.className = 'modal-overlay';
      overlay.setAttribute('role', 'dialog');
      overlay.setAttribute('aria-modal', 'true');
      overlay.setAttribute('aria-labelledby', 'modalTitle');

      overlay.innerHTML = `
        <div class="modal">
          <h2 id="modalTitle">Konfirmasi</h2>
          <p>Apakah Anda yakin ingin melanjutkan?</p>
          <button id="confirmBtn">Ya, Lanjutkan</button>
          <button id="cancelBtn">Batal</button>
        </div>
      `;

      document.body.appendChild(overlay);
      const confirmBtn = document.getElementById('confirmBtn');
      confirmBtn.focus();

      // Focus trap: loop fokus di dalam modal
      overlay.addEventListener('keydown', function trap(e) {
        const focusable = overlay.querySelectorAll('button, a, input, [tabindex]:not([tabindex="-1"])');
        const first = focusable[0];
        const last = focusable[focusable.length - 1];

        if (e.key === 'Tab') {
          if (e.shiftKey && document.activeElement === first) {
            e.preventDefault();
            last.focus();
          } else if (!e.shiftKey && document.activeElement === last) {
            e.preventDefault();
            first.focus();
          }
        }

        if (e.key === 'Escape') {
          closeModal();
        }
      });

      confirmBtn.addEventListener('click', function() {
        alert('Dikonfirmasi!');
        closeModal();
      });

      document.getElementById('cancelBtn').addEventListener('click', closeModal);
    }

    function closeModal() {
      const overlay = document.querySelector('.modal-overlay');
      if (overlay) overlay.remove();
      if (lastFocused) lastFocused.focus();
    }
  </script>
</body>
</html>
```

## Poin Penting
- Pindahkan fokus ke konten baru saat terjadi perubahan halaman yang signifikan, misalnya membuka modal atau panel.
- Saat menutup komponen seperti modal, kembalikan fokus ke elemen yang memicunya (trigger element).
- Terapkan focus trap di dalam modal agar fokus tidak keluar dari modal saat pengguna menekan Tab, sehingga pengguna keyboard tidak kehilangan konteks.
