# Navigasi Keyboard dengan tabindex untuk Fokus Elemen yang Dapat Diakses

## Analogi: Perpustakaan Digital

Bayangkan anda sedang berjalan di perpustakaan dan ingin mengunjungi setiap meja informasi secara berurutan. Tanpa peta, anda mungkin melewatkan beberapa meja atau mengunjunginya dalam urutan yang kacau. `tabindex` seperti memberikan nomor urut pada setiap meja informasi, sehingga pengunjung yang menggunakan peta (keyboard) bisa mengunjungi meja-meja tersebut dalam urutan yang logis dan tidak melewatkan satu pun.

## Penjelasan Detail

`tabindex` adalah atribut HTML yang menentukan urutan fokus keyboard (tab order) pada elemen-elemen di halaman web. Nilai `tabindex="0"` membuat elemen yang biasanya tidak dapat difokus (seperti `<div>` atau `<span>`) menjadi focusable melalui tombol Tab, dan menempatkannya dalam urutan alami dokumen. Nilai `tabindex="-1"` membuat elemen dapat difokus secara programatis (via JavaScript) tetapi tidak dapat dijangkau melalui navigasi Tab biasa. Nilai positif seperti `tabindex="1"`, `tabindex="2"`, dst. menentukan urutan fokus khusus, meskipun praktik ini sangat tidak disarankan karena dapat mengacaukan alur navigasi alami. Urutan navigasi keyboard yang baik sangat penting bagi pengguna dengan disabilitas motorik yang tidak bisa menggunakan mouse, pengguna screen reader, dan pengguna power user yang lebih suka navigasi keyboard.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Contoh Navigasi Keyboard dengan tabindex</title>
  <style>
    body { font-family: sans-serif; padding: 20px; }
    .card { border: 1px solid #ddd; padding: 15px; margin-bottom: 10px; border-radius: 4px; }
    .card:focus { outline: 3px solid #007bff; background: #f0f8ff; }
    button { padding: 8px 16px; margin-right: 8px; }
    .custom-widget { background: #f9f9f9; padding: 12px; border: 1px dashed #999; cursor: pointer; }
    .custom-widget:focus { outline: 3px solid #28a745; background: #e8f5e9; }
  </style>
</head>
<body>
  <h1>Navigasi Keyboard dengan tabindex</h1>

  <!-- Navigasi normal: elemen focusable secara default -->
  <a href="#">Link 1 (tabindex otomatis)</a>
  <br>
  <button>Tombol 1 (tabindex otomatis)</button>

  <h2>Elemen Kustom dengan tabindex</h2>

  <!-- tabindex="0" membuat div bisa difokus via Tab -->
  <div class="card" tabindex="0" role="region" aria-label="Kartu informasi 1">
    <h3>Kartu Informasi 1</h3>
    <p>Tekan Tab untuk fokus pada kartu ini. Gunakan Enter atau Spasi untuk berinteraksi.</p>
  </div>

  <!-- tabindex="0" pada widget kustom -->
  <div class="custom-widget" tabindex="0" role="button" aria-label="Widget kustom" id="widget1">
    Klik atau tekan Spasi/Enter untuk aktivasi
  </div>

  <!-- tabindex="-1" hanya bisa difokus via script -->
  <div class="card" tabindex="-1" id="focusableViaScript" role="region" aria-label="Kartu tersembunyi">
    <h3>Kartu Tersembunyi</h3>
    <p>Elemen ini bisa difokus via JavaScript tetapi tidak melalui Tab.</p>
  </div>

  <br>
  <button onclick="document.getElementById('focusableViaScript').focus()">
    Fokus ke Kartu Tersembunyi
  </button>

  <script>
    document.getElementById('widget1').addEventListener('keydown', function(e) {
      if (e.key === 'Enter' || e.key === ' ') {
        e.preventDefault();
        alert('Widget kustom diaktifkan!');
      }
    });
  </script>
</body>
</html>
```

## Poin Penting
- Gunakan `tabindex="0"` untuk membuat elemen non-interaktif menjadi focusable dalam urutan alami dokumen.
- Hindari nilai `tabindex` positif (1, 2, 3, dst.) karena mengacaukan urutan navigasi alami dan menyulitkan pengguna.
- Pastikan semua elemen interaktif dapat dioperasikan dengan keyboard — tidak hanya fokus, tetapi juga aktivasi via Enter atau Spasi.
