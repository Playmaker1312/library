# Skip Link untuk Navigasi Aksesibel Melewati Konten Berulang

## Analogi: Perpustakaan Digital

Bayangkan Anda memasuki perpustakaan yang setiap kali harus melewati lorong panjang berisi papan pengumuman, daftar peraturan, dan denah sebelum sampai ke meja informasi. Bagi pengunjung yang sudah hafal, lorong itu hanya membuang waktu. Skip link seperti pintu rahasia yang langsung membawa Anda dari pintu masuk ke meja informasi, melewati semua konten berulang yang tidak perlu.

## Penjelasan Detail

Skip link (atau skip navigation link) adalah tautan tersembunyi yang muncul ketika pengguna menekan tombol Tab saat pertama kali halaman dimuat. Tautan ini memungkinkan pengguna keyboard dan screen reader untuk melompati (skip) konten berulang seperti navigasi header, menu samping, atau breadcrumb, dan langsung menuju ke konten utama halaman. Skip link biasanya ditempatkan sebagai elemen pertama dalam elemen `<body>` dan menggunakan CSS untuk disembunyikan secara visual tetapi tetap dapat difokus. Standar WCAG 2.0 mengharuskan setidaknya satu mekanisme untuk melewati konten berulang, dan skip link adalah implementasi paling umum. Tanpa skip link, pengguna keyboard harus menekan Tab puluhan kali setiap kali memuat halaman hanya untuk mencapai konten utama, yang sangat tidak efisien dan membuat frustrasi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Contoh Skip Link</title>
  <style>
    body { font-family: sans-serif; margin: 0; padding: 0; }

    /* Skip link: tersembunyi secara default, muncul saat difokus */
    .skip-link {
      position: absolute;
      top: -40px;
      left: 0;
      background: #000;
      color: white;
      padding: 8px 16px;
      z-index: 1000;
      text-decoration: none;
    }
    .skip-link:focus {
      top: 0;
    }

    header { background: #333; color: white; padding: 20px; }
    nav ul { list-style: none; padding: 0; display: flex; gap: 16px; }
    nav a { color: white; text-decoration: none; }
    main { padding: 20px; max-width: 800px; margin: auto; }
    .sidebar { background: #f4f4f4; padding: 15px; margin-bottom: 20px; }
    footer { background: #333; color: white; text-align: center; padding: 15px; margin-top: 20px; }
  </style>
</head>
<body>
  <!-- Skip link: elemen pertama setelah body -->
  <a href="#main-content" class="skip-link">Lompat ke konten utama</a>

  <header>
    <h1>Situs Berita Aksesibel</h1>
    <nav aria-label="Navigasi utama">
      <ul>
        <li><a href="#">Beranda</a></li>
        <li><a href="#">Berita</a></li>
        <li><a href="#">Olahraga</a></li>
        <li><a href="#">Hiburan</a></li>
        <li><a href="#">Teknologi</a></li>
        <li><a href="#">Kontak</a></li>
      </ul>
    </nav>
  </header>

  <aside class="sidebar" aria-label="Navigasi sekunder">
    <h2>Menu Samping</h2>
    <ul>
      <li><a href="#">Profil</a></li>
      <li><a href="#">Pengaturan</a></li>
      <li><a href="#">Bantuan</a></li>
      <li><a href="#">Keluar</a></li>
    </ul>
  </aside>

  <!-- main-content adalah target skip link -->
  <main id="main-content" tabindex="-1">
    <h2>Konten Utama</h2>
    <article>
      <h3>Judul Artikel 1</h3>
      <p>Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.</p>
      <p>Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris nisi ut aliquip ex ea commodo consequat.</p>
    </article>
    <article>
      <h3>Judul Artikel 2</h3>
      <p>Duis aute irure dolor in reprehenderit in voluptate velit esse cillum dolore eu fugiat nulla pariatur.</p>
    </article>
  </main>

  <footer>
    <p>&copy; 2026 Situs Berita Aksesibel</p>
  </footer>
</body>
</html>
```

## Poin Penting
- Skip link harus menjadi elemen focusable pertama di halaman sehingga muncul saat pengguna menekan Tab pertama kali.
- Target skip link (biasanya `<main>`) harus memiliki `tabindex="-1"` agar bisa menerima fokus secara programatis.
- Gunakan CSS yang membuat skip link terlihat hanya saat difokus — jangan gunakan `display: none` atau `visibility: hidden` agar tetap dikenali screen reader.
