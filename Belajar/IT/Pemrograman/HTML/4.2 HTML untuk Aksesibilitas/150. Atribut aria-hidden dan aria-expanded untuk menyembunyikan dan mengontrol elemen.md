# Atribut aria-hidden dan aria-expanded untuk Menyembunyikan dan Mengontrol Elemen

## Analogi: Perpustakaan Digital

Di perpustakaan, ada ruangan yang tertutup tirai dan ada lemari yang terkunci. `aria-hidden` seperti memberi tahu pemandu: "ruangan ini ada di sini, tapi jangan dijelaskan karena tidak penting bagi pengunjung." Sedangkan `aria-expanded` seperti memberi tahu pemandu: "lemari ini sedang terbuka — isinya bisa dilihat," atau "lemari ini tertutup — jangan jelaskan isinya sekarang." Keduanya membantu pemandu memberikan informasi yang tepat pada waktu yang tepat.

## Penjelasan Detail

Atribut `aria-hidden` dan `aria-expanded` adalah dua atribut WAI-ARIA yang mengontrol bagaimana elemen dipersepsikan oleh teknologi bantu. `aria-hidden="true"` menyembunyikan elemen dari poin aksesibilitas (accessibility tree) tanpa menghilangkannya dari tampilan visual — berguna untuk elemen dekoratif, konten di luar layar, atau elemen yang tidak relevan bagi screen reader. Sebaliknya, `aria-hidden="false"` memastikan elemen terlihat oleh screen reader. Sementara itu, `aria-expanded` digunakan pada elemen yang dapat memperluas atau menyembunyikan konten, seperti tombol dropdown atau accordion. Nilai `true` menunjukkan panel atau konten sedang terbuka, `false` menunjukkan tertutup, dan `undefined` (tanpa atribut) menunjukkan bahwa elemen tidak dapat diperluas. Kedua atribut ini esensial untuk komponen interaktif agar screen reader dapat mengkomunikasikan status terkini kepada pengguna.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Contoh aria-hidden dan aria-expanded</title>
  <style>
    body { font-family: sans-serif; padding: 20px; }
    .accordion-btn { background: #007bff; color: white; padding: 10px; width: 100%; text-align: left; border: none; cursor: pointer; font-size: 16px; }
    .accordion-panel { padding: 10px; border: 1px solid #ccc; border-top: none; }
    .decorative-icon { margin-right: 8px; }
    .hidden-visually { position: absolute; width: 1px; height: 1px; padding: 0; margin: -1px; overflow: hidden; clip: rect(0,0,0,0); border: 0; }
  </style>
</head>
<body>
  <h1>Contoh aria-hidden dan aria-expanded</h1>

  <!-- aria-hidden pada ikon dekoratif -->
  <p>
    <span class="decorative-icon" aria-hidden="true">&#x2B50;</span>
    Selamat datang di halaman aksesibel!
  </p>

  <!-- Accordion dengan aria-expanded -->
  <h2>FAQ</h2>

  <div class="accordion">
    <button class="accordion-btn" aria-expanded="false" aria-controls="panel1" id="btn1">
      Apa itu HTML?
    </button>
    <div id="panel1" class="accordion-panel" hidden role="region" aria-labelledby="btn1">
      <p>HTML adalah bahasa markup untuk membuat struktur halaman web.</p>
    </div>
  </div>

  <div class="accordion">
    <button class="accordion-btn" aria-expanded="false" aria-controls="panel2" id="btn2">
      Apa itu CSS?
    </button>
    <div id="panel2" class="accordion-panel" hidden role="region" aria-labelledby="btn2">
      <p>CSS digunakan untuk mendesain tampilan halaman web.</p>
    </div>
  </div>

  <script>
    document.querySelectorAll('.accordion-btn').forEach(btn => {
      btn.addEventListener('click', function() {
        const panel = document.getElementById(this.getAttribute('aria-controls'));
        const isExpanded = this.getAttribute('aria-expanded') === 'true';
        this.setAttribute('aria-expanded', !isExpanded);
        panel.hidden = isExpanded;
      });
    });
  </script>

  <!-- Spacer dekoratif yang benar-benar tidak relevan -->
  <div aria-hidden="true" style="height: 20px;"></div>
</body>
</html>
```

## Poin Penting
- `aria-hidden="true"` menghapus elemen dari accessibility tree tetapi tetap menampilkannya secara visual — gunakan hanya untuk konten dekoratif atau tidak relevan.
- `aria-expanded` harus diperbarui secara dinamis dengan JavaScript setiap kali status expand berubah.
- Jangan gunakan `aria-hidden` pada elemen yang fokusnya dapat diterima (focusable) karena akan membuat pengguna keyboard kehilangan arah.
