# Web App Manifest sebagai file JSON untuk konfigurasi PWA

## Analogi: Perpustakaan Digital

Web App Manifest ibarat kartu identitas resmi sebuah perpustakaan digital yang dipajang di pintu masuk. Kartu ini memberi tahu pengunjung nama perpustakaan, ikon yang mewakilinya, warna tema yang digunakan, dan bagaimana perpustakaan akan ditampilkan di layar utama pengunjung. Sama seperti kartu identitas yang memudahkan orang mengenali dan menemukan kembali perpustakaan, manifest memungkinkan PWA diinstal di perangkat pengguna dan muncul seperti aplikasi native. Tanpa kartu identitas yang jelas, perpustakaan akan sulit dikenali dan diakses kembali.

## Penjelasan Detail

Web App Manifest adalah file JSON bernama `manifest.json` yang menyediakan metadata tentang aplikasi web. File ini memungkinkan PWA untuk diinstal di layar utama perangkat pengguna, memberikan pengalaman seperti aplikasi native. Properti penting dalam manifest meliputi `name`, `short_name`, `icons` (berbagai ukuran), `start_url`, `display` (fullscreen, standalone, minimal-ui, browser), `theme_color`, `background_color`, dan `orientation`. Browser membaca file ini saat pengguna mengunjungi situs dan menggunakannya untuk menentukan bagaimana aplikasi ditampilkan saat diinstal. Manifest juga mendukung properti seperti `scope` untuk membatasi halaman mana yang termasuk dalam aplikasi dan `categories` untuk klasifikasi di app store. Validasi manifest dapat dilakukan melalui Lighthouse atau langsung di Chrome DevTools.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Aplikasi Catatan</title>
  <link rel="manifest" href="manifest.json">
  <meta name="theme-color" content="#4A90D9">
</head>
<body>
  <h1>Catatan Saya</h1>
  <p>Aplikasi ini dapat diinstal di perangkat Anda.</p>
  <script>
    if ('serviceWorker' in navigator) {
      navigator.serviceWorker.register('sw.js');
    }
  </script>
</body>
</html>
```

```json
{
  "name": "Aplikasi Catatan Pribadi",
  "short_name": "Catatan",
  "description": "Aplikasi mencatat dengan dukungan offline",
  "start_url": "/index.html",
  "scope": "/",
  "display": "standalone",
  "background_color": "#FFFFFF",
  "theme_color": "#4A90D9",
  "orientation": "portrait-primary",
  "icons": [
    {
      "src": "/icons/icon-192.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "/icons/icon-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "maskable"
    }
  ],
  "categories": ["productivity", "utilities"]
}
```

## Poin Penting
- Web App Manifest wajib untuk membuat PWA yang dapat diinstal (installable).
- Properti `display: standalone` menghilangkan UI browser dan memberikan nuansa aplikasi native.
- Ikon harus disediakan dalam berbagai ukuran untuk mendukung berbagai perangkat dan konteks.
