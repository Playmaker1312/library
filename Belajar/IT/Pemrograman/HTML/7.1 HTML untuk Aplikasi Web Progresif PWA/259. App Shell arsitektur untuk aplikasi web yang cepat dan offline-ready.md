# App Shell arsitektur untuk aplikasi web yang cepat dan offline-ready

## Analogi: Perpustakaan Digital

App Shell seperti struktur fisik perpustakaan itu sendiri: rak buku, meja baca, pintu masuk, dan pencahayaan. Ketika pengunjung datang, mereka langsung melihat kerangka perpustakaan yang utuh meskipun buku-buku di rak belum semuanya terisi. Kerangka ini dimuat sekali dan di-cache, sehingga kunjungan berikutnya terasa instan. Konten buku yang ada di rak bisa diisi kemudian secara bertahap. Pengunjung tidak perlu menunggu seluruh perpustakaan dibangun dari awal setiap kali datang.

## Penjelasan Detail

App Shell Architecture adalah pendekatan desain PWA di mana shell aplikasi (HTML, CSS, JavaScript minimal) dimuat dan di-cache terlebih dahulu, sementara konten dimuat secara dinamis. Shell aplikasi mencakup navigasi utama, header, footer, dan struktur UI yang konsisten di seluruh halaman. Pendekatan ini memastikan aplikasi terasa cepat karena shell langsung ditampilkan dari cache, kemudian konten diisi melalui request API. App Shell sangat efektif untuk aplikasi dengan navigasi yang kompleks tetapi konten yang sering berubah, seperti email client, chat apps, atau dashboard. Implementasi App Shell memerlukan Service Worker untuk pre-cache shell saat install dan strategi Network First untuk konten dinamis. Pengguna mendapatkan pengalaman seperti aplikasi native dengan loading instan dan kemampuan offline untuk struktur dasar aplikasi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Aplikasi Surat</title>
  <link rel="stylesheet" href="shell.css">
  <link rel="manifest" href="manifest.json">
</head>
<body>
  <!-- App Shell -->
  <header class="app-header">
    <h1>Kotak Surat</h1>
    <nav>
      <a href="#inbox" onclick="muatKonten('inbox')">Inbox</a>
      <a href="#sent" onclick="muatKonten('sent')">Terkirim</a>
      <a href="#draft" onclick="muatKonten('draft')">Draft</a>
    </nav>
  </header>

  <main id="konten-utama">
    <div class="loader">Memuat...</div>
  </main>

  <footer class="app-footer">
    <p>Aplikasi Surat v1.0</p>
  </footer>

  <script>
    const kontenUtama = document.getElementById('konten-utama');

    async function muatKonten(folder) {
      kontenUtama.innerHTML = '<div class="loader">Memuat...</div>';
      try {
        const res = await fetch('/api/surat?folder=' + folder);
        const data = await res.json();
        renderSurat(data);
      } catch (err) {
        kontenUtama.innerHTML = '<p>Gagal memuat. Periksa koneksi.</p>';
      }
    }

    function renderSurat(suratList) {
      kontenUtama.innerHTML = suratList.map(s => `
        <article class="surat-item">
          <h3>${s.pengirim}</h3>
          <p>${s.perihal}</p>
          <small>${s.tanggal}</small>
        </article>
      `).join('');
    }

    // Muat inbox saat awal
    muatKonten('inbox');

    if ('serviceWorker' in navigator) {
      navigator.serviceWorker.register('sw-shell.js');
    }
  </script>
</body>
</html>
```

```javascript
// sw-shell.js
const SHELL_CACHE = 'shell-v1';
const SHELL_URLS = [
  '/',
  '/index.html',
  '/shell.css',
  '/app.js',
  '/manifest.json',
  '/icons/icon-192.png',
  '/icons/icon-512.png'
];

self.addEventListener('install', event => {
  event.waitUntil(
    caches.open(SHELL_CACHE).then(cache => {
      return cache.addAll(SHELL_URLS);
    })
  );
});

self.addEventListener('activate', event => {
  event.waitUntil(
    caches.keys().then(keys =>
      Promise.all(keys.filter(k => k !== SHELL_CACHE).map(k => caches.delete(k)))
    )
  );
});

self.addEventListener('fetch', event => {
  const url = new URL(event.request.url);

  // Shell: kirim dari cache langsung
  if (SHELL_URLS.includes(url.pathname)) {
    event.respondWith(caches.match(event.request));
    return;
  }

  // Konten API: network first
  if (url.pathname.startsWith('/api/')) {
    event.respondWith(networkFirst(event.request));
    return;
  }

  // Fallback: network first
  event.respondWith(networkFirst(event.request));
});

async function networkFirst(request) {
  try {
    const response = await fetch(request);
    return response;
  } catch (err) {
    const cached = await caches.match(request);
    if (cached) return cached;
    return new Response(JSON.stringify({ error: 'offline' }), {
      headers: { 'Content-Type': 'application/json' }
    });
  }
}
```

## Poin Penting
- App Shell adalah minimal HTML, CSS, JS yang di-cache untuk loading instan.
- Konten dimuat secara dinamis setelah shell ditampilkan, meningkatkan perceived performance.
- Cocok untuk aplikasi dengan UI kompleks dan konten dinamis seperti dashboard dan email client.
