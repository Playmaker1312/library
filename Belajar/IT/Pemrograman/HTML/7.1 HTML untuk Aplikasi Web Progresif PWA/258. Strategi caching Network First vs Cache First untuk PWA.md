# Strategi caching Network First vs Cache First untuk PWA

## Analogi: Perpustakaan Digital

Network First dan Cache First seperti dua kebijakan berbeda yang diterapkan pustakawan dalam melayani permintaan buku. Dengan Cache First, pustakawan selalu mengecek rak lokal terlebih dahulu. Jika buku ada, langsung diberikan tanpa perlu ke gudang pusat. Dengan Network First, pustakawan tetap pergi ke gudang pusat untuk memastikan mendapatkan edisi terbaru, dan hanya menggunakan rak lokal jika gudang pusat tutup. Cache First cocok untuk buku referensi yang jarang berubah. Network First cocok untuk buku bestseller yang sering terbit edisi baru.

## Penjelasan Detail

Cache First adalah strategi di mana Service Worker mencari respons dari cache terlebih dahulu. Jika ditemukan, respons dikembalikan tanpa request jaringan. Jika tidak ada, request dikirim ke jaringan dan hasilnya disimpan ke cache. Strategi ini sangat cocok untuk resource statis seperti CSS, JavaScript, font, dan gambar yang jarang berubah. Keuntungan utamanya adalah kecepatan dan kemampuan offline penuh. Kerugiannya adalah pengguna mungkin melihat konten usang jika cache tidak diperbarui. Network First adalah kebalikannya: Service Worker mencoba fetch dari jaringan terlebih dahulu. Jika berhasil, respons disimpan ke cache dan dikembalikan. Jika gagal (offline), fallback ke cache. Strategi ini cocok untuk halaman HTML utama, data API, atau konten yang memerlukan kesegaran. Kerugiannya adalah ketergantungan pada koneksi yang baik untuk performa optimal. Banyak PWA menggunakan kombinasi kedua strategi untuk resource berbeda.

```html
  <title>Network First vs Cache First</title>
</head>
<body>
  <h1>Demo Strategi Caching</h1>
  <p>Buka DevTools > Network, lalu reload untuk melihat perbedaan.</p>
  <section>
    <h2>Resource Cache First</h2>
    <img src="https://via.placeholder.com/150/4A90D9/FFFFFF?text=CF" alt="Cache First">
    <link rel="stylesheet" href="style-cf.css">
  </section>
  <section>
    <h2>Resource Network First</h2>
    <div id="api-data">Memuat data...</div>
  </section>
  <script>
    if ('serviceWorker' in navigator) {
      navigator.serviceWorker.register('sw-compare.js')
        .then(() => console.log('SW terdaftar'))
        .catch(err => console.error('SW gagal:', err));
    }

    fetch('/api/artikel-terbaru')
      .then(res => res.json())
      .then(data => {
        document.getElementById('api-data').textContent =
          'Data terbaru: ' + JSON.stringify(data);
      })
      .catch(() => {
        document.getElementById('api-data').textContent =
          'Gagal muat data (offline?)';
      });
  </script>
</body>
</html>
```

```javascript
// sw-compare.js
const CACHE_STATIC = 'static-v1';
const CACHE_DINAMIS = 'dinamis-v1';

const URL_CACHE_FIRST = [
  '/style-cf.css',
  'https://via.placeholder.com/150/4A90D9/FFFFFF?text=CF'
];

self.addEventListener('install', event => {
  event.waitUntil(
    caches.open(CACHE_STATIC).then(cache =>
      cache.addAll(URL_CACHE_FIRST)
    )
  );
});

self.addEventListener('activate', event => {
  event.waitUntil(
    caches.keys().then(keys =>
      Promise.all(
        keys.filter(k => k !== CACHE_STATIC && k !== CACHE_DINAMIS)
          .map(k => caches.delete(k))
      )
    )
  );
});

self.addEventListener('fetch', event => {
  const url = new URL(event.request.url);

  // Cache First untuk resource statis
  if (URL_CACHE_FIRST.some(u => url.href.includes(u))) {
    event.respondWith(cacheFirst(event.request));
    return;
  }

  // Network First untuk API dan halaman HTML
  if (url.pathname.startsWith('/api/') || url.pathname.endsWith('.html')) {
    event.respondWith(networkFirst(event.request));
    return;
  }

  // Default: Network First
  event.respondWith(networkFirst(event.request));
});

async function cacheFirst(request) {
  const cached = await caches.match(request);
  if (cached) return cached;
  const response = await fetch(request);
  const clone = response.clone();
  caches.open(CACHE_DINAMIS).then(cache => cache.put(request, clone));
  return response;
}

async function networkFirst(request) {
  try {
    const response = await fetch(request);
    const clone = response.clone();
    caches.open(CACHE_DINAMIS).then(cache => cache.put(request, clone));
    return response;
  } catch (err) {
    const cached = await caches.match(request);
    if (cached) return cached;
    return new Response('Konten tidak tersedia secara offline', {
      status: 503,
      headers: { 'Content-Type': 'text/plain' }
    });
  }
}
```

## Poin Penting
- Cache First: cepat dan offline-ready, risiko konten usang; cocok untuk resource statis.
- Network First: konten selalu segar, butuh koneksi baik; cocok untuk data dinamis.
- Kombinasikan kedua strategi berdasarkan jenis resource untuk performa optimal PWA.
