# Cache API untuk menyimpan resource statis dan dinamis di Service Worker

## Analogi: Perpustakaan Digital

Cache API seperti rak buku khusus di perpustakaan digital yang digunakan pustakawan untuk menyimpan salinan buku-buku favorit. Rak ini terbagi menjadi beberapa bagian: ada rak untuk buku referensi yang jarang berubah (cache statis) dan rak untuk buku pinjaman terbaru yang sering diperbarui (cache dinamis). Pustakawan bisa dengan cepat mengambil buku dari rak ini tanpa harus pergi ke gudang pusat setiap kali. Ketika rak penuh atau buku sudah usang, pustakawan bisa membersihkan dan menggantinya dengan yang baru.

## Penjelasan Detail

Cache API adalah mekanisme penyimpanan key-value di Service Worker yang memungkinkan penyimpanan pasangan Request-Response. Cache API berbeda dengan HTTP Cache karena memberikan kontrol penuh kepada pengembang melalui JavaScript. Resource statis seperti file HTML, CSS, JavaScript, dan gambar sering di-cache saat event `install` untuk memastikan aplikasi berfungsi offline. Cache dinamis digunakan untuk menyimpan respons dari API atau konten yang sering berubah, biasanya dilakukan saat event `fetch`. Metode utama Cache API meliputi `caches.open()`, `cache.put()`, `cache.add()`, `cache.addAll()`, `cache.match()`, dan `cache.delete()`. Setiap cache memiliki nama unik yang memudahkan manajemen versi dan pembersihan cache lama. Cache API tidak terbatas pada request asal yang sama sehingga dapat digunakan untuk menyimpan resource dari CDN.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Demo Cache API</title>
</head>
<body>
  <h1>Manajemen Cache</h1>
  <button id="simpanBtn">Simpan ke Cache</button>
  <button id="ambilBtn">Ambil dari Cache</button>
  <button id="hapusBtn">Hapus Cache</button>
  <pre id="output"></pre>
  <script>
    const output = document.getElementById('output');
    function tulis(pesan) {
      output.textContent += pesan + '\n';
    }

    if ('caches' in window) {
      document.getElementById('simpanBtn').onclick = async () => {
        const cache = await caches.open('cache-demo-v1');
        await cache.add('/index.html');
        tulis('index.html disimpan ke cache');
      };

      document.getElementById('ambilBtn').onclick = async () => {
        const cache = await caches.open('cache-demo-v1');
        const response = await cache.match('/index.html');
        if (response) {
          const text = await response.text();
          tulis('Ditemukan di cache (' + text.length + ' karakter)');
        } else {
          tulis('Tidak ditemukan di cache');
        }
      };

      document.getElementById('hapusBtn').onclick = async () => {
        await caches.delete('cache-demo-v1');
        tulis('Cache cache-demo-v1 dihapus');
      };
    } else {
      tulis('Cache API tidak didukung');
    }
  </script>
</body>
</html>
```

## Poin Penting
- Cache statis diisi saat `install`, cache dinamis diisi saat `fetch` berdasarkan kebutuhan.
- Setiap cache adalah penyimpanan terpisah dengan nama unik untuk memudahkan versi.
- Cache API menyimpan respons HTTP lengkap termasuk header, bukan hanya body.
