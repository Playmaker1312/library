# Lighthouse audit untuk PWA dan cara memenuhi kriteria installable

## Analogi: Perpustakaan Digital

Lighthouse seperti inspektur perpustakaan yang datang untuk mengecek apakah perpustakaan digital memenuhi standar kelayakan. Inspektur memeriksa apakah perpustakaan memiliki kartu identitas yang jelas (Web App Manifest), pustakawan yang siaga (Service Worker), koneksi yang aman (HTTPS), dan pengalaman yang memadai di berbagai perangkat. Jika semua kriteria terpenuhi, perpustakaan dinyatakan layak untuk dipasang di layar utama pengunjung. Inspektur juga memberikan skor dan rekomendasi perbaikan untuk setiap kategori.

## Penjelasan Detail

Lighthouse adalah alat audit otomatis dari Chrome DevTools yang mengukur kualitas PWA dalam lima kategori: Performance, Accessibility, Best Practices, SEO, dan PWA. Untuk memenuhi kriteria installable (dapat diinstal), PWA harus lulus audit PWA Lighthouse khususnya pada cek "Installable". Kriteria utamanya meliputi: memiliki Web App Manifest yang valid dengan properti `name`, `short_name`, `icons` (termasuk 192px dan 512px), `start_url`, dan `display` (standalone/minimal-ui). Service Worker harus terdaftar dan merespons event `fetch` dengan kode status 200. Semua halaman harus diakses melalui HTTPS. Aplikasi harus merespons dengan cepat di jaringan lambat dan memiliki custom splash screen. Lighthouse juga memeriksa apakah navigasi dapat di-cache oleh Service Worker dan apakah halaman memiliki meta tag viewport yang benar.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Aplikasi To-Do PWA</title>
  <meta name="description" content="Aplikasi daftar tugas dengan dukungan offline">
  <meta name="theme-color" content="#6366F1">
  <link rel="manifest" href="manifest.json">
  <link rel="icon" href="/icons/favicon.ico" type="image/x-icon">
  <link rel="apple-touch-icon" href="/icons/icon-192.png">
  <meta name="apple-mobile-web-app-capable" content="yes">
  <meta name="apple-mobile-web-app-status-bar-style" content="default">
</head>
<body>
  <h1>Daftar Tugas Saya</h1>
  <form id="todoForm">
    <input type="text" id="todoInput" placeholder="Tambah tugas..." required>
    <button type="submit">Tambah</button>
  </form>
  <ul id="todoList"></ul>

  <script>
    // Daftarkan Service Worker
    if ('serviceWorker' in navigator) {
      window.addEventListener('load', () => {
        navigator.serviceWorker.register('sw-lighthouse.js')
          .then(reg => console.log('SW terdaftar:', reg.scope))
          .catch(err => console.log('SW gagal:', err));
      });
    }

    // Aplikasi To-Do sederhana
    const form = document.getElementById('todoForm');
    const input = document.getElementById('todoInput');
    const list = document.getElementById('todoList');

    function renderTodos() {
      const todos = JSON.parse(localStorage.getItem('todos') || '[]');
      list.innerHTML = todos.map((t, i) =>
        `<li>${t} <button onclick="hapusTodo(${i})">x</button></li>`
      ).join('');
    }

    function tambahTodo(e) {
      e.preventDefault();
      const todos = JSON.parse(localStorage.getItem('todos') || '[]');
      todos.push(input.value);
      localStorage.setItem('todos', JSON.stringify(todos));
      input.value = '';
      renderTodos();
    }

    window.hapusTodo = (index) => {
      const todos = JSON.parse(localStorage.getItem('todos') || '[]');
      todos.splice(index, 1);
      localStorage.setItem('todos', JSON.stringify(todos));
      renderTodos();
    };

    form.addEventListener('submit', tambahTodo);
    renderTodos();

    // Deteksi apakah aplikasi berjalan standalone (diinstal)
    if (window.matchMedia('(display-mode: standalone)').matches) {
      document.body.classList.add('mode-installed');
    }
  </script>
</body>
</html>
```

```javascript
// sw-lighthouse.js
const CACHE_NAME = 'todo-cache-v1';
const URLS_TO_CACHE = ['/', '/index.html', '/manifest.json'];

self.addEventListener('install', event => {
  event.waitUntil(
    caches.open(CACHE_NAME).then(cache => cache.addAll(URLS_TO_CACHE))
  );
});

self.addEventListener('fetch', event => {
  event.respondWith(
    caches.match(event.request).then(response =>
      response || fetch(event.request)
    )
  );
});
```

## Poin Penting
- Kriteria installable Lighthouse: manifest valid, Service Worker, HTTPS, viewport, respons cepat.
- Ikon minimal 192px dan 512px wajib untuk memenuhi syarat installable.
- Jalankan Lighthouse di Chrome DevTools untuk mendapatkan skor dan rekomendasi perbaikan PWA.
