# Konsep Progressive Web App dan Peran HTML di Dalamnya

## Analogi: Perpustakaan Digital

Bayangkan sebuah perpustakaan yang bisa:
- Dibuka **tanpa internet** (buku sudah di-cache)
- Di-**install** di HP seperti aplikasi
- Mengirim **notifikasi** saat buku favorit tersedia
- Loading **sangat cepat** karena sudah disimpan

Ini adalah **Progressive Web App (PWA)** — website yang berperilaku seperti aplikasi native.

## Penjelasan Detail

PWA adalah website yang menggunakan teknologi web modern untuk memberikan **pengalaman seperti aplikasi**.

### Komponen PWA
1. **HTTPS** — koneksi aman (wajib)
2. **Web App Manifest** — file JSON untuk instalasi
3. **Service Worker** — JavaScript untuk cache offline
4. **Responsif** — bekerja di semua ukuran layar

### Peran HTML
HTML menghubungkan komponen PWA:
```html
<!-- Manifest untuk instalasi -->
<link rel="manifest" href="manifest.json">

<!-- Theme color untuk browser chrome -->
<meta name="theme-color" content="#2c3e50">

<!-- Ikon untuk berbagai ukuran -->
<link rel="apple-touch-icon" href="icon-192.png">

<!-- Register service worker -->
<script>
  if ('serviceWorker' in navigator) {
    navigator.serviceWorker.register('/sw.js');
  }
</script>
```

### Manfaat PWA
- Bisa diakses **offline**
- **Cepat** — cache menyimpan sumber daya
- Bisa di-**install** di home screen
- **Notifikasi push**
- **Ringan** — tidak sebesar aplikasi native

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <!-- PWA Components -->
    <link rel="manifest" href="manifest.json">
    <meta name="theme-color" content="#2c3e50">
    <meta name="apple-mobile-web-app-capable" content="yes">

    <!-- Icons -->
    <link rel="icon" href="icon-72.png">
    <link rel="apple-touch-icon" href="icon-192.png">

    <title>Perpustakaan Digital PWA</title>
  </head>
  <body>
    <h1>Perpustakaan Digital</h1>
    <p>Install aplikasi ini untuk akses offline!</p>

    <script>
      if ('serviceWorker' in navigator) {
        navigator.serviceWorker.register('sw.js');
      }
    </script>
  </body>
</html>
```

**File: manifest.json**
```json
{
  "name": "Perpustakaan Digital",
  "short_name": "Perpus Digital",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#2c3e50",
  "icons": [
    { "src": "icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "icon-512.png", "sizes": "512x512", "type": "image/png" }
  ]
}
```

## Poin Penting
- PWA = website yang **berfungsi seperti aplikasi**
- Komponen: **HTTPS + Manifest + Service Worker**
- HTML menghubungkan semua komponen PWA
- Bisa **offline**, **installable**, **fast**
- Service Worker = JavaScript untuk caching dan push notification
