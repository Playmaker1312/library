# Push Notification API dengan Service Worker untuk notifikasi

## Analogi: Perpustakaan Digital

Push Notification seperti sistem pengumuman perpustakaan yang mengirim pemberitahuan ke anggota. Ketika buku baru tiba atau batas peminjaman hampir habis, perpustakaan mengirimkan pesan ke anggota meskipun mereka sedang tidak berada di perpustakaan. Sistem ini memungkinkan perpustakaan berkomunikasi secara proaktif dengan anggotanya. Pesan akan tetap tersampaikan meskipun anggota sedang sibuk atau aplikasi perpustakaannya tidak sedang dibuka.

## Penjelasan Detail

Push Notification API terdiri dari dua bagian: Push API untuk menerima pesan dari server di Service Worker, dan Notification API untuk menampilkan notifikasi ke pengguna. Push dimulai dengan berlangganan ke push service menggunakan `registration.pushManager.subscribe()`. Server kemudian dapat mengirim pesan ke push service yang akan diteruskan ke browser. Saat pesan push diterima, event `push` dibangkitkan di Service Worker yang kemudian menampilkan notifikasi menggunakan `registration.showNotification()`. Pengguna dapat berinteraksi dengan notifikasi melalui event `notificationclick`. Proses ini memerlukan protokol HTTPS dan generated VAPID keys untuk autentikasi server. Push messages biasanya dienkripsi untuk keamanan. Browser membatasi payload push hingga maksimal 4KB sehingga disarankan hanya mengirim data minimal.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Push Notification Demo</title>
</head>
<body>
  <h1>Push Notification</h1>
  <button id="langgananBtn">Langganan Notifikasi</button>
  <pre id="status"></pre>

  <script>
    const status = document.getElementById('status');
    const langgananBtn = document.getElementById('langgananBtn');

    async function inisialisasi() {
      if (!('serviceWorker' in navigator) || !('PushManager' in window)) {
        status.textContent = 'Push Notification tidak didukung browser ini';
        return;
      }

      const reg = await navigator.serviceWorker.register('sw-push.js');
      status.textContent = 'Service Worker terdaftar';

      if (Notification.permission === 'denied') {
        status.textContent = 'Izin notifikasi ditolak';
        return;
      }

      if (Notification.permission === 'granted') {
        langgananBtn.disabled = true;
        langgananBtn.textContent = 'Sudah berlangganan';
      }

      langgananBtn.onclick = async () => {
        const permission = await Notification.requestPermission();
        if (permission !== 'granted') {
          status.textContent = 'Izin tidak diberikan';
          return;
        }

        const subscription = await reg.pushManager.subscribe({
          userVisibleOnly: true,
          applicationServerKey: urlBase64ToUint8Array(
            'BEl62iUYgUivxIkv69yViEuiBIa-Ib9-SkvMeAtA3LFgDzkrxZJj7g5Z4k2RjR0kHqSrlFhRqkGjcD7Hv6sR1qI'
          )
        });

        status.textContent = 'Berlangganan: ' + JSON.stringify(subscription);
        // Kirim subscription ke server
        await fetch('/api/subscribe', {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify(subscription)
        });
      };
    }

    function urlBase64ToUint8Array(base64String) {
      const padding = '='.repeat((4 - base64String.length % 4) % 4);
      const base64 = (base64String + padding)
        .replace(/\-/g, '+')
        .replace(/_/g, '/');
      const rawData = window.atob(base64);
      return Uint8Array.from([...rawData].map(ch => ch.charCodeAt(0)));
    }

    inisialisasi();
  </script>
</body>
</html>
```

```javascript
// sw-push.js
self.addEventListener('install', () => self.skipWaiting());
self.addEventListener('activate', event => event.waitUntil(clients.claim()));

self.addEventListener('push', event => {
  let data = { title: 'Notifikasi Baru', body: 'Anda mendapat pesan baru' };
  if (event.data) {
    try {
      data = event.data.json();
    } catch {
      data.body = event.data.text();
    }
  }

  event.waitUntil(
    self.registration.showNotification(data.title, {
      body: data.body,
      icon: '/icon-192.png',
      badge: '/badge-72.png',
      vibrate: [200, 100, 200],
      data: { url: data.url || '/' }
    })
  );
});

self.addEventListener('notificationclick', event => {
  event.notification.close();
  event.waitUntil(
    clients.openWindow(event.notification.data.url || '/')
  );
});
```

## Poin Penting
- Push Notification memerlukan VAPID keys untuk autentikasi server dan push service.
- Event `push` diterima Service Worker, event `notificationclick` untuk interaksi pengguna.
- Payload push terbatas (~4KB), kirim data minimal dan ambil detail dari server jika perlu.
