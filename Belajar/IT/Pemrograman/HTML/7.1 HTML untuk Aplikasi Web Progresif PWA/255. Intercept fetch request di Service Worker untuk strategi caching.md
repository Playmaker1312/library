# Intercept fetch request di Service Worker untuk strategi caching

## Analogi: Perpustakaan Digital

Intercept fetch request seperti pustakawan yang menyambut setiap pengunjung di pintu masuk dan memutuskan cara terbaik untuk memberikan buku yang diminta. Jika pengunjung meminta buku yang sudah ada di rak lokal (cache), pustakawan bisa langsung memberikannya. Jika buku tidak tersedia, pustakawan bisa pergi ke gudang pusat (server) untuk mengambilnya. Pustakawan juga bisa menerapkan aturan: untuk buku populer, selalu ambil yang terbaru dari gudang; untuk buku referensi, ambil dari rak lokal saja. Setiap strategi memiliki kelebihan tergantung jenis buku dan situasi pengunjung.

## Penjelasan Detail

Event `fetch` di Service Worker memungkinkan pengembang mencegat setiap request HTTP yang dibuat oleh halaman. Dengan metode `event.respondWith()`, Service Worker dapat mengembalikan respons dari cache, dari jaringan, atau kombinasi keduanya. Strategi caching yang umum meliputi: Cache Only (hanya dari cache), Network Only (hanya dari jaringan), Cache First (cache dulu, fallback ke jaringan), Network First (jaringan dulu, fallback ke cache), Stale While Revalidate (cache langsung, update cache di latar belakang), dan Cache and Network Race (ambil dari keduanya, mana yang lebih cepat). Pemilihan strategi tergantung pada jenis resource: untuk gambar profil mungkin Cache First, untuk data real-time mungkin Network First. Service Worker juga dapat memodifikasi request, menambahkan header, atau bahkan membuat respons baru sepenuhnya. Kemampuan ini memberikan kontrol penuh atas perilaku jaringan aplikasi web.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Strategi Caching</title>
</head>
<body>
  <h1>Demo Strategi Caching</h1>
  <div>
    <button onclick="fetchData('cache-first')">Cache First</button>
    <button onclick="fetchData('network-first')">Network First</button>
    <button onclick="fetchData('stale-revalidate')">Stale While Revalidate</button>
  </div>
  <pre id="hasil"></pre>
  <script>
    const hasil = document.getElementById('hasil');

    async function fetchData(strategi) {
      hasil.textContent = 'Mengambil data dengan strategi: ' + strategi + '\n';
      try {
        const res = await fetch('/api/data?strategi=' + strategi);
        const data = await res.json();
        hasil.textContent += JSON.stringify(data, null, 2);
      } catch (err) {
        hasil.textContent += 'Error: ' + err.message;
      }
    }

    if ('serviceWorker' in navigator) {
      navigator.serviceWorker.register('sw-strategi.js');
    }
  </script>
</body>
</html>
```

```javascript
// sw-strategi.js
const CACHE_NAME = 'strategi-cache-v1';

self.addEventListener('install', () => self.skipWaiting());
self.addEventListener('activate', event => {
  event.waitUntil(clients.claim());
});

self.addEventListener('fetch', event => {
  const url = new URL(event.request.url);
  const strategi = url.searchParams.get('strategi') || 'cache-first';

  if (strategi === 'cache-first') {
    event.respondWith(cacheFirst(event.request));
  } else if (strategi === 'network-first') {
    event.respondWith(networkFirst(event.request));
  } else if (strategi === 'stale-revalidate') {
    event.respondWith(staleWhileRevalidate(event.request));
  }
});

async function cacheFirst(request) {
  const cached = await caches.match(request);
  return cached || fetch(request).then(response => {
    const clone = response.clone();
    caches.open(CACHE_NAME).then(cache => cache.put(request, clone));
    return response;
  });
}

async function networkFirst(request) {
  try {
    const response = await fetch(request);
    const clone = response.clone();
    caches.open(CACHE_NAME).then(cache => cache.put(request, clone));
    return response;
  } catch (err) {
    const cached = await caches.match(request);
    return cached || new Response('Offline', { status: 503 });
  }
}

async function staleWhileRevalidate(request) {
  const cache = await caches.open(CACHE_NAME);
  const cached = await cache.match(request);
  const fetchPromise = fetch(request).then(response => {
    cache.put(request, response.clone());
    return response;
  });
  return cached || (await fetchPromise);
}
```

## Poin Penting
- Strategi caching dipilih berdasarkan jenis resource dan kebutuhan aplikasi.
- Cache First cocok untuk resource statis, Network First untuk data yang sering berubah.
- Stale While Revalidate memberikan keseimbangan antara kecepatan dan kesegaran data.
