# Atribut scope pada th untuk Menentukan Apakah Header untuk Kolom atau Baris

## Analogi: Perpustakaan Digital

Bayangkan **label rak** di perpustakaan. Ada dua jenis label:
- **Label di atas** kolom rak: "Fiksi", "Non Fiksi", "Sains" — ini `scope="col"`
- **Label di samping** baris rak: "Lantai 1", "Lantai 2" — ini `scope="row"`

`scope` memberitahu screen reader apakah header itu milik **kolom** atau **baris**. Ini penting untuk aksesibilitas — pengguna tunanetra bisa memahami struktur tabel.

## Penjelasan Detail

Atribut `scope` pada `<th>` menentukan **arah hubungan** header dengan data.

### Nilai `scope`
| Nilai | Arti | Contoh |
|-------|------|--------|
| `col` | Header untuk **kolom** (paling umum) | Header di baris pertama |
| `row` | Header untuk **baris** | Header di kolom pertama |
| `colgroup` | Header untuk **grup kolom** | colspan beberapa kolom |
| `rowgroup` | Header untuk **grup baris** | rowspan beberapa baris |
| `auto` | Browser menentukan (default) | Terserah browser |

### Visual
```
scope="col" → Header di ATAS, untuk kolom di bawahnya
     ↓
  | Judul | Penulis | ← scope="col"
  |-------|---------|
  | Buku  | Andrea  |

scope="row" → Header di SAMPING, untuk baris di kanannya
  | Kategori | Fiksi     | ← scope="row" untuk "Kategori"
  |          | Non Fiksi |
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Scope Attribute</title>
    <style>
      table, th, td { border: 1px solid #333; border-collapse: collapse; }
      th, td { padding: 10px; }
      th { background: #3498db; color: white; }
    </style>
  </head>
  <body>
    <h1>Data Inventaris Perpustakaan</h1>

    <table>
      <thead>
        <tr>
          <th scope="col">Kategori</th>
          <th scope="col">Judul Buku</th>
          <th scope="col">Penulis</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <th scope="row">Fiksi</th>
          <td>Laskar Pelangi</td>
          <td>Andrea Hirata</td>
        </tr>
        <tr>
          <th scope="row">Non Fiksi</th>
          <td>Sejarah Nusantara</td>
          <td>Bambang P.</td>
        </tr>
        <tr>
          <th scope="row">Sains</th>
          <td>Fisika untuk Semua</td>
          <td>Stephen H.</td>
        </tr>
      </tbody>
    </table>

    <p>Pada tabel di atas:</p>
    <ul>
      <li><code>scope="col"</code> → Header yang menjelaskan kolom (Kategori, Judul, Penulis)</li>
      <li><code>scope="row"</code> → Header yang menjelaskan baris (Fiksi, Non Fiksi, Sains)</li>
    </ul>
  </body>
</html>
```

## Poin Penting
- `scope` = menentukan **arah** hubungan header
- `scope="col"` = header **kolom** (paling umum)
- `scope="row"` = header **baris**
- Wajib untuk **aksesibilitas** — membantu screen reader
- Tidak mengubah tampilan visual, hanya semantik
