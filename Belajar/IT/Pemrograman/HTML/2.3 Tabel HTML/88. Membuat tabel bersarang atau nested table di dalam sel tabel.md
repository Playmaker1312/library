# Membuat Tabel Bersarang atau Nested Table di Dalam Sel Tabel

## Analogi: Perpustakaan Digital

Bayangkan sebuah **rak buku** yang di dalamnya ada **sub-rak** yang lebih kecil. Atau **kategori** yang berisi **sub-kategori**. Di HTML, ini disebut **tabel bersarang (nested table)** — tabel di dalam tabel.

Meskipun bisa dilakukan, nested table sebaiknya dihindari karena mempersulit layout dan aksesibilitas. Tapi kadang diperlukan untuk data kompleks.

## Penjelasan Detail

Nested table adalah **tabel yang diletakkan di dalam sel** tabel lain.

### Struktur
```html
<table>
  <tr>
    <td>
      <!-- Tabel di dalam sel -->
      <table>
        <tr>
          <th>Sub-header</th>
          <td>Sub-data</td>
        </tr>
      </table>
    </td>
  </tr>
</table>
```

### Aturan
- `<table>` lengkap diletakkan di dalam `<td>` atau `<th>`
- Tabel di dalam harus tetap valid (punya `<tr>`, `<td>`, dll)
- Styling terpisah — tabel dalam bisa diatur sendiri

### Kelemahan Nested Table
1. **Rumit** — HTML jadi susah dibaca dan dirawat
2. **Aksesibilitas buruk** — screen reader bingung
3. **Performa** — browser butuh lebih banyak resources
4. **Tidak responsif** — susah diatur untuk mobile

### Alternatif yang Lebih Baik
- Gunakan **CSS Grid** atau **Flexbox** untuk layout kompleks
- Gabungkan data yang sebenarnya jadi satu tabel dengan `colspan`/`rowspan`

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Nested Table</title>
    <style>
      table, th, td { border: 1px solid #333; border-collapse: collapse; }
      th, td { padding: 10px; }
      .inner-table { background: #f9f9f9; }
      .inner-table th { background: #666; color: white; }
    </style>
  </head>
  <body>
    <h1>Data Perpustakaan (Nested Table)</h1>

    <table>
      <thead>
        <tr>
          <th>Kategori</th>
          <th>Detail Buku</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <th>Fiksi</th>
          <td>
            <!-- Nested table -->
            <table class="inner-table" style="width: 100%;">
              <tr>
                <th>Judul</th>
                <th>Penulis</th>
              </tr>
              <tr>
                <td>Laskar Pelangi</td>
                <td>Andrea Hirata</td>
              </tr>
              <tr>
                <td>Bumi Manusia</td>
                <td>Pramoedya A.</td>
              </tr>
            </table>
          </td>
        </tr>
        <tr>
          <th>Non Fiksi</th>
          <td>
            <table class="inner-table" style="width: 100%;">
              <tr>
                <th>Judul</th>
                <th>Penulis</th>
              </tr>
              <tr>
                <td>Sejarah Nusantara</td>
                <td>Bambang P.</td>
              </tr>
            </table>
          </td>
        </tr>
      </tbody>
    </table>

    <p><strong>Catatan:</strong> Nested table sebaiknya dihindari. Gunakan <code>rowspan</code> atau CSS Grid untuk layout yang lebih baik.</p>
  </body>
</html>
```

## Poin Penting
- Nested table = **tabel di dalam tabel**
- Letak: di dalam `<td>` atau `<th>`
- **Sebaiknya dihindari** — rumit dan buruk untuk aksesibilitas
- Alternatif: `colspan`/`rowspan` atau CSS Grid/Flexbox
- Jika terpaksa pakai, pastikan styling jelas dan aksesibilitas tetap terjaga
