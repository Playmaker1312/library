# Atribut colspan untuk Menggabungkan Beberapa Kolom menjadi Satu Sel

## Analogi: Perpustakaan Digital

Bayangkan tabel inventaris perpustakaan yang punya **judul besar** yang mencakup beberapa kolom:

| Koleksi Buku Perpustakaan Digital         |
|----------------|----------------|-----------|
| Judul          | Penulis        | Tahun     |

"Koleksi Buku Perpustakaan Digital" membentang di **3 kolom** — ini adalah colspan.

`colspan` (column span) adalah atribut yang membuat satu sel **melebar ke beberapa kolom**.

## Penjelasan Detail

`colspan` digunakan pada `<th>` atau `<td>` untuk menggabungkan beberapa kolom.

### Format
```html
<td colspan="3">Teks ini melebar ke 3 kolom</td>
<th colspan="2">Header ini melebar ke 2 kolom</th>
```

### Cara Kerja
```html
<table border="1">
  <tr>
    <th colspan="3">Judul Besar (3 kolom)</th>  <!-- colspan=3 -->
  </tr>
  <tr>
    <td>Kolom 1</td>    <!-- kolom 1 -->
    <td>Kolom 2</td>    <!-- kolom 2 -->
    <td>Kolom 3</td>    <!-- kolom 3 -->
  </tr>
</table>
```

### Aturan Penting
- Jumlah `colspan` + kolom reguler harus sama per baris
- Jika tidak sama, tabel akan aneh (sel kelebihan)

```html
<tr>
  <th colspan="3">Gabung 3 kolom</th>  <!-- 3 kolom -->
</tr>
<tr>
  <td>A</td> <td>B</td> <td>C</td>     <!-- 3 kolom -->
</tr>
<tr>
  <td colspan="2">Gabung 2 kolom</td> <td>C</td>  <!-- total 3 -->
</tr>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Colspan</title>
    <style>
      table, th, td { border: 1px solid #333; border-collapse: collapse; }
      th, td { padding: 10px; text-align: center; }
    </style>
  </head>
  <body>
    <h1>Laporan Perpustakaan</h1>

    <table>
      <!-- Judul besar -->
      <tr>
        <th colspan="4">LAPORAN BULANAN PERPUSTAKAAN</th>
      </tr>

      <!-- Header kolom -->
      <tr>
        <th>Bulan</th>
        <th>Pengunjung</th>
        <th>Peminjaman</th>
        <th>Pengembalian</th>
      </tr>

      <!-- Data -->
      <tr>
        <td>Januari</td>
        <td>1.200</td>
        <td>850</td>
        <td>720</td>
      </tr>
      <tr>
        <td>Februari</td>
        <td>1.500</td>
        <td>920</td>
        <td>880</td>
      </tr>

      <!-- Total dengan colspan -->
      <tr>
        <td colspan="3"><strong>Total Pengunjung</strong></td>
        <td><strong>2.700</strong></td>
      </tr>
    </table>
  </body>
</html>
```

## Poin Penting
- `colspan="N"` = sel melebar **N kolom**
- Membantu membuat judul tabel yang membentang
- Jumlah kolom per baris harus **sama** (termasuk colspan)
- Bisa dipakai di `<th>` maupun `<td>`
- Angka minimum: 2 (colspan="1" tidak berguna)
