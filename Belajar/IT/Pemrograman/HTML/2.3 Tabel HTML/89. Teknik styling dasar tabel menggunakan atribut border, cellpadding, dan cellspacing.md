# Teknik Styling Dasar Tabel Menggunakan Atribut border cellpadding dan cellspacing

## Analogi: Perpustakaan Digital

Bayangkan **lembar laporan** yang dicetak. Laporan itu bisa diatur:
- **Border** → Garis pinggir tabel dan sel (seperti pigura foto)
- **Cellpadding** → Jarak antara isi sel dengan pinggir sel (seperti margin dalam bingkai)
- **Cellspacing** → Jarak antar sel (seperti celah antar pigura)

Atribut-atribut ini mengatur **tampilan dasar tabel**. Tapi catatan: atribut-atribut ini **usang (deprecated)** di HTML5 — lebih baik pakai CSS.

## Penjelasan Detail

### border
Memberi garis tepi pada tabel dan sel.
```html
<table border="1">  <!-- border="angka" — ketebalan garis -->
```
```html
<!-- CSS modern -->
<table style="border: 1px solid #333; border-collapse: collapse;">
```

### cellpadding
Jarak antara isi sel dengan batas sel (dalam pixel).
```html
<table cellpadding="10">
```
```html
<!-- CSS modern -->
<td style="padding: 10px;">
```

### cellspacing
Jarak antar sel (dalam pixel). Efeknya terlihat saat `border-collapse: separate`.
```html
<table cellspacing="5">
```
```html
<!-- CSS modern -->
<table style="border-collapse: separate; border-spacing: 5px;">
```

### border-collapse
Properti CSS kunci untuk tabel:
- `collapse` → border sel menyatu (seperti Excel modern)
- `separate` → border sel terpisah (seperti Excel lama)

```css
table { border-collapse: collapse; }
```

### Perbandingan
```html
<!-- HTML lama (usang) -->
<table border="1" cellpadding="10" cellspacing="5">
```

```html
<!-- CSS modern -->
<table style="border-collapse: separate; border-spacing: 5px;">
  <td style="padding: 10px; border: 1px solid #333;">
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Table Styling</title>
  </head>
  <body>
    <h1>Perbandingan Styling Tabel</h1>

    <h2>1. Atribut HTML (usang)</h2>
    <table border="3" cellpadding="15" cellspacing="5">
      <tr>
        <th>Judul</th>
        <th>Penulis</th>
      </tr>
      <tr>
        <td>Laskar Pelangi</td>
        <td>Andrea Hirata</td>
      </tr>
    </table>

    <h2>2. CSS Modern (border-collapse: collapse)</h2>
    <table style="border-collapse: collapse; border: 2px solid #333;">
      <tr>
        <th style="border: 2px solid #333; padding: 15px;">Judul</th>
        <th style="border: 2px solid #333; padding: 15px;">Penulis</th>
      </tr>
      <tr>
        <td style="border: 2px solid #333; padding: 15px;">Laskar Pelangi</td>
        <td style="border: 2px solid #333; padding: 15px;">Andrea Hirata</td>
      </tr>
    </table>

    <h2>3. CSS Modern (border-spacing)</h2>
    <table style="border-collapse: separate; border-spacing: 8px;">
      <tr>
        <th style="border: 2px solid #333; padding: 12px;">Judul</th>
        <th style="border: 2px solid #333; padding: 12px;">Penulis</th>
      </tr>
      <tr>
        <td style="border: 2px solid #333; padding: 12px;">Laskar Pelangi</td>
        <td style="border: 2px solid #333; padding: 12px;">Andrea Hirata</td>
      </tr>
    </table>
  </body>
</html>
```

## Poin Penting
- `border`, `cellpadding`, `cellspacing` = atribut **usang** (tapi masih berfungsi)
- Gunakan **CSS** sebagai pengganti: `border`, `padding`, `border-spacing`
- `border-collapse: collapse` = border menyatu (rapi)
- `border-collapse: separate` + `border-spacing` = border terpisah
- Untuk proyek modern, selalu gunakan CSS
