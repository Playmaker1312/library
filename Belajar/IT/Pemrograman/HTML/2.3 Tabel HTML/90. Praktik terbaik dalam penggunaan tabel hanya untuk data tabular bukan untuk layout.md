# Praktik Terbaik dalam Penggunaan Tabel Hanya untuk Data Tabular Bukan untuk Layout

## Analogi: Perpustakaan Digital

Bayangkan kamu ingin menata **ruang baca** perpustakaan. Kamu punya rak buku, meja baca, kursi, dan lampu.

- **Menggunakan tabel untuk layout** = Memaksakan semua perabot ke dalam grid kaku seperti lembar Excel. Rak buku harus di baris 1 kolom 1, meja di baris 1 kolom 2... Ini kaku, tidak fleksibel, dan susah diubah.
- **Menggunakan CSS untuk layout** = Menata perabot secara bebas dan fleksibel. Rak di kiri, meja di tengah, kursi di kanan. Bisa diubah kapan saja.

Di era HTML4, orang menggunakan `<table>` untuk **layout halaman** (menata sidebar, header, footer). Ini praktik **BURUK** karena:
1. Tabel untuk data, bukan desain
2. Tidak aksesibel
3. Tidak responsif
4. Susah dirawat

## Penjelasan Detail

### Kapan Pakai Tabel ✅
**Hanya untuk data tabular** — data yang butuh baris dan kolom:
- Daftar buku (judul, penulis, tahun, status)
- Nilai siswa (nama, mapel, nilai)
- Jadwal (hari, jam, ruang)
- Laporan keuangan (bulan, pendapatan, pengeluaran)
- Perbandingan produk (fitur, harga, rating)

### Kapan JANGAN Pakai Tabel ❌
- Layout halaman (header, sidebar, konten, footer)
- Membuat form
- Galeri gambar
- Navigasi
- Tombol atau ikon sejajar

### Alternatif Layout Modern
Gunakan **CSS**:
- **Flexbox** → layout 1 dimensi (baris/kolom)
- **CSS Grid** → layout 2 dimensi (grid kompleks)

### Contoh Buruk: Tabel untuk Layout
```html
<!-- JANGAN LAKUKAN INI -->
<table>
  <tr>
    <td colspan="2" id="header">Header</td>
  </tr>
  <tr>
    <td id="sidebar">Sidebar</td>
    <td id="content">Konten utama</td>
  </tr>
  <tr>
    <td colspan="2" id="footer">Footer</td>
  </tr>
</table>
```

### Contoh Baik: CSS untuk Layout
```html
<!-- LAKUKAN INI -->
<div style="display: flex; flex-direction: column;">
  <header>Header</header>
  <div style="display: flex;">
    <nav>Sidebar</nav>
    <main>Konten utama</main>
  </div>
  <footer>Footer</footer>
</div>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Best Practice Table</title>
    <style>
      table, th, td { border: 1px solid #333; border-collapse: collapse; }
      th, td { padding: 10px; }
    </style>
  </head>
  <body>
    <h1>Praktik Terbaik Tabel</h1>

    <!-- ✅ PAKAI TABEL UNTUK DATA -->
    <h2>✅ Data Tabular (Tabel Cocok)</h2>
    <table>
      <caption>Daftar Buku Perpustakaan</caption>
      <thead>
        <tr>
          <th>Judul</th>
          <th>Penulis</th>
          <th>Tahun</th>
          <th>Status</th>
        </tr>
      </thead>
      <tbody>
        <tr><td>Laskar Pelangi</td><td>Andrea Hirata</td><td>2005</td><td>Tersedia</td></tr>
        <tr><td>Bumi Manusia</td><td>Pramoedya A.</td><td>1980</td><td>Dipinjam</td></tr>
      </tbody>
    </table>

    <!-- ✅ TAPI PAKAI CSS UNTUK LAYOUT -->
    <h2>✅ Layout dengan CSS (Flexbox)</h2>
    <div style="display: flex; gap: 20px;">
      <div style="background: #e8f4f8; padding: 20px; flex: 1; text-align: center;">
        📚 Sidebar<br>Kategori Buku
      </div>
      <div style="background: #fef9e7; padding: 20px; flex: 3; text-align: center;">
        📖 Konten Utama<br>Daftar Buku
      </div>
    </div>
  </body>
</html>
```

## Poin Penting
- ✅ Tabel untuk **data tabular** — butuh baris & kolom
- ❌ Jangan tabel untuk **layout halaman** — pakai CSS (Flexbox/Grid)
- Tabel untuk layout = tidak responsif, tidak aksesibel, susah dirawat
- Di era HTML5, CSS sudah sangat mumpuni untuk layout
- Ingat: tabel adalah **alat penyajian data**, bukan alat desain
