# Tag th untuk Mendefinisikan Sel Header dalam Baris Tabel

## Analogi: Perpustakaan Digital

Bayangkan **label kolom** di bagian atas tabel inventaris perpustakaan:

| Judul Buku | Penulis | Tahun | Status |
|------------|---------|-------|--------|

Baris pertama ini memberi tahu pengunjung: "Kolom ini berisi judul, kolom itu berisi penulis, dst." Tulisannya tebal di tengah, berbeda dari data biasa.

`<th>` (table header) adalah **label kolom** — memberi tahu apa isi setiap kolom. Secara default, teksnya **tebal** dan **rata tengah**.

## Penjelasan Detail

`<th>` digunakan untuk mendefinisikan **sel header** dalam tabel.

### Atribut `<th>`
| Atribut | Fungsi |
|---------|--------|
| `scope` | Menentukan apakah header untuk kolom (`col`) atau baris (`row`) |
| `colspan` | Gabung beberapa kolom |
| `rowspan` | Gabung beberapa baris |
| `headers` | Hubungkan dengan header lain |

### Atribut `scope` untuk Aksesibilitas
```html
<th scope="col">Judul</th>     <!-- Header untuk kolom -->
<th scope="row">Laskar Pelangi</th>  <!-- Header untuk baris -->
```

`scope` membantu screen reader memahami hubungan header dengan data.

### Default Styling
- Font **tebal** (bold)
- Teks **rata tengah**
- Latar belakang default (abu-abu terang di beberapa browser)

### `<th>` di Baris atau Kolom
Header bisa di baris pertama (kolom) atau kolom pertama (baris):
```html
<table>
  <tr>
    <th>Judul</th>          <!-- Header kolom -->
    <th>Penulis</th>
  </tr>
  <tr>
    <th scope="row">Novel</th>  <!-- Header baris -->
    <td>Andrea Hirata</td>
  </tr>
</table>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Table Header</title>
    <style>
      table, th, td { border: 1px solid #2c3e50; border-collapse: collapse; }
      th, td { padding: 10px; }
      th {
        background: #2c3e50;
        color: white;
        text-align: center;
      }
    </style>
  </head>
  <body>
    <h1>Katalog Perpustakaan</h1>

    <table>
      <tr>
        <th scope="col">Kategori</th>
        <th scope="col">Judul Buku</th>
        <th scope="col">Penulis</th>
        <th scope="col">Harga</th>
      </tr>
      <tr>
        <th scope="row">Fiksi</th>
        <td>Laskar Pelangi</td>
        <td>Andrea Hirata</td>
        <td>Rp 85.000</td>
      </tr>
      <tr>
        <th scope="row">Non Fiksi</th>
        <td>Sejarah Nusantara</td>
        <td>Bambang Purwanto</td>
        <td>Rp 120.000</td>
      </tr>
      <tr>
        <th scope="row">Sains</th>
        <td>Fisika untuk Semua</td>
        <td>Stephen Hawking</td>
        <td>Rp 150.000</td>
      </tr>
    </table>
  </body>
</html>
```

## Poin Penting
- `<th>` = **sel header** — tebal dan rata tengah
- Atribut `scope` penting untuk **aksesibilitas**
  - `scope="col"` = header kolom
  - `scope="row"` = header baris
- Bisa di baris pertama (atas) atau kolom pertama (kiri)
- Styling bisa diubah dengan CSS
