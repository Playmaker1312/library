# Tag thead untuk Mengelompokkan Baris Header Tabel

## Analogi: Perpustakaan Digital

Bayangkan sebuah **buku laporan** yang punya bagian-bagian:

- **Kepala** → judul bab, header tabel (thead)
- **Isi** → data di dalam bab (tbody)
- **Kaki** → kesimpulan, catatan kaki (tfoot)

`<thead>` adalah **bagian kepala tabel** — mengelompokkan baris-baris header. Ini memudahkan browser dan CSS untuk memberi gaya khusus pada header.

## Penjelasan Detail

`<thead>` digunakan untuk mengelompokkan satu atau lebih baris header dalam tabel.

### Struktur Lengkap
```html
<table>
  <caption>Judul Tabel</caption>
  <thead>
    <tr>
      <th>Judul 1</th>
      <th>Judul 2</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Data 1</td>
      <td>Data 2</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td>Footer 1</td>
      <td>Footer 2</td>
    </tr>
  </tfoot>
</table>
```

### Manfaat `<thead>`
1. **Semantik** — browser tahu mana header tabel
2. **Styling** — mudah memberi gaya berbeda pada header
3. **Print** — header bisa diulang di setiap halaman saat print
4. **Scroll** — header tetap terlihat saat tabel di-scroll (dengan CSS)

### Aturan
- Hanya boleh ada **satu** `<thead>` per tabel
- Harus berisi `<tr>` dengan `<th>` (header)
- Urutan: `<caption>` → `<thead>` → `<tbody>` → `<tfoot>`

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Table Thead</title>
    <style>
      table, th, td { border: 1px solid #333; border-collapse: collapse; }
      th, td { padding: 10px; }
      thead {
        background: #2c3e50;
        color: white;
      }
      thead th {
        padding: 15px 10px;
        font-size: 1.1em;
      }
      tbody tr:nth-child(even) {
        background: #f2f2f2;
      }
      tfoot {
        background: #ecf0f1;
        font-weight: bold;
      }
    </style>
  </head>
  <body>
    <h1>Laporan Peminjaman Buku</h1>

    <table>
      <thead>
        <tr>
          <th>No</th>
          <th>Judul Buku</th>
          <th>Peminjam</th>
          <th>Tanggal</th>
        </tr>
      </thead>

      <tbody>
        <tr><td>1</td><td>Laskar Pelangi</td><td>Budi</td><td>10 Jan</td></tr>
        <tr><td>2</td><td>Bumi Manusia</td><td>Siti</td><td>15 Jan</td></tr>
        <tr><td>3</td><td>Pulang</td><td>Agus</td><td>20 Jan</td></tr>
        <tr><td>4</td><td>Fisika Dasar</td><td>Dewi</td><td>25 Jan</td></tr>
      </tbody>

      <tfoot>
        <tr>
          <td colspan="4">Total Peminjaman Bulan ini: 4 buku</td>
        </tr>
      </tfoot>
    </table>
  </body>
</html>
```

## Poin Penting
- `<thead>` = kelompok **header** tabel
- Meningkatkan **semantik** dan memudahkan **styling**
- Wajib menulis urutan yang benar: thead → tbody → tfoot
- Hanya **satu** `<thead>` per tabel
- Berguna untuk print (header diulang tiap halaman) dan scroll
