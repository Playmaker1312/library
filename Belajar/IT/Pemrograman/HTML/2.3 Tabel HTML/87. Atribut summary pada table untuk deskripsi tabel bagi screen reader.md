# Atribut summary pada table untuk Deskripsi Tabel bagi Screen Reader

## Analogi: Perpustakaan Digital

Bayangkan seorang **pengunjung tunanetra** datang ke perpustakaan. Sebelum membaca seluruh tabel, pustakawan memberi gambaran singkat: "Tabel ini berisi daftar buku dengan kolom judul, penulis, tahun terbit, dan status peminjaman."

Atribut `summary` pada `<table>` adalah **gambaran singkat** untuk screen reader. Deskripsi ini dibacakan sebelum pengguna menjelajahi tabel.

## Penjelasan Detail

Atribut `summary` memberikan **ringkasan** tentang struktur dan konten tabel untuk teknologi bantuan (screen reader).

### Format
```html
<table summary="Tabel ini menampilkan daftar buku yang tersedia di perpustakaan, termasuk judul, penulis, tahun terbit, dan status peminjaman.">
```

### Kapan Pakai `summary`?
- **Tabel kompleks** — banyak kolom, rowspan/colspan
- **Tabel dengan struktur tidak biasa** — perlu penjelasan
- **Tabel besar** — banyak baris

### Kapan Tidak Perlu?
- Tabel sederhana dengan `<caption>` yang sudah jelas
- Tabel kecil (2-3 kolom, beberapa baris)

### `summary` vs `caption`
- `<caption>` = judul yang **terlihat** oleh semua pengunjung
- `summary` = deskripsi **tersembunyi** (hanya screen reader)

Di HTML5, `summary` dianggap **usang (deprecated)**. Sebagai gantinya, gunakan kombinasi:
1. `<caption>` untuk judul
2. Teks penjelasan sebelum tabel
3. Atribut ARIA `aria-describedby` untuk deskripsi

### Pendekatan Modern (ARIA)
```html
<p id="desc-tabel">Tabel buku perpustakaan dengan informasi judul, penulis, tahun, dan status.</p>
<table aria-describedby="desc-tabel">
  ...
</table>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Table Summary</title>
    <style>
      table, th, td { border: 1px solid #333; border-collapse: collapse; }
      th, td { padding: 10px; }
    </style>
  </head>
  <body>
    <h1>Katalog Perpustakaan</h1>

    <!-- Metode 1: ARIA (modern) -->
    <p id="deskripsi-tabel" style="display: none;">Tabel ini berisi daftar buku perpustakaan dengan kolom No, Judul Buku, Penulis, Tahun Terbit, dan Status Peminjaman. Total ada 3 buku yang terdaftar.</p>

    <table aria-describedby="deskripsi-tabel">
      <caption>Daftar Buku Perpustakaan Digital</caption>
      <thead>
        <tr>
          <th>No</th>
          <th>Judul Buku</th>
          <th>Penulis</th>
          <th>Tahun</th>
          <th>Status</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td>1</td>
          <td>Laskar Pelangi</td>
          <td>Andrea Hirata</td>
          <td>2005</td>
          <td>Tersedia</td>
        </tr>
        <tr>
          <td>2</td>
          <td>Bumi Manusia</td>
          <td>Pramoedya A.</td>
          <td>1980</td>
          <td>Dipinjam</td>
        </tr>
        <tr>
          <td>3</td>
          <td>Pulang</td>
          <td>Tere Liye</td>
          <td>2015</td>
          <td>Tersedia</td>
        </tr>
      </tbody>
    </table>
  </body>
</html>
```

## Poin Penting
- `summary` = **deskripsi** untuk screen reader (usang di HTML5)
- Gunakan **`aria-describedby`** sebagai alternatif modern
- `<caption>` = judul terlihat, `summary`/`aria-describedby` = deskripsi untuk screen reader
- Hanya untuk **tabel kompleks** yang perlu penjelasan
- Tidak terlihat oleh pengguna biasa
