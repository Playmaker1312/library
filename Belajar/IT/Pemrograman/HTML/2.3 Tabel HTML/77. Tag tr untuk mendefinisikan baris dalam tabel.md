# Tag tr untuk Mendefinisikan Baris dalam Tabel

## Analogi: Perpustakaan Digital

Bayangkan sebuah **lembar Excel** berisi daftar buku. Setiap **baris horizontal** dalam lembar itu adalah satu entri buku: judul, penulis, tahun, status.

`<tr>` (table row) adalah **satu baris** dalam tabel HTML. Semua sel dalam baris itu — baik header (`<th>`) maupun data (`<td>`) — berada di dalam `<tr>`.

## Penjelasan Detail

`<tr>` digunakan untuk mendefinisikan **satu baris** dalam tabel.

### Struktur
```html
<table>
  <tr>       <!-- Baris pertama (header) -->
    <th>Judul</th>
    <th>Penulis</th>
  </tr>
  <tr>       <!-- Baris kedua (data) -->
    <td>Laskar Pelangi</td>
    <td>Andrea Hirata</td>
  </tr>
  <tr>       <!-- Baris ketiga (data) -->
    <td>Bumi Manusia</td>
    <td>Pramoedya A.</td>
  </tr>
</table>
```

### Aturan
- Jumlah `<td>`/`<th>` dalam setiap `<tr>` sebaiknya **sama** (konsisten)
- Jika tidak sama, tabel tetap tampil tapi ada sel kosong
- `<tr>` hanya boleh berisi `<td>` dan `<th>`

### Styling Alternatif Baris
Seringkali baris ganjil-genap diberi warna berbeda (zebra striping):
```css
tr:nth-child(even) { background: #f2f2f2; }
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Table Row</title>
    <style>
      table { border-collapse: collapse; width: 100%; }
      th, td { border: 1px solid #ddd; padding: 8px; text-align: left; }
      th { background: #2c3e50; color: white; }
      tr:nth-child(even) { background: #f2f2f2; }
      tr:hover { background: #e8f4f8; }
    </style>
  </head>
  <body>
    <h1>Daftar Anggota Perpustakaan</h1>

    <table>
      <tr>
        <th>No</th>
        <th>Nama</th>
        <th>Email</th>
        <th>Buku Dipinjam</th>
      </tr>
      <tr>
        <td>1</td>
        <td>Budi Santoso</td>
        <td>budi@email.com</td>
        <td>3</td>
      </tr>
      <tr>
        <td>2</td>
        <td>Siti Nurhaliza</td>
        <td>siti@email.com</td>
        <td>1</td>
      </tr>
      <tr>
        <td>3</td>
        <td>Agus Wijaya</td>
        <td>agus@email.com</td>
        <td>5</td>
      </tr>
    </table>
  </body>
</html>
```

## Poin Penting
- `<tr>` = **satu baris** dalam tabel
- Berisi `<th>` (header) atau `<td>` (data)
- Jumlah sel per baris sebaiknya **sama**
- Bisa di-styling dengan CSS (zebra, hover)
- Letak `<tr>` langsung di dalam `<table>`, `<thead>`, `<tbody>`, atau `<tfoot>`
