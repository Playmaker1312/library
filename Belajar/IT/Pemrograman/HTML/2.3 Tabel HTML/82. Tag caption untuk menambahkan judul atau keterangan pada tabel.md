# Tag caption untuk Menambahkan Judul atau Keterangan pada Tabel

## Analogi: Perpustakaan Digital

Bayangkan **judul tabel** yang tertera di atas daftar inventaris perpustakaan:

> **Tabel 1: Daftar Buku Terbaru Bulan Januari 2024**

Judul ini memberi konteks — pengunjung langsung tahu isi tabel tanpa harus membaca semua kolom.

`<caption>` adalah **judul tabel** yang muncul di atas (atau bawah) tabel. Ini membantu pengunjung dan screen reader memahami isi tabel secara cepat.

## Penjelasan Detail

`<caption>` digunakan untuk memberikan **judul atau keterangan** pada tabel.

### Aturan
- `<caption>` harus menjadi **anak pertama** dari `<table>` (sebelum `<tr>` atau `<thead>`)
- Hanya boleh ada **satu** `<caption>` per tabel
- Secara default, caption muncul di **atas** tabel

### Posisi Caption (CSS)
```css
caption { caption-side: top; }    /* di atas tabel (default) */
caption { caption-side: bottom; } /* di bawah tabel */
```

### Aksesibilitas
`<caption>` sangat penting untuk aksesibilitas — screen reader membacakannya terlebih dahulu sebelum menjelaskan struktur tabel.

### `<caption>` vs `<h>`
- **`<caption>`** → untuk judul tabel spesifik
- **`<h1>`-`<h6>`** → untuk judul bagian halaman

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Table Caption</title>
    <style>
      table, th, td { border: 1px solid #333; border-collapse: collapse; }
      th, td { padding: 10px; }
      caption {
        font-size: 1.2em;
        font-weight: bold;
        margin-bottom: 10px;
        color: #2c3e50;
      }
    </style>
  </head>
  <body>
    <h1>Data Perpustakaan</h1>

    <table>
      <caption>Tabel 1: Daftar Buku Terbaru Januari 2024</caption>
      <tr>
        <th>No</th>
        <th>Judul Buku</th>
        <th>Penulis</th>
        <th>Tahun</th>
      </tr>
      <tr>
        <td>1</td>
        <td>Laskar Pelangi</td>
        <td>Andrea Hirata</td>
        <td>2005</td>
      </tr>
      <tr>
        <td>2</td>
        <td>Bumi Manusia</td>
        <td>Pramoedya A.</td>
        <td>1980</td>
      </tr>
    </table>

    <br>

    <table>
      <caption style="caption-side: bottom;">Tabel 2: Statistik Pengunjung (caption di bawah)</caption>
      <tr>
        <th>Bulan</th>
        <th>Pengunjung</th>
      </tr>
      <tr>
        <td>Januari</td>
        <td>1.200</td>
      </tr>
      <tr>
        <td>Februari</td>
        <td>1.500</td>
      </tr>
    </table>
  </body>
</html>
```

## Poin Penting
- `<caption>` = **judul tabel** (anak pertama `<table>`)
- Muncul di atas tabel secara default
- Hanya **satu** caption per tabel
- Penting untuk **aksesibilitas** — screen reader membacanya
- Bisa dipindah ke bawah dengan CSS `caption-side: bottom`
