# Tag td untuk Mendefinisikan Sel Data dalam Baris Tabel

## Analogi: Perpustakaan Digital

Bayangkan **satu kotak** dalam lembar Excel. Di perpustakaan, itu adalah satu data spesifik: misalnya judul buku "Laskar Pelangi" atau penulis "Andrea Hirata".

`<td>` (table data) adalah **satu sel** dalam tabel yang berisi data biasa (bukan header). Ini adalah "isi" dari tabel.

## Penjelasan Detail

`<td>` digunakan untuk mendefinisikan **sel data** dalam baris tabel.

### Atribut `<td>`
| Atribut | Fungsi |
|---------|--------|
| `colspan` | Gabung beberapa kolom |
| `rowspan` | Gabung beberapa baris |
| `headers` | Hubungkan dengan header (aksesibilitas) |

### Perbedaan `<td>` vs `<th>`
| `<td>` | `<th>` |
|--------|--------|
| Data biasa | Header/judul kolom |
| Teks biasa (kiri) | Teks tebal + tengah |
| Tidak di-scope | Punya atribut `scope` |

### Styling
```css
td {
  border: 1px solid #ddd;
  padding: 10px;
  text-align: left;  /* default */
}
```

### Contoh dengan Atribut `headers`
Untuk aksesibilitas, hubungkan `<td>` dengan `<th>`:
```html
<tr>
  <th id="judul">Judul</th>
  <th id="penulis">Penulis</th>
</tr>
<tr>
  <td headers="judul">Laskar Pelangi</td>
  <td headers="penulis">Andrea Hirata</td>
</tr>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Table Data</title>
    <style>
      table, th, td { border: 1px solid #ccc; border-collapse: collapse; }
      th, td { padding: 10px; }
    </style>
  </head>
  <body>
    <h1>Data Peminjaman Buku</h1>

    <table>
      <tr>
        <th>Judul Buku</th>
        <th>Peminjam</th>
        <th>Tanggal Pinjam</th>
        <th>Tanggal Kembali</th>
      </tr>
      <tr>
        <td>Laskar Pelangi</td>
        <td>Budi Santoso</td>
        <td>10 Jan 2024</td>
        <td>24 Jan 2024</td>
      </tr>
      <tr>
        <td>Bumi Manusia</td>
        <td>Siti Nurhaliza</td>
        <td>15 Jan 2024</td>
        <td>29 Jan 2024</td>
      </tr>
      <tr>
        <td>Pulang</td>
        <td>Agus Wijaya</td>
        <td>20 Jan 2024</td>
        <td>-</td>
      </tr>
    </table>
  </body>
</html>
```

## Poin Penting
- `<td>` = **sel data** dalam tabel
- Berisi data biasa (judul, nama, angka, dll)
- Berbeda dengan `<th>` (header)
- Atribut: `colspan`, `rowspan`, `headers`
- Jumlah `<td>` per baris sebaiknya konsisten
