# Tag table sebagai Wadah Utama untuk Membuat Tabel

## Analogi: Perpustakaan Digital

Bayangkan **daftar inventaris** perpustakaan — tabel yang berisi judul buku, penulis, tahun terbit, dan status. Data tersusun rapi dalam **baris dan kolom**.

`<table>` adalah **lembar tabel** tempat kamu menyusun data dalam format baris dan kolom. Semua elemen tabel — baris, sel, header — berada di dalam `<table>`.

## Penjelasan Detail

`<table>` adalah wadah utama untuk **data tabular** — data yang perlu disajikan dalam baris dan kolom.

### Struktur Dasar Tabel
```html
<table>
  <tr>            <!-- Baris 1 -->
    <th>Judul</th>  <!-- Header -->
    <th>Penulis</th>
  </tr>
  <tr>            <!-- Baris 2 -->
    <td>Laskar Pelangi</td>  <!-- Data -->
    <td>Andrea Hirata</td>
  </tr>
</table>
```

### Elemen dalam `<table>`
| Tag | Kepanjangan | Fungsi |
|-----|-------------|--------|
| `<table>` | - | Wadah utama |
| `<tr>` | Table Row | Baris dalam tabel |
| `<th>` | Table Header | Sel header (tebal, tengah) |
| `<td>` | Table Data | Sel data biasa |
| `<caption>` | - | Judul/keterangan tabel |
| `<thead>` | Table Head | Kelompok baris header |
| `<tbody>` | Table Body | Kelompok baris data |
| `<tfoot>` | Table Foot | Kelompok baris footer |

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Table</title>
  </head>
  <body>
    <h1>Daftar Buku Perpustakaan</h1>

    <table border="1" style="border-collapse: collapse; width: 100%;">
      <tr>
        <th>Judul Buku</th>
        <th>Penulis</th>
        <th>Tahun</th>
        <th>Status</th>
      </tr>
      <tr>
        <td>Laskar Pelangi</td>
        <td>Andrea Hirata</td>
        <td>2005</td>
        <td>Tersedia</td>
      </tr>
      <tr>
        <td>Bumi Manusia</td>
        <td>Pramoedya A.</td>
        <td>1980</td>
        <td>Dipinjam</td>
      </tr>
      <tr>
        <td>Pulang</td>
        <td>Tere Liye</td>
        <td>2015</td>
        <td>Tersedia</td>
      </tr>
    </table>
  </body>
</html>
```

## Poin Penting
- `<table>` = wadah untuk **data tabular**
- Tabel punya baris (`<tr>`) dan sel (`<th>`/`<td>`)
- Gunakan tabel hanya untuk **data**, bukan layout halaman
- Struktur: `<table>` → `<tr>` → `<th>`/`<td>`
- Tambahkan `border` atau CSS agar terlihat rapi
