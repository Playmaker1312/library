# Tag tbody untuk Mengelompokkan Baris Isi atau Konten Tabel

## Analogi: Perpustakaan Digital

Bayangkan sebuah **buku laporan**. Bagian terbesarnya adalah **isi** — halaman demi halaman data. Bagian inilah yang paling penting, tempat semua informasi berada.

`<tbody>` adalah **bagian isi** tabel — tempat semua **data** berada. Ini adalah bagian tabel yang paling besar, berisi baris-baris `<tr>` dengan `<td>`.

## Penjelasan Detail

`<tbody>` digunakan untuk mengelompokkan **baris data utama** dalam tabel.

### Karakteristik
- Hanya boleh ada **satu** `<tbody>` (boleh lebih dari satu untuk memisah data)
- Berisi baris `<tr>` dengan `<td>` (data)
- Jika tabel punya `<thead>` atau `<tfoot>`, `<tbody>` harus ada

### Multiple `<tbody>` (Memisah Data)
```html
<table>
  <thead>...</thead>

  <tbody>
    <!-- Data Fiksi -->
    <tr><td>Laskar Pelangi</td></tr>
  </tbody>

  <tbody>
    <!-- Data Non Fiksi -->
    <tr><td>Sejarah Nusantara</td></tr>
  </tbody>
</table>
```

### Manfaat `<tbody>`
1. **Struktur semantik** — jelas mana header, data, footer
2. **Styling** — mudah bedakan gaya header dan data
3. **Multiple tbody** — pisah data berdasarkan kategori
4. **Aksesibilitas** — screen reader paham struktur

### Tanpa `<tbody>` pun Bisa
Browser secara otomatis membungkus baris `<tr>` langsung di `<table>` ke dalam `<tbody>` implisit. Tapi lebih baik eksplisit.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Table Tbody</title>
    <style>
      table, th, td { border: 1px solid #333; border-collapse: collapse; }
      th, td { padding: 10px; }
      thead { background: #2c3e50; color: white; }
      .fiksi { background: #e8f4f8; }
      .nonfiksi { background: #fef9e7; }
      tfoot { background: #ecf0f1; font-weight: bold; }
    </style>
  </head>
  <body>
    <h1>Katalog Buku</h1>

    <table>
      <thead>
        <tr>
          <th>Judul Buku</th>
          <th>Penulis</th>
          <th>Kategori</th>
        </tr>
      </thead>

      <!-- Multiple tbody untuk kategori berbeda -->
      <tbody class="fiksi">
        <tr><td>Laskar Pelangi</td><td>Andrea Hirata</td><td>Fiksi</td></tr>
        <tr><td>Bumi Manusia</td><td>Pramoedya A.</td><td>Fiksi</td></tr>
        <tr><td>Pulang</td><td>Tere Liye</td><td>Fiksi</td></tr>
      </tbody>

      <tbody class="nonfiksi">
        <tr><td>Sejarah Nusantara</td><td>Bambang P.</td><td>Non Fiksi</td></tr>
        <tr><td>Fisika Dasar</td><td>Stephen H.</td><td>Non Fiksi</td></tr>
      </tbody>

      <tfoot>
        <tr>
          <td colspan="3">Total koleksi: 5 buku</td>
        </tr>
      </tfoot>
    </table>
  </body>
</html>
```

## Poin Penting
- `<tbody>` = kelompok **data** tabel (bagian isi)
- Bisa ada **lebih dari satu** `<tbody>` dalam tabel
- Bersama `<thead>` dan `<tfoot>` membentuk struktur tabel lengkap
- Tanpa `<tbody>`, browser membuatnya implisit — tapi lebih baik eksplisit
- Berguna untuk **styling** dan **aksesibilitas**
