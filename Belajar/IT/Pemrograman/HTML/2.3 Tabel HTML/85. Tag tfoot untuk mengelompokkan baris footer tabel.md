# Tag tfoot untuk Mengelompokkan Baris Footer Tabel

## Analogi: Perpustakaan Digital

Bayangkan **bagian penutup** di akhir tabel — tempat total, rata-rata, atau kesimpulan berada. Di laporan perpustakaan, ini baris yang menunjukkan "Total buku: 1.234" atau "Rata-rata pengunjung: 500/hari".

`<tfoot>` adalah **bagian kaki** tabel — mengelompokkan baris ringkasan atau footer.

## Penjelasan Detail

`<tfoot>` digunakan untuk mengelompokkan **baris footer** dalam tabel.

### Posisi Unik
Meskipun ditulis **setelah** `<tbody>` di HTML, browser akan menampilkan `<tfoot>` di **bagian bawah tabel**.

```html
<table>
  <thead>...</thead>
  <tfoot>...</tfoot>    <!-- Ditulis setelah thead, sebelum tbody -->
  <tbody>...</tbody>
</table>
```

Atau:
```html
<table>
  <thead>...</thead>
  <tbody>...</tbody>
  <tfoot>...</tfoot>    <!-- Juga valid setelah tbody -->
</table>
```

### Manfaat `<tfoot>`
1. **Semantik** — jelas ini bagian ringkasan
2. **Print** — footer muncul di setiap halaman (jika tabel multi-halaman)
3. **Styling** — mudah bedakan footer dari data

### Aturan
- Hanya boleh ada **satu** `<tfoot>` per tabel
- Berisi `<tr>` dengan `<td>` atau `<th>`
- Paling umum berisi: total, rata-rata, jumlah

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Table Tfoot</title>
    <style>
      table, th, td { border: 1px solid #333; border-collapse: collapse; }
      th, td { padding: 10px; }
      thead { background: #2c3e50; color: white; }
      tfoot {
        background: #ecf0f1;
        font-weight: bold;
        border-top: 2px solid #2c3e50;
      }
    </style>
  </head>
  <body>
    <h1>Laporan Keuangan Perpustakaan</h1>

    <table>
      <thead>
        <tr>
          <th>Bulan</th>
          <th>Pendapatan</th>
          <th>Pengeluaran</th>
          <th>Keuntungan</th>
        </tr>
      </thead>

      <tbody>
        <tr><td>Januari</td><td>Rp 5.000.000</td><td>Rp 3.000.000</td><td>Rp 2.000.000</td></tr>
        <tr><td>Februari</td><td>Rp 6.500.000</td><td>Rp 3.500.000</td><td>Rp 3.000.000</td></tr>
        <tr><td>Maret</td><td>Rp 4.000.000</td><td>Rp 2.500.000</td><td>Rp 1.500.000</td></tr>
      </tbody>

      <!-- Tfoot untuk total -->
      <tfoot>
        <tr>
          <td><strong>Total</strong></td>
          <td><strong>Rp 15.500.000</strong></td>
          <td><strong>Rp 9.000.000</strong></td>
          <td><strong>Rp 6.500.000</strong></td>
        </tr>
      </tfoot>
    </table>
  </body>
</html>
```

## Poin Penting
- `<tfoot>` = kelompok **footer** tabel (total, ringkasan)
- Bisa ditulis **sebelum** atau **sesudah** `<tbody>`
- Tampil di bagian bawah tabel
- Hanya **satu** `<tfoot>` per tabel
- Berguna untuk print dan styling
