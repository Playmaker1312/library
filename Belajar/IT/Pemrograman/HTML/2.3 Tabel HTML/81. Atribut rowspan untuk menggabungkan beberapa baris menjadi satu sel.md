# Atribut rowspan untuk Menggabungkan Beberapa Baris menjadi Satu Sel

## Analogi: Perpustakaan Digital

Bayangkan tabel daftar buku yang punya **kategori** yang sama untuk beberapa baris:

| Kategori | Judul | Penulis |
|----------|-------|---------|
| Fiksi    | Laskar Pelangi | Andrea Hirata |
|          | Bumi Manusia   | Pramoedya A.  |
| Non Fiksi| Sejarah Nusantara | Bambang P. |

"Fiksi" membentang di **2 baris** — ini adalah rowspan.

`rowspan` adalah atribut yang membuat satu sel **memanjang ke beberapa baris**.

## Penjelasan Detail

`rowspan` digunakan pada `<th>` atau `<td>` untuk menggabungkan beberapa baris.

### Format
```html
<td rowspan="3">Teks ini memanjang ke 3 baris</td>
<th rowspan="2">Header ini memanjang 2 baris</th>
```

### Cara Kerja
```html
<table border="1">
  <tr>
    <th rowspan="2">Kategori</th>   <!-- akan memanjang 2 baris -->
    <td>Laskar Pelangi</td>
  </tr>
  <tr>
    <!-- <th> tidak perlu di sini — rowspan dari atas -->
    <td>Bumi Manusia</td>
  </tr>
</table>
```

Sel dengan `rowspan` "memakan" tempat di baris berikutnya, sehingga baris berikutnya memiliki **satu kolom lebih sedikit**.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Rowspan</title>
    <style>
      table, th, td { border: 1px solid #333; border-collapse: collapse; }
      th, td { padding: 10px; }
    </style>
  </head>
  <body>
    <h1>Katalog Perpustakaan</h1>

    <table>
      <tr>
        <th>Kategori</th>
        <th>Judul Buku</th>
        <th>Penulis</th>
        <th>Status</th>
      </tr>
      <tr>
        <td rowspan="3">Fiksi</td>
        <td>Laskar Pelangi</td>
        <td>Andrea Hirata</td>
        <td>Tersedia</td>
      </tr>
      <tr>
        <!-- Kategori "Fiksi" dari rowspan di atas -->
        <td>Bumi Manusia</td>
        <td>Pramoedya A.</td>
        <td>Dipinjam</td>
      </tr>
      <tr>
        <td>Pulang</td>
        <td>Tere Liye</td>
        <td>Tersedia</td>
      </tr>
      <tr>
        <td rowspan="2">Non Fiksi</td>
        <td>Sejarah Nusantara</td>
        <td>Bambang P.</td>
        <td>Tersedia</td>
      </tr>
      <tr>
        <td>Fisika untuk Semua</td>
        <td>Stephen H.</td>
        <td>Dipinjam</td>
      </tr>
    </table>
  </body>
</html>
```

## Poin Penting
- `rowspan="N"` = sel **memanjang N baris**
- Baris berikutnya punya **satu kolom lebih sedikit** (karena sudah terisi rowspan)
- Bisa dipakai di `<th>` maupun `<td>`
- Sering dipakai untuk kategori/grup yang sama di beberapa baris
- Hati-hati menghitung total baris — mudah salah
