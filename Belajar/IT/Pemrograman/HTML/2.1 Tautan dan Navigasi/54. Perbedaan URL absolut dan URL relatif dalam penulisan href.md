# Perbedaan URL Absolut dan URL Relatif dalam Penulisan href

## Analogi: Perpustakaan Digital

Bayangkan kamu memberi **alamat perpustakaan** kepada seseorang:

- **URL Absolut**: "Perpustakaan Digital, Jl. Merdeka No. 123, Jakarta Pusat, 10110, Indonesia" — alamat **lengkap dari awal**, bisa dipakai dari mana saja.

- **URL Relatif**: "Rak Fiksi, Lantai 2, sayap timur" — alamat **relatif dari posisi saat ini**. Hanya berguna jika kamu sudah di dalam perpustakaan.

Di HTML, URL absolut adalah URL lengkap (https://...). URL relatif adalah path dari posisi file saat ini.

## Penjelasan Detail

### URL Absolut
URL lengkap yang mengandung **protokol + domain + path**.

```html
<a href="https://perpustakaan.com/buku/fiksi.html">Link absolut</a>
<a href="https://google.com">Link ke situs lain</a>
```

**Kapan pakai?** — Link ke website lain, atau link absolut dari A ke B tanpa peduli posisi file.

### URL Relatif
Path dari **posisi file HTML saat ini**.

```html
<!-- File saat ini: /website/buku/index.html -->
<a href="fiksi.html">            ← /website/buku/fiksi.html</a>
<a href="../tentang.html">       ← /website/tentang.html</a>
<a href="/katalog/index.html">   ← /katalog/index.html (absolute path dari root)</a>
```

### Simbol Path Relatif
| Simbol | Arti | Contoh |
|--------|------|--------|
| `nama-file.html` | File di folder yang sama | `tentang.html` |
| `folder/nama-file.html` | File di subfolder | `buku/fiksi.html` |
| `../` | Naik satu folder | `../index.html` |
| `../../` | Naik dua folder | `../../index.html` |
| `/` | Mulai dari root domain | `/katalog/index.html` |

### Contoh Struktur Folder
```
/website
  /index.html
  /tentang.html
  /buku
    /fiksi.html
    /nonfiksi.html
  /img
    /logo.png
```

Dari `buku/fiksi.html`:
- Ke `tentang.html` → `../tentang.html`
- Ke `index.html` → `../index.html`
- Ke `logo.png` → `../img/logo.png`
- Ke `nonfiksi.html` → `nonfiksi.html`

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>URL Absolut vs Relatif</title>
  </head>
  <body>
    <h1>Contoh URL</h1>

    <h2>URL Absolut</h2>
    <ul>
      <li><a href="https://google.com">Google</a></li>
      <li><a href="https://perpustakaan.com/buku/fiksi.html">Buku Fiksi</a></li>
    </ul>

    <h2>URL Relatif</h2>
    <ul>
      <li><a href="tentang.html">Tentang (folder sama)</a></li>
      <li><a href="buku/fiksi.html">Fiksi (subfolder)</a></li>
      <li><a href="../index.html">Home (naik folder)</a></li>
      <li><a href="/katalog/index.html">Katalog (dari root)</a></li>
    </ul>
  </body>
</html>
```

## Poin Penting
- **URL Absolut** = URL lengkap (https://domain.com/path)
- **URL Relatif** = path dari posisi file saat ini
- Absolut untuk link ke **website lain**
- Relatif untuk link **internal** (lebih portable)
- `../` = naik satu folder, `/` = dari root domain
