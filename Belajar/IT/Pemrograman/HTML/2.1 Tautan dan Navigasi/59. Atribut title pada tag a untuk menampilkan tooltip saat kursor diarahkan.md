# Atribut title pada Tag a untuk Menampilkan Tooltip saat Kursor Diarahkan

## Analogi: Perpustakaan Digital

Bayangkan kamu melihat **judul buku** yang samar-samar di rak tinggi. Kamu mendekatkan wajah untuk membaca judul lengkapnya. Atau bayangkan **stiker informasi** yang muncul saat pengunjung mengarahkan jari ke arah papan petunjuk.

Atribut `title` pada tautan adalah **stiker informasi** yang muncul saat kursor diarahkan ke tautan (tooltip). Memberi penjelasan tambahan tanpa mengganggu tampilan halaman.

## Penjelasan Detail

Atribut `title` menambahkan **teks tooltip** (teks yang muncul saat kursor mouse diarahkan ke elemen).

### Format Dasar
```html
<a href="buku.html" title="Klik untuk melihat detail buku ini">Laskar Pelangi</a>
```

### Kapan Pakai `title`?
- **Tautan singkat** — menambahkan deskripsi: `title="Buka halaman detail"`
- **Ikon tanpa teks** — tombol ikon perlu penjelasan: `title="Cari buku"`
- **Singkatan** — menjelaskan kepanjangan: `title="HyperText Markup Language"`

### Atribut `title` di Berbagai Elemen
`title` tidak hanya untuk `<a>`, tapi juga elemen lain:
```html
<p title="Ini adalah penjelasan">Arahkan kursor ke sini</p>
<img src="logo.png" title="Logo Perpustakaan Digital">
```

### Kelemahan Tooltip
- **Tidak di mobile** — tidak ada hover di layar sentuh
- **Tidak aksesibel** — screen reader tidak selalu membacanya
- Jangan andalkan `title` untuk informasi **penting** — gunakan teks yang terlihat

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Title Attribute</title>
  </head>
  <body>
    <h1>Koleksi Buku</h1>

    <ul>
      <li>
        <a href="buku/laskar-pelangi.html" title="Klik untuk membaca sinopsis dan review">
          Laskar Pelangi
        </a>
      </li>
      <li>
        <a href="buku/bumi-manusia.html" title="Novel sejarah karya Pramoedya Ananta Toer">
          Bumi Manusia
        </a>
      </li>
      <li>
        <a href="buku/pulang.html" title="Buku terbaru dari Tere Liye">
          Pulang
        </a>
      </li>
    </ul>

    <h2>Ikon Toolbar</h2>
    <p>
      <a href="cari.html" title="Cari buku">🔍</a>
      <a href="keranjang.html" title="Lihat keranjang pinjaman">📚</a>
      <a href="profil.html" title="Profil anggota">👤</a>
    </p>

    <h2>Tooltip pada Teks Biasa</h2>
    <p>Belajar <abbr title="HyperText Markup Language">HTML</abbr> itu menyenangkan.</p>
  </body>
</html>
```

## Poin Penting
- Atribut `title` = **tooltip** saat hover
- Memberi informasi **tambahan**, bukan informasi utama
- Tidak muncul di **perangkat sentuh** (mobile)
- Tidak sepenuhnya **aksesibel**
- Jangan andalkan untuk informasi penting
