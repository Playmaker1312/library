# Atribut href untuk Menentukan Tujuan atau URL dari Tautan

## Analogi: Perpustakaan Digital

Bayangkan **papan petunjuk arah** di perpustakaan. Papan ini tidak berguna jika tidak ada alamat tujuan — "Ke Ruang Baca Lantai 2", "Ke Katalog Online", dll.

`href` (hypertext reference) adalah **alamat tujuan** dari tautan. Ini atribut **paling penting** pada tag `<a>` — tanpa `href`, tautan tidak bisa diklik.

## Penjelasan Detail

`href` menentukan URL atau lokasi tujuan saat tautan diklik.

### Nilai `href` yang Umum

| Jenis | Contoh | Kegunaan |
|-------|--------|----------|
| URL absolut | `href="https://google.com"` | Halaman di website lain |
| URL relatif | `href="tentang.html"` | File di folder yang sama |
| URL relatif (subfolder) | `href="buku/fiksi.html"` | File di subfolder |
| URL relatif (parent) | `href="../index.html"` | File di folder induk |
| Anchor internal | `href="#kontak"` | Bagian dalam halaman yang sama |
| Email | `href="mailto:admin@perpus.com"` | Kirim email |
| Telepon | `href="tel:+628123456789"` | Panggil nomor |
| Download | `href="file.pdf"` | Unduh file |

### URL Absolut vs Relatif
```html
<!-- Absolut: URL lengkap dari awal -->
<a href="https://perpustakaan.com/buku/fiksi.html">Buku Fiksi</a>

<!-- Relatif: path dari posisi file saat ini -->
<a href="buku/fiksi.html">Buku Fiksi</a>
<!-- Artinya: folder "buku", file "fiksi.html" di folder yang sama dengan halaman ini -->
```

### Path Relatif
```text
Folder struktur:
/website
  /index.html          ← halaman saat ini
  /tentang.html        ← href="tentang.html"
  /buku
    /fiksi.html        ← href="buku/fiksi.html"
  /img
    /logo.png          ← href="img/logo.png"
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Href Examples</title>
  </head>
  <body>
    <h1>Contoh Atribut Href</h1>

    <ul>
      <li><a href="https://google.com">URL Absolut (Google)</a></li>
      <li><a href="tentang.html">URL Relatif (tentang.html)</a></li>
      <li><a href="buku/fiksi.html">URL Relatif (subfolder)</a></li>
      <li><a href="#footer">Anchor Internal (ke footer)</a></li>
      <li><a href="mailto:admin@perpustakaan.com">Kirim Email</a></li>
      <li><a href="tel:+628123456789">Telepon</a></li>
      <li><a href="katalog.pdf" download>Unduh Katalog</a></li>
      <li><a href="#">Tidak ke mana-mana (placeholder)</a></li>
    </ul>

    <p style="margin-top: 500px;">Lorem ipsum (hanya untuk scroll)</p>

    <footer id="footer">
      <p>Ini footer — kamu sampai di sini karena mengklik anchor internal!</p>
      <p><a href="#">Kembali ke Atas</a></p>
    </footer>
  </body>
</html>
```

## Poin Penting
- `href` = **tujuan tautan** (wajib untuk link yang bisa diklik)
- **Absolut**: URL lengkap (https://...)
- **Relatif**: path dari posisi file saat ini
- **Anchor**: `#id` untuk bagian dalam halaman
- Juga support `mailto:`, `tel:`, dan `download`
