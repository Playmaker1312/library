# Membuat Tautan ke Bagian Tertentu dalam Halaman yang Sama Menggunakan id

## Analogi: Perpustakaan Digital

Bayangkan **daftar isi** di awal sebuah buku. Setiap bab memiliki **penanda halaman** — "Bab 1: halaman 1", "Bab 2: halaman 20". Kamu tinggal lihat nomor halaman, buka langsung ke halaman itu, tanpa harus membaca dari awal.

Di HTML, kamu bisa membuat **penanda (id)** di bagian tertentu halaman, lalu tautan langsung ke penanda itu. Ini disebut **anchor link** atau **jump link**.

## Penjelasan Detail

### Langkah 1: Buat Penanda dengan Atribut `id`
```html
<h2 id="sejarah">Sejarah Perpustakaan</h2>
```

### Langkah 2: Buat Tautan ke Penanda
```html
<a href="#sejarah">Lompat ke Sejarah Perpustakaan</a>
```

Tanda `#` diikuti nama id → browser akan scroll ke elemen dengan id tersebut.

### Aturan `id`
- **Unik** — tidak boleh ada dua elemen dengan id yang sama
- Tidak boleh mengandung spasi
- Case-sensitive (`#Sejarah` beda dengan `#sejarah`)
- Mulai dengan huruf

### Tautan ke Bagian di Halaman Lain
```html
<!-- Dari halaman A ke bagian di halaman B -->
<a href="tentang.html#sejarah">Lihat Sejarah di halaman Tentang</a>
```

### Kembali ke Atas
```html
<a href="#">Kembali ke Atas</a>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Anchor Link</title>
    <style>
      section { margin: 300px 0; padding: 20px; border: 1px solid #ddd; }
    </style>
  </head>
  <body>
    <h1>Profil Perpustakaan Digital</h1>

    <!-- Daftar Isi -->
    <h2>Daftar Isi</h2>
    <ul>
      <li><a href="#sejarah">Sejarah</a></li>
      <li><a href="#visi-misi">Visi dan Misi</a></li>
      <li><a href="#layanan">Layanan</a></li>
      <li><a href="#kontak">Kontak</a></li>
    </ul>

    <section id="sejarah">
      <h2>Sejarah</h2>
      <p>Perpustakaan Digital didirikan pada tahun 2020...</p>
      <p><a href="#">Kembali ke Atas</a></p>
    </section>

    <section id="visi-misi">
      <h2>Visi dan Misi</h2>
      <p>Menjadi perpustakaan digital terbaik di Indonesia...</p>
      <p><a href="#">Kembali ke Atas</a></p>
    </section>

    <section id="layanan">
      <h2>Layanan</h2>
      <p>Kami menyediakan layanan peminjaman buku online...</p>
      <p><a href="#">Kembali ke Atas</a></p>
    </section>

    <section id="kontak">
      <h2>Kontak</h2>
      <p>Email: admin@perpustakaan.com</p>
      <p><a href="#">Kembali ke Atas</a></p>
    </section>
  </body>
</html>
```

## Poin Penting
- Gunakan `id` sebagai **penanda** di elemen tujuan
- Tautan pakai `#` + nama id: `<a href="#sejarah">`
- `id` harus **unik** dalam satu halaman
- Bisa juga lompat ke bagian di halaman lain: `halaman.html#id`
- `<a href="#">` = kembali ke atas halaman
