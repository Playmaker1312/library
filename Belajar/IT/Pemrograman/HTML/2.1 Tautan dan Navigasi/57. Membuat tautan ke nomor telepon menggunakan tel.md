# Membuat Tautan ke Nomor Telepon menggunakan tel

## Analogi: Perpustakaan Digital

Bayangkan **nomor telepon** yang tertera di papan informasi perpustakaan. "Hubungi: 021-12345678". Di HP, pengunjung bisa langsung menekan nomor itu untuk menelepon.

Di web, tautan `tel:` adalah **tombol panggil digital**. Saat diklik di HP → langsung membuka aplikasi telepon dengan nomor tujuan sudah terisi.

## Penjelasan Detail

`tel:` adalah skema URL untuk tautan **nomor telepon**. Di perangkat mobile, ini sangat berguna — satu klik langsung menelepon.

### Format Dasar
```html
<a href="tel:+628123456789">Hubungi Kami</a>
```

### Format Nomor
Rekomendasi: gunakan format **internasional** (dengan kode negara).
```html
<a href="tel:+628123456789">+62 812-3456-789</a>
```

### Karakter dalam Nomor
Browser mengabaikan karakter non-angka seperti spasi, tanda kurung, dan strip.
```html
<!-- Semua ini sama bagi browser -->
<a href="tel:+628123456789">+62 812-3456-789</a>
<a href="tel:628123456789">+62 812 3456 789</a>
<a href="tel:08123456789">0812-3456-789</a>
```

### Di Desktop vs Mobile
- **Mobile**: Membuka aplikasi telepon
- **Desktop**: Beberapa aplikasi bisa menelepon (Skype, dll) atau tidak ada reaksi

### Kombinasi dengan mailto dan Link Biasa
```html
<p>
  Telepon: <a href="tel:+628123456789">(021) 1234-5678</a> |
  Email: <a href="mailto:admin@perpustakaan.com">admin@perpustakaan.com</a>
</p>
```

## Poin Penting
- `tel:` = tautan **nomor telepon** (langsung panggil)
- Di mobile → buka aplikasi telepon
- Gunakan format **internasional** (`+62xxx`)
- Karakter non-angka diabaikan browser
- Di desktop, fungsionalitas terbatas
