# Membuat Tautan ke Alamat Email menggunakan mailto

## Analogi: Perpustakaan Digital

Bayangkan **kotak surat** di pintu masuk perpustakaan. Pengunjung bisa menulis surat dan memasukkannya ke kotak ini. Di web, tautan `mailto:` adalah **kotak surat digital** — saat diklik, browser membuka program email pengguna.

## Penjelasan Detail

`mailto:` adalah skema URL yang memberitahu browser untuk membuka **klien email default** pengguna.

### Format Dasar
```html
<a href="mailto:admin@perpustakaan.com">Kirim Email</a>
```

Saat diklik → terbuka Outlook/Gmail/klien email dengan kolom "To" sudah terisi.

### Parameter Tambahan
Kamu bisa menambahkan parameter di URL `mailto:`:

```html
<a href="mailto:admin@perpustakaan.com?subject=Halo&body=Test">
  Kirim Email dengan Subjek
</a>
```

| Parameter | Fungsi | Contoh |
|-----------|--------|--------|
| `subject` | Subjek email | `?subject=Informasi Buku` |
| `cc` | Tembusan | `?cc=manager@perpustakaan.com` |
| `bcc` | Tembusan tersembunyi | `?bcc=arsip@perpustakaan.com` |
| `body` | Isi email | `&body=Halo, saya ingin bertanya...` |

Gabungan parameter pakai `&`:
```html
<a href="mailto:admin@perpustakaan.com?cc=manager@perpustakaan.com&subject=Pertanyaan&body=Halo%20Admin">
  Hubungi Kami
</a>
```

Catatan: spasi di body diganti `%20`.

### Multiple Recipients
```html
<a href="mailto:admin@perpustakaan.com,manager@perpustakaan.com">
  Kirim ke Banyak Orang
</a>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Mailto Link</title>
  </head>
  <body>
    <h1>Hubungi Perpustakaan</h1>

    <h2>Email Dasar</h2>
    <p><a href="mailto:admin@perpustakaan.com">Kirim Email ke Admin</a></p>

    <h2>Email dengan Subjek</h2>
    <p><a href="mailto:admin@perpustakaan.com?subject=Informasi%20Keanggotaan">Informasi Keanggotaan</a></p>

    <h2>Email dengan Subjek dan Body</h2>
    <p>
      <a href="mailto:admin@perpustakaan.com?subject=Pengembalian%20Buku&body=Halo%2C%0ASaya%20ingin%20mengembalikan%20buku...">
        Laporan Pengembalian Buku
      </a>
    </p>

    <h2>Kontak Lengkap</h2>
    <ul>
      <li>Email: <a href="mailto:admin@perpustakaan.com">admin@perpustakaan.com</a></li>
      <li>Bantuan: <a href="mailto:help@perpustakaan.com?subject=Bantuan">help@perpustakaan.com</a></li>
      <li>Kerjasama: <a href="mailto:partner@perpustakaan.com?subject=Kerjasama">partner@perpustakaan.com</a></li>
    </ul>
  </body>
</html>
```

## Poin Penting
- `mailto:` = buka **klien email** dengan alamat tujuan
- Bisa tambah parameter: `subject`, `cc`, `bcc`, `body`
- Parameter dipisah dengan `&`
- Spasi diganti `%20`, baris baru `%0A`
- Tidak semua pengguna punya klien email terinstall — siapkan fallback
