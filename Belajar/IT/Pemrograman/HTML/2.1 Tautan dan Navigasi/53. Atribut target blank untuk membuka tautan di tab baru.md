# Atribut target blank untuk Membuka Tautan di Tab Baru

## Analogi: Perpustakaan Digital

Bayangkan kamu sedang membaca buku di ruang baca. Ada catatan kaki yang berkata "Lihat juga buku referensi di rak sebelah". Tanpa atribut khusus, kamu **meninggalkan buku saat ini** dan pergi ke rak lain.

Tapi kalau ada **penanda buku** yang kamu selipkan di halaman saat ini, kamu bisa pergi ke rak lain lalu **kembali lagi** tanpa kehilangan halaman.

`target="_blank"` adalah **penanda buku digital**. Saat tautan diklik, halaman baru terbuka di **tab baru** — halaman lamamu tetap terbuka di tab sebelumnya.

## Penjelasan Detail

`target="_blank"` memberitahu browser untuk membuka tautan di **tab atau jendela baru**.

### Nilai Atribut `target`
| Nilai | Perilaku |
|-------|----------|
| `_self` | Buka di tab yang sama (default) |
| `_blank` | Buka di tab/jendela baru |
| `_parent` | Buka di frame induk |
| `_top` | Buka di jendela penuh (keluar dari frame) |

### Keamanan: `rel="noopener noreferrer"`
Saat pakai `target="_blank"`, halaman tujuan bisa mengakses halaman asal lewat `window.opener`. Ini risiko keamanan. Solusi:

```html
<a href="https://situs-luar.com" target="_blank" rel="noopener noreferrer">
  Kunjungi Situs
</a>
```

- `noopener` = mencegah akses `window.opener`
- `noreferrer` = sembunyikan referer (sumber lalu lintas)

### Kapan Pakai `target="_blank"`?
- Link ke website **eksternal**
- Link ke **PDF** atau dokumen
- Link ke halaman yang **berbeda konteks**
- Link ke **media sosial**

### Kapan JANGAN Pakai?
- Navigasi internal (halaman website sendiri)
- Link penting yang harus diingat pengguna (tab baru mudah terlewat)

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Target Blank</title>
  </head>
  <body>
    <h1>Link Eksternal Perpustakaan</h1>

    <h2>Tanpa target (buka di tab yang sama)</h2>
    <p><a href="tentang.html">Tentang Kami</a> — halaman internal, tetap di tab yang sama</p>

    <h2>Dengan target="_blank" (buka di tab baru)</h2>
    <ul>
      <li><a href="https://wikipedia.org" target="_blank" rel="noopener noreferrer">Wikipedia</a> — ensiklopedia bebas</li>
      <li><a href="https://google.com" target="_blank" rel="noopener noreferrer">Google</a> — mesin pencari</li>
      <li><a href="katalog.pdf" target="_blank">Katalog PDF</a> — dibuka di tab baru</li>
    </ul>

    <p><strong>Tips:</strong> Setelah mengklik link tab baru, tutup tab untuk kembali ke halaman ini.</p>
  </body>
</html>
```

## Poin Penting
- `target="_blank"` = buka tautan di **tab baru**
- Halaman asal **tetap terbuka** di tab lama
- WAJIB tambah `rel="noopener noreferrer"` untuk keamanan
- Untuk link eksternal, PDF, atau konten beda konteks
- Navigasi internal sebaiknya tetap di tab yang sama
