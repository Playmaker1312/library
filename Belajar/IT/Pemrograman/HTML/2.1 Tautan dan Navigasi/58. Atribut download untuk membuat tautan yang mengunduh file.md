# Atribut download untuk Membuat Tautan yang Mengunduh File

## Analogi: Perpustakaan Digital

Bayangkan **mesin fotokopi** di perpustakaan. Saat pengunjung menemukan buku yang ingin disalin, mereka menekan tombol dan mendapatkan salinan fisik.

Atribut `download` adalah **tombol fotokopi digital**. Biasanya, mengklik tautan ke file PDF akan membuka file di browser. Tapi dengan atribut `download`, browser akan **mengunduh** file tersebut alih-alih membukanya.

## Penjelasan Detail

Atribut `download` pada tag `<a>` memaksa browser untuk **mengunduh** file yang ditautkan, bukan membukanya.

### Format Dasar
```html
<a href="katalog.pdf" download>Unduh Katalog PDF</a>
```

### Menentukan Nama File
Kamu bisa memberi nama file yang berbeda saat diunduh:
```html
<a href="katalog.pdf" download="Katalog_Perpustakaan_2024.pdf">
  Unduh Katalog
</a>
```
File akan terunduh dengan nama `Katalog_Perpustakaan_2024.pdf`, bukan `katalog.pdf`.

### Keterbatasan
Atribut `download` hanya berfungsi untuk:
- File dari **domain yang sama** (same-origin)
- File dari domain lain jika respons server mengizinkan (CORS)

Untuk link ke domain lain, `download` tidak akan berfungsi.

### File yang Umum di-Download
- PDF, DOC, DOCX
- ZIP, RAR
- JPG, PNG (gambar)
- MP3, MP4
- CSV, JSON, XML

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Download Link</title>
  </head>
  <body>
    <h1>Unduh Berkas Perpustakaan</h1>

    <h2>Tanpa Atribut Download (File Dibuka di Browser)</h2>
    <p><a href="katalog.pdf">Lihat Katalog PDF</a> — file akan dibuka</p>

    <h2>Dengan Atribut Download (File Diunduh)</h2>
    <ul>
      <li><a href="katalog.pdf" download>Unduh Katalog Buku (PDF)</a></li>
      <li><a href="formulir-pendaftaran.docx" download>Unduh Formulir Pendaftaran</a></li>
      <li><a href="logo-perpus.png" download>Unduh Logo Perpustakaan</a></li>
    </ul>

    <h2>Download dengan Nama File Kustom</h2>
    <p><a href="katalog.pdf" download="Katalog_Perpustakaan_Digital_2024.pdf">Unduh Katalog (nama file: Katalog_Perpustakaan_Digital_2024.pdf)</a></p>
  </body>
</html>
```

## Poin Penting
- Atribut `download` = **unduh file**, bukan buka di browser
- Bisa tentukan nama file kustom: `download="nama-baru.pdf"`
- Hanya untuk file **same-origin** atau CORS
- Tidak perlu JavaScript, murni HTML
- Berguna untuk PDF, dokumen, gambar, dan file lainnya
