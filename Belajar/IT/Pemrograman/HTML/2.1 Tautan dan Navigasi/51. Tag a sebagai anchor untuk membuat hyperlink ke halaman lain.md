# Tag a sebagai Anchor untuk Membuat Hyperlink ke Halaman Lain

## Analogi: Perpustakaan Digital

Bayangkan **pintu penghubung** antara satu ruang baca ke ruang baca lainnya di perpustakaan. Atau **tautan dalam katalog** yang bertuliskan "Lihat buku terkait di rak sebelah".

`<a>` (anchor) adalah **pintu ajaib** yang menghubungkan halaman satu ke halaman lain. Klik teks atau tombol di dalamnya → langsung pindah ke halaman tujuan.

Inilah yang membuat web menjadi "web" — jaringan halaman yang saling terhubung.

## Penjelasan Detail

`<a>` adalah tag untuk membuat **hyperlink** — tautan yang menghubungkan ke halaman lain, file, email, atau bagian tertentu dalam halaman.

### Atribut Utama
| Atribut | Fungsi |
|---------|--------|
| `href` | URL tujuan tautan (wajib) |
| `target` | Cara membuka tautan (`_self`, `_blank`, `_parent`, `_top`) |
| `title` | Tooltip saat kursor diarahkan |
| `download` | Mengunduh file, bukan membukanya |
| `rel` | Hubungan dengan halaman tujuan |

### Format Dasar
```html
<a href="https://example.com">Klik di sini</a>
```

### Target
```html
<a href="halaman.html" target="_self">   Buka di tab yang sama (default)</a>
<a href="halaman.html" target="_blank">  Buka di tab baru</a>
```

### Contoh Berbagai Jenis Link
```html
<a href="halaman2.html">Ke halaman lain</a>
<a href="#bagian-bawah">Ke bagian bawah halaman</a>
<a href="mailto:admin@perpus.com">Kirim email</a>
<a href="file.pdf" download="Unduh">Unduh PDF</a>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Hyperlink</title>
  </head>
  <body>
    <h1>Navigasi Perpustakaan Digital</h1>

    <p>
      <a href="index.html">Beranda</a> |
      <a href="koleksi.html">Koleksi Buku</a> |
      <a href="tentang.html">Tentang Kami</a>
    </p>

    <h2>Link Eksternal</h2>
    <p>Kunjungi <a href="https://google.com" target="_blank">Google</a> untuk mencari buku.</p>

    <h2>Link Internal</h2>
    <p>Baca <a href="buku/laskar-pelangi.html">resensi Laskar Pelangi</a>.</p>

    <h2>Link Download</h2>
    <p><a href="katalog.pdf" download>Unduh Katalog Buku (PDF)</a></p>

    <h2>Link Email</h2>
    <p>Hubungi kami: <a href="mailto:admin@perpustakaan.com">admin@perpustakaan.com</a></p>
  </body>
</html>
```

## Poin Penting
- `<a>` = **anchor** — membuat hyperlink
- Atribut `href` = tujuan tautan (wajib)
- `target="_blank"` = buka di tab baru
- Bisa untuk: halaman, email, download, bagian halaman
- Teks di dalam `<a>` yang terlihat dan bisa diklik
