# Cara Membuat File HTML Pertama dengan Ekstensi .html atau .htm

## Analogi: Perpustakaan Digital

Bayangkan kamu ingin membuat **buku baru** di perpustakaan digital. Setiap buku harus punya **format yang benar** agar bisa dibaca pengunjung. File HTML adalah seperti **buku digital**:
- **Nama file** → judul buku
- **Ekstensi .html** → menandakan bahwa ini adalah buku HTML, bukan buku PDF atau Word
- **Isi file** → halaman-halaman buku

Ekstensi `.htm` juga bisa — bayangkan itu versi pendek dari `.html`, seperti singkatan nama buku. Keduanya sama-sama bisa dibaca.

## Penjelasan Detail

File HTML adalah file teks biasa yang disimpan dengan ekstensi `.html` atau `.htm`.

### Langkah Membuat File HTML Pertama

1. **Buka text editor** (VS Code, Notepad, dll)
2. **Tulis kode HTML**
3. **Simpan dengan ekstensi `.html`**
   - Buka menu File → Save As
   - Nama file: `index.html` (atau `halaman-pertama.html`)
   - Pastikan Save as type: All Files (*.*) atau HTML
   - Encoding: UTF-8

### Aturan Penamaan File HTML
- Gunakan huruf kecil (contoh: `beranda.html`, bukan `Beranda.HTML`)
- Gunakan tanda hubung untuk spasi (`tentang-kami.html`)
- Hindari karakter khusus (`@`, `!`, `$`, `#`, spasi)
- File utama biasanya bernama `index.html`

### .html vs .htm
- `.html` = standar modern (4 huruf, lebih jelas)
- `.htm` = warisan DOS (3 huruf, kompatibilitas lama)
- **Keduanya bekerja sama persis**
- Rekomendasi: gunakan `.html`

## Contoh Kode Implementasi

Cara membuat file HTML pertama:

```text
Langkah 1: Buka Notepad/VS Code
Langkah 2: Ketik ini:
```

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Halaman Pertamaku</title>
  </head>
  <body>
    <h1>Halo Dunia!</h1>
    <p>Ini adalah halaman HTML pertamaku.</p>
  </body>
</html>
```

```text
Langkah 3: Simpan sebagai "index.html"
Langkah 4: Double-click file HTML → otomatis terbuka di browser!
```

## Poin Penting
- File HTML adalah file teks biasa dengan ekstensi `.html`
- Simpan dengan encoding **UTF-8**
- `index.html` adalah nama standar untuk halaman utama
- Setelah disimpan, double-click untuk membuka di browser
