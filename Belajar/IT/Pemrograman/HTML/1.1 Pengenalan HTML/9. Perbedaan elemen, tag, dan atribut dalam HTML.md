# Perbedaan Elemen, Tag, dan Atribut dalam HTML

## Analogi: Perpustakaan Digital

Bayangkan kamu melihat **rak buku** di perpustakaan digital:

| Konsep | Analogi | Contoh HTML |
|--------|---------|-------------|
| **Tag** | **Label rak** — `<rak>` dan `</rak>` adalah tanda mulai dan selesainya rak | `<p>`, `</p>` |
| **Elemen** | **Rak buku lengkap** — dari label mulai, isinya, sampai label tutup | `<p>Isi buku</p>` |
| **Atribut** | **Stiker informasi** pada rak — seperti "Rak: Fiksi" yang memberi info tambahan | `class="fiksi"`, `id="rak-1"` |

**Tag** = label pembuka/penutup. **Elemen** = tag + konten. **Atribut** = informasi tambahan pada tag pembuka.

## Penjelasan Detail

### Tag
Tag adalah tanda kurung sudut (`< >`) yang berisi nama elemen.

Jenis tag:
- **Opening tag** — `<nama-tag>` (pembuka)
- **Closing tag** — `</nama-tag>` (penutup, pakai garis miring)
- **Self-closing tag** — `<nama-tag />` (tidak perlu penutup)

### Elemen
Elemen adalah kesatuan lengkap: **tag pembuka + konten + tag penutup** (atau self-closing tag).

```html
<p>Ini adalah konten paragraf</p>
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
        ↑  SATU ELEMEN  ↑
```

### Atribut
Atribut adalah informasi tambahan yang ditulis di **tag pembuka**.
Format: `nama-atribut="nilai"`

```html
<a href="https://google.com" target="_blank">Klik di sini</a>
   ^^^^^^^^^^^^^^^^^^^^^^^^ ^^^^^^^^^^^^^^^^^
         ↑ atribut              ↑ atribut
```

### Self-closing Tag
Beberapa tag tidak punya konten → langsung tutup sendiri.
```html
<br>    <!-- baris baru -->
<img src="foto.jpg">  <!-- gambar -->
<hr>    <!-- garis horizontal -->
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Contoh Tag Elemen Atribut</title>
  </head>
  <body>
    <!-- Elemen: tag pembuka + konten + tag penutup -->
    <h1>Judul Halaman</h1>
    <!-- ↑ tag ↑         ↑konten↑     ↑ tag penutup ↑ -->

    <!-- Elemen dengan atribut -->
    <img src="buku.jpg" alt="Sampul Buku" width="200">
    <!-- ↑ tag ↑ atribut ↑   ↑ atribut ↑   ↑ atribut ↑ -->

    <!-- Elemen bersarang (elemen di dalam elemen) -->
    <p>Buku <strong>sangat</strong> menarik!</p>
        <!-- ↑ elemen strong di dalam elemen p ↑ -->

    <!-- Self-closing tag -->
    <br>
    <hr>
  </body>
</html>
```

## Poin Penting
- **Tag** = pembatas (`<p>` dan `</p>`)
- **Elemen** = tag + konten di dalamnya (`<p>Teks</p>`)
- **Atribut** = info tambahan di tag pembuka (`class="fiksi"`)
- Self-closing tag tidak perlu tag penutup (`<br>`, `<img>`, `<hr>`)
