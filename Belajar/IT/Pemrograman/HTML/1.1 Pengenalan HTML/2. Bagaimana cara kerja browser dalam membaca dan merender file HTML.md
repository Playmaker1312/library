# Bagaimana Cara Kerja Browser dalam Membaca dan Merender File HTML

## Analogi: Perpustakaan Digital

Bayangkan kamu adalah **pengunjung perpustakaan digital** yang baru masuk. Kamu melihat cetak biru perpustakaan. Cara kerjamu membaca cetak biru itu mirip dengan cara browser membaca HTML:

1. **Terima cetak biru** → Kamu menerima lembaran blueprint (file HTML)
2. **Baca dari atas ke bawah** → Kamu melihat denah perpustakaan dari pintu masuk sampai ruang paling belakang
3. **Kenali simbol-simbol** → Setiap tag HTML adalah simbol yang kamu pahami artinya (`<h1>` = judul utama, `<p>` = paragraf)
4. **Terjemahkan ke bentuk nyata** → Kamu membayangkan bagaimana rak buku, meja baca, dan papan informasi akan diletakkan
5. **Tampilkan hasilnya** → Kamu menggambar ulang perpustakaan versimu berdasarkan cetak biru tersebut

## Penjelasan Detail

Proses browser merender HTML terdiri dari beberapa tahap:

1. **Parsing HTML** — Browser membaca file HTML dari atas ke bawah, mengubah teks mentah menjadi **DOM Tree** (Document Object Model). Setiap tag HTML menjadi node dalam pohon.

2. **Parsing CSS** — Browser membaca file CSS (jika ada) dan membuat **CSSOM Tree** (CSS Object Model).

3. **Membangun Render Tree** — DOM + CSSOM digabungkan menjadi Render Tree = elemen mana yang akan ditampilkan + bagaimana gayanya.

4. **Layout** — Browser menghitung posisi dan ukuran setiap elemen di layar.

5. **Painting** — Browser menggambar piksel ke layar.

```text
HTML → DOM Tree
CSS  → CSSOM Tree
         ↓
    Render Tree
         ↓
    Layout (posisi & ukuran)
         ↓
    Painting (gambar ke layar)
```

## Contoh Kode Implementasi

Untuk melihat DOM hasil parsing di browser:

1. Buka HTML di browser
2. Klik kanan → Inspect (atau F12)
3. Tab Elements → kamu bisa lihat DOM Tree hasil parsing browser

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Browser Reading</title>
  </head>
  <body>
    <h1>Judul Halaman</h1>
    <p>Ini adalah paragraf.</p>
  </body>
</html>
```

Browser akan memproses ini menjadi pohon DOM:
```
html
├── head
│   └── title
│       └── "Browser Reading"
└── body
    ├── h1
    │   └── "Judul Halaman"
    └── p
        └── "Ini adalah paragraf."
```

## Poin Penting
- Browser membaca HTML **sekuensial** dari atas ke bawah
- Proses rendering terdiri dari: Parse → Build Tree → Layout → Paint
- HTML yang salah pun tetap dicoba untuk dirender (error tolerance)
- Kamu bisa lihat hasil parsing DOM lewat Developer Tools (F12)
