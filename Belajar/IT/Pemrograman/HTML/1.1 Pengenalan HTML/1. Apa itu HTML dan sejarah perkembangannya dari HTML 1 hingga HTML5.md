# Apa itu HTML dan Sejarah Perkembangannya dari HTML 1 hingga HTML5

## Analogi: Perpustakaan Digital

Bayangkan kamu ingin membangun sebuah **perpustakaan digital** raksasa. HTML (HyperText Markup Language) adalah **cetak biru/blueprint** dari perpustakaan tersebut. Cetak biru ini menentukan:
- Di mana letak **rak buku** (konten)
- Di mana **papan informasi** (navigasi)
- Di mana **meja baca** (area konten utama)
- Bagaimana **label dan tanda** (heading/judul) tersusun

HTML **bukan** cat dinding (CSS - yang mengatur warna dan hiasan), dan **bukan** pustakawan (JavaScript - yang mengatur interaksi). HTML adalah **struktur dasarnya** — kerangka perpustakaannya.

## Penjelasan Detail

HTML adalah bahasa markup standar yang digunakan untuk membuat struktur halaman web. Dokumen HTML terdiri dari kumpulan **elemen** yang ditandai dengan **tag**. Browser membaca file HTML lalu menerjemahkannya menjadi halaman web yang bisa dilihat pengguna.

Sejarah singkat HTML:
| Versi | Tahun | Perubahan Utama |
|-------|-------|-----------------|
| HTML 1.0 | 1991 | Versi pertama, sangat dasar, hanya teks dan link |
| HTML 2.0 | 1995 | Standarisasi resmi pertama, mendukung form |
| HTML 3.2 | 1997 | Tabel, applet, text flow |
| HTML 4.01 | 1999 | Stylesheet, scripting, aksesibilitas lebih baik |
| XHTML 1.0 | 2000 | HTML dalam format XML yang lebih ketat |
| HTML5 | 2014 | Multimedia, semantic elements, canvas, API modern |

HTML5 adalah versi terbaru dan paling canggih, mendukung video, audio, grafik, dan aplikasi web tanpa plugin tambahan.

## Contoh Kode Implementasi

Dokumen HTML paling sederhana:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Halaman Pertamaku</title>
  </head>
  <body>
    <p>Halo, dunia!</p>
  </body>
</html>
```

## Poin Penting
- HTML adalah **kerangka**, bukan hiasan atau otak
- File HTML berekstensi `.html` atau `.htm`
- Browser membaca HTML dari atas ke bawah
- HTML terus berkembang, HTML5 adalah standar saat ini
