# Pengenalan Konsep Opening Tag dan Closing Tag serta Self-closing Tag

## Analogi: Perpustakaan Digital

Bayangkan kamu ingin menaruh buku di rak perpustakaan digital:

- **Opening tag** (`<p>`) = **Membuka pintu rak** → "Mulai menaruh konten di sini"
- **Closing tag** (`</p>`) = **Menutup pintu rak** → "Selesai, konten rak ini sudah lengkap"
- **Konten** = **Buku-buku** di dalam rak

Untuk rak khusus (self-closing), seperti **papan nama**:
- **Self-closing tag** (`<br>`) = **Papan nama sekali tempel** → tidak perlu buka-tutup, langsung jadi

Setiap konten harus punya awal dan akhir yang jelas agar perpustakaan tidak berantakan.

## Penjelasan Detail

### Opening Tag
Tag pembuka, ditulis dengan `<nama-tag>`.
```html
<p>
<h1>
<div>
<a>
```

### Closing Tag
Tag penutup, ditulis dengan `</nama-tag>` (pakai garis miring sebelum nama).
```html
</p>
</h1>
</div>
</a>
```

### Self-closing Tag
Tag yang langsung menutup sendiri, tidak perlu tag penutup terpisah.
```html
<br>      <!-- line break -->
<hr>      <!-- horizontal rule -->
<img>     <!-- image -->
<input>   <!-- input field -->
<meta>    <!-- metadata -->
<link>    <!-- link ke file eksternal -->
```

### Aturan Bersarang (Nesting)
Tag harus ditutup dalam urutan terbalik dari pembukaannya (seperti **stack**).

```html
<!-- BENAR -->
<p><strong>Ini teks tebal</strong></p>
<!-- urutan: buka p, buka strong, tutup strong, tutup p -->

<!-- SALAH -->
<p><strong>Ini teks tebal</p></strong>
<!-- urutan SALAH: buka p, buka strong, tutup p, tutup strong -->
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Opening Closing Tag</title>
  </head>
  <body>
    <!-- Opening tag + konten + closing tag -->
    <h1>Ini Heading</h1>
    <p>Ini paragraf dengan <strong>teks tebal</strong> di dalamnya.</p>

    <!-- Self-closing tag -->
    <hr>
    <p>Baris pertama.</p>
    <br>
    <p>Baris kedua setelah jeda.</p>
    <hr>

    <!-- Bersarang yang benar -->
    <div>
      <p>Paragraf di <em>dalam</em> div.</p>
    </div>
  </body>
</html>
```

## Poin Penting
- **Opening tag** = `<nama>`, **Closing tag** = `</nama>`
- Self-closing tag tidak butuh penutup (`<br>`, `<hr>`, `<img>`)
- Tag yang dibuka **paling akhir** harus ditutup **paling awal** (LIFO)
- Lupa menutup tag bisa merusak layout halaman
