# Struktur Dasar Dokumen HTML yang Benar dan Valid

## Analogi: Perpustakaan Digital

Bayangkan sebuah **perpustakaan digital** yang ideal. Setiap perpustakaan punya **struktur standar**:
1. **Plang Nama Perpustakaan** → di bagian paling atas (DOCTYPE)
2. **Gedung Utama** → seluruh bangunan (`<html>`)
3. **Ruang Administrasi** → tempat data tersembunyi seperti katalog, pengaturan (`<head>`)
4. **Ruang Baca Utama** → tempat konten yang terlihat pengunjung (`<body>`)

Tanpa struktur ini, perpustakaan akan kacau dan pengunjung bingung.

## Penjelasan Detail

Setiap dokumen HTML yang valid WAJIB memiliki struktur dasar berikut:

```html
<!DOCTYPE html>        <!-- 1. DOCTYPE: memberitahu browser versi HTML -->
<html lang="id">       <!-- 2. <html>: elemen root (induk dari semua elemen) -->
  <head>               <!-- 3. <head>: metadata, tidak tampil di halaman -->
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Judul Halaman</title>
  </head>
  <body>               <!-- 4. <body>: konten yang tampil di browser -->
    <h1>Halo Dunia</h1>
    <p>Ini paragraf pertama.</p>
  </body>
</html>
```

Aturan penting struktur HTML:
- Hanya ada SATU `<html>` (root element)
- `<head>` selalu SEBELUM `<body>`
- Semua tag harus **bersarang dengan benar** (nested properly)
- Gunakan indentasi agar mudah dibaca

## Contoh Kode Implementasi

Struktur HTML yang benar:

```html
<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Perpustakaan Digital</title>
  </head>
  <body>
    <h1>Selamat Datang di Perpustakaan Digital</h1>
    <p>Silakan membaca buku-buku yang tersedia.</p>
  </body>
</html>
```

## Poin Penting
- `<!DOCTYPE html>` harus ada di baris **pertama**
- `<html>` adalah **elemen root** (paling luar)
- `<head>` untuk **metadata** (tidak terlihat), `<body>` untuk **konten** (terlihat)
- Struktur ini WAJIB untuk dokumen HTML yang valid
