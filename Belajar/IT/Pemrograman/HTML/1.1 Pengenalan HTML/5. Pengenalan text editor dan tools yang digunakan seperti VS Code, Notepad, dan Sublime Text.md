# Pengenalan Text Editor dan Tools yang Digunakan

## Analogi: Perpustakaan Digital

Bayangkan kamu adalah **penulis buku** di perpustakaan digital. Untuk menulis, kamu butuh **alat tulis**:
- **Notepad** → Kertas polos dan pulpen. Bisa menulis, tapi tidak ada fitur khusus.
- **Sublime Text** → Buku catatan dengan spidol warna-warni. Cepat, ringan, dan bisa diwarnai.
- **VS Code** → Meja kerja digital super lengkap. Ada lampu baca, rak referensi, kertas bergaris, koreksi otomatis, dan ribuan alat bantu (ekstensi).

Semuanya bisa dipakai, tapi alat yang lebih canggih membuat pekerjaan lebih cepat dan nyaman.

## Penjelasan Detail

Text editor adalah aplikasi yang digunakan untuk menulis dan mengedit kode HTML.

| Tool | Kelebihan | Kekurangan | Cocok Untuk |
|------|-----------|------------|-------------|
| **Notepad** (built-in Windows) | Gratis, sudah ada | Tidak ada fitur tambahan | Absolute beginner, testing cepat |
| **VS Code** | Gratis, ekstensi melimpah, debugger, terminal | Agak berat | Semua level |
| **Sublime Text** | Super cepat, ringan | Berbayar (trial forever) | Developer yang suka kecepatan |
| **Notepad++** | Gratis, ringan, tab-based | Kurang modern | Windows user |
| **Atom** (dihentikan) | Gratis, open source | Sudah tidak dikembangkan | Legacy user |

### Fitur yang Membantu Belajar HTML
- **Syntax Highlighting** → kode HTML diberi warna berbeda
- **Emmet** → shortcut menulis tag HTML cepat
- **Live Preview** → lihat hasil langsung
- **Auto-completion** → saran tag otomatis

## Poin Penting
- Semua text editor bisa menulis HTML (file teks biasa)
- VS Code adalah **pilihan terbaik** untuk pemula
- Fitur syntax highlighting sangat membantu belajar
- Tidak perlu tool mahal untuk memulai
