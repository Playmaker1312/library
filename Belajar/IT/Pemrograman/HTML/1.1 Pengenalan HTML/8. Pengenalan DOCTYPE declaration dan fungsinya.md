# Pengenalan DOCTYPE Declaration dan Fungsinya

## Analogi: Perpustakaan Digital

Bayangkan kamu masuk ke sebuah **perpustakaan digital**. Di pintu masuk, ada **plang besar** yang bertuliskan:

> **"PERPUSTAKAAN DIGITAL — Standar Bangunan 2024"**

Plang ini memberitahu pengunjung (browser) bahwa perpustakaan ini dibangun mengikuti standar tertentu. Tanpa plang ini, pengunjung bingung: "Apakah ini perpustakaan standar lama atau baru? Bagaimana cara saya membaca denahnya?"

`<!DOCTYPE html>` adalah **plang pintu masuk** perpustakaan digitalmu. Letaknya WAJIB di baris **pertama** dokumen HTML, sebelum apa pun.

## Penjelasan Detail

`<!DOCTYPE html>` adalah deklarasi yang memberitahu browser tentang **versi HTML** yang digunakan dalam dokumen.

### Sejarah DOCTYPE
Di era HTML 4.01, DOCTYPE sangat rumit:
```html
<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN"
"http://www.w3.org/TR/html4/loose.dtd">
```

Di HTML5, DOCTYPE disederhanakan menjadi sangat pendek:
```html
<!DOCTYPE html>
```

### Fungsi DOCTYPE
1. **Memicu standar mode** (standards mode) di browser → browser merender halaman sesuai standar terbaru
2. **Mencegah quirks mode** → mode lama untuk kompatibilitas dengan website jadul
3. **Wajib untuk validasi** HTML

Tanpa DOCTYPE, browser masuk ke **quirks mode** — mencoba menebak-nebak, hasilnya bisa kacau.

### Aturan Penting
- DOCTYPE **bukan tag HTML** — ini adalah deklarasi
- DOKTYPE harus di **baris pertama** file
- Tidak perlu ditutup (self-closing declaration)
- Penulisan `<!DOCTYPE html>` (case insensitive, tapi huruf besar lebih umum)

## Contoh Kode Implementasi

```html
<!DOCTYPE html>   <!-- WAJIB: baris pertama -->
<html>
  <head>
    <title>Judul Halaman</title>
  </head>
  <body>
    <h1>Halaman dengan DOCTYPE yang benar</h1>
  </body>
</html>
```

Tanpa DOCTYPE (salah):
```html
<html>            <!-- Baris pertama bukan DOCTYPE -->
  <head>
    <title>Tanpa DOCTYPE</title>
  </head>
  <body>
    <h1>Halaman ini mungkin tampil aneh di beberapa browser</h1>
  </body>
</html>
```

## Poin Penting
- `<!DOCTYPE html>` harus di **baris pertama** file HTML
- Berfungsi memberitahu browser versi HTML yang digunakan
- Tanpa DOCTYPE → browser masuk **quirks mode** (mode kacau)
- HTML5 menggunakan DOCTYPE sederhana: `<!DOCTYPE html>`
