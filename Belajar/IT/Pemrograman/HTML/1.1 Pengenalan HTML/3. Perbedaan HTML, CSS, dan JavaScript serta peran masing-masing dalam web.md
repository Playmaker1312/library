# Perbedaan HTML, CSS, dan JavaScript serta Peran Masing-masing dalam Web

## Analogi: Perpustakaan Digital

Bayangkan tiga tim yang membangun perpustakaan digital:

| Tim | Peran | Analogi Perpustakaan |
|-----|-------|---------------------|
| **HTML** | Struktur & Konten | **Arsitek** — Membuat cetak biru: di mana rak buku, meja, papan nama, dan pintu berada. Menentukan isi perpustakaan. |
| **CSS** | Tampilan & Gaya | **Desainer Interior** — Memilih warna dinding, jenis kayu rak buku, font papan nama, dan pencahayaan. Membuat perpustakaan terlihat indah. |
| **JavaScript** | Interaksi & Perilaku | **Pustakawan** — melayani pengunjung, mencari buku, menambahkan buku baru, menutup pintu otomatis saat hujan. Membuat perpustakaan hidup dan responsif. |

Ketiganya HARUS bekerja sama. Tanpa HTML, tidak ada struktur. Tanpa CSS, tampilan berantakan. Tanpa JavaScript, halaman mati dan tidak interaktif.

## Penjelasan Detail

| Aspek | HTML | CSS | JavaScript |
|-------|------|-----|-----------|
| Kepanjangan | HyperText Markup Language | Cascading Style Sheets | (nama merek) |
| Fungsi utama | Membuat struktur & konten | Mengatur tampilan & layout | Mengatur perilaku & interaksi |
| Jenis | Bahasa markup | Bahasa stylesheet | Bahasa pemrograman |
| Contoh | `<h1>Judul</h1>`, `<p>Teks</p>` | `color: red;`, `font-size: 16px;` | `alert('Halo!');`, `button.onclick` |
| Disimpan di | File `.html` | File `.css` | File `.js` |
| Bisa berdiri sendiri? | Ya, dasar | Tidak, butuh HTML | Tidak, butuh HTML |

## Contoh Kode Implementasi

```html
<!-- HTML: Struktur -->
<!DOCTYPE html>
<html>
<head>
  <!-- CSS: Tampilan -->
  <style>
    .rak-buku {
      background-color: #8B4513;
      color: white;
      padding: 20px;
      border-radius: 10px;
    }
  </style>
</head>
<body>
  <div class="rak-buku">
    <p>Selamat datang di Perpustakaan Digital</p>
    <button id="tombolPinjam">Pinjam Buku</button>
  </div>

  <!-- JavaScript: Interaksi -->
  <script>
    document.getElementById('tombolPinjam').onclick = function() {
      alert('Buku berhasil dipinjam!');
    };
  </script>
</body>
</html>
```

## Poin Penting
- HTML = **struktur** (kerangka perpustakaan)
- CSS = **tampilan** (dekorasi perpustakaan)
- JavaScript = **interaksi** (pustakawan yang melayani)
- Ketiganya saling melengkapi, tidak bisa dipisahkan
