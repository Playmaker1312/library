# Cara Membuka dan Menjalankan File HTML di Browser

## Analogi: Perpustakaan Digital

Bayangkan kamu baru saja menulis **buku digital** (file HTML). Untuk membacanya, kamu perlu **meletakkan buku itu di meja baca** (browser). Browser adalah seperti **meja baca ajaib** yang bisa menerjemahkan cetak biru perpustakaan menjadi perpustakaan sungguhan.

Prosesnya sederhana:
1. Kamu punya buku (`index.html`)
2. Kamu letakkan di meja baca (browser)
3. Meja baca otomatis membuka buku dan menampilkannya

## Penjelasan Detail

Ada beberapa cara untuk membuka file HTML di browser:

### Cara 1: Double-click Langsung (Paling Mudah)
- Cari file `.html` di File Explorer
- Double-click file tersebut
- File akan terbuka di browser default

### Cara 2: Drag and Drop
- Buka browser (Chrome, Firefox, Edge)
- Seret (drag) file HTML dari File Explorer ke jendela browser
- File akan langsung terbuka

### Cara 3: Dari Browser - File → Open
- Buka browser
- Tekan `Ctrl + O` (Windows/Linux) atau `Cmd + O` (Mac)
- Pilih file HTML yang ingin dibuka

### Cara 4: VS Code - Live Server (Rekomendasi)
- Install ekstensi "Live Server" di VS Code
- Klik kanan file HTML → "Open with Live Server"
- File akan otomatis direfresh setiap kali kamu menyimpan perubahan

### Melihat Source Code HTML
Di browser, kamu bisa lihat kode HTML asli:
- Klik kanan → **View Page Source** (atau `Ctrl + U`)

## Contoh Kode Implementasi

Buat file `index.html` ini, lalu double-click:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Selamat Datang</title>
  </head>
  <body>
    <h1>Halo! Selamat datang di website pertama saya.</h1>
    <p>File ini dibuka menggunakan browser.</p>
  </body>
</html>
```

Setelah dibuka, coba:
1. Klik kanan → View Page Source → lihat kode HTML asli
2. Tekan F12 → Developer Tools → lihat bagaimana browser memproses HTML

## Poin Penting
- Cara termudah: **double-click** file `.html`
- Live Server sangat membantu saat coding (auto refresh)
- Kamu bisa lihat source code kapan saja dengan `Ctrl + U`
- File HTML bisa dibuka di browser MANAPUN
