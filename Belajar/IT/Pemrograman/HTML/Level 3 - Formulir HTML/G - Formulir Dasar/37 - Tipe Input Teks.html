Tipe Input Teks — Jenis Pintu Berbeda

Penjelasan

Elemen <input> memiliki atribut type yang menentukan jenis data yang bisa dimasukkan. Untuk data teks, ada beberapa tipe: text (teks biasa), email (alamat email), password (kata sandi — karakter ditutup), tel (nomor telepon), dan url (alamat web). Setiap tipe memicu keyboard yang berbeda di perangkat seluler dan memiliki validasi bawaan.

Fungsi

  • text: input teks bebas — nama, alamat, judul, dll.
  • email: validasi format email otomatis, keyboard @ di mobile
  • password: karakter disembunyikan (bullet/dot), tidak boleh tampil di layar
  • tel: memicu keypad numerik di perangkat seluler
  • url: validasi format URL, keyboard /.com di mobile

Cara Pengimplementasian

<label for="nama">Nama:</label>
<input type="text" id="nama" name="nama"
       placeholder="Masukkan nama lengkap">

<label for="email">Email:</label>
<input type="email" id="email" name="email"
       placeholder="contoh@email.com">

<label for="pass">Password:</label>
<input type="password" id="pass" name="pass"
       placeholder="Min 8 karakter">

<label for="telp">Telepon:</label>
<input type="tel" id="telp" name="telp"
       placeholder="0812-3456-7890">

<label for="web">Website:</label>
<input type="url" id="web" name="web"
       placeholder="https://contoh.com">

Analogi — Jenis Pintu Masuk

Bayangkan sebuah bangunan dengan berbagai jenis pintu:

  • text — Pintu masuk umum, bisa dilewati siapa saja tanpa syarat khusus
  • email — Pintu dengan pemindai yang memastikan yang masuk memiliki format "@" (validasi format)
  • password — Pintu buram/kaca gelap — orang di luar tidak bisa melihat apa yang ada di dalam
  • tel — Pintu putar yang hanya menerima orang dengan tinggi tertentu (hanya angka)
  • url — Pintu dengan pemindai yang memastikan yang masuk adalah alamat web valid (diawali http://)

Di perangkat seluler, setiap pintu otomatis menampilkan papan tombol yang sesuai — keypad teks untuk nama, keypad dengan "@" untuk email, keypad numerik untuk telepon.

Dipaki Untuk

  • text: nama pengguna, alamat, judul, komentar singkat
  • email: form pendaftaran, login via email, newsletter
  • password: form login, form ganti kata sandi
  • tel: nomor WhatsApp, kontak darurat, nomor telepon rumah
  • url: alamat website/social media, portofolio

Kesalahan Umum

  • Menggunakan type="text" untuk semua data — padahal type="email" dan type="url" menyediakan validasi bawaan dan keyboard yang tepat di mobile
  • Menyimpan password sebagai teks biasa (type="text") — membahayakan keamanan karena orang di sekitar bisa melihat
  • Mengandalkan validasi HTML saja tanpa validasi server — validasi HTML hanya kenyamanan front-end, bisa dilewati dengan mudah
  • Tidak menyertakan atribut placeholder sebagai petunjuk format pengisian
  • Tidak menggunakan inputmode untuk kustomisasi keyboard pada tipe yang kurang spesifik

Koneksi dengan Materi Sebelumnya

Materi sebelumnya memperkenalkan <input> secara umum beserta pasangannya <label>. Sekarang kita memperdalam dengan variasi tipe input teks. Setiap tipe menambahkan "aturan main" khusus pada input yang sama. Materi selanjutnya akan membahas tipe pilihan (checkbox, radio) yang bahkan lebih berbeda lagi perilakunya.

Soal Latihan

  1. Sebutkan tiga tipe input teks selain text dan jelaskan keyboard apa yang muncul di perangkat seluler untuk masing-masing!

    Lihat Jawaban

    email — keyboard dengan simbol @ dan domain umum (.com). tel — keypad numerik 0-9. url — keyboard dengan tombol /.com. password — keyboard biasa tetapi karakter yang diketik tidak terlihat.

  2. Mengapa menggunakan type="password" penting dan apa keterbatasannya?

    Lihat Jawaban

    Penting karena karakter password tidak terlihat di layar, melindungi dari "shoulder surfing" (orang mengintip dari belakang). Keterbatasannya: data tetap dikirim sebagai teks biasa jika tidak dienkripsi HTTPS — jadi HTTPS wajib digunakan. Juga, type="password" hanya menyembunyikan tampilan, bukan mengenkripsi data.

  3. Apa fungsi atribut placeholder pada input teks?

    Lihat Jawaban

    placeholder menampilkan teks petunjuk singkat di dalam kolom input sebelum pengguna mengetik. Teks ini akan hilang saat pengguna mulai mengetik. Gunakan untuk memberi contoh format, bukan sebagai pengganti <label>.
