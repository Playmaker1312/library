<label> dan <input> — Tanda Pengenal Ruangan

Penjelasan

<label> adalah elemen yang memberikan keterangan atau nama pada elemen input. Setiap <input> wajib memiliki <label> yang terkait. Hubungan ini bisa dibuat secara explicit (menggunakan atribut for pada label dan id pada input) atau secara implicit (dengan membungkus input di dalam label).

Fungsi

  • Memberi nama/judul pada elemen input sehingga pengguna tahu data apa yang harus diisi
  • Memperbesar area klik — saat label diklik, fokus melompat ke input yang terkait
  • Membantu pengguna screen reader membaca formulir dengan benar
  • Memenuhi standar aksesibilitas WCAG (Web Content Accessibility Guidelines)

Cara Pengimplementasian

<!-- Cara EKSPLISIT: for = id -->
<label for="nama">Nama Lengkap:</label>
<input type="text" id="nama" name="nama">

<!-- Cara IMPLISIT: label membungkus input -->
<label>
  Email:
  <input type="email" name="email">
</label>

Kedua cara di atas sah, tetapi cara eksplisit lebih disarankan karena lebih jelas dan tidak bergantung pada struktur DOM.

Analogi — Papan Nama di Depan Rumah

<label> ibarat papan nama yang dipasang di depan setiap rumah. Bayangkan sebuah perumahan dengan banyak rumah (input). Tanpa papan nama, Anda harus menebak-nebak rumah mana yang harus dimasuki. Dengan papan nama (label), Anda langsung tahu: "Ini rumah Pak Budi, itu rumah Bu Sari."

Kelebihan lainnya: saat Anda menyentuh atau menekan papan nama (for), pintu rumah yang sesuai akan terbuka (fokus berpindah ke input). Ini sangat membantu, terutama di perangkat seluler di mana area klik kecil sulit ditekan.

Dipaki Untuk

  • Semua formulir yang membutuhkan input dari pengguna — dari form login, pendaftaran, hingga survei
  • Memenuhi standar aksesibilitas agar formulir bisa digunakan oleh penyandang disabilitas
  • Meningkatkan user experience (UX) dengan memperbesar area klik — krusial di layar sentuh

Kesalahan Umum

  • Tidak menggunakan <label> sama sekali — hanya meletakkan teks biasa di samping input. Ini membuat screen reader kebingungan dan area klik tidak membesar.
  • Atribut for pada label tidak cocok dengan id pada input (misal typo), sehingga hubungan tidak terbentuk.
  • Menggunakan placeholder sebagai pengganti label — placeholder menghilang saat mengetik dan menyulitkan pengguna.
  • Lebih dari satu elemen input menggunakan id yang sama — id harus unik dalam satu halaman.

Koneksi dengan Materi Sebelumnya

Setelah memahami <form> sebagai wadah, materi ini memperkenalkan pasangan label dan input — komponen isi dari wadah tersebut. Label dan input adalah "batu bata" pertama yang mengisi struktur form. Materi berikutnya (tipe-tipe input) akan semakin memperkaya jenis "batu bata" yang bisa Anda gunakan.

Soal Latihan

  1. Apa perbedaan antara menghubungkan label dan input secara eksplisit (for + id) versus implisit (label membungkus input)?

    Lihat Jawaban

    Cara eksplisit menggunakan atribut for pada label dan id pada input. Cara implisit tidak perlu for/id — label cukup membungkus input di dalamnya. Cara eksplisit lebih disarankan karena lebih jelas dan tidak tergantung pada struktur DOM, sehingga lebih mudah dipelihara.

  2. Mengapa kita tidak boleh mengganti <label> dengan atribut placeholder?

    Lihat Jawaban

    Karena placeholder akan hilang begitu pengguna mulai mengetik, sehingga pengguna tidak bisa memastikan data apa yang harus diisi. Selain itu, screen reader membaca placeholder dengan cara berbeda dari label, yang bisa membingungkan pengguna tunanetra. placeholder hanya petunjuk tambahan, bukan pengganti label.

  3. Apa yang terjadi ketika atribut for pada label tidak cocok dengan id pada input manapun?

    Lihat Jawaban

    Tidak ada error yang muncul, tetapi hubungan antara label dan input tidak terbentuk. Akibatnya, mengklik label tidak akan memindahkan fokus ke input manapun, dan screen reader tidak bisa mengasosiasikan label dengan input yang benar.
