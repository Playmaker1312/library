📑 Tipe Input date, time & file

📄 Penjelasan

type="date" — menampilkan picker kalender (date picker) yang memudahkan pengguna memilih tanggal secara visual. Format nilai yang dikirim adalah YYYY-MM-DD (tahun-bulan-tanggal).

type="time" — menampilkan picker jam (time picker) untuk memilih waktu (jam dan menit, opsional detik). Format nilai yang dikirim adalah HH:MM atau HH:MM:SS.

type="file" — menampilkan tombol "Pilih File" yang membuka dialog file system pengguna. Mendukung accept untuk memfilter jenis file dan multiple untuk memilih banyak file sekaligus.

🚀 Fungsi

  • date — memilih tanggal lahir, tanggal janji temu, tanggal pesanan, dll. Browser menyediakan kalender interaktif.
  • time — memilih jam mulai acara, jam kedatangan, jam buka/tutup, dll.
  • file — mengunggah foto profil, dokumen PDF, lampiran email, dll.
  • accept — membatasi jenis file yang bisa dipilih (misal hanya gambar atau PDF).
  • multiple — mengizinkan pengguna memilih lebih dari satu file dalam satu kali klik.
Tipe Atribut Penting Nilai Dikirim
date min, max, value YYYY-MM-DD — misal 2026-06-22
time min, max, value, step HH:MM atau HH:MM:SS — misal 14:30
file accept, multiple Objek File (data biner)

🔧 Cara Pengimplementasian

<!-- Date picker -->
<input type="date" name="tanggal_lahir">

<!-- Date dengan batasan -->
<input type="date" name="tanggal_pesan" min="2026-01-01" max="2026-12-31">

<!-- Time picker -->
<input type="time" name="jam_mulai">

<!-- Time dengan step 30 menit -->
<input type="time" name="jam_selesai" step="1800">

<!-- File upload -->
<input type="file" name="foto_profil" accept="image/*">

<!-- File upload dengan filter spesifik -->
<input type="file" name="dokumen" accept=".pdf,.doc,.docx">

<!-- Multiple file upload -->
<input type="file" name="galeri" accept="image/*" multiple>

<!-- Catatan: form untuk file wajib punya enctype="multipart/form-data" -->
<form action="/upload" method="post" enctype="multipart/form-data">
    <input type="file" name="lampiran" accept=".pdf,.jpg" multiple>
    <button type="submit">Upload</button>
</form>

Nilai umum accept:

  • image/* — semua jenis gambar (jpg, png, gif, webp)
  • .pdf — dokumen PDF
  • .doc,.docx — dokumen Word
  • .xls,.xlsx — dokumen Excel
  • video/* — semua jenis video
  • .zip,.rar — file arsip

💡 Untuk type="file" formulir harus menggunakan enctype="multipart/form-data" dan method="post".

🏠 Analogi — Rumah

Bayangkan Anda mengelola sebuah bangunan perkantoran.

  • type="date" — seperti kalender meja resepsionis yang bisa dibolak-balik untuk memilih tanggal janji temu. Anda tinggal menunjuk tanggal, tanpa perlu menulis manual "22 Juni 2026".
  • type="time" — seperti jam dinding digital di ruang rapat yang bisa diatur ke waktu tertentu. Anda memutar jarum (atau mengklik) untuk memilih jam mulai meeting.
  • type="file" — seperti kotak surat masuk di depan gedung. Anda bisa memasukkan satu amplop (satu file) atau setumpuk amplop (multiple file). Label "accept" adalah petunjuk di kotak yang bertuliskan "Hanya untuk dokumen PDF dan JPG".
  • multiple — seperti kotak surat yang punya kapasitas besar — bisa menerima banyak amplop sekaligus, bukan satu per satu.

💡 Dipakai Untuk

  • Formulir pendaftaran — tanggal lahir, jam registrasi.
  • Formulir reservasi hotel — tanggal check-in/check-out, jam kedatangan.
  • Formulir upload — foto profil (1 file), galeri (multiple), dokumen lamaran kerja (PDF).
  • Sistem absensi — jam masuk dan jam pulang.
  • Formulir pengaduan — upload bukti screenshot.

⚠️ Kesalahan Umum

  • Lupa enctype="multipart/form-data": Tanpa ini, file tidak akan terupload. Formulir wajib menggunakan method="post" dan enctype="multipart/form-data".
  • Mengira accept menjamin keamanan: accept hanya memfilter di sisi klien. Pengguna tetap bisa memilih file apa pun. Validasi jenis dan ukuran file TETAP harus dilakukan di server!
  • Format date tidak sesuai region: Nilai yang dikirim selalu YYYY-MM-DD, tapi tampilan date picker tergantung browser/OS. Jangan kaget Indonesia menampilkan "DD/MM/YYYY" sementara Amerika "MM/DD/YYYY".
  • Menggunakan value pada date dengan format salah: Atribut value untuk date harus YYYY-MM-DD (ISO 8601), bukan DD/MM/YYYY.
  • Lupa atribut name pada file input: File input tanpa name tidak akan terkirim ke server.

🔗 Koneksi dengan Materi Sebelumnya

Tipe input ini melengkapi materi tipe input dasar (text, number, email) yang sudah dipelajari. date dan time bisa dikombinasikan dengan atribut min/max untuk membatasi rentang. file membutuhkan pemahaman tentang elemen <form> (terutama method dan enctype). Atribut multiple juga terkait dengan atribut disabled/readonly dalam hal kontrol interaksi pengguna.

📝 Soal Latihan

Soal 1: Buat form upload yang menerima file gambar (jpg/png) dan mengizinkan banyak file sekaligus. Sertakan atribut enctype yang benar!

📄 Lihat Jawaban 
<form action="/upload" method="post" enctype="multipart/form-data">
    <label for="gambar">Pilih Gambar:</label>
    <input type="file" id="gambar" name="galeri" accept=".jpg,.jpeg,.png" multiple>
    <button type="submit">Upload</button>
</form>

Soal 2: Buat input tanggal lahir dengan batas minimal tanggal 1 Januari 2000 dan maksimal hari ini (31 Desember 2015). Tulis kode HTML-nya!

📄 Lihat Jawaban 
<input type="date" name="tgl_lahir" min="2000-01-01" max="2015-12-31">

Format tanggal pada atribut min dan max harus YYYY-MM-DD.

Soal 3: Apa fungsi enctype="multipart/form-data" pada form yang memiliki input file? Apa yang terjadi jika tidak disertakan?

📄 Lihat Jawaban

enctype="multipart/form-data" memberi tahu server bahwa data form mengandung file biner yang perlu di-encode secara khusus. Tanpa atribut ini (default application/x-www-form-urlencoded), file tidak akan terkirim dengan benar — server hanya akan menerima nama file, bukan isi filenya.
