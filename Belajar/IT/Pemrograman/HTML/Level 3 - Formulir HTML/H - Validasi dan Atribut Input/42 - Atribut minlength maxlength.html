📑 Atribut minlength, maxlength, min & max

📄 Penjelasan

minlength — menentukan jumlah karakter minimum yang harus diketik pengguna pada input teks (text, email, password, textarea).

maxlength — membatasi jumlah karakter maksimum yang bisa diketik. Begitu mencapai batas, input tidak mau menerima karakter tambahan.

min — menentukan nilai minimal yang valid untuk input angka (number, range, date, dll).

max — menentukan nilai maksimal yang valid untuk input angka.

🚀 Fungsi

  • minlength / maxlength — memvalidasi panjang teks (contoh: nama 2–100 karakter, kata sandi minimal 8 karakter).
  • min / max — memvalidasi rentang numerik (contoh: umur 17–100, jumlah pesanan 1–99, tanggal lahir tidak di masa depan).
  • Semuanya mencegah data tidak valid masuk ke server tanpa perlu JavaScript.
Atribut Berlaku untuk tipe Cara kerja
minlength text, email, password, search, tel, url, textarea Batas bawah jumlah karakter (validasi saat submit)
maxlength sama seperti di atas Batas atas jumlah karakter (langsung dicegah saat mengetik)
min number, range, date, datetime-local, month, time, week Nilai minimum yang diterima
max sama seperti di atas Nilai maksimum yang diterima

🔧 Cara Pengimplementasian

<!-- Batas panjang teks -->
<input type="text" name="nama" minlength="2" maxlength="100">
<textarea name="alamat" maxlength="255"></textarea>

<!-- Rentang angka -->
<input type="number" name="umur" min="17" max="100">
<input type="number" name="jumlah" min="1" max="99" value="1">

<!-- Rentang tanggal -->
<input type="date" name="tgl_lahir" min="1920-01-01" max="2010-12-31">

<!-- Kombinasi lengkap -->
<label>Nama Depan (2-50 karakter):</label>
<input type="text" name="nama_depan" minlength="2" maxlength="50" required>

<label>Usia (17-100 tahun):</label>
<input type="number" name="usia" min="17" max="100" required>

Catatan: minlength tidak mencegah pengetikan seperti maxlength. Ia hanya menolak saat submit. maxlength langsung memblokir karakter tambahan saat diketik.

🏠 Analogi — Rumah

Bayangkan Anda sedang membangun pagar rumah.

  • minlength — seperti pagar dengan tinggi minimal 1 meter. Pagar yang terlalu pendek tidak diizinkan.
  • maxlength — seperti tinggi pagar maksimal 2 meter karena peraturan lingkungan. Tidak boleh lebih tinggi dari itu.
  • min — seperti jumlah lantai rumah minimal 1 lantai. Tidak boleh 0 lantai.
  • max — seperti jumlah lantai rumah maksimal 3 lantai karena batas zona bangunan.

Jika seseorang mencoba membangun pagar setinggi 3 meter (melanggar max), proyek akan ditolak. Jika halaman pesan hanya berisi 1 karakter (minlength dilanggar), formulir tidak bisa dikirim.

💡 Dipakai Untuk

  • Formulir registrasi — nama (2–100), password (min 8).
  • Formulir usia — input number dengan min 17 untuk batasan umur.
  • Formulir pemesanan — jumlah barang (min 1, maks 99).
  • Komentar atau ulasan — textarea dengan maxlength agar tidak terlalu panjang.
  • Input tanggal lahir — dengan rentang tahun tertentu.

⚠️ Kesalahan Umum

  • minlength di input number tidak berpengaruh: Gunakan min untuk input angka, bukan minlength.
  • Lupa batas atas textarea: Textarea tanpa maxlength bisa diisi teks sangat panjang dan membebani server.
  • Nilai min lebih besar dari max: Logika terbalik — browser tidak akan memprosesnya dengan benar.
  • Mengira maxlength membatasi panjang nilai angka: maxlength membatasi jumlah digit yang diketik, bukan nilai numerik. Untuk batas nilai numerik, gunakan min/max.
  • Tidak memberi pesan error kustom: Pesan default browser seperti "Harap persingkat teks ini hingga 100 karakter atau kurang" terkadang kurang ramah pengguna.

🔗 Koneksi dengan Materi Sebelumnya

Atribut ini melengkapi validasi dasar required yang sudah dipelajari. Jika required hanya memastikan kolom tidak kosong, minlength/maxlength dan min/max memastikan ukuran atau rentang data juga benar. Materi ini menjadi fondasi sebelum belajar pattern (validasi format dengan regex) yang akan datang.

📝 Soal Latihan

Soal 1: Buat input untuk nama pengguna dengan panjang 3–20 karakter dan input usia dengan rentang 13–120 tahun. Tulis kode HTML-nya!

📄 Lihat Jawaban 
<label>Nama Pengguna:</label>
<input type="text" name="username" minlength="3" maxlength="20" required>

<label>Usia:</label>
<input type="number" name="usia" min="13" max="120" required>

Soal 2: Jelaskan perbedaan perilaku minlength dan maxlength saat pengguna mengetik di kolom!

📄 Lihat Jawaban

maxlength langsung mencegah karakter tambahan saat diketik begitu batas tercapai. minlength tidak mencegah pengetikan — ia baru menolak saat formulir dikirim jika jumlah karakter kurang dari batas minimum.

Soal 3: Sebuah input nomor telepon tidak boleh kurang dari 10 digit. Atribut mana yang tepat: minlength="10" atau min="10"? Jelaskan!

📄 Lihat Jawaban

minlength="10" karena nomor telepon adalah input tel (bukan angka murni), dan minlength menghitung jumlah karakter. min hanya berlaku untuk input numerik seperti number atau range.
