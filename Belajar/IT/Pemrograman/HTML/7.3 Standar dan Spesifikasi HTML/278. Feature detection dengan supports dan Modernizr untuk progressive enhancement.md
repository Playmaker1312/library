# Feature detection dengan @supports dan Modernizr untuk progressive enhancement

## Analogi: Perpustakaan Digital

Feature detection seperti petugas perpustakaan yang menanyakan kemampuan pengunjung sebelum memberikan buku. Jika pengunjung bisa membaca braille, petugas memberikan buku braille. Jika hanya bisa membaca teks biasa, petugas memberikan buku cetak biasa. Petugas tidak menebak-nebak kemampuan pengunjung berdasarkan penampilan (browser sniffing), tetapi langsung mengetesnya. Pendekatan ini memastikan setiap pengunjung mendapatkan layanan yang sesuai dengan kemampuannya. Jika ada fitur perpustakaan baru (misalnya buku audio), petugas menawarkannya hanya kepada pengunjung yang bisa mendengar.

## Penjelasan Detail

Feature detection adalah teknik memeriksa apakah browser mendukung fitur tertentu sebelum menggunakannya, berbeda dengan browser sniffing yang menebak berdasarkan user agent. `@supports` adalah aturan CSS yang memungkinkan penulisan CSS conditional berdasarkan dukungan fitur. Modernizr adalah library JavaScript yang mendeteksi dukungan berbagai fitur HTML5 dan CSS3, menambahkan kelas ke elemen `<html>` sebagai indikator. Progressive enhancement adalah strategi yang dimulai dengan fungsionalitas dasar yang berfungsi di semua browser, kemudian menambahkan fitur lanjutan untuk browser yang mendukung. Pendekatan ini memastikan semua pengguna mendapatkan pengalaman yang dapat digunakan, sementara pengguna dengan browser modern mendapatkan pengalaman yang lebih kaya. Feature detection sebaiknya digunakan bersama polyfill untuk cakupan kompatibilitas maksimal.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id" class="no-js">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Feature Detection Demo</title>
  <style>
    /* Baseline: semua browser */
    .card {
      padding: 1rem;
      margin: 1rem 0;
      background: #f5f5f5;
    }

    /* Progressive enhancement dengan @supports */
    @supports (display: grid) {
      .card-grid {
        display: grid;
        grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
        gap: 1rem;
      }
    }

    @supports (backdrop-filter: blur(10px)) {
      .glass {
        background: rgba(255, 255, 255, 0.7);
        backdrop-filter: blur(10px);
        border: 1px solid rgba(255, 255, 255, 0.3);
      }
    }

    @supports not (display: grid) {
      .no-grid-note {
        display: block;
        background: #fff3cd;
        padding: 0.5rem;
        border: 1px solid #ffc107;
      }
    }

    /* Modernizr akan mengganti class ini */
    .no-js .js-only {
      display: none;
    }
    .js .js-only {
      display: block;
    }

    .no-webp .gambar-container::after {
      content: ' (Browser tidak mendukung WebP, fallback ke PNG)';
      font-size: 0.8em;
      color: #666;
    }
  </style>
</head>
<body>
  <h1>Feature Detection</h1>

  <div class="card-grid">
    <div class="card glass">
      <h2>CSS Grid</h2>
      <p>Jika browser mendukung Grid, kartu ini akan tersusun dalam grid.</p>
    </div>
    <div class="card glass">
      <h2>Backdrop Filter</h2>
      <p>Efek glass (kaca) akan muncul jika backdrop-filter didukung.</p>
    </div>
    <div class="card glass">
      <h2>Progressive Enhancement</h2>
      <p>Fitur canggih ditambahkan hanya jika browser mendukung.</p>
    </div>
  </div>

  <div class="no-grid-note js-only">
    Browser Anda tidak mendukung CSS Grid. Tampilan menggunakan layout fallback.
  </div>

  <div class="gambar-container">
    <picture>
      <source type="image/webp" srcset="https://via.placeholder.com/300x200.webp">
      <img src="https://via.placeholder.com/300x200.png" alt="Contoh gambar" style="max-width:100%">
    </picture>
    <p>Gambar akan menggunakan format WebP jika browser mendukung, fallback ke PNG.</p>
  </div>

  <script>
    // Feature detection JavaScript manual
    const featureResults = document.createElement('div');
    featureResults.className = 'card';

    function cekFitur(name, condition) {
      const supported = typeof condition === 'function' ? condition() : !!condition;
      return `<li>${name}: ${supported ? '&#9989;' : '&#10060;'}</li>`;
    }

    featureResults.innerHTML = `
      <h2>Hasil Feature Detection</h2>
      <ul>
        ${cekFitur('CSS Grid', CSS.supports('display', 'grid'))}
        ${cekFitur('IntersectionObserver', 'IntersectionObserver' in window)}
        ${cekFitur('fetch API', 'fetch' in window)}
        ${cekFitur('Service Worker', 'serviceWorker' in navigator)}
        ${cekFitur('WebP', (() => {
          const c = document.createElement('canvas');
          return c.toDataURL('image/webp').indexOf('image/webp') === 5;
        })())}
        ${cekFitur('Local Storage', 'localStorage' in window)}
        ${cekFitur('WebGL', (() => {
          try {
            const c = document.createElement('canvas');
            return !!(c.getContext('webgl') || c.getContext('experimental-webgl'));
          } catch(e) { return false; }
        })())}
        ${cekFitur('Touch Events', 'ontouchstart' in window)}
      </ul>
    `;

    document.body.appendChild(featureResults);

    // Update class untuk JavaScript
    document.documentElement.className =
      document.documentElement.className.replace('no-js', 'js');
  </script>

  <!-- Modernizr (contoh penggunaan via CDN) -->
  <!--
  <script src="https://cdnjs.cloudflare.com/ajax/libs/modernizr/2.8.3/modernizr.min.js"></script>
  <script>
    // Modernizr akan menambahkan class seperti .webp, .flexbox, .grid ke <html>
    if (Modernizr.webp) {
      console.log('WebP didukung');
    }
    if (Modernizr.grid) {
      console.log('CSS Grid didukung');
    }
  </script>
  -->
</body>
</html>
```

## Poin Penting
- `@supports` di CSS dan Modernizr di JavaScript adalah alat utama untuk feature detection.
- Progressive enhancement memastikan fungsionalitas dasar untuk semua browser, fitur lanjutan hanya untuk yang mendukung.
- Feature detection lebih andal daripada browser sniffing berdasarkan user agent.
