# HTML dalam standar aksesibilitas internasional (WCAG dan WAI-ARIA)

## Analogi: Perpustakaan Digital

Standar aksesibilitas seperti desain perpustakaan yang ramah untuk semua pengunjung, termasuk yang berkursi roda, tunanetra, atau tunarungu. Perpustakaan menyediakan jalur kursi roda, buku braille, papan petunjuk dengan huruf besar, dan audio guide. WCAG seperti aturan standar untuk membuat perpustakaan yang inklusif. WAI-ARIA seperti stiker dan label tambahan yang ditempel di rak buku untuk membantu pengunjung tunanetra yang menggunakan pembaca layar memahami tata letak dan fungsi setiap area perpustakaan.

## Penjelasan Detail

WCAG (Web Content Accessibility Guidelines) adalah standar internasional yang dikembangkan oleh W3C untuk membuat konten web lebih accessible. WCAG memiliki empat prinsip utama: Perceivable (dapat dipersepsikan), Operable (dapat dioperasikan), Understandable (dapat dipahami), dan Robust (kuat/kompatibel). Setiap prinsip memiliki kriteria sukses dengan tiga level: A (minimum), AA (standar), dan AAA (tertinggi). WAI-ARIA (Web Accessibility Initiative - Accessible Rich Internet Applications) adalah spesifikasi yang mendefinisikan cara menambah atribut aksesibilitas ke elemen HTML untuk meningkatkan aksesibilitas konten web dinamis. Atribut ARIA seperti `role`, `aria-label`, `aria-hidden`, `aria-expanded`, dan `aria-live` memberikan informasi tambahan untuk screen reader. HTML semantik adalah fondasi aksesibilitas: menggunakan elemen HTML sesuai fungsinya (misalnya `<nav>`, `<main>`, `<button>`) secara otomatis memberikan informasi aksesibilitas yang benar.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Aksesibilitas - WCAG & ARIA</title>
</head>
<body>
  <a href="#main-content" class="skip-link">Langsung ke konten utama</a>

  <header role="banner">
    <h1>Perpustakaan Digital Inklusif</h1>
    <nav role="navigation" aria-label="Navigasi utama">
      <ul>
        <li><a href="/" aria-current="page">Beranda</a></li>
        <li><a href="/katalog">Katalog</a></li>
        <li><a href="/tentang">Tentang</a></li>
        <li><a href="/kontak">Kontak</a></li>
      </ul>
    </nav>

    <form role="search" aria-label="Pencarian buku">
      <label for="cari" class="sr-only">Cari buku:</label>
      <input type="search" id="cari" name="q" placeholder="Cari judul buku...">
      <button type="submit" aria-label="Mulai pencarian">Cari</button>
    </form>
  </header>

  <main id="main-content" role="main">
    <h2>Koleksi Buku Terbaru</h2>

    <section aria-labelledby="daftar-buku-heading">
      <h3 id="daftar-buku-heading">Buku Tersedia</h3>

      <article aria-labelledby="buku1-judul">
        <h4 id="buku1-judul">Pemrograman Web Modern</h4>
        <p><strong>Penulis:</strong> Ahmad Fauzi</p>
        <p><strong>Status:</strong> <span aria-label="Tersedia" style="color: green">&#9989;</span></p>
        <button aria-label="Pinjam buku Pemrograman Web Modern">Pinjam</button>
      </article>
    </section>

    <section aria-label="Navigasi halaman">
      <h3>Halaman</h3>
      <nav aria-label="Paginasi hasil pencarian">
        <ul class="pagination">
          <li><a href="?page=1" aria-current="true" aria-label="Halaman 1, halaman aktif">1</a></li>
          <li><a href="?page=2" aria-label="Halaman 2">2</a></li>
          <li><a href="?page=3" aria-label="Halaman 3">3</a></li>
        </ul>
      </nav>
    </section>

    <div aria-live="polite" aria-atomic="true" class="notifikasi">
      <!-- Pemberitahuan akan diumumkan oleh screen reader -->
    </div>

    <!-- Komponen interaktif dengan ARIA -->
    <div role="tablist" aria-label="Informasi buku">
      <button role="tab" aria-selected="true" aria-controls="panel-deskripsi" id="tab-deskripsi">Deskripsi</button>
      <button role="tab" aria-selected="false" aria-controls="panel-ulasan" id="tab-ulasan">Ulasan</button>
    </div>

    <div role="tabpanel" id="panel-deskripsi" aria-labelledby="tab-deskripsi">
      <p>Buku ini membahas tentang pengembangan web modern dengan HTML5, CSS3, dan JavaScript.</p>
    </div>
    <div role="tabpanel" id="panel-ulasan" aria-labelledby="tab-ulasan" hidden>
      <p>Belum ada ulasan untuk buku ini.</p>
    </div>
  </main>

  <footer role="contentinfo">
    <p>&copy; 2026 Perpustakaan Digital. Semua hak dilindungi.</p>
  </footer>

  <style>
    .sr-only { position:absolute; width:1px; height:1px; padding:0; margin:-1px; overflow:hidden; clip:rect(0,0,0,0); border:0; }
    .skip-link { position:absolute; top:-40px; left:0; background:#000; color:#fff; padding:8px; z-index:100; }
    .skip-link:focus { top:0; }
    [aria-current="page"] { font-weight: bold; }
    [aria-current="true"] { background: #4A90D9; color: white; }
    [aria-selected="true"] { background: #4A90D9; color: white; }
  </style>
</body>
</html>
```

## Poin Penting
- WCAG memiliki 4 prinsip: Perceivable, Operable, Understandable, Robust dengan tiga level kepatuhan (A, AA, AAA).
- WAI-ARIA menambah atribut aksesibilitas untuk konten web dinamis dan komponen interaktif.
- HTML semantik adalah fondasi aksesibilitas; gunakan elemen sesuai fungsinya sebelum menambah ARIA.
