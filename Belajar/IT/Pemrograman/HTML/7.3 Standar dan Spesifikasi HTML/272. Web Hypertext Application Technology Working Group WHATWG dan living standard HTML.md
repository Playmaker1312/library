# Web Hypertext Application Technology Working Group (WHATWG) dan living standard HTML

## Analogi: Perpustakaan Digital

WHATWG seperti tim kurator perpustakaan yang terus-menerus memperbarui sistem katalog secara real-time. Berbeda dengan badan standarisasi yang menerbitkan buku pedoman setiap beberapa tahun, tim kurator ini memperbarui aturan setiap hari sesuai kebutuhan pengunjung dan teknologi baru. Jika ada cara baru yang lebih efisien untuk mengkategorikan buku, tim kurator langsung menerapkannya tanpa menunggu buku pedoman baru dicetak. Sistem katalog perpustakaan selalu up-to-date dan berkembang secara organik mengikuti kebutuhan.

## Penjelasan Detail

WHATWG (Web Hypertext Application Technology Working Group) dibentuk pada tahun 2004 oleh Apple, Mozilla, dan Opera karena ketidakpuasan terhadap arah pengembangan HTML oleh W3C yang dianggap terlalu lambat. WHATWG mengadopsi pendekatan "Living Standard" di mana spesifikasi HTML terus diperbarui secara kontinu tanpa versi. Tidak ada lagi "HTML5" atau "HTML5.1" — yang ada adalah "HTML Living Standard" yang selalu menjadi spesifikasi terkini. Keputusan dibuat berdasarkan prinsip "konsensus dan implementasi": fitur masuk standar jika ada dukungan dari setidaknya dua browser. Pada tahun 2019, W3C dan WHATWG sepakat bahwa WHATWG akan menjadi rumah utama untuk pengembangan HTML dan DOM, dengan W3C sebagai pengadopsi dan penerbit spesifikasi. Pendekatan Living Standard memungkinkan inovasi lebih cepat dan mengurangi fragmentasi standar.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>HTML Living Standard - Fitur Modern</title>
</head>
<body>
  <h1>Fitur dari HTML Living Standard</h1>

  <section>
    <h2>Elemen Modern</h2>
    <p>Elemen-elemen berikut adalah bagian dari HTML Living Standard:</p>

    <details>
      <summary>Klik untuk detail</summary>
      <p><code>&lt;details&gt;</code> dan <code>&lt;summary&gt;</code> adalah fitur interaktif untuk show/hide konten.</p>
    </details>

    <dialog id="dialogDemo">
      <p>Ini adalah elemen <code>&lt;dialog&gt;</code>.</p>
      <button onclick="document.getElementById('dialogDemo').close()">Tutup</button>
    </dialog>
    <button onclick="document.getElementById('dialogDemo').showModal()">Buka Dialog</button>
  </section>

  <section>
    <h2>Fitur Form Modern</h2>
    <form>
      <input type="text" placeholder="Pencarian" list="saran">
      <datalist id="saran">
        <option value="HTML">
        <option value="CSS">
        <option value="JavaScript">
      </datalist>
    </form>
  </section>

  <section>
    <h2>Lazy Loading (Native)</h2>
    <img src="https://via.placeholder.com/300" alt="Contoh" loading="lazy" width="300" height="200">
  </section>

  <footer>
    <p>Spesifikasi: <a href="https://html.spec.whatwg.org/">HTML Living Standard</a></p>
    <p>Terakhir diperbarui: Spesifikasi selalu mutakhir &mdash; tidak ada versi tetap.</p>
  </footer>
</body>
</html>
```

## Poin Penting
- WHATWG menggunakan pendekatan Living Standard, bukan versi tetap seperti HTML5.
- Fitur masuk standar jika sudah diimplementasikan oleh setidaknya dua browser utama.
- Sejak 2019, WHATWG resmi menjadi pengelola utama spesifikasi HTML dan DOM.
