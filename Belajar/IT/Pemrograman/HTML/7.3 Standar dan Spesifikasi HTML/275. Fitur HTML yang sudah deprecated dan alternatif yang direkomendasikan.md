# Fitur HTML yang sudah deprecated dan alternatif yang direkomendasikan

## Analogi: Perpustakaan Digital

Fitur deprecated seperti cara lama menyusun buku di perpustakaan yang sudah tidak digunakan lagi. Dulu perpustakaan menggunakan label berwarna untuk kategori buku, tetapi sekarang menggunakan sistem nomor desimal yang lebih akurat. Label berwarna lama masih bisa dilihat di beberapa buku lama, tetapi semua buku baru harus menggunakan sistem nomor. Perpustakaan secara bertahap mengganti label lama dengan yang baru. Pengunjung mungkin masih bisa membaca label lama, tapi lebih baik menggunakan sistem baru untuk hasil yang lebih baik.

## Penjelasan Detail

Deprecated (usang) merujuk pada fitur HTML yang masih didukung browser untuk kompatibilitas mundur tetapi tidak lagi direkomendasikan dan mungkin dihapus di masa depan. Contoh fitur yang sudah deprecated meliputi: elemen presentasional seperti `<center>`, `<font>`, `<big>`, `<strike>` yang fungsinya sudah digantikan oleh CSS. Atribut presentasi seperti `bgcolor`, `align`, `border` pada elemen tertentu. Elemen `<frame>` dan `<frameset>` untuk layout halaman, digantikan oleh CSS Grid dan Flexbox. Elemen `<marquee>` dan `<blink>` untuk animasi. Atribut `name` pada form digantikan oleh `id`. Beberapa elemen seperti `<b>` dan `<i>` tidak deprecated tetapi lebih baik diganti dengan `<strong>` dan `<em>` untuk semantik yang lebih baik. Menggunakan fitur deprecated dapat menyebabkan masalah kompatibilitas di masa depan dan nilai SEO yang lebih rendah. Validator HTML akan memberikan peringatan untuk fitur deprecated.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Fitur Deprecated vs Modern</title>
  <style>
    .deprecated { background: #fff0f0; padding: 1rem; margin: 1rem 0; }
    .modern { background: #f0fff0; padding: 1rem; margin: 1rem 0; }
  </style>
</head>
<body>
  <h1>Fitur Deprecated vs Alternatif Modern</h1>

  <div class="deprecated">
    <h2>Contoh Deprecated (Jangan Digunakan)</h2>

    <!-- center -->
    <center><p>Teks ini di-center dengan tag center (deprecated)</p></center>

    <!-- font -->
    <font color="red" size="5">Teks dengan font tag (deprecated)</font>

    <!-- big -->
    <p><big>Teks besar dengan big (deprecated)</big></p>

    <!-- strike -->
    <strike>Teks dicoret dengan strike (deprecated)</strike>
  </div>

  <div class="modern">
    <h2>Alternatif Modern (Direkomendasikan)</h2>

    <!-- CSS center -->
    <p style="text-align: center; color: red; font-size: 1.5em;">
      Teks di-center dengan CSS
    </p>

    <!-- CSS untuk ukuran dan warna -->
    <p style="color: red; font-size: 1.2em;">Teks dengan CSS modern</p>

    <!-- CSS untuk ukuran besar -->
    <p style="font-size: 1.5em;">Teks besar dengan CSS</p>

    <!-- del atau s untuk coretan -->
    <p><del>Teks dicoret dengan del (semantik)</del></p>
    <p><s>Teks dicoret dengan s (tidak akurat)</s></p>
  </div>

  <section>
    <h2>Tabel Perbandingan</h2>
    <table>
      <thead>
        <tr>
          <th>Deprecated</th>
          <th>Alternatif</th>
          <th>Keterangan</th>
        </tr>
      </thead>
      <tbody>
        <tr><td><code>&lt;center&gt;</code></td><td><code>text-align: center</code></td><td>CSS</td></tr>
        <tr><td><code>&lt;font&gt;</code></td><td><code>color</code>, <code>font-size</code></td><td>CSS</td></tr>
        <tr><td><code>&lt;big&gt;</code></td><td><code>font-size: larger</code></td><td>CSS</td></tr>
        <tr><td><code>&lt;strike&gt;</code></td><td><code>&lt;del&gt;</code> atau <code>&lt;s&gt;</code></td><td>Elemen semantik</td></tr>
        <tr><td><code>&lt;frameset&gt;</code></td><td>CSS Grid / Flexbox</td><td>Layout modern</td></tr>
        <tr><td><code>&lt;marquee&gt;</code></td><td>CSS animation</td><td>CSS</td></tr>
        <tr><td><code>bgcolor</code></td><td><code>background-color</code></td><td>CSS</td></tr>
        <tr><td><code>align</code> atribut</td><td><code>text-align</code>, <code>align-items</code></td><td>CSS</td></tr>
      </tbody>
    </table>
  </section>
</body>
</html>
```

## Poin Penting
- Fitur deprecated masih berfungsi di browser tetapi tidak direkomendasikan dan mungkin dihapus.
- Alternatif modern umumnya menggunakan CSS untuk presentasi dan elemen semantik untuk struktur.
- Gunakan W3C Validator untuk mendeteksi penggunaan fitur deprecated di halaman HTML.
