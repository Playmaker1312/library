# Browser compatibility tables dan cara mengecek dukungan fitur dengan caniuse

## Analogi: Perpustakaan Digital

Can I Use seperti katalog kompatibilitas yang memberi tahu petugas perpustakaan format buku apa yang didukung oleh berbagai jenis rak buku. Ada rak yang hanya bisa menampung buku bersampul keras, ada yang bisa menampung buku digital, dan ada yang mendukung semua format. Sebelum membeli buku baru, petugas mengecek katalog ini untuk memastikan buku tersebut bisa diletakkan di rak yang tersedia. Katalog ini diperbarui secara berkala saat rak-rak baru dipasang atau rak lama diperbarui.

## Penjelasan Detail

Browser compatibility tables adalah referensi yang menunjukkan fitur HTML, CSS, atau JavaScript mana yang didukung oleh berbagai browser dan versinya. Can I Use (caniuse.com) adalah situs referensi utama yang menyediakan data kompatibilitas browser yang akurat dan selalu diperbarui. Data mencakup dukungan desktop (Chrome, Firefox, Safari, Edge) dan mobile (Chrome Android, Safari iOS). Can I Use juga menampilkan statistik penggunaan global dan regional untuk membantu pengambilan keputusan. Selain Can I Use, ada MDN Browser Compatibility Tables yang terintegrasi langsung di dokumentasi MDN. Tools seperti Babel dan Autoprefixer menggunakan data dari Can I Use untuk menentukan transformasi dan prefix yang diperlukan. Data kompatibilitas juga tersedia melalui API untuk diintegrasikan ke build tools atau dashboard monitoring.

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Cek Dukungan Fitur Browser</title>
</head>
<body>
  <h1>Cek Dukungan Fitur HTML Modern</h1>

  <div id="hasil">
    <h2>Hasil Deteksi Browser</h2>
    <table>
      <thead>
        <tr>
          <th>Fitur</th>
          <th>Status</th>
          <th>Catatan</th>
        </tr>
      </thead>
      <tbody id="tbody-hasil"></tbody>
    </table>
  </div>

  <div class="info">
    <h2>Cara Manual Pengecekan</h2>
    <ol>
      <li>Kunjungi <a href="https://caniuse.com">caniuse.com</a></li>
      <li>Cari fitur yang ingin dicek (contoh: "dialog", "lazy loading")</li>
      <li>Lihat tabel dukungan per browser dan versi</li>
      <li>Perhatikan statistik penggunaan global untuk menilai risiko</li>
    </ol>
  </div>

  <script>
    function cekDukungan() {
      const fitur = [
        {
          nama: 'WebP (format gambar)',
          didukung: (() => {
            const canvas = document.createElement('canvas');
            return canvas.toDataURL('image/webp').indexOf('image/webp') === 5;
          })(),
          catatan: 'Browser modern mendukung WebP'
        },
        {
          nama: 'CSS Grid',
          didukung: CSS.supports('display', 'grid'),
          catatan: 'Didukung semua browser modern'
        },
        {
          nama: 'Lazy Loading Native',
          didukung: 'loading' in HTMLImageElement.prototype,
          catatan: 'Chrome, Firefox, Edge mendukung'
        },
        {
          nama: 'Dialog Element',
          didukung: typeof HTMLDialogElement !== 'undefined',
          catatan: 'Chrome, Firefox, Edge; Safari mulai mendukung'
        },
        {
          nama: 'Intersection Observer',
          didukung: 'IntersectionObserver' in window,
          catatan: 'Didukung semua browser modern'
        },
        {
          nama: 'Service Worker',
          didukung: 'serviceWorker' in navigator,
          catatan: 'Browser modern; HTTP/HTTPS'
        },
        {
          nama: 'WebP Animation',
          didukung: (() => {
            const elem = document.createElement('img');
            return 'lossy' in elem ? true : false;
          })(),
          catatan: 'Chrome mendukung, Firefox terbatas'
        }
      ];

      const tbody = document.getElementById('tbody-hasil');
      tbody.innerHTML = fitur.map(f => `
        <tr>
          <td>${f.nama}</td>
          <td style="color: ${f.didukung ? 'green' : 'red'}">
            ${f.didukung ? '&#9989; Didukung' : '&#10060; Tidak Didukung'}
          </td>
          <td>${f.catatan}</td>
        </tr>
      `).join('');
    }

    cekDukungan();

    // Data caniuse simulasi (contoh penggunaan API)
    const caniuseData = {
      'dialog': {
        'chrome': { 'desktop': '77', 'android': '77' },
        'firefox': { 'desktop': '98', 'android': '98' },
        'safari': { 'desktop': '15.4', 'ios': '15.4' },
        'edge': { 'desktop': '79' }
      },
      'css-grid': {
        'chrome': { 'desktop': '57', 'android': '57' },
        'firefox': { 'desktop': '52', 'android': '52' },
        'safari': { 'desktop': '10.1', 'ios': '10.3' },
        'edge': { 'desktop': '16' }
      }
    };

    console.log('Data kompatibilitas (caniuse simulasi):', caniuseData);
  </script>
</body>
</html>
```

## Poin Penting
- Can I Use menyediakan data kompatibilitas browser yang akurat dan selalu diperbarui.
- Feature detection dengan JavaScript memberikan informasi real-time tentang dukungan di browser pengguna.
- Gunakan data caniuse untuk menentukan polyfill, prefix, dan fallback yang diperlukan.
