# HTML conformance checker dan validasi menggunakan W3C Validator

## Analogi: Perpustakaan Digital

W3C Validator seperti petugas quality control di perpustakaan yang memeriksa setiap buku sebelum masuk ke rak. Petugas memeriksa apakah sampul buku sesuai standar, nomor ISBN valid, halaman tidak terbalik, dan label kategori benar. Jika ada kesalahan, buku dikembalikan untuk diperbaiki. Proses ini memastikan semua buku di perpustakaan memiliki kualitas yang konsisten dan mudah ditemukan oleh pengunjung. Tanpa quality control, akan ada buku dengan format aneh yang sulit diakses.

## Penjelasan Detail

HTML conformance checker (validator) adalah alat yang memeriksa apakah dokumen HTML mengikuti spesifikasi standar yang ditetapkan oleh W3C atau WHATWG. W3C Validator (validator.w3.org) adalah alat resmi yang memeriksa validitas HTML, menemukan kesalahan seperti tag tidak ditutup, atribut salah, elemen tidak sesuai konteks, dan duplikasi ID. Validasi dapat dilakukan melalui upload file, input URL, atau paste langsung. Selain W3C Validator, ada alat lain seperti Nu HTML Checker, HTMLHint, dan validator bawaan di editor kode (VS Code dengan ekstensi HTMLHint). Validasi HTML penting untuk kompatibilitas antar browser, aksesibilitas, SEO, dan memudahkan debugging. Halaman yang valid cenderung lebih konsisten perilakunya di berbagai browser dan perangkat. Validasi sebaiknya dilakukan secara otomatis dalam build process atau pre-commit hook.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Contoh HTML Valid</title>
</head>
<body>
  <h1>Selamat Datang</h1>
  <p>Halaman ini sudah divalidasi dan sesuai standar HTML.</p>

  <section>
    <h2>Praktik Validasi</h2>
    <ul>
      <li>Tag harus ditutup dengan benar</li>
      <li>Atribut harus memiliki nilai yang valid</li>
      <li>Tidak boleh ada duplikasi ID</li>
      <li>Elemen harus ditempatkan dalam konteks yang sesuai</li>
    </ul>
  </section>

  <!-- Contoh kesalahan umum -->
  <!--
  Kesalahan:
  <img src=foto.jpg>           -> atribut tidak dikutip
  <p>Paragraf                        -> tag tidak ditutup
  <div id="sama">...</div>           -> ID duplikat
  <div id="sama">...</div>           -> ID duplikat
  <span><div>...</div></span>         -> elemen block di dalam inline
  -->

  <footer>
    <p>Validasi dengan <a href="https://validator.w3.org/">W3C Validator</a></p>
  </footer>

  <script>
    // Validasi HTML otomatis menggunakan console
    document.addEventListener('DOMContentLoaded', () => {
      console.log('HTML siap divalidasi');

      // Cek duplikasi ID
      const ids = {};
      document.querySelectorAll('[id]').forEach(el => {
        if (ids[el.id]) {
          console.warn('ID duplikat ditemukan:', el.id);
        }
        ids[el.id] = true;
      });

      // Cek heading hierarchy
      const headings = document.querySelectorAll('h1, h2, h3, h4, h5, h6');
      let prevLevel = 0;
      headings.forEach(h => {
        const level = parseInt(h.tagName[1]);
        if (level > prevLevel + 1) {
          console.warn('Heading loncat:', h.tagName, 'setelah h' + prevLevel);
        }
        prevLevel = level;
      });
    });

    // Cek validitas markup via console
    console.log('Jumlah elemen:', document.querySelectorAll('*').length);
    console.log('Jumlah link:', document.querySelectorAll('a').length);
    console.log('Jumlah gambar:', document.querySelectorAll('img').length);
    console.log('Jumlah heading:', document.querySelectorAll('h1, h2, h3, h4, h5, h6').length);
  </script>
</body>
</html>
```

## Poin Penting
- W3C Validator memeriksa kesesuaian HTML terhadap spesifikasi standar web.
- HTML yang valid lebih kompatibel, accessible, dan mudah di-debug.
- Gunakan alat otomatis seperti HTMLHint, Nu Checker, atau validator bawaan editor.
