<code>, <pre>, <kbd>, <samp> — Kode, Format Asli, dan Input Keyboard

Penjelasan

<code> untuk menampilkan kode program secara inline. <pre> (preformatted) untuk teks yang format spasinya (spasi, tab, baris baru) dipertahankan persis seperti aslinya. <kbd> untuk menandai input keyboard. <samp> untuk menampilkan output dari program. Sering dikombinasikan <pre> dengan <code> untuk blok kode yang utuh.

Fungsi

Menyajikan kode program, perintah terminal, input keyboard, dan output program secara jelas dan semantik — memudahkan pembaca membedakan antara teks biasa, kode, tombol, dan hasil eksekusi.

Cara Pengimplementasian

<p>Gunakan fungsi <code>print()</code> untuk mencetak teks.</p>

<pre><code>function sapa(nama) {
    return "Halo, " + nama + "!";
}
console.log(sapa("Andi"));</code></pre>

<p>Tekan <kbd>Ctrl</kbd> + <kbd>S</kbd> untuk menyimpan.</p>

<p>Output: <samp>Halo, Andi!</samp></p>

Analogi

Di rumah ada papan catatan di dapur. <code> adalah tempelan kecil berisi resep singkat. <pre> adalah papan besar tempat kamu menulis persis seperti aslinya — setiap spasi dan baris baru dipertahankan. <kbd> seperti stiker di tombol saklar lampu yang bertuliskan "TEKAN SINI". <samp> seperti layar kulkas yang menampilkan suhu ruangan — hasil dari apa yang sudah kamu atur.

Dipakai Untuk

  • Menampilkan cuplikan kode di tutorial
  • Menulis perintah terminal atau CLI
  • Menandai tombol shortcut keyboard
  • Menampilkan output program atau log
  • Menulis teks dengan format spasial (puisi, ASCII art)

Kesalahan Umum

  • Menggunakan <pre> tanpa <code> untuk kode — <code> memberi makna semantik bahwa itu kode program.
  • Menulis konten di <pre> tanpa meng-escape karakter < dan > — browser akan mengartikannya sebagai tag HTML.
  • Menggunakan <kbd> untuk teks biasa — <kbd> khusus untuk input keyboard.
  • Lupa bahwa <pre> menggunakan font monospace secara default dan mempertahankan semua whitespace.

Koneksi dengan Materi Sebelumnya

Materi sebelumnya fokus pada kutipan (<blockquote>, <q>, <cite>). Sekarang kita masuk ke ranah teknis: menyajikan kode dan input keyboard. Ini sangat penting untuk membuat dokumentasi teknis, tutorial pemrograman, atau halaman panduan — pelengkap dari semua materi daftar dan kutipan yang sudah dipelajari.

Lihat Jawaban

    return a + b;
}
console.log(jumlah(3, 7)); // Output: 10</code></pre>
