Nested List — Daftar Bersarang

Penjelasan

Nested list adalah daftar di dalam daftar. Caranya dengan meletakkan <ul> atau <ol> baru di dalam <li>. Bisa dibuat hingga 3 level atau lebih, selama indentasi dijaga agar kode mudah dibaca.

Fungsi

Membuat hierarki atau kategorisasi informasi yang bertingkat, seperti sub-menu, struktur organisasi, outline bab buku, atau silsilah keluarga.

Cara Pengimplementasian

<ul>
    <li>Elektronik
        <ul>
            <li>Laptop
                <ul>
                    <li>MacBook</li>
                    <li>ThinkPad</li>
                </ul>
            </li>
            <li>Smartphone
                <ul>
                    <li>iPhone</li>
                    <li>Android</li>
                </ul>
            </li>
        </ul>
    </li>
    <li>Pakaian
        <ul>
            <li>Atasan</li>
            <li>Bawahan</li>
        </ul>
    </li>
</ul>

Analogi

Seperti struktur rumah: lantai dasar (level 1) memiliki beberapa ruangan. Di dalam ruangan (level 2) ada lemari. Di dalam lemari (level 3) ada laci-laci kecil. Setiap level adalah daftar yang berada di dalam item dari level di atasnya — makin ke dalam, makin detail isinya.

Dipakai Untuk

  • Menu navigasi bertingkat (dropdown)
  • Daftar isi buku
  • Struktur organisasi perusahaan
  • Kategorisasi produk (kategori → sub-kategori)
  • Silsilah keluarga

Kesalahan Umum

  • Meletakkan <ul> di luar <li> — daftar bersarang harus berada di dalam <li>, bukan setelahnya.
  • Tidak memberi indentasi yang rapi sehingga kode sulit dibaca.
  • Level bersarang terlalu dalam (lebih dari 4-5 level) sehingga membingungkan pengguna.

Koneksi dengan Materi Sebelumnya

Nested list menggabungkan konsep <ul> dan <ol> yang sudah dipelajari sebelumnya. Jika <ul> adalah lemari datar, nested list adalah lemari bertingkat — tetap menggunakan <li> yang sama, tetapi di dalamnya ada daftar baru.

Soal Latihan

1. Buatlah nested list 2 level dengan tema "Hewan": level 1 adalah jenis hewan (Mamalia, Reptil), level 2 adalah contoh hewan dari masing-masing jenis.

Lihat Jawaban 
<ul>
    <li>Mamalia
        <ul>
            <li>Kucing</li>
            <li>Anjing</li>
        </ul>
    </li>
    <li>Reptil
        <ul>
            <li>Ular</li>
            <li>Kadal</li>
        </ul>
    </li>
</ul>

2. Jelaskan kesalahan pada kode berikut dan perbaiki:

<ul>
    <li>Minuman
    <ul>
        <li>Teh</li>
        <li>Kopi</li>
    </ul>
    <li>Makanan
    <ul>
        <li>Nasi</li>
    </ul>
</ul>
Lihat Jawaban

Kesalahan: Tag <li> pertama ("Minuman") tidak ditutup, dan <li> kedua ("Makanan") juga tidak ditutup. Perbaikan:

<ul>
    <li>Minuman
        <ul>
            <li>Teh</li>
            <li>Kopi</li>
        </ul>
    </li>
    <li>Makanan
        <ul>
            <li>Nasi</li>
        </ul>
    </li>
</ul>
