<dl>, <dt>, <dd> — Description List (Daftar Deskripsi)

Penjelasan

<dl> adalah daftar yang berisi pasangan istilah dan definisi. Tag <dt> (description term) untuk istilahnya, dan <dd> (description details) untuk definisi atau penjelasannya. Satu <dt> bisa punya lebih dari satu <dd>.

Fungsi

Menyajikan informasi dalam format istilah-definisi, seperti glosarium, daftar istilah teknis, FAQ (tanya-jawab), atau metadata properti.

Cara Pengimplementasian

<dl>
    <dt>HTML</dt>
    <dd>Bahasa markup untuk membuat struktur halaman web.</dd>

    <dt>CSS</dt>
    <dd>Bahasa untuk mengatur tampilan halaman web.</dd>

    <dt>JavaScript</dt>
    <dd>Bahasa pemrograman untuk membuat halaman web interaktif.</dd>
</dl>

Analogi

Seperti papan nama di setiap kamar rumah. Di pintu kamar tidur tertulis "Kamar Tidur" (itu <dt>), dan di bawahnya ada penjelasan "Ruang untuk tidur dan istirahat" (itu <dd>). Setiap ruangan di rumah punya label dan deskripsi — itulah yang dilakukan <dl> untuk sekumpulan istilah.

Dipakai Untuk

  • Glosarium atau kamus istilah
  • FAQ (Frequently Asked Questions)
  • Daftar metadata (misal: Penulis: ..., Tahun: ...)
  • Informasi produk (fitur: penjelasan)
  • Detail kontak (Email: ..., Telepon: ...)

Kesalahan Umum

  • Menggunakan <ul> + <li> untuk format istilah: definisi — lebih baik pakai <dl> karena semantiknya tepat.
  • Meletakkan <dd> tanpa <dt> sebelumnya.
  • Bingung membedakan <dt> dan <dd> — <dt> untuk istilah (term), <dd> untuk deskripsi (definition).

Koneksi dengan Materi Sebelumnya

Jika <ul> dan <ol> adalah daftar item tunggal, <dl> adalah daftar berpasangan (istilah + definisi). Ini melengkapi kemampuan kita dalam menyajikan informasi — tidak hanya daftar biasa, tetapi juga daftar dengan penjelasan untuk setiap entri.

Soal Latihan

1. Buatlah description list yang berisi 3 istilah teknologi beserta definisinya menggunakan <dl>, <dt>, dan <dd>.

Lihat Jawaban 
<dl>
    <dt>API</dt>
    <dd>Antarmuka yang menghubungkan dua aplikasi.</dd>

    <dt>Database</dt>
    <dd>Tempat penyimpanan data terstruktur.</dd>

    <dt>Server</dt>
    <dd>Komputer yang melayani permintaan dari klien.</dd>
</dl>

2. Buatlah <dl> untuk FAQ dengan 2 pertanyaan. Gunakan <dt> sebagai pertanyaan dan <dd> sebagai jawaban.

Lihat Jawaban 
<dl>
    <dt>Apa itu HTML?</dt>
    <dd>HTML adalah bahasa markup untuk membuat struktur halaman web.</dd>

    <dt>Apa perbedaan tag dan atribut?</dt>
    <dd>Tag adalah elemen HTML (contoh: &lt;p&gt;), sedangkan atribut adalah properti yang melengkapi tag (contoh: class, id).</dd>
</dl>
