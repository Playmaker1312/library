DOCTYPE Declaration

Penjelasan

<!DOCTYPE html> adalah deklarasi yang wajib ditulis di baris pertama file HTML. Fungsinya adalah memberi tahu browser: "Dokumen ini menggunakan HTML versi terbaru (HTML5)". DOCTYPE bukanlah tag HTML — ia adalah instruksi khusus yang dikenal sebagai document type declaration.

Fungsi

Fungsi utama DOCTYPE adalah mencegah browser masuk ke Quirks Mode. Quirks Mode adalah mode lama di mana browser mencoba meniru perilaku browser jadul (era Netscape dan IE4/5) sehingga halaman bisa tampil kacau. Dengan <!DOCTYPE html>, browser masuk ke Standards Mode — mode di mana browser mengikuti spesifikasi web modern dengan benar.

Cara Pengimplementasian

Cukup tulis <!DOCTYPE html> di baris paling atas, sebelum tag <html>:

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Contoh DOCTYPE</title>
</head>
<body>
    <p>Halaman ini dalam Standards Mode.</p>
</body>
</html>

Perhatikan: DOCTYPE tidak memiliki tag penutup dan tidak case-sensitive — <!doctype html> juga sah, tapi konvensi menulisnya dengan huruf kapital.

Analogi

Bayangkan Anda membeli rumah dan menyerahkan denahnya ke kontraktor. DOCTYPE seperti label di sampul cetak biru yang bertuliskan "Gunakan kode bangunan terbaru tahun 2024". Tanpa label ini, kontraktor mungkin menggunakan aturan bangunan dari tahun 1990-an, yang menghasilkan rumah dengan fondasi tidak sesuai standar modern. Dengan label itu, kontraktor menggunakan peraturan terbaru sehingga rumah Anda kokoh dan aman.

Dipakai Untuk

Deklarasi DOCTYPE digunakan di setiap file HTML tanpa kecuali. Mulai dari halaman statis sederhana, website perusahaan, hingga aplikasi web kompleks. Tidak boleh ada satu pun file HTML yang lupa menyertakan DOCTYPE di baris pertamanya.

Kesalahan Umum

  • Tidak menulis DOCTYPE sama sekali — menyebabkan browser masuk Quirks Mode dan tampilan bisa kacau.
  • Menulis DOCTYPE setelah tag <html> — harus di baris pertama.
  • Menggunakan DOCTYPE versi lama seperti <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN"> — tidak perlu di era HTML5.
  • Mengira DOCTYPE adalah tag HTML — sebenarnya ia adalah deklarasi khusus, bukan tag.

Koneksi dengan Materi Sebelumnya

Setelah berhasil membuat file HTML pertama, sekarang kita belajar satu elemen penting yang harus ada di setiap file HTML: DOCTYPE. Ini adalah materi pertama dari rangkaian struktur wajib dokumen HTML, yang akan dilanjutkan dengan tag <html>, <head>, dan <body>.

Soal Latihan

Soal 1: Apa perbedaan antara Standards Mode dan Quirks Mode?

Jawaban: Standards Mode adalah mode di mana browser mengikuti spesifikasi web modern secara ketat, memastikan halaman dirender sesuai standar W3C. Quirks Mode adalah mode kompatibilitas ke belakang di mana browser meniru perilaku browser lama (seperti IE5) untuk mendukung halaman jadul, yang sering menghasilkan tampilan tidak konsisten dan sulit diatur.

Soal 2: Di manakah posisi penulisan <!DOCTYPE html> dan mengapa ia harus di posisi tersebut?

Jawaban: <!DOCTYPE html> harus ditulis di baris pertama file HTML, bahkan sebelum tag <html>. Ini karena browser perlu menentukan mode rendering (Standards vs Quirks) sebelum mulai membaca dokumen. Jika DOCTYPE tidak di baris pertama, atau ada karakter/spasi sebelumnya, browser bisa masuk ke Quirks Mode.
