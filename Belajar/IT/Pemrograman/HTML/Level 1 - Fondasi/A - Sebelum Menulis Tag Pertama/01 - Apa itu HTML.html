Apa itu HTML?

Penjelasan

HTML adalah singkatan dari HyperText Markup Language. HTML bukanlah bahasa pemrograman, melainkan markup language — yaitu bahasa yang digunakan untuk memberi struktur dan arti pada konten di web. HTML bekerja dengan cara "menandai" teks agar browser tahu mana judul, mana paragraf, mana gambar, dan seterusnya.

File HTML memiliki ekstensi .html dan dibaca oleh browser web seperti Chrome, Firefox, atau Edge.

Fungsi

Fungsi utama HTML adalah sebagai kerangka dasar dari sebuah halaman web. HTML menentukan apa saja yang ada di halaman dan bagaimana susunannya. Tanpa HTML, browser tidak akan tahu cara menampilkan konten. HTML adalah fondasi mutlak yang harus ada sebelum teknologi lain (seperti CSS dan JavaScript) bisa bekerja.

Cara Pengimplementasian

HTML ditulis dalam bentuk tag. Sebuah tag biasanya punya pasangan pembuka dan penutup, misalnya:

<h1>Ini Judul</h1>
<p>Ini paragraf.</p>

File HTML disimpan dengan ekstensi .html dan bisa langsung dibuka di browser mana pun.

Analogi

Bayangkan sebuah rumah. HTML adalah kerangka bangunan — yaitu struktur dasar seperti tiang, dinding, atap, pintu, dan jendela. Kerangka ini menentukan ruangan mana yang menjadi kamar tidur, mana yang menjadi dapur, dan mana yang menjadi kamar mandi. Tanpa kerangka ini, rumah tidak akan berbentuk. CSS adalah cat dan dekorasinya, sedangkan JavaScript adalah instalasi listrik dan pipa airnya.

Dipakai Untuk

HTML dipakai untuk membuat struktur halaman web — mulai dari halaman blog sederhana, profil perusahaan, toko online, dashboard aplikasi, hingga sistem manajemen kompleks. Setiap halaman web yang Anda lihat di internet pasti menggunakan HTML sebagai dasarnya.

Kesalahan Umum

  • Menganggap HTML sebagai bahasa pemrograman — HTML tidak punya logika seperti if-else atau loop.
  • Menyimpan file dengan ekstensi .txt atau .doc — browser hanya membaca .html.
  • Lupa menutup tag — meskipun beberapa browser bisa "memperbaiki", ini tetap praktik yang buruk.

Koneksi dengan Materi Sebelumnya

Ini adalah materi pertama. HTML adalah titik awal dari perjalanan belajar pengembangan web. Setelah memahami apa itu HTML, kita akan belajar bagaimana browser membaca HTML, bagaimana menyiapkan alat tulisnya, dan akhirnya menulis file HTML pertama.

Soal Latihan

Soal 1: Jelaskan perbedaan antara HTML, CSS, dan JavaScript dalam konteks pembangunan rumah.

Jawaban: HTML adalah kerangka bangunan (dinding, atap, pintu). CSS adalah cat, wallpaper, dan dekorasi yang membuat rumah indah dipandang. JavaScript adalah instalasi listrik dan pipa — yang membuat rumah bisa "hidup" (lampu menyala, keran mengalir, interaksi terjadi).

Soal 2: Mengapa HTML disebut sebagai "markup language" dan bukan "programming language"?

Jawaban: HTML disebut markup language karena ia hanya "menandai" teks dengan tag untuk memberi struktur dan makna. HTML tidak memiliki kemampuan logika seperti percabangan (if-else), perulangan (loop), atau komputasi matematis. Ia hanya mendeskripsikan konten, bukan memprosesnya.
