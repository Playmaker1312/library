Membuat File HTML Pertama

Penjelasan

Setelah memahami teori dan menyiapkan alat, saatnya praktik langsung! Membuat file HTML pertama adalah langkah konkret pertama Anda sebagai web developer. Sebuah file HTML hanyalah file teks biasa dengan ekstensi .html yang berisi kode markup untuk dibaca browser.

Fungsi

Langkah ini berfungsi untuk memastikan bahwa seluruh setup environment berjalan dengan benar — VS Code bisa menulis file, browser bisa membukanya, dan Live Server bisa menampilkan perubahan. Ini juga menjadi momen "Hello World" pertama Anda di dunia pengembangan web.

Cara Pengimplementasian

Ikuti langkah-langkah berikut:

  1. Buat folder project di komputer Anda (misal: projek-html-saya).
  2. Buka folder tersebut di VS Code (File → Open Folder).
  3. Buat file baru bernama index.html.
  4. Ketikkan kode berikut:
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Halo Dunia</title>
</head>
<body>
    <h1>Halo Dunia!</h1>
    <p>Ini file HTML pertamaku.</p>
</body>
</html>
  1. Klik kanan file → Open with Live Server (atau klik dua kali file untuk buka langsung di browser).
  2. Lihat hasilnya di browser!

Analogi

Membuat file HTML pertama seperti meletakkan batu bata pertama dari sebuah bangunan. Ini adalah fondasi fisik yang nyata — bukan lagi teori di atas kertas. Batu bata pertama ini mungkin kecil dan sederhana, tapi tanpanya, tidak akan ada rumah yang terbangun. Setiap halaman web rumit yang pernah Anda lihat berawal dari file .html sederhana seperti ini.

Dipakai Untuk

Ini adalah langkah awal untuk semua proyek web, mulai dari proyek belajar pribadi, tugas kuliah, portofolio, hingga pembuatan website profesional. Setiap proyek web dimulai dengan membuat file HTML — tidak ada pengecualian.

Kesalahan Umum

  • Lupa menyimpan file sebelum membukanya di browser — yang muncul adalah versi lama.
  • Menyimpan file dengan ekstensi .txt — browser tidak akan membaca sebagai HTML.
  • Mengetik kode secara manual tapi salah ketik (typo) — periksa kembali tanda kurung siku < dan >.
  • Tidak menggunakan Live Server — repot karena harus refresh manual setiap ada perubahan.

Koneksi dengan Materi Sebelumnya

Materi ini adalah implementasi langsung dari tiga materi sebelumnya: kita tahu apa itu HTML (teori), bagaimana browser membacanya (proses), dan alat apa yang digunakan (setup). Sekarang kita benar-benar membuat file dan melihat hasilnya. Ini adalah jembatan antara teori dan praktik.

Soal Latihan

Soal 1: Sebutkan langkah-langkah membuat file HTML pertama dan melihatnya di browser!

Jawaban: (1) Buat folder proyek. (2) Buka folder di VS Code. (3) Buat file index.html. (4) Tulis struktur HTML lengkap dengan <h1>Halo Dunia</h1>. (5) Simpan file (Ctrl+S). (6) Klik kanan file → Open with Live Server, atau klik dua kali file di File Explorer untuk membuka di browser.

Soal 2: Apa yang terjadi jika Anda lupa menyimpan file HTML sebelum membukanya di browser?

Jawaban: Browser akan menampilkan versi lama dari file tersebut — yaitu versi sebelum perubahan terakhir Anda simpan. Inilah mengapa penting untuk selalu menyimpan (Ctrl+S) sebelum me-refresh browser, atau lebih baik lagi, menggunakan Live Server yang otomatis mendeteksi perubahan.
