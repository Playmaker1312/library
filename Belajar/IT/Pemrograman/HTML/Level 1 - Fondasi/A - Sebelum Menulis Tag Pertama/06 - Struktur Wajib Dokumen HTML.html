Struktur Wajib Dokumen HTML

Penjelasan

Setiap dokumen HTML yang valid memiliki struktur wajib yang terdiri dari tiga tag utama: <html>, <head>, dan <body>. Selain itu, ada elemen penting di dalam <head> seperti <meta> untuk charset dan viewport, serta <title>. Atribut lang pada tag <html> juga wajib untuk aksesibilitas dan SEO.

Fungsi

Struktur ini berfungsi sebagai kerangka dasar yang memberikan arti pada setiap bagian halaman:

  • <html> — wadah utama, membungkus seluruh konten dokumen.
  • <head> — berisi informasi tentang dokumen (metadata), tidak tampil di halaman.
  • <body> — berisi semua konten yang tampak oleh pengguna.
  • <meta charset="UTF-8"> — menentukan encoding karakter agar huruf, simbol, dan emoji tampil benar.
  • <meta name="viewport"> — mengatur tampilan di perangkat mobile.
  • <title> — judul halaman yang muncul di tab browser.
  • lang="id" — memberitahu browser bahwa bahasa halaman adalah Indonesia.

Cara Pengimplementasian

Berikut adalah kerangka HTML yang wajib ada di setiap dokumen:

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Judul Halaman</title>
</head>
<body>
    <!-- Semua konten yang terlihat diletakkan di sini -->
</body>
</html>

Di VS Code, Anda bisa mengetik ! lalu tekan Tab untuk menghasilkan struktur ini secara otomatis (Emmet).

Analogi

Struktur HTML wajib seperti denah rumah yang sudah ditentukan oleh pemerintah:

  • <html> adalah batas tanah — seluruh bangunan harus berada di dalamnya.
  • <head> adalah ruang arsip — menyimpan dokumen penting seperti sertifikat tanah dan IMB (izin mendirikan bangunan) yang tidak terlihat dari luar, tapi sangat penting.
  • <body> adalah bangunan fisik — semua yang terlihat: ruang tamu, kamar, dapur.
  • <meta charset> seperti standar ukuran meter — memastikan semua ukuran konsisten.
  • <title> seperti papan nama rumah — yang terlihat di luar (tab browser).
  • lang="id" seperti stiker "Rumah ini berbahasa Indonesia" di pintu — membantu tamu (browser, screen reader) tahu bahasa yang digunakan.

Dipakai Untuk

Struktur ini wajib di setiap halaman web tanpa terkecuali. Baik itu halaman pribadi, blog, toko online, portal berita, sistem admin, atau aplikasi web — semuanya harus memiliki struktur html, head, dan body yang rapi. Tanpa struktur ini, halaman bisa tidak konsisten di berbagai browser dan perangkat.

Kesalahan Umum

  • Menulis konten di luar <body> — konten harus di dalam <body>.
  • Lupa menambahkan <meta charset="UTF-8"> — bisa menyebabkan karakter seperti "~" atau emoji tampil kacau.
  • Tidak menambahkan lang pada <html> — dapat mengurangi aksesibilitas dan SEO.
  • Lupa tag penutup </html> — meski browser toleran, ini praktik buruk.

Koneksi dengan Materi Sebelumnya

Materi ini adalah kelanjutan langsung dari DOCTYPE Declaration. Setelah menulis DOCTYPE di baris pertama, kita menulis struktur wajib: <html> sebagai induk, <head> untuk metadata, dan <body> untuk konten. Ini adalah cetak biru minimal yang harus ada di setiap file HTML, dan menjadi fondasi untuk mempelajari tag, elemen, dan atribut selanjutnya.

Soal Latihan

Soal 1: Sebutkan tiga tag utama yang wajib ada dalam struktur dokumen HTML dan jelaskan fungsi masing-masing!

Jawaban: (1) <html> — elemen akar yang membungkus seluruh dokumen HTML. (2) <head> — berisi metadata tentang dokumen seperti charset, viewport, title, dan link ke file CSS. (3) <body> — berisi semua konten yang akan ditampilkan di halaman browser.

Soal 2: Mengapa <meta charset="UTF-8"> penting dan apa yang terjadi jika tidak disertakan?

Jawaban: Meta charset UTF-8 penting karena mendefinisikan encoding karakter yang digunakan dokumen. UTF-8 mendukung hampir semua karakter di dunia termasuk huruf Latin, Arab, Kanji, dan emoji. Jika tidak disertakan, browser mungkin salah menebak encoding dan menampilkan karakter aneh (misal: "Selamat datang" menjadi "Selamat datangÃ©").
