# Apa itu HTML

## Penjelasan
HTML (HyperText Markup Language) adalah bahasa markup standar untuk membuat struktur halaman web. HTML bukan bahasa pemrograman — dia tidak memiliki logika, loop, atau kondisi. HTML hanya **menandai** konten agar browser tahu mana judul, paragraf, gambar, tautan, dan lain-lain.

## Fungsi
- Menyusun struktur dan hierarki konten web
- Menandai teks sebagai heading, paragraf, list, dll
- Menyematkan gambar, video, audio, dan tautan
- Memberi semantik agar mesin pencari dan pembaca layar memahami halaman

## Cara Pengimplementasian
```html
<h1>Judul Artikel</h1>
<p>Ini adalah paragraf pertama.</p>
<a href="https://example.com">Klik di sini</a>
<img src="foto.jpg" alt="Deskripsi foto">
```

## Analogi
Bayangkan HTML adalah **struktur rangka rumah** — pondasi, tiang, dinding, atap. Tanpa rangka, rumah tidak berbentuk. CSS adalah cat dan wallpaper (hiasan), JavaScript adalah listrik dan pipa air (fungsi). HTML sendiri hanya kerangka kosong yang menentukan ruangan mana letak dapur, kamar, dan ruang tamu.

## Dipakai Untuk
- Seluruh halaman web di internet
- Aplikasi web modern (React, Vue, Angular tetap pakai HTML)
- Dokumen yang perlu ditampilkan di browser
- Email marketing (HTML email)

## Kesalahan Umum
- Menganggap HTML sebagai bahasa pemrograman → padahal markup language
- Menulis HTML tanpa memahami semantik → pakai `<div>` untuk semuanya
- Tidak menutup tag → menyebabkan layout berantakan
- Menempelkan gaya (CSS) langsung di HTML secara berlebihan

## Koneksi dengan Materi Sebelumnya
Ini adalah fondasi paling dasar. Semua materi selanjutnya — CSS, JavaScript, framework — bertumpu di atas HTML. Jika struktur rumah tidak benar, cat dan listrik tidak bisa dipasang dengan baik.
