# Atribut type hidden untuk Menyimpan Data yang Tidak Ditampilkan ke Pengguna

## Analogi: Perpustakaan Digital

Bayangkan **stiker QR code** di belakang kartu anggota. Pengunjung tidak melihatnya, tapi mesin scan bisa membacanya. Stiker itu menyimpan **data tersembunyi** yang penting untuk sistem.

`<input type="hidden">` adalah **data tersembunyi** di formulir. Pengguna tidak melihatnya, tapi tetap dikirim ke server saat submit. Berguna untuk menyimpan ID, token, atau data yang tidak perlu diubah pengguna.

## Penjelasan Detail

`type="hidden"` membuat input yang **tidak terlihat** di halaman, tapi nilainya tetap dikirim saat form di-submit.

### Format
```html
<input type="hidden" name="user_id" value="12345">
<input type="hidden" name="token" value="abc123xyz">
```

### Kapan Pakai Hidden?
- **ID** data yang sedang diedit (misal: ID buku)
- **Token keamanan** (CSRF token)
- **Timestamp** saat form dibuat
- **Halaman asal** (referrer)
- **Data default** yang tidak perlu diubah pengguna

### Contoh Skenario
```html
<!-- Form edit buku — ID buku dikirim tersembunyi -->
<form action="update-buku.php" method="POST">
  <input type="hidden" name="id_buku" value="42">
  <label for="judul">Judul:</label>
  <input type="text" id="judul" name="judul" value="Laskar Pelangi">
  <button type="submit">Simpan</button>
</form>
```

### Catatan
- Hidden bukan untuk **data rahasia** (pengguna bisa lihat di Source Code)
- Untuk data rahasia, simpan di **server** (session), bukan di hidden
- Pengguna bisa memodifikasi hidden via Developer Tools (F12)

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Hidden Input</title>
  </head>
  <body>
    <h1>Edit Data Buku</h1>

    <form action="update.php" method="POST">
      <!-- Data tersembunyi yang dikirim ke server -->
      <input type="hidden" name="id_buku" value="42">
      <input type="hidden" name="token" value="a1b2c3d4e5">
      <input type="hidden" name="timestamp" value="2024-06-15 10:30:00">

      <!-- Data yang terlihat dan bisa diubah -->
      <p>
        <label for="judul">Judul Buku:</label><br>
        <input type="text" id="judul" name="judul" value="Laskar Pelangi">
      </p>

      <p>
        <label for="penulis">Penulis:</label><br>
        <input type="text" id="penulis" name="penulis" value="Andrea Hirata">
      </p>

      <p>
        <button type="submit">Simpan Perubahan</button>
      </p>
    </form>

    <p><small>Klik Kanan → View Page Source untuk melihat data hidden.</small></p>
  </body>
</html>
```

## Poin Penting
- `type="hidden"` = **data tersembunyi** (tidak terlihat)
- Nilainya tetap **dikirim** ke server
- Cocok untuk ID, token, data konteks
- **Bukan** untuk data rahasia — bisa dilihat di Source Code
- Gunakan session server untuk data yang benar-benar rahasia
