# Atribut type file untuk Mengunggah File dari Perangkat Pengguna

## Analogi: Perpustakaan Digital

Bayangkan **kotak drop-off** di perpustakaan tempat pengunjung bisa memasukkan file — foto, dokumen, PDF — untuk diunggah ke sistem.

`<input type="file">` adalah **pintu unggah file**. Pengguna bisa memilih file dari komputernya (foto, PDF, dokumen) untuk dikirim ke server.

## Penjelasan Detail

`type="file"` menampilkan tombol "Pilih File" yang membuka dialog file explorer pengguna.

### Atribut
| Atribut | Fungsi |
|---------|--------|
| `accept` | Filter jenis file yang diterima |
| `multiple` | Izinkan memilih banyak file sekaligus |
| `required` | Wajib upload |
| `capture` | Buka kamera (mobile) |

### Atribut `accept`
Filter berdasarkan ekstensi atau MIME type:
```html
<!-- Hanya gambar -->
<input type="file" accept="image/*">

<!-- Hanya PDF -->
<input type="file" accept=".pdf, application/pdf">

<!-- Gambar dan PDF -->
<input type="file" accept="image/*, .pdf">

<!-- Dari kamera HP -->
<input type="file" accept="image/*" capture="environment">
```

### Multiple Files
```html
<input type="file" multiple>
```
Pengguna bisa pilih beberapa file sekaligus (Ctrl+klik atau Shift+klik).

### Penting: `enctype` di Form
Saat upload file, form HARUS punya:
```html
<form action="upload.php" method="POST" enctype="multipart/form-data">
```
Tanpa ini, file tidak akan terkirim.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Upload File</title>
  </head>
  <body>
    <h1>Upload Koleksi Perpustakaan</h1>

    <!-- WAJIB: enctype="multipart/form-data" untuk upload file -->
    <form action="upload.php" method="POST" enctype="multipart/form-data">

      <p>
        <label for="foto">Foto Sampul Buku:</label><br>
        <input type="file" id="foto" name="foto"
               accept="image/*">
        <small>Format: JPG, PNG, WebP. Maksimal 2MB.</small>
      </p>

      <p>
        <label for="dokumen">Dokumen Buku (PDF):</label><br>
        <input type="file" id="dokumen" name="dokumen"
               accept=".pdf, application/pdf" required>
        <small>Hanya file PDF.</small>
      </p>

      <p>
        <label for="galeri">Galeri Foto (bisa banyak):</label><br>
        <input type="file" id="galeri" name="galeri"
               accept="image/*" multiple>
        <small>Bisa pilih beberapa foto sekaligus.</small>
      </p>

      <p>
        <button type="submit">Upload</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `type="file"` = tombol **pilih file** untuk upload
- `accept` = filter jenis file
- `multiple` = upload banyak file
- Form WAJIB pakai `enctype="multipart/form-data"`
- `capture` = buka kamera langsung di HP
