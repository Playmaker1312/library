# Tag label dan Atribut for untuk Menghubungkan Label dengan Elemen Input

## Analogi: Perpustakaan Digital

Bayangkan **label nama** di samping setiap kolom isian di formulir. Tanpa label, pengunjung bingung: "Kolom ini untuk apa?" Label juga punya fungsi penting: **saat label diklik, kolom inputnya otomatis fokus**.

`<label>` adalah **tanda nama** untuk input. Atribut `for` menghubungkan label dengan input tertentu (berdasarkan `id` input).

## Penjelasan Detail

`<label>` digunakan untuk memberi **label** pada elemen form. Dua cara menggunakannya:

### Cara 1: Atribut `for` (menunjuk `id` input)
```html
<label for="nama">Nama Lengkap:</label>
<input type="text" id="nama" name="nama">
```
Klik "Nama Lengkap:" → fokus ke input dengan `id="nama"`.

### Cara 2: Bungkus Input di Dalam Label
```html
<label>
  Nama Lengkap:
  <input type="text" name="nama">
</label>
```
Tanpa `for`, cukup bungkus input di dalam `<label>`.

### Manfaat Label
1. **Aksesibilitas** — screen reader membacakan label saat input difokuskan
2. **UX lebih baik** — area klik lebih besar (klik label = fokus input)
3. **Checkbox/Radio** — lebih mudah dicentang (klik teks, bukan kotak kecil)

### Aturan
- `for` harus cocok dengan `id` input (case-sensitive)
- Satu label untuk satu input
- Input bisa tanpa label, tapi tidak disarankan untuk aksesibilitas

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Label</title>
  </head>
  <body>
    <h1>Formulir Anggota</h1>

    <form action="daftar.php" method="POST">
      <!-- Cara 1: Label + for -->
      <p>
        <label for="nama">Nama Lengkap:</label><br>
        <input type="text" id="nama" name="nama" required>
      </p>

      <p>
        <label for="email">Alamat Email:</label><br>
        <input type="email" id="email" name="email" required>
      </p>

      <!-- Cara 2: Input di dalam label (tanpa for) -->
      <p>
        <label>
          <input type="checkbox" name="setuju" required>
          Saya setuju dengan syarat dan ketentuan
        </label>
      </p>

      <p>
        <label>
          <input type="radio" name="anggota" value="biasa" checked>
          Anggota Biasa
        </label>
        <label>
          <input type="radio" name="anggota" value="premium">
          Anggota Premium
        </label>
      </p>

      <p>
        <button type="submit">Daftar</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `<label>` = **label** untuk elemen form
- `for="id"` = hubungkan label dengan input berdasarkan `id`
- Atau bungkus input di dalam `<label>` (tanpa `for`)
- Manfaat: **aksesibilitas** dan **area klik lebih besar**
- WAJIB untuk checkbox/radio agar mudah diklik
