# Atribut type checkbox untuk Pilihan yang Bisa Dipilih Lebih dari Satu

## Analogi: Perpustakaan Digital

Bayangkan **daftar genre buku** yang bisa kamu pilih lebih dari satu: ☐ Fiksi, ☐ Non Fiksi, ☐ Sains, ☐ Sejarah. Kamu bisa centang Fiksi + Sains sekaligus.

`<input type="checkbox">` adalah **kotak centang** — pilihan yang bisa dipilih **lebih dari satu** dalam satu kelompok.

## Penjelasan Detail

`type="checkbox"` menampilkan kotak yang bisa dicentang ✅ atau dikosongkan ☐.

### Atribut
| Atribut | Fungsi |
|---------|--------|
| `checked` | Centang secara default |
| `value` | Nilai yang dikirim ke server (default: "on") |
| `name` | Nama field |
| `required` | Wajib dicentang |

### Cara Kerja
```html
<input type="checkbox" name="genre" value="fiksi" checked>
<input type="checkbox" name="genre" value="nonfiksi">
```
- Jika dicentang → server menerima `genre=fiksi`
- Jika tidak dicentang → server tidak menerima apa pun

### Aturan `name` untuk Checkbox
- Jika **bisa pilih banyak** → semua pakai `name` yang **sama** (array di server)
- Jika **pilihan independen** → masing-masing pakai `name` **berbeda**

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Checkbox</title>
  </head>
  <body>
    <h1>Pilihan Genre Buku</h1>

    <form action="simpan.php" method="POST">
      <p>Pilih genre favorit Anda (bisa lebih dari satu):</p>

      <p>
        <input type="checkbox" id="fiksi" name="genre[]" value="fiksi" checked>
        <label for="fiksi">Fiksi</label>

        <input type="checkbox" id="nonfiksi" name="genre[]" value="nonfiksi">
        <label for="nonfiksi">Non Fiksi</label>

        <input type="checkbox" id="sains" name="genre[]" value="sains">
        <label for="sains">Sains</label>

        <input type="checkbox" id="sejarah" name="genre[]" value="sejarah">
        <label for="sejarah">Sejarah</label>
      </p>

      <p>
        <input type="checkbox" id="setuju" name="setuju" required>
        <label for="setuju">Saya setuju dengan syarat dan ketentuan</label>
      </p>

      <p>
        <button type="submit">Simpan</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `type="checkbox"` = **kotak centang** (bisa pilih banyak)
- `checked` = centang secara default
- `value` = nilai yang dikirim (default "on")
- `name` sama → server terima array
- `name` beda → server terima nilai terpisah
