# Atribut type reset untuk Tombol Mengosongkan Semua Isian Formulir

## Analogi: Perpustakaan Digital

Bayangkan **tombol "Hapus Semua"** di meja pendaftaran. Jika pengunjung salah isi dan ingin memulai dari awal, mereka tekan tombol ini dan semua kolom kosong kembali.

`<input type="reset">` adalah **tombol reset** — saat diklik, semua input dalam form kembali ke nilai defaultnya (value awal atau kosong).

## Penjelasan Detail

`type="reset"` membuat tombol yang **mengembalikan semua input ke nilai awal**.

### Format
```html
<input type="reset" value="Hapus Semua">
```

Atau dengan `<button>`:
```html
<button type="reset">Hapus Semua</button>
```

### Cara Kerja
- Mengembalikan ke **nilai awal** (atribut `value`)
- Jika tidak ada `value` → input jadi kosong
- Checkbox/radio kembali ke state awal (`checked` atau tidak)
- Textarea kembali ke teks awal
- Select kembali ke opsi awal

### Kapan Pakai?
- Formulir panjang yang mungkin perlu diisi ulang
- Form dengan banyak field
- Form yang sering diisi berulang

### Kapan JANGAN Pakai?
- Form login (berbahaya jika ter-reset)
- Jika tidak ada nilai default yang berguna
- Form pendek (tidak perlu)

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Reset Button</title>
  </head>
  <body>
    <h1>Pendaftaran Anggota Baru</h1>

    <form action="daftar.php" method="POST">
      <p>
        <label for="nama">Nama:</label><br>
        <input type="text" id="nama" name="nama" value="Masukkan nama">
      </p>

      <p>
        <label for="email">Email:</label><br>
        <input type="email" id="email" name="email" placeholder="nama@email.com">
      </p>

      <p>Jenis Kelamin:</p>
      <p>
        <input type="radio" id="pria" name="jk" value="pria" checked>
        <label for="pria">Pria</label>
        <input type="radio" id="wanita" name="jk" value="wanita">
        <label for="wanita">Wanita</label>
      </p>

      <p>
        <input type="checkbox" id="setuju" name="setuju" checked>
        <label for="setuju">Saya setuju syarat dan ketentuan</label>
      </p>

      <p>
        <button type="submit">Daftar</button>
        <button type="reset">Reset Formulir</button>
        <!-- Atau: <input type="reset" value="Reset"> -->
      </p>
    </form>

    <p><small>Klik "Reset" → semua field kembali ke nilai awal.</small></p>
  </body>
</html>
```

## Poin Penting
- `type="reset"` = tombol **kembalikan ke nilai default**
- Tidak menghapus — mengembalikan ke `value` awal
- Berguna untuk form panjang
- Hati-hati: bisa menyebabkan frustrasi jika terklik tidak sengaja
- Alternatif: hapus manual dengan JavaScript
