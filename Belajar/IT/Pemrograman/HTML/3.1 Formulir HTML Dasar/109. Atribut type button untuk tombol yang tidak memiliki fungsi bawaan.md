# Atribut type button untuk Tombol yang Tidak Memiliki Fungsi Bawaan

## Analogi: Perpustakaan Digital

Bayangkan **tombol "Bantuan"** di meja pendaftaran. Tombol ini tidak mengirim data dan tidak mereset — hanya menunggu pustakawan memprogramnya: "Saat ditekan, tampilkan nomor darurat."

`<input type="button">` adalah **tombol tanpa fungsi bawaan**. Tidak submit, tidak reset. Fungsinya ditentukan sepenuhnya oleh JavaScript.

## Penjelasan Detail

`type="button"` membuat tombol yang **tidak melakukan apa pun secara default**. Harus dikombinasikan dengan JavaScript untuk memberi fungsi.

### Format
```html
<input type="button" value="Klik Saya" onclick="alert('Halo!')">
```

Atau dengan `<button>`:
```html
<button type="button" onclick="alert('Halo!')">Klik Saya</button>
```

### Perbedaan Ketiga Type Tombol
| Type | Fungsi Default |
|------|----------------|
| `submit` | Kirim data form |
| `reset` | Reset form ke default |
| `button` | **Tidak ada** — butuh JavaScript |

### Kapan Pakai `type="button"`?
- **Tombol JavaScript** — toggle menu, buka modal, hitung
- **Kontrol kustom** — tombol yang tidak berhubungan dengan form
- **Mencegah submit tidak sengaja** — jika tombol ada di dalam form

### Di Dalam Form
Jika tombol biasa diletakkan di dalam `<form>` tanpa `type`, defaultnya adalah `submit`! Jadi selalu tentukan `type="button"` untuk tombol non-submit di dalam form.

```html
<form action="cari.php">
  <input type="text" name="q">
  <button type="button" onclick="alert('Mencari...')">Cek</button>
  <!-- Tanpa type="button", tombol ini akan submit form! -->
</form>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Button Type</title>
  </head>
  <body>
    <h1>Demo Tombol Button</h1>

    <form action="cari.php" method="GET">
      <p>
        <label for="q">Cari Buku:</label><br>
        <input type="text" id="q" name="q" placeholder="Judul buku...">
      </p>

      <p>
        <!-- Submit: mengirim form -->
        <button type="submit">Cari</button>

        <!-- Button: tidak mengirim, butuh JavaScript -->
        <button type="button" onclick="alert('Fitur bantuan akan segera hadir!')">
          Bantuan
        </button>

        <button type="button" onclick="this.textContent='Sudah diklik!'">
          Klik Saya
        </button>
      </p>
    </form>

    <p>
      <!-- Tombol di luar form (tidak perlu type="button") -->
      <button onclick="alert('Tombol di luar form!')">
        Tombol Bebas
      </button>
    </p>
  </body>
</html>
```

## Poin Penting
- `type="button"` = tombol **tanpa fungsi bawaan**
- Harus dikombinasikan dengan **JavaScript**
- Di dalam `<form>`, WAJIB tulis `type="button"` agar tidak submit
- Lebih fleksibel daripada `submit`/`reset`
- Gunakan untuk toggle, modal, kalkulasi, dan interaksi kustom
