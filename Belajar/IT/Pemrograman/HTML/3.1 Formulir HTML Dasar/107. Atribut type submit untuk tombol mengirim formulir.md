# Atribut type submit untuk Tombol Mengirim Formulir

## Analogi: Perpustakaan Digital

Bayangkan **tombol "Kirim"** di meja pendaftaran — setelah semua formulir diisi, pengunjung menekan tombol ini dan data dikirim ke pustakawan.

`<input type="submit">` adalah **tombol kirim** — saat diklik, semua data dalam form dikirim ke URL yang ditentukan di atribut `action`.

## Penjelasan Detail

`type="submit"` membuat tombol yang **mengirim data formulir** ke server.

### Format
```html
<input type="submit" value="Kirim">
```

Atau dengan tag `<button>` (lebih fleksibel):
```html
<button type="submit">Kirim</button>
```

### `input submit` vs `button submit`
| `<input type="submit">` | `<button type="submit">` |
|-------------------------|--------------------------|
| Self-closing | Butuh tutup `</button>` |
| Teks di `value` | Teks di antara tag |
| Tidak bisa HTML di dalam | Bisa gambar/ikon di dalam |
| Lebih sederhana | Lebih fleksibel |

### Atribut
```html
<input type="submit" value="Simpan"
       formaction="simpan.php"  <!-- override action -->
       formmethod="POST"        <!-- override method -->
       formnovalidate           <!-- nonaktifkan validasi -->
       disabled>                <!-- nonaktifkan tombol -->
```

### Mencegah Submit Ganda
```html
<input type="submit" value="Kirim" onclick="this.disabled=true">
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Submit Button</title>
  </head>
  <body>
    <h1>Formulir Perpustakaan</h1>

    <form action="simpan.php" method="POST">
      <p>
        <label for="nama">Nama:</label><br>
        <input type="text" id="nama" name="nama" required>
      </p>

      <p>
        <label for="email">Email:</label><br>
        <input type="email" id="email" name="email" required>
      </p>

      <p>
        <!-- Input submit -->
        <input type="submit" value="Simpan Data">

        <!-- Button submit (lebih fleksibel) -->
        <button type="submit">
          <strong>✅</strong> Kirim
        </button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `type="submit"` = tombol yang **mengirim form**
- `value` = teks pada tombol
- Bisa ganti dengan `<button type="submit">` untuk lebih fleksibel
- Atribut `formaction`, `formmethod` override action/method form
- `disabled` = nonaktifkan tombol
