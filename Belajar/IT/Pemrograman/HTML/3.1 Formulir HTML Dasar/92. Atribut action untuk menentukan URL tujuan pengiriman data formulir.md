# Atribut action untuk Menentukan URL Tujuan Pengiriman Data Formulir

## Analogi: Perpustakaan Digital

Bayangkan **kotak saran** di perpustakaan. Pengunjung menulis saran di kertas dan memasukkannya ke kotak. Kotak itu punya alamat tujuan: "Kepala Perpustakaan".

`action` pada `<form>` adalah **alamat tujuan** — ke mana data formulir akan dikirim saat tombol submit diklik.

## Penjelasan Detail

`action` menentukan **URL** yang akan menerima data saat form dikirim.

### Format
```html
<!-- Kirim ke file PHP di server yang sama -->
<form action="proses.php" method="POST">

<!-- Kirim ke URL absolut -->
<form action="https://api.perpus.com/daftar" method="POST">

<!-- Kirim ke halaman yang sama (kosongkan action) -->
<form action="" method="GET">
<!-- atau tidak ditulis sama sekali -->
<form method="GET">
```

### Nilai Action
| Nilai | Keterangan |
|-------|------------|
| `"proses.php"` | File di folder yang sama |
| `"/daftar/proses.php"` | Path absolut dari root |
| `"https://api.example.com/submit"` | URL ke server lain |
| `""` (kosong) | Kirim ke halaman itu sendiri |
| Tidak ditulis | Kirim ke halaman itu sendiri |

### Catatan
- Action bisa di-*override* oleh tombol submit dengan atribut `formaction`
- Jika metode GET, action bisa mengandung query string
- Tanpa action, browser mengirim ke URL halaman saat ini

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Form Action</title>
  </head>
  <body>
    <h1>Formulir Perpustakaan</h1>

    <!-- Action ke file spesifik -->
    <form action="daftar-anggota.php" method="POST">
      <label for="nama">Nama:</label>
      <input type="text" id="nama" name="nama" required>
      <button type="submit">Daftar</button>
    </form>

    <hr>

    <!-- Action dikirim ke halaman sendiri (action="" atau tidak ditulis) -->
    <form method="GET">
      <label for="cari">Cari Buku:</label>
      <input type="text" id="cari" name="q" placeholder="Masukkan judul buku...">
      <button type="submit">Cari</button>
    </form>
    <!-- Catatan: data akan muncul di URL setelah submit -->
  </body>
</html>
```

## Poin Penting
- `action` = **URL tujuan** pengiriman data form
- Jika dikosongkan, data dikirim ke **halaman yang sama**
- Biasanya berisi file PHP, Node.js, atau API endpoint
- Atribut `formaction` pada tombol bisa override action utama
