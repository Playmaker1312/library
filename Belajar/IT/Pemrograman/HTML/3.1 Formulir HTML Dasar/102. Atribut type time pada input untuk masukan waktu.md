# Atribut type time pada Input untuk Masukan Waktu

## Analogi: Perpustakaan Digital

Bayangkan **jam digital** yang bisa kamu atur — memilih jam buka perpustakaan. Klik → muncul pemilih jam dan menit.

`<input type="time">` adalah **pemilih waktu** (time picker) bawaan browser.

## Penjelasan Detail

`type="time"` menampilkan input untuk memilih **waktu** (jam dan menit).

### Format
- Data dikirim: `HH:MM` (24-jam)
- Tampilan: tergantung browser (bisa dropdown jam-menit, atau keyboard)

### Atribut
```html
<input type="time" id="waktu" name="waktu"
       min="08:00" max="17:00"
       value="09:00"
       step="900">  <!-- step dalam detik: 900 = 15 menit -->
```

### Atribut `step`
- Default: `60` = setiap 1 menit
- `900` = setiap 15 menit
- `3600` = setiap 1 jam

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Input Time</title>
  </head>
  <body>
    <h1>Jam Buka Perpustakaan</h1>

    <form action="simpan.php" method="POST">
      <p>
        <label for="buka">Jam Buka:</label><br>
        <input type="time" id="buka" name="buka"
               value="08:00" min="06:00" max="12:00">
      </p>

      <p>
        <label for="tutup">Jam Tutup:</label><br>
        <input type="time" id="tutup" name="tutup"
               value="20:00" min="12:00" max="22:00">
      </p>

      <p>
        <label for="reminder">Waktu Pengingat:</label><br>
        <input type="time" id="reminder" name="reminder"
               step="900">
        <small>Kelipatan 15 menit</small>
      </p>

      <p>
        <button type="submit">Simpan Jadwal</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `type="time"` = **pemilih waktu** (jam:menit)
- Format: `HH:MM` (24-jam)
- `min`/`max` = batas waktu
- `step` = interval (dalam detik)
