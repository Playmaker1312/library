# Atribut type password pada Input untuk Masukan Kata Sandi Tersembunyi

## Analogi: Perpustakaan Digital

Bayangkan **kolom PIN** di mesin absensi perpustakaan. Saat kamu mengetik PIN, yang muncul bukan angka yang kamu ketik, tapi **bullet (●●●●)** — agar orang di belakangmu tidak bisa melihat PIN-mu.

`<input type="password">` adalah **kolom kata sandi** di HTML. Teks yang diketik akan disembunyikan — diganti dengan simbol bullet atau asterisk.

## Penjelasan Detail

`type="password"` menyembunyikan teks yang diketik pengguna.

### Perbedaan dengan `text`
```html
<!-- Teks terlihat -->
<input type="text" placeholder="Nama">

<!-- Teks tersembunyi (●●●) -->
<input type="password" placeholder="Kata Sandi">
```

### Atribut Khusus
| Atribut | Fungsi |
|---------|--------|
| `placeholder` | Petunjuk (tidak tersembunyi) |
| `maxlength` | Maksimal karakter |
| `minlength` | Minimal karakter |
| `pattern` | Validasi format |
| `autocomplete` | Saran simpan password |
| `required` | Wajib diisi |

### Keamanan
- **Hanya menyembunyikan tampilan** — data tetap dikirim polos jika tanpa HTTPS
- WAJIB gunakan **HTTPS** agar data terenkripsi saat dikirim
- Jangan set `maxlength` terlalu pendek (minimal 8 karakter)
- Browser bisa menawarkan menyimpan password (atribut `autocomplete`)

### Tips Keamanan
```html
<!-- Password dengan syarat minimal -->
<input type="password" name="pass" required
       minlength="8" pattern="(?=.*\d)(?=.*[a-z])(?=.*[A-Z]).{8,}"
       title="Minimal 8 karakter, mengandung huruf besar, kecil, dan angka">
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Input Password</title>
  </head>
  <body>
    <h1>Login Anggota Perpustakaan</h1>

    <form action="login.php" method="POST">
      <p>
        <label for="username">Username:</label><br>
        <input type="text" id="username" name="username" required
               placeholder="Masukkan username" autocomplete="username">
      </p>

      <p>
        <label for="password">Kata Sandi:</label><br>
        <input type="password" id="password" name="password" required
               placeholder="Masukkan kata sandi"
               minlength="8" autocomplete="current-password">
      </p>

      <p>
        <button type="submit">Login</button>
      </p>
    </form>

    <p><small>Kata sandi Anda akan disembunyikan saat diketik.</small></p>
  </body>
</html>
```

## Poin Penting
- `type="password"` = **sembunyikan teks** (●●●)
- Hanya menyembunyikan **tampilan** — tetap gunakan **HTTPS** untuk keamanan
- `minlength` = minimal karakter (rekomendasi: 8+)
- `autocomplete` = izinkan browser menyimpan password
- Jangan pernah tampilkan password di log atau URL
