# Atribut type radio untuk Pilihan yang Hanya Bisa Dipilih Satu dari Kelompok

## Analogi: Perpustakaan Digital

Bayangkan **tombol pilih jenis anggota** di formulir pendaftaran:
- ○ Anggota Biasa
- ○ Anggota Premium
- ○ Anggota VIP

Kamu hanya bisa memilih **satu** — jika klik Premium, pilihan Biasa otomatis terlepas (seperti tombol radio di mobil lama).

`<input type="radio">` adalah **tombol radio** — pilihan yang hanya bisa memilih **satu** dalam satu kelompok.

## Penjelasan Detail

`type="radio"` menampilkan tombol lingkaran 🔘 yang hanya bisa memilih **satu** dalam grup yang sama.

### Atribut
| Atribut | Fungsi |
|---------|--------|
| `name` | **Nama grup** — harus SAMA untuk satu kelompok pilihan |
| `value` | Nilai yang dikirim ke server |
| `checked` | Pilih secara default |

### Cara Kerja
```html
<input type="radio" name="anggota" value="biasa">
<input type="radio" name="anggota" value="premium" checked>
<input type="radio" name="anggota" value="vip">
```
Atribut `name` harus **sama** — ini membentuk grup. Hanya satu yang bisa dipilih.

### Bedanya dengan Checkbox
| Radio | Checkbox |
|-------|----------|
| Lingkaran 🔘 | Kotak ☐ |
| Pilih **satu** dalam grup | Pilih **banyak** |
| `name` sama dalam grup | `name` bisa sama atau beda |
| Wajib `value` | `value` opsional |

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Radio Button</title>
  </head>
  <body>
    <h1>Pendaftaran Anggota Perpustakaan</h1>

    <form action="daftar.php" method="POST">
      <p>Jenis Keanggotaan:</p>
      <p>
        <input type="radio" id="biasa" name="anggota" value="biasa" checked>
        <label for="biasa">Anggota Biasa (Gratis)</label><br>

        <input type="radio" id="premium" name="anggota" value="premium">
        <label for="premium">Anggota Premium (Rp 50.000/tahun)</label><br>

        <input type="radio" id="vip" name="anggota" value="vip">
        <label for="vip">Anggota VIP (Rp 150.000/tahun)</label>
      </p>

      <p>Status Pembayaran:</p>
      <p>
        <input type="radio" id="lunas" name="status" value="lunas">
        <label for="lunas">Lunas</label><br>

        <input type="radio" id="cicil" name="status" value="cicil">
        <label for="cicil">Cicil</label>
      </p>
      <!-- Grup berbeda karena name berbeda ('anggota' vs 'status') -->

      <p>
        <button type="submit">Daftar</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `type="radio"` = tombol pilih **satu** dalam grup
- `name` **sama** → satu grup (hanya satu yang bisa dipilih)
- `name` **beda** → grup berbeda (bisa pilih satu dari tiap grup)
- `value` = data yang dikirim ke server
- `checked` = pilihan default
