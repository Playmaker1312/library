# Atribut type email pada Input untuk Masukan Alamat Email dengan Validasi

## Analogi: Perpustakaan Digital

Bayangkan **kolom alamat email** di formulir pendaftaran. Saat kamu mengetik "budi@email" (tanpa .com), browser langsung memberi peringatan: "Format email tidak valid."

`<input type="email">` adalah **kolom email pintar** yang otomatis memeriksa apakah yang diketik sesuai format email (mengandung `@` dan domain).

## Penjelasan Detail

`type="email"` menyediakan input dengan **validasi format email** bawaan.

### Cara Kerja
- Browser memeriksa apakah input mengandung `@` dan domain
- Di mobile → keyboard menampilkan tombol `@` dan `.com`
- Jika tidak valid → form tidak bisa dikirim (pesan error otomatis)
- Validasi dasar (bukan 100% akurat, tapi cukup untuk umum)

### Atribut
```html
<input type="email" id="email" name="email"
       placeholder="nama@email.com"
       multiple        <!-- menerima multiple email (dipisah koma) -->
       required        <!-- wajib diisi -->
       autocomplete="email">
```

### Multiple Email
```html
<!-- Menerima beberapa email dipisah koma -->
<label for="emails">Undang teman (pisah dengan koma):</label>
<input type="email" id="emails" name="emails" multiple
       placeholder="teman1@email.com, teman2@email.com">
```

### Validasi vs JavaScript
`type="email"` memberi validasi dasar. Untuk validasi lebih ketat (cek domain benar-benar ada), butuh JavaScript atau server-side validation.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Input Email</title>
  </head>
  <body>
    <h1>Pendaftaran Anggota</h1>

    <form action="daftar.php" method="POST">
      <p>
        <label for="email">Alamat Email:</label><br>
        <input type="email" id="email" name="email"
               placeholder="nama@email.com"
               required autocomplete="email">
      </p>

      <p>
        <label for="confirm-email">Konfirmasi Email:</label><br>
        <input type="email" id="confirm-email" name="confirm-email"
               placeholder="ketik ulang email" required>
      </p>

      <p>
        <label for="multi-email">Undang Teman (opsional):</label><br>
        <input type="email" id="multi-email" name="teman"
               placeholder="teman@email.com, teman2@email.com" multiple>
        <small>Pisahkan beberapa email dengan koma.</small>
      </p>

      <p>
        <button type="submit">Daftar</button>
      </p>
    </form>

    <p><small>Coba ketik "budi@" lalu submit — browser akan menolak.</small></p>
  </body>
</html>
```

## Poin Penting
- `type="email"` = input email dengan **validasi format**
- Browser periksa ada `@` dan domain
- Keyboard mobile menampilkan tombol `@`
- `multiple` = menerima beberapa email (dipisah koma)
- Validasi dasar — validasi ketat butuh JavaScript/server
