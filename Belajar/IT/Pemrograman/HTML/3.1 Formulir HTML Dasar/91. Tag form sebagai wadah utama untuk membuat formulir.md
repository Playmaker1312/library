# Tag form sebagai Wadah Utama untuk Membuat Formulir

## Analogi: Perpustakaan Digital

Bayangkan **meja pendaftaran** di pintu masuk perpustakaan. Pengunjung mengisi formulir kertas: nama, email, nomor anggota. Lalu menyerahkannya ke pustakawan.

`<form>` adalah **meja pendaftaran** itu — wadah untuk semua elemen formulir (input, tombol, label). Semua data dari dalam `<form>` bisa dikirim ke server untuk diproses.

## Penjelasan Detail

`<form>` adalah wadah utama untuk **formulir interaktif**. Di dalamnya pengguna bisa memasukkan data dan mengirimkannya ke server.

### Atribut Utama
| Atribut | Fungsi |
|---------|--------|
| `action` | URL tujuan pengiriman data |
| `method` | Metode pengiriman: `GET` atau `POST` |
| `name` | Nama formulir |
| `autocomplete` | Aktif/nonaktif autocomplete (`on`/`off`) |
| `novalidate` | Nonaktifkan validasi HTML5 |
| `enctype` | Encoding data (`multipart/form-data` untuk upload file) |

### Struktur Dasar
```html
<form action="proses.php" method="POST">
  <label for="nama">Nama:</label>
  <input type="text" id="nama" name="nama">
  <button type="submit">Kirim</button>
</form>
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Form</title>
  </head>
  <body>
    <h1>Pendaftaran Anggota Perpustakaan</h1>

    <form action="daftar.php" method="POST">
      <p>
        <label for="nama">Nama Lengkap:</label><br>
        <input type="text" id="nama" name="nama" required>
      </p>

      <p>
        <label for="email">Email:</label><br>
        <input type="email" id="email" name="email" required>
      </p>

      <p>
        <label for="password">Kata Sandi:</label><br>
        <input type="password" id="password" name="password" required>
      </p>

      <p>
        <button type="submit">Daftar</button>
        <button type="reset">Hapus</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `<form>` = **wadah** formulir
- `action` = ke mana data dikirim
- `method` = cara kirim (`GET` atau `POST`)
- Di dalam form: input, label, tombol
- Tanpa `<form>`, data tidak bisa dikirim ke server
