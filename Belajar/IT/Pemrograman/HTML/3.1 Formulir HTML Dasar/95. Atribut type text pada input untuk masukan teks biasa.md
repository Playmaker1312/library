# Atribut type text pada Input untuk Masukan Teks Biasa

## Analogi: Perpustakaan Digital

Bayangkan **kolom isian** untuk menulis nama, alamat, atau judul buku. Ini adalah jenis input paling dasar — sebuah **kotak kosong** tempat pengunjung mengetik teks apa pun.

`<input type="text">` adalah **kotak teks** paling dasar di HTML. Pengguna bisa mengetik huruf, angka, atau simbol apa pun.

## Penjelasan Detail

`type="text"` adalah **default** untuk `<input>`. Jika `type` tidak ditentukan, browser akan menganggapnya sebagai `text`.

```html
<!-- Dua cara ini sama -->
<input type="text">
<input>  <!-- default = text -->
```

### Atribut untuk Input Text
| Atribut | Fungsi | Contoh |
|---------|--------|--------|
| `placeholder` | Teks petunjuk (abu-abu) | `placeholder="Masukkan nama"` |
| `maxlength` | Maksimal karakter | `maxlength="100"` |
| `minlength` | Minimal karakter | `minlength="3"` |
| `pattern` | Validasi dengan regex | `pattern="[A-Za-z ]+"` |
| `value` | Nilai awal | `value="John Doe"` |
| `readonly` | Hanya baca | `readonly` |
| `disabled` | Nonaktif | `disabled` |
| `size` | Lebar input (karakter) | `size="30"` |
| `autocomplete` | Saran autofill | `autocomplete="name"` |

### Perbedaan `placeholder` vs `value`
```html
<!-- Placeholder → hilang saat mengetik -->
<input type="text" placeholder="Nama lengkap">

<!-- Value → sudah terisi, harus dihapus manual -->
<input type="text" value="Nama lengkap">
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Input Text</title>
  </head>
  <body>
    <h1>Input Teks Biasa</h1>

    <form>
      <p>
        <label for="nama">Nama Lengkap:</label><br>
        <input type="text" id="nama" name="nama"
               placeholder="Masukkan nama lengkap"
               maxlength="50" required>
      </p>

      <p>
        <label for="alamat">Alamat:</label><br>
        <input type="text" id="alamat" name="alamat"
               placeholder="Jl. Merdeka No. 123"
               size="40">
      </p>

      <p>
        <label for="kode">Kode Anggota:</label><br>
        <input type="text" id="kode" name="kode"
               value="AG-001" readonly>
        <small>(Tidak bisa diubah)</small>
      </p>

      <p>
        <label for="catatan">Catatan:</label><br>
        <input type="text" id="catatan" name="catatan"
               placeholder="Opsional" disabled>
        <small>(Fitur belum tersedia)</small>
      </p>

      <button type="submit">Kirim</button>
    </form>
  </body>
</html>
```

## Poin Penting
- `type="text"` = input teks **default** (bisa tidak ditulis)
- `placeholder` = petunjuk dalam input (hilang saat mengetik)
- `maxlength` = batas karakter
- `readonly` = hanya baca, `disabled` = nonaktif
- `value` = nilai default yang sudah terisi
