# Atribut type number pada Input untuk Masukan Angka

## Analogi: Perpustakaan Digital

Bayangkan **kolom jumlah buku** yang dipinjam. Pengunjung tidak boleh mengetik "lima" atau "lima buku" — hanya angka: 1, 2, 3. Di mobile, keyboard angka langsung muncul.

`<input type="number">` adalah **kolom angka** yang hanya menerima nilai numerik. Dilengkapi tombol ▲▼ (spinner) untuk naik-turun nilai.

## Penjelasan Detail

`type="number"` membatasi input hanya pada **nilai numerik** (angka).

### Atribut Khusus
| Atribut | Fungsi | Contoh |
|---------|--------|--------|
| `min` | Nilai minimum | `min="0"` |
| `max` | Nilai maksimum | `max="100"` |
| `step` | Kelipatan perubahan | `step="5"` (loncat 5) |
| `value` | Nilai default | `value="1"` |

### Contoh Penggunaan
```html
<!-- Jumlah: 1 - 10, default 1 -->
<input type="number" id="jumlah" name="jumlah"
       min="1" max="10" value="1">

<!-- Usia: 0 - 150 -->
<input type="number" id="usia" name="usia"
       min="0" max="150">

<!-- Harga (step 1000) -->
<input type="number" id="harga" name="harga"
       min="0" step="1000">
```

### Input Number vs Input Text
| `type="number"` | `type="text"` |
|-----------------|---------------|
| Hanya angka | Huruf, angka, simbol |
| Ada spinner ▲▼ | Tidak ada spinner |
| Keyboard numerik di mobile | Keyboard biasa |
| Validasi otomatis | Tidak ada validasi |
| Bisa `min`, `max`, `step` | Tidak bisa |

### Catatan Penting
- Nilai `value` tetap dikirim sebagai **string** ke server
- Browser tidak mencegah input huruf sepenuhnya (tergantung browser)
- Untuk mata uang, pertimbangkan `type="text"` dengan validasi khusus

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Input Number</title>
  </head>
  <body>
    <h1>Peminjaman Buku</h1>

    <form action="pinjam.php" method="POST">
      <p>
        <label for="jumlah">Jumlah Buku Dipinjam:</label><br>
        <input type="number" id="jumlah" name="jumlah"
               min="1" max="5" value="1" step="1">
        <small>Maksimal 5 buku per peminjaman.</small>
      </p>

      <p>
        <label for="durasi">Durasi Peminjaman (hari):</label><br>
        <input type="number" id="durasi" name="durasi"
               min="7" max="30" value="14" step="7">
        <small>Kelipatan 7 hari.</small>
      </p>

      <p>
        <label for="usia">Usia (tahun):</label><br>
        <input type="number" id="usia" name="usia"
               min="0" max="150" placeholder="Masukkan usia">
      </p>

      <p>
        <button type="submit">Pinjam</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `type="number"` = input **angka** dengan spinner
- `min` = nilai minimum, `max` = nilai maksimum
- `step` = kelipatan perubahan
- `value` = nilai default
- Keyboard numerik otomatis di perangkat mobile
