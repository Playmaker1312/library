# Atribut type tel pada Input untuk Masukan Nomor Telepon

## Analogi: Perpustakaan Digital

Bayangkan **kolom nomor telepon** untuk menghubungi anggota perpustakaan. Di HP, kolom ini langsung menampilkan **keyboard numerik** — lebih mudah mengetik nomor.

`<input type="tel">` adalah **kolom nomor telepon**. Tidak ada validasi format khusus (karena format telepon berbeda tiap negara), tapi di mobile keyboard numerik muncul.

## Penjelasan Detail

`type="tel"` mengoptimalkan input untuk nomor telepon.

### Perbedaan dengan `type="number"`
| `type="tel"` | `type="number"` |
|-------------|-----------------|
| Keyboard numerik di mobile | Keyboard numerik + simbol |
| Bisa berisi tanda kurung, strip, + | Hanya angka dan koma |
| Tidak ada spinner | Ada spinner ▲▼ |
| Tidak ada validasi format | Validasi numerik |
| Cocok untuk no telepon | Cocok untuk jumlah/kuantitas |

### Kelebihan `type="tel"`
- Keyboard **numerik** di HP (bukan keyboard huruf)
- Menerima **karakter khusus**: `+`, `-`, `(`, `)`, spasi
- Tidak ada validasi format (karena format telepon sangat bervariasi)

### Validasi
Karena tidak ada validasi bawaan, kamu perlu `pattern` untuk validasi:
```html
<input type="tel" pattern="[0-9+\-\(\) ]+" placeholder="+62 812-3456-7890">
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Input Tel</title>
  </head>
  <body>
    <h1>Data Anggota Perpustakaan</h1>

    <form action="simpan.php" method="POST">
      <p>
        <label for="telp">Nomor Telepon:</label><br>
        <input type="tel" id="telp" name="telp"
               placeholder="+62 812-3456-7890"
               pattern="[0-9+\-\(\)\s]+"
               autocomplete="tel">
      </p>

      <p>
        <label for="hp">Nomor HP (WhatsApp):</label><br>
        <input type="tel" id="hp" name="hp"
               placeholder="08123456789"
               pattern="[0-9]{10,15}"
               autocomplete="tel-national">
      </p>

      <p>
        <button type="submit">Simpan</button>
      </p>
    </form>

    <p><small>Di HP, keyboard angka akan muncul otomatis untuk input telepon.</small></p>
  </body>
</html>
```

## Poin Penting
- `type="tel"` = input **nomor telepon**
- Keyboard **numerik** di perangkat mobile
- Menerima karakter seperti `+`, `-`, `(`, `)`, spasi
- Tidak ada validasi format bawaan — gunakan `pattern` jika perlu
- Berbeda dengan `type="number"` — lebih cocok untuk telepon
