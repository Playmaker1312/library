# Atribut type url pada Input untuk Masukan Alamat URL

## Analogi: Perpustakaan Digital

Bayangkan **kolom alamat website** untuk tautan ke blog atau portofolio anggota perpustakaan. Kamu harus mengetik URL yang valid — dimulai dengan `http://` atau `https://`.

`<input type="url">` adalah **kolom URL** dengan validasi format. Browser memeriksa apakah input dimulai dengan protokol yang valid (`http://`, `https://`, `ftp://`).

## Penjelasan Detail

`type="url"` digunakan untuk input **URL** (alamat web).

### Cara Kerja
- Browser memeriksa apakah URL dimulai dengan protokol (`http://`, `https://`, dll)
- Di mobile → keyboard menampilkan tombol `/`, `.com`
- Jika tidak valid → form tidak bisa dikirim

### Atribut
```html
<input type="url" id="website" name="website"
       placeholder="https://contoh.com"
       pattern="https://.*"    <!-- validasi kustom -->
       autocomplete="url">
```

### URL vs Teks Biasa
```html
<!-- Tanpa validasi URL -->
<input type="text" placeholder="Website (bebas format)">

<!-- Dengan validasi URL -->
<input type="url" placeholder="https://contoh.com">
```

### Validasi
- Validasi dasar: harus dimulai dengan protokol (`http://`, `https://`, dll)
- `https://google.com` ✅
- `google.com` ❌ (tanpa protokol)
- `www.google.com` ❌ (tanpa protokol)
- Untuk validasi yang lebih fleksibel, gunakan `pattern`

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Input URL</title>
  </head>
  <body>
    <h1>Profil Anggota Perpustakaan</h1>

    <form action="simpan.php" method="POST">
      <p>
        <label for="website">Website/Blog:</label><br>
        <input type="url" id="website" name="website"
               placeholder="https://namablog.com"
               autocomplete="url">
        <small>Masukkan URL lengkap dengan https://</small>
      </p>

      <p>
        <label for="github">GitHub:</label><br>
        <input type="url" id="github" name="github"
               placeholder="https://github.com/username"
               pattern="https://github.com/.*">
        <small>Hanya URL GitHub yang diterima</small>
      </p>

      <p>
        <label for="sosmed">Media Sosial (opsional):</label><br>
        <input type="url" id="sosmed" name="sosmed"
               placeholder="https://instagram.com/username">
      </p>

      <p>
        <button type="submit">Simpan Profil</button>
      </p>
    </form>

    <p><small>Coba ketik "google.com" (tanpa https) — browser akan menolak.</small></p>
  </body>
</html>
```

## Poin Penting
- `type="url"` = input **URL** dengan validasi protokol
- Browser periksa URL dimulai dengan `http://`, `https://`, dll
- Keyboard mobile menampilkan tombol `/` dan `.com`
- Gunakan `pattern` untuk validasi URL yang lebih spesifik
- Catat: `google.com` (tanpa `https://`) dianggap **tidak valid**
