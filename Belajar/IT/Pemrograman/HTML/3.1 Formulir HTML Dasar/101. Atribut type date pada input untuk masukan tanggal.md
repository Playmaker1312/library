# Atribut type date pada Input untuk Masukan Tanggal

## Analogi: Perpustakaan Digital

Bayangkan **kalender pop-up** yang muncul saat kamu mengklik kolom tanggal lahir. Kamu bisa memilih tanggal tanpa harus mengetik manual.

`<input type="date">` adalah **pemilih tanggal (date picker)** bawaan browser. Klik → muncul kalender → pilih tanggal.

## Penjelasan Detail

`type="date"` menampilkan **date picker** (kalender) untuk memilih tanggal.

### Format
- Data dikirim dalam format: `YYYY-MM-DD` (tahun-bulan-tanggal)
- Tampilan tergantung browser dan bahasa sistem

### Atribut
```html
<input type="date" id="tgl" name="tgl"
       min="2024-01-01"   <!-- tanggal minimum -->
       max="2024-12-31"   <!-- tanggal maksimum -->
       value="2024-06-15"> <!-- nilai default -->
```

### Peramban (Browser) Support
Didukung di semua browser modern. Di browser lama, fallback ke input teks biasa.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Input Date</title>
  </head>
  <body>
    <h1>Data Peminjaman</h1>

    <form action="pinjam.php" method="POST">
      <p>
        <label for="tgl-pinjam">Tanggal Peminjaman:</label><br>
        <input type="date" id="tgl-pinjam" name="tgl_pinjam"
               value="2024-06-15">
      </p>

      <p>
        <label for="tgl-kembali">Tanggal Pengembalian:</label><br>
        <input type="date" id="tgl-kembali" name="tgl_kembali"
               min="2024-06-15" max="2024-07-15">
        <small>Maksimal 30 hari dari hari ini</small>
      </p>

      <p>
        <label for="tgl-lahir">Tanggal Lahir:</label><br>
        <input type="date" id="tgl-lahir" name="tgl_lahir" required>
      </p>

      <p>
        <button type="submit">Simpan</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `type="date"` = **date picker** (kalender)
- Format value: `YYYY-MM-DD`
- `min`/`max` = batas tanggal
- Tidak semua browser lama mendukung (fallback ke teks)
