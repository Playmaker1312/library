# Tag input sebagai Elemen Masukan Data yang Paling Sering Digunakan

## Analogi: Perpustakaan Digital

Bayangkan **meja pendaftaran** yang punya berbagai jenis kolom isian:
- Kolom teks untuk nama
- Kolom khusus untuk email
- Kotak centang untuk setuju syarat
- Tombol radio untuk pilih jenis anggota

Semua kolom itu dibuat dengan **satu tag**: `<input>`. Yang membedakan adalah atribut `type` — menentukan **jenis input** yang ditampilkan.

`<input>` adalah **pisau Swiss Army** formulir HTML. Satu tag, banyak fungsi.

## Penjelasan Detail

`<input>` adalah **self-closing tag** untuk membuat kontrol input interaktif. Jenisnya ditentukan oleh atribut `type`.

### Atribut Umum `<input>`
| Atribut | Fungsi |
|---------|--------|
| `type` | Jenis input (text, password, email, dll) |
| `name` | Nama field (dikirim ke server) |
| `id` | ID unik (untuk label) |
| `value` | Nilai default/awal |
| `placeholder` | Teks petunjuk dalam input |
| `required` | Wajib diisi |
| `disabled` | Nonaktif |
| `readonly` | Hanya baca |
| `maxlength` | Panjang maksimal teks |
| `autofocus` | Fokus otomatis saat halaman dimuat |

### Jenis `type` Utama
| Type | Tampilan | Contoh |
|------|----------|--------|
| `text` | Kotak teks biasa | Nama, alamat |
| `password` | Teks tersembunyi (••••) | Kata sandi |
| `email` | Input email (validasi otomatis) | alamat@email.com |
| `number` | Input angka (dengan spinner) | 12345 |
| `checkbox` | Kotak centang ✅ | Setuju syarat |
| `radio` | Tombol bundar 🔘 | Pilihan gender |
| `file` | Pilih file | Upload foto |
| `date` | Pilih tanggal 📅 | Tanggal lahir |
| `submit` | Tombol kirim 🚀 | |

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Input Tag</title>
  </head>
  <body>
    <h1>Berbagai Jenis Input</h1>

    <form>
      <p>
        <label for="nama">Nama:</label><br>
        <input type="text" id="nama" name="nama" placeholder="Masukkan nama lengkap" required>
      </p>

      <p>
        <label for="email">Email:</label><br>
        <input type="email" id="email" name="email" placeholder="contoh@email.com">
      </p>

      <p>
        <label for="usia">Usia:</label><br>
        <input type="number" id="usia" name="usia" min="0" max="150">
      </p>

      <p>
        <label for="tgl">Tanggal Lahir:</label><br>
        <input type="date" id="tgl" name="tgl">
      </p>

      <p>
        <input type="checkbox" id="setuju" name="setuju" checked>
        <label for="setuju">Saya setuju dengan syarat dan ketentuan</label>
      </p>

      <p>
        <button type="submit">Kirim</button>
      </p>
    </form>
  </body>
</html>
```

## Poin Penting
- `<input>` = **elemen input** serbaguna
- Atribut `type` menentukan **jenis input**
- `name` = nama field untuk server (wajib)
- `id` = untuk menghubungkan dengan `<label>`
- Banyak atribut: `placeholder`, `required`, `value`, `disabled`
