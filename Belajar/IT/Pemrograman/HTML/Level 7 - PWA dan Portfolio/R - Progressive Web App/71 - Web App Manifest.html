Web App Manifest

Penjelasan

Web App Manifest adalah file JSON bernama manifest.json yang memberikan informasi tentang aplikasi web kepada browser. File ini memungkinkan website kamu "dipasang" (install) di layar depan HP atau desktop seperti aplikasi native. Manifest berisi metadata seperti nama, ikon, warna tema, dan cara aplikasi ditampilkan saat dibuka.

Fungsi

  • Membuat website bisa di-install sebagai aplikasi di perangkat pengguna
  • Menentukan tampilan aplikasi: layar penuh (standalone) atau dengan URL bar
  • Memberi identitas visual lewat ikon, nama, dan warna tema
  • Mengatur halaman awal (start_url) dan orientasi layar
  • Membedakan app versi pendek dan panjang lewat short_name dan name

Cara Pengimplementasian

{
  "name": "Portfolio Saya",
  "short_name": "Portfolio",
  "start_url": "/index.html",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#1a73e8",
  "icons": [
    {
      "src": "icon-192x192.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "icon-512x512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ]
}

Hubungkan ke HTML dengan:

<link rel="manifest" href="manifest.json">

Analogi (Rumah / Bangunan)

Manifest itu seperti papan nama dan brosur rumah. name adalah nama rumah di papan, short_name adalah panggilan akrabnya. icons adalah foto rumah dari berbagai ukuran. display: standalone berarti tamu melihat rumah tanpa halaman depan — langsung masuk ke ruang tamu. theme_color adalah cat tembok luar, background_color adalah warna lantai saat pertama buka pintu. start_url adalah pintu masuk utama yang selalu digunakan.

Dipakai Untuk

  • Website portofolio agar bisa di-install pengguna
  • Aplikasi berita, e-commerce, atau tool produktivitas
  • Semua PWA (Progressive Web App) wajib punya manifest
  • Website yang ingin tampil seperti aplikasi native tanpa lewat Google Play / App Store

Kesalahan Umum

  • Tidak menyertakan tag <link rel="manifest"> di HTML
  • Ukuran ikon tidak lengkap — minimal harus ada 192x192 dan 512x512
  • Typo JSON (kelebihan koma di akhir, kurang kutip) sehingga file tidak terbaca
  • start_url salah path sehingga halaman putih saat dibuka
  • Lupa mengatur display: standalone sehingga masih muncul address bar

Koneksi dengan Materi Sebelumnya

Manifest berhubungan dengan Service Worker (materi 72) karena keduanya diperlukan agar website bisa di-install. Service Worker menangani cache dan offline, sedangkan manifest mengatur tampilan saat aplikasi dibuka. Juga terkait dengan Lighthouse (materi 73) yang akan mengaudit apakah manifest sudah benar. Tanpa manifest, PWA tidak akan lulus audit PWA di Lighthouse.

Soal Latihan

  1. Apa fungsi properti display: standalone dalam manifest.json?

    Lihat Jawaban

    Properti display: standalone membuat aplikasi web dibuka tanpa elemen browser seperti address bar dan toolbar, sehingga tampil seperti aplikasi native layar penuh.

  2. Sebutkan minimal 3 properti yang wajib ada dalam manifest.json untuk PWA!

    Lihat Jawaban

    Tiga properti wajib: name (nama aplikasi), icons (kumpulan ikon berbagai ukuran), dan start_url (halaman pertama saat aplikasi dibuka). Properti lain seperti short_name, display, theme_color, dan background_color sangat disarankan.

  3. Bagaimana cara menghubungkan file manifest.json ke dokumen HTML?

    Lihat Jawaban

    Tambahkan tag <link rel="manifest" href="manifest.json"> di dalam elemen <head> pada file HTML.
