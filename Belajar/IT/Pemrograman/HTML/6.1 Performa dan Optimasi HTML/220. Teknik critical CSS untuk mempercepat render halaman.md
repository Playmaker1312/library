# Teknik Critical CSS untuk Mempercepat Render Halaman

## Analogi: Perpustakaan Digital

Ketika seorang anggota membuka buku di perpustakaan digital, ia ingin segera membaca halaman pertama tanpa harus menunggu seluruh buku diunduh. Critical CSS ibarat menyediakan sinopsis dan bab pertama langsung di layar, sementara halaman-halaman lain dimuat di latar belakang. Pengguna bisa langsung membaca tanpa menunggu buku selesai diunduh. Begitu pula dengan halaman web: kita mengirim CSS yang cukup untuk merender konten "di atas lipatan" (above the fold) segera, sementara CSS sisanya dimuat secara asinkron.

## Penjelasan Detail

Critical CSS adalah teknik mengekstrak dan menyisipkan aturan CSS yang diperlukan untuk merender bagian halaman yang terlihat pertama kali (above the fold) langsung di dalam tag `<style>` di `<head>`. CSS yang kurang kritis dimuat secara asinkron menggunakan JavaScript atau atribut `media="print"` yang kemudian diubah. Teknik ini menghilangkan render-blocking request untuk file CSS utama, sehingga browser dapat segera merender konten yang terlihat tanpa menunggu unduhan CSS selesai. Alat seperti Critical, Penthouse, atau PurgeCSS dapat digunakan untuk mengekstrak critical CSS secara otomatis. Hasilnya adalah peningkatan signifikan pada First Contentful Paint (FCP) dan Largest Contentful Paint (LCP).

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Critical CSS Demo</title>

  <!-- Critical CSS: langsung di-inline untuk render segera -->
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body {
      font-family: Arial, Helvetica, sans-serif;
      line-height: 1.6;
      color: #222;
      background: #fff;
    }
    header {
      background: linear-gradient(135deg, #1a237e, #283593);
      color: white;
      padding: 60px 20px;
      text-align: center;
    }
    header h1 { font-size: 2.5em; margin-bottom: 10px; }
    header p { font-size: 1.2em; opacity: 0.9; }
    .cta-button {
      display: inline-block;
      background: #ff6f00;
      color: white;
      padding: 12px 30px;
      border-radius: 50px;
      text-decoration: none;
      font-weight: bold;
      margin-top: 20px;
    }
    .container { max-width: 1100px; margin: 0 auto; padding: 20px; }
    /* Ini adalah critical CSS — cukup untuk render bagian atas halaman */
  </style>

  <!-- Non-critical CSS dimuat secara asinkron -->
  <link rel="preload" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.0/css/all.min.css" as="style" onload="this.onload=null;this.rel='stylesheet'">
  <noscript><link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.0/css/all.min.css"></noscript>
</head>
<body>
  <header>
    <h1>Belajar Critical CSS</h1>
    <p>Halaman ini langsung muncul karena CSS kritis di-inline</p>
    <a href="#" class="cta-button">Mulai Sekarang</a>
  </header>

  <main class="container">
    <section style="margin: 40px 0;">
      <h2>Apa itu Critical CSS?</h2>
      <p>Critical CSS adalah CSS yang dibutuhkan untuk merender konten "above the fold" — bagian halaman yang terlihat tanpa scroll.</p>
    </section>

    <section style="margin: 40px 0;">
      <h2>Bagaimana Cara Kerjanya?</h2>
      <ol style="margin-left: 20px;">
        <li>Ekstrak CSS yang diperlukan untuk bagian atas halaman</li>
        <li>Inline CSS tersebut di dalam tag &lt;style&gt; di &lt;head&gt;</li>
        <li>Muat CSS sisanya secara asinkron</li>
        <li>Halaman langsung merender tanpa menunggu CSS file besar</li>
      </ol>
    </section>

    <section style="margin: 40px 0; background: #f5f5f5; padding: 30px; border-radius: 8px;">
      <h2>Tools untuk Critical CSS</h2>
      <ul style="margin-left: 20px;">
        <li><strong>Critical</strong> (npm) — alat otomatis ekstraksi critical CSS</li>
        <li><strong>Penthouse</strong> — ekstrak critical CSS berdasarkan viewport tertentu</li>
        <li><strong>PurgeCSS</strong> — hapus CSS yang tidak digunakan</li>
        <li><strong>Webpack Plugin</strong> — integrasi critical CSS ke build pipeline</li>
      </ul>
    </section>

    <section style="margin: 40px 0;" id="non-critical">
      <h2>Konten di Bawah Lipatan</h2>
      <p>Bagian ini menggunakan CSS non-kritis yang dimuat secara asinkron.</p>
      <p>Font ikon di bawah baru muncul setelah CSS selesai dimuat:</p>
      <p style="font-size: 2em; color: #283593;">
        <i class="fas fa-tachometer-alt"></i>
        <i class="fas fa-rocket"></i>
        <i class="fas fa-chart-line"></i>
      </p>
    </section>
  </main>

  <footer style="background: #1a237e; color: white; text-align: center; padding: 20px; margin-top: 40px;">
    <p>© 2026 — Demo Critical CSS</p>
  </footer>

  <script>
    console.log('Non-critical CSS dimuat secara asinkron. Halaman sudah render!');
  </script>
</body>
</html>
```

## Poin Penting
- Critical CSS hanya efektif untuk halaman dengan banyak CSS; untuk halaman kecil, inline semua CSS mungkin lebih sederhana.
- Ukuran critical CSS yang di-inline sebaiknya tidak melebihi 14-17 KB agar tidak melebihi ukuran paket TCP awal.
- Ekstraksi critical CSS harus dilakukan untuk setiap halaman atau kelompok halaman yang berbeda karena konten above the fold berbeda-beda.
