# Teknik Code Splitting untuk Memuat Kode Sesuai Kebutuhan

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki ensiklopedia raksasa berisi 100 jilid. Jika setiap pengunjung harus mengunduh seluruh ensiklopedia hanya untuk membaca satu artikel, itu sangat tidak efisien. Code splitting adalah seperti memotong ensiklopedia menjadi jilid-jilid terpisah: pengunjung yang ingin tahu tentang "Sejarah" cukup mengunduh jilid 5 saja, bukan seluruh 100 jilid. Ketika ia kemudian ingin membaca "Teknologi", jilid 8 diunduh secara terpisah. Hasilnya: waktu muat awal menjadi sangat cepat karena hanya kode yang benar-benar dibutuhkan yang dimuat.

## Penjelasan Detail

Code splitting adalah teknik memecah bundle JavaScript menjadi potongan-potongan lebih kecil yang dimuat secara dinamis sesuai kebutuhan. Webpack, Vite, dan Rollup mendukung code splitting melalui dynamic `import()` syntax. Ada tiga pendekatan utama: split berdasarkan entry point (halaman/rute yang berbeda), split berdasarkan komponen (komponen besar yang jarang digunakan), dan split berdasarkan library (pustaka pihak ketiga yang besar dipisah). Manfaat utamanya adalah mengurangi ukuran bundle awal, mempercepat First Contentful Paint, dan menghemat bandwidth. Namun, code splitting memerlukan strategi yang baik — terlalu banyak split akan menyebabkan overhead HTTP request yang berlebihan.

    var loadedModules = {};

    function muatModul(namaModul) {
      var output = document.getElementById('modul-output');
      var logContainer = document.getElementById('modul-log');

      if (loadedModules[namaModul]) {
        output.textContent = '📂 Modul "' + namaModul + '" sudah dimuat sebelumnya. Menggunakan cache.\nUkuran: ' + loadedModules[namaModul].ukuran + ' KB';
        return;

      var waktu = Math.round(Math.random() * 800 + 200);

      output.textContent = '⏳ Memuat modul "' + namaModul + '"... (' + ukuran + ' KB, estimasi ' + waktu + 'ms)';

        loadedModules[namaModul] = { ukuran: ukuran, waktu: waktu };

        output.textContent = '✅ Modul "' + namaModul + '" berhasil dimuat!\n' +
          'Ukuran: ' + ukuran + ' KB\n' +

          'Total modul dimuat: ' + Object.keys(loadedModules).length + ' modul';

        logEntry.textContent = '✅ Modul "' + namaModul + '" (' + ukuran + ' KB, ' + waktu + 'ms) — lazy loaded';

## Poin Penting
- Gunakan dynamic `import()` untuk code splitting — ini adalah fitur JavaScript yang didukung Webpack, Vite, dan Rollup.
- Pantau ukuran bundle dengan tools seperti `webpack-bundle-analyzer` untuk menentukan titik split yang optimal.
- Code splitting yang terlalu agresif bisa menurunkan performa karena banyak HTTP request kecil; temukan keseimbangan (chunk ideal ~20-50 KB).
