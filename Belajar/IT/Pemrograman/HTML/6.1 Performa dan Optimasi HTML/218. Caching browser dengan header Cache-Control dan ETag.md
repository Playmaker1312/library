# Caching Browser dengan Header Cache-Control dan ETag

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki lemari penyimpanan khusus untuk buku-buku yang sering dipinjam. Ketika seorang anggota meminjam buku "Pengantar JavaScript", pustakawan mencatat tanggal peminjaman dan memberikan salinan. Jika anggota lain meminta buku yang sama dalam waktu singkat, pustakawan cukup memberikan salinan dari lemari tanpa harus mengambil dari rak utama. Cache-Control ibarat instruksi "simpan salinan ini selama 1 jam", sedangkan ETag seperti stempel edisi yang memudahkan pustakawan mengecek apakah salinan di lemari masih sama dengan yang di rak.

## Penjelasan Detail

Caching browser memungkinkan resource web disimpan secara lokal di perangkat pengguna setelah unduhan pertama. Header `Cache-Control` menentukan durasi dan kebijakan cache — misalnya `max-age=31536000` untuk menyimpan file selama satu tahun. `ETag` adalah token unik (biasanya hash konten) yang memungkinkan validasi sisi server: browser mengirim ETag yang dimiliki, server merespons dengan `304 Not Modified` jika konten masih sama, sehingga tidak perlu mengunduh ulang. Kombinasi kedua header ini sangat efektif: `Cache-Control` untuk menghindari permintaan sama sekali, dan `ETag` untuk memvalidasi secara efisien saat cache kedaluwarsa. Untuk file yang sering berubah seperti HTML, gunakan `no-cache` (tetap validasi); untuk aset statis seperti CSS/JS/logo, gunakan `max-age` panjang dengan fingerprinted filename.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Caching Browser</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 800px; margin: 20px auto; padding: 0 20px; background: #fafafa; }
    .cache-card { background: #fff3e0; border: 1px solid #ffe0b2; padding: 20px; border-radius: 8px; margin: 15px 0; }
    .cache-card pre { background: #fff8e1; padding: 10px; border-radius: 4px; }
    .btn-simulasi { background: #ff9800; color: white; border: none; padding: 8px 16px; border-radius: 4px; cursor: pointer; }
    .log-entry { padding: 5px 0; border-bottom: 1px dashed #ddd; font-family: monospace; font-size: 0.9em; }
  </style>
</head>
<body>
  <h1>Simulasi Caching Browser</h1>

  <div class="cache-card">
    <h2>Header yang Dikirim Server</h2>
    <pre>
Cache-Control: public, max-age=3600, immutable
ETag: "abc123-v2"
Last-Modified: Wed, 15 May 2026 10:30:00 GMT</pre>
    <p><strong>Cache-Control:</strong> File bisa disimpan publik (CDN + browser) selama 1 jam, dan tidak perlu dicek ulang (immutable).</p>
    <p><strong>ETag:</strong> "abc123-v2" — browser akan mengirim ini saat validasi.</p>
  </div>

  <div class="cache-card">
    <h2>Log Permintaan</h2>
    <div id="log-container">
      <div class="log-entry">🟢 [Cache HIT] style.css — diambil dari cache lokal</div>
      <div class="log-entry">🟢 [Cache HIT] app.js — diambil dari cache lokal</div>
      <div class="log-entry">🟡 [Validasi] data.json — ETag cocok, server: 304 Not Modified</div>
      <div class="log-entry">🔴 [MISS] index.html — tidak ada cache, unduh 2.4 KB</div>
    </div>
    <button class="btn-simulasi" onclick="simulasiCache()">Simulasi Request Baru</button>
  </div>

  <div class="cache-card">
    <h2>Cache Information</h2>
    <p id="cache-stats">Terakhir dimuat: timestamp akan muncul di sini</p>
    <button class="btn-simulasi" onclick="tampilkanTimestamp()">Muat Ulang Waktu</button>
  </div>

  <script>
    var requestCount = 0;
    var cacheHits = 0;

    function simulasiCache() {
      requestCount++;
      var isHit = Math.random() > 0.3;
      if (isHit) cacheHits++;

      var logContainer = document.getElementById('log-container');
      var now = new Date().toLocaleTimeString();
      var entry = document.createElement('div');
      entry.className = 'log-entry';

      if (isHit) {
        entry.innerHTML = '🟢 [' + now + '] [HIT] File diambil dari cache lokal';
      } else {
        entry.innerHTML = '🟡 [' + now + '] [MISS] File tidak ada di cache, mengunduh dari server';
      }

      logContainer.insertBefore(entry, logContainer.firstChild);

      if (logContainer.children.length > 10) {
        logContainer.removeChild(logContainer.lastChild);
      }

      var hitRate = Math.round((cacheHits / requestCount) * 100);
      document.getElementById('cache-stats').innerHTML =
        'Request: ' + requestCount + ' | Cache HIT: ' + cacheHits +
        ' | Hit Rate: ' + hitRate + '%' +
        ' | Waktu dihemat: ~' + (cacheHits * 200) + 'ms';
    }

    function tampilkanTimestamp() {
      document.getElementById('cache-stats').innerHTML =
        '🕐 Timestamp saat ini: ' + new Date().toISOString() +
        ' | Cache-Control max-age=3600 (kedaluwarsa: ' +
        new Date(Date.now() + 3600000).toLocaleTimeString() + ')';
    }
  </script>
</body>
</html>
```

## Poin Penting
- Gunakan `Cache-Control: immutable` untuk aset versioned/assets fingerprint agar browser tidak perlu mengecek ulang ke server.
- Kombinasi `ETag` + `Cache-Control: no-cache` memberi keseimbangan antara selalu segar dan efisien untuk konten dinamis.
- Hati-hati dengan `max-age` yang terlalu panjang — jika file diubah, pastikan nama file juga berubah (cache busting).
