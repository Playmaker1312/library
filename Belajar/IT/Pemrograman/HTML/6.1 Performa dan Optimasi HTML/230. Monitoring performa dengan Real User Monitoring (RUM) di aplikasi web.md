# Monitoring Performa dengan Real User Monitoring (RUM) di Aplikasi Web

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki sistem yang merekam setiap interaksi pengunjung secara anonim: berapa lama mereka mencari buku, halaman mana yang sering dikunjungi, di mana mereka mengalami keterlambatan, dan perangkat apa yang mereka gunakan. Ini adalah Real User Monitoring (RUM) — mengamati pengalaman nyata pengunjung, bukan simulasi laboratorium. Berbeda dengan Lighthouse yang seperti "inspektur yang datang pada hari Minggu siang", RUM seperti "CCTV yang merekam 24 jam" — memberikan data dari ribuan pengunjung sesungguhnya dengan berbagai perangkat, koneksi, dan lokasi.

## Penjelasan Detail

Real User Monitoring (RUM) mengumpulkan data performa dari pengguna nyata saat mereka berinteraksi dengan aplikasi web. Berbeda dengan synthetic monitoring (seperti Lighthouse) yang menggunakan lingkungan terkontrol, RUM menangkap variasi dunia nyata: perangkat berbeda, kondisi jaringan berbeda, lokasi geografis berbeda. Data RUM dikumpulkan menggunakan Performance API browser (`performance.getEntriesByType('paint')`, `PerformanceObserver`, web-vitals library) dan dikirim ke layanan analitik seperti Google Analytics, Datadog RUM, New Relic, atau open-source tool seperti Plausible. Metrik yang dilacak meliputi Core Web Vitals (LCP, FID/INP, CLS), TTFB, FCP, dan error rate. RUM sangat penting untuk mengidentifikasi regresi performa, memahami dampak perubahan kode pada pengguna nyata, dan menetapkan budget performa.

    function kirimDataRUM() {
      var log = document.getElementById('rum-log');
      var metrics = [
        'LCP: ' + (Math.random() * 2 + 1).toFixed(2) + 's',
        'FID: ' + Math.round(Math.random() * 80 + 10) + 'ms',
        'CLS: ' + (Math.random() * 0.1).toFixed(3),
        'TTFB: ' + Math.round(Math.random() * 300 + 100) + 'ms',
        'FCP: ' + (Math.random() * 1.5 + 0.5).toFixed(2) + 's'
      ];

      var entry = document.createElement('div');
      entry.innerHTML = '&gt; 📤 [' + new Date().toLocaleTimeString() + '] ' +
        'Navigasi: ' + (performance.navigation.type === 1 ? 'Reload' : 'Navigasi baru') +
        '<br>&gt; &nbsp;&nbsp; Metrik: ' + metrics.join(' | ');

      log.insertBefore(entry, log.firstChild);
      if (log.children.length > 8) {
        log.removeChild(log.lastChild);
      }
    }

    function simulasiError() {
      var log = document.getElementById('rum-log');
      var errors = [
        'TypeError: Cannot read property "data" of undefined',
        'SyntaxError: Unexpected token < in JSON at position 0',
        'ReferenceError: gtag is not defined',
        'Error: NetworkError when fetching resource'
      ];

      var randomError = errors[Math.floor(Math.random() * errors.length)];
      var entry = document.createElement('div');
      entry.innerHTML = '&gt; 💥 [' + new Date().toLocaleTimeString() + '] ERROR: ' + randomError;

      log.insertBefore(entry, log.firstChild);
      if (log.children.length > 8) {
        log.removeChild(log.lastChild);
      }
    }

    // Kirim data RUM otomatis saat halaman dimuat
    window.addEventListener('load', function () {
      setTimeout(kirimDataRUM, 2000);
    });

## Poin Penting
- Gunakan web-vitals library untuk mengukur Core Web Vitals secara akurat — library ini menangani edge case dan perbedaan implementasi browser.
- Kirim data RUM menggunakan `navigator.sendBeacon()` agar data tetap terkirim meskipun pengguna meninggalkan halaman (page unload).
- Fokus pada data persentil (p75) daripada rata-rata, karena rata-rata bisa menyesatkan akibat outlier.
