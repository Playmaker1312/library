# Minifikasi HTML, CSS, dan JavaScript untuk Mengurangi Ukuran File

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan digital yang menyimpan jutaan buku. Setiap buku ditulis dengan spasi ganda, margin lebar, dan banyak halaman kosong yang tidak perlu. Akibatnya, rak buku cepat penuh dan pengunjung harus menunggu lama saat meminjam buku. Dengan minifikasi, kita menghapus semua spasi berlebih, komentar, dan pemformatan yang tidak diperlukan — seperti mencetak ulang buku dengan font rapat tanpa margin — sehingga ukurannya menyusut drastis dan proses peminjaman menjadi lebih cepat.

## Penjelasan Detail

Minifikasi adalah proses menghilangkan karakter yang tidak diperlukan dari kode sumber tanpa mengubah fungsionalitasnya. Karakter yang dihapus meliputi spasi putih, baris baru, komentar, dan delimiter opsional. Untuk CSS dan JavaScript, minifikasi juga dapat memperpendek nama variabel lokal. Proses ini biasanya dilakukan sebagai bagian dari build pipeline menggunakan tools seperti Terser (JS), cssnano (CSS), dan html-minifier (HTML). Hasil minifikasi dapat mengurangi ukuran file hingga 30-70%, yang secara langsung mempercepat waktu loading halaman. File yang lebih kecil berarti lebih sedikit data yang ditransfer melalui jaringan, sehingga halaman web terasa lebih responsif terutama pada koneksi lambat.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Minifikasi HTML, CSS, JS</title>
  <style>
    /* CSS sebelum minifikasi */
    body {
      font-family: Arial, sans-serif;
      padding: 20px;
      background-color: #f4f4f4;
    }
    .card {
      border: 1px solid #ccc;
      padding: 15px;
      margin: 10px 0;
    }
    .btn {
      background: #0066cc;
      color: white;
      padding: 8px 16px;
      border: none;
      cursor: pointer;
    }
  </style>
</head>
<body>
  <h1>Demo Minifikasi</h1>
  <div class="card">
    <p>File ini menunjukkan kode yang BELUM terminifikasi.</p>
    <p>Dalam praktik nyata, tools build seperti Webpack akan:
      <br>- Menghapus spasi dan komentar
      <br>- Memperpendek nama variabel JS lokal
      <br>- Menggabungkan file
    </p>
    <button class="btn" onclick="hitungTotal()">Klik Saya</button>
    <p id="hasil"></p>
  </div>

  <h2>Ukuran File</h2>
  <div id="info-ukuran"></div>

  <script>
    // Fungsi sebelum minifikasi
    function hitungTotal() {
      var hargaBarang = 25000;
      var jumlahBarang = 3;
      var totalHarga = hargaBarang * jumlahBarang;
      var pajak = totalHarga * 0.11;
      var grandTotal = totalHarga + pajak;

      document.getElementById('hasil').innerHTML =
        'Total: Rp ' + grandTotal.toLocaleString('id-ID');
    }

    document.addEventListener('DOMContentLoaded', function () {
      var styleSize = document.querySelector('style').innerHTML.length;
      var scriptSize = document.querySelector('script').innerHTML.length;

      document.getElementById('info-ukuran').innerHTML =
        'Ukuran CSS: ' + styleSize + ' byte | ' +
        'Ukuran JS: ' + scriptSize + ' byte | ' +
        '<br>Setelah minifikasi: ~' +
        Math.round((styleSize + scriptSize) * 0.4) + ' byte (estimasi 60% lebih kecil)';
    });
  </script>
</body>
</html>
```

## Poin Penting
- Minifikasi hanya boleh dilakukan pada production, bukan saat development, karena kode terminifikasi sulit dibaca dan di-debug.
- Source map (.map) harus disediakan agar kode terminifikasi tetap bisa di-debug di browser.
- Beberapa tools minifikasi juga melakukan optimasi tambahan seperti tree-shaking dan dead code elimination.
