# Content Delivery Network (CDN) untuk Distribusi Konten Global

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan digital yang hanya memiliki satu gedung pusat di Jakarta. Anggota di Aceh harus menunggu 3 hari untuk meminjam buku. Dengan CDN, perpustakaan mendirikan cabang-cabang kecil di setiap provinsi — Miryang, Surabaya, Makassar, dan Jayapura — yang menyimpan salinan buku-buku populer. Ketika anggota di Aceh meminjam buku, salinannya dikirim dari cabang terdekat, bukan dari Jakarta. Waktu pengiriman turun dari 3 hari menjadi 3 jam. Inilah cara kerja CDN: mendekatkan konten ke pengguna.

## Penjelasan Detail

CDN adalah jaringan server yang tersebar secara geografis yang menyimpan salinan statis dari konten web. Ketika pengguna mengakses situs, DNS mengarahkan mereka ke server CDN terdekat. CDN mengurangi latency karena data menempuh jarak yang lebih pendek, mengurangi beban server asal karena permintaan dilayani oleh edge server, dan meningkatkan skalabilitas karena CDN menangani lonjakan traffic. Sebagian besar CDN juga menawarkan fitur keamanan seperti mitigasi DDoS dan Web Application Firewall. Layanan CDN populer termasuk Cloudflare, Fastly, Amazon CloudFront, dan Akamai. Meskipun CDN terutama untuk aset statis, beberapa juga mendukung komputasi edge untuk logika dinamis.

## Poin Penting
- CDN sangat efektif untuk aset statis (CSS, JS, gambar, font) tetapi tidak cocok untuk konten personal/dinamis tanpa konfigurasi khusus.
- Pilih CDN dengan titik kehadiran (PoP) yang banyak di wilayah target pengguna untuk latency minimal.
- Gunakan fitur `integrity` (SRI) saat memuat library dari CDN publik untuk memastikan file tidak dimodifikasi.
