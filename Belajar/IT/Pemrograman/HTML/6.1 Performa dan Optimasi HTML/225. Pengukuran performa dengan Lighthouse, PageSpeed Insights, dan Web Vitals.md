# Pengukuran Performa dengan Lighthouse, PageSpeed Insights, dan Web Vitals

## Analogi: Perpustakaan Digital

Perpustakaan digital perlu memastikan pengunjungnya puas. Untuk itu, mereka memasang alat ukur di setiap sudut: sensor kecepatan di pintu masuk (First Contentful Paint), stopwatch untuk waktu pencarian buku (Time to Interactive), dan pengukur kepuasan di meja baca (Cumulative Layout Shift). Lighthouse adalah auditor internal yang memberikan laporan lengkap dengan skor dan rekomendasi. PageSpeed Insights adalah konsultan eksternal yang mengevaluasi dari berbagai lokasi. Web Vitals adalah tiga metrik utama yang menjadi standar industri untuk mengukur pengalaman pengguna secara nyata.

## Penjelasan Detail

Lighthouse adalah alat audit otomatis built-in di Chrome DevTools yang mengukur performa, aksesibilitas, SEO, best practices, dan PWA. Ia menghasilkan skor 0-100 untuk setiap kategori dan memberikan rekomendasi perbaikan spesifik. PageSpeed Insights menggunakan Lighthouse tetapi dari server Google dengan simulasi koneksi 4G, memberikan data lapangan (field data) dari CrUX (Chrome User Experience Report) jika tersedia. Web Vitals adalah inisiatif Google yang mendefinisikan tiga metrik inti: LCP (Largest Contentful Paint) — waktu render konten terbesar, FID (First Input Delay) — responsivitas interaksi, dan CLS (Cumulative Layout Shift) — stabilitas visual. INP (Interaction to Next Paint) akan menggantikan FID pada Maret 2024. Ketiga alat ini saling melengkapi: Lighthouse untuk debugging, PageSpeed Insights untuk data global, Web Vitals untuk monitoring berkelanjutan.

## Poin Penting
- Fokus pada Core Web Vitals (LCP, FID/INP, CLS) karena metrik ini secara langsung memengaruhi peringkat pencarian Google (SEO).
- Gunakan data lapangan (field data) dari CrUX jika tersedia, karena data lab (Lighthouse) tidak selalu merepresentasikan pengalaman pengguna nyata.
- Integrasikan web-vitals library untuk memantau metrik nyata dari pengguna dan kirimkan ke analitik untuk monitoring berkelanjutan.
