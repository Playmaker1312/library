🏰 Tag meter dan progress HTML5

Apa Itu <meter> dan <progress>?

<meter> dan <progress> adalah elemen semantik HTML5 untuk menampilkan data numerik secara visual dalam bentuk batang.

  • <meter> — Menampilkan nilai dalam rentang yang diketahui (misalnya level keahlian 80 dari 100).
  • <progress> — Menampilkan kemajuan tugas yang belum selesai (misalnya upload file 45%).

Fungsi dan Atribut

<meter>

  • value — Nilai saat ini (wajib).
  • min — Nilai minimum (default 0).
  • max — Nilai maksimum (default 1).
  • low — Ambang batas bawah.
  • high — Ambang batas atas.
  • optimum — Nilai optimal.

Warna batang berubah berdasarkan posisi nilai: merah (di bawah low), kuning (antara low dan high), hijau (di sekitar optimum).

<progress>

  • value — Kemajuan saat ini.
  • max — Nilai maksimum (total pekerjaan).

Jika atribut value tidak disertakan, progress menampilkan animasi indeterminate (sedang berlangsung tanpa status pasti).

Cara Pengimplementasian

<!-- Meter untuk level keahlian -->
<label>Skill HTML:</label>
<meter value="80" min="0" max="100" low="30" high="70" optimum="90">80/100</meter>

<!-- Progress untuk loading -->
<label>Mengunduh file...</label>
<progress value="45" max="100">45%</progress>

<!-- Progress indeterminate (tanpa value) -->
<label>Memproses...</label>
<progress></progress>

Contoh Demo:

Skill HTML:

80/100

Nilai: 80/100 (Low: 30, High: 70, Optimum: 90) — Hijau karena mendekati optimum.

Skill CSS:

20/100

Nilai: 20/100 — Merah karena di bawah low.

Loading File:

45%

45% selesai.

Memproses (indeterminate):

Animasi berputar tanpa nilai pasti.

Analogi Rumah / Bangunan

<meter> seperti meteran listrik di rumah—menunjukkan pemakaian saat ini dalam rentang yang diketahui (0 - 1300 Watt). Ada zona aman (hijau), waspada (kuning), dan bahaya (merah).

<progress> seperti proses pembangunan rumah—pondasi 20%, tembok 50%, atap 80%. Kita tahu sudah sejauh mana, tapi belum selesai.

Progress indeterminate seperti tukang yang sedang bekerja—Anda tahu ada aktivitas, tapi belum bisa diukur persentasenya.

Dipakai Untuk

  • <meter> — Menampilkan level keahlian, kapasitas penyimpanan, suhu, nilai ujian, atau sensor.
  • <progress> — Indikator upload/download, pengisian formulir multi-step, instalasi aplikasi, loading screen.

Kesalahan Umum

  • ✖ Menggunakan <progress> untuk nilai statis yang sudah final (harusnya <meter>).
  • ✖ Lupa memberikan teks di antara tag (misal <meter>80/100</meter>) untuk fallback jika browser tidak mendukung.
  • ✖& #x2716; Menukar min/max antara meter dan progress. Progress tidak punya min (selalu 0).
  • ✖ Tidak menggunakan atribut low/high/optimum pada meter, sehingga warna tidak berfungsi optimal.

Koneksi dengan Materi Sebelumnya

<meter> dan <progress> melengkapi elemen semantik HTML5 lainnya seperti <details>, <summary>, dan <figure>. Mereka juga sering dikombinasikan dengan JavaScript untuk memperbarui nilai secara real-time, misalnya progress bar upload file.

Soal Latihan

Soal 1: Indikator Baterai

Buatlah elemen <meter> yang menampilkan level baterai 65% dengan ambang low di 20%, high di 80%, dan optimum di 100%.

📝 Jawaban 
<meter value="65" min="0" max="100" low="20" high="80" optimum="100">65%</meter>
Soal 2: Download File

Buatlah elemen <progress> yang menunjukkan file 120MB telah terunduh 72MB (dengan asumsi maks 120MB).

📝 Jawaban 
<progress value="72" max="120">72 dari 120 MB</progress>
