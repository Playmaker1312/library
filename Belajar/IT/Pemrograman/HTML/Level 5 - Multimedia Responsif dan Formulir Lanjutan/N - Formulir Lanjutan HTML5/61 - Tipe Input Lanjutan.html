🏰 Tipe Input Lanjutan HTML5

Apa Itu Tipe Input Lanjutan?

HTML5 memperkenalkan beberapa <input> baru yang memudahkan pengguna memasukkan data spesifik tanpa perlu JavaScript tambahan. Tipe-tipe ini menyediakan kontrol bawaan di browser seperti slider, color picker, dan search field.

Fungsi Masing-Masing Tipe

  • type="range" — Menampilkan slider geser untuk memilih angka dalam rentang tertentu.
  • type="color" — Membuka color picker untuk memilih warna.
  • type="search" — Field pencarian dengan tombol reset otomatis.
  • <datalist> — Menyediakan daftar saran otomatis saat mengetik.

Cara Pengimplementasian

<!-- Range Slider -->
<label for="rating">Rating:</label>
<input type="range" id="rating" min="1" max="10" value="5">
<output id="ratingOutput">5</output>

<!-- Color Picker -->
<label for="warna">Pilih Warna:</label>
<input type="color" id="warna" value="#3498db">

<!-- Search Field -->
<label for="cari">Cari:</label>
<input type="search" id="cari" placeholder="Ketik kata kunci...">

<!-- Datalist -->
<label for="buah">Buah:</label>
<input list="daftarBuah" id="buah" placeholder="Mulai mengetik...">
<datalist id="daftarBuah">
    <option value="Apel">
    <option value="Jeruk">
    <option value="Mangga">
    <option value="Pisang">
</datalist>

Analogi Rumah / Bangunan

Range seperti keran air yang bisa diputar ke kiri-kanan untuk mengatur besar kecilnya aliran air.

Color seperti toko cat tempat Anda memilih warna dari ribuan pilihan dengan sekali klik.

Search seperti papan pengumuman dengan tombol × untuk menghapus semua tulisan.

Datalist seperti arsip denah rumah—saat Anda mulai mengetik, arsip memberikan saran denah yang cocok.

Dipakai Untuk

  • Range: Rating produk, pengaturan volume, filter harga.
  • Color: Pemilih tema warna, editor grafis, kustomisasi tampilan.
  • Search: Kotak pencarian di website, filter data.
  • Datalist: Input kota, nama barang, atau data dengan opsi yang sudah ditentukan.

Kesalahan Umum

  • ✖ Lupa menambahkan atribut list pada input untuk menghubungkan ke <datalist>.
  • ✖ Tidak menyertakan min dan max pada range, sehingga default 0-100.
  • ✖ Tidak menggunakan tag <output> untuk menampilkan nilai range secara real-time.
  • ✖ Mengira <datalist> membatasi pilihan (fungsinya hanya saran, bukan pembatasan).

Koneksi dengan Materi Sebelumnya

Tipe input lanjutan ini adalah pengembangan dari tipe input dasar (text, number, password). Dikombinasikan dengan atribut form seperti required, placeholder, dan pattern, formulir menjadi lebih interaktif dan mudah digunakan.

Soal Latihan

Soal 1: Rating Film

Buatlah sebuah slider (type="range") dengan nilai minimal 0, maksimal 10, dan nilai awal 7. Tampilkan nilainya secara real-time menggunakan <output>.

📝 Jawaban 
<input type="range" min="0" max="10" value="7" oninput="out.value=this.value">
<output id="out">7</output>
Soal 2: Pencarian Kota

Buatlah input pencarian (type="search") yang dilengkapi <datalist> berisi tiga kota di Indonesia (Jakarta, Surabaya, Bandung).

📝 Jawaban 
<input type="search" list="kota" placeholder="Cari kota...">
<datalist id="kota">
    <option value="Jakarta">
    <option value="Surabaya">
    <option value="Bandung">
</datalist>
