Web Storage API — localStorage

Penjelasan

localStorage adalah properti dari Web Storage API yang memungkinkan kita menyimpan data di browser secara permanen — data tidak hilang meskipun browser ditutup dan dibuka kembali. Data disimpan dalam bentuk string key-value.

Kapasitas penyimpanan sekitar 5–10 MB per domain.

Fungsi

  • setItem(key, value) — menyimpan pasangan key-value
  • getItem(key) — mengambil value berdasarkan key
  • removeItem(key) — menghapus satu item
  • clear() — menghapus semua data localStorage

Cara Pengimplementasian

// Menyimpan data
localStorage.setItem('nama', 'Andi');

// Membaca data
const nama = localStorage.getItem('nama');
console.log(nama); // "Andi"

// Menghapus satu item
localStorage.removeItem('nama');

// Menyimpan objek (pakai JSON)
const user = { id: 1, nama: 'Budi' };
localStorage.setItem('user', JSON.stringify(user));

// Membaca objek
const userSimpan = JSON.parse(localStorage.getItem('user'));
console.log(userSimpan.nama); // "Budi"

// Menghapus semua
localStorage.clear();

Analogi — Lemari Penyimpanan Rumah

localStorage seperti lemari besi di dalam rumah. Barang yang kamu simpan di lemari besi akan tetap ada meskipun kamu pergi keluar rumah, tidur, atau bahkan bepergian berhari-hari. Begitu kamu kembali, barang itu masih ada di sana.

  • setItem = memasukkan barang ke dalam lemari dan memberinya label (key).
  • getItem = membuka lemari dan mengambil barang berdasarkan label.
  • removeItem = membuang satu barang tertentu dari lemari.
  • clear = mengosongkan seluruh isi lemari.
  • Hanya bisa menyimpan kertas (string). Kalau mau menyimpan benda kompleks (objek), kamu harus menuliskan deskripsinya di kertas lewat JSON.stringify, lalu membacanya kembali dengan JSON.parse.

Dipake Untuk

  • Menyimpan progress formulir multi-step agar tidak hilang saat refresh
  • Menyimpan preferensi tema terang/gelap
  • Menyimpan data keranjang belanja sederhana
  • Menyimpan token autentikasi (dengan hati-hati)
  • Cache data API ringan agar tidak fetch ulang

Kesalahan Umum

  • Lupa JSON.stringify/parse — menyimpan objek langsung menghasilkan "[object Object]". Selalu gunakan JSON.stringify saat menyimpan dan JSON.parse saat membaca.
  • Mengira data lintas domain — localStorage terikat pada domain, protokol, dan port. Data domain A tidak bisa diakses dari domain B.
  • Tidak ngecek null — getItem mengembalikan null jika key tidak ada. Akses properti dari null akan error.
  • Menyimpan data sensitif — localStorage tidak aman; jangan simpan password atau token rahasia di sini.
  • Kelebihan kuota — melebihi kapasitas akan throw exception QuotaExceededError.

Koneksi dengan Materi Sebelumnya

sessionStorage — saudara localStorage. Bedanya: sessionStorage hanya bertahan selama satu tab/sesi browser. Kalau tab ditutup, datanya hilang. localStorage bertahan selamanya sampai dihapus manual.

Form & Event — localStorage sering dikombinasikan dengan event input, change, atau submit untuk auto-save data formulir.

JSON — materi sebelumnya tentang JSON penting karena localStorage hanya menyimpan string. Objek harus diubah ke JSON dulu.

Soal Latihan

1. Buat kode untuk menyimpan objek { nama: "Sinta", umur: 22 } ke localStorage, lalu baca dan tampilkan nama di console.

Lihat Jawaban 
const data = { nama: "Sinta", umur: 22 };
localStorage.setItem('profil', JSON.stringify(data));

const ambil = JSON.parse(localStorage.getItem('profil'));
console.log(ambil.nama); // "Sinta"

2. Apa yang terjadi jika kamu menjalankan localStorage.getItem('keyTidakAda')? Bagaimana cara aman mengaksesnya?

Lihat Jawaban

Mengembalikan null. Cara aman:

const value = localStorage.getItem('keyTidakAda');
if (value !== null) {
    console.log(value);
} else {
    console.log('Key tidak ditemukan');
}

3. Sebutkan 3 perbedaan utama antara localStorage dan sessionStorage.

Lihat Jawaban
  1. Durasi: localStorage permanen sampai dihapus, sessionStorage hilang saat tab ditutup.
  2. Cakupan: localStorage dibagi antar tab domain sama, sessionStorage terisolasi per tab.
  3. Penggunaan umum: localStorage untuk preferensi jangka panjang, sessionStorage untuk data sementara seperti input form sekali pakai.
