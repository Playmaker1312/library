<template> — Tag Template HTML

Penjelasan

Elemen <template> adalah elemen HTML yang menyimpan konten tidak dirender di halaman. Konten di dalamnya tidak tampak dan tidak di-download (gambar, video, dsb) sampai diaktifkan dengan JavaScript. Template berfungsi sebagai stempel atau cetakan yang bisa digandakan kapan saja.

Konten template diakses lewat properti content (berupa DocumentFragment).

Fungsi

  • Menyimpan markup yang akan digunakan kembali (reusable)
  • Mengurangi duplikasi kode HTML
  • Mempermudah pembuatan komponen dinamis dengan JavaScript
  • Konten di dalamnya inert — tidak berpengaruh pada halaman sampai di-clone

Cara Pengimplementasian

<!-- Definisikan template -->
<template id="kartu-proyek">
  <div class="card">
    <h3 class="judul"></h3>
    <p class="deskripsi"></p>
    <span class="status"></span>
  </div>
</template>

<div id="daftar-proyek"></div>

<script>
  const template = document.getElementById('kartu-proyek');
  const daftar = document.getElementById('daftar-proyek');

  const proyek = [
    { judul: 'Aplikasi Absen', deskripsi: 'Sistem absensi RFID', status: 'Selesai' },
    { judul: 'Website Sekolah', deskripsi: 'Profil dan PPDB online', status: 'Progres' }
  ];

  proyek.forEach(item => {
    const clone = template.content.cloneNode(true);
    clone.querySelector('.judul').textContent = item.judul;
    clone.querySelector('.deskripsi').textContent = item.deskripsi;
    clone.querySelector('.status').textContent = item.status;
    daftar.appendChild(clone);
  });
</script>

Analogi — Cetakan Bangunan

<template> seperti cetakan (moulding) beton di proyek konstruksi. Cetakan itu sendiri bukan bangunan — cetakan disimpan di gudang dan tidak dipajang. Tapi ketika kamu butuh membuat tiang atau balok, kamu tuang adonan ke cetakan itu dan klon strukturnya berkali-kali.

  • <template> = cetakan besi di gudang (tidak terlihat di bangunan final).
  • content = bentuk/cetakan itu sendiri.
  • cloneNode(true) = menuang beton ke cetakan — menghasilkan salinan persis.
  • Setiap salinan bisa diberi warna/isi berbeda (mengisi textContent), seperti mengecat tiang beton dengan warna berbeda.
  • Tanpa template, kamu harus menulis ulang struktur rumah berkali-kali — boros dan rawan error.

Dipake Untuk

  • Membuat kartu proyek yang diulang (portofolio, daftar produk)
  • Membuat daftar item dari data API (user list, tabel dinamis)
  • Membuat elemen list yang seragam (to-do item, komentar)
  • Mengganti innerHTML yang rentan XSS — template lebih aman
  • Component pattern sederhana tanpa framework

Kesalahan Umum

  • Lupa cloneNode(true) — mengambil template.content langsung dan dipakai berulang. DocumentFragment hanya bisa dipasang sekali. Gunakan cloneNode(true) setiap kali.
  • Menyisipkan konten sebelum clone — mengisi data di dalam template asli akan memengaruhi semua clone. Isi data setelah clone dibuat.
  • Menganggap template seperti <div hidden> — bedanya: konten template inert (gambar tidak di-download, script tidak jalan), sedangkan <div hidden> tetap di-download tapi disembunyikan.
  • Lupa parameter true — cloneNode() tanpa true hanya menyalin elemen kosong tanpa anak-anaknya.

Koneksi dengan Materi Sebelumnya

DOM Manipulation — cloneNode, querySelector, dan appendChild adalah fondasi yang sudah dipelajari di bab DOM sebelumnya.

Event Handling — setelah clone ditambahkan ke DOM, kamu bisa pasang event listener seperti biasa.

Array & Looping — template sangat berguna saat di-loop dengan forEach atau map untuk menghasilkan banyak elemen dari data array.

Web Component — <template> adalah fondasi dari Custom Elements dan Shadow DOM pada materi Web Component nanti.

Soal Latihan

1. Buat template untuk item to-do (<li> berisi checkbox dan teks), lalu gunakan JavaScript untuk menambahkan 3 item: "Belajar HTML", "Belajar CSS", "Belajar JS".

Lihat Jawaban 
<template id="todo-item">
  <li>
    <input type="checkbox">
    <span class="teks"></span>
  </li>
</template>

<ul id="todo-list"></ul>

<script>
  const tmpl = document.getElementById('todo-item');
  const list = document.getElementById('todo-list');
  const tugas = ['Belajar HTML', 'Belajar CSS', 'Belajar JS'];

  tugas.forEach(t => {
    const clone = tmpl.content.cloneNode(true);
    clone.querySelector('.teks').textContent = t;
    list.appendChild(clone);
  });
</script>

2. Kenapa kita harus pakai cloneNode(true) dan bukan langsung template.content berulang kali? Jelaskan.

Lihat Jawaban

template.content mengembalikan satu DocumentFragment yang sama. Setelah fragment itu dipasang ke DOM sekali, fragment menjadi kosong. Jadi pemanggilan kedua akan menghasilkan fragment kosong. cloneNode(true) membuat salinan baru setiap kali sehingga template asli tidak habis dipakai.

3. Buat template kartu produk (gambar, nama, harga) dan clone 2 produk dari array data. (cukup tulis struktur template + script-nya)

Lihat Jawaban 
<template id="kartu-produk">
  <div class="produk">
    <img class="gambar" src="" alt="">
    <h4 class="nama"></h4>
    <p class="harga"></p>
  </div>
</template>

<div id="catalog"></div>

<script>
  const tmpl = document.getElementById('kartu-produk');
  const catalog = document.getElementById('catalog');
  const produk = [
    { nama: 'Mouse', harga: 150000, gambar: 'mouse.jpg' },
    { nama: 'Keyboard', harga: 250000, gambar: 'keyboard.jpg' }
  ];

  produk.forEach(p => {
    const clone = tmpl.content.cloneNode(true);
    clone.querySelector('.gambar').src = p.gambar;
    clone.querySelector('.nama').textContent = p.nama;
    clone.querySelector('.harga').textContent = 'Rp ' + p.harga;
    catalog.appendChild(clone);
  });
</script>
