# Kecepatan Loading Halaman dan Teknik Optimasi HTML seperti Minifikasi

## Analogi: Perpustakaan Digital

Minifikasi HTML adalah seperti mencetak buku dengan font lebih kecil, margin minimal, dan tanpa halaman judul -- informasi yang sama, tetapi ukurannya jauh lebih kecil sehingga buku siap dibaca lebih cepat.

## Penjelasan Detail

Teknik optimasi meliputi: minifikasi HTML (hapus spasi/komentar), kompresi Gzip/Brotli, lazy loading (`loading="lazy"`), cache browser, dan CDN. Google mengukur dengan Core Web Vitals: LCP (Largest Contentful Paint), FID (First Input Delay), CLS (Cumulative Layout Shift).

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Blog Cepat - Optimasi Kecepatan</title>
    <style>body{font-family:Arial,sans-serif;margin:0;padding:20px;background:#fff;color:#333}</style>
</head>
<body>
    <h1>Halaman dengan Loading Cepat</h1>
    <p>Halaman ini telah dioptimalkan dengan HTML terminifikasi.</p>
    <img src="foto.webp" alt="Contoh gambar" width="800" height="600" loading="lazy">
    <script defer src="analytics.js"></script>
</body>
</html>
```

## Poin Penting
- Minifikasi HTML adalah langkah paling sederhana namun efektif untuk mengurangi ukuran file
- Gunakan `loading="lazy"` pada gambar di bawah fold untuk menunda pemuatan
- Core Web Vitals (LCP, FID, CLS) adalah metrik utama yang memengaruhi peringkat pencarian
