# Structured Data Menggunakan JSON-LD dan Schema.org dalam HTML

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan digital di mana setiap buku memiliki kartu katalog terstruktur. Schema.org menyediakan kosakata standar untuk kartu katalog tersebut, sementara JSON-LD adalah format penulisannya. Dengan data terstruktur, mesin pencari tidak hanya membaca konten -- mereka memahami maknanya.

## Penjelasan Detail

JSON-LD ditulis dalam blok `<script type="application/ld+json">`. Schema.org menyediakan tipe seperti `Article`, `Product`, `Recipe`, `LocalBusiness`, `Event`, `FAQPage`. Google menggunakan data ini untuk rich results seperti bintang rating, harga, resep, dan FAQ di SERP.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Resep Nasi Goreng Kampung</title>
    <script type="application/ld+json">
    {
        "@context": "https://schema.org",
        "@type": "Recipe",
        "name": "Nasi Goreng Kampung",
        "author": {"@type": "Person", "name": "Chef Andi"},
        "datePublished": "2026-05-23",
        "description": "Resep nasi goreng kampung sederhana.",
        "prepTime": "PT10M",
        "cookTime": "PT15M",
        "recipeYield": "2 porsi",
        "recipeIngredient": ["2 piring nasi", "3 siung bawang merah", "2 siung bawang putih", "1 butir telur", "2 sdm kecap manis"],
        "recipeInstructions": [
            {"@type": "HowToStep", "text": "Haluskan bawang merah dan bawang putih."},
            {"@type": "HowToStep", "text": "Tumis bumbu halus hingga harum."},
            {"@type": "HowToStep", "text": "Masukkan nasi dan kecap, aduk rata."}
        ]
    }
    </script>
</head>
<body>
    <h1>Resep Nasi Goreng Kampung</h1>
    <p>Resep tradisional yang mudah dibuat di rumah.</p>
</body>
</html>
```

## Poin Penting
- JSON-LD adalah format yang direkomendasikan Google
- Validasi dengan Google Rich Results Test sebelum publikasi
- Satu halaman dapat memiliki beberapa blok JSON-LD
