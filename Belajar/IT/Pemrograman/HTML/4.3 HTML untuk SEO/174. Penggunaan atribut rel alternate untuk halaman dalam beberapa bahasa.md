# Penggunaan Atribut Rel Alternate untuk Halaman dalam Beberapa Bahasa

## Analogi: Perpustakaan Digital

Atribut `rel="alternate"` adalah papan petunjuk di setiap rak yang memberitahu pembaca versi bahasa lain dari buku yang sama. `hreflang` adalah label bahasa pada setiap tautan sehingga mesin pencari menyajikan versi yang tepat.

## Penjelasan Detail

Atribut `rel="alternate"` dengan `hreflang` menandai hubungan antar halaman versi bahasa. Sintaks: `<link rel="alternate" hreflang="kode" href="URL">`. Nilai `hreflang` menggunakan BCP 47. Tag harus bersifat resiprokal.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Tentang Kami</title>
    <link rel="alternate" hreflang="id" href="https://contoh.com/id/tentang">
    <link rel="alternate" hreflang="en" href="https://contoh.com/en/about">
    <link rel="alternate" hreflang="x-default" href="https://contoh.com/en/about">
</head>
<body>
    <h1>Tentang Perusahaan Kami</h1>
    <p>Kami adalah perusahaan global dengan kantor di berbagai negara.</p>
</body>
</html>
```

## Poin Penting
- Pastikan tautan `hreflang` bersifat resiprokal -- setiap halaman menunjuk ke semua versi bahasa
- Gunakan `x-default` sebagai fallback untuk pengguna yang bahasanya tidak tercakup
- Kode bahasa harus valid sesuai standar BCP 47
