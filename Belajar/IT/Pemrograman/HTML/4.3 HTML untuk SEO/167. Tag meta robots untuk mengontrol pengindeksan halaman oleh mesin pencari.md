# Tag Meta Robots untuk Mengontrol Pengindeksan Halaman oleh Mesin Pencari

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan digital dengan rak buku yang tak terbatas. Meta robots adalah stiker instruksi yang ditempel pustakawan pada setiap buku: "boleh dipinjamkan ke pengunjung" (index) atau "jangan ditampilkan di etalase" (noindex), "ikuti tautan di dalamnya" (follow) atau "abaikan tautannya" (nofollow). Tanpa stiker ini, pustakawan akan memperlakukan semua buku secara seragam.

## Penjelasan Detail

Tag meta robots ditempatkan di elemen `<head>` dan menggunakan atribut `name="robots"` dengan `content` berisi direktif koma-terpisah. Direktif utama meliputi `index`/`noindex`, `follow`/`nofollow`, `nosnippet`, dan `noarchive`. Nilai default jika tag tidak ada adalah `index, follow`. Halaman penting seperti konten utama harus `index, follow`, sementara halaman admin, hasil pencarian internal, atau halaman cetak sebaiknya `noindex, nofollow`.

| Direktif | Fungsi |
|---|---|
| `index` | Izinkan halaman masuk indeks pencarian |
| `noindex` | Cegah halaman masuk indeks pencarian |
| `follow` | Izinkan mesin pencari ikuti tautan |
| `nofollow` | Cegah mesin pencari ikuti tautan |

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Halaman Login Admin</title>
    <meta name="robots" content="noindex, nofollow">
</head>
<body>
    <h1>Login Admin</h1>
    <form action="/login" method="POST">
        <label for="user">Username:</label>
        <input type="text" id="user" name="user" required>
        <label for="pass">Password:</label>
        <input type="password" id="pass" name="pass" required>
        <button type="submit">Login</button>
    </form>
</body>
</html>
```

## Poin Penting
- Gunakan `noindex` untuk halaman non-publik seperti admin, login, atau hasil pencarian internal
- Meta robots hanya instruksi, bukan aturan mutlak
- Selalu tempatkan tag ini di `<head>`, bukan di `<body>`
