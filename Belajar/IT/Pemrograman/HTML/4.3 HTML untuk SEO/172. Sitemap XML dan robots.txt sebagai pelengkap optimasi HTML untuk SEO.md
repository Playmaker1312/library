# Sitemap XML dan Robots.txt sebagai Pelengkap Optimasi HTML untuk SEO

## Analogi: Perpustakaan Digital

Sitemap XML adalah daftar isi lengkap yang diberikan kepada pustakawan (mesin pencari), memberitahu mereka dokumen mana saja yang ada. Robots.txt adalah papan pengumuman di pintu masuk yang memberi tahu pustakawan area mana yang boleh dimasuki.

## Penjelasan Detail

Sitemap XML mencantumkan URL dengan metadata `lastmod`, `changefreq`, `priority`. Robots.txt berisi aturan `User-agent` dan `Disallow`. Keduanya bekerja bersama HTML untuk memastikan mesin pencari mengindeks halaman yang tepat secara efisien.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Beranda - Portal Berita</title>
    <link rel="sitemap" type="application/xml" href="/sitemap.xml">
</head>
<body>
    <h1>Portal Berita Terkini</h1>
    <p>Selamat datang di portal berita dengan konten terbaru setiap hari.</p>
</body>
</html>
```

```
<!-- robots.txt -->
User-agent: *
Disallow: /admin/
Disallow: /login/
Sitemap: https://contoh.com/sitemap.xml
```

```
<!-- sitemap.xml -->
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
    <url><loc>https://contoh.com/</loc><lastmod>2026-05-23</lastmod><changefreq>daily</changefreq><priority>1.0</priority></url>
    <url><loc>https://contoh.com/tentang</loc><lastmod>2026-05-20</lastmod><changefreq>monthly</changefreq><priority>0.8</priority></url>
</urlset>
```

## Poin Penting
- Sitemap membantu mesin pencari menemukan halaman yang tidak terdeteksi melalui crawl biasa
- Robots.txt mencegah pengindeksan halaman non-publik
- Cantumkan URL sitemap di dalam robots.txt
