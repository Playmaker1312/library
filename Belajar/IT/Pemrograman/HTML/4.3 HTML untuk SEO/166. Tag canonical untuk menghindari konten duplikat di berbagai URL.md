# Tag Canonical Untuk Menghindari Konten Duplikat Di Berbagai URL

## Analogi: Perpustakaan Digital

Di perpustakaan digital, sering kali buku yang sama tersimpan di beberapa rak berbeda dengan nomor katalog yang berbeda. Pustakawan perlu menentukan versi mana yang dianggap sebagai salinan utama resmi. Tag canonical adalah instruksi yang memberitahu mesin pencari versi URL mana yang dianggap sebagai sumber asli ketika konten identik tersedia di beberapa URL berbeda.

## Penjelasan Detail

Tag canonical (<link rel=\"canonical\">) adalah elemen HTML yang digunakan untuk mencegah masalah konten duplikat dengan menunjuk ke URL utama yang dianggap paling otoritatif. Konten duplikat terjadi ketika konten yang sama dapat diakses melalui beberapa URL berbeda, misalnya http vs https, www vs non-www, parameter URL, atau variasi sorting. Mesin pencari akan mengumpulkan sinyal peringkat dari semua URL duplikat dan menggabungkannya ke URL canonical. Tag canonical ditempatkan di bagian <head> dan harus merujuk pada URL absolut.

## Contoh Kode Implementasi

`html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Produk Sepatu Olahraga | TokoSepatu</title>
  <link rel="canonical" href="https://www.tokosepatu.com/produk/sepatu-lari">
</head>
<body>
  <main>
    <h1>Sepatu Lari</h1>
    <p>Sepatu lari terbaik untuk aktivitas harian Anda.</p>
    <p>Harga: Rp 450.000</p>
  </main>
</body>
</html>
`

## Poin Penting
- Tag canonical mencegah masalah konten duplikat dengan menunjuk ke URL utama yang otoritatif
- Gunakan URL absolut dalam atribut href dan tempatkan di bagian <head> halaman
- Jangan gunakan canonical yang sama untuk halaman yang berbeda isinya
