# Atribut Lang pada Tag Html untuk Menentukan Bahasa Dokumen

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan digital yang menampung buku dari berbagai negara. Setiap buku perlu label bahasa di sampulnya agar pustakawan bisa meletakkannya di rak yang benar. Atribut `lang` pada tag `<html>` adalah label bahasa tersebut -- memberitahu browser dan mesin pencari bahwa konten halaman ditulis dalam bahasa tertentu.

## Penjelasan Detail

Atribut `lang` menggunakan kode bahasa standar BCP 47 (seperti `id` untuk Indonesia, `en` untuk Inggris, `ja` untuk Jepang). Manfaatnya meliputi: pemilih bahasa yang tepat untuk pengucapan oleh screen reader, saran penerjemahan otomatis yang lebih akurat, penargetan hasil pencarian berdasarkan bahasa, dan penerapan font spesifik bahasa. Atribut ini juga dapat digunakan pada elemen turunan untuk menandai perubahan bahasa di dalam dokumen.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Tentang Kami - Perusahaan XYZ</title>
</head>
<body>
    <h1>Tentang Perusahaan Kami</h1>
    <p>Kami adalah perusahaan teknologi yang berfokus pada inovasi digital.</p>
    <p>English version: <a href="/en/" lang="en">Visit our English site</a></p>
</body>
</html>
```

## Poin Penting
- Selalu deklarasikan `lang` pada tag `<html>` sebagai atribut utama bahasa dokumen
- Gunakan `lang` pada elemen turunan jika ada perubahan bahasa di tengah konten
- Kode bahasa menggunakan standar BCP 47, misalnya `id`, `en`, `ja`, `zh-CN`
