# Twitter Card Meta Tags untuk Optimasi Tampilan di Platform Twitter

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan digital di mana setiap buku bisa ditweet ke timeline pengguna. Twitter Card adalah format kartu yang Anda desain -- menentukan apakah kartu hanya menampilkan judul (summary) atau gambar besar (summary_large_image). Tanpa Twitter Card, tautan Anda hanya tampil sebagai teks biasa.

## Penjelasan Detail

Twitter Card menggunakan meta tag prefiks `twitter:` di `<head>`. Jenis kartu: `summary`, `summary_large_image`, `app`, `player`. Tag wajib: `twitter:card`, `twitter:site`, `twitter:title`. Jika tag OG sudah ada, Twitter akan menggunakannya sebagai fallback.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Resep Nasi Goreng Spesial</title>
    <meta name="twitter:card" content="summary_large_image">
    <meta name="twitter:site" content="@dapurkita">
    <meta name="twitter:creator" content="@chef_andi">
    <meta name="twitter:title" content="Resep Nasi Goreng Spesial">
    <meta name="twitter:description" content="Ikuti langkah mudah membuat nasi goreng spesial.">
    <meta name="twitter:image" content="https://contoh.com/images/nasi-goreng.jpg">
</head>
<body>
    <h1>Resep Nasi Goreng Spesial</h1>
    <p>Nikmati nasi goreng spesial buatan sendiri.</p>
</body>
</html>
```

## Poin Penting
- Gunakan `summary_large_image` untuk konten visual seperti artikel atau resep
- Tag `twitter:` bersifat opsional jika tag OG sudah ada
- Uji kartu dengan Twitter Card Validator
