# Open Graph Meta Tags untuk Optimasi Tampilan saat Dibagikan di Media Sosial

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan digital di mana setiap buku bisa dipajang di etalase toko buku lain (media sosial). Open Graph (OG) adalah kartu tampilan yang Anda kirimkan -- menentukan judul, sampul, dan deskripsi yang akan muncul. Tanpa OG, platform akan menebak-nebak tampilan buku Anda. Dengan OG, Anda mengontrol persis bagaimana halaman terlihat ketika dibagikan.

## Penjelasan Detail

Open Graph diperkenalkan oleh Facebook dan kini diadopsi oleh hampir semua platform. Tag OG diawali dengan `og:` dan ditempatkan di `<head>`. Tag wajib: `og:title`, `og:type`, `og:image` (minimal 1200x630 px), dan `og:url`. Tag opsional: `og:description`, `og:locale`, `og:site_name`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Panduan SEO Lengkap</title>
    <meta property="og:title" content="Panduan SEO Lengkap untuk Pemula">
    <meta property="og:type" content="article">
    <meta property="og:url" content="https://contoh.com/blog/panduan-seo">
    <meta property="og:image" content="https://contoh.com/images/seo-guide.jpg">
    <meta property="og:description" content="Pelajari semua aspek SEO dari dasar hingga mahir.">
    <meta property="og:site_name" content="Blog Teknologi">
    <meta property="og:locale" content="id_ID">
</head>
<body>
    <h1>Panduan SEO Lengkap</h1>
    <p>Artikel komprehensif tentang optimasi mesin pencari.</p>
</body>
</html>
```

## Poin Penting
- Gunakan gambar OG minimal 1200x630 piksel untuk hasil terbaik
- Uji pratinjau dengan Facebook Sharing Debugger sebelum publikasi
- Sertakan `og:url` yang sama persis dengan URL kanonikal
