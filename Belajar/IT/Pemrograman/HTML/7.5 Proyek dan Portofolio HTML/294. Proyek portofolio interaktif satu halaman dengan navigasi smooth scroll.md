# Proyek portofolio interaktif satu halaman dengan navigasi smooth scroll

## Analogi: Perpustakaan Digital

Portofolio satu halaman seperti tur virtual perpustakaan yang dirancang khusus untuk memperkenalkan koleksi andalan. Pengunjung bisa scroll atau mengklik navigasi untuk pindah dari area resepsionis (hero) ke rak buku utama (proyek), ke area baca (tentang), dan ke meja informasi (kontak). Transisi antar bagian terasa mulus seperti berjalan di lorong perpustakaan yang dirancang dengan baik. Setiap bagian menampilkan informasi yang relevan tanpa harus membuka halaman baru.

## Penjelasan Detail

Proyek ini membangun portofolio interaktif satu halaman dengan navigasi smooth scroll menggunakan HTML, CSS, dan JavaScript. Navigasi sticky di bagian atas memudahkan akses ke setiap section. Smooth scroll memberikan pengalaman navigasi yang mulus saat pengguna mengklik link navigasi. Section meliputi Hero (intro dengan foto dan headline), Tentang (profil singkat), Proyek (grid karya), dan Kontak (formulir atau informasi kontak). Scroll spy dengan Intersection Observer menandai navigasi aktif berdasarkan section yang terlihat. Desain responsif memastikan portofolio terlihat baik di semua perangkat. Proyek ini bisa menjadi template portofolio developer atau desainer yang dapat dikustomisasi.

    // Smooth scroll spy dengan Intersection Observer
    const sections = document.querySelectorAll('section');
    const navLinks = document.querySelectorAll('nav ul li a');

    const observer = new IntersectionObserver((entries) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          navLinks.forEach(link => link.classList.remove('active'));
          const activeLink = document.querySelector(`nav ul li a[href="#${entry.target.id}"]`);
          if (activeLink) activeLink.classList.add('active');
        }
      });
    }, { threshold: 0.5 });

    sections.forEach(section => observer.observe(section));

## Poin Penting
- Scroll-behavior: smooth memberikan navigasi mulus tanpa JavaScript tambahan.
- Intersection Observer digunakan untuk scroll spy, menandai navigasi aktif berdasarkan section terlihat.
- Sticky navigation dengan backdrop-filter memberikan kesan modern dan tetap mudah diakses.
