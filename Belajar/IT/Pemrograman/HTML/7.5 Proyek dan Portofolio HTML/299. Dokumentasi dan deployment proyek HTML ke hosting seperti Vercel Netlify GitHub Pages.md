# Dokumentasi dan deployment proyek HTML ke hosting seperti Vercel, Netlify, GitHub Pages

## Analogi: Perpustakaan Digital

Deployment seperti memindahkan buku-buku dari ruang kerja penulis ke rak-rak perpustakaan umum. Penulis menyelesaikan buku (development), kemudian mengirimkannya ke percetakan (build), dan akhirnya mendistribusikannya ke perpustakaan (deploy). Vercel, Netlify, dan GitHub Pages seperti jaringan perpustakaan yang siap menampung dan mendistribusikan buku ke pengunjung. Setiap platform memiliki cara pengiriman yang berbeda: ada yang melalui terminal (CLI), ada yang melalui koper (drag & drop), dan ada yang terhubung langsung ke gudang penulis (Git repository).

## Penjelasan Detail

Dokumentasi proyek HTML mencakup README, struktur folder, instruksi instalasi, dan cara penggunaan. Deployment adalah proses mengunggah file HTML ke server hosting agar dapat diakses publik. Vercel: deploy dengan `vercel` CLI atau hubungkan GitHub repository, otomatis detect framework, support serverless functions, dan preview deployments. Netlify: deploy dengan `netlify deploy` CLI, drag & drop folder, atau hubungkan Git, memiliki Netlify Forms, Functions, dan Split Testing. GitHub Pages: gratis untuk repository publik, deploy dari branch `gh-pages` atau folder `/docs`, support custom domain. Best practices deployment: gunakan `.gitignore` untuk file build, optimasi aset (minify HTML/CSS/JS, kompres gambar), set cache headers, dan gunakan CDN. Setelah deploy, penting untuk memonitor performa dengan Lighthouse dan memastikan SSL aktif.

## Poin Penting
- Vercel, Netlify, dan GitHub Pages adalah platform hosting populer untuk proyek HTML statis.
- Dokumentasi README yang baik mencakup deskripsi, cara instalasi, struktur folder, dan teknologi yang digunakan.
- Best practices: minifikasi aset, optimize gambar, HTTPS, cache headers, dan testing dengan Lighthouse.
