# Proyek blog pribadi dengan artikel, sidebar, dan komentar statis

## Analogi: Perpustakaan Digital

Blog pribadi seperti ruang baca pribadi di perpustakaan yang menampilkan koleksi tulisan seseorang. Area utama (artikel) seperti rak buku utama yang menampilkan tulisan-tulisan terbaru. Sidebar seperti papan pengumuman di samping yang berisi profil penulis, kategori tulisan, dan link ke artikel populer. Komentar seperti buku tamu di mana pembaca bisa meninggalkan pesan. Meskipun blog ini statis (tanpa backend), semua informasi sudah tersusun rapi dan siap dibaca.

## Penjelasan Detail

Proyek ini membangun blog pribadi statis dengan HTML dan CSS. Layout utama menggunakan CSS Flexbox atau Grid untuk mengatur artikel dan sidebar. Artikel ditampilkan dengan judul, meta informasi (tanggal, penulis), dan cuplikan konten. Sidebar berisi profil singkat, daftar kategori, dan artikel populer. Komentar statis ditampilkan di bawah setiap artikel dengan nama pengunjung, tanggal, dan isi komentar. Karena blog ini statis, komentar ditulis langsung di file HTML. Blog ini bisa dikembangkan lebih lanjut dengan menambahkan form komentar yang terintegrasi dengan layanan seperti Disqus atau menggunakan static site generator seperti Hugo atau 11ty. Pendekatan ini memberikan fondasi untuk blog yang cepat, aman, dan mudah di-host di GitHub Pages atau Netlify.
