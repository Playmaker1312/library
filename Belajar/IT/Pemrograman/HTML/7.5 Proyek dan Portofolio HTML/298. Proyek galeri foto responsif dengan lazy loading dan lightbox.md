# Proyek galeri foto responsif dengan lazy loading dan lightbox

## Analogi: Perpustakaan Digital

Galeri foto seperti pameran buku bergambar di perpustakaan. Foto-foto dipajang di dinding (grid galeri) dalam ukuran kecil (thumbnail) sehingga pengunjung bisa melihat semua koleksi sekilas. Saat pengunjung tertarik dengan salah satu foto, mereka bisa mendekat dan melihatnya dalam ukuran besar (lightbox). Lazy loading seperti petugas perpustakaan yang hanya memasang foto yang sedang dilihat pengunjung, sementara foto lainnya tetap di gudang sampai diperlukan. Ini membuat halaman tetap cepat dimuat meskipun ada ratusan foto.

## Penjelasan Detail

Proyek ini membangun galeri foto responsif dengan lazy loading dan lightbox menggunakan HTML, CSS, dan JavaScript. Grid galeri menggunakan CSS Grid dengan ukuran thumbnail yang konsisten. Setiap gambar menggunakan atribut `loading="lazy"` untuk lazy loading native, sehingga gambar hanya dimuat saat mendekati viewport. Saat thumbnail diklik, lightbox menampilkan gambar dalam ukuran penuh dengan overlay gelap dan animasi transisi. Lightbox mendukung navigasi next/previous dan tombol tutup. Fitur tambahan: keyboard navigation (Esc untuk tutup, panah kiri/kanan untuk navigasi), dan animasi masuk/keluar. Responsivitas grid menyesuaikan jumlah kolom berdasarkan ukuran layar.

```html
    .lightbox.active { display: flex; }

<body>
  <header>

  </footer>

    const photos = [

      { src: 'https://picsum.photos/seed/4/800/800', thumb: 'https://picsum.photos/seed/4/300/300', caption: 'Area Anak' },
      { src: 'https://picsum.photos/seed/5/800/800', thumb: 'https://picsum.photos/seed/5/300/300', caption: 'Meja Baca' },
      { src: 'https://picsum.photos/seed/6/800/800', thumb: 'https://picsum.photos/seed/6/300/300', caption: 'Rak Digital' },
      { src: 'https://picsum.photos/seed/7/800/800', thumb: 'https://picsum.photos/seed/7/300/300', caption: 'Suasana Tenang' },
      { src: 'https://picsum.photos/seed/8/800/800', thumb: 'https://picsum.photos/seed/8/300/300', caption: 'Cahaya Alami' },
      { src: 'https://picsum.photos/seed/9/800/800', thumb: 'https://picsum.photos/seed/9/300/300', caption: 'Area Komputer' },
      { src: 'https://picsum.photos/seed/10/800/800', thumb: 'https://picsum.photos/seed/10/300/300', caption: 'Pojok Baca' },
      { src: 'https://picsum.photos/seed/11/800/800', thumb: 'https://picsum.photos/seed/11/300/300', caption: 'Langit-langit' },
      { src: 'https://picsum.photos/seed/12/800/800', thumb: 'https://picsum.photos/seed/12/300/300', caption: 'Eksterior' }
    ];

    let currentIndex = 0;
    const grid = document.getElementById('galleryGrid');
    const lightbox = document.getElementById('lightbox');
    const lightboxImg = document.getElementById('lightboxImg');
    const lightboxCaption = document.getElementById('lightboxCaption');
    const lightboxClose = document.getElementById('lightboxClose');
    const lightboxPrev = document.getElementById('lightboxPrev');
    const lightboxNext = document.getElementById('lightboxNext');

    function renderGallery() {
      grid.innerHTML = photos.map((photo, index) => `
        <div class="grid-item" data-index="${index}" onclick="openLightbox(${index})">
          <img
            src="${photo.thumb}"
            alt="${photo.caption}"
            loading="lazy"
            class="loading"
            onload="this.classList.remove('loading'); this.classList.add('loaded');"
            onerror="this.src='data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 width=%22300%22 height=%22300%22%3E%3Crect fill=%22%2316213e%22 width=%22300%22 height=%22300%22/%3E%3Ctext x=%2250%25%22 y=%2250%25%22 text-anchor=%22middle%22 fill=%22%23666%22 font-size=%2220%22%3EGagal%3C/text%3E%3C/svg%3E'; this.classList.remove('loading'); this.classList.add('loaded');"
          >
          <div class="caption">${photo.caption}</div>
        </div>
      `).join('');
    }

    function openLightbox(index) {
      currentIndex = index;
      updateLightbox();
      lightbox.classList.add('active');
      document.body.style.overflow = 'hidden';
    }

    function closeLightbox() {
      lightbox.classList.remove('active');
      document.body.style.overflow = '';
    }

    function updateLightbox() {
      const photo = photos[currentIndex];
      lightboxImg.src = photo.src;
      lightboxImg.alt = photo.caption;
      lightboxCaption.textContent = `${currentIndex + 1} dari ${photos.length} - ${photo.caption}`;
    }

    function prevPhoto() {
      currentIndex = (currentIndex - 1 + photos.length) % photos.length;
      updateLightbox();
    }

    function nextPhoto() {
      currentIndex = (currentIndex + 1) % photos.length;
      updateLightbox();
    }

    lightboxClose.addEventListener('click', closeLightbox);
    lightboxPrev.addEventListener('click', prevPhoto);
    lightboxNext.addEventListener('click', nextPhoto);

    document.addEventListener('keydown', (e) => {
      if (!lightbox.classList.contains('active')) return;
      if (e.key === 'Escape') closeLightbox();
      if (e.key === 'ArrowLeft') prevPhoto();
      if (e.key === 'ArrowRight') nextPhoto();
    });

    lightbox.addEventListener('click', (e) => {
      if (e.target === lightbox) closeLightbox();
    });

    renderGallery();
  </script>
</body>
</html>
```

## Poin Penting
- Lazy loading native (`loading="lazy"`) meningkatkan performa dengan memuat gambar hanya saat mendekati viewport.
- Lightbox memberikan pengalaman melihat gambar ukuran penuh dengan overlay gelap dan navigasi.
- Keyboard navigation (Esc, panah kiri/kanan) meningkatkan aksesibilitas lightbox.
