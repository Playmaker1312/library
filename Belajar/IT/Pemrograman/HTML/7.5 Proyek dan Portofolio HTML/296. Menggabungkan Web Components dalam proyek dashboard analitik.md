# Menggabungkan Web Components dalam proyek dashboard analitik

## Analogi: Perpustakaan Digital

Dashboard analitik seperti ruang kontrol perpustakaan yang menampilkan berbagai statistik secara real-time. Web Components adalah widget standar yang bisa dipasang di dashboard: widget jumlah pengunjung, widget buku terpopuler, widget denda keterlambatan. Setiap widget adalah komponen mandiri yang bisa digunakan di dashboard mana pun tanpa konflik. Widget ini seperti modul papan informasi yang bisa dipindah-pindah dan dipasang di berbagai dinding perpustakaan. Dashboard menyusun widget-widget ini dalam grid untuk memberikan gambaran lengkap tentang kondisi perpustakaan.

## Penjelasan Detail

Proyek ini membangun dashboard analitik menggunakan Web Components yang dibuat dengan Custom Elements dan Shadow DOM. Setiap komponen dashboard (KPI card, chart placeholder, data table, status widget) adalah Web Component independen dengan HTML, CSS, dan JavaScript sendiri yang terisolasi di Shadow DOM. Dashboard utama menggabungkan komponen-komponen ini dalam layout grid. Keuntungan Web Components: reusable di project mana pun, tidak bergantung framework, style terisolasi, dan mudah dipelihara. Proyek ini mendemonstrasikan cara membuat komponen dengan atribut kustom, event, dan slot untuk konten dinamis. Setiap komponen memiliki lifecycle callback (connectedCallback, attributeChangedCallback) yang memudahkan manajemen siklus hidup.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Dashboard Analitik - Perpustakaan</title>
  <style>
    * { box-sizing: border-box; margin: 0; padding: 0; }
    body { font-family: system-ui, -apple-system, sans-serif; background: #f0f2f5; color: #333; }
    .dashboard { max-width: 1200px; margin: auto; padding: 1.5rem; }
    .dashboard h1 { margin-bottom: 1.5rem; color: #2c3e50; }
    .grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(300px, 1fr)); gap: 1rem; }
  </style>
</head>
<body>
  <div class="dashboard">
    <h1>Dashboard Perpustakaan</h1>

    <div class="grid">
      <kpi-card label="Total Buku" value="12.340" icon="&#128218;" color="#4A90D9"></kpi-card>
      <kpi-card label="Anggota Aktif" value="2.156" icon="&#128101;" color="#27ae60"></kpi-card>
      <kpi-card label="Peminjaman Hari Ini" value="89" icon="&#128214;" color="#e67e22"></kpi-card>
      <kpi-card label="Denda Tertunda" value="Rp 2.5jt" icon="&#128176;" color="#e74c3c"></kpi-card>
    </div>

    <div class="grid" style="margin-top:1rem;">
      <data-table-widget title="Buku Populer" headers='["Judul", "Pengarang", "Dipinjam"]'
        rows='[["Pemrograman Web","Ahmad Fauzi","45"],["JavaScript","Siti Rahma","38"],["CSS Dasar","Budi Hartono","30"],["React.js","Dewi Lestari","28"]]'>
      </data-table-widget>

      <status-widget title="Status Sistem" status='[
        {"name":"Server Database","status":"online"},
        {"name":"API Service","status":"online"},
        {"name":"CDN","status":"degraded"},
        {"name":"Email Service","status":"offline"}
      ]'></status-widget>
    </div>
  </div>

  <script>
    // Web Component 1: KPI Card
    class KPICard extends HTMLElement {
      static get observedAttributes() {
        return ['label', 'value', 'icon', 'color'];
      }

      constructor() {
        super();
        this.attachShadow({ mode: 'open' });
      }

      connectedCallback() {
        this.render();
      }

      attributeChangedCallback() {
        this.render();
      }

      render() {
        const label = this.getAttribute('label') || 'Label';
        const value = this.getAttribute('value') || '0';
        const icon = this.getAttribute('icon') || '&#128200;';
        const color = this.getAttribute('color') || '#4A90D9';

        this.shadowRoot.innerHTML = `
          <style>
            .card { background: white; border-radius: 12px; padding: 1.5rem; box-shadow: 0 2px 8px rgba(0,0,0,0.08); display: flex; align-items: center; gap: 1rem; transition: transform 0.2s; }
            .card:hover { transform: translateY(-2px); }
            .icon { font-size: 2.5rem; width: 60px; height: 60px; background: ${color}15; border-radius: 12px; display: flex; align-items: center; justify-content: center; }
            .info h3 { font-size: 0.85rem; color: #888; margin-bottom: 0.25rem; }
            .info .value { font-size: 1.8rem; font-weight: bold; color: ${color}; }
          </style>
          <div class="card">
            <div class="icon">${icon}</div>
            <div class="info">
              <h3>${label}</h3>
              <div class="value">${value}</div>
            </div>
          </div>
        `;
      }
    }

    // Web Component 2: Data Table Widget
    class DataTableWidget extends HTMLElement {
      constructor() {
        super();
        this.attachShadow({ mode: 'open' });
      }

      connectedCallback() {
        this.render();
      }

      render() {
        const title = this.getAttribute('title') || 'Data';
        const headers = JSON.parse(this.getAttribute('headers') || '[]');
        const rows = JSON.parse(this.getAttribute('rows') || '[]');

        this.shadowRoot.innerHTML = `
          <style>
            .widget { background: white; border-radius: 12px; box-shadow: 0 2px 8px rgba(0,0,0,0.08); padding: 1.5rem; }
            h2 { font-size: 1.1rem; margin-bottom: 1rem; color: #2c3e50; }
            table { width: 100%; border-collapse: collapse; }
            th { text-align: left; padding: 0.5rem; background: #f8f9fa; font-size: 0.85rem; color: #666; }
            td { padding: 0.5rem; border-bottom: 1px solid #f0f0f0; font-size: 0.9rem; }
            tr:last-child td { border-bottom: none; }
          </style>
          <div class="widget">
            <h2>${title}</h2>
            <table>
              <thead>
                <tr>${headers.map(h => `<th>${h}</th>`).join('')}</tr>
              </thead>
              <tbody>
                ${rows.map(row => `<tr>${row.map(cell => `<td>${cell}</td>`).join('')}</tr>`).join('')}
              </tbody>
            </table>
          </div>
        `;
      }
    }

    // Web Component 3: Status Widget
    class StatusWidget extends HTMLElement {
      constructor() {
        super();
        this.attachShadow({ mode: 'open' });
      }

      connectedCallback() {
        this.render();
      }

      render() {
        const title = this.getAttribute('title') || 'Status';
        const statuses = JSON.parse(this.getAttribute('status') || '[]');

        this.shadowRoot.innerHTML = `
          <style>
            .widget { background: white; border-radius: 12px; box-shadow: 0 2px 8px rgba(0,0,0,0.08); padding: 1.5rem; }
            h2 { font-size: 1.1rem; margin-bottom: 1rem; color: #2c3e50; }
            .item { display: flex; justify-content: space-between; align-items: center; padding: 0.75rem 0; border-bottom: 1px solid #f0f0f0; }
            .item:last-child { border-bottom: none; }
            .name { font-size: 0.9rem; }
            .status { font-size: 0.8rem; padding: 0.2rem 0.6rem; border-radius: 20px; font-weight: 500; }
            .online { background: #d4edda; color: #155724; }
            .degraded { background: #fff3cd; color: #856404; }
            .offline { background: #f8d7da; color: #721c24; }
          </style>
          <div class="widget">
            <h2>${title}</h2>
            ${statuses.map(s => `
              <div class="item">
                <span class="name">${s.name}</span>
                <span class="status ${s.status}">${s.status}</span>
              </div>
            `).join('')}
          </div>
        `;
      }
    }

    customElements.define('kpi-card', KPICard);
    customElements.define('data-table-widget', DataTableWidget);
    customElements.define('status-widget', StatusWidget);
  </script>
</body>
</html>
```

## Poin Penting
- Web Components membuat komponen dashboard yang reusable, terisolasi, dan independen framework.
- Setiap komponen memiliki Shadow DOM untuk isolasi style dan markup.
- Atribut kustom memungkinkan konfigurasi komponen secara deklaratif dari HTML.
