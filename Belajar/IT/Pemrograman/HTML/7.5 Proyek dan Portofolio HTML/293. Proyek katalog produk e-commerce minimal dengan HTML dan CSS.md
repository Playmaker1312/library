# Proyek katalog produk e-commerce minimal dengan HTML dan CSS

## Analogi: Perpustakaan Digital

Katalog produk seperti rak buku display di perpustakaan yang memamerkan koleksi terbaru. Setiap produk seperti buku dengan sampul menarik, judul, harga, dan tombol "beli". Rak display ini tersusun rapi dalam grid sehingga pengunjung bisa melihat semua produk sekilas. Filter kategori seperti label rak yang membantu pengunjung menemukan genre yang diinginkan. Keranjang belanja seperti keranjang buku yang dibawa pengunjung untuk mengumpulkan buku yang ingin dipinjam.

## Penjelasan Detail

Proyek ini membangun katalog produk e-commerce minimal menggunakan HTML dan CSS. Produk ditampilkan dalam grid cards menggunakan CSS Grid atau Flexbox. Setiap card berisi gambar produk, nama produk, harga, rating, dan tombol aksi. Katalog dilengkapi dengan navigasi kategori, fitur pencarian sederhana, dan sidebar filter. Desain responsif menyesuaikan jumlah kolom grid berdasarkan ukuran layar. Harga menggunakan format mata uang yang konsisten. Efek hover memberikan feedback visual saat pengguna berinteraksi dengan card produk. Proyek ini bisa dikembangkan dengan JavaScript untuk fungsionalitas keranjang belanja, filter dinamis, dan pencarian real-time.
