# Tag meta author untuk Mencantumkan Penulis Halaman

## Analogi: Perpustakaan Digital

Bayangkan setiap buku di perpustakaan digital punya **halaman hak cipta** yang mencantumkan nama penulis. Pembaca yang penasaran bisa tahu siapa yang menulis buku tersebut.

`<meta name="author">` adalah **nama penulis/pencipta** dari perpustakaan digitalmu. Ini memberi tahu siapa yang membuat halaman web ini — apakah itu individu, organisasi, atau perusahaan.

Meskipun tidak tampak langsung oleh pengunjung biasa, informasi ini berguna untuk:
- Dokumentasi internal
- Analisis web
- Beberapa tool development

## Penjelasan Detail

`<meta name="author">` digunakan untuk mencantumkan nama penulis atau pembuat dokumen HTML.

### Format Penulisan
```html
<meta name="author" content="Nama Penulis">
<meta name="author" content="Nama Perusahaan atau Organisasi">
<meta name="author" content="Nama Tim">
```

### Meta Author vs Meta Description vs Title

| Fungsi | Tag | Contoh |
|--------|-----|--------|
| Nama halaman | `<title>` | "Beranda | Perpustakaan Digital" |
| Sinopsis | `meta description` | "Ribuan buku gratis..." |
| Pencipta | `meta author` | "Tim Perpustakaan Digital" |

### Catatan
- Meta author **tidak langsung** memengaruhi SEO
- Berguna untuk **manajemen konten** tim besar
- Beberapa CMS (Content Management System) otomatis mengisi ini

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Perpustakaan Digital Indonesia dengan ribuan koleksi buku gratis.">

    <!-- Meta author -->
    <meta name="author" content="Tim Perpustakaan Digital">
    <!-- Bisa juga dengan nama individu jika personal website -->
    <!-- <meta name="author" content="Budi Santoso"> -->

    <title>Beranda | Perpustakaan Digital</title>
  </head>
  <body>
    <h1>Selamat Datang di Perpustakaan Digital</h1>
    <p>Dibuat oleh Tim Perpustakaan Digital.</p>
  </body>
</html>
```

## Poin Penting
- `<meta name="author">` mencatat siapa pembuat halaman
- Berguna untuk dokumentasi dan manajemen konten
- Tidak berdampak langsung pada SEO
- Bersifat opsional, tapi baik untuk kelengkapan
