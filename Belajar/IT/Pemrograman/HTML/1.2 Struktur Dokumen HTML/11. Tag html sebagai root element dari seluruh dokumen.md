# Tag html sebagai Root Element dari Seluruh Dokumen

## Analogi: Perpustakaan Digital

Bayangkan seluruh perpustakaan digital kamu. Gedung perpustakaan itu sendiri adalah tag `html`. Semua yang ada di dalam perpustakaan — mulai dari ruang administrasi (`head`) hingga ruang baca utama (`body`) — harus berada **di dalam** gedung ini.

Tidak ada satu pun buku atau rak yang boleh berada di luar gedung. `html` adalah **batas terluar** dari perpustakaan digitalmu.

Begitu pengunjung (browser) melihat `html`, mereka tahu: "Ah, ini gedung perpustakaannya. Semua yang akan saya lihat ada di sini."

## Penjelasan Detail

Tag `<html>` adalah **root element** (elemen akar) dari seluruh dokumen HTML. Artinya:

- **Semua** elemen HTML lain harus berada di dalam `<html>`...`</html>`
- Hanya ada **SATU** `<html>` per dokumen
- `<html>` adalah **induk tertinggi** (parent paling atas) dalam hierarki DOM
- Atribut `lang` pada `<html>` menentukan bahasa dokumen

### Atribut `lang`

```html
<html lang="id">   <!-- Bahasa Indonesia -->
<html lang="en">   <!-- Bahasa Inggris -->
<html lang="ja">   <!-- Bahasa Jepang -->
```

Atribut `lang` penting untuk SEO, aksesibilitas (screen reader), dan fitur terjemahan browser.

### Posisi dalam Dokumen

```
<!DOCTYPE html>
<html>                ← Paling luar
  <head>...</head>     ← Di dalam html
  <body>...</body>     ← Di dalam html
</html>               ← Tutup
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <title>Perpustakaan Digital</title>
  </head>
  <body>
    <h1>Selamat Datang</h1>
    <p>Ini adalah halaman utama perpustakaan digital.</p>
  </body>
</html>
```

## Poin Penting
- `<html>` adalah **root element** — elemen paling luar
- Semua elemen harus di dalam `<html>`...`</html>`
- Gunakan atribut `lang` untuk menentukan bahasa
- Hanya ada SATU `<html>` per dokumen
