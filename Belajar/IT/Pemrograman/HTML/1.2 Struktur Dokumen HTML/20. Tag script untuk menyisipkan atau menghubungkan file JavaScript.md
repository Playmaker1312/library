# Tag script untuk Menyisipkan atau Menghubungkan File JavaScript

## Analogi: Perpustakaan Digital

Bayangkan kamu ingin menambahkan **pustakawan otomatis** ke perpustakaan digitalmu — robot yang bisa:
- Mencari buku saat pengunjung mengetik judul
- Menampilkan jam buka otomatis
- Membunyikan bel saat ada buku kembali

`<script>` adalah **pintu masuk untuk pustakawan ini**. Kamu bisa menulis instruksi langsung di halaman HTML (inline), atau menghubungkan ke file JavaScript eksternal yang berisi semua logika.

Tanpa `<script>`, perpustakaanmu hanya statis — cantik tapi tidak bisa berinteraksi dengan pengunjung.

## Penjelasan Detail

Tag `<script>` digunakan untuk menyisipkan atau menghubungkan kode **JavaScript** ke halaman HTML.

### Cara 1: Inline JavaScript (Langsung di HTML)
```html
<script>
  alert('Selamat datang di Perpustakaan Digital!');
</script>
```

### Cara 2: Eksternal JavaScript (File Terpisah — REKOMENDASI)
```html
<script src="script.js"></script>
```

### Atribut Penting `<script>`
| Atribut | Fungsi |
|---------|--------|
| `src` | Lokasi file JavaScript eksternal |
| `async` | Muat script secara asinkron (tidak urut) |
| `defer` | Muat script setelah HTML selesai diparse |
| `type="module"` | Untuk ES Modules (JavaScript modern) |

### Di Mana Letak `<script>`?
Ada dua tempat utama:

1. **Di `<head>`** — script dimuat sebelum konten (gunakan `defer` untuk menunda)
2. **Sebelum `</body>`** — script dimuat setelah konten (cara tradisional)

### Perbedaan `async` vs `defer` vs tanpa atribut

| | Tanpa | `async` | `defer` |
|--|-------|---------|---------|
| Waktu muat | Saat ditemukan (blocking) | Bersamaan dengan HTML | Bersamaan dengan HTML |
| Waktu eksekusi | Langsung | Begitu selesai muat | Setelah HTML selesai |
| Urutan eksekusi | Sesuai urutan | Tidak terjamin | Sesuai urutan |

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Beranda | Perpustakaan Digital</title>

    <!-- Script eksternal dengan defer (dimuat setelah HTML) -->
    <script src="script.js" defer></script>
  </head>
  <body>
    <h1>Selamat Datang di Perpustakaan Digital</h1>
    <button id="tombolSapa">Klik untuk Disapa</button>

    <!-- Inline script (atau taruh sebelum /body) -->
    <script>
      document.getElementById('tombolSapa').onclick = function() {
        alert('Halo! Selamat membaca!');
      };
    </script>
  </body>
</html>
```

**File: script.js**
```javascript
console.log('Perpustakaan Digital siap digunakan!');
```

## Poin Penting
- `<script>` untuk menambahkan **JavaScript** (interaksi/perilaku)
- Dua cara: **inline** (langsung) atau **eksternal** (file terpisah)
- Letakkan script **sebelum `</body>`** atau gunakan `defer` di `<head>`
- Script blocking = selesaikan baca script dulu baru lanjut render HTML
