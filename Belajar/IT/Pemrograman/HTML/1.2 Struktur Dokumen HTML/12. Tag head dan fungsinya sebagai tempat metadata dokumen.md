# Tag head dan Fungsinya sebagai Tempat Metadata Dokumen

## Analogi: Perpustakaan Digital

Bayangkan **ruang administrasi** perpustakaan digital. Ruangan ini (`<head>`) tidak terlihat oleh pengunjung yang duduk di ruang baca, tapi isinya sangat penting:

- **Judul perpustakaan** (`<title>`) → nama yang muncul di tab browser
- **Encoding buku** (`<meta charset>`) → aturan huruf yang dipakai
- **Deskripsi perpustakaan** (`<meta description>`) → informasi untuk mesin pencari
- **Koneksi ke katalog luar** (`<link>`) → menghubungkan CSS

Seperti ruang administrasi, `<head>` berisi data tentang data (metadata) — informasi yang diperlukan browser tapi tidak perlu dilihat pengguna.

## Penjelasan Detail

Tag `<head>` adalah wadah untuk **metadata** — data tentang dokumen HTML itu sendiri. Konten di dalam `<head>` **TIDAK** ditampilkan di halaman browser (kecuali `<title>` yang muncul di tab).

### Elemen yang Biasa Ada di `<head>`

| Elemen | Fungsi | Contoh |
|--------|--------|--------|
| `<title>` | Judul halaman (di tab browser) | `<title>Perpustakaan Digital</title>` |
| `<meta>` | Metadata: charset, deskripsi, viewport | `<meta charset="UTF-8">` |
| `<link>` | Hubungkan file eksternal (CSS, favicon) | `<link rel="stylesheet" href="style.css">` |
| `<style>` | CSS internal langsung di HTML | `<style>body { color: red; }</style>` |
| `<script>` | JavaScript (bisa di head atau body) | `<script src="app.js"></script>` |
| `<base>` | URL dasar untuk semua tautan relatif | `<base href="https://example.com/">` |

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
  <head>
    <!-- Judul halaman (wajib ada) -->
    <title>Perpustakaan Digital - Beranda</title>

    <!-- Metadata -->
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Perpustakaan digital dengan ribuan buku gratis">
    <meta name="author" content="Admin Perpus">

    <!-- Hubungkan CSS -->
    <link rel="stylesheet" href="style.css">

    <!-- CSS internal -->
    <style>
      body { font-family: Arial; }
    </style>
  </head>
  <body>
    <h1>Selamat Datang di Perpustakaan Digital</h1>
  </body>
</html>
```

## Poin Penting
- `<head>` berisi metadata — data tentang halaman
- Konten `<head>` **tidak tampil** di halaman browser
- `<title>` adalah satu-satunya elemen head yang terlihat (di tab browser)
- Letak `<head>` WAJIB sebelum `<body>`
