# Tag meta viewport untuk Pengaturan Tampilan di Perangkat Mobile

## Analogi: Perpustakaan Digital

Bayangkan **papan informasi** perpustakaan yang bisa menyesuaikan ukuran tulisannya. Saat pengunjung melihat dari **layar besar** (komputer), papan menampilkan teks lengkap. Saat dilihat dari **layar kecil** (HP), papan otomatis mengecilkan teksnya agar muat.

`<meta name="viewport">` adalah **pengatur skala** untuk perpustakaan digitalmu. Ini memberi tahu browser: "Sesuaikan tampilan perpustakaan ini agar muat di layar pengunjung, jangan terlalu kecil atau terlalu besar."

Tanpa meta viewport, halaman akan tampil **kecil sekali** di HP karena browser pikir lebar HP sama dengan lebar komputer.

## Penjelasan Detail

`<meta name="viewport">` mengatur bagaimana halaman web ditampilkan di perangkat mobile.

### Komponen Viewport

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

| Properti | Nilai | Fungsi |
|----------|-------|--------|
| `width=device-width` | device-width | Lebar halaman = lebar perangkat |
| `initial-scale=1.0` | angka | Tingkat zoom awal (1.0 = 100%) |
| `minimum-scale` | angka | Zoom minimum yang diizinkan |
| `maximum-scale` | angka | Zoom maksimum yang diizinkan |
| `user-scalable` | yes/no | Izin zoom oleh pengguna |

### Kenapa Penting?
Sebelum meta viewport, website didesain untuk layar ~1024px. Di HP dengan lebar 375px, website tampil **kecil dan perlu di-pinch-zoom**. Meta viewport memperbaiki ini.

### Kesalahan Umum
```html
<!-- JANGAN: user-scalable=no menghalangi aksesibilitas -->
<meta name="viewport" content="width=device-width, initial-scale=1.0, user-scalable=no">
```

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <!-- Viewport untuk mobile -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Perpustakaan Digital</title>
  </head>
  <body>
    <h1>Selamat Datang</h1>
    <p>Halaman ini akan nyaman dilihat di HP maupun komputer.</p>
  </body>
</html>
```

### Coba Sendiri
1. Buat HTML tanpa meta viewport → buka di HP → halaman kecil
2. Tambah meta viewport → buka di HP → halaman pas di layar

## Poin Penting
- Meta viewport membuat halaman **responsif di mobile**
- `width=device-width, initial-scale=1.0` adalah standar
- WAJIB ditambahkan untuk website modern
- Jangan nonaktifkan zoom (`user-scalable=no`) — buruk untuk aksesibilitas
