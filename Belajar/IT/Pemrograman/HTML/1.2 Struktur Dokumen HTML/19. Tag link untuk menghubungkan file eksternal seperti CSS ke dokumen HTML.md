# Tag link untuk Menghubungkan File Eksternal seperti CSS ke Dokumen HTML

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan digitalmu memiliki **katalog buku pusat** yang terhubung ke sistem manajemen terpisah. Daripada menulis daftar ribuan buku langsung di dinding perpustakaan, kamu cukup membuat **tautan** ke katalog tersebut.

`<link>` adalah seperti **pintu penghubung** ke ruang lain. Alih-alih menulis semua aturan gaya (CSS) di dalam perpustakaan, kamu bisa menghubungkan ke **lembar gaya eksternal** — sebuah dokumen terpisah yang berisi semua aturan tampilan.

Ini membuat perpustakaan tetap rapi: struktur di satu tempat, hiasan di tempat lain.

## Penjelasan Detail

Tag `<link>` digunakan untuk menghubungkan dokumen HTML dengan **sumber daya eksternal**. Yang paling umum adalah file CSS.

### Atribut Utama `<link>`
| Atribut | Fungsi | Contoh |
|---------|--------|--------|
| `rel` | Hubungan dengan file yang ditautkan | `rel="stylesheet"` |
| `href` | Lokasi file eksternal | `href="style.css"` |
| `type` | Tipe konten (opsional di HTML5) | `type="text/css"` |
| `media` | Media target | `media="print"` |

### Penggunaan Umum
```html
<!-- CSS eksternal (PALING UMUM) -->
<link rel="stylesheet" href="style.css">

<!-- Favicon (ikon di tab browser) -->
<link rel="icon" href="favicon.ico" type="image/x-icon">

<!-- Font dari Google Fonts -->
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Open+Sans">

<!-- Preload untuk optimasi -->
<link rel="preload" href="font.woff2" as="font">
```

### Keuntungan CSS Eksternal
1. **Pisah struktur dan gaya** — HTML bersih, CSS terpisah
2. **Caching** — file CSS di-cache browser, loading lebih cepat
3. **Reusable** — satu file CSS bisa dipakai banyak halaman
4. **Maintenance** — ubah satu file, semua halaman berubah

## Contoh Kode Implementasi

**File: index.html**
```html
<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Beranda | Perpustakaan Digital</title>

    <!-- Hubungkan CSS eksternal -->
    <link rel="stylesheet" href="style.css">

    <!-- Favicon -->
    <link rel="icon" href="favicon.ico" type="image/x-icon">
  </head>
  <body>
    <h1>Selamat Datang di Perpustakaan Digital</h1>
    <p class="deskripsi">Buku akan berwarna biru berkat CSS eksternal.</p>
  </body>
</html>
```

**File: style.css**
```css
body {
  font-family: Arial, sans-serif;
  background-color: #f5f5f5;
}
h1 {
  color: navy;
}
.deskripsi {
  color: blue;
  font-size: 18px;
}
```

## Poin Penting
- `<link>` menghubungkan HTML ke **sumber daya eksternal**
- Paling sering dipakai untuk **CSS** (`rel="stylesheet"`)
- Juga untuk **favicon, font, preload**, dll.
- File terpisah = lebih rapi, cepat, dan mudah dirawat
