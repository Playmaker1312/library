# Atribut Type Week Dan Month Pada Input Untuk Pemilih Minggu Dan Bulan

## Analogi: Perpustakaan Digital

Seperti kalender yang bisa dipilih berdasarkan minggu atau bulan tertentu, input type week dan month memungkinkan pengguna memilih periode waktu spesifik tanpa harus memilih tanggal individual. Ini memudahkan pencarian berdasarkan siklus mingguan atau bulanan.

## Penjelasan Detail

Input `type="week"` menampilkan pemilih yang mengembalikan nilai dalam format `yyyy-Www` (tahun dan nomor minggu), misalnya `2026-W21` untuk minggu ke-21 tahun 2026. Input `type="month"` mengembalikan nilai dalam format `yyyy-mm` (tahun dan bulan), misalnya `2026-05` untuk bulan Mei 2026. Kedua input ini menyediakan antarmuka kalender bawaan browser yang memudahkan pemilihan periode. Atribut `min`, `max`, dan `value` menggunakan format yang sesuai dengan masing-masing tipe. Browser yang tidak mendukung tipe ini akan menampilkan input teks biasa. Validasi bawaan memeriksa apakah nilai yang dimasukkan sesuai dengan format yang diharapkan.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Input Week dan Month</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 500px; margin: auto; padding: 20px; }
    .form-group { margin: 25px 0; padding: 20px; background: #f9f9f9; border-radius: 8px; }
    label { display: block; font-weight: bold; margin-bottom: 5px; color: #2c3e50; }
    input[type="week"], input[type="month"] { padding: 10px; font-size: 16px; border: 2px solid #3498db; border-radius: 5px; width: 100%; max-width: 250px; }
    .result { margin-top: 10px; padding: 10px; background: #e8f4f8; border-radius: 5px; display: none; }
    code { background: #f4f4f4; padding: 2px 6px; border-radius: 3px; }
  </style>
</head>
<body>
  <h1>Input Week &amp; Month</h1>
  <div class="form-group">
    <label for="weekPicker">Pilih Minggu:</label>
    <input type="week" id="weekPicker" value="2026-W21" min="2026-W01" max="2026-W52">
    <div class="result" id="weekResult">Minggu dipilih: <strong id="weekValue"></strong></div>
  </div>
  <div class="form-group">
    <label for="monthPicker">Pilih Bulan:</label>
    <input type="month" id="monthPicker" value="2026-05" min="2026-01" max="2026-12">
    <div class="result" id="monthResult">Bulan dipilih: <strong id="monthValue"></strong></div>
  </div>
  <p style="color:#7f8c8d;">Format: Week = <code>yyyy-Www</code>, Month = <code>yyyy-mm</code></p>
  <script>
    const weekPicker = document.getElementById('weekPicker');
    const monthPicker = document.getElementById('monthPicker');
    const weekResult = document.getElementById('weekResult');
    const monthResult = document.getElementById('monthResult');
    const weekValue = document.getElementById('weekValue');
    const monthValue = document.getElementById('monthValue');

    weekPicker.addEventListener('change', function() {
      weekValue.textContent = this.value;
      weekResult.style.display = 'block';
    });
    monthPicker.addEventListener('change', function() {
      monthValue.textContent = this.value;
      monthResult.style.display = 'block';
    });
    if (weekPicker.value) { weekPicker.dispatchEvent(new Event('change')); }
    if (monthPicker.value) { monthPicker.dispatchEvent(new Event('change')); }
  </script>
</body>
</html>
```

## Poin Penting
- Input `type="week"` mengembalikan nilai format `yyyy-Www` (tahun-minggu), `type="month"` format `yyyy-mm`
- Menyediakan antarmuka kalender bawaan browser untuk pemilihan periode
- Atribut min, max, dan value menggunakan format sesuai tipe masing-masing
