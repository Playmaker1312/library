# Tag Progress Untuk Menampilkan Kemajuan Dari Suatu Proses

## Analogi: Perpustakaan Digital

Seperti bilah kemajuan saat mengunduh e-book yang menunjukkan berapa persen sudah selesai, tag progress menampilkan kemajuan suatu proses kepada pengguna. Ini memberikan umpan balik visual tentang status tugas yang sedang berjalan.

## Penjelasan Detail

Tag `<progress>` adalah elemen HTML5 yang menampilkan indikator kemajuan suatu tugas yang sedang berlangsung. Atribut `value` menentukan seberapa banyak tugas telah selesai, dan `max` menentukan total nilai yang menunjukkan selesai. Tanpa atribut `value`, progress menampilkan animasi indeterminate (tidak pasti) yang bergerak terus-menerus, cocok untuk proses dengan durasi tidak diketahui. Browser menampilkan progress sebagai bilah berwarna yang terisi dari kiri ke kanan. Elemen ini berbeda dengan `<meter>` yang mengukur nilai statis dalam rentang; progress khusus untuk menunjukkan kemajuan tugas. Progress dapat diperbarui secara real-time dengan JavaScript untuk memberikan umpan balik visual selama proses seperti upload file, unduhan, atau rendering.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Tag Progress</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 500px; margin: auto; padding: 20px; }
    .progress-group { margin: 25px 0; padding: 20px; background: #f9f9f9; border-radius: 8px; text-align: center; }
    progress { width: 100%; height: 30px; border-radius: 5px; }
    progress::-webkit-progress-bar { background: #ecf0f1; border-radius: 5px; }
    progress::-webkit-progress-value { background: #3498db; border-radius: 5px; }
    progress::-moz-progress-bar { background: #3498db; border-radius: 5px; }
    .label { display: flex; justify-content: space-between; margin-bottom: 8px; }
    .label span { font-weight: bold; }
    button { padding: 10px 25px; background: #3498db; color: white; border: none; border-radius: 5px; cursor: pointer; font-size: 16px; margin-top: 15px; }
    button:disabled { background: #95a5a6; cursor: not-allowed; }
    .info { background: #ecf0f1; padding: 15px; border-radius: 8px; margin: 20px 0; }
  </style>
</head>
<body>
  <h1>Tag Progress - Indikator Kemajuan</h1>
  <div class="info">
    <p>Progress menunjukkan kemajuan tugas. Tanpa value, progress bersifat indeterminate (animasi terus).</p>
  </div>

  <div class="progress-group">
    <h3>Progress Determinate</h3>
    <div class="label">
      <span>Mengunduh file...</span>
      <span id="progressLabel">0%</span>
    </div>
    <progress id="downloadProgress" value="0" max="100"></progress>
    <br>
    <button id="mulaiBtn" onclick="mulaiDownload()">Mulai Unduh</button>
  </div>

  <div class="progress-group">
    <h3>Progress Indeterminate</h3>
    <p style="color:#7f8c8d;">Gunakan saat durasi proses tidak diketahui.</p>
    <progress id="indeterminate"></progress>
  </div>

  <script>
    function mulaiDownload() {
      const progress = document.getElementById('downloadProgress');
      const label = document.getElementById('progressLabel');
      const btn = document.getElementById('mulaiBtn');
      btn.disabled = true;
      btn.textContent = 'Mengunduh...';
      progress.value = 0;
      
      const interval = setInterval(() => {
        const increment = Math.floor(Math.random() * 10) + 1;
        let current = parseInt(progress.value) + increment;
        if (current >= 100) {
          current = 100;
          clearInterval(interval);
          btn.disabled = false;
          btn.textContent = 'Selesai!';
          setTimeout(() => { btn.textContent = 'Mulai Ulang'; }, 2000);
        }
        progress.value = current;
        label.textContent = current + '%';
      }, 400);
    }
  </script>
</body>
</html>
```

## Poin Penting
- Tag `<progress>` dengan atribut value dan max menampilkan kemajuan determinate (pasti)
- Tanpa atribut value, progress menampilkan animasi indeterminate untuk proses durasi tidak diketahui
- Perbarui nilai progress secara real-time dengan JavaScript untuk umpan balik visual
