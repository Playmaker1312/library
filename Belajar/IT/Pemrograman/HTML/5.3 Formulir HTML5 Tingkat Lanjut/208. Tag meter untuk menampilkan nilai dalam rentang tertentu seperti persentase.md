# Tag Meter Untuk Menampilkan Nilai Dalam Rentang Tertentu Seperti Persentase

## Analogi: Perpustakaan Digital

Seperti indikator bahan bakar pada mobil yang menunjukkan level bensin, tag meter menampilkan nilai dalam rentang tertentu secara visual. Ini cocok untuk menunjukkan persentase, level, atau pengukuran dalam batas yang diketahui.

## Penjelasan Detail

Tag `<meter>` adalah elemen HTML5 yang menampilkan nilai numerik dalam rentang yang diketahui. Atribut `value` menentukan nilai saat ini, `min` dan `max` menentukan rentang nilai (default 0 dan 1), `low` dan `high` menentukan ambang batas untuk indikasi visual, dan ` optimum` menentukan nilai optimal. Browser menampilkan meter sebagai bilah horizontal dengan perubahan warna: hijau di zona optimal, kuning di zona menengah, dan merah di zona rendah/tinggi jika nilai menyimpang dari optimum. Berbeda dengan `<progress>`, meter tidak menunjukkan kemajuan suatu tugas tetapi pengukuran statis dalam rentang. Elemen ini didukung oleh semua browser modern.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Tag Meter</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 600px; margin: auto; padding: 20px; }
    .meter-group { margin: 25px 0; padding: 15px; background: #f9f9f9; border-radius: 8px; }
    meter { width: 100%; height: 25px; }
    .label { display: flex; justify-content: space-between; margin-bottom: 5px; }
    .label span { font-weight: bold; color: #2c3e50; }
    .label .value { color: #7f8c8d; }
    .info { background: #ecf0f1; padding: 15px; border-radius: 8px; }
  </style>
</head>
<body>
  <h1>Tag Meter - Indikator Nilai</h1>
  <div class="info">
    <p>Meter menampilkan nilai dalam rentang dengan kode warna: hijau (optimal), kuning (hati-hati), merah (kurang/berlebih).</p>
  </div>

  <div class="meter-group">
    <div class="label"><span>Baterai</span><span class="value" id="bateraiLabel">75%</span></div>
    <meter id="baterai" value="75" min="0" max="100" low="20" high="80" optimum="100"></meter>
  </div>

  <div class="meter-group">
    <div class="label"><span>Penggunaan Disk</span><span class="value" id="diskLabel">45%</span></div>
    <meter id="disk" value="45" min="0" max="100" low="30" high="70" optimum="20"></meter>
  </div>

  <div class="meter-group">
    <div class="label"><span>Suhu CPU</span><span class="value" id="suhuLabel">65°C</span></div>
    <meter id="suhu" value="65" min="0" max="100" low="40" high="75" optimum="35"></meter>
  </div>

  <div class="meter-group">
    <div class="label"><span>Skor Keamanan</span><span class="value" id="skorLabel">92/100</span></div>
    <meter id="skor" value="92" min="0" max="100" low="40" high="80" optimum="100"></meter>
  </div>

  <script>
    // Demo interaktif: ubah nilai dengan slider
    const meters = document.querySelectorAll('meter');
    const labels = ['bateraiLabel', 'diskLabel', 'suhuLabel', 'skorLabel'];
    const values = [75, 45, 65, 92];
    meters.forEach((meter, i) => {
      setInterval(() => {
        const delta = (Math.random() - 0.5) * 10;
        let newVal = Math.max(0, Math.min(100, parseFloat(meter.value) + delta));
        meter.value = Math.round(newVal);
        document.getElementById(labels[i]).textContent = 
          i === 2 ? Math.round(newVal) + '°C' : 
          i === 3 ? Math.round(newVal) + '/100' : 
          Math.round(newVal) + '%';
      }, 3000);
    });
  </script>
</body>
</html>
```

## Poin Penting
- Tag `<meter>` menampilkan nilai dalam rentang dengan atribut value, min, max, low, high, optimum
- Warna meter berubah berdasarkan posisi nilai relatif terhadap low, high, dan optimum
- Berbeda dengan progress, meter untuk pengukuran statis bukan kemajuan tugas
