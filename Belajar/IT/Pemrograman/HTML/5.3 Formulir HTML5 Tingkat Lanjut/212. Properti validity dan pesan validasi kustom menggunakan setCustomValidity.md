# Properti Validity Dan Pesan Validasi Kustom Menggunakan SetCustomValidity

## Analogi: Perpustakaan Digital

Seperti petugas perpustakaan yang bisa menulis aturan khusus di luar ketentuan standar, `setCustomValidity()` memungkinkan Anda membuat pesan kesalahan kustom untuk validasi formulir. Properti `validity` memberikan informasi detail tentang jenis kesalahan validasi.

## Penjelasan Detail

Objek `validity` adalah properti dari elemen formulir yang berisi objek `ValidityState` dengan properti boolean yang menunjukkan jenis kesalahan validasi: `valueMissing` (required tidak diisi), `typeMismatch` (format salah), `patternMismatch` (tidak cocok pattern), `tooLong`/`tooShort` (panjang tidak sesuai), `rangeUnderflow`/`rangeOverflow` (nilai di luar rentang), `stepMismatch` (tidak sesuai step), `badInput` (input tidak dapat diubah), dan `valid` (semua valid). Metode `setCustomValidity(message)` pada elemen input memungkinkan Anda menetapkan pesan validasi kustom. Jika pesan tidak kosong, elemen dianggap tidak valid dan properti `validity.customError` menjadi `true`. Untuk mereset validasi kustom, panggil `setCustomValidity("")` dengan string kosong.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Validity & setCustomValidity</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 550px; margin: auto; padding: 20px; }
    .form-group { margin: 15px 0; }
    label { display: block; font-weight: bold; margin-bottom: 3px; }
    input { padding: 10px; width: 100%; max-width: 350px; border: 2px solid #ddd; border-radius: 5px; font-size: 16px; }
    input.valid { border-color: #27ae60; }
    input.invalid { border-color: #e74c3c; }
    .error-msg { color: #e74c3c; font-size: 0.85em; margin-top: 3px; display: none; }
    button { padding: 12px 30px; background: #3498db; color: white; border: none; border-radius: 5px; cursor: pointer; font-size: 16px; margin-top: 15px; }
    .validity-detail { background: #f9f9f9; padding: 15px; border-radius: 8px; margin: 20px 0; font-family: monospace; font-size: 0.85em; }
    .info { background: #ecf0f1; padding: 15px; border-radius: 8px; margin: 20px 0; }
  </style>
</head>
<body>
  <h1>Validity &amp; setCustomValidity</h1>
  <div class="info">
    <p>Properti <code>validity</code> menunjukkan detail kesalahan. <code>setCustomValidity()</code> membuat pesan validasi kustom.</p>
  </div>

  <form id="formValid">
    <div class="form-group">
      <label for="username">Username (4-12 karakter, huruf/angka):</label>
      <input type="text" id="username" required minlength="4" maxlength="12" pattern="[a-zA-Z0-9]+">
      <div class="error-msg" id="usernameError"></div>
    </div>
    <div class="form-group">
      <label for="konfirmasi">Ketik "SETUJU" untuk melanjutkan:</label>
      <input type="text" id="konfirmasi" required>
      <div class="error-msg" id="konfirmasiError"></div>
    </div>
    <button type="submit">Validasi</button>
  </form>

  <div class="validity-detail" id="detailValiditas">
    <strong>Detail validity.username:</strong><br>
    <span id="validityInfo">Belum ada data.</span>
  </div>

  <script>
    const form = document.getElementById('formValid');
    const username = document.getElementById('username');
    const konfirmasi = document.getElementById('konfirmasi');
    const usernameError = document.getElementById('usernameError');
    const konfirmasiError = document.getElementById('konfirmasiError');
    const validityInfo = document.getElementById('validityInfo');

    function validasiUsername() {
      username.classList.remove('valid', 'invalid');
      usernameError.style.display = 'none';
      username.setCustomValidity('');
      if (username.value && /[^a-zA-Z0-9]/.test(username.value)) {
        username.setCustomValidity('Username hanya boleh huruf dan angka.');
        usernameError.textContent = 'Username hanya boleh huruf dan angka.';
      } else if (username.value && username.value.length < 4) {
        username.setCustomValidity('Username minimal 4 karakter.');
        usernameError.textContent = 'Username minimal 4 karakter.';
      }
      if (!username.checkValidity()) {
        username.classList.add('invalid');
        if (username.validity.customError) usernameError.style.display = 'block';
      } else if (username.value) {
        username.classList.add('valid');
      }
      tampilkanDetail(username);
    }

    function validasiKonfirmasi() {
      konfirmasi.classList.remove('valid', 'invalid');
      konfirmasiError.style.display = 'none';
      konfirmasi.setCustomValidity('');
      if (konfirmasi.value && konfirmasi.value !== 'SETUJU') {
        konfirmasi.setCustomValidity('Ketik "SETUJU" tepat (huruf kapital).');
        konfirmasiError.textContent = 'Ketik "SETUJU" tepat (huruf kapital).';
        konfirmasi.classList.add('invalid');
        konfirmasiError.style.display = 'block';
      } else if (konfirmasi.value) {
        konfirmasi.classList.add('valid');
      }
    }

    function tampilkanDetail(el) {
      const v = el.validity;
      validityInfo.innerHTML = `
        valid: ${v.valid}<br>
        valueMissing: ${v.valueMissing}<br>
        patternMismatch: ${v.patternMismatch}<br>
        tooShort: ${v.tooShort}<br>
        tooLong: ${v.tooLong}<br>
        customError: ${v.customError}<br>
        typeMismatch: ${v.typeMismatch}
      `;
    }

    username.addEventListener('input', validasiUsername);
    konfirmasi.addEventListener('input', validasiKonfirmasi);

    form.addEventListener('submit', function(e) {
      e.preventDefault();
      validasiUsername();
      validasiKonfirmasi();
      if (form.checkValidity()) {
        alert('Semua validasi lolos! ✅');
        form.reset();
        username.classList.remove('valid');
        konfirmasi.classList.remove('valid');
      } else {
        form.reportValidity();
      }
    });
  </script>
</body>
</html>
```

## Poin Penting
- Properti `validity` berisi ValidityState dengan properti seperti valueMissing, patternMismatch, customError
- `setCustomValidity(pesan)` membuat pesan error kustom dan menandai elemen sebagai tidak valid
- Reset validasi kustom dengan memanggil `setCustomValidity("")` dengan string kosong
