# Teknik Desain Formulir Multi-Langkah Menggunakan HTML Dan JavaScript Dasar

## Analogi: Perpustakaan Digital

Seperti proses pendaftaran anggota perpustakaan yang dibagi menjadi beberapa tahap (isi data, verifikasi, cetak kartu), formulir multi-langkah memecah formulir panjang menjadi langkah-langkah kecil yang lebih mudah diisi pengguna.

## Penjelasan Detail

Formulir multi-langkah (wizard) meningkatkan pengalaman pengguna dengan membagi formulir panjang menjadi beberapa langkah terpisah. Setiap langkah ditampilkan satu per satu dengan navigasi "Sebelumnya" dan "Selanjutnya". Teknik implementasi meliputi: menyembunyikan semua langkah dengan CSS `display: none`, menampilkan langkah aktif, memvalidasi input sebelum pindah ke langkah berikutnya, dan menampilkan indikator kemajuan. Data dari setiap langkah dapat disimpan sementara di objek JavaScript atau dikumpulkan saat submit. Formulir multi-langkah sangat berguna untuk pendaftaran, checkout, survei panjang, dan pengaturan profil. Validasi per langkah mencegah pengguna melanjutkan jika ada kesalahan, mengurangi frustrasi dibandingkan formulir panjang dengan banyak error sekaligus.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Formulir Multi-Langkah</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 550px; margin: auto; padding: 20px; }
    .step { display: none; }
    .step.active { display: block; }
    .step-indicator { display: flex; justify-content: center; gap: 10px; margin: 20px 0; }
    .step-dot { width: 35px; height: 35px; border-radius: 50%; background: #ddd; display: flex; align-items: center; justify-content: center; font-weight: bold; color: white; }
    .step-dot.active { background: #3498db; }
    .step-dot.completed { background: #27ae60; }
    .step-dot .num { font-size: 14px; }
    .form-group { margin: 15px 0; }
    label { display: block; font-weight: bold; margin-bottom: 3px; }
    input, select { padding: 10px; width: 100%; max-width: 350px; border: 2px solid #ddd; border-radius: 5px; font-size: 16px; }
    input:focus { outline: none; border-color: #3498db; }
    .btn-group { display: flex; gap: 10px; margin-top: 20px; }
    button { padding: 12px 25px; border: none; border-radius: 5px; cursor: pointer; font-size: 16px; }
    .btn-next { background: #3498db; color: white; }
    .btn-prev { background: #95a5a6; color: white; }
    .btn-submit { background: #27ae60; color: white; }
    .error-msg { color: #e74c3c; font-size: 0.85em; display: none; }
    .review { background: #f9f9f9; padding: 15px; border-radius: 8px; }
  </style>
</head>
<body>
  <h1>Formulir Multi-Langkah</h1>

  <div class="step-indicator">
    <div class="step-dot active" id="dot1"><span class="num">1</span></div>
    <div class="step-dot" id="dot2"><span class="num">2</span></div>
    <div class="step-dot" id="dot3"><span class="num">3</span></div>
  </div>

  <form id="multiStepForm">
    <!-- Langkah 1 -->
    <div class="step active" id="step1">
      <h3>Langkah 1: Data Pribadi</h3>
      <div class="form-group">
        <label for="sNama">Nama Lengkap:</label>
        <input type="text" id="sNama" required minlength="3">
      </div>
      <div class="form-group">
        <label for="sEmail">Email:</label>
        <input type="email" id="sEmail" required>
      </div>
    </div>

    <!-- Langkah 2 -->
    <div class="step" id="step2">
      <h3>Langkah 2: Detail Akun</h3>
      <div class="form-group">
        <label for="sUsername">Username:</label>
        <input type="text" id="sUsername" required minlength="4">
      </div>
      <div class="form-group">
        <label for="sPassword">Password (min 6 karakter):</label>
        <input type="password" id="sPassword" required minlength="6">
      </div>
    </div>

    <!-- Langkah 3 -->
    <div class="step" id="step3">
      <h3>Langkah 3: Konfirmasi</h3>
      <div class="review" id="reviewData"></div>
    </div>

    <div class="btn-group">
      <button type="button" class="btn-prev" id="prevBtn" onclick="prevStep()">Sebelumnya</button>
      <button type="button" class="btn-next" id="nextBtn" onclick="nextStep()">Selanjutnya</button>
      <button type="submit" class="btn-submit" id="submitBtn" style="display:none;">Kirim</button>
    </div>
  </form>

  <script>
    let currentStep = 1;
    const totalSteps = 3;

    function showStep(step) {
      document.querySelectorAll('.step').forEach(s => s.classList.remove('active'));
      document.getElementById('step' + step).classList.add('active');
      for (let i = 1; i <= totalSteps; i++) {
        const dot = document.getElementById('dot' + i);
        dot.classList.remove('active', 'completed');
        if (i === step) dot.classList.add('active');
        else if (i < step) dot.classList.add('completed');
      }
      document.getElementById('prevBtn').style.display = step === 1 ? 'none' : 'inline-block';
      document.getElementById('nextBtn').style.display = step === totalSteps ? 'none' : 'inline-block';
      document.getElementById('submitBtn').style.display = step === totalSteps ? 'inline-block' : 'none';
      if (step === totalSteps) updateReview();
    }

    function nextStep() {
      const inputs = document.querySelectorAll('#step' + currentStep + ' input[required]');
      let valid = true;
      inputs.forEach(inp => { if (!inp.checkValidity()) valid = false; });
      if (!valid) { alert('Harap isi semua bidang yang wajib.'); return; }
      if (currentStep < totalSteps) { currentStep++; showStep(currentStep); }
    }

    function prevStep() {
      if (currentStep > 1) { currentStep--; showStep(currentStep); }
    }

    function updateReview() {
      const data = {
        nama: document.getElementById('sNama').value,
        email: document.getElementById('sEmail').value,
        username: document.getElementById('sUsername').value
      };
      document.getElementById('reviewData').innerHTML = `
        <p><strong>Nama:</strong> ${data.nama}</p>
        <p><strong>Email:</strong> ${data.email}</p>
        <p><strong>Username:</strong> ${data.username}</p>
      `;
    }

    document.getElementById('multiStepForm').addEventListener('submit', function(e) {
      e.preventDefault();
      alert('Pendaftaran berhasil! Data telah dikirim. ✅');
    });

    showStep(1);
  </script>
</body>
</html>
```

## Poin Penting
- Formulir multi-langkah membagi formulir panjang menjadi langkah-langkah kecil yang lebih mudah diisi
- Validasi per langkah mencegah pengguna melanjutkan jika ada kesalahan
- Indikator langkah (step indicator) membantu pengguna mengetahui posisi mereka dalam proses
