# Atribut Type Datetime-Local Pada Input Untuk Pemilih Tanggal Dan Waktu Lokal

## Analogi: Perpustakaan Digital

Seperti formulir pemesanan ruang rapat yang membutuhkan tanggal dan jam sekaligus, input datetime-local menyediakan antarmuka untuk memilih tanggal dan waktu secara bersamaan tanpa informasi zona waktu.

## Penjelasan Detail

Input dengan `type="datetime-local""` menampilkan pemilih tanggal dan waktu lokal bawaan browser, menggabungkan fungsi date picker dan time picker dalam satu kontrol. Nilai dikembalikan dalam format `yyyy-mm-ddThh:mm` (ISO 8601 tanpa zona waktu), misalnya `2026-05-23T14:30`. Berbeda dengan `type="datetime"` (yang sudah dihapus dari spesifikasi), datetime-local tidak menyertakan informasi zona waktu. Atribut `min` dan `max` membatasi rentang tanggal/waktu yang dapat dipilih, dan `step` mengontrol interval menit. Browser yang tidak mendukung akan menampilkan input teks biasa. Input ini ideal untuk formulir pemesanan, penjadwalan acara, dan pengaturan janji temu.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Input Datetime-Local</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 500px; margin: auto; padding: 20px; }
    .form-group { margin: 25px 0; padding: 20px; background: #f9f9f9; border-radius: 8px; }
    label { display: block; font-weight: bold; margin-bottom: 5px; color: #2c3e50; }
    input[type="datetime-local"] { padding: 10px; font-size: 16px; border: 2px solid #3498db; border-radius: 5px; width: 100%; max-width: 280px; }
    .info { background: #e8f4f8; padding: 15px; border-radius: 8px; margin: 20px 0; }
    .result { margin-top: 10px; padding: 10px; background: #d4edda; border-radius: 5px; display: none; }
    code { background: #f4f4f4; padding: 2px 6px; border-radius: 3px; }
  </style>
</head>
<body>
  <h1>Input Datetime-Local</h1>
  <div class="info">
    <p>Pilih tanggal dan waktu untuk janji temu. Format nilai: <code>yyyy-mm-ddThh:mm</code></p>
  </div>
  <div class="form-group">
    <label for="appointment">Jadwalkan Janji Temu:</label>
    <input type="datetime-local" id="appointment" value="2026-05-23T10:00">
    <div class="result" id="result">Janji temu dijadwalkan pada: <strong id="resultValue"></strong></div>
  </div>
  <p style="color:#7f8c8d;">Gunakan atribut <code>min</code> dan <code>max</code> untuk membatasi rentang tanggal yang dapat dipilih.</p>
  <script>
    const input = document.getElementById('appointment');
    const result = document.getElementById('result');
    const resultValue = document.getElementById('resultValue');
    input.addEventListener('change', function() {
      const val = this.value;
      if (val) {
        const date = new Date(val);
        resultValue.textContent = date.toLocaleString('id-ID', { dateStyle: 'long', timeStyle: 'short' });
        result.style.display = 'block';
      } else {
        result.style.display = 'none';
      }
    });
    input.dispatchEvent(new Event('change'));
  </script>
</body>
</html>
```

## Poin Penting
- Input `type="datetime-local"` menggabungkan date picker dan time picker dalam satu kontrol
- Nilai dikembalikan dalam format ISO `yyyy-mm-ddThh:mm` tanpa informasi zona waktu
- Atribut min, max, dan step membatasi rentang dan interval nilai yang dapat dipilih
