# Tag Datalist Untuk Menyediakan Saran Otomatis Pada Input Teks

## Analogi: Perpustakaan Digital

Seperti mesin katalog yang memberikan saran judul buku saat Anda mulai mengetik, tag datalist menampilkan daftar saran yang muncul saat pengguna mengetik di input. Ini membantu pengguna menemukan pilihan dengan cepat tanpa harus mengetik lengkap.

## Penjelasan Detail

Tag `<datalist>` adalah elemen HTML5 yang menyediakan daftar opsi yang sudah ditentukan sebelumnya untuk elemen `<input>`. Datalist dihubungkan ke input melalui atribut `list` pada input yang merujuk ke `id` datalist. Saat pengguna mengetik, browser menampilkan dropdown saran yang sesuai berdasarkan teks yang diketik. Opsi dalam datalist didefinisikan dengan elemen `<option>` yang memiliki atribut `value` (nilai yang dimasukkan) dan opsional `label` (teks deskriptif). Berbeda dengan `<select>`, datalist tidak membatasi pengguna pada opsi yang tersedia; pengguna tetap dapat memasukkan nilai kustom. Datalist didukung oleh semua browser modern dan bekerja dengan berbagai tipe input seperti text, search, url, email, dan color.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Tag Datalist</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 500px; margin: auto; padding: 20px; }
    .form-group { margin: 25px 0; }
    label { display: block; font-weight: bold; margin-bottom: 5px; color: #2c3e50; }
    input { padding: 10px; font-size: 16px; border: 2px solid #3498db; border-radius: 5px; width: 100%; max-width: 350px; }
    input:focus { outline: none; box-shadow: 0 0 5px rgba(52,152,219,0.3); }
    .info { background: #e8f4f8; padding: 15px; border-radius: 8px; margin: 20px 0; }
    .result { margin-top: 10px; padding: 10px; background: #f0f0f0; border-radius: 5px; }
  </style>
</head>
<body>
  <h1>Tag Datalist - Saran Otomatis</h1>
  <div class="info">
    <p>Mulai mengetik untuk melihat saran. Anda tetap dapat memasukkan nilai kustom.</p>
  </div>

  <div class="form-group">
    <label for="negara">Pilih Negara:</label>
    <input type="text" id="negara" list="negara-list" placeholder="Ketik nama negara...">
    <datalist id="negara-list">
      <option value="Indonesia">
      <option value="Malaysia">
      <option value="Singapura">
      <option value="Thailand">
      <option value="Vietnam">
      <option value="Filipina">
      <option value="Brunei">
      <option value="Myanmar">
      <option value="Kamboja">
      <option value="Laos">
    </datalist>
  </div>

  <div class="form-group">
    <label for="warna">Pilih Warna Favorit:</label>
    <input type="text" id="warna" list="warna-list" placeholder="Ketik nama warna...">
    <datalist id="warna-list">
      <option value="Merah">
      <option value="Biru">
      <option value="Hijau">
      <option value="Kuning">
      <option value="Ungu">
      <option value="Hitam">
      <option value="Putih">
      <option value="Coklat">
    </datalist>
  </div>

  <div class="result" id="result">Pilihan Anda akan muncul di sini.</div>
  <script>
    const inputs = document.querySelectorAll('input[list]');
    inputs.forEach(input => {
      input.addEventListener('change', function() {
        document.getElementById('result').textContent = 'Anda memilih: ' + this.value;
      });
    });
  </script>
</body>
</html>
```

## Poin Penting
- Datalist dihubungkan ke input dengan atribut `list` yang merujuk ke `id` datalist
- Opsi didefinisikan dengan elemen `<option>`, pengguna tetap bisa memasukkan nilai kustom
- Berbeda dengan `<select>`, datalist hanya memberikan saran tanpa membatasi pilihan
