# Constraint Validation API Untuk Validasi Formulir Yang Lebih Detail Dengan JavaScript

## Analogi: Perpustakaan Digital

Seperti petugas perpustakaan yang memeriksa kelengkapan formulir pendaftaran secara detail sebelum diterima, Constraint Validation API memberikan kontrol penuh atas validasi formulir. Anda dapat memeriksa validitas setiap bidang secara individual dengan JavaScript.

## Penjelasan Detail

Constraint Validation API adalah antarmuka JavaScript yang memungkinkan pemeriksaan dan kontrol validasi formulir HTML5 secara detail. API ini menyediakan properti dan metode untuk memeriksa validitas elemen formulir. Properti `willValidate` mengembalikan true jika elemen akan divalidasi. Metode `checkValidity()` mengembalikan boolean dan memicu event `invalid` jika tidak valid. `reportValidity()` melakukan hal yang sama tetapi juga menampilkan pesan validasi bawaan browser. API ini memungkinkan validasi sisi klien yang lebih canggih dengan umpan balik kustom tanpa mengandalkan sepenuhnya pada atribut HTML atau event submit.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Constraint Validation API</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 500px; margin: auto; padding: 20px; }
    .form-group { margin: 15px 0; }
    label { display: block; font-weight: bold; margin-bottom: 3px; }
    input { padding: 10px; width: 100%; max-width: 350px; border: 2px solid #ddd; border-radius: 5px; font-size: 16px; }
    input:focus { outline: none; }
    input.valid { border-color: #27ae60; }
    input.invalid { border-color: #e74c3c; }
    .error-msg { color: #e74c3c; font-size: 0.85em; margin-top: 3px; display: none; }
    button { padding: 12px 30px; background: #3498db; color: white; border: none; border-radius: 5px; cursor: pointer; font-size: 16px; margin-top: 15px; }
    .info { background: #ecf0f1; padding: 15px; border-radius: 8px; margin: 20px 0; }
  </style>
</head>
<body>
  <h1>Constraint Validation API</h1>
  <div class="info">
    <p>Validasi dilakukan saat input berubah menggunakan Constraint Validation API.</p>
  </div>

  <form id="myForm">
    <div class="form-group">
      <label for="nama">Nama Lengkap (min 3 karakter):</label>
      <input type="text" id="nama" required minlength="3">
      <div class="error-msg" id="namaError">Nama minimal 3 karakter.</div>
    </div>
    <div class="form-group">
      <label for="email">Email:</label>
      <input type="email" id="email" required>
      <div class="error-msg" id="emailError">Masukkan email yang valid.</div>
    </div>
    <div class="form-group">
      <label for="usia">Usia (18-100):</label>
      <input type="number" id="usia" required min="18" max="100">
      <div class="error-msg" id="usiaError">Usia harus antara 18-100.</div>
    </div>
    <div class="form-group">
      <label for="kodePos">Kode Pos (5 digit):</label>
      <input type="text" id="kodePos" required pattern="[0-9]{5}">
      <div class="error-msg" id="kodePosError">Kode pos harus 5 digit angka.</div>
    </div>
    <button type="submit">Kirim</button>
  </form>

  <script>
    const form = document.getElementById('myForm');
    const inputs = form.querySelectorAll('input');

    function validasiInput(input) {
      const errorEl = document.getElementById(input.id + 'Error');
      input.classList.remove('valid', 'invalid');
      if (input.checkValidity()) {
        input.classList.add('valid');
        errorEl.style.display = 'none';
      } else {
        input.classList.add('invalid');
        errorEl.style.display = 'block';
      }
    }

    inputs.forEach(input => {
      input.addEventListener('input', () => validasiInput(input));
      validasiInput(input);
    });

    form.addEventListener('submit', function(e) {
      e.preventDefault();
      let valid = true;
      inputs.forEach(input => {
        validasiInput(input);
        if (!input.checkValidity()) valid = false;
      });
      if (valid) {
        alert('Formulir valid! Data siap dikirim.');
        form.reset();
        inputs.forEach(input => validasiInput(input));
      }
    });
  </script>
</body>
</html>
```

## Poin Penting
- `checkValidity()` mengembalikan boolean dan memicu event invalid jika tidak valid
- Atribut validasi HTML (required, minlength, pattern, dll) dapat diperiksa secara programatik
- API ini memungkinkan validasi real-time dengan umpan balik visual kustom
