# Metode CheckValidity Dan ReportValidity Pada Elemen Formulir

## Analogi: Perpustakaan Digital

Seperti dua petugas validasi: satu hanya memberi tahu apakah formulir sudah benar, dan satu lagi memberi tahu sambil menunjukkan bagian yang salah. checkValidity memeriksa tanpa menampilkan pesan, reportValidity memeriksa dan menampilkan pesan error bawaan browser.

## Penjelasan Detail

Metode `checkValidity()` dan `reportValidity()` adalah bagian dari Constraint Validation API HTML5. `checkValidity()` mengembalikan nilai boolean: `true` jika elemen lolos validasi, `false` jika tidak. Saat mengembalikan `false`, metode ini juga memicu event `invalid` pada elemen tersebut. `reportValidity()` melakukan hal yang sama tetapi juga menampilkan pesan validasi bawaan browser (tooltip atau balon) yang menjelaskan kesalahan. Kedua metode dapat dipanggil pada elemen input individual atau pada elemen form secara keseluruhan. Pada form, `checkValidity()` mengembalikan `true` hanya jika semua elemen di dalamnya valid, sementara `reportValidity()` juga menampilkan pesan error pada elemen pertama yang tidak valid.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>checkValidity vs reportValidity</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 500px; margin: auto; padding: 20px; }
    .form-group { margin: 15px 0; }
    label { display: block; font-weight: bold; margin-bottom: 3px; }
    input { padding: 10px; width: 100%; max-width: 350px; border: 2px solid #ddd; border-radius: 5px; font-size: 16px; }
    input.valid { border-color: #27ae60; }
    input.invalid { border-color: #e74c3c; }
    button { padding: 10px 20px; margin: 5px; border: none; border-radius: 5px; cursor: pointer; font-size: 14px; }
    .btn-check { background: #3498db; color: white; }
    .btn-report { background: #e67e22; color: white; }
    .btn-submit { background: #27ae60; color: white; }
    .info { background: #ecf0f1; padding: 15px; border-radius: 8px; margin: 20px 0; }
    .log { margin-top: 15px; padding: 15px; background: #f9f9f9; border-radius: 8px; min-height: 50px; white-space: pre-wrap; font-family: monospace; }
    .field-row { display: flex; gap: 10px; align-items: center; }
  </style>
</head>
<body>
  <h1>checkValidity vs reportValidity</h1>
  <div class="info">
    <p><strong>checkValidity()</strong> mengembalikan boolean tanpa menampilkan pesan.<br>
    <strong>reportValidity()</strong> mengembalikan boolean dan menampilkan pesan error browser.</p>
  </div>

  <form id="demoForm">
    <div class="form-group">
      <label for="nama">Nama (required):</label>
      <input type="text" id="nama" required placeholder="Isi nama Anda">
    </div>
    <div class="form-group">
      <label for="email">Email (required, valid format):</label>
      <input type="email" id="email" required placeholder="contoh@email.com">
    </div>
    <div class="form-group">
      <label for="umur">Umur (18-65):</label>
      <input type="number" id="umur" min="18" max="65" placeholder="18-65">
    </div>
    
    <button type="button" class="btn-check" onclick="cekValiditas()">checkValidity()</button>
    <button type="button" class="btn-report" onclick="laporValiditas()">reportValidity()</button>
    <button type="submit" class="btn-submit">Submit (report)</button>
  </form>

  <div class="log" id="log">Hasil akan muncul di sini...</div>

  <script>
    const form = document.getElementById('demoForm');
    const log = document.getElementById('log');
    const inputs = form.querySelectorAll('input');

    function updateBorder(input) {
      input.classList.remove('valid', 'invalid');
      if (input.value.trim() === '') { return; }
      if (input.checkValidity()) input.classList.add('valid');
      else input.classList.add('invalid');
    }

    inputs.forEach(input => input.addEventListener('input', () => updateBorder(input)));

    function cekValiditas() {
      const valid = form.checkValidity();
      log.textContent = `form.checkValidity() = ${valid}\n\n`;
      inputs.forEach(input => {
        const v = input.checkValidity();
        log.textContent += `${input.id}: checkValidity() = ${v}\n`;
        updateBorder(input);
      });
    }

    function laporValiditas() {
      const valid = form.reportValidity();
      log.textContent = `form.reportValidity() = ${valid}\n(Menampilkan pesan error browser)`;
      inputs.forEach(input => updateBorder(input));
    }

    form.addEventListener('submit', function(e) {
      e.preventDefault();
      if (form.reportValidity()) {
        log.textContent = 'Form valid! Data siap dikirim. ✅';
      }
    });
  </script>
</body>
</html>
```

## Poin Penting
- `checkValidity()` mengembalikan boolean tanpa umpan balik visual ke pengguna
- `reportValidity()` mengembalikan boolean dan menampilkan pesan error bawaan browser
- Keduanya dapat dipanggil pada elemen individual atau objek form secara keseluruhan
