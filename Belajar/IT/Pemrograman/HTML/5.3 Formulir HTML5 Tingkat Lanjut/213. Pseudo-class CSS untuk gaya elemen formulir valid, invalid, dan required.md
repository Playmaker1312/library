# Pseudo-Class CSS Untuk Gaya Elemen Formulir Valid, Invalid, Dan Required

## Analogi: Perpustakaan Digital

Seperti stiker warna-warni yang ditempel pada buku: hijau untuk buku tersedia, merah untuk buku rusak, dan kuning untuk buku yang perlu ditandai. Pseudo-class CSS memberikan kode warna visual pada elemen formulir berdasarkan status validasinya.

## Penjelasan Detail

CSS menyediakan pseudo-class khusus untuk elemen formulir HTML5 yang mencerminkan status validasinya. `:valid` diterapkan saat elemen memenuhi semua constraint validasi, `:invalid` saat tidak memenuhi, dan `:required` untuk elemen dengan atribut required. Pseudo-class `:optional` untuk elemen tanpa required, `:in-range` dan `:out-of-range` untuk nilai dalam/luar rentang min-max, `:read-only` dan `:read-write` untuk status readonly. Pseudo-class ini memungkinkan styling otomatis tanpa JavaScript, memberikan umpan balik visual real-time saat pengguna mengisi formulir. Browser juga menerapkan gaya default untuk `:invalid`, yang bisa dioverride dengan CSS.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Pseudo-class CSS Formulir</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 500px; margin: auto; padding: 20px; }
    .form-group { margin: 20px 0; }
    label { display: block; font-weight: bold; margin-bottom: 5px; color: #2c3e50; }
    input, select { padding: 10px; width: 100%; max-width: 350px; border: 2px solid #ddd; border-radius: 5px; font-size: 16px; transition: border-color 0.3s, box-shadow 0.3s; }
    input:focus, select:focus { outline: none; }

    /* Pseudo-class styling */
    input:required { border-left: 4px solid #f39c12; }
    input:optional { border-left: 4px solid #95a5a6; }
    input:valid { border-color: #27ae60; }
    input:invalid { border-color: #e74c3c; }
    input:in-range { background: #f0fdf4; }
    input:out-of-range { background: #fef2f2; }
    select:valid { border-color: #27ae60; }
    select:invalid { border-color: #e74c3c; }
    input:read-only { background: #f3f3f3; border-style: dashed; }

    .error-msg { color: #e74c3c; font-size: 0.85em; margin-top: 3px; display: none; }
    input:invalid + .error-msg { display: block; }
    button { padding: 12px 30px; background: #3498db; color: white; border: none; border-radius: 5px; cursor: pointer; font-size: 16px; margin-top: 15px; }
    .info { background: #ecf0f1; padding: 15px; border-radius: 8px; margin: 20px 0; }
    .legend { display: flex; gap: 15px; flex-wrap: wrap; margin: 15px 0; }
    .legend-item { display: flex; align-items: center; gap: 5px; font-size: 0.85em; }
    .legend-item .dot { width: 12px; height: 12px; border-radius: 3px; }
  </style>
</head>
<body>
  <h1>Pseudo-class CSS Formulir</h1>
  <div class="info">
    <p>Styling otomatis dengan pseudo-class: <code>:valid</code>, <code>:invalid</code>, <code>:required</code>, <code>:in-range</code>, dll. Tanpa JavaScript!</p>
  </div>

  <div class="legend">
    <span class="legend-item"><span class="dot" style="background:#27ae60;"></span> :valid</span>
    <span class="legend-item"><span class="dot" style="background:#e74c3c;"></span> :invalid</span>
    <span class="legend-item"><span class="dot" style="background:#f39c12;"></span> :required</span>
    <span class="legend-item"><span class="dot" style="background:#95a5a6;"></span> :optional</span>
  </div>

  <form>
    <div class="form-group">
      <label for="nama">Nama (required):</label>
      <input type="text" id="nama" required placeholder="Minimal 3 karakter" minlength="3">
      <div class="error-msg">Nama minimal 3 karakter.</div>
    </div>
    <div class="form-group">
      <label for="email">Email (required):</label>
      <input type="email" id="email" required placeholder="contoh@email.com">
      <div class="error-msg">Masukkan email yang valid.</div>
    </div>
    <div class="form-group">
      <label for="usia">Usia (optional, 18-65):</label>
      <input type="number" id="usia" min="18" max="65" placeholder="18-65">
    </div>
    <div class="form-group">
      <label for="kota">Kota (required):</label>
      <select id="kota" required>
        <option value="">Pilih kota...</option>
        <option value="Jakarta">Jakarta</option>
        <option value="Bandung">Bandung</option>
        <option value="Surabaya">Surabaya</option>
      </select>
    </div>
    <button type="submit">Kirim</button>
  </form>

  <script>
    // Prevent form submit for demo
    document.querySelector('form').addEventListener('submit', function(e) {
      e.preventDefault();
      if (this.checkValidity()) alert('Form valid! ✅');
    });
  </script>
</body>
</html>
```

## Poin Penting
- Pseudo-class `:valid`, `:invalid`, `:required`, `:optional` memberikan gaya otomatis tanpa JavaScript
- `:in-range` dan `:out-of-range` untuk input number dengan atribut min/max
- Pseudo-class ini bekerja real-time saat pengguna mengetik dan mengisi formulir
