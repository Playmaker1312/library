# Tag Output Untuk Menampilkan Hasil Kalkulasi Dari Elemen Formulir

## Analogi: Perpustakaan Digital

Seperti kalkulator yang menampilkan hasil perhitungan di layar, tag output menampilkan hasil kalkulasi dari elemen-elemen formulir. Ini adalah cara semantik untuk menampilkan nilai yang dihasilkan dari interaksi pengguna.

## Penjelasan Detail

Tag `<output>` adalah elemen HTML5 semantik yang dirancang untuk menampilkan hasil kalkulasi atau keluaran dari elemen formulir. Atribut `for` pada output merujuk ke ID elemen-elemen yang mempengaruhinya, menghubungkan output dengan input terkait secara semantik. Nilai output dapat diperbarui secara dinamis dengan JavaScript melalui properti `value` atau `textContent`. Elemen output juga memiliki properti `defaultValue` yang menyimpan nilai awal. Meskipun secara visual mirip dengan `<span>`, penggunaan `<output>` memberikan makna semantik yang membantu aksesibilitas. Elemen ini tidak memiliki perilaku bawaan untuk menghitung; logika kalkulasi tetap harus ditulis dengan JavaScript.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Tag Output</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 500px; margin: auto; padding: 20px; }
    .form-group { margin: 20px 0; padding: 20px; background: #f9f9f9; border-radius: 8px; }
    label { display: inline-block; width: 120px; font-weight: bold; }
    input[type="number"] { padding: 8px; width: 100px; border: 2px solid #3498db; border-radius: 5px; font-size: 16px; }
    input[type="range"] { width: 200px; vertical-align: middle; }
    .result-box { margin-top: 15px; padding: 15px; background: #e8f4f8; border-radius: 8px; text-align: center; }
    output { font-size: 2em; font-weight: bold; color: #2c3e50; }
    .info { background: #ecf0f1; padding: 15px; border-radius: 8px; margin: 20px 0; }
    select { padding: 8px; border: 2px solid #3498db; border-radius: 5px; font-size: 16px; }
  </style>
</head>
<body>
  <h1>Tag Output - Hasil Kalkulasi</h1>
  <div class="info">
    <p>Hasil perhitungan ditampilkan dalam elemen <code>&lt;output&gt;</code> yang diperbarui secara real-time.</p>
  </div>

  <div class="form-group">
    <h3>Kalkulator Sederhana</h3>
    <label>Angka 1:</label>
    <input type="number" id="angka1" value="10"><br><br>
    <label>Angka 2:</label>
    <input type="number" id="angka2" value="5"><br><br>
    <label>Operasi:</label>
    <select id="operasi">
      <option value="+">Tambah (+)</option>
      <option value="-">Kurang (-)</option>
      <option value="*">Kali (×)</option>
      <option value="/">Bagi (÷)</option>
    </select>
    <div class="result-box">
      Hasil: <output id="hasil" for="angka1 angka2 operasi">15</output>
    </div>
  </div>

  <script>
    const angka1 = document.getElementById('angka1');
    const angka2 = document.getElementById('angka2');
    const operasi = document.getElementById('operasi');
    const hasil = document.getElementById('hasil');

    function hitung() {
      const a = parseFloat(angka1.value) || 0;
      const b = parseFloat(angka2.value) || 0;
      const op = operasi.value;
      let res = 0;
      switch(op) {
        case '+': res = a + b; break;
        case '-': res = a - b; break;
        case '*': res = a * b; break;
        case '/': res = b !== 0 ? a / b : 'Error'; break;
      }
      hasil.value = res;
    }

    angka1.addEventListener('input', hitung);
    angka2.addEventListener('input', hitung);
    operasi.addEventListener('change', hitung);
  </script>
</body>
</html>
```

## Poin Penting
- Tag `<output>` secara semantik menampilkan hasil kalkulasi dari elemen formulir
- Atribut `for` menghubungkan output dengan elemen input yang mempengaruhinya
- Logika kalkulasi ditulis dengan JavaScript, output hanya menampilkan nilai
