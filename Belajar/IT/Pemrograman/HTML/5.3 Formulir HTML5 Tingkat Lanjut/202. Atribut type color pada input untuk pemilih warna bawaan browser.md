# Atribut Type Color Pada Input Untuk Pemilih Warna Bawaan Browser

## Analogi: Perpustakaan Digital

Seperti palet cat yang bisa dipilih untuk menandai buku, input type color menyediakan pemilih warna bawaan browser. Pengguna dapat memilih warna dengan antarmuka visual tanpa perlu membuat komponen pemilih warna sendiri.

## Penjelasan Detail

Input dengan `type="color"` menampilkan pemilih warna (color picker) bawaan browser saat diklik. Nilai yang dikembalikan adalah string dalam format heksadesimal `#rrggbb` (6 digit). Atribut `value` dapat digunakan untuk menetapkan warna default, dan harus dalam format heksadesimal valid dengan tanda `#`. Ukuran tampilan color picker dapat disesuaikan dengan CSS. Aktivitas pemilihan warna memicu event `input` secara real-time saat pengguna memilih warna, dan event `change` saat pemilih ditutup. Input color didukung oleh semua browser modern dan menyediakan pengalaman yang konsisten. Nilai warna default adalah `#000000` (hitam) jika tidak ditentukan.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Input Type Color</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 500px; margin: auto; padding: 20px; text-align: center; }
    .color-demo { margin: 30px 0; }
    input[type="color"] { width: 80px; height: 80px; border: 3px solid #ddd; border-radius: 10px; cursor: pointer; padding: 0; }
    input[type="color"]::-webkit-color-swatch-wrapper { padding: 0; }
    input[type="color"]::-webkit-color-swatch { border: none; border-radius: 7px; }
    .preview { width: 200px; height: 200px; margin: 20px auto; border-radius: 15px; border: 3px solid #ddd; transition: background 0.2s; display: flex; align-items: center; justify-content: center; }
    .preview span { background: rgba(255,255,255,0.8); padding: 10px 20px; border-radius: 8px; font-family: monospace; font-size: 1.2em; }
    .info { background: #ecf0f1; padding: 15px; border-radius: 8px; }
  </style>
</head>
<body>
  <h1>Input Type Color</h1>
  <p>Klik kotak warna di bawah untuk membuka pemilih warna browser.</p>
  <div class="color-demo">
    <input type="color" id="colorPicker" value="#3498db">
  </div>
  <div class="preview" id="previewBox" style="background:#3498db;">
    <span id="hexValue">#3498db</span>
  </div>
  <div class="info">
    <p>Nilai heksadesimal: <strong id="hexDisplay">#3498db</strong></p>
    <p>Event <code>input</code> dipicu real-time saat pengguna memilih warna.</p>
  </div>
  <script>
    const colorPicker = document.getElementById('colorPicker');
    const previewBox = document.getElementById('previewBox');
    const hexValue = document.getElementById('hexValue');
    const hexDisplay = document.getElementById('hexDisplay');
    colorPicker.addEventListener('input', function() {
      const color = this.value;
      previewBox.style.background = color;
      hexValue.textContent = color;
      hexDisplay.textContent = color;
    });
  </script>
</body>
</html>
```

## Poin Penting
- Input `type="color"` menyediakan pemilih warna bawaan browser tanpa library tambahan
- Nilai dikembalikan dalam format heksadesimal `#rrggbb` dengan 6 digit
- Event `input` dipicu real-time, event `change` saat pemilih ditutup
