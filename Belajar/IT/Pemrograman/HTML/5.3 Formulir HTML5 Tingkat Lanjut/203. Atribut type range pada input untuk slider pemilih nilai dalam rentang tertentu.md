# Atribut Type Range Pada Input Untuk Slider Pemilih Nilai Dalam Rentang Tertentu

## Analogi: Perpustakaan Digital

Seperti penggeser volume pada radio yang bisa digerakkan ke kiri atau kanan, input type range menampilkan slider untuk memilih nilai dalam rentang tertentu. Pengguna dapat menyesuaikan nilai secara visual dan intuitif.

## Penjelasan Detail

Input dengan `type="range"` menampilkan kontrol slider horizontal (atau vertikal dengan CSS) yang memungkinkan pengguna memilih nilai numerik dalam rentang tertentu. Atribut `min` dan `max` menentukan batas bawah dan atas (default 0 dan 100), atribut `step` menentukan interval kenaikan (default 1), dan `value` menetapkan nilai awal. Input range memicu event `input` secara real-time saat slider digerakkan, dan event `change` saat pengguna melepaskan slider. Tampilan slider dapat dikustomisasi dengan CSS menggunakan pseudo-elemen `::-webkit-slider-thumb`, `::-moz-range-thumb`, dan `::-ms-thumb`. Input range ideal untuk kontrol volume, kecerahan, filter, atau pengaturan lain yang membutuhkan penyesuaian bertahap.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Input Type Range</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 500px; margin: auto; padding: 20px; text-align: center; }
    .slider-group { margin: 30px 0; }
    input[type="range"] { width: 100%; height: 8px; -webkit-appearance: none; background: #ddd; border-radius: 4px; outline: none; }
    input[type="range"]::-webkit-slider-thumb { -webkit-appearance: none; width: 22px; height: 22px; border-radius: 50%; background: #3498db; cursor: pointer; }
    input[type="range"]::-moz-range-thumb { width: 22px; height: 22px; border-radius: 50%; background: #3498db; cursor: pointer; border: none; }
    .value-display { font-size: 3em; font-weight: bold; color: #2c3e50; margin: 10px 0; }
    .box { width: 200px; height: 200px; margin: 20px auto; border-radius: 10px; background: #3498db; transition: all 0.1s; }
    .labels { display: flex; justify-content: space-between; color: #7f8c8d; }
  </style>
</head>
<body>
  <h1>Input Type Range - Slider</h1>
  <div class="slider-group">
    <label for="brightness">Kecerahan:</label>
    <div class="value-display" id="brightnessValue">100</div>
    <div class="labels"><span>Gelap</span><span>Terang</span></div>
    <input type="range" id="brightness" min="0" max="200" value="100" step="1">
  </div>
  <div class="box" id="colorBox" style="opacity:0.5;"></div>
  <script>
    const slider = document.getElementById('brightness');
    const box = document.getElementById('colorBox');
    const display = document.getElementById('brightnessValue');
    slider.addEventListener('input', function() {
      const val = this.value;
      display.textContent = val;
      box.style.opacity = val / 200;
    });
  </script>
</body>
</html>
```

## Poin Penting
- Input `type="range"` menampilkan slider untuk memilih nilai dalam rentang min-max
- Atribut `min`, `max`, `step`, dan `value` mengontrol rentang dan nilai slider
- Event `input` dipicu real-time, event `change` saat slider dilepaskan
