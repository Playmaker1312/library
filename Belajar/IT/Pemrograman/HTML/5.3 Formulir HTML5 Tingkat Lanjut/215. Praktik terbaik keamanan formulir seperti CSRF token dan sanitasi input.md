# Praktik Terbaik Keamanan Formulir Seperti CSRF Token Dan Sanitasi Input

## Analogi: Perpustakaan Digital

Seperti perpustakaan yang memverifikasi kartu anggota dan memeriksa isi tas sebelum pengunjung keluar, keamanan formulir melindungi aplikasi web dari serangan berbahaya. CSRF token seperti stempel verifikasi, sanitasi input seperti memeriksa isi buku yang dipinjam.

## Penjelasan Detail

Keamanan formulir web mencakup beberapa lapisan perlindungan. CSRF (Cross-Site Request Forgery) token adalah nilai unik yang dihasilkan server dan disertakan dalam setiap formulir, diverifikasi saat submit untuk memastikan permintaan berasal dari sumber yang sah. Sanitasi input membersihkan data dari karakter berbahaya dengan menghapus atau meng-escape tag HTML dan karakter khusus (menggunakan library seperti DOMPurify). Validasi sisi server wajib karena validasi sisi klien bisa dilewati. Headers keamanan seperti `Content-Security-Policy` dan `X-Frame-Options` melindungi dari serangan XSS dan clickjacking. Penggunaan HTTPS, pembatasan rate (rate limiting), dan CAPTCHA pada formulir publik melindungi dari serangan brute force dan spam. Penting juga untuk memvalidasi tipe, panjang, dan format data di server.

```html
  <title>Keamanan Formulir</title>
  <style>

    .form-group { margin: 15px 0; }
    label { display: block; font-weight: bold; margin-bottom: 3px; }
    input, textarea { padding: 10px; width: 100%; max-width: 400px; border: 2px solid #ddd; border-radius: 5px; font-size: 16px; }
    textarea { height: 80px; resize: vertical; }
    input:focus, textarea:focus { outline: none; border-color: #3498db; }
    button { padding: 12px 30px; background: #3498db; color: white; border: none; border-radius: 5px; cursor: pointer; font-size: 16px; }
    .security-list { background: #e8f4f8; padding: 15px; border-radius: 8px; margin: 20px 0; }
    .output { background: #f9f9f9; padding: 15px; border-radius: 8px; margin: 15px 0; font-family: monospace; word-break: break-all; }
    .warning { background: #fff3cd; padding: 15px; border-radius: 8px; margin: 20px 0; }
    .hidden { display: none; }
  </style>
</head>
<body>
  <h1>Praktik Terbaik Keamanan Formulir</h1>

  <div class="security-list">
    <strong>Lapisan Keamanan yang Didemonstrasikan:</strong>
    <ul>
      <li>CSRF Token (tersembunyi, unik per sesi)</li>
      <li>Sanitasi Input (menghapus tag HTML berbahaya)</li>
      <li>Validasi Sisi Klien (required, pattern)</li>
      <li>Rate Limiting (simulasi)</li>
      <li>HTTPS (gunakan di produksi)</li>
    </ul>
  </div>

  <div class="warning">
    <strong>Peringatan:</strong> Contoh ini hanya simulasi sisi klien. Di produksi, semua validasi dan sanitasi HARUS dilakukan di server.
  </div>

  <form id="secureForm">
    <!-- CSRF Token (simulasi) -->
    <input type="hidden" id="csrfToken" value="">

    <div class="form-group">
      <label for="nama">Nama:</label>
      <input type="text" id="nama" required maxlength="100" placeholder="Nama lengkap">
    </div>
    <div class="form-group">
      <label for="email">Email:</label>
      <input type="email" id="email" required placeholder="email@domain.com">
    </div>
    <div class="form-group">
      <label for="pesan">Pesan (maks 500 karakter):</label>
      <textarea id="pesan" required maxlength="500" placeholder="Tulis pesan Anda..."></textarea>
    </div>
    <button type="submit">Kirim Pesan Aman</button>
  </form>

  <h3>Hasil Sanitasi:</h3>

  <script>
    // Generate CSRF token (simulasi)
    function generateCSRFToken() {
      return 'csrf_' + Date.now() + '_' + Math.random().toString(36).substr(2, 10);
    }
    document.getElementById('csrfToken').value = generateCSRFToken();

    // Fungsi sanitasi input (sisi klien - untuk demo)
    function sanitasiInput(str) {
      const map = { '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#x27;' };
      return str.replace(/[&<>"']/g, function(m) { return map[m]; });
    }

    // Rate limiting sederhana (sisi klien - simulasi)
    let submitCount = 0;
    const maxSubmits = 3;
    let resetTime = Date.now() + 10000;

    document.getElementById('secureForm').addEventListener('submit', function(e) {
      e.preventDefault();

      // Cek rate limit
      if (Date.now() > resetTime) { submitCount = 0; resetTime = Date.now() + 10000; }
      submitCount++;
      if (submitCount > maxSubmits) {
        alert(`Terlalu banyak percobaan. Silakan coba lagi dalam ${Math.ceil((resetTime - Date.now())/1000)} detik.`);
        return;
      }

      // Validasi form
      if (!this.checkValidity()) {
        this.reportValidity();
        return;
      }

      // Ambil dan sanitasi data
      const nama = sanitasiInput(document.getElementById('nama').value);
      const email = sanitasiInput(document.getElementById('email').value);
      const pesan = sanitasiInput(document.getElementById('pesan').value);
      const token = document.getElementById('csrfToken').value;

      // Simulasi kirim data
      const output = document.getElementById('output');
      output.innerHTML = `
        <strong>Data yang akan dikirim (sudah disanitasi):</strong><br>
        CSRF Token: ${token}<br>
        Nama: ${nama}<br>
        Email: ${email}<br>
        Pesan: ${pesan}<br><br>
        <em style="color:#27ae60;">Data aman! Semua tag HTML telah di-escape.</em>
      `;

      alert('Formulir aman terkirim! (Simulasi) ✅\nCSRF Token: ' + token);
      this.reset();
    });

    // Demo: coba kirim dengan tag HTML
    document.getElementById('pesan').placeholder = 'Coba: <script>alert("xss")</script>';
  </script>
</body>
</html>
```

## Poin Penting
- CSRF token mencegah serangan Cross-Site Request Forgery dengan token unik per sesi
- Sanitasi input membersihkan data dari karakter dan tag HTML berbahaya untuk mencegah XSS
- Keamanan harus diterapkan di server, validasi sisi klien hanya kenyamanan bukan perlindungan
