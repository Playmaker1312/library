# Atribut Type Search Pada Input Untuk Kotak Pencarian Dengan Fitur Hapus Bawaan

## Analogi: Perpustakaan Digital

Seperti kotak saran di meja informasi perpustakaan yang memiliki tombol silang untuk menghapus teks, input type search menyediakan kotak pencarian dengan tombol hapus bawaan dari browser. Pengguna dapat membersihkan kata kunci dengan satu klik.

## Penjelasan Detail

Input dengan `type="search"` adalah elemen formulir HTML5 yang dirancang khusus untuk fungsi pencarian. Secara visual mirip dengan input teks biasa, tetapi browser menambahkan tombol hapus (×) di sisi kanan saat pengguna mulai mengetik, yang mengosongkan input saat diklik. Beberapa browser juga menambahkan ikon kaca pembesar dan gaya bawaan yang berbeda. Perilaku keyboard juga berbeda: menekan Escape pada input search akan menghapus teks. Atribut tambahan seperti `results` dan `autosave` dapat digunakan untuk mengaktifkan riwayat pencarian di beberapa browser. Input search juga mendukung atribut `placeholder`, `pattern`, dan atribut validasi lainnya. Penggunaan `type="search"` meningkatkan aksesibilitas karena pembaca layar dapat mengidentifikasinya sebagai bidang pencarian.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Input Type Search</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 500px; margin: auto; padding: 20px; }
    .search-box { display: flex; gap: 10px; margin: 20px 0; }
    input[type="search"] { flex: 1; padding: 12px 15px; border: 2px solid #3498db; border-radius: 25px; font-size: 16px; }
    input[type="search"]:focus { outline: none; box-shadow: 0 0 5px rgba(52,152,219,0.5); }
    button { padding: 12px 20px; background: #3498db; color: white; border: none; border-radius: 25px; cursor: pointer; }
    .note { background: #ecf0f1; padding: 15px; border-radius: 8px; margin-top: 20px; }
    .result { margin-top: 15px; padding: 10px; background: #e8f4f8; border-radius: 5px; display: none; }
  </style>
</head>
<body>
  <h1>Input Type Search</h1>
  <p>Coba ketik kata kunci dan lihat tombol hapus (×) di sisi kanan input.</p>
  <div class="search-box">
    <input type="search" id="cari" placeholder="Cari sesuatu..." autocomplete="off">
    <button onclick="cari()">Cari</button>
  </div>
  <div class="result" id="hasil">Anda mencari: <span id="keyword"></span></div>
  <div class="note">
    <strong>Fitur:</strong>
    <ul>
      <li>Tombol hapus (×) muncul saat ada teks</li>
      <li>Tekan Escape untuk menghapus teks</li>
      <li>Pembaca layar mengenali sebagai bidang pencarian</li>
    </ul>
  </div>
  <script>
    function cari() {
      const keyword = document.getElementById('cari').value;
      const hasil = document.getElementById('hasil');
      const span = document.getElementById('keyword');
      if (keyword.trim()) {
        span.textContent = keyword;
        hasil.style.display = 'block';
      } else {
        hasil.style.display = 'none';
      }
    }
    document.getElementById('cari').addEventListener('keydown', function(e) {
      if (e.key === 'Enter') cari();
    });
  </script>
</body>
</html>
```

## Poin Penting
- Input `type="search"` menampilkan tombol hapus bawaan browser untuk membersihkan teks
- Menekan tombol Escape pada input search akan menghapus teks yang sedang diketik
- Meningkatkan aksesibilitas dengan memberi sinyal ke pembaca layar bahwa ini bidang pencarian
