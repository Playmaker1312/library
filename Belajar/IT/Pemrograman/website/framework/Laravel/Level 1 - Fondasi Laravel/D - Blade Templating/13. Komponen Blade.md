# 13. Komponen Blade — UI yang Reusable

## Penjelasan

**Komponen Blade** adalah potongan UI yang bisa dipakai ulang di berbagai halaman. Ada dua jenis:

1. **Anonymous Component** — komponen sederhana dalam satu file blade
2. **Class Component** — komponen dengan class PHP untuk logika tambahan

Komponen menerima data melalui **props** dan konten melalui **slot**.

## Fungsi

- Membuat UI yang reusable (kartu buku, alert, tombol) — pakai di banyak halaman
- Memisahkan UI kompleks menjadi bagian-bagian kecil
- Konsistensi desain — komponen yang sama selalu tampil sama

## Cara Pengimplementasian

```blade
{{-- resources/views/components/buku-card.blade.php --}}
@props([
    'buku',
    'tampilkanHarga' => true,
    'ukuran' => 'normal',  // normal | kecil | besar
])

<div class="buku-card buku-card--{{ $ukuran }}">
    <h3>{{ $buku->judul }}</h3>
    <p>{{ $buku->pengarang }}</p>

    @if($tampilkanHarga)
        <p>Rp {{ number_format($buku->harga, 0, ',', '.') }}</p>
    @endif

    {{ $slot }}  {{-- Konten tambahan dari luar --}}
</div>
```

```blade
{{-- Cara pakai komponen --}}
<x-buku-card :buku="$buku" />

<x-buku-card :buku="$buku" :tampilkan-harga="false" ukuran="kecil" />

<x-buku-card :buku="$buku">
    {{-- Ini masuk ke $slot --}}
    <a href="{{ route('buku.show', $buku) }}">Lihat Detail</a>
</x-buku-card>
```

**Komponen Alert dengan slot:**
```blade
{{-- resources/views/components/alert.blade.php --}}
@props(['tipe' => 'info', 'judul' => null])

<div class="alert alert--{{ $tipe }}">
    @if($judul)
        <strong>{{ $judul }}</strong>
    @endif
    {{ $slot }}
</div>
```

```blade
<x-alert tipe="success" judul="Berhasil!">
    Buku berhasil ditambahkan.
</x-alert>

<x-alert tipe="danger">
    Stok buku tidak tersedia.
</x-alert>
```

**Named Slots** (multiple slot):
```blade
{{-- components/buku-card.blade.php --}}
<div class="card">
    <div class="card-header">
        {{ $header }}  {{-- Slot bernama 'header' --}}
    </div>
    <div class="card-body">
        {{ $slot }}  {{-- Slot utama --}}
    </div>
    <div class="card-footer">
        {{ $footer }}  {{-- Slot bernama 'footer' --}}
    </div>
</div>
```

```blade
<x-buku-card :buku="$buku">
    <x-slot:header>
        <h3>{{ $buku->judul }}</h3>
    </x-slot:header>

    <p>{{ $buku->deskripsi }}</p>

    <x-slot:footer>
        <a href="{{ route('buku.show', $buku) }}">Detail</a>
    </x-slot:footer>
</x-buku-card>
```

## Analogi

Komponen Blade seperti **stempel perpustakaan**:

Ada stempel "Tersedia" — bentuk, ukuran, dan tintanya selalu sama. Petugas tinggal menekan stempel di berbagai buku tanpa perlu menulis "Tersedia" setiap kali.

- **Props** = Pengaturan stempel: warna tinta merah atau biru?
- **Slot** = Ruang kosong di stempel untuk menulis tanggal
- **`<x-buku-card :buku="$buku" />`** = "Stempel kartu buku dengan data buku ini"

Di perpustakaan nyata:
- Stempel "TELAH DIKEMBALIKAN" → komponen alert
- Kartu katalog → komponen buku-card
- Label rak → komponen dengan variasi ukuran

Tanpa komponen, setiap halaman harus menulis ulang HTML kartu buku — rentan inkonsistensi. Dengan komponen, semua kartu buku selalu identik.

## Dipakai untuk Apa

- **Kartu/kard** — buku, anggota, peminjaman
- **Alert/notifikasi** — sukses, error, warning, info
- **Tombol dengan variasi** — tombol primary, secondary, danger
- **Form input** — input dengan label, error, dan validasi styling
- **Modal** — dialog konfirmasi
- **Pagination** — navigasi halaman

## Kesalahan Umum

1. **Nama prop tidak konsisten** — di komponen pakai `buku`, di pemanggilan pakai `:book` — tidak cocok
2. **Lupa `:` di binding** — `buku="$buku"` (string literal) vs `:buku="$buku"` (binding variabel)
3. **Kebab-case vs camelCase** — di Blade, prop `tampilkanHarga` dipanggil sebagai `tampilkan-harga`
4. **Menggunakan komponen yang tidak terdaftar** — komponen harus ada di `resources/views/components/`
5. **Terlalu banyak props** — komponen dengan 10+ props sulit dipakai
6. **Slot kosong tanpa default** — jika slot tidak diisi, tidak ada output (mungkin perlu default)

   ```blade
   {{-- components/buku-card.blade.php --}}
   @props(['buku'])
   <div class="card">
       <div class="header">{{ $header }}</div>
       <div class="body">{{ $slot }}</div>

   </div>
   ```

   ```blade
   </x-buku-card>
   ```

3. **Komponen vs @include:**
   - **Komponen** punya props, slot, data binding, dan logika sendiri (class component)
   - **@include** hanya menyertakan file blade — tidak punya props, tidak punya slot
   - **Gunakan komponen** untuk UI yang kompleks dengan data binding
   - **Gunakan @include** untuk potongan kecil tanpa data (misal: header statis)
   - Komponen lebih modern dan direkomendasikan untuk Laravel modern
