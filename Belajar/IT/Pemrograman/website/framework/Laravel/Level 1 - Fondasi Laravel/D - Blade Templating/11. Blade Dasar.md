# 11. Blade Dasar — Syntax yang Lebih Aman dari PHP Murni

## Penjelasan

**Blade** adalah template engine bawaan Laravel. Bedanya dengan PHP murni:
- Syntax lebih bersih dan ekspresif
- Output otomatis di-escape (aman dari XSS)
- File .blade.php di-cache menjadi PHP murni untuk performa
- Punya direktif khusus: `@if`, `@foreach`, `@auth`, dll.

**Output Variabel:**
```blade
{{ $buku->judul }}
{{-- Hasil: htmlspecialchars($buku->judul, ENT_QUOTES) -- otomatis aman dari XSS --}}

{{-- Jika BENAR-BENAR perlu HTML mentah (HATI-HATI XSS!) --}}
{!! $buku->deskripsiHtml !!}
{{-- Hanya untuk konten yang sudah dipastikan aman (dari admin) --}}
```

**Direktif Kontrol:**
```blade
@if($buku->stok > 0)
    <span>Tersedia ({{ $buku->stok }})</span>
@elseif($buku->stok === 0)
    <span>Stok Habis</span>
@else
    <span>Tidak Diketahui</span>
@endif

{{-- unless = if not --}}
@unless($buku->tersedia())
    <p>Buku tidak tersedia.</p>
@endunless
```

**Loop:**
```blade
@foreach($katalog as $buku)
    <p>{{ $loop->iteration }}. {{ $buku->judul }}</p>
    {{-- $loop->iteration: 1, 2, 3... --}}
    {{-- $loop->index: 0, 1, 2... --}}
    {{-- $loop->first: true jika pertama --}}
    {{-- $loop->last: true jika terakhir --}}
@endforeach

@forelse($katalog as $buku)
    <p>{{ $buku->judul }}</p>
@empty
    <p>Belum ada buku.</p>
@endforelse
```

## Fungsi

- Menampilkan data dari controller ke HTML
- Mengamankan output dari serangan XSS
- Menyediakan kontrol flow (if, loop) di dalam template
- Mengorganisir tampilan dengan layout dan komponen

## Cara Pengimplementasian

```blade
{{-- resources/views/buku/index.blade.php --}}
@extends('layouts.app')

@section('title', 'Katalog Buku')

@section('content')
<div class="container">
    <h1>Daftar Buku</h1>

    {{-- Cek apakah ada data --}}
    @if(count($buku) > 0)
        <ul>
            @foreach($buku as $item)
                <li>
                    <strong>{{ $item->judul }}</strong>
                    {{-- Akses properti dengan ?? (null safe) --}}
                    <em>{{ $item->pengarang ?? 'Tidak Diketahui' }}</em>

                    {{-- Cek stok --}}
                    @if($item->stok > 0)
                        <span class="badge bg-success">Tersedia</span>
                    @else
                        <span class="badge bg-danger">Habis</span>
                    @endif
                </li>
            @endforeach
        </ul>
    @else
        <p>Tidak ada buku dalam katalog.</p>
    @endif
</div>
@endsection
```

Perhatikan: semua variabel dibungkus `{{ }}`, bukan `<?= ?>`. Ini kebiasaan yang harus dipegang teguh.

## Analogi

Blade adalah **papan pengumuman perpustakaan** yang sudah diformat:

- `{{ $judul }}` = Tulis judul buku di papan — tinta **otomatis diamankan** (kalau ada tulisan berbahaya, ditutup)
- `{!! $html !!}` = Tulis dengan **tinta permanen** — lebih berbahaya karena tidak ada pengamanan
- `@if($stok > 0) ... @endif` = "Jika stok ada, tampilkan 'Tersedia'. Jika tidak, jangan tampilkan"
- `@foreach($buku as $item)` = "Untuk setiap buku di rak, tampilkan satu baris"

Di PHP murni, kamu harus menulis:
```php
<?php echo htmlspecialchars($buku->judul, ENT_QUOTES, 'UTF-8'); ?>
```
Di Blade, cukup:
```blade
{{ $buku->judul }}
```
Lebih pendek, lebih aman, lebih rapi.

## Dipakai untuk Apa

- **Setiap halaman yang menampilkan data** — semua view menggunakan Blade
- **Form** — menampilkan input, error, old value
- **Loop data** — daftar buku, daftar anggota, riwayat peminjaman
- **Kondisional UI** — tombol "Pinjam" hanya muncul jika stok > 0

## Kesalahan Umum

1. **Output tanpa `{{ }}`** — XSS vulnerability! Contoh: `<p><?= $judul ?></p>` — berbahaya
2. **Menggunakan `{!! !!}` sembarangan** — hanya untuk konten tepercaya (admin). Jangan untuk konten dari user
3. **Lupa `@` di direktif Blade** — `if(...)` bukan `@if(...)` — ini tidak akan bekerja
4. **Menutup direktif dengan salah** — `@if` harus ditutup `@endif`, bukan `@end`
5. **Loop bersarang tanpa variabel berbeda** — `@foreach($buku as $buku)` — timpa variabel asli!
6. **Akses properti null** — gunakan `$buku->pengarang ?? 'Tidak Diketahui'`

## Koneksi dengan Materi Sebelumnya

Poin 7-10 membahas route yang menentukan URL. Route mengembalikan view — dan view menggunakan Blade. Sekarang kamu tahu cara menulis view dengan Blade yang aman dan ekspresif.

**Benang merah ke depan:**
- Poin 12 (Layout Blade): Template utama yang dipakai semua halaman
- Poin 13 (Komponen Blade): UI reusable
- Poin 17 (Passing Data ke View): Data dari controller dikirim ke Blade

## Soal Latihan

1. **Praktik**: Buat file Blade yang menampilkan daftar buku dengan `@forelse`. Jika tidak ada buku, tampilkan "Belum ada buku!"
2. **Analisis**: Mengapa `{{ }}` lebih aman daripada `{!! !!}`? Berikan contoh serangan XSS!
3. **Praktik**: Buat loop `@foreach` yang menampilkan nomor urut (1, 2, 3) menggunakan `$loop->iteration`!

<details>
<summary>Jawaban</summary>

1. **Kode:**
   ```blade
   @forelse($buku as $item)
       <div>
           <h3>{{ $item->judul }}</h3>
           <p>{{ $item->pengarang }}</p>
       </div>
   @empty
       <p>Belum ada buku!</p>
   @endforelse
   ```

2. **Keamanan `{{ }}`:**
   `{{ }}` memanggil `htmlspecialchars()` yang mengubah karakter berbahaya menjadi entitas HTML.
   Contoh XSS: Jika user memasukkan `<script>alert('hacked')</script>` sebagai judul buku:
   - `{{ $judul }}` → output: `&lt;script&gt;alert('hacked')&lt;/script&gt;` (aman, tidak dieksekusi)
   - `{!! $judul !!}` → output: `<script>alert('hacked')</script>` (BERBAHAYA, script jalan)

3. **Loop dengan nomor urut:**
   ```blade
   <ol>
       @foreach($buku as $item)
           <li>{{ $loop->iteration }}. {{ $item->judul }}</li>
       @endforeach
   </ol>
   ```
   `$loop->iteration` mulai dari 1, berbeda dengan `$loop->index` yang mulai dari 0.
