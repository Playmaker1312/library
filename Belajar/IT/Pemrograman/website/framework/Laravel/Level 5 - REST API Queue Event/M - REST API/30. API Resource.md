# 30. API Resource — Transformasi Data yang Konsisten

## Penjelasan

**API Resource** adalah transformation layer yang mengubah data Eloquent menjadi response JSON yang konsisten. Daripada manual `return response()->json(...)` di setiap controller, API Resource memastikan format JSON selalu seragam.

Ada dua jenis:
1. **`JsonResource`** — untuk satu resource (single item)
2. **`ResourceCollection`** — untuk koleksi resource (daftar)

```bash
php artisan make:resource BukuResource
php artisan make:resource BukuCollection
```

**Perbandingan tanpa vs dengan Resource:**
```php
// ❌ Tanpa Resource — format tidak konsisten
public function show(Buku $buku)
{
    return response()->json([
        'id' => $buku->id,
        'judul' => $buku->judul,
        // ...format bisa beda di controller lain
    ]);
}

// ✅ Dengan Resource — format konsisten
public function show(Buku $buku)
{
    return new BukuResource($buku);
}
```

## Fungsi

- Transformasi data Eloquent ke JSON dengan format konsisten
- Menyembunyikan field sensitif (hanya kirim yang perlu)
- Menambahkan field komputasi (harga_format, url, relasi)
- Conditional attribute: hanya tampil dalam kondisi tertentu

## Cara Pengimplementasian

```php
<?php
// app/Http/Resources/BukuResource.php

namespace App\Http\Resources;

use Illuminate\Http\Request;
use Illuminate\Http\Resources\Json\JsonResource;

class BukuResource extends JsonResource
{
    public function toArray(Request $request): array
    {
        return [
            'id'         => $this->id,
            'judul'      => $this->judul,
            'pengarang'  => $this->pengarang,
            'isbn'       => $this->isbn,
            'tahun'      => $this->tahun,
            'harga'      => (int) $this->harga,
            'harga_format' => $this->harga_format,  // accessor
            'stok'       => $this->stok,
            'tersedia'   => $this->tersedia(),
            'kategori'   => $this->kategori,

            // Hanya tampil jika relasi di-load
            'peminjaman' => PeminjamanResource::collection(
                $this->whenLoaded('peminjaman')
            ),
            'total_peminjaman' => $this->whenCounted('peminjaman'),

            // Hanya untuk admin
            'created_at' => $this->when(
                $request->user()?->isAdmin(),
                $this->created_at?->toDateTimeString()
            ),

            // Link HATEOAS
            'links' => [
                'self' => route('api.v1.buku.show', $this->id),
            ],
        ];
    }
}
```

```php
<?php
// app/Http/Controllers/Api/V1/BukuController.php

namespace App\Http\Controllers\Api\V1;

use App\Http\Controllers\Controller;
use App\Http\Resources\BukuResource;
use App\Models\Buku;
use Illuminate\Http\Resources\Json\AnonymousResourceCollection;

class BukuController extends Controller
{
    public function index(Request $request): AnonymousResourceCollection
    {
        $buku = Buku::query()
            ->when($request->filled('kategori'), fn($q) => $q->kategori($request->kategori))
            ->withCount('peminjaman')
            ->paginate($request->per_page ?? 15);

        // Collection — otomatis include links dan meta
        return BukuResource::collection($buku);
    }

    public function show(Buku $buku): BukuResource
    {
        $buku->loadCount('peminjaman');
        return new BukuResource($buku);
    }

    public function store(StoreBukuRequest $request): JsonResponse
    {
        $buku = Buku::create($request->validated());

        return (new BukuResource($buku))
            ->response()
            ->setStatusCode(201);
    }
}
```

```php
<?php
// routes/api.php
Route::prefix('v1')->name('api.v1.')->group(function () {
    Route::apiResource('buku', Api\V1\BukuController::class)
         ->only(['index', 'show', 'store']);
});
```

## Analogi

API Resource seperti **kartu laporan perpustakaan versi digital**:

- **Data mentah** (Eloquent model) = Semua data di database — termasuk catatan internal (created_at, updated_at, id)
- **API Resource** = Kartu laporan yang diformat — hanya menampilkan yang perlu dilihat pengunjung: judul buku, pengarang, status ketersediaan
- **`whenLoaded`** = "Tampilkan detail peminjaman hanya jika diminta" — seperti lampiran opsional
- **`whenCounted`** = "Total peminjaman: 12" — tanpa menampilkan detail satu per satu

**Tanpa Resource:**
```php
return response()->json($buku);
// Mengirim SEMUA kolom — termasuk kolom sensitif!
```

**Dengan Resource:**
```php
return new BukuResource($buku);
// Hanya mengirim field yang didefinisikan di toArray — terkontrol!
```

## Dipakai untuk Apa

- **Setiap API endpoint** — konsistensi response JSON
- **API versioning** — resource berbeda untuk v1 dan v2
- **API dengan relasi** — menyertakan data relasi jika diminta
- **API publik** — menyembunyikan data internal (ID internal, timestamps)

## Kesalahan Umum

1. **Resource terlalu berat** — setiap request menghitung `harga_format`, `tersedia`, dll. Gunakan caching untuk komputasi berat
2. **N+1 di Resource** — `$this->peminjaman` di dalam loop tanpa eager loading. Gunakan `whenLoaded`
3. **Resource memanggil resource lain tanpa `whenLoaded`** — selalu load relasi dengan `with()` sebelum passing ke Resource
4. **Mengirim data sensitif** — pastikan field seperti `password`, `remember_token` tidak masuk ke `toArray`
5. **Resource untuk API dan Web sama** — web biasanya butuh data berbeda dengan API. Buat resource terpisah
6. **Lupa mengatur status code** — store harusnya 201, destroy harusnya 204

## Koneksi dengan Materi Sebelumnya

Poin 20-23 (Eloquent) menyediakan data. API Resource mentransformasinya untuk response JSON. Sebelumnya response berbentuk View (HTML), sekarang JSON.

**Benang merah ke depan:**
- Poin 31 (Sanctum): API Resource + Sanctum = API yang aman
- Poin 32 (Error Handling): Error API juga perlu format konsisten

## Soal Latihan

1. **Praktik**: Buat `BukuResource` dengan field: id, judul, pengarang, harga_format, tersedia, dan link self!
2. **Praktik**: Di controller API, gunakan `BukuResource::collection()` dengan pagination!
