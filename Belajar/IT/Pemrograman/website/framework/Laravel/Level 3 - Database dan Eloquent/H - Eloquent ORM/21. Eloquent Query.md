# 21. Eloquent Query — Ambil, Filter, Sort, Paginate

## Penjelasan

Eloquent menyediakan method yang ekspresif untuk mengambil data dari database. Tidak perlu menulis SQL — cukup panggil method PHP.

```php
// SQL: SELECT * FROM buku WHERE kategori = 'Teknologi' ORDER BY judul ASC
Buku::where('kategori', 'Teknologi')->orderBy('judul')->get();
```

**Kategori Query:**
- **Retrieval**: `all()`, `get()`, `first()`, `find()`, `findOrFail()`
- **Filter**: `where()`, `orWhere()`, `whereIn()`, `whereNull()`
- **Sort**: `orderBy()`, `latest()`, `oldest()`, `inRandomOrder()`
- **Agregasi**: `count()`, `sum()`, `avg()`, `max()`, `min()`
- **Paginasi**: `paginate()`, `simplePaginate()`, `cursorPaginate()`

## Fungsi

- Mengambil data dari database dengan syntax PHP yang ekspresif
- Menyaring, mengurutkan, dan membatasi data
- Menghitung agregasi tanpa SQL mentah
- Paginasi otomatis

## Cara Pengimplementasian

```php
<?php
class BukuController extends Controller
{
    public function index(Request $request): View
    {
        // ─── QUERY DASAR ─────────────────────────────────
        $semua = Buku::all();              // HATI-HATI: load semua! Jangan untuk data banyak.
        $baru  = Buku::latest()->get();    // order by created_at desc

        // ─── FILTER ───────────────────────────────────────
        $teknologi = Buku::where('kategori', 'Teknologi')->get();

        // Multiple kondisi
        $buku = Buku::where('kategori', 'Teknologi')
                    ->where('harga', '>', 100000)
                    ->orderBy('harga', 'desc')
                    ->get();

        // whereIn
        $buku = Buku::whereIn('kategori', ['Teknologi', 'Sains'])->get();

        // where null / not null
        $tanpaISBN = Buku::whereNull('isbn')->get();

        // ─── LOCAL SCOPE ──────────────────────────────────
        $tersedia   = Buku::tersedia()->get();  // scopeTersedia
        $pencarian  = Buku::pencarian('clean code')->get();

        // ─── PAGINASI (WAJIB untuk daftar data banyak) ─────
        $buku = Buku::latest()->paginate(12);
        // Di view: {{ $buku->links() }}

        // Paginate dengan kondisi
        $buku = Buku::tersedia()
                    ->when($request->filled('kategori'), function ($q) use ($request) {
                        $q->kategori($request->kategori);
                    })
                    ->when($request->filled('cari'), function ($q) use ($request) {
                        $q->pencarian($request->cari);
                    })
                    ->orderBy('judul')
                    ->paginate(12)
                    ->withQueryString();  // pertahankan filter di link paginasi

        // ─── AMBIL SATU RECORD ──────────────────────────
        $buku = Buku::find(1);             // null jika tidak ada
        $buku = Buku::findOrFail(1);       // abort(404) — ini yang paling sering dipakai
        $buku = Buku::first();             // record pertama
        $buku = Buku::firstOrFail();       // abort(404) jika tidak ada

        // firstOrCreate: ambil atau buat baru
        $buku = Buku::firstOrCreate(
            ['isbn' => '9780132350884'],
            ['judul' => 'Clean Code', 'pengarang' => 'Robert Martin', ...]
        );

        // ─── AGREGASI ────────────────────────────────────
        $total      = Buku::count();
        $tersedia   = Buku::tersedia()->count();
        $rataHarga  = Buku::avg('harga');
        $maxHarga   = Buku::max('harga');
        $totalStok  = Buku::sum('stok');

        // Cek exist
        $ada = Buku::where('isbn', '9780132350884')->exists();  // true/false

        // ─── CHUNKING (untuk data sangat besar) ──────────
        Buku::chunk(100, function ($buku) {
            // Proses 100 buku per batch — tidak makan memory
            foreach ($buku as $item) {
                // ...
            }
        });

        return view('buku.index', compact('buku'));
    }
}
```

## Analogi

Eloquent query seperti **sistem pencarian buku di perpustakaan**:

- **`all()`** = "Tunjukkan SEMUA buku" — (tapi kalau ada 10.000 buku, ini tidak efisien)
- **`findOrFail(5)`** = "Cari buku nomor 5" — langsung ke rak 5
- **`where('kategori', 'Teknologi')`** = "Cari semua buku di rak Teknologi"
- **`orderBy('judul')`** = "Urutkan berdasarkan abjad judul"
- **`paginate(12)`** = "Tunjukkan 12 buku per halaman"
- **`when($request->filled('cari'), ...)`** = "Jika pengunjung mencari sesuatu, filter; jika tidak, tampilkan semua"
- **`withQueryString()`** = "Ingat kata kunci pencarian saat pindah halaman"

Bayangkan pustakawan yang sangat efisien:
- "Cari buku Teknologi, harga di atas 100rb, urutkan termahal, 12 per halaman" → pustakawan langsung paham dan mengerjakannya dalam satu tarikan napas.

## Dipakai untuk Apa

- **Setiap halaman daftar** — katalog buku, daftar anggota, riwayat peminjaman
- **Setiap halaman detail** — menampilkan satu record
- **Filter dan pencarian** — form filter dengan query string
- **Dashboard** — statistik: jumlah buku, rata-rata harga, dll.

## Kesalahan Umum

1. **`all()` tanpa paginate untuk data besar** — 10.000 buku di-load sekaligus → berat, lama, boros memory. Gunakan `paginate()` atau `cursor()`
2. **`get()` lupa `->toArray()` atau `->toJson()`** — untuk debugging, gunakan `dd(Buku::get()->toArray())`
3. **N+1 problem** — query buku → foreach $buku->peminjaman → query per iterasi. Solusi: `with('peminjaman')`
4. **Filter tanpa `when()`** — `if($request->filled('cari')) { $q->where(...) }` — bisa, tapi `when()` lebih bersih
5. **Salah urutan where** — `where('stok', '>', 0)->where('harga', '<', 100000)` beda dengan `where('harga', '<', 100000)->where('stok', '>', 0)` — untuk AND sih sama
