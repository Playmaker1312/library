# 20. Eloquent Model — Dasar

## Penjelasan

**Eloquent** adalah ORM (Object-Relational Mapping) Laravel. ORM memungkinkan kamu berinteraksi dengan database menggunakan object PHP, bukan SQL mentah. Setiap tabel punya satu Model yang mewakilinya.

**Relasi antara Model dan Tabel:**
```php
class Buku extends Model {}  // → tabel: `buku` (otomatis, plural)
class KategoriBuku extends Model {}  // → tabel: `kategori_bukus`
```

**`$fillable` — Mass Assignment Protection:**
Properti paling penting di model. Mendefinisikan kolom mana yang BOLEH diisi massal via `create()` atau `update()`. Ini adalah fitur keamanan untuk mencegah attacker mengirim field yang tidak seharusnya.

## Fungsi

- Menjembatani PHP ↔ Database — query data tanpa SQL mentah
- Menyediakan method untuk CRUD: `create()`, `update()`, `delete()`
- Mass assignment protection via `$fillable`
- Tempat mendefinisikan: relasi, accessor, scope, casting

## Cara Pengimplementasian

```bash
php artisan make:model Buku -mfs
# = model + migration + factory + seeder
```

```php
<?php
// app/Models/Buku.php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\SoftDeletes;

class Buku extends Model
{
    use HasFactory, SoftDeletes;

    // ⚠️ WAJIB: kolom yang boleh diisi massal
    protected $fillable = [
        'judul', 'pengarang', 'isbn', 'penerbit',
        'tahun', 'harga', 'stok', 'kategori', 'deskripsi', 'sampul',
    ];

    // Cast: konversi tipe otomatis saat akses
    protected function casts(): array
    {
        return [
            'harga' => 'decimal:2',
            'stok'  => 'integer',
            'tahun' => 'integer',
        ];
    }

    // Accessor: modifikasi nilai saat diakses
    // $buku->harga_format → "Rp 150.000"
    public function getHargaFormatAttribute(): string
    {
        return 'Rp ' . number_format($this->harga, 0, ',', '.');
    }

    // Helper method
    public function tersedia(): bool
    {
        return $this->stok > 0;
    }

    // ─── LOCAL SCOPE ─────────────────────────────────────
    // Penggunaan: Buku::tersedia()->get()
    public function scopeTersedia(Builder $query): Builder
    {
        return $query->where('stok', '>', 0);
    }

    public function scopeKategori(Builder $query, string $kategori): Builder
    {
        return $query->where('kategori', $kategori);
    }

    public function scopePencarian(Builder $query, string $keyword): Builder
    {
        return $query->where(function ($q) use ($keyword) {
            $q->where('judul', 'like', "%{$keyword}%")
              ->orWhere('pengarang', 'like', "%{$keyword}%");
        });
    }
}
```

```php
{{-- Akses di view --}}
<h2>{{ $buku->judul }}</h2>
<p>{{ $buku->harga_format }}</p>  {{-- Accessor: "Rp 150.000" --}}
@if($buku->tersedia())
    <span>Tersedia ({{ $buku->stok }})</span>
@endif
```

## Analogi

Eloquent Model seperti **kartu katalog perpustakaan**:

- **Model `Buku`** = Kartu katalog untuk semua buku. Setiap buku punya satu kartu.
- **`$fillable`** = Kolom yang boleh diisi di kartu: judul, pengarang, tahun. Kolom sensitif seperti `is_admin` tidak termasuk — tidak boleh diisi sembarangan.
- **Accessor `harga_format`** = Saat kartu dibaca, harga ditampilkan dalam format "Rp 150.000" bukan "150000" mentah.
- **Scope `tersedia`** = Filter: "Tunjukkan hanya kartu buku yang stoknya > 0"
- **SoftDeletes** = Buku tidak dibuang, tapi diberi stiker "DIHAPUS" (deleted_at terisi)

**Tanpa Eloquent:**
```php
$buku = DB::select("SELECT * FROM buku WHERE id = ?", [$id]);
echo 'Rp ' . number_format($buku[0]->harga, 0, ',', '.');
```

**Dengan Eloquent:**
```php
$buku = Buku::findOrFail($id);
echo $buku->harga_format;
```

Jauh lebih bersih dan ekspresif, bukan?

## Dipakai untuk Apa

- **Setiap interaksi database** — semua query melewati model
- **CRUD** — create, read, update, delete
- **Relasi** — one-to-many, many-to-many
- **Query complex** — filter, sort, paginate, eager loading

## Kesalahan Umum

1. **`$fillable` tidak didefinisikan** — error mass assignment saat `create()` / `update()`. Jangan gunakan `$guarded = []` (ini menonaktifkan proteksi!)
2. **`$fillable` terlalu longgar** — memasukkan kolom sensitif seperti `is_admin` → user bisa upgrade diri sendiri
3. **Lupa `use HasFactory`** — factory tidak bisa dipanggil
4. **Nama model tidak sesuai konvensi** — model `Buku` otomatis cari tabel `buku`. Jika tabelnya `tb_buku`, perlu `protected $table = 'tb_buku'`
5. **Casting salah** — `harga` di-cast sebagai `integer` padahal ada desimal → data terpotong
6. **SoftDeletes tanpa migration yang sesuai** — tabel harus punya kolom `deleted_at`

## Koneksi dengan Materi Sebelumnya

Poin 18-19: migration membuat tabel, seeder mengisi data. Sekarang model menghubungkan kode PHP dengan tabel tersebut. Data hardcode (Level 2) diganti dengan Eloquent query.

**Benang merah ke depan:**
- Poin 21 (Eloquent Query): Cara mengambil, filter, dan paginate data
- Poin 23 (Relasi): Menghubungkan model Buku, Anggota, Peminjaman

## Soal Latihan

1. **Praktik**: Buat model `Kategori` dengan `$fillable` berisi `nama`, `slug`, `deskripsi`!
2. **Analisis**: Mengapa `$fillable` wajib didefinisikan? Apa yang terjadi jika tidak?
3. **Praktik**: Buat accessor `judul_uppercase` yang mengembalikan judul dalam huruf kapital!

<details>
<summary>Jawaban</summary>

1. **Model Kategori:**
   ```php
   <?php
   namespace App\Models;

   use Illuminate\Database\Eloquent\Model;
   use Illuminate\Database\Eloquent\Factories\HasFactory;

   class Kategori extends Model
   {
       use HasFactory;

       protected $fillable = ['nama', 'slug', 'deskripsi'];
   }
   ```

2. **Kenapa `$fillable` wajib:**
   - Mencegah **Mass Assignment Vulnerability** — attacker bisa mengirim field `is_admin=1` melalui form
   - Contoh serangan: form pendaftaran anggota kirim field tambahan `role=admin`
   - Jika `role` tidak ada di `$fillable`, field itu diabaikan
   - `$guarded = []` menonaktifkan semua proteksi — **JANGAN GUNAKAN!**

3. **Accessor judul_uppercase:**
   ```php
   // Cara lama
   public function getJudulUppercaseAttribute(): string
   {
       return strtoupper($this->judul);
   }

   // Cara modern (PHP 8+)
   use Illuminate\Database\Eloquent\Casts\Attribute;
   protected function judulUppercase(): Attribute
   {
       return Attribute::get(fn() => strtoupper($this->judul));
   }
   ```
   Penggunaan: `{{ $buku->judul_uppercase }}`
</details>
