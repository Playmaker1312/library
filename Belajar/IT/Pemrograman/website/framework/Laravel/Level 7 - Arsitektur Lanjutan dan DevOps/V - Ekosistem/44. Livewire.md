# 44. Livewire — Reactive UI Tanpa Full SPA

## Penjelasan

**Livewire** adalah framework full-stack untuk Laravel yang memungkinkan kamu membuat UI reaktif (seperti search tanpa reload, form real-time) tanpa menulis JavaScript. Cukup PHP dan Blade.

**Cara Kerja:**
1. Komponen Livewire merender HTML seperti biasa
2. Interaksi user (klik, input) dikirim ke server via AJAX
3. Server merender ulang komponen, mengirim HTML baru
4. Livewire mengganti bagian yang berubah di DOM (DOM diffing)

```bash
composer require livewire/livewire
php artisan make:livewire KatalogBuku
php artisan make:livewire FormPeminjaman
```

## Fungsi

- UI reaktif tanpa JavaScript — search, filter, form real-time
- Data binding otomatis — property PHP terhubung dengan input HTML
- Component-based — setiap bagian UI adalah komponen mandiri
- Performa — hanya bagian yang berubah yang di-render ulang

## Cara Pengimplementasian

```php
<?php
// app/Livewire/KatalogBuku.php

namespace App\Livewire;

use App\Models\Buku;
use Livewire\Component;
use Livewire\WithPagination;

class KatalogBuku extends Component
{
    use WithPagination;

    // Property — perubahan otomatis trigger re-render
    public string $pencarian = '';
    public string $kategori = '';
    public string $urutan = 'judul';

    // Reset halaman saat pencarian berubah
    public function updatingPencarian(): void
    {
        $this->resetPage();
    }

    public function render()
    {
        $buku = Buku::query()
            ->when($this->pencarian, fn($q) => $q->pencarian($this->pencarian))
            ->when($this->kategori, fn($q) => $q->kategori($this->kategori))
            ->orderBy($this->urutan)
            ->paginate(12);

        return view('livewire.katalog-buku', compact('buku'));
    }
}
```

```php
<?php
// app/Livewire/FormPeminjaman.php — dengan action

class FormPeminjaman extends Component
{
    public $buku_id = '';
    public $message = '';

    protected $rules = [
        'buku_id' => 'required|exists:buku,id',
    ];

    public function pinjam()
    {
        $this->validate();

        $buku = Buku::findOrFail($this->buku_id);

        if ($buku->stok < 1) {
            $this->message = 'Stok tidak tersedia.';
            return;
        }

        Peminjaman::create([
            'buku_id'    => $buku->id,
            'anggota_id' => auth()->id(),
            'tanggal_pinjam' => now(),
            'batas_kembali'  => now()->addDays(14),
        ]);

        $buku->decrement('stok');
        $this->message = 'Buku berhasil dipinjam!';
        $this->reset('buku_id');
    }

    public function render()
    {
        return view('livewire.form-peminjaman', [
            'bukuTersedia' => Buku::tersedia()->get(),
        ]);
    }
}
```

```blade
{{-- resources/views/livewire/form-peminjaman.blade.php --}}
<div>
    @if($message)
        <div class="alert alert-{{ str_contains($message, 'berhasil') ? 'success' : 'danger' }}">
            {{ $message }}

        <select wire:model="buku_id" class="border p-2 rounded w-full">
            <option value="">Pilih Buku</option>
            @foreach($bukuTersedia as $buku)
                <option value="{{ $buku->id }}">{{ $buku->judul }}</option>

                class="bg-blue-500 text-white px-4 py-2 rounded">
            <span wire:loading.remove>Pinjam Buku</span>
            <span wire:loading>Memproses...</span>
        </button>
    </form>
</div>
```

## Analogi

Livewire seperti **papan katalog digital perpustakaan**:

**Cara Lama (halaman statis):**
- Pengunjung mencari buku → submit form → halaman reload → lihat hasil
- Setiap interaksi = reload halaman penuh

**Cara Livewire:**
- Pengunjung mengetik judul → hasil filter muncul otomatis
- Pilih kategori → daftar berubah tanpa reload
- Klik "Pinjam" → konfirmasi muncul tanpa reload

**Perbedaan dengan JavaScript SPA (React/Vue):**
```
React/Vue:                 Livewire:
- JavaScript di frontend   - PHP di server
- API + JSON               - HTML via AJAX
- Full SPA                 - Tingkatkan halaman existing
- Butuh developer JS       - Cukup PHP + Blade
- Setup kompleks           - Satu perintah composer
```

Livewire cocok untuk aplikasi yang sudah pakai Laravel + Blade — menambah interaktivitas tanpa mengubah arsitektur.

## Dipakai untuk Apa

- **Search & filter real-time** — katalog buku, daftar anggota
- **Form multi-step** — pendaftaran bertahap tanpa reload
- **Inline editing** — edit field langsung di tabel
- **Dashboard real-time** — statistik yang update otomatis
- **Modal & dropdown** — komponen UI interaktif

## Kesalahan Umum

1. **Terlalu banyak property** — setiap perubahan property trigger re-render. Minimalisir jumlah property
2. **Query berat di render** — render dipanggil setiap interaksi. Cache query atau gunakan `defer`
3. **Lupa `wire:key` di loop** — error DOM diffing. Selalu tambahkan `wire:key` untuk item dalam loop
4. **Nested komponen terlalu dalam** — performa turun. Maksimal 2-3 level
5. **Menggabungkan Livewire dengan JavaScript manual** — bisa konflik. Gunakan `@this` untuk akses komponen dari JS
6. **Tidak paginate data** — semua data di-load sekali → berat. Gunakan `WithPagination` trait

## Koneksi dengan Materi Sebelumnya

Livewire melengkapi Laravel dengan interaktivitas. Blade (poin 11-13) adalah fondasi tampilan — Livewire membuatnya reaktif. Eloquent (poin 20-23) menyediakan data yang ditampilkan Livewire. Filament (poin 43) dibangun di atas Livewire.

**Benang merah ke depan:**
- Livewire adalah jembatan antara Laravel classic (Blade) dan modern SPA (React/Vue)
- Pelajari Livewire jika ingin UI interaktif tanpa JavaScript


3. **Livewire vs React/Vue:**
   - **Livewire**: render di server, kirim HTML. Cocok untuk: Laravel + Blade existing, tim yang dominan PHP, aplikasi yang butuh interaktivitas ringan-sedang.
   - **React/Vue**: render di client, kirim JSON. Cocok untuk: SPA penuh, UI yang sangat interaktif, mobile app, tim dengan frontend dedicated.
   - Livewire lebih cepat dibuat, React/Vue lebih powerful untuk UI kompleks.
