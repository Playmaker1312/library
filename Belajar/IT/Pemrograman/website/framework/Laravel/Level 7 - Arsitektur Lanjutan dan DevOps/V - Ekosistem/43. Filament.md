# 43. Filament — Admin Panel yang Powerful

## Penjelasan

**Filament** adalah framework admin panel untuk Laravel yang mempercepat pembuatan antarmuka CRUD. Dengan Filament, kamu bisa membuat admin panel lengkap (tabel, form, filter, action) dalam hitungan menit.

```bash
composer require filament/filament:"^3.0"
php artisan filament:install --panels
php artisan make:filament-user       # buat admin user
php artisan make:filament-resource Buku --generate  # CRUD otomatis
```

**Konsep Filament:**
- **Resource** — representasi CRUD untuk model (Buku, Anggota, Peminjaman)
- **Form** — definisi form (input, select, file upload, dll.)
- **Table** — definisi tabel (kolom, filter, action)
- **Widget** — komponen dashboard (statistik, chart)

## Fungsi

- Membangun admin panel dengan cepat — tinggal definisikan form dan table
- CRUD otomatis untuk setiap model
- UI yang konsisten (Tailwind CSS)
- Fitur built-in: auth, filter, export, notification

## Cara Pengimplementasian

```bash
composer require filament/filament:"^3.0"
php artisan filament:install --panels
php artisan make:filament-user  # email: admin@test.com, password: admin123
php artisan make:filament-resource Buku --generate

```

```php
<?php
// app/Filament/Resources/BukuResource.php

namespace App\Filament\Resources;

use App\Models\Buku;
use Filament\Forms;
use Filament\Resources\Resource;
use Filament\Tables;
use Filament\Tables\Columns\TextColumn;
use Filament\Forms\Components\TextInput;
use Filament\Forms\Components\Select;
use Filament\Forms\Components\Textarea;
use Filament\Forms\Components\FileUpload;

class BukuResource extends Resource
{
    protected static ?string $model = Buku::class;
    protected static ?string $navigationIcon = 'heroicon-o-book-open';
    protected static ?string $navigationLabel = 'Koleksi Buku';

    // ─── FORM (Create/Edit) ──────────────────────────
    public static function form(Forms\Form $form): Forms\Form
    {
        return $form->schema([
            TextInput::make('judul')
                ->required()
                ->maxLength(200),

            TextInput::make('pengarang')
                ->required()
                ->maxLength(100),

            TextInput::make('isbn')
                ->label('ISBN')
                ->numeric()
                ->digits(13)
                ->unique(ignoreRecord: true),

            Select::make('kategori')
                ->options([
                    'Teknologi' => 'Teknologi',
                    'Fiksi'     => 'Fiksi',
                    'Sains'     => 'Sains',
                    'Sejarah'   => 'Sejarah',
                ])
                ->required(),

            TextInput::make('harga')
                ->numeric()
                ->prefix('Rp')
                ->required(),

            TextInput::make('stok')
                ->numeric()
                ->minValue(0)
                ->required(),

            Textarea::make('deskripsi')
                ->columnSpanFull(),

            FileUpload::make('sampul')
                ->image()
                ->directory('buku-sampul')
                ->maxSize(2048),
        ]);
    }

    // ─── TABLE (Index) ───────────────────────────────
    public static function table(Tables\Table $table): Tables\Table
    {
        return $table
            ->columns([
                TextColumn::make('judul')
                    ->searchable()
                    ->sortable(),

                TextColumn::make('pengarang')
                    ->searchable(),

                TextColumn::make('kategori')
                    ->badge()
                    ->color(fn(string $state): string => match ($state) {
                        'Teknologi' => 'success',
                        'Fiksi'     => 'warning',
                        default     => 'gray',
                    }),

                TextColumn::make('harga')
                    ->money('IDR')
                    ->sortable(),

                TextColumn::make('stok')
                    ->badge()
                    ->color(fn(int $state): string =>
                        $state > 0 ? 'success' : 'danger'
                    ),

                TextColumn::make('peminjaman_count')
                    ->counts('peminjaman')
                    ->label('Dipinjam'),
            ])
            ->filters([
                Tables\Filters\SelectFilter::make('kategori')
                    ->options(['Teknologi', 'Fiksi', 'Sains', 'Sejarah']),
            ])
            ->actions([
                Tables\Actions\EditAction::make(),
                Tables\Actions\DeleteAction::make(),
            ])
            ->bulkActions([
                Tables\Actions\BulkActionGroup::make([
                    Tables\Actions\DeleteBulkAction::make(),
                ]),
            ]);
    }
}
```

```php
<?php
// app/Filament/Widgets/StatsOverview.php

namespace App\Filament\Widgets;

use App\Models\Buku;
use App\Models\Anggota;
use App\Models\Peminjaman;
use Filament\Widgets\StatsOverviewWidget as BaseWidget;
use Filament\Widgets\StatsOverviewWidget\Stat;

class StatsOverview extends BaseWidget
{
    protected function getStats(): array
    {
        return [
            Stat::make('Total Buku', Buku::count())
                ->icon('heroicon-o-book-open'),

            Stat::make('Anggota Aktif', Anggota::where('status', 'aktif')->count())
                ->icon('heroicon-o-users'),

            Stat::make('Buku Dipinjam', Peminjaman::where('status', 'dipinjam')->count())
                ->icon('heroicon-o-arrow-right-circle'),

            Stat::make('Denda Belum Dibayar', 'Rp ' .
                number_format(Peminjaman::where('status', 'terlambat')->sum('denda'), 0, ',', '.'))
                ->icon('heroicon-o-exclamation-circle'),
        ];
    }
}
```

## Analogi

Filament seperti **toko perabot perpustakaan lengkap**:

Daripada membuat meja sirkulasi, rak buku, dan lemari arsip dari nol (mengukur, memotong kayu, mengecat), perpustakaan tinggal beli **paket perabot standar** yang tinggal diatur posisinya.

- **Forms** = Pilih model meja: kayu jati atau multiplek? (TextInput, Select)
- **Tables** = Pilih ukuran lemari: 3 pintu atau 5 pintu? (kolom yang ditampilkan)
- **Widgets** = Pilih hiasan dinding: jam, lukisan, papan statistik

**Tanpa Filament:** buat admin panel → 2 minggu coding CSS + HTML + JS + controller
**Dengan Filament:** `php artisan make:filament-resource Buku --generate` → 5 menit

## Dipakai untuk Apa

- **Admin panel** — CRUD untuk semua model (buku, anggota, peminjaman)
- **Dashboard** — statistik overview, chart, recent activity
- **Data entry** — form dengan validasi, file upload, rich text
- **Reporting** — tabel dengan filter, search, export CSV/Excel

## Kesalahan Umum

1. **Customize terlalu berlebihan** — Filament sudah cantik; jangan ubah CSS unless necessary
2. **Resource tanpa `--generate`** — harus menulis form/table manual. Gunakan `--generate` untuk starter
3. **Relasi tidak di-set** — Filament bisa menampilkan relasi (anggota.nama) — set up `->relationship()` di kolom
4. **Authorization tidak diatur** — semua user bisa akses semua resource. Tambahkan Policy
5. **Terlalu banyak widget di dashboard** — lambat. Batasi widget yang butuh query berat

## Koneksi dengan Materi Sebelumnya

Filament membaca model (poin 20) dan migration (poin 18) — resource otomatis mendeteksi kolom. Policy (poin 28) bisa diintegrasikan untuk otorisasi. API (poin 30-32) tetap terpisah — Filament untuk admin, API untuk frontend/mobile.

**Benang merah ke depan:**
- Filament adalah cara tercepat untuk membangun admin panel di Laravel
- Poin 44 (Livewire): Filament dibangun di atas Livewire — memahami Livewire membantu kustomisasi Filament

2. **Praktik**: Tambahkan widget statistik di dashboard Filament — total buku, anggota, peminjaman!
