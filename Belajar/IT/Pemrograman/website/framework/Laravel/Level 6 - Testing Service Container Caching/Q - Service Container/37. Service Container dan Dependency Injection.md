# 37. Service Container dan Dependency Injection

## Penjelasan

**Service Container** adalah jantung Laravel yang mengelola dependency. Ketika kamu type-hint suatu class di constructor atau method, Laravel otomatis membuat instance-nya dan menyediakannya — ini disebut **Dependency Injection (DI)**.

**Service Container** melakukan:
1. **Resolusi otomatis** — jika suatu class tidak punya dependency, buat instance-nya
2. **Resolusi rekursif** — jika class A butuh class B, dan class B butuh class C, semua dibuat otomatis
3. **Binding** — kamu bisa memberitahu container: "Jika ada yang minta interface X, berikan implementasi Y"

**Konsep Binding:**
```php
// Tanpa binding: Laravel bisa buat instance class konkret
$this->app->make(BukuService::class);  // ok, class konkret

// Dengan binding: interface → implementasi
$this->app->bind(BukuRepositoryInterface::class, EloquentBukuRepository::class);
// Sekarang: $this->app->make(BukuRepositoryInterface::class)
// → mengembalikan EloquentBukuRepository
```

## Fungsi

- Mengelola pembuatan objek secara otomatis — tidak perlu `new` manual
- Memudahkan testing — dependency bisa di-swap dengan mock
- Memisahkan kode menjadi komponen yang independen (decoupling)
- Membuat arsitektur lebih fleksibel — ganti implementasi tanpa ubah controller

## Cara Pengimplementasian

```php
<?php
// 1. Buat Interface dan Implementasi

// app/Repositories/BukuRepositoryInterface.php
namespace App\Repositories;

interface BukuRepositoryInterface
{
    public function getAll();
    public function findById(int $id): Buku;
    public function create(array $data): Buku;
    public function update(Buku $buku, array $data): Buku;
    public function delete(Buku $buku): bool;
}

// app/Repositories/EloquentBukuRepository.php
class EloquentBukuRepository implements BukuRepositoryInterface
{
    public function getAll()
    {
        return Buku::latest()->paginate(12);
    }

    public function findById(int $id): Buku
    {
        return Buku::findOrFail($id);
    }

    public function create(array $data): Buku
    {
        return Buku::create($data);
    }

    public function update(Buku $buku, array $data): Buku
    {
        $buku->update($data);
        return $buku;
    }

    public function delete(Buku $buku): bool
    {
        return $buku->delete();
    }
}
```

```php
<?php
// 2. Binding di AppServiceProvider

// app/Providers/AppServiceProvider.php
namespace App\Providers;

use App\Repositories\BukuRepositoryInterface;
use App\Repositories\EloquentBukuRepository;
use Illuminate\Support\ServiceProvider;

class AppServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        // Bind interface ke implementasi
        $this->app->bind(
            BukuRepositoryInterface::class,
            EloquentBukuRepository::class,
        );

        // Singleton: satu instance untuk seluruh request
        $this->app->singleton(PeminjamanService::class, function ($app) {
            return new PeminjamanService(
                $app->make(BukuRepositoryInterface::class),
                $app->make(AnggotaRepositoryInterface::class),
            );
        });
    }

    public function boot(): void
    {
        // ...
    }
}
```

```php
<?php
// 3. Controller inject interface, bukan implementasi konkret

class BukuController extends Controller
{
    public function __construct(
        private BukuRepositoryInterface $bukuRepo,
    ) {}

    public function index(): View
    {
        $buku = $this->bukuRepo->getAll();
        return view('buku.index', compact('buku'));
    }

    public function show(int $id): View
    {
        $buku = $this->bukuRepo->findById($id);
        return view('buku.show', compact('buku'));
    }
}

// 4. Di test — swap dengan mock
class BukuTest extends TestCase
{
    public function test_index(): void
    {
        // Swap repository dengan mock
        $this->app->instance(
            BukuRepositoryInterface::class,
            Mockery::mock(BukuRepositoryInterface::class, function ($mock) {
                $mock->shouldReceive('getAll')->once()->andReturn(collect([]));
            })
        );

        $response = $this->get(route('buku.index'));
        $response->assertStatus(200);
    }
}
```

## Analogi

Service Container seperti **sistem pemesanan buku antar perpustakaan**:

- **Binding** = "Jika ada yang minta 'buku', berikan dari rak fiksi" — petugas toko buku tahu persis di mana mengambil buku yang diminta

- **Interface** = **Voucher "Buku"** — "Saya mau buku, tidak peduli buku apa. Yang penting saya dapat buku."
- **Implementasi** = **Buku fisik yang diberikan** — bisa dari rak fiksi, dari gudang, atau dari cabang lain

**Tanpa Service Container:**
```php
// Controller harus tahu SEMUA implementasi
class BukuController {
    private $repo;
    public function __construct() {
        $this->repo = new EloquentBukuRepository(); // TAHU spesifiknya
    }
}
```

**Dengan Service Container:**
```php
// Controller hanya tahu INTERFACE
class BukuController {
    public function __construct(
        private BukuRepositoryInterface $repo  // TIDAK TAHU implementasi
    ) {}
}
```

Keuntungan: jika suatu saat ingin ganti dari MySQL ke MongoDB, buat implementasi baru `MongoBukuRepository`, ubah binding di satu tempat. **Controller tidak perlu diubah sama sekali.**

## Dipakai untuk Apa

- **Repository Pattern** — pisahkan akses data dari bisnis logic
- **Service Layer** — business logic yang bisa di-test dengan mock
- **Arsitektur bersih** — controller tipis, service tebal
- **Testing** — swap dependency dengan mock

## Kesalahan Umum

1. **Binding tidak terdaftar** — error "Target [Interface] is not instantiable" — daftarkan di ServiceProvider
2. **Terlalu banyak binding** — tidak semua class perlu binding. Cukup yang perlu di-swap (interface)
3. **Membuat instance dengan `new` di controller** — jika sudah pakai DI, jangan `new Repository()`. Inject saja
4. **Controller terlalu banyak dependency** — >5 constructor parameter → mungkin perlu digabung
5. **Lupa `register()` vs `boot()`** — binding di `register()`, action setelah binding di `boot()`
