# 71. Buat Project Nuxt 3 Baru — Migrasi dari Vue SPA

## Penjelasan

Nuxt 3 adalah framework berbasis Vue 3 yang menyediakan SSR (Server-Side Rendering) secara bawaan. Berbeda dengan Vue SPA murni (hasil Level 1–6), Nuxt memiliki struktur folder sendiri, auto-import, file-based routing, dan `server/` untuk backend ringan.

Membuat project Nuxt baru dilakukan dengan perintah:

```bash
npx nuxi@latest init bookstore-nuxt
```

Ini akan membuat folder `bookstore-nuxt` sebagai project **terpisah** — bukan migrasi in-place dari project Vue SPA yang sudah ada.

**Struktur folder Nuxt vs Vue SPA:**

| Vue SPA | Nuxt 3 |
|---|---|
| `src/views/` | `pages/` (otomatis routing) |
| `src/router/index.ts` | Tidak perlu — routing dari struktur `pages/` |
| `src/components/` | `components/` (auto-import) |
| `src/composables/` | `composables/` (auto-import) |
| `src/stores/` (Pinia) | `stores/` (auto-import) |
| `src/App.vue` | `app.vue` (minimal) |
| `vite.config.ts` | `nuxt.config.ts` |
| Tidak ada | `server/api/` (endpoint backend) |

---

## Fungsi

- Framework Vue untuk SSR — halaman di-render di server, HTML siap untuk SEO
- Auto-import components, composables, stores — tidak perlu `import` manual
- Struktur proyek standar tanpa boilerplate konfigurasi router/vite terpisah
- Mode hybrid: SSG, SSR, atau static sekaligus dalam satu project

---

## Cara Implementasi

### 1. Buat project baru

```bash
npx nuxi@latest init bookstore-nuxt
cd bookstore-nuxt
npm install
```

### 2. Jalankan development server

```bash
npm run dev -- -o
```

### 3. `nuxt.config.ts` minimal

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  devtools: { enabled: true },
  modules: ['@pinia/nuxt']
})
```

### 4. `app.vue` — entry point minimal

```vue
<template>
  <NuxtPage />
</template>
```

### 5. Auto-import components

Buat file `components/BookCard.vue` — Nuxt otomatis mengenalinya:

```vue
<template>
  <div class="card">
    <h3>{{ title }}</h3>
    <p>{{ author }}</p>
  </div>
</template>

<script setup lang="ts">
defineProps<{
  title: string
  author: string
}>()
</script>
```

Gunakan di `pages/index.vue` tanpa import:

```vue
<template>
  <BookCard title="Clean Code" author="Robert Martin" />
</template>
```

### 6. Auto-import composables

Buat `composables/useBook.ts`:

```ts
export const useBook = () => {
  const books = ref([
    { id: 1, title: 'Clean Code', author: 'Robert Martin' }
  ])
  return { books }
}
```

Gunakan langsung di halaman:

```vue
<script setup lang="ts">
const { books } = useBook()
</script>
```

## Analogi — Toko Buku

Selama ini toko buku adalah **SPA** — semua barang (konten) ada di dalam toko, tapi Google (mesin pencari) hanya bisa lihat dari luar jendela. Isi rak tidak terlihat karena harus menjalankan JavaScript dulu.

Nuxt adalah **toko dengan etalase transparan** — semua barang sudah tertata rapi dari luar (server-side rendered HTML). Google bisa melihat SEMUA buku tanpa perlu masuk toko. Pengunjung juga melihat barang lebih cepat karena semuanya sudah siap dari server.

Struktur folder Nuxt ibarat denah toko yang sudah distandarisasi: rak depan = `pages/`, rak komponen = `components/`, bagian belakang = `server/`. Semua sudah punya tempatnya masing-masing tanpa perlu papan petunjuk tambahan.

---

## Dipakai untuk Apa

- Aplikasi Vue yang membutuhkan SEO (toko online, blog, company profile, landing page)
- Aplikasi yang ingin First Contentful Paint cepat
- Monolith frontend+backend ringan (dengan `server/api/`)
- Proyek yang ingin SSG hybrid (sebagian halaman statis, sebagian SSR)

## Kesalahan Umum

| Kesalahan | Akibat | Solusi |
|---|---|---|
| Migrasi bertahap di project SPA yang sama | Konflik dependensi, struktur campur aduk | Buat project Nuxt baru, copy kode secara selektif |
| Bingung auto-import — komponen tidak muncul | Komponen tidak terdaftar | Pastikan nama file komponen sesuai konvensi (PascalCase), letakkan di `components/` |
| Mengharapkan Vue Router `createRouter` masih ada | Error karena tidak ada router manual | Gunakan file-based routing di `pages/` |
| `npm run dev` gagal | Node.js versi < 18 | Pastikan Node 18+ |

---

## Hubungan dengan Materi Sebelumnya (Level 1–6)

Aplikasi SPA dari Level 1 hingga Level 6 sudah jadi dan berfungsi penuh. Namun SPA memiliki kelemahan:

- **SEO buruk** — Google bot sulit merender JavaScript SPA. Halaman buku tidak muncul di hasil pencarian.
- **First Contentful Paint lambat** — browser harus download JS, eksekusi, baru render konten.
- **Tidak ada etalase** — HTML awal kosong, hanya `<div id="app"></div>`.

Nuxt menyelesaikan semua masalah ini. Project baru dibuat terpisah, lalu kode views dan komponen di-copy ke dalam struktur Nuxt. Konsep Vue 3 (Composition API, TypeScript, Pinia, reactive) tetap sama — hanya framework pembungkusnya yang berbeda.
