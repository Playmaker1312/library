# 24. Slots — Komponen yang Fleksibel

## Penjelasan

**Slot** adalah mekanisme Vue untuk menyuntikkan konten dari luar ke dalam template komponen. Bayangkan slot sebagai "lubang" atau "tempat kosong" di komponen yang bisa diisi oleh parent dengan markup, teks, atau komponen lain.

### Slot default

```vue
<!-- BaseCard.vue -->
<template>
  <div class="card">
    <slot />
  </div>
</template>
```

Parent mengisi slot:
```vue
<BaseCard>
  <p>Isi konten di sini</p>
</BaseCard>
```

### Named slot

```vue
<!-- BaseCard.vue -->
<template>
  <div class="card">
    <header><slot name="header" /></header>
    <main><slot /></main>
    <footer><slot name="footer" /></footer>
  </div>
</template>
```

Parent mengisi named slot dengan `v-slot` atau `#`:
```vue
<BaseCard>
  <template #header>
    <h2>Judul</h2>
  </template>

  <p>Deskripsi buku...</p>

  <template #footer>
    <button>Beli</button>
  </template>
</BaseCard>
```

### Fallback content (konten default)

```vue
<!-- BaseCard.vue -->
<template>
  <div class="card">
    <slot name="header">
      <h3>Judul Default</h3>
    </slot>
  </div>
</template>
```

Jika parent tidak mengisi `#header`, maka `<h3>Judul Default</h3>` akan tampil.

### Conditional slot rendering

```vue
<script setup lang="ts">
import { useSlots } from 'vue'
const slots = useSlots()
</script>

<template>
  <div class="card">
    <header v-if="slots.header">
      <slot name="header" />
    </header>
    <slot />
  </div>
</template>
```

Gunakan `v-if="$slots.header"` untuk tidak render elemen `<header>` jika slot kosong (menghindari markup kosong).

---

## Fungsi

- Membuat komponen **template yang bisa dikustomisasi** dari luar
- Memisahkan **struktur (layout)** dari **konten**
- Mengurangi duplikasi markup — satu layout, banyak isi
- Named slot memungkinkan komponen memiliki **beberapa area konten**

---

## Cara Implementasi

### 1. BaseCard — komponen layout dengan slot

```vue
<!-- components/BaseCard.vue -->
<script setup lang="ts">
import { useSlots } from 'vue'

const slots = useSlots()
</script>

<template>
  <div class="base-card">
    <header v-if="slots.header">
      <slot name="header" />
    </header>

    <main>
      <slot />
    </main>

    <footer v-if="slots.footer">
      <slot name="footer" />
    </footer>
  </div>
</template>

<style scoped>
.base-card {
  border: 1px solid #e0e0e0;
  border-radius: 8px;
  padding: 1rem;
  margin-bottom: 1rem;
}
header { border-bottom: 1px solid #eee; padding-bottom: 0.5rem; }
main { padding: 0.75rem 0; }
footer { border-top: 1px solid #eee; padding-top: 0.5rem; }
</style>
```

### 2. BookCard — menggunakan BaseCard dengan slot

```vue
<!-- components/BookCard.vue -->
<script setup lang="ts">
import type { Book } from '@/types/book'
import BaseCard from '@/components/BaseCard.vue'

const props = defineProps<{ book: Book }>()

const emit = defineEmits<{
  'add-to-cart': [book: Book]
}>()
</script>

<template>
  <BaseCard>
    <template #header>
      <h3>{{ book.title }}</h3>
    </template>

    <p>Penulis: {{ book.author }}</p>
    <p>Harga: Rp{{ book.price.toLocaleString() }}</p>

    <template #footer>
      <button @click="emit('add-to-cart', book)">
        Tambah ke Keranjang
      </button>
    </template>
  </BaseCard>
</template>
```

### 3. BaseCard tanpa footer — fallback content terlihat

```vue
<BaseCard>
  <template #header>
    <h3>Promo Spesial!</h3>
  </template>

  <p>Diskon 20% semua buku programming.</p>

  <!-- #footer tidak diisi → fallback: tidak muncul
       karena kita pakai v-if="$slots.footer" -->
</BaseCard>
```

---

## Analogi — Toko Buku

**BaseCard** seperti **rak buku kosong** yang tingginya 3 tingkat:

| Slot | Tingkat rak | Contoh isi |
|---|---|---|
| `#header` | **Tingkat atas** | Foto buku, judul, genre badge |
| `default` | **Tingkat tengah** | Deskripsi, sinopsis, ulasan |
| `#footer` | **Tingkat bawah** | Harga, tombol beli, rating |

**BookCard** "meminjam" rak ini dan mengisi setiap tingkat sesuai kebutuhannya. **PromoCard** juga bisa pinjam rak yang sama — isinya berbeda.

Toko yang sama, rak yang sama, isi bisa berbeda-beda. Itulah fleksibilitas slot.

---

## Dipakai untuk apa

| Skenario | Contoh |
|---|---|
| Kartu / Card | BaseCard, ProductCard, ProfileCard |
| Modal / Dialog | Header (judul + close btn), body, footer (aksi) |
| List layout | List dengan header toolbar, item list, footer pagination |
| Form layout | Label di slot kiri, input di slot kanan |
| Tabel | Header kolom, body baris, footer summary |
| Layout halaman | PageHeader, PageContent, PageSidebar |

---

## Kesalahan Umum

| Kesalahan | Akibat | Cara Benar |
|---|---|---|
| Lupa `#` di named slot | Konten masuk ke slot default | Gunakan `#nama` atau `v-slot:nama` |
| Slot tidak muncul | Parent lupa isi, tidak ada fallback | Beri fallback content: `<slot>Konten default</slot>` |
| Render `<div>` kosong jika slot tak diisi | Markup berlebih | Gunakan `v-if="$slots.nama"` |
| Named slot typo (header vs headr) | Konten hilang tanpa warning | Debug dengan Vue DevTools |
| Menggunakan `$slots` di template tanpa `useSlots` | Tidak masalah, `$slots` global ada | Tapi `useSlots()` lebih eksplisit di `<script setup>` |

---

## Hubungan dengan Materi Sebelumnya

- **Poin 22 (Emit):** Setelah BookCard bisa interaktif (emit event), kita sekarang modularisasi tampilannya. BookCard lebih bersih karena layout diserahkan ke BaseCard.

- **Poin 20 (Komponen Dasar):** Slot adalah alat yang membuat komponen semakin *reusable*. BookCard tidak perlu define style karting — cukup pakai BaseCard dan isi slotnya.

- **Poin 15 (Conditional Rendering):** `v-if="$slots.header"` adalah contoh conditional rendering berdasarkan keberadaan slot.

- **Level 1 (Poin 6 - Komponen):** Di Level 1, komponen bersifat kaku — satu komponen satu tampilan. Dengan slot, satu komponen bisa menghasilkan **variasi tampilan tak terbatas**.

### Soal 1

Buat komponen `BaseModal.vue` dengan 3 slot: `#trigger` (tombol buka), `default` (isi modal), dan `#footer` (tombol aksi). Gunakan `v-if` untuk menampilkan/menyembunyikan modal. Implementasikan di parent dengan tombol "Buka Modal" dan isi berupa daftar buku.

<details>
<summary>Jawaban Soal 1</summary>

```vue
<!-- BaseModal.vue -->
<script setup lang="ts">
import { ref } from 'vue'

const terbuka = ref(false)
</script>

<template>
  <div>
    <div @click="terbuka = true">
      <slot name="trigger" />
    </div>

    <div v-if="terbuka" class="modal-overlay" @click="terbuka = false">
      <div class="modal-content" @click.stop>
        <slot />
        <footer v-if="$slots.footer">
          <slot name="footer" />
        </footer>
        <button @click="terbuka = false">Tutup</button>
      </div>
    </div>
  </div>
</template>

<style scoped>
.modal-overlay {
  position: fixed; inset: 0;
  background: rgba(0,0,0,0.5);
  display: flex; align-items: center; justify-content: center;
}
.modal-content {
  background: white; padding: 2rem; border-radius: 8px; min-width: 300px;
}
</style>
```
