# 23. Implementasi Cart State — Counter di Header

## Penjelasan

Setelah BookCard bisa emit event `'add-to-cart'` ke HomeView, kita perlu **menyimpan state keranjang** dan menampilkan jumlahnya di **header**. Masalahnya: `AppHeader` terpisah dari `HomeView` — data harus melewati `App.vue` dulu.

### Alur data (sementara tanpa Pinia)

```
BookCard → emit → HomeView (cart state) → props → App.vue → props → AppHeader
```

Inilah yang disebut **Props Drilling** — data diturunkan melalui komponen perantara yang sebenarnya tidak membutuhkannya.

---

## Fungsi

- Menyimpan daftar buku yang dipilih user (cart state)
- Menghitung jumlah item secara reaktif dengan `computed`
- Menampilkan counter di header sebagai feedback visual
- Memahami keterbatasan props drilling sebagai motivasi ke state management (Pinia)

---

## Cara Implementasi

### 1. Cart state di HomeView + computed cartCount

```vue
<!-- views/HomeView.vue -->
<script setup lang="ts">
import { ref, computed } from 'vue'
import BookCard from '@/components/BookCard.vue'
import type { Book } from '@/types/book'

const cartItems = ref<Book[]>([])
const cartCount = computed(() => cartItems.value.length)

const bukuPopuler: Book[] = [
  { id: 1, title: 'Vue.js untuk Pemula', author: 'Rudi', price: 95000 },
  { id: 2, title: 'TypeScript Lanjutan', author: 'Sari', price: 120000 },
]

function handleAddToCart(book: Book) {
  cartItems.value.push(book)
}
</script>

<template>
  <div>
    <BookCard
      v-for="buku in bukuPopuler"
      :key="buku.id"
      :book="buku"
      @add-to-cart="handleAddToCart"
    />
    <p v-if="cartItems.length">Total item di keranjang: {{ cartCount }}</p>
  </div>
</template>
```

### 2. Operasi cart lain (opsional)

```typescript
function removeFromCart(bookId: number) {
  cartItems.value = cartItems.value.filter(b => b.id !== bookId)
}

function clearCart() {
  cartItems.value = []
}
```

### 3. Props drilling — kirim data ke AppHeader via App.vue

**HomeView → App.vue**
```vue
<!-- App.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import HomeView from '@/views/HomeView.vue'
import AppHeader from '@/components/AppHeader.vue'
import type { Book } from '@/types/book'

const cartCount = ref(0)
// ... tapi kita perlu akses ke cartCount dari HomeView
</script>
```

**Masalah:** `cartCount` ada di `HomeView`, tapi `App.vue` dan `AppHeader` butuh akses. Salah satu solusi cepat: **angkat state ke App.vue**.

### 4. Solusi sementara: state di App.vue

```vue
<!-- App.vue -->
<script setup lang="ts">
import { ref, computed } from 'vue'
import AppHeader from '@/components/AppHeader.vue'
import HomeView from '@/views/HomeView.vue'
import type { Book } from '@/types/book'

const cartItems = ref<Book[]>([])
const cartCount = computed(() => cartItems.value.length)

function addToCart(book: Book) {
  cartItems.value.push(book)
}
</script>

<template>
  <AppHeader :cart-count="cartCount" />
  <HomeView @add-to-cart="addToCart" />
</template>
```

```vue
<!-- components/AppHeader.vue -->
<script setup lang="ts">
defineProps<{ cartCount: number }>()
</script>

<template>
  <header>
    <h1>BookStore</h1>
    <span class="badge">🛒 {{ cartCount }}</span>
  </header>
</template>
```

## Analogi — Toko Buku

BookCard (pegawai etalase) memberi tahu HomeView (manajer toko) bahwa ada buku terjual. Manajer mencatatnya di **buku catatan penjualan** (`cartItems`).

Tapi pegawai di **kasir (AppHeader)** juga perlu tahu jumlah total — agar bisa menyiapkan kantung belanja.

Jadi manajer harus **berteriak dari ruangannya ke kasir**: "Hari ini sudah terjual 3 buku!" (props drilling). Tidak efisien apalagi jika tokonya besar. Untuk sementara berfungsi, tapi di Level 3 kita akan pasang **interkom (Pinia)** yang langsung menghubungkan semua ruangan tanpa teriak-teriak.

## Dipakai untuk apa

| Skenario | Contoh |
|---|---|
| Cart / wishlist counter | Jumlah item di keranjang belanja |
| Notification badge | Notifikasi belum dibaca |
| Auth state | Menampilkan nama user di header setelah login |
| Multi-step form | Status progress di tiap langkah |
| Dark mode toggle | State tema dibutuhkan di banyak komponen |

---

## Kesalahan Umum

| Kesalahan | Akibat | Cara Benar |
|---|---|---|
| Mengubah props langsung dari child | Warning Vue | Gunakan emit + parent update state |
| Lupa `.value` saat mutasi array | Tidak reaktif | `cartItems.value.push(book)` atau `cartItems.value = [...cartItems.value, book]` |
| Menyimpan state di komponen yang terlalu dalam | Props drilling berlebihan | Angkat state ke parent terdekat yang memang butuh |
| Mutasi array dengan index assignment | Tidak reaktif | Gunakan splice, atau replace array: `arr.value = [...arr.value]` |
| Lupa `key` saat v-for | Performa turun, state kacau | Selalu beri `:key` unik (book.id) |

---

## Hubungan dengan Materi Sebelumnya

- **Poin 22 (Emit):** Langkah sebelumnya — BookCard emit `'add-to-cart'` ke HomeView. Sekarang kita tangkap event itu dan update state cart.
- **Poin 19 (Computed):** `cartCount` adalah computed yang otomatis update saat cartItems berubah.
- **Poin 18 (Props):** `cartCount` dikirim sebagai prop ke AppHeader — contoh nyata props drilling.
- **Level 1 (Poin 8-9):** Di Level 1, data buku bersifat statis. Sekarang data bisa berubah secara reaktif akibat interaksi user.
- **Motivasi ke Level 3:** Masalah props drilling ini akan dipecahkan oleh **Pinia** di Level 3 — satu store global yang bisa diakses komponen mana pun tanpa harus props drilling.

## Soal Latihan

### Soal 1

Buat fungsi `addToCart` yang tidak menambahkan buku jika judul yang sama sudah ada di keranjang (cegah duplikat). Gunakan `some()` untuk pengecekan.

<details>
<summary>Jawaban Soal 1</summary>

```typescript
function addToCart(book: Book) {
  const sudahAda = cartItems.value.some(item => item.id === book.id)
  if (sudahAda) {
    alert(`"${book.title}" sudah ada di keranjang!`)
    return
  }
  cartItems.value.push(book)
}
```

</details>

### Soal 2

Buat total harga di keranjang menggunakan computed — tampilkan di samping cartCount. Hitung dari `book.price` dikalikan quantity (asumsikan quantity selalu 1 per item).

<details>
<summary>Jawaban Soal 2</summary>

```typescript
const totalHarga = computed(() =>
  cartItems.value.reduce((total, book) => total + book.price, 0)
)
```

```vue
<!-- AppHeader.vue -->
<template>
  <header>
    <h1>BookStore</h1>
    <span>🛒 {{ cartCount }} item — Rp{{ totalHarga.toLocaleString() }}</span>
  </header>
</template>
```

Tambahkan prop baru di AppHeader:

```typescript
defineProps<{
  cartCount: number
  totalHarga: number
}>()
```
