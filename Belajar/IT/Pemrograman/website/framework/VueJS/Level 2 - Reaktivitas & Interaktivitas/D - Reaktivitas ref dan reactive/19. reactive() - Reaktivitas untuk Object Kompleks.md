# 19. `reactive()` — Reaktivitas untuk Object Kompleks

## Penjelasan

`reactive()` adalah fungsi Vue 3 yang membuat **object** menjadi reaktif. Berbeda dengan `ref`, properti `reactive()` bisa diakses **langsung tanpa `.value`**. Cocok untuk sekelompok state yang saling terkait.

```ts
import { reactive } from 'vue'

const filterState = reactive({
  search: '',
  category: 'all',
  sortBy: 'title',
  page: 1,
})

// Akses langsung — tanpa .value
filterState.search = 'vue'
filterState.page++
```

## Fungsi

Mengelompokkan beberapa state yang saling berhubungan menjadi satu object reaktif — lebih rapi dan mudah dikelola daripada ref terpisah-pisah.

## Cara Implementasi

```vue
<script setup lang="ts">
import { reactive, computed } from 'vue'

interface FilterState {
  search: string
  category: string
  sortBy: 'title' | 'price' | 'rating'
  page: number
  inStockOnly: boolean
}

const filterState = reactive<FilterState>({
  search: '',
  category: 'semua',
  sortBy: 'title',
  page: 1,
  inStockOnly: false,
})

const books = reactive([
  { title: 'Vue 3 Dasar', price: 75000, inStock: true, category: 'teknologi', rating: 4.5 },
  { title: 'Belajar TS', price: 65000, inStock: true, category: 'teknologi', rating: 4.2 },
  { title: 'Dongeng Sebelum Tidur', price: 50000, inStock: false, category: 'fiksi', rating: 4.8 },
])

function resetFilter() {
  filterState.search = ''
  filterState.category = 'semua'
  filterState.sortBy = 'title'
  filterState.page = 1
  filterState.inStockOnly = false
}
</script>

<template>
  <input v-model="filterState.search" placeholder="Cari..." />
  <select v-model="filterState.sortBy">
    <option value="title">Judul</option>
    <option value="price">Harga</option>
  </select>
  <button @click="resetFilter">Reset Filter</button>
</template>
```

### Kapan ref vs reactive

| Situasi | Pakai |
|---------|-------|
| Nilai tunggal (string, number, boolean) | `ref()` |
| Grup state yang saling terkait | `reactive()` |
| Array | Bisa keduanya, `ref()` lebih umum |
| Perlu re-assign seluruh nilai | `ref()` |
| Ingin akses tanpa `.value` | `reactive()` |

## Analogi — Toko Buku

Daripada punya 4 sensor terpisah (`ref` untuk search, `ref` untuk category, `ref` untuk sortBy), `reactive()` seperti **satu panel kontrol** yang menggabungkan semua tombol filter di toko. Semua tombol ada di satu panel — hemat tempat dan lebih rapi.

Tidak perlu `.value` karena semuanya properti dari satu object.

## Dipakai untuk apa

- Filter state kompleks (search, sort, category, page)
- Form multi-field
- State komponen yang saling terkait
- Konfigurasi / settings object

## Kesalahan Umum

| ❌ Salah | ✅ Benar |
|----------|----------|
| `reactive('string')` | `reactive()` hanya untuk object — primitif pakai `ref()` |
| Destructure `reactive()` lalu akses properti | Destructure **memutus reaktivitas** — gunakan `toRefs()` |
| Re-assign seluruh object `state = {...}` | Re-assign **menghancurkan reaktivitas** — ubah properti langsung |
| Lupa bahwa array juga object reaktif | Array di `reactive()` bisa diubah dengan method biasa (`push`, `splice`) |

```ts
// ❌ Destructure memutus reaktivitas
const { search, category } = filterState
search = 'vue' // Tidak reaktif!

// ✅ toRefs mempertahankan reaktivitas
const { search, category } = toRefs(filterState)
search.value = 'vue' // Reaktif

// ❌ Re-assign total
filterState = { search: 'vue', category: 'fiksi' }
// ✅ Assign per properti
filterState.search = 'vue'
filterState.category = 'fiksi'
```

## Hubungan dengan Materi Sebelumnya

**Poin 18**: `filterState` bisa langsung dipakai di `computed` sebagai dependency. Semua properti di dalamnya otomatis dilacak.

**Poin 20 nanti**: `watch()` bisa memonitor perubahan `filterState` (dengan `{ deep: true }`) dan menjalankan side effect seperti save ke localStorage.

### Soal 2

Buat `reactive` state `keranjang` berisi array `items` dan properti `total`. Buat fungsi `tambahItem(nama, harga)` yang push item baru. Mengapa `total` harus computed, bukan properti biasa?

<details>
<summary>Jawaban</summary>

```vue
<script setup lang="ts">
import { reactive, computed } from 'vue'

const keranjang = reactive<{ items: { nama: string; harga: number }[] }>({
  items: [],
})

const total = computed(() =>
  keranjang.items.reduce((sum, item) => sum + item.harga, 0)
)

function tambahItem(nama: string, harga: number) {
  keranjang.items.push({ nama, harga })
}
</script>

<template>
  <button @click="tambahItem('Buku Vue', 75000)">Tambah Buku Vue</button>
  <div v-for="(item, i) in keranjang.items" :key="i">{{ item.nama }} — Rp{{ item.harga }}</div>
  <p>Total: Rp{{ total.toLocaleString() }}</p>
</template>
```

> **Mengapa computed?** Karena jika `total` dideklarasikan sebagai properti biasa di `reactive`, nilainya tidak akan otomatis berubah saat `items` berubah. `computed` melacak dependency (`keranjang.items`) dan otomatis re-kalkulasi.
</details>
