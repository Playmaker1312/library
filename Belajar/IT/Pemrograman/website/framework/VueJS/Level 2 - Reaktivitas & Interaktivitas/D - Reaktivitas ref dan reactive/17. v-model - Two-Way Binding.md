# 17. `v-model` — Two-Way Binding

## Penjelasan

`v-model` adalah direktif Vue untuk **two-way binding** antara data di script dan elemen input di template. Secara internal, `v-model` setara dengan `:value` + `@input`.

```ts
// v-model="search" sama dengan:
// :value="search" @input="search = $event.target.value"
```

## Fungsi

Menghubungkan **data reaktif (ref)** dengan **elemen form** sehingga perubahan dari salah satu sisi otomatis tercermin di sisi lain.

## Cara Implementasi

```vue
<script setup lang="ts">
import { ref } from 'vue'

const searchQuery = ref('')
const inStockOnly = ref(false)
const sortBy = ref('title')
const category = ref('semua')
const qty = ref(1)
</script>

<template>
  <div class="filter-bar">
    <!-- Text -->
    <input v-model="searchQuery" placeholder="Cari buku..." />

    <!-- Number -->
    <input v-model.number="qty" type="number" min="1" />

    <!-- Checkbox -->
    <label>
      <input v-model="inStockOnly" type="checkbox" />
      Hanya yang tersedia
    </label>

    <!-- Select -->
    <select v-model="sortBy">
      <option value="title">Judul</option>
      <option value="price">Harga</option>
      <option value="rating">Rating</option>
    </select>

    <!-- Radio -->
    <label><input v-model="category" type="radio" value="fiksi" /> Fiksi</label>
    <label><input v-model="category" type="radio" value="nonfiksi" /> Nonfiksi</label>
    <label><input v-model="category" type="radio" value="semua" /> Semua</label>
  </div>
</template>
```

### Modifiers

| Modifier | Contoh | Fungsi |
|----------|--------|--------|
| `.lazy` | `v-model.lazy` | Update saat `change` (blur) bukan setiap ketik |
| `.number` | `v-model.number` | Parse otomatis ke number |
| `.trim` | `v-model.trim` | Hapus spasi kiri/kanan |

## Analogi — Toko Buku

`v-model` seperti **kaca dua arah di konter toko**. Dari luar (template), kamu bisa melihat dan menyentuh data. Dari dalam (script), data berubah dan terlihat di luar.

Kalau pelanggan menggeser slider harga di layar, di belakang layar harga filter ikut berubah — tanpa perlu pencet tombol apapun.

## Dipakai untuk apa

- Form input apa pun
- Search bar real-time
- Filter checkbox / radio / select
- Data binding form ke komponen

## Kesalahan Umum

| ❌ Salah | ✅ Benar |
|----------|----------|
| `v-model="searchQuery.value"` | `v-model="searchQuery"` |
| Lupa `.number` pada input type number | `v-model.number="qty"` |
| Mengubah props langsung dengan v-model | Gunakan `v-model` + `emit` / `computed` |

## Hubungan dengan Materi Sebelumnya

**Poin 16**: `ref()` membuat data reaktif. `v-model` adalah **cara paling umum mengubah data reaktif dari input user**.

**Poin 18 nanti**: Data dari `v-model` (misal `searchQuery`, `sortBy`) akan menjadi **dependency** dari `computed` untuk memfilter daftar buku secara otomatis.

## Soal Latihan

### Soal 1

Buat form filter toko buku dengan `v-model` untuk: input teks (judul buku), checkbox (hanya buku murah < Rp50.000), dan select (urutan: termurah / termahal).

<details>
<summary>Jawaban</summary>

```vue
<script setup lang="ts">
import { ref } from 'vue'

const judul = ref('')
const murahOnly = ref(false)
const urutan = ref('termurah')
</script>

<template>
  <div>
    <input v-model="judul" placeholder="Cari berdasarkan judul" />
    <label><input v-model="murahOnly" type="checkbox" /> Buku di bawah Rp50.000</label>
    <select v-model="urutan">
      <option value="termurah">Termurah</option>
      <option value="termahal">Termahal</option>
    </select>

    <p>Filter: {{ judul }} | Murah saja: {{ murahOnly }} | Urut: {{ urutan }}</p>
  </div>
</template>
```
</details>

### Soal 2

Buat input jumlah buku yang hanya menerima angka (gunakan `.number`), dengan tombol increment/decrement yang juga mengubah nilainya lewat ref `qty`.

<details>
<summary>Jawaban</summary>

```vue
<script setup lang="ts">
import { ref } from 'vue'

const qty = ref(1)

function tambah() {
  qty.value++
}

function kurang() {
  if (qty.value > 1) qty.value--
}
</script>

<template>
  <div>
    <button @click="kurang">−</button>
    <input v-model.number="qty" type="number" min="1" />
    <button @click="tambah">+</button>
    <p>Jumlah: {{ qty }}</p>
  </div>
</template>
```
</details>
