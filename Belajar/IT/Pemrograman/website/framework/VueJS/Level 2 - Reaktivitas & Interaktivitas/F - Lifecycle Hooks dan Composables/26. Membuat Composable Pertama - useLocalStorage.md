# 26. Membuat Composable Pertama — `useLocalStorage`

## Penjelasan

**Composable** adalah fungsi JavaScript/TypeScript yang memanfaatkan Composition API (`ref`, `computed`, `watch`, `onMounted`, dll) untuk membungkus logika yang bisa **dipakai ulang** di banyak komponen.

Ciri-ciri composable:

- Nama diawali `use` — konvensi Vue
- Mengembalikan object/array berisi state reaktif dan method
- Boleh memanggil composable lain di dalamnya
- Tidak terikat komponen tertentu

`useLocalStorage` adalah composable klasik yang mengelola persistensi data ke `localStorage` secara otomatis — ref otomatis tersimpan tiap kali berubah.

---

## Fungsi

- Menyediakan ref yang nilainya **otomatis disimpan** ke `localStorage` setiap kali berubah
- **Memuat** data dari `localStorage` saat pertama kali dibuat
- Menangani error `JSON.parse` jika data corrupt
- Menyediakan method `remove()` untuk menghapus data dari localStorage
- **Abstraksi:** komponen tidak perlu pusing dengan `localStorage.getItem` / `setItem` — cukup pakai ref biasa

---

## Cara Implementasi / Kode

```typescript
// composables/useLocalStorage.ts
import { ref, watch, type Ref } from 'vue'

export function useLocalStorage<T>(
  key: string,
  defaultValue: T
): { data: Ref<T>; remove: () => void } {
  // Load initial value from localStorage
  let initial = defaultValue
  const stored = localStorage.getItem(key)
  if (stored !== null) {
    try {
      initial = JSON.parse(stored) as T
    } catch {
      // data corrupt — fallback ke default
      initial = defaultValue
    }
  }

  const data = ref<T>(initial) as Ref<T>

  // Auto-save setiap kali data berubah
  watch(
    data,
    (newVal) => {
      localStorage.setItem(key, JSON.stringify(newVal))
    },
    { deep: true }
  )

  function remove() {
    localStorage.removeItem(key)
    data.value = defaultValue
  }

  return { data, remove }
}
```

### Contoh penggunaan di komponen:

```vue
<script setup lang="ts">
import { useLocalStorage } from '../composables/useLocalStorage'

interface Book {
  id: number
  title: string
  author: string
}

const { data: cart, remove: clearCart } = useLocalStorage<Book[]>('book-cart', [])
const { data: theme } = useLocalStorage<string>('theme', 'light')

function addToCart(book: Book) {
  cart.value.push(book)
}
</script>

<template>
  <p>Tema: {{ theme }}</p>
  <button @click="clearCart">Kosongkan Keranjang</button>
</template>
```

## Analogi — Toko Buku

`useLocalStorage` seperti **mesin stok otomatis** di toko buku.

Sebelum ada mesin ini, setiap pegawai harus:
1. Pagi hari: ambil buku catatan stok dari brankas (baca localStorage)
2. Setiap kali menjual: catat ulang di buku catatan dan juga salin ke brankas (manual getItem + setItem)
3. Sore hari: simpan buku catatan ke brankas

**Ribet dan rawan lupa.**

Dengan `useLocalStorage` (mesin stok otomatis):

- Pegawai cukup menulis di buku catatan (`cart.value.push(book)`)
- Mesin secara otomatis menyalin setiap perubahan ke brankas (`watch` + `localStorage.setItem`)
- Besok paginya, mesin otomatis memuat data dari brankas ke buku catatan yang baru (inisialisasi dari localStorage)
- Jika buku catatan robek/rusak (JSON corrupt), mesin memberikan buku baru kosong (fallback default)

Pegawai tinggal fokus jualan — tidak perlu mikir urusan simpan-menyimpan. **Itulah gunanya composable: menyembunyikan kompleksitas.**

## Dipakai untuk Apa (Use Case Nyata)

1. **Keranjang belanja** — cart items tetap ada meskipun halaman di-refresh
2. **Preferensi user** — tema gelap/terang, ukuran font, layout
3. **Draft form** — menyimpan input form sementara agar tidak hilang jika tidak sengaja tertutup
4. **Riwayat pencarian** — menyimpan kata kunci pencarian terakhir
5. **Game state** — skor, level, progress pemain

## Kesalahan Umum

| Kesalahan | Dampak | Cara Menghindari |
|-----------|--------|------------------|
| Tidak handle `JSON.parse` error | App crash saat data corrupt | Gunakan try-catch, fallback ke `defaultValue` |
| Lupa `{ deep: true }` untuk object/array | Hanya perubahan referensi yang tersimpan, mutasi nested tidak | Selalu set `{ deep: true }` jika data bisa nested |
| Key bentrok antar fitur | Data tertimpa | Gunakan prefix: `book-cart`, `book-filter` |
| Tidak fallback saat `localStorage` penuh / disabled (private mode Safari) | Error runtime | Bungkus panggilan `setItem` dalam try-catch |
| Menyimpan fungsi atau `undefined` | Tersimpan sebagai `null` | Hanya simpan data serializable (string, number, object, array) |

## Hubungan dengan Materi Sebelumnya

- **Poin 25 (`onMounted` / `onUnmounted`):** `useLocalStorage` menerapkan pola yang diajarkan di poin 25 — load data saat inisiasi (mirip onMounted), save data saat berubah. Bedanya, logika ini **dibungkus** dalam fungsi sehingga komponen lain bisa pakai tanpa menulis ulang.
- **Bagian D (`ref`):** `useLocalStorage` mengembalikan `Ref<T>` — penggunaannya persis seperti ref biasa.
- **Bagian E (`watch`):** Mekanisme auto-save memakai `watch` dengan `{ deep: true }`.
- **Level 1:** Dulu di Options API, persistensi dilakukan manual di `mounted()` dan `watch()`. Composable membuatnya reusable.

> **Konsep kunci:** Composable = kumpulan pola dari Bagian D, E, dan F yang dibungkus rapi untuk dipakai ulang.

## Soal Latihan + Jawaban

### Soal 1

Buat composable `useLocalStorage` yang mendukung tipe generik dan memiliki fitur `expiry` — data otomatis dihapus setelah waktu tertentu (dalam menit). Kembalikan juga `isExpired: ComputedRef<boolean>`.

<details>
<summary>Jawaban</summary>

```typescript
import { ref, computed, watch, type Ref, type ComputedRef } from 'vue'

export function useLocalStorage<T>(
  key: string,
  defaultValue: T,
  expiryMinutes?: number
): { data: Ref<T>; remove: () => void; isExpired: ComputedRef<boolean> } {
  let initial = defaultValue
  let expiryTime: number | null = null
  const stored = localStorage.getItem(key)

  if (stored !== null) {
    try {
      const parsed = JSON.parse(stored)
      if (parsed && typeof parsed === 'object' && '__expiry' in parsed) {
        expiryTime = parsed.__expiry
        if (Date.now() > expiryTime) {
          localStorage.removeItem(key)
          initial = defaultValue
        } else {
          initial = parsed.data as T
        }
      } else {
        initial = parsed as T
      }
    } catch {
      initial = defaultValue
    }
  }

  const data = ref<T>(initial) as Ref<T>

  const isExpired = computed(() => {
    if (expiryTime === null) return false
    return Date.now() > expiryTime
  })

  watch(
    data,
    (newVal) => {
      const toStore = expiryMinutes
        ? { data: newVal, __expiry: Date.now() + expiryMinutes * 60 * 1000 }
        : newVal
      localStorage.setItem(key, JSON.stringify(toStore))
    },
    { deep: true }
  )

  function remove() {
    localStorage.removeItem(key)
    data.value = defaultValue
  }

  return { data, remove, isExpired }
}
```

</details>

### Soal 2

Gunakan `useLocalStorage` di komponen `ThemeSwitcher` yang:
- Menyimpan tema (`'light'` / `'dark'`) ke localStorage
- Toggle tema saat tombol diklik
- Menerapkan class `dark` ke `<body>` saat tema dark
- Muat tema dari localStorage saat komponen dibuat

<details>
<summary>Jawaban</summary>

```vue
<script setup lang="ts">
import { watch } from 'vue'
import { useLocalStorage } from '../composables/useLocalStorage'

const { data: theme } = useLocalStorage<'light' | 'dark'>('theme', 'light')

function toggleTheme() {
  theme.value = theme.value === 'light' ? 'dark' : 'light'
}

watch(theme, (val) => {
  document.documentElement.setAttribute('data-theme', val)
  document.body.className = val === 'dark' ? 'dark' : ''
})
</script>

<template>
  <button @click="toggleTheme">
    {{ theme === 'light' ? '🌙 Mode Gelap' : '☀️ Mode Terang' }}
  </button>
</template>
```
