# 35. Membuat CartView — Halaman Keranjang Belanja

## Penjelasan

`CartView.vue` adalah halaman **keranjang belanja** lengkap. Ini adalah halaman yang menampilkan semua item yang sudah ditambahkan user, lengkap dengan quantity, total harga per item, dan ringkasan pesanan (order summary).

Halaman ini mengonsumsi data langsung dari **cart store** (Poin 33) — tidak perlu props dari parent, tidak perlu state lokal yang disinkronisasi.

---

## Fungsi

- Menampilkan daftar item di keranjang dengan detail (judul, harga, quantity, subtotal)
- User bisa mengubah quantity atau menghapus item langsung dari halaman ini
- Menampilkan **empty state** yang ramah jika keranjang kosong
- Menampilkan **order summary** — total harga, jumlah item
- Tombol "Lanjutkan ke Pembayaran" atau "Belanja Sekarang" (jika kosong)

---

## Cara Implementasi

### 1. Buat component `CartItemRow.vue`

```vue
<!-- src/components/CartItemRow.vue -->
<script setup lang="ts">
import type { CartItem } from '@/types/cart'
import { useCartStore } from '@/stores/cart'

defineProps<{ item: CartItem }>()
const cart = useCartStore()
</script>

<template>
  <div class="cart-item">
    <div class="item-info">
      <h4>{{ item.book.title }}</h4>
      <p class="author">{{ item.book.author }}</p>
      <p class="price">Rp{{ item.book.price.toLocaleString() }}</p>
    </div>

    <div class="item-actions">
      <button
        @click="cart.updateQuantity(item.book.id, item.quantity - 1)"
        :disabled="item.quantity <= 1"
      >−</button>

      <span class="quantity">{{ item.quantity }}</span>

      <button @click="cart.updateQuantity(item.book.id, item.quantity + 1)">
        +
      </button>

      <span class="subtotal">
        Rp{{ (item.book.price * item.quantity).toLocaleString() }}
      </span>

      <button class="btn-remove" @click="cart.removeItem(item.book.id)">
        ✕
      </button>
    </div>
  </div>
</template>
```

## Analogi — Toko Buku

`CartView` adalah **lantai kasir** — area di mana pelanggan melihat semua barang yang akan dibeli sebelum membayar.

| Elemen | Analogi |
|---|---|
| **Cart items** | Barang di atas meja kasir — satu per satu |
| **Quantity buttons** | Kasir menambah/mengurangi jumlah barang |
| **Order summary** | Bon sementara — jumlah + total harga |
| **Empty state** | Meja kasir kosong — tidak ada barang |
| **Tombol "Belanja Sekarang"** | Petunjuk ke pintu masuk: "Silakan ke rak buku dulu" |
| **"Kosongkan Keranjang"** | Semua barang dikembalikan ke rak |

Semua data berasal dari **papan informasi** (store) — tanpa pegawai harus menulis ulang satu per satu. Cukup lihat papan, langsung tahu apa yang akan dibeli pelanggan.

---

## Dipakai untuk apa

- **E-commerce:** Halaman keranjang penuh — ubah quantity, hapus item, lihat subtotal
- **Food delivery:** Review pesanan sebelum checkout — tambah catatan, hapus menu
- **Booking system:** Review jadwal yang dipilih sebelum bayar
- **Event registration:** Daftar tiket yang akan dibeli

---

## Kesalahan Umum

| Kesalahan | Akibat | Cara Benar |
|---|---|---|
| **Lupa handle empty state** | Tampilan putih kosong — tidak ramah | Selama `cart.isEmpty`, tampilkan pesan + tombol aksi |
| **Gunakan index sebagai `:key`** | Saat item dihapus, Vue salah tracking | Gunakan `item.book.id` yang unik |
| **Order summary tidak sticky** | User harus scroll ke bawah untuk lihat total | Gunakan `position: sticky` untuk sidebar |
| **Quantity bisa 0 atau negatif** | Harga kacau, buku gratis | `Math.max(1, quantity)` di action `updateQuantity` |
| **Tidak pakai `toLocaleString`** | Angka ditampilkan tanpa pemisah ribuan | `totalPrice.toLocaleString('id-ID')` |
| **Lupa daftarkan route `/cart`** | Halaman 404 saat navigasi | Pastikan route cart ada di `router/index.ts` |

---

## Hubungan dengan Materi Sebelumnya

- **Poin 34:** Store sudah diakses dari header (counter badge) dan BookCard (add to cart). Sekarang **halaman cart penuh** — daftar lengkap, edit quantity, hapus item.
- **Poin 33:** Semua getters (`items`, `totalItems`, `totalPrice`, `isEmpty`) dan actions (`updateQuantity`, `removeItem`, `clearCart`) yang dibuat di store, sekarang dipakai semua di halaman ini.
- **Poin 28 (Router):** Route `/cart` mengarah ke `CartView.vue`. Tanpa router, halaman ini tidak bisa diakses via URL.
- **Poin 23 (Cart State Level 2):** Di Level 2, cart hanya tampil sebagai counter di header. Sekarang halaman penuh dengan semua fungsionalitas.
- **Poin 31 (Navigation):** AppHeader punya `RouterLink` ke `/cart`, `RouterLink` di empty state kembali ke `/`.

### Soal 1

Tambahkan tombol **"Save for Later"** di setiap `CartItemRow` yang memindahkan item dari cart ke wishlist. Anggap ada fungsi `wishlist.addItem(book)` di wishlist store (akan dibuat di Poin 37). Setelah dipindah, item harus dihapus dari cart.

<details>
<summary>Jawaban Soal 1</summary>

```vue
<script setup lang="ts">
import { useCartStore } from '@/stores/cart'
import { useWishlistStore } from '@/stores/wishlist'

const cart = useCartStore()
const wishlist = useWishlistStore()

function saveForLater(item: CartItem) {
  wishlist.addItem(item.book)
  cart.removeItem(item.book.id)
}
</script>

<template>
  <div class="cart-item">
    <!-- ... item info ... -->
    <div class="item-actions">
      <!-- ... quantity buttons ... -->
      <button @click="saveForLater(item)" class="btn-save">
        Simpan untuk Nanti
      </button>
      <button @click="cart.removeItem(item.book.id)" class="btn-remove">✕</button>
    </div>
  </div>
</template>
```

### Soal 2

Buat sebuah **progres bar** di atas daftar cart items yang menunjukkan berapa item dari total yang sudah mencapai quantity >= 2 (anggaran "quantity minimal untuk diskon" adalah 2). Misal: ada 3 item di cart, 2 item sudah quantity >= 2, maka progress = 66%.

<details>
<summary>Jawaban Soal 2</summary>

**Opsi 1 — computed di CartView:**

```typescript
const itemsEligibleForDiscount = computed(() =>
  cart.items.filter(item => item.quantity >= 2).length
)

const discountProgress = computed(() =>
  cart.isEmpty
    ? 0
    : Math.round((itemsEligibleForDiscount.value / cart.items.length) * 100)
)
```

```vue

    </div>
  </div>
```

```typescript
// di cart store
const itemsEligibleForDiscount = computed(() =>
  items.value.filter(item => item.quantity >= 2).length
```
