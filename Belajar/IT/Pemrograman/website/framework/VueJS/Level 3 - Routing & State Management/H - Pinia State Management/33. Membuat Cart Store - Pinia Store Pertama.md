# 33. Membuat Cart Store — Pinia Store Pertama

## Penjelasan

**Pinia** adalah state management resmi Vue 3. Ia menggantikan Vuex dengan API yang lebih sederhana, dukungan TypeScript penuh, dan integrasi mulus dengan Composition API.

Sebuah **store** di Pinia terdiri dari 3 bagian utama:

| Bagian | Padanan Vue | Fungsi |
|---|---|---|
| **State** | `ref()` / `reactive()` | Data utama (reaktif) |
| **Getters** | `computed()` | Turunan data dari state (otomatis update) |
| **Actions** | `function()` | Method untuk memutasi state atau logic async |

### Syntax Composition API (setup store)

Kita gunakan **setup syntax** (mirip `<script setup>`) karena lebih natural dan TypeScript-friendly:

```typescript
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const useCartStore = defineStore('cart', () => {
  // state
  const items = ref<CartItem[]>([])

  // getters
  const totalItems = computed(() => ...)
  const totalPrice = computed(() => ...)

  // actions
  function addItem(book: Book) { ... }
  function removeItem(bookId: number) { ... }

  return { items, totalItems, totalPrice, addItem, removeItem }
})
```

---

## Fungsi

- Menyimpan state keranjang belanja **secara global** — semua komponen bisa akses
- Menghitung turunan data (total item, total harga) secara otomatis via getters
- Menyediakan method untuk memanipulasi cart dengan aman melalui actions
- Menghilangkan **props drilling** — state tidak perlu diturunkan parent-child

### 3. Definisikan tipe `CartItem`

```typescript
// src/types/cart.ts
import type { Book } from './book'

export interface CartItem {
  book: Book
  quantity: number
}
```

### 4. Buat file `src/stores/cart.ts`

```typescript
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import type { CartItem } from '@/types/cart'
import type { Book } from '@/types/book'

export const useCartStore = defineStore('cart', () => {
  // ─── State ───
  const items = ref<CartItem[]>([])

  // ─── Getters ───
  const totalItems = computed(() =>
    items.value.reduce((sum, item) => sum + item.quantity, 0)
  )

  const totalPrice = computed(() =>
    items.value.reduce((sum, item) => sum + item.book.price * item.quantity, 0)
  )

  const isEmpty = computed(() => items.value.length === 0)

  // ─── Actions ───
  function addItem(book: Book, quantity = 1) {
    const existing = items.value.find(item => item.book.id === book.id)
    if (existing) {
      existing.quantity += quantity
    } else {
      items.value.push({ book, quantity })
    }
  }

  function removeItem(bookId: number) {
    items.value = items.value.filter(item => item.book.id !== bookId)
  }

  function updateQuantity(bookId: number, quantity: number) {
    const item = items.value.find(i => i.book.id === bookId)
    if (item) {
      item.quantity = Math.max(1, quantity) // minimal 1
    }
  }

  function clearCart() {
    items.value = []
  }

  return {
    items, totalItems, totalPrice, isEmpty,
    addItem, removeItem, updateQuantity, clearCart
  }
})
```

### 5. Gunakan store di komponen

```vue
<script setup lang="ts">
import { useCartStore } from '@/stores/cart'

const cart = useCartStore()

// Akses state & getters
console.log(cart.totalItems)
console.log(cart.totalPrice)

// Panggil action
cart.addItem({ id: 1, title: 'Vue.js', price: 95000, author: 'Rudi' })
</script>
```

## Kesalahan Umum

| Kesalahan | Akibat | Cara Benar |
|---|---|---|
| **Mutasi state langsung dari komponen** | `cart.items.value.push(...)` — bekerja tapi melanggar pola | Selalu gunakan **actions**: `cart.addItem(book)` |
| **Lupa return nilai di setup store** | `defineStore` error karena tidak return object | Pastikan ada `return { items, totalItems, ... }` |
| **Membuat state di luar `defineStore`** | State tidak reaktif secara global | State HARUS di dalam fungsi `defineStore` |
| **Mengubah state tanpa `.value`** | Pinia unwraps ref otomatis, jadi `items.value.push` salah — sebenarnya `items.push` saja | Di setup store, gunakan `.value` seperti biasa. Saat akses dari komponen, tidak perlu `.value` |
| **Menyimpan data non-serializable di state** | Error saat hydration atau persist | Hindari simpan fungsi / DOM element di state |
| **Bikin banyak store terpisah untuk satu domain** | Store jadi sulit di-maintain | Satu domain = satu store (cart, user, product) |

**Catatan penting:** Saat di dalam komponen, akses state/getters langsung tanpa `.value`:
```typescript
const cart = useCartStore()
console.log(cart.totalItems) // ✅ benar — Pinia unwraps otomatis
```

Tapi di dalam **setup store** (fungsi `defineStore`), kita pakai `.value` seperti `ref` biasa.

- **Poin 17 (Computed Properties):** Getters di Pinia adalah `computed` — konsep yang sama, hanya ditempatkan di store.
- **Poin 20 (Composables):** Pinia setup store mirip dengan composable — bedanya Pinia terdaftar secara global dan bisa diakses dari komponen mana pun.

### Soal 1

Buat sebuah getter bernama `formattedPrice` yang mengembalikan `totalPrice` dalam format mata uang Rupiah (`Rp1.000.000`). Gunakan `toLocaleString('id-ID')`.

<details>
<summary>Jawaban Soal 1</summary>

```typescript
const formattedPrice = computed(() =>
  totalPrice.value.toLocaleString('id-ID', {
    style: 'currency',
    currency: 'IDR',
    minimumFractionDigits: 0
  })
)

// Jangan lupa tambahkan di return:
return { ..., formattedPrice }
```

Atau versi singkat tanpa currency symbol:

```typescript
const formattedPrice = computed(() =>
  `Rp${totalPrice.value.toLocaleString('id-ID')}`
)
```

Buat sebuah action `setItemsFromLocalStorage(items: CartItem[])` yang mengganti seluruh isi cart dengan data dari array yang diberikan. Action ini berguna untuk restore cart dari localStorage (akan relevan di Poin 36).

<details>
<summary>Jawaban Soal 2</summary>

```typescript
function setItemsFromLocalStorage(savedItems: CartItem[]) {

// Tambahkan di return:

```

**Catatan:** Di setup store, `items` adalah `ref`, jadi kita set `.value`-nya langsung. Reactive reference akan otomatis melacak perubahan.
