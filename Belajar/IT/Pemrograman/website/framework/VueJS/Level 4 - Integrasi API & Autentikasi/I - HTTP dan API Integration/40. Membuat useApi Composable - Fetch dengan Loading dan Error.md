# 40. Membuat useApi Composable — Fetch dengan Loading dan Error

## Penjelasan

Setiap kali aplikasi memanggil API, ada tiga state yang selalu muncul: **loading** (sedang mengambil data), **data** (hasilnya), dan **error** (jika gagal). Tanpa pola yang konsisten, setiap komponen akan menulis ulang kode yang sama — deklarasi `ref`, `try/catch`, `isLoading`, dan reset state.

`useApi<T>()` adalah generic composable yang membungkus pola tersebut menjadi reusable. Dengan generic `<T>`, composable ini type-safe — komponen tahu bentuk data yang akan diterima.

## Fungsi

- Menyediakan state management konsisten: `data`, `isLoading`, `error`
- Method `execute()` untuk menjalankan API call
- Method `reset()` untuk mengembalikan state ke awal
- Type-safe dengan generic `<T>`
- Mencegah boilerplate code berulang di setiap komponen

## Cara Implementasi

### 1. Composable `useApi` (`src/composables/useApi.ts`)

```typescript
import { ref, type Ref } from 'vue'

type AsyncFunction<T> = (...args: any[]) => Promise<T>

export function useApi<T>() {
  const data = ref<T | null>(null) as Ref<T | null>
  const isLoading = ref(false)
  const error = ref<string | null>(null)

  let abortController: AbortController | null = null

  async function execute(fn: AsyncFunction<T>): Promise<T | null> {
    // Cancel previous request if still running
    if (isLoading.value) {
      abortController?.abort()
    }
    abortController = new AbortController()

    isLoading.value = true
    error.value = null

    try {
      const result = await fn()
      data.value = result
      return result
    } catch (err: any) {
      const message =
        err?.response?.data?.message ||
        err?.message ||
        'Terjadi kesalahan yang tidak diketahui'
      error.value = message
      return null
    } finally {
      isLoading.value = false
    }
  }

  function reset() {
    data.value = null
    isLoading.value = false
    error.value = null
  }

  return {
    data,
    isLoading,
    error,
    execute,
    reset,
  }
}
```

### 2. Contoh Penggunaan di Komponen

```vue
<script setup lang="ts">
import { onMounted } from 'vue'
import { useApi } from '@/composables/useApi'
import { booksApi } from '@/api/books.api'
import type { PaginatedResult, Book } from '@/types/book'

const { data, isLoading, error, execute } = useApi<PaginatedResult<Book>>()

onMounted(() => {
  execute(() => booksApi.getAll({ page: 1, limit: 10 }))
})

function retry() {
  execute(() => booksApi.getAll({ page: 1, limit: 10 }))
}
</script>

<template>
  <div v-if="isLoading">Memuat data...</div>
  <div v-else-if="error">
    <p>{{ error }}</p>
    <button @click="retry">Coba Lagi</button>
  </div>
  <div v-else-if="data">
    <div v-for="book in data.data" :key="book.id">
      {{ book.title }}
    </div>
  </div>
</template>
```

### 3. Variasi: `useApiLazy` (tidak auto-execute)

```typescript
export function useApiLazy<T>() {
  const result = useApi<T>()
  return result
  // user memanggil .execute() manual
}
```

## Analogi — Toko Buku

`useApi` seperti **"prosedur standar menerima telepon"** di toko. Ada 3 langkah yang selalu sama:

1. **Angkat telepon** → `isLoading = true` (tunggu, jangan diganggu)
2. **Catat pesan** → `data = result` (barang sudah diterima)
3. **Tutup telepon** → `isLoading = false` (selesai)

Kalau sambungan bermasalah → **catat kesalahan** → `error = "Gangguan sambungan"`.

Prosedur ini **SAMA** untuk semua telepon — tidak peduli menelepon gudang buku, gudang furnitur, atau bagian akuntansi. Generic `<T>` memastikan **catatan selalu sesuai** jenis barang yang dipesan.

Misal:
- `useApi<Book>()` → catatan untuk barang buku
- `useApi<User[]>()` → catatan untuk daftar pegawai
- `useApi<PaginatedResult<Book>>()` → catatan untuk kumpulan buku dengan halaman

## Dipakai untuk Apa

- Semua komponen yang melakukan fetch data dari API
- Form submission: `execute` untuk POST/PUT
- Infinite scroll: panggil `execute` berulang dengan page berbeda
- Refresh data setelah mutasi: panggil ulang `execute`

## Kesalahan Umum

| Kesalahan | Akibat | Solusi |
|---|---|---|
| Lupa generic type `<T>` | `data` bertipe `unknown`, tidak auto-complete | Selalu tentukan `useApi<Book[]>()` |
| Tidak reset sebelum execute | Data lama tercampur data baru | Panggil `reset()` atau timpa di dalam `execute` |
| Race condition — 2 execute berbarengan | Data dari request pertama ditimpa request kedua | Gunakan AbortController untuk batalkan request lama |
| Execute di setup (sync) | Promise tidak ter-trigger | Panggil `execute` di `onMounted` |
| Error tidak dibaca detailnya | Pesan error generik "Terjadi kesalahan" | Parse `error.response.data.message` dari NestJS |

## Hubungan dengan Materi Sebelumnya

Di **Poin 38** kita punya Axios instance. Di **Poin 39** kita punya fungsi API (booksApi). Sekarang `useApi` menghubungkan keduanya — menyediakan **cara standar** untuk memanggil API dan mengelola state.

Tanpa useApi, setiap komponen akan seperti ini:

```typescript
// Tanpa useApi — boilerplate berulang
const books = ref<Book[]>([])
const isLoading = ref(false)
const error = ref<string | null>(null)

async function fetchBooks() {
  isLoading.value = true
  try {
    const res = await booksApi.getAll()
    books.value = res.data
  } catch (err: any) {
    error.value = err.message
  } finally {
    isLoading.value = false
  }
}
```

Dengan useApi, kode di atas jadi 3 baris:

```typescript
const { data, isLoading, error, execute } = useApi<PaginatedResult<Book>>()
onMounted(() => execute(() => booksApi.getAll()))
```

## Soal Latihan + Jawaban

### Soal 1

Buat composable `useApiWithCache<T>` yang extend useApi dengan fitur caching — jika data sudah pernah di-fetch, gunakan data cache daripada request baru (selama belum expired 30 detik).

<details>
<summary>Jawaban</summary>

```typescript
import { useApi } from './useApi'
import { ref } from 'vue'

export function useApiWithCache<T>(cacheKey: string, ttl: number = 30000) {
  const cache = ref<Map<string, { data: T; timestamp: number }>>(new Map())
  const api = useApi<T>()

  async function executeWithCache(
    fn: () => Promise<T>,
  ): Promise<T | null> {
    const cached = cache.value.get(cacheKey)
    if (cached && Date.now() - cached.timestamp < ttl) {
      api.data.value = cached.data
      return cached.data
    }

    const result = await api.execute(fn)
    if (result) {
      cache.value.set(cacheKey, { data: result, timestamp: Date.now() })
    }
    return result
  }

  return { ...api, execute: executeWithCache }
}
```

</details>

### Soal 2

Buat fungsi `executeSequentially` di dalam useApi yang menerima array fungsi dan menjalankannya satu per satu (serial), bukan paralel. Data dari setiap fungsi dikumpulkan dalam array.

<details>
<summary>Jawaban</summary>

```typescript
async function executeSequentially(
  fns: AsyncFunction<T>[],
): Promise<T[]> {
  const results: T[] = []
  isLoading.value = true
  error.value = null

  try {
    for (const fn of fns) {
      const result = await fn()
      results.push(result)
    }
    data.value = results[results.length - 1] ?? null
    return results
  } catch (err: any) {
    error.value = err.message || 'Eksekusi serial gagal'
    return []
  } finally {
    isLoading.value = false
  }
}
```

</details>
