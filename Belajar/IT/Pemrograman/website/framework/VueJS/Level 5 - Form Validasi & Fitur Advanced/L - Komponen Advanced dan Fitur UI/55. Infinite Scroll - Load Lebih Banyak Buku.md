# 55. Infinite Scroll — Load Lebih Banyak Buku

## Penjelasan

**Infinite scroll** adalah teknik memuat data lebih banyak secara otomatis saat user scroll ke bagian bawah halaman. Implementasi menggunakan **IntersectionObserver** — sebuah API browser yang mendeteksi kapan suatu elemen terlihat di viewport.

Ada dua pendekatan:
1. **Native IntersectionObserver API**
2. **`useIntersectionObserver` dari VueUse** (`@vueuse/core`) — lebih ringkas dan reaktif.

Pola: letakkan elemen `trigger` (`
` kosong) di bawah daftar buku. Saat elemen itu terlihat, panggil `loadMore()` → increment `page` → fetch data dari API → **append** hasil ke array (bukan replace). Gunakan flag `hasMore` dari `response.meta.totalPages` dan guard `!isLoadingMore.value` untuk mencegah trigger ganda.

## Fungsi

UX yang lebih smooth — user tinggal scroll, data termuat otomatis tanpa klik tombol "Load More" atau navigasi halaman.

## Cara Implementasi / Kode

### Opsi A — Native IntersectionObserver

```vue
<!-- views/HomeView.vue -->
<script setup lang="ts">
import { ref, onMounted, onUnmounted } from 'vue'
import { booksApi } from '@/api/books'
import type { Book } from '@/types'

const books = ref<Book[]>([])
const page = ref(1)
const isLoadingMore = ref(false)
const hasMore = ref(true)
const triggerEl = ref<HTMLDivElement | null>(null)
let observer: IntersectionObserver | null = null

async function loadMore() {
  if (isLoadingMore.value || !hasMore.value) return
  isLoadingMore.value = true

  try {
    const response = await booksApi.fetchAll({ page: page.value, limit: 12 })
    books.value.push(...response.data)
    hasMore.value = page.value < response.meta.totalPages
    page.value++
  } catch (err) {
    console.error('Gagal memuat buku:', err)
  } finally {
    isLoadingMore.value = false
  }
}

onMounted(() => {
  observer = new IntersectionObserver(
    ([entry]) => {
      if (entry.isIntersecting) loadMore()
    },
    { threshold: 0.1 }
  )
  if (triggerEl.value) observer.observe(triggerEl.value)
})

onUnmounted(() => {
  observer?.disconnect()
})
</script>

<template>
  <div class="book-grid">
    <div v-for="book in books" :key="book.id" class="book-card">
      {{ book.title }}
    </div>
  </div>

  <div ref="triggerEl" class="trigger">
    <p v-if="isLoadingMore">Memuat lebih banyak...</p>
    <p v-if="!hasMore && books.length > 0">
      Semua buku telah ditampilkan
    </p>
  </div>
</template>
```

import { useIntersectionObserver } from '@vueuse/core'

const books = ref<Book[]>([])

useIntersectionObserver(
  triggerEl,
  ([entry]) => {
    if (entry.isIntersecting) loadMore()

## Analogi — Toko Buku

Dulu etalase toko punya 12 buku per halaman, dengan nomor halaman di bawah — user harus klik "Halaman 2" untuk lihat buku berikutnya. Sekarang etalase seperti **rak tanpa ujung** — saat user scroll ke bawah, buku baru otomatis muncul. Seperti **conveyor belt** yang terus berjalan. Ada sensor di ujung rak (`IntersectionObserver`) — saat pengunjung sampai ke buku terakhir, sensor aktif dan sistem langsung menambah buku baru dari gudang. Muncul teks kecil "Memuat lebih banyak..." sebagai feedback.

## Kesalahan Umum

| Kesalahan | Solusi |
|-----------|--------|
| `loadMore` terpanggil berkali-kali (tanpa guard) | Guard dengan `if (isLoadingMore.value || !hasMore.value) return` di awal fungsi |
| Data duplikat karena tidak track `page` | Pastikan `page.value` di-increment hanya setelah fetch sukses, dan `response.data` di-*append* bukan di-*replace* |
| Race condition saat request cepat | Gunakan flag `isLoadingMore` dan nonaktifkan observer sementara (`observer.unobserve`) selama loading |
| Memory leak — observer tidak di-disconnect | Panggil `observer.disconnect()` di `onUnmounted` (native) atau VueUse otomatis cleanup |
| Scroll posisi hilang saat kembali dari halaman detail | Simpan scroll position di store / gunakan `keep-alive` |

## Soal Latihan

### Soal 1

Gabungkan infinite scroll dengan **search** dan **filter kategori**. Setiap kali query filter berubah, reset `page` ke 1, kosongkan `books`, lalu `loadMore()` dari awal.

<details>
<summary>Jawaban</summary>

```ts
const searchQuery = ref('')
const category = ref('')

watch([searchQuery, category], () => {
  page.value = 1
  books.value = []
  hasMore.value = true
  loadMore()
})

async function loadMore() {
  if (isLoadingMore.value || !hasMore.value) return
  isLoadingMore.value = true

  try {
    const params = {
      page: page.value,
      limit: 12,
      q: searchQuery.value,
      category: category.value,
    }
    const response = await booksApi.fetchAll(params)
    books.value.push(...response.data)
    hasMore.value = page.value < response.meta.totalPages
    page.value++
  } finally {
    isLoadingMore.value = false
  }
}
```

### Soal 2

Implementasi **virtual scroll** untuk daftar buku yang sangat besar (>10.000 item). Gunakan `vue-virtual-scroller` agar hanya item yang terlihat di DOM yang di-render.

<details>
<summary>Jawaban</summary>

```bash
npm install vue-virtual-scroller
```

```vue
<script setup lang="ts">
import { RecycleScroller } from 'vue-virtual-scroller'
import 'vue-virtual-scroller/dist/vue-virtual-scroller.css'
</script>

<template>
  <RecycleScroller
    class="scroller"
    :items="books"
    :item-size="200"
    key-field="id"
    v-slot="{ item }"
  >
    <div class="book-card">
      <h4>{{ item.title }}</h4>
      <p>{{ item.author }}</p>
    </div>
  </RecycleScroller>

  <!-- Trigger tetap ada di bawah scroller -->
  <div ref="triggerEl" @visible="loadMore" />
</template>
```

**Catatan:** `vue-virtual-scroller` tidak kompatibel dengan IntersectionObserver biasa. Solusi: gunakan event `@visible` dari `vue-virtual-scroller` atau pakai `@vueuse/components` dengan `UseIntersectionObserver`.

</details>
