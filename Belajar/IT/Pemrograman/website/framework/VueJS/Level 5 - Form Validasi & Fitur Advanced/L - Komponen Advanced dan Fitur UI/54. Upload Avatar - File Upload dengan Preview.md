# 54. Upload Avatar — File Upload dengan Preview

## Penjelasan

Komponen `AvatarUpload` memungkinkan user mengunggah foto profil. File `input` tipe `file` disembunyikan — user berinteraksi melalui tombol/area klik. Saat file dipilih, **preview** langsung tampil menggunakan `URL.createObjectURL(file)`. Sebelum upload, validasi ukuran (max 2MB) dan tipe file (hanya `image/jpeg`, `image/png`, `image/webp`).

Upload dilakukan dengan `FormData` via API, lalu store auth diperbarui dengan URL avatar baru.

## Fungsi

Memberi kemampuan user mengubah foto profil mereka — dari avatar default menjadi foto sendiri.

## Cara Implementasi / Kode

### 1. Komponen `AvatarUpload`

```vue
<!-- components/AvatarUpload.vue -->
<script setup lang="ts">
import { ref, computed } from 'vue'
import { useAuthStore } from '@/stores/auth'
import { usersApi } from '@/api/users'
import { useToast } from '@/composables/useToast'

const authStore = useAuthStore()
const { success, error } = useToast()

const fileInput = ref<HTMLInputElement | null>(null)
const previewUrl = ref<string | null>(null)
const selectedFile = ref<File | null>(null)
const isLoading = ref(false)
const uploadError = ref<string | null>(null)

const ALLOWED_TYPES = ['image/jpeg', 'image/png', 'image/webp']
const MAX_SIZE = 2 * 1024 * 1024 // 2MB

function triggerFileSelect() {
  fileInput.value?.click()
}

function onFileSelected(e: Event) {
  uploadError.value = null
  const input = e.target as HTMLInputElement
  const file = input.files?.[0]
  if (!file) return

  // Validasi tipe
  if (!ALLOWED_TYPES.includes(file.type)) {
    uploadError.value = 'Format tidak didukung. Gunakan JPG, PNG, atau WebP.'
    return
  }

  // Validasi ukuran
  if (file.size > MAX_SIZE) {
    uploadError.value = 'Ukuran file maksimal 2MB.'
    return
  }

  selectedFile.value = file
  previewUrl.value = URL.createObjectURL(file)
}

async function uploadAvatar() {
  if (!selectedFile.value) return
  isLoading.value = true
  uploadError.value = null

  try {
    const formData = new FormData()
    formData.append('avatar', selectedFile.value)

    const response = await usersApi.uploadAvatar(formData)
    authStore.user.avatar = response.avatarUrl
    success('Foto profil berhasil diperbarui')
    selectedFile.value = null
  } catch (err) {
    error('Gagal mengunggah avatar')
  } finally {
    isLoading.value = false
  }
}

function cancelPreview() {
  if (previewUrl.value) {
    URL.revokeObjectURL(previewUrl.value)
    previewUrl.value = null
  }
  selectedFile.value = null
  if (fileInput.value) fileInput.value.value = ''
}

const currentAvatar = computed(() => {
  return previewUrl.value ?? authStore.user?.avatar ?? '/default-avatar.png'
})
</script>

<template>
  <div class="avatar-upload">
    <input
      ref="fileInput"
      type="file"
      accept="image/jpeg,image/png,image/webp"
      class="hidden-input"
      @change="onFileSelected"
    />

    <div class="avatar-preview" @click="triggerFileSelect">
      <img :src="currentAvatar" alt="Preview avatar" />
      <div class="overlay">
        <span>Klik untuk ganti foto</span>
      </div>
    </div>

    <p v-if="uploadError" class="error-text">{{ uploadError }}</p>

    <div v-if="selectedFile" class="actions">
      <button :disabled="isLoading" @click="uploadAvatar">
        {{ isLoading ? 'Mengunggah...' : 'Simpan' }}
      </button>
      <button @click="cancelPreview" :disabled="isLoading">Batal</button>
    </div>
  </div>
</template>
```

### 2. API Service

```ts
// api/users.ts
export const usersApi = {
  async uploadAvatar(formData: FormData): Promise<{ avatarUrl: string }> {
    // FormData otomatis set Content-Type: multipart/form-data
    const { data } = await http.post('/users/avatar', formData)
    return data
  }
}
```

## Analogi — Toko Buku

Seperti **foto anggota** di kartu toko. Dulu fotonya bawaan (default avatar). Sekarang anggota bisa pasang foto sendiri. Ada bilik foto digital: klik tombol → pilih file → lihat preview (bisa ganti-ganti sebelum disimpan) → kalau sudah cocok, klik "Simpan". Ukuran file dicek — kalau terlalu besar (lebih dari 2MB), tolak dengan pesan: "Foto terlalu besar, maksimal 2MB". File `input` disembunyikan, yang terlihat hanya preview dan tombol.

## Dipakai untuk Apa

- Update foto profil di aplikasi web
- Upload gambar produk di dashboard toko
- Upload bukti transfer / scan dokumen
- Upload sampul buku di perpustakaan online

## Kesalahan Umum

| Kesalahan | Solusi |
|-----------|--------|
| Lupa set `Content-Type: multipart/form-data` | Pakai `FormData`, browser otomatis atur header-nya |
| `URL.createObjectURL` tidak di-revoke → memory leak | Panggil `URL.revokeObjectURL()` saat preview dibatalkan atau komponen unmount (`onUnmounted`) |
| Validasi hanya di frontend | Tetap validasi ukuran & tipe di backend juga — attacker bisa bypass frontend |
| Nilai `fileInput.value` tidak di-reset | Set `fileInput.value.value = ''` agar user bisa pilih file yang sama dua kali |
| `loading` state tidak dipakai → user klik berulang | Disable tombol selama `isLoading = true` |

## Soal Latihan

### Soal 1

Buat fungsi **compress image** sebelum upload. Jika resolusi gambar > 1024x1024, resize otomatis ke 512x512 menggunakan Canvas API, lalu kirim sebagai Blob.

<details>
<summary>Jawaban</summary>

```ts
function compressImage(file: File, maxW = 512, maxH = 512): Promise<Blob> {
  return new Promise((resolve, reject) => {
    const img = new Image()
    img.src = URL.createObjectURL(file)
    img.onload = () => {
      const canvas = document.createElement('canvas')
      let w = img.width, h = img.height
      if (w > maxW || h > maxH) {
        const ratio = Math.min(maxW / w, maxH / h)
        w = w * ratio
        h = h * ratio
      }
      canvas.width = w
      canvas.height = h
      const ctx = canvas.getContext('2d')!
      ctx.drawImage(img, 0, 0, w, h)
      canvas.toBlob(blob => {
        if (blob) resolve(blob)
        else reject(new Error('Compress gagal'))
      }, file.type, 0.8)
    }
    img.onerror = () => reject(new Error('Gagal load gambar'))
  })
}
```

Gunakan di `uploadAvatar`:

```ts
const compressed = await compressImage(selectedFile.value)
const formData = new FormData()
formData.append('avatar', compressed, selectedFile.value.name)
```

```ts
const dragOver = ref(false)

function onDrop(e: DragEvent) {
  dragOver.value = false
  const file = e.dataTransfer?.files[0]
  if (!file) return
  // Konversi DragEvent ke File, validasi & preview
  const fakeInput = { target: { files: [file] } } as unknown as Event
  onFileSelected(fakeInput)
}
```
