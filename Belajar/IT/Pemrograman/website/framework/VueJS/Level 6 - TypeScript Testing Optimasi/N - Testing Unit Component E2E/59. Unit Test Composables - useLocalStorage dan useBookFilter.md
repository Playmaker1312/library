# 59. Unit Test Composables — `useLocalStorage` dan `useBookFilter`

## Penjelasan

**Unit test** adalah pengujian terhadap unit kode terkecil (fungsi, composable, atau utilitas) secara **terisolasi** — tanpa bergantung pada DOM, komponen Vue, atau browser. Dengan Vitest (bundling `create-vue` sudah menyertakannya), kita dapat menjalankan test dengan cepat via Node.js.

File test biasanya diletakkan di `src/composables/__tests__/` dengan akhiran `.spec.ts`.

## Fungsi

- Memastikan setiap composable/logic berfungsi sesuai spesifikasi
- Menangkap regresi saat kode diubah
- Memberi kepercayaan diri untuk refactor tanpa merusak perilaku
- Menjadi dokumentasi hidup tentang input/output sebuah fungsi

### 3. Composable: `useLocalStorage`

```typescript
// src/composables/useLocalStorage.ts
import { ref, watch, type Ref } from 'vue'

export function useLocalStorage<T>(key: string, defaultValue: T): Ref<T> {
  const stored = localStorage.getItem(key)
  const data = ref<T>(stored ? JSON.parse(stored) : defaultValue)

  watch(data, (newVal) => {
    localStorage.setItem(key, JSON.stringify(newVal))
  }, { deep: true })

  return data
}
```

### 4. Test: `useLocalStorage`

```typescript
// src/composables/__tests__/useLocalStorage.spec.ts
import { describe, it, expect, beforeEach } from 'vitest'
import { useLocalStorage } from '../useLocalStorage'

describe('useLocalStorage', () => {
  beforeEach(() => {
    localStorage.clear()
  })

  it('mengembalikan default value jika localStorage kosong', () => {
    const count = useLocalStorage('count', 0)
    expect(count.value).toBe(0)
  })

  it('menyimpan nilai ke localStorage saat value berubah', () => {
    const count = useLocalStorage('count', 0)
    count.value = 5
    expect(JSON.parse(localStorage.getItem('count')!)).toBe(5)
  })

  it('membaca nilai yang sudah tersimpan di localStorage', () => {
    localStorage.setItem('name', JSON.stringify('Buku Vue'))
    const name = useLocalStorage('name', 'default')
    expect(name.value).toBe('Buku Vue')
  })

  it('bekerja dengan multiple keys secara independen', () => {
    const a = useLocalStorage('keyA', 'A')
    const b = useLocalStorage('keyB', 'B')
    a.value = 'X'
    expect(JSON.parse(localStorage.getItem('keyA')!)).toBe('X')
    expect(JSON.parse(localStorage.getItem('keyB')!)).toBe('B')
  })
})
```

### 5. Composable: `useBookFilter`

```typescript
// src/composables/useBookFilter.ts
export interface Book {
  id: number
  title: string
  author: string
  price: number
  inStock: boolean
}

export function useBookFilter(books: Book[]) {
  function filterBySearch(query: string) {
    if (!query.trim()) return books
    const q = query.toLowerCase()
    return books.filter(
      (b) =>
        b.title.toLowerCase().includes(q) ||
        b.author.toLowerCase().includes(q)
    )
  }

  function filterByStock(inStockOnly: boolean) {
    if (!inStockOnly) return books
    return books.filter((b) => b.inStock)
  }

  function filterByPrice(maxPrice: number) {
    return books.filter((b) => b.price <= maxPrice)
  }

  return { filterBySearch, filterByStock, filterByPrice }
}
```

### 6. Test: `useBookFilter`

```typescript
// src/composables/__tests__/useBookFilter.spec.ts
import { describe, it, expect } from 'vitest'
import { useBookFilter, type Book } from '../useBookFilter'

const sampleBooks: Book[] = [
  { id: 1, title: 'Vue.js Dasar', author: 'Andi', price: 75000, inStock: true },
  { id: 2, title: 'TypeScript Lanjut', author: 'Budi', price: 120000, inStock: false },
  { id: 3, title: 'Nuxt untuk Pemula', author: 'Andi', price: 95000, inStock: true },
]

describe('useBookFilter', () => {
  it('filterBySearch — mencari berdasarkan judul', () => {
    const { filterBySearch } = useBookFilter(sampleBooks)
    const result = filterBySearch('vue')
    expect(result).toHaveLength(1)
    expect(result[0].title).toBe('Vue.js Dasar')
  })

  it('filterBySearch — mencari berdasarkan penulis', () => {
    const { filterBySearch } = useBookFilter(sampleBooks)
    const result = filterBySearch('budi')
    expect(result).toHaveLength(1)
    expect(result[0].author).toBe('Budi')
  })

  it('filterByStock — hanya buku tersedia', () => {
    const { filterByStock } = useBookFilter(sampleBooks)
    const result = filterByStock(true)
    expect(result).toHaveLength(2)
    expect(result.every((b) => b.inStock)).toBe(true)
  })

  it('filterByPrice — buku di bawah harga maksimal', () => {
    const { filterByPrice } = useBookFilter(sampleBooks)
    const result = filterByPrice(100000)
    expect(result).toHaveLength(2)
  })
})
```

## Analogi — Toko Buku

Testing composable seperti **"uji coba mesin kasir di bengkel"**, bukan di toko.

Mesin kasir dicabut dari tokonya, dibawa ke ruang uji (test environment), dan diuji: *"Kalau tombol 1 ditekan, apa layar menunjukkan angka 1? Kalau ditambah tombol 2, jadi 3?"* Semua diuji tanpa perlu seluruh toko beroperasi — tanpa pelanggan, tanpa rak buku, tanpa lampu.

Lebih cepat, lebih fokus, dan tidak mengganggu pelanggan.

- `describe` seperti label **"Uji Coba Mesin Kasir Seri-9000"**
- `it` seperti **skenario individual**: "menekan tombol 1", "menekan tombol + lalu 2"

## Dipakai untuk Apa

- Validasi logic bisnis (filter, search, pagination, format currency)
- Test utilitas HTTP client (axios wrapper, error handler)
- Test state persistence (localStorage, sessionStorage, cookies)
- Test helper functions (date formatter, slug generator, dll)

## Kesalahan Umum

| Kesalahan | Dampak | Solusi |
|-----------|--------|--------|
| Tidak mock localStorage | Gagal di CI/CD (tidak ada Web API) | `beforeEach(() => localStorage.clear())` |
| Test bergantung implementasi internal | Test mudah patah saat refactor | Test behavior (input → output), bukan langkah internal |
| Satu `it()` terlalu besar | Sulit debug saat gagal | Satu `it()` untuk satu spesifik skenario |
| Tidak reset state antar test | Test saling memengaruhi | `beforeEach` untuk reset |

## Hubungan dengan Materi Sebelumnya

Composable adalah hasil dari **Level 2 (Poin 26-27)** — di level itu kita membuat `useLocalStorage` dan `useBookFilter` sebagai logic reusable. Karena composable adalah **fungsi murni** (pure function, tidak bergantung DOM), mereka sangat mudah diuji tanpa perlu mount komponen.

Dengan adanya test ini, semua fitur dari **Level 1–5** (reaktivitas, routing, state management, validasi form) kini memiliki jaring pengaman: setiap perubahan bisa dicek tanpa takut merusak.

## Soal Latihan

### Soal 1

Buat test untuk `useDebounce` — sebuah composable yang menerima `value: Ref<string>` dan delay, lalu mengembalikan `debouncedValue` yang berubah setelah delay tertentu.

<details>
<summary>Jawaban</summary>

```typescript
import { describe, it, expect, vi } from 'vitest'
import { ref } from 'vue'
import { useDebounce } from '../useDebounce'

describe('useDebounce', () => {
  it('nilai debounce tidak berubah sebelum delay', async () => {
    vi.useFakeTimers()
    const input = ref('Vue')
    const debounced = useDebounce(input, 300)
    expect(debounced.value).toBe('Vue')
    input.value = 'React'
    // belum 300ms
    expect(debounced.value).toBe('Vue')
    vi.useRealTimers()
  })

  it('nilai debounce berubah setelah delay', async () => {
    vi.useFakeTimers()
    const input = ref('Vue')
    const debounced = useDebounce(input, 300)
    input.value = 'Nuxt'
    vi.advanceTimersByTime(300)
    expect(debounced.value).toBe('Nuxt')
    vi.useRealTimers()
  })
})
```

### Soal 2

Buat test untuk `useBookFilter.filterBySearch` yang **case insensitive** dan mengembalikan array kosong jika tidak ada buku yang cocok.

<details>
<summary>Jawaban</summary>

```typescript
import { describe, it, expect } from 'vitest'
import { useBookFilter } from '../useBookFilter'

const data = [
  { id: 1, title: 'Vue.js Lanjutan', author: 'Andi', price: 85000, inStock: true },
]

describe('useBookFilter — edge cases', () => {
  it('pencarian case insensitive', () => {
    const { filterBySearch } = useBookFilter(data)
    expect(filterBySearch('VUE')).toHaveLength(1)
    expect(filterBySearch('vue')).toHaveLength(1)
    expect(filterBySearch('Vue.js')).toHaveLength(1)
  })

  it('mengembalikan array kosong jika tidak cocok', () => {
    const { filterBySearch } = useBookFilter(data)
    expect(filterBySearch('zzzz')).toEqual([])
  })

  it('query kosong mengembalikan semua buku', () => {
    const { filterBySearch } = useBookFilter(data)
    expect(filterBySearch('')).toHaveLength(1)
  })
})
```
