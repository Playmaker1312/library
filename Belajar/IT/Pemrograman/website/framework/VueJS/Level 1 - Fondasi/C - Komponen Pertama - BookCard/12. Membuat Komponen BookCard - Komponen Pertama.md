# 12. Membuat Komponen BookCard — Komponen Pertama

## Penjelasan

Setelah mempelajari anatomi file `.vue`, sekarang saatnya membuat komponen **pertama** yang benar-benar reusable: `BookCard.vue`. Komponen ini akan menampilkan informasi satu buku dalam bentuk "kartu" (card) — mencakup gambar sampul, judul, penulis, harga, dan rating.

Sebelum membuat komponen, kita perlu mendefinisikan struktur data buku menggunakan **TypeScript interface**. Kita buat file `book.types.ts` agar tipe `Book` bisa dipakai ulang di banyak komponen.

```
src/
└── types/
    └── book.types.ts      ← definisi interface Book
src/
└── components/
    └── features/
        └── BookCard.vue   ← komponen kartu buku
```

## Fungsi

- **Encapsulasi**: Membungkus tampilan satu buku dalam unit independen
- **Reusability**: Satu `BookCard` bisa dipakai ulang untuk menampilkan ratusan buku
- **Konsistensi**: Semua buku tampil dengan format yang seragam
- **Tipe aman**: Dengan TypeScript, kita bisa memastikan data buku yang masuk sesuai kontrak

## Cara Implementasi / Kode

### 1. Buat interface `Book`

Buat file `src/types/book.types.ts`:

```typescript
export interface Book {
  id: number
  title: string
  author: string
  price: number
  rating: number
  coverUrl: string
  isbn?: string        // opsional, tidak semua buku punya ISBN
  description?: string // opsional
}
```

### 2. Buat helper `formatPrice`

Kita perlu fungsi untuk memformat harga ke format rupiah. Buat file `src/utils/format.ts`:

```typescript
export function formatPrice(amount: number): string {
  return new Intl.NumberFormat('id-ID', {
    style: 'currency',
    currency: 'IDR',
    minimumFractionDigits: 0,
  }).format(amount)
}
```

### 3. Buat komponen `BookCard.vue`

Buat file `src/components/features/BookCard.vue`:

```vue
<template>
  <div class="card">
    <img
      :src="book.coverUrl"
      :alt="`Sampul buku ${book.title}`"
      class="cover"
    />
    <div class="info">
      <h3 class="title">{{ book.title }}</h3>
      <p class="author">{{ book.author }}</p>
      <p class="price">{{ formatPrice(book.price) }}</p>
      <div class="rating">
        <span
          v-for="star in 5"
          :key="star"
          class="star"
          :class="{ filled: star <= book.rating }"
        >
          ★
        </span>
        <span class="rating-text">({{ book.rating }}/5)</span>
      </div>
    </div>
  </div>

<script setup lang="ts">
import type { Book } from '@/types/book.types'
import { formatPrice } from '@/utils/format'

defineProps<{
  book: Book

</script>
```

### 4. Register path alias `@`

Pastikan `@` mengarah ke `src/`. Cek `vite.config.ts`:

```typescript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { fileURLToPath, URL } from 'node:url'

export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
})
```

Jika project dibuat dengan `create-vue`, alias `@` sudah tersedia secara default.

## Analogi — Toko Buku

**BookCard adalah "kartu katalog" untuk setiap buku di toko.**

Bayangkan sebuah toko buku fisik. Setiap buku punya kartu katalog kecil yang ditempel di rak: ada foto sampul, judul, nama penulis, harga, dan bintang rating. Daripada menulis informasi ini secara manual di setiap rak (yang rawan salah format), kita cetak **satu desain kartu katalog**, lalu gandakan untuk semua buku.

| Konsep | Analogi |
|--------|---------|
| `interface Book` | Formulir data buku yang seragam — semua buku harus diisi dengan format yang sama |
| `BookCard.vue` | Mesin cetak kartu katalog — desainnya tetap, isinya bisa diganti-ganti |
| `coverUrl` | Foto sampul buku yang ditempel di kartu |
| `formatPrice` | Stempel harga yang sudah tercetak format "Rp25.000" |
| Rating bintang | Stiker bintang yang ditempel — makin bagus bukunya, makin banyak bintang terisi |

## Dipakai untuk Apa di Dunia Nyata

- **Toko buku online** (seperti Gramedia.com, Periplus): Setiap buku di halaman daftar adalah BookCard
- **Aplikasi perpustakaan**: Daftar buku yang bisa dipinjam
- **Dashboard penjualan buku**: Setiap item di laporan penjualan bisa menggunakan BookCard
- ** aplikasi rekomendasi buku**: "Buku yang mungkin Anda suka" — semuanya BookCard
- **E-commerce apa pun** (bukan cuma buku): Card produk dengan gambar, nama, harga, rating adalah pola universal

## Kesalahan Umum

| Kesalahan | Dampak | Solusi |
|-----------|--------|--------|
| **Inline type di komponen** | Tipe tidak bisa dipakai ulang, harus copy-paste di komponen lain | Buat `book.types.ts` terpisah |
| **Tidak pakai `lang="ts"`** | Tidak ada type checking, autocomplete hilang | Tambahkan `lang="ts"` di `<script setup>` |
| **Hardcode URL gambar** | Komponen tidak fleksibel | Gunakan binding `:src="book.coverUrl"` |
| **Lupa import `formatPrice`** | Error di runtime: `formatPrice is not defined` | Import fungsi helper sebelum dipakai di template |
| **Path alias `@` tidak dikenal** | Error: Cannot find module '@/types/book.types' | Pastikan alias `@` sudah diset di `vite.config.ts` |

## Soal Latihan + Jawaban

### Soal 1
Apa keuntungan membuat `interface Book` di file terpisah (`book.types.ts`) dibanding mendefinisikan tipe langsung di komponen?

<details>
<summary>Jawaban</summary>

1. **Reusability**: Jika komponen lain (misal `BookDetail.vue`, `BookForm.vue`) butuh tipe Book, mereka bisa import dari satu sumber, tidak perlu define ulang.
2. **Type consistency**: Satu perubahan di `book.types.ts` otomatis berlaku di semua komponen yang menggunakan tipe tersebut.
3. **Separation of concerns**: Definisi data terpisah dari komponen — lebih bersih dan mudah dipahami.
4. **Lebih mudah di-test**: Tipe bisa diuji secara independen.
</details>

### Soal 2
Jika properti `rating` pada buku bernilai `4`, bintang (★) mana saja yang akan mendapat class `filled`? Jelaskan!

<details>
<summary>Jawaban</summary>

Bintang ke-1, 2, 3, dan 4 akan mendapat class `filled` (berwarna kuning). Bintang ke-5 tidak dapat class `filled` (tetap abu-abu).

Penjelasan: `:class="{ filled: star <= book.rating }"` — ketika `star` (1–5) lebih kecil atau sama dengan `book.rating` (4), maka class `filled` ditambahkan.
- star=1 → 1 <= 4 → **filled**
- star=2 → 2 <= 4 → **filled**
- star=3 → 3 <= 4 → **filled**
- star=4 → 4 <= 4 → **filled**
- star=5 → 5 <= 4 → **tidak** filled
</details>
