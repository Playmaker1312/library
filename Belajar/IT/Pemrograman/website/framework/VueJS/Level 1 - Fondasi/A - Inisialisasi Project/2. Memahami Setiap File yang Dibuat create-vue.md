# 2. Memahami Setiap File yang Dibuat `create-vue`

## Penjelasan

Setelah menjalankan `npm create vue@latest`, kita mendapatkan kurang lebih 30-40 file. Tidak perlu panik — setiap file punya peran spesifik. Memahami struktur ini penting agar kita tahu persis di mana menaruh kode.

## Fungsi

Memahami fungsi setiap file dan direktori sehingga kita tidak "tersesat" di project sendiri. Ini seperti membaca peta sebelum menjelajah hutan.

## Struktur File dan Penjelasan

```
bookstore-ui/
├── index.html              # Entry point HTML (Vite injects script ke sini)
├── vite.config.ts          # Konfigurasi Vite (alias, plugin, proxy)
├── tsconfig.json           # Konfigurasi TypeScript utama
├── tsconfig.app.json       # TypeScript khusus aplikasi
├── tsconfig.node.json      # TypeScript khusus Node (vite.config, dll)
├── package.json            # Dependencies dan scripts
├── env.d.ts                # Deklarasi tipe global (.vue modules)
├── .eslintrc.cjs           # Aturan ESLint
├── .prettierrc.json        # Aturan Prettier
├── .gitignore              # File yang diabaikan git
├── public/                 # Static assets (favicon, dll) — tidak di-process Vite
└── src/
    ├── main.ts             # Entry point aplikasi Vue — mount App
    ├── App.vue             # Root component — tempat RouterView
    ├── router/
    │   └── index.ts        # Definisi route (URL → component mapping)
    ├── stores/
    │   └── counter.ts      # Pinia store (state management) — contoh
    ├── components/
    │   ├── HelloWorld.vue  # Component contoh
    │   ├── TheWelcome.vue  # Component contoh
    │   └── icons/          # Icon components (jika dipilih)
    ├── views/
    │   ├── HomeView.vue    # Halaman Home
    │   └── AboutView.vue   # Halaman About
    ├── assets/
    │   ├── main.css        # Global CSS
    │   └── logo.svg        # Aset gambar
    └── composables/        # (opsional) Folder untuk reusable logic
```

### File Kunci

| File | Peran |
|------|-------|
| `index.html` | Satu-satunya HTML. Vite otomatis inject `<script type="module" src="src/main.ts">` |
| `src/main.ts` | Inisialisasi Vue App — `createApp(App).use(router).use(createPinia()).mount('#app')` |
| `src/App.vue` | Komponen paling atas. Biasanya hanya berisi `<RouterView />` |
| `src/router/index.ts` | `createRouter()` dengan array `routes` |
| `vite.config.ts` | Plugin Vue, resolve alias (`@/`), proxy API |

## Cara Implementasi

```bash
# Buka setiap file satu per satu di editor favorit, baca baris per baris
code src/main.ts
code src/App.vue
code src/router/index.ts
code vite.config.ts
```

Baca komentar di setiap file — file hasil `create-vue` sudah dikomentari dengan baik.

## Analogi: Toko Buku

Seperti memahami denah toko buku setelah membeli paket dasar:

| File/Folder | Analogi Toko |
|-------------|--------------|
| `index.html` | Pintu masuk utama toko |
| `src/main.ts` | Manajer toko yang menghidupkan semua sistem |
| `src/App.vue` | Bangunan utama toko — tempat semua rak berada |
| `src/router/index.ts` | Peta jalur pelanggan — mana rak fiksi, mana rak non-fiksi |
| `src/stores/` | Meja kasir — tempat semua transaksi tercatat |
| `src/components/` | Rak-rak buku (komponen kecil seperti label harga, keranjang) |
| `src/views/` | Etalase / bagian toko (Fiksi, Non-Fiksi, Anak-Anak) |
| `src/assets/` | Gudang — dekorasi, poster, logo |
| `composables/` | Resep rahasia — logika yang dipakai ulang |
| `public/` | Papan nama toko di luar — tidak berubah |
| `package.json` | Daftar inventaris — barang apa saja yang ada di toko |

## Hubungan dengan Materi Sebelumnya

**Poin 1** (Membuat Project dengan create-vue) menghasilkan file-file ini. Sekarang kita tidak hanya punya project, tapi juga **memahami setiap sudutnya**. Pengetahuan ini akan dipakai terus selama pengembangan: kita akan sering bolak-balik ke `router/index.ts`, `stores/`, `vite.config.ts`, dll.

## Dipakai Untuk Apa

- **Onboarding developer baru**: Memberikan tur struktur project.
- **Debugging**: Kalau ada error, kita tahu file mana yang perlu diperiksa.
- **Scalability**: Tim tahu persis di mana menaruh file baru (component baru → `components/features/`, view baru → `views/`, store baru → `stores/`).

## Kesalahan Umum

| Kesalahan | Dampak | Cara Hindari |
|-----------|--------|--------------|
| Mengedit `index.html` untuk routing | Routing tidak jalan | Routing urusan `vue-router`, bukan HTML |
| Menaruh kode di `App.vue` sampai ribuan baris | Sulit dibaca, sulit di-test | `App.vue` minimalis, delegasi ke komponen anak |
| Menghapus `env.d.ts` | TypeScript error `.vue` imports | Biarkan file deklarasi tipe |
| Bingung beda `views/` vs `components/` | Struktur berantakan | **Views** = halaman utuh (route target), **Components** = bagian halaman |
| Salah edit `tsconfig.node.json` untuk kode app | TypeScript konfigurasi error | `tsconfig.node.json` hanya untuk file Node (vite.config.ts) |

## Soal Latihan

**Soal 1:** Jelaskan perbedaan peran antara `src/components/` dan `src/views/`!

**Jawaban:**
- **`src/components/`**: Komponen reusable yang bisa dipakai di mana saja — seperti tombol, kartu, form, navbar. Mereka adalah *building blocks*.
- **`src/views/`**: Halaman lengkap yang dirender oleh router — seperti halaman Home, About, Dashboard. Sebuah *view* biasanya menyusun beberapa *component* menjadi satu halaman utuh.

**Soal 2:** File mana yang harus kita edit jika ingin menambahkan route baru (misal `/books`)?

**Jawaban:**
`src/router/index.ts`. Kita tambahkan objek baru ke array `routes`:
```typescript
{
  path: '/books',
  name: 'books',
  component: () => import('@/views/BooksView.vue')
}
```
Lalu buat file `src/views/BooksView.vue` sebagai halaman yang akan dirender.
