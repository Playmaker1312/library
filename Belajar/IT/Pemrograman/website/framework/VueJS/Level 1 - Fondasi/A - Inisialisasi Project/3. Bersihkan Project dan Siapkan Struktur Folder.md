# 3. Bersihkan Project dan Siapkan Struktur Folder

## Penjelasan

Project hasil `create-vue` datang dengan file contoh (boilerplate) seperti `HelloWorld.vue`, `TheWelcome.vue`, `icons/`, dan komponen lain yang tidak kita buat sendiri. Untuk memulai dengan pikiran jernih, kita hapus semua contoh dan siapkan struktur folder sesuai kebutuhan project bookstore-ui.

## Fungsi

- Start dengan basis kode yang bersih — tidak ada file yang tidak dipahami.
- Struktur folder yang terorganisir memudahkan kolaborasi tim.
- Mencegah kebingungan antara kode contoh dan kode asli.

## Cara Implementasi

### 1. Hapus File Boilerplate

```bash
# Hapus komponen contoh
Remove-Item -LiteralPath "src\components\HelloWorld.vue" -Force
Remove-Item -LiteralPath "src\components\TheWelcome.vue" -Force
Remove-Item -LiteralPath "src\components\icons" -Recurse -Force

# Hapus view contoh
Remove-Item -LiteralPath "src\views\HomeView.vue" -Force
Remove-Item -LiteralPath "src\views\AboutView.vue" -Force

# Hapus assets contoh
Remove-Item -LiteralPath "src\assets\logo.svg" -Force
Remove-Item -LiteralPath "src\assets\main.css" -Force

# Hapus store contoh
Remove-Item -LiteralPath "src\stores\counter.ts" -Force
```

### 2. Update `src/App.vue` — Jadikan Minimal

```vue
<script setup lang="ts">
import { RouterView } from 'vue-router'
</script>

<template>
  <RouterView />
</template>

<style scoped>
/* Global styling nanti di main.css */
</style>
```

### 3. Update `src/main.ts`

```typescript
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import router from './router'
import App from './App.vue'
import './assets/main.css'  // Kita buat file CSS global nanti

const app = createApp(App)

app.use(createPinia())
app.use(router)

app.mount('#app')
```

### 4. Update `src/router/index.ts` — Route Default

```typescript
import { createRouter, createWebHistory } from 'vue-router'

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes: [
    {
      path: '/',
      name: 'home',
      component: () => import('@/views/HomeView.vue'),
    },
  ],
})

export default router
```

### 5. Buat `src/views/HomeView.vue` Sederhana

```vue
<script setup lang="ts">
</script>

<template>
  <main>
    <h1>Selamat Datang di BookStore</h1>
    <p>Toko buku online favorit Anda.</p>
  </main>
</template>
```

### 6. Buat Struktur Folder Tambahan

```bash
# Buat folder yang akan dipakai nanti
New-Item -ItemType Directory -Path "src\components\common" -Force
New-Item -ItemType Directory -Path "src\components\features" -Force
New-Item -ItemType Directory -Path "src\composables" -Force
New-Item -ItemType Directory -Path "src\types" -Force
New-Item -ItemType Directory -Path "src\utils" -Force
New-Item -ItemType Directory -Path "src\assets" -Force  # (jika sudah terhapus)
```

### Struktur Final

```
src/
├── main.ts
├── App.vue
├── assets/
│   └── main.css
├── router/
│   └── index.ts
├── stores/
│   └── (kosong, siap diisi)
├── components/
│   ├── common/        # Tombol, input, card reusable
│   └── features/      # BookCard, CartItem, SearchBar
├── composables/        # useFetch, useAuth, useCart
├── types/              # Interface TypeScript (IBook, IUser)
├── utils/              # formatCurrency, validateEmail
└── views/
    └── HomeView.vue
```

## Analogi: Toko Buku

Seperti merenovasi toko buku yang baru dibeli — pemilik sebelumnya meninggalkan rak-rak lama (HelloWorld, counter store), poster usang (logo.svg), dan label harga model lama. Kita bongkar semua itu, cat ulang dinding (App.vue minimal), dan bangun tata letak baru: area kasir di sini (stores/), etalase best-seller di sana (components/features/), gang khusus (router/), dan gudang belakang (composables/).

## Dipakai Untuk Apa

- **Setiap project nyata**: Tidak ada project Vue profesional yang mempertahankan `HelloWorld.vue`.
- **Micro-frontend**: Setiap sub-app butuh struktur bersih sebelum dikembangkan.
- **Open source library**: Struktur folder yang rapi memudahkan kontributor.
- **Code review**: Tim bisa langsung navigasi tanpa tersesat di file contoh.

## Kesalahan Umum

| Kesalahan | Dampak | Cara Hindari |
|-----------|--------|--------------|
| Lupa update `router/index.ts` | Halaman 404 saat `npm run dev` | Setelah hapus route About, pastikan hanya route `/` yang ada |
| Tidak update `main.ts` | CSS tidak termuat, Pinia tidak terdaftar | Pastikan `import './assets/main.css'` dan `app.use(createPinia())` |
| Hapus `env.d.ts` | TypeScript error di `.vue` files | Biarkan file ini — penting untuk deklarasi modul `.vue` |
| Membuat struktur terlalu dalam | Path alias `@/` jadi panjang | Maksimal 3 level: `components/common/`, bukan `components/common/ui/base/` |

## Hubungan dengan Materi Sebelumnya

**Poin 1** membuat project, **Poin 2** memahami strukturnya. Sekarang (Poin 3) kita **membersihkan** struktur itu agar sesuai kebutuhan. Ini seperti membeli rumah (poin 1), melihat denahnya (poin 2), lalu merenovasi sesuai selera (poin 3).

## Soal Latihan

**Soal 1:** Mengapa kita perlu menghapus file boilerplate seperti `HelloWorld.vue` dan `TheWelcome.vue`? Kenapa tidak dibiarkan saja?

**Jawaban:**
1. **Kebingungan**: File contoh bisa disalahartikan sebagai kode asli oleh developer baru.
2. **Dead code**: File itu tidak dipakai di aplikasi final, tapi tetap ikut di-bundle (meski tree-shaking bisa hapus, lebih baik hapus manual).
3. **Code smell**: Project yang bersih memiliki 0 warning dan 0 file tidak terpakai.
4. **Fokus**: Developer bisa langsung fokus pada kode yang relevan dengan bisnis.

**Soal 2:** Sebutkan 3 folder yang kita buat di langkah 6! Dan apa isi yang akan ditaruh di masing-masing folder?

**Jawaban:**
1. **`components/common/`** → Komponen UI umum: `BaseButton.vue`, `BaseInput.vue`, `BaseCard.vue`, `BaseModal.vue`.
2. **`components/features/`** → Komponen spesifik fitur bisnis: `BookCard.vue`, `CartItem.vue`, `SearchBar.vue`, `ReviewList.vue`.
3. **`composables/`** → Logika reusable berbasis Composition API: `useFetch.ts` (fetch data buku), `useCart.ts` (manajemen keranjang), `useAuth.ts` (login/logout).
