# 8. Template Syntax Dasar — Interpolasi dan Direktif

## Penjelasan

Template syntax di Vue adalah cara kita menghubungkan data dari `<script setup>` ke tampilan di `<template>`. Ada tiga teknik utama:

1. **Interpolasi** — `{{ variabel }}` untuk menampilkan teks
2. **Attribute Binding** — `v-bind:attr` atau `:attr` untuk mengikat atribut HTML ke data
3. **Event Handling** — `v-on:event` atau `@event` untuk merespons aksi pengguna

Ini adalah fondasi **reaktivitas** Vue: saat data di script berubah, tampilan otomatis memperbarui diri.

## Fungsi

| Teknik | Sintaks | Fungsi |
|--------|---------|--------|
| Interpolasi | `{{ data }}` | Menampilkan nilai data sebagai teks di dalam elemen HTML |
| Binding atribut | `v-bind:src="data"` atau `:src="data"` | Mengikat atribut HTML (src, href, alt, disabled, dll.) ke data |
| Event handler | `v-on:click="fn"` atau `@click="fn"` | Menjalankan fungsi saat event tertentu terjadi |

### Perbedaan penting
- `{{ }}` hanya bekerja di **konten teks** (di antara tag pembuka dan penutup)
- `:` (v-bind) digunakan untuk **atribut HTML**
- `@` (v-on) digunakan untuk **event**

## Cara Implementasi / Kode

```vue
<template>
  <div class="book-display">
    <!-- Interpolasi: menampilkan teks -->
    <h1>{{ storeName }}</h1>
    <p>Buku: <strong>{{ bookTitle }}</strong></p>
    <p>Harga: Rp{{ price.toLocaleString('id-ID') }}</p>

    <!-- v-bind: mengikat atribut src ke data bookCover -->
    <img :src="bookCover" :alt="bookTitle" class="cover" />

    <!-- v-on: klik tombol untuk menjalankan fungsi -->
    <button @click="showInfo" class="btn">Lihat Detail</button>
    <p v-if="infoVisible">"{{ bookTitle }}" — sebuah novel karya {{ author }}.</p>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const storeName: string = 'Toko Buku Pustaka'
const bookTitle: string  = 'Laskar Pelangi'
const author: string     = 'Andrea Hirata'
const price: number      = 95000
const bookCover: string  = 'https://via.placeholder.com/150?text=Laskar+Pelangi'

const infoVisible = ref(false)

function showInfo() {
  infoVisible.value = !infoVisible.value
}
</script>

<style scoped>
.book-display {
  max-width: 400px;
  padding: 1.5rem;
  border: 1px solid #ddd;
  border-radius: 8px;
  text-align: center;
}

.cover {
  width: 150px;
  height: 200px;
  object-fit: cover;
  border-radius: 4px;
  margin: 1rem 0;
}

.btn {
  background: #42b883;
  color: white;
  border: none;
  padding: 0.5rem 1.5rem;
  border-radius: 4px;
  cursor: pointer;
}

.btn:hover {
  background: #3aa876;
}
</style>
```

### Langkah-langkah
1. Definisikan data di `<script setup>` (string, number, boolean, dll.)
2. Gunakan `{{ namaData }}` di template untuk menampilkan teks
3. Gunakan `:src="namaData"` untuk gambar, `:href` untuk link, dll.
4. Gunakan `@click="namaFungsi"` untuk tombol
5. Jika data perlu reaktif, bungkus dengan `ref()` (lebih detail di materi selanjutnya)

## Analogi — Toko Buku

| Teknik Vue | Analogi Toko Buku |
|------------|-------------------|
| `{{ bookTitle }}` | **Label harga** yang ditempel di rak — "Buku ini: Laskar Pelangi, Rp95.000". Isi label berubah otomatis jika data di buku catatan (script) diubah. |
| `:src="bookCover"` | **Menyambungkan keran air ke pipa** — ubah data gambar di script, foto sampul buku di rak langsung berganti. Tidak perlu copot pasang manual. |
| `@click="showInfo"` | **Bel pintu toko** — saat pembeli masuk (klik), bel berbunyi dan pemilik toko merespons (menjalankan fungsi). Setiap interaksi pengguna bisa ditangkap dan direspons. |

## Dipakai untuk Apa di Dunia Nyata

- **Menampilkan data dari API** — user name, product title, price, dll.
- **Mengikat gambar produk** — `:src="product.image"` di e-commerce
- **Tombol interaktif** — `@click="addToCart"`, `@submit="checkout"`
- **Link dinamis** — `:to="'/book/' + book.id"` (dengan Vue Router)

## Kesalahan Umum

| Kesalahan | Salah | Benar |
|-----------|-------|-------|
| **Interpolasi di atribut** | `<img src="{{ image }}">` | `<img :src="image">` |
| **Lupa `:` untuk bind** | `<img src="image">` (dianggap string literal "image") | `<img :src="image">` |
| **Lupa `()` di event** | `@click="showInfo"` tanpa `()` OK kalau tanpa argumen | Tapi jika butuh argumen: `@click="showInfo(book.id)"` |
| **Lupa `ref()` untuk data reaktif** | `let count = 0` (tidak reaktif) | `const count = ref(0)` |
| **Typo event name** | `@onclick` | `@click` |

## Soal Latihan + Jawaban

### Soal 1
Apa perbedaan antara `{{ bookTitle }}` dan `:src="bookCover"` dalam penggunaannya di template? Kapan masing-masing digunakan?

<details>
<summary>Jawaban</summary>

`{{ bookTitle }}` digunakan untuk **konten teks** di antara tag — misal `<h1>{{ bookTitle }}</h1>` akan menghasilkan `<h1>Laskar Pelangi</h1>`.

`:src="bookCover"` digunakan untuk **atribut HTML** — misal `<img :src="bookCover">` akan menghasilkan `<img src="https://...">`. Tidak bisa menggunakan `{{ }}` di atribut.

**Aturan praktis:** Di antara tag buka-tutup → `{{ }}`. Di dalam atribut HTML → `:` (v-bind).
</details>
