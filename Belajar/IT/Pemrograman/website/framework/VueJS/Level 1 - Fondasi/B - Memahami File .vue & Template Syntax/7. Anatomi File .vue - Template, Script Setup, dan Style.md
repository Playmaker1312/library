# 7. Anatomi File `.vue` — Template, Script Setup, dan Style

## Penjelasan

File `.vue` (Single-File Component / SFC) adalah blok bangunan utama di Vue 3. Satu file `.vue` mewakili satu komponen utuh yang terdiri dari tiga bagian:

```
<template>    →    HTML (struktur/tampilan)
<script setup> →    JavaScript/TypeScript (logika/data)
<style>       →    CSS (penampilan/estetika)
```

Ketiganya ditulis dalam satu file, sehingga kode lebih terorganisir dan mudah dipelihara.

## Fungsi

| Bagian | Fungsi |
|--------|--------|
| `<template>` | Menulis markup HTML yang akan dirender. Di sinilah kita menempatkan elemen-elemen UI. |
| `<script setup lang="ts">` | Menulis logika komponen: data, fungsi, computed, imports, lifecycle. `setup` adalah fitur Composition API yang lebih ringkas dari Options API. |
| `<style scoped>` | Menulis CSS yang **hanya** berlaku untuk komponen ini. Tidak bocor ke komponen lain. |

### Keunggulan `<script setup>`
- Tidak perlu `export default { ... }` seperti Options API
- Semua variabel dan fungsi langsung bisa dipakai di template tanpa mendaftarkannya di `data()` / `methods`
- Import komponen otomatis tersedia
- Kode lebih pendek dan bersih

### Tentang `scoped`
Kata kunci `scoped` membuat Vue menambahkan atribut data unik (contoh: `data-v-7ba5bd90`) ke setiap elemen di komponen, sehingga CSS hanya menarget elemen dengan atribut tersebut. CSS tidak "bocor" ke komponen lain.

### Tentang `lang="ts"`
Menambahkan `lang="ts"` memberi tahu compiler bahwa isi `<script>` ditulis dalam **TypeScript**. Ini memberikan type checking, autocomplete, dan dokumentasi yang lebih baik.

## Cara Implementasi / Kode

Buat file `HomeView.vue` dengan tiga bagian lengkap:

```vue
<template>
  <div class="home">
    <h1>{{ storeName }}</h1>
    <p>Selamat datang di toko buku kami!</p>
  </div>
</template>

<script setup lang="ts">
const storeName: string = 'Toko Buku Pustaka'
</script>

<style scoped>
.home {
  font-family: 'Segoe UI', sans-serif;
  text-align: center;
  padding: 2rem;
}

h1 {
  color: #2c3e50;
  border-bottom: 2px solid #42b883;
  display: inline-block;
  padding-bottom: 0.5rem;
}
</style>
```

### Langkah-langkah
1. Buat file bernama `HomeView.vue` di folder `src/views/` atau `src/components/`
2. Tulis `<template>` berisi elemen HTML yang kamu inginkan
3. Tulis `<script setup lang="ts">` berisi data dan logika
4. Tulis `<style scoped>` berisi CSS khusus komponen
5. Gunakan komponen ini di `App.vue` atau router

## Analogi — Toko Buku

Bayangkan sebuah **toko buku** memiliki banyak **rak**. Setiap rak adalah satu komponen `.vue`.

| Bagian File .vue | Analogi di Toko Buku |
|------------------|----------------------|
| `<template>` | **Tata letak rak** — posisi buku, label, dekorasi. Ini yang dilihat pengunjung. |
| `<script setup>` | **Daftar isi / catatan pemilik** — buku apa saja yang ada di rak ini, berapa harganya, stoknya. |
| `<style scoped>` | **Cat dan dekorasi** rak — warna rak, stiker, lampu. **Scoped** artinya cat ini hanya untuk rak ini, tidak berantakan ke rak lain. |

Kalau tidak pakai `scoped`, catnya bisa belepotan ke rak sebelah — `h1` di rak ini bisa kena warna yang sama dengan `h1` di rak lain.

## Dipakai untuk Apa di Dunia Nyata

- **Setiap komponen Vue** yang kamu buat selalu mengikuti struktur 3-bagian ini
- Komponen halaman (`HomeView.vue`, `BookDetail.vue`)
- Komponen UI kecil (`StarRating.vue`, `BookCard.vue`)
- Form, modal, tombol, navigation bar — semuanya file `.vue`

## Kesalahan Umum

| Kesalahan | Dampak | Solusi |
|-----------|--------|--------|
| **Lupa `scoped`** | CSS bentrok dengan komponen lain. `h1` di sini ikut mewarnai `h1` di komponen lain. | Selalu tambahkan `scoped` kecuali kamu sengaja ingin CSS global. |
| **Masih pakai Options API** | Kode jadi panjang dan kurang rapi (kecuali untuk project Vue 2). | Gunakan `<script setup>` (Composition API) untuk project baru. |
| **Lupa `lang="ts"`** | TypeScript tidak aktif, autocomplete terbatas. | Tambahkan `lang="ts"` di tag `<script>`. |
| **Meletakkan terlalu banyak logika di template** | Template jadi berantakan. | Simpan logika di `<script setup>`, template hanya untuk tampilan. |

## Soal Latihan + Jawaban

### Soal 1
Apa fungsi kata kunci `scoped` pada `<style scoped>`? Apa yang terjadi jika kita menghilangkannya?

<details>
<summary>Jawaban</summary>

`scoped` membatasi CSS agar hanya berlaku di komponen tersebut. Jika dihilangkan, CSS bisa "bocor" ke komponen lain. Contoh: `h1 { color: red; }` tanpa `scoped` akan mewarnai semua `h1` di seluruh aplikasi, bukan hanya komponen ini.
</details>
