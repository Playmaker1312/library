# 10. Conditional Rendering — `v-if` dan `v-show`

## Penjelasan

Dalam aplikasi nyata, tidak semua elemen harus selalu muncul. Terkadang kita ingin menampilkan atau menyembunyikan sesuatu berdasarkan kondisi. Vue menyediakan dua direktif untuk ini:

- **`v-if`** — menghapus atau menambahkan elemen dari DOM
- **`v-show`** — menyembunyikan atau menampilkan elemen dengan CSS `display: none`

Keduanya bekerja dengan nilai boolean (`true` / `false`).

## Fungsi

| Direktif | Cara Kerja | Kapan Dipakai |
|----------|-----------|---------------|
| `v-if` | Menghapus/menambahkan elemen dari DOM sepenuhnya | Kondisi jarang berubah (misal: status login, fitur berdasarkan role) |
| `v-show` | Hanya toggle CSS `display: none` — elemen tetap di DOM | Kondisi sering berubah (misal: tab, filter, accordion) |
| `v-else` | Pasangan `v-if`, muncul saat kondisi `false` | Bersama `v-if` untuk kondisi binary |
| `v-else-if` | Rantai kondisi tambahan | Lebih dari 2 kemungkinan |

### Tabel Perbandingan

| Aspek | `v-if` | `v-show` |
|-------|--------|----------|
| DOM | Elemen dihapus/ditambahkan | Elemen tetap ada |
| CSS | Tidak ada | `display: none` |
| Inisialisasi | Lambat (render hanya saat true) | Cepat (render sekali) |
| Toggle | Cepat (tambah/hapus DOM) | Lambat secara CPU? — sebenarnya lebih cepat karena hanya ubah CSS |
| Biaya Toggle | Mahal (manipulasi DOM) | Murah (ubah CSS) |
| `v-else` / `v-else-if` | Didukung | Tidak didukung |

## Cara Implementasi / Kode

```vue
<template>
  <div class="catalog">
    <h1>{{ storeName }}</h1>

    <!-- Toggle tombol filter -->
    <button @click="showDiscountedOnly = !showDiscountedOnly" class="filter-btn">
      {{ showDiscountedOnly ? 'Tampilkan Semua' : 'Diskon Saja' }}
    </button>

    <div class="book-list">
      <div v-for="book in books" :key="book.id" class="book-card">
        <img :src="book.cover" :alt="book.title" class="cover" />
        <h3>{{ book.title }}</h3>
        <p class="author">— {{ book.author }}</p>
        <p class="price">Rp{{ book.price.toLocaleString('id-ID') }}</p>

        <span v-if="book.inStock" class="badge badge-stock">In Stock</span>
        <span v-else class="badge badge-out">Out of Stock</span>

        <!-- v-show: Badge diskon — sering di-toggle -->
        <span v-show="showDiscountedOnly && book.discounted" class="badge badge-discount">
          DISKON!
        </span>
      </div>
    </div>
  </div>
</template>

</script>
```

### Langkah-langkah
1. Tentukan kondisi boolean di data (`book.inStock`, `book.discounted`)
2. Untuk kondisi tetap (stok), gunakan `v-if="book.inStock"` dengan `v-else`
3. Untuk kondisi yang sering berubah (filter diskon), gunakan `v-show`
4. Jika ada lebih dari 2 kondisi, gunakan rantai `v-if` / `v-else-if` / `v-else`

## Analogi — Toko Buku

| Direktif | Analogi Toko Buku |
|----------|-------------------|
| `v-if` | **Memajang buku di etalase vs menyimpannya di gudang** — kalau stok habis, buku benar-benar tidak ada di lantai toko (dihapus dari DOM). Kalau stok masuk, buku dikeluarkan dari gudang dan dipajang (ditambahkan ke DOM). |
| `v-show` | **Menutup buku dengan kain** — buku tetap di etalase, tapi tertutup kain (display:none). Pengunjung tidak melihatnya, tapi buku tetap ada di sana. Saat kain dibuka, buku langsung terlihat tanpa perlu mengeluarkan dari gudang. |
| `v-else` | **Label "Stok Tersedia" atau "Stok Habis"** — dua kemungkinan, salah satu pasti muncul. |

**Kapan pakai apa?**
- **Stok barang** jarang berubah selama session → `v-if`
- **Filter diskon** yang sering di-toggle pengguna → `v-show`
- **Tab / accordion** yang sering diklik → `v-show`
- **Menu berdasarkan role pengguna** (admin/user) → `v-if`

## Dipakai untuk Apa di Dunia Nyata

- **Badge "In Stock" / "Out of Stock"** pada produk
- **Status login** — tampilkan tombol "Login" atau "Profile"
- **Loading state** — tampilkan spinner saat data dimuat
- **Empty state** — tampilkan "Tidak ada data" jika array kosong
- **Role-based UI** — tampilkan fitur khusus admin
- **Tab panel, accordion, modal**

## Kesalahan Umum

| Kesalahan | Dampak | Solusi |
|-----------|--------|--------|
| **Pakai `v-if` untuk toggle cepat** (misal: tab, dropdown) | Manipulasi DOM terus-menerus, performa turun. | Gunakan `v-show` untuk toggle yang sering berubah. |
| **Pakai `v-show` untuk komponen berat** (banyak child, gambar besar) | DOM tetap ter-render meskipun tersembunyi — boros memori. | Gunakan `v-if` agar komponen benar-benar tidak di-render. |
| **`v-if` dan `v-for` di elemen sama** | Vue 3 memberi prioritas `v-if` lebih tinggi, bisa error. | Bungkus dengan `<template>` atau gunakan computed filter. |
| **Lupa `v-else` tidak bisa berdiri sendiri** | `v-else` harus langsung setelah elemen `v-if`. | Selalu tempatkan `v-else` sebagai sibling langsung setelah `v-if`. |

## Hubungan dengan Materi Sebelumnya

Di **Poin 9**, kita menampilkan semua buku dengan `v-for`. Sekarang kita **tambahkan dimensi kondisional** — setiap buku bisa punya badge berbeda berdasarkan propertinya (`inStock`, `discounted`). Ini membuat tampilan lebih informatif dan realistis.

Selanjutnya di **Poin 11**, kita akan menggabungkan kondisi dengan class/style binding untuk memberikan efek visual yang lebih kaya.

### Soal 1
Jelaskan perbedaan utama antara `v-if` dan `v-show`. Kapan sebaiknya menggunakan masing-masing?

<details>
<summary>Jawaban</summary>

`v-if` menghapus/menambahkan elemen dari DOM — cocok untuk kondisi yang jarang berubah (misal: status login). `v-show` hanya toggle CSS `display: none` — elemen tetap di DOM — cocok untuk kondisi yang sering berubah (misal: tab, filter dropdown).

**Aturan praktis:** Sering toggle → `v-show`. Jarang toggle / komponen berat → `v-if`.

### Soal 2
Buat komponen yang menampilkan badge berdasarkan rating buku menggunakan `v-if`/`v-else-if`/`v-else`:
- Rating >= 4.5: "Best Seller"
- Rating >= 3.5: "Populer"  
- Rating < 3.5: "Biasa"

```vue

const title: string = 'Laskar Pelangi'
```
