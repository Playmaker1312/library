# Optimasi CSS

## Penjelasan

Bootstrap ukuran penuh (~150KB CSS) mungkin mengandung banyak komponen yang tidak terpakai. Optimasi CSS berarti mengimpor hanya komponen yang benar-benar dipakai melalui Sass, mengurangi ukuran file, dan mempercepat loading.

## Fungsi

- Memperkecil ukuran file CSS (dari ~150KB ke ~30-50KB)
- Menghilangkan style yang tidak pernah dipakai
- Meningkatkan skor Performance di Lighthouse
- Mempercepat waktu render halaman

## Analogi

Optimasi CSS = **gudang yang rapi hanya menyimpan barang dipakai**. Bootstrap penuh seperti gudang besar berisi semua peralatan rumah tangga — banyak yang tidak pernah tersentuh. Import selektif seperti memindahkan hanya peralatan yang benar-benar dipakai sehari-hari ke rak depan, sisanya dibuang atau disimpan di gudang belakang (tidak di-load). Hasilnya: gudang lebih ringan, mudah dicari, dan rumah lebih cepat dibangun.

## Dipakai untuk apa

- Proyek produksi yang butuh performa tinggi
- Landing page sederhana (cukup grid + button + typography)
- Aplikasi web yang hanya menggunakan sebagian kecil Bootstrap
- Mengoptimalkan First Contentful Paint (FCP)

## Kesalahan umum yang sering terjadi

- **Lupa import utilities/api** — Utility class seperti `d-flex`, `mt-3` tidak akan berfungsi
- **Import semua komponen tetap saja** — Tujuan optimasi tidak tercapai, masih ~150KB
- **Hanya minify tanpa seleksi** — Minify memang memperkecil, tapi menghapus komponen lebih efektif
- **Tidak purge CSS yang tidak dipakai** — PurgeCSS/Tailwind bisa lebih agresif menghapus class yang tidak muncul di HTML
- **Mengabaikan komentar** — Komentar di SCSS tidak masalah, tapi di CSS production harus di-strip

## Koneksi dengan materi sebelumnya

Setelah audit mobile (materi 34), responsive spacing (35), display utility (36), dan aksesibilitas (37-38), website secara fungsional dan aksesibel sudah siap. Optimasi CSS adalah langkah performance — memastikan website tidak hanya bagus dan aksesibel, tapi juga cepat dimuat.

## Soal latihan & jawaban

**Soal 1:** Sebutkan 3 komponen Bootstrap yang WAJIB diimpor agar utility dasar berfungsi!

**Jawaban:**
1. `bootstrap/scss/functions`
2. `bootstrap/scss/variables`
3. `bootstrap/scss/utilities/api`

**Soal 2:** Mengapa kita tidak perlu mengimpor `bootstrap/scss/carousel` jika tidak memakainya?

**Jawaban:** Karena akan menambah ukuran file CSS secara tidak perlu. Setiap komponen yang diimpor menambah ~2-10KB ke file akhir. Mengimpor yang tidak dipakai = membuang bandwidth.

**Soal 3:** Apa perbedaan minify (`--style=compressed`) dengan selective import?

**Jawaban:** Minify menghapus spasi, newline, komentar dari CSS — mengurangi ukuran ~20-30%. Selective import menghilangkan seluruh komponen yang tidak dipakai — bisa mengurangi ukuran hingga 70-80%. Keduanya idealnya dikombinasikan.
