# Responsive Spacing

## Penjelasan

Bootstrap menyediakan utility spacing yang bisa berubah nilainya tergantung breakpoint. Kita bisa mengatur padding/margin berbeda untuk mobile, tablet, dan desktop hanya dengan satu class.

## Fungsi

- Memberi spasi yang proporsional di setiap ukuran layar
- Menghindari padding berlebihan di mobile atau kekurangan spasi di desktop
- Membuat tata letak lebih adaptif tanpa media query manual
- Mengontrol jarak antar elemen secara responsif

## Cara Pengimplementasian

```html
<!-- Padding Y responsif: kecil di mobile, besar di desktop -->
<div class="py-2 py-md-4 py-lg-5">
  Konten dengan padding adaptif
</div>

<!-- Padding X responsif -->
<div class="px-3 px-md-5">
  Konten dengan padding kiri-kanan responsif
</div>

<!-- Gap (gutter) responsif di grid -->
<div class="row g-2 g-md-4 g-lg-5">
  <div class="col-6">Item 1</div>
  <div class="col-6">Item 2</div>
  <div class="col-6">Item 3</div>
</div>

<!-- Margin adaptif: margin bawah hanya di desktop -->
<div class="mb-0 mb-md-4">
  Elemen dengan margin bottom hanya di layar ≥md
</div>
```

```scss
// Custom fluid font size dengan clamp()
h1 {
  font-size: clamp(1.75rem, 2.5vw + 1rem, 2.5rem);
}

.card-title {
  font-size: clamp(1rem, 1.5vw + 0.5rem, 1.25rem);
}
```

```css
/* Alternatif jika tidak pakai SCSS */
.fluid-text {
  font-size: clamp(1rem, 2vw + 0.5rem, 1.5rem);
}
```

## Analogi

Responsive spacing = **ruangan yang bisa diatur ulang tata letaknya**. Di rumah kecil (mobile), sofa ditempel ke dinding (padding kecil). Di rumah besar (desktop), sofa bisa diberi jarak dari dinding (padding besar). Ukuran furniture (font) juga bisa mengecil/membesar otomatis pakai clamp() seperti meja lipat yang fleksibel.

## Dipakai untuk apa

- Hero section dengan padding lebih lega di desktop
- Card grid dengan jarak antar card lebih rapat di mobile
- Tombol yang lebih besar di layar sentuh (mobile) vs lebih kecil di desktop
- Tipografi yang mengecil proporsional di layar sempit

## Kesalahan umum yang sering terjadi

- **Over-engineering spacing** — Menambahkan class responsive di setiap elemen, padahal cukup di parent
- **Lupa prefix breakpoint** — `py-5` tanpa `py-md-3` bikin mobile kelebihan padding
- **Menggunakan margin negatif tidak konsisten** — Bisa merusak gutter system Bootstrap
- **Tidak pakai clamp()** — Font size tetap menyebabkan teks kepanjangan atau kekecilan di layar tertentu

## Koneksi dengan materi sebelumnya

Sebelumnya kita belajar grid responsif (col-12 col-md-6). Responsive spacing melengkapi grid dengan mengontrol jarak internal (padding) & eksternal (margin) di setiap breakpoint, membuat tata letak lebih presisi.

## Soal latihan & jawaban

**Soal 1:** Tulis class Bootstrap untuk padding-top 3 di mobile dan padding-top 5 di desktop!

**Jawaban:** `pt-3 pt-lg-5`

**Soal 2:** Apa fungsi CSS `clamp(1rem, 2vw + 0.5rem, 1.5rem)`?

**Jawaban:** Memberi nilai font size minimal 1rem, ideal 2vw + 0.5rem, maksimal 1.5rem — ukuran menyesuaikan viewport secara fluid.

**Soal 3:** Apakah `g-4` dan `g-lg-3` bisa digabung? Jelaskan akibatnya!

**Jawaban:** Bisa. `g-4` memberi gutter 1.5rem untuk semua layar, lalu `g-lg-3` menimpa menjadi 1rem untuk layar ≥lg. Efek: jarak antar grid items lebih rapat di desktop.
