# visually-hidden & Kontras Warna

## Penjelasan

`visually-hidden` adalah utility Bootstrap yang menyembunyikan elemen secara visual tetapi tetap dibaca oleh screen reader. Kontras warna memastikan teks cukup terbaca dengan latar belakangnya, minimal rasio 4.5:1 untuk teks normal.

## Fungsi

- Memberi label pada tombol ikon tanpa mengganggu tampilan visual
- Menambahkan teks alternatif untuk screen reader pada elemen dekoratif/interaktif
- Memastikan teks terbaca oleh pengguna dengan low vision
- Membantu lolos audit aksesibilitas WCAG AA

## Cara Pengimplementasian

```html
<!-- visually-hidden untuk tombol icon -->
<button class="btn btn-outline-secondary">
  <span class="visually-hidden">Cari</span>
  🔍
</button>

<!-- visually-hidden untuk link icon -->
<a href="#">
  <span class="visually-hidden">Pengaturan akun</span>
  ⚙️
</a>

<!-- Judul tersembunyi untuk section -->
<section aria-labelledby="news-heading">
  <h2 id="news-heading" class="visually-hidden">Berita Terbaru</h2>
  <div class="card">...</div>
  <div class="card">...</div>
</section>

<!-- visually-hidden-focusable untuk skip link -->
<a href="#main" class="visually-hidden-focusable">Langsung ke konten</a>
```

```css
/* Custom: pastikan kontras warna memenuhi AA */
/* Gunakan tool untuk cek rasio: webaim.org/resources/contrastchecker/ */

/* Contoh kombinasi warna yang aman AA 4.5:1 */
.text-safe {
  color: #212529; /* dark gray on white — rasio ~16:1 */
}

.text-warning-safe {
  color: #664d03; /* dark amber on white — rasio ~7:1 */
  background-color: #fff3cd;
}

/* Hindari kombinasi ini — gagal AA */
.text-danger-bad {
  color: #ff0000; /* merah murni on putih — rasio ~4:0, gagal untuk teks kecil */
}
```

```html
<!-- Cek kontras dengan data atribut untuk testing -->
<span style="color: #6c757d;" data-contrast-ratio="4.68:1">Teks secondary (aman AA)</span>
<span style="color: #adb5bd;" data-contrast-ratio="3.25:1">Teks terlalu terang (gagal AA)</span>
```

## Analogi

visually-hidden = **label tersembunyi di furnitur**. Secara visual tidak terlihat, tapi ketika tunanetra meraba (screen reader) mereka bisa membaca "ini lemari pakaian" atau "ini tombol buka pintu". Kontras warna = **cat dinding dan tulisan yang kontras**. Dinding putih dengan spidol putih tidak terbaca — harus ada perbedaan jelas agar informasi tersampaikan. Rasio 4.5:1 seperti aturan minimal perbedaan warna antara dinding dan tulisan.

## Dipakai untuk apa

- Tombol ikon sosial media (Facebook, Twitter) yang hanya pakai logo
- Badge notifikasi tanpa teks
- Judul section yang sudah jelas dari konteks visual
- Status icon (sukses, error, warning) yang hanya berupa simbol
- Link "Buka di tab baru" dengan icon external

## Kesalahan umum yang sering terjadi

- **Menggunakan `visually-hidden` untuk konten tidak penting** — Malah membuat bising screen reader
- **Mengabaikan kontras pada focus indicator** — Focus ring harus kontras dengan background
- **Hanya andalkan warna untuk menyampaikan informasi** — Status error jangan cuma warna merah, tambah icon/teks
- **`visually-hidden` vs `d-none`** — Tertukar: `d-none` sembunyi dari semua orang (termasuk screen reader), `visually-hidden` hanya visual
- **Kombinasi warna "cuma beda tipis"** — Contoh: `#cccccc` di `#ffffff` hanya rasio 1.6:1, sangat tidak terbaca

## Koneksi dengan materi sebelumnya

Di materi 37 kita belajar ARIA untuk screen reader. `visually-hidden` adalah implementasi praktisnya — memberi label tanpa merusak desain. Kontras warna melengkapi aksesibilitas visual yang dimulai dari audit mobile (materi 34) dan tata letak responsif (materi 35-36).

## Soal latihan & jawaban

**Soal 1:** Apa perbedaan `class="visually-hidden"` dengan `class="d-none"`?

**Jawaban:** `visually-hidden` menyembunyikan elemen secara visual tetapi tetap dibaca screen reader. `d-none` menyembunyikan elemen sepenuhnya — baik visual maupun dari screen reader.

**Soal 2:** Berapa rasio kontras minimum untuk teks normal (ukuran < 18pt / < 14pt bold) agar lolos WCAG AA?

**Jawaban:** 4.5:1

**Soal 3:** Perbaiki tombol berikut agar aksesibel untuk screen reader:
```html
<button>✕</button>
```

**Jawaban:**
```html
<button>
  <span class="visually-hidden">Tutup</span>✕
</button>
```
Atau dengan aria-label:
```html
<button aria-label="Tutup">✕</button>
```
