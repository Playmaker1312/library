# Kustomisasi Dark Mode dengan Sass

## Penjelasan

Bootstrap 5.3+ menggunakan CSS variables (custom properties) yang nilainya berubah saat `data-bs-theme="dark"` diterapkan. Kita bisa meng-override variabel-variabel ini melalui SCSS untuk mendapatkan kontrol penuh atas tampilan dark mode.

## Fungsi

- Mengubah warna latar belakang (`--bs-body-bg`), teks (`--bs-body-color`), dan elemen sekunder (`--bs-secondary-bg`)
- Menyesuaikan warna border agar tetap kontras di kedua mode (`--bs-border-color`)
- Membuat transisi yang halus antara light dan dark mode
- Memberikan identitas visual yang unik tanpa meninggalkan ekosistem Bootstrap

## Cara Pengimplementasian

### 1. Override CSS Variables Langsung di CSS/SCSS

```scss
// variables-override.scss
// Mengubah variabel default Bootstrap
$body-bg: #f8f9fa;
$body-color: #212529;

// Override CSS Variables untuk Dark Mode
[data-bs-theme="dark"] {
  --bs-body-bg: #0d1117;           // background utama (hitam kebiruan)
  --bs-body-color: #c9d1d9;        // teks utama (putih keabu-abuan)
  --bs-secondary-bg: #161b22;      // background sekunder (sedikit lebih terang)
  --bs-tertiary-bg: #21262d;       // background tersier
  --bs-border-color: #30363d;      // warna border
  --bs-body-font-family: 'Inter', sans-serif;
}
```

### 2. Component Overrides Spesifik untuk Dark Mode

```scss
// component-dark.scss
[data-bs-theme="dark"] {
  // Navbar
  .navbar {
    --bs-navbar-bg: #161b22;
    border-bottom: 1px solid var(--bs-border-color);
  }

  // Card
  .card {
    background-color: #161b22;
    border-color: #30363d;
    box-shadow: 0 4px 6px rgba(0, 0, 0, 0.3);
  }

  // Button primary
  .btn-primary {
    --bs-btn-bg: #1f6feb;
    --bs-btn-border-color: #1f6feb;
    --bs-btn-hover-bg: #388bfd;
    --bs-btn-hover-border-color: #388bfd;
  }

  // Table
  .table {
    --bs-table-bg: #0d1117;
    --bs-table-striped-bg: #161b22;
    --bs-table-hover-bg: #1c2128;
    color: var(--bs-body-color);
  }

  // Form controls
  .form-control {
    background-color: #0d1117;
    border-color: #30363d;
    color: var(--bs-body-color);

    &:focus {
      background-color: #0d1117;
      border-color: #1f6feb;
      box-shadow: 0 0 0 2px rgba(31, 111, 235, 0.3);
    }
  }

  // Dropdown
  .dropdown-menu {
    background-color: #161b22;
    border-color: #30363d;
  }

  .dropdown-item {
    color: var(--bs-body-color);

    &:hover {
      background-color: #1c2128;
      color: #f0f6fc;
    }
  }

  // Modal
  .modal-content {
    background-color: #161b22;
    border-color: #30363d;
  }

  // Alert
  .alert-info {
    background-color: #0c2d4a;
    border-color: #1f6feb;
    color: #58a6ff;
  }
}
```

### 3. Transisi Smooth Global

```scss
// transitions.scss
* {
  // Terapkan transisi pada properti yang berubah saat tema berganti
  transition: background-color 0.35s ease,
              color 0.35s ease,
              border-color 0.35s ease,
              box-shadow 0.35s ease;
}

// Kecualikan elemen yang tidak perlu transisi (misal: gambar, video)
img, video, svg {
  transition: none;
}
```

### 4. Menggabungkan Semua di main.scss

```scss
// main.scss
// 1. Import Bootstrap variables dan functions
@import "../node_modules/bootstrap/scss/functions";
@import "../node_modules/bootstrap/scss/variables";
@import "../node_modules/bootstrap/scss/maps";
@import "../node_modules/bootstrap/scss/mixins";

// 2. Buat custom color scheme
$custom-colors: (
  "github-dark": #0d1117,
  "github-blue": #1f6feb,
);

$theme-colors: map-merge($theme-colors, $custom-colors);

// 3. Import Bootstrap
@import "../node_modules/bootstrap/scss/bootstrap";

// 4. Override dark mode
[data-bs-theme="dark"] {
  --bs-body-bg: #0d1117;
  --bs-body-color: #c9d1d9;
  --bs-secondary-bg: #161b22;
  --bs-border-color: #30363d;
}

// 5. Component custom dark mode
[data-bs-theme="dark"] {
  .navbar { background-color: #161b22; }
  .card {
    background-color: #161b22;
    border-color: #30363d;
  }
}
```

### 5. Compile SCSS ke CSS (via terminal)

```bash
npm install -g sass
sass main.scss style.css --watch
```

## Analogi

**Membangun Rumah:**

Kustomisasi dark mode dengan CSS variables seperti **mengganti seluruh cat rumah, furnitur, dan pencahayaan dengan satu setelan saklar**. Bayangkan rumahmu punya mode "siang" dengan dinding putih, sofa krem, dan lampu terang. Mode "malam" dengan dinding biru tua, sofa abu-abu gelap, dan lampu hangat redup.

CSS variable `--bs-body-bg` adalah **warna cat dinding utama**, `--bs-secondary-bg` adalah **warna furnitur sekunder** (seperti meja samping), `--bs-body-color` adalah **warna hiasan dinding**, dan `--bs-border-color` adalah **warna bingkai foto/pintu**. Dengan mengubah satu grup variabel ini, seluruh ruangan berubah tema seragam tanpa perlu mengecat ulang satu per satu.

Transisi smooth adalah **efek peredupan bertahap** — lampu tidak mati mendadak tapi meredup perlahan, cat tidak berubah instan tapi seolah memudar graceful.

## Dipakai untuk apa

- Aplikasi yang ingin dark mode dengan merek sendiri (brand color), bukan default Bootstrap
- Website yang membutuhkan kontras tinggi di mode gelap untuk aksesibilitas
- Dashboard dengan komponen kompleks yang perlu penyesuaian warna detail
- Tema premium/kustom yang dijual dengan variasi dark mode
- Sistem desain internal perusahaan yang konsisten di light dan dark

## Kesalahan umum yang sering terjadi

1. **Hanya mengganti `--bs-body-bg` dan `--bs-body-color`** — Komponen seperti card, table, form tetap tidak terbaca karena menggunakan variabel lain yang tidak di-override.

2. **Lupa menambahkan `[data-bs-theme="dark"]` selector** — Override ditulis secara global, sehingga malah merusak tampilan mode terang.

3. **Override di tempat yang salah dalam urutan import** — SCSS Bootstrap harus di-import terlebih dahulu sebelum override, agar variabel tidak ditimpa kembali oleh Bootstrap.

4. **Tidak menggunakan transisi** — Perubahan tema terasa patah-patah dan kurang profesional.

5. **Mengubah properti yang tidak relevan** — Beberapa developer mengubah padding/margin di selector tema, menyebabkan layout berubah saat toggle.

## Koneksi dengan materi sebelumnya

Pada Bootstrap Level 3 (Components), kita belajar menggunakan card, navbar, dan form dengan class Bootstrap. Sekarang kita bisa **mengontrol warna komponen-komponen tersebut secara global** melalui CSS variables — tanpa perlu mengubah struktur HTML. Ini juga terhubung dengan **Dark Mode Toggle** (file 41) karena override ini baru aktif saat `data-bs-theme="dark"` dipasang. Materi ini juga jembatan ke **Bootstrap JavaScript API** (file 44) dimana komponen yang dibuat via JS akan otomatis mengikuti tema yang sudah di-override.
