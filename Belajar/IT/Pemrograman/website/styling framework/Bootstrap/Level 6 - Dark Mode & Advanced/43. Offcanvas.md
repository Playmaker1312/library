# Offcanvas

## Penjelasan

Offcanvas adalah komponen Bootstrap untuk membuat panel samping yang muncul dari tepi layar. Berbeda dengan modal yang muncul di tengah, offcanvas muncul dari sisi tertentu (kiri, kanan, atas, bawah) dan bisa memiliki lebar kustom.

## Fungsi

- Menampilkan navigasi tambahan, menu, atau konten tanpa meninggalkan halaman utama
- Menghemat ruang layar dengan menyembunyikan panel sampai dibutuhkan
- Memberikan efek "geser masuk" yang lebih natural dibanding modal untuk konten sampingan
- Mendukung backdrop, keyboard dismiss, dan kontrol programatik

## Cara Pengimplementasian

### 1. Offcanvas Dasar (Start / Kiri)

```html
<!-- Tombol trigger -->
<button class="btn btn-primary" type="button"
        data-bs-toggle="offcanvas"
        data-bs-target="#offcanvasStart">
  Buka Menu Kiri
</button>

<!-- Offcanvas -->
<div class="offcanvas offcanvas-start" tabindex="-1"
     id="offcanvasStart"
     aria-labelledby="offcanvasStartLabel">
  <div class="offcanvas-header">
    <h5 class="offcanvas-title" id="offcanvasStartLabel">Menu Navigasi</h5>
    <button type="button" class="btn-close" data-bs-dismiss="offcanvas"></button>
  </div>
  <div class="offcanvas-body">
    <p>Ini adalah body offcanvas. Taruh navigasi atau konten apapun di sini.</p>
    <ul class="list-group">
      <li class="list-group-item">Beranda</li>
      <li class="list-group-item">Profil</li>
      <li class="list-group-item">Pengaturan</li>
    </ul>
  </div>
</div>
```

### 4. Offcanvas dengan Backdrop dan Keyboard Dismiss

```html
<!-- Tanpa backdrop (body tidak redup) -->
<div class="offcanvas offcanvas-start" data-bs-backdrop="false"
     tabindex="-1" id="offcanvasNoBackdrop">
  <!-- konten -->
</div>

<!-- Backdrop statis (tidak bisa tutup dengan klik backdrop) -->
<div class="offcanvas offcanvas-start" data-bs-backdrop="static"
     tabindex="-1" id="offcanvasStatic">
  <!-- konten -->
</div>

<!-- Nonaktifkan keyboard dismiss (tidak bisa tutup dengan Escape) -->
<div class="offcanvas offcanvas-start" data-bs-keyboard="false"
     tabindex="-1" id="offcanvasNoKeyboard">
  <!-- konten -->
</div>
```

### 6. Offcanvas dengan JavaScript (Programmatic Control)

```javascript
// Membuka offcanvas via JS
const offcanvasEl = document.getElementById('offcanvasStart');
const offcanvas = new bootstrap.Offcanvas(offcanvasEl);
offcanvas.show();

// Method lain
offcanvas.hide();
offcanvas.toggle();

// Event listener
offcanvasEl.addEventListener('show.bs.offcanvas', () => {
  console.log('Offcanvas akan dibuka');
});

offcanvasEl.addEventListener('shown.bs.offcanvas', () => {
  console.log('Offcanvas sudah terbuka');
});

offcanvasEl.addEventListener('hide.bs.offcanvas', () => {
  console.log('Offcanvas akan ditutup');
});

offcanvasEl.addEventListener('hidden.bs.offcanvas', () => {
  console.log('Offcanvas sudah tertutup');
});
```

## Analogi

**Membangun Rumah:**

Offcanvas seperti **lemari geser (sliding cabinet) yang muncul dari dalam dinding**. Di ruang tamu, ada dinding yang terlihat polos, tapi saat kamu sentuh sebuah tombol, tiba-tiba sebuah lemari besar meluncur keluar dari kiri — berisi remote TV, game, dan buku. Itulah `offcanvas-start`.

`offcanvas-end` seperti **lemari pajangan yang keluar dari dinding kanan** — isinya vas, foto, dan dekorasi. `offcanvas-top` seperti **penutup jendela roller blind yang turun dari atas**. `offcanvas-bottom` seperti **laci di bawah lantai yang naik ke atas**.

Backdrop adalah **tirai tembus pandang yang menutupi ruangan** saat lemari terbuka — memberi isyarat bahwa fokus kamu sekarang pada lemari tersebut. Keyboard dismiss (tekan Escape) seperti **sensor yang menutup lemari otomatis saat kamu melangkah mundur**. Custom width `--bs-offcanvas-width` adalah **ukuran lemari yang bisa kamu atur sendiri** — dari lemari sempit (250px) sampai lemari sebesar dinding (100vw).

## Dipakai untuk apa

- Navigasi menu samping (sidebar) di mobile
- Panel notifikasi yang muncul dari kanan
- Filter produk di toko online
- Keranjang belanja yang muncul saat diklik
- Form pencarian di panel atas
- Menu pengaturan cepat di bagian bawah (mobile)
- Detail item tanpa meninggalkan halaman utama

## Kesalahan umum yang sering terjadi

1. **Lupa menambahkan `tabindex="-1"`** — Offcanvas tidak bisa di-focus dan keyboard dismiss tidak berfungsi.

2. **Tidak menyertakan `aria-labelledby`** — Aksesibilitas terganggu, screen reader tidak bisa mengidentifikasi judul panel.

3. **Offcanvas tidak memiliki tinggi penuh di mobile** — Pada `offcanvas-bottom`, perlu `style="height: 300px;"` atau set minimal height.

4. **Dua offcanvas terbuka bersamaan** — Bootstrap hanya mendukung satu offcanvas aktif dalam satu waktu.

5. **Backdrop tidak muncul atau muncul tapi tidak berfungsi** — Periksa atribut `data-bs-backdrop` yang mungkin salah di-set ke `false`.

## Koneksi dengan materi sebelumnya

Offcanvas adalah variasi dari **Modal** (Level 3) yang dipelajari sebelumnya — keduanya memiliki backdrop, header, body, dan method show/hide. Perbedaannya: modal muncul di tengah, offcanvas muncul dari tepi. Ini juga terhubung dengan **Bootstrap JavaScript API** (file 44) karena offcanvas memiliki event dan method yang bisa dikontrol via JS (show, hide, toggle, events).
