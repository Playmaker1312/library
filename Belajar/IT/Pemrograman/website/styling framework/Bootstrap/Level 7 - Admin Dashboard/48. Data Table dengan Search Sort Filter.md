# Data Table dengan Search Sort Filter

## Penjelasan

Data table adalah **lemari arsip dengan indeks** di command center rumah. Jika stats card memberi gambaran sekilas (monitor) dan charts memberi tren (grafik di dinding), maka data table adalah tempat Anda menyimpan **semua catatan detail** — siapa penghuni, berapa tagihannya, kapan jatuh tempo, dan sebagainya. Seperti lemari arsip yang punya indeks A-Z, Anda bisa mencari (search), mengurutkan (sort), dan menyaring (filter) dokumen tanpa harus membuka satu per satu map.

Data table yang baik memiliki search input untuk mencari data, select filter untuk menyaring kategori, header kolom yang bisa diklik untuk sorting (asc/desc), pagination untuk membagi data ke halaman, checkbox untuk seleksi massal, serta tombol export untuk mengunduh data.

## Fungsi

- Menampilkan data dalam jumlah besar secara terstruktur dengan kolom yang bisa diurutkan
- Memungkinkan pencarian data secara real-time menggunakan input search
- Menyaring data berdasarkan kategori tertentu (status, tanggal, dll.)
- Membagi data ke halaman-halaman dengan navigasi pagination
- Memberikan kemampuan seleksi massal dengan checkbox "select all"
- Menyediakan ekspor data ke format CSV/Excel

## Analogi

**Rumah — Lemari Arsip dengan Indeks**

- Data table → **lemari arsip** yang berisi map-map penghuni, setiap map (baris) berisi informasi lengkap
- Thead → **label rak/laci** yang menunjukkan isi setiap kolom (Nama, Kamar, Tagihan)
- `cursor-pointer` + sort → **indeks A-Z pada laci** — klik sekali untuk urut A-Z, klik lagi untuk Z-A. Seperti menekan tombol di samping laci arsip
- Search input → **petugas arsip yang langsung mencari map tertentu** saat Anda menyebut nama — tanpa perlu membuka satu per satu laci
- Filter select → **penyaring berdasarkan kategori** — "Tunjukkan hanya map penghuni yang menunggak", seperti memberi stiker warna merah pada map tertentu
- Pagination → **bagian lemari yang ditampilkan per halaman** — tidak semua laci dibuka sekaligus, cukup 10 laci per halaman
- Checkbox "select all" → **menarik semua map dari laci yang sedang terbuka** untuk diproses bersama
- Export CSV → **mesin fotokopi di ujung ruangan** yang menggandakan seluruh daftar arsip ke dalam lembaran kertas untuk dibawa ke rapat
- Info table ("Menampilkan 1-10 dari 50") → **label di samping lemari** yang memberi tahu "Laci 1-10 dari total 50 laci sedang ditampilkan"

## Dipakai untuk apa

Data table dengan search-sort-filter-pagination adalah komponen universal di semua aplikasi bisnis: daftar pengguna, daftar transaksi, daftar produk, daftar pesanan, manajemen inventaris, data karyawan, laporan keuangan, dan log aktivitas.

## Kesalahan umum yang sering terjadi

1. **Sorting hanya mengurutkan halaman saat ini, bukan seluruh data** — pengguna mengklik sort tapi hanya 10 baris yang berubah urutannya. Solusi: sort harus diterapkan ke `filteredData` (keseluruhan data setelah filter), bukan hanya halaman saat ini.
2. **Search tidak case-insensitive** — mencari "budi" tidak menemukan "Budi". Solusi: gunakan `.toLowerCase()` pada kedua sisi perbandingan.
3. **Checkbox "select all" hanya mencentang visual, tidak mengubah state** — saat render ulang, semua checkbox kembali kosong. Solusi: simpan selected IDs dalam state (`Set`), dan proses select all dengan menambah/menghapus ID dari Set.
4. **Pagination tidak reset saat search/filter** — pengguna mencari sesuatu, tapi tetap di halaman 5 yang mungkin sudah kosong. Solusi: reset `state.page = 1` setiap kali search atau filter berubah.
5. **Export CSV tidak handle delimiter koma dengan benar** — jika ada data yang mengandung koma, CSV jadi kacau. Solusi: bungkus setiap nilai dalam tanda kutip ganda.

## Koneksi dengan materi sebelumnya

Tabel (Level 3) adalah dasar dari data table. Form input (Level 2) digunakan untuk search dan filter. Card (Level 2) membungkus seluruh komponen. Grid system (Level 4) mengatur layout header dengan search dan filter. JavaScript DOM manipulation (pengetahuan dasar frontend) digunakan untuk mengisi tabel secara dinamis. Pagination adalah pengembangan dari komponen list group/pagination Bootstrap (Level 2) yang diisi secara dinamis. **Perbedaan utama**: di Level 3 tabel bersifat statis (hardcode), di Level 7 tabel bersifat dinamis (data-driven).

```js
function sortData(array, key, asc = true) {
  const sorted = [...array].sort((a, b) => {
    let va = a[key], vb = b[key];
    if (typeof va === 'string') {
      va = va.toLowerCase();
      vb = vb.toLowerCase();
    }
    if (va < vb) return asc ? -1 : 1;
    if (va > vb) return asc ? 1 : -1;
    return 0;
  });
  return sorted;
}
```

### Soal 2

Buat search function yang memfilter array data berdasarkan keyword, mencocokkan dengan field `nama` dan `email`. Case-insensitive.

<details>
<summary>Jawaban</summary>

```js
function searchData(array, keyword) {
  if (!keyword) return array;
  const q = keyword.toLowerCase();
  return array.filter(item =>
    item.nama.toLowerCase().includes(q) ||
    item.email.toLowerCase().includes(q)
  );
}

// Contoh:
const users = [
  { nama: 'Budi Santoso', email: 'budi@mail.com' },
  { nama: 'Siti Aminah', email: 'siti@mail.com' },
];
console.log(searchData(users, 'budi'));
// [{ nama: 'Budi Santoso', email: 'budi@mail.com' }]
```
