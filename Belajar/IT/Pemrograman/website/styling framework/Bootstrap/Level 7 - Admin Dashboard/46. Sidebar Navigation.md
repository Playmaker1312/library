# Sidebar Navigation

## Penjelasan

Sidebar navigation adalah **panel saklar utama** di command center rumah. Di panel ini, semua saklar (navigasi) dikelompokkan secara rapi: saklar lampu lantai 1, saklar AC, saklar CCTV, dan sebagainya. Setiap saklar bisa ditekan (klik) untuk mengaktifkan fungsi tertentu, dan beberapa saklar memiliki sub-saklar yang bisa dikembangkan (collapsible submenu) — seperti saklar "Lantai 2" yang di dalamnya ada saklar kamar tidur, kamar mandi, dan ruang keluarga.

Sidebar di Bootstrap menggunakan komponen `nav-pills` yang dirotasi secara vertikal, dikombinasikan dengan `collapse` untuk submenu, serta ikon dan teks yang konsisten.

## Fungsi

- Menyediakan navigasi utama yang tetap (persistent) di seluruh halaman dashboard
- Mengelompokkan menu dan submenu secara hierarkis dengan collapsible
- Menampilkan informasi pengguna (avatar, nama, role) di bagian bawah
- Merespons perubahan ukuran layar (hide/show toggle)
- Memberi indikasi halaman aktif secara visual melalui class `active`

SCSS untuk sidebar:

```scss
// _sidebar.scss
$sidebar-width: 260px;
$sidebar-bg: #f8f9fa;
$sidebar-active-bg: #0d6efd;
$sidebar-active-color: #fff;

.sidebar {
  width: $sidebar-width;
  min-height: 100vh;
  background-color: $sidebar-bg;
  position: fixed;
  top: 0;
  left: 0;
  z-index: 1000;
  transition: transform 0.3s ease;

  // Nav pills vertical
  .nav-pills {
    .nav-link {
      border-radius: 0.5rem;
      margin-bottom: 2px;
      color: #333;
      transition: all 0.2s;

      i:first-child {
        font-size: 1.1rem;
        width: 1.5rem;
        text-align: center;
      }

      &:hover {
        background-color: darken($sidebar-bg, 5%);
      }

      &.active {
        background-color: $sidebar-active-bg;
        color: $sidebar-active-color;
        font-weight: 600;
      }

      // Collapse indicator rotation
      &[data-bs-toggle="collapse"] {
        .bi-chevron-down {
          transition: transform 0.3s ease;
        }

        &[aria-expanded="true"] .bi-chevron-down {
          transform: rotate(180deg);
        }
      }
    }
  }

  // Submenu
  .collapse .nav-pills .nav-link {
    font-size: 0.9rem;
    padding-top: 0.35rem;
    padding-bottom: 0.35rem;

    &.active {
      background-color: rgba($sidebar-active-bg, 0.15);
      color: $sidebar-active-bg;
    }
  }

  // User section
  .sidebar-footer {
    background-color: darken($sidebar-bg, 2%);
  }

  // Hide sidebar on mobile
  @media (max-width: 767.98px) {
    transform: translateX(-100%);

    &.show {
      transform: translateX(0);
    }
  }
}
```

JavaScript toggle untuk mobile:

```js
// sidebar.js
const sidebar = document.getElementById('sidebarNav');
const toggleBtn = document.getElementById('toggleSidebar');

toggleBtn?.addEventListener('click', () => {
  sidebar.classList.toggle('show');
});
```

## Analogi

**Rumah — Panel Saklar Utama**

- Sidebar → **panel saklar utama** yang terpasang di dinding dekat pintu masuk command center
- `nav-pills` → **deretan saklar** yang masing-masing punya fungsi spesifik (lampu, AC, CCTV)
- Collapsible submenu → **panel saklar yang punya sub-panel** — misalnya saklar "Lantai 2" bisa dibuka untuk menampilkan saklar kamar tidur, kamar mandi, ruang keluarga
- Icon (`bi-*`) → **lambang pada saklar** (gambar bola lampu untuk lampu, kipas untuk AC) yang membantu pengguna mengenali fungsi tanpa perlu membaca teks
- `active` class → **saklar yang sedang menyala** (posisi ON), ditandai dengan warna berbeda
- Badge notifikasi (angka 12) → **indikator merah** pada saklar yang menunjukkan ada sesuatu yang perlu perhatian (misal: 12 lampu mati)
- User info di bottom → **kartu identitas penghuni** yang ditempel di bagian bawah panel saklar
- `collapse` → **tutup panel sub-saklar** yang bisa dibuka/tutup agar panel utama tidak terlalu penuh
- Sidebar menghilang di mobile → **panel saklar yang bisa dilipat** saat ruangan sempit, cukup sentuh tombol untuk memunculkannya kembali

## Dipakai untuk apa

Sidebar navigation digunakan di semua aplikasi web modern yang membutuhkan hierarki navigasi: dashboard admin, panel hosting (cPanel), CMS backend (WordPress admin), aplikasi SaaS, sistem informasi sekolah/rumah sakit, dan aplikasi monitoring jaringan.

## Kesalahan umum yang sering terjadi

1. **Collapse submenu tidak berfungsi** — lupa menambahkan `data-bs-toggle="collapse"` dan `href` yang sesuai dengan id target. Pastikan id pada `.collapse` cocok dengan `href`.
2. **Class `active` tidak dinamis** — sidebar aktif tetap di satu menu meskipun halaman berubah. Solusi: set class active via JavaScript berdasarkan URL atau state aplikasi.
3. **Icon tidak konsisten** — ada menu yang pakai icon, ada yang tidak. Ini membingungkan pengguna. Solusi: tetapkan ikon untuk setiap menu.
4. **User info tertimpa konten navigasi** — user section tidak tetap di bawah. Solusi: gunakan `mt-auto` dengan `d-flex flex-column` pada sidebar.
5. **Sidebar tidak tertutup otomatis di mobile setelah klik link** — pengguna harus menutup manual. Solusi: tambahkan event listener pada `nav-link` di mobile untuk menutup sidebar.

## Koneksi dengan materi sebelumnya

Di Level 2 Anda telah belajar `navs & nav-pills` untuk navigasi horizontal (tab). Di Level 7, navigasi tersebut diputar menjadi vertikal dan ditempatkan di sidebar. Collapse (Level 6) digunakan untuk submenu — ini adalah penggabungan dari komponen navigasi dan collapse. Utility flexbox (`d-flex`, `flex-column`, `mt-auto`) menyusun layout internal sidebar. Ini semua adalah komposisi dari komponen-komponen Bootstrap yang sudah dipelajari sebelumnya.

### Soal 2

Apa fungsi `data-bs-toggle="collapse"` pada elemen `<a>` di sidebar?

<details>
<summary>Jawaban</summary>

`data-bs-toggle="collapse"` memberitahu Bootstrap untuk menginisialisasi komponen collapse pada elemen target (yang diacu melalui `href`). Saat diklik, elemen target akan muncul atau menghilang dengan animasi. Tanpa atribut ini, klik hanya akan melakukan navigasi biasa (link) tanpa efek buka/tutup submenu.

</details>

### Soal 3

Bagaimana cara menambahkan badge notifikasi di samping teks menu, misalnya menu "Pesan" dengan jumlah 5 pesan belum dibaca?

<details>
<summary>Jawaban</summary>

Gunakan class `badge` dengan `rounded-pill` dan `ms-auto` agar badge berada di ujung kanan link:

```html
<a class="nav-link d-flex align-items-center" href="#">
  <i class="bi bi-envelope me-3"></i>
  <span>Pesan</span>
  <span class="badge bg-danger rounded-pill ms-auto">5</span>
</a>
```

`ms-auto` mendorong badge ke kanan karena parent menggunakan `d-flex`.

</details>
