# Badge — Stiker / Label pada Barang

## Penjelasan
**Badge** adalah komponen kecil untuk menampilkan label, jumlah, atau status. Dalam analogi **Membangun Rumah**, badge adalah **stiker atau label yang ditempel pada barang** — seperti label harga, stiker "Diskon 50%", atau label "Baru" pada kemasan.

---

## Fungsi
- Menampilkan jumlah notifikasi (misal: inbox 5+)
- Memberi label status (Baru, Populer, Best Seller)
- Menambahkan konteks pada heading atau tombol

---

## Cara Pengimplementasian
Gunakan class `.badge` ditambah variant warna.

```html
<!-- Badge Dasar -->
<span class="badge bg-primary">Primary</span>
<span class="badge bg-secondary">Secondary</span>
<span class="badge bg-success">Success</span>
<span class="badge bg-danger">Danger</span>
<span class="badge bg-warning text-dark">Warning</span>
<span class="badge bg-info text-dark">Info</span>
<span class="badge bg-light text-dark">Light</span>
<span class="badge bg-dark">Dark</span>

<!-- Badge dalam Heading -->
<h1>Heading 1 <span class="badge bg-secondary">Baru</span></h1>
<h2>Heading 2 <span class="badge bg-secondary">Baru</span></h2>
<h3>Heading 3 <span class="badge bg-secondary">Baru</span></h3>

<!-- Badge Pill (membulat) -->
<span class="badge rounded-pill bg-primary">Pill Badge</span>
<span class="badge rounded-pill bg-danger">99+</span>

<!-- Badge Posisi pada Tombol -->
<button type="button" class="btn btn-primary position-relative">
  Inbox
  <span class="position-absolute top-0 start-100 translate-middle badge rounded-pill bg-danger">
    5+
    <span class="visually-hidden">pesan belum dibaca</span>
  </span>
</button>
```

---

## Analogi — Membangun Rumah
| Elemen | Analogi |
|--------|---------|
| `.badge bg-danger` | **Label stiker merah "DISKON"** — mencolok |
| `.badge bg-success` | **Stiker hijau "LULUS QUALITY CONTROL"** |
| `.rounded-pill` | **Label berbentuk bulat** — seperti stiker bundar |
| Badge di heading | **Label "Baru" pada kotak kemasan** |
| Badge di tombol | **Stiker jumlah di handle pintu** — "Tekan 5x" |

---

## Dipakai untuk apa
- Notifikasi jumlah (email, chat, keranjang)
- Label status pesanan (Diproses, Dikirim, Selesai)
- Tag / chip pada konten
- Angka pada pagination atau tab

---

## Kesalahan umum yang sering terjadi
| Kesalahan | Solusi |
|-----------|--------|
| Badge tidak terlihat karena warna terlalu terang | Tambahkan `text-dark` pada badge kuning/terang |
| Lupa `rounded-pill` padahal ingin bentuk bulat | Tambahkan class `rounded-pill` |
| Badge di tombol tidak rapi | Gunakan `position-relative` pada parent dan `translate-middle` |
| `visually-hidden` tidak ditambahkan untuk aksesibilitas | Selalu tambahkan teks untuk screen reader |

---

## Koneksi dengan materi sebelumnya
- **Level 1 — Typography**: Badge bisa diletakkan di dalam heading untuk memperkaya judul.
- **Level 2 — Button**: Badge sering ditempel di dalam button untuk menampilkan jumlah/notifikasi.

---

## Soal Latihan & Jawaban

### Soal 1
Buatlah badge **Danger** berbentuk **pill** dengan teks "99+".

<details>
<summary>Jawaban</summary>

```html
<span class="badge rounded-pill bg-danger">99+</span>
```
</details>

### Soal 2
Buatlah sebuah heading `<h3>` yang memiliki badge "Populer" di sampingnya.

<details>
<summary>Jawaban</summary>

```html
<h3>Materi Bootstrap <span class="badge bg-success">Populer</span></h3>
```
</details>

### Soal 3
Buatlah tombol "Notifikasi" dengan badge jumlah di pojok kanan atas.

<details>
<summary>Jawaban</summary>

```html
<button type="button" class="btn btn-primary position-relative">
  Notifikasi
  <span class="position-absolute top-0 start-100 translate-middle badge rounded-pill bg-danger">
    12
    <span class="visually-hidden">notifikasi baru</span>
  </span>
</button>
```
</details>
