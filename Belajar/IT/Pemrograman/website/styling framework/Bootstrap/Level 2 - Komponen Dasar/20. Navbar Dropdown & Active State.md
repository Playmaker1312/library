# Navbar Dropdown & Active State — Papan Petunjuk Bertingkat

## Penjelasan
**Dropdown** pada navbar memungkinkan menu bertingkat (sub-menu). Dalam analogi **Membangun Rumah**, dropdown adalah **papan petunjuk arah bertingkat** — misalnya papan utama bertuliskan "Lantai 2 ↓", lalu saat dilihat lebih dekat ada sub-petunjuk "Kamar Tidur ←", "Kamar Mandi →". **Active state** adalah **tanda "Kamu di sini"** yang menandai halaman sedang aktif.

---

## Fungsi
- Menyusun menu bertingkat (nested menu)
- Menghemat ruang navbar dengan menyembunyikan sub-menu
- Menandai halaman aktif dengan highlight visual

---

## Cara Pengimplementasian

```html
<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
  <div class="container-fluid">
    <a class="navbar-brand" href="#">RumahQ</a>
    <button class="navbar-toggler" type="button" data-bs-toggle="collapse"
            data-bs-target="#navbarDropdown" aria-controls="navbarDropdown"
            aria-expanded="false" aria-label="Toggle navigation">
      <span class="navbar-toggler-icon"></span>
    </button>

    <div class="collapse navbar-collapse" id="navbarDropdown">
      <ul class="navbar-nav">

        <!-- Active state -->
        <li class="nav-item">
          <a class="nav-link active" aria-current="page" href="#">Beranda</a>
        </li>

        <!-- Dropdown -->
        <li class="nav-item dropdown">
          <a class="nav-link dropdown-toggle" href="#" role="button"
             data-bs-toggle="dropdown" aria-expanded="false">
            Layanan
          </a>
          <ul class="dropdown-menu">
            <li><a class="dropdown-item" href="#">Desain Interior</a></li>
            <li><a class="dropdown-item" href="#">Renovasi</a></li>
            <li><a class="dropdown-item" href="#">Bangun Baru</a></li>
            <li><hr class="dropdown-divider"></li>
            <li><a class="dropdown-item" href="#">Konsultasi</a></li>
          </ul>
        </li>

        <li class="nav-item">
          <a class="nav-link" href="#">Kontak</a>
        </li>

      </ul>
    </div>
  </div>
</nav>
```

---

## Analogi — Membangun Rumah
| Elemen | Analogi |
|--------|---------|
| `.dropdown` | **Papan petunjuk yang bisa dibuka** — seperti buku petunjuk |
| `.dropdown-toggle` | **Tanda "↓" pada papan** — "ada info tambahan di bawah" |
| `.dropdown-menu` | **Daftar sub-petunjuk yang muncul** saat papan dibuka |
| `.dropdown-item` | **Setiap baris petunjuk detail** — "Kamar Mandi ←" |
| `.dropdown-divider` | **Garis pemisah** — seperti sekat antar kategori petunjuk |
| `.active` | **Stiker "Kamu di sini"** — menandai halaman yang sedang dikunjungi |
| `aria-current="page"` | **Label aksesibilitas** — memberitahu screen reader "ini halaman aktif" |

---

## Dipakai untuk apa
- Menu "Produk" dengan sub-kategori (Elektronik, Fashion, Makanan)
- Menu "Layanan" dengan sub-halaman
- Profil user dengan dropdown (Login, Register, Logout)
- Menandai halaman aktif di navigasi

---

## Kesalahan umum yang sering terjadi
| Kesalahan | Solusi |
|-----------|--------|
| Dropdown tidak terbuka | Pastikan `data-bs-toggle="dropdown"` ada dan Bootstrap JS terload |
| Lupa `dropdown-toggle` sehingga tidak ada panah | Tambahkan class `dropdown-toggle` pada link |
| Active state tidak muncul | Tambahkan class `active` dan `aria-current="page"` |
| Dropdown terpotong di layar kecil | Bootstrap otomatis menangani ini; pastikan `navbar-expand-*` sesuai |
| `dropdown-divider` tidak terlihat | Letakkan `<li><hr class="dropdown-divider"></li>` di antara item |

### Soal 3
Apa fungsi `aria-current="page"` dan mengapa penting?

<details>
<summary>Jawaban</summary>

`aria-current="page"` memberi tahu screen reader bahwa link tersebut adalah halaman yang sedang aktif. Ini penting untuk **aksesibilitas** (a11y) agar pengguna disabilitas yang menggunakan pembaca layar tahu posisi mereka di dalam website.
</details>
