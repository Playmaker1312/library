# Alert — Sirine / Lampu Peringatan

## Penjelasan
**Alert** adalah komponen untuk menampilkan pesan informatif, peringatan, atau konfirmasi. Dalam analogi **Membangun Rumah**, alert adalah **sirine kebakaran, lampu peringatan, atau bel pintu** — memberi tahu penghuni bahwa ada sesuatu yang perlu diperhatikan: "Kebakaran!" (danger), "Pintu terbuka" (warning), "Ada tamu" (info), "Paket sampai" (success).

---

## Fungsi
- Memberi umpan balik kepada pengguna (sukses, error, peringatan, info)
- Menampilkan pesan yang bisa ditutup (dismissible)
- Menyertakan tautan di dalam alert

---

## Cara Pengimplementasian

```html
<!-- Alert Dasar -->
<div class="alert alert-primary" role="alert">
  Pesan informatif utama.
</div>
<div class="alert alert-secondary" role="alert">
  Pesan sekunder.
</div>
<div class="alert alert-success" role="alert">
  ✅ Data berhasil disimpan!
</div>
<div class="alert alert-danger" role="alert">
  ⛔ Gagal menyimpan data.
</div>
<div class="alert alert-warning" role="alert">
  ⚠️ Periksa kembali input Anda.
</div>
<div class="alert alert-info" role="alert">
  ℹ️ Sistem akan diperbarui pukul 22.00.
</div>

<!-- Alert dengan Ikon (menggunakan HTML biasa) -->
<div class="alert alert-success d-flex align-items-center" role="alert">
  <svg class="bi flex-shrink-0 me-2" width="24" height="24" role="img" aria-label="Success:">
    <use xlink:href="#check-circle-fill"/>
  </svg>
  <div>Data berhasil dikirim!</div>
</div>

<!-- Dismissible Alert (bisa ditutup) -->
<div class="alert alert-warning alert-dismissible fade show" role="alert">
  <strong>Perhatian!</strong> Ini adalah pesan peringatan yang bisa ditutup.
  <button type="button" class="btn-close" data-bs-dismiss="alert" aria-label="Close"></button>
</div>

<!-- Alert dengan Link -->
<div class="alert alert-info" role="alert">
  Baca <a href="#" class="alert-link">syarat dan ketentuan</a> sebelum melanjutkan.
</div>

<div class="alert alert-success" role="alert">
  Pendaftaran berhasil! <a href="#" class="alert-link">Login sekarang</a>
</div>
```

---

## Analogi — Membangun Rumah
| Elemen | Analogi |
|--------|---------|
| `alert-success` | **Lampu hijau "Semua aman"** — POS paket sudah diantar |
| `alert-danger` | **Sirine kebakaran** — ada error, harus segera ditangani |
| `alert-warning` | **Lampu kuning "Hati-hati"** — lantai licin, periksa input |
| `alert-info` | **Bel informasi "Ada tamu"** — sekadar pemberitahuan |
| `alert-dismissible` | **Tombol matikan sirine** — klik X untuk menutup |
| `.btn-close` | **Tombol "OFF" pada alarm** — menutup alert |
| `alert-link` | **Tanda "Lihat peta evakuasi"** — link di dalam pesan peringatan |

---

## Dipakai untuk apa
- Notifikasi sukses setelah submit form
- Pesan error validasi
- Peringatan sebelum aksi penting (hapus data)
- Info maintenance atau pembaruan sistem
- Banner cookie / GDPR

---

## Kesalahan umum yang sering terjadi
| Kesalahan | Solusi |
|-----------|--------|
| Lupa menambahkan `role="alert"` | Selalu tambahkan `role="alert"` untuk aksesibilitas |
| Alert tidak bisa ditutup | Pastikan ada `alert-dismissible`, `fade show`, dan tombol dengan `data-bs-dismiss="alert"` |
| Link di alert tidak kelihatan | Gunakan class `alert-link` agar warnanya sesuai dengan konteks alert |
| Alert muncul terus padahal sudah dibaca | Gunakan dismissible agar user bisa menutup |

---

## Koneksi dengan materi sebelumnya
- **Level 2 — Button (15)**: Dismissible alert menggunakan button dengan class `btn-close`.
- **Level 1 — Spacing**: Alert bisa diberi margin (`mb-*`, `mt-*`) untuk jarak antar elemen.
- **Level 1 — Typography**: Gunakan `<strong>` untuk menonjolkan kata kunci dalam alert.

## Soal Latihan & Jawaban

### Soal 1
Buatlah alert **success** dengan pesan "Pembayaran berhasil diproses!" dan sebuah link "Lihat detail transaksi".

<details>
<summary>Jawaban</summary>

```html
<div class="alert alert-success" role="alert">
  Pembayaran berhasil diproses! <a href="#" class="alert-link">Lihat detail transaksi</a>
</div>
```
</details>

### Soal 2
Buatlah alert **danger** yang bisa ditutup (dismissible).

<details>
<summary>Jawaban</summary>

```html
<div class="alert alert-danger alert-dismissible fade show" role="alert">
  <strong>Error!</strong> Koneksi internet terputus.
  <button type="button" class="btn-close" data-bs-dismiss="alert" aria-label="Close"></button>
</div>
```
</details>

### Soal 3
Buatlah **3 alert** berjajar: info tentang jadwal maintenance, warning tentang backup data, dan success setelah backup selesai.

<details>
<summary>Jawaban</summary>

```html
<div class="alert alert-info" role="alert">
  ℹ️ Maintenance dijadwalkan pukul 02.00 - 04.00.
</div>
<div class="alert alert-warning" role="alert">
  ⚠️ Harap backup data sebelum maintenance.
</div>
<div class="alert alert-success" role="alert">
  ✅ Backup berhasil! Data aman.
</div>
```
</details>
