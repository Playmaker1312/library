# Button — Handle Pintu & Saklar Rumah

## Penjelasan
**Button** adalah elemen interaktif yang digunakan untuk melakukan aksi saat diklik. Dalam analogi **Membangun Rumah**, button adalah **handle pintu atau saklar listrik** — kamu tekan atau tarik untuk membuka pintu, menyalakan lampu, atau memicu sesuatu terjadi.

Bootstrap menyediakan banyak varian button: warna solid, outline, ukuran, full width, disabled state, active state, dan link button.

---

## Fungsi
- Memicu aksi seperti submit form, navigasi, toggle komponen, dll.
- Memberi sinyal visual bahwa elemen bisa diklik.
- Membedakan tingkat urgensi (danger = merah, primary = biru, dll).

---

## Cara Pengimplementasian
Gunakan class `.btn` sebagai dasar, lalu tambahkan class varian.

```html
<!-- Solid Button -->
<button class="btn btn-primary">Primary</button>
<button class="btn btn-secondary">Secondary</button>
<button class="btn btn-success">Success</button>
<button class="btn btn-danger">Danger</button>
<button class="btn btn-warning">Warning</button>
<button class="btn btn-info">Info</button>
<button class="btn btn-light">Light</button>
<button class="btn btn-dark">Dark</button>

<!-- Outline Button (hanya border, tanpa background) -->
<button class="btn btn-outline-primary">Outline Primary</button>
<button class="btn btn-outline-danger">Outline Danger</button>

<!-- Ukuran Button -->
<button class="btn btn-primary btn-lg">Large</button>
<button class="btn btn-primary btn-sm">Small</button>

<!-- Full Width Button -->
<div class="d-grid">
  <button class="btn btn-primary">Full Width</button>
</div>

<!-- Disabled & Active State -->
<button class="btn btn-primary" disabled>Disabled</button>
<button class="btn btn-primary active">Active</button>

<!-- Link Button -->
<a class="btn btn-primary" href="#" role="button">Link Button</a>
<button class="btn btn-link">Link</button>
```

---

## Analogi — Membangun Rumah
| Elemen | Analogi |
|--------|---------|
| `.btn-primary` | **Handle pintu utama (depan)** — paling sering digunakan |
| `.btn-danger` | **Saklar alarm kebakaran** — merah, peringatan |
| `.btn-outline` | **Handle transparan** — hanya terlihat garisnya |
| `.btn-lg` / `.btn-sm` | **Handle besar untuk pintu gudang / kecil untuk lemari** |
| `.disabled` | **Handle yang digembok** — tidak bisa diputar |
| `.active` | **Saklar yang sedang ON** — ditekan |
| `.btn-link` | **Handle yang terlihat seperti stiker arah** — bentuknya berbeda |

---

## Dipakai untuk apa
- Tombol submit di form
- Navigasi halaman
- Trigger modal, collapse, dropdown
- Aksi hapus/edit data

---

## Kesalahan umum yang sering terjadi
| Kesalahan | Solusi |
|-----------|--------|
| Lupa menambahkan class `.btn` | Selalu tulis `class="btn btn-xxx"` |
| Button di dalam `<a>` tanpa `role="button"` | Tambahkan `role="button"` pada tag `<a>` |
| Button tidak responsif di mobile | Gunakan `.btn-lg` atau `.d-grid` untuk full width |
| Outline button tidak terbaca | Pastikan kontras warna cukup dengan background |

---

## Koneksi dengan materi sebelumnya
- **Level 1 — Grid & Spacing**: Button bisa diletakkan dalam kolom grid, diberi margin dengan `m-*` dan padding dengan `p-*`.
- **Level 1 — Typography**: Teks di dalam button menggunakan class teks Bootstrap.
