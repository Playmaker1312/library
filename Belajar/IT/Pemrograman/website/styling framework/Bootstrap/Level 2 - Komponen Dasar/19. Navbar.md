# Navbar — Papan Petunjuk Arah

## Penjelasan
**Navbar** (navigation bar) adalah komponen navigasi utama di bagian atas halaman web. Dalam analogi **Membangun Rumah**, navbar adalah **papan petunjuk arah** yang dipasang di pintu masuk atau persimpangan — menunjukkan "Kamar Tidur →", "Dapur ←", "Ruang Tamu ↓" sehingga pengunjung tidak tersesat.

---

## Fungsi
- Menyediakan navigasi utama situs
- Responsif: berubah menjadi menu hamburger di layar kecil
- Bisa dibuat sticky (tetap di atas saat scroll)

---

## Cara Pengimplementasian

```html
<!-- Struktur Navbar Dasar -->
<nav class="navbar navbar-expand-lg navbar-light bg-light">
  <div class="container-fluid">
    <!-- Brand -->
    <a class="navbar-brand" href="#">RumahQ</a>

    <!-- Tombol Hamburger (muncul di layar kecil) -->
    <button class="navbar-toggler" type="button" data-bs-toggle="collapse"
            data-bs-target="#navbarNav" aria-controls="navbarNav"
            aria-expanded="false" aria-label="Toggle navigation">
      <span class="navbar-toggler-icon"></span>
    </button>

    <!-- Menu yang bisa collapse -->
    <div class="collapse navbar-collapse" id="navbarNav">
      <ul class="navbar-nav">
        <li class="nav-item">
          <a class="nav-link active" aria-current="page" href="#">Beranda</a>
        </li>
        <li class="nav-item">
          <a class="nav-link" href="#">Tentang</a>
        </li>
        <li class="nav-item">
          <a class="nav-link" href="#">Kontak</a>
        </li>
      </ul>
    </div>
  </div>
</nav>

<!-- Navbar dengan sticky-top (tetap di atas saat scroll) -->
<nav class="navbar navbar-expand-lg navbar-dark bg-dark sticky-top">
  <div class="container-fluid">
    <a class="navbar-brand" href="#">Sticky Navbar</a>
    <button class="navbar-toggler" type="button" data-bs-toggle="collapse"
            data-bs-target="#navbarSticky" aria-controls="navbarSticky"
            aria-expanded="false" aria-label="Toggle navigation">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="navbarSticky">
      <ul class="navbar-nav">
        <li class="nav-item"><a class="nav-link" href="#">Home</a></li>
        <li class="nav-item"><a class="nav-link" href="#">Features</a></li>
      </ul>
    </div>
  </div>
</nav>
```

---

## Analogi — Membangun Rumah
| Elemen | Analogi |
|--------|---------|
| `.navbar` | **Papan petunjuk arah utama** |
| `.navbar-brand` | **Nama rumah / logo** di bagian atas papan |
| `.nav-link` | **Tulisan arah** — "Kamar Tidur →" |
| `.navbar-toggler` | **Tombol "Buka peta"** — saat layar kecil, petunjuk disembunyikan |
| `.navbar-expand-lg` | **Aturan: petunjuk melebar di ruangan besar (≥992px)** |
| `.collapse` | **Petunjuk yang bisa dilipat** saat ruangan sempit |
| `.sticky-top` | **Papan petunjuk yang tetap terlihat meski halaman di-scroll** |
| `navbar-light bg-light` | **Papan berwarna terang** (sopan, elegan) |
| `navbar-dark bg-dark` | **Papan berwarna gelap** (modern, kontras) |

---

## Dipakai untuk apa
- Navigasi utama website
- Menu aplikasi web
- Header dengan brand, menu, dan tombol aksi
- Sidebar navigasi (versi vertical)

---

## Kesalahan umum yang sering terjadi
| Kesalahan | Solusi |
|-----------|--------|
| Menu tidak collapse di mobile | Pastikan `navbar-expand-lg` / `-md` dan `data-bs-target` cocok dengan `id` collapse |
| Lupa menyertakan `container-fluid` | Bungkus konten navbar dalam `container-fluid` atau `container` |
| Hamburger icon tidak muncul | Pastikan `navbar-toggler-icon` ada di dalam tombol |
| Link tidak aktif / tidak bisa diklik | Periksa apakah elemen collapse tidak menimpa link (z-index) |
| Navbar menutupi konten saat `sticky-top` | Tambahkan `padding-top` pada konten di bawahnya |

---

## Koneksi dengan materi sebelumnya
- **Level 1 — Grid**: Navbar menggunakan `container-fluid` untuk full-width atau `container` untuk terpusat.
- **Level 1 — Spacing**: Gunakan `me-auto`, `ms-auto`, `mx-auto` untuk mengatur posisi menu.
- **Level 2 — Button (15)**: Button bisa ditempatkan di dalam navbar untuk tombol aksi (Login, Daftar).

### Soal 3
Jelaskan fungsi dari atribut `data-bs-target` pada tombol hamburger.

<details>
<summary>Jawaban</summary>

`data-bs-target` berfungsi untuk menghubungkan tombol hamburger dengan elemen menu yang akan ditampilkan/ditutup. Nilainya adalah CSS selector (biasanya `#id`) yang merujuk ke `id` dari `<div class="collapse navbar-collapse">`. Tanpa ini, tombol hamburger tidak akan berfungsi.
</details>
