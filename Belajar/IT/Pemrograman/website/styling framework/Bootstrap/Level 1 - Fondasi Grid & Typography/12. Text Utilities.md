# Text Utilities

## Penjelasan
Bootstrap menyediakan kelas utilitas untuk mengatur tampilan teks: alignment (perataan), weight (ketebalan), transform (kapitalisasi), wrapping, dan truncate (pemotongan teks).

## Fungsi
Mengontrol tampilan teks tanpa harus menulis CSS custom — cepat dan konsisten.

## Cara Pengimplementasian

```html
<!-- Text alignment (perataan) -->
<p class="text-start">Rata kiri (default)</p>
<p class="text-center">Rata tengah</p>
<p class="text-end">Rata kanan</p>

<!-- Responsive alignment -->
<p class="text-center text-md-start">Center di HP, kiri di tablet+</p>

<!-- Font weight (ketebalan) -->
<p class="fw-bold">Tebal (bold)</p>
<p class="fw-semibold">Semi-tebal</p>
<p class="fw-normal">Normal</p>
<p class="fw-light">Tipis (light)</p>
<p class="fst-italic">Miring (italic)</p>
<p class="fst-normal">Normal</p>

<!-- Text transform (kapitalisasi) -->
<p class="text-lowercase">JADI KECIL SEMUA</p>
<p class="text-uppercase">jadi besar semua</p>
<p class="text-capitalize">setiap kata diawali kapital</p>

<!-- Truncate (potong dengan ellipsis) -->
<div class="row">
  <div class="col-4 text-truncate">
    Teks yang sangat panjang ini akan dipotong dengan tanda titik-titik...
  </div>
</div>

<!-- Line height -->
<p class="lh-1">Line height 1 (rapat)</p>
<p class="lh-sm">Line height small</p>
<p class="lh-base">Line height default</p>
<p class="lh-lg">Line height besar (renggang)</p>

<!-- Monospace -->
<p class="font-monospace">Teks monospace — cocok untuk kode</p>
```

## Analogi
Text utilities = **alat dekorasi dinding** rumah:
- `text-center` = **memasang lukisan tepat di tengah dinding**
- `fw-bold` = **menggunakan spidol tebal** untuk tulisan di papan
- `text-uppercase` = **tulisan kapital** seperti "EXIT" di papan darurat
- `text-truncate` = **papan nama yang terlalu panjang** — ujungnya terpotong "..."
- `font-monospace` = **huruf mesin ketik** — setiap huruf lebar sama

## Dipakai untuk apa
Merapikan teks: judul artikel rata tengah, tombol kapital semua, label bold, deskripsi produk dipotong jika terlalu panjang.

## Kesalahan umum yang sering terjadi
- Menggunakan `<br>` berkali-kali untuk spasi — lebih baik pakai margin utilities
- Mengira `text-end` adalah rata kanan kanan sekali (tidak, hanya rata kanan dalam container)
- `text-truncate` hanya bekerja pada elemen block dengan lebar terbatas (perlu `d-block` jika di inline)
- Mencampur `fw-bold` dengan `<b>` atau `<strong>` secara redundan

## Koneksi dengan materi sebelumnya
Heading (materi 11) mengatur hierarki teks, sedangkan text utilities mengatur detail tampilan teks. Bersama-sama mereka adalah "dekorasi dinding" yang melengkapi isi "ruangan" (kolom) dalam layout grid.

## Soal latihan & jawaban

**1. Buat teks rata tengah di HP, rata kiri di laptop!**
```html
<p class="text-center text-lg-start">Konten teks</p>
```

**2. Class apa yang membuat teks menjadi kapital semua?**
`text-uppercase`

**3. Dalam analogi rumah, apa yang diwakili oleh `fw-bold`?**
Spidol tebal untuk menulis di papan nama atau tanda — sehingga tulisan lebih terlihat dan terbaca dari kejauhan.
