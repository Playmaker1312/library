# Setup Bootstrap via npm + Vite

## Penjelasan
Vite adalah build tool modern yang cepat. Menggabungkan Vite dengan Bootstrap via npm cocok untuk project nyata yang membutuhkan kustomisasi, modularisasi, dan optimasi produksi.

## Fungsi
Menyediakan lingkungan pengembangan profesional: hot reload, kompilasi SCSS kustom, bundling file, dan tree-shaking.

## Cara Pengimplementasian

```bash
# 1. Buat project Vite
npm create vite@latest project-ku -- --template vanilla

# 2. Masuk ke folder
cd project-ku

# 3. Install Bootstrap
npm install bootstrap @popperjs/core

# 4. Import Bootstrap di main.js
```

```js
// main.js
import 'bootstrap/dist/css/bootstrap.min.css';
import 'bootstrap/dist/js/bootstrap.bundle.min.js';
```

```html
<!-- index.html -->
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  <div class="container py-5">
    <h1 class="text-center text-primary">Bootstrap + Vite</h1>
  </div>
  <script type="module" src="/main.js"></script>
</body>
</html>
```

## Analogi
Setup npm + Vite seperti **membangun bengkel tukang kayu permanen** — kamu memiliki gergaji listrik, meja kerja, dan lemari penyimpanan sendiri. Butuh waktu lebih lama untuk menyiapkan, tetapi semua alat selalu tersedia dan bisa kamu modifikasi sesuai kebutuhan untuk proyek besar.

## Dipakai untuk apa
Project profesional dan berskala besar yang perlu kustomisasi tema, SCSS kustom, atau kolaborasi tim dengan version control.

## Kesalahan umum yang sering terjadi
- Lupa menjalankan `npm install` setelah clone repo
- Tidak mengimpor file CSS Bootstrap, hanya JS-nya
- Mengimpor Bootstrap dua kali (CDN + npm)
- Salah path pada `main.js`

## Koneksi dengan materi sebelumnya
Setup CDN (materi 2) cocok untuk belajar cepat. Setup npm + Vite adalah versi profesional untuk project nyata. Pilih sesuai kebutuhan, seperti memilih antara menyewa alat atau memiliki bengkel sendiri.

## Soal latihan & jawaban

**1. Perintah apa untuk membuat project Vite baru dengan template vanilla?**
`npm create vite@latest nama-project -- --template vanilla`

**2. Sebutkan minimal 2 kelebihan setup npm + Vite dibanding CDN!**
- Hot reload (perubahan langsung terlihat tanpa refresh manual)
- Bisa kustomisasi variable SCSS Bootstrap
- Tree-shaking (hanya mengirim kode yang dipakai)

**3. Apa fungsi `@popperjs/core` dalam instalasi Bootstrap?**
Popper.js adalah library positioning yang digunakan Bootstrap untuk komponen seperti tooltip, dropdown, dan popover agar muncul di posisi yang benar.
