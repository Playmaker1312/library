# 29. Setup Sass + Bootstrap

## Penjelasan

Seperti tukang kayu yang butuh **workshop (Vite)** untuk mengolah **kayu mentah (Sass)** sebelum digunakan membangun rumah, kita perlu menyiapkan lingkungan kerja agar Bootstrap + Sass bisa berjalan bersama. Vite akan menjadi "gudang alat" yang mengompilasi SCSS menjadi CSS otomatis setiap kali kita menyimpan perubahan.

## Fungsi

- Mengaktifkan **Sass compiler** di dalam proyek Bootstrap
- Membuat **entry point** (`main.scss`) sebagai gerbang utama custom styling
- Memisahkan **struktur folder** agar rapi — seperti lemari arsip biru rumah
- Hot-reload saat mengedit SCSS, seperti tukang kayu yang langsung melihat hasil potongannya

## Cara Pengimplementasian

```bash
# 1. Buat proyek Vite baru
npm create vite@latest proyek-bootstrap -- --template vanilla

cd proyek-bootstrap

# 2. Install Bootstrap dan Sass
npm install bootstrap
npm install -D sass

# 3. Buat folder scss/
mkdir src/scss
```

```javascript
// vite.config.js
// Konfigurasi Vite — seperti mengatur tata letak workshop tukang kayu
import { defineConfig } from 'vite'

export default defineConfig({
  css: {
    preprocessorOptions: {
      scss: {
        // Beri tahu Vite di mana mencari file SCSS via node_modules
        // agar @import "bootstrap/scss/..." bisa ditemukan
        loadPaths: ['./node_modules']
      }
    }
  }
})
```

```scss
// src/scss/main.scss
// Entry point — gerbang utama rumah, semua aliran SCSS masuk lewat sini

// 1. Import Bootstrap dulu
@import "bootstrap/scss/bootstrap";

// 2. Tambahkan custom styles di bawah
// (akan diisi di materi selanjutnya)
```

```html
<!-- index.html -->
<!-- Hubungkan hasil kompilasi CSS -->
<link rel="stylesheet" href="/src/scss/main.scss">
```

```bash
# 4. Jalankan dev server — workshop mulai bekerja
npm run dev
```

## Analogi

| Komponen | Analogi Rumah |
|---|---|
| Vite | Workshop tukang kayu dengan mesin serba otomatis |
| Sass | Tukang kayu yang bisa membentuk ulang material |
| `main.scss` | Gerbang utama / pintu depan rumah |
| `node_modules` | Gudang material di pinggir workshop |
| `vite.config.js` | Denah / tata letak mesin di workshop |

## Dipakai untuk apa

- **Setiap proyek Bootstrap kustom** wajib melewati setup ini
- Proyek yang butuh **theme kustom** (brand color, spacing, dll)
- Membangun **design system** internal tim — seperti membuat cetakan rumah massal

## Kesalahan umum yang sering terjadi

1. **Lupa install `sass` sebagai devDependency** — SCSS tidak akan dikompilasi, muncul error `Cannot find module 'sass'`
2. **Tidak mengatur `loadPaths`** — Vite tidak bisa menemukan file Bootstrap di `node_modules`
3. **Menghubungkan file `.scss` langsung di HTML tanpa Vite** — browser tidak paham SCSS
4. **Menimpa file Bootstrap asli di `node_modules`** — jangan! Buat file terpisah di `src/scss/`

## Koneksi dengan materi sebelumnya

- **Level 3 (Komponen Lanjutan)**: Semua komponen itu "jadi" — sekarang kita belajar membuat versi kustom dari komponen tersebut
- **Dasar Vite**: Seharusnya sudah familiar dengan `npm create vite` dari materi sebelumnya
- **CSS Custom Properties vs Sass**: CSS variables (dipelajari di Level 3) bersifat runtime, Sass variables bersifat compile-time — dua alat berbeda di workshop yang sama

## Soal Latihan & Jawaban

### Soal 1

Apa fungsi `loadPaths: ['./node_modules']` di `vite.config.js`?

<details>
<summary>Jawaban</summary>

Memberi tahu Vite agar bisa meresolve `@import "bootstrap/scss/..."` tanpa menulis path panjang seperti `../../node_modules/bootstrap/scss/...`. Ibarat memberi tahu tukang kayu di mana gudang material berada.
</details>

### Soal 2

Buat perintah bash untuk membuat proyek Vite baru bernama `toko-rumah` dengan template vanilla, lalu install Bootstrap dan Sass.

<details>
<summary>Jawaban</summary>

```bash
npm create vite@latest toko-rumah -- --template vanilla
cd toko-rumah
npm install bootstrap
npm install -D sass
mkdir src/scss
```
</details>

### Soal 3

Apa yang terjadi jika kita lupa menjalankan `npm install -D sass`?

<details>
<summary>Jawaban</summary>

Vite tidak akan bisa mengompilasi file `.scss`. Saat browser di-refresh, akan muncul error di console/terminal karena tidak ada Sass compiler yang terpasang. Ibarat workshop tukang kayu tidak memiliki gergaji.
</details>
