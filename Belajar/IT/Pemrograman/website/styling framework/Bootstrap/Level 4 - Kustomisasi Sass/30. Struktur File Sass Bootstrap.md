# 30. Struktur File Sass Bootstrap

## Penjelasan

Bootstrap memiliki **lemari arsip biru rumah** yang sangat terorganisir di dalam `node_modules/bootstrap/scss/`. Setiap laci (folder) dan map (file) memiliki fungsi spesifik — seperti arsitek yang menata cetak biru rumah per bagian: fondasi, rangka, atap, hingga dekorasi. Urutan import sangat penting karena setiap file bergantung pada file sebelumnya.

## Fungsi

- Memahami **urutan hirarki** Sass Bootstrap agar override berjalan mulus
- Mampu **import selektif** — hanya mengambil komponen yang dipakai (menghemat ukuran file CSS)
- Mengetahui apa itu **functions, variables, mixins, components** sebagai "lapisan" rumah

## Cara Pengimplementasian

### Struktur folder `node_modules/bootstrap/scss/`

```
scss/
├── _functions.scss         # 1. Alat ukur & kalkulasi (seperti meteran tukang kayu)
├── _variables.scss         # 2. Cetakan/resep cat tembok (spacer, warna, font)
├── _variables-dark.scss    #    Cetakan versi gelap (dark mode)
├── _maps.scss              #    Peta/tabel referensi warna & utilitas
├── _mixins.scss            # 3. Pola potong kayu yang bisa dipakai ulang
├── mixins/                 #    Kumpulan pola khusus per komponen
├── _utilities.scss         # 4. Alat multifungsi (Utility API)
├── vendors/                #    Plugin pihak ketiga
├── _root.scss              #    CSS Custom Properties
├── _reboot.scss            #    Reset CSS — fondasi dasar rumah
├── _type.scss              #    Tipografi — jenis dan ukuran pintu/jendela
├── _images.scss            #    Gaya untuk gambar
├── _tables.scss            #    Gaya tabel
├── _forms.scss             #    Gaya form
├── _buttons.scss           #    Tombol — gagang pintu
├── _card.scss              #    Kartu — bingkai foto di dinding
├── _navbar.scss            #    Navigasi — papan petunjuk arah
├── ... (komponen lain)
├── _helpers.scss           #    Helper classes
├── _spinners.scss          #    Animasi loading
└── bootstrap.scss          # ★ File utama yang mengimpor semua di atas
```

### Urutan import yang benar (wajib!)

```scss
// main.scss — gerbang utama, urutan TIDAK BOLEH salah

// ============================================
// LAPISAN 1: Fondasi (wajib, urutannya mutlak)
// ============================================

// 1. Functions — HARUS pertama (alat ukur)
@import "bootstrap/scss/functions";

// 2. Variables — HARUS kedua (cetakan)
//     (setelah ini kita bisa override variabel)
@import "bootstrap/scss/variables";

// 3. Variables Dark — setelah variables utama
@import "bootstrap/scss/variables-dark";

// 4. Maps — peta warna & spacing
@import "bootstrap/scss/maps";

// ============================================
// LAPISAN 2: Kerangka (opsional, urutan penting)
// ============================================

// 5. Mixins — HARUS setelah variables
@import "bootstrap/scss/mixins";

// 6. Root — CSS custom properties
@import "bootstrap/scss/root";

// ============================================
// LAPISAN 3: Fondasi visual (opsional)
// ============================================

// 7. Reboot — reset CSS
@import "bootstrap/scss/reboot";

// 8. Typography — tipografi
@import "bootstrap/scss/type";

// ============================================
// LAPISAN 4: Komponen (pilih sesuai kebutuhan)
// ============================================

@import "bootstrap/scss/buttons";
@import "bootstrap/scss/card";
@import "bootstrap/scss/navbar";
@import "bootstrap/scss/forms";
@import "bootstrap/scss/grid";

// ============================================
// LAPISAN 5: Utilities & Helpers
// ============================================

@import "bootstrap/scss/utilities";
@import "bootstrap/scss/helpers";
```

### Import selektif — hanya ambil yang dipakai

```scss
// Daripada mengimpor semua 40+ file Bootstrap,
// kita bisa pilih komponen yang benar-benar dipakai.
// Ibarat tukang kayu yang hanya membawa palu dan obeng, bukan seluruh gudang.

// Fondasi wajib:
@import "bootstrap/scss/functions";
@import "bootstrap/scss/variables";
@import "bootstrap/scss/variables-dark";
@import "bootstrap/scss/maps";
@import "bootstrap/scss/mixins";
@import "bootstrap/scss/root";

// Komponen yang dipakai saja:
@import "bootstrap/scss/reboot";
@import "bootstrap/scss/type";
@import "bootstrap/scss/grid";
@import "bootstrap/scss/buttons";
@import "bootstrap/scss/card";
@import "bootstrap/scss/forms";
@import "bootstrap/scss/navbar";

// Utility API
@import "bootstrap/scss/utilities";

// Helper
@import "bootstrap/scss/helpers";
```

## Analogi

| File/Folder | Analogi Lemari Arsip Rumah |
|---|---|
| `functions.scss` | Meteran, busur, alat ukur tukang kayu |
| `variables.scss` | Cetakan/resep cat tembok — warna, ukuran, jarak |
| `mixins/` | Kumpulan pola potong kayu siap pakai |
| `reboot.scss` | Fondasi beton rumah — dasar yang meratakan segalanya |
| `components/` | Gambar detail jendela, pintu, lemari per ruangan |
| `utilities.scss` | Kotak alat multifungsi tambahan |
| `bootstrap.scss` | Daftar isi lemari arsip — index semua map |
| Urutan import | Hirarki lemari arsip — laci atas (fondasi) ke laci bawah (detail) |

## Dipakai untuk apa

- **Override variabel** tanpa error — hanya bisa override VARIABEL setelah `variables` diimpor dan SEBELUM komponen lain diimpor
- **Menghemat ukuran file CSS** — import hanya komponen yang terpakai (bisa hemat 60-70% ukuran)
- **Memahami error kompilasi** — error "undefined variable" biasanya karena urutan import salah

## Kesalahan umum yang sering terjadi

1. **Mengimpor `bootstrap/scss/bootstrap` langsung** — tidak bisa override variabel karena semua sudah terlanjur dikompilasi
2. **Urutan import salah** — misal `mixins` sebelum `variables` → error `Undefined variable`
3. **Override variabel SETELAH komponen** — override tidak akan berpengaruh karena komponen sudah pakai nilai lama
4. **Import semua file tapi hanya pakai 5 komponen** — boros ukuran CSS (file bisa 250KB+ padahal perlu 80KB)
5. **Lupa import `maps`** — Utility API dan beberapa mixin gagal karena butuh peta warna

## Koneksi dengan materi sebelumnya

- **Level 1-3**: Kita pakai `bootstrap.min.css` utuh — sekarang kita bongkar isinya dan pilih komponen sendiri
- **Level 1 (Grid)**: `grid.scss` ada di lapisan komponen — sekarang kita tahu asal-usul class `.container` dan `.row`
- **Level 2 (Utilities)**: `utilities.scss` isinya class seperti `.mt-3`, `.d-flex` — kita akan kustomisasi di materi 33

## Soal Latihan & Jawaban

### Soal 1

Apa yang terjadi jika kita mengimpor `bootstrap/scss/mixins` sebelum `bootstrap/scss/variables`?

<details>
<summary>Jawaban</summary>

Error kompilasi SCSS: `Undefined variable "$spacer"` (atau variabel lainnya). Mixins menggunakan variabel dari `_variables.scss`, jadi ia harus diimpor setelahnya. Ibarat mencoba memotong kayu dengan pola yang belum diukur.
</details>

### Soal 2

Sebutkan 3 file "fondasi wajib" yang HARUS diimpor pertama kali (dalam urutan yang benar) saat melakukan import selektif Bootstrap.

<details>
<summary>Jawaban</summary>

1. `functions` — alat ukur
2. `variables` — cetakan/resep
3. `variables-dark` — cetakan versi gelap

Atau bisa juga: functions → variables → variables-dark → maps → mixins → root.
</details>

### Soal 3

Mengapa kita tidak bisa mengubah nilai `$primary` jika kita mengimpor `bootstrap/scss/bootstrap` secara langsung (satu baris)?

<details>
<summary>Jawaban</summary>

Karena `@import "bootstrap/scss/bootstrap"` mengimpor SEMUA file sekaligus — variabel sudah dipakai oleh komponen sebelum kita sempat menimpa nilainya. Kita harus import `variables` dulu, override, baru import komponen. Ibarat mencoba mengganti cetakan cat setelah tembok sudah dicat.
</details>
