# 33. Utility API

## Penjelasan

Utility API adalah **alat multifungsi tambahan** di workshop Bootstrap — seperti obeng dengan 20 mata yang bisa diganti. Daripada membuat class utility satu per satu (`.gap-1`, `.gap-2`, `.rounded-custom`, dll), Utility API memungkinkan kita **mendefinisikan template** dan Bootstrap **mengenerate** semua kelas secara otomatis.

## Fungsi

- **Generasi utility class otomatis** — tulis sekali, dapat puluhan class
- **Konsistensi** — utility baru tetap mengikuti scale, breakpoint, dan sistem Bootstrap
- **Efisiensi** — tidak perlu menulis `@each` loop manual setiap kali mau bikin utility
- **Ekstensibilitas** — bisa menambah, mengubah, atau menonaktifkan utility Bootstrap

## Cara Pengimplementasian

### Struktur Utility API

```scss
// Setiap utility dalam API memiliki struktur:

// $utilities: map-merge($utilities, (
//   "nama-utility": (
//     property: css-property,
//     values: (key1: value1, key2: value2),
//     class: prefix-class,    // opsional, default = nama-utility
//     responsive: true,        // opsional, generate .-sm, .-md, dll
//     state: (hover, focus),  // opsional, generate .-hover, .-focus
//     print: true,             // opsional, versi print
//     rtl: true,               // opsional, right-to-left support
//     local-vars: (...)        // opsional, CSS custom properties
//   )
// ));
```

### Persyaratan: file `_utilities.scss` harus diimpor

```scss
// main.scss — Utility API ada di sini
@import "bootstrap/scss/utilities";

// Utility API diproses OLEH Bootstrap lewat file ini,
// jadi semua map-merge harus dilakukan SEBELUM baris ini
// atau gunakan file terpisah yang diimpor sebelumnya.
```

### Cara 1: Map-merge langsung di main.scss (SEBELUM import utilities)

```scss
// main.scss
@import "bootstrap/scss/functions";
@import "bootstrap/scss/variables";
@import "bootstrap/scss/variables-dark";
@import "bootstrap/scss/maps";
@import "bootstrap/scss/mixins";
@import "bootstrap/scss/root";
@import "bootstrap/scss/reboot";
@import "bootstrap/scss/type";
@import "bootstrap/scss/grid";
@import "bootstrap/scss/buttons";
@import "bootstrap/scss/card";
@import "bootstrap/scss/navbar";
@import "bootstrap/scss/forms";

// ============================================
// CUSTOM UTILITY API — Tulis SEBELUM import utilities
// ============================================

// --- 1. Custom Gap — jarak antar bata ---
// Bootstrap punya gap-1 sampai gap-5 (0.25rem - 3rem).
// Kita tambah gap-6 sampai gap-10.

$utilities: map-merge($utilities, (
  "gap": (
    property: gap,
    class: gap,
    values: map-merge(
      map-get($utilities, "gap", "values"),
      (
        6: $spacer * 4,
        7: $spacer * 5.5,
        8: $spacer * 7,
        9: $spacer * 9,
        10: $spacer * 12,
      )
    )
  )
));

// --- 2. Custom Rounded — variasi sudut tumpuan tambahan ---
// Bootstrap punya rounded, rounded-1, rounded-2, rounded-3, rounded-circle, rounded-pill
// Kita tambah rounded-xs dan rounded-xl.

$utilities: map-merge($utilities, (
  "rounded-xs": (
    property: border-radius,
    class: rounded,
    values: (
      xs: 2px,
    )
  ),
  "rounded-xl": (
    property: border-radius,
    class: rounded,
    values: (
      xl: 20px,
    )
  )
));

// --- 3. Custom Cursor — bentuk kursor mouse ---
// Bootstrap tidak punya utility cursor. Kita buat sendiri.

$utilities: map-merge($utilities, (
  "cursor": (
    property: cursor,
    class: cursor,
    values: (
      pointer: pointer,
      grab: grab,
      grabbing: grabbing,
      zoom-in: zoom-in,
      zoom-out: zoom-out,
      not-allowed: not-allowed,
      crosshair: crosshair,
      help: help,
    )
  )
));

// --- 4. Custom Opacity — tingkat transparansi lebih detail ---
$utilities: map-merge($utilities, (
  "opacity": (
    property: opacity,
    class: opacity,
    values: (
      0: 0,
      25: 0.25,
      50: 0.5,
      65: 0.65,
      75: 0.75,
      80: 0.8,
      90: 0.9,
      100: 1,
    )
  )
));

// --- 5. Custom Text Gradient — gradien pada teks ---
$utilities: map-merge($utilities, (
  "text-gradient": (
    property: background,
    class: text-gradient,
    values: (
      primary: linear-gradient(135deg, $primary, darken($primary, 15%)),
      secondary: linear-gradient(135deg, $secondary, darken($secondary, 15%)),
      sunset: linear-gradient(135deg, #FDCB6E, #E17055),
      ocean: linear-gradient(135deg, #74B9FF, #6C5CE7),
    ),
    local-vars: (
      "bg-clip": text,
      "text-fill-color": transparent,
    )
  )
));

// --- 6. Custom Width & Height — ukuran khusus ---
$utilities: map-merge($utilities, (
  "width-custom": (
    property: width,
    class: w,
    values: (
      10: 10%,
      20: 20%,
      30: 30%,
      40: 40%,
      60: 60%,
      70: 70%,
      80: 80%,
      90: 90%,
    )
  ),
  "height-custom": (
    property: height,
    class: h,
    values: (
      10: 10%,
      20: 20%,
      30: 30%,
      40: 40%,
      60: 60%,
      70: 70%,
      80: 80%,
      90: 90%,
    )
  )
));

// ============================================
// TERAKHIR: Import utilities — API diproses di sini
// ============================================
@import "bootstrap/scss/utilities";

// ============================================
// LAPISAN KUSTOM KOMPONEN
// ============================================
// (komponen dari materi 32)
```

## Analogi

| Komponen Utility API | Analogi Membangun Rumah |
|---|---|
| `$utilities` map | Kotak alat multifungsi — obeng dengan banyak mata |
| `property` | Fungsi alat — "memotong", "mengencangkan" |
| `class` | Label pada laci alat — "obeng", "palu" |
| `values` | Set ukuran mata obeng — Philips #1, #2, Flathead 3mm |
| `responsive: true` | Versi alat yang bisa dipakai di ruangan berbeda |
| `state: hover` | Alat yang "bereaksi" saat disentuh |
| `map-merge` | Menambah alat baru ke dalam kotak tanpa membuang yang lama |
| `local-vars` | Setelan khusus pada alat — "obeng ini dilapisi karet" |

## Dipakai untuk apa

- **Menambah utility yang tidak ada** — cursor, text gradient, custom opacity
- **Memperpanjang skala utility yang ada** — gap, rounded, width, height
- **Mempermudah tim** — desainer cukup pakai class `.cursor-grab` tanpa harus nulis CSS manual
- **Konsistensi lintas proyek** — utility API bisa diexport sebagai package terpisah
- **Mengurangi CSS berulang** — daripada 10 komponen punya `cursor: pointer` manual, cukup `.cursor-pointer`

## Kesalahan umum yang sering terjadi

1. **Map-merge SETELAH `@import "utilities"`** — utility tidak akan tergenerate karena API sudah diproses
2. **Salah syntax map** — lupa koma di akhir entry, atau kurung kurawal tidak seimbang → error kompilasi
3. **Menimpa utility yang sudah ada** — membuat utility "gap" dari nol tanpa `map-merge` akan menghapus gap Bootstrap default
4. **Responsive tanpa breakpoint** — set `responsive: true` tapi lupa bahwa class jadi `.gap-6-sm`, `.gap-6-md`, dll — ukuran file membengkak
5. **Typo di properti CSS** — misal `property: color` bukan `background` untuk text gradient — utility tidak bekerja
6. **Lupa bahwa utility API memproses map `$utilities`** — jika kita definisikan di file terpisah, pastikan file itu diimpor SEBELUM `@import "bootstrap/scss/utilities"`

## Koneksi dengan materi sebelumnya

- **Materi 30 (Struktur File)**: `_utilities.scss` ada di lapisan terakhir — Utility API adalah "puncak" dari sistem Bootstrap
- **Materi 31 (Override Variables)**: Utility API mengonsumsi variabel seperti `$spacer` dan `$theme-colors`
- **Materi 32 (Custom Component)**: Utility API adalah alternatif dari komponen kustom — untuk class kecil yang dipakai berulang

## Soal Latihan & Jawaban

### Soal 1

Apa yang terjadi jika kita menulis `$utilities: map-merge(...)` SETELAH baris `@import "bootstrap/scss/utilities";`?

<details>
<summary>Jawaban</summary>

Utility tidak akan tergenerate. File `_utilities.scss` Bootstrap memproses map `$utilities` dan langsung mengeluarkan CSS saat itu juga. Setelah diproses, menambah map tidak menghasilkan class baru. Ibarat menambahkan mata obeng ke kotak alat setelah obengnya sudah dipakai.
</details>

### Soal 2

Buat Utility API untuk custom **text-decoration** dengan nilai: none, underline, line-through. Beri class prefix `td` (contoh: `.td-none`, `.td-underline`).

<details>
<summary>Jawaban</summary>

```scss
$utilities: map-merge($utilities, (
  "text-decoration": (
    property: text-decoration,
    class: td,
    values: (
      none: none,
      underline: underline,
      line-through: line-through,
    )
  )
));
```
</details>

### Soal 3

Apa fungsi `responsive: true` dalam Utility API? Sebutkan kelebihan dan kekurangannya!

<details>
<summary>Jawaban</summary>

`responsive: true` membuat Bootstrap menggenerate versi utility untuk setiap breakpoint (sm, md, lg, xl, xxl).

Contoh: `.cursor-grab-sm`, `.cursor-grab-md`, `.cursor-grab-lg`

**Kelebihan:** Utility bisa berubah di ukuran layar berbeda — sangat fleksibel.

**Kekurangan:** Ukuran file CSS membengkak (setiap utility × 6 breakpoint). Gunakan hanya jika benar-benar dibutuhkan.
</details>
