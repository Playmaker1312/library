# 31. Override Bootstrap Variables

## Penjelasan

Variabel Bootstrap adalah **cetakan/resep cat tembok** rumah. Warna biru default Bootstrap, ukuran font, jarak antar ruangan (spacer), sudut tumpuan (border-radius), bayangan — semua diatur oleh variabel. Seperti mencampur cat tembok sendiri sebelum mengecat, kita bisa mengubah nilai variabel ini sebelum komponen Bootstrap menggunakannya.

## Fungsi

- **Brand identity** — menyesuaikan warna dengan logo perusahaan (warna primer, sekunder)
- **Konsistensi desain** — mengubah satu variabel berdampak ke seluruh komponen
- **Memperpanjang skala** — spacer default hanya sampai `5` (3rem), bisa diperpanjang sampai `10` atau lebih
- **Mengubah karakter visual** — dari Bootstrap yang "rounded" menjadi "sharp" (border-radius 0)

## Cara Pengimplementasian

### Struktur file yang benar

```scss
// src/scss/main.scss

// LAPISAN 1: Fondasi Bootstrap
@import "bootstrap/scss/functions";

// LAPISAN 2: Variables Bootstrap (nilai default)
@import "bootstrap/scss/variables";
@import "bootstrap/scss/variables-dark";

// ★ LAPISAN OVERRIDE: Tulis override VARIABEL DISINI ★
// (setelah variables Bootstrap, SEBELUM komponen)

// 1. Brand Colors
$primary:       #6C5CE7;      // Ungu — warna brand
$secondary:     #00CEC9;      // Teal — aksen brand
$success:       #00B894;      // Hijau segar
$info:          #74B9FF;      // Biru muda
$warning:       #FDCB6E;      // Kuning hangat
$danger:        #E17055;      // Merah bata
$light:         #F8F9FA;      // Putih gading
$dark:          #2D3436;      // Abu-abu pekat

// 2. Typography — font keluarga & ukuran
$font-family-sans-serif:    'Inter', 'Segoe UI', system-ui, sans-serif;
$font-family-monospace:     'JetBrains Mono', 'Fira Code', monospace;
$font-size-base:            1rem;       // 16px — ukuran font dasar
$font-size-lg:              $font-size-base * 1.25;  // 20px
$font-size-sm:              $font-size-base * .875;  // 14px
$headings-font-family:      'Poppins', sans-serif;
$headings-font-weight:      700;

// 3. Spacing — perpanjang skala spacer
$spacer: 1rem;  // default 16px

// $spacer * 1 = .p-1 = 0.25rem (4px)
// $spacer * 2 = .p-2 = 0.5rem  (8px)
// ... default hanya sampai $spacer * 5 = 3rem (48px)
//
// Perpanjang dengan map custom:
$custom-spacers: (
  6: $spacer * 4,    // 4rem  (64px)
  7: $spacer * 5.5,  // 5.5rem (88px)
  8: $spacer * 7,    // 7rem  (112px)
  9: $spacer * 9,    // 9rem  (144px)
  10: $spacer * 12,  // 12rem (192px)
);

// Gabungkan dengan spacer Bootstrap
$spacers: map-merge($spacers, $custom-spacers);

// 4. Border Radius — sudut tumpuan
$border-radius:              8px;
$border-radius-sm:           4px;
$border-radius-lg:           16px;
$border-radius-pill:         50rem;

// 5. Shadows — bayangan
$box-shadow:                 0 2px 8px rgba(0, 0, 0, 0.08);
$box-shadow-sm:              0 1px 3px rgba(0, 0, 0, 0.05);
$box-shadow-lg:              0 8px 32px rgba(0, 0, 0, 0.12);

// 6. Component-specific variables

// Navbar
$navbar-padding-y:           1rem;
$navbar-dark-color:          rgba(255, 255, 255, 0.9);
$navbar-dark-hover-color:    $primary;

// Button
$btn-padding-y:              0.5rem;
$btn-padding-x:              1.5rem;
$btn-border-radius:          $border-radius;
$btn-font-weight:            600;

// Card
$card-border-radius:         $border-radius-lg;
$card-box-shadow:            $box-shadow;
$card-border-color:          transparent;
$card-cap-bg:                transparent;

// Form
$input-border-radius:        $border-radius;
$input-padding-y:            0.625rem;
$input-focus-border-color:   $primary;
$input-focus-box-shadow:     0 0 0 3px rgba($primary, 0.25);

// LAPISAN 3: Import komponen SETELAH override
@import "bootstrap/scss/maps";
@import "bootstrap/scss/mixins";
@import "bootstrap/scss/root";
@import "bootstrap/scss/reboot";
@import "bootstrap/scss/type";
@import "bootstrap/scss/grid";
@import "bootstrap/scss/buttons";
@import "bootstrap/scss/card";
@import "bootstrap/scss/navbar";
@import "bootstrap/scss/forms";
@import "bootstrap/scss/utilities";
```

### Untuk menggunakan font dari Google Fonts

```html
<!-- index.html — tambahkan di <head> -->
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&family=Poppins:wght@600;700&display=swap" rel="stylesheet">
```

## Analogi

| Variabel | Analogi Membangun Rumah |
|---|---|
| `$primary` | Cat warna utama tembok rumah |
| `$font-family-base` | Jenis kayu untuk semua pintu |
| `$spacer` | Jarak antar bata (modul dasar) |
| `$border-radius` | Tingkat ketumpulan sudut meja |
| `$box-shadow` | Intensitas bayangan atap |
| `$navbar-padding-y` | Tebal bantalan papan nama jalan |
| `$btn-border-radius` | Bentuk gagang pintu (tumpul/tajam) |
| `$card-border-color` | Warna bingkai foto di dinding |

## Dipakai untuk apa

- **Membangun design system** perusahaan dengan warna brand yang konsisten
- **Membuat tema dark/light** dengan kumpulan variabel berbeda
- **Mengubah karakter visual** Bootstrap secara drastis (misal dari rounded ke square, dari biru ke ungu)
- **Menambah utility spacing** untuk layout yang butuh jarak lebih besar

## Kesalahan umum yang sering terjadi

1. **Override di tempat salah** — menulis `$primary` SEBELUM `@import "bootstrap/scss/variables"` → tidak akan error, tapi juga tidak berefek (variabel ditimpa lagi oleh default Bootstrap)
2. **Override SETELAH komponen diimport** — komponen sudah pakai nilai lama, override tidak berpengaruh
3. **Lupa merge map** — menulis `$spacers: (6: 4rem)` akan MENGHAPUS semua spacer default 1-5, harus pakai `map-merge`
4. **Tidak konsisten** — mengubah `$primary` tapi lupa mengubah `$input-focus-border-color` dan `$navbar-dark-hover-color` sehingga warna fokus form masih biru Bootstrap
5. **Font tidak muncul** — sudah set `$font-family-sans-serif` tapi lupa load Google Fonts di HTML

## Koneksi dengan materi sebelumnya

- **Materi 30 (Struktur File)**: Override hanya mungkin karena kita memahami urutan import yang benar
- **Level 2 (Spacing & Typography)**: Class `.mt-3`, `.fs-4` dulu cuma 5 level — sekarang bisa lebih dengan custom spacers
- **Level 3 (Komponen)**: Navbar, button, card, form dulu hanya bisa dikustom lewat CSS biasa — sekarang langsung dari "pabriknya"
- **CSS Custom Properties (Level 3)**: Sass variables dikompilasi jadi nilai tetap, CSS variables bisa berubah runtime — dua alat berbeda untuk kebutuhan berbeda

## Soal Latihan & Jawaban

### Soal 1

Apa yang terjadi jika kita menulis `$primary: #E17055;` SEBELUM baris `@import "bootstrap/scss/variables";`?

<details>
<summary>Jawaban</summary>

Tidak terjadi error, tapi override tidak berpengaruh. Nilai `$primary` yang kita set akan ditimpa oleh nilai default Bootstrap saat `_variables.scss` diimpor. Ibarat mencampur cat, lalu menuangnya ke ember yang sudah berisi cat lain — hasilnya tetap sesuai isi ember.
</details>

### Soal 2

Diketahui `$spacer: 1rem`. Jika kita ingin menambah kelas `.mt-8` dengan nilai `7rem`, bagaimana cara menulisnya?

<details>
<summary>Jawaban</summary>

```scss
$custom-spacers: (
  8: $spacer * 7,  // 7rem
);
$spacers: map-merge($spacers, $custom-spacers);
```
</details>

### Soal 3

Sebutkan 3 variabel Bootstrap yang bisa diubah untuk mengkustomisasi tampilan tombol (button)!

<details>
<summary>Jawaban</summary>

- `$btn-padding-y` — padding vertikal tombol
- `$btn-padding-x` — padding horizontal tombol
- `$btn-border-radius` — sudut tombol
- `$btn-font-weight` — ketebalan font tombol
- `$btn-font-size` — ukuran font tombol
</details>
