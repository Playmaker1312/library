# Tailwind v4 - Migrasi dari v3

## Penjelasan

- Tailwind v4 membawa perubahan arsitektur besar. Jika v3 menggunakan file `tailwind.config.js` terpisah sebagai pusat konfigurasi, v4 menggantinya dengan direktif `@theme` di file CSS utama.
- Proses instalasi berubah: cukup `npm install tailwindcss @tailwindcss/vite` lalu pasang plugin `@tailwindcss/vite` di `vite.config.js`. Tidak perlu lagi `tailwind.config.js` dan `postcss.config.js` untuk project Vite.
- Import dilakukan dengan `@import "tailwindcss"` langsung di file CSS, bukan lagi `@tailwind base`, `@tailwind components`, `@tailwind utilities`.
- Dark mode kini menggunakan `@variant dark { ... }` di CSS, bukan class strategy di config.
- Color space default berubah ke oklch (`oklch(...)`) yang memberikan warna lebih akurat secara perceptual dibanding RGB/heksadesimal.
- `@apply` kini bisa digunakan dalam `@layer` dan lebih stabil.
- Banyak utility baru seperti `field-sizing`, `@container`, `text-balance`, dan `text-pretty`.

## Fungsi

Memodernisasi cara kerja Tailwind agar lebih terintegrasi dengan CSS native, mengurangi boilerplate file config, dan memanfaatkan fitur CSS terbaru.

## Cara Pengimplementasian / Kode

**Perbandingan config v3 vs v4:**

v3 (`tailwind.config.js`):

```js
module.exports = {
  content: ["./index.html", "./src/**/*.{js,ts,jsx}"],
  darkMode: "class",
  theme: {
    extend: {
      colors: {
        primary: "#1d4ed8",
      },
      fontFamily: {
        heading: ["Poppins", "sans-serif"],
      },
    },
  },
  plugins: [],
};
```

v4 (`style.css`):

```css
@import "tailwindcss";

@theme {
  --color-primary: #1d4ed8;
  --font-family-heading: "Poppins", sans-serif;
}

@variant dark {
  --color-primary: #60a5fa;
}
```

**vite.config.js v4:**

```js
import { defineConfig } from "vite";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({
  plugins: [tailwindcss()],
});
```

**Style CSS v4 lengkap:**

```css
@import "tailwindcss";

@theme {
  --color-brand: oklch(0.55 0.2 260);
  --color-brand-light: oklch(0.7 0.15 260);
  --font-family-sans: "Inter", sans-serif;
  --spacing-page: 1.5rem;
  --breakpoint-xs: 30rem;
}

@variant dark {
  --color-brand: oklch(0.75 0.18 260);
  --color-brand-light: oklch(0.85 0.1 260);
}

@layer base {
  body {
    font-family: var(--font-family-sans);
  }
}
```

## Analogi

v3 adalah seperti rumah dengan buku panduan konstruksi terpisah yang tebal. Setiap kali ingin mengganti warna cat, Anda harus membuka buku itu, mencari halamannya, menulis ulang, lalu kembali ke rumah. v4 adalah rumah dengan instruksi langsung ditulis di dinding: cat ulang saja area yang terlihat, semua perubahan langsung kelihatan tanpa harus bolak-balik buku.

## Dipakai untuk Apa

- Project baru yang ingin memanfaatkan kemudahan Tailwind v4.
- Migrasi project v3 ke v4 untuk mendapatkan performa build lebih cepat dan fitur CSS native.
- Tim yang ingin mengurangi kompleksitas file konfigurasi.

## Kesalahan Umum yang Sering Terjadi

- Masih menjalankan `npx tailwindcss init` di v4 (tidak diperlukan).
- Mengimpor file CSS setelah `@import "tailwindcss"` tanpa menggunakan `@layer`.
- Lupa memasang `@tailwindcss/vite` plugin di `vite.config.js`, sehingga utility tidak ter-generate.
- Menggunakan `@apply` di luar `@layer` yang menyebabkan warning.
- Mengharapkan class seperti `dark:` berfungsi tanpa mendefinisikan `@variant dark`.
- Menggunakan `@theme` dengan nama kustom yang tidak mengikuti konvensi `--category-name`.

## Koneksi dengan Materi Sebelumnya

Level 5 membahas best practice Tailwind: organisasi komponen, custom utility, responsive design. v4 adalah cara baru yang lebih modern dalam menerapkan semua best practice tersebut. Konsep utility-first tetap sama, tapi implementasinya lebih bersih dengan `@theme` menggantikan `tailwind.config.js` dan `@variant` untuk dark mode. Semua pola dari Level 5 tetap relevan, hanya cara konfigurasinya yang berubah.

## Soal Latihan

Migrasikan konfigurasi Tailwind v3 berikut ke format v4:

```js
// tailwind.config.js v3
module.exports = {
  content: ["./src/**/*.{html,js}"],
  darkMode: "class",
  theme: {
    extend: {
      colors: {
        primary: "#3b82f6",
        danger: "#ef4444",
      },
      fontFamily: {
        display: ["Playfair Display", "serif"],
      },
      spacing: {
        18: "4.5rem",
      },
    },
  },
};
```

Buat file `style.css` versi v4-nya.

```css
@import "tailwindcss";

@theme {
  --color-primary: #3b82f6;
  --color-danger: #ef4444;
  --font-family-display: "Playfair Display", serif;
  --spacing-18: 4.5rem;

@variant dark {
  --color-primary: #93c5fd;
  --color-danger: #fca5a5;
}
```

Penjelasan:
- Semua `theme.extend` di v3 langsung ditulis ke dalam blok `@theme` di v4.
- `darkMode: "class"` diganti dengan `@variant dark { ... }`.
- Nama kustom menggunakan prefix `--color-`, `--font-family-`, `--spacing-` sesuai konvensi v4.
- Tidak perlu `content` karena v4 otomatis mendeteksi file berdasarkan konteks project.
