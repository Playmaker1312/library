# Plugin Forms

## Penjelasan

- `@tailwindcss/forms` adalah plugin resmi Tailwind yang melakukan reset style bawaan browser pada elemen form (input, select, textarea, checkbox, radio).
- Tanpa plugin ini, elemen form memiliki style berbeda di tiap browser. Plugin forms menyamakan tampilan dasar agar konsisten lintas browser.
- Plugin ini mengubah default focus ring, border, padding, dan ukuran elemen form agar sesuai dengan design system Tailwind.
- Tidak perlu mengubah HTML -- cukup instal plugin dan semua elemen form otomatis mendapat style baru.
- Cocok untuk: `<input>`, `<select>`, `<textarea>`, `<checkbox>`, `<radio>`, `<select multiple>`.
- Kamu tetap bisa meng-override style dengan utility Tailwind biasa seperti `rounded-lg`, `border-gray-300`, `focus:ring-blue-500`.
- Plugin forms bisa dikustomisasi melalui `theme.extend` untuk mengubah border, padding, dan ring default.

## Fungsi

Mereset dan menyeragamkan tampilan semua elemen form lintas browser, memberikan baseline yang bersih dan konsisten sehingga mudah ditata ulang dengan utility Tailwind.

## Cara Pengimplementasian / Kode

**Instalasi:**

```bash
npm install -D @tailwindcss/forms
```

**Config:**

```js
// tailwind.config.js
module.exports = {
  plugins: [
    require('@tailwindcss/forms'),
    // optional: kustomisasi strategy
    // require('@tailwindcss/forms')({ strategy: 'class' }),
  ],
}
```

**HTML -- Form lengkap dengan plugin forms:**

## Analogi

Bayangkan kamu membeli sebidang tanah kosong untuk membangun rumah. Tanpa plugin forms, tanah itu berbatu, tidak rata, dan penuh semak -- setiap kontraktor (browser) membersihkannya dengan cara sendiri. Plugin forms seperti jasa land clearing yang meratakan tanah, memasang pondasi dasar, dan menyiapkan lahan siap bangun. Setelah itu, kamu tinggal membangun struktur di atasnya dengan utility Tailwind.

## Dipakai untuk Apa

- Form pendaftaran, login, dan kontak
- Checkout form di e-commerce
- Form survey dan kuesioner
- Dashboard dengan filter dan pencarian
- Settings page dengan preferensi pengguna

## Kesalahan Umum yang Sering Terjadi

1. **Lupa install plugin**: Form tetap memiliki style browser default yang tidak konsisten dan sulit ditata.
2. **Mengandalkan plugin saja tanpa styling lanjutan**: Plugin hanya reset dasar. Kamu tetap perlu utility Tailwind untuk membuat form yang indah (`rounded-lg`, `focus:ring`, dll).
3. **Focus ring tidak terlihat**: Jika menggunakan `focus:ring-0` tanpa memberikan alternatif focus indicator, aksesibilitas keyboard terganggu.
4. **Checkbox dan radio tidak proporsional**: Terlalu kecil atau besar karena padding/margin tidak sesuai.
5. **Tidak menangani state error**: Plugin forms tidak otomatis menangani `:invalid` atau `aria-invalid`. Perlu manual dengan `border-red-500`.

## Koneksi dengan Materi Sebelumnya

Setelah menguasai plugin typography (materi 35) untuk menata konten baca, sekarang plugin forms melengkapi untuk menata input pengguna. Brand dari materi 31, dark mode dari materi 33-34, dan layer components dari materi 32 bisa dikombinasikan untuk membuat form yang sesuai brand dan mendukung dark mode.
