# Extend vs Override

## Penjelasan

- `tailwind.config.js` adalah pusat kustomisasi Tailwind.
- **Override** dilakukan dengan menulis properti langsung di dalam objek `theme`. Ini akan mengganti seluruh nilai default Tailwind untuk properti tersebut.
- **Extend** dilakukan dengan menulis properti di dalam objek `theme.extend`. Ini akan menambahkan nilai baru ke dalam properti yang sudah ada tanpa menghapus nilai default.
- Properti yang bisa dikustomisasi: `colors`, `fontFamily`, `spacing`, `boxShadow`, `animation`, `screens`, `borderRadius`, dan masih banyak lagi.
- Jika ingin mengganti total nilai default, gunakan override. Jika hanya ingin menambah varian baru di samping default, gunakan extend.
- Override bisa berbahaya karena menghilangkan utility bawaan yang mungkin masih dibutuhkan.
- Extend mempertahankan semua nilai default dan hanya menambahkan kustomisasi di atasnya.

## Fungsi

Mengontrol bagaimana Tailwind menghasilkan kelas utility -- apakah ingin menimpa seluruh tema default atau hanya menambahkan beberapa nilai kustom di atas default.

## Cara Pengimplementasian / Kode

**Override (mengganti total):**

```js
// tailwind.config.js
module.exports = {
  theme: {
    screens: {
      'sm': '640px',
      'md': '768px',
      'lg': '1024px',
    },
    // semua breakpoint default lain (xl, 2xl) TIDAK ADA
  },
}
```

**Extend (menambah tanpa menghapus default):**

```js
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      colors: {
        'brand-primary': '#1a1a2e',
        'brand-secondary': '#e94560',
      },
      fontFamily: {
        heading: ['Poppins', 'sans-serif'],
      },
      spacing: {
        '18': '4.5rem',
        '88': '22rem',
      },
      boxShadow: {
        'glow': '0 0 15px rgba(233, 69, 96, 0.5)',
      },
      animation: {
        'spin-slow': 'spin 3s linear infinite',
      },
      screens: {
        'xs': '480px',   // tetap punya sm, md, lg, xl, 2xl
      },
    },
  },
}
```

```html
<!-- Contoh penggunaan kustomisasi di HTML -->
<div class="bg-brand-primary font-heading shadow-glow animate-spin-slow">
  Elemen dengan brand kustom
</div>
```

## Analogi

**Extend** seperti menambah kamar baru atau memperluas ruangan di rumah yang sudah ada. Struktur asli rumah tetap utuh, kamu hanya menambahkan ruang tambahan.

**Override** seperti membangun ulang rumah dari nol. Kamu menentukan sendiri berapa banyak kamar, ukuran, dan tata letak -- semua keputusan default dari kontraktor sebelumnya dibuang.

## Dipakai untuk Apa

- **Extend**: menambahkan warna brand perusahaan, font khas, spacing custom, animasi baru, atau breakpoint khusus tanpa kehilangan utility bawaan Tailwind.
- **Override**: membuat design system yang sangat berbeda dari Tailwind default, atau ketika proyek hanya membutuhkan subset kecil dari utility yang ada.

## Kesalahan Umum yang Sering Terjadi

1. **Override tidak sengaja**: Menulis properti di `theme` (bukan `theme.extend`) tanpa sadar telah menghapus semua nilai default untuk properti itu.
2. **Lupa nesting**: Semua properti extend harus berada di dalam `theme.extend = {}`, bukan sebagai properti terpisah.
3. **Menimpa warna yang sama**: Jika menggunakan override pada `colors`, semua warna default seperti `blue-500`, `red-500`, dll hilang.
4. **Typo nama properti**: Nama properti di extend harus sama persis dengan yang ada di default Tailwind, misal `fontFamily` bukan `font-family`.
5. **Tidak restart dev server**: Perubahan config membutuhkan restart agar diterapkan.

## Koneksi dengan Materi Sebelumnya

Level 3 menggunakan utility default Tailwind seperti `bg-blue-500`, `text-gray-900`, dan `font-sans`. Sekarang dengan extend, kamu bisa membuat brand sendiri (`bg-brand-primary`, `text-brand-secondary`, `font-heading`) yang tetap hidup berdampingan dengan semua utility default. Brand inilah yang akan digunakan konsisten di seluruh proyek.

## Soal Latihan

Buat konfigurasi Tailwind yang melakukan:
1. Extend warna dengan `primary: #0f172a` dan `accent: #f59e0b`
2. Extend fontFamily dengan `display: ['Inter', 'sans-serif']`
3. Extend spacing dengan `15: '3.75rem'`
4. Extend animasi dengan `bounce-slow: 'bounce 2s infinite'`

Kemudian buat div yang menggunakan semua kustomisasi tersebut sekaligus.
