# col-span & Responsive Grid

## Penjelasan
- `col-span-N`: item melebar N kolom (col-span-2, col-span-3, ... col-span-full)
- `row-span-N`: item meninggi N baris (row-span-2, row-span-3, ...)
- `col-start-N` / `col-end-N`: menentukan posisi awal/akhir kolom secara eksplisit
- `row-start-N` / `row-end-N`: menentukan posisi awal/akhir baris secara eksplisit
- Responsive grid: `grid-cols-1 md:grid-cols-2 lg:grid-cols-4` -- perubahan jumlah kolom di breakpoint berbeda
- `grid-cols-12`: grid 12 kolom sangat umum digunakan seperti Bootstrap
- Bento grid: grid dengan item ukuran berbeda yang membentuk layout tidak beraturan seperti bento box
- Auto-fit vs auto-fill: `grid-cols-autofill` untuk jumlah kolom otomatis berdasarkan ukuran

## Fungsi
Membuat grid layout dengan item yang memiliki ukuran berbeda-beda (tidak seragam), serta mengubah jumlah kolom secara responsif.

## Analogi
`col-span-2` seperti **menyewa 2 tempat parkir untuk 1 mobil besar** -- Anda mengambil lebih dari satu slot. `row-span-2` seperti **rumah 2 lantai yang menempati 1 tanah** -- secara horizontal hanya 1 slot, tapi vertikal 2. Bento grid seperti **nampan bento** yang punya kompartemen besar untuk nasi, kompartemen kecil untuk lauk, dan kompartemen memanjang untuk sayur. Responsive grid seperti **rak yang bisa diubah jumlah sekatnya** -- di toko kecil (HP) cukup 1-2 sekat, di gudang besar (desktop) bisa 4-6 sekat.

## Dipakai untuk Apa
- Layout dashboard dengan widget ukuran berbeda (grafik besar, statistik kecil)
- Gallery foto dengan thumbnail berbagai ukuran
- Halaman artikel dengan sidebar
- Banner promosi besar di samping card-card kecil
- Layout majalah/koran
- Halaman produk dengan featured product lebih besar

## Kesalahan Umum yang Sering Terjadi
- Menggunakan `col-span` lebih besar dari jumlah kolom total (misal `col-span-5` dalam `grid-cols-3`)
- Lupa bahwa `col-span-full` lebih mudah daripada `col-span-{jumlah}` untuk full width
- Tidak menambahkan `auto-rows` untuk grid dengan row-span, menyebabkan baris tidak cukup tinggi
- Menggunakan `col-span-*` di mobile tanpa menyadari mobile hanya 1 kolom (col-span tidak berguna)
- Tidak konsisten antara jumlah kolom dan distribusi col-span

## Koneksi dengan Materi Sebelumnya
Sebelumnya kita belajar grid dasar (grid-cols, gap). Sekarang kita bisa membuat item dengan ukuran berbeda dalam grid yang sama. Ini penting untuk layout dashboard, halaman beranda, dan gallery. Juga belajar responsive grid yang merupakan fondasi dari **mobile-first** design -- nanti akan diperdalam di materi responsive prefix.

## Soal Latihan
Buat bento grid layout dengan:
1. Grid 4 kolom di desktop, 2 kolom di tablet, 1 kolom di mobile
2. Item besar 2x2 (lebar 2, tinggi 2)
3. Item lebar horizontal (col-span-2, row-span-1)
4. Item tinggi vertikal (col-span-1, row-span-2)
5. Item-item kecil 1x1
6. Beri warna berbeda tiap item
