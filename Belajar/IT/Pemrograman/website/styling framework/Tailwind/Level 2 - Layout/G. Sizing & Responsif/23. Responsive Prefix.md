# Responsive Prefix

## Penjelasan
- Tailwind menggunakan **mobile-first** approach: style tanpa prefix berlaku untuk semua ukuran layar, lalu ditimpa dengan prefix untuk layar lebih besar
- Breakpoint default Tailwind:
  - `sm:` 640px (tablet kecil / HP landscape)
  - `md:` 768px (tablet besar / iPad)
  - `lg:` 1024px (laptop)
  - `xl:` 1280px (desktop)
  - `2xl:` 1536px (monitor besar)
- Pola responsive: `grid-cols-1 md:grid-cols-2 lg:grid-cols-4`
  - Default: 1 kolom (mobile)
  - md ke atas: 2 kolom
  - lg ke atas: 4 kolom
- Prefix bisa diterapkan ke utility apa pun: `text-sm lg:text-lg`, `p-4 md:p-8`, `flex-col md:flex-row`
- Konfigurasi kustom: breakpoint bisa diubah di `tailwind.config.js`

## Fungsi
Membuat layout yang menyesuaikan diri dengan berbagai ukuran layar (responsif) dengan cara yang deklaratif dan konsisten.

## Analogi
Responsive prefix seperti **arsitek yang mendesain bangunan dengan konsep "expandable"** -- pertama bangun untuk ukuran terkecil (rumah tipe 36), lalu tambahkan sayap bangunan untuk lahan yang lebih luas. `grid-cols-1` adalah pondasi dasar yang berfungsi di semua lahan. `md:grid-cols-2` adalah penambahan ruang untuk lahan sedang. `lg:grid-cols-4` adalah sayap penuh untuk lahan besar. Mobile-first berarti **selalu pikirkan rumah minimalis dulu, baru diperluas**.

## Dipakai untuk Apa
- Layout halaman yang menyesuaikan jumlah kolom
- Navigasi yang berubah dari hamburger menu (mobile) ke horizontal (desktop)
- Ukuran font dan spacing yang berbeda tiap layar
- Gallery dan grid produk
- Form yang layout-nya berubah di layar berbeda
- Hero section dengan teks dan gambar yang menyesuaikan
- Sidebar yang collapse di mobile

## Kesalahan Umum yang Sering Terjadi
- Tidak mengikuti prinsip mobile-first (menulis style desktop di default, lalu override dengan `sm:` untuk mobile -- yang tidak akan bekerja karena `sm:` untuk >= 640px)
- Menggunakan `lg:hidden` untuk menyembunyikan sesuatu di mobile, padahal yang benar adalah `hidden lg:block`
- Menulis prefix terlalu banyak, membuat class terlalu panjang (bisa diatasi dengan komponen atau `@apply`)
- Lupa test di semua breakpoint, hanya fokus di satu ukuran layar
- Mengira prefix `sm:` berarti "hanya untuk layar kecil" (padahal berarti "untuk layar >= small")
- Breakpoint tidak sesuai dengan konten, misalnya teks jadi terlalu kecil di tablet

## Koneksi dengan Materi Sebelumnya
Ini adalah materi pamungkas dari Level 2. Semua yang sudah dipelajari -- padding, margin, space, flexbox, grid, container, max-width, sizing -- semuanya bisa diberi prefix responsive. Pola `grid-cols-1 md:grid-cols-2 lg:grid-cols-4` menggabungkan grid dengan responsive. `p-4 md:p-8` menggabungkan spacing dengan responsive. Mobile-first adalah filosofi utama Tailwind yang akan dipakai di semua project selanjutnya.

## Soal Latihan
Buat sebuah halaman landing page yang sepenuhnya responsif dengan:
1. Navigasi: di mobile 2 elemen (logo + hamburger), di desktop tampil menu horizontal
2. Hero: di mobile teks di tengah dengan CBM, di desktop teks di kiri + gambar ilustrasi di kanan (flex-col md:flex-row)
3. Fitur: mobile 1 kolom, tablet 2 kolom, desktop 4 kolom
4. Testimonial: mobile 1 kolom, md 2 kolom, dengan card yang memiliki padding responsif
5. Footer: sederhana, tetap konsisten di semua layar
