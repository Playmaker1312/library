# motion-reduce

## Penjelasan
- `prefers-reduced-motion` adalah media query CSS yang mendeteksi preferensi sistem operasi user: apakah mereka meminta animasi dikurangi atau dimatikan.
- Pengguna dengan gangguan vestibular (keseimbangan), migrain, atau epilepsi sering mengaktifkan fitur ini karena animasi bisa memicu gejala fisik seperti mual, pusing, atau kejang.
- Tailwind menyediakan dua variant untuk ini: `motion-reduce:` dan `motion-safe:`.
- `motion-reduce:` berisi style yang AKTIF ketika user meminta reduced motion. Biasanya berisi `transition: none`, `animation: none`, atau versi statis dari animasi.
- `motion-safe:` berisi style yang AKTIF ketika user TIDAK meminta reduced motion (default). Animasi normal ditempatkan di sini.
- Prinsipnya: **animasi sebagai peningkatan (enhancement), bukan keharusan**. Konten harus tetap bisa diakses tanpa animasi.
- Jangan hanya mematikan animasi — pastikan transisi state tetap terlihat (misal: instant color change, bukan fade yang lambat).

## Fungsi
- Memberikan kontrol kepada user atas pengalaman animasi mereka
- Mencegah gejala fisik pada pengguna dengan gangguan vestibular, migrain, atau epilepsi
- Memenuhi standar WCAG 2.1 Success Criterion 2.3.3 (Animation from Interactions)
- Menjaga usability: animasi mempercantik, tapi konten tetap harus berfungsi tanpa animasi

## Cara Pengimplementasian / Kode

```html
<!-- Animasi loading spinner yang mati saat reduced motion -->
<div class="flex items-center gap-2">
  <div
    class="h-4 w-4 rounded-full bg-blue-600
           motion-safe:animate-spin"
  >
  </div>
  <span>Memuat data...</span>
</div>
```

```html
<!-- Card yang muncul dengan slide-in animation -->
<div
  class="translate-y-4 opacity-0 transition-all duration-500
         motion-safe:animate-[fadeIn_0.5s_ease_forwards]
         motion-reduce:translate-y-0 motion-reduce:opacity-100"
>
  <h2 class="text-lg font-semibold">Kartu Informasi</h2>
  <p class="text-gray-600">Konten kartu tetap terlihat meski animasi dimatikan.</p>
</div>

<style>
  @keyframes fadeIn {
    to {
      opacity: 1;
      transform: translateY(0);
    }
  }
</style>
```

```js
// Untuk interaksi JS — deteksi preferensi sebelum menjalankan animasi
const prefersReducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches;

function handleScrollAnimation(element) {
  if (prefersReducedMotion) {
    // Tampilkan langsung tanpa animasi
    element.classList.add('opacity-100');
    element.classList.remove('opacity-0');
  } else {
    // Jalankan animasi normal
    element.classList.add('animate-fadeIn');
  }
}
```

```html
<!-- Hover scale pada card — versi aman untuk reduced motion -->
<article
  class="rounded-lg border border-gray-200 p-4 transition-colors duration-200
         hover:border-blue-600 hover:shadow-md
         motion-safe:hover:scale-105 motion-safe:transition-transform"
>
  <!-- Konten card -->
</article>
```

```html
<!-- Parallax atau background animation -->
<section
  class="bg-fixed bg-cover bg-center py-20
         motion-reduce:bg-scroll"
  style="background-image: url('hero.jpg')"
>
  <!-- motion-reduce:bg-scroll mengganti bg-fixed dengan bg-scroll -->
  <!-- agar efek paralaks tidak menyebabkan mual -->
  <h1 class="text-4xl font-bold text-white">Selamat Datang</h1>
</section>
```

## Analogi
motion-reduce seperti saklar "jangan goncang" yang ada di rumah sakit atau ambulans. Saat tombol itu ditekan, semua gerakan yang tidak perlu dihentikan — pasien tidak boleh terguncang. Begitu juga di web: sebagian user adalah "pasien" yang butuh ketenangan. motion-safe adalah kondisi normal di mana gerakan diperbolehkan, seperti jalan raya yang lancar tanpa hambatan.

## Dipakai untuk Apa
- Loading spinner, skeleton screen, progress bar yang berputar
- Scroll-triggered animation (fade-in, slide-in, scale-in)
- Hover effects: scale, translate, rotate pada kartu atau tombol
- Background parallax — mengganti dengan background statis
- Carousel auto-slide — nonaktifkan auto-slide saat reduced motion
- Page transition dan route animation di SPA
- Tooltip atau dropdown yang muncul dengan transisi halus

## Kesalahan Umum yang Sering Terjadi
- Hanya menambahkan `motion-reduce:*` tanpa `motion-safe:*` — animasi berjalan di semua kondisi (tidak ada perubahan)
- Mematikan semua transisi termasuk transisi state penting (contoh: hover color) — cukup nonaktifkan durasi/gerakan
- Animasi infinite (berputar terus) tidak dimatikan — ini yang paling berbahaya untuk pengguna epilepsi
- Hanya handle CSS tapi lupa handle JS — animasi JavaScript juga harus di-deteksi preferensinya
- Menganggap semua user suka animasi — selalu sediakan fallback tanpa animasi
- Menggunakan `animation: none` pada elemen yang membutuhkan indikator visual (contoh: loading state) — ganti dengan indikator non-animasi

## Koneksi dengan Materi Sebelumnya
Di Level 3 kamu belajar animasi Tailwind seperti `animate-spin`, `animate-ping`, `transition`. Di materi 40 kamu belajar sr-only dan focus untuk aksesibilitas penglihatan dan keyboard. motion-reduce melengkapi aksesibilitas dari sisi vestibular/motion sensitivity. Animasi tetap boleh ada, tapi harus bisa dimatikan. Ini adalah bagian dari produksi yang bertanggung jawab.

## Soal Latihan
Buat sebuah tombol dengan efek hover naik ke atas (translateY -2px) dan shadow yang membesar. Di motion-reduce, tombol hanya berganti warna background tanpa pergerakan. Gunakan utility Tailwind murni tanpa CSS kustom.

<details>
<summary>Jawaban</summary>

```html
<button
  class="rounded-lg bg-blue-600 px-6 py-3 text-base font-medium text-white shadow-md
         transition-colors duration-200
         hover:bg-blue-700
         motion-safe:transition-all motion-safe:duration-200
         motion-safe:hover:-translate-y-0.5 motion-safe:hover:shadow-lg
         focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-blue-600 focus-visible:ring-offset-2"
>
  Klik Saya
</button>
```

Penjelasan:
- `transition-colors` tetap aktif di semua kondisi agar hover color tetap smooth.
- `transition-all` hanya di `motion-safe` agar pergerakan tidak terjadi di reduced motion.
- `hover:-translate-y-0.5` dan `hover:shadow-lg` dibungkus `motion-safe` agar tidak ada pergerakan fisik.
- Saat reduced motion: tombol hanya berganti warna dari blue-600 ke blue-700 tanpa naik.
- Fungsi tombol tetap utuh, hanya efek visual yang dikurangi.
</details>
