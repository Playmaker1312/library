# Prettier Plugin Tailwind

## Penjelasan
- **prettier-plugin-tailwindcss** adalah plugin Prettier yang secara otomatis mengurutkan class Tailwind dalam elemen HTML/JSX sesuai dengan aturan resmi Tailwind. Urutannya: layout, spacing, sizing, typography, visual, border, effect, transition, dan variant.
- Class diurutkan berdasarkan kategori (layout -> spacing -> sizing -> dll) dan variant (base -> hover -> focus -> dark -> dll). Ini membuat kode lebih mudah dipindai dan konsisten di seluruh tim.
- Plugin ini bekerja otomatis saat kamu menjalankan `npx prettier --write .` atau menyimpan file di editor yang terintegrasi Prettier.
- **ESLint plugin tailwindcss** (eslint-plugin-tailwindcss) memberikan aturan linting tambahan seperti mencegah class yang salah urut, class yang tidak ada, atau class yang bertentangan.
- Setup-nya sederhana: cukup tambahkan plugin ke konfigurasi Prettier, tidak perlu konfigurasi tambahan.

## Fungsi
- Mengurutkan class Tailwind secara konsisten dan otomatis sesuai standar resmi
- Mencegah perdebatan tim tentang urutan class di code review
- Mendeteksi class yang salah eja atau tidak valid (via ESLint)
- Mengintegrasikan format class dengan workflow Prettier yang sudah ada
- Mempercepat proses review karena kode lebih terstruktur dan terbaca

## Cara Pengimplementasian / Kode

```json5
// .prettierrc — di root project
{
  "plugins": ["prettier-plugin-tailwindcss"],
  "tabWidth": 2,
  "semi": true,
  "singleQuote": true,
  "trailingComma": "es5"
}
```

```json5
// .eslintrc.json — aturan tambahan untuk Tailwind
{
  "extends": [
    "next/core-web-vitals",
    "plugin:tailwindcss/recommended"
  ],
  "plugins": ["tailwindcss"],
  "rules": {
    "tailwindcss/classnames-order": "warn",
    "tailwindcss/no-custom-classname": "warn",
    "tailwindcss/no-contradicting-classname": "error"
  },
  "settings": {
    "tailwindcss": {
      "callees": ["cn", "clsx", "twMerge"],
      "config": "tailwind.config.js"
    }
  }
}
```

```bash
# Install dependencies
npm install -D prettier prettier-plugin-tailwindcss
npm install -D eslint-plugin-tailwindcss

# Format semua file
npx prettier --write .

# Cek dengan ESLint
npx eslint src/
```

```html
<!-- Sebelum prettier-plugin-tailwindcss — class tidak terurut -->
<button class="rounded-xl text-white bg-blue-600 hover:bg-blue-700 px-6 py-3 text-base font-medium shadow-lg">
  Klik
</button>

<!-- Sesudah prettier-plugin-tailwindcss — class terurut otomatis -->
<!-- urutan: layout (rounded), spacing (px, py), typography (text, font), visual (bg, text, shadow), variant (hover) -->
<button class="rounded-xl px-6 py-3 text-base font-medium text-white bg-blue-600 shadow-lg hover:bg-blue-700">
  Klik
</button>
```

## Analogi
prettier-plugin-tailwindcss seperti petugas gudang material bangunan yang merapikan semua bahan sesuai raknya: batu bata di rak A, semen di rak B, cat di rak C. Tukang bangunan (developer) jadi lebih cepat mencari bahan yang dibutuhkan. Tanpa petugas ini, gudang akan berantakan dan tukang harus mencari-cari setiap kali butuh sesuatu.

## Dipakai untuk Apa
- Semua project Tailwind, terutama yang dikerjakan oleh tim
- Codebase besar dengan banyak komponen — sorting class sangat membantu navigasi
- Integrasi dengan CI/CD untuk memastikan semua PR memiliki format class yang konsisten
- Project yang sudah menggunakan Prettier — tinggal tambahkan satu plugin
- Onboarding developer baru — mereka tidak perlu belajar urutan class, plugin yang atur

## Kesalahan Umum yang Sering Terjadi
- Lupa menambahkan plugin ke array `plugins` di `.prettierrc` — plugin terinstall tapi tidak aktif
- Tidak menginstall plugin sebagai devDependency — plugin tidak ikut terinstall saat clone project
- Bentrok dengan prettier-plugin-tailwindcss versi lama saat upgrade Tailwind — selalu cek kompatibilitas versi
- Tidak mengkonfigurasi `callees` di ESLint settings — fungsi seperti cn() dianggap class kustom
- Menjalankan prettier tanpa `--write` — hanya menampilkan output tanpa mengubah file
- Tidak mengintegrasikan dengan editor (VS Code settings) — format tidak otomatis saat save

```json5
// VS Code settings.json — auto-format on save
{
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": true
  }
}
```

## Koneksi dengan Materi Sebelumnya
Di materi 38 kamu belajar cn() untuk manage class secara logic. Di materi 39 kamu belajar @apply untuk mengelompokkan class. Sekarang prettier-plugin-tailwindcss memastikan semua class — baik di JSX, HTML, maupun file CSS — memiliki urutan yang konsisten. Ini adalah langkah terakhir sebelum produksi: kode yang rapi secara logic sudah, sekarang rapi secara format.

## Soal Latihan
Buat konfigurasi Prettier dan ESLint untuk project Tailwind yang menggunakan fungsi `cn()`. Tuliskan juga contoh komponen sebelum dan sesudah di-format.
