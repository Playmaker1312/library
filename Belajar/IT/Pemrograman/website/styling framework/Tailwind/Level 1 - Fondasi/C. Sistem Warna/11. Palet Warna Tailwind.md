# Palet Warna Tailwind

## Penjelasan
- Tailwind menyediakan palet warna yang sangat lengkap: **22 warna dasar**, masing-masing dengan 22-25 shade dari 50 hingga 950.
- Setiap warna memiliki nama seperti `blue`, `red`, `green`, `slate`, `gray`, `zinc`, `neutral`, `stone`, `orange`, `amber`, `yellow`, `lime`, `emerald`, `teal`, `cyan`, `sky`, `indigo`, `violet`, `purple`, `fuchsia`, `pink`, `rose`.
- Format penulisan: `[warna]-[shade]`, contoh: `bg-blue-500`, `text-red-700`, `border-green-300`.
- **Pola penggunaan shade**:
  - **50-100**: Paling terang — untuk background halus, efek hover ringan.
  - **200-300**: Terang — untuk border halus, background card, badge.
  - **400-500**: Medium — untuk warna utama elemen, tombol primer, teks biasa.
  - **600-700**: Gelap — untuk teks penting, tombol hover, aksen kuat.
  - **800-900**: Sangat gelap — untuk teks utama (heading), background dark mode.
  - **950**: Paling gelap — hampir hitam, untuk kontras maksimal.
- **Warna Neutral**: `slate`, `gray`, `zinc`, `neutral`, `stone` — untuk background, text, border. Paling sering dipakai.
  - `slate` — sedikit biru (modern, profesional).
  - `gray` — benar-benar netral.
  - `zinc` — sedikit hangat.
  - `neutral` — hangat netral.
  - `stone` — hangat natural.

## Fungsi
Palet warna Tailwind memberi sistem warna yang konsisten, Kontras yang terjamin antar shade, dan tidak perlu mikir nilai hex.

## Analogi
Palet warna Tailwind seperti **katalog cat tembok** di toko bangunan. Untuk setiap warna (biru, merah, hijau, dll) ada 22 tingkat kecerahan dari paling pucat (50) hingga paling pekat (950). Kamu tinggal pilih: "Saya mau cat biru tingkat 500 untuk tembok utama, tingkat 200 untuk border, tingkat 700 untuk aksen." Tidak perlu campur cat manual.

## Dipakai untuk Apa
- Background: `bg-slate-50` untuk background halaman, `bg-white` untuk card.
- Teks: `text-gray-900` untuk judul, `text-gray-600` untuk body.
- Border: `border-gray-200` untuk border card.
- Tombol: `bg-blue-500` untuk tombol primer, `bg-blue-600` untuk hover.
- Alert: `bg-red-50` + `text-red-700` + `border-red-200`.

## Kesalahan Umum yang Sering Terjadi
- **Menggunakan shade terlalu terang untuk teks**: Teks dengan `text-gray-300` di background putih sangat sulit dibaca. Minimal `text-gray-500` untuk teks kecil, `text-gray-700` untuk body.
- **Menggunakan shade terlalu gelap untuk background**: Background `bg-gray-900` dengan teks hitam tidak terbaca. Pastikan kontras cukup.
- **Mencampur terlalu banyak warna dalam satu halaman**: Pilih 1-2 warna utama dan konsisten. Jangan setiap elemen beda warna.
- **Lupa bahwa slate, gray, zinc itu berbeda**: Mereka mirip tapi tidak sama. Pilih satu sebagai warna netral utama dan konsisten.

## Koneksi dengan Materi Sebelumnya
Setelah menguasai tipografi (materi 6-10), sekarang kamu belajar warna — elemen visual kedua paling penting setelah teks. Kombinasi tipografi yang baik + warna yang tepat = desain yang profesional.

## Soal Latihan

Buat sebuah card dengan: background menggunakan shade 50 dari warna primary pilihanmu, border shade 200, teks judul shade 900, teks body shade 600, tombol shade 500 dengan hover shade 600. Gunakan Tailwind Play.
