# Memahami JIT (Just-In-Time)

## Penjelasan
- Tailwind versi 3 ke atas menggunakan **JIT engine** — sistem yang membangkitkan CSS secara real-time berdasarkan apa yang benar-benar kamu tulis di file.
- Cara kerja: JIT memindai (scan) semua file yang kamu tentukan di `content` config — bisa `.html`, `.js`, `.ts`, `.vue`, `.jsx`, `.php`, dll.
- Dari hasil scan, JIT mencari string yang cocok dengan pattern utility Tailwind (misal `bg-blue-500`, `p-4`, `text-lg`).
- Hanya utility yang ditemukan di file-file itu yang akan di-generate menjadi CSS. Utility lain tidak ikut — nol unused CSS.
- JIT juga memungkinkan **arbitrary values**: `top-[37px]`, `bg-[#1da1f1]`, `text-[14px]` — nilai kustom apapun langsung inline tanpa perlu config.
- Sebelum JIT (Tailwind v2), Tailwind mengenerate SEMUA kemungkinan kombinasi utility dari config, menghasilkan file CSS besar (ratusan KB) lalu dipurge.

## Fungsi
JIT membuat proses develop lebih cepat (tidak perlu nunggu purge), file output super kecil (hanya CSS yang dipakai), dan memberi fleksibilitas arbitrary value tanpa perlu konfigurasi tambahan.

## Cara Pengimplementasian / Kode

```html
<!-- Tailwind akan scan semua class di file ini -->
<div>
  <!-- Utility standar — pasti ke-scan -->
  <h1 class="text-3xl font-bold text-blue-600">Judul</h1>

  <!-- Arbitrary value — JIT langsung generate -->
  <p class="text-[14px] text-[#1da1f1]">Teks dengan ukuran kustom</p>

  <!-- Arbitrary value untuk spacing -->
  <div class="mt-[37px]">Margin top 37px persis</div>

  <!-- Grid dengan arbitrary column -->
  <div class="grid grid-cols-[200px_1fr_auto]">
    <div>Sidebar</div>
    <div>Konten</div>
    <div>Aside</div>
  </div>
</div>
```

## Analogi
JIT seperti **chef di restoran fine dining**. Chef tidak menyiapkan semua menu yang ada di buku resep dari pagi — dia hanya memasak pesanan yang masuk dari pelanggan. Pelanggan juga bisa pesan di luar menu ("Tolong buatkan spaghetti dengan saus tomat buatan sendiri, pake basil segar") dan chef akan langsung buatkan. Hasilnya: 0 makanan terbuang, sesuai pesanan.

## Dipakai untuk Apa
- Semua proyek Tailwind v3+. JIT aktif secara default, tidak perlu konfigurasi khusus.
- Saat kamu butuh nilai desain yang tidak ada di default Tailwind (misal warna brand exact, ukuran custom).
- Proyek dengan CSS output size yang harus sekecil mungkin (performance-critical).

## Kesalahan Umum yang Sering Terjadi
- **Lupa nambah path file di `content` config**: JIT tidak akan menscan file tersebut, class Tailwind di dalamnya tidak kebaca, jadinya tidak ke-generate. Selalu pastikan kamu include folder dan ekstensi file yang benar.
- **Menganggap JIT ajaib bisa baca class dari database atau API**: JIT hanya menscan file statis. Kalau class Tailwind dimasukkan secara dinamis (misal dari database), JIT tidak akan tahu dan perlu di-declare secara eksplisit di safelist.
- **Overuse arbitrary value**: Kalau semua ukuran pakai arbitrary value, hilang benefit konsistensi desain. Arbitrary value untuk pengecualian, bukan untuk utama.

## Koneksi dengan Materi Sebelumnya
JIT adalah mesin yang membuat utility-first approach menjadi efisien. Tanpa JIT, utility-first akan menghasilkan file CSS raksasa. Dengan JIT, ukuran file tetap kecil karena hanya utility yang kamu pakai yang di-generate.

## Soal Latihan

Buat sebuah elemen card di Tailwind Play yang menggunakan 3 arbitrary value: warna background custom (pakai kode hex brand), lebar card custom (pakai angka persis), dan border radius custom. Pastikan class tetap bisa di-render di preview.
