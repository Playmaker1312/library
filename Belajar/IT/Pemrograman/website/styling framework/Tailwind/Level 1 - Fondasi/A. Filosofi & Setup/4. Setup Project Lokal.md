# Setup Project Lokal

## Penjelasan
- Cara paling umum dan recommended untuk setup Tailwind lokal adalah menggunakan **Vite** sebagai bundler.
- Langkah-langkah:
  1. **Buat project baru** dengan npm: `npm create vite@latest nama-project -- --template vanilla`
  2. **Masuk ke folder**: `cd nama-project`
  3. **Install Tailwind**: `npm install -D tailwindcss @tailwindcss/vite`
  4. **Konfigurasi Vite**: tambahkan plugin Tailwind di `vite.config.js`
  5. **Import Tailwind di CSS**: tambahkan `@import "tailwindcss"` di file CSS utama
  6. **Jalankan dev server**: `npm run dev`
- Alternatif setup lain: Tailwind CLI, PostCSS, Laravel, Next.js, Remix, dll.
- File `tailwind.config.js` sebenarnya tidak wajib untuk setup dasar — Tailwind v4 menggunakan CSS-first configuration.
- Dev server (`npm run dev`) akan hot-reload setiap kali kamu mengubah file HTML/template.

## Fungsi
Setup lokal memberi kamu environment develop profesional dengan autocomplete, hot reload, build production, dan kontrol penuh atas konfigurasi.

## Cara Pengimplementasian / Kode

```bash
# 1. Buat project Vite
npm create vite@latest proyek-tailwind-ku -- --template vanilla

# 2. Masuk ke direktori
cd proyek-tailwind-ku

# 3. Install Tailwind v4 + plugin Vite
npm install -D tailwindcss @tailwindcss/vite
```

```js
// vite.config.js — tambahkan plugin Tailwind
import { defineConfig } from 'vite'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [
    tailwindcss(),
  ],
})
```

```css
/* style.css — import Tailwind */
@import "tailwindcss";
```

```html
<!-- index.html — langsung pakai class Tailwind -->
<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Proyek Tailwind</title>
    <link rel="stylesheet" href="/style.css" />
  </head>
  <body class="bg-gray-100 p-8">
    <h1 class="text-3xl font-bold text-blue-600">Halo Tailwind!</h1>
  </body>
</html>
```

```bash
# 4. Jalankan dev server
npm run dev
```

## Analogi
Tailwind Play adalah **gerai percontohan** furnitur — kamu lihat contoh, cobain duduk, tapi tidak bisa bawa pulang. Setup lokal adalah **rumahmu sendiri** — kamu beli bahannya, pasang sendiri, atur sesuai keinginan. Hasilnya lebih permanen dan bisa kamu bangun besar.

## Dipakai untuk Apa
- Semua proyek serius, dari website sederhana hingga aplikasi kompleks.
- Proyek yang perlu integrasi dengan framework (React, Vue, Laravel, dll).
- Proyek yang butuh build step dan optimasi produksi.

## Kesalahan Umum yang Sering Terjadi
- **Tidak menjalankan `npm install`**: Setelah clone repo, selalu jalankan `npm install` dulu.
- **Salah ekstensi file di content**: Pastikan path di konfigurasi mencakup semua file yang kamu pakai.
- **Lupa import CSS Tailwind**: File CSS utama harus berisi `@import "tailwindcss"` supaya utility-nya aktif.
- **Menjalankan perintah di folder yang salah**: Pastikan terminal sedang di direktori project.

## Koneksi dengan Materi Sebelumnya
