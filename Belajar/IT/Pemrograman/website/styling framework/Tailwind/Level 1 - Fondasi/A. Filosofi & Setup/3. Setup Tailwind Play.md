# Setup Tailwind Play

## Penjelasan
- **Tailwind Play** adalah playground online resmi di `play.tailwindcss.com` — cara termudah untuk mulai bereksperimen dengan Tailwind tanpa install apa pun.
- Tampilan terdiri dari:
  - **Panel kiri**: tempat menulis HTML dengan class Tailwind.
  - **Panel kanan**: preview real-time hasil render.
  - **Toolbar atas**: tombol untuk format HTML, toggle layar, share, export, dll.
- Setiap utility class yang kamu ketik otomatis ter-apply di preview — Instant feedback.
- Ada **autocomplete** (IntelliSense) built-in di panel kiri — cukup mulai ngetik class, muncul saran.
- Bisa ganti versi Tailwind (pilih versi terbaru).
- Ada tab **Config** untuk mengubah `tailwind.config.js` jika perlu.
- Tombol **Share** menghasilkan URL unik yang bisa dikirim ke orang lain — cocok untuk bertanya atau nunjukkin bug.
- Bisa **download** sebagai HTML file.

## Fungsi
Tailwind Play memberi lingkungan belajar instan tanpa setup — cocok untuk mencoba class baru, prototyping cepat, debugging, atau sharing kode.

## Cara Pengimplementasian / Kode

Buka `https://play.tailwindcss.com` — langsung bisa pakai. Contoh kiri:

```html
<div class="min-h-screen bg-gradient-to-br from-blue-500 to-purple-600 flex items-center justify-center">
  <div class="bg-white p-8 rounded-2xl shadow-2xl max-w-sm">
    <h1 class="text-2xl font-bold text-gray-800 mb-2">Halo, Tailwind!</h1>
    <p class="text-gray-600">Ini adalah card cantik yang dibuat langsung di Tailwind Play.</p>
    <button class="mt-4 bg-blue-500 text-white px-6 py-2 rounded-lg hover:bg-blue-600 transition">
      Klik Saya
    </button>
  </div>
</div>
```

## Analogi
Tailwind Play seperti **showroom bata lego**. Kamu datang, ada meja dengan ribuan bata, kamu tinggal nyoba nyusun bentuk apa pun tanpa perlu beli, tanpa perlu bawa alat sendiri. Kalau udah jadi, bisa difoto (share URL) atau dibawa pulang (download HTML).

## Dipakai untuk Apa
- Belajar Tailwind pertama kali.
- Mencoba utility class tertentu sebelum dipakai di proyek asli.
- Membuat reproducible bug report (share URL).
- Prototype desain cepat.

## Kesalahan Umum yang Sering Terjadi
- **Lupa klik Share sebelum close tab**: Semua progress hilang. Selalu share/save URL atau download sebelum tutup.
- **Mengganti versi Tailwind tanpa sengaja**: Cek versi di dropdown — pastikan pakai versi stabil terbaru.
- **Mengharapkan arbitrary value JS**: Tailwind Play hanya render HTML statis. Kalau perlu interaksi, pakai framework atau proyek lokal.

## Koneksi dengan Materi Sebelumnya
Sebelum setup proyek lokal (materi 4), kamu wajib fasih dulu dengan Tailwind Play supaya paham pattern utility Tailwind tanpa distraksi setup toolchain.
