# Font Size

## Penjelasan
- Tailwind menyediakan skala ukuran font yang konsisten: `text-xs` hingga `text-9xl`.
- Setiap level size sudah memiliki **line-height otomatis** yang proporsional — kamu tidak perlu mikir line-height manual untuk teks biasa.
- Skala yang tersedia:
  - `text-xs`: 0.75rem (12px) — line-height 1rem (16px)
  - `text-sm`: 0.875rem (14px) — line-height 1.25rem (20px)
  - `text-base`: 1rem (16px) — line-height 1.5rem (24px) — default
  - `text-lg`: 1.125rem (18px) — line-height 1.75rem (28px)
  - `text-xl`: 1.25rem (20px) — line-height 1.75rem (28px)
  - `text-2xl`: 1.5rem (24px) — line-height 2rem (32px)
  - `text-3xl`: 1.875rem (30px) — line-height 2.25rem (36px)
  - `text-4xl`: 2.25rem (36px) — line-height 2.5rem (40px)
  - `text-5xl`: 3rem (48px) — line-height 1
  - `text-6xl`: 3.75rem (60px) — line-height 1
  - `text-7xl`: 4.5rem (72px) — line-height 1
  - `text-8xl`: 6rem (96px) — line-height 1
  - `text-9xl`: 8rem (128px) — line-height 1
- Mulai `text-5xl` ke atas, line-height menggunakan `1` (tight) karena ukuran besar biasanya untuk headline.
- Kamu bisa override line-height dengan `leading-*` jika perlu.

## Fungsi
Font size utility memberi kontrol ukuran teks yang konsisten dan proporsional tanpa perlu mengingat nilai CSS — cukup pilih skala yang sesuai.

## Cara Pengimplementasian / Kode

```html
<div class="p-8 space-y-2">
  <p class="text-xs">text-xs — 12px (untuk label kecil)</p>
  <p class="text-sm">text-sm — 14px (untuk caption)</p>
  <p class="text-base">text-base — 16px (paragraf default)</p>
  <p class="text-lg">text-lg — 18px (paragraf besar)</p>
  <p class="text-xl">text-xl — 20px (sub-heading kecil)</p>
  <p class="text-2xl">text-2xl — 24px (sub-heading)</p>
  <p class="text-3xl">text-3xl — 30px (heading)</p>
  <p class="text-4xl">text-4xl — 36px (heading besar)</p>
  <p class="text-5xl">text-5xl — 48px (hero)</p>
  <p class="text-6xl">text-6xl — 60px (hero besar)</p>
</div>
```

## Analogi
Font size di Tailwind seperti **katalog ukuran bata yang sudah standar**. Ada bata kecil (xs), bata sedang (base), bata besar (xl), dan seterusnya. Kamu tidak perlu potong bata sendiri atau ukur manual — tinggal pilih dari katalog, ukuran dan jarak antar bata (line-height) sudah otomatis sesuai proporsi.

## Dipakai untuk Apa
- Menentukan ukuran teks untuk heading, sub-heading, body text, caption, label.
- Membuat hierarki visual yang jelas antar elemen teks.

## Kesalahan Umum yang Sering Terjadi
- **Menggunakan `text-base` untuk semua teks**: Padahal hierarki visual penting. Jangan takut bedakan ukuran untuk judul, subjudul, dan body.
- **Menambahkan line-height manual di semua tempat**: Line-height default sudah optimal. Hanya override jika ada kasus khusus (misal button dengan satu baris teks).
- **Skip ke 5xl langsung tanpa transisi**: Gunakan gradasi ukuran, jangan lompat dari `text-base` ke `text-5xl` tanpa alasan jelas.

## Koneksi dengan Materi Sebelumnya
Setelah setup environment (materi 3-5), kamu mulai masuk ke utility class pertama. Font size adalah fondasi dari semua materi typography selanjutnya — sebelum atur font-weight, alignment, atau spacing, kamu harus tahu dulu scale ukurannya.
