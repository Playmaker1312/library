# 10. Operator Perbandingan

## Penjelasan
Operator perbandingan digunakan untuk membandingkan dua nilai dan mengembalikan hasil boolean (`true` atau `false`): `>` (lebih besar), `<` (lebih kecil), `>=` (lebih besar atau sama), `<=` (lebih kecil atau sama), `==` (sama dengan — loose, dengan coercion), `===` (sama dengan — strict, tanpa coercion), `!=` (tidak sama — loose), dan `!==` (tidak sama — strict). Perbedaan `==` dan `===` sangat krusial: `==` melakukan type coercion, `===` tidak.

## Fungsi
Operator perbandingan memungkinkan program membuat keputusan berdasarkan kondisi tertentu. Apakah suhu rumah sudah mencapai target AC? Apakah user sudah cukup umur? Apakah password cocok? Apakah stok barang masih ada? Semua pertanyaan ini dijawab dengan operator perbandingan.

## Cara Pengimplementasian
```js
const suhuAC = 24;
const suhuSekarang = 30;

console.log(suhuSekarang > suhuAC);   // true (lebih panas)
console.log(suhuSekarang < suhuAC);   // false
console.log(suhuSekarang === 30);     // true
console.log(suhuSekarang !== 24);     // true

// Perbedaan == dan ===
console.log(5 == "5");   // true (coercion: string "5" jadi number)
console.log(5 === "5");  // false (tipe berbeda)
console.log(0 == false); // true (coercion)
console.log(0 === false); // false (tipe berbeda)

console.log("a" < "b");  // true (dibandingkan secara Unicode)
console.log("Z" < "a");  // true (kode ASCII Z < a)
```

## Analogi
Operator perbandingan seperti **alat ukur dan timbangan di rumah**:
- `>` / `<` = meteran untuk mengukur apakah lemari lebih panjang dari ruangan
- `>=` / `<=` = mengukur apakah barang muat atau pas
- `===` = mengecek apakah dua kunci identik (merk, ukuran, dan bentuk sama persis)
- `==` = mengecek apakah dua kunci bisa membuka pintu yang sama (fungsi sama, walau beda bahan)
- `!==` / `!=` = memastikan dua barang tidak sama (misalnya memastikan cat tembok bukan warna biru)

## Dipakai Untuk Apa
Digunakan dalam semua struktur kontrol (if, switch, loop) — validasi form (apakah password cukup panjang?), otorisasi (apakah user adalah admin?), filter data (tampilkan produk dengan harga di bawah 100rb), menentukan pemenang game (skor lebih tinggi), dan logika bisnis apapun yang butuh perbandingan.

## Kesalahan Umum
Kesalahan paling terkenal adalah menggunakan `=` (assignment) di dalam kondisi `if` sebagai pengganti `===`. Contoh: `if (x = 5)` — ini tidak membandingkan x dengan 5, melainkan meng-assign 5 ke x! Selalu gunakan `===` (strict equality) untuk menghindari kejutan dari coercion. Ingat: `==` menganggap `0`, `""`, dan `false` sama — yang sering tidak diinginkan.

## Keterkaitan dengan Materi Sebelumnya
Setelah mempelajari operator aritmatika (materi 9) dan type coercion (materi 8), materi operator perbandingan menjadi jembatan ke pengambilan keputusan (if/else nanti). Kamu perlu bisa membandingkan nilai sebelum bisa memutuskan sesuatu — seperti mengecek suhu sebelum memutuskan menyalakan AC.

## Soal Latihan
Apa output dari kode berikut?
```js
console.log(10 > "5");
console.log(10 === "10");
console.log("5" == 5);
console.log(false == 0);
```

<details>
<summary>Jawaban</summary>
`true` (string "5" di-coerce ke number 5), `false` (strict — number vs string), `true` (loose — coercion), `true` (loose — false di-coerce ke 0).
</details>
