# 2. Cara Menjalankan JavaScript — Tiga Cara

## Penjelasan
Ada tiga cara utama untuk menjalankan kode JavaScript: (1) langsung di console browser, (2) menyisipkan kode di dalam file HTML dengan tag `<script>`, dan (3) membuat file `.js` terpisah lalu dipanggil dari HTML. Masing-masing cara punya kegunaan tersendiri. Console browser cocok untuk eksperimen cepat, tag `<script>` untuk proyek kecil sederhana, dan file terpisah untuk proyek yang lebih terstruktur.

## Fungsi
Mengetahui cara menjalankan JavaScript memungkinkan kamu memilih alat yang tepat sesuai kebutuhan. Console browser berguna untuk debugging dan testing cepat. Tag `<script>` internal cocok untuk halaman tunggal. File `.js` eksternal adalah standar industri untuk proyek nyata karena memisahkan kode dari struktur halaman.

## Cara Pengimplementasian
**Cara 1 — Console Browser:**
Buka browser (Chrome/Firefox/Edge), tekan `F12` atau `Ctrl+Shift+I`, klik tab "Console", lalu ketik:
```js
console.log("Halo dari console!");
```

**Cara 2 — Tag `<script>` di HTML:**
```html
<!DOCTYPE html>
<html>
<body>
  <script>
    console.log("Halo dari dalam HTML!");
  </script>
</body>
</html>
```

**Cara 3 — File `.js` Eksternal:**
Buat file `script.js`:
```js
console.log("Halo dari file eksternal!");
```
Panggil di HTML:
```html
<script src="script.js"></script>
```

## Analogi
Tiga cara menjalankan JavaScript seperti tiga cara menggunakan peralatan di rumah:
- **Console browser** = menyalakan lampu dengan saklar — instan, langsung bisa dicoba
- **Tag `<script>`** = memasang perangkat yang sudah terintegrasi di dinding — built-in
- **File `.js` eksternal** = membeli peralatan listrik dari toko lalu menyambungkannya — fleksibel dan bisa dipindah ke rumah lain

## Dipakai Untuk Apa
Console browser digunakan developer untuk debugging dan mencoba kode cepat. Tag `<script>` internal kadang dipakai untuk halaman landing sederhana. File eksternal adalah standar di proyek profesional — semua framework React, Vue, Angular menggunakan pendekatan file terpisah.

## Kesalahan Umum
Pemula sering lupa menuliskan tag `<script>` dengan urutan yang benar — script harus diletakkan sebelum tag `</body>` atau menggunakan atribut `defer` agar tidak memblokir rendering halaman. Juga sering terjadi kebingungan saat file `.js` tidak ditemukan karena path-nya salah.

## Keterkaitan dengan Materi Sebelumnya
Setelah mengenal apa itu JavaScript (materi 1), langkah berikutnya adalah tahu bagaimana cara "menyalakan" dan menjalankannya. Ini seperti setelah membeli peralatan listrik, kamu perlu tahu cara menyambungkannya ke sumber listrik.

## Soal Latihan
Sebutkan tiga cara menjalankan JavaScript dan kapan waktu yang tepat menggunakan masing-masing cara!
