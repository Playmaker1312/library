# 4. VS Code Setup

## Penjelasan
Visual Studio Code (VS Code) adalah code editor gratis dan open-source yang sangat populer untuk pengembangan JavaScript. Untuk memulai, instal VS Code dari code.visualstudio.com, lalu tambahkan ekstensi-esensial seperti Prettier (format kode otomatis), ESLint (deteksi error), Live Server (menjalankan HTML dengan auto-reload), dan JavaScript (ES6) code snippets. VS Code memiliki integrated terminal yang memudahkan menjalankan perintah tanpa meninggalkan editor.

## Fungsi
VS Code berfungsi sebagai "bengkel kerja" utama untuk menulis, mengedit, mengorganisir, dan men-debug kode JavaScript. Dengan ekstensi yang tepat, VS Code bisa mendeteksi error syntax, memformat kode secara otomatis, memberikan saran autocomplete, dan menjalankan kode langsung dari editor.

## Cara Pengimplementasian
1. Download dan install VS Code dari code.visualstudio.com
2. Buka VS Code, buka folder proyek: `File > Open Folder`
3. Install ekstensi penting:
   - Prettier — Code formatter
   - ESLint — Linter
   - Live Server — Auto-reload browser
4. Buat file baru `index.html` dan `script.js`
5. Klik kanan `index.html` > `Open with Live Server`
6. Buka console browser (F12) untuk melihat output

Contoh struktur folder:
```
projek-rumah/
├── index.html
├── style.css
└── script.js
```

## Analogi
VS Code adalah **bengkel kerja dan gudang alat rumah**. Di dalamnya ada semua peralatan yang kamu butuhkan: palu, obeng, gergaji (ekstensi), meja kerja (editor), dan lemari penyimpanan (file explorer). Tanpa bengkel yang rapi, membangun rumah akan berantakan. VS Code membantu kamu bekerja dengan terstruktur dan efisien.

## Dipakai Untuk Apa
VS Code digunakan developer untuk menulis dan mengelola kode setiap hari. Fitur seperti IntelliSense (autocomplete), debugging terintegrasi, Git integration, dan terminal bawaan membuat alur kerja menjadi sangat produktif. Live Server memungkinkan kamu melihat perubahan kode secara real-time di browser.

## Kesalahan Umum
Pemula sering melewatkan instalasi ekstensi penting sehingga coding menjadi tidak efisien. Juga sering terjadi kebingungan antara menyimpan file di lokasi yang salah atau tidak menyimpan file sama sekali sebelum menjalankannya (lupa Ctrl+S). Pastikan file `.js` sudah dipanggil dengan benar di HTML.

## Keterkaitan dengan Materi Sebelumnya
Setelah mengetahui apa itu JavaScript (materi 1), cara menjalankannya (materi 2), dan alat debugging (materi 3), sekarang kamu perlu lingkungan kerja yang nyaman. VS Code adalah "rumah" tempat kamu akan menulis dan mengelola semua kode JavaScript-mu.
