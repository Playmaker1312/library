# 3. console.log & Teman-temannya

## Penjelasan
`console.log()` adalah function bawaan JavaScript untuk mencetak output ke console browser. Selain `log`, ada juga `console.warn()` untuk peringatan, `console.error()` untuk error, `console.table()` untuk menampilkan data dalam bentuk tabel, `console.group()` untuk mengelompokkan log, dan `console.time()` / `console.timeEnd()` untuk mengukur waktu eksekusi. Semua ini adalah alat bantu debugging yang sangat penting.

## Fungsi
`console.log` dan teman-temannya berfungsi sebagai "jendela pengintai" ke dalam kode yang sedang berjalan. Kamu bisa melihat nilai variabel, melacak alur eksekusi, menemukan bug, dan mengukur performa kode. Ini adalah alat debugging paling dasar dan paling sering digunakan oleh semua developer JavaScript.

## Cara Pengimplementasian
```js
console.log("Ini log biasa");        // Output: Ini log biasa
console.warn("Ini peringatan!");     // Output kuning dengan ikon warning
console.error("Ini error!");         // Output merah dengan ikon error

const barang = [
  {nama: "Meja", harga: 500000},
  {nama: "Kursi", harga: 250000}
];
console.table(barang);               // Menampilkan tabel

console.time("Timer");
for (let i = 0; i < 1000000; i++) {}
console.timeEnd("Timer");            // Output: Timer: X ms
```

## Analogi
`console.log` seperti **papan informasi di pintu masuk rumah** yang memberitahu apa yang sedang terjadi di dalam. `console.warn` seperti stiker peringatan "Hati-hati lantai licin". `console.error` seperti alarm kebakaran. `console.table` seperti denah rumah yang terstruktur rapi. `console.time` seperti stopwatch untuk mengukur berapa lama waktu yang dibutuhkan untuk membersihkan ruangan.

## Dipakai Untuk Apa
Digunakan setiap hari oleh developer untuk debugging — melihat apakah suatu function dipanggil, apakah nilai variabel sudah benar, melacak urutan eksekusi kode, mengukur performa, dan menampilkan data kompleks dengan format yang mudah dibaca.

## Kesalahan Umum
Pemula sering meninggalkan `console.log` di kode produksi. Meskipun tidak merusak aplikasi, ini dianggap praktik buruk karena bisa membanjiri console dan membocorkan informasi internal. Gunakan `console.log` hanya untuk debugging dan hapus sebelum deploy ke produksi.

## Keterkaitan dengan Materi Sebelumnya
Setelah tahu cara menjalankan JavaScript (materi 2), kamu perlu alat untuk melihat hasil eksekusi kode. `console.log` adalah cara termudah untuk "melihat" apa yang dilakukan kode kamu — seperti menyalakan lampu di rumah lalu melihat isinya.
