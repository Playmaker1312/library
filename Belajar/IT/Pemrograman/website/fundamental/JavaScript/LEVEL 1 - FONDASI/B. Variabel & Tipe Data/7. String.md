# 7. String

## Penjelasan
String adalah tipe data untuk merepresentasikan teks. Di JavaScript, string ditulis dengan tanda kutip — bisa kutip tunggal (`'...'`), kutip ganda (`"..."`), atau backtick (`` `...` ``) untuk template literal. String memiliki berbagai method seperti `.length`, `.toUpperCase()`, `.toLowerCase()`, `.includes()`, `.slice()`, dan `.replace()`. Template literal memudahkan penggabungan string dengan ekspresi menggunakan `${...}`.

## Fungsi
String digunakan untuk menyimpan dan memanipulasi teks — nama pengguna, pesan error, URL, alamat, deskripsi produk, kode HTML, dan hampir semua data berbentuk teks. Method-method string memudahkan pencarian, pemotongan, penggabungan, dan transformasi teks.

## Cara Pengimplementasian
```js
const namaRumah = "Rumah Mawar";
const alamat = 'Jl. Melati No. 5';
// Template literal (backtick)
const deskripsi = `Rumah ${namaRumah} berlokasi di ${alamat}`;

console.log(deskripsi);
// Output: Rumah Rumah Mawar berlokasi di Jl. Melati No. 5

console.log(namaRumah.length);           // 11
console.log(namaRumah.toUpperCase());    // "RUMAH MAWAR"
console.log(namaRumah.includes("Mawar")); // true
console.log(namaRumah.slice(0, 5));      // "Rumah"
console.log(namaRumah.replace("Mawar", "Melati")); // "Rumah Melati"
```

## Analogi
String adalah **papan nama rumah dan semua tulisan di dalam rumah**. Ukuran papan nama (`.length`), mengecat ulang huruf besar/kecil (`.toUpperCase()`), mencari kata tertentu di papan (`.includes()`), memotong papan (`.slice()`), mengganti tulisan (`.replace()`). Template literal seperti papan nama yang bisa diisi dengan informasi dinamis — seperti papan digital yang menampilkan alamat dan nama pemilik secara otomatis.

## Dipakai Untuk Apa
Digunakan untuk validasi form (cek panjang password), manipulasi teks (format tanggal, filter kata kunci), generate HTML dinamis, parsing URL, menampilkan pesan ke user, dan hampir semua fitur yang melibatkan teks di aplikasi web.

## Kesalahan Umum
Kesalahan umum adalah mencampur kutip yang salah — memulai string dengan kutip tunggal dan mengakhirinya dengan kutip ganda akan error. Juga lupa menggunakan backtick saat perlu interpolasi variabel (menggabungkan string dengan `+` padahal bisa pakai `${}`). Perlu diingat bahwa string bersifat immutable — method seperti `.replace()` tidak mengubah string asli, melainkan mengembalikan string baru.
