# 5. var, let, const

## Penjelasan
`var`, `let`, dan `const` adalah tiga cara mendeklarasikan variabel di JavaScript. `var` adalah cara lama (sebelum ES6) dan memiliki scope function, bukan block. `let` adalah cara modern untuk variabel yang nilainya bisa berubah, dengan scope block. `const` digunakan untuk variabel yang nilainya tetap (konstan) dan tidak bisa di-reassign. Saat ini, `var` sudah jarang digunakan dan praktik terbaik adalah menggunakan `const` secara default, dan `let` jika memang nilainya perlu diubah.

## Fungsi
Variabel berfungsi seperti "kotak penyimpanan" untuk menampung data di memori. Dengan variabel, kamu bisa menyimpan nilai, memberi nama, dan mengaksesnya kembali nanti. `const` menjamin bahwa kotak penyimpanan tidak akan diganti dengan kotak lain, sementara `let` mengizinkan isi kotak diganti.

## Cara Pengimplementasian
```js
// var (hindari penggunaan)
var namaLama = "Rumah Tua";
namaLama = "Rumah Baru"; // Bisa diubah
console.log(namaLama);

// let (bisa diubah)
let kamar = "Kamar Tidur";
kamar = "Kamar Tamu"; // Bisa diubah
console.log(kamar);

// const (tidak bisa diubah)
const alamatRumah = "Jl. Merdeka No. 1";
// alamatRumah = "Jl. Baru"; // Error! Tidak bisa di-reassign
console.log(alamatRumah);
```

## Analogi
Variabel adalah **kotak-kotak penyimpanan di gudang rumah**.
- `var` = kotak kardus bekas (bisa dipindah-pindah seenaknya, berantakan)
- `let` = kotak plastik bening dengan label (rapi, bisa diganti isinya)
- `const` = lemari besi terkunci (sekali diisi, tidak bisa diganti barangnya)

## Dipakai Untuk Apa
Digunakan di hampir setiap baris kode JavaScript. `const` dipakai untuk menyimpan nilai tetap seperti konfigurasi, elemen DOM, atau reference ke object/array. `let` dipakai untuk counter loop, akumulator, atau nilai yang memang perlu diubah. `var` digunakan hampir tidak pernah lagi di kode modern.

## Kesalahan Umum
Mencoba mengubah nilai `const` adalah error paling umum. Pemula juga sering bingung dengan hoisting pada `var` — `var` bisa diakses sebelum dideklarasikan (nilainya `undefined`), sementara `let` dan `const` tidak bisa (ReferenceError). Gunakan `const` secara default untuk menghindari perubahan yang tidak disengaja.

## Soal Latihan
Apa perbedaan antara `let` dan `const`? Kapan sebaiknya menggunakan masing-masing?

<details>
<summary>Jawaban</summary>
`let` digunakan untuk variabel yang nilainya bisa berubah (reassignable), sedangkan `const` untuk variabel yang nilainya tetap (tidak bisa di-reassign). Praktik terbaik: gunakan `const` secara default, dan gunakan `let` hanya jika kamu tahu nilainya perlu diubah.
