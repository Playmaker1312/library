# 18. break & continue

## Penjelasan
`break` dan `continue` adalah dua keyword yang mengontrol alur eksekusi di dalam loop. `break` menghentikan loop sepenuhnya — eksekusi melompat keluar dari loop. `continue` menghentikan iterasi saat ini dan langsung melanjutkan ke iterasi berikutnya (melewati sisa kode di bawahnya). Keduanya bisa digunakan di `for`, `while`, `do-while`, dan `switch`.

## Fungsi
`break` berguna untuk menghentikan loop lebih awal ketika target sudah ditemukan (pruning — tidak perlu lanjut mencari). `continue` berguna untuk melewati iterasi yang tidak relevan atau tidak perlu diproses, tanpa menghentikan loop sepenuhnya.

## Cara Pengimplementasian
```js
// break: mencari kamar mandi di rumah — berhenti begitu ketemu
const ruangan = ["Tamu", "Tidur", "Mandi", "Dapur", "Garasi"];
for (let i = 0; i < ruangan.length; i++) {
  if (ruangan[i] === "Mandi") {
    console.log(`Kamar mandi ditemukan di indeks ${i}`);
    break; // Berhenti mencari — sudah ketemu
  }
  console.log(`Bukan kamar mandi: ${ruangan[i]}`);
}

// continue: membersihkan rumah — skip kamar yang sudah bersih
const kebersihanKamar = ["Kotor", "Bersih", "Kotor", "Kotor", "Bersih"];
for (let i = 0; i < kebersihanKamar.length; i++) {
  if (kebersihanKamar[i] === "Bersih") {
    console.log(`Kamar ${i + 1} sudah bersih — skip`);
    continue; // Lewati, lanjut ke kamar berikutnya
  }
  console.log(`Membersihkan kamar ${i + 1}...`);
}

// break di while
let dayaListrik = 100;
while (true) {
  dayaListrik -= 20;
  console.log(`Daya tersisa: ${dayaListrik}%`);
  if (dayaListrik <= 0) {
    console.log("Listrik padam!");
    break;
  }
}
```

## Analogi
**Berjalan di lorong rumah yang panjang.**
- **`break`:** Kamu sedang mencari kamar tidur. Begitu kamu membuka pintu dan melihat itu kamar tidur, kamu langsung berhenti — tidak perlu memeriksa kamar lainnya. Kamu keluar dari lorong itu.
- **`continue`:** Kamu sedang menyapu semua kamar. Kamu buka kamar pertama, sapu. Kamar kedua — ternyata masih ada orang tidur. Kamu lewati (continue), tutup pintu, lanjut ke kamar ketiga. Kamu tetap melanjutkan tugas, tapi melewati kamar yang tidak bisa dip roses sekarang.

## Dipakai Untuk Apa
`break`: pencarian data (berhenti setelah item ditemukan), validasi (berhenti jika satu item tidak valid), infinite loop yang dihentikan oleh kondisi tertentu. `continue`: filter data dalam loop (skip item yang tidak memenuhi kriteria), melewati nilai `null` atau `undefined` dalam array, memproses hanya item genap dalam deretan angka.

## Kesalahan Umum
Menggunakan `break` di dalam `if` di dalam `forEach` — `break` tidak bisa digunakan di `forEach`, hanya di loop tradisional (`for`, `while`, `do-while`). Juga menggunakan `continue` di dalam `switch` (yang sudah menggunakan `break`) — bisa membingungkan. Pastikan label loop jika menggunakan nested loop dengan `break` atau `continue`.

## Keterkaitan dengan Materi Sebelumnya
`break` dan `continue` beroperasi di dalam struktur loop (`for` — materi 16, `while`/`do-while` — materi 17) dan `switch` (materi 14). Konsep truthy/falsy (materi 12) digunakan dalam kondisi `if` yang memicu `break` atau `continue`.

## Soal Latihan
Buat array `["Kamar A", "Kamar B", "Gudang", "Kamar C", "Kamar D"]`. Gunakan loop dengan `continue` untuk skip "Gudang" dan `break` jika sudah membersihkan 3 kamar.

<details>
<summary>Jawaban</summary>

```js
const kamar = ["Kamar A", "Kamar B", "Gudang", "Kamar C", "Kamar D"];
let dibersihkan = 0;

for (let i = 0; i < kamar.length; i++) {
  if (kamar[i] === "Gudang") {
    console.log(`${kamar[i]} — skip, bukan kamar tidur`);
    continue;
  }
  console.log(`Membersihkan ${kamar[i]}...`);
  dibersihkan++;
  if (dibersihkan >= 3) {
    console.log("Cukup, 3 kamar sudah bersih!");
    break;
  }
}
```
