# 17. while & do-while

## Penjelasan
`while` dan `do-while` adalah dua struktur perulangan yang berbasis kondisi, bukan counter. `while` mengecek kondisi terlebih dahulu sebelum menjalankan blok kode — jika kondisi awal sudah `false`, blok tidak pernah dijalankan. `do-while` menjalankan blok kode setidaknya sekali, baru mengecek kondisi setelahnya. Keduanya terus berulang selama kondisi bernilai `true`.

## Fungsi
Kedua loop ini cocok ketika jumlah iterasi tidak diketahui sebelumnya — misalnya, menunggu input pengguna, membaca data hingga habis, atau mengulang hingga suatu kondisi terpenuhi. `while` lebih umum digunakan; `do-while` digunakan ketika kamu ingin menjamin blok kode dijalankan minimal satu kali.

## Cara Pengimplementasian
```js
// while: mengecat rumah — berhenti saat cat habis
let stokCat = 3;
while (stokCat > 0) {
  console.log(`Mengecat dinding... sisa cat: ${stokCat}`);
  stokCat--;
}
console.log("Cat habis, beli lagi!");

// do-while: cek pintu rumah — setidaknya sekali
let pintuTerkunci;
do {
  pintuTerkunci = Math.random() > 0.5;
  console.log(pintuTerkunci ? "Pintu terkunci" : "Pintu terbuka");
} while (pintuTerkunci);
console.log("Akhirnya pintu terbuka!");

// while dengan flag
let sedangRenovasi = true;
let hari = 0;
while (sedangRenovasi) {
  hari++;
  console.log(`Hari ke-${hari}: renovasi berjalan...`);
  if (hari >= 5) {
    sedangRenovasi = false;
    console.log("Renovasi selesai!");
  }
}
```

## Analogi
- **`while`:** **Membuka pintu rumah yang terkunci.** Kamu cek dulu apakah pintu terkunci (`while (terkunci)`). Jika iya, kamu coba kunci lagi. Jika tidak, kamu masuk. Kalau dari awal sudah tidak terkunci, kamu langsung masuk tanpa perlu coba-coba.
- **`do-while`:** **Mengetuk pintu sebelum masuk.** Kamu ketuk dulu sekali (blok kode jalan), lalu dengar apakah ada jawaban (kondisi). Jika tidak ada jawaban, kamu ketuk lagi. Minimal kamu sudah mengetuk satu kali, tidak seperti `while` yang mungkin tidak mengetuk sama sekali.

## Dipakai Untuk Apa
Validasi input berulang (minta user input sampai valid), polling status server (ulang sampai dapat response), membaca file stream sampai habis, game loop (ulang selama game belum selesai), koneksi ulang otomatis, dan animasi berbasis kondisi.

## Kesalahan Umum
Infinite loop karena kondisi tidak pernah berubah menjadi `false` — pastikan ada statement di dalam loop yang memengaruhi kondisi. Juga lupa bahwa `while` mungkin tidak menjalankan blok sama sekali jika kondisi awal `false`, padahal kamu mungkin ingin blok dijalankan minimal sekali (saat itulah pakai `do-while`).

## Keterkaitan dengan Materi Sebelumnya
Sama seperti `for`, `while` dan `do-while` menggunakan truthy/falsy (materi 12) untuk mengevaluasi kondisi. Operator perbandingan (materi 10) dan logika (materi 11) digunakan untuk membentuk kondisi yang kompleks. Variabel (materi 5) menyimpan state yang dimodifikasi di dalam loop.

## Soal Latihan
Buat `while` loop yang mensimulasikan mengecek setiap kamar di rumah sampai menemukan kamar yang berisi kucing. Gunakan array `["Kosong", "Kosong", "Kucing", "Kosong"]`.

<details>
<summary>Jawaban</summary>

```js
const kamar = ["Kosong", "Kosong", "Kucing", "Kosong"];
let i = 0;

while (i < kamar.length && kamar[i] !== "Kucing") {
  console.log(`Kamar ${i + 1}: ${kamar[i]}`);
  i++;
}

if (i < kamar.length) {
  console.log(`Kucing ditemukan di kamar ${i + 1}!`);
} else {
  console.log("Kucing tidak ditemukan");
}
```
