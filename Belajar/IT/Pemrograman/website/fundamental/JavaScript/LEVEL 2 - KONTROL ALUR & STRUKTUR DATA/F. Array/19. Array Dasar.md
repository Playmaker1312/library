# 19. Array Dasar

## Penjelasan
Array adalah struktur data yang menyimpan kumpulan nilai dalam satu variabel, diurutkan berdasarkan indeks numerik (dimulai dari 0). Array bisa menampung tipe data apa pun — number, string, boolean, object, bahkan array lain. Di JavaScript, array bersifat dinamis: ukurannya bisa berubah setelah dibuat. Array dideklarasikan dengan tanda kurung siku `[]` dan elemen dipisahkan dengan koma.

## Fungsi
Array memungkinkan penyimpanan dan pengelolaan data yang berurutan dan terstruktur. Tanpa array, kamu harus membuat variabel terpisah untuk setiap item (bayangkan `kamar1`, `kamar2`, `kamar3`...). Array memberikan kemampuan untuk mengakses, menambah, menghapus, dan memanipulasi koleksi data dengan efisien.

## Cara Pengimplementasian
```js
// Membuat array
const rumah = ["Ruang Tamu", "Kamar Tidur", "Dapur", "Kamar Mandi"];
console.log(rumah); // ["Ruang Tamu", "Kamar Tidur", "Dapur", "Kamar Mandi"]

// Akses elemen — indeks mulai dari 0
console.log(rumah[0]); // "Ruang Tamu"
console.log(rumah[2]); // "Dapur"
console.log(rumah[4]); // undefined (tidak ada)

// Mengubah elemen
rumah[1] = "Kamar Utama";
console.log(rumah); // ["Ruang Tamu", "Kamar Utama", "Dapur", "Kamar Mandi"]

// Properti penting
console.log(rumah.length); // 4 — jumlah elemen
console.log(rumah[rumah.length - 1]); // "Kamar Mandi" — elemen terakhir

// Array dengan berbagai tipe data
const campuran = ["Garasi", 2, true, null, { ukuran: 20 }];
```

## Analogi
**Rak sepatu — koleksi berurut.** Bayangkan rak sepatu di teras rumah yang memiliki 4 slot bernomor. Slot 0 adalah sepatu olahraga, slot 1 adalah sepatu kerja, slot 2 adalah sandal, slot 3 adalah sepatu hujan. Kamu bisa mengambil sepatu dari slot tertentu (akses indeks), mengganti sepatu di slot tertentu (ubah elemen), menambah slot baru di ujung (push), atau mengeluarkan sepatu dari tengah (splice). Setiap sepatu punya posisi tetap berdasarkan urutan.

## Dipakai Untuk Apa
Menyimpan daftar barang (daftar belanja, inventaris rumah), kumpulan data dari API (daftar pengguna, produk), urutan langkah (tahapan renovasi), koordinat (peta rumah), dan semua data yang membutuhkan urutan atau indeks.

## Kesalahan Umum
Lupa bahwa indeks array dimulai dari 0, bukan 1 — sehingga elemen terakhir ada di `array[length - 1]`. Juga mengira `const` array berarti tidak bisa diubah — `const` hanya mencegah reassignment, tapi isi array tetap bisa dimodifikasi. Mengakses indeks yang tidak ada mengembalikan `undefined`, bukan error.

## Keterkaitan dengan Materi Sebelumnya
Array adalah tipe data object dalam JavaScript (materi 6). Elemen array bisa berupa tipe data primitif (materi 6) atau object. Array sering digunakan dengan loop (materi 16-18) untuk memproses setiap elemennya. `const` (materi 5) digunakan untuk deklarasi array.
