# 20. Array Methods — forEach, map, filter, reduce

## Penjelasan
Empat method array ini adalah fondasi pemrograman fungsional di JavaScript. `forEach` menjalankan fungsi untuk setiap elemen (seperti loop, tapi lebih deklaratif). `map` mentransformasi setiap elemen dan mengembalikan array baru dengan panjang yang sama. `filter` menyaring elemen berdasarkan kondisi dan mengembalikan array baru dengan elemen yang lolos. `reduce` mereduksi seluruh array menjadi satu nilai (angka, object, array baru, dll) dengan akumulator.

## Fungsi
Method-method ini memungkinkan manipulasi array dengan kode yang lebih bersih, lebih mudah dibaca, dan bebas dari efek samping (immutable — tidak mengubah array asli, kecuali `forEach`). Mereka menggantikan loop `for` tradisional untuk sebagian besar kasus dan merupakan gaya yang dominan di kode JavaScript modern.

## Cara Pengimplementasian
```js
const ruangan = ["Tamu", "Tidur", "Dapur", "Mandi"];

// forEach — seperti berjalan dan melihat setiap ruangan
ruangan.forEach((ruang, index) => {
  console.log(`${index + 1}. ${ruang}`);
});

// map — mengubah setiap ruangan menjadi ukurannya (m²)
const ukuran = ruangan.map(ruang => `${ruang}: 20m²`);
console.log(ukuran);
// ["Tamu: 20m²", "Tidur: 20m²", "Dapur: 20m²", "Mandi: 20m²"]

// filter — hanya ruangan yang namanya mengandung huruf 'a'
const berisiA = ruangan.filter(ruang => ruang.includes("a"));
console.log(berisiA); // ["Tamu", "Dapur", "Mandi"]

// reduce — menghitung total luas rumah
const luasPerRuangan = [15, 20, 10, 8];
const totalLuas = luasPerRuangan.reduce((akumulator, luas) => {
  return akumulator + luas;
}, 0);
console.log(totalLuas); // 53

// Chaining — menggabungkan method
const angka = [1, 2, 3, 4, 5, 6];
const hasil = angka
  .filter(n => n % 2 === 0)   // [2, 4, 6]
  .map(n => n * 10)           // [20, 40, 60]
  .reduce((a, b) => a + b, 0); // 120
console.log(hasil); // 120
```

## Analogi
**Empat tugas berbeda di dalam rumah:**
- **`forEach`:** Kamu masuk ke setiap kamar, lihat sekilas, catat apa yang ada — kamu hanya mengamati, tidak mengubah apa pun.
- **`map`:** Kamu mengganti lampu di setiap kamar dengan lampu LED — setiap kamar mendapat perubahan yang sama, dan setelah selesai kamu punya "rumah baru" dengan lampu baru.
- **`filter`:** Kamu hanya masuk ke kamar yang pintunya terbuka — kamu menyaringnya dari semua kamar yang ada.
- **`reduce`:** Kamu mengumpulkan semua barang berharga dari setiap kamar ke dalam satu kardus besar — semua barang dari seluruh rumah jadi satu.

## Dipakai Untuk Apa
`forEach`: logging, efek samping (menyimpan ke database), rendering UI per item. `map`: transformasi data (mengubah format tanggal, menambah properti). `filter`: pencarian, penyaringan berdasarkan kriteria. `reduce`: aggregasi data (total, rata-rata, grouping, flatten array).

## Kesalahan Umum
Lupa bahwa `map` dan `filter` mengembalikan array baru — jika tidak ditangkap dalam variabel, hasilnya hilang. Juga lupa memberikan nilai awal (initial value) pada `reduce` — jika array kosong tanpa initial value, akan error. `forEach` tidak bisa dihentikan dengan `break` — gunakan `for...of` atau `some` jika perlu berhenti di tengah.

## Keterkaitan dengan Materi Sebelumnya
Method-method ini menerima callback function sebagai argumen — konsep fungsi yang akan dipelajari lebih dalam di Level 3. Mereka menggunakan array (materi 19) sebagai basis. Operator perbandingan (materi 10) digunakan dalam kondisi `filter`. Arrow function (panah) sering digunakan bersama method ini.

## Soal Latihan
Dari array `[3, 7, 1, 9, 4, 6]`, gunakan chaining `filter` (ambil angka ganjil), `map` (kalikan 2), dan `reduce` (jumlahkan semua).

```js
const angka = [3, 7, 1, 9, 4, 6];
const hasil = angka
  .filter(n => n % 2 !== 0)   // [3, 7, 1, 9]
  .map(n => n * 2)            // [6, 14, 2, 18]
  .reduce((a, b) => a + b, 0); // 40
console.log(hasil); // 40
```
