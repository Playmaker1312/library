# 23. Object Dasar

## Penjelasan
Object adalah struktur data yang menyimpan koleksi properti dalam bentuk pasangan key-value (kunci-nilai). Key adalah string (atau Symbol), dan value bisa berupa tipe data apa pun (number, string, boolean, array, object lain, bahkan fungsi). Object dideklarasikan dengan kurung kurawal `{}`. Tidak seperti array yang terurut berdasarkan indeks, object tidak terurut — data diakses melalui key, bukan posisi.

## Fungsi
Object memungkinkan representasi data yang kompleks dan terstruktur dengan makna semantik. Daripada menyimpan `"Rumah", 2020, 150` dalam array tanpa konteks, object menyimpan `{nama: "Rumah", tahun: 2020, luas: 150}` — jelas properti apa yang dimaksud apa nilainya. Object adalah fondasi dari hampir semua struktur data di JavaScript.

## Cara Pengimplementasian
```js
// Membuat object literal
const rumahSaya = {
  nama: "Rumah Impian",
  tahunDibangun: 2020,
  luasTanah: 150,
  adaGarasi: true
};
console.log(rumahSaya);

// Akses properti — dua cara
console.log(rumahSaya.nama);        // "Rumah Impian" — dot notation
console.log(rumahSaya["luasTanah"]); // 150 — bracket notation

// Mengubah properti
rumahSaya.nama = "Rumah Keluarga";
rumahSaya["luasTanah"] = 200;

// Menambah properti baru
rumahSaya.alamat = "Jl. Sejahtera No. 1";
rumahSaya["jumlahKamar"] = 4;

// Menghapus properti
delete rumahSaya.adaGarasi;
console.log(rumahSaya);

// Object dengan properti bertipe object/array
const rumahLengkap = {
  pemilik: { nama: "Budi", umur: 30 },
  kamar: ["Tidur", "Mandi", "Tamu"],
  luas: 200
};
console.log(rumahLengkap.pemilik.nama); // "Budi"
```

## Analogi
**Lemari dengan laci berlabel.** Bayangkan sebuah lemari besar di rumah. Setiap laci punya label: "Pakaian", "Dokumen", "Alat Tulis", "Obat-obatan". Kamu bisa membuka laci "Pakaian" untuk mengambil isinya (akses properti), menaruh barang baru di laci "Elektronik" (tambah properti), atau mengganti isi laci "Dokumen" dengan yang baru (ubah properti). Kamu mencari barang berdasarkan labelnya, bukan nomor lacinya — persis seperti object yang diakses via key, bukan indeks.

## Dipakai Untuk Apa
Representasi data dunia nyata (pengguna, produk, rumah, mobil), konfigurasi aplikasi, parameter fungsi, response API, menyimpan state di aplikasi (React state, Vue data), dan semua data yang memiliki properti bernama.

## Kesalahan Umum
Menggunakan dot notation untuk key yang mengandung spasi atau karakter khusus — harus bracket notation (`obj["properti dengan spasi"]`). Juga mengira bahwa dua object dengan isi sama adalah equal — `{a:1} == {a:1}` adalah `false` karena mereka object berbeda di memori. Lupa bahwa `const` pada object hanya mencegah reassignment, bukan mutasi properti.

## Keterkaitan dengan Materi Sebelumnya
Object adalah tipe data non-primitif (materi 6). Nilai properti bisa berupa tipe data primitif (materi 6), array (materi 19), atau object lain. Operator `typeof` (materi 2) mengembalikan `"object"` untuk object. Variabel `const` (materi 5) sering digunakan untuk object.

## Soal Latihan
Buat object `rumah` dengan properti: nama, luas, jumlahKamar, dan alamat. Cetak nama rumah, ubah luas menjadi 300, tambah properti `warnaCat: "Putih"`, lalu hapus alamat.

<summary>Jawaban</summary>

```js
const rumah = {
  nama: "Rumah Biru",
  luas: 150,
  jumlahKamar: 3,
  alamat: "Jl. Mawar No. 5"
};

console.log(rumah.nama); // "Rumah Biru"
rumah.luas = 300;
rumah.warnaCat = "Putih";
delete rumah.alamat;
console.log(rumah); // { nama: "Rumah Biru", luas: 300, jumlahKamar: 3, warnaCat: "Putih" }
```
