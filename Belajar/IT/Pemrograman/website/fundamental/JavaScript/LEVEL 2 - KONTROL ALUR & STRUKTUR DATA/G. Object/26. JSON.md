# 26. JSON

## Penjelasan
JSON (JavaScript Object Notation) adalah format teks ringan untuk menyimpan dan mengirim data terstruktur. Meskipun mirip dengan object JavaScript, JSON memiliki aturan lebih ketat: semua key harus diapit tanda kutip ganda (`"`), string value juga harus kutip ganda, tidak ada komentar, tidak boleh ada fungsi atau `undefined`, dan tipe data yang didukung terbatas (string, number, boolean, null, array, object). JSON bersifat language-independent — bisa digunakan di JavaScript, Python, PHP, dan bahasa lain.

## Fungsi
JSON adalah format universal untuk pertukaran data antara server dan klien (web API), konfigurasi aplikasi (`package.json`, `tsconfig.json`), penyimpanan data lokal (`localStorage`), dan komunikasi antar sistem yang berbeda bahasa pemrograman. Hampir semua API modern menggunakan JSON sebagai format response.

## Cara Pengimplementasian
```js
// Object JavaScript
const rumah = {
  nama: "Rumah Biru",
  luas: 200,
  kamar: 4,
  adaGarasi: true,
  fasilitas: ["AC", "TV", "Kulkas"],
  alamat: {
    jalan: "Jl. Anggrek No. 5",
    kota: "Jakarta"
  }
};

// Convert object JavaScript ke JSON string — JSON.stringify()
const jsonString = JSON.stringify(rumah);
console.log(jsonString);
// {"nama":"Rumah Biru","luas":200,"kamar":4,"adaGarasi":true,
//  "fasilitas":["AC","TV","Kulkas"],"alamat":{"jalan":"Jl. Anggrek No. 5","kota":"Jakarta"}}

// JSON string yang dikirim dari server / API
const responseAPI = `{
  "nama": "Rumah Hijau",
  "luas": 150,
  "kamar": 3
}`;

// Convert JSON string ke object JavaScript — JSON.parse()
const parsedData = JSON.parse(responseAPI);
console.log(parsedData.nama); // "Rumah Hijau"
console.log(parsedData.luas); // 150

// JSON dengan formatting (pretty print)
console.log(JSON.stringify(rumah, null, 2));
// {
//   "nama": "Rumah Biru",
//   "luas": 200,
//   ...
// }

// Simpan ke localStorage dan baca kembali
localStorage.setItem("rumahSaya", JSON.stringify(rumah));
const stored = JSON.parse(localStorage.getItem("rumahSaya"));
console.log(stored.nama); // "Rumah Biru"
```

## Analogi
**Blueprint rumah untuk dikirim ke arsitek.** Kamu memiliki rumah dalam bentuk fisik (object JavaScript di memori). Untuk mengirim detail rumah ke arsitek di kota lain, kamu harus menggambarnya dalam bentuk blueprint (JSON string) — format standar yang bisa dibaca siapa pun. Arsitek menerima blueprint itu lalu membangun ulang rumah versi digitalnya (parse JSON). Blueprint tidak bisa berisi benda fisik seperti furnitur (fungsi/undefined) — hanya informasi tertulis (string, number, boolean, dll).

## Dipakai Untuk Apa
Mengirim/menerima data dari REST API (`fetch('/api/rumah').then(r => r.json())`), menyimpan data pengguna di `localStorage`, file konfigurasi (`package.json`), komunikasi WebSocket, export/import data, dan pertukaran data antar layanan mikro.

## Kesalahan Umum
Lupa bahwa JSON key harus pakai kutip ganda — `{nama: "Rumah"}` valid di JS tapi tidak valid di JSON. Juga meninggalkan trailing comma — `[1, 2, 3,]` valid di JS tapi error di JSON. Menggunakan `undefined` sebagai nilai — JSON.stringify mengubahnya menjadi `null` atau menghapus properti tersebut. `JSON.parse` dengan string yang tidak valid akan melempar error — selalu bungkus dengan `try/catch`.

## Keterkaitan dengan Materi Sebelumnya
JSON secara visual mirip dengan object JavaScript (materi 23) dan array (materi 19). Tipe data primitif (materi 6) menjadi nilai dalam JSON. `JSON.stringify` dan `JSON.parse` adalah fungsi bawaan yang menggunakan konsep konversi tipe (type coercion — materi 8). JSON adalah jembatan antara JavaScript (client) dan dunia luar.
