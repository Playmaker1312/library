# 24. Object Methods & Iterasi

## Penjelasan
JavaScript menyediakan beberapa method bawaan untuk bekerja dengan object. `Object.keys()` mengembalikan array berisi semua key/nama properti. `Object.values()` mengembalikan array berisi semua nilai. `Object.entries()` mengembalikan array berisi pasangan `[key, value]`. Untuk iterasi, `for...in` loop bisa digunakan untuk遍历 semua properti enumerable (termasuk yang diwarisi dari prototype). `hasOwnProperty()` mengecek apakah properti milik object itu sendiri (bukan warisan).

## Fungsi
Method-method ini memungkinkan konversi object ke array untuk dip roses dengan method array seperti `map`, `filter`, `forEach`. `for...in` berguna ketika kamu perlu iterasi properti object tanpa tahu nama propertinya sebelumnya. Ini sangat penting untuk debugging, manipulasi data dinamis, dan serialisasi.

## Cara Pengimplementasian
```js
const rumah = {
  nama: "Rumah Idaman",
  luas: 200,
  kamar: 4,
  warnaCat: "Biru"
};

// Object.keys() — dapatkan daftar properti
const properti = Object.keys(rumah);
console.log(properti); // ["nama", "luas", "kamar", "warnaCat"]

// Object.values() — dapatkan daftar nilai
const nilai = Object.values(rumah);
console.log(nilai); // ["Rumah Idaman", 200, 4, "Biru"]

// Object.entries() — dapatkan pasangan [key, value]
const entries = Object.entries(rumah);
console.log(entries);
// [["nama", "Rumah Idaman"], ["luas", 200], ["kamar", 4], ["warnaCat", "Biru"]]

// entries + forEach — iterasi elegan
Object.entries(rumah).forEach(([key, value]) => {
  console.log(`${key}: ${value}`);
});

// for...in loop — iterasi semua properti
for (const key in rumah) {
  if (rumah.hasOwnProperty(key)) {
    console.log(`${key} -> ${rumah[key]}`);
  }
}

// Konversi object ke array lalu transformasi
const daftarProperti = Object.entries(rumah).map(([k, v]) => {
  return `${k}: ${typeof v === 'number' ? v + ' unit' : v}`;
});
console.log(daftarProperti);
// ["nama: Rumah Idaman", "luas: 200 unit", "kamar: 4 unit", "warnaCat: Biru"]
```

## Analogi
**Buku inventaris rumah.**
- **`Object.keys()`:** Kamu membuka buku inventaris dan hanya membaca daftar labelnya: "Nama Rumah", "Luas", "Kamar", "Warna Cat".
- **`Object.values()`:** Kamu membaca daftar isinya saja: "Rumah Idaman", 200, 4, "Biru".
- **`Object.entries()`:** Kamu membaca buku baris per baris: baris 1 "Nama Rumah: Rumah Idaman", baris 2 "Luas: 200", dst.
- **`for...in`:** Kamu berkeliling rumah, melihat satu per satu properti — "Ini namanya Rumah Idaman, ini luasnya 200 meter..." — tanpa melewatkan satu pun.

## Dipakai Untuk Apa
Debugging (melihat semua properti object), transformasi data (mengubah object ke format yang dibutuhkan API), validasi dinamis (cek apakah semua field terisi), cloning object, rendering tabel dinamis, dan serialisasi data.

## Kesalahan Umum
Menggunakan `for...in` untuk array — meskipun bisa (karena array adalah object), hasilnya tidak terduga dan tidak disarankan. Juga lupa bahwa `for...in` juga meng iterasi properti dari prototype chain — selalu gunakan `hasOwnProperty()` untuk memfilternya. `Object.keys()` tidak menjamin urutan di semua engine (meskipun modern engine mengurutkan secara insertion order).

## Keterkaitan dengan Materi Sebelumnya
Method ini mengubah object (materi 23) menjadi array (materi 19), yang kemudian bisa dip roses dengan method array seperti `forEach`, `map` (materi 20). Konsep truthy/falsy (materi 12) digunakan dalam validasi dengan `hasOwnProperty`.

## Soal Latihan
Buat object `inventarisRumah` dengan 3 properti. Gunakan `Object.entries()` dan `forEach` untuk mencetak setiap properti dalam format: "Properti [key] bernilai [value]".

<summary>Jawaban</summary>

```js
const inventarisRumah = {
  meja: 4,
  kursi: 8,
  lampu: 6
};

Object.entries(inventarisRumah).forEach(([key, value]) => {
  console.log(`Properti ${key} bernilai ${value}`);
});
// "Properti meja bernilai 4"
// "Properti kursi bernilai 8"
// "Properti lampu bernilai 6"
```
