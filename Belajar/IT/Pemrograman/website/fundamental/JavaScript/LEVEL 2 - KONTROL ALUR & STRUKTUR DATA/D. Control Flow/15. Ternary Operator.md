# 15. Ternary Operator

## Penjelasan
Ternary operator (`condition ? exprIfTrue : exprIfFalse`) adalah satu-satunya operator JavaScript yang menerima tiga operand. Ini adalah cara singkat untuk menulis `if/else` dalam satu baris — operator ini mengevaluasi kondisi, lalu mengembalikan ekspresi pertama jika truthy, atau ekspresi kedua jika falsy. Ternary bukan pengganti `if/else` untuk semua situasi, melainkan alat untuk assignment atau return bersyarat yang ringkas.

## Fungsi
Mempersingkat kode ketika kamu perlu memilih antara dua nilai berdasarkan suatu kondisi, terutama untuk assignment variabel, return value dari fungsi, atau template string. Ternary membuat kode lebih padat dan ekspresif — asalkan kondisinya sederhana.

## Cara Pengimplementasian
```js
const sudahMandi = true;
const status = sudahMandi ? "Wangii ✨" : "Belum mandi 😅";
console.log(status); // "Wangii ✨"

// Bersarang (nested ternary) — hati-hati dengan readability
const suhu = 25;
const aktivitas = suhu < 20 ? "Pakai selimut" :
                  suhu <= 28 ? "Santai" :
                  "Nyalakan AC";
console.log(aktivitas); // "Santai"

// Ternary di template literal
const jam = 14;
const salam = `Selamat ${jam < 12 ? "pagi" : jam < 18 ? "siang" : "malam"}`;
console.log(salam); // "Selamat siang"

// Ternary untuk return
function izinMasuk(umur) {
  return umur >= 17 ? "Silakan masuk" : "Ditemani orang tua";
}
console.log(izinMasuk(15)); // "Ditemani orang tua"
```

## Analogi
**Memilih antara dua pintu di rumah.** Kamu berdiri di depan dua pintu: kiri dan kanan. Jika lampu hijau menyala (`condition` true), kamu buka pintu kiri (`exprIfTrue`). Jika merah (`condition` false), kamu buka pintu kanan (`exprIfFalse`). Tidak ada jalan tengah, tidak ada proses panjang — langsung pilih salah satu dan dapatkan hasilnya.

## Dipakai Untuk Apa
Memberi nilai default (`const warna = userWarna || "putih"` bisa juga pakai `||`, tapi ternary untuk kasus yang lebih eksplisit), menentukan teks tombol berdasarkan state (`simpan ? "Menyimpan..." : "Simpan"`), render kondisional di React/UI, validasi singkat (`umur >= 17 ? "Dewasa" : "Anak-anak"`).

## Kesalahan Umum
Terlalu banyak nested ternary yang membuat kode sulit dibaca — jika butuh lebih dari 2 level, lebih baik pakai `if/else` biasa atau `switch`. Juga menggunakan ternary untuk mengeksekusi beberapa statement (bukan mengembalikan nilai) — ternary seharusnya untuk expression, bukan statement. Contoh salah: `kondisi ? doA() : doB()` — ini bisa dilakukan tapi lebih baik pakai `if/else`.

## Keterkaitan dengan Materi Sebelumnya
Ternary adalah operator (seperti operator di materi 9-12) yang memanfaatkan konsep truthy/falsy (materi 12) untuk mengevaluasi kondisi. Nilai yang dihasilkan bisa berupa tipe data apa pun (materi 6) dan bisa langsung di-assign ke variabel (materi 5).

## Soal Latihan
Gunakan ternary operator untuk menentukan apakah sebuah rumah layak huni berdasarkan luas (minimal 30 m²) dan memiliki atap. Hasilkan string "Layak huni" atau "Tidak layak huni".

<summary>Jawaban</summary>

```js
const luas = 45;
const adaAtap = true;
const hasil = luas >= 30 && adaAtap ? "Layak huni" : "Tidak layak huni";
console.log(hasil); // "Layak huni"
```
