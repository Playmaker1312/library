# 14. switch-case

## Penjelasan
`switch-case` adalah struktur percabangan yang mengevaluasi satu ekspresi dan mencocokkan nilainya dengan beberapa kemungkinan kasus (`case`). Setiap `case` diikuti oleh nilai yang akan dibandingkan (menggunakan strict comparison `===`). Jika cocok, kode di dalam `case` tersebut dijalankan hingga menemukan `break`. Jika tidak ada `case` yang cocok, blok `default` akan dijalankan (jika ada). Tanpa `break`, eksekusi akan "jatuh" (fall-through) ke case berikutnya.

## Fungsi
`switch-case` digunakan ketika ada satu variabel atau ekspresi yang perlu dibandingkan dengan banyak nilai tetap. Ini lebih rapi dan lebih mudah dibaca daripada rantai `if/else if` yang panjang, terutama ketika semua percabangan bergantung pada nilai yang sama.

## Cara Pengimplementasian
```js
const lantai = 2;

switch (lantai) {
  case 1:
    console.log("Lantai 1: Ruang tamu, dapur, garasi");
    break;
  case 2:
    console.log("Lantai 2: Kamar tidur, kamar mandi");
    break;
  case 3:
    console.log("Lantai 3: Loteng, balkon");
    break;
  default:
    console.log("Lantai tidak dikenal — rumah hanya 3 lantai");
}

// Fall-through yang disengaja
const peran = "tamu";
switch (peran) {
  case "pemilik":
  case "penghuni":
    console.log("Akses penuh ke semua ruangan");
    break;
  case "tamu":
    console.log("Akses terbatas: ruang tamu dan kamar mandi");
    break;
  default:
    console.log("Tidak diizinkan masuk");
}
```

## Analogi
**Papan petunjuk arah di dalam rumah.** Kamu berdiri di persimpangan lorong dan melihat papan: "Jika tamu → ruang tamu (case 1). Jika keluarga → ruang keluarga (case 2). Jika pengantar paket → teras (case 3). Jika tidak ada yang cocok → keluar (default)." Kamu tidak perlu mengecek satu per satu dengan if/else — langsung lihat papan dan ambil jalur yang sesuai.

## Dipakai Untuk Apa
Menangani aksi berdasarkan input pengguna (misalnya menu: "1. Lihat, 2. Tambah, 3. Hapus"), parsing kode status HTTP, mengelola state mesin (state machine), routing halaman sederhana, dan penanganan tipe data yang terbatas jumlahnya.

## Kesalahan Umum
Lupa menulis `break` sehingga terjadi fall-through yang tidak disengaja — kode di case berikutnya ikut dijalankan. Juga lupa bahwa `switch` menggunakan strict comparison (`===`), jadi `switch("1")` tidak akan cocok dengan `case 1`. Terlalu banyak `case` yang serupa mungkin lebih baik ditangani dengan `if/else` atau object lookup.

## Keterkaitan dengan Materi Sebelumnya
`switch-case` menggunakan operator perbandingan strict `===` (materi 10) secara implisit. Nilai yang dibandingkan biasanya bertipe string atau number (materi 6). Konsep truthy/falsy (materi 12) tidak berlaku di sini karena perbandingan bersifat eksplisit.
