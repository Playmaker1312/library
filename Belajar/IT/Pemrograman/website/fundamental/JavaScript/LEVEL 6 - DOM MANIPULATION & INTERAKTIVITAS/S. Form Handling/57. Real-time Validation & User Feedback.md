# 57. Real-time Validation & User Feedback

## Penjelasan
Daripada menunggu submit, validasi real-time memberikan umpan balik langsung saat pengguna mengetik — mirip satpam yang langsung mengingatkan saat ada data tamu yang salah saat diisi.

## Fungsi
Memberi tahu pengguna dengan cepat apakah input valid, tanpa harus menunggu tombol submit ditekan.

## Cara Pengimplementasian
```html
<!DOCTYPE html>
<html>
<head>
  <style>
    .input-group { margin-bottom: 12px; }
    .error { color: red; font-size: 0.85em; display: none; }
    .input-group input:invalid,
    .input-group input.error-border { border: 2px solid red; }
    .input-group input.valid-border { border: 2px solid green; }
    .feedback { padding: 8px; border-radius: 4px; margin-top: 4px; display: none; }
    .feedback.success { background: #d4edda; color: #155724; display: block; }
    .feedback.error { background: #f8d7da; color: #721c24; display: block; }
  </style>
</head>
<body>
  <h1>🏠 Registrasi Tamu — Real-time</h1>

  <form id="formTamu">
    <div class="input-group">
      <label>Nama Lengkap (min 3 karakter):</label>
      <input type="text" id="nama" required>
      <div class="error" id="errorNama">Nama minimal 3 karakter</div>
    </div>

    <div class="input-group">
      <label>Email:</label>
      <input type="email" id="email">
      <div class="error" id="errorEmail">Email tidak valid</div>
    </div>

    <div class="input-group">
      <label>Nomor Telepon:</label>
      <input type="text" id="telepon" placeholder="08123456789">
      <div class="error" id="errorTelepon">Nomor harus 10-13 digit angka</div>
    </div>

    <div class="input-group">
      <label>Usia (17-100):</label>
      <input type="number" id="usia" min="17" max="100">
      <div class="error" id="errorUsia">Usia harus 17-100 tahun</div>
    </div>

    <div id="feedbackGlobal" class="feedback">Semua data valid ✅</div>
    <button type="submit">Daftar</button>
  </form>

  <script>
    // Validasi real-time — seperti satpam yang ngecek data sambil jalan
    const fields = {
      nama: {
        element: document.getElementById('nama'),
        error: document.getElementById('errorNama'),
        validate: (v) => v.trim().length >= 3
      },
      email: {
        element: document.getElementById('email'),
        error: document.getElementById('errorEmail'),
        validate: (v) => !v || /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(v)
      },
      telepon: {
        element: document.getElementById('telepon'),
        error: document.getElementById('errorTelepon'),
        validate: (v) => !v || /^\d{10,13}$/.test(v)
      },
      usia: {
        element: document.getElementById('usia'),
        error: document.getElementById('errorUsia'),
        validate: (v) => !v || (parseInt(v) >= 17 && parseInt(v) <= 100)
      }
    };

    Object.values(fields).forEach(field => {
      field.element.addEventListener('input', function() {
        const valid = field.validate(this.value);
        field.error.style.display = valid ? 'none' : 'block';
        this.className = this.value ? (valid ? 'valid-border' : 'error-border') : '';
        updateGlobalFeedback();
      });
    });

    function updateGlobalFeedback() {
      const semuaValid = Object.values(fields).every(f => {
        const el = f.element;
        return !el.value || f.validate(el.value);
      });
      const fb = document.getElementById('feedbackGlobal');
      if (semuaValid && Object.values(fields).some(f => f.element.value)) {
        fb.className = 'feedback success';
        fb.textContent = '✅ Semua data valid!';
      } else {
        fb.className = 'feedback';
      }
    }

    document.getElementById('formTamu').addEventListener('submit', function(e) {
      e.preventDefault();
      const semuaValid = Object.values(fields).every(f => {
        const el = f.element;
        return el.value && f.validate(el.value);
      });
      if (semuaValid) {
        alert('✅ Tamu berhasil terdaftar!');
      } else {
        alert('❌ Perbaiki data yang salah!');
      }
    });
  </script>
</body>
</html>
```

## Analogi
- **Tanpa real-time** = seperti tamu isi formulir kertas, baru dicek satpam saat mau submit. Kalau salah, suruh isi ulang dari awal.
- **Dengan real-time** = satpam berdiri di samping meja dan langsung bilang "Adik, nama kurang panjang" saat tamu baru nulis 2 huruf.
- **Border hijau/merah** = lampu indikasi: "OK" atau "Perlu diperbaiki"
- **Feedback text** = satpam bicara langsung

## Dipakai Untuk Apa
- Password strength checker
- Username availability (via fetch ke server)
- Form registrasi panjang (progress bar validasi)
- Input harga/format khusus

## Kesalahan Umum
1. **Terlalu agresif** — validasi saat input masih kosong padahal baru fokus. Validasi hanya jika sudah ada perubahan.
2. **Regex overkill** — regex email yang rumit kadang menolak email valid. Gunakan yang sederhana.
3. **Tidak handle input kosong** — field opsional boleh kosong, jangan divalidasi.
4. **Feedback tidak aksesibel** — lupa aria-live untuk screen reader.
5. **Debounce tidak dipakai** — validasi real-time async (cek username via API) perlu debounce agar tidak request tiap karakter.

## Keterkaitan dengan Materi Sebelumnya
Event listener `input` + `change` dari Level 5 (DOM events) dan `fetch` untuk validasi async (misal cek email sudah terdaftar).

## Soal Latihan
Buat validasi real-time untuk `<input id="password">` yang menampilkan teks "Password terlalu pendek" jika kurang dari 8 karakter.
