# 56. Membaca & Memvalidasi Form

## Penjelasan
Form HTML digunakan untuk mengumpulkan data dari pengguna (seperti formulir pendaftaran tamu). JavaScript membaca nilai input dan memvalidasinya sebelum dikirim.

## Fungsi
Mendapatkan data input dan memastikan data yang dikirim memenuhi syarat (tidak kosong, format benar, dll).

## Cara Pengimplementasian
```html
<!DOCTYPE html>
<html>
<body>
  <h1>📋 Formulir Pendaftaran Tamu</h1>

  <form id="formTamu">
    <div>
      <label>Nama Tamu:</label>
      <input type="text" id="nama" required>
    </div>
    <div>
      <label>Jumlah Anggota Keluarga:</label>
      <input type="number" id="jumlah" min="1" max="10">
    </div>
    <div>
      <label>Email:</label>
      <input type="email" id="email">
    </div>
    <div>
      <label>Tipe Kamar:</label>
      <select id="tipeKamar">
        <option value="">-- Pilih --</option>
        <option value="standard">Standard</option>
        <option value="deluxe">Deluxe</option>
      </select>
    </div>
    <div>
      <label>Setuju aturan rumah?</label>
      <input type="checkbox" id="setuju" value="ya">
    </div>
    <button type="submit">Daftar Tamu</button>
  </form>

  <div id="hasil"></div>

  <script>
    document.getElementById('formTamu').addEventListener('submit', function(e) {
      e.preventDefault(); // jangan reload halaman

      // Baca satu per satu — seperti petugas baca formulir kertas
      const nama = document.getElementById('nama').value.trim();
      const jumlah = document.getElementById('jumlah').value;
      const email = document.getElementById('email').value.trim();
      const tipeKamar = document.getElementById('tipeKamar').value;
      const setuju = document.getElementById('setuju').checked;

      // Validasi dasar
      if (!nama) {
        alert('Nama tamu harus diisi!');
        return;
      }
      if (!tipeKamar) {
        alert('Pilih tipe kamar!');
        return;
      }
      if (!setuju) {
        alert('Setujui aturan rumah!');
        return;
      }
      if (jumlah && (jumlah < 1 || jumlah > 10)) {
        alert('Jumlah anggota keluarga harus 1-10!');
        return;
      }

      // Tampilkan data
      const hasil = document.getElementById('hasil');
      hasil.innerHTML = `
        <h3>✅ Tamu Terdaftar:</h3>
        <p>Nama: ${nama}</p>
        <p>Jumlah: ${jumlah || '1'}</p>
        <p>Email: ${email || '-'}</p>
        <p>Tipe Kamar: ${tipeKamar}</p>
      `;
    });
  </script>
</body>
</html>
```

## Analogi
- **Form HTML** = formulir pendaftaran tamu di meja resepsionis
- **`value`** = membaca apa yang ditulis tamu di kertas
- **`checked`** = melihat apakah tamu mencentang kotak persetujuan
- **`submit event`** = tamu menekan tombol "Kirim" formulir
- **`preventDefault`** = resepsionis menahan kertasnya — "sebentar, saya cek dulu"
- **Validasi** = resepsionis periksa: "namanya diisi?", "emailnya bener?"

## Dipakai Untuk Apa
- Login/register form
- Pemesanan tiket
- Form survey
- Setting profil pengguna

## Kesalahan Umum
1. **Tidak trim() input** — spasi di awal/akhir lolos. Selalu `trim()`.
2. **Validasi hanya di frontend** — frontend bisa dimanipulasi. Selalu validasi ulang di backend.
3. **Lupa handle checkbox/radio** — checkbox pakai `.checked` (boolean), bukan `.value`.
4. **Tidak `preventDefault`** — halaman reload, data JS hilang sebelum sempat diproses.
5. **Mengandalkan required HTML** — `required` bisa dilewati dengan tools. JS validation tetap perlu.

## Keterkaitan dengan Materi Sebelumnya
Level 5 (fetch) biasanya dipanggil di dalam event submit form: baca form → validasi → kirim data via fetch → tampilkan hasil.

## Soal Latihan
Baca nilai dari `<input id="usia" type="number">` dan validasi bahwa usia minimal 17 tahun. Jika kurang, tampilkan alert.
