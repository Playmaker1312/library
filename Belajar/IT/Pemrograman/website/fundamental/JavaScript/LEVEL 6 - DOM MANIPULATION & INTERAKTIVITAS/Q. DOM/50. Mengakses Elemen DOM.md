# 50. Mengakses Elemen DOM

## Penjelasan
DOM (Document Object Model) adalah representasi struktur HTML sebagai pohon objek. Untuk memanipulasi DOM, pertama kita harus mengakses elemen yang ingin diubah menggunakan metode seleksi.

## Fungsi
Mendapatkan referensi ke elemen HTML tertentu agar bisa dibaca, diubah, atau dihapus.

## Cara Pengimplementasian
```html
<!DOCTYPE html>
<html>
<body>
  <h1 id="judul">Selamat Datang di Rumah</h1>
  <p class="ruangan">Ruang Tamu</p>
  <p class="ruangan">Kamar Tidur</p>
  <ul>
    <li>Meja</li>
    <li>Kursi</li>
  </ul>
  <script>
    // Berdasarkan ID — seperti cari ruangan pakai nama spesifik
    const judul = document.getElementById('judul');
    console.log(judul.textContent);

    // Berdasarkan class — seperti cari semua ruangan bertipe "kamar"
    const ruangan = document.getElementsByClassName('ruangan');
    console.log(ruangan.length); // 2

    // querySelector — seperti minta satpam: "cari ruangan pertama yg kelasnya ruangan"
    const pertama = document.querySelector('.ruangan');
    console.log(pertama.textContent); // Ruang Tamu

    // querySelectorAll — seperti "cari semua ruangan"
    const semua = document.querySelectorAll('.ruangan');
    console.log(semua.length); // 2

    // Berdasarkan tag — seperti "cari semua pintu"
    const items = document.getElementsByTagName('li');
    console.log(items.length); // 2
  </script>
</body>
</html>
```

## Analogi
Rumah = dokumen HTML. DOM adalah **peta/denah rumah** yang mencatat semua ruangan, pintu, jendela, dan perabot.
- `getElementById` = mencari ruangan berdasarkan nomor uniknya (misal: "Kamar Utama")
- `getElementsByClassName` = mencari semua ruangan bertipe "kamar"
- `querySelector` = bertanya ke satpam: "cari ruangan pertama yang memenuhi syarat X"
- `querySelectorAll` = "cari semua ruangan yang memenuhi syarat X"
- `getElementsByTagName` = "cari semua pintu di rumah ini"

## Dipakai Untuk Apa
- Menampilkan atau menyembunyikan elemen
- Membaca input form
- Mengubah konten dinamis
- Animasi dan transisi

## Kesalahan Umum
1. **querySelector return null jika tidak ditemukan** — selalu cek sebelum akses properti.
2. **getElementsByClassName/Name return HTMLCollection LIVE** — koleksi berubah otomatis jika DOM berubah; querySelectorAll return NodeList STATIC.
3. **Salah selector** — lupa titik (`.`) untuk class atau `#` untuk ID di querySelector.
4. **Menjalankan script sebelum DOM siap** — bungkus dengan `DOMContentLoaded` atau taruh script di akhir body.

## Keterkaitan dengan Materi Sebelumnya
Level 5 (async/fetch) mempersiapkan data dari server; data itu sering dimasukkan ke DOM. Misal: hasil fetch API ditampilkan dengan mengakses elemen `<div id="container">` lalu mengisi kontennya.

## Soal Latihan
Buat seleksi elemen menggunakan `querySelectorAll` untuk semua elemen dengan class `kamar`, lalu console.log jumlahnya.

> !jawaban: `const kamar = document.querySelectorAll('.kamar'); console.log(kamar.length);`!
