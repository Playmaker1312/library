# 52. Membuat & Menambahkan Elemen DOM

## Penjelasan
Kita bisa membuat elemen HTML baru dari JavaScript lalu menyisipkannya ke dalam DOM — seperti membangun ruangan baru di rumah lalu menghubungkannya ke denah.

## Fungsi
Membuat konten dinamis yang bertambah seiring interaksi pengguna, seperti daftar belanja, kartu produk, atau notifikasi.

## Cara Pengimplementasian
```html
<!DOCTYPE html>
<html>
<body>
  <h1>Daftar Ruangan</h1>
  <ul id="daftarRuangan">
    <li>Ruang Tamu</li>
  </ul>
  <button onclick="tambahRuangan()">+ Tambah Ruangan</button>

  <script>
    function tambahRuangan() {
      // createElement — bangun ruangan baru dari nol
      const liBaru = document.createElement('li');

      // isi ruangan dengan teks
      liBaru.textContent = 'Kamar Baru ' + Date.now();

      // appendChild — pasang ruangan baru ke dalam rumah (di akhir)
      document.getElementById('daftarRuangan').appendChild(liBaru);
    }

    // Contoh lain: menyisipkan di posisi tertentu
    function sisipDiAwal() {
      const liBaru = document.createElement('li');
      liBaru.textContent = 'Garasi';
      const parent = document.getElementById('daftarRuangan');

      // insertBefore — selipkan sebelum anak pertama
      parent.insertBefore(liBaru, parent.firstChild);
    }

    // removeChild — bongkar ruangan
    function hapusRuangan() {
      const parent = document.getElementById('daftarRuangan');
      if (parent.lastChild) {
        parent.removeChild(parent.lastChild);
      }
    }

    // cloneNode — duplikat desain ruangan
    function duplikatPertama() {
      const asli = document.querySelector('#daftarRuangan li');
      if (asli) {
        const duplikat = asli.cloneNode(true); // true = dalam-dalam
        document.getElementById('daftarRuangan').appendChild(duplikat);
      }
    }
  </script>
</body>
</html>
```

## Analogi
- `createElement('div')` = membangun ruangan kosong (div) di pabrik, belum terpasang
- `appendChild` = menyambung ruangan baru ke denah rumah (di bagian belakang)
- `insertBefore` = menyelipkan ruangan di antara dua ruangan yang sudah ada
- `removeChild` = membongkar ruangan dari rumah
- `cloneNode` = membuat replika persis sebuah ruangan

## Dipakai Untuk Apa
- Menampilkan data dari database (tabel dinamis)
- Infinite scroll (tambah konten saat scroll)
- Notifikasi toast
- Todo list / daftar dinamis

## Kesalahan Umum
1. **Membuat elemen tapi lupa append** — elemen hanya ada di memori, tidak muncul.
2. **innerHTML +=** untuk nambah elemen — ini rebuild semua child, ga efisien. Pakai `appendChild`.
3. **appendChild memindahkan elemen existing** — jika node sudah ada di DOM, ia dipindahkan, bukan dicopy.
4. **Lupa `true` di cloneNode** — secara default cloneNode(false) hanya copy elemen tanpa child.

## Keterkaitan dengan Materi Sebelumnya
Di Level 5 kita `fetch` data array dari API. Setelah dapat array itu, kita loop dan `createElement` untuk setiap item — dari data mentah jadi tampilan nyata di rumah.
