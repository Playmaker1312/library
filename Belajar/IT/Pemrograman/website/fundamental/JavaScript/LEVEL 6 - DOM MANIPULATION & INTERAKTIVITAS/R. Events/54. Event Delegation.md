# 54. Event Delegation

## Penjelasan
Event delegation adalah teknik menempatkan SATU event listener di elemen induk (parent) untuk menangani event dari banyak elemen anak (child), memanfaatkan **event bubbling** — gelembung event yang naik dari anak ke induk.

## Fungsi
Menghemat memori dan menyederhanakan kode dengan satu listener untuk banyak elemen, terutama untuk elemen yang ditambahkan secara dinamis.

## Cara Pengimplementasian
```html
<!DOCTYPE html>
<html>
<body>
  <h1>Rumah dengan Banyak Pintu</h1>

  <!-- SATU satpam untuk SEMUA pintu → event delegation -->
  <div id="rumah">
    <div class="pintu" data-ruang="Ruang Tamu">🚪 Pintu Ruang Tamu</div>
    <div class="pintu" data-ruang="Kamar Tidur">🚪 Pintu Kamar Tidur</div>
    <div class="pintu" data-ruang="Dapur">🚪 Pintu Dapur</div>
    <div class="pintu" data-ruang="Garasi">🚪 Pintu Garasi</div>
  </div>

  <button onclick="tambahPintuBaru()">+ Tambah Pintu Baru</button>
  <div id="log"></div>

  <script>
    // DELEGASI: satpam cukup di pintu utama (#rumah)
    document.getElementById('rumah').addEventListener('click', function(event) {
      // Cek apakah yang diklik adalah pintu
      const pintu = event.target.closest('.pintu');
      if (!pintu) return; // bukan pintu, abaikan

      const ruang = pintu.dataset.ruang;
      document.getElementById('log').innerHTML += `🔔 ${ruang} — ada tamu!<br>`;
    });

    // Pintu baru tetap terdeteksi meskipun ditambahkan setelah listener dipasang
    function tambahPintuBaru() {
      const baru = document.createElement('div');
      baru.className = 'pintu';
      baru.dataset.ruang = 'Kamar Baru ' + Date.now();
      baru.textContent = '🚪 Pintu Kamar Baru';
      document.getElementById('rumah').appendChild(baru);
    }
  </script>
</body>
</html>
```

## Analogi
Daripada menempatkan SATPAM di setiap pintu rumah (boros), kita tempatkan SATU SATPAM di **pintu utama rumah**. Ketika tamu masuk melalui pintu mana pun, suara bel naik ke pintu utama (bubbling) dan satpam di sana menangani semua tamu.

- Tanpa delegasi = setiap pintu punya satpam sendiri
- Dengan delegasi = satu satpam di pintu utama yang menyapa semua tamu

## Dipakai Untuk Apa
- List/dinamis (todo list, komentar, feed) yang sering ditambah item baru
- Table dengan banyak baris
- Menu dropdown
- Menghemat memory di aplikasi besar (ribuan elemen)

## Kesalahan Umum
1. **Tidak filter target** — event dari klik di ruang kosong ikut terproses. Selalu cek `event.target` atau `closest`.
2. **Mengandalkan `event.target` langsung** — jika anak punya sub-elemen (misal span di dalam button), target bisa salah. Pakai `closest('.selector')`.
3. **Event yang tidak bubbling** — `focus`, `blur`, `scroll`, `load`, `error`, `mouseenter`, `mouseleave` tidak bubbling. Delegasi tidak bekerja.
4. **Delegasi berlebihan** — untuk 2-3 tombol, lebih baik pasang listener langsung.

## Keterkaitan dengan Materi Sebelumnya
Setelah Level 5 async/fetch menambah item ke DOM secara dinamis, event delegation memastikan item baru itu tetap interaktif tanpa harus pasang ulang listener.

## Soal Latihan
Buat `<ul id="daftar-belanja">` dengan 3 `<li>` awal. Gunakan event delegation: satu klik di `<ul>` akan menampilkan teks barang yang diklik ke console.
