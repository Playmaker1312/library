# NPM & Vite Setup

## Penjelasan
**NPM** (Node Package Manager) adalah package manager untuk JavaScript — tempat mengunduh, mengelola, dan membagikan kode pihak ketiga (package). NPM menyediakan registry (npmjs.com), CLI (`npm`), dan file `package.json` sebagai manifest proyek. **Vite** adalah build tool modern yang menggunakan ES Module asli saat development dan Rollup untuk production — dikenal sangat cepat karena dev server-nya menggunakan native ESM tanpa bundling.

## Fungsi
**NPM:**
- Menginstall dependencies (package pihak ketiga)
- Mengelola versi package melalui `package.json` dan `package-lock.json`
- Menjalankan script (`npm run build`, `npm run dev`)
- Menerbitkan package ke registry

**Vite:**
- Dev server super cepat dengan Hot Module Replacement (HMR)
- Build production yang dioptimalkan (minify, code splitting, tree shaking)
- Mendukung TypeScript, JSX, CSS, dan asset lain tanpa konfigurasi manual
- Konfigurasi minimal via `vite.config.js`

## Cara Pengimplementasian

### Setup Proyek dengan Vite
```bash
# Buat proyek baru (seperti membeli tanah untuk bangun rumah)
npm create vite@latest rumah-impian -- --template vanilla

# Masuk ke direktori
cd rumah-impian

# Install dependencies (seperti membeli material bangunan)
npm install

# Jalankan dev server (melihat proses pembangunan rumah secara live)
npm run dev

# Build untuk production (tahap akhir rumah siap huni)
npm run build

# Preview hasil build
npm run preview
```

### Struktur Proyek
```
rumah-impian/
├── node_modules/       # Gudang material (tidak di-commit)
├── public/             # Aset publik (brochure rumah)
├── src/                # Denah dan konten rumah
│   ├── main.js         # Pintu masuk utama
│   └── style.css       # Cat dan dekorasi
├── index.html          # Kerangka rumah
├── package.json        # Daftar belanja material
├── vite.config.js      # Cetak biru build system
└── package-lock.json   # Resi pembelian material (versi persis)
```

### package.json — Daftar Belanja Material
```json
{
  "name": "rumah-impian",
  "version": "1.0.0",
  "description": "Proyek rumah impian",
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  },
  "dependencies": {
    "lodash": "^4.17.21"
  },
  "devDependencies": {
    "vite": "^6.0.0"
  }
}
```

### Mengelola Package
```bash
# Install dependency production (perabot tetap di rumah)
npm install lodash

# Install devDependency (alat tukang, tidak dibutuhkan saat huni)
npm install --save-dev vitest

# Hapus package (buang material tak terpakai)
npm uninstall lodash

# Update semua package (perbarui material)
npm update

# Lihat package usang
npm outdated
```

### vite.config.js — Cetak Biru Build
```js
import { defineConfig } from "vite";

export default defineConfig({
  root: ".",              // Denah utama
  base: "/",              // Jalur akses rumah
  build: {
    outDir: "dist",       // Rumah jadi diletakkan di sini
    minify: "esbuild",    // Alat merapikan rumah
  },
  server: {
    port: 3000,           // Nomor rumah di development
  },
});
```

## Analogi
Membangun **RUMAH** membutuhkan dua peran: **NPM** adalah **toko material bangunan** — tempat membeli semua bahan (paku, cat, pipa, listrik). `package.json` adalah **daftar belanja** yang mencatat nama dan jumlah material. `node_modules` adalah **gudang material** di lokasi proyek. `npm install` adalah **proses pengiriman material** dari toko ke gudang. **Vite** adalah **kontraktor/kepala tukang** yang membangun rumah dari material tersebut. Vite membaca daftar belanja (`package.json`), mengambil material dari gudang (`node_modules`), lalu membangun rumah dengan cepat. Saat `dev`, Vite membangun **kerangka sementara** untuk inspeksi. Saat `build`, Vite menyelesaikan **rumah final yang rapi dan siap huni** ke folder `dist`.

| Konsep | Analogi Rumah |
|---|---|
| NPM Registry | Toko material bangunan online |
| `package.json` | Daftar belanja material |
| `node_modules` | Gudang material di lokasi |
| `npm install` | Proses kirim material ke gudang |
| Vite | Kontraktor/kepala tukang bangunan |
| `vite.config.js` | Cetak biru & spesifikasi bangunan |
| `npm run dev` | Lihat proses bangun secara live |
| `npm run build` | Rumah final siap huni |
| `dist/` | Rumah jadi yang dikirim ke klien |

## Kesalahan Umum
- Lupa `npm install` setelah clone repo — langsung run dev, error module not found. Solusi: selalu jalankan `npm install` pertama
- Commit `node_modules` ke git — seharusnya di `.gitignore`
- Perbedaan environment: `npm install` tanpa `--save-dev` membuat package masuk `dependencies` padahal seharusnya `devDependencies`
- Versi tidak cocok: ^4.0.0 bisa menginstall 4.99.99 yang mungkin membawa breaking change
- Lupa `type: "module"` di package.json — import ES Modules tidak berfungsi di Node.js
