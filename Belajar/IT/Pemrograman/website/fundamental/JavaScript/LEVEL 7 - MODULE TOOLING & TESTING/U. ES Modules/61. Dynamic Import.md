# Dynamic Import

## Penjelasan
Dynamic Import (`import()`) adalah sintaks untuk mengimpor module secara asynchronous dan kondisional — tidak seperti `import` statis yang harus di-declare di top-level. `import()` mengembalikan Promise yang resolve ke module object, sehingga bisa dipanggil kapan saja di dalam fungsi, blok if, atau event handler.

## Fungsi
- **Lazy loading** — module hanya di-load saat benar-benar dibutuhkan, mempercepat initial load
- **Kondisional** — import hanya terjadi jika kondisi tertentu terpenuhi (misal role user, feature flag)
- **Error handling** — bisa `.catch()` jika module gagal di-load
- **Dinamis** — path module bisa berupa expression/string hasil runtime

## Cara Pengimplementasian
```js
// 📁 lampu.js
export function nyalakan() {
  return "Lampu rumah menyala";
}
export const merk = "Philips";

// 📁 main.js — rumah utama

// Static import (selalu dijalankan)
import Rumah from "./rumah.js";

// Dynamic import (hanya saat dibutuhkan)
const tombolDarurat = document.getElementById("emergency");

tombolDarurat.addEventListener("click", async () => {
  try {
    // Pintu darurat dibuka hanya saat tombol ditekan
    const moduleLampu = await import("./lampu.js");
    console.log(moduleLampu.nyalakan()); // Lampu rumah menyala
    console.log(moduleLampu.merk);       // Philips
  } catch (err) {
    console.error("Gagal buka pintu darurat:", err);
  }
});

// Dynamic import dengan kondisi
async function muatFiturTambahan(tipeRumah) {
  if (tipeRumah === "mewah") {
    const kolam = await import("./kolamRenang.js");
    kolam.isiAir();
  } else if (tipeRumah === "sederhana") {
    const taman = await import("./taman.js");
    taman.siramTanaman();
  }
}

// Path dinamis (berdasarkan input)
const namaRuang = "dapur";
const { default: Ruang } = await import(`./ruangan/${namaRuang}.js`);

// Destructuring hasil dynamic import
const { bukaPintu, tutupJendela } = await import("./aksesRumah.js");
```

### Dynamic Import dengan default export
```js
// Jika module menggunakan export default
const moduleDefault = await import("./rumah.js");
const Rumah = moduleDefault.default; // .default untuk akses default export

// Atau langsung destructure
const { default: Rumah, luasTanah } = await import("./rumah.js");
```

## Analogi
**RUMAH** memiliki **pintu darurat** yang hanya dibuka saat terjadi keadaan tertentu — tidak selalu terbuka seperti pintu utama. Saat ada kebakaran (event), penghuni membuka pintu darurat (`import()`), masuk ke ruangan khusus (module), lalu mengambil peralatan darurat. Begitu selesai, pintu bisa ditutup kembali. Pintu darurat juga bisa menuju ke **gudang yang berbeda tergantung kebutuhan** — misal gudang alat kebun jika musim tanam, gudang pemanas jika musim dingin (kondisional). `import()` adalah Promise, jadi kita **menunggu pintu terbuka** (await) sebelum masuk.

| Konsep | Analogi Rumah |
|---|---|
| `import()` | Pintu darurat yang hanya dibuka saat perlu |
| Promise result | Hasil setelah pintu darurat terbuka |
| `.default` | Akses ke pintu utama dari luar via pintu darurat |
| `catch` | Gagal buka pintu darurat (rusak/tak ada) |
| Kondisional | Memilih gudang mana yang dibuka sesuai situasi |

## Dipakai Untuk Apa
- **Lazy loading komponen** di React (`React.lazy(() => import('./Komponen'))`)
- **Code splitting** di Vite/Webpack — memecah bundle besar menjadi chunk kecil
- **Memuat polyfill** hanya jika browser tidak mendukung fitur tertentu
- **Fitur berdasarkan peran** — misal module admin hanya di-load untuk user admin
- **i18n** — memuat file bahasa hanya saat user mengganti bahasa

## Kesalahan Umum
- Menganggap `import()` seperti fungsi biasa — ia adalah sintaks keyword, meskipun mirip fungsi
- Lupa `await` atau `.then()` — hasilnya Promise, bukan module langsung
- Salah handle error — asumsikan network selalu berhasil, padahal bisa gagal (404, timeout)
- Menggunakan `import()` dengan template literal tanpa validasi — bisa inject path berbahaya
- Mencoba dynamic import di environment yang tidak mendukung (Node < 13, browser tua tanpa type=module)
- Menaruh `import()` di dalam hot loop tanpa caching — setiap panggilan buat request baru

## Keterkaitan dengan Materi Sebelumnya
- **LEVEL 1 (Fundamental)**: `import()` mengembalikan Promise — konsep async dari awal
- **LEVEL 2 (Function)**: `import()` sering dipanggil di dalam arrow function async atau callback event
- **LEVEL 3 (Object & Array)**: Hasilnya adalah module object (key-value) — bisa di-destructure
- **LEVEL 4 (DOM)**: Pemicu dynamic import sering dari event DOM (`click`, `scroll`, dll)
- **LEVEL 5 (Asynchronous)**: Ini adalah bentuk paling langsung dari asynchronous + Promise; related ke `fetch()`
- **LEVEL 6 (OOP)**: Class dari module bisa di-dynamic import, lalu di-instantiate setelah resolve
- **LEVEL 7 (File 60)**: Static import adalah saudara dynamic import — statis untuk kebutuhan tetap, dinamis untuk kebutuhan kondisional
