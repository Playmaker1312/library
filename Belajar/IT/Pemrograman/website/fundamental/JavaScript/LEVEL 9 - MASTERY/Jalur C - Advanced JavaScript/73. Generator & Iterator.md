# Generator & Iterator

## Penjelasan
**Iterator** adalah objek yang memiliki method `next()` yang mengembalikan `{ value, done }`. Iterator memungkinkan kita melintasi koleksi data satu per satu.

**Generator** adalah fungsi khusus (`function*`) yang bisa dihentikan sementara (pause) dengan `yield` dan dilanjutkan lagi (resume). Generator mengembalikan iterator.

Keduanya adalah protokol untuk membuat data dapat diiterasi secara terkendali — tidak harus memuat semua data di memori sekaligus.

## Fungsi
- Membuat data dapat diiterasi dengan lazy evaluation (data dihasilkan saat diminta)
- Menghemat memori untuk data besar/tak terbatas
- Mengontrol alur eksekusi fungsi (pause/resume)
- Implementasi custom iteration logic

## Cara Pengimplementasian

```javascript
// GENERATOR — analogi RUMAH: kran air yang bisa ditutup/buka
// Air tidak mengalir terus — kamu buka kran, air keluar, kamu tutup, air berhenti

// Generator sederhana: kran air kamar mandi
function* kranAir() {
  console.log('Kran dibuka...');
  yield 'Air dingin';           // pause, keluarkan value pertama
  console.log('Kran diputar lagi...');
  yield 'Air hangat';           // pause, keluarkan value kedua
  console.log('Kran ditutup...');
  yield 'Air mati';             // pause, keluarkan value ketiga
  console.log('Kran selesai');
  return 'Tidak ada air lagi';  // done: true
}

const kran = kranAir();
console.log(kran.next());       // { value: 'Air dingin', done: false }
console.log(kran.next());       // { value: 'Air hangat', done: false }
console.log(kran.next());       // { value: 'Air mati', done: false }
console.log(kran.next());       // { value: 'Tidak ada air lagi', done: true }

// Generator untuk rumah dengan ruangan tak terbatas
function* ruanganRumah() {
  let i = 1;
  while (true) {
    yield `Ruangan ${i++}`;     // lazy — hanya dibuat saat diminta
  }
}

const ruangan = ruanganRumah();
console.log(ruangan.next().value); // "Ruangan 1"
console.log(ruangan.next().value); // "Ruangan 2"
console.log(ruangan.next().value); // "Ruangan 3"
// Bisa terus tanpa batas — tidak pakai memori untuk semua ruangan

// ITERATOR — analogi RUMAH: berjalan dari satu ruangan ke ruangan lain
// Rumah adalah koleksi ruangan, dan kita jalan satu per satu

const rumahSaya = {
  ruangans: ['Ruang Tamu', 'Kamar Tidur', 'Dapur', 'Kamar Mandi'],
  [Symbol.iterator]() {
    let index = 0;
    const ruangans = this.ruangans;
    return {
      next() {
        if (index < ruangans.length) {
          return { value: ruangans[index++], done: false };
        }
        return { value: undefined, done: true };
      }
    };
  }
};

// Sekarang rumahSaya bisa di-loop pakai for...of!
for (const ruang of rumahSaya) {
  console.log(`Memasuki ${ruang}`);
}
// "Memasuki Ruang Tamu"
// "Memasuki Kamar Tidur"
// "Memasuki Dapur"
// "Memasuki Kamar Mandi"

// Generator juga bisa delegasi yield*
function* semuaRuangan() {
  yield* rumahSaya;             // delegasikan iterator
  yield 'Garasi';
  yield 'Halaman Belakang';
}

console.log([...semuaRuangan()]);
// ["Ruang Tamu", "Kamar Tidur", "Dapur", "Kamar Mandi", "Garasi", "Halaman Belakang"]
```

## Analogi
Generator = **kran air di rumah**. Kran bisa dibuka (mulai generator) — air mengalir. Kamu putar kran ke kiri (first yield), air keluar. Kamu tutup (pause), air berhenti. Kamu buka lagi (next call), air mengalir lagi. Tidak seperti selang yang terus mengalir (fungsi biasa), kran memberi kendali penuh kapan air keluar. Generator juga bisa menghasilkan air tak terbatas dari sumur (data tak terbatas) tanpa perlu menampung semua air di ember (memori).

Iterator = **berjalan dari satu ruangan ke ruangan lain di rumah**. Kamu tidak melompat ke semua ruangan sekaligus — kamu jalan ke ruang tamu, lalu kamar tidur, lalu dapur, satu per satu. `next()` adalah langkah kaki berikutnya. `for...of` adalah pemandu tur yang otomatis mengantarmu ke setiap ruangan sampai selesai.

## Dipakai Untuk Apa
- Infinite scroll / data stream — data dimuat bertahap tanpa henti
- Pagination — yield halaman berikutnya saat diminta
- Custom data structures — implementasi `[Symbol.iterator]` untuk tree, graph, dll
- Async generator — `for await...of` untuk stream data real-time
- Redux Saga — middleware generator untuk side effects

## Kesalahan Umum
1. **Generator bukan array** — tidak bisa pakai `map`, `filter`, `reduce` langsung. Konversi dengan `[...gen]` dulu
2. **Generator sekali pakai** — setelah iterasi selesai (done: true), generator tidak bisa diulang. Buat instance baru
3. **Lupa `function*` (bintang)** — `function*` bukan `function`, bedanya adalah bintang
4. **Yield di dalam callback** — `yield` hanya bisa dipanggil langsung di dalam generator function, tidak di dalam callback nested
5. **Infinite loop tanpa break** — generator while(true) baik, tapi pastikan ada kondisi berhenti atau dipanggil terbatas

## Keterkaitan dengan Materi Sebelumnya
Di Level 2, kamu belajar array iteration (`for`, `forEach`, `map`). Iterable protocol (`Symbol.iterator`) adalah yang membuat array bisa di-loop. Generator memperluas konsep ini: bukan hanya array, tapi apapun bisa dibuat iterable. Di Level 5, kamu belajar async/await — async generator (`async function*`) dan `for await...of` adalah gabungan generator + async untuk stream data. Promise dan generator pernah dijadikan dasar async/await sebelum ECMAScript 2017.

## Soal Latihan

Apa output dari kode berikut?

```javascript
function* hitungMundur(n) {
  while (n > 0) {
    yield n--;
  }
  return 'Selesai!';
}

const gen = hitungMundur(3);
console.log(gen.next().value);
console.log(gen.next().value);
console.log(gen.next().value);
console.log(gen.next().value);
```

>!3, 2, 1, lalu `undefined` (karena `return` mengembalikan `{ value: 'Selesai!', done: true }`, tapi `.value` dari objek dengan `done: true` hanya bisa diakses jika properti value diambil — di sini `gen.next().value` mengambil value dari objek `{ value: 'Selesai!', done: true }`, jadi sebenarnya output: 3, 2, 1, 'Selesai!'.!
