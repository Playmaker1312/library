# 44. Membuat & Menggunakan Promise

## Penjelasan
Promise adalah objek yang merepresentasikan **janji** — sebuah nilai yang mungkin tersedia sekarang, nanti, atau tidak sama sekali. Promise memiliki tiga status: **pending** (menunggu), **fulfilled** (berhasil), dan **rejected** (gagal). Promise menyediakan `.then()` untuk menangani keberhasilan, `.catch()` untuk menangani kegagalan, dan `.finally()` untuk kode yang jalan apapun hasilnya. Promise lahir untuk menyelesaikan masalah Callback Hell.

## Fungsi
Promise membuat kode asynchronous lebih terstruktur dan mudah dibaca. Alih-alih callback bersarang, Promise memungkinkan chaining dengan `.then()` yang rata (flat). Promise juga menyediakan cara standar untuk menangani error asynchronous via `.catch()`, dan menggabungkan beberapa Promise paralel dengan `Promise.all()`, `Promise.race()`, dll.

## Cara Pengimplementasian
```js
// Membuat Promise — tukang bangunan janji akan datang
function pesanTukang(namaTukang) {
  return new Promise((resolve, reject) => {
    console.log(`Mencari ${namaTukang}...`);

    setTimeout(() => {
      const datang = Math.random() > 0.3; // 70% berhasil

      if (datang) {
        resolve(`${namaTukang} datang membawa alat`);
      } else {
        reject(`${namaTukang} tidak datang (sibuk)`);
      }
    }, 2000);
  });
}

// Menggunakan Promise
pesanTukang("Tukang Kayu")
  .then((pesan) => {
    console.log("Berhasil:", pesan);
  })
  .catch((error) => {
    console.log("Gagal:", error);
  })
  .finally(() => {
    console.log("Transaksi selesai (apapun hasilnya)");
  });
```

```js
// Promise chaining — rantai pekerjaan
function galiPondasi() {
  return new Promise((resolve) => {
    setTimeout(() => {
      console.log("Pondasi selesai digali");
      resolve("pondasi");
    }, 1000);
  });
}

function corBeton(hasilGalian) {
  return new Promise((resolve) => {
    setTimeout(() => {
      console.log(`${hasilGalian} sudah dicor beton`);
      resolve("beton");
    }, 1000);
  });
}

function pasangBata(hasilCor) {
  return new Promise((resolve) => {
    setTimeout(() => {
      console.log(`${hasilCor} sudah dipasang bata`);
      resolve("dinding");
    }, 1000);
  });
}

galiPondasi()
  .then(corBeton)
  .then(pasangBata)
  .then((hasil) => console.log(`Rumah jadi: ${hasil}`))
  .catch((err) => console.log(`Proses gagal: ${err}`));
```

## Analogi
**Promise = janji tukang bangunan ke pemilik rumah**. Tukang bilang: "Saya janji akan datang minggu depan untuk memperbaiki atap. Mungkin saya datang (fulfilled), mungkin saya tidak datang (rejected)." Pemilik rumah menunggu (pending) dan menyiapkan dua rencana: `.then()` = kalau datang, kita perbaiki atap; `.catch()` = kalau tidak datang, cari tukang lain; `.finally()` = apapun yang terjadi, rumah tetap harus diurus.

## Dipakai Untuk Apa
Promise dipakai di hampir semua operasi asynchronous modern: mengambil data dari API (`fetch()` mengembalikan Promise), operasi database, baca/tulis file di Node.js, delay/timer (`setTimeout` versi Promise), dan semua library modern yang menggunakan async pattern.

## Kesalahan Umum
Lupa me-return Promise di dalam chain `.then()` — menyebabkan `undefined` diteruskan ke `.then()` berikutnya. Tidak menangani error dengan `.catch()` — menyebabkan unhandled promise rejection. Membuat Promise tapi tidak pernah memanggil `resolve()` atau `reject()` — Promise menggantung selamanya (memory leak). Juga: membuat nesting Promise (masih "then hell") meskipun sudah pakai Promise — padahal bisa di-chain rata.

## Keterkaitan dengan Materi Sebelumnya
Di Level 4 (class, OOP), kamu belajar membuat class sebagai cetakan objek. Kamu bisa membuat class yang me-return Promise dari method-method-nya:
```js
class Rumah {
  constructor() { this.status = "kosong"; }
  renovasi() {
    return new Promise((resolve) => {
      setTimeout(() => {
        this.status = "renovasi";
        resolve(this.status);
      }, 2000);
    });
  }
}
```
Ini menggabungkan struktur OOP dengan pola asynchronous Promise.

## Soal Latihan
Buat fungsi `tungguAntrian(nomor)` yang mengembalikan Promise. Promise resolve setelah 1 detik dengan pesan `"Nomor ${nomor} dipanggil"`, tapi jika nomor habis (>10), Promise reject dengan `"Nomor tidak valid"`.

```js
function tungguAntrian(nomor) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (nomor > 10) {
        reject("Nomor tidak valid");
      } else {
        resolve(`Nomor ${nomor} dipanggil`);
      }
    }, 1000);
  });
}

tungguAntrian(5).then(console.log).catch(console.error);
tungguAntrian(11).then(console.log).catch(console.error);
// Output: "Nomor 5 dipanggil" lalu "Nomor tidak valid"
```
