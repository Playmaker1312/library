# 47. Fetch API

## Penjelasan
Fetch API adalah antarmuka JavaScript modern untuk melakukan HTTP Request — mengambil (GET) atau mengirim data ke server. `fetch()` mengembalikan Promise yang resolve ke objek `Response`. Untuk membaca body response, perlu dipanggil method `.json()` (untuk JSON) atau `.text()` (untuk teks biasa). Fetch menggantikan `XMLHttpRequest` (XHR) yang lebih tua dan lebih rumit. Fetch adalah bawaan browser dan Node.js (versi 18+).

## Fungsi
Fetch memungkinkan aplikasi web berkomunikasi dengan server tanpa reload halaman — mengambil data, mengirim form, update profil, menampilkan daftar produk, dll. Ini adalah fondasi dari arsitektur **Single Page Application (SPA)** modern. Tanpa Fetch, setiap interaksi dengan server harus reload halaman — seperti jaman 2000-an.

## Cara Pengimplementasian
```js
// GET request — mengambil data dari API
async function ambilDataPenghuni() {
  try {
    const response = await fetch("https://jsonplaceholder.typicode.com/users");

    if (!response.ok) {
      throw new Error(`HTTP Error: ${response.status}`);
    }

    const data = await response.json();
    console.log("Data penghuni:", data);
  } catch (error) {
    console.log("Gagal mengambil data:", error.message);
  }
}

ambilDataPenghuni();
```

```js
// Menggunakan Promise .then() (tanpa async/await)
fetch("https://jsonplaceholder.typicode.com/users/1")
  .then((response) => {
    if (!response.ok) throw new Error(`Status ${response.status}`);
    return response.json();
  })
  .then((user) => console.log("Nama penghuni:", user.name))
  .catch((err) => console.error("Error:", err));
```

```js
// Fetch dengan opsi (method, header)
async function contohFetchLengkap() {
  const response = await fetch("https://jsonplaceholder.typicode.com/posts/1", {
    method: "GET",
    headers: {
      "Content-Type": "application/json",
      "Accept": "application/json"
    }
  });

  if (!response.ok) throw new Error("Gagal");

  const post = await response.json();
  console.log("Post:", post.title);
}
```

```js
// GET parameter / query string
async function cariRumah(query) {
  const url = new URL("https://api.contoh.com/rumah");
  url.searchParams.set("kota", query);
  url.searchParams.set("harga_max", "500000");

  const res = await fetch(url);
  const data = await res.json();
  return data;
}
```

## Analogi
**Fetch = memesan material bangunan dari toko online**. Kamu kirim permintaan (request) ke toko bangunan (server): "Saya mau pesan 50 sak semen." Toko akan memproses dan mengirimkan balasan (response). Proses ini asynchronous — kamu tidak perlu diam di depan pintu menunggu, bisa melakukan kegiatan lain. Saat paket datang (`response.ok`), kamu buka (`response.json()`). Jika paket tidak datang atau rusak (`!response.ok` atau network error), kamu tangani di `catch`.

## Dipakai Untuk Apa
Fetch API dipakai untuk: mengambil data dari REST API (data user, produk, artikel), mengirim form login/register, autocomplete search (mengetik langsung cari), infinite scroll (ambil data lebih banyak saat scroll ke bawah), upload file, dan update konten secara real-time tanpa reload halaman.

## Kesalahan Umum
Lupa mengecek `response.ok` — `fetch()` hanya reject jika ada network error, bukan jika server mengembalikan HTTP 404 atau 500. Jadi `response.status` 404 tetap masuk ke `.then()`, bukan `.catch()`. Lupa memanggil `.json()` — data yang diterima masih berupa objek Response, bukan data JSON yang siap pakai. Juga: tidak menangani error dengan try/catch atau .catch().

## Keterkaitan dengan Materi Sebelumnya
Di Level 4 (class, OOP), kamu bisa membuat service class yang membungkus Fetch API:
```js
class ApiRumah {
  constructor(baseURL) {
    this.baseURL = baseURL;
  }

  async getRumah(id) {
    const res = await fetch(`${this.baseURL}/rumah/${id}`);
    if (!res.ok) throw new Error(this.handleError(res.status));
    return res.json();
  }

  handleError(status) {
    const errors = { 404: "Rumah tidak ditemukan", 500: "Server error" };
    return errors[status] || "Unknown error";
  }
}
```
Ini menggabungkan struktur class (Level 4) dengan Fetch API untuk kode yang reusable dan rapi.

```js
async function ambilUser(id) {
  try {
    const res = await fetch(`https://jsonplaceholder.typicode.com/users/${id}`);
    if (!res.ok) throw new Error(`User ${id} tidak ditemukan (status ${res.status})`);
    return await res.json();
  } catch (error) {
    console.error(error.message);
    return null;
  }
}

// Test
ambilUser(1).then((user) => console.log(user?.name)); // "Leanne Graham"
ambilUser(999).then((user) => console.log(user));      // null
```
