# Class Inheritance

## Penjelasan
Class inheritance memungkinkan sebuah class mewarisi properti dan method dari class lain menggunakan keyword `extends`. Class anak (child) dapat menambah atau menimpa (override) method dari class induk (parent). Di dalam constructor child, `super()` wajib dipanggil untuk menginisialisasi induk. Ibarat rumah turunan: dari rumah minimalis, Anda buat rumah minimalis-berkolam yang mewarisi semua fitur plus tambahan sendiri.

## Fungsi
- Mendefinisikan hierarki "is-a" (RumahMewah **adalah** Rumah).
- Menghindari duplikasi kode dengan mewarisi dari class yang sudah ada.
- Memungkinkan overriding dan polymorphism.

## Cara Pengimplementasian

```javascript
// Class Inheritance — analogi RUMAH TURUNAN
class Rumah {
  constructor(tipe, kamar, warna) {
    this.tipe = tipe;
    this.kamar = kamar;
    this.warna = warna;
  }

  info() {
    return `${this.warna} ${this.tipe} dengan ${this.kamar} kamar`;
  }

  renovasi() {
    return `Merombak ${this.tipe}`;
  }
}

// RumahMewah adalah turunan Rumah
class RumahMewah extends Rumah {
  constructor(tipe, kamar, warna, kolamRenang, garasi) {
    super(tipe, kamar, warna); // wajib — panggil constructor induk
    this.kolamRenang = kolamRenang;
    this.garasi = garasi;
  }

  // Method baru — khusus RumahMewah
  infoMewah() {
    const kolam = this.kolamRenang ? "ada kolam" : "tanpa kolam";
    return `Rumah mewah ${this.warna}, ${kolam}, garasi ${this.garasi} mobil`;
  }

  // Override method info dari induk
  info() {
    return `${super.info()} — ${this.infoMewah()}`;
  }
}

const rm = new RumahMewah("Mewah", 6, "Putih", true, 2);
console.log(rm.info());
// "Putih Mewah dengan 6 kamar — Rumah mewah Putih, ada kolam, garasi 2 mobil"

console.log(rm.renovasi());   // "Merombak Mewah" — method warisan
console.log(rm instanceof RumahMewah); // true
console.log(rm instanceof Rumah);      // true — karena turunan
```

## Analogi
Inheritance = **rumah turunan dengan tambahan ruangan**. Rumah minimalis punya 3 kamar, 1 kamar mandi, dapur. RumahMewah mewarisi semua itu, lalu menambahkan kolam renang, garasi, dan taman. Tamu yang datang ke RumahMewah tetap bisa menggunakan dapur dan kamar mandi warisan dari Rumah — seperti method `renovasi()` yang diturunkan.

## Dipakai Untuk Apa
- Model data yang memiliki hierarki alami (User → Admin, Employee → Manager)
- Komponen UI yang punya basis sama (Button → IconButton → SubmitButton)
- Framework/library yang menyediakan base class untuk di-extend

## Kesalahan Umum
- Lupa panggil `super()` di constructor child — error: "Must call super constructor"
- Memanggil `super()` sebelum menggunakan `this` — urutan penting
- Inheritance chain terlalu dalam (diamond problem) — kompleks dan rapuh
- Overriding method tanpa sengaja karena nama method bentrok

## Keterkaitan dengan Materi Sebelumnya
Di Level 3, Anda belajar function dan closure. Inheritance adalah evolusi alami dari pola constructor + prototype chain. Di ES6, `extends` dan `super` menggantikan `ParentClass.call(this)` dan `Object.create(Parent.prototype)` yang rumit.

## Soal Latihan

Apa outputnya?

```javascript
class A {
  constructor() { this.x = 1; }
  getX() { return this.x; }
}

class B extends A {
  constructor() {
    super();
    this.x = 2;
  }
  getX() {
    return super.getX() + this.x;
  }
}

const b = new B();
console.log(b.getX());
```

>!`4`. `super.getX()` mengembalikan `this.x` dalam konteks instance B, yaitu `2`. Ditambah `this.x` (juga `2`) = `4`. `super` merujuk ke prototype, tapi `this` tetap instance yang sama.!
