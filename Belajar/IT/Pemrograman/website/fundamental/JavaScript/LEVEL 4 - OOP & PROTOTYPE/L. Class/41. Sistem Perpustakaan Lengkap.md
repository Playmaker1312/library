# Sistem Perpustakaan Lengkap

## Penjelasan
Sistem perpustakaan adalah studi kasus nyata yang menggabungkan seluruh konsep Level 4: prototype chain, constructor function / class, inheritance, dan composition. Kita akan membangun sistem manajemen perpustakaan dengan buku, anggota, petugas, dan peminjaman — semuanya dalam tema **RUMAH**. Perpustakaan adalah rumah bagi buku, anggota adalah penghuni, dan petugas adalah pengelola rumah.

## Fungsi
- Mengintegrasikan OOP & Prototype dalam satu aplikasi utuh.
- Mendemonstrasikan pewarisan (inheritance) dan komposisi secara berdampingan.
- Memberikan contoh arsitektur software sederhana namun realistis.

## Cara Pengimplementasian

```javascript
// === SISTEM PERPUSTAKAAN LENGKAP — TEMA RUMAH ===

// --- MODUL KOMPOSISI (seperti modul rumah) ---

const punyaAlamat = (state) => ({
  gantiAlamat: (almt) => { state.alamat = almt; },
  getAlamat: () => state.alamat
});

const punyaKontak = (state) => ({
  hubungi: () => `Menghubungi ${state.nama} di ${state.telp}`
});

const bisaCetak = (state) => ({
  cetak: () => state.data.map((item, i) => `${i + 1}. ${item.info()}`).join("\n")
});

// --- CLASS: RUMAH DASAR (inheritance base) ---

class Rumah {
  constructor(nama, alamat) {
    this.nama = nama;
    this.alamat = alamat;
    this._listrik = true;
  }

  info() {
    return `${this.nama} di ${this.alamat}`;
  }

  nyalakanLampu() {
    return this._listrik ? "Lampu menyala" : "Listrik padam";
  }
}

// --- INHERITANCE: Perpustakaan adalah Rumah khusus ---

class Perpustakaan extends Rumah {
  constructor(nama, alamat, jamBuka) {
    super(nama, alamat);
    this.jamBuka = jamBuka;
    this.koleksi = [];    // buku-buku
    this.anggota = [];    // anggota terdaftar
    this.petugas = [];    // petugas
    this.peminjaman = []; // transaksi aktif
  }

  // --- MANAJEMEN BUKU ---
  tambahBuku(buku) {
    this.koleksi.push(buku);
    return `${buku.judul} ditambahkan ke ${this.nama}`;
  }

  cariBuku(judul) {
    return this.koleksi.find((b) => b.judul.toLowerCase().includes(judul.toLowerCase()));
  }

  // --- MANAJEMEN ANGGOTA ---
  daftarkanAnggota(anggota) {
    this.anggota.push(anggota);
    anggota.terdaftarDi = this.nama;
    return `${anggota.nama} terdaftar di ${this.nama}`;
  }

  // --- MANAJEMEN PETUGAS ---
  tambahPetugas(petugas) {
    this.petugas.push(petugas);
    return `Petugas ${petugas.nama} ditugaskan`;
  }

  // --- PEMINJAMAN ---
  pinjamBuku(idAnggota, judulBuku, tanggal) {
    const anggota = this.anggota.find((a) => a.id === idAnggota);
    const buku = this.cariBuku(judulBuku);

    if (!anggota) return "Anggota tidak ditemukan";
    if (!buku || buku.dipinjam) return "Buku tidak tersedia";
    if (anggota.pinjamanAktif >= anggota.maksPinjam)
      return `Anggota mencapai batas pinjam (${anggota.maksPinjam})`;

    buku.dipinjam = true;
    anggota.pinjamanAktif++;
    this.peminjaman.push({ idAnggota, judul: buku.judul, tanggal, status: "aktif" });
    return `"${buku.judul}" dipinjam oleh ${anggota.nama}`;
  }

  kembalikanBuku(idAnggota, judulBuku) {
    const anggota = this.anggota.find((a) => a.id === idAnggota);
    const buku = this.cariBuku(judulBuku);

    if (!buku || !buku.dipinjam) return "Buku tidak dalam peminjaman";
    buku.dipinjam = false;
    anggota.pinjamanAktif--;

    const transaksi = this.peminjaman.find(
      (p) => p.idAnggota === idAnggota && p.judul === judulBuku && p.status === "aktif"
    );
    if (transaksi) transaksi.status = "dikembalikan";
    return `"${buku.judul}" dikembalikan oleh ${anggota.nama}`;
  }

  // --- LAPORAN ---
  laporanBukuTersedia() {
    const tersedia = this.koleksi.filter((b) => !b.dipinjam);
    return `Buku tersedia (${tersedia.length}):\n${tersedia.map((b, i) => `  ${i + 1}. ${b.info()}`).join("\n")}`;
  }

  info() {
    return `📚 ${super.info()} | Buka ${this.jamBuka} | ${this.koleksi.length} buku, ${this.anggota.length} anggota`;
  }
}

// --- CLASS BUKU ---
class Buku {
  constructor(judul, penulis, tahun, genre = "Umum") {
    this.judul = judul;
    this.penulis = penulis;
    this.tahun = tahun;
    this.genre = genre;
    this.dipinjam = false;
  }

  info() {
    return `${this.judul} — ${this.penulis} (${this.tahun}) [${this.genre}]${this.dipinjam ? " *dipinjam*" : ""}`;
  }
}

// --- INHERITANCE: Anggota (anggota perpustakaan = penghuni rumah) ---

class Penghuni {
  constructor(nama, id, telp) {
    this.nama = nama;
    this.id = id;
    this.telp = telp;
    this.pinjamanAktif = 0;
  }

  info() {
    return `${this.nama} (ID: ${this.id})`;
  }
}

class Anggota extends Penghuni {
  constructor(nama, id, telp, tipe = "reguler") {
    super(nama, id, telp);
    this.tipe = tipe;
    this.maksPinjam = tipe === "premium" ? 10 : 3;
    this.denda = 0;
    this.terdaftarDi = null;
  }

  info() {
    return `${super.info()} — ${this.tipe} (max ${this.maksPinjam} pinjam)`;
  }
}

// --- COMPOSITION: Petugas (gabungan Penghuni + modul alamat & kontak) ---

function buatPetugas(nama, id, telp, alamat, jabatan) {
  const state = { nama, id, telp, alamat, jabatan };

  return {
    ...new Penghuni(nama, id, telp),   // base via inheritance-like
    jabatan: state.jabatan,
    ...punyaAlamat(state),
    ...punyaKontak(state),
    info() {
      return `Petugas: ${state.nama} — ${state.jabatan} | ${state.alamat}`;
    },
    prosesPeminjaman(anggota, buku, perpus) {
      return perpus.pinjamBuku(anggota.id, buku.judul, new Date().toLocaleDateString());
    }
  };
}

// --- COMPOSITION: Laporan (modul cetak) ---

function buatLaporanKoleksi(perpustakaan) {
  const state = { data: perpustakaan.koleksi };
  return {
    ...bisaCetak(state),
    judul: `Koleksi ${perpustakaan.nama}`
  };
}

// =================== SKENARIO PENGGUNAAN ===================

// 1. Bangun perpustakaan
const perpus = new Perpustakaan(
  "Rumah Baca Ilmu",
  "Jl. Merdeka No. 10",
  "08:00 - 20:00"
);
console.log(perpus.info());

// 2. Tambah buku
const buku1 = new Buku("JavaScript Dasar", "Budi", 2022, "Pemrograman");
const buku2 = new Buku("OOP JavaScript", "Ani", 2023, "Pemrograman");
const buku3 = new Buku("Algoritma", "Cahyo", 2021, "Komputer");
const buku4 = new Buku("Novel Horor", "Dewi", 2024, "Fiksi");

console.log(perpus.tambahBuku(buku1));
console.log(perpus.tambahBuku(buku2));
console.log(perpus.tambahBuku(buku3));
console.log(perpus.tambahBuku(buku4));

// 3. Daftar anggota (inheritance)
const anggota1 = new Anggota("Siti", "A001", "08123456789", "premium");
const anggota2 = new Anggota("Rudi", "A002", "08198765432", "reguler");

console.log(perpus.daftarkanAnggota(anggota1));
console.log(perpus.daftarkanAnggota(anggota2));

// 4. Buat petugas (composition)
const petugas1 = buatPetugas("Pak Joko", "P001", "0822334455", "Jl. Rumah No. 5", "Kepala Perpus");
console.log(perpus.tambahPetugas(petugas1));
console.log(petugas1.info());

// 5. Transaksi peminjaman
console.log(perpus.pinjamBuku("A002", "JavaScript", new Date()));  // Rudi pinjam JS
console.log(perpus.pinjamBuku("A002", "Algoritma", new Date()));   // Rudi pinjam Algoritma
console.log(perpus.pinjamBuku("A001", "OOP", new Date()));         // Siti pinjam OOP

// 6. Cetak laporan via komposisi
const laporan = buatLaporanKoleksi(perpus);
console.log("\n=== LAPORAN KOLEKSI ===");
console.log(laporan.cetak());

// 7. Tampilkan buku tersedia
console.log("\n=== BUKU TERSEDIA ===");
console.log(perpus.laporanBukuTersedia());

// 8. Pengembalian
console.log(perpus.kembalikanBuku("A002", "Algoritma"));

// 9. Cek status akhir
console.log("\n=== STATUS AKHIR ===");
console.log(anggota1.info());
console.log(anggota2.info());
console.log(`Jumlah peminjaman aktif: ${perpus.peminjaman.filter((p) => p.status === "aktif").length}`);
```

## Analogi
Sistem perpustakaan = **Rumah Baca**. Perpustakaan adalah rumah bagi ribuan buku (koleksi). Penghuni rumah adalah anggota yang boleh meminjam buku. Petugas adalah pengelola rumah yang menjaga sirkulasi. Inheritance: Anggota premium dan reguler adalah tipe penghuni yang mewarisi sifat dasar penghuni. Composition: Petugas menggabungkan modul alamat dan kontak; Laporan menggabungkan modul cetak. Semua elemen bekerja bersama seperti rumah yang tertata rapi.

## Dipakai Untuk Apa
- Aplikasi manajemen inventaris / perpustakaan sungguhan
- Sistem informasi sekolah, kantor, atau organisasi
- Studi kasus pembelajaran arsitektur OOP di dunia nyata

## Kesalahan Umum
- Menempatkan terlalu banyak tanggung jawab dalam satu class (God object)
- Inheritance yang terlalu dalam — lebih baik komposisi untuk variasi perilaku
- Lupa menangani edge case (anggota tidak ditemukan, buku sudah dipinjam)
- Tidak memisahkan concern: sebaiknya class Peminjaman terpisah dari Perpustakaan

## Keterkaitan dengan Materi Sebelumnya
Seluruh Level 3 (closure, function, array method) dipakai di sini: `find`, `filter`, `map` untuk pencarian dan laporan, closure di komposisi (`state`), dan arrow function sebagai callback. Level 2 (object & array) jadi fondasi data. Level 1 (tipe data) jadi dasar properti.

## Soal Latihan

Buat class `BukuDigital` yang mewarisi `Buku` dengan properti tambahan `formatFile` (PDF/EPUB) dan `ukuranMB`. Override method `info()` untuk menampilkan format file. Buat instance dan panggil `info()`-nya.

>!
```javascript
class BukuDigital extends Buku {
  constructor(judul, penulis, tahun, genre, formatFile, ukuranMB) {
    super(judul, penulis, tahun, genre);
    this.formatFile = formatFile;
    this.ukuranMB = ukuranMB;
  }

  info() {
    return `${super.info()} | ${this.formatFile} (${this.ukuranMB}MB)`;
  }
}

const ebook = new BukuDigital("JS Guide", "Eko", 2024, "Pemrograman", "PDF", 15);
console.log(ebook.info());
// "JS Guide — Eko (2024) [Pemrograman] | PDF (15MB)"
```
