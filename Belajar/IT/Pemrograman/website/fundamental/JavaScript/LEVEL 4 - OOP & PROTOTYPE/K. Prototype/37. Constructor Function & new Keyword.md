# Constructor Function & new Keyword

## Penjelasan
Constructor function adalah fungsi biasa yang dipanggil dengan keyword `new` untuk membuat objek baru. Ketika `new` digunakan, JavaScript secara otomatis membuat objek kosong, mengikat `this` ke objek baru, menghubungkan objek ke `Constructor.prototype`, lalu mengembalikan objek tersebut (kecuali fungsi mengembalikan objek lain). Ibarat kontraktor rumah: `new` memanggil kontraktor, yang menyiapkan lahan kosong, memasang cetak biru, dan menyerahkan rumah jadi.

## Fungsi
- Membuat banyak objek dengan struktur dan method yang sama.
- Merepresentasikan _"class"_ sebelum ES6.
- Menyediakan reusable _blueprint_ dengan prototype sharing.

## Cara Pengimplementasian

```javascript
// Constructor Function — analogi KONTRAKTOR RUMAH
function Rumah(tipe, kamar, warna) {
  // `this` adalah objek baru yang dibuat oleh `new`
  this.tipe = tipe;
  this.kamar = kamar;
  this.warna = warna;
  // Method langsung di instance (tidak efisien — lihat prototype)
}

// Method via prototype — efisien, dipakai bersama
Rumah.prototype.info = function () {
  return `${this.warna} ${this.tipe} dengan ${this.kamar} kamar`;
};

Rumah.prototype.nyalakanLampu = function () {
  return `Lampu di ${this.tipe} menyala`;
};

// Membangun rumah — panggil dengan `new`
const rumah1 = new Rumah("Minimalis", 3, "Putih");
const rumah2 = new Rumah("Joglo", 5, "Coklat");

console.log(rumah1.info());        // "Putih Minimalis dengan 3 kamar"
console.log(rumah2.info());        // "Coklat Joglo dengan 5 kamar"
console.log(rumah1.nyalakanLampu() === rumah2.nyalakanLampu()); // method SAMA (referensi)
console.log(rumah1 instanceof Rumah); // true

// Cek hubungan prototype
console.log(Object.getPrototypeOf(rumah1) === Rumah.prototype); // true
```

## Analogi
Constructor function = **kontraktor rumah**. `new` = **proses memanggil kontraktor**. Kontraktor (`Rumah`) datang dengan cetak biru (prototype), menyiapkan lahan kosong (objek baru), mengisi spesifikasi (tipe, kamar, warna), lalu menyerahkan kunci rumah jadi. Semua rumah yang dibangun kontraktor yang sama punya buku panduan yang identik (method prototype).

## Dipakai Untuk Apa
- Membangun objek dalam jumlah banyak dengan struktur seragam
- Library/framework JavaScript lawas (pre-ES6) seperti jQuery, Backbone
- Memahami akar dari `class` syntax ES6

## Kesalahan Umum
- Lupa menulis `new` saat memanggil constructor — `this` jadi global (window/undefined)
- Menaruh method langsung di `this` di dalam constructor (boros memori)
- Mengembalikan objek lain dari constructor function (mengabaikan objek `this`)
- Menganggap `Constructor` itu sendiri adalah tipe data (padahal object biasa)

## Keterkaitan dengan Materi Sebelumnya
Di Level 3, function bisa menjadi closure yang menyimpan state. Constructor function memanfaatkan mekanisme `new` dan prototype untuk membuat objek massal. Pahami bahwa function adalah first-class citizen — bisa dipanggil dengan `new` untuk peran berbeda.

## Soal Latihan

Apa outputnya?

```javascript
function Rumah(warna) {
  this.warna = warna;
  this.kamar = 2;
}

Rumah.prototype.kamar = 4;

const r = new Rumah("Merah");
console.log(r.kamar);
console.log(r.hasOwnProperty("kamar"));
```

>!`2` lalu `true`. `this.kamar = 2` di constructor membuat properti _own_ pada instance, yang menutupi `prototype.kamar`. `hasOwnProperty` mengembalikan `true` karena `kamar` milik instance, bukan prototype.!
