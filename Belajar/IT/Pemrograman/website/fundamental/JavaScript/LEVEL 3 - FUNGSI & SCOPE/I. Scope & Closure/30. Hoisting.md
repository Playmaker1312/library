# 30. Hoisting

## Penjelasan
**Hoisting** adalah mekanisme JavaScript di mana deklarasi variabel dan fungsi dipindahkan ("diangkat") ke atas scope-nya sebelum kode dieksekusi. Untuk **Function Declaration**, seluruh fungsi diangkat sehingga bisa dipanggil sebelum dideklarasikan. Untuk **`var`**, hanya deklarasinya yang diangkat (nilainya `undefined`), bukan inisialisasinya. Untuk **`let`** dan **`const`**, deklarasinya diangkat tapi tidak diinisialisasi — berada di "Temporal Dead Zone" (TDZ) sehingga tidak bisa diakses sebelum baris deklarasi.

## Fungsi
Hoisting memungkinkan function declaration digunakan di mana saja dalam scope-nya tanpa khawatir urutan deklarasi. Ini memudahkan pembacaan kode karena fungsi utama bisa diletakkan di bawah, sedangkan logika eksekusi di atas. Untuk variabel, hoisting adalah efek samping yang perlu dipahami untuk menghindari bug.

## Cara Pengimplementasian
```js
// Function Declaration — full hoisting
console.log(cekRumah()); // ✅ "Ini rumah" — fungsi diangkat seluruhnya

function cekRumah() {
  return "Ini rumah";
}

// var — hanya deklarasi yang dihoist
console.log(alamatRumah); // ✅ undefined (bukan error!)
var alamatRumah = "Jl. Mawar";

// Di atas sebenarnya dieksekusi seperti:
// var alamatRumah; // di-hoist
// console.log(alamatRumah); // undefined
// alamatRumah = "Jl. Mawar";

// let / const — Temporal Dead Zone
// console.log(namaRumah); // ❌ ReferenceError — TDZ
let namaRumah = "Rumah Biru";

// console.log(hargaRumah); // ❌ ReferenceError — TDZ
const hargaRumah = 500000;
```

## Analogi
**Hoisting = Menaikkan perabot ke lantai atas rumah**:
- **Function Declaration** = **Mengangkat sofa utuh ke lantai 2** — sofa bisa langsung dipakai begitu sampai di atas, lengkap dan siap pakai.
- **`var`** = **Menaikkan kardus kosong ke loteng** — kardusnya sudah di atas (deklarasi di-hoist), tapi isinya belum dimasukkan (nilai `undefined`).
- **`let` / `const`** = **Memesan lift untuk lemari** — kamu tahu lemari akan naik (deklarasi di-hoist), tapi lemari belum bisa dipakai sampai lift benar-benar tiba di lantai tujuan (melewati TDZ).
- **Temporal Dead Zone (TDZ)** = **Lorong waktu antara lift dipanggil dan pintu lift terbuka** — lemari ada di dalam lift, tapi kamu belum bisa mengambilnya.

## Dipakai Untuk Apa
Hoisting pada function declaration dimanfaatkan agar kamu bisa menulis kode dengan fungsi utama di bagian bawah dan logika pemanggilan di bagian atas (lebih mudah dibaca). Pemahaman hoisting juga penting saat debugging — error `undefined` misterius pada `var` sering disebabkan hoisting. Pengetahuan tentang TDZ membantu kamu menulis kode yang lebih aman dengan `let`/`const`.

## Kesalahan Umum
Paling umum: mengira `var` di-hoisting dengan nilainya. Contoh: `console.log(x); var x = 5;` menghasilkan `undefined`, bukan error dan bukan 5. Mengakses `let`/`const` sebelum deklarasi menghasilkan ReferenceError karena TDZ. Juga, function expression tidak di-hoisting meskipun menggunakan `var` — hanya deklarasi variabelnya yang dihoist (jadi `undefined`), sehingga memanggilnya sebelum assignment menghasilkan TypeError.
