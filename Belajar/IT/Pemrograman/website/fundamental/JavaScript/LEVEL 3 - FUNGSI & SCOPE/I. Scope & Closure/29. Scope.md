# 29. Scope

## Penjelasan
**Scope** adalah konsep yang menentukan di bagian mana dari kode suatu variabel dapat diakses. JavaScript memiliki tiga jenis scope: **Global Scope** (variabel bisa diakses dari mana saja), **Function Scope** (variabel hanya bisa diakses di dalam function tempat ia dideklarasikan — berlaku untuk `var`), dan **Block Scope** (variabel hanya bisa diakses di dalam block `{ }` — berlaku untuk `let` dan `const`). Setiap kali sebuah fungsi dipanggil, JavaScript membuat **scope baru** di dalamnya.

## Fungsi
Scope melindungi variabel dari konflik nama dan akses yang tidak diinginkan. Variabel di dalam fungsi tidak akan "bocor" ke luar, sehingga kamu bisa menggunakan nama variabel yang sama di fungsi berbeda tanpa masalah. Scope juga membantu manajemen memori — variabel lokal akan dihapus setelah fungsi selesai dieksekusi.

## Cara Pengimplementasian
```js
// Global Scope
const rumahGlobal = "Rumah Utama"; // Bisa diakses di mana saja

function kamarDepan() {
  // Function Scope (var)
  var perabotVar = "Meja var"; // Hanya di dalam kamarDepan
  console.log(rumahGlobal); // ✅ Bisa akses global
  
  if (true) {
    // Block Scope (let/const)
    let perabotLet = "Kursi let"; // Hanya di block ini
    const perabotConst = "Lemari const"; // Hanya di block ini
    var perabotVar2 = "Rak var"; // ❗ Bocor ke function scope!
    console.log(perabotLet); // ✅ Bisa akses
    console.log(rumahGlobal); // ✅ Bisa akses
  }
  
  console.log(perabotVar2); // ✅ "Rak var" — var bocor keluar block!
  // console.log(perabotLet); // ❌ ReferenceError — let tidak bocor
}

kamarDepan();
// console.log(perabotVar); // ❌ ReferenceError — function scope
```

## Analogi
**Scope = ruangan-ruangan di dalam rumah**:
- **Global Scope** = **Halaman luar rumah** — semua orang bisa mengaksesnya, termasuk tetangga dan orang lewat.
- **Function Scope** = **Kamar tidur pribadi** — hanya penghuni kamar itu yang tahu isi lemari di dalamnya (`var`).
- **Block Scope** = **Laci di dalam meja** — hanya di dalam laci itulah benda-benda kecil (`let`/`const`) tersimpan.
- **Scope chain** = **Pintu antar ruangan** — dari ruang dalam kamu bisa keluar ke halaman, tapi dari halaman tidak bisa masuk ke kamar tanpa izin.

## Dipakai Untuk Apa
Global scope dipakai untuk variabel konfigurasi aplikasi, environment variable, atau state global yang memang perlu diakses semua fungsi. Function scope dipakai untuk variabel internal fungsi yang tidak perlu diketahui luar. Block scope dipakai untuk variabel sementara seperti counter loop (`for (let i = 0; ...)`), variabel dalam kondisi `if`, atau variabel dalam block `try/catch`.

## Kesalahan Umum
Menggunakan `var` di dalam block sehingga variabel "bocor" keluar. Lupa bahwa variabel yang dideklarasikan tanpa keyword (`x = 5`) menjadi global otomatis (error di strict mode). Juga, pemula sering bingung bahwa block `if`, `for`, `while` dengan `var` tidak menciptakan scope baru — `var` hanya peduli pada function scope. Gunakan `let`/`const` secara default untuk menghindari masalah ini.

## Keterkaitan dengan Materi Sebelumnya
Scope berhubungan langsung dengan materi variabel (5. var, let, const) di Level 1 — perbedaan utama `var`, `let`, `const` ada pada scope-nya. Saat kamu menulis fungsi (materi 27), setiap fungsi menciptakan scope barunya sendiri. Pemahaman scope akan menjadi fondasi untuk materi berikutnya: Hoisting (30) dan Closure (31).

## Soal Latihan
Apa output dari kode berikut?
```js
let a = "luar";
if (true) {
  let a = "dalam";
  console.log(a);
}
console.log(a);
```

<details>
<summary>Jawaban</summary>
Output: `"dalam"` lalu `"luar"`. Variabel `a` di dalam block adalah variabel baru (block scope dengan `let`), tidak menimpa `a` di luar block.
</details>
