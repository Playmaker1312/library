# 32. Higher-Order Functions

## Penjelasan
**Higher-Order Function (HOF)** adalah fungsi yang melakukan setidaknya satu dari dua hal: menerima fungsi lain sebagai argumen (callback), atau mengembalikan fungsi lain sebagai hasil. Ini dimungkinkan karena di JavaScript, fungsi adalah **first-class citizen** — fungsi bisa diperlakukan seperti nilai (disimpan dalam variabel, dikirim sebagai argumen, dikembalikan dari fungsi lain). Array methods seperti `.map()`, `.filter()`, `.reduce()` adalah contoh HOF bawaan JavaScript.

## Fungsi
HOF memungkinkan abstraksi pola umum — daripada menulis loop manual setiap kali, kamu bisa menggunakan HOF untuk memproses data secara deklaratif. HOF membuat kode lebih ringkas, mudah dibaca, dan mudah diuji karena logika kecil (callback) dipisahkan dari logika iterasi. HOF juga memungkinkan **komposisi fungsi** — menggabungkan fungsi-fungsi kecil untuk membangun operasi kompleks.

## Cara Pengimplementasian
```js
// HOF yang menerima fungsi sebagai argumen
function prosesRumah(rumah, transformFn) {
  return transformFn(rumah);
}

const rumah = { nama: "Rumah Biru", luas: 120 };

const hasil = prosesRumah(rumah, (r) => `${r.nama} seluas ${r.luas} m²`);
console.log(hasil); // Rumah Biru seluas 120 m²

// HOF yang mengembalikan fungsi (factory function)
function buatPembersih(alat) {
  return function(ruangan) {
    console.log(`Membersihkan ${ruangan} dengan ${alat}`);
  };
}

const sapu = buatPembersih("sapu");
const pel = buatPembersih("pel");

sapu("ruang tamu"); // Membersihkan ruang tamu dengan sapu
pel("kamar tidur"); // Membersihkan kamar tidur dengan pel

// Array HOF bawaan — .map() .filter() .reduce()
const kamar = ["Tidur", "Mandi", "Tamu", "Dapur"];
const kamarBesar = kamar.filter(k => k.length > 4); // ["Tidur", "Mandi", "Dapur"]
console.log(
  kamar
    .filter(k => k !== "Mandi")
    .map(k => `Kamar ${k}`)
    .join(", ")
); // Kamar Tidur, Kamar Tamu, Kamar Dapur
```

## Analogi
**HOF = Kontraktor yang mempekerjakan tukang lain**:
Kontraktor proyek rumah (HOF) tidak harus mengerjakan semuanya sendiri. Dia bisa:
- **Menerima tukang** (fungsi callback) — "Hei tukang cat, cat dinding ini!" — kontraktor menerima pekerja dan menyuruh mereka bekerja.
- **Mengembalikan tukang spesialis** (factory function) — "Aku akan melatihmu jadi tukang listrik spesialis" — kontraktor melatih dan mengirim tukang ke proyek lain.
- **.map(), .filter(), .reduce()** = **Mandor dengan tugas spesifik** — `.map()` mengubah setiap ruangan (pasang keramik di semua kamar), `.filter()` memilih ruangan tertentu (pilih kamar yang perlu dicat ulang), `.reduce()` menggabungkan semua (hitung total anggaran renovasi).

## Dipakai Untuk Apa
HOF digunakan di mana-mana: Array methods (`.map()`, `.filter()`, `.reduce()`, `.forEach()`, `.find()`, `.some()`, `.every()`), event listener (`element.addEventListener("click", callback)`), fungsi timer (`setTimeout()`, `setInterval()`), middleware Express/Redux, komposisi komponen di React (Higher-Order Components), dan utility libraries seperti Lodash.

## Kesalahan Umum
Pemula sering lupa bahwa HOF seperti `.map()` mengembalikan array baru, tidak mengubah array asli — jadi harus ditampung dalam variabel. Juga, menggunakan `.forEach()` padahal `.map()` lebih tepat (`.map()` untuk transformasi, `.forEach()` untuk side effect). Kesalahan lain: membuat HOF sendiri tanpa menangani konteks `this` dengan benar jika menggunakan function declaration biasa.

## Keterkaitan dengan Materi Sebelumnya
HOF adalah pengembangan dari konsep fungsi sebagai nilai (materi 27 — Function Expression & Arrow). HOF memanfaatkan closure (materi 31) — factory function menggunakan closure untuk "mengingat" argumen seperti `alat`. Callback functions (materi 33) adalah aplikasi langsung dari HOF. Pemahaman array (Level 2) diperlukan untuk menggunakan `.map()`/`.filter()`/`.reduce()` secara efektif.

## Soal Latihan
Buat HOF `buatSuhuRumah(pengubah)` yang menerima fungsi pengubah suhu, lalu gunakan untuk mengubah suhu dari Celsius ke Fahrenheit dan ke Kelvin.

<details>
<summary>Jawaban</summary>
```js
function buatSuhuRumah(pengubah) {
  return function(celsius) {
    return pengubah(celsius);
  };
}

const keFahrenheit = buatSuhuRumah(c => (c * 9/5) + 32);
const keKelvin = buatSuhuRumah(c => c + 273.15);
console.log(keFahrenheit(30)); // 86
console.log(keKelvin(30)); // 303.15
```
