# 35. Recursion

## Penjelasan
**Recursion** adalah teknik pemrograman di mana sebuah fungsi memanggil dirinya sendiri. Setiap panggilan rekursif harus memiliki **base case** (kondisi berhenti) untuk mencegah infinite loop, dan **recursive case** (masalah yang diperkecil) yang mendekati base case setiap pemanggilan. Recursion sering digunakan untuk masalah yang bisa dipecah menjadi sub-masalah yang lebih kecil dengan pola yang sama — seperti traversing tree, perhitungan matematika (faktorial, fibonacci), dan algoritma divide-and-conquer.

## Fungsi
Recursion membuat kode lebih elegan dan deklaratif untuk masalah yang memiliki struktur rekursif alami (seperti nested object, DOM tree, direktori file, struktur data tree). Recursion bisa menggantikan loop (iterasi) untuk kasus tertentu, meskipun biasanya lebih lambat dan memakan lebih banyak memori (karena call stack). Recursion juga memungkinkan solusi yang sangat sulit diimplementasikan dengan iterasi biasa.

## Cara Pengimplementasian
```js
// Recursion: hitung total lantai rumah
function totalLantai(n) {
  // Base case: rumah dengan 0 lantai = 0
  if (n === 0) return 0;
  // Recursive case: 1 lantai + sisa lantai di bawahnya
  return 1 + totalLantai(n - 1);
}
console.log(totalLantai(5)); // 5

// Recursion: hitung total kamar di kompleks rumah bersarang
const kompleks = {
  nama: "Rumah Utama",
  kamar: 3,
  sayap: [
    { nama: "Sayap Kiri", kamar: 2, sayap: [] },
    {
      nama: "Sayap Kanan",
      kamar: 1,
      sayap: [
        { nama: "Garasi", kamar: 0, sayap: [] }
      ]
    }
  ]
};

function hitungTotalKamar(gedung) {
  let total = gedung.kamar;
  for (const s of gedung.sayap) {
    total += hitungTotalKamar(s); // Rekursif untuk setiap sayap
  }
  return total;
}
console.log(hitungTotalKamar(kompleks)); // 6 (3+2+1+0)

// Recursion vs Iteration: faktorial
function faktorialRekursif(n) {
  if (n <= 1) return 1;
  return n * faktorialRekursif(n - 1);
}

function faktorialIteratif(n) {
  let hasil = 1;
  for (let i = 2; i <= n; i++) hasil *= i;
  return hasil;
}

console.log(faktorialRekursif(5)); // 120
console.log(faktorialIteratif(5)); // 120
```

## Analogi
**Recursion = Cermin yang memantulkan cermin lain**:
Bayangkan kamu berdiri di antara dua cermin yang saling berhadapan. Kamu melihat dirimu, yang di dalamnya ada dirimu lagi, dan seterusnya (rekursi). Tapi ada batasnya — cermin terkecil di paling ujung hanya memantulkan titik (base case).
- **Base case** = **Cermin paling kecil** — tidak ada pantulan lagi, hanya titik. Ini yang menghentikan rekursi.
- **Recursive case** = **Cermin yang memantulkan cermin lain** — setiap pantulan lebih kecil dari sebelumnya.
- **Call stack** = **Tumpukan cermin** — semakin dalam pantulan, semakin banyak cermin yang ditumpuk. Kalau terlalu dalam, bisa pecah (stack overflow).

**Analogi rumah**: Bayangkan rumah boneka (Russian doll/matryoshka) — membuka boneka besar (fungsi utama), di dalamnya ada boneka lebih kecil (panggilan rekursif), terus sampai boneka terkecil yang tidak bisa dibuka lagi (base case). Setelah sampai boneka terkecil, kamu mulai menutup kembali semua boneka (return value merambat ke atas).

## Dipakai Untuk Apa
Recursion dipakai untuk: **Traversal struktur data tree** (DOM tree, file system, komponen tree), **Algoritma pencarian dan pengurutan** (Binary Search, Merge Sort, Quick Sort), **Parsing ekspresi** (compiler, kalkulator), **Masalah matematika** (faktorial, fibonacci, fibonacci dengan memoization), **Backtracking** (puzzle, path finding), **Struktur data** (Linked List, Tree, Graph traversal).

## Kesalahan Umum
**Lupa base case** — menyebabkan infinite recursion dan stack overflow. **Tidak memperkecil masalah** — rekursi tidak pernah mendekati base case. **Stack overflow** untuk rekursi yang terlalu dalam (JavaScript biasanya memiliki batas ~10.000 panggilan). **Performa buruk tanpa memoization** — fibonacci rekursif naif memiliki kompleksitas O(2^n). **Bingung antara rekursi dan iterasi** — rekursi bukan selalu lebih baik; untuk masalah linear sederhana, iterasi lebih efisien.

## Keterkaitan dengan Materi Sebelumnya
Recursion adalah bentuk spesial dari fungsi (materi 27) — fungsi yang memanggil dirinya sendiri. Recursion sering diterapkan sebagai pure function (materi 34) — deterministik dan tanpa side effect. HOF (materi 32) bisa digunakan untuk membuat fungsi rekursif yang lebih umum (seperti `reduce` yang bisa didefinisikan secara rekursif). Materi closure (materi 31) berguna jika menggabungkan rekursi dengan memoization. Struktur data array dan object dari Level 2 sering menjadi input recursion.

## Soal Latihan
Buat fungsi rekursif `fibonacci(n)` yang mengembalikan angka fibonacci ke-n (deret: 0, 1, 1, 2, 3, 5, 8, 13...). Base case: fib(0)=0, fib(1)=1.

<details>
<summary>Jawaban</summary>
```js
function fibonacci(n) {
  if (n === 0) return 0;
  if (n === 1) return 1;
  return fibonacci(n - 1) + fibonacci(n - 2);
}
console.log(fibonacci(7)); // 13

// Optimasi dengan memoization (opsional):
function fibMemo(n, memo = {}) {
  if (n in memo) return memo[n];
  if (n === 0) return 0;
  if (n === 1) return 1;
  memo[n] = fibMemo(n - 1, memo) + fibMemo(n - 2, memo);
  return memo[n];
}
```
