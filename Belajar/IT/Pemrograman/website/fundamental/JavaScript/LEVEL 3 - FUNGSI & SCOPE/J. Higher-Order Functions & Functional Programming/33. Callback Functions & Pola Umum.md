# 33. Callback Functions & Pola Umum

## Penjelasan
**Callback function** adalah fungsi yang dikirimkan sebagai argumen ke fungsi lain dan akan dipanggil (dieksekusi) di dalam fungsi tersebut. Callback memungkinkan kode menjadi **asinkron** (tidak memblokir eksekusi berikutnya) atau **deklaratif** (kamu bilang "apa yang harus dilakukan", bukan "bagaimana melakukannya"). Pola callback adalah fondasi dari semua pola asinkron di JavaScript — Promise, async/await, dan event-driven programming.

## Fungsi
Callback memisahkan **kapan** suatu tindakan dilakukan dari **apa** tindakannya. Contoh: tombol bel rumah — kamu tidak tahu kapan tamu akan datang, tapi kamu sudah menyiapkan apa yang harus dilakukan (bel berbunyi). Callback juga memungkinkan komposisi kode yang fleksibel — fungsi yang sama bisa dipanggil dengan callback berbeda untuk menghasilkan perilaku berbeda.

## Cara Pengimplementasian
```js
// Callback sinkron — eksekusi langsung
function renovasiRumah(ruangan, callback) {
  console.log(`Mulai renovasi ${ruangan}...`);
  callback(ruangan);
  console.log(`Selesai ${ruangan}`);
}

renovasiRumah("kamar tidur", (ruang) => {
  console.log(`  > Mengecat ${ruang}`);
});
// Mulai renovasi kamar tidur...
//   > Mengecat kamar tidur
// Selesai kamar tidur

// Callback asinkron — setTimeout (simulasi)
function pasangAC(namaRuangan, callback) {
  console.log(`Memasang AC di ${namaRuangan}...`);
  setTimeout(() => {
    console.log(`AC ${namaRuangan} terpasang!`);
    callback(null, `${namaRuangan} sudah dingin`);
  }, 1000);
}

pasangAC("ruang tamu", (err, pesan) => {
  if (err) {
    console.log("Gagal:", err);
    return;
  }
  console.log(pesan);
});
// Memasang AC di ruang tamu...
// (1 detik kemudian)
// AC ruang tamu terpasang!
// ruang tamu sudah dingin

// Pola umum: Event listener

```

## Analogi
**Callback = Bel rumah yang terhubung ke berbagai perangkat**:
- Kamu memasang bel rumah dan menghubungkannya ke **lonceng** (callback). Saat tamu menekan tombol (event), lonceng berbunyi (callback dipanggil).
- Kalau kamu mengganti lonceng dengan **lampu** (callback berbeda), saat tamu menekan tombol, lampu menyala — fungsi yang sama (bel rumah), perilaku berbeda (callback).
- **Callback sinkron** = **Lampu yang menyala langsung saat saklar ditekan** — terjadi saat itu juga.
- **Callback asinkron** = **Memesan furnitur** — kamu memesan (memanggil fungsi), kasir bilang "nanti kami kirim" (langsung kembali), dan beberapa hari kemudian furnitur tiba (callback dipanggil).
- **Callback hell** = **Rantai renovasi rumah yang kacau**: "Setelah cat kering, pasang lampu, lalu pasang gorden, lalu...", semua bersarang di dalam satu sama lain sehingga kode menjadi segitiga terbalik yang sulit dibaca.

## Dipakai Untuk Apa
Callback dipakai untuk: **Event handling** (click, keypress, submit), **Operasi I/O asinkron** (baca file, request HTTP, query database), **Array methods** (`.forEach()`, `.map()`, `.filter()`, `.sort()` dengan comparator), **Timer** (`setTimeout()`, `setInterval()`), **Middleware pattern** (Express.js), dan **Error-first callback** (pola Node.js: `fs.readFile(path, (err, data) => ...)`).

## Kesalahan Umum
**Callback Hell** (pyramid of doom) — callback bersarang terlalu dalam sehingga kode sulit dibaca dan di-maintain. **Lupa menangani error** — callback biasanya punya parameter error pertama (error-first callback) yang sering diabaikan. **Callback dipanggil lebih dari sekali** — menyebabkan bug sulit dilacak. **Inversion of Control** — kamu memberikan kontrol ke fungsi lain, termasuk kapan dan bagaimana callback dipanggil. Solusi modern: Promise dan async/await.

## Keterkaitan dengan Materi Sebelumnya
Callback adalah aplikasi langsung dari HOF (materi 32) — HOF yang menerima fungsi sebagai argumen. Callback memanfaatkan closure (materi 31) — callback "mengingat" variabel di scope pembuatnya. Arrow function (materi 27) sangat sering digunakan sebagai callback karena sintaksnya ringkas. Di materi level berikutnya, kamu akan belajar Promise (evolusi dari callback) dan async/await (sintaks yang membuat kode asinkron terlihat seperti sinkron).

## Soal Latihan
Buat fungsi `prosesAntrianRumah(antrian, callback)` yang menerima array nama ruangan dan callback. Fungsi memproses setiap ruangan satu per satu dengan jeda 500ms (simulasi dengan setTimeout loop). Panggil dengan callback yang mencatat "Membersihkan [ruangan]".

<details>
<summary>Jawaban</summary>
```js
function prosesAntrianRumah(antrian, callback) {
  antrian.forEach((ruang, i) => {
    setTimeout(() => callback(ruang), i * 500);
  });
}

prosesAntrianRumah(["Dapur", "Kamar", "Taman"], (r) => {
  console.log(`Membersihkan ${r}`);
});
// (0.5s) Membersihkan Dapur
// (1.0s) Membersihkan Kamar
// (1.5s) Membersihkan Taman
```
