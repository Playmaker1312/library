# 27. Function Declaration vs Expression vs Arrow

## Penjelasan
JavaScript memiliki tiga cara utama mendefinisikan fungsi. **Function Declaration** dideklarasikan dengan kata kunci `function` di awal statement dan di-hoisting — bisa dipanggil sebelum ditulis. **Function Expression** menyimpan fungsi ke dalam variabel, tidak di-hoisting, dan bisa dibuat anonymous. **Arrow Function** adalah sintaks ES6 yang lebih ringkas, tidak memiliki `this` sendiri, dan tidak bisa digunakan sebagai constructor.

## Fungsi
Ketiganya digunakan untuk membungkus kode yang bisa dipanggil ulang. Function Declaration cocok untuk fungsi utama yang perlu tersedia di seluruh scope. Function Expression cocok untuk fungsi yang disimpan sebagai nilai (callback, method object). Arrow Function ideal untuk fungsi singkat satu baris atau ketika ingin mempertahankan binding `this` dari lingkup sekitarnya.

## Cara Pengimplementasian
```js
// Function Declaration — di-hoisting
console.log(luasRumah(10, 8)); // Bisa dipanggil sebelum deklarasi
function luasRumah(p, l) {
  return p * l;
}

// Function Expression — tidak di-hoisting
const kelilingRumah = function(p, l) {
  return 2 * (p + l);
};
console.log(kelilingRumah(10, 8)); // 36

// Arrow Function — ringkas, tidak punya this sendiri
const volumeRumah = (p, l, t) => p * l * t;
console.log(volumeRumah(10, 8, 4)); // 320

// Arrow dengan satu parameter — boleh tanpa kurung
const pajakRumah = harga => harga * 0.1;
console.log(pajakRumah(500000)); // 50000
```

## Analogi
Dalam konteks **RUMAH**:
- **Function Declaration** = **Cetak biru rumah utama** — sudah ada di lemari arsitek sejak awal, bisa dilihat kapan saja bahkan sebelum lemari dibuka (hoisting).
- **Function Expression** = **Rakitan furnitur IKEA** — kamu harus mengeluarkan dari kotak dan merakitnya dulu sebelum bisa digunakan.
- **Arrow Function** = **Pintu otomatis sensor** — ringkas, tidak punya "pintu sendiri" (tidak punya `this` sendiri), dan langsung bekerja tanpa perlu pegangan pintu.

## Dipakai Untuk Apa
Function Declaration dipakai untuk fungsi utama aplikasi (helper, utilitas global). Function Expression dipakai untuk callback, event handler, atau fungsi yang disimpan dalam objek. Arrow Function dipakai untuk callback array (`.map()`, `.filter()`), fungsi singkat, atau saat perlu mengikat `this` ke konteks induk (seperti dalam class atau event listener).

## Kesalahan Umum
Menggunakan Arrow Function sebagai method object akan salah karena `this` tidak mengacu ke objek. Contoh: `const rumah = { nama: "Rumahku", panggil: () => console.log(this.nama) }` — `this.nama` adalah `undefined`. Juga, Arrow Function tidak bisa dipanggil dengan `new` (bukan constructor). Function Declaration di dalam block (`if`, `for`) bisa menyebabkan perilaku tidak terduga di strict mode.

## Keterkaitan dengan Materi Sebelumnya
Setelah menguasai variabel (`let`/`const` dari Level 1), kamu bisa menyimpan fungsi sebagai nilai layaknya variabel — inilah Function Expression. Pemahaman tentang scope (akan datang di materi 29) penting untuk memahami bagaimana `this` bekerja di Arrow Function vs regular function.

## Soal Latihan
Apa output dari kode berikut?
```js
console.log(coba(2));
var coba = function(n) { return n * 3; };
console.log(coba(2));
```

<details>
<summary>Jawaban</summary>
Baris pertama error (TypeError: coba is not a function) karena `var coba` di-hoisting sebagai `undefined`, bukan function. Baris kedua mencetak 6 karena Function Expression sudah di-assign. Gunakan `const` agar error lebih jelas.
</details>
