# 28. Parameters — Default, Rest & Destructuring

## Penjelasan
JavaScript modern (ES6+) menyediakan tiga fitur parameter canggih. **Default Parameters** memberikan nilai bawaan jika argumen tidak diberikan atau `undefined`. **Rest Parameters** (`...args`) menangkap sisa argumen menjadi array. **Destructuring Parameters** memecah object/array langsung di parameter fungsi, sehingga tidak perlu mengakses properti satu per satu.

## Fungsi
Default parameter mencegah error `undefined` dan mengurangi kode pengecekan manual. Rest parameter memungkinkan fungsi menerima jumlah argumen tak terbatas tanpa menggunakan object `arguments`. Destructuring parameter membuat kode lebih bersih saat fungsi menerima object konfigurasi atau array data.

## Cara Pengimplementasian
```js
// Default Parameter
function bangunRumah(panjang = 10, lebar = 8) {
  console.log(`Luas: ${panjang * lebar} m²`);
}
bangunRumah();           // Luas: 80 m² (pakai default)
bangunRumah(15);         // Luas: 120 m² (lebar default 8)

// Rest Parameter — menangkap sisa argumen
function daftarKamar(utama, ...lainnya) {
  console.log(`Kamar utama: ${utama}`);
  console.log(`Kamar lain: ${lainnya.join(", ")}`);
}
daftarKamar("Tidur", "Tamu", "Mandi", "Belajar");
// Kamar utama: Tidur
// Kamar lain: Tamu, Mandi, Belajar

// Destructuring Object Parameter
function displayRumah({ nama, luas, kamar = 3 }) {
  console.log(`${nama} — ${luas} m², ${kamar} kamar`);
}
displayRumah({ nama: "Rumah Biru", luas: 120 }); // Rumah Biru — 120 m², 3 kamar

// Destructuring Array Parameter
function ukuranKamar([p, l, t = 3]) {
  console.log(`Ukuran: ${p}x${l}x${t} m`);
}
ukuranKamar([5, 4]); // Ukuran: 5x4x3 m
```

## Analogi
Dalam konteks **RUMAH**:
- **Default Parameter** = **Kunci cadangan di pot bunga** — kalau kamu lupa bawa kunci asli (tidak kasih argumen), masih ada kunci default yang bisa dipakai.
- **Rest Parameter** = **Kotak "barang lain-lain" di gudang** — semua barang yang tidak masuk kategori utama dikumpulkan di satu kotak (array).
- **Destructuring Parameter** = **Bongkar koper langsung di rak** — daripada mengeluarkan baju satu per satu dari koper, kamu langsung membuka koper dan rak sudah terisi (properti langsung dipetakan ke variabel).

## Dipakai Untuk Apa
Default parameter dipakai untuk fungsi konfigurasi, optional options, atau fallback nilai. Rest parameter dipakai untuk fungsi log (menampilkan banyak argumen), fungsi matematika variadik (sum semua angka), atau wrapper function. Destructuring parameter dipakai untuk menerima object options/konfigurasi (pola umum di library React, Express), atau saat fungsi menerima data terstruktur dari API.

## Kesalahan Umum
Default parameter hanya berlaku untuk `undefined`, bukan `null` — `bangunRumah(null, 5)` tetap pakai `null`. Rest parameter harus menjadi parameter terakhir. Destructuring parameter tanpa nilai default akan error jika argumen `undefined` dilewatkan — beri default object kosong: `function fn({ a } = {})`. Pemula juga sering lupa bahwa destructuring array di parameter menggunakan `[]`, object menggunakan `{}`.

## Keterkaitan dengan Materi Sebelumnya
Destructuring parameter adalah pengembangan dari destructuring assignment yang diperkenalkan di Level 1 (variabel). Default parameter berkaitan dengan truthy/falsy (nilai default menggunakan `||` vs default parameter yang hanya bereaksi pada `undefined`). Rest parameter mirip dengan spread operator (sama-sama menggunakan `...`) yang sudah kamu pelajari di materi array/object.

## Soal Latihan
Buat fungsi `aturRumah` dengan parameter destructuring object yang memiliki properti `warna` (default "putih"), `lantai` (default 1), dan `kamar` (default 2). Panggil dengan `aturRumah({ warna: "biru" })`.

<summary>Jawaban</summary>
```js
function aturRumah({ warna = "putih", lantai = 1, kamar = 2 } = {}) {
  console.log(`Rumah ${warna}, ${lantai} lantai, ${kamar} kamar`);
}
aturRumah({ warna: "biru" }); // Rumah biru, 1 lantai, 2 kamar
```
