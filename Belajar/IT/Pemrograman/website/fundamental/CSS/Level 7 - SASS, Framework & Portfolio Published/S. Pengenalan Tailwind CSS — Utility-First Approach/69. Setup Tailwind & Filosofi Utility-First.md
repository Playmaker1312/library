# 69. Setup Tailwind & Filosofi Utility-First

## Penjelasan

Tailwind CSS adalah framework **utility-first** — menulis CSS dengan class utility kecil di HTML, bukan CSS kustom.

```html
<!-- Custom CSS approach -->
<div class="card">...</div>
<!-- .card { background: white; border-radius: 12px; padding: 24px; box-shadow: ...; } -->

<!-- Tailwind approach -->
<div class="bg-white rounded-xl p-6 shadow-md">...</div>
<!-- Tidak perlu nulis CSS — class utility langsung di HTML -->
```

## Fungsi

- **Cepat**: styling langsung di HTML, tidak perlu buka file CSS
- **Konsisten**: design system built-in (warna, spacing, typography)
- **Small CSS**: JIT (Just-In-Time) compiler hanya generate class yang dipakai

## Cara Pengimplementasian

**Setup Tailwind:**
```bash
npm install -D tailwindcss @tailwindcss/cli
npx tailwindcss init
```

**tailwind.config.js:**
```javascript
export default {
  content: ['./*.html', './src/**/*.{html,js}'],
  theme: {
    extend: {
      colors: {
        primary: {
          500: '#3b82f6',
          600: '#2563eb',
          700: '#1d4ed8',
        }
      },
      fontFamily: {
        sans: ['Inter', 'sans-serif'],
      }
    },
  },
}
```

**Input CSS (style.css):**
```css
@import "tailwindcss";
```

**Build:**
```bash
npx @tailwindcss/cli -i ./src/style.css -o ./dist/style.css --watch
```

**Contoh komponen dengan Tailwind:**
```html
<article class="bg-white rounded-xl shadow-md overflow-hidden hover:shadow-lg transition-shadow">
  <img class="w-full aspect-video object-cover" src="..." alt="">
  <div class="p-6">
    <h3 class="text-xl font-bold text-gray-900 mb-2">Judul Proyek</h3>
    <p class="text-gray-600 leading-relaxed">Deskripsi proyek...</p>
    <a href="#" class="inline-block mt-4 px-6 py-2 bg-primary-600 text-white rounded-lg hover:bg-primary-700 transition-colors">
      Lihat Detail
    </a>
  </div>
</article>
```

## Analogi

Custom CSS seperti **tukang kayu yang membuat furnitur dari nol** — setiap lemari dibuat dengan ukuran, cat, dan desain khusus.

Tailwind utility-first seperti **IKEA** — semua furnitur dibuat dari komponen standar (papan 60cm, sekrup M6, engsel universal). Kamu tinggal pilih dan rakit. Hasilnya mungkin terlihat mirip, tapi cepat dibuat, konsisten, dan mudah dirakit ulang.

## Dipakai Untuk Apa

- Rapid prototyping
- Project dengan tim besar (konsistensi)
- Project yang tidak terlalu membutuhkan desain unik
- Landing page, dashboard, admin panel

## Kesalahan Umum

- **HTML terlalu panjang**: class utility membuat HTML panjang — trade-off yang harus diterima
- **Mencampur Tailwind dengan CSS kustom berlebihan**: jika butuh gaya unik, buat komponen dengan `@apply` atau CSS biasa
- **Tidak konfigurasi theme**: warna default Tailwind mungkin tidak cocok — extend theme
- **Bingung nama class**: perlu belajar class name Tailwind (beda dengan CSS biasa)

## Hubungan dengan Materi Sebelumnya

Level 1-6: kita belajar CSS dari dasar hingga arsitektur. **Tailwind** adalah alternatif approach — utility-first, bukan semantic CSS. Memahami keduanya (CSS kustom dan Tailwind) membuat developer lebih versatile.

## Soal Latihan

### Soal 1
Tulis tombol primary dengan Tailwind (background biru, teks putih, rounded, padding).

**Jawaban:**
```html
<button class="bg-blue-600 text-white rounded-lg px-6 py-2 hover:bg-blue-700">
  Klik
</button>
```

### Soal 2
Apa filosofi utility-first?

**Jawaban:**
Menggunakan class utility kecil yang melakukan satu hal (`.bg-blue-600`, `.text-white`, `.rounded-lg`) dan dikomposisikan di HTML, bukan menulis CSS kustom.

### Soal 3
Apa kelebihan dan kekurangan Tailwind vs CSS kustom?

**Jawaban:**
Kelebihan: cepat, konsisten, file CSS kecil (JIT). Kekurangan: HTML panjang, perlu belajar class name, kustomisasi terbatas oleh konfigurasi.
