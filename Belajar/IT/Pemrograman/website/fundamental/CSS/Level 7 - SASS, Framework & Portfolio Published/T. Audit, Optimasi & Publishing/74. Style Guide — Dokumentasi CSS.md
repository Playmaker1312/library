# 74. Style Guide — Dokumentasi CSS

## Penjelasan

Style guide adalah halaman yang menampilkan **semua komponen visual** website — warna, tipografi, tombol, card, form. Fungsinya sebagai referensi dan dokumentasi.

```html
<h1>Style Guide — Portfolio</h1>

<section>
  <h2>Colors</h2>
  <div class="color-swatch" style="background: #2563eb">Primary</div>
  <div class="color-swatch" style="background: #f9fafb">Surface</div>
</section>
```

## Fungsi

- Dokumentasi — satu halaman untuk lihat semua komponen
- Konsistensi — developer/designer lihat style guide sebelum buat komponen baru
- Referensi cepat — "Warna primary apa?" → buka styleguide

## Analogi

Seperti **katalog furnitur IKEA** — semua produk difoto, diberi nama, dan dikelompokkan. Mau lihat kursi? Buka halaman kursi. Mau lihat semua varian lemari? Ada di halaman lemari.

Style guide adalah katalog website kita. Developer (termasuk kita sendiri 3 bulan kemudian) bisa buka styleguide.html untuk lihat "Tombol primary seperti apa?" tanpa harus cari di CSS.

## Dipakai Untuk Apa

- Dokumentasi project
- Referensi tim
- Portofolio — tunjukkan bahwa kamu punya sistem desain

## Kesalahan Umum

- **Style guide tidak update**: komponen CSS sudah berubah, style guide masih lama — tidak berguna
- **Hanya warna dan font saja**: lupa form, alert, loading state — dokumentasi semua komponen
- **Tidak pakai CSS variables**: style guide harus pakai variable yang sama, agar saat variable berubah, style guide otomatis update
- **Style guide tidak accessible**: pastikan halaman style guide sendiri juga accessible

## Hubungan dengan Materi Sebelumnya

Poin 58: design token. **Style guide** adalah manifestasi visual dari token tersebut. Ini adalah dokumentasi hidup — saat token berubah, style guide otomatis berubah (karena pakai variable yang sama).

## Soal Latihan

### Soa1 1
Apa itu style guide CSS?

**Jawaban:**
Halaman HTML yang mendokumentasikan semua komponen visual website — warna, tipografi, tombol, card, form. Berfungsi sebagai referensi dan dokumentasi.

### Soal 2
Apa manfaat style guide untuk tim?

**Jawaban:**
Konsistensi — semua developer lihat komponen yang sama. Efisien — tidak perlu tanya "warna primary apa?" atau "padding card berapa?".

### Soal 3
Mengapa style guide perlu menggunakan CSS variables?

**Jawaban:**
Agar style guide otomatis update saat variable berubah (misal dark mode, rebranding). Tanpa variable, style guide adalah dokumentasi statis yang cepat usang.
