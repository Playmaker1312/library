# 66. Setup SASS & Nesting

## Penjelasan

SASS (Syntactically Awesome Style Sheets) adalah **preprocessor** CSS — kode ditulis di `.scss`, di-compile menjadi `.css`.

**Nesting**: menulis CSS bersarang yang mencerminkan struktur HTML, bukan selector flat.

```scss
// SCSS — nesting
.card {
  border: 1px solid var(--color-border);
  
  &__image {
    width: 100%;
    aspect-ratio: 16 / 9;
  }
  
  &__title {
    font-size: var(--text-xl);
  }
  
  &--featured {
    border-color: var(--color-primary);
  }
}

// Compile ke CSS:
// .card { border: 1px solid var(--color-border); }
// .card__image { width: 100%; aspect-ratio: 16/9; }
// .card__title { font-size: var(--text-xl); }
// .card--featured { border-color: var(--color-primary); }
```

## Fungsi

- Nesting — CSS yang lebih bersih dan terstruktur
- Variables, mixin, function — kode reusable
- Partials & @use — modularisasi

## Cara Pengimplementasian

**Setup:**
```bash
npm install -D sass
```

**Compile:**
```bash
# Satu kali
npx sass scss/main.scss css/styles.css

# Watch mode
npx sass --watch scss:css
```

**package.json script:**
```json
{
  "scripts": {
    "sass": "sass --watch scss:css",
    "build": "sass --style=compressed scss:css"
  }
}
```

**Nesting — praktik terbaik:**
```scss
// ✅ Baik: nesting 2-3 level
.nav {
  display: flex;
  
  &__list {
    display: flex;
    gap: var(--space-6);
  }
  
  &__link {
    color: var(--color-primary);
    
    &:hover {
      text-decoration: underline;
    }
  }
}

// ❌ Buruk: nesting terlalu dalam
.card {
  .wrapper {
    .content {
      .title { ... } // 4 level nesting
    }
  }
}
```

## Analogi

Seperti **lemari dengan rak dan laci**:
- CSS biasa = semua barang di satu laci tanpa sekat — campur aduk
- SASS nesting = lemari dengan rak untuk piring, laci untuk sendok, gantungan untuk gelas — setiap level organisasi merepresentasikan struktur

`&` di SASS seperti **kata "ini"** — `&__title` = "card ini punya title" → `.card__title`. `&:hover` = "card ini saat di-hover" → `.card:hover`.

## Dipakai Untuk Apa

- Project CSS yang sudah besar
- Tim developer
- Component-based styling (React, Vue, Angular)

## Kesalahan Umum

- **Nesting terlalu dalam (>3 level)**: specificity jadi tinggi, CSS jadi besar
- **Lupa `&` untuk BEM**: tulis `__title` tanpa `&` jadi `.card __title` (space = descendant)
- **Nesting untuk selector yang tidak perlu**: `html { body { main { ... } } }` — tidak perlu, buat specificity tinggi
- **Lupa compile**: edit .scss tapi lupa compile — perubahan tidak muncul

## Hubungan dengan Materi Sebelumnya

Poin 63-64: BEM dan organisasi file. **SASS** adalah tools yang membuat BEM lebih mudah dengan nesting (`&__element`, `&--modifier`). Ini adalah langkah dari CSS manual ke workflow profesional.

## Soal Latihan

### Soal 1
Tulis SCSS untuk komponen button BEM dengan nesting.

**Jawaban:**
```scss
.btn {
  padding: 12px 24px;
  
  &__icon { margin-right: 8px; }
  
  &--primary { background-color: blue; }
  &--secondary { background-color: gray; }
}
```

### Soal 2
Apa fungsi tanda `&` di SASS?

**Jawaban:**
`&` merujuk ke parent selector. `&__title` di dalam `.card` = `.card__title`. `&:hover` = `.card:hover`.

### Soal 3
Apa perintah untuk compile SASS ke CSS secara otomatis?

**Jawaban:**
`sass --watch input.scss:output.css` atau `sass --watch scss:css` untuk folder.
