# 63. Metodologi BEM — Penamaan Class yang Konsisten

## Penjelasan

BEM = **B**lock **E**lement **M**odifier — metodologi penamaan class CSS yang konsisten.

```
Block:       .block                     (komponen mandiri)
Element:     .block__element            (bagian dari block)
Modifier:    .block--modifier           (variasi block)
             .block__element--modifier  (variasi element)
```

```css
.project-card { }                    /* Block */
.project-card__image { }             /* Element */
.project-card__title { }             /* Element */
.project-card--featured { }          /* Modifier */
.project-card__title--large { }      /* Element + modifier */
```

## Fungsi

- Konsistensi penamaan — semua developer paham struktur
- Specificity rendah (semua class = 0,0,1,0) — mudah di-override
- Tidak ada selector bersarang yang panjang

## Cara Pengimplementasian

```css
/* BEM — Block */
.project-card {
  border: 1px solid var(--color-border);
  border-radius: var(--radius-lg);
  overflow: hidden;
}

/* BEM — Element (bagian dari block) */
.project-card__image {
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
}

.project-card__body {
  padding: var(--space-6);
}

.project-card__title {
  font-size: var(--text-xl);
  font-weight: var(--font-weight-bold);
  margin-bottom: var(--space-2);
}

.project-card__description {
  color: var(--color-text-muted);
  line-height: var(--leading-relaxed);
}

/* BEM — Modifier */
.project-card--featured {
  border-color: var(--color-primary);
  border-width: 2px;
}

.project-card--dark {
  background-color: var(--color-surface);
  color: white;
}

.project-card__title--large {
  font-size: var(--text-2xl);
}
```

```html
<article class="project-card project-card--featured">
  <img class="project-card__image" src="..." alt="...">
  <div class="project-card__body">
    <h3 class="project-card__title project-card__title--large">Judul</h3>
    <p class="project-card__description">Deskripsi</p>
  </div>
</article>
```

## Analogi

BEM seperti **penamaan benda di rumah dengan sistem**:
- **Block** = "Lemari" — benda utama
- **Element** = "Lemari__Pintu", "Lemari__Gagang", "Lemari__Rak" — bagian dari lemari
- **Modifier** = "Lemari--Besar", "Lemari--KayuJati" — variasi lemari

Dengan sistem ini, semua orang di rumah tahu: "Lemari__Pintu--Kaca" adalah pintu lemari dengan variasi kaca. Jelas, tidak ambigu.

Tanpa BEM: `.pintu` — pintu yang mana? Pintu lemari, pintu kamar, pintu rumah?

## Dipakai Untuk Apa

- Semua komponen CSS yang reusable
- Project tim — bahasa bersama
- Project besar — maintainability

## Kesalahan Umum

- **BEM tidak konsisten**: kadang pakai `__`, kadang pakai `--` terbalik — tetapkan aturan
- **Element di dalam element**: `.card__body__title` — terlalu dalam. `card__title` sudah cukup karena title adalah bagian dari card, bukan bagian dari body
- **Modifier tanpa block/element**: `--featured` tanpa `.card--featured` — tidak jelas
- **Terlalu detail**: `.header__nav__list__item__link` — simplify: `.nav__link` cukup

## Hubungan dengan Materi Sebelumnya

Semua level sebelumnya: kita menulis CSS tanpa sistem penamaan — class bisa `card-title`, `cardTitle`, `CardTitle`. **BEM** menstandarisasi. Ini penting untuk SASS nesting (Poin 66) dan arsitektur yang scalable.

## Soal Latihan

### Soa1 1
Tulis BEM untuk komponen button: block `.btn`, element `.btn__icon`, modifier `.btn--primary`.

**Jawaban:**
```css
.btn { }
.btn__icon { }
.btn--primary { }
```

### Soal 2
Apa yang dimaksud dengan Block, Element, Modifier di BEM?

**Jawaban:**
Block = komponen mandiri. Element = bagian dari block (__). Modifier = variasi block/element (--).

### Soal 3
Mengapa BEM menggunakan `__` dan `--` dan bukan hanya "-" atau "_"?

**Jawaban:**
Untuk membedakan secara visual: `__` = element (bagian dari), `--` = modifier (variasi dari). Class utility seperti `.flex`, `.hidden` tetap pakai satu kata — tidak bingung dengan BEM.
