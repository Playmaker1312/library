# 57. transform-origin & Efek 3D Dasar

## Penjelasan

- **`transform-origin`**: titik pusat transformasi (default: center)
- **Perspektif 3D**: memberi efek kedalaman dengan `perspective` dan `rotateX/Y/Z`

```css
/* Transform origin */
.element {
  transform-origin: center center;   /* default */
  transform-origin: top left;        /* transformasi dari pojok kiri atas */
  transform-origin: 20px 50px;       /* koordinat spesifik */
}

/* Perspektif 3D */
.parent {
  perspective: 1000px;
}

.child {
  transform: rotateY(180deg);
  transform-style: preserve-3d;
  backface-visibility: hidden;
}
```

## Fungsi

- Kontrol pusat transformasi — scale dari kiri vs dari tengah
- Efek 3D — flip card, cube, card deck

## Cara Pengimplementasian

```css
/* Scale dari pojok — menu underline effect */
.menu-item::after {
  content: "";
  position: absolute;
  bottom: 0;
  left: 0;
  width: 100%;
  height: 2px;
  background-color: var(--color-primary);
  transform: scaleX(0);
  transform-origin: left center;
  transition: transform 0.3s ease;
}

.menu-item:hover::after {
  transform: scaleX(1);
}

/* Scale dari kanan untuk efek berbeda */
.menu-item-right::after {
  transform-origin: right center;
}

/* Flip card 3D */
.flip-card {
  perspective: 1000px;
  width: 300px;
  height: 400px;
}

.flip-card-inner {
  position: relative;
  width: 100%;
  height: 100%;
  transition: transform 0.6s ease;
  transform-style: preserve-3d;
}

.flip-card:hover .flip-card-inner {
  transform: rotateY(180deg);
}

.flip-card-front, .flip-card-back {
  position: absolute;
  inset: 0;
  backface-visibility: hidden;
  border-radius: var(--radius-lg);
}

.flip-card-front {
  background-color: var(--color-surface);
}

.flip-card-back {
  background-color: var(--color-primary);
  color: white;
  transform: rotateY(180deg);
  display: flex;
  align-items: center;
  justify-content: center;
}

/* Efek tilt 3D sederhana */
.card-3d {
  transition: transform 0.1s ease;
}

.card-3d:hover {
  transform: perspective(1000px) rotateX(5deg) rotateY(5deg);
}
```

## Analogi

- **transform-origin** = **engsel pintu**. Pintu biasa berengsel di sisi kiri (transform-origin: left). Pintu bisa juga berengsel di kanan, atas, atau bahkan di tengah (pintu putar).
  - Engsel kiri = buka dari kiri
  - Engsel kanan = buka dari kanan
  - Engsel tengah = pintu putar

- **Perspektif 3D** = **melihat rumah dari jarak tertentu**. `perspective: 1000px` = kamu melihat dari 1 meter. Makin kecil nilai perspektif, makin dekat — efek 3D makin dramatis.

## Dipakai Untuk Apa

- Menu hover underline (scaleX dari kiri/kanan)
- Flip card (rotasi 3D)
- Card tilt effect
- Modal/profil card dengan efek 3D

## Kesalahan Umum

- **Lupa perspective di parent**: efek 3D tidak bekerja tanpa perspective — hanya terlihat 2D
- **Lupa backface-visibility: hidden**: sisi belakang card terlihat transparan — perlu disembunyikan
- **transform-style: preserve-3d tidak di-set**: children tidak mempertahankan transformasi 3D
- **Flip card di mobile**: hover tidak ada di layar sentuh — butuh click/tap handler

## Hubungan dengan Materi Sebelumnya

Poin 56: transform 2D (translate, scale, rotate). **transform-origin** mengontrol pusat transformasi. **Perspektif 3D** membawa transformasi ke dimensi baru — flip card, tilt, depth. Efek ini membuat portofolio lebih interaktif dan memorable.

## Soal Latihan

### Soal 1
Tulis CSS untuk underline hover yang muncul dari kiri ke kanan.

**Jawaban:**
```css
.link::after {
  content: ""; display: block;
  width: 100%; height: 2px;
  background: blue;
  transform: scaleX(0);
  transform-origin: left center;
  transition: transform 0.3s ease;
}
.link:hover::after { transform: scaleX(1); }
```

### Soal 2
Apa fungsi `backface-visibility: hidden` di flip card?

**Jawaban:**
Menyembunyikan sisi belakang elemen — saat card diputar 180 derajat, sisi depan tidak terlihat terbalik.

### Soal 3
Apa efek dari nilai `perspective` yang kecil (misal 200px)?

**Jawaban:**
Perspektif kecil = kamera lebih dekat ke objek — efek 3D lebih dramatis dan ekstrem. Perspektif besar (2000px) = kamera lebih jauh — efek 3D lebih halus.
