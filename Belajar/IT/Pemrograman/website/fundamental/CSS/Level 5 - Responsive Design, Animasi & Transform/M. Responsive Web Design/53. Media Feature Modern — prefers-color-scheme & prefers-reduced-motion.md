# 53. Media Feature Modern — prefers-color-scheme & prefers-reduced-motion

## Penjelasan

Media queries tidak hanya untuk **ukuran layar** — tapi juga **preferensi pengguna**:

| Media Feature | Fungsi |
|---------------|--------|
| `prefers-color-scheme` | Deteksi dark/light mode OS |
| `prefers-reduced-motion` | Deteksi preferensi mengurangi animasi |
| `prefers-contrast` | Deteksi preferensi kontras tinggi |
| `prefers-reduced-transparency` | Deteksi preferensi transparansi rendah |

```css
@media (prefers-color-scheme: dark) {
  :root { /* variable untuk dark mode */ }
}

@media (prefers-reduced-motion: reduce) {
  * { animation-duration: 0.01ms !important; }
}
```

## Fungsi

- Menghormati preferensi OS user — dark mode, reduced motion
- Aksesibilitas — user dengan gangguan vestibular bisa matikan animasi
- UX yang lebih personal

## Cara Pengimplementasian

```css
/* Dark mode — otomatis dari OS */
:root {
  --color-bg: #ffffff;
  --color-text: #111827;
  --color-surface: #f9fafb;
  --color-border: #e5e7eb;
}

@media (prefers-color-scheme: dark) {
  :root {
    --color-bg: #0f172a;
    --color-text: #f8fafc;
    --color-surface: #1e293b;
    --color-border: #334155;
  }
  
  img { opacity: 0.8; transition: opacity 0.3s; }
  img:hover { opacity: 1; }
}

/* Dark mode dengan toggle manual + OS preference */
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { /* variable dark */ }
}
[data-theme="dark"] { /* variable dark */ }

/* Reduced motion — hormati preferensi user */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

/* High contrast */
@media (prefers-contrast: high) {
  :root {
    --color-text: #000000;
    --color-border: #000000;
  }
}
```

## Analogi

- **prefers-color-scheme** = seperti **sensor cahaya di rumah** — saat di luar gelap, lampu otomatis meredup (dark mode). Kamu tidak perlu nyalakan sendiri.
- **prefers-reduced-motion** = seperti **keluarga yang minta lampu kedip-kedip dimatikan** — karena membuat pusing. Lampu tetap nyala, tapi tidak berkedip.
- **prefers-contrast** = seperti **kakek yang minta tulisan diperbesar dan kontras ditingkatkan** — biar terbaca.

Ini semua tentang **menghormati preferensi** — rumah yang ramah untuk semua penghuni.

## Dipakai Untuk Apa

- Dark mode website
- Mengurangi animasi untuk aksesibilitas
- Mode kontras tinggi

## Kesalahan Umum

- **Hanya pakai toggle, abaikan prefers-color-scheme**: harus pakai keduanya — otomatis dari OS + toggle manual
- **Lupa reduced motion**: animasi 2 detik bisa menyebabkan mual pada user dengan gangguan vestibular
- **Dark mode hanya ubah color, lupa ubah shadow dan image**: shadow hitam di dark mode tidak terlihat, image terlalu terang

## Hubungan dengan Materi Sebelumnya

Poin 50-52: media query untuk ukuran layar. Tapi web modern juga perlu responsif terhadap **preferensi user** — dark mode, reduced motion. Media feature `prefers-*` menjawab ini. Dark mode nanti akan diperdalam di Poin 59 dengan CSS Variables.

## Soal Latihan

### Soal 1
Tulis media query untuk dark mode yang mengubah background dan text color.

**Jawaban:**
```css
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg: #0f172a;
    --color-text: #f8fafc;
  }
}
```

### Soal 2
Mengapa prefers-reduced-motion penting untuk aksesibilitas?

**Jawaban:**
Animasi dan gerakan di layar bisa menyebabkan mual, vertigo, atau sakit kepala pada pengguna dengan gangguan vestibular (keseimbangan). Reduced motion menghormati kebutuhan mereka.

### Soal 3
Bagaimana menggabungkan prefers-color-scheme dengan toggle manual?

**Jawaban:**
Gunakan CSS Variables yang diubah oleh keduanya: (1) `:root` untuk default. (2) `@media (prefers-color-scheme: dark) { :root:not([data-theme='light']) }` untuk auto. (3) `[data-theme='dark']` untuk toggle manual override.
