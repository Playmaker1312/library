# 51. Responsive Navigation — Menu Hamburger Murni CSS

## Penjelasan

Menu navigasi **collapse** di mobile menjadi ikon hamburger, dan **expand** saat diklik — semuanya dengan CSS murni (tanpa JavaScript) menggunakan **checkbox trick**.

```css
/* Sembunyikan checkbox secara visual */
.nav-toggle { display: none; }

/* Hamburgar icon */
.hamburger { display: none; /* tampilkan hanya di mobile */ }

/* Menu links: horizontal di desktop, vertikal di mobile */
```

## Fungsi

- Navigasi responsif tanpa JavaScript
- Ikon hamburger di mobile, menu horizontal di desktop

## Cara Pengimplementasian

```css
/* HTML:
<nav class="nav">
  <input type="checkbox" class="nav-toggle" id="nav-toggle">
  <label class="hamburger" for="nav-toggle">
    <span></span><span></span><span></span>
  </label>
  <ul class="nav-links">
    <li><a href="#">Beranda</a></li>
    <li><a href="#">Proyek</a></li>
  </ul>
</nav>
*/

/* Desktop — default */
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

.nav-links {
  display: flex;
  gap: var(--space-6);
  list-style: none;
}

/* Mobile */
@media (max-width: 767px) {
  .hamburger {
    display: flex;
    flex-direction: column;
    gap: 5px;
    cursor: pointer;
    z-index: 10;
  }
  
  .hamburger span {
    display: block;
    width: 24px;
    height: 2px;
    background-color: var(--color-text);
    transition: transform 0.3s ease, opacity 0.3s ease;
  }
  
  .nav-links {
    display: none;           /* sembunyi di mobile */
    flex-direction: column;
    position: absolute;
    top: 100%;
    left: 0;
    right: 0;
    background-color: white;
    padding: var(--space-4);
    box-shadow: 0 4px 6px rgba(0,0,0,0.1);
  }
  
  /* Tampilkan menu saat checkbox dicentang */
  .nav-toggle:checked ~ .nav-links {
    display: flex;
  }
  
  /* Animasi hamburger ke X */
  .nav-toggle:checked ~ .hamburger span:nth-child(1) {
    transform: rotate(45deg) translate(5px, 5px);
  }
  .nav-toggle:checked ~ .hamburger span:nth-child(2) {
    opacity: 0;
  }
  .nav-toggle:checked ~ .hamburger span:nth-child(3) {
    transform: rotate(-45deg) translate(5px, -5px);
  }
}
```

## Analogi

Seperti **pintu lipat di rumah minimalis**:
- Di rumah besar (desktop): pintu terbuka penuh — menu terlihat horizontal
- Di rumah kecil (mobile): pintu dilipat — hanya terlihat gagangnya (hamburger icon)
- Saat gagang ditarik (checkbox dicentang): pintu terbuka — menu muncul

Semua mekanis (buka/tutup) ada di engsel dan gagang — tidak perlu motor listrik (JavaScript).

## Dipakai Untuk Apa

- Navigasi utama website
- Sidebar mobile toggle

## Kesalahan Umum

- **Checkbox tidak hidden sempurna**: gunakan `position: absolute; opacity: 0` atau `display: none`
- **Label for tidak cocok dengan checkbox id**: klik hamburger tidak bereaksi
- **Menu di atas konten lain**: pastikan menu absolut punya background dan z-index

## Hubungan dengan Materi Sebelumnya

Poin 50: mobile-first dengan media query. Tapi navigasi perlu **toggle** — show/hide menu di mobile. Dengan checkbox trick CSS murni, kita bisa buat hamburger menu tanpa JavaScript. Ini memperkuat prinsip: sebisa mungkin, gunakan CSS dulu sebelum JavaScript.

## Soal Latihan

### Soal 1
Apa elemen HTML yang digunakan sebagai toggle untuk hamburger menu CSS murni?

**Jawaban:**
`<input type="checkbox">` — disembunyikan secara visual, di-toggle via `<label>`.

### Soal 2
Apa CSS untuk menampilkan menu saat checkbox dicentang?

**Jawaban:**
```css
.nav-toggle:checked ~ .nav-links { display: flex; }
```
Selector `~` (general sibling) memilih `.nav-links` yang merupakan saudara setelah checkbox.

### Soal 3
Apa kelemahan hamburger menu CSS murni?

**Jawaban:**
Tidak bisa menutup menu dengan klik di luar area menu (perlu JavaScript). Juga tidak bisa animasi masuk/keluar yang kompleks.
