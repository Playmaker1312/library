# 50. Mobile-First & Media Queries

## Penjelasan

**Mobile-first**: tulis CSS untuk mobile dulu (default), lalu gunakan media query untuk layar lebih besar.

**Media query**: aturan CSS yang hanya aktif berdasarkan kondisi tertentu — biasanya lebar viewport.

```css
/* MOBILE-FIRST: default untuk mobile */
.projects-grid {
  display: grid;
  grid-template-columns: 1fr;  /* 1 kolom di mobile */
  gap: var(--space-4);
}

/* TABLET: 768px ke atas */
@media (min-width: 768px) {
  .projects-grid {
    grid-template-columns: repeat(2, 1fr);  /* 2 kolom */
    gap: var(--space-6);
  }
}

/* DESKTOP: 1024px ke atas */
@media (min-width: 1024px) {
  .projects-grid {
    grid-template-columns: repeat(3, 1fr);  /* 3 kolom */
  }
}
```

Breakpoints referensi:
```
sm:  640px   — smartphone landscape
md:  768px   — tablet portrait
lg:  1024px  — tablet landscape / laptop
xl:  1280px  — desktop
2xl: 1536px  — large desktop
```

## Fungsi

- Website bisa diakses di semua ukuran layar
- Mobile-first memaksa prioritas: konten penting dulu, layout besar kemudian

## Cara Pengimplementasian

```css
/* MOBILE-FIRST PATTERN */

/* Mobile: default (tanpa media query) */
body { font-size: var(--text-base); }
.sidebar { display: none; }  /* sembunyi di mobile */
.nav-links { display: none; } /* menu hamburger di mobile */

/* Tablet */
@media (min-width: 768px) {
  body { font-size: var(--text-lg); }
  .sidebar { display: block; }
  .nav-links { display: flex; }
}

/* Desktop */
@media (min-width: 1024px) {
  .container { padding-inline: var(--space-8); }
  .hero { padding-block: var(--space-20); }
}

/* Operator logika di media query */
@media (min-width: 768px) and (max-width: 1023px) {
  /* Hanya tablet */
}

@media (min-width: 1024px), (max-width: 480px) {
  /* Desktop ATAU mobile kecil */
}

@media not print {
  /* Semua media kecuali print */
}
```

## Analogi

Mobile-first seperti **membangun rumah dari dalam ke luar**:
1. **Mobile** = ruang inti (kamar mandi, dapur, ruang keluarga) — fungsional untuk 1-2 orang
2. **Tablet** = tambah ruang makan — lebih lega
3. **Desktop** = tambah ruang tamu, taman — properti lengkap

Kebalikannya (desktop-first): bangun rumah besar dulu, lalu bongkar untuk ukuran kecil — tidak efisien.

## Dipakai Untuk Apa

- Semua website modern
- Responsive grid, navigation, typography, layout

## Kesalahan Umum

- **Desktop-first (max-width)**: lebih banyak CSS override, prioritas salah
- **Breakpoint terlalu banyak**: 3-4 sudah cukup untuk sebagian besar website
- **Breakpoint berdasarkan device, bukan konten**: pilih breakpoint berdasarkan konten mulai terlihat jelek, bukan berdasarkan iPhone/Android
- **Media query tidak terorganisir**: taruh media query di dekat aturan yang di-override

## Hubungan dengan Materi Sebelumnya

Level 4: layout desktop sudah bagus dengan Grid dan Flexbox. Tapi bagaimana dengan **layar kecil**? **Mobile-first dan media queries** memastikan website tetap nyaman di HP, tablet, dan monitor besar.

## Soal Latihan

### Soal 1
Tulis mobile-first grid: 1 kolom di mobile, 2 kolom di tablet (768px), 3 kolom di desktop (1024px).

**Jawaban:**
```css
.grid { display: grid; grid-template-columns: 1fr; gap: 16px; }
@media (min-width: 768px) { .grid { grid-template-columns: repeat(2, 1fr); gap: 24px; } }
@media (min-width: 1024px) { .grid { grid-template-columns: repeat(3, 1fr); } }
```

### Soal 2
Apa keuntungan mobile-first dibanding desktop-first?

**Jawaban:**
Prioritas konten penting dulu, CSS lebih sedikit (tidak perlu override banyak properti), performa lebih baik di mobile, dan selaras dengan tren mayoritas traffic web.

### Soal 3
Apa dasar pemilihan breakpoint yang baik?

**Jawaban:** Berdasarkan **konten** — pada lebar berapa grid mulai terlihat terlalu sempit atau teks terlalu panjang. Bukan berdasarkan perangkat tertentu.
