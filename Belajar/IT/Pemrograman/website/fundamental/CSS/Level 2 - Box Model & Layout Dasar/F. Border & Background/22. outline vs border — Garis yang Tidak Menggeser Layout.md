# 22. outline vs border — Garis yang Tidak Menggeser Layout

## Penjelasan

- **`outline`**: garis di luar border — **tidak memengaruhi layout** (tidak menambah ukuran)
- **`border`**: garis tepi yang jadi bagian box model — **memengaruhi layout** (menambah ukuran)

```css
/* Border — menggeser layout */
.element {
  border: 3px solid black;  /* +6px ke total ukuran (tanpa border-box) */
  outline: none;             /* ❌ JANGAN: hilangkan fokus keyboard */
}

/* Outline — tidak menggeser layout */
.element:focus-visible {
  outline: 2px solid var(--color-primary);
  outline-offset: 2px;  /* jarak outline dari elemen */
}
```

## Fungsi

- **outline**: indikator fokus keyboard (aksesibilitas) — tidak mengubah layout
- **border**: garis tepi permanen yang jadi bagian desain

## Cara Pengimplementasian

```css
/* ❌ JANGAN LAKUKAN INI — aksesibilitas buruk */
*:focus { outline: none; }

/* ✅ LAKUKAN INI — custom outline yang tetap terlihat */
:focus-visible {
  outline: 2px solid var(--color-primary);
  outline-offset: 2px;
}

/* Perbedaan outline vs border secara visual */
.border-example {
  border: 3px solid red;           /* ↑ Menggeser konten di sekitarnya */
}

.outline-example {
  outline: 3px solid red;          /* ↑ Tidak menggeser apapun */
  outline-offset: -3px;            /* outline di dalam elemen */
}
```

**Kapan pakai outline:**
- Focus indicator untuk keyboard user
- Debugging layout (outline tidak mengubah ukuran)
- Efek hover yang tidak menggeser elemen lain

## Analogi

Border seperti **bingkai foto** — bingkai menambah ukuran total foto, jadi harus dipertimbangkan saat menempatkan di dinding.

Outline seperti **senter yang menyorot foto di dinding** — sorotan berada di luar bingkai, tidak mengubah posisi foto, dan bisa diatur jaraknya (outline-offset). Sorotan (outline) biasanya hanya muncul saat diperlukan — seperti saat fokus keyboard.

## Dipakai Untuk Apa

- **outline**: focus indicator aksesibilitas, debugging layout
- **border**: permanen — membatasi elemen, dekorasi

## Kesalahan Umum

- **`outline: none` tanpa pengganti**: user keyboard tidak bisa melihat elemen mana yang aktif — masalah aksesibilitas serius
- **Outline tidak dianggap penting**: padahal penting untuk navigasi keyboard
- **Mengira outline dan border sama**: keduanya mirip secara visual, tapi outline tidak memengaruhi ukuran elemen

## Hubungan dengan Materi Sebelumnya

Poin 21: border adalah garis tepi yang jadi **bagian box model**. Sekarang kita kenali **outline** — "saudara" border yang tidak menggeser layout. Paling penting: **jangan hapus outline** — ini untuk aksesibilitas keyboard. Ganti dengan yang lebih baik, bukan dihilangkan.

## Soal Latihan

### Soal 1
Apa perbedaan utama outline dan border?

**Jawaban:**
Border merupakan bagian dari box model — memengaruhi ukuran dan layout. Outline berada di luar box model — tidak memengaruhi ukuran atau posisi elemen.

### Soal 2
Mengapa `*:focus { outline: none; }` berbahaya?

**Jawaban:**
Ini menghilangkan indikator fokus untuk semua elemen. User yang navigasi dengan keyboard (Tab) tidak tahu elemen mana yang sedang aktif — website menjadi tidak dapat diakses.

### Soal 3
Tulis CSS untuk custom focus indicator dengan warna biru dan offset 2px.

**Jawaban:**
```css
:focus-visible {
  outline: 2px solid #2563eb;
  outline-offset: 2px;
}
```
