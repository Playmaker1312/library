# 24. Display: block, inline & inline-block

## Penjelasan

Tiga nilai `display` paling dasar:

| Nilai | Perilaku | Contoh Elemen |
|-------|----------|---------------|
| **block** | Ambil seluruh lebar, mulai baris baru | `<div>`, `<p>`, `<h1>`, `<section>` |
| **inline** | Ikuti aliran teks, tidak bisa set width/height | `<span>`, `<a>`, `<em>`, `<strong>` |
| **inline-block** | Ikuti aliran teks, tapi bisa set width/height | Kombinasi keduanya |

```css
/* Default block */
p, div, h1, section, ul, li {
  display: block; /* default — otomatis, tidak perlu ditulis */
}

/* Default inline */
span, a, em, strong {
  display: inline; /* default — tidak perlu ditulis */
}

/* inline-block — untuk tombol dan komponen */
.btn {
  display: inline-block;
  width: auto;        /* bisa diset */
  padding: 12px 24px; /* padding berfungsi penuh */
  margin: 8px;         /* margin semua sisi berfungsi */
}
```

## Fungsi

- **block**: layout vertikal — section, card, container
- **inline**: teks di dalam paragraf — link, highlight, bold
- **inline-block**: tombol, badge, komponen yang inline tapi butuh dimensi

## Cara Pengimplementasian

```css
/* Block — default untuk div, p, heading */
.section {
  display: block;  /* default — biasanya tidak perlu ditulis */
  width: 100%;
}

/* Inline — default untuk span, a */
.nav-link {
  display: inline;
  /* width dan height tidak berpengaruh */
  /* margin-top/bottom tidak berpengaruh */
  padding: 0 8px;  /* padding horizontal berfungsi */
}

/* Inline-block — untuk tombol */
.btn {
  display: inline-block;
  padding: var(--space-3) var(--space-6);
  /* width dan height berfungsi */
  /* margin semua sisi berfungsi */
  background-color: var(--color-primary);
  color: white;
  border-radius: var(--radius-md);
}

/* Hidden element */
.hidden {
  display: none; /* hilang sepenuhnya dari layout */
}
```

## Analogi

**Block** seperti **rumah tapak** — setiap rumah punya lahan sendiri (lebar penuh), berjejer ke bawah. Tidak bisa ada rumah lain di kanan/kirinya.

**Inline** seperti **batu bata di dinding** — batu bata mengikuti alur baris, tidak bisa diatur lebar/tinggi sendiri. Jika ingin bata lebih besar, istilahnya "tidak bisa".

**Inline-block** seperti **lemari di tepi ruangan** — lemari mengikuti aliran ruangan (inline), tapi kamu bisa atur ukuran lebar dan tingginya. Lemari lain bisa ada di kiri/kanannya jika muat.

## Dipakai Untuk Apa

- **block**: layout utama (section, div, header, footer)
- **inline**: link dalam paragraf, teks yang di-highlight
- **inline-block**: tombol, badge, avatar inline, komponen kecil

## Kesalahan Umum

- **Set width/height di inline**: tidak berpengaruh — harus ubah ke inline-block atau block
- **Margin top/bottom di inline**: tidak berfungsi — hanya margin horizontal
- **`display: none` vs `visibility: hidden`**: display none hilangkan dari layout, visibility hidden tetap ada ruangnya
- **Tidak sadar default display**: mencoba `display: block` di div (padahal sudah block secara default)

## Hubungan dengan Materi Sebelumnya

Poin 16-23: box model, border, background sudah dipahami. Tapi **bagaimana elemen mengalir di halaman?** Jawabannya ada di `display`. Block = ambil seluruh baris. Inline = ikut aliran teks. Inline-block = keduanya. Ini adalah **jembatan** menuju Flexbox dan Grid di Level 4.

## Soal Latihan

### Soal 1
Sebutkan satu contoh elemen HTML yang defaultnya block dan satu yang defaultnya inline.

**Jawaban:**
Block: `<div>`, `<p>`, `<h1>`, `<section>` (salah satu). Inline: `<span>`, `<a>`, `<em>`, `<strong>` (salah satu).

### Soal 2
Mengapa width tidak berpengaruh di elemen inline?

**Jawaban:**
Elemen inline dirancang untuk mengalir dalam teks — lebarnya ditentukan oleh konten. Mengubah inline ke inline-block atau block memberikan kontrol width.

### Soal 3
Apa perbedaan `display: none` dan `visibility: hidden`?

**Jawaban:**
`display: none` — elemen dihapus dari layout, tidak ada ruang, tidak terlihat. `visibility: hidden` — elemen tidak terlihat tapi ruangnya tetap ada di layout (transparan).
