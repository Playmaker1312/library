# 23. background-color, background-image & Gradien

## Penjelasan

- **`background-color`**: warna latar belakang solid
- **`background-image`**: gambar atau gradien sebagai latar
- **Gradien**: transisi warna yang mulus

```css
.hero {
  background-color: var(--color-primary-dark);
  background-image: linear-gradient(135deg, var(--color-primary-dark), var(--color-primary));
}
```

## Fungsi

- Memberi latar visual pada elemen — dari warna solid hingga gambar kompleks
- Menciptakan kedalaman dan atmosfer

## Cara Pengimplementasian

```css
/* Background color — sudah dipelajari di Poin 11 */
.section {
  background-color: var(--color-surface);
}

/* Background image — properti lengkap */
.hero {
  background-image: url('images/hero-bg.jpg');
  background-size: cover;           /* gambar menutup seluruh area */
  background-position: center;      /* fokus di tengah */
  background-repeat: no-repeat;     /* tidak diulang */
}

/* Gradien linear */
.hero {
  background-image: linear-gradient(
    135deg,                          /* arah */
    var(--color-primary-dark) 0%,    /* warna awal */
    var(--color-primary) 50%,        /* warna tengah */
    var(--color-primary-light) 100%  /* warna akhir */
  );
}

/* Multiple background: overlay + gambar */
.hero {
  background-image: 
    linear-gradient(rgba(0, 0, 0, 0.5), rgba(0, 0, 0, 0.5)),
    url('images/hero-bg.jpg');
  background-size: cover;
  background-position: center;
}

/* Shorthand background */
.hero {
  background: 
    linear-gradient(rgba(0,0,0,0.5), rgba(0,0,0,0.5)),
    url('hero.jpg') center/cover no-repeat;
}
```

## Analogi

Di rumah:
- **background-color** = dinding dicat warna solid putih
- **background-image** = wallpaper dengan motif tertentu
- **Gradien** = dinding dengan efek ombre — warna biru tua di atas perlahan memudar ke biru muda di bawah
- **Multiple background** = wallpaper motif bunga dengan lapisan tipis cat putih transparan di atasnya (overlay)

## Dipakai Untuk Apa

- Hero section: gradien atau gambar latar penuh
- Card: background-color berbeda untuk variasi
- Section divider: gradien antar section
- Overlay: teks tetap terbaca di atas gambar

## Kesalahan Umum

- **Gambar tidak muncul**: path salah — gunakan path relatif ke file CSS
- **Lupa background-size: cover**: gambar diulang atau tidak proporsional
- **Gradien + teks tidak kontras**: teks tersembunyi di gradien — pastikan kontras cukup
- **Terlalu banyak gradien**: setiap section pakai gradien berbeda — website terlihat ramai

## Hubungan dengan Materi Sebelumnya

Poin 11: background-color sudah kita gunakan. Sekarang **background-image** dan **gradien** — latar yang lebih dari sekadar warna solid. Dengan gradien, hero section terlihat lebih hidup. Multiple background (overlay) memastikan teks tetap terbaca di atas gambar.

## Soal Latihan

### Soal 1
Tulis CSS untuk hero section dengan gradien biru gelap ke biru terang (135 derajat).

**Jawaban:**
```css
.hero {
  background-image: linear-gradient(135deg, #1e3a8a, #3b82f6);
}
```

### Soal 2
Apa fungsi `background-size: cover`?

**Jawaban:**
Gambar diperbesar/diperkecil untuk menutup seluruh area elemen — proporsi terjaga, tapi sebagian gambar mungkin terpotong. Alternatif: `contain` (gambar utuh, mungkin ada ruang kosong).

### Soal 3
Mengapa kita perlu overlay (gradien transparan di atas gambar) di hero section?

**Jawaban:**
Overlay gelap memastikan teks putih tetap kontras dan terbaca di atas gambar yang mungkin terang di beberapa area. Tanpa overlay, teks bisa tidak terbaca tergantung area gambar di belakangnya.
