# 18. padding — Ruang di Dalam Elemen

## Penjelasan

`padding` adalah ruang antara **konten** dan **border** — di dalam elemen. Membuat konten tidak menempel ke tepi elemen.

```css
:root {
  /* Spacing scale — konsisten untuk seluruh website */
  --space-1:  0.25rem;  /*  4px */
  --space-2:  0.5rem;   /*  8px */
  --space-3:  0.75rem;  /* 12px */
  --space-4:  1rem;     /* 16px */
  --space-5:  1.25rem;  /* 20px */
  --space-6:  1.5rem;   /* 24px */
  --space-8:  2rem;     /* 32px */
  --space-10: 2.5rem;   /* 40px */
  --space-12: 3rem;     /* 48px */
  --space-16: 4rem;     /* 64px */
  --space-20: 5rem;     /* 80px */
  --space-24: 6rem;     /* 96px */
}
```

## Fungsi

- Memberi "ruang bernapas" di dalam elemen
- Konten tidak menempel ke border/tepi elemen
- Meningkatkan keterbacaan dan estetika

## Cara Pengimplementasian

```css
/* Shorthand padding — 4 cara penulisan */

/* 1 nilai: semua sisi */
.card { padding: var(--space-6); }

/* 2 nilai: atas-bawah | kiri-kanan */
.card { padding: var(--space-4) var(--space-6); }

/* 3 nilai: atas | kiri-kanan | bawah */
.card { padding: var(--space-2) var(--space-4) var(--space-6); }

/* 4 nilai: atas | kanan | bawah | kiri (jarum jam) */
.card { padding: var(--space-2) var(--space-4) var(--space-6) var(--space-8); }

/* Padding per sisi */
.card {
  padding-top:    var(--space-4);
  padding-right:  var(--space-6);
  padding-bottom: var(--space-4);
  padding-left:   var(--space-6);
}
```

Contoh implementasi di komponen:
```css
.section {
  padding-block: var(--space-16);  /* padding atas & bawah */
  padding-inline: var(--space-6);  /* padding kiri & kanan */
}

.btn {
  padding: var(--space-3) var(--space-6);  /* vertikal 12px, horizontal 24px */
}

.card-body {
  padding: var(--space-6);
}
```

## Analogi

Padding seperti **jarak antara lukisan dengan bingkainya** (matte). Lukisan tidak boleh menempel langsung ke tepi bingkai — perlu ruang agar terlihat lebih elegan dan fokus. Semakin besar padding, semakin "mewah" rasanya. Di kartu pos, padding adalah margin putih di sekeliling tulisan.

## Dipakai Untuk Apa

- Card, button, section — semua elemen yang butuh jarak internal
- Body konten dari header, footer, sidebar
- Input field — teks tidak menempel ke tepi input

## Kesalahan Umum

- **Padding tidak konsisten**: kadang 16px, kadang 15px, kadang 1rem — gunakan spacing variables
- **Padding di semua sisi padpa di satu sisi butuh berbeda**: gunakan `padding-top`, `padding-inline`, dll.
- **Lupa padding horizontal di container**: konten menempel ke tepi layar — beri `padding-inline: var(--space-6)` di container

## Hubungan dengan Materi Sebelumnya

Poin 16-17: paham box model dan border-box. Sekarang **padding** — properti paling sering diutak-atik setelah color. Spacing system (`--space-1` sampai `--space-24`) memastikan konsistensi. Tidak ada lagi padding 17px di satu tempat dan 16px di tempat lain.

## Soal Latihan

### Soal 1
Tulis padding 16px atas-bawah dan 24px kiri-kanan menggunakan shorthand.

**Jawaban:**
```css
padding: 16px 24px;
```

### Soal 2
Apa perbedaan padding dan margin?

**Jawaban:**
Padding di **dalam** border (ruang antara konten dan border). Margin di **luar** border (jarak antar elemen). Padding memengaruhi ukuran total elemen (dengan border-box, ukuran tetap), margin mendorong elemen lain.

### Soal 3
Mengapa spacing system (--space-1 hingga --space-24) penting?

**Jawaban:**
Konsistensi visual — semua jarak menggunakan skala yang sama (4-8-12-16-24-32-48-64...), bukan angka random. Memudahkan maintenance — jika ingin spacing lebih longgar, cukup ubah variable di :root.
