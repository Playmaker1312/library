# 19. margin — Ruang di Luar Elemen & Margin Collapsing

## Penjelasan

`margin` adalah ruang di **luar border** — jarak antara elemen satu dengan yang lain.

**Margin Collapsing**: ketika dua margin vertikal bertemu (milik elemen berbeda atau parent-child), margin digabung menjadi satu — hanya yang **lebih besar** yang berlaku.

```css
/* Margin collapsing contoh */
h2 { margin-bottom: 32px; }  /* 32px */
p  { margin-top: 16px; }     /* 16px */
/* Jarak aktual h2 → p: 32px (bukan 48px!) — margin collapse */
```

## Fungsi

- Memberi jarak antar elemen
- `margin: auto` — centering elemen block horizontal
- Margin collapsing — fitur (bukan bug!) untuk mencegah jarak berlebihan

## Cara Pengimplementasian

```css
/* Shorthand sama dengan padding */
.element {
  margin: var(--space-6);                    /* semua sisi */
  margin: var(--space-4) var(--space-6);     /* vertikal | horizontal */
  margin: var(--space-2) var(--space-4) var(--space-6); /* atas | horizontal | bawah */
  margin: var(--space-2) var(--space-4) var(--space-6) var(--space-8); /* atas kanan bawah kiri */
}

/* Margin auto — centering block element */
.container {
  max-width: 1200px;
  margin-inline: auto;  /* sama dengan margin-left: auto; margin-right: auto */
}

/* Margin negatif — tarik elemen ke arah tertentu */
.overlap-element {
  margin-top: -40px;  /* elemen naik, tumpang tindih dengan elemen sebelumnya */
}

/* Logical properties — modern */
.card {
  margin-block: var(--space-6);  /* margin atas & bawah */
  margin-inline: auto;           /* margin kiri & kanan auto (center) */
}
```

**Margin collapsing — 3 skenario:**
1. **Adjacent siblings**: dua elemen bersebelahan vertikal — margin terbesar menang
2. **Parent-child**: margin anak menembus parent jika parent tidak punya border/padding
3. **Empty element**: margin atas dan bawah elemen kosong bertemu dan collapse

## Analogi

Margin seperti **jarak antar bingkai foto di dinding**:
- Dua bingkai dipasang — satu berjarak 10cm dari tepi dinding (margin-bottom), satu berjarak 5cm (margin-top). Jarak aktual? Bukan 15cm, tapi **10cm** — margin collapse, yang besar menang.
- Ini mencegah jarak berlipat ganda. Bayangkan jika setiap paragraf punya margin 16px atas dan bawah. Jarak antar paragraf akan 32px — terlalu besar. Collapsing membuatnya tetap 16px.

## Dipakai Untuk Apa

- Jarak antar section (margin-block besar)
- Jarak antar heading dan paragraf ($heading margin-bottom)
- Centering container (margin-inline: auto)
- Memberi ruang di sekitar elemen

## Kesalahan Umum

- **Margin collapsing tidak disadari**: memberi margin 20px ke bawah parent dan 30px ke atas anak — jarak 30px, bukan 50px
- **Margin auto untuk vertikal**: `margin: auto` hanya untuk horizontal — vertikal perlu flexbox/grid
- **Margin negatif berlebihan**: layout jadi tidak terduga
- **Margin di inline element**: margin vertikal (top/bottom) tidak berfungsi di inline element

## Hubungan dengan Materi Sebelumnya

Poin 18: padding untuk ruang **di dalam** elemen. Sekarang margin untuk ruang **di luar** — jarak antar elemen. Dua properti ini sering tertukar. Ingat: padding = dorong border ke luar, margin = dorong elemen lain. Margin collapsing adalah fitur penting yang harus dipahami agar spacing tidak membingungkan.

## Soal Latihan

### Soal 1
Apa itu margin collapsing?

**Jawaban:**
Ketika dua margin vertikal bertemu (antar elemen atau parent-child), margin digabung menjadi satu — hanya nilai terbesar yang berlaku. Ini mencegah jarak berlipat ganda.

### Soal 2
Tulis CSS untuk membuat elemen dengan class `.container` berada di tengah halaman secara horizontal.

**Jawaban:**
```css
.container {
  max-width: 1200px;
  margin-left: auto;
  margin-right: auto;
  /* Atau modern: margin-inline: auto */
}
```

### Soal 3
Mengapa margin vertikal tidak berfungsi di elemen inline (seperti `<span>`)?

**Jawaban:**
Elemen inline hanya mengikuti aliran teks — tinggi baris ditentukan oleh `line-height`, bukan `margin`. Margin horizontal (kiri/kanan) tetap berfungsi.
