# 14. font-weight, font-style & text-decoration

## Penjelasan

- **`font-weight`**: ketebalan teks (100-900 atau keyword)
- **`font-style`**: normal atau italic
- **`text-decoration`**: garis pada teks (underline, line-through, none)

```css
:root {
  --font-weight-normal: 400;
  --font-weight-medium: 500;
  --font-weight-semibold: 600;
  --font-weight-bold: 700;
}

h1, h2, h3 { 
  font-weight: var(--font-weight-bold); 
}

blockquote {
  font-style: italic;
}

a {
  text-decoration: none; /* hilangkan underline default */
}

a:hover {
  text-decoration: underline; /* munculkan saat hover */
}

del, .strikethrough {
  text-decoration: line-through;
}
```

## Fungsi

- **font-weight**: hierarki ketebalan — bold untuk judul, normal untuk body
- **font-style**: penekanan atau kutipan (italic)
- **text-decoration**: status link (underline), koreksi (line-through), dekorasi

## Cara Pengimplementasian

```css
:root {
  --fw-normal: 400;
  --fw-medium: 500;
  --fw-semibold: 600;
  --fw-bold: 700;
}

body { font-weight: var(--fw-normal); }
h1 { font-weight: var(--fw-bold); }
h2 { font-weight: var(--fw-semibold); }

a {
  color: var(--color-primary);
  text-decoration: none;
  font-weight: var(--fw-medium);
}

a:hover {
  text-decoration: underline;
}

.decorative-text {
  font-style: italic;
  text-decoration: underline wavy var(--color-primary);
}
```

## Analogi

Di rumah:
- **font-weight** = ketebalan spidol untuk label. Spidol tebal untuk label "LISTRIK" (bold), spidol sedang untuk "Kamar Tidur" (semibold), spidol tipis untuk daftar isi lemari (normal)
- **font-style: italic** = tulisan miring seperti di undangan resmi
- **text-decoration: underline** = stabilo yang menggaris bawahi teks penting

## Dipakai Untuk Apa

- **font-weight**: judul (bold), sub-judul (semibold), body (normal), tombol (medium)
- **font-style**: kutipan, catatan, istilah asing (italic)
- **text-decoration**: link (hilangkan underline default, munculkan saat hover), teks yang dihapus (line-through)

## Kesalahan Umum

- **Lupa import font weight**: font tetap pakai weight default meski sudah set `font-weight: 300` — pastikan weight tersebut di-import dari Google Fonts
- **Hanya pakai bold dan normal**: weight 500 dan 600 sering diabaikan, padahal berguna untuk hierarki yang lebih halus
- **Underline di semua link (termasuk gambar)**: `a img { text-decoration: none }` — underline di gambar tidak masuk akal

## Hubungan dengan Materi Sebelumnya

Poin 13: ukuran teks sudah diatur. Sekarang **ketebalan, gaya, dan dekorasi** — detail yang membuat hierarki lebih jelas. Judul tidak hanya lebih besar tapi juga lebih tebal. Link tidak hanya biru tapi juga punya interaksi hover dengan underline.

## Soal Latihan

### Soal 1
Tulis CSS untuk membuat heading 1 tebal dan heading 2 semibold.

**Jawaban:**
```css
h1 { font-weight: 700; }
h2 { font-weight: 600; }
```

### Soal 2
Apa perbedaan `text-decoration: none` dan `text-decoration: underline`?

**Jawaban:**
`none` menghilangkan garis pada teks (biasanya digunakan untuk menghilangkan underline default link). `underline` menambahkan garis di bawah teks.

### Soal 3
Mengapa kita perlu meng-import weight 400, 500, 600, 700 dari Google Fonts — tidak cukup hanya 400 dan 700?

**Jawaban:**
Jika font-weight 500 atau 600 tidak di-import, browser akan melakukan **font synthesis** (menebalkan font 400 secara buatan) — hasilnya tidak sehalus font asli. Untuk hasil optimal, import semua weight yang akan digunakan.
