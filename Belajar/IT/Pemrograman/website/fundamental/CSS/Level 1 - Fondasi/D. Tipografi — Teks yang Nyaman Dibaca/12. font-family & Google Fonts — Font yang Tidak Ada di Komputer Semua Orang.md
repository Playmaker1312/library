# 12. font-family & Google Fonts — Font yang Tidak Ada di Komputer Semua Orang

## Penjelasan

- **`font-family`**: menentukan jenis font yang digunakan
- **Font stack**: urutan font alternatif — jika font pertama tidak ada, pakai yang berikutnya
- **Google Fonts**: layanan font gratis yang di-host online

```css
/* System font stack — tanpa external request */
body {
  font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', 
               Roboto, Oxygen, Ubuntu, sans-serif;
}

/* Dengan Google Fonts — import dulu */
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap');

body {
  font-family: 'Inter', -apple-system, sans-serif;
}
```

## Fungsi

- Mengontrol tampilan teks agar sesuai dengan desain
- Font yang tepat meningkatkan kredibilitas dan kenyamanan baca
- Google Fonts menyediakan font gratis tanpa perlu hosting sendiri

## Cara Pengimplementasian

**1. Tambahkan di `<head>` HTML:**
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=Merriweather:wght@700&display=swap" rel="stylesheet">
```

**2. Gunakan di CSS:**
```css
:root {
  --font-sans: 'Inter', -apple-system, BlinkMacSystemFont, sans-serif;
  --font-serif: 'Merriweather', Georgia, 'Times New Roman', serif;
  --font-mono: 'Fira Code', 'Courier New', monospace;
}

body { 
  font-family: var(--font-sans); 
}

h1 { 
  font-family: var(--font-serif); 
}

code, pre { 
  font-family: var(--font-mono); 
}
```

## Analogi

Font stack seperti **daftar kontraktor rumah** — "Panggil Pak Ahmat dulu, kalau sibuk coba Bu Sari, kalau keduanya tidak bisa hubungi Toko Bangunan Jaya." Browser berusaha pakai font pertama, lalu turun ke alternatif jika font pertama tidak tersedia di komputer user.

## Dipakai Untuk Apa

- Body teks: font sans-serif yang bersih dan mudah dibaca (Inter, Open Sans)
- Heading: font yang lebih dekoratif atau contrasting
- Code: font monospace untuk kode programming

## Kesalahan Umum

- **Hanya satu font**: jika font tidak tersedia, browser pakai default (Times New Roman) — font stack penting
- **Lupa import Google Fonts**: font tidak tampil, fallback ke default
- **Terlalu banyak font weight**: loading lambat. Pilih hanya weight yang dipakai (400, 500, 600, 700)
- **Gunakan `display=block` atau `display=swap`**: `swap` memastikan teks tetap terbaca dengan fallback sementara font loading

## Hubungan dengan Materi Sebelumnya

Poin 10-11: warna sudah terdefinisi dan teraplikasi. Sekarang **tipografi** — yang paling berdampak pada kenyamanan baca. Font yang tepat membuat website terlihat profesional. Kita simpan konfigurasi font di CSS Variables agar konsisten.

## Soal Latihan

### Soal 1
Tulis font stack yang menggunakan Inter sebagai font utama, dengan fallback Arial, dan terakhir sans-serif generic.

**Jawaban:**
```css
font-family: 'Inter', Arial, sans-serif;
```

### Soal 2
Apa fungsi `display=swap` pada URL Google Fonts?

**Jawaban:**
`display=swap` memerintahkan browser untuk menampilkan teks dengan font fallback terlebih dahulu sementara font utama masih loading. Setelah font utama selesai diunduh, teks ditukar. Ini mencegah **FOUT** (Flash of Invisible Text) — teks tidak terlihat saat font loading.

### Soal 3
Apa yang terjadi jika kita hanya menulis `font-family: 'Inter'` tanpa fallback?

**Jawaban:**
Jika font Inter tidak tersedia (gagal loading, atau tidak di-import), browser menggunakan font serif default (Times New Roman) — sangat berbeda dengan Inter. Selalu sediakan font stack dengan fallback.
