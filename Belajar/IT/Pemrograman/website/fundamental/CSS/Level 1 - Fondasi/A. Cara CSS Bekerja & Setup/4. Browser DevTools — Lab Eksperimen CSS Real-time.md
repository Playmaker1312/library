# 4. Browser DevTools — Lab Eksperimen CSS Real-time

## Penjelasan

Chrome DevTools adalah tool bawaan browser untuk menginspeksi HTML dan CSS. Cara membuka:
- **F12** atau **Ctrl+Shift+I** (Windows)
- Klik kanan elemen → **Inspect**

Panel penting untuk CSS:
- **Elements**: lihat HTML dan CSS yang diterapkan pada elemen
- **Styles**: edit CSS real-time (tidak disimpan permanen)
- **Computed**: lihat nilai final CSS setelah semua kalkulasi
- **Box Model**: visualisasi padding, border, margin elemen

## Fungsi

- Debug CSS yang "tidak jalan" — lihat properti mana yang di-override
- Eksperimen real-time: ubah nilai, lihat perubahan instan
- Copy CSS dari elemen tertentu
- Analisis box model, lebar, tinggi elemen

## Cara Pengimplementasian

1. Buka website portofolio di Chrome
2. Klik kanan pada judul `<h1>` → Inspect
3. Di panel **Styles**, lihat semua CSS yang diterapkan
4. Klik nilai CSS (misal `color`) dan ubah langsung dengan keyboard
5. Lihat berubahan real-time di browser
6. Refresh halaman — perubahan hilang (tidak tersimpan)

Manfaatkan fitur:
```
Styles panel:
  - Centang/unisentang properti untuk lihat efeknya
  - Tambah properti baru dengan klik "element.style" 
  - Lihat properti yang dicoret (di-override)
  
Computed panel:
  - Lihat nilai final properti tertentu
  - Filter properti dengan mengetik di kotak Filter

Box Model diagram:
  - Visual: content → padding → border → margin
  - Hover angka untuk highlight di halaman
```

## Analogi

DevTools seperti **cermin ajaib tukang cat** — kamu bisa melihat lapisan cat dari dekat, menggores sedikit untuk lihat warna di bawahnya, mencoba warna baru tanpa benar-benar mengecat, dan melihat hasilnya instan. Kalau hasilnya jelek, tinggal "hapus" (refresh) dan mulai lagi.

## Dipakai Untuk Apa

- Debugging: mencari tahu mengapa style tidak ter-apply
- Eksperimen: coba-coba value sebelum menulis permanen
- Belajar: lihat bagaimana website lain menggunakan CSS
- Audit: cek properti yang tidak terpakai (Coverage tab)

## Kesalahan Umum

- **Tidak sadar ada properti di-override**: DevTools tunjukkan properti dicoret
- **Lupa perubahan tidak permanen**: edit di DevTools lalu lupa menyimpan ke file
- **Hanya lihat Styles, lupa Computed**: Computed menunjukkan nilai final (setelah semua kalkulasi)
- **Panik saat CSS "ngaco"**: DevTools adalah alat debug pertama — bukan stack overflow

## Hubungan dengan Materi Sebelumnya

Poin 1-3 sudah membahas teori cara CSS bekerja, cara menulis, dan format aturan. Sekarang kita punya **laboratorium real-time** untuk menguji semua teori itu. Setiap poin selanjutnya di roadmap ini akan selalu menggunakan DevTools untuk verifikasi — ini alat paling penting seorang CSS developer.

## Soal Latihan

### Soal 1
Sebutkan 3 panel utama di DevTools yang berguna untuk CSS dan fungsi singkatnya.

**Jawaban:**
- **Elements**: lihat struktur HTML dan CSS yang diterapkan
- **Styles**: edit CSS real-time
- **Computed**: lihat nilai final CSS setelah perhitungan

### Soal 2
Bagaimana cara melihat properti CSS mana yang di-override oleh properti lain?

**Jawaban:**
Di panel **Styles**, properti yang di-override akan tampil **dicoret** (strikethrough). Cari selector dengan prioritas lebih tinggi atau urutan lebih akhir.

### Soal 3
Mengapa DevTools disebut "Lab Eksperimen CSS"? Jelaskan.

**Jawaban:**
Karena kita bisa mengubah properti CSS secara real-time dan langsung melihat hasilnya tanpa harus mengedit file, save, dan refresh. Cocok untuk mencoba berbagai nilai sebelum menulis permanen di editor.
