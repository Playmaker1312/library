# 3. Anatomi Aturan CSS — Selector, Property & Value

## Penjelasan

Setiap aturan CSS terdiri dari 3 bagian wajib:

```css
selector {
  property: value;
}
```

- **Selector**: menentukan elemen HTML mana yang akan di-style
- **Property**: aspek visual yang ingin diubah (warna, ukuran, dll)
- **Value**: nilai yang diberikan ke property tersebut

Contoh nyata:
```css
h1 {
  color: #1e40af;
  font-size: 2.5rem;
}
```

## Fungsi

- Memberi struktur penulisan CSS yang konsisten
- Memisahkan "siapa yang di-style" (selector) dari "style-nya apa" (property: value)
- Standar yang dikenali semua browser

## Cara Pengimplementasian

```css
/* Komentar CSS */
/* selector { property: value; } */

body {
  font-family: sans-serif;
  line-height: 1.6;
  color: #333;
}

h1, h2, h3 {
  font-weight: bold;
}

.project-card {
  border: 1px solid #ddd;
  border-radius: 8px;
  padding: 16px;
}
```

Aturan sintaks:
- **`:`** (titik dua) memisahkan property dari value
- **`;`** (titik koma) mengakhiri setiap deklarasi
- **`{}`** (kurung kurawal) membungkus semua deklarasi
- **`/* */`** digunakan untuk komentar (tidak dibaca browser)

## Analogi

Aturan CSS seperti **resep masakan**:
- **Selector** = "Untuk siapa resep ini?" — misal "Untuk kue coklat"
- **Property** = "Apa yang diubah?" — misal "suhu oven", "waktu panggang"
- **Value** = "Menjadi apa?" — misal "180 derajat", "25 menit"

Jadi `h1 { color: red; }` artinya: "Untuk semua h1, ubah warna teks menjadi merah."

## Dipakai Untuk Apa

- Menulis semua aturan CSS dalam bentuk yang terstruktur
- Digunakan di inline, internal, maupun external stylesheet
- Dasar dari semua kode CSS yang akan datang

## Kesalahan Umum

- **Lupa titik koma** (`;`) di akhir deklarasi — browser tetap membaca baris berikutnya, tapi bisa menyebabkan error jika deklarasi berikutnya tidak dikenali
- **Lupa kurung tutup** (`}`) — semua CSS setelahnya tidak akan terbaca
- **Spasi berlebih atau typo** di property/value — browser abaikan baris tersebut
- **Komentar tidak ditutup** (`/*`) — semua kode setelahnya jadi komentar

## Hubungan dengan Materi Sebelumnya

Poin 1 menjelaskan alur kerja CSS. Poin 2 memilih external stylesheet sebagai cara penulisan. Sekarang kita pelajari **format penulisan aturan CSS** — bahasa yang akan kita gunakan untuk semua file `.css` ke depannya.

## Soal Latihan

### Soal 1
Tulis aturan CSS yang membuat semua paragraf (`<p>`) berwarna biru tua dan ukuran font 18px.

**Jawaban:**
```css
p {
  color: darkblue;
  font-size: 18px;
}
```

### Soal 2
Apa fungsi tanda titik koma (`;`) di CSS?

**Jawaban:**
Mengakhiri setiap deklarasi (property: value). Tanpa `;`, browser bingung di mana satu deklarasi berakhir.

### Soal 3
Dari kode berikut, mana selector, property, dan value?
```css
.card { background-color: #f0f0f0; }
```

**Jawaban:**
- Selector: `.card`
- Property: `background-color`
- Value: `#f0f0f0`
