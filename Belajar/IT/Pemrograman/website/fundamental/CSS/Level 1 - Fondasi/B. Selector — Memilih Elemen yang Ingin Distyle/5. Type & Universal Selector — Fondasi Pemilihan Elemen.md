# 5. Type & Universal Selector — Fondasi Pemilihan Elemen

## Penjelasan

- **Universal selector** (`*`): memilih **semua** elemen HTML
- **Type selector**: memilih elemen berdasarkan **nama tag** HTML (`h1`, `p`, `div`, `a`)

```css
/* Universal: semua elemen */
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

/* Type: semua elemen dengan tag tertentu */
body {
  font-family: sans-serif;
  line-height: 1.6;
}

h1, h2, h3 {
  line-height: 1.2;
  color: #1e40af;
}
```

## Fungsi

- **Universal**: reset CSS — menghapus style bawaan browser yang tidak konsisten
- **Type**: memberi style dasar untuk setiap jenis elemen

## Cara Pengimplementasian

```css
/* Reset CSS — tulis di paling atas stylesheet */
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

/* Type selector untuk elemen utama */
body {
  background-color: #ffffff;
  color: #111827;
}

a {
  color: inherit;
  text-decoration: none;
}

img {
  max-width: 100%;
  height: auto;
  display: block;
}
```

## Analogi

Di rumah, **Universal selector** seperti aturan "semua furnitur harus punya alas" — berlaku untuk semua benda. **Type selector** seperti aturan "semua kursi harus warna coklat" — hanya untuk benda jenis tertentu. Universal = aturan global untuk seluruh rumah. Type = aturan khusus per kategori benda.

## Dipakai Untuk Apa

- Reset global untuk konsistensi antar browser
- Styling dasar untuk body, heading, paragraph, link, gambar
- Memberikan fondasi sebelum style lebih spesifik

## Kesalahan Umum

- **Universal selector dianggap lambat**: mitos lama — di website modern, performa `*` tidak signifikan
- **Lupa reset CSS**: margin/padding default browser bikin layout terlihat berbeda di browser lain
- **Type selector terlalu general**: jika semua `p` diubah font-nya, tapi ada `p` di sidebar yang perlu berbeda — gunakan class selector

## Hubungan dengan Materi Sebelumnya

Poin 1-4: kita tahu CSS, cara menulis, format aturan, dan alat debug. Sekarang kita belajar **memilih elemen mana yang akan di-style**. Type dan Universal selector adalah yang paling dasar — memahami ini penting sebelum beralih ke selector yang lebih spesifik.

## Soal Latihan

### Soal 1
Tulis universal selector yang memberi `box-sizing: border-box` ke semua elemen.

**Jawaban:**
```css
* {
  box-sizing: border-box;
}
```

### Soal 2
Apa perbedaan type selector `p` dengan `h1`?

**Jawaban:**
`p` memilih semua elemen paragraf, `h1` memilih semua heading level 1. Keduanya adalah type selector, hanya berbeda tag HTML.

### Soal 3
Mengapa reset CSS menggunakan universal selector penting?

**Jawaban:**
Setiap browser punya style default yang berbeda (misal margin body 8px di Chrome, 10px di Firefox). Reset CSS menghilangkan perbedaan ini sehingga website terlihat konsisten di semua browser.
