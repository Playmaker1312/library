# 36. Aktivasi Flexbox & Konsep Dasar

## Penjelasan

Flexbox adalah model layout satu dimensi — mengatur distribusi ruang antar elemen dalam satu **baris** ATAU satu **kolom**.

Konsep dasar:
- **Flex container**: parent dengan `display: flex`
- **Flex items**: children langsung dari flex container
- **Main axis**: sumbu utama (arah flex-direction)
- **Cross axis**: sumbu silang (tegak lurus main axis)

```css
.container {
  display: flex; /* aktivasi flexbox */
}
```

## Fungsi

- Layout satu dimensi (baris atau kolom) yang fleksibel
- Distribusi ruang otomatis antar item
- Centering vertikal dan horizontal dengan mudah
- Pengganti float dan inline-block untuk layout modern

## Cara Pengimplementasian

```css
/* Aktivasi Flexbox */
.main-nav {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: var(--space-4) var(--space-6);
}

.nav-links {
  display: flex;
  gap: var(--space-6);
  list-style: none;
  padding: 0;
  margin: 0;
}

/* Struktur HTML */
/* <nav class="main-nav">
     <div class="logo">Logo</div>
     <ul class="nav-links">
       <li><a href="#">Beranda</a></li>
       <li><a href="#">Proyek</a></li>
     </ul>
   </nav> */
```

## Analogi

Flexbox seperti **rak piring di dapur**:
- **Display: flex** = rak dipasang — siap menampung piring
- **Flex container** = rak itu sendiri
- **Flex items** = piring-piring di rak
- **Main axis** = arah rak dipasang (horizontal seperti rak biasa, atau vertikal seperti rak gelas)
- **Cross axis** = tegak lurus arah rak (vertikal jika rak horizontal)

Sebelum flexbox, menata piring di rak perlu float dan clearfix — rumit. Flexbox membuatnya intuitif.

## Dipakai Untuk Apa

- Navigasi (logo kiri, links kanan)
- Centering konten (vertikal + horizontal)
- Card row yang sama tinggi
- Tombol dengan ikon
- Layout komponen kecil

## Kesalahan Umum

- **display: flex di banyak level tanpa perlu**: flexbox hanya memengaruhi children langsung, bukan grandchildren
- **Lupa flex container itu block-level**: `display: flex` membuat container berperilaku seperti block — lebar penuh. Alternatif: `display: inline-flex`
- **Flex item tidak responsif secara default**: item bisa menyusut — atur dengan `flex-wrap` atau `flex-shrink`

## Hubungan dengan Materi Sebelumnya

Level 1-3: kita mengatur warna, tipografi, spacing, dan interaksi. Tapi layout masih menggunakan display block/inline — navigasi belum rapi, card belum sejajar. **Flexbox** adalah solusi layout satu dimensi yang akan merevolusi cara kita menata elemen.

## Soal Latihan

### Soal 1
CSS apa untuk mengaktifkan flexbox?

**Jawaban:**
```css
display: flex;
```

### Soal 2
Sebutkan 2 properti utama flex container untuk mengatur posisi item.

**Jawaban:**
`justify-content` (main axis) dan `align-items` (cross axis).

### Soal 3
Apa perbedaan flex container dan flex items?

**Jawaban:**
Flex container adalah parent dengan `display: flex`. Flex items adalah children **langsung** dari flex container. Hanya children langsung yang terpengaruh properti flex — grandchildren tidak.
