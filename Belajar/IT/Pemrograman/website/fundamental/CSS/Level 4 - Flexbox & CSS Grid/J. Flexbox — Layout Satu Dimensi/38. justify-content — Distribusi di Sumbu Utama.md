# 38. justify-content — Distribusi di Sumbu Utama

## Penjelasan

`justify-content` mengatur bagaimana flex items didistribusikan sepanjang **main axis** (sumbu utama).

```css
.container {
  display: flex;
  justify-content: flex-start;      /* default: semua ke kiri */
  justify-content: flex-end;        /* semua ke kanan */
  justify-content: center;          /* semua ke tengah */
  justify-content: space-between;   /* pertama-kiri, terakhir-kanan, sisa dibagi */
  justify-content: space-around;    /* ruang sama di setiap sisi item */
  justify-content: space-evenly;    /* ruang benar-benar sama antar item */
}
```

## Fungsi

- Mengontrol distribusi ruang kosong antar flex items
- Sangat berguna untuk navigasi, header, tombol grup

## Cara Pengimplementasian

```css
/* Header: logo kiri, nav kanan */
.main-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: var(--space-4) var(--space-6);
}

/* Tombol grup di tengah */
.btn-group {
  display: flex;
  justify-content: center;
  gap: var(--space-4);
}

/* Card row: sama rata */
.card-row {
  display: flex;
  justify-content: space-evenly;
  flex-wrap: wrap;
  gap: var(--space-6);
}
```

Visualisasi distribusi:
```
flex-start:    [A][B][C]___________________
flex-end:     __________________[A][B][C]
center:       ________[A][B][C]________
space-between: [A]________[B]________[C]
space-around:  __[A]____[B]____[C]__
space-evenly:  __[A]__[B]__[C]__[D]__
```

## Analogi

Seperti **pengaturan furnitur di ruang tamu**:
- **flex-start** = semua kursi dirapat ke dinding kiri
- **flex-end** = semua kursi dirapat ke dinding kanan
- **center** = semua kursi di tengah ruangan
- **space-between** = kursi pertama di kiri, terakhir di kanan, sisanya rata di antaranya
- **space-evenly** = jarak antar kursi sama persis — seperti ruang tunggu dokter

## Dipakai Untuk Apa

- Navigasi header: space-between (logo kiri, menu kanan)
- Hero section: center
- Tombol: center, space-evenly
- Footer links: space-between

## Kesalahan Umum

- **Tidak ada efek karena semua item full-width**: justify-content tidak berguna jika total item = lebar container — tidak ada ruang kosong
- **Space-between vs space-around tertukar**: between untuk tepi menempel, around untuk ruang di setiap sisi item
- **Lupa flex-direction**: justify-content mengikuti main axis — jika column, justify mengontrol vertikal

## Hubungan dengan Materi Sebelumnya

Poin 36-37: flexbox aktif dengan arah tertentu. Tapi di mana posisi item? **justify-content** mengatur distribusi di sumbu utama. Untuk navigasi, `space-between` membuat logo di kiri dan menu di kanan — pola paling umum di web.

## Soal Latihan

### Soal 1
Tulis CSS untuk membuat header dengan logo di kiri dan nav di kanan.

**Jawaban:**
```css
header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```

### Soal 2
Apa perbedaan `space-between` dan `space-evenly`?

**Jawaban:**
`space-between`: item pertama di awal, terakhir di akhir, ruang hanya di antara item. `space-evenly`: ruang yang sama di semua sisi — termasuk sebelum item pertama dan setelah item terakhir.

### Soal 3
Kapan `justify-content` tidak memberikan efek?

**Jawaban:**
Ketika total lebar item = lebar container — tidak ada ruang kosong untuk didistribusikan (misal satu item flex: 1 mengisi penuh).
